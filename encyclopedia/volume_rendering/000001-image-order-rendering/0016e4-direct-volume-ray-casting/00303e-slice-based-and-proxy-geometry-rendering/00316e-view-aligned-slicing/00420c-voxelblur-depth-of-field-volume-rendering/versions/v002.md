# VoxelBlur Depth-of-Field Volume Rendering

Also called: Depth of Field Effects for Interactive Direct Volume Rendering implementation

## Overview
VoxelBlur is an interactive direct volume rendering method that provides a depth-of-field effect by selectively blurring voxels based on their distance from a predefined focus plane, simulating real-world camera lens systems [S1, unofficial]. It extends the view-aligned slicing technique by splitting the rendering pipeline into front-to-back and back-to-front passes, each maintaining an intermediate buffer where blur is applied during compositing [S1, unofficial]. Unlike standard back-to-front blending which relies on native GPU blending, VoxelBlur uses custom shader-based blending to enable the blur effect, allowing users to enhance depth perception and separate focus from context [S1, unofficial].

## How it works
**Inputs and Outputs:**
- **Input:** 3D volume data (8 or 16-bit integers), camera parameters (position, orientation, focal plane, strength), and a focus plane definition [S1, unofficial].
- **Output:** A 2D image with depth-of-field blur effects [S1, unofficial].

**Data Structures:**
- **Volume Data:** Stored in 3D textures [S1, unofficial]. Supports arbitrary dimensions, byte skipping, and gzip-compressed raw data via a custom metadata format [S1, unofficial].
- **Intermediate Buffers:** Two framebuffer objects (FBOs) are used: one for the front slices (front-to-back) and one for the back slices (back-to-front) [S1, unofficial].
- **Circle of Confusion (CoC):** A radius value derived from camera parameters and distance to the focal plane, transformed into clip-space for sampling [S1, unofficial].

**Preprocessing:**
1. Load volume data into a 3D texture [S1, unofficial].
2. Apply 3D Gaussian convolution using a compute shader to reduce noise and smooth surfaces [S1, unofficial].
3. Calculate gradients using another compute shader and optionally rescale data to [0, 1] range [S1, unofficial].

**Rendering Steps:**
1. **Slice Generation:** Intersect several view-aligned planes with the volume's bounding box to create polygons [S1, unofficial].
2. **Tessellation:** Tessellate polygons into triangles [S1, unofficial].
3. **Splitting:** Divide slices into two sets: those in front of the focal plane and those behind it [S1, unofficial].
4. **Front Pass:** Process front slices in front-to-back order [S1, unofficial]. For each slice, render the slice to the front intermediate buffer [S1, unofficial]. Sample the previous content of the front intermediate buffer with blur (using 4 samples on the CoC radius) and combine with the current slice using custom blending [S1, unofficial].
5. **Back Pass:** Process back slices in back-to-front order [S1, unofficial]. For each slice, render the slice to the back intermediate buffer [S1, unofficial]. Sample the previous content of the back intermediate buffer with blur (using 4 samples on the CoC radius) and combine with the current slice using custom blending [S1, unofficial].
6. **Final Compositing:** Combine the two intermediate buffers to produce the final output image [S1, unofficial].

**Pseudocode:**

def voxelblur_render(volume_texture, camera_params, focus_plane, strength):
    # Preprocessing
    smoothed_volume = gaussian_convolution_3d(volume_texture)
    gradients = calculate_gradients(smoothed_volume)
    rescaled_volume = rescale_to_0_1(smoothed_volume, gradients)

    # Setup intermediate buffers
    front_buffer = create_fbo()
    back_buffer = create_fbo()

    # Generate slices
    slices = generate_view_aligned_slices(rescaled_volume, camera_params)

    # Split slices
    front_slices = [s for s in slices if s.distance_to_focus_plane < 0]
    back_slices = [s for s in slices if s.distance_to_focus_plane >= 0]

    # Sort front slices front-to-back
    front_slices.sort(key=lambda s: s.distance_to_camera)
    # Sort back slices back-to-front
    back_slices.sort(key=lambda s: -s.distance_to_camera)

    # Front pass
    for slice in front_slices:
        render_slice_to_fbo(slice, front_buffer, rescaled_volume, gradients)
        coc_radius = calculate_coc_radius(slice, focus_plane, camera_params, strength)
        clip_space_coc = transform_to_clip_space(coc_radius, camera_params)
        blurred_prev = sample_with_blur(front_buffer, clip_space_coc, num_samples=4)
        composite_with_blur(front_buffer, blurred_prev)

    # Back pass
    for slice in back_slices:
        render_slice_to_fbo(slice, back_buffer, rescaled_volume, gradients)
        coc_radius = calculate_coc_radius(slice, focus_plane, camera_params, strength)
        clip_space_coc = transform_to_clip_space(coc_radius, camera_params)
        blurred_prev = sample_with_blur(back_buffer, clip_space_coc, num_samples=4)
        composite_with_blur(back_buffer, blurred_prev)

    # Final compositing
    final_image = combine_buffers(front_buffer, back_buffer)
    return final_image

## Background
VoxelBlur was developed by Schott et al. as an interactive direct volume rendering program [S1, unofficial]. It is based on the slicing volume rendering method, which uses view-aligned planes intersected with the volume's bounding box [S1, unofficial]. The depth-of-field effect was introduced to enhance depth perception and separate focus from context [S1, unofficial]. The implementation uses OpenGL 3.3 core profile and compute shaders for preprocessing [S1, unofficial].
