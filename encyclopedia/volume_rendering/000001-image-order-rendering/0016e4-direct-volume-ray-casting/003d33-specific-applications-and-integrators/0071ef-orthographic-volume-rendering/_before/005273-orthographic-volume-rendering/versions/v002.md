# Orthographic Volume Rendering

Also called: Canonical View Generation, Canonical View Setup

## Overview
Orthographic Volume Rendering generates an orthographic projection of a 3D volume by temporarily configuring a parallel projection camera, rendering to a full-resolution buffer, and resampling the result to the target resolution [S1, unofficial].

## How it works
**Inputs and Outputs:**
- **Input:** A renderer instance, a volume object, a target image buffer, a blend mode integer, and two 3D direction vectors (`viewDirection`, `viewUp`) [S1, unofficial].
- **Output:** A 2D image representing the orthographic projection of the volume [S1, unofficial].

**Data Structures:**
- **`bigImage`**: A temporary RGB unsigned char image with dimensions matching the render window size (`size[0]`, `size[1]`, `1`) [S1, unofficial].
- **`scale`**: A 2D array of doubles storing magnification factors for resampling [S1, unofficial].
- **`bounds`**: The axis-aligned bounding box of the volume, an array of 6 doubles `[minX, maxX, minY, maxY, minZ, maxZ]` [S1, unofficial].
- **`center`**: The centroid of the volume bounds [S1, unofficial].

**Parameters:**
- **`viewDirection`**: The direction the camera looks along [S1, unofficial].
- **`viewUp`**: The upward vector for camera orientation [S1, unofficial].
- **`blend_mode`**: Integer specifying the compositing mode [S1, unofficial].

**Step-by-Step Procedure:**
1. **Disable Buffer Swapping:** Prevent screen flicker during setup by disabling buffer swapping on the render window [S1, unofficial].
2. **Allocate Temporary Buffer:** Create a temporary RGB unsigned char image (`bigImage`) with dimensions equal to the current render window size [S1, unofficial].
3. **Compute Resampling Scale:** Calculate scale factors to map the full-resolution render to the target output dimensions (`dim[0]`, `dim[1]`) [S1, unofficial].
4. **Isolate Volume Rendering:** Save visibility flags for all renderers and props, then set all to `false` except the target renderer and volume to isolate the render [S1, unofficial].
5. **Compute Camera Geometry:** Retrieve volume center and bounds [S1, unofficial]. Compute distance `d` as the x-axis span of the bounds: `d = bounds[1] - bounds[0]` [S1, unofficial]. Configure a parallel projection camera: set focal point to volume center, position to `center - d * viewDirection`, viewUp to `viewUp`, and parallel scale to `d/2` [S1, unofficial].
6. **Render:** Execute a single render pass [S1, unofficial].
7. **Resample and Copy:** Restore the original camera, resample `bigImage` to the target dimensions using a resampling filter with axis magnification factors, and copy pixels to the output image [S1, unofficial].
8. **Restore State:** Restore all saved visibility flags for renderers and props, and re-enable buffer swapping [S1, unofficial].

**Pseudocode:**
```python
def CreateCanonicalView(ren, volume, image, blend_mode, viewDirection, viewUp):
    # 1. Disable buffer swapping
    ren.render_window.swap_buffers = False

    # 2. Allocate temporary buffer matching window size
    size = ren.render_window.get_size()
    bigImage = allocate_rgb_unsigned_char_image(size[0], size[1], 1)

    # 3. Compute scale factors for resampling
    dim = image.get_dimensions()
    scale = [0.0, 0.0]
    scale[0] = dim[0] / size[0]
    scale[1] = dim[1] / size[1]

    # 4. Isolate volume
    saved_flags = save_visibility_flags(ren)
    set_all_visibility_false(ren)
    set_visibility_true(ren, volume)

    # 5. Configure Orthographic Camera
    bounds = volume.get_bounds()
    center = volume.get_center()
    d = bounds[1] - bounds[0]

    camera = ren.get_active_camera()
    camera.set_focal_point(center)
    camera.set_position([
        center[0] - d * viewDirection[0],
        center[1] - d * viewDirection[1],
        center[2] - d * viewDirection[2]
    ])
    camera.set_view_up(viewUp)
    camera.set_parallel_scale(d / 2.0)
    camera.set_parallel_projection(True)

    # 6. Render
    ren.render_window.render()

    # 7. Resample to target dimensions
    resampler = create_image_resample_filter()
    resampler.set_input(bigImage)
    resampler.set_output_dimensions(dim[0], dim[1], 1)
    resampler.set_magnification(scale[0], scale[1], 1.0)
    resampled_image = resampler.execute()

    # Copy result to output image
    image.copy_from(resampled_image)

    # 8. Restore state
    restore_visibility_flags(ren, saved_flags)
    ren.render_window.swap_buffers = True
```

**Edge Cases and Pitfalls:**
- **Precision:** The calculation of `d` relies on the X-axis span [S1, unofficial]. If the volume is rotated or the bounding box is not aligned with the world axes, this may not represent the true extent along the view direction [S1, unofficial].
- **Visibility:** Failure to isolate the volume may result in background elements or other volumes being rendered into the buffer [S1, unofficial].
- **Buffer Swapping:** If buffer swapping is not disabled, the user may see flickering or intermediate render states during setup [S1, unofficial].

## Operating characteristics
Time and memory complexity are not given in the sources [S1, unofficial]. The method requires a full render pass to a temporary buffer and a resampling step [S1, unofficial].

## Background
The method is defined in the `CreateCanonicalView` function within the `vtkMultiVolRen` extension for the Visualization Toolkit (VTK) [S1, unofficial].
