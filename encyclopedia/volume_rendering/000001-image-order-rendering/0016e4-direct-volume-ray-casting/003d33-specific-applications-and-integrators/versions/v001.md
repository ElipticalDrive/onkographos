# Specific Applications and Integrators

Also called: Application-specific volume integration, specialized ray casters

## Overview
This family encompasses ray casting integrators and techniques tailored for specific physical simulations, manufacturing processes, or high-fidelity visual styles, rather than general-purpose scalar field visualization. It differs from standard Direct Volume Ray Casting by incorporating domain-specific constraints—such as time-varying projector geometries in additive manufacturing, spatially varying parameter fields for artistic control, or full photon transport physics for photorealism—into the integration loop [S1, S2, unofficial].

## Shared principles
The integrators in this family extend the standard emission-absorption model or replace it entirely with more complex physical models. Commonalities include:
1.  **Auxiliary Data Sampling:** Many methods sample additional volumes or fields (e.g., customization parameters, time slots, or light maps) alongside the primary scalar data [S1, S2, unofficial].
2.  **Modified Integration Weights:** The contribution of each sample is weighted by factors specific to the application, such as projector geometry in TVAM or photon path probability in Cinematic Rendering [S1, S2, unofficial].
3.  **Extended Ray State:** Rays may carry additional state variables beyond position and direction, such as time (for temporal patterns), weight (for stochastic sampling), or bounce count (for path tracing) [S1, S2, unofficial].

## Subtopics

### [Customization Volume Integration](5291-customization-volume-integration.md)
A method for applying position-dependent modifications to visualization parameters, such as gamma correction, without altering the underlying scalar field. It decouples the control field from the transfer function by storing parameters in a separate auxiliary volume sampled alongside the primary data.

### [TVAM Integrator](6814-tvam-integrator.md)
A base class for Volumetric Additive Manufacturing (TVAM) ray casters that handles projector ray sampling, time sampling, and stochastic vs. regular sampling modes. It provides the foundational infrastructure for mapping pixel coordinates to emitter positions and time slots, distinguishing itself from specific physical models like the Radon Integrator by not implementing the absorption physics itself.

### [Cinematic Rendering](9473-cinematic-rendering.md)
A physiologically-based method that simulates visible photon interactions with CT/MRI data to produce photorealistic images. Unlike standard ray casting, it uses path tracing with Monte Carlo integration to model global illumination effects like subsurface scattering, soft shadows, and ambient occlusion, requiring hundreds to thousands of samples per pixel.

### Cutting Plane Integration
An interactive clipping technique that renders a semi-transparent plane mesh and normal arrow to dynamically slice the volume and reveal internal structures [S1, unofficial].
- **Definition:** Updates raycasting uniforms to intersect with a user-defined plane, effectively clipping the volume domain [S1, unofficial].
- **Step:** Maps normalized height to world Z position via $z = 200 - 400 \times \text{planeHeight}$, and applies rotation using degrees converted to radians, with a $\pi$ offset if `renderAbove` is true [S1, unofficial].
- **Parameter:** `planeHeight` (normalized float 0–1), `planeRotX`/`planeRotY` (rotation angles), and `renderAbove` (boolean flip flag) [S1, unofficial].

## Background
The need for specialized integrators arises from the limitations of generic volume rendering in specific domains. TVAM integrators were developed to address the geometric complexity of projecting light patterns in 3D printing [S1, unofficial]. Cinematic Rendering emerged in medical imaging to provide radiologists with photorealistic depth cues and tissue interaction effects that standard DVR lacks [S2]. Customization integration allows artists and analysts to apply non-linear visual adjustments spatially, offering finer control than global transfer functions [S1, unofficial].
