# Multi-frame Depth Estimation via Volume Rendering

Also called: Occupancy Volume Rendering

## Overview
Multi-frame Depth Estimation via Volume Rendering projects 3D occupancy fields into multi-camera depth maps by casting rays through a parameterized coordinate system and computing depth via accumulated weights and densities [S1]. It distinguishes itself from standard Direct Volume Ray Casting by explicitly addressing the sampling imbalance inherent in large-scale autonomous driving scenes; instead of uniform depth sampling, it samples uniformly in a normalized parameterized space and maps back to ego coordinates to ensure balanced point distribution for optimization [S1].

## How it works
**Inputs and Outputs:**
*   **Input:** Camera center $o$, ray direction $d$, inside region lengths $l_x, l_y, l_z$, voxel size $d_v$, and a predicted density field $\sigma$.
*   **Output:** Depth value $D(v)$ for each pixel.

**Data Structures:**
*   **Ray:** Defined as $v(t) = o + td$ for $t \in [t_n, t_f]$.
*   **Sampling Points:** A set of $L(v)$ points $\{t_k\}_{k=1}^{L(v)}$ along the ray.
*   **Density:** $\sigma(t_k)$, the occupancy density at point $t_k$.

**Steps:**
1.  **Ray Definition:** Cast a ray from the camera center $o$ along direction $d$ towards the pixel. The ray is parameterized as $v(t) = o + td$, where $t$ represents the distance in ego coordinates [S1].
2.  **Determine Sampling Parameters:** Calculate the bound $r_b(v)$ of the inside region for the ray and the specific number of samples $L(v)$ required:
    $$ r_b(v) = \frac{\sqrt{(d \cdot i l_x)^2 + (d \cdot j l_y)^2 + (d \cdot k l_z)^2}}{2\|d\|} $$
    $$ L(v) = \frac{2 r_b(v)}{\alpha d_v} $$
    where $i, j, k$ are unit vectors in the $x, y, z$ directions, $l_x, l_y, l_z$ are the lengths of the inside region, $d_v$ is the voxel size, and $\alpha$ is a scaling factor (typically 0.667) [S1].
3.  **Parameterized Sampling:** Sample $L(v)$ points from a uniform distribution $U[0, 1]$ in the parameterized coordinate system [S1].
4.  **Coordinate Mapping:** Use the inverse function of the parameterization (Equation 1 in source, not explicitly defined in notes but implied as the mapping from parameterized space to ego coordinates) to calculate the sampled points $\{t_k\}$ in ego coordinates [S1].
5.  **Density Prediction:** Obtain the density $\sigma(t_k)$ at each sampled point. The method predicts rendering weight directly rather than raw density to better adapt to the occupancy representation [S1].
6.  **Depth Computation:** Compute the depth $D(v)$ using the front-to-back accumulation equation:
    $$ D(v) = \sum_{k=1}^{L} T(t_k)(1 - \exp(-\sigma(t_k)\delta_k))t_k $$
    where the transmittance $T(t_k)$ is:
    $$ T(t_k) = \exp\left(-\sum_{k'=1}^{k-1} \sigma(t_k')\delta_{k'}\right) $$
    and $\delta_k = t_{k+1} - t_k$ are the intervals between sampled points [S1].

**Pseudocode:**
```python
def render_depth(camera_center, ray_direction, inside_region_lengths, voxel_size, alpha, density_field):
    """
    Renders depth for a single ray using multi-frame volume rendering.
    
    Args:
        camera_center: 3D vector (o)
        ray_direction: 3D vector (d)
        inside_region_lengths: tuple (lx, ly, lz)
        voxel_size: float (dv)
        alpha: float (scaling factor, e.g., 0.667)
        density_field: function sigma(t) returning density at 3D point t
        
    Returns:
        depth: float
    """
    # Step 1: Ray is defined as v(t) = o + t*d
    
    # Step 2: Calculate sampling parameters
    lx, ly, lz = inside_region_lengths
    d_norm = norm(ray_direction)
    
    # Unit vectors
    i = [1, 0, 0]
    j = [0, 1, 0]
    k = [0, 0, 1]
    
    # Dot products
    d_dot_ix = dot(ray_direction, i) * lx
    d_dot_jy = dot(ray_direction, j) * ly
    d_dot_kz = dot(ray_direction, k) * lz
    
    # Bound rb(v)
    rb = sqrt(d_dot_ix**2 + d_dot_jy**2 + d_dot_kz**2) / (2 * d_norm)
    
    # Number of samples L(v)
    L = int(2 * rb / (alpha * voxel_size))
    
    # Step 3: Sample L points from U[0, 1] in parameterized coordinate
    # Note: The exact inverse function mapping parameterized space to ego coordinates
    # is not fully detailed in the provided text, but is assumed to be a linear 
    # or affine mapping based on the ray bounds. We assume a helper function 
    # map_param_to_ego(u) exists which maps u in [0,1] to t in ego coordinates.
    # [G] Implementation note: In many occupancy grids, this maps the normalized 
    # coordinate to the physical extent of the grid along the ray.
    u_samples = random_uniform(L)
    
    # Step 4: Calculate sampled points {tk} in ego coordinates
    t_samples = [map_param_to_ego(u) for u in u_samples]
    t_samples.sort() # Ensure sorted order for front-to-back
    
    # Step 5: Get density sigma(tk)
    # The method predicts rendering weight directly, but the formula uses sigma.
    # We assume density_field returns the effective sigma.
    sigmas = [density_field(point_to_3d(t)) for t in t_samples]
    
    # Step 6: Compute depth
    depth = 0.0
    transmittance = 1.0
    
    for k in range(L):
        t_k = t_samples[k]
        sigma_k = sigmas[k]
        
        # Interval delta_k
        if k < L - 1:
            delta_k = t_samples[k+1] - t_k
        else:
            # [G] For the last sample, delta is often assumed to be the same as previous
            # or a small epsilon to prevent division by zero if needed, 
            # though here it is used in exp(-sigma*delta).
            delta_k = t_k - t_samples[k-1] if k > 0 else 0.01 
            
        # Weight contribution
        weight = transmittance * (1 - exp(-sigma_k * delta_k))
        depth += weight * t_k
        
        # Update transmittance
        transmittance *= exp(-sigma_k * delta_k)
        
    return depth
```

**Parameters:**
*   $\alpha$: Scaling factor for sample count. Typical value: 0.667 [S1].
*   $d_v$: Voxel size.

**Edge Cases and Pitfalls:**
*   **Sampling Imbalance:** Uniform sampling in depth or disparity space results in an unbalanced series of points in the parameterized grid, detrimental to optimization. This is solved by sampling in the parameterized coordinate space $U[0,1]$ and mapping back [S1].
*   **Large-scale Scenes:** Conventional supervision (difference between rendered and raw images) does not work well due to large-scale scenes and few-view supervision [S1].

## Subtopics

### Semantic Volume Rendering
A variant that renders semantic outputs from volume features using the same volume rendering equation as depth estimation, but with semantic values $S(t_k)$ instead of depth [S1]. It maps volume features to semantic outputs $S(x)$ using a semantic head with $c$ output channels [S1]. To save memory and improve efficiency, it does not render pixels assigned with 'uncertain' labels (pixels with M zero logits) [S1]. It renders only the central frame instead of multiple frames and reduces the sample ratio to $L_s = L/4$ [S1]. The output is computed as $\hat{S}_{pix}(r) = \sum_{k=1}^{L_s} T(t_k)(1 - \exp(-\sigma(t_k)\delta_k))S(t_k)$ [S1]. The loss function is $L_{total} = \sum_i L_i^{pe} + \lambda L_i^{sem}(\hat{S}_{pix}, S_{pix})$, where $L_{sem}$ is cross-entropy loss and $\lambda$ is the semantic loss weight (typically 0.05) [S1].

## Operating characteristics
*   **Complexity:** Time complexity is linear with respect to the number of samples $L(v)$ per ray. Memory complexity depends on the storage of the 3D occupancy grid and the intermediate transmittance/density values.
*   **Performance:** The method is evaluated on the nuScenes and SemanticKITTI datasets [S1]. It produces visually appealing depth maps with texture details and fine-grained occupancy [S1].
*   **Strengths:** Adapts well to occupancy representations by predicting rendering weight directly. The parameterized sampling strategy ensures balanced point distribution, which is critical for optimization in large-scale scenes [S1].
*   **Limitations:** Conventional photometric supervision is ineffective for this method due to large-scale scenes and limited view supervision [S1]. It requires a 3D convolution network to extract features and predict occupancy outputs [S1].

## Background
The method was introduced in "OccNeRF: Advancing 3D Occupancy Prediction in LiDAR-Free Environments" [S1]. It builds on the foundational mechanism of Direct Volume Ray Casting [19-direct-volume-ray-casting.md], specifically diverging in the Compositing step by using a parameterized coordinate system for sampling [S1]. It is widely used in NeRF-based methods for 3D occupancy prediction in autonomous driving environments [S1].
