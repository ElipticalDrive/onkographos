# TVAM Integrator

Also called: common TVAM integrator base class

## Overview
The TVAM Integrator is a base class for volumetric additive manufacturing (TVAM) ray casters that handles projector ray sampling, time sampling, and regular versus stochastic sampling modes [S1, unofficial]. It solves the problem of generating correct ray paths for tomographic projection by managing the mapping from pixel coordinates to emitter positions and time slots. It differs from sibling methods like the [Radon Integrator](7470-radon-integrator.md) and [CornerIntegrator](7445-cornerintegrator.md) by providing the foundational sampling infrastructure without implementing specific physical models (such as pure absorption or corner masking) [S1, unofficial].

## How it works
**Inputs and Outputs:**
*   **Inputs:** Scene description containing shapes (specifically a target shape and an interior medium), projector emitter definitions, and configuration parameters.
*   **Outputs:** A set of rays defined by origin, direction, time, and weight, ready for traversal.

**Data Structures:**
The integrator maintains state for active pixels and sample positions.
*   `active_pixels`: Array of pixel indices.
*   `spp`: Samples per pixel.
*   `w`, `h`: Width and height of the projector image.
*   `n_patterns`: Total number of projection patterns (time slots).
*   `emitter_idx`: Index of the current emitter.

**Parameters:**
*   `sample_time` (bool, default `False`): If true, adds a stochastic offset to the time sample.
*   `print_time` (float, default `1.0`): Scaling factor for ray weight.
*   `target_id` (str, default `'target'`): ID of the target shape for surface-aware discretization.
*   `transmission_only` (bool, default `True`): If true, only samples the transmission component of the BSDF at interfaces.
*   `regular_sampling` (bool, default `False`): If true, samples from the center of the pixel (0.5 offset) instead of using a random offset.
*   `K` (int, default `2`): Exponent for physical model evaluation (used in derived classes).
*   `M` (int, default `4`): Exponent for sparsity evaluation (used in derived classes).
*   `tp` (float, default `0.1`): Threshold parameter (used in derived classes).
*   `top` (float, default `0.2`): Threshold parameter (used in derived classes).
*   `tinhibitor` (float, default `0.2`): Threshold parameter (used in derived classes).
*   `weight_object` (float, default `1`): Weight for object regions.
*   `weight_void` (float, default `1`): Weight for void regions.
*   `weight_limit` (float, default `1`): Weight for limit regions.
*   `weight_sparsity` (float, default `0`): Weight for sparsity.

**Steps:**

1.  **Prepare:**
    *   If `regular_sampling` is true, force `spp` to 1. Shooting from the pixel center makes `spp > 1` nonsensical [S1, unofficial].
    *   Check if `wavefront_size` (calculated as `active_size * spp`) exceeds $2^{32}$. If so, raise an exception [S1, unofficial].

2.  **Parse Scene:**
    *   Iterate over scene shapes to find the target shape (identified by `target_id`) and the interior medium [S1, unofficial].
    *   Raise an error if more than one medium is found [S1, unofficial].

3.  **Sample Rays:**
    *   Compute discrete sample position `idx` by repeating `active_pixels` `spp` times [S1, unofficial].
    *   Compute pixel coordinates `pos.y` and `pos.x` from `pixel_idx`:
        $$ pos.y = \lfloor pixel\_idx / w \rfloor $$
        $$ pos.x = pixel\_idx - (pos.y \times w) $$
    *   Convert pixel position to floating point $[0, 1]$ range:
        *   If `regular_sampling` is true, add 0.5 offset to both coordinates.
        *   Else, add `sampler.next_2d()` to both coordinates.
        *   Scale by $1/w$ for x and $1/h$ for y.
    *   Compute time sample:
        $$ time = emitter\_idx / n\_patterns $$
        *   If `sample_time` is true, add `sampler.next_1d()` to `time` before dividing by `n_patterns` (or effectively adding a fractional slot offset) [S1, unofficial].
    *   Sample ray from emitter using the computed position and time.
    *   Scale ray weight by `print_time` (specifically, multiply by $1 / \text{print\_time}$, which is equivalent to dividing by `print_time` if `print_time` represents the PDF denominator, though the source says "scale weight by print_time (1/pdf of time sample)" implying the weight adjustment compensates for the time sampling probability) [S1, unofficial].

**Pseudocode:**

```python
def prepare(self):
    if self.regular_sampling:
        self.spp = 1
    if self.active_size * self.spp > 2**32:
        raise Exception("Wavefront size exceeds 2^32")

def parse_scene(self, scene):
    target_shape = None
    medium = None
    for shape in scene.shapes:
        if shape.id == self.target_id:
            target_shape = shape
        if shape.has_medium:
            if medium is not None:
                raise Exception("More than one medium found")
            medium = shape.medium
    if target_shape is None:
        raise Exception("Target shape not found")
    return target_shape, medium

def sample_rays(self, sampler, emitter, active_pixels, w, h, n_patterns, emitter_idx):
    # Repeat active_pixels spp times
    indices = []
    for p in active_pixels:
        for _ in range(self.spp):
            indices.append(p)
    
    rays = []
    for pixel_idx in indices:
        # Compute pixel coordinates
        row_idx = pixel_idx // w
        col_idx = pixel_idx - (row_idx * w)
        
        # Convert to [0, 1]
        if self.regular_sampling:
            u = (col_idx + 0.5) / w
            v = (row_idx + 0.5) / h
        else:
            u = (col_idx + sampler.next_2d()[0]) / w
            v = (row_idx + sampler.next_2d()[1]) / h
            
        # Compute time
        time = emitter_idx / n_patterns
        if self.sample_time:
            time += sampler.next_1d() / n_patterns
            
        # Sample ray from emitter
        ray = emitter.sample(u, v, time)
        
        # Scale weight
        ray.weight *= self.print_time
        
        rays.append(ray)
    return rays
```

**Edge Cases and Pitfalls:**
*   **Regular Sampling:** Enforcing `spp=1` when `regular_sampling` is true is critical to avoid redundant samples from the same pixel center [S1, unofficial].
*   **Wavefront Overflow:** Checking against $2^{32}$ prevents integer overflow in wavefront processing [S1, unofficial].
*   **Multiple Mediums:** The parser strictly enforces a single interior medium to ensure consistent physical modeling [S1, unofficial].

## Subtopics

### [CornerIntegrator](7445-cornerintegrator.md)
Specialized integrator that filters rays intersecting build volume corners to reduce discretization artifacts.

### [Radon Integrator](7470-radon-integrator.md)
Computes the Radon transform by tracing rays through a purely absorptive medium.

## Operating characteristics
*   **Time Complexity:** Linear with respect to the number of active pixels and samples per pixel ($O(N \times SPP)$).
*   **Memory Complexity:** Linear with respect to the number of rays generated.
*   **Strengths:** Provides a flexible base for TVAM simulations, supporting both regular and stochastic sampling.
*   **Limitations:** Does not implement specific physical interactions (absorption, scattering) itself; relies on derived classes for that.
*   **When to use:** When implementing a custom TVAM integrator that requires specific ray sampling logic or physical models.
*   **When not to use:** For standard volume rendering without additive manufacturing constraints.

## Background
The TVAM Integrator originates from the Dr. TVAM project, an inverse rendering framework for Tomographic Volumetric Additive Manufacturing [S1, unofficial]. It was developed to facilitate the simulation of light propagation in DLP-based 3D printing processes, enabling the optimization of projection patterns for accurate object fabrication.
