# Minimum Intensity Projection


## Overview
Minimum Intensity Projection (MinIP) is a volume rendering technique that projects the scalar field by selecting the voxel with the lowest intensity value along each viewing ray [S1][S2, unofficial]. Unlike front-to-back compositing, it does not accumulate opacity or color, instead maintaining a single accumulator initialized to $+\infty$ [Parent]. It is primarily used in medical imaging to visualize low-density structures such as air-filled lungs or fluid-filled ventricles, complementing Maximum Intensity Projection (MIP) which highlights high-density structures like bones or contrast-enhanced vessels [S1].

## How it works
**Inputs and Outputs:**
*   **Input:** 3D volume data $V$ (scalar field), camera parameters (origin $O$, direction $D$), volume bounds, and a transfer function $TF$.
*   **Output:** 2D image pixel color and depth.

**Data Structures:**
*   **Accumulator:** `the_ref` (float), initialized to $+\infty$ [S2, unofficial].
*   **Position:** `the_coord` (vec3), initialized to ray start [S2, unofficial].
*   **Value:** `the_value` (vec4), stores the RGBA color from the transfer function [S2, unofficial].

**Algorithm Steps:**
1.  **Ray Initialization:** Cast a ray from the eye through the pixel. Determine entry $t_{start}$ and exit $t_{end}$ [Parent].
2.  **Primary Search:** Iterate $n$ steps along the ray. For each step $i$:
    *   Compute position $P_i = O + t_i D$.
    *   Sample volume $d_i = V(P_i)$ using trilinear interpolation [Parent].
    *   If $d_i < \text{the\_ref}$, update $\text{the\_ref} \leftarrow d_i$, $\text{the\_coord} \leftarrow P_i$, and $\text{the\_value} \leftarrow TF(d_i)$ [S2, unofficial].
3.  **Refinement (Optional but specified in [S2, unofficial]):** To locate the minimum more precisely, perform a binary search-like refinement around `the_coord`.
    *   Initialize `substep` = step size.
    *   Loop 4 times:
        *   `substep` $\leftarrow$ `substep` / 2.
        *   Sample $P_{left} = \text{the\_coord} - \text{substep}$ and $P_{right} = \text{the\_coord} + \text{substep}$.
        *   Let $d_{left} = V(P_{left})$ and $d_{right} = V(P_{right})$.
        *   If $d_{left} \le \text{the\_ref}$, update accumulator with $P_{left}, d_{left}$ [S2, unofficial].
        *   Else if $d_{right} < \text{the\_ref}$, update accumulator with $P_{right}, d_{right}$ [S2, unofficial].
4.  **Color and Depth:**
    *   Convert color to physical space if necessary (e.g., sRGB to linear) [S2, unofficial].
    *   Compute depth $z$ from the final `the_coord` transformed to NDC [S2, unofficial].

```python
def minip_ray_cast(volume, origin, direction, bounds, dims, step_size, transfer_function):
    """
    Renders a single ray using Minimum Intensity Projection with refinement.
    """
    # 1. Intersection [G]

    t_start = max(t0, 0.0)
    t_end = t1
    
    if t_start >= t_end:
        return None, None

    # 2. Initialization
    the_ref = float('inf')
    the_coord = None
    the_value = None

    # 3. Primary Loop
    while t < t_end:
        # Position in world space
        pos = [origin[i] + t * direction[i] for i in range(3)]
        
        # Sample volume [Parent]
        # Assuming trilinear interpolation defined in parent or helper

        # Update minimum

            the_ref = scalar_val
            the_coord = pos
            the_value = transfer_function(scalar_val)
            
        t += step_size

    # 4. Refinement Loop [S2, unofficial]
    if the_coord is not None:
        substep = step_size
        for _ in range(4):
            substep *= 0.5
            # Calculate neighbors
            coord1 = [the_coord[i] - substep * direction[i] for i in range(3)]
            coord2 = [the_coord[i] + substep * direction[i] for i in range(3)]
            
            val1 = trilinear_interpolate(volume, coord1, dims)
            val2 = trilinear_interpolate(volume, coord2, dims)
            
            # Update logic from [S2, unofficial]
            if val1 <= the_ref:
                the_ref = val1
                the_coord = coord1
                the_value = transfer_function(val1)
            elif val2 < the_ref:
                the_ref = val2
                the_coord = coord2
                the_value = transfer_function(val2)

    # 5. Output
    if the_value is None:
        return None, None
        
    # Color space conversion [S2, unofficial]
    color_rgb = the_value.rgb
    # Assuming srgb2physical is defined or identity if not srgb
    physical_color = srgb2physical(color_rgb) if the_value.colorspace == 'srgb' else color_rgb
    opacity = the_value.a * 1.0 # u_material.opacity assumed 1.0 for simplicity

    return (physical_color, opacity), depth
```

**Parameters:**
*   `step_size`: Distance between samples. Typical values depend on volume resolution and desired speed [S2, unofficial].
*   `nsteps`: Number of primary steps. Often derived from volume dimensions and step size [S2, unofficial].

**Edge Cases:**
*   **Flat Regions:** If the minimum is constant over a range, the refinement step helps pinpoint a specific location, but the value remains the same [S2, unofficial].
*   **Noise:** MinIP is sensitive to noise, as it highlights the absolute lowest value, which may be an artifact rather than a structure [S1].

## Subtopics

### Slab MinIP
Renders a subset of the volume (a slab) along the viewing direction to reduce clutter and improve performance. It selects the minimum within the slab thickness [S1].

### Local MinIP
Computes the minimum within a local neighborhood rather than the entire ray, useful for isolating specific features [S1].

## Operating characteristics
*   **Time Complexity:** $O(N \cdot S)$, where $N$ is the number of pixels and $S$ is the number of samples per ray. The refinement step adds a constant overhead (4 iterations) [S2, unofficial].
*   **Memory Complexity:** $O(1)$ per ray, as only the current minimum is stored [S2, unofficial].
*   **Strengths:** Rapidly generates images highlighting low-density structures (e.g., lungs, airways) [S1]. Hardware-accelerated via simple comparison operations [S1].
*   **Limitations:** Loses depth information, making it difficult to distinguish overlapping structures of different densities [S1]. Sensitive to noise [S1].
*   **When to use:** When visualizing low-intensity features is the primary goal, or as a complement to MIP [S1].

## Background
MinIP was developed alongside MIP for diagnostic imaging, particularly in 3D CT and MR angiography [S1]. It allows for the interactive exploration of low-density anatomical structures, mitigating the depth-perception drawback of static projections through animation [S1].
