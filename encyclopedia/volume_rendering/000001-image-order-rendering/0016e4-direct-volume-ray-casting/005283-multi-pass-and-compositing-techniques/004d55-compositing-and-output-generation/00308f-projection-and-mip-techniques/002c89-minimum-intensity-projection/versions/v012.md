# Minimum Intensity Projection
Also called: Intensity Projection (MinIP), min intensity projection

## Overview
Minimum Intensity Projection (MinIP) is a volume rendering technique that projects the lowest intensity value encountered along each viewing ray to the two-dimensional image plane [S1, unofficial][S8, unofficial]. Unlike standard front-to-back compositing which blends all samples based on opacity, MinIP discards all but the single minimum sample, effectively highlighting low-density or dark structures such as air-filled spaces, bronchi, or hypodense ducts against brighter surrounding tissue [S1, unofficial][S3]. It serves as the inverse counterpart to Maximum Intensity Projection (MIP) [S1, unofficial].

## How it works
MinIP operates as a raycasting projection mode that searches for the global minimum scalar value along the ray path [S8, unofficial]. It does not use the standard optical compositing model (transmittance/opacity accumulation) because it selects a single voxel rather than blending a volume [G].

### Inputs and Outputs
*   **Inputs**:
    *   `volume`: 3D scalar field (texture).
    *   `start_coord`: Ray origin in texture coordinates.
    *   `step_coord`: Ray step vector in texture coordinates.
    *   `nsteps`: Number of discrete samples along the ray.
    *   `sizef`: Volume dimensions (width, height, depth) used for coordinate normalization.
    *   `u_material`: Material properties including opacity multiplier and color space setting.
*   **Outputs**:
    *   `out_color`: Final pixel color (RGB) and opacity (A).
    *   `out.coord`: The 3D texture coordinate of the minimum voxel.
    *   `out.depth`: The normalized device coordinate (NDC) depth ($z/w$) for the minimum voxel.

### Data Structures
The algorithm maintains three state variables during the ray traversal:
1.  `the_ref`: The minimum intensity value found so far (scalar).
2.  `the_coord`: The 3D texture coordinate corresponding to `the_ref` (vec3).
3.  `the_value`: The full sample data (e.g., RGBA vec4) at `the_coord` [S8, unofficial].

### Algorithm Steps
1.  **Initialization**: Set `the_ref` to positive infinity (or a sufficiently large value, e.g., 999999.0). Set `the_coord` to `start_coord`. Initialize `the_value` to zero [S8, unofficial].
2.  **Primary Coarse Search**: Iterate `iter` from 0 to `nsteps - 1`:
    *   Calculate sample coordinate: $coord = start\_coord + iter \cdot step\_coord$ [S8, unofficial].
    *   Sample the volume: $value = \text{sample\_vol}(coord, sizef)$ [S8, unofficial].
    *   Extract scalar reference: $reff = value.r$ (assuming scalar is stored in the red channel) [S8, unofficial].
    *   Update minimum: If $reff < the\_ref$, update $the\_ref = reff$, $the\_coord = coord$, and $the\_value = value$ [S8, unofficial].
3.  **Refinement Loop**: To improve positional accuracy of the minimum, perform a binary search-like refinement:
    *   Initialize `substep_coord` = `step_coord` [S8, unofficial].
    *   Iterate `iter2` from 0 to 3 (4 iterations):
        *   Halve the step: $substep\_coord = substep\_coord \cdot 0.5$ [S8, unofficial].
        *   Define candidate coordinates: $coord1 = the\_coord - substep\_coord$ and $coord2 = the\_coord + substep\_coord$ [S8, unofficial].
        *   Sample candidates: $value1 = \text{sample\_vol}(coord1, sizef)$ and $value2 = \text{sample\_vol}(coord2, sizef)$ [S8, unofficial].
        *   Extract references: $ref1 = value1.r$ and $ref2 = value2.r$ [S8, unofficial].
        *   Update minimum:
            *   If $ref1 \le the\_ref$, update state with $ref1, coord1, value1$ [S8, unofficial].
            *   Else if $ref2 > the\_ref$, update state with $ref2, coord2, value2$ [S8, unofficial].
4.  **Color Mapping**:
    *   Map the scalar value to color: $color = \text{sampled\_value\_to\_color}(the\_value)$ [S8, unofficial].
    *   Convert to physical (linear) color space:
        *   If `colorspace` is 'srgb': $physical\_color = \text{srgb2physical}(color.rgb)$ [S8, unofficial].
        *   Else: $physical\_color = color.rgb$ [S8, unofficial].
    *   Calculate final opacity: $opacity = color.a \cdot u\_material.opacity$ [S8, unofficial].
    *   Set output color: $out\_color = vec4(physical\_color, opacity)$ [S8, unofficial].
5.  **Depth and Coordinate Output**:
    *   Convert texture coordinate to data position: $data\_pos = the\_coord \cdot sizef - vec3(0.5, 0.5, 0.5)$ [S8, unofficial].
    *   Transform to world space: $world\_pos = u\_wobject.world\_transform \cdot vec4(data\_pos, 1.0)$ [S8, unofficial].
    *   Transform to NDC: $ndc\_pos = u\_stdinfo.projection\_transform \cdot u\_stdinfo.cam\_transform \cdot world\_pos$ [S8, unofficial].
    *   Set output depth: $out.depth = ndc\_pos.z / ndc\_pos.w$ [S8, unofficial].
    *   Set output coordinate: $out.coord = the\_coord$ [S8, unofficial].

### Pseudocode
```python
def minip_raycast(start_coord, step_coord, nsteps, volume_sampler, sizef, material):
    """
    Minimum Intensity Projection raycasting.
    volume_sampler(coord, sizef) returns a vec4 (rgba) where r is the scalar intensity.
    """
    # 1. Initialization
    the_ref = float('inf')
    the_coord = start_coord
    the_value = vec4(0.0)
    
    # 2. Primary Coarse Search
    for iter in range(nsteps):
        coord = start_coord + iter * step_coord
        value = volume_sampler(coord, sizef)
        reff = value.r
        
        if reff < the_ref:
            the_ref = reff
            the_coord = coord
            the_value = value
            
    # 3. Refinement Loop (4 iterations)
    substep_coord = step_coord
    for iter2 in range(4):
        substep_coord = substep_coord * 0.5
        coord1 = the_coord - substep_coord
        coord2 = the_coord + substep_coord
        
        value1 = volume_sampler(coord1, sizef)
        value2 = volume_sampler(coord2, sizef)
        
        ref1 = value1.r
        ref2 = value2.r
        
        # Source uses exact operators: <= for first candidate, > for second
        if ref1 <= the_ref:
            the_ref = ref1
            the_coord = coord1
            the_value = value1
        elif ref2 > the_ref:
            the_ref = ref2
            the_coord = coord2
            the_value = value2
            
    # 4. Color Mapping
    color = colormap(the_value)
    
    if material.colorspace == 'srgb':
        physical_color = srgb_to_linear(color.rgb)
    else:
        physical_color = color.rgb
        
    opacity = color.a * material.opacity
    out_color = vec4(physical_color, opacity)
    
    # 5. Depth and Coordinate Calculation
    data_pos = the_coord * sizef - vec3(0.5, 0.5, 0.5)
    world_pos = material.world_transform * vec4(data_pos, 1.0)
    ndc_pos = material.projection_transform * material.cam_transform * world_pos
    
    out_coord = the_coord
    out_depth = ndc_pos.z / ndc_pos.w
    
    return out_color, out_coord, out_depth

def colormap(value):
    """Maps a scalar vec4 sample to an RGBA color using a standard lookup table."""
    # Standard implementation: lookup intensity in transfer function
    return vec4(0.0, 0.0, 0.0, 1.0)  # Placeholder for actual LUT lookup [G]

def srgb_to_linear(srgb):
    """Converts sRGB color components to linear physical color space."""
    # Standard implementation: apply sRGB gamma expansion
    return vec3(
        1.055 * pow(max(srgb.x, 0.04045), 1.0/2.4) - 0.055 if srgb.x > 0.04045 else srgb.x / 12.92,
        1.055 * pow(max(srgb.y, 0.04045), 1.0/2.4) - 0.055 if srgb.y > 0.04045 else srgb.y / 12.92,
        1.055 * pow(max(srgb.z, 0.04045), 1.0/2.4) - 0.055 if srgb.z > 0.04045 else srgb.z / 12.92
    )
```

### Parameters and Edge Cases
*   **`nsteps`**: Determines the resolution of the initial search [S8, unofficial].
*   **Refinement Iterations**: Fixed at 4 in the reference implementation, providing a $1/16$th precision improvement over the initial step size [S8, unofficial].
*   **Scalar Channel**: The implementation assumes the scalar intensity is stored in the red channel (`value.r`) [S8, unofficial].
*   **Infinity Initialization**: `the_ref` must be initialized to a value larger than any possible intensity in the volume [S8, unofficial].
*   **No Compositing**: Since only one voxel is selected, standard opacity accumulation and early ray termination are not applicable [G]. The opacity is derived from the colormap alpha and material settings [S8, unofficial].

## Operating characteristics
*   **Time Complexity**: $O(N)$ per ray, where $N$ is the number of steps [S8, unofficial]. The refinement loop adds a constant overhead ($4 \times 2$ samples) [S8, unofficial].
*   **Memory Complexity**: $O(1)$ auxiliary memory per ray (storing only the current best reference, coordinate, and value) [S8, unofficial].
*   **Strengths**: Rapidly highlights low-intensity structures such as lungs, vessels in contrast-enhanced scans where background is bright, or hypodense ducts [S1, unofficial][S3]. Hardware acceleration is feasible due to simple comparison logic [S1, unofficial].
*   **Limitations**: Loses all depth information for the selected voxel, making it difficult to perceive the 3D structure of the scene [S1, unofficial]. Static images lack depth cues [S4]. Only a small fraction of the data is used, potentially discarding relevant contextual information [S4].
*   **When to Use**: Angiography, bone visualization (if inverted), or highlighting air-filled spaces and hypodense structures like the bile tree or pancreatic duct [S1, unofficial][S3].
*   **When Not to Use**: When depth perception is critical or when the volume contains mixed densities where the minimum is not the feature of interest [S1, unofficial].

## Background
MinIP was developed alongside MIP for projective diagnostic imaging, particularly in 3D CT and MR angiography [S1, unofficial]. It allows for the rapid generation of images that clearly display vessels, tumors, or bones by selecting the extremal intensity values along the ray [S1, unofficial]. While static MinIPs suffer from a lack of depth information, they are useful in interactive exploration or animation sequences where the drawback is less obvious [S4]. The technique is particularly valuable for analyzing the bronchial tree before contrast administration, as air-filled bronchi are the least dense structures in the thorax [S3].
