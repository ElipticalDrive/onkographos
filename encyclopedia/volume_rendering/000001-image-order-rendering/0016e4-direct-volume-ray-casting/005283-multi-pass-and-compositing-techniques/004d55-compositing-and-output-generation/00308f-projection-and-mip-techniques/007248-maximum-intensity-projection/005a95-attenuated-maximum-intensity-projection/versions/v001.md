# Attenuated Maximum-Intensity Projection


## Overview
Attenuated Maximum-Intensity Projection (Attenuated MIP) is a volume rendering technique that projects the maximum intensity along rays while suppressing contributions from deep or weak samples using an exponential falloff based on accumulated intensity [S1, unofficial]. Unlike standard [Maximum Intensity Projection](10702-maximum-intensity-projection-mip.md) which simply selects the highest value regardless of depth, Attenuated MIP dims background haze and weaker structures, ensuring that only strong, distinct peaks survive the projection [S1, unofficial]. It is chosen when the goal is to highlight high-intensity features without the visual clutter of overlapping lower-intensity volumes that often obscures detail in standard MIP.

## How it works
**Inputs and Outputs**
*   **Volume:** A 3D array `vol` of shape $(n_x, n_y, n_z)$ containing float32 values [S1, unofficial].
*   **Geometry:** `origin` (world coordinates of `vol[0,0,0]`), `spacing` (voxel dimensions per axis), `near_pts` and `far_pts` (world-space entry and exit points for each pixel, shape $(H, W, 3)$) [S1, unofficial].
*   **Parameters:** `value_range` $(lo, hi)$ defining the contrast window, `attenuation` coefficient (default 0.05), `n_samples` (default 256), and `colormap` [S1, unofficial].
*   **Output:** An RGB image of size $(H, W, 3)$ with values in $[0, 255]$ [S1, unofficial].

**Data Structures**
*   `out_val`: Array of size $H \times W$, initialized to $-\infty$, storing the running maximum intensity [S1, unofficial].
*   `acc`: Scalar accumulator initialized to $0.0$, storing the sum of normalized intensities along the ray [S1, unofficial].
*   `inv_span`: Precomputed scalar $1.0 / (hi - lo)$ [S1, unofficial].

**Algorithm Steps**
1.  **Initialization:** Set `out_val` to $-\infty$ and `acc` to $0.0$. If $hi \le lo$, set $hi = lo + 1.0$ to prevent division by zero [S1, unofficial].
2.  **Ray Sampling Loop:** For each sample index $s$ from $0$ to $n_{samples}-1$:
    a.  Calculate parametric position $t = s / (n_{samples} - 1)$ if $n_{samples} > 1$, else $0.0$ [S1, unofficial].
    b.  Compute world point $P = P_0 + (P_1 - P_0) \cdot t$, where $P_0$ and $P_1$ are the near and far points for the current pixel [S1, unofficial].
    c.  Convert $P$ to continuous voxel indices:
        $$
        f_x = \frac{P_x - origin_x}{spacing_x}, \quad f_y = \frac{P_y - origin_y}{spacing_y}, \quad f_z = \frac{P_z - origin_z}{spacing_z}
        $$
    d.  Identify valid voxels where $0 \le f_x < n_x-1$, $0 \le f_y < n_y-1$, $0 \le f_z < n_z-1$ [S1, unofficial].
    e.  For valid voxels, compute integer floor coordinates $(x_0, y_0, z_0)$ and ceiling coordinates $(x_1, y_1, z_1)$, clamped to maximum dimensions. Compute fractional parts $dx = f_x - x_0$, $dy = f_y - y_0$, $dz = f_z - z_0$ [S1, unofficial].
    f.  Perform trilinear interpolation of the 8 surrounding voxels:
        $$
        \begin{aligned}
        c_{00} &= vol[x_0, y_0, z_0](1-dx) + vol[x_1, y_0, z_0]dx \\
        c_{10} &= vol[x_0, y_1, z_0](1-dx) + vol[x_1, y_1, z_0]dx \\
        c_{01} &= vol[x_0, y_0, z_1](1-dx) + vol[x_1, y_0, z_1]dx \\
        c_{11} &= vol[x_0, y_1, z_1](1-dx) + vol[x_1, y_1, z_1]dx \\
        c_0 &= c_{00}(1-dy) + c_{10}dy \\
        c_1 &= c_{01}(1-dy) + c_{11}dy \\
        interp &= c_0(1-dz) + c_1 dz
        \end{aligned}
        $$
    g.  Normalize the interpolated value to $[0, 1]$:
        $$
        nval = \text{clip}\left(\frac{interp - lo}{hi - lo}, 0.0, 1.0\right)
        $$
    h.  Calculate the attenuation weight:
        $$
        w = e^{-\text{attenuation} \cdot acc}
        $$
    i.  Compute candidate value: $cand = nval \cdot w$ for valid voxels, else $-\infty$ [S1, unofficial].
    j.  Update running maximum and accumulator:
        $$
        out\_val = \max(out\_val, cand)
        $$
        $$
        acc = acc + nval
        $$
3.  **Post-processing:**
    a.  Clip finite values in `out_val` to $[0, 1]$, replacing non-finite values with $0.0$:
        $$
        norm = \text{clip}(\text{where}(\text{isfinite}(out\_val), out\_val, 0.0), 0.0, 1.0)
        $$
    b.  Map to 8-bit index: $idx = \text{clip}(\lfloor norm \cdot 255 \rfloor, 0, 255)$ [S1, unofficial].
    c.  Lookup color from `colormap` using $idx$. If no colormap, use grayscale $[norm, norm, norm]$. Convert to uint8 RGB [S1, unofficial].

**Pseudocode**
```python
import numpy as np

def attenuated_mip(vol, origin, spacing, near_pts, far_pts, value_range, 
                   attenuation=0.05, n_samples=256, colormap=None):
    """
    Render Attenuated Maximum-Intensity Projection.
    
    Args:
        vol: (nx, ny, nz) float32 array
        origin: (ox, oy, oz) tuple
        spacing: (sx, sy, sz) tuple
        near_pts: (H, W, 3) float array
        far_pts: (H, W, 3) float array
        value_range: (lo, hi) tuple
        attenuation: float
        n_samples: int
        colormap: function or None
        
    Returns:
        img: (H, W, 3) uint8 array
    """
    H, W = near_pts.shape[:2]
    lo, hi = value_range
    
    # Handle degenerate range
    if hi <= lo:
        hi = lo + 1.0
        
    inv_span = 1.0 / (hi - lo)
    
    # Initialize output
    out_val = np.full((H, W), -np.inf)
    acc = 0.0
    
    # Precompute spacing inverses for speed
    inv_spacing = np.array([1.0/s for s in spacing])
    
    for s in range(n_samples):
        # Parametric position
        if n_samples > 1:
            t = s / (n_samples - 1)
        else:
            t = 0.0
            
        # World point P
        P = near_pts + (far_pts - near_pts) * t
        
        # Continuous voxel indices
        fx = (P[:, :, 0] - origin[0]) * inv_spacing[0]
        fy = (P[:, :, 1] - origin[1]) * inv_spacing[1]
        fz = (P[:, :, 2] - origin[2]) * inv_spacing[2]
        
        # Determine valid voxels (inside bounds)
        valid = (fx >= 0) & (fx < vol.shape[0]-1) & \
                (fy >= 0) & (fy < vol.shape[1]-1) & \
                (fz >= 0) & (fz < vol.shape[2]-1)
        
        if not np.any(valid):
            continue
            
        # Integer coordinates
        x0 = np.floor(fx).astype(int)
        y0 = np.floor(fy).astype(int)
        z0 = np.floor(fz).astype(int)
        
        x1 = np.minimum(x0 + 1, vol.shape[0] - 1)
        y1 = np.minimum(y0 + 1, vol.shape[1] - 1)
        z1 = np.minimum(z0 + 1, vol.shape[2] - 1)
        
        # Fractional parts
        dx = fx - x0
        dy = fy - y0
        dz = fz - z0
        
        # Trilinear interpolation
        # Get voxel values
        v000 = vol[x0, y0, z0]
        v100 = vol[x1, y0, z0]
        v010 = vol[x0, y1, z0]
        v110 = vol[x1, y1, z0]
        v001 = vol[x0, y0, z1]
        v101 = vol[x1, y0, z1]
        v011 = vol[x0, y1, z1]
        v111 = vol[x1, y1, z1]
        
        # Interpolate
        c00 = v000 * (1 - dx) + v100 * dx
        c10 = v010 * (1 - dx) + v110 * dx
        c01 = v001 * (1 - dx) + v101 * dx
        c11 = v011 * (1 - dx) + v111 * dx
        
        c0 = c00 * (1 - dy) + c10 * dy
        c1 = c01 * (1 - dy) + c11 * dy
        
        interp = c0 * (1 - dz) + c1 * dz
        
        # Normalize
        nval = np.clip((interp - lo) * inv_span, 0.0, 1.0)
        
        # Attenuation weight
        weight = np.exp(-attenuation * acc)
        
        # Candidate value
        cand = np.where(valid, nval * weight, -np.inf)
        
        # Update max and accumulator
        out_val = np.maximum(out_val, cand)
        acc += nval
        
    # Post-processing
    norm = np.clip(np.where(np.isfinite(out_val), out_val, 0.0), 0.0, 1.0)
    idx = np.clip((norm * 255.0).astype(np.int32), 0, 255)
    
    # Color mapping
    if colormap is not None:
        # Assuming colormap returns (H, W, 3) array for indices
        img = colormap(idx)
    else:
        # Grayscale
        img = np.stack([norm, norm, norm], axis=-1) * 255.0
        
    return img.astype(np.uint8)
```

**Parameters**
*   `attenuation`: Float controlling the exponential falloff. Default is $0.05$ [S1, unofficial].
*   `n_samples`: Integer number of samples per ray. Default is $256$ [S1, unofficial].
*   `value_range`: Tuple $(lo, hi)$ for contrast window [S1, unofficial].
*   `colormap`: String or function for color mapping [S1, unofficial].

**Edge Cases and Pitfalls**
*   If $hi \le lo$, the span is set to $1.0$ to avoid division by zero [S1, unofficial].
*   If spacing on any axis is $< 10^{-12}$, it is replaced with $1.0$ [S1, unofficial].
*   Early ray termination is not explicitly defined in the source; the loop runs for all $n_{samples}$ [S1, unofficial].
*   The accumulator `acc` grows monotonically, causing deeper samples to be exponentially suppressed [S1, unofficial].

## Subtopics

### [Maximum Intensity Projection](10702-maximum-intensity-projection-mip.md)
Selects the absolute maximum value along the ray without attenuation. Choose when highlighting the brightest structure is the sole priority and depth cues are not needed.

### [Projected Slabs Approximation](1449-projected-slabs-approximation.md)
Approximates volume rendering by projecting slabs. Choose for faster rendering of large volumes where exact ray casting is too slow.

### [Forward Projection (aTx)](1492-forward-projection-atx.md)
A specific forward projection method. Choose when integrating specific attenuation models.

### [Minimum Intensity Projection](5299-minimum-intensity-projection.md)
Selects the minimum value. Choose for visualizing low-intensity features like airways or vessels.

General projection techniques. Choose as a baseline for simpler 2D projections.

## Operating characteristics
*   **Time Complexity:** $O(H \cdot W \cdot n_{samples})$ per frame, where $H, W$ are image dimensions and $n_{samples}$ is the number of samples per ray [S1, unofficial].
*   **Memory Complexity:** $O(H \cdot W)$ for the output and accumulator arrays, plus $O(n_x \cdot n_y \cdot n_z)$ for the volume [S1, unofficial].
*   **Performance:** Performance depends heavily on $n_{samples}$ and interpolation cost. The exponential attenuation calculation adds a small overhead per sample [S1, unofficial].
*   **Strengths:** Reduces visual clutter from background noise; highlights strong peaks; simple to implement [S1, unofficial].
*   **Limitations:** May obscure weaker structures if attenuation is too high; not physically accurate for light transport [S1, unofficial].
*   **When to use:** When the goal is to highlight high-intensity features in noisy or dense volumes [S1, unofficial].
*   **When not to use:** When accurate depth perception or quantitative intensity analysis is required [S1, unofficial].

## Background
Attenuated MIP is described as a CPU-emulated rendering technique in the source [S1, unofficial]. It is used in the `voxel` library for visualizing 3D data, particularly in contexts like diffractometer data where highlighting strong peaks is important [S1, unofficial]. The technique is attributed to the implementation in the `stacy-zhang/voxel` repository [S1, unofficial].
