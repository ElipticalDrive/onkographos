# Projection

Also called: Direct Volume Rendering via Projection, Orthographic Projection (Summation), Summation Projection, Summed Reprojection, Summed projection, Total Intensity Projection, Voxel Projection

## Overview
Projection is a direct volume rendering technique that visualizes the total accumulated intensity of a 3D volume along a specific axis by summing voxel values [S1, unofficial][S2, unofficial]. It compresses volumetric data into a 2D representation where pixel brightness corresponds to the line integral of the scalar field along the viewing ray [S1, unofficial]. Unlike [Maximum Intensity Projection](902-maximum-intensity-projection.md), which highlights the highest density structures, projection sums all contributions along the ray, which decreases noise but significantly reduces image contrast due to cumulative background activity [S3, unofficial].

## How it works
**Inputs and Outputs:**
*   **Input:** A 3D volume $V$ represented as a discrete grid of voxels, typically stored as a 3D array where each element $V(x, y, z)$ holds a scalar intensity value [S1, unofficial].
*   **Output:** A 2D accumulator array initialized to zero, with dimensions matching the volume perpendicular to the projection axis [S1, unofficial].

**Data Structures:**
The input volume is stored as a 3D array [S1, unofficial]. The output is a 2D array of shape $(D_y, D_z)$ when projecting along the X-axis [S1, unofficial].

**Algorithm Steps:**
1. Initialize a 2D output array `vr` with zeros, matching the dimensions of the volume perpendicular to the projection axis [S1, unofficial].
2. Iterate through each slice index $i$ along the projection axis (X-axis) [S1, unofficial].
3. Extract the 2D slice at index $i$ [S1, unofficial].
4. Add the slice values to the corresponding positions in the output accumulator [S1, unofficial].

**Formula:**
The accumulated intensity for each output pixel $(y, z)$ is computed as:
$$ I(y, z) = \sum_{x=0}^{D_x-1} V(x, y, z) $$
where $D_x$ is the number of voxels along the projection axis, and $V(x, y, z)$ is the scalar intensity at voxel coordinates $(x, y, z)$ [S1, unofficial].

**Pseudocode:**
```python
def projection(volume):
    """
    Computes the orthographic projection (summation) of a 3D volume along the first axis.
    
    Args:
        volume: 3D list or array of shape (D_x, D_y, D_z).
        
    Returns:
        2D list or array of shape (D_y, D_z) containing the summed intensities.
    """
    dx, dy, dz = len(volume), len(volume[0]), len(volume[0][0])
    # Initialize output array with zeros matching the Y and Z dimensions
    vr = [[0.0 for _ in range(dz)] for _ in range(dy)]
    
    # Iterate through each slice along the X-axis (first dimension)
    for i in range(dx):
        # Extract the 2D slice at index i
        img_slice = volume[i]
        
        # Add the slice to the accumulator
        for y in range(dy):
            for z in range(dz):
                vr[y][z] += img_slice[y][z]
                
    return vr
```

**Parameters and Edge Cases:**
*   **Axis Selection:** The projection direction is determined by which axis is iterated over [S1, unofficial].
*   **Typical Values:** Not given in the sources.
*   **Precision:** Not given in the sources.
*   **Boundaries:** The method assumes the volume is fully contained within the grid bounds; out-of-bounds access is not handled [G].
*   **Degenerate Input:** If the volume contains only zero-valued voxels, the output will be uniformly zero [G].

## Subtopics

### [Cylinder Projection](12798-cylinder-projection.md)
A viewpoint-independent technique for visualizing 3D vector fields on surfaces, specifically designed for generating film loops where the viewpoint rotates about the vertical z-axis. It projects the 3D vector onto the surface along a direction pointing radially away from the rotational axis. It is chosen when preserving the z-component of a vector field during rotational motion is required, yielding results similar to XY Normal Projection but with more intuitive visualization for this specific motion.

## Operating characteristics
**Time and Memory Complexity:**
*   **Time:** $O(N)$, where $N$ is the total number of voxels in the volume, since each voxel is visited exactly once [S1, unofficial].
*   **Memory:** $O(D_y \times D_z)$ for the output image, plus the input volume storage, with no additional per-ray buffers required [S1, unofficial].

**Performance and Scaling:**
*   The method is extremely fast and highly parallelizable, as each output pixel is independent of others [G]. It scales linearly with volume size [G].

**Strengths and Limitations:**
*   **Strengths:** Simple to implement and computationally inexpensive [G]. Summed reprojection decreases noise, but at the expense of image contrast [S3, unofficial].
*   **Limitations:** Produces images with inferior contrast compared to slice display and Maximum Intensity Projection [S3, unofficial]. It suffers from cumulative background activity, where structures far from the viewing plane interfere with the assessment of closer structures [S3, unofficial].

## Background
The projection method, specifically referred to as "summed reprojection" or "raw projection," has been evaluated in clinical studies comparing lesion contrast in SPECT images [S3, unofficial]. It is often contrasted with Maximum Activity Projection, which provides superior lesion contrast and decreased image noise compared to summed reprojection [S3, unofficial].
