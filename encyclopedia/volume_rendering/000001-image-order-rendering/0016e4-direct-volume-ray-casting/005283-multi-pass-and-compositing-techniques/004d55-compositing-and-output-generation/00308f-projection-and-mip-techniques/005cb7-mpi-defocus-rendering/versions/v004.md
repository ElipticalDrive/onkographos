# MPI Defocus Rendering

Also called: Multiplane image defocus, Synthetic Defocus Rendering, Synthetic Defocus Rendering from MPI

## Overview
MPI Defocus Rendering synthesizes images with depth-of-field blur and lateral camera translation by compositing a precomputed Multi-Plane Image (MPI) representation [S1]. It differs from standard ray casting by operating on discrete disparity planes rather than continuous volumetric samples, allowing for efficient simulation of defocus blur via 2D image-space convolutions [S1].

## How it works
### Inputs and Outputs
**Inputs:**
*   $N$: Number of planes in the MPI.
*   $\mathbf{c}_{mpi}^{(i)}$: Color tensor for plane $i$ (RGB, linear HDR space).
*   $\alpha_{mpi}^{(i)}$: Opacity tensor for plane $i$.
*   $i_{focus}$: Index of the focal plane.
*   $\Delta r$: Scalar controlling the simulated aperture size (defocus strength).
*   $\Delta \mathbf{d}$: 2D vector controlling lateral camera translation parallel to the image plane.

**Outputs:**
*   $C$: The final composited image.

### Data Structures
The MPI consists of $N$ fronto-parallel RGBA planes [S1]. The planes are indexed from back to front ($i = 0$ to $N-1$) [S1]. Colors are stored in linear HDR space [S1].

### Steps
1.  **Precompute MPI:** Generate the MPI representation from the trained model [S1]. The MPI comprises a series of fronto-parallel RGBA planes sampled linearly in disparity within a camera frustum at a central camera pose [S1].
2.  **Initialize Accumulator:** Set the output color accumulator $C \leftarrow 0$ [S1].
3.  **Iterate Planes:** For each plane $i$ from $0$ to $N-1$ (back to front):
    a.  **Calculate Blur Radius:** Compute the blur radius $r$ based on the distance of the current plane from the focal plane:
        $$ r = \Delta r \cdot |i - i_{focus}| $$
    b.  **Generate Kernel:** Create a blur kernel $k_{blur}$ using a circular mask of radius $r$ centered at the origin [S1]. This is implemented as a 2D Fourier space convolution [S1].
    c.  **Blur Color:** Premultiply the plane's color by its alpha ($\mathbf{c}_{mpi}^{(i)} \cdot \alpha_{mpi}^{(i)}$) and convolve with the kernel:
        $$ \mathbf{c}_{blur} = \text{convolve}(\mathbf{c}_{mpi}^{(i)} \cdot \alpha_{mpi}^{(i)}, k_{blur}) $$
    d.  **Blur Alpha:** Convolve the plane's alpha with the kernel:
        $$ \alpha_{blur} = \text{convolve}(\alpha_{mpi}^{(i)}, k_{blur}) $$
    e.  **Calculate Translation Offset:** Compute the translation vector $\mathbf{d}$ for the current plane:
        $$ \mathbf{d} = \Delta \mathbf{d} \cdot i $$
    f.  **Translate Blurred Layers:** Apply continuous 2D image translation using bilinear resampling to the blurred color and alpha:
        $$ \mathbf{c}_{trans} = \text{translate}(\mathbf{c}_{blur}, \mathbf{d}) $$
        $$ \alpha_{trans} = \text{translate}(\alpha_{blur}, \mathbf{d}) $$
    g.  **Composite:** Add the translated color to the accumulator using the transmittance $(1 - \alpha_{trans})$:
        $$ C \leftarrow \mathbf{c}_{trans} + (1 - \alpha_{trans}) C $$
        The color $\mathbf{c}_{trans}$ is not multiplied by $\alpha_{trans}$ here because the color was already premultiplied by alpha in step 3c [S1].
4.  **Return Result:** Output $C$ [S1].

### Parameters
*   $i_{focus}$: Controls the focal plane depth [S1].
*   $\Delta r$: Controls the simulated aperture size, determining defocus strength [S1].
*   $\Delta \mathbf{d}$: A 2D vector controlling camera translation parallel to the image plane [S1].
*   Typical values: Not given in the sources [S1].

### Pseudocode
```python
import numpy as np

def mpi_defocus_rendering(c_mpi, alpha_mpi, i_focus, delta_r, delta_d):
    """
    Synthetic defocus rendering from a Multi-Plane Image.
    c_mpi: list of N arrays (H, W, 3), colors in linear HDR space.
    alpha_mpi: list of N arrays (H, W), opacities.
    i_focus: int, focal plane index.
    delta_r: float, simulated aperture size.
    delta_d: tuple (dx, dy), 2D vector for lateral camera translation.
    """
    N = len(c_mpi)
    H, W, _ = c_mpi[0].shape
    C = np.zeros((H, W, 3))
    
    for i in range(N):
        # 1. Calculate blur radius based on distance from focal plane
        r = delta_r * abs(i - i_focus)
        
        # 2. Generate blur kernel (circular mask, radius r) [G]
        k_blur = _make_circular_kernel(r)
        
        # 3. Premultiply color by alpha before blurring
        c_premult = c_mpi[i] * alpha_mpi[i][..., np.newaxis]
        
        # 4. Convolve color and alpha with kernel [G]
        c_blur = _convolve_2d(c_premult, k_blur)
        alpha_blur = _convolve_2d(alpha_mpi[i], k_blur)
        
        # 5. Calculate translation offset for this plane
        d = (delta_d[0] * i, delta_d[1] * i)
        
        # 6. Translate blurred layers using bilinear resampling [G]
        c_trans = _bilinear_translate(c_blur, d)
        alpha_trans = _bilinear_translate(alpha_blur, d)
        
        # 7. Composite: C = c_trans + (1 - alpha_trans) * C
        transmittance = 1.0 - alpha_trans[..., np.newaxis]
        C = c_trans + transmittance * C
        
    return C

def _make_circular_kernel(r):
    """Returns a normalized circular mask of radius r [G]."""
    size = int(2 * r) + 1
    y, x = np.ogrid[:size, :size]
    center = size // 2
    mask = (x - center)**2 + (y - center)**2 <= r**2
    return mask.astype(float) / mask.sum()

def _convolve_2d(image, kernel):
    """2D convolution using FFT for efficiency [G]."""
    # Apply FFT convolution per channel
    out = np.zeros_like(image)
    for c in range(image.shape[2]):
        out[:, :, c] = np.fft.ifft2(
            np.fft.fft2(image[:, :, c]) * np.fft.fft2(kernel, s=image.shape[:2])
        ).real
    return out

def _bilinear_translate(image, offset):
    """Continuous 2D translation using bilinear resampling [G]."""
    H, W = image.shape[:2]
    dy, dx = offset
    # Create coordinate grids
    y, x = np.mgrid[0:H, 0:W]
    y_new = y - dy
    x_new = x - dx
    # Clip to valid range for bilinear interpolation
    y0 = np.clip(y_new.astype(int), 0, H - 2)
    x0 = np.clip(x_new.astype(int), 0, W - 2)
    y1 = y0 + 1
    x1 = x0 + 1
    # Interpolation weights
    sy = y_new - y0
    sx = x_new - x0
    # Bilinear interpolation
    val = (image[y0, x0] * (1 - sy) * (1 - sx) +
           image[y0, x1] * (1 - sy) * sx +
           image[y1, x0] * sy * (1 - sx) +
           image[y1, x1] * sy * sx)
    return val
```

### Edge Cases and Pitfalls
*   **Premultiplication:** The color must be premultiplied by alpha *before* blurring [S1]. The accumulation step does not apply alpha to $\mathbf{c}_{trans}$ because the premultiplication in the blur step already accounts for it [S1].
*   **Indexing:** MPI planes are indexed from back to front ($i=0$ is back) [S1].
*   **Color Space:** Colors must be in linear HDR space during processing [S1].

## Operating characteristics
*   **Time Complexity:** Not given in the sources [S1].
*   **Memory Complexity:** Not given in the sources [S1].
*   **Strengths:** Efficient simulation of defocus blur and lateral translation without per-pixel ray marching [S1]. Suitable for high dynamic range (HDR) raw image synthesis [S1].
*   **Limitations:** Relies on the quality of the precomputed MPI [S1]. Defocus blur is approximated via 2D convolution, which assumes thin-lens optics [S1].
*   **When to use:** When synthetic defocus and camera translation are required for view synthesis from an MPI [S1].
*   **When not to use:** Not given in the sources [S1].

## Background
MPI Defocus Rendering was introduced in the context of "NeRF in the Dark," a method for high dynamic range view synthesis from noisy raw images [S1]. The approach leverages the efficiency of Multi-Plane Images (MPIs) [S1]. It builds on prior work addressing synthetic defocus [S1]. The method was developed to handle the challenges of low-light photography, where Bayer masking and raw domain processing are necessary to mitigate noise artifacts [S1].
