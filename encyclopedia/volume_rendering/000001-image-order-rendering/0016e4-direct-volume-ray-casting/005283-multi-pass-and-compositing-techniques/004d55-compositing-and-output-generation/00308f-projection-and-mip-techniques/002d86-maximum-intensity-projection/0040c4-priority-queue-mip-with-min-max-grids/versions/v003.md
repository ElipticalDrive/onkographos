# Priority Queue MIP with Min/Max Grids

Also called: Front-to-Back MIP, Maximum Intensity Projection (MIP) with Priority Queue, Min/Max Grid MIP, Min/Max Multilevel Grid MIP, Parker et al. MIP, Priority Queue MIP

## Overview
Priority Queue MIP with Min/Max Grids is a ray-casting technique that efficiently computes the Maximum Intensity Projection (MIP) by combining a hierarchical spatial acceleration structure with a priority queue [S1]. Unlike standard ray marching, it processes nodes in descending order of their stored maximum values, terminating early when the highest-priority leaf cell is reached [S1]. It is primarily used in medical imaging to visualize thin, high-intensity structures like blood vessels [S1].

## How it works
**Inputs:** A 3D volume dataset, a camera view defining rays, and a min/max multilevel grid where each node stores the minimum and maximum scalar values of its contained voxels [S1].
**Outputs:** For each pixel, the maximum scalar value encountered along the ray and its corresponding 3D position [S3, unofficial].

**Data Structures:**
1. **Min/Max Multilevel Grid:** A hierarchical tree where each node stores `min_val` and `max_val` for its bounding box [S1].
2. **Priority Queue:** A max-heap storing nodes ordered by `max_val` [S1].

**Algorithm Steps:**
1. **Initialization:** Initialize the priority queue with the root node and its `max_val` [S1]. Initialize `global_max = -infinity` and `global_max_pos = ray.start` [G].
2. **Iteration:** While the queue is not empty, extract the node `N` with the highest `max_val` [S1]. If `N` is an internal node, insert its children into the queue with their respective `max_val`s [S1]. If `N` is a leaf node, perform macro-cell traversal to find the maximum value along the ray segment through the cell [S1]. Store this encountered maximum value back into the priority queue [S1].
3. **Termination:** The algorithm terminates if the leaf cell that was just processed appears at the head of the priority queue [S1].
4. **Macro-Cell Traversal:** At each pierced cell-face within the leaf, perform bi-linear interpolation assuming a linear function along the ray, which implies no extremal value exists strictly within the cell [S1]. Track the maximum interpolated value and its position [S3, unofficial].

**Pseudocode:**
```python
import math
import heapq

def priority_queue_mip(ray_origin, ray_direction, min_max_grid):
    # Priority queue stores (-max_val, node) for max-heap behavior
    pq = [(-min_max_grid.root.max_val, min_max_grid.root)]
    heapq.heapify(pq)
    
    global_max = -math.inf
    global_max_pos = ray_origin
    
    while pq:
        neg_max_val, node = heapq.heappop(pq)
        current_max_val = -neg_max_val
        
        if node.is_leaf():
            local_max, local_pos = macro_cell_traversal(ray_origin, ray_direction, node.bounds)
            if local_max > global_max:
                global_max = local_max
                global_max_pos = local_pos
            heapq.heappush(pq, (-local_max, node))
            if pq[0][0] == -local_max:
                break
        else:
            for child in node.children:
                heapq.heappush(pq, (-child.max_val, child))
                
    return global_max, global_max_pos
```

**Edge Cases and Pitfalls:**
* **Precision:** Bi-linear interpolation assumes linearity; if the volume data has high-frequency details within a cell, the maximum might be missed [S1].
* **Boundaries:** Correctly handling ray entry and exit from the volume and leaf nodes is critical [G].

## Background
The method was suggested by Parker et al. in [PPL* 99] as an important technique for real-world medical imaging applications [S1]. It uses a priority queue in conjunction with a spatial data structure, specifically min/max multilevel grids, to track cells with maximum values [S1]. While Parker et al. used min/max multilevel grids, other common min/max hierarchical data structures could also be exploited [S1]. The technique is part of the broader field of ray tracing-based volume rendering, which has been developed since the early 1990s [S1].
