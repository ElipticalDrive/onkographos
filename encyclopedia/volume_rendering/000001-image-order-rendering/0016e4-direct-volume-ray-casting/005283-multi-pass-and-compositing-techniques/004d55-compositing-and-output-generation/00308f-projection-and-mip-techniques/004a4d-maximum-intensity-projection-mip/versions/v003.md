# Maximum Intensity Projection (MIP)

Also called: MIP Shader, Max intensity

## Overview
Maximum Intensity Projection (MIP) is a volume rendering technique that projects the maximum scalar value encountered along each viewing ray onto the 2D image plane [S1, unofficial]. It is primarily used to highlight high-intensity structures, such as blood vessels in angiography or bone in CT scans, by suppressing lower-intensity background noise [S1, unofficial]. Unlike standard front-to-back compositing which blends all samples, MIP discards all intermediate values in favor of the single maximum, which causes it to lose depth differentiation and the ability to distinguish whether the maximum lies in the front or back of the volume [S1, unofficial].

## How it works
**Inputs and Outputs:**
*   **Input:** A 3D scalar volume dataset $V$, a camera ray $R$ defined by origin $O$ and direction $D$, and a sampling step size $\Delta s$.
*   **Output:** A single scalar intensity value $C(R)$ for each pixel.

**Data Structures:**
*   **Volume:** A 3D array of scalar values. In the reference implementation, this is stored as a `Data3DTexture` with `RedFormat` and `FloatType` [S2, unofficial].
*   **Ray State:** Accumulator for the maximum value found so far, initialized to negative infinity or the minimum possible value of the data type.

**Numbered Steps:**
1.  **Ray Initialization:** For each pixel, construct a ray $R$ from the camera origin through the pixel center. Determine the entry and exit points of the ray into the volume bounding box.
2.  **Sampling Loop:** Iterate along the ray from the entry point to the exit point with a fixed step size $\Delta s$ (or adaptive step size). The number of steps $N$ is determined by the ray length and $\Delta s$ [S2, unofficial].
3.  **Trilinear Interpolation:** For each step position $P_i$ along the ray, sample the scalar value $v_i$ from the volume using trilinear interpolation [S1, unofficial].
4.  **Maximum Update:** Compare the sampled value $v_i$ with the current maximum accumulator $M$. If $v_i > M$, update $M \leftarrow v_i$.
5.  **Termination:** Continue until the ray exits the volume.
6.  **Output:** Assign the final maximum value $M$ to the pixel color/intensity.

**Formula:**
The output intensity $C(R)$ for a ray $R$ is defined as:
$$
C(R) = \max_{i} \{ v_i \}
$$
where $v_i$ is the scalar value of the $i$-th sample along the ray [S1, unofficial].

**Parameters:**
*   **Steps:** The number of samples per ray. In the reference implementation, this is set via `setSteps(200)` [S2, unofficial].
*   **Step Size:** Not explicitly defined in the reference code, but typically derived from volume resolution or ray length.

**Edge Cases and Pitfalls:**
*   **Depth Ambiguity:** MIP loses the differentiation of front/behind relationships. It is impossible to determine if the maximum intensity originates from a structure in the foreground or background [S1, unofficial].
*   **Noisy Data:** While good for noisy data, small noise spikes can be projected as significant structures [S1, unofficial].
*   **Missing Details:** Regular sampling may miss thin structures if the step size is too large [S1, unofficial].

**Pseudocode:**
```python
def maximum_intensity_projection(volume, ray_origin, ray_direction, num_steps):
    """
    Renders a single pixel using Maximum Intensity Projection.
    
    Args:
        volume: 3D array or texture object supporting trilinear sampling.
        ray_origin: 3D vector (x, y, z).
        ray_direction: 3D vector (x, y, z), normalized.
        num_steps: Integer, number of samples along the ray.
        
    Returns:
        float: The maximum scalar value found along the ray.
    """
    # Initialize maximum to negative infinity
    max_val = -float('inf')
    
    # Calculate step size based on ray length and number of steps
    # Note: Exact ray length calculation depends on volume bounds, 
    # which are not provided in the source snippet. 
    # We assume a normalized step or pre-calculated step size is available.
    # For implementation completeness, we assume a step vector `step_vec`.
    step_vec = ray_direction * (1.0 / num_steps) # Placeholder for actual step size calculation
    
    current_pos = ray_origin
    
    for i in range(num_steps):
        # Sample the volume at current position
        # Assuming volume.sample(pos) performs trilinear interpolation
        # [S1, unofficial] mentions trilinear interpolation
        value = volume.sample(current_pos)
        
        # Update maximum
        if value > max_val:
            max_val = value
            
        # Advance along the ray
        current_pos = current_pos + step_vec
        
    return max_val
```

## Operating characteristics
*   **Time Complexity:** $O(N)$ per pixel, where $N$ is the number of samples along the ray. Linear with respect to the number of steps.
*   **Memory Complexity:** $O(1)$ auxiliary memory per pixel, as only the current maximum needs to be stored. The volume data itself requires $O(V)$ memory.
*   **Performance:** Fast to compute as it avoids the accumulation and blending overhead of front-to-back compositing. However, it requires full traversal of the ray through the volume unless early termination is adapted (which is not standard for MIP since a higher value might appear later).
*   **Strengths:** Excellent for highlighting high-contrast structures; robust against noise; simple implementation.
*   **Limitations:** No depth cueing; occlusion of lower-intensity structures behind high-intensity ones; loss of anatomical context regarding depth.
*   **When to use:** Angiography, bone visualization, or any scenario where the highest intensity values are the feature of interest.
*   **When not to use:** When depth perception is critical or when visualizing structures with similar intensities but different depths.

## Background
Maximum Intensity Projection was developed as a variation of ray casting for direct volume rendering. It is widely used in medical imaging, particularly in CT and MRI, to visualize vascular structures and bones. The technique is highlighted in educational materials on direct volume rendering as a method to handle noisy data by selecting the most prominent signal along the ray [S1, unofficial].
