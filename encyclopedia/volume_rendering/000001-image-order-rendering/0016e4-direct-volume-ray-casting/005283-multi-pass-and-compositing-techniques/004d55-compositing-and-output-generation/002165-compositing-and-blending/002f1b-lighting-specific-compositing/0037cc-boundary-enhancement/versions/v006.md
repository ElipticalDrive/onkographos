# Boundary Enhancement

Also called: Edge enhancement, Feature enhancement, Boundary enhancement via bump mapping

## Overview
Boundary enhancement is a compositing technique designed to improve the visibility of object boundaries and material interfaces within volume data [S1][S2, unofficial]. It addresses the problem of ambiguous internal structures by emphasizing edges, often used in conjunction with silhouette techniques in medical illustration to clarify anatomical boundaries [S2, unofficial]. Unlike standard direct volume rendering which blends raw transfer function outputs, this method modifies the opacity and color contributions specifically at gradient-heavy regions to sharpen perceived surfaces [S1, S3]. It sets itself apart from sibling methods like [Incremental Blending for In-scattering](2880-incremental-blending-for-in-scattering.md) and [Intermixing](5139-intermixing.md) by focusing on geometric edge definition rather than light transport simulation or multi-pass accumulation strategies.

## How it works
**Inputs and Outputs:**
*   **Input:** Volume dataset $V$, classification map $C$, viewing ray $R$, and bump strength parameter $v_{bump}$ [S4].
*   **Output:** Enhanced color $C_{out}$ and opacity $\alpha_{out}$ for the final pixel [S1][S2, unofficial].

**Data Structures:**
*   **Sample Intensity ($i_{sample}$):** The intensity value used for illumination calculations after boundary perturbation [S4].
*   **Classified Intensity ($i_{class}$):** The intensity value derived from the transfer function classification [S4].
*   **Gradient Vector ($\nabla V$):** Computed on-the-fly from intensity values to determine surface normals [S4].

**Steps:**
1.  **Ray Casting:** Cast rays through the volume data. For each sample point along the ray, retrieve the raw intensity value [S1].
2.  **Classification:** Apply the transfer function to classify the sample, determining its material properties and base intensity $i_{class}$ [S4].
3.  **Gradient Computation:** Compute the spatial gradient $\nabla V$ at the sample point using neighboring voxel intensities. This gradient represents the surface normal for illumination [S4].
4.  **Boundary Enhancement (Bump Mapping):** If the sample lies on a material boundary (identified via histogram analysis or gradient magnitude thresholds), perturb the gradient direction or intensity to simulate bump mapping [S4].
    *   Calculate the enhanced sample intensity $i_{sample}$ using the formula:
        $$ i_{sample\_j} = (i_{class\_j} \times v_{bump}) - (v_{bump} - 1) $$
        where $i_{sample\_j}$ is the sample intensity for illumination, $i_{class\_j}$ is the classified sample intensity, and $v_{bump}$ is the bump value [S4].
    *   If $v_{bump}$ is near zero, no enhancement is visible [S4].
    *   Typical value for $v_{bump}$ is 1.5 [S4].
5.  **Illumination:** Use the perturbed gradient or intensity $i_{sample}$ to compute lighting contributions (e.g., Phong shading) [S1, S4].
6.  **Compositing:** Blend the enhanced color and opacity contributions into the accumulator using standard front-to-back or back-to-front compositing [S1][S2, unofficial].

**Parameters:**
*   $v_{bump}$: Strength of the bump effect. Typical value: 1.5 [S4].

**Edge Cases and Pitfalls:**
*   **Precision:** On-the-fly gradient computation requires careful handling of floating-point precision to avoid noise amplification at boundaries [S4].
*   **Boundaries:** The technique relies on accurate identification of material boundaries; incorrect classification can lead to false edge enhancement [S2, unofficial][S4].

## Subtopics

### [Temporal Gradient Enhancement](8138-temporal-gradient-enhancement.md)
Temporal Gradient Enhancement is a boundary enhancement technique for time-varying volume data that highlights features varying rapidly over time by computing gradients in the time dimension and modifying shading/opacity based on these gradients. Unlike standard animation which renders individual time steps independently, this method uses data from previous and next time steps for the current rendering to maintain coherence. It sets itself apart from spatial enhancement techniques (such as those using Non-Photorealistic Rendering strokes) by avoiding artifacts introduced into animations, ensuring visual coherence from one time step to the next.

### Feature Enhancement
Feature Enhancement is a technique that adds texture and contrast to the volume render, furthering the effects of edge enhancement [S3]. It increases the contrast between objects at different depths and adds 3D features to the render, often applied after basic edge enhancement and volumetric filtering [S3].

### Boundary Enhancement via Bump Mapping
Boundary Enhancement via Bump Mapping is a boundary enhancement algorithm based on bump mapping applied to cutting surfaces to enhance anatomical boundaries blended with structures from additional data sets [S4]. It perturbs surface normals (gradients) to simulate bump mapping, improving the perception of underlying structures clipped by cutting planes [S4]. It sets itself apart by specifically targeting structures intersected by cutting planes, manipulating gradients at the boundary of structures while keeping other gradients unchanged to cause localized illumination changes [S4].

## Operating characteristics
*   **Time Complexity:** Adds overhead for on-the-fly gradient computation and bump mapping calculations per sample [S4].
*   **Memory Complexity:** Requires storage for gradient vectors if not computed on-the-fly, but on-the-fly computation minimizes memory usage [S4].
*   **Performance:** Enhances visual clarity of boundaries but may increase rendering time due to additional gradient and lighting calculations [S3, S4].
*   **Strengths:** Improves readability of complex anatomical structures, especially when combined with cutting planes [S4]. Effective in medical illustration for highlighting organ/tissue boundaries [S2, unofficial].
*   **Limitations:** Dependent on accurate classification and gradient computation; may introduce artifacts if parameters are not tuned correctly [S4].

## Background
Boundary enhancement originated as a technique to improve the visibility of object boundaries within volume data, particularly in medical visualization [S1][S2, unofficial]. It has been integrated into various volume rendering pipelines, including those using Phong illumination models and view-dependent transparency [S1]. The technique is often part of a broader illustrative visualization framework that includes silhouetting and sketching to aid in medical education and surgical planning [S2, unofficial].
