# Phong Shading with Volume Rendering
Also called: compositeShaderPhong

## Overview
Phong Shading with Volume Rendering enhances standard direct volume ray casting by applying Phong illumination (diffuse and specular) to volume samples based on computed gradients [S1, unofficial]. It builds on [Lighting-Specific Compositing](5940-lighting-specific-compositing.md) and differs from the standard composite shader by computing modified color and opacity terms that encode surface-like shading cues before front-to-back compositing [S1, unofficial]. It is distinct from sibling methods such as [Incremental Blending for In-scattering](2880-incremental-blending-for-in-scattering.md), [Intermixing](5139-intermixing.md), and [Boundary Enhancement](8071-boundary-enhancement.md) by explicitly deriving Phong reflection terms per sample rather than modifying compositing weights or in-scattering contributions [S1, unofficial].

## How it works
**Inputs and Outputs**
*   **Input:** A 3D volume dataset, a transfer function, camera position ($v_{position}$), light direction vector ($lightVector$), and lighting parameters ($shininess$, $k_s$) [S1, unofficial].
*   **Output:** A 2D image with Phong-shaded volumetric appearance [S1, unofficial].

**Data Structures**
The method maintains per-ray accumulators for color and opacity, and retrieves per-sample color and gradient data [S1, unofficial].
*   $C_{acc}$: Accumulated color (RGBA).
*   $\alpha_{acc}$: Accumulated opacity (float).
*   $c$: Interpolated sample color (RGBA) retrieved from the volume at the current ray position [S1, unofficial].
*   $normal$: Gradient vector retrieved from the volume at the current ray position [S1, unofficial].

**Numbered Steps**
1.  **Ray Setup:** Perform standard Axis-Aligned Bounding Box (AABB) intersection to determine the entry point $t_0$, exit point $t_1$, and step size $sampleLength$ [S1, unofficial].
2.  **Initialization:** Initialize the color accumulator and opacity accumulator [S1, unofficial]. Exact initial values are not given in the sources [S1, unofficial].
3.  **Ray Marching Loop:** Iterate $i$ from $0$ to $SAMPLES-1$ while the ray has hit the volume and accumulated opacity $\alpha_{acc}$ is less than $0.99$ [S1, unofficial]:
    a.  **Sample Retrieval:** Retrieve the interpolated color $c$ and the gradient vector $normal$ at the current ray position [S1, unofficial].
    b.  **Normal Processing:** If $normal$ is not zero, normalize it to obtain $\hat{n}$ [S1, unofficial].
    c.  **Vector Computation:** Compute the view direction vector $\hat{v}$ from the sample point to the camera position ($v_{position}$) and normalize it [S1, unofficial]. Normalize the light direction vector $\hat{l} = lightVector$ [S1, unofficial].
    d.  **Diffuse Term:** Compute the diffuse term as the clamped dot product of the normal and the light vector [S1, unofficial].
    e.  **Specular Term:** Compute the specular term as the $shininess$ power of the clamped dot product of the reflected light vector and the view direction [S1, unofficial].
    f.  **Color Modification:** Modify the sample color $c$ by combining the diffuse term, an ambient-like term ($0.05 \cdot c$), and the specular term scaled by $k_s$ [S1, unofficial].
    g.  **Alpha Preservation:** Preserve the original alpha value from the sample in $tempa$ [S1, unofficial].
    h.  **Compositing:** Apply the modified color $c$ to the front-to-back compositing formula and update the accumulated opacity [S1, unofficial].
    i.  **Termination Check:** If $\alpha_{acc} \ge 0.99$, set $\alpha_{acc} = 1.0$ and break [S1, unofficial].
    j.  **Advance:** Advance the ray position by $sampleLength$ [S1, unofficial].

**Formulas**
*   Diffuse: $D = \max(0, \hat{n} \cdot \hat{l})$
*   Specular: $S = \max(0, \hat{r} \cdot \hat{v})^{shininess}$, where $\hat{r} = 2(\hat{n} \cdot \hat{l})\hat{n} - \hat{l}$
*   Modified Color: $c' = c \cdot 0.05 + c \cdot D + c \cdot k_s \cdot S$
*   Front-to-Back Compositing: $C_{acc} \leftarrow C_{acc} + c' \cdot (1 - \alpha_{acc})$, $\alpha_{acc} \leftarrow \alpha_{acc} + (1 - \alpha_{acc}) \cdot tempa$

**Pseudocode**
```python
def phong_shading_volume_ray_casting(volume, tf, t0, t1, SAMPLES, lightVector, vposition, shininess, ks, ray_origin, ray_direction):
    sampleLength = (t1 - t0) / SAMPLES
    C_acc = vec4(0.0, 0.0, 0.0, 0.0)
    alpha_acc = 0.0
    t = t0

    for i in range(SAMPLES):
        if alpha_acc >= 0.99:
            alpha_acc = 1.0
            break

        ray_pos = ray_origin + t * ray_direction
        if t < t0 or t > t1:
            break

        c = volume.sample(ray_pos)
        normal = volume.gradient(ray_pos)

        if length(normal) > 0:
            n_hat = normalize(normal)
            v_hat = normalize(vposition - ray_pos)
            l_hat = normalize(lightVector)

            diffuse = max(0.0, dot(n_hat, l_hat))
            r_hat = 2.0 * dot(n_hat, l_hat) * n_hat - l_hat
            specular = max(0.0, dot(r_hat, v_hat)) ** shininess

            c = c * 0.05 + c * diffuse + c * ks * specular

        tempa = c.a

        C_acc = C_acc + c * (1.0 - alpha_acc)
        alpha_acc = alpha_acc + (1.0 - alpha_acc) * tempa

        t += sampleLength

    return C_acc
```

**Parameters**
*   $shininess$: The specular exponent for the Phong model [S1, unofficial].
*   $k_s$: The specular coefficient multiplier [S1, unofficial].
*   $lightVector$: The direction vector of the light source [S1, unofficial].
*   $v_{position}$: The position of the camera/viewpoint [S1, unofficial].

**Edge Cases and Pitfalls**
*   **Zero Gradient:** If the gradient vector is zero, the normal cannot be normalized [S1, unofficial]. The method skips the lighting modification for that sample [S1, unofficial].
*   **Early Termination:** The loop terminates when accumulated opacity reaches $0.99$, at which point opacity is clamped to $1.0$ and the loop breaks [S1, unofficial].
*   **Boundary Handling:** AABB intersection must correctly identify rays that miss the volume to prevent out-of-bounds sampling [G].

## Operating characteristics
*   **Time Complexity:** $O(S)$ per ray, where $S$ is the number of samples [G]. Lighting calculations (dot products, power, vector normalization) add a constant overhead per sample compared to standard compositing [G].
*   **Memory Complexity:** $O(1)$ per ray for accumulators and temporary vectors [G].
*   **Measured Performance:** Not given in the sources [S1, unofficial].
*   **Scaling:** Not given in the sources [S1, unofficial].
*   **Strengths:** Adds surface-like shading cues to the volume, enhancing shape perception [S1, unofficial].
*   **Limitations:** Relies on gradient computation; accuracy depends on volume resolution and transfer function smoothness [S1, unofficial].
*   **When to use:** When surface-like shading cues are desired for volumetric data visualization [S1, unofficial].
*   **When not to use:** When physically accurate volumetric light transport is required instead of surface approximations [S1, unofficial].
