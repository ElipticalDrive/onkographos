# Illumination model level intermixing


## Overview
Illumination model level intermixing is a multi-modal rendering technique where ray samples from different volumes are combined before colors and opacities are computed [S1, unofficial]. It addresses the limitations of image-level intermixing by resolving depth ordering issues through accumulation-level combination, specifically allowing for physically motivated mixing of distinct volumetric properties (e.g., emission vs. attenuation) prior to the final lighting calculation [S1, unofficial]. It sets itself apart from standard accumulation-level intermixing by treating the combined density as a single physical entity for the purpose of optical property lookup, rather than blending final color/opacity values.

## How it works
**Inputs and Outputs:**
*   **Inputs:** Multiple volume datasets (e.g., $V_1, V_2$), each with associated density fields $\rho_i$ and potentially distinct optical properties.
*   **Outputs:** A final pixel color $C$ and opacity $\alpha$.

**Data Structures:**
*   Ray parameters: origin $\mathbf{o}$, direction $\mathbf{d}$, step size $\Delta s$.
*   Volume data: Scalar fields $\rho_i(\mathbf{x})$ for each volume $i$.
*   Transfer functions: $T_{color}(\rho)$, $T_{opacity}(\rho)$ mapping density to color and opacity.

**Steps:**
1.  **Ray Casting:** Cast a ray through the scene.
2.  **Sample Acquisition:** For each step $j$ along the ray at position $\mathbf{x}_j$, sample the density $\rho_{i,j}$ from each volume $i$.
3.  **Density Combination:** Compute a combined density $\rho_{comb}$ at $\mathbf{x}_j$. The primary method is a weighted sum:
    $$ \rho_{comb} = \sum_{i} w_i \rho_{i,j} $$
    where $w_i$ are weights assigned to each volume [S1, unofficial].
    *   *Alternative Role Assignment:* Assign specific physical roles to volumes. For example, one volume acts as an emission source ($\rho_{emit}$) and another as an attenuator ($\rho_{att}$) [S1, unofficial].
4.  **Optical Property Lookup:** Use $\rho_{comb}$ to look up the color $c_j$ and opacity $\alpha_j$ using the transfer functions:
    $$ c_j = T_{color}(\rho_{comb}) $$
    $$ \alpha_j = T_{opacity}(\rho_{comb}) $$
    [S1, unofficial].
5.  **Compositing:** Composite the samples $(c_j, \alpha_j)$ along the ray using standard front-to-back or back-to-front volume rendering integration to produce the final pixel color.

**Parameters:**
*   Weights $w_i$: Determined by the physical relationship between modalities (e.g., 1:1 for simple density addition, or specific ratios for emission/attenuation balance) [S1, unofficial].
*   Step size $\Delta s$: Standard volume rendering step size.

**Edge Cases and Pitfalls:**
*   **Unit Mismatch:** Densities from different modalities (e.g., Hounsfield units in CT vs. arbitrary intensity in SPECT) may have different scales. Normalization or careful weighting is required [S1, unofficial].
*   **Degenerate Input:** If all $\rho_{i,j}$ are zero, $\rho_{comb}$ is zero, resulting in background color.

**Pseudocode:**
```python
def illumination_model_intermixing(ray_origin, ray_direction, volumes, transfer_functions):
    """
    volumes: list of objects, each having a sample_density(x) method
    transfer_functions: dict with 'color' and 'opacity' functions
    """
    color_accum = [0.0, 0.0, 0.0]
    alpha_accum = 0.0
    transmittance = 1.0
    
    # Standard ray marching loop
    for t in range(0, ray_length, step_size):
        pos = ray_origin + ray_direction * t
        
        # 1. Sample densities from all volumes
        densities = []
        for vol in volumes:
            densities.append(vol.sample_density(pos))
            
        # 2. Combine densities (Weighted Sum)
        # Example: simple sum. Weights can be adjusted per volume.
        combined_density = sum(densities)
        
        # 3. Lookup optical properties from combined density
        color = transfer_functions['color'](combined_density)
        opacity = transfer_functions['opacity'](combined_density)
        
        # 4. Composite
        alpha = opacity * transmittance
        color_accum = color_accum + alpha * color
        transmittance = transmittance * (1.0 - opacity)
        
        if transmittance < epsilon:
            break
            
    return color_accum
```

## Subtopics

## Operating characteristics
*   **Time Complexity:** $O(N \cdot M)$, where $N$ is the number of ray steps and $M$ is the number of volumes. Requires sampling all volumes at every step.
*   **Memory Complexity:** $O(M \cdot V)$, where $V$ is the size of each volume dataset.
*   **Strengths:** Physically intuitive for mixed-media scenarios (e.g., emissive activity within attenuating tissue); avoids color bleeding artifacts associated with image-level blending [S1, unofficial].
*   **Limitations:** Requires careful normalization of heterogeneous data sources; computationally expensive due to multiple texture lookups per step [S1, unofficial].
*   **When to use:** Multi-modal visualization where physical interaction between modalities (like attenuation of emission) is relevant, such as SPECT/CT fusion or radiation dose planning [S1, unofficial].

## Background
Originating from multi-modal volume rendering research, this technique is described in the context of accumulation-level intermixing [S1, unofficial]. It was demonstrated by Cai and Sakas in the scenario of radiation therapy dose planning, visualizing an emissive radiation beam embedded in an attenuating CT volume [S1, unofficial]. The method leverages the advantage of multi-channel data to avoid the need for complex color transfer function searches when reproducing original physical properties [S1, unofficial].
