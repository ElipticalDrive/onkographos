# Lighting-Specific Compositing
## Overview
Lighting-Specific Compositing is a family of volume rendering techniques that integrate illumination models (such as in-scattering, Phong shading, or boundary enhancement) directly into the compositing loop, rather than treating lighting as a post-processing step or a simple per-sample color multiplication [G]. It solves the problem of physically inaccurate or visually flat rendering by allowing light transport effects to influence the accumulation of opacity and color at the sample level [G]. It differs from standard direct volume ray casting by modifying the color and opacity terms ($c_i, \alpha_i$) before they enter the front-to-back accumulator, and from image-level compositing by preserving depth coherence for complex lighting interactions like occlusion and shadowing [G].

## Shared principles
All methods in this family operate on a sequence of samples $(c_i, \alpha_i)$ encountered along a ray, where $c_i$ is the sample color (RGB) and $\alpha_i$ is the sample opacity (A) [G]. The core mechanism involves an accumulator state $(C_{acc}, \alpha_{acc})$ initialized to $(0, 0)$ (or background color/opacity) and updated iteratively for each sample [G].

The standard optical model assumes that light is emitted or scattered by the volume and attenuated by absorption [G]. The standard front-to-back compositing equation updates these accumulators for each sample $i$ from front to back:
$$
C_{acc}^{(i)} = C_{acc}^{(i-1)} + (1 - \alpha_{acc}^{(i-1)}) \alpha_i C_i
$$
$$
\alpha_{acc}^{(i)} = \alpha_{acc}^{(i-1)} + (1 - \alpha_{acc}^{(i-1)}) \alpha_i
$$
where $C_{acc}^{(0)} = 0$ and $\alpha_{acc}^{(0)} = 0$ [G]. The term $(1 - \alpha_{acc}^{(i-1)})$ represents the transmittance, i.e., the fraction of light reaching sample $i$ from the camera side [G].

In iterative form using transmittance $T = 1 - \alpha_{acc}$:
$$
\begin{aligned}
C_{final} &\leftarrow C_{final} + c_i \cdot \alpha_i \cdot T \\
T &\leftarrow T \cdot (1 - \alpha_i)
\end{aligned}
$$
Where $T$ is initialized to $1.0$ and represents the accumulated transparency $\prod (1-\alpha_j)$ [G].

The final pixel color is often composited over a background color $C_{bg}$ using $C_{final} = C_{acc} + (1 - \alpha_{acc}) C_{bg}$ [G].

Early ray termination is a common optimization where the loop breaks if $T$ falls below a small threshold (e.g., $10^{-6}$), as further samples contribute negligibly to the color [G].

```python
def compositing_loop(samples, background_color):
    """
    Standard front-to-back compositing loop shared by the family.
    samples: list of (color: vec3, opacity: float) sorted front-to-back.
    background_color: vec3 for the scene background.
    """
    C_acc = vec3(0.0)
    T = 1.0
    
    for c_i, alpha_i in samples:
        C_acc = C_acc + T * alpha_i * c_i
        T = T * (1.0 - alpha_i)
        
        # Early ray termination
        if T <= 1e-6:
            break
            
    # Composite over background
    return C_acc + T * background_color
```

## Subtopics

### [Incremental Blending for In-scattering](2880-incremental-blending-for-in-scattering.md)
Incremental Blending for In-scattering approximates light scattering in volume rendering by discretizing the scattering sphere into $J$ directions and accumulating the results via incremental blending. It computes the in-scattering contribution for each direction independently and blends them into a stored accumulator buffer. It builds on [Lighting-Specific Compositing](5940-lighting-specific-compositing.md) by introducing indirect attenuation parameters and a dedicated light buffer for scattering propagation [G]. See [Incremental Blending for In-scattering](2880-incremental-blending-for-in-scattering.md).

### [Intermixing](5139-intermixing.md)
Intermixing is a technique for rendering multi-channel volume data by separately evaluating the illumination model for each channel at every ray sample and combining the results during the accumulation phase. It distinguishes itself from image-level compositing by correctly handling occlusions between different channels, as it retains depth information that image-level blending discards. It is more flexible than other approaches but computationally more expensive. See [Intermixing](5139-intermixing.md).

### [Boundary Enhancement](8071-boundary-enhancement.md)
Boundary enhancement is a compositing technique designed to improve the visibility of object boundaries and material interfaces within volume data. It addresses the problem of indistinct edges in standard volume rendering by emphasizing transitions between different tissues or structures, often used in conjunction with silhouette techniques in medical illustration. Unlike standard direct volume rendering which relies on opacity and color accumulation, this method modifies the shading or opacity contribution based on boundary detection. See [Boundary Enhancement](8071-boundary-enhancement.md).

### [Phong Shading with Volume Rendering](12805-phong-shading-with-volume-rendering.md)
Phong Shading with Volume Rendering enhances standard direct volume ray casting by applying Phong lighting (diffuse and specular) to volume samples based on surface normals derived from volume gradients. Unlike standard compositing which treats samples as colored blobs, this method calculates surface-like shading interactions before compositing, adding geometric depth cues to the volume. It differs from standard composite shaders by incorporating gradient-based normals and Phong lighting calculations into the color computation before compositing. See [Phong Shading with Volume Rendering](12805-phong-shading-with-volume-rendering.md).

### Shadow Catcher Compositing
- **Definition:** A technique for rendering shadow catchers where the camera sees the background darkened by the ratio of visible to total direct light, with alpha carrying shadow opacity [S1, unofficial].
- **Steps:** Darken the background by the ratio of visible to total direct light. Store shadow opacity in the alpha channel on a transparent background [S1, unofficial].
- **Pitfalls:** Indirect rays must still see the ground to ensure correct global illumination interaction [S1, unofficial].

### Contour Rendering Compositing
- **Definition:** A compositing step for contour rendering that uses Maximum Intensity Projection (MIP) or Local Maximum Intensity Projection (LMIP) to combine ray samples [S2, unofficial].
- **Steps:** 1. Perform classification and shading for all ray samples [S2, unofficial]. 2. Composite using MIP (max intensity) or LMIP to prevent stronger contours from hiding weaker, closer contours [S2, unofficial].

### Light Value Blending
- **Definition:** Blends four light values (a, b, c, d) into a single packed light value, replacing any zero values with the fourth value before averaging [S3, unofficial].
- **Steps:** If a == 0, set a = d. If b == 0, set b = d. If c == 0, set c = d. Return ((a + b + c + d) >> 2) & 0xFF00FF [S3, unofficial].

### Hybrid Lighting Volume Rendering
- **Definition:** Computes final HDR light intensity $L(x, l)$ for a ray at location $x$ in direction $l$ by combining volumetric lighting from a Lighting Volume Sky Gradient (LVSG) and an environment map $L_{env}$ using alpha compositing [S4].
- **Steps:** Select $K$ equi-spaced locations along the ray from $x$ in direction $l$. Use nearest neighbor interpolation to retrieve voxel values $\{\alpha_k, \xi_k\}$ from LVSG for each of the $K$ locations [S4]. Query the environment map intensity $L_{env}(l)$ in direction $l$ using bilinear interpolation [S4].
- **Formula:** $L(x, l) = \sum_{k=1}^{K} \tau_{k-1} \alpha_k G(-l; \xi_k) + \tau_K L_{env}(l)$, where $\tau_k = \prod_{i=1}^{k} (1 - \alpha_i)$ is the transmittance, and $\tau_0 = 1$ [S4].
- **Parameters:** $K$: Number of equi-spaced sampling locations along the ray. $\alpha_k$: Alpha (opacity) value from LVSG at sample $k$. $\xi_k$: Lighting feature/vector from LVSG at sample $k$. $G(-l; \xi_k)$: Lighting contribution function using feature $\xi_k$ and incoming direction $-l$. $L_{env}(l)$: Radiance from the HDR sky environment map in direction $l$ [S4].
- **Usage:** Used for rendering object insertion and shadows [S4].

### DLI Compositing
- **Steps:** Combine the DLI of each frame with the reference image by multiplying each pixel of the reference image by the value of the DLI stored in the corresponding pixel [S5]. Perform the compositing process on all frames to obtain an image that makes the smoke move perceptible [S5].
