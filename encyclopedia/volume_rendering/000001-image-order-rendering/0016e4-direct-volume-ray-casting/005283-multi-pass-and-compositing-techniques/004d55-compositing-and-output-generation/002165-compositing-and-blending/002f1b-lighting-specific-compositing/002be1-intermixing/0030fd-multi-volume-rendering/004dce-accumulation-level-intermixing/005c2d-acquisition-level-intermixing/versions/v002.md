# Acquisition Level Intermixing

Also called: Data intermixing at acquisition level, Statistical Vectorial Volume Classification, Vectorial Volume Classification

## Overview
Acquisition Level Intermixing is a multi-volume rendering framework that fuses multiple spatially aligned scalar volumes into a single vectorial volume before the standard rendering pipeline begins [S1, S2]. Unlike [Accumulation-level intermixing](13575-accumulation-level-intermixing.md), which combines ray samples during traversal, this method performs statistical classification on the combined data to extract material properties, thereby preserving depth ordering and enabling joint analysis of dependent acquisitions [S2].

## How it works
**Inputs and Outputs:**
*   **Inputs:** $N$ scalar volumes $\{V_1, V_2, \dots, V_N\}$ representing different acquisitions of the same subject, assumed to be spatially aligned on a common grid [S1, S2].
*   **Outputs:** A final rendered image based on classified material properties [S1, S2].

**Data Structures:**
*   **Vectorial Volume ($V_{vec}$):** A 3D grid where each voxel at position $\mathbf{x}$ contains a vector $\mathbf{v}(\mathbf{x})$ of dimension $N$ [S1, S2].
    *   Layout: $\mathbf{v}(\mathbf{x}) = [v_1(\mathbf{x}), v_2(\mathbf{x}), \dots, v_N(\mathbf{x})]$, where $v_i(\mathbf{x})$ is the scalar value from volume $V_i$ at $\mathbf{x}$ [S1, S2].
    *   Size: Not given in the sources.

**Parameters:**
*   $N$: Number of acquisitions [S1, S2].
*   $K$: Total number of tissues or materials to classify [S2].
*   $C_k$: Assigned color for material $k$, where $1 \le k \le K$ [S2].
*   $\alpha_k$: Assigned global opacity for material $k$, where $1 \le k \le K$ [S2].

**Steps:**

1.  **3D/3D Image Registration:** Align the $N$ input volumes into the same spatial space [S1, S2].
2.  **Form Vectorial Volume:** Construct $V_{vec}$ by stacking the aligned scalar volumes so each voxel contains a vector of $n$ elements corresponding to the information of the $n$ acquisitions [S1, S2].
3.  **Statistical Classification:** Apply a statistical multi-dimensional classification method to $V_{vec}$ to estimate material probability distributions [S1, S2]. The sources specify a neighborhood weighted Gaussian mixture model [S1, S2]. This step yields the probability that a voxel belongs to each of the $K$ materials [S2]. *Note:* The detailed algorithm is in prior work [S1, Ref 9; S2, Ref 14] and is not provided here [S1, S2].
4.  **Assign Material Properties:** Based on the classification results, assign the material color $C_k$ and global opacity $\alpha_k$ for each of the $K$ tissues [S2].
5.  **Rendering:** Render the multi-volume using the classified material properties [S1, S2]. The method supports both surface rendering (extracting geometric primitives) and direct volume rendering techniques [S2].

**Pseudocode:**

```python
def acquisition_level_intermixing(volumes, num_tissues):
    # volumes: List of N scalar 3D arrays (volumes), all same shape (W, H, D).
    # num_tissues: Integer K, number of materials to classify.
    # Returns: Rendered image or material property maps.

    N = len(volumes)
    shape = volumes[0].shape

    # Step 1: Registration
    # [G] Assumes input volumes are already aligned to a common grid.

    # Step 2: Form Vectorial Volume
    # Stack volumes along a new axis to create a vector per voxel.
    # Resulting shape: (W, H, D, N)
    vectorial_volume = [
        [[volumes[i][z][y][x] for i in range(N)] for y in range(shape[1])]
        for z in range(shape[0])
    ]

    # Step 3: Statistical Classification
    # Apply neighborhood weighted Gaussian mixture model.
    # This returns material probability distributions for each voxel.
    # [Comment] The specific mathematical formulation of the classification
    # algorithm is detailed in prior work [S1, Ref 9; S2, Ref 14] and is not provided here.
    material_probabilities = classify_vectorial_volume(vectorial_volume, num_tissues)

    # Step 4: Assign Material Properties
    # C_k: Color for tissue k
    # alpha_k: Opacity for tissue k
    # These are user-defined or derived from the classification confidence.
    colors = [None] * num_tissues
    opacities = [None] * num_tissues

    # Step 5: Rendering
    # Render using the classified properties.
    # This can be surface rendering or direct volume rendering.
    # [Comment] Standard volume rendering compositing or mesh extraction is applied here.
    image = render_material_properties(material_probabilities, colors, opacities)

    return image

def classify_vectorial_volume(data, k):
    # [Comment] The specific mathematical formulation of the classification
    # algorithm is detailed in prior work [S1, Ref 9; S2, Ref 14] and is not provided here.
    return [[0.0] * k for _ in range(len(data) * len(data[0]) * len(data[0][0]))]

def render_material_properties(probs, colors, opacities):

    return [0] * 100
```

**Edge Cases and Pitfalls:**
*   **Noise:** The classification method is chosen specifically to be less affected by noise, but poor signal-to-noise ratio in input acquisitions may still degrade material probability estimates [S2].
*   **Boundary Mis-classification:** Standard classification may fail at boundaries; the neighborhood weighted approach is used to mitigate this [S2].

## Operating characteristics
*   **Time Complexity:** Not given in the sources.
*   **Memory Complexity:** Not given in the sources.
*   **Strengths:**
    *   Preserves depth ordering by mixing data at the earliest stage (acquisition level) rather than during ray casting [S2].
    *   Enables joint statistical analysis of dependent acquisitions (e.g., from the same patient) [S1, S2].
    *   Reduces mis-classification on boundaries compared to scalar-only methods [S2].
*   **Limitations:**
    *   Requires high-quality 3D/3D registration [S1, S2].
    *   Computationally intensive due to multi-dimensional classification [S1, S2].
*   **When to use:** Multi-modal medical imaging visualization where multiple acquisitions of the same subject need to be combined (e.g., preoperative kidney planning) [S2].
*   **When not to use:** When volumes are not spatially aligned or represent independent subjects [S1, S2].

## Background
Acquisition Level Intermixing was proposed to address the limitations of existing multi-volume rendering methods that mix data at specific steps of the rendering pipeline (image, composition, or illumination levels) [S2]. The authors argue that volumes from the same patient are not independent and should be analyzed together [S1, S2]. The method was demonstrated in the context of medical imaging, specifically for preoperative kidney planning [S2]. The statistical classification component relies on a neighborhood weighted Gaussian mixture model, detailed in prior work by the same authors [S1, Ref 9; S2, Ref 14].
