# Incremental Lighting for In-Scattering

Also called: Translucency Approximation via Indirect Attenuation

## Overview
Incremental Lighting for In-Scattering is a screen-space technique that approximates volumetric light scattering (translucency) by propagating and blurring indirect lighting components across volume slices [S1]. It extends the base incremental blending method by introducing per-channel indirect attenuation parameters and a blur operation, allowing light to change color as it penetrates deeper into the volume [S1].

## How it works
This method builds on [Incremental Blending for In-scattering](2880-incremental-blending-for-in-scattering.md) by modifying the light buffer initialization, the compositing blend function, and the data flow to support spatial blurring of indirect attenuation [S1].

### Inputs and Outputs
*   **Inputs:**
    *   Volume data (density, color) [S1].
    *   Indirect attenuation parameters $A_i$: Alpha values for each RGB color channel, distinct from the standard alpha $A$ used in the eye pass [S1].
    *   Light color $C_L$ [S1].
    *   Sample distance $d$ [S1].
    *   Blur angle: A user-defined parameter scaling the perturbation radius [S1].
    *   Perturbation texture: A 2D texture storing offset vectors used to modify texture coordinates for blurring [S1].
*   **Outputs:**
    *   Final rendered image with translucent lighting effects [S1].

### Data Structures
*   **Light Buffers:** Two framebuffers (or textures) are used in an alternating fashion [S1].
    *   $L_{current}$: Stores the indirect attenuation state for the current slice iteration [S1].
    *   $L_{next}$: The render target for the updated attenuation state after blurring and blending [S1].
*   **Perturbation Texture:** A texture containing offset data used to perturb texture coordinates for the blur sampling [S1].

### Algorithm Steps
The method modifies the standard incremental ray casting loop as follows:

1.  **Initialization:** Initialize the light buffer ($L_{current}$) with the value $1 - C_L$ instead of the standard light color $C_L$ [S1].
2.  **Per-Slice Loop:** For each volume slice, perform the following:
    3.  **Eye Pass (Pass 1):**
        *   Sample the volume to obtain the direct fragment color $C$ [S1].
        *   Read the indirect attenuation value $A_{in}$ from $L_{current}$ [S1].
        *   Multiply the fragment color by the remaining indirect transmission: $C_{final} = C \times (1 - A_{in})$ [S1].
        *   Output $C_{final}$ to the color buffer [S1].
    4.  **Light Pass (Pass 2):**
        *   Set the fragment shader color to $A_i$ instead of $0$ [S1].
        *   Replace the standard Over operator with the Light Buffer Compositing blend defined in Equation 8 [S1].
        *   Modify the texture coordinates for sampling $L_{current}$ using the perturbation texture [S1].
        *   Calculate the blur radius $R$ scaled by the sample distance $d$ and the blur angle [S1].
        *   Sample $L_{current}$ multiple times using the modified texture coordinates [S1].
        *   Compute the blurred attenuation as a weighted sum of the sampled values [S1].
        *   Blend the blurred attenuation into $L_{next}$ using the Light Buffer Compositing operation [S1].
    5.  **Buffer Swap:** After processing the slice, swap $L_{current}$ and $L_{next}$ so that the updated buffer becomes the source for the next slice's Eye Pass [S1].

### Pseudocode
```python
# Initialization
L_buffers = [create_2d_texture(width, height), create_2d_texture(width, height)]
L_current = L_buffers[0]
L_next = L_buffers[1]
L_current.fill(1.0 - C_L)  # Initialize with 1 - Light Color [S1]

# Per-Slice Loop
for slice in volume_slices:
    # Pass 1: Eye Pass
    for fragment in slice:
        # Standard volume sampling to get direct color C and standard alpha A [G]
        C_direct, A_standard = sample_volume(fragment)
        
        # Read indirect attenuation from current light buffer [S1]
        A_indirect = L_current.sample(fragment.uv)
        
        # Multiply direct color by remaining indirect transmission [S1]
        C_final = C_direct * (1.0 - A_indirect)
        
        output_color_buffer(fragment.uv, C_final)

    # Pass 2: Light Pass (Update and Blur Light Buffer)
    L_next.clear()
    
    # Blur radius scales with sample distance d and blur angle [S1]
    R = d * blur_angle
    
    for fragment in slice:
        # 1. Compute Blurred Indirect Attenuation
        blurred_A = 0.0
        weight_sum = 0.0
        
        # Sample current light buffer multiple times with perturbed coordinates [S1]
        for k in range(blur_samples):
            # Perturb UV using perturbation texture scaled by R [S1]
            perturbation = perturbation_texture.sample(fragment.uv)
            uv_perturbed = fragment.uv + perturbation * R
            
            # Sample the current light buffer
            val = L_current.sample(uv_perturbed)
            
            # Weighted sum using a standard normalized box kernel [G]
            w = 1.0 / blur_samples
            blurred_A += val * w
            weight_sum += w
            
        blurred_A /= weight_sum
        
        # 2. Compute Incoming Fragment Color for Light Buffer
        # The fragment shader color is set to Ai instead of 0 [S1]
        C_in = A_indirect
        A_in = A_indirect
        
        # 3. Apply Light Buffer Compositing (Equation 8) [S1]
        # C0 is the color currently in the target render buffer (L_next)
        C_target = L_next.sample(fragment.uv)
        
        # Equation 8: C_out = C_in * (1 - C_target) + C_target * (1 - A_in)
        C_out = C_in * (1.0 - C_target) + C_target * (1.0 - A_in)
        
        L_next.set_pixel(fragment.uv, C_out)

    # Swap buffers after each slice [S1]
    L_current, L_next = L_next, L_current

    return fragment.color, fragment.alpha
```

### Parameters
*   **$A_i$**: Indirect attenuation parameters, alpha values for each RGB channel. Must be set independently per channel to achieve color-changing penetration [S1].
*   **$d$**: Sample distance, used to calculate the blur radius [S1].
*   **Blur Angle**: User-defined parameter scaling the perturbation radius [S1].

### Edge Cases and Pitfalls
*   **Color-Changing Penetration:** To achieve effects like white light turning red as it penetrates (e.g., flashlight under hand), set the $A_i$ value for red smaller than the $A_i$ values for green and blue. This results in lower attenuation of the red component, allowing more red light to pass through deeper layers [S1].
*   **Precision:** The method relies on screen-space buffers. Matching the resolution of light propagation to the viewport produces crisp shadows with minimal aliasing artifacts [S1].
*   **Decoupling:** The resolution of light transport is decoupled from the 3D data grid, allowing accurate lighting of volumes without increasing the 3D sampling density [S1].

## Operating characteristics
*   **Time Complexity:** Linear with respect to the number of volume samples and slices, plus the cost of the blur operation (multiple samples per fragment in Pass 2) [S1].
*   **Memory Complexity:** Requires two additional light buffers (framebuffers) in addition to standard color and depth buffers [S1].
*   **Strengths:**
    *   Produces convincing translucent effects for clouds and atmospheric phenomena [S1].
    *   Decouples light transport resolution from 3D data grid resolution [S1].
    *   Matches light propagation resolution to viewport, reducing aliasing in shadows [S1].
*   **Limitations:**
    *   Approximation: Relies on local neighborhood blurring, which may not capture complex global light transport accurately [G].
    *   Requires additional buffer management and passes [G].
