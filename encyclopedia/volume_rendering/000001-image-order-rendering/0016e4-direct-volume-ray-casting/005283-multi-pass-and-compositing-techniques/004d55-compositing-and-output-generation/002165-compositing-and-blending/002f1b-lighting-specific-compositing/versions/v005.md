# Lighting-Specific Compositing
## Overview
Lighting-Specific Compositing encompasses techniques that modify the standard front-to-back compositing equation to incorporate lighting effects, multi-channel illumination, geometric boundary enhancement, and shadow handling directly into the accumulation step. It sets itself apart from [Pre-Integration Lookup](2854-pre-integration-lookup.md) (which approximates integration via texture lookups) and [Binary Swap Compositing](3264-binary-swap-compositing.md) (which focuses on parallel reduction structures), as it specifically addresses the illumination model within the compositing loop [G].

## Shared principles
This family modifies the standard compositing loop detailed in [Compositing and Blending](2515-compositing-and-blending.md) by computing lighting-specific contributions per sample or per channel before blending them into the accumulator. Instead of using raw transfer function outputs, each method derives modified color $\Delta C_i$ and opacity $\Delta \alpha_i$ terms that encode illumination effects, shadowing, or geometric cues [G]. Early ray termination remains applicable when the accumulated opacity exceeds a threshold [G].

## Subtopics

### [Incremental Blending for In-scattering](2880-incremental-blending-for-in-scattering.md)
Approximates volumetric light scattering by accumulating scattered light from discrete directions. It sets itself apart by treating the scattering integral as a sum of directional components blended incrementally, allowing interactive updates. Choose this when global illumination effects are needed without full path tracing costs.

### [Intermixing](5139-intermixing.md)
Renders multi-channel volume data by evaluating illumination per channel and combining results during accumulation. It handles inter-channel occlusions naturally, unlike image-level intermixing. Choose this for visualizing complex interactions between distinct data sources (e.g., tissue types).

### [Boundary Enhancement](8071-boundary-enhancement.md)
Improves boundary visibility by modulating opacity based on geometric cues (silhouettes). It suppresses opacity when the view vector aligns with the surface normal, creating dark outlines. Choose this to enhance edge definition in volumes.

### [Phong Shading with Volume Rendering](12805-phong-shading-with-volume-rendering.md)
Applies Phong lighting (diffuse/specular) to volume samples using gradient-based normals. It adds surface-like shading to volumes, unlike standard compositing which lacks geometric shading. Choose this for surface-like appearance in volumetric data.

### Shadow Catcher Compositing
A technique for rendering shadow catchers where the camera sees the background darkened by the ratio of visible to total direct light, with alpha carrying shadow opacity [S1, unofficial]. The implementation darkens the background by this ratio and stores shadow opacity in the alpha channel on a transparent background [S1, unofficial]. A key pitfall is that indirect rays must still see the ground to ensure correct global illumination interaction [S1, unofficial].

### Contour Rendering Compositing
A compositing step for contour rendering that uses Maximum Intensity Projection (MIP) or Local Maximum Intensity Projection (LMIP) to combine ray samples [S2, unofficial]. The process performs classification and shading for all ray samples, then composites using MIP (max intensity) or LMIP to prevent stronger contours from hiding weaker, closer contours [S2, unofficial].

### Light Value Blending
Blends four light values (a, b, c, d) into a single packed light value, replacing any zero values with the fourth value before averaging [S3, unofficial]. The steps are: if a == 0, set a = d; if b == 0, set b = d; if c == 0, set c = d; return ((a + b + c + d) >> 2) & 0xFF00FF [S3, unofficial].

## Background
The separation of volume rendering into classification, shading, and compositing stages allows lighting-specific modifications to be applied during the compositing phase [S2, unofficial]. Shadow catcher compositing, which darkens the background based on visible direct light ratios, is supported in modern rendering engines alongside physical sky models and IES light controls [S1, unofficial].
