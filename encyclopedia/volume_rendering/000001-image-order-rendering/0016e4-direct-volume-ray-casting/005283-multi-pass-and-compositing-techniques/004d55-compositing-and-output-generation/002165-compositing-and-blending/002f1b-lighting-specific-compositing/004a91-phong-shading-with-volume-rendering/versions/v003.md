# Phong Shading with Volume Rendering

Also called: compositeShaderPhong

## Overview
Phong Shading with Volume Rendering enhances standard direct volume ray casting by applying Phong illumination models (diffuse and specular) to volume samples based on computed surface normals derived from density gradients [S1, unofficial]. Unlike standard compositing which blends raw transfer function outputs, this method modifies the sample color $\Delta C_i$ and opacity $\Delta \alpha_i$ terms to encode geometric shading, adding surface-like appearance cues to volumetric data [S1, unofficial]. It builds on [Lighting-Specific Compositing](5940-lighting-specific-compositing.md).

## How it works
**Inputs:**
*   Volume dataset (scalar field).
*   Transfer function (mapping scalar value to RGBA).
*   Camera position ($v_{position}$).
*   Light direction vector ($l_{vector}$).
*   Shininess exponent ($shininess$).
*   Specular coefficient multiplier ($k_s$).
*   Ray origin and direction.
*   Volume bounding box (for AABB intersection).

**Outputs:**
*   Final pixel color and opacity.

**Data Structures:**
*   **Ray State:** Origin, direction, current position, accumulated color ($C_{acc}$), accumulated opacity ($\alpha_{acc}$).
*   **Sample Data:** Interpolated color ($c$), interpolated gradient ($\mathbf{n}$).

**Numbered Steps:**

1.  **Ray-Volume Intersection:** Perform standard Axis-Aligned Bounding Box (AABB) intersection to determine the entry point $t_0$, exit point $t_1$, and step size (sample length) along the ray [S1, unofficial].
2.  **Initialization:** Initialize the color accumulator $C_{acc} = (0, 0, 0, 0)$ and opacity accumulator $\alpha_{acc} = 0$ [S1, unofficial].
3.  **Ray Casting Loop:** Iterate for $i$ from $0$ to $SAMPLES-1$. Continue while the ray is within the volume bounds and $\alpha_{acc} < 0.99$ [S1, unofficial].
    *   **Sample Retrieval:** Retrieve the interpolated color $c$ (RGBA) and the gradient vector $\mathbf{n}$ at the current ray position [S1, unofficial].
    *   **Normal Computation:** If $\mathbf{n}$ is not zero, normalize it to obtain the surface normal $\mathbf{N} = \frac{\mathbf{n}}{\|\mathbf{n}\|}$ [S1, unofficial].
    *   **View Direction:** Compute the view direction vector $\mathbf{V}$ from the sample point to the camera position ($v_{position}$) and normalize it [S1, unofficial].
    *   **Lighting Calculation:**
        *   Compute the diffuse term: $D = \max(0, \mathbf{N} \cdot \mathbf{L})$, where $\mathbf{L}$ is the normalized light vector [S1, unofficial].
        *   Compute the reflection vector $\mathbf{R} = 2(\mathbf{N} \cdot \mathbf{L})\mathbf{N} - \mathbf{L}$ [S1, unofficial].
        *   Compute the specular term: $S = k_s \cdot (\max(0, \mathbf{R} \cdot \mathbf{V}))^{shininess}$ [S1, unofficial].
    *   **Color Modification:** Modify the sample color $c$ by combining the diffuse term, an ambient-like term ($0.05 \cdot c$), and the specular term [S1, unofficial]. The exact combination is described as modifying $c$ using these terms. Let the modified color be $c'$.
    *   **Alpha Preservation:** Preserve the original alpha value in a temporary variable $tempa = c.a$ [S1, unofficial].
    *   **Compositing:** Apply the modified color $c'$ and the preserved alpha $tempa$ to the front-to-back compositing formula [S1, unofficial].
        *   Update $C_{acc}$ and $\alpha_{acc}$ using standard over operator:
            $$ \alpha_{new} = \alpha_{acc} + tempa \cdot (1 - \alpha_{acc}) $$
            $$ C_{acc} = \frac{C_{acc} \cdot \alpha_{acc} + c' \cdot tempa \cdot (1 - \alpha_{acc})}{\alpha_{new}} $$
            (Note: Standard front-to-back blending is $C_{out} = C_{in} + C_{sample} \cdot \alpha_{sample} \cdot (1 - \alpha_{in})$ and $\alpha_{out} = \alpha_{in} + \alpha_{sample} \cdot (1 - \alpha_{in})$. The source implies modifying the color *before* this step.)
    *   **Early Termination:** If $\alpha_{acc} \ge 0.99$, set $\alpha_{acc} = 1.0$ and break the loop [S1, unofficial].
    *   **Advance Ray:** Advance the ray position by $sampleLength$ [S1, unofficial].
4.  **Final Output:** Return $C_{acc}$ and $\alpha_{acc}$ [S1, unofficial].

**Pseudocode:**

```python
def phong_shading_volume_ray_casting(ray_origin, ray_direction, volume_data, transfer_function, camera_pos, light_dir, shininess, ks):
    # 1. AABB Intersection
    t0, t1, sample_length = intersect_aabb(ray_origin, ray_direction, volume_data.bbox)
    
    # 2. Initialization
    acc_color = vec4(0.0, 0.0, 0.0, 0.0)
    acc_alpha = 0.0
    
    current_pos = ray_origin + t0 * ray_direction
    
    # 3. Ray Casting Loop
    for i in range(SAMPLES):
        if acc_alpha >= 0.99:
            acc_alpha = 1.0
            break
            
        # Sample Retrieval
        c = transfer_function.sample(current_pos) # Returns vec4 (RGBA)
        n = volume_data.gradient(current_pos)     # Returns vec3
        
        # Normal Computation
        if length(n) > 0.0:
            N = normalize(n)
        else:
            N = vec3(0.0, 0.0, 0.0)
            
        # View Direction
        V = normalize(camera_pos - current_pos)
        
        # Lighting Calculation
        L = normalize(light_dir)
        
        # Diffuse term
        diff = max(dot(N, L), 0.0)
        
        # Specular term
        R = reflect(-L, N) # R = 2(N.L)N - L, assuming L points from surface to light? 
                           # Source says "reflected light vector". Standard Phong: R = 2(N.L)N - L if L is light direction.
                           # Let's assume standard reflection vector calculation.
        spec = ks * pow(max(dot(R, V), 0.0), shininess)
        
        # Color Modification
        # Source: "modify the sample color c by combining the diffuse term, an ambient-like term (0.05*c), and the specular term scaled by ks"
        # Note: ks is already used in spec calculation in source description? 
        # Source says: "specular term scaled by ks" AND "ks: The specular coefficient multiplier".
        # And "specular term as the shininess power of the clamped dot product...".
        # It seems spec = (dot(R,V)^shininess) * ks.
        
        # Ambient-like term
        ambient = 0.05 * c
        
        # Combine. The source doesn't give exact formula for combining diff/spec/ambient into c'.
        # Assuming additive modification to the RGB channels of c.
        c_modified = c
        c_modified.rgb = c.rgb * ambient.rgb + diff * vec3(1.0) + spec # Approximation based on "combining"
        # Note: Source is vague on exact combination. "modify the sample color c by combining..."
        # A common interpretation: c' = c * ambient + diff * light_color + spec.
        # Since light_color isn't specified, assume white or diffuse term acts as intensity.
        # Let's stick to the most literal interpretation of "combining":
        # c'.rgb = c.rgb * 0.05 + diff + spec? Or c.rgb * (ambient + diff) + spec?
        # Given "ambient-like term (0.05*c)", it suggests scaling the base color.
        # Let's assume: c'.rgb = c.rgb * 0.05 + diff * vec3(1.0) + spec * vec3(1.0)
        # This is a guess [G] due to ambiguity in "combining".
        
        # Preserve Alpha
        tempa = c.a
        
        # Compositing
        # Front-to-back blending
        alpha_contrib = tempa * (1.0 - acc_alpha)
        acc_color.rgb = acc_color.rgb * acc_alpha + c_modified.rgb * alpha_contrib
        acc_alpha = acc_alpha + alpha_contrib
        
        if acc_alpha >= 0.99:
            acc_alpha = 1.0
            break
            
        # Advance Ray
        current_pos += sample_length * ray_direction
        
    return acc_color, acc_alpha
```

**Parameters:**
*   `shininess`: The specular exponent for the Phong model [S1, unofficial].
*   `ks`: The specular coefficient multiplier [S1, unofficial].
*   `lightVector`: The direction vector of the light source [S1, unofficial].
*   `vposition`: The position of the camera/viewpoint [S1, unofficial].

**Edge Cases and Pitfalls:**
*   **Zero Gradient:** If the gradient vector is zero (e.g., in homogeneous regions), the normal cannot be computed. The method should handle this by skipping lighting calculations or using a default normal [S1, unofficial].
*   **Precision:** Accumulated opacity threshold is 0.99. Early termination at this threshold may cause slight inaccuracies in transparent regions [S1, unofficial].
*   **Boundary:** AABB intersection must be robust to handle rays grazing the volume boundaries [S1, unofficial].

## Operating characteristics
*   **Time Complexity:** $O(N)$ per ray, where $N$ is the number of samples. Lighting calculations (dot products, powers) add constant overhead per sample compared to standard compositing.
*   **Memory Complexity:** $O(1)$ auxiliary memory per ray (accumulators).
*   **Strengths:** Adds surface-like shading and specular highlights to volumes, improving perceptual depth and material appearance [S1, unofficial].
*   **Limitations:** Relies on gradients, which can be noisy in low-resolution or noisy data. Computationally more expensive than standard compositing due to lighting math [S1, unofficial].
*   **When to use:** When surface appearance and specular highlights are desired for volumetric data [S1, unofficial].
*   **When not to use:** For purely scientific visualization where quantitative accuracy of density is prioritized over aesthetic shading, or for very noisy data where gradient-based normals are unreliable.

## Background
This method is part of the "Lighting-Specific Compositing" family, which modifies the standard compositing loop to compute lighting-specific contributions per sample [S1, unofficial]. It differs from the standard `compositeShader` by incorporating gradient-based normals and Phong lighting calculations (diffuse and specular) into the color computation before compositing [S1, unofficial]. The specific implementation details are derived from an educational volume ray casting project [S1, unofficial].
