# Non-Linear Gradient Interpolation for Pre-Integrated Volume Rendering

Also called: Non-linear gradient interpolation, Non-linear polynomial interpolation, Pre-Integrated Volume Rendering with Non-Linear Gradient Interpolation, Pre-integration with quadratic gradient interpolation, Quadratic gradient interpolation

## Overview
Non-linear gradient interpolation is a technique for pre-integrated direct volume rendering that reduces shading errors by interpolating gradients between front and back samples along a quadratic curve instead of a linear segment, allowing accurate computation of 2D pre-integration look-up tables [S1]. It sets itself apart from linear gradient interpolation by approximating the non-linear path of a normalized gradient vector as a quadratic polynomial, thereby avoiding the energy loss and shading errors inherent in linear interpolation which assumes the normalization term $\eta(t)=1$ [S1].

## How it works
**Inputs and Outputs:**
*   **Inputs:** Front sample properties $S_f$, Back sample properties $S_b$, Front normalized gradient $N_f$, Back normalized gradient $N_b$, Light direction $L$, Specular half-vector $H$, Shininess $n_\delta$, Slab size $D$, normalization factor $r$, and pre-computed 2D lookup tables [S1].
*   **Outputs:** Diffuse shading coefficient $\tilde{C}_d$, Specular shading coefficient $\tilde{C}_s$ [S1].

**Data Structures:**
*   **Lookup Tables:** Four 2D tables for the diffuse term ($I_0, I_1, I_2, I_3$) and five 2D tables for the specular term ($I_{00}, I_{10}, I_{20}, I_{30}$) [S1].
*   **Representation:** 16-bit unsigned short in GPU memory [S1].
*   **Indexing:** Tables are indexed by $S_f$ and $S_b$ [S1].

**Definitions:**
*   $\alpha = \arccos(N_f \cdot N_b) / 2$: Half the angle between front and back normals [S1].
*   $r$: A normalization factor derived from the geometry of the interpolated gradient arc [S1].
*   $s = t/D$: Normalized distance along the slab, $t \in [0, D]$ [S1].
*   $s_0 = S_f + s(S_b - S_f)$: Normalized scalar value at position $s$ [S1].
*   $d = D / (S_b - S_f)$: Scaling factor for the integral substitution [S1].
*   $\eta(t) \approx \frac{\cos(\alpha) \cdot x^2}{x^2 (\cos(\alpha) - 1) + 1}$: Quadratic approximation of the normalization term, where $x = \frac{2t}{D} - 1 = 2s - 1$ [S1].
*   $\nabla g(t)/\|\nabla g(t)\| \approx \frac{(1 + (2t/D - 1)^2 (\cos(\alpha) - 1)) (\|\nabla g(0)\| t + \|\nabla g(D)\| (D - t))}{D \cos(\alpha)}$: Approximated normalized gradient vector [S1].

**Step-by-Step Method:**

1.  **Compute Angle:** Calculate $\alpha = \arccos(N_f \cdot N_b) / 2$ [S1].
2.  **Compute Diffuse Coefficients ($a_k$):** Calculate coefficients using $N_f, N_b, L, \alpha$, and $r$:
    $$ a_0 = \frac{4(\cos(\alpha) - 1)}{\cos(\alpha)} $$
    $$ a_1 = N_b \cdot L - N_f \cdot L $$
    $$ a_2 = \frac{N_b \cdot L - (1 + r)N_f \cdot L}{r(2N_f \cdot L - N_b \cdot L)} $$
    $$ a_3 = \frac{N_f \cdot L}{r} $$
    [S1]
3.  **Access Diffuse Lookup Tables:** Retrieve $I_0(S_f, S_b), I_1(S_f, S_b), I_2(S_f, S_b), I_3(S_f, S_b)$ from the pre-computed 2D tables [S1].
    $$ I_k(S_f, S_b) = d \int_{S_f}^{S_b} c(s_0) \cdot s^k \cdot \exp(-d \sigma(S_f, s_0)) \, ds_0 $$
    [S1]
4.  **Compute Diffuse Shading:** Calculate $\tilde{C}_d = K_d (a_0 I_0 + a_1 I_1 + a_2 I_2 + a_3 I_3)$ [S1].
5.  **Handle Negative Dot Products (Diffuse):** If $N_f \cdot L < 0$ or $N_b \cdot L < 0$, apply case-based handling: if both are positive, use the standard formulation; if either is negative, fade in/out the non-negative value; if both are negative, the result is 0 [S1].
6.  **Specular Term Approximation:** Replace the Phong lobe $\cos(\theta)^{n_\delta}$ with a Phong cone approximation: $\cos(\theta)^{n_\delta} \approx 1 + n_\delta (\cos(\theta) - 1)$, where $\cos(\theta) = N \cdot H$ [S1].
7.  **Compute Specular Coefficients:** Calculate $a_0(H), a_1(H), a_2(H), a_3(H)$ using $H$ instead of $L$ with the same formulas as step 2 [S1].
8.  **Access Specular Lookup Tables:** Retrieve $I_{00}, I_{10}, I_{20}, I_{30}$ [S1].
    $$ I_{00}(S_f, S_b) = d \int_{S_f}^{S_b} (s < 0.5 ? 2s : 2 - 2s) \cdot \exp(-d \sigma(S_f, s_0)) \, ds_0 $$
    [S1]
9.  **Compute Specular Shading:** Calculate $\tilde{C}_s = K_s (I_{00} + n_\delta (a_0(H)I_{00} + a_1(H)I_{10} + a_2(H)I_{20} + a_3(H)I_{30}) - n_\delta I_{00})$ [S1].
10. **Handle Negative Dot Products (Specular):** Specular values become negative if $N(s_0) \cdot H < \text{thresh} = (n_\delta - 1)/n_\delta$. If both $N_f \cdot H > \text{thresh}$ and $N_b \cdot H > \text{thresh}$, use the standard formulation. If either is below the threshold, use a fading approximation. If both $N_f \cdot L < 0$ and $N_b \cdot L < 0$, a highlight may exist between samples; use the $I_{00}$ approximation [S1].

**Pseudocode:**

```python
def sample_2d_table(table, sf, sb):
    """Helper to access a pre-computed 2D lookup table indexed by sf and sb."""
    return table[sf][sb]

def compute_shading(Nf, Nb, Sf, Sb, L, H, n_delta, Ka, Kd, Ks, D, r, 
                    T_I0, T_I1, T_I2, T_I3, T_I00, T_I10, T_I20, T_I30):
    # 1. Compute angle alpha
    cos_alpha = dot(Nf, Nb)
    alpha = acos(cos_alpha) / 2.0
    
    # 2. Compute Diffuse Coefficients
    Nf_dot_L = dot(Nf, L)
    Nb_dot_L = dot(Nb, L)
    
    a0 = 4.0 * (cos(alpha) - 1.0) / cos_alpha
    a1 = Nb_dot_L - Nf_dot_L
    denom_a2 = r * (2.0 * Nf_dot_L - Nb_dot_L)
    a2 = (Nb_dot_L - (1.0 + r) * Nf_dot_L) / denom_a2 if abs(denom_a2) > 1e-9 else 0.0
    a3 = Nf_dot_L / r

    # 3. Handle Negative Dot Products (Diffuse)
    if Nf_dot_L < 0 and Nb_dot_L < 0:
        Cd = 0.0
    elif Nf_dot_L > 0 and Nb_dot_L > 0:
        # 4. Access Diffuse Lookup Tables
        I0 = sample_2d_table(T_I0, Sf, Sb)
        I1 = sample_2d_table(T_I1, Sf, Sb)
        I2 = sample_2d_table(T_I2, Sf, Sb)
        I3 = sample_2d_table(T_I3, Sf, Sb)
        # 5. Compute Diffuse Shading
        Cd = Kd * (a0 * I0 + a1 * I1 + a2 * I2 + a3 * I3)
    else:
        # Fading approximation for mixed signs
        I0 = sample_2d_table(T_I0, Sf, Sb)
        I1 = sample_2d_table(T_I1, Sf, Sb)
        Cd = Kd * (a0 * I0 + a1 * I1) # Simplified fading per source guidelines

    # 6. Specular Coefficients (using H)
    Nf_dot_H = dot(Nf, H)
    Nb_dot_H = dot(Nb, H)
    thresh = (n_delta - 1.0) / n_delta
    
    a0_s = 4.0 * (cos(alpha) - 1.0) / cos_alpha
    a1_s = Nb_dot_H - Nf_dot_H
    denom_a2_s = r * (2.0 * Nf_dot_H - Nb_dot_H)
    a2_s = (Nb_dot_H - (1.0 + r) * Nf_dot_H) / denom_a2_s if abs(denom_a2_s) > 1e-9 else 0.0
    a3_s = Nf_dot_H / r

    # 7. Access Specular Lookup Tables
    I00 = sample_2d_table(T_I00, Sf, Sb)
    I10 = sample_2d_table(T_I10, Sf, Sb)
    I20 = sample_2d_table(T_I20, Sf, Sb)
    I30 = sample_2d_table(T_I30, Sf, Sb)

    # 8. Handle Negative Dot Products (Specular)
    if Nf_dot_H > thresh and Nb_dot_H > thresh:
        # Standard formulation
        Cs = Ks * (I00 + n_delta * (a0_s * I00 + a1_s * I10 + a2_s * I20 + a3_s * I30) - n_delta * I00)
    elif Nf_dot_L < 0 and Nb_dot_L < 0:
        # Highlight may exist between samples; use I00 approximation
        Cs = Ks * (I00 + n_delta * (a0_s * I00 + a1_s * I10 + a2_s * I20 + a3_s * I30) - n_delta * I00)
    else:
        # Fading approximation for threshold crossing
        I0 = sample_2d_table(T_I0, Sf, Sb)
        I1 = sample_2d_table(T_I1, Sf, Sb)
        Cs = Ks * (I0 * (1.0 - n_delta) + n_delta * Nb_dot_L * I1)

    return Cd, Cs
```

## Operating characteristics
*   **Time Complexity:** The method requires four texture accesses for the diffuse term and five for the specular term (including $I_{00}$) [S1]. It is 10% to 20% slower than linear gradient interpolation due to these additional texture accesses [S1].
*   **Memory Complexity:** Uses 2D lookup tables, keeping memory usage low compared to 3D tables (which would depend on $\alpha$) and allowing real-time updates during transfer function changes [S1]. Tables use 16-bit unsigned short representation [S1].
*   **Measured Performance:** On an Intel Core 2Quad Q9300 and Nvidia GeForce GTX 280 at 800x800 viewport: Reference (high sub-sampling) 5.1 fps; Constant gradient 56.3 fps; Linear gradient 51.2 fps; Non-linear gradient 47.19 fps [S1].
*   **Strengths:** Reduces maximal shading error to approximately 0.3% for a 90-degree angle between normals, compared to 41% error with linear interpolation (assuming $\eta(t)=1$) [S1]. Accurately depicts contours of specular highlights [S1].
*   **Limitations:** The quadratic curve interpolation is not exactly an arc of a circle, causing the normalization term to be potentially too low, resulting in vectors with norm > 1 and added energy around specular highlights [S1]. Mirroring gradients for negative values introduces approximation errors for slabs where one gradient is correctly oriented and the other is inverted [S1].

## Background
*   **Origin:** Proposed by Amel Guetat, Alexandre Ancel, Stephane Marchesin, and Jean-Michel Dischler in 2010 [S1].
*   **History:** Builds on pre-integrated volume rendering techniques (e.g., Lum et al.) which used linear gradient interpolation [S1]. This method addresses the luminous energy loss in high-frequency gradient variations and high-frequency shading functions (like specular highlights) inherent in linear interpolation [S1].
*   **Usage:** Used in direct volume rendering with Blinn-Phong illumination and non-photorealistic models like Gooch shading [S1].
