# Spatially Varying Kernel Filtering

Also called: Non-Stationary Filtering, Spatially Varying Convolution

## Overview
Spatially Varying Kernel Filtering is a technique where the reconstruction kernel or weighting function differs for each pixel, rather than being stationary as in standard convolution [S1, unofficial]. It solves the problem of applying spatially dependent blurring or smoothing (e.g., varying Point Spread Functions) which cannot be solved using standard convolution algorithms or FFT [S1, unofficial]. Unlike [Separable Convolution](14593-separable-convolution.md), which optimizes a single stationary kernel, this method requires per-pixel kernel evaluation [S1, unofficial].

## How it works
**Inputs:**
- Input image $\mathbf{L}$ of size $n \times n$ [S1, unofficial].
- A set of weighting functions $w_{\mathbf{x}'}(\mathbf{x}' - \mathbf{x})$ that define the contribution of neighbor $\mathbf{x}'$ to the target pixel $\mathbf{x}$ [S1, unofficial].

**Outputs:**
- Filtered image $\mathbf{L}'$ [S1, unofficial].

**Data Structures:**
- Kernel size is typically small (e.g., $m \times m$) to manage computational cost [S1, unofficial].
- Storage for weighting functions is Not given in the sources. [G]

**Steps:**
1. Iterate over each pixel $\mathbf{x}$ in the output image [G].
2. For each pixel $\mathbf{x}$, identify the neighborhood of source pixels $\mathbf{x}'$ [G].
3. Compute the weighted sum of the input image values using the specific weighting function for that location:
   $$ \mathbf{L}'(\mathbf{x}) = \sum_{\mathbf{x}'} w_{\mathbf{x}'}(\mathbf{x}' - \mathbf{x})\mathbf{L}(\mathbf{x}') $$
   where $w_{\mathbf{x}'}$ is the weight assigned to neighbor $\mathbf{x}'$ for target $\mathbf{x}$ [S1, unofficial].
4. Normalize the result if the kernel is not pre-normalized by summing the kernel values and multiplying the kernel by the reciprocal value to conserve energy [S1, unofficial].

**Pseudocode:**
```python
def spatially_varying_filter(L, get_weights):
    """
    L: Input image (n x n)
    get_weights: Function that returns a list of (dx, dy, weight) for a given center pixel
    """
    n = len(L)
    L_prime = [[0.0] * n for _ in range(n)]
    
    for x in range(n):
        for y in range(n):
            weights = get_weights(x, y)
            sum_val = 0.0
            sum_weights = 0.0
            
            for dx, dy, w in weights:
                nx, ny = x + dx, y + dy
                if 0 <= nx < n and 0 <= ny < n:
                    sum_val += w * L[nx][ny]
                    sum_weights += w
            
            if sum_weights != 0:
                L_prime[x][y] = sum_val / sum_weights
            else:
                L_prime[x][y] = 0.0
                
    return L_prime
```

**Edge Cases and Pitfalls:**
- **Normalization:** If the sum of weights is zero or near-zero, division by zero occurs; guard against this [G].
- **Boundary Conditions:** The neighborhood $\mathbf{x}'$ may fall outside the image bounds; explicit handling (e.g., clamping, mirroring, or ignoring out-of-bounds contributions) is required [G].
- **Complexity:** The naive implementation is $O(n^2 m^2)$, where $m$ is the kernel radius; FFT cannot be used [S1, unofficial].

## Subtopics

### Dynamic Adaptive Filtering (FAD)
A specific variant of spatially varying filtering that convolves in the neighborhood of the analyzed point (not just along a vector direction) to obtain a smooth result rich in local dynamic information [S2, unofficial]. It uses a local filtering kernel pattern rotated to the direction assumed by the vector field at each point [S2, unofficial]. Unlike Line Integral Convolution (LIC), which convolves along lines, FAD convolves spatially in the local environment [S2, unofficial]. Iterating FAD independently does not produce changes/improvements [S2, unofficial]. It can use reduced kernels (e.g., 3x3) for low computational cost [S2, unofficial]. Example asymmetric filter: $\begin{pmatrix} 1 & 1 & 1 \\ 0 & 0 & 0 \\ -1 & -1 & -1 \end{pmatrix}$ [S2, unofficial]. Example symmetric filter: $\begin{pmatrix} -1 & -1 & -1 \\ 2 & 3 & 2 \\ -1 & -1 & -1 \end{pmatrix}$ [S2, unofficial].

## Operating characteristics
- **Time Complexity:** Generally $O(n^2 m^2)$ for an image of size $n \times n$ and kernel size $m \times m$ [S1, unofficial]. It cannot be accelerated by FFT or standard convolution optimizations [S1, unofficial].
- **Memory Complexity:** Not given in the sources. [G]
- **Strengths:** Allows for spatially dependent effects like varying blur or directional emphasis based on local features [S1, unofficial][S2, unofficial].
- **Limitations:** High computational cost compared to stationary convolution; requires careful normalization [S1, unofficial].

## Background
Originated in the context of image processing and light transport simulation, specifically addressing the need to handle spatially varying Point Spread Functions (PSF) [S1, unofficial]. The term "Dynamic Adaptive Filtering" (FAD) was developed in the context of vector field visualization, combining texture convolution with local dynamic information [S2, unofficial].
