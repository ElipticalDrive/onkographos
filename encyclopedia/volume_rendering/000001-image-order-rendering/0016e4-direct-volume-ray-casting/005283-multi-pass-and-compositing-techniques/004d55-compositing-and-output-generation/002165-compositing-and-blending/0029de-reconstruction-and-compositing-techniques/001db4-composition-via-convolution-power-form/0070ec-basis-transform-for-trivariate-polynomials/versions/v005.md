# Basis Transform for Trivariate Polynomials

Also called: B-spline to Bernstein/Power Basis Transform

## Overview
This method transforms a trivariate polynomial representation from the B-spline basis (used in tri-linear or tri-cubic filtering) to either the scaled Bernstein basis or the power basis. This transformation enables efficient root finding and composition via a Horner scheme, avoiding the memory overhead of storing explicit polynomial descriptions for every voxel in large datasets [S1]. It sets itself apart from naive substitution by leveraging the tensor product structure of the basis to reduce computational complexity and register usage [S1].

## How it works
The method converts local voxel data, initially defined by surrounding data values in a B-spline basis, into a form suitable for efficient evaluation.

**Inputs:**
- Voxel data values (coefficients in B-spline basis).
- Polynomial degree $d$ (supported values: 0, 1, 2) [S2, unofficial].
- Evaluation point coordinates $(x, y, z)$ [S2, unofficial].

**Outputs:**
- Transformed coefficients in the target basis (scaled Bernstein or power basis) [S1].
- Evaluated polynomial value (when integrated with Horner scheme) [S1].

**Data Structures:**
- **Basis Vector ($b$):** A vector containing the monomial or Bernstein basis terms.
  - For degree 0: $b = [1]$ [S2, unofficial].
  - For degree 1: $b = [1, x, y, z]$ [S2, unofficial].
  - For degree 2: $b = [1, x, y, z, xy, xz, yz, x^2, y^2, z^2]$ [S2, unofficial].
- **Basis Matrix ($B$):** A matrix where each row corresponds to the basis vector of a specific point. Size is $P.rows() \times b.size()$ [S2, unofficial].

**Steps:**
1. **One-Dimensional Basis Transform:**
   The transformation from 1D B-spline basis to the target basis is a matrix multiplication of the basis vector with a $(d+1) \times (d+1)$ matrix [S1].
   - To **scaled Bernstein basis**: Requires 6 multiplications [S1].
   - To **power basis**: Requires 8 multiplications [S1].
   - Matrices are constructed to contain zeros and ones, scaled by a constant factor to minimize operations [S1].

2. **N-Dimensional Basis Transform Construction:**
   The N-dimensional basis is a tensor product of the 1D bases. The full transform is constructed from $N \cdot (d+1)^{N-1}$ one-dimensional basis transforms [S1]. For trivariate polynomials ($N=3$), this involves combining the 1D transforms across dimensions [S1].

3. **Integration with Horner Scheme:**
   The basis transform is integrated into a Horner scheme for composition. This separation of single dimensions allows for efficient on-the-fly transformation during rendering, avoiding the storage of explicit polynomial descriptions which would increase memory consumption by a factor of $(d+1)^3$ [S1].

### Basis Matrix Generation
This variant focuses on the construction of the basis matrix $B$ for a set of points.
- **Step 1:** Compute the basis vector size by calling `polynomial_basis_vector` with degree 2 on the first point $P(0)$ [S2, unofficial].
- **Step 2:** Initialize basis matrix $B$ of size $(P.rows(), bv.size())$ with zeros [S2, unofficial].
- **Step 3:** For each point $P(i)$, compute its basis vector $bv$ and assign it to row $i$ of $B$ [S2, unofficial].

## Operating characteristics
- **Time Complexity:** The 1D basis transform requires 6 multiplications for scaled Bernstein basis and 8 for power basis [S1]. The N-dimensional transform is constructed from $N \cdot (d+1)^{N-1}$ 1D transforms [S1].
- **Memory Complexity:** Avoids storing explicit polynomial descriptions, reducing memory consumption by a factor of $(d+1)^3$ compared to storing all polynomials explicitly [S1].
- **Performance:** Efficient for large datasets due to on-the-fly transformation and integration with Horner scheme [S1].
- **Strengths:** Reduces register usage and computation compared to naive substitution [S1].
- **Limitations:** Only supports degrees 0, 1, and 2 [S2, unofficial]. Exact matrix values for degrees 1 and 2 are not provided, requiring implementation details to be derived or inferred.

## Background
The method originates from wavelet-based multiresolution isosurface rendering, where B-spline polynomials are used for tri-linear and tri-cubic filtering [S1]. The transformation to Bernstein or power basis facilitates efficient root finding and composition in volume rendering contexts [S1].
