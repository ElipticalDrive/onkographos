# Training Ray Compositing (Sigma)

Also called: Ray Compositing for Training (Sigma + Ambient)

## Overview
Training Ray Compositing (Sigma) is a differentiable volume rendering technique that composites per-ray samples of density ($\sigma$), color ($\text{RGB}$), and ambient light into final pixel values while computing gradients for all inputs during the backward pass [S1, unofficial]. It differs from standard inference compositing by explicitly supporting gradient propagation to density and color parameters, enabling end-to-end training of neural radiance fields [S1, unofficial]. It builds on [Training Ray Compositing](3785-training-ray-compositing.md) by providing the specific implementation for training with sigma and ambient contributions.

## How it works
**Inputs and Outputs:**
The method takes pre-sampled ray data and produces composite image colors, accumulated alpha weights, and depth values, along with gradients for the inputs.

**Data Structures:**
The input tensors must be contiguous in memory. The layout is as follows [S1, unofficial]:
- `sigmas`: `float`, shape `[M,]`, volume density values for $M$ samples.
- `rgbs`: `float`, shape `[M, 3]`, view-dependent color values for $M$ samples.
- `ambient`: `float`, shape `[M,]`, ambient light contribution for $M$ samples.
- `deltas`: `float`, shape `[M, 2]`, step sizes (typically near and far distances or interval lengths) for $M$ samples.
- `rays`: `int32`, shape `[N, 3]`, ray indices or identifiers mapping samples to $N$ rays.

The output tensors are allocated as [S1, unofficial]:
- `weights_sum`: `float`, shape `[N,]`, output alpha channel (accumulated weight).
- `ambient_sum`: `float`, shape `[N,]`, output ambient contribution.
- `depth`: `float`, shape `[N,]`, output depth.
- `image`: `float`, shape `[N, 3]`, output RGB color.

**Parameters:**
- `T_thresh`: `float`, default $10^{-4}$. Transparency threshold. Rays with accumulated transparency below this value are considered fully opaque and can be skipped or terminated [S1, unofficial].

**Algorithm Steps:**
1.  **Preprocessing:** Ensure `sigmas`, `rgbs`, `ambient`, and `rays` are contiguous in memory [S1, unofficial].
2.  **Dimension Extraction:** Let $M$ be the number of samples (`sigmas.shape[0]`) and $N$ be the number of rays (`rays.shape[0]`) [S1, unofficial].
3.  **Output Allocation:** Allocate output tensors `weights_sum`, `ambient_sum`, `depth`, and `image` with the shapes defined above [S1, unofficial].
4.  **Forward Compositing:** Call the forward kernel `_backend.composite_rays_train_sigma_forward` with inputs `sigmas`, `rgbs`, `ambient`, `deltas`, `rays`, and `T_thresh` to compute the composite outputs [S1, unofficial].
5.  **Save for Backward:** Save `sigmas`, `rgbs`, `ambient`, `deltas`, `rays`, `weights_sum`, `ambient_sum`, `depth`, `image`, $M$, $N$, and `T_thresh` for use in the backward pass [S1, unofficial].
6.  **Backward Gradient Computation:**
    a.  Ensure gradient inputs `grad_weights_sum`, `grad_ambient_sum`, and `grad_image` are contiguous [S1, unofficial].
    b.  Retrieve saved tensors and dimensions [S1, unofficial].
    c.  Initialize gradient tensors `grad_sigmas`, `grad_rgbs`, and `grad_ambient` with zeros [S1, unofficial].
    d.  Call the backward kernel `_backend.composite_rays_train_sigma_backward` to compute gradients for `sigmas`, `rgbs`, and `ambient` based on the saved forward state and gradient inputs [S1, unofficial].
    e.  Call the CUDA backend kernel `_backend.composite_rays_ambient_sigma` to handle ambient light gradient propagation [S1, unofficial].

**Pseudocode:**
```python
import torch
import torch.nn.functional as F

def composite_rays_train_sigma_forward(sigmas, rgbs, ambient, deltas, rays, t_thresh=1e-4):
    """
    Forward pass for training ray compositing with sigma and ambient.
    
    Args:
        sigmas: [M] float, volume density
        rgbs: [M, 3] float, view-dependent color
        ambient: [M] float, ambient light
        deltas: [M, 2] float, step sizes (near, far)
        rays: [N, 3] int32, ray indices
        t_thresh: float, transparency threshold
        
    Returns:
        weights_sum: [N] float, accumulated alpha
        ambient_sum: [N] float, accumulated ambient
        depth: [N] float, accumulated depth
        image: [N, 3] float, composite RGB
    """
    # Ensure contiguous
    sigmas = sigmas.contiguous()
    rgbs = rgbs.contiguous()
    ambient = ambient.contiguous()
    deltas = deltas.contiguous()
    rays = rays.contiguous()
    
    M = sigmas.shape[0]
    N = rays.shape[0]
    
    # Allocate outputs
    weights_sum = torch.zeros(N, dtype=sigmas.dtype, device=sigmas.device)
    ambient_sum = torch.zeros(N, dtype=sigmas.dtype, device=sigmas.device)
    depth = torch.zeros(N, dtype=sigmas.dtype, device=sigmas.device)
    image = torch.zeros(N, 3, dtype=sigmas.dtype, device=sigmas.device)
    
    # Call CUDA kernel
    # _backend.composite_rays_train_sigma_forward(
    #     sigmas, rgbs, ambient, deltas, rays, 
    #     weights_sum, ambient_sum, depth, image, t_thresh
    # )
    # Note: The actual CUDA implementation handles the ray marching and compositing logic.
    # The logic approximates:
    # T_i = exp(-sum_{j=0}^{i-1} sigma_j * delta_j)
    # w_i = T_i * (1 - exp(-sigma_i * delta_i))
    # image = sum(w_i * rgb_i)
    # depth = sum(w_i * depth_i)
    # weights_sum = sum(w_i)
    # ambient_sum = sum(w_i * ambient_i)
    
    return weights_sum, ambient_sum, depth, image

class CompositeRaysTrainSigma(torch.autograd.Function):
    @staticmethod
    def forward(ctx, sigmas, rgbs, ambient, deltas, rays, t_thresh=1e-4):
        weights_sum, ambient_sum, depth, image = composite_rays_train_sigma_forward(
            sigmas, rgbs, ambient, deltas, rays, t_thresh
        )
        ctx.save_for_backward(sigmas, rgbs, ambient, deltas, rays, weights_sum, ambient_sum, depth, image)
        ctx.t_thresh = t_thresh
        return weights_sum, ambient_sum, depth, image

    @staticmethod
    def backward(ctx, grad_weights_sum, grad_ambient_sum, grad_depth, grad_image):
        sigmas, rgbs, ambient, deltas, rays, weights_sum, ambient_sum, depth, image = ctx.saved_tensors
        t_thresh = ctx.t_thresh
        
        # Ensure gradients are contiguous
        grad_weights_sum = grad_weights_sum.contiguous()
        grad_ambient_sum = grad_ambient_sum.contiguous()
        grad_image = grad_image.contiguous()
        
        # Initialize gradients
        grad_sigmas = torch.zeros_like(sigmas)
        grad_rgbs = torch.zeros_like(rgbs)
        grad_ambient = torch.zeros_like(ambient)
        
        # Call backward kernel
        # _backend.composite_rays_train_sigma_backward(
        #     grad_weights_sum, grad_ambient_sum, grad_image,
        #     sigmas, rgbs, ambient, deltas, rays,
        #     grad_sigmas, grad_rgbs, grad_ambient
        # )
        # Note: The actual CUDA implementation computes the chain rule gradients.
        # Gradients for depth are not propagated to sigmas [S1, unofficial].
        
        return grad_sigmas, grad_rgbs, grad_ambient, None, None, None

def composite_rays_train_sigma(sigmas, rgbs, ambient, deltas, rays, t_thresh=1e-4):
    return CompositeRaysTrainSigma.apply(sigmas, rgbs, ambient, deltas, rays, t_thresh)
```

**Edge Cases and Pitfalls:**
- The gradient for depth is not propagated to `sigmas` [S1, unofficial].
- Input tensors must be contiguous; non-contiguous tensors will cause errors in the CUDA kernel [S1, unofficial].

## Subtopics

### [Training Ray Compositing (Backward)](3893-training-ray-compositing-backward.md)
Computes gradients of the volume rendering loss with respect to density and color parameters during the backward pass. It is the backward counterpart to this method.

### [Ray Compositing for Training (Uncertainty)](3909-ray-compositing-for-training-uncertainty.md)
Extends this method by estimating and backpropagating uncertainty alongside standard outputs.

### [Gradient Scaling by Distance Squared](8937-gradient-scaling-by-distance-squared.md)
A technique used during backpropagation to improve training stability for distant objects by scaling gradients based on squared distance.

### Ray Compositing for Training (Triplane/Aud/Eye)
Composites rays for training with triplane-based ambient lighting (auditory and eye-specific), computing gradients for sigmas, RGBs, and various ambient components [S1, unofficial]. It ensures `amb_aud`, `amb_eye`, and `uncertainty` are contiguous, allocates sums for these components, and calls `_backend.composite_rays_train_triplane_forward` [S1, unofficial]. The transparency threshold `T_thresh` defaults to $10^{-4}$ [S1, unofficial]. The gradient for depth is not propagated to sigmas [S1, unofficial].

### CUDA Ray Compositing
A GPU-accelerated kernel that performs alpha compositing of pre-sampled RGB and sigma values along rays to produce final image and depth [S2, unofficial]. It iterates through samples for each alive ray, accumulating transparency and computing weighted RGB and depth contributions [S2, unofficial]. Inputs are `sigmas` `[n_alive * n_step]`, `rgbs` `[n_alive * n_step, 3]`, and `deltas` `[n_alive * n_step, 2]`. Outputs `weights_sum`, `depth`, and `image` are in-place [S2, unofficial]. The transparency threshold `T_thresh` determines when rays are considered fully opaque [S2, unofficial].

## Operating characteristics
- **Time Complexity:** Linear with respect to the number of samples $M$ and rays $N$, as each sample is processed once in the forward and backward passes.
- **Memory Complexity:** Linear with respect to $M$ and $N$ for storing inputs, outputs, and saved tensors for the backward pass.
- **Performance:** Implemented as a CUDA kernel for high performance on GPU hardware [S1, unofficial][S2, unofficial].
- **Strengths:** Differentiable, allowing end-to-end training of neural radiance fields with ambient light contributions [S1, unofficial].
- **Limitations:** Requires contiguous memory layout for inputs [S1, unofficial]. Gradient for depth is not propagated to sigmas, which may limit certain optimization scenarios [S1, unofficial].

## Background
Training Ray Compositing (Sigma) is part of the ER-NeRF framework, which integrates neural radiance fields with audio and visual cues for training [S1, unofficial]. It is used in applications requiring differentiable volume rendering with ambient light modeling, such as neural head avatars [S1, unofficial]. The method is implemented in the ER-NeRF repository [S1, unofficial].
