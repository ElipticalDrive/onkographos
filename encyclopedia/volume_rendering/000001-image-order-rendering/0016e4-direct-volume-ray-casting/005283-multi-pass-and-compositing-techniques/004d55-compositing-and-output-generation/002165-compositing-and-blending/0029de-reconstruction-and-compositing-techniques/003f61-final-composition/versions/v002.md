# Final Composition

Also called: Density-dependent interpolation, Segment compositing, Volume imaging, Volumetric Compositing

## Overview
Final Composition builds on [Reconstruction and Compositing Techniques](4646-reconstruction-and-compositing-techniques.md) by integrating information from the entire volume into a rendered image using lighting to depict surfaces, rather than performing exact boundary determination [S1, unofficial]. It distinguishes itself from segmentation-based approaches by allowing intermediate voxel values to define regions, making it suitable for visualizing structures where precise edges are ambiguous [S1, unofficial]. It is primarily used in medical imaging, such as SPECT, to portray organ surfaces while being heavily dependent on chosen intensity ranges [S1, unofficial].

## How it works
**Inputs and Outputs:**
*   **Input:** A 3D volume dataset (voxel intensities), a set of intensity ranges defining specific organs or regions, and lighting parameters [S1, unofficial].
*   **Output:** A 2D rendered image where organ surfaces are depicted via integration and lighting [S1, unofficial].

**Data Structures:**
*   **Volume:** 3D array of voxel intensities.
*   **Transfer Function:** Maps intensity ranges to optical properties (opacity $\alpha$, color $c$), allowing intermediate values between defined regions rather than binary thresholds [S1, unofficial].

**Steps:**
1.  **Define Intensity Ranges:** Select ranges to define organs or regions, allowing intermediate values rather than strict segmentation [S1, unofficial].
2.  **Sample the Ray:** For each pixel, cast a ray through the volume [G].
3.  **Evaluate Optical Properties:** For each sample point along the ray, determine opacity $\alpha_i$ and color $c_i$ based on the voxel value and the defined intensity ranges [S1, unofficial].
4.  **Integrate with Lighting:** Integrate the volume along the ray using lighting information to depict surfaces [S1, unofficial]. The standard front-to-back compositing equation updates the accumulated color and opacity:
    $$C_{acc}^{(i)} = C_{acc}^{(i-1)} + (1 - \alpha_{acc}^{(i-1)}) \alpha_i C_i$$
    $$\alpha_{acc}^{(i)} = \alpha_{acc}^{(i-1)} + (1 - \alpha_{acc}^{(i-1)}) \alpha_i$$
    where $C_{acc}^{(0)} = 0$ and $\alpha_{acc}^{(0)} = 0$ [G].
5.  **Composite:** Accumulate the lit samples from front to back [G].
6.  **Background Composite:** Composite the final accumulated color over a background color $C_{bg}$:
    $$C_{final} = C_{acc} + (1 - \alpha_{acc}) C_{bg}$$ [G].
7.  **Density-Dependent Interpolation:** For implementations using convolution solutions, voxel segments are composited using either a low-density convolution solution weighted by optical depth, a high-density diffusion solution, or a density-dependent interpolation of the two to eliminate aliasing artifacts [S2, unofficial].

**Parameters:**
*   **Intensity Ranges:** User-defined or automatically selected thresholds that define the organs [S1, unofficial].

**Edge Cases and Pitfalls:**
*   **Intensity Range Dependence:** The method is heavily dependent on the chosen intensity ranges [S1, unofficial].
*   **Surface-Only Portrayal:** Only organ surfaces are portrayed, not the interior [S1, unofficial].
*   **Aliasing:** Abrupt switches between low-density and high-density solutions can cause aliasing artifacts, which are mitigated by density-dependent interpolation [S2, unofficial].

**Pseudocode:**
```python
def final_composition(volume, ray_origin, ray_direction, transfer_function, lighting_model, background_color):
    # Initialize accumulators
    acc_color = [0.0, 0.0, 0.0]
    acc_alpha = 0.0
    transmittance = 1.0
    t = 0.0
    step_size = 1.0  # Not given in the sources.

    # Sample along ray
    while t < volume.max_depth and transmittance > 1e-4:
        pos = ray_origin + ray_direction * t
        voxel_val = volume.sample(pos)
        alpha, color = transfer_function(voxel_val)
        lit_color = lighting_model(color, pos)

        # Front-to-back compositing with lighting
        contribution = lit_color * alpha * transmittance
        acc_color += contribution
        acc_alpha += alpha * transmittance
        transmittance *= (1.0 - alpha)

        t += step_size

    # Composite over background
    final_color = acc_color + transmittance * background_color
    return final_color
```

## Operating characteristics
*   **Strengths:** Incorporates information from the entire volume, avoiding the need for exact segmentation [S1, unofficial]. Effective for depicting organ surfaces in medical imaging, such as SPECT [S1, unofficial].
*   **Limitations:** Heavily dependent on user-selected intensity ranges [S1, unofficial]. Does not portray interior details, only surfaces [S1, unofficial].
*   **Performance:** Not explicitly quantified in the provided sources [S1, unofficial]. Standard ray casting complexity applies, with additional cost for lighting calculations [G].

## Background
Final Composition, also referred to as Volume Imaging or Volumetric Compositing, was developed as an alternative to methods that require exact boundary determination or segmentation [S1, unofficial]. It is particularly noted in the context of three-dimensional display of SPECT images [S1, unofficial]. The method allows for the integration of the entire volume's information, using lighting to enhance surface perception [S1, unofficial].
