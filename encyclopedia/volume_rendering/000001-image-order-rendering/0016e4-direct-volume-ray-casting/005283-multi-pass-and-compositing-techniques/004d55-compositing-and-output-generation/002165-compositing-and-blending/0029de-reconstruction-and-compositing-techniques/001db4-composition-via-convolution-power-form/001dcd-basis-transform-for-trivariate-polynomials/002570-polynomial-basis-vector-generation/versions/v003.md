# Polynomial Basis Vector Generation


## Overview
Polynomial Basis Vector Generation constructs the explicit monomial basis vector for a given spatial point and polynomial degree [S1, unofficial]. It serves as the foundational step for [Basis Transform for Trivariate Polynomials](1609-basis-transform-for-trivariate-polynomials.md), enabling the conversion of B-spline coefficients into a form suitable for efficient root finding and volume compositing [S1, unofficial]. Unlike methods that store full polynomial descriptions, this method generates the basis vector on-the-fly, avoiding the memory overhead of storing every single polynomial's coefficients explicitly [S1, unofficial]. It is distinct from the Basis Matrix Generation variant, which aggregates these vectors into a matrix structure for batch processing [S1, unofficial].

## How it works
**Inputs:**
- `degree`: Integer specifying the polynomial degree. Supported values are 0, 1, and 2 [S1, unofficial].
- `point`: A spatial coordinate $(x, y, z)$ [S1, unofficial].

**Outputs:**
- `b`: A vector containing the monomial basis elements [S1, unofficial].

**Data Structures:**
- The basis vector `b` is a dynamic array of floating-point numbers [G].
- For degree $d$, the size of `b` corresponds exactly to the number of unique monomials specified for that degree [S1, unofficial].

**Steps:**
1. Check the `degree`.
2. If `degree` is 0: Initialize `b` with a single element: $[1]$ [S1, unofficial].
3. If `degree` is 1: Initialize `b` with 4 elements: $[1, x, y, z]$ [S1, unofficial].
4. If `degree` is 2: Initialize `b` with 10 elements: $[1, x, y, z, x \cdot y, x \cdot z, y \cdot z, x^2, y^2, z^2]$ [S1, unofficial].
5. Return `b` [S1, unofficial].

**Pseudocode:**
```python
def polynomial_basis_vector(degree, x, y, z):
    """
    Generates the polynomial basis vector for a given degree and point (x,y,z).
    Based on [S1, unofficial].
    """
    if degree == 0:
        return [1.0]
    elif degree == 1:
        return [1.0, x, y, z]
    elif degree == 2:
        return [1.0, x, y, z, x * y, x * z, y * z, x * x, y * y, z * z]
    else:
        # Not given in the sources.
        raise ValueError("Degree must be 0, 1, or 2")
```

**Parameters:**
- `degree`: 0, 1, or 2 [S1, unofficial].

**Edge Cases and Pitfalls:**
- Degrees higher than 2 are not supported in the provided source [S1, unofficial].

## Subtopics

### Basis Matrix Generation
This variant aggregates individual basis vectors into a matrix [S1, unofficial]. It computes the basis vector size by calling `polynomial_basis_vector` with degree 2 on the first point $P(0)$ [S1, unofficial]. It initializes a basis matrix $B$ of size $(P.\text{rows}(), bv.\text{size}())$ with zeros [S1, unofficial]. For each point $P(i)$, it computes its basis vector $bv$ and assigns it to row $i$ of $B$ [S1, unofficial]. Note: The source implementation computes the basis vector size based on the first point but the content of the vector depends on the degree [S1, unofficial].
