# Composition via Convolution (Power Form)

Also called: Power Form

## Overview
Composition via Convolution (Power Form) evaluates the composition of a trivariate polynomial field with a linear ray parameterization, transforming the 3D function into a univariate polynomial along the ray [S1]. It solves the problem of high computational cost and register pressure associated with naive polynomial substitution, enabling efficient implementation on GPU architectures [S1]. Unlike [Composition via Scaled Bernstein Form](1592-composition-via-scaled-bernstein-form.md), which maintains a uniform data representation for better numerical stability and root-finding compatibility, the Power Form uses power bases and convolution operators to minimize operation counts and register usage, offering superior performance for direct evaluation [S1].

## How it works
The method computes the coefficients of the resulting univariate polynomial $f(t)$ by leveraging the associative property of convolution to reduce the number of multiplications and additions required [S1].

**Inputs and Outputs:**
- Input: Trivariate polynomial coefficients $f_{ijk}$ for $i,j,k \in \{0, \dots, d\}$, where $d$ is the degree of the basis functions [S1].
- Input: Ray parameterization coefficients for the x, y, and z components: $\mathbf{r}_x = [p_x, v_x]$, $\mathbf{r}_y = [p_y, v_y]$, $\mathbf{r}_z = [p_z, v_z]$ [S1].
- Output: Coefficient sequence $\mathbf{f}$ of the resulting univariate polynomial of degree $3d$ [S1].

**Data Structures:**
- Coefficients are stored as floating-point arrays or sequences [S1].
- Intermediate power expressions $\mathbf{r}_x^i$, $\mathbf{r}_y^j$, $\mathbf{r}_z^k$ are computed incrementally [S1].

**Numbered Steps:**
1. **Initialize Power Sequences:** Compute the power expressions for the ray components incrementally using convolution [S1]. For the x-component: $\mathbf{r}_x^0 = [1]$ and $\mathbf{r}_x^i = \mathbf{r}_x^{i-1} * \mathbf{r}_x$ for $i = 1, \dots, d$ [S1]. Repeat for $\mathbf{r}_y$ and $\mathbf{r}_z$ [S1]. The convolution $*$ of two coefficient sequences $A$ and $B$ results in a sequence $C$ where $C_k = \sum_{m=0}^k A_m B_{k-m}$ [S1]. This step is equivalent to the Horner scheme for polynomial evaluation [S1].
2. **Compute Inner Sum ($\mathbf{f}_{ij}$):** For each pair $(i, j)$, compute the intermediate polynomial coefficients $\mathbf{f}_{ij}$ by convolving the trivariate coefficients with the z-component powers: $\mathbf{f}_{ij} = \sum_{k=0}^d f_{ijk} \cdot \mathbf{r}_z^k$ [S1]. Here, $f_{ijk} \cdot \mathbf{r}_z^k$ denotes scalar multiplication of the coefficient sequence $\mathbf{r}_z^k$ by $f_{ijk}$ [S1].
3. **Compute Middle Sum:** For each $i$, compute the sum over $j$: $\mathbf{g}_i = \sum_{j=0}^d \mathbf{r}_y^j * \mathbf{f}_{ij}$ [S1]. Note that $\mathbf{f}_{ij}$ is computed and consumed immediately, allowing memory reuse [S1].
4. **Compute Final Sum:** Compute the final coefficient sequence $\mathbf{f}$ by summing over $i$: $\mathbf{f} = \sum_{i=0}^d \mathbf{r}_x^i * \mathbf{g}_i$ [S1].

**Formulas:**
The core composition formula is:
$$ \mathbf{f} = \sum_{i=0}^d \mathbf{r}_x^i * \sum_{j=0}^d \mathbf{r}_y^j * \underbrace{\sum_{k=0}^d f_{ijk} \cdot \mathbf{r}_z^k}_{\mathbf{f}_{ij}} $$
Where $\mathbf{r}_x = [p_x, v_x]$ is the coefficient sequence of the x-component of the ray [S1].

**Parameters:**
- $d$: Degree of the polynomial basis. Typical value is 3 (cubic) [S1].

**Edge Cases and Pitfalls:**
- **Register Pressure:** A naive implementation requires too many operations and registers to fit into a GPU framework (e.g., 135 registers for $d=3$) [S1]. The convolution structure ensures that no more than one factor $f_{ij}$ and $f_i$ needs to be available at the same time, allowing memory reuse and reducing register usage to 27 for $d=3$ [S1].
- **Precision:** The Power Form yields a higher Mean Squared Error (MSE) than Scaled Bernstein forms but executes significantly faster [S1].

**Pseudocode:**
```python
def convolution(seq_a, seq_b):
    len_a, len_b = len(seq_a), len(seq_b)
    res = [0.0] * (len_a + len_b - 1)
    for i in range(len_a):
        for j in range(len_b):
            res[i + j] += seq_a[i] * seq_b[j]
    return res

def composition_via_convolution_power_form(f_coeffs, ray_coeffs):
    d = len(ray_coeffs[0]) - 1
    r_x, r_y, r_z = [[1.0]], [[1.0]], [[1.0]]
    for i in range(1, d + 1):
        r_x.append(convolution(r_x[i-1], ray_coeffs[0]))
        r_y.append(convolution(r_y[i-1], ray_coeffs[1]))
        r_z.append(convolution(r_z[i-1], ray_coeffs[2]))

    final_f = [0.0] * (3 * d + 1)
    for i in range(d + 1):
        g_i = [0.0] * (2 * d + 1)
        for j in range(d + 1):
            f_ij = [0.0] * (d + 1)
            for k in range(d + 1):
                term = [c * f_coeffs[i][j][k] for c in r_z[k]]
                for m in range(len(term)):
                    f_ij[m] += term[m]
            conv_res = convolution(r_y[j], f_ij)
            for m in range(len(conv_res)):
                g_i[m] += conv_res[m]
        conv_res_final = convolution(r_x[i], g_i)
        for m in range(len(conv_res_final)):
            final_f[m] += conv_res_final[m]
    return final_f
```

## Subtopics

### [Composition via Scaled Bernstein Form](1592-composition-via-scaled-bernstein-form.md)
Evaluates composition using scaled Bernstein basis for better numerical stability and uniform data representation, avoiding basis conversion for root finding.

### [Basis Transform for Trivariate Polynomials](1609-basis-transform-for-trivariate-polynomials.md)
Transforms trivariate polynomials from B-spline to scaled Bernstein or power basis to enable efficient root finding and compositing.

## Operating characteristics
- **Time Complexity:** The Power Form method requires significantly fewer operations than the naive approach [S1]. For $d=3$, it uses 234 multiplications and 360 additions, compared to 1839 multiplications and 990 additions for the naive method [S1].
- **Memory Complexity:** The convolution structure reduces register usage from 135 registers (naive) to 27 registers (PF), allowing it to fit into GPU register space [S1].
- **Performance:** In relative terms, the PF method is approximately 278 times faster than the naive method (relative time $3.6 \times 10^{-3}$ vs 1) [S1].
- **Accuracy:** The Mean Squared Error (MSE) for PF is $22.6 \times 10^{-12}$, which is higher than the Scaled Bernstein forms (e.g., SB2 has MSE $4.78 \times 10^{-12}$) but lower than the naive method ($162.3 \times 10^{-12}$) [S1].
- **Strengths:** High performance due to low operation count and register usage; suitable for GPU implementation [S1].
- **Limitations:** Lower numerical stability compared to Bernstein forms; not suitable if root finding is required without basis conversion [S1].

## Background
The method originates from research on efficient polynomial evaluation along rays for volume rendering [S1]. It builds on the use of convolution operators for polynomial composition to optimize computation for GPU frameworks [S1].
