# Data Value Zoom

Also called: Domain Zoom, Intensity domain scaling, Scalar Range Zoom

## Overview
Data Value Zoom is a technique for exploring narrow regions of scalar data values by dynamically adjusting the mapping of floating-point data values to the integer indices required by graphics hardware [S2, unofficial][S3, unofficial]. It acts as a zoom function in the data domain, rescaling the intensity range so that the colour map's minimum and maximum match the selected interval, unlike intensity clipping which simply discards out-of-range values [S1].

## How it works
**Inputs and Outputs:**
*   **Input:** A scalar value $v$, `minThreshold`, `maxThreshold`, and `DATAMIN` [S1].
*   **Output:** A rescaled value $v'$ mapped to the interval $[0, 1]$, or `DATAMIN` if $v$ falls outside the threshold range [S1].

**Data Structures:**
The technique modifies the scalar-to-integer mapping function used by graphics hardware to index the transfer function or lookup table (LUT) [S2, unofficial][S3, unofficial]. Instead of a fixed global range, the mapping dynamically scales the active intensity domain so that the colour map's minimum and maximum correspond to the user-defined thresholds [S1].

**Steps:**
1. Calculate `discardRatio` as $1.0 / (\text{maxThreshold} - \text{minThreshold})$ [S1].
2. If $v > \text{maxThreshold}$, set $v \leftarrow \text{DATAMIN}$ [S1].
3. Else if $v < \text{minThreshold}$, set $v \leftarrow \text{DATAMIN}$ [S1].
4. Else, set $v \leftarrow v - \text{minThreshold}$ [S1].
5. Else, set $v \leftarrow v \times \text{discardRatio}$ [S1].
6. Return $v$ [S1].

**Formulas:**
The mapping function $M(v)$ is defined as:
$$
M(v) = \begin{cases}
\text{DATAMIN} & \text{if } v > \text{maxThreshold} \text{ or } v < \text{minThreshold} \\
(v - \text{minThreshold}) \times \frac{1}{\text{maxThreshold} - \text{minThreshold}} & \text{otherwise}
\end{cases}
$$
where $v$ is the input scalar value, `minThreshold` and `maxThreshold` define the active zoom interval, and `DATAMIN` is the lower bound of the data range used for out-of-bounds values [S1].

**Pseudocode:**
```python
def data_value_zoom(val, minThreshold, maxThreshold, DATAMIN):
    discardRatio = 1.0 / (maxThreshold - minThreshold)
    if val > maxThreshold:
        val = DATAMIN
    elif val < minThreshold:
        val = DATAMIN
    else:
        val = val - minThreshold
        val = val * discardRatio
    return val
```

**Parameters:**
*   `minThreshold`: Lower bound for scaling. Example value: $1.12\times10^{-2}$ Jy/beam [S1].
*   `maxThreshold`: Upper bound for scaling. Example value: $0.3609$ Jy/beam [S1].
*   `DATAMIN`: Lower bound of the data range, used to map out-of-bounds values [S1].

**Edge Cases and Pitfalls:**
*   **Division by Zero:** If `maxThreshold` equals `minThreshold`, the `discardRatio` calculation fails; a guard must ensure `maxThreshold > minThreshold` [G].
*   **Out-of-Bounds Handling:** Values outside the zoom range are mapped to `DATAMIN`, which must be correctly interpreted by the transfer function (e.g., mapped to transparent or background colour) to avoid rendering artifacts [S1].
*   **Quantization:** The rescaled float values are converted to integers for hardware indexing, which may introduce quantization artifacts if the zoom interval is extremely narrow relative to the LUT resolution [S2, unofficial][S3, unofficial].

## Operating characteristics
*   **Time Complexity:** $O(1)$ per sample during ray casting [S1].
*   **Memory Complexity:** Not given in the sources [S1].
*   **Strengths:** Provides a dynamic way to explore features within divergent data ranges without discarding values [S1].
*   **Limitations:** Does not improve spatial resolution; only adjusts the scalar-to-integer mapping for hardware rendering [S2, unofficial][S3, unofficial].
*   **When to use:** When exploring narrow regions of data values or adjusting intensity bounds for divergent ranges in techniques like Maximum Intensity Projection (MIP) [S1][S2, unofficial][S3, unofficial].
*   **When not to use:** Not given in the sources [S1].

## Background
Data Value Zoom, also referred to as Intensity domain scaling, was described for use in the Cave Automatic Virtual Environment (CAVE) to allow interactive exploration of narrow data regions by adjusting the floating-point to integer mapping required by graphics hardware [S2, unofficial][S3, unofficial]. The technique is implemented as a shader kernel that rescales intensity bounds for visualisation techniques such as Maximum Intensity Projection (MIP) and Adaptive Volume Image Projection (AVIP) [S1].
