# Inverse Deformation Texture
Also called: Inverse Free-Form Volumetric Deformation, Inverse Parameterization, Inverse Parameterization for Volumetric Deformation

## Overview
Inverse Deformation Texture is a technique used when forward free-form volumetric deformation is impossible to solve analytically or efficiently in real-time [S1, S2, unofficial]. It constructs a lattice grid around the deformed volume in world space and associates each lattice point with texture coordinates in a unit reference volume, allowing efficient evaluation of the deformation via trilinear interpolation in fragment shaders [S1, S2, unofficial]. It sets itself apart from forward deformation methods by avoiding the need to invert the deformation function at runtime, which is computationally prohibitive for infinite-detail volumes [S1, unofficial].

## How it works
**Inputs and Outputs:**
- Input: A deformed volume (e.g., fire) defined by a set of forces or a simulation in world space.
- Output: A 3D texture (Inverse Deformation Texture) that maps world-space positions to unit-volume texture coordinates.

**Data Structures:**
- **Lattice Grid:** A 3D regular grid defined in world space coordinates surrounding the deformed volume.
- **Inverse Deformation Texture:** A 3D texture where each texel stores the texture coordinates $(u, v, w)$ in the unit reference volume corresponding to the world-space position of the lattice point.

**Steps:**
1. **Construct Lattice:** Build a lattice grid around the deformed volume in world space coordinates [S1, S2, unofficial].
2. **Associate Coordinates:** For each point in the lattice, determine its corresponding texture coordinates in the unit fire volume [S1, S2, unofficial]. This effectively pre-computes the inverse mapping from world space to the reference parameter space.
3. **Interpolate:** Use a 3D shader flame texture (the reference volume) to implicitly interpolate all points of the fire surfaces by sampling the Inverse Deformation Texture at the fragment's world-space position [S1, S2, unofficial].

**Pseudocode:**
```python
# Pre-computation phase (offline or setup)
def build_inverse_deformation_texture(lattice_points, reference_volume_map):
    """
    lattice_points: List of 3D world-space coordinates forming the lattice grid.
    reference_volume_map: Function or data structure mapping world-space coordinates 
                          to texture coordinates in the unit volume.
    Returns: A 3D texture where each texel corresponds to a lattice point.
    """
    texture = create_3d_texture(size=lattice_grid_dimensions)
    for i, world_pos in enumerate(lattice_points):
        # Get the corresponding texture coordinates in the unit volume
        # This step assumes the inverse mapping is known or pre-computed
        tex_coords = reference_volume_map(world_pos)
        texture.set_texel(i, tex_coords)
    return texture

# Runtime phase (fragment shader)
def render_fragment(world_position, inverse_deformation_texture, flame_texture):
    """
    world_position: The world-space position of the current fragment.
    inverse_deformation_texture: The pre-computed 3D texture.
    flame_texture: The 3D shader flame texture in the unit volume.
    Returns: The color of the fragment.
    """
    # Find the lattice point closest to world_position
    # In practice, this involves finding the voxel in the lattice grid
    lattice_index = find_lattice_index(world_position, inverse_deformation_texture)
    
    # Sample the inverse deformation texture to get texture coordinates
    # Trilinear interpolation is used for smoothness
    tex_coords = inverse_deformation_texture.sample(lattice_index)
    
    # Sample the flame texture using the obtained texture coordinates
    color = flame_texture.sample(tex_coords)
    return color
```

**Parameters:**
- Lattice resolution: Not given in the sources.
- Reference volume size: Unit volume (1x1x1).

**Edge Cases and Pitfalls:**
- Forward deformation cannot be solved analytically [S1, unofficial].
- Numerical solutions for forward deformation require significant computation and exhibit robustness problems [S1, unofficial].
- Real-time deformation of the entire infinite-detail volume is impossible [S1, unofficial].

## Operating characteristics
- **Time Complexity:** Depends on the lattice resolution and the cost of finding the nearest lattice point. Trilinear interpolation is constant time.
- **Memory Complexity:** Proportional to the number of lattice points.
- **Strengths:** Avoids real-time inversion of complex deformation functions. Efficient evaluation in fragment shaders.
- **Limitations:** Requires pre-computation or setup. Accuracy depends on lattice resolution.

## Background
Origin: Developed by Y. Vanzine for real-time volumetric rendering of fire in production systems [S1, S2, unofficial]. The method is based on the lattice method described in [13] (referenced in [S1, unofficial]) and [9] (referenced in [S2, unofficial]).
