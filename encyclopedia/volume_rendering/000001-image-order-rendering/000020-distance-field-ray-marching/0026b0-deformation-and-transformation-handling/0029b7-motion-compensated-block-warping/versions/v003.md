# Motion-Compensated Block Warping

Also called: Inter-frame motion compensation

## Overview
Motion-Compensated Block Warping is a technique for compressing dynamic Truncated Signed Distance Fields (TSDF) by predicting the current frame's geometry from the previous frame using estimated rigid body motion [S1]. It improves prediction accuracy over static methods by inverse-warping voxel samples from the target block into the previously reconstructed TSDF and resampling them via trilinear interpolation [S1]. Unlike global transformation methods, this approach operates on local blocks, allowing for piecewise-rigid motion estimation which is essential for complex, non-uniform scene dynamics [S1].

## How it works
The method consists of two main phases: motion estimation to determine the rigid transform between frames, and motion compensation to generate the predictor for residual coding.

**Inputs and Outputs:**
*   **Inputs:** Current frame TSDF block $s_t^{(b)}$, previous frame reconstructed TSDF block $\hat{s}_{t-1}^{(b)}$, and the spatial neighborhood structure.
*   **Outputs:** A motion-compensated predictor block and the 6-DoF rigid transform parameters $(\mathbf{r}, \mathbf{t})$ encoded as side information.

**Data Structures:**
*   **TSDF Block:** A 3D grid of voxel values.
*   **Motion Parameters:** A translation vector $\mathbf{t} \in \mathbb{R}^3$ and an Euler-angle rotation vector $\mathbf{r} \in \mathbb{R}^3$.
*   **Neighborhood:** A stitched $3 \times 3 \times 3$ array of blocks surrounding the target block to support interpolation across boundaries.

**Algorithm Steps:**

1.  **Motion Estimation:** Estimate the rigid transform $(\mathbf{r}, \mathbf{t})$ that aligns the previous frame's geometry to the current frame. This is done by minimizing the squared residuals between the warped previous samples and the current samples [S1].
2.  **Inverse Warping:** For each voxel center position $\mathbf{p}_i$ in the target block $b$ at frame $t$, apply the inverse of the estimated rigid transform $\mathbf{T}^{-1}(\cdot; \mathbf{r}, \mathbf{t})$ to map $\mathbf{p}_i$ into the coordinate space of the previous frame [S1].
3.  **Resampling:** Evaluate the TSDF value at the warped location using trilinear interpolation over the stitched $3 \times 3 \times 3$ neighborhood from the previous frame $\hat{s}_{t-1}^{(b)}$ [S1]. This handles fractional positions and boundary crossings.
4.  **Residual Coding:** Compute the difference between the current frame's TSDF values and the interpolated predictor. Encode these residual coefficients (e.g., using DCT) [S1].
5.  **Side Information Encoding:** Encode the 6-DoF transform $(\mathbf{r}, \mathbf{t})$ for each block. The decoder applies the same inverse warp to reconstruct the identical predictor before decoding residuals [S1].

**Formulas:**

The residual for a sample $i$ is defined as [S1]:
$$ \epsilon_i(\mathbf{r}, \mathbf{t}) = \hat{s}_{t-1}^{(b)}(\mathbf{T}(\mathbf{p}_i; \mathbf{r}, \mathbf{t})) - s_t^{(b)}(\mathbf{p}_i) $$
where $\mathbf{T}(\cdot; \mathbf{r}, \mathbf{t})$ is the rigid transform parameterized by rotation $\mathbf{r}$ and translation $\mathbf{t}$, and $\hat{s}_{t-1}^{(b)}$ is the trilinearly interpolated TSDF from the previous frame.

The optimal transform is found by minimizing the sum of squared residuals [S1]:
$$ \mathbf{t}, \mathbf{r} := \arg \min_{\mathbf{t}, \mathbf{r}} \sum_{i \in \Omega} \epsilon_i(\mathbf{r}, \mathbf{t})^2 $$
where $\Omega$ is the set of sample positions within the block.

The update step in the damped Gauss-Newton optimization is [S1]:
$$ \Delta \mathbf{p} = -(J^\top J + \lambda I)^{-1} J^\top \boldsymbol{\varepsilon} $$
where $J$ is the Jacobian of the residuals with respect to the parameters, $\boldsymbol{\varepsilon}$ is the vector of residuals, and $\lambda$ is a damping factor for numerical stability.

**Pseudocode:**

```python
def motion_compensated_block_warping(current_block, prev_block_reconstructed, neighborhood_blocks):
    """
    Generates a motion-compensated predictor for a TSDF block.
    
    Args:
        current_block: TSDF values for the current frame block b at time t.
        prev_block_reconstructed: Reconstructed TSDF values for block b at time t-1.
        neighborhood_blocks: Stitched 3x3x3 array of blocks surrounding b in t-1.
        
    Returns:
        predictor: Interpolated TSDF values for the current block.
        transform: Estimated 6-DoF rigid transform (r, t).
    """
    
    # 1. Motion Estimation
    # Initialize transform to zero motion
    r = [0.0, 0.0, 0.0] # Euler angles
    t = [0.0, 0.0, 0.0] # Translation
    
    # Define sample positions p_i for the current block
    sample_positions = get_voxel_centers(current_block)
    
    # Minimize squared residuals using damped Gauss-Newton
    # Objective: sum( (interp(prev_block, T(p_i; r, t)) - current_block(p_i))^2 )
    converged = False
    while not converged:
        # Calculate residuals epsilon_i(r, t)
        residuals = []
        for p_i in sample_positions:
            # Apply rigid transform T to p_i
            warped_pos = apply_rigid_transform(p_i, r, t)
            # Trilinear interpolation over the 3x3x3 neighborhood
            # This handles fractional positions and block boundaries
            val = trilinear_interpolate(warped_pos, neighborhood_blocks)
            residuals.append(val - current_block.get_value(p_i))
        
        # Check convergence: if objective decrease is below threshold, stop
        if check_convergence(residuals):
            converged = True
            break
            
        # Compute Jacobian J approximately via finite difference
        J = compute_jacobian_finite_difference(sample_positions, r, t, neighborhood_blocks, current_block)
        
        # Solve for update step Delta p
        # Delta p = -(J^T J + lambda I)^-1 J^T epsilon
        epsilon = vector(residuals)
        lambda_damp = 1e-4 # Small damping factor
        update = solve_linear_system(-(J.T @ J + lambda_damp * identity_matrix(6)), J.T @ epsilon)
        
        # Update parameters
        r_new, t_new = update_rotation_translation(r, t, update)
        
        # Clamp updates to prevent divergence
        # Translation magnitude clamped to 1 voxel
        # Rotation magnitude clamped to 5 degrees
        r, t = clamp_updates(r_new, t_new, max_trans=1.0, max_rot_deg=5.0)
        
    # 2. Motion Compensation (Prediction)
    predictor = []
    for p_i in sample_positions:
        # Inverse warp: map current position to previous frame coordinates
        # Note: The estimation minimizes T(p_i) -> prev, so we use the forward T
        # to find where p_i came from in the previous frame.
        # Actually, the formula uses T(p_i) to sample from prev.
        # If T maps prev->curr, we need T_inv(curr) -> prev.
        # The source defines epsilon using T(p_i) sampling from prev.
        # This implies T maps current local coords to previous local coords?
        # Or T is the transform FROM prev TO curr?
        # Source: "inverse-warping its voxel-center sample positions into the previous... TSDF"
        # Formula: s_hat_{t-1}(T(p_i)) - s_t(p_i).
        # This implies T maps p_i (in current block space) to a location in prev block space.
        # So T is the "inverse warp" transform estimated.
        
        warped_pos = apply_rigid_transform(p_i, r, t)
        val = trilinear_interpolate(warped_pos, neighborhood_blocks)
        predictor.append(val)
        
    return predictor, (r, t)

def apply_rigid_transform(p, r, t):
    """
    Applies rigid transform defined by Euler angles r and translation t to point p.
    Assumes r is rotation vector (axis-angle or Euler) and t is translation.
    """
    # Construct rotation matrix R from Euler angles r
    R = euler_to_rotation_matrix(r)
    # Apply rotation and translation
    # The specific order (R*p + t vs R*(p+t)) depends on convention.
    # Standard rigid transform: p' = R*p + t
    return R @ p + t
```

**Edge Cases and Pitfalls:**
*   **Insufficient Samples:** If too few reliable samples are available or the $3 \times 3 \times 3$ neighborhood is incomplete (e.g., at the volume boundary), the method falls back to zero-motion prediction ($\mathbf{r} = \mathbf{0}, \mathbf{t} = \mathbf{0}$) [S1].
*   **Divergence:** The Gauss-Newton optimization can diverge if updates are too large. Clamping translation to 1 voxel and rotation to 5 degrees per step prevents this [S1].
*   **Boundary Interpolation:** Warped samples may land in neighboring blocks. The stitched $3 \times 3 \times 3$ neighborhood ensures valid trilinear interpolation is always possible [S1].

## Subtopics

### Per-Block Motion Estimation
This variant focuses on the optimization procedure used to determine the 6-DoF rigid transform for each block independently [S1]. It differs from global motion estimation by allowing piecewise-rigid motion, which is necessary for complex deformations. It is chosen when the scene contains multiple moving objects or non-rigid deformations that can be approximated locally. The method uses a damped Gauss-Newton algorithm to minimize the squared residuals between the warped previous frame and the current frame [S1].

## Operating characteristics
*   **Time Complexity:** The complexity is dominated by the motion estimation step, which involves iterative Gauss-Newton optimization for each block. The number of iterations depends on the convergence threshold and the complexity of the motion. Resampling is linear in the number of voxels per block.
*   **Memory Complexity:** Requires storing the previous frame's TSDF blocks and the stitched $3 \times 3 \times 3$ neighborhood for interpolation. The sparse representation (e.g., voxel hashing) helps manage memory for large volumes [S1].
*   **Performance:** Implemented with CUDA acceleration, the method achieves real-time or near-real-time performance on modern GPUs (e.g., NVIDIA RTX 4090) for typical resolutions [S1].
*   **Strengths:** Significantly reduces residual error for dynamic scenes compared to static compression, leading to higher compression ratios. Handles local motion variations.
*   **Limitations:** Computationally expensive due to per-block optimization. Fails to capture non-rigid deformations well if the block size is too large. Requires accurate initial estimates or robust clamping to avoid divergence.

## Background
Motion-Compensated Block Warping was introduced in the context of implicit surface compression, specifically in the paper "Implicit Surface Compression -- with Good Old Discrete Cosine Transform and Motion Compensation" [S1]. It builds upon the principles of sparse TSDF representation and voxel hashing [S1]. The method leverages the temporal coherence of dynamic 3D scans to improve compression efficiency.
