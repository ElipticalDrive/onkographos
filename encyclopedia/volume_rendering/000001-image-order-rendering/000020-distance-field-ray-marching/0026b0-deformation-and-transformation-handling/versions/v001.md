# Deformation and Transformation Handling

Also called: SDF Transformation, Inverse Mapping, Motion Compensation

## Overview
This family handles the application of spatial transformations (rigid body motion, scaling, deformation) to Signed Distance Fields (SDFs) and Truncated Signed Distance Fields (TSDFs) during ray marching. It solves the problem of rendering animated, deforming, or non-uniformly positioned geometry without recomputing the underlying distance field or vertex buffers for every frame. It sets itself apart from static sphere tracing by introducing coordinate space transformations (inverse model matrices) or temporal warping (motion compensation) to align the query point with the reference geometry, building on [Distance-field ray marching](21-distance-field-ray-marching.md).

## Shared principles
The core principle is that the SDF or TSDF is defined in a specific coordinate space (local, undeformed, or previous frame). To query the distance at a world-space or current-frame position $\mathbf{p}$, the position must be mapped back to the reference space $\mathbf{p}'$ where the field is static.

1.  **Coordinate Mapping:** For rigid transformations, the world-space point $\mathbf{p}$ is transformed by the inverse of the object's model matrix $M^{-1}$ to obtain the local-space point $\mathbf{p}_{local} = M^{-1}\mathbf{p}$. The SDF is then evaluated as $f(\mathbf{p}_{local})$ [S1, S2, unofficial].
2.  **Distance Scaling:** If the transformation includes non-uniform scaling, the distance value returned by the SDF must be scaled to maintain metric correctness. For a uniform scale $s$, the distance is scaled by $s$: $f'(\mathbf{p}) = s \cdot f(\mathbf{p}/s)$ [S35, unofficial].
3.  **Temporal Warping:** For video compression or temporal coherence, voxel centers in a target frame are inverse-warped into the coordinate space of the previous frame using a 6-DoF rigid transform $(\mathbf{r}, \mathbf{t})$. The TSDF value is then retrieved via trilinear interpolation from the previous frame's block and its $3 \times 3 \times 3$ neighborhood [S1, unofficial].
4.  **Jacobian Estimation:** For non-rigid deformation, the step size and direction in ray marching are adjusted using the Jacobian of the deformation field to account for local stretching and rotation, ensuring the ray does not overshoot deformed surfaces [S1, unofficial].

## Subtopics

### [Inverse Model Matrix Transformation for Distance Fields](1962-inverse-model-matrix-transformation-for-distance-fields.md)
Applies rigid body transformations (rotation and translation) to SDF primitives by transforming the sample point using the inverse of the object's model matrix before evaluation. It solves the problem of animating or positioning individual SDF objects independently without modifying the underlying distance function definitions. Unlike direct geometry transformation, it preserves the analytical nature of the SDF by operating in the object's local coordinate space.

### [Motion-Compensated Block Warping](4613-motion-compensated-block-warping.md)
Improves prediction accuracy for moving scenes by inverse-warping voxel-center samples of a target block into the previously reconstructed Truncated Signed Distance Field (TSDF) and resampling at the warped locations using trilinear interpolation. It sets itself apart from static transformation methods by estimating per-block rigid motion to align temporal frames, thereby reducing residual energy before transform-domain coding.

### [Mesh Transformation via Embree RTC](5669-mesh-transformation-via-embree-rtc.md)
Applies a 4x4 transformation matrix to mesh vertices within an Embree ray tracing scene, updating the geometry buffer in place while preserving the original source mesh data. It differs from its sibling [Inverse Model Matrix Transformation for Distance Fields](1962-inverse-model-matrix-transformation-for-distance-fields.md) by modifying the actual vertex positions in the Embree buffer rather than applying inverse transformations to the ray origin or direction, and from [Motion-Compensated Block Warping](4613-motion-compensated-block-warping.md) by operating on explicit mesh geometry rather than warping pre-computed blocks or fields. It is used when the scene geometry needs to be physically updated for subsequent ray tracing operations.

### NTSL Marching
#### definition
A ray marching technique that integrates a deformed scene by marching in the undeformed space and mapping positions/normals to the deformed space using a Jacobian estimate [S1, unofficial].

#### step
1. Initialize `s_sum` to `start` and `pos` to `ipos` [S1, unofficial].
2. Loop up to `MAX_MARCHING_STEPS`:
   a. Calculate `inv_jacobian` by inverting the Jacobian estimated at `pos` with `force` [S1, unofficial].
   b. Calculate `s_undeformed` as the absolute value of the scene SDF at `pos` [S1, unofficial].
   c. Accumulate `s_undeformed` to `s_sum` [S1, unofficial].
   d. Calculate `u_epsilon` as `s_sum * (s_sum * rad_pixel * determinant(inv_jacobian))` [S1, unofficial].
   e. If `s_undeformed < u_epsilon`, return `vec4(pos, 1)` indicating a hit [S1, unofficial].
   f. If `s_sum >= end`, return `vec4(0)` indicating no hit (marched too far) [S1, unofficial].
   g. If `s_undeformed < 3 * u_epsilon`, advance `pos` by `s_undeformed * normalized(inv_jacobian * w)` [S1, unofficial].
   h. Otherwise (`s_undeformed >= 3 * u_epsilon`), advance `pos` by `s_undeformed * normalized(inv_jacobian * w)` [S1, unofficial].
3. If the loop completes without returning, return `vec4(0)` [S1, unofficial].

#### parameter
- `MAX_MARCHING_STEPS`: The maximum number of iterations for the marching loop [S1, unofficial].
- `rad_pixel`: A constant used in the epsilon calculation for stopping criteria [S1, unofficial].

#### pitfall
The ODE solver (`ode23`) is commented out in the main loop, so the fallback to simple stepping is always used [S1, unofficial].

## Background
The concept of transforming SDFs via inverse matrices is a standard technique in ray marching, popularized by Inigo Quilez and others in the demoscene and real-time graphics communities [S35, unofficial]. Motion-compensated block warping for TSDFs is specific to 3D video compression and volumetric video streaming, where temporal redundancy is exploited by warping previous frames to predict current frames [S1, unofficial]. NTSL Marching appears in experimental graphics codebases (NTSL-graphics) focusing on deformed field integration [S1, unofficial].
