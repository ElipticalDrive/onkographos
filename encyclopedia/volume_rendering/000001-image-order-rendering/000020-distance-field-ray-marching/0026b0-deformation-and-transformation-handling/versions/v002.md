# Deformation and Transformation Handling

Also called: SDF Transformation, Dynamic SDF Handling, Motion-Compensated Warping

## Overview
This family addresses the problem of rendering animated, deformed, or dynamically positioned geometry within distance-field ray marching. While [Distance-field ray marching](21-distance-field-ray-marching.md) assumes static primitives, this family provides mechanisms to apply rigid body transformations, non-rigid deformations, and temporal motion compensation to the scene representation. It differs from static sphere tracing by introducing coordinate space transformations (local-to-world or world-to-local) and, in the case of dynamic volumes, predictive warping to handle temporal redundancy.

## Shared principles
The core principle across all methods is the decoupling of the geometric definition (the base SDF or TSDF function) from its spatial placement and deformation state.

1.  **Coordinate Space Transformation:** For rigid bodies, the evaluation point $\mathbf{p}$ in world space is transformed into the object's local coordinate space $\mathbf{q}$ before querying the base SDF $f_{base}$. The transformed distance is $f_{world}(\mathbf{p}) = f_{base}(M^{-1}\mathbf{p})$, where $M$ is the model matrix [S1, S2, unofficial]. This preserves the analytical properties of the SDF (such as the Lipschitz constant) provided the transformation is rigid (rotation and translation only) or uniform scaling is handled explicitly [S2, unofficial].
2.  **Normal Transformation:** Surface normals computed in local space must be transformed back to world space for shading. For a rigid transformation with rotation matrix $R$, the world normal $\mathbf{n}_w$ is $R \mathbf{n}_l$. If non-uniform scaling is involved, the inverse-transpose of the transformation matrix must be used to preserve orthogonality [G].
3.  **Temporal Prediction (Dynamic Volumes):** For dynamic 3D volumes represented as Truncated Signed Distance Fields (TSDF), motion is handled by estimating a rigid transform $(\mathbf{r}, \mathbf{t})$ between frames. The current frame's data is predicted by inverse-warping the previous frame's voxel data using this transform, reducing the residual error to be encoded or computed [S1, unofficial].

## Subtopics

### [Inverse Model Matrix Transformation for Distance Fields](1962-inverse-model-matrix-transformation-for-distance-fields.md)
This method applies rigid body transformations (rotation and translation) to SDF primitives by transforming the sample point using the inverse of the object's model matrix before evaluation. It solves the problem of animating or positioning individual SDF objects independently without modifying the underlying distance function definitions. Unlike direct geometry transformation, it preserves the analytical nature of the SDF by operating in the object's local coordinate space.

### [Motion-Compensated Block Warping](4613-motion-compensated-block-warping.md)
Motion-Compensated Block Warping is a technique for compressing dynamic 3D volumes by predicting the current frame's Truncated Signed Distance Field (TSDF) from the previously reconstructed frame using rigid body motion. It solves the problem of temporal redundancy in dynamic scenes by inverse-warping voxel samples from the target frame into the coordinate space of the previous frame, creating a predictor that captures the bulk of the geometric change. Unlike static compression or simple frame-differencing, it explicitly models 6-DoF rigid motion per block, allowing for efficient residual coding of the remaining geometric details.

### [Mesh Transformation via Embree RTC](5669-mesh-transformation-via-embree-rtc.md)
This method updates the geometry of a mesh within an Embree ray tracing context by applying a 4x4 transformation matrix to the vertex buffer while preserving the original source data. It solves the problem of dynamic mesh animation in Embree by allowing the scene graph to reflect current vertex positions without reallocating geometry buffers. It differs from [Inverse Model Matrix Transformation for Distance Fields](1962-inverse-model-matrix-transformation-for-distance-fields.md) by operating on explicit mesh primitives rather than implicit distance fields, and from [Motion-Compensated Block Warping](4613-motion-compensated-block-warping.md) by updating vertex positions directly rather than warping compressed voxel blocks.

### NTSL Marching
#### definition
- [S1, unofficial] A ray marching technique that integrates a deformed scene by marching in the undeformed space and mapping positions/normals to the deformed space using a Jacobian estimate.

#### step
- [S1, unofficial] Initialize $s_{sum}$ to start and $pos$ to $ipos$.
- [S1, unofficial] Loop up to `MAX_MARCHING_STEPS`: Calculate `inv_jacobian` by inverting the Jacobian estimated at $pos$ with force.
- [S1, unofficial] Calculate $s_{undeformed}$ as the absolute value of the scene SDF at $pos$.
- [S1, unofficial] Accumulate $s_{undeformed}$ to $s_{sum}$.
- [S1, unofficial] Calculate $u_{epsilon}$ as $s_{sum} \cdot (s_{sum} \cdot rad\_pixel \cdot \det(\text{inv\_jacobian}))$.
- [S1, unofficial] If $s_{undeformed} < u_{epsilon}$, return $\text{vec4}(pos, 1)$ indicating a hit.
- [S1, unofficial] If $s_{sum} \ge end$, return $\text{vec4}(0)$ indicating no hit (marched too far).
- [S1, unofficial] If $s_{undeformed} < 3 \cdot u_{epsilon}$, advance $pos$ by $s_{undeformed} \cdot \text{normalized}(\text{inv\_jacobian} \cdot w)$.
- [S1, unofficial] Otherwise ($s_{undeformed} \ge 3 \cdot u_{epsilon}$), advance $pos$ by $s_{undeformed} \cdot \text{normalized}(\text{inv\_jacobian} \cdot w)$ (same step as the if branch).
- [S1, unofficial] If the loop completes without returning, return $\text{vec4}(0)$.

#### parameter
- [S1, unofficial] `MAX_MARCHING_STEPS`: The maximum number of iterations for the marching loop.
- [S1, unofficial] `rad_pixel`: A constant used in the epsilon calculation for stopping criteria.

#### pitfall
- [S1, unofficial] The ODE solver (`ode23`) is commented out in the main loop, so the fallback to simple stepping is always used.

## Background
The concept of transforming SDFs via inverse matrices is a standard technique in implicit modeling, popularized by Ericson's *Real-Time Collision Detection* and widely adopted in real-time ray marching shaders [S2, unofficial]. Motion-compensated warping for TSDFs originates from video compression techniques adapted for 3D volumetric data, specifically in the context of dynamic 3D reconstruction and compression [S1, unofficial]. The NTSL Marching variant appears in experimental graphics codebases exploring deformed field integration [S1, unofficial].
