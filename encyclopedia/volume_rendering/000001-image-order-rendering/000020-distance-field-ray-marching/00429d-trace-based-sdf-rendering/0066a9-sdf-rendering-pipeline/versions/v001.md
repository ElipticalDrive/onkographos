# SDF Rendering Pipeline

Also called: Ray Marching with Reflections and Shadows, Raycasting SDF, Raymarched SDF Rendering, SDF Raymarching, SDF Raymarching in Three.js ShaderPass, Signed Distance Field Ray Marching

## Overview

The SDF Rendering Pipeline generates depth, normal, and color images from a Signed Distance Field (SDF) representation by shooting rays from the camera and marching them through the scene to find surface intersections [S1, S3, unofficial]. It differs from volume rendering by evaluating the distance function analytically or via sparse structures to find exact surface hits rather than integrating density along the ray, and it differs from basic raycasting by supporting recursive reflections and shadow testing [S3, unofficial]. The method produces a final image by accumulating lighting contributions from a sun and multiple point lights across up to two bounces [S3, unofficial].

## How it works

### Inputs and Outputs
**Inputs:**
*   Camera parameters: position (`cameraPos`), view direction, projection matrix (`proj`), inverse view matrix (`viewInv`), inverse projection matrix (`projInv`), field of view (`fov`), resolution (`iResolution`) [S3, S4, unofficial].
*   Scene definition: A set of objects defined by SDF primitives (Sphere, Box, Torus, Capsule) or a TSDF volume [S1, S3, unofficial]. Each object has position, color, reflectivity, and geometric parameters [S3, unofficial].
*   Lighting: Sun direction (`sunDir`), sun color (`sunColor`), and up to 32 point lights defined by position, color, and type [S3, unofficial].
*   Parameters: `MAX_STEPS` (max iterations), `MAX_DIST` (max ray distance), `MAX_OBJS` (max objects), `MAX_LIGHTS` (max lights), hit threshold (`eps_hit`), normal estimation epsilon (`eps_norm`) [S3, unofficial].

**Outputs:**
*   Color buffer (`fragColor`): RGBA image with accumulated lighting [S3, S4, unofficial].
*   Depth buffer: Clip-space depth of the nearest surface [S4, unofficial].
*   Normal buffer: Surface normals at hit points [S1, unofficial].

### Data Structures

**Object Uniform Buffer Layout:**
Arrays stored in GPU memory, indexed by object ID `j`:
*   `objPos`: `vec3[MAX_OBJS]` – World position.
*   `objColor`: `vec4[MAX_OBJS]` – RGBA color.
*   `objReflect`: `float[MAX_OBJS]` – Reflectivity coefficient ($r_{curr}$).
*   `objType`: `int[MAX_OBJS]` – Type identifier (0 = Sphere/Light) [S3, unofficial].
*   `objInvRotMat`: `mat3[MAX_OBJS]` – Inverse rotation matrix for local space transformation [S3, unofficial].
*   `sphereRadii`: `float[MAX_OBJS]` – Radius for spheres [S3, unofficial].
*   `boxSizes`: `vec3[MAX_OBJS]` – Half-extents for boxes [S3, unofficial].
*   `torusRadii`: `vec2[MAX_OBJS]` – Toroidal and poloidal radii [S3, unofficial].
*   `capsuleSize`: `vec2[MAX_OBJS]` – Radius and half-height for capsules [S3, unofficial].

**Ray State:**
*   `ro`: `vec3` – Ray origin.
*   `rd`: `vec3` – Ray direction (normalized).
*   `t`: `float` – Distance traveled along ray.
*   `id`: `int` – ID of the hit object (-1 if none).
*   `isLight`: `bool` – True if the hit object is a light source.

### Steps

1.  **Initialize Rays:** For each pixel with screen coordinates $(u, v)$, compute the ray direction.
    *   Calculate UV: $uv = (fragCoord - 0.5 \cdot iResolution) / iResolution.y$ [S3, unofficial].
    *   Calculate Focal Length: $focal = 1 / \tan(fov / 2)$ [S3, unofficial].
    *   Compute Direction: $rd = \text{normalize}(focal \cdot camForward + uv_x \cdot camRight + uv_y \cdot camUp)$ [S3, unofficial].
    *   Set Origin: $ro = cameraPos$ [S3, unofficial].
    *   *Alternative Initialization (Three.js):* Unproject NDC coordinates to world space using `projInv` and `viewInv`, then set $rd = \text{normalize}(worldPos - cameraPos) \cdot distFactor$ where $distFactor = 0.25$ [S4, unofficial].

2.  **Ray Marching Loop:** Iterate to find the surface intersection.
    *   Initialize $t = 0.0$, $id = -1$, $isLight = false$ [S3, unofficial].
    *   Loop $i$ from $0$ to $MAX\_STEPS - 1$:
        *   Evaluate distance $d = \text{map}(ro + rd \cdot t, id)$ [S3, unofficial].
        *   If $d < \epsilon_{hit}$ (typically $0.001$):
            *   Set hit point $p = ro + rd \cdot t$ [S3, unofficial].
            *   If $id \neq -1$ and $objType[id] == 0$ (Light):
                *   Set $isLight = true$, break loop [S3, unofficial].
            *   Else:
                *   Break loop (Surface hit) [S3, unofficial].
        *   If $t > MAX\_DIST$ (typically $50.0$):
            *   Break loop (Ray escaped) [S3, unofficial].
        *   Advance: $t \leftarrow t + d$ [S3, unofficial].

3.  **Normal Estimation:** If a surface was hit ($id \neq -1$ and not a light):
    *   Compute normal $n$ using central finite differences with $\epsilon_{norm} = 0.001$ [S3, unofficial]:
        $$ n = \text{normalize} \begin{bmatrix} \text{map}(p + \epsilon_{norm} \hat{x}, id) - \text{map}(p - \epsilon_{norm} \hat{x}, id) \\ \text{map}(p + \epsilon_{norm} \hat{y}, id) - \text{map}(p - \epsilon_{norm} \hat{y}, id) \\ \text{map}(p + \epsilon_{norm} \hat{z}, id) - \text{map}(p - \epsilon_{norm} \hat{z}, id) \end{bmatrix} $$
    *   [S3, unofficial]. Note: Some implementations use analytic normals if available [S2, unofficial].

4.  **Shadow Testing:** For each light source $j$:
    *   Compute light direction: $l = \text{normalize}(objPos[j] - p)$ [S3, unofficial].
    *   Compute distance to light: $distToLight = \| objPos[j] - p \|$ [S3, unofficial].
    *   Cast shadow ray:
        *   Origin: $ro_{shadow} = p + n \cdot 0.01$ (offset to prevent self-intersection) [S3, unofficial].
        *   Direction: $rd_{shadow} = l$ [S3, unofficial].
        *   March towards light with step size starting at $0.01$.
        *   If $\text{map}(q, id, isLight) < \epsilon_{hit}$:
            *   If $isLight$ is true: Light is visible (no shadow) [S3, unofficial].
            *   If $isLight$ is false: Ray is blocked (shadow) [S3, unofficial].
    *   [S3, unofficial].

5.  **Lighting Calculation:**
    *   Initialize $finalColor = 0$, $r_{last} = 1.0$ [S3, unofficial].
    *   Loop bounce $b$ from $0$ to $1$ (up to 2 bounces):
        *   Reset $t = 0.0$, $id = -1$, $isLight = false$ [S3, unofficial].
        *   Perform Ray Marching (Step 2) starting from current $ro, rd$.
        *   If hit:
            *   If $isLight$:
                *   $finalColor += r_{last} \cdot \text{white}$ [S3, unofficial].
                *   Break bounce loop (Light termination) [S3, unofficial].
            *   Compute Normal $n$ (Step 3) [S3, unofficial].
            *   Compute Sun Contribution:
                *   If not in shadow from `sunDir`: $L_{sun} = \text{getSunContribution}(p, n, rd, sunDir, sunColor)$ [S3, unofficial].
                *   Else: $L_{sun} = 0$ [S3, unofficial].
            *   Compute Ambient: $L_{amb} = 0$ [S3, unofficial].
            *   Compute Scene Lighting:
                *   $L_{diff} = 0$, $L_{spec} = 0$ [S3, unofficial].
                *   For each light $j$ (up to `MAX_LIGHTS`):
                    *   If not in shadow:
                        *   $l = \text{normalize}(objPos[j] - p)$ [S3, unofficial].
                        *   Diffuse: $L_{diff} += \text{dot}(n, l) \cdot objColor[j].rgb$ [S3, unofficial].
                        *   Specular (Blinn-Phong):
                            *   $h = \text{normalize}(l + (-rd))$ [S3, unofficial].
                            *   $spec = \text{clamp}(\max(n \cdot h, 0)^{32}, 0, 1)$ [S3, unofficial].
                            *   $L_{spec} += spec \cdot objColor[j].rgb$ [S3, unofficial].
            *   Accumulate Color:
                *   $r_{curr} = objReflect[id]$ [S3, unofficial].
                *   $C_{out} = C_{in} + r_{last} \cdot (1 - r_{curr}) \cdot objColor[id].rgb \cdot (L_{diff} + 0.2 L_{spec} + L_{sun} + L_{amb})$ [S3, unofficial].
                *   Update $finalColor$ [S3, unofficial].
                *   Update Ray for next bounce:
                    *   $ro = p + n \cdot 0.01$ [S3, unofficial].
                    *   $rd = \text{reflect}(rd, n)$ [S3, unofficial].
                    *   $r_{last} = r_{last} \cdot r_{curr}$ [S3, unofficial].
        *   Else (No Hit):
            *   Add Environment Color: $finalColor += r_{last} \cdot 0.5 \cdot \text{getEnvironment}(rd)$ [S3, unofficial].
            *   $r_{last} = 0.0$ [S3, unofficial].
            *   Break step loop [S3, unofficial].

6.  **Final Output:**
    *   If no hit occurred in any bounce: $fragColor = \text{vec4}(\text{getEnvironment}(rd), 1.0)$ [S3, unofficial].
    *   Else: $fragColor = \text{vec4}(finalColor, 1.0)$ [S3, unofficial].
    *   *Three.js Variant:* Mix `sdfResult` with `sceneColor` using `sdfResult.a` as alpha [S4, unofficial]. Set `gl_FragDepth` from clip-space Z [S4, unofficial].

### SDF Primitives Formulas

*   **Sphere:** $d = \| p - objPos[i] \| - sphereRadii[i]$ [S3, unofficial].
*   **Box:** Transform $p$ to local space: $q = objInvRotMat[i] \cdot (p - objPos[i])$.
    $d = \text{length}(\max(q, 0.0)) + \min(\max(q_x, \max(q_y, q_z)), 0.0)$ [S3, unofficial].
*   **Torus:** Transform $p$ to local space: $q = objInvRotMat[i] \cdot (p - objPos[i])$.
    $u = \text{vec2}(\| q_{xz} \| - torusRadii[i].x, q_y)$ [S3, unofficial].
    $d = \| u \| - torusRadii[i].y$ [S3, unofficial].
*   **Capsule:** Transform $p$ to local space: $q = objInvRotMat[i] \cdot (p - objPos[i])$.
    $q_y = \text{clamp}(q_y, 0, capsuleSize[i].y)$ [S3, unofficial].
    $d = \| q \| - capsuleSize[i].x$ [S3, unofficial].

### Pseudocode

```python
def sdf_render_pipeline(camera_pos, camera_forward, camera_right, camera_up, fov, resolution, objects, lights, sun_dir, sun_color):
    """
    Renders an image using SDF ray marching with reflections and shadows.
    """
    width, height = resolution
    focal = 1.0 / tan(fov / 2.0)
    max_steps = 80
    max_dist = 50.0
    eps_hit = 0.001
    eps_norm = 0.001
    max_objs = 32
    max_lights = 32
    
    # Pre-calculate object matrices and params
    obj_data = []
    for obj in objects:
        obj_data.append({
            'pos': obj.position,
            'color': obj.color,
            'reflect': obj.reflectivity,
            'type': obj.type, # 0 for Sphere/Light
            'inv_rot': obj.inv_rotation_matrix,
            'params': obj.params # radius, size, etc.
        })

    image = zeros((height, width, 3))

    for y in range(height):
        for x in range(width):
            # 1. Initialize Ray
            uv_x = (x + 0.5 - width / 2.0) / height
            uv_y = (y + 0.5 - height / 2.0) / height
            rd = normalize(focal * camera_forward + uv_x * camera_right + uv_y * camera_up)
            ro = camera_pos
            
            final_color = vec3(0.0)
            r_last = 1.0
            hit_any = False
            
            # 5. Bounce Loop (0 to 1)
            for bounce in range(2):
                t = 0.0
                hit_id = -1
                is_light = False
                
                # 2. Ray Marching
                for step in range(max_steps):
                    # Evaluate distance
                    d = map_scene(ro + rd * t, obj_data)
                    
                    if d < eps_hit:
                        hit_any = True
                        p = ro + rd * t
                        # Find which object caused the hit
                        hit_id = find_hit_object(p, obj_data)
                        if hit_id != -1 and obj_data[hit_id]['type'] == 0:
                            is_light = True
                        break
                    
                    if t > max_dist:
                        break
                        
                    t += d
                
                if is_light:
                    final_color += r_last * vec3(1.0, 1.0, 1.0)
                    break # Light termination
                
                if t > max_dist or hit_id == -1:
                    # Environment
                    final_color += r_last * 0.5 * get_environment(rd)
                    r_last = 0.0
                    break
                
                # 3. Normal Estimation
                p = ro + rd * t
                n = compute_normal(p, hit_id, obj_data, eps_norm)
                
                # 4. Shadow Testing & Lighting
                # Sun
                sun_contrib = 0.0
                if not is_in_shadow(p, n, sun_dir, obj_data, max_steps):
                    sun_contrib = compute_sun(p, n, sun_dir, sun_color)
                
                # Lights
                diff = 0.0
                spec = 0.0
                for j in range(len(lights)):
                    if j >= max_lights: break
                    light_pos = lights[j].position
                    light_dir = normalize(light_pos - p)
                    if not is_in_shadow(p, n, light_dir, obj_data, max_steps):
                        # Diffuse
                        diff += max(dot(n, light_dir), 0.0) * lights[j].color.rgb
                        # Specular
                        h = normalize(light_dir + (-rd))
                        spec += pow(max(dot(n, h), 0.0), 32.0) * lights[j].color.rgb
                
                # Accumulate
                r_curr = obj_data[hit_id]['reflect']
                obj_col = obj_data[hit_id]['color'].rgb
                ambient = 0.0
                
                final_color += r_last * (1.0 - r_curr) * obj_col * (diff + 0.2 * spec + sun_contrib + ambient)
                
                # Prepare for next bounce
                ro = p + n * 0.01
                rd = reflect(rd, n)
                r_last *= r_curr

            if not hit_any:
                final_color = get_environment(rd)
                
            image[y, x] = final_color

    return image

def map_scene(p, obj_data):
    """Returns minimum distance to any object."""
    min_d = infinity
    for i, obj in enumerate(obj_data):
        d = 0.0
        if obj['type'] == 'Sphere':
            d = length(p - obj['pos']) - obj['params'][0]
        elif obj['type'] == 'Box':
            q = obj['inv_rot'] @ (p - obj['pos'])
            d = length(max(q, 0.0)) + min(max(q[0], max(q[1], q[2])), 0.0)
        elif obj['type'] == 'Torus':
            q = obj['inv_rot'] @ (p - obj['pos'])
            u = vec2(length(q[0:2]) - obj['params'][0], q[2])
            d = length(u) - obj['params'][1]
        elif obj['type'] == 'Capsule':
            q = obj['inv_rot'] @ (p - obj['pos'])
            q_y = clamp(q[1], 0.0, obj['params'][1])
            q[1] = q_y
            d = length(q) - obj['params'][0]
        
        if d < min_d:
            min_d = d
    return min_d

def compute_normal(p, hit_id, obj_data, eps):
    """Central finite differences."""
    dx = vec3(eps, 0.0, 0.0)
    dy = vec3(0.0, eps, 0.0)
    dz = vec3(0.0, 0.0, eps)
    
    d_x = map_scene(p + dx, obj_data) - map_scene(p - dx, obj_data)
    d_y = map_scene(p + dy, obj_data) - map_scene(p - dy, obj_data)
    d_z = map_scene(p + dz, obj_data) - map_scene(p - dz, obj_data)
    
    return normalize(vec3(d_x, d_y, d_z))

def is_in_shadow(p, n, light_dir, obj_data, max_steps):
    """Returns True if shadowed."""
    ro = p + n * 0.01
    rd = light_dir
    for step in range(max_steps):
        d = map_scene(ro + rd * step, obj_data) # Simplified step logic
        if d < 0.001:
            # Check if it's a light or geometry
            # In this simplified version, assume geometry blocks
            return True
        step += 0.01 # Fixed step or adaptive
        if step > 100.0: # Arbitrary light distance
            break
    return False
```

### Edge Cases and Pitfalls
*   **Normal Precision:** The epsilon for normal calculation ($0.001$) is hardcoded. If the scene scale is very small or very large, this leads to inaccurate normals [S3, unofficial].
*   **Shadow Acne:** Using a fixed offset ($0.01$) and hard threshold ($0.001$) for shadow testing causes self-shadowing artifacts (shadow acne) [S3, unofficial].
*   **Self-Intersection:** Rays reflecting off surfaces must be offset by $n \cdot 0.01$ to prevent immediate re-intersection [S3, unofficial].
*   **Shader Compatibility:** In Three.js, setting `gl_FragColor` alpha to $0.0$ may fail in revisions $\ge 137$; use $1.0$ [S4, unofficial].
*   **Hit Threshold:** Some implementations use $d < 0.001 \cdot t$ instead of a fixed epsilon to scale tolerance with distance [S3, unofficial].

## Subtopics

### [Differentiable SDF Rendering](21555-differentiable-sdf-rendering.md)
Computes gradients of pixel colors with respect to SDF parameters or scene variables by wrapping the ray intersection in an automatic differentiation framework. Choose this when optimizing geometry or camera parameters, as it enables backpropagation through the rendering pipeline.

## Operating characteristics

*   **Time Complexity:** $O(P \cdot B \cdot S \cdot O)$, where $P$ is pixels, $B$ is bounces (2), $S$ is max steps (80), and $O$ is objects (32) per step [S3, unofficial].
*   **Memory Complexity:** $O(O)$ for object data, $O(P)$ for buffers [S3, unofficial].
*   **Performance:** Real-time on modern GPUs for simple scenes with few objects and bounces [S3, unofficial].
*   **Strengths:** Sharp surfaces, easy implementation, supports reflections and shadows [S3, unofficial].
*   **Limitations:** No soft shadows (without PCF), limited to analytic SDFs or TSDF volumes, precision issues with normals [S3, unofficial].
*   **When to Use:** Real-time visualization, procedural geometry, differentiable rendering [S3, S1, unofficial].
*   **When Not to Use:** Complex organic geometry without SDF representation, soft global illumination [S3, unofficial].

## Background

The SDF Rendering Pipeline originates from ray marching techniques for Signed Distance Fields, popularized in real-time graphics for rendering smooth, procedural geometry [S3, unofficial]. It has been implemented in various contexts, including SLAM-based 3D reconstruction using TSDF volumes [S1, unofficial], dynamic neural field rendering [S2, unofficial], and educational raymarchers [S3, unofficial]. Integration with web-based frameworks like Three.js allows for interactive SDF visualization via custom shader passes [S4, unofficial].
