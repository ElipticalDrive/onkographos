# Adaptive Ray Marching with Temporal Reprojection

Also called: HZL Fluid Effects Studio volume renderer, field mode shading

## Overview
This method renders volumes by combining adaptive ray marching with temporal reprojection to reduce noise and flickering in animated sequences [S1, unofficial]. It builds on [Adaptive Step Size Calculation](4671-adaptive-step-size-calculation.md) by varying step length based on density thresholds, and differs from [Ray Marching with Adaptive Step Count and Cone Sampling](4808-ray-marching-with-adaptive-step-count-and-cone-sampling.md) by using screen-space reprojection of the previous frame rather than cone-based filtering for temporal stability [S1, unofficial][G].

## How it works
**Inputs:** Ray origin and direction, volume density field, `stepSize` (base step length), `densityScale` (opacity scaling factor), `absorption` (absorption coefficient multiplier), `adaptiveSteppingEnabled` (boolean flag), `historyTexture` (previous frame buffer), `historyWeight` (base blend weight), `emittedLight` (emissive contribution), `smokeColor` (base volume color), and `fieldMode` (integer 0-7 for color mapping) [S1, unofficial].

**Outputs:** Final accumulated color (`accumulated.rgb`) and alpha (`accumulated.a`) [S1, unofficial].

**Data Structures:** `accumulated` holds `rgb` (float3) and `a` (float), initialized to zero [S1, unofficial]. `history` holds `rgb` and `a` sampled from `historyTexture` [S1, unofficial]. `representativePosition` stores the world or view space position of the current ray step for reprojection [S1, unofficial].

**Parameters:** `stepSize`, `densityScale`, `absorption`, `adaptiveSteppingEnabled`, `historyWeight`, `emissionStrength` (multiplier for `emittedLight`), and `fieldMode` (0-7) [S1, unofficial].

**Steps:**
1. Initialize `accumulated.rgb` and `accumulated.a` to zero [S1, unofficial].
2. Loop through ray steps:
   a. Compute `currentStep` as `stepSize`, multiplied by 4.0 if `adaptiveSteppingEnabled` is true and `density < 0.004` [S1, unofficial].
   b. Calculate opacity: $opacity = 1.0 - \exp(-density \cdot densityScale \cdot currentStep \cdot absorption \cdot 4.0)$ [S1, unofficial].
   c. Update accumulated color: $accumulated.rgb \leftarrow accumulated.rgb + (1.0 - accumulated.a) \cdot (opacity \cdot smokeColor + emittedLight \cdot currentStep)$ [S1, unofficial].
   d. Update accumulated alpha: $accumulated.a \leftarrow accumulated.a + (1.0 - accumulated.a) \cdot opacity$ [S1, unofficial].
   e. If `accumulated.a > 0.985`, break the loop [S1, unofficial].
   f. Increment `distanceAlongRay` by `currentStep` [S1, unofficial].
3. If `accumulated.a < 0.002`, discard the fragment [S1, unofficial].
4. If `temporalEnabled` and `foundVolume` are true: project `representativePosition` to previous clip space, compute UV, clamp to `[0.0, 1.0]`, sample `historyTexture`, compute `responsiveWeight`, and blend `accumulated` with `history` [S1, unofficial].

**Formulas:**
- $opacity = 1.0 - \exp(-density \cdot densityScale \cdot currentStep \cdot absorption \cdot 4.0)$ [S1, unofficial]
- $accumulated.rgb \leftarrow accumulated.rgb + (1.0 - accumulated.a) \cdot (opacity \cdot smokeColor + emittedLight \cdot currentStep)$ [S1, unofficial]
- $accumulated.a \leftarrow accumulated.a + (1.0 - accumulated.a) \cdot opacity$ [S1, unofficial]
- $responsiveWeight = historyWeight \cdot (1.0 - |history.a - accumulated.a|)$ [S1, unofficial]

**Pseudocode:**
```python
def adaptive_ray_marching_with_temporal_reprojection(ray_origin, ray_direction, volume_sampler, history_texture, camera_state, params):
    accumulated_rgb = vec3(0.0)
    accumulated_a = 0.0
    step_size = params.stepSize
    density_scale = params.densityScale
    absorption = params.absorption
    adaptive_enabled = params.adaptiveSteppingEnabled
    history_weight = params.historyWeight
    emitted_light = params.emittedLight
    smoke_color = params.smokeColor
    temporal_enabled = params.temporalEnabled
    found_volume = False
    distance_along_ray = 0.0
    
    while True:
        ray_position = ray_origin + ray_direction * distance_along_ray
        density = volume_sampler.sample(ray_position)
        
        if adaptive_enabled and density < 0.004:
            current_step = step_size * 4.0
        else:
            current_step = step_size
            
        opacity = 1.0 - exp(-density * density_scale * current_step * absorption * 4.0)
        accumulated_rgb += (1.0 - accumulated_a) * (opacity * smoke_color + emitted_light * current_step)
        accumulated_a += (1.0 - accumulated_a) * opacity
        
        if accumulated_a > 0.985:
            found_volume = True
            break
            
        distance_along_ray += current_step
        # [G] Maximum step limit or distance threshold not given in sources; implementation requires a loop bound.
        
    if accumulated_a < 0.002:
        return None
        
    if temporal_enabled and found_volume:
        prev_clip_pos = camera_state.previous_view_projection @ ray_position
        if prev_clip_pos.w > 0.0:
            prev_uv = vec2(prev_clip_pos.x / prev_clip_pos.w, prev_clip_pos.y / prev_clip_pos.w)
            prev_uv = vec2(clamp(prev_uv.x, 0.0, 1.0), clamp(prev_uv.y, 0.0, 1.0))
            history = history_texture.sample(prev_uv)
            responsive_weight = history_weight * (1.0 - abs(history.a - accumulated_a))
            blend_factor = clamp(responsive_weight, 0.0, 0.95)
            accumulated_rgb = mix(accumulated_rgb, history.rgb, blend_factor)
            accumulated_a = mix(accumulated_a, history.a, blend_factor)
            
    return vec4(accumulated_rgb, accumulated_a)
```

**Edge Cases and Pitfalls:**
- Temporal reprojection requires `prevClip.w > 0.0`; clamp UV to `[0.0, 1.0]` to avoid out-of-bounds sampling [S1, unofficial].
- Ghosting is mitigated by scaling `historyWeight` with `(1.0 - abs(history.a - accumulated.a))` and clamping the blend factor to `[0.0, 0.95]` [S1, unofficial].
- Fragments with final opacity below `0.002` are discarded to avoid rendering transparent pixels [S1, unofficial].
- `fieldMode` (0-7) controls smoke color mapping via conditional branches, but the exact branching logic is not detailed in the sources [S1, unofficial].
