# Non-Linear Sphere Tracing

Also called: Non-linear sphere tracing for deformed SDFs, RaymarchNonlinear, Rendering deformed signed distance fields

## Overview
Non-Linear Sphere Tracing (NLST) is a ray marching technique for directly rendering Signed Distance Fields (SDFs) that have been subjected to non-linear spatial deformations [S1]. It solves the problem that standard sphere tracing fails on deformed SDFs because the deformation invalidates the Euclidean distance metric, and computing the inverse deformation $D^{-1}$ is often impossible or unknown [S1]. Unlike [Sphere Tracing](1674-sphere-tracing.md), which assumes a static metric space, NLST formulates the ray traversal as an initial value problem (IVP) solved via numerical integration of an ordinary differential equation (ODE), allowing it to follow the curved ray trajectory in undeformed space while maintaining large step sizes [S1]. It differs from [Cone Intersection](1553-cone-intersection.md) and [Segment Tracing](1675-segment-tracing.md) by explicitly modeling the deformation's Jacobian to correct the step direction, rather than using geometric bounds or linear approximations [S1][S2, unofficial].

## How it works
**Inputs and Outputs:**
*   **Input:** A signed distance function $S(\hat{\mathbf{x}})$ defined in undeformed (object) space $\hat{\mathbf{x}}$; a forward deformation function $D(\hat{\mathbf{x}})$ mapping object space to deformed space; a ray origin $\mathbf{p}$ and direction $\boldsymbol{\omega}$ in deformed space; a maximum step count $N_{max}$; a hit threshold $\epsilon$; and a maximum travel distance $D_{max}$ [S1][S2, unofficial].
*   **Output:** A hit structure containing the deformed position $\mathbf{x}_{hit}$, the corrected normal $\mathbf{n}_{hit}$, and the distance traveled [S1][S2, unofficial].

**Data Structures:**
The implementation uses a `SceneHit` structure to track the ray state:
*   `position`: `float3` (current position in undeformed space $\hat{\mathbf{x}}$).
*   `normal`: `float3` (current normal estimate, initialized to zero).
*   `distanceTravelled`: `float` (accumulated arc-length $\hat{s}$ in undeformed space).
*   `hit`: `bool` (flag indicating surface intersection) [S2, unofficial].

**Numbered Steps:**
1.  **Initialize:** Set `sceneHit.position` to $\hat{\mathbf{x}}_0$ (from hull initialization or $D^{-1}(\mathbf{p})$ if available) [S1][S2, unofficial]. Set `sceneHit.distanceTravelled` = 0. Set `sceneHit.hit` = false. Set `sceneHit.normal` = $(0,0,0)$ [S2, unofficial].
2.  **Loop:** For $i$ from 0 to $N_{max} - 1$:
    a.  **Evaluate SDF:** Compute $h = S(\text{sceneHit.position})$ [S2, unofficial].
    b.  **Check Hit:** If $h \le \epsilon$, set `sceneHit.hit` = true [S2, unofficial]. Compute the standard SDF normal $\mathbf{n} = \nabla S(\text{sceneHit.position})$ using finite differences [S2, unofficial]. Compute the Jacobian $J$ of the deformation $D$ at the hit position [S2, unofficial]. Compute $J^{-1}$. Set `sceneHit.normal` = $\text{normalize}((J^{-1})^T \mathbf{n})$ [S2, unofficial]. Break loop [S2, unofficial].
    c.  **Compute Vector Field:** Compute the Jacobian $J$ at the current position using central finite differences [S2, unofficial]. Compute $J^{-1}$. Calculate the unit tangent vector in undeformed space:
        $$ \boldsymbol{\omega}(\hat{\mathbf{x}}) = \frac{J_D^{-1}(\hat{\mathbf{x}}) \boldsymbol{\omega}_0}{\|J_D^{-1}(\hat{\mathbf{x}}) \boldsymbol{\omega}_0\|} $$
        where $\boldsymbol{\omega}_0$ is the initial ray direction in deformed space [S1][S2, unofficial].
    d.  **Integrate (Runge-Kutta):** Advance the position using a 4th-order Runge-Kutta integrator with step size $h$:
        $$ k_1 = \boldsymbol{\omega}(\text{sceneHit.position}, \boldsymbol{\omega}_0) $$
        $$ k_2 = \boldsymbol{\omega}(\text{sceneHit.position} + 0.5 h k_1, \boldsymbol{\omega}_0) $$
        $$ k_3 = \boldsymbol{\omega}(\text{sceneHit.position} + 0.5 h k_2, \boldsymbol{\omega}_0) $$
        $$ k_4 = \boldsymbol{\omega}(\text{sceneHit.position} + h k_3, \boldsymbol{\omega}_0) $$
        $$ \text{sceneHit.position} = \text{sceneHit.position} + \frac{h}{6}(k_1 + 2k_2 + 2k_3 + k_4) $$
        [S2, unofficial].
    e.  **Update Distance:** `sceneHit.distanceTravelled` += $h$ [S2, unofficial].
    f.  **Check Max Distance:** If `sceneHit.distanceTravelled` $\ge D_{max}$, break loop [S2, unofficial].
3.  **Final Transform:** If `sceneHit.hit` is true, transform `sceneHit.position` to deformed space using $D(\text{sceneHit.position})$ [S1].

**Formulas:**
*   **Ray Integral in Undeformed Space:** $\hat{\mathbf{x}}(\hat{s}) = D^{-1}(\mathbf{p}) + \int_0^{\hat{s}} \hat{\boldsymbol{\omega}}(\hat{\mathbf{x}}(t)) dt$, where the tangent vector is $\hat{\boldsymbol{\omega}}(\hat{\mathbf{x}}) = \frac{J_D^{-1}(\hat{\mathbf{x}}) \boldsymbol{\omega}}{\|J_D^{-1}(\hat{\mathbf{x}}) \boldsymbol{\omega}\|}$ [S1].
*   **Jacobian Finite Differences:** $J_{ij} = \frac{D_i(\mathbf{x} + h_{diff}\mathbf{e}_j) - D_i(\mathbf{x} - h_{diff}\mathbf{e}_j)}{2 h_{diff}}$, where $h_{diff}$ is the differential step size and $\mathbf{e}_j$ are basis vectors [S2, unofficial].
*   **Normal Transformation:** $\mathbf{n}_{corrected} = \frac{(J^{-1})^T \mathbf{n}}{\|(J^{-1})^T \mathbf{n}\|}$, transforming the SDF gradient normal to deformed space [S2, unofficial].

**Parameters:**
*   $N_{max}$ (MAX_STEPS): Integer, default 200 [S2, unofficial].
*   $\epsilon$ (THRESHOLD): Float, default 0.0001 [S2, unofficial].
*   $D_{max}$ (MAX_DISTANCE): Float, default 400.0 [S2, unofficial].
*   $h_{diff}$ (NORMAL_DIFFERENTIAL): Float, default 0.0001 [S2, unofficial].
*   Deformation parameters (e.g., $\alpha$ for sinusoidal deformation): Default 1.0 [S2, unofficial].

**Pitfalls:**
*   **Singular Jacobian:** If the deformation causes $J_D$ to be singular or near-singular, $J_D^{-1}$ becomes unstable [S2, unofficial]. Deformations must be locally foldover-free [S1].
*   **Inverse Requirement:** The method requires $D^{-1}$ at least once for the initial seed $\hat{\mathbf{x}}_0$ [S1]. If $D^{-1}$ does not exist (e.g., non-bijective deformations), the hull-based initialization is mandatory [S1].
*   **Concave Objects:** Limited $N_{max}$ may cause missed intersections for concave objects or grazing angles [S1].
*   **Performance:** SDF evaluations are expensive. Naive step reduction degrades performance significantly [S1].

**Pseudocode:**
```python
def compute_jacobian(x, deform_func, h_diff):
    # Central finite differences for 3x3 Jacobian
    dx = deform_func(x + (h_diff, 0, 0)) - deform_func(x - (h_diff, 0, 0))
    dy = deform_func(x + (0, h_diff, 0)) - deform_func(x - (0, h_diff, 0))
    dz = deform_func(x + (0, 0, h_diff)) - deform_func(x - (0, 0, h_diff))
    grad1 = (dx.x, dy.x, dz.x) / (2.0 * h_diff)
    grad2 = (dx.y, dy.y, dz.y) / (2.0 * h_diff)
    grad3 = (dx.z, dy.z, dz.z) / (2.0 * h_diff)
    return transpose(matrix_from_columns(grad1, grad2, grad3))

def nonlinear_sphere_tracing(ray_origin, ray_direction, max_steps, threshold, max_distance, sdf_func, deform_func, normal_diff):
    hit = SceneHit(position=ray_origin, normal=(0,0,0), distance_travelled=0.0, hit=False)
    omega0 = normalize(ray_direction)
    
    for _ in range(max_steps):
        h = sdf_func(hit.position)
        
        if h <= threshold:
            hit.hit = True
            n = compute_sdf_normal(hit.position, sdf_func)
            J = compute_jacobian(hit.position, deform_func, normal_diff)
            J_inv = inverse(J)
            hit.normal = normalize(transpose(J_inv) @ n)
            break
            
        J = compute_jacobian(hit.position, deform_func, normal_diff)
        J_inv = inverse(J)
        
        def get_omega(x):
            J_x = compute_jacobian(x, deform_func, normal_diff)
            return normalize(inverse(J_x) @ omega0)
            
        k1 = get_omega(hit.position)
        k2 = get_omega(hit.position + 0.5 * h * k1)
        k3 = get_omega(hit.position + 0.5 * h * k2)
        k4 = get_omega(hit.position + h * k3)
        hit.position = hit.position + (h / 6.0) * (k1 + 2*k2 + 2*k3 + k4)
        
        hit.distance_travelled += h
        
        if hit.distance_travelled >= max_distance:
            break
            
    if hit.hit:
        hit.position = deform_func(hit.position)
    return hit
```

## Subtopics

### Hull-based initialization for non-linear sphere tracing
A variant that avoids computing the global inverse deformation $D^{-1}$ by using a coarse marching cubes mesh [S1]. The hull is deformed, rasterized, and the deformed position is mapped back to object space via barycentric interpolation to provide the initial ray start point $\hat{\mathbf{x}}_0$ [S1]. This enables the use of deformations where $D^{-1}$ is unknown or non-existent, such as complex skinning or sculpting brushes [S1].

## Operating characteristics
*   **Time Complexity:** Dominated by SDF evaluations and Jacobian inversions per step [S1][S2, unofficial]. The Runge-Kutta method requires multiple vector field evaluations per step but no additional SDF lookups for sub-stepping, preserving the performance advantage over naive ray marching [S1].
*   **Memory Complexity:** Low, requiring storage for the SDF and the deformation function [S1]. The hull mesh is small and transient [S1].
*   **Performance:** On an NVIDIA Titan RTX at 1080p, NLST takes ~10-13ms for complex scenes (Dinosaur, Head, Elephant), significantly faster than high-resolution Marching Cubes (e.g., S=1024 takes >9s) [S1]. It is more than twice as fast as Marching Cubes at the lowest resolution (S=32) while preserving thin features [S1].
*   **Strengths:** Preserves infinite resolution and sharp features; handles non-linear deformations (LBS, FFDs, Kelvinlets) without artifacts; avoids inverse deformation computation via hull initialization [S1].
*   **Limitations:** Requires $D$ to be a space deformation (evaluable at arbitrary points); fails if $J_D$ is singular; performance degrades at grazing angles or for highly concave objects with limited steps; does not support collision detection in deformed space due to lack of arbitrary point evaluation [S1].

## Background
NLST was introduced by Dario Seyb, Alec Jacobson, Derek Nowrouzezahrai, and Wojciech Jarosz in their paper "Non-linear sphere tracing for rendering deformed signed distance fields" (2020) [S1]. It builds on Barr's [1984] formulation for deforming parametric curves/surfaces by casting sphere tracing as an ODE initial value problem [S1]. The method addresses the limitations of meshing-based deformation (loss of detail, recomputation) and previous implicit deformation techniques that required inverse deformations or suffered from discontinuities [S1]. It has been implemented in prototype modeling applications using the Unity3D engine [S1].
