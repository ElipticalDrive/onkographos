# Dynamic Sampling Step Adjustment

Also called: Adaptive Step Doubling, Empty Space Step Doubling

## Overview
Dynamic Sampling Step Adjustment accelerates volume rendering by increasing the ray marching step size when traversing empty or low-density regions, thereby reducing the total number of samples required [S1, unofficial]. It solves the inefficiency of uniform step sizes in sparse volumes, such as volumetric clouds or fog, where large portions of the ray contribute negligible opacity [S1, unofficial]. Unlike [Safe Raymarching Step Size](1462-safe-raymarching-step-size.md), which relies on geometric bounds like Signed Distance Fields (SDFs) to guarantee no geometry is missed, this method relies on density thresholds and operates directly on the scalar field values [S1, unofficial]. It differs from [Adaptive Step Size Ray Marching](2312-adaptive-step-size-ray-marching.md) by using a discrete doubling strategy rather than continuous gradient-based scaling [S1, unofficial].

## How it works
**Inputs:**
- Ray origin $\mathbf{o}$ and direction $\mathbf{d}$ (normalized).
- Volume texture $V$ with associated mipmaps.
- Empty density threshold $\tau$ (scalar value below which space is considered empty).
- Initial step size $\Delta s_0$.
- Initial mipmap level offset $m_0$ (index into the mipmap chain).

**Outputs:**
- Composed color and opacity for the pixel.

**Data Structures:**
- Current step size $\Delta s$.
- Current mipmap offset $m$.
- Consecutive empty sample counter $k$ (optional, or tracked by state).

**Algorithm:**
The method modifies the standard front-to-back ray marching loop. At each step, the density is sampled. If the density is below the threshold $\tau$, the step size is doubled, and the mipmap level is increased (coarsening the resolution). If the density is non-empty (above $\tau$), the step size is reset, and the ray position is adjusted to ensure the feature is sampled.

1.  Initialize $\Delta s = \Delta s_0$, $m = m_0$, and current position $\mathbf{p} = \mathbf{o}$.
2.  While the ray is within the volume bounds and opacity $< 1.0$:
    a. Sample the volume at $\mathbf{p}$ using mipmap level $m_0 + m$. Let the density be $\rho = V(\mathbf{p}, m_0 + m)$.
    b. If $\rho < \tau$:
        i. Double the step size: $\Delta s \leftarrow 2 \Delta s$.
        ii. Increment the mipmap offset: $m \leftarrow m + 1$.
        iii. Advance the ray: $\mathbf{p} \leftarrow \mathbf{p} + \Delta s \mathbf{d}$.
    c. Else ($\rho \ge \tau$):
        i. Step back one step: $\mathbf{p} \leftarrow \mathbf{p} - \Delta s \mathbf{d}$.
        ii. Reset step size: $\Delta s \leftarrow \Delta s_0$.
        iii. Reset mipmap offset: $m \leftarrow m_0$.
        iv. Advance one standard step: $\mathbf{p} \leftarrow \mathbf{p} + \Delta s_0 \mathbf{d}$.
        v. Perform standard compositing for this sample.
    d. Perform compositing for the current sample if it was a "standard" step or if the doubling logic dictates accumulation (Note: [S1, unofficial] implies the "step back" logic is to re-sample the feature with higher resolution, implying the doubled step skipped the feature boundary).

**Pseudocode:**
```python
def dynamic_step_adjustment_raymarch(ray_origin, ray_direction, volume_texture, threshold, initial_step, initial_mip_offset):
    p = ray_origin
    step_size = initial_step
    mip_offset = initial_mip_offset
    accumulated_opacity = 0.0
    accumulated_color = (0.0, 0.0, 0.0)
    
    # Pre-calculate inverse direction for bounds check if needed
    # Assume volume bounds are defined by min/max coordinates
    
    while is_inside_volume(p):
        # Sample at current resolution
        density = volume_texture.sample(p, mip_offset + initial_mip_offset)
        
        if density < threshold:
            # Empty space: double step and go coarser
            step_size *= 2.0
            mip_offset += 1
            p += step_size * ray_direction
        else:
            # Non-empty: step back to re-sample the feature boundary accurately
            p -= step_size * ray_direction
            step_size = initial_step
            mip_offset = initial_mip_offset
            
            # Advance one standard step
            p += step_size * ray_direction
            
            # Compositing step (standard front-to-back)
            alpha = 1.0 - exp(-density * step_size) # Example absorption model
            color = volume_texture.sample_color(p, mip_offset + initial_mip_offset)
            
            contribution = alpha * (1.0 - accumulated_opacity)
            accumulated_color += contribution * color
            accumulated_opacity += contribution
            
            if accumulated_opacity >= 1.0:
                break
                
    return accumulated_color, accumulated_opacity
```

**Parameters:**
- $\tau$: Threshold for "empty". Typical value depends on the volume's density range (e.g., 0.01 for normalized density) [S1, unofficial].
- $\Delta s_0$: Initial step size. Must be small enough to capture the finest details of the volume at the base mipmap level [S1, unofficial].
- $m_0$: Base mipmap level. Usually 0 [S1, unofficial].

**Edge Cases and Pitfalls:**
- **Artifacts:** The method may cause visual artifacts in some cases, particularly if the step doubling skips over thin, high-density features that fall between the coarse samples [S1, unofficial].
- **Precision:** Large step sizes may lead to precision issues in floating-point position calculations over long rays [S1, unofficial].
- **Performance:** The performance gains are described as "small" in some contexts, and the overhead of mipmap selection and conditional branching may negate benefits in dense volumes [S1, unofficial].

## Subtopics

### Gradient-driven Sampling
Gradient-driven Sampling is a variant that adjusts step sizes based on the magnitude of the scalar field gradient $|\nabla s|$, which indicates local feature sharpness [S2]. It takes smaller steps near high-gradient regions resembling surfaces to capture transitions accurately, and larger steps in smooth interiors [S2]. The step size is dynamically adjusted based on the gradient direction and a threshold, bounded by minimum and maximum distances to prevent under- or over-sampling [S2]. This method achieves efficiency gains of 2-3x over uniform sampling without aliasing artifacts in boundary-heavy volumes like CT angiography data [S2].

## Operating characteristics
- **Time Complexity:** $O(N)$ where $N$ is the number of samples, but $N$ is significantly reduced in empty regions compared to uniform sampling. The reduction factor depends on the sparsity of the volume.
- **Memory Complexity:** $O(1)$ additional memory per ray, plus the storage for the mipmap chain [S1, unofficial].
- **Performance:** Provides small performance gains in sparse volumes like volumetric clouds [S1, unofficial]. Gradient-driven variants report 2-3x efficiency gains in boundary-heavy volumes [S2].
- **Strengths:** Simple to implement; effective for sparse, large-scale volumes like clouds or fog [S1, unofficial].
- **Limitations:** May cause artifacts if the step doubling skips thin features; gains are small in dense volumes; requires mipmap chain [S1, unofficial].
- **When to use:** Volumetric clouds, fog, or other sparse volumes where large empty spaces dominate the ray path [S1, unofficial].
- **When not to use:** Dense volumes with fine, thin details that might be skipped by doubling steps; scenes requiring strict geometric accuracy without post-processing refinement [S1, unofficial].

## Background
The technique of dynamically adjusting step sizes based on density emptiness is used in real-time volume rendering, particularly for atmospheric effects like clouds [S1, unofficial]. It is often employed in game engines to optimize the rendering of volumetric clouds by skipping empty sky regions [S1, unofficial]. The specific "step back and double" logic is described in the context of implementing volumetric cloud effects in games [S1, unofficial]. Gradient-driven sampling is a broader category of adaptive sampling used in medical imaging and scientific visualization to handle high-frequency details [S2].
