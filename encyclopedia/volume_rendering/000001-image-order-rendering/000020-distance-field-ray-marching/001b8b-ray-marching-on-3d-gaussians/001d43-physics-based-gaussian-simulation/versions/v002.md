# Physics-based Gaussian Simulation
## Overview
Physics-based Gaussian Simulation is a method that integrates physics-based continuum mechanics directly within 3D Gaussian Splatting (3DGS), treating each Gaussian as a discrete physical particle with volume for direct simulation [S1][S2, unofficial]. It solves the problem of animating 3D representations by creating a unified simulation-to-rendering pipeline, allowing for physically accurate dynamics rather than relying on pre-recorded motion or simple deformation [S1][S2, unofficial]. It sets itself apart from standard 3DGS by embedding physical laws into the representation itself, enabling the Gaussians to behave like material particles [S1][S2, unofficial].

def physics_based_gaussian_simulation(gaussians, dt, gravity):
    """
    Simulate physics for a set of 3D Gaussians.
    :param gaussians: List of Gaussian objects with attributes p, volume, v.
    :param dt: Time step.
    :param gravity: Gravity vector.
    """
    # Step 1: Treat each Gaussian as a discrete physical particle with volume [S1][S2, unofficial].
    # Step 2: Integrate physics-based continuum mechanics directly within 3DGS [S1][S2, unofficial].
    for g in gaussians:
        # External force (e.g., gravity)
        force = gravity * g.volume  # Volume acts as mass proxy [G]
        # Internal forces (e.g., pressure, viscosity) for Position-Based Fluids [S2, unofficial]

        g.velocity += force * dt / g.volume
        g.position += g.velocity * dt
    # Step 3: Reconstruct surfaces and disentangle objects for active simulation using a mesh-based framework [S2, unofficial].
    # Not given in the sources.
    return gaussians

## Background
**Origin:** PhysGaussian integrates physics-based continuum mechanics directly within 3DGS [S1][S2, unofficial]. Gaussian Splashing performs physical simulations using Position-Based Fluids [S2, unofficial].
**History:** Developed as part of the evolution of 3DGS to enable animation and recreate dynamic behavior in 3D representations [S1][S2, unofficial].
**Usage:** Used for physically accurate simulation of 3D representations, including fluid simulation and mesh-based frameworks with attached Gaussians for texture rendering [S2, unofficial].
