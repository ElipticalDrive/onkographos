# Spherical Beta View-Dependent Color

Also called: Beta Splatting, Spherical Beta (SB) appearance model, Spherical Beta lobes

## Overview
Spherical Beta (SB) is a specular appearance model that adds explicit specular lobes on top of a diffuse base color, used for view-dependent color in 3D Gaussian Splatting [S1, S2, unofficial]. It is distinct from Spherical Harmonics (SH) by using a parametric lobe function rather than a global basis expansion, allowing for sharper highlights with fewer parameters [S2, unofficial]. It is orthogonal to SH, where SH (typically degree 0) supplies the diffuse base and SB adds the specular component [S2, unofficial].

## How it works
### Inputs and Outputs
**Inputs:**
- Gaussian splat parameters: position, covariance (or scale/rotation), opacity, and base color.
- SH coefficients (optional, typically degree 0 for SB-only specular, or degree 3 for hybrid) [S2, unofficial].
- SB lobe parameters: number of lobes ($N_{lobes}$), axis direction, sharpness, and color [S1, S2, unofficial].

**Outputs:**
- Final pixel color for each splat during rasterization [S1, unofficial].

### Data Structures
Each SB lobe stores 6 floats in the following order: $[r, g, b, \theta, \phi, \beta]$ [S2, unofficial].
- $r, g, b$: Color components of the lobe.
- $\theta, \phi$: Spherical angles defining the lobe axis direction.
- $\beta$: Sharpness parameter.

During preprocessing (load time), lobe parameters are converted and stored as half floats (16-bit) [S1, unofficial]. One 16-byte texel is stored per lobe per splat [S1, unofficial].

### Numbered Steps
1. **Preprocessing**: Convert lobe parameters (axis from spherical angles $\theta, \phi$, sharpness $\beta$, and activated color $rgb$) into half-floats [S1, unofficial].
2. **Densification**: Handle the `sb_number` parameter through densification strategies (DefaultStrategy and MCMCStrategy) [S2, unofficial].
3. **Rendering**: For each splat, compute the color contribution of each lobe [S1, unofficial].
4. **Composition**: Add the lobe contributions to the base color (from SH or base color) [S1, unofficial].
5. **Clamping**: Clamp the base color to zero before adding lobe contributions to prevent negative base colors from absorbing part of the highlight [S1, unofficial].
6. **Export**: Export SB parameters to PLY files via additive properties named `sb_params_*`, matching the reference implementation's naming convention [S2, unofficial]. Leave standard `f_dc_*` / `f_rest_*` schema untouched [S2, unofficial].

### Formulas
The color contribution of each lobe is calculated as [S1, unofficial]:

$$
C_{lobe} = \text{softplus}(rgb) \cdot \max(\text{dot}(dir, axis), 0)^{4 \cdot \exp(\beta)}
$$

Where:
- $dir$: View direction vector.
- $axis$: Lobe axis direction vector derived from $\theta, \phi$.
- $rgb$: Color components of the lobe.
- $\beta$: Sharpness parameter.
- $\text{softplus}(x) = \ln(1 + e^x)$ [S1, unofficial].

The final color is:

$$
C_{final} = \max(C_{base}, 0) + \sum_{i=1}^{N_{lobes}} C_{lobe, i}
$$

Where $C_{base}$ is the color from SH degree 0 or base color [S1, unofficial].

### Parameters
- **Number of lobes ($N_{lobes}$)**: Up to 4 lobes are rendered. The trainers default to 2 lobes [S1, unofficial].
- **sh_degree**: The degree of spherical harmonics used for the diffuse base. Typical value: 0 (for SB-only specular) or 3 (default in nerfstudio) [S2, unofficial].
- **sb_number**: The number of SB lobes to use. Typical values: 0 (purely diffuse), 2 (Beta Splatting setting) [S2, unofficial].

### Edge Cases and Pitfalls
- **Negative Base Colors**: The base color must be clamped to zero before adding lobe contributions. Many splats have negative base colors, which would otherwise absorb part of the highlight [S1, unofficial].
- **Format Support**: Compressed PLY, SOG, and SPZ formats currently do not support lobe data storage. Only uncompressed PLY is supported [S1, unofficial].
- **Beta Kernel**: This implementation only covers the Spherical Beta color lobes, not the Beta kernel. The Beta kernel replaces the Gaussian falloff with opacity * $(1 - r^2)^\beta$ and a hard cutoff, and requires changes to quad extent, bounds/culling, and per-splat values. Files using the kernel will not render correctly with this PR [S1, unofficial].
- **Splat with Lobes but no SH**: For splats with lobes but no SH, the color is re-evaluated as the camera moves [S1, unofficial].
- **Rejection of Unsupported Formats**: The splat and ply_compressed formats reject SB lobes rather than dropping them silently [S2, unofficial].

### Pseudocode
```python
def compute_spherical_beta_color(splat, view_dir):
    """
    Compute the final color for a splat using Spherical Beta lobes.
    
    Args:
        splat: Object containing:
            - base_color: Color from SH degree 0 or base color (3 floats)
            - lobes: List of lobe parameters, each being [r, g, b, theta, phi, beta]
            - sb_number: Number of lobes to use
        view_dir: View direction vector (3 floats)
        
    Returns:
        Final color (3 floats)
    """
    # Clamp base color to zero to prevent absorption of highlights
    base_color = max(splat.base_color, 0.0)
    
    total_lobe_color = [0.0, 0.0, 0.0]
    
    # Iterate over the specified number of lobes
    for i in range(splat.sb_number):
        lobe = splat.lobes[i]
        r, g, b, theta, phi, beta = lobe
        
        # Convert spherical angles to axis vector
        axis = spherical_to_cartesian(theta, phi)
        
        # Compute dot product
        dot_product = dot(view_dir, axis)
        
        # Compute lobe contribution
        # softplus(rgb)
        softplus_rgb = [
            log(1 + exp(r)),
            log(1 + exp(g)),
            log(1 + exp(b))
        ]
        
        # max(dot(dir, axis), 0)^(4 * exp(beta))
        exponent = 4.0 * exp(beta)
        lobe_factor = max(dot_product, 0.0) ** exponent
        
        # Add to total lobe color
        total_lobe_color[0] += softplus_rgb[0] * lobe_factor
        total_lobe_color[1] += softplus_rgb[1] * lobe_factor
        total_lobe_color[2] += softplus_rgb[2] * lobe_factor
        
    # Final color
    final_color = [
        base_color[0] + total_lobe_color[0],
        base_color[1] + total_lobe_color[1],
        base_color[2] + total_lobe_color[2]
    ]
    
    return final_color

def spherical_to_cartesian(theta, phi):
    """
    Convert spherical angles to Cartesian coordinates.
    
    Args:
        theta: Polar angle (0 to pi)
        phi: Azimuthal angle (0 to 2*pi)
        
    Returns:
        Cartesian vector (3 floats)
    """
    x = sin(theta) * cos(phi)
    y = sin(theta) * sin(phi)
    z = cos(theta)
    return [x, y, z]
```

## Operating characteristics
- **Time Complexity**: The shader computes one `pow` operation per lobe [S1, unofficial]. With up to 4 lobes, this is a constant number of operations per splat.
- **Memory Complexity**: Each lobe stores 6 floats. With 2 lobes, this is 12 floats per splat, compared to 45 floats for SH bands 1-3 [S1, unofficial].
- **Measured Performance**:
  - On MipNeRF-360 (7 scenes, 30k steps, RTX 4090):
    - MCMC SH0/SB2: 29.602 dB PSNR, 104 MB PLY size, 0.91 GB Peak VRAM, 52.0 FPS, 487s train time [S2, unofficial].
    - Default SH0/SB2: 29.465 dB PSNR, 332 MB PLY size, 2.17 GB Peak VRAM, 31.1 FPS, 616s train time [S2, unofficial].
  - Comparison to SH3/SB0:
    - MCMC SH0/SB2 vs MCMC SH3/SB0: +0.15 dB PSNR, -56% PLY size, -39% Peak VRAM, +19% Render speed, -5% Train time [S2, unofficial].
    - Default SH0/SB2 vs Default SH3/SB0: +0.30 dB PSNR, -54% PLY size, -53% Peak VRAM, +5% Render speed, -16% Train time [S2, unofficial].
- **Strengths**: Higher PSNR, smaller model size (44-46% of SH3), roughly half the peak VRAM, faster render speed, and faster training time compared to SH degree 3 [S2, unofficial].
- **Limitations**: Only uncompressed PLY is supported for lobe data storage [S1, unofficial]. The Beta kernel is not included, which would require more extensive changes to the renderer [S1, unofficial].
- **When to Use**: When view-dependent specular highlights are important and computational efficiency is a priority. SB is a strict win over SH3 in terms of PSNR, size, VRAM, and speed [S2, unofficial].
- **When Not to Use**: When compressed PLY, SOG, or SPZ formats are required, as they do not support lobe data storage [S1, unofficial]. When the Beta kernel is needed for more accurate Gaussian falloff modeling [S1, unofficial].

## Background
Spherical Beta (SB) is the specular model from Deformable Beta Splatting (Liu et al., SIGGRAPH 2025) [S1, unofficial]. It was integrated into the PlayCanvas engine (Pull Request #9729) for WebGL2 and WebGPU, and into the nerfstudio-project/gsplat (Pull Request #1056) for training and export [S1, S2, unofficial]. The model was designed to provide higher PSNR and faster speed at half the size and memory than SH degree 3 [S1, unofficial].
