# Sphere Tracing with Composite SDF and Adaptive Sampling

Also called: Ray Marching with Character SDFs, SDF Sphere Tracing with Letter/Arc Geometry, SDF-Sphere-Tracing

## Overview
This method extends standard sphere tracing to render scenes composed of primitive shapes, character segments (letters), and arcs using Signed Distance Functions (SDFs) [S1, unofficial]. It integrates a path tracer with up to 3 bounces, handling distinct hit types (DIFFUSE, LETTER, ARC, SUN) with specific shading and reflection logic [S1, unofficial]. The rendering employs adaptive sampling with variance-based convergence to determine when sufficient samples have been collected for each pixel [S1, unofficial]. It is distinguished from sibling methods by its explicit handling of non-primitive character geometry via segment projection and its specific adaptive convergence criteria based on luminance variance [S1, unofficial].

## How it works
### Inputs and Outputs
**Inputs:**
*   Camera parameters: Origin $\mathbf{o}$, direction vectors, width, height, Field of View (FOV = 32 degrees) [S1, unofficial].
*   Scene data:
    *   `shapes`: List of primitive SDF objects (e.g., boxes) with a `Distance(p)` method [S1, unofficial].
    *   `characters`: List of `vec3` pairs representing line segments (letters). Index $j$ is start, $j+1$ is end [S1, unofficial].
    *   `arcs`: List of arc objects with a `distance(p)` method [S1, unofficial].
    *   `surronding_bbox`: A bounding box SDF used for acceleration culling [S1, unofficial].
    *   `mats`: List of materials with `bsdf_sample` and `isSpecular` methods [S1, unofficial].
*   Parameters: `thicc` = 0.6f, `bbox_threshold` = 5.5f, `smallStep` = 0.001f, `maximum_hit_distance` = 1000.0f, `minimum_hit_distance` = 0.0001f, `maximum_step` = 1024 [S1, unofficial].

**Outputs:**
*   Final image buffer with tone-mapped RGB values [S1, unofficial].

### Data Structures
*   `Ray`: Struct with `vec3 o` (origin) and `vec3 d` (direction) [S1, unofficial].
*   `Shape`: Abstract base class with virtual `float Distance(vec3 p)` and material pointer [S1, unofficial].
*   `Arc`: Object with `float distance(vec3 p)` method [S1, unofficial].
*   `Material`: Abstract base class with virtual `vec3 bsdf_sample(const vec3& dir_in, const vec3& n)` and `bool isSpecular()` [S1, unofficial].
*   `ONB`: Orthonormal Basis constructed from a normal vector, providing `u`, `v`, `w` axes [S1, unofficial].

### Algorithm Steps

1.  **Ray Generation**: For each pixel $(i, j)$, generate a ray $\mathbf{r}$ using a pinhole camera model with 32-degree FOV [S1, unofficial].
2.  **Adaptive Sampling Loop**:
    *   Initialize `sum` (color accumulator) to $\mathbf{0}$, `sum_square` (luminance squared sum) to $0$, `sum_so_far` (luminance sum) to $0$, and `num_sample_used` to $0$ [S1, unofficial].
    *   Loop with step size `step` = 16 up to `ns` = 16 total samples:
        *   For `num` from 0 to `step`-1:
            *   Generate a jittered ray $\mathbf{r}$ for the pixel [S1, unofficial].
            *   Compute radiance $\mathbf{C} = \text{PathTrace}(\mathbf{r})$ [S1, unofficial].
            *   Add $\mathbf{C}$ to `sum` [S1, unofficial].
            *   Compute luminance $L = 0.2126 C_x + 0.7152 C_y + 0.0722 C_z$ [S1, unofficial].
            *   Update `sum_square += L^2` and `sum_so_far += L` [S1, unofficial].
        *   Update `num_sample_used += step` [S1, unofficial].
        *   Compute mean $\mu = \frac{\text{sum\_so\_far}}{\text{num\_sample\_used}}$ and variance $\sigma^2 = \frac{\text{sum\_square}}{\text{num\_sample\_used}} - \mu^2$ [S1, unofficial].
        *   Check convergence: If $\sigma^2 < 0.0001$ and $\min(C_x, C_y, C_z) > 0.2$ for the current sample average, stop sampling for this pixel [S1, unofficial].
3.  **Path Tracing** (for a single ray $\mathbf{r}$):
    *   Initialize radiance $\mathbf{L} = \mathbf{0}$ and throughput $\mathbf{T} = (1, 1, 1)$ [S1, unofficial].
    *   Loop `bounce` from 0 to 2:
        *   Call `SphereTrace` with current ray $\mathbf{r}$ to find hit distance $t$, hit point $\mathbf{p}$, and hit type [S1, unofficial].
        *   If no hit (miss):
            *   Add $\mathbf{T} \times (50, 80, 100)$ to $\mathbf{L}$ [S1, unofficial].
            *   Return $\mathbf{L}$ [S1, unofficial].
        *   Update throughput: $\mathbf{T} \leftarrow \mathbf{T} \times 0.2$ [S1, unofficial].
        *   **If HIT_TYPE == DIFFUSE**:
            *   Compute normal $\mathbf{n}$ from the shape's SDF gradient [S1, unofficial].
            *   Sample BSDF to get new direction $\mathbf{d}_{new}$ using ONB [S1, unofficial].
            *   Create shadow ray towards light direction $(0.6, 0.6, 1.0)$ normalized [S1, unofficial].
            *   If shadow ray hits SUN:
                *   Compute incident factor (cosine of angle) [S1, unofficial].
                *   Add $\mathbf{T} \times (500, 400, 100) \times \text{incident}$ to $\mathbf{L}$ [S1, unofficial].
            *   Update $\mathbf{r}$ origin to $\mathbf{p} + \mathbf{n} \times 0.1$ and direction to $\mathbf{d}_{new}$ [S1, unofficial].
        *   **If HIT_TYPE == LETTER or ARC**:
            *   Compute normal $\mathbf{n}$ using central finite differences with `smallStep` = 0.001f [S1, unofficial]:
                $$ \mathbf{n} = \text{normalize}\left( \frac{f(\mathbf{p} + \Delta x) - f(\mathbf{p} - \Delta x)}{2\Delta x}, \frac{f(\mathbf{p} + \Delta y) - f(\mathbf{p} - \Delta y)}{2\Delta y}, \frac{f(\mathbf{p} + \Delta z) - f(\mathbf{p} - \Delta z)}{2\Delta z} \right) $$
            *   Compute reflected direction $\mathbf{d}_{refl} = \mathbf{r}.d - 2(\mathbf{r}.d \cdot \mathbf{n})\mathbf{n}$ [S1, unofficial].
            *   Offset hit point: $\mathbf{p} \leftarrow \mathbf{p} + \mathbf{n} \times 0.2$ [S1, unofficial].
            *   Update $\mathbf{r}$ origin to $\mathbf{p} + \mathbf{n} \times 0.1$ and direction to normalized $\mathbf{d}_{refl}$ [S1, unofficial].
        *   **If HIT_TYPE == SUN**:
            *   Add $\mathbf{T} \times (50, 80, 100)$ to $\mathbf{L}$ [S1, unofficial].
            *   Return $\mathbf{L}$ [S1, unofficial].
4.  **Sphere Tracing** (finding closest hit):
    *   Initialize $t = 0$, `mint` = $\infty$, `hit_type` = UNKNOWN [S1, unofficial].
    *   Loop `i` from 0 to `maximum_step` (1024):
        *   If $t > 1000.0$, return MISS [S1, unofficial].
        *   Current position $\mathbf{p} = \mathbf{r}.o + \mathbf{r}.d \times t$ [S1, unofficial].
        *   **Check Primitives**: For each shape $j$, compute $d = \text{shapes}[j].\text{Distance}(\mathbf{p})$. If $d < \text{mint}$, update `mint` = $d$, `hit_type` = DIFFUSE, `shape_id` = $j$ [S1, unofficial].
        *   **Check Acceleration**: Compute $d_{bbox} = \text{surronding\_bbox}.\text{Distance}(\mathbf{p})$ [S1, unofficial].
        *   If $d_{bbox} < 5.5$:
            *   **Check Letters**: Iterate characters in pairs ($j, j+1$):
                *   $\mathbf{begin} = \text{characters}[j]$, $\mathbf{end} = \text{characters}[j+1]$ [S1, unofficial].
                *   $\mathbf{seg} = \mathbf{end} - \mathbf{begin}$ [S1, unofficial].
                *   Project $\mathbf{p}$ onto segment: $u = -\min\left(\frac{(\mathbf{begin} - \mathbf{p}) \cdot \mathbf{seg}}{\|\mathbf{seg}\|^2}, 0\right)$ [S1, unofficial].
                *   Clamp $u = \min(u, 1.0)$ [S1, unofficial].
                *   Closest point $\mathbf{c} = \mathbf{begin} + u \times \mathbf{seg}$ [S1, unofficial].
                *   Distance $d = \|\mathbf{p} - \mathbf{c}\| - 0.6$ [S1, unofficial].
                *   If $d < \text{mint}$, update `mint` = $d$, `hit_type` = LETTER, `character_id` = $j$ [S1, unofficial].
            *   **Check Arcs**: For each arc $j$, compute $d = \text{arcs}[j].\text{Distance}(\mathbf{p})$. If $d < \text{mint}$, update `mint` = $d$, `hit_type` = ARC, `arc_id` = $j$ [S1, unofficial].
        *   Advance ray: $t \leftarrow t + \text{mint}$ [S1, unofficial].
        *   If `mint` < 0.0001:
            *   Check for SUN: If $19.9 - \mathbf{p}.y < 0$, `hit_type` = SUN [S1, unofficial].
            *   Return HIT with $t$, $\mathbf{p}$, `hit_type` [S1, unofficial].
5.  **Tone Mapping**:
    *   For each pixel color $\mathbf{C}$:
        *   Add bias: $\mathbf{C} \leftarrow \mathbf{C} + \frac{14}{241}$ [S1, unofficial].
        *   Reinhard tone mapping: $\mathbf{C}_{final} = \frac{\mathbf{C}}{\mathbf{C} + 1} \times 255$ [S1, unofficial].
        *   Convert to 8-bit integer [S1, unofficial].

### Pseudocode

```python
import math
import random

def sphere_tracing(ray_o, ray_d, shapes, characters, arcs, surrounding_bbox, max_steps=1024, max_dist=1000.0, min_dist=0.0001):
    """
    Core sphere tracing loop for composite SDF scene.
    Returns (hit, t, hit_point, hit_type, shape_id, char_id, arc_id)
    """
    t = 0.0
    mint = float('inf')
    hit_type = None
    shape_id = None
    char_id = None
    arc_id = None

    for _ in range(max_steps):
        if t > max_dist:
            return False, None, None, None, None, None, None

        p = ray_o + t * ray_d

        # Check primitive shapes
        for j, shape in enumerate(shapes):
            d = shape.distance(p)
            if d < mint:
                mint = d
                hit_type = 'DIFFUSE'
                shape_id = j

        # Check acceleration box
        dist_bbox = surrounding_bbox.distance(p)
        
        if dist_bbox < 5.5:
            # Check letters (characters are pairs)
            for j in range(0, len(characters), 2):
                begin = characters[j]
                end = characters[j+1]
                seg = end - begin
                seg_len_sq = seg.dot(seg)
                
                if seg_len_sq == 0:
                    continue

                # Projection parameter
                # begin_x = -min( (begin - p) . seg / seg_len_sq, 0.0 )
                dot_val = (begin - p).dot(seg) / seg_len_sq
                begin_x = -min(dot_val, 0.0)
                begin_x = min(begin_x, 1.0)
                
                hit_point_letter = begin + begin_x * seg
                d = (p - hit_point_letter).length() - 0.6 # thicc = 0.6
                
                if d < mint:
                    mint = d
                    hit_type = 'LETTER'
                    char_id = j

            # Check arcs
            for j, arc in enumerate(arcs):
                d = arc.distance(p)
                if d < mint:
                    mint = d
                    hit_type = 'ARC'
                    arc_id = j

        t += mint

        if mint < min_dist:
            # Check for SUN
            sun_check = 19.9 - p.y
            if sun_check < 0.0:
                hit_type = 'SUN'
            
            hit_point = ray_o + t * ray_d
            return True, t, hit_point, hit_type, shape_id, char_id, arc_id

    return False, None, None, None, None, None, None

def path_trace(ray_o, ray_d, shapes, characters, arcs, mats, surrounding_bbox):
    """
    Path tracer with up to 3 bounces.
    """
    L = vec3(0.0, 0.0, 0.0)
    T = vec3(1.0, 1.0, 1.0)
    light_dir = vec3(0.6, 0.6, 1.0).normalize()
    bg_color = vec3(50.0, 80.0, 100.0)
    sun_color = vec3(500.0, 400.0, 100.0)

    for bounce in range(3):
        hit, t, hit_point, hit_type, shape_id, char_id, arc_id = sphere_tracing(ray_o, ray_d, shapes, characters, arcs, surrounding_bbox)
        
        if not hit:
            L += T * bg_color
            return L

        T *= 0.2

        if hit_type == 'DIFFUSE':
            # Compute normal from shape SDF
            normal = compute_normal(hit_point, shapes[shape_id])
            
            # Sample BSDF
            mat = mats[shape_id]
            coord = mat.bsdf_sample(ray_d, normal)
            onb = ONB(normal)
            new_dir = coord.x * onb.u + coord.y * onb.v + coord.z * onb.w
            
            # Shadow ray
            shadow_hit, shadow_t, shadow_p, shadow_type, _, _, _ = sphere_tracing(hit_point, light_dir, shapes, characters, arcs, surrounding_bbox)
            
            if shadow_hit and shadow_type == 'SUN':
                # Incident factor (cosine)
                incident = max(0.0, new_dir.dot(light_dir)) # Simplified, assuming new_dir is towards light
                L += T * sun_color * incident
            
            ray_o = hit_point + normal * 0.1
            ray_d = new_dir.normalize()

        elif hit_type in ('LETTER', 'ARC'):
            small_step = 0.001
            if hit_type == 'LETTER':
                dx = compute_distance_letter_optimize(hit_point + vec3(small_step, 0, 0), characters, char_id) - \
                     compute_distance_letter_optimize(hit_point - vec3(small_step, 0, 0), characters, char_id)
                dy = compute_distance_letter_optimize(hit_point + vec3(0, small_step, 0), characters, char_id) - \
                     compute_distance_letter_optimize(hit_point - vec3(0, small_step, 0), characters, char_id)
                dz = compute_distance_letter_optimize(hit_point + vec3(0, 0, small_step), characters, char_id) - \
                     compute_distance_letter_optimize(hit_point - vec3(0, 0, small_step), characters, char_id)
            else: # ARC
                dx = arcs[arc_id].distance(hit_point + vec3(small_step, 0, 0)) - arcs[arc_id].distance(hit_point - vec3(small_step, 0, 0))
                dy = arcs[arc_id].distance(hit_point + vec3(0, small_step, 0)) - arcs[arc_id].distance(hit_point - vec3(0, small_step, 0))
                dz = arcs[arc_id].distance(hit_point + vec3(0, 0, small_step)) - arcs[arc_id].distance(hit_point - vec3(0, 0, small_step))
            
            normal = vec3(dx, dy, dz).normalize()
            reflected_dir = ray_d - 2.0 * ray_d.dot(normal) * normal
            
            hit_point += normal * 0.2
            ray_o = hit_point + normal * 0.1
            ray_d = reflected_dir.normalize()

        elif hit_type == 'SUN':
            L += T * bg_color
            return L

    return L

def compute_distance_letter_optimize(position, characters, char_id):
    """
    Computes distance to a specific letter segment pair.
    """
    begin = characters[char_id]
    end = characters[char_id + 1]
    seg = end - begin
    seg_len_sq = seg.dot(seg)
    
    if seg_len_sq == 0:
        return position.length()

    dot_val = (begin - position).dot(seg) / seg_len_sq
    begin_x = -min(dot_val, 0.0)
    begin_x = min(begin_x, 1.0)
    
    hit_point_letter = begin + begin_x * seg
    d = (position - hit_point_letter).length() - 0.6
    return d

    shapes = initialize_shapes()
    characters = initialize_characters()
    arcs = initialize_arcs()
    surrounding_bbox = initialize_bbox()
    mats = [diffuse_room]

    ns = 16
    step = 16
    convergence_rate = 0.0001
    
    image = []

    for j in range(height):
        for i in range(width):
            sum_color = vec3(0.0, 0.0, 0.0)
            sum_lum_sq = 0.0
            sum_lum = 0.0
            num_samples = 0
            converged = False

            for s in range(0, ns, step):
                for _ in range(step):
                    # Generate jittered ray
                    p = ((i + random.random()) / width)
                    q = ((j + random.random()) / height)
                    ray = camera_generate_ray(p, q)
                    
                    color = path_trace(ray.o, ray.d, shapes, characters, arcs, mats, surrounding_bbox)
                    sum_color += color
                    
                    lum = 0.2126 * color.x + 0.7152 * color.y + 0.0722 * color.z
                    sum_lum_sq += lum * lum
                    sum_lum += lum
                
                num_samples += step
                mean_lum = sum_lum / num_samples
                var_lum = (sum_lum_sq / num_samples) - (mean_lum ** 2)
                
                # Check convergence
                # Note: The source checks min color component > 0.2f on the *current* sample's color?
                # Or the accumulated? The source says: "If variance < convergence_rate and min color component > 0.2f, stop"
                # It implies checking the current batch or total. Given the loop structure, it likely checks the current state.
                # However, 'min color component' usually refers to the average color so far or the latest sample.
                # The source code snippet:
                # float mean = sum_so_far / num_sample_used;
                # float variance = sum_square / num_sample_used - mean * mean;
                # if (variance < convergence_rate && min(sum * ins) > 0.2f) ...
                # So it checks the average color of all samples so far.
                
                avg_color = sum_color / num_samples
                if var_lum < convergence_rate and min(avg_color.x, avg_color.y, avg_color.z) > 0.2:
                    converged = True
                    break
            
            if not converged:
                avg_color = sum_color / ns
            
            # Tone mapping
            final_color = avg_color + vec3(14.0/241.0, 14.0/241.0, 14.0/241.0)
            final_color = vec3(
                final_color.x / (final_color.x + 1.0) * 255.0,
                final_color.y / (final_color.y + 1.0) * 255.0,
                final_color.z / (final_color.z + 1.0) * 255.0
            )
            image.append(final_color)

    return image
```

### Edge Cases and Pitfalls
*   **Normal Estimation**: Finite differences for SDFs require a small step size (0.001f) to balance precision and noise [S1, unofficial].
*   **Self-Intersection**: Ray origins are offset by `normal * 0.1` after a hit to prevent self-intersection [S1, unofficial].
*   **Letter Projection**: The projection parameter $u$ must be clamped to $[0, 1]$ to ensure the closest point lies on the segment [S1, unofficial].
*   **SUN Detection**: The SUN is detected based on the Y-coordinate of the hit point ($19.9 - y < 0$), which is a scene-specific heuristic [S1, unofficial].

## Operating characteristics
*   **Time Complexity**: $O(N \cdot M \cdot B)$, where $N$ is the number of pixels, $M$ is the number of shapes/letters/arcs, and $B$ is the number of bounces (3) [S1, unofficial]. Adaptive sampling may reduce effective $N$ if convergence is reached early.
*   **Memory Complexity**: $O(M)$ for storing scene geometry [S1, unofficial].
*   **Performance**: The method uses a simple bounding box acceleration for letters/arcs, which is less efficient than a BVH but sufficient for small scenes [S1, unofficial]. The use of `step` = 16 for adaptive sampling reduces variance checks overhead [S1, unofficial].
*   **Strengths**: Simple implementation, handles complex character geometry via SDFs, adaptive sampling reduces noise in uniform areas [S1, unofficial].
*   **Limitations**: No global illumination beyond direct lighting and simple reflections (no indirect diffuse bounces for letters/arcs, only specular-like reflection), limited to 3 bounces, SUN detection is hardcoded [S1, unofficial].
