# SDF Scaling and Early Ray Termination for Fast Sphere Tracing

Also called: SDF Scaling, Two-pass SDF Scaling

## Overview
This method accelerates sphere tracing by using a two-pass approach: a low-resolution pre-pass that applies Signed Distance Function (SDF) scaling and early termination to generate a coarse distance buffer, followed by a full-resolution pass that uses this buffer to initialize ray origins closer to surfaces [S1]. It distinguishes itself from sibling methods like [Standard Constant Step Ray Marching](1080-standard-constant-step-ray-marching.md) and [Sphere Tracing](1674-sphere-tracing.md) by explicitly modifying the SDF geometry in the pre-pass to prevent missed small features and reduce step counts, while using a single low-resolution buffer instead of a filtered pyramid to reduce memory cost and complexity compared to [Inverse Pyramid Rendering](1080-standard-constant-step-ray-marching.md) [S1].

## How it works
The method operates in two distinct passes [S1]. The first pass renders at a reduced resolution to create a "head start" for the second pass [S1]. The second pass performs full-resolution sphere tracing, initializing rays based on the distance data from the first pass [S1].

### Inputs and Outputs
*   **Inputs**:
    *   Scene definition containing implicit surfaces defined by SDFs $f(\mathbf{p})$ [S1].
    *   Camera parameters (origin $\mathbf{o}$, direction $\mathbf{d}$) [S1].
    *   Target resolution $R_{target}$ (e.g., 3840x2160) [S1].
    *   Low-resolution scale factor $s$ (e.g., $s=4$, resulting in $R_{low} = R_{target}/s$) [S1].
    *   Convergence threshold $\epsilon_{base}$ (standard for full res) [G].
    *   Early termination threshold $\epsilon_{early}$ (larger than $\epsilon_{base}$) [S1].
    *   Shadow hardness parameter $k$ (optional, for shadow rays) [S1].
*   **Outputs**:
    *   Final rendered image at $R_{target}$ [S1].
    *   Intermediate low-resolution distance buffer $B_{low}$ of size $R_{low}$ [S1].

### Data Structures
*   **Low-Resolution Buffer ($B_{low}$)**: A 2D array of size $W_{low} \times H_{low}$, where $W_{low} = W_{target}/s$ and $H_{low} = H_{target}/s$ [S1]. Each element stores a scalar distance value $d_{approx}$ [S1].
*   **Ray Batch Mapping**: Each pixel $(u_{low}, v_{low})$ in $B_{low}$ corresponds to an $s \times s$ block of pixels in the full-resolution image [S1]. For $s=4$, 16 full-resolution rays share the same $d_{approx}$ value [S1].

### SDF Scaling Logic
Before rendering in the low-resolution pass, the SDF values are modified based on the camera's position relative to the implicit surface [S1]. This ensures that small objects are not missed due to the lower sampling rate [S1].

1.  **Camera Position Check**: For each ray, evaluate the SDF at the camera origin to determine if the camera is "in front" (outside) or "behind" (inside) the surface [S1].
    *   Let $d_{cam} = f(\mathbf{o})$.
    *   If $d_{cam} > 0$, the camera is outside.
    *   If $d_{cam} < 0$, the camera is inside.
2.  **Scaling Operation**:
    *   **Outside ($d_{cam} > 0$)**: Inflate the SDF. The effective distance function becomes $f'(\mathbf{p}) = f(\mathbf{p}) + \delta$, where $\delta > 0$ is a scaling offset [S1]. This expands the footprint of the surface, ensuring it covers more pixels in the low-res buffer.
    *   **Inside ($d_{cam} < 0$)**: Deflate the SDF. The effective distance function becomes $f'(\mathbf{p}) = f(\mathbf{p}) - \delta$ [S1]. This contracts the volume.
    *   **Hole Handling**: For SDFs representing holes (created via subtraction operations), the logic is inverted to improve approximation:
        *   If camera is in front ($d_{cam} > 0$), decrease the volume size of the hole-generating SDF (deflate) [S1].
        *   If camera is behind ($d_{cam} < 0$), scale up the hole-generating SDF (inflate) [S1].

### Early Ray Termination (Pass 1)
During the low-resolution sphere tracing, the convergence threshold is increased to $\epsilon_{early}$, where $\epsilon_{early} > \epsilon_{base}$ [S1].
*   **Termination Condition**: The ray marching loop terminates when $f'(\mathbf{p}) < \epsilon_{early}$ [S1].
*   **Purpose**: This provides a fast, approximate distance to the surface and prevents rays from overshooting small features that might be missed at low resolution [S1].
*   **Trade-off**: Higher $\epsilon_{early}$ values cause edges to appear rounded and reduce geometric accuracy [S1].

### Step-by-Step Algorithm

#### Pass 1: Low-Resolution Pre-processing
1.  Initialize $B_{low}$ with $t_{max}$ (or infinity) [G].
2.  For each pixel $(u_{low}, v_{low})$ in $B_{low}$:
    a.  Construct ray $\mathbf{r}(t) = \mathbf{o} + t\mathbf{d}$ corresponding to the low-res pixel [S1].
    b.  Evaluate $d_{cam} = f(\mathbf{o})$ once to determine scaling direction [S1].
    c.  Initialize $t = 0$ [G].
    d.  Loop:
        i.  Evaluate scaled SDF: $d = f'(\mathbf{o} + t\mathbf{d})$ [S1].
        ii. If $d < \epsilon_{early}$, terminate. Set $B_{low}[u_{low}, v_{low}] = t$ [S1].
        iii. If $t > t_{max}$, terminate. Set $B_{low}[u_{low}, v_{low}] = t_{max}$ [G].
        iv. Advance: $t \leftarrow t + \max(d, 0.0)$ [G].
3.  Store $B_{low}$ [S1].

#### Pass 2: Full-Resolution Rendering
1.  For each pixel $(u, v)$ in the target resolution:
    a.  Map to low-res pixel: $u_{low} = \lfloor u / s \rfloor$, $v_{low} = \lfloor v / s \rfloor$ [G].
    b.  Retrieve approximated distance: $d_{approx} = B_{low}[u_{low}, v_{low}]$ [S1].
    c.  **Ray Origin Reconstruction**:
        *   If $d_{approx} < t_{max}$:
            *   Set new ray origin $\mathbf{o}' = \mathbf{o} + d_{approx}\mathbf{d}$ [S1].
            *   Set initial step $t = 0$ (relative to $\mathbf{o}'$) [G].
        *   Else:
            *   Set $\mathbf{o}' = \mathbf{o}$, $t = 0$ [G].
    d.  Perform standard sphere tracing from $\mathbf{o}'$ with threshold $\epsilon_{base}$:
        i.  Loop:
            1.  Evaluate SDF: $d = f(\mathbf{o}' + t\mathbf{d})$ [S1].
            2.  If $d < \epsilon_{base}$, hit surface. Compute shading. Terminate [S1].
            3.  If $t > t_{max}$, miss. Terminate [G].
            4.  Advance: $t \leftarrow t + \max(d, 0.0)$ [G].
    e.  **Shadow Rays**:
        *   If shading requires shadows, use $d_{approx}$ to initialize shadow ray origin [S1].
        *   Set shadow hardness $k$ [S1].
        *   Trace shadow ray from $\mathbf{o}' + d_{approx}\mathbf{d}$ towards light source [S1].

### Pseudocode

```python
import math

def sphere_trace_sdf_scaling(scene, camera, resolution, scale_factor=4, 
                             epsilon_base=0.001, epsilon_early=0.05, 
                             t_max=100.0, delta_scale=0.1):
    """
    Implements SDF Scaling and Early Ray Termination.
    
    Args:
        scene: Object with method evaluate_sdf(p) returning signed distance.
        camera: Object with origin o and direction(u, v) returning normalized vector.
        resolution: Tuple (W, H) for target resolution.
        scale_factor: Integer, ratio of target to low-res resolution (e.g., 4).
        epsilon_base: Convergence threshold for full-res pass.
        epsilon_early: Larger threshold for low-res pass.
        t_max: Maximum ray distance.
        delta_scale: Magnitude of SDF inflation/deflation.
        
    Returns:
        Image buffer at target resolution.
    """
    W, H = resolution
    W_low, H_low = W // scale_factor, H // scale_factor
    
    # Buffer to store approximated distances from low-res pass
    low_res_buffer = [[t_max for _ in range(W_low)] for _ in range(H_low)]
    
    # --- Pass 1: Low-Resolution Pre-processing ---
    for v_low in range(H_low):
        for u_low in range(W_low):
            d = camera.direction(u_low, v_low)
            o = camera.origin
            
            # Evaluate camera position once per ray
            cam_dist = scene.evaluate_sdf(o)
            
            t = 0.0
            while t < t_max:
                p = o + t * d
                f_val = scene.evaluate_sdf(p)
                
                # Apply SDF Scaling based on camera position
                if cam_dist > 0:
                    f_scaled = f_val + delta_scale
                else:
                    f_scaled = f_val - delta_scale
                
                # Early Termination
                if f_scaled < epsilon_early:
                    low_res_buffer[v_low][u_low] = t
                    break
                
                # Step advancement (clamp to non-negative to prevent oscillation)
                step = max(f_scaled, 0.0)
                t += step
            
            # If loop finishes without break, t_max remains stored

    # --- Pass 2: Full-Resolution Rendering ---
    image = [[(0, 0, 0) for _ in range(W)] for _ in range(H)]
    
    for v in range(H):
        for u in range(W):
            d = camera.direction(u, v)
            o = camera.origin
            
            # Map to low-res buffer
            u_low = u // scale_factor
            v_low = v // scale_factor
            
            d_approx = low_res_buffer[v_low][u_low]
            
            # Ray Origin Reconstruction
            if d_approx < t_max:
                o_prime = o + d_approx * d
                t = 0.0
            else:
                o_prime = o
                t = 0.0
            
            # Full-Resolution Sphere Tracing
            while t < t_max:
                p = o_prime + t * d
                f_val = scene.evaluate_sdf(p)
                
                if f_val < epsilon_base:
                    color = shade_surface(p, d)
                    image[v][u] = color
                    break
                
                step = max(f_val, 0.0)
                t += step
            
            if t >= t_max:
                image[v][u] = (0, 0, 0) # Miss
                
    return image

def shade_surface(p, d):
    """Standard Lambertian shading for demonstration [G]."""
    normal = p / math.sqrt(sum(c*c for c in p))
    light_dir = [0.0, 1.0, 0.0]
    diff = max(sum(n*l for n, l in zip(normal, light_dir)), 0.0)
    return (0.5 + 0.5 * diff, 0.5 + 0.5 * diff, 0.5 + 0.5 * diff)
```

### Parameters
*   **Scale Factor ($s$)**: Typically 4 (reducing 4K to 960x540) [S1].
*   **$\epsilon_{early}$**: Must be larger than $\epsilon_{base}$; values that are too high cause rounding artifacts [S1].
*   **$\delta$ (Scaling Offset)**: Not explicitly defined in sources, but described as "scale up" or "scale down" [S1]. Implementation requires a scalar value.
*   **Shadow Hardness ($k$)**: Controls shadow penumbra width. Higher $k$ = harder shadows [S1].

### Edge Cases and Pitfalls
*   **Rounding Artifacts**: High $\epsilon_{early}$ values cause sharp edges to become rounded, reducing geometric fidelity [S1].
*   **Hole Approximation**: Incorrect scaling logic for subtracted SDFs (holes) can lead to visual artifacts. The scaling direction must be inverted for hole-generating primitives relative to the camera position [S1].
*   **Precision**: Low-resolution buffer stores distance values. Precision loss in $B_{low}$ may affect the accuracy of the ray origin reconstruction in Pass 2 [G].

## Operating characteristics
*   **Time Complexity**: The low-resolution pass is $O((W/s) \cdot (H/s))$ [G]. The full-resolution pass benefits from reduced step counts because rays start closer to surfaces [S1]. In the 'Primitives' scene, shadow rays often terminated after 1 step [S1].
*   **Memory Complexity**: Requires one additional buffer of size $W \cdot H / s^2$ [G]. This uses a single low-resolution buffer instead of a filtered pyramid, reducing memory cost and complexity [S1].
*   **Performance**:
    *   On NVIDIA RTX-3070Ti, 4K resolution: 3x speedup in frame time compared to state-of-the-art without anti-aliasing [S1].
    *   Shadow ray performance: 2.1x improvement in 'Primitives', 1.52x in 'Columns', 1.8x in 'Greek Temple', and 1.5x in 'Sponza atrium' [S1].
*   **Strengths**: Reduces step count significantly; low memory overhead; enables anti-aliasing without proportional cost increase [S1].
*   **Limitations**: Introduces geometric approximation errors (rounded edges); requires two passes; sensitive to $\epsilon_{early}$ selection [S1].

## Background
This method was proposed in the paper "Skipping Spheres: SDF Scaling & Early Ray Termination for Fast Sphere Tracing" [S1]. It addresses the trade-off between rendering speed and visual quality in sphere tracing, specifically targeting the issue of missed small features at low resolutions and the high cost of full-resolution tracing [S1]. It builds on the principles of [Step Size and Termination Rules](4132-step-size-and-termination-rules.md) and improves upon [Sphere Tracing](1674-sphere-tracing.md) by introducing geometric scaling in a pre-pass [S1].
