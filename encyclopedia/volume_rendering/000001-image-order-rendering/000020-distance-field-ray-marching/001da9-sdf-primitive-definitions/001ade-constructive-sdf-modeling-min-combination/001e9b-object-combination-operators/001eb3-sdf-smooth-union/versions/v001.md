# SDF Smooth Union

Also called: Smooth Minimum, Smooth Union (S-Union), LogSumExp SDF Union

## Overview
SDF Smooth Union is a method to combine two or more Signed Distance Functions (SDFs) into a single smooth SDF, avoiding sharp edges at the intersection of primitives [S2, S3]. It approximates the boolean union operation using a blending parameter $k$ [S1]. It sets itself apart from its siblings, such as [Multi-Material Distance Fields](1943-multi-material-distance-fields.md), by focusing on geometric blending of distances rather than material interpolation, although it can be extended to blend materials [S3].

## How it works
The method combines individual SDF results to produce a unified distance field. Two primary formulations exist: the polynomial smooth minimum (often called `smin`) and the LogSumExp smooth minimum.

### Inputs and Outputs
*   **Inputs**: Two (or more) signed distance values $a$ and $b$ (or $S_i(p)$) at a query point, and a smoothness parameter $k$ (or blend factor).
*   **Outputs**: A single signed distance value representing the smooth union.

### Data Structures
When combining multiple primitives with associated materials, the result is often wrapped in a structure [S3]:
*   `SdResult`: A struct containing:
    *   `distance` (float): The signed distance value.
    *   `material` (struct): Material properties (diffuse, specular, etc.) [S3].

### Formulas

#### 1. Polynomial Smooth Minimum (`smin`)
This variant uses a cubic polynomial approximation [S4].

Let $a$ and $b$ be the two SDF values. Let $k$ be the blend radius (smoothness parameter) [S4].

1.  Calculate the interpolation factor $h$:
    $$ h = \text{clamp}\left(0.5 + 0.5 \cdot \frac{b - a}{k}, 0.0, 1.0\right) $$
2.  Calculate the result:
    $$ \text{result} = \text{mix}(b, a, h) - k \cdot h \cdot (1.0 - h) $$
    Where $\text{mix}(b, a, h) = b + h(a - b)$ [S4].

Alternatively, expressed directly [S1]:
$$ \text{union}(d_1, d_2, k) = \text{mix}(d_2, d_1, h) - k \cdot h \cdot (1 - h) $$
where $h = \text{clamp}(0.5 + 0.5 \cdot \frac{d_2 - d_1}{k}, 0., 1.)$ [S1].

#### 2. LogSumExp Smooth Minimum
This variant uses the soft-min approximation via exponentials [S2].

For a set of SDFs $S_i(p)$:
$$ S_{union}(p) = -\frac{1}{k} \ln \left( \sum_{i} e^{-k \cdot S_i(p)} \right) $$
Or equivalently:
$$ S_{union}(p) = \frac{1}{-k} \text{logsumexp}_{i}(-k \cdot S_i(p)) $$
where $k$ is a positive float controlling smoothness [S2].

### Parameters
*   **$k$ (blend radius / smoothness)**: Controls the width of the transition region between shapes. Higher values result in a smoother union [S1, S2]. Typical values depend on the desired "blobbiness" or scale of the primitives [S4]. In specific implementations, typical values are 0.5 for primitive blending and 0.33 for final scene blending [S3].

### Pseudocode

```python
def smin_polynomial(a: float, b: float, k: float) -> float:
    """
    Polynomial smooth union of two SDF values.
    :param a: First SDF value
    :param b: Second SDF value
    :param k: Blend radius (smoothness). Must be > 0.
    :return: Smoothly blended distance
    """
    # Clamp h to [0, 1]
    h = 0.5 + 0.5 * (b - a) / k
    h = max(0.0, min(1.0, h))
    
    # Mix and subtract correction term
    mix_val = b + h * (a - b)
    result = mix_val - k * h * (1.0 - h)
    return result

def smin_logsumexp(values: list, k: float) -> float:
    """
    LogSumExp smooth union for multiple SDF values.
    :param values: List of SDF values
    :param k: Smoothness parameter
    :return: Smoothly blended distance
    """
    if not values:
        return float('inf')
    
    # Compute -k * S_i
    neg_k_s = [-k * s for s in values]
    
    # Find max for numerical stability
    max_val = max(neg_k_s)
    
    # Compute logsumexp
    sum_exp = sum(math.exp(val - max_val) for val in neg_k_s)
    log_sum_exp = math.log(sum_exp) + max_val
    
    # Final result
    return -log_sum_exp / k

def combine_sdfs_with_materials(sdfs: list, materials: list, p: vec3, k: float) -> dict:
    """
    Combines multiple SDFs with materials using polynomial smin.
    :param sdfs: List of SDF evaluation functions
    :param materials: List of material structs
    :param p: Query point
    :param k: Blend factor
    :return: SdResult dict with distance and material
    """
    # 1. Evaluate individual SDFs
    distances = []
    for sdf_func in sdfs:
        # Transform point if necessary (e.g., translation, rotation)
        # p_transformed = transform(p) 
        dist = sdf_func(p)
        distances.append(dist)
    
    # 2. Combine distances using smin
    # For more than 2, nest the smin calls or use logsumexp
    combined_dist = distances[0]
    for i in range(1, len(distances)):
        combined_dist = smin_polynomial(combined_dist, distances[i], k)
        
    # 3. Combine materials (simplified: use material of the closest primitive or blend)
    # Note: The source [S3] implies material blending is possible but focuses on distance.
    # A simple approach is to pick the material of the primitive with the smallest distance.
    min_idx = distances.index(min(distances))
    combined_material = materials[min_idx]
    
    return {"distance": combined_dist, "material": combined_material}
```

### Edge Cases and Pitfalls
*   **Precision**: When using LogSumExp, subtracting the maximum value before exponentiation is required for numerical stability [S2, G].
*   **Boundary**: The polynomial `smin` is only $C^1$ continuous if $k$ is chosen appropriately relative to the curvature of the primitives [G].
*   **Degenerate Input**: If $k=0$, the operation becomes a hard min (boolean union), which may cause discontinuities in derivatives if not handled [S1, G].

## Subtopics

### Polynomial Smooth Minimum
A blending function for combining two SDF values to create organic, metaball-like merges between primitives without branching or trigonometry [S4]. It uses a cubic polynomial approximation [S4]. Choose this when computational efficiency is prioritized over the exact soft-min properties of the LogSumExp variant. It is controlled by the blend radius parameter $k$ (or `uBlendK`) [S4].

### LogSumExp Smooth Minimum
A method using the soft-min approximation via exponentials [S2]. It provides a smoother transition and is mathematically equivalent to the soft-min function. Choose this when a more "natural" blending behavior is desired or when combining more than two primitives, as it generalizes easily to $N$ inputs. It is controlled by the positive float `blend_k` [S2].

## Operating characteristics
*   **Time Complexity**: $O(1)$ per pair of SDFs for Polynomial; $O(N)$ for LogSumExp with $N$ inputs.
*   **Memory Complexity**: $O(1)$ for Polynomial; $O(N)$ for LogSumExp to store intermediate exponentials.
*   **Strengths**: Produces smooth, organic transitions; avoids sharp edges; computationally cheap.
*   **Limitations**: The resulting distance field is an approximation and not a true Euclidean distance field [G]. The smoothness parameter $k$ must be tuned per scene scale.
*   **When to use**: When creating organic shapes, metaballs, or smooth architectural details.
*   **When not to use**: When exact distance properties are required for collision detection or physics [G].

## Background
The concept of smooth minimum operators for SDFs has been popularized in the context of ray marching and procedural modeling. The polynomial variant (`smin`) is widely used in shader code for its simplicity [S4]. The LogSumExp variant is derived from the soft-min function in optimization and machine learning [S2]. These methods are commonly used in real-time graphics, particularly in demoscene productions and procedural generation tools [S3].
