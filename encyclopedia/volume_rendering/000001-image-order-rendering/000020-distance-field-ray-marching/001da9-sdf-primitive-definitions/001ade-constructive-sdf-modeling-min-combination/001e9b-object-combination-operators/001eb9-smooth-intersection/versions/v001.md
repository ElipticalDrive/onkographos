# Smooth Intersection

Also called: S-Intersection

## Overview
Smooth Intersection is a constructive SDF operator that blends the overlap region of two shapes to produce rounded edges, approximating the boolean intersection [S1, S2, unofficial]. Unlike the standard `min` operator which creates sharp corners, this method introduces a blending parameter $k$ to control the radius of the smooth transition [S1, S2, unofficial]. It is distinct from Smooth Union, which blends the exterior of shapes, and provides a continuous distance field suitable for differentiable rendering [S1, S2, unofficial].

## How it works
**Inputs:**
- $d_1$: Signed distance value of the first shape at the query point.
- $d_2$: Signed distance value of the second shape at the query point.
- $k$: Smoothing factor (blending radius). Must be non-negative.

**Output:**
- $d$: The resulting smoothed signed distance.

**Data Structures:**
- Floating-point scalars for $d_1, d_2, k, h, d$.

**Steps:**
1. Calculate the interpolation factor $h$ based on the difference between distances and the smoothing factor:
   $$ h = \text{clamp}\left(0.5 - 0.5 \frac{d_2 - d_1}{k}, 0.0, 1.0\right) $$
   [S1, S2, unofficial]
2. Calculate the blended distance using linear interpolation (mix) and a quadratic correction term:
   $$ d = \text{mix}(d_2, d_1, h) + k \cdot h \cdot (1.0 - h) $$
   [S1, S2, unofficial]
   Where $\text{mix}(a, b, t) = a \cdot (1 - t) + b \cdot t$.

**Pseudocode:**
```python
def smooth_intersection(d1: float, d2: float, k: float) -> float:
    """
    Computes the smooth intersection of two signed distance fields.
    
    Args:
        d1: Distance to the first shape.
        d2: Distance to the second shape.
        k: Smoothing factor (blending radius).
        
    Returns:
        Smoothed signed distance.
    """
    if k == 0.0:
        # Fallback to standard min intersection if k is zero to avoid division by zero
        # [G] Standard behavior for boolean intersection is min(d1, d2)
        return min(d1, d2)
    
    # Calculate h: interpolation factor
    # h = clamp(0.5 - 0.5 * (d2 - d1) / k, 0.0, 1.0)
    ratio = (d2 - d1) / k
    h = 0.5 - 0.5 * ratio
    if h < 0.0:
        h = 0.0
    elif h > 1.0:
        h = 1.0
        
    # Calculate mix: linear interpolation between d2 and d1
    # mix(d2, d1, h) = d2 * (1 - h) + d1 * h
    mixed = d2 * (1.0 - h) + d1 * h
    
    # Calculate final distance
    # d = mixed + k * h * (1.0 - h)
    d = mixed + k * h * (1.0 - h)
    
    return d
```

**Parameters:**
- $k$: The smoothing factor or blending radius. Controls the width of the transition zone between the two shapes. Typical values depend on the scale of the scene. [S1, S2, unofficial]

**Edge Cases and Pitfalls:**
- If $k=0$, the formula involves division by zero. The implementation must handle this by falling back to the standard boolean intersection (`min(d1, d2)`) [G].
- The resulting distance field is not a true Euclidean distance field in the transition region; it is an approximation. This may affect ray marching step sizes if strict distance bounds are required, though it is generally sufficient for visualization and differentiable rendering [S1, S2, unofficial].

## Operating characteristics
- **Time Complexity:** $O(1)$ per query. Involves basic arithmetic operations.
- **Memory Complexity:** $O(1)$. No additional data structures required.
- **Strengths:** Produces visually smooth, rounded edges between intersecting shapes; differentiable with respect to inputs (useful for gradient-based optimization) [S1, S2, unofficial].
- **Limitations:** The output is not a true distance field in the blend region, which can lead to inaccuracies in strict distance-based algorithms like exact ray marching if not accounted for. The choice of $k$ affects the visual quality and may require tuning per scene scale.
- **When to use:** When rounded intersections are desired in SDF modeling, especially in differentiable rendering pipelines [S1, S2, unofficial].
- **When not to use:** When strict Euclidean distance bounds are required for correctness in ray marching, or when sharp boolean edges are desired.

## Background
Smooth Intersection is part of the family of smooth boolean operators used in Signed Distance Field (SDF) modeling. It allows for the creation of complex shapes with rounded features without explicit mesh processing. The specific formulation using the clamp and mix functions is popularized in modern differentiable rendering frameworks and SDF tutorials [S1, S2, unofficial].
