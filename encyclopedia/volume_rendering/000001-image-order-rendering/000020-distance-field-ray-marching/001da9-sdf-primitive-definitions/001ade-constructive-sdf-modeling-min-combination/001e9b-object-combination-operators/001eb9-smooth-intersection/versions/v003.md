# Smooth Intersection
Also called: S-Intersection
## Overview
Smooth Intersection is a constructive SDF operator that approximates the boolean intersection of two shapes by blending their overlap region [S1, unofficial][S2, unofficial]. It replaces the sharp corner of the standard `min` operator with a smooth transition controlled by a radius parameter $k$ [S1, unofficial][S2, unofficial]. Unlike [SDF Smooth Union](1817-sdf-smooth-union.md) which merges exterior volumes, it blends interior overlaps [G]. It differs from [Multi-Material Distance Fields](1943-multi-material-distance-fields.md) by focusing purely on geometric distance blending rather than material assignment [G].
## How it works
**Inputs:** $d_1$ and $d_2$ (scalar signed distances to two shapes), and $k$ (blending radius or smoothing factor, $k \ge 0$) [S1, unofficial][S2, unofficial].
**Output:** $d$ (scalar smoothed signed distance) [S1, unofficial][S2, unofficial].
**Data Structures:** Not given in the sources [S1, unofficial][S2, unofficial].
**Steps:**
1. Calculate the interpolation factor $h$ based on the distance difference and smoothing factor: $h = \text{clamp}\left(0.5 - 0.5 \frac{d_2 - d_1}{k}, 0.0, 1.0\right)$ [S1, unofficial][S2, unofficial].
2. Calculate the blended distance using linear interpolation and a quadratic correction term: $d = \text{mix}(d_2, d_1, h) + k \cdot h \cdot (1.0 - h)$ [S1, unofficial][S2, unofficial].
Where $\text{mix}(a, b, t) = a \cdot (1 - t) + b \cdot t$ [S1, unofficial][S2, unofficial].
**Parameters:** $k$: The smoothing factor or blending radius [S1, unofficial][S2, unofficial].
**Edge Cases and Pitfalls:**
- If $k=0$, the formula involves division by zero; implementations typically fall back to `min(d1, d2)` [G].
- The output is not a true Euclidean distance field in the transition region; it is an approximation [G].
- Lipschitz continuity is preserved only when the gradients of the two SDFs are orthogonal; if they deviate by more than 30 degrees or the surfaces are parallel and close, artifacts may occur [S1, unofficial][S2, unofficial].
**Pseudocode:**
```python
def smooth_intersection(d1: float, d2: float, k: float) -> float:
    if k == 0.0:
        return min(d1, d2)  # [G] Fallback to standard boolean intersection to avoid division by zero
    ratio = (d2 - d1) / k
    h = 0.5 - 0.5 * ratio
    if h < 0.0:
        h = 0.0
    elif h > 1.0:
        h = 1.0
    mixed = d2 * (1.0 - h) + d1 * h
    return mixed + k * h * (1.0 - h)
```
## Subtopics

### [SDF Smooth Union](1817-sdf-smooth-union.md)
Blends the exterior of two shapes to merge volumes [G]. It sets itself apart by operating on disjoint or overlapping boundaries rather than interior overlaps [G]. Choose it when creating rounded corners between objects that should form a single continuous volume [G].

### [Multi-Material Distance Fields](1943-multi-material-distance-fields.md)
Extends SDFs to handle multiple materials with distinct properties [G]. It sets itself apart by associating material IDs or properties with distance regions rather than just geometry [G]. Choose it when different regions require different shading or physical attributes [G].

## Operating characteristics
- **Time Complexity:** $O(1)$ per query [G].
- **Memory Complexity:** $O(1)$ [G].
- **Measured performance:** Not given in the sources [S1, unofficial][S2, unofficial].
- **Scaling:** Not given in the sources [S1, unofficial][S2, unofficial].
- **Strengths:** Produces visually smooth transitions; differentiable with respect to inputs [S1, unofficial][S2, unofficial].
- **Limitations:** Not a true distance field in the blend region, which can affect strict distance-based algorithms [G].
- **When to use:** SDF modeling requiring rounded intersections [G].
- **When not to use:** When sharp boolean edges or strict Euclidean distance bounds are required [G].
