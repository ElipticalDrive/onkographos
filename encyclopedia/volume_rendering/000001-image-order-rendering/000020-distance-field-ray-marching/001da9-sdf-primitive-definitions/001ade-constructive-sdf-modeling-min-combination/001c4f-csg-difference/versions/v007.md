# CSG Difference
Also called: SDF Difference, Subtraction of SDFs, CSG Subtraction

## Overview
The CSG Difference method performs a boolean subtraction of one implicit shape from another within a Constructive SDF Modeling pipeline. It solves the problem of carving out volume from a base object using a tool object, resulting in a solid region that exists in the base but not in the tool. It differs from its parent, [Constructive SDF Modeling (Min Combination)](871-constructive-sdf-modeling-min-combination.md), by using a max operation with negation rather than a simple min, and from [Smooth SDF Composition](2685-smooth-sdf-composition.md) by producing sharp, non-differentiable boundaries rather than smooth transitions.

## How it works
**Inputs and Outputs:**
- Input: Two Signed Distance Field (SDF) functions, $S_a$ (the tool/subtracted shape) and $S_b$ (the base/retained shape).
- Output: A combined SDF function $S_{diff}$ representing the difference.

**Data Structures:**
- Scalar SDF: A function or lookup table returning a single floating-point value representing distance to the surface.
- Vector SDF: A function or lookup table returning a 3D vector (or 4D with homogeneous coordinate) representing the distance and potentially normal information.

**Formula:**
The scalar sample for the difference at point $p$ is defined as [S1, unofficial]:
$$ S_{diff}(p) = \max(S_b(p), -S_a(p)) $$

For vector samples, the operation is applied component-wise or via vector magnitude logic depending on the specific vector SDF definition, but generally follows [S1, unofficial]:
$$ V_{diff}(p) = \max(V_b(p), -V_a(p)) $$
*Note: The vector max operation typically implies taking the maximum distance magnitude while preserving the sign logic relative to the surface.*

**Steps:**
1. Evaluate the tool SDF at the query point $p$: $d_a = S_a(p)$.
2. Evaluate the base SDF at the query point $p$: $d_b = S_b(p)$.
3. Negate the tool distance: $-d_a$.
4. Compute the maximum of the base distance and the negated tool distance: $d_{result} = \max(d_b, -d_a)$.
5. Return $d_{result}$.

**Pseudocode:**
```python
def csg_difference(p, sdf_a, sdf_b):
    """
    Computes the CSG difference of shape A from shape B.
    Result is solid where B is solid, except where A is solid.
    """
    # Evaluate distances
    dist_a = sdf_a(p)
    dist_b = sdf_b(p)
    
    # Apply formula: max(S_b, -S_a)
    # Note: In many SDF implementations, the sign indicates inside/outside.
    # If S_a is positive outside and negative inside, -S_a flips the inside/outside logic.
    # The max operation ensures the result is the distance to the nearest "retained" surface.
    result = max(dist_b, -dist_a)
    
    return result
```

**Edge Cases and Pitfalls:**
- **Precision:** Near the intersection of the two surfaces, the cancellation of values in $-S_a$ and $S_b$ can lead to precision issues. [G] Ensure epsilon comparisons in ray marching account for the combined error bounds of both SDFs.
- **Boundaries:** The resulting SDF is continuous but not necessarily differentiable at the boundary where $S_b(p) = -S_a(p)$. This creates sharp edges, which is the intended behavior for hard CSG.

## Subtopics

### [Smooth Subtraction](1840-smooth-subtraction.md)
Provides a differentiable approximation of the CSG difference by blending the subtraction with a smoothing parameter, avoiding sharp edges. Choose this when gradient-based optimization or avoiding artifacts in differentiable rendering is required.

## Operating characteristics
- **Time Complexity:** $O(1)$ per sample, requiring two SDF evaluations and one max operation.
- **Memory Complexity:** $O(1)$ auxiliary memory.
- **Strengths:** Exact boolean representation; sharp, clean edges; computationally cheap.
- **Limitations:** Non-differentiable at the cut boundary; can produce artifacts in differentiable rendering pipelines; sensitive to the alignment of the two shapes.
- **When to use:** When hard, precise boolean cuts are required and differentiability is not needed.
- **When not to use:** When smooth transitions or gradient-based optimization are required (use [Smooth Subtraction](1840-smooth-subtraction.md) instead).

## Background
The CSG Difference is a fundamental operation in Constructive Solid Geometry (CSG) applied to Signed Distance Fields. It was formalized in the context of SDFs by researchers and practitioners in computer graphics, notably documented in repositories such as [S1, unofficial] and [S2, unofficial]. It builds directly on the min-combination logic of [Constructive SDF Modeling (Min Combination)](871-constructive-sdf-modeling-min-combination.md) by leveraging the property that negating an SDF flips its inside/outside status, allowing the max operator to select the "retained" volume.
