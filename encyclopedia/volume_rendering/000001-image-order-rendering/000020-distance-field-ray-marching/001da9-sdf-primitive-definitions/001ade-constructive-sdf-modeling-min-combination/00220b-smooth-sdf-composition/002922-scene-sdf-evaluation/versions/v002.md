# Scene SDF Evaluation
Also called: SDF Scene Composition, Signed Distance Function (SDF) Scene Composition

## Overview
Scene SDF Evaluation computes the minimum signed distance from a query point to any primitive in a scene, effectively performing a union operation across all defined geometry [S1, unofficial]. It aggregates multiple distinct primitives into a single scene-level distance field rather than composing a single smooth blend of shapes [G].

## How it works
**Inputs:**
- `point`: The 3D query position ($p \in \mathbb{R}^3$) [G].
- `scene`: A structure containing arrays of primitives (spheres, cuboids) and their counts [S1, unofficial].

**Outputs:**
- `min_dist`: The scalar signed distance to the nearest surface in the scene [S1, unofficial].

**Data Structures:**
- `Sphere`: Contains `center` ($c \in \mathbb{R}^3$) and `radius` ($r \in \mathbb{R}$) [G].
- `Cuboid`: Contains `center` ($c \in \mathbb{R}^3$), `half_extents` ($h \in \mathbb{R}^3$), and optionally `orientation` ($q \in \mathbb{R}^4$) if rotated [G].
- `Scene`: Contains `sphere_count` (uint), `cuboid_count` (uint), `spheres` (array of Sphere), and `cuboids` (array of Cuboid) [S1, unofficial].

**Steps:**
1. Initialize `min_dist` to `MAX_SIGNED_DISTANCE` (10000.0) [S1, unofficial].
2. Iterate through all spheres ($i = 0$ to `scene.sphere_count - 1`):
   - For each sphere $i$, evaluate the sphere SDF: $d_{sphere} = \| p - c_i \| - r_i$ [G].
   - Update `min_dist = min(min_dist, d_{sphere})` [S1, unofficial].
3. Iterate through all cuboids ($j = 0$ to `scene.cuboid_count - 1`):
   - For each cuboid $j$, evaluate the cuboid SDF [S1, unofficial].
   - Update `min_dist = min(min_dist, d_{cuboid})` [S1, unofficial].
4. Return `min_dist` [S1, unofficial].

**Pseudocode:**
```python
def evaluate_scene_sdf(point, scene):
    min_dist = 10000.0
    for i in range(scene.sphere_count):
        sphere = scene.spheres[i]
        sphere_dist = length(point - sphere.center) - sphere.radius
        if sphere_dist < min_dist:
            min_dist = sphere_dist
    for j in range(scene.cuboid_count):
        cuboid = scene.cuboids[j]
        cuboid_dist = evaluate_sdf_cuboid(cuboid, point)
        if cuboid_dist < min_dist:
            min_dist = cuboid_dist
    return min_dist

def evaluate_sdf_cuboid(cuboid, point):
    # [G] Standard axis-aligned cuboid SDF: transform point to local space,
    # compute d = max(|p_local| - h, 0), return length(d)
    local_point = point - cuboid.center
    d = max(abs(local_point) - cuboid.half_extents, 0.0)
    return length(d)
```

**Parameters:**
- `MAX_SIGNED_DISTANCE`: `10000.0` [S1, unofficial].

**Edge Cases:**
- If the scene is empty, the function returns `MAX_SIGNED_DISTANCE` [S1, unofficial].
- Precision issues may arise if primitives are extremely close or overlapping, though the min operation handles overlaps correctly for unions [G].

## Subtopics

### SDF Intersection
A boolean intersection operation for SDFs that returns the maximum distance value at any point, representing the region common to both shapes [S2, unofficial]. To implement, evaluate the SDF for both shapes at point $p$ and return $\max(d_1, d_2)$ [S2, unofficial]. This is the dual of the union operation used in the main scene evaluation [G].

## Operating characteristics
- **Time Complexity:** $O(N)$, where $N$ is the total number of primitives in the scene. Each primitive is evaluated exactly once [G].
- **Memory Complexity:** $O(N)$ to store the primitive data structures [G].
- **Strengths:** Simple to implement; allows for complex scene composition using basic primitives [G].
- **Limitations:** Performance degrades linearly with scene complexity. Not suitable for very large scenes without spatial acceleration structures (which are not part of this basic evaluation method) [G].

## Background
The method originates from ray marching techniques using Signed Distance Functions [G]. The specific implementation pattern of iterating through spheres and cuboids is documented in the `ray-marcher` project [S1, unofficial]. The use of min for union and max for intersection in SDF composition is demonstrated by Alan Zucconi [S2, unofficial].
