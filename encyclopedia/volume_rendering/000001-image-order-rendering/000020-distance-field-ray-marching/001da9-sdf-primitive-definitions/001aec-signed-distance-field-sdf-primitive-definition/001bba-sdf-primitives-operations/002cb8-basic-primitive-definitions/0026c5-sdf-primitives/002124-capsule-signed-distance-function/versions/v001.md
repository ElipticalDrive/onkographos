# Capsule Signed Distance Function

Also called: 3D Capsule SDF, Capsule SDF, Capsule3D SDF, Signed Capsule, sdCapsule

## Overview
The Capsule Signed Distance Function computes the exact Euclidean distance from a query point to a 3D capsule, defined as a cylinder of radius $r$ capped by hemispheres at its endpoints. It solves the primitive distance query required for ray marching in volume rendering and ray tracing. It is distinguished from the [Sphere Signed Distance Function](1237-sphere-signed-distance-function.md) by its linear axis and from the [Signed Box Distance Function](1092-signed-box-distance-function.md) by its smooth, rounded geometry. It builds on [SDF Primitives](1731-sdf-primitives.md) by providing a closed-form solution for a shape with rotational symmetry along a finite segment.

## How it works
**Inputs and Outputs:**
- Input: Query point $p \in \mathbb{R}^3$, capsule endpoints $a, b \in \mathbb{R}^3$, radius $r \in \mathbb{R}^+$.
- Output: Signed distance $d \in \mathbb{R}$. Positive outside, negative inside, zero on surface.

**Data Structures:**
- Vectors $p, a, b$ are 3D Cartesian coordinates.
- Scalar $r$ is a single floating-point value.

**Steps:**
1. Compute the vector from endpoint $a$ to the query point: $pa = p - a$.
2. Compute the vector representing the capsule axis: $ba = b - a$.
3. Compute the squared length of the axis: $len\_sq = ba \cdot ba$.
4. Determine the projection parameter $h$ of $p$ onto the segment $ab$:
   - If $len\_sq < \epsilon$ (where $\epsilon$ is a small threshold, e.g., $10^{-12}$), set $h = 0$. [S4, unofficial]
   - Otherwise, compute $h = \text{clamp}\left(\frac{pa \cdot ba}{len\_sq}, 0.0, 1.0\right)$. [S2, S4, unofficial]
5. Compute the closest point on the segment: $closest = a + ba \cdot h$.
6. Compute the vector from the closest point to $p$: $diff = p - closest$.
7. Return the distance: $d = \|diff\| - r$. [S2, S4, unofficial]

**Formula:**
$$
h = \text{clamp}\left(\frac{(p-a) \cdot (b-a)}{\|b-a\|^2}, 0, 1\right)
$$
$$
d = \|(p-a) - h(b-a)\| - r
$$

**Parameters:**
- $r$: Radius of the capsule. Typical values depend on scene scale. [S3, unofficial] uses $r=0.12$.
- $a, b$: Endpoints. The capsule is the set of points within distance $r$ of the line segment $ab$.

**Edge Cases and Pitfalls:**
- **Degenerate Capsule:** If $a = b$, the axis length is zero. The division by $\|b-a\|^2$ must be guarded. The sources suggest clamping $h$ to 0 if the squared length is negligible, effectively treating the capsule as a sphere centered at $a$. [S4, unofficial]
- **Precision:** Using squared length in the denominator avoids square roots during projection but requires careful handling of near-zero lengths. [S4, unofficial]
- **Coordinate Systems:** The function is general for any orientation in 3D space. An axis-aligned variant exists where $a=(0,0,0)$ and $b=(0,h,0)$, simplifying the projection to a simple clamp on the Y coordinate. [S1, unofficial]

**Pseudocode:**
```python
def sd_capsule(p: Vec3, a: Vec3, b: Vec3, r: float) -> float:
    """
    Computes the signed distance from point p to a capsule defined by endpoints a, b and radius r.
    """
    # Vector from a to p
    pa = p - a
    # Vector from a to b (axis)
    ba = b - a
    
    # Squared length of the axis
    len_sq = ba.dot(ba)
    
    # Projection parameter h
    # Guard against degenerate capsule (a == b)
    if len_sq < 1e-12:
        h = 0.0
    else:
        # Project pa onto ba, clamped to [0, 1]
        h = max(0.0, min(1.0, pa.dot(ba) / len_sq))
        
    # Closest point on the segment
    closest = a + ba * h
    
    # Distance from point to closest point, minus radius
    diff = p - closest
    return diff.length() - r
```

## Subtopics

### Axis-Aligned Capsule
A specialized case where the capsule is aligned with a coordinate axis (typically Y). It simplifies the calculation to clamping the corresponding coordinate. [S1, unofficial]

### 2D Capsule
The 2D equivalent, often called a "stadium" or "capsule" in 2D graphics. It uses the same projection logic but in 2D space. [S4, unofficial]

## Operating characteristics
- **Time Complexity:** $O(1)$. The calculation involves a constant number of vector operations (subtraction, dot product, clamp, length).
- **Memory Complexity:** $O(1)$. No auxiliary data structures are required.
- **Strengths:** Exact analytical solution; no approximation error; fast evaluation; supports arbitrary orientation in 3D.
- **Limitations:** None significant for standard rendering. The only pitfall is the degenerate case $a=b$, which must be handled to avoid division by zero.
- **When to use:** When rendering or ray-marching objects with cylindrical bodies and rounded ends, such as limbs, pipes, or stylized characters.

## Background
The capsule SDF is a standard primitive in Signed Distance Field rendering, popularized by Inigo Quilez's online articles and code repositories. It is widely used in ray marching for its ability to represent complex organic shapes with simple primitives. The implementation shown in [S2, unofficial] and [S4, unofficial] is a direct translation of Quilez's GLSL code into other languages. The axis-aligned version [S1, unofficial] is a simplification for specific use cases.
