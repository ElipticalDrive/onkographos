# Ellipsoid Signed Distance Function

Also called: Ellipsoid Approximation, Ellipsoid Improved, Ellipsoid SDF

## Overview
Computes the signed distance from a point to an ellipsoid defined by semi-axes $r$. It provides a fast approximation (V1) or a more accurate iterative-free approximation (V2) compared to the exact root-finding solution. V2 is preferred for ray marching due to better continuity, though both are approximations [S1, S2, unofficial].

## How it works
**Inputs:** Point $p \in \mathbb{R}^3$, semi-axes radii $r \in \mathbb{R}^3$ (where $r_i > 0$).
**Output:** Signed distance $d$.

**Data Structures:**
- $p$: 3-component vector.
- $r$: 3-component vector.

**Steps:**
1. Compute $k_1 = \| p / r \|$.
2. Compute $k_2 = \| p / (r \circ r) \|$, where $\circ$ is component-wise multiplication.
3. Return $d = \frac{k_1 (k_1 - 1.0)}{k_2}$.

**Formula:**
$$ d = \frac{\| p / r \| (\| p / r \| - 1)}{\| p / (r \circ r) \|} $$

**Parameters:**
- $r$: Semi-axes lengths. Must be positive.

**Edge Cases:**
- If $r_i = 0$, the function is undefined. [G] Clamp $r$ to a small epsilon if necessary.
- If $p = 0$, $k_1=0, k_2=0$, resulting in $0/0$. [G] Return $-\min(r)$ for the interior case.

**Pseudocode:**
```python
def ellipsoid_sdf(p, r):
    # p: vec3, r: vec3
    # Avoid division by zero
    r_safe = max(r, 1e-8)
    
    # Step 1: k1 = length(p / r)
    k1 = length(p / r_safe)
    
    # Step 2: k2 = length(p / (r * r))
    r_sq = r_safe * r_safe
    k2 = length(p / r_sq)
    
    # Step 3: Return k1 * (k1 - 1.0) / k2
    # Note: This is the "Improved" V2 version.
    # V1 is (k1 - 1.0) * min(r), which is less accurate.
    d = k1 * (k1 - 1.0) / k2
    
    return d
```

## Operating characteristics
- **Time Complexity:** $O(1)$, constant number of arithmetic operations.
- **Memory Complexity:** $O(1)$.
- **Accuracy:** V2 is significantly more accurate than V1, especially for highly anisotropic ellipsoids. However, it is still an approximation and not the exact SDF [S1, unofficial]. The exact SDF requires solving a quartic equation [S2, unofficial].
- **Strengths:** Fast, differentiable, smooth.
- **Limitations:** Not exact. May cause artifacts in high-precision ray marching if the error exceeds the step size.

## Background
The ellipsoid SDF is a standard primitive in SDF libraries. V1 and V2 are attributed to Inigo Quilez [S1, unofficial]. The "Improved" version (V2) is widely adopted in real-time graphics for its balance of speed and accuracy.
