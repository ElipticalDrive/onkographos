# Rectangle Signed Distance Function

Also called: 2D Rectangle SDF, sdRect

## Overview
Computes the exact Euclidean distance from a query point to the boundary of an axis-aligned rectangle centered at the origin. It serves as a fundamental primitive for distance-field ray marching, allowing for efficient collision detection and rendering of rectangular shapes without polygonal approximation. It is the 2D analog of the [Signed Box Distance Function](1092-signed-box-distance-function.md).

## How it works
**Inputs:**
- $p$: Query point in 2D space ($\vec{vec2}$).
- $hsize$: Half-extents of the rectangle along the x and y axes ($\vec{vec2}$). The rectangle spans $[-hsize_x, hsize_x] \times [-hsize_y, hsize_y]$.

**Outputs:**
- $d$: Signed distance. Positive if outside, negative if inside, zero on the boundary.

**Data Structures:**
- $\vec{vec2}$: A vector with two floating-point components ($x, y$).

**Steps:**
1. Calculate the vector $dv$ representing the displacement from the rectangle's boundary in each axis:
   $$dv = |p| - hsize$$
   where $|p|$ applies the absolute value component-wise to $p$.
2. Calculate the distance to the exterior boundary (clamped positive part):
   $$outsideDistance = \| \max(dv, 0) \|$$
   where $\max(dv, 0)$ applies the maximum operator to each component of $dv$ with $0$, and $\|\cdot\|$ is the Euclidean length.
3. Calculate the distance to the interior boundary (clamped negative part):
   $$insideDistance = \min(\max(dv_x, dv_y), 0)$$
   This captures the distance to the closest edge when the point is inside the rectangle.
4. Return the sum:
   $$d = outsideDistance + insideDistance$$

**Formula:**
$$d = \|\max(dv, 0)\| + \min(\max(dv_x, dv_y), 0)$$

**Pseudocode:**
```python
def sdRect(p: Vec2, hsize: Vec2) -> float:
    # Step 1: Calculate displacement from boundary
    dv = Vec2(abs(p.x), abs(p.y)) - hsize
    
    # Step 2: Calculate outside distance (Euclidean norm of positive components)
    # max(dv, 0.0) clamps negative components to 0
    outside_dist = length(max(dv, 0.0))
    
    # Step 3: Calculate inside distance (minimum of components, clamped to 0)
    # min(max(dv.x, dv.y), 0.0) gets the closest edge distance if inside
    inside_dist = min(max(dv.x, dv.y), 0.0)
    
    # Step 4: Combine
    return outside_dist + inside_dist
```

**Parameters:**
- $hsize$: Typical values depend on scene scale. For unit-aligned grids, $hsize$ might be $(0.5, 0.5)$ for a $1 \times 1$ rectangle.

**Edge Cases:**
- **Precision:** Near the boundary, floating-point precision may cause jitter. [G] Clamping or epsilon checks are often used in ray marching loops to prevent infinite loops or z-fighting.
- **Degenerate Input:** If $hsize$ contains zero or negative values, the geometry is invalid or degenerate. The formula assumes $hsize_x, hsize_y > 0$.

## Subtopics

### Cube Signed Distance Function
A 3D extension for a cube centered at the origin with width, height, and length equal to 2.0 (half-extents of 1.0). It follows the same logic as the 2D rectangle but operates in 3D space. It is chosen when rendering cubic primitives.
**Definition:**
$$d = \|\max(d, 0)\| + \min(\max(d_x, \max(d_y, d_z)), 0)$$
where $d = |p| - (1.0, 1.0, 1.0)$.
**Code:**
```python
def cubeSDF(p: Vec3) -> float:
    d = Vec3(abs(p.x), abs(p.y), abs(p.z)) - Vec3(1.0, 1.0, 1.0)
    insideDistance = min(max(d.x, max(d.y, d.z)), 0.0)
    outsideDistance = length(max(d, 0.0))
    return insideDistance + outsideDistance
```

## Operating characteristics
- **Time Complexity:** $O(1)$. The calculation involves a fixed number of arithmetic operations and vector norms.
- **Memory Complexity:** $O(1)$. No auxiliary data structures are required.
- **Strengths:** Exact distance calculation ensures no aliasing artifacts from polygonal approximations. Very fast evaluation makes it suitable for real-time ray marching.
- **Limitations:** Limited to axis-aligned rectangles. Rotated or skewed rectangles require transformation of the query point $p$ into the rectangle's local space before applying the function.
- **When to use:** Ideal for rendering simple rectangular shapes, UI elements, or grid-based structures in ray marching.
- **When not to use:** For complex curved surfaces or non-axis-aligned rectangles where transformation overhead outweighs benefits, or when higher-order primitives are needed.

## Background
The Signed Distance Function for rectangles is a standard primitive in the field of ray marching and implicit surface rendering.
