# CSG Operations on Implicit Functions

Also called: CSG implicit surfaces, SDF Boolean Operations, Union/Intersection via min/max

## Overview
Constructive Solid Geometry (CSG) on implicit functions composites multiple primitive shapes into a single implicit surface by applying Boolean logic to their distance fields [S1, S5, unofficial]. This method allows the rendering of complex geometries composed of multiple primitives using a single field evaluation, which is essential for ray marching and bisection tracers [S1, unofficial]. Unlike explicit mesh operations, CSG on implicit functions reduces geometric composition to arithmetic operations on scalar values, enabling normals and shadows derived from the resulting field's gradient [S4, unofficial]. It is distinguished from sibling primitives by its role as a compositing layer that combines the outputs of [Sphere Signed Distance Function](1237-sphere-signed-distance-function.md), [Signed Box Distance Function](1092-signed-box-distance-function.md), and other primitives into a unified scene representation [G].

## How it works
**Inputs and Outputs:**
*   **Inputs:** Two or more signed distance functions (SDFs), denoted $f_1(\mathbf{p})$ and $f_2(\mathbf{p})$, evaluated at a point $\mathbf{p}$ in 3D space [S3, S4, unofficial]. Each $f_i$ returns a scalar representing the signed distance to the surface of the $i$-th primitive [S3, unofficial].
*   **Outputs:** A new signed distance function $f_{result}(\mathbf{p})$ that represents the Boolean combination of the input shapes [S1, S3, unofficial].

**Data Structures:**
The method operates on scalar values during ray marching [S4, unofficial]. In voxel-based implementations, it operates on 3D grids of floating-point values [S6, unofficial].

**Core Formulas:**
The fundamental CSG operations on SDFs are defined as follows [S2][S3, S4, S5, S6, unofficial]:

1.  **Union:** The distance to the union is the minimum of the individual distances [S2][S4, S5, S6, unofficial]. A point is inside the union if it is inside at least one component [S5, unofficial].
    $$f_{union}(\mathbf{p}) = \min(f_1(\mathbf{p}), f_2(\mathbf{p}))$$
2.  **Intersection:** The distance to the intersection is bounded by the maximum of the individual distances [S2]. A point is inside the intersection only if it is inside all components [S5, unofficial].
    $$f_{intersection}(\mathbf{p}) = \max(f_1(\mathbf{p}), f_2(\mathbf{p}))$$
3.  **Difference (Subtraction):** Subtracting shape $B$ from shape $A$ is equivalent to intersecting $A$ with the complement of $B$ [S2][S4, S5, unofficial]. The complement of an SDF is its negation [S2].
    $$f_{diff}(\mathbf{p}) = \max(f_1(\mathbf{p}), -f_2(\mathbf{p}))$$

**Proof of Correctness for Intersection (Signed Distance Bounds):**
While Union preserves the exact signed distance property, Intersection and Difference yield *signed distance bounds* rather than exact distances [S2]. This is because DeMorgan’s theorem does not hold directly with min/max operators for distance bounds (the minimum operator is not complemented properly) [S2]. The correctness of the intersection bound $\max(d_A, d_B)$ is verified by four cases [S2]:
*   **Case I ($d_A < 0, d_B < 0$):** Both points are inside [S2]. The distance to the intersection edge is the larger (less negative) of the two distances [S2].
*   **Case II ($d_A < 0, d_B > 0$):** Point is inside $A$ but outside $B$ [S2]. The closest point on $A$ to $\mathbf{p}$ may not be in the intersection, but no point in the intersection can be closer than $d_B$ [S2]. Thus, the bound is $d_B$ (which is $> d_A$) [S2].
*   **Case III ($d_A > 0, d_B < 0$):** Symmetric to Case II [S2].
*   **Case IV ($d_A > 0, d_B > 0$):** Both points are outside [S2]. The closest point in the intersection is no closer than the farther of the two distances [S2].

**Pseudocode (Ray Marching Context):**
```python
def ray_march_csg(scene_func, ray_origin, ray_direction, max_steps=64, max_dist=100.0, epsilon=0.001):
    """
    Standard sphere tracing loop using a composite CSG scene function.
    scene_func(p) must internally call the appropriate min/max operations.
    """
    t = 0.0
    for _ in range(max_steps):
        pos = ray_origin + t * ray_direction
        dist = scene_func(pos)
        if dist < epsilon:
            return t, pos
        if t > max_dist:
            return float('inf'), None
        t += dist
    return float('inf'), None
```

**Pseudocode (Voxel Grid Context):**
For voxel-based level set operations, the operations are applied element-wise across the grid [S6, unofficial].
```python
def voxel_union(buffer_a, buffer_b):
    """In-place union of two voxel buffers."""
    dims = buffer_a.dims()
    for k in range(dims.min.z, dims.max.z + 1):
        for j in range(dims.min.y, dims.max.y + 1):
            for i in range(dims.min.x, dims.max.x + 1):
                buffer_a[i, j, k] = min(buffer_a[i, j, k], buffer_b[i, j, k])

def voxel_difference(buffer_a, buffer_b):
    """In-place difference (A minus B) of two voxel buffers."""
    dims = buffer_a.dims()
    for k in range(dims.min.z, dims.max.z + 1):
        for j in range(dims.min.y, dims.max.y + 1):
            for i in range(dims.min.x, dims.max.x + 1):
                buffer_a[i, j, k] = max(buffer_a[i, j, k], -buffer_b[i, j, k])
```

**Edge Cases and Pitfalls:**
*   **Material/Color Changes:** Polygonizers generating meshes from CSG level sets do not inherently consider material properties [S5, unofficial]. This can lead to drastic color changes between vertices at CSG boundaries if materials are not treated as surface boundaries (inside/outside changes) [S5, unofficial].
*   **Signed Distance Bound Accuracy:** Intersection and Difference operations do not preserve the exact signed distance property [S2]. The resulting field is a bound, which may cause sphere tracing to step conservatively compared to an exact SDF, though it remains valid for rendering [S2].

## Subtopics

### Smooth Union
An alternative to the standard Union operation that creates a smooth transition (rounded fillets) between the edges of two shapes rather than a sharp crease [S3, S4, unofficial]. It takes an additional float parameter $k$ (typically 0 to 2) determining the degree of smoothness [S3, S4, unofficial]. It uses a polynomial blend function `smin(a, b, k)` instead of `min(a, b)` [S4, unofficial].

### Smooth Intersection
Similar to Smooth Union, this operation creates a smooth transition for the intersection of two shapes [S3, unofficial]. It retains the common part but blends the boundary smoothly using a smooth blend function with a smoothness parameter $k$ [S3, unofficial].

### Smooth Subtract
Similar to Smooth Union, this operation subtracts the second shape from the first with a smooth transition at the boundary [S3, unofficial]. It applies the smooth blend function combined with negation logic [S3, unofficial].

### Union Stairs
A binary operation that takes the union of two shapes and creates a set of steps between the edges where they connect [S3, unofficial]. Union Stairs takes two additional float parameters: $r$ (step width) and $n$ (number of steps) [S3, unofficial].

### Difference Stairs
Behaves like Union Stairs but performs subtraction (A minus B) instead of union, creating stepped boundaries for the difference operation [S3, unofficial].

### Intersection Stairs
Behaves like Union Stairs but performs intersection, creating stepped boundaries for the intersection operation [S3, unofficial].

### Noise
A unary operation that adds Perlin noise to the signed distance of a shape [S3, unofficial]. It takes a float parameter `noiseProp` (0 to 0.5) determining the intensity of the noise [S3, unofficial]. It uses a GLSL `mix` function to blend the noise into the distance value: `mix(f, f + noise, noiseProp)` [S3, unofficial].

### Onion
A unary operation that creates a hole inside a shape, resulting in a hollow object [S3, unofficial]. It takes a float parameter `thickness` (smaller values result in larger holes) [S3, unofficial].

### Constructive Solid Geometry (CSG) on Level Sets
A voxel-based implementation of CSG operations that applies Boolean logic directly to discrete 3D grids [S6, unofficial]. Union is implemented as `A_new(i,j,k) = min(A(i,j,k), B(i,j,k))`, intersection as `A_new(i,j,k) = max(A(i,j,k), B(i,j,k))`, and difference as `A_new(i,j,k) = max(A(i,j,k), -B(i,j,k))` [S6, unofficial]. In user interface terms, intersection corresponds to a copy operation, union to a paste operation, and difference to a cut operation [S6, unofficial].

    *   **Simplicity:** Complex geometry is defined by simple arithmetic expressions [S4, unofficial].

    *   **Intersection Bounds:** Intersection and Difference operations yield signed distance *bounds*, not exact distances [S2].

## Background
CSG on implicit surfaces was formalized following Ricci's work in 1974, which established that minimum and maximum operations on functions result in union and intersection operations on their implicit surfaces [S2]. The method is a cornerstone of ray-marched rendering, enabling the creation of complex fractals and composite objects with minimal code overhead [S4, unofficial]. The specific arithmetic formulations for SDFs (min for union, max for intersection) were further detailed in subsequent literature on geometric methods for ray tracing [S2].
