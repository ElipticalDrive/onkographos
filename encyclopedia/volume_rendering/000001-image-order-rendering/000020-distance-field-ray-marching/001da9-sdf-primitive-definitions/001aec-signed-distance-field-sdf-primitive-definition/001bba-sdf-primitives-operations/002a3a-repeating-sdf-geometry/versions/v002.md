# Repeating SDF Geometry
Also called: Modulated SDF, Repeated, Repeated SDF, SDF Repetition (Folding), Tiled SDF, Tiling SDF

## Overview
Repeating SDF Geometry creates a periodic tiling of a base signed distance field by folding 3D coordinates into a fundamental domain centered at the origin [S1, unofficial]. It segments space into infinite parallel regions of repeated distance by taking the modulus of a point’s position along one or more axes before computing the signed distance [S2, unofficial][S3, unofficial][S4, unofficial]. This technique allows for the infinite repetition of geometry for no extra computational cost [S2, unofficial][S3, unofficial][S4, unofficial].

## How it works
**Inputs and Outputs**
*   **Input:** A query point $P = (x, y, z)$, a base SDF function, and a repetition period $T$ [S2, unofficial][S3, unofficial][S4, unofficial].
*   **Output:** The signed distance value from the query point to the tiled geometry [S2, unofficial][S3, unofficial][S4, unofficial].

**Data Structures**
The method operates statelessly on input coordinates [G]. The period $T$ is typically stored as a uniform variable, constant, or struct field [S1, unofficial]. Not given in the sources.

**Parameters**
*   $T$: The spacing between repetitions along each axis. In the canonical example, $T = 4$ [S3, unofficial][S4, unofficial].
*   Offset: Applied before the modulus operation to center the repetition domain. In the canonical example, the offset is $T/2 = 2$ [S3, unofficial][S4, unofficial].

**Algorithm Steps**
1. For each coordinate $c \in \{x, y, z\}$ designated for repetition:
   a. Apply an offset: $c_{off} = c + T/2$.
   b. Apply the modulo operation: $c_{mod} = c_{off} \pmod T$.
   c. Center the result: $c' = c_{mod} - T/2$.
2. Coordinates not designated for repetition are passed through unchanged ($c' = c$) [S2, unofficial][S3, unofficial][S4, unofficial].
3. Construct the transformed point $P' = (x', y', z')$ [S1, unofficial].
4. Evaluate the base SDF at $P'$ to return the signed distance [S1, unofficial][S4, unofficial].

**Formula**
For a coordinate $c$ and period $T$:
$$ c' = \left( (c + \frac{T}{2}) \pmod T \right) - \frac{T}{2} $$

**Pseudocode**
```python
def repeating_sdf(pt: tuple, base_sdf, period: float) -> float:
    """
    Computes the signed distance for repeating geometry.
    
    Args:
        pt: The query point as a tuple (x, y, z).
        base_sdf: The base signed distance function (e.g., sphere, cube).
        period: The spacing between repetitions (scalar applied to x and z in the canonical example).
        
    Returns:
        The signed distance value.
    """
    # Canonical example uses period 4 and offset 2 for x and z, leaving y unchanged [S2, unofficial][S3, unofficial][S4, unofficial]
    x_folded = ((pt[0] + period / 2.0) % period) - period / 2.0
    y_folded = pt[1]
    z_folded = ((pt[2] + period / 2.0) % period) - period / 2.0
    return base_sdf((x_folded, y_folded, z_folded))
```

**Edge Cases and Pitfalls**
*   **Boundary Conditions:** The technique relies on the periodicity of the modulus function to create infinite repetition for no extra cost [S4, unofficial].

## Operating characteristics
*   **Time Complexity:** $O(1)$ per ray step, identical to the base SDF evaluation [G]. The folding operation adds negligible overhead [G].
*   **Memory Complexity:** $O(1)$. No additional memory is required for the tiling logic [G].
*   **Measured Performance:** Infinite repetition is achieved for "no extra cost" compared to a single instance [S2, unofficial][S3, unofficial][S4, unofficial].
*   **Strengths:** Extremely efficient for creating large-scale environments, grids, or repetitive patterns without increasing draw calls or geometry complexity [G].
*   **Limitations:** Only supports periodic, regular tiling [G].
*   **When to use:** When you need to render large numbers of identical objects efficiently [G].
*   **When not to use:** When objects need to be unique or irregularly spaced [G].
