# SDF Rounding

Also called: Distance Offset, Rounding, Rounding Transformation, SDF Offset

## Overview
SDF Rounding is a geometric transformation that modifies a Signed Distance Field (SDF) primitive by subtracting a constant radius value from its distance result, effectively rounding the edges of the shape by that specified radius [S1, S2, unofficial]. It is distinct from domain manipulation operators (which alter the coordinate space) and boolean operations (which combine multiple SDFs), acting instead as a direct offset on the scalar field values [S1, S2, unofficial].

## How it works
**Inputs and Outputs:**
- Input: A query point $p \in \mathbb{R}^3$ and a base SDF function $d(p)$ returning the signed distance to the primitive surface.
- Input: A rounding radius $r \ge 0$.
- Output: The rounded signed distance $d_{rounded}(p)$.

**Data Structures:**
- The SDF function $d(p)$ is typically implemented as a callable returning a float or tensor.
- The radius $r$ is a scalar float.

**Steps:**
1. Evaluate the base SDF at the query point $p$ to obtain the unsigned distance $d = d(p)$.
2. Subtract the rounding radius $r$ from the distance value.
3. Return the result $d_{rounded} = d - r$.

**Formula:**
$$ d_{rounded}(p) = d(p) - r $$

Where:
- $d(p)$ is the signed distance from point $p$ to the original primitive surface.
- $r$ is the rounding radius parameter.

**Parameters:**
- $r$: The distance at which to perform the rounding. Typical values depend on the scale of the primitive; for example, a radius of 0.1 is used in reference implementations [S1, S2, unofficial].

**Edge Cases and Pitfalls:**
- If $r$ is larger than the minimum feature size of the primitive, the SDF may become zero or positive in regions where the primitive should still exist, potentially causing the shape to disappear or invert incorrectly if not handled by the ray marching logic.
- The sign of the distance is preserved relative to the original surface, but the zero-crossing (surface) moves inward by $r$.

**Pseudocode:**
```python
def sdf_rounding(sdf_func, radius):
    """
    Applies SDF rounding to a base signed distance function.
    
    Args:
        sdf_func: A callable that takes a point p (vec3) and returns the signed distance.
        radius: A float representing the rounding radius r.
        
    Returns:
        A callable that returns the rounded signed distance.
    """
    def rounded_sdf(p):
        # Evaluate the base SDF
        d = sdf_func(p)
        # Subtract the radius to round the edges
        return d - radius
    return rounded_sdf
```

## Subtopics

### [SDF Onion](1846-sdf-onion.md)
Creates a hollow shell by taking the absolute value of the rounded distance and subtracting a radius. It is a specific application of SDF Rounding that inverts the interior.

## Operating characteristics
- **Time Complexity:** $O(1)$ per evaluation, as it involves a single subtraction after the base SDF evaluation.
- **Memory Complexity:** $O(1)$, requiring only the storage of the radius parameter.
- **Strengths:** Simple to implement; computationally inexpensive; effectively softens sharp edges without altering the underlying geometry's topology significantly.
- **Limitations:** Does not account for curvature; large radii can distort the shape significantly or cause self-intersections in complex primitives. Not suitable for creating smooth fillets that follow the natural curvature of the object.

## Background
SDF Rounding is a standard technique in ray marching and implicit surface rendering, derived from the mathematical property that offsetting a distance field by a constant value shifts the zero-level set. It is widely used in procedural modeling and real-time rendering to create rounded primitives. The method is implemented in various open-source ray marching libraries [S1, S2, unofficial].
