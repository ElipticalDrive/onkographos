# SDF Onion

Also called: Onion, Onion SDF, SDF Absolute Value Offset, SDF Shell

## Overview
The SDF Onion operation creates a hollow shell or layered structure from a solid Signed Distance Field (SDF) primitive by taking the absolute value of the distance and subtracting a specified radius [S1, S2, unofficial]. It transforms a solid object into a hollow one with a wall thickness equal to the offset radius [S1, unofficial]. It is a specific application of [SDF Rounding](1829-sdf-rounding.md), distinguished by its use of the absolute value function to invert the interior of the shape, effectively creating a void where the original solid existed [S2, unofficial].

## How it works
**Inputs:**
1.  `sdf`: A function or primitive representing a solid shape, returning the signed distance $d$ from a query point $p$.
2.  `radius`: A scalar float $r \ge 0$ representing the thickness of the shell [S2, unofficial].

**Outputs:**
*   A new SDF function returning the distance to the nearest surface of the hollow shell.

**Data Structures:**
*   No complex data structures are required. The operation is a point-wise mathematical transformation applied to the output of the parent SDF.

**Steps:**
1.  Evaluate the parent SDF at the query point $p$ to obtain the signed distance $d = \text{sdf}(p)$ [S2, unofficial].
2.  Compute the absolute value of the signed distance: $d_{abs} = |d|$ [S1, S2, unofficial].
3.  Subtract the radius $r$ from the absolute distance: $d_{onion} = d_{abs} - r$ [S2, unofficial].
4.  Return $d_{onion}$ [S2, unofficial].

**Formula:**
$$ d_{onion}(p) = |\text{sdf}(p)| - r $$

Where:
*   $p$ is the 3D query point.
*   $\text{sdf}(p)$ is the signed distance from $p$ to the original solid shape.
*   $r$ is the shell radius/thickness.

**Parameters:**
*   `radius` ($r$): The thickness of the shell. Typical values depend on the scale of the parent primitive. If $r$ is larger than the minimum dimension of the parent shape, the shell may collapse or become invalid (empty interior) [G].

**Edge Cases and Pitfalls:**
*   **Zero Thickness:** If $r=0$, the result is $|d|$, which represents the distance to the surface of the solid (unsigned distance), effectively making the interior "solid" in terms of ray marching convergence but with inverted normals if used for shading [G].
*   **Large Radius:** If $r$ exceeds the distance from the center to the nearest surface of the parent shape, the resulting SDF may be positive everywhere inside the original volume, creating a large void. If $r$ is very large, the shell may disappear entirely if the parent shape is small [G].
*   **Degenerate Shapes:** For shapes with zero volume or thin surfaces, the absolute value operation combined with subtraction may produce artifacts or unexpected topology if the radius is not carefully chosen relative to the shape's curvature [G].

**Pseudocode:**
```python
def sdf_onion(sdf_func, radius):
    """
    Creates an SDF for a hollow shell from a solid SDF.
    
    Args:
        sdf_func: A callable that takes a 3D point p and returns the signed distance.
        radius: The thickness of the shell (r >= 0).
        
    Returns:
        A callable that returns the signed distance to the shell surface.
    """
    def onion_sdf(p):
        # Step 1: Evaluate parent SDF
        d = sdf_func(p)
        
        # Step 2: Take absolute value
        d_abs = abs(d)
        
        # Step 3: Subtract radius
        d_onion = d_abs - radius
        
        return d_onion
    
    return onion_sdf
```

## Subtopics

### SDF Sphere Onion

## Operating characteristics
*   **Time Complexity:** $O(1)$ per query point, as it involves a constant number of arithmetic operations (absolute value, subtraction) on top of the parent SDF evaluation.
*   **Memory Complexity:** $O(1)$, as no additional data structures are stored.
*   **Strengths:** Simple to implement, computationally cheap, effective for creating hollow objects.
*   **Limitations:** The shell thickness is uniform and determined by the radius parameter. It cannot create variable thickness shells without more complex operations. The interior of the shell is empty, which may require additional logic for ray marching if the ray needs to stop at the inner surface.
*   **When to use:** When a hollow version of a solid primitive is required.
*   **When not to use:** When variable thickness or complex internal structures are needed.

## Background
The SDF Onion operation is a technique derived from constructive solid geometry (CSG) and signed distance field manipulation. It is commonly used in ray marching and implicit surface rendering to create hollow objects. The specific implementation using absolute value and subtraction is a standard trick in the graphics community for creating shells [S1, S2, unofficial]. It is often referred to as "Onion" due to the layered, hollow nature of the resulting shape.
