# Finite Repetition
Also called: Bounded Tiling, Finite Domain Repetition, Limited Repetition

## Overview
Finite Repetition creates a bounded grid of repeated instances of a Signed Distance Function (SDF) by limiting the replication count in each dimension to a specified range $[-l, l]$ [S1, unofficial][S2, unofficial]. Unlike infinite tiling operators that repeat a primitive across the entire domain, this method confines the geometry to a finite box, preventing artifacts from distant, unrendered repetitions. It differs from siblings like [Infinite Repetition](link) by applying a hard clamp on the cell index, and from [Mirrored Repetition](link) by preserving the original orientation without flipping [S1, unofficial][S2, unofficial].

## How it works
**Inputs:**
- $\mathbf{p}$: The query position vector (modified in place).
- $\mathbf{c}$: The period vector defining the cell size in each dimension.
- $\mathbf{l}$: The limit vector defining the maximum number of cells in each direction from the origin.

**Outputs:**
- $\mathbf{p}'$: The transformed position mapped to the nearest valid cell within the bounds.
- (Implicitly) The cell index is calculated but not returned as a separate value in the core formula, though it can be derived from the intermediate step.

**Data Structures:**
- Vectors $\mathbf{p}, \mathbf{c}, \mathbf{l}$ are 3D floating-point vectors.

**Steps:**
1. Normalize the position by the period: compute $\mathbf{u} = \mathbf{p} / \mathbf{c}$.
2. Round to the nearest integer cell index: compute $\mathbf{q} = \text{round}(\mathbf{u})$.
3. Clamp the cell index to the finite bounds: compute $\mathbf{q}_{\text{clamped}} = \text{clamp}(\mathbf{q}, -\mathbf{l}, \mathbf{l})$.
4. Map back to the local coordinate: compute $\mathbf{p}' = \mathbf{p} - \mathbf{c} \cdot \mathbf{q}_{\text{clamped}}$.

**Formula:**
$$ \mathbf{q} = \text{clamp}\left(\text{round}\left(\frac{\mathbf{p}}{\mathbf{c}}\right), -\mathbf{l}, \mathbf{l}\right) $$
$$ \mathbf{p}' = \mathbf{p} - \mathbf{c} \cdot \mathbf{q} $$

**Parameters:**
- $\mathbf{c}$: Cell size. Must be non-zero.
- $\mathbf{l}$: Limit. Must be non-negative.

**Edge Cases:**
- If $\mathbf{c}$ contains zero, division is undefined. [G] Implementers should check for zero components and handle them (e.g., by skipping repetition or using a small epsilon).
- If $\mathbf{p}$ is exactly on the boundary between cells, `round` behavior depends on the implementation (typically round to nearest even or away from zero). Consistency with other operators is required.

**Pseudocode:**
```python
import math

def repeat_finite(p, c, l):
    """
    Finite repetition of an SDF.
    
    Args:
        p (list/tuple of 3 floats): Input position.
        c (list/tuple of 3 floats): Period (cell size) for each dimension.
        l (list/tuple of 3 floats): Limit (max cells) for each dimension.
        
    Returns:
        list/tuple of 3 floats: Transformed position p'.
    """
    # Step 1 & 2: Divide by period and round to nearest integer
    q = []
    for i in range(3):
        if c[i] == 0:
            # [G] Guard against division by zero. 
            # If period is zero, repetition is undefined. 
            # Assuming no repetition in this dimension for safety.
            q.append(0)
        else:
            val = p[i] / c[i]
            # Round to nearest integer
            q.append(math.floor(val + 0.5) if val >= 0 else math.ceil(val - 0.5))
            
    # Step 3: Clamp to limits
    q_clamped = []
    for i in range(3):
        # Clamp between -l[i] and l[i]
        lower = -l[i]
        upper = l[i]
        if q[i] < lower:
            q_clamped.append(lower)
        elif q[i] > upper:
            q_clamped.append(upper)
        else:
            q_clamped.append(q[i])
            
    # Step 4: Map back to local coordinate
    p_prime = []
    for i in range(3):
        p_prime.append(p[i] - c[i] * q_clamped[i])
        
    return p_prime
```

### Finite Domain Repetition

### Limited Repetition
General term for any repetition with a count limit.

## Operating characteristics
- **Time Complexity**: $O(1)$ per query, involving basic arithmetic and clamping.
- **Memory Complexity**: $O(1)$, no additional data structures.
- **Strengths**: Efficiently creates bounded grids without infinite recursion or large memory footprints. Prevents rendering artifacts from distant cells.
- **Limitations**: Only works for axis-aligned grids. Not suitable for curved or non-periodic structures.
- **When to use**: When you need a finite array of objects (e.g., a grid of cubes) and want to avoid the overhead or artifacts of infinite tiling.
- **When not to use**: For infinite patterns or non-grid-based repetitions.

## Background
Finite Repetition is a standard technique in SDF-based rendering for creating bounded periodic structures. It is derived from the general concept of domain manipulation, where the input space is partitioned into cells. The specific clamping mechanism ensures that only a finite number of cells are considered, making it suitable for scenes with limited extent.
