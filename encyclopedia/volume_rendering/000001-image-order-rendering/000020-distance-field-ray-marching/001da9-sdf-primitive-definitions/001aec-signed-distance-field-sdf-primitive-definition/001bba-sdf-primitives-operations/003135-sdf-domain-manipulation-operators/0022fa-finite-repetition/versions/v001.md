# Finite Repetition

Also called: Bounded Tiling, Finite Domain Repetition, Limited Repetition

## Overview
Finite Repetition creates a bounded grid of repeated instances of a base Signed Distance Function (SDF) primitive, limiting the replication count to a specified range in each dimension [S1, S2, unofficial]. Unlike infinite tiling operators, it restricts the domain to a finite box, preventing geometry from extending to infinity [S2, unofficial]. It is chosen when a localized, tiled structure is required without the computational cost or visual artifacts of infinite repetition [S2, unofficial].

## How it works
**Inputs:**
- `p`: Input position vector ($\mathbb{R}^3$).
- `c`: Period vector defining the cell size in each dimension ($\mathbb{R}^3$).
- `l`: Limit vector defining the maximum number of cells to replicate in each dimension ($\mathbb{R}^3$).

**Outputs:**
- `p'`: Transformed position vector mapped to the nearest valid cell within the bounds.

**Data Structures:**
- Vectors `p`, `c`, `l` are typically 3-component floating-point vectors.

**Steps:**
1. Normalize the position by the period: $u = p / c$.
2. Round each component of $u$ to the nearest integer to find the cell index: $q_{raw} = \text{round}(u)$.
3. Clamp the cell indices to the limits: $q = \text{clamp}(q_{raw}, -l, l)$.
4. Map the position back to the local cell: $p' = p - c \cdot q$.

**Formula:**
$$ q = \text{clamp}\left(\text{round}\left(\frac{p}{c}\right), -l, l\right) $$
$$ p' = p - c \cdot q $$

**Parameters:**
- `c`: Must be non-zero. Typical values depend on the desired tile size.
- `l`: Non-negative integers or floats representing the radius of the grid in cells.

**Edge Cases:**
- If `c` contains zero, division is undefined. [G] Guard against zero components in `c`.
- If `l` is zero, the result is the identity transformation (no repetition).

**Pseudocode:**
```python
def repeat_finite(p: Vec3, c: Vec3, l: Vec3) -> Vec3:
    # Step 1 & 2: Divide and round
    q_raw = p / c
    q_raw = q_raw.round()
    
    # Step 3: Clamp to limits
    q = q_raw.clamp(-l, l)
    
    # Step 4: Map back
    p_prime = p - c * q
    
    return p_prime
```

## Subtopics

## Operating characteristics
**Time Complexity:** $O(1)$ per query.
**Memory Complexity:** $O(1)$.
**Strengths:** Efficiently creates bounded tiled structures; avoids infinite recursion or memory issues associated with infinite tiling.
**Limitations:** Only creates a finite grid; not suitable for infinite patterns.
**When to use:** When a limited number of repeated primitives is needed.
**When not to use:** For infinite tiling or when the number of repetitions is not known or bounded.

## Background
Finite Repetition is a domain manipulation operator for SDFs, popularized in the context of ray marching and implicit modeling by authors such as Inigo Quilez and others in the procedural geometry community [S1, S2, unofficial]. It is a variation of infinite tiling, adapted for bounded scenes.
