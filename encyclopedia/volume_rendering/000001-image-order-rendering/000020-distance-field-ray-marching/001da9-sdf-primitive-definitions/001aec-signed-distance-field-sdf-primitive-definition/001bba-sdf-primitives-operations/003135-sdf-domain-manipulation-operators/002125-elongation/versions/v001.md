# Elongation

Also called: Elongation operator, elongation transform

## Overview
Elongation is a domain manipulation operator for Signed Distance Fields (SDFs) that stretches a shape along a specified vector. It solves the problem of creating tapered or extended geometric forms from base primitives without altering the primitive's core definition. It is distinct from [SDF Domain Manipulation Operators](1730-sdf-domain-manipulation-operators.md) in that it specifically modifies the distance value based on a directional vector rather than just transforming the input coordinates, and from [SDF Primitives](1731-sdf-primitives.md) as it is a post-processing step applied to an existing SDF evaluation.

## How it works
**Inputs:**
- $p$: The 3D query point (vector).
- $s$: The elongation vector (vector).
- $SDF_{base}(q)$: The base signed distance function to be elongated.

**Outputs:**
- $d_{out}$: The elongated signed distance value.

**Data Structures:**
- Standard 3D vectors for $p$ and $s$.
- Intermediate vectors $q$ and scalar $d$.

**Steps:**
1. Compute the intermediate vector $q$ by subtracting the elongation vector $s$ from the absolute value of the query point $p$:
   $$ q = |p| - s $$
   [S1, unofficial]
2. Evaluate the base SDF at the positive part of $q$. Let $q_+$ be the component-wise positive part of $q$ (i.e., $q_+ = \max(q, 0)$).
   $$ d_{base} = SDF_{base}(q_+) $$
   [S1, unofficial]
3. Compute the negative part of $q$, clamped to zero:
   $$ q_- = \max(-q, 0) $$
   [S1, unofficial]
4. Add the maximum component of $q_-$ to the base distance. Let $m = \max(q_-)$.
   $$ d_{out} = d_{base} + m $$
   [S1, unofficial]

**Pseudocode:**
```python
def elongation(p, s, sdf_base):
    # Step 1: q = |p| - s
    abs_p = abs(p)
    q = abs_p - s
    
    # Step 2: Evaluate base SDF at positive part of q
    q_pos = max(q, 0.0) # Component-wise max
    d_base = sdf_base(q_pos)
    
    # Step 3: Compute negative part of q clamped to 0
    q_neg = max(-q, 0.0) # Component-wise max
    
    # Step 4: Add max of negative part
    m = max(q_neg) # Maximum component
    d_out = d_base + m
    
    return d_out
```

**Parameters:**
- $s$: The elongation vector. Its magnitude controls the degree of stretch. Direction determines the axis of elongation.

**Edge Cases and Pitfalls:**
- If $s$ is zero, the operator returns the base SDF evaluated at $|p|$.
- Precision issues may arise if $|p|$ and $s$ are very close, leading to cancellation errors in $q$.
- The base SDF must handle the transformed coordinates correctly; if the base SDF assumes a specific orientation, the elongation vector must align with it.

## Subtopics

### End-point Corrector
A technique to address field variation divergence near skeleton end-points in SCALIS fields. It forces an additional sampling position near end-points to increase correlation between the minima of individual primitives and the global field. It is implemented by adding a segment primitive with constant radius at the end vertices of the skeleton. The length of the end-point corrector segment is proportional to the prescribed radius at the end vertices of the skeleton and a constant depending on the kernel used. If end-point correctors are absent, a heuristic presented in section 6.2 of [S2] can compensate for this shortcoming. [S2]

## Operating characteristics
**Time and Memory Complexity:**
- Time: $O(1)$ relative to the base SDF evaluation, plus the cost of the base SDF itself.
- Memory: $O(1)$ for intermediate vectors.

**Measured Performance:**
- Not given in the sources.

**Scaling:**
- Scales linearly with the complexity of the base SDF.

**Strengths and Limitations:**
- Strengths: Simple to implement, computationally cheap, allows for complex shapes from simple primitives.
- Limitations: The resulting SDF may not be perfectly smooth if the base SDF has discontinuities or if the elongation vector causes self-intersections in the distance field logic.

**When to use it and when not:**
- Use when you need to stretch or taper a shape along a specific axis.
- Do not use when you need a perfectly smooth, continuous distance field without any potential artifacts from the max operation, or when the base primitive is not suitable for the elongation direction.
