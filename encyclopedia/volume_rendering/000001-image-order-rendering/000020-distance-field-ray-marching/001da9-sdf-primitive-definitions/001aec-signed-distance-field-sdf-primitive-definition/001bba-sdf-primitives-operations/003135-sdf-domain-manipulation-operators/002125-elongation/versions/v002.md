# Elongation


## Overview
Elongation modifies a base signed distance function by shifting the query point's absolute coordinates by an elongation vector, then adjusting the resulting distance with the maximum negative coordinate offset [S1, unofficial]. It is a post-processing step applied to an existing SDF evaluation, distinct from coordinate-only transformations [S1, unofficial].

## How it works
**Inputs:**
- $p$: The 3D query point (vector).
- $s$: The elongation vector (vector).
- $SDF_{base}(q)$: The base signed distance function to be elongated.

**Outputs:**
- $d_{out}$: The elongated signed distance value.

**Data Structures:**
- Standard 3D vectors for $p$ and $s$.
- Intermediate vector $q$ and scalar $d_{out}$.

**Steps:**
1. Compute the intermediate vector $q$ by subtracting the elongation vector $s$ from the absolute value of the query point $p$:
   $$ q = |p| - s $$
   [S1, unofficial]
2. Evaluate the base SDF at the component-wise positive part of $q$:
   $$ d_{base} = SDF_{base}(\max(q, 0)) $$
   [S1, unofficial]
3. Compute the component-wise negative part of $q$, clamped to zero, and take its maximum component:
   $$ m = \max(\max(-q, 0)) $$
   [S1, unofficial]
4. Add $m$ to the base distance:
   $$ d_{out} = d_{base} + m $$
   [S1, unofficial]

**Pseudocode:**
```python
def elongation(p, s, sdf_base):
    # Step 1: q = |p| - s
    q = abs(p) - s
    
    # Step 2: Evaluate base SDF at positive part of q
    q_pos = max(q, 0.0)  # Component-wise max
    d_base = sdf_base(q_pos)
    
    # Step 3 & 4: Add max of negative part clamped to 0
    q_neg = max(-q, 0.0)  # Component-wise max
    m = max(q_neg)        # Maximum component
    d_out = d_base + m
    
    return d_out
```

## Subtopics

### End-point Corrector
A technique to address field variation divergence near skeleton end-points in SCALIS fields [S2]. It forces an additional sampling position near end-points to increase correlation between the minima of individual primitives and the global field [S2]. It is implemented by adding a segment primitive with constant radius at the end vertices of the skeleton [S2]. The length of the end-point corrector segment is proportional to the prescribed radius at the end vertices of the skeleton and a constant depending on the kernel used [S2]. If end-point correctors are absent, a heuristic presented in section 6.2 of [S2] can compensate for this shortcoming [S2].
