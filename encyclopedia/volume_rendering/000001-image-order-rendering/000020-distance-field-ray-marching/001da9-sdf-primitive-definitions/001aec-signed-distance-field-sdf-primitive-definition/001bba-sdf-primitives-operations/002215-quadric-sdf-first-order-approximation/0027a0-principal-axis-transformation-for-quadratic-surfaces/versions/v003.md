# Principal Axis Transformation for Quadratic Surfaces

Also called: Eigenvalue Analysis of Quadratic Forms, Principal Component Analysis of Quadrics

## Overview
The Principal Axis Transformation (PAT) diagonalizes the quadratic form matrix of a general quadratic function to identify principal curvatures and axes [S1, unofficial]. This method maps a generic quadratic surface to a standard prototype (paraboloid or hyperbolic paraboloid) to enable optimal, error-bounded triangulation of its zero-level set [S1, unofficial].

## How it works
**Inputs and Outputs:**
- Input: Quadratic function coefficients $c_{20}, c_{11}, c_{02}, c_{10}, c_{01}, c_{00}$ [S1, unofficial].
- Output: Eigenvalues $\lambda_1, \lambda_2$, normalized eigenvectors $\mathbf{e}_1, \mathbf{e}_2$, and the classification of the surface type (Elliptic, Hyperbolic, or Parabolic) [S1, unofficial].

**Data Structures:**
- Matrix $C$: A $2 \times 2$ symmetric matrix representing the quadratic form [S1, unofficial].
  $$ C = \begin{pmatrix} c_{20} & c_{11} \\ c_{11} & c_{02} \end{pmatrix} $$
- Eigenvalues: Scalars $\lambda_1, \lambda_2$.
- Eigenvectors: Normalized 2D vectors $\mathbf{e}_1 = (e_{11}, e_{12})^T$, $\mathbf{e}_2 = (e_{21}, e_{22})^T$ [S1, unofficial].

**Steps:**
1. **Construct Matrix C:** Extract the quadratic coefficients from the input function [S1, unofficial]. The linear and constant terms do not affect the principal axes or curvature classification [S1, unofficial].
2. **Compute Eigenvalues:** Solve the characteristic equation $\det(C - \lambda I) = 0$ for $\lambda_1$ and $\lambda_2$ [S1, unofficial].
3. **Compute Eigenvectors:** For each $\lambda_i$, solve $(C - \lambda_i I)\mathbf{v} = 0$ and normalize the resulting vector $\mathbf{v}$ to obtain $\mathbf{e}_i$ [G].
4. **Classify Surface:** Determine the surface type based on the product of the eigenvalues [S1, unofficial]:
   - Elliptic if $\lambda_1 \lambda_2 > 0$.
   - Hyperbolic if $\lambda_1 \lambda_2 < 0$.
   - Parabolic if $\lambda_1 \lambda_2 = 0$ [S1, unofficial].

**Formulas:**
The quadratic function is represented as:
$$ f(x, y) = (x \ y) \begin{pmatrix} c_{20} & c_{11} \\ c_{11} & c_{02} \end{pmatrix} \begin{pmatrix} x \\ y \end{pmatrix} + (c_{10} \ c_{01}) \begin{pmatrix} x \\ y \end{pmatrix} + c_{00} $$
The quadratic form is $\mathbf{x}^T C \mathbf{x} = 0$ [S1, unofficial].

**Pseudocode:**
```python
import math

def principal_axis_transformation(c20, c11, c02, c10, c01, c00):
    # Step 1: Construct Matrix C
    # C is symmetric: [[c20, c11], [c11, c02]]
    # Linear and constant terms are ignored for axis determination [S1, unofficial]
    
    # Step 2: Compute Eigenvalues
    # Characteristic equation: lambda^2 - trace(C)*lambda + det(C) = 0
    trace_C = c20 + c02
    det_C = c20 * c02 - c11 * c11
    discriminant = trace_C**2 - 4 * det_C
    
    if discriminant < 0:
        raise ValueError("Negative discriminant implies complex eigenvalues, invalid for real quadratic surfaces.")
        
    sqrt_disc = math.sqrt(discriminant)
    lambda1 = (trace_C + sqrt_disc) / 2
    lambda2 = (trace_C - sqrt_disc) / 2
    
    # Step 3: Compute Eigenvectors
    # For lambda1
    if abs(c11) > 1e-9:
        e1 = (1.0, (lambda1 - c20) / c11)
    else:
        e1 = (0.0, 1.0) if abs(lambda1 - c02) < 1e-9 else (1.0, 0.0)
    norm1 = math.sqrt(e1[0]**2 + e1[1]**2)
    e1 = (e1[0] / norm1, e1[1] / norm1)
    
    # For lambda2
    if abs(c11) > 1e-9:
        e2 = (1.0, (lambda2 - c20) / c11)
    else:
        e2 = (0.0, 1.0) if abs(lambda2 - c02) < 1e-9 else (1.0, 0.0)
    norm2 = math.sqrt(e2[0]**2 + e2[1]**2)
    e2 = (e2[0] / norm2, e2[1] / norm2)
    
    # Step 4: Classify Surface
    product = lambda1 * lambda2
    if product > 0:
        surface_type = "Elliptic"
    elif product < 0:
        surface_type = "Hyperbolic"
    else:
        surface_type = "Parabolic"
        
    return {
        "lambda1": lambda1,
        "lambda2": lambda2,
        "e1": e1,
        "e2": e2,
        "surface_type": surface_type
    }
```

**Edge Cases and Pitfalls:**
- **Precision:** If $c_{11}$ is near zero, eigenvector calculation may suffer from division by zero; handle via conditional checks [G].
- **Degenerate Input:** If both eigenvalues are zero, the surface is planar and the cluster region can be triangulated by only considering the vertices of its convex boundary polygon [S1, unofficial].

## Subtopics

### [Elliptic Case Triangulation](5516-elliptic-case-triangulation.md)
Generates a mesh for elliptic quadrics ($\lambda_1 \lambda_2 > 0$) by mapping an optimal equilateral prototype triangle from a canonical paraboloid space ($g = \bar{x}^2 + \bar{y}^2$) to the target surface. It is distinguished by its use of the paraboloid prototype and reliance on PAT to preserve error bounds analytically. See [Elliptic Case Triangulation](5516-elliptic-case-triangulation.md).

### Hyperbolic Case Triangulation
Generates a mesh for hyperbolic quadrics ($\lambda_1 \lambda_2 < 0$) by placing vertices exactly on the surface to minimize interpolation error [S1, unofficial]. It uses the prototype $h(\bar{x}, \bar{y}) = \bar{x}^2 - \bar{y}^2$ [S1, unofficial]. The transformation from prototype to original function (for $\lambda_1 > 0, \lambda_2 < 0$) is $\begin{pmatrix} x \\ y \end{pmatrix} = H \begin{pmatrix} \bar{x} \\ \bar{y} \end{pmatrix}$, where $H = \begin{pmatrix} \frac{1}{\sqrt{\lambda_1}} e_{11} & \frac{1}{\sqrt{-\lambda_2}} e_{21} \\ \frac{1}{\sqrt{\lambda_1}} e_{12} & \frac{1}{\sqrt{-\lambda_2}} e_{22} \end{pmatrix}$ [S1, unofficial]. If $\lambda_1 < 0$ and $\lambda_2 > 0$, the triangulation is obtained by considering the quadratic form of $-f$ [S1, unofficial]. Optimal triangle vertices for $h$ are $(\sqrt{\epsilon}, \sqrt{\epsilon})^T$, $(\sqrt{\epsilon}, -\sqrt{\epsilon})^T$, and $((1-\sqrt{5})\sqrt{\epsilon}, 0)^T$ [S1, unofficial]. The maximal error for any edge $ab$ is $\varepsilon_{\text{ab}} = \frac{1}{4} |(a_x - b_x)^2 - (a_y - b_y)^2|$ [S1, unofficial]. The final triangulation is established by transforming two edges according to $H$ [S1, unofficial].

## Background
Originated in the context of multiresolution modeling for scientific visualization, specifically for the triangulation of quadratic surface graphs [S1, unofficial]. The method leverages classical linear algebra techniques (eigenvalue decomposition) to simplify quadratic forms [S1, unofficial].
