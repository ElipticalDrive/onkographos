# Lipschitz Transformation Bounds

Also called: Distances to Transformed Objects, SDF Transformation with Lipschitz Bounds, Transformed implicit surfaces

## Overview
Lipschitz Transformation Bounds compute the distances to implicitly defined surfaces after applying spatial transformations by adjusting the Lipschitz constant of the inverse transformation [S1]. This method provides a valid step size bound for ray marching when the underlying Signed Distance Field (SDF) is transformed [G]. It sets itself apart from [Uniform Scaling of SDFs](2394-uniform-scaling-of-sdfs.md) by handling non-uniform, non-linear, and complex deformations (tapering, twisting) where a single scalar scale factor is insufficient, and from [Implicit Surface Field Function Evaluation](1599-implicit-surface-field-function-evaluation.md) by explicitly addressing the geometric distortion introduced by the coordinate transformation itself [S1].

## How it works
The core problem is that the Lipschitz constant of a composed function $f(T^{-1}(\mathbf{x}))$ is bounded by the product of the Lipschitz constants of $f$ and $T^{-1}$ [S1]. Since $f$ (the base SDF) is typically 1-Lipschitz, the step size in ray marching must be scaled by the Lipschitz constant of the inverse transformation $T^{-1}$ [G].

### Inputs and Outputs
- **Input**: The inverse transformation function $T^{-1}(\mathbf{x})$, the base SDF $d(\mathbf{x})$, and the ray origin $\mathbf{o}$ and direction $\mathbf{d}$ [S1].
- **Output**: A valid step size $\Delta t$ for ray marching, derived from the local Lipschitz bound $L$ of $T^{-1}$ [G].

### Data Structures
No specific complex data structures are required beyond standard vector/matrix types. For interval-based analysis (e.g., tapering), an interval representation $[min, max]$ is used to bound the transformation parameters over a step [S2].

### Steps
1. **Identify Transformation Type**: Determine the analytical form of $T^{-1}$ (Isometry, Uniform Scale, Linear Deformation, Taper, or Twist) [S1].
2. **Compute Lipschitz Constant ($L$)**: Calculate the maximum norm of the Jacobian of $T^{-1}$ over the relevant domain [S1].
   - For **Isometries** (rotations, translations, reflections), $L = 1$. The distance is preserved:
     $$ d(T^{-1}(\mathbf{0})) = d(T^{-1}(\mathbf{x}) - T^{-1}(\mathbf{0})) \quad \text{(Eq. 45)} $$
   - For **Uniform Scale** $s$, where $T(\mathbf{x}) = s\mathbf{x}$, the inverse is scaling by $1/s$. The Lipschitz constant is $1/s$. The distance is:
     $$ d(s T^{-1}(\mathbf{0})) = \frac{1}{s} d(T^{-1}(\mathbf{x}) - T^{-1}(\mathbf{0})) \quad \text{(Eq. 47)} $$
   - For **Linear Deformation**, use the power method to find the largest eigenvalue of the inverse transformation matrix [S1].
   - For **Taper**, compute the minimum scaling factor along the taper axis [S1].
   - For **Twist**, compute the bound over a constrained domain (e.g., unit cylinder) [S1].
3. **Calculate Step Size**: Given the base SDF value $d_{base}$ at the current ray position, the safe step size is:
     $$ \Delta t = \frac{d_{base}}{L} $$
     [G] In practice, a small epsilon is often subtracted from $d_{base}$ to prevent infinite loops at exact intersections.

### Formulas and Parameters
- **Taper Lipschitz Constant**:
  The taper deformation scales two axes by a function $\alpha(z)$ of the third axis. The inverse uses $\alpha^{-1}(z)$. The Lipschitz constant is the tightest tapering amount:
  $$ Lip_{taper} = \min \frac{1}{\alpha(z)} \quad \text{(Eq. 49)} $$
  [G] The minimum is taken over the interval of $z$ traversed by the ray step.

- **Twist Lipschitz Constant**:
  Twisting rotates two axes by a linear function $\theta(z)$ of the third axis. Twisting is not Lipschitz on unbounded domains; it must be constrained to a domain like a unit cylinder along the twisting axis. The Lipschitz constant for the bounded twist is:
  $$ Lip_{twist} = \sqrt{4 + \frac{\theta^2}{4}} \quad \text{(Eq. 51)} $$
  Here, $\theta$ represents the angular rate of twist [S1].

### Edge Cases and Pitfalls
- **Unbounded Twist**: Twisting is not Lipschitz over unbounded domains because the distance between points grows linearly with their distance from the twisting axis. It must be constrained to a specific domain (e.g., unit cylinder) to satisfy the Lipschitz criterion [S1].
- **Precision**: Numerical instability in computing the Jacobian norm for complex deformations can lead to invalid step sizes. Interval analysis is recommended for robust bounds [S2].

### Pseudocode
```python
import math

def compute_lipschitz_bound(transformation_type, params, ray_interval):
    """
    Computes the Lipschitz constant L for the inverse transformation T^-1.
    
    Args:
        transformation_type: str ('isometry', 'uniform_scale', 'taper', 'twist')
        params: dict of transformation parameters (e.g., scale, alpha_func, theta)
        ray_interval: tuple (z_min, z_max) for interval evaluation
        
    Returns:
        L: float, the Lipschitz constant of the inverse transformation
    """
    if transformation_type == 'isometry':
        return 1.0
    elif transformation_type == 'uniform_scale':
        s = params['scale']
        return 1.0 / s
    elif transformation_type == 'taper':
        # Taper scales x, y by alpha(z). Inverse uses alpha_inv(z).
        # L = min(1/alpha(z)) over the interval.
        # We evaluate alpha(z) at the interval endpoints and find the minimum.
        z_min, z_max = ray_interval
        alpha_min = min(params['alpha_func'](z_min), params['alpha_func'](z_max))
        if alpha_min <= 0:
            return float('inf') # Degenerate case
        return 1.0 / alpha_min
    elif transformation_type == 'twist':
        # Twist is bounded to a unit cylinder.
        # L = sqrt(4 + theta^2 / 4)
        theta = params['theta_rate']
        return math.sqrt(4 + (theta ** 2) / 4)
    else:
        raise ValueError("Unsupported transformation type")
```

## Subtopics

### Lipschitz Bound Computation for Tapering Transformation
A method to compute the bound of the norm of the Jacobian for a tapering transformation to determine the Lipschitz bound. For a given input interval $e$, $\|J_{\omega^{-1}}(e)\|$ can be obtained by developing the equation or by interval analysis. The Jacobian matrix for tapering transformation $\omega^{-1}(\mathbf{p}) = (\alpha(z)x, \alpha(z)y, z)$ where $\beta = \alpha'$ is:
$$ \mathbf{J}_{\omega^{-1}} = \begin{pmatrix} \alpha & 0 & \beta \\ 0 & \alpha & 0 \\ \beta & 0 & 1 \end{pmatrix} $$
The Euclidean norm is:
$$ \|\mathbf{J}_{\omega^-}\| = \frac{1}{\sqrt{2}}\sqrt{\alpha^2 + 2\beta^2 + 1 + (1 + \alpha)\sqrt{\alpha^2 - 2\alpha + 4\beta^2 + 1}} $$
This formulation enables robust interval-based evaluation of the Lipschitz bound for tapered deformations [S2].

## Operating characteristics
- **Time Complexity**: $O(1)$ for isometry, uniform scale, and twist (closed-form). $O(k)$ for taper and linear deformation where $k$ is the cost of evaluating the Jacobian norm or solving for eigenvalues (power method).
- **Memory Complexity**: $O(1)$.
- **Strengths**: Handles complex, non-linear deformations (taper, twist) that break simple scaling assumptions. Provides mathematically guaranteed step sizes for convergence.
- **Limitations**: Twist requires domain constraints (unit cylinder). Taper requires careful evaluation of the minimum scaling factor. Linear deformation requires iterative eigenvalue computation.
- **When to use**: When transforming SDFs with non-uniform, non-linear, or rotational deformations.
- **When not to use**: For simple uniform scaling (use [Uniform Scaling of SDFs](2394-uniform-scaling-of-sdfs.md)) or rigid body motion (isometry).

## Background
The method originates from the geometric ray tracing of implicit surfaces, specifically in the context of Sphere Tracing. It was detailed in the seminal paper "Sphere Tracing: A Geometric Method for the Antialiased Ray Tracing of Implicit Surfaces" [S1]. The analysis of Lipschitz bounds for specific deformations like tapering and twisting was further refined in "Segment Tracing Using Local Lipschitz Bounds" [S2].
