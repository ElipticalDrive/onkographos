# SDDF with Ellipsoidal Priors and Neural Residuals

Also called: Signed Directional Distance Function (SDDF), Scene-level SDDF

## Overview
This method learns a scene-level Signed Directional Distance Function (SDDF) using a hybrid explicit-implicit representation to enable fast, single-query differentiable novel view synthesis and geometric reconstruction [S1]. It solves the challenge of learning directional distance fields for complex scenes by combining an explicit ellipsoidal prior, which approximates coarse object shapes and occlusions, with an implicit neural residual network that refines fine details [S1]. Unlike standard SDFs that require iterative sphere tracing, or NeRFs that optimize volume density for photometry, this approach directly predicts the signed distance to the nearest surface along a specific viewing direction in a single forward pass [S1].

## How it works
The model predicts the SDDF value $\hat{f}(\mathbf{p}, \mathbf{v})$ for a query position $\mathbf{p} \in \mathbb{R}^3$ and viewing direction $\mathbf{v} \in S^2$ by summing an explicit ellipsoidal prior $f(\mathbf{p}, \mathbf{v})$ and a neural residual $\delta f(\mathbf{p}, \mathbf{v})$ [S1]:

$$ \hat{f}(\mathbf{p}, \mathbf{v}) = f(\mathbf{p}, \mathbf{v}) + \delta f(\mathbf{p}, \mathbf{v}) $$

The SDDF is defined such that it is continuous when a ray enters occupied space from free space, but discontinuous when leaving occupied space [S1]. The method assumes sensors remain in free space and observe the scene from outside-in, avoiding the discontinuity issue [S1].

### Data Structures

**Ellipsoidal Prior Parameters:**
The prior consists of $N$ ellipsoids. For each ellipsoid $i \in \{1, \dots, N\}$, the parameters are:
*   Center $\mathbf{c}_i \in \mathbb{R}^3$
*   Rotation matrix $\mathbf{R}_i \in \mathbb{R}^{3 \times 3}$ (orthonormal)
*   Scale vector $\mathbf{s}_i \in \mathbb{R}^3$ (semi-axes lengths)
*   Weight $\alpha_i \in \mathbb{R}$ (optional, often normalized)

**Neural Residual Network:**
*   **Latent Network ($L$):** A small MLP that takes the intersection point and viewing direction to produce a latent feature vector $\mathbf{z} \in \mathbb{R}^m$.
*   **Residual Decoder ($R$):** An MLP that takes $\mathbf{z}$ and outputs the residual scalar $\delta f$.

### Inputs and Outputs
*   **Inputs:** 3D position $\mathbf{p}$, viewing direction $\mathbf{v}$.
*   **Outputs:** Signed distance $\hat{f}(\mathbf{p}, \mathbf{v})$.
*   **Training Data:** RGB-D images or LiDAR scans. RGB-D data is downsampled (20× for most datasets, 5× for Replica Hotel) to match LiDAR ray density [S1].

### Algorithm Steps

1.  **Initialize Ellipsoids:**
    Initialize $N$ ellipsoids to approximate the scene geometry. $N=128$ for most scenes, $N=256$ for Gibson Allensville [S1]. Initialization should not rely solely on K-means++ as it over-segments planar surfaces; a specialized initialization is preferred [S1].

2.  **Compute Ellipsoidal Prior $f(\mathbf{p}, \mathbf{v})$:**
    For each ellipsoid $i$, compute the distance from $\mathbf{p}$ to the ellipsoid surface along direction $\mathbf{v}$. The prior $f(\mathbf{p}, \mathbf{v})$ is the minimum signed distance among all ellipsoids that are "visible" or relevant, typically the closest intersection [S1]. The specific closed-form SDDF for an ellipsoid is defined in [Ellipsoid SDDF Prior](10639-ellipsoid-sddf-prior.md). The prior is optimized using closed-form gradients to accelerate training [S1].

3.  **Construct Latent Feature:**
    Find the intersection point $\mathbf{p}_{int} = \mathbf{p} + f(\mathbf{p}, \mathbf{v})\mathbf{v}$ on the surface predicted by the prior. Construct a latent feature $\mathbf{z}$ using $\mathbf{p}_{int}$ and $\mathbf{v}$. The construction must satisfy the directional Eikonal constraint to ensure robustness to viewing distance [S1].
    *   *Embedding:* The inputs to the Latent Network are embedded. The source notes a Fourier embedding ablation: $\mathbf{m} = [\sin(2\pi\mathbf{B}_{\text{p}}\mathbf{p}), \cos(2\pi\mathbf{B}_{\text{p}}\mathbf{p}), \sin(2\pi\mathbf{B}_{\text{v}}\mathbf{v}), \cos(2\pi\mathbf{B}_{\text{v}}\mathbf{v})]$ where $\mathbf{B}_p, \mathbf{B}_v \in \mathbb{R}^{25 \times 3}$ are random Fourier features sampled from $\mathcal{N}(0, 1)$ [S1]. However, the method prefers **polynomial embedding** for better generalization across scenes without scene-specific frequency tuning [S1].

4.  **Predict Residual:**
    Pass $\mathbf{z}$ through the Residual Decoder $R$ to get $\delta f(\mathbf{p}, \mathbf{v})$ [S1].

5.  **Combine:**
    Compute $\hat{f}(\mathbf{p}, \mathbf{v}) = f(\mathbf{p}, \mathbf{v}) + \delta f(\mathbf{p}, \mathbf{v})$ [S1].

6.  **Training Optimization:**
    *   **Loss:** Minimize the difference between $\hat{f}(\mathbf{p}, \mathbf{v})$ and ground truth SDDF values derived from sensor measurements.
    *   **Eikonal Constraint:** The model is designed such that the combination satisfies an Eikonal-like constraint by construction, ensuring unit gradient magnitude properties [S1].
    *   **Negative Sample Augmentation:** Crucial for training. Without negative SDDF samples (points inside objects), ellipsoids regress into the interior, causing missing ray intersections and wrong ellipsoid selection [S1].

### Parameters and Typical Values
*   **Number of Ellipsoids:** 128 (standard), 256 (Gibson Allensville) [S1].
*   **RGB-D Downsampling:** 20× (most datasets), 5× (Replica Hotel) [S1].
*   **Embedding Dimensions:** 25 dimensions per input (position/direction) in Fourier ablation [S1].
*   **Random Fourier Features:** Sampled from $\mathcal{N}(0, 1)$ [S1].

### Edge Cases and Pitfalls
*   **Discontinuity:** The SDDF definition is discontinuous when a ray leaves occupied space. This is handled by assuming sensors stay in free space and only observe from outside-in [S1].
*   **Too Few Ellipsoids:** Prevents accurate approximation of object shapes [S1].
*   **Too Many Ellipsoids:** Causes spurious occlusions between ellipsoids and moves redundant ellipsoids out of the scene during testing [S1].
*   **Missing Negative Samples:** Without negative SDDF samples, ellipsoids regress into object interiors, leading to missing ray intersections and incorrect ellipsoid selection [S1].
*   **K-means++ Initialization:** Causes larger errors by using excessive ellipsoids for planar surfaces [S1].
*   **Embedding Choice:** Fourier embedding requires scene-specific spatial frequency tuning; polynomial embedding is preferred for generalization [S1].

## Subtopics

### [Ellipsoid SDDF Prior](10639-ellipsoid-sddf-prior.md)
A closed-form analytical function for computing the SDDF of a single ellipsoid, serving as the geometric prior. It provides the coarse structure and handles occlusion modeling explicitly. Choose this when you need a differentiable, explicit geometric primitive for the coarse approximation stage.

## Operating characteristics
*   **Time Complexity:** Inference is a single forward pass, making it significantly faster than iterative sphere tracing (SDF-Instant-NGP) or volume rendering (Nerfacto). On Replica-Hotel (Intel 14900K, RTX-3090), inference is 69 ms/frame, which is 1.5× faster than SDF-Instant-NGP and 4× faster than Nerfacto [S1].
*   **Memory Complexity:** Low GPU memory usage. Max training memory is 3.3 GB on Replica-Hotel, lower than RaDe-GS (18.7 GB) and Nerfacto (4.7 GB) [S1].
*   **Training Time:** 100 minutes on Replica-Hotel, slower than SDF-Instant-NGP (3 min) and RaDe-GS (30 min), attributed to the extra direction input and hybrid optimization [S1].
*   **Accuracy:** State-of-the-art MAE on Replica and Gibson datasets for both LiDAR and RGB-D inputs. Outperforms Nerfacto in distance prediction error and captures sharper details than SDF-Instant-NGP [S1].
*   **Strengths:** Single-query differentiable synthesis, low memory, handles occlusions well via explicit prior, robust to viewing distance due to Eikonal constraint satisfaction.
*   **Limitations:** Slower inference than highly optimized Gaussian Splatting (RaDe-GS: 7 ms vs 69 ms), requires careful initialization and negative sample augmentation.

## Background
The method was introduced in "Learning Scene-Level Signed Directional Distance Function With Ellipsoidal Priors and Neural Residuals" [S1]. It addresses limitations of previous SDDF formulations: object-level SDDF [15] ignores objects behind the viewing position, and PDDF [16] lacks sign information and has discontinuities. This work defines a scene-level SDDF that is continuous when entering occupied space and retains sign information. It builds on [SDF Training with Eikonal Loss](2553-sdf-training-with-eikonal-loss.md) by incorporating Eikonal regularization but extends it to the directional domain with a hybrid explicit-implicit architecture.
