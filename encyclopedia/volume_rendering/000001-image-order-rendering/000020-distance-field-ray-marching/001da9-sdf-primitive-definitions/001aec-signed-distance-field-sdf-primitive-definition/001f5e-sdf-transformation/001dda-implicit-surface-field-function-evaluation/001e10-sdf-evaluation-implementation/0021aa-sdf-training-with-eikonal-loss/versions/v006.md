# SDF Training with Eikonal Loss

Also called: SDF Surface Training with Eikonal Loss, Neural SDF Training with Eikonal Regularization

## Overview
SDF Training with Eikonal Loss optimizes a neural implicit Signed Distance Function (SDF) to reconstruct a 3D surface from point cloud data by enforcing the Eikonal equation, which requires the gradient magnitude of the SDF to be unity everywhere [S2][S3, S4, unofficial]. Unlike density-based volume rendering methods like [NeRF](1000-nerf.md) that predict scalar density and color, this method predicts a signed distance value, allowing for explicit surface extraction and topological consistency through gradient regularization [S4, unofficial][S7]. It differs from [SDF Optimization via Finite Differences](3086-sdf-optimization-via-finite-differences.md) by using automatic differentiation for exact gradient computation rather than numerical approximation [S3, S4, unofficial].

## How it works
**Inputs and Outputs:**
*   **Input:** A point cloud dataset $P = \{p_i\}$ with associated normals $N = \{n_i\}$ (optional but recommended for orientation), and a bounding box $\Omega$ defining the training volume [S2][S3, S4, unofficial].
*   **Output:** A trained Multi-Layer Perceptron (MLP) $\Phi(x; \theta)$ that outputs the signed distance $d$ and its gradient $\nabla \Phi$ for any 3D coordinate $x$ [S3, S4, unofficial].

**Data Structures:**
*   **MLP $\Phi$:** A feedforward neural network. The input is a 3D coordinate vector $x \in \mathbb{R}^3$. The output is a scalar distance $d \in \mathbb{R}$ and optionally the gradient vector $\nabla \Phi \in \mathbb{R}^3$ [S3, S4, unofficial].
*   **Point Cloud Tensor:** A tensor of shape $(N, 3)$ containing vertex coordinates, typically centered at the origin [S3, S4, unofficial].
*   **Optimizer State:** Parameters $\theta$ for the MLP, updated via an optimizer (e.g., Adam) [S3, S4, unofficial].

**Parameters:**
*   $\lambda_{Eik}$: Weight for the Eikonal regularization term. Typical value: $0.02$ [S1].
*   $\lambda_{inter}$: Weight for the interior regularization term (penalizing points inside the object). Typical value: derived from `cfg.training.inter_weight` [S3, S4, unofficial].
*   $\beta_0$: Parameter for the exponential decay in interior loss. Typical value: $1.0$ [S2].
*   `batch_size`: Number of points sampled per optimization step [S3, S4, unofficial].
*   `bounds`: Spatial limits $[min_x, max_x, min_y, max_y, min_z, max_z]$ for sampling random points [S3, S4, unofficial].
*   `lr`: Learning rate for the optimizer [S4, unofficial].

**Numbered Steps:**

1.  **Initialization:**
    *   Load the point cloud data.
    *   Center the point cloud by subtracting the mean: $P_{centered} = P - \text{mean}(P)$ [S3, S4, unofficial].
    *   Initialize the MLP $\Phi$ and the optimizer (e.g., Adam) with learning rate `lr` [S3, S4, unofficial].
    *   [G] Ensure the MLP weights are initialized appropriately (e.g., He or Xavier initialization) to avoid vanishing gradients initially.

2.  **Sampling:**
    *   Sample a batch of points $P_{cloud}$ uniformly from the centered point cloud $P_{centered}$ [S3, S4, unofficial].
    *   Sample a batch of points $P_{rand}$ uniformly within the bounding box $\Omega$ [S3, S4, unofficial].

3.  **Forward Pass (Point Cloud):**
    *   Query the MLP for distances at $P_{cloud}$: $d_{cloud} = \Phi(P_{cloud})$ [S3, S4, unofficial].
    *   Compute the Point Cloud Loss $\mathcal{L}_{data}$:
        $$ \mathcal{L}_{data} = \frac{1}{N_{cloud}} \sum_{i=1}^{N_{cloud}} |d_{cloud}^{(i)}| $$
        [S3, S4, unofficial]. Note: If normals are available, a normal consistency term can be added: $\lambda_3 |1 - \langle \nabla \Phi(x), n(x) \rangle|$ [S2].

4.  **Forward Pass (Random Points):**
    *   Query the MLP for distances and gradients at $P_{rand}$: $(d_{rand}, \nabla \Phi_{rand}) = \Phi(P_{rand})$ [S3, S4, unofficial].
    *   Compute the Interior Regularization Loss $\mathcal{L}_{inter}$:
        $$ \mathcal{L}_{inter} = \frac{1}{N_{rand}} \sum_{i=1}^{N_{rand}} \exp(-\beta_0 |d_{rand}^{(i)}|) $$
        [S2][S3, S4, unofficial]. This term penalizes points close to the surface (where $d \approx 0$) to prevent the network from predicting zero everywhere [S3, S4, unofficial].

5.  **Eikonal Loss Computation:**
    *   Compute the Eikonal Loss $\mathcal{L}_{eikonal}$:
        $$ \mathcal{L}_{eikonal} = \frac{1}{N_{rand}} \sum_{i=1}^{N_{rand}} \left( \|\nabla \Phi_{rand}^{(i)}\|_2 - 1 \right)^2 $$
        [S3, S4, unofficial]. Alternatively, an L1 version is used: $\frac{1}{N} \sum |\|\nabla \Phi\|_2 - 1|$ [S2].

6.  **Total Loss and Optimization:**
    *   Compute the total loss:
        $$ \mathcal{L}_{total} = \mathcal{L}_{data} + \lambda_{Eik} \mathcal{L}_{eikonal} + \lambda_{inter} \mathcal{L}_{inter} $$
        [S2][S3, S4, unofficial].
    *   Perform backpropagation: `optimizer.zero_grad()`, `loss.backward()`, `optimizer.step()` [S3, S4, unofficial].

**Pseudocode:**

```python
import torch
import torch.nn as nn
import torch.optim as optim

class NeuralSDF(nn.Module):
    def __init__(self, hidden_dim=256, num_layers=8):
        super().__init__()
        layers = []
        for i in range(num_layers):
            layers.append(nn.Linear(3, hidden_dim))
            layers.append(nn.ReLU())
        layers.append(nn.Linear(hidden_dim, 1))
        self.network = nn.Sequential(*layers)

    def forward(self, x):
        # x shape: (N, 3)
        return self.network(x)

    def get_distance_and_gradient(self, x):
        x.requires_grad_(True)
        dist = self.forward(x)
        # Compute gradient of distance w.r.t input x
        grad = torch.autograd.grad(
            dist.sum(), x, create_graph=True, retain_graph=True, only_inputs=True
        )[0]
        return dist, grad

def eikonal_loss(gradients):
    # gradients shape: (N, 3)
    grad_norms = torch.norm(gradients, dim=1)
    return torch.mean((grad_norms - 1.0) ** 2)

def train_sdf(model, point_cloud, bounds, batch_size, num_epochs, lr, 
              lambda_eik=0.02, lambda_inter=1.0, beta_0=1.0):
    optimizer = optim.Adam(model.parameters(), lr=lr)
    
    # Center point cloud
    points = point_cloud - torch.mean(point_cloud, dim=0)
    points = points.cuda()
    
    for epoch in range(num_epochs):
        # 1. Sample points from point cloud
        indices = torch.randint(0, len(points), (batch_size,))
        cloud_points = points[indices]
        
        # 2. Sample random points in bounds
        # bounds: [min_x, max_x, min_y, max_y, min_z, max_z]
        rand_points = torch.rand(batch_size, 3).cuda()
        rand_points = rand_points * (bounds[1::2] - bounds[0::2]) + bounds[0::2]
        
        # 3. Compute Point Cloud Loss
        dist_cloud, _ = model.get_distance_and_gradient(cloud_points)
        loss_data = torch.mean(torch.abs(dist_cloud))
        
        # 4. Compute Random Points Loss (Eikonal + Interior)
        dist_rand, grad_rand = model.get_distance_and_gradient(rand_points)
        
        # Eikonal Loss: ||grad||_2 = 1
        loss_eik = eikonal_loss(grad_rand)
        
        # Interior Loss: penalize points near surface
        # exp(-beta_0 * |dist|)
        loss_inter = torch.mean(torch.exp(-beta_0 * torch.abs(dist_rand)))
        
        # 5. Total Loss
        loss = loss_data + lambda_eik * loss_eik + lambda_inter * loss_inter
        
        # 6. Backpropagate
        optimizer.zero_grad()
        loss.backward()
        optimizer.step()
        
        if epoch % 100 == 0:
            print(f"Epoch {epoch}, Loss: {loss.item():.4f}")
```

## Subtopics

### [Sphere Loss](2750-sphere-loss.md)
A regularization term used during the pretraining phase to initialize the SDF network as a sphere, providing a stable geometric prior before refining with point cloud data and Eikonal regularization.

### [MLP Distillation](4829-mlp-distillation.md)
Compresses a large SDF network into a smaller MLP by minimizing output discrepancy, transferring geometric knowledge from a teacher to a student network.

### [SDDF with Ellipsoidal Priors and Neural Residuals](10638-sddf-with-ellipsoidal-priors-and-neural-residuals.md)
Combines explicit ellipsoidal priors with implicit neural residuals to learn a Signed Directional Distance Function, handling occlusions and fine details while satisfying the directional Eikonal constraint.

### [SDF-Instant-NGP Training](10640-sdf-instant-ngp-training.md)
Defines the training procedure for an SDF baseline using specific hyperparameters and includes a sign loss term to enforce positive SDF values outside the surface.

### [TetraSDF Training Procedure](13235-tetrasdf-training-procedure.md)
Optimizes a neural network using a multi-resolution tetrahedral grid, combining L1 regression, Eikonal regularization, and weight normalization for efficient multi-resolution handling.

### Bias Network for High-Fidelity Points
A network that captures geometric bias between volume rendering and point modeling, trained on high-fidelity points to enhance detail representation [S5, unofficial]. It filters points with predicted variance below a threshold $\epsilon$ to create a set $P_s$, then optimizes a bias MLP $f_b$ using L1 loss against ideal SDF values (0) for these points [S5, unofficial]. The final SDF is the sum of the base SDF and the bias SDF: $f_{final}(x_P) = f(x_P) + f_b(x_P)$ [S5, unofficial].

### SDF Training with Chamfer Distance
Trains a neural network to predict Unsigned Distance Function (UDF) values and gradients, projecting query points onto the implicit surface via gradient descent and minimizing Chamfer distance to ground truth points [S6, unofficial]. The projection step uses the formula $x_{moved} = x_{sample} - \frac{\nabla \text{UDF}(x_{sample})}{\|\nabla \text{UDF}(x_{sample})\|} \cdot \text{UDF}(x_{sample})$ [S6, unofficial]. A critical pitfall is ensuring `samples.requires_grad = True` before computing gradients [S6, unofficial].

### Implicit Surface to Volume Transformation
Represents scene geometry as a surface $S = \{x \in \mathbb{R}^3 \mid F(x) = 0\}$ and transforms it into a volumetric model for rendering [S7]. It enforces the Eikonal property via a loss term and converts SDF values to pseudo-density $\sigma_i$ using a Laplace cumulative distribution function $\Psi(d)$ with an optimizable scale parameter $\beta$ [S7]. Unlike volumetric radiance fields, it restricts density prediction to spatial coordinates $x$ while allowing color to depend on view direction [S7].

## Operating characteristics
*   **Time Complexity:** $O(N \cdot L)$ per iteration, where $N$ is the number of sampled points and $L$ is the depth of the MLP [S3, S4, unofficial]. Gradient computation adds a similar cost due to backpropagation through the network [S3, unofficial].
*   **Memory Complexity:** $O(N)$ to store the gradients and intermediate activations for the batch of points [S3, S4, unofficial].
*   **Measured Performance:** Applying mild Eikonal regularization ($\lambda_{Eik} = 0.02$) significantly improves Hausdorff Distance (HD) by suppressing spurious outliers, though it may cause a marginal decrease in Chamfer Distance and F1 score compared to an unregularized baseline [S1].
*   **Strengths:** Enforces topological consistency and clean surface extraction; differentiable gradients allow for precise surface normal estimation; compatible with various neural network architectures [S1][S3, S4, unofficial].
*   **Limitations:** Requires careful tuning of regularization weights ($\lambda_{Eik}$, $\lambda_{inter}$) to balance surface precision and topological correctness; sensitive to the initialization and bounding box definition [S1][S3, unofficial].
*   **When to Use:** When high-quality surface reconstruction from point clouds is required, and explicit surface extraction or normal consistency is needed [S2][S3, unofficial].
*   **When Not to Use:** When the scene has complex transparency or volumetric effects that cannot be represented by a single implicit surface [S7].

## Background
The method originates from the application of neural implicit representations for 3D geometry reconstruction, specifically leveraging the properties of Signed Distance Functions (SDFs) [S2][S3, unofficial]. The Eikonal regularization term, enforcing $|\nabla \Phi(x)| = 1$, is a standard constraint for SDFs to ensure the function represents a true distance field [S2][S3, S4, unofficial]. Early implementations used this approach for point cloud reconstruction and neural surface rendering, distinguishing it from density-based methods like NeRF [S2][S4, unofficial]. The technique has been further developed in various contexts, including integration with hash encoding for efficiency [S2] and adaptation for specific rendering pipelines like VolSDF [S3, unofficial][S7].
