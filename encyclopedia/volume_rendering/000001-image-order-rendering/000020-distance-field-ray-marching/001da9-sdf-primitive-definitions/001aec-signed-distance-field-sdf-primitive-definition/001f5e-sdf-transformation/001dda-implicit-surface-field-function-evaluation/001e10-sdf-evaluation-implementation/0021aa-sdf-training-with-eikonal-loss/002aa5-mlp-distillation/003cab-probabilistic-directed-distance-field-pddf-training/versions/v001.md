# Probabilistic Directed Distance Field (PDDF) Training

Also called: DDF Learning and Loss Functions, PDDF Optimization, Probabilistic Directed Distance Field (PDDF), View Consistency Inequality

## Overview
Probabilistic Directed Distance Field (PDDF) Training is a method for learning directed distance fields (DDFs) from mesh data by allowing the depth output to be a probability distribution rather than a scalar. This approach solves the problem of representing discontinuous depth and visibility fields with a continuous ($C^1$) neural network, which is essential for handling occlusions and surface boundaries without artifacts. It sets itself apart from standard SDF training by explicitly modeling view-dependent discontinuities through a mixture of Dirac deltas, enabling differentiable rendering via ray-casting that depends only on a single forward pass [S1].

## How it works
**Inputs and Outputs:**
*   **Input:** A triangular mesh defining surface $S$ and bounding volume $B$.
*   **Output:** A neural network predicting a visibility field $\xi(p, v) \in [0, 1]$ and a probabilistic depth field $P_{p,v}(d)$.

**Data Structures:**
The network outputs $K$ components for each oriented point $\tau = (p, v)$:
1.  **Visibility:** $\widehat{\xi} \in \mathbb{R}$ (sigmoid output).
2.  **Mixture Weights:** $\widehat{w}_i \in \mathbb{R}$ for $i \in \{1, \dots, K\}$, constrained such that $\sum_{i=1}^K \widehat{w}_i = 1$.
3.  **Delta Locations:** $\widehat{d}_i \in \mathbb{R}$ for $i \in \{1, \dots, K\}$, representing candidate depths.

The predicted probability distribution is:
$$ P_{p,v}(d) = \sum_{i=1}^K \widehat{w}_i \delta(d - \widehat{d}_i) $$
The final predicted depth is $d^* = \widehat{d}_{i^*}$, where $i^* = \arg\max_i \widehat{w}_i$ [S1].

**Parameters:**
*   $K$: Number of Dirac delta components. Typical value is $K=2$ [S1].
*   $\gamma_{\text{E},d}, \gamma_{\text{E},\xi}$: Eikonal regularization weights [S1].
*   $\gamma_V, \gamma_T$: Weight field regularization weights [S1].

**Ground Truth Extraction:**
Samples are generated from the mesh in six types [S1]:
1.  **(U) Uniform:** Random $(p, v)$ in bounding box.
2.  **(A) At-surface:** Points where ground truth visibility $\xi(p, v)=1$.
3.  **(B) Bounding:** $p \in \partial B$ with $v$ pointing interior.
4.  **(S) Surface:** $p \in S$ with $v \sim U[S^2]$ (uniform on sphere).
5.  **(T) Tangent:** $v$ lies in the tangent space of the surface point $q(p, v)$.
6.  **(O) Offset:** $p$ offset from (T) samples along normal $n(p, v)$ by a small value.

**Loss Functions:**
Let $\xi, n, d$ be ground truth visibility, normal, and depth. Let $\widehat{\xi}, \widehat{w}_i, \widehat{d}_i$ be network predictions. Let $i^* = \arg\max_j \widehat{w}_j$ [S1].

1.  **Minimum Distance Loss:** Trains the highest probability depth component [S1]:
    $$ \mathcal{L}_d = \xi | \widehat{d}_{i^*} - d | $$
2.  **Visibility Loss:** Binary cross entropy [S1]:
    $$ \mathcal{L}_\xi = \text{BCE}(\xi, \widehat{\xi}) $$
3.  **First-Order Normals Loss:** Matches surface normals derived from $\nabla_p \widehat{d}_{i^*}$ via Property II (gradient of depth yields normal) [S1]:
    $$ \mathcal{L}_n = -\xi | n^T n_{b i^*}(p, v) | $$
    where $n_{b i^*}$ is the normalized gradient of the predicted depth component $i^*$ with respect to position $p$.
4.  **Directed Eikonal Regularization:** Applied to visibility and each delta component [S1]:
    $$ \mathcal{L}_{\text{DE}} = \gamma_{\text{E},d} \sum_{i=1}^K \xi \left[ \nabla_i \widehat{d}_i \cdot v + 1 \right]^2 + \gamma_{\text{E},\xi} \left[ \nabla_\xi \widehat{\xi} \cdot v \right]^2 $$
    where $\nabla_i$ denotes the gradient with respect to $p$ for the $i$-th depth component.
5.  **Weight Field Regularization:** Encourages low entropy (preventing unnecessary switching) and transition at discontinuities [S1]:
    $$ \mathcal{L}_W = \gamma_V \mathcal{L}_V + \gamma_T \mathcal{L}_T $$
    (Specific forms of $\mathcal{L}_V$ and $\mathcal{L}_T$ are not fully detailed in the provided text, but $\mathcal{L}_V$ is described as weight variance/entropy related).

**View Consistency Inequality:**
A key constraint for DDFs is view consistency. If $\tau_1 = (p_1, v_1)$ is visible such that $q_1 = p_1 + d(\tau_1)v_1 \in S$, and $\tau_2 = (p_2, v_2)$ also sees $q_1$ (i.e., $\exists t > 0$ such that $p_2 + t v_2 = q_1$), then [S1]:
1.  $\xi(\tau_2) = 1$
2.  $d(\tau_2) \le \| p_2 - q_1 \|_2 = t$

This inequality ensures that if a surface point is known from one view, other views seeing that point must predict a depth less than or equal to the geometric distance to it [S1].

**Pseudocode:**

```python
import torch
import torch.nn as nn

class PDDFNetwork(nn.Module):
    def __init__(self, K=2):
        super().__init__()
        self.K = K
        # Network architecture to output K weights, K depths, 1 visibility
        # Input: (p, v) concatenated
        # Output: [w_1...w_K, d_1...d_K, xi]
        self.backbone = nn.Sequential(
            nn.Linear(6, 256), # 3 for p, 3 for v
            nn.ReLU(),
            nn.Linear(256, 256),
            nn.ReLU(),
            nn.Linear(256, 2 * K + 1) # K weights, K depths, 1 visibility
        )

    def forward(self, p, v):
        """
        p: (N, 3) positions
        v: (N, 3) directions
        Returns:
        xi: (N,) visibility
        w: (N, K) weights
        d: (N, K) depths
        """
        x = torch.cat([p, v], dim=-1)
        out = self.backbone(x)
        
        # Split outputs
        xi_raw = out[:, -1]
        xi = torch.sigmoid(xi_raw)
        
        w_raw = out[:, :-1]
        w = torch.softmax(w_raw, dim=-1)
        
        d = out[:, :-K-1].reshape(-1, self.K)
        
        return xi, w, d

def compute_loss(xi_pred, w_pred, d_pred, xi_gt, d_gt, n_gt, p, v, gamma_E_d=1.0, gamma_E_xi=1.0):
    """
    Computes the total training loss for PDDF.
    """
    N = xi_pred.shape[0]
    K = w_pred.shape[1]
    
    # 1. Find max likelihood index i*
    # w_pred shape: (N, K)
    i_star = torch.argmax(w_pred, dim=-1) # (N,)
    
    # Gather the depth corresponding to i*
    # d_pred shape: (N, K)
    d_star = d_pred[torch.arange(N), i_star] # (N,)
    
    # 2. Minimum Distance Loss
    # L_d = xi * |d_star - d_gt|
    # Only apply where ground truth is visible
    mask_visible = xi_gt > 0.5 # Assuming binary visibility for loss application
    L_d = torch.mean(mask_visible.float() * torch.abs(d_star - d_gt))
    
    # 3. Visibility Loss
    # BCE between predicted xi and ground truth xi
    L_xi = nn.functional.binary_cross_entropy(xi_pred, xi_gt)
    
    # 4. First-Order Normals Loss
    # Requires computing gradient of d_star w.r.t p
    # d_star is a scalar per sample, p is (N, 3)
    # We need to compute gradient of the selected depth component
    # Note: In practice, this requires careful handling of the argmax discontinuity
    # or using a soft selection during gradient flow. 
    # The source specifies using Property II: normal is gradient of depth.
    # We approximate this by computing gradients for all K components and selecting,
    # or using straight-through estimator if argmax is used.
    # For implementation completeness, we compute gradients for the selected component.
    
    # To compute grad(d_star, p), we need d_star to be differentiable w.r.t p.
    # Since i_star depends on w, and w depends on p, we might use straight-through.
    # However, the source implies matching normals derived from nabla_p d_{b i*}.
    # Let's compute gradients for all d_i and pick the one for i_star.
    
    d_all = d_pred # (N, K)
    # Compute gradients of each d_i w.r.t p
    # grad_d_i: (N, K, 3)
    grad_d_all = torch.autograd.grad(
        d_all.sum(), p, create_graph=True, retain_graph=True, only_inputs=True
    )[0] # (N, K, 3)
    
    # Select gradient for i_star
    # grad_d_star: (N, 3)
    idx = torch.arange(N).unsqueeze(1).expand(-1, K)
    grad_d_star = grad_d_all[idx, i_star.unsqueeze(1)].squeeze(1)
    
    # Normalize gradient to get predicted normal
    grad_norm = torch.norm(grad_d_star, dim=-1, keepdim=True) + 1e-8
    n_pred = grad_d_star / grad_norm
    
    # L_n = -xi * |n^T n_pred|
    # n_gt is (N, 3)
    dot_product = torch.sum(n_gt * n_pred, dim=-1) # (N,)
    L_n = torch.mean(mask_visible.float() * (-dot_product))
    
    # 5. Directed Eikonal Regularization
    # L_DE = gamma_E_d * sum_i xi * [grad(d_i) . v + 1]^2 + gamma_E_xi * [grad(xi) . v]^2
    
    # Gradient of xi w.r.t p
    grad_xi = torch.autograd.grad(
        xi_pred.sum(), p, create_graph=True, retain_graph=True, only_inputs=True
    )[0] # (N, 3)
    
    # Term for visibility
    eik_xi = torch.sum(grad_xi * v, dim=-1) + 1.0 # (N,)
    L_E_xi = torch.mean(mask_visible.float() * eik_xi**2)
    
    # Term for each depth component
    L_E_d = 0.0
    for i in range(K):
        grad_d_i = grad_d_all[:, i, :] # (N, 3)
        eik_d_i = torch.sum(grad_d_i * v, dim=-1) + 1.0 # (N,)
        L_E_d += torch.mean(mask_visible.float() * eik_d_i**2)
    
    L_DE = gamma_E_d * L_E_d + gamma_E_xi * L_E_xi
    
    # 6. Weight Field Regularization (Placeholder for specific L_V, L_T)
    # Source mentions L_W = gamma_V L_V + gamma_T L_T
    # L_V encourages low entropy (high confidence)
    entropy = -torch.sum(w_pred * torch.log(w_pred + 1e-8), dim=-1)
    L_V = torch.mean(entropy)
    
    # L_T encourages transition at discontinuities (not fully specified in text)
    # Assuming a placeholder for now
    L_T = torch.tensor(0.0) 
    
    L_W = L_V # Using only L_V as L_T is not defined in source
    
    total_loss = L_d + L_xi + L_n + L_DE + L_W
    
    return total_loss, {
        'L_d': L_d,
        'L_xi': L_xi,
        'L_n': L_n,
        'L_DE': L_DE,
        'L_W': L_W
    }
```

**Edge Cases and Pitfalls:**
*   **Discontinuity Handling:** The weight field $w(p, v)$ must smoothly transition between indices to allow the selected delta $d_{i^*}$ to jump. If weights do not transition smoothly, the network may fail to represent occlusions or surface boundaries correctly [S1].
*   **Gradient Flow:** The selection of $i^* = \arg\max_i w_i$ is non-differentiable. Implementation requires a straight-through estimator or a soft approximation during backpropagation to allow gradients to flow to the weights and depths [G].
*   **Precision:** The view consistency inequality relies on precise geometric intersection. Numerical errors in ray-surface intersection for ground truth extraction can lead to inconsistent labels [S1].

## Operating characteristics
*   **Time Complexity:** Rendering is $O(1)$ per pixel (single forward pass), independent of mesh complexity [S1]. Training cost depends on the number of samples and the gradient computations for $K$ depth components.
*   **Memory Complexity:** Stores $K$ depth values and $K$ weights per network output. $K=2$ is typical [S1].
*   **Strengths:** Handles discontinuities (occlusions, surface boundaries) naturally via probabilistic outputs; differentiable; fast rendering [S1].
*   **Limitations:** Requires careful tuning of weight field regularization to prevent unnecessary switching; non-differentiable argmax selection [S1].
*   **When to use:** When learning shape representations from meshes that require handling complex occlusions and view-dependent discontinuities, especially for differentiable rendering [S1].
*   **When not to use:** For simple, convex, or non-occluded shapes where a standard SDF suffices; if computational efficiency during training is critical and $K>1$ is too expensive.

## Background
Probabilistic Directed Distance Fields were introduced to address the limitations of standard DDFs in representing discontinuous fields with continuous neural networks. The method builds on the concept of Directed Distance Fields (DDFs) and their view consistency properties. The specific formulation using mixtures of Dirac deltas for discontinuity handling is detailed in the source paper [S1].
