# DeepSDF Neural Network
Also called: DeepSDF

## Overview
DeepSDF is a neural network architecture that maps 3D coordinates to signed distance field (SDF) values using a learned global latent code [S1, unofficial]. It solves the problem of implicit surface representation by replacing explicit geometric primitives with a continuous function approximator, allowing the reconstruction of complex shapes from a single latent vector [S1, unofficial].

## How it works
**Inputs and Outputs:**
- Input: A latent code vector $z$ and a 3D coordinate $p = (x, y, z)$ [G].
- Output: A scalar signed distance value $d$ [G].

**Data Structures:**
- **Latent Code ($z$):** A vector of dimension $latent\_dim$ [S1, unofficial].
- Default size is 16 [S1, unofficial].
- **Model Weights:** A two-layer Multi-Layer Perceptron (MLP) [G].
- Layer 1: Linear transformation from $latent\_dim + 3$ to 256 units, followed by ReLU activation [S1, unofficial].
- Layer 2: Linear transformation from 256 to 1 unit, outputting the SDF value [S1, unofficial].

**Algorithm Steps:**
1. **Initialization:** Initialize the MLP weights and the latent code $z$ [G].
2. **Latent Expansion:** For a batch of coordinates, expand the latent code $z$ to match the batch size, creating a tensor $Z$ where each row is $z$ [S1, unofficial].
3. **Concatenation:** Concatenate $Z$ and the batch of 3D coordinates $P$ along the feature dimension to form the input tensor $X = [Z, P]$ [S1, unofficial].
4. **Forward Pass:**
   - Compute $H_1 = \text{ReLU}(W_1 X + b_1)$, where $W_1 \in \mathbb{R}^{256 \times (latent\_dim + 3)}$ and $b_1 \in \mathbb{R}^{256}$ [S1, unofficial].
   - Compute $d = W_2 H_1 + b_2$, where $W_2 \in \mathbb{R}^{1 \times 256}$ and $b_2 \in \mathbb{R}^{1}$ [S1, unofficial].
5. **Training (Optional Context):** If training, sample points uniformly in $[-1.5, 1.5]^3$ and compute ground truth SDF (e.g., for a sphere: $\|p\| - r$) to minimize loss [S1, unofficial].

**Parameters:**
- $latent\_dim$: Dimensionality of the latent code. Default: 16 [S1, unofficial].
- $lr$: Learning rate for Adam optimizer. Default: 0.001 [S1, unofficial].
- $batch\_size$: Number of samples per batch. Default: 128 [S1, unofficial].
- $num\_epochs$: Number of training epochs. Default: 10 [S1, unofficial].

**Pseudocode:**
```python
def deepsdf_forward(latent_code, coords, weights):
    """
    Args:
        latent_code: list of floats, length L
        coords: list of floats, length 3
        weights: dict with 'W1' (256 x (L+3)), 'b1' (256), 'W2' (1 x 256), 'b2' (1)
    Returns:
        sdf_value: float
    """
    L = len(latent_code)
    # Concatenate latent code and coordinates
    x = latent_code + coords  # length L + 3

    # Layer 1: Linear + ReLU
    h1 = [0.0] * 256
    for i in range(256):
        dot = sum(weights['W1'][i][j] * x[j] for j in range(L + 3)) + weights['b1'][i]
        h1[i] = max(0.0, dot)  # ReLU

    # Layer 2: Linear (no activation specified for output)
    sdf_value = sum(weights['W2'][0][i] * h1[i] for i in range(256)) + weights['b2'][0]
    return sdf_value
```

**Edge Cases and Pitfalls:**
- **Boundary Conditions:** The training data generation samples in $[-1.5, 1.5]^3$, which may not cover the full extent of all shapes in a dataset if they are larger than this bounding box [S1, unofficial].
- **Degenerate Input:** If the latent code is not properly expanded to match the batch size of coordinates, the concatenation will fail or produce incorrect results [S1, unofficial].

## Subtopics

### [Vox2SDF](4047-vox2sdf.md)
Vox2SDF is a neural network pipeline that converts a discrete 3D voxel grid into a continuous Signed Distance Field (SDF) representation. It solves the problem of implicit surface reconstruction from discrete inputs by encoding the voxel structure into a latent vector and decoding it via a position-conditional MLP to predict SDF values at arbitrary 3D points. Unlike [DeepSDF Neural Network](3051-deepsdf-neural-network.md), which relies on a global latent code independent of input geometry, Vox2SDF derives its latent code directly from the input voxel grid using a 3D CNN encoder, allowing it to generalize across different shapes within a category while preserving input-specific geometric details.

## Operating characteristics
**Time and Memory Complexity:**
- **Inference Time:** Linear with respect to the number of query points $N$ and the latent dimension $L$ [G].
- Complexity: $O(N \cdot (L \cdot W_1 + W_1 \cdot W_2))$, where $W_1=256, W_2=1$ [G].
- **Memory:** Dominated by the latent code size ($L$) and the model weights ($256(L+3) + 256 + 1$) [G].
