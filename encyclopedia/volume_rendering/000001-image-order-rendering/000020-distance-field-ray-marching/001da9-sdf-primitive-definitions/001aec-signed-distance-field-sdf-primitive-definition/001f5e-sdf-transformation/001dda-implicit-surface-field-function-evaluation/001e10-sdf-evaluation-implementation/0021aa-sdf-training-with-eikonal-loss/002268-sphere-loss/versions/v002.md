# Sphere Loss

Also called: Analytical Sphere Distance Loss, SDF Sphere Pretraining Loss

## Overview
Sphere Loss is a regularization term used during the pretraining of Signed Distance Field (SDF) networks to initialize the implicit surface representation as a sphere [S1, S2, unofficial]. It minimizes the mean squared error between the network's predicted SDF values and the analytical Euclidean distance to a sphere surface of a specified radius [S1, S2, unofficial].

## How it works
Sphere Loss operates by comparing the output of the SDF network against the ground-truth analytical SDF for a sphere [S2, unofficial]. It is typically applied during a pretraining phase before the network is trained on target point cloud data or images [S1, S2, unofficial].

**Inputs and Outputs:**
- **Inputs:**
  - `points`: A tensor of 3D coordinates, shape $(N, 3)$, representing the query points [S1, S2, unofficial].
  - `signed_distance`: A tensor containing the network's predicted SDF values, indexed at `[..., 0]` [S1, unofficial].
  - `radius`: The radius $r$ of the target sphere [S1, S2, unofficial]. Default value is $1.0$ [S1, unofficial].
- **Output:**
  - A scalar loss value $\mathcal{L}_{\text{sphere}}$ [S1, S2, unofficial].

**Data Structures:**
- Points are stored as floating-point coordinates $(x, y, z)$ [S1, S2, unofficial].
- Predicted SDF values are stored as floating-point scalars [S1, S2, unofficial].

**Steps:**
1. Extract the predicted SDF values from the input tensor. If the input is multi-channel, select the first channel: $f(x_i) = \text{signed\_distance}[i, 0]$ [S1, unofficial].
2. Compute the L2 norm (Euclidean distance from the origin) for each point: $\|x_i\|_2 = \sqrt{x_i^2 + y_i^2 + z_i^2}$ [S1, S2, unofficial].
3. Compute the analytical SDF for a sphere centered at the origin with radius $r$: $d_i = \|x_i\|_2 - r$ [S1, S2, unofficial].
4. Calculate the difference between the predicted SDF and the analytical SDF: $\Delta_i = f(x_i) - d_i$ [S1, S2, unofficial].
5. Square the differences and compute the mean over all $N$ points [S1, S2, unofficial].

**Formula:**
The loss is defined as the Mean Squared Error (MSE) between the predicted SDF $\phi(x_i)$ (or $f(x_i)$) and the analytical sphere distance:

$$
\mathcal{L}_{\text{sphere}} = \frac{1}{N} \sum_{i=1}^{N} \left( \phi(x_i) - (\|x_i\|_2 - r) \right)^2
$$

Where:
- $N$ is the number of points [S1, S2, unofficial].
- $\phi(x_i)$ or $f(x_i)$ is the predicted signed distance at point $x_i$ [S1, S2, unofficial].
- $\|x_i\|_2$ is the L2 norm of the point coordinates $x_i$ [S1, S2, unofficial].
- $r$ is the sphere radius [S1, S2, unofficial].

**Pseudocode:**
```python
import torch

def sphere_loss(signed_distance: torch.Tensor, points: torch.Tensor, radius: float = 1.0) -> torch.Tensor:
    # Extract predicted SDF values (first channel)
    predicted_sdf = signed_distance[..., 0]
    # Compute analytical sphere SDF: ||p|| - r
    point_norms = torch.norm(points, dim=-1)
    analytical_sdf = point_norms - radius
    # Compute MSE
    loss = torch.square(predicted_sdf - analytical_sdf).mean()
    return loss
```

**Parameters:**
- `radius`: The radius of the sphere. Typical value is $1.0$ [S1, unofficial].
- `points`: Shape $(N, 3)$ [S1, S2, unofficial].
- `signed_distance`: Tensor of predicted SDF values, indexed at `[..., 0]` [S1, unofficial].

**Edge Cases and Pitfalls:**
- **Center Assumption:** The analytical formula $\|x_i\|_2 - r$ assumes the sphere is centered at the origin $(0,0,0)$ [S1, S2, unofficial]. If the target sphere is centered elsewhere, the points must be translated relative to the center before computing the norm [G].
- **Input Shape:** The implementation assumes the SDF is the first channel [S1, unofficial]. If the network outputs a scalar directly, indexing `[..., 0]` may fail or behave unexpectedly depending on the tensor rank [G].
- **Precision:** For very large or very small radii, floating-point precision issues may arise in the norm calculation [G].

## Background
Sphere Loss is used in repositories such as `Neural_Surfaces` and `Neural-Volume-Rendering-and-Surface-Rendering` to pretrain SDF networks [S1, S2, unofficial]. It is applied to regularize the predicted SDF to match the analytical SDF of a sphere with a specified radius [S1, unofficial].

## Subtopics

### Eikonal Loss
Enforces the unit gradient magnitude constraint ($\|\nabla \phi(x)\| = 1$) on the SDF [Parent]. Sphere Loss is often used in conjunction with Eikonal Loss, where Sphere Loss provides geometric initialization and Eikonal Loss ensures the distance field property [Parent].

### SDF Training with Eikonal Loss
The parent method that incorporates Sphere Loss as a pretraining step or auxiliary loss term to stabilize training [Parent].
