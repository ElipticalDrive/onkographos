# Torus Signed Distance Function

Also called: Link SDF, Link Shape SDF, Signed Torus, sdTorus

## Overview
Computes the exact Euclidean distance from a query point to the surface of a torus (a "link" shape) defined by a major radius and a minor radius. It solves the primitive distance query required for ray marching and constructive solid geometry (CSG) operations. It is distinguished from sibling primitives like the [Cylinder Signed Distance Function](2739-cylinder-signed-distance-function.md) by its closed-loop topology and from [Distance to Superquadrics](1561-distance-to-superquadrics.md) by its specific algebraic form for a torus.

## How it works
**Inputs:**
- $p = (p_x, p_y, p_z)$: Query point in 3D space.
- $R$: Major radius (distance from the center of the tube to the center of the torus).
- $r$: Minor radius (radius of the tube).

**Outputs:**
- $d$: Signed distance. Positive outside, negative inside, zero on surface.

**Data Structures:**
- None required; scalar computation.

**Steps:**
1. Compute the distance of the point's projection onto the torus's symmetry plane (XZ plane) from the origin. Let this be $\rho = \sqrt{p_x^2 + p_z^2}$.
2. Construct a 2D vector $q$ representing the distance from the point to the centerline of the torus tube.
   - The sources provide two variations for the alignment and parameterization:
     - **Variation A (Y-axis aligned, standard):** The torus lies in the XZ plane, symmetric around the Y-axis.
       $$q = (\rho - R, p_y)$$
       $$d = \sqrt{q_x^2 + q_y^2} - r$$
       This matches the implementation in [S2, unofficial].
     - **Variation B (Generalized/Link shape):** [S1, unofficial] defines a "link shape" with an additional length parameter $l$ and uses a different coordinate mapping involving `linear_mapping`. However, the core geometric distance for a standard torus is best represented by Variation A. Variation B appears to implement a more complex deformation or a specific "link" topology where the cross-section is modified. For a standard torus, Variation A is the canonical SDF.
3. Return $d$.

**Formula (Canonical):**
$$d = \sqrt{(\sqrt{p_x^2 + p_z^2} - R)^2 + p_y^2} - r$$

**Parameters:**
- $R > 0$: Major radius.
- $r > 0$: Minor radius.
- Constraint: $r < R$ for a standard ring torus. If $r = R$, it is a horn torus; if $r > R$, it is a spindle torus (self-intersecting).

**Edge Cases:**
- **Origin:** If $p=(0,0,0)$, $\rho=0$, $q=(-R, 0)$, $d = R - r$.
- **Self-intersection:** For spindle tori ($r > R$), the SDF remains valid but the "inside" region is complex.
- **Precision:** Near the surface, standard floating-point precision is sufficient.

**Pseudocode:**
```python
def sd_torus(p: tuple, R: float, r: float) -> float:
    """
    Computes signed distance to a torus centered at origin, aligned with Y-axis.
    p: (px, py, pz)
    R: Major radius
    r: Minor radius
    """
    px, py, pz = p
    
    # Distance from point to the centerline of the torus in the XZ plane
    # sqrt(px^2 + pz^2) is the radial distance in XZ plane
    rho = (px**2 + pz**2)**0.5
    
    # Vector from the centerline of the tube to the point
    # q_x is the distance from the major radius circle
    # q_y is the vertical distance from the XZ plane
    qx = rho - R
    qy = py
    
    # Euclidean distance from the tube centerline
    dist_to_centerline = (qx**2 + qy**2)**0.5
    
    # Signed distance: distance to centerline minus tube radius
    return dist_to_centerline - r
```

## Subtopics

### Link Shape SDF
A variation that includes a length parameter, potentially for non-circular cross-sections or deformed tori. Use when modeling chain links or specific mechanical parts. [Link SDF](1560-link-sdf.md).

### Spindle Torus
A torus where $r > R$. The SDF formula remains the same, but the topology changes. Use for specific organic or abstract shapes. [Spindle Torus](1562-spindle-torus.md).

## Operating characteristics
- **Time Complexity:** $O(1)$. Requires two square roots and basic arithmetic.
- **Memory Complexity:** $O(1)$. No auxiliary data structures.
- **Strengths:** Exact analytic solution; no iterative approximation; robust for ray marching.
- **Limitations:** Only applies to perfect tori. Cannot model tori with varying cross-sections or twists without deformation.
- **When to use:** When rendering or ray marching perfect toroidal shapes.
- **When not to use:** For complex toroidal structures with varying thickness or non-circular cross-sections.

## Background
The SDF for a torus is a standard primitive in signed distance function libraries, popularized by tools like the glsl-sdf-primitives repository [S2, unofficial] and used in various ray tracing implementations [S1, unofficial]. It is a fundamental building block for CSG operations involving toroidal shapes.
