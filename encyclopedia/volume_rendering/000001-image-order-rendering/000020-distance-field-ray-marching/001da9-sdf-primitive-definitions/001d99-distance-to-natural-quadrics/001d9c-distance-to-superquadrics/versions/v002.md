# Distance to Superquadrics

Also called: Superellipsoid distance, Superellipsoids, Superquadric Distance via p-norm, Supertori, pq-norm distance

## Overview
Distance to Superquadrics generalizes standard natural quadrics (spheres, cylinders, cones) and tori into superquadrics and supertori by replacing the Euclidean $L_2$ norm with the $L_p$ (or $L_{pq}$) norm [S1, S2]. This method allows for the creation of shapes with rounded, square, or pinched cross-sections by varying the exponent parameter $p$ [S1]. It is distinct from [Distance to Natural Quadrics](1559-distance-to-natural-quadrics.md) because it operates in a non-Euclidean metric space, requiring a specific conversion to Euclidean distances to ensure consistent ray marching behavior and blending with other primitives [S1, S2].

## How it works
**Inputs:**
*   Point $p = (x, y, z)$ in 3D space.
*   Shape exponent $p$ (scalar, $p > 0$) [S1].
*   Radius $r$ (scalar, defining the scale of the superellipsoid) [S1].
*   Optional: Exponents $p, q$ for asymmetric superquadrics (supertori or generalized ellipsoids) [S2].

**Outputs:**
*   Signed distance $d(p)$ in Euclidean space [S1].

**Data Structures:**
*   No persistent data structures required. The function is stateless and computes the distance analytically per query [G].

**Formulas:**
The core distance metric is the $L_p$ norm [S1]. In 2D, the $L_p$ norm of a vector $(x, y)$ is defined as [S1]:
$$ ||(x, y)||_p = (|x|^p + |y|^p)^{1/p} $$
In 3D, for a superellipsoid centered at the origin, the implicit surface is defined by [S1]:
$$ (|x|^p + |y|^p + |z|^p)^{1/p} = r $$
The raw distance in the $L_p$ metric, denoted $d_p(p)$, is calculated as [S1]:
$$ d_p(p) = (|x|^p + |y|^p + |z|^p)^{1/p} - r $$

**Euclidean Conversion:**
Because ray marching requires a unifying Euclidean metric space to compare distances between different primitives and to ensure the step size is safe (i.e., the ray does not pass through the surface), the $L_p$ distance must be converted to an equivalent Euclidean distance [S1, S2].

Let $r_e$ be the radius of the largest Euclidean sphere inscribed within the $L_p$-norm superellipsoid of radius $r$ (in the $L_p$ metric) [S1]. The conversion factor depends on $p$ [S1]:
$$ r_e = \begin{cases} r \cdot \frac{3^{1/p}}{\sqrt{3}} & \text{if } p < 2 \\ r & \text{if } p \ge 2 \end{cases} $$
The final Euclidean signed distance $d_{eucl}(p)$ is scaled by the ratio of the inscribed radius to the nominal radius [S1]:
$$ d_{eucl}(p) = d_p(p) \cdot \frac{r_e}{r} $$
Substituting $r_e/r$:
$$ d_{eucl}(p) = \begin{cases} \left( (|x|^p + |y|^p + |z|^p)^{1/p} - r \right) \cdot \frac{3^{1/p}}{\sqrt{3}} & \text{if } p < 2 \\ (|x|^p + |y|^p + |z|^p)^{1/p} - r & \text{if } p \ge 2 \end{cases} $$

**Parameters:**
*   $p$: Controls the shape [S1].
    *   $p = 2$: Euclidean sphere (round) [S1].
    *   $p = 1$: Octahedron (diamond in 2D) [S1].
    *   $p \to \infty$: Cube (square in 2D, chessboard metric) [S1].
    *   $0 < p < 1$: Pinched or star-shaped variations [S1].
*   $r$: Base radius [S1].

**Pseudocode:**
```python
import math

def distance_to_superquadric_sdf(x, y, z, p, r):
    """Computes the Euclidean signed distance to a superellipsoid."""
    if p <= 0:
        return float('inf')
    sum_p = abs(x)**p + abs(y)**p + abs(z)**p
    lp_norm = sum_p ** (1.0 / p)
    d_lp = lp_norm - r
    if p < 2.0:
        factor = (3.0 ** (1.0 / p)) / math.sqrt(3.0)
    else:
        factor = 1.0
    return d_lp * factor

def ray_march_superquadric(ox, oy, oz, dx, dy, dz, p, r, max_steps=1000, max_dist=100.0, tol=1e-4):
    """Standard sphere tracing loop using the superquadric SDF."""
    t = 0.0
    for _ in range(max_steps):
        if t > max_dist:
            return float('inf')
        px = ox + t * dx
        py = oy + t * dy
        pz = oz + t * dz
        d = distance_to_superquadric_sdf(px, py, pz, p, r)
        if d < tol:
            return t
        t += d
    return float('inf')
```

**Edge Cases and Pitfalls:**
*   **Metric Unification:** Using $L_p$ distances directly for blending or comparison with other primitives (like spheres or cylinders) is invalid because they exist in different metric spaces [S1, S2]. The Euclidean conversion is mandatory for correct visual results in composite scenes [S1, S2].
*   **Precision:** For very large $p$, $|x|^p$ can overflow or underflow. Standard floating-point handling applies [G].
*   **Degenerate Input:** $p=0$ is undefined. $p < 0$ produces non-convex, pinched shapes that may require specialized handling not covered by the standard convex superellipsoid definition [S1].

## Subtopics

### Supertori
A generalization of the torus using $L_p$ norms for both the major and minor circles [S1]. It follows the same conversion principles as superellipsoids but applies the norm to the distance evaluation of the torus's cross-section [S1].

### pq-norm Superquadrics
Uses different exponents $p$ and $q$ for different axes (e.g., $|x|^p + |y|^q + |z|^p$) [S2]. This allows for asymmetric shapes. The Euclidean conversion factor must be derived based on the specific $p, q$ values, typically involving the maximum inscribed sphere in the asymmetric metric [S2].

### Euclidean Inscribed Sphere Radius for Superellipsoid
Calculates the radius of the largest Euclidean sphere $r_e$ inscribed within a pq-norm superellipsoid of radius $r_s$ in the pq-norm metric [S2]. The formula is $r_e = r_s \frac{\sqrt{3}}{\sqrt[p]{3} + \sqrt[q]{3}}$ if $p$ or $q < 2$, otherwise $r_e = r_s \frac{\sqrt{3}}{3}$ [S2].

## Operating characteristics
*   **Time Complexity:** $O(1)$ per query [G]. Requires $O(1)$ arithmetic operations (powers, roots, absolute values) [G].
*   **Memory Complexity:** $O(1)$. No auxiliary data structures [G].
*   **Strengths:** Provides a continuous family of shapes from spheres to cubes to pinched forms with a single parameter [G]. Efficient for ray marching when the Euclidean conversion is applied [G].
*   **Limitations:** The gradient is not always smooth at $p=1$ or $p \to \infty$ boundaries in the raw metric, though the Euclidean conversion helps maintain continuity in the signed distance field [G]. The conversion factor is an approximation based on the inscribed sphere; it ensures safety (no tunneling) but may result in slightly larger step sizes than strictly necessary for non-spherical shapes, potentially slowing convergence slightly compared to exact analytical normals for simple primitives [G].
*   **When to use:** When a shape with adjustable "squareness" or "pinchedness" is needed, or when blending between different geometric primitives in a unified SDF framework [G].

## Background
Superquadrics were introduced by Alan Barr in 1981 [S1, S2]. The concept arises from generalizing the distance metrics used in basic primitive definitions [S1]. While natural quadrics rely on the Euclidean $L_2$ norm, superquadrics utilize the $L_p$ norm to create a broader class of implicit surfaces [S1]. This method is integral to the Sphere Tracing algorithm, as it allows the rendering of complex, organic, or mechanical shapes that are not representable by simple quadratic equations [S1]. The requirement for Euclidean conversion was highlighted to ensure that the geometric method of sphere tracing remains valid across different metric spaces [S1, S2].
