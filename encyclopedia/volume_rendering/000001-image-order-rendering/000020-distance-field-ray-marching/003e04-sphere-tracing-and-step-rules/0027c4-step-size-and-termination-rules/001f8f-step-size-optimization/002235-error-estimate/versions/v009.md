# Error Estimate
Also called: Relative Error Metric, Adaptive Stepping Error Metric

## Overview
Error Estimate calculates a relative error metric to drive adaptive stepping in volume rendering or ray marching [S1, unofficial]. It sets itself apart from static step size rules by dynamically scaling the step size based on the magnitude of the field value relative to a threshold, ensuring precision where the field changes rapidly or is small [S1, unofficial].

## How it works
**Inputs and Outputs:**
- Input: A scalar field value $y$ (typically a vector, e.g., RGB or 3D coordinate difference), a scaling factor $k$, and a threshold value.
- Output: A scalar relative error metric $E$.

**Data Structures:**
- $y$: A vector of values (e.g., `vec3` in GLSL/OpenGL Shading Language context) representing the current field evaluation or residual.
- $k$: A scalar constant used for normalization or scaling.
- threshold: A small positive scalar to prevent division by zero or excessive step sizes when $y$ is near zero.

**Steps:**
1. Compute the absolute value of each component of $y$: $|y_i|$.
2. Determine the maximum absolute component: $M = \max(|y_x|, |y_y|, |y_z|)$.
3. Calculate the denominator: $D = \max(M, \text{threshold})$.
4. Compute the relative error for each component: $r_{v,i} = \frac{|k|}{D}$.
5. The final error metric is the maximum component of $r_v$ plus a small constant `FLOAT_MIN` to ensure non-zero results:
   $$ E = \max(r_{v,x}, \max(r_{v,y}, r_{v,z})) + \text{FLOAT\_MIN} $$

**Pseudocode:**
```python
def error_estimate(y, k, threshold, float_min=1e-8):
    """
    Calculate relative error metric for adaptive stepping.
    
    Args:
        y (list/tuple of 3 floats): Scalar field values or residuals.
        k (float): Scaling factor.
        threshold (float): Minimum denominator to avoid division by zero.
        float_min (float): Small constant to ensure non-zero output.
        
    Returns:
        float: Relative error metric.
    """
    # Step 1 & 2: Compute max absolute component
    abs_y = [abs(val) for val in y]
    max_abs_y = max(abs_y)
    
    # Step 3: Calculate denominator with threshold
    denominator = max(max_abs_y, threshold)
    
    # Step 4: Compute relative error components
    # Note: k is typically constant, so |k| is constant
    abs_k = abs(k)
    r_v = [abs_k / denominator for _ in range(3)]
    
    # Step 5: Return max component + FLOAT_MIN
    max_r_v = max(r_v)
    return max_r_v + float_min
```

**Parameters:**
- $k$: Scaling factor. Not given in the sources.
- threshold: Small positive value. Not given in the sources.
- FLOAT_MIN: Smallest positive normalized floating-point number. Typically $1.17549435 \times 10^{-38}$ for IEEE 754 single-precision.

**Edge Cases:**
- If $y$ is zero, the threshold prevents division by zero.
- If $k$ is zero, the error estimate is `FLOAT_MIN`.

## Operating characteristics
- **Time Complexity:** $O(1)$ per evaluation.
- **Memory Complexity:** $O(1)$.
- **Strengths:** Simple, efficient, adapts to local field magnitude.
- **Limitations:** Depends on appropriate choice of $k$ and threshold. Not given in the sources for specific performance metrics.
