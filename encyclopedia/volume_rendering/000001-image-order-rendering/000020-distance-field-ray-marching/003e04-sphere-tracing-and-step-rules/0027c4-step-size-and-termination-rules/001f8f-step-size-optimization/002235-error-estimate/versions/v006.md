# Error Estimate

Also called: Relative Error Metric

## Overview
Error Estimate calculates a relative error metric to guide adaptive stepping in volume rendering or ray marching. It serves as a termination or refinement criterion by quantifying the deviation of the current sample relative to the local signal magnitude. It sets itself apart from siblings like [Safe Raymarching Step Size](1462-safe-raymarching-step-size.md) by focusing on the *relative* change in the field value rather than the absolute geometric distance, allowing for adaptive precision in regions of high signal variance.

## How it works
**Inputs and Outputs:**
- Input: A scalar value $k$ (typically the derivative or difference of the field function along the ray), a vector $y$ (typically the current field value or accumulated density), and a scalar `threshold` to prevent division by zero.
- Output: A scalar error metric $E$.

**Data Structures:**
- $k$: Scalar float.
- $y$: Vector (e.g., `vec3` or `vec4`), representing the current state or field value.
- `threshold`: Scalar float, a small positive constant.

**Steps:**
1. Compute the absolute value of the denominator components: $d_i = \max(|y_i|, \text{threshold})$ for each component $i$ of $y$.
2. Compute the relative error for each component: $r_{v,i} = \left| \frac{k}{d_i} \right|$.
3. Determine the maximum relative error across all components: $r_{max} = \max(r_{v,x}, r_{v,y}, r_{v,z})$.
4. Add a machine epsilon constant `FLOAT_MIN` to ensure the result is strictly positive and numerically stable.
5. Return $E = r_{max} + \text{FLOAT\_MIN}$.

**Formulas:**
$$ r_v = \left| \frac{k}{\max(|y|, \text{threshold})} \right| $$
$$ E = \max(r_v) + \text{FLOAT\_MIN} $$

Where:
- $k$ is the numerator scalar.
- $y$ is the denominator vector.
- $\max(|y|, \text{threshold})$ is applied component-wise.
- $\max(r_v)$ is the component-wise maximum of the resulting vector $r_v$.
- `FLOAT_MIN` is the smallest positive normalized floating-point number (e.g., $1.17549435 \times 10^{-38}$ for IEEE 754 single precision).

**Parameters:**
- `threshold`: A small positive value to avoid division by zero. Typical value: Not given in the sources.
- `FLOAT_MIN`: Machine epsilon. Typical value: Not given in the sources.

**Edge Cases and Pitfalls:**
- **Division by Zero:** If $y$ is zero and no threshold is used, the result is undefined. The threshold prevents this.
- **Numerical Stability:** Adding `FLOAT_MIN` ensures the error is never exactly zero, which can be important for convergence checks in iterative solvers.

**Pseudocode:**
```python
def error_estimate(k: float, y: Vector3, threshold: float) -> float:
    """
    Calculate relative error metric for adaptive stepping.
    
    Args:
        k: Scalar numerator (e.g., derivative or difference).
        y: Vector denominator (e.g., current field value).
        threshold: Minimum value for denominator to prevent division by zero.
        
    Returns:
        Relative error metric.
    """
    # Compute denominator components: max(|y_i|, threshold)
    denom_x = max(abs(y.x), threshold)
    denom_y = max(abs(y.y), threshold)
    denom_z = max(abs(y.z), threshold)
    
    # Compute relative error components
    r_v_x = abs(k / denom_x)
    r_v_y = abs(k / denom_y)
    r_v_z = abs(k / denom_z)
    
    # Find maximum relative error
    r_max = max(r_v_x, r_v_y, r_v_z)
    
    # Add machine epsilon for stability
    FLOAT_MIN = 1.17549435e-38  # IEEE 754 single precision min positive normalized
    return r_max + FLOAT_MIN
```

## Subtopics

### [Data-Dependent Error Metric for Scalar Fields](6981-data-dependent-error-metric-for-scalar-fields.md)
This method refines the mesh only in regions with values close to a chosen isovalue $v_{iso}$, reducing computation time by ignoring regions far from the isovalue. It sets itself apart from its sibling, the Mean-Square Error Metric, which evaluates error globally within an element regardless of isovalue proximity, potentially leading to unnecessary refinement in regions far from the target isosurface.

## Operating characteristics
**Time and Memory Complexity:**
- Time: $O(1)$ per evaluation.
- Memory: $O(1)$.

**Measured Performance:**
- Not given in the sources.

**Scaling:**
- Not given in the sources.

**Strengths and Limitations:**
- **Strengths:** Provides a scale-invariant error metric, making it suitable for adaptive stepping in fields with varying magnitudes.
- **Limitations:** Requires careful selection of the threshold to avoid numerical instability or misleading error estimates in low-signal regions.

**When to Use:**
- Use when adaptive stepping based on relative signal change is preferred over absolute geometric distance.

**When Not to Use:**
- Do not use when absolute error bounds are required or when the signal magnitude is consistently near zero.
