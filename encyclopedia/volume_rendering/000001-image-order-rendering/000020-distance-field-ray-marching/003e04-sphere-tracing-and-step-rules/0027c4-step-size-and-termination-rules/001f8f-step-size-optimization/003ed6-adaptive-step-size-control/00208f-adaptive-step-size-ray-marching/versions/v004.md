# Adaptive Step Size Ray Marching

Also called: DDVR, DDVR Raymarching Shader, Ray Marching with Adaptive Step Size and Temporal Accumulation, Adaptive Step Size Volume Rendering

## Overview
Adaptive Step Size Ray Marching is a GPU-based direct volume rendering technique that reduces computational cost by varying the ray marching step size based on local density and distance, combined with temporal accumulation and denoising [S1][S2, S3, unofficial]. It solves the trade-off between rendering quality and performance inherent in linear sampling by using fine steps inside dense regions and coarse steps outside, while leveraging previous frame data to stabilize noise [S1][S2, unofficial]. Unlike [Dynamic Sampling Step Adjustment](2442-dynamic-sampling-step-adjustment.md), which may adjust steps based on gradient magnitude or other local derivatives, this method explicitly uses a noise-driven step size selection and temporal reprojection for real-time performance [S2, unofficial].

## How it works
The method implements a ray marching loop where the step size is dynamically selected from a noise buffer, allowing for non-uniform sampling along the ray. It supports both 3D static volumes and 4D time-varying volumes, with optional temporal accumulation to reduce noise over frames [S2, unofficial].

### Inputs and Outputs
**Inputs:**
- Camera state: View matrix, projection matrix, position, and movement flag (`cam.moved`) [S2, unofficial].
- Volume data: 3D texture (`volumeTexture`) for density, optional 4D texture (`volumeTexture4DNextFrame`) for time interpolation [S2, unofficial].
- Transfer function: 1D color mapping texture (`colorMapping`) [S2, unofficial].
- Geometry: Bounding box defined by `bbmin` and `bbmax` [S2, unofficial].
- Noise buffer: `noiseImage` storing per-pixel step size and offset [S2, unofficial].
- Depth buffer: `positionDepthBufferImage` storing world position of the first hit [S2, unofficial].
- Configuration: `stepSize`, `scalarMinMax`, `illuminationScale`, `rotationAngles`, `interpolationFactor`, flags for `accumulation`, `motionVectorCalc`, `bVolume4D`, `pingpong4D` [S2, unofficial].

**Outputs:**
- `outputImage`: Final rendered RGBA color [S2, unofficial].
- `motionVectorImage`: Motion vectors for reprojection (if enabled) [S2, unofficial].
- Updated `noiseImage`: Step size and offset for the next frame [S2, unofficial].
- Updated `positionDepthBufferImage`: First hit position and depth [S2, unofficial].

### Data Structures
The implementation relies on specific buffer layouts defined in the shader and host code [S2, unofficial]:

1.  **Uniform Block (set=0, binding=0):**
    -   `dimensions`: `vec3` (volume dimensions)
    -   `bbmin`, `bbmax`: `vec3` (bounding box corners)
    -   `rotationAngles`: `vec2` (rotation for bounding box)
    -   `scalarMinMax`: `vec2` (min/max density for normalization)
    -   `stepSize`: `float` (base step size)
    -   `illuminationScale`: `float`
    -   `ellapsedTime`: `float`
    -   `accumulation`: `int` (0 or 1)
    -   `motionVectorCalc`: `int` (0 or 1)
    -   `bVolume4D`: `int` (0 or 1)
    -   `interpolationFactor`: `float`
    -   `pingpong4D`: `int` (0 or 1)

2.  **Camera Block (set=0, binding=1):**
    -   `cam`: Struct containing `transform` (mat4), `proj` (mat4), `camView` (mat4), `moved` (bool) [S2, unofficial].

3.  **Textures/Images:**
    -   `noiseImage` (set=0, binding=2): `image2D`, format `rg32f`.
        -   `.r`: Current step size (0 if using default).
        -   `.g`: Ray offset for jittering.
        -   `.b`, `.a`: Unused (0.0) [S2, unofficial].
    -   `colorMapping` (set=0, binding=3): `sampler1D` [S2, unofficial].
    -   `volumeTexture` (set=1, binding=1): `sampler3D` [S2, unofficial].
    -   `volumeTexture4DNextFrame` (set=1, binding=2): `sampler3D` (for 4D volumes) [S2, unofficial].
    -   `outputImage` (set=1, binding=0): `image2D`, format `rgba8` [S2, unofficial].
    -   `positionDepthBufferImage` (set=1, binding=3): `image2D`, format `rgba32f`.
        -   `.xyz`: World position of first hit.
        -   `.w`: Depth `t` along the ray [S2, unofficial].
    -   `motionVectorImage` (set=1, binding=5): `image2D`, format `rgba8`.
        -   `.xy`: Motion vector in UV space.
        -   `.z`: Unused (0.0).
        -   `.w`: Unused (1.0) [S2, unofficial].
    -   `previousCam` (set=1, binding=4): Buffer storing camera state from previous frame [S2, unofficial].

### Numbered Steps

1.  **Ray Generation and Intersection:**
    -   Initialize ray origin from camera position (`cam.transform[3].xyz`) and direction from UV coordinates, projection, and view matrices [S2, unofficial].
    -   Perform ray-box intersection against `bbmin` and `bbmax` to find entry (`tEntry`) and exit (`tExit`) distances [S2, unofficial].
    -   If no intersection, store black color `(0,0,0,1)` in `outputImage`, zero `positionDepthBufferImage`, and return [S2, unofficial].

2.  **Initialization:**
    -   Initialize `transmittance = 1.0`, `accumulatedColor = vec3(0.0)`, `firstHit = false` [S2, unofficial].
    -   Load `rayOffset` from `noiseImage.g` [S2, unofficial].
    -   Determine `m_stepSize`: If `noiseImage.r` is 0, use `stepSize`; otherwise, use `noiseImage.r` [S2, unofficial].
    -   Calculate `stepDir = rayDir * m_stepSize` [S2, unofficial].
    -   Set initial position `pos = rayOrigin + tEntry * rayDir` [S2, unofficial].

3.  **Ray Marching Loop:**
    -   Iterate `t` from `tEntry + rayOffset` to `tExit` with step `m_stepSize` [S2, unofficial].
    -   **Coordinate Calculation:**
        -   Calculate UVW coordinates relative to the bounding box [S2, unofficial].
        -   Apply rotation using `rotationAngles` (rotationY for x-angle, rotationX for y-angle) [S2, unofficial].
    -   **Density Sampling:**
        -   If `bVolume4D == 1`:
            -   Sample `density1` from `volumeTexture` and `density2` from `volumeTexture4DNextFrame` based on `pingpong4D` flag [S2, unofficial].
            -   Mix densities using `interpolationFactor` [S2, unofficial].
        -   If `bVolume4D == 0`:
            -   Sample `density` directly from `volumeTexture` [S2, unofficial].
    -   **Density Threshold Check:**
        -   If `density > 0.01`, proceed with compositing [S2, unofficial].
    -   **Color Mapping:**
        -   Calculate `colorMappingCoord = clamp((density - scalarMinMax.x) / (scalarMinMax.y - scalarMinMax.x), 0.0, 1.0)` [S2, unofficial].
        -   Sample `s = colorMapping(colorMappingCoord)` to get color and extinction (alpha) [S2, unofficial].
    -   **Compositing (Alpha Blending):**
        -   Extract `extinction = s.a` [S2, unofficial].
        -   Calculate `alpha = 1.0 - exp(-extinction * m_stepSize)` [S2, unofficial].
        -   Calculate `contribution = transmittance * s.rgb * alpha` [S2, unofficial].
        -   Update `accumulatedColor += contribution` [S2, unofficial].
        -   Update `transmittance *= (1.0 - alpha)` [S2, unofficial].
    -   **First Hit Storage:**
        -   If `!firstHit` and `alpha > 0.0`, set `firstHit = true` and store `pos` and `t` in `positionDepthBufferImage` [S2, unofficial].
    -   **Early Ray Termination:**
        -   If `1.0 - transmittance > 0.95`, break the loop [S2, unofficial].
    -   **Advance Position:**
        -   `pos += stepDir` [S2, unofficial].

4.  **Post-Processing and Accumulation:**
    -   **Gamma Correction:** Apply gamma 2.2 to `accumulatedColor.rgb`: `pow(accumulatedColor.rgb, vec3(1.0 / 2.2))` [S2, unofficial].
    -   **Final Color Calculation:**
        -   `finalAlpha = 1.0 - transmittance` [S2, unofficial].
        -   `finalColor = vec4(accumulatedColor, finalAlpha) * illuminationScale` [S2, unofficial].
    -   **Temporal Accumulation (if `accumulation == 1` and `!cam.moved`):**
        -   Load `lastFrameColor` from `outputImage` [S2, unofficial].
        -   Blend: `finalColor.rgb = lastFrameColor.rgb * (1.0 - finalAlpha) + finalColor.rgb * finalAlpha` [S2, unofficial].
        -   Blend Alpha: `finalColor.a = lastFrameColor.a * (1.0 - finalAlpha) + finalColor.a * finalAlpha` [S2, unofficial].
    -   **Camera Movement Handling:**
        -   If `cam.moved` is true, reset `positionDepthBufferImage` to zero and `noiseImage.g` to 0 to prevent artifacts [S2, unofficial].
    -   **Motion Vector Calculation (if `motionVectorCalc == 1`):**
        -   Load position from `positionDepthBufferImage`. If `position.xyz` is zero, store zero motion vector and return [S2, unofficial].
        -   Get depth `t = position.w` [S2, unofficial].
        -   Calculate previous ray origin and direction from `previousCam` [S2, unofficial].
        -   Reproject position to previous frame coordinates using a reprojection function [S2, unofficial].
        -   Calculate motion vector difference in UV space, map to `[0, 1]`, and store in `motionVectorImage` [S2, unofficial].
    -   **Store Output:**
        -   Store `finalColor` in `outputImage` [S2, unofficial].

5.  **Noise Update:**
    -   Update `noiseImage` for the next frame [S2, unofficial].
    -   If `accumulation == 1`, call `updateNoiseOffset(pixelCoord, m_stepSize)` [S2, unofficial].
    -   Update `stepOffset` (stored in `noiseImage.g`): `stepOffset += (1 / m_stepSize * 10) * 0.00001` [S2, unofficial].
    -   If `accumulation == 0`, store `noiseImage.r` and reset `g` component to 0 [S2, unofficial].

### Pseudocode

```python
# Constants
EARLY_STOP_THRESHOLD = 0.95
GAMMA = 2.2

# Inputs
ray_origin = cam.transform[3].xyz
ray_dir = normalize(calculate_direction_from_uv(uv, cam.proj, cam.camView))
t_entry, t_exit = ray_box_intersect(ray_origin, ray_dir, bbmin, bbmax)

if t_entry is None:
    output_image[uv] = vec4(0.0, 0.0, 0.0, 1.0)
    position_depth_buffer[uv] = vec4(0.0, 0.0, 0.0, 0.0)
    return

# Initialization
transmittance = 1.0
accumulated_color = vec3(0.0)
first_hit = False
ray_offset = noise_image[uv].g

# Determine step size
if noise_image[uv].r == 0.0:
    m_step_size = step_size
else:
    m_step_size = noise_image[uv].r

step_dir = ray_dir * m_step_size
pos = ray_origin + t_entry * ray_dir

# Ray Marching Loop
t = t_entry + ray_offset
while t < t_exit:
    # Calculate UVW coordinates relative to bounding box
    uvw = calculate_uvw(pos, bbmin, bbmax, rotationAngles)
    
    # Sample density
    if bVolume4D:
        density1 = sample_3d_texture(volumeTexture, uvw)
        density2 = sample_3d_texture(volumeTexture4DNextFrame, uvw)
        density = mix(density1, density2, interpolationFactor)
    else:
        density = sample_3d_texture(volumeTexture, uvw)
    
    # Density threshold check
    if density > 0.01:
        # Color mapping
        norm_density = clamp((density - scalarMinMax.x) / (scalarMinMax.y - scalarMinMax.x), 0.0, 1.0)
        s = sample_1d_texture(colorMapping, norm_density)
        extinction = s.a
        
        # Compositing
        alpha = 1.0 - exp(-extinction * m_step_size)
        contribution = transmittance * s.rgb * alpha
        accumulated_color += contribution
        transmittance *= (1.0 - alpha)
        
        # First hit storage
        if not first_hit and alpha > 0.0:
            first_hit = True
            position_depth_buffer[uv] = vec4(pos, t)
        
        # Early ray termination
        if 1.0 - transmittance > EARLY_STOP_THRESHOLD:
            break
    
    pos += step_dir
    t += m_step_size

# Post-Processing
accumulated_color = pow(accumulated_color, vec3(1.0 / GAMMA))
final_alpha = 1.0 - transmittance
final_color = vec4(accumulated_color, final_alpha) * illuminationScale

# Temporal Accumulation
if accumulation and not cam.moved:
    last_frame_color = output_image[uv]
    final_color.rgb = last_frame_color.rgb * (1.0 - final_alpha) + final_color.rgb * final_alpha
    final_color.a = last_frame_color.a * (1.0 - final_alpha) + final_color.a * final_alpha

# Motion Vector Calculation
if motionVectorCalc:
    hit_pos = position_depth_buffer[uv].xyz
    if all(hit_pos == 0.0):
        motion_vector_image[uv] = vec4(0.0, 0.0, 0.0, 1.0)
    else:
        depth = position_depth_buffer[uv].w
        prev_ray_origin = previous_cam.transform[3].xyz
        prev_ray_dir = normalize(calculate_direction_from_uv(uv, previous_cam.proj, previous_cam.camView))
        prev_pos = reproject_position(hit_pos, depth, cam, previous_cam)
        motion_vec = calculate_motion_vector(uv, prev_pos)
        motion_vector_image[uv] = vec4(motion_vec, 0.0, 1.0)

# Store Output
output_image[uv] = final_color

# Update Noise
if accumulation:
    noise_image[uv].g += (1.0 / m_step_size * 10.0) * 0.00001
else:
    noise_image[uv].g = 0.0
```

### Parameters
-   `stepSize`: Base step size for ray marching [S2, unofficial].
-   `scalarMinMax`: Min/max density values for normalization [S2, unofficial].
-   `illuminationScale`: Multiplier for final color [S2, unofficial].
-   `rotationAngles`: Rotation angles for the volume bounding box [S2, unofficial].
-   `interpolationFactor`: Factor for mixing 4D volume frames [S2, unofficial].
-   `accumulation`: Boolean flag for temporal accumulation [S2, unofficial].
-   `motionVectorCalc`: Boolean flag for motion vector calculation [S2, unofficial].
-   `bVolume4D`: Boolean flag for 4D volume support [S2, unofficial].

### Edge Cases and Pitfalls
-   **Camera Movement:** If the camera moves, the depth buffer and noise offset must be reset to zero to prevent incorrect reprojection and accumulation artifacts [S2, unofficial].
-   **No Intersection:** If the ray does not intersect the volume, output black and zero the depth buffer [S2, unofficial].
-   **Zero Position:** If the first hit position is zero (no hit), motion vectors should be zero to avoid division by zero [S2, unofficial].
-   **Precision:** The method uses a Taylor approximation for transmittance update in some implementations, which may introduce slight inaccuracies compared to the exponential function [S3, unofficial].
-   **Color Banding:** Random offsets based on fragment coordinates can minimize color banding [S3, unofficial].

## Operating characteristics
-   **Time Complexity:** The number of sampling steps is reduced compared to linear sampling, especially in empty space, due to adaptive step sizes [S1]. However, the exact complexity depends on the density distribution and the noise-driven step size selection [S2, unofficial].
-   **Memory Complexity:** Requires storage for `noiseImage`, `positionDepthBufferImage`, `motionVectorImage`, and potentially `previousCam` state, in addition to the volume textures [S2, unofficial].
-   **Performance:** The method is designed for real-time performance on GPUs, leveraging parallelization and temporal accumulation to reduce noise without requiring high sample counts per frame [S1][S2, unofficial].
-   **Quality:** Achieves a Structural Similarity Index (SSIM) of 0.95 compared to source images in experiments [S1].
-   **Strengths:** Reduces computational cost, supports 4D volumes, provides stable results via temporal accumulation [S1][S2, unofficial].
-   **Limitations:** Requires additional buffers for noise and motion vectors; temporal accumulation can cause ghosting if camera movement is not handled correctly [S2, unofficial].

## Background
The method was proposed to address the excessive computational cost of GPU-based 3-D volume rendering, particularly in parallelized ray-casting algorithms [S1]. It draws inspiration from photography, where distant objects are less detailed, applying a non-linear sampling function to vary step sizes based on distance and density [S1]. The implementation described in [S2, unofficial] is part of the DDVR project, which integrates this technique with temporal accumulation and denoising for real-time direct volume rendering [S2, unofficial]. The approach has been tested on Windows and macOS [S2, unofficial].
