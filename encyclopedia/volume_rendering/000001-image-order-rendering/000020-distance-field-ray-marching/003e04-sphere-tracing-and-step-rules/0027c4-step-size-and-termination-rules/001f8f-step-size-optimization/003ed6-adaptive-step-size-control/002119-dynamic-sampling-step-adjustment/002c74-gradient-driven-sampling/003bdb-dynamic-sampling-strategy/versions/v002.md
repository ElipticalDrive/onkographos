# Dynamic Sampling Strategy
Also called: Shading-error-driven Dynamic Sampling
## Overview
A procedure to dynamically determine the number and locations of sample points in a participating medium to accurately reproduce shading variations and minimize rendering errors [S1]. It adapts sample locations based on shading error, unlike prior methods that sample based on density distribution [S1]. It builds on [Gradient-driven Sampling](5281-gradient-driven-sampling.md) by using a specific gradient-based error metric to drive a recursive splitting process [S1].
## How it works
**Inputs:**
- Volume geometry and optical properties (scattering/absorption coefficients) [S1, G].
- Light source positions and intensities [S1, G].
- Camera parameters [G].
- Initial coarse set of sample points (or empty set for first iteration) [S1].

**Outputs:**
- Final set of sample points $\{x_j\}$ with associated source radiance $L_{x_j}$ and gradient $\nabla L_{x_j}$ [S1].
- Rendered image via ray marching using interpolated radiance [S1].

**Data Structures:**
- Sample Point: A 3D position $x_j$, source radiance scalar $L_{x_j}$, and source radiance gradient vector $\nabla L_{x_j}$ [S1].
- Error Metric: A scalar value per sample or region indicating shading error magnitude [G].

**Steps:**
1. **Initial Sampling:** Generate a small initial set of sample points $\{x_j\}$ distributed in the medium [S1].
2. **Radiance Evaluation:** At each sample point $x_j$, numerically evaluate the source radiance $L_{x_j}$ and its gradient $\nabla L_{x_j}$ using a volume ray tracer [S1].
3. **Interpolation:** Reconstruct source radiance $L_x$ at arbitrary points $x$ in the volume using gradient-based interpolation from the sample points [S1]. This interpolation is efficiently applied via sample splatting [S1].
4. **Error Estimation:** Compute the shading error for regions in the medium [S1]. Areas where the reconstructed source radiance results in significant shading errors are identified [S1].
5. **Dynamic Adjustment (Recursive Splitting):** Identify sample points or regions with high shading error [S1]. Recursively split these high-error samples by placing additional sample points in those areas [S1]. The splitting process replaces high-error samples with finer grid vertices or new sample points [S1].
6. **Rendering:** Perform volume ray marching to composite the final radiance along view rays using the interpolated source radiance from the final set of sample points [S1].

**Pseudocode:**
```python
def dynamic_sampling_strategy(volume, lights, camera, max_iterations=5):
    # Initial coarse sampling distributed in the medium [S1]
    samples = generate_initial_samples(volume)
    
    for iteration in range(max_iterations):
        # Evaluate source radiance and its gradient at each sample point [S1]
        for sample in samples:
            sample.L = evaluate_source_radiance(sample.pos, volume, lights)
            sample.grad_L = evaluate_gradient(sample.pos, volume, lights)
            
        # Reconstruct radiance across the volume using gradient-based interpolation via splatting [S1]
        # Interpolation error is computed by comparing reconstructed values against direct evaluations or analytical bounds [G]
        error_map = compute_interpolation_error(samples, volume, lights)
        
        # Identify regions with significant shading error [S1]
        high_error_regions = find_high_error_regions(error_map, threshold=0.0)
        
        if not high_error_regions:
            break
            
        # Recursively split high-error regions by placing additional sample points [S1]
        new_samples = []
        for region in high_error_regions:
            # Split region by generating new sample points within its bounds
            # Exact splitting geometry is implementation-specific but aims to reduce error [S1]
            new_samples.extend(split_region(region, samples))
            
        samples.extend(new_samples)
        
    return samples

def generate_initial_samples(volume):
    # Distribute initial points uniformly or via coarse heuristic in the volume bounds [G]
    return [Sample(pos=v) for v in volume.uniform_grid(n=4)]

def evaluate_source_radiance(pos, volume, lights):
    # Numerical evaluation via volume ray tracing from light to point [S1]
    return volume.trace_ray(pos, lights)

def evaluate_gradient(pos, volume, lights):
    # Numerical evaluation of the gradient of source radiance [S1]
    # Computed via finite differences or analytical derivatives if available [G]
    eps = 1e-3
    return (volume.trace_ray(pos + eps, lights) - volume.trace_ray(pos - eps, lights)) / (2 * eps)

def compute_interpolation_error(samples, volume, lights):
    # Estimate shading error by comparing interpolated radiance against direct samples [G]
    # Uses gradient-based scheme efficiently applied by sample splatting [S1]
    return volume.compute_splatting_error(samples)

def find_high_error_regions(error_map, threshold):
    # Return regions where error exceeds threshold [G]
    return [r for r in error_map.regions if r.error > threshold]

def split_region(region, existing_samples):
    # Generate new sample points within the high-error region to refine sampling [S1]
    # Replaces high-error samples with finer grid vertices or new points [S1]
    return [Sample(pos=region.center + offset) for offset in region.subdivide()]
```

**Parameters:**
- `max_iterations`: Maximum number of refinement iterations. Not given in the sources.
- `error_threshold`: Threshold for determining "significant shading errors". Not given in the sources.

**Edge Cases and Pitfalls:**
- **Precision:** Numerical evaluation of radiance and gradient must be accurate to avoid propagating errors into the interpolation [S1].
- **Boundaries:** Handling of volume boundaries during sample generation and splitting is not explicitly detailed [S1].
- **Degenerate Input:** If the medium is homogeneous, shading error may be low everywhere, leading to minimal sampling [S1].

## Subtopics

### [Dynamic Sampling with Recursive Sample Splitting](9091-dynamic-sampling-with-recursive-sample-splitting.md)
Uses a specific gradient-based error metric to drive a recursive splitting process that replaces high-error samples with finer grid vertices. Choose when accurate modeling of sharp shading variations (e.g., light shafts) is required.

## Operating characteristics
- **Time Complexity:** Depends on the number of sample points and iterations [S1]. Real-time performance is claimed for dynamic scenes [S1].
- **Memory Complexity:** Proportional to the number of sample points stored [G].
- **Performance:** Comparable to ray tracing in accuracy but faster due to adaptive sampling and interpolation [S1].
- **Strengths:** Captures all-frequency shading effects (glows, shadows, light shafts) in real-time without precomputation [S1].
- **Limitations:** Requires numerical evaluation of radiance and gradient at each sample point, which can be costly if not optimized [S1].
- **When to Use:** Real-time rendering of inhomogeneous, single-scattering media with sharp shading variations [S1].

## Background
Originated in the paper "Gradient-based Interpolation and Sampling for Real-time Rendering of Inhomogeneous, Single-scattering Media" (2008) [S1]. It was developed to address artifacts in previous methods that sampled based on density distribution, aiming for real-time rendering of dynamic lighting and scenes [S1].
