# Dynamic Sampling Step Adjustment

Also called: Adaptive Step Doubling, Empty Space Step Doubling

## Overview
Dynamic Sampling Step Adjustment is a technique for optimizing ray marching in distance-field rendering by dynamically increasing the step size when traversing empty space and restoring it upon entering occupied regions [S1, unofficial]. It solves the problem of wasted computation on uniform, empty volumes by skipping large distances, thereby reducing the number of texture lookups and shading operations [S1, unofficial]. It sets itself apart from uniform sampling by adapting to local emptiness rather than feature density, and from gradient-driven methods by relying on binary occupancy (empty vs. non-empty) rather than field magnitude [S1, unofficial].

## How it works
**Inputs and Outputs:**
*   Input: Current ray position $p$, current step size $s$, current mip-map offset $m$, and a scalar field query function $F(p)$ that returns density.
*   Output: Updated ray position $p'$, updated step size $s'$, and updated mip-map offset $m'$.

**Data Structures:**
*   `step_size`: A floating-point value representing the current distance to advance along the ray.
*   `mip_offset`: An integer index or bias used to select the appropriate mip-map level for texture sampling, corresponding to the current `step_size`.
*   `original_step_size`: The base step size initialized at the start of the ray march.
*   `original_mip_offset`: The base mip-map offset initialized at the start of the ray march.

**Algorithm Steps:**
1.  Initialize `step_size` to `original_step_size` and `mip_offset` to `original_mip_offset` [S1, unofficial].
2.  Sample the scalar field at the current ray position $p$ using the current `mip_offset` [S1, unofficial].
3.  Check if the sampled density is empty (e.g., density $\le 0$ or below a threshold) [S1, unofficial].
4.  If the density is empty:
    *   Double the `step_size`: $s_{new} = 2 \times s_{old}$ [S1, unofficial].
    *   Increment the `mip_offset` to match the coarser resolution required by the larger step size [S1, unofficial].
    *   Advance the ray position: $p_{new} = p_{old} + s_{new}$ [S1, unofficial].
    *   Repeat from step 2 with the new position and parameters.
5.  If the density is non-empty:
    *   Step back one step: $p_{new} = p_{old} - s_{old}$ [S1, unofficial].
    *   Restore `step_size` to `original_step_size` [S1, unofficial].
    *   Restore `mip_offset` to `original_mip_offset` [S1, unofficial].
    *   Proceed with standard ray marching using the restored parameters [S1, unofficial].

**Parameters:**
*   Doubling factor: 2 [S1, unofficial].
*   Empty threshold: Not given in the sources. Typically density $\le 0$ or a small epsilon [G].

**Edge Cases and Pitfalls:**
*   **Artifacts:** This optimization may cause visual artifacts in some cases, particularly if the transition between empty and occupied space is not handled smoothly or if the doubling skips over thin features [S1, unofficial].
*   **Performance Gains:** The performance improvement is described as small [S1, unofficial].
*   **Precision:** Restoring the exact previous position requires careful handling of floating-point arithmetic to avoid jitter or gaps [G].

**Pseudocode:**
```python
def dynamic_sampling_step_adjustment(ray_origin, ray_direction, field_texture, original_step_size, original_mip_offset):
    # Initialize state
    current_pos = ray_origin
    current_step = original_step_size
    current_mip = original_mip_offset
    
    # Ray length limit
    max_dist = 100.0 
    t = 0.0
    
    while t < max_dist:
        # Sample density at current position
        density = field_texture.sample(current_pos, current_mip)
        
        if density <= 0.0:
            # Empty space: double step size and increase mip offset
            current_step *= 2.0
            current_mip += 1
            
            # Advance ray
            current_pos += ray_direction * current_step
            t += current_step
        else:
            # Non-empty space: step back and restore parameters
            current_pos -= ray_direction * current_step
            current_step = original_step_size
            current_mip = original_mip_offset
            
            # Break to allow standard marching or shading logic to take over
            break
            
    return current_pos, current_step, current_mip
```

## Subtopics

### [Gradient-driven Sampling](5281-gradient-driven-sampling.md)
Gradient-driven Sampling is a dynamic step size adjustment technique for distance-field ray marching that refines traversal steps according to the magnitude of the scalar field gradient $|\nabla s|$. It solves the problem of balancing rendering accuracy against computational cost in volumes with sharp boundaries, such as CT angiography data, by taking smaller steps in high-gradient regions to capture transitions accurately and larger steps in smooth interiors. It sets itself apart from uniform sampling by adapting to local feature sharpness, achieving 2-3x efficiency gains without aliasing artifacts.

### [Dynamic Texture Slice Resampling](6101-dynamic-texture-slice-resampling.md)
Dynamic Texture Slice Resampling is a technique for volume rendering that dynamically updates slicing steps according to viewing directions to maintain a constant step size during the Direct Volume Rendering (DVR) process. It solves the problem of striping artifacts caused by non-uniform sampling steps. The method adapts the sampling density to the viewing geometry to maintain high rendering performance.

### Dynamic Adaptive Sampling Ray-Casting
Dynamic Adaptive Sampling Ray-Casting is an improved volume rendering algorithm designed to address slow rendering speed and low sampling efficiency in 3D reconstruction of medical images by dynamically adjusting sampling intervals and using a new rendering operator [S2]. It uses the central difference gradient method to obtain the corresponding sampling interval dynamically according to the different sampling points [S2]. It applies a new rendering operator based on the color value and opacity changes before and after the ray enters the volume element, and the resistance luminosity [S2]. On the ISBI2018 dataset, the ray-casting DAS algorithm reduces and avoids artifact phenomena in CT image rendering and improves image visibility compared to Francisco Sans' algorithm, Roba Binyahibs' algorithm, Feiniu Yuan's algorithm, Leonardo's algorithm, and Yan Zhang's algorithm [S2]. Compared with other algorithms, this method achieves faster rendering speed while ensuring the quality of the generated image [S2].

### Geometry Sampling Adjustment
Geometry Sampling Adjustment is a method to adjust the maximum number of geometry samples per streamline based on a geometry sampling factor [S3, unofficial]. It sets `m_maxGeometrySamples` to `m_maxSamples / m_geometrySampling + 1` [S3, unofficial]. The parameter `m_maxSamples` is the base maximum number of samples per streamline, and `m_geometrySampling` is a factor used to reduce the number of geometry samples [S3, unofficial].

## Operating characteristics
*   **Time Complexity:** Reduces the number of texture lookups in empty regions by a factor proportional to the size of the empty space, but adds overhead for checking density and managing state [S1, unofficial].
*   **Memory Complexity:** Minimal additional memory, requiring only storage for current step parameters and original values [S1, unofficial].
*   **Measured Performance:** Provides small performance gains [S1, unofficial].
*   **Strengths:** Simple to implement; effective for scenes with large empty volumes [S1, unofficial].
*   **Limitations:** May cause artifacts; small performance gains; not suitable for capturing thin features without additional logic [S1, unofficial].
*   **When to use:** When rendering volumes with significant empty space and where small performance gains are acceptable [S1, unofficial].
*   **When not to use:** When high accuracy at thin boundaries is required or when artifacts are unacceptable [S1, unofficial].

## Background
The concept of dynamic step adjustment in the context of empty space doubling is discussed in the context of real-time volume cloud rendering [S1, unofficial]. The broader context of dynamic adaptive sampling for medical image ray-casting was proposed by Huadeng Wang et al. in 2020 [S2]. Geometry sampling adjustment is found in vector field visualization implementations [S3, unofficial].
