# Dynamic Sampling Step Adjustment

Also called: Adaptive Step Doubling, Empty Space Step Doubling

## Overview
Dynamic Sampling Step Adjustment is a ray marching optimization technique that increases the step size when the ray traverses empty space (zero density) and restores it upon encountering geometry. It solves the problem of redundant samples in homogeneous or empty regions, thereby reducing computational cost. It distinguishes itself from [Gradient-driven Sampling](5281-gradient-driven-sampling.md) by using binary density presence rather than gradient magnitude to drive step selection, and from [Variance-based Step Size Adaptation](13161-variance-based-step-size-adaptation.md) by relying on simple emptiness checks rather than statistical variance.

## How it works
**Inputs and Outputs:**
*   Input: Ray $r(t) = \mathbf{o} + t\mathbf{d}$, current step size $\Delta t$, current mip-map offset $mipOffset$, and a density evaluation function $D(\mathbf{p})$ returning scalar density.
*   Output: Updated step size $\Delta t'$, updated mip-map offset $mipOffset'$, and updated ray position $t'$.

**Data Structures:**
*   `base_step`: The initial, safe step size.
*   `current_step`: The active step size, initialized to `base_step`.
*   `base_mipOffset`: The initial texture sampling level.
*   `current_mipOffset`: The active mip-map level, initialized to `base_mipOffset`.
*   `empty_count`: Integer counter for consecutive empty samples.

**Numbered Steps:**
1.  Evaluate density $d = D(\mathbf{o} + t\mathbf{d})$ at the current position.
2.  If $d > \epsilon$ (where $\epsilon$ is a small threshold, e.g., machine epsilon or a defined empty threshold):
    *   The ray has hit geometry or non-empty volume.
    *   Step back: $t \leftarrow t - \Delta t$.
    *   Reset step size: $\Delta t \leftarrow \text{base\_step}$.
    *   Reset mip-map offset: $mipOffset \leftarrow \text{base\_mipOffset}$.
    *   Reset empty counter: `empty_count` $\leftarrow 0$.
    *   Proceed with standard rendering/sampling at the reset position.
3.  If $d \le \epsilon$ (empty space):
    *   Increment empty counter: `empty_count` $\leftarrow \text{empty\_count} + 1$.
    *   Double the step size: $\Delta t \leftarrow \Delta t \times 2$.
    *   Increase mip-map offset: $mipOffset \leftarrow mipOffset + 1$ (or clamp to max mip level).
    *   Advance ray: $t \leftarrow t + \Delta t$.
4.  Repeat until termination conditions (hit, escape, or max iterations) are met.

**Formulas:**
*   Step update on empty: $\Delta t_{new} = 2 \cdot \Delta t_{old}$
*   Position update: $t_{new} = t_{old} + \Delta t_{new}$
*   Mip update: $mipOffset_{new} = \min(mipOffset_{old} + 1, mipMax)$

**Parameters:**
*   `base_step`: Typically determined by the Lipschitz constant of the SDF or the voxel size in volume rendering. Not given in the sources for specific values.
*   `epsilon`: Threshold for "empty". Not given in the sources.

**Edge Cases and Pitfalls:**
*   **Artifacts:** The optimization provides small performance gains and may cause artifacts in some cases [S1, unofficial]. This can occur if the step size doubles too aggressively, skipping over thin features or causing aliasing.
*   **Oscillation:** If the ray oscillates between empty and non-empty regions, the step size and mip offset will fluctuate, potentially causing visual instability.
*   **Boundary Precision:** Stepping back one step upon hit ensures the ray is re-evaluated at the boundary, but precision errors in floating-point arithmetic may cause the ray to slightly penetrate or miss the surface if not handled with a small epsilon check.

**Pseudocode:**
```python
def dynamic_sampling_step_adjustment(ray_origin, ray_direction, base_step, base_mip_offset, max_mip_offset, density_func, epsilon=1e-6):
    """
    Performs ray marching with dynamic step adjustment for empty space.
    
    Args:
        ray_origin: 3D vector, ray origin.
        ray_direction: 3D vector, normalized ray direction.
        base_step: float, initial step size.
        base_mip_offset: int, initial mip-map level.
        max_mip_offset: int, maximum mip-map level.
        density_func: function(p) -> float, returns density at point p.
        epsilon: float, threshold for empty space.
        
    Returns:
        t: float, final accumulated distance.
        hit: bool, whether a hit was detected.
    """
    t = 0.0
    current_step = base_step
    current_mip_offset = base_mip_offset
    empty_count = 0
    hit = False
    
    # Safety limit to prevent infinite loops
    max_iterations = 1000
    iteration = 0
    
    while iteration < max_iterations:
        # Calculate current position
        p = ray_origin + t * ray_direction
        
        # Evaluate density
        density = density_func(p, mip_offset=current_mip_offset)
        
        if density > epsilon:
            # Hit non-empty space
            hit = True
            # Step back to the boundary
            t = t - current_step
            # Reset step size and mip offset
            current_step = base_step
            current_mip_offset = base_mip_offset
            empty_count = 0
            # Break or continue with hit processing
            break
        else:
            # Empty space
            empty_count += 1
            # Double step size
            current_step = current_step * 2
            # Increase mip offset
            if current_mip_offset < max_mip_offset:
                current_mip_offset += 1
            # Advance ray
            t = t + current_step
            
        iteration += 1
        
    return t, hit
```

## Subtopics

### [Gradient-driven Sampling](5281-gradient-driven-sampling.md)
Gradient-driven sampling is a ray marching technique that dynamically adjusts step sizes based on the magnitude of the scalar field gradient, refining traversal in regions with high feature sharpness while coarsening it in smooth interiors. It distinguishes itself from uniform sampling by adapting to local geometry to preserve boundary details without aliasing, and from hierarchical sampling by using gradient magnitude rather than variance or error tolerance to drive step selection.

### [Dynamic Texture Slice Resampling](6101-dynamic-texture-slice-resampling.md)
Dynamic Texture Slice Resampling is a technique for volume rendering that dynamically updates slicing steps according to viewing directions to maintain a constant step size during the Direct Volume Rendering (DVR) process. It solves the problem of striping artifacts caused by non-uniform sampling steps. The method adapts the sampling density to the viewing geometry to maintain high rendering performance.

### Dynamic Adaptive Sampling Ray-Casting
Dynamic Adaptive Sampling Ray-Casting is an improved volume rendering algorithm designed to address slow rendering speed and low sampling efficiency in 3D reconstruction of medical images by dynamically adjusting sampling intervals and using a new rendering operator [S2]. It uses the central difference gradient method to obtain the corresponding sampling interval dynamically according to the different sampling points [S2]. It applies a new rendering operator based on the color value and opacity changes before and after the ray enters the volume element, and the resistance luminosity [S2]. On the ISBI2018 dataset, the ray-casting DAS algorithm reduces and avoids artifact phenomena in CT image rendering and improves image visibility compared to Francisco Sans' algorithm, Roba Binyahibs' algorithm, Feiniu Yuan's algorithm, Leonardo's algorithm, and Yan Zhang's algorithm [S2]. Compared with other algorithms, this method achieves faster rendering speed while ensuring the quality of the generated image [S2].

### Geometry Sampling Adjustment
Geometry Sampling Adjustment is a method to adjust the maximum number of geometry samples per streamline based on a geometry sampling factor [S3, unofficial]. It sets `m_maxGeometrySamples` to `m_maxSamples / m_geometrySampling + 1` [S3, unofficial]. `m_maxSamples` is the base maximum number of samples per streamline, and `m_geometrySampling` is a factor used to reduce the number of geometry samples [S3, unofficial].

## Operating characteristics
*   **Time Complexity:** Reduces the number of samples in empty space by a factor of up to $2^k$ where $k$ is the number of consecutive empty samples. However, the doubling strategy can lead to overshooting thin features if not carefully managed.
*   **Memory Complexity:** Minimal additional memory required (a few counters and variables).
*   **Measured Performance:** Provides small performance gains [S1, unofficial].
*   **Strengths:** Simple to implement, effective for scenes with large empty regions (e.g., atmospheric rendering, large voids in medical volumes).
*   **Limitations:** May cause artifacts [S1, unofficial]. Not suitable for scenes with fine, thin details that might be skipped by large steps.
*   **When to use:** When rendering volumes with significant empty space and performance is critical.
*   **When not to use:** When rendering fine details or when artifacts are unacceptable.

## Background
The technique is commonly used in real-time volume rendering, particularly in game engines for atmospheric effects like clouds and fog [S1, unofficial]. It is also applied in medical image processing to improve rendering speed [S2]. The concept of doubling step size in empty space is a standard optimization in sphere tracing and ray marching [S1, unofficial].
