# Segment Tracing with Local Lipschitz Bounds

Also called: Local Lipschitz Segment Tracing, Segment Tracing Using Local Lipschitz Bounds

## Overview
Segment Tracing is a ray marching algorithm for implicit surfaces that computes a local Lipschitz bound $\lambda(e)$ for each ray segment $e$ to determine safe, adaptive step sizes, significantly reducing field function queries compared to global bound methods [S1]. Unlike [Gradient-based Sphere Tracing with Lipschitz Constraints](1936-gradient-based-sphere-tracing-with-lipschitz-constraints.md) which uses gradient magnitude to estimate step size, Segment Tracing rigorously bounds the gradient of the deformed field and the Jacobian of the deformation map to guarantee no surface intersections are skipped, even under complex non-linear warping [S1].

## How it works

### Inputs and Outputs
*   **Inputs**: A ray defined by origin $o$ and direction $d$; a scalar field defined by a Blob Tree (sum of primitives, potentially with deformation operators); scene bounding box [S2, unofficial].
*   **Outputs**: Intersection distance $t$, accumulated opacity $\alpha$, and accumulated color $C$ [S2, unofficial].

### Data Structures

**Blob Tree Node Hierarchy**
The scalar field is represented as a tree [S2, unofficial]. Two primary node types are defined in the reference implementation [S2, unofficial]:

1.  **BlobTreePoint (Primitive)**
    *   `Vector c`: Center of the primitive.
    *   `double r`: Radius of the primitive.
    *   `double e`: Energy (intensity magnitude).
    *   `Box box`: Axis-aligned bounding box enclosing the primitive.
    *   `double k`: Precomputed global Lipschitz constant for this primitive.

2.  **BlobTreeBlend (Composite)**
    *   `BlobTreeNode* e[2]`: Pointers to left and right child nodes.
    *   `Box box`: Bounding box of the union of children.
    *   `double k`: Global Lipschitz constant (sum of children's $k$).

**Box**
*   `Vector a`: Minimum corner.
*   `Vector b`: Maximum corner.

**Segment**
*   Defined by endpoints $a$ and $b$ (vectors). Used to compute local bounds [S2, unofficial].

### Formulas

**1. Deformed Field Gradient**
For a warping function $\omega: \mathbb{R}^3 \to \mathbb{R}^3$ deforming space, the field function is $f_W = f_N \circ \omega^{-1}$ [S1]. The gradient is:
$$ \nabla f_W = \nabla(f_N \circ \omega^{-1}) = \nabla f_N \circ \omega^{-1} \cdot \mathbf{J}_{\omega^{-1}} $$
where $\mathbf{J}_{\omega^{-1}}$ is the Jacobian matrix of the inverse deformation [S1].

**2. Lipschitz Bound Estimation**
The local Lipschitz bound $\lambda(e)$ for a segment $e$ is estimated by bounding the gradient norm and the Jacobian norm:
$$ \|\nabla(f_N \circ \omega^{-1})\| \leq \|\nabla f_N \circ \omega^{-1}\| \cdot \|\mathbf{J}_{\omega^{-1}}\| $$
Two bounds must be computed for segment $e$: the bound of the gradient norm $\|\nabla(f_N \circ \omega^{-1})(e)\|$ and the bound of the Jacobian norm $\|\mathbf{J}_{\omega^{-1}}(e)\|$ [S1].

**3. Gradient Bound via Bounding Sphere**
To bound the gradient over the deformed segment $\omega^{-1}(e)$, a bounding sphere $S$ is computed such that $S \supset \omega^{-1}(e)$ [S1]. Let $\lambda$ be the global Lipschitz bound of $\omega^{-1}$ and $c$ be the segment center [S1]. The inclusion property is:
$$ \omega^{-1}(e) \subset \mathbf{S}(\omega^{-1}(c), \lambda \|e\|/2) $$
The upper bound is then:
$$ \sup \|\nabla f_N \circ \omega^{-1}(e)\| \leq \sup \|\nabla f_N(S)\| $$
This allows bounding the gradient by recursively querying the sub-tree for the sphere $S$, which is simpler than evaluating the curve $\omega^{-1}(e)$ directly [S1].

**4. Jacobian Norm**
The Euclidean norm of the Jacobian is the square root of the spectral radius of $\mathbf{J}_{\omega^{-1}} \mathbf{J}_{\omega^{-1}}^*$:
$$ \|\mathbf{J}_{\omega^{-1}}\| = \sqrt{\rho(\mathbf{J}_{\omega^{-1}} \mathbf{J}_{\omega^{-1}}^*)} $$
In the general case where spectral norm computation is difficult, the Frobenius norm is used as a fallback:
$$ \|\mathbf{J}_{\omega^{-1}}\| \leq \|\mathbf{J}_{\omega^{-1}}\|_F = \sqrt{\sum_{i,j} (\mathbf{J}_{\omega^{-1}})_{ij}^2} $$
This is less accurate but easier to compute [S1].

**5. Intersection Rejection Criterion**
For a segment $e=[a,b]$ with center $c$, the segment does not intersect the surface if:
$$ \frac{|f(c)|}{\lambda(e)} > \|e\| $$
This allows early rejection in binary search bisection [S1].

**6. Optimized Bisection**
Instead of equal halves, the interval $e=[a,b]$ is shrunk to $[e_a, e_b]$ where:
$$ e_a = a + \frac{|f(a)|}{\lambda(e)}, \quad e_b = b - \frac{|f(b)|}{\lambda(e)} $$
This discards parts of the interval guaranteed to be free of intersections [S1].

### Parameters
*   $\epsilon$: Small constant for numerical stability, defined as $10^{-3}$ [S2, unofficial].
*   $e_{overstep}$: Overstep factor, range $[1.0, 2.0]$. Implementation uses $1.0$ [S2, unofficial].
*   $c_{accel}$: Acceleration factor for step size increase. Implementation uses $1.5$ [S2, unofficial].
*   $\lambda$: Global Lipschitz bound of $\omega^{-1}$, used for bounding sphere radius [S1].

### Pseudocode

```python
def SegmentTracing(ray_o, ray_d, blob_tree, box_min, box_max):
    # 1. Intersect with scene bounding box
    t_min, t_max = box_min.Intersect(ray_o, ray_d)
    if t_min is None:
        return False, 0.0, 0.0, 0.0

    t = t_min
    alpha = 0.0
    color = [0.0, 0.0, 0.0]
    step_count = 0
    ts = t_max - t_min  # max allowed step size
    te = 0.0            # previous step size
    overstep_factor = 1.0
    ce = overstep_factor - 1.0  # = 0.0 per implementation
    accel_factor = 1.5
    epsilon = 1e-3

    while t < t_max and alpha < 1.0:
        step_count += 1
        p = ray_o + t * ray_d

        intensity = blob_tree.Intensity(p)
        if intensity > 0.0:
            return True, t, alpha, color

        grad = blob_tree.Gradient(p)
        grad_norm = Norm(grad)

        seg_start = ray_o + t * ray_d
        seg_end = ray_o + (t + ts) * ray_d
        segment = Segment(seg_start, seg_end)

        K = blob_tree.K(segment)
        if K == 0.0:
            tk = ts
        else:
            tk = abs(intensity) / K
            tk = min(tk, ts)

        ts = tk

        if tk < ce * te:
            t = t - ce * te
            te = 0.0
            continue

        te = max(tk * overstep_factor, epsilon)
        t = t + te

        ts = tk * accel_factor

        # Volume accumulation (not detailed in core algorithm notes)
        # alpha_seg = 1.0 - exp(-intensity * te)
        # color += alpha_seg * alpha * [1.0, 1.0, 1.0]
        # alpha += alpha_seg * (1.0 - alpha)

    return False, t, alpha, color

def Norm(v):
    return (v[0]**2 + v[1]**2 + v[2]**2)**0.5

def SquaredNorm(v):
    return v[0]**2 + v[1]**2 + v[2]**2

def Dot(u, v):
    return u[0]*v[0] + u[1]*v[1] + u[2]*v[2]

def Normalize(v):
    n = Norm(v)
    if n == 0.0: return [0.0, 0.0, 0.0]
    return [x/n for x in v]

class Segment:
    def __init__(self, start, end):
        self.start = start
        self.end = end
    def GetBox(self):
        return Box(Min(self.start, self.end), Max(self.start, self.end))
    def Intersect(self, box):
        # Simplified AABB intersection check
        b = box.GetBox()
        for i in range(3):
            if self.start[i] > b.b[i] or self.end[i] < b.a[i]:
                return False
        return True

class Box:
    def __init__(self, a, b):
        self.a = a
        self.b = b
    def GetBox(self):
        return self
    def Intersect(self, ray_o, ray_d):
        t_min, t_max = -float('inf'), float('inf')
        for i in range(3):
            if abs(ray_d[i]) < 1e-6:
                if ray_o[i] < self.a[i] or ray_o[i] > self.b[i]:
                    return None, None
            else:
                t1 = (self.a[i] - ray_o[i]) / ray_d[i]
                t2 = (self.b[i] - ray_o[i]) / ray_d[i]
                t_min = max(t_min, min(t1, t2))
                t_max = min(t_max, max(t1, t2))
        if t_min > t_max:
            return None, None
        return t_min, t_max

def Min(a, b):
    return [min(a[i], b[i]) for i in range(3)]

def Max(a, b):
    return [max(a[i], b[i]) for i in range(3)]

def BlobTreePoint_K(segment, c, r, e):
    a = segment.start
    b = segment.end
    if not segment.Intersect(Box([c[i]-r for i in range(3)], [c[i]+r for i in range(3)])):
        return 0.0
    axis = Normalize(b - a)
    l = Dot(c - a, axis)
    kk = 0.0
    if l < 0.0:
        kk = CubicFalloffK(SquaredNorm(c - a), SquaredNorm(c - b), r, e)
    elif Norm(b - a) < l:
        kk = CubicFalloffK(SquaredNorm(c - b), SquaredNorm(c - a), r, e)
    else:
        dd = SquaredNorm(c - a) - (l * l)
        kk = CubicFalloffK(dd, max(SquaredNorm(c - b), SquaredNorm(c - a)), r, e)
    grad_factor = max(abs(Dot(axis, Normalize(c - a))), abs(Dot(axis, Normalize(c - b))))
    return kk * grad_factor

def CubicFalloffK(a_sq, b_sq, R, s):
    R_sq = R * R
    if a_sq > R_sq:
        return 0.0
    if b_sq < (R_sq / 5.0):
        t = 1.0 - b_sq / R_sq
        return abs(s) * 6.0 * (b_sq**0.5 / R_sq) * (t * t)
    elif a_sq > (R_sq / 5.0):
        t = 1.0 - a_sq / R_sq
        return abs(s) * 6.0 * (a_sq**0.5 / R_sq) * (t * t)
    else:
        return 1.72 * abs(s) / R
```

### Edge Cases and Pitfalls
1.  **Spectral Norm Computation**: Computing the exact spectral norm of the Jacobian is difficult. Use the Frobenius norm as a fallback [S1].
2.  **Uniform Distribution**: For objects with uniform primitive distribution and uniform Lipschitz bounds (e.g., Chess king, Amphora), the overhead of computing $\lambda(e)$ makes Segment Tracing slower than Sphere Tracing. Use Ray or Sphere variations instead [S1].
3.  **Degenerate BVH Partition**: If `std::partition` places all elements on one side during BVH construction, adjust `midIndex` to `(begin + end) / 2` to ensure recursion progresses [S2, unofficial].
4.  **Ray Parallel to Slab**: In `Box::Intersect`, if a ray direction component $d[i]$ is near zero ($|d[i]| < \epsilon$), the ray is parallel to the slab. If the origin is outside the slab, return no intersection [S2, unofficial].
5.  **Segment-BVH Culling**: `BlobTreeBlend::K` checks if the segment's bounding box intersects the node's box. If not, return 0 [S2, unofficial].

## Operating characteristics

### Time and Memory Complexity
*   **Time**: The algorithm reduces field function queries by one to two orders of magnitude for complex models compared to global Sphere Tracing [S1]. However, the computation of $\lambda(e)$ adds overhead per step [S1].
*   **Memory**: Preserves the compact format of hierarchical implicit surface models (Blob Trees). Does not require additional memory structures like voxel grids [S1].

### Measured Performance
*   **CPU**: On Intel Core i7 3GHz, Segment Tracing reduced queries significantly for Chandelier and Temple models [S1].
*   **GPU**: On nVidia GeForce 2070, Segment Tracing achieved 67 Hz vs 6 Hz for standard Sphere Tracing, an acceleration factor close to an order of magnitude [S1].

### Strengths and Limitations
*   **Strengths**: Significantly fewer field function queries for complex, non-linear deformations. Safe stepping guaranteed by local bounds.
*   **Limitations**: Overhead of computing $\lambda(e)$ can negate benefits for simple or uniformly distributed primitives. Computation of Jacobian norms can be costly if spectral norm is required [S1].

### When to Use
*   Use for complex implicit surfaces with non-linear deformations (warping) where global bounds are too conservative.
*   Avoid for simple, uniformly distributed primitives where Ray or Sphere variations are faster [S1].

## Background

### Origin
Segment Tracing was introduced by Eric Galin, Eric Guérin, Axel Paris, and Adrien Peytavie in 2020 in the paper "Segment Tracing Using Local Lipschitz Bounds" published in *Computer Graphics Forum* [S2, unofficial].

### History and Development
The method builds upon Sphere Tracing and Lipschitz-constrained ray marching. It specifically addresses the inefficiency of global Lipschitz bounds in the presence of local variations in field complexity and deformation. The technique is particularly effective for blob trees with deformation operators (e.g., tapering) [S1].

### Applications
*   Rendering complex implicit surfaces defined by blob trees.
*   Volume rendering using scalar fields defined by cubic falloff primitives.
*   Global illumination secondary ray intersections where field function query cost is critical [S1].
