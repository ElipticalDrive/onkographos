# Chamfer-L1 Distance Computation

Also called: Chamfer Distance, Chamfer-L1

## Overview
Chamfer-L1 Distance Computation is a metric evaluation technique used to quantify the geometric fidelity between a predicted Signed Distance Function (SDF) and a ground-truth mesh representation. It solves the problem of comparing two discrete geometric representations by measuring the average nearest-neighbor distance between sampled points on the predicted surface and the ground-truth surface. It sets itself apart from its siblings in the Sphere Tracing family by serving as a post-processing evaluation metric rather than a ray-marching step-size rule; while siblings like [Cone Intersection](1553-cone-intersection.md) optimize traversal, this method utilizes sphere tracing to generate the high-fidelity samples required for the distance calculation.

## How it works
The method computes the Chamfer distance between two point sets: $P_{pred}$ (samples from the predicted SDF) and $P_{gt}$ (samples from the ground-truth mesh). The distance is typically defined as the mean of the nearest-neighbor distances in both directions, though the specific implementation cited uses a one-sided or symmetric variant depending on the library.

**Inputs:**
1.  Predicted SDF field $S(x)$.
2.  Ground-truth mesh $M$.
3.  Bounding volume $B$ (axis-aligned box containing the object).
4.  Number of samples $N = 2^{17} = 131,072$.

**Outputs:**
1.  Scalar Chamfer distance value.

**Data Structures:**
*   $P_{pred}$: List of 3D points $(x, y, z)$ sampled from the zero-level set of $S$.
*   $P_{gt}$: List of 3D points sampled from the surface of $M$.

**Steps:**
1.  **Sample Predicted Surface:**
    a.  Uniformly sample $N$ points $x_i$ within the bounding volume $B$.
    b.  For each $x_i$, assign a random spherical direction $d_i$ (uniformly distributed on the unit sphere).
    c.  Trace a ray $r_i(t) = x_i + t \cdot d_i$ using sphere tracing on $S$.
    d.  Collect intersection points $p_j$ where $S(p_j) \approx 0$.
    e.  Repeat sampling until the minimum required number of surface points is obtained, adhering to the stopping criterion defined in the parent context (typically ensuring sufficient coverage of the surface) [S1].
2.  **Sample Ground-Truth Surface:**
    a.  Extract the ground-truth mesh $M$ (e.g., via Marching Cubes) or sample directly from the implicit ground-truth SDF if available. Note that mesh extraction introduces additional error [S1].
    b.  Uniformly sample points $P_{gt}$ from the surface of $M$.
3.  **Compute Distance:**
    a.  For each point $p \in P_{pred}$, find the nearest neighbor $q \in P_{gt}$ using Euclidean distance: $d(p, P_{gt}) = \min_{q \in P_{gt}} \|p - q\|_2$.
    b.  For each point $q \in P_{gt}$, find the nearest neighbor $p \in P_{pred}$: $d(q, P_{pred}) = \min_{p \in P_{pred}} \|q - p\|_2$.
    c.  The Chamfer distance is the mean of these distances. The specific implementation referenced uses the Chamfer distance as implemented in PyTorch3D [S1].

**Pseudocode:**
```python
import torch
import numpy as np

def compute_chamfer_l1(sdf_function, mesh_vertices, mesh_faces, bounding_volume, num_samples=131072):
    """
    Computes Chamfer distance between predicted SDF and ground-truth mesh.
    Note: This pseudocode reflects the sampling strategy described in [S1].
    Actual distance calculation relies on PyTorch3D implementation [S1].
    """
    # 1. Sample points in bounding volume
    # Uniform sampling in bounding box B
    min_coords, max_coords = bounding_volume
    samples = torch.rand(num_samples, 3) * (max_coords - min_coords) + min_coords
    
    # 2. Trace rays using sphere tracing to find surface intersections
    predicted_points = []
    for i in range(num_samples):
        x0 = samples[i]
        # Random spherical direction
        direction = torch.randn(3)
        direction = direction / torch.norm(direction)
        
        # Sphere tracing loop (conceptual, details in Sphere Tracing article)
        t = 0.0
        max_steps = 100
        for step in range(max_steps):
            pos = x0 + t * direction
            dist = sdf_function(pos)
            if dist < 1e-4: # Surface hit
                predicted_points.append(pos)
                break
            t += dist
            if t > 10.0: # Max ray length
                break
                
    predicted_points = torch.stack(predicted_points)
    
    # 3. Sample ground truth mesh
    # Uniformly sample from mesh surface
    gt_points = sample_mesh_surface(mesh_vertices, mesh_faces, num_samples)
    
    # 4. Compute Chamfer Distance using PyTorch3D logic [S1]
    # PyTorch3D's chamfer_distance computes mean nearest neighbor distance
    # in both directions.
    loss = pytorch3d_loss.chamfer_distance(predicted_points, gt_points)
    
    return loss

def sample_mesh_surface(vertices, faces, num_samples):
    """Uniformly sample points from a triangle mesh."""
    # Calculate face areas
    v0 = vertices[faces[:, 0]]
    v1 = vertices[faces[:, 1]]
    v2 = vertices[faces[:, 2]]
    face_areas = 0.5 * torch.norm(torch.cross(v1 - v0, v2 - v0), dim=1)
    
    # Sample faces based on area
    face_probs = face_areas / torch.sum(face_areas)
    selected_faces = torch.multinomial(face_probs, num_samples, replacement=True)
    
    # Sample barycentric coordinates
    u = torch.rand(num_samples)
    v = torch.rand(num_samples)
    mask = u + v > 1
    u[mask] = 1 - u[mask]
    v[mask] = 1 - v[mask]
    
    # Interpolate vertices
    pts = (1 - u - v).unsqueeze(1) * v0[selected_faces] + \
          u.unsqueeze(1) * v1[selected_faces] + \
          v.unsqueeze(1) * v2[selected_faces]
    return pts
```

**Parameters:**
*   $N = 131,072$: Number of initial samples in the bounding volume [S1].
*   Resolution: 512×512 for image metrics, but Chamfer is geometry-based [S1].

**Edge Cases:**
*   **Mesh Extraction Error:** Using Marching Cubes to obtain ground-truth samples introduces additional error compared to sampling the true implicit SDF [S1].
*   **Empty Space:** If the predicted SDF fails to capture the surface, the nearest neighbor distance may be large or undefined if no intersection is found.

## Subtopics

## Operating characteristics
*   **Complexity:** The sampling phase is $O(N \cdot S)$ where $N$ is the number of initial samples and $S$ is the average sphere tracing steps. The distance computation is $O(|P_{pred}| \cdot |P_{gt}|)$ for naive nearest neighbor, or $O((|P_{pred}| + |P_{gt}|) \log |P_{gt}|)$ with spatial indexing.
*   **Performance:** The method is computationally expensive due to the ray tracing required to sample the predicted SDF surface [S1].
*   **Strengths:** Provides a robust, differentiable metric for training implicit representations.
*   **Limitations:** Sensitive to the quality of ground-truth mesh extraction; does not account for normal alignment directly (though Normal-L2 is computed separately) [S1].

## Background
The method is used in the context of Neural Geometric Level of Detail (NGLOD) for real-time rendering with implicit 3D shapes [S1]. It leverages the Chamfer distance implementation from PyTorch3D [S1]. The approach was introduced to evaluate the accuracy of predicted SDFs against ground-truth meshes in neural rendering pipelines.
