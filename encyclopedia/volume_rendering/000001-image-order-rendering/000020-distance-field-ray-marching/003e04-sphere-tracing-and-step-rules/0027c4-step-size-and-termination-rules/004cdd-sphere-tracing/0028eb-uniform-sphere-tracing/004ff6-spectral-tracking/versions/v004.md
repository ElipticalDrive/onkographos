# Spectral Tracking

Also called: Single-Distribution Spectral Tracking, Vectorized Weighted Delta Tracking

## Overview
Spectral Tracking is a volumetric rendering technique that efficiently handles spectrally resolved optical properties by decomposing the medium's scattering and absorption coefficients into spectral components (e.g., RGB) and using a single majorant density to drive the sampling process for all wavelengths simultaneously [S3]. Unlike naive delta tracking, which invokes the tracker separately for each wavelength, spectral tracking invokes the tracker only once, computing a spectrally resolved collision weight at each step to counteract the discrepancy between the single sampling distribution and the true per-wavelength free-path distribution [S3]. It differs from its parent, Uniform Sphere Tracing, by replacing the scalar transmittance accumulation with a vectorized throughput update that accounts for spectral variance, and from its sibling, Auto-Relaxed Sphere Tracing, by explicitly managing spectral weights rather than relaxing the majorant bound [S3].

## How it works
**Inputs and Outputs:**
- **Input:** A Volume Scene Definition (`vsdf`) containing the density volume, emission volume, and a global scattering ratio (`scatter`); a ray (`ray`) with origin `o` and direction `d`; a maximum travel distance (`max_distance`); and a random number generator state (`rng`).
- **Output:** A pair containing the total path length traveled and a spectral throughput vector (`f`) representing the accumulated contribution [S2, unofficial].

**Data Structures:**
- `vec3f`: A 3-component vector representing spectral values (Red, Green, Blue).
- `sigma_t`, `sigma_s`, `sigma_a`, `sigma_n`: Spectral vectors for total extinction, scattering, absorption, and null (non-interaction) coefficients.
- `Pt`, `Ps`, `Pn`, `Pa`: Scalar probabilities for total, scattering, null, and absorption events, derived from the spectral coefficients and the majorant.
- `wD` (or `contrib`): A spectral vector used to track the weight correction factor. In the implementation [S2, unofficial], this is updated element-wise.

**Parameters:**
- `majorant_density`: The upper bound on the total extinction coefficient across all wavelengths and space. Typically set to `max_density` [S2, unofficial].
- `imax_density`: The inverse of the majorant density ($1 / \text{majorant\_density}$) [S2, unofficial].
- `scatter`: A scalar representing the albedo or scattering ratio of the medium [S2, unofficial].

**Algorithm Steps:**

1.  **Initialization:**
    -   Retrieve `max_density` from the volume object (`density_vol->max_voxel * object->density_mult`) [S2, unofficial].
    -   Set `majorant_density = max_density` and `imax_density = 1.0f / max_density` [S2, unofficial].
    -   Initialize `path_length = 0.0f` [S2, unofficial].
    -   Initialize spectral throughput vectors: `tr = vec3f(1)` (transmittance) and `f = vec3f(1)` (final contribution/throughput) [S2, unofficial].
    -   Calculate initial scattering coefficient vector: `sigma_s = vsdf.scatter * max_density` [S2, unofficial].
    -   Calculate scattering probability: `Ps = sigma_s * imax_density` [S2, unofficial].
    -   Initialize spectral weight vector `wD` (or `contrib`) to ones, though in the specific implementation [S2, unofficial], `contrib` is initialized to zero and updated conditionally. Note: The theoretical formulation [S3] initializes $w_D \leftarrow (1, \dots, 1)^{N_\lambda}$. The implementation [S2, unofficial] handles weights via the `contrib` vector logic below.

2.  **Loop:**
    -   **Sample Path Length:**
        -   Generate a uniform random number $\zeta \in [0, 1)$ using `rng` [S3].
        -   Compute tentative distance: $t = -\ln(1 - \zeta) / \text{majorant\_density}$ [S3].
        -   Update `path_length += t` [S2, unofficial]. (Note: Source [S2, unofficial] uses `path_length -= log(...) * imax_density`, which is mathematically equivalent to adding $-\ln(\dots)/\text{majorant}$).
        -   **Termination Check:** If `path_length >= max_distance`, break the loop [S2, unofficial].

    -   **Evaluate Coefficients:**
        -   Calculate current position: $\mathbf{x} = \text{ray}.o + \text{path\_length} \times \text{ray}.d$ [S2, unofficial].
        -   Evaluate total extinction coefficient at $\mathbf{x}$: $\sigma_t(\mathbf{x}) = \text{vec3f}(\text{eval\_vpt\_density}(vsdf, \mathbf{x}))$ [S2, unofficial]. This returns the spectral extinction vector.
        -   Calculate null (non-interaction) coefficient: $\sigma_n(\mathbf{x}) = \text{majorant\_density} - \sigma_t(\mathbf{x})$ [S2, unofficial].
        -   Calculate absorption coefficient: $\sigma_a(\mathbf{x}) = \sigma_t(\mathbf{x}) - \sigma_s$ [S2, unofficial].     -   **Calculate Probabilities:**
        -   $P_t(\mathbf{x}) = \sigma_t(\mathbf{x}) \times \text{imax\_density}$ [S2, unofficial].
        -   $P_n(\mathbf{x}) = \sigma_n(\mathbf{x}) \times \text{imax\_density}$ [S2, unofficial].
        -   $P_a(\mathbf{x}) = 1.0 - P_s - P_n(\mathbf{x})$ [S2, unofficial]. (Note: $P_s$ is constant from initialization).

    -   **Event Selection:**
        -   Generate a random number $\xi \in [0, 1)$ [S3].
        -   **Absorption:** If $\xi < P_a(\mathbf{x})$ (specifically `max(Pa) > rand1f(rng)` in [S2, unofficial] to handle vector max, though theoretically it compares against the scalar probability derived from the spectral weight or max component):
            -   Calculate contribution weight: $\text{contrib} = \sigma_a(\mathbf{x}) / (\text{majorant\_density} \times P_a(\mathbf{x}))$ [S2, unofficial].
            -   Normalize: $\text{contrib} /= \max(\text{contrib})$ [S2, unofficial].
            -   Set event type to `EVENT_ABSORB` [S2, unofficial].
            -   Return `{ path_length, tr * contrib }` [S2, unofficial].

            -   Calculate contribution weight: $\text{contrib} = \sigma_s / (\text{majorant\_density} \times P_s)$ [S2, unofficial].
            -   Normalize: $\text{contrib} /= \max(\text{contrib})$ [S2, unofficial].
            -   Set event type to `EVENT_SCATTER` [S2, unofficial].
            -   Return `{ path_length, tr * contrib }` [S2, unofficial].
        -   **Null (Non-Interaction):** Else:
            -   Calculate contribution weight: $\text{contrib} = \sigma_n(\mathbf{x})$ [S2, unofficial].

**Pseudocode (based on [S2, unofficial]):**

```python
def eval_spectral_tracking(vsdf, max_distance, rng, ray):
    object = vsdf.object
    density_vol = object.density_vol
    max_density = density_vol.max_voxel * object.density_mult
    majorant_density = max_density
    imax_density = 1.0f / max_density
    
    path_length = 0.0f
    tr = vec3f(1.0)
    f = vec3f(1.0)
    
    # sigma_s is assumed constant based on vsdf.scatter in this implementation
    sigma_s = vsdf.scatter * max_density
    Ps = sigma_s * imax_density
    
    while True:
        # Sample path length
        rand_val = rand1f(rng)
        path_length -= log(1.0 - rand_val) * imax_density
        
        if path_length >= max_distance:
            break
            
        current_pos = ray.o + path_length * ray.d
        
        # Evaluate spectral extinction
        sigma_t = vec3f(eval_vpt_density(vsdf, current_pos))
        
        # Calculate coefficients
        sigma_n = majorant_density - sigma_t
        sigma_a = sigma_t - sigma_s
        
        # Calculate probabilities
        Pt = sigma_t * imax_density
        Pn = sigma_n * imax_density
        Pa = 1.0 - Ps - Pn
        
        # Update transmittance (Note: This line appears in source [S2, unofficial], 
        # though standard DT handles transmittance via weights. 
        # Included here as per source [S2, unofficial].)
        tr *= exp(-sigma_t * path_length)
        
        contrib = vec3f(0.0)
        
        # Event selection
        # Note: Source [S2, unofficial] uses max(Pa) and max(Pt) for comparison.
        # This implies checking against the maximum component of the spectral vector.
        if max(Pa) > rand1f(rng):
            # Absorption
            contrib = sigma_a / (majorant_density * Pa)
            contrib /= max(contrib)
            vsdf.event = EVENT_ABSORB
            vsdf.density = sigma_t
            return { path_length, tr * contrib }
        elif max(Pt) > rand1f(rng):
            # Scattering
            contrib = sigma_s / (majorant_density * Ps)
            contrib /= max(contrib)
            vsdf.event = EVENT_SCATTER
            vsdf.density = sigma_t
            return { path_length, tr * contrib }
        else:
            # Null event
            contrib = sigma_n
            contrib /= max(contrib)
            f *= contrib
            
    return { max_distance, f }
```

**Edge Cases and Pitfalls:**
-   **Variance Growth:** If the spectral weights $w_D$ deviate significantly from 1 (e.g., when $P_\lambda \ll |\mu_\lambda / \bar{\mu}|$), the throughput can grow geometrically, leading to high variance [S3].
-   **Implementation Discrepancy:** The implementation in [S2, unofficial] contains a transmittance update `tr *= exp(-sigma_t*path_length)` which is non-standard for Delta Tracking (where transmittance is usually implicit in the weight or handled via the majorant sampling). This may lead to incorrect results if not accounted for, as noted by the issue reporter [S2, unofficial].
-   **Constant Scattering:** The implementation [S2, unofficial] assumes `sigma_s` is constant (`vsdf.scatter * max_density`), which may not hold for heterogeneous media with varying albedo.

## Subtopics

### [Unidirectional Spectral Tracking](14101-unidirectional-spectral-tracking.md)
Unidirectional Spectral Tracking is a variant that employs specific unidirectional event selection logic to simplify throughput update and termination conditions for single-bounce or specific path configurations [14101-unidirectional-spectral-tracking.md]. It relies on a mean-based majorant rather than a per-voxel maximum, differing from the parent Spectral Tracking which uses a global or per-voxel maximum majorant [14101-unidirectional-spectral-tracking.md].

### Spectral and Decomposition Tracking Combined
This variant combines spectral tracking with decomposition tracking to further reduce variance and render time in heterogeneous volumes, particularly for subsurface scattering [S3]. By using approximate minimum and maximum values over the entire medium (found via random sampling in a pre-pass) for control and free-path-sampling coefficients, it achieves a 2.70× reduction in LTUV over delta tracking, with decomposition tracking providing an additional 2.05× reduction [S3]. In the translucent dragon scene, this combination reduced total render time by 22% and yielded 1.65× lower RMSE compared to delta tracking [S3]. The performance gain is attributed to different path distributions and lower throughputs allowing Russian roulette to terminate paths earlier [S3].

## Operating characteristics
-   **Time Complexity:** $O(N)$ where $N$ is the number of steps along the ray. Each step involves evaluating the density volume and performing vector operations.
-   **Memory Complexity:** $O(1)$ auxiliary space per ray, excluding the storage for the volume data itself.
-   **Performance:** Spectral tracking reduces the number of tracker invocations compared to naive delta tracking by handling all wavelengths in a single pass [S3]. In the translucent dragon scene, spectral tracking reduced LTUV by 2.70× over delta tracking [S3]. Combined with decomposition tracking, it reduced render time by 22% [S3].
-   **Strengths:** Efficient handling of spectrally resolved properties; reduced variance compared to naive per-wavelength delta tracking; suitable for heterogeneous volumes.
-   **Limitations:** Variance can increase if the majorant bound is loose or if spectral weights deviate significantly from 1 [S3]. The implementation in [S2, unofficial] has noted correctness issues regarding transmittance calculation.

## Background
Spectral Tracking was introduced by Kutz et al. in the paper "Spectral and Decomposition Tracking for Rendering Heterogeneous Volumes" [S3]. It was implemented in the Yocto/GL project by RickyMexx as `eval_spectral_tracking` [S1, unofficial]. The method addresses the inefficiency of handling spectrally resolved collision coefficients by invoking the tracker separately for each wavelength, instead using a single distribution for all wavelengths and reweighting [S3].
