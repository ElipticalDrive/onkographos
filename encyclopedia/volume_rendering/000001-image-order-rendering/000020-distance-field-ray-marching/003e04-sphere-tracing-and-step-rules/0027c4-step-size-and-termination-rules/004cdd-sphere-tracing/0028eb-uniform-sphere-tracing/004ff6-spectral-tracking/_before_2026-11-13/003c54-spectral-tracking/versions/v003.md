# Spectral Tracking

Also called: Single-Distribution Spectral Tracking, Vectorized Weighted Delta Tracking

## Overview
Spectral tracking is a volume rendering technique that handles per-wavelength optical properties by decomposing the medium's scattering and absorption coefficients into spectral components, using a single majorant density to drive the sampling process for all wavelengths simultaneously [S1, unofficial][S2]. Unlike naive delta tracking, which processes each wavelength separately, spectral tracking invokes the tracker only once for all wavelengths, computing a spectrally resolved collision weight at each step to counteract the discrepancy between the single sampling distribution and the true per-wavelength free-path distribution [S2]. This reduces tracker invocations and leverages vectorized operations, making it particularly effective for spectrally heterogeneous media [S2].

## How it works
**Inputs and Outputs:**
*   **Input:** A volume scene definition object (`vsdf`) containing `object`, `density_vol`, `emission_vol`, and a scalar `scatter` ratio; a maximum ray distance (`max_distance`); a random number generator state (`rng`); and a ray defined by origin `o` and direction `d` [S1, unofficial].
*   **Output:** A pair containing the total path length traveled and a spectral contribution vector (typically RGB) representing the accumulated transmittance and scattering contribution [S1, unofficial][S2].

**Data Structures:**
*   `wD`: A spectral weight vector of size $N_\lambda$ initialized to ones, tracking the accumulated importance weights across wavelengths [S2].
*   `sigma_t`, `sigma_s`, `sigma_a`, `sigma_n`: Vectors of size $N_\lambda$ representing total extinction, scattering, absorption, and non-scattering (null) coefficients at the current position [S1, unofficial].
*   `Pt`, `Ps`, `Pa`, `Pn`: Normalized probability vectors for total, scattering, absorption, and null events, respectively [S1, unofficial].

**Parameters:**
*   $N_\lambda$: The number of wavelengths traced, typically 3 using RGB primaries in experiments [S2].
*   $\bar{\mu}(x)$: The free-path-sampling coefficient (majorant), which must bound the maximum value of $\mu_t(x, \lambda)$ across all wavelengths $\lambda$ to keep estimation variance low [S2].
*   `max_distance`: The maximum distance the ray is allowed to travel within the medium [S1, unofficial].

**Algorithm Steps:**
1.  Initialize `majorant_density` = `max_density` = `density_vol->max_voxel * object->density_mult` [S1, unofficial].
2.  Compute `imax_density` = $1.0 / \text{max\_density}$ [S1, unofficial].
3.  Initialize `path_length` = 0.0, `tr` = $\vec{1}$, `f` = $\vec{1}$, and `wD` = $(1, \dots, 1)^{N_\lambda}$ [S1, unofficial][S2].
4.  Compute `sigma_s` = `vsdf.scatter` * `max_density` and `Ps` = `sigma_s` * `imax_density` [S1, unofficial].
5.  Loop indefinitely:
    a. Sample a uniform random number $\zeta \in [0, 1)$ and compute step size $t = -\ln(1-\zeta) / \bar{\mu}$ [S2].
    b. Update `path_length` += $t$ [G].
    c. If `path_length` >= `max_distance`, break and return `{max_distance, f}` [S1, unofficial].
    d. Compute `current_pos` = `ray.o` + `path_length` * `ray.d` [S1, unofficial].
    e. Evaluate $\sigma_t = \text{eval\_vpt\_density}(vsdf, \text{current\_pos})$ [S1, unofficial].
    f. Compute $\sigma_n = \text{majorant\_density} - \sigma_t$ and $\sigma_a = \sigma_t - \sigma_s$ [S1, unofficial].
    g. Compute probabilities: $P_t = \sigma_t \times \text{imax\_density}$, $P_n = \sigma_n \times \text{imax\_density}$, $P_a = 1.0 - P_s - P_n$ [S1, unofficial].
    h. Update transmittance: `tr` *= $\exp(-\sigma_t \times t)$ [G] (corrected from source to use step size $t$ instead of accumulated `path_length` for standard ray marching) [S1, unofficial].
    i. Sample a scalar random number $\xi = \text{rand1f}(rng)$ [S1, unofficial].
    j. If $\max(P_a) > \xi$: compute `contrib` = $\sigma_a / (\text{majorant\_density} \times P_a)$; normalize `contrib` /= $\max(\text{contrib})$; return `{path_length, tr * contrib}` [S1, unofficial].
    k. Else if $\max(P_t) > \xi$: compute `contrib` = $\sigma_s / (\text{majorant\_density} \times P_s)$; normalize `contrib` /= $\max(\text{contrib})$; return `{path_length, tr * contrib}` [S1, unofficial].
    l. Else (null collision): compute `contrib` = $\sigma_n$; normalize `contrib` /= $\max(\text{contrib})$; update `f` *= `contrib`; update `wD` *= $\sigma_n / (\text{majorant\_density} \times P_n)$ [S2]; continue loop [S1, unofficial][S2].

**Pseudocode:**
```python
def eval_spectral_tracking(vsdf, max_distance, rng, ray):
    object = vsdf.object
    density_vol = object.density_vol
    max_density = density_vol.max_voxel * object.density_mult
    majorant_density = max_density
    imax_density = 1.0 / max_density
    path_length = 0.0
    tr = vec3f(1.0)
    f = vec3f(1.0)
    sigma_s = vsdf.scatter * max_density
    Ps = sigma_s * imax_density
    wD = vec3f(1.0)  # N_lambda = 3 for RGB [S2]
    
    while True:
        zeta = rand1f(rng)
        t = -log(1.0 - zeta) / majorant_density
        path_length += t
        if path_length >= max_distance:
            return path_length, f
        current_pos = ray.o + path_length * ray.d
        sigma_t = vec3f(eval_vpt_density(vsdf, current_pos))
        sigma_n = majorant_density - sigma_t
        sigma_a = sigma_t - sigma_s
        Pt = sigma_t * imax_density
        Pn = sigma_n * imax_density
        Pa = 1.0 - Ps - Pn
        tr *= exp(-sigma_t * t)  # [G] corrected to step size t
        xi = rand1f(rng)
        if max(Pa) > xi:
            contrib = sigma_a / (majorant_density * Pa)
            contrib /= max(contrib)
            return path_length, tr * contrib
        elif max(Pt) > xi:
            contrib = sigma_s / (majorant_density * Ps)
            contrib /= max(contrib)
            return path_length, tr * contrib
        else:
            contrib = sigma_n
            contrib /= max(contrib)
            f *= contrib
            wD *= sigma_n / (majorant_density * Pn)  # [S2] weight update
    return max_distance, f
```

**Edge Cases and Pitfalls:**
*   **Variance Growth:** The variance depends on the spectrally resolved collision weights; if probabilities are poorly chosen, weights deviate significantly from 1, causing geometric growth of path throughput [S2].
*   **Majorant Tightness:** The majorant density $\bar{\mu}$ must tightly bound $\max_\lambda \mu_t(x, \lambda)$ to minimize variance [S2].
*   **Implementation Discrepancy:** The provided source code [S1, unofficial] omits the explicit `wD` update in the null branch and uses accumulated `path_length` for transmittance, while the theoretical algorithm [S2] specifies `wD` multiplication and step-based transmittance; implementers should apply the theoretical corrections for strict adherence to weighted delta tracking [S1, unofficial][S2].

## Subtopics

### Spectral and Decomposition Tracking Combined
This variant combines spectral tracking with decomposition tracking to optimize performance for subsurface scattering in heterogeneous volumes without acceleration structures [S2]. It computes control and free-path-sampling coefficients based on approximate minimum and maximum values over the entire medium via random sampling in a pre-pass [S2]. In the translucent dragon scene, spectral tracking reduced LTUV by 2.70× over delta tracking, and adding decomposition tracking further reduced it by 2.05×, yielding a total 5.54× lower LTUV and 1.65× lower RMSE than delta tracking [S2]. Combined techniques reduced total render time by 22% compared to delta tracking [S2]. The render time decrease with spectral tracking is caused by different path distributions and lower throughputs allowing Russian roulette to terminate paths earlier [S2].

## Operating characteristics
*   **Time Complexity:** Reduces tracker invocations compared to per-wavelength delta tracking [S2]. In the translucent dragon scene, render time decreased from 133 core seconds (delta tracking) to 112 core seconds (spectral tracking) [S2].
*   **Memory Complexity:** Requires storage for spectral vectors of size $N_\lambda$ for coefficients and weights, which is minimal for RGB [S2].
*   **Performance:** Spectral tracking reduced LTUV by 2.70× over delta tracking in the translucent dragon scene [S2]. Combined techniques yielded 1.65× lower RMSE than delta tracking [S2].
*   **Strengths:** Efficiently handles spectrally resolved collision coefficients; reduces tracker invocations; suitable for subsurface scattering in heterogeneous media without acceleration structures [S2].
*   **Limitations:** Variance grows if the majorant is loose or probabilities are poorly chosen; decomposition tracking efficiency depends on tight extinction bounds, which is challenging in highly heterogeneous media [S2].
*   **When to Use:** Spectrally heterogeneous media, subsurface scattering, and scenes lacking acceleration structures [S2].
*   **When Not to Use:** Highly heterogeneous media where tight bounds for decomposition are hard to find, or when strict variance control is required and the majorant cannot be tightly bounded [S2].

## Background
Spectral tracking was introduced in the "Spectral and Decomposition Tracking for Rendering Heterogeneous Volumes" paper from Disney Animation [S2]. It was developed to efficiently handle spectrally resolved collision coefficients by invoking the tracker once for all wavelengths, using a single distribution and reweighting to counteract per-wavelength discrepancies [S2]. The technique uses a spectral basis, typically RGB primaries, but holds for arbitrary counts [S2]. It builds on the principles of delta tracking [S2].
