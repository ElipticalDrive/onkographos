# SDF Ray Marching with Grid Lookup

Also called: Intersect kernel

## Overview
A GPU-based ray marching algorithm that samples a 3D Signed Distance Function (SDF) grid to find the first intersection point of a ray with the zero-level set (surface) [S1, unofficial]. It sets itself apart from [Standard Constant Step Ray Marching](1080-standard-constant-step-ray-marching.md) by using linear interpolation to evaluate the SDF at arbitrary points within the grid bounds, allowing for precise intersection detection without fixed step constraints [S1, unofficial].

## How it works
**Inputs and Outputs:**
*   `grid`: 3D tensor of float SDF values, shape `(grid_res_x, grid_res_y, grid_res_z)`.
*   `origins`: 2D tensor of float ray origins, shape `(N, 3)`.
*   `directions`: 2D tensor of float ray directions, shape `(N, 3)`.
*   `origin_image_distances`: 1D tensor of float distances from camera origin to image plane, shape `(N,)`.
*   `pixel_distances`: 1D tensor of float distances from camera origin to pixel locations, shape `(N,)`.
*   `bounding_box_min`: 3D vector defining the minimum corner of the SDF grid's axis-aligned bounding box.
*   `bounding_box_max`: 3D vector defining the maximum corner of the SDF grid's axis-aligned bounding box.
*   `grid_res_x`, `grid_res_y`, `grid_res_z`: Integer resolutions of the SDF grid along each axis.
*   `max_steps`: Integer maximum number of marching steps per ray (default: 1000) [S1, unofficial].

**Outputs:**
*   `voxel_position`: 2D tensor of float, shape `(N, 3)`, storing the voxel coordinates of the intersection.
*   `intersection_pos`: 2D tensor of float, shape `(N, 3)`, storing the 3D world coordinates of the intersection.
*   `gotten_result`: 1D tensor of int, shape `(N,)`, flag indicating if an intersection was found (1) or not (0).

**Data Structures:**
The SDF grid is stored as a contiguous 3D array. Ray parameters are stored in parallel arrays for batch processing.

**Steps:**
1.  Initialize `depth = 0`, `first_time = true`, `gotten_result = 0` for each ray [S1, unofficial].
2.  Loop for `max_steps` [S1, unofficial]:
    a.  Calculate current point: `reached_point_x = origins[i] + depth * directions[i]` (and y, z) [S1, unofficial].
    b.  Call `ValueAt` to get SDF distance at `reached_point` [S1, unofficial].
    c.  Check for exit: If `distance == -1`, set `voxel_position` and `intersection_pos` to -1, set `gotten_result = 1`, and break [S1, unofficial].
    d.  Check for intersection: If `distance < pixel_distances[pixel_index] / origin_image_distances[pixel_index] * depth` AND `distance` is truthy (non-zero), record intersection. Set `voxel_position` to floor of current point (clamped to `grid_res - 1`). Set `intersection_pos` to current point. Set `gotten_result = 1` and break [S1, unofficial].
    e.  Increment `depth` [S1, unofficial].

**ValueAt (Trilinear Interpolation):**
1.  Compute fractional coordinates `tx`, `ty`, `tz` relative to the grid cell containing the point [S1, unofficial].
2.  Interpolate along X to get `c01, c23, c45, c67` [S1, unofficial].
3.  Interpolate along Y to get `c0, c1` [S1, unofficial].
4.  Interpolate along Z for final result [S1, unofficial].

**Pseudocode:**
```python
def value_at(grid, point, grid_res, bounding_box_min, bounding_box_max):
    # Map world point to grid coordinates
    grid_x = (point[0] - bounding_box_min[0]) / (bounding_box_max[0] - bounding_box_min[0]) * (grid_res[0] - 1)
    grid_y = (point[1] - bounding_box_min[1]) / (bounding_box_max[1] - bounding_box_min[1]) * (grid_res[1] - 1)
    grid_z = (point[2] - bounding_box_min[2]) / (bounding_box_max[2] - bounding_box_min[2]) * (grid_res[2] - 1)

    # Check bounds
    if not (0 <= grid_x < grid_res[0] and 0 <= grid_y < grid_res[1] and 0 <= grid_z < grid_res[2]):
        return -1.0

    # Get integer and fractional parts
    ix = int(grid_x)
    iy = int(grid_y)
    iz = int(grid_z)
    fx = grid_x - ix
    fy = grid_y - iy
    fz = grid_z - iz

    # Clamp indices
    ix = max(0, min(ix, grid_res[0] - 1))
    iy = max(0, min(iy, grid_res[1] - 1))
    iz = max(0, min(iz, grid_res[2] - 1))

    # Trilinear interpolation
    c000 = grid[ix, iy, iz]
    c100 = grid[min(ix + 1, grid_res[0] - 1), iy, iz]
    c010 = grid[ix, min(iy + 1, grid_res[1] - 1), iz]
    c110 = grid[min(ix + 1, grid_res[0] - 1), min(iy + 1, grid_res[1] - 1), iz]
    c001 = grid[ix, iy, min(iz + 1, grid_res[2] - 1)]
    c101 = grid[min(ix + 1, grid_res[0] - 1), iy, min(iz + 1, grid_res[2] - 1)]
    c011 = grid[ix, min(iy + 1, grid_res[1] - 1), min(iz + 1, grid_res[2] - 1)]
    c111 = grid[min(ix + 1, grid_res[0] - 1), min(iy + 1, grid_res[1] - 1), min(iz + 1, grid_res[2] - 1)]

    # Interpolate along X
    c01 = c000 * (1 - fx) + c100 * fx
    c23 = c010 * (1 - fx) + c110 * fx
    c45 = c001 * (1 - fx) + c101 * fx
    c67 = c011 * (1 - fx) + c111 * fx

    # Interpolate along Y
    c0 = c01 * (1 - fy) + c23 * fy
    c1 = c45 * (1 - fy) + c67 * fy

    # Interpolate along Z
    return c0 * (1 - fz) + c1 * fz

def ray_marching_with_grid_lookup(grid, origins, directions, origin_image_distances, pixel_distances, grid_res, bounding_box_min, bounding_box_max, max_steps=1000):
    N = origins.shape[0]
    voxel_position = torch.full((N, 3), -1.0)
    intersection_pos = torch.full((N, 3), -1.0)
    gotten_result = torch.zeros(N, dtype=torch.int)

    for i in range(N):
        depth = 0.0
        gotten_result[i] = 0
        for step in range(max_steps):
            # Calculate current point
            reached_point = origins[i] + depth * directions[i]

            # Get SDF distance
            distance = value_at(grid, reached_point, grid_res, bounding_box_min, bounding_box_max)

            # Check for exit
            if distance == -1.0:
                voxel_position[i] = -1.0
                intersection_pos[i] = -1.0
                gotten_result[i] = 1
                break

            # Check for intersection
            # Note: The condition uses pixel_distances and origin_image_distances
            # to scale the distance check relative to the ray's progress
            threshold = pixel_distances[i] / origin_image_distances[i] * depth
            if distance < threshold and distance != 0.0:
                # Record intersection
                voxel_position[i] = torch.floor(reached_point).clamp(0, torch.tensor(grid_res) - 1)
                intersection_pos[i] = reached_point
                gotten_result[i] = 1
                break

            depth += 1.0 # Increment depth

    return voxel_position, intersection_pos, gotten_result
```

## Subtopics

### [Raycasting with Irregular Grid Interpolation](12445-raycasting-with-irregular-grid-interpolation.md)
This method extends SDF ray marching to handle hierarchical voxel grids with varying resolutions. It solves the problem of evaluating the Signed Distance Function (SDF) at arbitrary points near boundaries between different resolution levels, where standard tri-linear interpolation is invalid. It sets itself apart from its parent by replacing the uniform interpolation kernel with a local polynomial fit derived from a linear system, ensuring continuity across resolution boundaries.

## Operating characteristics
**Time and Memory Complexity:**
Time complexity is $O(N \cdot S)$, where $N$ is the number of rays and $S$ is the number of steps per ray (up to `max_steps`). Memory complexity is $O(N)$ for storing ray results, plus $O(grid\_res\_x \cdot grid\_res\_y \cdot grid\_res\_z)$ for the SDF grid [S1, unofficial].

**Measured Performance:**
Performance depends on the grid resolution and the number of steps required to find the intersection. The use of trilinear interpolation allows for efficient GPU implementation [S1, unofficial].

**Strengths and Limitations:**
Strengths include precise intersection detection and efficient GPU implementation. Limitations include the need for a pre-computed SDF grid and potential artifacts near resolution boundaries if not handled correctly [S1, unofficial].

**When to Use:**
Use when precise intersection detection is required and an SDF grid is available. Not suitable for dynamic scenes where the SDF grid changes frequently [S1, unofficial].

## Background
Originated in the context of differentiable rendering and neural implicit representations, specifically in the CVPR 2020 paper "SDFDiff: Difficult Rendering with Signed Distance Functions" [S1, unofficial]. The method is used in neural rendering pipelines to optimize 3D shapes from 2D images [S1, unofficial].
