# Raycasting with Irregular Grid Interpolation

Also called: Adaptive Grid Raycasting, TSDF Zero-Level Set Extraction

## Overview
This method extends SDF ray marching to handle hierarchical voxel grids with varying resolutions [S1]. It solves the problem of evaluating the Signed Distance Function (SDF) at arbitrary points near boundaries between different resolution levels, where standard tri-linear interpolation is invalid [S1]. It sets itself apart from its parent by replacing the uniform interpolation kernel with a local polynomial fit derived from a linear system, ensuring continuity across resolution boundaries [S1].

## How it works
**Inputs:**
*   Camera pose $(R, t)$ and intrinsic calibration $K$ [S1].
*   Hierarchical TSDF grid composed of voxel blocks with potentially different resolutions [S1].
*   Pre-computed depth range map: for each pixel, the minimum and maximum depth values derived from projecting the bounding boxes of observed voxel blocks into the image [S1].

**Outputs:**
*   A map of 3D points and surface normals (and optionally surface colors) corresponding to the zero-level set $F(X) = 0$ [S1].

**Data Structures:**
*   **Depth Range Map:** A 2D array mapping pixel coordinates $(u, v)$ to a depth interval $[d_{min}, d_{max}]$ [S1].
*   **Voxel Block:** Internal grid data layout and storage format are not given in the sources [S1].

**Algorithm:**

1.  **Pre-computation:** Project the bounding boxes of all observed voxel blocks into the image plane [S1]. For each pixel, determine the plausible depth range $[d_{min}, d_{max}]$ by filling these projections with appropriate minimum and maximum depth values [S1].
2.  **Ray Casting Loop:** For each pixel $(u, v)$, construct the ray origin and direction from the camera model $(R, t, K)$ [G]. Initialize the ray step range using the pre-computed $[d_{min}, d_{max}]$ for this pixel [S1]. Perform ray marching steps along the line of sight to find the point $X$ where $F(X) = 0$ [S1].
3.  **SDF Evaluation $F(X)$:** At each ray marching step, evaluate the SDF at the current 3D point $X = (X, Y, Z)$ by identifying the 8 surrounding grid points (corners of the voxel cube containing $X$) [S1]. Check if any two of these 8 surrounding grid points reside in different resolution levels (i.e., different voxel blocks) [S1]. If all 8 points reside in the same resolution level, use standard tri-linear interpolation by accumulating values from the 8 surrounding grid points weighted by linear interpolation coefficients [S1]. If points span different resolutions, use the irregular interpolation function defined below [S1].
4.  **Irregular Grid Interpolation:** When the 8 surrounding points span different resolutions, solve for the interpolating function coefficients [S1]. The function is defined as:
    $$ F(X, Y, Z) = a_1 XYZ + a_2 XY + a_3 YZ + a_4 XZ + a_5 X + a_6 Y + a_7 Z + a_8 $$
    Each of the 8 surrounding grid points $(X_i, Y_i, Z_i)$ with known SDF values $F(X_i, Y_i, Z_i)$ provides one equation [S1]. This results in the linear system:
    $$ \mathbf{A} \begin{pmatrix} a_1 \\ \vdots \\ a_8 \end{pmatrix} = \begin{pmatrix} F(X_1, Y_1, Z_1) \\ \vdots \\ F(X_8, Y_8, Z_8) \end{pmatrix} $$
    The matrix $\mathbf{A}$ is constructed such that row $i$ is:
    $$ [X_i Y_i Z_i, \ X_i Y_i, \ Y_i Z_i, \ X_i Z_i, \ X_i, \ Y_i, \ Z_i, \ 1] $$
    To solve this system efficiently:
    a. Arbitrarily shift the coordinate system of the points such that the first point becomes the origin ($X_1 = 0$) [S1].
    b. This trivially solves for $a_8$ (the constant term) [S1].
    c. Solve the remaining inhomogeneous $7 \times 7$ system for $a_1, \dots, a_7$ using Gaussian elimination [S1].
    d. Evaluate $F(X, Y, Z)$ using the solved coefficients [S1].
5.  **Termination:** The exact termination tolerance and maximum step count are not given in the sources [S1]. The method iterates along the line of sight within the pre-computed depth range to find the zero-level set [S1].

**Pseudocode:**

```python
def tri_linear_interpolate(points_8, values_8, query):
    # Assumes points_8 form a unit cube with points_8[0] as the minimum corner
    x0, y0, z0 = points_8[0]
    fx = query[0] - x0
    fy = query[1] - y0
    fz = query[2] - z0
    w000 = (1-fx)*(1-fy)*(1-fz)
    w100 = fx*(1-fy)*(1-fz)
    w010 = (1-fx)*fy*(1-fz)
    w110 = fx*fy*(1-fz)
    w001 = (1-fx)*(1-fy)*fz
    w101 = fx*(1-fy)*fz
    w011 = (1-fx)*fy*fz
    w111 = fx*fy*fz
    return (w000*values_8[0] + w100*values_8[1] + w010*values_8[2] + w110*values_8[3] +
            w001*values_8[4] + w101*values_8[5] + w011*values_8[6] + w111*values_8[7])

def gaussian_elimination(A, b):
    # Solves Ax = b for square A using Gaussian elimination with partial pivoting
    n = len(A)
    M = [A[i][:] + [b[i]] for i in range(n)]
    for i in range(n):
        max_row = i
        for k in range(i+1, n):
            if abs(M[k][i]) > abs(M[max_row][i]):
                max_row = k
        M[i], M[max_row] = M[max_row], M[i]
        pivot = M[i][i]
        if abs(pivot) < 1e-12:
            continue
        for k in range(i+1, n):
            factor = M[k][i] / pivot
            for j in range(i, n+1):
                M[k][j] -= factor * M[i][j]
    x = [0.0] * n
    for i in range(n-1, -1, -1):
        x[i] = M[i][n]
        for j in range(i+1, n):
            x[i] -= M[i][j] * x[j]
        x[i] /= M[i][i]
    return x

def evaluate_sdf_irregular(points_8, values_8, query_point):
    # Shift coordinates so the first point is at the origin
    origin = points_8[0]
    shifted_points = [(p[0]-origin[0], p[1]-origin[1], p[2]-origin[2]) for p in points_8]
    shifted_query = (query_point[0]-origin[0], query_point[1]-origin[1], query_point[2]-origin[2])

    # a8 is the value at the origin (first point)
    a8 = values_8[0]

    # Build 7x7 system for a1..a7 using points 1..7 (indices 1 to 7)
    A = []
    b = []
    for i in range(1, 8):
        x, y, z = shifted_points[i]
        row = [x*y*z, x*y, y*z, x*z, x, y, z]
        A.append(row)
        b.append(values_8[i] - a8)

    # Solve for coefficients a1..a7
    coeffs = gaussian_elimination(A, b)

    # Evaluate polynomial at shifted query point
    qx, qy, qz = shifted_query
    result = (coeffs[0]*qx*qy*qz + coeffs[1]*qx*qy + coeffs[2]*qy*qz +
              coeffs[3]*qx*qz + coeffs[4]*qx + coeffs[5]*qy + coeffs[6]*qz + a8)
    return result

def raycast_pixel(u, v, camera, grid, depth_map):
    ray_origin, ray_direction = camera.get_ray(u, v)
    d_min, d_max = depth_map[u, v]
    t = d_min
    step = 0.01  # Not given in sources [G]
    epsilon = 1e-4  # Not given in sources [G]
    while t < d_max:
        X = (ray_origin[0] + t*ray_direction[0],
             ray_origin[1] + t*ray_direction[1],
             ray_origin[2] + t*ray_direction[2])
        points_8, values_8 = grid.get_surrounding_points(X)
        if grid.is_irregular(points_8):
            F = evaluate_sdf_irregular(points_8, values_8, X)
        else:
            F = tri_linear_interpolate(points_8, values_8, X)
        if abs(F) < epsilon:
            # Normal computation method is not given in the sources [G]
            return X, (0.0, 0.0, 0.0)
        t += step
    return None
```

**Parameters:**
*   **Epsilon:** Threshold for zero-level set detection. Not given in the sources. [S1]
*   **Step Size:** Not given in the sources. [S1]

**Edge Cases and Pitfalls:**
*   **Cost:** Irregular grid interpolation is computationally expensive due to the linear system solution [S1].
*   **Optimization:** A simple check must be performed to ensure irregular interpolation is only used when at least two of the 8 surrounding grid points reside in different resolution levels [S1].
*   **Numerical Stability:** Details regarding the numerical stability of the $7 \times 7$ Gaussian elimination are not given in the sources. [S1]

## Operating characteristics
*   **Time Complexity:** Not given in the sources. [S1]
*   **Memory Complexity:** Not given in the sources. [S1]
*   **Performance:** The method is implemented on GPU using CUDA [S1]. The cost of irregular interpolation is mitigated by the check to ensure it is only performed at resolution boundaries [S1].
*   **Strengths:** Handles hierarchical grids with varying resolutions seamlessly, maintaining accuracy at boundaries [S1].
*   **Limitations:** Higher computational cost at resolution boundaries compared to uniform grids [S1].
*   **When to use:** When using hierarchical TSDF representations with multiple resolution levels [S1].
*   **When not to use:** For uniform grids where tri-linear interpolation suffices [S1].

## Background
The method originates from the work on Hierarchical Voxel Block Hashing for Efficient Integration of Depth Images [S1]. It was developed to support online ICP tracking and TSDF integration in a hierarchical representation, allowing for efficient storage and processing of large-scale 3D data [S1]. The source code is available at http://infinitam.org [S1].
