# Adaptive Step Size Calculation

Also called: Cone-angle based step size, Step Size Calculation, Step Size Determination, Step Size Heuristic

## Overview
Adaptive Step Size Calculation determines the distance between samples during ray marching by varying the step size based on the ray's position and a cone angle parameter [S1, unofficial]. It differs from standard constant step ray marching by dynamically adjusting the step size rather than using a fixed value [S1, unofficial].

## How it works
**Inputs and Outputs:**
- Input: Current ray time $t$, cone angle $\alpha$, minimum step size $dt_{min}$, maximum step size $dt_{max}$.
- Output: Step size $dt$.

**Data Structures:**
Not given in the sources. [G]

**Steps:**
1. Compute the raw step size by multiplying the current ray time by the cone angle [S1, unofficial].
2. Clamp the result to the range $[dt_{min}, dt_{max}]$ [S1, unofficial].

**Formula:**
The step size is calculated as:
$$ dt = \text{clamp}(t \cdot \alpha, dt_{min}, dt_{max}) $$
Where:
- $t$: Current ray time [S1, unofficial].
- $\alpha$: Cone angle for volume rendering [S1, unofficial].
- $dt_{min}$: Minimum step size [S1, unofficial].
- $dt_{max}$: Maximum step size [S1, unofficial].

**Parameters:**
- $dt_{min}$: Not given in the sources. [G]
- $dt_{max}$: Not given in the sources. [G]
- $\alpha$: Not given in the sources. [G]

**Pseudocode:**
```python
def calculate_adaptive_step_size(t: float, cone_angle: float, dt_min: float, dt_max: float) -> float:
    """
    Calculate adaptive step size based on cone angle heuristic.
    
    Args:
        t: Current ray time/distance.
        cone_angle: Cone angle for volume rendering.
        dt_min: Minimum step size.
        dt_max: Maximum step size.
        
    Returns:
        Clamped step size.
    """
    raw_step = t * cone_angle
    step_size = max(dt_min, min(dt_max, raw_step))
    return step_size
```

**Edge Cases and Pitfalls:**
- If $t=0$, the step size becomes 0, which may cause infinite loops or degenerate behavior. A guard should ensure $t > 0$ or use a minimum step size [G].
- Precision issues may arise if $t \cdot \alpha$ is very small or very large relative to floating-point limits [G].

## Subtopics

### [Ray Marching with Adaptive Step Count and Cone Sampling](4808-ray-marching-with-adaptive-step-count-and-cone-sampling.md)
Renders volumetric clouds by adaptively selecting the number of ray march steps based on the viewing angle and using cone sampling to approximate light transport within the volume. It balances rendering performance and visual quality by using fewer steps for top-down views and more steps for horizon views. It differs from standard constant step ray marching by varying the step count dynamically and from sibling methods by using a fixed kernel of 6 offset vectors rotated towards the light source for density estimation along the light path. Choose it when rendering volumetric clouds where viewing angle significantly impacts visual quality and performance. [G]

### [Adaptive Ray Marching with Temporal Reprojection](4840-adaptive-ray-marching-with-temporal-reprojection.md)
Performs volume rendering by combining adaptive ray marching with temporal accumulation to reduce noise and flickering in animated scenes. It builds on [Adaptive Step Size Calculation](4671-adaptive-step-size-calculation.md) by using density thresholds to vary step size, and extends standard ray marching by reprojection of the previous frame's color and alpha into the current frame's screen space. It is distinct from sibling methods like [Ray Marching with Adaptive Step Count and Cone Sampling](4808-ray-marching-with-adaptive-step-count-and-cone-sampling.md) by relying on spatial reprojection rather than cone-based filtering for temporal stability [G]. Choose it when rendering animated volumetric scenes requiring temporal stability and noise reduction. [G]
