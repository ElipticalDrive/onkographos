# Adaptive Step Size Calculation

Also called: Cone-angle based step size, Step Size Calculation, Step Size Determination, Step Size Heuristic

## Overview
Adaptive Step Size Calculation determines the distance between samples during ray marching by varying the step size based on the ray's position and the viewing geometry, specifically using a cone angle heuristic to balance rendering speed and accuracy [S1, unofficial]. It differs from standard constant step ray marching by dynamically adjusting the step count based on the cone angle, and from sibling methods like [Dartmouth Distance Sampling](7211-dartmouth-distance-sampling.md) by relying on a fixed cone-angle heuristic rather than distance field derivatives or specific sampling distributions [S1, unofficial].

## How it works
**Inputs and Outputs:**
- Input: Current ray time/position $t$, cone angle $\alpha$, minimum step size $dt_{min}$, maximum step size $dt_{max}$.
- Output: Step size $dt$.

**Data Structures:**
No specific data structures are required beyond scalar variables for the parameters.

**Steps:**
1. Calculate the adaptive step size $dt$ using the cone angle heuristic.
2. Clamp the result to the range $[dt_{min}, dt_{max}]$.

**Formula:**
The step size is calculated as:
$$ dt = \text{clamp}(t \cdot \alpha, dt_{min}, dt_{max}) $$
Where:
- $t$: Current ray time (distance along the ray) [S1, unofficial].
- $\alpha$: Cone angle for volume rendering [S1, unofficial].
- $dt_{min}$: Minimum allowed step size [S1, unofficial].
- $dt_{max}$: Maximum allowed step size [S1, unofficial].

**Parameters:**
- $dt_{min}$: Not given in the sources.
- $dt_{max}$: Not given in the sources.
- $\alpha$: Not given in the sources.

**Pseudocode:**
```python
def calculate_adaptive_step_size(t: float, cone_angle: float, dt_min: float, dt_max: float) -> float:
    """
    Calculate adaptive step size based on cone angle heuristic.
    
    Args:
        t: Current ray time/distance.
        cone_angle: Cone angle for volume rendering.
        dt_min: Minimum step size.
        dt_max: Maximum step size.
        
    Returns:
        Clamped step size.
    """
    # Calculate raw step size based on cone angle heuristic
    raw_step = t * cone_angle
    
    # Clamp to allowed range
    step_size = max(dt_min, min(dt_max, raw_step))
    
    return step_size
```

**Edge Cases and Pitfalls:**
- If $t=0$, the step size becomes 0, which may cause infinite loops or degenerate behavior. A guard should ensure $t > 0$ or use a minimum step size [G].
- Precision issues may arise if $t \cdot \alpha$ is very small or very large relative to floating-point limits.

## Subtopics

### [Ray Marching with Adaptive Step Count and Cone Sampling](4808-ray-marching-with-adaptive-step-count-and-cone-sampling.md)
Renders volumetric clouds by adaptively selecting the number of ray march steps based on the viewing angle and using cone sampling to approximate light transport within the volume. It balances rendering performance and visual quality by using fewer steps for top-down views and more steps for horizon views, while cone sampling mitigates artifacts from single-sample lighting. It differs from standard constant step ray marching by varying the step count dynamically and from sibling methods by using a fixed kernel of 6 offset vectors rotated towards the light source for density estimation along the light path.

### [Adaptive Ray Marching with Temporal Reprojection](4840-adaptive-ray-marching-with-temporal-reprojection.md)
Performs volume rendering by combining adaptive ray marching with temporal accumulation to reduce noise and flickering in animated scenes. It builds on [Adaptive Step Size Calculation](4671-adaptive-step-size-calculation.md) by using density thresholds to vary step size, and extends standard ray marching by reprojection of the previous frame's color and alpha into the current frame's screen space. It is distinct from sibling methods like [Ray Marching with Adaptive Step Count and Cone Sampling](4808-ray-marching-with-adaptive-step-count-and-cone-sampling.md) by relying on spatial reprojection rather than cone-based filtering for temporal stability [G].

## Operating characteristics
**Time and Memory Complexity:**
The calculation is $O(1)$ in time and memory, as it involves simple arithmetic operations on scalar values.

**Measured Performance:**

**Strengths and Limitations:**
- Strengths: Dynamically adjusts step size based on viewing geometry, potentially improving performance for certain viewing angles [S1, unofficial].
- Limitations: Relies on a heuristic that may not be optimal for all scenes or volume types. The cone angle parameter needs careful tuning [S1, unofficial].

**When to Use:**
Use when rendering volumetric scenes where viewing angle significantly impacts visual quality and performance, such as volumetric clouds [S1, unofficial].

**When Not to Use:**
Avoid when high precision is required regardless of viewing angle, or when the cone angle heuristic does not accurately represent the volume's structure.
