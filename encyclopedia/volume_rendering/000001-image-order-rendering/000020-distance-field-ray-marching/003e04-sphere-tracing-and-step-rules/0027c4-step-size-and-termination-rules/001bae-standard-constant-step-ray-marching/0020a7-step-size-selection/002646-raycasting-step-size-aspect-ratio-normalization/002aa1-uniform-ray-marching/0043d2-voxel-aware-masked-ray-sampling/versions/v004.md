# Voxel-Aware Masked Ray Sampling

Also called: NSVF Hierarchical Ray Sampling with Voxel-Aware Masking, NSVF parallel ray sampling, NSVF voxel intersection sampling

## Overview
Voxel-Aware Masked Ray Sampling is a ray sampling strategy for sparse voxel fields that samples points only within intersected voxels, handling variable numbers of intersections per ray by padding and masking [S1, unofficial]. It differs from standard NeRF uniform or stratified sampling by using probability proportional to distance within valid voxel intervals, and from dense volume rendering by eliminating computation in empty space through explicit ray-voxel intersection tests [S1, unofficial]. It builds on [Uniform Ray Marching](4810-uniform-ray-marching.md) by restricting sampling to allocated sparse voxels.

## How it works
**Inputs:**
- `rays`: Ray origins and directions (batched).
- `voxel_field`: Sparse voxel structure providing intersection data.
- `max_hits`: Maximum number of voxel intersections per ray (default 60) [S1, unofficial].
- `chunk_size`: Number of rays processed in parallel before padding (default 4096) [S1, unofficial].
- `fixed_num_samples`: If > 0, constant number of samples; otherwise derived from step size [S1, unofficial].
- `step_size`: Base step size for raymarching (default 0.01) [S1, unofficial].
- `fine_num_sample_ratio`: Ratio of samples for the fine pass compared to the coarse pass (default 0) [S1, unofficial].
- `inverse_distance_coarse_sampling`: Controls non-uniform sampling ('none', 'camera', 'origin') [S1, unofficial].
- `bg_color`: Background color for missed rays [S1, unofficial].
- `BG_DEPTH`: Background depth value (default 5.0) [S1, unofficial].

**Outputs:**
- `sampled_dists`: Distances along the ray for each sample point.
- `sampled_idx`: Voxel indices for each sample point.
- `sampled_depth`: Depth values for each sample point.
- `missed`: Boolean mask indicating rays that hit no voxels.
- `colors`, `depths`: Compositing results for valid rays.

**Data Structures:**
- `intersection_outputs`: Dictionary containing:
  - `min_depth`: Tensor of minimum depths for each ray-voxel intersection interval.
  - `max_depth`: Tensor of maximum depths for each ray-voxel intersection interval.
  - `intersected_voxel_idx`: Tensor of voxel indices for each interval.
  - `probs`: Tensor of sampling probabilities for each interval.
  - `steps`: Tensor of number of samples to draw from each interval.
- `all_results`: Dictionary containing:
  - `missed`: Tensor of size `(full_size,)` indicating missed rays.
  - `colors`: Tensor of size `(full_size, 3)` for RGB colors.
  - `depths`: Tensor of size `(full_size,)` for depths.
  - `normal`: Optional tensor of size `(full_size, 3)`.
  - `voxel_depth`: Optional tensor of size `(full_size,)`.
  - `voxel_edges`: Optional tensor of size `(full_size, 3)`.
  - `feat_n2`: Optional tensor of size `(full_size,)`.

**Steps:**

1. **Parallel Chunking:** If the total number of rays `full_size` exceeds `chunk_size`, split the input into chunks of size `chunk_size`. Process each chunk with the core sampling logic, then pad the results to a uniform shape. Padding uses `maxlen` (maximum length among chunks), filling `sampled_idx` with -1, `sampled_depth` with `MAX_DEPTH`, and `sampled_dists` with 0.0 [S1, unofficial].

2. **Intersection Data Preparation:** For each ray, obtain `min_depth`, `max_depth`, and `intersected_voxel_idx` from the voxel field. Calculate distances between `min_depth` and `max_depth`. Mask out invalid voxels (where `pts_idx == -1`) by setting their distance to 0.0 [S1, unofficial].

3. **Probability Calculation:** Compute probabilities for sampling steps by normalizing the distances by their sum along the last dimension:
   $$
   \text{probs} = \frac{\text{dists}}{\sum \text{dists}}
   $$
   where `dists` is the masked distance tensor [S1, unofficial].

4. **Step Count Determination:**
   - If `fixed_num_samples > 0`, set `steps` to a constant tensor of value `fixed_num_samples`.
   - Otherwise, set `steps` to:
     $$
     \text{steps} = \frac{\sum \text{dists}}{\text{step\_size}}
     $$
   - If hierarchical sampling is enabled (`fine_num_sample_ratio > 0`), update `steps` for the fine pass to be the count of valid voxel indices multiplied by the ratio:
     $$
     \text{steps} = (\text{sampled\_point\_voxel\_idx} \neq -1).sum(-1).float() \times \text{fine\_num\_sample\_ratio}
     $$
     [S1, unofficial].

5. **Sampling and Gathering:** Sample points along the ray based on `steps` and `probs`. Gather `sampled_dists` and `sampled_idx` using ordered indices. Fill masked positions (rays that hit `MAX_DEPTH` or have no intersections) with 0.0 for distances and -1 for indices [S1, unofficial].

6. **Truncation:** Identify rays that hit the maximum depth boundary by comparing `sampled_depth` to `MAX_DEPTH`:
   $$
   \text{sampled\_masks} = (\text{sampled\_depth} == \text{MAX\_DEPTH})
   $$
   Calculate the maximum number of valid steps across all rays:
   $$
   \text{num\_max\_steps} = \max_{\text{rays}} (\sim \text{sampled\_masks}).sum(-1)
   $$
   Truncate `sampled_depth`, `sampled_dists`, and `sampled_idx` to `num_max_steps` [S1, unofficial].

7. **Postprocessing:** Fill missed rays with background values:
   $$
   \text{missed} = \text{fill\_in}((\text{fullsize}), \text{hits}, \text{all\_results}['\text{missed}'], 1.0)
   $$
   $$
   \text{colors} = \text{fill\_in}((\text{fullsize}, 3), \text{hits}, \text{all\_results}['\text{colors}'], 0.0)
   $$
   $$
   \text{depths} = \text{fill\_in}((\text{fullsize}), \text{hits}, \text{all\_results}['\text{depths}'], 0.0)
   $$
   Add background contribution:
   $$
   \text{colors} += \text{missed.unsqueeze}(-1) \times \text{bg\_color}
   $$
   $$
   \text{depths} += \text{missed} \times \text{BG\_DEPTH}
   $$
   [S1, unofficial].

    Core sampling logic for a chunk of rays.

    # Mask invalid voxels
    dists = (max_depth - min_depth).clone()

        steps = torch.full_like(dists, fixed_num_samples)
    else:
        steps = dists.sum(dim=-1) / step_size

    # to sample indices from probs, then interpolate dists.
    
    # For the purpose of the article, we assume this returns:
    # sampled_dists, sampled_idx, sampled_depth
    # where sampled_depth is the depth of the last sample or MAX_DEPTH if truncated
    
    sampled_dists = torch.zeros_like(dists) # Placeholder
    sampled_idx = torch.full_like(intersected_voxel_idx, -1, dtype=torch.long)
    sampled_depth = torch.full_like(dists, float('inf'))
    
    # Simulate sampling
    for i in range(rays.shape[0]):
        num_samples = int(steps[i].item())
        if num_samples > 0:
            # Sample indices from probs
            sample_indices = torch.multinomial(probs[i], num_samples, replacement=True)
            # Interpolate dists

            sampled_dists[i, :num_samples] = dists[i, sample_indices]
            sampled_idx[i, :num_samples] = intersected_voxel_idx[i, sample_indices]
            sampled_depth[i, :num_samples] = dists[i, sample_indices] # Depth is approximated by dist

    return sampled_dists, sampled_idx, sampled_depth, torch.zeros(rays.shape[0], dtype=torch.bool), torch.zeros(rays.shape[0], 3), torch.zeros(rays.shape[0])

## Subtopics

### [Sparse Voxel-based Sampling and Rendering](16760-sparse-voxel-based-sampling-and-rendering.md)
A rendering pipeline that dynamically allocates voxels only where objects and surfaces exist, restricting ray marching and volume integration to occupied regions. It differs from dense volume rendering by eliminating computation in empty space, and from uniform ray marching by requiring explicit ray-voxel intersection tests to determine traversal order. It builds on [Voxel-Aware Masked Ray Sampling](11092-voxel-aware-masked-ray-sampling.md) by adding the constraint that sampling is strictly limited to allocated sparse voxels.

## Operating characteristics
- **Time Complexity:** Depends on the number of voxel intersections per ray. With sparse voxels, this is typically much lower than dense volume rendering. The parallel chunking strategy allows for efficient GPU utilization.
- **Memory Complexity:** Proportional to the number of rays and the maximum number of hits per ray (`max_hits`). Padding to `max_hits` can lead to memory inefficiency if rays have significantly fewer intersections.
- **Performance:** Efficient for scenes with sparse geometry. Performance degrades if rays intersect many voxels or if `max_hits` is set too high.
- **Strengths:** Eliminates computation in empty space, supports hierarchical sampling, handles variable intersection counts.
- **Limitations:** Requires explicit ray-voxel intersection tests, padding can waste memory, background handling must be correct to avoid NaNs.
- **When to use:** Sparse voxel fields, scenes with large empty regions, hierarchical rendering.
- **When not to use:** Dense volumes, scenes with many small objects causing many intersections, hardware without support for dynamic padding/masking.

## Background
Voxel-Aware Masked Ray Sampling is part of the NSVF (Neural Sparse Voxel Fields) framework developed by Facebook Research [S1, unofficial]. It was introduced to enable efficient rendering of large-scale scenes using sparse voxel representations, addressing the inefficiency of uniform sampling in empty space.
