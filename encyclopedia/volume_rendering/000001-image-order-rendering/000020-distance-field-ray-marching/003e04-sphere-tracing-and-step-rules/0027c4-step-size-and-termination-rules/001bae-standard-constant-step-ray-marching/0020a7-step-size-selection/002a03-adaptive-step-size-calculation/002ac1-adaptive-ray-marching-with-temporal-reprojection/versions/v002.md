# Adaptive Ray Marching with Temporal Reprojection

Also called: HZL Fluid Effects Studio volume renderer, field mode shading

## Overview
This method performs volume rendering by combining adaptive ray marching with temporal accumulation to reduce noise and flickering in animated scenes [S1, unofficial]. It builds on [Adaptive Step Size Calculation](4671-adaptive-step-size-calculation.md) by using density thresholds to vary step size, and extends standard ray marching by reprojection of the previous frame's color and alpha into the current frame's screen space [S1, unofficial]. It is distinct from sibling methods like [Ray Marching with Adaptive Step Count and Cone Sampling](4808-ray-marching-with-adaptive-step-count-and-cone-sampling.md) by relying on spatial reprojection rather than cone-based filtering for temporal stability [G].

## How it works
**Inputs:**
- Ray origin and direction [S1, unofficial].
- Volume density field (accessed via ray marching) [S1, unofficial].
- `stepSize`: Base step length for ray marching through the volume [S1, unofficial].
- `densityScale`: Scaling factor applied to density in the opacity calculation [S1, unofficial].
- `absorption`: Absorption coefficient multiplier used in the opacity exponent [S1, unofficial].
- `adaptiveSteppingEnabled`: Boolean flag that doubles the step size (multiplies by 4.0) when density falls below 0.004 [S1, unofficial].
- `historyTexture`: Previous frame's accumulated color and alpha buffer [S1, unofficial].
- `historyWeight`: Base weight for temporal history blending, modulated by alpha difference [S1, unofficial].
- `emittedLight`: Emissive contribution per unit step [S1, unofficial].
- `smokeColor`: Base color of the volume [S1, unofficial].
- `fieldMode`: Integer switch (0-7) controlling the smoke color mapping logic via conditional branches [S1, unofficial].

**Outputs:**
- Final accumulated color (`accumulated.rgb`) and alpha (`accumulated.a`) [S1, unofficial].

**Data Structures:**
- `accumulated`: A vector or struct holding `rgb` (float3) and `a` (float). Initialized to zero [S1, unofficial].
- `history`: Sampled from `historyTexture` at reprojected UV coordinates. Holds `rgb` and `a` [S1, unofficial].
- `representativePosition`: World or view space position of the current ray step, used for reprojection [S1, unofficial].

**Parameters:**
- `stepSize`: Base step length [S1, unofficial].
- `densityScale`: Scaling factor [S1, unofficial].
- `absorption`: Absorption multiplier [S1, unofficial].
- `adaptiveSteppingEnabled`: Boolean [S1, unofficial].
- `historyWeight`: Base blend weight [S1, unofficial].
- `emissionStrength`: Multiplier for emitted light (used in `emittedLight` calculation) [S1, unofficial].
- `fieldMode`: Integer (0-7) [S1, unofficial].

**Steps:**
1. Initialize `accumulated.rgb` and `accumulated.a` to zero [S1, unofficial].
2. Loop through ray steps:
   a. Compute `currentStep`. If `adaptiveSteppingEnabled` is true and current `density < 0.004`, set `currentStep = stepSize * 4.0` [S1, unofficial]. Otherwise, `currentStep = stepSize` [S1, unofficial].
   b. Calculate opacity:
      $$opacity = 1.0 - \exp(-density \cdot densityScale \cdot currentStep \cdot absorption \cdot 4.0)$$ [S1, unofficial].
   c. Update accumulated color:
      $$accumulated.rgb \leftarrow accumulated.rgb + (1.0 - accumulated.a) \cdot (opacity \cdot smokeColor + emittedLight \cdot currentStep)$$ [S1, unofficial].
   d. Update accumulated alpha:
      $$accumulated.a \leftarrow accumulated.a + (1.0 - accumulated.a) \cdot opacity$$ [S1, unofficial].
   e. If `accumulated.a > 0.985`, break the loop [S1, unofficial].
   f. Increment `distanceAlongRay` by `currentStep` [S1, unofficial].
3. If `accumulated.a < 0.002`, discard the fragment (do not write to color buffer) [S1, unofficial].
4. If `temporalEnabled` is true and `foundVolume` is true:
   a. Project `representativePosition` to previous clip space [S1, unofficial].
   b. Compute UV coordinates from previous clip space [S1, unofficial].
   c. Clamp UV to `[0.0, 1.0]` [S1, unofficial].
   d. Sample `historyTexture` at clamped UV to get `history` [S1, unofficial].
   e. Compute `responsiveWeight`:
      $$responsiveWeight = historyWeight \cdot (1.0 - |history.a - accumulated.a|)$$ [S1, unofficial].
   f. Blend:
      $$accumulated = mix(accumulated, history, clamp(responsiveWeight, 0.0, 0.95))$$ [S1, unofficial].

**Pseudocode:**
```python
def adaptive_ray_marching_with_temporal_reprojection(ray_origin, ray_direction, volume_sampler, history_texture, camera_state, params):
    # Initialize accumulation
    accumulated_rgb = vec3(0.0)
    accumulated_a = 0.0
    
    # Parameters
    step_size = params.stepSize
    density_scale = params.densityScale
    absorption = params.absorption
    adaptive_enabled = params.adaptiveSteppingEnabled
    history_weight = params.historyWeight
    emitted_light = params.emittedLight
    smoke_color = params.smokeColor
    field_mode = params.fieldMode
    
    # Temporal reprojection state
    temporal_enabled = params.temporalEnabled
    found_volume = False
    
    # Ray marching loop
    distance_along_ray = 0.0
    while True:
        # Get density at current position
        ray_position = ray_origin + ray_direction * distance_along_ray
        density = volume_sampler.sample(ray_position)
        
        # Adaptive step size
        if adaptive_enabled and density < 0.004:
            current_step = step_size * 4.0
        else:
            current_step = step_size
            
        # Opacity calculation
        opacity = 1.0 - exp(-density * density_scale * current_step * absorption * 4.0)
        
        # Color accumulation
        accumulated_rgb += (1.0 - accumulated_a) * (opacity * smoke_color + emitted_light * current_step)
        
        # Alpha accumulation
        accumulated_a += (1.0 - accumulated_a) * opacity
        
        # Termination
        if accumulated_a > 0.985:
            found_volume = True
            break
            
        distance_along_ray += current_step
        
        # [G] Max step limit not given in sources; implementation requires a loop bound or distance threshold.
        
    # Discard transparent fragments
    if accumulated_a < 0.002:
        return None
        
    # Temporal reprojection
    if temporal_enabled and found_volume:
        # Project representative position to previous frame's clip space
        prev_clip_pos = camera_state.previous_view_projection @ ray_position
        
        # Compute UV
        if prev_clip_pos.w > 0.0:
            prev_uv = vec2(prev_clip_pos.x / prev_clip_pos.w, prev_clip_pos.y / prev_clip_pos.w)
            prev_uv = vec2(clamp(prev_uv.x, 0.0, 1.0), clamp(prev_uv.y, 0.0, 1.0))
            
            # Sample history
            history = history_texture.sample(prev_uv)
            
            # Responsive weight
            responsive_weight = history_weight * (1.0 - abs(history.a - accumulated_a))
            
            # Blend
            blend_factor = clamp(responsive_weight, 0.0, 0.95)
            accumulated_rgb = mix(accumulated_rgb, history.rgb, blend_factor)
            accumulated_a = mix(accumulated_a, history.a, blend_factor)
            
    return vec4(accumulated_rgb, accumulated_a)
```

**Edge Cases and Pitfalls:**
- **Temporal Reprojection Bounds:** If the previous frame projection has `w <= 0.0`, the UV calculation is invalid [S1, unofficial]. Clamp UV to `[0.0, 1.0]` to avoid sampling outside bounds [S1, unofficial].
- **Ghosting:** Mitigated by scaling `historyWeight` with `(1.0 - abs(history.a - accumulated.a))` and clamping the blend factor to `[0.0, 0.95]` [S1, unofficial].
- **Transparent Pixels:** Fragments with final opacity below `0.002` are discarded to avoid rendering transparent pixels [S1, unofficial].
- **Field Mode:** The `fieldMode` parameter (0-7) controls smoke color mapping logic via conditional branches, but the specific logic is not detailed in the sources [S1, unofficial].
