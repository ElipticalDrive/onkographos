# Adaptive Step Size Calculation

Also called: Cone-angle based step size, Step Size Calculation

## Overview
Adaptive Step Size Calculation determines the distance between samples during ray marching by scaling the current ray time with a cone angle parameter and clamping the result [S1, unofficial]. It solves the problem of balancing rendering speed and visual quality by dynamically adjusting step size based on ray progress and viewing geometry [G]. It differs from standard constant step ray marching by varying the step size dynamically, and from sibling methods like [Raycasting Step Size & Aspect Ratio Normalization](3734-raycasting-step-size-aspect-ratio-normalization.md) by relying on a cone-angle heuristic rather than aspect ratio normalization for step determination [S1, G, unofficial].

## How it works
**Inputs and Outputs:**
- Input: `t` (current ray time), `cone_angle` (cone angle for volume rendering), `dt_min` (minimum step size), `dt_max` (maximum step size) [S1, unofficial].
- Output: `dt` (the calculated step size for the current sample) [S1, unofficial].

**Data Structures:**
The method operates on scalar values; no complex data structures are required [G].

**Steps:**
1. Calculate the raw step size by multiplying the current ray time `t` by the `cone_angle` [S1, unofficial].
2. Clamp the result to the range `[dt_min, dt_max]` to prevent steps that are too small or too large [S1, unofficial].

**Formula:**
$$ dt = \text{clamp}(t \times \text{cone\_angle}, dt\_min, dt\_max) $$

Where:
- $t$: Current ray time [S1, unofficial].
- $\text{cone\_angle}$: Cone angle for volume rendering [S1, unofficial].
- $dt\_min$: Minimum step size [S1, unofficial].
- $dt\_max$: Maximum step size [S1, unofficial].

**Pseudocode:**
```python
def calculate_adaptive_step_size(t, cone_angle, dt_min, dt_max):
    raw_step = t * cone_angle
    step_size = max(dt_min, min(raw_step, dt_max))
    return step_size
```

**Parameters:**
Not given in the sources.

**Edge Cases and Pitfalls:**
If `t` or `cone_angle` is zero, the raw step size becomes zero and is clamped to `dt_min` [G]. Precision issues may arise if `t` is very large or very small, but clamping mitigates extreme values [G].

## Subtopics

### [Ray Marching with Adaptive Step Count and Cone Sampling](4808-ray-marching-with-adaptive-step-count-and-cone-sampling.md)
This method performs volume rendering of volumetric clouds by adaptively selecting the number of ray march steps based on the viewing angle and using cone sampling to approximate light transport within the volume. It solves the problem of balancing rendering performance and visual quality in real-time atmospheric clouds, where top-down views require fewer steps than horizon views, and single-sample lighting causes banding artifacts. It differs from standard constant step ray marching by varying the step count dynamically and from sibling methods by using a fixed kernel of 6 offset vectors rotated towards the light source for density estimation along the light path.

### [Adaptive Ray Marching with Temporal Reprojection](4840-adaptive-ray-marching-with-temporal-reprojection.md)
This method performs volume rendering by combining adaptive ray marching with temporal accumulation to reduce noise and flickering in animated scenes. It builds on [Adaptive Step Size Calculation](4671-adaptive-step-size-calculation.md) by using density thresholds to vary step size, and extends standard ray marching by reprojection of the previous frame's color and alpha into the current frame's screen space. It is distinct from sibling methods like [Ray Marching with Adaptive Step Count and Cone Sampling](4808-ray-marching-with-adaptive-step-count-and-cone-sampling.md) by relying on spatial reprojection rather than cone-based filtering for temporal stability [G].

## Operating characteristics
Time and memory complexity are $O(1)$ per sample, as the method performs a constant number of arithmetic operations [G]. Measured performance, scaling behavior, strengths, limitations, and usage recommendations are not given in the sources [S1, unofficial].
