# FBM Sphere Tracing with BVH Acceleration

Also called: High-level view algorithm of how step size is computed during the FBM loop, Procedural FBM Sphere Tracing

## Overview
This method accelerates the sphere tracing of isosurfaces defined by Fractal Brownian Motion (FBM) noise by computing valid Sphere Distance Bounds (SDB) and adaptive step sizes using a dynamic Bounding Volume Hierarchy (BVH) derived from the FBM structure itself [S1]. It progressively evaluates octaves while bounding the remaining potential contribution to determine if the total function value can exceed the isosurface threshold, using an Early Stop threshold parameter $k$ to limit octave evaluations [S1]. Unlike naive sphere tracing which evaluates the full FBM at every step, this approach supports features like Adaptive Lipschitz constants, Sub-stepping, Early Stop+k, and Quadratic Taylor inclusion functions [S1].

## How it works
The algorithm computes a step size and the final FBM value by iterating through the octaves of the noise function [S1]. It maintains a running sum of the FBM value ($F$), the derivative along the ray ($dF$), and the accumulated step size [S1]. At each octave, it constructs a bounding volume for the remaining octaves to determine if further evaluation is necessary or if a larger step can be taken [S1].

**Inputs:**
*   $\mathbf{p}$: Current 3D position [S1].
*   $n$: Total number of octaves in the FBM sum [S1].
*   $v(\cdot)$: Threshold function (hypertexture), typically approximated by its 1st order affine Taylor polynomial [S1].
*   $\mathbf{u}$: Normalized ray direction vector [S1].
*   $k$: Early Stop threshold parameter [S1].
*   $\lambda_{noise}, \gamma_{noise}$: Lipschitz constants for the base noise function (e.g., Perlin noise) [S1].

**Outputs:**
*   $F$: Final FBM value [S1].
*   $step$: Computed step size for the ray march [S1].

**Data Structures:**
*   $F$: Scalar, accumulated FBM value [S1].
*   $dF$: Scalar, accumulated derivative along the ray direction [S1].
*   $step$: Scalar, accumulated step size [S1].
*   $BVH$: Scalar bounding volume representing the maximum possible contribution of remaining octaves [S1].
*   $inclFuncParams$: Tuple $(BVH, \lambda, dF, \gamma)$ passed to the intersection function [S1].

**Parameters:**
*   $n$: Typical value 20 (as used in Sponge scene tests) [S1].
*   $k$: Typical values tested: 0, 1, 2, 3 [S1].
*   $\lambda, \gamma$: Global Lipschitz constants initialized as $\lambda_{Fn}$ and $\gamma_{Fn}$ [S1].

**Algorithm Steps:**
1.  **Initialization**: Set $F \leftarrow 0$, $dF \leftarrow 0$, $step \leftarrow 0$. Set global Lipschitz constants $\lambda \leftarrow \lambda_{Fn}$ and $\gamma \leftarrow \gamma_{Fn}$ [S1].
2.  **Loop**: For each octave $i$ from 1 to $n$:
    a.  **Accumulate Value**: Add the current octave value to the sum: $F \leftarrow F + o_i(\mathbf{p})$ [S1].
    b.  **Accumulate Derivative**: Add the derivative of the current octave along the ray direction: $dF \leftarrow dF + (\mathbf{u} \cdot o'_i(\mathbf{p}))$ [S1].
    c.  **Compute BVH**: Calculate the bounding volume for the remaining octaves: $BVH \leftarrow F + s(i+1, n)$, where $s(i+1, n)$ is the sum of the maximum possible contributions of octaves $i+1$ to $n$ [S1].
    d.  **Determine Step Computation**: Check if step size computation is required. It is true if it is the last octave ($i == n$) OR if the ray is outside the bounding volume ($BVH - v(0) < 0$) [S1].
    e.  **Compute Step Size**: If step computation is required:
        i.  **Adaptive Lipschitz**: Replace global constants with local values for the current octave: $\lambda \leftarrow \lambda_{Fi}$, $\gamma \leftarrow \gamma_{Fi}$ [S1].
        ii. **Prepare Parameters**: Set $inclFuncParams \leftarrow (BVH, \lambda, dF, \gamma)$ [S1].
        iii. **Intersect**: Compute the current step size: $curr\_step \leftarrow intersect(inclFuncParams, v)$ [S1].
        iv. **Accumulate Step**: $step \leftarrow step + curr\_step$ [S1].
        v.  **Sub-stepping Guard**: Enforce minimum step size: $step \leftarrow \max(step, curr\_step)$ [S1].
    f.  **Sub-stepping**: Move ray position: $\mathbf{p} \leftarrow \mathbf{p} + \mathbf{u} \cdot curr\_step$ [S1]. Update sum: $F \leftarrow v(curr\_step)$ [S1]. Update threshold: $v \leftarrow v$ at $curr\_step$ [S1]. Update derivative: $dF \leftarrow dF + \gamma \cdot curr\_step$ [S1]. Clamp derivative: $dF \leftarrow \max(dF, \lambda)$ [S1].
    g.  **Early Stop+k**: Decrement $k$. If $k < 0$, break the loop [S1].
3.  **Return**: Return final $F$ and $step$ [S1].

**Pseudocode:**
```python
def fbm_sphere_tracing(p, n, v_func, u, k, lambda_noise, gamma_noise):
    """
    Computes FBM value and step size using BVH acceleration.
    This function implements the FBM evaluation loop that returns a valid SDB step size.
    
    Args:
        p: Current 3D position (vec3)
        n: Number of octaves (int)
        v_func: Threshold function (callable), approximated by 1st order Taylor polynomial [S1]
        u: Ray direction (vec3, normalized)
        k: Early stop threshold (int)
        lambda_noise: Global Lipschitz constant for noise (float)
        gamma_noise: Global gamma constant for noise (float)
        
    Returns:
        F: Final FBM value (float)
        step: Computed step size (float)
    """
    F = 0.0
    dF = 0.0
    step = 0.0
    
    # Global Lipschitz constants
    lambda_val = lambda_noise
    gamma_val = gamma_noise
    
    for i in range(1, n + 1):
        # Evaluate current octave and its derivative along the ray
        octave_val = evaluate_octave(i, p)
        octave_deriv = evaluate_octave_derivative(i, p)
        
        F += octave_val
        dF += dot(u, octave_deriv)
        
        # Compute Bounding Volume for remaining octaves
        remaining_sum = sum_remaining_octave_bounds(i + 1, n)
        BVH = F + remaining_sum
        
        # Determine if step size computation is required
        comp_step = (i == n) or (BVH - v_func(0) < 0)
        
        if comp_step:
            # Adaptive Lipschitz: use local constants for current octave
            lambda_val = get_local_lipschitz(i)
            gamma_val = get_local_gamma(i)
            
            # Compute current step size via inclusion function intersection
            curr_step = compute_step_intersection(BVH, lambda_val, dF, gamma_val, v_func)
            
            # Accumulate step size
            step += curr_step
            step = max(step, curr_step)  # Enforce minimum step size
            
            # Sub-stepping: advance ray and update state
            p = p + u * curr_step
            F = v_func(curr_step)
            v_at_step = v_func(curr_step)
            dF += gamma_val * curr_step
            dF = max(dF, lambda_val)
            
            # Early Stop+k
            k -= 1
            if k < 0:
                break
                
    return F, step

def evaluate_octave(i, p):
    """Returns the value of the i-th FBM octave at position p."""
    # Standard FBM octave evaluation (e.g., Perlin noise scaled by amplitude)
    return noise(i, p)

def evaluate_octave_derivative(i, p):
    """Returns the gradient of the i-th FBM octave at position p."""
    return gradient_noise(i, p)

def sum_remaining_octave_bounds(i, n):
    """Returns the sum of maximum amplitudes for octaves i to n."""
    return sum(amplitude(j) for j in range(i, n + 1))

def get_local_lipschitz(i):
    """Returns the local Lipschitz constant for octave i."""
    return lambda_noise * amplitude(i)

def get_local_gamma(i):
    """Returns the local gamma constant for octave i."""
    return gamma_noise * amplitude(i)

def compute_step_intersection(BVH, lambda_val, dF, gamma_val, v_func):
    """
    Computes the step size where the inclusion function crosses the threshold.
    Uses a linear approximation: BVH + dF * step = v(0).
    """
    if dF <= 0:
        return float('inf')  # Safe fallback when derivative is non-positive
    curr_step = (v_func(0) - BVH) / dF
    return max(0.0, curr_step)
```

**Edge Cases and Pitfalls:**
*   **Thread Divergence**: The FBM sum loop may exit earlier for some threads than others due to Early Stop [S1]. However, rays from the same warp are spatially coherent, so divergence is typically limited to a single octave [S1].
*   **GPU Memory Usage**: The method avoids $O(n)$ per-thread data storage required by dynamic re-ordering methods, making it more suitable for fast GPU implementation [S1].
*   **Threshold Approximation**: The threshold function $v(\mathbf{p})$ is approximated by its 1st order (affine) Taylor polynomial [S1]. Higher order threshold functions were not implemented as the approximation showed no noticeable error in tested scenes [S1].
*   **Noise Parameters**: The algorithm requires $\lambda_{noise}$ and $\gamma_{noise}$ for arbitrary noise functions [S1]. Default values depend on the noise type (e.g., Perlin noise with or without absolute value) [S1].

### [FBM Sphere Tracing with Implicit BVH](1901-fbm-sphere-tracing-with-implicit-bvh.md)
This method accelerates the sphere tracing of isosurfaces defined by Fractal Brownian Motion (FBM) noise by treating the cascaded sum of octaves as a dynamic, implicit Bounding Volume Hierarchy (BVH). It progressively evaluates octaves while bounding the remaining potential contribution to determine if the total function value can exceed the isosurface threshold, allowing for early termination and empty space skipping. Unlike naive sphere tracing which evaluates the full FBM at every step, this approach reduces the average evaluation cost by progressively evaluating octaves while bounding the remaining potential contribution to determine if the total function value can exceed the isosurface threshold, using an Early Stop threshold parameter $k$ to limit octave evaluations. It builds on [FBM Sphere Tracing with BVH Acceleration](1728-fbm-sphere-tracing-with-bvh-acceleration.md) by replacing the explicit spatial tree with a procedural hierarchy derived from the FBM structure itself.

## Operating characteristics
*   **Time Complexity**: The method reduces the average number of octaves computed per ray significantly [S1]. In the Sponge scene (close view), Early Stop reduced average octaves from 49,596.3 to 24,252.6, achieving a 1.9x speedup [S1]. In the far view, it reduced octaves from 56,577.8 to 10,347.0, achieving a 4.7x speedup [S1].
*   **Memory Complexity**: The method avoids $O(n)$ per-thread data storage, making it memory-efficient for GPU implementation compared to dynamic re-ordering methods [S1].
*   **Performance**: On an Nvidia RTX 4080 Ti at 1024×1024 resolution:
    *   Adaptive Lipschitz reduced average steps from 428.1 to 331.7 (1.3x speedup) in the Sponge scene [S1].
    *   Sub-stepping reduced average steps from 331.7 to 265.2 (1.2x speedup) over Adaptive Lipschitz alone in the Sponge scene [S1].
    *   Early Stop+k=1 reduced average octaves to 3,815.0 and time to 65.0ms (1.1x speedup over ES only) in the Sponge scene [S1].
*   **Strengths**: Significant reduction in the number of octaves computed per ray, especially in empty space. Low memory overhead. Suitable for GPU implementation [S1].
*   **Limitations**: Dynamic re-ordering [WH96] could yield slightly smaller step sizes, but the BVH approach has much lower performance overhead (no memory requirement or sorting), resulting in better overall GPU performance [S1].
*   **When to Use**: Rendering large, detailed procedural volumetric noise scenes where the cost of evaluating noise dominates [S1].
*   **When Not to Use**: Scenes where dynamic re-ordering is feasible and memory is not a constraint, and maximum step size optimality is critical over GPU performance [S1].

## Background
The method was introduced in the paper "Fast sphere tracing of procedural volumetric noise for very large and detailed scenes" [S1]. It was implemented in GLSL fragment shaders and tested on scenes such as the "Sponge" scene, which consists of a 20-octave FBM of Perlin noise [S1]. The paper highlights the importance of GPU efficiency, noting that thread divergence is limited due to spatial coherence of rays within a warp [S1]. The method avoids the need for external object data, making it fully procedural [S1].
