# Soft Shadows via Cone Tracing

Also called: Cone Tracing for Soft Shadows, Cone-based Shadowing, Scattering approximation via cones, Soft Shadows via Shadow Cones

## Overview
Soft shadows via cone tracing approximate soft shadow boundaries and light scattering by casting a cone $\Psi$ from a surface point towards the light source instead of a single ray [S2, unofficial]. Unlike standard shadow rays that only measure binary occlusion, this method aggregates extinction values within the cone to estimate both occlusion and scattered light, producing visually plausible soft shadow borders [S2, unofficial]. It is distinguished from its sibling [Cone Tracing](5679-cone-tracing.md) by its specific application to light transport in participating media, where the cone aperture controls the softness and scattering range [S1, unofficial].

## How it works
**Inputs and Outputs:**
*   **Inputs:** Surface point $x$, light direction, light intensity $I_L$, extinction coefficient field $\tau(t)$, and cone aperture angle [S1, S2, unofficial].
*   **Outputs:** Shadowed and scattered lighting term $I_{Sh}(s)$ [S2, unofficial].

**Data Structures:**
*   **Cone $\Psi$:** Defined by origin $x$, direction (light vector), and aperture angle. The cone diameter grows linearly with distance from the origin [S2, unofficial].
*   **Extinction Field:** Discretized volume data (voxels) containing extinction coefficients $\tau(t)$ [S2, unofficial].

**Parameters:**
*   **Aperture Angle:** Controls the trade-off between scattering range and influence magnitude. Narrow cones (e.g., 1°) approximate forward scattering with limited range and strong influence, while wide cones (e.g., 25°) approximate isotropic scattering with broad range and reduced individual voxel influence [S2, unofficial]. Tested values include 1°, 5°, 10°, and 25° [S1, unofficial].

**Formulas:**
The shadowed and scattered lighting term $I_{Sh}(s)$ is calculated as [S2, unofficial]:
$$
I_{Sh}(s) \approx I_L \cdot e^{-\int_{t_{Sh}} h(t) \tau(t) dt}
$$
Where:
*   $I_{Sh}(s)$: Shadowed and scattered lighting term.
*   $I_L$: Incoming light intensity.
*   $t_{Sh}$: Path within the cone $\Psi$.
*   $\tau(t)$: Extinction coefficient at distance $t$.
*   $h(t)$: Weighting function, defined as the inverse of the aggregate query size $V_q^{-1}$ [S2, unofficial].

At each step, the local occlusion value $\alpha_2$ is accumulated to update the ambient occlusion term $\delta$ using a decay function $f(r)$ controlled by a user-defined rate $\lambda$ [S1, unofficial]:
$$
\delta = \delta + (1-\delta)\alpha_2 f(r)
$$

**Steps:**
1. Initialize accumulated occlusion $\delta = 0$ and integral accumulator $S = 0$ at surface point $x$ [S1, S2, unofficial].
2. March along the light direction in discrete steps $\Delta t$, expanding the cone $\Psi$ according to the aperture angle [S2, unofficial].
3. At each step $t$, compute the cone cross-sectional area $A(t) = \pi (t \tan(\theta/2))^2$, where $\theta$ is the aperture angle [G].
4. Query the extinction coefficient $\tau(t)$ within the cone cross-section and aggregate it into a local occlusion value $\alpha_2$ [S1, S2, unofficial].
5. Compute the weighting function $h(t) = 1 / A(t)$ (or $1/V_q$ for volume queries) to account for the growing query size, which causes influence to decrease rapidly with distance [S2, unofficial].
6. Update the ambient occlusion term: $\delta \leftarrow \delta + (1-\delta)\alpha_2 e^{-\lambda t}$ [S1, unofficial].
7. Accumulate the weighted extinction for the final lighting integral: $S \leftarrow S + h(t) \tau(t) \Delta t$ [S2, unofficial].
8. Compute the final shadowed and scattered lighting term: $I_{Sh}(s) = I_L \cdot e^{-S}$ [S2, unofficial].

**Pseudocode:**
```python
import math

def compute_soft_shadow_cone_tracing(surface_point, light_direction, light_intensity, extinction_field, aperture_angle, decay_rate, step_size, max_distance):
    """
    Computes soft shadows and scattering using cone tracing.
    """
    delta = 0.0
    integral_sum = 0.0
    half_angle = aperture_angle / 2.0
    tan_half = math.tan(half_angle)

    t = 0.0
    while t < max_distance:
        cone_radius = t * tan_half
        current_pos = scale_vector(light_direction, t) + surface_point

        # Aggregate extinction within the cone cross-section to get local occlusion alpha_2
        alpha_2 = aggregate_cone_extinction(current_pos, light_direction, cone_radius, extinction_field)

        # Weighting function h(t) = 1 / V_q. Scales by inverse cross-sectional area.
        cone_area = math.pi * (cone_radius ** 2)
        h_t = 1.0 / max(cone_area, 1e-6)

        # Update ambient occlusion term delta
        decay = math.exp(-decay_rate * t)
        delta = delta + (1.0 - delta) * alpha_2 * decay

        # Accumulate weighted extinction for the final lighting integral
        tau_t = sample_extinction(current_pos, extinction_field)
        integral_sum += h_t * tau_t * step_size

        t += step_size

    # Final shadowed and scattered lighting term
    I_Sh = light_intensity * math.exp(-integral_sum)
    return I_Sh

def scale_vector(v, s):
    return [v[0]*s, v[1]*s, v[2]*s]

def aggregate_cone_extinction(origin, direction, radius, extinction_field):
    # Samples voxels within the cone cross-section and returns normalized occlusion alpha_2
    total = 0.0
    samples = 8
    for i in range(samples):
        angle = 2.0 * math.pi * i / samples
        offset = radius * 0.5
        perp1 = get_perpendicular(direction)
        perp2 = cross(direction, perp1)
        pos = origin + scale_vector(perp1, offset * math.cos(angle)) + scale_vector(perp2, offset * math.sin(angle))
        total += sample_extinction(pos, extinction_field)
    return min(1.0, total / samples)

def get_perpendicular(v):
    # Returns a vector perpendicular to v
    if abs(v[0]) < 0.9:
        return cross(v, [1, 0, 0])
    else:
        return cross(v, [0, 1, 0])

def cross(a, b):
    return [a[1]*b[2]-a[2]*b[1], a[2]*b[0]-a[0]*b[2], a[0]*b[1]-a[1]*b[0]]

def sample_extinction(pos, extinction_field):
    # Returns tau(t) at position pos via standard volume texture lookup [G]
    return extinction_field.sample(pos)
```

**Edge Cases and Pitfalls:**
*   **Homogeneous Media Assumption:** The method assumes the scattering function $R$ is constant for all directions and scattering is proportional to extinction [S2, unofficial]. This works well for homogeneous media like smoke or wax-like materials but may fail for heterogeneous media without separate transfer functions [S2, unofficial].
*   **Cone Angle Selection:** A narrow cone may miss scattered light from wide angles, while a wide cone may dilute the signal from individual voxels [S2, unofficial].
*   **Precision:** The weighting function $h(t)$ decreases rapidly as the cone grows, which may lead to underflow or loss of precision for distant occluders [S2, unofficial].

## Operating characteristics
*   **Performance:** Shadow computation using cones is 40% faster than classical shadow rays (0.0079s vs. 0.0132s) [S2, unofficial].
*   **Memory:** Requires storage for the extinction field and potentially normal/albedo textures if used in a deferred shading context [S1, unofficial].
*   **Complexity:** Time complexity scales linearly with the number of cone steps and sampling density per step. Memory complexity is dominated by the voxel grid resolution. Not given in the sources.
*   **Strengths:** Fast approximation for soft shadows and light scattering; produces visually plausible soft shadow borders; integrates scattering into the shadow term [S2, unofficial].
*   **Limitations:** Approximation may not accurately model complex scattering in heterogeneous media; requires careful tuning of cone aperture [S2, unofficial].

## Background
*   **Origin:** The method is based on the concept of cone tracing, an extension of sphere tracing for SDF rendering [Parent]. The specific application to soft shadows and scattering in volume rendering was proposed in [S2, unofficial].
*   **History:** Cone tracing was originally introduced for SDF rendering [Parent]. The adaptation for soft shadows in voxel-based global illumination was explored in [S1, unofficial] and [S2, unofficial].
*   **Usage:** Used in real-time global illumination systems, particularly those using voxel cone tracing for indirect lighting [S1, unofficial].
