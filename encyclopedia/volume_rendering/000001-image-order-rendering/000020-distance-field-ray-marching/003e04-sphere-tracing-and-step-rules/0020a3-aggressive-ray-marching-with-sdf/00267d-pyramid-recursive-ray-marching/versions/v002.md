# Pyramid Recursive Ray Marching

Also called: Depth Rendering Pipeline, trivial

## Overview
Pyramid Recursive Ray Marching is a multi-scale acceleration technique for Signed Distance Field (SDF) ray marching that initializes depth estimates at low resolution and recursively refines them at higher resolutions [S1, unofficial]. It distinguishes itself from standard aggressive ray marching by decoupling the coarse initialization phase from the fine-grained recursive refinement, allowing for larger initial steps in empty space while maintaining precision near surfaces [S1, unofficial].

## How it works
**Inputs:**
- Latent code vector $z \in \mathbb{R}^d$ [G].
- Camera pose defined by intrinsic matrix $K$ and extrinsic matrix $RT$ [G].
- Image resolution $(H, W)$ [S1, unofficial].
- Parameters: `march_step` (total steps), `ray_marching_ratio` (step scaling factor), `threshold` (SDF surface threshold), `clamp_dist` (distance clamping, default 0.1) [S1, unofficial], `split_type` ('depth' or 'raydepth') [S1, unofficial], `sample_index_type` ('min_abs', default) [S1, unofficial].

**Outputs:**
- Rendered depth map $Z \in \mathbb{R}^{H \times W}$ [S1, unofficial].
- Valid mask $M \in \{0, 1\}^{H \times W}$ [S1, unofficial].
- Minimum SDF sample per ray for differentiability [S1, unofficial].
- Points and SDF values along the ray [S1, unofficial].

**Data Structures:**
- `scale_list`: List of resolutions from lowest to highest [S1, unofficial].
- `rays_list`: List of ray origins and directions for each scale [S1, unofficial].
- `grid_maps`: List of SDF values sampled at each scale [S1, unofficial].
- `index_maps`: Mapping indices for upsampling from lower to higher resolution [S1, unofficial].
- `recalib_maps`: Recalibration factors for ray direction/origin adjustments [S1, unofficial].

**Algorithm Steps:**

1.  **Initialization:**
    - Compute camera rays for the target resolution $(H, W)$ [G].
    - Calculate initial intersection with unit spheres to determine `init_zdepth` and a preliminary `valid_mask` [S1, unofficial].
    - Initialize `min_sdf_sample_new` tensor with zeros and enable gradients [S1, unofficial].

2.  **Scale Pyramid Construction:**
    - Initialize scale lists and step lists. If `march_step_list[-1] == -1`, set it to `march_step - sum(march_step_list[:-1])` [S1, unofficial].
    - Generate a list of downscaled grid maps, rays, index maps, recalib maps, and valid masks for each scale in `scale_list` in reversed order (coarsest to finest) [S1, unofficial].
    - For scales other than the original ($idx > 0$), compute downscaled grid maps and rays using `get_downscaled_camera_rays` [S1, unofficial].
    - Calculate the valid mask for the current scale by max-pooling the previous scale's valid mask using `maxpool_valid_mask_with_index` [S1, unofficial].

3.  **Coarse-to-Fine Marching Loop:**
    - Iterate through scales from largest (lowest resolution) to smallest (original resolution) [S1, unofficial].
    - For non-final scales ($idx > 0$), perform single-scale ray marching using `ray_marching_trivial` [S1, unofficial].
    - Unmap the results from the valid mask indices to full image dimensions using `unmap_tensor_with_valid_mask` [S1, unofficial].
    - Upsample the SDF, points, and z-depth to the next higher resolution using the `index_map` and `recalib_map` [S1, unofficial].
    - For the final scale ($idx == 0$), perform recursive ray marching using `ray_marching_recursive` [S1, unofficial].
    - Concatenate the final scale results with the upsampled results from previous scales, filtering by the valid mask [S1, unofficial].

4.  **Differentiable Sample Selection:**
    - Get differentiable samples by finding the minimum SDF sample [S1, unofficial].
    - Copy `min_sdf_sample` values to `min_sdf_sample_new` at valid mask indices [S1, unofficial].
    - For invalid mask indices, set `min_sdf_sample_new` to $dist + threshold - radius$ to handle camera gradients [S1, unofficial].

5.  **Depth Computation:**
    - Compute source z-depth as `init_zdepth` at valid mask plus `marching_zdepth` [S1, unofficial].
    - Copy `src_zdepth` to $Z$ at valid mask indices and reshape to $(H, W)$ [S1, unofficial].
    - Update `valid_mask` using `valid_mask_render` [S1, unofficial].
    - If `no_grad_depth` is true, detach $Z$ from the computation graph [S1, unofficial].

**Pseudocode:**

```python
def pyramid_recursive_ray_marching(latent_code, K, RT, H, W, march_step, threshold, clamp_dist=0.1, split_type='depth', sample_index_type='min_abs', no_grad_depth=False, radius=1.0):
    # 1. Initialization
    rays = compute_camera_rays(K, RT, H, W)
    init_zdepth, valid_mask = compute_initial_sphere_intersection(rays)
    min_sdf_sample_new = [[0.0 for _ in range(W)] for _ in range(H)]

    # 2. Scale Pyramid Construction
    scale_list = generate_scale_list(H, W, march_step)
    march_step_list = [march_step // (2**i) for i in range(len(scale_list))]
    if march_step_list[-1] == -1:
        march_step_list[-1] = march_step - sum(march_step_list[:-1])

    rays_list, grid_maps, index_maps, recalib_maps, valid_masks = [], [], [], [], []
    for i, scale in enumerate(reversed(scale_list)):
        if i == 0:
            current_rays = get_downscaled_camera_rays(rays, scale)
            current_grid = sample_sdf_grid(latent_code, current_rays, scale)
            current_valid = compute_valid_mask(current_rays)
        else:
            current_rays = get_downscaled_camera_rays(rays, scale)
            current_grid = sample_sdf_grid(latent_code, current_rays, scale)
            current_valid = maxpool_valid_mask_with_index(valid_masks[-1], index_maps[-1])
        rays_list.append(current_rays)
        grid_maps.append(current_grid)
        valid_masks.append(current_valid)
        index_maps.append(generate_index_map(scale, scale_list[-(i-1)] if i > 0 else None))
        recalib_maps.append(generate_recalib_map(split_type, current_rays))

    # 3. Coarse-to-Fine Marching Loop
    upsampled_sdf, upsampled_zdepth, upsampled_points = None, None, None
    for idx in range(len(scale_list)):
        current_rays, current_grid, current_valid = rays_list[idx], grid_maps[idx], valid_masks[idx]
        if idx < len(scale_list) - 1:
            sdf_list, zdepth_list, points_list = ray_marching_trivial(current_rays, current_grid, march_step_list[idx], threshold, clamp_dist)
            sdf_full = unmap_tensor_with_valid_mask(sdf_list, current_valid, H, W)
            zdepth_full = unmap_tensor_with_valid_mask(zdepth_list, current_valid, H, W)
            points_full = unmap_tensor_with_valid_mask(points_list, current_valid, H, W)
            next_idx = idx + 1
            upsampled_sdf = upsample_tensor(sdf_full, index_maps[next_idx], recalib_maps[next_idx])
            upsampled_zdepth = upsample_tensor(zdepth_full, index_maps[next_idx], recalib_maps[next_idx])
            upsampled_points = upsample_tensor(points_full, index_maps[next_idx], recalib_maps[next_idx])
        else:
            sdf_list, zdepth_list, points_list = ray_marching_recursive(current_rays, current_grid, march_step_list[idx], threshold, clamp_dist, init_zdepth=upsampled_zdepth, sdf_init=upsampled_sdf)
            final_sdf = concatenate_with_upsampled(sdf_list, upsampled_sdf, current_valid)
            final_zdepth = concatenate_with_upsampled(zdepth_list, upsampled_zdepth, current_valid)
            final_points = concatenate_with_upsampled(points_list, upsampled_points, current_valid)

    # 4. Differentiable Sample Selection
    min_sdf = find_min_sdf(final_sdf, sample_index_type)
    for y in range(H):
        for x in range(W):
            if current_valid[y][x] == 1:
                min_sdf_sample_new[y][x] = min_sdf[y][x]
            else:
                dist = compute_ray_length(rays[y][x])
                min_sdf_sample_new[y][x] = dist + threshold - radius

    # 5. Depth Computation
    src_zdepth = [[0.0 for _ in range(W)] for _ in range(H)]
    for y in range(H):
        for x in range(W):
            if current_valid[y][x] == 1:
                src_zdepth[y][x] = init_zdepth[y][x] + final_zdepth[y][x]
    Z = [src_zdepth[y][x] for y in range(H) for x in range(W)]
    valid_mask = valid_mask_render(final_sdf, threshold)
    if no_grad_depth:
        Z = Z.detach() # Conceptual detachment for autograd frameworks

    return Z, valid_mask, min_sdf_sample_new, final_points
```

**Edge Cases and Pitfalls:**
- **Precision:** Upsampling artifacts may occur if index maps are not accurately computed [G].
- **Boundaries:** Invalid mask indices must be handled explicitly to prevent NaN gradients during backpropagation [S1, unofficial].
- **Degenerate Input:** If `march_step_list[-1] == -1`, it must be set to `march_step - sum(march_step_list[:-1])` to ensure total steps are preserved [S1, unofficial].

## Background
Pyramid Recursive Ray Marching is part of the DIST-Renderer project, an unofficial implementation of DeepSDF rendering techniques [S1, unofficial]. It was developed to address the computational cost of high-resolution SDF rendering by leveraging multi-scale processing [S1, unofficial]. The method is used in the context of neural implicit surface representation and differentiable rendering [S1, unofficial].
