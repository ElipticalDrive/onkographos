# Unbiased Estimation of Transmitted Lighting

Also called: Fermat's Principle Path Tracing, Two-Point Tracing for Caustics

## Overview
A path tracing technique to estimate transmitted caustics by finding direct paths between a receptor point and a light source using Fermat's principle, handling both refractive interfaces and heterogeneous media [S1]. Unlike Manifold Walk which handles surface deformations, this method characterizes curved light paths inside heterogeneous material, allowing unified estimation of surface and volume induced caustics [S1].

## How it works
**Inputs:**
*   Receptor point $\mathbf{x}_0$ (camera pixel origin).
*   Light source point $\mathbf{x}_n$ (or area light integration).
*   $n-1$ intermediate points $\mathbf{x}_i$ lying on refractive interfaces defined by Signed Distance Functions (SDFs) $g_i$ [S1].
*   Refractive Index Function (RIF) $\eta(\mathbf{x})$ [S1].

**Outputs:**
*   Valid optical path connecting $\mathbf{x}_0$ to $\mathbf{x}_n$ satisfying Fermat's principle [S1].

**Data Structures:**
*   **RIF Representation:** The RIF $\eta(\mathbf{x})$ is often approximated within a single cell (e.g., tetrahedron or voxel) such that $\eta^2(\mathbf{x})$ has a constant gradient. Specifically:
    $$ \eta^2(\mathbf{x}) = A_0 + A_1 \mathbf{x}_x + A_2 \mathbf{x}_y + A_3 \mathbf{x}_z = A_0 + \boldsymbol{\gamma} \cdot \mathbf{x} \quad (3) $$
    where $\boldsymbol{\gamma} = \nabla \eta^2(\mathbf{x})$ is constant [S1].
*   **Bubble Obstacles:** Bubbles are represented as opaque obstacles to limit complexity. The RIF resolution must be a multiple of the bubble voxel grid resolution to guarantee no intersection with a bubble is missed while stepping through the tetrahedron [S1].

**Step-by-Step Method:**
1.  **Formulate Optical Path Length (OPL):** Define the OPL between $n+1$ points as the sum of integrals along straight-line segments between consecutive points:
    $$ L(\mathbf{x}_0, \dots, \mathbf{x}_n) = \sum_{k=0}^{n-1} L_k = \sum_{k=0}^{n-1} \int_{\mathbf{x}_k}^{\mathbf{x}_{k+1}} \eta \, ds \quad (1) $$
    [S1]
2.  **Apply Fermat's Principle:** Identify physical paths as curves $\Gamma: \mathbb{R} \to \mathbb{R}^3$ for which the variation of the OPL is zero:
    $$ dL = 0 \quad (12) $$
    This defines a variational problem where multiple specular paths connecting $\mathbf{x}_0$ and $\mathbf{x}_n$ are found by searching for all curves satisfying this condition [S1].
3.  **Solve for Ray Trajectory in Heterogeneous Media:** Within a cell where $\eta^2(\mathbf{x}) = A_0 + \boldsymbol{\gamma} \cdot \mathbf{x}$, the ray trajectory $\mathbf{x}(\tau)$ and momentum $\mathbf{p}(\tau)$ are second-order polynomials. The momentum is defined as $\|\mathbf{p}(\tau)\| = \eta(\mathbf{x}(\tau))$ [S1]. The analytical solutions are:
    $$ \mathbf{x}(\tau) = \frac{1}{4}\boldsymbol{\gamma} \tau^2 + \mathbf{p}_0\tau + \mathbf{x}_0 \quad (4) $$
    $$ \mathbf{p}(\tau) = \frac{1}{2}\boldsymbol{\gamma} \tau + \mathbf{p}_0 \quad (4) $$
    The equation $\|\mathbf{p}(\tau)\| = \eta(\mathbf{x}(\tau))$ only needs to be enforced at the starting point $\mathbf{x}_0 = \mathbf{x}(0)$ because the polynomial structure ensures it holds for other $\tau$ values given the constant gradient assumption [S1].
4.  **Iterative Path Finding:** Use an iterative approach to find the path coordinates. The method checks for convergence by comparing a loss function (related to the validity of the path) to zero, often using a smoothing function $s$ to approximate the discontinuity check [S1, S2].
5.  **Handle Interfaces:** For paths crossing $n-1$ interfaces defined by SDFs $g_i$, the intermediate points $\mathbf{x}_i$ are optimized such that they lie on the surfaces $g_i(\mathbf{x}_i) = 0$ while minimizing the total OPL [S1].

**Pitfalls:**
*   **Bubbles:** Bubbles are treated as opaque obstacles. If the RIF resolution is not a multiple of the bubble voxel grid resolution, intersections with bubbles may be missed during stepping [S1].
*   **Multiple Paths:** Multiple paths may connect two points; all must be found to ensure unbiasedness [S1].

## Subtopics

### Fermat-Path-Tracing
A path finding method that simulates any number of diffractions or reflections by minimizing according to Fermat’s principle [S2]. It minimizes the optical path length (Fermat's principle), as opposed to MPT which minimizes another cost function [S2]. It finds a path using an iterative approach and checks for convergence by comparing the MPT loss function to zero using a smoothing function $s$ [S2].

## Operating characteristics
*   **Complexity:** Not given in the sources.
*   **Performance:** Implemented in Mitsuba3 using the standard path tracing integrator with 1M samples per pixel [S1].
*   **Strengths:** Unified estimation of surface and volume induced caustics; handles heterogeneous materials with spatially varying RIF [S1].
*   **Limitations:** Bubbles are simplified as opaque obstacles, potentially missing complex internal reflections within bubbles [S1].

## Background
Originated in the context of rendering transparent glass objects with irregularities, such as hand-blown glass panels [S1]. The method builds on the principle that physical light paths are stationary points of the optical path length [S1]. It is implemented in the Mitsuba3 renderer [S1].
