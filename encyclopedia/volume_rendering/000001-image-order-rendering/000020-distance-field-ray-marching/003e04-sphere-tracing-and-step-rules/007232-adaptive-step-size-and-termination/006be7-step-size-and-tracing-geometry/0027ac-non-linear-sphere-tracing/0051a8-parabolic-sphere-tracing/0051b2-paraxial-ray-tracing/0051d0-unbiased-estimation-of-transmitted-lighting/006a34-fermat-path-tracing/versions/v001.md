# Fermat-Path-Tracing

Also called: Fermat's Principle Path Tracing, Two-Point Tracing for Caustics

## Overview
Fermat-Path-Tracing (FPT) is a path-finding method that simulates any number of diffractions or reflections by minimizing the optical path length according to Fermat’s principle [S1]. It is distinguished from Min-Path-Tracing (MPT) by its specific objective function, which minimizes optical path length rather than a generic cost function [S1]. It builds on [Unbiased Estimation of Transmitted Lighting](14564-unbiased-estimation-of-transmitted-lighting.md) by providing the specific optimization mechanism for transmitted caustics.

## How it works
**Inputs and Outputs:**
*   **Inputs:** Scene geometry (interfaces, media), source position, receptor position, and initial path parameters.
*   **Outputs:** A valid path connecting the source to the receptor satisfying physical constraints.

**Steps:**
1.  **Initialization:** Initialize path coordinates. In the approximation case, the transmitter $Tx$ may start at an initialization point with parameter $\alpha = 1$ [S1].
2.  **Iterative Optimization:** Find a path using an iterative approach [S1]. The method minimizes the optical path length (Fermat's principle) [S1].
3.  **Convergence Check:** Compare the loss function to zero using a smoothing function $s$ [S1]. The method uses the MPT loss function, which evaluates to zero when the path is valid [S1]. Comparison to zero is approximated with the smoothing function $s$ [S1].

## Subtopics

### Min-Path-Tracing
Min-Path-Tracing (MPT) is a path finding method that simulates any number and any type of interactions by minimizing a cost function [S1]. It differs from FPT by minimizing a generic cost function rather than specifically the optical path length [S1]. It uses the same iterative approach and convergence check via the MPT loss function and smoothing function $s$ [S1]. It is described in [10] (Eertmans et al., 2023) [S1].

## Background
Fermat-Path-Tracing is part of a framework for fully differentiable ray tracing via discontinuity smoothing for radio network optimization [S1]. It is implemented in the DiffeRT2d toolbox, which is available as an open-source Python module [S1]. The method is compatible with both 2D and 3D scenes [S1].
