# Screen-Space Ray Casting with Adaptive Step Size

Also called: In-scattered Radiance with Inverted Transmittance, PSRayCast

## Overview
Screen-Space Ray Casting with Adaptive Step Size is a pixel shader technique that renders volumetric scattering by casting rays from the camera through each pixel into a 3D texture, accumulating in-scattered radiance using an adaptive step size based on density changes and transmittance [S1, unofficial]. It distinguishes itself from fixed-step ray marching by dynamically adjusting the sampling interval to maintain visual fidelity in high-density regions while skipping empty space, and it operates entirely in screen space without requiring explicit geometry intersection beyond depth buffer occlusion [S1, unofficial].

## How it works
**Inputs and Outputs**
*   **Input:** Pixel shader input structure `PSIn` containing `Pos` (`float4`) and `UV` (`float2`) [S1, unofficial]. Global constants include `g_worldViewProjI` (inverse world-view-projection matrix), `g_eyePt` (eye position), `g_worldI` (inverse world matrix), `g_step` (initial step size), `g_numSamples` (maximum samples), `ZERO_THRESHOLD` (empty/occlusion threshold), `ABSORPTION` (accumulation constant), `g_hasLightProbes` (boolean), `g_roSHCoeffs` (light probe coefficients), and optionally a depth texture controlled by `_HAS_DEPTH_MAP_` [S1, unofficial].
*   **Output:** Accumulated in-scattered radiance `scatter` (`float4`) [S1, unofficial].

**Data Structures**
*   `PSIn`: `Pos` (`float4`, clip-space position), `UV` (`float2`, normalized texture coordinates) [S1, unofficial].
*   `shCoeffs`: Array of `SH_NUM_COEFF` spherical harmonic coefficients (size not specified) [S1, unofficial].

**Step-by-Step Method**

1.  **Ray Origin Calculation**: Convert screen UV to local space ray origin [S1, unofficial].
    *   Transform UV to clip space: `pos.xy = uv * 2.0 - 1.0; pos.zw = float2(0.0, 1.0);` [S1, unofficial]
    *   Flip Y axis: `pos.y = -pos.y;` [S1, unofficial]
    *   Transform to world space: `pos = mul(pos, g_worldViewProjI);` [S1, unofficial]
    *   Divide by W: `rayOrigin = pos.xyz / pos.w;` [S1, unofficial]

2.  **Ray Direction Calculation**:
    *   Transform eye position to local space: `localSpaceEyePt = mul(float4(g_eyePt, 1.0), g_worldI);` [S1, unofficial]
    *   Compute direction: `rayDir = normalize(rayOrigin - localSpaceEyePt);` [S1, unofficial]

3.  **Ray Validation**: Call `ComputeRayOrigin(rayOrigin, rayDir)`; if invalid, discard pixel [S1, unofficial].

4.  **Occlusion Culling (Optional)**: If `_HAS_DEPTH_MAP_` is enabled:
    *   Get depth value: `z = g_txDepth[idx];` [S1, unofficial]
    *   Convert UV to clip-space XY: `xy = uv * 2.0 - 1.0; xy.y = -xy.y;` [S1, unofficial]
    *   Create clip-space position: `clipPos = float3(xy, z);` [S1, unofficial]
    *   Calculate `tMax` using `GetTMax(pos, rayOrigin, rayDir)` to limit ray traversal distance [S1, unofficial].

5.  **Light Probe Loading**: If `g_hasLightProbes` is true and not in a light pass, load spherical harmonic coefficients: `LoadSH(shCoeffs, g_roSHCoeffs);` [S1, unofficial]

6.  **Initialization**:
    *   `scatter = 0.0` [S1, unofficial]
    *   `t = 0.0` (distance along ray) [S1, unofficial]
    *   `step = g_step` (current step size) [S1, unofficial]
    *   `prevDensity = 0.0` [S1, unofficial]

7.  **Ray Marching Loop**: Iterate `g_numSamples` times:
    *   **Position Update**: `pos = rayOrigin + rayDir * t;` [S1, unofficial]
    *   **Boundary Check**: If `any(abs(pos) > 1.0)`, break loop (volume is unit cube) [S1, unofficial].
    *   **Texture Coordinate Conversion**: `uvw = LocalToTex3DSpace(pos);` [S1, unofficial]
    *   **Volume Sampling**: `color = GetSample(uvw);` (Returns density in `.w` and color in `.xyz`) [S1, unofficial]
    *   **Empty Space Skip**: If `color.w <= ZERO_THRESHOLD`, continue to next iteration (skip lighting/accumulation) [S1, unofficial].
    *   **Lighting Calculation**:
        *   If point light: `lightDir = normalize(localSpaceLightPt - pos);` [S1, unofficial]
        *   Otherwise: Use precomputed `lightDir`. [S1, unofficial]
        *   Compute light intensity: `light = GetLight(pos, lightDir, shCoeffs);` [S1, unofficial]
    *   **Adaptive Step Size Update**:
        *   Compute transmittance: `transm = 1.0 - scatter.w;` [S1, unofficial]
        *   Compute density difference: `dDensity = color.w - prevDensity;` [S1, unofficial]
        *   Compute new step: `newStep = GetStep(dDensity, transm, color.w, g_step);` [S1, unofficial]
        *   Average step: `step = (step + newStep) * 0.5;` [S1, unofficial]
    *   **Accumulation**:
        *   If color is not pre-multiplied: `color.xyz *= color.w;` [S1, unofficial]
        *   Apply lighting: `color.xyz *= light;` [S1, unofficial]
        *   Add to scatter: `scatter += color * ABSORPTION * transm;` [S1, unofficial]
    *   **Termination Check**: If `transm < ZERO_THRESHOLD`, break loop [S1, unofficial].
    *   **Update State**: `prevDensity = color.w;` [G] (Required for next iteration's `dDensity` calculation)

8.  **Final Normalization**: `scatter.xyz /= 2.0 * PI;` [S1, unofficial]

**Pseudocode**

```python
def ScreenSpaceRayCast(uv, depth_texture, has_depth_map, has_light_probes,
                       world_view_proj_inv, eye_pos, world_inv,
                       initial_step, max_samples, zero_threshold, absorption,
                       sh_coeffs, light_probe_coeffs):
    # 1. Ray Origin
    pos = [uv[0] * 2.0 - 1.0, uv[1] * 2.0 - 1.0, 0.0, 1.0]
    pos[1] = -pos[1]
    pos = mul(pos, world_view_proj_inv)
    ray_origin = [pos[0] / pos[3], pos[1] / pos[3], pos[2] / pos[3]]

    # 2. Ray Direction
    local_eye = mul([eye_pos[0], eye_pos[1], eye_pos[2], 1.0], world_inv)
    ray_dir = normalize([ray_origin[0] - local_eye[0], ray_origin[1] - local_eye[1], ray_origin[2] - local_eye[2]])

    # 3. Validation
    if not ComputeRayOrigin(ray_origin, ray_dir):
        return [0.0, 0.0, 0.0, 0.0]

    # 4. Occlusion Culling
    t_max = float('inf')
    if has_depth_map:
        z = depth_texture.Sample(uv)
        xy = [uv[0] * 2.0 - 1.0, uv[1] * 2.0 - 1.0]
        xy[1] = -xy[1]
        clip_pos = [xy[0], xy[1], z]
        t_max = GetTMax(clip_pos, ray_origin, ray_dir)

    # 5. Light Probes
    sh_coeffs_loaded = None
    if has_light_probes:
        sh_coeffs_loaded = LoadSH(sh_coeffs, light_probe_coeffs)

    # 6. Initialization
    scatter = [0.0, 0.0, 0.0, 0.0]
    t = 0.0
    step = initial_step
    prev_density = 0.0

    # 7. Loop
    for _ in range(max_samples):
        pos = [ray_origin[0] + ray_dir[0] * t, ray_origin[1] + ray_dir[1] * t, ray_origin[2] + ray_dir[2] * t]

        if any(abs(p) > 1.0 for p in pos):
            break

        uvw = LocalToTex3DSpace(pos)
        color = GetSample(uvw)

        if color[3] <= zero_threshold:
            prev_density = color[3]
            t += step
            continue

        light_dir = [0.0, 0.0, 0.0]
        light = GetLight(pos, light_dir, sh_coeffs_loaded)

        transm = 1.0 - scatter[3]
        d_density = color[3] - prev_density
        new_step = GetStep(d_density, transm, color[3], initial_step)
        step = (step + new_step) * 0.5

        if not is_pre_multiplied(color):
            color[0] *= color[3]
            color[1] *= color[3]
            color[2] *= color[3]
        color[0] *= light
        color[1] *= light
        color[2] *= light
        scatter[0] += color[0] * absorption * transm
        scatter[1] += color[1] * absorption * transm
        scatter[2] += color[2] * absorption * transm
        scatter[3] += color[3] * absorption * transm

        if transm < zero_threshold:
            break

        prev_density = color[3]
        t += step

    scatter[0] /= 2.0 * PI
    scatter[1] /= 2.0 * PI
    scatter[2] /= 2.0 * PI

    return scatter

# Helper definitions
def mul(a, b):

    return [sum(a[i] * b[i][j] for i in range(len(a))) for j in range(len(b[0]))]

def normalize(v):
    length = (v[0]**2 + v[1]**2 + v[2]**2)**0.5
    return [x / length for x in v] if length > 0 else [0.0, 0.0, 0.0]

    # Loads spherical harmonic coefficients from light probes
    return coeffs

    # Converts local space position to 3D texture coordinates
    return [pos[0] * 0.5 + 0.5, pos[1] * 0.5 + 0.5, pos[2] * 0.5 + 0.5]
```

**Parameters**
*   `g_step`: Initial step size for ray marching. Value not given in the sources.
*   `g_numSamples`: Maximum number of samples per ray. Value not given in the sources.
*   `ZERO_THRESHOLD`: Threshold for skipping empty space and terminating ray due to full occlusion. Value not given in the sources.
*   `ABSORPTION`: Constant used in accumulation formula. Value not given in the sources.

**Edge Cases and Pitfalls**
*   **Boundary Sampling**: The check `any(abs(pos) > 1.0)` prevents sampling outside the unit cube volume [S1, unofficial].
*   **Ray Direction**: Normalization of `rayDir` ensures consistent step sizes regardless of camera position [S1, unofficial].
*   **Empty Space**: Density values below `ZERO_THRESHOLD` are skipped to save computation, but `prevDensity` must still be updated to ensure correct `dDensity` calculation for the next non-empty sample [S1, unofficial].
