# Dynamic Sampling Step Adjustment

Also called: Adaptive Step Doubling, Empty Space Step Doubling

## Overview
Dynamic Sampling Step Adjustment accelerates ray marching through homogeneous or empty regions by exponentially increasing the step size when no density is detected, then restoring the original step size upon encountering geometry [S1, unofficial]. It distinguishes itself from sibling methods like [Adaptive Step Size Ray Marching](2312-adaptive-step-size-ray-marching.md) by relying on binary emptiness checks rather than continuous density metrics, and from [Variance-based Step Size Adaptation](13161-variance-based-step-size-adaptation.md) by using discrete doubling rather than statistical variance to drive step selection [S1, unofficial].

## How it works
**Inputs and Outputs:**
*   Input: Current ray position $t$, current step size $\Delta t$, current mip-map offset $mipOffset$, and a scalar field query function $S(p)$ returning density.
*   Output: Updated ray position $t_{new}$, updated step size $\Delta t_{new}$, and updated mip-map offset $mipOffset_{new}$.

**Data Structures:**
*   `step_size`: Floating point value representing the current traversal step.
*   `mipOffset`: Integer or floating point index indicating the resolution level of the scalar field being sampled.
*   `consecutive_empty_count`: Integer counter tracking how many consecutive samples returned zero density.

**Parameters:**
*   `initial_step_size`: The base step size for non-empty regions. Typical value: Not given in the sources.
*   `doubling_threshold`: The number of consecutive empty samples required to trigger a step size increase. Typical value: Not given in the sources (implies "multiple").
*   `mip_scale`: The factor by which `mipOffset` increases per doubling. Typical value: Not given in the sources.

**Algorithm:**
1.  Sample the scalar field at the current ray position $t$ to obtain density $d = S(t)$.
2.  If $d > 0$ (non-empty):
    *   Reset `consecutive_empty_count` to 0.
    *   Restore `step_size` to `initial_step_size`.
    *   Restore `mipOffset` to its base value (typically 0 or the highest resolution level).
    *   Advance the ray by `step_size`: $t_{new} = t + step\_size$.
3.  If $d == 0$ (empty):
    *   Increment `consecutive_empty_count`.
    *   If `consecutive_empty_count` exceeds `doubling_threshold`:
        *   Double the `step_size`: $step\_size = step\_size \times 2$.
        *   Increase `mipOffset` to sample a coarser mip-map level: $mipOffset = mipOffset + mip\_scale$.
        *   Reset `consecutive_empty_count` to 0 (or keep incrementing depending on implementation; the source implies resetting the condition check for the next doubling).
    *   Advance the ray by the current `step_size`: $t_{new} = t + step\_size$.
4.  Clamp `step_size` to global bounds $[\Delta t_{min}, \Delta t_{max}]$ to prevent infinite loops or excessive skipping [S1, unofficial].

**Pseudocode:**
```python
def dynamic_sampling_step_adjustment(ray_t, initial_step_size, mip_offset_base, scalar_field):
    step_size = initial_step_size
    mip_offset = mip_offset_base
    consecutive_empty = 0
    
    # Sample current position
    density = scalar_field.sample(ray_t, mip_offset)
    
    if density > 0:
        # Geometry found: reset adaptation
        consecutive_empty = 0
        step_size = initial_step_size
        mip_offset = mip_offset_base
        ray_t += step_size
    else:
        # Empty space detected
        consecutive_empty += 1
        
        # Check if we should double the step size
        # Note: 'multiple' is vague; assuming a threshold of 1 or more for immediate doubling 
        # or a specific count. Standard implementation often doubles after 1 or 2 empty samples.
        # Here we assume a threshold of 1 for immediate response to emptiness, 
        # or we can use a counter. The source says "multiple consecutive", implying >1.
        # Let's assume a threshold of 2 for safety, or 1 if 'multiple' implies just 'more than one frame'.
        # Given the ambiguity, we implement a generic threshold check.
        if consecutive_empty >= 2: 
            step_size *= 2
            mip_offset += 1 # Increase mip level for coarser sampling
            consecutive_empty = 0 # Reset counter for next doubling phase
            
        ray_t += step_size
        
    return ray_t, step_size, mip_offset
```

**Edge Cases and Pitfalls:**
*   **Artifacts:** The optimization provides small performance gains and may cause artifacts in some cases, particularly if the step size doubles too aggressively across thin features [S1, unofficial].
*   **Precision:** Restoring the exact `mipOffset` and `step_size` requires careful state management to avoid drift.
*   **Boundary Handling:** If the ray exits the volume bounds, the step size adjustment should be disabled or clamped to prevent sampling outside the valid data range.

## Subtopics

### [Gradient-driven Sampling](5281-gradient-driven-sampling.md)
Gradient-driven sampling is a ray marching technique that dynamically adjusts step sizes based on the magnitude of the scalar field gradient, refining traversal in regions with high feature sharpness while coarsening it in smooth interiors. It distinguishes itself from uniform sampling by adapting to local geometry to preserve boundary details without aliasing, and from hierarchical sampling by using gradient magnitude rather than variance or error tolerance to drive step selection.

### [Dynamic Texture Slice Resampling](6101-dynamic-texture-slice-resampling.md)
Dynamic Texture Slice Resampling is a technique for volume rendering that dynamically updates slicing steps according to viewing directions to maintain a constant step size during the Direct Volume Rendering (DVR) process. It solves the problem of striping artifacts caused by non-uniform sampling steps. The method adapts the sampling density to the viewing geometry to maintain high rendering performance.

### [Dynamic Adaptive Sampling Ray-Casting](7687-dynamic-adaptive-sampling-ray-casting.md)
Dynamic Adaptive Sampling Ray-Casting (DAS) is a volume rendering method that accelerates 3D reconstruction by dynamically adjusting sampling intervals based on local voxel gradients and employing a specialized light-blocking composition operator. It addresses the slow rendering speed and low sampling efficiency of standard ray-casting in medical image processing by reducing redundant samples in homogeneous regions while maintaining high precision near isosurfaces. Unlike sibling methods that may ignore voxel correlation or use fixed intervals, DAS explicitly links sampling density to the full increment of voxel value differences and gradient magnitude.

### Geometry Sampling Adjustment
A method to adjust the maximum number of geometry samples per streamline based on a geometry sampling factor [S2, unofficial]. It sets `m_maxGeometrySamples` to `m_maxSamples / m_geometrySampling + 1`, where `m_maxSamples` is the base maximum number of samples per streamline and `m_geometrySampling` is a factor used to reduce the number of geometry samples [S2, unofficial].

## Operating characteristics
*   **Time Complexity:** Reduces the number of samples in empty space by a factor of $2^k$ where $k$ is the number of doublings, leading to $O(1)$ average cost per empty region traversal compared to $O(N)$ for uniform sampling.
*   **Memory Complexity:** Minimal overhead; requires storing only the current step size, mip offset, and a counter.
*   **Performance:** Provides small performance gains [S1, unofficial].
*   **Strengths:** Simple to implement; effective for scenes with large empty volumes (e.g., atmospheric clouds with sparse bases).
*   **Limitations:** May cause artifacts if the doubling threshold is too low or the step size grows too large for the feature size [S1, unofficial]. Not suitable for high-frequency details without additional checks.
*   **When to use:** When rendering large volumes with significant empty space, such as atmospheric effects or sparse particle systems.
*   **When not to use:** When high-frequency details are present in empty-looking regions or when artifact sensitivity is high.

## Background
The technique is described in the context of implementing volumetric cloud effects in real-time rendering, specifically mentioning its use in conjunction with blue noise dithering and temporal upsampling [S1, unofficial]. It is noted as a simple optimization that can be combined with other techniques like HDRP-style cloud rendering [S1, unofficial].
