# Adaptive Step Method

Also called: Adaptive RK2

## Overview
The Adaptive Step Method is a numerical integration technique for volume rendering that dynamically adjusts the ray marching step size to maintain a specified error tolerance [S1]. It solves the problem of balancing rendering speed and accuracy by estimating the local truncation error at each step and modifying the step length accordingly [S1]. Unlike fixed-step methods, it uses a user-defined tolerance parameter rather than a fixed step count, making it more user-friendly [S1]. It distinguishes itself from its sibling [Data-Dependent Error Metric for Scalar Fields](6981-data-dependent-error-metric-for-scalar-fields.md) by using order-difference estimation (Euler vs. RK2) rather than field-specific gradients, and from [Stepsize Annealing](7542-stepsize-annealing.md) by its explicit error-based feedback loop [S1].

## How it works
**Inputs:**
*   Current position $P_n$ and direction $D$.
*   Radiance transfer function (scattering coefficient $\sigma_s$, emission $L_e$, extinction $\sigma_t$).
*   Target relative error tolerance $E$.
*   Current step size $dt$.

**Outputs:**
*   Next position $P_{n+1}$.
*   Accumulated radiance contribution.
*   Updated step size $dt_{new}$.

**Data Structures:**
*   Position $P$: 3D vector $(x, y, z)$.
*   Step size $dt$: Scalar float.
*   Error $E$: Scalar float (tolerance).

**Method Steps:**
1.  **Euler Estimate:** Compute the next position using Euler’s method (first-order) with the current step size $dt$. Let this be $P_{Euler}$ [S1].
    $$ P_{Euler} = P_n + dt \cdot V(P_n) $$
    Where $V(P)$ is the derivative of the state (e.g., radiance or position in phase space) at $P$. In standard volume rendering, this often refers to the radiance integration step.

2.  **RK2 Estimate:** Compute the next position using a second-order Runge-Kutta method (midpoint or Heun) with the same step size $dt$. Let this be $P_{RK2}$ [S1].
    $$ k_1 = V(P_n) $$
    $$ k_2 = V(P_n + \frac{dt}{2} k_1) $$
    $$ P_{RK2} = P_n + dt \cdot k_2 $$

3.  **Error Estimation:** Calculate the relative error between the two estimates [S1].
    $$ error = \frac{|P_{RK2} - P_{Euler}|}{|P_{RK2}| + \epsilon} $$
    Where $\epsilon$ is a small constant to prevent division by zero [G].

4.  **Step Size Adjustment:** Compare the estimated error against the tolerance $E$ and adjust $dt$ [S1].
    *   If $error > E$: Reduce step size.
        $$ dt_{new} = dt \cdot \left( \frac{E}{error} \right)^{1/2} $$
        (The exponent $1/2$ corresponds to the order difference between Euler (1st) and RK2 (2nd) [G]).
    *   If $error \le E$: Increase step size.
        $$ dt_{new} = dt \cdot \left( \frac{error}{E} \right)^{1/3} $$
        (The exponent $1/3$ is a conservative growth factor for stability [G]).

5.  **Integration:** Perform the actual integration step using the higher-order method (RK2) to advance the ray to $P_{n+1}$ and accumulate radiance [S1].

**Pseudocode:**
```python
def adaptive_step(P_n, dt, tolerance, velocity_func):
    # 1. Euler step (1st order)
    V_n = velocity_func(P_n)
    P_euler = P_n + dt * V_n

    # 2. RK2 step (2nd order) - Midpoint method
    V_mid = velocity_func(P_n + 0.5 * dt * V_n)
    P_rk2 = P_n + dt * V_mid

    # 3. Error estimation
    # Use relative error to handle scale
    denom = max(abs(P_rk2), 1e-8)
    error = abs(P_rk2 - P_euler) / denom

    # 4. Adjust step size
    if error > tolerance:
        # Reduce step size: factor of (tolerance/error)^(1/order_diff)
        # Order diff is 2-1=1, but standard practice uses sqrt for safety
        dt = dt * (tolerance / error) ** 0.5
    else:
        # Increase step size: conservative growth
        dt = dt * (error / tolerance) ** (1.0/3.0)

    # 5. Finalize step using the more accurate method (RK2)
    P_next = P_rk2
    return P_next, dt
```

**Edge Cases and Pitfalls:**
*   **High-Frequency Illumination:** In scenes with sharp light beams or high-frequency illumination, the method may increase the step size in dark, low-error regions. This can cause the ray to skip over the high-frequency light beams entirely, resulting in visible artifacts [S1].
*   **Maximum Step Size:** To mitigate the skipping of high-frequency features, a maximum step size constraint is required [S1].
*   **Precision:** Floating-point precision errors in the error estimation can lead to oscillating step sizes [G].

## Subtopics

### Adaptive Time Integration (Steady/Particle)
A variant used for particle tracing or steady flow integration that keeps integration error constant by adjusting the time step $dt$ [S2, unofficial]. It uses 11 function evaluations (compared to 8 for standard RK2) and requires a conservative factor of 0.9 for $dt$ changes [S2, unofficial]. It uses specific exponents for shrinking and growing $dt$: SHRINK is $1/2$ for second-order RK and $1/4$ for fourth-order RK; GROW is $1/3$ for second-order RK and $1/5$ for fourth-order RK [S2, unofficial]. The algorithm evaluates velocity at the current position, performs a half-step RK, a full-step RK, evaluates velocity at the half-step position, and then performs a final correction step to estimate error [S2, unofficial].

## Operating characteristics
*   **Time Complexity:** Variable per step due to multiple function evaluations (Euler + RK2 = 2-3 evaluations per step vs. 1 for Euler) [S1].
*   **Memory Complexity:** Low; requires storing only current position and velocity [S1].
*   **Performance:** Provides better accuracy than Euler for the same render time at low tolerances [S1]. However, it can be slower than fixed-step methods if the tolerance is very tight [S1].
*   **Strengths:** User-friendly via tolerance parameter; adapts to scene complexity [S1].
*   **Limitations:** Can fail on high-frequency illumination without a maximum step size constraint; artifacts may persist even with restrictive tolerances if the scene has sharp discontinuities (e.g., shadows) [S1].
*   **Hardware:** Tested on Intel Core i5 at 2.4GHz with 4GB RAM, parallelized using threads [S1].

## Background
The method was tested and described in the context of differential ray marching for participating media [S1]. It was evaluated against fixed-step methods (Euler, RK2) in scenes including green fog and car headlights with sharp shadows [S1]. The adaptive time integration variant for particle flows was described in the context of unsteady flow volumes [S2, unofficial].
