# Field Error Metric

Also called: Error Estimation Methods, Field Error Measurement, Scalar Value Difference Error, Surface Error Measurement

## Overview
The Field Error Metric estimates approximation error in simplified meshes by measuring discrepancies in scalar field values between the original and simplified representations [S1]. It complements surface boundary error metrics by evaluating internal data variations within the mesh domain [S1].

## How it works
**Inputs:**
1. Original scalar field defined on a tetrahedral mesh domain [S1].
2. Simplified mesh representation [S1].
3. Scalar field range $R = \max(f) - \min(f)$ of the original field [S1].

**Outputs:**
1. Normalized field error percentage [S1].

**Data Structures:**
- Sample points $P$: 3D coordinates including original mesh vertices and interpolated points inside each tetrahedron [S1].
- Scalar values $f(p)$: Field value at point $p$ [S1].

**Steps:**
1. Sample points $P$ inside the domain of the original mesh, including vertices and interior interpolated points of each tetrahedron [S1].
2. For each point $p \in P$, check if it lies inside the domain of the simplified mesh [S1].
3. Discard points outside the simplified mesh domain; these are excluded from field error and contribute to surface boundary error instead [S1].
4. For remaining points, compute the difference between the original scalar value $f_{\text{orig}}(p)$ and the simplified mesh scalar value $f_{\text{simp}}(p)$ [S1].
5. Aggregate the differences and normalize by the original field range $R$ to express the result as a percentage [S1].

**Formula:**
Let $P_{\text{valid}}$ be the set of sample points inside the simplified mesh domain. The field error $E_{\text{field}}$ is:
$$ E_{\text{field}} = \frac{\sum_{p \in P_{\text{valid}}} |f_{\text{orig}}(p) - f_{\text{simp}}(p)|}{|P_{\text{valid}}| \cdot R} \times 100\% $$
The sources specify computing "differences between their scalar values" and normalizing field error percentages relative to the field range, without specifying squared differences [S1].

**Parameters:**
- $R$: Range of the original scalar field [S1].

**Edge Cases and Pitfalls:**
- Points outside the simplified mesh domain must be explicitly ignored to avoid double-counting with surface boundary error metrics [S1].
- Interpolation accuracy for $f_{\text{simp}}(p)$ depends on the method used within the simplified mesh elements [G].

**Pseudocode:**
```python
def compute_field_error_metric(original_field, simplified_mesh, original_range):
    """
    Computes the normalized field error metric.
    Args:
        original_field: Function or data structure providing f_orig(p).
        simplified_mesh: Data structure providing f_simp(p) and is_inside(p).
        original_range: The scalar range (max - min) of the original field.
    Returns:
        float: Normalized field error percentage.
    """
    # 1. Generate sample points P inside the original domain
    # [G] The sources do not specify the sampling strategy; implementers must generate points including vertices and interior tetrahedron points.
    sample_points = []
    
    total_error = 0.0
    count = 0
    
    for p in sample_points:
        # 2. Check if point is inside simplified mesh domain
        if not simplified_mesh.is_inside(p):
            # 3. Ignore points outside simplified domain
            continue
            
        # 4. Get scalar values
        f_orig = original_field.evaluate(p)
        f_simp = simplified_mesh.evaluate(p)
        
        # 5. Compute difference
        diff = abs(f_orig - f_simp)
        total_error += diff
        count += 1
        
    if count == 0:
        return 0.0
        
    # 6. Normalize by range and count
    normalized_error = total_error / (count * original_range)
    return normalized_error * 100.0
```

## Subtopics

### Implicit Function Error Metric
A method to measure approximation quality by computing the Euclidean distance between the output mesh and the implicit surface [S2]. It globally increases accuracy by subdividing each triangle three times to increase the number of error sampling points [S2]. The error at point $p$ is approximated by $e(p) \approx \frac{|f(p)|}{\|\nabla f(p)\|}$, where $f(p)$ is the implicit function value and $\nabla f(p)$ is its gradient [S2].

## Background
The Field Error Metric was introduced in the context of streaming simplification of tetrahedral meshes [S1]. It was proposed alongside surface boundary error measurement (using Metro [30]) as an alternative method to evaluate the quality of simplified field data using scalar value differences [S1]. The implementation differs from prior approaches by explicitly ignoring points outside the simplified mesh domain to separate field error from surface boundary error [S1].
