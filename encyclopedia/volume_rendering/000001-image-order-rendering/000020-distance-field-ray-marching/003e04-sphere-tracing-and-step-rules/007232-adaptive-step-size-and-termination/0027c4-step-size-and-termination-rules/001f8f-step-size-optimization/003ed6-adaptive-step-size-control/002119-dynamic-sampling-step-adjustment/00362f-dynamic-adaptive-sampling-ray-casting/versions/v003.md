# Dynamic Adaptive Sampling Ray-Casting

Also called: Improved Ray-Casting Algorithm Using Dynamic Adaptive Sampling, Ray-casting DAS algorithm, ray-casting algorithm using dynamic adaptive sampling

## Overview
Dynamic Adaptive Sampling Ray-Casting (DAS) is a volume rendering method that accelerates 3D reconstruction by dynamically adjusting sampling intervals based on local voxel gradients and employing a specialized light-blocking composition operator [S1]. It addresses the slow rendering speed and low sampling efficiency of standard ray-casting in medical image processing by reducing redundant samples in homogeneous regions while maintaining high precision near isosurfaces [G]. Unlike sibling methods that may ignore voxel correlation or use fixed intervals, DAS explicitly links sampling density to the full increment of voxel value differences and gradient magnitude [S1].

## How it works

### Inputs and Outputs
**Inputs:**
*   A 3D volume dataset $V$ with dimensions $D_x \times D_y \times D_z$ [G].
*   A ray defined by origin $\mathbf{o}$ and direction $\mathbf{d}$ [G].
*   A preset voxel value threshold $T_{iso}$ for isosurface detection [S1].
*   A maximum step size limit to prevent aliasing or missed features [G].

**Outputs:**
*   Final pixel color and opacity for the ray [G].

### Data Structures
*   **Volume Grid:** Stored as a 3D array of scalar values (voxel intensities) [G].
*   **Sampling Point:** A 3D coordinate $(x, y, z)$ and associated color/opacity attributes [G].
*   **Gradient:** A 3D vector computed via central differences [S1].

### Parameters
*   $T_{iso}$: Preset voxel value threshold used to determine if the ray has entered a significant volume region [S1].
*   $\Delta_{max}$: Maximum allowable sampling interval to prevent aliasing or missed features [G].
*   $\epsilon$: Small constant for numerical stability in gradient calculation [G].

### Algorithm Steps

1.  **Ray Initialization:**
    Start the ray at the entry point into the volume bounding box [G]. Initialize current position $\mathbf{p}_0$, previous position $\mathbf{p}_{prev}$, and accumulated color $C_{acc} = (0,0,0)$ with accumulated opacity $\alpha_{acc} = 0.0$ [G].

2.  **Dynamic Step Size Calculation:**
    At each sampling point $\mathbf{p}_i$, calculate the sampling interval $\Delta s$ dynamically [S1].
    *   Compute the gradient $\nabla V(\mathbf{p}_i)$ using the central difference method [S1].
    *   Calculate the voxel value difference between adjacent points [S1]. If $\mathbf{p}_{prev}$ exists, compute $\Delta V = |V(\mathbf{p}_i) - V(\mathbf{p}_{prev})|$ [S1].
    *   The sampling interval is determined by the gradient magnitude and the voxel difference relative to the threshold $T_{iso}$ [S1]. High gradients or large differences result in smaller steps; low gradients result in larger steps [S1].

3.  **Step Advancement:**
    Advance the ray by $\Delta s$: $\mathbf{p}_{next} = \mathbf{p}_i + \Delta s \cdot \mathbf{d}$ [S1].
    Update $\mathbf{p}_{prev} = \mathbf{p}_i$ and $\mathbf{p}_i = \mathbf{p}_{next}$ [S1].

4.  **Isosurface Intersection Estimation (Recursive):**
    If the step size $\Delta s$ is large, the precision of the intersection point between the ray and the isosurface may be reduced [S1].
    *   Apply a recursive estimation method based on the current intersection point to refine the position where the ray crosses the threshold $T_{iso}$ [S1].
    *   This improves search precision without requiring excessively small fixed steps [S1].

5.  **Light-Blocking Composition (New Rendering Operator):**
    Instead of standard trilinear interpolation of eight equidistant points, use a light-blocking operator that considers changes before and after the ray enters the volume element [S1].
    *   Sample the voxel at the current position [G].
    *   Calculate opacity $\alpha$ and color $C$ based on the voxel value [S1].
    *   Apply the "resistance luminosity" concept: modify the opacity and color values as well as the photometry before and after the ray enters the volume element [S1].
    *   Update accumulated color and opacity using this new operator [S1].

6.  **Termination:**
    Stop when the ray exits the volume or the accumulated opacity reaches 1.0 [G].

### Pseudocode

```python
import math

def ray_casting_das(ray_origin, ray_direction, volume, threshold_T_iso, max_steps=1000):
    # Ray-box intersection for unit cube [0,1]^3 [G]
    inv_dir = tuple(1.0 / d if abs(d) > 1e-8 else 1e8 for d in ray_direction)
    t_min = max((0.0 - ray_origin.x) * inv_dir.x, (1.0 - ray_origin.x) * inv_dir.x)
    t_min = max(t_min, (0.0 - ray_origin.y) * inv_dir.y, (1.0 - ray_origin.y) * inv_dir.y)
    t_min = max(t_min, (0.0 - ray_origin.z) * inv_dir.z, (1.0 - ray_origin.z) * inv_dir.z)
    t_max = min((1.0 - ray_origin.x) * inv_dir.x, (0.0 - ray_origin.x) * inv_dir.x)
    t_max = min(t_max, (1.0 - ray_origin.y) * inv_dir.y, (0.0 - ray_origin.y) * inv_dir.y)
    t_max = min(t_max, (1.0 - ray_origin.z) * inv_dir.z, (0.0 - ray_origin.z) * inv_dir.z)
    if t_min > t_max or t_max < 0.0:
        return (0.0, 0.0, 0.0, 0.0)

    p_current = ray_origin + ray_direction * t_min
    p_prev = None
    acc_color = (0.0, 0.0, 0.0)
    acc_alpha = 0.0
    step_size = 0.5
    dx = dy = dz = 1.0 / max(volume.shape)

    for _ in range(max_steps):
        if acc_alpha >= 1.0 or t_min + step_size > t_max:
            break

        v_curr = trilinear(volume, p_current)
        grad = central_diff_gradient(volume, p_current, dx, dy, dz)
        grad_mag = magnitude(grad)

        if p_prev is not None:
            v_prev = trilinear(volume, p_prev)
            v_diff = abs(v_curr - v_prev)
        else:
            v_diff = 0.0

        # Dynamic step size calculation [G]: combines gradient magnitude and voxel difference relative to threshold
        # Sources specify using full increment formula of voxel difference, central difference gradient, and threshold [S1]
        step_size = min(0.5, 1.0 / (grad_mag + 1e-6))
        if p_prev is not None:
            step_size = min(step_size, 0.1 / (v_diff + 1e-6))

        p_next = p_current + ray_direction * step_size

        # Recursive refinement for large steps [S1]
        if step_size > 0.2 and p_prev is not None:
            if (v_prev - threshold_T_iso) * (v_curr - threshold_T_iso) < 0:
                t_refine = 0.5
                for _ in range(5):
                    p_mid = p_prev + ray_direction * (step_size * t_refine)
                    v_mid = trilinear(volume, p_mid)
                    if (v_prev - threshold_T_iso) * (v_mid - threshold_T_iso) < 0:
                        t_refine *= 0.5
                    else:
                        t_refine = 0.5 + t_refine * 0.5
                p_current = p_prev + ray_direction * (step_size * t_refine)
                v_curr = trilinear(volume, p_current)

        # Light-blocking composition operator [S1]
        # Uses resistance luminosity and changes in opacity/color before and after entering volume element
        alpha = sigmoid(v_curr - threshold_T_iso)
        color = volume_color(p_current)
        alpha = alpha * (1.0 + v_diff)
        alpha = min(alpha, 1.0)

        weight = alpha * (1.0 - acc_alpha)
        acc_color = acc_color + color * weight
        acc_alpha = acc_alpha + weight

        p_prev = p_current
        p_current = p_next
        t_min += step_size

    return (acc_color[0], acc_color[1], acc_color[2], acc_alpha)

def trilinear(volume, p):
    x, y, z = p
    x = max(0.0, min(1.0, x))
    y = max(0.0, min(1.0, y))
    z = max(0.0, min(1.0, z))
    ix, fx = math.modf(x * (volume.shape[0] - 1))
    iy, fy = math.modf(y * (volume.shape[1] - 1))
    iz, fz = math.modf(z * (volume.shape[2] - 1))
    ix, iy, iz = int(ix), int(iy), int(iz)
    v000 = volume[ix, iy, iz]
    v100 = volume[min(ix+1, volume.shape[0]-1), iy, iz]
    v010 = volume[ix, min(iy+1, volume.shape[1]-1), iz]
    v110 = volume[min(ix+1, volume.shape[0]-1), min(iy+1, volume.shape[1]-1), iz]
    v001 = volume[ix, iy, min(iz+1, volume.shape[2]-1)]
    v101 = volume[min(ix+1, volume.shape[0]-1), iy, min(iz+1, volume.shape[2]-1)]
    v011 = volume[ix, min(iy+1, volume.shape[1]-1), min(iz+1, volume.shape[2]-1)]
    v111 = volume[min(ix+1, volume.shape[0]-1), min(iy+1, volume.shape[1]-1), min(iz+1, volume.shape[2]-1)]
    return (v000*(1-fx)*(1-fy)*(1-fz) + v100*fx*(1-fy)*(1-fz) + v010*(1-fx)*fy*(1-fz) + v110*fx*fy*(1-fz) + v001*(1-fx)*(1-fy)*fz + v101*fx*(1-fy)*fz + v011*(1-fx)*fy*fz + v111*fx*fy*fz)

def central_diff_gradient(volume, p, dx, dy, dz):
    x, y, z = p
    x = max(0.0, min(1.0, x))
    y = max(0.0, min(1.0, y))
    z = max(0.0, min(1.0, z))
    gx = (trilinear(volume, (x+dx, y, z)) - trilinear(volume, (x-dx, y, z))) / (2*dx)
    gy = (trilinear(volume, (x, y+dy, z)) - trilinear(volume, (x, y-dy, z))) / (2*dy)
    gz = (trilinear(volume, (x, y, z+dz)) - trilinear(volume, (x, y, z-dz))) / (2*dz)
    return (gx, gy, gz)

def magnitude(v):
    return (v[0]**2 + v[1]**2 + v[2]**2)**0.5

def sigmoid(x):
    return 1.0 / (1.0 + 2.718281828**(-x))

def volume_color(p):
    return (0.5, 0.5, 0.5)
```

### Edge Cases and Pitfalls
*   **Large Step Sizes:** If the dynamic step size is too large, the ray may skip over thin structures [S1]. The recursive estimation method is used to mitigate this, but precision may still be lower than fixed small-step methods [S1].
*   **Homogeneous Regions:** In regions with zero gradient, the step size might become very large [G]. A maximum step size limit is necessary to prevent artifacts [G].
*   **Boundary Conditions:** Central difference requires neighbors on both sides [G]. At volume boundaries, coordinates are clamped to `[0, 1]` to prevent out-of-bounds access [G].

### Improved Ray Casting for Coarse Grained Soil
An algorithm for reconstructing 3D models of coarse-grained soil fabric using improved ray casting with adaptive segmentation of threshold and simulated annealing [S3]. It performs adaptive segmentation of threshold while preprocessing original CT data fields, filters meaningless data to reserve target coarse-grained soil data, and applies ray casting for volume rendering [S3]. To determine the optimum threshold, it applies a simulated annealing algorithm to find the maximum between-cluster variance [S3]. It shows transparency and reconstructs soil fabric, reducing reconstruction time and enhancing visual effects and efficiency [S3]. Experiments were conducted in Matlab 6.5 [S3].

## Operating characteristics

### Time and Memory Complexity
*   **Time:** The algorithm reduces the number of sampling points per ray compared to fixed-step ray casting, leading to faster rendering speeds [S1, S2]. However, each step requires gradient calculation (multiple interpolations) and a complex composition operator, which adds per-step overhead [G].
*   **Memory:** Requires storage for the 3D volume dataset. No significant additional memory structures are mentioned beyond standard ray-casting buffers [S1].

### Measured Performance
*   On the ISBI2018 dataset, the ray-casting DAS algorithm reduces and avoids artifact phenomena in CT image rendering and improves image visibility compared to Francisco Sans' algorithm, Roba Binyahibs' algorithm, Feiniu Yuan's algorithm, Leonardo's algorithm, and Yan Zhang's algorithm [S2].
*   It achieves faster rendering speed while ensuring the quality of the generated image [S1, S2].

### Strengths and Limitations
*   **Strengths:**
    *   Faster rendering speed due to adaptive sampling [S1].
    *   Improved image quality and visibility by considering voxel correlation and gradients [S1].
    *   Reduced artifacts in CT image rendering [S2].
    *   Novel light-blocking composition operator improves photometry [S1].
*   **Limitations:**
    *   Complexity of the dynamic step calculation and recursive intersection estimation may be harder to implement than simple fixed-step methods [S1].
    *   The exact formulas for the dynamic step and light-blocking operator are not fully detailed in the source, making implementation reliant on interpretation [S1].

### When to Use
*   Use when rendering medical images (e.g., CT scans) where speed is critical but quality must be maintained [S1, S2].
*   Use when the volume has varying density, allowing for significant variation in sampling intervals [S1].

### When Not to Use
*   Use fixed-step ray casting if the volume is small or homogeneous, as the overhead of gradient calculation may not be justified [G].
*   Use if the exact mathematical formulation of the "light-blocking" operator is required for strict physical accuracy, as it is a novel, non-standard operator [S1].

## Background

*   **Origin:** The algorithm was proposed by Huadeng Wang, Guang Xu, Xipeng Pan, and Xiaonan Luo in 2020 [S1].
*   **Paper:** "A Novel Ray-Casting Algorithm Using Dynamic Adaptive Sampling," published in *Wireless Communications and Mobile Computing*, Volume 2020, Article ID 8822624 [S1].
*   **Context:** It builds on the traditional ray-casting algorithm proposed by Levoy in 1988 [S1]. It addresses shortcomings in 3D reconstruction of medical images, such as slow rendering speed and low sampling efficiency [S1].
*   **Development:** The method introduces dynamic adaptive sampling based on voxel value differences and gradients, a recursive intersection estimation method, and a new light-blocking composition operator [S1].
