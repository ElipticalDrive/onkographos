# Compute Minimal Sample Distance Per Pixel
Also called: ComputeMinimalSamplePerPixel, Projected Cell Axis Step Size
## Overview
Computes the minimal sample distance per pixel by projecting each dataset cell axis onto the viewport, accounting for camera and volume transforms [S1, unofficial].
## How it works
**Inputs and Outputs:**
*   **Inputs:** `renderer` (a `vtkRenderer` pointer providing camera and viewport state) and `volume` (a `vtkVolume` pointer providing dataset geometry and transformation) [S1, unofficial].
*   **Outputs:** The computed minimal sample distance and a boolean flag indicating whether the calculation should be ignored.
**Data Structures:**
The method accesses the renderer's camera state and the volume's geometry and transformation matrices [S1, unofficial]. It validates scalar data using a `CellFlag` property to reject unsupported field data formats [S1, unofficial].
**Steps:**
1.  **Validation:** Verify that valid scalar data exists on the input and that the `CellFlag` does not indicate field data, which is unsupported [S1, unofficial].
2.  **Transform Preparation:** Update the transformed volume inputs to ensure correct coordinate space alignment [S1, unofficial].
3.  **Axis Projection:** Project each of the three dataset cell axes onto the viewport, accounting for the volume and camera transforms [S1, unofficial].
4.  **Degeneracy Check:** If any axis is degenerate (aligned with the view direction), set `IgnoreSampleDistancePerPixel` to true [S1, unofficial].
5.  **Distance Calculation:** Compute the minimal sample distance from the projected axes lengths [S1, unofficial].
**Pseudocode:**
```python
def dot(a, b):
    return a[0]*b[0] + a[1]*b[1] + a[2]*b[2]

def magnitude(v):
    return (v[0]**2 + v[1]**2 + v[2]**2)**0.5

def compute_minimal_sample_distance(renderer, volume):
    # 1. Validation
    scalars = volume.get_scalars()
    if scalars is None:
        raise ValueError("No scalars found on input.")
    if volume.get_cell_flag() == 2:
        raise ValueError("Only point or cell scalar support - found field scalars instead.")

    # 2. Transform Preparation
    volume.transformed_input.update()
    volume.transformed_input.set_update_extent_to_whole_extent()
    volume.transformed_input.update()

    # 3. Axis Projection and Degeneracy Check
    spacing = volume.get_spacing()
    axes = [[spacing[0], 0, 0], [0, spacing[1], 0], [0, 0, spacing[2]]]
    view_dir = renderer.get_view_direction()
    view_dir = [v / magnitude(view_dir) for v in view_dir]
    ignore_flag = False
    min_projected_length = float('inf')

    for axis in axes:
        world_axis = volume.transform_matrix().transform(axis)
        # Check degeneracy: aligned with view direction
        if abs(dot(world_axis, view_dir)) > 0.9999:
            ignore_flag = True
            break
        # Project onto view plane (remove component along view direction)
        projected = [world_axis[i] - dot(world_axis, view_dir) * view_dir[i] for i in range(3)]
        length = magnitude(projected)
        if length < min_projected_length:
            min_projected_length = length

    return min_projected_length, ignore_flag
```
**Parameters:**
*   `renderer`: VTK renderer pointer [S1, unofficial].
*   `volume`: VTK volume pointer [S1, unofficial].
*   `CellFlag`: Property indicating scalar type; value 2 denotes field data, which causes the method to fail [S1, unofficial].
**Edge Cases:**
*   **Degenerate Axes:** If a dataset axis is parallel to the view direction, the projected length is zero or undefined, and the method sets `IgnoreSampleDistancePerPixel` to true [S1, unofficial].
*   **Field Data:** If the input scalars are field data, the method fails as it only supports point or cell scalars [S1, unofficial].
## Subtopics

### [Projected Voxel Size / LOD Calculation](4189-projected-voxel-size-lod-calculation.md)
Projected Voxel Size / LOD Calculation computes a scalar metric representing the projected size of a voxel relative to the camera, primarily used for Level-of-Detail (LOD) decisions and step size adaptation in volume rendering.

### [L1 Voxel Thickness Slice Stepping](17718-l1-voxel-thickness-slice-stepping.md)
L1 Voxel Thickness Slice Stepping is a method for determining the distance between consecutive oblique slices in a volume viewport to ensure no voxel overlap and no gaps. It uses the L1 norm (Manhattan distance) of the projected voxel spacing vector along the view plane normal, rather than the L2 norm (Euclidean distance). It sets itself apart from its sibling [Projected Voxel Size / LOD Calculation](4189-projected-voxel-size-lod-calculation.md) by focusing on the discrete overlap test of voxel lattices rather than continuous projection scaling.
