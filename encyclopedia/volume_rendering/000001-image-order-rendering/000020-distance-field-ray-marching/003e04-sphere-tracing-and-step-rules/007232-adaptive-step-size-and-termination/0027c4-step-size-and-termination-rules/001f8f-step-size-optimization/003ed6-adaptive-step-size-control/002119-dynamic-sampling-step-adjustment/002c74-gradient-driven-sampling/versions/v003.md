# Gradient-driven Sampling

Also called: Gradient-based Step Size Adjustment

## Overview
Gradient-driven sampling is a ray marching technique that dynamically adjusts step sizes based on the magnitude of the scalar field gradient, refining traversal in regions with high feature sharpness while coarsening it in smooth interiors [S1]. It distinguishes itself from uniform sampling by adapting to local geometry to preserve boundary details without aliasing, and from hierarchical sampling by using gradient magnitude rather than variance or error tolerance to drive step selection [S1].

## How it works
**Inputs and Outputs**
*   **Input:** A scalar field $s(\mathbf{x})$ representing the volume data; a ray defined by origin $\mathbf{o}$ and direction $\mathbf{d}$; a minimum step size $h_{min}$ and maximum step size $h_{max}$; a gradient threshold $\tau$ (optional, for determining "high" gradient regions) [S1].
*   **Output:** A sequence of sample points along the ray and the accumulated transmittance/opacity for compositing [S1].

**Data Structures**
*   **Ray State:** Current position $\mathbf{p}$, current step size $h$, accumulated color/transmittance.
*   **Scalar Field Access:** Trilinear or trilinear interpolation of $s(\mathbf{x})$ to compute values at arbitrary positions [S1].

**Method Steps**
1.  **Initialize:** Set current position $\mathbf{p} = \mathbf{o}$ and step size $h = h_{initial}$ (typically $h_{max}$ or a base resolution-dependent value) [S1].
2.  **Sample Scalar Field:** Evaluate the scalar field value $s(\mathbf{p})$ at the current position [S1].
3.  **Compute Gradient:** Calculate the gradient vector $\nabla s(\mathbf{p})$ at $\mathbf{p}$ using central differences or analytic derivatives if available. Compute the gradient magnitude $|\nabla s(\mathbf{p})|$ [S1].
4.  **Determine Step Size:**
    *   The step size is dynamically adjusted based on the gradient magnitude. High gradient magnitudes indicate sharp transitions (e.g., surfaces), requiring smaller steps. Low gradient magnitudes indicate smooth regions, allowing larger steps [S1].
    *   A common heuristic maps $|\nabla s(\mathbf{p})|$ to $h$. For example, $h \propto 1/|\nabla s(\mathbf{p})|$ or uses a thresholded function. If $|\nabla s(\mathbf{p})| > \tau$, reduce $h$; otherwise, increase $h$ towards $h_{max}$ [S1].
    *   [G] The exact mapping function is not specified in the sources, but it must be monotonic: higher gradient $\rightarrow$ smaller step.
5.  **Bound Step Size:** Clamp the computed step size $h$ to the range $[h_{min}, h_{max}]$ to prevent under-sampling (aliasing) or over-sampling (performance loss) [S1].
6.  **Advance Ray:** Update position $\mathbf{p} \leftarrow \mathbf{p} + h \cdot \mathbf{d}$ [S1].
7.  **Composite:** Sample the scalar field at the new position, compute color/opacity, and accumulate into the ray's result using front-to-back compositing [S1].
8.  **Terminate:** If the ray exits the volume bounds or transmittance drops below a threshold, stop. Otherwise, return to Step 2.

**Pseudocode**
```python
def gradient_driven_sampling(ray_origin, ray_direction, volume, h_min, h_max, tau):
    p = ray_origin
    t = 0.0
    accumulated_color = (0.0, 0.0, 0.0)
    accumulated_transmittance = 1.0
    
    while t < volume.max_distance:
        # Sample scalar field
        s_val = volume.sample(p)
        
        # Compute gradient magnitude
        grad = volume.compute_gradient(p)
        grad_mag = magnitude(grad)
        
        # Determine step size based on gradient
        # High gradient -> small step; Low gradient -> large step
        # Heuristic: inverse proportionality, adjusted by threshold
        if grad_mag > tau:
            # In high gradient regions, take smaller steps
            # Base step is scaled down by gradient magnitude relative to threshold
            h = h_max * (tau / grad_mag)
        else:
            # In smooth regions, take larger steps, up to h_max
            h = h_max
            
        # Bound step size
        h = max(h_min, min(h_max, h))
        
        # Advance ray
        p = p + h * ray_direction
        t += h
        
        # Composite
        s_new = volume.sample(p)
        color = volume.get_color(s_new)
        alpha = volume.get_opacity(s_new)
        
        # Front-to-back compositing
        accumulated_color += accumulated_transmittance * color * alpha
        accumulated_transmittance *= (1.0 - alpha)
        
        if accumulated_transmittance < 0.001:
            break
            
    return accumulated_color
```

**Parameters**
*   $h_{min}$: Minimum step size. Not given in the sources.
*   $h_{max}$: Maximum step size. Not given in the sources.
*   $\tau$: Gradient threshold. Not given in the sources.

**Edge Cases and Pitfalls**
*   **Zero Gradient:** If $|\nabla s(\mathbf{p})| = 0$, the step size calculation may divide by zero. The logic must handle this by defaulting to $h_{max}$ or a safe minimum [S1].
*   **Noise:** High-frequency noise in the scalar field can cause erratic gradient magnitudes, leading to tiny steps and performance degradation. Smoothing the volume data before computing gradients is recommended [G].
*   **Boundary Precision:** While gradient-driven sampling improves boundary accuracy, it may still miss sub-voxel features if $h_{min}$ is not sufficiently small [S1].

## Subtopics

### [Dynamic Sampling Strategy](9081-dynamic-sampling-strategy.md)
A procedure to dynamically determine the number and locations of sample points in a participating medium to accurately reproduce shading variations and minimize rendering errors. It adapts sample locations based on shading error, unlike prior methods that sample based on density distribution. It builds on Gradient-driven Sampling by using a specific gradient-based error metric to drive a recursive splitting process.

### [FTLE-based Quad Size Estimation](12446-ftle-based-quad-size-estimation.md)
A method to determine conservative quad sizes for isosurface rendering that guarantees complete covering of isosurfaces by estimating the separation factor between seeds using Finite-Time Lyapunov Exponent (FTLE) concepts from dynamical systems theory. Unlike standard FTLE which measures predictability over a fixed time interval, this method adapts the separation metric to the distance along gradient field lines to the target isosurface, ensuring quads are large enough to cover the surface but small enough to avoid gaps.

### Gray-Two step Gradient Weighted Projection
A variant that uses a weighted sum of grayscale gradient and Laplacian terms for particle projection onto isosurfaces [S2, unofficial].
*   **Step:** In the early iteration stage, set weight $\alpha$ high and $\beta$ low so the grayscale term dominates, leveraging its quadratic convergence to quickly pull particles to the surface vicinity [S2, unofficial]. As iteration proceeds, gradually increase the weight of the second-order gradient (Laplacian) term, allowing particles to finely adjust to edge positions indicated by zero-crossings of the second-order gradient [S2, unofficial]. Dynamically adjust step size based on gradient magnitude: enlarge step size in regions with small gradients to accelerate convergence; reduce step size in regions with large gradients to ensure accuracy [S2, unofficial]. Repeat the projection process until particle positions stabilize, achieving precise projection onto edge positions on the isosurface [S2, unofficial].
*   **Formula:** The particle position update $\Delta p$ is a weighted sum of the grayscale gradient term $\Delta p_{grayscale}$ and the Laplacian term $\Delta p_{lapdaction}$, with dynamic weights $\alpha$ and $\beta$:
    $$ \Delta p = \alpha \cdot \Delta p_{grayscale} + \beta \cdot \Delta p_{lapdaction} $$

## Operating characteristics
*   **Time Complexity:** Depends on the distribution of gradients. In smooth regions, steps are large, reducing sample count. In boundary-heavy regions, steps are small, increasing sample count. Overall, it achieves efficiency gains of 2-3x over uniform sampling [S1].
*   **Memory Complexity:** Same as uniform sampling, as it does not require additional data structures beyond the volume and ray state [S1].
*   **Measured Performance:** Achieves 2-3x speedup over uniform sampling without aliasing artifacts in boundary-heavy volumes like CT angiography data [S1].
*   **Strengths:** Enhances detail preservation in boundary-heavy volumes; coarsens traversal in smooth interiors; no aliasing artifacts in boundary-heavy volumes [S1].
*   **Limitations:** Performance may degrade in volumes with high-frequency noise or complex internal structures where gradients are consistently high [G].
*   **When to Use:** Boundary-heavy volumes like CT angiography data [S1].
*   **When Not to Use:** Volumes with uniform density or where performance is critical and detail preservation is less important [G].

## Background
Gradient-driven sampling is a technique used in volume ray casting to optimize the sampling process along rays [S1]. It is integral to front-to-back compositing pipelines and can reduce rendering time in datasets with sparse opaque features, like medical scans [S1].
