# Structure-aware sampling

Also called: SDF-based adaptive sampling, adaptive sphere tracing

## Overview
Structure-aware sampling is an adaptive ray marching algorithm that uses a Signed Distance Function (SDF) and its filtered gradient to determine step sizes, ensuring efficient traversal and accurate surface intersection [S1]. It leverages structural information from LiDAR point clouds and neural fields to skip free space via an occupancy map and avoid false revert steps in unconverged neural distance fields (NDFs) by incorporating a predicted scale parameter [S1]. It sets itself apart from standard sphere tracing by using a filtered slope to modulate step size and a specific stability check involving the scale $\beta_i$ to handle the uncertainty of learned SDFs [S1].

## How it works
**Inputs and Outputs:**
*   **Input:** Rendering direction $\mathbf{d}$, camera origin, neural field function $f_S(\mathbf{x})$ which returns $(s, \beta)$, transmittance threshold $\epsilon_T = 0.001$, relaxation coefficient $\gamma = 0.7$, and a visible-aware occupancy map for free-space skipping [S1].
*   **Output:** Ray samples $\{t_i, m_i\}$, where $t_i$ is the ray parameter and $m_i$ is the filtered slope at that step [S1].

**Data Structures:**
*   **Ray State:** Current position $\mathbf{x}(t_i)$, current ray parameter $t_i$, current SDF value $s_i$, current scale $\beta_i$, current filtered slope $m$, current transmittance $T$ [S1].
*   **Occupancy Map:** A data structure mapping 3D space to visibility status, used to skip free space [S1].

**Parameters:**
*   $\gamma = 0.7$: Relaxation coefficient for filtering the gradient [S1].
*   $\epsilon_T = 0.001$: Transmittance threshold for termination [S1].

**Algorithm Steps:**
1.  Initialize $t_i = 0$, query $f_S(\mathbf{x}(t_i))$ to get $(s_i, \beta_i)$, set $m = -1$, and $T = 1$ [S1].
2.  Check if the ray should continue: loop while $s_i > 0$ (outside surface) OR $T > \epsilon_T$ (not fully opaque) [S1].
3.  Calculate adaptive step size $\delta_i = |s_i| \cdot \frac{1 - m}{2}$ [S1].
4.  Advance ray: $t_{i+1} = t_i + \delta_i$ [S1].
5.  Query neural field at new position: $(s_{i+1}, \beta_{i+1}) = f_S(\mathbf{x}(t_{i+1}))$ [S1].
6.  Verify step stability: If $\delta_i \le |s_i| + |s_{i+1}| + 3\beta_i$, proceed to update transmittance and slope; otherwise, revert [S1].
7.  Update Transmittance: $T = T \cdot \exp(-\sigma(s_i, \beta_i, m) \cdot \delta_i)$ [S1]. The density $\sigma$ is derived from the SDF, scale, and filtered slope to avoid expensive analytical gradients [S1].
8.  Estimate Gradient Slope: $M = (s_{i+1} - s_i) / \delta_i$ [S1].
9.  Filter Gradient: $m = \gamma m + (1 - \gamma) M$ [S1].
10. Record Sample: Store $(t_i, m_i) = (t_{i+1}, m)$ [S1].
11. If the stability check failed (step 6), revert: set $m = -1$ and do not update the ray parameter $t_i$ (the loop repeats at the current position) [S1].
12. Update state for next iteration: $t_i = t_{i+1}$, $s_i = s_{i+1}$, $\beta_i = \beta_{i+1}$ only occur inside the successful step branch [S1].

**Pseudocode:**
```python
import math

def structure_aware_sampling(camera_origin, direction, neural_field, occupancy_map, epsilon_T=0.001, gamma=0.7):
    """
    Performs structure-aware sampling along a ray.
    
    Args:
        camera_origin: 3D vector, start of the ray.
        direction: 3D vector, normalized ray direction.
        neural_field: Function f_S(x) returning (s, beta).
        occupancy_map: Function or structure to check if a point is in free space.
        epsilon_T: Transmittance threshold for termination.
        gamma: Relaxation coefficient for slope filtering.
        
    Returns:
        List of tuples (t, m) representing ray samples.
    """
    samples = []
    t = 0.0
    x = camera_origin + t * direction
    s, beta = neural_field(x)
    m = -1.0
    T = 1.0
    
    while s > 0 or T > epsilon_T:
        delta = abs(s) * (1 - m) / 2
        t_next = t + delta
        x_next = camera_origin + t_next * direction
        s_next, beta_next = neural_field(x_next)
        
        if delta <= abs(s) + abs(s_next) + 3 * beta:
            # [G] Exact SDF-to-density formula not given in sources; standard conversion applied here.
            sigma = max(0.0, -s / beta) if beta > 0 else 0.0
            T = T * math.exp(-sigma * delta)
            M = (s_next - s) / delta
            m = gamma * m + (1 - gamma) * M
            samples.append((t_next, m))
            t = t_next
            s = s_next
            beta = beta_next
        else:
            m = -1.0
    return samples
```

**Edge Cases and Pitfalls:**
*   **False Reverts:** In unconverged Neural Distance Fields (NDFs), standard sphere tracing might trigger false reverts [S1]. This method avoids this by including the predicted scale $\beta_i$ in the intersection check condition ($\delta_i \le |s_i| + |s_{i+1}| + 3\beta_i$) [S1].
*   **Local Minima:** The algorithm continues marching even behind surfaces (when $s_i < 0$) to avoid getting stuck in poor local minima, terminating only when transmittance $T$ falls below $\epsilon_T$ [S1].
*   **Gradient Estimation:** The filtered slope $m$ is used in the SDF-to-density transition to avoid expensive analytical or numerical gradient calculations [S1].
*   **Precision and Boundaries:** Not given in the sources.

## Operating characteristics
*   **Time Complexity:** Adaptive; steps are larger in free space (skipped via occupancy map) and smaller near surfaces (higher sampling frequency for accurate slope estimation) [S1].
*   **Memory Complexity:** Depends on the neural field and occupancy map storage. The algorithm itself uses constant memory per ray [S1].
*   **Strengths:** Efficiently skips free space using an occupancy map; handles unconverged neural fields robustly by accounting for scale $\beta_i$; avoids expensive gradient calculations by using filtered slopes [S1].
*   **Limitations:** Relies on the quality of the neural field $f_S$ and the occupancy map; requires tuning of $\gamma$ and $\epsilon_T$ [S1].
*   **When to Use:** Rendering scenes with LiDAR data and neural surface representations where free-space skipping and robust handling of learned SDFs are beneficial [S1].

## Background
Structure-aware sampling was introduced in the context of neural surface reconstruction and rendering for LiDAR-visual systems [S1]. It builds on the principles of sphere tracing and adaptive ray marching, specifically addressing the challenges of rendering neural signed distance functions (NDFs) derived from LiDAR point clouds [S1]. The method was developed to improve efficiency and accuracy in dynamic scenes where LiDAR points may traverse dynamic objects and static backgrounds [S1].
