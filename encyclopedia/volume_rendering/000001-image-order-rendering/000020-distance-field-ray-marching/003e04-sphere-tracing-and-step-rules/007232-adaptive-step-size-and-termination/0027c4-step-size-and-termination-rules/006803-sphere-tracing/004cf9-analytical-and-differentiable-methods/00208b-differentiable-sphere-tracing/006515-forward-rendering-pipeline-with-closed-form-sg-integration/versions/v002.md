# Forward Rendering Pipeline with Closed-Form SG Integration

Also called: Forward Rendering Pipeline

## Overview
This method performs differentiable forward rendering of scenes defined by Signed Distance Functions (SDFs) and Spherical Gaussian (SG) approximations for appearance [S1]. It solves the rendering equation by representing both the environment lighting and the Bidirectional Reflectance Distribution Function (BRDF) as SGs, allowing the integral to be computed in closed form [S1]. It sets itself apart from sibling methods by explicitly modeling the specular component via SGs for relighting, rather than relying solely on neural radiance fields or implicit neural representations without explicit physics-based material parameters [G].

## How it works
**Inputs:**
*   Ray origin $o$ and direction $d$ [S1].
*   Scene geometry defined by SDF $S(x; \Theta)$ and its parameters $\Theta$ [S1].
*   Appearance parameters: environment map represented by $M$ SGs with parameters $\{\xi_k, \lambda_k, \mu_k\}_{k=1}^M$, specular BRDF parameters $\{\lambda, \mu\}$, and diffuse albedo MLP parameters $\Phi$ [S1].

**Outputs:**
*   Observed color $L_o(\omega_o; x)$ for the ray [S1].

**Data Structures:**
*   **Spherical Gaussian (SG):** Defined by amplitude $\xi$, sharpness $\lambda$, and direction $\mu$ [G].
*   **MLP:** A multi-layer perceptron mapping position $x$ to diffuse albedo $a$ [S1].

**Steps:**
1.  **Sphere Tracing:** Find the intersection point $x$ between the ray $r = o + td$ and the surface $S(x; \Theta)$ using sphere tracing [S1].
2.  **Normal Computation:** Compute the surface normal $n = \nabla_x S$ at $x$ using automatic differentiation [S1].
3.  **Albedo Computation:** Compute the diffuse albedo $a(x; \Phi)$ at $x$ by evaluating the MLP [S1].
4.  **Closed-Form Integration:** Compute the color for ray $r$ by evaluating the rendering equation in closed form using the SG approximation with $n$, environment map parameters, $a$, specular BRDF parameters, and viewing direction $d$ [S1].

**Formulas:**
The rendering equation involves the incident radiance $L_i(\omega_i)$ and the BRDF $f_r(\omega_o, \omega_i; x) = \pi a + f_s(\omega_o, \omega_i; x)$, both represented with SGs [S1]. The geometry term $\omega_i \cdot n$ is approximated as an SG [S1]:
$$
\omega_i \cdot n \approx G(\omega_i; 0.0315, n, 32.7080) - 31.7003 \quad (9)
$$
The observed color $L_o(\omega_o; x)$ is computed by integrating the multiplication of the environment map SGs, the warped specular BRDF SG, and the geometry term approximation in closed form [S1].

**Parameters:**
*   $\{\xi_k, \lambda_k, \mu_k\}_{k=1}^M$: Environment map SG parameters [S1].
*   $\{\lambda, \mu\}$: Specular BRDF parameters [S1].
*   $\Phi$: Diffuse albedo MLP parameters [S1].

**Edge Cases:**
*   Precision in automatic differentiation for normal computation [S1].
*   Degenerate input where the ray does not intersect the surface is handled by sphere tracing termination rules from the parent method [G].

**Pseudocode:**
```python
import numpy as np

def forward_rendering_pipeline(ray_o, ray_d, sdf_fn, env_sg_params, brdf_params, albedo_mlp_params, max_steps=64, tol=1e-4):
    # Step 1: Sphere Tracing to find intersection x
    t = 0.0
    for _ in range(max_steps):
        x = ray_o + t * ray_d
        dist = sdf_fn(x)
        if dist < tol:
            break
        t += dist
    else:
        return np.zeros(3)  # No intersection found

    # Step 2: Compute normal n = ∇_x S at x via automatic differentiation
    eps = 1e-5
    n = np.zeros(3)
    for i in range(3):
        x_plus = x.copy(); x_plus[i] += eps
        x_minus = x.copy(); x_minus[i] -= eps
        n[i] = (sdf_fn(x_plus) - sdf_fn(x_minus)) / (2 * eps)
    n = n / np.linalg.norm(n)

    # Step 3: Compute diffuse albedo a(x; Φ) at x
    a = albedo_mlp_forward(x, albedo_mlp_params)

    # Step 4: Compute color by evaluating rendering equation in closed form with SG approximation
    color = closed_form_sg_integration(env_sg_params, brdf_params, n, ray_d, a)
    return color

def albedo_mlp_forward(x, params):
    # MLP evaluation for diffuse albedo [S1]
    w1, b1, w2, b2 = params
    h = np.maximum(0, x @ w1 + b1)
    return np.maximum(0, h @ w2 + b2)

def closed_form_sg_integration(env_sg_params, brdf_params, n, view_dir, albedo):
    # Integrates multiplication of environment SGs, warped specular BRDF, and geometry term approximation [S1]
    total_color = np.zeros(3)
    for xi, lam, mu in env_sg_params:
        # Approximate geometry term ω_i · n as SG: G(ω_i; 0.0315, n, 32.7080) - 31.7003
        geo_sg = (0.0315, n, 32.7080)
        geo_offset = -31.7003
        # Combine environment SG, specular BRDF SG, and geometry SG
        combined_sg = sg_product(xi, lam, mu, brdf_params, geo_sg)
        # Integrate combined SG over hemisphere
        total_color += sg_hemisphere_integral(combined_sg, view_dir) * albedo
    return total_color

def sg_product(xi1, lam1, mu1, brdf_params, geo_sg):
    # Standard closed-form product of Spherical Gaussians [G]
    xi2, lam2, mu2 = brdf_params[0], brdf_params[1], brdf_params[2]
    xi3, lam3, mu3 = geo_sg
    lam_c = lam1 + lam2 + lam3
    mu_c = (lam1 * mu1 + lam2 * mu2 + lam3 * mu3) / lam_c
    xi_c = xi1 * xi2 * xi3 * np.exp(-0.5 * lam_c * (1 - np.dot(mu1, mu2)) - 0.5 * lam_c * (1 - np.dot(mu2, mu3)))
    return (xi_c, lam_c, mu_c)

def sg_hemisphere_integral(sg, view_dir):
    # Standard integral of an SG over the hemisphere [G]
    xi, lam, mu = sg
    return xi * (2 * np.pi / (lam + 1)) * max(0, np.dot(mu, view_dir))
```

## Subtopics

### Closed-Form SG Integration for Rendering
Integrates the multiplication of Spherical Gaussians representing the environment map, warped specular BRDF, and geometry term approximation in closed form to compute the observed color $L_o(\omega_o; x)$ [S1]. The optimizable parameters are $\{\xi_k, \lambda_k, \mu_k\}_{k=1}^M$ (environment map), $\{\lambda, \mu\}$ (specular BRDF), and $\Phi$ (diffuse albedo MLP) [S1].

## Operating characteristics
*   **Time Complexity:** Not given in the sources.
*   **Memory Complexity:** Not given in the sources.
*   **Strengths:** Fully differentiable with respect to all parameters, enabling inverse rendering and optimization [S1]. Closed-form integration avoids sampling noise [G].
*   **Limitations:** Relies on the SG approximation for the BRDF and geometry term, which may not capture all high-frequency lighting effects perfectly [G].
*   **When to use:** When differentiable rendering with explicit material parameters and relighting capabilities is required [G].
*   **When not to use:** When high-fidelity global illumination beyond SG approximation is needed without significant computational overhead [G].

## Background
Originated in the PhySG paper (Li et al., 2021) [S1]. It builds on [Differentiable Sphere Tracing](2316-differentiable-sphere-tracing.md) by adding a physics-based appearance model using Spherical Gaussians [G]. It is used for inverse rendering, material editing, and relighting of 3D scenes [S1].
