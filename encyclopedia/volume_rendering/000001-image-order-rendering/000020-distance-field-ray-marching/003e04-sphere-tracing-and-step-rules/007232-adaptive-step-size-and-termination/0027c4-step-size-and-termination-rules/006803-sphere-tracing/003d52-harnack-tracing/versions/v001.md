# Harnack Tracing

Also called: Ray Tracing Harmonic Functions

## Overview
Harnack tracing is a method for efficiently computing the first zero-crossing along a ray for (near-)harmonic functions, analogous to sphere tracing for signed distance functions [S1]. It visualizes surfaces encoded by harmonic functions (including angle-valued functions and those with singularities) by using conservative Harnack bounds on the growth of harmonic functions to determine step sizes, avoiding numerical issues common to generic root finding methods [S2, unofficial]. Unlike sphere tracing which uses distance bounds, Harnack tracing uses bounds on the growth of harmonic functions [S2, unofficial].

## How it works
**Inputs and Outputs:**
- Input: A ray $r(t) = \mathbf{o} + t\mathbf{d}$, a harmonic function $h(\mathbf{x})$, and a target level set value (typically 0).
- Output: The distance $t$ to the first zero-crossing along the ray.

**Data Structures:**
- The harmonic function $h(\mathbf{x})$ is evaluated pointwise. In specific implementations involving dipole sums, the function is represented as a sum of dipole contributions [S1].

**Algorithm Steps:**
1. Initialize the current position on the ray, $t = t_{near}$, and the current function value $v = h(r(t))$.
2. While $|v|$ is greater than a convergence threshold $\epsilon$:
   a. Compute a conservative upper bound on the growth of the harmonic function from the current position to a candidate next position. This bound ensures that the step size does not cross a level set boundary without detection [S2, unofficial].
   b. Determine the step size $\Delta t$ based on this bound. The step size is chosen such that the function value cannot change sign within the interval $[t, t + \Delta t]$ unless a zero-crossing is present, but the bound is tight enough to allow large steps [S2, unofficial].
   c. Advance the position: $t \leftarrow t + \Delta t$.
   d. Evaluate the harmonic function at the new position: $v \leftarrow h(r(t))$.
3. Return $t$.

**Formulas:**
The core mechanism relies on Harnack's inequality, which provides bounds on the ratio of values of a positive harmonic function at two points. For a general harmonic function, conservative bounds on the growth are used to estimate the maximum possible change in the function value over a step [S2, unofficial]. The exact formula for the bound depends on the specific representation of the harmonic function (e.g., dipole sum) and the geometry of the domain [S1][S2, unofficial].

**Parameters:**
- Convergence threshold $\epsilon$: Not given in the sources.
- Near/Far limits: Defined by the ray's clipping planes [S1].

**Edge Cases and Pitfalls:**
- **Numerical Stability:** The method avoids numerical issues common to generic root finding methods by relying on conservative bounds rather than derivative-based convergence [S2, unofficial].
- **Performance:** In practice, for certain representations like fast primal queries in dipole sums, Harnack tracing provides negligible acceleration compared to standard ray marching because the fast queries contribute only minor overhead to the overall inverse rendering runtime [S1].
- **Singularities:** The method can handle harmonic functions with singularities, such as angle-valued functions [S2, unofficial].

## Operating characteristics
- **Time Complexity:** Computes the first zero-crossing with logarithmic complexity in terms of the number of dipole sum queries [S1].
- **Memory Complexity:** Not given in the sources.
- **Measured Performance:** In practice, for fast primal queries in dipole sum representations, Harnack tracing provides negligible acceleration compared to standard ray marching because the fast queries contribute only minor overhead to the overall inverse rendering runtime [S1].
- **Strengths:** Avoids numerical issues common to generic root finding methods; can visualize surfaces directly from point clouds or polygon soup without linear solves or mesh extraction [S2, unofficial]; handles singularities and angle-valued functions [S2, unofficial].
- **Limitations:** May provide negligible acceleration in some contexts [S1]; requires a harmonic function representation [S2, unofficial].
- **When to Use:** When visualizing surfaces encoded by harmonic functions, especially those with singularities or from point clouds/polygon soup [S2, unofficial].
- **When Not to Use:** When standard ray marching is sufficient and the overhead of computing Harnack bounds is not justified by the performance gain [S1].

## Background
Harnack tracing was introduced by Gillespie et al. in 2024 as a method for visualizing surfaces encoded by harmonic functions [S1][S2, unofficial]. It is analogous to sphere tracing for signed distance functions [S1]. The method allows for the visualization of smooth surfaces directly from point clouds (via Poisson surface reconstruction) or polygon soup (via generalized winding numbers) without linear solves or mesh extraction [S2, unofficial]. It is also used to visualize nonplanar polygons, surfaces from architectural geometry, mesh "exoskeletons", and key mathematical objects including knots, links, spherical harmonics, and Riemann surfaces [S2, unofficial].
