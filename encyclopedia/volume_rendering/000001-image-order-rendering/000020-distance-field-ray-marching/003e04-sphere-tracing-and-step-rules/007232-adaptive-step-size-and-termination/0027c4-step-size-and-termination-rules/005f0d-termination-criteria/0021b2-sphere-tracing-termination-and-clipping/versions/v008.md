# Sphere Tracing Termination and Clipping

Also called: Sphere Tracing Stopping Criteria, Sphere Tracing Termination Conditions

## Overview
Sphere Tracing Termination and Clipping defines the conditions under which a ray-marching loop halts, ensuring the algorithm returns a valid intersection point or correctly identifies a miss. It solves the problem of premature termination (missing surfaces due to large steps) and infinite loops (rays escaping to infinity or oscillating). It sets itself apart from sibling methods like [Standard Constant Step Ray Marching](1080-standard-constant-step-ray-marching.md) by leveraging the Lipschitz continuity of the Signed Distance Function (SDF) to guarantee safety without fixed step sizes, and from [Interval Raymarching](13020-interval-raymarching.md) by relying on point-wise distance evaluations rather than interval arithmetic bounds.

## How it works
The method operates on a ray defined by origin $\mathbf{o}$ and normalized direction $\mathbf{d}$, parameterized by distance $t$. The core loop evaluates the SDF $f(\mathbf{p})$ at $\mathbf{p} = \mathbf{o} + t\mathbf{d}$ to determine step size and check termination.

### Inputs and Outputs
*   **Inputs:** Ray origin $\mathbf{o}$, ray direction $\mathbf{d}$, SDF function $f(\mathbf{p})$, maximum iteration count $k_{max}$, stopping distance threshold $\delta$, far plane clipping depth $t_{clip}$, and optional oscillation tolerance.
*   **Outputs:** Boolean `hit` (true if surface intersected), final distance $t$, and intersection point $\mathbf{p}$.

### Data Structures
*   **State:** Current distance $t$, previous distance $t_{prev}$ (for oscillation check), minimum screen-space distance $d_{min}$ (for screen-space selection), and corresponding point $\mathbf{p}_{min}$.
*   **Constants:** $\delta = 0.0003$ [S1], $k_{max} = 200$ [S1], $t_{clip} = 5.0$ [S1].

### Numbered Steps
1.  **Initialization:** Set $t = 0.0$, $t_{prev} = 0.0$, $d_{min} = \infty$, $\mathbf{p}_{min} = \mathbf{o}$.
2.  **Iteration Loop:** For $i$ from $0$ to $k_{max} - 1$:
    a.  **Far Plane Clip:** If $t > t_{clip}$, terminate and return `hit = false` [S1].
    b.  **Position Evaluation:** Compute $\mathbf{p} = \mathbf{o} + t\mathbf{d}$.
    c.  **SDF Evaluation:** Compute $d = f(\mathbf{p})$.
    d.  **Surface Hit Check:** If $d < \delta$, terminate and return `hit = true`, $t$ [S1].
    e.  **Oscillation Check:** If $|t - t_{prev}| < 6\delta$, terminate and return `hit = false` (or handle as miss) [S1].
    f.  **Screen-Space Tracking:** If $d < d_{min}$, update $d_{min} = d$ and $\mathbf{p}_{min} = \mathbf{p}$ [S5, unofficial].
    g.  **Step Size Calculation:** Compute $\Delta t = d$ (assuming unit Lipschitz constant) or $\Delta t = d / \lambda$ [S2].
    h.  **Advance:** Set $t_{prev} = t$, then $t = t + \Delta t$.
3.  **Post-Loop Handling:**
    a.  If loop finished without hit:
        i.  **Screen-Space Selection:** If using screen-space intersection selection, return `hit = false` but use $\mathbf{p}_{min}$ as the closest approach point for shading or aura elimination [S5, unofficial].
        ii. **Dynamic Epsilon:** If secondary rays, compute $\epsilon_{dynamic} = 2\max(\epsilon_{min}, |f(\mathbf{p})|)$ to prevent self-intersection [S5, unofficial].

### Formulas
*   **Stopping Criterion:** Terminate if $d < \delta$ [S1].
*   **Oscillation Detection:** Terminate if $|t_{current} - t_{previous}| < 6\delta$ [S1].
*   **Cone Tracing Threshold (Adaptive):** $\hat{\epsilon}(\hat{s}) = \hat{s} \hat{r}_p$, where $\hat{s}$ is distance in undeformed space and $\hat{r}_p$ is pixel radius in undeformed space [S2].
*   **Pixel Radius in Undeformed Space:** $\hat{r}_p = s r_p J_D^{-1}$, where $s$ is distance in deformed space, $r_p$ is pixel radius in deformed space, and $J_D^{-1}$ is the inverse Jacobian determinant [S2].
*   **Dynamic Epsilon:** $\epsilon_{dynamic} = 2\max(\epsilon_{min}, |f(\mathbf{p})|)$ [S5, unofficial].

### Parameters
*   $\delta = 0.0003$: Stopping distance threshold [S1].
*   $k_{max} = 200$: Maximum sphere tracing iterations [S1].
*   $t_{clip} = 5.0$: Far plane clipping depth [S1].
*   $\epsilon_{min}$: Minimum epsilon value to prevent precision issues when $f(\mathbf{p}) \approx 0$ [S5, unofficial].

### Edge Cases and Pitfalls
*   **Oscillation:** Rays may oscillate near the surface if the step size is not reduced sufficiently. The check $|t_{current} - t_{previous}| < 6\delta$ detects this and terminates the ray to prevent infinite loops [S1].
*   **Self-Intersection:** Secondary rays (refraction/reflection) may immediately re-intersect the surface due to floating-point inaccuracies. Using a global $\epsilon$ is insufficient; dynamic epsilon based on local $f(\mathbf{p})$ is required [S5, unofficial].
*   **Surface Swimming:** If the error threshold $\hat{\epsilon}$ is too high, the surface appears to shift position depending on the view direction [S2].
*   **Grazing Rays:** Standard termination may miss grazing intersections, causing "aura" artifacts. Screen-space tracking allows selecting the closest point even if the ray does not strictly intersect within $\delta$ [S5, unofficial].

### Pseudocode
```python
def sphere_trace_termination_and_clipping(ray_origin, ray_direction, sdf_func, 
                                          max_iterations=200, delta=0.0003, 
                                          far_plane_clip=5.0, use_screen_space=False):
    t = 0.0
    t_prev = 0.0
    d_min = float('inf')
    p_min = ray_origin
    
    for i in range(max_iterations):
        # Far plane clipping
        if t > far_plane_clip:
            return False, t, ray_origin + ray_direction * t
        
        p = ray_origin + ray_direction * t
        d = sdf_func(p)
        
        # Surface hit check
        if d < delta:
            return True, t, p
        
        # Screen-space tracking for grazing rays
        if use_screen_space and d < d_min:
            d_min = d
            p_min = p
            
        # Oscillation check
        if abs(t - t_prev) < 6 * delta:
            # Terminate to prevent infinite loop
            if use_screen_space:
                return False, t, p_min
            return False, t, p
            
        # Step size calculation (assuming Lipschitz constant lambda = 1)
        # In general: step = d / lambda
        step = d
        
        # Advance
        t_prev = t
        t += step
        
    # Max iterations reached
    if use_screen_space:
        return False, t, p_min
    return False, t, ray_origin + ray_direction * t
```

## Subtopics

### [Affine Arithmetic Early Skip Test](4313-affine-arithmetic-early-skip-test.md)
A constant-time heuristic to detect non-collision within a working interval, avoiding expensive root-finding.

### [Dynamic Epsilon for Self-Intersection Prevention](4318-dynamic-epsilon-for-self-intersection-prevention.md)
Computes a local offset $\varepsilon_{\text{dynamic}}$ at each intersection to prevent self-intersection artifacts in secondary rays.

### [Convex Object Optimization](4367-convex-object-optimization.md)
Accelerates interior traversal by using convex bounding volumes to determine entry and exit points, reducing iterations.

### [Discontinuity Reduction via Fixed-Point Iteration](4368-discontinuity-reduction-via-fixed-point-iteration.md)
Post-processing step to smooth discontinuities in $f(p)$ and reduce procedural texturing artifacts.

### [Ray Intersection with Grazing Point Detection](4463-ray-intersection-with-grazing-point-detection.md)
Tracks the grazing point (tangent contact) during marching to resolve contacts missed by standard termination.

### [Gradient Magnitude Windowing](8299-gradient-magnitude-windowing.md)
Binary filtering technique discarding samples with gradient magnitude below a threshold $t_g$ to reduce noise.

### Cone Tracing Error Threshold
A method to determine the adaptive error threshold $\hat{\epsilon}$ based on ray distance and pixel footprint, ensuring rays terminate when the pixel cone intersects the surface [S2]. The threshold is calculated as $\hat{\epsilon}(\hat{s}) = \hat{s} \hat{r}_p$, where $\hat{s}$ is the distance along the ray in undeformed space and $\hat{r}_p$ is the radius of one pixel in undeformed space [S2]. The pixel radius is computed as $\hat{r}_p = s r_p J_D^{-1}$, where $s$ is distance in deformed space, $r_p$ is pixel radius in deformed space, and $J_D^{-1}$ is the inverse Jacobian determinant [S2]. This threshold is applied during adaptive integration to bound error [S2]. If the threshold is too high, artifacts manifest as the surface "swimming", appearing in different places depending on view direction [S2].

### Blend Mode
A rendering mode that traverses voxels and sums their value until value accumulation results in enough content, either being opaque for early termination or containing greater than zero content for blending with a user-specified background [S3, unofficial]. The high cost of voxel access can shrink or invert performance gains of block walking and culling in this mode [S3, unofficial].

### Optimized Binary Search with Local Lipschitz Bounds
A binary search method that recursively subdivides an interval, using local Lipschitz bounds to exclude intervals earlier and shrink sub-intervals asymmetrically [S4]. The interval $e=[a,b]$ is shrunk to $[e_a, e_b]$ using $e_a = a + |f(a)|/\lambda(e)$ and $e_b = b - |f(b)|/\lambda(e)$ [S4]. This reduces field function query count and provides timing speed-ups compared to standard binary search [S4].

### Screen-Space Intersection Selection
A technique to eliminate 'aura' artifacts caused by rays grazing objects. Instead of using the last step of a non-intersecting ray, it uses the point where the ray was closest to the object in screen space, and terminates the ray when this screen-space distance equals half the pixel distance [S5, unofficial]. If the ray does not intersect, it returns the position corresponding to the minimum screen-space distance found during the march [S5, unofficial].

### Pile-Top Ray Clipping
Clips upward-tracing rays to the top of a particle pile to prevent walking through empty cells up to the ceiling [S6, unofficial]. It runs a 64-thread compute pass to find the highest sorted particle center and clips rays to the slab under this maximum height plus the largest particle radius [S6, unofficial].

## Operating characteristics
*   **Time Complexity:** $O(k)$, where $k$ is the number of iterations until termination. Typically bounded by $k_{max}$ [S1].
*   **Memory Complexity:** $O(1)$ auxiliary space for state variables [S1].
*   **Performance:** The oscillation check and screen-space tracking add minimal overhead but significantly improve robustness against infinite loops and visual artifacts [S1][S5, unofficial]. Cone tracing adds computational cost for Jacobian evaluation but improves quality [S2].
*   **Strengths:** Guarantees no surface penetration (if Lipschitz constant is known), handles complex implicit surfaces, prevents infinite loops via oscillation detection.
*   **Limitations:** Requires Lipschitz continuity; fails for non-Lipschitz functions without modification; oscillation check may terminate rays prematurely if not tuned correctly [S1].

## Background
Originating from John C. Hart's 1994 paper "Sphere Tracing: A Geometric Method for the Antialiased Ray Tracing of Implicit Surfaces" [S1, implied context], the method has been refined to handle practical issues like oscillation and far-plane clipping. The specific parameters $\delta=0.0003$, $k_{max}=200$, and far plane clip of 5.0 are documented in the Neural Geometric Level of Detail paper [S1]. Screen-space intersection selection and dynamic epsilon were proposed to address grazing rays and self-intersection in enhanced sphere tracing [S5, unofficial]. Cone tracing was introduced to provide principled error thresholds for deformed SDFs [S2].
