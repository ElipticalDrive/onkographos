# Adaptive SDF Ray Marching with Variable Step Size

Also called: Marching SDF raycast, SDF Raycasting with Adaptive Marching, TSDF depth generation

## Overview
This method generates a synthetic depth map by marching a ray through a trilinearly interpolated Signed Distance Function (SDF) volume until the zero-crossing surface is found, primarily used for real-time camera tracking by comparing the rendered depth against incoming RGBD frames [S1, unofficial]. It differs from its parent, Predictive Adaptive SDF Ray Marching, by using a simpler step size logic based on the current distance estimate and a fixed truncation limit rather than a prediction from the previous two steps [S1, unofficial]. It is distinct from its sibling, Dynamic SDF Ray Marching with Adaptive Step Skipping, as it does not skip steps but rather adjusts the step magnitude continuously based on the local SDF value [S1, unofficial].

## How it works
**Inputs:**
*   Camera pose $T_{wc}$ (SE3 transformation from world to camera).
*   Camera intrinsics $K$.
*   Image dimensions $w \times h$.
*   TSDF volume `vol` with voxel size `vol.VoxelSizeUnits` and bounding box `bbox`.
*   Ray clipping distances `near` and `far`.
*   Boolean flag `subpix` for sub-pixel refinement.
*   Parameter `trunc_dist`: maximum step size when outside the truncation region (typically $2.0 \times$ voxel size) [S1, unofficial].

**Outputs:**
*   Depth image `imgdepth` ($w \times h$).
*   Color image `img` ($w \times h$).
*   Normal image `norm` ($w \times h$, RGBA).

**Data Structures:**
*   `vol`: A 3D grid storing trilinearly interpolated SDF values. Access is performed via `vol.GetUnitsTrilinearClamped(point)` which returns the SDF value $S$ at a world-space point, clamping to the volume bounds.
*   `bbox`: Axis-aligned bounding box defined by `bbox.Min` and `bbox.Max` in world coordinates.

**Algorithm Steps:**

1.  **Thread Initialization:**
    Compute pixel coordinates $u, v$ from thread indices:
    $$ u = \text{blockIdx.x} \times \text{blockDim.x} + \text{threadIdx.x} $$
    $$ v = \text{blockIdx.y} \times \text{blockDim.y} + \text{threadIdx.y} $$
    If $u \ge w$ or $v \ge h$, terminate the thread.

2.  **Ray Setup:**
    Compute ray origin in world space:
    $$ C_w = \text{SE3Translation}(T_{wc}) $$
    Compute ray direction in camera space by unprojecting pixel coordinates:
    $$ r_c = K.\text{Unproject}(u, v) $$
    Transform direction to world space:
    $$ r_w = \text{mulSO3}(T_{wc}, r_c) $$
    Normalize $r_w$ if not already unit length (standard unprojection usually yields direction vectors, but normalization ensures consistent step sizing).

3.  **Ray-Box Intersection:**
    Compute intersection intervals with the volume bounding box using the slab method:
    $$ t_{min}^{bound} = (\text{bbox.Min} - C_w) / r_w $$
    $$ t_{max}^{bound} = (\text{bbox.Max} - C_w) / r_w $$
    $$ t_{min} = \min(t_{min}^{bound}, t_{max}^{bound}) $$
    $$ t_{max} = \max(t_{min}^{bound}, t_{max}^{bound}) $$
    Determine the valid ray segment $[\lambda_{start}, \lambda_{end}]$:
    $$ \lambda_{start} = \max(t_{min}.x, t_{min}.y, t_{min}.z, \text{near}) $$
    $$ \lambda_{end} = \min(t_{max}.x, t_{max}.y, t_{max}.z, \text{far}) $$

4.  **Marching Loop:**
    If $\lambda_{start} < \lambda_{end}$:
    *   Initialize $\lambda = \lambda_{start}$.
    *   Initialize `lastSDF` = InvalidValue (e.g., NaN or a sentinel indicating no previous value).
    *   Initialize `minStep` = `vol.VoxelSizeUnits.x`.
    *   Initialize `step` = 0.
    *   Initialize `depth` = 0.

    While $\lambda < \lambda_{end}$:
    *   Evaluate SDF at current position:
        $$ S = \text{vol.GetUnitsTrilinearClamped}(C_w + \lambda r_w) $$
    *   **Surface Crossing Check:**
        If $S \le 0$ and `lastSDF` $> 0$:
        *   The surface was crossed between the previous step and the current step.
        *   **Sub-pixel Refinement:** If `subpix` is true, refine the depth using linear interpolation:
            $$ \lambda \leftarrow \lambda + \text{step} \times \frac{S}{\text{lastSDF} - S} $$
        *   Set `depth` = $\lambda$.
        *   Break the loop.
    *   **Step Size Update:**
        $$ \text{step} = \begin{cases} \max(S, \text{minStep}) & \text{if } S > 0 \\ \text{trunc_dist} & \text{if } S \le 0 \end{cases} $$
        *   Note: When $S > 0$, the step size is the current distance to the surface (clamped to `minStep`). When $S \le 0$ (inside the volume), the step size is fixed at `trunc_dist` to prevent overshooting the surface on subsequent iterations if the crossing wasn't detected immediately (though the crossing check usually catches it).
    *   **Advance Ray:**
        $$ \lambda \leftarrow \lambda + \text{step} $$
    *   **Update History:**
        $$ \text{lastSDF} = S $$

    Else (ray does not intersect volume):
    *   Skip to output initialization with `depth` = 0.

5.  **Normal Computation:**
    If `depth` > 0:
    *   Compute surface point in world space:
        $$ P_w = C_w + \text{depth} \cdot r_w $$
    *   Compute gradient (normal) using backward differences:
        $$ \nabla S = \text{vol.GetUnitsBackwardDiffDxDyDz}(P_w) $$
    *   Normalize normal:
        $$ N_w = \frac{\nabla S}{|\nabla S|} \quad \text{if } |\nabla S| > 0, \text{ else } (0,0,1) $$
    *   Transform normal to camera space:
        $$ N_c = \text{mulSO3inv}(T_{wc}, N_w) $$
    *   **Shading:**
        $$ \text{Color} = \text{PhongShade}(\text{depth} \cdot r_c, N_c) $$

6.  **Output Writing:**
    *   If `depth` > 0:
        *   `imgdepth(u,v)` = `depth`
        *   `img(u,v)` = `Color`
        *   `norm(u,v)` = $(N_c, 1)$
    *   Else:
        *   `imgdepth(u,v)` = InvalidValue
        *   `img(u,v)` = 0
        *   `norm(u,v)` = $(0,0,0,0)$

**Pseudocode:**

```python
def adaptive_sdf_ray_march(u, v, w, h, T_wc, K, vol, bbox, near, far, subpix, trunc_dist):
    # 1. Thread Initialization
    if u >= w or v >= h:
        return None, None, None

    # 2. Ray Setup
    C_w = T_wc.translation()
    r_c = K.unproject(u, v)
    r_w = T_wc.rotation_matrix() @ r_c
    r_w = r_w / np.linalg.norm(r_w) # Ensure unit length

    # 3. Ray-Box Intersection
    t_min_bound = (bbox.min - C_w) / r_w
    t_max_bound = (bbox.max - C_w) / r_w
    
    t_min = np.minimum(t_min_bound, t_max_bound)
    t_max = np.maximum(t_min_bound, t_max_bound)
    
    lambda_start = max(t_min[0], t_min[1], t_min[2], near)
    lambda_end = min(t_max[0], t_max[1], t_max[2], far)

    depth = 0.0
    normal_cam = np.array([0.0, 0.0, 0.0])
    color = np.array([0.0, 0.0, 0.0])

    if lambda_start < lambda_end:
        lambda_curr = lambda_start
        last_sdf = float('nan')
        min_step = vol.voxel_size_units[0]
        step = 0.0
        
        # 4. Marching Loop
        while lambda_curr < lambda_end:
            pos_world = C_w + lambda_curr * r_w
            sdf = vol.get_trilinear_clamped(pos_world)
            
            # Surface Crossing Check
            if sdf <= 0 and (np.isnan(last_sdf) or last_sdf > 0):
                # Refine if requested
                if subpix and not np.isnan(last_sdf):
                    # Linear interpolation for sub-pixel accuracy
                    # lambda_curr is the position AFTER the step that produced 'sdf'
                    # last_sdf was the value at lambda_curr - step
                    # We want to find lambda where SDF=0
                    # lambda_refined = (lambda_curr - step) + step * (last_sdf / (last_sdf - sdf))
                    # However, the source formula is: lambda <- lambda + step * S / (lastSDF - S)
                    # This implies lambda is the PREVIOUS position before the step that hit <=0?
                    # Let's re-read source: "lambda <- lambda + step * S / (lastSDF - S)"
                    # In the loop: step is calculated from PREVIOUS iteration's S?
                    # Source: "Update step: step = ... Advance: lambda <- lambda + step. Update lastSDF = S."
                    # So when we detect crossing, 'step' is the step taken to get to current 'sdf'.
                    # 'lastSDF' is the SDF at 'lambda_curr - step'.
                    # The formula adds to 'lambda' (current position).
                    # Standard linear interpolation: lambda_hit = lambda_prev + step * (last_sdf / (last_sdf - sdf))
                    # lambda_prev = lambda_curr - step
                    # lambda_hit = lambda_curr - step + step * (last_sdf / (last_sdf - sdf))
                    # lambda_hit = lambda_curr + step * (last_sdf / (last_sdf - sdf) - 1)
                    # lambda_hit = lambda_curr + step * ( (last_sdf - (last_sdf - sdf)) / (last_sdf - sdf) )
                    # lambda_hit = lambda_curr + step * ( sdf / (last_sdf - sdf) )
                    # This matches the source formula: lambda <- lambda + step * S / (lastSDF - S)
                    lambda_curr = lambda_curr + step * sdf / (last_sdf - sdf)
                
                depth = lambda_curr
                break
            
            # Step Size Update
            if sdf > 0:
                step = max(sdf, min_step)
            else:
                step = trunc_dist
            
            # Advance
            lambda_curr = lambda_curr + step
            
            # Update History
            last_sdf = sdf

    # 5 & 6. Output
    if depth > 0:
        P_w = C_w + depth * r_w
        grad = vol.get_backward_diff_gradient(P_w)
        norm_len = np.linalg.norm(grad)
        if norm_len > 0:
            N_w = grad / norm_len
        else:
            N_w = np.array([0.0, 0.0, 1.0])
        
        N_c = T_wc.rotation_matrix().T @ N_w
        
        # Phong shading placeholder
        color = phong_shade(depth * r_c, N_c)
        
        return depth, color, np.append(N_c, 1.0)
    else:
        return float('nan'), np.array([0.0, 0.0, 0.0]), np.array([0.0, 0.0, 0.0, 0.0])
```

**Parameters:**
*   `trunc_dist`: Maximum step size when the ray is inside the truncation region (SDF $\le 0$). Typical value is $2.0 \times$ voxel size [S1, unofficial].
*   `subpix`: Boolean flag enabling sub-pixel depth refinement via linear interpolation at the surface crossing [S1, unofficial].

**Edge Cases and Pitfalls:**
*   If the ray never crosses from positive to negative SDF (e.g., ray starts inside the volume or misses the volume entirely), `depth` remains 0, and outputs are set to invalid/zero values [S1, unofficial].
*   Precision issues may arise if `lastSDF` and `SDF` are very close, leading to division by near-zero in the sub-pixel refinement step. The check `lastSDF > 0` and `SDF <= 0` ensures a sign change, but numerical stability depends on the step size relative to the gradient magnitude.

## Subtopics

### Predictive Adaptive SDF Ray Marching
Uses the previous two distance estimates to predict the next step, offering potentially smoother convergence but requiring more state. [Link](19536-predictive-adaptive-sdf-ray-marching.md)

### Dynamic SDF Ray Marching with Adaptive Step Skipping
Skips steps entirely based on adaptive criteria rather than just adjusting step size. [Link](19684-dynamic-sdf-ray-marching-with-adaptive-step-skipping.md)

## Operating characteristics
*   **Time Complexity**: Per-pixel time complexity is $O(k)$, where $k$ is the number of march steps. $k$ is bounded by $\frac{\lambda_{end} - \lambda_{start}}{\text{minStep}}$ [S1, unofficial].
*   **Memory Access**: Memory access is coalesced for volume trilinear fetches when executed on a GPU, as threads in a warp typically access adjacent pixels and thus adjacent volume regions [S1, unofficial].
*   **Strengths**: Real-time performance suitable for SLAM and camera tracking; adaptive step size reduces the number of samples needed in free space compared to constant step marching.
*   **Limitations**: Performance degrades in regions with high surface curvature or thin structures where small steps are required; relies on the quality of the TSDF volume.

## Background
This method is part of a GPU-based real-time RGBD camera tracking system for large dense scene 3D reconstruction. It was described in the context of volumetric fusion and rendering using a Truncated Signed Distance Function (TSDF) volume. The approach leverages the efficiency of ray marching with adaptive step sizes to generate synthetic depth maps for comparison with incoming depth frames in an Iterative Closest Point (ICP) registration loop [S1, unofficial].
