# Sparse Voxel-based Sampling and Rendering

Also called: Sparse Voxel Ray Marching, Occupancy-Restricted Volume Integration

## Overview
A rendering pipeline that dynamically allocates voxels only where objects and surfaces exist, restricting ray marching and volume integration to occupied regions [S1]. It differs from dense volume rendering by eliminating computation in empty space, and from uniform ray marching by requiring explicit ray-voxel intersection tests to determine traversal order [S1]. It builds on [Voxel-Aware Masked Ray Sampling](11092-voxel-aware-masked-ray-sampling.md) by adding the constraint that sampling is strictly limited to allocated sparse voxels.

## How it works
**Inputs:** Camera ray origin $\mathbf{o}$ and direction $\mathbf{d}$; sparse voxel grid structure containing only occupied cells; step size ratio for sampling within voxels.
**Outputs:** Accumulated color and opacity along the ray.

**Data Structures:**
The sparse voxel grid stores only occupied voxels. Each voxel contains SDF (Signed Distance Field) and color data. The structure supports efficient ray-voxel intersection tests to identify which sparse voxels a camera ray traverses [S1].

**Steps:**
1.  **Ray-Voxel Intersection:** Perform ray-voxel intersection tests to identify the sequence of sparse voxels intersected by the camera ray [S1].
2.  **Point Sampling:** Sample points within the intersected sparse voxels using the configured step size ratio [S1]. The sampling positions are determined by the ray parameter $s$ within the voxel bounds.
3.  **Volume Rendering:** Apply volume rendering to aggregate the sampled SDF and color values along the ray [S1]. This involves accumulating opacity and color based on the sampled density/opacity values.

**Formulas:**
Let $s_i$ be the sample positions along the ray. The color $C_\lambda$ and opacity $\alpha$ at sample $i$ are derived from the sparse voxel data at position $\mathbf{o} + s_i \mathbf{d}$ [S1]. The accumulation follows standard volume rendering integration:
$$ C = \sum_{i} T_i \alpha_i C_\lambda(s_i) $$
$$ T_i = \prod_{j=0}^{i-1} (1 - \alpha_j) $$
where $T_i$ is the transmission up to sample $i$ [S1].

**Parameters:**
*   Step size ratio: Configured to balance accuracy and performance [S1].
*   Typical operating frequencies: 5 Hz for tracking, 2 Hz for optimization on synthetic Replica dataset [S1].

**Edge Cases and Pitfalls:**
*   Challenging scenarios (e.g., high complexity or noise) may reduce throughput below the typical 5 Hz/2 Hz rates [S1].
*   Precision issues may arise if the sparse voxel structure does not accurately represent thin surfaces or high-frequency details.

**Pseudocode:**
```python
def sparse_voxel_render(ray_origin, ray_direction, sparse_voxel_grid):
    # Step 1: Identify intersected sparse voxels
    intersected_voxels = ray_voxel_intersection_test(ray_origin, ray_direction, sparse_voxel_grid)
    
    if not intersected_voxels:
        return background_color, 0.0
    
    accumulated_color = [0.0, 0.0, 0.0]
    accumulated_opacity = 0.0
    transmission = 1.0
    
    # Step 2 & 3: Sample and integrate within intersected voxels
    for voxel in intersected_voxels:
        # Determine sampling range within the voxel
        t_min, t_max = voxel.intersect_range(ray_origin, ray_direction)
        
        # Sample points within the voxel using configured step size ratio
        num_samples = calculate_num_samples(t_max - t_min, voxel.step_size_ratio)
        
        for i in range(num_samples):
            t = t_min + (i + 0.5) * (t_max - t_min) / num_samples
            sample_pos = ray_origin + t * ray_direction
            
            # Retrieve SDF and color from sparse voxel
            sdf_value, color = sparse_voxel_grid.get_data(voxel, sample_pos)
            
            # Convert SDF to opacity (assuming standard mapping)
            opacity = sdf_to_opacity(sdf_value)
            
            # Volume rendering accumulation
            weight = transmission * opacity
            accumulated_color += weight * color
            accumulated_opacity += weight
            transmission *= (1.0 - opacity)
            
            # Early termination if fully opaque
            if accumulated_opacity > 0.99:
                break
                
    return accumulated_color, accumulated_opacity
```

## Subtopics

### Raycasting
Density/gradient (Post-DVRI) or color/opacity (Pre-DVRI) in each DVRI interval are generated via point sampling, commonly trilinear filtering, and composited [S2, unofficial]. Space samples are spaced at equal distances $\Delta s$. Some approaches jitter sampling positions to eliminate patterned artifacts or apply space-leaping for empty regions [S2, unofficial]. For strict iso-surface rendering, the iso-surface location is analytically computed when the ray enters a voxel [S2, unofficial]. Early ray termination is used: rays terminate when accumulated opacity reaches a value close to unity [S2, unofficial]. All samples and gradient components are computed by trilinear interpolation of grid data [S2, unofficial]. The step size $\Delta s$ should be 1 (one voxel length) if frequency content is unknown, following the Nyquist theorem [S2, unofficial].

## Operating characteristics
*   **Time Complexity:** Per-frame tracking takes ~150-200 ms; joint frame and map optimization takes 450-550 ms on a single NVIDIA RTX 3090 [S1].
*   **Memory Complexity:** Significantly less memory than dense voxel grids. For example, on the Replica office-0 scene, the method uses 1.04 MB for decoder and 0.149 MB for voxel embeddings, compared to NICE-SLAM's 238.88 MB [S1].
*   **Performance:** Typical operating frequencies are 5 Hz for tracking and 2 Hz for optimization on the synthetic Replica dataset [S1].
*   **Strengths:** Efficient memory usage by allocating voxels only where objects exist; good occlusion relationship between real and virtual objects [S1].
*   **Limitations:** Throughput may drop in challenging scenarios with high complexity or noise [S1]. Low-resolution depth maps (e.g., from iOS devices) can limit reconstruction quality [S1].

## Background
Originated from Vox-Fusion, a dense tracking and mapping system with voxel-based neural implicit representation [S1]. It was developed to achieve better reconstruction accuracy while using significantly less memory than previous methods like NICE-SLAM [S1]. The method allows for reconstruction of scenes without prior knowledge, including outdoor RGB-D sequences captured with handheld devices [S1].
