# Dartmouth Distance Sampling
Also called: PDF for Sampling, Probability Density Function (PDF) for Sampling, Segment-based Distance Sampling

## Overview
Dartmouth Distance Sampling is a Monte Carlo importance sampling technique for volume rendering that constructs a probability density function (PDF) matching the exponential transmittance component of the light transport integral to cancel it analytically [S1]. It differs from standard ray marching by treating the integration domain as a series of trapezoidal segments defined by the projected corners of the bounding box, allowing for direct sampling of the free path length rather than fixed or adaptive step iteration [S1].

## How it works
**Inputs and Outputs**
*   **Input:** Camera ray origin $O$, direction $D$, three sorted projected corner distances along the ray $t_{C,1}, t_{C,2}, t_{C,3}$, extinction coefficient $\sigma_t$, and the distance from a sample point $x$ towards the light source $d_m(x)$ [S1].
*   **Output:** A sampled distance $x$ along the ray, drawn from the constructed PDF [S1].

**Data Structures**
The method partitions the ray into three segments based on the projected box corners: $[0, t_{C,1}]$, $[t_{C,1}, t_{C,2}]$, and $[t_{C,2}, t_{C,3}]$ [S1]. Each segment $i$ stores a precomputed integral weight $\mathcal{I}_i$ representing the accumulated transmittance over that interval [S1].

**Formulas**
The PDF is constructed by combining the probability of selecting a segment with the conditional probability of selecting a distance within that segment [S1].

1.  **Segment Selection Probability:** The probability of selecting segment $i$ is proportional to the radiance scattered within that segment relative to the total maximum unoccluded radiance [S1]:
    $$ P(x \in [t_{C,i-1}, t_{C,i}]) = \frac{\mathcal{I}_i}{\text{total}} $$
    Where $\mathcal{I}_i = \int_{t_{C,i-1}}^{t_{C,i}} e^{-\sigma_t(x + d_m(x))} dx$ [S1].

2.  **Conditional Distance Probability:** Given segment $i$ is selected, the probability density for distance $x$ is the transmittance at $x$ normalized by the segment integral [S1]:
    $$ P(x | x \in [t_{C,i-1}, t_{C,i}]) = \frac{T'(x)}{\mathcal{I}_i} = \frac{e^{-\sigma_t(x + d_m(x))}}{\mathcal{I}_i} $$
    Where $T'(x)$ is the transmittance at $x$ [S1].

3.  **Final PDF:** The assembled PDF for a point $x$ relative to the projected corners is [S1]:
    $$ \text{PDF}(x) = \begin{cases} \frac{\mathcal{I}_1}{\text{total}} \cdot \frac{T'(x)}{\mathcal{I}_1} & x < t_{C,1} \\ \frac{\mathcal{I}_2}{\text{total}} \cdot \frac{T'(x)}{\mathcal{I}_2} & t_{C,1} < x < t_{C,2} \\ \frac{\mathcal{I}_3}{\text{total}} \cdot \frac{T'(x)}{\mathcal{I}_3} & \text{otherwise} \end{cases} $$
    The source notation uses $\mathcal{I}'_i$ and $\mathcal{I}'_i(x)$ interchangeably for the transmittance term, which simplifies to $T'(x)$ [S1].

**Steps**
1.  **Project Corners:** Compute the intersection distances of the ray with the bounding box geometry to obtain sorted values $t_{C,1}, t_{C,2}, t_{C,3}$ [S1].
2.  **Compute Integrals:** Calculate $\mathcal{I}_i$ for each segment by integrating the exponential transmittance function over the segment bounds [S1].
3.  **Select Segment:** Generate a uniform random number to select segment $i$ with probability $\mathcal{I}_i / \text{total}$ [S1].
4.  **Sample Distance:** Within the selected segment, sample the exact continuous distance $x$ using the conditional PDF $P(x | \text{segment } i)$ [S2, unofficial].

**Pseudocode**
```python
import math
import random

def dartmouth_distance_sampling(ray_origin, ray_dir, box_min, box_max, sigma_t, light_dir):
    # 1. Project box corners onto the ray (slab method)
    t_min = (box_min - ray_origin) / ray_dir
    t_max = (box_max - ray_origin) / ray_dir
    t_enter = max(min(t_min), min(t_max))
    t_exit = min(max(t_min), max(t_max))
    # Source defines three projected corners; we use entry, exit, and a third boundary
    t_C = sorted([t_enter, t_exit, t_exit + 1.0])
    
    # 2. Precompute segment integrals I_i
    segments = [(0.0, t_C[0]), (t_C[0], t_C[1]), (t_C[1], t_C[2])]
    I = []
    # [G] Assuming collimated light, d_m(x) is linear: d_m(x) = a*x + b
    a = light_dir.dot(ray_dir)
    b = (ray_origin - light_origin).dot(light_dir)
    k = sigma_t * (1.0 + a)
    for start, end in segments:
        if abs(k) < 1e-9:
            I_val = (end - start) * math.exp(-sigma_t * b)
        else:
            I_val = (math.exp(-k * start - sigma_t * b) - math.exp(-k * end - sigma_t * b)) / k
        I.append(I_val)
        
    total_I = sum(I)
    
    # 3. Select segment based on probability I_i / total_I
    r = random.random()
    cumulative = 0.0
    segment_idx = 0
    for i, val in enumerate(I):
        cumulative += val / total_I
        if r < cumulative:
            segment_idx = i
            break
            
    start, end = segments[segment_idx]
    
    # 4. Sample x within the segment using the conditional PDF
    # [G] Inversion sampling for exponential distribution over [start, end]
    u = random.random()
    if abs(k) < 1e-9:
        x = start + u * (end - start)
    else:
        x = -math.log(math.exp(-k * start) - u * (math.exp(-k * start) - math.exp(-k * end))) / k
        
    return x
```

**Edge Cases and Pitfalls**
*   **Geometry Mismatch:** The method fails when the exit point along the camera ray is much closer than the distance from the origin towards the light source [S1].
*   **Non-Constant Distance:** It deviates in cases where the distance to the box boundary is not constant (i.e., $d_{E,S} \neq d_{E,E}$) [S1].
*   **Discontinuities:** The presence of box corners creates a function that is not smooth, with clear differences in the rate of change around the distance of the projected corners [S1].

## Subtopics

### Segment-based Distance Sampling
A variant that explicitly discretizes the ray into segments corresponding to geometric features before applying the PDF [S1]. It sets itself apart by prioritizing geometric alignment over continuous distribution fitting, and should be chosen when scene boundaries dominate variance [S1].

### PDF for Sampling
Emphasizes the construction of the probability density function to match the integrand's exponential term [S1]. It differs by focusing on analytical cancellation of the transmittance decay, and is preferred when homogeneous media or collimated lighting are present [S1].

## Operating characteristics
*   **Complexity:** Requires computing segment integrals, which for heterogeneous media is handled by subdividing the space and multiplying transmittance evaluations at runtime rather than costly precomputation [S2, unofficial].
*   **Strengths:** Cancels the exponential transmittance term analytically, reducing variance in Monte Carlo integration [S1].
*   **Limitations:** Fails or deviates significantly when the light source geometry does not align with the camera ray's exit point or when boundary distances are not constant [S1]. The PDF is not necessarily monotonically decreasing [S1].
*   **When to use:** Homogeneous media with simple light geometries where the exponential term dominates the variance [S1].

## Background
Dartmouth Distance Sampling was introduced in the paper "Collimated Whole Volume Light Scattering in Homogeneous Finite Media" [S1]. It is part of an optimized Monte Carlo integration strategy for volume rendering that connects light rays along the camera ray to reduce redundant computations [S1].
