# SDF Light Shaping
Also called: Cylindrical light shaping, Raymarched Light Shaping, SDF-Based Light Shaping

## Overview
SDF Light Shaping is a technique for defining the geometry of volumetric light shafts using Signed Distance Functions (SDFs) during raymarching [S1, unofficial]. It solves the problem of arbitrary light volume boundaries by allowing the renderer to accumulate light only when a sample point lies within a mathematically defined shape (e.g., cylinder, cone, sphere) [S1, unofficial]. It differs from standard cone raymarching by decoupling the light's physical geometry from the ray's direction, enabling complex, non-conical volumes like cylinders or toruses to be rendered in post-processing [S1, unofficial].

## How it works
**Inputs and Outputs**
The method takes the ray origin, ray direction, light position, light direction, shape radius, step size, depth limits, and smooth edge width as inputs [S1, unofficial]. It outputs the accumulated light color for the current pixel.

**Data Structures**
No complex data structures are required; the method operates on scalar values and 3D vectors [S1, unofficial].

**SDF Definition**
The core of the method is an SDF function that returns the signed distance from a point $p$ to the surface of the light shape [S1, unofficial]. For a cylinder, the function is defined as follows [S1, unofficial]:
1. Calculate the vector from the sample point to the light's axis origin:
   $$p\_to\_origin = p - axisOrigin$$
2. Calculate the projection length of this vector onto the light's axis direction:
   $$projectionLength = dot(p\_to\_origin, axisDir)$$
3. Find the closest point on the axis to the sample point:
   $$closestPointOnAxis = axisOrigin + axisDir \times projectionLength$$
4. Calculate the Euclidean distance from the sample point to this closest point on the axis:
   $$distanceToAxis = length(p - closestPointOnAxis)$$
5. Return the signed distance by subtracting the radius:
   $$sdfVal = distanceToAxis - radius$$

**Algorithm Steps**
1. Initialize the raymarching loop with a distance variable $t$ set to $0.0$ [S1, unofficial].
2. For each step, calculate the sample position:
   $$samplePos = rayOrigin + rayDir \times t$$
3. Check boundary conditions: if $t > sceneDepth$ or $t > cameraFar$, terminate the loop [S1, unofficial].
4. Evaluate the SDF for the current $samplePos$ using the light's parameters ($lightPos$, $lightDir$, radius) [S1, unofficial].
5. Calculate the **shape factor** to determine if the point is inside the light volume and to soften the edges:
   $$shapeFactor = smoothstep(0.0, -smoothEdgeWidth, sdfVal)$$
   Here, $smoothEdgeWidth$ controls the transition softness [S1, unofficial].
6. **Early Exit Optimization:** If $shapeFactor < 0.1$, the point is considered outside the light volume. Increment $t$ by $STEP\_SIZE$ and continue to the next iteration without accumulating light [S1, unofficial].
7. If $shapeFactor \ge 0.1$, proceed with light accumulation using the $shapeFactor$ to modulate the result [S1, unofficial].

**Pseudocode**
```python
def sd_cylinder(p, axis_origin, axis_dir, radius):
    """
    Calculates the signed distance from point p to a cylinder defined by
    axis_origin, axis_dir, and radius.
    """
    axis_dir = normalize(axis_dir) # [G] Standard requirement for correct projection
    p_to_origin = p - axis_origin
    projection_length = dot(p_to_origin, axis_dir)
    closest_point_on_axis = axis_origin + axis_dir * projection_length
    distance_to_axis = length(p - closest_point_on_axis)
    return distance_to_axis - radius

def raymarch_light_shaping(ray_origin, ray_dir, light_pos, light_dir, 
                           radius, smooth_edge_width, step_size, 
                           scene_depth, camera_far):
    """
    Raymarches through a volume shaped by an SDF.
    Returns accumulated light color as a vec4.
    """
    accumulated_light = vec4(0.0, 0.0, 0.0, 1.0)
    t = 0.0
    max_dist = min(scene_depth, camera_far)
    
    # Reference implementation uses a fixed step count [S1, unofficial]
    for _ in range(1000): 
        if t > max_dist:
            break
            
        sample_pos = ray_origin + ray_dir * t
        
        # Evaluate SDF
        sdf_val = sd_cylinder(sample_pos, light_pos, light_dir, radius)
        
        # Calculate shape factor for soft edges
        # smoothstep(edge0, edge1, x)
        shape_factor = smoothstep(0.0, -smooth_edge_width, sdf_val)
        
        # Early exit if outside the light volume
        if shape_factor < 0.1:
            t += step_size
            continue
            
        # [G] Standard volumetric accumulation: add light modulated by shape factor and step size
        light_color = vec3(1.0)
        accumulated_light.rgb += light_color * shape_factor * step_size
        
        t += step_size
        
    return accumulated_light
```

**Parameters**
*   `smoothEdgeWidth`: Width of the smooth edge for the cylinder shape, set to $0.1$ [S1, unofficial].
*   `radius`: The radius of the cylinder in the example, set to $2.0$ [S1, unofficial].
*   `STEP_SIZE`: The distance advanced per raymarch step. Not explicitly defined in the sources [S1, unofficial].

**Edge Cases and Pitfalls**
*   **Smoothstep Direction:** The `smoothstep` parameters are ordered `(0.0, -smoothEdgeWidth, sdfVal)` [S1, unofficial]. Since `smoothEdgeWidth` is positive, the second argument is negative [S1, unofficial]. This ensures that when `sdfVal` is negative (inside the cylinder), the result is $1.0$, and it fades to $0.0$ as `sdfVal` becomes positive (outside) [S1, unofficial].
*   **Threshold Selection:** The threshold `0.1` for early exit is taken directly from the reference implementation [S1, unofficial].

## Operating characteristics
*   **Time Complexity:** $O(N)$ where $N$ is the number of raymarch steps per pixel [G].
*   **Memory Complexity:** $O(1)$ auxiliary memory as no voxel grids or textures are required for the shape definition [S1, unofficial].
*   **Strengths:** Allows for arbitrary light shapes (cylinders, cones, spheres, toruses) without modifying the raymarching geometry logic [S1, unofficial]. Efficient due to early exit optimization [S1, unofficial].
*   **Limitations:** The light shape is static relative to the light source's coordinate system [S1, unofficial].
*   **When to use:** When volumetric light needs to conform to specific geometric constraints (e.g., light passing through a cylindrical window or shaft) [S1, unofficial].

## Background
The technique was demonstrated by Kenny Pirman in his habitat demo scene, a 3D reconstruction of an O’Neil cylindrical world, where volumetric light was shaped as a cylinder using SDFs [S1, unofficial]. The method builds upon general raymarching techniques and SDF primitives [S1, unofficial].
