# Sphere Tracing with Represent Hit

Also called: RayMarch, Sphere Tracing with Surface/Represent Passes, SphereTracingFPass, SphereTracingKPass, Surface/Represent Ray Marching

## Overview
Sphere Tracing with Represent Hit is a deferred rendering technique that extends standard sphere tracing by tracking two distinct hit points per pixel: a primary **surface hit** (the nearest geometric intersection) and a **represent hit** (a proxy for the surface at the pixel's radius) [S1, unofficial]. This dual-pass approach is designed to handle transparency and aliasing artifacts at object edges by evaluating visibility and occlusion from both points and selecting the ray with greater visual impact (higher alpha) [S1, unofficial]. It differs from standard sphere tracing by explicitly maintaining a "represent" state to capture edge information that would otherwise be missed by a single convergence check [S1, unofficial].

## How it works
The method operates as a deferred rendering pass, writing results to two render targets: index 0 for the surface hit and index 1 for the represent hit [S1, unofficial]. It assumes a Signed Distance Field (SDF) map is available, where each sample returns a `float2` containing the distance and a material ID [S1, unofficial].

### Inputs and Outputs
**Inputs:**
*   Ray origin $\mathbf{o}$ and direction $\mathbf{d}$ (normalized) [S1, unofficial].
*   Clipping planes: `ClippingPlanes.x` (near) and `ClippingPlanes.y` (far) [S1, unofficial].
*   `SphereTracingSteps`: Maximum number of marching iterations [S1, unofficial].
*   `RadiusPixel`: The radius of the pixel in world space, used to determine the "represent" zone [S1, unofficial].
*   SDF Map: A texture or function returning `(distance, material_id)` [S1, unofficial].
*   `DisableAntiAliasing`: Boolean flag to switch between AA and non-AA variants [S1, unofficial].

**Outputs:**
*   `surfaceHit`: Structure containing `DistanceToWorld`, `TraceDistance`, `MaterialId`, and `Position` [S1, unofficial].
*   `representHit`: Structure containing `DistanceToWorld`, `Alpha`, `MaterialId`, and `Position` [S1, unofficial].

### Data Structures
The algorithm maintains two hit structures. The exact layout is inferred from the usage in [S1, unofficial]:

**Hit Structure:**
*   `DistanceToWorld`: `float` (distance from camera origin to hit point)
*   `TraceDistance`: `float` (distance along the ray for shading/lighting calculations)
*   `MaterialId`: `int` (identifier for the material at the hit point; -1 indicates no hit)
*   `Position`: `float3` (world space position of the hit)
*   `Alpha`: `float` (opacity/visual impact, specific to represent hit)

### Algorithm Steps
1.  **Initialization**:
    *   Set `surfaceHit` and `representHit` distances to `ClippingPlanes.x` and `ClippingPlanes.y` respectively [S1, unofficial].
    *   Set `surfaceHit.MaterialId = -1` and `representHit.MaterialId = -1` [S1, unofficial].
    *   Set `representHit.DistanceToWorld = 1000000` (a large value to ensure updates) [S1, unofficial].
    *   Set `representHit.Alpha = 0` [S1, unofficial].
    *   Initialize ray distance `t = ClippingPlanes.x` [S1, unofficial].
    *   Sample the SDF at `r.Origin + t * r.Direction` to get `currentMap` (distance, material ID) [S1, unofficial].
    *   Initialize loop counter `i = 0` and `representFound = false` [S1, unofficial].

2.  **Marching Loop**:
    *   Loop `i` from 0 to `SphereTracingSteps - 1` [S1, unofficial].
    *   Calculate adaptive epsilon: `epsilon = 0.0015 * t` [S1, unofficial].
    *   **Surface Hit Check**: If `currentMap.distance <= epsilon`:
        *   Set `surfaceHit.DistanceToWorld = t` [S1, unofficial].
        *   Set `surfaceHit.TraceDistance = t` [S1, unofficial].
        *   Set `surfaceHit.MaterialId = currentMap.material_id` [S1, unofficial].
        *   Set `surfaceHit.Position = r.Origin + t * r.Direction` [S1, unofficial].
        *   Break loop [S1, unofficial].
    *   **Represent Hit Logic**:
        *   Sample next point: `nextMap = Map(r.Origin + (t + currentMap.distance) * r.Direction)` [S1, unofficial].
        *   Check if inside pixel radius: If `currentMap.distance < (t * RadiusPixel)`:
            *   If `nextMap.distance > currentMap.distance` (moving away from surface) and `representFound == false`:
                *   Set `representFound = true` [S1, unofficial].
            *   If `currentMap.distance < representHit.DistanceToWorld` and (`representHit.MaterialId == -1` or `representHit.MaterialId == currentMap.material_id`):
                *   Update `representHit.DistanceToWorld = t` [S1, unofficial].
                *   Update `representHit.MaterialId = currentMap.material_id` [S1, unofficial].
                *   Update `representHit.Position = r.Origin + t * r.Direction` [S1, unofficial].
    *   **Advance Ray**:
        *   `t += currentMap.distance` [S1, unofficial].
        *   `currentMap = nextMap` [S1, unofficial].
    *   **Far Clipping Check**: If `t > ClippingPlanes.y`:
        *   Set `surfaceHit.TraceDistance = ClippingPlanes.y` [S1, unofficial].
        *   Set `surfaceHit.MaterialId = -1` [S1, unofficial].
        *   Break loop [S1, unofficial].

3.  **Post-Loop Processing**:
    *   If `representHit.MaterialId >= 0`:
        *   Calculate `representHit.Alpha = 1.0 - representHit.DistanceToWorld / (representHit.TraceDistance * RadiusPixel)` [S1, unofficial].
        *   Update `representHit.Position` (if not already set) [S1, unofficial].
    *   If loop finished without a surface hit (`i == SphereTracingSteps`):
        *   Use the latest `currentMap` data for `surfaceHit` as a fallback [S1, unofficial].
    *   If `surfaceHit.MaterialId < 0` or `representHit.MaterialId < 0`:
        *   Set corresponding `Alpha` to 0 [S1, unofficial].

4.  **Ray Marching and Evaluation**:
    *   If `DisableAntiAliasing` is true, call `RayMarchNoAA(r, surfaceHit, representHit)`; else call `RayMarch(r, surfaceHit, representHit)` [S1, unofficial].
    *   Evaluate hits: Call `EvaluateHit(id.xy, r, surfaceHit, surface)` and `EvaluateHit(id.xy, r, representHit, represent)` [S1, unofficial].
    *   Write final data: Call `WriteSphereTracingData(id.xy, 0, surface)` and `WriteSphereTracingData(id.xy, 1, represent)` [S1, unofficial].

### Pseudocode
```python
def sphere_tracing_with_represent_hit(ray_origin, ray_direction, clipping_near, clipping_far, 
                                      sphere_tracing_steps, radius_pixel, sdf_map, 
                                      disable_anti_aliasing):
    # Initialization
    surface_hit = {
        'DistanceToWorld': clipping_near,
        'TraceDistance': clipping_near,
        'MaterialId': -1,
        'Position': ray_origin + ray_direction * clipping_near
    }
    represent_hit = {
        'DistanceToWorld': 1000000.0,
        'Alpha': 0.0,
        'MaterialId': -1,
        'Position': ray_origin + ray_direction * clipping_near
    }
    
    t = clipping_near
    current_map = sdf_map(ray_origin + ray_direction * t) # Returns (distance, material_id)
    i = 0
    represent_found = False
    
    # Marching Loop
    for i in range(sphere_tracing_steps):
        epsilon = 0.0015 * t
        
        # Surface Hit Check
        if current_map.distance <= epsilon:
            surface_hit['DistanceToWorld'] = t
            surface_hit['TraceDistance'] = t
            surface_hit['MaterialId'] = current_map.material_id
            surface_hit['Position'] = ray_origin + ray_direction * t
            break
            
        # Sample Next Point
        next_map = sdf_map(ray_origin + ray_direction * (t + current_map.distance))
        
        # Represent Hit Logic
        if current_map.distance < (t * radius_pixel):
            if next_map.distance > current_map.distance and not represent_found:
                represent_found = True
            
            if current_map.distance < represent_hit['DistanceToWorld']:
                if represent_hit['MaterialId'] == -1 or represent_hit['MaterialId'] == current_map.material_id:
                    represent_hit['DistanceToWorld'] = t
                    represent_hit['MaterialId'] = current_map.material_id
                    represent_hit['Position'] = ray_origin + ray_direction * t
        
        # Advance Ray
        t += current_map.distance
        current_map = next_map
        
        # Far Clipping Check
        if t > clipping_far:
            surface_hit['TraceDistance'] = clipping_far
            surface_hit['MaterialId'] = -1
            break
            
    # Post-Loop Processing
    if represent_hit['MaterialId'] >= 0:
        # Avoid division by zero if TraceDistance is 0 or very small
        trace_denom = max(surface_hit['TraceDistance'] * radius_pixel, 1e-6)
        represent_hit['Alpha'] = 1.0 - represent_hit['DistanceToWorld'] / trace_denom
        
    if i == sphere_tracing_steps:
        # Fallback hit if loop finished without explicit break
        surface_hit['DistanceToWorld'] = t
        surface_hit['TraceDistance'] = t
        surface_hit['MaterialId'] = current_map.material_id
        surface_hit['Position'] = ray_origin + ray_direction * t
        
    if surface_hit['MaterialId'] < 0:
        surface_hit['Alpha'] = 0.0 # Assuming Alpha field exists or is handled in evaluation
    if represent_hit['MaterialId'] < 0:
        represent_hit['Alpha'] = 0.0
        
    # Ray Marching and Evaluation
    if disable_anti_aliasing:
        ray_march_no_aa(ray_origin, ray_direction, surface_hit, represent_hit)
    else:
        ray_march(ray_origin, ray_direction, surface_hit, represent_hit)
        
    evaluate_hit(surface_hit, 'surface')
    evaluate_hit(represent_hit, 'represent')
    
    write_sphere_tracing_data(0, surface_hit)
    write_sphere_tracing_data(1, represent_hit)
```

### Parameters and Edge Cases
*   **Epsilon**: The adaptive epsilon `0.0015 * t` is used to determine convergence [S1, unofficial].
*   **Radius Pixel**: This parameter defines the threshold for "represent" hits. If the SDF value is less than `t * RadiusPixel`, the point is considered within the pixel's influence [S1, unofficial].
*   **Material ID Matching**: The represent hit only updates if the material ID matches the current represent hit's material ID or if no represent hit has been found yet [S1, unofficial]. This prevents mixing materials in the represent pass.
*   **Fallback**: If the loop completes without a surface hit, the last sampled point is used as the surface hit [S1, unofficial].
*   **Pitfalls**: Precision issues may arise if `t` is very small or very large, affecting the adaptive epsilon and the alpha calculation. The large initial value for `representHit.DistanceToWorld` (1,000,000) assumes a scene scale that fits within this range [S1, unofficial].

## Operating characteristics
*   **Time Complexity**: $O(N)$ per pixel, where $N$ is `SphereTracingSteps`. The dual-pass nature (surface and represent) adds a constant factor overhead compared to single-pass sphere tracing [S1, unofficial].
*   **Memory Complexity**: Requires storage for two hit structures per pixel, plus intermediate textures for deferred rendering (e.g., `SphereTracingDataTexture`, `AmbientOcclusionTexture`) [S1, unofficial].
*   **Performance**: Performance depends on the number of steps and the complexity of the SDF evaluation. The represent hit logic adds conditional checks but does not increase the number of SDF samples [S1, unofficial].
*   **Strengths**: Reduces aliasing at object edges by capturing represent hits; handles transparency better than standard sphere tracing [S1, unofficial].
*   **Limitations**: Increased memory usage due to dual render targets; potential for artifacts if `RadiusPixel` is not tuned correctly for the scene scale [S1, unofficial].
*   **When to Use**: Deferred rendering pipelines where edge aliasing is a concern and SDFs are available [S1, unofficial].
*   **When Not to Use**: Real-time applications with strict memory constraints or where SDFs are not feasible [S1, unofficial].
