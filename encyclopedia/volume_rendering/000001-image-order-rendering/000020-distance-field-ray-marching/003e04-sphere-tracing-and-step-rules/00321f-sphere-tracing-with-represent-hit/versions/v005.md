# Sphere Tracing with Represent Hit

Also called: RayMarch, Sphere Tracing with Surface/Represent Passes, SphereTracingFPass, SphereTracingKPass, Surface/Represent Ray Marching

## Overview
Sphere Tracing with Represent Hit is a deferred rendering technique for Signed Distance Fields (SDF) that tracks both a primary surface hit and a 'represent' hit (a proxy for the surface at the pixel radius) to handle transparency and aliasing at object edges [S1, unofficial]. It selects the ray with greater visual impact (higher alpha) to trace, writing results to two render targets: index 0 for the surface and index 1 for the represent hit [S1, unofficial].

## How it works
**Inputs and Outputs:**
*   **Inputs:** Ray origin $\mathbf{o}$, ray direction $\mathbf{d}$ (normalized), SDF map function $Map(\mathbf{p})$ returning a float2 (distance, material ID), clipping planes $[ClippingPlanes.x, ClippingPlanes.y]$, maximum sphere tracing steps $N_{steps}$, and pixel radius factor $RadiusPixel$ [S1, unofficial].
*   **Outputs:** Two hit structures: `surfaceHit` and `representHit`, each containing `DistanceToWorld`, `TraceDistance`, `MaterialId`, `Position`, and `Alpha` [S1, unofficial].

**Data Structures:**
*   `HitRecord`: A structure containing:
    *   `DistanceToWorld`: float, distance from camera origin to hit point.
    *   `TraceDistance`: float, total distance traveled along ray.
    *   `MaterialId`: int, material identifier from SDF map.
    *   `Position`: vec3, 3D world position of the hit.
    *   `Alpha`: float, opacity value (0.0 to 1.0).
*   `currentMap`: float2, current SDF sample (distance, material ID).
*   `nextMap`: float2, next SDF sample.

**Parameters:**
*   $N_{steps}$: Maximum number of marching iterations (e.g., 64).
*   $RadiusPixel$: Scaling factor for pixel radius approximation.
*   $ClippingPlanes$: Near and far clipping distances.

**Algorithm Steps:**
1.  **Initialization:**
    *   Initialize `surfaceHit` and `representHit` with near plane clipping distance ($ClippingPlanes.x$) and far plane ($ClippingPlanes.y$).
    *   Set `surfaceHit.MaterialId = -1`, `representHit.MaterialId = -1`.
    *   Set `representHit.DistanceToWorld = 1000000` (large value).
    *   Set `representHit.Alpha = 0`.
    *   Initialize ray distance $t = ClippingPlanes.x$.
    *   Sample SDF at $\mathbf{p} = \mathbf{o} + t\mathbf{d}$ to get `currentMap`.
    *   Initialize loop counter $i = 0$.
    *   Initialize `representFound = false`.

2.  **Marching Loop:**
    *   Loop $i$ from 0 to $N_{steps} - 1$:
        *   Calculate adaptive epsilon: $\epsilon = 0.0015 \times t$.
        *   **Surface Hit Check:** If `currentMap.x` $\le \epsilon$:
            *   Set `surfaceHit.DistanceToWorld = t`.
            *   Set `surfaceHit.TraceDistance = t`.
            *   Set `surfaceHit.MaterialId = currentMap.y`.
            *   Set `surfaceHit.Position = \mathbf{o} + t\mathbf{d}`.
            *   Break loop.
        *   **Represent Hit Logic:**
            *   Sample next point: $\mathbf{p}_{next} = \mathbf{o} + (t + \text{currentMap}.x)\mathbf{d}$.
            *   Get `nextMap = Map(\mathbf{p}_{next})`.
            *   Check if inside pixel radius: If `currentMap.x` $< (t \times RadiusPixel)$:
                *   If `nextMap.x` $>$ `currentMap.x` (moving away from surface) and `representFound == false`:
                    *   Set `representFound = true`.
                *   If `currentMap.x` $<$ `representHit.DistanceToWorld` and (`representHit.MaterialId == -1` or `representHit.MaterialId == currentMap.y`):
                    *   Update `representHit.DistanceToWorld = t`.
                    *   Update `representHit.MaterialId = currentMap.y`.
                    *   Update `representHit.TraceDistance = t`.
                    *   Update `representHit.Position = \mathbf{o} + t\mathbf{d}`.
        *   **Advance Ray:**
            *   $t \leftarrow t + \text{currentMap}.x$.
            *   `currentMap = nextMap`.
        *   **Far Clipping Check:**
            *   If $t > ClippingPlanes.y$:
                *   Set `surfaceHit.TraceDistance = ClippingPlanes.y`.
                *   Set `surfaceHit.MaterialId = -1`.
                *   Break loop.

3.  **Post-Processing:**
    *   If loop finished without hit ($i == N_{steps}$):
        *   Use latest `currentMap` data for `surfaceHit` (fallback hit).
        *   Set `surfaceHit.DistanceToWorld = t`.
        *   Set `surfaceHit.TraceDistance = t`.
        *   Set `surfaceHit.MaterialId = currentMap.y`.
        *   Set `surfaceHit.Position = \mathbf{o} + t\mathbf{d}`.
    *   If `representHit.MaterialId >= 0`:
        *   Calculate `representHit.Alpha = 1.0 - representHit.DistanceToWorld / (representHit.TraceDistance * RadiusPixel)`.
        *   Update `representHit.Position`.
    *   If `surfaceHit.MaterialId < 0` or `representHit.MaterialId < 0`:
        *   Set corresponding `Alpha` to 0.

4.  **Final Evaluation:**
    *   Perform ray marching: If `DisableAntiAliasing` is true, call `RayMarchNoAA(r, surfaceHit, representHit)`; else call `RayMarch(r, surfaceHit, representHit)` [S1, unofficial].
    *   Evaluate hits: Call `EvaluateHit(id.xy, r, surfaceHit, surface)` and `EvaluateHit(id.xy, r, representHit, represent)` [S1, unofficial].
    *   Write final data: Call `WriteSphereTracingData(id.xy, 0, surface)` and `WriteSphereTracingData(id.xy, 1, represent)` [S1, unofficial].

**Pseudocode:**
```python
def sphere_tracing_with_represent_hit(ray_origin, ray_direction, sdf_map, clipping_planes, max_steps, radius_pixel):
    """
    Sphere Tracing with Represent Hit algorithm.
    
    Args:
        ray_origin: vec3, camera origin
        ray_direction: vec3, normalized ray direction
        sdf_map: callable, returns (distance: float, material_id: int) for a point
        clipping_planes: tuple (near: float, far: float)
        max_steps: int, maximum number of marching steps
        radius_pixel: float, scaling factor for pixel radius
        
    Returns:
        surface_hit: dict with keys 'DistanceToWorld', 'TraceDistance', 'MaterialId', 'Position', 'Alpha'
        represent_hit: dict with keys 'DistanceToWorld', 'TraceDistance', 'MaterialId', 'Position', 'Alpha'
    """
    near_plane, far_plane = clipping_planes
    
    # Initialize surface hit
    surface_hit = {
        'DistanceToWorld': near_plane,
        'TraceDistance': near_plane,
        'MaterialId': -1,
        'Position': ray_origin + near_plane * ray_direction,
        'Alpha': 0.0
    }
    
    # Initialize represent hit
    represent_hit = {
        'DistanceToWorld': 1000000.0,
        'TraceDistance': near_plane,
        'MaterialId': -1,
        'Position': ray_origin + near_plane * ray_direction,
        'Alpha': 0.0
    }
    
    t = near_plane
    current_map = sdf_map(ray_origin + t * ray_direction)
    represent_found = False
    
    for i in range(max_steps):
        # Adaptive epsilon
        epsilon = 0.0015 * t
        
        # Surface hit check
        if current_map[0] <= epsilon:
            surface_hit['DistanceToWorld'] = t
            surface_hit['TraceDistance'] = t
            surface_hit['MaterialId'] = current_map[1]
            surface_hit['Position'] = ray_origin + t * ray_direction
            break
        
        # Sample next point
        next_point = ray_origin + (t + current_map[0]) * ray_direction
        next_map = sdf_map(next_point)
        
        # Represent hit logic
        if current_map[0] < (t * radius_pixel):
            if next_map[0] > current_map[0] and not represent_found:
                represent_found = True
            
            if current_map[0] < represent_hit['DistanceToWorld']:
                if represent_hit['MaterialId'] == -1 or represent_hit['MaterialId'] == current_map[1]:
                    represent_hit['DistanceToWorld'] = t
                    represent_hit['MaterialId'] = current_map[1]
                    represent_hit['TraceDistance'] = t
                    represent_hit['Position'] = ray_origin + t * ray_direction
        
        # Advance ray
        t += current_map[0]
        current_map = next_map
        
        # Far clipping check
        if t > far_plane:
            surface_hit['TraceDistance'] = far_plane
            surface_hit['MaterialId'] = -1
            break
    
    # Post-processing
    if i == max_steps - 1 and surface_hit['MaterialId'] == -1:
        # Fallback hit if loop finished without explicit hit
        surface_hit['DistanceToWorld'] = t
        surface_hit['TraceDistance'] = t
        surface_hit['MaterialId'] = current_map[1]
        surface_hit['Position'] = ray_origin + t * ray_direction
        
    if represent_hit['MaterialId'] >= 0:
        # Calculate alpha for represent hit
        if represent_hit['TraceDistance'] * radius_pixel != 0:
            represent_hit['Alpha'] = 1.0 - represent_hit['DistanceToWorld'] / (represent_hit['TraceDistance'] * radius_pixel)
        else:
            represent_hit['Alpha'] = 0.0
            
    if surface_hit['MaterialId'] < 0:
        surface_hit['Alpha'] = 0.0
    if represent_hit['MaterialId'] < 0:
        represent_hit['Alpha'] = 0.0
        
    return surface_hit, represent_hit
```

**Edge Cases and Pitfalls:**
*   **Precision:** Adaptive epsilon $\epsilon = 0.0015 \times t$ scales with distance, which may cause issues at very large distances or very small scales if not clamped.
*   **Boundaries:** Far clipping plane must be handled to prevent infinite loops or invalid hits.
*   **Degenerate Input:** If `TraceDistance` is zero or `RadiusPixel` is zero, division by zero occurs in alpha calculation. Guard against this.
*   **Material ID Consistency:** The represent hit only updates if the material ID matches the current hit or is uninitialized (-1). This prevents mixing materials in the represent pass.

## Operating characteristics
*   **Time Complexity:** $O(N_{steps})$ per pixel, where $N_{steps}$ is the maximum number of sphere tracing iterations. The represent hit logic adds constant overhead per step.
*   **Memory Complexity:** $O(1)$ per pixel for hit records. Requires two render targets (surface and represent).
*   **Measured Performance:** Not given in the sources.
*   **Scaling:** Performance scales linearly with resolution and maximum steps. The represent hit pass does not significantly increase computational cost as it shares the same marching loop.
*   **Strengths:** Handles transparency and aliasing at object edges by tracking a 'represent' hit. Deferred rendering allows for efficient lighting calculations.
*   **Limitations:** Requires two render targets. Alpha calculation for represent hit is heuristic and may not be physically accurate.
*   **When to use:** When rendering SDFs with transparency or soft edges where standard sphere tracing produces aliasing artifacts.
*   **When not to use:** When memory bandwidth is limited (due to two render targets) or when hard-edged opaque SDFs are sufficient.

## Background
Sphere Tracing with Represent Hit is an unofficial technique described in a GitHub repository [S1, unofficial]. It extends standard sphere tracing by introducing a secondary 'represent' hit to improve visual quality at object boundaries. The technique is implemented in a deferred rendering pipeline, integrating with ambient occlusion and environment mapping passes.
