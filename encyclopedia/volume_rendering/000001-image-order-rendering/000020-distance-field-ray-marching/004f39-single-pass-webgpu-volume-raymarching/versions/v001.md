# Single-pass WebGPU volume raymarching

Also called: raymarchScene, volume raymarcher

## Overview
This method renders volumetric data (such as magnetic field magnitude) in a single GPU pass using WebGPU, performing analytic ray-box intersection, early-alpha termination, and optional central-difference Phong shading. It differs from standard sphere tracing [Distance-field ray marching](21-distance-field-ray-marching.md) by operating on explicit 3D texture volumes rather than implicit Signed Distance Functions (SDFs), allowing for complex, non-uniform density distributions.

## How it works
**Inputs and Outputs:**
*   **Input:** A 3D texture containing volume data (e.g., density or field magnitude), camera parameters (origin $\mathbf{o}$, direction $\mathbf{d}$), and rendering parameters (steps, density scale, shading flags).
*   **Output:** A 2D color buffer (RGBA) representing the rendered volume.

**Data Structures:**
*   **Volume Texture:** A 3D texture (e.g., `texture_3d<f32>` in WGSL). The object space is defined as the unit box $[-0.5, 0.5]^3$. Texture coordinates are computed as $\mathbf{pos} + 0.5$ to map the box to $[0, 1]^3$.
*   **Transfer Function:** Maps sampled density values to color and opacity. Can be linear, logarithmic, or symlog.

**Parameters:**
*   `steps`: Number of samples per ray across the clipped segment. Default: 256 [S1, unofficial].
*   `density`: Opacity scale factor for the emission-absorption transfer function [S1, unofficial].
*   `shaded`: Boolean flag to enable Phong shading. Default: `false` [S1, unofficial].
*   `EARLY_ALPHA`: Threshold for early ray termination. Default: 0.98 [S1, unofficial].
*   `SHADE_T_FLOOR`: Minimum accumulated opacity threshold to enable gradient computation for shading. Default: $1/255$ [S1, unofficial].

**Algorithm Steps:**

1.  **Ray-Box Intersection:**
    Compute the entry ($t_{min}$) and exit ($t_{max}$) distances of the ray with the unit box $[-0.5, 0.5]^3$.
    *   Calculate inverse direction components: $inv\_dir = 1.0 / \mathbf{d}$.
    *   **Pitfall Handling:** If any component of $\mathbf{d}$ is near zero (e.g., $|d_i| < 1.0e-8$), substitute $inv\_dir_i$ with a large finite slope ($1.0e30$) to avoid $0 \times \infty = \text{NaN}$ results [S1, unofficial].
    *   Compute axis-aligned intersections:
        $$ t_{axis\_min} = (\mathbf{box\_min} - \mathbf{o}) \cdot inv\_dir $$
        $$ t_{axis\_max} = (\mathbf{box\_max} - \mathbf{o}) \cdot inv\_dir $$
    *   Determine entry and exit:
        $$ t_0 = \max(t_{axis\_min}) $$
        $$ t_1 = \min(t_{axis\_max}) $$
    *   If $t_0 > t_1$, the ray misses the box.

2.  **Ray Marching Loop:**
    Iterate from $t = t_0$ to $t = t_1$ in $N$ steps (where $N = \text{steps}$). Step size $\Delta t = (t_1 - t_0) / N$.
    For each step $i$:
    *   **Position:** $\mathbf{p} = \mathbf{o} + (t_0 + i \cdot \Delta t) \mathbf{d}$.
    *   **Sampling:** Sample the volume texture at $\mathbf{p}$ to get density $D$.
    *   **Transfer Function:** Compute opacity $\alpha$ and color $C$ from $D$ using the transfer function scaled by `density`.
    *   **Accumulation:** Use front-to-back blending:
        $$ C_{out} = C_{in} + C \cdot \alpha \cdot (1 - \alpha_{in}) $$
        $$ \alpha_{in} = \alpha_{in} + \alpha \cdot (1 - \alpha_{in}) $$
    *   **Early Termination:** If $\alpha_{in} > \text{EARLY\_ALPHA}$, break the loop [S1, unofficial].

3.  **Shading (Optional):**
    If `shaded` is true and $\alpha_{in} \ge \text{SHADE\_T\_FLOOR}$:
    *   Compute the gradient $\nabla D$ at the current sample position using central differences. This requires 6 additional texture taps (3 pairs) per step [S1, unofficial].
    *   Normalize $\nabla D$ to get the surface normal $\mathbf{n}$.
    *   Apply Phong lighting model using $\mathbf{n}$, view direction, and light direction.
    *   If $\alpha_{in} < \text{SHADE\_T\_FLOOR}$, skip gradient computation to maintain performance budgets (e.g., < 8 ms) [S1, unofficial].

**Pseudocode (WGSL-style logic):**

```python
# Constants
EARLY_ALPHA = 0.98
SHADE_T_FLOOR = 1.0 / 255.0
MAX_INV_DIR = 1.0e30
EPSILON = 1.0e-8

# Ray-Box Intersection
def intersect_box(ray_origin, ray_dir):
    # Handle near-zero direction components to avoid NaN
    inv_dir = [MAX_INV_DIR if abs(d) < EPSILON else 1.0/d for d in ray_dir]
    
    box_min = [-0.5, -0.5, -0.5]
    box_max = [0.5, 0.5, 0.5]
    
    # Calculate t for each axis
    t_min = [(box_min[i] - ray_origin[i]) * inv_dir[i] for i in range(3)]
    t_max = [(box_max[i] - ray_origin[i]) * inv_dir[i] for i in range(3)]
    
    # Entry and exit points
    t_entry = max(t_min)
    t_exit = min(t_max)
    
    return t_entry, t_exit

# Main Raymarching Function
def raymarch_volume(ray_origin, ray_dir, volume_texture, steps, density, shaded):
    t0, t1 = intersect_box(ray_origin, ray_dir)
    
    # If ray misses box
    if t0 > t1:
        return [0.0, 0.0, 0.0, 0.0]
    
    dt = (t1 - t0) / steps
    acc_color = [0.0, 0.0, 0.0]
    acc_alpha = 0.0
    
    for i in range(steps):
        t = t0 + i * dt
        pos = ray_origin + ray_dir * t
        
        # Sample volume
        density_val = sample_volume(volume_texture, pos)
        
        # Transfer function (simplified)
        alpha = 1.0 - exp(-density * density_val)
        color = transfer_function(density_val)
        
        # Front-to-back blending
        weight = alpha * (1.0 - acc_alpha)
        acc_color = acc_color + color * weight
        acc_alpha = acc_alpha + weight
        
        # Early termination
        if acc_alpha > EARLY_ALPHA:
            break
            
        # Optional Shading
        if shaded and acc_alpha >= SHADE_T_FLOOR:
            # Compute gradient using central differences (6 taps)
            normal = compute_gradient_normal(volume_texture, pos)
            # Apply Phong lighting
            final_color = apply_phong_lighting(acc_color, normal, ray_dir)
            acc_color = final_color
            
    return [acc_color[0], acc_color[1], acc_color[2], acc_alpha]
```

## Operating characteristics
*   **Time Complexity:** $O(N)$ per pixel, where $N$ is the number of steps. With early termination, the average case is often significantly less than $N$.
*   **Memory Complexity:** $O(1)$ per pixel for accumulation; $O(V)$ for the volume texture storage, where $V$ is the texture resolution.
*   **Performance:** Designed to run within an 8 ms budget on modern GPUs [S1, unofficial]. Performance is heavily dependent on the `steps` parameter and the density of the volume.
*   **Strengths:** Single-pass execution allows for real-time interaction. Analytic ray-box intersection is efficient. Early-alpha termination optimizes rendering of transparent regions.
*   **Limitations:** Fixed step size can lead to aliasing in sparse regions or slow convergence in dense regions. Central-difference shading increases texture fetch count by 6x for shaded samples.

## Background
This method is implemented in the `webpic` project by Ruslan Saitis, which provides a WebGPU-based visualization tool for scientific data [S1, unofficial]. It is designed to run in the browser, leveraging WebGPU for high-performance parallel computation. The implementation includes features like HMR (Hot Module Replacement) for shader editing and support for various transfer functions.
