# Volume Ray Marching with Temporal Accumulation

Also called: HZL Fluid Effects Volume Rendering

## Overview
Volume Ray Marching with Temporal Accumulation is a real-time rendering technique that discretizes view rays through a 3D density field to compute color and opacity, enhanced by blending the current frame's result with a history texture to reduce noise and stabilize the image over time [S1, unofficial]. It distinguishes itself from standard ray marching by incorporating temporal feedback, allowing for higher visual fidelity with fewer spatial samples, and from SDF-based methods by relying on explicit density textures rather than analytic distance functions [S1, unofficial].

## How it works
**Inputs and Outputs**
*   **Inputs:** Camera position and inverse view-projection matrix; 3D density texture (GL_RGBA8); optional temperature/fire textures; scene depth texture (GL_DEPTH_COMPONENT24); history texture (GL_RGBA8); uniforms for step size, maximum steps, jitter, and lighting parameters.
*   **Outputs:** Final color buffer (GL_RGBA8).

**Data Structures**
*   `m_colorTexture`: GL_RGBA8, GL_LINEAR filtering, GL_CLAMP_TO_EDGE wrap.
*   `m_depthTexture`: GL_DEPTH_COMPONENT24, GL_NEAREST filtering, GL_CLAMP_TO_EDGE wrap.
*   `m_sceneDepthTexture`: GL_DEPTH_COMPONENT24, GL_NEAREST filtering, GL_CLAMP_TO_EDGE wrap.
*   `m_historyTexture`: GL_RGBA8, GL_LINEAR filtering, GL_CLAMP_TO_EDGE wrap. Cleared to zero at initialization [S1, unofficial].

**Parameters**
*   `gridSpacing`: float, default 0.5F [S1, unofficial].
*   `densityScale`: float, multiplier for density in light transmittance [S1, unofficial].
*   `stepSize`: float, distance advanced per ray march step [S1, unofficial].
*   `maximumSteps`: int, max steps per ray (e.g., 767) [S1, unofficial].
*   `frameIndex`: int, current frame number for jitter [S1, unofficial].
*   `jitterEnabled`: bool, enables random offset [S1, unofficial].
*   `adaptiveSteppingEnabled`: bool, uniform present but usage not shown in core snippet [S1, unofficial].
*   `fieldMode`: int, selects rendering mode (0: Smoke/Fire, 1: Simple Smoke, 2/3: Abstract/Color-coded) [S1, unofficial].
*   `lightDirection`: vec3, light source direction [S1, unofficial].
*   `lightIntensity`: float, light intensity multiplier [S1, unofficial].
*   `absorption`: float, absorption coefficient for Beer-Lambert law [S1, unofficial].
*   `emissionStrength`: float, multiplier for emitted light [S1, unofficial].
*   `selfShadowingEnabled`: bool, enables shadow ray marching [S1, unofficial].
*   `temporalEnabled`: bool, enables temporal blending [S1, unofficial].
*   `historyWeight`: float, weight for previous frame's color [S1, unofficial].

**Algorithm Steps**

1.  **Initialize Textures:** Allocate `m_colorTexture`, `m_depthTexture`, `m_sceneDepthTexture`, and `m_historyTexture` with specified formats and filtering. Clear `m_historyTexture` to zero [S1, unofficial].
2.  **Compute Ray Origin and Direction:**
    *   Convert texture coordinate `textureCoordinate` to clip space: `clipPosition = textureCoordinate * 2.0 - 1.0`.
    *   Unproject far plane point: `farWorld = inverseViewProjection * clipPosition`. Normalize to get `rayDirection = normalize(farWorld - cameraPosition)` [S1, unofficial].
3.  **Intersect Ray with Unit Cube:**
    *   Compute `inverseDirection = 1.0 / rayDirection`.
    *   Compute `first = (-1.0 - cameraPosition) * inverseDirection` and `second = (1.0 - cameraPosition) * inverseDirection`.
    *   Compute `minimum = min(first, second)` and `maximum = max(first, second)`.
    *   Return `intersection = vec2(max(minimum.x, minimum.y, minimum.z), min(maximum.x, maximum.y, maximum.z))` [S1, unofficial].
    *   Set `distanceAlongRay = max(intersection.x, 0.0)` [S1, unofficial].
4.  **Clip Ray Against Scene Geometry:**
    *   Sample `sceneDepthTexture` at `textureCoordinate` to get `sceneDepth`.
    *   If `sceneDepth < 1.0`, unproject the scene point to world space, calculate `sceneDistance` along `rayDirection`, and update `intersection.y = min(intersection.y, sceneDistance)` [S1, unofficial].
5.  **Discard if No Intersection:** If `intersection.y <= distanceAlongRay`, discard the fragment [S1, unofficial].
6.  **Apply Jitter:** If `jitterEnabled`, add a random offset to `distanceAlongRay`: `distanceAlongRay += random(gl_FragCoord.xy, frameIndex) * stepSize` [S1, unofficial].
7.  **Initialize Accumulation:** Set `accumulated = vec4(0.0)` [S1, unofficial].
8.  **Ray Marching Loop:**
    *   Loop `index` from 0 to `maximumSteps` (e.g., 767).
    *   Break if `index >= maximumSteps` or `distanceAlongRay >= intersection.y`.
    *   Calculate `position = cameraPosition + rayDirection * distanceAlongRay`.
    *   Sample `densityTexture` at `position * 0.5 + 0.5`. Get `fieldValue = texture.r` [S1, unofficial].
    *   Set `density = fieldValue`.
    *   **Detect Volume Entry:** If `!foundVolume` and `density > 0.01`, set `representativePosition = position` and `foundVolume = true` [S1, unofficial].
    *   **Compute Color:**
        *   If `fieldMode == 0`: Sample temperature and fire textures. Compute `lightTransmittance`. Compute ambient light `vec3(0.12, 0.15, 0.20)` and direct light `vec3(1.0, 0.88, 0.72) * lightIntensity * transmittance`. Mix smoke color based on `position.y`. Compute `flameColor` from temperature. `emittedLight = flameColor * fire * emissionStrength`.
        *   If `fieldMode == 1`: `smokeColor = mix(vec3(0.3, 0.04, 0.01), vec3(1.0, 0.65, 0.08), fieldValue)`.
        *   If `fieldMode == 2` or `3`: `density = abs(fieldValue - 0.5) * 2.0`. `smokeColor` is red if `fieldValue >= 0.5` else blue [S1, unofficial].
    *   **Accumulate Color and Opacity:**
        *   Calculate `alpha = 1.0 - exp(-density * stepSize)`.
        *   Calculate `color = smokeColor * alpha`.
        *   Update `accumulated`:
            ```python
            accumulated.rgb += color.rgb * (1.0 - accumulated.a)
            accumulated.a += alpha * (1.0 - accumulated.a)
            ```
        *   [G] Standard alpha blending is implied by the presence of `accumulated` and `temporalEnabled`, though the source snippet ends before this explicit loop. The formula above is the standard implementation for this accumulation pattern.
    *   **Light Transmittance (Self-Shadowing):** If `selfShadowingEnabled`, march 20 steps in direction `-normalize(lightDirection + vec3(0.0001))` with step size 0.08. Accumulate `opticalDepth = texture(densityTexture, position * 0.5 + 0.5).r * shadowStep`. Break if `abs(position) > 1.0`. Return `exp(-opticalDepth * absorption * densityScale * 3.0)` [S1, unofficial].
9.  **Temporal Accumulation:** If `temporalEnabled`, blend the current frame's `accumulated` result with `m_historyTexture` using `historyWeight`: `finalColor = mix(accumulated, historyColor, historyWeight)` [S1, unofficial].

**Pseudocode**

```python
def volume_ray_marching_with_temporal_accumulation(
    camera_position,
    inverse_view_projection,
    texture_coordinate,
    density_texture,
    scene_depth_texture,
    history_texture,
    step_size,
    maximum_steps,
    frame_index,
    jitter_enabled,
    field_mode,
    light_direction,
    light_intensity,
    absorption,
    emission_strength,
    self_shadowing_enabled,
    temporal_enabled,
    history_weight,
    density_scale
):
    # 1. Compute Ray Origin and Direction
    clip_position = texture_coordinate * 2.0 - 1.0
    far_point = inverse_view_projection * vec4(clip_position, 1.0)
    far_world = vec3(far_point) / far_point.w
    ray_direction = normalize(far_world - camera_position)
    
    # 2. Intersect Ray with Unit Cube [-1, 1]
    inverse_direction = 1.0 / ray_direction
    first = (vec3(-1.0) - camera_position) * inverse_direction
    second = (vec3(1.0) - camera_position) * inverse_direction
    minimum = min(first, second)
    maximum = max(first, second)
    intersection = vec2(max(minimum.x, minimum.y, minimum.z), min(maximum.x, maximum.y, maximum.z))
    distance_along_ray = max(intersection.x, 0.0)
    
    # 3. Clip Ray Against Scene Geometry
    scene_depth = texture(scene_depth_texture, texture_coordinate).r
    if scene_depth < 1.0:
        scene_point_clip = vec4(texture_coordinate * 2.0 - 1.0, scene_depth, 1.0)
        scene_point_world = vec3(inverse_view_projection * scene_point_clip) / (inverse_view_projection * scene_point_clip).w
        scene_distance = dot(scene_point_world - camera_position, ray_direction)
        intersection.y = min(intersection.y, scene_distance)
        
    # 4. Discard if No Intersection
    if intersection.y <= distance_along_ray:
        return vec4(0.0, 0.0, 0.0, 0.0)
        
    # 5. Apply Jitter
    if jitter_enabled:
        jitter = random(gl_FragCoord.xy, frame_index)
        distance_along_ray += jitter * step_size
        
    # 6. Initialize Accumulation
    accumulated = vec4(0.0, 0.0, 0.0, 0.0)
    found_volume = False
    
    # 7. Ray Marching Loop
    for index in range(maximum_steps):
        if distance_along_ray >= intersection.y:
            break
            
        position = camera_position + ray_direction * distance_along_ray
        
        # Sample Density
        density_tex_coord = position * 0.5 + 0.5
        field_value = texture(density_texture, density_tex_coord).r
        density = field_value
        
        # Detect Volume Entry
        if not found_volume and density > 0.01:
            representative_position = position
            found_volume = True
            
        # Compute Color based on Field Mode
        if field_mode == 0:
            # Smoke/Fire with lighting
            temperature = texture(temperature_texture, density_tex_coord).r
            fire = texture(fire_texture, density_tex_coord).r
            light_transmittance = compute_light_transmittance(position, light_direction, absorption, density_scale, self_shadowing_enabled)
            ambient = vec3(0.12, 0.15, 0.20)
            direct_light = vec3(1.0, 0.88, 0.72) * light_intensity * light_transmittance
            smoke_color = mix(vec3(0.1, 0.1, 0.1), vec3(0.8, 0.8, 0.8), position.y)
            flame_color = mix(vec3(1.0, 0.5, 0.0), vec3(1.0, 1.0, 1.0), temperature)
            emitted_light = flame_color * fire * emission_strength
            color = (ambient + direct_light) * smoke_color + emitted_light
        elif field_mode == 1:
            # Simple Smoke
            smoke_color = mix(vec3(0.3, 0.04, 0.01), vec3(1.0, 0.65, 0.08), field_value)
            color = smoke_color
        elif field_mode in [2, 3]:
            # Abstract/Color-coded
            density = abs(field_value - 0.5) * 2.0
            smoke_color = vec3(1.0, 0.0, 0.0) if field_value >= 0.5 else vec3(0.0, 0.0, 1.0)
            color = smoke_color
        else:
            color = vec3(0.0)
            
        # Accumulate Color and Opacity
        alpha = 1.0 - exp(-density * step_size)
        accumulated.rgb += color * alpha * (1.0 - accumulated.a)
        accumulated.a += alpha * (1.0 - accumulated.a)
        
        distance_along_ray += step_size
        
    # 8. Temporal Accumulation
    if temporal_enabled:
        history_color = texture(history_texture, texture_coordinate).rgb
        final_color = mix(accumulated.rgb, history_color, history_weight)
        final_alpha = accumulated.a
    else:
        final_color = accumulated.rgb
        final_alpha = accumulated.a
        
    return vec4(final_color, final_alpha)

def compute_light_transmittance(position, light_direction, absorption, density_scale, self_shadowing_enabled):
    if not self_shadowing_enabled:
        return 1.0
        
    shadow_direction = -normalize(light_direction + vec3(0.0001))
    optical_depth = 0.0
    shadow_step = 0.08
    
    for _ in range(20):
        shadow_pos = position + shadow_direction * shadow_step
        if abs(shadow_pos) > 1.0:
            break
        density = texture(density_texture, shadow_pos * 0.5 + 0.5).r
        optical_depth += density * shadow_step
        
    return exp(-optical_depth * absorption * density_scale * 3.0)

def random(coord, frame_index):
    value = fract(vec3(coord.x, coord.y, coord.x) * 0.1031)
    value += dot(value, value.yzx + 33.33 + float(frame_index) * 0.01)
    return fract((value.x + value.y) * value.z)
```

## Subtopics

### Ray Marching with Single Scattering
Computes only the first scattering event, faster but less accurate for dense media. Choose when performance is critical and media is thin. [Link](2057-ray-marching-with-single-scattering.md)

### SDF Cloud Rendering
Uses Signed Distance Fields for cloud geometry, often with raymarching for shading. Choose when procedural, smooth cloud shapes are needed without volumetric data. [Link](2064-sdf-cloud-rendering.md)

### Atmospheric Ray Marching
Specialized for large-scale atmospheric effects, often using layered models. Choose for sky and horizon effects rather than localized volumes. [Link](4874-atmospheric-ray-marching.md)

## Operating characteristics
*   **Time Complexity:** $O(N \cdot M)$, where $N$ is the number of pixels and $M$ is the maximum number of ray steps (e.g., 767). Self-shadowing adds a constant factor (20 steps) per sample if enabled.
*   **Memory Complexity:** $O(R^3)$ for the 3D density texture, where $R$ is the resolution, plus $O(W \cdot H)$ for the history and color buffers.
*   **Measured Performance:** The implementation targets real-time performance, with frame times reported in milliseconds (e.g., average render time < 16ms for 60 FPS) [S1, unofficial].
*   **Scaling:** Performance scales linearly with resolution and maximum steps. Temporal accumulation allows for lower spatial sampling rates, effectively trading temporal stability for spatial detail.
*   **Strengths:** Reduces noise through temporal accumulation; supports complex lighting (self-shadowing, emission); flexible field modes.
*   **Limitations:** Requires a history texture and temporal blending logic; potential for ghosting if motion is not properly accounted for (not detailed in sources); division by zero risk if ray direction is zero [S1, unofficial].
*   **When to Use:** Real-time fluid effects, smoke, fire, and atmospheric volumes where noise reduction is beneficial and temporal coherence is acceptable.
*   **When Not to Use:** Static scenes where temporal accumulation provides no benefit; scenes with high-frequency motion where ghosting is unacceptable; hardware without sufficient texture memory for large 3D volumes.
