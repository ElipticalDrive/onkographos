# Volume Ray Marching with Temporal Accumulation

Also called: HZL Fluid Effects Volume Rendering

## Overview
Volume Ray Marching with Temporal Accumulation is a real-time rendering technique that integrates the Radiative Transfer Equation (RTE) through a 3D density field using ray marching, stabilized by blending the current frame's result with a history texture [S1, unofficial]. Unlike standard ray marching which may produce temporal noise or flickering at low step counts, this method uses temporal accumulation to reduce noise and stabilize the image over frames [S1, unofficial]. It is distinct from [SDF Cloud Rendering](2064-sdf-cloud-rendering.md) by its explicit use of a history buffer for temporal coherence, and from [Atmospheric Ray Marching](4874-atmospheric-ray-marching.md) by its focus on localized fluid effects with specific lighting modes for smoke and fire [S1, unofficial].

## How it works
**Inputs and Outputs:**
*   **Inputs:** Camera position and inverse view-projection matrix, density texture (GL_RGBA8, sampled from R channel), optional temperature/fire textures, scene depth texture (GL_DEPTH_COMPONENT24), and previous frame's accumulated color (history texture, GL_RGBA8).
*   **Outputs:** Final color buffer (GL_RGBA8).

**Data Structures:**
*   `m_colorTexture`: GL_RGBA8, GL_LINEAR filtering, GL_CLAMP_TO_EDGE wrap.
*   `m_depthTexture`: GL_DEPTH_COMPONENT24, GL_NEAREST filtering, GL_CLAMP_TO_EDGE wrap.
*   `m_sceneDepthTexture`: GL_DEPTH_COMPONENT24, GL_NEAREST filtering, GL_CLAMP_TO_EDGE wrap.
*   `m_historyTexture`: GL_RGBA8, GL_LINEAR filtering, GL_CLAMP_TO_EDGE wrap. Cleared to zero at initialization.

**Parameters:**
*   `stepSize`: float, distance advanced per ray march step.
*   `maximumSteps`: int, max steps per ray (default 767 in source).
*   `densityScale`: float, multiplier for density values.
*   `absorption`: float, absorption coefficient for Beer-Lambert law.
*   `emissionStrength`: float, multiplier for emitted light.
*   `lightDirection`: vec3, light source direction.
*   `lightIntensity`: float, light intensity multiplier.
*   `fieldMode`: int, 0=Smoke/Fire, 1=Simple Smoke, 2/3=Abstract/Color-coded.
*   `temporalEnabled`: bool, enable temporal accumulation.
*   `historyWeight`: float, weight for previous frame in accumulation.
*   `jitterEnabled`: bool, enable jittering.
*   `selfShadowingEnabled`: bool, enable shadow ray marching.
*   `gridSpacing`: float, debug visualization spacing (default 0.5).

**Steps:**

1.  **Initialize Textures:** Allocate `m_colorTexture`, `m_depthTexture`, `m_sceneDepthTexture`, and `m_historyTexture` with specified formats and filtering. Clear `m_historyTexture` to zero.
2.  **Compute Ray Origin and Direction:**
    *   Convert texture coordinate `uv` to clip space: `clipPos = uv * 2.0 - 1.0`.
    *   Unproject far plane point: `farWorld = inverseViewProjection * clipPos`.
    *   Ray origin: `o = cameraPosition`.
    *   Ray direction: `d = normalize(farWorld - o)`.
3.  **Intersect Ray with Unit Cube:**
    *   Compute inverse direction: `invD = 1.0 / d`.
    *   Compute intersections with box `[-1, 1]`:
        *   `t1 = (-1.0 - o) * invD`
        *   `t2 = (1.0 - o) * invD`
        *   `tMin = min(t1, t2)`
        *   `tMax = max(t1, t2)`
        *   `entry = max(tMin.x, tMin.y, tMin.z)`
        *   `exit = min(tMax.x, tMax.y, tMax.z)`
    *   If `entry > exit`, no intersection.
4.  **Clip Ray Against Scene Geometry:**
    *   Sample `m_sceneDepthTexture` at `uv` to get `sceneDepth`.
    *   If `sceneDepth < 1.0`:
        *   Unproject scene point: `sceneWorld = inverseViewProjection * vec4(uv * 2.0 - 1.0, sceneDepth, 1.0)`.
        *   Calculate distance along ray: `sceneDist = dot(sceneWorld - o, d)`.
        *   Update `exit = min(exit, sceneDist)`.
5.  **Discard if No Intersection:** If `exit <= entry`, discard fragment.
6.  **Apply Jitter:** If `jitterEnabled`, add random offset to `entry`:
    *   `jitter = random(gl_FragCoord.xy, frameIndex) * stepSize`.
    *   `entry += jitter`.
7.  **Initialize Accumulation:** `accumulated = vec4(0.0)`.
8.  **Ray Marching Loop:**
    *   Loop `i` from 0 to `maximumSteps - 1`.
    *   If `entry >= exit`, break.
    *   Position: `p = o + d * entry`.
    *   Sample density: `fieldValue = texture(densityTexture, p * 0.5 + 0.5).r`.
    *   Set `density = fieldValue`.
    *   **Detect Volume Entry:** If `!foundVolume` and `density > 0.01`, set `foundVolume = true` and `representativePosition = p`.
    *   **Compute Color:**
        *   If `fieldMode == 0` (Smoke/Fire):
            *   Sample temperature/fire textures.
            *   Compute light transmittance (see below).
            *   Ambient: `vec3(0.12, 0.15, 0.20)`.
            *   Direct: `vec3(1.0, 0.88, 0.72) * lightIntensity * transmittance`.
            *   Mix smoke color based on `p.y`.
            *   Compute flame color from temperature.
            *   Emitted Light: `flameColor * fire * emissionStrength`.
        *   If `fieldMode == 1` (Simple Smoke):
            *   `smokeColor = mix(vec3(0.3, 0.04, 0.01), vec3(1.0, 0.65, 0.08), fieldValue)`.
        *   If `fieldMode == 2` or `3` (Abstract):
            *   `density = abs(fieldValue - 0.5) * 2.0`.
            *   `smokeColor = (fieldValue >= 0.5) ? vec3(1.0, 0.0, 0.0) : vec3(0.0, 0.0, 1.0)`.
    *   **Accumulate Color and Opacity:**
        *   `alpha = 1.0 - exp(-density * stepSize)`.
        *   `color = smokeColor * alpha`.
        *   `accumulated += color * (1.0 - accumulated.a)`.
        *   `accumulated.a += alpha * (1.0 - accumulated.a)`.
    *   **Advance Ray:** `entry += stepSize`.
9.  **Light Transmittance Calculation (Self-Shadowing):**
    *   If `selfShadowingEnabled`:
        *   `shadowDir = normalize(lightDirection + vec3(0.0001))`.
        *   `opticalDepth = 0.0`.
        *   Loop 20 steps with `shadowStep = 0.08`.
        *   `pos = p - shadowDir * step`.
        *   If `abs(pos) > 1.0`, break.
        *   `opticalDepth += texture(densityTexture, pos * 0.5 + 0.5).r * shadowStep`.
        *   `transmittance = exp(-opticalDepth * absorption * densityScale * 3.0)`.
10. **Temporal Accumulation:**
    *   If `temporalEnabled`:
        *   `currentFrameColor = accumulated.rgb`.
        *   `previousFrameColor = texture(m_historyTexture, uv).rgb`.
        *   `finalColor = mix(previousFrameColor, currentFrameColor, historyWeight)`.
    *   Else:
        *   `finalColor = accumulated.rgb`.
11. **Output:** Write `finalColor` to `m_colorTexture`.

**Pseudocode:**

```python
def volume_ray_marching_with_temporal_accumulation(
    camera_position,
    inverse_view_projection,
    density_texture,
    scene_depth_texture,
    history_texture,
    frame_index,
    step_size,
    maximum_steps,
    density_scale,
    absorption,
    emission_strength,
    light_direction,
    light_intensity,
    field_mode,
    temporal_enabled,
    history_weight,
    jitter_enabled,
    self_shadowing_enabled,
    uv
):
    # 1. Compute Ray
    clip_pos = uv * 2.0 - 1.0
    far_world = inverse_view_projection @ vec4(clip_pos, 1.0)
    far_world = vec3(far_world) / far_world.w
    origin = camera_position
    direction = normalize(far_world - origin)
    inverse_direction = 1.0 / direction

    # 2. Intersect with Unit Cube [-1, 1]
    t1 = (-1.0 - origin) * inverse_direction
    t2 = (1.0 - origin) * inverse_direction
    t_min = min(t1, t2)
    t_max = max(t1, t2)
    entry = max(t_min.x, t_min.y, t_min.z)
    exit = min(t_max.x, t_max.y, t_max.z)

    # 3. Clip with Scene Depth
    scene_depth = scene_depth_texture.sample(uv).r
    if scene_depth < 1.0:
        scene_world = inverse_view_projection @ vec4(uv * 2.0 - 1.0, scene_depth, 1.0)
        scene_world = vec3(scene_world) / scene_world.w
        scene_dist = dot(scene_world - origin, direction)
        exit = min(exit, scene_dist)

    if exit <= entry:
        return vec4(0.0)

    # 4. Apply Jitter
    if jitter_enabled:
        jitter = random_gl_frag_coord(frame_index) * step_size
        entry += jitter

    # 5. Initialize Accumulation
    accumulated = vec4(0.0)
    found_volume = False

    # 6. Ray Marching Loop
    for i in range(maximum_steps):
        if entry >= exit:
            break

        position = origin + direction * entry
        # Map world [-1,1] to texture [0,1]
        texture_coord = position * 0.5 + 0.5
        field_value = density_texture.sample(texture_coord).r
        density = field_value

        if not found_volume and density > 0.01:
            found_volume = True

        # Compute Color based on Field Mode
        smoke_color = vec3(0.0)
        if field_mode == 0:
            # Smoke/Fire mode
            # Simplified: assume temperature/fire textures sampled elsewhere
            # Ambient and Direct Light
            ambient = vec3(0.12, 0.15, 0.20)
            # Light transmittance calculation required here
            transmittance = compute_light_transmittance(position, light_direction, density_texture, density_scale, absorption)
            direct = vec3(1.0, 0.88, 0.72) * light_intensity * transmittance
            # Mix smoke color based on position.y (simplified)
            smoke_color = mix(vec3(0.3, 0.04, 0.01), vec3(1.0, 0.65, 0.08), field_value)
            # Emitted light from fire (simplified)
            emitted = vec3(1.0, 0.5, 0.0) * emission_strength
            color = (ambient + direct) * smoke_color + emitted
        elif field_mode == 1:
            smoke_color = mix(vec3(0.3, 0.04, 0.01), vec3(1.0, 0.65, 0.08), field_value)
            color = smoke_color
        elif field_mode in [2, 3]:
            density = abs(field_value - 0.5) * 2.0
            smoke_color = vec3(1.0, 0.0, 0.0) if field_value >= 0.5 else vec3(0.0, 0.0, 1.0)
            color = smoke_color
        else:
            color = vec3(0.0)

        # Accumulate
        alpha = 1.0 - exp(-density * step_size)
        accumulated.rgb += color * alpha * (1.0 - accumulated.a)
        accumulated.a += alpha * (1.0 - accumulated.a)

        entry += step_size

    # 7. Temporal Accumulation
    if temporal_enabled:
        previous_color = history_texture.sample(uv).rgb
        final_color = mix(previous_color, accumulated.rgb, history_weight)
    else:
        final_color = accumulated.rgb

    return vec4(final_color, 1.0)

def compute_light_transmittance(position, light_direction, density_texture, density_scale, absorption):
    if not self_shadowing_enabled:
        return 1.0
    shadow_dir = normalize(light_direction + vec3(0.0001))
    optical_depth = 0.0
    shadow_step = 0.08
    for _ in range(20):
        pos = position - shadow_dir * shadow_step
        if abs(pos).x > 1.0 or abs(pos).y > 1.0 or abs(pos).z > 1.0:
            break
        density = density_texture.sample(pos * 0.5 + 0.5).r
        optical_depth += density * shadow_step
    return exp(-optical_depth * absorption * density_scale * 3.0)

def random_gl_frag_coord(frame_index):
    coordinate = vec2(gl_FragCoord.xy)
    value = fract(vec3(coordinate.xyx) * 0.1031)
    value += dot(value, value.yzx + 33.33 + float(frame_index) * 0.01)
    return fract((value.x + value.y) * value.z)
```

## Operating characteristics
*   **Time Complexity:** O(N * M) per pixel, where N is the number of ray steps (maximumSteps) and M is the number of shadow steps (20) if self-shadowing is enabled.
*   **Memory Complexity:** O(W * H) for the history texture and scene depth texture, where W and H are the screen dimensions.
*   **Performance:** The method is designed for real-time rendering, typically achieving 60+ FPS on modern GPUs for moderate resolutions and step counts [S1, unofficial]. Performance scales with the number of steps and the complexity of the density field.
*   **Strengths:** Reduces temporal noise and flickering, provides stable images for dynamic scenes, supports various lighting modes for different visual effects.
*   **Limitations:** Can introduce ghosting if the scene moves rapidly or if the history weight is too high. Requires careful tuning of parameters like step size and jitter to avoid artifacts. Division by zero in ray direction can cause issues if not handled [S1, unofficial].
*   **When to Use:** Suitable for real-time fluid effects, smoke, and fire rendering where temporal stability is important.
*   **When Not to Use:** Not suitable for offline rendering where high accuracy is required, or for scenes with very fast motion where ghosting is unacceptable.

## Background
This technique is part of the HZL Fluid Effects Studio, an open-source project for real-time fluid simulation and rendering [S1, unofficial]. It builds upon the principles of volume ray marching and temporal accumulation, which are well-established in computer graphics for noise reduction in path tracing and other stochastic rendering methods. The specific implementation details, such as the use of a unit cube for ray-box intersection and the specific lighting modes, are tailored for fluid effects visualization.
