# SDF Cloud Rendering

Also called: Signed Distance Field Clouds

## Overview
SDF Cloud Rendering is a technique for rendering volumetric clouds using Signed Distance Fields (SDFs) via ray marching in a fragment shader, utilizing warped sphere primitives and smooth unions to create complex shapes [S1, unofficial]. It differs from standard volumetric methods by representing the cloud volume as an implicit surface defined by analytic distance functions rather than a sampled density grid, allowing for sharp, stylized cloud structures with minimal memory overhead [S1, unofficial].

## How it works
The method renders clouds by ray marching through a scene defined by a composite SDF constructed from warped spheres. It computes shading via a secondary shadow march and applies tone mapping for final output.

### Inputs and Outputs
*   **Inputs**: Fragment coordinates (`gl_FragCoord`), screen resolution (`screenSize`), camera field of view (45.0 degrees), and a random seed for jitter generation.
*   **Outputs**: A final color value for each pixel, tone-mapped to the [0, 1] range.

### Data Structures
No complex data structures are used. The scene is defined entirely by procedural functions. Constants are defined as follows:
*   `MAX_MARCHING_STEPS`: Integer, 100.
*   `MIN_DIST`: Float, 0.0.
*   `MAX_DIST`: Float, 100.0.
*   `EPSILON`: Float, 0.0001.
*   `STEP_SCALE`: Float, 0.67.
*   `LIGHT`: Vector3, `(-10.0, 10.0, 3.0)`.
*   `EXPOSURE`: Float, 1.0.
*   `WHITE`: Float, 200.0.

### Formulas
1.  **Jitter Function**: Generates pseudo-random displacement based on a seed.
    $$ \text{jitter}(m, o) = 0.09 \sum_{p=0}^{2} \frac{\sin((o + \text{seed} + 1234.0 \cdot m) \cdot 2^p)}{2^p} $$
    Where $m$ is the mix amount (coordinate component), $o$ is the offset, and seed is a constant.

2.  **Warping**: Distorts space to create organic cloud shapes.
    $$ \text{warp}(\mathbf{v}, s) = \mathbf{v} + s \cdot \begin{bmatrix} \text{jitter}(v_x, 0.0) \\ \text{jitter}(v_y, 0.2) \\ \text{jitter}(v_z, 0.5) \end{bmatrix} $$

3.  **Sphere SDF**:
    $$ \text{sphereSDF}(\mathbf{p}, \mathbf{c}, r) = \|\mathbf{p} - \mathbf{c}\| - r $$

4.  **Smooth Union**: Blends two SDFs $d_1$ and $d_2$ with factor $k$.
    $$ h = \text{clamp}\left(0.5 + 0.5 \frac{d_2 - d_1}{k}, 0.0, 1.0\right) $$
    $$ \text{smoothUnion}(d_1, d_2, k) = \text{mix}(d_2, d_1, h) - k \cdot h \cdot (1.0 - h) $$

5.  **Scene SDF**:
    $$ \text{sceneSDF}(\mathbf{p}) = \min\left(\text{smoothUnion}(\text{sphereSDF}(\text{warp}(\mathbf{p}, 1.5), \mathbf{c}_1, 1.0), \text{sphereSDF}(\text{warp}(\mathbf{p}, 1.5), \mathbf{c}_2, 0.5), 0.4), \text{sphereSDF}(\text{warp}(\mathbf{p}, 1.5), \mathbf{c}_3, 0.3)\right) $$
    Where $\mathbf{c}_1=(0.5, 0.0, 0.0)$, $\mathbf{c}_2=(-0.5, -0.4, 0.2)$, $\mathbf{c}_3=(-0.8, 0.55, 0.2)$.

6.  **Shadow**: Approximates occlusion by marching towards the light.
    $$ \text{shadow}(\mathbf{o}, \mathbf{d}) = \min_{i} \left( k \frac{h_i}{t_i} \right) $$
    Where $h_i = \text{sceneSDF}(\mathbf{o} + t_i \mathbf{d})$, $t_i$ accumulates $h_i \cdot \text{STEP\_SCALE}$, and $k=2.0$.

7.  **Hable Tone Mapping**:
    $$ \text{toneMap}(x) = \frac{x(Ax+CB)+DE}{x(Ax+B)+DF} - \frac{E}{F} $$
    With $A=0.15, B=0.50, C=0.10, D=0.20, E=0.02, F=0.30$.

### Pseudocode

```python
def jitter(mix_amount, offset, seed):
    amount = 0.0
    scale = 1.0
    offset += seed
    for power in range(3):
        amount += sin((offset * 1234.0 + mix_amount) * scale) / scale
        scale *= 2.0
    return amount * 0.09

def warp(v, scale, seed):
    return v + scale * vec3(
        jitter(v.x, 0.0, seed),
        jitter(v.y, 0.2, seed),
        jitter(v.z, 0.5, seed)
    )

def sphere_sdf(sample_point, origin, radius):
    return length(sample_point - origin) - radius

def smooth_union(d1, d2, k):
    h = clamp(0.5 + 0.5 * (d2 - d1) / k, 0.0, 1.0)
    return mix(d2, d1, h) - k * h * (1.0 - h)

def scene_sdf(sample_point, seed):
    warped = warp(sample_point, 1.5, seed)
    d1 = sphere_sdf(warped, vec3(0.5, 0.0, 0.0), 1.0)
    d2 = sphere_sdf(warped, vec3(-0.5, -0.4, 0.2), 0.5)
    smoothed = smooth_union(d1, d2, 0.4)
    d3 = sphere_sdf(warped, vec3(-0.8, 0.55, 0.2), 0.3)
    return min(smoothed, d3)

def ray_direction(field_of_view, size, frag_coord):
    xy = frag_coord - size / 2.0
    z = size.y / tan(radians(field_of_view) / 2.0)
    return normalize(vec3(xy, -z))

def ray_march(eye, marching_direction, start, end, seed):
    depth = start
    for i in range(100):
        dist = scene_sdf(eye + depth * marching_direction, seed)
        if dist < 0.0001:
            return depth
        depth += dist * 0.67
        if depth >= end:
            return end
    return end

def shadow_calc(origin, dir, seed):
    k = 2.0
    t = 100.0 * 0.0001
    res = 1.0
    for i in range(100):
        h = scene_sdf(origin + t * dir, seed)
        if h < 0.0001:
            return 0.0
        t += h * 0.67
        res = min(res, k * h / t)
    return res

def tone_map(x):
    A = 0.15
    B = 0.50
    C = 0.10
    D = 0.20
    E = 0.02
    F = 0.30
    return (x * (A * x + C * B) + D * E) / (x * (A * x + B) + D * F) - E / F

def render(frag_coord, screen_size, seed):
    dir = ray_direction(45.0, screen_size, frag_coord)
    eye = vec3(0.0, 0.0, 8.0)
    dist = ray_march(eye, dir, 0.0, 100.0, seed)

    if dist > 100.0 - 0.0001:
        # Sky gradient
        d = dot(dir, normalize(vec3(0.0, -1.0, 0.0)))
        d = d * 6.0
        d = d / 2.0 + 0.5
        d = max(0.0, min(1.0, d))
        return mix(vec3(4.0, 40.0, 100.0), vec3(20.0, 100.0, 100.0), d)

    intersection = eye + dist * dir
    to_light = normalize(vec3(-10.0, 10.0, 3.0) - intersection)
    shadow_val = shadow_calc(intersection, to_light, seed)
    
    light_color = vec3(100.0, 100.0, 100.0)
    dark_color = vec3(5.0, 8.0, 20.0)
    color = mix(dark_color, light_color, shadow_val)
    
    return color

def main(frag_coord, screen_size, seed):
    color = render(frag_coord, screen_size, seed)
    exposure = 1.0
    white = 200.0
    w_scale = 1.0 / tone_map(exposure * white)
    final_color = tone_map_vec(exposure * color) * w_scale
    return final_color
```

### Parameters and Edge Cases
*   **Precision**: The method uses `mediump` float precision in the reference implementation [S1, unofficial]. This may cause jittering or artifacts in the shadow calculation or SDF evaluation for high-resolution displays or large scenes.
*   **Boundaries**: The ray march terminates at `MAX_DIST` (100.0). If the cloud structure extends beyond this, it will be clipped.
*   **Degenerate Input**: If `screenSize` is zero or invalid, the ray direction calculation will fail. The `EPSILON` threshold prevents infinite loops if the ray grazes the surface.

## Operating characteristics
*   **Time Complexity**: $O(N)$ per pixel, where $N$ is the number of ray marching steps (100). The shadow calculation adds another $O(N)$ cost per pixel. Total complexity is $O(2N)$ per pixel.
*   **Memory Complexity**: $O(1)$. No textures or large buffers are required.
*   **Performance**: Extremely fast on modern GPUs due to the lack of texture sampling and simple arithmetic operations. Suitable for real-time rendering at high resolutions.
*   **Strengths**: Low memory footprint, sharp edges, stylized appearance, easy to integrate into existing shaders.
*   **Limitations**: Cannot represent internal density variations or complex lighting effects like subsurface scattering accurately. The "clouds" are essentially solid shapes with smooth boundaries, not true volumetric clouds.

## Background
The technique was created by Dave Pagurek as a small experiment in rendering with signed distance fields, presented at Graphics Interface 2019 [S1, unofficial]. It demonstrates the potential of SDFs for creating organic, volumetric-like shapes without the computational cost of traditional volumetric rendering.
