# Volumetric and Atmospheric Rendering

Also called: Volumetric Rendering, Atmospheric Rendering

## Overview
Volumetric and Atmospheric Rendering is a family of techniques that render participating media (clouds, fog, smoke) and planetary atmospheres by integrating light transport along rays [G]. It differs from [SDF Cloud Rendering](2064-sdf-cloud-rendering.md) by solving the radiative transfer equation (or approximations like single scattering) rather than constructing explicit geometry via Signed Distance Fields, and from [Ray Marching with Single Scattering](2057-ray-marching-with-single-scattering.md) by focusing on global atmospheric phenomena rather than localized procedural clouds [G].

## Shared principles
The method renders participating media by shooting a ray through each pixel and repeatedly querying a density field or analytic function [S1, unofficial]. Unlike surface rendering, the ray accumulates color and opacity as it traverses the medium [G].

The core loop initializes a ray with an origin point $\mathbf{o}$ and a normalized direction vector $\mathbf{d}$ [G]. It maintains a current position $\mathbf{p}$ (initially $\mathbf{o}$) [G]. In each iteration:
1. The density $\sigma_t$ (extinction coefficient) is evaluated at $\mathbf{p}$ [G].
2. The transmittance is updated using the Beer-Lambert law: $T \leftarrow T \cdot \exp(-\sigma_t \cdot \Delta s)$, where $\Delta s$ is the step size [G].
3. The scattered light contribution is calculated based on the phase function and light source visibility [G].
4. The accumulated color is updated: $C \leftarrow C + T \cdot \sigma_s \cdot L_{scattered} \cdot \Delta s$, where $\sigma_s$ is the scattering coefficient and $L_{scattered}$ is the incoming radiance [G].
5. The position is advanced: $\mathbf{p} \leftarrow \mathbf{p} + \Delta s \cdot \mathbf{d}$ [G].
6. The loop continues while the step count is less than $\text{MAX\_STEPS}$ [G].

If the loop terminates without significant opacity (e.g., $T$ remains high), the ray contributes the background sky color [G].

Parameters include $\text{MAX\_STEPS}$ (a safety cap, typically 32 to 128 depending on implementation [G]) and $\text{HIT\_THRESHOLD}$ (epsilon) [G]. A maximum range or accumulated travel distance limit can also bound rays that miss [G].

```python
def ray_march_volume(ro, v, density_func, light_color, phase_func, max_steps=40, step_size=0.1, max_range=100.0):
    p = ro
    transmittance = 1.0
    accumulated_color = vec3(0.0)
    for i in range(max_steps):
        dist = dot(p - ro, v)
        if dist > max_range:
            break
        density = density_func(p)
        if density < 1e-4:
            p += v * step_size
            continue
        step_transmittance = exp(-density * step_size)
        scattered = light_color * phase_func(dot(v, normalize(light_color - p)))
        accumulated_color += transmittance * density * step_transmittance * scattered * step_size
        transmittance *= step_transmittance
        if transmittance < 0.01:
            break
        p += v * step_size
    sky_color = vec3(0.5, 0.6, 0.8)
    return accumulated_color + transmittance * sky_color
```

## Subtopics

### [Ray Marching with Single Scattering](2057-ray-marching-with-single-scattering.md)
Ray marching with single scattering is a real-time technique for rendering volumetric clouds using OpenGL/WebGL ray marching, procedural noise for density, and physically-based single scattering illumination. It solves the problem of rendering translucent, animated volumetric media efficiently by approximating light transport with a single scattering event per sample, balancing visual fidelity against computational cost. It differs from [SDF Cloud Rendering](2064-sdf-cloud-rendering.md) by using procedural noise instead of signed distance fields for density, and from [Atmospheric Ray Marching](4874-atmospheric-ray-marching.md) by focusing on localized cloud volumes with explicit bounding boxes and wind animation rather than global atmospheric scattering.

### [SDF Cloud Rendering](2064-sdf-cloud-rendering.md)
SDF Cloud Rendering is a technique for rendering volumetric clouds using Signed Distance Fields (SDFs) via ray marching in a fragment shader, utilizing warped sphere primitives and smooth unions to create complex shapes. It differs from [Ray Marching with Single Scattering](2057-ray-marching-with-single-scattering.md) and [Atmospheric Ray Marching](4874-atmospheric-ray-marching.md) by constructing the volume geometry explicitly through analytic distance functions rather than sampling a density field or solving the radiative transfer equation with phase functions.

### [Atmospheric Ray Marching](4874-atmospheric-ray-marching.md)
A ray marching technique for rendering planetary atmospheres using single scattering, exponential density falloff, and Rayleigh phase function.

## Background
The technique originated in real-time graphics for rendering clouds and fog [G]. The specific implementation details for wax volume raymarching, including the use of a 4³ occupancy grid to skip empty blocks and reduce texture reads by 3x, were documented in a GitHub pull request for a lava lamp simulation [S1, unofficial]. The method employs a separable kernel for density generation and temporal smoothing [S1, unofficial].
