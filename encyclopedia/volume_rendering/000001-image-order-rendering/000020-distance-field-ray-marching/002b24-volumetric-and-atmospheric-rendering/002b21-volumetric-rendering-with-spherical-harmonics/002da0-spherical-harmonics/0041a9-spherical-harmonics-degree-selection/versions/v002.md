# Spherical Harmonics Degree Selection

Also called: SH basis selection

## Overview
Spherical Harmonics Degree Selection determines the maximum bandwidth $L$ of the SH basis used to represent directional signals (such as radiance or color) in volumetric rendering. It balances reconstruction fidelity against memory consumption, as higher degrees increase the number of coefficients quadratically. It differs from [Spherical Harmonics Approximation](8741-spherical-harmonics-approximation.md) by focusing on the capacity limit (bandwidth) rather than the projection or fitting process itself.

## How it works
**Inputs:**
- Target maximum degree $L_{target}$ (integer $\ge 0$).
- Source data containing directional coefficients, potentially at a higher degree $L_{source}$.

**Outputs:**
- A set of SH coefficients truncated to degree $L_{target}$.
- Metadata indicating the effective bandwidth.

**Data Structures:**
- Coefficients are stored as a vector of size $N = (L+1)^2$ for a given degree $L$.
- The linear index $i$ maps degree $l$ and order $m$ via $i = l^2 + l + m$ [S1, Child 10564].
- For real-valued rendering, coefficients correspond to the real basis functions $Y_{lm}$ .

**Steps:**
1. **Determine Capacity:** Calculate the total number of coefficients required for the target degree:
   $$ N_{target} = (L_{target} + 1)^2 $$
2. **Check Compatibility:** If the source data has a maximum degree $L_{source} < L_{target}$, pad the coefficient vector with zeros up to index $N_{target} - 1$ [G]. If $L_{source} \ge L_{target}$, proceed to truncation.
3. **Truncate (if necessary):** If $L_{source} > L_{target}$, discard all coefficients corresponding to degrees $l > L_{target}$. This involves keeping only the first $N_{target}$ coefficients in the linear indexing scheme [S2, unofficial].
4. **Validation:** Ensure $L_{target} \ge 0$. If $L_{target} = 0$, only the DC component ($l=0, m=0$) is retained.

**Parameters:**
- $L_{target}$: Typical values range from 0 to 4 in standard volumetric rendering pipelines [S1].
- $L_{source}$: Determined by the data generation method (e.g., training resolution or splat properties).

**Edge Cases and Pitfalls:**
- **Memory Scaling:** Memory usage scales as $O(L^2)$. Increasing $L$ from 2 to 3 increases coefficient count from 9 to 16 (78% increase) [S1].
- **Precision:** Truncation introduces approximation error. Higher degrees capture finer angular details but may amplify noise if the signal is not sufficiently band-limited [S1].
- **Boundary:** $L=0$ represents a constant color field with no directional variation.

**Pseudocode:**
```python
def select_sh_degree(coefficients, l_source, l_target):
    """
    Selects or truncates SH coefficients to a target degree.
    
    Args:
        coefficients: List or array of SH coefficients.
        l_source: The maximum degree of the input coefficients.
        l_target: The desired maximum degree.
        
    Returns:
        Truncated or padded coefficient list.
    """
    # Calculate required size for target degree
    n_target = (l_target + 1) ** 2
    
    # If source is smaller, pad with zeros
    if l_source < l_target:
        current_size = (l_source + 1) ** 2
        # Pad with zeros to reach n_target
        padded_coeffs = coefficients + [0.0] * (n_target - current_size)
        return padded_coeffs
    
    # If source is larger, truncate
    elif l_source >= l_target:
        # Keep only the first n_target coefficients
        # This implicitly discards all l > l_target
        return coefficients[:n_target]
    
    # If equal, return as is
    else:
        return coefficients
```

## Subtopics

### SH Degree Truncation
A specific implementation of degree selection used in preprocessing pipelines (e.g., for Gaussian Splatting variants). It checks if the loaded splat's `get_max_sh_degree()` differs from `params.sh_degree` and modifies the splat data in-place to match the target parameter, lowering memory and compute requirements [S2, unofficial].

## Operating characteristics
- **Time Complexity:** Selection is $O(1)$ if the size is pre-calculated, or $O(N)$ for copying/truncating the coefficient array, where $N = (L+1)^2$.
- **Memory Complexity:** $O(L^2)$. Each coefficient typically requires 3 floats (RGB) or 4 floats (RGBA).
- **Performance:** PSNR generally increases with SH degree. On a 256^3 grid, PSNR rises from 26.13 (Degree 0) to 28.29 (Degree 3) [S1]. On a 512^3 grid, it rises from 26.99 (Degree 0) to 29.98 (Degree 4) [S1].
- **Trade-offs:** Higher degrees improve visual fidelity but significantly increase memory usage. Computational cost for rendering is not obviously affected by SH degree in some implementations, but memory bandwidth becomes a bottleneck [S1].
- **When to use:** Use low degrees (0-2) for coarse lighting or memory-constrained environments. Use higher degrees (3-4) for high-fidelity rendering where directional detail is critical [S1].

## Background
The concept of limiting spherical harmonic expansions to a finite bandwidth is fundamental to signal processing on the sphere. In the context of volumetric rendering, specifically Direct Volume Ray Casting and Neural Radiance Fields (NeRF), SH degree selection became a critical hyperparameter for balancing quality and resource usage. Empirical studies on DVGO (Direct Voxel Grid Optimization) demonstrated the quantitative impact of degree selection on PSNR [S1]. The technique is widely used in modern 3D Gaussian Splatting implementations to manage the complexity of directional appearance [S2, unofficial].
