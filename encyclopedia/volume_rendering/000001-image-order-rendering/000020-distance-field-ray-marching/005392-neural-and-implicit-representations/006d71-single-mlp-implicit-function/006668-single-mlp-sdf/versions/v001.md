# Single MLP SDF

Also called: MLP SDF, SDF decoder, Single MLP

## Overview
Single MLP SDF is a coordinate-based neural implicit representation that parameterizes a signed distance field (SDF) using a single Multi-Layer Perceptron (MLP) $f_\theta$ [S2]. It solves the problem of representing continuous 3D geometry without voxelization or explicit mesh extraction by mapping 3D coordinates directly to distance values [S2]. Unlike hierarchical grid-based methods (e.g., [HIGS](21357-single-mlp-implicit-function.md)) that rely on learned feature grids, this method relies entirely on the MLP's capacity to approximate the distance function, often augmented with fixed positional encoding [S2]. It is distinct from [Ray Marching with Neural SDF](2409-ray-marching-with-neural-sdf.md) in that it specifically denotes the *decoder architecture* (a single MLP) rather than the rendering pipeline, and from [Implicit Neural Representation (INR)](19545-implicit-neural-representation-inr.md) by its specific application to SDFs using a single-layer network structure [S1, unofficial][S2].

## How it works
**Inputs and Outputs**
*   **Input:** A 3D point $x \in \mathbb{R}^3$.
*   **Output:** A scalar signed distance value $\hat{s} \in \mathbb{R}$.

**Data Structures**
*   **MLP Parameters $\theta$:** A single set of weights and biases for the decoder network. The network is a single-layer MLP (one hidden layer) with a hidden dimension of 64 [S1, unofficial].
*   **Positional Encoding $\gamma(x)$:** A fixed mapping that transforms the input coordinate $x$ into a higher-dimensional space to increase the network's expressiveness [S2]. The specific implementation of $\gamma$ is not detailed in the provided notes, but it is described as a "fixed positional encoding" [S2].

**Algorithm**
1.  **Positional Encoding:** Compute the encoded representation $\gamma(x)$ of the input point $x$.
2.  **MLP Forward Pass:** Pass $\gamma(x)$ through the single-layer MLP $f_\theta$ to compute the predicted SDF value $\hat{s}$.

**Formula**
The computation is defined as [S2]:
$$ \hat{s} = f_\theta(\gamma(x)) $$
where:
*   $\hat{s}$ is the predicted SDF value.
*   $f_\theta$ is the single-layer MLP parameterized by $\theta$.
*   $\gamma(x)$ is the fixed positional encoding of point $x$.

**Training Procedure**
The method is trained offline using a joint optimization strategy [S1, unofficial].
1.  **Dataset Compilation:** Compile an offline training dataset using six scenes from the Replica dataset [S1, unofficial].
2.  **View Simulation:** Randomly simulate 128 camera views with ground truth poses for each scene [S1, unofficial].
3.  **Optimization Setup:**
    *   Use the Adam optimizer with a learning rate of $10^{-3}$ [S1, unofficial].
    *   Train for a total of 1200 epochs [S1, unofficial].
    *   Use the SDF loss defined in Problem 1 of the source [S1, unofficial].
4.  **Coarse-to-Fine Strategy:** Activate all fine-level features after 200 epochs [S1, unofficial]. *Note: This step implies the context of hierarchical features, but for the pure "Single MLP" definition, the core inference remains $f_\theta(\gamma(x))$.*
5.  **Finalization:** After training, discard any associated grid features (if applicable in the broader context) and save only the decoder parameters $\theta$ [S1, unofficial].

## Operating characteristics
*   **Time Complexity:** Inference is $O(1)$ with respect to spatial resolution, but depends on the MLP depth and width. For a single-layer MLP with hidden dimension 64, the cost is low per query. However, ray marching requires many queries per pixel, making it slower than grid-based lookups [S2].
*   **Memory Complexity:** $O(D^2)$ where $D$ is the hidden dimension (64). It stores only the MLP weights, resulting in very low memory footprint compared to dense grids [S1, unofficial][S2].
*   **Strengths:** Resolution-independent representation; compact storage (only $\theta$ is saved) [S1, unofficial][S2]; simple architecture [S1, unofficial].
*   **Limitations:** High query cost for ray marching; potential difficulty in capturing high-frequency details with a single-layer MLP compared to deeper networks or hybrid methods [S2].
*   **When to use:** When memory is constrained and the geometry is relatively smooth or can be represented by a simple MLP [S2].
*   **When not to use:** For high-resolution scenes requiring fine details where grid-based methods (e.g., [HIGS](21357-single-mlp-implicit-function.md)) or deeper networks might perform better [S1, unofficial][S2].

## Background
The Single MLP SDF approach originates from the use of coordinate-based neural networks for implicit surface reconstruction [S2]. It was popularized by the introduction of positional encoding for novel view synthesis [S2]. The specific configuration of a single-layer MLP with hidden dimension 64 for SDF decoding is detailed in the HIGS paper [S1, unofficial]. The use of fixed positional encoding $\gamma(x)$ to map coordinates to a higher-dimensional space is a standard technique in neural implicit representations [S2].
