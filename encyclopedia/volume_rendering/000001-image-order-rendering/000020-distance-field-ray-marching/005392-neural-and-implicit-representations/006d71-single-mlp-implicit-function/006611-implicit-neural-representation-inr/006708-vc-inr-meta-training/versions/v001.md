# VC-INR Meta-Training
Also called: INR Meta-training stage

## Overview
VC-INR Meta-Training is the pre-training phase for Variational Compression of Implicit Neural Representations (VC-INR), designed to learn a shared network parameterization and a latent modulation initialization that enables rapid adaptation to new data instances [S1, unofficial]. It solves the problem of initializing an Implicit Neural Representation (INR) such that a small set of latent parameters can quickly adapt the shared weights to fit specific data (e.g., images or audio) with minimal storage overhead [S1, unofficial]. Unlike standard INR training which optimizes weights for a single instance, this method uses meta-learning to optimize the initialization itself, allowing the model to generalize across a distribution of data types [S1, unofficial]. It differs from siblings like WIRE by focusing on the meta-initialization of modulations rather than positional encoding, and from SPW by optimizing latent codes for compression rather than semantic priors [S1, unofficial].

## How it works
**Inputs and Outputs:**
*   **Input:** A dataset $\{x_i, y_i\}_{i=1}^N$ where $x$ represents input coordinates (e.g., pixel positions, audio samples) and $y$ represents target values (e.g., pixel intensities, audio amplitudes).
*   **Output:** A shared network parameter vector $\theta$ and a latent modulation initialization vector $\phi_0$ [S1, unofficial].

**Data Structures:**
*   **Shared Network ($\theta$):** A neural network $f(x, \theta, \phi)$ parameterized by $\theta$. The architecture typically uses LayerNorm to stabilize training [S1, unofficial].
*   **Latent Modulation Initialization ($\phi_0$):** A vector of parameters that modulate the shared network.
*   **Adapted Latent Modulation ($\phi_j$):** The result of adapting $\phi_0$ for a specific instance $j$ [S1, unofficial].

**Parameters:**
*   $\alpha$: Inner-loop step size (meta-learned).
*   $\beta$: Outer-loop step size [S1, unofficial].
*   $B$: Batch size for sampling [S1, unofficial].

**Algorithm:**
The method minimizes the expected loss after one step of inner-loop adaptation. The inner loop adapts the latent modulation $\phi_0$ to fit a specific instance, and the outer loop updates the shared parameters $\theta$ and the initialization $\phi_0$ to minimize the loss on the adapted model [S1, unofficial].

1.  Initialize shared network parameters $\theta$ and latent modulation initialization $\phi_0$.
2.  While not converged:
    a. Sample a batch of data $B = \{(x_j, y_j)\}_{j=1}^B$.
    b. For each instance $j$ in $B$:
        i. Compute the adapted latent modulation $\phi_j$ by taking one gradient step on $\phi_0$:
           $$ \phi_j = \phi_0 - \alpha \nabla_{\phi_0} L_{MSE}(f(x_j, \theta, \phi_0), y_j) $$
    c. Compute the outer-loop gradients using the adapted models $\phi_j$:
        i. Update $\phi_0$:
           $$ \phi_0 \leftarrow \phi_0 - \beta \mathbb{E}_{j \in B} [\nabla_{\phi_0} L_{MSE}(f(x_j, \theta, \phi_j), y_j)] $$
        ii. Update $\theta$:
           $$ \theta \leftarrow \theta - \beta \mathbb{E}_{j \in B} [\nabla_{\theta} L_{MSE}(f(x_j, \theta, \phi_j), y_j)] $$

**Pseudocode:**
```python
def vc_inr_meta_training(dataset, shared_network, initial_phi_0, alpha, beta, batch_size, max_iterations):
    """
    VC-INR Meta-Training Algorithm.
    
    Args:
        dataset: List of tuples (x, y).
        shared_network: Function f(x, theta, phi) returning prediction.
        initial_phi_0: Initial latent modulation vector phi_0.
        alpha: Inner-loop step size (meta-learned).
        beta: Outer-loop step size.
        batch_size: Number of samples per batch.
        max_iterations: Maximum number of outer-loop updates.
        
    Returns:
        theta: Shared network parameters.
        phi_0: Optimized latent modulation initialization.
    """
    # Initialize shared network parameters theta
    theta = initialize_shared_network_parameters()
    
    # Current phi_0 is passed in or initialized
    phi_0 = initial_phi_0
    
    for iteration in range(max_iterations):
        # Sample batch
        batch = sample_batch(dataset, batch_size)
        
        # Accumulators for outer-loop gradients
        grad_phi_0_sum = zeros_like(phi_0)
        grad_theta_sum = zeros_like(theta)
        
        for x_j, y_j in batch:
            # Inner-loop adaptation: compute phi_j
            # phi_j = phi_0 - alpha * grad_phi_0 L_MSE(f(x_j, theta, phi_0), y_j)
            # We need the gradient of the loss with respect to phi_0 at phi_0
            loss_at_phi_0 = mse_loss(shared_network(x_j, theta, phi_0), y_j)
            grad_phi_0_at_phi_0 = gradient(loss_at_phi_0, phi_0)
            phi_j = phi_0 - alpha * grad_phi_0_at_phi_0
            
            # Outer-loop update: compute gradients using the adapted phi_j
            # We need gradients of L_MSE(f(x_j, theta, phi_j), y_j) w.r.t phi_0 and theta
            loss_at_phi_j = mse_loss(shared_network(x_j, theta, phi_j), y_j)
            
            # Gradient w.r.t phi_0
            # Note: phi_j depends on phi_0, so we compute the full gradient
            grad_phi_0_at_phi_j = gradient(loss_at_phi_j, phi_0)
            grad_phi_0_sum += grad_phi_0_at_phi_j
            
            # Gradient w.r.t theta
            grad_theta_at_phi_j = gradient(loss_at_phi_j, theta)
            grad_theta_sum += grad_theta_at_phi_j
        
        # Update phi_0 and theta
        batch_size_actual = len(batch)
        phi_0 = phi_0 - beta * (grad_phi_0_sum / batch_size_actual)
        theta = theta - beta * (grad_theta_sum / batch_size_actual)
        
    return theta, phi_0
```

**Edge Cases and Pitfalls:**
*   **Instability:** Meta-learning is highly unstable by default, especially with large dimensions of $\phi$ [S1, unofficial]. This requires extensive hyperparameter search [S1, unofficial].
*   **LayerNorm:** LayerNorm is essential to smooth the loss landscape and bound the norm of $\phi$, preventing divergence [S1, unofficial].
*   **Step Size:** The step size $\alpha$ is meta-learned (MetaSGD) and acts as a preconditioner for the gradient [S1, unofficial].

## Subtopics

### [Geometric Implicit Neural Representation](21468-geometric-implicit-neural-representation.md)
A Geometric INR is a neural network $f: \mathbb{R}^3 \rightarrow \mathbb{R}$ that approximates a Signed Distance Function (SDF) of a regular surface $S$, characterized by the property that the magnitude of its gradient is approximately unity ($\|\nabla f\| \approx 1$). It solves the problem of reconstructing 3D geometry from sparse or noisy input data (such as oriented point clouds or posed images) by enforcing geometric constraints, specifically the Eikonal equation and normal alignment, during training. Unlike standard INRs that may only fit data values, Geometric INRs explicitly regularize the differential properties of the implicit function to ensure the zero-level set represents a clean, regular surface without spurious components.

## Operating characteristics
*   **Time Complexity:** The method requires two forward and backward passes per instance per batch (one for inner-loop adaptation, one for outer-loop gradient computation), making it computationally expensive compared to standard INR training [S1, unofficial].
*   **Memory Complexity:** Requires storing gradients for both $\theta$ and $\phi_0$ for the outer loop, and temporary storage for $\phi_j$ during the inner loop [S1, unofficial].
*   **Performance:** VC-INR achieves compression performance comparable to JPEG and JPEG-2000 on standard benchmarks like Kodak and CIFAR-10, with PSNR values ranging from 22.76 to 48.32 depending on the bit-per-pixel (bpp) rate [S1, unofficial].
*   **Strengths:** Effectively utilizes increasing network capacity (width), unlike methods like Functa which show decreasing performance for non-linear mappings [S1, unofficial].
*   **Limitations:** Highly sensitive to hyperparameters due to instability; requires LayerNorm for stable training [S1, unofficial].

## Background
VC-INR Meta-Training was introduced in the paper "Modality-Agnostic Variational Compression of Implicit Neural Representations" by Schwarz et al. (2023) [S1, unofficial]. It builds upon the MAML (Model-Agnostic Meta-Learning) framework, adapting it for implicit neural representations to enable efficient compression by learning a good initialization for latent modulations [S1, unofficial]. The method is part of a broader effort to compress INRs for storage and transmission, leveraging the fact that a small number of bits can encode a latent code that adapts a shared network to a specific instance [S1, unofficial].
