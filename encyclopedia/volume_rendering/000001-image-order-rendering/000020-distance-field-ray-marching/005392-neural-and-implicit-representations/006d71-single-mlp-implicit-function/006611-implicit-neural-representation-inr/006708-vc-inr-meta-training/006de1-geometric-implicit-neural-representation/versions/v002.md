# Geometric Implicit Neural Representation

Also called: Geometric INR, Implicit Neural Representation for SDFs, Neural SDF with geometric losses

## Overview
A Geometric Implicit Neural Representation (Geometric INR) is a neural network $f: \mathbb{R}^3 \rightarrow \mathbb{R}$ that approximates a Signed Distance Function (SDF) of a regular surface $S$, characterized by the property that the magnitude of its gradient is approximately unity ($\|\nabla f\| \approx 1$) [S1]. It solves the problem of reconstructing 3D geometry from sparse or noisy input data (such as oriented point clouds or posed images) by enforcing geometric constraints, specifically the Eikonal equation and normal alignment, during training [S1]. Unlike standard INRs that may only fit data values, Geometric INRs explicitly regularize the differential properties of the implicit function to ensure the zero-level set represents a clean, regular surface without spurious components [S1].

## How it works
**Inputs and Outputs**
*   **Input Data:** Either an oriented point cloud $\{p_i, N_i\}_{i=1}^n$ sampled from the surface $S$ (where $p_i \in S$ and $N_i$ is the normal at $p_i$), or a set of posed images $\{I_j\}$ with projection matrices $W_j$ mapping screen coordinates to world coordinates [S1].
*   **Output:** A trained neural network $f_\theta: \mathbb{R}^3 \rightarrow \mathbb{R}$ approximating the SDF, from which the geometry is extracted as the zero-level set $S \approx f^{-1}(0)$ [S1].

**Data Structures**
*   **Neural Network $f_\theta$:** A coordinate-based neural network (e.g., MLP) with parameters $\theta$ [S1].
*   **Training Domain $\Omega$:** The spatial region over which the Eikonal regularization integral is computed [S1].
*   **Point Sets:** Surface points $P = \{p_i\}$ with normals $N = \{N_i\}$, and additional regularization points $Q = \{q_k\}$ sampled outside the surface to mitigate noise [S1].

**Loss Function**
The total loss $L(\theta)$ combines data constraints and geometric regularization:
$$ L(\theta) = L_{data}(\theta) + L_{Eik}(\theta) $$
[S1]

1.  **Eikonal Regularization ($L_{Eik}$):** Enforces the SDF property $\|\nabla f\| = 1$ throughout the training domain $\Omega$:
    $$ L_{Eik}(\theta) = \int_{\Omega} (\|\nabla f\| - 1)^2 dp $$
    [S1]
2.  **Normal Alignment:** Enforces alignment between the network gradient and surface normals on $S$:
    $$ L_{normal}(\theta) = \int_{S} (1 - \langle \nabla f, N \rangle) dS $$
    [S1]
3.  **Data Constraint ($L_{data}$):** For point clouds, enforces $f(p_i) = 0$ and $\nabla f(p_i) = N_i$ [S1]. For images, enforces photometric consistency $I(\theta, W_j) = I_j$ via differentiable rendering [S1].

**Numbered Steps**
1.  **Define Input Data:** Acquire either an oriented point cloud $\{p_i, N_i\}$ or posed images $\{I_j\}$ with projection matrices $W_j$ [S1].
2.  **Sample Regularization Points:** If using point clouds, sample additional points $\{q_k\}$ outside the surface points $\{p_i\}$ to prevent spurious zero-level set components [S1].
3.  **Define Network:** Initialize the neural network $f_\theta: \mathbb{R}^3 \rightarrow \mathbb{R}$ with parameters $\theta$ [S1].
4.  **Construct Loss:** Formulate $L(\theta)$ using the Eikonal term over $\Omega$, the normal alignment term over $S$, and the data term ($L_{data}$) [S1].
5.  **Optimize:** Use a variant of gradient descent with mini-batches to minimize $L(\theta)$ [S1]. Mini-batches are necessary because computing the full gradient $\nabla L$ is often infeasible due to dataset size [S1].
6.  **Inference:** Extract the geometry by computing the zero-level set $S \approx f^{-1}(0)$ [S1].

**Pseudocode**
```python
def train_geometric_inr(points, normals, domain_samples, num_epochs=1000, lr=1e-4):
    """
    Trains a Geometric INR to approximate an SDF.
    
    Args:
        points: Array of shape (N, 3) representing surface points p_i.
        normals: Array of shape (N, 3) representing normals N_i.
        domain_samples: Array of shape (M, 3) representing points q_k in domain Omega.
        num_epochs: Number of training iterations.
        lr: Learning rate.
        
    Returns:
        theta: Trained network parameters.
    """
    # Initialize network parameters theta (weights and biases of an MLP)
    theta = initialize_parameters()
    
    for epoch in range(num_epochs):
        # 1. Sample mini-batches of surface points
        batch_points, batch_normals = sample_batch(points, normals)
        
        # 2. Sample mini-batch of domain points for Eikonal regularization
        if domain_samples is not None:
            batch_domain = sample_batch(domain_samples)
        else:
            batch_domain = random_sample_in_bounding_box(batch_points)
            
        # 3. Compute forward pass for surface points
        f_surface = forward_model(batch_points, theta)
        grad_surface = compute_gradient(f_surface, batch_points)
        
        # 4. Compute forward pass for domain points
        f_domain = forward_model(batch_domain, theta)
        grad_domain = compute_gradient(f_domain, batch_domain)
        
        # 5. Compute Loss Terms
        
        # Data Loss: Enforce f(p) = 0 and grad(f)(p) = N
        loss_sdf = mean_squared_error(f_surface, zeros_like(f_surface))
        loss_normal = mean_squared_error(grad_surface, batch_normals)
        loss_data = loss_sdf + loss_normal
        
        # Eikonal Loss: Enforce ||grad(f)|| = 1 in domain Omega
        grad_norm_domain = vector_norm(grad_domain, axis=1)
        loss_eikonal = mean_squared_error(grad_norm_domain, ones_like(grad_norm_domain))
        
        # Total Loss
        loss = loss_data + loss_eikonal
        
        # 6. Backpropagate and optimize
        grad_theta = compute_gradient(loss, theta)
        theta = update_parameters(theta, grad_theta, lr)
        
    return theta

def compute_gradient(output, inputs):
    """
    Computes the gradient of the network output with respect to input points
    using reverse-mode automatic differentiation.
    """
    # Standard autograd implementation builds a computational graph
    # and propagates gradients backwards.
    grad = autograd_grad(output, inputs, grad_outputs=ones_like(output), create_graph=True)[0]
    return grad

def update_parameters(theta, grad_theta, lr):
    """Performs a gradient descent step."""
    return theta - lr * grad_theta

def sample_batch(data):
    """Randomly samples a subset of data points."""
    return data[torch.randint(0, len(data), size=(batch_size,))]

def random_sample_in_bounding_box(points):
    """Samples points uniformly within the axis-aligned bounding box of the input points."""
    min_coords = points.min(axis=0)
    max_coords = points.max(axis=0)
    return min_coords + torch.rand(batch_size, 3) * (max_coords - min_coords)

def forward_model(x, theta):
    """Evaluates the MLP forward pass."""
    # Standard MLP: x -> Linear -> Activation -> Linear -> ... -> scalar output
    return apply_mlp(x, theta)

def vector_norm(v, axis=1):
    """Computes the L2 norm along the specified axis."""
    return torch.sqrt(torch.sum(v**2, axis=axis))

def mean_squared_error(pred, target):
    """Computes the mean squared error between predictions and targets."""
    return torch.mean((pred - target)**2)

def initialize_parameters():
    """Initializes network weights and biases."""
    return torch.nn.ParameterDict({
        'W1': torch.randn(3, 64), 'b1': torch.zeros(64),
        'W2': torch.randn(64, 64), 'b2': torch.zeros(64),
        'W3': torch.randn(64, 1)
    })

def apply_mlp(x, params):
    """Standard MLP forward pass."""
    x = torch.relu(x @ params['W1'] + params['b1'])
    x = torch.relu(x @ params['W2'] + params['b2'])
    return x @ params['W3'] + params['b3']
```

**Edge Cases and Pitfalls**
*   **Sparse Sampling Noise:** Sparse sampling near the surface can introduce noise in regions with no data [S1]. This is handled by imposing the Eikonal equation on additional points outside the surface samples [S1].
*   **Spurious Components:** Enforcing $f(p_i)=0$ and $\nabla f(p_i)=N_i$ on oriented point clouds alone may result in spurious components on the zero-level set [S1]. Mitigation involves sampling additional points $\{q_k\}$ outside $\{p_i\}$ [S1].
*   **Infeasible Gradients:** Computing the full gradient $\nabla L$ may be infeasible due to dataset size; mini-batches must be used [S1].

## Operating characteristics
*   **Time Complexity:** Not given in the sources. Training time depends on the number of network parameters, the size of the mini-batches, and the number of epochs [S1].
*   **Memory Complexity:** Not given in the sources. Memory usage is dominated by the storage of the neural network parameters and the active mini-batches of points and normals during training [S1].
*   **Strengths:** Produces smooth, regular surfaces; leverages differential properties (normals, curvatures) for robust reconstruction; suitable for dynamic scenes by extending domain to space-time $\mathbb{R}^3 \times \mathbb{R}$ [S1].
*   **Limitations:** Requires careful sampling of the training domain $\Omega$ to avoid noise; inference requires extracting the zero-level set via sphere tracing or level-set methods [S1].
*   **When to Use:** 3D reconstruction from oriented point clouds or posed images, surface animation, and dynamic geometric INRs [S1].
*   **When Not to Use:** Not given in the sources.

## Background
Geometric INRs are part of the broader family of Implicit Neural Representations (INRs), also known as neural fields or neural implicits [S1]. The specific focus on geometric constraints, particularly the Eikonal equation $\|\nabla f\| = 1$, stems from the need to regularize INRs trained on sparse data [S1]. Traditional implicit representations encode surfaces as zero-level sets of functions, but without geometric constraints, neural networks may produce irregular zero-level sets [S1]. The use of the Eikonal equation as a regularization term was introduced to ensure that the learned function behaves like a true Signed Distance Function, providing stable normals and enabling applications like sphere tracing and surface evolution [S1]. Recent frameworks enhance training performance by exploring geometric losses and curvature information for adaptive sampling [S1].
