# Neural and Implicit Representations

Also called: Neural Implicit Surfaces, Neural SDFs, Neural Radiance Fields (NeRF) [S2, unofficial]

## Overview
Neural and Implicit Representations replace analytical Signed Distance Functions (SDFs) or voxel grids with parameterized neural networks (typically MLPs) to define scene geometry and appearance [S1][S2, unofficial]. This family solves the limitation of analytical SDFs, which cannot represent complex, organic, or data-driven shapes, by learning a continuous scalar field from data [S1]. It differs from [Ray-marched Shadows](1087-ray-marched-shadows.md) and other sibling methods by substituting the hand-crafted distance function $f(\mathbf{p})$ with a learned function $\Phi_\theta(\mathbf{p})$, enabling the rendering of high-fidelity, non-analytic geometry defined by latent codes or multi-view inputs [S1][S2, unofficial].

## Shared principles
All methods in this family operate on the principle that a neural network $\Phi_\theta: \mathbb{R}^3 \to \mathbb{R}$ (or $\mathbb{R}^3 \times \mathbb{R}^3 \to \mathbb{R}$ for view-dependent color) approximates a continuous implicit field. The surface is defined as the zero-level set $L_0(\Phi_\theta) = \{ \mathbf{x} \in \mathbb{R}^3 \mid \Phi_\theta(\mathbf{x}) = 0 \}$ [S1].

Rendering proceeds via ray marching (typically sphere tracing or uniform sampling) along rays $r(t) = \mathbf{o} + t\mathbf{d}$. At each sample point $\mathbf{p}$, the network is queried to obtain the SDF value $d = \Phi_\theta(\mathbf{p})$ and potentially the color/emission $c$. The SDF value determines the step size in sphere tracing or the density/extinction coefficient in volumetric integration [S1][S2, unofficial].

Normals are estimated analytically via the gradient of the network output using backpropagation or numerically via finite differences:
$$
\mathbf{n}(\mathbf{p}) = \frac{\nabla \Phi_\theta(\mathbf{p})}{\|\nabla \Phi_\theta(\mathbf{p})\|}
$$
[S1][S2, unofficial].

Training involves minimizing a loss between rendered images and ground truth, often using differentiable rendering to propagate gradients through the ray marching and network evaluation steps [S1].

## Subtopics

### [Ray-marching on 3D Gaussians](1036-ray-marching-on-3d-gaussians.md)
A volumetric rendering method that evaluates the full Gaussian mixture along rays to accurately handle primitive overlap and compute the volumetric integral, contrasting with the rasterization-based approximations of standard 3D Gaussian Splatting (3DGS). It solves the problem of spatial overlap and incorrect self-attenuation inherent in 3DGS by performing adaptive sampling and analytical integration, ensuring that overlapping Gaussians are resolved with precision governed by sample count rather than rasterization artifacts. Unlike [RBF Particle Volume Path Tracing](9641-rbf-particle-volume-path-tracing.md) which uses different basis functions, this method retains the standard 3DGS Gaussian parameterization but changes the integration logic to be physically more accurate.

### [Ray Marching with Neural SDF](2409-ray-marching-with-neural-sdf.md)
Ray Marching with Neural SDF is a rendering technique that approximates the Space Distance Field (SDF) using a deep neural network and renders images by marching rays along the estimated distance field. It differs from traditional SDF ray marching by replacing the analytical distance function with a learned implicit representation, allowing for the rendering of complex, non-analytic shapes defined by latent codes.

### [RBF Particle Volume Path Tracing](9641-rbf-particle-volume-path-tracing.md)
RBF Particle Volume Path Tracing renders particle-based datasets (such as SPH fluid simulations) by modeling the volume as a continuous scalar field composed of additive weighted radial basis functions (RBFs), specifically Gaussians. This approach solves the visual clutter and pathological performance issues associated with BVH-based ray tracing of overlapping splatted particles by treating the volume as a single field rather than discrete geometry. It distinguishes itself from [Ray-marching on 3D Gaussians](1036-ray-marching-on-3d-gaussians.md) by using a BVH traversal for efficient spatial culling of contributing particles and from [Ray Marching with Neural SDF](2409-ray-marching-with-neural-sdf.md) by relying on explicit analytical kernels rather than learned implicit fields. It extends previous RBF implementations restricted to ray casting by integrating RBF reconstruction into a volume sampling kernel API that supports unbiased path tracing via delta tracking.

### [MetaNLR++](15259-metanlr.md)
MetaNLR++ is a neural rendering method for novel view synthesis that combines a neural implicit shape representation (a Signed Distance Function) with 2D CNN-based image feature extraction, aggregation, and re-projection. It solves the problem of slow training and rendering times associated with previous neural lumigraph methods by leveraging meta-learning to specialize initializations, enabling high-quality convergence in minutes and real-time rendering. Unlike volumetric methods like NeRF, MetaNLR++ renders explicit surfaces via sphere tracing, and unlike earlier neural surface methods like NLR++, it uses deep feature blending to inpaint geometry errors and avoid artifacts from imperfect shape reconstruction.

### NeuMesh Rendering Pipeline
A neural implicit rendering pipeline that learns a disentangled mesh-based implicit field for geometry and texture editing [S1].
*   **Step:** Pre-compute near-far bounds for each ray by counting the minimum and maximum distances of ray-to-mesh intersections. Sample 64 coarse points along the ray. Adopt a progressive up-sampling strategy to guide the sampling of 64 fine points, yielding 128 samples for each ray [S1].
*   **Formula:** Distillation loss: Supervised with output from the teacher model (NeuS) for queried color and SDF value. Formula referenced as Eq.(4) in Sec 3.2. Background supervision: Binary cross-entropy loss using foreground masks for unbounded backgrounds [S1].
*   **Parameter:** Batch size: 512 rays. Optimizer: Adam with initial learning rate 0.0005 and cosine annealing scheduler with 5000 warm-up steps. Hardware: Single Nvidia RTX3090-24G GPU. Training time: Approximately 16 hours for each model [S1].
*   **Layout:** Model Architecture: Geometry Code $l_g(x)$ (dim 32), Texture Code $l_t(x)$ (dim 32), Sign Distance $h(x)$ (dim 1). Interpolated Items include $l_t(x)$ (dim 32), gradient of SDF $|\nabla_x s|$ (dim 256), $s$ (dim 256), $\gamma$ (dim 256), $h(x)$ (dim 1), $d$ (dim 160), $\gamma$ (dim 32). Geometry Decoder outputs (256, 256, 256). Radiance Decoder outputs (3) [S1].

### Implicit Function Rendering Pipeline
A general rendering architecture combining an implicit function, sampling scheme, and renderer [S2, unofficial].
*   **Definition:** A rendering architecture that combines an implicit function (scene representation), a sampling scheme (raymarching), and a renderer to produce images from ray bundles [S2, unofficial].
*   **Step:** Forward pass: Call the renderer with the implicit function, the sampling routine, and the ray bundle. Image assembly: Reshape the output feature tensor to (image_size[1], image_size[0], 3) and convert to numpy array [S2, unofficial].

## Background
The concept of implicit surfaces dates back to constructive solid geometry, but neural representations emerged with the introduction of Neural Radiance Fields (NeRF) [S2, unofficial]. Subsequent works like DeepSDF and NeuS adapted this to explicit surface representations using SDFs [S1][S2, unofficial]. MetaNLR++ and NeuMesh represent recent advancements focusing on efficient training and explicit surface editing [S1]. These methods are widely used in novel view synthesis, 3D reconstruction, and geometric modeling [S1][S2, unofficial].
