# Two-Stage Optimization Pipeline

Also called: Finalizing Neural Scene Reconstruction

## Overview
The Two-Stage Optimization Pipeline is a post-processing refinement method for 3D Gaussian Splatting that decouples geometric alignment from material and lighting optimization [S1, unofficial][S2]. It corrects accumulated camera pose errors and refines coarse scene geometry in the first stage, then locks the Gaussian geometry to optimize material and lighting parameters using pre-computed per-Gaussian visibility [S1, unofficial][S2].

## How it works
**Inputs:** A set of registered images, initial camera poses (with seed image pose fixed), and an initial 3D Gaussian point cloud [S1, unofficial][S2].
**Outputs:** Optimized camera poses, refined 3D Gaussian primitives, and optimized material and lighting parameters [S1, unofficial][S2].

**Data Structures:**
*   **3D Gaussian Primitive:** Position, covariance matrix (or scale/rotation), opacity, spherical harmonic coefficients, and an additional normal vector $\mathbf{n}$ [S2].
*   **Camera Pose:** 6-DoF transformation matrix [S1, unofficial].
*   **Visibility Map:** Per-Gaussian visibility $V(\omega_i)$ pre-computed over the hemispherical domain defined by normal $\mathbf{n}$ [S2].

**Steps:**
1.  **Stage 1: Pose Correction.** Optimize all camera poses using point-to-camera ray consistency loss (Eq. 8 in [S1, unofficial]) to correct accumulated errors, fixing only the seed image pose. Use poses from previous training epochs as initial values [S1, unofficial].
2.  **Stage 1: Geometry Refinement.** Optimize a vanilla 3D Gaussian point cloud augmented with normal vectors $\mathbf{n}$, applying normal gradient-based densification [S2].
3.  **Stage 2: Visibility Pre-computation.** Pre-compute per-Gaussian visibility $V(\omega_i)$ across the hemispherical domain determined by $\mathbf{n}$ using ray tracing [S2].
4.  **Stage 2: Material and Lighting Optimization.** Lock the geometry of all 3D Gaussians and optimize material and lighting parameters using the pre-computed visibility [S2]. Refine scene details using explicit 3D Gaussian primitives densification and pruning strategies from [28] to improve rendering quality beyond the coarse geometry of the scene regressor [S1, unofficial].

**Pseudocode:**

```python
def two_stage_optimization(images, initial_poses, initial_gaussians):
    # Stage 1: Pose Correction
    fixed_pose_idx = 0  # Seed image pose is fixed
    optimized_poses = initial_poses.copy()
    # [G] Standard gradient descent on 6-DoF pose parameters, excluding fixed_idx, using point-to-camera ray consistency loss (Eq. 8)
    optimized_poses = optimize_poses(images, optimized_poses, fixed_pose_idx)
    
    # Stage 1: Geometry Refinement
    gaussians = initial_gaussians
    # [G] Augment each Gaussian with a normal vector n
    for g in gaussians:
        g.normal = compute_initial_normal(g)
    # [G] Differentiable rasterization optimization of positions, opacities, and normals
    gaussians = optimize_geometry(gaussians, images, optimized_poses)
    # [G] Normal gradient-based densification as specified in the method
    gaussians = apply_normal_gradient_densification(gaussians)
    
    # Stage 2: Visibility Pre-computation
    for g in gaussians:
        # Pre-compute visibility V(omega_i) over the hemispherical domain defined by n using ray tracing
        g.visibility = precompute_visibility(g.normal)
        
    # Stage 2: Material and Lighting Optimization
    # Lock geometry (positions, covariances, opacities, normals)
    locked_gaussians = lock_geometry(gaussians)
    # [G] Inverse rendering optimization of BRDF and lighting parameters using pre-computed visibility
    material_params, lighting_params = optimize_material_lighting(locked_gaussians, images, optimized_poses)
    # [G] Explicit 3D Gaussian primitives densification and pruning strategies from [28] to refine scene details
    gaussians = apply_densification_pruning(gaussians)
    
    return optimized_poses, gaussians, material_params, lighting_params
```

**Parameters:**
*   **Seed Image Pose:** Fixed during Stage 1 [S1, unofficial].
*   **Densification/Pruning Strategy:** From [28] (Not given in the sources) [S1, unofficial].
*   **Visibility Domain:** Hemispherical domain determined by normal $\mathbf{n}$ [S2].

**Edge Cases:**
*   **Accumulated Pose Errors:** Addressed by Stage 1 pose optimization [S1, unofficial].
*   **Coarse Geometry:** Addressed by Stage 2 densification/pruning and material optimization [S1, unofficial].
*   **GPU Memory Limitations:** Initial scene regressor uses low-resolution images, necessitating Stage 2 refinement [S1, unofficial].

## Operating characteristics
*   **Time Complexity:** Not given in the sources [S1, unofficial][S2].
*   **Memory Complexity:** Not given in the sources [S1, unofficial][S2].
*   **Performance:** Improves rendering quality beyond coarse geometry [S1, unofficial]. Enables realistic relighting [S2].
*   **Strengths:** Corrects accumulated pose errors, refines geometry, enables relighting [S1, unofficial][S2].
*   **Limitations:** Requires two stages, increasing complexity. Initial geometry may be coarse [S1, unofficial].
*   **When to Use:** When finalizing reconstruction after incremental registration or when relighting is required [S1, unofficial][S2].
*   **When Not to Use:** Not given in the sources [S1, unofficial][S2].

## Background
*   **Origin:** Proposed in [S1, unofficial] for finalizing neural scene reconstruction and in [S2] for point-based relighting.
*   **History:** Developed to address limitations of incremental registration and coarse geometry in scene regressors [S1, unofficial].
*   **Usage:** Used in 3DGS-based pose-free methods and point-based relighting pipelines [S1, unofficial][S2].
