# NeuMesh Rendering Pipeline

Also called: NeuMesh

## Overview
NeuMesh is a neural rendering method that represents scenes using a deformable mesh scaffold to decouple geometry and texture, enabling efficient ray marching with high-frequency detail synthesis [S1]. It solves the limitation of standard neural implicit fields (like NeuS) by providing an explicit mesh structure that supports geometry editing while maintaining the rendering quality of neural SDFs [S1]. It replaces generic SDF evaluation with a mesh-based interpolation of learned codes [S1].

## How it works
The method renders a scene by marching rays through a neural implicit field defined on a mesh. The core innovation is the disentanglement of geometry and texture into separate learnable codes associated with mesh vertices, which are interpolated during ray marching [S1].

### Inputs and Outputs
*   **Inputs**: Camera parameters (origin $\mathbf{o}$, direction $\mathbf{d}$), a triangular mesh scaffold (vertices $\mathbf{V}$, faces $\mathbf{F}$), and pre-trained neural network parameters [S1].
*   **Outputs**: Final pixel color $\hat{C}(\mathbf{r})$ [S1].

### Data Structures
The model architecture consists of two main components: the Geometry Code and the Texture Code, stored per vertex or interpolated [S1].

1.  **Geometry Code** $\mathbf{l}_g(\mathbf{x})$: A vector of dimension 32 [S1].
2.  **Texture Code** $\mathbf{l}_t(\mathbf{x})$: A vector of dimension 32 [S1].
3.  **Sign Distance** $h(\mathbf{x})$: A scalar value of dimension 1 [S1].
4.  **Interpolated Items**: During ray marching, these are computed for each sample point $\mathbf{x}$:
    *   $\nabla_{\mathbf{x}} s$: Gradient of the SDF, dimension 256 [S1].
    *   $s$: SDF value, dimension 256 [S1].
    *   $\gamma^{(i)}$: Positional encoding or frequency components, dimension 256 or 32 [S1].
    *   $h(\mathbf{x})$: Sign distance, dimension 1 [S1].
    *   $\mathbf{d}$: Auxiliary vector, dimension 160 [S1].
5.  **Decoders**:
    *   **Geometry Decoder**: Multi-Layer Perceptron (MLP) with 3 hidden layers, size 256, using SoftPlus activation [S1]. Outputs SDF-related features.
    *   **Radiance Decoder**: MLP with 4 hidden layers, size 256, using ReLU activation [S1]. Outputs radiance (color) with dimension 3 [S1].

### Algorithm Steps

1.  **Pre-computation of Bounds**:
    For each ray $\mathbf{r}$, compute the near and far bounds by finding the minimum and maximum distances of ray-to-mesh intersections [S1].

2.  **Coarse Sampling**:
    Sample 64 coarse points along the ray within the pre-computed bounds [S1].

3.  **Fine Sampling (Progressive Up-sampling)**:
    Use a progressive up-sampling strategy (as described in Wang et al. [55], referenced in [S1]) to guide the sampling of 64 fine points [S1]. This results in a total of 128 samples per ray (64 coarse + 64 fine) [S1].

4.  **Neural Field Evaluation**:
    For each sample point $\mathbf{p}$ on the ray:
    *   Interpolate the Geometry Code $\mathbf{l}_g$, Texture Code $\mathbf{l}_t$, and Sign Distance $h$ from the mesh vertices surrounding $\mathbf{p}$ [S1].
    *   Compute the SDF value $s$ and its gradient $\nabla_{\mathbf{x}} s$ using the Geometry Decoder [S1].
    *   Compute the radiance (color) using the Radiance Decoder [S1].

5.  **Volume Rendering**:
    Accumulate color and transmittance using standard volume rendering integration over the 128 samples [S1].

### Formulas
*   **Distillation Loss**: Supervised with output from the teacher model (NeuS) for queried color and SDF value [S1].
*   **Background Supervision**: Binary cross-entropy loss using foreground masks for unbounded backgrounds [S1].

### Pseudocode

```python
def render_ray(ray_origin, ray_direction, mesh, geometry_decoder, radiance_decoder, 
               geometry_codes, texture_codes, sign_distances):
    # Step 1: Pre-compute near-far bounds
    t_min, t_max = compute_ray_mesh_bounds(ray_origin, ray_direction, mesh)
    
    # Step 2: Sample 64 coarse points
    coarse_ts = sample_linear(t_min, t_max, num_samples=64)
    coarse_samples = [ray_origin + t * ray_direction for t in coarse_ts]
    
    # Step 3: Progressive up-sampling for 64 fine points
    # Guided by coarse samples to find SDF zero-crossings [S1]
    fine_ts = progressive_upsample(coarse_samples, geometry_decoder, geometry_codes, texture_codes, sign_distances, num_fine=64)
    fine_samples = [ray_origin + t * ray_direction for t in fine_ts]
    
    all_samples = coarse_samples + fine_samples
    
    accumulated_color = [0.0, 0.0, 0.0]
    accumulated_transmittance = 1.0
    beta = 100.0  # Temperature parameter [G]
    
    for p in all_samples:
        # Interpolate codes from mesh vertices at p
        l_g = interpolate_geometry_code(p, mesh, geometry_codes)
        l_t = interpolate_texture_code(p, mesh, texture_codes)
        h = interpolate_sign_distance(p, mesh, sign_distances)
        
        # Evaluate Geometry Decoder
        s, grad_s = geometry_decoder(l_g, l_t, h)
        
        # Evaluate Radiance Decoder
        c = radiance_decoder(l_g, l_t, h, grad_s)
        
        # Volume rendering step
        alpha = compute_alpha(s, beta)
        weight = accumulated_transmittance * alpha
        accumulated_color = [accumulated_color[i] + weight * c[i] for i in range(3)]
        accumulated_transmittance *= (1.0 - alpha)
        
        if accumulated_transmittance < 1e-4:
            break
            
    return accumulated_color

def compute_ray_mesh_bounds(origin, direction, mesh):
    t_vals = []
    for face in mesh.faces:
        t = ray_triangle_intersect(origin, direction, face)
        if t is not None:
            t_vals.append(t)
    return (min(t_vals), max(t_vals)) if t_vals else (0.0, float('inf'))

def sample_linear(t_min, t_max, num_samples):
    return [t_min + i * (t_max - t_min) / (num_samples - 1) for i in range(num_samples)]

def progressive_upsample(coarse_samples, geometry_decoder, geometry_codes, texture_codes, sign_distances, num_fine):
    # Samples points near coarse samples where SDF crosses zero [G]
    fine_ts = []
    for p in coarse_samples:
        l_g = interpolate_geometry_code(p, mesh, geometry_codes)
        # Query SDF to find zero-crossing interval, sample midpoint
        fine_ts.append(ray_origin + p * direction) 
    return fine_ts[:num_fine]

def interpolate_geometry_code(point, mesh, codes):
    face = find_containing_face(point, mesh)
    weights = compute_barycentric_weights(point, face)
    return sum(w * codes[v] for w, v in zip(weights, face.vertices))

def interpolate_texture_code(point, mesh, codes):
    face = find_containing_face(point, mesh)
    weights = compute_barycentric_weights(point, face)
    return sum(w * codes[v] for w, v in zip(weights, face.vertices))

def interpolate_sign_distance(point, mesh, distances):
    face = find_containing_face(point, mesh)
    weights = compute_barycentric_weights(point, face)
    return sum(w * distances[v] for w, v in zip(weights, face.vertices))

def compute_alpha(s, beta):
    return 1.0 - math.exp(-beta * max(0.0, s))
```

### Parameters
*   **Batch Size**: 512 rays [S1].
*   **Optimizer**: Adam [S1].
*   **Learning Rate**: Initial 0.0005 [S1].
*   **Scheduler**: Cosine annealing with 5000 warm-up steps [S1].
*   **Hardware**: Single Nvidia RTX3090-24G GPU [S1].
*   **Training Time**: Approximately 16 hours per model [S1].

### Edge Cases and Pitfalls
*   **Unbounded Backgrounds**: Standard NeuMesh assumes bounded scenes. For unbounded backgrounds, foreground masks must be used with binary cross-entropy loss during training to prevent background artifacts [S1].
*   **Geometry Editing Consistency**: When deforming the mesh, the local consistency of learnable signed distances must be maintained. Rotations of surface normals must be compensated in the learnable signed indicator $h(\mathbf{x})$ to ensure the interpolated SDF remains consistent [S1].
*   **Precision**: The SDF gradient $\nabla_{\mathbf{x}} s$ is used in the radiance decoder. Numerical instability in gradient computation can affect shading quality [S1].

## Subtopics

### Mixed Neural-Traditional Rendering Pipeline
A pipeline that integrates neural objects with traditional mesh rendering to support dynamic shadow casting across both in a single scene [S2]. Uses shared camera and light settings to generate rendering buffers, integrates scenes via depth-based composition, and applies shadow mapping for the final result [S2].

## Operating characteristics
*   **Time Complexity**: Rendering involves 128 samples per ray (64 coarse + 64 fine) [S1]. Pre-computing ray-mesh bounds accelerates the marching loop [S1].
*   **Memory Complexity**: Stores geometry codes (dim 32), texture codes (dim 32), and sign distances per vertex, plus the MLP parameters for the decoders (3-4 layers, 256 hidden units) [S1].
*   **Performance**: Trains in ~16 hours on a single RTX3090 [S1]. Rendering quality shows better appearance details than NeuS and NeuTex on DTU and NeRF Synthetic datasets [S1].
*   **Strengths**: Explicit mesh scaffold allows for geometry editing; disentangled codes improve high-frequency detail synthesis; efficient ray marching via pre-computed bounds [S1].
*   **Limitations**: Requires a pre-existing mesh scaffold; unbounded scenes require hybrid background modeling [S1].

## Background
NeuMesh was introduced to address the limitations of neural implicit fields in supporting geometry editing and efficient rendering [S1]. It builds on the principles of neural SDFs (like NeuS) but introduces a mesh-based representation to decouple geometry and texture [S1]. The method is used in 3D editing applications [S1].
