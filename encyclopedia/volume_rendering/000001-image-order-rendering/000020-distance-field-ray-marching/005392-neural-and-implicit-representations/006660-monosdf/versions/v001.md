# MonoSDF

Also called: MonoSDF: Exploring Monocular Geometric Cues for Neural Implicit Surface Reconstruction
## Overview
MonoSDF is a neural implicit surface reconstruction framework that integrates data-driven monocular geometric priors (depth and surface normals) into the optimization of signed distance functions (SDFs) [S1]. It solves the problem of poor reconstruction quality in textureless regions and limited-view scenarios, where standard photometric consistency fails [S1]. Unlike [Manhattan-SDF](link), which relies on dense multi-view stereo (MVS) depth maps and strict Manhattan world assumptions requiring semantic segmentation, MonoSDF uses general-purpose monocular estimators, removing the need for semantic labels and enabling scalability to larger, unstructured scenes [S1].
## How it works
**Inputs:** A set of $N$ posed RGB images $\{I_i\}_{i=1}^N$ with known camera poses. Pretrained monocular depth and normal estimators are used to generate initial depth maps $D_i$ and normal maps $N_i$ for each input image [S1].

**Outputs:** A neural implicit SDF field $f_\theta(\mathbf{x})$ and a color field $c_\theta(\mathbf{x})$ (or equivalent appearance representation) that reconstruct the 3D scene geometry and appearance [S1].

**Data Structures:**
The scene is represented by a neural network $f_\theta$ (e.g., an MLP or multi-resolution feature grid) parameterized by $\theta$. The network takes a 3D coordinate $\mathbf{x} \in \mathbb{R}^3$ as input and outputs a scalar SDF value $d = f_\theta(\mathbf{x})$ and a color vector $\mathbf{c} = c_\theta(\mathbf{x})$ [S1].

**Numbered Steps:**
1.  **Monocular Prior Estimation:** For each input image $I_i$, compute the predicted depth map $D_i$ and surface normal map $N_i$ using a general-purpose pretrained monocular estimator [S1].
2.  **Ray Sampling:** For each pixel in the input images, cast a ray $\mathbf{r}(t) = \mathbf{o} + t\mathbf{d}$ into the scene. Sample points along the ray. To reconstruct surfaces, points are typically sampled near the zero-level set of the SDF [S1][S2, unofficial].
3.  **Volume Rendering:** Evaluate the SDF $f_\theta(\mathbf{r}(t))$ and color $c_\theta(\mathbf{r}(t))$ at sampled points. Compute the volume rendering integral for RGB color, depth, and normal at each pixel. The rendered normal $\hat{\mathbf{n}}$ is derived from the gradient of the SDF: $\hat{\mathbf{n}} = \nabla f_\theta(\mathbf{x}) / \|\nabla f_\theta(\mathbf{x})\|$ [S1].
4.  **Loss Computation:** The total loss $\mathcal{L}$ combines photometric and geometric terms [S1]:
    $$ \mathcal{L} = \mathcal{L}_{rgb} + \lambda_d \mathcal{L}_{depth} + \lambda_n \mathcal{L}_{normal} $$
    Where:
    *   $\mathcal{L}_{rgb}$ is the photometric reconstruction loss between rendered RGB and input image RGB.
    *   $\mathcal{L}_{depth}$ is the consistency loss between rendered depth and the monocular depth prior $D_i$.
    *   $\mathcal{L}_{normal}$ is the consistency loss between rendered normals and the monocular normal prior $N_i$.
    *   $\lambda_d, \lambda_n$ are weighting hyperparameters [S1].
5.  **Optimization:** Minimize $\mathcal{L}$ with respect to network parameters $\theta$ using gradient descent [S1].

**Parameters:**
*   Image resolution: $384 \times 384$ pixels [S1].
*   Loss weights ($\lambda_d, \lambda_n$): Not given in the sources.

**Edge Cases and Pitfalls:**
*   **Textureless Regions:** Standard photometric loss fails here; monocular normals provide necessary constraints [S1].
*   **Scale Ambiguity:** Monocular depth is inherently scale-ambiguous. The SDF optimization must handle this, potentially through scale-invariant losses or normalization, though specific scaling strategies are not detailed in the provided notes [S1].
*   **Error Propagation:** Errors in monocular depth/normal predictions can mislead the SDF optimization. The complementary nature of photometric and recognition cues helps mitigate this [S1].

**Pseudocode:**
```python
def train_monosdf(images, poses, monocular_estimator, sdf_network, num_epochs):
    """
    Train MonoSDF using monocular geometric priors.
    """
    optimizer = Adam(sdf_network.parameters())
    
    # Precompute monocular priors
    monocular_depths = []
    monocular_normals = []
    for img in images:
        depth, normal = monocular_estimator.predict(img)
        monocular_depths.append(depth)
        monocular_normals.append(normal)
        
    for epoch in range(num_epochs):
        total_loss = 0
        for i, (img, pose) in enumerate(zip(images, poses)):
            # 1. Sample rays from image pixels
            rays = sample_rays_from_image(img, pose)
            
            # 2. Sample points along rays (e.g., near SDF zero-level set)
            points, t_vals = sample_points_along_rays(rays, sdf_network)
            
            # 3. Evaluate SDF and Color
            sdf_values = sdf_network(points)
            colors = sdf_network.get_color(points)
            
            # 4. Volume Render
            rendered_rgb, rendered_depth, rendered_normal = volume_render(
                points, sdf_values, colors, t_vals
            )
            
            # 5. Compute Losses
            # Photometric loss
            loss_rgb = mse(rendered_rgb, img)
            
            # Geometric losses against monocular priors
            # Note: Rendering depth/normal must be aligned with input image coordinates
            loss_depth = consistency_loss(rendered_depth, monocular_depths[i])
            loss_normal = consistency_loss(rendered_normal, monocular_normals[i])
            
            # Total Loss
            loss = loss_rgb + lambda_d * loss_depth + lambda_n * loss_normal
            
            # 6. Backpropagate
            optimizer.zero_grad()
            loss.backward()
            optimizer.step()
            
            total_loss += loss.item()
            
        print(f"Epoch {epoch}: Loss {total_loss / len(images)}")
```
[G] `volume_render` implements the standard volume rendering integral using the SDF to compute opacity weights (e.g., via the cumulative distribution function of the SDF). `consistency_loss` typically uses L1 or L2 distance. `sample_points_along_rays` should prioritize points near the zero-crossing of the SDF for surface reconstruction.

## Subtopics

### [MonoNeRD](17640-mononerd.md)
MonoNeRD is a monocular 3D target detection framework that models the scene as a Signed Distance Function (SDF) to achieve dense 3D geometric and occupancy representation. It distinguishes itself from standard NeRF-based detection by treating intermediate frustum representations as SDF-based NeRFs, which effectively masks out free space and reduces ambiguity in the feature volume. This approach was the first to introduce volume rendering into the monocular 3D detection (M3D) domain, demonstrating the potential for implicit reconstruction of image-based 3D perception.

## Operating characteristics
*   **Time Complexity:** Optimization is iterative and depends on the neural network size and number of sampled points per ray. Monocular priors are computed once offline, reducing per-iteration cost compared to MVS [S1].
*   **Memory Complexity:** Depends on the neural network architecture (MLP or feature grid) and the number of rays sampled. Not given in the sources.
*   **Strengths:** Improves reconstruction quality in textureless regions; scales to larger scenes; removes need for semantic segmentation and Manhattan world assumptions [S1].
*   **Limitations:** Relies on the accuracy of pretrained monocular estimators; scale ambiguity of monocular depth [S1].
*   **When to use:** When multi-view stereo is unreliable due to textureless regions or sparse views, and semantic segmentation is unavailable [S1].
*   **When not to use:** When high-precision metric depth is required without scale ambiguity, or when monocular priors are known to be inaccurate for the specific scene type [S1].

## Background
MonoSDF was introduced in the paper "MonoSDF: Exploring Monocular Geometric Cues for Neural Implicit Surface Reconstruction" published at NeurIPS 2022 [S1]. It builds on neural implicit surface reconstruction methods like NeuS [S2, unofficial]. It addresses limitations of previous works like Manhattan-SDF, which required dense MVS depth and semantic segmentation [S1]. The method leverages the complementary nature of photometric consistency and monocular recognition cues [S1].
