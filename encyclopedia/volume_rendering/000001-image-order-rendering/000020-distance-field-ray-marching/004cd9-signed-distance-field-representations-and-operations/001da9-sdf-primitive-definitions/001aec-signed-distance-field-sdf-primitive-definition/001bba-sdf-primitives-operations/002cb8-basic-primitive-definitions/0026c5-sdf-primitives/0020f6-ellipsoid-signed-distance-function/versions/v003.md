# Ellipsoid Signed Distance Function

Also called: Ellipsoid SDF

## Overview
Computes the signed distance from a 3D point to an ellipsoid defined by semi-axes radii, or to a 2D disk (a degenerate ellipsoid with one radius set to zero) for handling non-watertight surfaces like walls. It distinguishes itself from the [Sphere Signed Distance Function](1237-sphere-signed-distance-function.md) by supporting anisotropic scaling, and from the [Signed Box Distance Function](1092-signed-box-distance-function.md) by providing smooth, analytic curvature. Two variants exist: a fast approximation and a more accurate iterative-free formula.

## How it works
**Inputs:**
- Point $p \in \mathbb{R}^3$ in local ellipsoid coordinates.
- Radii vector $r = (r_x, r_y, r_z) \in \mathbb{R}^3_{>0}$ (or $r_z=0$ for a disk).

**Outputs:**
- Signed distance $d$. Positive outside, negative inside.

**Data Structures:**
- Vectors $p, r$ are standard 3D floats.

**Steps:**
1. Normalize the point by dividing by radii: $p' = p / r$.
2. Compute $k_1 = \|p'\|$.
3. Compute $k_2 = \|p / (r \cdot r)\|$ (where $r \cdot r$ is component-wise squaring).
4. Calculate distance: $d = \frac{k_1(k_1 - 1.0)}{k_2}$.

**Parameters:**
- $r_x, r_y, r_z$: Semi-axes lengths. Typical values depend on scene scale. For a 2D disk, set $r_z = 0$ and use the SDDF variant described in Background.

**Edge Cases:**
- If $r_i = 0$, the division is undefined. Use the 2D disk SDDF formulation instead [S1].
- If $k_2 \approx 0$ (point at origin), distance is 0.

**Pseudocode:**
```python
def ellipsoid_sdf(p: Vec3, r: Vec3) -> float:
    # p: point in local space
    # r: semi-axes (r_x, r_y, r_z)
    
    # Component-wise division
    p_div_r = p / r
    
    # k1 = length(p / r)
    k1 = length(p_div_r)
    
    # Component-wise squared radii
    r_sq = r * r
    
    # k2 = length(p / (r * r))
    p_div_r_sq = p / r_sq
    k2 = length(p_div_r_sq)
    
    # Avoid division by zero if point is at origin
    if k2 == 0.0:
        return 0.0
        
    # Formula: k1 * (k1 - 1.0) / k2
    d = k1 * (k1 - 1.0) / k2
    
    return d
```

**Alternative Approximation:**
A faster but less accurate variant uses the minimum radius:
$$d_{approx} = (k_1 - 1.0) \cdot \min(r_x, r_y, r_z)$$
This is valid for points far from the surface but fails to be a true SDF near the ellipsoid [S2, unofficial].

## Subtopics

### [Sphere Signed Distance Function](1237-sphere-signed-distance-function.md)
A special case where $r_x=r_y=r_z$. Use when isotropy is required.

### [Signed Box Distance Function](1092-signed-box-distance-function.md)
Use for axis-aligned rectangular volumes. The ellipsoid SDF is smoother but computationally heavier.

### [Capsule Signed Distance Function](2439-capsule-signed-distance-function.md)
Use for linear extrusions. The ellipsoid SDF is a single blob, not a line segment.

## Operating characteristics
- **Time Complexity:** $O(1)$ with a few multiplications, divisions, and a square root.
- **Memory Complexity:** $O(1)$.
- **Strengths:** Analytic, differentiable, handles anisotropy. The accurate formula is exact for the ellipsoid shape.
- **Limitations:** The accurate formula can be numerically unstable if $k_2$ is very small. The approximation is not a true SDF (gradient magnitude $\neq 1$).
- **When to use:** When anisotropic shapes are needed and analytical gradients are required for ray marching or optimization.

## Background
The ellipsoid SDF is derived from the geometric property that an ellipsoid is a scaled sphere. The accurate formula $d = \frac{k_1(k_1 - 1.0)}{k_2}$ is attributed to Inigo Quilez [S2, unofficial]. It is widely used in ray marching for soft shadows and reflections. The 2D disk variant is used in recent neural rendering approaches to handle non-watertight objects like curtains or walls by setting one radius to zero, resulting in a Signed Directional Distance Function (SDDF) [S1].
