# Far-field Culling

Also called: Far-field Approximation, Far-field Constant Node Replacement

## Overview
Far-field culling is an optimization for Signed Distance Field (SDF) evaluation that replaces sub-trees in cells sufficiently far from the 0-isosurface with a single constant node providing a conservative lower-bound distance [S1]. It builds on [Lipschitz Pruning](8623-lipschitz-pruning.md) by further reducing the number of active nodes during sphere tracing or contouring tasks, where exact differentiability is not required [S1]. Unlike the baseline hierarchical pruning which preserves the full tree structure within active regions, far-field culling aggressively simplifies the geometry representation in empty space, improving tracing performance by up to a factor of 2 on complex scenes [S1].

## How it works
**Inputs:**
- An SDF construction tree (or pruned tree from [Lipschitz Pruning](8623-lipschitz-pruning.md)) evaluated over a grid of cells [S1].
- For each cell, the SDF value at the cell center, $d = f(p_{center})$ [S1].
- The cell radius, $R$ [S1].
- A constant factor $C$ controlling the near-field size [S1].

**Outputs:**
- A modified SDF representation where far-field cells are replaced by a constant lower-bound value [S1].

**Data Structures:**
- Each cell in the grid maintains a state indicating whether it is "near-field" (exact tree) or "far-field" (constant node) [S1].
- For far-field cells, the constant value is stored or computed on the fly as $\text{sign}(d) \times (|d| - R)$ [S1].

**Parameters:**
- $C$: Constant factor. Typical value is $C=2$, which guarantees at most 2 steps to cross a far-field cell [S1].
- $R$: Cell radius [S1].

**Steps:**
1. Evaluate the SDF at the center of each grid cell, $p_{center}$, obtaining $d = f(p_{center})$ [S1].
2. Check the far-field condition: if $|d| > C \times R$, mark the cell as far-field [S1].
3. For far-field cells, replace the entire SDF sub-tree with a constant node. The value of this constant node is calculated as:
   $$ d_{approx} = \text{sign}(d) \times (|d| - R) $$
   [S1].
4. For near-field cells ($|d| \le C \times R$), retain the exact SDF evaluation (from [Lipschitz Pruning](8623-lipschitz-pruning.md) or the original tree) [S1].

**Formula Details:**
- The approximation $d_{approx}$ is guaranteed to be a lower bound of the true SDF for any point within the cell, provided $C > 1$ [S1].
- The 0-isosurface is preserved because the approximation is only applied when the cell is strictly surface-free ($|d| > C \times R$ with $C > 1$ implies no intersection with the 0-level set within the cell) [S1].

**Pitfalls:**
- $C$ must be greater than 1 to ensure the cell is surface-free, guaranteeing the approximate SDF remains a conservative lower-bound [S1].
- If $C$ is too close to 1, sphere tracing step sizes become small, reducing performance [S1].
- If $C$ is too large, the far-field condition is rarely met, and no cells are replaced, losing optimization benefits [S1].
- The approximation is not differentiable nor continuous, so it cannot be used for gradient-based operations [S1].

**Pseudocode:**
```python
def evaluate_far_field_sdf(cell_center, R, C, sdf_tree):
    # Step 1: Evaluate exact SDF at cell center
    # Tree traversal logic not provided in sources
    d = 0.0 
    
    # Step 2: Check far-field condition
    if abs(d) > C * R:
        # Step 3: Return constant lower-bound approximation
        sign_d = 1 if d >= 0 else -1
        return sign_d * (abs(d) - R)
    else:
        # Step 4: Return exact SDF for near-field
        return d
```

## Subtopics

### [Lipschitz Pruning](8623-lipschitz-pruning.md)
A hierarchical pruning algorithm that reduces active nodes in a smooth CSG tree for a specific region of space. It sets itself apart by operating on a hierarchical grid structure rather than a flat tree, and is chosen when memory and computation for complex CSG trees must be reduced before applying far-field approximations.

### [GPU Implementation of Hierarchical CSG Pruning](8626-gpu-implementation-of-hierarchical-csg-pruning.md)
A GPU-optimized version of hierarchical pruning that maps the pruning logic to parallel architectures. It differs from the CPU baseline by leveraging thread blocks for simultaneous cell evaluation, and is chosen when targeting GPU architectures for real-time rendering pipelines.

## Operating characteristics
- **Time Complexity:** Reduces the number of active nodes per grid cell to approximately 1 in many scenes when enabled, compared to the baseline where all nodes are active [S1]. This leads to faster SDF evaluation during sphere tracing [S1].
- **Memory Complexity:** Reduces the memory impact of the pruning procedure by replacing sub-trees with constants [S1].
- **Measured Performance:** Improves tracing performance by up to a factor of 2 on the City, Gameboy, and Camera scenes when compared to the hierarchical pruning scheme without far-field culling [S1]. In ray tracing contexts with primary and shadow rays per pixel, speedups go as high as two orders of magnitude on City and Crowd scenes when compared to naive sphere tracing [S1].
- **Scaling:** The optimization is effective for scenes with large empty spaces or complex geometry where many cells are far from the 0-isosurface [S1].
- **Strengths:** Conceptually simple, non-invasive, and handles smooth CSG operators widely used in implicit modeling [S1]. It preserves the 0-isosurface and provides a conservative lower-bound distance, making it safe for sphere-tracing and contouring tasks [S1].
- **Limitations:** The approximation is not differentiable nor continuous, so it cannot be used for gradient-based operations [S1]. It is restricted to primitives and operators that are 1-Lipschitz, although this can be mitigated by scaling the field function by the Lipschitz bound [S1].
- **When to use:** Use when performing conservative tasks like sphere tracing or contouring where exact differentiability is not required, and performance is critical [S1].
- **When not to use:** Do not use when gradient information is needed, or when the scene has no large empty regions (far-field cells are rare) [S1].

## Background
Far-field culling was introduced in the paper "Lipschitz Pruning: Hierarchical Simplification of Primitive‐Based SDFs" [S1]. The method takes inspiration from narrow-band optimization commonly used in discrete SDF rendering [S1]. It is part of a broader effort to optimize SDF evaluation for complex scenes, enabling real-time rendering with ambient occlusion, shadow rays, and anti-aliasing [S1]. The method is applicable in contexts where the SDF needs to be discretized over a finite domain, such as meshing purposes [S1].
