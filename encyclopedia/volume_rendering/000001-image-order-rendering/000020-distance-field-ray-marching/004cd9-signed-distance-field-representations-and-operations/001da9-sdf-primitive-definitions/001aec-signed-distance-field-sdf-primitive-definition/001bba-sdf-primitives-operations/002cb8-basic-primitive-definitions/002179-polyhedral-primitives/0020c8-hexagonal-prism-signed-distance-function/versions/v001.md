# Hexagonal Prism Signed Distance Function

Also called: Hexagonal Prism SDF, Signed Hexagonal Prism, sdHexPrism

## Overview
Computes the signed Euclidean distance from a point to a hexagonal prism aligned with the Z-axis, defined by its half-width $h_x$ and half-height $h_y$ [S1, S2, unofficial]. It differs from the triangular prism by utilizing six-fold rotational symmetry to reflect the query point into a fundamental sector, reducing the distance calculation to a simpler 2D case [S1, unofficial]. It is distinct from the octahedron, which uses linear interpolation of normals rather than geometric reflection [2339-octahedron-signed-distance-function.md].

## How it works
**Inputs:**
- `p`: Query point $(p_x, p_y, p_z)$ [S1, S2, unofficial].
- `h`: Parameter vector $(h_x, h_y)$, where $h_x$ is the hexagon radius (distance from center to vertex or flat side, depending on orientation convention) and $h_y$ is the half-height of the prism [S1, S2, unofficial].

**Outputs:**
- `d`: Signed distance. Positive outside, negative inside [S1, S2, unofficial].

**Data Structures:**
- No persistent data structures. The function is stateless.

**Steps:**
1.  **Absolute Value:** Compute $q = |p|$, i.e., $q_x = |p_x|, q_y = |p_y|, q_z = |p_z|$ [S1, S2, unofficial]. This exploits symmetry to work in the first octant.
2.  **Reflection (Fundamental Domain):** Reflect the point $(q_x, q_y)$ into the fundamental domain of the hexagon.
    *   Define constant vector $k = (-\cos(\pi/6), \sin(\pi/6), \tan(\pi/6)) \approx (-0.8660254, 0.5, 0.57735)$ [S1, unofficial].
    *   Compute dot product $dot = k_x q_x + k_y q_y$ [S1, unofficial].
    *   If $dot < 0$, reflect: $q_x \leftarrow q_x - 2 \cdot dot \cdot k_x$ and $q_y \leftarrow q_y - 2 \cdot dot \cdot k_y$ [S1, unofficial].
    *   *Note:* Source [S2, unofficial] uses a different orientation (flat-topped) and does not perform reflection, instead using a direct max formula. The reflection method [S1, unofficial] is more general for pointy-topped hexagons.
3.  **2D Hexagon Distance:** Calculate the distance to the hexagonal cross-section in the XY plane.
    *   Using the reflected $q_x, q_y$ and radius $h_x$:
    *   $d_{xy} = \max(q_x, q_y) - h_x$ [S2, unofficial] (for flat-topped).
    *   Or more generally for the reflected point: $d_{xy} = \text{length}(\max(q_x - \text{clamp}(q_x, -k_z h_x, k_z h_x), q_y - h_x, 0)) + \min(\max(q_x, q_y), 0)$ [S1, unofficial].
    *   *Simplified Implementation:* A common robust approach for the reflected point $(q_x, q_y)$ is:
        $d_{hex} = \max(q_x \cdot \frac{\sqrt{3}}{2} + q_y \cdot \frac{1}{2}, q_y) - h_x$ [S2, unofficial].
4.  **3D Prism Distance:** Combine with the Z-axis distance.
    *   $d_z = q_z - h_y$ [S1, S2, unofficial].
    *   $d = \min(\max(d_{hex}, d_z), 0) + \text{length}(\max(d_{hex}, d_z, 0))$ [S1, unofficial].
    *   Alternatively, using the max formula from [S2, unofficial]: $d = \max(d_z, d_{hex})$ [S2, unofficial]. *Note: [S1, unofficial] and [S2, unofficial] provide different formulations. [S1, unofficial] is the standard "min/max/length" SDF pattern for extruded shapes. [S2, unofficial] appears to be a simplified version for a specific orientation or approximation.* The [S1, unofficial] formulation is geometrically correct for the signed distance.

**Pseudocode:**
```python
import numpy as np

def sd_hex_prism(p: np.ndarray, h: np.ndarray) -> float:
    """
    Computes signed distance to a hexagonal prism.
    p: (3,) array, query point.
    h: (2,) array, [h_x, h_y]. h_x is hexagon radius, h_y is half-height.
    """
    # 1. Absolute value
    q = np.abs(p)
    qx, qy, qz = q[0], q[1], q[2]
    hx, hy = h[0], h[2] # Note: h[1] is h_y
    
    # 2. Reflection into fundamental domain (Pointy-topped hexagon)
    # k = (-cos(pi/6), sin(pi/6), tan(pi/6))
    kx, ky, kz = -np.cos(np.pi / 6.0), np.sin(np.pi / 6.0), np.tan(np.pi / 6.0)
    
    dot = kx * qx + ky * qy
    if dot < 0:
        qx = qx - 2.0 * dot * kx
        qy = qy - 2.0 * dot * ky
        
    # 3. Distance to hexagon cross-section
    # Using the formula from [S1, unofficial] for the reflected point
    # d_xy = length(max(q_xy - clamp(q_xy, ...), h_x, 0)) + min(max(q_xy), 0)
    # Simplified equivalent for the reflected sector:
    d_xy = np.sqrt(max(qx - hx, 0.0)**2 + max(qy - hx, 0.0)**2) # Approximation if not careful
    # Correct [S1, unofficial] formula:
    # d_xy = length(max(vec2(qx, qy) - vec2(clamp(qx, -kz*hx, kz*hx), hx), 0.0)) + min(max(qx, qy), 0.0)
    # However, since we reflected into the fundamental domain where qx >= 0 and qy >= 0, 
    # and the domain is bounded by the hexagon edge, a simpler check is often used:
    # d_xy = max(qx * 0.866025 + qy * 0.5, qy) - hx  [S2 orientation]
    
    # Let's stick to the robust [S1, unofficial] structure for the final distance calculation
    # d_xy calculation for the reflected point in the fundamental domain:
    # The fundamental domain is a triangle. The distance is to the hypotenuse or legs.
    # A standard implementation for the reflected point (qx, qy) is:
    d_xy = np.sqrt(max(qx - hx, 0.0)**2 + max(qy - hx, 0.0)**2) # This is for a square, not hex
    
    # Correct [S1, unofficial] logic:
    # d_xy = length(max(q_xy - clamp(q_xy, -kz*hx, kz*hx), hx, 0.0)) + min(max(qx, qy), 0.0)
    # Since qx, qy >= 0 after abs, and we reflected, we are in the sector.
    # Let's use the explicit [S1, unofficial] formula:
    clamp_x = np.clip(qx, -kz * hx, kz * hx)
    d_xy_vec = np.array([max(qx - clamp_x, 0.0), max(qy - hx, 0.0)])
    d_xy = np.linalg.norm(d_xy_vec) + min(max(qx, qy), 0.0)
    
    # 4. 3D Distance
    d_z = qz - hy
    d = min(max(d_xy, d_z), 0.0) + np.sqrt(max(d_xy, 0.0)**2 + max(d_z, 0.0)**2)
    
    return d
```
*Note: The pseudocode above attempts to reconcile [S1, unofficial] and [S2, unofficial]. [S2, unofficial] provides a much simpler formula `max(q.z-h.y, max(q.x*0.866025+q.y*0.5, q.y)-h.x)` which assumes a specific orientation (flat-topped) and does not use reflection. For a general implementation, the reflection method [S1, unofficial] is preferred for pointy-topped hexagons.*

**Simplified Pseudocode (Flat-topped, from [S2, unofficial]):**
```python
def sd_hex_prism_flat(p: np.ndarray, h: np.ndarray) -> float:
    q = np.abs(p)
    qx, qy, qz = q[0], q[1], q[2]
    hx, hy = h[0], h[1]
    d_xy = max(qx * 0.866025 + qy * 0.5, qy) - hx
    d_z = qz - hy
    return max(d_xy, d_z)
```

## Operating characteristics
- **Time Complexity:** $O(1)$ per query. Involves basic arithmetic operations and a square root.
- **Memory Complexity:** $O(1)$. No auxiliary storage.
- **Strengths:** Exact signed distance, enabling smooth collision detection and ray marching. Efficient for real-time rendering.
- **Limitations:** Orientation-dependent. The formula changes based on whether the hexagon is pointy-topped or flat-topped. [S1, unofficial] and [S2, unofficial] implement different orientations.

## Background
The Hexagonal Prism SDF is part of the family of polyhedral primitives used in ray marching and constructive solid geometry (CSG) [S1, S2, unofficial]. It was popularized in the context of GLSL SDF libraries for real-time graphics [S2, unofficial]. The reflection technique used in [S1, unofficial] is a standard method for handling hexagonal symmetry in SDFs.
