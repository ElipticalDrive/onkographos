# SDF Primitives & Operations

Also called: Implicit Shape Functions, Signed Distance Function (SDF) Primitives and Operators, Signed Distance Function Primitives

## Overview
SDF Primitives & Operations provide the analytical building blocks for distance-field ray marching by defining exact Euclidean distances from query points to geometric surfaces and combining them via Boolean and smoothing operators [S1, unofficial][S5, unofficial][S6, unofficial]. Unlike [SDF Domain Manipulation Operators](1730-sdf-domain-manipulation-operators.md) which transform the coordinate space to create patterns, primitives define the base geometry itself, while operations combine these distances arithmetically to form complex scenes [S1, unofficial][S3, unofficial]. This method guarantees no underestimation of distance, preventing ray overshooting during marching [S1, unofficial][S5, unofficial].

## How it works
**Inputs and Outputs:**
- **Input:** A 3D query point $\mathbf{p}$ (in local or world space) and primitive parameters (e.g., radius, position, normal).
- **Output:** A scalar signed distance $d(\mathbf{p})$ and optionally a material identifier.

**Data Structures:**
- **Primitive Parameters:** Vary by shape. Common fields include:
  - `position`: `Vec3` (center or reference point).
  - `radius`/`size`: `f32` (scalar dimension).
  - `normal`: `Vec3` (unit vector for planes/cones).
  - `height`: `f32` (for cylinders, cones, pyramids).
- **Material Enum:**
  ```python
  class Material(Enum):
      Lambertian = {"color": Vec3}
      Emissive = {"color": Vec3}
      Specular = {"color": Vec3, "specularity": f32, "fuzziness": f32}
  ```
- **DistInfo Struct:**
  ```python
  class DistInfo:
      distance: f32
      material: Material
  ```

**Core Formulas and Steps:**

1.  **Basic Primitives:** Compute the exact signed distance.
    -   **Sphere:** Center $\mathbf{c}$, radius $r$.
        $$d(\mathbf{p}) = \|\mathbf{p} - \mathbf{c}\| - r$$
        [S1, unofficial][S3, unofficial][S5, unofficial]
    -   **Box (AABB):** Half-extents $\mathbf{b} = (b_x, b_y, b_z)$.
        Let $\mathbf{q} = |\mathbf{p}| - \mathbf{b}$.
        $$d(\mathbf{p}) = \|\max(\mathbf{q}, 0)\| + \min(\max(q_x, \max(q_y, q_z)), 0)$$
        [S1, unofficial][S3, unofficial][S5, unofficial]
    -   **Plane:** Point $\mathbf{p}_0$, unit normal $\mathbf{n}$.
        $$d(\mathbf{p}) = \mathbf{n} \cdot (\mathbf{p} - \mathbf{p}_0)$$
        [S1, unofficial][S6, unofficial]
    -   **Torus:** Center $\mathbf{c}$, major radius $R$, minor radius $r$.
        $$d(\mathbf{p}) = \|\vec{2}(\|\mathbf{p}_{xy} - \mathbf{c}_{xy}\| - R, p_z - c_z)\| - r$$
        [S1, unofficial][S6, unofficial]
    -   **Cylinder:** Axis-aligned, center $\mathbf{c}$, height $h$, radius $r$.
        Project $\mathbf{p}$ to axis. Clamp height component. Compute distance to radius.
        [S6, unofficial]
    -   **Cone:** Tip $\mathbf{t}$, axis $\mathbf{a}$ (unit), height $h$, radius $r_{base}$.
        Compute distance to infinite cone, then clamp to height bounds.
        [S6, unofficial]
    -   **Pyramid:** Height $h$, base size. Complex analytical formula involving distance to triangular faces.
        [S5, unofficial]
    -   **Octahedron:** Size $s$.
        $$d(\mathbf{p}) = \frac{|p_x| + |p_y| + |p_z| - s}{\sqrt{3}}$$
        [S5, unofficial]

2.  **Boolean Operations:** Combine SDFs $f_A$ and $f_B$.
    -   **Union:**
        $$d_{union}(\mathbf{p}) = \min(f_A(\mathbf{p}), f_B(\mathbf{p}))$$
        [S1, unofficial][S7, unofficial][S8, unofficial]
    -   **Intersection:**
        $$d_{intersect}(\mathbf{p}) = \max(f_A(\mathbf{p}), f_B(\mathbf{p}))$$
        [S1, unofficial][S7, unofficial][S8, unofficial]
    -   **Difference (A minus B):**
        $$d_{diff}(\mathbf{p}) = \max(f_A(\mathbf{p}), -f_B(\mathbf{p}))$$
        [S1, unofficial][S7, unofficial][S8, unofficial]

3.  **Transformations:** Apply inverse transform to $\mathbf{p}$ before evaluation.
    -   **Translation:** $\mathbf{p}' = \mathbf{p} - \mathbf{offset}$.
        [S1, unofficial][S3, unofficial]
    -   **Rotation:** $\mathbf{p}' = R^{-1} \mathbf{p}$ (or $q \mathbf{p} q^{-1}$ for quaternion).
        [S1, unofficial][S2, unofficial]

4.  **Normal Computation:**
    Use central differences with epsilon $\epsilon$.
    $$\mathbf{n}(\mathbf{p}) = \text{normalize}\left( \begin{bmatrix} f(\mathbf{p}+\epsilon\mathbf{x}) - f(\mathbf{p}-\epsilon\mathbf{x}) \\ f(\mathbf{p}+\epsilon\mathbf{y}) - f(\mathbf{p}-\epsilon\mathbf{y}) \\ f(\mathbf{p}+\epsilon\mathbf{z}) - f(\mathbf{p}-\epsilon\mathbf{z}) \end{bmatrix} \right)$$
    [S3, unofficial]

**Pseudocode:**
```python
def sdf_sphere(p: Vec3, center: Vec3, radius: f32) -> f32:
    return length(p - center) - radius

def sdf_box(p: Vec3, center: Vec3, half_extents: Vec3) -> f32:
    # Shift point to local space
    p_local = p - center
    # Calculate distance to AABB
    q = abs(p_local) - half_extents
    # Distance is length of positive part + min of max component (negative if inside)
    dist = length(max(q, 0.0)) + min(max(q.x, max(q.y, q.z)), 0.0)
    return dist

def sdf_union(d1: f32, d2: f32) -> f32:
    return min(d1, d2)

def sdf_intersection(d1: f32, d2: f32) -> f32:
    return max(d1, d2)

def sdf_difference(d1: f32, d2: f32) -> f32:
    return max(d1, -d2)

def compute_normal(sdf_func, p: Vec3, eps: f32 = 0.001) -> Vec3:
    dx = sdf_func(p + Vec3(eps, 0, 0)) - sdf_func(p - Vec3(eps, 0, 0))
    dy = sdf_func(p + Vec3(0, eps, 0)) - sdf_func(p - Vec3(0, eps, 0))
    dz = sdf_func(p + Vec3(0, 0, eps)) - sdf_func(p - Vec3(0, 0, eps))
    return normalize(Vec3(dx, dy, dz))
```

**Parameters:**
- `MAX_DIST`: `f32 = 30.0` (Typical max ray length) [S1, unofficial].
- `MAX_STEPS`: `i32 = 1000` (Typical max marching steps) [S1, unofficial].
- `eps`: `f32 = 0.001` (Normal computation step size) [S3, unofficial].

**Edge Cases and Pitfalls:**
- **Division by Zero:** In Mandelbulb SDF, `atan(w.x/w.z)` fails if $w.z=0$, and `acos(w.y/r)` fails if $r=0$ [S1, unofficial].
- **Discontinuities:** Sharp Boolean operations (`min`/`max`) create discontinuous normals, which can cause artifacts in lighting or smooth blending [S8, unofficial].
- **Underestimation:** Primitives must return exact Euclidean distance. Any underestimation causes ray overshooting [S5, unofficial].

## Subtopics

### [SDF Domain Manipulation Operators](1730-sdf-domain-manipulation-operators.md)
Transforms input position $\mathbf{p}$ to create periodic/mirrored patterns without altering geometry. Choose for tiling or symmetry.

### [Quadric SDF (First-Order Approximation)](2682-quadric-sdf-first-order-approximation.md)
Approximates quadric surfaces using Taylor expansion. Choose for speed over precision on complex implicit surfaces.

### [Repeating SDF Geometry](4713-repeating-sdf-geometry.md)
Periodic tiling via coordinate folding. Choose for infinite repetition of base geometry at no extra cost.

### [Basic Primitive Definitions](5346-basic-primitive-definitions.md)
Foundational analytical SDFs (Sphere, Box, etc.). Choose as atomic building blocks for exact distance guarantees.

## Operating characteristics
- **Time Complexity:** $O(1)$ per primitive evaluation. Total time depends on ray marching steps, which scales with scene complexity and resolution.
- **Memory Complexity:** $O(1)$ storage (no mesh data). Scene graph size scales with number of primitives/operations.
- **Performance:** Extremely fast for simple primitives; slower for complex fractals (e.g., Mandelbulb) or deep recursion in CSG trees [S1, unofficial][S2, unofficial].
- **Strengths:** Resolution-independent, compact representation, easy Boolean operations, no z-fighting.
- **Limitations:** No exact normals (requires approximation), sharp edges from Boolean ops, potential for overshooting if distance is underestimated.

## Background
Originating from Hart's work on implicit surfaces [S7, unofficial], SDF primitives became popular in real-time graphics via Quilez's tutorials [S8, unofficial] and open-source implementations like [S1, unofficial]. They are widely used in ray marching, procedural generation, and voxel-based rendering [S5, unofficial][S6, unofficial].
