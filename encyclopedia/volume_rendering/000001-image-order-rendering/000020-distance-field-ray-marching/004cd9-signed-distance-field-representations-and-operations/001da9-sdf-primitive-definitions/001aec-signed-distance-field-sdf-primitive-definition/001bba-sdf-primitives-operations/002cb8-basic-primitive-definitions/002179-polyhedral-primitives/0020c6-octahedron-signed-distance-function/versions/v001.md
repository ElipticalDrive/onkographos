# Octahedron Signed Distance Function
Also called: Octahedron SDF, sdOctahedron
## Overview
Computes the exact signed distance from a point to a regular octahedron centered at the origin with size parameter $s$. It solves the primitive definition problem for ray marching by providing a closed-form analytic solution, avoiding iterative approximation. It is distinguished from its siblings, the [Hexagonal Prism](2348-hexagonal-prism.md) and [Triangular Prism](2865-triangular-prism.md), by its specific symmetry group and face geometry, offering a distinct aesthetic for procedural geometry.
## How it works
**Inputs:** Point $p = (p_x, p_y, p_z)$ in 3D space; size $s$ (distance from center to vertex along axes).
**Outputs:** Signed distance $d$. Negative if inside, positive if outside, zero on surface.

**Data Structures:**
- $p$: Input vector.
- $q$: Permuted and transformed vector used for face-specific calculation.
- $m$: Scalar intermediate value.
- $k$: Scalar clamp value.

**Steps:**
1.  Compute absolute coordinates: $p \leftarrow |p|$.
2.  Compute $m = p_x + p_y + p_z - s$.
3.  Determine the closest face region by comparing $3p_i$ against $m$:
    -   If $3p_x < m$, set $q = (p_x, p_y, p_z)$.
    -   Else if $3p_y < m$, set $q = (p_y, p_z, p_x)$.
    -   Else if $3p_z < m$, set $q = (p_z, p_x, p_y)$.
    -   Else (central region), return $m \cdot \tan(\pi/6)$.
4.  Calculate $k = \text{clamp}(0.5 \cdot (q_z - q_y + s), 0, s)$.
5.  Compute the distance vector $v = (q_x, q_y - s + k, q_z - k)$.
6.  Return $d = |v|$.

**Formulas:**
-   $m = \sum p_i - s$
-   $k = \max(0, \min(s, 0.5(q_z - q_y + s)))$
-   $d = \sqrt{q_x^2 + (q_y - s + k)^2 + (q_z - k)^2}$

**Parameters:**
-   $s$: Size of the octahedron. Typical values depend on scene scale.

**Edge Cases:**
-   **Precision:** Near the center, the distance is linear ($m \cdot \tan(\pi/6)$). Floating point errors in $m$ directly affect the sign.
-   **Boundaries:** The logic relies on the symmetry of the octahedron. Points exactly on the boundaries between regions (e.g., $3p_x = m$) are handled by the `else if` chain, which is mathematically continuous but may exhibit slight discontinuities in derivatives due to branch selection.

**Pseudocode:**
```python
import math

def sd_octahedron(p, s):
    """
    Computes the signed distance to an octahedron of size s.
    p: tuple or list of 3 floats (x, y, z)
    s: float, size parameter
    """
    # Step 1: Absolute coordinates
    px, py, pz = abs(p[0]), abs(p[1]), abs(p[2])
    
    # Step 2: Calculate m
    m = px + py + pz - s
    
    # Step 3: Determine region
    if 3.0 * px < m:
        qx, qy, qz = px, py, pz
    elif 3.0 * py < m:
        qx, qy, qz = py, pz, px
    elif 3.0 * pz < m:
        qx, qy, qz = pz, px, py
    else:
        # Central region
        return m * math.tan(math.pi / 6.0)
    
    # Step 4: Calculate k
    k = max(0.0, min(s, 0.5 * (qz - qy + s)))
    
    # Step 5 & 6: Distance
    dx = qx
    dy = qy - s + k
    dz = qz - k
    
    return math.sqrt(dx*dx + dy*dy + dz*dz)
```
## Subtopics

### Equilateral Triangle Signed Distance Function
Computes the signed distance to an equilateral triangle with inscribed radius $r$. It transforms the point into a canonical frame, reflects it if necessary to handle symmetry, and clamps to the triangle's edges. It is chosen when 2D triangular primitives are needed in SDF scenes. Based on Inigo Quilez's exact function [S2, unofficial].

## Operating characteristics
**Time Complexity:** $O(1)$. Constant number of arithmetic operations and comparisons.
**Memory Complexity:** $O(1)$. No auxiliary data structures.
**Strengths:** Exact analytic solution; no iteration required; fast evaluation suitable for real-time ray marching.
**Limitations:** Only applies to regular octahedra centered at the origin. Scaling requires adjusting $s$.
**When to use:** When rendering octahedral geometry in ray marching or SDF-based rendering.
**When not to use:** For irregular octahedra or when the octahedron is not axis-aligned (requires transformation of $p$ before calling).
## Background
The function is a standard primitive in the repertoire of signed distance functions for ray marching, popularized by Inigo Quilez's online articles and code snippets. It is widely used in procedural generation and real-time graphics for its efficiency and clean geometry.
