# Circle Signed Distance Function

Also called: 2D Circle SDF, 2D Sphere SDF, Circle SDF, sdCircle

## Overview
The Circle Signed Distance Function computes the signed distance from a 2D query point to the perimeter of a circle centered at the origin [S2, unofficial]. It returns a negative value inside the circle, a positive value outside, and zero on the boundary [S2, unofficial]. It serves as the 2D analog of the Sphere Signed Distance Function [Parent](1237-sphere-signed-distance-function.md).

## How it works
**Inputs:**
- $p$: A 2D query point, represented as a vector $(p_x, p_y)$ [S1, unofficial].
- $r$: The radius of the circle, a scalar [S1, unofficial].

**Outputs:**
- $d$: The signed distance from $p$ to the circle boundary [S2, unofficial].

**Data Structures:**
Not given in the sources.

**Formula:**
The signed distance is calculated as the Euclidean norm of the query point minus the radius:
$$ d = \|p\| - r $$
where $\|p\| = \sqrt{p_x^2 + p_y^2}$ [S1, unofficial].

**Pseudocode:**
```python
def sd_circle(p: tuple, r: float) -> float:
    """
    Computes the signed distance from point p to a circle of radius r centered at origin.
    
    Args:
        p: Tuple (x, y) representing the 2D query point.
        r: Float representing the radius of the circle.
        
    Returns:
        Float representing the signed distance. Negative if inside, positive if outside.
    """
    return (p[0] ** 2 + p[1] ** 2) ** 0.5 - r
```

**Edge Cases and Pitfalls:**
- **Sign Interpretation:** A negative result indicates the point is inside the circle, zero indicates it is on the boundary, and a positive result indicates it is outside [S2, unofficial].
- **Zero Radius:** If $r=0$, the function returns the distance to the origin [G]. This is mathematically valid but may cause degenerate behavior in ray marching if not handled.
- **Negative Radius:** The radius $r$ should be non-negative [G]. If a negative radius is passed, the sign of the distance will be inverted relative to the geometric expectation.
- **Off-Center Circles:** For circles not centered at the origin, the query point must be translated by the circle's center vector before evaluation [G].

## Operating characteristics
- **Time Complexity:** $O(1)$ [G].
- **Memory Complexity:** $O(1)$ [G].
- **Strengths:** Extremely fast evaluation; analytically exact distance [G].
- **Limitations:** Only applies to circles centered at the origin [G].
- **When to use:** Ideal for 2D ray marching and procedural texture generation [G].

## Background
The Circle SDF is the 2D analog of the Sphere Signed Distance Function [G]. Its implementation relies on the standard definition of Euclidean distance [G].
