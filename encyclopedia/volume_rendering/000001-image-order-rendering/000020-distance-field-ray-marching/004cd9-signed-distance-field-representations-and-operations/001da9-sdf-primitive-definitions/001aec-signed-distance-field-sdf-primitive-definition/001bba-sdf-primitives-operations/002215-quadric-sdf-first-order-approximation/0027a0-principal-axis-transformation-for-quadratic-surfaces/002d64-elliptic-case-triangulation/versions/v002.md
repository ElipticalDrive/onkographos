# Elliptic Case Triangulation


## Overview
Elliptic Case Triangulation generates a mesh approximation for the graph surface of a quadratic function $f$ of elliptic type, which is equivalent to a paraboloid $g(\bar{x}, \bar{y}) = \bar{x}^2 + \bar{y}^2$ [S1, unofficial]. It converts the continuous quadratic surface into a discrete triangular mesh by mapping an optimal equilateral prototype triangle from canonical space to the target surface space via a principal axis transformation [S1, unofficial]. It is distinguished from the Hyperbolic Case Triangulation by its paraboloid prototype and from general meshing methods by its analytical error bound preservation [S1, unofficial].

## How it works
**Inputs:**
*   Quadratic function $f$ (or its symmetric matrix $C$), error tolerance $\epsilon > 0$, cluster region boundary, and cluster centroid $c$ [S1, unofficial].

**Outputs:**
*   A set of triangles forming a triangulation of the surface within the cluster region [S1, unofficial].

**Data Structures:**
*   **Prototype Triangle:** Defined in canonical coordinates $(\bar{x}, \bar{y})$ [S1, unofficial].
*   **Transformation Matrix $G$:** $2 \times 2$ matrix mapping canonical to physical coordinates [S1, unofficial].
*   **Edge Vectors:** Two vectors defining the regular triangulation lattice [S1, unofficial].

**Steps:**

1.  **Eigen-decomposition:** Compute the eigenvalues $\lambda_1, \lambda_2$ and normalized eigenvectors $e_1 = (e_{11}, e_{12})^T, e_2 = (e_{21}, e_{22})^T$ of the quadratic matrix $C$. For the elliptic case, the eigenvalues are positive [S1, unofficial].
2.  **Handle Negative Eigenvalues:** If eigenvalues are negative, replace $f$ with $-f$ to imply positive eigenvalues [S1, unofficial].
3.  **Construct Transformation Matrix $G$:** The transformation maps the canonical paraboloid $g(\bar{x}, \bar{y}) = \bar{x}^2 + \bar{y}^2$ to the quadratic form $f$. The matrix $G$ is constructed from the eigenvectors scaled by the inverse square roots of the eigenvalues:
    $$
    G = \begin{pmatrix}
    \frac{1}{\sqrt{\lambda_1}} e_{11} & \frac{1}{\sqrt{\lambda_2}} e_{21} \\
    \frac{1}{\sqrt{\lambda_1}} e_{12} & \frac{1}{\sqrt{\lambda_2}} e_{22}
    \end{pmatrix}
    $$
    The source text contains a typo in equation (2.9) writing $\frac{1}{\sqrt{1}}$ and $\frac{1}{\sqrt{2}}$ instead of $\frac{1}{\sqrt{\lambda_1}}$ and $\frac{1}{\sqrt{\lambda_2}}$ [S1, unofficial].
4.  **Define Prototype Triangle:** In the canonical space $(\bar{x}, \bar{y})$, the optimal triangle is equilateral with a circumscribed circle radius $R = \sqrt{2\epsilon}$. The vertices are:
    $$
    v_1 = \begin{pmatrix} -\sqrt{2\epsilon} \\ 0 \end{pmatrix}, \quad
    v_2 = \begin{pmatrix} \sqrt{0.5\epsilon} \\ \sqrt{1.5\epsilon} \end{pmatrix}, \quad
    v_3 = \begin{pmatrix} \sqrt{0.5\epsilon} \\ -\sqrt{1.5\epsilon} \end{pmatrix}
    $$
    This triangle maximizes area for a given maximal error $\epsilon$, which occurs at the center and vertices [S1, unofficial].
5.  **Transform Edges:** Compute edge vectors $u = v_2 - v_1$ and $v = v_3 - v_1$. Transform only these two edges according to $G$: $U = G u$, $V = G v$ [S1, unofficial].
6.  **Generate Triangulation:** Establish a regular triangulation emanating from the cluster centroid $c$ using $U$ and $V$. For positive eigenvalues, place vertices below the surface by $\epsilon$ (if $f$ was flipped to $-f$, place vertices above by $\epsilon$) [S1, unofficial]. Only generate triangles that lie entirely within the cluster region, leaving untriangulated gaps at boundaries [S1, unofficial].

**Pseudocode:**

```python
import math

def elliptic_case_triangulation(C, centroid, is_inside, epsilon):
    """
    Generates triangulation for elliptic quadratic SDF.
    C: 2x2 symmetric matrix [[c11, c12], [c12, c22]]
    centroid: (cx, cy)
    is_inside: function(x, y) -> bool
    epsilon: float, error tolerance
    """
    # 1. Eigen-decomposition
    c11, c12, c22 = C[0][0], C[0][1], C[1][1]
    trace = c11 + c22
    det = c11 * c22 - c12**2
    discriminant = math.sqrt(max(0, trace**2 - 4 * det))
    
    lambda1 = (trace + discriminant) / 2
    lambda2 = (trace - discriminant) / 2
    
    if lambda1 <= 0 or lambda2 <= 0:
        raise ValueError("Not an elliptic case: eigenvalues must be positive.")

    # Compute normalized eigenvectors
    if abs(c12) > 1e-9:
        e1 = (1.0, -(c11 - lambda1) / c12)
    else:
        e1 = (0.0, 1.0)
    norm_e1 = math.sqrt(e1[0]**2 + e1[1]**2)
    e1 = (e1[0] / norm_e1, e1[1] / norm_e1)
    e2 = (-e1[1], e1[0])  # Orthogonal to e1

    # 2. Construct G matrix
    inv_sqrt_l1 = 1.0 / math.sqrt(lambda1)
    inv_sqrt_l2 = 1.0 / math.sqrt(lambda2)
    G = [
        [e1[0] * inv_sqrt_l1, e2[0] * inv_sqrt_l2],
        [e1[1] * inv_sqrt_l1, e2[1] * inv_sqrt_l2]
    ]

    # 3. Prototype triangle vertices in canonical space
    sqrt_eps = math.sqrt(epsilon)
    v1 = (-math.sqrt(2) * sqrt_eps, 0.0)
    v2 = (math.sqrt(0.5) * sqrt_eps, math.sqrt(1.5) * sqrt_eps)
    v3 = (math.sqrt(0.5) * sqrt_eps, -math.sqrt(1.5) * sqrt_eps)

    # 4. Transform edge vectors
    def mat_vec_mul(M, v):
        return (M[0][0]*v[0] + M[0][1]*v[1], M[1][0]*v[0] + M[1][1]*v[1])

    u = (v2[0] - v1[0], v2[1] - v1[1])
    v = (v3[0] - v1[0], v3[1] - v1[1])
    U = mat_vec_mul(G, u)
    V = mat_vec_mul(G, v)

    # 5. Generate triangulation
    triangles = []
    max_idx = 200  # Heuristic range; adjust based on cluster size

    for i in range(-max_idx, max_idx):
        for j in range(-max_idx, max_idx):
            p0_x = centroid[0] + i * U[0] + j * V[0]
            p0_y = centroid[1] + i * U[1] + j * V[1]

            p1_x = p0_x + U[0]
            p1_y = p0_y + U[1]
            p2_x = p0_x + V[0]
            p2_y = p0_y + V[1]

            # Boundary culling: only triangles entirely inside the cluster
            if is_inside(p0_x, p0_y) and is_inside(p1_x, p1_y) and is_inside(p2_x, p2_y):
                # Apply offset: place vertices below the surface by epsilon [G]
                # In practice, shift each vertex along the surface normal by epsilon
                triangles.append(((p0_x, p0_y), (p1_x, p1_y), (p2_x, p2_y)))

    return triangles
```

**Edge Cases and Pitfalls:**
*   **Precision:** The square roots of eigenvalues can be small, leading to large scaling factors in $G$. Use double precision [S1, unofficial].
*   **Boundary Gaps:** The method explicitly leaves gaps at cluster boundaries [S1, unofficial].
*   **Degenerate Input:** If eigenvalues are zero, the surface is not elliptic (parabolic or planar). The method fails [S1, unofficial].

## Operating characteristics
*   **Time Complexity:** $O(N)$ where $N$ is the number of triangles in the cluster. Generating the grid is linear in the area covered.
*   **Memory Complexity:** $O(N)$ to store the triangle list.
*   **Performance:** The method is analytically optimal for error bound $\epsilon$ within the elliptic region. It avoids iterative meshing algorithms.
*   **Strengths:** Exact error control, simple construction, regular structure.
*   **Limitations:** Only works for positive definite quadratic forms. Leaves boundary gaps. Requires eigen-decomposition.
*   **When to use:** When rendering quadratic SDF primitives (ellipsoids, ellipsoidal blobs) with strict error bounds.
*   **When not to use:** For hyperbolic surfaces (use Hyperbolic Case) or if a watertight mesh is required without post-processing (gaps are inherent).

## Background
The method originates from multiresolution modeling for scientific visualization, specifically in the context of approximating quadratic surfaces for volume rendering. It is detailed in the work by [S1, unofficial]. The approach leverages the rotational symmetry of the canonical paraboloid to define an optimal equilateral triangle, then maps this triangle to the general elliptic case via principal axis transformation.
