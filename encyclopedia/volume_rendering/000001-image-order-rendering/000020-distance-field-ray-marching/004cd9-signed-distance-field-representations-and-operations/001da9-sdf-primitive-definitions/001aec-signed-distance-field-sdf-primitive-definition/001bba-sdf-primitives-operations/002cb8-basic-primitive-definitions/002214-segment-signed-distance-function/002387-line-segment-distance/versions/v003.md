# Line Segment Distance

Also called: Point-to-Line Distance Calculation, Segment SDF, sdSegment

## Overview
Computes the Euclidean distance from a point `p` to a line segment defined by endpoints `l0` and `l1` [S1, unofficial]. It distinguishes itself from infinite line distance methods by clamping the projection parameter to the segment bounds, correctly handling proximity to endpoints [S1, unofficial].

## How it works
**Inputs:** Point `p`, segment endpoints `l0`, `l1` (all 3D vectors) [S1, unofficial].
**Output:** Scalar Euclidean distance [S1, unofficial].

1. Compute vector `v = l1 - l0` and `w = p - l0` [S1, unofficial].
2. Compute dot products `c1 = dot(v, w)` and `c2 = dot(v, v)` [S1, unofficial].
3. If `c1 <= 0.0`, the closest point is `l0`; return `length(p - l0)` [S1, unofficial].
4. If `c2 <= c1`, the closest point is `l1`; return `length(p - l1)` [S1, unofficial].
5. Compute projection parameter `b = c1 / c2` [S1, unofficial].
6. Compute projection point `pb = l0 + b * v` [S1, unofficial].
7. Return `length(p - pb)` [S1, unofficial].

```python
def line_segment_distance(p, l0, l1):
    v = l1 - l0
    w = p - l0
    c1 = dot(v, w)
    if c1 <= 0.0:
        return length(p - l0)
    c2 = dot(v, v)
    if c2 <= c1:
        return length(p - l1)
    b = c1 / c2
    pb = l0 + b * v
    return length(p - pb)
```

**Edge cases:** If `l0 == l1`, `c2` is zero, causing division by zero in step 5. Guard against `c2 < \epsilon` by returning `length(p - l0)` [G].

## Subtopics

### Point-to-Line Distance
Computes the vector from a point `p` to the closest point on an infinite line defined by origin `o` and direction `d` [S2, unofficial]. It does not clamp the projection, allowing the closest point to be anywhere on the line [S2, unofficial]. Use when the segment bounds are irrelevant or the line is truly infinite [S2, unofficial].

```python
def point_to_line_distance(p, o, d):
    op = p - o
    scale_factor = dot(op, d) / dot(d, d)
    q = o + scale_factor * d
    return p - q
```
