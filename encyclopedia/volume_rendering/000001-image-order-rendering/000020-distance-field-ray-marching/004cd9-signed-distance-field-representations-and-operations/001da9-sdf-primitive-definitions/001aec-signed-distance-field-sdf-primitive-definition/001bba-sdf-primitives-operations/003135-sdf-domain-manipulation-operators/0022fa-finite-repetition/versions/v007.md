# Finite Repetition
Also called: Bounded Tiling, Finite Domain Repetition, Limited Repetition

## Overview
Finite Repetition creates a bounded grid of repeated instances of a base Signed Distance Function (SDF) within a specified limit. Unlike infinite tiling operators, it restricts the replication count to a finite number of cells in each dimension, preventing geometry from extending to infinity. It is chosen when a discrete, limited array of objects is required without the computational cost or visual artifacts of infinite repetition.

## How it works
**Inputs and Outputs:**
- Input: Query point $\mathbf{p} \in \mathbb{R}^3$, period vector $\mathbf{c} \in \mathbb{R}^3$ (cell size), limit vector $\mathbf{l} \in \mathbb{R}^3$ (maximum cell index magnitude).
- Output: Transformed point $\mathbf{p}'$ mapped to the canonical cell, and implicitly the cell index $\mathbf{q}$ for potential use as a random seed.

**Data Structures:**
- Vectors $\mathbf{p}, \mathbf{c}, \mathbf{l}$ are typically 3-component floating-point vectors.

**Steps:**
1.  **Normalization**: Divide the query point by the period: $\mathbf{u} = \mathbf{p} / \mathbf{c}$.
2.  **Quantization**: Round each component of $\mathbf{u}$ to the nearest integer to find the cell index: $\mathbf{q}_{raw} = \text{round}(\mathbf{u})$.
3.  **Clamping**: Clamp the cell index to the finite limit: $\mathbf{q} = \text{clamp}(\mathbf{q}_{raw}, -\mathbf{l}, \mathbf{l})$.
4.  **Mapping**: Subtract the periodic offset to map $\mathbf{p}$ back to the canonical region of the selected cell: $\mathbf{p}' = \mathbf{p} - \mathbf{c} \cdot \mathbf{q}$.
5.  **Evaluation**: The base SDF is evaluated at $\mathbf{p}'$.

**Formula:**
$$ \mathbf{q} = \text{clamp}(\text{round}(\mathbf{p} / \mathbf{c}), -\mathbf{l}, \mathbf{l}) $$
$$ \mathbf{p}' = \mathbf{p} - \mathbf{c} \cdot \mathbf{q} $$

**Parameters:**
- $\mathbf{c}$: Period size. Must be non-zero.
- $\mathbf{l}$: Limit. Defines the extent of the grid.

**Edge Cases:**
- If $\mathbf{c}$ has zero components, division is undefined.
- Points outside the limit $\mathbf{l}$ are clamped to the boundary cells, creating a "hard edge" where the SDF value jumps discontinuously if the base SDF does not decay to infinity.

**Pseudocode:**
```python
def repeat_finite(p, c, l):
    # Step 1 & 2: Divide and round to find raw cell index
    q_raw = p / c
    q_raw = round(q_raw)
    
    # Step 3: Clamp to finite limit
    q = clamp(q_raw, -l, l)
    
    # Step 4: Map to canonical cell
    p_prime = p - c * q
    
    return p_prime, q
```

## Operating characteristics
- **Time Complexity**: $O(1)$ per query.
- **Memory Complexity**: $O(1)$.
- **Strengths**: Efficiently generates bounded arrays of objects; avoids infinite recursion or memory issues associated with infinite tiling.
- **Limitations**: Discontinuous boundaries at the limit $\mathbf{l}$ unless the base SDF is explicitly shaped to fade out.
- **When to use**: When a specific, limited number of repeated objects is needed.

## Background
Finite Repetition is a standard technique in procedural geometry and SDF rendering, popularized by Inigo Quilez's online articles on SDF primitives [S1, S2, unofficial]. It serves as the bounded counterpart to infinite tiling operators.
