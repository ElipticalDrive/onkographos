# Finite Repetition

Also called: Bounded Tiling, Finite Domain Repetition, Limited Repetition

## Overview
Finite Repetition creates a bounded grid of repeated instances of a base Signed Distance Function (SDF) primitive, limiting the replication count to a specified range in each dimension [S1, unofficial][S2, unofficial]. Unlike infinite tiling operators, it restricts the domain to a finite box [S2, unofficial].

## How it works
**Inputs:**
- `p`: Input position vector ($\mathbb{R}^3$) [S1, unofficial][S2, unofficial].
- `c`: Period vector defining the cell size in each dimension ($\mathbb{R}^3$) [S1, unofficial][S2, unofficial].
- `l`: Limit vector defining the maximum number of cells to replicate in each dimension ($\mathbb{R}^3$) [S1, unofficial][S2, unofficial].

**Outputs:**
- `p'`: Transformed position vector mapped to the nearest valid cell within the bounds [S1, unofficial][S2, unofficial].

**Data Structures:**
- Vectors `p`, `c`, `l` are 3-component floating-point vectors [G].

**Steps:**
1. Normalize the position by the period: $u = p / c$ [S1, unofficial][S2, unofficial].
2. Round each component of $u$ to the nearest integer to find the cell index: $q_{\text{raw}} = \text{round}(u)$ [S1, unofficial][S2, unofficial].
3. Clamp the cell indices to the limits: $q = \text{clamp}(q_{\text{raw}}, -l, l)$ [S2, unofficial].
4. Map the position back to the local cell: $p' = p - c \cdot q$ [S2, unofficial].

**Formula:**
$$ q = \text{clamp}\left(\text{round}\left(\frac{p}{c}\right), -l, l\right) $$
$$ p' = p - c \cdot q $$
[S2, unofficial]

**Parameters:**
- `c`: Must be non-zero [G]. Typical values depend on the desired tile size [G].
- `l`: Non-negative values representing the radius of the grid in cells [S1, unofficial][S2, unofficial].

**Edge Cases:**
- If `c` contains zero, division is undefined [G]. Guard against zero components in `c` before division.
- If `l` is zero, the result is the identity transformation (no repetition) [G].

**Pseudocode:**
```python
def repeat_finite(p: Vec3, c: Vec3, l: Vec3) -> Vec3:
    # Step 1 & 2: Divide by period and round to nearest integer
    q_raw = (p / c).round()
    
    # Step 3: Clamp cell indices to limits [-l, l]
    q = q_raw.clamp(-l, l)
    
    # Step 4: Map position back to local cell
    p_prime = p - c * q
    
    return p_prime
```
