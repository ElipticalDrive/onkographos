# ComputeLocalState

Also called: Hierarchical SDF Tree State Computation

## Overview
ComputeLocalState is a procedure that determines the local state (ACTIVE, INACTIVE, or SKIPPED) of nodes in a hierarchical Signed Distance Field (SDF) tree relative to a specific spatial cell [S1]. It utilizes Lipschitz pruning to identify and ignore primitives that are provably too far from the cell's surface to affect the local distance field, thereby optimizing subsequent ray marching or evaluation steps [S1]. It differs from standard tree traversal by combining post-order evaluation with immediate state-based culling, building on the hierarchical CSG pruning framework described in [GPU Implementation of Hierarchical CSG Pruning](8626-gpu-implementation-of-hierarchical-csg-pruning.md) [G].

## How it works
**Inputs:**
- `nodes`: An array representing the hierarchical SDF tree structure [S1].
- `p`: The center point of the current spatial cell [S1].
- `R`: The radius of the current spatial cell [S1].

**Outputs:**
- The `state` field of each node in `nodes` is updated to one of: `ACTIVE`, `INACTIVE`, or `SKIPPED` [S1].

**Data Structures:**
- **Node**: Contains fields for `state` (enum), `blendData` (tuple: operator type `OP`, blending radius `k`, sign `s`, complementary flags `ca`, `cb`), `cFlag` (sign multiplier), and `primData` (for leaf primitives) [S1].
- **Stack**: Stores tuples of `(distance, node_index)` [S1].

**Algorithm:**
The procedure iterates through the tree nodes in post-order traversal [S1]. For each node, it evaluates the local state based on the distances of its children (or the primitive itself if a leaf) and the pruning bound derived from the cell radius $R$ and blending radius $k$ [S1].

1. Initialize an empty stack [S1].
2. For each node index `i` in `PostOrderTraversal(nodes)`:
    a. Retrieve node `n = nodes[i]` [S1].
    b. If `n` is a leaf:
        i. Set `n.state = ACTIVE` [S1].
        ii. Evaluate the primitive SDF at `p` using `n.primData` to get distance `d` [S1].
    c. If `n` is not a leaf:
        i. Pop `(b', right)` from the stack (right child) [S1].
        ii. Pop `(a', left)` from the stack (left child) [S1].
        iii. Extract `OP, k, s, ca, cb` from `n.blendData` [S1].
        iv. Check pruning condition: if $|a' - b'| > k + 2R$:
            1. If $s \cdot a' \le s \cdot b'$, set `nodes[right].state = INACTIVE` [S1].
            2. Else, set `nodes[left].state = INACTIVE` [S1].
            3. Set `n.state = SKIPPED` [S1].
        v. Else:
            1. Set `n.state = ACTIVE` [S1].
        vi. Compute distance `d` by applying operator `OP` to transformed child distances: `d = OP(ca * a', cb * b', k)` [S1].
    d. Push `(n.cFlag * d, i)` onto the stack [S1].

**Pseudocode:**

```python
# Constants
ACTIVE = "ACTIVE"
INACTIVE = "INACTIVE"
SKIPPED = "SKIPPED"

def IsLeaf(node):
    return node.type == "LEAF"

def EvalPrimitive(p, prim_data):
    return prim_data.sdf(p)  # [G]

def PostOrderTraversal(nodes):
    # Yields indices in post-order (left child, right child, parent)
    # Assumes nodes have left_child and right_child indices
    def traverse(idx):
        if idx is not None:
            left = nodes[idx].left_child
            right = nodes[idx].right_child
            if left is not None: yield from traverse(left)
            if right is not None: yield from traverse(right)
            yield idx
    yield from traverse(0)

def ComputeLocalState(nodes, p, R):
    stack = []
    for i in PostOrderTraversal(nodes):
        n = nodes[i]
        if IsLeaf(n):
            n.state = ACTIVE
            d = EvalPrimitive(p, n.primData)
        else:
            b_prime, right_idx = stack.pop()
            a_prime, left_idx = stack.pop()
            OP, k, s, ca, cb = n.blendData
            if abs(a_prime - b_prime) > k + 2 * R:
                if s * a_prime <= s * b_prime:
                    nodes[right_idx].state = INACTIVE
                else:
                    nodes[left_idx].state = INACTIVE
                n.state = SKIPPED
            else:
                n.state = ACTIVE
            d = OP(ca * a_prime, cb * b_prime, k)
        stack.append((n.cFlag * d, i))
```

**Parameters:**
- `R`: Cell radius. Typical values depend on the spatial partitioning resolution [G].
- `k`: Blending radius from the CSG operator [S1].

**Edge Cases and Pitfalls:**
- **Precision**: The pruning condition relies on the difference between child distances. Floating-point inaccuracies may lead to incorrect pruning if $|a' - b'|$ is very close to $k + 2R$ [G].
- **Boundary Conditions**: The method assumes the cell radius $R$ accurately bounds the region of interest. If $R$ is underestimated, valid primitives may be pruned [G].
- **Empty Stack**: The algorithm assumes a valid tree structure where every internal node has two children [G].

## Subtopics

### Far-field Culling
An optimization that replaces distant trees with a single constant node providing a lower-bound distance field. This is not differentiable but preserves the 0-isosurface [S1].

## Operating characteristics
- **Time Complexity**: Linear with respect to the number of nodes in the tree, $O(N)$, as each node is visited exactly once in post-order [G].
- **Memory Complexity**: $O(H)$ for the stack, where $H$ is the height of the tree [G].
- **Performance**: The procedure is fast enough to be useful in dynamic contexts where the scene is modified (e.g., parameter changes, adding/deleting sub-trees) [S1].
- **Strengths**: Efficiently prunes irrelevant parts of the SDF tree based on spatial locality and Lipschitz properties [S1].
- **Limitations**: The pruning is conservative; it may not prune all irrelevant nodes if the Lipschitz bound is loose. The far-field approximation is not continuous or differentiable [S1].

## Background
The method is described in "Lipschitz Pruning: Hierarchical Simplification of Primitive‐Based SDFs" [S1]. It is part of a broader effort to optimize SDF evaluation and rendering by leveraging hierarchical structures and spatial culling. The approach builds on narrow-band optimization techniques used in discrete SDF rendering [S1].
