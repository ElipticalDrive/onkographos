# SDF Rounding

Also called: Distance Offset, Rounded, Rounded Corners in SDFs, Rounding, Rounding Transformation, SDF Domain Manipulation, SDF Offset, SDF Rounding/Offset

## Overview
SDF Rounding is a geometric transformation that modifies a Signed Distance Field (SDF) primitive by subtracting a constant radius value from its distance output, effectively rounding off hard edges and corners [S1, S4, unofficial]. It is a specific instance of [SDF Domain Manipulation Operators](1730-sdf-domain-manipulation-operators.md) that operates on the distance value rather than the input position vector [S2, unofficial].

## How it works
**Inputs and Outputs:**
- Input: A base SDF function $d_{base}(\mathbf{p})$ returning the signed distance from point $\mathbf{p}$ to the surface, and a scalar rounding radius $r \ge 0$ [S1, S2, unofficial].
- Output: A new SDF function $d_{rounded}(\mathbf{p})$ representing the shape with rounded features.

**Data Structures:**
The implementation typically encapsulates the base SDF and the radius parameter [S1, S3, unofficial]. For example, a `Rounded` struct contains:
- `sdf`: The base SDF primitive instance.
- `offset` (f32): The constant value added to the distance [S3, unofficial].

**Steps:**
1. Evaluate the base SDF at the query point $\mathbf{p}$ to obtain the raw signed distance $d = d_{base}(\mathbf{p})$ [S1, S3, unofficial].
2. Subtract the rounding radius $r$ from the raw distance: $d_{rounded} = d - r$ [S1, S2, S4, unofficial].
3. Return $d_{rounded}$ [S2, unofficial].

**Formula:**
$$ d_{rounded}(\mathbf{p}) = d_{base}(\mathbf{p}) - r $$

**Parameters:**
- $r$ (float): The rounding radius. Typical values depend on the scale of the primitive (e.g., 0.1 for a unit cube) [S1, S2, unofficial].

**Edge Cases and Pitfalls:**
- If $r$ exceeds the primitive's minimum feature size, the zero-level set may disappear or invert [G].
- Precision issues may arise if $d_{base}(\mathbf{p}) \approx r$, leading to numerical instability near the new surface boundary [G].

**Pseudocode:**
```python
def sdf_rounding(sdf_func, radius):
    def rounded_sdf(p):
        base_distance = sdf_func(p)
        return base_distance - radius
    return rounded_sdf
```

## Subtopics

### [SDF Onion](1846-sdf-onion.md)
The SDF Onion operation creates a hollow shell or layered structure from a solid SDF primitive by taking the absolute value of the distance and subtracting a specified radius. It is a specific application of SDF Rounding that inverts the interior of the shape to create a void. Unlike standard rounding which smooths exterior edges, Onion creates internal layers by exploiting the symmetry of the absolute distance function.

### SDF Displacement Maps
A variant where the constant offset $r$ is replaced by a spatially varying function, such as a sine wave [S4, unofficial]. The formula becomes $d_{disp}(\mathbf{p}) = d_{base}(\mathbf{p}) + \text{offset}(\mathbf{p})$ [S4, unofficial]. This allows for dynamic surface details like ripples or noise, as seen in the example: $\text{offset} = \sin(k \cdot x) \sin(k \cdot y) \sin(k \cdot z) (0.25 + 0.25 \sin(\text{time}))$ [S4, unofficial].

## Operating characteristics
- **Time Complexity:** $O(1)$ per evaluation, requiring only one arithmetic subtraction [G].
- **Memory Complexity:** $O(1)$, requiring storage for the radius/offset parameter [G].
- **Strengths:** Simple to implement; computationally cheap; effective for creating smooth, organic, or filleted shapes from basic primitives [S4, unofficial].
- **Limitations:** The distance metric is shifted globally rather than producing exact geometric fillets; large radii can distort the shape significantly [S4, unofficial].
- **When to use:** When visual smoothness is preferred over mathematical precision of the distance field, or for quick prototyping of rounded shapes [G].
- **When not to use:** When exact distance metrics are required for accurate ray marching convergence or collision detection in the rounded regions [G].

## Background
SDF Rounding leverages the property that subtracting a constant from a distance function shifts the zero-level set (the surface) inward, smoothing sharp features [S4, unofficial]. It is commonly used in ray marching and implicit surface rendering to generate complex-looking geometry from simple primitives [S1, S2, unofficial].
