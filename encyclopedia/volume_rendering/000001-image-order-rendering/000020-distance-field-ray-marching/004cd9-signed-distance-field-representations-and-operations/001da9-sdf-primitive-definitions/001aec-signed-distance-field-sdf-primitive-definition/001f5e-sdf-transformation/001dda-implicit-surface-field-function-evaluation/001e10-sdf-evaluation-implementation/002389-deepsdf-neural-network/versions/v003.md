# DeepSDF Neural Network
Also called: DeepSDF, DeepSDF Network Architecture

## Overview
DeepSDF is a neural network architecture that maps 3D coordinates to signed distance field (SDF) values using a shape-specific latent code [S1, unofficial][S2, unofficial]. It solves the problem of implicit surface representation by learning a continuous function that generalizes across shapes within a category, enabling compact storage and high-quality reconstruction [S1, unofficial][S2, unofficial]. Unlike [Vox2SDF](4047-vox2sdf.md), which derives its latent code from a discrete voxel grid via a 3D CNN, DeepSDF relies on a global latent code independent of the input geometry structure, allowing it to capture fine geometric details without voxelization artifacts [S1, unofficial].

## How it works
**Inputs and Outputs:**
- Input: A latent code vector $z \in \mathbb{R}^{d_z}$ representing a specific shape instance, and a 3D coordinate $p \in \mathbb{R}^3$.
- Output: A scalar signed distance value $s \in \mathbb{R}$ representing the distance from $p$ to the implicit surface, with sign indicating inside/outside.

**Data Structures:**
- **Latent Code ($z$):** A vector of dimension $d_z$. Sources vary on default dimension: 16 [S1, unofficial] or 512 [S2, unofficial].
- **Coordinates ($p$):** A 3D point.
- **Network Weights:** Parameters of the Multi-Layer Perceptron (MLP).

**Network Architecture:**
The network is an MLP that concatenates the latent code and coordinates. Two distinct architectural variants are cited:

1.  **Variant A (Simple):**
    - Input dimension: $d_z + 3$.
    - Layer 1: Linear($d_z + 3$, 256), ReLU.
    - Layer 2: Linear(256, 1), Tanh [S1, unofficial].

2.  **Variant B (Deep with Skip Connections):**
    - Input dimension: $d_z + 3$.
    - Hidden dimension $d_h$: Default 1024 [S2, unofficial].
    - Number of hidden layers $L$: Default 8 [S2, unofficial].
    - Skip connections: Applied at layer indices $S = [3, 7]$ (0-indexed relative to hidden layers, or specific layer indices in the sequence) [S2, unofficial].
    - Activation: ReLU for hidden layers, Tanh for output [S2, unofficial].
    - Dropout: 0.2 applied after each hidden layer except the last [S2, unofficial].

**Numbered Steps:**
1.  **Input Preparation:** Reshape the batch of coordinates to shape $(-1, 3)$ and the latent codes to $(-1, d_z)$. Concatenate them along the feature dimension to form the input tensor $x_{in} = [z; p]$ with shape $(-1, d_z + 3)$ [S2, unofficial].
2.  **Forward Pass (Variant B):**
    - Let $h_0 = x_{in}$.
    - For layer $i$ from 0 to $L-1$:
        - If $i \in S$ (skip layers): Concatenate the current hidden state $h_i$ with the original input $x_{in}$ to form $x_{skip} = [h_i; x_{in}]$. The input to the linear layer is $x_{skip}$.
        - Else: The input to the linear layer is $h_i$.
        - Apply Linear transformation: $h_{temp} = W_i \cdot x_{current} + b_i$.
        - Apply Dropout with rate 0.2 (if not the last hidden layer) [S2, unofficial].
        - Apply ReLU activation: $h_{i+1} = \text{ReLU}(h_{temp})$.
    - Final Layer: Apply Linear($d_h$, 1) followed by Tanh activation to produce the output $s$ [S2, unofficial].
3.  **Output Reshaping:** Reshape the output tensor to $(-1, 1)$ [S2, unofficial].

**Formulas:**
- Input concatenation: $x_{in} = \text{concat}(z, p)$
- Hidden layer computation (with skip connection at index $k$):
  $$h_{i+1} = \text{ReLU}(\text{Dropout}(W_i \cdot \text{concat}(h_i, x_{in}) + b_i)) \quad \text{if } i \in S$$
  $$h_{i+1} = \text{ReLU}(\text{Dropout}(W_i \cdot h_i + b_i)) \quad \text{if } i \notin S$$
- Output: $s = \tanh(W_{out} \cdot h_L + b_{out})$

**Parameters:**
- $d_z$: Latent dimension. Default 16 [S1, unofficial] or 512 [S2, unofficial].
- $d_h$: Hidden dimension. Default 1024 [S2, unofficial].
- $L$: Number of hidden layers. Default 8 [S2, unofficial].
- $S$: Skip layer indices. Default [3, 7] [S2, unofficial].
- $\alpha$: Dropout rate. Default 0.2 [S2, unofficial].
- $\eta$: Learning rate. Default 0.001 [S1, unofficial].
- $B$: Batch size. Default 128 [S1, unofficial].
- $E$: Number of epochs. Default 10 [S1, unofficial].

**Edge Cases and Pitfalls:**
- **Precision:** The Tanh output activation bounds the SDF value to $[-1, 1]$. This may limit the representation of large distances or require scaling of input coordinates [S2, unofficial].
- **Boundary Conditions:** Training samples are often generated uniformly in a bounding box (e.g., $[-1.5, 1.5]^3$) [S1, unofficial]. Points far from the surface may have less accurate gradients.
- **Latent Code Expansion:** The latent code must be expanded to match the batch size for each forward pass if the same shape is processed for multiple points [S1, unofficial].

**Pseudocode:**
```python
import torch
import torch.nn as nn

class DeepSDFNetwork(nn.Module):
    def __init__(self, latent_dim=512, hidden_dim=1024, num_hidden_layers=8, skip_layers=[3, 7]):
        super(DeepSDFNetwork, self).__init__()
        self.latent_dim = latent_dim
        self.hidden_dim = hidden_dim
        self.num_hidden_layers = num_hidden_layers
        self.skip_layers = set(skip_layers)
        
        # Layer 0: Input is concat(latent, coords) -> hidden_dim
        self.layers = nn.ModuleList()
        self.layers.append(nn.Linear(latent_dim + 3, hidden_dim))
        
        # Hidden layers
        for i in range(num_hidden_layers):
            if i in self.skip_layers:
                # Skip connection: concat previous hidden with original input
                self.layers.append(nn.Linear(hidden_dim + latent_dim + 3, hidden_dim))
            else:
                self.layers.append(nn.Linear(hidden_dim, hidden_dim))
        
        # Output layer
        self.output_layer = nn.Linear(hidden_dim, 1)
        
        # Dropout applied after each hidden layer except the last
        self.dropout = nn.Dropout(p=0.2)

    def forward(self, latent_code, points):
        """
        latent_code: (B, latent_dim)
        points: (B, 3)
        """
        # Concatenate latent code and points
        x_in = torch.cat([latent_code, points], dim=-1)  # (B, latent_dim + 3)
        
        h = x_in
        for i, layer in enumerate(self.layers):
            if i in self.skip_layers:
                # Concatenate current hidden state with original input
                h = torch.cat([h, x_in], dim=-1)
            
            h = layer(h)
            
            # Apply dropout and ReLU for hidden layers
            # The last layer in self.layers is the output layer, handled separately
            if i < len(self.layers) - 1:
                h = self.dropout(h)
                h = torch.relu(h)
        
        # Output layer: Linear -> Tanh
        output = self.output_layer(h)
        output = torch.tanh(output)
        
        return output
```

## Subtopics

### [Vox2SDF](4047-vox2sdf.md)
Vox2SDF is a neural network pipeline that converts a discrete 3D voxel grid into a continuous Signed Distance Field (SDF) representation. It solves the problem of implicit surface reconstruction from discrete inputs by encoding the voxel structure into a latent vector and decoding it via a position-conditional MLP to predict SDF values at arbitrary 3D points. Unlike [DeepSDF Neural Network](3051-deepsdf-neural-network.md), which relies on a global latent code independent of input geometry, Vox2SDF derives its latent code directly from the input voxel grid using a 3D CNN encoder, allowing it to generalize across different shapes within a category while preserving input-specific geometric details.

## Operating characteristics
- **Time Complexity:** Inference is $O(L \cdot d_h)$ per point, where $L$ is the number of hidden layers and $d_h$ is the hidden dimension. Training time depends on the number of epochs and batch size.
- **Memory Complexity:** $O(d_z + L \cdot d_h^2)$ for storing weights and latent codes.
- **Performance:** Performance varies significantly based on the latent dimension and network depth. Variant B with $d_z=512$ and $d_h=1024$ is more expressive but computationally heavier than Variant A [S1, unofficial][S2, unofficial].
- **Strengths:** Compact representation via latent code; continuous surface representation; ability to generalize across shapes.
- **Limitations:** Requires training for each shape category; inference speed may be slower than analytic primitives; output bounded by Tanh activation [S2, unofficial].
- **When to use:** When a compact, continuous representation of a shape category is needed, and training data is available.
- **When not to use:** For real-time applications with strict latency constraints where analytic primitives suffice, or when no training data is available.

## Background
DeepSDF was introduced as a method for learning continuous signed distance functions for shape representation [S1, unofficial][S2, unofficial]. It builds on the idea of using neural networks to represent implicit surfaces, allowing for high-quality reconstruction and generalization. The architecture has been implemented in various forms, with variations in network depth, skip connections, and latent dimensionality [S1, unofficial][S2, unofficial].
