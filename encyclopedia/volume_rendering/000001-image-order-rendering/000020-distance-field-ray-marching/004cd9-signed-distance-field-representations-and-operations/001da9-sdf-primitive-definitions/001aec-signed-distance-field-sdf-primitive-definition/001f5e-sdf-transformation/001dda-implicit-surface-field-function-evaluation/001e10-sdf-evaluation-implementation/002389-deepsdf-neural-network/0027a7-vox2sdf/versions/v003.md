# Vox2SDF

Also called: Neural SDF from Voxels, Voxel-to-SDF

## Overview
Vox2SDF is a neural network pipeline that converts a discrete 3D voxel grid into a continuous Signed Distance Field (SDF) representation [S1, unofficial]. It solves the problem of implicit surface reconstruction from discrete inputs by encoding the voxel structure into a global latent vector, which is then decoded by a position-conditional Multi-Layer Perceptron (MLP) to predict SDF values at arbitrary 3D coordinates [S1, unofficial]. Unlike [DeepSDF](3051-deepsdf-neural-network.md), which relies on a learned prior over shape variations via a latent code conditioned on object category, Vox2SDF directly encodes the specific geometry of the input voxel grid into the latent vector, allowing for exact reconstruction of the input shape rather than a probabilistic average [S1, unofficial].

## How it works
**Inputs and Outputs:**
*   **Input:** A 3D voxel grid tensor of shape $(1, H, W, D)$, typically binary or occupancy-based. Default spatial resolution is $128 \times 128 \times 128$ [S1, unofficial].
*   **Output:** A scalar SDF value for a given 3D query point $\mathbf{x} = (x, y, z)$ [S1, unofficial].

**Data Structures:**
1.  **Voxel Grid:** 3D tensor. The implementation hardcodes the input channel dimension to 1 [S1, unofficial].
2.  **Latent Vector:** 1D tensor of size `latent_size` (default 256) [S1, unofficial].
3.  **Query Points:** 2D tensor of shape $(N, 3)$ containing $N$ query coordinates [S1, unofficial].

**Algorithm Steps:**
1.  **Encoding:** Pass the voxel grid through a 3D Convolutional Neural Network (CNN) encoder.
    *   The encoder consists of 3 blocks. Each block contains: `Conv3d(1->16, k=3, s=2, p=1)` -> `BatchNorm` -> `ReLU` -> `MaxPool3d(2)` -> `Dropout(0.3)`.
    *   Channel progression: $16 \rightarrow 32 \rightarrow 64$ [S1, unofficial].
    *   Flatten the resulting feature map. The code hardcodes the flattened size as $64 \times 1 \times 1 \times 1 = 64$ [S1, unofficial].
    *   Pass through Fully Connected (FC) layers: `Linear(64, 512)` -> `BatchNorm` -> `ReLU` -> `Dropout(0.3)` -> `Linear(512, latent_size)` [S1, unofficial].
    *   Output the latent vector $\mathbf{z}$ [S1, unofficial].
2.  **Latent Replication:** For a batch of $N$ query points, replicate the latent vector $\mathbf{z}$ $N$ times to match the batch size of query points [S1, unofficial].
3.  **Concatenation:** Concatenate the replicated latent vector $\mathbf{z}$ with the query coordinates $\mathbf{x}$ along the feature dimension to form input $\mathbf{c} = [\mathbf{z}; \mathbf{x}]$ [S1, unofficial].
4.  **Decoding:** Pass $\mathbf{c}$ through the SDF Decoder MLP.
    *   Layer 0: `Linear(latent_dim + 3, hidden_dim)`
    *   Hidden Layers $i=1 \dots L-2$:
        *   If $i \pmod 4 == 0$: `Linear(hidden_dim + latent_dim + 3, hidden_dim)` (Skip connection: concatenate $\mathbf{z}$ and $\mathbf{x}$ to the hidden representation).
        *   Else: `Linear(hidden_dim, hidden_dim)`
    *   Final Layer: `Linear(hidden_dim, 1)` [S1, unofficial].
    *   Activations: `ReLU` for hidden layers, `Tanh` for the final output [S1, unofficial].
5.  **Output:** The result is the predicted SDF value $SDF(\mathbf{x})$ [S1, unofficial].

**Formulas:**
The SDF prediction for a query point $\mathbf{x}$ given latent code $\mathbf{z}$ is:
$$ SDF(\mathbf{x}) = \tanh(h_L) $$
Where $h_L$ is the output of the final linear layer. The hidden states $h_i$ are computed as:
$$ h_0 = \text{ReLU}(\mathbf{W}_0 [\mathbf{z}; \mathbf{x}] + \mathbf{b}_0) $$
$$ h_i = \begin{cases} \text{ReLU}(\mathbf{W}_i [h_{i-1}; \mathbf{z}; \mathbf{x}] + \mathbf{b}_i) & \text{if } i \pmod 4 == 0 \\ \text{ReLU}(\mathbf{W}_i h_{i-1} + \mathbf{b}_i) & \text{otherwise} \end{cases} $$
for $i = 1, \dots, L-2$, where $L$ is the number of hidden layers + 1. The final layer is $h_L = \mathbf{W}_{out} h_{L-1} + \mathbf{b}_{out}$ [S1, unofficial].

**Parameters:**
*   `input_voxel_grid_size`: Default 128 [S1, unofficial].
*   `latent_dimension`: Default 256 [S1, unofficial].
*   `decoder_hidden_dimension`: Default 512 [S1, unofficial].
*   `decoder_num_hidden_layers`: Default 10 [S1, unofficial].
*   `num_points_per_minor_batch`: Controls memory usage during training/inference. Default varies by config [S1, unofficial].
*   `learning_rate`: Adam optimizer step size. Default varies by config [S1, unofficial].

**Edge Cases and Pitfalls:**
*   **Shape Mismatch:** The encoder hardcodes the flattened feature size to 64 ($64 \times 1 \times 1 \times 1$). Changing `input_voxel_grid_size` without adjusting this hardcoded value causes a shape mismatch at the first FC layer (`self.fc1`) [S1, unofficial].
*   **Decoder Hardcoding:** The final decoder layer is hardcoded as `Linear(512, 1)`. Changing `decoder_hidden_dimension` from 512 breaks the network unless this layer is updated [S1, unofficial].
*   **Memory Management:** During mesh extraction (Marching Cubes), query points are processed in batches (e.g., 200,000 points) to prevent GPU Out-Of-Memory (OOM) errors. Results are accumulated via concatenation before reshaping [S1, unofficial].

**Pseudocode:**
```python
import torch
import torch.nn as nn
import torch.nn.functional as F

class VoxelCNNEncoder(nn.Module):
    def __init__(self, latent_size):
        super().__init__()
        # 3 blocks of Conv3d -> BN -> ReLU -> MaxPool3d -> Dropout
        self.encoder = nn.Sequential(
            nn.Conv3d(1, 16, kernel_size=3, stride=2, padding=1),
            nn.BatchNorm3d(16),
            nn.ReLU(),
            nn.MaxPool3d(2),
            nn.Dropout3d(0.3),
            
            nn.Conv3d(16, 32, kernel_size=3, stride=2, padding=1),
            nn.BatchNorm3d(32),
            nn.ReLU(),
            nn.MaxPool3d(2),
            nn.Dropout3d(0.3),
            
            nn.Conv3d(32, 64, kernel_size=3, stride=2, padding=1),
            nn.BatchNorm3d(64),
            nn.ReLU(),
            nn.MaxPool3d(2),
            nn.Dropout3d(0.3)
        )
        # Hardcoded flattened size based on 128x128x128 input
        self.fc1 = nn.Linear(64, 512)
        self.bn1 = nn.BatchNorm1d(512)
        self.fc2 = nn.Linear(512, latent_size)

    def forward(self, x):
        # x shape: (B, 1, H, W, D)
        features = self.encoder(x)
        features = features.flatten(start_dim=1)
        x = self.fc1(features)
        x = self.bn1(x)
        x = F.relu(x)
        x = F.dropout(x, p=0.3, training=self.training)
        x = self.fc2(x)
        return x

class SDFDecoder(nn.Module):
    def __init__(self, latent_dim=256, hidden_dim=512, num_layers=10):
        super().__init__()
        self.latent_dim = latent_dim
        self.hidden_dim = hidden_dim
        self.num_layers = num_layers
        
        layers = []
        # Input layer
        layers.append(nn.Linear(latent_dim + 3, hidden_dim))
        
        # Hidden layers
        for i in range(1, num_layers - 1):
            if i % 4 == 0:
                # Skip connection: concat latent and pos to hidden
                layers.append(nn.Linear(hidden_dim + latent_dim + 3, hidden_dim))
            else:
                layers.append(nn.Linear(hidden_dim, hidden_dim))
        
        # Output layer
        layers.append(nn.Linear(hidden_dim, 1))
        
        self.layers = nn.ModuleList(layers)
        self.dropout = nn.Dropout(0.3)
        self.relu = nn.ReLU()
        self.tanh = nn.Tanh()

    def forward(self, latent, points):
        # latent: (B, latent_dim)
        # points: (B, 3)
        # Concatenate latent and points
        input_cat = torch.cat([latent, points], dim=1)
        
        h = self.layers[0](input_cat)
        h = self.relu(h)
        
        for i in range(1, self.num_layers - 1):
            if i % 4 == 0:
                # Skip connection
                h = torch.cat([h, latent, points], dim=1)
            h = self.layers[i](h)
            h = self.relu(h)
            h = self.dropout(h)
            
        # Final layer
        out = self.layers[-1](h)
        return self.tanh(out)

class Vox2SDF(nn.Module):
    def __init__(self, latent_size=256, hidden_dim=512, num_layers=10):
        super().__init__()
        self.encoder = VoxelCNNEncoder(latent_size)
        self.decoder = SDFDecoder(latent_dim=latent_size, hidden_dim=hidden_dim, num_layers=num_layers)

    def forward(self, voxel_grid, points):
        # voxel_grid: (B, 1, H, W, D)
        # points: (B, N, 3) -> reshape to (B*N, 3)
        batch_size, num_points = points.shape[0], points.shape[1]
        
        # Encode
        latent = self.encoder(voxel_grid) # (B, latent_size)
        
        # Repeat latent for each point
        # latent: (B, 1, latent_size) -> (B, N, latent_size) -> (B*N, latent_size)
        latent = latent.unsqueeze(1).expand(-1, num_points, -1)
        latent = latent.reshape(-1, latent.size(-1))
        
        # Reshape points to (B*N, 3)
        points = points.reshape(-1, 3)
        
        # Decode
        sdf_pred = self.decoder(latent, points)
        
        # Reshape back to (B, N, 1)
        sdf_pred = sdf_pred.reshape(batch_size, num_points, 1)
        return sdf_pred
```

## Operating characteristics
*   **Time Complexity:** Encoding is $O(H \cdot W \cdot D \cdot C_{out})$ for the CNN. Decoding is $O(N \cdot L \cdot D_{hidden})$ for $N$ query points and $L$ MLP layers.
*   **Memory Complexity:** The encoder requires memory proportional to the voxel grid size and intermediate feature maps. The decoder requires memory proportional to the number of query points processed in a batch. Large batches of query points (e.g., for Marching Cubes) require careful batching to avoid GPU OOM [S1, unofficial].
*   **Performance:** Evaluated on ShapeNet categories using MSE loss on sampled SDF points. Mesh extraction is performed via Marching Cubes at level 0 [S1, unofficial].
*   **Strengths:** Directly encodes specific input geometry; differentiable end-to-end pipeline.
*   **Limitations:** Single global latent vector limits representation of multi-object or highly complex scenes compared to grid-based latents [S1, unofficial]. Hardcoded dimensions in the reference implementation reduce flexibility [S1, unofficial].

## Background
Vox2SDF is an implementation of a neural network pipeline for converting voxel models into neural SDF representations [S1, unofficial]. It builds upon the concept of DeepSDF [3051-deepsdf-neural-network.md] but adapts the encoder to take a voxel grid as input rather than generating a latent code from a category label. The specific architecture and codebase are from an unofficial repository by TurtleJayWang [S1, unofficial].
