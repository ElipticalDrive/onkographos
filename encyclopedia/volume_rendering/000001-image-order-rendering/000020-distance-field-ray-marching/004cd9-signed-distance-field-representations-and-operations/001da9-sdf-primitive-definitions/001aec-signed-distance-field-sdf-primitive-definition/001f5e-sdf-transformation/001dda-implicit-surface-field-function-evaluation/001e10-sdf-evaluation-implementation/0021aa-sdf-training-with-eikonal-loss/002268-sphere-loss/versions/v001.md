# Sphere Loss

Also called: Analytical Sphere Distance Loss, SDF Sphere Pretraining Loss

## Overview
Sphere Loss is a regularization term used during the pretraining of Signed Distance Field (SDF) networks to initialize the implicit surface representation as a sphere [S1, S2, unofficial]. It minimizes the mean squared error between the network's predicted SDF values and the analytical Euclidean distance to a sphere surface of a specified radius [S1, S2, unofficial]. Unlike general Eikonal loss which enforces gradient constraints on arbitrary shapes, Sphere Loss provides a strong geometric prior by forcing the network to learn a specific, simple topology, stabilizing subsequent training on complex shapes [S1, S2, unofficial].

## How it works
Sphere Loss operates by comparing the output of the SDF network against the ground-truth analytical SDF for a sphere. It is typically applied during a pretraining phase before the network is trained on target point cloud data or images [S1, S2, unofficial].

**Inputs and Outputs:**
- **Inputs:**
  - `points`: A tensor of 3D coordinates, shape $(N, 3)$, representing the query points [S1, S2, unofficial].
  - `signed_distance`: A tensor containing the network's predicted SDF values. In the reference implementation, this is indexed as `[..., 0]`, implying the SDF is the first channel of a multi-channel output or a specific layer output [S1, unofficial].
  - `radius`: The radius $r$ of the target sphere [S1, S2, unofficial]. Default value is $1.0$ [S1, S2, unofficial].
- **Output:**
  - A scalar loss value $\mathcal{L}_{\text{sphere}}$ [S1, S2, unofficial].

**Data Structures:**
- Points are stored as floating-point coordinates $(x, y, z)$ [S1, S2, unofficial].
- Predicted SDF values are stored as floating-point scalars [S1, S2, unofficial].

**Steps:**
1. Extract the predicted SDF values from the input tensor. If the input is multi-channel, select the first channel: $f(x_i) = \text{signed\_distance}[i, 0]$ [S1, unofficial].
2. Compute the L2 norm (Euclidean distance from the origin) for each point: $\|x_i\|_2 = \sqrt{x_i^2 + y_i^2 + z_i^2}$ [S1, S2, unofficial].
3. Compute the analytical SDF for a sphere centered at the origin with radius $r$: $d_i = \|x_i\|_2 - r$ [S1, S2, unofficial].
4. Calculate the difference between the predicted SDF and the analytical SDF: $\Delta_i = f(x_i) - d_i$ [S1, S2, unofficial].
5. Square the differences and compute the mean over all $N$ points [S1, S2, unofficial].

**Formula:**
The loss is defined as the Mean Squared Error (MSE) between the predicted SDF $\phi(x_i)$ (or $f(x_i)$) and the analytical sphere distance:

$$
\mathcal{L}_{\text{sphere}} = \frac{1}{N} \sum_{i=1}^{N} \left( \phi(x_i) - (\|x_i\|_2 - r) \right)^2
$$

Where:
- $N$ is the number of points [S1, S2, unofficial].
- $\phi(x_i)$ or $f(x_i)$ is the predicted signed distance at point $x_i$ [S1, S2, unofficial].
- $\|x_i\|_2$ is the L2 norm of the point coordinates $x_i$ [S1, S2, unofficial].
- $r$ is the sphere radius [S1, S2, unofficial].

**Pseudocode:**
```python
import torch

def sphere_loss(signed_distance: torch.Tensor, points: torch.Tensor, radius: float = 1.0) -> torch.Tensor:
    """
    Computes the Sphere Loss for pretraining an SDF network.
    
    Args:
        signed_distance: Tensor of predicted SDF values. Shape [..., C].
                         The SDF value is assumed to be at index 0.
        points: Tensor of 3D coordinates. Shape [..., 3].
        radius: Radius of the target sphere. Default 1.0.
        
    Returns:
        Scalar tensor representing the mean squared error.
    """
    # Extract predicted SDF values (first channel)
    # [G] Assuming standard PyTorch indexing; if signed_distance is 1D, use signed_distance directly.
    predicted_sdf = signed_distance[..., 0]
    
    # Compute analytical sphere SDF: ||p|| - r
    # [G] torch.norm computes the L2 norm along the specified dimension.
    point_norms = torch.norm(points, dim=-1)
    analytical_sdf = point_norms - radius
    
    # Compute MSE
    # [G] torch.square is element-wise squaring. mean() computes the average over all elements.
    loss = torch.square(predicted_sdf - analytical_sdf).mean()
    
    return loss
```

**Parameters:**
- `radius`: The radius of the sphere. Typical value is $1.0$ [S1, S2, unofficial].
- `points`: Shape $(N, 3)$ [S1, S2, unofficial].
- `signed_distance`: Shape $(N, 1)$ or $(N, C)$ where $C \ge 1$ [S1, unofficial].

**Edge Cases and Pitfalls:**
- **Center Assumption:** The analytical formula $\|x_i\|_2 - r$ assumes the sphere is centered at the origin $(0,0,0)$. If the target sphere is centered elsewhere, the points must be translated relative to the center before computing the norm [G].
- **Input Shape:** The implementation assumes the SDF is the first channel. If the network outputs a scalar directly, indexing `[..., 0]` may fail or behave unexpectedly depending on the tensor rank [S1, unofficial].
- **Precision:** For very large or very small radii, floating-point precision issues may arise in the norm calculation [G].

## Subtopics

### Eikonal Loss
Enforces the unit gradient magnitude constraint ($\|\nabla \phi(x)\| = 1$) on the SDF. Sphere Loss is often used in conjunction with Eikonal Loss, where Sphere Loss provides geometric initialization and Eikonal Loss ensures the distance field property [Parent].

### SDF Training with Eikonal Loss
The parent method that incorporates Sphere Loss as a pretraining step or auxiliary loss term to stabilize training [Parent].

## Operating characteristics
- **Time Complexity:** $O(N)$, where $N$ is the number of points. The computation involves a norm calculation and a mean operation, both linear in the number of points [S1, S2, unofficial].
- **Memory Complexity:** $O(N)$ to store the points and predicted SDF values during the forward pass [S1, S2, unofficial].
- **Strengths:** Provides a strong geometric prior, accelerating convergence and preventing mode collapse during the initial stages of SDF training [S1, S2, unofficial].
- **Limitations:** Only applicable when the target shape is a sphere or can be approximated by a sphere. It does not enforce the Eikonal equation (unit gradient) on its own [S1, S2, unofficial].
- **When to Use:** During the pretraining phase of an SDF network when initializing with a simple shape like a sphere [S1, S2, unofficial].
- **When Not to Use:** When the target shape is complex and not sphere-like, or when the network is already trained on complex shapes and no longer needs this specific prior [S1, S2, unofficial].

## Background
Sphere Loss was introduced in the context of neural surface reconstruction and implicit surface learning. It is used in repositories such as `Neural_Surfaces` and `Neural-Volume-Rendering-and-Surface-Rendering` to pretrain SDF networks [S1, S2, unofficial]. The method leverages the analytical simplicity of the sphere's distance function to provide a stable starting point for more complex implicit surface representations [S1, S2, unofficial].
