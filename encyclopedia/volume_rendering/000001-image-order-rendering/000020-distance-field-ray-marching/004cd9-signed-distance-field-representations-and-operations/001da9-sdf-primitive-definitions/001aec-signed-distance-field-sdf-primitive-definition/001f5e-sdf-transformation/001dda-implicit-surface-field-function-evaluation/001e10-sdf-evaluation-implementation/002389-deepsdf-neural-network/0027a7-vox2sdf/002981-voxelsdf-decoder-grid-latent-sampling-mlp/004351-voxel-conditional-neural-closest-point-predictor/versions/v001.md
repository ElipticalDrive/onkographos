# Voxel-Conditional Neural Closest Point Predictor

Also called: Neural Closest Point Predictor

## Overview
The Voxel-Conditional Neural Closest Point Predictor is a neural network module that synthesizes surface details by mapping any 3D query point $x$ to its closest point on a target surface $S$, conditioned on a voxelized representation $V$ of the shape [S1, unofficial]. It solves the problem of refining coarse voxel-based mesh reconstructions into high-fidelity surfaces by predicting the displacement vector to the implicit surface, effectively defining the surface as the zero-level set of the predicted vector field [S1, unofficial]. Unlike methods requiring ground-truth point clouds or normals (e.g., CSPNet), it operates solely on the voxel input, making it suitable for generative tasks where ground-truth geometry is unavailable [S1, unofficial].

## How it works
**Inputs and Outputs:**
- **Input:** A binary voxel grid $V \in \{0, 1\}^r$ representing the coarse shape, and a 3D query point $x \in \mathbb{R}^3$.
- **Output:** A 3D vector $\hat{p} \in \mathbb{R}^3$ representing the predicted closest point on the surface $S$ relative to the origin, or the displacement vector $x - CP(x)$ depending on implementation convention. The surface is implicitly defined by $S = \{x \in \mathbb{R}^3 \mid h_\theta(V, x) - x = 0\}$ [S1, unofficial].

**Data Structures:**
- **Voxel Grid:** A 3D tensor of binary values. The encoder processes this through a hierarchy of resolutions.
- **Multi-resolution Features:** A set of feature vectors extracted from different layers of the 3D convolutional network, corresponding to resolutions $32^3, 16^3, 8^3$ (and potentially $4^3$ in the encoder path) [S1, unofficial].
- **Query Point Features:** A concatenated vector formed by tri-linearly interpolating the multi-resolution features at the query location $x$.

**Numbered Steps:**
1. **Data Preparation:** Normalize training meshes to a unit bounding box. Voxelize the mesh and extract the boundary mesh $T^s = (V^s, F^s_{tri})$ [S1, unofficial].
2. **Ground Truth Calculation:** For each vertex $v^s \in V^s$, calculate the closest point $p^s$ on the ground truth surface $S$ [S1, unofficial].
3. **Sampling:** Sample training points along line segments connecting boundary vertices to their closest points: $\{(1-\alpha)p^s + \alpha v^s \mid \alpha \in [0, 1]\}$ for each $v^s$ [S1, unofficial]. This creates a sampling band tied to the voxel output [S1, unofficial].
4. **Feature Encoding:**
   - Pass the voxel grid $V$ through a 4-layer 3D convolutional encoder with widths $\{32, 64, 128, 256\}$, reducing resolution from $32^3$ to $4^3$ [S1, unofficial].
   - Extract features from intermediate layers (resolutions $32^3, 16^3, 8^3$) [S1, unofficial].
   - For each query point $x$, perform tri-linear interpolation on the feature maps from each convolution layer to obtain multi-resolution features at $x$ [S1, unofficial].
5. **Feature Decoding:** Concatenate the interpolated multi-resolution features. Pass the concatenated vector through a two-layer Multi-Layer Perceptron (MLP) [S1, unofficial].
6. **Prediction:** The MLP outputs the predicted closest point vector [S1, unofficial].

**Formula:**
The closest point function is defined as:
$$ CP(x) = \arg \min_{p \in S} \| p - x \|_2 $$
The network $h_\theta(V, x)$ approximates this function [S1, unofficial].

**Parameters:**
- **Network Architecture:** Multi-scale voxel network with 6-layer 3D convolutions extracting features at resolutions $32^3, 16^3, 8^3$, fed into a fully connected layer [S1, unofficial]. Alternatively described as a 4-layer encoder with widths $\{32, 64, 128, 256\}$ followed by a 2-layer MLP [S1, unofficial].
- **Training:** 500 epochs, learning rate $2 \times 10^{-3}$ [S1, unofficial].

**Edge Cases and Pitfalls:**
- The closest point function is discontinuous at points on the medial axis [S1, unofficial].
- The network is only valid for points close to the final surface [S1, unofficial]. It relies on the voxelized shape as an initial mesh reconstruction to ensure query points remain in the valid region [S1, unofficial].

## Operating characteristics
- **Time Complexity:** Depends on the number of query points and the cost of tri-linear interpolation across multiple resolutions. The MLP inference is negligible compared to the interpolation and convolution encoding.
- **Memory Complexity:** Requires storing the multi-resolution feature maps from the 3D convolutional encoder. The source specifies resolutions $32^3, 16^3, 8^3$ [S1, unofficial].
- **Strengths:** Can synthesize fine surface details from coarse voxels; does not require ground-truth normals or point clouds, making it suitable for generative models [S1, unofficial].
- **Limitations:** The closest point function is discontinuous on the medial axis, limiting validity to points close to the surface [S1, unofficial]. Requires a good initial voxel representation [S1, unofficial].
- **When to use:** When refining a voxel-based shape into a detailed mesh and ground-truth surface normals are not available.
- **When not to use:** For points far from the surface or when medial axis discontinuities are a concern.

## Background
The Voxel-Conditional Neural Closest Point Predictor was introduced in the Neural Volumetric Mesh Generator (NVMG) paper [S1, unofficial]. It is part of a pipeline that uses voxels as an intermediate representation for mesh generation and editing. The method is inspired by IF-Net (Implicit Function Network) for multi-resolution feature extraction [S1, unofficial]. It addresses the limitation of previous closest point prediction networks like CSPNet, which require ground-truth point clouds and normals, by conditioning the prediction on the voxel grid alone [S1, unofficial].
