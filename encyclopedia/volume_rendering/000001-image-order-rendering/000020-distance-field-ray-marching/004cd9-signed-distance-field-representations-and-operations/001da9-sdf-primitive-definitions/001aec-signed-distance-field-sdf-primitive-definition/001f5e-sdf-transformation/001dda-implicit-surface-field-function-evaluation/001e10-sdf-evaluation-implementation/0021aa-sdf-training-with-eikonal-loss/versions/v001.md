# SDF Training with Eikonal Loss

Also called: Eikonal Loss, Neural SDF Optimization, Neural SDF Training with Eikonal Regularization, Neural SDF Training with Point Cloud and Eikonal Regularization, SDF Regularization, SDF Surface Training with Eikonal Loss, VolSDF Training

## Overview
SDF Training with Eikonal Loss is a method for optimizing a neural implicit Signed Distance Field (SDF) to match 3D point cloud data by enforcing the Eikonal equation constraint. It solves the problem of training an arbitrary scalar field to represent a valid geometric distance function, which requires the gradient magnitude to be unity everywhere. Unlike [DeepSDF Neural Network](3051-deepsdf-neural-network.md), which typically optimizes for zero-level set fitting without explicit gradient constraints, this method adds a regularization term that penalizes deviations from unit gradient norms, ensuring the output is a true signed distance field rather than just a binary segmentation or occupancy field.

## How it works
The method trains a Multi-Layer Perceptron (MLP) to predict the signed distance from any 3D point to a target surface defined by a point cloud. The training process combines a data fidelity term (matching the point cloud) with an Eikonal regularization term (enforcing geometric consistency).

### Inputs and Outputs
*   **Input**: A 3D point cloud $P$ representing the target surface.
*   **Output**: An MLP model $\phi(x)$ that outputs the signed distance value for any input coordinate $x \in \mathbb{R}^3$.

### Data Structures
*   **MLP Model**: A standard feedforward neural network. In the reference implementation [S1, S2, unofficial], it is defined within a `NeuralSurface` class. The network takes a 3D coordinate as input and outputs a scalar distance value.
*   **Point Cloud Data**: A tensor of shape $(N, 3)$ containing vertex coordinates.
*   **Training Configuration**:
    *   `cfg.training.batch_size`: Number of points sampled per optimization step.
    *   `cfg.training.bounds`: A bounding box (min/max coordinates) defining the spatial limits for sampling random points.
    *   `cfg.training.eikonal_weight`: Weight for the gradient Eikonal loss term.
    *   `cfg.training.inter_weight`: Weight for the interior regularization loss term.
    *   `lr`: Learning rate for the optimizer.

### Numbered Steps

1.  **Data Preprocessing**: Load the point cloud vertices and center them by subtracting the mean coordinate.
    $$ P_{centered} = P - \text{mean}(P) $$
2.  **Model Initialization**: Initialize the MLP and an optimizer (typically Adam) with the specified learning rate.
3.  **Pretraining (Optional)**: Before training on the specific point cloud, the network may be pretrained using [Sphere Loss](2750-sphere-loss.md) to initialize the implicit surface as a sphere, stabilizing subsequent training [S1, S2, unofficial].
4.  **Sampling**:
    *   Sample a batch of points $X_{pc}$ uniformly from the centered point cloud $P_{centered}$.
    *   Sample a batch of points $X_{rand}$ uniformly within the training bounding box `cfg.training.bounds`.
5.  **Forward Pass (Point Cloud)**:
    *   Query the MLP for distances at $X_{pc}$: $D_{pc} = \phi(X_{pc})$.
    *   Compute the point cloud loss as the mean L2 norm of the distances (expecting zero at the surface):
        $$ \mathcal{L}_{pc} = \frac{1}{N_{pc}} \sum_{i=1}^{N_{pc}} \| D_{pc,i} \|_2 $$
6.  **Forward Pass (Random Points)**:
    *   Query the MLP for distances and gradients at $X_{rand}$. The gradients $\nabla \phi(X_{rand})$ are computed using automatic differentiation.
    *   Let $D_{rand} = \phi(X_{rand})$ and $G_{rand} = \nabla \phi(X_{rand})$.
7.  **Loss Computation**:
    *   **Interior Regularization**: Penalize points inside the object (negative distance) to encourage the zero-level set to be the surface. This uses an exponential weighting based on the distance magnitude:
        $$ \mathcal{L}_{inter} = \text{mean}(\exp(-100 \cdot |D_{rand}|)) $$
        The factor $100$ (written as `1e2` in code) scales the exponential decay [S2, unofficial].
    *   **Eikonal Loss**: Enforce that the gradient magnitude is 1. Sources provide two variants of this loss:
        *   Variant 1 (L1): $\mathcal{L}_{eikonal} = \frac{1}{N} \sum_{i=1}^{N} |\|\nabla \phi(x_i)\|_2 - 1|$ [S1, unofficial].
        *   Variant 2 (L2): $\mathcal{L}_{eikonal} = \frac{1}{N} \sum_{i=1}^{N} (\|\nabla \phi(x_i)\|_2 - 1)^2$ [S2, unofficial].
    *   **Total Loss**:
        $$ \mathcal{L}_{total} = \mathcal{L}_{pc} + \mathcal{L}_{inter} \cdot w_{inter} + \mathcal{L}_{eikonal} \cdot w_{eikonal} $$
        where $w_{inter}$ is `cfg.training.inter_weight` and $w_{eikonal}$ is `cfg.training.eikonal_weight` [S2, unofficial].
8.  **Optimization**:
    *   Zero gradients.
    *   Backpropagate the total loss.
    *   Step the optimizer.

### Pseudocode

```python
import torch
import torch.nn as nn

def compute_eikonal_loss(gradients: torch.Tensor) -> torch.Tensor:
    """
    Computes the Eikonal loss enforcing unit gradient magnitude.
    Uses L2 loss variant as per [S2, unofficial].
    """
    # Compute L2 norm of gradients along the last dimension (features)
    grad_norms = torch.norm(gradients, p=2, dim=-1)
    # Return mean squared difference from 1.0
    return torch.mean((grad_norms - 1.0) ** 2)

def train_sdf_eikonal(model: nn.Module, point_cloud: torch.Tensor, config: dict):
    """
    Trains a neural SDF using Eikonal loss.
    
    Args:
        model: Neural network instance with get_distance_and_gradient method.
        point_cloud: Tensor of shape (N, 3) containing the target surface points.
        config: Dictionary containing training hyperparameters.
    """
    # 1. Center point cloud
    mean_pos = torch.mean(point_cloud, dim=0, keepdim=True)
    centered_points = point_cloud - mean_pos
    
    # 2. Initialize optimizer
    optimizer = torch.optim.Adam(model.parameters(), lr=config['lr'])
    
    # 3. Training Loop
    for epoch in range(config['num_epochs']):
        optimizer.zero_grad()
        
        # 4. Sample points from point cloud
        # Select random indices from the centered points
        pc_indices = torch.randint(0, centered_points.shape[0], (config['batch_size'],))
        points_pc = centered_points[pc_indices]
        
        # 5. Query distances for point cloud points
        distances_pc = model.get_distance(points_pc) # Shape: (batch_size, 1)
        
        # 6. Compute Point Cloud Loss (L2 norm of distances)
        loss_pc = torch.norm(distances_pc, dim=-1).mean()
        
        # 7. Sample random points in bounds
        # Uniform distribution within config['bounds']
        bounds = config['bounds'] # Assume [min_x, max_x, min_y, max_y, min_z, max_z]
        rand_points = torch.rand(config['batch_size'], 3)
        rand_points = rand_points * (bounds[1::2] - bounds[0::2]) + bounds[0::2]
        
        # 8. Query distances and gradients for random points
        distances_rand, gradients_rand = model.get_distance_and_gradient(rand_points)
        
        # 9. Compute Interior Regularization Loss
        # Penalize points inside the object (negative distance)
        # exp(-1e2 * |distance|)
        inter_loss = torch.exp(-1e2 * torch.abs(distances_rand)).mean()
        
        # 10. Compute Eikonal Loss
        eikonal_loss_val = compute_eikonal_loss(gradients_rand)
        
        # 11. Combine Losses
        total_loss = (loss_pc + 
                      inter_loss * config['inter_weight'] + 
                      eikonal_loss_val * config['eikonal_weight'])
        
        # 12. Backpropagate and Optimize
        total_loss.backward()
        optimizer.step()
```

### Parameters and Typical Values
*   **Learning Rate (`lr`)**: Typically $10^{-4}$ to $10^{-3}$ for Adam [S2, unofficial].
*   **Batch Size**: Depends on memory; common values are 2048–8192 points per batch [S1, S2, unofficial].
*   **Eikonal Weight (`eikonal_weight`)**: Often set to 1.0 or tuned to balance with the point cloud loss [S2, unofficial].
*   **Interior Weight (`inter_weight`)**: Scales the exponential interior loss; typically small (e.g., 0.1–1.0) [S2, unofficial].
*   **Exponential Scale**: The factor $100$ (1e2) in the interior loss term is fixed in the reference implementation [S2, unofficial].

### Edge Cases and Pitfalls
*   **Precision**: The exponential term $\exp(-100 \cdot |d|)$ can underflow for points far from the surface, resulting in zero gradients. This is intentional to ignore irrelevant regions but requires careful handling of floating-point precision.
*   **Boundary Conditions**: Random points sampled outside the object's convex hull may not contribute meaningfully to the Eikonal constraint if the interior loss dominates. The bounding box must be large enough to cover the object but not excessively large to waste computation.
*   **Gradient Vanishing**: If the network fails to learn a proper SDF, gradients may become zero or very small, causing the Eikonal loss to saturate. Pretraining with [Sphere Loss](2750-sphere-loss.md) helps mitigate this [S1, S2, unofficial].

## Subtopics

### [Sphere Loss](2750-sphere-loss.md)
Sphere Loss is a regularization term used during the pretraining of Signed Distance Field (SDF) networks to initialize the implicit surface representation as a sphere. It minimizes the mean squared error between the network's predicted SDF values and the analytical Euclidean distance to a sphere surface of a specified radius. Unlike general Eikonal loss which enforces gradient constraints on arbitrary shapes, Sphere Loss provides a strong geometric prior by forcing the network to learn a specific, simple topology, stabilizing subsequent training on complex shapes.

### Bias Network for High-Fidelity Points
A network that captures geometric bias between volume rendering and point modeling, specifically trained on high-fidelity points to enhance detail representation [S3, unofficial]. It filters the point set $P$ to create $P_s$ containing only points with predicted variance below threshold $\epsilon$: $P_s = \{x_P \mid x_P \in P, \bar{\sigma}^2(x_P) < \epsilon\}$ [S3, unofficial]. The bias SDF value $f_b(x_P)$ is computed using a dedicated MLP: $f_b(x_P) = \text{MLP}_{bias}(x_P)$ [S3, unofficial]. The final SDF value is the sum of the base SDF $f(x_P)$ and the bias SDF: $f_{final}(x_P) = f(x_P) + f_b(x_P)$ [S3, unofficial]. The Bias network is optimized using L1 loss $\mathcal{L}_{bias} = \frac{1}{D_{P_s}} \sum_{x_P \in P_s} |f_\varepsilon(x_P) - f_{final}(x_P)|$, assuming ideal SDF values $f_\varepsilon(x_P)$ are 0 [S3, unofficial]. This allows the model to learn high-frequency details from reliable points while remaining independent of volume rendering gradients [S3, unofficial].

## Operating characteristics
*   **Time Complexity**: Linear with respect to the number of sampled points $N$ and the depth/width of the MLP. Each training step requires $N$ forward passes and $N$ backward passes through the network.
*   **Memory Complexity**: Linear with respect to $N$ for storing gradients and intermediate activations. The model size is constant.
*   **Performance**: The Eikonal constraint significantly improves the geometric accuracy of the reconstructed surface compared to methods without it, particularly in regions with sparse point cloud data. However, it requires careful tuning of loss weights to prevent the regularization from overpowering the data fidelity term.
*   **Strengths**: Produces valid signed distance fields with smooth gradients; robust to noise in point clouds when combined with variance filtering (as in Bias Network); enables efficient ray marching for rendering.
*   **Limitations**: Sensitive to hyperparameter tuning (loss weights, learning rate); may struggle with highly complex geometries if the MLP capacity is insufficient; pretraining step adds overhead.
*   **When to Use**: Ideal for reconstructing surfaces from point clouds where a true distance field is required for downstream tasks like ray marching or collision detection.
*   **When Not to Use**: If only occupancy or binary segmentation is needed, simpler methods like [DeepSDF Neural Network](3051-deepsdf-neural-network.md) without Eikonal loss may suffice. If high-frequency details are critical and point clouds are sparse, consider combining with [Bias Network for High-Fidelity Points](2750-sphere-loss.md).

## Background
The method originates from the need to train neural networks to output signed distance functions rather than just occupancy or density fields. The Eikonal equation $|\nabla \phi(x)| = 1$ is a fundamental property of signed distance functions. By enforcing this constraint during training, the network learns a geometrically consistent representation. This approach is central to methods like VolSDF, which combines neural volume rendering with SDF representations [S1, unofficial]. The implementation details provided in the sources are based on educational assignments and unofficial repositories [S1, S2, unofficial], while the Bias Network variant is described in the Point-NeuS paper [S3, unofficial].
