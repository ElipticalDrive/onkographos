# Polynomial Smooth Minimum

Also called: Quilez smin, Quilez smooth min, smoothMin

## Overview
Polynomial Smooth Minimum is a blending function for combining two Signed Distance Function (SDF) values to create organic, metaball-like merges between primitives without branching or trigonometry [S1, S2, S3, unofficial]. It performs a smooth union of two SDFs using a radius parameter $k$, creating a blending effect when objects are close in distance [S2, S3, unofficial]. It sets itself apart from hard minimum operators by providing a continuous, differentiable transition zone, and from exponential smooth minimums by using a quadratic polynomial which is computationally cheaper but has a slightly different falloff shape [S1, S2, unofficial].

## How it works
**Inputs and Outputs:**
- Inputs: Two scalar SDF values $a$ and $b$, and a non-negative smoothing radius $k$.
- Output: A single scalar SDF value representing the smooth union.

**Data Structures:**
- No complex data structures; operates on scalar floats.

**Parameters:**
- $k$: Smoothing radius. Controls the width of the blending region. Typical values are 0.2 or 0.3 [S2, unofficial]. Exposed as a UI slider in some implementations [S1, unofficial].

**Algorithm:**
The method computes an intermediate blend factor $h$ based on the difference between $a$ and $b$ relative to $k$. If $k$ is effectively zero, it falls back to the hard minimum.

1. If $k \le 10^{-6}$, return $\min(a, b)$ [S2, unofficial].
2. Calculate the absolute difference: $\Delta = |a - b|$.
3. Calculate the blend factor $h$:
   $$ h = \frac{\max(k - \Delta, 0.0)}{k} $$
   This is equivalent to clamping the linear interpolation factor:
   $$ h = \text{clamp}\left(0.5 + 0.5 \cdot \frac{b - a}{k}, 0.0, 1.0\right) $$
   [S1, S2, unofficial].
4. Calculate the result using the minimum of $a$ and $b$ and the blend factor:
   $$ \text{smin}(a, b, k) = \min(a, b) - h^2 \cdot k \cdot 0.25 $$
   [S2, unofficial].
   
   Alternatively, using the mix formulation from [S1, unofficial]:
   $$ \text{result} = \text{mix}(b, a, h) - k \cdot h \cdot (1.0 - h) $$
   where $\text{mix}(b, a, h) = b + h(a - b)$.

**Pseudocode:**
```python
def polynomial_smin(a: float, b: float, k: float) -> float:
    # Fallback to hard union if smoothing radius is negligible
    if k <= 1e-6:
        return min(a, b)
    
    # Calculate blend factor h
    # h represents how much the two fields overlap
    diff = abs(a - b)
    h = max(k - diff, 0.0) / k
    
    # Calculate smooth minimum
    # Using the quadratic form: min(a,b) - h^2 * k * 0.25
    min_val = min(a, b)
    result = min_val - (h * h) * k * 0.25
    
    return result
```

**Edge Cases and Pitfalls:**
- If $k=0$, the function must handle division by zero or return the hard minimum. The check $k \le 10^{-6}$ handles this [S2, unofficial].
- The function is $C^1$ continuous (continuous first derivative) but not $C^2$ at the boundaries of the blending region ($h=0$ and $h=1$) [S2, unofficial]. This is generally sufficient for ray marching normals estimation.
- Precision issues may arise if $k$ is very small relative to the floating-point precision of $a$ and $b$.

## Subtopics

### Polynomial Smooth Maximum
Polynomial Smooth Maximum is the dual operator for smooth intersection (or subtraction when combined with negation). It blends the maximum of two SDFs.
- **Definition:** Computes a smooth maximum of two distances $a$ and $b$ with smoothing factor $k$ [S2, unofficial].
- **Formula:**
  $$ h = \frac{\max(k - |a - b|, 0)}{k} $$
  $$ \text{smax}(a, b, k) = \max(a, b) + h^2 \cdot k \cdot 0.25 $$
  [S2, unofficial].
- **Code:**
  ```python
  def polynomial_smax(a: float, b: float, k: float) -> float:
      if k <= 1e-6:
          return max(a, b)
      diff = abs(a - b)
      h = max(k - diff, 0.0) / k
      max_val = max(a, b)
      result = max_val + (h * h) * k * 0.25
      return result
  ```
  [S2, unofficial].
- **Usage:** Used for smooth intersection of SDFs. Smooth subtraction of $d1$ from $d2$ is implemented as $\text{smax}(-d1, d2, k)$ [S2, unofficial].

## Operating characteristics
- **Time Complexity:** $O(1)$ per pair of SDFs. Involves basic arithmetic operations (abs, max, min, multiply, add).
- **Memory Complexity:** $O(1)$. No auxiliary memory required.
- **Strengths:** Computationally efficient compared to exponential smooth minimums (no `exp` or `log` calls). Provides smooth, organic blending suitable for metaballs and soft object unions [S1, S3, unofficial].
- **Limitations:** The blending region is strictly limited to $k$. Outside this region, it behaves exactly like the hard min/max. The $C^1$ continuity is sufficient for most rendering but may show slight artifacts in high-precision normal estimation if not handled carefully [S2, unofficial].
- **When to use:** When organic blending of SDF primitives is needed and performance is a concern, or when the specific quadratic falloff is desired over the exponential falloff.
- **When not to use:** When a sharper or softer transition than the quadratic curve allows is needed, or when $C^2$ continuity is strictly required.

## Background
The method is attributed to Inigo Quilez, a prominent graphics programmer known for his work on SDFs and ray marching [S1, S2, unofficial]. It is widely used in real-time ray marching shaders to create complex scenes from simple primitives [S3, unofficial]. The technique avoids branching and trigonometry, making it ideal for GPU execution [S1, unofficial].
