# Smooth Subtraction
Also called: S-Subtraction
## Overview
Smooth Subtraction provides a smooth approximation of the boolean difference operation ($A \setminus B$) for two Signed Distance Functions (SDFs) [S2, unofficial]. It blends the subtraction of one shape from another using a smoothing parameter $k$ [S1, unofficial].
## How it works
### Inputs and Outputs
- **Inputs**:
  - $d_1$: SDF value of the subtracted volume [S2, unofficial].
  - $d_2$: SDF value of the base volume [S2, unofficial].
  - $k$: Smoothing factor or blending radius ($k > 0$) [S2, unofficial].
- **Output**:
  - $d$: Smoothed SDF value for the difference [S1, unofficial].
### Data Structures
The operation is point-wise and scalar, requiring no auxiliary data structures [G].
### Steps
1. Compute the blending factor $h$ by clamping a linear function of the distance sum:
   $$ h = \text{clamp}\left(0.5 - 0.5 \frac{d_2 + d_1}{k}, 0.0, 1.0\right) $$
2. Compute the linear interpolation between $d_2$ and $-d_1$ using $h$:
   $$ \text{mix}(d_2, -d_1, h) = d_2 \cdot (1 - h) + (-d_1) \cdot h $$
3. Add the smoothstep correction term to the interpolation:
   $$ d = \text{mix}(d_2, -d_1, h) + k \cdot h \cdot (1.0 - h) $$
### Formula
$$ h = \text{clamp}\left(0.5 - 0.5 \frac{d_2 + d_1}{k}, 0.0, 1.0\right) $$
$$ d = \text{mix}(d_2, -d_1, h) + k \cdot h \cdot (1.0 - h) $$
$$ \text{mix}(a, b, t) = a \cdot (1 - t) + b \cdot t $$
where $\text{clamp}(v, \text{min}, \text{max})$ restricts $v$ to $[\text{min}, \text{max}]$ [G].
### Parameters
- **$k$**: The smoothing factor or blending radius [S2, unofficial]. Typical values: Not given in the sources. [G]
### Edge Cases and Pitfalls
- **Division by Zero**: $k$ must be strictly positive to prevent division by zero in the $h$ calculation [G].
- **Precision**: When $d_1$ and $d_2$ are large with opposite signs, cancellation errors may occur in $d_1 + d_2$ [G].
### Pseudocode
```python
def smooth_subtraction(d1: float, d2: float, k: float) -> float:
    if k <= 0.0:
        raise ValueError("k must be positive.")
    h = 0.5 - 0.5 * (d2 + d1) / k
    h = max(0.0, min(1.0, h))
    mix_val = d2 * (1.0 - h) + (-d1) * h
    return mix_val + k * h * (1.0 - h)
```

## Operating characteristics
- **Time Complexity**: $O(1)$ per query point [G].
- **Memory Complexity**: $O(1)$ auxiliary memory [G].
- **Measured Performance**: Not given in the sources. [G]
- **Strengths**: Differentiable, allowing gradient descent on parameters [G].
- **Limitations**: The result is an approximation, not a true boolean difference. The smoothing radius $k$ introduces a bias; the resulting surface is not exactly at distance 0 from the original boolean boundary [G].
- **When to use**: Differentiable rendering, neural implicit surface optimization, or when smooth transitions between objects are visually preferred over sharp corners [G].
- **When not to use**: When exact boolean geometry is required for collision detection or non-differentiable rendering [G].
## Background
Derived from differentiable constructive solid geometry requirements in neural rendering and optimization contexts [G]. Implemented in PyTorch-based SDF rendering libraries [G].
