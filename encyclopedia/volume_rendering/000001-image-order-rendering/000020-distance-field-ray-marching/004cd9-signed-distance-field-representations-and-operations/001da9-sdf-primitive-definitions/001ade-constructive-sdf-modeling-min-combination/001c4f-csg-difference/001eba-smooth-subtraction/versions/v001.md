# Smooth Subtraction
Also called: S-Subtraction
## Overview
Smooth Subtraction provides a differentiable approximation of the boolean difference operation ($A \setminus B$) for two Signed Distance Functions (SDFs) [S1, unofficial]. Unlike the standard CSG difference which uses a sharp minimum function, this method blends the result using a smooth parameter $k$, enabling gradient-based optimization in neural rendering pipelines [S1, unofficial]. It is distinct from hard CSG operations by maintaining $C^1$ continuity at the boundary, which is critical for differentiable rendering but introduces a smoothing artifact controlled by $k$ [S1, unofficial].
## How it works
### Inputs and Outputs
- **Inputs**:
  - $d_1$: SDF value of the subtracted volume (the "hole" or removed object) at the query point.
  - $d_2$: SDF value of the base volume (the object being cut) at the query point.
  - $k$: Blending radius or smoothness parameter ($k > 0$).
- **Output**:
  - $d_{sub}$: The smoothed SDF value representing the difference.

### Data Structures
No complex data structures are required; the operation is point-wise and scalar.

### Steps
1. Compute the sum of the distances: $s = d_2 + d_1$.
2. Compute the blending factor $h$ using the smoothstep-like interpolation:
   $$ h = \text{clamp}\left(0.5 - 0.5 \cdot \frac{s}{k}, 0.0, 1.0\right) $$
   where $\text{clamp}(v, min, max)$ restricts $v$ to the range $[min, max]$.
3. Compute the linear interpolation (mix) between the base SDF $d_2$ and the negated subtracted SDF $-d_1$:
   $$ \text{mix}(d_2, -d_1, h) = d_2 \cdot (1 - h) + (-d_1) \cdot h $$
4. Compute the final smoothed subtraction value:
   $$ d_{sub} = \text{mix}(d_2, -d_1, h) + k \cdot h \cdot (1 - h) $$

### Formula
The complete formula is:
$$ d_{sub} = \text{mix}(d_2, -d_1, h) + k \cdot h \cdot (1 - h) $$
with:
$$ h = \text{clamp}\left(0.5 - \frac{d_1 + d_2}{2k}, 0.0, 1.0\right) $$
$$ \text{mix}(a, b, t) = a(1 - t) + bt $$

### Parameters
- **$k$**: The blending radius. Controls the width of the smooth transition zone. Typical values depend on the scale of the scene; it should be small relative to the features of interest to preserve sharpness, but large enough to ensure numerical stability for gradients [S1, unofficial]. Not given in the sources.

### Edge Cases and Pitfalls
- **Division by Zero**: The formula does not involve division, but the term $\frac{d_1 + d_2}{2k}$ can become large if $k$ is very small. Ensure $k > 0$.
- **Gradient Discontinuity**: While the function is $C^1$ continuous, the second derivative is discontinuous at the boundaries of the blend region ($h=0$ and $h=1$). This may affect higher-order optimization methods [S1, unofficial].
- **Precision**: When $d_1$ and $d_2$ are large and opposite in sign, cancellation errors may occur in $d_1 + d_2$. Use double precision if necessary [G].

### Pseudocode
```python
def smooth_subtraction(d1, d2, k):
    """
    Compute smooth subtraction of SDF d1 from d2 with smoothness k.
    
    Args:
        d1: SDF of the object to subtract (scalar or array).
        d2: SDF of the base object (scalar or array).
        k: Blending radius (scalar, must be > 0).
        
    Returns:
        d_sub: Smoothed SDF value.
    """
    if k <= 0:
        raise ValueError("Smoothness parameter k must be positive.")
        
    # Step 1: Compute sum
    s = d2 + d1
    
    # Step 2: Compute blending factor h
    # h = clamp(0.5 - 0.5 * (d1 + d2) / k, 0.0, 1.0)
    h = 0.5 - 0.5 * (s / k)
    h = max(0.0, min(1.0, h))
    
    # Step 3: Compute mix(d2, -d1, h)
    # mix(a, b, t) = a * (1 - t) + b * t
    mix_val = d2 * (1.0 - h) + (-d1) * h
    
    # Step 4: Compute final result
    d_sub = mix_val + k * h * (1.0 - h)
    
    return d_sub
```

## Subtopics

### Hard CSG Difference
Uses the `min` function for sharp boundaries. Choose when differentiability is not required and exact boolean operations are needed. See [CSG Difference](1238-csg-difference.md).

### Smooth Union
Blends two SDFs together using a similar smoothstep approach. Choose when merging objects with rounded intersections is desired. See [Smooth Union](1239-smooth-union.md).

## Operating characteristics
- **Time Complexity**: $O(1)$ per query point. The operation involves basic arithmetic and clamping.
- **Memory Complexity**: $O(1)$ auxiliary memory.
- **Strengths**: Differentiable, allowing gradient descent on parameters $d_1, d_2$ or $k$. Smooth boundaries avoid aliasing artifacts in gradient-based optimization.
- **Limitations**: The result is an approximation, not a true boolean difference. The smoothing radius $k$ introduces a bias; the resulting surface is not exactly at distance 0 from the original boolean boundary. Performance is identical to hard CSG, but gradient computation requires careful handling of the non-differentiable points at $h=0,1$ if not using automatic differentiation tools [S1, unofficial].
- **When to use**: Differentiable rendering, neural implicit surface optimization, or when smooth transitions between objects are visually preferred over sharp corners.
- **When not to use**: When exact boolean geometry is required for collision detection or non-differentiable rendering.

## Background
Smooth Subtraction is derived from the need for differentiable constructive solid geometry (CSG) in neural rendering and optimization contexts. It is implemented in PyTorch-based SDF rendering libraries such as Sphere-Tracing-PyTorch3D [S1, unofficial]. The technique generalizes the smooth union operator to the difference operation by negating the subtracted SDF before blending.
