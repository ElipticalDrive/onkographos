# Torus Signed Distance Function

Also called: Link SDF, Link Shape SDF, Signed Torus, sdTorus

## Overview
Computes the signed distance from a query point to the surface of a torus centered at the origin and aligned with the Y-axis [S2, unofficial]. It provides the primitive distance query required for distance-field ray marching and constructive solid geometry (CSG) operations [G]. It is distinguished from sibling primitives like the [Cylinder Signed Distance Function](2739-cylinder-signed-distance-function.md) by its closed-loop topology and from [Distance to Superquadrics](1561-distance-to-superquadrics.md) by its specific algebraic form for a torus [G].

## How it works
**Inputs:**
- $p = (p_x, p_y, p_z)$: Query point in 3D space.
- $R$: Major radius (distance from the torus center to the tube centerline).
- $r$: Minor radius (radius of the tube cross-section).

**Outputs:**
- $d$: Signed distance. Positive outside the torus, negative inside, zero on the surface [G].

**Data Structures:**
- None required; scalar computation.

**Steps:**
1. Compute the radial distance of the point's projection onto the XZ plane from the origin: $\rho = \sqrt{p_x^2 + p_z^2}$ [S2, unofficial].
2. Construct a 2D vector $q = (q_x, q_y)$ representing the offset from the torus centerline: $q_x = \rho - R$, $q_y = p_y$ [S2, unofficial].
3. Compute the Euclidean distance from $q$ to the origin and subtract the minor radius: $d = \sqrt{q_x^2 + q_y^2} - r$ [S2, unofficial].

**Formula:**
$$d = \sqrt{(\sqrt{p_x^2 + p_z^2} - R)^2 + p_y^2} - r$$

**Parameters:**
- $R > 0$: Major radius.
- $r > 0$: Minor radius.
- Constraint: $r < R$ yields a standard ring torus; $r = R$ yields a horn torus; $r > R$ yields a self-intersecting spindle torus [G].

**Edge Cases:**
- **Origin:** If $p=(0,0,0)$, $\rho=0$, $q=(-R, 0)$, $d = R - r$.
- **Precision:** Near the surface or when $\rho \approx R$, standard floating-point precision is sufficient [G].
- **Self-intersection:** For spindle tori ($r > R$), the SDF remains mathematically valid but defines a complex nested inside region [G].

**Pseudocode:**
```python
def sd_torus(p: tuple, R: float, r: float) -> float:
    """
    Computes signed distance to a torus centered at origin, aligned with Y-axis.
    p: (px, py, pz)
    R: Major radius
    r: Minor radius
    """
    px, py, pz = p
    # Radial distance in the XZ plane
    rho = (px**2 + pz**2)**0.5
    # 2D vector from the torus centerline to the point
    qx = rho - R
    qy = py
    # Signed distance: distance to centerline minus tube radius
    return (qx**2 + qy**2)**0.5 - r
```

## Subtopics

### Link Shape SDF
A variation that includes a length parameter for non-circular cross-sections or deformed tori, sometimes referred to as a link shape [S1, unofficial]. Use when modeling chain links or specific mechanical parts. [Link SDF](1560-link-sdf.md).

### Spindle Torus
A torus where $r > R$. The SDF formula remains the same, but the topology changes to a self-intersecting shape. Use for specific organic or abstract shapes. [Spindle Torus](1562-spindle-torus.md).

## Operating characteristics
- **Time Complexity:** $O(1)$. Requires two square roots and basic arithmetic [G].
- **Memory Complexity:** $O(1)$. No auxiliary data structures [G].
- **Strengths:** Exact analytic solution; no iterative approximation; robust for ray marching [G].
- **Limitations:** Only applies to perfect tori. Cannot model tori with varying cross-sections or twists without deformation [G].
- **When to use:** When rendering or ray marching perfect toroidal shapes [G].
- **When not to use:** For complex toroidal structures with varying thickness or non-circular cross-sections [G].

## Background
The SDF for a torus is a standard primitive in signed distance function libraries, popularized by tools like the glsl-sdf-primitives repository [S2, unofficial]. It is a fundamental building block for CSG operations involving toroidal shapes [G].
