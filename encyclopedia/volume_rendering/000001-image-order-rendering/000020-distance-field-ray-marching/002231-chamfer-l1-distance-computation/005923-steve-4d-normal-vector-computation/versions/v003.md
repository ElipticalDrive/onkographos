# STEVE 4D Normal Vector Computation

Also called: 4D Space-Time Normal Formulation, STEVE 4D Extension, STEVE 4D Normal Vector Computation & Subspace Orientation

## Overview
Computes the oriented normal vector of a 4D simplex defined by four space-time events, providing the geometric foundation for the 4D extension of the STEVE algorithm [S1, unofficial]. It handles the mixed spatial-temporal signature of Minkowski space to ensure consistent orientation for higher-dimensional polytope construction in relativistic heavy-ion collision simulations [S1, unofficial].

## How it works
**Inputs:** Four 4D events $x^\mu_1, x^\mu_2, x^\mu_3, x^\mu_4$, where each event is a tuple $(x, y, z, t)$ representing spatial coordinates and time [S1, unofficial].
**Outputs:** A covariant 4-normal vector $d\sigma_\mu$ and a contravariant 4-normal vector $d\sigma^\mu$ [S1, unofficial].

**Data Structures:**
The method operates on difference vectors derived from the input events [S1, unofficial]. Let the basis vectors be $\mathbf{e}_x, \mathbf{e}_y, \mathbf{e}_z, \mathbf{e}_t$ [S1, unofficial]. The contravariant event is defined as $x^\mu = x \mathbf{e}_x + y \mathbf{e}_y + z \mathbf{e}_z + t \mathbf{e}_t$ [S1, unofficial].

**Parameters:**
The metric tensor $g_{\mu\nu}$ is assumed diagonal: $g_{\mu\nu} = \text{diag}(g_{11}, g_{22}, g_{33}, g_{44})$ [S1, unofficial].
*   **Relativistic case:** $g_{\mu\nu} = \text{diag}(-1, -1, -1, +1)$ [S1, unofficial].
*   **Non-relativistic case:** $g_{\mu\nu} = \text{diag}(+1, +1, +1, +1)$ [S1, unofficial].

**Steps:**

1.  **Compute Edge Differences:**
    Calculate the differences between the second, third, and fourth events relative to the first event for each dimension [S1, unofficial]. Let indices $1, 2, 3, 4$ correspond to $x, y, z, t$ respectively [S1, unofficial].
    $$
    \begin{aligned}
    dx_1 &= x_2 - x_1, & dx_2 &= x_3 - x_1, & dx_3 &= x_4 - x_1 \\
    dy_1 &= y_2 - y_1, & dy_2 &= y_3 - y_1, & dy_3 &= y_4 - y_1 \\
    dz_1 &= z_2 - z_1, & dz_2 &= z_3 - z_1, & dz_3 &= z_4 - z_1 \\
    dt_1 &= t_2 - t_1, & dt_2 &= t_3 - t_1, & dt_3 &= t_4 - t_1
    \end{aligned}
    $$
    Define the component mapping: $dx_m^1 = dx_m$, $dx_m^2 = dy_m$, $dx_m^3 = dz_m$, $dx_m^4 = dt_m$ for $m \in \{1, 2, 3\}$ [S1, unofficial].

2.  **Compute 3D Determinants of Differences:**
    Calculate the determinant $dS^{ikl}$ for all unique combinations of indices $i, k, l \in \{1, 2, 3, 4\}$ [S1, unofficial].
    $$dS^{ikl} = \det \begin{pmatrix} dx_1^i & dx_2^i & dx_3^i \\ dx_1^k & dx_2^k & dx_3^k \\ dx_1^l & dx_2^l & dx_3^l \end{pmatrix}$$
    This determinant represents the signed volume of the parallelepiped spanned by the difference vectors restricted to the subspace defined by indices $i, k, l$ [S1, unofficial].

3.  **Compute Contravariant 4-Normal:**
    The contravariant normal $d\sigma^\mu$ is computed by scaling the determinants with the inverse metric components [S1, unofficial].
    $$d\sigma^\mu = \frac{1}{6} \left( \frac{dS^{234}}{g_{11}}, \frac{dS^{143}}{g_{22}}, \frac{dS^{124}}{g_{33}}, \frac{dS^{132}}{g_{44}} \right)$$
    The $\mu$-th component uses the determinant of the subspace excluding $\mu$ [S1, unofficial].

4.  **Compute Covariant 4-Normal:**
    The covariant normal $d\sigma_\mu$ is obtained by lowering the index with the metric tensor $g_{\mu\nu}$ [S1, unofficial].
    $$d\sigma_\mu = g_{\mu\nu} d\sigma^\nu = \frac{1}{6} (dS^{234}, dS^{143}, dS^{124}, dS^{132})$$
    The source notation $dS^{2344}$ etc. denotes the metric-contracted component, but the diagonal metric factors cancel exactly with the contravariant scaling, making the covariant form independent of the 4D metric choice [S1, unofficial].

5.  **Subspace Orientation (for VESTA N-cycles):**
    When applying the marching variant of VESTA to the eight 3D bounding subspaces of a 4D cell (tesseract), inverse orientations must be chosen for the generated VESTA N-cycles in the $x_0$, $y_1$, $z_0$, and $t_1$ subspaces [S1, unofficial]. This ensures consistent, orientation-preserving construction of higher-dimensional polytopes [S1, unofficial].

**Pseudocode:**

```python
def steve_4d_normal(x1, x2, x3, x4, metric_diag):
    """
    Computes the covariant and contravariant 4-normal vectors for a 4D simplex.
    
    Args:
        x1, x2, x3, x4: Tuples (x, y, z, t) representing the 4 events.
        metric_diag: List/Tuple of 4 floats [g11, g22, g33, g44].
        
    Returns:
        covariant_normal: Tuple (d_sigma_1, d_sigma_2, d_sigma_3, d_sigma_4)
        contravariant_normal: Tuple (d_sigma^1, d_sigma^2, d_sigma^3, d_sigma^4)
    """
    # Step 1: Compute differences relative to event 1
    # diffs[m][i] stores the i-th component of the m-th edge vector
    # i=0:x, 1:y, 2:z, 3:t
    diffs = [[0]*4 for _ in range(3)]
    for m in range(3):
        e_curr = [x1, x2, x3, x4][m+1]
        e_ref = x1
        for i in range(4):
            diffs[m][i] = e_curr[i] - e_ref[i]
    
    # Step 2: Compute required 3x3 determinants
    def det3(v1, v2, v3):
        return (v1[0] * (v2[1]*v3[2] - v2[2]*v3[1]) -
                v1[1] * (v2[0]*v3[2] - v2[2]*v3[0]) +
                v1[2] * (v2[0]*v3[1] - v2[1]*v3[0]))
    
    # Extract columns for indices 0,1,2,3 (x,y,z,t)
    col = [[diffs[m][i] for m in range(3)] for i in range(4)]
    
    # Compute specific determinants per source formula
    dS_234 = det3(col[1], col[2], col[3]) # y, z, t
    dS_143 = det3(col[0], col[3], col[2]) # x, t, z
    dS_124 = det3(col[0], col[1], col[3]) # x, y, t
    dS_132 = det3(col[0], col[2], col[1]) # x, z, y
    
    g11, g22, g33, g44 = metric_diag
    
    # Step 3: Contravariant Normal
    d_sigma_contravariant = (
        dS_234 / g11,
        dS_143 / g22,
        dS_124 / g33,
        dS_132 / g44
    )
    
    # Step 4: Covariant Normal (metric factors cancel)
    d_sigma_covariant = (
        dS_234,
        dS_143,
        dS_124,
        dS_132
    )
    
    # Scale by 1/6
    d_sigma_contravariant = tuple(c / 6.0 for c in d_sigma_contravariant)
    d_sigma_covariant = tuple(c / 6.0 for c in d_sigma_covariant)
    
    return d_sigma_covariant, d_sigma_contravariant
```

**Edge Cases and Pitfalls:**
*   **Isochronous Hypersurface:** If $dt_1=dt_2=dt_3=0$ (all events lie on the same time slice), the covariant normal simplifies to $d\sigma_\mu = \frac{1}{6} (0, 0, 0, dS^{132})$ [S1, unofficial]. Here $dS^{132}$ equals the negative volume of the parallelepiped spanned by the spatial difference vectors [S1, unofficial].
*   **Metric Dependence:** In the non-relativistic limit ($g_{\mu\nu} = \text{diag}(+1, +1, +1, +1)$), the covariant and contravariant normals are identical ($d\sigma_\mu \equiv d\sigma^\mu$) [S1, unofficial]. In the relativistic case, they differ due to metric scaling [S1, unofficial].
*   **Orientation Consistency:** The choice of edge differences ($x_2-x_1$, etc.) and the specific determinant permutations are critical for the $\oplus/\ominus$ naming convention and consistent orientation in 4D [S1, unofficial].

## Background
The method originates from the STEVE (Space-Time-Enclosing Volume Extraction) algorithm, specifically its extension to 4D space-time for relativistic applications [S1, unofficial]. It was developed by B. R. Schlei at GSI Helmholtzzentrum für Schwerionenforschung [S1, unofficial]. The work builds upon lower-dimensional (2D, 3D) contour vector orientation principles, extending them to 4D using geometric algebra and multilinear basis concepts [S1, unofficial]. It is used in the context of relativistic heavy-ion collision simulations to extract 4D volumes from event data [S1, unofficial].
