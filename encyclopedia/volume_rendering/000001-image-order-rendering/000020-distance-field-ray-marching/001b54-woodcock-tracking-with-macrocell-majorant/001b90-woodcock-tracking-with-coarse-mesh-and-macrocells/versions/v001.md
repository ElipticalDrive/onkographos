# Woodcock Tracking with Coarse Mesh and Macrocells

Also called: Null-collision Woodcock with macrocell majorant, Woodcock ray casting on AMR

## Overview
This method performs volume rendering using Woodcock tracking (null-collision) within coarse mesh elements, utilizing macrocell densities to determine the majorant extinction value [S1, unofficial]. It builds on [Woodcock Tracking with Macrocell Majorant](986-woodcock-tracking-with-macrocell-majorant.md) by integrating the traversal of a coarse mesh structure to manage the underlying adaptive mesh refinement (AMR) data [S1, unofficial]. Using macrocell majorant values provides a tighter majorant than using only transfer function opacity, reducing null collisions and improving performance [S1, unofficial].

## How it works
**Inputs:** Ray origin, ray direction, maximum ray length ($t_{max}$), coarse mesh structure, macrocell density values, transfer function (TF), and scalar field data.
**Outputs:** Final pixel color.

**Data Structures:**
*   **Coarse Mesh:** A hierarchy of coarse tetrahedra. Each coarse element has an associated `macrocellMajorant` value.
*   **Macrocell Values:** An array or map where `macrocellValues[coarseID]` stores the maximum macrocell density for that coarse element.
*   **Transfer Function:** Provides `tf.opacity` (scalar to opacity mapping) and `tf.getColor(scalar)` (scalar to RGBA color).
*   **Refinement Tree:** Used to locate the specific fine tetrahedron within a coarse element.

**Algorithm Steps:**

1.  **Coarse Element Traversal:**
    Call `TraverseCoarseMesh(ray)` to determine the current coarse element ID (`coarseID`), the back face distance (`tBack`), and the next face distance (`tNextFace`) [S1, unofficial].
    *   If `coarseID` is -1, the ray has exited the volume. Return the background color [S1, unofficial].

2.  **Majorant Calculation:**
    Retrieve the macrocell majorant: `macrocellMajorant = macrocellValues[coarseID]` [S1, unofficial].
    Call `WoodcockElem` with this majorant [S1, unofficial].
    *   Inside `WoodcockElem`, calculate the effective majorant:
        $$ \sigma_{max} = \text{tf.opacity} \times \text{macrocellMajorant} $$
    *   If $\sigma_{max} \le 0$, return `false` (no emission/absorption possible) [S1, unofficial].

3.  **Free Path Sampling:**
    Sample a free path length using the majorant $\sigma_{max}$:
    $$ t_{step} = -\frac{\log(1 - \text{rand}())}{\sigma_{max}} $$
    Update the ray position:
    $$ t_{ray} = t_{ray} + t_{step} $$
    *   If $t_{ray} \ge t_{max}$, return `false` [S1, unofficial].

4.  **Tetrahedron Location:**
    Calculate the sample point:
    $$ P = \text{ray.org} + t_{ray} \times \text{ray.dir} $$
    If the sample point is outside the current tetrahedron (checked against `tExit`), traverse the refinement tree to find the specific fine tetrahedron (`sampleTetID`) and its vertices (`tetVertices`) [S1, unofficial].
    *   Update `tExit` to the distance to the exit face of the new tetrahedron [S1, unofficial].

5.  **Scalar Sampling and Acceptance:**
    Sample the scalar value at $P$ using `sampleTetID` and `tetVertices` [S1, unofficial].
    *   If the scalar is not in the transfer function range, continue the loop (null collision) [S1, unofficial].
    *   Get the color: `color = tf.getColor(scalar)` [S1, unofficial].
    *   Perform the null-collision acceptance test:
        $$ \text{color.opacity} \times \text{tf.opacity} \ge \text{rand}() \times \sigma_{max} $$
    *   If accepted, return `color` [S1, unofficial].
    *   Otherwise, treat as a null collision and continue the loop [S1, unofficial].

6.  **Boundary Handling:**
    When stepping over to the next coarse element, if the previous volume was less dense, the free path might overstep the boundary [S1, unofficial]. To fix this, set `ray.t` to just after the next coarse element's minimum $t$ value in front of the ray, effectively taking a step back to the beginning of the next coarse element [S1, unofficial]. This step is not needed if macrocell majorant values are not used [S1, unofficial].

**Pseudocode:**

def woodcock_coarse(ray, macrocell_values, tf, t_max):
    """
    Main loop for Woodcock tracking on coarse mesh.
    ray: object with .org, .dir, .t (current t)
    macrocell_values: dict mapping coarse_id to max macrocell density
    tf: transfer function object with .opacity(scalar), .get_color(scalar), .in_range(scalar)
    t_max: maximum ray length
    """
    while True:
        # 1. Traverse coarse mesh
        coarse_id, t_back, t_next_face = traverse_coarse_mesh(ray)
        
        if coarse_id == -1:
            return background_color
        
        # 2. Get macrocell majorant
        macrocell_majorant = macrocell_values[coarse_id]
        
        # 3. Process element
        color = woodcock_elem(ray, t_back, coarse_id, macrocell_majorant, tf, t_max)
        
        if color is not None:
            return color
        
        # 4. Handle boundary crossing
        # If we exited the element, reset t to just after the next face to prevent overstepping
        # due to density changes between elements
        ray.t = t_next_face + epsilon

    # No, line 24 uses color.opacity * tf.opacity.

    sigma_max = tf.opacity * macrocell_majorant
    
    if sigma_max <= 0:
        return None
    
    # Initialize tetrahedron info
    sample_tet_id = 0
    tet_vertices = []
    
    while True:
        # Sample free path
        ray.t = ray.t - log(1 - rand()) / sigma_max
        
        if ray.t >= t_max:
            return None
        
        sample_point = ray.org + ray.t * ray.dir
        
        # Check if we are still in the current tetrahedron
        if ray.t > t_exit:

            sample_tet_id, tet_vertices = traverse_refinement_tree(sample_point, coarse_tet_id)

## Operating characteristics
*   **Performance:** Using macrocell majorant values reduces null collisions compared to using only transfer function opacity, leading to better performance [S1, unofficial].
*   **Complexity:** The complexity depends on the coarse mesh traversal and the refinement tree depth. The method allows for interactive frame rates on tested datasets [S1, unofficial].
*   **Memory:** Requires storing coarse mesh structures, macrocell values, and the refinement tree. The transfer function and scalars reside in GPU memory [S1, unofficial].
*   **Limitations:** Only emission and absorption are implemented; secondary effects are not supported [S1, unofficial].

## Background
This method is part of a volume rendering system for tree-based tetrahedral adaptive mesh refinement (AMR) data [S1, unofficial]. It was implemented alongside a ray marching method [S1, unofficial]. The approach leverages the fact that transfer functions and scalars reside in GPU memory, allowing recalculation during rendering [S1, unofficial].
