# Menger Sponge Raymarching

Also called: Menger Journey, Menger Tower, Menger sponge

## Overview
Menger Sponge Raymarching is a procedural distance-field technique that renders the Menger sponge fractal by iteratively applying a recursive modulo-based signed distance function (SDF) [S1, unofficial]. It distinguishes itself from general fractal raymarching by using a specific iterative construction that efficiently approximates the infinite-detail sponge geometry within a bounded volume, combined with a floor plane for grounding [S1, unofficial].

## How it works
**Inputs and Outputs:**
*   **Inputs:** Camera position `prp`, view reference point `vrp`, up vector `vuv`, screen resolution `resolution`, and pixel coordinates [S1, unofficial].
*   **Outputs:** Fragment color `gl_FragColor` [S1, unofficial].

**Data Structures:**
*   `vec2` return type for SDF functions: `.x` stores the signed distance, `.y` stores the material ID (0 for floor, 1 for sponge) [S1, unofficial].
*   `vec3` for positions and vectors.
*   `float` for scalar values.

**Numbered Steps:**
1.  **Camera Setup:** Calculate view direction `vpn = normalize(vrp - prp)` [S1, unofficial]. Calculate basis vectors `u = normalize(cross(vuv, vpn))` and `v = cross(vpn, u)` [S1, unofficial]. Calculate screen coordinate `scrCoord = vcv + vPos.x * u * aspect + vPos.y * v`, where `vcv = prp + vpn` and `aspect = resolution.x / resolution.y` [S1, unofficial]. Ray direction `scp = normalize(scrCoord - prp)` [S1, unofficial].
2.  **Raymarching Loop:** Initialize `f = 0.0` (accumulated distance) and `d = vec2(0.02, 0.0)` (current distance and material) [S1, unofficial]. Loop up to 256 times: if `abs(d.x) < 0.001` or `f > 100.0`, break [S1, unofficial]. Advance `f += d.x` [S1, unofficial]. Compute point `p = prp + scp * f` [S1, unofficial]. Evaluate `d = distance_to_obj(p)` [S1, unofficial].
3.  **SDF Evaluation (`distance_to_obj`):** Compute `floor_dist = obj_floor(p)` [S1, unofficial]. Compute `sponge_dist = obj_menger(p)` [S1, unofficial]. Return `obj_union(floor_dist, sponge_dist)` [S1, unofficial].
4.  **Menger SDF (`obj_menger`):** Initialize `d2 = obj_box(p)` and `s = 1.0` [S1, unofficial]. Loop `m` from 0 to 2 (3 iterations): `a = mod(p * s, 2.0) - 1.0` [S1, unofficial]. `s *= 3.0` [S1, unofficial]. `r = 1.0 - 4.0 * abs(a)` [S1, unofficial]. `c = obj_cross(r) / s` [S1, unofficial]. `d2.x = max(d2.x, c.x)` [S1, unofficial]. Return `vec2(d2.x, 1.0)` [S1, unofficial].
5.  **Cross SDF (`obj_cross`):** Define `inf = 100.0` [S1, unofficial]. `da = obj_box_s(p, vec3(inf, 2.0, 2.0))` [S1, unofficial]. `db = obj_box_s(p.yzx, vec3(2.0, inf, 2.0))` [S1, unofficial]. `dc = obj_box_s(p.zxy, vec3(2.0, 2.0, inf))` [S1, unofficial]. Return `vec2(min(da.x, min(db.x, dc.x)), 1.0)` [S1, unofficial].
6.  **Box SDF (`obj_box_s`):** `di = abs(p) - b` [S1, unofficial]. `mc = max(di.x, max(di.y, di.z))` [S1, unofficial]. `d = min(mc, length(max(di, 0.0)))` [S1, unofficial]. Return `vec2(d, 1.0)` [S1, unofficial].
7.  **Floor SDF (`obj_floor`):** Return `vec2(p.y + 10.0, 0.0)` [S1, unofficial].
8.  **Union (`obj_union`):** If `obj0.x < obj1.x`, return `obj0`, else return `obj1` [S1, unofficial].
9.  **Shading:** If hit (`f < maxd`): compute normal `n` using central differences with `e = vec3(0.02, 0, 0)` [S1, unofficial]. `b = dot(n, normalize(prp - p))` [S1, unofficial]. Color `c` is `floor_color(p)` if material ID is 0, else `prim_c(p)` [S1, unofficial]. Final color: `(b * c + pow(b, 60.0)) * (1.0 - f * 0.01)` [S1, unofficial].

**Formulas:**
*   Box SDF: $d = \min(mc, \text{length}(\max(di, 0.0)))$ where $di = |p| - b$ and $mc = \max(di.x, \max(di.y, di.z))$ [S1, unofficial].
*   Menger iteration: $a = \text{mod}(p \cdot s, 2.0) - 1.0$, $r = 1.0 - 4.0|a|$, $c = \text{obj\_cross}(r)/s$, $d.x = \max(d.x, c.x)$, with $s$ scaling by 3.0 each iteration [S1, unofficial].
*   Normal approximation: $n = \text{normalize}([d.x - \text{SDF}(p - e_x).x, d.x - \text{SDF}(p - e_y).x, d.x - \text{SDF}(p - e_z).x])$ where $e = (0.02, 0, 0)$ [S1, unofficial].

**Parameters:**
*   `maxd`: Maximum ray march depth, typically `100.0` [S1, unofficial].
*   `epsilon` (`e`): Step size for normal calculation, typically `vec3(0.02, 0, 0)` [S1, unofficial].
*   `box_size` (`b`): Base box dimensions, typically `vec3(4.0, 4.0, 4.0)` [S1, unofficial].
*   `iterations`: Number of Menger iterations, typically `3` [S1, unofficial].
*   `min_dist`: Hit threshold, typically `0.001` [S1, unofficial].

**Edge Cases and Pitfalls:**
*   NVIDIA OpenGL drivers may crash with 'lost connection' messages on Windows with certain hardware (e.g., GeForce GTX 660, driver R334.67) [S1, unofficial].
*   AMD hardware (e.g., Radeon R7) has been tested without issues [S1, unofficial].

**Pseudocode:**
```python
import math

def maxcomp(p):
    return max(p[0], max(p[1], p[2]))

def obj_box_s(p, b):
    di = [abs(p[i]) - b[i] for i in range(3)]
    mc = maxcomp(di)
    d = min(mc, math.sqrt(sum(max(d, 0.0)**2 for d in di)))
    return (d, 1.0)

def obj_box(p):
    b = [4.0, 4.0, 4.0]
    return obj_box_s(p, b)

def obj_cross(p):
    inf = 100.0
    da = obj_box_s(p, [inf, 2.0, 2.0])
    db = obj_box_s([p[1], p[2], p[0]], [2.0, inf, 2.0])
    dc = obj_box_s([p[2], p[0], p[1]], [2.0, 2.0, inf])
    min_dist = min(da[0], min(db[0], dc[0]))
    return (min_dist, 1.0)

def obj_menger(p):
    d2 = obj_box(p)
    s = 1.0
    for _ in range(3):
        a = [(p[i] * s) % 2.0 - 1.0 for i in range(3)]
        s *= 3.0
        r = [1.0 - 4.0 * abs(a[i]) for i in range(3)]
        c_dist, _ = obj_cross(r)
        d2 = (max(d2[0], c_dist / s), 1.0)
    return d2

def obj_floor(p):
    return (p[1] + 10.0, 0.0)

def obj_union(obj0, obj1):
    if obj0[0] < obj1[0]:
        return obj0
    else:
        return obj1

def distance_to_obj(p):
    return obj_union(obj_floor(p), obj_menger(p))

def compute_normal(p, eps=0.02):
    d = distance_to_obj(p)[0]
    dx = d - distance_to_obj([p[0]-eps, p[1], p[2]])[0]
    dy = d - distance_to_obj([p[0], p[1]-eps, p[2]])[0]
    dz = d - distance_to_obj([p[0], p[1], p[2]-eps])[0]
    return normalize([dx, dy, dz])

def normalize(v):
    l = math.sqrt(v[0]**2 + v[1]**2 + v[2]**2)
    return [v[0]/l, v[1]/l, v[2]/l]

def raymarch(prp, scp, maxd=100.0):
    f = 0.0
    d = (0.02, 0.0)
    for _ in range(256):
        if abs(d[0]) < 0.001 or f > maxd:
            break
        f += d[0]
        p = [prp[i] + scp[i] * f for i in range(3)]
        d = distance_to_obj(p)
    return f, d
```

## Operating characteristics
*   **Time Complexity:** Linear with respect to the number of raymarching steps and the number of Menger iterations (constant 3 in the reference implementation) [S1, unofficial]. Each step involves a constant number of arithmetic operations [S1, unofficial].
*   **Memory Complexity:** Constant, $O(1)$, as no scene data structures are stored [S1, unofficial].
*   **Performance:** The iterative modulo operations are computationally inexpensive but can cause driver instability on certain NVIDIA hardware (e.g., GeForce GTX 660 with driver R334.67) under Windows, leading to "lost connection" errors [S1, unofficial]. AMD hardware (e.g., Radeon R7) has been tested without issues [S1, unofficial].
*   **Strengths:** Efficiently renders complex fractal geometry without explicit mesh data [S1, unofficial].
*   **Limitations:** Fixed iteration count limits detail depth [S1, unofficial]. Driver compatibility issues on specific NVIDIA hardware [S1, unofficial].

The technique was implemented in GLSL by Geeks3D in a 2014 code sample update [S1, unofficial]. It is used in real-time raymarching demos and shader art [S1, unofficial].

## Subtopics

### Menger Sponge Variations
*   **What it is:** Alternative implementations of the Menger SDF, such as `obj_menger_simple`, which uses a single iteration of the cross operation instead of the full loop [S1, unofficial].
*   **Difference:** Simpler but less detailed than the full iterative version [S1, unofficial].
*   **When to choose:** For simpler fractal-like structures or performance-critical applications where full detail is not required [S1, unofficial].
*   **Link:** [Menger Sponge Raymarching](52-menger-sponge-raymarching.md)

### Floor Plane Integration
*   **What it is:** The addition of a simple plane SDF (`obj_floor`) to the scene to provide a ground for the Menger sponge [S1, unofficial].
*   **Difference:** Adds context and lighting reference to the floating fractal [S1, unofficial].
*   **When to choose:** When a grounded scene is desired [S1, unofficial].
*   **Link:** [Menger Sponge Raymarching](52-menger-sponge-raymarching.md)
