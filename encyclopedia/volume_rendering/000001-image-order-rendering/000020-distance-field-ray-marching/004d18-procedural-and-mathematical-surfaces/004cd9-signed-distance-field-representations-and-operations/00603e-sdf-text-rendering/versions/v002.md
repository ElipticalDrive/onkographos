# SDF Text Rendering

Also called: TMP_SDF-Mobile Overlay

## Overview
SDF Text Rendering renders text by sampling a pre-computed font atlas in screen space [S1, unofficial]. It solves the problem of rendering crisp, scalable text with outlines and gradients on constrained hardware by omitting complex 3D effects like bevels, bump mapping, and environment mapping found in full desktop SDF shaders [S1, unofficial].

## How it works
**Inputs and Outputs:**
*   **Input:** A 2D font atlas texture (`_MainTex`) containing the SDF values in the alpha channel, vertex positions, UV coordinates, and UI parameters (scale, bias, outline width, colors) [S1, unofficial].
*   **Output:** A final color `half4 c` for each pixel, including face color, outline color, and alpha [S1, unofficial].

**Data Structures:**
The vertex shader outputs a `pixel_t` struct with the following layout [S1, unofficial]:
*   `vertex`: `SV_POSITION` (Clip space position).
*   `faceColor`: `COLOR` (RGBA).
*   `outlineColor`: `COLOR1` (RGBA).
*   `texcoord0`: `TEXCOORD0` (Texture UV for atlas sampling; Mask UV for clipping).
*   `param`: `TEXCOORD1` (Packed half4: `x` = Scale, `y` = BiasIn, `z` = BiasOut, `w` = BiasFace).
*   `mask`: `TEXCOORD2` (Position in clip space `xy`; Softness factors `zw`).

**Parameters:**
*   `_GradientScale` (float, default 5): Scales the distance field gradient for the font atlas [S1, unofficial].
*   `_WeightNormal` (float, default 0): Base weight value for normal text style [S1, unofficial].
*   `_WeightBold` (float, default 0.5): Base weight value for bold text style [S1, unofficial].
*   `_FaceDilate` (Range -1 to 1, default 0): Dilates the face color region [S1, unofficial].
*   `_OutlineWidth` (Range 0 to 1, default 0): Thickness of the outline [S1, unofficial].
*   `_OutlineSoftness` (Range 0 to 1, default 0): Softness applied to both sides of the outline [S1, unofficial].
*   `_PerspectiveFilter` (Range 0 to 1, default 0.875): Factor for perspective correction of the distance field scale [S1, unofficial].
*   `_Sharpness` (Range -1 to 1, default 0): Adjusts the sharpness of the distance field sampling [S1, unofficial].
*   `_ClipRect` (vector, default -32767,-32767,32767,32767): Clipping rectangle for UI masking [S1, unofficial].
*   `_MaskSoftnessX/Y` (float, default 0): Softness factors for the clipping mask [S1, unofficial].

**Steps:**

1.  **Compute Pixel Size:** Calculate the pixel size in world space from the clip position and projection matrix [S1, unofficial].
    $$ \text{pixelSize} = \frac{vPosition.w}{\begin{bmatrix} \text{ScaleX} \\ \text{ScaleY} \end{bmatrix} \cdot \left| \begin{bmatrix} P_{00} & P_{01} \\ P_{10} & P_{11} \end{bmatrix} \cdot \begin{bmatrix} \text{ScreenParams}_x \\ \text{ScreenParams}_y \end{bmatrix} \right|} $$
    Where $P$ is the projection matrix `UNITY_MATRIX_P` and `ScreenParams` is the screen resolution [S1, unofficial].

2.  **Compute Base Scale:** Derive the base scale factor from the pixel size [S1, unofficial].
    $$ scale = \frac{1}{\sqrt{\text{pixelSize}_x^2 + \text{pixelSize}_y^2}} $$
    [S1, unofficial]

3.  **Apply Perspective Filter:** If the projection is orthographic (`UNITY_MATRIX_P[3][3] == 0`), lerp between the absolute scale and a view-direction dependent scale using `_PerspectiveFilter` to prevent distortion [S1, unofficial]. Otherwise, use the computed scale directly [G].

4.  **Compute Weight and Dilate:** Calculate the text weight based on normal/bold states and apply face dilation [S1, unofficial].
    $$ weight = \frac{\text{lerp}(\_WeightNormal, \_WeightBold, bold)}{4.0} $$
    $$ weight = (weight + \_FaceDilate) \cdot \_ScaleRatioA \cdot 0.5 $$
    [S1, unofficial]

5.  **Compute Bias and Outline:** Determine the bias values for the face and outline regions, adjusting for softness [S1, unofficial].
    $$ scale = \frac{scale}{1 + (\_OutlineSoftness \cdot \_ScaleRatioA \cdot scale)} $$
    $$ bias = (0.5 - weight) \cdot scale - 0.5 $$
    $$ outline = \_OutlineWidth \cdot \_ScaleRatioA \cdot 0.5 \cdot scale $$
    [S1, unofficial]

6.  **Pack Parameters:** Pack the computed values into the `param` output for the fragment shader [S1, unofficial].
    $$ param.x = scale $$
    $$ param.y = bias - outline $$
    $$ param.z = bias + outline $$
    $$ param.w = bias $$
    [S1, unofficial]

7.  **Sample Distance Field:** In the fragment shader, sample the alpha channel of the font atlas [S1, unofficial].
    $$ d = \text{tex2D}(\_MainTex, input.texcoord0.xy).a \cdot input.param.x $$
    [S1, unofficial]

8.  **Compute Face Color:** Determine the face color based on the distance value and the face bias [S1, unofficial].
    $$ c = input.faceColor \cdot \text{saturate}(d - input.param.w) $$
    [S1, unofficial]

9.  **Apply Outline:** Blend between the outline color and face color based on the distance relative to the outline bias, then multiply by the inner bias [S1, unofficial].
    $$ c = \text{lerp}(input.faceColor, input.outlineColor, \text{saturate}(d - input.param.z)) \cdot \text{saturate}(d - input.param.y) $$
    [S1, unofficial]

10. **Apply Clipping Mask:** Softly clip the text using the `_ClipRect` and mask softness [S1, unofficial].
    $$ m = \text{saturate}((\_ClipRect.zw - \_ClipRect.xy - |input.mask.xy|) \cdot input.mask.zw) $$
    $$ c *= m.x \cdot m.y $$
    [S1, unofficial]

**Pseudocode:**

```python
def lerp(a, b, t):
    return a + (b - a) * t

def saturate(x):
    return max(0.0, min(1.0, x))

def abs_val(x):
    return x if x >= 0 else -x

def sqrt_val(x):
    return x ** 0.5

def vec2(x, y):
    return (x, y)

def mat2x2_mul_vec2(M, v):
    return (M[0][0] * v[0] + M[0][1] * v[1], M[1][0] * v[0] + M[1][1] * v[1])

def sdf_text_rendering(v_position_w, scale_xy, screen_params, projection_matrix,
                       weight_normal, weight_bold, bold, face_dilate, scale_ratio_a,
                       outline_width, outline_softness, perspective_filter,
                       main_tex_alpha, face_color, outline_color,
                       clip_rect, mask_xy, mask_zw):
    # Step 1: Compute Pixel Size
    p_matrix_2x2 = (
        (projection_matrix[0][0], projection_matrix[0][1]),
        (projection_matrix[1][0], projection_matrix[1][1])
    )
    screen_vec = vec2(screen_params[0], screen_params[1])
    abs_proj_scale = vec2(abs_val(mat2x2_mul_vec2(p_matrix_2x2, screen_vec)[0]),
                          abs_val(mat2x2_mul_vec2(p_matrix_2x2, screen_vec)[1]))
    scale_vec = vec2(scale_xy[0], scale_xy[1])
    denominator = vec2(scale_vec[0] * abs_proj_scale[0], scale_vec[1] * abs_proj_scale[1])
    pixel_size = vec2(v_position_w / denominator[0], v_position_w / denominator[1])

    # Step 2: Compute Base Scale
    scale = 1.0 / sqrt_val(pixel_size[0]**2 + pixel_size[1]**2)

    # Step 3: Apply Perspective Filter
    if projection_matrix[3][3] == 0:
        view_dir_scale = scale
        scale = lerp(scale, view_dir_scale, perspective_filter)

    # Step 4: Compute Weight and Dilate
    weight = lerp(weight_normal, weight_bold, bold) / 4.0
    weight = (weight + face_dilate) * scale_ratio_a * 0.5

    # Step 5: Compute Bias and Outline
    scale = scale / (1.0 + (outline_softness * scale_ratio_a * scale))
    bias = (0.5 - weight) * scale - 0.5
    outline = outline_width * scale_ratio_a * 0.5 * scale

    # Step 6: Pack Parameters
    param_scale = scale
    param_bias_in = bias - outline
    param_bias_out = bias + outline
    param_bias_face = bias

    # Step 7: Sample Distance Field
    d = main_tex_alpha * param_scale

    # Step 8: Compute Face Color
    c = face_color * saturate(d - param_bias_face)

    # Step 9: Apply Outline
    c = lerp(face_color, outline_color, saturate(d - param_bias_out)) * saturate(d - param_bias_in)

    # Step 10: Apply Clipping Mask
    m_x = saturate((clip_rect[2] - clip_rect[0] - abs_val(mask_xy[0])) * mask_zw[0])
    m_y = saturate((clip_rect[3] - clip_rect[1] - abs_val(mask_xy[1])) * mask_zw[1])
    c = c * m_x * m_y

    return c
```

## Subtopics

### [True Raymarched Text Reveal](18132-true-raymarched-text-reveal.md)
True Raymarched Text Reveal is a technique that renders text animations by converting DOM glyphs into a 3D Signed Distance Field (SDF), marching rays through it, and revealing the text using smooth-min metaballs and SDF-gradient lighting. It differs from its sibling [RayMarchedHeading](18123-sdf-text-rendering.md) by performing actual 3D raymarching through an extruded SDF rather than marching 2D blur taps along a smear line.

## Operating characteristics
*   **Time Complexity:** O(1) per pixel, as it involves a single texture sample and arithmetic operations [S1, unofficial].
*   **Memory Complexity:** O(1) per pixel for the shader state; O(N) for the font atlas texture where N is the number of characters [S1, unofficial].
*   **Measured Performance:** Optimized for mobile devices by omitting bevel, bump, environment mapping, and glow options [S1, unofficial].
*   **Strengths:** High performance, crisp text at any scale, supports outlines and gradients [S1, unofficial].
*   **Limitations:** Limited to 2D rendering; no true 3D depth effects like bevels or lighting interactions with 3D geometry [S1, unofficial].
*   **When to use:** UI text rendering on mobile or low-power devices where performance is critical [S1, unofficial].
*   **When not to use:** When 3D text effects, bevels, or integration with 3D lighting are required [S1, unofficial].

## Background
The technique leverages the properties of Signed Distance Fields to render text efficiently on GPUs [S1, unofficial]. It is widely used in mobile game UIs and applications requiring scalable, high-quality text [S1, unofficial].
