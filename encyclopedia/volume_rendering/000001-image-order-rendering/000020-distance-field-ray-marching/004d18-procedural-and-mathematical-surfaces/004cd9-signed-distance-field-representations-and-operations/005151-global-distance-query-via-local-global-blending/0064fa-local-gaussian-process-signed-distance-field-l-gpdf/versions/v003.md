# Local Gaussian Process Signed Distance Field (L-GPDF)
Also called: L-GPDF
## Overview
The Local Gaussian Process Signed Distance Field (L-GPDF) is a temporary, patch-based representation used within the VDB-GPDF framework to enable fast, probabilistic queries of Euclidean distance and surface properties for arbitrary points in large-scale environments [S1]. It solves the computational bottleneck of global Gaussian Process (GP) regression by maintaining a local GP model for each leaf node of a VDB structure, allowing direct querying of distance with uncertainty without the post-processing required by TSDF or occupancy fusion frameworks [S1]. It sets itself apart from its parent method by providing the specific local inference engine that feeds into the global blending process, focusing on incremental, frame-by-frame updates of local surface geometry [S1].

## How it works
**Inputs and Outputs:**
The method takes a set of voxels $P_{v\{i\}}$ from the current sensor frame $i$, organized into leaf nodes of a VDB structure, as input [S1]. It outputs a temporary L-GPDF consisting of a collection of independent Gaussian Processes, one per leaf node, capable of querying distance, surface properties, and variance at any test point [S1].

**Data Structures:**
A VDB Leaf Node is a container holding a subset of voxels $P_{v\{i\}}$ [S1]. The VDB structure ensures efficient access and automatically divides voxels into these leaf nodes [S1]. A Local GP Model is formulated for each leaf node separately using the voxels in that node as training points [S1].

**Steps:**
1. Voxelization and Leaf Division: The input voxel set $P_{v\{i\}}$ is voxelized and automatically divided into leaf nodes by the VDB structure [S1].
2. Local GP Formulation: Iterate through each leaf node of the local VDB and treat the voxels within the current leaf node as training points to formulate a separate Gaussian Process for that node [S1].
3. Distance Field Inference: For a test point $x^*$, compute the distance field inference and variance using the GP regression equations (referred to as Eq. 3 and Eq. 4 in the source) [S1].
4. Surface Properties Inference: Model the surface properties inference for the test point $x^*$ using the following formula [S1]:
   $$ \hat{\mathbf{c}}_t(x^*) = (k_{x^*} X K_{XX} + \sigma_c^2 I)^{-1} \mathbf{c} $$
   Where $\hat{\mathbf{c}}_t(x^*)$ is the predicted surface property at $x^*$ [S1], $k_{x^*}$ is the kernel vector between the test point and training points [S1], $K_{XX}$ is the kernel matrix of training points [S1], $\sigma_c^2$ is the noise variance for surface properties [S1], $I$ is the identity matrix [S1], $\mathbf{c}$ is the vector of observed surface properties at training points [S1], and the notation $k_{x^*} X K_{XX}$ represents the kernel evaluation between the test point and the training data matrix as written in the source [S1].
5. Querying: The L-GPDF is ready to query distance, surface properties, and variance for any testing point [S1].
6. Re-modeling: The temporary and local L-GPDF is re-modeled at every frame $i$ to incorporate new sensor data [S1].

**Pseudocode:**
```python
import numpy as np

def update_l_gpdf(vdb_leaf_nodes, current_frame_voxels):
    """
    Updates the Local Gaussian Process Signed Distance Field (L-GPDF)
    for a given frame by re-modeling GPs for each leaf node.
    """
    l_gpdf = {}
    # Assign voxels to leaf nodes based on spatial coordinates [G]
    leaf_nodes_with_voxels = {leaf.id: [] for leaf in vdb_leaf_nodes}
    for voxel in current_frame_voxels:
        # VDB automatically divides voxels into leaf nodes [S1]
        leaf_id = int(voxel.position[0] // vdb_leaf_nodes[0].resolution)
        if leaf_id in leaf_nodes_with_voxels:
            leaf_nodes_with_voxels[leaf_id].append(voxel)

    for leaf_id, voxels in leaf_nodes_with_voxels.items():
        if not voxels:
            continue
        X_train = np.array([v.position for v in voxels])
        c_train = np.array([v.surface_properties for v in voxels])
        N = len(X_train)

        # Compute Kernel Matrix K_XX [G]
        # The kernel function is not specified in the sources [S1]
        K_XX = np.zeros((N, N))
        for i in range(N):
            for j in range(N):
                dist = np.linalg.norm(X_train[i] - X_train[j])
                # Placeholder kernel evaluation [G]
                K_XX[i, j] = np.exp(-dist**2 / 2.0)

        # Add noise to diagonal for stability [G]
        sigma_c = 1e-3 # Value not given in sources [S1]
        K_XX_noisy = K_XX + sigma_c**2 * np.eye(N)

        # Compute inverse of K_XX_noisy [G]
        try:
            K_inv = np.linalg.inv(K_XX_noisy)
        except np.linalg.LinAlgError:
            K_inv = np.linalg.pinv(K_XX_noisy)

        l_gpdf[leaf_id] = {
            'X_train': X_train,
            'c_train': c_train,
            'K_inv': K_inv,
            'sigma_c': sigma_c
        }
    return l_gpdf

def query_l_gpdf(l_gpdf, test_point):
    """
    Queries the L-GPDF for distance and surface properties at a test point.
    """
    # Find the leaf node containing or nearest to the test point [G]
    leaf_id = int(test_point[0] // 1.0)
    if leaf_id not in l_gpdf:
        return None, None, None

    gp_model = l_gpdf[leaf_id]
    X_train = gp_model['X_train']
    c_train = gp_model['c_train']
    K_inv = gp_model['K_inv']
    sigma_c = gp_model['sigma_c']
    N = len(X_train)

    # Compute kernel vector between test point and training points [G]
    # The kernel function is not specified in the sources [S1]
    k_x_star = np.array([np.exp(-np.linalg.norm(test_point - x)**2 / 2.0) for x in X_train])

    # Predict surface properties (Eq. 6 from source)
    # Source formula: ĉt(x*) = (k_x* X K_XX + σ_c^2 I)^-1 c [S1]
    surface_prop = k_x_star @ K_inv @ c_train

    # Predict distance (Eq. 3 and 4 from source, not detailed) [S1]
    # Not given in the sources.
    distance = 0.0
    variance = 0.0

    return distance, surface_prop, variance
```

**Parameters:**
$\sigma_c^2$ is the noise variance for surface properties, and its value is not given in the sources [S1]. The kernel function is not specified in the sources [S1].

**Edge Cases and Pitfalls:**
A singular kernel matrix may occur if training points are too close or identical, requiring pseudo-inverse or increased regularization [G]. An empty leaf node contains no voxels, so no GP is formed and queries should return undefined or default values [G]. Re-modeling the L-GPDF at every frame $i$ incurs computational cost if leaf nodes are large [S1].

## Subtopics

### [VDB-GPDF](22456-vdb-gpdf.md)
VDB-GPDF is an online incremental mapping framework that couples Gaussian Process (GP) distance fields with the OpenVDB data structure to enable fast, probabilistic queries of Euclidean distance, surface properties, and uncertainties for arbitrary points in large-scale environments. It solves the computational bottleneck of global GP regression by maintaining a temporary Local GP Signed Distance Field (L-GPDF) for local queries and fusing these results into a persistent Global GP Signed Distance Field (G-GPDF). Unlike TSDF or occupancy fusion frameworks (e.g., VDBFusion, VDBblox) that require post-processing to approximate the Euclidean Signed Distance Field (ESDF), VDB-GPDF fuses directly on the ESDF using the L-GPDF, allowing direct querying of distance with uncertainty.

## Operating characteristics
The time complexity is dominated by the GP regression for each leaf node, where computing the kernel matrix is $O(N^2)$ and inverting it is $O(N^3)$ for a leaf node with $N$ voxels [S1]. This cost is incurred per frame per leaf node because the L-GPDF is re-modeled at every frame $i$ [S1]. The memory complexity is proportional to the number of voxels in the local VDB, specifically storing the kernel matrix inverse for each leaf node, which is $O(N^2)$ per leaf node [S1]. Measured performance is not given in the sources [S1]. The VDB structure allows for efficient access and division of voxels into leaf nodes, which helps in scaling to large environments [S1]. Strengths include direct querying of distance with uncertainty and no post-processing requirement [S1]. Limitations include the computational cost of GP regression per frame and the requirement to re-model at every frame [S1]. The method should be used when probabilistic distance queries with uncertainty are needed in large-scale environments and computational resources allow for per-frame GP updates [S1].

## Background
The Local Gaussian Process Signed Distance Field (L-GPDF) was introduced in the VDB-GPDF paper [S1]. It is part of an online incremental mapping framework that uses Gaussian Processes to model signed distance fields [S1]. The method addresses the limitations of traditional TSDF and occupancy fusion methods by providing a probabilistic representation of the distance field [S1].
