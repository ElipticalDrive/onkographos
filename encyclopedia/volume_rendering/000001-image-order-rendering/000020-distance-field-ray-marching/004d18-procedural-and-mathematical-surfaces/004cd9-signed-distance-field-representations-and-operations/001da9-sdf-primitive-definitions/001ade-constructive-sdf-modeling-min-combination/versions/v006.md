# Constructive SDF Modeling (Min Combination)

Also called: Min Combination, Min SDF, SDF Union, Union of SDFs, SDF Union via Min, SDF Min Operation

## Overview
Constructive SDF Modeling (Min Combination) computes the signed distance from a query point to the geometric union of multiple primitives by returning the minimum of their individual signed distance functions (SDFs) [S1, S2, S3, S5, S8, S9, S10, unofficial]. It solves the problem of representing complex scenes composed of many objects as a single continuous distance field, enabling efficient ray marching by providing a conservative lower bound on the distance to the nearest surface [S9, unofficial]. It differs from [Smooth SDF Composition](2685-smooth-sdf-composition.md) by producing sharp, non-differentiable boundaries at object intersections rather than smooth transitions, and from [Boolean Operations on Distance Fields](1961-boolean-operations-on-distance-fields.md) by strictly implementing the union operation via the minimum operator [S2, S10, unofficial].

## How it works
**Inputs and Outputs:**
*   **Input:** A query point $\mathbf{p} \in \mathbb{R}^3$ and a set of $N$ SDF primitives $\{d_i(\mathbf{p})\}_{i=0}^{N-1}$, where each $d_i$ returns the signed distance to the $i$-th shape [S4, S5, S9, unofficial].
*   **Output:** A scalar value $d_{\text{scene}}(\mathbf{p})$ representing the distance to the closest surface in the union [S4, S9, unofficial].

**Data Structures:**
The scene is typically represented as a collection of primitive objects. A common layout stores these in separate containers for efficient iteration, such as:
*   `world_spheres`: List of Sphere objects, each containing center $\mathbf{c}$ and radius $r$.
*   `world_boxes`: List of Box objects, each containing center $\mathbf{c}$ and half-sizes $\mathbf{b}$.
*   `world_toruses`: List of Torus objects, each containing center $\mathbf{c}$, major radius $R$, and minor radius $r$.
*   `world_mandelbulbs`: List of Mandelbulb objects [S4, unofficial].

**Formulas:**
The core operation is the minimum function [S2, S3, S5, S8, unofficial]:
$$ d_{\text{union}}(\mathbf{p}) = \min(d_A(\mathbf{p}), d_B(\mathbf{p})) $$
For a scene with $N$ primitives:
$$ d_{\text{scene}}(\mathbf{p}) = \min_{i=0}^{N-1} (d_i(\mathbf{p})) $$
[S4, S5, unofficial]

Common primitive SDF definitions used as inputs [S1, S6, unofficial]:
*   **Sphere:** $d_{\text{sphere}}(\mathbf{p}, \mathbf{c}, r) = \|\mathbf{p} - \mathbf{c}\| - r$
*   **Plane:** $d_{\text{plane}}(\mathbf{p}, y) = \mathbf{p}.y - y$ [S1, S6, unofficial]
*   **Box (Axis-Aligned):** $d_{\text{box}}(\mathbf{p}, \mathbf{c}, \mathbf{b}) = \|\max(\mathbf{p} - \mathbf{c} - \mathbf{b}, \mathbf{0})\| + \min(\max((\mathbf{p} - \mathbf{c} - \mathbf{b}).x, (\mathbf{p} - \mathbf{c} - \mathbf{b}).y, (\mathbf{p} - \mathbf{c} - \mathbf{b}).z), 0.0)$ [S6, unofficial]
*   **Torus:** $d_{\text{torus}}(\mathbf{p}, \mathbf{c}, R, r) = \|\mathbf{q}\| - r$, where $\mathbf{q} = (\|\mathbf{p}_{xz} - \mathbf{c}_{xz}\| - R, \mathbf{p}.y - \mathbf{c}.y)$ [S6, unofficial]

**Parameters:**
*   $N$: Number of primitives in the scene.
*   Primitive-specific parameters (e.g., $r$ for sphere radius, $\mathbf{c}$ for center) [S1, S6, unofficial].

**Steps:**
1.  Initialize `min_dist` to positive infinity (or a sufficiently large value like `std::numeric_limits<double>::max()`) [S4, S9, unofficial]. *Note: Hardcoding a finite value like 999 is a pitfall if objects are farther away [S4, unofficial].*
2.  For each primitive $i$ in the scene:
    a. Evaluate the primitive's SDF at $\mathbf{p}$ to get $d_i$.
    b. If $d_i < \text{min\_dist}$, set $\text{min\_dist} = d_i$.
3.  Return `min_dist` [S4, S9, S10, unofficial].

**Pseudocode:**
```python
def scene_sdf(p: Vector3, primitives: List[Primitive]) -> float:
    """
    Computes the signed distance to the union of all primitives.
    :param p: Query point in 3D space.
    :param primitives: List of objects implementing a 'distance(p)' method.
    :return: Minimum signed distance to any primitive.
    """
    min_dist = float('inf')  # Initialize to infinity [S4, S9, unofficial]
    
    for primitive in primitives:
        # Evaluate individual SDF [S4, S9, S10, unofficial]
        dist = primitive.distance(p)
        
        # Update minimum [S4, S9, unofficial]
        if dist < min_dist:
            min_dist = dist
            
    return min_dist
```

**Edge Cases and Pitfalls:**
*   **Initialization:** Initializing `min_dist` to a hardcoded finite value (e.g., 999) causes incorrect results if all scene objects are farther than that value [S4, unofficial]. Use infinity or the distance to the first object [S4, unofficial].
*   **Derivative Discontinuity:** The `min` operator results in non-smooth unions with discontinuous derivatives (slopes) at the intersection of objects, which can cause visible artifacts in shading or normal estimation [S10, unofficial].
*   **Overshooting:** Using a distance larger than the minimum (e.g., from a far object) instead of the true minimum causes the ray marcher to skip across the nearer surface, breaking convergence [S9, unofficial]. The SDF must be a conservative lower bound [S9, unofficial].

## Operating characteristics
*   **Time Complexity:** $O(N)$ per query point, where $N$ is the number of primitives [S4, S9, unofficial]. Each primitive must be evaluated to find the minimum.
*   **Memory Complexity:** $O(N)$ to store the primitive definitions [S4, unofficial].
*   **Strengths:** Simple to implement; provides a guaranteed lower bound for sphere tracing convergence; allows rendering of complex scenes without triangle meshes [S9, S10, unofficial].
*   **Limitations:** Sharp, non-differentiable corners at intersections; performance degrades linearly with the number of primitives [S10, unofficial].
*   **When to use:** When sharp geometric unions are desired and the number of primitives is manageable [S10, unofficial].
*   **When not to use:** When smooth blending is required (use [Smooth SDF Composition](2685-smooth-sdf-composition.md)) or when $N$ is very large (consider spatial partitioning or [Infinite Tiling with Modulo](1632-infinite-tiling-with-modulo.md) for repetitions) [S10, unofficial].

## Background
The method is based on the approach described by Iñigo Quilez in his "Distance Functions" resources [S9, unofficial]. It is a fundamental technique in ray marching, allowing the construction of complex scenes from simple primitives by treating the scene as a single implicit function defined by the minimum distance [S9, S10, unofficial]. The theoretical basis for union (min), intersection (max), and complement (negation) operations on distance fields is detailed in early raymarching literature [S2, unofficial].
