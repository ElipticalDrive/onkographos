# Material Object Format


## Overview
The Material Object Format is a data structure that holds surface shading information, including color, physical properties, and texture descriptors, accessible from both host and device code [S1]. It distinguishes itself by explicitly separating geometric displacement (via `heightmapTex`) from shading calculations and by managing texture projection modes and normal deflection scaling [S1].

## How it works
### Inputs and Outputs
*   **Input**: Material parameters (`albedo`, `metalness`, `roughness`, `F0`) and optional texture descriptors [S1].
*   **Output**: A `Material` instance containing shading and texture metadata [S1].

### Data Structures
The `Material` object consists of the following fields [S1]:

| Field | Type | Description |
| :--- | :--- | :--- |
| `albedo` | `vec3` (linear float) | Surface color in linear RGB [S1]. |
| `metalness` | `float` | Range $[0, 1]$. Controls specular vs. diffuse shading contribution [S1]. |
| `roughness` | `float` | Range $[0, 1]$. Controls smoothness of reflections and light scattering [S1]. |
| `F0` | `vec3` (linear float) | Base reflectivity when `metalness` is 0 [S1]. |
| `triplar` | `bool` | Texture projection mode. `false` for XZ planar mapping, `true` for triplanar mapping [S1]. |
| `normalStrength` | `float` | Linear scaling factor for normal deflection from normal maps [S1]. |
| `albedoTex` | `int` | Texture descriptor for sRGB albedo map. Value $-1$ if unused. Multiplied with `albedo` [S1]. |
| `normalTex` | `int` | Texture descriptor for linear detail normal map. Value $-1$ if unused [S1]. |
| `roughnessTex` | `int` | Texture descriptor for linear roughness map. Value $-1$ if unused. Multiplied with `roughness` [S1]. |
| `metalnessTex` | `int` | Texture descriptor for linear metalness map. Value $-1$ if unused. Multiplied with `metalness` [S1]. |
| `heightmapTex` | `int` | Texture descriptor for linear displacement heightmap. Value $-1$ if unused. Used for geometric displacement by the object SDF, not for shading [S1]. |
| `ambietTex` | `int` | Texture descriptor for linear ambient occlusion map. Value $-1$ if unused [S1]. |

Texture descriptors are integers referencing texture objects or mipmap arrays, and only the descriptor value is needed to read a texture from device code [S1].

### Construction Logic
Two constructors initialize the `Material` object [S1]:

1.  **Full Constructor**: Takes `albedo`, `metalness`, `roughness`, and `F0` as arguments [S1].
    *   Sets all texture descriptors (`albedoTex`, `normalTex`, `roughnessTex`, `metalnessTex`, `heightmapTex`, `ambietTex`) to $-1$ [S1].
    *   Sets `triplar` to `false` (planar mapping) [S1].
    *   Sets `normalStrength` to $1.0$ [S1].
2.  **Simplified Constructor**: Takes `albedo`, `roughness`, and `metalness` [S1].
    *   Calls the Full Constructor with these values and a default `F0` of $[0.04, 0.04, 0.04]$ [S1].
    *   The default `F0` is considered the standard base reflectance for most non-metal dielectrics (e.g., plastics, organic materials) [S1].

### Pseudocode
```python
class Material:
    def __init__(self, albedo, metalness, roughness, F0=None):
        """
        Implements both constructors:
        - Constructor 1 (Full): F0 is provided.
        - Constructor 2 (Simplified): F0 is None, defaults to [0.04, 0.04, 0.04].
        """
        if F0 is None:
            F0 = [0.04, 0.04, 0.04]
        
        self.albedo = albedo
        self.metalness = metalness
        self.roughness = roughness
        self.F0 = F0
        
        self.triplar = False
        self.normalStrength = 1.0
        
        self.albedoTex = -1
        self.normalTex = -1
        self.roughnessTex = -1
        self.metalnessTex = -1
        self.heightmapTex = -1
        self.ambietTex = -1
```

### Edge Cases and Pitfalls
*   **Texture Descriptors**: All texture fields default to $-1$ to specify the material as textureless [S1].
*   **Heightmap vs. Shading**: `heightmapTex` is explicitly excluded from shading calculations and is used solely by the object SDF for geometric displacement [S1].
*   **Normal Strength**: `normalStrength` scales normal deflection from normal map textures, which is useful when displacing a surface at a less steep angle than the normal map is designed for [S1].
