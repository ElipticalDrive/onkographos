# Polynomial Smooth Minimum
Also called: Quilez smin, Quilez smooth min, smoothMin

## Overview
Polynomial Smooth Minimum is a blending function for combining two Signed Distance Function (SDF) values to create organic, metaball-like merges between primitives without branching or trigonometry [S1, unofficial]. It sets itself apart from the standard `min` operator by providing a continuous, differentiable transition controlled by a smoothing radius parameter $k$, allowing for smooth union operations in Constructive SDF Modeling [S2, unofficial].

## How it works
**Inputs and Outputs:**
- Inputs: Two scalar SDF values $a$ and $b$, and a non-negative smoothing radius $k$ [S2, unofficial].
- Output: A single scalar value representing the smooth minimum of $a$ and $b$ [S2, unofficial].

**Data Structures:**
- Operates on scalar floating-point values with no auxiliary data structures [S2, unofficial].

**Algorithm:**
The method computes an intermediate blend factor $h$ based on the distance between $a$ and $b$ relative to $k$, then adjusts the minimum value by a quadratic term [S2, unofficial].

1. **Edge Case Handling:** If $k \le 10^{-6}$, return $\min(a, b)$ to avoid division by zero or numerical instability [S2, unofficial].
2. **Compute Blend Factor:** Calculate $h = \max(k - |a - b|, 0.0) / k$ [S2, unofficial]. This value ranges from $0.0$ (when $|a - b| \ge k$) to $1.0$ (when $a = b$) [S2, unofficial].
3. **Compute Result:** Return $\min(a, b) - h^2 \cdot k \cdot 0.25$ [S2, unofficial].

*Note: Source [S1, unofficial] provides an equivalent formulation using $h = \text{clamp}(0.5 + 0.5(b - a)/k, 0.0, 1.0)$ and $\text{result} = \text{mix}(b, a, h) - k \cdot h \cdot (1.0 - h)$ [S1, unofficial]. Both yield identical results for the same inputs [G].*

**Pseudocode:**
```python
def polynomial_smooth_minimum(a: float, b: float, k: float) -> float:
    if k <= 1e-6:
        return min(a, b)
    diff = abs(a - b)
    h = max(k - diff, 0.0) / k
    return min(a, b) - (h * h * k * 0.25)
```

**Parameters:**
- $k$: The blend radius parameter, exposed as a UI slider [S1, unofficial]. Typical values are $0.2$ or $0.3$ [S2, unofficial].

**Edge Cases and Pitfalls:**
- When $|a - b| \ge k$, $h = 0$ and the result equals $\min(a, b)$, preserving the hard union outside the blending region [S2, unofficial].
- Floating-point precision may cause artifacts when subtracting close values for large $k$ [G].

## Subtopics

### Polynomial Smooth Maximum
The dual operator for smooth intersection, combining two SDF values using a smoothing factor $k$ [S2, unofficial]. It computes $h = \max(k - |a - b|, 0.0) / k$ and returns $\max(a, b) + h^2 \cdot k \cdot 0.25$ [S2, unofficial]. Choose this when carving out material smoothly or implementing smooth subtraction, as it is implemented as `smax(-d1, d2, k)` for smooth subtraction and `smax(d1, d2, k)` for smooth intersection [S2, unofficial].

## Background
The method is attributed to Inigo Quilez, a prominent graphics programmer known for his work on ray marching and SDFs [S2, unofficial]. It is widely known in the procedural geometry community as "Quilez smin" [S2, unofficial]. The technique is used in real-time ray marching shaders for creating complex organic shapes from simple primitives [S3, unofficial].
