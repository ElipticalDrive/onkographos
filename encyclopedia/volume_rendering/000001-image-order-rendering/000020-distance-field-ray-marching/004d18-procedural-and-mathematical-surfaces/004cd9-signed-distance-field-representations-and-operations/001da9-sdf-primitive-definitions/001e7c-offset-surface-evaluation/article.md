# Offset Surface Evaluation

Also called: Distance to Offset Surfaces, Global offset, Local offset, Point-to-set distance

## Overview
Offset Surface Evaluation computes the distance from a query point to a surface generated by offsetting a skeleton geometry by a fixed distance [S1]. It defines smooth, thickened representations of curves, surfaces, or meshes for implicit modeling and ray marching [S1]. It is distinguished from its siblings by its reliance on a global point-to-set distance search (global offset) rather than a local parametric displacement, which avoids the interior self-intersections and high-degree algebraic artifacts common in local offset methods [S1].

## How it works
The method evaluates the distance to an offset surface by finding the closest point on the underlying skeleton geometry [S1].

**Inputs and Outputs:**
- Input: Query point $\mathbf{p}$, skeleton geometry $S$ (e.g., a space curve or surface), constant offset distance $c$ [S1].
- Output: Signed distance $d(\mathbf{p})$ to the offset surface [S1].

**Data Structures:**
- Skeleton representation: Parametric form $\mathbf{s}(t)$ for curves or $\mathbf{s}(u,v)$ for surfaces, or a mesh vertex list with normals [S1][S2, unofficial].
- Distance metric: Euclidean distance [S1].

**Steps:**
1. **Search Skeleton:** Search the entire set $S$ for the closest point $\mathbf{s}^*$ to $\mathbf{p}$ [S1].
2. **Solve for Curves:** For a parametric curve $\mathbf{s}(t)$, find the point where the tangent is perpendicular to the vector pointing to $\mathbf{p}$ by solving $(\mathbf{s}(t) - \mathbf{p}) \cdot \mathbf{s}'(t) = 0$ [S1]. This can be converted to a degree-5 Bernstein polynomial and solved via convex hull bounding [S1].
3. **Search for Meshes:** For meshes, iterate over vertices or primitives to find the minimum distance [S2, unofficial].
4. **Compute Distance:** Calculate the Euclidean distance $d_{\text{raw}} = \|\mathbf{p} - \mathbf{s}^*\|$ [S1].
5. **Apply Offset:** The signed distance to the offset surface is $d(\mathbf{p}) = d_{\text{raw}} - c$ [S1].

**Parameters:**
- $c$: Constant offset distance applied to the skeleton [S1]. Typical values are not given in the sources.

**Pitfalls:**
- **Interior Surfaces:** Global offsets avoid interior surfaces, whereas local offsets can cause gradient discontinuities or result in high-degree algebraic representations [S1].
- **Mesh Self-Intersection:** When offsetting a mesh by moving vertices along normals, self-intersections are not handled automatically [S2, unofficial].

**Pseudocode:**
> **Unverified code.** The code below did not pass a test run against a reference implementation, or no test fits it, so it may contain errors.

```python
def offset_surface_distance(p, skeleton_primitives, c):
    """
    Computes distance from point p to the offset surface of a skeleton by distance c.
    skeleton_primitives: list of objects with a closest_point(p) method.
    c: float, constant offset distance.
    """
    min_dist_sq = float('inf')
    for prim in skeleton_primitives:
        # Primitive-specific closest point search (curve parameter solve or triangle test)
        pt = prim.closest_point(p)
        dist_sq = (p[0] - pt[0])**2 + (p[1] - pt[1])**2 + (p[2] - pt[2])**2
        if dist_sq < min_dist_sq:
            min_dist_sq = dist_sq
    raw_dist = min_dist_sq**0.5
    return raw_dist - c
```

## Subtopics

### Offset Surface Creation
Creates an offset surface from a mesh by moving vertices along their computed normals by a given distance [S2, unofficial]. It is a local offset method, distinct from the global point-to-set distance approach [S1]. It is chosen for mesh-based modeling where normals are available [S2, unofficial]. It does not handle self-intersections, as vertices are moved independently along their original normals [S2, unofficial].
- **Definition:** Parametric displacement of mesh vertices [S2, unofficial].
- **Steps:**
  1. Ensure normals are computed: `mesh->need_normals()` [S2, unofficial].
  2. Iterate over all vertices $i$ from $0$ to $nv-1$ [S2, unofficial].
  3. Update vertex position: `mesh->vertices[i] += amount * mesh->normals[i]` [S2, unofficial].
  4. Invalidate bounding box and bounding sphere flags [S2, unofficial].
- **Parameters:** `amount`: distance to offset along normals [S2, unofficial].
- **Pitfalls:** Does not handle self-intersections; vertices are moved independently along their original normals [S2, unofficial].

## Operating characteristics
- **Time Complexity:** Depends on the skeleton search [S1]. For a mesh, it is $O(N)$ where $N$ is the number of primitives, unless accelerated by a BVH or grid [S2, unofficial]. For parametric curves, it involves solving polynomial equations, which is constant time but potentially expensive per evaluation [S1].
- **Memory Complexity:** $O(N)$ to store the skeleton geometry [S2, unofficial].
- **Strengths:** Global offsets avoid interior surfaces and are more desirable for ray-tracing and CSG operations [S1]. They provide smooth, continuous distance fields [S1].
- **Limitations:** Local offsets can cause gradient discontinuities [S1]. Mesh-based local offsets do not handle self-intersections [S2, unofficial].
- **When to use:** When a smooth, thickened representation of a curve or surface is needed for ray marching or implicit modeling [S1].
- **When not to use:** When the skeleton has high curvature leading to self-intersections, or when performance is critical and the skeleton is a large mesh without acceleration structures [S1][S2, unofficial].

## Background
The concept of offset surfaces is rooted in computer-aided geometric design (CAGD) and implicit surface rendering [S1]. Global offsets are defined geometrically by the implicit equation $d(\mathbf{p}) = 0$, where $d(\mathbf{p})$ is the point-to-set distance to a closed skeleton geometry $S$ [S1]. When $d$ is constant, the surface fleshes out the skeleton [S1]. The formulation of point-to-set distance reduces the search space for closest point determination to primitives such as parametric surfaces [S1]. Global offsets are usually defined as geometric implicit surfaces, whereas local offsets are usually defined parametrically [S1]. Global offsets are considered more desirable [Hoffman, 1989] as they avoid interior surfaces which can cause problems in ray-tracing and CSG [van Wijk, 1984]. The offset of an algebraic implicit surface is algebraic, though of higher degree in general [S1].
