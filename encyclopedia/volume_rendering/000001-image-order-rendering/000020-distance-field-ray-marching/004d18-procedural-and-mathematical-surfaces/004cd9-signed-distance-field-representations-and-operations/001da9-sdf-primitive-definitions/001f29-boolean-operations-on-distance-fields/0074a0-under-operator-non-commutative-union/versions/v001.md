# Under Operator (Non-commutative Union)

Also called: Non-commutative under operator, Over Operator, Non-commutative Union, symmetric over operator, union with replacement

## Overview
The under operator is a non-commutative Boolean operator for multiphase Signed Distance Fields (SDFs) that performs a union of phases while replacing the phase labels of the first operand with those of the second operand [S1]. It solves the problem of assembling composite objects where one material (e.g., cement) must visually "cover" or replace the identity of another (e.g., rock blocks) in overlapping regions, without altering the underlying geometric distance values of the covering material [S1]. It differs from the standard commutative union (min) by enforcing a strict occlusion order, and from the [Contact Operator](23047-contact-operator.md) by not generating an internal interface surface between phases [S1].

## How it works
**Inputs and Outputs:**
*   **Input:** Two multiphase objects $\mathcal{A}$ and $\mathcal{B}$, each defined by a vector of $n$ signed distance fields $\{\phi_{\mathcal{A}_1}, \dots, \phi_{\mathcal{A}_n}\}$ and $\{\phi_{\mathcal{B}_1}, \dots, \phi_{\mathcal{B}_n}\}$.
*   **Output:** A resulting multiphase object $\mathcal{C} = \mathcal{A} \cup_- \mathcal{B}$ with $n$ phases, where each phase $i$ has a signed distance field $\phi_i$.

**Data Structures:**
The implementation assumes a structure where each phase $i$ is represented by its scalar SDF value $\phi_i$ at a given point in space. No additional bit-packing is specified in the sources; standard floating-point representation is implied [S1].

**Formulas:**
The set-theoretic definition for the $i$-th phase of the result is:
$$ \mathcal{C}_i = (\mathcal{A}_i \cup \mathcal{B}_i) - \bigcup_{j \neq i} \mathcal{B}_j $$
where $\cup$ denotes standard set union and $-$ denotes set difference [S1].

The corresponding signed distance field computation for each phase $i \in [1, n]$ is:
$$ \phi_i = \max(\min(\phi_{\mathcal{A}_i}, \phi_{\mathcal{B}_i}), -\min(\phi_{\mathcal{B}_i})) $$
where $\phi_{\mathcal{A}_i}$ and $\phi_{\mathcal{B}_i}$ are the SDF values of phase $i$ in objects $\mathcal{A}$ and $\mathcal{B}$ respectively [S1].

**Parameters:**
*   $n$: The number of phases. Not given in the sources.

**Edge Cases and Pitfalls:**
*   **Precision:** Standard floating-point precision applies. No specific epsilon is given in the sources [S1].
*   **Boundaries:** The operator is defined for all $i \in [1, n]$. If $n=1$, the operator reduces to the standard union $\min(\phi_{\mathcal{A}_1}, \phi_{\mathcal{B}_1})$ because the term $-\min(\phi_{\mathcal{B}_1})$ is always greater than or equal to $\min(\phi_{\mathcal{A}_1}, \phi_{\mathcal{B}_1})$ only if $\phi_{\mathcal{A}_1} > \phi_{\mathcal{B}_1}$? No, if $\phi_{\mathcal{A}_1} < \phi_{\mathcal{B}_1}$, min is $\phi_{\mathcal{A}_1}$. $-\min(\phi_{\mathcal{B}_1}) = -\phi_{\mathcal{B}_1}$. If $\phi_{\mathcal{A}_1} < -\phi_{\mathcal{B}_1}$, then result is $\phi_{\mathcal{A}_1}$. This behavior needs careful testing [S1].

## Subtopics

### [Local Phase Change](23054-local-phase-change.md)
The Local Phase Change operator modifies the phase labels of a multiphase SDF within a specific spatial region defined by another SDF. It solves the problem of selectively reassigning material identities (phases) in a composite object without altering the underlying geometry's shape, effectively performing a "cut and paste" of phase labels. It differs from global phase reassignment by being spatially localized and from geometric Boolean operations by preserving the distance values of the target phase while only updating the label [23054-local-phase-change.md].

### Phase-Specific Smooth-Boolean Operator
A phase-specific smooth union with a shape $S$ over other phases, denoted $\mathcal{B} = \bigcup_+^*(\mathcal{A}, S, k)$. It smooths the union of phase $k$ and shape $S$, while subtracting this result from all other phases [S1]. The set operations are $\mathcal{B}_k = \mathcal{A}_k \cup^* S$ and $\mathcal{B}_i = \mathcal{A}_i - (\mathcal{A}_k \cup^* S)$ for all $i \neq k$, where $\cup^*$ is the smooth union with blending radius $r$ [S1]. The phase functions are computed as $\phi_{\mathcal{B}_k} = \widetilde{\phi_k}$ and $\phi_{\mathcal{B}_i} = \max(\phi_{\mathcal{A}_i}, \widetilde{\phi_k})$ for all $i \neq k$, where $\widetilde{\phi_k} = s(\phi_{\mathcal{A}_k}, f)$ and $f$ is the SDF of shape $S$. The function $s$ represents the smooth union formulation [S1].

## Operating characteristics
*   **Time Complexity:** Linear with respect to the number of phases $n$ and the number of sample points, as each phase is computed independently using constant-time arithmetic operations [S1].
*   **Memory Complexity:** Linear with respect to the number of phases $n$ to store the input and output SDFs [S1].
*   **Measured Performance:** Not given in the sources.
*   **Strengths:** Allows for the construction of complex composite materials (e.g., rocks with cement) where the occluding material's phase identity is preserved in the overlap [S1].
*   **Limitations:** Non-commutative, so the order of operands matters. The explicit computational formula provided in the source may not fully align with the set-theoretic definition regarding other phases [S1].
*   **When to use:** When assembling multiphase objects where one phase should visually replace another in overlapping regions.
*   **When not to use:** When commutative union is required or when an internal contact surface between phases is desired (use [Contact Operator](23047-contact-operator.md) instead) [S1].

## Background
The under operator was introduced in the context of multiphase Signed Distance Fields to address the limitations of standard Boolean operators (union, intersection, difference) which do not directly adapt to multiphase models [S1]. It is part of the PhaseTree framework for representing and manipulating multiphase implicit surfaces [S1]. The operator is symmetric to the over operator, where $\mathcal{A} \cup_+ \mathcal{B}$ is equivalent to $\mathcal{B} \cup_- \mathcal{A}$ [S1].
