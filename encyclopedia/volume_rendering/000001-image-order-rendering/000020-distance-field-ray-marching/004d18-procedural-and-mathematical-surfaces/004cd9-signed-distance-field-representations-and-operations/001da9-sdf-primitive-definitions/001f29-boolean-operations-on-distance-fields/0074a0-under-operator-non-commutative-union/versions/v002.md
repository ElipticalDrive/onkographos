# Under Operator (Non-commutative Union)

Also called: Non-commutative under operator, Over Operator, Non-commutative Union, symmetric over operator, union with replacement

## Overview
The under operator is a non-commutative Boolean operator for multiphase Signed Distance Fields (SDFs) that performs a union of phases while replacing the phase labels of the first operand with those of the second operand [S1]. It solves the problem of assembling composite objects where one material must visually cover or replace the identity of another in overlapping regions, without altering the underlying geometric distance values of the covering material [S1]. It differs from the standard commutative union (min) by enforcing a strict occlusion order, and from the [Contact Operator](23047-contact-operator.md) by not generating an internal interface surface between phases [S1].

## How it works
**Inputs and Outputs:**
*   **Input:** Two multiphase objects $\mathcal{A}$ and $\mathcal{B}$, each defined by a vector of $n$ signed distance fields $\{\phi_{\mathcal{A}_1}, \dots, \phi_{\mathcal{A}_n}\}$ and $\{\phi_{\mathcal{B}_1}, \dots, \phi_{\mathcal{B}_n}\}$ [S1].
*   **Output:** A resulting multiphase object $\mathcal{C} = \mathcal{A} \cup_- \mathcal{B}$ with $n$ phases, where each phase $i$ has a signed distance field $\phi_i$ [S1].

**Data Structures:**
Each phase $i$ is represented by its scalar SDF value $\phi_i$ at a given point in space [S1].

**Formulas:**
The set-theoretic definition for the $i$-th phase of the result is:
$$ \mathcal{C}_i = (\mathcal{A}_i \cup \mathcal{B}_i) - \bigcup_{j \neq i} \mathcal{B}_j $$
where $\cup$ denotes standard set union and $-$ denotes set difference [S1].

The corresponding signed distance field computation for each phase $i \in [1, n]$ is:
$$ \phi_i = \max(\min(\phi_{\mathcal{A}_i}, \phi_{\mathcal{B}_i}), -\min(\phi_{\mathcal{B}_i})) $$
where $\phi_{\mathcal{A}_i}$ and $\phi_{\mathcal{B}_i}$ are the SDF values of phase $i$ in objects $\mathcal{A}$ and $\mathcal{B}$ respectively [S1].

**Parameters:**
*   $n$: The number of phases [S1]. Typical values are not given in the sources.

**Pseudocode:**
```python
def under_operator(phi_A, phi_B):
    """Computes the non-commutative under operator for multiphase SDFs.
    
    Args:
        phi_A: List of n SDF values for object A.
        phi_B: List of n SDF values for object B.
        
    Returns:
        phi_C: List of n SDF values for the result.
    """
    n = len(phi_A)
    phi_C = [0.0] * n
    for i in range(n):
        phi_C[i] = max(min(phi_A[i], phi_B[i]), -min(phi_B[i]))
    return phi_C
```

**Edge Cases and Pitfalls:**
*   **Precision:** Standard floating-point precision applies [S1].
*   **Boundaries:** The formula applies for all $i \in [1, n]$ [S1].
*   **Discrepancy Note:** The explicit phase function formula provided in the source does not explicitly compute the union of other phases $\bigcup_{j \neq i} \mathcal{B}_j$ from the set definition, which may represent a simplification or specific assumption in the source [S1].

## Subtopics

### [Local Phase Change](23054-local-phase-change.md)
The Local Phase Change operator modifies the phase labels of a multiphase SDF within a specific spatial region defined by another SDF. It differs from global phase reassignment by being spatially localized and from geometric Boolean operations by preserving the distance values of the target phase while only updating the label. Choose it when selectively reassigning material identities in a composite object without altering the underlying geometry's shape is required.

### Phase-Specific Smooth-Boolean Operator
A phase-specific smooth union with a shape $S$ over other phases, denoted $\mathcal{B} = \bigcup_+^*(\mathcal{A}, S, k)$ [S1]. It smooths the union of phase $k$ and shape $S$, while subtracting this result from all other phases [S1]. The set operations are $\mathcal{B}_k = \mathcal{A}_k \cup^* S$ and $\mathcal{B}_i = \mathcal{A}_i - (\mathcal{A}_k \cup^* S)$ for all $i \neq k$, where $\cup^*$ is the smooth union with blending radius $r$ [S1]. The phase functions are computed as $\phi_{\mathcal{B}_k} = \widetilde{\phi_k}$ and $\phi_{\mathcal{B}_i} = \max(\phi_{\mathcal{A}_i}, \widetilde{\phi_k})$ for all $i \neq k$, where $\widetilde{\phi_k} = s(\phi_{\mathcal{A}_k}, f)$ and $f$ is the SDF of shape $S$ [S1]. The function $s$ represents the smooth union formulation [S1]. Choose it when blending geometries smoothly while enforcing phase replacement behavior is required [S1].

## Background
The under operator was introduced in the context of multiphase Signed Distance Fields to address the limitations of standard Boolean operators (union, intersection, difference) which do not directly adapt to multiphase models [S1]. It is part of the PhaseTree framework for representing and manipulating multiphase implicit surfaces [S1]. The operator is symmetric to the over operator, where $\mathcal{A} \cup_+ \mathcal{B}$ is equivalent to $\mathcal{B} \cup_- \mathcal{A}$ [S1].
