# FRep R-function Boolean Operations

Also called: Function Representation Boolean Operations, R-function logic

## Overview
FRep R-function Boolean Operations perform set-theoretic operations (union, intersection, subtraction) on implicit surfaces defined by scalar fields $f_1$ and $f_2$ using R-functions, ensuring specific continuity properties based on the parameter $\alpha$ [S1]. Unlike the standard SDF operations (min/max) which produce $C^1$ discontinuities along the entire bisector plane where $f_1 = f_2$, R-functions allow for the construction of surfaces with $C^1$ continuity restricted only to the intersection of the zero-level sets, or smooth blending [S1]. This method is distinct from basic SDF primitives by providing a mathematical framework for constructing complex, continuous implicit models from simpler components without explicit mesh topology [S1].

## How it works

### Inputs and Outputs
*   **Inputs**: Two scalar fields $f_1(\mathbf{x})$ and $f_2(\mathbf{x})$ representing the distance or implicit functions of two objects [S1]. A continuity parameter $\alpha \in \{0, 1\}$ selecting the R-function class [S1]. Optional parameters for variants (e.g., blending coefficients $a_0, a_1, a_2$, lattice frequencies $q$, phases $p$, thresholds $l$, offsets $d$) [S1].
*   **Outputs**: A resulting scalar field $f_3(\mathbf{x})$ representing the union, intersection, or subtraction of the input objects [S1].

### Data Structures
The method operates on scalar fields [S1]. In a procedural implementation, these are functions mapping 3D coordinates to real numbers [G]. No explicit grid or voxel structure is required for the definition, though evaluation occurs at query points $\mathbf{x} = (x, y, z)$ [S1].

### Formulas and Steps

#### 1. Standard R-function Boolean Operations
The core operations are defined by the R-function logic $\lor_\alpha, \land_\alpha, \setminus_\alpha$ [S1].

**Class $\alpha = 1$ (Standard SDF-like):**
These functions are $C^1$ discontinuous at all points where $f_1 = f_2$ [S1].
*   **Union**:
    $$f_3 = f_1 \lor_1 f_2 = \max(f_1, f_2)$$
*   **Intersection**:
    $$f_3 = f_1 \land_1 f_2 = \min(f_1, f_2)$$
*   **Subtraction**:
    $$f_3 = f_1 \setminus_1 f_2 = \min(f_1, -f_2)$$

**Class $\alpha = 0$ (Smooth R-functions):**
These functions have $C^1$ discontinuity only at points where both arguments are equal to zero ($f_1 = 0 \land f_2 = 0$) [S1].
*   **Union**:
    $$f_3 = f_1 \lor_0 f_2 = \sqrt{f_1^2 + f_2^2 + \sqrt{f_1^4 + f_2^4}}$$
*   **Intersection**:
    $$f_3 = f_1 \land_0 f_2 = \sqrt{f_1^2 + f_2^2 - \sqrt{f_1^4 + f_2^4}}$$
*   **Subtraction**:
    $$f_3 = f_1 \setminus_0 f_2 = \sqrt{f_1^2 + f_2^2} - \sqrt{f_1^4 + f_2^4}$$

#### 2. Infinite Regular Lattice Construction
This variant models infinite regular 3D lattices by combining periodic slabs [S1].

**Step 1: Define Parallel Slabs**
Define three sets of infinite parallel slabs orthogonal to the coordinate axes using trigonometric functions [S1]:
$$s_x(x,y,z) = \sin(q_x x + p_x) - l_x$$
$$s_y(x,y,z) = \sin(q_y y + p_y) - l_y$$
$$s_z(x,y,z) = \sin(q_z z + p_z) - l_z$$
*   $q$: Frequency/distance between slabs.
*   $p$: Phase/position of slabs relative to the origin.
*   $l$: Threshold defining slab thickness, where $-1 < l < 1$ [S1].

**Step 2: Define Rods (Intersection of Slabs)**
Intersect orthogonal slab sets to form rods parallel to one axis. Optional offsets $d_x, d_y, d_z$ can be applied to adjust cross-section shape [S1]:
$$r_x = s_y \land_\alpha s_z + d_x$$
$$r_y = s_x \land_\alpha s_z + d_y$$
$$r_z = s_x \land_\alpha s_y + d_z$$
*   If $d_x = d_y = d_z$, rods have circular cross-sections.
*   Otherwise, rods have elliptical cross-sections [S1].

**Step 3: Define Lattice (Union of Rods)**
Union the rods to form the infinite lattice [S1]:
$$g(x,y,z) = r_x \lor_\alpha r_y \lor_\alpha r_z$$
Explicitly:
$$g = (s_y \land_\alpha s_z) \lor_\alpha (s_x \land_\alpha s_z) \lor_\alpha (s_x \land_\alpha s_y)$$

#### 3. Microstructure-External Shape Combination
This variant combines an infinite microstructure lattice $g$ with an external object shape $F$ [S1].

**Step 1: Define Internal Offset**
Create an internal offset of the external shape $F$ using threshold $l_o > 0$ [S1]:
$$F_o(x,y,z) = F(x,y,z) - l_o$$

**Step 2: Define Object Shell**
Subtract the offset from the original shape to create a thin shell [S1]:
$$F_s(x,y,z) = F \setminus_\alpha F_o$$

**Step 3: Truncate Lattice**
Intersect the infinite lattice with the original external shape to fit it inside [S1]:
$$F_g = g \land_\alpha F$$

**Step 4: Combine Shell and Lattice**
Union the shell and the truncated lattice to form the final scaffold [S1]:
$$F_m(x,y,z) = F_s \lor_\alpha F_g = (F \setminus_\alpha F_o) \lor_\alpha (g \land_\alpha F)$$

#### 4. Blending Operations
This variant produces smooth transitions between surfaces instead of sharp edges by adding a displacement term [S1].

**Blending Intersection Formula:**
$$f_1 \land_b f_2 = (f_1 \land_\alpha f_2) + a_0 \left( \left(\frac{f_1}{a_1}\right)^2 + \left(\frac{f_2}{a_2}\right)^2 \right)$$
*   $a_0, a_1, a_2$: Parameters controlling the blend shape.
*   $a_0 < 0$: Corresponds to a blend with removed material (chamfer) [S1].

### Pseudocode

```python
import math

def r_function_union(f1, f2, alpha=0):
    """
    Computes the R-function union of two scalar fields.
    alpha=1: max(f1, f2)
    alpha=0: sqrt(f1^2 + f2^2 + sqrt(f1^4 + f2^4))
    """
    if alpha == 1:
        return max(f1, f2)
    elif alpha == 0:
        f1_sq = f1 * f1
        f2_sq = f2 * f2
        f1_4 = f1_sq * f1_sq
        f2_4 = f2_sq * f2_sq
        inner_sqrt = math.sqrt(f1_4 + f2_4)
        return math.sqrt(f1_sq + f2_sq + inner_sqrt)
    else:
        raise ValueError("Alpha must be 0 or 1")

def r_function_intersection(f1, f2, alpha=0):
    """
    Computes the R-function intersection of two scalar fields.
    alpha=1: min(f1, f2)
    alpha=0: sqrt(f1^2 + f2^2 - sqrt(f1^4 + f2^4))
    """
    if alpha == 1:
        return min(f1, f2)
    elif alpha == 0:
        f1_sq = f1 * f1
        f2_sq = f2 * f2
        f1_4 = f1_sq * f1_sq
        f2_4 = f2_sq * f2_sq
        inner_sqrt = math.sqrt(f1_4 + f2_4)
        return math.sqrt(f1_sq + f2_sq - inner_sqrt)
    else:
        raise ValueError("Alpha must be 0 or 1")

def r_function_subtraction(f1, f2, alpha=0):
    """
    Computes the R-function subtraction of two scalar fields.
    alpha=1: min(f1, -f2)
    alpha=0: sqrt(f1^2 + f2^2) - sqrt(f1^4 + f2^4)
    """
    if alpha == 1:
        return min(f1, -f2)
    elif alpha == 0:
        f1_sq = f1 * f1
        f2_sq = f2 * f2
        f1_4 = f1_sq * f1_sq
        f2_4 = f2_sq * f2_sq
        return math.sqrt(f1_sq + f2_sq) - math.sqrt(f1_4 + f2_4)
    else:
        raise ValueError("Alpha must be 0 or 1")

def slab_function_x(x, y, z, qx, px, lx):
    return math.sin(qx * x + px) - lx

def slab_function_y(x, y, z, qy, py, ly):
    return math.sin(qy * y + py) - ly

def slab_function_z(x, y, z, qz, pz, lz):
    return math.sin(qz * z + pz) - lz

def lattice_function(x, y, z, qx, px, lx, qy, py, ly, qz, pz, lz, alpha=0, dx=0, dy=0, dz=0):
    """
    Computes the infinite regular lattice function.
    """
    # Step 1: Slabs
    sx = slab_function_x(x, y, z, qx, px, lx)
    sy = slab_function_y(x, y, z, qy, py, ly)
    sz = slab_function_z(x, y, z, qz, pz, lz)
    
    # Step 2: Rods (Intersection of orthogonal slabs)
    # Note: The source defines rods as intersections. 
    # r_x is intersection of sy and sz.
    r_x = r_function_intersection(sy, sz, alpha) + dx
    r_y = r_function_intersection(sx, sz, alpha) + dy
    r_z = r_function_intersection(sx, sy, alpha) + dz
    
    # Step 3: Lattice (Union of rods)
    lattice = r_function_union(r_x, r_y, alpha)
    lattice = r_function_union(lattice, r_z, alpha)
    
    return lattice

def microstructure_scaffold(F_func, g_func, x, y, z, lo, alpha=0):
    """
    Computes the microstructure scaffold combining external shape F and lattice g.
    F_func: function returning F(x,y,z)
    g_func: function returning g(x,y,z)
    lo: offset threshold > 0
    """
    F_val = F_func(x, y, z)
    g_val = g_func(x, y, z)
    
    # Step 1: Internal offset
    Fo_val = F_val - lo
    
    # Step 2: Shell (Subtraction)
    Fs_val = r_function_subtraction(F_val, Fo_val, alpha)
    
    # Step 3: Truncated Lattice (Intersection)
    Fg_val = r_function_intersection(g_val, F_val, alpha)
    
    # Step 4: Final Scaffold (Union)
    Fm_val = r_function_union(Fs_val, Fg_val, alpha)
    
    return Fm_val

def blending_intersection(f1, f2, alpha=0, a0=0, a1=1, a2=1):
    """
    Computes the blending intersection.
    a0 < 0 corresponds to removed material (chamfer).
    """
    base_intersection = r_function_intersection(f1, f2, alpha)
    blend_term = a0 * ((f1 / a1)**2 + (f2 / a2)**2)
    return base_intersection + blend_term
```

### Edge Cases and Pitfalls
*   **Continuity Discontinuities**: The $\alpha=1$ class functions are $C^1$ discontinuous at all points where $f_1 = f_2$ [S1]. The $\alpha=0$ class has $C^1$ discontinuity only at points where both arguments are equal to zero [S1].
*   **Lattice Continuity**: For the regular lattice using $\alpha=0$, the function is $C^1$ continuous in the entire domain except at surface edges resulting from intersection and union operations [S1].
*   **Offset Constraint**: The offset threshold $l_o$ in the microstructure combination must be positive ($l_o > 0$) to define the internal offset for the thin shell [S1].
*   **Slab Threshold**: The slab threshold $l$ must satisfy $-1 < l < 1$ [S1].

## Subtopics

### Infinite Regular Lattice Construction
A method to model infinite regular 3D lattices by defining parallel slabs using periodic trigonometric functions, intersecting them to form rods, and uniting the rods [S1]. It is chosen when a periodic, infinite cellular structure is required [S1]. It differs from finite lattice representations by being defined analytically over the entire domain [S1].

### Microstructure-External Shape Combination
A method to combine an infinite microstructure lattice with a given external object shape by creating a thin shell and intersecting the lattice with the object [S1]. It is chosen when embedding internal structures within a specific boundary [S1]. It differs from simple clipping by using R-function subtraction to maintain smooth shell thickness [S1].

### Blending Operations
A method to produce smooth transitions between surfaces instead of sharp edges by adding a displacement term to standard R-functions [S1]. It is chosen when chamfering or smoothing the edges of boolean operations is desired [S1]. It differs from standard boolean operations by introducing parameters $a_0, a_1, a_2$ to control the blend shape [S1].

## Operating characteristics

*   **Time Complexity**: Evaluation is $O(1)$ per point query, involving a constant number of trigonometric, square root, and arithmetic operations [S1]. The cost depends on the depth of the boolean tree (number of nested operations) [S1].
*   **Memory Complexity**: $O(1)$ for procedural evaluation, as no grid or mesh data is stored [S1]. Parameters are stored in constant space [S1].
*   **Measured Performance**: Not given in the sources [S1].
*   **Scaling**: The method scales well with resolution since it is procedural [S1]. However, evaluating deep boolean trees or complex lattices with many parameters increases computational cost per sample [S1].
*   **Strengths**: Compact representation, arbitrary parameterization, ability to model infinite structures, and control over continuity properties ($C^1$) [S1].
*   **Limitations**: $C^1$ discontinuities still exist at specific boundaries (edges of intersections/unions) even with $\alpha=0$ [S1]. Blending requires tuning parameters [S1].
*   **When to use**: Procedural modeling of microstructures, implicit surfaces requiring specific continuity, and infinite periodic patterns [S1].
*   **When not to use**: When explicit mesh topology is required or when exact $C^\infty$ continuity everywhere is needed without blending [G].

## Background

The method originates from the Function Representation (FRep) approach to procedural modeling, which addresses the drawbacks of Boundary Representation (BRep) and voxel-based models [S1]. R-functions were introduced by Rabinovich and later developed by Shapiro and others for implicit modeling [S1]. The specific application to microstructures and lattices using trigonometric functions was proposed in the paper "Procedural function-based modelling of volumetric microstructures" [S1]. This work builds on earlier applications of implicit surfaces to periodic structures like chess boards [S1].
