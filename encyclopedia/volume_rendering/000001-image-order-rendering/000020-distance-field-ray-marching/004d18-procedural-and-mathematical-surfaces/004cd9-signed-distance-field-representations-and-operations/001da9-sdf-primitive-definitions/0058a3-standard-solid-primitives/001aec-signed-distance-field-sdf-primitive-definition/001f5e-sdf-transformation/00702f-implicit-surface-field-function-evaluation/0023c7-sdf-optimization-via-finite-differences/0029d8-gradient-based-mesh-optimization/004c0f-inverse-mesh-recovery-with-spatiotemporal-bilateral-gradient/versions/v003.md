# Inverse Mesh Recovery with Spatiotemporal Bilateral Gradient Filtering

Also called: Edge-aware cross-bilateral filter for mesh recovery, Spatiotemporal optimizer for inverse recovery

## Overview
This method is a gradient-based optimization technique for recovering mesh geometry from multi-view images by optimizing vertex positions [S1]. It solves the problem of slow convergence and loss of sharp features (silhouettes, thin structures) in inverse rendering, which occurs when standard Laplacian smoothing dilutes sparse silhouette gradients [S1]. It sets itself apart from its parent [Gradient-Based Mesh Optimization](4628-gradient-based-mesh-optimization.md) by replacing the Laplacian postfilter with an edge-aware cross-bilateral filter that preserves values on silhouettes, enabling faster convergence on models with thin structures or many silhouettes [S1].

## How it works
The method follows the Large Steps framework [S1], but replaces the postfilter on the intermediate variable $m_t$ with a mesh cross-bilateral filter. The optimization minimizes the geometric difference between the rendered views of the current mesh and the reference multi-view images [S1].

**Inputs:**
- Reference multi-view images (depth/mask or photometric data) [S1].
- Initial mesh geometry (typically a sphere) [S1].
- Hyperparameters: learning rate $\alpha$, Adam momentum $\beta_1, \beta_2$, regularization $\lambda$, bilateral filter range parameters $\sigma_\phi, \sigma_d$ [S1].

**Outputs:**
- Optimized mesh vertex positions [S1].

**Data Structures:**
- **Mesh:** Defined by vertex positions $V \in \mathbb{R}^{3 \times N}$ and connectivity [S1].
- **Vertex Normals:** $\hat{n} \in \mathbb{R}^{3 \times N}$, computed from mesh geometry [S1].
- **Gradient Vectors:** $h \in \mathbb{R}^N$ (scalar field to be filtered, e.g., displacement or loss gradient) [S1].
- **Laplacian Matrix:** $L \in \mathbb{R}^{N \times N}$, the standard cotangent Laplacian [S1].

**Parameters:**
- $\alpha$ (learning rate): $1 \times 10^{-2}$ for cube, $3 \times 10^{-2}$ for dragon [S1].
- $\beta_1, \beta_2$ (Adam momentum): $0.9, 0.99$ [S1].
- $\lambda$ (regularization weight): $19$ [S1].
- $\sigma_\phi$ (photometric range parameter): $0.4$ [S1].
- $\sigma_d$ (spatial distance parameter): $0.5$ [S1].
- $N_{samples}$: 16 samples per pixel for forward rendering, 1 sample per pixel for gradient [S1].

**Algorithm Steps:**

1.  **Initialization:** Initialize the mesh as a sphere with approximately 10,000 vertices [S1].
2.  **Iteration Loop:** For each optimization step $t$:
    a.  **Rendering:** Render all views using the current mesh. Use 16 samples per pixel for the forward pass and 1 sample per pixel for the gradient computation [S1].
    b.  **Loss Computation:** Compute the loss using the L1 norm between the rendered output and the reference [S1].
    c.  **Gradient Update:** Compute the gradient of the loss with respect to the mesh parameters. Update the vertex positions using the UniformAdam optimizer with parameters $\beta_1=0.9, \beta_2=0.99$ and learning rate $\alpha$ [S1].
    d.  **Prefiltering:** Apply a Laplacian prefilter to the gradient/parameter update. This step is crucial for diffusing silhouette gradients [S1].
    e.  **Postfiltering (Cross-Bilateral Filter):** Apply the mesh cross-bilateral filter to the intermediate variable $m_t$ (the update or state being filtered). This replaces the Laplacian smoothing used in Large Steps [S1].
        i.  Sample $N=32$ directions $s_i \in S^2$ on the unit sphere using the Sobol sequence [S1].
        ii. Compute diagonal data matrices $W_i$ and partition of unity matrices $\Phi_i$ for each direction $s_i$ [S1].
        iii. Construct the matrix $M$ by concatenating vectors $W_i h$ and $W_i \mathbf{1}$ [S1].
        iv. Solve the linear system $(I + \lambda L) X = M$ for $X$ [S1].
        v.  Compute the filtered result $\tilde{h}$ using component-wise operations on $X$ [S1].
    f.  **Optional Postfilter on $v_t$:** In ablation studies, applying a bilateral filter on the intermediate variable $v_t$ (along with UniformAdam infinity norm) was found to perform well, though it may cause small cracks on sharp edges [S1].
    g.  **Learning Rate Schedule:** Apply an exponential learning rate scheduler that reduces the learning rate to a factor of 0.6 at the end of the optimization [S1].
3.  **Upsampling (Conditional):** For models with thin structures (e.g., dragon), upsample the mesh at specific iterations (10, 30, 60) by remeshing to reduce the average edge length by a factor of 2. Models with sharp edges but no thin structures (e.g., cube) do not require remeshing [S1].

**Cross-Bilateral Filter Formula:**
The filtered vector $\tilde{h}$ is computed as:
$$
\tilde{h} = \frac{\sum_{i=1}^N \Phi(\hat{n}, s_i) (I + \lambda L)^{-1} W(\hat{n}, s_i) h}{\sum_{i=1}^N \Phi(\hat{n}, s_i) (I + \lambda L)^{-1} W(\hat{n}, s_i) \mathbf{1}}
$$
where:
- $h$ is the vector to be filtered.
- $\mathbf{1}$ is the vector of ones.
- $W_i = W(\hat{n}, s_i)$ is the diagonal data matrix with elements $\exp(\hat{n} \cdot s_i / \sigma_d)$ [S1].
- $\Phi_i = \Phi(\hat{n}, s_i)$ is the diagonal partition of unity matrix with elements $\exp(\hat{n} \cdot s_i / \sigma_\phi)$ [S1].
- $L$ is the Laplacian matrix [S1].
- $\lambda$ is the regularization parameter [S1].
- $N=32$ is the number of sampled directions [S1].

**Efficient Implementation:**
To avoid $N$ separate matrix solves, concatenate the vectors $W_i h$ and $W_i \mathbf{1}$ into a single matrix $M \in \mathbb{R}^{N \times 2N}$:
$$
M = \left[ \begin{array}{c|c} W_1 h & W_1 \mathbf{1} \\ \vdots & \vdots \\ W_N h & W_N \mathbf{1} \end{array} \right]
$$
Compute $X = (I + \lambda L)^{-1} M$ using a single matrix solve (e.g., Cholesky decomposition) [S1]. The final $\tilde{h}$ is obtained by component-wise division of the first $N$ columns of $X$ by the second $N$ columns, weighted by $\Phi_i$ [S1].

**Pitfalls:**
- Laplacian preconditioning smooths gradients at silhouettes, causing them to be diluted. This is problematic for models with thin structures and many silhouettes (e.g., dragon), as vertices near but not on silhouettes receive no silhouette gradients, and Laplacian smoothing dilutes the values on the silhouette vertices [S1].
- Using a bilateral filter on $v_t$ can cause small cracks in the edges due to aggressive updates, although it provides comparable convergence to the proposed method on cubes [S1].

import torch

def compute_cross_bilateral_filter(h, normals, L, lambda_reg, sigma_phi, sigma_d, num_directions=32):
    """
    Compute the mesh cross-bilateral filter efficiently using a single matrix solve.
    
    Args:
        h: Tensor (V,) - vector to be filtered (m_t)
        normals: Tensor (V, 3) - vertex normals
        L: Tensor (V, V) - Laplacian matrix
        lambda_reg: float - regularization parameter
        sigma_phi: float - photometric range parameter
        sigma_d: float - spatial distance parameter
        num_directions: int - number of Sobol directions (default 32)
        
    Returns:
        h_tilde: Tensor (V,) - filtered vector
    """
    V = h.shape[0]
    
    # 1. Sample directions on unit sphere using Sobol sequence [S1]
    sobol = torch.quasirandom.SobolEngine(3, scramble=True)
    raw = sobol.draw(num_directions)
    directions = raw * 2 - 1  # Map to [-1, 1]
    directions = directions / (torch.norm(directions, dim=1, keepdim=True) + 1e-8)  # Normalize
    
    # 2. Compute weights for each direction [S1]
    # normals: (V, 3), directions: (num_directions, 3) -> dots: (V, num_directions)
    dots = torch.matmul(normals, directions.T)
    
    # W_i diagonal elements: exp(n_hat . s_i / sigma_d)
    W = torch.exp(dots / sigma_d)
    
    # Phi_i diagonal elements: exp(n_hat . s_i / sigma_phi)
    Phi = torch.exp(dots / sigma_phi)
    
    # 3. Construct matrix M = [W_1 h ... W_N h | W_1 1 ... W_N 1]
    # W_h: (V, num_directions) where col i = W[:, i] * h
    W_h = h.unsqueeze(1) * W
    # W_1: (V, num_directions) where col i = W[:, i]
    W_1 = W
    M = torch.cat([W_h, W_1], dim=1)
    
    # 4. Solve (I + lambda * L) * X = M using Cholesky [S1]
    A = torch.eye(V, device=h.device) + lambda_reg * L
    try:
        L_chol = torch.linalg.cholesky(A)
        X = torch.linalg.cho_solve((L_chol, True), M)
    except RuntimeError:
        X = torch.linalg.solve(A, M)
        
    # 5. Compute h_tilde = sum(Phi_i * X[:, i]) / sum(Phi_i * X[:, N+i])
    numerator = torch.sum(Phi * X[:, :num_directions], dim=1)
    denominator = torch.sum(Phi * X[:, num_directions:], dim=1)
    denominator = torch.clamp(denominator, min=1e-8)
    
    return numerator / denominator

## Subtopics

### Bilateral gradient filtering for meshes
This is the core filtering mechanism used in the method. It replaces the postfilter on $m_t$ with a cross-bilateral filter using vertex normals $\hat{n}$ for the data term. It samples $N=32$ directions $s_i \in S^2$ on the unit sphere using the Sobol sequence. It computes the filter efficiently by concatenating vectors $W(\hat{n}, s_i)h$ and $W(\hat{n}, s_i)\mathbf{1}$ into matrix $M = [W(\hat{n}, s_1)h \dots W(\hat{n}, s_N)h \mid W(\hat{n}, s_1)\mathbf{1} \dots W(\hat{n}, s_N)\mathbf{1}]$, then computing $(I + \lambda L)^{-1} M$ using a single matrix solve. The filtered result is $\tilde{h} = \frac{\sum_{i=1}^N \Phi(\hat{n}, s_i) (I+\lambda L)^{-1} W(\hat{n}, s_i) h}{\sum_{i=1}^N \Phi(\hat{n}, s_i) (I+\lambda L)^{-1} W(\hat{n}, s_i) \mathbf{1}}$. The diagonal elements of $W_i$ are computed using the von Mises-Fisher kernel $\exp(\hat{n} \cdot s_i / \sigma_d)$, and $\Phi_i$ using $\exp(\hat{n} \cdot s_i / \sigma_\phi)$ [S1].

## Operating characteristics
- **Time Complexity:** The cross-bilateral filter requires solving a linear system $(I + \lambda L)^{-1} M$. The overhead over Large Steps (which uses Laplacian smoothing) is minor (<10%) [S1].
- **Memory Complexity:** Requires storing the Laplacian matrix $L$ and the matrix $M$ of size $N \times 2K$ [S1].
- **Performance:** On an NVIDIA GeForce RTX 3080 GPU, the method converges faster than Large Steps on models with thin structures and many silhouettes (e.g., dragon) [S1].
- **Strengths:** Preserves sharp edges and silhouettes better than Laplacian smoothing. Faster convergence on thin structures. Low overhead [S1].
- **Limitations:** Introduces two new hyperparameters ($\sigma_\phi, \sigma_d$) that require tuning. Assumes spatial coherence in parameters. Bilateral filtering on $v_t$ can cause small cracks on sharp edges [S1].
- **When to use:** When recovering meshes with thin structures, many silhouettes, or sharp edges where Laplacian smoothing dilutes gradients [S1].
- **When not to use:** When parameters lack obvious spatial coherence [S1].

## Background
The method was introduced in the paper "Spatiotemporal Bilateral Gradient Filtering for Inverse Rendering" [S1]. It builds on the Large Steps framework [S1], which uses Laplacian smoothing and an infinity norm as filters. The authors found that Laplacian preconditioning smooths gradients at silhouettes, causing them to be diluted, which is problematic for models with thin structures [S1]. The proposed method replaces the postfilter with a mesh cross-bilateral filter, inspired by the generalized bilateral filter from Solomon et al. [2014] [S1]. The implementation uses PyTorch [Paszke et al. 2019] and Mitsuba 3 [Jakob et al. 2022] [S1].
