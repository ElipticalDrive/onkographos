# Basic Primitive Definitions


## Overview
Basic Primitive Definitions provide the foundational analytical functions that compute the exact Euclidean signed distance from a query point to standard geometric shapes, serving as the atomic building blocks for distance-field ray marching [S11, unofficial]. They replace explicit mesh geometry with implicit mathematical definitions, enabling safe, large step sizes along rays by leveraging the continuous scalar field where the sign indicates interior ($d < 0$) or exterior ($d > 0$) status [G]. Unlike polygonal primitives or iterative approximations, these primitives rely on closed-form algebraic solutions for standard shapes like spheres, boxes, and tori [S11, unofficial].

## How it works
**Inputs and Outputs:** The function takes a query point $p \in \mathbb{R}^3$ and primitive parameters (e.g., radius $r$, half-extents $b$, major/minor radii $R, r_t$). It outputs a scalar signed distance $d \in \mathbb{R}$.

**Canonical Placement:** Primitives are defined in a local coordinate system centered at the origin $(0,0,0)$ and axis-aligned where applicable [G].

**Transformation:** To render a primitive at a different position, rotation, or scale, the query point $p$ is transformed into the primitive's local space (inverse transformation) before evaluation, or the primitive parameters are adjusted accordingly [S11, unofficial].

**Signed Output:** The function returns a scalar $d \in \mathbb{R}$. $d < 0$ indicates the point is inside the primitive, $d > 0$ indicates it is outside, and $d = 0$ lies on the surface [S11, unofficial].

**Gradient Availability:** The functions are differentiable almost everywhere, allowing for the computation of surface normals via the gradient $\nabla d$ [G].

**Formulas:**
- **Sphere** (radius $r$): $d(p, r) = \|p\| - r$ [S1, S2, S5, S6, S10, unofficial].
- **Box** (axis-aligned, centered at origin, half-extents $b$): $q = |p| - b$; $d(p, b) = \|\max(q, 0)\| + \min(\max(q_x, \max(q_y, q_z)), 0)$ [S1, S2, S5, S6, S10, unofficial].
- **Torus** (major radius $R$, minor radius $r_t$): $q = (\sqrt{p_x^2 + p_z^2} - R, p_y)$; $d(p, R, r_t) = \|q\| - r_t$ [S1, S2, S7, S9, S10, unofficial].
- **Plane** (unit normal $n$, offset $d_{\text{offset}}$): $d(p, n) = p \cdot n + d_{\text{offset}}$ [S3, S7, S11, unofficial].
- **Cylinder** (radius $r$, half-height $h$, aligned with Y-axis): $d = (|\sqrt{p_x^2 + p_z^2}| - r, |p_y| - h)$; $d(p) = \min(\max(d_x, d_y), 0) + \|\max(d)\|$ [S7, S11, unofficial].
- **Capsule** (endpoints $a, b$, radius $r$): $ba = b - a$, $pa = p - a$; $h = \max(0, \min(1, \frac{pa \cdot ba}{ba \cdot ba}))$; $d(p) = \|pa - ba \cdot h\| - r$ [S7, S11, unofficial].

**Parameters:** Typical parameters include radius $r \in \mathbb{R}^+$, half-extents $b \in \mathbb{R}^3$, and major/minor radii $R, r_t \in \mathbb{R}^+$.

**Edge Cases and Pitfalls:** Degenerate inputs (e.g., zero radius) require guards to avoid division by zero or invalid geometry. Precision issues near $d=0$ can cause ray marching artifacts; a small epsilon threshold is typically used for convergence [G].

## Subtopics

### [Ellipsoid Signed Distance Function](2397-ellipsoid-signed-distance-function.md)
Computes the signed distance from a 3D point to an ellipsoid defined by semi-axes radii, or to a 2D disk (a degenerate ellipsoid with one radius set to zero) for handling non-watertight surfaces like walls. It distinguishes itself from the [Sphere Signed Distance Function](1237-sphere-signed-distance-function.md) by supporting anisotropic scaling, and from the [Signed Box Distance Function](1092-signed-box-distance-function.md) by providing smooth, analytic curvature [G]. Two variants exist: a fast approximation and a more accurate iterative-free formula.

### [Capsule Signed Distance Function](2439-capsule-signed-distance-function.md)
The Capsule Signed Distance Function computes the exact Euclidean distance from a query point in 3D space to the surface of a capsule, defined as a line segment with a constant radius. It represents smooth, rounded tubular geometry for ray marching and volume rendering without polygonal approximation [G]. It is distinguished from the [Sphere SDF](1237-sphere-signed-distance-function.md) by its linear axis and from the [Box SDF](1092-box-sdf.md) by its cylindrical symmetry and hemispherical ends [G].

### [Polyhedral Primitives](2529-polyhedral-primitives.md)
Polyhedral primitives compute the exact Euclidean signed distance from a query point to the surface of convex polyhedra, enabling precise ray marching and collision detection for shapes with flat faces and sharp edges [G]. They are distinguished from smooth primitives (like spheres) by their piecewise-linear geometry and from implicit surfaces by their reliance on symmetry folding or explicit face/edge projections to resolve the distance analytically [G].

### [Cone Signed Distance Function](2594-cone-signed-distance-function.md)
The Cone Signed Distance Function computes the exact Euclidean distance from a query point to the surface of a cone, defined by a base radius and height, with a sign indicating whether the point lies inside or outside the volume. It solves the problem of efficiently rendering or querying conical primitives in ray marching and implicit surface modeling without approximation errors associated with polygonal meshes. It is distinguished from the [Segment Signed Distance Function](2679-segment-signed-distance-function.md) by its continuous lateral surface and from [Polyhedral Primitives](2529-polyhedral-primitives.md) by its smooth, non-polyhedral geometry.

### [Segment Signed Distance Function](2679-segment-signed-distance-function.md)
The Segment Signed Distance Function computes the Euclidean distance from a query point to a finite line segment defined by two endpoints. It solves the problem of determining proximity to 1D geometric primitives in 3D space, serving as the foundational building block for more complex shapes like capsules and tubes. It differs from infinite line distance functions by clamping the projection parameter to the segment bounds, ensuring the result is zero if the point lies on the segment and correctly handling points projecting outside the endpoints.

### [Arc Signed Distance Function](3922-arc-signed-distance-function.md)
Computes the signed distance from a 3D point to a tube of radius `arc_tube_radius` running along a circular arc defined by a center, orientation, aperture, and radii `ra` and `rb`.

### [Basic Geometric Primitives](23026-basic-geometric-primitives.md)
Basic Geometric Primitives provide the foundational signed distance functions (SDFs) for common shapes—specifically the Sphere, Box, and Plane—used in distance-field ray marching and constructive solid geometry (CSG). They differ from complex or derived primitives (such as Capsules or Tori) by offering closed-form, exact Euclidean distance calculations with minimal computational overhead, serving as the atomic building blocks for procedural modeling.

### Rhombic Triacontahedron SDF
A Signed Distance Function for a Rhombic Triacontahedron crystal shape, constructed by folding 3D space using specific magic numbers and directions multiple times [S12, unofficial]. Initialize magic numbers: $c = \cos(\pi/5)$, $s = \sqrt{0.75 - c^2}$, and direction $n = (-0.5, -c, s)$ [S12, unofficial]. First fold: take absolute value of $p$ ($p = |p|$), then fold along $n$: $p \leftarrow p - 2 \cdot \min(0, p \cdot n) \cdot n$ [S12, unofficial]. Second fold: take absolute value of $p_{xy}$ ($p_{xy} = |p_{xy}|$), then fold along $n$: $p \leftarrow p - 2 \cdot \min(0, p \cdot n) \cdot n$ [S12, unofficial]. Third fold: take absolute value of $p_{xy}$ ($p_{xy} = |p_{xy}|$), then fold along $n$: $p \leftarrow p - 2 \cdot \min(0, p \cdot n) \cdot n$ [S12, unofficial]. Compute distance: return $p_z - 1$ as the signed distance to the surface [S12, unofficial].

### Inverted Torus Rendering
Renders the torus interior tube as empty space by negating the torus SDF, enabling natural front-to-back occlusion and eliminating donut-hole artifacts [S13, unofficial]. Negate torus SDF: `return -(d_ring - r)`. Treat negative SDF as empty space (tube cavity), positive SDF as solid (donut hole, outside) [S13, unofficial]. Ray march naturally finds tube interior [S13, unofficial]. Prevents donut-hole artifacts by ensuring ray marching only operates inside the tube cavity [S13, unofficial].

### Butterfly SDF Primitives
Signed Distance Field functions for the butterfly's components: `sdWing` for the flapping wings, `sdBody` for the thorax/abdomen, and `sdAntenna` for the antennae. These are combined in `mapButterfly` to return the minimum distance and material ID [S14, unofficial]. Wing SDF logic un-bends the point to wing space, checks the outline, and calculates thickness and camber to form a slab [S14, unofficial]. Body SDF logic uses a parametric radius function based on normalized Z coordinate `u` [S14, unofficial]. Antenna SDF logic uses a quadratic bezier-like curve `c` for the spine and varying radius [S14, unofficial].

### Death Star SDF Primitive
Construct Death Star using `sdDeathStar` primitive with radii $r_a=5.0$, $r_b=2.0$, $d=6.0$, offset $(0,0,0)$, and rotation $\text{rotateX}(0.5) \times \text{rotateY}(1.5 + \sin(u_{\text{time}}/7.0))$ [S15, unofficial].

### Spherical Signed Distance Field
A structure used to represent visibility by encoding the signed distance to the boundary of the occluded region in the sphere [S16, unofficial].

### Superellipsoid Primitives
Uses superellipsoids and a 'slice-27 grid' (3D equivalent of Flash's slice-9 grids) for geometry primitives, allowing rounded 3D shapes with customizable corners [S17, unofficial]. Specify primitive properties: corner distance (independently for xyz), wall thickness, or bounding box for visible region [S17, unofficial]. Combine primitives using Voronoi style distance (typically clamped to xy or ground plane) or advanced boolean intersections with material priority [S17, unofficial]. Apply volumetric texturing in object space with automatically generated texture coordinates measured in meters to scale independently of voxel size [S17, unofficial]. Generate UVW coordinates along length, height, and depth (into walls) [S17, unofficial]. Assign special material IDs for distinct normal generation (e.g., distinct boards) [S17, unofficial].

## Background
The specific implementations for basic primitives (sphere, box, torus) are standard in the computer graphics community for implicit modeling and collision detection [S9, unofficial]. The inverted torus technique for rendering tube-like structures without artifacts is documented in specific GPU implementation guides [S13, unofficial]. Butterfly and superellipsoid variants represent specialized applications in procedural generation and voxel-based world generation [S14, unofficial][S17, unofficial].
