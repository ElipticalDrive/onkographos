# CSG Distance Field Evaluation (Single Point)
## Overview
A recursive algorithm to compute the signed distance from a single point to a Constructive Solid Geometry (CSG) tree, supporting Union, Intersection, Difference, Replace, Translation, Rotation, Plane, Cylinder, Sphere, and Box primitives [S1, unofficial]. It differs from the batched variant by operating on a single coordinate vector and returning a scalar distance, serving as the fundamental evaluation kernel for ray marching or point-in-solid tests [S1, unofficial].
## How it works
### Inputs and outputs
- **Input**: `pos` (3D point, `vec3f`), `node` (pointer to CSG node structure), `box` (axis-aligned bounding box, `aabb`, used for culling).
- **Output**: `float` signed distance. Returns `FLT_MAX` if the point is outside the node's bounding box or if the node is empty.

### Data structures
The algorithm assumes a node structure `n` with a type field `n->type` and child pointers or primitive data:
- `n->type`: Enum indicating the operation (`C_UNION`, `C_INTERSECTION`, `C_DIFFERENCE`, `C_REPLACE`, `C_TRANSLATION`, `C_ROTATION`, `C_PLANE`, `C_CYLINDERXZ`, `C_CYLINDERXY`, `C_CYLINDERYZ`, `C_SPHERE`, `C_BOX`, `C_EMPTY`).
- `n->left`, `n->right`: Pointers to child nodes for binary operations.
- `n->n`: Pointer to child node for unary operations (Translation, Rotation, Replace).
- Primitive data fields (e.g., `p->p` for plane normal/w, `c->cCOORD` for cylinder axis/center, `s->r` for sphere radius, `box.extent` for box half-extents).

### Steps
1. **Culling**: Compute the intersection of the query `box` with the node's bounding box `n->box`. Let `isec` be the intersection box. If `any(gt(isec.pmin, isec.pmax))`, return `FLT_MAX` [S1, unofficial].
2. **Dispatch**: Based on `n->type`, perform the following:
   - **Union (`C_UNION`)**: Return `min(dist(u->left, pos, box), dist(u->right, pos, box))` [S1, unofficial].
   - **Intersection (`C_INTERSECTION`)**: Return `max(dist(i->left, pos, box), dist(i->right, pos, box))` [S1, unofficial].
   - **Difference (`C_DIFFERENCE`)**: Return `max(dist(d->left, pos, box), -dist(d->right, pos, box))` [S1, unofficial].
   - **Replace (`C_REPLACE`)**: Return `dist(r->left, pos, box)` [S1, unofficial].
   - **Translation (`C_TRANSLATION`)**: Let `t` be the translation vector `t->p`. Return `dist(t->n, pos - t->p, aabb(box.pmin - t->p, box.pmax - t->p))` [S1, unofficial].
   - **Rotation (`C_ROTATION`)**: Let `r->q` be the rotation quaternion. Compute `pos_rot = xfmpoint(conj(r->q), pos)`. Return `dist(r->n, pos_rot, aabb::all())` [S1, unofficial].
   - **Plane (`C_PLANE`)**: Let `p->p` be the plane equation `ax + by + cz + w = 0`. Return `dot(pos, p->p.xyz()) + p->p.w` [S1, unofficial].
   - **Cylinder (`C_CYLINDERXZ`, `C_CYLINDERXY`, `C_CYLINDERYZ`)**: Let `c->cCOORD` be the axis-aligned center point and `c->r` be the radius. The function `pos.COORD()` selects the two coordinates perpendicular to the cylinder axis. Return `length(pos.COORD() - c->cCOORD) - c->r` [S1, unofficial].
   - **Sphere (`C_SPHERE`)**: Let `s->r` be the radius. Return `length(pos) - s->r` [S1, unofficial].
   - **Box (`C_BOX`)**: Let `box.extent` be the half-extents. Compute `d = abs(pos) - box.extent`. Return `min(max(d.x, max(d.y, d.z)), 0.0f) + length(max(d, vec3f(0.0f)))` [S1, unofficial].
   - **Empty (`C_EMPTY`)**: Return `FLT_MAX` [S1, unofficial].

### Pseudocode
```python
import math

def dist(pos, node, box):
    """
    Compute signed distance from pos to the CSG tree rooted at node.
    box: AABB used for culling.
    """
    # Step 1: Culling
    # Compute intersection of box and node's bounding box n->box
    # isec.pmin = max(box.pmin, node.box.pmin)
    # isec.pmax = min(box.pmax, node.box.pmax)
    # If any component of isec.pmin > isec.pmax, return FLT_MAX
    if any(isec.pmin > isec.pmax):
        return float('inf')

    n = node
    t = n.type

    if t == C_UNION:
        return min(dist(pos, n.left, box), dist(pos, n.right, box))
    elif t == C_INTERSECTION:
        return max(dist(pos, n.left, box), dist(pos, n.right, box))
    elif t == C_DIFFERENCE:
        return max(dist(pos, n.left, box), -dist(pos, n.right, box))
    elif t == C_REPLACE:
        return dist(pos, n.left, box)
    elif t == C_TRANSLATION:
        # t->p is the translation vector
        new_pos = pos - n.p
        new_box_min = box.pmin - n.p
        new_box_max = box.pmax - n.p
        new_box = AABB(new_box_min, new_box_max)
        return dist(new_pos, n.n, new_box)
    elif t == C_ROTATION:
        # r->q is the rotation quaternion
        # xfmpoint applies quaternion conjugate rotation to point
        pos_rot = xfmpoint(conj(n.q), pos)
        # aabb::all() implies an infinite or sufficiently large box
        return dist(pos_rot, n.n, AABB.infinite())
    elif t == C_PLANE:
        # p->p is a vec4f representing ax+by+cz+w
        return dot(pos, n.p.xyz()) + n.p.w
    elif t in (C_CYLINDERXZ, C_CYLINDERXY, C_CYLINDERYZ):
        # c->cCOORD is the center point on the axis
        # c->r is the radius
        # pos.COORD() selects the 2D coordinates perpendicular to the axis
        center_2d = pos.COORD() - n.cCOORD.COORD()
        return length(center_2d) - n.r
    elif t == C_SPHERE:
        return length(pos) - n.r
    elif t == C_BOX:
        # box.extent is vec3f of half-extents
        d = abs(pos) - n.extent
        return min(max(d.x, max(d.y, d.z)), 0.0f) + length(max(d, vec3f(0.0f)))
    elif t == C_EMPTY:
        return float('inf')
    else:
        # Unknown type
        return float('inf')

def xfmpoint(q, p):
    """Apply quaternion rotation q to point p. q is assumed normalized."""
    # Standard quaternion rotation: p' = q * p * q^-1
    # For unit quaternion, q^-1 = conj(q)
    # Implementation depends on vector/quaternion library conventions.
    # Here we assume a standard implementation.
    t = 2.0 * cross(q.xyz(), p)
    return p + q.w * t + cross(t, q.xyz())

def conj(q):
    return vec4f(q.x, -q.y, -q.z, q.w)
```

### Parameters and Edge Cases
- **Precision**: Floating-point precision issues may arise near the surface of primitives. The box SDF formula is robust but relies on correct `extent` values [S1, unofficial].
- **Boundaries**: The culling step is critical for performance. If the bounding box intersection is invalid (empty), the recursion stops immediately [S1, unofficial].
- **Degenerate Input**: Empty nodes return `FLT_MAX`. Primitives with zero radius or extent may produce incorrect distances if not handled, though standard SDF formulas generally handle zero-size primitives gracefully (e.g., sphere radius 0 returns distance to origin) [S1, unofficial].

## Operating characteristics
- **Time Complexity**: O(N) in the worst case, where N is the number of nodes in the CSG tree, as it may traverse the entire tree. Pruning via bounding box culling reduces average case complexity.
- **Memory Complexity**: O(D) where D is the depth of the CSG tree, due to recursion stack.
- **Strengths**: Simple, recursive structure; supports complex CSG operations; efficient culling.
- **Limitations**: Single-point evaluation; no batch optimization; recursion depth limits for very deep trees.
- **When to use**: When evaluating distance for a single point is sufficient, or as a kernel for batched evaluation.

## Background
The algorithm is described in the `mini.q` repository by bsegovia [S1, unofficial]. It is a standard implementation of CSG operations on Signed Distance Fields, commonly used in ray marching and implicit surface rendering.
