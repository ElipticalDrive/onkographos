# Segment Signed Distance Function

Also called: Segment SDF, sdSegment, Distance to line segment

## Overview
Computes the Euclidean distance from a query point $p$ to a line segment defined by endpoints $a$ and $b$ [S1, unofficial][S3, unofficial]. It differs from infinite line distance by clamping the projection parameter to the segment bounds, ensuring the result is zero if the point lies on the segment [S3, unofficial]. This method serves as the geometric core for signed distance field (SDF) primitives in ray marching [S3, unofficial]. It builds on [Basic Primitive Definitions](5346-basic-primitive-definitions.md).

## How it works
**Inputs and Outputs:**
*   **Input:** Query point $p \in \mathbb{R}^3$ (or $\mathbb{R}^2$ depending on implementation context), segment endpoints $a, b \in \mathbb{R}^3$ (or $\mathbb{R}^2$).
*   **Output:** Scalar signed distance $d \in \mathbb{R}$. $d < 0$ indicates the point is inside the primitive, $d > 0$ indicates it is outside, and $d = 0$ lies on the surface [S1, unofficial].

**Assumptions:**
All implementations assume the primitive is centered at the origin and axis-aligned where applicable. Transformations (rotation, translation, scaling) are applied to the query point $p$ before evaluation, or the primitive parameters are adjusted accordingly [S1, unofficial].

**Data Structures:**
*   Point/Vector: A structure or type supporting subtraction, dot product, length (norm), and scalar multiplication. Commonly `vec2` or `vec3` in GLSL/HLSL, or `Vec2`/`Vec3` in Rust/C++.

**Steps:**
1.  Compute the segment vector: $ab = b - a$.
2.  Compute the vector from the first endpoint to the query point: $ap = p - a$.
3.  Compute the squared length of the segment: $len\_sq = ab \cdot ab$.
4.  Determine the projection parameter $t$:
    *   If $len\_sq > \epsilon$ (where $\epsilon$ is a small threshold, e.g., $10^{-12}$ or $10^{-8}$ depending on implementation precision):
        $$t = \text{clamp}\left(\frac{ap \cdot ab}{len\_sq}, 0.0, 1.0\right)$$
    *   Else (degenerate segment, effectively a point):
        $$t = 0.0$$
5.  Compute the closest point on the segment: $closest = a + ab \cdot t$.
6.  Return the distance: $d = \| p - closest \|$.

**Formula:**
An equivalent formulation using normalized direction and clamped length [S2, unofficial]:
$$v = \frac{b - a}{\| b - a \|}$$
$$l = \text{clamp}(v \cdot (p - a), 0, \| b - a \|)$$
$$d = \| p - a - l \cdot v \|$$

**Parameters:**
*   $p$: Query point.
*   $a, b$: Segment endpoints.
*   $\epsilon$: Epsilon for floating-point comparison and degenerate segment detection. Typical values: $10^{-12}$ for squared length checks [S3, unofficial], $10^{-8}$ for direct distance comparisons [S4, unofficial].

**Edge Cases and Pitfalls:**
*   **Degenerate Segment:** If $a \approx b$, the segment length is near zero. Division by zero must be avoided. The sources handle this by checking if $len\_sq$ is below a threshold and defaulting $t$ to 0.0 [S3, unofficial][S4, unofficial].
*   **Precision:** Use squared lengths for comparisons to avoid square root operations until the final distance calculation [S3, unofficial].

**Pseudocode:**
```python
def sd_segment(p, a, b, epsilon=1e-12):
    """
    Computes the signed distance from point p to the segment [a, b].
    Assumes p, a, b are vectors with dot(), subtract(), and length() methods.
    Returns a scalar distance.
    """
    # 1. Vector from a to b
    ab = b - a
    
    # 2. Vector from a to p
    ap = p - a
    
    # 3. Squared length of segment
    len_sq = ab.dot(ab)
    
    # 4. Projection parameter t
    if len_sq > epsilon:
        # Clamp t to [0, 1]
        t = max(0.0, min(1.0, ap.dot(ab) / len_sq))
    else:
        # Degenerate segment (point)
        t = 0.0
        
    # 5. Closest point on segment
    closest = a + ab * t
    
    # 6. Distance
    dist_vec = p - closest
    return dist_vec.length()
```

## Subtopics

### [Line Segment Distance](3058-line-segment-distance.md)
Computes the Euclidean distance from a query point `p` to a line segment defined by endpoints `l0` and `l1`. It differs from infinite line distance by clamping the projection parameter to the segment bounds, ensuring the result is zero if the point lies on the segment. This method serves as the geometric core for signed distance field (SDF) primitives in ray marching.

### Point on Segment Check
Checks if point Q lies on the line segment between Pi and Pj using distance comparison with epsilon tolerance.
**Steps:**
1. Calculate distances $dis1$ (Pi to Q), $dis2$ (Pj to Q), and $dis3$ (Pi to Pj).
2. If $dis3 + \epsilon < dis1 + dis2$, return false (Q is not on segment).
3. Otherwise, return true.
**Parameters:**
*   $\epsilon$: Epsilon for floating point comparison, defined as $10^{-8}$ [S4, unofficial].

### Point-to-Segment Distance
Computes the closest point on a line segment $[v0, v1]$ to a query point $p$. The result lies on the closed segment by clamping the parameter $t$ to $[0, 1]$. [S5]

### Capsule Signed Distance Function — 2D Capsule SDF
Signed distance to a 2D capsule (stadium) between points `a` and `b` with radius `r`. Formula: $\text{segment}(p, a, b) - r$. [S3, unofficial]

## Operating characteristics
*   **Time Complexity:** $O(1)$. The calculation involves a constant number of vector operations (subtraction, dot product, clamp, length).
*   **Memory Complexity:** $O(1)$. No auxiliary data structures are required.
*   **Strengths:** Extremely fast evaluation, suitable for real-time ray marching and SDF rendering. Handles degenerate cases gracefully.
*   **Limitations:** Only applies to linear segments. For complex shapes, multiple segments or higher-order primitives are needed.
*   **When to use:** When rendering thin structures, wires, or as a component of more complex primitives (like capsules or tubes).
*   **When not to use:** When the geometry is not well-approximated by a line segment, or when higher-order continuity is required without additional smoothing.

## Background
The segment SDF is a fundamental building block in procedural geometry and ray marching. It is widely used in shaders and real-time rendering engines. The implementation details are found in various open-source graphics repositories and libraries [S1, unofficial][S2, unofficial][S3, unofficial][S4, unofficial][S5]. The concept of clamping the projection parameter to the segment bounds is standard in computational geometry for distance queries to line segments.
