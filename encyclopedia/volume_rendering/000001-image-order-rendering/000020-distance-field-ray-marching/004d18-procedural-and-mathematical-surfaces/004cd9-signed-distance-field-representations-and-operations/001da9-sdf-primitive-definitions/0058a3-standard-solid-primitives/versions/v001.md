# Standard Solid Primitives

Also called: Canonical SDFs, Basic SDF Primitives, Natural Quadrics

## Overview
Standard Solid Primitives are closed-form analytical Signed Distance Functions (SDFs) for canonical 3D shapes, serving as the foundational building blocks for procedural geometry in distance-field ray marching. They solve the problem of defining scene geometry without explicit mesh tessellation by providing conservative distance estimates that guarantee ray step sizes will not overshoot surfaces [S1, unofficial]. Unlike [Constructive SDF Modeling (Min Combination)](871-constructive-sdf-modeling-min-combination.md) which combines primitives, this method focuses on the base analytical definitions of canonical shapes (spheres, boxes, tori, etc.) and their immediate geometric properties [G].

## Shared principles
All standard solid primitives share the following mechanism and mathematical properties:

1.  **Input/Output Contract**: The function takes a 3D query point $p = (p_x, p_y, p_z)$ and primitive-specific parameters (e.g., radius $r$, center $c$, half-extents $b$). It returns a scalar float $d = \text{SDF}(p)$ .
2.  **Sign Convention**: The sign of $d$ indicates the point's location relative to the surface:
    *   $d < 0$: The point is inside the object.
    *   $d = 0$: The point is on the surface.
    *   $d > 0$: The point is outside the object .
3.  **Euclidean Distance**: The magnitude $|d|$ represents the shortest Euclidean distance from $p$ to the nearest point on the surface .
4.  **Lipschitz Bound**: For exact SDFs, the ray can safely advance by $|d(p)|$ in each step of the ray marching loop without overshooting the surface .
5.  **Coordinate Transformation**: If a primitive is transformed (rotated, translated, scaled), the inverse transformation is applied to the query point $p$ before evaluation. For a transformation matrix $M$, compute $p' = M^{-1} p$. Non-uniform scaling requires distance compensation .
6.  **Normal Approximation**: Surface normals $n$ are approximated via central finite differences with step size $\epsilon$ (typically $0.0001$) :
    $$ n = \text{normalize}\left( \begin{bmatrix} \text{SDF}(p + (\epsilon, 0, 0)) - d \\ \text{SDF}(p + (0, \epsilon, 0)) - d \\ \text{SDF}(p + (0, 0, \epsilon)) - d \end{bmatrix} \right) $$

## Subtopics

### [Signed Distance Field (SDF) Primitive Definition](890-signed-distance-field-sdf-primitive-definition.md)
A method for representing 3D geometry using closed-form analytical functions that return the shortest Euclidean distance from any query point to the nearest surface. It solves the problem of defining scene geometry for ray marching by providing a conservative distance estimate. Unlike [Constructive SDF Modeling (Min Combination)](871-constructive-sdf-modeling-min-combination.md) which combines primitives, this method focuses on the base analytical definitions of canonical shapes.

### [Distance to Natural Quadrics](1559-distance-to-natural-quadrics.md)
Provides exact signed distance functions for standard solid modeling primitives—specifically planes, spheres, cylinders, cones, and tori—aligned with canonical axes and centered at the origin. It solves the problem of querying the Euclidean distance from a point to these surfaces for use in distance-field ray marching and constructive solid geometry. Unlike generic implicit surface solvers, these closed-form solutions are computationally efficient and serve as the foundational building blocks for more complex shapes, blends, and deformations.

### Cylindrical SDF Primitives
A technique for rendering implicit geometry defined by SDFs using ray marching, specifically for cap cylinder shapes [S1, unofficial].
*   **Definition**: The core function `capCylinder` computes the distance to a capped cylinder. Given point $p$, radius $r$, and half-height $h$, it computes $d = \text{abs}(\text{vec2f}(\text{length}(p.yz), p.x)) - \text{vec2}(r, h)$ and returns $\text{min}(\text{max}(d.x, d.y), 0.) + \text{length}(\text{max}(d, \text{vec2f}(0.)))$ [S1, unofficial].
*   **Usage**: Used to define outer and inner cylinders (e.g., for light sources) by translating the query point and adjusting radii [S1, unofficial].
*   **Normal Calculation**: Normals are calculated using finite differences with step $h=0.001$ and kernel $k=\text{vec2f}(1, -1)$, summing contributions from four offset samples [S1, unofficial].
*   **Ray Marching**: The loop initializes $d = \text{map}(pp)$, $t = \text{abs}(d)$, and iterates while $d > 0.001$, updating $t += \text{abs}(d)$ [S1, unofficial].
*   **Parameters**: Typical values include `OUTER_RADIUS` = 0.4255, `INNER_RADIUS` = 0.385, and `LIGHT_POS` X-offset = 0.035 [S1, unofficial].

## Background
The concept of using analytical functions for distance queries in ray tracing originated with the development of ray marching algorithms. The specific closed-form solutions for natural quadrics (planes, spheres, cylinders, cones, tori) are widely cited in computer graphics literature as efficient alternatives to mesh-based intersection tests . The term "Natural Quadrics" refers to the fact that these shapes are defined by quadratic equations in canonical orientations .
