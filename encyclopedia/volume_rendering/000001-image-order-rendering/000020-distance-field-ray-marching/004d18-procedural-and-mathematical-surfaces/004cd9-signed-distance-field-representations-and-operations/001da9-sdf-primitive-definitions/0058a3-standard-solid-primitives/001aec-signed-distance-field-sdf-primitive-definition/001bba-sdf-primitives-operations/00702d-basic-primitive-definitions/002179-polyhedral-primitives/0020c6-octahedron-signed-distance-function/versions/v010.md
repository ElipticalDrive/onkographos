# Octahedron Signed Distance Function

Also called: Octahedron SDF, sdOctahedron

## Overview
Computes the Euclidean signed distance from a query point to the surface of a regular octahedron centered at the origin. It differs from other polyhedral primitives by exploiting the octahedron's specific symmetry to reduce the computation to a few conditional branches and a single vector length calculation, avoiding the iterative folding used in more complex shapes like the dodecahedron.

## How it works
**Inputs:** Query point $p = (p_x, p_y, p_z)$; size parameter $s$ (distance from center to vertex along axes).
**Output:** Signed distance $d$. Negative inside, positive outside.

1.  **Symmetry Reduction**: Compute $q = |p|$. Map $p$ into the first octant where $q_x, q_y, q_z \ge 0$.
2.  **Central Region Check**: Calculate $m = q_x + q_y + q_z - s$. If the point is in the central region (closest to the origin relative to the face normals), return $m \cdot \tan(\pi/6)$. Note: $\tan(\pi/6) \approx 0.57735027$.
3.  **Face Identification**: Determine which of the three coordinate planes ($xy, yz, zx$) the closest face lies on by comparing $3q_i$ against $m$.
    *   If $3q_x < m$, the closest face is in the $yz$ plane (relative to the folded space). Set $q' = (q_x, q_y, q_z)$.
    *   Else if $3q_y < m$, the closest face is in the $xz$ plane. Set $q' = (q_y, q_z, q_x)$.
    *   Else if $3q_z < m$, the closest face is in the $xy$ plane. Set $q' = (q_z, q_x, q_y)$.
    *   *Note*: The central region check (Step 2) handles the case where no single face dominates in this specific branching logic, effectively covering the "else" case.
4.  **Distance Calculation**:
    *   Let $q'_x, q'_y, q'_z$ be the components of the selected $q'$.
    *   Calculate $k = \text{clamp}(0.5 \cdot (q'_z - q'_y + s), 0.0, s)$.
    *   Compute the vector $v = (q'_x, q'_y - s + k, q'_z - k)$.
    *   Return $d = \|v\|$.

**Pseudocode:**
```python
def sd_octahedron(p, s):
    # 1. Symmetry reduction
    q = abs(p)
    qx, qy, qz = q.x, q.y, q.z
    
    # 2. Central region check
    m = qx + qy + qz - s
    if m >= 0.0: # Inside or on boundary of central region? 
                 # Actually, m < 0 is inside. The source returns m * tan(pi/6) 
                 # when the condition 3*p_i < m fails for all i.
                 # Let's follow the source logic strictly.
        pass

    # 3. Face identification
    # The source uses: if 3*p.x < m ... else if 3*p.y < m ... else if 3*p.z < m ... else return m*tan(pi/6)
    # This implies the "else" branch is the central region.
    
    if 3.0 * qx < m:
        q_prime = (qx, qy, qz)
    elif 3.0 * qy < m:
        q_prime = (qy, qz, qx)
    elif 3.0 * qz < m:
        q_prime = (qz, qx, qy)
    else:
        # Central region
        return m * 0.57735027 # tan(pi/6)

    # 4. Distance calculation
    qx_p, qy_p, qz_p = q_prime
    k = clamp(0.5 * (qz_p - qy_p + s), 0.0, s)
    
    # Vector components
    vx = qx_p
    vy = qy_p - s + k
    vz = qz_p - k
    
    return sqrt(vx*vx + vy*vy + vz*vz)
```

**Parameters:**
*   $s$: Size of the octahedron. Typically $s > 0$.

**Edge Cases:**
*   $s=0$: Degenerate point at origin.
*   Precision: Clamping $k$ prevents numerical instability when the point is exactly on the symmetry planes.

## Subtopics

### Equilateral Triangle Signed Distance Function
Computes the signed distance to an equilateral triangle with inscribed radius $r$. It transforms the 2D point into a fundamental domain using rotation and reflection, then computes the distance to the boundary. It is used for 2D cross-sections or planar primitives. Choose it when a 2D triangular shape is needed. Based on Inigo Quilez's exact function [S2, unofficial].

## Operating characteristics
*   **Time Complexity**: $O(1)$. Constant number of arithmetic operations and comparisons.
*   **Memory Complexity**: $O(1)$. No auxiliary data structures.
*   **Strengths**: Extremely fast evaluation, suitable for real-time ray marching. Simple branching logic.
*   **Limitations**: Only applies to regular octahedra. Not suitable for irregular polyhedra without modification.
*   **Scaling**: Linear with respect to $s$.

## Background
The octahedron SDF is a standard primitive in procedural geometry and ray marching, popularized by Inigo Quilez's online articles on SDFs. It is part of the family of polyhedral primitives used in signed distance field rendering.
