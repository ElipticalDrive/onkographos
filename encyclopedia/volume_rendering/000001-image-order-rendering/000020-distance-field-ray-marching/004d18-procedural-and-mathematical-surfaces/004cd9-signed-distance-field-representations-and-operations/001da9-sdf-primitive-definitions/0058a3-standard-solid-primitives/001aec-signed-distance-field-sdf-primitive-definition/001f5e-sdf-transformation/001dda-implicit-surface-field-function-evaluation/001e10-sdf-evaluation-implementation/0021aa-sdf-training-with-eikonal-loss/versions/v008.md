# SDF Training with Eikonal Loss

Also called: Neural SDF Training with Eikonal Regularization, SDF Surface Training with Eikonal Loss

## Overview
SDF Training with Eikonal Loss optimizes a neural network to predict a Signed Distance Function (SDF) from point cloud data by enforcing the Eikonal equation, which requires the gradient magnitude of the SDF to be unity everywhere [S3, S5, unofficial]. This method distinguishes itself from density-based volume rendering (like NeRF) by directly modeling the geometric distance field, ensuring topological consistency and smooth surface reconstruction [S1][S5, unofficial]. It serves as the foundational training procedure for implicit surface representations, upon which variants like [SDF-Instant-NGP Training](10640-sdf-instant-ngp-training.md) and [TetraSDF Training Procedure](13235-tetrasdf-training-procedure.md) build.

## How it works
**Inputs:**
*   Point cloud data: Vertices $P = \{p_i\}$ and optionally normals $N = \{n_i\}$ [S2][S5, unofficial].
*   Training bounding box $\Omega$ defined by `cfg.training.bounds` [S3, S5, unofficial].
*   Hyperparameters: `batch_size`, `eikonal_weight`, `inter_weight`, `lr`, `lr_scheduler_gamma`, `lr_scheduler_step_size`, `pretrain_iters` [S3, S4, S5, unofficial].

**Outputs:**
*   Optimized neural network parameters $\theta$ representing the SDF $\Phi_\theta(x)$ [S2][S3, unofficial].

**Data Structures:**
*   `NeuralSurface`: A PyTorch module containing an MLP to predict distance for any input point [S3, unofficial].
*   `optimizer`: Adam optimizer initialized with learning rate `lr` [S3, S5, unofficial].
*   `lr_scheduler`: LambdaLR scheduler [S4, S5, unofficial].

**Steps:**

1.  **Preprocessing:** Load the point cloud vertices and center them by subtracting the mean:
    $$ P_{centered} = P - \text{mean}(P) $$
    [S3, S5, unofficial]

2.  **Pretraining (Optional but Recommended):** Pretrain the network using a Sphere Loss on random points to initialize the implicit surface as a sphere [S4, S5, unofficial]. This provides a stable geometric prior [S1].
    *   Sample random points within the bounding box.
    *   Compute loss against the analytical SDF of a sphere with radius $R=1.0$ (or specified config).
    *   Run for `pretrain_iters` iterations [S5, unofficial].

3.  **Main Training Loop:** For each epoch:
    a.  **Sample Point Cloud Points:** Select a batch of points $X_{pc}$ from the centered point cloud $P_{centered}$ [S3, S5, unofficial].
    b.  **Compute Point Cloud Loss:**
        *   Query the SDF network for distances: $D_{pc} = \Phi_\theta(X_{pc})$ [S3, S5, unofficial].
        *   Compute the L2 norm of distances (assuming signed distance should be zero at surface):
            $$ \mathcal{L}_{data} = \frac{1}{N_{pc}} \sum_{i=1}^{N_{pc}} \| D_{pc,i} \|_2 $$
            [S3, S5, unofficial]
        *   *Note:* If normals are available, the data loss can include a normal consistency term: $\lambda_3 |1 - \langle \nabla_x \Phi(x), n(x) \rangle|$ [S2].

    c.  **Sample Eikonal Points:** Sample a batch of points $X_{eik}$ uniformly within the bounding box $\Omega$ [S3, S5, unofficial].

    d.  **Compute Eikonal Loss Components:**
        *   Query distances and gradients: $(D_{eik}, G_{eik}) = (\Phi_\theta(X_{eik}), \nabla \Phi_\theta(X_{eik}))$ [S3, S5, unofficial].
        *   **Gradient Eikonal Loss:** Enforce unit gradient magnitude:
            $$ \mathcal{L}_{eik} = \frac{1}{N_{eik}} \sum_{i=1}^{N_{eik}} \left( \| G_{eik,i} \|_2 - 1 \right)^2 $$
            [S3, S5, unofficial]
        *   **Interior/Off-surface Regularization (Optional):** Penalize points inside the object or far from the surface to suppress spurious outliers [S1][S3, S5, unofficial].
            $$ \mathcal{L}_{inter} = \frac{1}{N_{eik}} \sum_{i=1}^{N_{eik}} \exp(-100 \cdot |D_{eik,i}|) $$
            [S3, S5, unofficial]

    e.  **Total Loss:**
        $$ \mathcal{L}_{total} = \mathcal{L}_{data} + \lambda_{eik} \mathcal{L}_{eik} + \lambda_{inter} \mathcal{L}_{inter} $$
        Where $\lambda_{eik}$ is `cfg.training.eikonal_weight` and $\lambda_{inter}$ is `cfg.training.inter_weight` [S3, S5, unofficial].

    f.  **Optimization Step:**
        *   Zero gradients: `optimizer.zero_grad()`
        *   Backpropagate: `loss.backward()`
        *   Step optimizer: `optimizer.step()`
        *   Update learning rate: `lr_scheduler.step()` [S3, S4, S5, unofficial].

**Pseudocode:**

```python
import torch
import torch.nn as nn

def eikonal_loss(gradients: torch.Tensor) -> torch.Tensor:
    """
    Computes the Eikonal loss enforcing unit gradient magnitude.
    Args:
        gradients: Tensor of shape (N, 3) containing spatial gradients of the SDF.
    Returns:
        Scalar loss value.
    """
    # Compute L2 norm of gradients along the last dimension
    grad_norms = torch.linalg.norm(gradients, dim=-1)
    # Mean absolute difference from 1.0 (or squared difference as per S5)
    # S3 uses abs, S5 uses squared. S5 is more common in modern implementations.
    loss = ((grad_norms - 1.0) ** 2).mean()
    return loss

def train_sdf(model, optimizer, lr_scheduler, point_cloud, cfg):
    """
    Trains a neural SDF using Eikonal loss.
    """
    # 1. Preprocessing
    all_points = torch.Tensor(point_cloud["verts"]).cuda().view(-1, 3)
    all_points = all_points - torch.mean(all_points, dim=0).unsqueeze(0)
    
    # 2. Pretraining (Sphere Loss) - Optional
    if cfg.training.pretrain_iters > 0:
        pretrain_sdf(model, optimizer, cfg)

    # 3. Main Training Loop
    for epoch in range(cfg.training.num_epochs):
        # Sample points from point cloud
        points = select_random_points(all_points, cfg.training.batch_size)
        
        # Compute Point Cloud Loss
        distances = model.implicit_fn.get_distance(points)
        loss_data = torch.linalg.norm(distances, dim=-1).mean()
        
        # Sample random points in bounds for Eikonal regularization
        eikonal_points = get_random_points(cfg.training.batch_size, cfg.training.bounds, "cuda")
        
        # Compute Eikonal Loss
        eikonal_distances, eikonal_gradients = model.implicit_fn.get_distance_and_gradient(eikonal_points)
        
        # Gradient Eikonal Loss
        loss_eik = eikonal_loss(eikonal_gradients) * cfg.training.eikonal_weight
        
        # Interior Regularization (suppress spurious outliers)
        # exp(-beta * |distance|) where beta = 1e2
        loss_inter = torch.exp(-1e2 * torch.abs(eikonal_distances)).mean() * cfg.training.inter_weight
        
        # Total Loss
        loss = loss_data + loss_eik + loss_inter
        
        # Optimization Step
        optimizer.zero_grad()
        loss.backward()
        optimizer.step()
        
        # Learning Rate Schedule
        lr_scheduler.step()

def pretrain_sdf(model, optimizer, cfg):
    """
    Pretrains SDF with sphere loss.
    """
    for _ in range(cfg.training.pretrain_iters):
        points = get_random_points(cfg.training.batch_size, cfg.training.bounds, "cuda")
        distances = model.implicit_fn.get_distance(points)
        # Sphere loss: minimize distance to sphere of radius 1.0
        loss = sphere_loss(distances, points, 1.0)
        
        optimizer.zero_grad()
        loss.backward()
        optimizer.step()

def sphere_loss(distances, points, radius):
    """
    Computes loss between predicted SDF and analytical sphere SDF.
    """
    # Analytical SDF for sphere centered at origin with given radius
    # d(x) = ||x|| - radius
    analytical_sdf = torch.linalg.norm(points, dim=-1) - radius
    # L2 loss
    return torch.mean((distances - analytical_sdf) ** 2)
```

**Parameters:**
*   `cfg.training.eikonal_weight`: Weight for the gradient Eikonal loss term [S3, S5, unofficial].
*   `cfg.training.inter_weight`: Weight for the interior regularization term [S3, S5, unofficial].
*   `cfg.training.batch_size`: Number of points sampled per optimization step [S3, S5, unofficial].
*   `cfg.training.bounds`: Spatial limits for sampling random eikonal points [S3, S5, unofficial].
*   `lr`: Learning rate for the Adam optimizer [S5, unofficial].
*   `lr_scheduler_gamma`: Gamma factor for the LambdaLR learning rate scheduler [S5, unofficial].
*   `lr_scheduler_step_size`: Step size for the LambdaLR learning rate scheduler [S4, S5, unofficial].
*   `pretrain_iters`: Number of iterations for the pretraining phase using sphere loss [S5, unofficial].

**Edge Cases and Pitfalls:**
*   **Gradient Computation:** Ensure `samples.requires_grad = True` is set before computing gradients to enable backpropagation through the network [S7, unofficial].
*   **Precision:** The Eikonal loss can be sensitive to the scaling of the input coordinates. Centering the point cloud is critical [S3, S5, unofficial].
*   **Spurious Outliers:** Without interior regularization, the SDF may develop spurious zero-level sets. The term $\exp(-100 |d|)$ helps suppress these [S1][S3, S5, unofficial].
*   **Topological Noise:** Mild Eikonal regularization ($\lambda_{Eik} \approx 0.02$) can suppress topological noise at the cost of minor surface precision [S1].

## Subtopics

### [Sphere Loss](2750-sphere-loss.md)
A regularization term used during the pretraining phase to initialize the implicit surface as a sphere. It minimizes the MSE between the network's predicted SDF and the analytical SDF of a sphere, providing a stable geometric prior.

### [MLP Distillation](4829-mlp-distillation.md)
Compresses a large SDF network into a smaller MLP by minimizing output discrepancy, transferring geometric knowledge from a teacher to a student network.

### [SDDF with Ellipsoidal Priors and Neural Residuals](10638-sddf-with-ellipsoidal-priors-and-neural-residuals.md)
Learns a Signed Directional Distance Function by combining an explicit ellipsoidal prior with an implicit neural residual, handling occlusions and discontinuities.

### [SDF-Instant-NGP Training](10640-sdf-instant-ngp-training.md)
Defines the training procedure for an SDF baseline using Instant-NGP acceleration, explicitly including a sign loss for free-space samples.

### [TetraSDF Training Procedure](13235-tetrasdf-training-procedure.md)
Optimizes a neural network using a multi-resolution tetrahedral grid, combining L1 regression, Eikonal regularization, and weight normalization.

### Bias Network for High-Fidelity Points
A network that captures geometric bias between volume rendering and point modeling, trained on high-fidelity points to enhance detail representation [S6, unofficial]. It filters points with predicted variance below a threshold $\epsilon$ to create a set $P_s$, then optimizes a bias MLP $f_b$ such that the final SDF $f_{final} = f + f_b$ minimizes the L1 loss against ideal SDF values (0) on $P_s$ [S6, unofficial].

### SDF Training with Chamfer Distance
Trains a neural network to predict Unsigned Distance Function (UDF) values and gradients, projecting query points onto the implicit surface via gradient descent and minimizing Chamfer distance to ground truth points [S7, unofficial]. It uses the update rule $x_{moved} = x_{sample} - \frac{\nabla \text{UDF}(x_{sample})}{\|\nabla \text{UDF}(x_{sample})\|} \cdot \text{UDF}(x_{sample})$ [S7, unofficial].

### Implicit Surface to Volume Transformation
Represents scene geometry as a surface $S = \{x \mid F(x) = 0\}$ and transforms it into a volumetric model by computing pseudo-density $\sigma_i = \Psi(F(x_i))$ using a Laplace cumulative distribution function $\Psi(d)$ [S8]. This allows standard volume rendering techniques to be applied to SDFs [S8].

### Sparse Points SDF Loss
Computes loss on sparse points extracted from batch data, filtering points inside a unit sphere and weighting them, though the specific loss value is multiplied by 0.0 in the reference implementation [S9, unofficial].

### Surface SDF Loss
Computes the mean absolute SDF value on surface points, also multiplied by 0.0 in the reference implementation [S9, unofficial].

### SDF Smoothness Loss
Regularizes the reconstructed surface by penalizing gradients of the SDF between adjacent sampled points along a ray, encouraging geometric smoothness [S10].

## Operating characteristics
*   **Time Complexity:** Depends on the number of training iterations, batch size, and network depth. Each iteration requires forward and backward passes through the MLP for both point cloud and random points [S3, S5, unofficial].
*   **Memory Complexity:** Proportional to the batch size and the number of network parameters. Gradients for all points must be stored during backpropagation [S3, S5, unofficial].
*   **Performance:** Enforcing the Eikonal constraint improves topological consistency and reduces spurious artifacts compared to unconstrained SDF training [S1]. However, it may slightly decrease surface precision (Chamfer Distance/F1) if the regularization weight is too high [S1].
*   **Strengths:** Produces smooth, well-defined surfaces; compatible with standard volume rendering pipelines via density transformation; robust to noise when combined with regularization [S1][S3, S5, unofficial].
*   **Limitations:** Requires careful tuning of regularization weights; pretraining can help convergence but adds overhead; may struggle with highly complex geometries without additional priors or acceleration structures [S1][S3, S5, unofficial].
*   **When to Use:** When reconstructing surfaces from point clouds or when a smooth, differentiable distance field is required for downstream tasks like rendering or physics simulation [S2][S3, S5, unofficial].
*   **When Not to Use:** When high-frequency details are critical and not captured by the point cloud; when computational resources are extremely limited and acceleration structures (like [SDF-Instant-NGP Training](10640-sdf-instant-ngp-training.md)) are not feasible [S1][S5, unofficial].

## Background
The method originates from the use of neural implicit representations for 3D reconstruction, specifically leveraging the properties of Signed Distance Functions [S2][S3, S5, unofficial]. The Eikonal equation $|\nabla \phi(x)| = 1$ is a fundamental property of SDFs, and enforcing it during neural network training ensures the output behaves like a true distance field [S3, S5, unofficial]. Key developments include the VolSDF paper [S3, unofficial][S8] which integrated SDFs with volume rendering, and various implementations in academic assignments and repositories [S3, S4, S5, unofficial]. The technique is widely used in neural surface rendering, 3D reconstruction, and novel view synthesis [S2][S3, S5, unofficial][S8].
