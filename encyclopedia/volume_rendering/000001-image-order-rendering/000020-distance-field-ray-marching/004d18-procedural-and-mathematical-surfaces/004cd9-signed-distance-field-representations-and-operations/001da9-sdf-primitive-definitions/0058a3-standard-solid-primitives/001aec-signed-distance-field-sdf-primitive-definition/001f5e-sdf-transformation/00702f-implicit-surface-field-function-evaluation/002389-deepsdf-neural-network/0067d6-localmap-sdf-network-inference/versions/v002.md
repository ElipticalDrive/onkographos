# LocalMap SDF Network Inference

Also called: LocalMap Decoder, LocalMap SDF Network

## Overview
The LocalMap SDF Network Inference method is a neural network architecture that encodes 3D spatial coordinates into feature vectors and decodes them into Signed Distance Field (SDF) values and inverse sigma (isigma) values for density estimation [S1, unofficial]. It is a specific implementation within the LocalMap framework, distinguishing itself from general-purpose implicit surface networks by its dual-output design for simultaneous geometry and density prediction [S1, unofficial].

## How it works
**Inputs and Outputs:**
*   **Input:** A 3D position vector $\mathbf{xyz} = (x, y, z)$ [S1, unofficial].
*   **Output:** A tensor containing two scalar values: the SDF value and the scaled inverse sigma value [S1, unofficial].

**Data Structures:**
The decoder output is a tensor with shape $(N, 2)$ for $N$ points, where the last dimension is split into two channels [S1, unofficial].
*   Channel 0: SDF value [S1, unofficial].
*   Channel 1: Raw inverse sigma value (before activation) [S1, unofficial].

**Parameters:**
*   `k_decoder_implementation`: Integer flag (0 or 1) selecting the decoder backend [S1, unofficial].
    *   0: Custom PyTorch Linear stack [S1, unofficial].
    *   1: TCNN `FullyFusedMLP` [S1, unofficial].
*   `k_bce_isigma`: Scaling factor applied to the softplus output of the inverse sigma [S1, unofficial].
*   `encoding_type`: Enum or string specifying the positional encoding scheme used by the encoding map [S1, unofficial].
*   `normalized`: Boolean flag indicating if input coordinates are normalized before encoding [S1, unofficial].

**Steps:**
1.  **Position Encoding:** Encode the input position $\mathbf{xyz}$ using the encoding map [S1, unofficial].
    $$ \mathbf{xyz\_feat} = \text{encoding}(\mathbf{xyz}, \text{encoding\_type}, \text{normalized}) $$ [S1, unofficial].
2.  **Feature Decoding:** Pass the encoded features $\mathbf{xyz\_feat}$ through the selected decoder [S1, unofficial].
    *   If `k_decoder_implementation == 0`:
        $$ \mathbf{output} = \text{decoder}(\mathbf{xyz\_feat}) $$ [S1, unofficial].
    *   If `k_decoder_implementation == 1`:
        $$ \mathbf{output} = \text{p\_decoder\_tcnn}(\mathbf{xyz\_feat}) $$ [S1, unofficial].
3.  **Split Output:** Split the decoder output tensor along the last dimension into two parts: SDF and raw isigma [S1, unofficial].
    $$ [\text{sdf}, \text{raw\_isigma}] = \text{split}(\mathbf{output}, \{1, 1\}, \text{dim}=-1) $$ [S1, unofficial].
4.  **Inverse Sigma Activation:** Apply the softplus function to the raw isigma and scale it [S1, unofficial].
    $$ \text{isigma} = 1 + \text{softplus}(\text{raw\_isigma}, \beta=100) \times \text{k\_bce\_isigma} $$ [S1, unofficial].
    The final output tensor is $[\text{sdf}, \text{isigma}]$ [S1, unofficial].

**Pseudocode:**
```python
import torch
import torch.nn.functional as F

def localmap_sdf_inference(xyz, encoding_map, decoder, decoder_tcnn, 
                           k_decoder_implementation, k_bce_isigma, 
                           encoding_type, normalized):
    """
    Perform SDF and isigma inference for a batch of 3D points.
    
    Args:
        xyz: Tensor of shape (N, 3) containing 3D coordinates.
        encoding_map: Object with method 'encoding(xyz, encoding_type, normalized)'.
        decoder: PyTorch module for custom Linear stack (used if k_decoder_implementation == 0).
        decoder_tcnn: TCNN FullyFusedMLP module (used if k_decoder_implementation == 1).
        k_decoder_implementation: Integer (0 or 1) selecting the decoder backend.
        k_bce_isigma: Float scaling factor for inverse sigma.
        encoding_type: String or enum for encoding scheme.
        normalized: Boolean for coordinate normalization.
        
    Returns:
        sdf: Tensor of shape (N, 1) with SDF values.
        isigma: Tensor of shape (N, 1) with scaled inverse sigma values.
    """
    # Step 1: Encode input position
    xyz_feat = encoding_map.encoding(xyz, encoding_type, normalized)
    
    # Step 2: Pass through decoder
    if k_decoder_implementation == 0:
        output = decoder(xyz_feat)
    elif k_decoder_implementation == 1:
        output = decoder_tcnn(xyz_feat)
    else:
        raise ValueError("k_decoder_implementation must be 0 or 1")
        
    # Step 3: Split output into SDF and raw isigma
    sdf, raw_isigma = torch.split(output, 1, dim=-1)
    
    # Step 4: Apply softplus and scaling to isigma
    isigma = 1.0 + F.softplus(raw_isigma, beta=100) * k_bce_isigma
    
    return sdf, isigma
```

**Edge Cases and Pitfalls:**
*   **Decoder Selection:** Ensure `k_decoder_implementation` matches the available backend [S1, unofficial].
*   **Softplus Stability:** The beta parameter in softplus is fixed at 100 [S1, unofficial].
*   **Input Normalization:** The `normalized` flag must be consistent with how the encoding map was configured [S1, unofficial].
