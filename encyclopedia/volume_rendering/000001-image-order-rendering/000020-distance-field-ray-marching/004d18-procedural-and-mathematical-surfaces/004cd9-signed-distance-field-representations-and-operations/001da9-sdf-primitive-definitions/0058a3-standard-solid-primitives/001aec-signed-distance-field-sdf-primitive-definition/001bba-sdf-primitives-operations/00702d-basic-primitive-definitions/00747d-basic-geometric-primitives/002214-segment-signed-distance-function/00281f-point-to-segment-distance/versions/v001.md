# Point-to-Segment Distance
Also called: Closest Point on Line Segment, Distance to line segment, closestPointOnSegment, closestPointOnSegmentToPoint

## Overview
Computes the closest point on a line segment to a query point, which is the core geometric primitive for evaluating the distance to a line segment. It differs from infinite line projection by clamping the result to the segment's endpoints, ensuring the output lies on the closed segment [S1][S2, unofficial].

## How it works
**Inputs:**
- `a`: First endpoint of the segment (vector).
- `b`: Second endpoint of the segment (vector).
- `p`: Query point (vector).

**Outputs:**
- `closest`: The point on the segment `[a, b]` closest to `p` (vector).

**Data Structures:**
- Vectors support arithmetic operations (`+`, `-`, `* scalar`) and dot product (`dot(u, v)`).

**Steps:**
1. Calculate the segment vector: `segVec = b - a`.
2. Calculate the projection parameter `t` using the dot product:
   $$ t = \frac{\text{dot}(p - a, \text{segVec})}{\text{dot}(\text{segVec}, \text{segVec})} $$
3. Clamp `t` to the range `[0, 1]` to ensure the point lies on the segment rather than the infinite line passing through it [S1][S2, unofficial].
4. Calculate the destination point: `closest = a + segVec * t`.
5. Return `closest` [S2, unofficial].

**Pseudocode:**
```python
def closestPointOnSegment(a, b, p):
    segVec = b - a
    segLenSq = dot(segVec, segVec)
    
    # Handle degenerate segment (zero length)
    if segLenSq == 0:
        return a
        
    t = dot(p - a, segVec) / segLenSq
    
    # Clamp t to [0, 1]
    if t < 0.0:
        t = 0.0
    elif t > 1.0:
        t = 1.0
        
    return a + segVec * t
```

**Parameters:**
- `Vec3T`: Any vector type supporting arithmetic and dot product [S1].

**Edge Cases:**
- **Degenerate Segment:** If `a == b`, `segLenSq` is zero. Division by zero must be handled, typically by returning `a` [G].
- **Precision:** Floating-point inaccuracies may cause `t` to slightly exceed `[0, 1]` before clamping, but explicit clamping handles this.

## Operating characteristics
- **Time Complexity:** $O(1)$ constant time operations (vector subtractions, dot products, division, clamping).
- **Memory Complexity:** $O(1)$ auxiliary space.
- **Strengths:** Extremely fast, numerically stable for non-degenerate segments, essential for SDF evaluation.
- **Limitations:** Fails or requires special handling for zero-length segments.

## Background
This method is a standard geometric utility found in collision detection and SDF libraries. It is implemented in OpenVDB's `nanovdb::math` namespace [S1] and used in voxel architecture generation tools [S2, unofficial].
