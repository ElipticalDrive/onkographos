# Augmented SDF

Also called: Conservative Proxy, Conservative SDF Construction from Bounding Volume, Conservative Signed Distance Field Construction, Discontinuous Proxy, Proxy Nodes, tilde f

## Overview
Augmented SDF is a conservative variant of a signed distance field (SDF) that embeds a bounding volume to accelerate field queries outside the volume [S1, S3]. It replaces the expensive original SDF evaluation with a simpler, inexpensive distance-to-boundary function for points outside the volume, creating a discontinuous but conservative signed distance field [S2]. Unlike its siblings, it prioritizes query speed over continuity, making it unsuitable for smooth Boolean operators but highly effective for sphere tracing and polygonization [S2].

## How it works
**Inputs and Outputs:**
*   **Input:** The original signed distance field function $f(\mathbf{p})$, a bounding volume $B$ (derived from Sphere Carving points), and a small positive constant $\varepsilon$.
*   **Output:** The augmented field function $f_e(\mathbf{p})$ (also denoted $\tilde{f}$).

**Data Structures:**
The bounding volume $B$ is represented as a compact signed distance field $d(\mathbf{p}, B)$. The sources specify two primary types of bounding volumes:
1.  **Convex Polyhedra:** Constructed as the geometric convex hull $H(P)$ of a point set $P$ generated by Sphere Carving [S1, S3]. The property $H(P) \supseteq O$ (where $O$ is the object) is guaranteed [S1].
2.  **Ellipsoids/Simple Shapes:** Defined as spheres, ellipsoids, or unions thereof [S1, S2].

The memory footprint is compact, embedded directly in the function definition, avoiding external acceleration structures like grids or octrees [S1, S3].

**Parameters:**
*   $\varepsilon$: A small positive constant ensuring the 0-level set of $f_e$ matches $f$. Typical/Default value: $0.01$ [S1, S3]. Formally, it represents a lower bound of the distance to the object surface $\partial O$ [S2].

**Steps:**
1.  **Bounding Volume Construction:** Generate the bounding volume $B$. If using convex hulls, compute $H(P)$ from the point set $P$ obtained via Sphere Carving [S1, S3].
2.  **Query Evaluation:** For a query point $\mathbf{p}$:
    *   Compute the distance to the bounding volume: $d_B = d(\mathbf{p}, B)$.
    *   If $d_B > \varepsilon$, return $d_B$ (or the proxy function value).
    *   Otherwise, return $f(\mathbf{p})$ [S1, S3].

**Formulas:**
The conservative SDF definition is given by [S1, S3]:

$$
\tilde{f}(\mathbf{p}) = 
\begin{cases} 
d(\mathbf{p}, \mathcal{B}) & \text{if } d(\mathbf{p}, \mathcal{B}) > \varepsilon \\
f(\mathbf{p}) & \text{otherwise}
\end{cases}
$$

Alternatively, described as a proxy node $P$ replacing $f$ outside volume $V$ with a simpler function $b$ [S2]:

$$
f_e(\mathbf{p}) = 
\begin{cases} 
f(\mathbf{p}) & \text{if } \mathbf{p} \in V \\
b(\mathbf{p}) & \text{otherwise}
\end{cases}
$$

Where the exterior proxy function $b$ is defined as [S2]:

$$
b = d(\mathbf{p}, \partial V) + \varepsilon
$$

Here, $d(\mathbf{p}, \partial V)$ is the Euclidean distance to the volume boundary, and $\varepsilon$ is formally defined as [S2]:

$$
\varepsilon = \min_{\mathbf{p} \in V} f(\mathbf{p})
$$

If the proxy is used to accelerate evaluation *inside* the object $O$ (where $b(\mathbf{p}) < 0$), the interior proxy is defined as [S2]:

$$
b = -d(\mathbf{p}, \partial V) - \varepsilon
$$

**Pseudocode:**

```python
def augmented_sdf(p, f_original, bounding_volume, epsilon=0.01):
    """
    Evaluate the augmented SDF at point p.
    
    Args:
        p: 3D point (vector).
        f_original: Function evaluating the original SDF f(p).
        bounding_volume: Object representing the bounding volume B, 
                         providing a method distance_to_boundary(p).
        epsilon: Small positive constant (default 0.01).
    
    Returns:
        The augmented SDF value f_e(p).
    """
    # Compute distance to the bounding volume boundary
    # Note: For convex hulls, this is the distance to the hull surface.
    # For simple shapes (sphere/ellipsoid), this is standard analytic distance.
    dist_to_bound = bounding_volume.distance_to_boundary(p)
    
    # Check if point is sufficiently outside the bounding volume
    if dist_to_bound > epsilon:
        # Return the conservative proxy value
        # This is equivalent to dist_to_bound + epsilon if using the 
        # specific proxy definition b = d(p, dV) + epsilon
        return dist_to_bound + epsilon
    
    else:
        # Point is inside or very close to the bounding volume boundary.
        # Fall back to the expensive original SDF evaluation.
        return f_original(p)
```

**Edge Cases and Pitfalls:**
*   **Discontinuity:** The function $f_e$ is discontinuous at the boundary $\partial V$ [S2]. It is piecewise Lipschitz but not globally continuous.
*   **Operator Compatibility:** Because of the discontinuity, proxy nodes cannot be inserted below nodes requiring Lipschitz or continuous fields, such as smooth union operators. Doing so produces rendering artifacts [S2]. They are only safe with Boolean or warping operators [S2].
*   **GPU Artifacts:** In per-pixel cost comparison visualizations (e.g., sphere tracing), GPU memory access pattern inconsistencies can cause visible artifacts [S1, S3].
*   **Conservativeness:** The method produces a *conservative* SDF. The 0-level set is preserved by $\varepsilon$, but the distance values outside $B$ are approximations [S1, S2].

## Operating characteristics
**Time and Memory Complexity:**
*   **Memory:** Compact. The bounding volume is embedded in the function definition, avoiding the overhead of external acceleration structures like grids or octrees [S1, S3].
*   **Time:** Significantly faster for queries outside the bounding volume. The expensive $f(\mathbf{p})$ is skipped if $d(\mathbf{p}, B) > \varepsilon$ [S1, S3].

**Measured Performance:**
*   In tests with ~1 million queries in a box surrounding the object, $f_e$ performs 3.3 to 4.9 times faster on average than the base field $f$ [S1, S3].
*   Using a convex bound in a Sphere Tracing scenario can provide up to a 50% speedup [S1, S3].
*   In ray-object intersection performance tests using Sphere Tracing, proxy nodes achieved an average speedup of $\times 7$ compared to the reference object [S2].
*   On the Temple model, using capsule, half-sphere, and cylinder proxy volumes resulted in an average speedup factor of approximately $\times 6.86$ [S2].

**Strengths and Limitations:**
*   **Strengths:** Fast queries for points outside the volume; compact memory footprint; compatible with Sphere Tracing and Segment Tracing [S1, S3].
*   **Limitations:** Discontinuous at $\partial V$; cannot be used with smooth Boolean operators; only yields conservative distance fields [S2].

**When to Use:**
*   Use when query speed is critical and the object is complex.
*   Use when the construction tree involves only Boolean or warping operators above the proxy node [S2].
*   Use for sphere tracing or polygonization where points far from the surface are common [S1, S3].

**When Not to Use:**
*   Do not use if smooth blending or continuous field properties are required (e.g., smooth unions) [S2].
*   Do not use if exact distance values outside the bounding volume are required [S2].

## Background
**Origin:**
The Augmented SDF (specifically the conservative variant using bounding volumes from Sphere Carving) was introduced in the paper "Sphere Carving: Bounding Volumes for Signed Distance Fields" [S1, S3]. The concept of proxy nodes (P) as discontinuous simplification nodes was further detailed in "Accelerating Signed Distance Functions" [S2].

**History and Development:**
The method relies on "Sphere Carving," an algorithm that generates a set of empty spheres and a point set $P$ whose convex hull bounds the object surface [S1, S3]. The bounding volume is constructed from this point set without requiring supplementary queries of $f$ [S1, S3]. The approach was developed to address the computational cost of evaluating complex SDFs, particularly in real-time rendering contexts like sphere tracing [S1, S3].

**Usage:**
It is used to provide fast SDF queries for points outside the bounding volume while maintaining accuracy inside [S3]. It is applicable in sphere tracing, polygonization, and simulation [S1, S3].
