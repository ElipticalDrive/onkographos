# Surface SDF Loss

Also called: SDF Supervision Loss, Ground Truth SDF Loss

## Overview
The Surface SDF Loss is a supervised regularization term that constrains a neural network's predicted Signed Distance Field (SDF) values to match ground truth SDF data. It solves the problem of ensuring geometric accuracy by minimizing the discrepancy between predicted signed distances and known surface locations. Unlike the parent Eikonal loss which enforces gradient magnitude constraints, this loss directly supervises the scalar field values [S2].

## How it works
**Inputs and Outputs:**
*   **Input:** A set of query points $\mathcal{Q}$, the neural network's predicted SDF values $s(\mathbf{x})$ for $\mathbf{x} \in \mathcal{Q}$, and ground truth SDF values $s_{GT}(\mathbf{x})$ for the same points.
*   **Output:** A scalar loss value $\mathcal{L}_s$.

**Data Structures:**
*   Points $\mathbf{x}$ are typically sampled from the object surface, free space, or interior.
*   $s_{GT}$ is pre-computed or retrieved from a ground truth source (e.g., rendered from meshes using tools like Trimesh) [S2].

**Steps:**
1.  Evaluate the neural network $f_s(\mathbf{x})$ to obtain predicted SDF values $s$ for all query points $\mathbf{x} \in \mathcal{Q}$.
2.  Retrieve corresponding ground truth SDF values $s_{GT}$ for each $\mathbf{x}$.
3.  Compute the absolute difference between predicted and ground truth values for each point.
4.  Calculate the mean of these absolute differences over the entire set $\mathcal{Q}$.

**Formula:**
$$
\mathcal{L}_s(s) = \|s - s_{GT}\|_1 = \frac{1}{|\mathcal{Q}|} \sum_{\mathbf{x} \in \mathcal{Q}} |s(\mathbf{x}) - s_{GT}(\mathbf{x})|
$$
Where:
*   $s$ is the predicted SDF value.
*   $s_{GT}$ is the ground truth SDF value.
*   $\|\cdot\|_1$ denotes the L1 norm (mean absolute error in this context) [S2].

**Parameters:**
*   Weighting factor $\lambda_s$: Multiplies $\mathcal{L}_s$ in the total loss function. Typical values are not specified in the sources [S2].

**Edge Cases and Pitfalls:**
*   **Ground Truth Availability:** Requires access to accurate ground truth SDFs, which may need to be generated via ray marching against mesh representations [S2].
*   **Sampling Density:** The loss depends on the distribution of query points $\mathcal{Q}$. Insufficient sampling near the surface may lead to poor convergence [S2].

**Pseudocode:**
```python
def compute_surface_sdf_loss(predicted_sdf: Tensor, ground_truth_sdf: Tensor) -> Tensor:
    """
    Computes the L1 loss between predicted SDF values and ground truth SDF values.
    
    Args:
        predicted_sdf: Tensor of shape (N,) containing predicted SDF values s.
        ground_truth_sdf: Tensor of shape (N,) containing ground truth SDF values s_GT.
        
    Returns:
        Scalar Tensor representing the mean absolute error.
    """
    # Compute element-wise absolute difference
    abs_diff = torch.abs(predicted_sdf - ground_truth_sdf)
    
    # Compute mean over all query points
    loss = torch.mean(abs_diff)
    
    return loss
```

## Subtopics

### Track-SDF Regularizer
A variant applied to Directional Distance Field (DDF) models rather than the SDF model itself. It constrains DDF predictions to be consistent with SDF surface predictions. It computes points using DDF predictions ($\mathbf{p} + d\mathbf{r}$) for point-direction pairs $(\mathbf{p}, \mathbf{r})$ pointing to the surface, and minimizes the L1 norm of the SDF value at these points: $\mathcal{L}_{ts}(d) = \|f_s(\mathbf{p} + d\mathbf{r})\|_1$. This ensures the DDF-derived point lies close to the SDF zero-level set. It is applied only to the DDF model, not the SDF model [S2].

## Operating characteristics
*   **Time Complexity:** Linear with respect to the number of query points $|\mathcal{Q}|$, as it involves a single pass of subtraction, absolute value, and mean calculation.
*   **Memory Complexity:** Linear with respect to $|\mathcal{Q}|$ to store predicted and ground truth values.
*   **Strengths:** Directly enforces geometric accuracy against known ground truth. Simple to implement and differentiate.
*   **Limitations:** Requires ground truth SDF data, which may not always be available. Does not enforce smoothness or gradient constraints (handled by Eikonal loss).
*   **When to use:** When ground truth SDFs are available and geometric fidelity is prioritized over gradient consistency.
*   **When not to use:** When ground truth is unavailable or when only gradient-based regularization is desired.

## Background
The Surface SDF Loss is introduced in the context of the FIRe (Fast Inverse Rendering Using Directional and Signed Distance Functions) framework [S2]. It is used to supervise the SDF network to predict signed distances consistent with ground truth SDFs generated from rendered rays using Trimesh [S2]. The approach is part of a broader family of regularization and gradient losses for implicit surface representations [S2].
