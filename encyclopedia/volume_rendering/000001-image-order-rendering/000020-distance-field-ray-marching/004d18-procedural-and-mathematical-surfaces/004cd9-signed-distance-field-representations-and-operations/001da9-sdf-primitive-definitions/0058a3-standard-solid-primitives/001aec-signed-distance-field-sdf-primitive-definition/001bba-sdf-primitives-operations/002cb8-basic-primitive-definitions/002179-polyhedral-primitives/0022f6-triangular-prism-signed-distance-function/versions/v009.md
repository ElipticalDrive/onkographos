# Triangular Prism Signed Distance Function

Also called: Signed Triangle Prism, Triangular Prism SDF, sdTriPrism

## Overview
Computes the signed distance from a query point to the surface of a triangular prism. It solves the problem of defining a smooth, differentiable boundary for a prism-shaped volume, enabling its use in ray marching and implicit modeling. It is distinguished from other polyhedral primitives by its specific triangular cross-section geometry, defined by an equilateral triangle in the XY plane and extrusion along the Z axis.

## How it works
**Inputs and Outputs:**
- Input: Query point $p = (p_x, p_y, p_z)$ in local space.
- Input: Half-dimensions $h = (h_x, h_y)$. $h_x$ controls the triangle size, $h_y$ controls the half-height.
- Output: Signed distance $d$.

**Data Structures:**
- No persistent data structures. The function is stateless.

**Steps:**
1.  Compute the absolute value of the query point components to exploit symmetry: $q = |p|$. This maps the query point into the first octant, allowing the use of a single formula for the entire space [S2, unofficial].
2.  Calculate the vertical distance component: $d_z = q_z - h_y$. This represents the distance to the top or bottom face [S2, unofficial].
3.  Calculate the horizontal distance component to the equilateral triangle cross-section. The triangle is oriented with one vertex pointing along the positive X-axis. The distance to the triangle edges is computed using the formula:
    $$ d_{xy} = \max(q_x \cdot \frac{\sqrt{3}}{2} + q_y \cdot \frac{1}{2}, -q_y) - h_x \cdot \frac{1}{2} $$
    Here, $q_x \cdot \frac{\sqrt{3}}{2} + q_y \cdot \frac{1}{2}$ computes the distance to the slanted edge, and $-q_y$ accounts for the symmetry of the triangle's other edges in the absolute space [S2, unofficial].
4.  The final signed distance is the maximum of the vertical and horizontal components:
    $$ d = \max(d_z, d_{xy}) $$
    This correctly handles the corners where the side faces meet the top/bottom faces [S2, unofficial].

**Parameters:**
- $h_x$: Half-width of the triangle. The side length of the equilateral triangle is $2 h_x$.
- $h_y$: Half-height of the prism. The total height is $2 h_y$.
- Constant: $\frac{\sqrt{3}}{2} \approx 0.866025$ [S2, unofficial].

**Pseudocode:**
```python
import numpy as np

def sd_tri_prism(p: np.ndarray, h: np.ndarray) -> float:
    """
    Compute signed distance to a triangular prism.
    
    Args:
        p: Query point (3,)
        h: Half-dimensions (2,), h[0] is half-width (triangle related), h[1] is half-height
        
    Returns:
        Signed distance
    """
    # Step 1: Absolute coordinates for symmetry
    q = np.abs(p)
    
    # Step 2: Vertical distance to top/bottom faces
    d_z = q[2] - h[1]
    
    # Step 3: Horizontal distance to triangular cross-section
    # The triangle is equilateral, oriented with a vertex at +X.
    # Distance to the slanted edge and the vertical symmetry axis.
    # 0.866025 is sqrt(3)/2, 0.5 is 1/2.
    d_xy = max(q[0] * 0.866025 + q[1] * 0.5, -q[1]) - h[0] * 0.5
    
    # Step 4: Combine
    d = max(d_z, d_xy)
    
    return d
```

**Edge Cases:**
- If $h_x$ or $h_y$ is zero, the primitive degenerates to a line or point. The formula still holds but may produce non-smooth gradients at the degenerate features.
- Precision issues may arise if $p$ is very close to the surface and the constants are not represented with sufficient precision.

## Operating characteristics
- **Time Complexity:** $O(1)$. The function involves a constant number of arithmetic operations.
- **Memory Complexity:** $O(1)$. No additional memory is required.
- **Strengths:** Extremely fast evaluation, suitable for real-time ray marching. Smooth gradients almost everywhere, allowing for accurate normal computation.
- **Limitations:** Only defines a triangular prism. Not suitable for non-equilateral triangles without modification.
- **When to use:** When a triangular prism shape is needed in a ray-marched scene.
- **When not to use:** When a different polygonal base (e.g., square, hexagon) is required.

## Background
The triangular prism SDF is a standard primitive in the family of signed distance functions for procedural geometry. It is commonly found in GLSL-based ray marching tutorials and libraries, such as those by Inigo Quilez and others who popularized SDFs for real-time graphics. The specific formulation using absolute values and max functions is a standard technique for constructing polyhedral SDFs [S2, unofficial].
