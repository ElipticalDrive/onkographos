# Geometry Loss


## Overview
Geometry Loss is a composite regularization term used to supervise the training of Signed Distance Field (SDF) neural networks, ensuring that the predicted implicit surface accurately matches ground truth geometry while maintaining physical consistency. It addresses the ambiguity between shape and radiance in inverse rendering by combining SDF regression, Eikonal regularization, depth/normal supervision, and smoothness constraints. It differs from sibling methods like Sphere Loss or MLP Distillation by explicitly incorporating multi-view geometric priors (depth and normals) and specific topological penalties (bubble loss) rather than relying solely on point-cloud or volume-based constraints.

## How it works
**Inputs and Outputs:**
*   **Inputs:** A trained SDF network $d(x)$, ground truth SDF values $s_{GT}$, ground truth depth $D(r)$ and normals $N(r)$ for sampled rays $R$, and a minibatch of 3D points $X$ near the surface.
*   **Outputs:** A scalar loss value $L_{geo}$ used for backpropagation.

**Data Structures:**
*   $X$: Minibatch of 3D points uniformly sampled in 3D space and near the surface.
*   $R$: Set of rays/pixels sampled in the minibatch.
*   $\hat{N}(r)$: Predicted normal at ray $r$, derived from $\nabla d(x)$.
*   $N(r)$: Ground truth normal at ray $r$.
*   $\hat{D}(r)$: Predicted depth at ray $r$.
*   $D(r)$: Ground truth depth at ray $r$.
*   $\epsilon$: Small random uniform 3D perturbation.

**Formulas:**
The total geometry loss is a weighted sum of five terms [S2]:
$$ L_{geo} = \lambda_1 L_{eikonal} + \lambda_2 L_{depth} + \lambda_3 L_{normal} + \lambda_4 L_{smooth} + \lambda_5 L_{bubble} $$

1.  **Eikonal Loss ($L_{eikonal}$):** Enforces that the gradient magnitude of the SDF is 1 everywhere, a property of true distance fields [S2]:
    $$ L_{eikonal} = \sum_{x \in X} (\|\nabla d(x)\|^2 - 1)^2 $$
    where $\nabla d(x)$ is the gradient of the SDF at point $x$ [S2].

2.  **Depth Loss ($L_{depth}$):** Supervises the predicted depth against ground truth using L1 loss [S2]:
    $$ L_{depth} = \sum_{r \in R} \|\hat{D}(r) - D(r)\|_1 $$

3.  **Normal Loss ($L_{normal}$):** Supervises the predicted surface normals against ground truth using angular L1 loss [S2]:
    $$ L_{normal} = \sum_{r \in R} \|1 - \hat{N}(r) \cdot N(r)\|_1 $$

4.  **Smoothness Loss ($L_{smooth}$):** Encourages smooth surface reconstruction by penalizing differences in gradients between nearby points [S2]:
    $$ L_{smooth} = \sum_{x \in S} \|\nabla d(x) - \nabla d(x + \epsilon)\|_2 $$
    where $S$ is a minibatch of points sampled near the surface and $\epsilon$ is a small random uniform 3D perturbation [S2].

5.  **Bubble Loss ($L_{bubble}$):** A topological penalty to prevent isolated floating geometry. The exact formula is not provided in the sources, but it is applied to penalize "bubbles" or disconnected components in the reconstructed geometry [S2].

**Parameters:**
*   $\lambda_1, \lambda_2, \lambda_3, \lambda_4, \lambda_5$: Hyperparameters weighting each loss term. Their values vary during the training process [S2]. Specifically, $\lambda_5$ (bubble loss) is set to 0 during the initial warm-up step until the network reconstructs coarse geometry [S2].

**Pseudocode:**
```python
def compute_geometry_loss(sdf_network, points_X, rays_R, points_S, 
                          gt_sdf, gt_depth, gt_normals, epsilon):
    """
    Computes the composite geometry loss L_geo.
    
    Args:
        sdf_network: Neural network predicting signed distance d(x).
        points_X: Minibatch of 3D points for Eikonal regularization.
        rays_R: Set of rays for depth and normal supervision.
        points_S: Minibatch of points near surface for smoothness.
        gt_sdf: Ground truth SDF values (used if L_sdf is included, 
                though L_geo definition in [S2] focuses on other terms).
        gt_depth: Ground truth depth values for rays R.
        gt_normals: Ground truth normal vectors for rays R.
        epsilon: Small random 3D perturbation vector.
        
    Returns:
        L_geo: Scalar loss value.
    """
    # 1. Eikonal Loss: ||grad(d(x))||^2 should be 1
    grad_X = compute_gradient(sdf_network, points_X)
    eikonal_term = sum((norm(grad_x)**2 - 1)**2 for grad_x in grad_X)
    
    # 2. Depth Loss: L1 difference between predicted and GT depth
    pred_depths = compute_depth(sdf_network, rays_R)
    depth_term = sum(abs(pred_d - gt_d) for pred_d, gt_d in zip(pred_depths, gt_depth))
    
    # 3. Normal Loss: Angular L1 difference between predicted and GT normals
    pred_normals = compute_normals(sdf_network, rays_R)
    normal_term = sum(abs(1.0 - dot(pred_n, gt_n)) for pred_n, gt_n in zip(pred_normals, gt_normals))
    
    # 4. Smoothness Loss: L2 difference between gradients of nearby points
    grad_S = compute_gradient(sdf_network, points_S)
    grad_S_perturbed = compute_gradient(sdf_network, points_S + epsilon)
    smooth_term = sum(norm(grad_s - grad_sp) for grad_s, grad_sp in zip(grad_S, grad_S_perturbed))
    
    # 5. Bubble Loss: Topological penalty (formula not specified in sources)
    # [G] Implementation detail: Typically involves checking for isolated 
    #     components or volume consistency. Placeholder for specific method.
    bubble_term = compute_bubble_loss(sdf_network, points_S) 
    
    # Combine with weights (lambda values vary by training step)
    # Note: L_sdf (L1 on SDF values) is mentioned in [S1] but not explicitly 
    # in the L_geo formula in [S2]. If L_sdf is required, add lambda_0 * L_sdf.
    L_geo = (lambda_1 * eikonal_term + 
             lambda_2 * depth_term + 
             lambda_3 * normal_term + 
             lambda_4 * smooth_term + 
             lambda_5 * bubble_term)
             
    return L_geo

    """Computes the gradient of the SDF output with respect to input points."""
    # [G] Standard automatic differentiation in PyTorch/TensorFlow

    distances = network(points)
    gradients = torch.autograd.grad(
        distances.sum(), points, create_graph=True, retain_graph=True
```

**Edge Cases and Pitfalls:**
*   **Precision:** Computing gradients via automatic differentiation can be sensitive to network initialization. The Eikonal term is non-convex and can lead to local minima if not regularized properly [S2].
*   **Boundaries:** The smoothness loss requires sampling points $x$ and $x+\epsilon$ near the surface. If $\epsilon$ is too large, it may sample outside the relevant region; if too small, numerical noise dominates [S2].
*   **Degenerate Input:** If the ground truth normals or depths are missing or noisy, the $L_{normal}$ and $L_{depth}$ terms may mislead the optimizer. The warm-up step helps mitigate this by initially ignoring $L_{bubble}$ and focusing on coarse geometry [S2].

## Operating characteristics
*   **Time Complexity:** Dominated by the computation of gradients ($\nabla d(x)$) for all sampled points and rays. Each gradient computation requires a backward pass through the network.
*   **Memory Complexity:** Requires storing intermediate gradients for backpropagation. The number of sampled points ($X, S$) and rays ($R$) scales linearly with memory usage.
*   **Strengths:** Enforces strict geometric priors (unit gradient, smoothness) and leverages multi-view consistency via depth and normals.
*   **Limitations:** Computationally expensive due to repeated gradient calculations. Sensitive to hyperparameter tuning ($\lambda_i$).
*   **When to use:** When training neural SDFs for inverse rendering or high-fidelity reconstruction where geometric accuracy is critical.
*   **When not to use:** For real-time inference where speed is paramount, or when ground truth depth/normal data is unavailable.

## Background
Geometry Loss was introduced in the context of intrinsic indoor scene reconstruction and editing using neural SDFs. It builds upon the Eikonal regularization technique [S2]. The method is part of the $I^2$-SDF framework, which aims to disentangle geometry and material properties from multi-view images. The specific combination of Eikonal, depth, normal, smoothness, and bubble losses was proposed to handle shape-radiance ambiguity and ensure topologically correct reconstructions [S2].
