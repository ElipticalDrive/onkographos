# Distance to Natural Quadrics

Also called: Natural Quadrics SDF, SDF for Natural Quadrics

## Overview
Distance to Natural Quadrics provides exact Signed Distance Functions (SDFs) for standard solid modeling primitives, including planes, spheres, cylinders, cones, and tori [S2]. These functions return the Euclidean distance from a query point to the nearest surface, enabling efficient distance-field ray marching (sphere tracing) and Constructive Solid Geometry (CSG) operations [S2][S4, unofficial]. Unlike [Distance to Superquadrics](1561-distance-to-superquadrics.md), which generalizes shapes using non-Euclidean $L_p$ norms for rounded or pinched cross-sections, Natural Quadrics operate in standard Euclidean space, providing the foundational algebraic forms for closed-loop topologies like tori and capped geometries like cylinders [S1, unofficial][S2].

## How it works
The method evaluates the signed distance $d$ for specific primitive types. All primitives assume the query point $p$ is in local coordinates; if the primitive is transformed, the inverse transformation is applied to $p$ first [Parent].

### Inputs and Outputs
*   **Input**: Query point $p = (p_x, p_y, p_z)$. Primitive-specific parameters (e.g., radius $r$, center $c$, half-extents, major/minor radii).
*   **Output**: Scalar signed distance $d$.

### Data Structures
No complex data structures are required. Parameters are typically passed as scalars or vectors.

### Formulas and Steps

#### 1. Plane
A plane is defined by a unit normal $n$ and a point $p_0$ on the plane [S2].
$$ d(p) = n \cdot (p - p_0) $$
*   $n$: Unit normal vector.
*   $p_0$: Any point on the plane.

#### 2. Sphere
A sphere is defined by center $c$ and radius $r$ [S2].
$$ d(p) = \|p - c\| - r $$
For a unit sphere at the origin:
$$ d(p) = \|p\| - 1 $$

#### 3. Cylinder
The sources provide definitions for both infinite and capped cylinders.

**Infinite Cylinder**:
For a cylinder aligned with the $z$-axis and radius $r$, the distance is the 2D distance from the projection onto the $xy$-plane to the unit circle, minus the radius [S2].
$$ d(p) = \text{dist}_{2D}((p_x, p_y), \text{circle}_r) - r $$
Where $\text{dist}_{2D}((x,y), \text{circle}_r) = \sqrt{x^2 + y^2} - r$.
*Note: [S3, unofficial] provides a simplified version for a cylinder aligned with the $z$-axis using half-height $dim.z$ as radius, but this is ambiguous for capped cylinders.*

**Capped Cylinder**:
[S1, unofficial] defines a capped cylinder aligned with the $Y$-axis, with radius $r$ and half-height $h$.
1.  Compute intermediate distances:
    $$ d_{xy} = \sqrt{p_x^2 + p_z^2} - r $$
    $$ d_y = |p_y| - h $$
2.  Combine:
    $$ d = \min(\max(d_{xy}, d_y), 0) + \max(\max(d_{xy}, d_y), 0) $$
    *   If $d_{xy} < 0$ and $d_y < 0$ (inside): $d = \min(d_{xy}, d_y)$.
    *   If outside: $d = \max(d_{xy}, d_y)$.
    *   If clamped $Y$ differs from original $Y$ (point is outside height bounds), the distance to the nearest cap is added [S1, unofficial].

#### 4. Cone
A cone centered at the origin, oriented along the $z$-axis, with divergence angle $\theta$ [S2].
$$ d(p) = \text{dist}_{2D}((p_x, p_z), \text{cone profile}) $$
The derivation involves the angle of divergence $\theta$ from the $z$-axis [S2].
[S1, unofficial] provides a GLSL implementation for a cone with half-angle parameters $c$ (sin/cos) and height $h$:
1.  Define $q = h \cdot (c_x/c_y, -1.0)$.
2.  Let $w = (\|p_{xz}\|, p_y)$.
3.  Compute vectors $a$ and $b$ based on projections onto $q$.
4.  $d = \sqrt{\min(\|a\|^2, \|b\|^2)} \cdot \text{sign}(s)$, where $s$ determines inside/outside.

#### 5. Torus
A torus is the product of two circles. It is defined by a major radius $R$ (distance from center of tube to center of torus) and a minor radius $r$ (radius of the tube) [S2][S4, unofficial]. The torus is centered at the origin and spun about the $z$-axis [S2].
1.  Compute the distance from the point to the major circle in the $xz$-plane:
    $$ q_x = \sqrt{p_x^2 + p_z^2} - R $$
    $$ q_y = p_y $$
2.  The signed distance is the distance from $q$ to the origin minus the minor radius:
    $$ d(p) = \sqrt{q_x^2 + q_y^2} - r $$
*   Typical values: $R=0.8, r=0.3$ [S4, unofficial].

### Pseudocode

```python
import math

def sdf_plane(p, n, p0):
    """
    Signed distance to a plane.
    p: query point (x, y, z)
    n: unit normal vector (nx, ny, nz)
    p0: point on the plane (x0, y0, z0)
    """
    # Vector from p0 to p
    dx = p[0] - p0[0]
    dy = p[1] - p0[1]
    dz = p[2] - p0[2]
    # Dot product
    return dx * n[0] + dy * n[1] + dz * n[2]

def sdf_sphere(p, c, r):
    """
    Signed distance to a sphere.
    p: query point (x, y, z)
    c: center (cx, cy, cz)
    r: radius
    """
    dx = p[0] - c[0]
    dy = p[1] - c[1]
    dz = p[2] - c[2]
    return math.sqrt(dx*dx + dy*dy + dz*dz) - r

def sdf_cylinder_infinite(p, r):
    """
    Signed distance to an infinite cylinder aligned with Z-axis.
    p: query point (x, y, z)
    r: radius
    """
    dx = p[0]
    dy = p[1]
    return math.sqrt(dx*dx + dy*dy) - r

def sdf_cylinder_capped(p, r, h):
    """
    Signed distance to a capped cylinder aligned with Y-axis.
    p: query point (x, y, z)
    r: radius
    h: half-height
    """
    # Distance to the side surface (infinite cylinder along Y)
    # Project to XZ plane
    dist_side = math.sqrt(p[0]**2 + p[2]**2) - r
    
    # Distance to the caps (top and bottom)
    dist_cap = abs(p[1]) - h
    
    # Combine
    # If inside both (negative), take the max (closest to surface)
    # If outside either, take the max of the positive distances
    d_side = dist_side
    d_cap = dist_cap
    
    # Logic: min(max(d_side, d_cap), 0) + max(max(d_side, d_cap), 0)
    # This is equivalent to: if inside, min(neg, neg) = neg (dist to closest surface)
    # If outside, max(pos, pos) = pos (dist to closest surface)
    # If one in, one out, the logic handles the corner
    
    max_d = max(d_side, d_cap)
    min_d = min(d_side, d_cap)
    
    if max_d < 0:
        return min_d
    else:
        return max_d

def sdf_torus(p, R, r):
    """
    Signed distance to a torus.
    p: query point (x, y, z)
    R: major radius
    r: minor radius
    """
    # Distance from point to the center of the tube ring in XZ plane
    q_x = math.sqrt(p[0]**2 + p[2]**2) - R
    q_y = p[1]
    
    return math.sqrt(q_x**2 + q_y**2) - r

def sdf_cone(p, h, sin_theta, cos_theta):
    """
    Signed distance to a cone aligned with Y-axis (based on S1 GLSL adaptation).
    p: query point (x, y, z)
    h: height parameter (used to define q)
    sin_theta: sin of half-angle
    cos_theta: cos of half-angle
    """
    # q = h * (cos/sin, -1) -> q_x = h * cos/sin, q_y = -h
    # Note: S1 uses c.x/c.y which is cot(theta). 
    # Let's use the standard geometric approach for a cone with apex at origin, axis Y, half-angle alpha.
    # r = x^2 + z^2. dist = max(r*cos(alpha) - y*sin(alpha), -y) ? 
    # Using S1 logic adapted for Y-axis alignment:
    
    # w = (length(p.xz), p.y)
    w_x = math.sqrt(p[0]**2 + p[2]**2)
    w_y = p[1]
    
    # q = h * (cos/sin, -1)
    # Let k = h * cos_theta / sin_theta
    k = h * cos_theta / sin_theta
    q_x = k
    q_y = -h
    
    # dot(w, q)
    dot_wq = w_x * q_x + w_y * q_y
    dot_qq = q_x**2 + q_y**2
    
    # clamp(dot(w,q)/dot(q,q), 0, 1)
    t = dot_wq / dot_qq
    if t < 0: t = 0
    elif t > 1: t = 1
    
    # a = w - q * t
    a_x = w_x - q_x * t
    a_y = w_y - q_y * t
    
    # b = w - q * (clamp(w.x/q.x, 0, 1), 1)
    t2 = w_x / q_x
    if t2 < 0: t2 = 0
    elif t2 > 1: t2 = 1
    
    b_x = w_x - q_x * t2
    b_y = w_y - q_y * 1
    
    # d = min(dot(a,a), dot(b,b))
    d_a = a_x**2 + a_y**2
    d_b = b_x**2 + b_y**2
    dist_sq = min(d_a, d_b)
    
    # s = sign(q.y) * (w.x * q.y - w.y * q.x) ... wait, S1 uses k*(w.x*q.y - w.y*q.x)
    # k in S1 is sign(q.y)
    k_sign = 1 if q_y > 0 else -1
    s_val = k_sign * (w_x * q_y - w_y * q_x)
    
    return math.sqrt(dist_sq) * (1 if s_val >= 0 else -1)
```

### Parameters and Edge Cases
*   **Precision**: Floating-point precision issues may arise when points are very close to the surface ($d \approx 0$). Central finite differences for normals should use a small $\epsilon$ (e.g., $0.0001$) [Parent].
*   **Boundaries**: For capped primitives (Cylinder, Cone), the transition between the side surface and the cap must be handled continuously. The formula $\min(\max(d_{side}, d_{cap}), 0) + \max(\max(d_{side}, d_{cap}), 0)$ ensures $C^0$ continuity [S1, unofficial].
*   **Degenerate Input**: A cone with $\theta = 0$ or $\theta = \pi/2$ requires special handling to avoid division by zero in trigonometric ratios.

## Operating characteristics
*   **Time Complexity**: $O(1)$ per primitive evaluation. Involves basic arithmetic and square roots.
*   **Memory Complexity**: $O(1)$. No auxiliary data structures.
*   **Performance**: Extremely fast, suitable for real-time ray marching. [S2] notes that while these closed-form solutions are efficient, they are less useful for higher-order constructions like blends compared to superquadrics, which allow for smoother deformations.
*   **Strengths**: Exact distances, Lipschitz continuous (allowing safe ray marching steps), simple implementation.
*   **Limitations**: Cannot represent complex shapes without CSG operations. Non-uniform scaling requires distance compensation [Parent].

## Background
The concept of Sphere Tracing and Signed Distance Functions was introduced by John C. Hart in 1994 [S2]. The appendix "A Distance to Natural Quadrics and Torus" in Hart's paper derives these specific SDFs for planes, spheres, cylinders, cones, and tori, providing a tutorial for developing such functions [S2]. These primitives form the basis of implicit surface rendering and are widely used in real-time graphics for procedural geometry [S3, unofficial].
