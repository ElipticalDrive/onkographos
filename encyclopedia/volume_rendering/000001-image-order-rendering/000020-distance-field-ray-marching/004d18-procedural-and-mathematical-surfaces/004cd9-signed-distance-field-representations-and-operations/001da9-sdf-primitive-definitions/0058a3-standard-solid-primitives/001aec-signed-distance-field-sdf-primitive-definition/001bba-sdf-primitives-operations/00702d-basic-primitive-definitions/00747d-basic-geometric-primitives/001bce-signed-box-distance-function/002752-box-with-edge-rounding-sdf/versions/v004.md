# Box with Edge Rounding SDF
Also called: Box with Edge Rounding, Rounded Box Distance Function, Rounded Box SDF, SDF Primitive: Box with Edge Rounding, sdBoxRounded

## Overview
Computes the signed Euclidean distance from a query point to the surface of an axis-aligned box whose edges and corners are rounded by a constant radius. It solves the problem of defining smooth, organic variations of standard rectangular primitives for ray marching and implicit modeling. It differs from the [Signed Box Distance Function](1092-signed-box-distance-function.md) by replacing sharp 90-degree corners with spherical fillets, allowing for continuous normals and softer visual interactions.

## How it works
**Inputs and Outputs:**
- Input: Query point $p \in \mathbb{R}^3$, box half-extents $b = (b_x, b_y, b_z)$, edge/corner rounding radius $e$.
- Output: Signed distance $d$. Positive outside, negative inside, zero on the surface.

**Data Structures:**
- $p$: `vec3` (float x, y, z).
- $b$: `vec3` (float x, y, z), representing half-width, half-height, half-depth.
- $e$: `float`, the radius of the rounding. Must satisfy $0 \le e \le \min(b_x, b_y, b_z)$.

**Steps:**
1. Compute the absolute coordinates of the point relative to the box center: $p_{abs} = |p|$.
2. Compute the distance to the unrounded box faces: $q = p_{abs} - b$.
3. Clamp negative components to zero to isolate the region outside the box faces: $q_{pos} = \max(q, 0.0)$.
4. Compute the distance to the rounded corners/edges. This is done by treating the "excess" distance from the box as a vector from the corner center. The corner centers are located at $(\pm b_x, \pm b_y, \pm b_z)$. The vector from the nearest corner to the point is $q_{pos}$. The distance to the corner sphere is $k = \|q_{pos}\|$.
5. The raw distance to the rounded geometry is $d_{raw} = k - e$.
6. Adjust for the signed nature. If the point is inside the unrounded box ($q$ has negative components), the distance is determined by the closest face. If outside, it is determined by the closest edge/corner sphere.
   - A unified formula often used is: $d = \| \max(|p| - b, 0) \| - e$. However, this returns unsigned distance for the outer shell. For a *signed* distance function (SDF), we must account for the interior.
   - The standard SDF implementation combines the box distance and the rounding. Let $d_{box}$ be the distance to the sharp box. Let $d_{round}$ be the distance to the rounded corners.
   - A common robust implementation (derived from [S2, unofficial] and [S1, unofficial]) calculates the distance to the rounded box as:
     $$ d = \text{length}(\max(|p| - b, 0.0)) - e $$
     This formula alone is unsigned for the outer region. To make it signed, we check if the point is inside the sharp box.
     $$ d_{signed} = \begin{cases} d_{box} & \text{if } d_{box} < 0 \\ \max(d_{box}, \| \max(|p| - b, 0.0) \| - e) & \text{if } d_{box} \ge 0 \end{cases} $$
     Actually, a simpler and widely cited SDF for rounded boxes (e.g., Inigo Quilez's style) is:
     $$ d = \text{length}(\max(|p| - b, 0.0)) - e $$
     This is technically an *unsigned* distance to the rounded box surface from the outside. For a true SDF that is negative inside, we use:
     $$ d = \text{length}(\max(|p| - b, 0.0)) - e $$
     Wait, if $p$ is inside the sharp box, $\max(|p|-b, 0)$ is zero (or has zeros). The length is 0. $d = -e$. This is incorrect for the interior of the sharp box, which should be close to 0 or negative based on face distance.
     
     Correct SDF logic:
     1. $q = |p| - b$
     2. $d_{box} = \text{length}(\max(q, 0.0)) + \min(\max(q, 0.0), 0.0)$ (This is the standard box SDF)
     3. For rounded box, we replace the corner contribution.
     4. The distance to the rounded box is:
        $$ d = \text{length}(\max(|p| - b, 0.0)) - e $$
        This formula is valid for the *outside*. For the *inside*, the distance is determined by the closest face of the sharp box, but clipped by the rounding.
        
     Let's look at [S2, unofficial]:
     `float d = length(max(abs(p)-vec3(2.0,0.5,2.0),0.0))-0.2;`
     This returns a value that is negative inside the "rounded" volume? No, if $p=0$, $|p|-b = -b$. $\max(-b, 0) = 0$. $length(0) - 0.2 = -0.2$.
     If $p$ is far outside, $d$ is positive.
     If $p$ is inside the sharp box but outside the rounded volume?
     The "rounded box" volume is the intersection of the sharp box and the expanded box? No, it's the sharp box with corners cut off.
     The interior of the rounded box is the set of points where $d < 0$.
     The formula $d = \| \max(|p| - b, 0) \| - e$ works as a signed distance function if we consider the "rounded box" to be the shape where the corners are rounded.
     However, strictly speaking, the distance to the *surface* is what is needed.
     
     Let's refine the algorithm based on [S1, unofficial] and [S2, unofficial]:
     1. $q = |p| - b$
     2. $d_{out} = \| \max(q, 0.0) \| - e$
     3. $d_{in} = \min(q) + e$? No.
     
     Standard SDF for rounded box (from Quilez):
     ```glsl
     float sdRoundedBox( vec3 p, vec3 b, float r )
     {
       vec3 q = abs(p) - b;
       return length(max(q,0.0)) + min(max(q.x,max(q.y,q.z)),0.0) - r;
     }
     ```
     This is the correct SDF.
     - `max(q, 0.0)` isolates the outside components.
     - `length(...)` computes distance to the corner sphere.
     - `min(max(q.x, max(q.y, q.z)), 0.0)` computes the distance to the nearest face if inside, or 0 if outside.
     - Subtracting `r` shifts the surface inward by the radius.

**Pseudocode:**
```python
def sd_rounded_box(p: Vec3, b: Vec3, r: float) -> float:
    """
    Computes signed distance to a rounded box.
    p: query point
    b: half-extents (width/2, height/2, depth/2)
    r: rounding radius
    """
    # Step 1: Absolute coordinates minus half-extents
    q = abs(p) - b
    
    # Step 2: Distance to the outside corner spheres
    # max(q, 0) keeps only positive components (outside the box faces)
    outside_dist = length(max(q, 0.0))
    
    # Step 3: Distance to the inside faces
    # min(max(q.x, max(q.y, q.z)), 0) is negative if inside, 0 if outside
    # It represents the distance to the nearest face if inside the box
    inside_dist = min(max(q.x, max(q.y, q.z)), 0.0)
    
    # Step 4: Combine and subtract radius
    d = outside_dist + inside_dist - r
    
    return d
```

**Parameters:**
- $r$ (or $e$): Rounding radius. Typical values depend on $b$. $r$ should be $< \min(b_x, b_y, b_z)$. If $r \ge \min(b)$, the shape degenerates (e.g., to a capsule or sphere).

**Edge Cases:**
- $r = 0$: Reduces to [Signed Box Distance Function](1092-signed-box-distance-function.md).
- $r \ge \min(b_x, b_y, b_z)$: The box corners meet or overlap. The shape becomes a capsule-like form or a sphere. The SDF remains valid but may lose the "box" character.
- Precision: Near the boundaries where the face distance transitions to edge/corner distance, the function is $C^1$ continuous (smooth normals), but numerical precision issues can arise if $r$ is very small relative to floating-point epsilon.

## Subtopics

### Rounded Box2D SDF
Computes the signed distance to a 2D rounded rectangle. It is defined as the distance to a sharp 2D box with half-extents $b-r$, minus the radius $r$. Formula: $\text{box2d}(p, b - r) - r$. It is chosen when working in 2D space or extruding 2D profiles. [S3, unofficial]

### Unsigned Rounded Box SDF
Computes the unsigned distance from a point to an axis-aligned box with rounded corners. Formula: $d = \|\max(|p| - b, 0)\| - r$. It returns negative values if the point is inside the rounded box. It is simpler than the SDF version as it does not calculate the interior face distance separately, making it suitable for collision detection where only the boundary matters. [S4, unofficial]

## Operating characteristics
- **Time Complexity:** $O(1)$. Involves a fixed number of arithmetic operations, vector subtractions, absolute values, max/min, and a square root (length).
- **Memory Complexity:** $O(1)$. No auxiliary data structures.
- **Performance:** Extremely fast, suitable for real-time ray marching in fragment shaders. The square root is the most expensive operation, but it is unavoidable for Euclidean distance.
- **Strengths:** Provides smooth, organic shapes; continuous normals for lighting; simple parameterization.
- **Limitations:** Cannot represent sharp features; rounding radius limits the aspect ratio of the box (cannot round a very thin box fully).

## Background
The Signed Distance Field for a rounded box is a staple in procedural geometry and ray marching, popularized by Inigo Quilez's tutorials on distance functions. It allows for the creation of soft, mechanical, or organic shapes without the need for mesh tessellation. It is widely used in real-time graphics, voxel engines, and implicit modeling.
