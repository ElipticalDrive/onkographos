# Deep Medial Field (DMF) Network Architecture

Also called: DMF Network

## Overview
The Deep Medial Field (DMF) Network is a neural implicit surface representation that extends the DeepSDF architecture by predicting the medial field in addition to the signed distance field (SDF) and its gradient. While DeepSDF outputs only the SDF value $\Phi(x)$, DMF predicts two medial field components $M^+(x)$ and $M^-(x)$, the SDF $\Phi(x)$, and the SDF gradient $\nabla\Phi(x)$. This extension allows for the efficient computation of medial field ambient occlusion (MFAO) and provides information about local shape thickness. It is distinct from [Vox2SDF](4047-vox2sdf.md) which uses voxel grids, and builds on the [DeepSDF Neural Network](3051-deepsdf-neural-network.md) by adding specific heads to handle the discontinuous nature of the medial field.

## How it works
**Inputs:** A 3D point $x \in \mathbb{R}^3$.
**Outputs:** Four values:
1.  $M^+(x) \in \mathbb{R}$: Medial field value for the outside of the shape ($x \in O^+$).
2.  $M^-(x) \in \mathbb{R}$: Medial field value for the inside of the shape ($x \in O^-$).
3.  $\Phi(x) \in \mathbb{R}$: Signed distance value.
4.  $\nabla\Phi(x) \in \mathbb{R}^3$: Gradient of the SDF.

**Data Structures:**
The network consists of a shared fully connected backbone (MLP) and four separate fully connected heads.
*   **Shared Backbone:** An MLP with 6 hidden layers. It takes the transformed input coordinates and outputs a shared feature vector.
*   **Heads:** Four separate MLPs, each with 2 hidden layers. Each hidden layer contains 64 neurons. The output layer is linear.
    *   Head 1: Outputs $M^+(x)$.
    *   Head 2: Outputs $M^-(x)$.
    *   Head 3: Outputs $\Phi(x)$.
    *   Head 4: Outputs $\nabla\Phi(x)$.

**Parameters:**
*   **Random Fourier Features (RFF):** 64 bands are used to transform input coordinates.
*   **Weighting Constant ($\alpha$):** Set to $10^{-3}$ [S1, unofficial].
*   **Activation:** The backbone and heads use the same activation functions as the core MLP in [Gropp et al. 2020] (typically GeLU or ReLU with geometric initialization, though specific activation names are not explicitly detailed in the provided text, the structure is defined by the layer counts) [S1, unofficial].

**Algorithm:**
1.  **Input Transformation:** Transform the input coordinate $x$ into Random Fourier Features (RFF). Let $f_i$ be the $i$-th Fourier feature band.
2.  **Feature Weighting:** Weight each Fourier feature $f_i$ by $w_i = \alpha ||f_i||$, where $||f_i||$ is the frequency of the $i$-th band and $\alpha = 10^{-3}$ [S1, unofficial]. This weighting preserves the network's bias towards spherical topology [S1, unofficial].
3.  **Concatenation:** Concatenate the weighted Fourier features with the original un-transformed coordinates $x$.
4.  **Shared Encoding:** Pass the concatenated vector through the shared backbone MLP (6 hidden layers) to obtain a shared feature vector $h$ [S1, unofficial].
5.  **Head Decoding:** Pass $h$ through each of the four separate heads to obtain the outputs:
    *   $M^+(x)$
    *   $M^-(x)$
    *   $\Phi(x)$
    *   $\nabla\Phi(x)$
6.  **Medial Field Combination:** Compute the final medial field $M(x)$ using the sign of $\Phi(x)$ to handle the discontinuity at the surface $\partial O$:
    $$
    M(x) = \begin{cases} 
    M^+(x) & \text{if } \Phi(x) > 0 \\
    M^-(x) & \text{if } \Phi(x) < 0 
    \end{cases}
    $$
    This formulation allows the network to model the discontinuity of the medial field at the surface, which ordinary Lipschitz MLPs cannot approximate directly [S1, unofficial].

**Edge Cases and Pitfalls:**
*   **Discontinuity:** The medial field has a discontinuity at the surface $\partial O$. Ordinary MLPs are Lipschitz and cannot approximate this discontinuity directly. The solution is to predict $M^+$ and $M^-$ separately for the outside and inside, then combine them based on the sign of $\Phi(x)$ [S1, unofficial].
*   **Fourier Feature Weighting:** The weighting constant $\alpha$ must be small ($10^{-3}$) to preserve the network's bias towards spherical topology [S1, unofficial].

## Operating characteristics
**Time and Memory Complexity:**
The complexity is dominated by the shared backbone MLP and the four heads. The backbone has 6 hidden layers, and each head has 2 hidden layers with 64 neurons. The input dimension is $3 + 2 \times 64 = 131$. The output dimension is $1 + 1 + 1 + 3 = 6$.
*   **Memory:** The number of parameters depends on the layer widths. The backbone width is not explicitly given, but the heads have 64 neurons. The backbone likely has a similar width.
*   **Time:** Inference is fast as it involves only forward passes through small MLPs.

**Strengths and Limitations:**
*   **Strengths:** Provides medial field information for ambient occlusion approximation (MFAO) and local shape thickness. Handles the discontinuity of the medial field effectively.
*   **Limitations:** Requires predicting additional outputs ($M^+, M^-$) which increases model size and training complexity compared to standard DeepSDF.

**When to Use:**
Use when medial field information is needed for applications like ambient occlusion or shape analysis. Not needed if only SDF is required.

## Background
The Deep Medial Field Network was introduced by Daniel Rebain, Ke Li, Vincent Sitzmann, Soroosh Yazdani, Kwang Moo Yi, and Andrea Tagliasacchi in the paper "Deep Medial Fields" [S1, unofficial]. It builds upon the DeepSDF architecture [Gropp et al. 2020] and Random Fourier Features [Tancik et al. 2020]. The method was developed to provide an efficient alternative for approximating ambient occlusion using the medial field.
