# SDF Deformations

Also called: Non-uniform spatial distortion, Space Deformation, Twist deformation, Warping Operator

## Overview
SDF Deformations apply a non-uniform spatial distortion to a Signed Distance Field by warping the coordinate space [S1][S2, unofficial]. This technique generates complex, organic, or mechanical deformations (such as twisted cables) from simple primitive SDFs without requiring explicit mesh topology [S1][S2, unofficial]. It is distinguished from [Warped-Space SDF Ray Marching](4726-warped-space-sdf-ray-marching.md) by its explicit handling of multiphase SDFs and the mathematical constraint of the Lipschitz constant to preserve distance accuracy [S1].

## How it works
**Inputs and Outputs:**
*   **Input:** A warping function $\omega: \mathbb{R}^3 \rightarrow \mathbb{R}^3$, a base SDF $\Phi_{\mathcal{A}}$ (potentially multiphase), and a scaling factor $\lambda$ [S1].
*   **Output:** A deformed SDF $\Phi(\mathbf{p})$ that preserves the signed distance property [S1].

**Data Structures:**
*   **Warping Function $\omega$:** A mapping from world coordinates to deformed coordinates [S1]. The implementation requires the inverse function $\omega^{-1}$ to evaluate the distance at the deformed point [S1].
*   **Lipschitz Constant $\lambda$:** A scalar value $\lambda \geq \sup \|\mathbf{J}_{\omega^{-1}}\|$, where $\mathbf{J}_{\omega^{-1}}$ is the Jacobian matrix of the inverse warping function [S1]. This ensures the deformed field remains a valid distance field [S1].

**Numbered Steps:**
1.  **Compute Inverse Warp:** For a query point $\mathbf{p}$, determine the pre-warp coordinate $\mathbf{p}' = \omega^{-1}(\mathbf{p})$ [S1].
2.  **Evaluate Base SDF:** Compute the base distance $\phi_{\mathcal{A}}(\mathbf{p}')$ at the pre-warp coordinate [S1].
3.  **Scale Distance:** Divide the base distance by $\lambda$ to obtain the deformed distance: $\phi_{\text{def}} = \phi_{\mathcal{A}}(\mathbf{p}') / \lambda$ [S1].
4.  **Multiphase Handling (Optional):** If deforming only a specific phase $k$ within a multiphase structure $\mathcal{A}$, apply the over operator to combine the deformed phase with undeformed phases [S1].
    *   For the target phase $k$: $\phi_k = \phi_{\mathcal{A}_k}(\mathbf{p}') / \lambda$ [S1].
    *   For all other phases $i \neq k$: $\phi_i = \max(\phi_{\mathcal{A}_i}(\mathbf{p}), -\phi_{\mathcal{A}_i}(\mathbf{p}') / \lambda)$ [S1].

**Formulas:**
For global warping of all phases:
$$ \Phi(\mathbf{p}) = \frac{1}{\lambda} \Phi_{\mathcal{A}} \circ \omega^{-1}(\mathbf{p}) $$
where $\lambda \geq \sup \|\mathbf{J}_{\omega^{-1}}\|$ [S1].

For partial phase deformation $D(\mathcal{A}, k)$:
$$ D(\mathcal{A}, k) = D(\mathcal{A}_k) \cup_+ (\mathcal{A} - \mathcal{A}_k) $$
Function evaluation:
$$ \phi_i = \max(\phi_{\mathcal{A}_i}, -\phi_{\mathcal{A}_i} \circ \omega^{-1}/\lambda) \quad \forall i \neq k $$
$$ \phi_k = \phi_{\mathcal{A}_k} \circ \omega^{-1}/\lambda $$
[S1].

**Parameters:**
*   $\lambda$: Scaling factor constrained by the supremum of the Jacobian norm of the inverse warping function to preserve the signed distance property [S1].

**Edge Cases and Pitfalls:**
*   **Lipschitz Violation:** If $\lambda$ is too small, the resulting field is no longer a valid signed distance field, leading to incorrect ray marching steps and visual artifacts [S1].
*   **Inverse Solving:** Computing $\omega^{-1}(\mathbf{p})$ may require iterative numerical methods if $\omega$ is complex, which can impact performance [G].
*   **Phase Boundaries:** When deforming only a subset of phases, the interaction between deformed and undeformed regions must be handled carefully to avoid gaps or overlaps, typically using the `max` operator as defined [S1].

**Pseudocode:**
```python
def sdf_deformation(p, base_sdf, omega_inv, lambda_val, phase_k=None, num_phases=None):
    """
    Computes the deformed SDF value at point p.
    
    Args:
        p: vec3, query point in world space.
        base_sdf: function, returns SDF value(s) at a point.
        omega_inv: function, returns omega^-1(p).
        lambda_val: float, Lipschitz constant >= sup||J_omega_inv||.
        phase_k: int or None, if set, deforms only this phase.
        num_phases: int or None, required if phase_k is set.
        
    Returns:
        float or vecN, deformed SDF value(s).
    """
    # Step 1: Compute inverse warp
    p_prime = omega_inv(p)
    
    # Step 2 & 3: Evaluate base SDF and scale
    if phase_k is None:
        # Global warping
        phi_base = base_sdf(p_prime)
        return phi_base / lambda_val
    else:
        # Partial phase warping
        # Evaluate base SDF at both original and deformed points
        phi_base_original = base_sdf(p)
        phi_base_deformed = base_sdf(p_prime)
        
        result_phases = []
        for i in range(num_phases):
            if i == phase_k:
                # Deform only phase k
                phi_k = phi_base_deformed[i] / lambda_val
                result_phases.append(phi_k)
            else:
                # Combine undeformed phase i with deformed phase k
                # phi_i = max(phi_A_i, -phi_A_i_composed / lambda)
                phi_i = max(phi_base_original[i], -phi_base_deformed[i] / lambda_val)
                result_phases.append(phi_i)
        
        return result_phases
```

## Subtopics

### Twist Deformation
Applies a rotation angle that varies linearly with position (e.g., along the Y-axis) to create helical or twisted structures like cables [S1][S2, unofficial]. It is chosen for generating twisted geometries without explicit mesh topology [S2, unofficial].

### Multiphase Warping
Applies deformation to only a subset of phases in a multiphase SDF, chosen when only specific components of a complex assembly need to be distorted while others remain static [S1]. It is implemented using the over operator to preserve undeformed phases [S1].

## Operating characteristics
*   **Time Complexity:** Dominated by the evaluation of $\omega^{-1}(\mathbf{p})$ and the base SDF. If $\omega^{-1}$ requires iteration, complexity increases [G].
*   **Memory Complexity:** O(1) additional memory per query, assuming $\omega^{-1}$ is computed on the fly [G].
*   **Strengths:** Enables complex, organic shapes from simple primitives; supports multiphase structures for detailed internal geometry [S1][S2, unofficial].
*   **Limitations:** Requires careful calculation of $\lambda$ to preserve distance accuracy; inverse warping can be computationally expensive or numerically unstable [S1, G].
*   **When to Use:** When creating twisted, bent, or distorted geometries that are difficult to model with standard primitives [S2, unofficial].
*   **When Not to Use:** When high performance is critical and $\omega^{-1}$ is expensive to compute, or when the deformation is uniform (use simple transformation instead) [G].

## Background
The concept of space deformation for SDFs was formalized in the context of multiphase SDFs by the PhaseTree authors [S1]. The warping operator allows for the deformation of space following classical formulations, enabling the creation of complex scenes like twisted electrical cables [S1]. The technique is widely used in ray marching for procedural geometry, as demonstrated by examples such as twisting deformations and displacement maps [S2, unofficial].
