# SDF Representation DOP

Also called: Signed Distance Field Representation

## Overview
The SDF Representation DOP creates a signed distance field from geometry to enable fast inside/outside testing for collision detection [S1]. It supports multiple construction modes, including ray intersection and laser scanning, to handle various geometry types and watertightness requirements [S1].

## How it works
**Inputs and Outputs**
*   **Input Geometry:** The parent geometry data is used to create the SDF [S1]. A Geometry data attached as subdata overrides the parent, allowing proxy geometry or explicit external volume files [S1].
*   **First Input:** Optional connector to control which simulation objects are modified via the Group parameter [S1].
*   **Other Inputs:** Connectors for data nodes that act as modifiers [S1].
*   **Output:** A signed distance field data structure attached to the specified objects [S1].

**Data Structures**
The SDF is stored on a 3D voxel grid [S1]. The grid resolution is defined by the `Divisions` parameter, computed within a bounding box slightly larger than the geometry [S1]. In `Volume Sample` mode, divisions are ignored and computed from the source volume's voxel size [S1]. Each voxel stores a scalar distance value: positive outside, negative inside, zero on the surface [S1].

**Algorithm Steps**
The construction process depends on the selected `Mode` and `Laser Scan` setting:
1.  **Geometry Source:** Uses parent geometry data, or attached subdata if present [S1].
2.  **Grid Setup:** Initializes a 3D grid based on `Divisions` or source volume resolution [S1].
3.  **Distance Calculation:** Depends on `Mode`. Ray Intersect uses ray intersection for accuracy [S1]. Meta Balls evaluates metaball field directly (requires Laser Scan off) [S1]. Implicit Box/Sphere/Plane fills bounding box, sphere, or divides box along smallest axis [S1]. Minimum computes distance to surface/curve, with `Offset` expanding/shrinking [S1]. Volume Sample reads raw volume primitive as SDF [S1]. Height Field treats volume as 2D heightfield with orthographic distances [S1]. Laser Scan (On) sends rays along primary axes, uses closest/farthest intersections, marks voxels between as inside [S1]. Laser Scan (Off) sends rays along primary axes, finds all intersections, tests segments for inside/outside using normals [S1].
4.  **Sign Correction:** `Fix Signs` post-processes to correct numerical imprecision and inconsistent signs [S1].
5.  **Boundary Stabilization:** `Force Bounds` forces boundary voxels to exterior to prevent incorrect sign stabilization [S1].
6.  **Sign Inversion:** `Invert Sign` reverses inside/outside sense [S1].
7.  **Sign Sweep:** If `Sign Sweep Threshold` is set, performs passes to eliminate large inconsistent blocks [S1]. An invalid transition occurs if SDF value change exceeds `Threshold * Cell Width` [S1]. Geometry is ray-intersected to determine correct sign, which propagates forward [S1]. Repeats up to `Max Sign Sweep Count` [S1].

**Parameters**
*   `Mode`: String. Options: `Ray Intersect`, `Meta Balls`, `Implicit Box`, `Implicit Sphere`, `Implicit Plane`, `Minimum`, `Volume Sample`, `Height Field` [S1].
*   `Divisions`: Integer. Grid resolution. Minimum feature size must be larger than grid spacing to avoid detail loss [S1].
*   `Offset`: Float. Expands (positive) or shrinks (negative) the volume [S1].
*   `Tolerance`: Float. Scale-invariant tolerance for ray intersections, multiplied by geometry size [S1].
*   `Laser Scan`: Boolean. On: uses closest/farthest intersections (robust to non-watertight) [S1]. Off: uses all intersections (requires watertight) [S1].
*   `Fix Signs`: Boolean. Enables post-processing for sign consistency [S1].
*   `Force Bounds`: Boolean. Forces boundary voxels to exterior [S1].
*   `Invert Sign`: Boolean. Reverses inside/outside [S1].
*   `Sign Sweep Threshold`: Float. Threshold for invalid sign transitions relative to cell width [S1].
*   `Max Sign Sweep Count`: Integer. Maximum iterations for sign sweep [S1].
*   `Data Sharing`: Enum. `Do Not Share Data`, `Share Data Across All Time`, `Share Data In One Timestep` [S1].
*   `Activation`: Expression/Float. Non-zero attaches data; zero removes it [S1].
*   `Group`: String. Subset of objects to affect [S1].
*   `Data Name`: String. Name for attaching data, supports subdata paths (e.g., "Forces/Fan") [S1].
*   `Unique Data Name`: Boolean. Modifies `Data Name` to ensure unique attachment so it will not overwrite existing data [S1].

**Pseudocode**
```python
def compute_sdf(geometry, params):
    # 1. Determine geometry source
    source_geom = params.get('subdata_geometry') or geometry

    # 2. Determine grid bounds and resolution
    if params['mode'] == 'Volume Sample':
        grid = create_grid_from_volume(source_geom)
    else:
        bbox = compute_bounding_box(source_geom)
        grid = create_grid(bbox, params['divisions'])

    # 3. Compute distances based on mode
    if params['mode'] == 'Ray Intersect':
        compute_ray_intersect_sdf(grid, source_geom, params['tolerance'])
    elif params['mode'] == 'Meta Balls':
        compute_metaball_sdf(grid, source_geom)
    elif params['mode'] == 'Implicit Box':
        fill_grid_with_bbox(grid, source_geom)
    elif params['mode'] == 'Implicit Sphere':
        fill_grid_with_bounding_sphere(grid, source_geom)
    elif params['mode'] == 'Implicit Plane':
        create_plane_sdf(grid, source_geom)
    elif params['mode'] == 'Minimum':
        compute_minimum_distance_sdf(grid, source_geom, params['offset'])
    elif params['mode'] == 'Volume Sample':
        sample_volume_sdf(grid, source_geom)
    elif params['mode'] == 'Height Field':
        compute_heightfield_sdf(grid, source_geom)
    else:
        if params['laser_scan']:
            compute_laser_scan_sdf(grid, source_geom, params['tolerance'])
        else:
            compute_full_ray_sdf(grid, source_geom, params['tolerance'])

    # 4. Fix Signs
    if params['fix_signs']:
        correct_signs(grid, source_geom)
        if params['force_bounds']:
            force_boundary_exterior(grid)
        
        # 5. Sign Sweep
        if params['sign_sweep_threshold'] > 0:
            cell_width = compute_cell_width(grid)
            for i in range(params['max_sign_sweep_count']):
                if not sweep_signs(grid, params['sign_sweep_threshold'], source_geom, cell_width):
                    break

    # 6. Invert Sign
    if params['invert_sign']:
        invert_sdf(grid)

    return grid

# Helper definitions
def compute_bounding_box(geom):
    return (min(p.x for p in geom.points), min(p.y for p in geom.points), min(p.z for p in geom.points),
            max(p.x for p in geom.points), max(p.y for p in geom.points), max(p.z for p in geom.points))

def create_grid(bbox, divisions):
    return [[[0.0 for _ in range(divisions)] for _ in range(divisions)] for _ in range(divisions)]

def create_grid_from_volume(vol):
    return [[[0.0 for _ in range(vol.divisions_x)] for _ in range(vol.divisions_y)] for _ in range(vol.divisions_z)]

def compute_ray_intersect_sdf(grid, geom, tolerance):
    for x in range(len(grid)):
        for y in range(len(grid[0])):
            for z in range(len(grid[0][0])):
                grid[x][y][z] = ray_intersect_distance(x, y, z, geom, tolerance)

def compute_metaball_sdf(grid, geom):
    for x in range(len(grid)):
        for y in range(len(grid[0])):
            for z in range(len(grid[0][0])):
                grid[x][y][z] = metaball_field(x, y, z, geom)

def fill_grid_with_bbox(grid, geom):
    for x in range(len(grid)):
        for y in range(len(grid[0])):
            for z in range(len(grid[0][0])):
                grid[x][y][z] = 0.0

def fill_grid_with_bounding_sphere(grid, geom):
    center, radius = compute_bounding_sphere(geom)
    for x in range(len(grid)):
        for y in range(len(grid[0])):
            for z in range(len(grid[0][0])):
                dist = distance_to_center(x, y, z, center)
                grid[x][y][z] = radius - dist

def create_plane_sdf(grid, geom):
    bbox = compute_bounding_box(geom)
    plane_axis = min(bbox[0], bbox[1], bbox[2])
    for x in range(len(grid)):
        for y in range(len(grid[0])):
            for z in range(len(grid[0][0])):
                grid[x][y][z] = 0.0 if below_plane(x, y, z, plane_axis) else 1.0

def compute_minimum_distance_sdf(grid, geom, offset):
    for x in range(len(grid)):
        for y in range(len(grid[0])):
            for z in range(len(grid[0][0])):
                grid[x][y][z] = min_distance_to_surface(x, y, z, geom) + offset

def sample_volume_sdf(grid, vol):
    for x in range(len(grid)):
        for y in range(len(grid[0])):
            for z in range(len(grid[0][0])):
                grid[x][y][z] = vol.sample(x, y, z)

def compute_heightfield_sdf(grid, vol):
    for x in range(len(grid)):
        for y in range(len(grid[0])):
            for z in range(len(grid[0][0])):
                grid[x][y][z] = vol.height(x, y)

def compute_laser_scan_sdf(grid, geom, tolerance):
    for axis in ['x', 'y', 'z']:
        for coord in range(len(grid)):
            ray = cast_ray_along_axis(axis, coord, geom, tolerance)
            if ray.intersections:
                inside = False
                for hit in ray.intersections:
                    if not inside:
                        inside = True
                        start = hit.t
                    else:
                        inside = False
                        end = hit.t
                        mark_voxels_between(start, end, axis, coord, grid, value=1.0)

def compute_full_ray_sdf(grid, geom, tolerance):
    for axis in ['x', 'y', 'z']:
        for coord in range(len(grid)):
            ray = cast_ray_along_axis(axis, coord, geom, tolerance)
            if ray.intersections:
                for i in range(0, len(ray.intersections) - 1, 2):
                    start = ray.intersections[i].t
                    end = ray.intersections[i+1].t
                    mark_voxels_between(start, end, axis, coord, grid, value=1.0 if is_inside(start, end, geom) else -1.0)

def correct_signs(grid, geom):
    for x in range(len(grid)):
        for y in range(len(grid[0])):
            for z in range(len(grid[0][0])):
                if not is_consistent_sign(x, y, z, grid):
                    grid[x][y][z] = propagate_sign(x, y, z, grid)

def force_boundary_exterior(grid):
    for x in range(len(grid)):
        for y in range(len(grid[0])):
            for z in range(len(grid[0][0])):
                if is_boundary_voxel(x, y, z, grid):
                    grid[x][y][z] = abs(grid[x][y][z])

def sweep_signs(grid, threshold, geom, cell_width):
    flipped = False
    for x in range(len(grid)):
        for y in range(len(grid[0])):
            for z in range(len(grid[0][0])):
                if abs(grid[x][y][z] - grid[x+1][y][z]) > threshold * cell_width:
                    correct = ray_intersect_inside(x, y, z, geom)
                    if grid[x][y][z] != correct:
                        grid[x][y][z] = correct
                        flipped = True
    return flipped

def invert_sdf(grid):
    for x in range(len(grid)):
        for y in range(len(grid[0])):
            for z in range(len(grid[0][0])):
                grid[x][y][z] = -grid[x][y][z]

def compute_cell_width(grid):
    return 1.0 / len(grid) # Assumes normalized grid spacing
```

**Edge Cases and Pitfalls**
*   **Non-watertight Geometry:** Use `Laser Scan` mode to avoid reliance on normals [S1].
*   **Interior Features:** `Laser Scan` mode cannot represent interior features [S1].
*   **Sign Inversion Stabilization:** `Fix Signs` may stabilize inverted signs at the boundary; use `Force Bounds` to mitigate [S1].
*   **Convergence:** Too low a `Sign Sweep Threshold` may prevent convergence [S1].
*   **Hollow Objects:** Use `Invert Sign` on an inner box for robust hollow representation [S1].

## Operating characteristics
*   **Time Complexity:** Depends on grid resolution (`Divisions`) and geometry complexity [S1]. Sign sweeps add iterative cost [S1].
*   **Memory Complexity:** Proportional to the number of voxels in the grid [S1]. Data sharing options (`Share Data Across All Time`, `Share Data In One Timestep`) can significantly reduce memory footprint for multiple objects [S1].
*   **Strengths:** Fast inside/outside testing; robust handling of non-watertight geometry via Laser Scanning; flexible modes for different geometry types [S1].
*   **Limitations:** Precomputation cost; memory usage for high-resolution grids; potential for sign errors requiring post-processing [S1].
*   **When to Use:** Rigid body collision detection in simulations [S1].
*   **When Not to Use:** When visual fidelity of the volume is the primary goal rather than collision topology; when geometry is extremely complex and grid resolution cannot capture details [S1].

## Background
The SDF Representation DOP is part of Houdini's dynamics (DOP) network, designed to integrate signed distance fields into simulation workflows for collision detection [S1]. It builds on the concept of SDFs as functions evaluating distance to surface with sign indicating inside/outside [S1].
