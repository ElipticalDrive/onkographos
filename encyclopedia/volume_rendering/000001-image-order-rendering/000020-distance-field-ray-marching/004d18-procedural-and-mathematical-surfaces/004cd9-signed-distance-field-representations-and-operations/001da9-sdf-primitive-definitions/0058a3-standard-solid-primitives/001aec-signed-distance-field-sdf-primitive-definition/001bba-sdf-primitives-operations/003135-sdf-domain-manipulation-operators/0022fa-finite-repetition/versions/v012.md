# Finite Repetition

Also called: Bounded Tiling, Finite Domain Repetition, Limited Repetition

## Overview
Finite Repetition creates a bounded, periodic tiling of a base Signed Distance Function (SDF) within a specified limit, preventing the infinite replication seen in standard domain repetition [S1, S2, unofficial]. It solves the problem of creating finite arrays of objects (e.g., a grid of spheres) without requiring manual instance management or clipping planes [S1, S2, unofficial]. Unlike [Infinite Repetition via Dual Offset](14771-infinite-repetition-via-dual-offset.md), which constructs complex interlocking patterns, Finite Repetition applies a simple clamping operation to the cell index, making it computationally cheaper and suitable for any base primitive [S1, S2, unofficial].

## How it works
Finite Repetition maps a query point $\mathbf{p}$ to the nearest cell center within a bounded range $[-l, l]$ along each axis, then translates $\mathbf{p}$ back to the local coordinate system of that cell [S1, S2, unofficial].

**Inputs and Outputs:**
- Input: Query point $\mathbf{p} \in \mathbb{R}^3$, period vector $\mathbf{c} \in \mathbb{R}^3$ (cell size), limit vector $\mathbf{l} \in \mathbb{R}^3$ (max cell index per axis).
- Output: Transformed point $\mathbf{p}' \in \mathbb{R}^3$.

**Data Structures:**
- $\mathbf{p}, \mathbf{c}, \mathbf{l}$ are typically 3-component floating-point vectors.
- $\mathbf{q}$ is an intermediate integer or floating-point vector representing the cell index.

**Steps:**
1.  Compute the cell index $\mathbf{q}$ by dividing $\mathbf{p}$ by $\mathbf{c}$ and rounding to the nearest integer [S1, S2, unofficial].
2.  Clamp $\mathbf{q}$ to the range $[-\mathbf{l}, \mathbf{l}]$ component-wise [S2, unofficial].
3.  Compute the transformed point $\mathbf{p}' = \mathbf{p} - \mathbf{c} \cdot \mathbf{q}$ [S2, unofficial].
4.  Evaluate the base SDF: $d_{result}(\mathbf{p}) = d_{base}(\mathbf{p}')$ [S1, S2, unofficial].

**Formula:**
$$ \mathbf{q} = \text{clamp}\left(\text{round}\left(\frac{\mathbf{p}}{\mathbf{c}}\right), -\mathbf{l}, \mathbf{l}\right) $$
$$ \mathbf{p}' = \mathbf{p} - \mathbf{c} \cdot \mathbf{q} $$

Where:
- $\text{round}(\cdot)$ rounds to the nearest integer.
- $\text{clamp}(v, min, max)$ limits $v$ to $[min, max]$.
- Division and multiplication are component-wise.

**Parameters:**
- $\mathbf{c}$: Period size. Typical values depend on the base primitive scale.
- $\mathbf{l}$: Limit. Must be non-negative. If $\mathbf{l}$ is large, the behavior approaches infinite repetition.

**Edge Cases and Pitfalls:**
- **Boundary Precision:** At the exact boundary between cells, rounding errors may cause jitter. Using `round()` is standard, but ensure consistent tie-breaking if required [S1, S2, unofficial].
- **Zero Period:** $\mathbf{c}$ must not contain zero components.
- **Negative Coordinates:** The formula handles negative $\mathbf{p}$ correctly due to the symmetric clamping range $[-\mathbf{l}, \mathbf{l}]$ [S2, unofficial].

**Pseudocode:**
```python
def repeat_finite(p: Vec3, c: Vec3, l: Vec3) -> Vec3:
    # Step 1: Compute cell index
    q = p / c
    q = round(q)
    
    # Step 2: Clamp to limit
    q = clamp(q, -l, l)
    
    # Step 3: Transform point
    p_prime = p - c * q
    
    return p_prime
```

## Subtopics

### [Infinite Repetition via Dual Offset](14771-infinite-repetition-via-dual-offset.md)
Infinite Repetition via Dual Offset creates a perfect, interlocking hexagonal honeycomb pattern by combining two separate rectangular repetition grids that are offset from each other.

## Operating characteristics
- **Time Complexity:** $O(1)$ per query. Involves basic arithmetic operations (division, rounding, clamping, subtraction).
- **Memory Complexity:** $O(1)$. No additional data structures required.
- **Strengths:** Extremely fast; no branching overhead; supports arbitrary base SDFs; easy to implement.
- **Limitations:** Creates sharp discontinuities at the boundary of the limit $\mathbf{l}$ if the base SDF is not zero there. The transition from the last valid cell to the empty space is abrupt unless the base SDF is designed to fade out.
- **When to use:** When a fixed, finite grid of objects is needed.
- **When not to use:** When infinite tiling is desired (use [Infinite Repetition via Dual Offset](14771-infinite-repetition-via-dual-offset.md) or standard infinite repetition) or when smooth transitions between cells are required.

## Background
Finite Repetition is a domain manipulation operator for Signed Distance Functions, popularized in the context of ray marching and implicit surface rendering. It is attributed to Inigo Quilez's work on SDFs [S1, S2, unofficial]. The method is widely used in procedural geometry generation for creating bounded arrays of primitives.
