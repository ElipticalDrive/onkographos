# MetaSDF

Also called: Gradient-based meta-learning of shape spaces, Meta-learning Signed Distance Functions

## Overview
MetaSDF is a method for learning a prior over signed distance function (SDF) shape spaces by treating shape reconstruction as a meta-learning problem, where a neural network is specialized to a new shape via few steps of gradient descent on context observations [S1, unofficial]. It sets itself apart from auto-decoder frameworks by performing specialization in the forward pass via a fixed number of gradient steps, making it an order of magnitude faster at inference, and from pooling-based set-encoders by avoiding the underfitting of context sets [S1, unofficial].

## How it works
**Inputs and Outputs:**
*   **Input:** A dataset $\mathcal{D}$ of $N$ shapes. Each shape $i$ is represented by a set of $K$ point samples from its ground-truth SDF: $X_i = \{(x_j, s_j) : s_j = \text{SDF}_i(x_j)\}_{j=1}^K$, where $x_j \in \mathbb{R}^3$ are spatial coordinates and $s_j \in \mathbb{R}$ are signed distances [S1, unofficial].
*   **Output:** Meta-parameters $\theta$ and per-parameter inner learning rates $\alpha$ for a neural network $\Phi$ that approximates the SDF [S1, unofficial].

**Data Structures:**
*   **Meta-parameters $\theta$:** The initial weights of the neural network $\Phi$, shared across all tasks/shapes [S1, unofficial].
*   **Inner learning rates $\alpha$:** A vector of per-parameter learning rates for the inner loop, initialized to $1 \times 10^{-1}$ [S1, unofficial].
*   **Outer learning rate $\beta$:** A scalar used to update meta-parameters and inner learning rates [S1, unofficial].
*   **Network $\Phi$:** A fully connected ReLU-MLP. In 2D experiments, it has 4 layers and 256 hidden units [S1, unofficial].

**Formulas:**
The surface of the shape is represented implicitly as the zero-level set of the neural network $\Phi_i$:
$$ L_0(\Phi_i) = \{x \in \mathbb{R}^3 \mid \Phi_i(x) = 0\}, \quad \Phi_i: \mathbb{R}^3 \to \mathbb{R} $$
[S1, unofficial]

The inner-loop update rule for shape $i$ at step $j$ is:
$$ \phi_{j+1}^i = \phi_j^i - \alpha \nabla_{\phi_j^i} \mathcal{L}(\Phi(x; \phi_j^i), s) $$
where $\phi_0^i = \theta$, and $\mathcal{L}$ is the loss function [S1, unofficial].

**Parameters:**
*   $k$: The number of inner-loop gradient descent steps. In 2D MNIST experiments, $k=5$ [S1, unofficial].
*   $\alpha$: Per-parameter inner learning rates, initialized to $1 \times 10^{-1}$ [S1, unofficial].
*   $\beta$: Outer learning rate. In 2D experiments, $\beta = 1 \times 10^{-4}$ [S1, unofficial].

**Steps:**
1.  Initialize inner, per-parameter learning rates $\alpha$ and meta-parameters $\theta$ [S1, unofficial].
2.  Sample a batch of shape datasets $X_i \sim \mathcal{D}$ [S1, unofficial].
3.  For each shape $i$ in the batch:
    a. Split $X_i$ into a training set $X_i^{\text{train}}$ and a test set $X_i^{\text{test}}$ [S1, unofficial].
    b. Initialize inner parameters $\phi_0^i = \theta$ and training loss $\mathcal{L}_{\text{train}} = 0$ [S1, unofficial].
    c. For $j$ from 0 to $k-1$:
        i. Compute the L1 loss over the context training set:
           $$ \mathcal{L}_{\text{train}} \leftarrow \frac{1}{|X_i^{\text{train}}|} \sum_{(x,s) \in X_i^{\text{train}}} |\Phi(x; \phi_j^i) - s| $$
           [S1, unofficial]
        ii. Update inner parameters:
            $$ \phi_{j+1}^i \leftarrow \phi_j^i - \alpha \nabla_{\phi_j^i} \mathcal{L}_{\text{train}} $$
            [S1, unofficial]
    d. Compute the test loss using the specialized parameters $\phi_k^i$:
       $$ \mathcal{L}_{\text{test}} \leftarrow \mathcal{L}_{\text{test}} + \frac{1}{|X_i^{\text{test}}|} \sum_{(x,s) \in X_i^{\text{test}}} |\Phi(x; \phi_k^i) - s| $$
       [S1, unofficial]
4.  Backpropagate the test loss $\mathcal{L}_{\text{test}}$ through the inner-loop update steps to the meta-parameters $\theta$ and learning rates $\alpha$ [S1, unofficial].
5.  Update meta-parameters:
    $$ (\theta, \alpha) \leftarrow (\theta, \alpha) - \beta \nabla_{(\theta, \alpha)} \mathcal{L}_{\text{test}} $$
    [S1, unofficial]

**Pseudocode:**
```python
def metasdf_train(dataset_d, outer_lr_beta, inner_steps_k):
    # Initialize meta-parameters theta and per-parameter learning rates alpha
    theta = np.random.randn(256, 3)
    alpha = np.ones_like(theta) * 1e-1

    while not training_done():
        batch_shapes = random.sample(dataset_d, batch_size)
        total_test_loss = 0.0

        for shape_i in batch_shapes:
            x_train, s_train = shape_i.train_set
            x_test, s_test = shape_i.test_set

            # Initialize inner parameters to meta-parameters
            phi = theta.copy()

            # Inner loop: specialize to the shape
            for _ in range(inner_steps_k):
                # Compute L1 loss on context training set
                predictions = forward_pass(phi, x_train)
                l1_loss = np.mean(np.abs(predictions - s_train))

                # Compute gradient and update inner parameters
                grad = backward_pass(l1_loss, phi)
                phi = phi - alpha * grad

            # Compute test loss on specialized network
            test_predictions = forward_pass(phi, x_test)
            test_loss = np.mean(np.abs(test_predictions - s_test))
            total_test_loss += test_loss / len(batch_shapes)

        # Outer loop: update meta-parameters and learning rates
        meta_grad = backward_pass(total_test_loss, [theta, alpha])
        theta = theta - outer_lr_beta * meta_grad['theta']
        alpha = alpha - outer_lr_beta * meta_grad['alpha']

    return theta, alpha

def forward_pass(weights, x):
    # Forward pass for a 4-layer fully connected ReLU-MLP
    h1 = np.maximum(0, weights[0] @ x + weights[1])
    h2 = np.maximum(0, weights[2] @ h1 + weights[3])
    h3 = np.maximum(0, weights[4] @ h2 + weights[5])
    return weights[6] @ h3 + weights[7]

def backward_pass(loss, params):
    # Computes gradients via automatic differentiation
    return autograd.grad(loss, params)

def training_done():
    return False
```

**Edge Cases and Pitfalls:**
*   Clamping the L1 loss in the inner loop of a gradient-based meta-learning algorithm leads to unstable training [S1, unofficial].
*   To ensure stable 3D training, a multitask loss tracking both SDF values and occupancy (sign) is used instead of clamping [S1, unofficial]. Instead of predicting a single signed distance output, the network predicts two values: the distance to the surface and the sign of the distance function. The L1 SDF loss is combined with a binary cross-entropy sign loss with an uncertainty loss weighting scheme [S1, unofficial].

## Operating characteristics
*   **Time Complexity:** Inference is an order of magnitude faster than auto-decoders [S1, unofficial]. In 2D MNIST experiments, MetaSDF inference takes about 50 ms (5 gradient descent steps), compared to ~4 seconds for hypernetworks and concatenation-based approaches [S1, unofficial]. In 3D ShapeNet experiments, test-time reconstruction speed improved from 8 seconds (DeepSDF) to 0.4 seconds (MetaSDF) [S1, unofficial].
*   **Memory Complexity:** Not given in the sources.
*   **Performance:**
    *   On 2D MNIST with dense context, MetaSDF L1 error is $0.044 \times 10^{-3}$, compared to $0.050 \times 10^{-3}$ for HyperNet and $0.108 \times 10^{-3}$ for Cond. NP [S1, unofficial].
    *   On 2D MNIST with zero-level set context, MetaSDF L1 error is $0.015 \times 10^{-3}$, compared to $1.562 \times 10^{-3}$ for HyperNet and $1.813 \times 10^{-3}$ for Cond. NP [S1, unofficial].
    *   On 3D ShapeNet planes with dense context, MetaSDF mean/median Chamfer Distance is $0.553/0.068 \times 10^{-3}$, compared to DeepSDF $0.073/0.031 \times 10^{-3}$ [S1, unofficial].
    *   On 3D ShapeNet planes with zero-level set context, MetaSDF mean/median Chamfer Distance is $0.139/0.067 \times 10^{-3}$, compared to PointNet Enc. $0.558/0.222 \times 10^{-3}$ [S1, unofficial].
*   **Strengths:** Faster inference than auto-decoders; does not require observations on a regular grid (unlike convolutional encoders); equivariant to 3D transformations; outperforms pooling-based set-encoders, especially with zero-level set context [S1, unofficial].
*   **Limitations:** Requires careful tuning of inner/outer learning rates; unstable training if L1 loss is clamped in the inner loop [S1, unofficial].
*   **When to use:** When fast test-time inference of SDFs from partial observations is required, and the observations are not on a regular grid [S1, unofficial].
*   **When not to use:** When a single latent code optimization is preferred for simplicity, or when training data is extremely limited such that meta-learning priors cannot be effectively learned [S1, unofficial].

## Background
MetaSDF was introduced by Vincent Sitzmann, Eric R. Chan, Noah Snavely, Richard Tucker, and Gordon Wetzstein in 2020 [S1, unofficial]. It builds on the concept of neural implicit shape representations, specifically addressing the slow test-time optimization required by auto-decoder frameworks like DeepSDF [S1, unofficial]. The method leverages MAML-like algorithms to optimize the inference algorithm itself, allowing for fast test-time adaptation [S1, unofficial]. It is used for learning 2D SDFs from MNIST digits and 3D shape spaces from the ShapeNet dataset [S1, unofficial].
