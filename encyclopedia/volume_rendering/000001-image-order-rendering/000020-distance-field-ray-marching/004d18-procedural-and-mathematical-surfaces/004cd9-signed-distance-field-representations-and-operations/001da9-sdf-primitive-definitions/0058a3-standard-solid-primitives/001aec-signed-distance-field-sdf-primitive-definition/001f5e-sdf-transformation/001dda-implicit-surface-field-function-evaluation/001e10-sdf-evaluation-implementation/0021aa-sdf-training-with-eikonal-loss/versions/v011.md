# SDF Training with Eikonal Loss

Also called: Implicit Geometric Regularization (IGR), Implicit neural representations with Eikonal regularization, Neural SDF Training with Eikonal Regularization, SDF Surface Training with Eikonal Loss, Training of Deep Implicit Surface Networks (SDF MLP)

## Overview
This method trains a Multi-Layer Perceptron (MLP) to represent a Signed Distance Function (SDF) directly from raw 3D point cloud data (with or without normals) by minimizing a loss function that enforces two constraints: the network output must vanish at the input points, and the gradient magnitude of the network must equal one everywhere [S6, unofficial]. It solves the problem of learning high-fidelity implicit neural representations without requiring pre-computed 3D supervision (such as occupancy grids or pre-computed SDFs) or explicit regularization on the zero level set [S6, unofficial]. Unlike [SDF Optimization via Finite Differences](3086-sdf-optimization-via-finite-differences.md) which relies on numerical approximations, this method uses automatic differentiation to enforce the Eikonal equation $|\nabla \phi(x)| = 1$ as a continuous regularization term, implicitly guiding the geometry toward a valid signed distance field [S6, unofficial].

## How it works
**Inputs and Outputs:**
*   **Input:** A point cloud dataset $X = \{x_i\}_{i \in I} \subset \mathbb{R}^3$, optionally accompanied by normal vectors $N = \{n_i\}_{i \in I} \subset \mathbb{R}^3$. The 3D space is typically normalized to a bounding box, commonly $[-1, 1]^3$ [S1, S7, unofficial].
*   **Output:** An MLP $f(x; \theta)$ parameterized by $\theta$ that approximates the signed distance function $\phi(x)$ of the underlying surface $S$, where $S = \{x \mid \phi(x) = 0\}$ [S6, unofficial].

**Data Structures:**
*   **MLP Architecture:** A feedforward neural network. Common configurations tested include depths $D \in \{4, 6, 8, 10, 15, 20\}$ and widths $W \in \{45, 60, 90\}$, maintaining constant total neuron counts (e.g., D6-W60 has 6 hidden layers of 60 neurons each) [S1, unofficial].
*   **Activation:** Softplus is specified as the non-linear differentiable activation function applied entrywise [S6, unofficial].
*   **Optimizer:** Adam optimizer [S7, unofficial].

**Training Procedure:**
1.  **Data Preprocessing:** Center the input point cloud by subtracting its mean: $x_{centered} = x - \text{mean}(x)$ [S7, unofficial].
2.  **Initialization (Optional):** Pretrain the SDF using a sphere loss on random points to provide a stable initialization [S5, unofficial].
3.  **Sampling:** For each optimization step, sample two sets of points:
    *   $P_{surface}$: Random points from the input point cloud $X$ [S7, unofficial].
    *   $P_{eikonal}$: Random points uniformly sampled from the training bounding box $\Omega$ [S7, unofficial].
4.  **Forward Pass:**
    *   Query the MLP for distances and gradients at $P_{surface}$: $d_i = f(x_i; \theta)$ and $\nabla f(x_i; \theta)$ for $x_i \in P_{surface}$ [S4, unofficial].
    *   Query the MLP for distances and gradients at $P_{eikonal}$: $d_j = f(x_j; \theta)$ and $\nabla f(x_j; \theta)$ for $x_j \in P_{eikonal}$ [S4, unofficial].
5.  **Loss Computation:**
    *   **Point Cloud Loss ($\mathcal{L}_{data}$):** Enforces the network output to be zero at the surface points. If normals are available, it may also align gradients with normals. The basic form is the mean absolute distance:
        $$ \mathcal{L}_{data} = \frac{1}{N_s} \sum_{i=1}^{N_s} |f(x_i; \theta)| $$
        where $N_s$ is the number of surface points [S7, unofficial]. If normals $n_i$ are provided, a normal consistency term is added: $\lambda_3 |1 - \langle \nabla_x \Phi(x), n(x) \rangle|$ [S3].
    *   **Eikonal Loss ($\mathcal{L}_{eikonal}$):** Enforces the gradient magnitude to be 1. The standard form is the mean absolute deviation from 1:
        $$ \mathcal{L}_{eikonal} = \frac{1}{N_e} \sum_{j=1}^{N_e} \left| \|\nabla f(x_j; \theta)\|_2 - 1 \right| $$
        where $N_e$ is the number of eikonal points [S4, unofficial]. Some implementations use the squared L2 norm: $\frac{1}{N_e} \sum_{j=1}^{N_e} (\|\nabla f(x_j; \theta)\|_2 - 1)^2$ [S7, unofficial].
    *   **Interior/Off-Surface Regularization (Optional):** To suppress spurious outliers and enforce positive distances outside the surface, an exponential penalty is applied to points with negative SDF values (inside the object) or generally off-surface:
        $$ \mathcal{L}_{off} = \mathbb{E}_{x \sim D} [\psi(f(x; \theta))] $$
        where $\psi(x, \beta_0) = \exp(-\beta_0 |x|)$ with $\beta_0 = 1$ [S3]. In practice, this is often implemented as a weighted term added to the loss:
        $$ \mathcal{L}_{interior} = \text{mean}(\exp(-100 \cdot |d_j|)) \times \text{inter\_weight} $$
        This penalizes points inside the object more heavily [S4, S7, unofficial].
6.  **Total Loss:**
    $$ \mathcal{L}(\theta) = \mathcal{L}_{data} + \lambda_{eik} \mathcal{L}_{eikonal} + \lambda_{off} \mathcal{L}_{off} $$
    where $\lambda_{eik}$ and $\lambda_{off}$ are hyperparameters [S3][S7, unofficial].
7.  **Optimization Step:**
    *   Zero gradients: `optimizer.zero_grad()`
    *   Backpropagate: `loss.backward()`
    *   Step optimizer: `optimizer.step()` [S7, unofficial].
8.  **Learning Rate Schedule:** Use a scheduler such as LambdaLR with a base learning rate (e.g., $10^{-3}$), decay factor (e.g., 0.1 every 20 epochs) [S1, S7, unofficial].

**Pseudocode:**
```python
import torch
import torch.nn as nn

class NeuralSDF(nn.Module):
    def __init__(self, hidden_dim=64, num_layers=6):
        super().__init__()
        layers = []
        for i in range(num_layers):
            layers.append(nn.Linear(3 if i == 0 else hidden_dim, hidden_dim))
            layers.append(nn.Softplus()) # Softplus activation [S6, unofficial]
        layers.append(nn.Linear(hidden_dim, 1))
        self.network = nn.Sequential(*layers)

    def forward(self, x):
        return self.network(x)

def compute_gradient(network, points):
    """Computes the gradient of the network output w.r.t input points."""
    points.requires_grad_(True)
    output = network(points)
    grad = torch.autograd.grad(
        outputs=output.sum(),
        inputs=points,
        create_graph=True,
        retain_graph=True
    )[0]
    return grad

def eikonal_loss(gradients):
    """Computes the Eikonal loss: mean absolute difference of gradient norm from 1."""
    grad_norms = torch.norm(gradients, dim=1, keepdim=True)
    return torch.mean(torch.abs(grad_norms - 1.0))

def train_sdf(model, point_cloud, bounds, batch_size=1024, 
              eikonal_weight=0.02, inter_weight=0.0, 
              optimizer=None, num_epochs=100):
    """
    Trains the SDF model using Eikonal regularization.
    
    Args:
        model: NeuralSDF instance.
        point_cloud: Tensor of shape (N, 3) containing surface points.
        bounds: Tuple (min_val, max_val) for uniform sampling.
        batch_size: Number of points per batch.
        eikonal_weight: Lambda_eik for Eikonal loss.
        inter_weight: Lambda_off for interior/off-surface regularization.
        optimizer: PyTorch optimizer instance.
        num_epochs: Number of training epochs.
    """
    device = next(model.parameters()).device
    point_cloud = point_cloud.to(device)
    
    # Center point cloud [S7, unofficial]
    mean = torch.mean(point_cloud, dim=0, keepdim=True)
    point_cloud = point_cloud - mean
    
    min_val, max_val = bounds
    range_val = max_val - min_val
    
    for epoch in range(num_epochs):
        # 1. Sample surface points [S7, unofficial]
        indices = torch.randint(0, point_cloud.size(0), (batch_size,))
        surface_points = point_cloud[indices]
        
        # 2. Sample eikonal points uniformly in bounds [S7, unofficial]
        eikonal_points = torch.rand(batch_size, 3, device=device) * range_val + min_val
        
        # 3. Compute distances and gradients for surface points [S4, unofficial]
        surface_grads = compute_gradient(model, surface_points)
        surface_dists = model(surface_points)
        
        # 4. Compute distances and gradients for eikonal points [S4, unofficial]
        eikonal_grads = compute_gradient(model, eikonal_points)
        eikonal_dists = model(eikonal_points)
        
        # 5. Compute Losses [S7, unofficial]
        # Point cloud loss: mean absolute distance to zero
        loss_data = torch.mean(torch.abs(surface_dists))
        
        # Eikonal loss: gradient norm should be 1
        loss_eikonal = eikonal_loss(eikonal_grads)
        
        # Interior/Off-surface regularization [S4, S7, unofficial]
        # Penalize points inside the object (negative distance)
        # Using exp(-1e2 * |d|) as per [S4, S7, unofficial]
        loss_interior = torch.exp(-1e2 * torch.abs(eikonal_dists)).mean()
        
        # Total Loss
        loss = loss_data + eikonal_weight * loss_eikonal + inter_weight * loss_interior
        
        # 6. Optimization Step [S7, unofficial]
        optimizer.zero_grad()
        loss.backward()
        optimizer.step()
        
        # Optional: Print loss for monitoring
        if epoch % 10 == 0:
            print(f"Epoch {epoch}: Loss={loss.item():.4f}, Data={loss_data.item():.4f}, Eikonal={loss_eikonal.item():.4f}")

    return model
```

**Parameters:**
*   **Eikonal Weight ($\lambda_{eik}$):** Controls the strength of the unit gradient constraint. Typical value: $0.02$ [S2][S7, unofficial].
*   **Interior Weight ($\lambda_{off}$):** Scales the exponential interior loss. Typical value: depends on config, often small or zero if not needed [S4, S7, unofficial].
*   **Learning Rate:** Starts at $10^{-3}$ [S1, unofficial].
*   **Weight Decay:** $10^{-4}$ [S1, unofficial].
*   **Batch Size:** Varies, e.g., 1024 or as defined in config [S4, S7, unofficial].
*   **Bounds:** Spatial limits for random sampling, e.g., $[-1, 1]^3$ [S7, unofficial].

**Edge Cases and Pitfalls:**
*   **Non-Uniqueness:** The solution to the Eikonal equation vanishing on a discrete point set is not unique. The method relies on implicit regularization to find a plausible SDF rather than any arbitrary solution [S6, unofficial].
*   **Approximation Quality:** The zero-level isosurface only approximates the ground-truth mesh; quality depends on MLP capacity (depth/width) [S1, unofficial].
*   **Gradient Computation:** `requires_grad_(True)` must be set on input points before computing gradients to enable backpropagation [S9, unofficial].
*   **Precision:** Using automatic differentiation is preferred over numerical estimates for gradient computation [S6, unofficial].

### Bias Network for High-Fidelity Points
A network that captures geometric bias between volume rendering and point modeling, specifically trained on high-fidelity points to enhance detail representation [S8, unofficial]. It filters the point set $P$ to create $P_s$ containing only points with predicted variance below threshold $\epsilon$: $P_s = \{x_P \mid x_P \in P, \bar{\sigma}^2(x_P) < \epsilon\}$ [S8, unofficial]. The bias SDF value $f_b(x_P)$ is computed using a dedicated MLP: $f_b(x_P) = \text{MLP}_{bias}(x_P)$ [S8, unofficial]. The final SDF value is $f_{final}(x_P) = f(x_P) + f_b(x_P)$ [S8, unofficial]. The Bias network is optimized using L1 loss $L_{bias} = \frac{1}{D_{P_s}} \sum_{x_P \in P_s} |f_\epsilon(x_P) - f_{final}(x_P)|$, assuming ideal SDF values $f_\epsilon(x_P)$ are 0 [S8, unofficial]. Parameter $\epsilon$ is the variance threshold [S8, unofficial].

### SDF Training with Chamfer Distance
Trains a neural network to predict Unsigned Distance Function (UDF) values and gradients, projecting query points onto the implicit surface via gradient descent and minimizing Chamfer distance to ground truth points [S9, unofficial]. The projection is computed as: $x_{moved} = x_{sample} - \frac{\nabla \text{UDF}(x_{sample})}{\|\nabla \text{UDF}(x_{sample})\|} \cdot \text{UDF}(x_{sample})$ [S9, unofficial]. A parameter `df_filter` thresholds the UDF value to filter points during extra point cloud generation [S9, unofficial]. Pitfall: `samples.requires_grad = True` must be set before computing gradients [S9, unofficial].

### Implicit Surface to Volume Transformation
Represents scene geometry as a surface $S$ characterized by an implicit function $F$, where $S = \{x \in \mathbb{R}^3 \mid F(x) = 0\}$ [S10]. It enforces the Eikonal property on $F$ using a loss term that penalizes deviations of the gradient magnitude from 1 [S10]. The implicit surface is transformed into a volumetric model by computing a pseudo-density $\sigma_i$ from the SDF value using a cumulative distribution function: $\sigma_i = \Psi(F(x_i))$ [S10]. The function $\Psi(d)$ is defined as:
$$ \Psi(d) = \begin{cases} \frac{1}{2} \exp(-d/\beta) & \text{for } d \geq 0 \\ 1 - \frac{1}{2} \exp(d/\beta) & \text{for } d < 0 \end{cases} $$
where $\beta$ is an optimizable scale parameter [S10]. Points are sampled near the surface and uniformly throughout the volume $\Omega$ for Eikonal loss computation [S10]. Unlike volumetric radiance fields, this restricts the network to predict density based only on spatial coordinates $x$, while allowing color $c$ to depend on view-dependent features like direction $d$ [S10].

### L1 Regression Baseline for SDF
A baseline method that trains an MLP to regress a pre-computed approximated signed distance function (SDF) using an L1 loss, serving as a fidelity comparison to the proposed implicit geometric regularization method [S6, unofficial]. It pre-computes approximated SDF values $s(x)$ for all points in the training distribution $D_0$ using the local SDF approximation formula: $s(x) = n^{*T} (x - y^*)$, where $y^* = \arg\min_{y \in S} \|y - x\|_2$ and $n^*$ is the unit normal of the triangle containing $y^*$ [S6, unofficial]. The MLP is trained by minimizing $\mathbb{E}_{x \sim D_0} |f(x; \theta) - s(x)|$ [S6, unofficial]. Parameters include the input raw scan $S$ (triangle soup), point sample $X \subset S$ (250k points), normal sample $N$, and training distribution $D_0$ (500k points, 2 points for every point in $X$) [S6, unofficial]. This method approximates the SDF in the vicinity of the surface and uses off-surface points, resulting in fewer details compared to the IGR method which incorporates only points strictly on the surface [S6, unofficial].

## Operating characteristics
*   **Time Complexity:** Training time depends on the number of epochs, batch size, and MLP depth/width. Inference time for a D6-W60 MLP ranges from 15.0 to 25.3 seconds for mesh extraction (marching cubes) on various ShapeNet objects, with a mean of 20.8 seconds [S1, unofficial].
*   **Memory Complexity:** Memory usage is dominated by the MLP parameters and the gradient computation graph during backpropagation. For D6-W60, the mean face count of the extracted mesh is 146,827 [S1, unofficial].
*   **Performance:** The method produces state-of-the-art surface approximations with higher level-of-detail and fidelity compared to previous methods that require 3D supervision [S6, unofficial]. It suppresses spurious outliers and topological noise with mild Eikonal regularization ($\lambda_{Eik} = 0.02$), accepting a marginal decrease in surface precision (Chamfer Distance/F1) for improved topological consistency [S2].
*   **Strengths:** Works directly from raw point cloud data without pre-computed SDFs or occupancy grids [S6, unofficial]. Implicit regularization favors smooth and plausible zero level sets [S6, unofficial].
*   **Limitations:** Approximation quality depends on MLP capacity [S1, unofficial]. The solution to the Eikonal equation is not unique for discrete point data [S6, unofficial].
*   **When to Use:** When training on raw point clouds with or without normals and high-fidelity implicit representations are required without 3D supervision [S6, unofficial].
*   **When Not to Use:** When real-time inference is critical and MLP capacity is limited, or when pre-computed SDFs are available and regression is sufficient [S6, unofficial].

## Background
The method was introduced by Amos Gropp et al. in the paper "Implicit Geometric Regularization for Learning Shapes" (ICML 2020) [S6, unofficial]. It addresses the limitation of previous implicit neural representations that required 3D supervision (pre-computed SDFs or occupancy grids) [S6, unofficial]. The key insight is that optimizing a loss function encouraging the network to vanish on the input point cloud and have a unit norm gradient possesses an implicit geometric regularization property that favors smooth and natural zero level set surfaces [S6, unofficial]. The method has been used on datasets like ShapeNetCoreV1 (Rifle, Chair, Airplane, Sofa, Table categories) [S1, unofficial] and D-Faust for human scans [S6, unofficial]. It differs from NeRF by using SDF values and Eikonal regularization instead of density and color prediction [S7, unofficial].
