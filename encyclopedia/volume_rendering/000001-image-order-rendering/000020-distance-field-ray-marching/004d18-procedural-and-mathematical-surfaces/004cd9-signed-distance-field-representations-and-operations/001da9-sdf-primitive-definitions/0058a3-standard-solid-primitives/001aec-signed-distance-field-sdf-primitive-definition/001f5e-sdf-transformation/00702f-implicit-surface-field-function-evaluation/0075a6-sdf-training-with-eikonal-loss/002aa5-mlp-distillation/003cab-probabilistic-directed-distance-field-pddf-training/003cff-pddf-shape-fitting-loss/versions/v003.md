# PDDF Shape-Fitting Loss

Also called: PDDF loss

## Overview
The PDDF Shape-Fitting Loss ($\mathcal{L}_S$) is the training objective for Probabilistic Directed Distance Fields (PDDF), a method that represents 3D shapes using a probabilistic distribution over directed distance components [S1]. It solves the problem of training neural networks to predict depth, visibility, and surface normals from oriented point data by combining a minimum distance loss, visibility and normal matching, Directed Eikonal regularization, and weight field regularizations [S1]. It sets itself apart from standard SDF training by explicitly modeling the uncertainty and switching between multiple delta components via a probabilistic weight field, rather than predicting a single deterministic distance value [S1].

## How it works
**Inputs and Outputs:**
*   **Inputs:** Oriented points $(p, v)$ where $p$ is position and $v$ is view direction. Ground truth data includes visibility $\xi$, surface normal $n$, and depth $d$. Predictions from the network are visibility $\hat{\xi}$, depth components $\hat{d}_i$, and weights $w_i$ for $i \in \{1, \dots, K\}$.
*   **Outputs:** A scalar loss value $\mathcal{L}_S$.

**Data Structures:**
*   $K$: Number of delta components. Sources specify $K=2$ [S1].
*   $i^*$: The maximum likelihood index, defined as $i^* = \arg \max_j w_j$ [S1].
*   $\hat{d}_{b_{i^*}}$: The depth component corresponding to the maximum likelihood index [S1].
*   $n_{b_{i^*}}(p, v)$: The surface normal derived from the gradient of the predicted depth at the maximum likelihood index, $\nabla_p \hat{d}_{b_{i^*}}$ [S1].

**Formulas:**
The total loss is a weighted sum of five components [S1]:

$$
\mathcal{L}_S = \gamma_d \mathcal{L}_d + \gamma_\xi \mathcal{L}_\xi + \gamma_n \mathcal{L}_n + \mathcal{L}_{\text{DE}} + \mathcal{L}_W \quad (2)
$$

1.  **Minimum Distance Loss ($\mathcal{L}_d$):** Trains the highest probability depth component to match the ground truth depth [S1].
    $$
    \mathcal{L}_d = \xi | \hat{d}_{b_{i^*}} - d |
    $$
    where $\xi$ is the ground truth visibility [S1].

2.  **Visibility Objective ($\mathcal{L}_\xi$):** Binary cross-entropy between predicted visibility $\hat{\xi}$ and ground truth visibility $\xi_b$ (denoted as $\xi$ in the loss formula context, but $\xi_b$ in the definition) [S1].
    $$
    \mathcal{L}_\xi = \text{BCE}(\hat{\xi}, \xi_b)
    $$

3.  **Normals Loss ($\mathcal{L}_n$):** Matches the predicted surface normal (derived from $\nabla_p \hat{d}_{b_{i^*}}$) to the ground truth normal $n$ [S1].
    $$
    \mathcal{L}_n = -\xi | n^T n_{b_{i^*}}(p, v) |
    $$

4.  **Directed Eikonal Regularization ($\mathcal{L}_{\text{DE}}$):** Applied to the visibility and each delta component of depth, analogous to SDF work [S1].
    $$
    \mathcal{L}_{\text{DE}} = \gamma_{\text{E},d} \sum_i \xi \left[ \nabla_i \hat{d}_i v + 1 \right]^2 + \gamma_{\text{E},\xi} [\nabla_\xi \hat{\xi} v]^2
    $$
    where $\nabla_i$ denotes the gradient with respect to the $i$-th component [S1].

5.  **Weight Field Regularization ($\mathcal{L}_W$):** Encourages low entropy outputs and controlled transitions [S1].
    $$
    \mathcal{L}_W = \gamma_V \mathcal{L}_V + \gamma_T \mathcal{L}_T
    $$
    *   **Weight Variance Loss ($\mathcal{L}_V$):** Encourages low entropy PDDF outputs to prevent $i^*$ from switching unnecessarily [S1].
        $$
        \mathcal{L}_V = \sum_i w_i
        $$
    *   **Weight Transition Loss ($\mathcal{L}_T$):** Encourages the maximum likelihood delta component to change $i^*$ when a discontinuity is required [S1].
        $$
        \mathcal{L}_T = \max(0, \varepsilon_T - |\nabla_p w_{1n}|)^2
        $$
        where $\varepsilon_T$ is a hyper-parameter controlling the desired transition speed [S1].

**Parameters:**
*   $\gamma_d, \gamma_\xi, \gamma_n, \gamma_V, \gamma_T, \gamma_{\text{E},d}, \gamma_{\text{E},\xi}$: Weighting hyper-parameters for each loss term. Values not given in the sources.
*   $\varepsilon_T$: Hyper-parameter for transition speed. Value not given in the sources.
*   $K=2$: The number of delta components [S1].

**Pseudocode:**
```python
def pddf_shape_fitting_loss(p, v, d_gt, n_gt, xi_gt, xi_b_gt, 
                            d_pred, xi_pred, w_pred, 
                            gamma_d, gamma_xi, gamma_n, gamma_V, gamma_T, 
                            gamma_E_d, gamma_E_xi, epsilon_T):
    """
    Computes the PDDF Shape-Fitting Loss.
    
    Args:
        p: Position tensor.
        v: View direction tensor.
        d_gt: Ground truth depth tensor.
        n_gt: Ground truth normal tensor.
        xi_gt: Ground truth visibility tensor.
        xi_b_gt: Ground truth visibility tensor for BCE (xi_b in source).
        d_pred: Predicted depth components tensor [K, ...].
        xi_pred: Predicted visibility tensor.
        w_pred: Predicted weights tensor [K, ...].
        gamma_d, gamma_xi, gamma_n, gamma_V, gamma_T, gamma_E_d, gamma_E_xi: Loss weights.
        epsilon_T: Transition speed hyper-parameter.
        
    Returns:
        Total loss scalar.
    """
    # Find maximum likelihood index i*
    # w_pred shape: [K, ...]
    # argmax returns indices along dim 0
    i_star = torch.argmax(w_pred, dim=0)
    
    # Gather the depth component corresponding to i*
    # d_pred shape: [K, ...]
    # We need to index d_pred with i_star. 
    # Assuming standard broadcasting or gather implementation:
    # d_b_i_star = d_pred[i_star, ...]
    # Note: In a real implementation, gather or advanced indexing is used.
    # Here we assume a helper or direct indexing if shapes align.
    # For simplicity in pseudocode, we assume d_pred[i_star] retrieves the correct component.
    d_b_i_star = d_pred[i_star]
    
    # Compute predicted normal from gradient of d_b_i_star w.r.t p
    # n_b_i_star = gradient(d_b_i_star, p)
    # Note: Source says n_b_i*(p,v) via grad_p d_b_i*.
    # We assume a function compute_gradient that returns the gradient vector.
    n_b_i_star = compute_gradient(d_b_i_star, p)
    
    # 1. Minimum Distance Loss L_d
    # L_d = xi | d_b_i* - d |
    # xi is ground truth visibility (xi_gt)
    L_d = xi_gt * torch.abs(d_b_i_star - d_gt)
    
    # 2. Visibility Objective L_xi
    # L_xi = BCE(xi, xi_b)
    # xi is prediction (xi_pred), xi_b is ground truth (xi_b_gt)
    L_xi = binary_cross_entropy(xi_pred, xi_b_gt)
    
    # 3. Normals Loss L_n
    # L_n = -xi | n^T n_b_i* |
    # n is ground truth normal (n_gt)
    # xi is ground truth visibility (xi_gt)
    dot_product = torch.sum(n_gt * n_b_i_star, dim=-1)
    L_n = -xi_gt * torch.abs(dot_product)
    
    # 4. Directed Eikonal Regularization L_DE
    # L_DE = gamma_E_d * sum_i [ xi * (grad_i(d_i) . v + 1)^2 ] + gamma_E_xi * [ xi * (grad_xi(xi) . v)^2 ]
    # Note: Source formula has xi inside the sum for d and outside for xi? 
    # Source: gamma_E,d Σ_i ξ [∇_i d̂_i v + 1]^2 + γ_E,ξ [∇_ξ ξ̂ v]^2
    # It seems xi (ground truth visibility) is used as a mask for the depth term.
    
    L_DE_d = torch.zeros_like(L_d)
    for i in range(K):
        grad_d_i = compute_gradient(d_pred[i], p)
        term = torch.sum(grad_d_i * v, dim=-1) + 1
        L_DE_d += xi_gt * (term ** 2)
    L_DE_d = gamma_E_d * L_DE_d
    
    grad_xi = compute_gradient(xi_pred, p)
    term_xi = torch.sum(grad_xi * v, dim=-1)
    L_DE_xi = gamma_E_xi * (term_xi ** 2)
    
    L_DE = L_DE_d + L_DE_xi
    
    # 5. Weight Field Regularization L_W
    # L_V = sum_i w_i
    L_V = torch.sum(w_pred, dim=0)
    
    # L_T = max(0, epsilon_T - |grad_p w_1n|)^2
    # Note: Source says "using w1 alone is sufficient". 
    # w_1n likely refers to the gradient of w_1 along the normal direction n? 
    # Or gradient of w_1? Source: |∇_p w_1n|. 
    # Given "w_1n" and context of "transition speed", it might be the gradient of w_1.
    # However, "w_1n" is ambiguous. Let's assume it means the gradient of w_1 with respect to p.
    # But wait, "w_1n" could mean w_1 projected on n? 
    # Source text: "LT = max(0, εT − |∇pw1n|) 2". 
    # In many contexts, subscript n denotes normal component. 
    # But ∇_p is spatial gradient. 
    # Let's assume it is the magnitude of the spatial gradient of w_1.
    # If it meant normal component, it would likely be (∇_p w_1 . n).
    # Given the ambiguity, we compute the magnitude of the gradient of w_1.
    # Note: L_T is only applied to S and T data. We assume a mask is applied later or inputs are filtered.
    grad_w1 = compute_gradient(w_pred[0], p)
    mag_grad_w1 = torch.norm(grad_w1, dim=-1)
    L_T = torch.clamp(epsilon_T - mag_grad_w1, min=0) ** 2
    
    L_W = gamma_V * L_V + gamma_T * L_T
    
    # Total Loss
    L_S = gamma_d * L_d + gamma_xi * L_xi + gamma_n * L_n + L_DE + L_W
    
    return L_S
```

**Edge Cases and Pitfalls:**
*   $\mathcal{L}_T$ is only applied to oriented points that are surface (S) and tangent (T) data, where a discontinuity is desired [S1]. Applying it to other data types (e.g., occluded points) is incorrect [S1].
*   The index $i^*$ is determined by the maximum weight $w_j$. If weights are equal, the behavior is not specified [S1].
*   Precision issues may arise in gradient computation for $\mathcal{L}_{\text{DE}}$ and $\mathcal{L}_T$ if the network outputs are not smooth [S1].

## Subtopics

### [Conditional Probabilistic Directed Distance Field (CPDDF)](17904-conditional-probabilistic-directed-distance-field-cpddf.md)
The Conditional Probabilistic Directed Distance Field (CPDDF) is a generative method that encodes 3D shapes into a latent vector and decodes it into a depth field for efficient rendering. It builds on [PDDF Shape-Fitting Loss](9353-pddf-shape-fitting-loss.md) by conditioning the probabilistic distance field on a learned latent representation $z_s$ rather than a fixed parameterization. This allows for the generation of diverse shapes from a Gaussian prior while maintaining the rendering efficiency of directed distance fields.

## Operating characteristics
*   **Time Complexity:** Not given in the sources.
*   **Memory Complexity:** Not given in the sources.
*   **Measured Performance:** Not given in the sources.
*   **Strengths:** Encourages low entropy outputs to prevent unnecessary switching of the maximum likelihood component, while allowing transitions at discontinuities [S1]. Uses directed Eikonal regularization for better surface alignment [S1].
*   **Limitations:** Requires careful tuning of hyper-parameters ($\gamma$ values, $\varepsilon_T$) [S1]. The transition loss $\mathcal{L}_T$ is only applicable to specific data types (S and T) [S1].
*   **When to use:** When training PDDF models for ray-based shape representations where probabilistic depth prediction is beneficial [S1].
*   **When not to use:** When a deterministic SDF is sufficient and probabilistic modeling adds unnecessary complexity [S1].

## Background
The PDDF Shape-Fitting Loss was introduced in the paper "Probabilistic Directed Distance Fields for Ray-Based Shape Representations" [S1]. It is part of the broader development of Probabilistic Directed Distance Fields (PDDF) for representing 3D shapes. The method builds on prior work in SDF training and directed distance fields [S1].
