# Polyhedral Primitives
Also called: Polyhedral SDFs, Polyhedron Signed Distance Functions
## Overview
This family provides exact signed distance functions (SDFs) for convex polyhedra and prisms, enabling precise ray marching and collision detection without mesh discretization. Unlike smooth primitives like spheres or tori, polyhedral primitives exhibit sharp edges and vertices, requiring specific geometric logic (such as face identification or space folding) to compute the Euclidean distance correctly. They are distinguished from general polyhedral approximations by providing analytical, non-iterative solutions for specific symmetric shapes.
## Shared principles
All primitives in this family compute the Euclidean signed distance $d$ from a query point $p$ to the surface of a canonical shape centered at the origin.
1.  **Symmetry Reduction**: Most primitives exploit reflectional symmetry across coordinate planes. The first step is typically computing $q = |p|$, mapping the query point into the first octant (or a smaller fundamental domain). This simplifies the distance calculation by reducing the number of cases to check [S1, unofficial].
2.  **Signed Distance Convention**: The output $d$ is negative if $p$ is inside the primitive, positive if outside, and zero on the surface.
3.  **Composition for Extrusions**: Prisms (Triangular, Hexagonal) are often computed by combining the 2D cross-section distance $d_{2D}$ with the 1D height distance $d_{cap}$. The standard composition for an extruded primitive is:
    $$ d = \min(\max(d_{2D}, d_{cap}), 0.0) + \text{length}(\max(d_{2D}, d_{cap}, 0.0)) $$
    where $\text{length}$ is the Euclidean norm. If the point is inside both bounds ($d_{2D} \le 0$ and $d_{cap} \le 0$), the distance is simply the maximum of the two negative values (closest to the surface). If outside, the distance is the hypotenuse of the distances to the nearest face and cap .
4.  **Fundamental Domain Folding**: Complex polyhedra like the Dodecahedron use a sequence of rotations and reflections to fold the 3D space into a fundamental region (a wedge or pyramid) where the closest feature is always a single face or edge. The distance is then computed relative to the boundaries of this folded region [S1, unofficial].
## Subtopics

### [Octahedron Signed Distance Function](2339-octahedron-signed-distance-function.md)
Computes the exact signed distance to an octahedron. It is distinguished by its reliance on a specific face-identification logic based on the sum of absolute coordinates and permutations to handle the central region vs. face regions. Choose this when a symmetric, axis-aligned octahedron is needed.

### [Hexagonal Prism Signed Distance Function](2348-hexagonal-prism-signed-distance-function.md)
Computes the distance to a hexagonal prism aligned with the Z-axis. It differs from the triangular prism by using a six-sided cross-section, allowing for denser packing or specific geometric modeling needs, while remaining computationally cheaper than complex polyhedra like the dodecahedron. Choose this for hexagonal columns or tiles.

### [Triangular Prism Signed Distance Function](2865-triangular-prism-signed-distance-function.md)
Computes the distance to an equilateral triangular prism. It differs from general polyhedral SDFs by exploiting the symmetry of the equilateral cross-section to use a closed-form analytical solution without iterative projection. Choose this for triangular columns or architectural elements.

### [Dodecahedron Modulo](3737-dodecahedron-modulo.md)
Computes the distance to a regular dodecahedron by folding the input space into a fundamental region using a sequence of reflections and rotations. It is distinguished by its complex folding sequence involving the golden ratio and dihedral angles. Choose this for high-symmetry 12-sided polyhedra.

### Pyramid Signed Distance Function
Computes the signed distance function for a pyramid with height $h$.
- Calculate $m_2 = h^2 + 0.25$ [S1, unofficial].
- Take the absolute value of the XZ components of $p$ [S1, unofficial].
- Swap X and Z if $Z > X$ to fold the pyramid into a fundamental domain [S1, unofficial].
- Subtract $0.5$ from X and Z [S1, unofficial].
- Calculate $q$ as a transformed vector: $q = (p_z, h p_y - 0.5 p_x, h p_x + 0.5 p_y)$ [S1, unofficial].
- Calculate $s = \max(-q_x, 0.0)$ [S1, unofficial].
- Calculate $t = \text{clamp}((q_y - 0.5 p_z) / (m_2 + 0.25), 0.0, 1.0)$ [S1, unofficial].
- Calculate squared distances $a$ and $b$ to the edges [S1, unofficial].
- Calculate $d_2$ as the minimum of $a$ and $b$, or $0$ if inside [S1, unofficial].
- Return the final signed distance [S1, unofficial].

### Rhombus Signed Distance Function
Computes the signed distance function for a rhombus with semi-axes $s$ and height $h$.
- Calculate $f$ using the dot product of $s$ and $s - 2 p_{xz}$, clamped to $[-1, 1]$ [S1, unofficial].
- Calculate $q_x$ as the length of the vector from the rhombus edge minus the radius, multiplied by the sign [S1, unofficial].
- Return the signed distance using the min/max/length formula for box-like shapes [S1, unofficial].

## Background
The analytical SDFs for polyhedra are primarily derived from the work of Inigo Quilez, who popularized exact distance functions for ray marching in his online articles and GLSL code snippets [S1, unofficial]. The specific implementations for the Octahedron, Triangular Prism, and Hexagonal Prism are widely available in open-source ray tracing repositories such as Torch-Sphere-Tracer [S1, unofficial]. The Dodecahedron modulo approach relies on spherical tiling and fundamental domain folding techniques described in specialized graphics literature [S1, unofficial]. These primitives are used in procedural modeling, collision detection in physics engines, and real-time rendering where mesh loading is prohibitive.
