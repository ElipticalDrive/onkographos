# SDF Smoothness Loss

Also called: Gradient Penalty Loss, SDF Gradient Regularization, Smooth Loss (Ls)

## Overview
SDF Smoothness Loss regularizes the reconstructed surface by penalizing the difference between the spatial gradients of the Signed Distance Function (SDF) at adjacent sampled points, thereby encouraging geometric smoothness and reducing high-frequency noise in the predicted field [S1]. Unlike the Eikonal loss which enforces the unit-norm constraint on the gradient magnitude, this loss enforces continuity of the gradient direction and magnitude across local neighborhoods [S1].

## How it works
**Inputs and Outputs:**
- Input: A set of sampled 3D points $\mathcal{X}$, the SDF network $d_\Omega(\mathbf{p})$, and a small perturbation vector $\varepsilon$.
- Output: A scalar loss value $\mathcal{L}_s$.

**Data Structures:**
- $\mathcal{X}$: Set of $N_{sm}$ query points $\mathbf{p}$.
- $d_\Omega(\mathbf{p})$: Scalar SDF value predicted by the MLP for point $\mathbf{p}$.
- $\nabla d_\Omega(\mathbf{p})$: Spatial gradient of the SDF at $\mathbf{p}$, computed via automatic differentiation.

**Steps:**
1. For each point $\mathbf{p} \in \mathcal{X}$, compute the SDF gradient $\nabla d_\Omega(\mathbf{p})$ with respect to $\mathbf{p}$.
2. Compute a perturbed point $\mathbf{p}' = \mathbf{p} + \varepsilon$.
3. Compute the SDF gradient at the perturbed point $\nabla d_\Omega(\mathbf{p}')$.
4. Calculate the Euclidean distance between the two gradient vectors.
5. Average these distances over all $N_{sm}$ points.

**Formula:**
The smooth loss $\mathcal{L}_s$ is defined as [S1]:
$$ \mathcal{L}_s = \frac{1}{N_{sm}} \sum_{\mathbf{p} \in \mathcal{X}} \| \nabla d_\Omega(\mathbf{p}) - \nabla d_\Omega(\mathbf{p} + \varepsilon) \|_2 $$
where:
- $N_{sm}$ is the number of points used to compute the loss.
- $\varepsilon$ is a small perturbation applied to the point.
- $\nabla d_\Omega(\mathbf{p})$ is the gradient of the SDF output produced by the geometry MLP at $\mathbf{p}$.

**Parameters:**
- $\varepsilon$: Small perturbation magnitude. Not given in the sources.
- $N_{sm}$: Number of sampled points. Not given in the sources.

**Pseudocode:**
```python
def compute_sdf_smooth_loss(sdf_network, points, epsilon):
    """
    Computes the SDF Smoothness Loss.
    
    Args:
        sdf_network: Neural network predicting SDF values.
        points: Tensor of shape (N, 3) containing query points p.
        epsilon: Tensor of shape (3,) or (N, 3) containing perturbation vector.
        
    Returns:
        Scalar loss value.
    """
    # Compute gradients at original points
    points.requires_grad_(True)
    sdf_values = sdf_network(points)
    grad_original = torch.autograd.grad(
        sdf_values, points, grad_outputs=torch.ones_like(sdf_values),
        create_graph=True, retain_graph=True, only_inputs=True
    )[0]
    
    # Compute perturbed points
    points_perturbed = points + epsilon
    
    # Compute gradients at perturbed points
    points_perturbed.requires_grad_(True)
    sdf_values_perturbed = sdf_network(points_perturbed)
    grad_perturbed = torch.autograd.grad(
        sdf_values_perturbed, points_perturbed, grad_outputs=torch.ones_like(sdf_values_perturbed),
        create_graph=True, retain_graph=True, only_inputs=True
    )[0]
    
    # Compute L2 distance between gradients
    diff = grad_original - grad_perturbed
    loss = torch.mean(torch.norm(diff, dim=1))
    
    return loss
```

## Subtopics

### SDF Field Regularization
A variant for discrete SDF fields (e.g., on tetrahedral meshes) that uses normal smoothing via gradient alignment and K-nearest neighbor weighted averaging [S2, unofficial]. It expresses the gradient within a tetrahedron as a function of SDF values at vertices and spatial gradients of interpolation weights, then aligns these gradients with those of a smoothed SDF field [S2, unofficial]. The regularization term is [S2, unofficial]:
$$ \mathcal{L}_{reg} = 0.5 \sum_t \left(1 - \frac{\nabla sdf_t \cdot \nabla sdf_{t,smooth}}{\|\nabla sdf_t\| \|\nabla sdf_{t,smooth}\|}\right)^2 $$
where $\nabla sdf_t$ is the gradient in tetrahedron $t$, and $\nabla sdf_{t,smooth}$ is the gradient of the smoothed SDF [S2, unofficial]. It also employs a total variation loss on mesh edges [S2, unofficial]. Parameters include weight factors $w_{reg}$ and $w_{tv}$ [S2, unofficial].

## Operating characteristics
- **Time Complexity**: Requires two forward passes with gradient computation per point (original and perturbed), doubling the gradient computation cost compared to a single Eikonal loss evaluation.
- **Memory Complexity**: Requires storing intermediate gradients for both the original and perturbed points during backpropagation.
- **Strengths**: Effective at suppressing high-frequency noise and ensuring local geometric smoothness in neural SDF representations [S1].
- **Limitations**: Sensitive to the choice of perturbation $\varepsilon$; if $\varepsilon$ is too large, it may smooth out fine details; if too small, numerical instability may occur. Not given in the sources.

## Background
The SDF Smoothness Loss was introduced in the context of ray-distance volume rendering for neural scene reconstruction to address depth ambiguities and improve surface quality [S1]. It complements the Eikonal loss by focusing on gradient continuity rather than just gradient magnitude [S1].
