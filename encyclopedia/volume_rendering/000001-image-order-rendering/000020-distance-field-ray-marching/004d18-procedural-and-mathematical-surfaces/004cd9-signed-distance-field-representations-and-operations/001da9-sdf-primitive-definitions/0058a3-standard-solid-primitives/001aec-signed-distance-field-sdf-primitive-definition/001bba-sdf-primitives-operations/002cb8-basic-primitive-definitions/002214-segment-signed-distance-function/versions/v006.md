# Segment Signed Distance Function

Also called: Segment SDF, sdSegment, Distance to line segment

## Overview
The Segment Signed Distance Function computes the Euclidean distance from a query point to a finite line segment defined by two endpoints. It solves the problem of determining proximity to 1D geometric primitives in 3D space, serving as the foundational building block for more complex shapes like capsules and tubes. It differs from infinite line distance functions by clamping the projection parameter to the segment bounds, ensuring the result is zero if the point lies on the segment and correctly handling points projecting outside the endpoints [S3, S4, unofficial].

## How it works
**Inputs and Outputs:**
*   **Input:** Query point $p$ (vector), segment endpoints $a$ and $b$ (vectors).
*   **Output:** Scalar signed distance $d$. Note: While the parent family defines signed distance with negative values inside, a line segment has zero volume. Standard implementations return the non-negative Euclidean distance [S1, S3, S4, unofficial]. For signed operations (e.g., in CSG), the sign is often determined by an external orientation or treated as unsigned distance [S2, S3, unofficial].

**Data Structures:**
*   Vectors $p, a, b$ of dimension $N$ (typically 2 or 3).
*   Scalar intermediate values for projection parameter $t$ or $h$.

**Steps:**
1.  Compute the segment vector: $ab = b - a$.
2.  Compute the vector from the start point to the query point: $ap = p - a$.
3.  Compute the squared length of the segment: $len\_sq = ab \cdot ab$.
4.  Handle degenerate segments: If $len\_sq$ is near zero (e.g., $< 10^{-12}$), the segment is a point. The closest point is $a$ (or $b$). Return $\|p - a\|$ [S3, S4, unofficial].
5.  Compute the projection parameter $t$ (or $h$) of $p$ onto the line defined by $ab$:
    $$ t = \frac{ap \cdot ab}{len\_sq} $$
6.  Clamp $t$ to the segment bounds $[0, 1]$:
    $$ t_{clamped} = \text{clamp}(t, 0.0, 1.0) $$
7.  Compute the closest point on the segment:
    $$ closest = a + ab \cdot t_{clamped} $$
8.  Return the Euclidean distance:
    $$ d = \| p - closest \| $$

**Alternative Formula (Normalized):**
Some implementations normalize the direction vector first [S2, unofficial]:
1.  $v = \frac{b - a}{\|b - a\|}$
2.  $l = \text{clamp}(v \cdot (p - a), 0, \|b - a\|)$
3.  $d = \| p - a - l \cdot v \|$

**Parameters:**
*   $p$: Query point.
*   $a, b$: Segment endpoints.
*   Epsilon for degenerate check: Typically $10^{-12}$ or $10^{-8}$ depending on precision requirements [S3, S4, unofficial].

**Edge Cases and Pitfalls:**
*   **Degenerate Segment:** If $a = b$, the denominator in step 4 becomes zero. Division by zero must be avoided by checking $len\_sq$ against a small epsilon [S3, S4, unofficial].
*   **Precision:** In floating-point arithmetic, checking for exact equality with zero is unsafe. Use epsilon comparisons for degenerate checks [S4, unofficial].
*   **Signedness:** As a 1D object in 3D space, it has no interior. The "signed" aspect is often implicit or handled by the caller (e.g., in CSG operations) rather than the primitive itself returning negative values for "inside" [S1, S3, unofficial].

**Pseudocode:**
```python
def sd_segment(p, a, b):
    """
    Computes the Euclidean distance from point p to the segment [a, b].
    
    Args:
        p: Vector-like object with subtraction, dot product, and length.
        a: Start point of the segment.
        b: End point of the segment.
        
    Returns:
        float: Distance from p to the closest point on the segment.
    """
    # 1. Segment vector
    ab = b - a
    
    # 2. Vector from start to query point
    ap = p - a
    
    # 3. Squared length of segment
    len_sq = ab.dot(ab)
    
    # 4. Handle degenerate segment (point)
    if len_sq < 1e-12:
        return p.length() # Distance from p to a (since a == b)
    
    # 5. Projection parameter
    t = ap.dot(ab) / len_sq
    
    # 6. Clamp to segment bounds
    t = max(0.0, min(1.0, t))
    
    # 7. Closest point
    closest = a + ab * t
    
    # 8. Distance
    return (p - closest).length()
```

## Subtopics

### Point on Segment Check
Checks if a query point $Q$ lies on the line segment between endpoints $P_i$ and $P_j$. It calculates the distances $d_1 = \|P_i - Q\|$, $d_2 = \|P_j - Q\|$, and $d_3 = \|P_i - P_j\|$. If $d_3 + \epsilon < d_1 + d_2$, the point is not on the segment (triangle inequality violation due to floating point error or actual deviation); otherwise, it is considered on the segment. Uses an epsilon of $10^{-8}$ [S4, unofficial].

### Point-to-Segment Distance
Computes the closest point on a line segment $[v_0, v_1]$ to a query point $p$. The result is guaranteed to lie on the closed segment by clamping the interpolation parameter $t$ to $[0, 1]$. Supports generic vector types with arithmetic and dot product support [S5].

### Capsule Signed Distance Function — 2D Capsule SDF
Computes the signed distance to a 2D capsule (stadium shape) defined by endpoints $a$ and $b$ and radius $r$. The formula is simply the segment distance minus the radius: $d = \text{segment}(p, a, b) - r$. Negative values indicate the point is inside the capsule [S3, unofficial].

## Operating characteristics
*   **Time Complexity:** $O(1)$. Involves a constant number of vector subtractions, dot products, and a square root.
*   **Memory Complexity:** $O(1)$. No auxiliary data structures required.
*   **Strengths:** Extremely fast, numerically stable (with epsilon checks), and differentiable almost everywhere (gradient is the normalized vector from closest point to $p$, except at endpoints and the midpoint of degenerate cases).
*   **Limitations:** Not signed in the traditional volumetric sense (no interior). Requires epsilon handling for degenerate cases.
*   **When to use:** Ray marching for thin objects, collision detection, proximity queries.
*   **When not to use:** When a true volumetric interior is required (use Cylinder or Capsule instead).

## Background
The segment distance function is a fundamental primitive in Signed Distance Field (SDF) rendering, popularized by Inigo Quilez's online articles on distance functions [S2, S3, unofficial]. It is widely used in real-time graphics for rendering thin structures like wires, hair, and tubes without explicit mesh geometry. The algorithm is derived from basic vector projection geometry [S1, S4, unofficial].
