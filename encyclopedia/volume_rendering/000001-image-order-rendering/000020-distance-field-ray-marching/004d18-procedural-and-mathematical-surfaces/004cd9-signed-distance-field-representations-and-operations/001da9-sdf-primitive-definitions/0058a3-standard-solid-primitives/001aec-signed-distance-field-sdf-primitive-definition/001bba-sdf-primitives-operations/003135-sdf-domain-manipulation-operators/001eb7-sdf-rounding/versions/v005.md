# SDF Rounding

Also called: Distance Offset, Rounded, Rounded Corners in SDFs, Rounding Transformation, SDF Domain Manipulation, SDF Offset, SDF Rounding/Offset

## Overview
SDF Rounding is a geometric transformation that modifies a Signed Distance Function (SDF) by subtracting a constant scalar value from the computed distance. This operation effectively rounds the hard edges and corners of the implicit surface defined by the base SDF, creating a smooth, filleted geometry [S1, S5, unofficial]. It serves as the fundamental mechanism for creating rounded primitives and is the basis for more complex operations like [SDF Onion](1846-sdf-onion.md) [S2, unofficial]. Unlike [Elongation](2440-elongation.md) which stretches space, or [Finite Repetition](2869-finite-repetition.md) which tiles space, SDF Rounding operates directly on the scalar distance field output [S1, S5, unofficial].

## How it works
**Inputs and Outputs:**
*   **Input:** A query point $\mathbf{p}$ in 3D space, a base SDF function $d_{base}(\mathbf{p})$, and a rounding radius $r$ (scalar).
*   **Output:** The rounded signed distance $d_{rounded}(\mathbf{p})$.

**Data Structures:**
No complex data structures are required. The operation is a pure function of the distance value.

**Steps:**
1.  Evaluate the base SDF at the query point $\mathbf{p}$ to obtain the unsigned distance to the surface: $d = d_{base}(\mathbf{p})$.
2.  Subtract the rounding radius $r$ from the distance $d$.
3.  Return the result.

**Formula:**
$$ d_{rounded}(\mathbf{p}) = d_{base}(\mathbf{p}) - r $$

Where:
*   $d_{base}(\mathbf{p})$ is the distance returned by the underlying primitive (e.g., a cube, sphere, or union).
*   $r$ is the radius of the rounding. If $r > 0$, the surface is inset (rounded). If $r < 0$, the surface is expanded (beveled outward). If $r = 0$, the original shape is returned.

**Parameters:**
*   $r$ (float): The rounding radius. Typical values depend on the scale of the primitive. For a unit cube, $r=0.1$ creates a noticeable fillet [S1, unofficial].

**Edge Cases and Pitfalls:**
*   **Negative Distance:** If $d_{base}(\mathbf{p}) < r$, the result is negative. This correctly indicates that the point is inside the rounded volume. The isosurface $d_{rounded}=0$ corresponds to the surface at distance $r$ from the original sharp edges.
*   **Precision:** Subtracting a constant does not introduce numerical instability, but extreme values of $r$ relative to the primitive size may cause the rounded shape to self-intersect or vanish if $r$ exceeds the primitive's minimum feature size (e.g., rounding a thin box too much eliminates it entirely).
*   **Interior vs Exterior:** The operation preserves the sign of the distance. Points outside the original shape remain outside (or become further inside the rounded volume) if $d > r$. Points inside remain inside.

**Pseudocode:**
```python
def sdf_rounding(p, base_sdf, radius):
    """
    Computes the rounded SDF by subtracting a constant radius from the base SDF.
    
    Args:
        p (vec3): Query point.
        base_sdf (function): Function returning distance for the base shape.
        radius (float): The rounding radius.
        
    Returns:
        float: The rounded signed distance.
    """
    # Step 1: Query the base SDF at the original point
    distance = base_sdf(p)
    
    # Step 2: Subtract the radius
    rounded_distance = distance - radius
    
    # Step 3: Return result
    return rounded_distance
```

## Subtopics

### SDF Displacement Maps
SDF Displacement Maps extend the concept of constant offset by using a spatially varying function instead of a constant scalar. The offset is calculated as a function of position and time, allowing for dynamic, organic deformation of the surface [S5, unofficial]. The formula becomes $d_{result}(\mathbf{p}) = d_{base}(\mathbf{p}) + \text{offset}(\mathbf{p}, t)$, where $\text{offset}$ is typically a sinusoidal function [S5, unofficial]. This creates wavy or rippling surfaces while maintaining the analytical distance properties required for ray marching, provided the displacement amplitude is small relative to the wavelength to avoid self-intersection artifacts [S5, unofficial].

## Operating characteristics
**Time and Memory Complexity:**
*   **Time:** $O(1)$ per query. The operation adds a single subtraction to the cost of evaluating the base SDF.
*   **Memory:** $O(1)$. No additional storage is required beyond the base SDF's parameters.

**Measured Performance:**
Performance is identical to the base SDF evaluation. For example, rounding a cube SDF adds negligible overhead compared to the `abs` and `max` operations inherent in the cube definition [S5, unofficial].

**Strengths and Limitations:**
*   **Strengths:** Extremely cheap to compute; analytically exact for the rounded surface; works with any base SDF.
*   **Limitations:** Cannot create complex internal structures or hollow shells on its own (requires [SDF Onion](1846-sdf-onion.md) for that); limited to uniform thickness changes.

**When to use it:**
Use when you need to soften sharp edges of primitives (e.g., rounded cubes, spheres) or create uniform thickness variations. Do not use when you need non-uniform deformation or complex internal voids.

## Background
SDF Rounding is a standard technique in ray marching and implicit surface rendering, popularized by the "ray marching and signed distance fields" tutorials and lectures, such as those from the University of Cambridge [S5, unofficial]. It relies on the mathematical property that the set of points at a constant distance $r$ from a surface forms a parallel surface. By shifting the isosurface threshold, one effectively moves the surface along its normal field. This technique is foundational in procedural geometry generation for real-time graphics [S1, S5, unofficial].
