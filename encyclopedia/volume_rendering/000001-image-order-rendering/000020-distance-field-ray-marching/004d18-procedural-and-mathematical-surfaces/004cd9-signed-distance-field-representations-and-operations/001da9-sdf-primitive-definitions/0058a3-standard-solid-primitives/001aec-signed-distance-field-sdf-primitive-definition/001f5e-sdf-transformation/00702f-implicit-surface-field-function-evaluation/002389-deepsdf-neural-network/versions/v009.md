# DeepSDF Neural Network

Also called: DeepSDF Network Architecture, Neural Implicit Surface Representation, SDF Model

## Overview
DeepSDF is a neural network architecture that learns a continuous signed distance field (SDF) representation for 3D shapes by mapping a shape-specific latent code and 3D coordinates to a signed distance value [S4, unofficial][S6, unofficial]. It solves the problem of implicit surface reconstruction from sparse or unstructured data by learning a continuous implicit function parameterized as a multi-layer perceptron [S3, unofficial]. Unlike [Vox2SDF](4047-vox2sdf.md), which encodes a discrete voxel grid into a latent vector for exact reconstruction, DeepSDF uses a learned prior over shape variations, enabling generalization to unseen shapes within a category at the cost of producing a probabilistic average rather than an exact replica [S1, unofficial][S6, unofficial].

## How it works
**Inputs and Outputs:**
*   **Inputs:** A latent code vector $z \in \mathbb{R}^{d_z}$ representing the shape, and a 3D query point $p \in \mathbb{R}^3$ [S4, unofficial].
*   **Output:** A scalar signed distance value $s \in \mathbb{R}$ [S6, unofficial].

**Data Structures:**
The model is a multi-layer perceptron (MLP) [S3, unofficial]. Architectures vary by implementation:
1.  **Minimal Implementation:** Input dimension $d_z + 3$. Hidden Layer 1: Linear($d_z + 3$, 256) with ReLU activation. Output Layer: Linear(256, 1) [S4, unofficial].
2.  **Detailed Implementation:** Input preparation concatenates $z$ and $p$ along the feature dimension [S6, unofficial]. Layer sequence: Linear(515, 1024) + ReLU $\rightarrow$ Linear(1024, 1024) + ReLU $\rightarrow$ Linear(1024, 1024) + ReLU $\rightarrow$ Linear(2042, 1024) + ReLU (skip connection) $\rightarrow$ Linear(1024, 1024) + ReLU $\rightarrow$ Linear(1024, 1024) + ReLU $\rightarrow$ Linear(2042, 1024) + ReLU (skip connection) $\rightarrow$ Linear(1024, 1) + Tanh activation [S6, unofficial]. Dropout(0.2) is applied after each hidden layer except the final layer [S6, unofficial].

**Numbered Steps:**
1.  **Latent Code Expansion:** Expand the single shape-specific latent code $z$ to match the batch size $B$, resulting in $Z \in \mathbb{R}^{B \times d_z}$ [S4, unofficial].
2.  **Input Concatenation:** For each query point $p_i \in \mathbb{R}^3$, concatenate $z_i$ and $p_i$ to form the input vector $x_i = [z_i; p_i] \in \mathbb{R}^{d_z+3}$ [S4, unofficial].
3.  **Forward Pass:** Pass $x_i$ through the MLP layers. For layers $i$ where skip connections are active (e.g., indices 3 and 6 in the detailed implementation), concatenate the original input $x_i$ to the current hidden representation before applying the linear transformation [S6, unofficial].
4.  **Regularization:** Apply Dropout(0.2) after the output of each hidden layer, excluding the final layer [S6, unofficial].
5.  **Output Activation:** The final layer applies a Tanh activation function, squashing the output to $[-1, 1]$ [S6, unofficial].
6.  **Reshape:** Reshape the output tensor to $(-1, 1)$ to return the SDF values for the batch [S6, unofficial].

**Formulas:**
*   **Input Vector:** $x = \text{concat}(z, p)$ [S4, unofficial].
*   **Skip Connection Input:** $x_{skip} = \text{concat}(h_{prev}, x)$ for specific layers [S6, unofficial].
*   **Output:** $s = \tanh(\text{Linear}_{last}(h_{last}))$ [S6, unofficial].

**Parameters:**
*   **latent_dim ($d_z$):** Dimensionality of the latent code. Default 16 [S4, unofficial], default 512 [S6, unofficial].
*   **hidden_dim:** Width of hidden layers. Default 1024 [S6, unofficial].
*   **num_hidden_layers:** Number of hidden MLP layers. Default 8 [S6, unofficial].
*   **skip_layers:** Indices of layers receiving skip connections. Default [3, 7] (1-based) or [3, 6] (0-based) [S6, unofficial].
*   **lr:** Learning rate for Adam optimizer. Default 0.001 [S4, unofficial].
*   **batch_size:** Number of samples per batch. Default 128 [S4, unofficial].
*   **num_epochs:** Number of training epochs. Default 10 [S4, unofficial].

**Edge Cases and Pitfalls:**
*   **Precision:** The Tanh output limits the SDF range to $[-1, 1]$. Input geometry must be normalized to fit within this range, otherwise SDF values will be clipped [G].
*   **Boundary:** The latent code is category-specific. Querying with a latent code from one category on geometry from another yields undefined results [G].
*   **Degenerate Input:** If the latent code is all zeros or noise, the network outputs a default shape determined by the training distribution [G].

**Pseudocode:**
```python
import torch
import torch.nn as nn

class DeepSDFNetwork(nn.Module):
    def __init__(self, latent_dim=512, hidden_dim=1024, num_hidden_layers=8, skip_layers=(3, 6)):
        super().__init__()
        self.skip_layers = set(skip_layers)
        self.layers = nn.ModuleList()
        # Layer 0
        self.layers.append(nn.Sequential(
            nn.Linear(latent_dim + 3, hidden_dim),
            nn.ReLU(),
            nn.Dropout(0.2)
        ))
        # Hidden Layers 1 to num_hidden_layers-2
        for i in range(1, num_hidden_layers - 1):
            if i in self.skip_layers:
                self.layers.append(nn.Sequential(
                    nn.Linear(hidden_dim + latent_dim + 3, hidden_dim),
                    nn.ReLU(),
                    nn.Dropout(0.2)
                ))
            else:
                self.layers.append(nn.Sequential(
                    nn.Linear(hidden_dim, hidden_dim),
                    nn.ReLU(),
                    nn.Dropout(0.2)
                ))
        # Output Layer
        self.layers.append(nn.Sequential(
            nn.Linear(hidden_dim, 1),
            nn.Tanh()
        ))

    def forward(self, latent_code, points):
        x = torch.cat([latent_code, points], dim=-1)
        h = x
        for i, layer in enumerate(self.layers):
            if i in self.skip_layers:
                h = torch.cat([h, x], dim=-1)
            h = layer(h)
        return h
```

## Subtopics

### Vox2SDF
Vox2SDF is a neural network pipeline that converts a discrete 3D voxel grid into a continuous Signed Distance Field (SDF) representation [S1, unofficial]. It solves implicit surface reconstruction from discrete inputs by encoding the voxel structure into a global latent vector, which is then decoded by a position-conditional Multi-Layer Perceptron (MLP) to predict SDF values at arbitrary 3D coordinates [S1, unofficial]. It builds on [DeepSDF](3051-deepsdf-neural-network.md) by conditioning the SDF prediction on a voxel grid input rather than a category label [S1, unofficial].

### [DeepSDF Training Loop](4738-deepsdf-training-loop.md)
The DeepSDF Training Loop is the optimization procedure for the DeepSDF model, which jointly learns a continuous signed distance field (SDF) representation for 3D shapes and a per-shape latent code. It solves the problem of reconstructing arbitrary 3D geometry from sparse or unstructured point cloud data by mapping (latent code, 3D coordinate) pairs to signed distance values using a multi-layer perceptron. It differs from Vox2SDF by optimizing a continuous implicit function and per-shape latent codes rather than relying solely on a discrete grid decoder.

### DeepSDF Training with Image Latents
Jointly trains a ResNet-18 encoder and DeepSDF to learn an implicit surface per image from a training set [S7]. It encodes the rendering of each shape into a latent vector using ResNet-18, concatenates this latent vector with a query point, and learns the SDF for that point using DeepSDF [S7]. Query points are sampled close to the surface (400,000 points) [S7]. It is trained for 2,000 epochs per category using the ADAM optimizer [S7].

### Learnable Signed Distance Encoding
Uses a learnable sign indicator to compute interpolated signed distances for spatial query points to provide spatial distinguishability perpendicular to the surface, avoiding issues with non-watertight meshes where physical SDF sign might reverse [S8]. It differs from physically computed signed distance (Liu et al. [21]) which fails on general object meshes that are not watertight or have predefined skinning weights, causing ray-to-mesh intersection counting confusion and unexpected sign reversal [S8]. It differs from relative position encoding (PointNet [38]) which concatenates codes and relative coordinate offsets encoded by a shallow MLP (2 hidden layers, 64 hidden sizes) and uses inverse distance weighting. Learnable signed distance shows better performance (PSNR 27.254 vs 26.308 on Lego, 27.881 vs 27.270 on DTU 69) [S8].

### Independent SDF Prediction
Uses two independent SDF networks for deformable and non-deformable entities to learn semantically separable geometry in canonical space [S9]. It assigns a semantic label weight $\omega_j$ to each 3D point based on distance to the nearest 3D joint in the per-entity canonical skeleton $J_{j p0}$: $\omega_j = \exp(-\text{dist}^2 / \sigma^2)$ [S9]. It assigns background weight $\omega_{bg}$ for points far from skeletons: $\omega_{bg} = 1.0 - \text{clamp}(\sum_j \omega_j, 1.0)$ [S9]. It concatenates semantic label (dim 3), canonical point, and pose input (total dim $3+3+n_b$) and passes through the SDF prediction network [S9]. The network $F_{c \to \Omega}^j$ takes input dimension $\mathbb{R}^{3+3+n_b}$ and outputs dimension $\mathbb{R}^{1+256}$ (SDF scalar + 256-dim global feature) [S9].

## Operating characteristics
**Time and Memory Complexity:**
*   **Time:** Inference is $O(L \cdot H)$ per query point, where $L$ is the number of layers and $H$ is the hidden dimension [G]. Training time depends on the number of epochs and batch size [S4, unofficial].
*   **Memory:** Memory usage is dominated by the latent code storage ($O(N \cdot d_z)$ for $N$ shapes) and the MLP weights ($O(L \cdot H^2)$) [G].

**Measured Performance:**

**Scaling:**

**Strengths and Limitations:**
*   **Strengths:** Continuous representation allows for high-resolution mesh extraction; latent code enables compact storage and interpolation of shapes [S1, unofficial].
*   **Limitations:** Requires a large dataset for training; generalization to unseen categories is poor without retraining; the Tanh output limits the SDF range [S6, unofficial].

**When to Use:**
*   Use when a continuous, differentiable representation of 3D shapes is needed for tasks like rendering, editing, or interpolation [S1, unofficial].

**When Not to Use:**
*   Do not use when exact reconstruction of a specific input geometry is required without a learned prior (use [Vox2SDF](4047-vox2sdf.md) instead) [S1, unofficial].

## Background
DeepSDF was introduced as a method for learning continuous signed distance fields [S1, unofficial][S2]. It builds on the idea of using neural networks to represent implicit surfaces, allowing for the learning of shape priors from large datasets of 3D models [S1, unofficial]. The method has been extended to various tasks, including single-view reconstruction [S7], texture editing [S8], and dynamic scene reconstruction [S9].
