# Off-surface Point Loss


## Overview
The off-surface point loss is a regularization term applied during the training of Signed Distance Field (SDF) networks [S1]. It computes a penalty for points sampled in the exterior region of the target geometry based on the network's predicted signed distance values [S1]. It complements the surface SDF loss and is distinct from the [SDF Loss](17752-sdf-loss.md), which primarily targets points on or near the surface [S1].

## How it works
The method operates in the canonical space of the target mesh (e.g., SMPL) [S1]. It involves sampling points in the exterior volume and applying an exponential penalty based on the network's output [S1].

**Inputs:**
- $f_{\sigma_f}(\mathbf{x})$: The SDF network function parameterized by $\sigma_f$, returning the signed distance at point $\mathbf{x}$ [S1].
- $\hat{\mathbf{X}}_{\text{off}}$: A set of sampled points in canonical space [S1].
- $|P|$: The number of points in $\hat{\mathbf{X}}_{\text{off}}$ [S1].

**Outputs:**
- $\mathcal{L}_O$: The scalar off-surface point loss value [S1].

**Data Structures:**
- $\hat{\mathbf{X}}_{\text{off}}$: A set of 3D coordinates. In the source implementation, $|P| = 1024$ [S1]. Points are sampled such that their Euclidean distance to the canonical mesh surface is greater than $20$cm [S1].

**Steps:**
1. Sample $1024$ points $\hat{\mathbf{x}}$ in canonical space such that the distance from $\hat{\mathbf{x}}$ to the canonical mesh surface is $> 20$cm [S1]. Let this set be $\hat{\mathbf{X}}_{\text{off}}$ [S1].
2. For each point $\hat{\mathbf{x}} \in \hat{\mathbf{X}}_{\text{off}}$, evaluate the SDF network $f_{\sigma_f}(\hat{\mathbf{x}})$ [S1].
3. Compute the loss using the formula:
   $$ \mathcal{L}_O = \frac{1}{|P|} \sum_{\hat{\mathbf{x}} \in \hat{\mathbf{X}}_{\text{off}}} \exp \left( -100 \cdot f_{\sigma_f}(\hat{\mathbf{x}}) \right) $$
   where the coefficient $100$ (written as $1e^2$ in the source) scales the penalty [S1].

**Parameters:**
- Number of points $|P|$: $1024$ [S1].
- Distance threshold for sampling: $> 20$cm [S1].
- Exponential coefficient: $100$ ($1e^2$) [S1].
- Weight $\lambda_O$: $100$ (used in total loss combination, though the formula itself contains the internal coefficient) [S1].

**Edge Cases and Pitfalls:**
- If the network predicts negative values for off-surface points, the exponent becomes positive, yielding large loss values [S1].
- The threshold of $20$cm and the coefficient $100$ are calibrated for the specific scale of the SMPL mesh in canonical space [S1].

**Pseudocode:**
```python
import math

def off_surface_point_loss(sdf_network, points_off, num_points=1024):
    """
    Computes the off-surface point loss.
    
    Args:
        sdf_network: Function f_sigma_f(x) returning SDF value.
        points_off: Array of shape (num_points, 3) containing points 
                    > 20cm from the mesh surface in canonical space.
        num_points: Number of points (default 1024).
        
    Returns:
        Scalar loss value.
    """
    # Evaluate SDF at all off-surface points
    sdf_values = [sdf_network(x) for x in points_off]
    
    # Compute exponential penalty: exp(-100 * f(x))
    penalties = [math.exp(-100.0 * v) for v in sdf_values]
    
    # Average over all points
    loss = sum(penalties) / len(penalties)
    
    return loss
```

## Subtopics

### Inside Point Loss
The inside point loss is a variant that regularizes points located inside the mesh [S1]. It samples $1024$ points in canonical space that are inside the mesh and whose distance to the surface is greater than $1$cm [S1]. The loss is defined as:
$$ \mathcal{L}_I = \frac{1}{|P|} \sum_{\hat{\mathbf{x}} \in \hat{\mathbf{X}}_{\text{in}}} \text{sigmoid} \left( 5000 \cdot f_{\sigma_f}(\hat{\mathbf{x}}) \right) $$
where $\hat{\mathbf{X}}_{\text{in}}$ is the set of inside points, and the coefficient is $5000$ ($5e^3$) [S1].

## Background
The off-surface point loss was introduced in the ARAH (Animatable Volume Rendering of Articulated Human SDFs) method [S1]. It is part of a set of regularization losses including Eikonal loss, inside point loss, and skinning loss, designed to train robust SDF representations for articulated human bodies [S1].
