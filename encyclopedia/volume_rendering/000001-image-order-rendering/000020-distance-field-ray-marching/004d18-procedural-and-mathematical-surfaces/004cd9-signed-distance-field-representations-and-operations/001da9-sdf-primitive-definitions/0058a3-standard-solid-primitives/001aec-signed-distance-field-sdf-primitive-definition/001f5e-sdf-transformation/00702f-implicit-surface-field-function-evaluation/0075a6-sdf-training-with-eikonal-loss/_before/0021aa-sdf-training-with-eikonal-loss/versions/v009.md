# SDF Training with Eikonal Loss

Also called: Neural SDF Training with Eikonal Regularization, SDF Surface Training with Eikonal Loss

## Overview
SDF Training with Eikonal Loss is a method for reconstructing a 3D surface $S$ from a point cloud $\{p_i\}$ with normals $\{n_i\}$ by optimizing a neural implicit function $\Phi(x)$ to represent a Signed Distance Field (SDF) [S3]. It solves the problem of learning high-fidelity implicit neural representations directly from raw data without requiring 3D supervision (such as pre-computed occupancy grids) or explicit regularization on the zero level set [S6, unofficial]. Unlike sibling methods like [Batched SDF Inference](2329-batched-sdf-inference.md) which focuses on efficient evaluation, or [SDF Optimization via Finite Differences](3086-sdf-optimization-via-finite-differences.md) which approximates gradients numerically, this method enforces the Eikonal equation $|\nabla \Phi(x)| = 1$ via a differentiable regularization term, implicitly guiding the network to learn a valid distance field [S6, unofficial].

## How it works
**Inputs and Outputs:**
*   **Input:** A point cloud dataset $\{p_i\} \subset \mathbb{R}^3$ with associated normals $\{n_i\} \subset \mathbb{R}^3$ [S3]. Optionally, a bounding box $\Omega$ for sampling [S7, unofficial].
*   **Output:** A trained Multi-Layer Perceptron (MLP) $\Phi(x; \theta)$ that outputs the signed distance to the surface for any input coordinate $x$ [S4, unofficial].

**Data Structures:**
*   **MLP Architecture:** A feedforward neural network mapping $\mathbb{R}^3 \rightarrow \mathbb{R}$. Common configurations include depths $D \in \{4, 6, 8, 10, 15, 20\}$ and widths $W \in \{45, 60, 90\}$, maintaining constant total neurons (e.g., D6-W60 has 360 neurons) [S1, unofficial].
*   **Point Cloud Buffer:** A tensor of shape $(N, 3)$ containing vertex coordinates, optionally normalized to $[-1, 1]^3$ [S1, S7, unofficial].
*   **Optimizer State:** Parameters $\theta$ for the MLP, optimized using Adam [S7, unofficial].

**Numbered Steps:**

1.  **Data Preprocessing:** Load the point cloud vertices. Center the point cloud by subtracting the mean:
    $$ p_{centered} = p - \text{mean}(p, \text{dim}=0) $$
    [S7, unofficial]. Normalize the 3D space to a bounding box, typically $[-1, 1]^3$ [S1, unofficial].

2.  **Pretraining (Optional but Recommended):** Initialize the network using a "Sphere Loss" to provide a stable geometric prior [S1, unofficial][S2].
    *   Sample random points $x$ uniformly within the bounding box.
    *   Compute the analytical SDF of a sphere with radius $R$: $d_{sphere}(x) = \|x\| - R$.
    *   Minimize the Mean Squared Error (MSE): $\mathcal{L}_{sphere} = \frac{1}{N} \sum (\Phi(x) - d_{sphere}(x))^2$ [S1, unofficial][S2].
    *   This phase runs for `pretrain_iters` iterations [S7, unofficial].

3.  **Sampling:** For each optimization step, sample two sets of points:
    *   **Surface Points:** Randomly select $N_s$ points from the input point cloud $\{p_i\}$ [S7, unofficial].
    *   **Eikonal Points:** Randomly select $N_e$ points uniformly from the bounding box $\Omega$ [S7, unofficial].

4.  **Forward Pass:**
    *   Query the MLP for distances and gradients at surface points:
        $$ d_i = \Phi(p_i), \quad g_i = \nabla_x \Phi(p_i) \big|_{x=p_i} $$
        [S7, unofficial].
    *   Query the MLP for distances and gradients at eikonal points:
        $$ d_j = \Phi(x_j), \quad g_j = \nabla_x \Phi(x_j) \big|_{x=x_j} $$
        [S7, unofficial].

5.  **Loss Computation:** The total loss $\mathcal{L}$ is a weighted sum of terms [S3]:
    $$ \mathcal{L} = \mathcal{L}_{data} + \lambda_1 \mathcal{L}_{eikonal} + \lambda_2 \mathcal{L}_{off} $$
    [S3].

    *   **Data Loss ($\mathcal{L}_{data}$):** Constrains the implicit function to match the point cloud and normals [S3].
        $$ \mathcal{L}_{data} = \frac{1}{N_s} \sum_{i=1}^{N_s} \left( |\Phi(p_i)| + \lambda_3 |1 - \langle \nabla_x \Phi(p_i), n_i \rangle| \right) $$
        [S3]. The first term forces the surface to pass through the points; the second aligns the gradient with the provided normal. If normals are unavailable, the second term is omitted [S6, unofficial].

    *   **Eikonal Loss ($\mathcal{L}_{eikonal}$):** Enforces the unit gradient magnitude constraint $|\nabla \Phi(x)| = 1$ [S4, unofficial].
        $$ \mathcal{L}_{eikonal} = \frac{1}{N_e} \sum_{j=1}^{N_e} \left( \|\nabla_x \Phi(x_j)\|_2 - 1 \right)^2 $$
        [S7, unofficial]. Note: Some implementations use the L1 norm $|\|\nabla \Phi\|_2 - 1|$ [S4, unofficial].

    *   **Interior/Off-Surface Loss ($\mathcal{L}_{off}$):** Encourages points off the surface to have non-zero values, specifically penalizing points inside the object to suppress spurious outliers [S3][S7, unofficial].
        $$ \mathcal{L}_{off} = \frac{1}{N_e} \sum_{j=1}^{N_e} \exp(-\beta_0 |d_j|) $$
        [S3]. Here $\beta_0 = 1$ [S3]. In some implementations, this is combined with the Eikonal term using an "inter-weight" [S7, unofficial]:
        $$ \mathcal{L}_{interior} = \exp(-100 \cdot |d_j|) $$
        [S7, unofficial].

6.  **Optimization:**
    *   Compute the total loss:
        $$ \mathcal{L}_{total} = \mathcal{L}_{data} + \lambda_{eik} \mathcal{L}_{eikonal} + \lambda_{inter} \mathcal{L}_{interior} $$
        [S7, unofficial].
    *   Perform backpropagation: `optimizer.zero_grad()`, `loss.backward()`, `optimizer.step()` [S7, unofficial].
    *   Use the Adam optimizer with a learning rate schedule (e.g., starting at $10^{-3}$, decaying by a factor of 10 every 20 epochs) [S1, S7, unofficial].

**Pseudocode:**

```python
import torch
import torch.nn as nn

def eikonal_loss(gradients: torch.Tensor) -> torch.Tensor:
    """
    Computes the Eikonal loss: mean squared error of gradient norm from 1.
    Args:
        gradients: Tensor of shape (N, 3) containing spatial gradients.
    Returns:
        Scalar loss value.
    """
    # Compute L2 norm of gradients along the last dimension
    grad_norms = torch.norm(gradients, p=2, dim=1)
    # Return mean squared difference from 1.0
    return torch.mean((grad_norms - 1.0) ** 2)

def train_sdf(model, optimizer, point_cloud, normals, cfg):
    """
    Training loop for SDF with Eikonal Loss.
    """
    # 1. Preprocessing: Center point cloud
    all_points = point_cloud.clone()
    all_points = all_points - torch.mean(all_points, dim=0, keepdim=True)
    
    # 2. Pretraining (Sphere Loss) - Optional
    if cfg.pretrain_iters > 0:
        for _ in range(cfg.pretrain_iters):
            # Sample random points in bounds
            pretrain_points = get_random_points(cfg.batch_size, cfg.bounds, device='cuda')
            distances = model(pretrain_points)
            # Analytical sphere SDF (radius 1.0)
            sphere_sdf = torch.norm(pretrain_points, dim=1, keepdim=True) - 1.0
            loss = torch.mean((distances - sphere_sdf) ** 2)
            
            optimizer.zero_grad()
            loss.backward()
            optimizer.step()

    # 3. Main Training Loop
    for epoch in range(cfg.num_epochs):
        # Sample surface points
        surface_indices = torch.randint(0, len(all_points), (cfg.batch_size,))
        surface_points = all_points[surface_indices]
        
        # Query surface points
        # Note: model must return (distance, gradient)
        surf_dists, surf_grads = model.get_distance_and_gradient(surface_points)
        
        # Compute Data Loss
        # Term 1: Distance to zero
        loss_dist = torch.mean(torch.abs(surf_dists))
        # Term 2: Normal alignment (if normals provided)
        if normals is not None:
            surf_normals = normals[surface_indices]
            # Normalize gradients to unit length for dot product comparison
            surf_grads_norm = surf_grads / (torch.norm(surf_grads, dim=1, keepdim=True) + 1e-9)
            loss_normal = torch.mean(torch.abs(1.0 - torch.sum(surf_grads_norm * surf_normals, dim=1)))
            loss_data = loss_dist + cfg.lambda_normal * loss_normal
        else:
            loss_data = loss_dist

        # Sample Eikonal points (uniform in bounding box)
        eikonal_points = get_random_points(cfg.batch_size, cfg.bounds, device='cuda')
        eikonal_dists, eikonal_grads = model.get_distance_and_gradient(eikonal_points)
        
        # Compute Eikonal Loss
        loss_eikonal = eikonal_loss(eikonal_grads)
        
        # Compute Interior/Off-Surface Loss
        # Penalize points close to zero that are not on the surface (optional but common)
        # Using exponential decay for points inside/near surface
        loss_interior = torch.mean(torch.exp(-1e2 * torch.abs(eikonal_dists)))
        
        # Total Loss
        loss = loss_data + cfg.eikonal_weight * loss_eikonal + cfg.inter_weight * loss_interior
        
        # Optimization Step
        optimizer.zero_grad()
        loss.backward()
        optimizer.step()
        
        # Learning Rate Scheduler Step (if using LambdaLR)
        lr_scheduler.step()

def get_random_points(n, bounds, device):
    """
    Samples n points uniformly within the bounding box.
    bounds: tuple (min_val, max_val), e.g., (-1.0, 1.0)
    """
    min_val, max_val = bounds
    return torch.rand(n, 3, device=device) * (max_val - min_val) + min_val
```

**Parameters:**
*   $\lambda_{eik}$ (or `eikonal_weight`): Weight for the Eikonal regularization. Typical value: $0.02$ [S2].
*   $\lambda_{inter}$ (or `inter_weight`): Weight for the interior/off-surface loss.
*   $\beta_0$: Exponential decay factor for interior loss. Set to $1$ [S3].
*   Learning Rate: Starts at $10^{-3}$ [S1, unofficial].
*   Weight Decay: $10^{-4}$ [S1, unofficial].
*   Batch Size: Depends on memory; typical values range from 1024 to 4096 points [S7, unofficial].

**Edge Cases and Pitfalls:**
*   **Non-Uniqueness:** The solution to the Eikonal equation vanishing on a point set is not unique. The method relies on implicit regularization (SGD dynamics) to find a plausible SDF rather than an arbitrary one [S6, unofficial].
*   **Vanishing Gradients:** For thin objects, the learned scale parameter $\beta$ in related density transformations can become large, causing gradients to vanish rapidly as distance increases, preventing recovery of thin structures [S13].
*   **Approximation Quality:** The zero-level isosurface only approximates the ground truth; quality depends on MLP capacity (depth/width) [S1, unofficial].
*   **Gradient Computation:** Ensure `requires_grad=True` is set on sampled points before computing gradients to enable backpropagation [S9, unofficial].

## Subtopics

### [Sphere Loss](2750-sphere-loss.md)
A pretraining regularization term that initializes the SDF network to match an analytical sphere, providing a stable geometric prior before refining with point cloud data.

### [MLP Distillation](4829-mlp-distillation.md)
Compresses a large SDF network into a smaller MLP by minimizing output discrepancy, transferring geometric knowledge from a teacher to a student network.

### [SDDF with Ellipsoidal Priors and Neural Residuals](10638-sddf-with-ellipsoidal-priors-and-neural-residuals.md)
Combines explicit ellipsoidal priors with neural residuals to learn a Signed Directional Distance Function, handling occlusions and discontinuities better than standard SDFs.

### [SDF-Instant-NGP Training](10640-sdf-instant-ngp-training.md)
Defines the training procedure for an SDF baseline using Instant-NGP acceleration, explicitly including a sign loss for free-space samples.

### [TetraSDF Training Procedure](13235-tetrasdf-training-procedure.md)
Optimizes an SDF using a multi-resolution tetrahedral grid, combining L1 regression, Eikonal regularization, and weight normalization for efficient mesh extraction.

### [Surface SDF Loss](14235-surface-sdf-loss.md)
A regularizer for Directional Distance Fields (DDF) that enforces consistency with a co-trained SDF by constraining DDF-reconstructed points to lie on the SDF's zero-level set.

### [Geometry Loss](17091-geometry-loss.md)
A composite regularization term incorporating multi-view geometric priors (depth, normals) and topological penalties (bubble loss) alongside SDF regression and Eikonal terms.

### Bias Network for High-Fidelity Points
A network that captures geometric bias between volume rendering and point modeling, trained on high-fidelity points to enhance detail representation [S8, unofficial]. It filters the point set $P$ to create $P_s$ containing only points with predicted variance below threshold $\epsilon$ ($P_s = \{x_P \mid \bar{\sigma}^2(x_P) < \epsilon\}$) [S8, unofficial]. The bias SDF $f_b(x_P)$ is computed via a dedicated MLP, and the final SDF is $f_{final}(x_P) = f(x_P) + f_b(x_P)$ [S8, unofficial]. The network is optimized using L1 loss $\mathcal{L}_{bias} = \frac{1}{D_{P_s}} \sum_{x_P \in P_s} |f_\epsilon(x_P) - f_{final}(x_P)|$, assuming ideal SDF values $f_\epsilon(x_P)$ are 0 [S8, unofficial].

### SDF Training with Chamfer Distance
Trains a neural network to predict Unsigned Distance Function (UDF) values and gradients, projecting query points onto the implicit surface via gradient descent and minimizing Chamfer distance to ground truth points [S9, unofficial]. The projection is computed as $x_{moved} = x_{sample} - \frac{\nabla \text{UDF}(x_{sample})}{\|\nabla \text{UDF}(x_{sample})\|} \cdot \text{UDF}(x_{sample})$ [S9, unofficial]. A critical pitfall is ensuring `samples.requires_grad = True` before computing gradients [S9, unofficial].

### Implicit Surface to Volume Transformation
Represents scene geometry as a surface $S = \{x \in \mathbb{R}^3 \mid F(x) = 0\}$ [S10]. It enforces the Eikonal property on $F$ and transforms the implicit surface into a volumetric model by computing pseudo-density $\sigma_i = \Psi(F(x_i))$ using a Laplace cumulative distribution function: $\Psi(d) = \frac{1}{2} \exp(-d/\beta)$ for $d \geq 0$ and $1 - \frac{1}{2} \exp(d/\beta)$ for $d < 0$ [S10]. The scale parameter $\beta$ is optimizable [S10].

### Sparse Points SDF Loss
Extracts sparse points and weights from a batch, filters points inside the unit sphere, and computes SDF values using an occupancy field. The loss is computed as the mean of `abs(sparse_pts_sdf) * pts_weights` multiplied by 0.0, effectively acting as a placeholder or weak constraint in some pipelines [S11, unofficial].

### SDF Smoothness Loss
Regularizes the reconstructed surface by penalizing gradients of the SDF between adjacent sampled points along a ray, encouraging geometric smoothness [S12].

### Bubble Loss for Thin Object Recovery
Applies a loss term to 'bubbles' (3D points derived from depth images) to enforce zero SDF values, recovering gradients for thin/small objects where standard SDF training fails due to vanishing gradients [S13]. The loss is $L_{bubble} = \sum_{p \in P} |d(x(p, D))|$ [S13].

## Operating characteristics
*   **Time Complexity:** Training time depends on the number of epochs and the cost of computing gradients via backpropagation through the MLP. Inference time for a D6-W60 MLP is approximately 20.8 seconds for mesh extraction (Marching Cubes) on a single object [S1, unofficial].
*   **Memory Complexity:** Memory usage is dominated by the MLP parameters (e.g., D6-W60 has 360 neurons, negligible compared to grid-based methods) and the point cloud data [S1, unofficial].
*   **Performance:** Produces state-of-the-art implicit neural representations with higher fidelity and detail compared to methods requiring 3D supervision [S6, unofficial].
*   **Strengths:** Works directly from raw point clouds without 3D supervision; implicit regularization avoids bad zero-loss solutions; differentiable.
*   **Limitations:** Approximation quality depends on MLP capacity; not unique solution without regularization; may struggle with thin structures without specific losses (e.g., Bubble Loss) [S1, unofficial][S13].
*   **When to Use:** When reconstructing shapes from point clouds with normals is required, and a continuous, differentiable implicit representation is needed for downstream tasks like rendering or editing.
*   **When Not to Use:** When real-time inference is critical without acceleration structures (like Instant-NGP), or when the input data lacks normals and the Eikonal constraint alone is insufficient to resolve ambiguity [S6, unofficial].

## Background
The method originates from the work on Implicit Geometric Regularization for Learning Shapes [S6, unofficial], which demonstrated that encouraging a neural network to vanish on input point clouds and have unit norm gradients leads to high-fidelity implicit neural representations. It builds on earlier works using implicit neural representations [S6, unofficial] and is distinct from NeRF by using SDF values and Eikonal regularization instead of density and color prediction [S7, unofficial]. The approach has been widely adopted in neural surface rendering and implicit geometry representation [S3][S7, unofficial].
