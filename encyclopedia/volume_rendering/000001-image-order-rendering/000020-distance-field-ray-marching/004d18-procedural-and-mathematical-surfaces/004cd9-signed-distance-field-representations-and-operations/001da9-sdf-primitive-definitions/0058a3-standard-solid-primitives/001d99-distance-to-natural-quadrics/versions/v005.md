# Distance to Natural Quadrics

Also called: Natural Quadrics SDF, SDF for Natural Quadrics

## Overview
Distance to Natural Quadrics provides exact signed distance functions (SDFs) for standard solid modeling primitives—specifically planes, spheres, cylinders, cones, and tori—aligned with canonical axes and centered at the origin [S2]. It solves the problem of querying the Euclidean distance from a point to these surfaces for use in distance-field ray marching (sphere tracing) and constructive solid geometry (CSG) [S2][S4, unofficial]. Unlike generic implicit surface solvers, these closed-form solutions are computationally efficient and serve as the foundational building blocks for more complex shapes, blends, and deformations [S2].

## How it works
The method defines the signed distance $d(p)$ for a query point $p$ relative to specific primitive geometries. The sign is negative if $p$ is inside the object and positive if outside [S3, unofficial]. All primitives below assume canonical orientation unless transformed by the caller.

### Inputs and Outputs
- **Input**: Query point $p = (p_x, p_y, p_z)$ in 3D space. Primitive parameters (radius, height, normal, etc.).
- **Output**: Scalar signed distance $d$.

### Data Structures
No complex data structures are required; the functions operate on scalar values or vectors.

### Formulas and Steps

**1. Plane**
A plane is defined by a unit normal vector $n$ and a point $p_0$ on the plane [S2].
$$ d(p) = n \cdot (p - p_0) $$
*Note: The source [S2] notation $n \times (p - p_0)$ is interpreted as the dot product, as the result is a scalar distance.*

**2. Sphere**
A sphere is defined by center $c$ and radius $r$ [S2].
$$ d(p) = \|p - c\| - r $$
For a unit sphere at the origin ($c=0, r=1$):
$$ d(p) = \|p\| - 1 $$

**3. Cylinder (Infinite)**
The source [S2] describes a unit-radius cylinder centered about the z-axis. It projects the point into the xy-plane and measures the distance to the unit circle [S2].
$$ d(p) = \text{dist}_{2D}((p_x, p_y), \text{unit circle}) - 1 $$
Where $\text{dist}_{2D}((x,y), \text{unit circle}) = \sqrt{x^2 + y^2} - 1$.
Thus:
$$ d(p) = \sqrt{p_x^2 + p_y^2} - 1 $$
*Note: Source [S3, unofficial] provides a generic cylinder function `cylinder(p, dim)` returning `length(p.xz) - dim.z`, implying an infinite cylinder aligned with the Y-axis with radius `dim.z`. Source [S1, unofficial] provides a **capped** cylinder SDF, which is distinct from the infinite version in [S2].*

**4. Cone**
A cone centered at the origin oriented along the z-axis with divergence angle $\theta$ [S2].
$$ d(p) = \text{dist}_{2D}((p_x, p_z), \text{cone profile}) $$
The source [S1, unofficial] provides a more robust implementation for a cone defined by radius $r$ and height $h$ (aligned with Y-axis in the code, but described along Z in text). The code in [S1, unofficial] uses:
$$ q = (r, -h) $$
$$ w = (\sqrt{p_x^2 + p_z^2}, p_y) $$
$$ a = w - q \cdot \text{clamp}\left(\frac{w \cdot q}{q \cdot q}, 0.0, 1.0\right) $$
$$ b = w - q \cdot \text{clamp}\left(\frac{w_x}{q_x}, 0.0, 1.0\right) $$
$$ k = \text{sign}(q_y) $$
$$ d = \sqrt{\min(\|a\|^2, \|b\|^2)} \cdot \text{sign}(k(w_x q_y - w_y q_x)) $$

**5. Torus**
A torus is the product of two circles. It is defined by major radius $R$ (distance from center of tube to center of torus) and minor radius $r$ (radius of the tube) [S4, unofficial]. Centered at the origin and spun about the z-axis [S2][S4, unofficial].
Let $q = (\sqrt{p_x^2 + p_z^2} - R, p_y)$ [S4, unofficial].
$$ d(p) = \|q\| - r $$
$$ d(p) = \sqrt{(\sqrt{p_x^2 + p_z^2} - R)^2 + p_y^2} - r $$

### Parameters
- **Torus**: $t[0]$ (Major radius $R$), typical value 0.8; $t[1]$ (Minor radius $r$), typical value 0.3 [S4, unofficial].
- **Cone**: Radius $r$, Height $h$ [S1, unofficial].
- **Sphere**: Radius $r$, Center $c$ [S2].
- **Plane**: Normal $n$, Point $p_0$ [S2].

### Edge Cases and Pitfalls
- **Capped vs Infinite Cylinder**: Source [S2] defines an infinite cylinder. Source [S1, unofficial] defines a capped cylinder. Implementers must distinguish between the two. The capped cylinder SDF in [S1, unofficial] handles the end caps by checking if the point's Y-coordinate is outside the height bounds $[-h, h]$. If so, it adds the distance to the nearest cap [S1, unofficial].
- **Precision**: Square roots are used in all distance calculations. Near the surface, precision issues may arise; however, the closed-form nature avoids iterative solvers [S2].
- **Cone Apex**: The cone SDF in [S1, unofficial] handles the apex and base via the clamp operations on $a$ and $b$, ensuring continuity [S1, unofficial].

### Pseudocode

```python
import math

def sdf_plane(p, n, p0):
    """
    Signed distance to a plane.
    p: query point (x, y, z)
    n: unit normal vector (nx, ny, nz)
    p0: point on the plane (x0, y0, z0)
    """
    return n[0]*(p[0]-p0[0]) + n[1]*(p[1]-p0[1]) + n[2]*(p[2]-p0[2])

def sdf_sphere(p, c, r):
    """
    Signed distance to a sphere.
    p: query point (x, y, z)
    c: center (cx, cy, cz)
    r: radius
    """
    dx = p[0] - c[0]
    dy = p[1] - c[1]
    dz = p[2] - c[2]
    return math.sqrt(dx*dx + dy*dy + dz*dz) - r

def sdf_cylinder_infinite(p, r):
    """
    Signed distance to an infinite cylinder aligned with Z-axis.
    p: query point (x, y, z)
    r: radius
    Note: Source [S2] uses XY plane for cylinder axis Z.
    """
    return math.sqrt(p[0]**2 + p[1]**2) - r

def sdf_cylinder_capped(p, r, h):
    """
    Signed distance to a capped cylinder aligned with Y-axis.
    p: query point (x, y, z)
    r: radius
    h: half-height
    Based on [S1, unofficial].
    """
    # Distance to the infinite cylinder surface
    dist_cyl = math.sqrt(p[0]**2 + p[2]**2) - r
    # Distance to the caps (top and bottom)
    dist_cap = abs(p[1]) - h
    
    # Combine: if inside height bounds, distance is to side; else, distance to cap
    # The formula from [S1, unofficial] is: min(max(dx, dy), 0) + max(norm(max(d, 0)), 0)
    # where d = (dist_cyl, dist_cap)
    
    d_x = dist_cyl
    d_y = dist_cap
    
    # Part 1: min(max(d_x, d_y), 0)
    # This part is 0 if both are positive (outside), or negative if one is negative (inside)
    part1 = min(max(d_x, d_y), 0.0)
    
    # Part 2: max(norm(max(d, 0)), 0)
    # This adds the distance to the boundary if we are outside
    max_d_x = max(d_x, 0.0)
    max_d_y = max(d_y, 0.0)
    part2 = math.sqrt(max_d_x**2 + max_d_y**2)
    
    return part1 + part2

def sdf_cone(p, r, h):
    """
    Signed distance to a cone aligned with Y-axis.
    p: query point (x, y, z)
    r: base radius
    h: height
    Based on [S1, unofficial].
    """
    # q is the point at the base in 2D (radius, -height)
    qx = r
    qy = -h
    
    # w is the point in 2D (radius from axis, y)
    wx = math.sqrt(p[0]**2 + p[2]**2)
    wy = p[1]
    
    # dot product of w and q
    dot_wq = wx*qx + wy*qy
    dot_qq = qx*qx + qy*qy
    
    # clamp factor for projection onto segment q
    t = dot_wq / dot_qq
    t_clamped = max(0.0, min(1.0, t))
    
    # Vector a: projection onto the segment connecting (0,0) to q? 
    # Actually, a is w - q * clamp(...)
    ax = wx - qx * t_clamped
    ay = wy - qy * t_clamped
    
    # Vector b: projection onto the infinite line?
    # b = w - q * clamp(wx/qx, 0, 1)
    # Note: if qx is 0, this is a degenerate cone (line). Assuming qx > 0.
    t_b = wx / qx
    t_b_clamped = max(0.0, min(1.0, t_b))
    
    bx = wx - qx * t_b_clamped
    by = wy - qy * t_b_clamped
    
    # Distance squared
    d_sq_a = ax*ax + ay*ay
    d_sq_b = bx*bx + by*by
    
    d = math.sqrt(min(d_sq_a, d_sq_b))
    
    # Sign
    k = 1.0 if qy < 0 else -1.0 # sign(qy)
    # sign(k * (wx*qy - wy*qx))
    # Note: qy is -h, so qy is negative.
    cross = wx*qy - wy*qx
    s = k * cross
    
    return d * (1.0 if s > 0 else -1.0)

def sdf_torus(p, R, r):
    """
    Signed distance to a torus aligned with Z-axis.
    p: query point (x, y, z)
    R: major radius
    r: minor radius
    Based on [S4, unofficial].
    """
    # q = (sqrt(px^2 + pz^2) - R, py)
    qx = math.sqrt(p[0]**2 + p[2]**2) - R
    qy = p[1]
    
    return math.sqrt(qx**2 + qy**2) - r
```

## Operating characteristics
- **Time Complexity**: $O(1)$ per query. Each SDF involves a constant number of arithmetic operations and square roots.
- **Memory Complexity**: $O(1)$. No auxiliary data structures are stored for the primitive itself.
- **Performance**: Highly efficient for ray marching, allowing large step sizes [S3, unofficial]. The closed-form nature avoids iterative convergence checks required by implicit surface solvers [S2].
- **Strengths**: Exact distances ensure stable ray marching; no tuning of parameters like epsilon or iteration limits is required [S2].
- **Limitations**: Limited to specific canonical orientations. Arbitrary orientation requires transforming the query point $p$ into the primitive's local space before evaluation [G].

## Background
The concept of sphere tracing using signed distance fields was introduced by John C. Hart in 1994 [S2]. The appendix of Hart's paper "Sphere Tracing: A Geometric Method for the Antialiased Ray Tracing of Implicit Surfaces" derives the SDFs for standard solid modeling primitives (Plane, Sphere, Cylinder, Cone, Torus) [S2]. These derivations were intended to aid in the implementation of sphere tracing and serve as a tutorial for developing SDFs for other primitives [S2]. The torus SDF is also widely cited in modern ray marching tutorials and implementations [S4, S3, unofficial].
