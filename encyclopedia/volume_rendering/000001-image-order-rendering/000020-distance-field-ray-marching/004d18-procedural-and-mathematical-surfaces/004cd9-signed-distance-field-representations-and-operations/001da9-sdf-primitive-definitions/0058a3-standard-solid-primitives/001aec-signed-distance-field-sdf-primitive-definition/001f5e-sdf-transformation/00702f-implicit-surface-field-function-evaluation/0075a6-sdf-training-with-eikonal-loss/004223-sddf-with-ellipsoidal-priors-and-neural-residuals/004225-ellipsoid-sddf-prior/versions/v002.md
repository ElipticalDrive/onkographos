# Ellipsoid SDDF Prior

Also called: Ellipsoid Signed Directional Distance Function, Single Ellipsoid SDDF, Ellipsoid-based Prior Network, Prior network P

## Overview
The Ellipsoid SDDF Prior is an explicit geometric representation that approximates the coarse shape of an environment using a set of $M$ learnable ellipsoids [S1]. It serves as the foundational prior for a Signed Directional Distance Function (SDDF), handling occlusions explicitly and providing a closed-form analytical solution for the distance field [S1]. It differs from implicit neural fields by offering an analytic, differentiable geometric prior that satisfies the directional Eikonal equation by construction, leaving fine details to be recovered by a subsequent neural residual network [S1].

## How it works
**Inputs and Outputs:**
*   **Inputs:** Ray origin $\mathbf{p} \in \mathbb{R}^3$, ray direction $\mathbf{v} \in \mathbb{S}^2$ (unit vector), and ellipsoid parameters: center $\mathbf{c} \in \mathbb{R}^3$, rotation matrix $\mathbf{R} \in \mathbb{R}^{3 \times 3}$, and radii vector $\mathbf{r} \in \mathbb{R}^3_+$ [S1].
*   **Outputs:** SDDF value $f(\mathbf{p}, \mathbf{v}; \mathcal{E})$, intersection indicator $i(\mathbf{p}, \mathbf{v})$, and sign indicator $s(\mathbf{p}, \mathbf{v})$ [S1].

**Data Structures:**
*   **Ellipsoid Parameters:**
    *   $\mathbf{c}$: Center position [S1].
    *   $\mathbf{R}$: Rotation matrix [S1]. Parameterized via Lie algebra: $\mathbf{T} = \mathbf{T}_0 \exp(\xi^\wedge)$, where $\mathbf{T}_0$ is a fixed initial pose, $\xi = (\boldsymbol{\rho}, \boldsymbol{\theta}) \in \mathbb{R}^6$ is learnable, $\boldsymbol{\rho}$ is translation, $\boldsymbol{\theta}$ maps to rotation via skew-symmetric matrix $\xi^\wedge$ and matrix exponential [S1].
    *   $\mathbf{r}$: Radii vector [S1]. Parameterized as $\mathbf{r} = \mathbf{r}_0 \exp(\mathbf{s})$, where $\mathbf{r}_0 \in \mathbb{R}^3_+$ is fixed initialization and $\mathbf{s} \in \mathbb{R}^3$ is learnable [S1]. This ensures $\mathbf{r}$ remains positive [S1].
    *   $\mathbf{Q}_0 = \text{diag}(\mathbf{r})$ [S1].

**Formulas and Definitions:**
1.  **Local Frame Transformation:**
    Transform world-space coordinates to the ellipsoid's local frame:
    $$ \mathbf{p}' = \mathbf{R}^\top (\mathbf{p} - \mathbf{c}) $$
    $$ \mathbf{v}' = \mathbf{R}^\top \mathbf{v} $$
    $$ \mathbf{w}' = \mathbf{p}' \times \mathbf{v}' $$
    $$ \mathbf{Q}_1 = \det(\mathbf{Q}_0) \mathbf{Q}_0^{-1} $$
    [S1]

2.  **Intersection Indicator:**
    Determines if the ray intersects the ellipsoid [S1].
    $$ i(\mathbf{p}, \mathbf{v}) = \mathbf{v}'^\top \mathbf{Q}_1^2 \mathbf{v}' - \mathbf{w}'^\top \mathbf{Q}_0^2 \mathbf{w}' $$
    If $i(\mathbf{p}, \mathbf{v}) < 0$, the ray does not intersect the ellipsoid [S1].

3.  **Sign Indicator:**
    Determines if the point is inside or outside the ellipsoid [S1].
    $$ s(\mathbf{p}, \mathbf{v}) = \mathbf{p}'^\top \mathbf{Q}_1^2 \mathbf{p}' - \det(\mathbf{Q}_0)^2 $$
    $s(\mathbf{p}, \mathbf{v}) < 0$ means $\mathbf{p} \in \mathcal{E}$ (inside); $s(\mathbf{p}, \mathbf{v}) > 0$ means $\mathbf{p} \notin \mathcal{E}$ (outside) [S1]. This form is used for better numerical stability than $\mathbf{p}'^\top \mathbf{Q}_0^{-2} \mathbf{p}' - 1$ [S1].

4.  **Validity Function:**
    Handles cases where the ellipsoid is behind the ray [S1].
    $$ \beta = \max(i(\mathbf{p}, \mathbf{v}), 0) + \epsilon, \quad \epsilon > 0 $$
    $$ v(\mathbf{p}, \mathbf{v}) = -\frac{\det(\mathbf{Q}_0)\sqrt{\beta} + \mathbf{p}'^\top \mathbf{Q}_1^2 \mathbf{v}'}{\mathbf{v}'^\top \mathbf{Q}_1^2 \mathbf{v}'} s(\mathbf{p}, \mathbf{v}) $$
    $v(\mathbf{p}, \mathbf{v}) < 0$ indicates the ellipsoid is behind the view ray [S1].

5.  **SDDF Prior Value:**
    $$ f(\mathbf{p}, \mathbf{v}; \mathcal{E}) = \begin{cases} -\frac{\det(\mathbf{Q}_0)\sqrt{\beta} + \mathbf{p}'^\top \mathbf{Q}_1^\top \mathbf{v}'}{\mathbf{v}'^\top \mathbf{Q}_1^\top \mathbf{v}'}, & v(\mathbf{p}, \mathbf{v}) \geq 0 \\ \infty, & v(\mathbf{p}, \mathbf{v}) < 0 \end{cases} $$
    When $i(\mathbf{p}, \mathbf{v}) < 0$ (no intersection) and valid, this simplifies to the distance to a virtual plane: $-\frac{\mathbf{p}'^\top \mathbf{Q}_1^2 \mathbf{v}'}{\mathbf{v}'^\top \mathbf{Q}_1^2 \mathbf{v}'}$ [S1].

**Pseudocode:**
```python
def ellipsoid_sddf_prior(p, v, c, R, r):
    # Helper definitions for self-contained execution
    def diag(vec):
        return [[vec[0], 0, 0], [0, vec[1], 0], [0, 0, vec[2]]]
    def det3x3(M):
        return M[0][0]*(M[1][1]*M[2][2] - M[1][2]*M[2][1]) - M[0][1]*(M[1][0]*M[2][2] - M[1][2]*M[2][0]) + M[0][2]*(M[1][0]*M[2][1] - M[1][1]*M[2][0])
    def inv_diag(M):
        return [[1.0/M[0][0], 0, 0], [0, 1.0/M[1][1], 0], [0, 0, 1.0/M[2][2]]]
    def cross(a, b):
        return [a[1]*b[2] - a[2]*b[1], a[2]*b[0] - a[0]*b[2], a[0]*b[1] - a[1]*b[0]]
    def dot(a, b):
        return a[0]*b[0] + a[1]*b[1] + a[2]*b[2]
    def mat_vec(M, v):
        return [M[0][0]*v[0] + M[0][1]*v[1] + M[0][2]*v[2],
                M[1][0]*v[0] + M[1][1]*v[1] + M[1][2]*v[2],
                M[2][0]*v[0] + M[2][1]*v[1] + M[2][2]*v[2]]
    def mat_mul(A, B):
        return [[A[0][0]*B[0][0]+A[0][1]*B[1][0]+A[0][2]*B[2][0], A[0][0]*B[0][1]+A[0][1]*B[1][1]+A[0][2]*B[2][1], A[0][0]*B[0][2]+A[0][1]*B[1][2]+A[0][2]*B[2][2]],
                [A[1][0]*B[0][0]+A[1][1]*B[1][0]+A[1][2]*B[2][0], A[1][0]*B[0][1]+A[1][1]*B[1][1]+A[1][2]*B[2][1], A[1][0]*B[0][2]+A[1][1]*B[1][2]+A[1][2]*B[2][2]],
                [A[2][0]*B[0][0]+A[2][1]*B[1][0]+A[2][2]*B[2][0], A[2][0]*B[0][1]+A[2][1]*B[1][1]+A[2][2]*B[2][1], A[2][0]*B[0][2]+A[2][1]*B[1][2]+A[2][2]*B[2][2]]]

    # 1. Compute Q0 and Q1
    Q0 = diag(r)
    det_Q0 = det3x3(Q0)
    Q1 = mat_mul([[det_Q0, 0, 0], [0, det_Q0, 0], [0, 0, det_Q0]], inv_diag(Q0))
    Q1_sq = mat_mul(Q1, Q1)
    Q0_sq = mat_mul(Q0, Q0)

    # 2. Transform to local frame
    p_prime = mat_vec(R, [p[0]-c[0], p[1]-c[1], p[2]-c[2]])
    v_prime = mat_vec(R, v)
    w_prime = cross(p_prime, v_prime)

    # 3. Compute Intersection Indicator
    v_Q1_sq_v = dot(v_prime, mat_vec(Q1_sq, v_prime))
    w_Q0_sq_w = dot(w_prime, mat_vec(Q0_sq, w_prime))
    i = v_Q1_sq_v - w_Q0_sq_w

    # 4. Compute Sign Indicator
    p_Q1_sq_p = dot(p_prime, mat_vec(Q1_sq, p_prime))
    s = p_Q1_sq_p - det_Q0**2

    # 5. Compute Validity and SDDF
    epsilon = 1e-8
    beta = max(i, 0.0) + epsilon

    denom_valid = dot(v_prime, mat_vec(Q1_sq, v_prime))
    num_valid = det_Q0 * (beta ** 0.5) + dot(p_prime, mat_vec(Q1_sq, v_prime))

    if denom_valid == 0:
        v_val = 0.0
    else:
        v_val = -(num_valid / denom_valid) * s

    if v_val < 0:
        return float('inf'), i, s

    denom_sddf = denom_valid
    num_sddf = det_Q0 * (beta ** 0.5) + dot(p_prime, mat_vec(Q1, v_prime))

    if denom_sddf == 0:
        f_val = float('inf')
    else:
        f_val = -num_sddf / denom_sddf

    return f_val, i, s
```

**Parameters:**
*   $M$: Number of ellipsoids [S1]. Defines the capacity of the explicit prior [S1]. Typical value not specified [S1].

**Edge Cases and Pitfalls:**
*   **No Intersection:** If $i(\mathbf{p}, \mathbf{v}) < 0$, the SDDF is $\infty$ [S1]. This must be handled to avoid numerical issues [S1].
*   **Ellipsoid Behind Ray:** If $s(\mathbf{p}, \mathbf{v}) > 0$ (point outside) and the ellipsoid is behind the ray, the standard formula yields a negative value, but the true SDDF should be $\infty$ [S1]. The validity function $v(\mathbf{p}, \mathbf{v})$ detects this and returns $\infty$ [S1].
*   **Numerical Stability:** A small $\epsilon > 0$ is added to $\beta$ in the square root term to ensure stable backward propagation [S1].

## Subtopics

### Residual Network for SDDF Correction
Predicts a correction term $\delta_f(\mathbf{p}, \mathbf{v})$ to refine the coarse geometric prior [S1]. It differs from standard MLPs by using a linear transformation of degree-2 monomial embeddings of the intersection point and local direction, inspired by the polynomial nature of the ellipsoid SDDF [S1]. Choose this when fine geometric details must be recovered while preserving the Eikonal constraint [S1]. See [Residual Network for SDDF Correction](10638-sddf-with-ellipsoidal-priors-and-neural-residuals.md#residual-network-for-sddf-correction).

### Fusing Multiple Ellipsoid SDDFs
Computes the SDDF for a union of $M$ ellipsoids by aggregating individual properties via min/max operations [S1]. It differs from single-ellipsoid evaluation by prioritizing intersected ellipsoids and handling scene-level occlusions [S1]. Choose this for multi-object scenes where $O(M)$ per-ray scaling is acceptable [S1]. See [Fusing Multiple Ellipsoid SDDFs](10638-sddf-with-ellipsoidal-priors-and-neural-residuals.md#fusing-multiple-ellipsoid-sddfs).

### Custom Backward Propagation for Ellipsoidal SDDF Prior
Manually implements gradient computation for the ellipsoidal SDDF prior to optimize GPU memory and speed, replacing automatic differentiation [S1]. It differs from standard autograd by explicitly deriving chain-rule gradients for intermediate scalar variables in the local frame [S1]. Choose this when training large-scale scenes with strict memory constraints [S1]. See [Custom Backward Propagation for Ellipsoidal SDDF Prior](10638-sddf-with-ellipsoidal-priors-and-neural-residuals.md#custom-backward-propagation-for-ellipsoidal-sddf-prior).

## Operating characteristics
*   **Complexity:** The prior network computation is $O(M)$ per ray due to the min/max operations over $M$ ellipsoids [S1].
*   **Strengths:** Provides a closed-form, differentiable geometric prior that satisfies the directional Eikonal equation by construction [S1]. Handles occlusions explicitly [S1]. Compatible with unsigned DDF by setting one axis radius to 0 (forming a 2D disk) for non-watertight objects [S1].
*   **Limitations:** The prior network alone provides only a coarse approximation; fine details require the residual network [S1]. Numerical stability requires careful handling of the validity function and $\epsilon$ [S1].
*   **When to use:** When a coarse, analytic geometric prior is needed for scene-level SDDF reconstruction, especially for differentiable rendering or SLAM where Eikonal constraints are beneficial [S1].

## Background
The method originates from the paper "Learning Scene-Level Signed Directional Distance Function With Ellipsoidal Priors and Neural Residuals" [S1]. It addresses the challenge of learning a continuous, implicit representation of scene-level SDDFs, which are sensitive to both position and direction [S1]. The approach builds on the definition of SDDF as a function measuring signed distance from a point to an occupied space along a viewing direction, extending object-level SDDFs to scene-level representations [S1].
