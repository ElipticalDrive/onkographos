# Bubble Loss for Thin Object Recovery
Also called: Lbubble
## Overview
Bubble Loss is a geometric regularization term designed to recover thin or small objects in Signed Distance Field (SDF) representations where standard training fails due to vanishing gradients [S1]. It addresses the limitation that neural SDFs often ignore small structures because the gradient signal from the radiance loss diminishes rapidly as the distance from the learned surface increases [S1]. Unlike standard depth losses that supervise the zero-level set globally, Bubble Loss specifically targets "bubbles"—3D points derived from depth images corresponding to missing geometry—to enforce zero SDF values and restore gradient flow [S1].
## How it works
**Inputs and Outputs:**
- Input: A minibatch of sampled pixels $P$, depth image $D(u,v)$, camera pose $[R|t]$, and camera intrinsics $K$.
- Input: The trained or partially trained SDF network $d(x; \theta)$.
- Output: A scalar loss value $\mathcal{L}_{\text{bubble}}$.

**Data Structures:**
- $D$: A 2D array of depth values, where $D(u,v)$ is the depth at pixel coordinates $(u,v)$.
- $P$: A set of pixel indices $(u,v)$ sampled for the current training iteration.

**Steps:**
1. **Sample Pixels:** Select a minibatch of pixels $P$ from the depth image. Note: The source suggests an error-guided adaptive sampling strategy to avoid wasting computation on well-reconstructed planar areas, focusing instead on error-prone regions [S1].
2. **Back-project to 3D:** For each pixel $p=(u,v) \in P$, compute the corresponding 3D point $x(p, D)$ in the world coordinate system using the depth value and camera parameters [S1]:
   $$ x(p, D) = t + D(u, v) \cdot R K^{-1} \begin{bmatrix} u \\ v \\ 1 \end{bmatrix} $$
   where $t$ is the camera translation vector, $R$ is the rotation matrix, and $K$ is the intrinsic matrix [S1].
3. **Evaluate SDF:** Query the neural network to obtain the predicted SDF value $d(x)$ at the computed 3D point $x(p, D)$ [S1].
4. **Compute Loss:** Calculate the absolute value of the SDF prediction for each point and sum them over the minibatch [S1]:
   $$ \mathcal{L}_{\text{bubble}} = \sum_{p \in P} |d(x(p, D))| $$

**Pitfalls:**
- **Vanishing Gradients:** In standard SDF training, the radiance loss involves a sigmoid function $\sigma(d) = \frac{1}{1 + e^{-\beta d}}$. The derivative $\frac{\partial \sigma}{\partial d}$ vanishes rapidly as the distance $d$ increases, especially when the learned parameter $\beta$ is large [S1]. This prevents gradient flow to thin objects that are not yet close to the zero-level set, causing the network to ignore them [S1]. Bubble Loss circumvents this by directly minimizing $|d(x)|$, which provides a non-vanishing gradient signal even when the SDF value is large, effectively "inserting" a surface at the depth location to guide the SDF growth [S1].

**Pseudocode:**
```python
def bubble_loss(depth_image, camera_pose, intrinsics, sdf_network, sampled_pixels):
    """
    Computes the Bubble Loss for thin object recovery.
    
    Args:
        depth_image: 2D array D(u,v) containing depth values.
        camera_pose: Tuple (R, t) representing rotation matrix and translation vector.
        intrinsics: Matrix K for camera intrinsics.
        sdf_network: Function d(x; theta) evaluating the SDF at point x.
        sampled_pixels: List of pixel coordinates [(u1, v1), ...].
        
    Returns:
        Scalar loss value.
    """
    R, t = camera_pose
    loss_sum = 0.0
    
    for u, v in sampled_pixels:
        # 1. Get depth value
        d_val = depth_image[u, v]
        
        # 2. Back-project to 3D world coordinates
        # Homogeneous pixel coordinate
        pixel_homo = np.array([u, v, 1.0])
        
        # Inverse intrinsic multiplication
        # K_inv is precomputed inverse of intrinsics
        inv_intrinsics = np.linalg.inv(intrinsics)
        ray_dir_cam = inv_intrinsics @ pixel_homo
        
        # Transform ray direction to world space
        ray_dir_world = R @ ray_dir_cam
        
        # Scale by depth and add camera origin
        x_3d = t + d_val * ray_dir_world
        
        # 3. Evaluate SDF at this point
        sdf_val = sdf_network(x_3d)
        
        # 4. Accumulate absolute SDF value
        loss_sum += abs(sdf_val)
        
    return loss_sum
```
## Subtopics

### [SDF Growth Refinement](23288-sdf-growth-refinement.md)
A post-training optimization strategy that uses error-guided sampling to iteratively guide SDF growth from spatial points where missing thin segments meet the existing surface. It builds on the concept of targeting error-prone areas but operates after the initial training phase to further refine thin structures.

## Operating characteristics
- **Complexity:** The computational cost is linear with respect to the number of sampled pixels $|P|$, as it involves a single back-projection and SDF query per pixel.
- **Performance:** It is most effective for scenes containing thin structures (e.g., lamp wires, branches) that are otherwise lost during standard SDF optimization [S1].
- **Limitations:** Applying this loss uniformly across all pixels is computationally wasteful for large planar areas that are already well-reconstructed. Therefore, it is typically combined with an adaptive sampling strategy to focus on regions with high reconstruction error [S1].
- **Scaling:** The loss scales with the number of bubbles inserted; however, since it only requires a forward pass through the SDF network, it integrates efficiently into standard training loops.
## Background
Bubble Loss was introduced in the context of *I²-SDF: Intrinsic Indoor Scene Reconstruction and Editing via Raytracing in Neural SDFs* [S1]. The method was developed to address the specific failure mode of neural SDFs in recovering small or thin geometry, which is a common issue in indoor scene reconstruction where such objects constitute a small percentage of the total volume but are visually significant [S1]. The term "bubble" refers to the artificial surface created at the depth location, which acts as a gradient source to "grow" the SDF field into the missing region [S1].
