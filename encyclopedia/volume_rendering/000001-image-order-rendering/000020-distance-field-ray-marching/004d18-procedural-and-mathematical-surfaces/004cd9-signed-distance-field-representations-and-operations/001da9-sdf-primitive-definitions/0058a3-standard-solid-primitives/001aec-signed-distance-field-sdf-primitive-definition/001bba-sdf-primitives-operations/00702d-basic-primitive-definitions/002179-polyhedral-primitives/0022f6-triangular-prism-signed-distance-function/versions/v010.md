# Triangular Prism Signed Distance Function

Also called: Signed Triangle Prism, Triangular Prism SDF, sdTriPrism

## Overview
Computes the signed distance from a 3D point to an equilateral triangular prism aligned with the Z-axis. It differs from general polyhedral SDFs by exploiting the symmetry of the equilateral cross-section to use a closed-form analytical solution without iterative projection, offering higher performance for this specific primitive [S1, S2, unofficial].

## How it works
**Inputs:**
- `p`: The query point $(x, y, z)$ as a 3D vector.
- `h`: A 2D parameter vector $(h_x, h_y)$ defining the geometry.

**Outputs:**
- `d`: The signed distance. Positive if outside, negative if inside.

**Data Structures:**
- `p`: `vec3` or tuple of floats $(p_x, p_y, p_z)$.
- `h`: `vec2` or tuple of floats $(h_x, h_y)$.

**Steps:**
1.  Compute the absolute value of the input point to exploit symmetry: $q = |p|$. This maps the query point into the first octant.
2.  Calculate the distance to the triangular cross-section in the XY plane. The triangle is equilateral with side length related to $h_x$ and is oriented such that one vertex points along the positive X-axis (or equivalent symmetry axis depending on convention, but the formula below assumes a specific canonical orientation).
3.  Calculate the distance to the top/bottom caps in the Z direction.
4.  Combine these distances using the max function to determine the final signed distance.

**Formula:**
$$
q = |p|
$$
$$
d = \max(q_z - h_y, \max(q_x \cdot \frac{\sqrt{3}}{2} + q_y \cdot \frac{1}{2}, -q_y) - h_x \cdot \frac{1}{2})
$$

Where:
- $q = (q_x, q_y, q_z)$ is the component-wise absolute value of $p$.
- $h_x$ controls the size of the triangular cross-section. Specifically, the distance from the center to the flat side is $h_x/2$. The constant $0.866025 \approx \frac{\sqrt{3}}{2}$.
- $h_y$ is the half-height of the prism along the Z-axis.

**Pseudocode:**
```python
import numpy as np

def sd_tri_prism(p: np.ndarray, h: np.ndarray) -> float:
    """
    Compute signed distance to an equilateral triangular prism.
    
    Args:
        p: Query point (3,)
        h: Geometry parameters (2,) where h[0] is half-width related param, h[1] is half-height
        
    Returns:
        Signed distance
    """
    # Step 1: Absolute coordinates
    q = np.abs(p)
    
    # Constants
    sqrt3_2 = np.sqrt(3) / 2.0  # 0.866025
    half = 0.5
    
    # Step 2: Distance to triangular cross-section
    # The term (q_x * sqrt3_2 + q_y * 0.5) represents the distance to one of the slanted sides
    # The term (-q_y) represents the distance to the flat base side (in the absolute space)
    # We take the max of these two, then subtract the half-width offset
    tri_dist = max(q[0] * sqrt3_2 + q[1] * 0.5, -q[1]) - h[0] * half
    
    # Step 3: Distance to caps
    cap_dist = q[2] - h[1]
    
    # Step 4: Combine
    d = max(cap_dist, tri_dist)
    
    return d
```

**Edge Cases and Pitfalls:**
- **Precision:** The constant $\frac{\sqrt{3}}{2}$ should be computed with sufficient precision (e.g., `np.sqrt(3)/2.0` or `0.8660254037844386`) to avoid artifacts in ray marching.
- **Orientation:** This formula assumes a specific canonical orientation. If the prism is rotated, the point `p` must be transformed into the local frame before applying this function.
- **Inside/Outside:** The function returns negative values inside the prism. Ray marching algorithms typically use this sign to determine step direction or termination.

## Operating characteristics
- **Time Complexity:** $O(1)$. Constant time evaluation involving basic arithmetic operations.
- **Memory Complexity:** $O(1)$. No auxiliary data structures required.
- **Strengths:** Extremely fast evaluation, suitable for real-time rendering and dense volume rendering where many samples are taken per ray.
- **Limitations:** Only applies to equilateral triangular prisms aligned with the Z-axis. For arbitrary triangles or orientations, a more general polyhedral SDF or transformation is needed.
- **When to use:** When rendering scenes with many triangular prism primitives or when performance is critical and the geometry matches the canonical form.

## Background
The triangular prism SDF is a standard primitive in Signed Distance Field (SDF) ray marching, popularized by shaders and libraries such as Inigo Quilez's work and subsequent GLSL utility libraries [S2, unofficial]. It is part of the family of polyhedral primitives that leverage geometric symmetries for efficient distance computation [S1, unofficial].
