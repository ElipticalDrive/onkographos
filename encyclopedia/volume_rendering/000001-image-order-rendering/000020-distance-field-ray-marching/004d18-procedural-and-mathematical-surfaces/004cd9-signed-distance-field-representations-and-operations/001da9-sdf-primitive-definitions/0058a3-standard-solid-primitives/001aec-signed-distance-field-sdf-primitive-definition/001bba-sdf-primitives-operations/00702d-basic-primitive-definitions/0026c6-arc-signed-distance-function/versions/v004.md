# Arc Signed Distance Function

Also called: SDF Arc, sdArc

## Overview
Computes the signed distance from a 3D point to a tube of radius `arc_tube_radius` running along a circular arc defined by a center, orientation, aperture, and radii `ra` and `rb` [S1, unofficial].

## How it works
**Inputs:** Point $p = (p_x, p_y, p_z)$; Arc parameters: `arc_center` ($C$), `arc_tube_radius` ($r_t$), `orientation_angle` ($\theta$), `aperture_angle` ($\alpha$), `ra` ($R_a$), `rb` ($R_b$) [S1, unofficial]. Precomputed constants: `sca_cos` ($\cos \theta$), `sca_sin` ($\sin \theta$), `scb_cos` ($\cos(\alpha/2)$), `scb_sin` ($\sin(\alpha/2)$) [S1, unofficial]. A global `depth` value is used for the z-coordinate of the arc plane [S1, unofficial].
**Outputs:** Signed distance $d$.
**Data Structures:**
The `Arc` struct contains:
- `vec3 arc_center`: Center of the arc in 3D space [S1, unofficial].
- `float arc_tube_radius`: Radius of the tube [S1, unofficial].
- `float orientation_angle`: Rotation of the arc plane around the Z-axis (degrees) [S1, unofficial].
- `float aperture_angle`: Total angular span of the arc (degrees) [S1, unofficial].
- `float sca_cos`, `float sca_sin`: Precomputed $\cos(\theta)$ and $\sin(\theta)$ [S1, unofficial].
- `float scb_cos`, `float scb_sin`: Precomputed $\cos(\alpha/2)$ and $\sin(\alpha/2)$ [S1, unofficial].
- `float ra`: Radius of the circle defining the arc path [S1, unofficial].
- `float rb`: Radius of an inner circle (default 0.0f) [S1, unofficial].

**Steps:**
1. Construct position vector in the arc's local XY plane: $pos = (p_x, p_y, \text{depth})$ [S1, unofficial].
2. Translate by arc center: $pos \leftarrow pos - C$ [S1, unofficial].
3. Rotate by orientation angle $\theta$:
   $$x = pos_x \cos \theta - pos_y \sin \theta$$
   $$y = pos_x \sin \theta + pos_y \cos \theta$$
   $$pos_x = x, \quad pos_y = y$$ [S1, unofficial].
4. Symmetrize X: $pos_x \leftarrow |pos_x|$ [S1, unofficial].
5. Compute intermediate value $k$:
   $$k = \begin{cases} pos_x \sin(\alpha/2) + pos_y \cos(\alpha/2) & \text{if } \cos(\alpha/2) pos_x > \sin(\alpha/2) pos_y \\ \sqrt{pos_x^2 + pos_y^2} & \text{otherwise} \end{cases}$$ [S1, unofficial].
6. Compute project distance:
   $$d_{proj} = \sqrt{pos_x^2 + pos_y^2 + R_a^2 - 2 R_a k} - R_b$$ [S1, unofficial].
7. Compute final distance:
   $$d = \sqrt{d_{proj}^2 + p_z^2} - r_t$$ [S1, unofficial].

**Pitfalls:**
- Angles must be converted from degrees to radians ($\times \pi/180$) before computing sine/cosine [S1, unofficial].
- The `depth` parameter is a global constant for the arc's Z-plane, not derived from $p_z$ [S1, unofficial].
- Precision issues may arise if $R_a \approx 0$ or if the point is far from the arc [G].

**Pseudocode:**
```python
def sd_arc(p_x, p_y, p_z, arc_center_x, arc_center_y, arc_center_z, arc_tube_radius, sca_cos, sca_sin, scb_cos, scb_sin, ra, rb, depth):
    # 1. Construct position vector
    pos_x = p_x
    pos_y = p_y
    pos_z = depth

    # 2. Translate by arc center
    pos_x -= arc_center_x
    pos_y -= arc_center_y
    pos_z -= arc_center_z

    # 3. Rotate by orientation angle
    x = pos_x * sca_cos - pos_y * sca_sin
    y = pos_x * sca_sin + pos_y * sca_cos
    pos_x = x
    pos_y = y

    # 4. Take absolute value of x
    pos_x = abs(pos_x)

    # 5. Compute intermediate value k
    if scb_cos * pos_x > scb_sin * pos_y:
        k = pos_x * scb_sin + pos_y * scb_cos
    else:
        k = (pos_x * pos_x + pos_y * pos_y) ** 0.5

    # 6. Compute project distance
    dist_sq = pos_x * pos_x + pos_y * pos_y
    project_distance = (dist_sq + ra * ra - 2.0 * ra * k) ** 0.5 - rb

    # 7. Compute final distance
    return (project_distance * project_distance + p_z * p_z) ** 0.5 - arc_tube_radius
```

## Subtopics

### Geodesic Arc Length Calculation
Computes the exact arc length $l(a, \rho_0)$ for a quadratic Gaussian Splatting primitive using the integral $l(a, \rho_0) = \int \sqrt{1 + (2at)^2} dt$ [S2]. The solution is $l(a, \rho_0) = \frac{u\sqrt{1+u^2} + \ln(u + \sqrt{1+u^2})}{4a}$ where $u = 2at$ [S2]. This is used for high-quality surface reconstruction but is not part of the standard SDF distance calculation [S2].

## Operating characteristics
- **Time Complexity:** $O(1)$ per point, requiring several arithmetic operations and precomputed trigonometric values [G].
- **Memory Complexity:** $O(1)$ for the `Arc` struct parameters [G].
- **Strengths:** Efficiently models curved tubular structures without voxelization [S1, unofficial].
- **Limitations:** Limited to specific circular arc geometries; requires precomputed trigonometric values [S1, unofficial].
- **When to use:** When rendering curved tubes or rings defined by a center, orientation, and aperture [S1, unofficial].

## Background
The Arc SDF is implemented in the source code provided by [S1, unofficial]. It utilizes fast trigonometric approximations and SSE optimizations for performance [S1, unofficial]. The geodesic arc length formula is derived in "Quadratic Gaussian Splatting" for second-order geometric primitives [S2].
