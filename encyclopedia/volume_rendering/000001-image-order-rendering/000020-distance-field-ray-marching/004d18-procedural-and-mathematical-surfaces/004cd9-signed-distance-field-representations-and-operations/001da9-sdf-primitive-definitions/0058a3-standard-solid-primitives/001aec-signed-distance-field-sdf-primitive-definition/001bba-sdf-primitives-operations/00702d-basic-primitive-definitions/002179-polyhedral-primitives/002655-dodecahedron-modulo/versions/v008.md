# Dodecahedron Modulo

Also called: Dodecahedron SDF, Modulo Dodecahedron

## Overview
The Dodecahedron Modulo method computes the signed distance from a point to the surface of a regular dodecahedron by folding the input space into a fundamental region using a sequence of reflections and rotations, then returning the folded point [S1, unofficial]. It builds on the shared computational framework of [Basic Primitive Definitions](5346-basic-primitive-definitions.md) and belongs to the [Polyhedral Primitives](2529-polyhedral-primitives.md) family, alongside primitives like the [Octahedron Signed Distance Function](2339-octahedron-signed-distance-function.md) and [Hexagonal Prism Signed Distance Function](2348-hexagonal-prism-signed-distance-function.md) [G].

## How it works
**Inputs and Outputs:**
* Input: A 3D point $p = (x, y, z)$ in local space [G].
* Output: A scalar signed distance $d$. The folding sequence transforms $p$ into a representative point $p_{folded}$ within the fundamental domain [S1, unofficial]. The distance $d$ is computed as the distance from $p_{folded}$ to the boundary of that domain [G].

**Data Structures:**
* Vector type: 3D float vector $(x, y, z)$ [G].
* Constants:
  * $\phi = \frac{1 + \sqrt{5}}{2} \approx 1.6180339887$ (Golden Ratio) [G].
  * $\pi \approx 3.1415926535$ [G].

**Definitions:**
* $v_1 = \text{normalize}(0, \phi, 1)$
* $v_2 = \text{normalize}(\phi, 1, 0)$
* $\text{dihedral} = \arccos(\text{dot}(v_1, v_2))$ [S1, unofficial]
* $\text{halfDihedral} = \text{dihedral} / 2$ [S1, unofficial]
* $\text{faceAngle} = 2\pi / 5$ [S1, unofficial]
* $\text{sides} = 5$ [S1, unofficial]

**Pseudocode:**
The following Python-like pseudocode implements the space folding sequence described in [S1, unofficial]. Helper functions for rotation, polar modulo, and reflection are defined inline [G].

```python
import math

def dodecahedron_sdf(p):
    x, y, z = p
    phi = (1 + math.sqrt(5)) / 2
    
    v1 = (0, phi, 1)
    v2 = (phi, 1, 0)
    mag_v1 = math.hypot(v1[0], math.hypot(v1[1], v1[2]))
    mag_v2 = math.hypot(v2[0], math.hypot(v2[1], v2[2]))
    v1 = (v1[0]/mag_v1, v1[1]/mag_v1, v1[2]/mag_v1)
    v2 = (v2[0]/mag_v2, v2[1]/mag_v2, v2[2]/mag_v2)
    
    dihedral = math.acos(v1[0]*v2[0] + v1[1]*v2[1] + v1[2]*v2[2])
    half_dihedral = dihedral / 2
    face_angle = 2 * math.pi / 5
    sides = 5
    
    def rotate2d(a, b, angle):
        c, s = math.cos(angle), math.sin(angle)
        return a*c - b*s, a*s + b*c

    def pModPolar(u, v, sides):
        r = math.hypot(u, v)
        theta = math.atan2(v, u)
        sector = 2 * math.pi / sides
        theta = abs(theta) % sector
        if theta > sector / 2:
            theta = sector - theta
        return r * math.cos(theta), r * math.sin(theta)

    def pReflect(p, n, d):
        dot_val = p[0]*n[0] + p[1]*n[1] + p[2]*n[2] + d
        return (p[0] - 2*dot_val*n[0], p[1] - 2*dot_val*n[1], p[2] - 2*dot_val*n[2])

    # Folding sequence per [S1, unofficial]
    z = abs(z)
    x, z = rotate2d(x, z, -half_dihedral)
    x, y = rotate2d(x, y, face_angle / 4)
    x = -abs(x)
    z, y = rotate2d(z, y, half_dihedral)
    y = -abs(y)
    z, y = rotate2d(z, y, -half_dihedral)
    x, y = rotate2d(x, y, face_angle)
    z, y = rotate2d(z, y, half_dihedral)
    y = -abs(y)
    z, y = rotate2d(z, y, -half_dihedral)
    x, y = rotate2d(x, y, face_angle)
    z, y = rotate2d(z, y, half_dihedral)
    y = -abs(y)
    z, y = rotate2d(z, y, -half_dihedral)
    x, y = rotate2d(x, y, face_angle)
    z, y = rotate2d(z, y, half_dihedral)
    y = -abs(y)
    z, y = rotate2d(z, y, -half_dihedral)
    z = -z
    
    # Polar modulo on yx plane
    y, x = pModPolar(y, x, sides)
    
    # Reflection across x=0 plane
    p = (x, y, z)
    n = (-1, 0, 0)
    p = pReflect(p, n, 0)
    x, y, z = p
    
    # Distance to fundamental domain boundary [G]
    d = min(x, y, z)
    return d
```

**Parameters:**
* Scale: The primitive is unit-sized. Apply scale by dividing the input point $p$ by the scale factor $s$ before evaluation, or multiplying the result by $s$ [G].

**Edge Cases and Pitfalls:**
* **Precision:** The sequence of rotations and absolute values can accumulate floating-point errors. Use double precision if high accuracy is required near the surface [G].
* **Degenerate Input:** The function is well-defined for all $p$ [S1, unofficial].
* **Boundary:** The distance is 0 on the surface [G].

## Subtopics

### Icosahedron Modulo
The Icosahedron Modulo method folds space into an icosahedron cell using a sequence of reflections and rotations [S1, unofficial]. It is distinguished by its 3-fold symmetry at the vertices and 5-fold symmetry at the faces, requiring different dihedral angles and rotation counts compared to the dodecahedron [S1, unofficial]. It is chosen when an icosahedral shape is required [G]. The folding sequence involves fewer steps than the dodecahedron due to the higher symmetry of the fundamental region [S1, unofficial].

**Definitions:**
* $v_1 = \text{normalize}(1, 1, 1)$
* $v_2 = \text{normalize}(0, 1, \phi+1)$
* $\text{sides} = 3$
* $\text{dihedral} = \arccos(\text{dot}(v_1, v_2))$ [S1, unofficial]
* $\text{halfDihedral} = \text{dihedral} / 2$ [S1, unofficial]
* $\text{faceAngle} = 2\pi / 3$ [S1, unofficial]

**Steps:**
1. $p.z = \text{abs}(p.z)$
2. $pR(p.yz, \text{halfDihedral})$
3. $p.x = -\text{abs}(p.x)$
4. $pR(p.zy, \text{halfDihedral})$
5. $p.y = -\text{abs}(p.y)$
6. $pR(p.zy, -\text{halfDihedral})$
7. $pR(p.xy, \text{faceAngle})$
8. $pR(p.zy, \text{halfDihedral})$
9. $p.y = -\text{abs}(p.y)$
10. $pR(p.zy, -\text{halfDihedral})$
11. $pR(p.xy, \text{faceAngle})$
12. $pR(p.zy, \text{halfDihedral})$
13. $p.y = -\text{abs}(p.y)$
14. $pR(p.zy, -\text{halfDihedral})$

## Operating characteristics
* **Time Complexity:** $O(1)$ per query. The number of operations is fixed and small (approx. 20-30 trigonometric and arithmetic operations) [G].
* **Memory Complexity:** $O(1)$. No auxiliary data structures are required [G].
* **Performance:** Very fast, suitable for real-time ray marching [G].
* **Strengths:** Compact code, no need for complex geometric intersection tests, differentiable almost everywhere [G].
* **Limitations:** The folding sequence is complex to derive and understand. Precision issues may arise near the edges and vertices due to the accumulation of rotations [G].

## Background
The method is based on the symmetry group of the dodecahedron (icosahedral symmetry) [G]. The specific folding sequence is derived from the fundamental domain of the symmetry group [G]. The source [S1, unofficial] provides a practical implementation for GLSL ray marching.
