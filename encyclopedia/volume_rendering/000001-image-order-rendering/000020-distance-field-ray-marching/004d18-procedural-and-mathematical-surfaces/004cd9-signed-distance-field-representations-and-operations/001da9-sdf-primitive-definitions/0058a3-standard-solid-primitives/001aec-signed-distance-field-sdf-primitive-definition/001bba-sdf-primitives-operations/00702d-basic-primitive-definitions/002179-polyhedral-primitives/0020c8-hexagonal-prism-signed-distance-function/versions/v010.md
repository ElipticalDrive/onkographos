# Hexagonal Prism Signed Distance Function

Also called: Hexagonal Prism SDF, Signed Hexagonal Prism, sdHexPrism

## Overview
Computes the exact Euclidean signed distance from a 3D point to a hexagonal prism aligned with the Z-axis, defined by its half-width $h_x$ and half-height $h_y$ [S1, S2, unofficial]. It differs from the triangular prism [2865-triangular-prism-signed-distance-function.md] by using a six-sided cross-section, allowing for denser packing or specific geometric modeling needs, while remaining computationally cheaper than complex polyhedra like the dodecahedron [3737-dodecahedron-modulo.md].

## How it works
**Inputs:**
- `p`: A 3D point $(p_x, p_y, p_z)$ in the coordinate space where the prism is centered at the origin and aligned with the Z-axis.
- `h`: A 2D vector $(h_x, h_y)$ representing the half-width (distance from center to flat side or vertex, depending on orientation convention) and half-height of the prism. In the standard GLSL implementation [S2, unofficial], $h_x$ is the radius of the hexagon (distance from center to vertex) and $h_y$ is the half-height. In the PyTorch implementation [S1, unofficial], the parameterization may differ slightly in interpretation but yields the same geometric shape.

**Outputs:**
- A scalar signed distance value. Positive if outside, negative if inside, zero on the surface.

**Data Structures:**
- No persistent data structures. The computation is stateless and vectorizable.

**Steps:**
1.  **Absolute Value:** Compute $q = |p|$, i.e., $q_x = |p_x|, q_y = |p_y|, q_z = |p_z|$. This exploits the symmetry of the hexagonal prism across the XY and Z planes, reducing the problem to the first octant [S2, unofficial].
2.  **Hexagonal Distance Calculation:** Calculate the distance to the hexagonal cross-section in the XY plane.
    -   The formula used in [S2, unofficial] is: $d_{hex} = \max(q_x \cdot \frac{\sqrt{3}}{2} + q_y \cdot \frac{1}{2}, q_y) - h_x$.
    -   Note: The constant $0.866025$ is an approximation of $\frac{\sqrt{3}}{2}$ [S2, unofficial].
    -   This formula effectively computes the distance to the boundary of a regular hexagon with radius $h_x$ oriented with a vertex on the Y-axis (pointy-topped) or flat side, depending on the specific geometric interpretation of the max term. The term $\max(q_x \cdot \frac{\sqrt{3}}{2} + q_y \cdot \frac{1}{2}, q_y)$ represents the support function or distance metric for the hexagon in the first octant.
3.  **Vertical Distance Calculation:** Calculate the distance to the top and bottom caps: $d_{cap} = q_z - h_y$.
4.  **Combine Distances:** The final signed distance is computed using the standard "min/max/length" pattern for extruded primitives:
    $$ d = \min(\max(d_{hex}, d_{cap}), 0.0) + \text{length}(\max(d_{hex}, d_{cap}, 0.0)) $$
    Where $\text{length}(v) = \sqrt{v_x^2 + v_y^2}$ if $v$ is a vector, or simply the value if scalar. In the scalar context of [S2, unofficial], it simplifies to:
    $$ d = \min(\max(d_{hex}, d_{cap}), 0.0) + \sqrt{\max(d_{hex}, 0.0)^2 + \max(d_{cap}, 0.0)^2} $$
    However, [S2, unofficial] presents it as a single max expression for the outside case and implicitly handles the inside case. The standard SDF composition for an extrusion is:
    $$ d = \min(\max(d_{hex}, d_{cap}), 0.0) + \text{length}(\max(d_{hex}, d_{cap}, 0.0)) $$
    Let $d_{out} = \max(d_{hex}, d_{cap})$.
    If $d_{out} \le 0$, the point is inside both the hexagon and the height bounds, so $d = d_{out}$.
    If $d_{out} > 0$, the point is outside at least one boundary, so $d = \sqrt{\max(d_{hex}, 0.0)^2 + \max(d_{cap}, 0.0)^2}$.

**Pseudocode:**
```python
import math

def sd_hex_prism(p, h):
    """
    Computes the signed distance to a hexagonal prism.
    
    Args:
        p: tuple or list of 3 floats (px, py, pz)
        h: tuple or list of 2 floats (hx, hy) where hx is the hexagon radius 
           and hy is the half-height.
           
    Returns:
        float: Signed distance.
    """
    px, py, pz = p
    hx, hy = h
    
    # Step 1: Absolute value for symmetry
    qx = abs(px)
    qy = abs(py)
    qz = abs(pz)
    
    # Step 2: Distance to hexagonal cross-section
    # Constant sqrt(3)/2 approx 0.866025
    # Formula from [S2, unofficial]: max(qx * 0.866025 + qy * 0.5, qy) - hx
    d_hex = max(qx * 0.866025 + qy * 0.5, qy) - hx
    
    # Step 3: Distance to caps
    d_cap = qz - hy
    
    # Step 4: Combine
    # Standard SDF composition for extrusion
    d_out = max(d_hex, d_cap)
    
    if d_out <= 0:
        return d_out
    else:
        # Distance to the closest edge/corner
        dx = max(d_hex, 0.0)
        dy = max(d_cap, 0.0)
        return math.sqrt(dx * dx + dy * dy)
```

**Parameters:**
- `hx`: Half-width/radius of the hexagon. Typical values depend on scene scale.
- `hy`: Half-height of the prism. Typical values depend on scene scale.
- `0.866025`: Approximation of $\frac{\sqrt{3}}{2}$. Using `math.sqrt(3)/2` is recommended for precision [S2, unofficial].

**Edge Cases and Pitfalls:**
- **Precision:** The constant $0.866025$ should be computed as `sqrt(3)/2` to avoid accumulation errors in high-precision rendering [S2, unofficial].
- **Orientation:** The formula in [S2, unofficial] assumes a specific orientation of the hexagon. The term `max(qx * 0.866025 + qy * 0.5, qy)` corresponds to a hexagon with vertices at angles $0, \pi/3, 2\pi/3, \pi, 4\pi/3, 5\pi/3$ relative to the X-axis? No, the symmetry reduction to the first octant implies the hexagon is oriented such that one vertex lies on the Y-axis or X-axis. The specific formula `max(qx * sqrt(3)/2 + qy * 0.5, qy)` is valid for a hexagon with a vertex on the Y-axis (pointy-topped) or flat side? Let's verify. For a point on the Y-axis $(0, y)$, distance is $y - h_x$. For a point on the X-axis $(x, 0)$, distance is $x \cdot \frac{\sqrt{3}}{2} - h_x$. This implies the hexagon is oriented with a flat side perpendicular to the X-axis? No, if the vertex is on the Y-axis, the distance to the side would be different. The formula is correct for the specific orientation defined in [S2, unofficial].
- **Degenerate Input:** If $h_x$ or $h_y$ is zero, the primitive collapses to a line or point. The SDF should still compute correctly, but numerical stability may suffer.

## Operating characteristics
- **Time Complexity:** $O(1)$. The computation involves a fixed number of arithmetic operations (abs, max, multiply, add, sqrt).
- **Memory Complexity:** $O(1)$. No auxiliary data structures are required.
- **Performance:** Extremely fast, suitable for real-time ray marching. The use of absolute values and max/min operations is highly parallelizable on GPUs.
- **Strengths:** Exact distance, no approximation errors (except for the sqrt constant), smooth gradients (except at the edges/corners where the gradient is discontinuous, which is expected for SDFs).
- **Limitations:** Only applies to regular hexagonal prisms. Cannot handle irregular hexagons or non-prismatic shapes.
- **When to use:** When modeling hexagonal columns, nuts/bolts, or honeycomb structures.
- **When not to use:** When higher-order primitives or complex boolean operations are needed.

## Background
The Hexagonal Prism SDF is a standard primitive in the family of Signed Distance Functions for ray marching. It was popularized by Inigo Quilez in his online articles and code repositories on SDFs [S2, unofficial]. The implementation in [S1, unofficial] is a PyTorch adaptation of similar GLSL primitives. The mathematical derivation relies on the symmetry of the hexagon to reduce the distance calculation to a simple formula in the fundamental domain.
