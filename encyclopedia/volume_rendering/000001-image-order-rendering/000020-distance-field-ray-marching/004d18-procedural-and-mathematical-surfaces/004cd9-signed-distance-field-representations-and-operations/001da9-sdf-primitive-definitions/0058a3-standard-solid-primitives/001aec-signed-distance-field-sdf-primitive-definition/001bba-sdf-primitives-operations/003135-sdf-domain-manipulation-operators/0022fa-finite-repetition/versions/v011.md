# Finite Repetition
Also called: Bounded Tiling, Finite Domain Repetition, Limited Repetition

## Overview
Finite Repetition repeats a base Signed Distance Function (SDF) a limited number of times in 3D space by restricting the replication count within a specified limit $\mathbf{l}$ along each axis [S1, S2, unofficial]. Unlike [Infinite Repetition via Dual Offset](14771-infinite-repetition-via-dual-offset.md), which creates interlocking patterns over unbounded space, Finite Repetition produces a discrete, finite array of objects [S1, S2, unofficial].

## How it works
Finite Repetition maps a query point $\mathbf{p}$ to the nearest instance within the bounded grid by calculating an integer offset vector $\mathbf{q}$ and subtracting the corresponding periodic displacement [S1, S2, unofficial].

**Inputs and Outputs:**
- Input: Query position $\mathbf{p}$ (vec3), period/size $\mathbf{c}$ (vec3), limit $\mathbf{l}$ (vec3) [S1, S2, unofficial].
- Output: Transformed position $\mathbf{p}'$ (vec3) to be passed to the base SDF [S1, S2, unofficial].

**Data Structures:**
- $\mathbf{p}, \mathbf{c}, \mathbf{l}$ are typically 3-component floating-point vectors [G].
- $\mathbf{q}$ is an intermediate integer vector [G].

**Steps:**
1. Divide $\mathbf{p}$ by $\mathbf{c}$ and round each component to the nearest integer [S1, S2, unofficial].
2. Clamp the result to the limit $\mathbf{l}$ to enforce the finite boundary [S2, unofficial].
3. Subtract the periodic displacement $\mathbf{c} \cdot \mathbf{q}$ from $\mathbf{p}$ to map to the canonical cell [S1, S2, unofficial].

**Formula:**
$$ \mathbf{q} = \text{clamp}\left(\text{round}\left(\frac{\mathbf{p}}{\mathbf{c}}\right), -\mathbf{l}, \mathbf{l}\right) $$ [S2, unofficial]
$$ \mathbf{p}' = \mathbf{p} - \mathbf{c} \cdot \mathbf{q} $$ [S2, unofficial]

Where:
- $\text{round}(\cdot)$ rounds to the nearest integer [G].
- $\text{clamp}(x, \min, \max)$ restricts $x$ to $[\min, \max]$ [G].
- $\mathbf{l}$ defines the maximum number of cells in each direction from the origin [S2, unofficial].

**Parameters:**
- $\mathbf{c}$: Cell size (period). Must be non-zero [G].
- $\mathbf{l}$: Repetition limit. Typically positive integers or floats representing cell counts [G].

**Edge Cases and Pitfalls:**
- **Zero Period**: Division by zero if any component of $\mathbf{c}$ is zero [G]. Ensure $\mathbf{c}$ components are strictly positive.
- **Boundary Precision**: Points exactly on cell boundaries may round unpredictably depending on floating-point representation [G]. Standard `round` behavior (round half to even or away from zero) should be consistent.
- **Limit Zero**: If $\mathbf{l} = 0$, $\mathbf{q}$ becomes $\mathbf{0}$, and $\mathbf{p}' = \mathbf{p}$, effectively disabling repetition [G].

**Pseudocode:**
```python
def repeat_finite(p, c, l):
    """
    Finite domain repetition for SDF.
    p: input position (vec3)
    c: cell size/period (vec3)
    l: repetition limit (vec3)
    Returns: transformed position (vec3)
    """
    q = (p / c).round().clamp(-l, l)
    return p - c * q
```

## Subtopics

### [Infinite Repetition via Dual Offset](14771-infinite-repetition-via-dual-offset.md)
Creates a perfect, interlocking hexagonal honeycomb pattern using two offset rectangular grids. Choose this when you need unbounded, interlocking tiling with potential per-column properties, accepting higher computational cost.

## Operating characteristics
- **Time Complexity**: $O(1)$ per query [G].
- **Memory Complexity**: $O(1)$ [G].
- **Strengths**: Simple to implement, computationally cheap, prevents infinite recursion in ray marching [G].
- **Limitations**: Creates sharp boundaries at the limit $\mathbf{l}$; objects outside the limit are not rendered [G].
- **When to use**: Bounded tiling, finite arrays of objects, architectural elements with fixed counts [G].
- **When not to use**: Unbounded tiling, infinite floors/walls (use [Infinite Repetition via Dual Offset](14771-infinite-repetition-via-dual-offset.md)) [G].

## Background
Finite Repetition is a standard domain manipulation operator in Signed Distance Field rendering [G]. It is a fundamental building block for creating structured scenes without explicit mesh geometry [G]. The method relies on the mathematical property of periodicity and clamping to bound the repetition [S1, S2, unofficial].
