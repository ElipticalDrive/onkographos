# SDF Domain Manipulation Operators

Also called: Domain Manipulation Operators, SDF Modifiers, SDF domain transformations, Shape Transformations, Space Partitioning, pSomething operators

## Overview
SDF Domain Manipulation Operators modify the input query position vector $\mathbf{p}$ before it is passed to a base Signed Distance Function (SDF) primitive, effectively partitioning or warping the spatial domain to create periodic, mirrored, reflected, or twisted structures [S1, S3, unofficial]. Unlike sibling operators that act on scalar distance values (such as [CSG Operations](1329-csg-operations-on-implicit-functions.md) or [SDF Rounding](1829-sdf-rounding.md)), domain operators transform the coordinate space itself, allowing complex geometries to be generated from simple primitives through spatial repetition or symmetry [S1, S3, unofficial]. This family is distinct from [Infinite Repetition via Dual Offset](14771-infinite-repetition-via-dual-offset.md) in its specific implementation of cell indexing and boundary handling, and from [SDF Tiling via Modulo](4713-sdf-tiling-via-modulo.md) in its broader scope of non-periodic transformations like twisting and elongation.

## Shared principles
All domain manipulation operators share a common mechanism: they accept a query point $\mathbf{p}$ and return a transformed point $\mathbf{p}'$ (and optionally a cell index or symmetry identifier) that is then evaluated by a base SDF $d_{base}(\mathbf{p}')$. The convention is that $\mathbf{p}$ is passed as an in-out argument, modified in place [S1, S3, unofficial].

The general structure for a domain operator $D$ is:
$$ \mathbf{p}' = D(\mathbf{p}, \text{params}) $$
$$ d_{result}(\mathbf{p}) = d_{base}(\mathbf{p}') $$

Key shared properties:
1.  **Cell Indexing**: Many operators (particularly repetition and mirroring) return an integer or float cell index $c$ that identifies which spatial cell the query point $\mathbf{p}$ maps to. This index can be used for material ID assignment or as a random seed for procedural variation [S1, S3, unofficial].
2.  **Centering**: For cell index 0, the transformed point $\mathbf{p}'$ is typically unchanged, and the cells are centered on the origin. This ensures that objects do not need to be manually offset to fit within the periodic boundaries [S1, S3, unofficial].
3.  **Component-wise Operation**: Operators often act on subsets of dimensions (e.g., `<p.x>` or `<p.zx>`) or all three dimensions independently [S1, S3, unofficial].

## Subtopics

### [CSG Operations on Implicit Functions](1329-csg-operations-on-implicit-functions.md)
CSG Operations combine multiple SDFs using Boolean logic (Union, Intersection, Difference) by operating on scalar distance values rather than transforming the input position vector. This method enables the construction of complex composite shapes from simple primitives. Unlike other domain operators that warp space, CSG operators reduce constructive solid geometry to arithmetic operations on scalar fields, handling near-tangent intersections by combining density or distance values.

### [SDF Rounding](1829-sdf-rounding.md)
SDF Rounding modifies a primitive by subtracting a constant radius $r$ from its distance output, effectively rounding off hard edges and corners. It is a specific instance of domain manipulation that operates on the distance value rather than the input position vector, providing a simple way to soften geometry.

### [Elongation](2440-elongation.md)
Elongation applies a non-isometric domain transformation to stretch or compress geometry along a specified vector $\mathbf{s}$. It creates tapered or elongated structures by applying absolute-value subtraction and distance correction to the query point. This is essential for modeling organic or tapered shapes like bones or fibers, setting it apart from uniform scaling by selectively deforming the spatial domain.

### [Finite Repetition](2869-finite-repetition.md)
Finite Repetition repeats a base SDF a limited number of times in 3D space, creating a bounded grid of instances. It solves the problem of creating tiled structures without infinite recursion by restricting the replication count within a specified limit $l$ along each axis. Unlike infinite repetition, it produces a discrete, finite array of objects suitable for bounded scenes.

### Boolean Subtraction with Domain Repetition
This technique creates complex geometry by subtracting domain-repeated smaller objects from a non-repeated larger object, such as domain-repeated cubes subtracted from a larger sphere [S4, unofficial]. It combines domain repetition with subtracting distance fields from each other to generate intricate details [S4, unofficial].

### Symmetry Y
Reflects an SDF across the XZ plane by taking the absolute value of the Y component of $\mathbf{p}$ [S5, unofficial].

### Symmetry X
Reflects an SDF across the YZ plane by taking the absolute value of the X component of $\mathbf{p}$ [S5, unofficial].

### Symmetry Z
Reflects an SDF across the XY plane by taking the absolute value of the Z component of $\mathbf{p}$ [S5, unofficial].

## Background
The concept of domain manipulation in Signed Distance Fields was popularized in the context of ray marching for real-time rendering, particularly in the work of Inigo Quilez and others in the demoscene and procedural generation communities [S1, S4, unofficial]. The "pSomething" naming convention (e.g., `pMod`, `pMirror`) originates from shader code libraries designed for compact, efficient SDF evaluation [S1, S3, unofficial]. These operators allow for the creation of complex, high-detail scenes with minimal code by leveraging the mathematical properties of distance fields under spatial transformations [S4, unofficial].
