# Signed Box Distance Function

Also called: Box SDF, Box SDF v2, Rectangular (Axis-Aligned Box) SDF, SDF Box, SDF Cube, Signed Box, sdBox

## Overview
The Signed Box Distance Function computes the exact Euclidean signed distance from a query point $p$ to the surface of an axis-aligned box centered at the origin [S9, S12, S13, unofficial]. It solves the problem of defining a precise implicit volume primitive for ray marching, ensuring that the distance estimate is neither an under-estimate (which causes ray overshooting) nor an over-estimate (which causes visual artifacts) [S13, S14, unofficial]. It differs from the [Unsigned Box Distance Function](3750-unsigned-box-distance-function.md) by distinguishing interior from exterior space, and from the [Box with Edge Rounding SDF](4004-box-with-edge-rounding-sdf.md) by maintaining sharp 90-degree corners [S1].

## How it works
**Inputs and Outputs:**
*   Input: A query point $p \in \mathbb{R}^3$ and the box half-extents $b \in \mathbb{R}^3$ (where $b_i$ is half the side length along axis $i$). If the box is not centered at the origin or axis-aligned, $p$ is transformed into the box's local space first [S2, S16, unofficial].
*   Output: A scalar $d \in \mathbb{R}$. $d < 0$ if $p$ is inside, $d > 0$ if $p$ is outside, $d = 0$ on the surface.

**Data Structures:**
*   `p`: Vector of 3 floats $(p_x, p_y, p_z)$.
*   `b`: Vector of 3 floats $(b_x, b_y, b_z)$ representing half-extents.

**Algorithm:**
The method exploits symmetry by taking the absolute value of the point coordinates, reducing the problem to the first octant [S2, unofficial]. It then calculates the distance to the nearest face/edge/corner based on whether the point is inside or outside the box bounds [S13, S14, unofficial].

1.  Compute the difference vector $di$ by subtracting the half-extents from the absolute coordinates of $p$:
    $$ di = |p| - b $$
    where $|p| = (|p_x|, |p_y|, |p_z|)$.
2.  Calculate the maximum component of $di$, denoted $res$:
    $$ res = \max(di_x, \max(di_y, di_z)) $$
    This value represents the signed distance along the axis where the point is furthest from the center relative to the box boundary.
3.  Determine the final distance based on the sign of $res$:
    *   If $res > 0$ (point is outside): The distance is the Euclidean length of the positive components of $di$. This correctly accounts for edges and corners.
        $$ d = \| \max(di, 0) \|_2 $$
        where $\max(di, 0)$ is the vector $(\max(di_x, 0), \max(di_y, 0), \max(di_z, 0))$ and $\|\cdot\|_2$ is the L2 norm.
    *   If $res \le 0$ (point is inside): The distance is simply $res$ (which is negative or zero).
        $$ d = res $$

**Pseudocode:**
```python
def signed_box_distance(p: Vec3, b: Vec3) -> float:
    """
    Computes the signed Euclidean distance from point p to an axis-aligned box
    centered at the origin with half-extents b.
    
    Args:
        p: Query point (x, y, z).
        b: Half-extents (bx, by, bz).
        
    Returns:
        Signed distance. Negative if inside, positive if outside.
    """
    # Step 1: Exploit symmetry by taking absolute values
    abs_p = Vec3(abs(p.x), abs(p.y), abs(p.z))
    
    # Step 2: Calculate difference vector
    di = abs_p - b
    
    # Step 3: Calculate the maximum component (distance along the dominant axis)
    res = max(di.x, max(di.y, di.z))
    
    # Step 4: Determine if inside or outside and compute final distance
    if res > 0:
        # Outside: Euclidean distance to the nearest face, edge, or corner
        # Clamp negative components to zero, then take L2 norm
        positive_di = Vec3(max(di.x, 0.0), max(di.y, 0.0), max(di.z, 0.0))
        return length(positive_di)
    else:
        # Inside: The distance is the negative of the maximum component
        return res
```

**Parameters:**
*   `b`: Half-extents. For a $1 \times 1 \times 1$ box, $b = (0.5, 0.5, 0.5)$ [S13, unofficial].

**Edge Cases and Pitfalls:**
*   **Corner Artifacts (Version 1):** A simplified version that returns $\min(res, \| \max(di, 0) \|)$ underestimates the distance in corner regions [S13, S14, unofficial]. This leads to smaller ray steps, slower convergence, and incorrect ambient occlusion (black dots) [S13, S14, unofficial]. The correct implementation (Version 2) uses the conditional logic above to avoid this [S14, unofficial].
*   **Overestimation:** Overestimating the distance can cause the ray to pass through the surface or inaccurately estimate the surface point position [S13, unofficial].
*   **Precision:** The function is differentiable almost everywhere. The gradient $\nabla d$ can be used for surface normals [Parent].

## Subtopics

### [Unsigned Box Distance Function](3750-unsigned-box-distance-function.md)
The Unsigned Box Distance Function computes the Euclidean distance from a query point to the surface of an axis-aligned box centered at the origin, returning only non-negative values regardless of whether the point lies inside or outside the volume. Unlike its sibling, the Signed Box Distance Function, which distinguishes interior from exterior space, this method treats the box as a solid boundary where internal points are measured by their distance to the nearest face.

### [Box with Edge Rounding SDF](4004-box-with-edge-rounding-sdf.md)
Computes the signed Euclidean distance from a query point to the surface of an axis-aligned box whose edges and corners are rounded by a constant radius. It solves the problem of defining smooth, organic variations of standard rectangular primitives for ray marching and implicit modeling. It differs from the [Signed Box Distance Function](1092-signed-boxdistance-function.md) by replacing sharp 90-degree corners with spherical fillets, allowing for continuous normals and softer visual interactions.

### [Rectangle Signed Distance Function](4031-rectangle-signed-distance-function.md)
Computes the exact Euclidean distance from a query point to the boundary of an axis-aligned rectangle centered at the origin. It is the 2D analog of the [Signed Box Distance Function](1092-signed-boxdistance-function.md).

### [Oriented Box2D SDF](4370-oriented-box2d-sdf.md)
Computes the signed Euclidean distance from a 2D point to a line segment of arbitrary length and thickness, effectively representing a 2D box with rounded corners oriented along the segment axis. It differs from the [Unsigned Box Distance Function](3750-unsigned-boxdistance-function.md) by providing signed output and from the [Signed Box Distance Function](1092-signed-boxdistance-function.md) by operating in 2D with a specific segment-based orientation rather than a general 3D axis-aligned or oriented box. It serves as a primitive for constructing 2D shapes in ray marching or implicit modeling.

### Oriented Box SDF
Computes the signed distance from a point to an Oriented Bounding Box (OBB). It transforms the point into the box's local coordinate system using the inverse of the box's transformation matrix, computes the distance to the unit box scaled by the box's dimensions, and adjusts for being inside or outside [S16, unofficial].
**Steps:**
1.  Transform the input point `point` into the box's local coordinate system: `trans = self.full_inverse * point.extend(1.0)`.
2.  Compute the vector `q_local` representing the distance from the unit box surface scaled by the box's scale: `q_local = (trans.abs() - Vec4::splat(1.0)) * self.scale`.
3.  Compute the distance: `dist = q_local.max(Vec4::ZERO).length() + q_local.x.max(q_local.y.max(q_local.z)).min(0.0)`.

## Operating characteristics
*   **Time Complexity:** $O(1)$. The computation involves a fixed number of arithmetic operations (absolute value, subtraction, max, min, length).
*   **Memory Complexity:** $O(1)$. No auxiliary data structures are required.
*   **Performance:** Extremely fast, making it suitable for real-time ray marching and implicit modeling [S13, S15, unofficial].
*   **Strengths:** Exact Euclidean distance ensures correct ray stepping and accurate ambient occlusion [S13, S14, unofficial]. Simple implementation.
*   **Limitations:** Sharp corners can cause aliasing in some rendering contexts if not handled with appropriate sampling or anti-aliasing techniques [S13, unofficial]. The "cheap" approximation $d = \max(|p-c| - s)$ is not a true Euclidean distance function for points outside corners and should be avoided for precise applications like AO [S15, unofficial].

## Background
The Signed Box Distance Function is a fundamental primitive in Signed Distance Field (SDF) ray marching. The exact formulation (Version 2) was popularized by Inigo Quilez in his online resources on distance functions [S9, S13, S14, unofficial]. Earlier versions or approximations existed, such as the "cheap" box SDF which intersects half-spaces [S15, unofficial], but these were noted to underestimate distance at corners, leading to visual artifacts in ambient occlusion [S13, S14, unofficial]. The correct formulation distinguishes between inside and outside cases to provide the true Euclidean distance [S14, unofficial]. It is widely used in procedural geometry, ray marching shaders, and implicit modeling [S2, S9, S16, unofficial].
