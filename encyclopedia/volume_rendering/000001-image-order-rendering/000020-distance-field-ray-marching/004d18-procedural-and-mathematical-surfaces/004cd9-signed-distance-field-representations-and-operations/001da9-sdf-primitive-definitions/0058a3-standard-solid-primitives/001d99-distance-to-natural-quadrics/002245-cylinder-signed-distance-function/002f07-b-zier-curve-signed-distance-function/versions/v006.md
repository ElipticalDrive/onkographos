# Bézier Curve Signed Distance Function

Also called: Distance to Generalized Cylinder (Bézier Curve), Offset surface distance, Skeletal model distance

## Overview
Computes the distance to the global offset surface of a cubic Bézier space curve, modeling a generalized cylinder with a fixed radius [S1]. It differs from closed-form primitive SDFs by solving for the closest point on a parametric curve through root finding of the orthogonality condition [S1].

## How it works
**Inputs:** Query point $x \in \mathbb{R}^3$, cubic Bézier control points $P_0, P_1, P_2, P_3 \in \mathbb{R}^3$, radius $R$ [S1].
**Outputs:** Signed distance $d(x)$ to the offset surface [G].
**Data Structures:** Control points stored as 3D vectors, coefficients for the degree-5 polynomial derived from the orthogonality condition [G].

**Steps:**
1. Define the space curve parametrically as $p(u)$ for $u \in [0, 1]$ [S1].
2. Translate coordinates so the query point is at the origin for derivation, or use relative coordinates $q = x - p(u)$ [S1].
3. Find the closest point $p(u)$ satisfying the orthogonality condition $(x - p(u)) \cdot p'(u) = 0$ [S1].
4. Convert the orthogonality equation into a degree-5 1D Bézier curve [S1].
5. Solve the degree-5 1D Bézier curve efficiently for roots in $[0, 1]$ [S1].
6. Compute the distance $r = \|p(u^*)\|$ for each valid root and the endpoints, then return $d(x) = r - R$ [G].

**Pseudocode:**
```python
def comb(n, k):
    if k < 0 or k > n: return 0
    if k == 0 or k == n: return 1
    if k > n // 2: k = n - k
    res = 1
    for i in range(k): res = res * (n - i) // (i + 1)
    return res

def dot(a, b):
    return a[0]*b[0] + a[1]*b[1] + a[2]*b[2]

def bezier_point(Q0, Q1, Q2, Q3, u):
    u2, u3 = u*u, u*u*u
    u1, u12, u13 = 1-u, (1-u)*(1-u), (1-u)*(1-u)*(1-u)
    return (u13*Q0 + 3*u12*u*Q1 + 3*u1*u2*Q2 + u3*Q3)

def bernstein_subdivision(coeffs, degree):
    n = degree
    left = [0.0] * (n + 1)
    right = [0.0] * (n + 1)
    left[0] = coeffs[0]
    right[n] = coeffs[n]
    for i in range(1, n + 1):
        left[i] = left[i-1] * (n - i + 1) / n + coeffs[i] / n
        right[n - i] = right[n - i + 1] * i / n + coeffs[n - i] / n
    return left[:n//2 + 1], right[n//2:]

def find_bernstein_roots(coeffs, degree):
    roots = []
    def subdivide(c, deg, u_min, u_max):
        if deg == 0:
            if abs(c[0]) < 1e-9: roots.append((u_min + u_max) / 2.0)
            return
        if min(c) * max(c) > 0: return
        if u_max - u_min < 1e-7: roots.append(u_min); return
        c1, c2 = bernstein_subdivision(c, deg)
        mid = (u_min + u_max) / 2.0
        subdivide(c1, deg // 2, u_min, mid)
        subdivide(c2, deg // 2, mid, u_max)
    subdivide(coeffs, degree, 0.0, 1.0)
    return roots

def bezier_sdf(x, P0, P1, P2, P3, R):
    Q0, Q1, Q2, Q3 = (P0 - x), (P1 - x), (P2 - x), (P3 - x)
    D0, D1, D2 = 3*(Q1 - Q0), 3*(Q2 - Q1), 3*(Q3 - Q2)
    coeffs = [0.0] * 6
    for k in range(6):
        val = 0.0
        for i in range(k + 1):
            if i <= 3 and (k - i) <= 2:
                factor = (comb(3, i) * comb(2, k - i)) / comb(5, k)
                val += factor * dot([Q0, Q1, Q2, Q3][i], [D0, D1, D2][k - i])
        coeffs[k] = val
    roots = find_bernstein_roots(coeffs, 5)
    min_dist_sq = min(dot(Q0, Q0), dot(Q3, Q3))
    for u in roots:
        if 0.0 <= u <= 1.0:
            min_dist_sq = min(min_dist_sq, dot(bezier_point(Q0, Q1, Q2, Q3, u), bezier_point(Q0, Q1, Q2, Q3, u)))
    return (min_dist_sq ** 0.5) - R
```

**Parameters:**
- $R$: Radius of the generalized cylinder. Typical values depend on scene scale [G].

**Edge Cases:**
- The closest point may lie at the curve endpoints $u=0$ or $u=1$, requiring explicit boundary checks [S1].
- The degree-5 polynomial may yield multiple valid roots; the global minimum distance must be selected [S1].
- Precision issues may occur near degenerate curves or when the query point lies exactly on the curve [G].

## Subtopics

### [Footvector Representation](8501-footvector-representation.md)
The Footvector Representation is a geometric generalization of Signed Distance Functions (SDFs) for curves and surfaces, defined by the vector pointing from a query point to its closest point (footpoint) on the shape [G]. Unlike standard SDFs which only provide scalar distance, this representation retains directional information, enabling exact offset surface computation for Constructive Solid Geometry (CSG) operations via fast iterative methods. It builds on the [Bézier Curve Signed Distance Function](5929-b-zier-curve-signed-distance-function.md) and differs from the [Spline Tube to Cylinder Mapping](10061-spline-tube-to-cylinder-mapping.md) by explicitly tracking the footpoint vector rather than mapping to a cylinder tube. It is chosen when precise geometric invariants and exact offsetting are required, though it poses implementation challenges for GPU shaders due to higher-order function mappings.

### [Spline Tube to Cylinder Mapping](10061-spline-tube-to-cylinder-mapping.md)
Spline Tube to Cylinder Mapping is a technique for mapping points from an arbitrary spline tube to a canonical vertical cylinder, enabling the direct querying of pre-defined isotropic procedural density fields. It solves the problem of inverse parameterization in volumetric rendering by providing a robust Signed Distance Function (SDF) to the curve, which yields the curvilinear abscissa required for texture coordinate calculation.

## Operating characteristics
- **Time Complexity:** Constant time per query, dominated by solving a degree-5 polynomial via subdivision or iterative root finding, which is more expensive than closed-form primitives [G].
- **Memory Complexity:** Minimal, storing only four 3D control points and the radius [G].
- **Strengths:** Provides exact distance to smooth, organic tubes without discretization artifacts [G].
- **Limitations:** Root finding can be numerically unstable for highly curved or nearly linear segments [G].
- **When to use:** Rendering skeletal models or generalized cylinders where exact offset surfaces are required [S1].
- **When not to use:** Performance-critical applications where linear segment approximation or simpler primitives suffice [G].

## Background
Originated in implicit modeling and ray tracing of generalized cylinders [S1]. The method leverages the orthogonality condition to locate the closest point on a parametric curve, converting the problem into a solvable degree-5 1D Bézier curve [S1].
