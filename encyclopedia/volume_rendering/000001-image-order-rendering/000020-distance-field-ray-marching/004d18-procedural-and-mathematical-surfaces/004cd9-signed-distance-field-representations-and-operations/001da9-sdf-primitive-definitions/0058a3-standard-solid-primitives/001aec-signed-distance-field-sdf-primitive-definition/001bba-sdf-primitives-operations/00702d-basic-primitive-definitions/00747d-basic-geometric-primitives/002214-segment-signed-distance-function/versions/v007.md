# Segment Signed Distance Function

Also called: Segment SDF, sdSegment, Distance to line segment

## Overview
The Segment Signed Distance Function computes the Euclidean distance from a query point to a finite line segment defined by two endpoints [S3, unofficial]. It solves the problem of determining proximity to 1D geometric primitives in 2D or 3D space, serving as the foundational building block for more complex shapes like capsules and tubes [G]. It differs from infinite line distance functions by clamping the projection parameter to the segment bounds, ensuring the result is zero if the point lies on the segment and correctly handling points projecting outside the endpoints [S3, unofficial].

## How it works
**Inputs and Outputs:**
*   **Input:** Query point $p$ (vector), segment endpoints $a$ and $b$ (vectors).
*   **Output:** Scalar distance $d$. Standard implementations return the non-negative Euclidean distance [S3, unofficial], though some variants return the squared distance for performance [S1, unofficial].

**Data Structures:**
*   Vectors $p, a, b$ of dimension $N$ (typically 2 or 3) [S2, S3, unofficial].
*   Scalar intermediate values for projection parameter $t$ or $h$ [G].

**Steps:**
1.  Compute the segment vector: $ab = b - a$ [S3, unofficial].
2.  Compute the vector from the start point to the query point: $ap = p - a$ [S3, unofficial].
3.  Compute the squared length of the segment: $len\_sq = ab \cdot ab$ [S3, unofficial].
4.  Handle degenerate segments: If $len\_sq$ is near zero (e.g., $< 10^{-12}$), the segment is a point [S3, S4, unofficial]. The closest point is $a$. Return $\|p - a\|$ [S3, unofficial].
5.  Compute the projection parameter $t$ of $p$ onto the line defined by $ab$:
    $$ t = \frac{ap \cdot ab}{len\_sq} $$
6.  Clamp $t$ to the segment bounds $[0, 1]$:
    $$ t_{clamped} = \text{clamp}(t, 0.0, 1.0) $$
7.  Compute the closest point on the segment:
    $$ closest = a + ab \cdot t_{clamped} $$
8.  Return the Euclidean distance:
    $$ d = \| p - closest \| $$

**Alternative Formula (Normalized):**
Some implementations normalize the direction vector first [S2, unofficial]:
1.  $v = \frac{b - a}{\|b - a\|}$
2.  $l = \text{clamp}(v \cdot (p - a), 0, \|b - a\|)$
3.  $d = \| p - a - l \cdot v \|$ [S2, unofficial].

**Parameters:**
*   $p$: Query point.
*   $a, b$: Segment endpoints.
*   Epsilon for degenerate check: Typically $10^{-12}$ or $10^{-8}$ depending on precision requirements [S3, S4, unofficial].

**Edge Cases and Pitfalls:**
*   **Degenerate Segment:** If $a = b$, the denominator in step 5 becomes zero. Division by zero must be avoided by checking $len\_sq$ against a small epsilon [S3, S4, unofficial].
*   **Precision:** In floating-point arithmetic, checking for exact equality with zero is unsafe. Use epsilon comparisons for degenerate checks [S4, unofficial].

**Pseudocode:**
```python
def sd_segment(p, a, b):
    """
    Computes the Euclidean distance from point p to the segment [a, b].
    
    Args:
        p: Vector-like object with subtraction, dot product, and length.
        a: Start point of the segment.
        b: End point of the segment.
        
    Returns:
        float: Distance from p to the closest point on the segment.
    """
    # 1. Segment vector
    ab = b - a
    
    # 2. Vector from start to query point
    ap = p - a
    
    # 3. Squared length of segment
    len_sq = ab.dot(ab)
    
    # 4. Handle degenerate segment (point)
    if len_sq < 1e-12:
        return (p - a).length()
    
    # 5. Projection parameter
    t = ap.dot(ab) / len_sq
    
    # 6. Clamp to segment bounds
    t = max(0.0, min(1.0, t))
    
    # 7. Closest point
    closest = a + ab * t
    
    # 8. Distance
    return (p - closest).length()
```

## Subtopics

### [Line Segment Distance](3058-line-segment-distance.md)
Computes the Euclidean distance from a query point `p` to a line segment defined by endpoints `l0` and `l1`. It differs from infinite line distance by clamping the projection parameter to the segment bounds, ensuring the result is zero if the point lies on the segment [G]. This method serves as the geometric core for signed distance field (SDF) primitives in ray marching [G].

### [Point on Segment Check](3967-point-on-segment-check.md)
The Point on Segment Check determines whether a query point $Q$ lies exactly on the line segment defined by endpoints $P_i$ and $P_j$ [G]. It solves the geometric containment problem for 1D segments embedded in 2D or 3D space [G]. It is distinguished from [Line Segment Distance](3058-line-segment-distance.md) and [Point-to-Segment Distance](4205-point-to-segment-distance.md) by returning a binary boolean result rather than a scalar distance value, serving as a primitive predicate within the [Segment Signed Distance Function](2679-segment-signed-distance-function.md) [G].

### [Point-to-Segment Distance](4205-point-to-segment-distance.md)
Computes the closest point on a line segment to a query point, which is the core geometric primitive for evaluating the distance to a line segment. It differs from infinite line projection by clamping the result to the segment's endpoints, ensuring the output lies on the closed segment.

### Capsule Signed Distance Function — 2D Capsule SDF
Computes the signed distance to a 2D capsule (stadium) between points `a` and `b` with radius `r` [S3, unofficial]. Formula: $\text{segment}(p, a, b) - r$ [S3, unofficial]. Code: `pub fn capsule2d(p: Vec2, a: Vec2, b: Vec2, r: f32) -> f32 { segment(p, a, b) - r }` [S3, unofficial].

## Operating characteristics
*   **Time Complexity:** $O(1)$ [G]. Involves a constant number of vector subtractions, dot products, and a square root [G].
*   **Memory Complexity:** $O(1)$ [G]. No auxiliary data structures required [G].
*   **Strengths:** Extremely fast, numerically stable with epsilon checks, and differentiable almost everywhere (gradient is the normalized vector from closest point to $p$, except at endpoints and degenerate cases) [G].
*   **Limitations:** Not signed in the traditional volumetric sense (no interior) [G]. Requires epsilon handling for degenerate cases [S3, S4, unofficial].
*   **When to use:** Ray marching for thin objects, collision detection, proximity queries [G].
*   **When not to use:** When a true volumetric interior is required (use Cylinder or Capsule instead) [G].

## Background
The segment distance function is a fundamental primitive in Signed Distance Field (SDF) rendering, popularized by Inigo Quilez's online articles on distance functions [S2, S3, unofficial]. It is widely used in real-time graphics for rendering thin structures like wires, hair, and tubes without explicit mesh geometry [G]. The algorithm is derived from basic vector projection geometry [S1, S4, unofficial].
