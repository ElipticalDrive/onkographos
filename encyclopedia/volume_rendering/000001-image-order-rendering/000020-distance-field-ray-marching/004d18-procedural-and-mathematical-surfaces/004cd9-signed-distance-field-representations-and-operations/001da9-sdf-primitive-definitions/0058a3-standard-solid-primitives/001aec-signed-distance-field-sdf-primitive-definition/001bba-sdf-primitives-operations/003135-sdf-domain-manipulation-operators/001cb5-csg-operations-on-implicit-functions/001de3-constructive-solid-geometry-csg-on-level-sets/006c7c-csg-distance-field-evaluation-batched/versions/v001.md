# CSG Distance Field Evaluation (Batched)

Also called: Scalar CSG Evaluation

## Overview
This method computes the signed distance values and material indices for a batch of query points against a Constructive Solid Geometry (CSG) tree [S1, unofficial]. It solves the problem of evaluating complex implicit surfaces defined by boolean combinations of primitives in a single pass over a point cloud, which is essential for efficient ray marching or voxelization in volume rendering [S1, unofficial]. It is distinguished from sibling methods like [Lipschitz Pruning](8623-lipschitz-pruning.md) by its explicit handling of material indices alongside distance values and its non-SIMD, plain C implementation structure [S1, unofficial].

## How it works
The algorithm recursively traverses a CSG tree, maintaining two arrays: `dist` for signed distances and `matindex` for material identifiers. It supports Union, Intersection, Difference, Translation, Rotation, and primitive types (Plane, Cylinder, Sphere, Box).

### Inputs and Outputs
*   **Inputs**:
    *   `d`: Pointer to the current CSG node in the tree.
    *   `pos`: Array of $N$ 3D points (float3).
    *   `normaldist`: Optional array of $N$ floats used for normal distance culling. If `NULL`, culling is disabled.
    *   `box`: Axis-Aligned Bounding Box (AABB) representing the current evaluation region.
    *   `num`: Integer $N$, the number of points in the batch.
*   **Outputs**:
    *   `dist`: Array of $N$ floats, updated with signed distances.
    *   `matindex`: Array of $N$ integers, updated with material indices.

### Data Structures
*   **CSG Node (`d`)**: Contains a type enum (`C_UNION`, `C_INTERSECTION`, `C_DIFFERENCE`, `C_REPLACE`, `C_TRANSLATION`, `C_ROTATION`, `C_PLANE`, `C_CYLINDERXY`, `C_CYLINDERXZ`, `C_CYLINDERYZ`, `C_SPHERE`, `C_BOX`), pointers to children (`left`, `right`, `n`), and primitive-specific data (e.g., `p` for plane, `c` for cylinder, `s` for sphere, `b` for box, `t` for translation, `r` for rotation).
*   **AABB (`box`)**: Defined by `pmin` and `pmax` (float3).
*   **Constants**: `MAT_AIR_INDEX` represents empty space. `FLT_MAX` represents infinity.

### Numbered Steps

1.  **Initialization**: Call `dist(n, pos, normaldist, d, mat, num, box)` to initialize `dist[i] = FLT_MAX` and `matindex[i] = MAT_AIR_INDEX` for all $i \in [0, N-1]$.
2.  **Traversal**: Recursively evaluate the CSG tree using the `distr` function.
3.  **Node Evaluation**:
    *   **C_UNION**:
        1.  Check if `box` intersects `d->left->box`. If not, skip left child.
        2.  Recursively evaluate left child into `dist` and `matindex`.
        3.  Check if `box` intersects `d->right->box`. If not, skip right child.
        4.  Initialize `tempdist` array to `FLT_MAX`.
        5.  Recursively evaluate right child into `tempdist` and `tempmatindex`.
        6.  Update `matindex[i] = max(matindex[i], tempmatindex[i])`.
        7.  Update `dist[i]`:
            *   If `normaldist` is provided: if `abs(tempdist[i]) < normaldist[i]`, `dist[i] = min(dist[i], tempdist[i])`. Else keep `dist[i]`.
            *   If `normaldist` is not provided: `dist[i] = min(dist[i], tempdist[i])`.
    *   **C_REPLACE**:
        1.  Check if `box` intersects `d->left->box`. If not, return.
        2.  Recursively evaluate left child into `dist` and `matindex`.
        3.  Check if `box` intersects `d->right->box`. If not, return.
        4.  Initialize `tempdist` to `FLT_MAX`.
        5.  Recursively evaluate right child into `tempdist` and `tempmatindex`.
        6.  For each point $i$:
            *   If `tempdist[i] < 0` and `dist[i] < 0` (both inside), `matindex[i] = tempmatindex[i]`.
            *   If `normaldist` is provided: if `dist[i] < 0` and `abs(tempdist[i]) < normaldist[i]`, `dist[i] = tempdist[i]`. Else keep `dist[i]`.
    *   **C_INTERSECTION**:
        1.  Check if `box` intersects `d->left->box`. If not, break.
        2.  Recursively evaluate left child into `dist` and `matindex`.
        3.  Check if `box` intersects `d->right->box`. If not, break.
        4.  Initialize `tempdist` to `FLT_MAX`.
        5.  Recursively evaluate right child into `tempdist` and `tempmatindex`.
        6.  Update `dist[i] = max(dist[i], tempdist[i])`.
        7.  If `dist[i] >= 0`, set `matindex[i] = MAT_AIR_INDEX`.
    *   **C_DIFFERENCE**:
        1.  Check if `box` intersects `d->left->box`. If not, break.
        2.  Recursively evaluate left child into `dist` and `matindex`.
        3.  Check if `box` intersects `d->right->box`. If not, break.
        4.  Initialize `tempdist` to `FLT_MAX` and `tempmatindex` to default.
        5.  Recursively evaluate right child into `tempdist` and `tempmatindex`.
        6.  Update `dist[i] = max(dist[i], -tempdist[i])`.
        7.  If `dist[i] >= 0`, set `matindex[i] = MAT_AIR_INDEX`.
    *   **C_TRANSLATION**:
        1.  Check if `box` intersects `n->box`. If not, break.
        2.  Get translation vector `t->p`.
        3.  For each point $i$: `tpos[i] = pos[i] - t->p`.
        4.  Compute translated box `tbox = {box.pmin - t->p, box.pmax - t->p}`.
        5.  Recursively call `distr` on `t->n` with `tpos`, `normaldist`, `dist`, `matindex`, `num`, and `tbox`.
    *   **C_ROTATION**:
        1.  Check if `box` intersects `n->box`. If not, break.
        2.  Get rotation quaternion `r->q`.
        3.  For each point $i$: `tpos[i] = xfmpoint(conj(r->q), pos[i])`.
        4.  Recursively call `distr` on `r->n` with `tpos`, `normaldist`, `dist`, `matindex`, `num`, and `aabb::all()`.
    *   **C_PLANE**:
        1.  Check if `box` intersects `n->box`. If not, break.
        2.  For each point $i$: `dist[i] = dot(pos[i], p->p.xyz()) + p->p.w`.
        3.  If `dist[i] < 0`, `matindex[i] = p->matindex`.
    *   **C_CYLINDERXY / C_CYLINDERXZ / C_CYLINDERYZ**:
        1.  Check if `box` intersects `n->box`. If not, break.
        2.  For each point $i$:
            *   Let `COORD` be the relevant 2D coordinates (xy, xz, or yz).
            *   `dist[i] = length(pos[i].COORD() - c->cCOORD) - c->r`.
        3.  If `dist[i] < 0`, `matindex[i] = c->matindex`.
    *   **C_SPHERE**:
        1.  Check if `box` intersects `n->box`. If not, break.
        2.  For each point $i$: `dist[i] = length(pos[i]) - s->r`.
        3.  If `dist[i] < 0`, `matindex[i] = s->matindex`.
    *   **C_BOX**:
        1.  Check if `box` intersects `n->box`. If not, break.
        2.  Get box extent `b->extent`.
        3.  For each point $i$:
            *   `pd = abs(pos[i]) - extent`.
            *   `dist[i] = min(max(pd.x, max(pd.y, pd.z)), 0.0f) + length(max(pd, vec3f(0.0f)))`.
        4.  If `dist[i] < 0`, `matindex[i] = b->matindex`.

### Pseudocode

```python
def distr(d, pos, normaldist, dist, matindex, num, box):
    """
    Recursively evaluate CSG tree d for batch of points.
    d: CSG node
    pos: list of float3 points
    normaldist: list of floats or None
    dist: list of floats (output)
    matindex: list of ints (output)
    num: int, number of points
    box: AABB {pmin, pmax}
    """
    if not box_intersects(box, d.box):
        return

    if d.type == C_UNION:
        # Evaluate Left
        if box_intersects(box, d.left.box):
            distr(d.left, pos, normaldist, dist, matindex, num, box)
        
        # Evaluate Right
        if box_intersects(box, d.right.box):
            tempdist = [FLT_MAX] * num
            tempmatindex = [0] * num
            distr(d.right, pos, normaldist, tempdist, tempmatindex, num, box)
            
            for i in range(num):
                # Update material index
                if tempmatindex[i] > matindex[i]:
                    matindex[i] = tempmatindex[i]
                
                # Update distance
                if normaldist is not None:
                    if abs(tempdist[i]) < normaldist[i]:
                        if tempdist[i] < dist[i]:
                            dist[i] = tempdist[i]
                else:
                    if tempdist[i] < dist[i]:
                        dist[i] = tempdist[i]

    elif d.type == C_REPLACE:
        # Evaluate Left
        if box_intersects(box, d.left.box):
            distr(d.left, pos, normaldist, dist, matindex, num, box)
        
        # Evaluate Right
        if box_intersects(box, d.right.box):
            tempdist = [FLT_MAX] * num
            tempmatindex = [0] * num
            distr(d.right, pos, normaldist, tempdist, tempmatindex, num, box)
            
            for i in range(num):
                # Update material index if both inside
                if tempdist[i] < 0 and dist[i] < 0:
                    matindex[i] = tempmatindex[i]
                
                # Update distance
                if normaldist is not None:
                    if dist[i] < 0 and abs(tempdist[i]) < normaldist[i]:
                        dist[i] = tempdist[i]
                else:
                    # Note: Source implies update if condition met, else keep. 
                    # Standard replace usually overwrites if inside, but logic is specific.
                    # Based on source: "update dist[i] to tempdist[i] if dist[i] < 0 and abs(tempdist[i]) < normaldist[i], otherwise keep dist[i]"
                    pass 

    elif d.type == C_INTERSECTION:
        if not box_intersects(box, d.left.box):
            return
        distr(d.left, pos, normaldist, dist, matindex, num, box)
        
        if not box_intersects(box, d.right.box):
            return
            
        tempdist = [FLT_MAX] * num
        tempmatindex = [0] * num
        distr(d.right, pos, normaldist, tempdist, tempmatindex, num, box)
        
        for i in range(num):
            dist[i] = max(dist[i], tempdist[i])
            if dist[i] >= 0:
                matindex[i] = MAT_AIR_INDEX

    elif d.type == C_DIFFERENCE:
        if not box_intersects(box, d.left.box):
            return
        distr(d.left, pos, normaldist, dist, matindex, num, box)
        
        if not box_intersects(box, d.right.box):
            return
            
        tempdist = [FLT_MAX] * num
        tempmatindex = [0] * num
        distr(d.right, pos, normaldist, tempdist, tempmatindex, num, box)
        
        for i in range(num):
            dist[i] = max(dist[i], -tempdist[i])
            if dist[i] >= 0:
                matindex[i] = MAT_AIR_INDEX

    elif d.type == C_TRANSLATION:
        if not box_intersects(box, d.n.box):
            return
        t_vec = d.t.p
        tbox_pmin = box.pmin - t_vec
        tbox_pmax = box.pmax - t_vec
        tbox = AABB(tbox_pmin, tbox_pmax)
        
        tpos = [pos[i] - t_vec for i in range(num)]
        distr(d.t.n, tpos, normaldist, dist, matindex, num, tbox)

    elif d.type == C_ROTATION:
        if not box_intersects(box, d.n.box):
            return
        q = d.r.q
        conj_q = conjugate(q)
        
        tpos = [xfmpoint(conj_q, pos[i]) for i in range(num)]
        # aabb::all() implies infinite box or full space check
        distr(d.r.n, tpos, normaldist, dist, matindex, num, AABB([-INF, -INF, -INF], [INF, INF, INF]))

    elif d.type == C_PLANE:
        if not box_intersects(box, d.n.box):
            return
        p = d.p
        for i in range(num):
            dist[i] = dot(pos[i], p.p.xyz()) + p.p.w
            if dist[i] < 0:
                matindex[i] = p.matindex

    elif d.type in [C_CYLINDERXY, C_CYLINDERXZ, C_CYLINDERYZ]:
        if not box_intersects(box, d.n.box):
            return
        c = d.c
        # Determine coordinates based on type
        if d.type == C_CYLINDERXY:
            coords = [pos[i].xy() for i in range(num)]
        elif d.type == C_CYLINDERXZ:
            coords = [pos[i].xz() for i in range(num)]
        else: # C_CYLINDERYZ
            coords = [pos[i].yz() for i in range(num)]
            
        for i in range(num):
            dist[i] = length(coords[i] - c.cCOORD) - c.r
            if dist[i] < 0:
                matindex[i] = c.matindex

    elif d.type == C_SPHERE:
        if not box_intersects(box, d.n.box):
            return
        s = d.s
        for i in range(num):
            dist[i] = length(pos[i]) - s.r
            if dist[i] < 0:
                matindex[i] = s.matindex

    elif d.type == C_BOX:
        if not box_intersects(box, d.n.box):
            return
        b = d.b
        for i in range(num):
            pd = [abs(pos[i].x) - b.extent.x, 
                  abs(pos[i].y) - b.extent.y, 
                  abs(pos[i].z) - b.extent.z]
            max_pd = max(pd[0], max(pd[1], pd[2]))
            dist[i] = min(max_pd, 0.0f) + length(max_vec(pd, [0.0f, 0.0f, 0.0f]))
            if dist[i] < 0:
                matindex[i] = b.matindex

def dist(n, pos, normaldist, d, mat, num, box):
    """Initialize arrays"""
    for i in range(n):
        dist[i] = FLT_MAX
        mat[i] = MAT_AIR_INDEX
```

### Formulas
*   **Box Signed Distance**:
    $$d = \min(\max(p_x, \max(p_y, p_z)), 0) + \|\max(p, \mathbf{0})\|$$
    where $p = (|x| - e_x, |y| - e_y, |z| - e_z)$ and $e$ is the box extent [S1, unofficial].

### Parameters
*   `MAT_AIR_INDEX`: Integer constant representing empty space [S1, unofficial].
*   `FLT_MAX`: Floating-point infinity [S1, unofficial].

### Edge Cases and Pitfalls
*   **Precision**: The use of `FLT_MAX` for initialization requires careful handling of comparisons to avoid overflow or incorrect min/max operations if not initialized properly [S1, unofficial].
*   **Boundaries**: Bounding box intersection checks are critical for pruning. If `box_intersects` is incorrect, performance degrades significantly [S1, unofficial].
*   **Normal Distance Culling**: When `normaldist` is provided, the logic `abs(tempdist[i]) < normaldist[i]` is specific. If `normaldist` is not provided, standard min/max logic applies [S1, unofficial].

## Subtopics

### Lipschitz Pruning
A sibling method that uses Lipschitz constants to prune the search space during distance field evaluation, potentially offering better performance for complex scenes but requiring Lipschitz constant computation [8623-lipschitz-pruning.md].

### Constructive Solid Geometry (CSG) on Level Sets
The parent method that defines the general framework for CSG operations on implicit functions, of which this batched evaluation is a specific implementation [1627-constructive-solid-geometry-csg-on-level-sets.md].

## Operating characteristics
*   **Time Complexity**: $O(N \cdot D)$, where $N$ is the number of points and $D$ is the depth of the CSG tree. Each point is evaluated at each node in the worst case, but bounding box pruning reduces this.
*   **Memory Complexity**: $O(N)$ for the distance and material index arrays, plus $O(N)$ for temporary arrays in Union/Intersection/Difference operations.
*   **Performance**: The non-SIMD implementation may be slower than SIMD-optimized versions but is portable and simple [S1, unofficial].
*   **Strengths**: Handles complex CSG trees, supports material indices, and provides batched evaluation for efficiency.
*   **Limitations**: Non-SIMD, potentially high memory usage for temporary arrays in boolean operations, and no explicit handling of normals beyond distance culling.

## Background
The method is derived from the `mini.q` project by bsegovia, which provides a compact implementation of various graphics algorithms [S1, unofficial]. It is designed for integration into volume rendering pipelines where efficient evaluation of procedural and mathematical surfaces is required.
