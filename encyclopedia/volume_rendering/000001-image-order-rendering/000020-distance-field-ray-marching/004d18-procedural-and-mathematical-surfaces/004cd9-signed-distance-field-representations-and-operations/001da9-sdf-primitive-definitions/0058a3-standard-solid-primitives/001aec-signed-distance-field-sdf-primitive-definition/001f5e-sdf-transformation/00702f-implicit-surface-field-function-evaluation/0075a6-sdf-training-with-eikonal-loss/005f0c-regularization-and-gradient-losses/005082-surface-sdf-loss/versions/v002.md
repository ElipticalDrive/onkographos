# Surface SDF Loss

Also called: SDF Surface Loss

## Overview
Surface SDF Loss is a regularization term used in neural implicit surface reconstruction to enforce geometric consistency between a Signed Distance Field (SDF) model and a Directional Distance Field (DDF) model. It constrains the DDF predictions by ensuring that points projected along the predicted directional distances lie close to the zero-level set of the SDF. It differs from standard SDF supervision (which compares against ground truth) by enforcing agreement between two learned representations [S2].

## How it works
**Inputs and Outputs:**
*   **Inputs:**
    *   $f_s(\cdot)$: The SDF network function.
    *   $(p, r)$: A set of point-direction tuples where the ray originates at $p$ and points toward the object surface.
    *   $d$: The predicted directional distance from the DDF network for each tuple $(p, r)$.
*   **Outputs:**
    *   $\mathcal{L}_{ts}$: A scalar loss value representing the mean absolute SDF value at the projected points.

**Data Structures:**
*   Points $p \in \mathbb{R}^3$.
*   Directions $r \in \mathbb{R}^3$ (typically normalized).
*   Distances $d \in \mathbb{R}$.

**Steps:**
1.  For each point-direction tuple $(p, r)$ and its predicted directional distance $d$:
    *   Compute the projected point $x_{proj}$ using the formula:
        $$ x_{proj} = p + d \cdot r $$
2.  Evaluate the SDF network at the projected point:
    $$ s_{pred} = f_s(x_{proj}) $$
3.  Compute the L1 norm of the SDF value:
    $$ \mathcal{L}_{ts}(d) = \| f_s(p + d \cdot r) \|_1 $$
4.  The total loss is the mean of $\mathcal{L}_{ts}(d)$ over all sampled tuples.

**Parameters:**
*   None specific to the loss function itself, other than the hyperparameter $\lambda_{ts}$ for weighting in the total loss.

**Edge Cases and Pitfalls:**
*   **Application Domain:** This loss is applied **only** to the DDF model parameters. It does not backpropagate gradients to the SDF model [S2].
*   **Surface Proximity:** The point-direction pairs $(p, r)$ must be selected such that they point to the object surface; otherwise, the projection may land in empty space or inside the object, leading to misleading gradients.
*   **Zero-Level Set:** The goal is to minimize the SDF value to 0, not the distance itself.

**Pseudocode:**
```python
def surface_sdf_loss(sdf_network, ddf_directional_distances, points, directions):
    """
    Computes the Surface SDF Loss (Track-SDF Regularizer).
    
    Args:
        sdf_network: Function f_s(x) returning SDF value.
        ddf_directional_distances: Tensor d of shape (N,) containing predicted directional distances.
        points: Tensor p of shape (N, 3) containing ray origins.
        directions: Tensor r of shape (N, 3) containing ray directions.
        
    Returns:
        Scalar loss value.
    """
    # Step 1: Compute projected points using DDF predictions
    # x_proj = p + d * r
    projected_points = points + ddf_directional_distances.unsqueeze(1) * directions
    
    # Step 2: Evaluate SDF at projected points
    # s_pred = f_s(x_proj)
    sdf_values = sdf_network(projected_points)
    
    # Step 3: Compute L1 norm of SDF values
    # L_ts = || f_s(p + d*r) ||_1
    loss_per_point = torch.abs(sdf_values)
    
    # Step 4: Mean over all points
    total_loss = torch.mean(loss_per_point)
    
    return total_loss
```

## Subtopics

### Track-SDF Regularizer
The Track-SDF Regularizer is the specific implementation of the Surface SDF Loss described in [S2]. It is used in the FIRe framework to align DDF predictions with SDF geometry. It is chosen when training coupled SDF and DDF models to ensure that the directional distances predicted by the DDF correspond to actual surface intersections defined by the SDF. It is distinct from SDF Loss (which uses ground truth) and DDF Loss (which uses ground truth distances).

## Operating characteristics
*   **Time Complexity:** Linear with respect to the number of sampled point-direction tuples $N$. Requires one forward pass through the SDF network for each tuple.
*   **Memory Complexity:** Linear with respect to $N$ to store intermediate projected points and SDF values.
*   **Strengths:** Enforces geometric consistency between two different implicit representations without requiring ground truth geometry for the DDF component.
*   **Limitations:** Relies on the accuracy of the SDF model; if the SDF is poorly trained, the regularizer may provide misleading gradients. Only applicable to DDF training.
*   **When to use:** When using a DDF model alongside an SDF model in inverse rendering or shape reconstruction.
*   **When not to use:** When training only an SDF model or when ground truth distances are available for direct supervision.

## Background
The Surface SDF Loss, referred to as the "Track-SDF Regularizer," was introduced in the FIRe (Fast Inverse Rendering Using Directional and Signed Distance Functions) paper [S2]. It addresses the inconsistency between predicted directional distances and signed distances in multi-representation neural implicit modeling.
