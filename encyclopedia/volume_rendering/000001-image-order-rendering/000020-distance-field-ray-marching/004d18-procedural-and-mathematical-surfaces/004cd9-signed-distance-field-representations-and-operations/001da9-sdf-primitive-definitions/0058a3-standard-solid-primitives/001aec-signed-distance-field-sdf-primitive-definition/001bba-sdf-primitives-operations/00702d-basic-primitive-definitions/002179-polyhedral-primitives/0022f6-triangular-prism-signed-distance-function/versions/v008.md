# Triangular Prism Signed Distance Function

Also called: Signed Triangle Prism, Triangular Prism SDF, sdTriPrism

## Overview
Computes the exact Euclidean signed distance from a query point to the surface of a triangular prism. It differs from other polyhedral primitives by projecting the query point onto a 2D equilateral triangle in the cross-sectional plane, leveraging the triangle's symmetry to avoid iterative projection steps. It builds on [Polyhedral Primitives](2529-polyhedral-primitives.md).

## How it works
**Inputs:** Query point $p \in \mathbb{R}^3$ and parameter vector $h \in \mathbb{R}^2$.
**Outputs:** Scalar signed distance $d \in \mathbb{R}$.

**Data Structures:**
*   $p$: Input point $(p_x, p_y, p_z)$.
*   $h$: Parameter vector $(h_x, h_y)$. $h_x$ controls the triangle size, $h_y$ controls the half-height.

**Assumptions:**
The prism is centered at the origin, with its axis aligned to the Z-axis. The cross-section is an equilateral triangle. The primitive is axis-aligned. Transformations are applied to $p$ before evaluation.

**Formula:**
The distance is computed by taking the absolute value of the query point to exploit symmetry, then calculating the distance to the 2D equilateral triangle in the XY plane and the distance to the height bounds in the Z plane.

Let $q = |p| = (|p_x|, |p_y|, |p_z|)$.
The signed distance is:
$$ d = \max(q_z - h_y, \max(q_x \cdot \frac{\sqrt{3}}{2} + q_y \cdot \frac{1}{2}, -q_y) - h_x \cdot \frac{1}{2}) $$

Where:
*   $q_z = |p_z|$
*   $q_x = |p_x|$
*   $q_y = |p_y|$
*   $\frac{\sqrt{3}}{2} \approx 0.866025$
*   $h_x$ is the half-width parameter related to the triangle side length.
*   $h_y$ is the half-height of the prism.

**Pseudocode:**
```python
import numpy as np

def sd_tri_prism(p: np.ndarray, h: np.ndarray) -> float:
    """
    Compute signed distance to a triangular prism.
    
    Args:
        p: Query point (3,)
        h: Parameters (2,) where h[0] is triangle size parameter, h[1] is half-height
        
    Returns:
        Signed distance
    """
    # Take absolute value of point coordinates
    q = np.abs(p)
    
    # Extract components
    qx, qy, qz = q
    
    # Calculate distance to the triangular cross-section in XY plane
    # The term (qx * sqrt(3)/2 + qy * 1/2) corresponds to the projection onto one of the triangle's normal vectors
    # The term (-qy) corresponds to the projection onto the bottom edge's normal
    # We take the max of these two, then subtract the size parameter scaled by 0.5
    tri_dist = max(qx * 0.866025 + qy * 0.5, -qy) - h[0] * 0.5
    
    # Calculate distance to the top/bottom caps in Z direction
    cap_dist = qz - h[1]
    
    # The final distance is the maximum of the cross-section distance and the cap distance
    # This correctly handles the corners and edges where both constraints are active
    d = max(cap_dist, tri_dist)
    
    return d
```

**Edge Cases and Pitfalls:**
*   **Precision:** The constant $0.866025$ is an approximation of $\frac{\sqrt{3}}{2}$. For high-precision applications, use `np.sqrt(3)/2` or `math.sqrt(3)/2`.
*   **Degenerate Input:** If $h_x = 0$, the triangle collapses to a line segment. If $h_y = 0$, the prism collapses to a triangle. The formula still holds but may produce distances to degenerate shapes.
*   **Sign Convention:** The output $d$ is positive outside, negative inside, and zero on the surface.

## Operating characteristics
*   **Time Complexity:** $O(1)$ constant time. Only basic arithmetic operations and absolute values are required.
*   **Memory Complexity:** $O(1)$ constant space.
*   **Strengths:** Extremely fast evaluation, no iterative refinement needed, exact distance.
*   **Limitations:** Only applies to equilateral triangular prisms. Non-equilateral triangles require different formulations.
*   **When to use:** When rendering or ray-marching equilateral triangular prisms is required.
*   **When not to use:** For non-equilateral triangular prisms or when higher-order primitives are needed.

## Background
The triangular prism SDF is a standard primitive in Signed Distance Field (SDF) ray marching, popularized by Inigo Quilez's work on SDF primitives. It is widely used in procedural modeling and ray marching shaders due to its simplicity and efficiency. The specific formula using the absolute value and the specific linear combination of coordinates exploits the symmetry of the equilateral triangle.
