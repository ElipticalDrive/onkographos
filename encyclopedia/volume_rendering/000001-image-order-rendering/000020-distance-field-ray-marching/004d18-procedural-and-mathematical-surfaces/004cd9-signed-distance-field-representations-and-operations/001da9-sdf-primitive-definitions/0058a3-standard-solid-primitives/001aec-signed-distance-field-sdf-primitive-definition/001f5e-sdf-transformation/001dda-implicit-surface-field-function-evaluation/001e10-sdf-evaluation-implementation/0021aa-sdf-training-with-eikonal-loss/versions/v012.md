# SDF Training with Eikonal Loss

Also called: Implicit Geometric Regularization, Implicit neural representations with Eikonal regularization, Neural SDF Training with Eikonal Regularization, SDF Surface Training with Eikonal Loss, Training of Deep Implicit Surface Networks (SDF MLP)

## Overview
This method trains a Multi-Layer Perceptron (MLP) to predict a Signed Distance Function (SDF) directly from raw 3D point cloud data by enforcing the Eikonal equation, which requires the gradient magnitude of the SDF to be unity everywhere [S6, unofficial]. Unlike methods that require pre-computed 3D supervision (such as occupancy grids or pre-computed SDFs) or explicit regularization on the zero-level set, this approach relies on implicit geometric regularization to produce high-fidelity surfaces with smooth topology [S6, unofficial]. It sets itself apart from standard SDF evaluation implementations by introducing a specific loss term that penalizes deviations of the gradient norm from 1, thereby ensuring the learned function behaves as a true distance field rather than an arbitrary implicit function [S4, S7, unofficial].

## How it works
**Inputs and Outputs:**
*   **Input:** A 3D point cloud $P = \{p_i\}$ with associated normals $N = \{n_i\}$ (optional) and a bounding box $\Omega$ defining the training volume [S3][S6, unofficial].
*   **Output:** An MLP parameterized by $\theta$ that approximates the signed distance function $\phi(x; \theta)$ [S6, unofficial].

**Data Structures:**
*   **MLP Architecture:** A feed-forward neural network. Common configurations include depth $D$ and width $W$ (e.g., D6-W60) [S1, unofficial]. The network uses a non-linear differentiable activation function applied entrywise, typically Softplus [S6, unofficial].
*   **Point Cloud Data:** Tensors of shape $(N, 3)$ for vertices and $(N, 3)$ for normals [S7, unofficial].
*   **Optimizer State:** Parameters for Adam optimizer (learning rate, weight decay) [S1, S7, unofficial].

**Numbered Steps:**

1.  **Data Preprocessing:**
    *   Load the point cloud vertices.
    *   Center the point cloud by subtracting the mean: $P_{centered} = P - \text{mean}(P)$ [S7, unofficial].
    *   Normalize the 3D space to a bounding box, typically $[-1, 1]^3$ [S1, S7, unofficial].

2.  **Pretraining (Optional but Recommended):**
    *   Sample random points uniformly within the bounding box $\Omega$ [S5, unofficial].
    *   Pretrain the SDF using a "sphere loss" or similar initialization loss to ensure the network starts with a plausible distance field structure [S5, S7, unofficial]. This involves minimizing the distance of points to a unit sphere or similar prior [S7, unofficial].

3.  **Sampling:**
    *   **Surface Points:** Sample a batch of points $x_s$ from the input point cloud $P$ [S4, S7, unofficial].
    *   **Eikonal Points:** Sample a batch of points $x_e$ uniformly from the bounding box $\Omega$ [S4, S7, unofficial]. These points cover the volume, including free space and inside the object, to enforce the gradient constraint globally [S6, unofficial].

4.  **Forward Pass & Gradient Computation:**
    *   Query the MLP for distances and gradients at the sampled points.
    *   For surface points $x_s$: Compute distance $d_s = \phi(x_s; \theta)$ [S4, unofficial].
    *   For eikonal points $x_e$: Compute distance $d_e = \phi(x_e; \theta)$ and gradient $\nabla \phi(x_e; \theta)$ using automatic differentiation [S4, S7, unofficial].
    *   *Note:* Ensure `requires_grad=True` is set for input points before computing gradients to enable backpropagation [S9, unofficial].

5.  **Loss Computation:**
    The total loss $\mathcal{L}$ is a weighted sum of the following terms [S3][S4, S7, unofficial]:

    *   **Point Cloud Loss ($\mathcal{L}_{data}$):** Encourages the SDF to be zero at the observed points.
        $$ \mathcal{L}_{data} = \frac{1}{N_s} \sum_{i=1}^{N_s} |\phi(x_{s,i}; \theta)| $$
        If normals are available, an additional alignment term can be added: $\lambda_3 |1 - \langle \nabla_{x} \phi(x), n(x) \rangle|$ [S3].

    *   **Eikonal Loss ($\mathcal{L}_{eikonal}$):** Enforces the unit gradient magnitude constraint $|\nabla \phi(x)| = 1$ [S4, S7, unofficial].
        $$ \mathcal{L}_{eikonal} = \frac{1}{N_e} \sum_{j=1}^{N_e} \left( \|\nabla \phi(x_{e,j}; \theta)\|_2 - 1 \right)^2 $$
        Some implementations use the absolute difference $|\|\nabla \phi\|_2 - 1|$ [S4, unofficial].

    *   **Interior/Free-Space Regularization (Optional):** Penalizes points inside the object or in free space to prevent flat regions or spurious outliers [S4, S7, unofficial].
        $$ \mathcal{L}_{inter} = \mathbb{E}_{x \in \Omega} \left[ \exp(-\beta_0 |d_e|) \right] $$
        Where $\beta_0$ is typically set to $100$ (or $1e2$) [S3][S7, unofficial]. This term is often weighted by `inter_weight` [S4, unofficial].

    *   **Total Loss:**
        $$ \mathcal{L} = \mathcal{L}_{data} + \lambda_{eik} \mathcal{L}_{eikonal} + \lambda_{inter} \mathcal{L}_{inter} $$
        Typical values: $\lambda_{eik} \in [0.01, 0.02]$ [S1, unofficial][S2], $\lambda_{inter}$ varies by config [S7, unofficial].

6.  **Optimization:**
    *   Perform backpropagation: `optimizer.zero_grad()`, `loss.backward()`, `optimizer.step()` [S4, S7, unofficial].
    *   Use the Adam optimizer with a learning rate starting at $1e-3$ and weight decay $1e-4$ [S1, unofficial].
    *   Apply a learning rate scheduler (e.g., LambdaLR) decaying every 20 epochs by a factor of 10 [S1, S5, unofficial].

**Pseudocode:**

```python
import torch
import torch.nn as nn

class NeuralSDF(nn.Module):
    def __init__(self, hidden_dim=64, num_layers=6):
        super().__init__()
        layers = []
        layers.append(nn.Linear(3, hidden_dim))
        layers.append(nn.Softplus())
        for _ in range(num_layers - 1):
            layers.append(nn.Linear(hidden_dim, hidden_dim))
            layers.append(nn.Softplus())
        layers.append(nn.Linear(hidden_dim, 1))
        self.network = nn.Sequential(*layers)

    def forward(self, x):
        return self.network(x)

def compute_eikonal_loss(gradient):
    """
    Computes the Eikonal loss: mean squared error of gradient norm from 1.
    Args:
        gradient: Tensor of shape (N, 3) containing spatial gradients.
    Returns:
        Scalar loss value.
    """
    grad_norm = torch.norm(gradient, dim=1, keepdim=True) # Shape (N, 1)
    return torch.mean((grad_norm - 1.0) ** 2)

def train_sdf(model, point_cloud, bounds, config):
    """
    Trains the SDF model using Eikonal regularization.
    """
    optimizer = torch.optim.Adam(model.parameters(), lr=1e-3, weight_decay=1e-4)
    scheduler = torch.optim.lr_scheduler.LambdaLR(optimizer, lr_lambda=lambda epoch: 0.1 ** (epoch // 20))
    
    # Pretraining phase (optional)
    # ... (implement sphere loss pretraining) ...

    for epoch in range(config.num_epochs):
        # 1. Sample points
        # Surface points from point cloud
        surface_points = sample_random_points(point_cloud, config.batch_size)
        
        # Eikonal points uniformly in bounding box
        eikonal_points = sample_random_points_uniform(bounds, config.batch_size)
        
        # Ensure gradients are tracked
        surface_points.requires_grad_(True)
        eikonal_points.requires_grad_(True)
        
        # 2. Forward pass
        # Surface distances
        surface_dist = model(surface_points).squeeze(-1)
        
        # Eikonal distances and gradients
        eikonal_dist = model(eikonal_points).squeeze(-1)
        # Compute gradients using autograd
        gradients = torch.autograd.grad(
            eikonal_dist, eikonal_points, 
            grad_outputs=torch.ones_like(eikonal_dist), 
            create_graph=True, 
            retain_graph=True
        )[0]
        
        # 3. Compute Losses
        # Point cloud loss (L1 distance to 0)
        loss_data = torch.mean(torch.abs(surface_dist))
        
        # Eikonal loss
        loss_eikonal = compute_eikonal_loss(gradients)
        
        # Interior/Free-space regularization (optional)
        # Penalize points close to zero in the volume to avoid flat regions
        # Using exp(-beta * |dist|) where beta=100
        beta = 100.0
        loss_inter = torch.mean(torch.exp(-beta * torch.abs(eikonal_dist)))
        
        # Total loss
        total_loss = (loss_data + 
                      config.eikonal_weight * loss_eikonal + 
                      config.inter_weight * loss_inter)
        
        # 4. Backpropagate
        optimizer.zero_grad()
        total_loss.backward()
        optimizer.step()
        
        scheduler.step()
```

**Parameters:**
*   `eikonal_weight`: Weight for the gradient magnitude regularization term. Typical value: $0.01$ to $0.02$ [S1, unofficial][S2][S7, unofficial].
*   `inter_weight`: Weight for the interior/free-space regularization term [S4, S7, unofficial].
*   `batch_size`: Number of points sampled per optimization step [S4, unofficial].
*   `bounds`: Spatial limits for sampling random eikonal points, typically $[-1, 1]^3$ [S4, S7, unofficial].
*   `learning_rate`: Initial learning rate for Adam, typically $1e-3$ [S1, unofficial].
*   `activation`: Non-linear activation function, typically Softplus [S6, unofficial].

**Edge Cases and Pitfalls:**
*   **Non-Uniqueness:** The solution to the Eikonal equation vanishing on a point set is not unique. The method relies on implicit regularization to find a plausible SDF rather than any arbitrary solution [S6, unofficial].
*   **Approximation Quality:** The zero-level isosurface only approximates the ground-truth mesh; quality depends on MLP capacity (depth/width) [S1, unofficial].
*   **Gradient Computation:** `requires_grad=True` must be set for input points before computing gradients to enable backpropagation [S9, unofficial].
*   **Precision:** Using absolute difference vs. squared difference in Eikonal loss can affect stability; squared difference is more common in literature [S7, unofficial], while absolute difference is used in some implementations [S4, unofficial].

### Bias Network for High-Fidelity Points
A network that captures geometric bias between volume rendering and point modeling, trained on high-fidelity points to enhance detail representation [S8, unofficial]. It filters points with predicted variance below a threshold $\epsilon$ to create a set $P_s$, then optimizes a bias MLP $f_b$ using L1 loss against ideal SDF values (assumed 0) on these points: $L_{bias} = \frac{1}{D_{Ps}} \sum |f_\epsilon(x_P) - (f(x_P) + f_b(x_P))|$ [S8, unofficial].

### SDF Training with Chamfer Distance
Trains a network to predict Unsigned Distance Function (UDF) values and gradients, projecting query points onto the implicit surface via gradient descent and minimizing Chamfer distance [S9, unofficial]. It moves samples $x_{sample}$ to the surface using $x_{moved} = x_{sample} - \frac{\nabla \text{UDF}(x_{sample})}{\|\nabla \text{UDF}(x_{sample})\|} \cdot \text{UDF}(x_{sample})$ [S9, unofficial]. A critical pitfall is ensuring `samples.requires_grad = True` before gradient computation [S9, unofficial].

### Implicit Surface to Volume Transformation
Represents geometry as a surface $S = \{x \mid F(x) = 0\}$ and transforms it to a volumetric model by computing pseudo-density $\sigma_i = \Psi(F(x_i))$ using a Laplace cumulative distribution function parameterized by an optimizable scale $\beta$ [S10]. Unlike volumetric radiance fields, it restricts the network to predict density based only on spatial coordinates, allowing color to depend on view direction [S10].

### L1 Regression Baseline for SDF
A baseline method that trains an MLP to regress a pre-computed approximated SDF using L1 loss, serving as a fidelity comparison [S6, unofficial]. It approximates the SDF locally using $s(x) = n^{*T} (x - y^*)$ where $y^*$ is the closest point on the surface. This method results in fewer details compared to Eikonal regularization because it approximates the SDF nearby the surface rather than strictly on it [S6, unofficial].

### SDF Regression
The goal is to regress a feed-forward network to approximate the SDF induced by a surface, preferred over occupancy learning because SDFs are more immediately useful for graphics operations like CSG and distance queries [S11, unofficial].

## Operating characteristics
*   **Time Complexity:** Depends on the number of MLP evaluations per batch and the number of epochs. Inference time for a D6-W60 MLP is approximately 20.8 seconds for mesh extraction (Marching Cubes) on a single object [S1, unofficial].
*   **Memory Complexity:** Proportional to the MLP size (parameters) and the batch size of points stored in memory during training [S1, S4, unofficial].
*   **Performance:** Produces state-of-the-art implicit neural representations with higher fidelity and detail compared to regression-based methods or those requiring 3D supervision [S6, unofficial].
*   **Strengths:** Works directly from raw point clouds without pre-computed 3D supervision; enforces smooth, plausible zero-level sets through implicit regularization; differentiable end-to-end [S6, unofficial].
*   **Limitations:** Approximation quality is limited by MLP capacity; the solution to the Eikonal equation is not unique, relying on SGD to find a good local minimum; requires careful tuning of regularization weights ($\lambda_{eik}$) [S1, S6, unofficial].
*   **When to Use:** When high-fidelity surface reconstruction from point clouds is required without access to ground-truth SDFs or occupancy grids.
*   **When Not to Use:** When real-time inference is critical and MLP evaluation is too slow, or when the input data is extremely noisy and requires explicit topological constraints beyond implicit regularization.

## Background
The method was introduced by Amos Gropp et al. in 2020 in the paper "Implicit Geometric Regularization for Learning Shapes" [S6, unofficial]. It addresses the limitation of previous implicit neural representations that required 3D supervision (pre-computed SDFs or occupancy grids) [S6, unofficial]. The key insight is that minimizing the deviation of the gradient norm from 1 (the Eikonal equation) acts as an implicit geometric regularizer, favoring smooth and natural zero-level set surfaces even when trained only on raw point cloud data [S6, unofficial]. It has been widely adopted in subsequent works such as VolSDF [S4, unofficial][S10] and various neural surface rendering pipelines [S7, unofficial].
