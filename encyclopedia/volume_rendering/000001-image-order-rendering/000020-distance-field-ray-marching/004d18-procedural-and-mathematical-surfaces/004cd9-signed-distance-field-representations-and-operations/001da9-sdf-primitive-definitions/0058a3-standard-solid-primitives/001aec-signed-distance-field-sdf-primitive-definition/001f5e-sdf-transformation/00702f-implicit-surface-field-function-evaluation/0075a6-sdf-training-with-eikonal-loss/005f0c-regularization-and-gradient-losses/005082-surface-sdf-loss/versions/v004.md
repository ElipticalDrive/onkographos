# Surface SDF Loss


## Overview
The Surface SDF Loss is a regression loss function used to supervise neural networks predicting Signed Distance Fields (SDFs) by minimizing the L1 distance between predicted signed distances and ground truth SDF values [S1, unofficial]. It is distinguished from occupancy-based losses (e.g., [Occupancy Networks](14234-occupancy-networks.md)) by directly optimizing geometric accuracy rather than binary classification, though it is often combined with sign supervision for stability in meta-learning contexts [S2].

## How it works
The loss is computed over a set of query points $\mathcal{Q}$ located on the surface of the target geometry. For each point $\mathbf{x} \in \mathcal{Q}$, the network $f(\mathbf{x})$ predicts the signed distance $s$. The loss is the mean absolute error between the predicted distance and the ground truth distance (which is zero for points exactly on the surface, or the known distance if ground truth SDF values are provided).

**Inputs:**
- $f(\mathbf{x})$: Neural network predicting SDF value $s$ at query point $\mathbf{x}$.
- $\mathcal{Q}_{surface}$: Set of query points on the surface.
- $s_{gt}(\mathbf{x})$: Ground truth SDF value at $\mathbf{x}$ (typically $0$ for surface points).

**Outputs:**
- $\mathcal{L}_{surface}$: Scalar loss value.

**Data Structures:**
- Query points $\mathbf{x}$: 3D coordinates $(x, y, z)$.
- Predicted SDF $s$: Scalar float.

**Steps:**
1. Sample a batch of points $\mathcal{Q}_{surface}$ on the surface of the target geometry.
2. For each point $\mathbf{x}_i \in \mathcal{Q}_{surface}$, compute the predicted SDF value $s_i = f(\mathbf{x}_i)$.
3. Compute the ground truth SDF value $s_{gt, i}$ for each point. For points exactly on the surface, $s_{gt, i} = 0$.
4. Compute the L1 loss for each point: $l_i = |s_i - s_{gt, i}|$.
5. Compute the mean loss: $\mathcal{L}_{surface} = \frac{1}{N} \sum_{i=1}^{N} l_i$, where $N$ is the number of points.

**Formula:**
$$ \mathcal{L}_{surface} = \frac{1}{N} \sum_{i=1}^{N} |f(\mathbf{x}_i) - s_{gt}(\mathbf{x}_i)| $$

**Parameters:**
- $N$: Number of surface points. Not given in the sources.
- Weighting factor $\lambda_{surface}$: Hyperparameter to balance this loss with others (e.g., Eikonal loss). Not given in the sources.

**Edge Cases and Pitfalls:**
- If surface points are not accurately sampled, the loss may not converge to the correct geometry.
- The loss assumes the network output is a signed distance function; if the network is not constrained to satisfy the Eikonal equation (covered in [Regularization and Gradient Losses](17793-regularization-and-gradient-losses.md)), the gradients may be inconsistent with the predicted distances.
- In some implementations, if `surface_sdf` is not provided, the loss may be computed as the mean of `abs(surface_sdf)` multiplied by a weight (e.g., 0.0 if not active) [S1, unofficial].

**Pseudocode:**
```python
def surface_sdf_loss(f, surface_points, surface_sdf_gt):
    """
    Compute the Surface SDF Loss.
    
    Args:
        f: Neural network function that takes 3D points and returns SDF values.
        surface_points: Tensor of shape (N, 3) containing query points on the surface.
        surface_sdf_gt: Tensor of shape (N,) containing ground truth SDF values (typically 0).
        
    Returns:
        loss: Scalar tensor representing the mean L1 loss.
    """
    # Predict SDF values for the surface points
    predicted_sdf = f(surface_points)
    
    # Compute L1 loss between predicted and ground truth SDF values
    # Note: If surface_sdf_gt is not provided or is None, the loss might be skipped or set to 0
    # as per [S1, unofficial], but standard implementation assumes ground truth is available.
    if surface_sdf_gt is None:
        return 0.0
    
    loss = torch.mean(torch.abs(predicted_sdf - surface_sdf_gt))
    return loss
```

## Subtopics

### [SDF Loss](17752-sdf-loss.md)
SDF Loss is a regression loss function used to supervise neural networks predicting Signed Distance Fields (SDFs) by minimizing the L1 distance between predicted signed distances and ground truth SDF values. It is distinguished from occupancy-based losses (e.g., [Occupancy Networks](14234-occupancy-networks.md)) by directly optimizing geometric accuracy rather than binary classification, though it is often combined with sign supervision for stability in meta-learning contexts.

### [Off-surface Point Loss](19753-off-surface-point-loss.md)
The off-surface point loss is a regularization term used in training Signed Distance Field (SDF) networks to enforce that the predicted distance values are positive and large for points located far outside the target geometry. It complements the surface SDF loss by penalizing the network for predicting negative or small positive values in the exterior region, thereby preventing the SDF from collapsing or becoming ambiguous in empty space. It is distinct from the [SDF Loss](17752-sdf-loss.md) which primarily targets points on or near the surface.

### Track-SDF Regularizer
The Track-SDF Regularizer is a constraint used in Directional Distance Field (DDF) and SDF co-training to ensure consistency between the two representations. It enforces that points predicted by the DDF model lie close to the SDF zero-level set. Specifically, for point-direction pairs $(p, r)$ that point to the object surface, the DDF prediction $d$ is used to compute a new point $p + dr$. The loss minimizes the L1 norm of the SDF value at this new point: $\mathcal{L}_{ts}(d) = \|f_s(p+dr)\|_1$. This loss is applied only to the DDF model, not the SDF model [S2].

## Operating characteristics
- **Time Complexity**: Linear with respect to the number of surface points $N$, $O(N)$, as it involves a forward pass through the network and a mean reduction.
- **Memory Complexity**: Linear with respect to $N$, $O(N)$, to store the predicted SDF values and gradients.
- **Strengths**: Directly optimizes geometric accuracy; simple to implement; effective when combined with gradient-based losses like Eikonal.
- **Limitations**: Requires accurate surface point sampling; does not enforce smoothness or gradient magnitude constraints on its own.
- **When to use**: When training SDF networks for high-fidelity geometry reconstruction where surface accuracy is critical.
- **When not to use**: When only occupancy information is available or when computational resources are extremely limited and approximate geometry is acceptable.

## Background
The Surface SDF Loss is a fundamental component in the training of neural SDF representations. It was introduced in the context of SDFStudio, a framework for learning SDFs from multi-view images [S1, unofficial]. The method builds on the idea that SDFs can be learned by minimizing the difference between predicted and ground truth distances at surface points. The Track-SDF Regularizer, a variant used in conjunction with DDF, was introduced in the FIRe paper for fast inverse rendering [S2].
