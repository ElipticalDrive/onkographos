# Batched SDF Query with Joint Configuration


## Overview
This method evaluates Signed Distance Fields (SDFs) for volumetric structures across multiple joint configurations and query points simultaneously to manage memory during batched inference [S1, unofficial]. It differs from single-configuration queries by integrating Forward Kinematics (FK) chains to support automatic differentiation with respect to joint angles, enabling gradient-based optimization such as trajectory optimization for collision avoidance [S1, unofficial].

## How it works
**Inputs and Outputs:**
- `points`: Input tensor of shape $(N, d)$ representing $N$ geometric points in $d$ dimensions [S1, unofficial].
- `joint_configuration`: Input tensor of shape $(B, J)$ representing $B$ batched configurations, each with $J$ joint angles [S1, unofficial].
- `range_per_dim`: Input tensor of shape $(d, 2)$ specifying the minimum and maximum range for each dimension [S1, unofficial].
- `compute_grad`: Boolean parameter for the `CachedSDF` class; if `False`, gradient computation is skipped entirely to improve performance [S1, unofficial].
- `sdf_val`: Output tensor of shape $(B, N)$ containing signed distance values [S1, unofficial].
- `sdf_grad`: Output tensor of shape $(B, N, d)$ containing gradients with respect to points, or `None` if `compute_grad` is `False` [S1, unofficial].

**Data Structures:**
The implementation uses a custom PyTorch `Function` subclass (e.g., `ObjectFrameSDF`) to manage the forward and backward passes for automatic differentiation [S1, unofficial]. The forward pass evaluates the SDF and saves the gradient tensor for the backward pass [S1, unofficial]. The backward pass computes the gradient of the loss with respect to the input points by multiplying the upstream gradient by the saved SDF gradient [S1, unofficial].

**Steps:**
1. **Range Validation:** Check if query points lie within the specified `range_per_dim` using the `is_inside` helper function, which returns a boolean tensor indicating membership [S1, unofficial].
2. **Configuration Application:** Apply the batched joint configuration to the SDF object via `set_joint_configuration`, which internally computes the Forward Kinematics (FK) chain to transform points into the object frame [S1, unofficial].
3. **SDF Evaluation:** Evaluate the SDF value at the transformed points. If `compute_grad` is `True`, compute the gradient of the SDF with respect to the points in the object frame [S1, unofficial].
4. **Gradient Accumulation (Backward):** If `compute_grad` is `True`, the backward pass computes the gradient of the loss with respect to the input points using element-wise multiplication [S1, unofficial].

**Formulas:**
The `is_inside` helper function evaluates membership as:
$$ \text{is\_inside}(\mathbf{P}, \mathbf{R}) = \bigwedge_{i=0}^{d-1} (R_{i,0} \le P_{:,i} \le R_{i,1}) $$
where $\mathbf{P}$ is the points tensor of shape $(N, d)$ and $\mathbf{R}$ is the range tensor of shape $(d, 2)$ [S1, unofficial].
The backward pass computes the gradient with respect to the points as:
$$ \frac{\partial \text{loss}}{\partial \mathbf{P}_{\text{obj}}} = \frac{\partial \text{loss}}{\partial \text{sdf\_val}} \otimes \text{sdf\_grad} $$
where $\otimes$ denotes element-wise multiplication broadcasted appropriately [S1, unofficial].

```python
def is_inside(points: torch.Tensor, range_per_dim: torch.Tensor) -> torch.Tensor:
    """Check if points are within the specified range per dimension."""
    return torch.all((range_per_dim[:, 0] <= points) & (points <= range_per_dim[:, 1]), dim=-1)

        # Expand points to (B, N, d) for batched evaluation

            points = points.unsqueeze(0).expand(B, -1, -1)

    @staticmethod
    def backward(ctx, grad_outputs):
        if not ctx.compute_grad:
            return None, None, None
        sdf_grad, = ctx.saved_tensors
        dsdf_vals_dpoints = grad_outputs[0].unsqueeze(-1) * sdf_grad
        return dsdf_vals_dpoints, None, None

def query(points: torch.Tensor, joint_config: torch.Tensor, range_per_dim: torch.Tensor, compute_grad: bool = True) -> tuple:
    """Query SDF for batched joint configurations."""
    # Validate points are within range
    is_in_range = is_inside(points, range_per_dim)
    # Set configuration and evaluate
    sdf_val, sdf_grad = CachedSDF.apply(points, joint_config, compute_grad)
    return sdf_val, sdf_grad
```

**Parameters:**
- `compute_grad`: Boolean. Default `True`. If `False`, skips gradient computation, improving performance [S1, unofficial].
- `points`: Input tensor of shape $(N, d)$ [S1, unofficial].
- `range_per_dim`: Input tensor of shape $(d, 2)$ [S1, unofficial].

**Edge Cases and Pitfalls:**
- **Boundaries:** Points outside `range_per_dim` may yield undefined or incorrect SDF values if not pre-filtered [S1, unofficial].
- **Degenerate Input:** Empty point sets or zero-sized batches should be handled gracefully by the underlying batched kernel [S1, unofficial].

## Operating characteristics
**Time and Memory Complexity:**
- Time complexity scales linearly with the number of points $N$ and the number of batched configurations $B$ [S1, unofficial].
- Memory complexity is dominated by the storage of $B \times N$ SDF values and gradients [S1, unofficial].

**Measured Performance:**
- On an RTX 4070 with an 8-link Kuka robot:
    - Single configuration with 100K points: 3.1 ms [S1, unofficial].
    - 1000 configurations x 10K points: 198 ms [S1, unofficial].
    - 5000 configurations x 10K points: 997 ms [S1, unofficial].

**Strengths and Limitations:**
- **Strengths:** High throughput for batched queries; supports autograd for optimization [S1, unofficial].
- **Limitations:** Not given in the sources.

**When to Use:**
- Use for trajectory optimization, collision avoidance, and any scenario requiring gradient-based optimization over joint configurations [S1, unofficial].

**When Not to Use:**
- Avoid for single-point queries where overhead of batching is not justified [S1, unofficial].

## Background
This method originates from the `pytorch_volumetric` library by the University of Michigan ARM Lab [S1, unofficial]. It is designed to integrate volumetric SDF representations with robotic kinematics, enabling efficient collision checking and optimization in high-dimensional configuration spaces [S1, unofficial].
