# Signed Distance Field (SDF) Primitive Definition

Also called: SDF Function, SDF Shapes, Signed Distance Field (SDF), Signed Distance Function (SDF), Signed Distance Function Primitives

## Overview
A Signed Distance Field (SDF) Primitive Definition is a method for representing 3D geometry using closed-form analytical functions that return the shortest Euclidean distance from a query point to the nearest surface, along with a sign indicating whether the point is inside or outside the object [S2, S3, S8, unofficial]. It solves the problem of defining complex scene geometry for distance-field ray marching without explicit mesh tessellation, enabling efficient, noise-free rendering and boolean composition [S1, unofficial][S5][S9, unofficial]. Unlike [Distance to Natural Quadrics](1559-distance-to-natural-quadrics.md) which focuses on algebraic quadric surfaces, SDF primitives provide exact distance bounds for a wide variety of canonical shapes (spheres, boxes, tori) and their combinations, guaranteeing that ray marching steps do not overshoot surfaces [S8, S15, unofficial].

## How it works
**Inputs and Outputs**: The function takes a 3D query point $p = (p_x, p_y, p_z)$ and primitive-specific parameters (e.g., radius $r$, center $c$, half-extents $b$). It returns a scalar float $d = \text{SDF}(p)$.

**Data Structures**:
*   **Point**: A 3D vector $p$.
*   **Primitive Parameters**:
    *   Sphere: `struct sph { float r; vec3 c; }` [S14, unofficial]
    *   Box: `struct box { vec3 p; vec3 size; }` where `size` is full size, divided by 2 in calculation [S14, unofficial].
    *   Cylinder: `struct cylinder { vec2 p; float r; }` (center in XZ plane) [S14, unofficial].
    *   Cylinder Capped: `struct cylinderCapped { float r; float h; }` (half-height) [S14, unofficial].
    *   Cone: `struct cone { float r; float h; vec3 c; }` [S14, unofficial].
    *   Plane: `struct plane { vec4 k; }` where `k.xyz` is normal and `k.w` is offset [S14, unofficial].
    *   Torus: `struct tor { float inR; float outR; }` [S14, unofficial].
    *   Generalized Distance Function (GDF): Array of 19 normalized `vec3` directions `GDFVectors[19]` [S6, S13, unofficial].

**Numbered Steps**:
1.  **Coordinate Transformation**: If the primitive is transformed (rotated, translated, scaled), apply the inverse transformation matrix $M^{-1}$ to the query point $p$ before evaluation: $p' = M^{-1} p$ [S11, unofficial]. For non-uniform scaling, distance compensation is required [S14, unofficial].
2.  **Distance Evaluation**: Compute the signed distance $d$ using the specific analytical formula for the primitive type.
3.  **Sign Convention**: The result $d$ follows the convention: $d < 0$ inside, $d = 0$ on surface, $d > 0$ outside [S2, S15, unofficial].
4.  **Normal Approximation**: Compute the surface normal $n$ using central finite differences with step size $\epsilon$ (typically $0.0001$) [S11, S13, unofficial]:
    $$ n = \text{normalize}\left( \begin{bmatrix} \text{SDF}(p + (\epsilon, 0, 0)) - d \\ \text{SDF}(p + (0, \epsilon, 0)) - d \\ \text{SDF}(p + (0, 0, \epsilon)) - d \end{bmatrix} \right) $$

**Formulas**:
*   **Sphere**: $d(p) = \|p - c\| - r$ [S11, S14, unofficial].
*   **Box (Exact)**: Let $d = |p - p_{box}| - b$ where $b$ is half-extents. Then $d_{box} = \|\max(d, 0)\| + \min(\max(d_x, \max(d_y, d_z)), 0)$ [S14, unofficial].
    *   *Cheap Box (Overestimate)*: $d_{cheap} = \max(|p| - b)$ [S6, unofficial].
*   **Cylinder (Infinite)**: $d(p) = \|(p_{xz} - p_{center})\| - r$ [S14, unofficial].
*   **Cylinder (Capped)**: Let $d_x = \|p_{xz}\| - r$ and $d_y = |p_y| - h$. Then $d = \min(\max(d_x, d_y), 0) + \|\max(d, 0)\|$ [S14, unofficial].
*   **Cone**: Let $\phi = \arctan(r/h)$. $d = \max(\sqrt{x^2+z^2}\cos(\phi) - |y|\sin(\phi), \max(y-h, -y))$ [S14, unofficial].
*   **Plane**: $d(p) = p \cdot n + d_{offset}$ [S14, unofficial].
*   **Torus**: $d = \|(\|p_{xz}\| - R_{out}, p_y)\| - R_{in}$ [S14, unofficial].
*   **L-Norm Torus (Tor88)**: Uses $L_8$ norm for rounded corners. $q = (\|p_{xz}\|_8 - R_{out}, p_y)$, result is $\|q\|_8 - R_{in}$ [S14, unofficial].
*   **Generalized Distance Function (GDF)**: Uses pre-normalized vectors $v_i$.
    *   With exponent $e$: $d = (\sum_{i=begin}^{end} |\text{dot}(p, v_i)|^e)^{1/e} - r$ [S13, unofficial].
    *   Sharp edges ($e \to \infty$): $d = \max_{i} |\text{dot}(p, v_i)| - r$ [S6, unofficial].

**Pseudocode**:
```python
def sdf_sphere(p: vec3, center: vec3, radius: float) -> float:
    return length(p - center) - radius

def sdf_box(p: vec3, center: vec3, half_extents: vec3) -> float:
    d = abs(p - center) - half_extents
    # Exact distance including corners
    return length(max(d, vec3(0))) + min(max(d.x, max(d.y, d.z)), 0)

def sdf_torus(p: vec3, large_radius: float, small_radius: float) -> float:
    q = vec2(length(p.xz) - large_radius, p.y)
    return length(q) - small_radius

def sdf_plane(p: vec3, normal: vec3, offset: float) -> float:
    return dot(p, normal) + offset

def sdf_capsule(p: vec3, a: vec3, b: vec3, radius: float) -> float:
    ab = b - a
    t = clamp(dot(p - a, ab) / dot(ab, ab), 0.0, 1.0)
    return length((ab * t + a) - p) - radius

def sdf_cone(p: vec3, radius: float, height: float) -> float:
    q = vec2(length(p.xz), p.y)
    tip = q - vec2(0, height)
    mantle_dir = normalize(vec2(height, radius))
    mantle = dot(tip, mantle_dir)
    d = max(mantle, -q.y)
    projected = dot(tip, vec2(mantle_dir.y, -mantle_dir.x))
    
    # Distance to tip
    if (q.y > height) and (projected < 0):
        d = max(d, length(tip))
    
    # Distance to base ring
    if (q.x > radius) and (projected > length(vec2(height, radius))):
        d = max(d, length(q - vec2(radius, 0)))
        
    return d

def sdf_gdf(p: vec3, radius: float, vectors: list[vec3], begin: int, end: int, exponent: float = 1e9) -> float:
    d = 0.0
    for i in range(begin, end + 1):
        val = abs(dot(p, vectors[i]))
        if exponent < 1e8:
            d += pow(val, exponent)
        else:
            d = max(d, val)
    if exponent < 1e8:
        return pow(d, 1.0 / exponent) - radius
    return d - radius
```

**Parameters**:
*   $\epsilon$ (gradient step): $0.0001$ [S11, unofficial].
*   Torus major radius $s$: $70$ (example) [S4, unofficial].
*   Torus minor radius $t$: $15$ (example) [S4, unofficial].
*   Round Box half-size $b$: $\text{vec3}(20, 20, 5)$ (example) [S4, unofficial].
*   Round Box radius $r$: $10$ (example) [S4, unofficial].
*   GDF PHI constant: $\sqrt{5} \cdot 0.5 + 0.5$ [S13, unofficial].

**Edge Cases and Pitfalls**:
*   **Non-Uniform Scaling**: Standard inverse transformation does not preserve Euclidean distance; explicit scaling factors or distance compensation are required [S14, unofficial].
*   **Discontinuities**: Taking `min()` or `max()` of two SDFs yields sharp discontinuities in the derivative, affecting normal quality [S11, unofficial].
*   **GDF Performance**: Loops in GDF implementations (e.g., for Icosahedrons) may fail to unroll on certain drivers (e.g., Nvidia 350.12), causing slowdowns [S13, unofficial].
*   **Approximation Errors**: The `fBlob` function is not a correct distance bound [S6, unofficial]. Variable exponent GDFs are slow and may not produce correct distances, allowing for bulging [S13, unofficial].
*   **Arbitrary Meshes**: Not every shape has a closed-form SDF; arbitrary meshes require approximate SDFs (baked into 3D textures or generated from BVH traversal) [S15, unofficial].

## Subtopics

### [SDF Primitives & Operations](1075-sdf-primitives-operations.md)
Provides foundational analytical functions and geometric operators (union, intersection, difference, smooth blending) for composing scene geometry. It focuses on base primitives and immediate min/max operators, distinct from coordinate transformation or complex CSG.

### [SDF Transformation](1086-sdf-transformation.md)
Applies geometric transformations (rotation, translation, scaling, deformation) by manipulating query point coordinates before evaluation. It preserves mathematical integrity for ray marching, relying on inverse mapping for isometries or explicit factors for scaling.

### [k-SDF](9530-k-sdf.md)
A representation for real-time view synthesis of fuzzy geometries using $k$ lightweight, semi-transparent mesh shells. It models implicit geometry as $k$ distinct SDFs combined with view-dependent transparency, bounding samples per ray for real-time performance on low-cost hardware.

### [SDF Representation DOP](12996-sdf-representation-dop.md)
Creates a volumetric SDF from geometry for fast inside/outside testing in collision detection. It focuses on topological correctness for rigid body dynamics, using modes like Laser Scanning for non-watertight geometry.

### SDF Grid Modeling
A float grid where active values describe the distance to a surface, with negative values inside and positive outside, and the surface at zero [S16, unofficial]. It allows for efficient boolean operations with smooth transitions, which are difficult on meshes, and supports smoothing via nodes like the SDF Grid Mean [S16, unofficial].

## Operating characteristics
*   **Time Complexity**: $O(1)$ per primitive evaluation. Total time depends on the number of primitives and ray marching steps.
*   **Memory Complexity**: $O(1)$ for analytical primitives. $O(N)$ for grid-based SDFs [S10, S16, unofficial].
*   **Performance**: Significantly faster than ray-triangle intersection for complex scenes due to adaptive stepping [S1, unofficial]. Accuracy improves with exact distance bounds [S1, unofficial].
*   **Strengths**: No tessellation artifacts, easy boolean composition, smooth normals via finite differences, compact representation [S1, S9, unofficial].
*   **Limitations**: No closed-form SDF for arbitrary meshes [S15, unofficial]. Sharp edges from boolean ops can cause normal artifacts [S11, unofficial]. Non-uniform scaling requires compensation [S14, unofficial].
*   **When to Use**: Real-time rendering, procedural geometry, ray marching.
*   **When Not to Use**: When exact mesh topology is required for collision or when non-uniform scaling is prevalent without compensation.

## Background
The Signed Distance Function was introduced as an implicit function for representing real surfaces, where the zero level set defines the surface [S2, unofficial][S5]. It is widely used in ray marching for real-time graphics, replacing explicit mesh tessellation with continuous scalar fields [S1, S9, unofficial]. The method relies on the Lipschitz bound to ensure safe ray stepping [S15, unofficial]. It is used in neural rendering for clearer geometry compared to density fields [S5], and in volume rendering for collision detection and topological analysis [S10, S16, unofficial].
