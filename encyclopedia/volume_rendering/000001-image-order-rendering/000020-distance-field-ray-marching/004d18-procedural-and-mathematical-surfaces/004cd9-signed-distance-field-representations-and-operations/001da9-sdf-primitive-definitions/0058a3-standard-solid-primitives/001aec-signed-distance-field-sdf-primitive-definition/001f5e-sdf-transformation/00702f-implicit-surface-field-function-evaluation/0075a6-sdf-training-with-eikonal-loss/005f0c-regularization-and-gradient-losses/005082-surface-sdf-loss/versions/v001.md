# Surface SDF Loss

Also called: Track-SDF Regularizer

## Overview
The Surface SDF Loss (also known as the Track-SDF Regularizer) is a training objective for Directional Distance Field (DDF) networks that enforces geometric consistency with a co-trained Signed Distance Field (SDF) network [S2]. It solves the problem where predicted directional distances and signed distances may disagree by constraining points reconstructed via the DDF to lie on the zero-level set of the SDF [S2]. Unlike the Eikonal loss which enforces unit gradient magnitude, this loss explicitly links the two representations by minimizing the SDF value at DDF-reconstructed points [S2].

## How it works
**Inputs and Outputs:**
*   **Inputs:**
    *   $f_s(\cdot)$: The SDF network function.
    *   $(p, r)$: Point-direction tuples where $p$ is a 3D point and $r$ is a direction vector pointing toward the object surface.
    *   $d$: The predicted directional distance scalar for the tuple $(p, r)$ from the DDF network.
*   **Outputs:**
    *   $\mathcal{L}_{ts}$: The scalar loss value.

**Data Structures:**
*   **Point-Direction Tuples:** A list or batch of pairs $(p, r)$. $p \in \mathbb{R}^3$, $r \in \mathbb{R}^3$ (normalized).
*   **DDF Prediction:** A scalar $d$ per tuple, representing the distance along $r$ from $p$ to the surface.

**Steps:**
1.  **Reconstruct Surface Points:** For each point-direction tuple $(p, r)$ with predicted directional distance $d$, compute the reconstructed 3D point $x$ using the formula:
    $$x = p + d \cdot r$$
    This point $x$ is the DDF's prediction of where the surface lies along ray $r$ starting at $p$.
2.  **Evaluate SDF:** Evaluate the SDF network $f_s$ at the reconstructed point $x$ to obtain the signed distance value:
    $$v = f_s(x) = f_s(p + d \cdot r)$$
3.  **Compute Loss:** Calculate the L1 norm of the SDF value. The loss is the mean of these absolute values over the batch:
    $$\mathcal{L}_{ts}(d) = \|f_s(p + d \cdot r)\|_1$$
    In practice, for a batch of $N$ tuples, this is:
    $$\mathcal{L}_{ts} = \frac{1}{N} \sum_{i=1}^{N} |f_s(p_i + d_i \cdot r_i)|$$

**Parameters:**
*   **Weight:** The sources do not specify a default weight for this loss term in the context of the total loss function. [S2]
*   **Point-Direction Selection:** The tuples $(p, r)$ must be those that "point to the object surface" [S2]. The exact method for selecting these tuples (e.g., via ray marching or sampling) is not detailed in the provided notes, but they are assumed to be provided as input to the loss computation [S2].

**Pitfalls:**
*   **Model Scope:** This loss is applied **only** to the DDF model. The SDF model is **not** updated using this loss [S2]. Attempting to backpropagate through $f_s$ to update the SDF weights is incorrect.
*   **Zero-Level Set Ambiguity:** If the DDF prediction $d$ is significantly inaccurate, $x$ may lie far from the surface, where $f_s(x)$ might be large or noisy, potentially leading to unstable gradients.
*   **Direction Validity:** The direction $r$ must genuinely point toward the surface. If $r$ points away from the surface, $p + d \cdot r$ may not correspond to the nearest surface intersection, violating the assumption that the point should be near the zero-level set.

**Pseudocode:**
```python
def surface_sdf_loss(sdf_network, ddf_directional_distances, points, directions):
    """
    Computes the Track-SDF Regularizer loss.
    
    Args:
        sdf_network: The SDF neural network function f_s.
        ddf_directional_distances: Tensor of shape (N,) containing predicted distances d.
        points: Tensor of shape (N, 3) containing points p.
        directions: Tensor of shape (N, 3) containing direction vectors r.
        
    Returns:
        Scalar loss value.
    """
    # Step 1: Reconstruct points using DDF predictions
    # x = p + d * r
    reconstructed_points = points + (ddf_directional_distances.unsqueeze(1) * directions)
    
    # Step 2: Evaluate SDF at reconstructed points
    # v = f_s(x)
    sdf_values = sdf_network(reconstructed_points)
    
    # Step 3: Compute L1 norm of SDF values
    # L_ts = mean(|v|)
    loss = torch.mean(torch.abs(sdf_values))
    
    return loss
```

## Operating characteristics
*   **Time Complexity:** $O(N)$, where $N$ is the number of point-direction tuples. Requires one forward pass through the SDF network for each tuple.
*   **Memory Complexity:** $O(N)$ to store the reconstructed points and intermediate SDF values.
*   **Strengths:** Directly enforces consistency between two different distance representations (SDF and DDF), improving geometric accuracy.
*   **Limitations:** Only regularizes the DDF; does not directly improve the SDF. Relies on the quality of the point-direction tuples.
*   **When to Use:** When training a DDF network alongside an SDF network and geometric consistency between them is desired.
*   **When Not to Use:** When only an SDF is being trained, or when the DDF and SDF are not intended to represent the same surface geometry consistently.

## Background
The Surface SDF Loss, referred to as the "Track-SDF Regularizer," was introduced in the context of the FIRe (Fast Inverse Rendering Using Directional and Signed Distance Functions) framework [S2]. It addresses the need for the predicted directional distance and signed distance to agree, ensuring that points derived from the DDF model lie close to the surface predicted by the SDF model [S2].
