# Curve-based Volumetric Free-Form Deformation

Also called: Volumetric Free-Form Deformation

## Overview
Curve-based Volumetric Free-Form Deformation (VFFD) is a technique for manipulating the macro shape and flow of a volumetric unit volume (specifically procedural fire) using an open uniform B-spline curve [S1][S2, unofficial]. It solves the problem of real-time macro-level interactivity and deformation by constructing a lattice of curves around a central spline, allowing flexible shape manipulation while maintaining texture coordinates for rendering [S1]. Unlike direct deformation methods that require solving inverse parameterization on the GPU, VFFD constructs a world-space lattice associated with texture coordinates, which the graphics hardware implicitly evaluates via texture coordinate interpolation [S1][S2, unofficial].

## How it works
**Inputs:**
- Control points $P_i$ for the center spline, where $i = 0 \dots n-1$ and $n$ is the number of control points [S1][S2, unofficial].
- Fire radius $r$, defining the cross-section size [S1][S2, unofficial].
- Lattice resolution $c$, determining the number of samples along the curve [S1][S2, unofficial].
- B-spline degree $p$ [S1][S2, unofficial].

**Outputs:**
- A lattice in world space consisting of $c$ sections, where each section is defined by four corner curves [S1][S2, unofficial].
- Texture coordinates assigned to lattice vertices to map back to the unit fire volume [S1][S2, unofficial].

**Data Structures:**
- **Control Points:** Array of 3D vectors $P_i$ [S1][S2, unofficial].
- **Knot Vector:** Values $t_i$ defining the B-spline domain [S1][S2, unofficial].
- **Corner Curves:** Four sets of control points defining the cross-section at each lattice section [S1][S2, unofficial].
- **Lattice Vertices:** Points in world space with associated texture coordinates $(x, y, z)$ [S1][S2, unofficial].

**Formulas:**
The center curve $C(t)$ is defined by the open uniform B-spline:
$$ C(t) = \sum_{i=0}^{n-1} N_{i, \text{degree}}(t) \cdot P_i \quad (6) $$
where $N_{i,p}(t)$ is the B-spline basis function of degree $p$ [S1][S2, unofficial].

The knot values $t_i$ for an open uniform B-spline are defined as [S1][S2, unofficial]:
$$ t_i = \begin{cases} 0 & \text{if } i \leq \text{degree} \\ i - \text{degree} & \text{if } \text{degree} < i < n \\ n - \text{degree} & \text{otherwise} \end{cases} \quad (3) $$

The basis functions are computed recursively [S1][S2, unofficial]:
$$ N_{i,0}(t) = \begin{cases} 1 & \text{if } t_i \leq t < t_{i+1} \\ 0 & \text{otherwise} \end{cases} \quad (4) $$
$$ N_{i,p}(t) = \frac{t_{i+p+1} - t}{t_{i+p} - t_i} N_{i,p-1}(t) + \frac{t - t_i}{t_{i+p+1} - t_{i+1}} N_{i+1,p-1}(t) \quad (5) $$

**Steps:**
1.  **Sample Center Curve Properties:** For each control point $P_i$, determine the parameter $t$ at which that control point has the most influence. For a uniform B-spline, this is $t = \frac{i}{n-1}$ for $i = 0 \dots n-1$ [S1][S2, unofficial].
2.  **Compute Normal and Velocity:** At each sampled $t$, compute the velocity vector $\vec{V}_i$ (tangent) and normal vector $\vec{N}_i$ of the center curve $C(t)$ [S1][S2, unofficial].
3.  **Define Cross-Section Plane:** For each control point $P_i$, define a square in the plane defined by $P_i$ and $\vec{V}_i$, centered at $P_i$ [S1][S2, unofficial].
4.  **Set Cross-Section Size:** The edge length of the square is $2r$, where $r$ is the fire radius [S1][S2, unofficial].
5.  **Align Squares:** Align all $n$ squares along their respective central curve normals $\vec{N}_i$ to reduce twisting [S1][S2, unofficial].
6.  **Generate Corner Curves:** Generate four additional curves by placing control points on the corners of these squares [S1][S2, unofficial].
7.  **Sample Lattice Sections:** Sample the center curve parameter $t$ uniformly $c$ times (where $c$ is the lattice resolution) to obtain $c$ values of $t$ in the domain $[0, 1]$ [S1][S2, unofficial].
8.  **Evaluate Corner Positions:** For each of the $c$ sampled $t$ values, evaluate the four corner curves using Equation (6) to obtain $c$ sets of correlated positions on the four corner curves [S1][S2, unofficial].
9.  **Assign Texture Coordinates:** Assign each lattice vertex a texture coordinate $\text{tex}_i = (x, \frac{i}{c-1}, z)$, where $x$ and $z$ are $1$ or $-1$ depending on which corner curve the vertex belongs to, and $i$ is the index of the lattice section ($0 \dots c-1$) [S1][S2, unofficial].
10. **Render Lattice:** Divide the lattice into a finite set of cubes and render only the required triangles within these cubes to minimize pixel shader coverage and ensure every section is rendered [S2, unofficial].

**Pseudocode:**
```python
def compute_b_spline_basis(t, knots, degree):
    """
    Computes the B-spline basis functions N_{i,p}(t) for a given t.
    knots: list of knot values t_i
    degree: integer degree p
    Returns: list of basis function values N_{i, degree}(t)
    """
    n = len(knots) - degree - 1  # Number of control points
    # Initialize degree 0 basis functions
    N = [0.0] * n
    for i in range(n):
        if knots[i] <= t < knots[i+1]:
            N[i] = 1.0
        else:
            N[i] = 0.0
    # Compute higher degree basis functions
    for p in range(1, degree + 1):
        for i in range(n - p + 1):
            left_num = knots[i+p] - t
            left_den = knots[i+p] - knots[i]
            left = (left_num / left_den) * N[i] if left_den != 0 else 0.0
            right_num = t - knots[i]
            right_den = knots[i+p+1] - knots[i+1]
            right = (right_num / right_den) * N[i+1] if right_den != 0 else 0.0
            N[i] = left + right
    return N

def evaluate_b_spline(t, control_points, knots, degree):
    """Evaluates the B-spline curve C(t) at parameter t."""
    basis = compute_b_spline_basis(t, knots, degree)
    point = [0.0, 0.0, 0.0]
    for i, cp in enumerate(control_points):
        point[0] += basis[i] * cp[0]
        point[1] += basis[i] * cp[1]
        point[2] += basis[i] * cp[2]
    return point

def compute_tangent(t, control_points, knots, degree):
    """Computes the tangent vector C'(t) using a small finite difference [G]."""
    eps = 1e-6
    p1 = evaluate_b_spline(t - eps, control_points, knots, degree)
    p2 = evaluate_b_spline(t + eps, control_points, knots, degree)
    return normalize(p2 - p1)

def compute_normal(tangent, up_vector=(0.0, 1.0, 0.0)):
    """Computes a normal vector perpendicular to the tangent and a fixed up vector [G]."""
    return normalize(cross(tangent, up_vector))

def normalize(v):
    """Standard vector normalization [G]."""
    mag = (v[0]**2 + v[1]**2 + v[2]**2)**0.5
    if mag == 0: return [0.0, 0.0, 0.0]
    return [v[0]/mag, v[1]/mag, v[2]/mag]

def cross(a, b):
    """Standard 3D cross product [G]."""
    return [a[1]*b[2] - a[2]*b[1], a[2]*b[0] - a[0]*b[2], a[0]*b[1] - a[1]*b[0]]

def curve_based_vffd(control_points, radius, lattice_resolution, degree):
    """
    Constructs the VFFD lattice.
    control_points: list of 3D vectors P_i
    radius: float r
    lattice_resolution: int c
    degree: int p
    Returns: list of lattice sections, each section is a list of 4 corner points
    """
    n = len(control_points)
    
    # 1. Compute knot vector for open uniform B-spline
    knots = []
    for i in range(n + degree + 1):
        if i <= degree:
            knots.append(0.0)
        elif i < n:
            knots.append(i - degree)
        else:
            knots.append(n - degree)
            
    # 2. Sample center curve properties at t = i / (n-1)
    samples_t = [i / (n - 1) for i in range(n)]
    
    # 3. Compute normal and velocity for each sample
    normals = []
    velocities = []
    for t in samples_t:
        tangent = compute_tangent(t, control_points, knots, degree)
        normal = compute_normal(tangent)
        normals.append(normal)
        velocities.append(tangent)
        
    # 4. Define corner control points for each section
    corner_control_points = []
    for i in range(n):
        P = control_points[i]
        N = normals[i]
        V = velocities[i]
        V_norm = normalize(V)
        # Define the four corners of the square cross-section
        c1 = P + radius * N + radius * V_norm
        c2 = P - radius * N + radius * V_norm
        c3 = P - radius * N - radius * V_norm
        c4 = P + radius * N - radius * V_norm
        corner_control_points.append([c1, c2, c3, c4])
        
    # 5. Sample lattice sections
    lattice_t_values = [i / (lattice_resolution - 1) for i in range(lattice_resolution)]
    lattice_sections = []
    for idx, t in enumerate(lattice_t_values):
        section_corners = []
        for corner_idx in range(4):
            basis = compute_b_spline_basis(t, knots, degree)
            corner_point = [0.0, 0.0, 0.0]
            for i in range(n):
                cp = corner_control_points[i][corner_idx]
                corner_point[0] += basis[i] * cp[0]
                corner_point[1] += basis[i] * cp[1]
                corner_point[2] += basis[i] * cp[2]
            section_corners.append(corner_point)
        lattice_sections.append(section_corners)
        
    return lattice_sections
```

**Parameters:**
- $n$: Number of control points [S1][S2, unofficial].
- $r$: Radius of the fire, defining the cross-section size [S1][S2, unofficial].
- $c$: Resolution of the lattice, determining the number of samples along the curve [S1][S2, unofficial].
- $p$: Degree of the B-spline [S1][S2, unofficial].

**Edge Cases and Pitfalls:**
- **Inverse Parameterization:** The pixel shader operates on deformed world space $P'$ to return texture space $P$, but the deformation function $D(P)$ defines $P'$ from $P$ [S2, unofficial]. This cannot be solved analytically on the GPU [S2, unofficial]. The method avoids this by constructing a lattice in world space associated with texture coordinates, allowing the graphics hardware to implicitly evaluate the mapping $D(P)$ via texture coordinate interpolation [S1][S2, unofficial].
- **Pixel Coverage:** The shader can only render to locations occupied by triangle fragments, and the final pixel coverage is not known a priori [S2, unofficial]. The method solves this by dividing the lattice into a finite set of cubes and rendering only the required triangles within these cubes [S2, unofficial].
- **Discontinuities:** Linear interpolation on the lattice creates discontinuities in the first derivative of the curve on the borders of each lattice section [S2, unofficial]. Refining the lattice resolution approximates the continuous deformation to an arbitrary degree of accuracy [S2, unofficial].
- **Precision:** The knot vector construction and basis function evaluation must handle edge cases where denominators are zero (e.g., $t_{i+p} - t_i = 0$) [S1][S2, unofficial].

## Operating characteristics
- **Time Complexity:** Not given in the sources.
- **Memory Complexity:** Not given in the sources.
- **Performance:** The performance impact of additional lattice sections is relatively small, allowing over-estimation of resolution [S2, unofficial].
- **Strengths:** Real-time macro-level interactivity, flexible shape manipulation, avoids inverse parameterization on GPU [S1][S2, unofficial].
- **Limitations:** Discontinuities in the first derivative at lattice section borders, limited to deforming a fixed number of points without loss of detail (cannot deform the entire volume with noise in real time) [S1][S2, unofficial].
- **When to Use:** When real-time deformation of volumetric fire or similar volumes is required, and macro-level control is needed [S1][S2, unofficial].
- **When Not to Use:** Not given in the sources.

## Background
Curve-based Volumetric Free-Form Deformation was introduced by Alfred R. Fuller, Hari Krishnan, Karim Mahrous, Bernd Hamann, and Kenneth I. Joy from the University of California, Davis, in 2007 [S1][S2, unofficial]. It was developed as part of a system for generating procedural volumetric fire in real time, combining curve-based deformation with hardware-accelerated volumetric rendering and procedural noise [S1][S2, unofficial]. The method builds on earlier work in curve-based fire design and particle simulation [S1][S2, unofficial].
