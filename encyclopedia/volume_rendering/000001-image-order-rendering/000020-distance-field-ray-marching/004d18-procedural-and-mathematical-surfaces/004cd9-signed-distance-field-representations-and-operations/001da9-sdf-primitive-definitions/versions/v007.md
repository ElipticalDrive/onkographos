# SDF Primitive Definitions

Also called: Analytical SDFs, Base Primitives, Canonical Shapes

## Overview
SDF Primitive Definitions provide closed-form analytical functions for canonical 3D shapes (spheres, boxes, tori, planes) that serve as the foundational building blocks for procedural geometry in distance-field ray marching. They solve the problem of defining scene geometry without explicit mesh tessellation by providing conservative distance estimates that guarantee ray step sizes will not overshoot surfaces [S1]. Unlike [Constructive SDF Modeling (Min Combination)](871-constructive-sdf-modeling-min-combination.md) which combines primitives, this method focuses on the base analytical definitions of canonical shapes and their immediate geometric properties [G].

## Shared principles
The family operates on the principle that a scene is defined by a scalar field $f(\mathbf{p})$ where the zero-level set $f(\mathbf{p}) = 0$ represents the surface. For sphere tracing to be valid, the function must satisfy the Lipschitz condition with constant 1, ensuring $|f(\mathbf{p}_1) - f(\mathbf{p}_2)| \le \|\mathbf{p}_1 - \mathbf{p}_2\|$. This guarantees that the value $f(\mathbf{p})$ is a safe lower bound on the distance to the surface, allowing the ray marcher to step forward by exactly $f(\mathbf{p})$ without tunneling [S2, 9643, unofficial].

Composition is achieved through Boolean operations on the distance values:
*   **Union**: $f_{union}(\mathbf{p}) = \min(f_1(\mathbf{p}), f_2(\mathbf{p}))$ .
*   **Intersection**: $f_{intersect}(\mathbf{p}) = \max(f_1(\mathbf{p}), f_2(\mathbf{p}))$ .
*   **Subtraction**: $f_{sub}(\mathbf{p}) = \max(-f_1(\mathbf{p}), f_2(\mathbf{p}))$ .

Transformations are applied by mapping the query point $\mathbf{p}$ into the local coordinate space of the primitive using the inverse transformation matrix $M^{-1}$ before evaluation . Procedural noise (e.g., FBM) is often used to perturb these analytical surfaces, creating hypertextures where the isosurface is defined by $SDF(\mathbf{p}) + B_n(\mathbf{p}) = 0$ [S1].

## Subtopics

### [Constructive SDF Modeling (Min Combination)](871-constructive-sdf-modeling-min-combination.md)
Constructive SDF Modeling (Min Combination) computes the signed distance from a query point to the geometric union of multiple primitives by returning the minimum of their individual signed distance functions (SDFs). It solves the problem of representing complex scenes composed of many objects as a single continuous distance field, enabling efficient ray marching by ensuring the returned distance is a conservative lower bound to the nearest surface. What sets it apart from its siblings, such as [Smooth SDF Composition](2685-smooth-sdf-composition.md), is that it produces sharp, non-differentiable boundaries at intersections rather than smooth transitions, and it differs from [Boolean Operations on Distance Fields](1961-boolean-operations-on-distance-fields.md) by specifically implementing the union operation via the `min` operator, whereas intersection and difference require `max` or negation. See [Constructive SDF Modeling (Min Combination)](871-constructive-sdf-modeling-min-combination.md).

### [Pyroclastic Sphere Primitive](1579-pyroclastic-sphere-primitive.md)
The Pyroclastic Sphere Primitive is a procedural signed distance field (SDF) primitive that displaces a base sphere's surface using procedural noise to create organic, turbulent shapes with overhangs. It distinguishes itself from static SDF primitives by combining a low-frequency sinusoidal "breathing" modulation with high-frequency fractal Brownian motion (fBM) and sinusoidal products to generate complex surface topology. Unlike standard sphere primitives, it supports 2D displacement to prevent density disconnection, making it suitable for volumetric effects like smoke or lava. See [Pyroclastic Sphere Primitive](1579-pyroclastic-sphere-primitive.md).

### [Offset Surface Evaluation](1782-offset-surface-evaluation.md)
Offset Surface Evaluation computes the signed distance from a query point to a surface generated by offsetting a base "skeleton" geometry by a fixed distance. It solves the problem of defining smooth, thickened representations of curves, surfaces, or meshes for use in implicit modeling and ray marching. It is distinguished from its siblings by its reliance on a global point-to-set distance search (global offset) rather than a local parametric displacement, which avoids the interior self-intersections and high-degree algebraic artifacts common in local offset methods. See [Offset Surface Evaluation](1782-offset-surface-evaluation.md).

### [Boolean Operations on Distance Fields](1961-boolean-operations-on-distance-fields.md)
Boolean operations on Signed Distance Fields (SDFs) are Constructive Solid Geometry (CSG) primitives that combine two or more base SDFs to create complex shapes by performing set-theoretic unions, intersections, and differences. Unlike standard geometric primitives, these operations allow the construction of arbitrary topology from simple building blocks without requiring mesh generation. The method is distinguished by its reliance on component-wise minimum and maximum functions to preserve the distance field property, ensuring that the resulting function remains a valid distance field for ray marching. See [Boolean Operations on Distance Fields](1961-boolean-operations-on-distance-fields.md).

### [Standard Solid Primitives](16223-standard-solid-primitives.md)
Standard Solid Primitives are closed-form analytical Signed Distance Functions (SDFs) for canonical 3D shapes, serving as the foundational building blocks for procedural geometry in distance-field ray marching. They solve the problem of defining scene geometry without explicit mesh tessellation by providing conservative distance estimates that guarantee ray step sizes will not overshoot surfaces. Unlike [Constructive SDF Modeling (Min Combination)](871-constructive-sdf-modeling-min-combination.md) which combines primitives, this method focuses on the base analytical definitions of canonical shapes (spheres, boxes, tori, etc.) and their immediate geometric properties [G]. See [Standard Solid Primitives](16223-standard-solid-primitives.md).

### Implicit Surface Representation
#### definition
Representation of an implicit surface as a grid-based Signed Distance Function (SDF) using tricubic interpolation to ensure continuous surface normals [S1].
#### usage
Used in the implementation based on the cuda_ad_rgb backend of Mitsuba 3 [S1].

### SDF Bounding Box Clipping
#### definition
A technique to restrict a signed distance field (SDF) to a specific bounding box by intersecting the object's SDF with a box SDF, avoiding artifacts caused by clamping coordinates [S2, unofficial].
#### step
Compute the object's local SDF value (`d_pt`) using the modulo-repeated coordinate pattern. Calculate the bounding box extents and center: `bb_extents = (bounding_box_max - bounding_box_min) * 0.5` and `bb_center = bounding_box_min + bb_extents`. Compute the distance from the point to the box surface: `bb_p = max(abs(p - bb_center) - bb_extents, 0.)`. Compute the box SDF as the maximum component of `bb_p`: `d_bb = max(max(bb_p.x, bb_p.y), bb_p.z)`. Return the maximum of the object SDF and the box SDF to intersect them: `return max(d_pt, d_bb)` [S2, unofficial].
#### pitfall
Clamping coordinates (e.g., `clamp(p.xyz, min, max)`) before computing the SDF results in the SDF returning a constant distance very close to the surface, causing raymarching to run out of iterations and produce stretched artifacts [S2, unofficial].

### SDF Scene Graph API
#### definition
A fluent API for defining 3D scenes using Signed Distance Field (SDF) primitives, boolean/smooth operators, and transformations, tagged with hatch directions [S3, unofficial].
#### step
Create primitives: `SdfNode.sphere(center, radius)`, `SdfNode.box_(size)`, `SdfNode.torus(major_radius, minor_radius)`, `SdfNode.plane_y(y_value)`. Apply transformations: `.displace(freq, amp)`, `.round(radius)`, `.rotate_x/y/z(angle)`, `.translate((x, y, z))`, `.repeat_xz()`. Combine nodes: `.smooth_union(other_node, k)`, `.smooth_subtract(other_node, k)`, `.union(other_node)`, `.intersect(other_node)`, `.subtract(other_node)`, where `k` is the blending radius for smooth variants. Set hatch direction: `.hatch_dir(x, y, z)` sets the 3D tangent vector that strokes follow on that subtree's surface [S3, unofficial].

## Background
The concept of using analytical distance functions for ray marching was popularized by Inigo Quilez in his online tutorials, establishing the standard definitions for primitives like spheres, boxes, and tori . The use of these primitives as building blocks for Constructive Solid Geometry (CSG) via min/max operators is a standard technique in procedural modeling . More recent developments include the integration of SDFs into differentiable rendering pipelines, such as in Mitsuba 3, where grid-based SDFs with interpolation are used for inverse rendering [S1]. Fluent APIs for scene definition, such as HatchForge, have also emerged to simplify the composition of these primitives [S3, unofficial].
