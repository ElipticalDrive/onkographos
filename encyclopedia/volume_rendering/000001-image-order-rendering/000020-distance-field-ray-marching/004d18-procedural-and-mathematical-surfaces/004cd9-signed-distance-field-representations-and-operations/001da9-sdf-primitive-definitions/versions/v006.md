# SDF Primitive Definitions

Also called: Analytical SDF Primitives, Canonical SDF Shapes

## Overview
SDF Primitive Definitions provide analytical scalar functions $f(\mathbf{p})$ that return the exact Euclidean distance from a query point $\mathbf{p}$ to the nearest surface of a canonical geometric shape [S2, S3, unofficial]. This method replaces explicit mesh tessellation with continuous algebraic solutions, enabling efficient distance-field ray marching (sphere tracing) by providing a safe lower bound on the distance to the surface [S1, unofficial]. Unlike [Constructive SDF Modeling](871-constructive-sdf-modeling-min-combination.md), which focuses on composition, this method defines the base primitives themselves [G].

## How it works
**Inputs and Outputs:**
*   **Input:** A 3D query point $\mathbf{p} \in \mathbb{R}^3$ and primitive-specific parameters (e.g., radius, height, position).
*   **Output:** A scalar value $d \in \mathbb{R}$ representing the signed distance. Positive values denote points outside the object, negative values denote points inside, and zero defines the surface boundary [S2, unofficial].

**Data Structures:**
No persistent data structures are required for the evaluation of a single primitive. The function is stateless and pure.

**Steps:**
1.  **Transform Point:** If the primitive is not at the origin or has a non-unit scale, map the query point $\mathbf{p}$ into the primitive's local coordinate space using the inverse transformation matrix $M^{-1}$ . Let the transformed point be $\mathbf{p}_{local}$.
2.  **Evaluate Canonical Distance:** Compute the distance $d_{local}$ from $\mathbf{p}_{local}$ to the canonical shape centered at the origin. The specific formula depends on the primitive type (see Subtopics).
3.  **Return Result:** Return $d_{local}$.

**Formulas:**
The general form for a transformed primitive is:
$$ f(\mathbf{p}) = f_{canonical}(M^{-1} \mathbf{p}) $$
where $f_{canonical}$ is the analytical distance function for the untransformed primitive .

**Parameters:**
*   **Radius ($r$):** For spheres and cylinders. Typical values depend on scene scale.
*   **Height ($h$):** For cylinders and cones.
*   **Bounding Box Min/Max:** For box intersections [S1, unofficial].

**Edge Cases and Pitfalls:**
*   **Clamping Artifacts:** Clamping coordinates (e.g., `clamp(p.xyz, min, max)`) before computing the SDF results in the SDF returning a constant distance very close to the surface, causing raymarching to run out of iterations and produce stretched artifacts [S1, unofficial]. Instead, intersect the object's SDF with a box SDF to restrict the field [S1, unofficial].
*   **Precision:** Standard floating-point precision is sufficient for most primitives, but finite difference normal calculation requires a small step size $h$ (e.g., 0.001) [S3, unofficial].

**Pseudocode:**
```python
def evaluate_sdf_primitive(p: vec3, primitive_type: str, params: dict) -> float:
    """
    Evaluates the signed distance for a canonical primitive.
    params: dict containing 'radius', 'height', 'position', etc.
    """
    # 1. Transform point to local space (simplified for origin-aligned primitives)
    # In a general implementation, p_local = inverse_transform * p
    p_local = p - params.get('position', vec3(0, 0, 0))
    
    if primitive_type == "sphere":
        r = params.get('radius', 1.0)
        return length(p_local) - r
        
    elif primitive_type == "box":
        # Box defined by extents from center
        extents = params.get('extents', vec3(1, 1, 1))
        # Distance to box surface
        d = max(abs(p_local) - extents, 0.0)
        return length(d) - min(max(d.x, max(d.y, d.z)), 0.0) # Simplified box SDF
        
    elif primitive_type == "cylinder":
        # Cap cylinder: axis along Y, height h, radius r
        r = params.get('radius', 1.0)
        h = params.get('height', 1.0)
        # Distance to outer cylinder surface
        # Using the formula from [S3, unofficial] adapted for generic cap cylinder
        # d = abs(vec2(length(p.yz), p.x)) - vec2(r, h) is for specific orientation
        # General cap cylinder along Y:
        dist_to_axis = length(p_local.xz)
        dy = abs(p_local.y) - h
        dx = dist_to_axis - r
        if dy > 0 and dx > 0:
            return length(vec2(dx, dy))
        elif dy > 0:
            return dy
        elif dx > 0:
            return dx
        else:
            return min(dy, dx)
            
    else:
        return 0.0 # Placeholder for other primitives
```

## Subtopics

### [Constructive SDF Modeling (Min Combination)](871-constructive-sdf-modeling-min-combination.md)
Constructive SDF Modeling (Min Combination) is a method for defining complex geometric scenes by combining primitive Signed Distance Functions (SDFs) using the minimum operator to represent the geometric union of volumes. It solves the problem of rendering multiple distinct objects as a single continuous scalar field, allowing a ray marcher to step forward by the distance to the nearest surface without tunneling. Unlike [Smooth SDF Composition](2685-smooth-sdf-composition.md), which blends primitives to create organic transitions, Min Combination produces sharp, non-differentiable boundaries at the intersection of objects, preserving the exact geometric union defined by Boolean logic.

### [Signed Distance Field (SDF) Primitive Definition](890-signed-distance-field-sdf-primitive-definition.md)
A Signed Distance Field (SDF) Primitive Definition is a method for representing 3D geometry using analytical scalar functions $f(\mathbf{p})$ that return the shortest Euclidean distance from a query point $\mathbf{p}$ to the nearest surface of a canonical shape. The sign of the result indicates spatial containment: positive values denote points outside the object, negative values denote points inside, and zero defines the surface boundary. This method replaces explicit mesh tessellation with continuous algebraic solutions, enabling efficient ray marching (sphere tracing) by providing a safe lower bound on the distance to the surface, which guarantees no tunneling occurs during step advancement. Unlike [Constructive SDF Modeling](871-constructive-sdf-modeling-min-combination.md) which focuses on composition, this method defines the base primitives themselves [G].

### [Distance to Natural Quadrics](1559-distance-to-natural-quadrics.md)
Distance to Natural Quadrics provides closed-form Signed Distance Functions (SDFs) for standard solid modeling primitives, including spheres, cylinders, cones, planes, and tori. These functions compute the exact Euclidean distance from a query point to the surface of the primitive, enabling efficient distance-field ray marching (sphere tracing). Unlike generic or approximate methods, these analytical solutions are computationally cheap and serve as the foundational building blocks for Constructive Solid Geometry (CSG) operations. They are distinct from [Superquadrics](1561-distance-to-superquadics.md) because they rely on the standard Euclidean $L_2$ norm rather than generalized $L_p$ norms, and from [Cylinder SDF](2739-cylinder-signed-distance-function.md) in that the natural quadric definitions often assume infinite extent or specific canonical orientations unless explicitly capped.

### [Pyroclastic Sphere Primitive](1579-pyroclastic-sphere-primitive.md)
The Pyroclastic Sphere Primitive is a procedural signed distance field (SDF) primitive that generates organic, cloud-like or volcanic shapes by perturbing a base sphere's distance function with procedural noise. It solves the problem of creating complex, non-convex volumetric structures with overhangs and disconnected density regions that cannot be achieved with simple analytical spheres. It distinguishes itself from standard SDF primitives by adding a noise displacement term to the distance value, and from pure noise volumes by maintaining a coherent spherical base shape.

### [Infinite Tiling with Modulo](1632-infinite-tiling-with-modulo.md)
Infinite Tiling with Modulo is a technique for rendering infinite, repeating patterns of a single Signed Distance Field (SDF) primitive by folding space using the modulo operator. It allows a single primitive SDF to be tiled infinitely at essentially zero extra computational cost, enabling the creation of ray-marched fractals like Mandelbulbs and Menger sponges. Unlike explicit mesh instances, it generates infinite geometry procedurally by mapping query points into a periodic local coordinate system.

### [Offset Surface Evaluation](1782-offset-surface-evaluation.md)
Offset Surface Evaluation computes the signed distance from a query point $\mathbf{p}$ to a surface generated by offsetting a base "skeleton" geometry $S$ by a fixed distance $c$. It solves the problem of defining smooth, thickened versions of curves, surfaces, or meshes for use in implicit modeling and ray tracing. It is distinguished from its siblings by its reliance on a global point-to-set distance search rather than simple parametric displacement or local Boolean combinations.

### [Boolean Operations on Distance Fields](1961-boolean-operations-on-distance-fields.md)
Boolean operations on Signed Distance Fields (SDFs) allow the construction of complex 3D geometry from simple primitives by combining their scalar distance values. This method solves the problem of representing Constructive Solid Geometry (CSG) in ray marching without explicit mesh topology, enabling the creation of arbitrary shapes through algebraic combination of distance functions. It is distinguished from explicit mesh CSG by operating directly on the continuous scalar field, ensuring the resulting function remains a valid distance field (satisfying the Lipschitz condition) for sphere tracing.

### Recursive Signed Distance Fields
A technique to compose recursive and fractal scenes by adding a loop to the signed distance function and applying a tiling operator on each iteration [S2, unofficial]. Recursive SDFs are costly and impact performance significantly, even with low recursion levels [S2, unofficial]. To mitigate this, recursive construction is often wrapped in bounding boxes, formed by adding a slightly larger version of the primitive distance field base [S2, unofficial].

### Cylindrical SDF Primitives
A technique for rendering implicit geometry defined by Signed Distance Functions (SDFs) using ray marching, specifically for a cap cylinder shape [S3, unofficial]. The distance is calculated using `d = abs(vec2f(length(p.yz), p.x)) - vec2(r, h); return min(max(d.x, d.y), 0.) + length(max(d, vec2f(0.)))` [S3, unofficial]. Normals are calculated using finite differences with $h=0.001$ and kernel $k=\text{vec2f}(1, -1)$ [S3, unofficial]. Typical parameters include `OUTER_RADIUS: 0.4255`, `INNER_RADIUS: 0.385`, and `LIGHT_POS: 0.035` [S3, unofficial].

### SDF Room with Planks
Computes the signed distance to a room shape composed of two bounding boxes (b1, b2) and a plank surface (b3). The plank surface is repeated periodically along the x-axis with a period of 8 units [S4, unofficial]. The modulo operation for periodic repetition uses integer division and subtraction instead of the `fmod` function for performance, taking 6.1s compared to 6.3s for the while-loop version [S4, unofficial]. The `Room` struct inherits from `Shape` and contains pointers to three `Shape` objects (b1, b2, b3) and a `Material` pointer `m` [S4, unofficial].

### Implicit Surface Representation
Representation of an implicit surface as a grid-based Signed Distance Function (SDF) using tricubic interpolation to ensure continuous surface normals [S5]. Used in the implementation based on the `cuda_ad_rgb` backend of Mitsuba 3 [S5].

## Operating characteristics
*   **Time Complexity:** $O(1)$ per primitive evaluation. Recursive or tiled variants increase complexity based on the number of iterations or depth [S2, S3, unofficial].
*   **Memory Complexity:** $O(1)$ for analytical primitives. Grid-based implicit representations require $O(N^3)$ memory for the grid [S5].
*   **Performance:** Analytical primitives are computationally cheap [S2, unofficial]. Recursive SDFs are costly and significantly impact performance [S2, unofficial].
*   **Strengths:** No mesh storage required; infinite resolution; easy composition via Boolean operations [S1, unofficial].
*   **Limitations:** Limited to shapes with known analytical distance functions; sharp edges in Min Combination are non-differentiable [S1, unofficial].

## Background
The use of analytical SDF primitives for ray marching was popularized by Inigo Quilez in his online tutorials [S1, S2, S3, unofficial][S5]. The concept of using distance fields for rendering dates back to earlier work on implicit surfaces, but the specific application to sphere tracing with analytical primitives is a cornerstone of modern real-time ray marching [S1, unofficial].
