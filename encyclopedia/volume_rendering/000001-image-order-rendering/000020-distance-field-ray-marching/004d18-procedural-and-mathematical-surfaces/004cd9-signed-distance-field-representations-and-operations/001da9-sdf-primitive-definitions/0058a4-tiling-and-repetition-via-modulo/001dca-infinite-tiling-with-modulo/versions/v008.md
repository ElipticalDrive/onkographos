# Infinite Tiling with Modulo

Also called: Infinite Crystal Grid SDF, Infinite Tiling via Modulo, Modulo SDF, Modulo Tiling, Repeat function, Tiling SDFs, Tiling via Modulo

## Overview
Infinite Tiling with Modulo is a technique for rendering infinite repeating patterns by using the modulo operator to fold space, allowing a single primitive SDF to be tiled infinitely [S1, S2, unofficial]. It sets itself apart from explicit mesh instances by computing the scene geometry implicitly at essentially zero extra cost per instance, enabling ray-marched fractal renderers like Mandelbulbs and Menger sponges [S3, unofficial].

## How it works
**Inputs and Outputs:**
*   Input: Ray position `p` (vec3), tile period/size `c` (float).
*   Output: Transformed position `q` (vec3) suitable for SDF evaluation.

**Data Structures:**
None required beyond standard vector types [G].

**Steps:**
1.  Apply the modulo operation to the sampling point `p` using the period `c`, adding an offset to center tiles at integer multiples of `c` [S1, S2, unofficial].
2.  Evaluate the base SDF using the transformed coordinate `q` [S2, unofficial].

**Formulas:**
The core transformation is defined as:
$$ q = \text{mod}\left(p + \frac{c}{2}, c\right) - \frac{c}{2} $$
Where:
*   $p$ is the world-space ray position.
*   $c$ is the period or size of the tile [S2, unofficial].
*   $\text{mod}(a, b)$ is the floating-point modulo operation [G].
*   $q$ is the folded coordinate.

**Parameters:**
*   `c` (Tile Size): The period of the modulo operation. Lower values make objects appear closer; higher values make them further apart [S2, unofficial].
*   Offset: Added before modulo to center the tile differently, e.g., `mod(p + 1.5, 3.0) - 1.5` for a period of `3.0` to center a tile at the origin [S1, unofficial].

**Pseudocode:**
```python
import math

def repeat(p: list, c: float) -> list:
    """
    Tiles space infinitely by folding the sampling point p using modulo.
    
    Args:
        p: The world-space position to tile [x, y, z].
        c: The period (size) of the tile.
        
    Returns:
        The folded position q [x, y, z].
    """
    # Fold space into [-c/2, c/2) centered at origin
    # Equivalent to mod(p + c/2, c) - c/2
    q = [(p[i] + c / 2.0) % c - c / 2.0 for i in range(3)]
    return q

def sdf_tiled(p: list, c: float, base_sdf_func) -> float:
    """
    Evaluates an SDF with infinite tiling.
    
    Args:
        p: World-space position [x, y, z].
        c: Tile period.
        base_sdf_func: Function that computes the SDF for a single tile centered at origin.
        
    Returns:
        Signed distance to the nearest tiled surface.
    """
    q = repeat(p, c)
    return base_sdf_func(q)
```

**Edge Cases and Pitfalls:**
*   **Negative Coordinates:** The standard repeat function works correctly for negative coordinates due to the properties of modulo and the centering shift [S2, unofficial]. However, some simplified explanations assume positive quadrants [S4, unofficial].

## Subtopics

### Finite Tiling
A variant of Infinite Tiling which produces a finite number of repetitions of a shape [S4, unofficial]. It takes an additional vector $\vec{l}$ as input, where $\vec{l}$ is the corner of the box used to limit the number of repetitions of the shape [S4, unofficial]. This allows for controlled tiling within a specific volume rather than infinite space [S4, unofficial].

## Operating characteristics
*   **Time Complexity:** $O(1)$ per ray step, as it adds only a few arithmetic operations (modulo, subtraction) before the base SDF evaluation, contributing essentially zero extra cost [S3, unofficial].
*   **Memory Complexity:** $O(1)$, no additional data structures are required [G].
*   **Performance:** Enables rendering of scenes with effectively infinite geometry at real-time frame rates, provided the base SDF is efficient [S3, unofficial].
*   **Strengths:** Ideal for fractals and procedural environments [S3, unofficial].
*   **Limitations:** All tiles are identical copies; cannot vary geometry per tile without additional logic (e.g., coordinate-dependent transformations) [G].

## Background
The technique is fundamental to ray marching with SDFs, popularized by demoscene artists and researchers like Inigo Quilez [S2, S3, unofficial]. It leverages the mathematical property of periodicity to create complex structures like Menger sponges and Mandelbulbs from simple primitives [S3, unofficial].
