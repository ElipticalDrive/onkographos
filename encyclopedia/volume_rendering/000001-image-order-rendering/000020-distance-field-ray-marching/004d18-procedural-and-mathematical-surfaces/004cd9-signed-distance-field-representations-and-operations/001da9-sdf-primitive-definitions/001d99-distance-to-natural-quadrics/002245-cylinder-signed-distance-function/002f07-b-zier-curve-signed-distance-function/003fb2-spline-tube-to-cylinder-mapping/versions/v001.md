# Spline Tube to Cylinder Mapping

Also called: Cylinder Mapping, Spline Tube Deformation, Spline tube deformation mapping

## Overview
Spline Tube to Cylinder Mapping is a technique for rendering procedural density fields inside deformed spline tubes by mapping points from the deformed space back to a canonical reference cylinder [S1, unofficial]. It solves the problem of applying isotropic procedural noise or density functions to arbitrarily bent or twisted volumes without storing or transforming the density field itself [S1, unofficial]. Unlike [Footvector Representation](8501-footvector-representation.md), which typically relies on local geometric properties for distance queries, this method explicitly constructs a coordinate transformation based on the Frenet frame to query a pre-defined cylinder density field [S1, unofficial].

## How it works
**Inputs:**
- A point $P$ in 3D space within the spline tube.
- A spline curve $C(t)$ defining the tube's axis.
- A reference cylinder defined as a vertical cylinder of radius 1 and height 1, with its lower base centered at the origin.

**Outputs:**
- Mapped coordinates $M$ in the reference cylinder, used to query the isotropic density field.

**Data Structures:**
- Spline curve $C(t)$: Defined by control points. For cubic splines, segments are cubic Bézier curves. For quadratic variants, segments are defined by three control points.
- Frenet Frame at point $O$: Consisting of the tangent vector $\vec{T}$, normal vector $\vec{N}$, and binormal vector $\vec{B}$.

**Steps:**
1. **Find Closest Point:** Find the point $O$ on the spline curve $C$ that is closest to the query point $P$. This involves solving for the parameter $t$ such that the distance $\|P - C(t)\|$ is minimized [S1, unofficial].
2. **Construct Frenet Frame:** Calculate the Frenet Frame at point $O$ using the Frenet–Serret formulas [S1, unofficial].
   - Tangent: $\vec{T} = \frac{C'(t)}{\|C'(t)\|}$
   - Normal: $\vec{N} = \frac{\vec{T}'}{\|\vec{T}'\|}$ (assuming $\vec{T}' \neq 0$)
   - Binormal: $\vec{B} = \vec{T} \times \vec{N}$
3. **Calculate Angle:** Compute the vector $\vec{OP} = P - O$. Calculate the angle $\alpha$ between $\vec{OP}$ and the Frenet normal vector $\vec{N}$ [S1, unofficial].
   - $\alpha = \arccos\left(\frac{\vec{OP} \cdot \vec{N}}{\|\vec{OP}\|}\right)$
   - Note: The sign of the angle relative to the binormal $\vec{B}$ determines the orientation in the cross-section. Specifically, the component along $\vec{B}$ is $\vec{OP} \cdot \vec{B}$.
4. **Calculate Curvilinear Abscissa:** Find the curvilinear abscissa $l$ of $O$, defined as the arc length of the spline curve from the beginning of the tube to $O$ [S1, unofficial].
5. **Calculate Mapped Coordinates:** Compute the mapped coordinates $M$ in the reference cylinder.
   - Let $r$ be the radius of the spline tube at point $O$.
   - Let $L_{total}$ be the total length of the spline curve.
   - The height in the cylinder is determined by the normalized position along the curve. The source provides two variants:
     - **No Stretching:** Height $h = l$.
     - **With Stretching:** Height $h = t = \frac{l}{L_{total}}$.
   - The radial distance in the cylinder is scaled by the tube radius: $r_{mapped} = \frac{\|\vec{OP}\|}{r}$.
   - The coordinates $M = (x, y, z)$ in the reference cylinder (radius 1, height 1) are:
     $$ M = \left( \cos(\alpha) \cdot \frac{\|\vec{OP}\|}{r}, \ h, \ \sin(\alpha) \cdot \frac{\|\vec{OP}\|}{r} \right) $$
     Where the $z$-component uses the sign from the binormal projection to preserve orientation [S1, unofficial].

**Pseudocode:**
```python
import math
import numpy as np

def get_frenet_frame(tangent, tangent_derivative):
    """
    Computes Normal and Binormal from Tangent and its derivative.
    """
    T = tangent / np.linalg.norm(tangent)
    T_prime = tangent_derivative / np.linalg.norm(tangent_derivative)
    N = T_prime - np.dot(T_prime, T) * T
    N = N / np.linalg.norm(N)
    B = np.cross(T, N)
    return T, N, B

def spline_tube_to_cylinder(P, spline_curve, radius_func, use_stretching=True):
    """
    Maps point P in spline tube to reference cylinder.
    
    Args:
        P: numpy array, point in 3D space.
        spline_curve: Object with methods get_point(t), get_tangent(t), 
                      get_tangent_derivative(t), get_arc_length(t), 
                      get_total_length(), and find_closest_t(P).
        radius_func: Function radius(t) returning tube radius at t.
        use_stretching: Boolean, if True, normalizes height by total length.
        
    Returns:
        M: numpy array, mapped coordinates in reference cylinder (radius 1, height 1).
    """
    # Step 1: Find closest point O on spline curve
    t_closest = spline_curve.find_closest_t(P)
    O = spline_curve.get_point(t_closest)
    
    # Step 2: Construct Frenet Frame at O
    tangent = spline_curve.get_tangent(t_closest)
    tangent_deriv = spline_curve.get_tangent_derivative(t_closest)
    T, N, B = get_frenet_frame(tangent, tangent_deriv)
    
    # Step 3: Calculate Angle alpha
    OP = P - O
    dist_OP = np.linalg.norm(OP)
    
    # Angle between OP and Normal N
    # We need to determine the signed angle in the N-B plane
    # proj_N = dot(OP, N)
    # proj_B = dot(OP, B)
    # alpha = atan2(proj_B, proj_N)
    
    proj_N = np.dot(OP, N)
    proj_B = np.dot(OP, B)
    alpha = math.atan2(proj_B, proj_N)
    
    # Step 4: Calculate Curvilinear Abscissa l
    l = spline_curve.get_arc_length(t_closest)
    L_total = spline_curve.get_total_length()
    
    # Step 5: Calculate Mapped Coordinates
    r = radius_func(t_closest)
    
    # Normalized radial distance
    r_mapped = dist_OP / r
    
    # Height in reference cylinder
    if use_stretching:
        h = l / L_total
    else:
        h = l
        
    # Reference cylinder has radius 1 and height 1.
    # The source defines M = (cos(a)*r_mapped, h, sin(a)*r_mapped)
    # Note: The source implies the cylinder axis is Z (or Y depending on convention).
    # Based on "vertical cylinder... lower base centered at origin", 
    # and formula components, we map to (x, y, z) where y is height.
    
    M = np.array([
        math.cos(alpha) * r_mapped,
        h,
        math.sin(alpha) * r_mapped
    ])
    
    return M
```

**Parameters:**
- **Reference Cylinder:** Vertical cylinder of radius 1 and height 1, lower base centered at origin [S1, unofficial].
- **Stretching:** Optional boolean. If true, the height coordinate is normalized by the total curve length, simulating expansion/contraction of the volume [S1, unofficial].

**Edge Cases and Pitfalls:**
- **Stretching Effect:** Making a longer spline tube without stretching does not stretch the volume; it appears as if a longer cylinder was bent. Stretching is required to simulate expansion [S1, unofficial].
- **SDF Derivation:** If the closest point $O$ is solvable, an SDF function can be derived, justifying the use of Sphere Marching for bounding box detection [S1, unofficial].
- **Varying Radius:** If the radius varies, the surface normal is no longer perpendicular to the curve axis, which breaks the standard SDF assumptions and can cause boundary detection bugs in sphere marching [S1, unofficial].

## Subtopics

### [Quadratic Bezier Tube Deformation](10138-quadratic-bezier-tube-deformation.md)
A deformation technique using quadratic Bezier curves instead of cubic splines. A segment is defined by three control points A, B, and C. It starts at A ($t=0$), ends at C ($t=1$), is tangent to $\vec{AB}$ at $t=0$ and $\vec{BC}$ at $t=1$ [10138-quadratic-bezier-tube-deformation.md]. It is chosen for its simplicity and ability to form smooth geometry via concatenation of segments.

### Varying Radius Spline Tube Mapping
The radius of the Bezier/spline curve is defined as a function of the curvilinear abscissa, allowing shapes like cones or DNA-like tubes [S1, unofficial]. This increases the complexity of the sphere marching algorithm because the varying radius makes the surface normal no longer perpendicular to the curve axis, which is problematic for the SDF function and can create bugs where boundaries are not detected properly [S1, unofficial].

### Twisting Spline Tube Mapping
Altering the angle $\alpha$ used for mapping to induce a twisting effect. The angle can depend on the curvilinear abscissa or time to create animations [S1, unofficial]. This is trivial to implement by modifying the angle calculation in the mapping step.

## Operating characteristics
- **Time Complexity:** Dominated by finding the closest point on the spline curve, which typically requires iterative numerical methods (e.g., Newton-Raphson) or subdivision. The Frenet frame calculation and mapping are $O(1)$ once the closest point is found.
- **Memory Complexity:** $O(1)$ auxiliary memory, as it does not store the density field or the deformed mesh. It only requires the spline control points and the procedural density function.
- **Strengths:** Allows for complex, animated, and procedurally generated volumes (e.g., solar flares, dust clouds) without heavy memory overhead or complex mesh transformations [S1, unofficial].
- **Limitations:** Varying radius features can break SDF-based sphere marching robustness [S1, unofficial]. The method assumes the spline curve is well-behaved (no sharp kinks that break Frenet frame continuity).

## Background
The method was introduced in the context of real-time rendering of interstellar dust clouds and solar flares [S1, unofficial]. It leverages the Frenet–Serret formulas, originally developed by Jean Frédéric Frenet (1847–1851) [S1, unofficial]. The technique allows artists to sculpt procedural noise by defining the axis of a volume with splines, while the internal density remains isotropic in the canonical space.
