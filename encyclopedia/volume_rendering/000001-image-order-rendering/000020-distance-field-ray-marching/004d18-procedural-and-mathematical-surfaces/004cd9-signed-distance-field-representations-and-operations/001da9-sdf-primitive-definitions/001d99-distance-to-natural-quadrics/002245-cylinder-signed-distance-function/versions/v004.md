# Cylinder Signed Distance Function

Also called: Capped Cylinder SDF, Cylinder SDF, Finite Cylinder SDF, Signed Capped Cylinder, Signed Cylinder, Signed Distance Function (SDF) for Cylinder, sdCappedCylinder, sdCylinder

## Overview
The Cylinder Signed Distance Function computes the exact Euclidean distance from a query point to the surface of a finite cylinder defined by two endpoints and a radius [S1, unofficial]. It solves the problem of ray marching against capped cylindrical primitives, which are common in scene geometry and constructive solid geometry (CSG) [G]. Unlike the infinite cylinder SDF, this method accounts for the end caps, returning the distance to the nearest point on the curved side, the top cap, or the bottom cap [S1, unofficial]. It is distinct from [Distance to Superquadrics](1561-distance-to-superquadrics.md) and [Torus Signed Distance Function](2864-torus-signed-distance-function.md) by its specific piecewise definition based on the projection onto the cylinder's axis [S1, unofficial][S4, unofficial].

## How it works
### Inputs and Outputs
- **Input**: A query point $v \in \mathbb{R}^3$, two endpoints $c_1, c_2 \in \mathbb{R}^3$ defining the cylinder axis, and a radius $r \in \mathbb{R}^+$ [S1, unofficial].
- **Output**: A scalar signed distance $d$. $d < 0$ if inside, $d = 0$ on surface, $d > 0$ if outside [S1, unofficial].

### Data Structures
No complex data structures are required. The method operates on standard 3D vectors and scalars [G].

### Steps
The algorithm determines the closest point on the infinite line segment defined by $c_1$ and $c_2$, then computes the distance to that point, adjusting for the radius and the capped ends [S1, unofficial].

1. **Compute Axis Vector and Length**:
   Let $dir = c_2 - c_1$.
   Let $h = \|dir\|$ be the height (length) of the cylinder [S1, unofficial].
2. **Project Query Point onto Axis**:
   Compute the parameter $t$ representing the normalized position of the projection of $v$ onto the line segment $[c_1, c_2]$ [S1, unofficial].
   $$ t = \frac{dir \cdot (v - c_1)}{dir \cdot dir} $$
   Here, $t=0$ corresponds to $c_1$ and $t=1$ corresponds to $c_2$ [S1, unofficial].
3. **Compute Closest Point on Infinite Line**:
   $$ p = c_1 + dir \cdot t $$
   This is the closest point on the *infinite* line passing through $c_1$ and $c_2$ [S1, unofficial].
4. **Compute Side Distance**:
   Calculate the distance from the query point to the axis line, minus the radius [S1, unofficial].
   $$ side\_dist = \|v - p\| - r $$
   This value is negative if the point is inside the infinite cylinder and positive if outside [S2, unofficial].
5. **Determine Final Distance Based on $t$**:
   The final distance depends on whether the projection $p$ falls within the segment $[c_1, c_2]$ (i.e., $0 \le t \le 1$) or outside it [S1, unofficial].
   - **Case A: Inside the segment ($0 \le t \le 1$)**:
     The closest point on the capped cylinder is either on the side wall or on one of the end caps [S1, unofficial].
     - If $side\_dist \ge 0$ (outside the side wall), the distance is simply $side\_dist$ [S1, unofficial].
     - If $side\_dist < 0$ (inside the side wall), the point is inside the infinite cylinder. The signed distance is the negative of the minimum distance to any surface (side wall or caps) [G].
       $$ d = \max(side\_dist, -h \cdot t, -h \cdot (1-t)) $$
   - **Case B: Projection beyond $c_2$ ($t > 1$)**:
     The distance to the cap plane is $dist\_cap = h \cdot (t - 1)$ [S1, unofficial].
     - If $side\_dist \ge 0$, the closest point is on the cap edge (corner), so $d = \sqrt{side\_dist^2 + dist\_cap^2}$ [S1, unofficial].
     - If $side\_dist < 0$, the closest point is on the cap face, so $d = -dist\_cap$ [G].
   - **Case C: Projection before $c_1$ ($t < 0$)**:
     The distance to the cap plane is $dist\_cap = h \cdot (-t)$ [S1, unofficial].
     - If $side\_dist \ge 0$, the closest point is on the cap edge, so $d = \sqrt{side\_dist^2 + dist\_cap^2}$ [S1, unofficial].
     - If $side\_dist < 0$, the closest point is on the cap face, so $d = -dist\_cap$ [G].

### Pseudocode
```python
def sd_capped_cylinder(v, c1, c2, r):
    # v, c1, c2 are 3D vectors (x, y, z)
    # r is radius
    
    dir = c2 - c1
    h_sq = dot(dir, dir)
    
    # Handle degenerate cylinder (point)
    if h_sq < 1e-12:
        return length(v - c1) - r
        
    h = sqrt(h_sq)
    
    # Project v onto the line segment
    t = dot(dir, v - c1) / h_sq
    
    # Closest point on the infinite line
    p = c1 + dir * t
    
    # Distance to the axis, minus radius
    side_dist = length(v - p) - r
    
    if t >= 0.0 and t <= 1.0:
        # Projection falls within the segment
        if side_dist >= 0.0:
            # Outside the side wall
            return side_dist
        else:
            # Inside the side wall
            # Return negative distance to nearest surface (side or caps)
            return max(side_dist, -h * t, -h * (1.0 - t))
            
    elif t > 1.0:
        # Projection beyond c2
        dist_cap = h * (t - 1.0)
        if side_dist >= 0.0:
            # Outside side wall, distance to corner (cap edge)
            return sqrt(side_dist * side_dist + dist_cap * dist_cap)
        else:
            # Inside side wall, closest point is on the cap face
            return -dist_cap
            
    else: # t < 0.0
        # Projection before c1
        dist_cap = h * (-t)
        if side_dist >= 0.0:
            # Outside side wall, distance to corner (cap edge)
            return sqrt(side_dist * side_dist + dist_cap * dist_cap)
        else:
            # Inside side wall, closest point is on the cap face
            return -dist_cap
```

### Parameters
- $c_1, c_2$: Endpoints of the cylinder axis. [S1, unofficial]
- $r$: Radius of the cylinder. [S1, unofficial]

### Edge Cases and Pitfalls
- **Degenerate Cylinder**: If $c_1 = c_2$, the height is 0. The function should return the distance to a sphere of radius $r$ centered at $c_1$ [S1, unofficial].
- **Precision**: When $t$ is very close to 0 or 1, floating point errors may cause the point to be classified incorrectly as outside the segment, leading to a discontinuity in the derivative. Clamping $t$ to $[0, 1]$ before computing $p$ can help, but the distance calculation must remain consistent [G].
- **Axis Alignment**: For axis-aligned cylinders, the formula from [S4, unofficial] (`d = abs(vec2(length(p.xz),p.y)) - h; return min(max(d.x,d.y),0.0) + length(max(d,0.0))`) is structurally identical to the box SDF but in 2D radial coordinates [S2, unofficial]. It avoids branching and is preferred for performance in aligned cases [G].

## Subtopics

### Ring Signed Distance Function
Computes the signed distance to a 2D ring (annulus) with radius $r$ and thickness $th$. It is defined as $|\|p\| - r| - th \cdot 0.5$. This is effectively a 2D cross-section of a torus or a flat cylinder with a hole [S4, unofficial].

## Operating characteristics
- **Time Complexity**: $O(1)$. The computation involves a constant number of vector operations, dot products, and square roots [G].
- **Memory Complexity**: $O(1)$. No auxiliary data structures are needed [G].
- **Performance**: Very fast, suitable for real-time ray marching. The square root operation is the most expensive part, but it is unavoidable for Euclidean distance [G].
- **Strengths**: Exact distance, works for any orientation (if general algorithm is used), robust for CSG operations [G].
- **Limitations**: The general endpoint-based algorithm involves more branches than the axis-aligned version. For axis-aligned cylinders, the [S4, unofficial] formula is preferred for performance [G].

## Background
Signed distance functions for basic primitives are foundational in ray marching and implicit modeling. The cylinder SDF is a standard primitive, often attributed to the work on SDFs by Inigo Quilez and others in the demoscene and computer graphics community [S2, unofficial][S4, unofficial]. The general endpoint-based formulation is described in [S1, unofficial]. The method is widely used in raymarching shaders and implicit surface rendering [S1, unofficial][S3, unofficial].
