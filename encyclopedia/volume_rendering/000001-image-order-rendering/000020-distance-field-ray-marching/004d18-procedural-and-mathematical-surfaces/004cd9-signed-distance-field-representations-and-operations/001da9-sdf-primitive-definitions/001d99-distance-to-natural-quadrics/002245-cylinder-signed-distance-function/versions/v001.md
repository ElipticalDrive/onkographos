# Cylinder Signed Distance Function

Also called: Capped Cylinder SDF, Cylinder SDF, Finite Cylinder SDF, Signed Capped Cylinder, Signed Cylinder, Signed Distance Function (SDF) for Cylinder, sdCappedCylinder, sdCylinder

## Overview
The Cylinder Signed Distance Function (SDF) computes the exact Euclidean distance from a query point to a finite cylinder defined by two endpoints and a radius [S1, unofficial]. It solves the problem of implicit surface representation for capped cylinders, which are essential for modeling pipes, limbs, and structural elements in ray marching [S1, S2, unofficial]. Unlike infinite cylinders, which only measure radial distance, the capped variant correctly handles the end caps and corners, returning negative values inside the volume and positive values outside [S2, S4, unofficial]. It is distinct from [Torus Signed Distance Function](2864-torus-signed-distance-function.md) (which models a ring) and [Distance to Superquadrics](1561-distance-to-superquadrics.md) (which offers smoothable variations but not exact Euclidean distance for standard primitives) [S2, unofficial][S5].

## How it works
**Inputs:**
*   $p$: Query point (Vector3).
*   $c_1, c_2$: Cylinder endpoints (Vector3) [S1, unofficial].
*   $r$: Cylinder radius (scalar) [S1, unofficial].

**Outputs:**
*   $d$: Signed distance (scalar). Negative if inside, positive if outside, zero on surface [S2, unofficial].

**Data Structures:**
*   Standard 3D vector ($x, y, z$) and scalar types. No special bit-packing required for the core function.

**Steps:**
1.  **Compute Axis Geometry:**
    *   Calculate the axis direction vector: $dir = c_2 - c_1$ [S1, unofficial].
    *   Calculate the squared length of the axis: $len\_sq = dir \cdot dir$ [S1, S4, unofficial].
    *   *Edge Case:* If $len\_sq < \epsilon$ (degenerate cylinder, effectively a sphere), return $length(p - c_1) - r$ [G].

2.  **Project Point onto Axis:**
    *   Calculate vector from start point to query: $pa = p - c_1$ [S1, S4, unofficial].
    *   Compute the normalized projection parameter $t$ (clamped to $[0, 1]$):
        $$ t = \frac{pa \cdot dir}{len\_sq} $$
        $$ t = \max(0.0, \min(1.0, t)) $$ [S1, S4, unofficial].

3.  **Compute Closest Point on Segment:**
    *   Calculate the closest point on the finite axis segment:
        $$ closest = c_1 + dir \cdot t $$ [S1, S4, unofficial].

4.  **Calculate Radial Distance:**
    *   Compute the vector from the closest axis point to the query point:
        $$ diff = p - closest $$ [S1, S4, unofficial].
    *   Calculate the radial distance from the axis:
        $$ side\_dist = length(diff) - r $$ [S1, S4, unofficial].

5.  **Determine Signed Distance:**
    *   The distance is negative if the point is inside the cylinder's radial bounds AND within the axial bounds.
    *   However, the standard robust implementation for ray marching often simplifies this by checking the "outside" distance and adding the "inside" correction [S2, S4, unofficial].
    *   A more direct approach derived from [S1, unofficial] and [S4, unofficial]:
        *   If $t$ is strictly between 0 and 1 (point is radially outside but axially within the segment):
            *   If $side\_dist \ge 0$: return $side\_dist$.
            *   If $side\_dist < 0$: return $side\_dist$ (inside).
        *   If $t$ is clamped to 0 or 1 (point is axially beyond an end cap):
            *   The distance to the end cap center (or edge) must be considered.
            *   Let $cap\_dist = length(diff) - r$ if we treat the end as a disk? No, [S1, unofficial] provides a specific logic for the caps involving the corner.
    
    *   **Unified Formula (from [S4, unofficial] adapted for arbitrary axis):**
        The [S4, unofficial] implementation for axis-aligned cylinders uses a 2D projection trick. For an arbitrary axis, the general geometric solution [S1, unofficial] is:
        
        1.  $t = clamp(dot(p - c_1, c_2 - c_1) / dot(c_2 - c_1, c_2 - c_1), 0.0, 1.0)$
        2.  $closest = c_1 + t * (c_2 - c_1)$
        3.  $dist = length(p - closest) - r$
        
        This returns the distance to the *surface*. To make it *signed*:
        *   We need to know if the point is inside.
        *   The point is inside if $length(p - closest) < r$ AND $0 < t < 1$.
        *   If $t=0$ or $t=1$, the "inside" region is the hemisphere/cap.
        
        *Correction based on [S2, unofficial] and [S4, unofficial] which provide the exact signed formula for axis-aligned cases:*
        
        For an axis-aligned cylinder (e.g., Y-axis) with half-height $h$ and radius $r$:
        1.  $q = (length(p_{xz}) - r, |p_y| - h)$
        2.  $d = max(q, 0.0)$
        3.  $inside = min(max(q_x, q_y), 0.0)$
        4.  $outside = length(d)$
        5.  $return outside + inside$ [S2, S4, unofficial].
