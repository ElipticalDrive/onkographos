# Signed Box Distance Function

Also called: Box SDF, Rectangular (Axis-Aligned Box) SDF, SDF Box, SDF Cube, Signed Box, sdBox

## Overview
The Signed Box Distance Function computes the exact Euclidean distance from a query point to the boundary of an axis-aligned box centered at the origin, returning negative values for interior points and positive values for exterior points [S9, S11, unofficial]. It solves the problem of defining implicit volumetric primitives for ray marching without polygonal approximation, serving as a fundamental building block for complex scene composition via set operations [S2, S9, unofficial]. Unlike the cheaper approximation that intersects half-spaces, the exact formulation correctly calculates distances to edges and corners, preventing the underestimation errors that cause aliasing and incorrect ambient occlusion [S12, S13, unofficial].

## How it works
**Inputs and Outputs:**
*   Input: A 3D query point $p$ (vector), and box half-extents $b$ (vector of positive floats representing half the side lengths along each axis). The box is centered at the origin $(0,0,0)$.
*   Output: A scalar signed distance $d$.

**Data Structures:**
*   $p$: `vec3` (x, y, z).
*   $b$: `vec3` (bx, by, bz).

**Algorithm:**
The method exploits symmetry by taking the absolute value of the point coordinates, effectively folding the 3D space into the first octant [S2, S9, unofficial]. It then computes the distance to the box boundary in this folded space, distinguishing between interior and exterior regions [S9, S12, unofficial].

1.  **Fold:** Compute the absolute value of the point coordinates: $p' = |p|$.
2.  **Offset:** Subtract the half-extents from the folded point to get the difference vector $q$:
    $$ q = |p| - b $$
    Here, $q_i = |p_i| - b_i$ for each axis $i \in \{x, y, z\}$ [S9, S11, unofficial].
3.  **Classify:** Determine if the point is inside or outside by checking the maximum component of $q$. Let $c = \max(q_x, \max(q_y, q_z))$ [S11, S12, unofficial].
    *   If $c < 0$, the point is strictly inside the box (all components of $q$ are negative).
    *   If $c \ge 0$, the point is on the surface or outside.
4.  **Compute Distance:**
    *   **Inside:** The signed distance is the maximum component of $q$ (which is negative). This represents the distance to the closest face [S11, S12, unofficial].
        $$ d_{inside} = c $$
    *   **Outside:** The signed distance is the Euclidean length of the positive components of $q$. This correctly accounts for distances to edges and corners [S9, S11, unofficial].
        $$ d_{outside} = \| \max(q, 0) \| $$
        where $\max(q, 0)$ is a vector where each component is $\max(q_i, 0)$ [S12, unofficial].
5.  **Combine:** The final signed distance is the sum of the inside distance (clamped to 0 if outside) and the outside distance (clamped to 0 if inside). A common compact formulation is:
    $$ d = \min(c, 0) + \| \max(q, 0) \| $$
    Alternatively, using the max/min logic directly:
    $$ d = \min(\max(q_x, \max(q_y, q_z)), 0) + \text{length}(\max(q, 0)) $$ [S9, S11, unofficial].

**Pseudocode:**
```python
def signed_box_distance(p: Vec3, b: Vec3) -> float:
    """
    Computes the signed distance from point p to an axis-aligned box
    centered at the origin with half-extents b.
    
    Args:
        p: Query point (x, y, z).
        b: Half-extents (bx, by, bz). Must be positive.
        
    Returns:
        Signed distance. Negative if inside, positive if outside.
    """
    # Step 1 & 2: Fold and Offset
    # q = abs(p) - b
    qx = abs(p.x) - b.x
    qy = abs(p.y) - b.y
    qz = abs(p.z) - b.z
    
    # Step 3: Classify
    # c = max(qx, max(qy, qz))
    c = max(qx, max(qy, qz))
    
    # Step 4 & 5: Compute and Combine
    # Inside distance: min(c, 0)
    # Outside distance: length(max(q, 0))
    
    # Compute max(q, 0) components
    qx_pos = max(qx, 0.0)
    qy_pos = max(qy, 0.0)
    qz_pos = max(qz, 0.0)
    
    # Euclidean norm of positive components
    outside_dist = sqrt(qx_pos**2 + qy_pos**2 + qz_pos**2)
    
    # Inside distance clamped to 0
    inside_dist = min(c, 0.0)
    
    return inside_dist + outside_dist
```

**Parameters:**
*   $b$: Half-extents. Typical values depend on scene scale. For a unit box, $b = (0.5, 0.5, 0.5)$ [S12, unofficial].
*   $p$: Query point.

**Edge Cases and Pitfalls:**
*   **Degenerate Box:** If any component of $b$ is zero, the box collapses to a plane, line, or point. The formula still holds mathematically but may cause numerical instability in derivatives (normals) [G].
*   **Precision:** Using `float` precision can lead to slight inaccuracies in normal computation near corners, affecting shading [S12, unofficial].
*   **Approximation vs Exact:** A cheaper approximation $d = \max(|p| - b)$ (taking the max component of the result) is not a true Euclidean distance for points outside corners; it underestimates the distance in corner regions [S12, S13, unofficial]. This underestimation causes smaller ray steps (slower convergence) and incorrect ambient occlusion (artifacts) [S12, S13, unofficial]. The exact formula above must be used for correct AO and smooth shading.

## Subtopics

### Unsigned Box Distance Function
Computes the unsigned distance from a point to an axis-aligned box centered at the origin. It always returns non-negative values. It is defined as $d = \|\max(|p| - b, 0)\|$ [S9, unofficial]. Use this when the inside/outside distinction is not required, such as for collision detection where only surface proximity matters.

### Box with Edge Rounding SDF
Computes the signed distance to a box with rounded edges, defined by half-extents $b$ and edge radius $e$. It modifies the standard box SDF by adding the radius to the folded coordinates before clamping, then subtracting the radius from the result. Use this for softer, more realistic geometry [S15, unofficial].

### Oriented Box2D SDF
Computes the signed distance to a 2D box with custom orientation and thickness between points `a` and `b`. It transforms the query point into the local frame of the segment [a, b] and then calls the 2D box SDF. Use this for oriented rectangular primitives in 2D scenes [S11, unofficial].

## Operating characteristics
*   **Time Complexity:** $O(1)$. The computation involves a fixed number of arithmetic operations (absolute value, subtraction, max, min, square root) regardless of scene complexity.
*   **Memory Complexity:** $O(1)$. No auxiliary data structures are required beyond the input point and box parameters.
*   **Measured Performance:** On modern GPUs, this function is extremely fast, often taking only a few clock cycles. It is a primary candidate for inline expansion in ray marchers [S2, unofficial].
*   **Strengths:** Exact Euclidean distance ensures correct ray marching step sizes, preventing overshooting [S2, unofficial]. Correct corner distances enable accurate ambient occlusion and smooth normals [S12, S13, unofficial].
*   **Limitations:** The square root operation is slightly more expensive than the max-only approximation, but the visual correctness is critical for advanced effects like AO [S12, unofficial].
*   **When to use:** Always use the exact formulation for production-quality ray marching, especially when ambient occlusion or smooth shading is required. Use the approximation only for simple silhouette rendering where performance is critical and visual artifacts are acceptable [S12, S14, unofficial].

## Background
The Signed Box Distance Function is a standard primitive in the field of Signed Distance Fields (SDFs) for ray marching. It was popularized by Inigo Quilez in his online resources on distance functions [S2, S9, unofficial]. The exact formulation (Algorithm 3.6 in [S12, S13, unofficial]) distinguishes itself from earlier approximations (Algorithm 3.5 in [S12, S13, unofficial]) by correctly handling corner distances, which was shown to be crucial for accurate ambient occlusion computation. It is widely implemented in graphics libraries and educational ray marchers [S9, S11, unofficial].
