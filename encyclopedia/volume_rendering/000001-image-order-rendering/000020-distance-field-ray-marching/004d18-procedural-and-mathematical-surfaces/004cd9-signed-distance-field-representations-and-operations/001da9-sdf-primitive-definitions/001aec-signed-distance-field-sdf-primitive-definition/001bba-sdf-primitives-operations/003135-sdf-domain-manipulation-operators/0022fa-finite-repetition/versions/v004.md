# Finite Repetition
Also called: Bounded Tiling, Finite Domain Repetition, Limited Repetition

## Overview
Finite Repetition creates a bounded grid of repeated instances of a base Signed Distance Function (SDF) within a specified limit. Unlike infinite tiling operators, it restricts the replication count to a finite number of cells in each dimension, effectively carving out a "window" into an infinite periodic structure. It is chosen when a localized cluster of objects is required without the computational cost or visual artifacts of infinite repetition extending to infinity.

## How it works
**Inputs and Outputs:**
- Input: Query point $\mathbf{p} \in \mathbb{R}^3$, period vector $\mathbf{c} \in \mathbb{R}^3$ (cell size), limit vector $\mathbf{l} \in \mathbb{R}^3$ (maximum cell index magnitude).
- Output: Modified point $\mathbf{p}'$ mapped to the local coordinate within the active cell, and the distance to the base SDF evaluated at $\mathbf{p}'$.

**Data Structures:**
- Vectors $\mathbf{p}, \mathbf{c}, \mathbf{l}$ are typically 3-component floating-point vectors.

**Steps:**
1.  Compute the cell index $\mathbf{q}$ by dividing the query point by the period and rounding to the nearest integer:
    $$ \mathbf{q} = \text{round}\left(\frac{\mathbf{p}}{\mathbf{c}}\right) $$
2.  Clamp the cell index to the specified limits to enforce the finite boundary:
    $$ \mathbf{q}_{\text{clamped}} = \text{clamp}(\mathbf{q}, -\mathbf{l}, \mathbf{l}) $$
    where clamp is applied component-wise: $q_i = \max(-l_i, \min(q_i, l_i))$.
3.  Map the query point back to the local coordinate of the clamped cell:
    $$ \mathbf{p}' = \mathbf{p} - \mathbf{c} \cdot \mathbf{q}_{\text{clamped}} $$
4.  Evaluate the base SDF at $\mathbf{p}'$.

**Pseudocode:**
```python
def repeat_finite(p: Vec3, c: Vec3, l: Vec3) -> Vec3:
    """
    Maps p to the local coordinate of the finite repetition cell.
    p: Query point
    c: Period vector (cell size)
    l: Limit vector (max cell index magnitude per axis)
    Returns: Transformed point p'
    """
    # Step 1: Calculate cell index
    q = p / c
    
    # Step 2: Round to nearest integer
    q = round(q)
    
    # Step 3: Clamp to limits
    q = clamp(q, -l, l)
    
    # Step 4: Map back to local coordinate
    p_prime = p - c * q
    
    return p_prime
```

**Parameters:**
- $\mathbf{c}$: Defines the spacing between repetitions. Must be non-zero.
- $\mathbf{l}$: Defines the extent of the repetition. If $l_i = 0$, only the central cell (index 0) is active.

**Edge Cases:**
- If any component of $\mathbf{c}$ is zero, division is undefined. [G] Implementers should ensure $\mathbf{c}$ components are strictly positive or handle zero-periods as a special case (e.g., no repetition in that axis).
- If $\mathbf{p}$ is exactly on a boundary between cells, `round()` behavior depends on the language/runtime. Standard rounding to nearest even or away from zero may cause discontinuities in the derivative if not handled consistently.

## Operating characteristics
- **Time Complexity:** $O(1)$ per query. Involves basic arithmetic operations (division, rounding, clamping, subtraction).
- **Memory Complexity:** $O(1)$ auxiliary space.
- **Strengths:** Efficiently creates bounded clusters of geometry. Avoids infinite recursion or large bounding box issues associated with infinite tiling.
- **Limitations:** The distance field is not smooth across the boundaries of the finite region if the base SDF does not naturally decay to zero at the cell edges. The "cut" at the limit $\mathbf{l}$ creates a hard boundary in the domain, which may result in visible seams or non-physical distances if the base SDF is not designed to be zero at the cell boundary.

## Background
Finite Repetition is a domain manipulation operator used in ray marching and implicit surface rendering. It is a variant of infinite tiling (modulo-based repetition) where the periodic domain is truncated. It appears in unofficial SDF libraries and shader code repositories as a means to create localized patterns.
