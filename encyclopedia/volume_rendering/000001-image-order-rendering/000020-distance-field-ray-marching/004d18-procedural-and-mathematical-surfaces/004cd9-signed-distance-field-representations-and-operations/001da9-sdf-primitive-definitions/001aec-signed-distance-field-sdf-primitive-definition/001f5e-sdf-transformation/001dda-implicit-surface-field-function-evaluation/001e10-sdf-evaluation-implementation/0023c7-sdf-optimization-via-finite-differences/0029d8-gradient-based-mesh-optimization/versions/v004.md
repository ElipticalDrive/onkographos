# Gradient-Based Mesh Optimization

Also called: nvdiffrec-style optimization

## Overview
Gradient-Based Mesh Optimization reconstructs unknown 3D meshes by optimizing a randomly initialized Signed Distance Field (SDF) to minimize geometric differences against a reference mesh using multi-view images [S1, unofficial]. It solves the problem of recovering geometry from sparse or noisy observations by treating mesh vertices or SDF values as differentiable parameters updated via gradient descent [S1, unofficial]. It sets itself apart from its siblings by directly optimizing the SDF field values (and optionally learnable weights) to minimize multiview mask and depth losses, relying on finite difference gradients for the SDF evaluation [S1, unofficial].

## How it works
**Inputs and Outputs:**
*   **Inputs:** A set of multi-view images (or masks) of the target object, camera poses, and a randomly initialized SDF field defined on a grid or tetrahedral mesh.
*   **Outputs:** An optimized SDF field and/or mesh geometry that minimizes the difference between the rendered view of the optimized SDF and the target reference data.

**Data Structures:**
*   **SDF Field:** A scalar field $S$ defined on a domain. In tetrahedral implementations, each vertex $v_i$ has an SDF value $S_i \in \mathbb{R}$ and a deformation value $\Delta v_i \in \mathbb{R}^3$ [S3].
*   **Mesh Representation:** The surface is extracted from the SDF (e.g., via marching cubes or DMTet) to compute rendering losses [S1, unofficial][S3].

**Steps:**
1.  **Initialization:** Initialize the SDF field randomly [S1, unofficial]. If using DMTet, initialize vertices with base positions and zero deformations [S3].
2.  **Rendering:** Render the current mesh/SDF from the given camera poses to obtain rendered masks $M'$ and/or depth maps [S1, unofficial][S3].
3.  **Loss Calculation:** Compute the loss between the rendered output and the ground truth (reference mesh/masks) [S1, unofficial][S3].
    *   **Mask Loss:** Calculate the L1 norm between the ground truth mask $M$ and the rendered mask $M'$ [S3]:
        $$L_{mask} = \frac{|M - M'|}{2}$$
    *   **Depth Loss:** Minimize depth differences against the reference mesh [S1, unofficial].
    *   **Regularization:** Optionally add a developability regularizer ($L_{dev}$) to encourage fabricability from panels [S1, unofficial]. Add Implicit Geometric Regularization (IGR) as an eikonal loss to constrain the gradient magnitude of the SDF field $f_\theta$ to be close to 1 [S3]:
        $$L_{eikonal} = E_{v_0 \in V_0} (||\nabla f_\theta (v_0 )||^2 - 1)^2$$
4.  **Optimization:** Update the SDF values and/or vertex deformations using gradient descent to minimize the total loss [S1, unofficial][S3].
5.  **Progressive Encoding (Optional):** If using neural representations, employ progressive position encoding to alleviate high-frequency noise while retaining details. The encoding frequency is gradually increased after training reaches a certain stage [S3].

**Parameters:**
*   **Regularization Weights:** Initially set low to avoid hindering convergence; incrementally increased if artifacts appear [S1, unofficial].
*   **L1 Regularizer on Flexible Weights:** Generally low impact for single shape, but stabilizes generative pipelines [S1, unofficial].

**Pseudocode:**
```python
# Initialize SDF field values and/or vertex deformations randomly
sdf_values = random_init_sdf_field()
vertex_deformations = zeros_like(vertices)

for iteration in range(num_iterations):
    # 1. Update mesh geometry from SDF (e.g., DMTet extraction)
    # v_i' = v_i + delta_v_i
    current_mesh = extract_mesh(sdf_values, vertex_deformations)
    
    # 2. Render current mesh to get masks and depth
    rendered_masks = render(current_mesh, camera_poses)
    rendered_depths = render_depth(current_mesh, camera_poses)
    
    # 3. Compute Losses
    # Mask Loss: L1 norm between ground truth and rendered mask
    # Note: Source [S3] defines L_mask = |M - M'| / 2
    loss_mask = mean(abs(ground_truth_masks - rendered_masks)) / 2.0
    
    # Depth Loss (conceptual, based on [S1, unofficial])
    loss_depth = mean(abs(ground_truth_depths - rendered_depths))
    
    # Eikonal Regularization (based on [S3])
    # Constrain gradient magnitude of SDF to 1
    sdf_gradients = compute_sdf_gradients(sdf_values)
    loss_eikonal = mean((norm(sdf_gradients, dim=-1)**2 - 1)**2)
    
    # Developability Regularizer (optional, based on [S1, unofficial])
    loss_dev = compute_developability_loss(current_mesh)
    
    # Total Loss
    total_loss = loss_mask + loss_depth + lambda_eikonal * loss_eikonal + lambda_dev * loss_dev
    
    # 4. Backpropagate and Update
    total_loss.backward()
    
    # Update SDF values
    sdf_values = sdf_values - learning_rate * sdf_values.grad
    
    # Update vertex deformations (if applicable)
    vertex_deformations = vertex_deformations - learning_rate * vertex_deformations.grad
    
    # Clear gradients
    sdf_values.grad.zero_()
    vertex_deformations.grad.zero_()
    
    # Progressive Position Encoding Update (if using neural SDF)
    if iteration in encoding_schedule:
        increase_position_encoding_frequency()
```

## Subtopics

### [Inverse Mesh Recovery with Spatiotemporal Bilateral Gradient Filtering](13136-inverse-mesh-recovery-with-spatiotemporal-bilateral-gradient.md)
This method is a gradient-based optimization technique for recovering mesh geometry from multi-view images by optimizing vertex positions. It solves the problem of slow convergence and loss of sharp features (silhouettes, thin structures) in inverse rendering, which occurs when standard Laplacian smoothing dilutes sparse silhouette gradients. It sets itself apart from its parent [Gradient-Based Mesh Optimization](4628-gradient-based-mesh-optimization.md) by replacing the Laplacian postfilter with an edge-aware cross-bilateral filter that preserves values on silhouettes, enabling faster convergence on models with thin structures or many silhouettes.

### Gradient-Based Mesh Optimization via Sphere Fitting
This variant approximates non-deformed initial mesh geometry with a set of spheres to compute visibility. The mesh is deformed by translating and rotating these spheres, allowing inverse problems to supervise sphere parameters and update geometry [S2]. To determine the initial position and radius of each sphere, it minimizes the total volume occupied by the sphere set outside the mesh (sphere outside volume) along with a term encouraging the sphere set to cover the mesh surface, optimized using gradient descent [S2]. It connects sphere centers as an embedded graph to drive mesh deformation, where each sphere is connected to its K-nearest vertices on the template [S2]. Mesh deformation is parameterized by the rotation and translation of each sphere, which are optimized using rendering loss during inverse problems [S2].

### DMTet Surface Reconstruction with Eikonal Regularization
This variant defines object geometry as a Signed Distance Field (SDF) on a tetrahedral mesh $T$. Each vertex $v_i$ has an SDF value $S_i \in \mathbb{R}$ and a deformation value $\Delta v_i \in \mathbb{R}^3$. The mesh is updated as $v_i' = v_i + \Delta v_i$ [S3]. It supervises the optimization using rendered masks derived from projecting the object according to camera poses [S3]. It uses progressive position encoding to alleviate high-frequency noise while retaining details, gradually increasing the encoding frequency after training reaches a certain stage [S3]. It adds Implicit Geometric Regularization (IGR) as an eikonal loss to constrain the gradient magnitude of the SDF field $f_\theta$ to be close to 1: $L_{eikonal} = E_{v_0 \in V_0} (||\nabla f_\theta (v_0 )||^2 - 1)^2$ [S3].

## Operating characteristics
*   **Time Complexity:** Depends on the number of optimization iterations and the cost of rendering/gradient computation per iteration. Gradient descent requires multiple forward and backward passes per step.
*   **Memory Complexity:** Proportional to the resolution of the SDF grid or the number of vertices in the tetrahedral mesh, plus the memory for storing gradients and intermediate rendering buffers.
*   **Strengths:** Can recover detailed geometry from sparse views; differentiable nature allows end-to-end optimization with other neural components; eikonal regularization helps maintain smooth, well-defined surfaces.
*   **Limitations:** Sensitive to initialization; prone to local minima; high-frequency noise can be introduced without proper regularization (e.g., eikonal loss or progressive encoding); computationally expensive due to repeated rendering and gradient computation.
*   **When to Use:** When reconstructing geometry from multi-view images where explicit mesh topology is unknown or difficult to match; when integrating mesh optimization into differentiable rendering pipelines.
*   **When Not to Use:** When real-time performance is critical; when the target geometry is extremely complex with thin structures that require specialized filtering (see [Inverse Mesh Recovery with Spatiotemporal Bilateral Gradient Filtering](13136-inverse-mesh-recovery-with-spatiotemporal-bilateral-gradient.md)).

## Background
Gradient-based mesh optimization for SDFs has been developed in the context of differentiable rendering and inverse graphics. The FlexiCubes method [S1, unofficial] popularized optimizing SDF values and learnable weights to minimize geometric differences against reference meshes. The DMTet approach [S3] combines tetrahedral meshes with SDFs and eikonal regularization for robust surface reconstruction. Sphere fitting variants [S2] offer an alternative parameterization for deformation and visibility computation in inverse problems.
