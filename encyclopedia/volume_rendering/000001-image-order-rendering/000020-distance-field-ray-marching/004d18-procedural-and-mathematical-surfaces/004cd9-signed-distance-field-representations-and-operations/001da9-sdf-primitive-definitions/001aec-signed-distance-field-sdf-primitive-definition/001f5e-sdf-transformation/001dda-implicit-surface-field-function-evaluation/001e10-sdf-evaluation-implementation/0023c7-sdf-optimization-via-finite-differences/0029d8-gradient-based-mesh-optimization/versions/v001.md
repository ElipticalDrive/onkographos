# Gradient-Based Mesh Optimization

Also called: nvdiffrec-style optimization

## Overview
Gradient-Based Mesh Optimization reconstructs unknown meshes by optimizing a randomly initialized Signed Distance Field (SDF) to minimize geometric differences against a reference mesh using multiview mask and depth losses [S1, unofficial]. It differs from standard SDF evaluation by treating the SDF values as learnable parameters updated via gradient descent rather than fixed analytical functions.

## How it works
**Inputs:**
- Target mesh (reference geometry) for loss computation.
- Multiview images or masks of the target.
- Randomly initialized SDF grid or point cloud.

**Outputs:**
- Optimized SDF field.
- Extracted mesh (via Marching Cubes or similar) matching the target.

**Data Structures:**
- SDF values: Tensor of shape $(N,)$ where $N$ is the number of grid points or vertices.
- Losses: Scalar values for mask difference and depth difference.

**Steps:**
1. **Initialize SDF:** Randomly initialize the SDF values at the grid points or vertices. [S1, unofficial]
2. **Render/Extract:** Render the current SDF state to generate multiview masks and depth maps, or extract a mesh to compute geometric distance. [S1, unofficial]
3. **Compute Loss:** Calculate the difference between the rendered/extracted output and the target reference mesh using:
   - Multiview mask loss (e.g., binary cross-entropy or IoU).
   - Depth loss (e.g., L1 or L2 distance between rendered and target depth maps). [S1, unofficial]
4. **Backpropagate:** Compute gradients of the loss with respect to the SDF values. [S1, unofficial]
5. **Update SDF:** Perform gradient descent to update the SDF values. [S1, unofficial]
6. **Regularization (Optional):** Apply a developability regularizer ($L_{dev}$) to encourage fabricability from panels if the target is a deformable object. [S1, unofficial]
   - Regularization weights are initially set low to avoid hindering convergence and incremented if artifacts appear. [S1, unofficial]
   - An L1 regularizer on flexible weights may be applied to stabilize generative pipelines (e.g., GET3D), though it has low impact for single shapes. [S1, unofficial]

**Pseudocode:**
```python
# Initialize SDF values randomly
sdf_values = torch.randn(num_points)
sdf_values.requires_grad = True

# Optimizer
optimizer = torch.optim.Adam([sdf_values], lr=0.01)

for iteration in range(num_iterations):
    optimizer.zero_grad()
    
    # Render current SDF to get masks and depths
    # Note: This requires a differentiable renderer or mesh extraction
    rendered_masks = render_sdf_masks(sdf_values)
    rendered_depths = render_sdf_depths(sdf_values)
    
    # Compute losses against target
    mask_loss = compute_mask_loss(rendered_masks, target_masks)
    depth_loss = compute_depth_loss(rendered_depths, target_depths)
    
    total_loss = mask_loss + depth_loss
    
    # Optional: Add regularization
    if use_developability:
        dev_loss = compute_developability_loss(sdf_values)
        total_loss += reg_weight * dev_loss
        
    if use_flexible_weight_reg:
        flex_reg = torch.norm(sdf_values, p=1)
        total_loss += flex_reg_weight * flex_reg
        
    # Backpropagate
    total_loss.backward()
    
    # Update SDF
    optimizer.step()
    
    # Update regularization weights if necessary
    if artifacts_detected:
        reg_weight *= 1.1
```

**Edge Cases and Pitfalls:**
- **Precision:** SDF values must be precise enough to distinguish inside/outside. [G]
- **Boundaries:** Ensure the SDF domain covers the entire target mesh. [G]
- **Degenerate Input:** If the target mesh has holes or non-manifold geometry, loss computation may be unstable. [G]

## Subtopics

### Gradient-Based Mesh Optimization via Sphere Fitting
Approximates non-deformed initial mesh geometry with a set of spheres to compute visibility. The mesh is deformed by translating and rotating these spheres, allowing inverse problems to supervise sphere parameters and update geometry [S2].
- **Steps:**
  1. Determine initial position and radius of each sphere by minimizing the total volume occupied by the sphere set outside the mesh (sphere outside volume) along with a term encouraging the sphere set to cover the mesh surface. Optimized using gradient descent [S2].
  2. Connect sphere centers as an embedded graph to drive mesh deformation. Each sphere is connected to its K-nearest vertices on the template [S2].
  3. Parameterize mesh deformation by the rotation and translation of each sphere. Optimize these parameters using rendering loss during inverse problems [S2].
- **When to choose:** When visibility computation is a bottleneck and the geometry can be approximated by spheres [S2].

## Operating characteristics
- **Time Complexity:** Depends on the number of SDF points and iterations. Gradient descent requires multiple forward passes through the renderer/extractor per iteration.
- **Memory Complexity:** Stores SDF values and gradients. [S1, unofficial]
- **Strengths:** Can reconstruct complex geometries from limited views; differentiable end-to-end. [S1, unofficial]
- **Limitations:** Sensitive to initialization; may converge to local minima; computationally expensive due to repeated rendering/optimization. [S1, unofficial]
- **When to use:** When reconstructing meshes from multiview data where analytical SDFs are unknown. [S1, unofficial]
- **When not to use:** When real-time performance is required or when the geometry is simple enough for analytical SDFs. [S1, unofficial]

## Background
Originated in the context of differentiable rendering and inverse graphics. The method is associated with workflows like nvdiffrec-style optimization [S1, unofficial]. It builds on the ability to backpropagate through rendering pipelines to optimize geometric parameters [S1, unofficial].
