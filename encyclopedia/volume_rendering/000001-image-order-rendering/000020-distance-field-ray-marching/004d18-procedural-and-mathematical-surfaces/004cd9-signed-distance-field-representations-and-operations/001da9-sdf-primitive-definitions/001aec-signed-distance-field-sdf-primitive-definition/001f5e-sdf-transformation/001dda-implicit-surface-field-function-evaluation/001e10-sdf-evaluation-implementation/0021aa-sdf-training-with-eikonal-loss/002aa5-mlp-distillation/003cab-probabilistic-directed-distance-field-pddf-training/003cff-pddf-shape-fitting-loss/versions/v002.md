# PDDF Shape-Fitting Loss

Also called: PDDF loss

## Overview
The PDDF Shape-Fitting Loss ($\mathcal{L}_S$) is the primary training objective for Probabilistic Directed Distance Fields [S1]. It supervises the network's prediction of visibility, surface normals, and a mixture of depth components [S1]. It learns accurate implicit surface representations from oriented point clouds by combining geometric consistency, visibility prediction, and regularization of the probabilistic weight fields [S1]. It distinguishes itself from standard SDF training by explicitly modeling depth as a discrete mixture of delta functions (PDDF) and enforcing transitions between these components at surface discontinuities via a dedicated weight transition loss [S1].

## How it works

### Inputs and Outputs
**Inputs:**
*   Oriented points $(p, v)$, where $p$ is the 3D position and $v$ is the viewing direction [S1].
*   Ground truth data: visibility $\xi$, surface normal $n$, and depth $d$ [S1].
*   Network predictions: visibility $\hat{\xi}$, depth components $\hat{d}_i$, and weights $w_i$ for $i \in \{1, \dots, K\}$ [S1].
*   Hyperparameters: $\gamma_d, \gamma_\xi, \gamma_n, \gamma_{E,d}, \gamma_{E,\xi}, \gamma_V, \gamma_T, \varepsilon_T$ [S1].
*   $K=2$: The number of delta components [S1].
**Outputs:**
*   Scalar loss value $\mathcal{L}_S$ [S1].

### Data Structures
The PDDF representation at a point consists of:
*   $w_i$: Scalar weight for the $i$-th depth component [S1].
*   $\hat{d}_i$: Scalar predicted depth for the $i$-th component [S1].
*   $\hat{\xi}$: Scalar predicted visibility [S1].
The maximum likelihood index is defined as:
$$ i^* = \arg \max_j w_j $$

### Formulas
The total loss is a weighted sum of five components:
$$ \mathcal{L}_S = \gamma_d \mathcal{L}_d + \gamma_\xi \mathcal{L}_\xi + \gamma_n \mathcal{L}_n + \mathcal{L}_{\text{DE}} + \mathcal{L}_{W} \quad (2) $$

1.  **Minimum Distance Loss ($\mathcal{L}_d$):** Trains the highest probability depth component to match the ground truth depth [S1].
    $$ \mathcal{L}_d = \xi | d_{b_{i^*}} - d | $$

2.  **Visibility Objective ($\mathcal{L}_\xi$):** Binary cross-entropy between predicted and ground truth visibility [S1].
    $$ \mathcal{L}_\xi = \text{BCE}(\hat{\xi}, \xi_b) $$

3.  **Normals Loss ($\mathcal{L}_n$):** Matches surface normals using the gradient of the predicted depth of the maximum likelihood component [S1].
    $$ \mathcal{L}_n = -\xi | n^T n_{b_{i^*}}(p, v) | $$
    Where $n_{b_{i^*}}(p, v)$ is the normal derived from $\nabla_p \hat{d}_{b_{i^*}}$ [S1].

4.  **Directed Eikonal Regularization ($\mathcal{L}_{\text{DE}}$):** Enforces the Eikonal equation on visibility and depth components [S1].
    $$ \mathcal{L}_{\text{DE}} = \gamma_{\text{E},d} \sum_i \xi \left[ \nabla_i \hat{d}_i \cdot v + 1 \right]^2 + \gamma_{\text{E},\xi} \left[ \nabla_\xi \hat{\xi} \cdot v \right]^2 \quad (1) $$

5.  **Weight Field Regularization ($\mathcal{L}_{W}$):** Encourages low entropy and controlled transitions [S1].
    $$ \mathcal{L}_{W} = \gamma_V \mathcal{L}_V + \gamma_T \mathcal{L}_T $$
    *   **Weight Variance Loss ($\mathcal{L}_V$):** Encourages low entropy (sharp peaks) in the weight distribution to prevent $i^*$ from switching unnecessarily [S1].
        $$ \mathcal{L}_V = \sum_i w_i $$
    *   **Weight Transition Loss ($\mathcal{L}_T$):** Encourages the maximum likelihood component to change $i^*$ when a discontinuity is required [S1].
        $$ \mathcal{L}_T = \max(0, \varepsilon_T - |\nabla_p w_{1n}|)^2 $$

### Parameters
*   $\gamma_d, \gamma_\xi, \gamma_n$: Weights for distance, visibility, and normals losses. Values not given in the sources.
*   $\gamma_{E,d}, \gamma_{E,\xi}$: Weights for Directed Eikonal terms. Values not given in the sources.
*   $\gamma_V, \gamma_T$: Weights for weight regularization terms. Values not given in the sources.
*   $\varepsilon_T$: Hyper-parameter controlling the desired transition speed. Value not given in the sources.
*   $K=2$: Number of delta components [S1].

### Pseudocode
```python
def pddf_shape_fitting_loss(p, v, xi_gt, n_gt, d_gt, xi_pred, d_pred, w_pred, 
                            gamma_d, gamma_xi, gamma_n, gamma_E_d, gamma_E_xi, 
                            gamma_V, gamma_T, epsilon_T):
    """
    Computes the PDDF Shape-Fitting Loss.
    
    Args:
        p: (N, 3) Point positions.
        v: (N, 3) Viewing directions.
        xi_gt: (N,) Ground truth visibility.
        n_gt: (N, 3) Ground truth normals.
        d_gt: (N,) Ground truth depth.
        xi_pred: (N,) Predicted visibility.
        d_pred: (N, K) Predicted depth components.
        w_pred: (N, K) Predicted weights.
        
    Returns:
        loss: Scalar loss value.
    """
    K = d_pred.shape[1]
    
    # 1. Identify maximum likelihood index
    i_star = [w_pred[i].index(max(w_pred[i])) for i in range(len(w_pred))]
    
    # Gather the depth component corresponding to i_star
    d_b_i_star = [d_pred[i][i_star[i]] for i in range(len(d_pred))]
    
    # 2. Minimum Distance Loss
    L_d = [xi_gt[i] * abs(d_b_i_star[i] - d_gt[i]) for i in range(len(xi_gt))]
    L_d = sum(L_d) / len(L_d)
    
    # 3. Visibility Objective
    eps = 1e-7
    xi_pred_clipped = [max(eps, min(1 - eps, x)) for x in xi_pred]
    L_xi = -sum([xi_gt[i] * math.log(xi_pred_clipped[i]) + (1 - xi_gt[i]) * math.log(1 - xi_pred_clipped[i]) for i in range(len(xi_gt))]) / len(xi_gt)
    
    # 4. Normals Loss
    # Compute gradient of d_b_i_star w.r.t p
    grad_d_b_i_star = compute_gradient(d_b_i_star, p)
    norm_grad = [max(1e-7, math.sqrt(sum(g**2 for g in grad_d_b_i_star[i]))) for i in range(len(grad_d_b_i_star))]
    n_b_i_star = [[grad_d_b_i_star[i][j] / norm_grad[i] for j in range(3)] for i in range(len(grad_d_b_i_star))]
    
    dot_prod = [sum(n_gt[i][j] * n_b_i_star[i][j] for j in range(3)) for i in range(len(n_gt))]
    L_n = -sum([xi_gt[i] * abs(dot_prod[i]) for i in range(len(xi_gt))]) / len(xi_gt)
    
    # 5. Directed Eikonal Regularization
    L_DE_d = 0.0
    for i in range(K):
        d_i = [d_pred[j][i] for j in range(len(d_pred))]
        grad_d_i = compute_gradient(d_i, p)
        dot_d_v = [sum(grad_d_i[j][k] * v[j][k] for k in range(3)) for j in range(len(grad_d_i))]
        term = [x + 1.0 for x in dot_d_v]
        L_DE_d += sum([xi_gt[j] * (term[j] ** 2) for j in range(len(xi_gt))]) / len(xi_gt)
    
    grad_xi = compute_gradient(xi_pred, p)
    dot_xi_v = [sum(grad_xi[j][k] * v[j][k] for k in range(3)) for j in range(len(grad_xi))]
    L_DE_xi = sum([x ** 2 for x in dot_xi_v]) / len(dot_xi_v)
    
    L_DE = gamma_E_d * L_DE_d + gamma_E_xi * L_DE_xi
    
    # 6. Weight Field Regularization
    L_V = sum([sum(w_pred[j]) for j in range(len(w_pred))]) / len(w_pred)
    
    w_1 = [w_pred[j][0] for j in range(len(w_pred))]
    grad_w_1 = compute_gradient(w_1, p)
    dot_w_n = [sum(grad_w_1[j][k] * n_gt[j][k] for k in range(3)) for j in range(len(grad_w_1))]
    abs_dot_w_n = [abs(x) for x in dot_w_n]
    L_T = sum([(max(0, epsilon_T - x) ** 2) for x in abs_dot_w_n]) / len(abs_dot_w_n)
    
    L_W = gamma_V * L_V + gamma_T * L_T
    
    # 7. Total Loss
    L_S = gamma_d * L_d + gamma_xi * L_xi + gamma_n * L_n + L_DE + L_W
    
    return L_S
```

### Edge Cases and Pitfalls
*   **Gradient Computation:** The normals loss and Eikonal loss require gradients of the network outputs with respect to the input positions $p$ [S1]. This requires `create_graph=True` in autograd to allow second-order derivatives if needed, or at least first-order derivatives for the Eikonal term [G].
*   **Weight Transition Loss Application:** $\mathcal{L}_T$ is only applied to oriented points that are surface (S) and tangent (T) data, where a discontinuity is desired [S1]. It should not be applied to all points indiscriminately [S1]. The pseudocode above applies it to all points; in implementation, a mask for S/T points should be used [G].
*   **K=2 Assumption:** The transition loss uses $w_1$ alone [S1]. This is valid because $K=2$, so $w_1$ determines the switch between the two components [S1].
*   **L_V Formula:** The formula $\mathcal{L}_V = \sum_i w_i$ is unusual [S1]. If weights are normalized to sum to 1, this term is constant ($K$) [G]. The source text says it encourages "low entropy", which usually involves $\sum w_i \log w_i$ [G]. However, the explicit formula is $\sum w_i$ [S1]. We follow the explicit formula [S1].

## Operating characteristics

### Time and Memory Complexity
*   **Time:** The loss computation involves forward passes for gradients, which doubles the computational cost of the forward pass for the depth and visibility predictions [G]. The Eikonal term sums over $K$ components [S1].
*   **Memory:** Requires storing gradients for $p$ for each output ($d_i, \xi$) [G]. This increases memory usage proportional to the number of components $K$ [G].

### Strengths and Limitations
*   **Strengths:** Explicitly handles visibility and depth as a mixture, allowing for multi-modal depth distributions [S1]. The transition loss helps in learning sharp discontinuities [S1].
*   **Limitations:** The weight variance loss formula is non-standard [S1]. The method relies on oriented point cloud data, which may not be available for all scenes [S1].

### When to Use
*   Use when training PDDF models from oriented point clouds [S1].
*   Use when accurate surface normals and visibility prediction are required [S1].

### When Not to Use
*   Do not use for standard SDF training without the probabilistic depth mixture [S1].
*   Do not use if oriented point cloud data is not available [S1].

## Background

### Origin
The PDDF Shape-Fitting Loss was introduced in "Probabilistic Directed Distance Fields for Ray-Based Shape Representations" [S1].

### History
The method builds on prior SDF work [60]-[64] and extends it by incorporating a probabilistic mixture of depth components [S1].

### Usage
Used in ray-based shape representations for rendering and reconstruction [S1].
