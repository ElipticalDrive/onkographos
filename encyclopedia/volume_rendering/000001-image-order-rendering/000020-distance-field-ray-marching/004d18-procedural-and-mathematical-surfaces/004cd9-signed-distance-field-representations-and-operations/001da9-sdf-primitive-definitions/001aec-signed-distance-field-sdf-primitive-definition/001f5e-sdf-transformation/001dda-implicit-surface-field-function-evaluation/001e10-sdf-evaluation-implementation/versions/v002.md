# SDF Evaluation Implementation

Also called: SDF Handler Implementation, SDF Query Handler

## Overview
SDF Evaluation Implementation provides the runtime interface for querying Signed Distance Field (SDF) values and normals from implicit representations [S1, unofficial]. It abstracts underlying SDF definitions into a uniform callable interface suitable for ray marching and intersection queries [G]. Unlike [Implicit Surface Field Function Evaluation](1599-implicit-surface-field-function-evaluation.md), which defines the mathematical concept of the field function $d = f(x,y,z)$, this implementation focuses on the software architecture and numerical execution required to evaluate these queries [G].

## How it works

### Inputs and Outputs
*   **Inputs**: Query point $q \in \mathbb{R}^3$ [S1, unofficial]; SDF identifier or configuration (e.g., name, fractal parameters) [S1, S4, unofficial]; Batch of sample points [S2, unofficial]; Tetrahedron vertices [S1, unofficial].
*   **Outputs**: Scalar distance value $d \in \mathbb{R}$ [S1, unofficial]; Normal vector $n \in \mathbb{R}^3$ [S1, unofficial]; Intersection times and normals for ray/tetrahedron intersections [S1, unofficial].

### Data Structures
*   **SDF Query Handler**: A class or struct that encapsulates the SDF evaluation logic [S1, unofficial]. Fields: `sdf_name` (string), `sdf_func` (lambda/function pointer), `min_step_size` (float) [S1, unofficial].
*   **Sample Batch**: A tensor or array structure containing input coordinates and output storage [S2, unofficial]. Layout: A 2D array where columns 0-2 store coordinates $(x,y,z)$ and column 3 stores the SDF value $d$ [S2, unofficial].

### Steps
1.  **Initialization and Validation**: Receive SDF identifier `name` [S1, unofficial]. Validate `name` using `is_valid_sdf_name(name)` [S1, unofficial]. If invalid, throw `std::runtime_error("unknown SDF '" + name + "')` [S1, unofficial]. Construct an evaluation lambda `sdf_func` that converts input coordinates to the target vector type and calls `sdf::evaluate(name, glm_p)` [S1, unofficial]. Store `sdf_func` and `min_step_size` in the handler instance [S1, unofficial].
2.  **Point Query**: Input query point $q$ [S1, unofficial]. Call `query_normal_SDF(q, sdf_func)` [S1, unofficial]. Evaluate $d = \text{sdf\_func}(q)$ [S1, unofficial]. Compute gradient $\nabla d$ using finite differences [S3, unofficial]. Normalize to obtain $n = \nabla d / \|\nabla d\|$ [G]. Return $d$ and $n$ [S1, unofficial].
3.  **Tetrahedron Intersection Query**: Input tetrahedron vertices, `sdf_func`, output arrays for intersection times and normals, query count array, and `min_step_size` [S1, unofficial]. Call `tet_edge_intersections_SDF` [S1, unofficial]. Evaluate SDF at all 4 vertices [S1, unofficial]. Identify edges where the sign of the SDF value changes [S1, unofficial]. For each crossing edge, perform linear interpolation to find the intersection point $p$ and time $t$ [S1, unofficial]. Compute the normal at $p$ using `query_normal_SDF(p, sdf_func)` [S1, unofficial]. Store $t$ and $n$ in output arrays and increment query count [S1, unofficial].

### Pseudocode
```python
import math

class Vector3:
    def __init__(self, x, y, z):
        self.x = x
        self.y = y
        self.z = z
    def __add__(self, other):
        return Vector3(self.x + other.x, self.y + other.y, self.z + other.z)
    def __sub__(self, other):
        return Vector3(self.x - other.x, self.y - other.y, self.z - other.z)
    def __mul__(self, scalar):
        return Vector3(self.x * scalar, self.y * scalar, self.z * scalar)
    def length(self):
        return math.sqrt(self.x**2 + self.y**2 + self.z**2)
    def normalize(self):
        l = self.length()
        if l < 1e-8: return Vector3(0, 0, 1)
        return Vector3(self.x/l, self.y/l, self.z/l)

def lerp(a, b, t):
    return Vector3(a.x + (b.x - a.x) * t, a.y + (b.y - a.y) * t, a.z + (b.z - a.z) * t)

def is_valid_sdf_name(name):
    return name in ["sphere", "mandelbulb", "neural"]

def sdf_evaluate(name, point):
    if name == "sphere":
        return (point - Vector3(0,0,0)).length() - 1.0
    elif name == "mandelbulb":
        return evaluate_mandelbulb(point, power=8.0, scale=1.0, center=Vector3(0,0,0), bailout=2.0, max_iterations=20)
    return 0.0

def evaluate_mandelbulb(point, power, scale, center, bailout, max_iterations):
    z = Vector3((point.x - center.x)/scale, (point.y - center.y)/scale, (point.z - center.z)/scale)
    dr = 1.0
    r = 0.0
    for i in range(max_iterations):
        r = z.length()
        if r > bailout:
            break
        theta = math.acos(max(-1.0, min(1.0, z.z / r)))
        phi = math.atan2(z.y, z.x)
        dr = (r ** (power - 1.0)) * power * dr + 1.0
        zr = r ** power
        theta = theta * power
        phi = phi * power
        z = Vector3(
            zr * math.sin(theta) * math.cos(phi),
            zr * math.sin(theta) * math.sin(phi),
            zr * math.cos(theta)
        ) + Vector3((point.x - center.x)/scale, (point.y - center.y)/scale, (point.z - center.z)/scale)
    return (0.5 * math.log(r) * r / dr) * scale

class SDFQueryHandler:
    def __init__(self, name, min_step_size=1e-3):
        if not is_valid_sdf_name(name):
            raise RuntimeError(f"unknown SDF '{name}'")
        self.name = name
        self.min_step_size = min_step_size
        self.sdf_func = lambda p: sdf_evaluate(name, p)

    def query_normal(self, q):
        return query_normal_SDF(q, self.sdf_func)

    def query_intersections(self, tets):
        times = []
        normals = []
        for tet in tets:
            vals = [self.sdf_func(v) for v in tet]
            edges = [(0,1), (0,2), (0,3), (1,2), (1,3), (2,3)]
            for i, j in edges:
                d1, d2 = vals[i], vals[j]
                if d1 * d2 < 0:
                    t = d1 / (d1 - d2)
                    p = lerp(tet[i], tet[j], t)
                    n = query_normal_SDF(p, self.sdf_func)[1]
                    times.append(t)
                    normals.append(n)
        return times, normals

def query_normal_SDF(q, sdf_func):
    eps = 1e-4
    d = sdf_func(q)
    d_xp = sdf_func(Vector3(q.x + eps, q.y, q.z))
    d_xm = sdf_func(Vector3(q.x - eps, q.y, q.z))
    d_yp = sdf_func(Vector3(q.x, q.y + eps, q.z))
    d_ym = sdf_func(Vector3(q.x, q.y - eps, q.z))
    d_zp = sdf_func(Vector3(q.x, q.y, q.z + eps))
    d_zm = sdf_func(Vector3(q.x, q.y, q.z - eps))
    grad = Vector3((d_xp - d_xm) / (2*eps), (d_yp - d_ym) / (2*eps), (d_zp - d_zm) / (2*eps))
    norm = grad.length()
    if norm < 1e-8:
        return d, Vector3(0, 0, 1)
    return d, grad / norm
```

### Parameters
*   `min_step_size`: Minimum step size for ray marching or intersection refinement. Default: $10^{-3}$ [S1, unofficial].
*   `eps`: Finite difference step size for gradient computation. Default: $10^{-4}$ [S3, unofficial].
*   `max_batch`: Integer maximum batch size for inference. Default: $32^3$ (32,768 samples) [S2, unofficial].
*   `relaxation`: Constant factor for threshold definition. Value: $1.5$ [S2, unofficial].
*   `SDF clamp range`: $[-1.0, 1.0]$ [S3, unofficial].
*   `Gradient computation subset`: Only first 100 SDF values updated per iteration [S3, unofficial].
*   `scale`: Global scaling factor applied to input point offset and final distance [S4, unofficial].
*   `power`: Exponent for fractal mapping [S4, unofficial].
*   `bailout`: Maximum radius threshold to break iteration early [S4, unofficial].
*   `max_iterations`: Maximum number of fractal iterations [S4, unofficial].

### Edge Cases and Pitfalls
*   **Invalid SDF Name**: The SDF name is validated at construction time; if invalid, `std::runtime_error("unknown SDF '" + name + "')` is thrown [S1, unofficial].
*   **Zero Gradient**: If the gradient magnitude is near zero, the normal is undefined; a default normal or error handling is required [G].
*   **Numerical Stability**: In fractal SDFs (e.g., Mandelbulb), large radius values can cause overflow; a `bailout` threshold breaks iteration early [S4, unofficial].
*   **Precision**: Finite difference gradients are computed using a fixed `eps`; only the first 100 SDF values are updated per iteration for speed [S3, unofficial].

## Subtopics

### Batched SDF Inference
Batched SDF Inference optimizes the evaluation of SDF values for large sets of samples by processing them in chunks to manage memory usage and leverage GPU parallelism [S2, unofficial]. It is chosen when evaluating millions of points where individual kernel launches would incur excessive overhead [S2, unofficial]. Unlike single-point queries, this method disables gradients for the batch to save memory and computation if gradients are not immediately needed [S2, unofficial].
*   **Parameters**: `max_batch`: Integer maximum batch size for inference. Default: $32^3$ (32,768 samples) [S2, unofficial].
*   **Steps**:
    1.  Disable gradients for the sample batch [S2, unofficial].
    2.  Get total number of samples $N$ [S2, unofficial].
    3.  Initialize `head = 0` [S2, unofficial].
    4.  Loop while `head < N`:
        *   Extract sample subset from `head` to `min(head + max_batch, N)` [S2, unofficial].
        *   Decode/Evaluate SDF for the subset [S2, unofficial].
        *   Store results in column 3 of the samples array [S2, unofficial].
        *   Increment `head` by `max_batch` [S2, unofficial].
    5.  Return SDF values from column 3 [S2, unofficial].

### SDF Validity Check with Relaxation
SDF Validity Check with Relaxation classifies samples as "positive," "negative," or "valid" (near the surface) based on a relaxed threshold [S2, unofficial]. It is used during training or post-processing to identify points close to the zero-level set for loss computation or mesh extraction [S2, unofficial]. It differs from strict binary classification by allowing a margin around the surface defined by `voxel_size * relaxation` [S2, unofficial].
*   **Parameters**: `relaxation`: Constant factor for threshold definition. Value: $1.5$ [S2, unofficial].
*   **Steps**:
    1.  Identify **positive samples**: those where $d > \text{voxel\_size} \times \text{relaxation}$ [S2, unofficial].
    2.  Identify **negative samples**: those where $-d > \text{voxel\_size} \times \text{relaxation}$ [S2, unofficial].
    3.  Identify **valid samples**: those where $|d| \le \text{voxel\_size} \times \text{relaxation}$ [S2, unofficial].

### SDF Optimization via Finite Differences
SDF Optimization via Finite Differences optimizes SDF values and learnable weights (e.g., in deformable fields like FlexiCubes) by computing gradients of a mesh-extraction loss with respect to the SDF values using finite differences [S3, unofficial]. It is chosen when automatic differentiation is not available or when the SDF is represented as a discrete set of values rather than a neural network [S3, unofficial]. It updates only a subset of SDF values per iteration for speed [S3, unofficial].
*   **Parameters**:
    *   `eps`: Finite difference step size. Value: $10^{-4}$ [S3, unofficial].
    *   `SDF clamp range`: $[-1.0, 1.0]$ [S3, unofficial].
    *   `Gradient computation subset`: Only first 100 SDF values updated per iteration [S3, unofficial].
*   **Layout**:
    *   `beta`: Matrix<double, Dynamic, 12, RowMajor>, size num_cubes x 12 [S3, unofficial].
    *   `alpha`: Matrix<double, Dynamic, 8, RowMajor>, size num_cubes x 8 [S3, unofficial].
    *   `gamma`: VectorXd, size num_cubes [S3, unofficial].
*   **Steps**:
    1.  Initialize `beta`, `alpha`, `gamma` to zero. Add noise: `beta(i,j) += noise(rng)*0.1`, etc. [S3, unofficial].
    2.  Compute SDF gradients using finite differences with `eps=1e-4` [S3, unofficial].
    3.  Loop $i$ from 0 to $\min(100, \text{sdf.size()}) - 1$:
        *   Perturb `sdf[i] += eps`, extract mesh_plus, compute `loss_plus` [S3, unofficial].
        *   Perturb `sdf[i] -= 2*eps`, extract mesh_minus, compute `loss_minus` [S3, unofficial].
        *   Reset `sdf[i] += eps` [S3, unofficial].
        *   Compute `sdf_grad[i] = (loss_plus - loss_minus) / (2*eps)` [S3, unofficial].
    4.  Apply gradient step: `optimizer.step(sdf, sdf_grad)` [S3, unofficial].
    5.  Clamp SDF values to $[-1.0, 1.0]$ [S3, unofficial].

### Mandelbulb SDF Evaluation
Mandelbulb SDF Evaluation computes the distance to a Mandelbulb fractal, a 3D generalization of the Mandelbrot set [S4, unofficial]. It is chosen for generating complex, organic-looking fractal shapes [S4, unofficial]. It differs from analytic primitives by using iterative complex number mapping in 3D spherical coordinates [S4, unofficial].
*   **Parameters**:
    *   `scale`: Global scaling factor [S4, unofficial].
    *   `power`: Exponent for fractal mapping [S4, unofficial].
    *   `bailout`: Maximum radius threshold to break iteration [S4, unofficial].
    *   `max_iterations`: Maximum number of iterations [S4, unofficial].
*   **Formula**:
    $$ d = \frac{0.5 \cdot \log(r) \cdot r}{dr} \cdot \text{scale} $$
    where $r$ is the final radius and $dr$ is the derivative [S4, unofficial].
*   **Steps**:
    1.  Initialize $z = \frac{\text{point} - c}{\text{scale}}$, $dr = 1.0$, $r = 0.0$ [S4, unofficial].
    2.  Loop $i$ from 0 to `max_iterations - 1`:
        *   Update $r = \|z\|$ [S4, unofficial].
        *   If $r > \text{bailout}$, break [S4, unofficial].
        *   Compute spherical coordinates: $\theta = \arccos(z.z / r)$, $\phi = \operatorname{atan2}(z.y, z.x)$ [S4, unofficial].
        *   Update derivative: $dr = r^{\text{power} - 1} \cdot \text{power} \cdot dr + 1.0$ [S4, unofficial].
        *   Compute radial power $zr = r^{\text{power}}$ [S4, unofficial].
        *   Apply power to angles: $\theta = \theta \cdot \text{power}$, $\phi = \phi \cdot \text{power}$ [S4, unofficial].
        *   Update position: $z = zr \cdot (\sin\theta\cos\phi, \sin\theta\sin\phi, \cos\theta) + \frac{\text{point} - c}{\text{scale}}$ [S4, unofficial].
    3.  Return distance $d$ using the formula above [S4, unofficial].

## Operating characteristics

*   **Time Complexity**:
    *   Single point query: $O(1)$ for analytic primitives; $O(I)$ for fractals (where $I$ is max iterations) [S4, unofficial].
    *   Batched inference: $O(N/B)$ where $N$ is total samples and $B$ is batch size [S2, unofficial].
    *   Finite difference gradient: $O(3 \cdot K)$ where $K$ is the number of perturbed values (e.g., 100) [S3, unofficial].
*   **Memory Complexity**:
    *   Batched inference: $O(B)$ for the current batch [S2, unofficial].
    *   Neural SDF: Depends on network size [S1, unofficial].
*   **Measured Performance**:
    *   Not given in the sources.
*   **Strengths**:
    *   Flexibility to support various SDF types (analytic, neural, fractal) [S1, S4, unofficial].
    *   Batched inference improves throughput for large-scale queries [S2, unofficial].
    *   Relaxation allows for robust surface identification [S2, unofficial].
*   **Limitations**:
    *   Only the first 100 SDF values are updated per iteration for speed, limiting gradient coverage [S3, unofficial].
    *   Fractal evaluation is computationally expensive due to iterations [S4, unofficial].
*   **When to Use**:
    *   Use for ray marching in volume rendering where SDF values are needed per sample [S1, unofficial].
    *   Use batched inference for training or large-scale point cloud evaluation [S2, unofficial].
*   **When Not to Use**:
    *   Avoid finite difference optimization for large-scale SDFs due to $O(K)$ cost per gradient step [S3, unofficial].

## Background

*   **Origin**: The concept of SDFs dates back to early computational geometry, but their use in rendering and neural implicit surfaces has grown significantly with the advent of neural rendering and differentiable rendering [G].
*   **Development**:
    *   `SDFQueryHandler` and related structures are part of modern C++/Python rendering pipelines like `subgrid-marching` [S1, unofficial].
    *   Batched inference and relaxation techniques are common in neural SDF training frameworks like `DIST-Renderer` [S2, unofficial].
    *   Finite difference optimization for SDFs is used in deformable mesh extraction methods like `FlexiCubes` [S3, unofficial].
    *   Mandelbulb SDF evaluation is a classic technique in fractal rendering, implemented in various graphics libraries [S4, unofficial].
*   **Usage**: Used in ray marching, neural implicit surface reconstruction, and fractal generation [S1, S2, S3, S4, unofficial].
