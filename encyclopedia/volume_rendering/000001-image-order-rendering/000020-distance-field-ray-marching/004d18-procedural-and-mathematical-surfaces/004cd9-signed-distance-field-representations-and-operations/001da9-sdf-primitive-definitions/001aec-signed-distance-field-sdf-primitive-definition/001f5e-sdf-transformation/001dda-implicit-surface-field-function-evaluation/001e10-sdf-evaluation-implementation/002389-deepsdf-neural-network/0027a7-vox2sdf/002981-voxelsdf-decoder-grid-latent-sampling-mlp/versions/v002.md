# VoxelSDF Decoder (Grid Latent Sampling + MLP)

Also called: Latent Grid SDF, Voxel-conditioned SDF MLP

## Overview
The VoxelSDF Decoder predicts Signed Distance Function (SDF) values at arbitrary 3D query points by interpolating a gridded latent code and passing the result through a Multi-Layer Perceptron (MLP) [S1, unofficial]. It conditions the SDF prediction on local spatial context within a voxel grid rather than a single global latent vector [S1, unofficial].

## How it works
**Inputs and Outputs:**
- Input: A latent embedding tensor `embeddings` of shape `(batch_size, latent_dim, voxel_grid_size+1, voxel_grid_size+1, voxel_grid_size+1)` [S1, unofficial].
- Input: A query point tensor `points` of shape `(batch_size, num_points, 3)` [S1, unofficial].
- Output: An SDF value tensor of shape `(batch_size, num_points, 1)` [S1, unofficial].

**Data Structures:**
- `embeddings`: A 5D tensor storing latent vectors at grid vertices. The spatial dimensions have size `voxel_grid_size + 1` to support trilinear interpolation across `voxel_grid_size` cells [S1, unofficial].
- `points`: A 3D tensor of query coordinates.

**Parameters:**
- `latent_dim`: Dimension of the latent vectors. Default: 32 [S1, unofficial].
- `voxel_grid_size`: Spatial resolution of the latent grid. Default: 8 [S1, unofficial].
- `num_layers`: Number of residual blocks in the MLP. Default: 4 [S1, unofficial].
- `hidden_dim`: MLP hidden size. Default: 128 [S1, unofficial].

**Steps:**
1. **Grid Sampling (Interpolation):** For each query point $p = (x, y, z)$ in `points`, sample the corresponding latent vector $z_p$ from the `embeddings` grid using trilinear interpolation. The coordinates are mapped to $[-1, 1]$ such that grid corners correspond to $\pm 1$ when `align_corners=True` [G].
   $$ z_p = \text{trilinear\_sample}(\text{embeddings}, p, \text{padding\_mode}=\text{'zeros'}, \text{align\_corners}=\text{True}) $$
   The output of this step has shape `(batch_size, num_points, latent_dim)` [S1, unofficial].
2. **MLP Decoding:** Pass the sampled latent vector $z_p$ through the MLP to predict the SDF value. The provided code snippet passes the sampled latent tensor directly to the model, indicating the MLP is conditioned solely on the latent code [S1, unofficial].
   $$ \text{sdf} = \text{MLP}(z_p) $$
   The MLP consists of `num_layers` residual blocks with `hidden_dim` neurons [S1, unofficial].
3. **Output:** The output is the predicted SDF value for each query point [S1, unofficial].

**Pseudocode:**
```python
def lerp(a, b, t):
    return [a[i] * (1.0 - t) + b[i] * t for i in range(len(a))]

def VoxelSDFDecoder_Forward(embeddings, points, latent_dim, num_layers, hidden_dim):
    # embeddings: (batch_size, latent_dim, grid_size+1, grid_size+1, grid_size+1)
    # points: (batch_size, num_points, 3)
    batch_size, num_points = points.shape[0], points.shape[1]
    sampled_latents = []
    
    for b in range(batch_size):
        for n in range(num_points):
            p = points[b, n]
            # Map normalized coordinates [-1, 1] to grid indices [0, grid_size]
            grid_size = embeddings.shape[2] - 1
            idx = (p + 1.0) / 2.0 * grid_size
            idx = [max(0.0, min(v, grid_size)) for v in idx]
            
            i0 = [int(v) for v in idx]
            i1 = [i0[k] + 1 for k in range(3)]
            w = [idx[k] - i0[k] for k in range(3)]
            
            # Fetch 8 surrounding latent vectors (padding_mode='zeros')
            def get_latent(i, j, k):
                if 0 <= i <= grid_size and 0 <= j <= grid_size and 0 <= k <= grid_size:
                    return embeddings[b, :, i, j, k]
                return [0.0] * latent_dim
            
            v000 = get_latent(i0[0], i0[1], i0[2])
            v100 = get_latent(i1[0], i0[1], i0[2])
            v010 = get_latent(i0[0], i1[1], i0[2])
            v110 = get_latent(i1[0], i1[1], i0[2])
            v001 = get_latent(i0[0], i0[1], i1[2])
            v101 = get_latent(i1[0], i0[1], i1[2])
            v011 = get_latent(i0[0], i1[1], i1[2])
            v111 = get_latent(i1[0], i1[1], i1[2])
            
            # Trilinear interpolation
            c00 = lerp(v000, v100, w[0])
            c01 = lerp(v001, v101, w[0])
            c10 = lerp(v010, v110, w[0])
            c11 = lerp(v011, v111, w[0])
            c0 = lerp(c00, c10, w[1])
            c1 = lerp(c01, c11, w[1])
            z_p = lerp(c0, c1, w[2])
            sampled_latents.append(z_p)
            
    latent = [sampled_latents[b * num_points + n] for b in range(batch_size) for n in range(num_points)]
    latent = reshape(latent, (batch_size, num_points, latent_dim))
    sdf = MLP(latent, num_layers, hidden_dim)
    return reshape(sdf, (batch_size, num_points, 1))
```

**Edge Cases and Pitfalls:**
- **Boundary Conditions:** `padding_mode='zeros'` returns a zero latent vector for points outside the grid bounds, which may produce incorrect SDF predictions instead of extrapolating the surface [S1, unofficial].
- **Coordinate System:** `align_corners=True` requires query points to be normalized to $[-1, 1]$ so that grid corners map exactly to $\pm 1$ [G]. Mismatched ranges cause sampling errors [G].
- **Precision:** Trilinear interpolation is continuous and differentiable across the grid, but gradients vanish outside the grid bounds due to zero-padding [G].

## Subtopics

## Operating characteristics
- **Time Complexity:** $O(N \cdot D)$ for grid sampling and $O(N \cdot L \cdot H)$ for the MLP, where $N$ is query points, $D$ is `latent_dim`, $L$ is `num_layers`, and $H$ is `hidden_dim` [G].
- **Memory Complexity:** $O(V^3 \cdot D)$ for the latent grid, where $V$ is `voxel_grid_size` and $D$ is `latent_dim` [G].
- **Performance:** Efficient for real-time rendering due to small grid size and fast MLP inference on GPUs [G].
- **Strengths:** Captures local geometric details better than a single global latent vector [S1, unofficial].
- **Limitations:** Resolution is limited by `voxel_grid_size`; fine details smaller than the voxel size may be lost [G]. Interpolation artifacts may occur at grid boundaries [G].

## Background
The VoxelSDF Decoder is a variant of the DeepSDF approach that uses a voxel grid of latent codes instead of a single global code [S1, unofficial]. It was implemented in the VC-SDFGen repository [S1, unofficial].
