# Point Colorization via Projective SDF

Also called: Projective SDF Colorization, Projective SDF Filtering & Color Sampling

## Overview
Point Colorization via Projective SDF assigns RGB colors to a set of 3D points by projecting them into training views, filtering based on alpha confidence and projective depth consistency, and sampling the closest valid color from the rendered reference frames [S1, unofficial]. It differs from standard nearest-neighbor colorization by enforcing geometric consistency through a projective Signed Distance Field (SDF) metric, ensuring that sampled colors correspond to the visible surface rather than occluded geometry or background [S1, unofficial].

## How it works
**Inputs:**
- `pts`: Tensor of shape $(N, 3)$ containing 3D point coordinates in world space [S1, unofficial].
- `voxel_model`: A sparse voxel representation capable of rendering color, depth, and alpha [S1, unofficial].
- `cam_lst`: List of training camera objects, each providing `position`, `lookat`, `project`, and `render` methods [S1, unofficial].
- `args.alpha_thres`: Scalar threshold for alpha filtering (e.g., 0.5) [S1, unofficial].
- `args.use_mean`: Boolean flag to select mean depth (`True`) or median depth (`False`) from the renderer [S1, unofficial].

**Outputs:**
- `closest_color`: Tensor of shape $(N, 3)$ containing the assigned RGB color for each point [S1, unofficial].
- `closest_dist`: Tensor of shape $(N)$ containing the minimum projective SDF distance for each point [S1, unofficial].

**Data Structures:**
- `closest_color`: Initialized to $[0.5, 0.5, 0.5]$ for all points [S1, unofficial].
- `closest_dist`: Initialized to $+\infty$ for all points [S1, unofficial].
- `valid_pts_idx`: Indices of points currently considered valid, initially all points projected within the image bounds [S1, unofficial].

**Parameters:**
- `mode='bilinear'`: Interpolation mode for `grid_sample` [S1, unofficial].
- `align_corners=False`: Coordinate alignment setting for `grid_sample` to prevent edge bias [S1, unofficial].

**Algorithm Steps:**

1.  **Initialization**:
    Set `closest_color` to $0.5$ for all $N$ points. Set `closest_dist` to $+\infty$ for all $N$ points.

2.  **Iterate over Training Cameras**:
    For each camera `cam` in `cam_lst`:
    
    a.  **Render Reference Frame**:
        Call `render_pkg = voxel_model.render(cam, color_mode="sh0", output_depth=True, output_T=True)` [S1, unofficial].
        Extract `frame_color` from `render_pkg['color']` [S1, unofficial].
        Select `frame_depth`: if `args.use_mean` is true, use `render_pkg['raw_depth'][[0]]` (mean); otherwise, use `render_pkg['raw_depth'][[2]]` (median) [S1, unofficial].
        Compute `frame_alpha = 1 - render_pkg['raw_T']` [S1, unofficial].
        Get image dimensions $H, W$ from `frame_depth.shape[-2:]` [S1, unofficial].

    b.  **Project Points**:
        Compute projected UV coordinates: `pts_uv = cam.project(pts)` [S1, unofficial].
        Filter points outside the image bounds $[-1, 1]$:
        `filter_idx = torch.where((pts_uv.abs() <= 1).all(-1))[0]` [S1, unofficial].
        Update valid indices and points:
        `valid_pts_idx = filter_idx`
        `valid_pts = pts[filter_idx]`
        `pts_uv = pts_uv[filter_idx]`
        If `valid_pts` is empty, skip to the next camera [G].

    c.  **Alpha Filtering**:
        Sample alpha at projected UVs using bilinear interpolation:
        $$ \text{pts\_frame\_alpha} = \text{grid\_sample}(\text{frame\_alpha}.view(1,1,H,W), \text{pts\_uv}.view(1,1,-1,2), \text{mode}='bilinear', \text{align\_corners}=False).flatten() $$
        [S1, unofficial].
        Filter points with alpha below threshold:
        `filter_idx = torch.where(pts_frame_alpha > args.alpha_thres)[0]` [S1, unofficial].
        Update valid arrays:
        `valid_pts_idx = valid_pts_idx[filter_idx]`
        `valid_pts = valid_pts[filter_idx]`
        `pts_uv = pts_uv[filter_idx]`
        If `valid_pts` is empty, skip to the next camera [G].

    d.  **Compute Projective SDF Distance**:
        Sample frame depth at projected UVs:
        $$ \text{pts\_frame\_depth} = \text{grid\_sample}(\text{frame\_depth}.view(1,1,H,W), \text{pts\_uv}.view(1,1,-1,2), \text{mode}='bilinear', \text{align\_corners}=False).flatten() $$
        [S1, unofficial].
        Compute camera-space depth for each point:
        $$ \text{pts\_depth} = (\text{valid\_pts} - \text{cam.position}) \cdot \text{cam.lookat} $$
        [S1, unofficial].
        Compute absolute projective distance:
        $$ \text{pts\_dist} = |\text{pts\_frame\_depth} - \text{pts\_depth}| $$
        [S1, unofficial].

    e.  **Update Closest Color**:
        Identify points with smaller distance than current best:
        `filter_idx = torch.where(pts_dist < closest_dist[valid_pts_idx])[0]` [S1, unofficial].
        Update valid indices for this iteration:
        `valid_pts_idx = valid_pts_idx[filter_idx]`
        `pts_uv = pts_uv[filter_idx]`
        `pts_dist = pts_dist[filter_idx]`
        `valid_pts = valid_pts[filter_idx]`
        If `valid_pts` is empty, continue to next camera [G].
        
        Sample color at filtered UVs:
        $$ \text{pts\_color} = \text{grid\_sample}(\text{frame\_color}[None], \text{pts\_uv}.view(1,1,-1,2), \text{mode}='bilinear', \text{align\_corners}=False).squeeze().T $$
        [S1, unofficial].
        
        Update global closest arrays:
        `closest_dist[valid_pts_idx] = pts_dist`
        `closest_color[valid_pts_idx] = pts_color`
        [S1, unofficial].

3.  **Return**:
    Return `closest_color` and `closest_dist` [S1, unofficial].

**Pseudocode:**

```python
import torch
import torch.nn.functional as F

def point_colorization_via_projective_sdf(pts, voxel_model, cam_lst, args):
    """
    Args:
        pts: (N, 3) tensor of 3D points
        voxel_model: SparseVoxelModel with render method
        cam_lst: List of camera objects
        args: Object with alpha_thres, use_mean, bandwidth_vox
    Returns:
        closest_color: (N, 3) tensor
        closest_dist: (N,) tensor
    """
    N = pts.shape[0]
    closest_color = torch.full((N, 3), 0.5, dtype=torch.float32, device=pts.device)
    closest_dist = torch.full((N,), float('inf'), dtype=torch.float32, device=pts.device)
    
    for cam in cam_lst:
        # 1. Render reference frame
        render_pkg = voxel_model.render(cam, color_mode="sh0", output_depth=True, output_T=True)
        frame_color = render_pkg['color']
        
        if args.use_mean:
            frame_depth = render_pkg['raw_depth'][[0]]
        else:
            frame_depth = render_pkg['raw_depth'][[2]]
            
        frame_alpha = 1 - render_pkg['raw_T']
        H, W = frame_depth.shape[-2:]
        
        # 2. Project points
        pts_uv = cam.project(pts)
        
        # Filter points outside image bounds [-1, 1]
        valid_mask = (pts_uv.abs() <= 1).all(dim=-1)
        valid_indices = torch.where(valid_mask)[0]
        
        if valid_indices.numel() == 0:
            continue
            
        valid_pts = pts[valid_indices]
        pts_uv_valid = pts_uv[valid_indices]
        
        # 3. Alpha filtering
        # grid_sample expects coordinates in [-1, 1]
        pts_frame_alpha = F.grid_sample(
            frame_alpha.view(1, 1, H, W),
            pts_uv_valid.view(1, 1, -1, 2),
            mode='bilinear',
            align_corners=False
        ).flatten()
        
        alpha_mask = pts_frame_alpha > args.alpha_thres
        valid_indices = valid_indices[alpha_mask]
        valid_pts = valid_pts[alpha_mask]
        pts_uv_valid = pts_uv_valid[alpha_mask]
        
        if valid_indices.numel() == 0:
            continue
            
        # 4. Compute Projective SDF
        pts_frame_depth = F.grid_sample(
            frame_depth.view(1, 1, H, W),
            pts_uv_valid.view(1, 1, -1, 2),
            mode='bilinear',
            align_corners=False
        ).flatten()
        
        # Camera space depth: dot product of point offset and look-at vector
        pts_depth = (valid_pts - cam.position) @ cam.lookat
        
        # Absolute distance
        pts_dist = (pts_frame_depth - pts_depth).abs()
        
        # 5. Update closest
        # Compare with current closest_dist for these specific indices
        current_closest = closest_dist[valid_indices]
        update_mask = pts_dist < current_closest
        
        update_indices = valid_indices[update_mask]
        update_pts_uv = pts_uv_valid[update_mask]
        update_pts_dist = pts_dist[update_mask]
        
        if update_indices.numel() == 0:
            continue
            
        # Sample color
        pts_color = F.grid_sample(
            frame_color[None],
            update_pts_uv.view(1, 1, -1, 2),
            mode='bilinear',
            align_corners=False
        ).squeeze().T
        
        # Update global arrays
        closest_dist[update_indices] = update_pts_dist
        closest_color[update_indices] = pts_color
        
    return closest_color, closest_dist
```

**Edge Cases and Pitfalls:**
- **Precision**: Use `float32` for coordinates and depths to match typical rendering pipelines [S1, unofficial].
- **Boundaries**: Points projected exactly to the image edge may suffer from interpolation bias if `align_corners=True`; the method uses `align_corners=False` to mitigate this [S1, unofficial].
- **Degenerate Input**: If no training views cover a point (all projections outside bounds or low alpha), the point retains the initial color $[0.5, 0.5, 0.5]$ and distance $\infty$ [S1, unofficial].

## Operating characteristics
- **Time Complexity**: $O(N \cdot C)$, where $N$ is the number of points and $C$ is the number of training cameras. Each camera requires rendering and grid sampling operations proportional to $N$ [S1, unofficial].
- **Memory Complexity**: $O(N)$ for storing `closest_color` and `closest_dist` [S1, unofficial].
- **Strengths**: Robust to occlusion by using projective depth consistency; leverages existing sparse voxel rendering infrastructure [S1, unofficial].
- **Limitations**: Requires access to training views and their depth/alpha outputs; performance scales linearly with the number of cameras [S1, unofficial].

## Background
This method is part of the SVaR (Sparse Voxel Rasterization) pipeline for 3D reconstruction and colorization [S1, unofficial]. It builds on Per-Frame SDF Computation to assign colors to points derived from adaptive sparse voxels [S1, unofficial]. The approach was introduced in the context of efficient mesh extraction and colorization from sparse voxel representations [S1, unofficial].
