# Non-Uniform Scaling of SDFs

Also called: Anisotropic SDF Scaling, Non-Uniform Scaling of Signed Distance Functions

## Overview
Non-uniform scaling of Signed Distance Fields (SDFs) is a technique to transform an SDF primitive by scaling its axes by different factors, ensuring the ray marching algorithm does not overestimate the distance to the surface [S1, unofficial]. Unlike uniform scaling, which allows for exact distance compensation, non-uniform scaling distorts distances anisotropically; this method uses the minimum scaling factor as a conservative correction multiplier to guarantee distance underestimation, which is safe for ray marching convergence [S2, unofficial].

## How it works
**Inputs:**
- `samplePoint`: The 3D coordinate in world space where the SDF is being evaluated [S1, unofficial].
- `s`: A 3D vector `(s_x, s_y, s_z)` representing the non-uniform scaling factors for the X, Y, and Z axes [S1, unofficial].
- `baseSDF`: A function that evaluates the unscaled SDF [S1, unofficial].

**Outputs:**
- `dist`: The corrected signed distance value [S1, unofficial].

**Data Structures:**
- Not given in the sources.

**Steps:**
1. **Transform the sample point:** Divide the `samplePoint` by the scaling vector `s` [S1, unofficial]. This maps the world-space point into the local space of the unscaled primitive [S1, unofficial].
   $$ p_{local} = \frac{samplePoint}{s} = \left( \frac{x}{s_x}, \frac{y}{s_y}, \frac{z}{s_z} \right) $$
2. **Evaluate the base SDF:** Compute the distance in the local space using the unscaled primitive definition [S1, unofficial].
   $$ d_{local} = baseSDF(p_{local}) $$
3. **Apply correction factor:** Multiply the local distance by the minimum of the scaling factors [S1, unofficial].
   $$ dist = d_{local} \times \min(s_x, s_y, s_z) $$

**Formula:**
For a general SDF `someSDF` scaled by vector $s = (s_x, s_y, s_z)$, the transformed SDF $S_{scaled}(x, y, z)$ is:
$$ S_{scaled}(x, y, z) = someSDF\left(\frac{x}{s_x}, \frac{y}{s_y}, \frac{z}{s_z}\right) \times \min(s_x, s_y, s_z) $$

**Example Derivation (Unit Sphere):**
Consider a unit sphere scaled to half its size along the X-axis ($s_x=0.5, s_y=1, s_z=1$) [S1, unofficial][S2, unofficial].
The unscaled unit sphere SDF is $\sqrt{x^2 + y^2 + z^2} - 1$ [G].
Applying the non-uniform scaling formula:
1. Transform point: $(\frac{x}{0.5}, \frac{y}{1}, \frac{z}{1}) = (2x, y, z)$ [S1, unofficial].
2. Evaluate base SDF: $\sqrt{(2x)^2 + y^2 + z^2} - 1$ [S1, unofficial].
3. Multiply by min scaling factor: $\min(0.5, 1, 1) = 0.5$ [S1, unofficial].
Resulting corrected SDF:
$$ sphereSDF(x, y, z) = 0.5 \times \left( \sqrt{(2x)^2 + y^2 + z^2} - 1 \right) $$

**Pitfalls and Edge Cases:**
- **Overestimation Risk:** Non-uniform scaling cannot exactly compensate for distance distortion because the correction factor depends on the location of the closest point on the surface relative to the sampling point, which is unknown during evaluation [S1, unofficial][S2, unofficial]. Using the minimum scaling factor is a safe approximation that ensures the returned distance is never greater than the true distance (underestimation), preventing ray marching from skipping the surface [S1, unofficial][S2, unofficial].
- **Directional Variance:** The overestimation factor varies depending on where the sampling point and the closest surface point are located [S1, unofficial][S2, unofficial]. For the half-scaled sphere example, evaluating at $(2, 0, 0)$ with the naive unscaled formula yields 3, while the true distance is 1.5 [S1, unofficial][S2, unofficial].
- **Zero/Negative Scaling:** Scaling factors must be positive [G]. Zero or negative scaling breaks the geometric interpretation of the distance field and the validity of the minimum factor heuristic [G].

**Pseudocode:**
```python
def non_uniform_scaled_sdf(sample_point, scaling_factors, base_sdf):
    """
    Evaluates an SDF with non-uniform scaling.
    
    Args:
        sample_point: tuple or list of 3 floats (x, y, z)
        scaling_factors: tuple or list of 3 floats (sx, sy, sz)
        base_sdf: function that takes (x, y, z) and returns float distance
        
    Returns:
        float: The corrected signed distance
    """
    sx, sy, sz = scaling_factors
    
    # Step 1: Transform sample point to local space
    local_x = sample_point[0] / sx
    local_y = sample_point[1] / sy
    local_z = sample_point[2] / sz
    
    # Step 2: Evaluate base SDF in local space
    local_dist = base_sdf(local_x, local_y, local_z)
    
    # Step 3: Multiply by the minimum scaling factor
    min_scale = min(sx, sy, sz)
    corrected_dist = local_dist * min_scale
    
    return corrected_dist
```
