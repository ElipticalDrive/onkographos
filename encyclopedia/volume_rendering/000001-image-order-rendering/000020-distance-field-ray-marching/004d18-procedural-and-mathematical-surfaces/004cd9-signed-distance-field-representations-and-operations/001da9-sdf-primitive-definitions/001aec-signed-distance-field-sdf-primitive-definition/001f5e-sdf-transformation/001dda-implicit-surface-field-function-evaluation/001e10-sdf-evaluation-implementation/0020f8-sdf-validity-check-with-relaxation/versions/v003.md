# SDF Validity Check with Relaxation


## Overview
This method classifies Signed Distance Field (SDF) samples into positive, negative, and valid near-zero categories by applying a relaxation threshold scaled to the voxel size [S1, unofficial]. It solves the problem of ambiguous SDF magnitudes during ray marching by explicitly identifying samples near the zero-level set [G]. It differs from [Batched SDF Inference](2329-batched-sdf-inference.md) by focusing on post-evaluation validation rather than generation, and from [Eikonal SDF Refinement](4597-eikonal-sdf-refinement.md) by using a simple threshold check rather than solving the Eikonal equation for gradient correction [G].

## How it works
**Inputs:**
- `sdf_values`: Array of SDF values for a batch of samples [G].
- `voxel_size`: The spatial size of the voxel grid cell [G].
- `relaxation`: A dimensionless constant factor defining the validity threshold [S1, unofficial].

**Outputs:**
- `valid_mask`: Boolean array indicating which samples are within the valid relaxation band [G].
- `positive_mask`: Boolean array for samples with SDF > threshold [G].
- `negative_mask`: Boolean array for samples with SDF < -threshold [G].

**Data Structures:**
- `sdf_values`: 1D or N-dimensional array of floats [G].
- `valid_mask`, `positive_mask`, `negative_mask`: Boolean arrays of the same shape as `sdf_values` [G].

**Parameters:**
- `relaxation`: Default value is 1.5 [S1, unofficial].

**Steps:**
1. Calculate the relaxation threshold: $T = \text{voxel\_size} \times \text{relaxation}$ [S1, unofficial].
2. Identify positive samples: those where $\text{sdf} > T$ [S1, unofficial].
3. Identify negative samples: those where $-\text{sdf} > T$ (equivalent to $\text{sdf} < -T$) [S1, unofficial].
4. Identify valid samples: those where $|\text{sdf}| \le T$ [S1, unofficial].

**Pseudocode:**
```python
def check_valid(sdf_values, voxel_size, relaxation=1.5):
    """
    Classify SDF samples based on relaxation threshold.
    
    Args:
        sdf_values: Array of SDF values.
        voxel_size: Size of one voxel in world units.
        relaxation: Threshold factor (default 1.5).
        
    Returns:
        valid_mask: Samples near zero (|sdf| <= threshold).
        positive_mask: Samples far positive (sdf > threshold).
        negative_mask: Samples far negative (sdf < -threshold).
    """
    # Calculate threshold
    threshold = voxel_size * relaxation
    
    # Identify positive samples: SDF value > voxel_size * relaxation
    positive_mask = sdf_values > threshold
    
    # Identify negative samples: -SDF value > voxel_size * relaxation
    # Equivalent to sdf_values < -threshold
    negative_mask = -sdf_values > threshold
    
    # Identify valid samples: absolute SDF value <= voxel_size * relaxation
    valid_mask = abs(sdf_values) <= threshold
    
    return valid_mask, positive_mask, negative_mask
```

**Edge Cases and Pitfalls:**
- If `voxel_size` is zero, the threshold becomes zero, potentially misclassifying all non-zero values as invalid [G]. Guard against division by zero or invalid grid configurations [G].
- Precision issues near the threshold boundary may cause flickering if the SDF value oscillates around $T$ [G]. Consider using a small epsilon for floating-point comparisons if stability is required [G].

## Subtopics

### [Eikonal SDF Refinement](4597-eikonal-sdf-refinement.md)
Corrects inaccurate SDF values near the zero-level set by solving the Eikonal equation $|\nabla \phi| = 1$ over neighboring voxels. It sets itself apart by using an analytical solution to ensure the gradient magnitude is exactly 1, rather than just smoothing values. It builds on this method.
