# SDF Domain Manipulation Operators

Also called: Domain Manipulation Operators, SDF Modifiers, SDF domain transformations, Shape Transformations, Space Partitioning, pSomething operators

## Overview
SDF Domain Manipulation Operators are a family of functions that transform the input query position $\mathbf{p}$ before evaluating a base Signed Distance Function (SDF), thereby creating periodic, mirrored, reflected, or otherwise structured spatial patterns without altering the underlying primitive geometry [S1, unofficial][S3, unofficial]. Unlike [CSG Operations on Implicit Functions](1329-csg-operations-on-implicit-functions.md) which combine distance values arithmetically, or [SDF Rounding](1829-sdf-rounding.md) which shifts the distance scalar, these operators modify the coordinate space itself to partition the domain into cells [S1, unofficial][S3, unofficial]. They are distinct from [Elongation](2440-elongation.md), which adjusts the distance output based on coordinate offsets, and [Finite Repetition](2869-finite-repetition.md), which is a specific bounded implementation of domain repetition.

## Shared principles
All domain manipulation operators in this family follow a common structural pattern: they accept the query point $\mathbf{p}$ as an input (often passed by reference or as the first argument) and modify it in place to map the global coordinate to a local cell coordinate suitable for the base primitive [S1, unofficial][S3, unofficial].

1.  **Input Convention**: The position vector $\mathbf{p}$ is typically the first argument. For operators acting on subsets of dimensions, specific components are supplied (e.g., $\langle p.x \rangle$ or $\langle p.zx \rangle$) [S1, unofficial].
2.  **Cell Indexing**: Many operators return a cell index (or identifier) in addition to modifying $\mathbf{p}$ [S1, unofficial][S3, unofficial]. This index can be used for optional purposes such as random seeding or material identification. For cell index 0, $\mathbf{p}$ remains unchanged, and cells are centered on the origin, meaning objects do not need to be manually translated to fit the grid [S1, unofficial].
3.  **Coordinate Transformation**: The core mechanism involves mapping $\mathbf{p}$ to a local coordinate $\mathbf{p}'$ within a defined period or cell size. This is often achieved using modulo arithmetic, absolute values, or trigonometric rotations [S1, unofficial][S3, unofficial].
4.  **Evaluation**: The base SDF is evaluated at the transformed point $\mathbf{p}'$ [S1, unofficial][S3, unofficial].

## Subtopics

### [CSG Operations on Implicit Functions](1329-csg-operations-on-implicit-functions.md)
CSG Operations combine SDFs using boolean logic (union, intersection, difference) via arithmetic operators on distance values. It is chosen when constructing complex shapes from simple primitives is required. It builds on domain manipulation by handling the combination of distance fields resulting from spatial transformations.

### [SDF Rounding](1829-sdf-rounding.md)
SDF Rounding modifies the distance value by subtracting a radius $r$, effectively rounding edges. It is chosen for smoothing sharp features. It differs from domain operators by modifying the scalar output rather than the input coordinate space.

### [Elongation](2440-elongation.md)
Elongation shifts the query point's absolute coordinates by an elongation vector and adjusts the distance with the maximum negative coordinate offset. It is chosen for stretching shapes along axes. It is a post-processing step on the distance value, distinct from coordinate-only transformations.

### [Finite Repetition](2869-finite-repetition.md)
Finite Repetition creates a bounded grid of repeated SDF instances by limiting replication to a range $[-l, l]$. It is chosen when infinite tiling artifacts are undesirable. It differs from infinite repetition by clamping the cell index.

### Boolean Subtraction with Domain Repetition
Creates complex geometry by subtracting domain-repeated smaller objects from a non-repeated larger object (e.g., domain repeated cubes subtracted from a larger sphere) [S4, unofficial]. This combines domain repetition with subtracting distance fields from each other to create complex objects [S4, unofficial].

### Symmetry Y
Reflects an SDF across the XZ plane by taking the absolute value of the Y component of $\mathbf{p}$ [S5, unofficial].

### Symmetry X
Reflects an SDF across the YZ plane by taking the absolute value of the X component of $\mathbf{p}$ [S5, unofficial].

### Symmetry Z
Reflects an SDF across the XY plane by taking the absolute value of the Z component of $\mathbf{p}$ [S5, unofficial].

## Background
The concept of manipulating the domain of a Signed Distance Function to create complex patterns originated in the context of ray marching and procedural geometry generation. Early implementations focused on simple periodic repetitions and reflections to create textures and structures like grids and mirrors [S4, unofficial]. The "pSomething" naming convention (e.g., `pMod`, `pMirror`) is prevalent in GLSL-based ray marching shaders, popularized by community resources and unofficial repositories [S1, unofficial][S3, unofficial]. These operators allow for the creation of intricate scenes with minimal code overhead by reusing simple primitive definitions through spatial transformations [S6, unofficial].
