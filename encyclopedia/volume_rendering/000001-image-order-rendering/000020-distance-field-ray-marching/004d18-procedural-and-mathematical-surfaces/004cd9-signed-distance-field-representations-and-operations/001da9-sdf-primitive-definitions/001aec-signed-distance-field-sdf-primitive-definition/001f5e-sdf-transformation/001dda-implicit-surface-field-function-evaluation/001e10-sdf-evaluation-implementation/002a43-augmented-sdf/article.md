# Augmented SDF

Also called: Conservative SDF Construction from Bounding Volume, tilde f

## Overview
Augmented SDF is a conservative variant of a signed distance field (SDF) that accelerates field queries by embedding a bounding volume derived from the object's geometry. It solves the performance bottleneck of expensive SDF evaluations for points far from the surface by returning the distance to the bounding volume instead. It differs from sibling methods like [Batched SDF Inference](2329-batched-sdf-inference.md) by using geometric bounds rather than neural inference, and from [SDF Validity Check with Relaxation](2399-sdf-validity-check-with-relaxation.md) by providing a strict conservative bound rather than a relaxed validity region.

## How it works
**Inputs and Outputs:**
*   **Input:** The original SDF function $f(\mathbf{p})$, and a point set $P$ generated by Sphere Carving [S1].
*   **Output:** The augmented SDF function $\tilde{f}(\mathbf{p})$ (also denoted $f_e$).

**Data Structures:**
*   **Bounding Volume $\mathcal{B}$:** A geometric representation of the object's extent. It is constructed as the convex hull $H(P)$ of the point set $P$, or a union of convex polyhedra/ellipsoids derived from $P$ [S1]. The memory footprint is compact, embedded directly in the function definition, avoiding external acceleration structures like grids or octrees [S1].

**Parameters:**
*   **$\varepsilon$ (epsilon):** A small positive constant ensuring the 0-level set of $\tilde{f}$ matches $f$. Typical value: $0.01$ [S1].

**Steps:**
1.  **Bounding Volume Construction:** Compute the geometric convex hull $H(P)$ of the point set $P$ generated by Sphere Carving. This hull is guaranteed to contain the object $O$ ($O \subset H(P)$) [S1].
2.  **Query Optimization:** For a query point $\mathbf{p}$, compute the distance to the bounding volume $\mathcal{B}$, denoted $d(\mathbf{p}, \mathcal{B})$.
3.  **Conditional Evaluation:**
    *   If $d(\mathbf{p}, \mathcal{B}) > \varepsilon$, return $d(\mathbf{p}, \mathcal{B})$.
    *   Otherwise, return $f(\mathbf{p})$ [S1].

**Formula:**
The conservative SDF is defined as [S1]:
$$
\tilde{f}(\mathbf{p}) = 
\begin{cases} 
d(\mathbf{p}, \mathcal{B}) & \text{if } d(\mathbf{p}, \mathcal{B}) > \varepsilon \\
f(\mathbf{p}) & \text{otherwise}
\end{cases}
$$
Where:
*   $\mathbf{p}$ is the query point.
*   $\mathcal{B}$ is the bounding volume.
*   $d(\mathbf{p}, \mathcal{B})$ is the distance from $\mathbf{p}$ to $\mathcal{B}$.
*   $f(\mathbf{p})$ is the original SDF value.
*   $\varepsilon$ is the threshold constant [S1].

**Edge Cases and Pitfalls:**
*   **GPU Memory Access Patterns:** In per-pixel cost comparison visualizations (e.g., Sphere Tracing), artifacts may appear due to GPU memory access pattern inconsistencies when branching between the bounding volume check and the original SDF evaluation [S1].
*   **Conservativeness:** The bounding volume must strictly contain the object. The convex hull $H(P)$ is guaranteed to satisfy $O \subset H(P)$ if $P$ is derived correctly from Sphere Carving [S1].

## Subtopics

### Sphere Carving
The method used to generate the point set $P$ and empty spheres $S$ that define the bounding volume. It iteratively carves the space to find surface points. [Sphere Carving](1658-sdf-evaluation-implementation.md#sphere-carving)

### Convex Hull Construction
The geometric operation to create $H(P)$ from $P$. [Convex Hull](1658-sdf-evaluation-implementation.md#convex-hull)

## Operating characteristics
*   **Time Complexity:** The query time is $O(1)$ for points outside the bounding volume (distance to $\mathcal{B}$), and $O(T)$ for points inside, where $T$ is the cost of the original SDF $f$.
*   **Memory Complexity:** Compact. The bounding volume is embedded in the function definition, avoiding the memory overhead of external acceleration structures like grids or octrees [S1].
*   **Performance:** In tests with ~1 million queries in a box surrounding the object, $\tilde{f}$ performs 3.3 to 4.9 times faster on average than the base field $f$ [S1]. In Sphere Tracing scenarios, using a convex bound can provide up to a 50% speedup [S1].
*   **Strengths:** Fast queries for points far from the surface; compact memory footprint; compatible with other acceleration techniques like Sphere Tracing or Segment Tracing [S1].
*   **Limitations:** Requires pre-computation of the point set $P$ via Sphere Carving; potential artifacts in GPU visualizations due to memory access patterns [S1].
*   **When to use:** When the SDF evaluation is expensive and many queries occur outside the immediate vicinity of the surface.
*   **When not to use:** When the object is highly non-convex and the bounding volume becomes too loose, reducing the effectiveness of the early-out check.

## Background
Augmented SDF was introduced in the context of Sphere Carving, a method for constructing bounding volumes for SDFs. The technique leverages the property that the convex hull of points generated by Sphere Carving contains the object, allowing for a conservative approximation of the distance field. It is used in applications such as sphere tracing, polygonization, and simulation to accelerate field queries [S1].
