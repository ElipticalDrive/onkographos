# Triangular Prism Signed Distance Function

Also called: Signed Triangle Prism, Triangular Prism SDF, sdTriPrism

## Overview
Computes the signed distance from a 3D point to an equilateral triangular prism aligned with the Z-axis. It differs from general polyhedral SDFs by exploiting the symmetry of the equilateral base to provide a closed-form, branch-free solution using absolute values and max operations, avoiding iterative projection or complex geometric decomposition.

## How it works
**Inputs:**
- `p`: A 3D point $(p_x, p_y, p_z)$ in local space.
- `h`: A 2D parameter vector $(h_x, h_y)$ defining the prism geometry.
  - $h_x$: Half the side length of the equilateral triangle base.
  - $h_y$: Half the height of the prism along the Z-axis.

**Outputs:**
- `d`: The signed distance. Positive if outside, negative if inside.

**Data Structures:**
- None required beyond standard floating-point vectors.

**Steps:**
1.  Compute the absolute value of the input point to exploit symmetry: $q = |p|$.
    $$ q_x = |p_x|, \quad q_y = |p_y|, \quad q_z = |p_z| $$
2.  Calculate the distance to the triangular cross-section in the XY plane. The equilateral triangle is oriented with one vertex pointing along the positive X-axis (due to the absolute value transformation and specific coefficient arrangement).
    - Compute the distance to the vertical edge (X-direction):
      $$ d_{edge} = q_x \cdot \frac{\sqrt{3}}{2} + q_y \cdot \frac{1}{2} $$
      Note: The source uses the approximation $0.866025 \approx \frac{\sqrt{3}}{2}$ and $0.5 = \frac{1}{2}$.
    - Compute the distance to the horizontal edge (Y-direction):
      $$ d_{vert} = -q_y $$
      *Note: In the context of the `max` function below, this term effectively handles the "bottom" edge of the triangle in the transformed coordinate system.*
    - Combine these to get the radial distance from the triangle boundary:
      $$ d_{tri} = \max(d_{edge}, d_{vert}) - h_x \cdot 0.5 $$

      **Parameters:**
      - $0.866025 \approx \frac{\sqrt{3}}{2}$
      - $0.5 = \frac{1}{2}$

      **Pseudocode:**
      ```python
      def sdTriPrism(p: Vector3, h: Vector2) -> float:
          """
          Computes signed distance to triangular prism.
          p: input point (x, y, z)
          h: (h_x, h_y) where h_x is half-side, h_y is half-height
          """
          # Step 1: Absolute values for symmetry in Z and X (partially)
          q_x = abs(p.x)
          q_y = abs(p.y)
          q_z = abs(p.z)
          
          # Step 2: Distance to top/bottom faces
          d_z = q_z - h.y
          
          # Step 3: Distance to triangular cross-section
          # Note: Source [S2, unofficial] uses original p.y in the max calculation, not q_y.
          # This creates an asymmetric handling of the Y-axis relative to the triangle orientation.
          term1 = q_x * 0.866025 + p.y * 0.5
          term2 = -p.y
          d_xy = max(term1, term2) - h.x * 0.5
          
          # Step 4: Combine
          d = max(d_z, d_xy)
          
          return d
      ```

      **Edge Cases:**
      - $h_x = 0$ or $h_y = 0$: Degenerate to triangle or line. The formula still holds but distance may be inaccurate at boundaries if not handled with epsilon.
      - Precision: The constant $0.866025$ is an approximation. For higher precision, use $\cos(\pi/6)$ or $\frac{\sqrt{3}}{2}$.

## Operating characteristics
- **Time Complexity:** $O(1)$. Constant number of arithmetic operations.
- **Memory Complexity:** $O(1)$. No auxiliary data structures.
- **Strengths:** Extremely fast evaluation, suitable for real-time ray marching. No branching (using `max` and `abs`).
- **Limitations:** Only supports equilateral triangles. Orientation is fixed (aligned with Z, specific Y-axis asymmetry per source).

## Background
The function is a standard primitive in Signed Distance Field (SDF) ray marching, popularized by shader coding communities. It appears in collections like `glsl-sdf-primitives` [S2, unofficial] and is used in procedural geometry generation.
