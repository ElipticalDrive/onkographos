# Deforming SDF Sphere with Noise

Also called: Animated Noise SDF Sphere, Animated SDF Displacement, SDF Sphere with Noise Displacement, Signed Distance Field (SDF) Sphere with Noise Displacement

## Overview
This method defines an implicit surface by displacing the radius of a base sphere using animated procedural noise, creating a breathing, organic shape suitable for pyroclastic or fluid-like visual effects [S1, unofficial]. It distinguishes itself from static SDF primitives by combining a low-frequency sinusoidal "breathing" modulation with high-frequency fractal Brownian motion (fBM) and sinusoidal products to generate complex, time-varying surface topology [S1, unofficial].

## How it works
### Inputs and Outputs
*   **Inputs**:
    *   $\mathbf{p}$: The 3D point in world space to evaluate.
    *   $t$: The global animation time (`g_time`).
    *   `sphere_radius`: The base radius $R$ of the sphere.
    *   `noise_amplitude`: The scaling factor $A_{noise}$ for the displacement magnitude.
*   **Outputs**:
    *   $d(\mathbf{p})$: The signed distance from $\mathbf{p}$ to the deformed surface.

### Data Structures
No complex data structures are required. The method relies on scalar arithmetic and vector operations. The implementation assumes access to a standard `fractal_brownian_motion` function [S1, unofficial].

### Parameters
*   `sphere_radius` ($R$): Base radius. Typical value: $1.5$ [S1, unofficial].
*   `noise_amplitude` ($A_{noise}$): Displacement strength. Value not explicitly fixed in the source code snippet but used as a multiplier [S1, unofficial].
*   `g_time` ($t$): Global time variable, advancing per frame [S1, unofficial].

### Formulas
The signed distance is calculated as:
$$
d(\mathbf{p}) = \|\mathbf{p}\| - (r(t) + D(\mathbf{p}, t))
$$

Where:
1.  **Base Radius** $r(t)$:
    $$
    r(t) = R + A_{breath} \sin(\omega_{breath} t)
    $$
    With $A_{breath} = 0.25$ and $\omega_{breath} = 2.0$ [S1, unofficial].

2.  **Sinusoidal Displacement** $D_{sin}$:
    $$
    D_{sin} = \sin(16 x + \phi) \sin(16 y + \phi) \sin(16 z + \phi)
    $$
    Where $\phi = 6.0 t$ [S1, unofficial].

3.  **fBM Displacement** $D_{fbm}$:
    $$
    D_{fbm} = \text{fBM}(2\mathbf{p} + \mathbf{v}(t))
    $$
    Where $\mathbf{v}(t) = (t, 0.7t, 1.3t)$ [S1, unofficial].

4.  **Total Displacement** $D$:
    $$
    D = A_{noise} \left( 0.6 D_{sin} + 0.8 (D_{fbm} - 0.5) \right)
    $$
    The term $(D_{fbm} - 0.5)$ centers the fBM output, assuming it ranges roughly $[0, 1]$ [S1, unofficial].

### Steps
1.  Calculate the time-varying base radius $r$ using the sine wave modulation.
2.  Calculate the phase offset $\phi$ for the sinusoidal component.
3.  Compute the sinusoidal displacement $D_{sin}$ by multiplying three sine waves modulated by the point coordinates and phase.
4.  Compute the fBM displacement $D_{fbm}$ by evaluating the noise function at a scaled and time-shifted position.
5.  Combine the sinusoidal and fBM components into a total displacement $D$, weighted by `noise_amplitude`.
6.  Return the signed distance as the Euclidean norm of $\mathbf{p}$ minus the sum of the displaced radius $r$ and displacement $D$.

### Pseudocode
```python
def signed_distance(p: Vec3, g_time: float, sphere_radius: float, noise_amplitude: float) -> float:
    """
    Computes the signed distance for a deforming sphere with noise.
    
    Args:
        p: The 3D point to evaluate.
        g_time: Global animation time.
        sphere_radius: Base radius R.
        noise_amplitude: Scaling factor for displacement.
        
    Returns:
        Signed distance to the surface.
    """
    # 1. Base radius breathes over time
    r = sphere_radius + 0.25 * sin(g_time * 2.0)
    
    # 2. Phase for sinusoidal displacement
    phase = g_time * 6.0
    
    # 3. Sinusoidal displacement component
    sin_disp = sin(16.0 * p.x + phase) * sin(16.0 * p.y + phase) * sin(16.0 * p.z + phase)
    
    # 4. Fractal Brownian Motion displacement
    # Time-shifted position vector
    time_shift = Vec3(g_time, g_time * 0.7, g_time * 1.3)
    # Scaled position
    scaled_p = p * 2.0
    fbm = fractal_brownian_motion(scaled_p + time_shift)
    
    # 5. Total displacement
    # Note: fBM is assumed to be in [0, 1] range based on source usage (fbm - 0.5)
    displacement = noise_amplitude * (0.6 * sin_disp + 0.8 * (fbm - 0.5))
    
    # 6. Final SDF
    return p.norm() - (r + displacement)
```

### Edge Cases and Pitfalls
*   **fBM Range**: The formula assumes `fractal_brownian_motion` returns values in $[0, 1]$. If the implementation returns $[-1, 1]$, the centering term $(D_{fbm} - 0.5)$ will be incorrect, shifting the displacement bias [S1, unofficial].
*   **Precision**: High-frequency sine terms ($16x$) may cause precision issues if coordinates are large. Normalizing or clamping input coordinates might be necessary for stability in large scenes [G].
*   **Self-Intersection**: Large `noise_amplitude` values can cause the surface to fold over itself, leading to incorrect normals if computed via gradient, though the SDF value remains valid for ray marching [G].

## Operating characteristics
*   **Time Complexity**: $O(1)$ per point evaluation, dominated by the cost of the `fractal_brownian_motion` function and trigonometric operations.
*   **Memory Complexity**: $O(1)$, no auxiliary data structures.
*   **Strengths**: Extremely cheap to evaluate; no precomputation or storage required; produces organic, animated shapes suitable for real-time rendering.
*   **Limitations**: The displacement is purely procedural and may not match specific artistic references; high-frequency noise can alias if not filtered; the "breathing" effect is uniform and may look artificial if not tuned [S1, unofficial].
*   **When to use**: Real-time rendering of organic, animated spheres (e.g., lava balls, energy orbs) where performance is critical.
*   **When not to use**: When precise geometric control or static, non-repeating patterns are required.

## Background
This method originates from the "Kaboom_Diffusion" project by OmerNYU, which implements a ray-marched renderer using Signed Distance Fields (SDFs) [S1, unofficial]. It is part of a broader trend in real-time graphics of using procedural noise to animate implicit surfaces, avoiding the need for mesh deformation or texture animation [S1, unofficial]. The specific combination of sinusoidal products and fBM is used to create a "pyroclastic" look with overhangs and complex surface detail [S1, unofficial].
