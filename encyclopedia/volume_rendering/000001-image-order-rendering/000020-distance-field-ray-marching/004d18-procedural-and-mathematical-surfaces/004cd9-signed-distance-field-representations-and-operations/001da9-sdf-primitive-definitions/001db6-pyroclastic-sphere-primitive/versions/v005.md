# Pyroclastic Sphere Primitive

Also called: Pyroclastic noise primitive

## Overview
The Pyroclastic Sphere Primitive is a procedural signed distance field (SDF) primitive that generates organic, cloud-like or volcanic shapes by perturbing a base sphere's distance function with procedural noise [S1, unofficial]. It solves the problem of creating complex, non-convex volumetric structures with overhangs and disconnected density regions that cannot be achieved with simple analytical spheres [S1, unofficial]. It distinguishes itself from standard SDF primitives by adding a noise displacement term to the distance value, and from pure noise volumes by maintaining a coherent spherical base shape [S1, unofficial].

## How it works
**Inputs and Outputs:**
*   **Input:** World-space query point $\mathbf{p}$, sphere center $\mathbf{c}$, sphere radius $r$, noise function $m(\cdot)$, noise amplitude $A$, noise gamma $\gamma$, 2D displacement flag $d_{2D}$, voxel size $\mathbf{v}$, base density $\rho_0$.
*   **Output:** Density value $\rho(\mathbf{p})$.

**Data Structures:**
The primitive stores attributes: `radius` (float), `wsCenter` (Vector3), `fractal` (NoiseFunction object), `amplitude` (float), `gamma` (float), `density` (float), `displace2D` (bool).

**Steps:**
1.  **Transform to Local Space:** Map the world-space query point $\mathbf{p}$ to the sphere's local coordinate system, normalized by the radius:
    $$ \mathbf{lsP} = \frac{\mathbf{p} - \mathbf{c}}{r} $$
2.  **Determine Noise Sample Point:** Decide whether to use 3D or 2D displacement based on the flag $d_{2D}$:
    $$ \mathbf{nsP} = \begin{cases} \frac{\mathbf{lsP}}{\|\mathbf{lsP}\|} & \text{if } d_{2D} \text{ is true} \\ \mathbf{lsP} & \text{if } d_{2D} \text{ is false} \end{cases} $$
    *Note: If $\mathbf{lsP}$ is near zero, handle division by zero by clamping or returning a default normal [G].*
3.  **Evaluate Noise:** Compute the raw fractal noise value at $\mathbf{nsP}$:
    $$ n = m(\mathbf{nsP}) $$
4.  **Apply Gamma and Amplitude:** Scale and gamma-correct the noise value:
    $$ f = A \cdot n^{\gamma} $$
5.  **Compute Base Sphere Distance:** Calculate the signed distance from the origin in local space:
    $$ s = \|\mathbf{lsP}\| - 1.0 $$
6.  **Compute Filter Width:** Determine the antialiasing threshold based on the voxel size:
    $$ w_{filter} = \|\mathbf{v}\| $$
    $$ w_{thresh} = \frac{w_{filter} \cdot 0.5}{r} $$
7.  **Compute Pyroclastic Value:** Combine the sphere distance and noise, then apply a smoothstep-like fit to create a gradual transition:
    $$ v_{pyro} = \text{fit}(s - f, -w_{thresh}, w_{thresh}, 1.0, 0.0) $$
    Where $\text{fit}(x, a, b, c, d)$ maps $x$ from range $[a, b]$ to $[c, d]$. This is equivalent to $\text{smoothstep}(a, b, x)$ mapped to output range.
8.  **Compute Final Density:** Scale by the base density:
    $$ \rho(\mathbf{p}) = \rho_0 \cdot v_{pyro} $$

**Formulas:**
The core density calculation can be summarized as:
$$ \rho(\mathbf{p}) = \rho_0 \cdot \text{smoothstep}(-w_{thresh}, w_{thresh}, \|\frac{\mathbf{p}-\mathbf{c}}{r}\| - 1.0 - A \cdot m(\mathbf{nsP})^\gamma) $$

**Parameters:**
*   `radius`: Radius of the base sphere.
*   `amplitude`: Scaling factor for the noise displacement.
*   `gamma`: Gamma correction exponent for the noise function (typically $>1$ to darken shadows in noise).
*   `displace2D`: Boolean flag. If true, noise is evaluated on the sphere surface (2D displacement), preventing overhangs. If false, noise is evaluated in 3D space, allowing overhangs and disconnected density [S1, unofficial].
*   `density`: Base density multiplier.

**Edge Cases and Pitfalls:**
*   **Overhangs:** Using 3D displacement ($d_{2D} = \text{false}$) allows the noise to push the surface inward or outward independently along the ray, potentially creating disconnected density islands (overhangs) that may not be visible from the camera or may cause rendering artifacts [S1, unofficial]. Use 2D displacement ($d_{2D} = \text{true}$) to project the noise sample onto the sphere surface, ensuring displacement is constant along the normal vector and preventing disconnection [S1, unofficial].
*   **Singularity:** When $\mathbf{lsP}$ is near zero, normalization for 2D displacement fails. Clamp or handle this case [G].
*   **Antialiasing:** The `filterWidth` and `thresholdWidth` are crucial for smooth transitions. Ignoring them results in aliased, hard-edged noise artifacts [S1, unofficial].

**Pseudocode:**
```python
def pyroclastic_sphere_sample(p, c, radius, noise_func, amplitude, gamma, displace2d, voxel_size, base_density):
    # Step 1: Transform to local space
    ls_p = (p - c) / radius
    
    # Step 2: Determine noise sample point
    if displace2d:
        length = ls_p.length()
        if length < 1e-6:
            # Handle singularity: default to (1,0,0) or similar
            ns_p = Vector(1.0, 0.0, 0.0)
        else:
            ns_p = ls_p / length
    else:
        ns_p = ls_p
        
    # Step 3: Evaluate noise
    raw_noise = noise_func.eval(ns_p)
    
    # Step 4: Apply gamma and amplitude
    # Clamp raw_noise to [0, 1] if noise function can return negative values before gamma
    # Assuming noise_func returns [0,1] or similar positive range for gamma to work correctly
    fractal_func = amplitude * (raw_noise ** gamma)
    
    # Step 5: Compute sphere distance
    sphere_func = ls_p.length() - 1.0
    
    # Step 6: Compute filter width
    filter_width = voxel_size.length()
    threshold_width = (filter_width * 0.5) / radius
    
    # Step 7: Compute pyroclastic value using smoothstep-like fit
    # fit(x, a, b, c, d) maps x from [a,b] to [c,d]
    # Equivalent to: c + (d - c) * smoothstep(a, b, x)
    # Here c=1.0, d=0.0, so it's 1.0 - smoothstep(-threshold_width, threshold_width, sphere_func - fractal_func)
    val = sphere_func - fractal_func
    pyro_value = 1.0 - smoothstep(-threshold_width, threshold_width, val)
    
    # Step 8: Final density
    density = base_density * pyro_value
    
    return density

def smoothstep(edge0, edge1, x):
    t = clamp((x - edge0) / (edge1 - edge0), 0.0, 1.0)
    return t * t * (3.0 - 2.0 * t)

def clamp(v, min_val, max_val):
    if v < min_val: return min_val
    if v > max_val: return max_val
    return v
```

## Subtopics

### [Deforming SDF Sphere with Noise](1759-deforming-sdf-sphere-with-noise.md)
This method defines an implicit surface by displacing the radius of a base sphere using animated procedural noise, creating a time-varying organic shape. It distinguishes itself from static SDF primitives by combining a low-frequency sinusoidal "breathing" modulation with high-frequency fractal Brownian motion (fBM) and sinusoidal products to generate complex surface topology.

## Operating characteristics
*   **Time Complexity:** $O(1)$ per sample, dominated by the noise function evaluation.
*   **Memory Complexity:** $O(1)$, storing only primitive attributes.
*   **Strengths:** Generates complex, organic shapes with minimal parameters; supports antialiasing via smoothstep; 2D displacement prevents visual artifacts from overhangs.
*   **Limitations:** Limited to sphere-like base shapes; noise artifacts if parameters are not tuned; 3D displacement can cause disconnected density.
*   **When to use:** When organic, cloud-like, or volcanic volumetric shapes are needed within a sphere-like bounding volume.
*   **When not to use:** When precise control over non-spherical base geometry is required, or when disconnected density islands are undesirable and 2D displacement is too restrictive.

## Background
The Pyroclastic Sphere Primitive was introduced in the context of production volume rendering, specifically in the "Production Volume Rendering" seminar notes from the University of Freiburg [S1, unofficial]. It is designed to create "pyroclastic" looks, resembling volcanic clouds or dense smoke, by using noise as a displacement on a distance field [S1, unofficial]. The method builds on the principles of Signed Distance Field Representations and Operations [1578-sdf-primitive-definitions.md], using Boolean operations and transformations as defined in the parent article.
