# Pyroclastic Sphere Primitive


## Overview
The Pyroclastic Sphere Primitive is a procedural signed distance field (SDF) primitive that displaces a base sphere's surface using procedural noise to create organic, turbulent shapes with overhangs [S1, unofficial]. It distinguishes itself from static SDF primitives by combining a low-frequency sinusoidal "breathing" modulation with high-frequency fractal Brownian motion (fBM) and sinusoidal products to generate complex surface topology [S1, unofficial]. Unlike standard sphere primitives, it supports 2D displacement to prevent density disconnection, making it suitable for volumetric effects like smoke or lava [S1, unofficial].

## How it works
**Inputs:**
- World position $wsP$ of the sample point.
- World center $wsCenter$ of the sphere.
- Sphere radius $radius$.
- Voxel size $wsVoxelSize$ (for antialiasing).
- Noise function $m(P)$ (typically fBM).
- Parameters: $amplitude$, $gamma$, $displace2D$ (boolean), $density$.

**Outputs:**
- Sample density value.

**Data Structures:**
- No persistent data structures. All computations are per-sample.

**Steps:**
1. Transform world position to local space:
   $$lsP = \frac{wsP - wsCenter}{radius}$$
2. Determine noise sample point $nsP$:
   - If $displace2D$ is true: $nsP = \frac{lsP}{|lsP|}$ (project onto unit sphere).
   - Otherwise: $nsP = lsP$.
3. Evaluate fractal noise function at $nsP$:
   $$rawNoise = m(nsP)$$
4. Apply gamma correction and amplitude scaling:
   $$fractalFunc = amplitude \cdot \gamma(rawNoise)$$
   Where $\gamma(x)$ is the gamma correction function.
5. Compute sphere distance function:
   $$sphereFunc = |lsP| - 1.0$$
6. Compute filter width and threshold width:
   $$filterWidth = |wsVoxelSize|$$
   $$thresholdWidth = \frac{filterWidth \cdot 0.5}{radius}$$
7. Compute final pyroclastic value using smoothstep-like fitting:
   $$pyroValue = \text{fit}(sphereFunc - fractalFunc, -thresholdWidth, thresholdWidth, 1.0, 0.0)$$
   Where $\text{fit}(x, a, b, c, d)$ is equivalent to $\text{smoothstep}(a, b, x)$ mapped to range $[c, d]$. Specifically:
   $$t = \frac{x - a}{b - a}$$
   $$pyroValue = c + (d - c) \cdot t \cdot (2 - t) \quad \text{if } 0 < t < 1 \text{ else } c \text{ or } d$$
8. Set sample density:
   $$sample.value = density \cdot pyroValue$$

**Formula:**
The pyroclastic density is defined as:
$$pyroclasticDensity(P) = \max(radius - |P/radius| + |m(P)|, 0)$$
The final density is:
$$density = \text{smoothStep}(pyroclasticDensity, 0, 0.05)$$

**Parameters:**
- $displace2D$: Boolean flag to enable 2D displacement (projecting noise sample to sphere surface). Default: false [S1, unofficial].
- $radius$: Radius of the sphere primitive. Typical value: 1.0 [S1, unofficial].
- $amplitude$: Scaling factor for the noise function. Typical value: 0.1–0.5 [S1, unofficial].
- $gamma$: Gamma correction applied to noise function. Typical value: 2.2 [S1, unofficial].

**Edge Cases and Pitfalls:**
- Overhangs: Without 2D displacement, noise can cause density to disconnect from the main body. Use $displace2D$ to prevent this [S1, unofficial].
- Precision: Ensure $lsP$ is normalized correctly to avoid division by zero when $lsP$ is near zero.
- Antialiasing: Use $thresholdWidth$ based on voxel size to smooth transitions [S1, unofficial].

**Pseudocode:**
```python
def pyroclastic_sphere_sample(wsP, wsCenter, radius, wsVoxelSize, noise_func, amplitude, gamma, displace2D, density):
    # Step 1: Transform to local space
    lsP = (wsP - wsCenter) / radius
    
    # Step 2: Determine noise sample point
    if displace2D:
        nsP = lsP / length(lsP)
    else:
        nsP = lsP
    
    # Step 3: Evaluate fractal noise
    raw_noise = noise_func(nsP)
    
    # Step 4: Gamma correction and amplitude scaling
    fractal_func = amplitude * gamma_correction(raw_noise, gamma)
    
    # Step 5: Sphere distance function
    sphere_func = length(lsP) - 1.0
    
    # Step 6: Filter and threshold width
    filter_width = length(wsVoxelSize)
    threshold_width = (filter_width * 0.5) / radius
    
    # Step 7: Smoothstep fitting
    x = sphere_func - fractal_func
    pyro_value = smoothstep(-threshold_width, threshold_width, x)
    
    # Step 8: Set density
    sample_value = density * pyro_value
    
    return sample_value

def gamma_correction(x, gamma):
    return x ** (1.0 / gamma)

def smoothstep(edge0, edge1, x):
    t = max(0.0, min(1.0, (x - edge0) / (edge1 - edge0)))
    return t * t * (3.0 - 2.0 * t)
```

## Subtopics

### [Deforming SDF Sphere with Noise](1759-deforming-sdf-sphere-with-noise.md)
This method defines an implicit surface by displacing the radius of a base sphere using animated procedural noise, creating a time-varying organic shape. It distinguishes itself from static SDF primitives by combining a low-frequency sinusoidal "breathing" modulation with high-frequency fractal Brownian motion (fBM) and sinusoidal products to generate complex surface topology.

## Operating characteristics
- **Time Complexity:** O(1) per sample, as it involves a fixed number of arithmetic operations and a noise evaluation.
- **Memory Complexity:** O(1), no persistent data structures.
- **Performance:** Fast due to simple math and noise evaluation. Performance depends on the complexity of the noise function (e.g., fBM layers).
- **Strengths:** Creates organic, turbulent shapes; supports antialiasing via smoothstep; flexible via parameters.
- **Limitations:** Can produce disconnected density if 2D displacement is not used; noise evaluation can be costly if high-frequency details are required.
- **When to Use:** For volumetric effects requiring organic shapes, such as smoke, lava, or clouds.
- **When Not to Use:** For precise, smooth surfaces where noise artifacts are undesirable.

## Background
The Pyroclastic Sphere Primitive was introduced in "Production Volume Rendering" [S1, unofficial]. It is based on the concept of using distance functions combined with procedural noise to create complex shapes. The method is inspired by techniques described in Ebert et al.'s "Texturing & Modeling" [S1, unofficial]. It is commonly used in production volume rendering for creating natural-looking effects.
