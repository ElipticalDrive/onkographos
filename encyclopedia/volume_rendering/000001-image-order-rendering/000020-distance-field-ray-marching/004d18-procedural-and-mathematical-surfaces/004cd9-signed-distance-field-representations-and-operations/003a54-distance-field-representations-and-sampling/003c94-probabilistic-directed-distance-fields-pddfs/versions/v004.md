# Probabilistic Directed Distance Fields (PDDFs)

Also called: Probabilistic DDF

## Overview
Probabilistic Directed Distance Fields (PDDFs) are a variant of Directed Distance Fields (DDFs) designed to differentiably model the inherent discontinuities in the underlying field, specifically surface and occlusion discontinuities [S1, S2]. While standard DDFs output a single scalar depth value, PDDFs modify the formulation so that the network outputs probability distributions over rays rather than a single value, allowing a $C^1$ continuous neural network to represent the discontinuous field of a DDF [S1].

## How it works
**Inputs and Outputs**
*   **Input:** A query point $\mathbf{p} \in \mathbb{R}^3$ and a viewing direction $\mathbf{v} \in S^2$ [S1].
*   **Output:** A probability density function $P_{\mathbf{p},\mathbf{v}}(d)$ over depths $d \ge 0$, from which a final depth $d^*$ and visibility $\xi(\mathbf{p}, \mathbf{v})$ are derived [S1].

**Data Structures**
The network output is a density field representing a mixture of Dirac delta functions [S1]. For a fixed number of components $K$, the output consists of:
1.  **Mixture Weights:** A vector $\mathbf{w} = [w_1, w_2, \dots, w_K]$ where $w_i \ge 0$ and $\sum_{i=1}^K w_i = 1$ [S1].
2.  **Delta Locations:** A vector $\mathbf{d} = [d_1, d_2, \dots, d_K]$ where $d_i \ge 0$ [S1].

**Parameters**
*   $K$: The number of mixture components in the Dirac delta mixture. The typical value used in the source literature is $K=2$ [S1].

**Algorithm**
The PDDF is evaluated as follows:

1.  **Network Forward Pass:** Given input $(\mathbf{p}, \mathbf{v})$, the neural network outputs the mixture weights $\mathbf{w}$ and delta locations $\mathbf{d}$ [S1].
2.  **Probability Density Definition:** The probability density over depth is defined as:
    $$
    P_{\mathbf{p},\mathbf{v}}(d) = \sum_{i=1}^K w_i \delta(d - d_i)
    $$
    where $\delta(\cdot)$ is the Dirac delta function [S1].
3.  **Depth Selection:** The output depth $d^*$ is determined by selecting the delta component with the highest weight:
    $$
    i^* = \operatorname*{arg\,max}_{i} w_i
    $$
    $$
    d^* = d_{i^*}
    $$
    [S1].
4.  **Visibility:** The visibility field $\xi(\mathbf{p}, \mathbf{v})$ is handled separately and remains unchanged from the standard DDF formulation [S1].

**Pseudocode**
```python
def evaluate_pddf(network, p, v, K=2):
    """
    Evaluates a Probabilistic Directed Distance Field.
    
    Args:
        network: A neural network function that takes (p, v) and returns 
                 weights w and depths d.
        p: Query point (3D vector).
        v: Viewing direction (3D vector).
        K: Number of mixture components (default 2).
        
    Returns:
        d_star: The selected output depth.
        w: The full weight vector.
        d: The full depth vector.
    """
    w, d = network(p, v)
    i_star = max(range(K), key=lambda i: w[i])
    d_star = d[i_star]
    return d_star, w, d
```

**Edge Cases and Pitfalls**
*   **Discontinuous Output Depth:** Discontinuities in the output depth $d^*$ occur when the dominant weight $w_{i^*}$ switches from one delta location $d_i$ to another $d_j$ which may be arbitrarily far apart [S1].
*   **Smooth Transition Handling:** To handle the discontinuity in $d^*$ while maintaining a $C^1$ network, the weight field $\mathbf{w}(\mathbf{p}, \mathbf{v})$ is allowed to smoothly transition between indices at surface or occlusion discontinuities [S1]. This ensures the network remains differentiable even though the final selected depth $d^*$ is discontinuous [S1].
*   **Weight Normalization:** The weights $w_i$ must strictly sum to 1 [S1]. In implementation, this is typically enforced via a Softmax layer at the network output [G].

## Subtopics

### Bounded 3D Distance Texture Ray Marching
*   **What it is:** A method using bounded 3D distance textures for ray marching.
*   **Difference:** Uses explicit texture lookups for distance bounds rather than neural network outputs.
*   **When to choose:** When hardware acceleration for texture sampling is preferred over neural inference.
*   **Link:** [Bounded 3D Distance Texture Ray Marching](1115-bounded-3d-distance-texture-ray-marching.md)

### Sparse Point Set Haptic Rendering via Distance Field
*   **What it is:** Haptic rendering using distance fields derived from sparse point sets.
*   **Difference:** Focuses on haptic feedback and point-set based geometry rather than differentiable neural shape representation.
*   **When to choose:** For haptic simulation tasks with sparse data.
*   **Link:** [Sparse Point Set Haptic Rendering via Distance Field](17003-sparse-point-set-haptic-rendering-via-distance-field.md)

## Operating characteristics
*   **Time Complexity:** Not given in the sources [S1, S2].
*   **Memory Complexity:** Not given in the sources [S1, S2].
*   **Strengths:** Enables differentiable rendering of shapes with complex topology and occlusions by smoothing the training signal via probability distributions [S1, S2]. Allows extraction of classical unsigned distance fields and higher-order geometry (normals, curvatures) via network derivatives [S1].
*   **Limitations:** The output depth $d^*$ is still discontinuous, which can cause artifacts in rendering if not handled carefully during the final selection step [S1]. The method relies on neural network capacity to learn the weight transitions [S1].
*   **When to use:** When training neural implicit representations for 3D shapes, single-image 3D reconstruction, or generative modeling where differentiability is crucial [S1, S2].
*   **When not to use:** Not given in the sources [S1, S2].

## Background
Probabilistic Directed Distance Fields were introduced to address the difficulty of training differentiable neural networks with standard DDFs, which are inherently discontinuous functions of position and view direction [S1, S2]. The method is applied to single-shape fitting, unpaired 3D-aware generative image modeling, and single-image 3D reconstruction tasks [S1, S2].
