# Gouraud Shading

Also called: intensity interpolation shading, smooth shading

## Overview
Gouraud shading is a method for rendering smooth surfaces by computing lighting colors at mesh vertices and linearly interpolating these intensities across the resulting facets [S1][S2, unofficial]. It solves the problem of faceted appearance in polygonal approximations of curved surfaces by creating continuous color gradients [S2, unofficial]. Unlike Phong shading, which interpolates normals and recomputes lighting per pixel, Gouraud shading performs the lighting calculation only at vertices [S1].

## How it works
**Inputs:**
- A mesh defined by vertices $\mathbf{v}_i$ and faces (triangles) connecting them [G].
- Per-vertex normal vectors $\mathbf{n}_i$ [S2, unofficial].
- Light source direction $\mathbf{l}$ and view direction $\mathbf{v}$ (or camera position) [G].
- Material properties (diffuse color $C_d$, ambient color $C_a$) [G].

**Outputs:**
- A rasterized image with smooth color gradients across polygons [G].

**Data Structures:**
- **Vertex Buffer:** Stores position $\mathbf{p}_i$ and normal $\mathbf{n}_i$ for each vertex $i$ [G].
- **Index Buffer:** Defines triangles by referencing vertex indices [G].
- **Frame Buffer:** Stores the final interpolated color for each pixel [G].

**Steps:**
1. **Normal Averaging:** For curved surfaces, compute the normal $\mathbf{n}_i$ for each vertex $i$ by averaging the normals of all adjacent faces $F_j$ that share the vertex:
   $$ \mathbf{n}_i = \frac{\sum_{j \in \text{adj}(i)} \mathbf{n}_{F_j}}{\|\sum_{j \in \text{adj}(i)} \mathbf{n}_{F_j}\|} $$
   If normals are not averaged, the discontinuity in slope results in a faceted or gem-like appearance [S2, unofficial]. For planar surfaces, the same normal is applied to all defining vertices [S2, unofficial].

2. **Vertex Color Computation:** Determine a vertex color using the angle between the light source direction and the vertex normal vector [S2, unofficial]. The color is computed based on a lighting model and the vertex normals [S1]. Let $\mathbf{n}_i$ be the normalized vertex normal, $\mathbf{l}$ be the normalized light direction, and $\mathbf{v}$ be the view direction. The diffuse component is:
   $$ C_{diffuse, i} = C_d \cdot \max(0, \mathbf{n}_i \cdot \mathbf{l}) $$
   The total vertex color is:
   $$ C_i = C_a + C_{diffuse, i} $$
   [G].

3. **Rasterization and Interpolation:** For each triangle defined by vertices $i, j, k$, compute the barycentric coordinates $(\alpha, \beta, \gamma)$ for each pixel inside the triangle. Interpolate the color $C$ at the pixel:
   $$ C_{pixel} = \alpha C_i + \beta C_j + \gamma C_k $$
   [S1][S2, unofficial].

**Pseudocode:**
```python
def gouraud_shading(mesh, light_dir, ambient_color, diffuse_color, frame_buffer):
    # Step 1: Compute vertex normals
    vertex_normals = {}
    for face in mesh.faces:
        v0, v1, v2 = face.vertices
        edge1 = v1.pos - v0.pos
        edge2 = v2.pos - v0.pos
        face_normal = normalize(cross(edge1, edge2))
        for v in [v0, v1, v2]:
            if v.id not in vertex_normals:
                vertex_normals[v.id] = vec3(0.0, 0.0, 0.0)
            vertex_normals[v.id] += face_normal
    for v_id in vertex_normals:
        vertex_normals[v_id] = normalize(vertex_normals[v_id])

    # Step 2: Compute vertex colors
    vertex_colors = {}
    for v in mesh.vertices:
        n = vertex_normals[v.id]
        diff = max(0.0, dot(n, normalize(light_dir)))
        vertex_colors[v.id] = ambient_color + diffuse_color * diff

    # Step 3: Rasterize triangles
    for face in mesh.faces:
        v0, v1, v2 = face.vertices
        c0 = vertex_colors[v0.id]
        c1 = vertex_colors[v1.id]
        c2 = vertex_colors[v2.id]
        bbox_min = min(v0.pos, v1.pos, v2.pos)
        bbox_max = max(v0.pos, v1.pos, v2.pos)
        for y in range(int(bbox_min.y), int(bbox_max.y) + 1):
            for x in range(int(bbox_min.x), int(bbox_max.x) + 1):
                pixel_pos = vec2(float(x), float(y))
                alpha, beta, gamma = compute_barycentric(pixel_pos, v0.pos, v1.pos, v2.pos)
                if alpha >= 0.0 and beta >= 0.0 and gamma >= 0.0:
                    final_color = alpha * c0 + beta * c1 + gamma * c2
                    frame_buffer[x, y] = final_color

def compute_barycentric(p, v0, v1, v2):
    v0v1 = v1 - v0
    v0v2 = v2 - v0
    v0p = p - v0
    dot00 = dot(v0v2, v0v2)
    dot01 = dot(v0v2, v0v1)
    dot02 = dot(v0v2, v0p)
    dot11 = dot(v0v1, v0v1)
    dot12 = dot(v0v1, v0p)
    inv_denom = 1.0 / (dot00 * dot11 - dot01 * dot01)
    u = (dot11 * dot02 - dot01 * dot12) * inv_denom
    v = (dot00 * dot12 - dot01 * dot02) * inv_denom
    return 1.0 - u - v, u, v
```

**Parameters:**
- **Shading Model:** `GL_SMOOTH` (or equivalent) enables Gouraud shading; `GL_FLAT` disables it [S2, unofficial].
- **Normal Averaging:** Essential for curved surfaces [S2, unofficial].

**Edge Cases:**
- **Faceted Appearance:** Occurs if normals are not averaged for curved surfaces [S2, unofficial].

## Background
The method is also known as intensity interpolation shading [S1]. It is supported by OpenGL via `glShadeModel(GL_SMOOTH)` [S2, unofficial]. It is used in applications like Smokeview for visualizing fire dynamics simulation data, where smooth shading helps convey the three-dimensionality of blockages and iso-surfaces [S2, unofficial].
