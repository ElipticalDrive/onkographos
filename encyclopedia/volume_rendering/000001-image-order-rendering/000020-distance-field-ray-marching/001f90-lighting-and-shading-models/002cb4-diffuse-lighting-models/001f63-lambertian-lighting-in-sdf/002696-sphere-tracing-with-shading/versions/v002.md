# Sphere Tracing with Shading

Also called: Sphere Tracing with Shading | ronja-tutorials/ShaderTutorials

## Overview
This method extends sphere tracing by computing diffuse lighting on surfaces defined by Signed Distance Fields (SDFs) [S1, unofficial]. It solves the problem of rendering shaded geometry without explicit mesh topology by deriving surface normals via finite differences and applying a Lambertian lighting model in world space [S1, unofficial]. Unlike [Sphere Tracing Basics](52-sphere-tracing-basics.md), which returns a flat base color on hit, this method integrates a light direction and color to produce a shaded result [S1, unofficial].

## How it works
**Inputs and Outputs:**
*   **Input:** The fragment shader receives vertex position in local space (`localPosition`) and view direction (`viewDirection`) [S1, unofficial]. Shader properties include `_Color` (base color), `_WorldSpaceLightPos0` (light position/direction for directional lights), and `_LightColor0` (light intensity/color) [S1, unofficial].
*   **Output:** Final fragment color (RGBA) [S1, unofficial].

**Data Structures:**
*   **Constants:**
    *   `MAX_STEPS`: Integer, default 10 [S1, unofficial].
    *   `THICKNESS`: Float, default 0.01 [S1, unofficial].
    *   `NORMAL_EPSILON`: Float, default 0.01 [S1, unofficial].
*   **Matrices:** `unity_ObjectToWorld` (4x4), `unity_WorldToObject` (4x4) [S1, unofficial].

**Steps:**

1.  **Ray Initialization:** The vertex shader constructs the ray origin and direction in local object space using `unity_WorldToObject` [S1, unofficial].
2.  **Ray Marching Loop:** Iterate up to `MAX_STEPS` [S1, unofficial]. In each iteration, calculate the sample point $P = O + D \times progress$, evaluate the SDF $d = scene(P)$, and advance progress by $d$ [S1, unofficial]. If $d < THICKNESS$, the surface is hit and shading proceeds [S1, unofficial]. If iterations exceed `MAX_STEPS`, the fragment is discarded [S1, unofficial].
3.  **Normal Estimation:** Calculate the gradient of the SDF using central differences in local object space [S1, unofficial]. The resulting gradient vector is in local space, then transformed to world space using `unity_ObjectToWorld` with a w-component of 0 to exclude translation, and normalized [S1, unofficial].
4.  **Lighting Calculation:** Compute the diffuse lighting contribution by reading the world-space light direction from `_WorldSpaceLightPos0.xyz`, calculating the clamped dot product of the world-space normal and light direction, and multiplying by `_LightColor0` [S1, unofficial].
5.  **Material Composition:** Multiply the object's base color `_Color` by the computed light color to produce the final output [S1, unofficial].

**Pseudocode:**

```python
# Constants
MAX_STEPS = 10
THICKNESS = 0.01
NORMAL_EPSILON = 0.01

# Standard math helpers
def length(v):
    return (v[0]**2 + v[1]**2 + v[2]**2)**0.5

def normalize(v):
    l = length(v)
    return tuple(x / l for x in v) if l > 0 else (0.0, 0.0, 0.0)

def dot(a, b):
    return a[0]*b[0] + a[1]*b[1] + a[2]*b[2]

def saturate(x):
    return max(0.0, min(1.0, x))

def mul_matrix_vec(matrix, vec):
    return tuple(sum(matrix[r][c] * vec[c] for c in range(4)) for r in range(4))

# SDF Definition (Unit Sphere)
def scene(pos):
    return length(pos) - 0.5

# Normal Calculation
def get_normal(pos):
    eps = NORMAL_EPSILON
    change_x = scene((pos[0]+eps, pos[1], pos[2])) - scene((pos[0]-eps, pos[1], pos[2]))
    change_y = scene((pos[0], pos[1]+eps, pos[2])) - scene((pos[0], pos[1]-eps, pos[2]))
    change_z = scene((pos[0], pos[1], pos[2]+eps)) - scene((pos[0], pos[1], pos[2]-eps))

    gradient_local = (change_x, change_y, change_z)

    # Transform to world space (direction vector, w=0)
    gradient_world_4 = mul_matrix_vec(unity_ObjectToWorld, (gradient_local[0], gradient_local[1], gradient_local[2], 0))
    gradient_world = (gradient_world_4[0], gradient_world_4[1], gradient_world_4[2])

    return normalize(gradient_world)

# Lighting Calculation
def light_color(position):
    normal = get_normal(position)
    light_dir = normalize((_WorldSpaceLightPos0[0], _WorldSpaceLightPos0[1], _WorldSpaceLightPos0[2]))
    intensity = saturate(dot(normal, light_dir))
    return tuple(c * intensity for c in _LightColor0)

# Material Composition
def material(position):
    return tuple(c * l for c, l in zip(_Color, light_color(position)))

# Fragment Shader
def frag(v2f_input):
    pos = v2f_input.localPosition
    view_dir_world = normalize((v2f_input.viewDirection[0], v2f_input.viewDirection[1], v2f_input.viewDirection[2]))
    view_dir_local_4 = mul_matrix_vec(unity_WorldToObject, (view_dir_world[0], view_dir_world[1], view_dir_world[2], 0))
    view_dir_local = (view_dir_local_4[0], view_dir_local_4[1], view_dir_local_4[2])

    progress = 0.0

    for i in range(MAX_STEPS):
        sample_point = (pos[0] + view_dir_local[0]*progress, pos[1] + view_dir_local[1]*progress, pos[2] + view_dir_local[2]*progress)
        distance = scene(sample_point)

        if distance < THICKNESS:
            return material(sample_point)

        progress += distance

    return (0.0, 0.0, 0.0, 0.0)
```

**Parameters:**
*   `MAX_STEPS`: 10 [S1, unofficial].
*   `THICKNESS`: 0.01 [S1, unofficial].
*   `NORMAL_EPSILON`: 0.01 [S1, unofficial].

**Edge Cases and Pitfalls:**
*   **Depth Buffer:** Sphere-traced geometry does not write correct hardware depth [S1, unofficial]. The shader must use `Queue="Transparent"` and `ZWrite Off` to prevent incorrect occlusion by rasterized geometry [S1, unofficial].
*   **Batching:** Static and dynamic batching must be disabled (`DisableBatching="True"`) [S1, unofficial]. The vertex shader relies on `unity_WorldToObject` to construct the ray, which is only valid per-object and breaks under batching [S1, unofficial].

## Operating characteristics
*   **Time Complexity:** $O(N)$ where $N$ is the number of steps until hit or `MAX_STEPS` [S1, unofficial]. Each step requires one SDF evaluation [S1, unofficial]. Normal calculation requires 6 additional SDF evaluations per hit [S1, unofficial].
*   **Memory Complexity:** $O(1)$ auxiliary memory [S1, unofficial].
*   **Strengths:** No mesh required; smooth geometry at any resolution; simple implementation [S1, unofficial].
*   **Limitations:** Limited by `MAX_STEPS` (jagged edges if too low); normal estimation via finite differences is approximate and sensitive to `NORMAL_EPSILON`; no specular or complex lighting models included [S1, unofficial].
*   **When to use:** Simple shaded primitives where mesh overhead is undesirable [S1, unofficial].
