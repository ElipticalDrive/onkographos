# Sphere Tracing with Shading

Also called: Sphere Tracing with Shading | ronja-tutorials/ShaderTutorials

## Overview
This method extends sphere tracing by computing diffuse lighting on surfaces defined by Signed Distance Fields (SDFs). It solves the problem of rendering shaded geometry without explicit mesh topology by deriving surface normals via finite differences and applying a Lambertian lighting model in world space. Unlike [Sphere Tracing Basics](52-sphere-tracing-basics.md), which returns a flat base color on hit, this method integrates a light direction and color to produce a shaded result.

## How it works
**Inputs and Outputs:**
*   **Input:** Fragment shader receives vertex position in local space (`localPosition`) and view direction (`viewDirection`). Shader properties include `_Color` (base color), `_WorldSpaceLightPos0` (light position/direction for directional lights), and `_LightColor0` (light intensity/color).
*   **Output:** Final fragment color (RGBA).

**Data Structures:**
*   **Constants:**
    *   `MAX_STEPS`: Integer, default 10.
    *   `THICKNESS`: Float, default 0.01.
    *   `NORMAL_EPSILON`: Float, default 0.01.
*   **Matrices:** `unity_ObjectToWorld` (4x4), `unity_WorldToObject` (4x4).

**Steps:**

1.  **Ray Initialization:**
    Construct the ray origin and direction in local object space. The origin is the vertex position. The direction is the normalized view vector transformed from view space to local space using `unity_WorldToObject` [S1, unofficial].

2.  **Ray Marching Loop:**
    Iterate up to `MAX_STEPS`. In each iteration:
    *   Calculate the sample point: $P = O + D \times progress$.
    *   Evaluate the SDF: $d = scene(P)$.
    *   **Hit Test:** If $d < THICKNESS$, the surface is hit. Proceed to shading.
    *   **Step:** Advance progress: $progress \leftarrow progress + d$.
    *   **Miss Test:** If iterations exceed `MAX_STEPS`, discard the fragment.

3.  **Normal Estimation (Finite Differences):**
    To compute the surface normal at the hit point $P$, calculate the gradient of the SDF using central differences in local object space [S1, unofficial]:
    $$
    \begin{aligned}
    \Delta_x &= scene(P + (\epsilon, 0, 0)) - scene(P - (\epsilon, 0, 0)) \\
    \Delta_y &= scene(P + (0, \epsilon, 0)) - scene(P - (0, \epsilon, 0)) \\
    \Delta_z &= scene(P + (0, 0, \epsilon)) - scene(P - (0, 0, \epsilon))
    \end{aligned}
    $$
    where $\epsilon = NORMAL\_EPSILON$.
    The resulting gradient vector $G_{local} = (\Delta_x, \Delta_y, \Delta_z)$ is in local space. Transform it to world space $G_{world}$ using the object-to-world matrix, treating it as a direction (w=0) [S1, unofficial]:
    $$ G_{world} = normalize( mul(unity\_ObjectToWorld, float4(\Delta_x, \Delta_y, \Delta_z, 0)) ) $$

4.  **Lighting Calculation:**
    Compute the diffuse lighting contribution [S1, unofficial]:
    *   Get light direction $L$. For a directional light, $L = normalize(_WorldSpaceLightPos0.xyz)$.
    *   Compute diffuse intensity: $I = saturate(dot(G_{world}, L))$.
    *   Compute light color: $C_{light} = I \times _LightColor0$.

5.  **Material Composition:**
    Combine the base color with the lighting [S1, unofficial]:
    $$ Color = _Color \times C_{light} $$

**Pseudocode:**

```python
# Constants
MAX_STEPS = 10
THICKNESS = 0.01
NORMAL_EPSILON = 0.01

# SDF Definition (Unit Sphere)
def scene(pos):
    return length(pos) - 0.5

# Normal Calculation
def get_normal(pos):
    # Central differences in local space
    change_x = scene(pos + float3(NORMAL_EPSILON, 0, 0)) - scene(pos - float3(NORMAL_EPSILON, 0, 0))
    change_y = scene(pos + float3(0, NORMAL_EPSILON, 0)) - scene(pos - float3(0, NORMAL_EPSILON, 0))
    change_z = scene(pos + float3(0, 0, NORMAL_EPSILON)) - scene(pos - float3(0, 0, NORMAL_EPSILON))
    
    gradient_local = float3(change_x, change_y, change_z)
    
    # Transform to world space (direction vector, w=0)
    gradient_world = mul(unity_ObjectToWorld, float4(gradient_local, 0))
    
    return normalize(gradient_world)

# Lighting Calculation
def light_color(position):
    normal = get_normal(position)
    # Light direction for directional light
    light_dir = normalize(_WorldSpaceLightPos0.xyz)
    
    # Diffuse intensity
    intensity = saturate(dot(normal, light_dir))
    
    return intensity * _LightColor0

# Material Composition
def material(position):
    return _Color * light_color(position)

# Fragment Shader
def frag(v2f_input):
    # Ray setup in local space
    pos = v2f_input.localPosition
    # Transform view direction to local space
    view_dir_world = normalize(v2f_input.viewDirection)
    view_dir_local = mul(unity_WorldToObject, float4(view_dir_world, 0)).xyz
    
    progress = 0.0
    
    for i in range(MAX_STEPS):
        sample_point = pos + view_dir_local * progress
        distance = scene(sample_point)
        
        if distance < THICKNESS:
            return material(sample_point)
        
        progress += distance
        
    # Discard if max steps exceeded
    discard
```

**Parameters:**
*   `MAX_STEPS`: 10 [S1, unofficial].
*   `THICKNESS`: 0.01 [S1, unofficial].
*   `NORMAL_EPSILON`: 0.01 [S1, unofficial].

**Edge Cases and Pitfalls:**
*   **Depth Buffer:** Sphere-traced geometry does not write correct hardware depth. The shader must use `Queue="Transparent"` and `ZWrite Off` to prevent incorrect occlusion by rasterized geometry [S1, unofficial].
*   **Batching:** Static and dynamic batching must be disabled (`DisableBatching="True"`). The vertex shader relies on `unity_WorldToObject` to construct the ray, which is only valid per-object and breaks under batching [S1, unofficial].

## Operating characteristics
*   **Time Complexity:** $O(N)$ where $N$ is the number of steps until hit or `MAX_STEPS`. Each step requires one SDF evaluation. Normal calculation requires 6 additional SDF evaluations per hit.
*   **Memory Complexity:** $O(1)$ auxiliary memory.
*   **Strengths:** No mesh required; smooth geometry at any resolution; simple implementation.
*   **Limitations:** Limited by `MAX_STEPS` (jagged edges if too low); normal estimation via finite differences is approximate and sensitive to `NORMAL_EPSILON`; no specular or complex lighting models included [S1, unofficial].
*   **When to use:** Simple shaded primitives where mesh overhead is undesirable.
*   **When not to use:** Complex scenes requiring high-performance depth buffering or advanced lighting (specular, reflections) [S1, unofficial].
