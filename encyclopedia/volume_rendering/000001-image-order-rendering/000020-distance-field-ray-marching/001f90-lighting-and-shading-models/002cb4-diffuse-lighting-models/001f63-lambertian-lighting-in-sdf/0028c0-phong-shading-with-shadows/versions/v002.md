# Phong Shading with Shadows

Also called: Phong Relighting, Standard Illumination Model

## Overview
Phong Shading with Shadows calculates the final pixel color by combining diffuse and specular lighting contributions using the Phong reflection model, modulated by shadow factors to determine visibility [S2, unofficial]. It differs from its parent, Lambertian Lighting in SDF, by adding specular highlights and explicit shadow casting, and from its sibling, Sphere Tracing with Shading, by using a specific analytical reflection model rather than generic shading [G].

## How it works
**Inputs and Outputs:**
*   **Input:** Signed Distance Field (SDF) function $S(p)$, camera parameters, light source definitions, and material properties [S1, S2, unofficial].
*   **Output:** Final color $C$ for each pixel [S2, unofficial].

**Data Structures:**
The implementation uses two primary structures to define the scene and material properties [S2, unofficial]:
1.  `struct material`:
    *   `vec3 ka`: Ambient color constant.
    *   `float kd`: Diffuse reflection constant.
    *   `float ks`: Specular reflection constant.
    *   `float kp`: Shininess exponent (often denoted as $n$ in literature). Higher values result in smoother, shinier highlights [S1, unofficial].
2.  `struct light`:
    *   `vec3 c`: Light color/position.
    *   `float intensiv`: Light intensity.

**Numbered Steps:**
1.  **Ray Marching:** Perform sphere tracing through the SDF to find the intersection point $p$ on the surface [G]. If no intersection is found within the maximum distance, return the background color [G].
2.  **Surface Normal Recovery:** Calculate the surface normal $n$ at point $p$ by evaluating the gradient of the SDF and normalizing it [S1, unofficial]:
    $$ n = \frac{\nabla S(p)}{\|\nabla S(p)\|} $$
    Where $\nabla S(p)$ is approximated using finite differences or analytical derivatives if available [G].
3.  **Light Direction Calculation:** Compute the normalized light direction $l$ pointing from the surface point $p$ to the light [S2, unofficial]:
    $$ l = \text{normalize}(L[0].c - p) $$
    For a directional light, $l$ is constant; for a point light, $l$ varies per pixel [G].
4.  **Shadow Factor Computation:** Determine the shadow factor $sh$ by casting a shadow ray from $p$ towards the light source [S2, unofficial].
    *   **Hard Shadows:** $sh = 1$ if the ray does not intersect any geometry before reaching the light; $sh = 0$ otherwise [G].
    *   **Soft Shadows:** $sh$ is computed based on the distance to the nearest occluder relative to the light distance, creating penumbra effects [G].
5.  **Phong Reflection Model:** Calculate the diffuse and specular components [S2, unofficial]:
    *   **Diffuse:**
        $$ C_{diff} = k_d I \max(n \cdot l, 0) $$
        Where $I$ is the light intensity/color [S2, unofficial].
    *   **Specular:**
        First, compute the reflection vector $r$:
        $$ r = \text{reflect}(-v, n) $$
        Where $v$ is the view direction (from $p$ to camera) [G]. Then:
        $$ C_{spec} = k_s \max(r \cdot l, 0)^{k_p} $$
        The source formula applies $I$ only to the diffuse term, while $k_s$ scales the specular term directly [S2, unofficial].
6.  **Final Color:** Combine ambient, diffuse, specular, and shadow factors [S2, unofficial]:
    $$ C = (k_a + C_{diff} + C_{spec}) \times sh $$
    Where $k_a$ is the ambient color/intensity [S2, unofficial].

**Pseudocode:**
```python
import math

def get_surface_normal(sdf_func, p):
    eps = 1e-4
    dx = sdf_func(p + vec3(eps, 0, 0)) - sdf_func(p - vec3(eps, 0, 0))
    dy = sdf_func(p + vec3(0, eps, 0)) - sdf_func(p - vec3(0, eps, 0))
    dz = sdf_func(p + vec3(0, 0, eps)) - sdf_func(p - vec3(0, 0, eps))
    gradient = vec3(dx, dy, dz) / (2 * eps)
    return normalize(gradient)

def reflect(v, n):
    return v - 2 * dot(v, n) * n

def phong_shading_with_shadows(sdf_func, ray_origin, ray_direction, light, material, max_steps, max_dist):
    p = ray_origin
    t = 0.0
    
    # 1. Ray Marching
    for _ in range(max_steps):
        dist = sdf_func(p)
        if dist < 1e-4:
            break
        if t + dist > max_dist:
            return vec3(0, 0, 0)
        t += dist
        p += ray_direction * dist
    else:
        return vec3(0, 0, 0)

    # 2. Surface Normal Recovery
    n = get_surface_normal(sdf_func, p)
    
    # 3. Light Direction
    l = normalize(light.c - p)
    
    # 4. Shadow Factor
    shadow_pos = p + n * 1e-4
    shadow_t = 0.0
    shadow_hit = False
    for _ in range(max_steps):
        dist = sdf_func(shadow_pos)
        if dist < 1e-4:
            shadow_hit = True
            break
        if shadow_t > max_dist:
            break
        shadow_t += dist
        shadow_pos += l * dist
    sh = 0.0 if shadow_hit else 1.0
    
    # 5. Phong Reflection Model
    v = normalize(-ray_direction)
    ndotl = max(dot(n, l), 0.0)
    C_diff = material.kd * light.intensiv * ndotl
    
    r = reflect(-v, n)
    rdotl = max(dot(r, l), 0.0)
    C_spec = material.ks * (rdotl ** material.kp)
    
    # 6. Final Color
    C = (material.ka + C_diff + C_spec) * sh
    return C
```

**Parameters:**
*   $k_s$: Specular constant. Not given in the sources.
*   $k_d$: Diffuse constant. Not given in the sources.
*   $k_a$: Ambient constant. Not given in the sources.
*   $k_p$ (or $n$): Shininess constant. Higher values make the surface smoother and shinier [S1, unofficial]. Not given in the sources.

**Edge Cases and Pitfalls:**
*   **Self-Intersection:** When casting shadow rays, the ray origin must be offset along the normal to avoid hitting the surface it originated from [G].
*   **Gradient Approximation:** Finite difference approximation of the normal can be noisy if the SDF is not smooth or if $\epsilon$ is chosen poorly [G].
*   **Shadow Artifacts:** Hard shadows can cause aliasing [G].

## Subtopics

### [Lighting Transfer Function](6468-lighting-transfer-function.md)
A 2D lookup table storing ambient, diffuse, specular, and opacity enhancement components based on dot products of normalized gradient, light vector, and half-way vector, allowing various shading models to be evaluated at constant cost.

## Operating characteristics
*   **Time Complexity:** $O(N \cdot M)$ where $N$ is the number of pixels and $M$ is the number of ray march steps per pixel. Shadow casting adds another $M$ steps per lit pixel [G].
*   **Memory Complexity:** $O(1)$ per pixel if the SDF is analytical. If the SDF is voxel-based, $O(V)$ where $V$ is the volume size [G].
*   **Strengths:** Simple to implement, provides realistic specular highlights, easy to integrate with existing SDF renderers [G].
*   **Limitations:** Phong model is physically inaccurate (specular lobe shape), hard shadows can be aliased, normal approximation can be noisy [G].
*   **When to use:** Real-time rendering of smooth, shiny objects defined by SDFs [G].
*   **When not to use:** Physically based rendering requiring accurate microfacet models, or when soft shadows are critical and performance is not a constraint (use path tracing) [G].

## Background
The Phong shading model was introduced by Bui Tuong Phong in 1973 [G]. It is a widely used empirical shading model in computer graphics [G].
