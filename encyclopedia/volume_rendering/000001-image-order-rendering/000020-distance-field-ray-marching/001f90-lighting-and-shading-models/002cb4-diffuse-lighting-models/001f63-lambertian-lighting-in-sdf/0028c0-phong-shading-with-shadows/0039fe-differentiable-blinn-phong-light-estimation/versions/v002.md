# Differentiable Blinn-Phong Light Estimation

Also called: Differentiable Light Source Estimation via Blinn-Phong

## Overview
This method solves the inverse problem of estimating the position and intensity of point light sources given an observed image, known scene geometry, and material properties [S1, unofficial]. It formulates light estimation as an optimization problem that minimizes the photometric error between a rendered image and the target image using a differentiable rendering pipeline based on the Blinn-Phong model [S1, unofficial]. It distinguishes itself from sibling methods like [Lighting Transfer Function](6468-lighting-transfer-function.md) and its parent [Phong Shading with Shadows](4356-phong-shading-with-shadows.md) by explicitly modeling 3D point light sources and handling non-distant lighting parallax, whereas alternatives like Spherical Harmonics are limited to low-frequency or distant lighting approximations [S1, unofficial].

## How it works

### Inputs and Outputs
*   **Inputs:**
    *   Observed image $I^*$.
    *   Scene geometry $G = (X, N, C)$, where $X$ is the surface point, $N$ is the normal, and $C$ is the camera position [S1, unofficial].
    *   Material parameters $M = (k_d, k_s, \alpha)$, representing diffuse reflectance, specular reflectance, and shininess [S1, unofficial].
    *   Initial guess for light source parameters $L$ [S1, unofficial].
*   **Outputs:**
    *   Estimated light source parameters $L$ (position $L_i$ and intensity $I_{L,i}$) [S1, unofficial].

### Data Structures
The method operates on standard image and vector data structures [S1, unofficial]. No specific custom data structures (like VDB or BVH) are required beyond standard arrays for the image $I$, geometry maps (depth/normal), and the parameter vector $L$ [S1, unofficial].
*   $L$: A vector containing the parameters for all light sources. For a single point light, this includes position coordinates and intensity [S1, unofficial].
*   $I$: A 2D array representing the rendered image.
*   $S_i$: A scalar shadow term (1 if lit, 0 if shadowed) for each light $i$ at each pixel [S1, unofficial].

### Formulas
The Blinn-Phong image formation model is defined as [S1, unofficial]:

$$
I = k_d \cdot L_a + \sum_i S_i \cdot I_{L,i} \cdot \left( k_d \cdot (L_i - X)^t N + k_s \cdot (H^t N)^\alpha \right)
$$

Where:
*   $L_a$ is ambient illumination.
*   $k_d$ is diffuse reflectance.
*   $S_i$ is the shadow term for light $i$ (1 if the point is lit, 0 otherwise) [S1, unofficial].
*   $I_{L,i}$ is the intensity of light $i$ [S1, unofficial].
*   $L_i$ is the position of light $i$.
*   $X$ is the surface point.
*   $N$ is the surface normal.
*   $k_s$ is specular reflectance.
*   $\alpha$ is the shininess exponent.
*   $H$ is the halfway vector between the viewer direction $(C - X)$ and the light source vector $(L_i - X)$ [S1, unofficial].

The specular term $I_s$ is calculated as [S1, unofficial]:
$$
I_s = k_s \cdot \sum_i S_i \cdot (H^t N)^\alpha \cdot I_{L,i}
$$

The diffuse term $I_d$ for a directly lit point ($S_i=1$) is [S1, unofficial]:
$$
I_d = k_d \cdot \sum_i S_i \cdot (L_i - X)^t N \cdot I_{L,i}
$$

The photometric error $E$ to be minimized is the L2-norm of the difference between the rendered image $I$ and the observed image $I^*$ [S1, unofficial]:
$$
E = ||I - I^*||^2
$$

The gradient of the energy with respect to the illumination parameters $L$ is [S1, unofficial]:
$$
\frac{\partial E}{\partial L} = (I - I^*)^T \frac{\partial I}{\partial L}
$$

The total image Jacobian $\frac{\partial I}{\partial L}$ is approximated as [S1, unofficial]:
$$
\frac{\partial I}{\partial L} = \frac{\partial I_d}{\partial L} + \frac{\partial I_s}{\partial L} + (I_d + I_s) \cdot \frac{\partial S}{\partial L}
$$

### Parameters
*   **Learning rate:** 0.02 [S1, unofficial].
*   **Stopping condition:** Optimization stops when the relative energy change falls below $10^{-4}$ [S1, unofficial].
*   **Light intensity ($I_L$):** In experiments, set to the true value 0.5 [S1, unofficial].
*   **Material parameters (ideal):** $k_d = 1.0$, $k_s = 1.0$, $\alpha = 10$, $I_a = 0.5$ [S1, unofficial].

### Steps
1.  **Initialization:** Initialize the light source parameters $L$ to an initial guess [S1, unofficial].
2.  **Rendering:** Render an image $I$ using the current light source estimation $L$, geometry $G$, and materials $M$ [S1, unofficial]. This includes calculating shadows and specularities [S1, unofficial].
3.  **Error Calculation:** Compute the photometric error $E = ||I - I^*||^2$ [S1, unofficial].
4.  **Gradient Computation:** Compute the Jacobian matrix $\frac{\partial I}{\partial L}$ [S1, unofficial].
    *   The terms $\frac{\partial I_d}{\partial L}$ and $\frac{\partial I_s}{\partial L}$ are computed via automatic differentiation (e.g., PyTorch) using the chain rule on the differentiable parts of the Blinn-Phong model [S1, unofficial].
    *   The shadow Jacobian $\frac{\partial S}{\partial L}$ is approximated using finite differences [S1, unofficial]. This involves rendering six shadow maps around the current light source position estimation to numerically approximate the derivative [S1, unofficial].
5.  **Optimization:** Update $L$ using gradient descent with the computed gradient $\frac{\partial E}{\partial L}$. Repeat until convergence [S1, unofficial].

### Pseudocode

```python
import torch

def compute_shadow_term(X, L_pos, shadow_depth_buffer, bias=1e-3):
    """
    Compute binary shadow term S for each point.
    X: (B, 3) Surface points
    L_pos: (B, 3) Light positions
    shadow_depth_buffer: (B,) Depth values from light's perspective (pre-rendered)
    bias: float Shadow acne bias
    Returns: S: (B,) Shadow term (1.0 if lit, 0.0 if shadowed)
    """
    dist_to_light = torch.norm(X - L_pos, dim=1, keepdim=True)
    # Z-buffer comparison: point is lit if its distance to light is less than stored depth + bias
    S = (dist_to_light < shadow_depth_buffer + bias).float()
    return S

def estimate_light_source(I_star, X, N, C, kd, ks, alpha, La, L_init, shadow_depth_buffer, lr=0.02, tol=1e-4, max_iter=1000):
    """
    Estimate light source parameters using differentiable Blinn-Phong rendering.
    """
    L = torch.tensor(L_init, requires_grad=True, dtype=torch.float32)
    prev_E = None

    for i in range(max_iter):
        L_pos = L[:3]
        L_int = L[3]

        # Vector from surface to light and camera
        L_vec = L_pos - X
        C_vec = C - X

        # Halfway vector
        H = torch.normalize(L_vec + C_vec)

        # Diffuse term
        diff_dot = torch.sum(N * L_vec, dim=1, keepdim=True)
        I_d = kd * diff_dot * L_int

        # Specular term
        spec_dot = torch.sum(N * H, dim=1, keepdim=True)
        spec_pow = torch.pow(torch.clamp(spec_dot, min=0.0), alpha)
        I_s = ks * spec_pow * L_int

        # Shadow term (binary, non-differentiable)
        S = compute_shadow_term(X, L_pos, shadow_depth_buffer)

        # Rendered image
        I = kd * La + S * (I_d + I_s)

        # Photometric error
        E = torch.sum((I - I_star)**2)

        # Check stopping condition
        if prev_E is not None and abs(E - prev_E) / prev_E < tol:
            break
        prev_E = E

        # Gradient computation
        # 1. Differentiable parts (Id, Is) via autograd (S treated as constant)
        L.requires_grad_(True)
        I_diff = kd * La + S.detach() * (I_d + I_s)
        E_diff = torch.sum((I_diff - I_star)**2)
        grad_diff = torch.autograd.grad(E_diff, L, retain_graph=True)[0]

        # 2. Shadow Jacobian via finite differences (6 shadow maps)
        eps = 1e-3
        dS_dL = torch.zeros(3, dtype=torch.float32)
        for j in range(3):
            L_pos_plus = L_pos.clone()
            L_pos_plus[j] += eps
            S_plus = compute_shadow_term(X, L_pos_plus, shadow_depth_buffer)

            L_pos_minus = L_pos.clone()
            L_pos_minus[j] -= eps
            S_minus = compute_shadow_term(X, L_pos_minus, shadow_depth_buffer)

            dS_dL[j] = torch.mean(S_plus - S_minus) / (2 * eps)

        # 3. Combine Jacobian approximation: dI/dL = dId/dL + dIs/dL + (Id + Is) * dS/dL
        # Gradient of E w.r.t L: dE/dL = 2 * (I - I*) * dI/dL
        # The autograd already computed grad_diff = dE/dL for the differentiable part.
        # We add the shadow contribution: 2 * (I - I*) * (I_d + I_s) * dS/dL
        shadow_grad = 2.0 * (I - I_star) * (I_d + I_s) * dS_dL.unsqueeze(0).expand_as(I)
        grad_shadow = torch.sum(shadow_grad, dim=1)

        # Total gradient
        grad = grad_diff + grad_shadow

        # Optimization step
        L = L - lr * grad.detach()

    return L
```

### Edge Cases and Pitfalls
*   **Shadow Differentiability:** Shadow mapping is inherently non-differentiable due to the binary Z-buffer comparison. Approximating it with a smooth activation function (e.g., $\arctan(a.|z-d+b|)$) leads to degenerated gradients if the slope is too steep, or smooth shadows if too shallow. The authors were unable to find a working threshold for this approach [S1, unofficial].
*   **Shadow Map Quality:** Using coarse point-based rendering or incomplete depth maps for shadow maps results in incomplete or aliased shadows. This can disadvantage the method if the Phong model already fits the data well, as imperfect shadows may not provide useful gradients. However, imperfect shadows have proven effective for robustness in noisy scenarios [S1, unofficial].
*   **Lighting Models:** Spherical Harmonics (SH) and Haar wavelets are unsuitable for point light sources. SH recovers only low-frequency components, and Haar wavelets model only distant lighting (2D directions), failing to capture the localized angular nature or parallax of point lights [S1, unofficial].

## Operating characteristics

### Time and Memory Complexity
*   **Time:** Convergence is achieved in an average of one minute across 54 experiments (9 scenes, 6 light positions) [S1, unofficial]. Each iteration requires rendering the image and, for the shadow Jacobian approximation, rendering six additional shadow maps [S1, unofficial].
*   **Memory:** Memory usage is dominated by the storage of the image, geometry maps, and the shadow maps required for finite difference approximation.

### Measured Performance
*   **Ideal Reflectance:** The method performs similarly to state-of-the-art methods [2, 22] on ideal reflectance [S1, unofficial].
*   **Noisy Reflectance:** On noisy reflectance ($m=0.1$), the method achieved a success rate of 79.63% with an average error of 0.2100, compared to 5.56% success rate for [2] and 14.81% for [22] [S1, unofficial].
*   **Robustness:** The method systematically achieves better light source estimation in cases of incorrect reflectance estimation compared to alternatives [S1, unofficial].

### Strengths and Limitations
*   **Strengths:** Robust to noisy reflectance estimation; handles 3D point light sources and parallax; uses standard differentiable rendering pipelines (PyTorch).
*   **Limitations:** Relies on accurate geometry and material parameters; shadow approximation is computationally expensive (6 shadow maps per iteration); sensitive to shadow map quality (aliasing/incompleteness).

### When to Use
*   Use when estimating point light sources in scenes with known geometry and materials, especially when reflectance parameters may be noisy or imperfect.
*   Use when parallax effects from non-distant lights are significant.

### When Not to Use
*   Do not use if only distant lighting is present (consider SH or Haar wavelets).
*   Do not use if high-quality, complete depth maps and shadow maps are unavailable, as aliasing may degrade performance.

## Background

### Origin
The method was introduced in the paper "Robust Point Light Source Estimation Using Differentiable Rendering" [S1, unofficial].

### History and Development
The approach leverages automatic differentiation libraries (PyTorch) to create a differentiable rendering pipeline. It addresses the limitations of previous methods that struggled with noisy reflectance or could not model point light sources effectively. The authors explored various illumination models, including Spherical Harmonics and Haar wavelets, but found them unsuitable for point lights due to frequency and directional limitations [S1, unofficial].

### Applications
*   Light source estimation in computer vision and graphics.
*   Robust lighting estimation in the presence of noisy material parameters.
