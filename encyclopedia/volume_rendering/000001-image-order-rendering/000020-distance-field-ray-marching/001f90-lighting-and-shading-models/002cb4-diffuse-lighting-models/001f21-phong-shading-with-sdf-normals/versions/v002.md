# Phong Shading with SDF Normals

Also called: Phong Shading using SDF Gradients, normal vector interpolation shading

## Overview
Phong Shading with SDF Normals is a lighting model that applies the Phong reflection model to surfaces defined by Signed Distance Fields (SDFs) [S2, unofficial]. It solves the problem of realistic illumination for ray-marched geometry by computing surface normals via the SDF gradient and accumulating lighting contributions per fragment [S2, unofficial]. It differs from [Lambertian Lighting in SDF](2023-lambertian-lighting-in-sdf.md) by including specular highlights and from [Blinn-Phong Shading in Volume Rendering](2809-blinn-phong-shading-in-volume-rendering.md) by using the exact reflected light vector rather than the half-vector approximation [G].

## How it works
**Inputs and Outputs:**
*   **Input:** Ray origin $\mathbf{o}$, ray direction $\mathbf{d}$, scene SDF function $S(\mathbf{p})$, light positions $\mathbf{L}_j$, light intensities $\vec{i}_j$, material parameters $\vec{k}_d, \vec{k}_s, \alpha$, and viewer position $\mathbf{V}$ [G].
*   **Output:** Fragment color $C_{out}$ [G].

**Data Structures:**
*   **SDF Function:** A scalar field $S: \mathbb{R}^3 \to \mathbb{R}$ [G].
*   **Material Parameters:**
    *   $\vec{k}_d$: Diffuse reflection coefficient (RGB vector) [S2, unofficial].
    *   $\vec{k}_s$: Specular reflection coefficient (RGB vector) [S2, unofficial].
    *   $\alpha$: Shininess exponent (scalar) [S2, unofficial].

**Steps:**
1.  **Ray Marching:** March along the ray to find the intersection point $\mathbf{p}$ where $S(\mathbf{p}) \approx 0$ [G].
2.  **Normal Estimation:** Compute the surface normal $\hat{N}$ at $\mathbf{p}$ using the gradient of the SDF [S2, unofficial]:
    $$ \hat{N} = \frac{\nabla S(\mathbf{p})}{\|\nabla S(\mathbf{p})\|} $$
    [G] In practice, $\nabla S(\mathbf{p})$ is computed via central finite differences if an analytical gradient is unavailable:
    $$ \nabla S(\mathbf{p}) \approx \left( \frac{S(\mathbf{p} + \epsilon \hat{x}) - S(\mathbf{p} - \epsilon \hat{x})}{2\epsilon}, \frac{S(\mathbf{p} + \epsilon \hat{y}) - S(\mathbf{p} - \epsilon \hat{y})}{2\epsilon}, \frac{S(\mathbf{p} + \epsilon \hat{z}) - S(\mathbf{p} - \epsilon \hat{z})}{2\epsilon} \right) $$
    where $\epsilon$ is a small step size (e.g., $10^{-4}$) [G].
3.  **Lighting Loop:** Initialize $C_{out} = \vec{0}$ [G]. For each light $j$:
    a. Compute light direction: $\hat{L} = \frac{\mathbf{L}_j - \mathbf{p}}{\|\mathbf{L}_j - \mathbf{p}\|}$ [G].
    b. Compute view direction: $\hat{V} = \frac{\mathbf{V} - \mathbf{p}}{\|\mathbf{V} - \mathbf{p}\|}$ [G].
    c. Compute reflected light direction: $\hat{R} = 2(\hat{N} \cdot \hat{L})\hat{N} - \hat{L}$ [G].
    d. Calculate diffuse term: $D = \max(0, \hat{L} \cdot \hat{N})$ [S2, unofficial].
    e. Calculate specular term: $S_{pec} = \max(0, \hat{R} \cdot \hat{V})^\alpha$ [S2, unofficial].
    f. Accumulate contribution:
    $$ C_{out} += (\hat{L} \cdot \hat{N})(\vec{k}_s \odot \vec{i}_j) + (\hat{R} \cdot \hat{V})^\alpha (\vec{k}_d \odot \vec{i}_j) $$
    [S2, unofficial] The source formula explicitly assigns $\vec{k}_s$ to the diffuse dot product and $\vec{k}_d$ to the specular term.
    g. Clip negative dot products to zero before use [S2, unofficial].
4.  **Final Color:** Return $C_{out}$ [G].

**Pseudocode:**
```python
def phong_shading_sdf(p, N, lights, k_d, k_s, alpha, V):
    """
    p: hit point (vec3)
    N: normalized surface normal (vec3)
    lights: list of dicts with 'pos' (vec3) and 'intensity' (vec3)
    k_d: diffuse coefficient (vec3)
    k_s: specular coefficient (vec3)
    alpha: shininess (float)
    V: viewer position (vec3)
    """
    color = vec3(0.0)
    for light in lights:
        L = normalize(light['pos'] - p)
        V_dir = normalize(V - p)
        R = 2.0 * dot(N, L) * N - L
        
        # Clip negative dot products to zero [S2, unofficial]
        diff_dot = max(0.0, dot(L, N))
        spec_dot = max(0.0, dot(R, V_dir))
        
        # Accumulate contribution per source formula [S2, unofficial]
        color += diff_dot * (k_s * light['intensity']) + (spec_dot ** alpha) * (k_d * light['intensity'])
        
    return color
```

**Parameters:**
*   $\vec{k}_d$: Diffuse reflection coefficient (RGB vector) [S2, unofficial].
*   $\vec{k}_s$: Specular reflection coefficient (RGB vector) [S2, unofficial].
*   $\alpha$: Shininess exponent (scalar) [S2, unofficial].

**Edge Cases:**
*   If $\nabla S(\mathbf{p})$ is near zero (flat region or singularity), the normal is undefined [G]. Clamp the gradient magnitude or use a fallback normal [G].
*   If the ray does not intersect the SDF (no hit), return background color [G].

## Subtopics

### [SDF Phong Lighting](4260-sdf-phong-lighting.md)
Applies directional diffuse and specular lighting to text rendered via SDFs by using estimated surface normals and a configurable light angle. It differs from standard SDF rendering by accumulating Phong reflection terms per fragment rather than relying solely on distance-based alpha or simple shading. Choose it when specular highlights are desired for SDF-rendered objects [G].

## Operating characteristics
*   **Time Complexity:** Not given in the sources.
*   **Memory Complexity:** Not given in the sources.
*   **Strengths:** Provides realistic specular highlights and smooth shading on SDF geometry [G].
*   **Limitations:** Computationally expensive due to gradient estimation and multiple light evaluations [G]. Sensitive to SDF resolution for normal accuracy [G].
*   **When to use:** When specular highlights are desired for SDF-rendered objects [G].
*   **When not to use:** For performance-critical applications with many lights or low-end hardware [G].

## Background
Phong shading was introduced by Bui Tuong Phong in 1973 [G]. The application to SDFs is a modern adaptation for ray marching [G]. The specific formula and parameter usage described here are documented in a final project writeup for a computer graphics course [S2, unofficial]. The general concept of normal vector interpolation shading is described in the context of R-based isosurface rendering [S1].
