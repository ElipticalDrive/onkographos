# SDF Phong Lighting

Also called: SDF Directional Lighting, TextMeshPro Lighting

## Overview
SDF Phong Lighting applies directional diffuse and specular lighting to Signed Distance Field (SDF) text using estimated surface normals and a configurable light angle [S1, unofficial]. It builds on [Phong Shading with SDF Normals](1977-phong-shading-with-sdf-normals.md) by computing lighting contributions per fragment based on the Phong reflection model, using normals derived from the SDF gradient [S1, unofficial].

## How it works
**Inputs and Outputs:**
- **Input:** SDF value $d$, surface normal $\mathbf{n}$, base color $C_{base}$, and lighting parameters [S1, unofficial].
- **Output:** Final fragment color $C_{final}$ [S1, unofficial].

**Data Structures:**
- **Lighting Parameters:** A configuration struct containing:
  - `_LightAngle` (float): Light direction in radians (default 3.1416) [S1, unofficial].
  - `_SpecularColor` (vec3): Specular highlight color (default 1,1,1) [S1, unofficial].
  - `_SpecularPower` (float): Specular intensity multiplier (default 2.0) [S1, unofficial].
  - `_Reflectivity` (float): Specular shininess exponent (default 10) [S1, unofficial].
  - `_Diffuse` (float): Diffuse lighting factor (default 0.5) [S1, unofficial].
  - `_Ambient` (float): Ambient lighting factor (default 0.5) [S1, unofficial].

**Steps:**
1. **Compute Light Direction:** Derive the normalized light direction vector $\mathbf{l}$ from `_LightAngle` [S1, unofficial].
   $$ \mathbf{l} = (\cos(\text{\_LightAngle}), \sin(\text{\_LightAngle}), 0) $$
2. **Compute Specular Term:** Calculate the specular contribution using the Phong specular model [S1, unofficial].
   $$ \text{spec} = \text{pow}(\max(0, \mathbf{n} \cdot \mathbf{l}), \text{\_Reflectivity}) $$
3. **Scale Specular:** Multiply the specular term by `_SpecularColor` and `_SpecularPower` [S1, unofficial].
   $$ C_{spec} = \text{\_SpecularColor} \times \text{spec} \times \text{\_SpecularPower} $$
4. **Compute Diffuse Term:** Calculate the diffuse attenuation using a subtraction-based model [S1, unofficial].
   $$ C_{diff} = 1 - (\mathbf{n} \cdot \mathbf{l}) \times \text{\_Diffuse} $$
5. **Compute Ambient Term:** Apply an ambient term that varies based on the normal's Z-component [S1, unofficial].
   $$ C_{amb} = \text{lerp}(\text{\_Ambient}, 1, \mathbf{n}_z^2) $$
6. **Combine:** Multiply the base color by the diffuse and ambient terms, then add the specular term [S1, unofficial].
   $$ C_{final} = C_{base} \times C_{diff} \times C_{amb} + C_{spec} $$

**Pseudocode:**
```python
import math

class Vec3:
    def __init__(self, x, y, z):
        self.x, self.y, self.z = x, y, z
    def dot(self, other):
        return self.x * other.x + self.y * other.y + self.z * other.z
    def scale(self, s):
        return Vec3(self.x * s, self.y * s, self.z * s)
    def add(self, other):
        return Vec3(self.x + other.x, self.y + other.y, self.z + other.z)

def lerp(a, b, t):
    return a + (b - a) * t

def sdf_phong_lighting(n: Vec3, base_color: Vec3, light_angle: float, specular_color: Vec3, specular_power: float, reflectivity: float, diffuse: float, ambient: float) -> Vec3:
    # 1. Compute light direction from angle
    l = Vec3(math.cos(light_angle), math.sin(light_angle), 0.0)

    # 2. Compute specular term
    dot_nl = max(0.0, n.dot(l))
    spec = pow(dot_nl, reflectivity)
    specular_term = specular_color.scale(spec * specular_power)

    # 3. Compute diffuse term
    diffuse_factor = 1.0 - (dot_nl * diffuse)

    # 4. Compute ambient term
    ambient_factor = lerp(ambient, 1.0, n.z * n.z)

    # 5. Combine
    final_color = base_color.scale(diffuse_factor * ambient_factor).add(specular_term)

    return final_color
```

**Edge Cases and Pitfalls:**
- **Normal Degeneracy:** If $\nabla d$ is zero, normalization fails [G].
- **Negative Diffuse:** The formula $1 - (\mathbf{n} \cdot \mathbf{l}) \times \text{\_Diffuse}$ can produce negative lighting if $\mathbf{n} \cdot \mathbf{l}$ is large and $\text{\_Diffuse} > 1$ [G].
- **Light Angle Interpretation:** The source uses `_LightAngle` as a single float, implying a 2D direction [S1, unofficial].

## Subtopics

### SDF Glow Effect
Adds a colored glow around the text by computing a falloff function based on the signed distance and applying it to a glow color [S1, unofficial]. Parameters include `_GlowColor` (default 0,1,0,0.5), `_GlowOffset` (default 0), `_GlowInner` (default 0.05), `_GlowOuter` (default 0.05), and `_GlowPower` (default 0.75) [S1, unofficial]. Implementation calls `GetGlowColor(sd, scale)` and adds the result to the face color: `faceColor.rgb += glowColor.rgb * glowColor.a` [S1, unofficial].

## Operating characteristics
**Time and Memory Complexity:**
- **Time:** $O(1)$ per fragment, involving trigonometric functions, dot products, and power operations [G].
- **Memory:** $O(1)$ auxiliary storage for parameters and intermediate vectors [G].

**Measured Performance:**
- Not given in the sources.

**Strengths and Limitations:**
- **Strengths:** Simple to implement; provides visual depth to SDF text; configurable via scalar parameters [G].
- **Limitations:** Diffuse model is non-standard (subtraction-based); light direction is limited to a 2D angle in the source implementation; no shadowing is included [S1, unofficial].

**When to Use:**
- Use for 2D text rendering or simple volumes where a single directional light is sufficient [G].

**When Not to Use:**
- Do not use for physically based rendering or scenes requiring multiple lights, shadows, or complex material interactions [G].
