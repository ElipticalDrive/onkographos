# SDF Phong Lighting

Also called: SDF Directional Lighting, TextMeshPro Lighting

## Overview
SDF Phong Lighting applies directional diffuse and specular lighting to text rendered via Signed Distance Fields (SDFs) by using estimated surface normals and a configurable light angle [S1, unofficial]. It differs from standard SDF rendering by accumulating Phong reflection terms per fragment rather than relying solely on distance-based alpha or simple shading [S1, unofficial][S2].

## How it works
**Inputs and Outputs:**
*   **Inputs:** Signed distance value ($sd$), estimated surface normal ($n$), base face color ($col$), light direction angle ($\theta$), and shader parameters [S1, unofficial].
*   **Outputs:** Final shaded color ($col_{final}$) [S1, unofficial].

**Data Structures:**
No complex data structures are required beyond standard shader uniforms and local variables [G]. The normal $n$ is derived from the SDF gradient [S2].

**Parameters:**
*   `_LightAngle` (float, default 3.1416): Light direction in radians [S1, unofficial].
*   `_SpecularColor` (Color, default 1,1,1,1): Specular highlight color [S1, unofficial].
*   `_SpecularPower` (float, default 2.0): Specular intensity multiplier [S1, unofficial].
*   `_Reflectivity` (float, default 10): Specular shininess exponent [S1, unofficial].
*   `_Diffuse` (float, default 0.5): Diffuse lighting factor [S1, unofficial].
*   `_Ambient` (float, default 0.5): Ambient lighting factor [S1, unofficial].

**Steps:**
1.  Compute light direction from `_LightAngle` [S1, unofficial].
2.  Compute specular: $spec = \text{pow}(\max(0, n \cdot l), \text{Reflectivity})$ [S1, unofficial].
3.  Scale specular by `_SpecularColor` and `_SpecularPower` [S1, unofficial].
4.  Compute diffuse: $col_{diff} = 1 - (n \cdot l) \times \text{Diffuse}$, then apply $col = col \times col_{diff}$ [S1, unofficial].
5.  Compute ambient: $col_{amb} = \text{lerp}(\text{Ambient}, 1, n_z^2)$, then apply $col = col \times col_{amb}$ [S1, unofficial].
6.  Add specular to base color: $col_{final} = col + spec_{scaled}$ [S1, unofficial].

**Pseudocode:**
```python
def sdf_phong_lighting(n, col, light_angle, specular_color, specular_power, reflectivity, diffuse, ambient):
    # 1. Compute light direction from angle
    # Standard 2D mapping from angle in radians
    l = normalize(vec2(cos(light_angle), sin(light_angle)))
    
    # 2. Compute specular: spec = pow(max(0, dot(n, l)), Reflectivity)
    dot_nl = max(0.0, dot(n, l))
    spec = pow(dot_nl, reflectivity)
    
    # 3. Scale specular by SpecularColor and SpecularPower
    spec_scaled = specular_color * spec * specular_power
    
    # 4. Compute diffuse: col *= 1 - (dot(n, light) * Diffuse)
    col = col * (1.0 - (dot_nl * diffuse))
    
    # 5. Compute ambient: col *= lerp(Ambient, 1, n.z*n.z)
    n_z_sq = n.z * n.z if len(n) > 2 else 0.0
    col = col * lerp(ambient, 1.0, n_z_sq)
    
    # 6. Add specular to base color
    final_col = col + spec_scaled
    
    return final_col
```

**Edge Cases and Pitfalls:**
The formula uses $n_z$, implying a 3D normal vector [S1, unofficial]. If the SDF is strictly 2D, $n_z$ is 0, making the ambient term constant `Ambient` [G]. The diffuse formula $1 - (n \cdot l) \times \text{Diffuse}$ reduces color intensity as the light aligns with the normal, which is non-standard for diffuse lighting and may represent a stylistic shadowing effect [S1, unofficial]. Floating-point precision in the power operation may cause banding at high `_Reflectivity` values [G].

## Subtopics

### SDF Glow Effect
Adds a colored glow around the text by computing a falloff function based on the signed distance and applying it to a glow color [S1, unofficial]. Parameters include `_GlowColor` (default 0,1,0,0.5), `_GlowOffset` (default 0), `_GlowInner` (default 0.05), `_GlowOuter` (default 0.05), and `_GlowPower` (default 0.75) [S1, unofficial]. The implementation computes `glowColor = GetGlowColor(sd, scale)` and adds it to the face color: `faceColor.rgb += glowColor.rgb * glowColor.a` [S1, unofficial]. The `GetGlowColor` function implementation is not provided in the sources [S1, unofficial].

### Per-Fragment Phong Lighting with Gradient Normals
Volume shading enabled by the user, based on per-fragment Phong lighting where normal vectors are derived from the gradient of the scalar field [S2].
