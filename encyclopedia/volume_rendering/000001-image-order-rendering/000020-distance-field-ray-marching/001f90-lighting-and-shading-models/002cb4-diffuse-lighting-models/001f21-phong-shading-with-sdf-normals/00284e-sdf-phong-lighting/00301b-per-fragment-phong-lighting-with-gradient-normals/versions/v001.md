# Per-Fragment Phong Lighting with Gradient Normals

Also called: Gradient-based Phong Shading, Phong Lighting with Gradient Normals, Phong Shading with Gradient Normals

## Overview
This method applies per-fragment Phong or Gouraud shading to volume data by deriving surface normals from the gradient of the scalar field [S1, S2]. It provides a realistic 3D impression by combining these gradient-based normals with a light vector [S2]. It differs from standard SDF Phong lighting [SDF Phong Lighting] by explicitly calculating normals via finite differences of the scalar field rather than assuming a signed distance function, and it differs from Diffuse Lighting for Volume Ray Casting [Diffuse Lighting for Volume Ray Casting] by supporting specular highlights and a configurable Phong/Gouraud model rather than diffuse-only shading [S2].

## How it works
**Inputs and Outputs:**
*   **Input:** A 3D scalar field (density values), a threshold value, a light vector, and interpolation mode [S2].
*   **Output:** Shaded color for each fragment/voxel [S2].

**Data Structures:**
*   **Scalar Field:** A 3D grid of density values. The source specifies a range of 0 to 4095, implying 12-bit unsigned integer storage or similar fixed-point representation [S2].
*   **Light Vector:** A 3D vector that moves with the view vector [S2].

**Steps:**
1.  **Thresholding:** Determine if the current voxel's density value $D$ is above the specified threshold $T$. If $D \le T$, shading is not applied (or the voxel is treated as background/transparent depending on the broader rendering context) [S2].
2.  **Gradient Calculation:** Calculate the normal vector $\mathbf{n}$ at the current position using the gradients of the density values. This is typically done via finite differences [S2].
    *   Let $\nabla D = (\frac{\partial D}{\partial x}, \frac{\partial D}{\partial y}, \frac{\partial D}{\partial z})$.
    *   $\mathbf{n} = \frac{\nabla D}{\|\nabla D\|}$ [S2].
3.  **Lighting Model:** Calculate the shading color using the Phong or Gouraud model [S2].
    *   The Phong model includes diffuse and specular components. The Gouraud model interpolates colors across primitives (though in per-fragment volume rendering, this distinction often maps to whether specular highlights are computed per-fragment or per-vertex/voxel; the source notes highlights are an optional switch) [S2].
    *   The light vector $\mathbf{l}$ is used in the calculation [S2].
4.  **Interpolation:** When sampling the scalar field for gradient calculation or color retrieval, use either nearest neighbor or trilinear interpolation [S2].
5.  **Highlights:** If "Shading with Highlights" is enabled, include the specular component in the Phong calculation [S2].

**Parameters:**
*   **Threshold Value ($T$):** Selects the density region for shading. Range: 0 to 4095 [S2].
    *   Typical values: ~400 for skin, ~1700 for bones, 3200 for teeth [S2].
*   **Light Vector:** Moves with the view vector [S2].
*   **Interpolation Mode:** Nearest neighbor or trilinear [S2].

**Pseudocode:**
```python
def per_fragment_phong_gradient_shading(density_field, threshold, view_vector, interpolation_mode, enable_highlights):
    """
    density_field: 3D array of density values (0-4095)
    threshold: float, density threshold for shading
    view_vector: 3D vector, direction from camera to scene
    interpolation_mode: 'nearest' or 'trilinear'
    enable_highlights: bool
    """
    # Light vector moves with view vector. 
    # Assuming a standard setup where light is opposite to view or fixed relative to view.
    # Source says "light vector moves with the view vector". 
    # We assume a standard Phong lighting setup where light direction l is derived from view.
    # For implementation, let's assume a simple case: light is coming from the camera direction (view_vector normalized).
    # Or more commonly in such interactive viewers, light is fixed in world space or view space.
    # Given the ambiguity, we define l as the normalized view vector for this specific "moves with view" constraint.
    light_vector = normalize(view_vector) 
    
    # Get current voxel position and density
    # In a full ray marcher, this happens per sample. Here we assume per-fragment/voxel access.
    # Let pos be the current 3D coordinate in the grid.
    
    density = sample_scalar_field(density_field, pos, interpolation_mode)
    
    if density <= threshold:
        return background_color # Shading not applied below threshold
        
    # Calculate gradient using finite differences
    # Nearest neighbor interpolation for gradient calculation might be less accurate, 
    # but source allows choosing interpolation for shading colors. 
    # We assume trilinear is better for gradients if available, but source links interpolation to "calculating shading colors".
    # We will use the specified interpolation mode for sampling neighbors.
    
    dx = sample_scalar_field(density_field, pos + (1,0,0), interpolation_mode) - sample_scalar_field(density_field, pos - (1,0,0), interpolation_mode)
    dy = sample_scalar_field(density_field, pos + (0,1,0), interpolation_mode) - sample_scalar_field(density_field, pos - (0,1,0), interpolation_mode)
    dz = sample_scalar_field(density_field, pos + (0,0,1), interpolation_mode) - sample_scalar_field(density_field, pos - (0,0,1), interpolation_mode)
    
    gradient = (dx, dy, dz)
    normal = normalize(gradient)
    
    # Phong Lighting Model
    # Diffuse component
    diffuse = max(0, dot(normal, light_vector))
    
    # Specular component (only if highlights enabled)
    if enable_highlights:
        # Reflection vector r = 2 * dot(n, l) * n - l
        # View vector v is -light_vector in this specific "moves with view" context if light is from camera
        # Or if light is fixed, v is view direction. 
        # Source says light moves with view. Let's assume light is from camera.
        # Then view vector v is opposite to light_vector.
        view_dir = -light_vector
        reflection = 2 * dot(normal, light_vector) * normal - light_vector
        specular = pow(max(0, dot(reflection, view_dir)), 32) # Typical shininess
    else:
        specular = 0
        
    color = ambient + diffuse * diffuse_color + specular * specular_color
    return color
```

## Subtopics

### [Diffuse Lighting for Volume Ray Casting](6760-diffuse-lighting-for-volume-ray-casting.md)
A technique to illuminate a volume by calculating normals for every voxel using finite differences of the scalar field, then applying a diffuse lighting model. It is a subset of this method, lacking specular highlights and the configurable Phong/Gouraud model [Diffuse Lighting for Volume Ray Casting].

## Operating characteristics
*   **Time Complexity:** Linear with respect to the number of voxels/fragments processed. Gradient calculation requires 6 additional scalar field samples per voxel (or fewer if optimized) [S2].
*   **Memory Complexity:** Requires storage for the scalar field and potentially temporary buffers for gradients if precomputed, though per-fragment calculation keeps memory low [S2].
*   **Performance:** The method is interactive, as noted in the context of TF design tools [S1]. The choice of interpolation (nearest vs. trilinear) affects both accuracy and speed [S2].
*   **Strengths:** Provides realistic 3D shape perception through shading [S2]. Simple to implement using standard finite differences [S2].
*   **Limitations:** Can only visualize one tissue type at a time if used with a single threshold, unlike full volume rendering which assigns opacity to multiple ranges [S2]. Gradient noise in low-resolution or noisy data can lead to noisy normals [S2].
*   **When to use:** When a quick, realistic 3D view of a specific density range (e.g., bones) is needed without full volume integration [S2].
*   **When not to use:** When multiple tissue types with varying opacities need to be visualized simultaneously [S2].

## Background
This method originates from early volume visualization applications, specifically the "VOLUME RENDERING Application" by Thomas Lidy (2001-2002) [S2]. It was also employed in flexible transfer function design interfaces to provide immediate visual feedback during TF modification [S1]. The approach leverages the gradient of the scalar field as a proxy for surface normals, a common technique in volume shading to enhance shape perception [S1, S2].
