# Blinn-Phong Shading in Volume Rendering

Also called: Shaded Volume Rendering (SVR)

## Overview
Blinn-Phong Shading in Volume Rendering is a technique that applies the Blinn-Phong reflectance model to surface normals derived from a Signed Distance Function (SDF) during distance-field ray marching [S1, unofficial]. It differs from sibling methods by combining front-to-back volume integration with specular highlights, whereas [Phong Shading with SDF Normals](1977-phong-shading-with-sdf-normals.md) uses the Phong model and [Lambertian Lighting in SDF](2023-lambertian-lighting-in-sdf.md) restricts itself to diffuse lighting only.

## How it works
**Inputs and Outputs:**
*   **Input:** A 3D volume texture (`volumeTexture`) containing intensity data, a 1D transfer function texture (`tfTexture`), a uniform transform matrix, light position, light color, and shading parameters (diffuse, specular, ambient, shininess).
*   **Output:** A 2D image with accumulated color and alpha.

**Data Structures:**
*   **Uniforms:** A struct containing:
    *   `transform`: `mat4x4<f32>` for coordinate transformation.
    *   `lightPos`: `vec3<f32>` light position.
    *   `lightColour`: `vec3<f32>` light color.
    *   `diffuse`: `f32` diffuse multiplier.
    *   `specular`: `f32` specular multiplier.
    *   `ambient`: `f32` ambient multiplier.
    *   `tfSize`: `f32` size of the transfer function texture.
*   **Textures:**
    *   `volumeTexture`: `texture_3d<f32>` at binding 0.
    *   `volumeSampler`: sampler at binding 1.
    *   `tfTexture`: `texture_1d<f32>` at binding 3.

**Steps:**

1.  **Ray Generation:**
    Generate a full-screen triangle using vertex indices to produce positions $(-1, 3)$, $(-1, -1)$, and $(3, -1)$ in clip space [S1, unofficial]. For each fragment, transform the screen coordinate $(coord.xy, 0.0, 1.0)$ by the uniform transform matrix to get the ray origin $\mathbf{pos}$, and transform $(0.0, 0.0, 1.0, 0.0)$ to get the ray direction $\mathbf{dir}$ [S1, unofficial].

2.  **Ray-Box Intersection:**
    Compute entry (`near`) and exit (`far`) distances by calculating the inverse direction, bounding box distances, and taking the min/max of axis intersections. Clamp `near` to 0 if negative [S1, unofficial].

3.  **Ray Marching Loop:**
    Iterate from `near` to `far`. For each step:
    *   Transform the current position using the uniform matrix.
    *   Normalize coordinates to the $[0, 1]$ range.
    *   Sample the 3D volume texture at these coordinates.
    *   Convert the RG8 format sample to a normalized 16-bit intensity value:
        $$ \text{intensity} = \frac{\text{sample}.x + \text{sample}.y \times 255}{256} $$
        [S1, unofficial]

4.  **Normal Calculation:**
    Compute the surface normal $\mathbf{n}$ using central differences on the intensity field. For each axis, sample the intensity at $\mathbf{pos} + \mathbf{offset}$ and $\mathbf{pos} - \mathbf{offset}$, subtract them, and normalize the resulting vector $\mathbf{delta}$ [S1, unofficial]. This aligns with the parent's principle of deriving normals from the SDF gradient [G].

5.  **Transfer Function Lookup:**
    Map the sampled intensity $val$ to a 1D texture index:
    $$ \text{tfIndex} = \lfloor val \times \text{uniforms.tfSize} \rfloor $$
    Load the color $\mathbf{c}$ from `tfTexture` at this index [S1, unofficial].

6.  **Blinn-Phong Lighting:**
    Calculate the light direction $\mathbf{l}$ (from $\mathbf{p}$ to light), view direction $\mathbf{v}$ (from $\mathbf{p}$ to camera), and half vector $\mathbf{h} = \frac{\mathbf{l} + \mathbf{v}}{\|\mathbf{l} + \mathbf{v}\|}$ [G].
    *   Diffuse component: $D = \max(0.0, \mathbf{n} \cdot \mathbf{l}) \times \text{diffuse}$
    *   Specular component: $S = \text{pow}(\max(0.0, \mathbf{n} \cdot \mathbf{h}), \text{shininess}) \times \text{specular}$
    *   Ambient component: $A = \text{ambient}$
    *   Combined lit color:
        $$ \mathbf{litColor} = \text{lightColour} \times (\mathbf{c}.rgb \times (D + A) + S) $$
        [S1, unofficial]
    *   Note: `shininess` is typically set to 10.0 [S1, unofficial].

7.  **Front-to-Back Composition:**
    Update the accumulated color $\mathbf{accColour}$ using alpha blending:
    $$ \alpha = (1.0 - \mathbf{accColour}.a) \times \mathbf{c}.a $$
    $$ \mathbf{accColour}.rgb += \alpha \times \mathbf{litColor}.rgb $$
    $$ \mathbf{accColour}.a += \alpha $$
    Break the loop if $\mathbf{accColour}.a \ge 0.95$ [S1, unofficial].

**Pseudocode:**

```python
# Vertex Shader
def vert_main(vertex_index: u32) -> vec4<f32>:
    pos = [vec2(3.0, -1.0), vec2(-1.0, -1.0), vec2(-1.0, 3.0)]
    return vec4(pos[vertex_index], 0.0, 1.0)

# Fragment Shader
def ray_box_intersection(bbox_min: vec3, bbox_max: vec3, ray_pos: vec3, ray_dir: vec3) -> vec2:
    inv_dir = 1.0 / ray_dir
    bot = inv_dir * (bbox_min - ray_pos)
    top = inv_dir * (bbox_max - ray_pos)
    rmin = min(top, bot)
    rmax = max(top, bot)
    t_near = max(max(rmin.x, rmin.y), rmin.z)
    t_far = min(min(rmax.x, rmax.y), rmax.z)
    return vec2(t_near, t_far)

def frag_main(coord: vec2) -> vec4:
    # 1. Ray Generation
    pos = uniforms.transform * vec4(coord, 0.0, 1.0)
    dir = uniforms.transform * vec4(0.0, 0.0, 1.0, 0.0)
    
    # 2. Ray-Box Intersection
    size = vec3(texture_dimensions(volume_texture))
    intersect = ray_box_intersection(vec3(0.0), size, pos.xyz, dir.xyz)
    near = max(0, intersect.x)
    far = intersect.y
    
    acc_colour = vec4(0.0, 0.0, 0.0, 0.0)
    
    # 3. Ray Marching Loop
    for k in range(near, far):
        transformed = uniforms.transform * vec4(coord, float(k), 1.0)
        coords = transformed.xyz / size
        
        # Sample and Convert Intensity
        sample = texture_sample(volume_texture, volume_sampler, coords)
        intensity = (sample.x + sample.y * 255.0) / 256.0
        
        # 4. Normal Calculation (Central Differences)
        # Note: In a real implementation, offsets must be scaled by volume dimensions
        # and derivatives taken in world space or consistent local space.
        # Here we assume a simplified gradient estimation for the method description.
        eps = 1.0 / size
        dx = texture_sample(volume_texture, volume_sampler, coords + vec3(eps.x, 0, 0)).x - \
             texture_sample(volume_texture, volume_sampler, coords - vec3(eps.x, 0, 0)).x
        dy = texture_sample(volume_texture, volume_sampler, coords + vec3(0, eps.y, 0)).x - \
             texture_sample(volume_texture, volume_sampler, coords - vec3(0, eps.y, 0)).x
        dz = texture_sample(volume_texture, volume_sampler, coords + vec3(0, 0, eps.z)).x - \
             texture_sample(volume_texture, volume_sampler, coords - vec3(0, 0, eps.z)).x
        
        normal = normalize(vec3(dx, dy, dz))
        
        # 5. Transfer Function Lookup
        tf_index = int(intensity * uniforms.tf_size)
        tf_color = texture_sample(tf_texture, tf_sampler, vec3(float(tf_index) / uniforms.tf_size, 0, 0))
        
        # 6. Blinn-Phong Lighting
        light_dir = normalize(uniforms.light_pos - pos.xyz)
        view_dir = normalize(-pos.xyz) # Assuming camera at origin for simplicity, or use inverse transform
        half_dir = normalize(light_dir + view_dir)
        
        diffuse = max(0.0, dot(normal, light_dir)) * uniforms.diffuse
        specular = pow(max(0.0, dot(normal, half_dir)), 10.0) * uniforms.specular # shininess = 10.0
        ambient = uniforms.ambient
        
        lit_color = uniforms.light_colour * (tf_color.rgb * (diffuse + ambient) + specular)
        
        # 7. Front-to-Back Composition
        alpha = (1.0 - acc_colour.a) * tf_color.a
        acc_colour.rgb += alpha * lit_color.rgb
        acc_colour.a += alpha
        
        if acc_colour.a >= 0.95:
            break
            
    return acc_colour
```

## Operating characteristics
*   **Time Complexity:** Linear with respect to the number of samples along the ray, which depends on the volume depth and step size. The loop breaks early if opacity threshold is reached.
*   **Memory Complexity:** Dominated by the storage of the 3D volume texture and the 1D transfer function texture.
*   **Strengths:** Provides realistic specular highlights that enhance the perception of surface curvature and depth in volumetric data.
*   **Limitations:** Computationally more expensive than unshaded volume rendering due to normal calculation and lighting per sample. The quality of normals depends heavily on the resolution of the volume and the step size of the ray marcher.
*   **When to use:** When visual clarity of internal structures and surface-like appearance is desired.
*   **When not to use:** When performance is critical and specular highlights are not necessary, or when the volume data is too noisy for stable normal estimation.

## Background
Blinn-Phong Shading in Volume Rendering, specifically implemented as Shaded Volume Rendering (SVR), was popularized by implementations such as the `ossium` project for WebGPU [S1, unofficial]. It builds upon the principles of distance-field ray marching and applies the classic Blinn-Phong reflectance model to the gradients of the volume data.
