# Blinn-Phong Shading in Volume Rendering

Also called: Shaded Volume Rendering (SVR)

## Overview
Blinn-Phong Shading in Volume Rendering is a technique that applies the Blinn-Phong reflectance model to surface normals derived from volume intensity gradients during distance-field ray marching [S1, unofficial]. It distinguishes itself from sibling methods by computing specular highlights using the half-vector approximation and including ambient and diffuse components to simulate glossy surfaces [S1, unofficial].

## How it works
**Inputs and Outputs:**
*   **Input:** A 3D volume texture (`volumeTexture`) containing intensity data, a 1D transfer function texture (`tfTexture`), a uniform transform matrix, light position, light color, and shading parameters (diffuse, specular, ambient, shininess) [S1, unofficial].
*   **Output:** A 2D screen image with accumulated color and alpha [S1, unofficial].

**Data Structures:**
*   **Uniforms:** A struct containing:
    *   `transform`: `mat4x4<f32>` for transforming screen coordinates to volume space.
    *   `lightPos`: `vec3<f32>` in volume space.
    *   `lightColour`: `vec3<f32>` (RGB).
    *   `diffuse`: `f32` multiplier.
    *   `specular`: `f32` multiplier.
    *   `ambient`: `f32` multiplier.
    *   `tfSize`: `f32` size of the transfer function texture.
*   **Textures:**
    *   `volumeTexture`: `texture_3d<f32>` at binding 0.
    *   `volumeSampler`: Sampler at binding 1.
    *   `tfTexture`: `texture_1d<f32>` at binding 3.

**Steps:**
1.  **Ray Generation:** Generate a full-screen triangle using vertex indices to produce positions $(-1, 3)$, $(-1, -1)$, and $(3, -1)$ in clip space [S1, unofficial]. For each fragment, transform the screen coordinate $(coord.xy, 0.0, 1.0)$ by the uniform transform matrix to get the ray origin $\mathbf{pos}$, and transform $(0.0, 0.0, 1.0, 0.0)$ to get the ray direction $\mathbf{dir}$ [S1, unofficial].
2.  **Ray-Box Intersection:** Compute entry (`near`) and exit (`far`) distances by calculating inverse direction, bounding box distances, and taking min/max of axis intersections. Clamp `near` to 0 if negative [S1, unofficial].
3.  **Marching Loop:** Iterate from `near` to `far`. At each step:
    *   Transform the current position using the uniform matrix and normalize coordinates to the $[0, 1]$ range [S1, unofficial].
    *   Sample the 3D volume texture at these coordinates [S1, unofficial].
    *   Convert the sampled RG8 format value to a normalized 16-bit intensity: $I = \frac{sample.x + sample.y \times 255}{256}$ [S1, unofficial].
    *   **Normal Calculation:** Estimate the surface normal $\mathbf{n}$ using central differences. For each axis, sample the intensity at $\mathbf{p} + \delta$ and $\mathbf{p} - \delta$, subtract them, and normalize the resulting vector $\mathbf{\Delta}$ [S1, unofficial].
    *   **Transfer Function:** Map the intensity $I$ to a 1D texture index $tfIndex = \lfloor I \times \text{tfSize} \rfloor$ and load the color $\mathbf{c}$ from `tfTexture` [S1, unofficial].
    *   **Lighting:** Calculate light direction $\mathbf{l}$ (from $\mathbf{p}$ to light), view direction $\mathbf{v}$ (from $\mathbf{p}$ to camera), and half vector $\mathbf{h} = \frac{\mathbf{l} + \mathbf{v}}{\|\mathbf{l} + \mathbf{v}\|}$ [S1, unofficial]. Compute:
        *   Diffuse: $D = \max(0, \mathbf{n} \cdot \mathbf{l}) \times \text{diffuse}$
        *   Specular: $S = \text{pow}(\max(0, \mathbf{n} \cdot \mathbf{h}), \text{shininess}) \times \text{specular}$
        *   Ambient: $A = \text{ambient}$
        *   Combined: $\mathbf{litColor} = \text{lightColour} \times (\mathbf{c} \times (D + A) + S)$ [S1, unofficial].
    *   **Front-to-Back Composition:** Update accumulated color $\mathbf{accColor}$ using alpha blending:
        *   $\alpha_{new} = (1.0 - \mathbf{accColor}.a) \times \mathbf{c}.a$
        *   $\mathbf{accColor}.rgb += \alpha_{new} \times \mathbf{c}.rgb$
        *   $\mathbf{accColor}.a += \alpha_{new}$
        *   Break if $\mathbf{accColor}.a \ge 0.95$ [S1, unofficial].

**Pseudocode:**
```python
class Vec3:
    def __init__(self, x, y, z): self.x, self.y, self.z = x, y, z
    def __add__(self, o): return Vec3(self.x+o.x, self.y+o.y, self.z+o.z)
    def __sub__(self, o): return Vec3(self.x-o.x, self.y-o.y, self.z-o.z)
    def __mul__(self, s): return Vec3(self.x*s, self.y*s, self.z*s)
    def __truediv__(self, s): return Vec3(self.x/s, self.y/s, self.z/s)
    def dot(self, o): return self.x*o.x + self.y*o.y + self.z*o.z
    def length(self): return (self.x**2 + self.y**2 + self.z**2)**0.5
    def normalize(self): l = self.length(); return Vec3(self.x/l, self.y/l, self.z/l) if l > 0 else Vec3(0,0,0)

class Vec4:
    def __init__(self, x, y, z, w): self.x, self.y, self.z, self.w = x, y, z, w
    @property
    def xyz(self): return Vec3(self.x, self.y, self.z)

def ray_box_intersection(bbox_min, bbox_max, ray_pos, ray_dir):
    inv_dir = Vec3(1.0/ray_dir.x, 1.0/ray_dir.y, 1.0/ray_dir.z)
    bot = inv_dir * (bbox_min - ray_pos)
    top = inv_dir * (bbox_max - ray_pos)
    rmin = Vec3(min(top.x, bot.x), min(top.y, bot.y), min(top.z, bot.z))
    rmax = Vec3(max(top.x, bot.x), max(top.y, bot.y), max(top.z, bot.z))
    t_near = max(rmin.x, max(rmin.y, rmin.z))
    t_far = min(rmax.x, min(rmax.y, rmax.z))
    return (t_near, t_far)

def textureSample(tex, sampler, coords):
    # Standard graphics texture lookup returning (r, g, b, a)
    return (0.5, 0.5, 0.0, 1.0) 

def frag_main(coord, uniforms, volumeTexture, volumeSampler, tfTexture):
    pos = uniforms.transform * Vec4(coord.x, coord.y, 0.0, 1.0)
    dir = uniforms.transform * Vec4(0.0, 0.0, 1.0, 0.0)
    
    size = Vec3(*textureDimensions(volumeTexture))
    intersect = ray_box_intersection(Vec3(0.0, 0.0, 0.0), size, pos.xyz, dir.xyz)
    near = max(0, int(intersect[0]))
    far = int(intersect[1])
    
    acc_color = Vec4(0.0, 0.0, 0.0, 0.0)
    
    for k in range(near, far + 1):
        transformed = uniforms.transform * Vec4(coord.x, coord.y, float(k), 1.0)
        coords = transformed.xyz / size
        
        sample = textureSample(volumeTexture, volumeSampler, coords)
        intensity = (sample[0] + sample[1] * 255.0) / 256.0
        
        eps = Vec3(1.0/size.x, 1.0/size.y, 1.0/size.z)
        p_plus_x = coords + Vec3(eps.x, 0.0, 0.0)
        p_minus_x = coords - Vec3(eps.x, 0.0, 0.0)
        p_plus_y = coords + Vec3(0.0, eps.y, 0.0)
        p_minus_y = coords - Vec3(0.0, eps.y, 0.0)
        p_plus_z = coords + Vec3(0.0, 0.0, eps.z)
        p_minus_z = coords - Vec3(0.0, 0.0, eps.z)
        
        def get_intensity(p):
            s = textureSample(volumeTexture, volumeSampler, p)
            return (s[0] + s[1] * 255.0) / 256.0
            
        grad_x = get_intensity(p_plus_x) - get_intensity(p_minus_x)
        grad_y = get_intensity(p_plus_y) - get_intensity(p_minus_y)
        grad_z = get_intensity(p_plus_z) - get_intensity(p_minus_z)
        normal = Vec3(grad_x, grad_y, grad_z).normalize()
        
        tf_index = int(intensity * uniforms.tfSize)
        color = textureSample(tfTexture, volumeSampler, Vec3(float(tf_index) / uniforms.tfSize, 0.0, 0.0))
        
        light_dir = (uniforms.lightPos - pos.xyz).normalize()
        view_dir = (-pos.xyz).normalize()
        half_dir = (light_dir + view_dir).normalize()
        
        diffuse = max(0.0, normal.dot(light_dir)) * uniforms.diffuse
        specular = (max(0.0, normal.dot(half_dir)) ** 10.0) * uniforms.specular
        ambient = uniforms.ambient
        
        lit_color = uniforms.lightColour * (Vec3(color[0], color[1], color[2]) * (diffuse + ambient) + Vec3(specular, specular, specular))
        
        alpha = (1.0 - acc_color.w) * color[3]
        acc_color.x += alpha * lit_color.x
        acc_color.y += alpha * lit_color.y
        acc_color.z += alpha * lit_color.z
        acc_color.w += alpha
        
        if acc_color.w >= 0.95:
            break
            
    return acc_color
```

**Parameters:**
*   `shininess`: 10.0 [S1, unofficial].
*   `diffuse`, `specular`, `ambient`: Set via uniforms, typical values not specified in sources [S1, unofficial].

**Edge Cases and Pitfalls:**
*   **Precision:** The intensity conversion from RG8 to 16-bit float uses integer arithmetic in the source description, which may introduce quantization artifacts if not handled carefully in the shader [S1, unofficial].
*   **Boundaries:** The ray-box intersection clamps `near` to 0, which may cause artifacts if the ray origin is inside the volume but the intersection logic assumes an external origin [S1, unofficial].
*   **Normal Estimation:** Central differences require sampling at offsets; the source describes the method but does not specify the exact offset magnitude for discrete volumes [S1, unofficial].

## Subtopics

### Phong Shading with SDF Normals
Uses the reflection vector instead of the half vector for specular highlights, offering more accurate reflections but higher computational cost. Choose when visual fidelity of specular highlights is critical. [Phong Shading with SDF Normals](1977-phong-shading-with-sdf-normals.md)

### Lambertian Lighting in SDF
Only computes diffuse lighting, ignoring specular and ambient components. Choose for matte, non-reflective surfaces or when performance is paramount. [Lambertian Lighting in SDF](2023-lambertian-lighting-in-sdf.md)

### Gouraud Shading
Computes lighting at vertices and interpolates across the surface, which is less accurate for curved surfaces but faster. Choose for low-poly approximations or very high-performance requirements. [Gouraud Shading](4645-gouraud-shading.md)

## Operating characteristics
*   **Time Complexity:** Linear with respect to the number of samples along the ray, which depends on the volume depth and step size [S1, unofficial]. The breaking condition at 95% opacity can reduce average samples [S1, unofficial].
*   **Memory Complexity:** Low, requiring only the volume texture, transfer function texture, and uniform buffers [S1, unofficial].
*   **Measured Performance:** Implemented in `ossium` for WebGPU, running in the browser [S1, unofficial]. Specific performance metrics (FPS, resolution) are not provided in the sources [S1, unofficial].
*   **Strengths:** Real-time capable on modern GPUs; provides visually appealing glossy surfaces; simple to implement [S1, unofficial].
*   **Limitations:** Approximate specular highlights (Blinn-Phong); normal estimation can be noisy in discrete volumes; transfer function mapping is linear and may not capture complex material properties [S1, unofficial].
*   **When to Use:** Real-time volume visualization where glossy appearance is desired and performance is a constraint [S1, unofficial].
*   **When Not to Use:** Scientific visualization requiring physically accurate light transport or high-fidelity normal estimation [S1, unofficial].

## Background
Blinn-Phong Shading in Volume Rendering was implemented in the `ossium` project, a WebGPU-based application for displaying 3D volumes created from DICOM files in the browser [S1, unofficial]. The technique is part of the broader field of Shaded Volume Rendering (SVR), which enhances traditional volume rendering by adding surface shading cues to improve depth perception and material appearance [S1, unofficial].
