# Ray Marching with Reflections

Also called: GLSL reflect function for raymarching, Metal Material Scattering, Ray Marching with Recursive Reflections, Reflection and Refraction in Raymarching, Spherical Marching with Reflections, raytraced reflections, renderReflection

## Overview
Ray Marching with Reflections extends distance-field ray marching by iteratively scattering rays specularly upon surface intersection to simulate mirror-like or metallic materials [S1, S3, unofficial]. Unlike standard ray marching which terminates at the first hit, this method continues the ray path in the reflected direction, accumulating color contributions weighted by material reflectivity [S4, unofficial]. It distinguishes itself from [Approximate Refraction](3072-approximate-refraction.md) by handling surface reflection rather than transmission, and from [Screen-Space Reflections](9698-screen-space-reflections.md) by operating in full 3D volume space rather than restricted screen-space depth buffers [S2, unofficial].

## How it works
**Inputs and Outputs:**
*   **Input:** Initial ray origin $\mathbf{r}_o$ and direction $\mathbf{r}_d$; Signed Distance Function (SDF) $f(\mathbf{x})$; Material reflectivity parameter $c_{refl}$; Maximum reflection bounces $N_{max}$ [S2, S4, unofficial].
*   **Output:** Final accumulated color $\mathbf{C}_{out}$ [S2, unofficial].

**Data Structures:**
*   **Ray:** Struct containing `origin` ($\mathbf{p}$, vec3) and `direction` ($\mathbf{d}$, vec3) [S1, unofficial].
*   **HitRecord:** Struct containing `t` (distance to hit, float), `hit_point` ($\mathbf{p}$, vec3), `normal` ($\mathbf{n}$, vec3), and `material` properties [S2, S4, unofficial].

**Steps:**
1.  **Initialization:** Set accumulated color $\mathbf{C}_{acc} = \mathbf{0}$, transmission mask $\mathbf{M} = \mathbf{1}$, and current ray $\mathbf{r} = (\mathbf{r}_o, \mathbf{r}_d)$ [S2, S4, unofficial].
2.  **Loop:** For bounce index $i$ from $0$ to $N_{max}-1$:
    a.  **March:** Perform SDF ray marching along $\mathbf{r}$ to find the closest intersection distance $t$. If no intersection is found within the maximum step limit, $t$ is considered invalid or infinite [S2, S4, unofficial].
    b.  **Hit Handling:**
        i.  If intersection found ($t < \infty$):
            1.  Compute intersection point: $\mathbf{p} = \mathbf{r}.origin + t \cdot \mathbf{r}.direction$ [S2, unofficial].
            2.  Compute surface normal $\mathbf{n}$ using the SDF gradient:
                $$ \mathbf{n} = \frac{\nabla f(\mathbf{p})}{\|\nabla f(\mathbf{p})\|} $$
                where $\nabla f(\mathbf{p})$ is estimated via finite differences [S2, S3, unofficial].
            3.  Compute direct illumination $\mathbf{C}_{light}$ at $\mathbf{p}$ using $\mathbf{n}$, view direction, and light sources [S2, S4, unofficial].
            4.  Accumulate color: $\mathbf{C}_{acc} \leftarrow \mathbf{C}_{acc} + \mathbf{M} \odot \mathbf{C}_{light}$ [S2, unofficial].
            5.  Update mask: $\mathbf{M} \leftarrow \mathbf{M} \cdot c_{refl}$ [S2, unofficial].
            6.  Check termination: If $\|\mathbf{M}\| < \epsilon$ (e.g., $0.001$), break loop [S4, unofficial].
            7.  Prepare next ray:
                *   Compute reflected direction: $\mathbf{r}_{new\_d} = \text{reflect}(\mathbf{r}.direction, \mathbf{n})$ [S1, S3, unofficial].
                *   Guard against degenerate normals: If $\|\mathbf{r}_{new\_d}\| < 10^{-8}$, set $\mathbf{r}_{new\_d} = \mathbf{n}$ [S1, unofficial].
                *   Offset origin to prevent self-intersection (shadow acne): $\mathbf{p}_{new} = \mathbf{p} + \mathbf{n} \cdot \delta$, where $\delta \in [0.001, 0.05]$ [S2, S4, unofficial].
                *   Set $\mathbf{r} = (\mathbf{p}_{new}, \mathbf{r}_{new\_d})$ [S2, S4, unofficial].
        ii. If no intersection found:
            1.  If $i=0$ (primary ray missed), set $\mathbf{C}_{acc} = \mathbf{C}_{sky}$ (e.g., $(0.3, 0.2, 0.8)$) [S2, unofficial].
            2.  Else, add background contribution: $\mathbf{C}_{acc} \leftarrow \mathbf{C}_{acc} + \mathbf{M} \odot \mathbf{C}_{background}(\mathbf{r})$ [S4, unofficial].
            3.  Break loop [S4, unofficial].
3.  **Post-Processing:**
    a.  Apply tone mapping: $\mathbf{C}_{acc} = \frac{\mathbf{C}_{acc}}{\mathbf{C}_{acc} + \mathbf{1}}$ [S2, unofficial].
    b.  Apply gamma correction: $\mathbf{C}_{out} = \mathbf{C}_{acc}^{(1/\gamma)}$, typically $\gamma = 1.1$ [S2, unofficial].

**Pseudocode:**
```python
def ray_march_with_reflections(ray_origin, ray_direction, sdf_func, max_bounces, c_refl, epsilon=0.001):
    """
    ray_origin: vec3
    ray_direction: vec3 (normalized)
    sdf_func: function(x) -> float
    max_bounces: int
    c_refl: float (reflection coefficient, 0.0 to 1.0)
    epsilon: float (transmittance threshold)
    """
    accum = vec3(0.0)
    mask = vec3(1.0)
    curr_ray_origin = ray_origin
    curr_ray_dir = ray_direction
    
    for i in range(max_bounces):
        # 1. March
        hit_dist = march_sdf(curr_ray_origin, curr_ray_dir, sdf_func)
        
        if hit_dist is not None and hit_dist < MAX_STEP:
            # 2. Hit Found
            p = curr_ray_origin + hit_dist * curr_ray_dir
            
            # 3. Compute Normal
            grad = compute_sdf_gradient(p, sdf_func)
            n = normalize(grad)
            
            # 4. Direct Illumination (Placeholder for specific lighting model)
            # Uses PBR or simple diffuse/specular based on n, view_dir, light_dirs
            color = direct_illumination(p, n, curr_ray_dir)
            
            # 5. Accumulate
            accum = accum + mask * color
            
            # 6. Update Mask
            mask = mask * c_refl
            
            # 7. Termination Check
            if length(mask) < epsilon:
                break
                
            # 8. Prepare Next Ray
            # Reflect direction
            new_dir = reflect(curr_ray_dir, n)
            
            # Guard degenerate case
            if length(new_dir) < 1e-8:
                new_dir = n
                
            # Offset origin to prevent self-intersection
            # Source [S2, unofficial] uses 0.05, Source [S4, unofficial] uses 0.001. 
            # We use a small constant delta.
            delta = 0.001 
            new_origin = p + n * delta
            
            curr_ray_origin = new_origin
            curr_ray_dir = new_dir
        else:
            # 9. Miss
            if i == 0:
                accum = vec3(0.3, 0.2, 0.8) # Sky color
            else:
                # Add background contribution
                bg_color = compute_background_color(curr_ray_origin, curr_ray_dir)
                accum = accum + mask * bg_color
            break
            
    # 10. Post-processing
    # Tone mapping
    accum = accum / (accum + vec3(1.0))
    # Gamma correction
    gamma = 1.1
    accum = pow(accum, vec3(1.0/gamma))
    
    return accum

def march_sdf(origin, direction, sdf_func):
    """
    Standard SDF ray marching loop.
    Returns distance to hit or None if no hit.
    """
    t = 0.0
    max_steps = 64
    step_size = 0.01
    
    for _ in range(max_steps):
        p = origin + t * direction
        d = sdf_func(p)
        
        if d < 0.001:
            return t
        if t > 100.0: # Arbitrary far plane
            return None
            
        t += d * step_size # Simplified march step; actual implementations vary
        
    return None

def compute_sdf_gradient(p, sdf_func):
    """
    Finite difference gradient estimation.
    """
    eps = 0.001
    x = vec3(1, 0, 0)
    y = vec3(0, 1, 0)
    z = vec3(0, 0, 1)
    
    dx = sdf_func(p + x * eps) - sdf_func(p - x * eps)
    dy = sdf_func(p + y * eps) - sdf_func(p - y * eps)
    dz = sdf_func(p + z * eps) - sdf_func(p - z * eps)
    
    return vec3(dx, dy, dz) / (2 * eps)

def direct_illumination(p, n, view_dir):
    """
    Placeholder for lighting calculation.
    In [S2, unofficial], this calls directIllumination(hs, curr_ray, c_refl).
    """
    # Simplified diffuse lighting for demonstration
    light_dir = normalize(vec3(1, 1, 1))
    diff = max(dot(n, light_dir), 0.0)
    return vec3(0.8) * diff
```

**Parameters:**
*   $c_{refl}$: Reflection coefficient multiplier. Controls the attenuation of color per bounce. Default value: $0.3$ [S2, unofficial].
*   $N_{max}$: Number of reflection bounces. If $1$, uses a single bounce path. Default value: $0$ (no recursion) or $1$ depending on implementation [S2, S4, unofficial].
*   $\epsilon$: Transmittance threshold. Stops recursion when mask magnitude drops below this value. Default value: $0.001$ [S4, unofficial].
*   $\delta$: Offset distance for ray origin. Prevents self-intersection. Values range from $0.001$ to $0.05$ [S2, S4, unofficial].

**Edge Cases and Pitfalls:**
*   **Self-Intersection (Shadow Acne):** Casting a ray from the exact intersection point causes the ray to immediately hit the same surface. Mitigated by offsetting the origin along the normal by $\delta$ [S2, S4, unofficial].
*   **Degenerate Normals:** If the reflection vector becomes near-zero (e.g., grazing angles or numerical instability), it should be clamped to the normal direction to prevent undefined behavior [S1, unofficial].
*   **Infinite Recursion:** Without a termination condition based on transmittance ($\epsilon$) or max bounces, reflective scenes can cause stack overflows or infinite loops [S4, unofficial].

## Subtopics

### Raytracing Extension (Reflections)
Extends basic raycasting by continuing the ray path after intersection to realize reflections, distinguishing raytracing (interaction continuation) from raycasting (single throw) [S5, unofficial].

### Chromatic Dispersion Glass Rendering
Renders glass with Fresnel reflection and per-channel refraction for chromatic dispersion ($n = 1.48/1.50/1.52$). Falls back to reflected ray on total-internal-reflection and applies distance-compounding tint. The 3-trace dispersion path is gated to grazing angles [S6, unofficial].

### Reflection Blending
Interpolates between specular lighting and environment reflection color based on a blend factor. Computes environment reflection color via an environment map and mixes it with specular sum, resetting specular sum and light Y to 1.0 after blending [S7, unofficial].

## Operating characteristics
*   **Time Complexity:** $O(N \cdot B)$, where $N$ is the number of pixels and $B$ is the number of reflection bounces. Each bounce requires a full SDF march.
*   **Memory Complexity:** $O(1)$ per pixel, as only the current ray state and accumulated color are stored.
*   **Performance:** Significantly more expensive than standard ray marching due to recursive SDF evaluations. Performance scales linearly with $N_{max}$ and $c_{refl}$ (higher reflectivity requires more bounces to converge).
*   **Strengths:** Produces physically plausible mirror-like reflections in SDF scenes without requiring explicit geometry meshes.
*   **Limitations:** Cannot handle complex scene reflections if the SDF is expensive to evaluate. Limited to local reflections (no global illumination unless combined with other techniques).
*   **When to Use:** For shiny, metallic, or mirror-like surfaces in procedural SDF scenes.
*   **When Not to Use:** For diffuse surfaces (wastes computation) or when performance is critical and reflections are not visually necessary.

## Background
Originating from the generalization of raycasting to raytracing, this method allows for the simulation of light interaction with surfaces beyond the first hit [S5, unofficial]. It is commonly implemented in GLSL-based raymarchers using the `reflect` function [S3, unofficial]. The technique is widely used in real-time graphics for creating reflective materials in voxel or SDF-based environments [S1, S4, unofficial].
