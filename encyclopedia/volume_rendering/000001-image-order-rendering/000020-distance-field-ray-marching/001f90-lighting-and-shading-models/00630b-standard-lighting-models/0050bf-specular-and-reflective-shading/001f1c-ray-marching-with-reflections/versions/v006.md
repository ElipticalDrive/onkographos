# Ray Marching with Reflections

Also called: GLSL reflect function for raymarching, Metal Material Scattering, Ray Marching with Recursive Reflections, Reflection and Refraction in Raymarching, Spherical Marching with Reflections, raytraced reflections, renderReflection

## Overview
Ray Marching with Reflections extends distance-field ray marching by iteratively casting new rays upon surface intersection to simulate specular reflection, allowing the renderer to capture environment interactions and mirror-like surfaces [S1, S3, S4, unofficial]. Unlike standard ray marching which terminates at the first hit, this method continues the ray path, attenuating the contribution of each bounce based on material reflectivity [S4, unofficial]. It sets itself apart from [Screen-Space Reflections](9698-screen-space-reflections.md) by operating in 3D volume space rather than screen space, and from [Approximate Refraction](3072-approximate-refraction.md) by explicitly computing reflected ray directions rather than approximating visual distortion [S2, unofficial].

## How it works
**Inputs and Outputs:**
*   **Input:** Initial ray origin $\mathbf{o}$ and direction $\mathbf{d}$ (typically from camera to pixel), Signed Distance Function (SDF) $f(\mathbf{x})$ defining the scene geometry, material properties (reflectivity, color), and maximum reflection count $N_{max}$.
*   **Output:** Final pixel color $\mathbf{C}_{final}$.

**Data Structures:**
*   **Ray:** Struct containing origin $\mathbf{o} \in \mathbb{R}^3$ and direction $\mathbf{d} \in \mathbb{R}^3$ (normalized).
*   **HitRecord:** Struct containing intersection distance $t$, intersection point $\mathbf{p} = \mathbf{o} + t\mathbf{d}$, surface normal $\mathbf{n}$, and material reference.

**Step-by-Step Method:**

1.  **Initialization:**
    *   Set accumulated color $\mathbf{C}_{accum} = \mathbf{0}$.
    *   Set transmission mask/weight $\mathbf{W} = \mathbf{1}$ (or $1.0$ for scalar).
    *   Set current ray $\mathbf{r}_{curr} = (\mathbf{o}, \mathbf{d})$.
    *   Set reflection coefficient multiplier $c_{refl}$ (typically $0.3$) [S2, unofficial].
    *   Set maximum bounces $N_{max}$ (e.g., 1 for single bounce, higher for recursion) [S4, unofficial].
    *   Set epsilon offset $\epsilon$ (e.g., $0.001$ to $0.05$) to prevent self-intersection [S2, S4, unofficial].

2.  **Reflection Loop:**
    For bounce index $i$ from $0$ to $N_{max}$:
    
    a. **Ray Marching:**
       Perform standard distance-field ray marching along $\mathbf{r}_{curr}$ to find the closest surface intersection.
       *   Let $t$ be the step distance where $f(\mathbf{r}_{curr}.\mathbf{o} + t \cdot \mathbf{r}_{curr}.\mathbf{d}) \approx 0$.
       *   If no intersection is found within the scene bounds (miss):
           *   If $i == 0$, set $\mathbf{C}_{accum} = \mathbf{C}_{sky}$ (e.g., $(0.3, 0.2, 0.8)$) [S2, unofficial].
           *   Else, add $\mathbf{W} \cdot \mathbf{C}_{sky}$ to $\mathbf{C}_{accum}$ [S4, unofficial].
           *   Break loop.

    b. **Intersection Processing:**
       If intersection found at distance $t$:
       *   Compute intersection point: $\mathbf{p} = \mathbf{r}_{curr}.\mathbf{o} + t \cdot \mathbf{r}_{curr}.\mathbf{d}$.
       *   Compute surface normal $\mathbf{n}$ using the SDF gradient:
           $$ \mathbf{n} = \frac{\nabla f(\mathbf{p})}{\|\nabla f(\mathbf{p})\|} $$
           [G] The gradient $\nabla f(\mathbf{p})$ is typically estimated via finite differences:
           $$ \nabla f(\mathbf{p}) \approx \begin{bmatrix} f(\mathbf{p} + \delta \mathbf{x}) - f(\mathbf{p} - \delta \mathbf{x}) \\ f(\mathbf{p} + \delta \mathbf{y}) - f(\mathbf{p} - \delta \mathbf{y}) \\ f(\mathbf{p} + \delta \mathbf{z}) - f(\mathbf{p} - \delta \mathbf{z}) \end{bmatrix} \frac{1}{2\delta} $$
           where $\delta$ is a small step size (e.g., $0.001$) [G].
       *   Compute direct illumination $\mathbf{C}_{light}$ at $\mathbf{p}$ using $\mathbf{n}$, view direction, and light sources [S2, S4, unofficial].
       *   Update accumulated color:
           $$ \mathbf{C}_{accum} \leftarrow \mathbf{C}_{accum} + \mathbf{W} \cdot \mathbf{C}_{light} $$
       *   Update transmission weight:
           $$ \mathbf{W} \leftarrow \mathbf{W} \cdot c_{refl} $$
           [S2, unofficial] Alternatively, use material reflectivity $R$: $\mathbf{W} \leftarrow \mathbf{W} \cdot R^2$ [S4, unofficial].
       *   Check for termination: If $\mathbf{W} < \epsilon_{thresh}$ (e.g., $0.001$), break loop [S4, unofficial].
       *   Prepare next ray:
           *   Compute reflection direction: $\mathbf{d}_{new} = \text{reflect}(-\mathbf{r}_{curr}.\mathbf{d}, \mathbf{n})$.
               [G] The GLSL `reflect(I, N)` function computes: $\mathbf{R} = \mathbf{I} - 2(\mathbf{I} \cdot \mathbf{N})\mathbf{N}$, where $\mathbf{I}$ is the incident vector (pointing *towards* the surface, i.e., $-\mathbf{d}$).
           *   Handle degenerate case: If $\|\mathbf{d}_{new}\| < 10^{-8}$, set $\mathbf{d}_{new} = \mathbf{n}$ [S1, unofficial].
           *   Offset origin to prevent self-intersection: $\mathbf{o}_{new} = \mathbf{p} + \epsilon \cdot \mathbf{n}$ [S2, S4, unofficial].
           *   Update current ray: $\mathbf{r}_{curr} = (\mathbf{o}_{new}, \mathbf{d}_{new})$.

3.  **Post-Processing:**
    *   Apply tone mapping: $\mathbf{C}_{final} = \frac{\mathbf{C}_{accum}}{\mathbf{C}_{accum} + \mathbf{1}}$ [S2, unofficial].
    *   Apply gamma correction: $\mathbf{C}_{final} = \mathbf{C}_{final}^{1/\gamma}$ (e.g., $\gamma = 1.1$) [S2, unofficial].

**Pseudocode:**

```python
def ray_march_with_reflections(ray_origin, ray_direction, max_bounces, epsilon=0.001, c_refl=0.3):
    """
    Renders a scene using ray marching with specular reflections.
    
    Args:
        ray_origin: vec3, initial ray origin.
        ray_direction: vec3, initial ray direction (normalized).
        max_bounces: int, maximum number of reflection bounces.
        epsilon: float, offset to prevent self-intersection.
        c_refl: float, reflection coefficient multiplier per bounce.
        
    Returns:
        vec3, final pixel color.
    """
    accum_color = vec3(0.0)
    transmission_weight = vec3(1.0)
    current_ray_origin = ray_origin
    current_ray_dir = ray_direction
    
    for i in range(max_bounces + 1):
        # 1. Ray Marching
        hit_distance = ray_march(current_ray_origin, current_ray_dir)
        
        if hit_distance > 0.0:
            # Intersection found
            hit_point = current_ray_origin + hit_distance * current_ray_dir
            normal = compute_sdf_normal(hit_point)
            
            # 2. Lighting
            # Compute direct illumination based on hit_point, normal, and lights
            light_color = compute_direct_illumination(hit_point, normal, current_ray_dir)
            
            # 3. Accumulate
            accum_color += transmission_weight * light_color
            
            # 4. Update Weight
            transmission_weight *= c_refl
            
            # 5. Termination Check
            if length(transmission_weight) < 0.001:
                break
                
            # 6. Prepare Next Ray
            # Reflect direction: R = I - 2(I.N)N, where I is incident vector (-current_ray_dir)
            incident = -current_ray_dir
            reflection_dir = reflect(incident, normal)
            
            # Handle degenerate reflection
            if length(reflection_dir) < 1e-8:
                reflection_dir = normal
                
            # Offset origin to prevent self-intersection
            next_origin = hit_point + epsilon * normal
            next_dir = normalize(reflection_dir)
            
            current_ray_origin = next_origin
            current_ray_dir = next_dir
        else:
            # Miss: Hit background/sky
            sky_color = vec3(0.3, 0.2, 0.8) # Example sky color
            if i == 0:
                accum_color = sky_color
            else:
                accum_color += transmission_weight * sky_color
            break
            
    # Post-processing
    # Tone mapping
    accum_color = accum_color / (accum_color + vec3(1.0))
    # Gamma correction
    gamma = 1.1
    accum_color = pow(accum_color, vec3(1.0 / gamma))
    
    return accum_color

def reflect(incident, normal):
    """
    Computes the reflection vector.
    incident: vec3, vector pointing TOWARDS the surface.
    normal: vec3, surface normal.
    """
    return incident - 2.0 * dot(incident, normal) * normal

def compute_sdf_normal(point):
    """
    Computes the normal using finite differences.
    """
    delta = 0.001
    p = point
    grad_x = sdf(p + vec3(delta, 0, 0)) - sdf(p - vec3(delta, 0, 0))
    grad_y = sdf(p + vec3(0, delta, 0)) - sdf(p - vec3(0, delta, 0))
    grad_z = sdf(p + vec3(0, 0, delta)) - sdf(p - vec3(0, 0, delta))
    gradient = vec3(grad_x, grad_y, grad_z) / (2.0 * delta)
    return normalize(gradient)

def ray_march(origin, direction):
    """
    Performs distance-field ray marching.
    Returns distance to surface, or -1 if no intersection.
    """
    t = 0.0
    max_steps = 100
    max_dist = 100.0
    
    for _ in range(max_steps):
        p = origin + t * direction
        d = sdf(p)
        if d < 0.001:
            return t
        if t > max_dist:
            return -1.0
        t += d
    return -1.0
```

**Parameters:**
*   `max_bounces` ($N_{max}$): Controls recursion depth. Default: 1 (single bounce) or higher for recursive reflections [S4, unofficial].
*   `c_refl`: Reflection coefficient multiplier. Default: $0.3$ [S2, unofficial].
*   `epsilon`: Offset for ray origin. Default: $0.001$ to $0.05$ [S2, S4, unofficial].
*   `gamma`: Gamma correction exponent. Default: $1.1$ [S2, unofficial].

**Edge Cases and Pitfalls:**
*   **Self-Intersection (Shadow Acne):** Casting a new ray from the exact intersection point causes the ray to immediately re-intersect the same surface. This is prevented by offsetting the new origin along the normal by $\epsilon$ [S2, S4, unofficial].
*   **Degenerate Reflection:** If the incident ray is parallel to the normal, the reflection vector may become zero. Guard against this by checking the length of the reflection vector and defaulting to the normal [S1, unofficial].
*   **Infinite Recursion:** Without a termination condition (weight threshold or max bounces), reflections can loop infinitely. Terminate when transmission weight drops below $0.001$ [S4, unofficial].

## Subtopics

### [Ray Marching with Refraction and Beer's Law Absorption](1947-ray-marching-with-refraction-and-beer-s-law-absorption.md)
This method extends distance-field ray marching to simulate transparent dielectric objects by handling refraction, total internal reflection (TIR), and exponential light absorption (Beer's Law) over multiple bounces. Unlike standard ray marching which terminates at the first surface hit, this approach continues the ray through transparent boundaries, flipping the normal direction to track interior traversal and accumulating distance for attenuation. It distinguishes itself from [Approximate Refraction](3072-approximate-refraction.md) by explicitly computing the refracted ray direction and handling TIR, and from [Cone Marching](3808-cone-marching.md) by using a single ray path rather than volumetric cone integration for absorption.

### [Nested Raymarching for Refraction](1957-nested-raymarching-for-refraction.md)
Nested Raymarching for Refraction models a glass-like surface by refracting the ray direction upon entering the object, marching inside the object, and refracting again upon exiting. It differs from [Ray Marching with Reflections](1963-ray-marching-with-reflections.md) by handling transmission through transparent volumes rather than surface reflection, and from [Approximate Refraction](3072-approximate-refraction.md) by performing explicit nested raymarching rather than approximating the exit point.

### [Reflected Ray Directions](2028-reflected-ray-directions.md)
Reflected Ray Directions is a geometric method used in volume rendering and ray marching to determine the propagation direction of a ray after it interacts with a surface boundary. It solves the problem of simulating specular reflection by computing a new ray vector based on the incident direction and the surface normal. It differs from sibling methods like [Refracted Ray Directions](3915-refracted-ray-directions.md) by computing transmission (bending) rather than reflection (bouncing), and serves as the geometric foundation for energy-splitting techniques like [Fresnel Reflection/Refraction](9067-fresnel-reflection-refraction.md) [G].

### [Real-time Reflection of Clouds](2398-real-time-reflection-of-clouds.md)
Not given in the sources.

### [Approximate Refraction](3072-approximate-refraction.md)
Approximate refraction is a technique to make a fluid surface appear to refract objects behind it, which is faster and simpler to implement than ray tracing. Convex regions of the surface magnify the image behind them, concave regions shrink it, and flat regions allow rays to pass straight through.

### [Cone Marching](3808-cone-marching.md)
Cone Marching is an optimization for distance-field ray marching that groups bundles of rays into a cone to skip repeated Signed Distance Function (SDF) calculations. It differs from standard ray marching by performing a coarse, vertex-shader-based march of these cones to advance the ray origin and step count before the fragment shader resumes fine-grained marching.

### [Screen-Space Reflections](9698-screen-space-reflections.md)
Screen-Space Reflections (SSR) is a global illumination technique that uses rays in screen space to trace against the depth buffer to achieve effects like reflections and color bleeding, which direct illumination cannot achieve. It sets itself apart from sibling methods like [Ray Marching with Reflections](1963-ray-marching-with-reflections.md) by operating entirely within the 2D screen coordinate system and utilizing the existing depth buffer, rather than marching through a 3D volume or scene graph. This makes it significantly cheaper than full ray tracing but limited to visible geometry.

### [Flipped Reflection Ray Masking](12503-flipped-reflection-ray-masking.md)
Flipped Reflection Ray Masking is a regularization technique for few-shot novel view synthesis that generates additional training rays by reflecting input viewing directions across estimated surface normals. It solves the problem of insufficient supervision in sparse-view scenarios by providing geometrically consistent auxiliary signals, while discarding rays that are geometrically inconsistent with the scene to prevent noise. It sets itself apart from sibling methods like [Nested Raymarching for Refraction](1957-nested-raymarching-for-refraction.md) by focusing on reflection-based regularization rather than refraction physics, and from [Screen-Space Reflections](9698-screen-space-reflections.md) by operating in the training data generation phase rather than post-processing.

### Raytracing Extension (Reflections)
Extending the raycasting process by continuing the ray path after intersection to realize reflections [S5, unofficial]. Raycasting throws rays into the scene, whereas raytracing continues the interaction of rays with the scene (e.g., reflecting off surfaces like a silver wall) [S5, unofficial].

### Chromatic Dispersion Glass Rendering
Renders glass with Fresnel reflection and per-channel refraction for chromatic dispersion [S6, unofficial]. It applies Fresnel reflection plus per-channel refraction for chromatic dispersion (n = 1.48/1.50/1.52), falls back to the reflected ray on total-internal-reflection, applies distance-compounding tint, and gates the 3-trace dispersion path to grazing angles [S6, unofficial].

### Reflection Blending
Interpolates between specular lighting and environment reflection color based on a blend factor [S7, unofficial]. It gets the environment reflection color using an environment map and mixes specular light with reflection using a blend vector component, resetting the specular sum and light Y to 1.0 after blending [S7, unofficial].

## Operating characteristics
*   **Time Complexity:** $O(N \cdot B)$, where $N$ is the number of ray march steps per bounce and $B$ is the number of reflection bounces. Each bounce requires a full ray march.
*   **Memory Complexity:** $O(1)$ auxiliary memory per pixel, as the recursion is iterative.
*   **Performance:** Performance degrades linearly with the number of bounces and scene complexity (SDF evaluation cost). [S5, unofficial] notes that raytracing (including reflections) can significantly increase iteration counts compared to simple raycasting.
*   **Strengths:** Accurate specular reflections, mirror effects, and recursive lighting interactions in 3D space.
*   **Limitations:** Computationally expensive for high bounce counts. Limited to the geometry defined by the SDF. Cannot handle transparent refraction without extension (e.g., [Ray Marching with Refraction and Beer's Law Absorption](1947-ray-marching-with-refraction-and-beer-s-law-absorption.md)).
*   **When to Use:** When mirror-like surfaces, recursive reflections, or accurate specular highlights are required in a raymarched scene.
*   **When Not to Use:** When performance is critical and reflections are not visually necessary, or when transparent/translucent materials are the primary focus (use refraction methods instead).

## Background
The method originates from the extension of raycasting to raytracing, where ray paths are continued after intersection to simulate reflections [S5, unofficial]. Early implementations in raymarching used the GLSL `reflect` function to compute new ray directions upon SDF intersection [S3, unofficial]. The technique has been widely adopted in real-time graphics for creating reflective materials in distance-field rendered scenes [S1, S2, S4, unofficial].
