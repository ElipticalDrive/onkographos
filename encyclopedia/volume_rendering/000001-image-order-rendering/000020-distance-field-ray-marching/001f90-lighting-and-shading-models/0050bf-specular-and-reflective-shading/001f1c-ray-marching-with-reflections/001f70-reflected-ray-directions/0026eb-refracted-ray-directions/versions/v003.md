# Refracted Ray Directions

Also called: refract

## Overview
Calculates the refracted direction of a ray given surface normals and refractive indices, handling entry and exit scenarios for spherical objects [S1, unofficial]. It computes the transmitted vector rather than the mirrored vector [G], and provides the geometric direction vector rather than the energy weighting factor used by [Fresnel Reflection/Refraction](9067-fresnel-reflection-refraction.md) [G].

## How it works
**Inputs:**
- `ob`: The intersected object (must support `getType()`, `getRefractive()`, and `surfaceNormal()`).
- `point`: The 3D intersection point.
- `ray`: The incoming ray direction (normalized).
- `from`: The ray origin (used to determine normal orientation).
- `ref`: The current medium's refractive index (passed as a mutable container, e.g., a list, to allow in-place updates).

**Outputs:**
- `Vector3`: The normalized refracted ray direction.
- `ref`: Updated to the object's refractive index.

**Data Structures:**
- `Vector3`: A 3D vector with components `x`, `y`, `z`.
- `float`: Standard 32-bit floating point.

**Steps:**
1. Calculate the surface normal $N$ at `point` relative to `from` [S1, unofficial].
2. Set $n_1$ to the current refractive index `ref` [S1, unofficial].
3. Set $n_2$ to the object's refractive index `ob->getRefractive()` [S1, unofficial].
4. Calculate $s = \text{dot}(\text{ray}, N)$ [S1, unofficial].
5. If the object is a sphere and $s > 0$ (indicating the ray is exiting the sphere), swap $n_1$ and $n_2$ [S1, unofficial].
6. Calculate the ratio $n = n_1 / n_2$ [S1, unofficial].
7. Calculate the refracted direction using the formula:
   $$ \text{refracted} = n \cdot (\text{ray} - s \cdot N) - N \cdot \sqrt{1 - n^2 \cdot (1 - s^2)} $$ [S1, unofficial].
8. Normalize the result [S1, unofficial].
9. Update `ref` to $n_2$ [S1, unofficial].

**Pseudocode:**
```python
SPHERE_TYPE = 0

def refract(ob, point, ray, from, ref):
    N = surface_normal(ob, point, from)
    n1 = ref[0]
    n2 = ob.get_refractive()
    s = dot(ray, N)
    if ob.get_type() == SPHERE_TYPE and s > 0:
        n1, n2 = n2, n1
    n = n1 / n2
    refracted = n * (ray - s * N) - N * sqrt(1.0 - n * n * (1.0 - s * s))
    refracted = refracted.normalize()
    ref[0] = n2
    return refracted
```

**Edge Cases:**
- The check `s > 0` combined with `getType() == sphere` determines if the ray is exiting the sphere, which triggers the index swap [S1, unofficial].

## Subtopics

### [Fresnel Reflection/Refraction](9067-fresnel-reflection-refraction.md)
Calculates the Fresnel reflectance for unpolarized light at an interface between two media with different indices of refraction. It determines the ratio of reflected to refracted light energy, which is essential for physically based rendering of dielectrics and metals. It sets itself apart from sibling methods by providing the weighting factor ($k_R$) used to blend reflected and refracted ray contributions, rather than calculating the ray directions themselves.
