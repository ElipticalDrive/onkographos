# Nested Raymarching for Refraction

Also called: GLASSREFLECT, Glass Refraction via Nested Raymarching, Glass-like surface modeling

## Overview
Nested Raymarching for Refraction models a glass-like surface by refracting the ray direction upon entering the object, marching inside the object, and refracting again upon exiting [S1, unofficial].

## How it works
**Inputs and Outputs:**
The method takes a ray origin $\mathbf{o}$, ray direction $\mathbf{d}$, a signed distance field function $S(\mathbf{p})$, a refractive index ratio $\eta$ (ratio of the incident medium to the glass), and a maximum march step count as inputs [S1, unofficial]. It outputs the color at the final intersection point, or a background color if the ray escapes without hitting a surface [S1, unofficial].

**Data Structures:**
The algorithm maintains standard raymarching state variables for the current position $\mathbf{p}$ and current direction $\mathbf{d}$ [G]. No additional complex data structures are required beyond the SDF evaluation [G].

**Steps:**
1. **Initial March:** Perform standard raymarching along $\mathbf{d}$ using $S(\mathbf{p})$ until a surface is intersected at $\mathbf{p}_{entry}$ [S1, unofficial].
2. **Entry Refraction:** Compute the new ray direction $\mathbf{d}_{in}$ using the standard refraction formula with incident direction $\mathbf{d}$, surface normal $\mathbf{n}_{entry}$, and ratio $\eta$ [S1, unofficial].
3. **Nested March (Inside Glass):** Initialize a nested loop for marching inside the glass [S1, unofficial]. Set the current position $\mathbf{p}_{curr} = \mathbf{p}_{entry}$ and direction $\mathbf{d}_{curr} = \mathbf{d}_{in}$ [G]. Because the ray is inside the object, the signed distance values returned by $S$ are negative [S1, unofficial]. To march forward, subtract the negative distance (i.e., use its absolute value) when calculating the step size [S1, unofficial]. Loop: evaluate $d = S(\mathbf{p}_{curr})$. If $d > 0$, the ray has exited the object; break the nested loop. Otherwise, step forward: $\mathbf{p}_{curr} \leftarrow \mathbf{p}_{curr} + \mathbf{d}_{curr} \cdot \max(|d|, \epsilon)$ [G].
4. **Exit Refraction:** When the loop breaks because $d > 0$, the current position $\mathbf{p}_{exit}$ is near the exit surface [S1, unofficial]. Compute the exit normal $\mathbf{n}_{exit} = \nabla S(\mathbf{p}_{exit})$ [G]. The normal at the exit point points away from the object center (outward) [S1, unofficial]. For the refraction calculation from glass to air, use the negated normal $-\mathbf{n}_{exit}$ and the reciprocal of the entry refractive index, $1/\eta$ [S1, unofficial]. Compute the final direction $\mathbf{d}_{out} = \text{refract}(\mathbf{d}_{curr}, -\mathbf{n}_{exit}, 1/\eta)$ [S1, unofficial].
5. **Final March:** Continue raymarching along $\mathbf{d}_{out}$ in the external medium to find the final intersection or background [S1, unofficial].

**Pitfalls:**
* **Normal Direction:** When exiting, the SDF normal points outward. It must be negated ($-\mathbf{n}$) for the refraction formula to correctly compute the transmission from inside to outside [S1, unofficial].
* **Index Ratio:** The refractive index ratio must be inverted ($1/\eta$) upon exit, as the ray travels from the denser medium (glass) to the rarer medium (air) [S1, unofficial].
* **Negative Distances:** Inside the object, SDF values are negative. The marching logic must subtract these negative distances to step forward correctly [S1, unofficial].

**Pseudocode:**
```python
def nested_raymarch_refraction(ray_origin, ray_dir, sdf, eta, max_steps):
    # 1. Initial March
    pos = ray_origin
    dir = ray_dir
    hit = False
    for _ in range(max_steps):
        dist = sdf(pos)
        if dist < 0.001:
            hit = True
            break
        pos += dir * max(dist, 0.001)
    if not hit:
        return BACKGROUND_COLOR

    # 2. Entry Refraction
    normal_in = normalize(sdf_gradient(pos, sdf))
    dir_in = refract(dir, normal_in, eta)

    # 3. Nested March (Inside Glass)
    pos = pos + dir_in * 0.001 # Offset to avoid self-intersection [G]
    for _ in range(max_steps):
        dist = sdf(pos)
        if dist > 0.0: # Exit detected
            break
        # Inside glass, SDF values are negative. Subtract distances to march forward.
        step_size = max(abs(dist), 0.001)
        pos += dir_in * step_size

    # 4. Exit Refraction
    normal_out = normalize(sdf_gradient(pos, sdf))
    # Normal points away from surface; negate for internal-to-external refraction.
    # Index ratio is inverted (glass to air).
    dir_out = refract(dir_in, -normal_out, 1.0 / eta)

    # 5. Final March
    pos = pos + dir_out * 0.001
    for _ in range(max_steps):
        dist = sdf(pos)
        if dist < 0.001:
            break
        pos += dir_out * max(dist, 0.001)
    return compute_color(pos)

def refract(i, n, eta):
    # Standard vector refraction formula [G]
    dot = sum(a*b for a,b in zip(i, n))
    k = 1.0 - eta * eta * (1.0 - dot * dot)
    if k < 0.0:
        return i # Total internal reflection fallback
    return [eta * i[j] + (eta * dot - (k ** 0.5)) * n[j] for j in range(len(i))]

def sdf_gradient(p, sdf_func, eps=0.001):
    # Finite difference approximation of the SDF normal [G]
    return normalize([
        sdf_func([p[0]+eps, p[1], p[2]]) - sdf_func([p[0]-eps, p[1], p[2]]),
        sdf_func([p[0], p[1]+eps, p[2]]) - sdf_func([p[0], p[1]-eps, p[2]]),
        sdf_func([p[0], p[1], p[2]+eps]) - sdf_func([p[0], p[1], p[2]-eps])
    ])

def compute_color(p):
    return (1.0, 1.0, 1.0) # Shading logic not specified in sources [G]

def normalize(v):
    l = (sum(x*x for x in v))**0.5
    return [x/l for x in v] if l > 0 else v

BACKGROUND_COLOR = (0.0, 0.0, 0.0)
```

## Subtopics

### Two-Sided Refraction Beam Handling
A method to handle light passing through transparent objects by computing refraction beams at both front and back intersections simultaneously [S2]. It runs the refinement process once for both reflection and refraction, as the heuristic depends only on geometry [S2]. It computes the refraction beam at the first intersection and immediately computes the second refraction [S2]. To intersect rays from inside the objects, it uses a distance impostor: a cube map storing surface normals and distance from a reference point (typically the object's center) [S2]. This speeds up rendering but cannot render caustics inside the object [S2].

## Background
This method was described in the COS 426 Final Project Writeup on Raymarching with Signed Distance Fields [S1, unofficial]. It is presented as a "relatively simple glass-like effect" that is "the most tricky to get right" among reflection types [S1, unofficial]. The authors note that a more sophisticated approach modeling glass as a material that both reflects and refracts light was attempted but unsuccessful [S1, unofficial].
