# YUV Color Space Shading with Glow

Also called: YUV Shading, YUV Volume Shading

## Overview
This method performs volume raycasting illumination in the YUV color space to decouple luminance from chrominance [S1, unofficial]. It differs from standard RGB shading by computing lighting effects primarily on the luminance channel, while interpolating color channels based on a technique-derived factor [S1, unofficial].

## How it works
**Inputs:**
*   Surface point $\mathbf{p}$ and normal $\mathbf{n}$ (derived from SDF gradient [G]).
*   View direction $\mathbf{v}$ and light direction $\mathbf{l}$ [G].
*   Base color values $C_1, C_2$ in YUV space [S1, unofficial].
*   Interpolation factor $\alpha$ derived from the technique's output [S1, unofficial].
*   Glow mapping function $G(\cdot)$ and additional texture fetch for glow [S1, unofficial].

**Outputs:**
*   Final shaded color $C_{final}$ in YUV space [S1, unofficial].

**Data Structures:**
*   YUV Color Vector: $\mathbf{C} = [Y, U, V]^T$ [G].
*   Glow Texture: 2D or 3D texture storing glow intensity [S1, unofficial].

**Steps:**
1.  **Geometric Setup:** Compute normal $\mathbf{n}$, view vector $\mathbf{v}$, and light vector $\mathbf{l}$ [G].
2.  **Luminance Calculation:** Calculate the luminance component $Y$ as the minimum of two values, $Y_1$ and $Y_2$ [S1, unofficial]:
    $$ Y = \min(Y_1, Y_2) $$
3.  **Color Interpolation:** Interpolate the chrominance components ($U, V$) between two color states $\mathbf{C}_1$ and $\mathbf{C}_2$ using the factor $\alpha$ [S1, unofficial]:
    $$ \mathbf{C}_{interp} = (1 - \alpha) \mathbf{C}_1 + \alpha \mathbf{C}_2 $$
4.  **Specular Highlight (Optional):** Add specular highlights to the result [S1, unofficial].
5.  **Volumetric Glow:** Realize volumetric glow by exploiting an additional texture fetch and a glow mapping function [S1, unofficial]:
    $$ C_{final} = \mathbf{C}_{interp} + G(\text{GlowTexture}(\mathbf{p})) $$
    This allows indirect illumination to be captured independently of the transfer function [S1, unofficial].

**Pseudocode:**
```python
def yuv_shading_with_glow(p, n, v, l, C1_yuv, C2_yuv, alpha, glow_texture, glow_func):
    # Step 1: Geometric Setup [G]
    # n, v, l are assumed normalized

    # Step 2: Luminance Calculation [S1, unofficial]
    Y1 = C1_yuv[0]
    Y2 = C2_yuv[0]
    Y = min(Y1, Y2)

    # Step 3: Color Interpolation [S1, unofficial]
    U = (1.0 - alpha) * C1_yuv[1] + alpha * C2_yuv[1]
    V = (1.0 - alpha) * C1_yuv[2] + alpha * C2_yuv[2]

    # Step 4: Specular Highlights [S1, unofficial]
    h = normalize(v + l)
    spec = pow(max(dot(n, h), 0.0), 32.0)
    Y += spec

    # Step 5: Volumetric Glow [S1, unofficial]
    glow_intensity = glow_texture.sample(p)
    glow_contribution = glow_func(glow_intensity)
    Y += glow_contribution

    return [Y, U, V]
```

**Parameters:**
*   $\alpha$: Interpolation factor derived from the technique's output [S1, unofficial]. Typical values: Not given in the sources.
*   Glow Mapping Function: Specific implementation details not given in the sources.

**Edge Cases:**
*   Precision: YUV conversion and interpolation may introduce precision errors [S2, unofficial].
*   Boundaries: Not given in the sources.

## Subtopics

### RGB to YUV Conversion
Converts RGB images to YUV color space and back using JPEG standard conversion matrices [S2, unofficial].
*   **Definition:** Linear transformation using fixed 3x3 matrices [S2, unofficial].
*   **Parameters:**
    *   `RGB_TO_YUV`: Matrix `[[0.299, 0.587, 0.114], [-0.168736, -0.331264, 0.5], [0.5, -0.418688, -0.081312]]` [S2, unofficial].
    *   `YUV_TO_RGB`: Matrix `[[1.0, 0.0, 1.402], [1.0, -0.34414, -0.71414], [1.0, 1.772, 0.0]]` [S2, unofficial].
    *   `YUV_OFFSET`: Array `[0, 128.0, 128.0]` reshaped to `(1,1,-1)`, added to YUV output [S2, unofficial].
*   **When to use:** Not given in the sources.

## Background
Originated in Timo Ropinski's work on advanced illumination techniques for GPU-based volume raycasting [S1, unofficial]. The method leverages the YUV color space to simplify lighting calculations and enhance visual effects like glow [S1, unofficial]. The RGB to YUV conversion matrices are based on JPEG standards [S2, unofficial].
