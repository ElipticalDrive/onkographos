# Voxel Shader Volumetric Ray Marching

Also called: Phoenix Volumetric Rendering, V-Ray Volume Grid Shading

## Overview
Voxel Shader Volumetric Ray Marching is a shading method for Fire/Smoke simulations and meshes that reads voxel grid data from a Phoenix Simulator or V-Ray Volume Grid [S1]. It handles volumetric shading via specific rollouts (Fire, Smoke Color, Smoke Opacity) because standard Maya materials cannot shade volumetrics [S1]. It sets itself apart from its siblings by providing a dedicated UI-driven pipeline for Phoenix FD and V-Ray Volume Grids, offering specific controls for motion blur, displacement, and emission that are not available in generic voxel shading pipelines [S1].

## How it works
**Inputs and Outputs:**
*   **Inputs:** Voxel grid data (Temperature, Smoke, Speed, Fuel, Velocity, etc.), camera position/direction, light positions/directions, and shader parameters (Step %, Surface Channel, etc.) [S1].
*   **Outputs:** Color, Alpha, and optionally Render Elements (Normals, Velocity, Z-Depth, Material ID) [S1].

**Data Structures:**
*   **Voxel Grid:** A 3D array of cells. Each cell contains values for various channels (e.g., Temperature, Smoke) [S1].
*   **Velocity Texture:** A custom 3D texture where colors represent velocity direction per cell. Y/Z components are flipped (Blue/Green channels) [S1].

**Parameters:**
*   `rendstep` (Step %): Ray marching step as a percentage of cell size. Recommended >=90%. Must be >0. If >100, cells are skipped [S1].
*   `rendshadstep` (Shadow Step %): Ray marching step for shadow/lighting rays. Typically higher than `rendstep` [S1].
*   `borderFade`: Distance in Scene Units from grid boundaries where content becomes transparent [S1].
*   `mbmult` (Motion Blur Multiplier): Multiplier for motion blur strength. Can be negative [S1].
*   `sarg` (Surface Channel): Defines fluid surface for solid rendering/displacement. Options: Texture, Liquid/Temperature, Smoke, Speed, Fuel, Viscosity [S1].
*   `rendSurfLevel_x/t/s/v/f` (Isosurface Level): Threshold value for geometry surface generation. Default 0.5 [S1].
*   `rendInvertNorm` (Invert Volume): Swaps inside/outside definition. Default: values above surface level are internal [S1].
*   `rendUseGizmo` (Render Cutter): Restricts rendering to inside a selected geometric object's volume [S1].
*   `rendInvGizmo` (Invert Cutter): Restricts rendering to outside the cutter [S1].
*   `geommode` (Render as Geometry): V-Ray only. Produces result using procedural geometry (multiple transparent layers) [S1].
*   `rendHeatHaze` (Heat Haze): Traces ray changing direction according to Surface channel gradient. Value 1 approx normal heat haze [S1].
*   `emSource` (Fire Emission): Source channel for emissive fire color/light. Options: Disabled, Temperature, Smoke, Speed, Fuel, Texture [S1].
*   `emModulate` (Modulate): Multiplies Based on channel by Texture map [S1].
*   `difSource` (Smoke Color Based on): Source channel for smoke color. Options: Disabled, Temperature, Smoke, Speed, Texture, Constant Color, RGB, Fuel [S1].
*   `difModulate` (Smoke Color Modulate): Multiplies color by texture in Texture slot if Based on is not Texture [S1].
*   `difScattering` (Scattering): Controls light scattering. Options: Ray-traced (GI only), Disabled, Approximate [S1].
*   `rendDispl` (Displacement Amount): Displacement strength multiplier [S1].
*   `rendDisplFine` (Displacement Texture): Specifies the displacement map [S1].
*   `rendDispltSurf` (Displacement Type): Gradient driven, Surface driven, Vector, Advection [S1].
*   `emIgnoreAlpha` (Fire Opacity Mode): Use Smoke Opacity, Fully Visible, Use Own Opacity [S1].
*   `emLightsPersist` (Lights Persist): Forces simulator to emit light even if rendering is disabled [S1].
*   `rendVelTexture` (Velocity Texture): Custom 3D texture for motion blur. Overrides Velocity grid channel [S1].
*   `rendHeatHaze` (Heat Haze): Traces ray changing direction according to Surface channel gradient [S1].
*   `materialID` (Volumetric Material ID): Material ID color for the MaterialID Render Element [S1].
*   `volZDepth` (Volumetric ZDepth): Used to generate a Z-depth Render Element [S1].
*   `volMoblurMethod` (Volumetric Motion Blur): Ray-traced (default) vs Grid-based [S1].
*   `sampler` (Sampler Type): Box, Linear, Spherical [S1].

**Numbered Steps:**
1.  **Initialize Ray:** For each pixel, cast a ray from the camera through the voxel grid [S1].
2.  **Check Render Cutter:** If `rendUseGizmo` is enabled, check if the ray intersects the cutter volume. If `rendInvGizmo` is enabled, shade if the ray does *not* intersect the cutter [S1].
3.  **Determine Step Size:** Calculate the step size for the camera ray based on `rendstep` and the cell size. Calculate the step size for shadow rays based on `rendshadstep` [S1].
4.  **Ray Marching Loop:**
    a.  Advance the ray by the step size.
    b.  Sample the voxel grid at the current position.
    c.  If `sampler` is Box, use the value of the current cell. If Linear, blend with neighbors. If Spherical, use weight-based sampling [S1].
    d.  Apply `borderFade` if near grid boundaries [S1].
    e.  Accumulate color, opacity, and other properties based on the sampled values and shader parameters (Fire Emission, Smoke Color, etc.) [S1].
    f.  If `rendHeatHaze` is enabled, adjust the ray direction based on the gradient of the Surface channel [S1].
    g.  If `volMoblurMethod` is Grid-based, use pre-pass data for motion blur. If Ray-traced, use the velocity vector from the grid or `rendVelTexture` to stretch the contents [S1].
    h.  Check for termination conditions (e.g., full opacity, end of grid) [S1].
5.  **Shadow Ray Marching:** For each light, cast shadow rays using `rendshadstep` to determine occlusion [S1].
6.  **Displacement (if Render as Geometry):** If `geommode` is enabled, generate procedural geometry from the voxel grid using the `sarg` and `rendSurfLevel` parameters. Apply displacement using `rendDispl`, `rendDisplFine`, and `rendDispltSurf` [S1].
7.  **Output:** Return the accumulated color, alpha, and any requested Render Elements (Normals, Velocity, Z-Depth, Material ID) [S1].

**Formulas:**
*   **Step Size:** $step = rendstep \times cell\_size / 100$ [S1].
*   **Velocity Vector from Texture:** $v = (R, -B, -G)$ where R, G, B are the red, green, blue components of the `rendVelTexture` [S1].
*   **Heat Haze Direction:** The ray direction is adjusted based on the gradient of the Surface channel, scaled by `rendHeatHaze` [S1].

**Pseudocode:**
```python
def voxel_shader_volumetric_ray_marching(camera_ray, voxel_grid, params):
    # Initialize accumulation variables
    accumulated_color = (0, 0, 0)
    accumulated_alpha = 0
    
    # Determine step sizes
    camera_step = params['rendstep'] * voxel_grid.cell_size / 100
    shadow_step = params['rendshadstep'] * voxel_grid.cell_size / 100
    
    # Check Render Cutter
    if params['rendUseGizmo']:
        if not ray_intersects_gizmo(camera_ray, params['gizmo']):
            return (0, 0, 0, 0) # Outside cutter
    if params['rendInvGizmo']:
        if ray_intersects_gizmo(camera_ray, params['gizmo']):
            return (0, 0, 0, 0) # Inside cutter (if inverted)
            
    # Ray Marching Loop
    t = 0
    while t < params['max_distance']:
        # Advance ray
        current_pos = camera_ray.origin + camera_ray.direction * t
        
        # Check boundary fade
        if is_near_boundary(current_pos, voxel_grid, params['borderFade']):
            fade_factor = get_boundary_fade(current_pos, voxel_grid, params['borderFade'])
        else:
            fade_factor = 1.0
            
        # Sample voxel grid
        voxel_value = sample_voxel_grid(current_pos, voxel_grid, params['sampler'])
        
        # Apply border fade
        voxel_value *= fade_factor
        
        # Calculate emission and scattering
        emission = calculate_emission(voxel_value, params['emSource'], params['emTexture'], params['emModulate'])
        scattering = calculate_scattering(voxel_value, params['difSource'], params['difTexture'], params['difModulate'], params['difScattering'])
        
        # Accumulate
        alpha_contribution = voxel_value['opacity'] * fade_factor
        color_contribution = emission + scattering
        
        accumulated_color += color_contribution * (1 - accumulated_alpha)
        accumulated_alpha += alpha_contribution * (1 - accumulated_alpha)
        
        if accumulated_alpha >= 1.0:
            break
            
        # Heat Haze
        if params['rendHeatHaze'] > 0:
            gradient = calculate_surface_gradient(current_pos, voxel_grid, params['sarg'])
            camera_ray.direction += gradient * params['rendHeatHaze']
            camera_ray.direction = normalize(camera_ray.direction)
            
        # Motion Blur (Grid-based)
        if params['volMoblurMethod'] == 'Grid-based':
            # Use pre-pass data
            pass
        elif params['volMoblurMethod'] == 'Ray-traced':
            # Use velocity vector
            if params['rendVelTexture']:
                vel_color = sample_texture_3d(params['rendVelTexture'], current_pos)
                velocity = (vel_color.r, -vel_color.g, -vel_color.b) # Y/Z flipped
            else:
                velocity = voxel_grid.velocity[current_pos]
            # Stretch contents along velocity vector [G]
            
        t += camera_step
        
    return accumulated_color, accumulated_alpha

def calculate_emission(voxel_value, em_source, em_texture, em_modulate):
    if em_source == 'Disabled':
        return (0, 0, 0)
    elif em_source == 'Texture':
        color = sample_texture_2d(em_texture, voxel_value.uv)
        if em_modulate:
            color *= em_texture_modulation
        return color
    else:
        # Based on cache channel (Temperature, Smoke, etc.)
        channel_value = voxel_value[em_source]
        return remap_channel_to_color(channel_value, em_source)

def calculate_scattering(voxel_value, dif_source, dif_texture, dif_modulate, dif_scattering):
    if dif_scattering == 'Disabled':
        return (0, 0, 0)
    elif dif_scattering == 'Ray-traced':
        # Physically accurate scattering (requires GI) [G]
        return ray_traced_scattering(voxel_value, dif_source, dif_texture, dif_modulate)
    elif dif_scattering == 'Approximate':
        # Approximate scattering [G]
        return approximate_scattering(voxel_value, dif_source, dif_texture, dif_modulate)
    else:
        return (0, 0, 0)

def sample_voxel_grid(pos, voxel_grid, sampler_type):
    if sampler_type == 'Box':
        return voxel_grid.get_cell_value(pos)
    elif sampler_type == 'Linear':
        return linear_interpolation(pos, voxel_grid)
    elif sampler_type == 'Spherical':
        return spherical_weighted_sampling(pos, voxel_grid)
```

## Subtopics

### Smoke Color Mapping
Smoke Color Mapping determines the diffuse color of the smoke. It requires external light to become visible if GI is enabled. The `difSource` parameter specifies the source channel (Temperature, Smoke, Speed, Texture, Constant Color, RGB, Fuel). If `difSource` is not Texture, the color is multiplied by the texture in the `difTexture` slot if `difModulate` is enabled. The `difScattering` parameter controls light scattering (Ray-traced, Disabled, Approximate) [S1].

## Operating characteristics
*   **Time Complexity:** Depends on the number of steps per ray, which is determined by `rendstep` and the grid resolution. Shadow rays add additional complexity. Grid-based motion blur requires a pre-pass, increasing time [S1].
*   **Memory Complexity:** Depends on the voxel grid size and the number of channels stored. Grid-based motion blur requires additional memory for pre-pass data [S1].
*   **Measured Performance:** Box sampler is the fastest. Linear is 20-30% faster than Spherical. Spherical is the smoothest but slowest [S1].
*   **Scaling:** Performance scales with grid resolution and the number of lights. Increasing `rendstep` or `rendshadstep` improves performance but reduces quality [S1].
*   **Strengths:** Provides detailed control over volumetric shading for Phoenix FD and V-Ray Volume Grids. Supports various displacement types and motion blur methods [S1].
*   **Limitations:** `Render as Geometry` slows down rendering. Grid-based motion blur requires more memory. Standard Maya materials cannot be used [S1].
*   **When to Use:** When rendering Fire/Smoke simulations from Phoenix FD or V-Ray Volume Grids in Maya.
*   **When Not to Use:** When using standard Maya materials or when performance is critical and high quality is not required (use Box sampler) [S1].

## Background
The Voxel Shader is part of the Phoenix FD plugin for Maya, developed by Chaos Group. It is designed to work with Phoenix Simulator and V-Ray Volume Grid data [S1].
