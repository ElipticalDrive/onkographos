# Voxel Neighborhood Light Gathering


## Overview
Voxel Neighborhood Light Gathering computes local lighting conditions for a target voxel by sampling the light intensity of its 26 immediate neighbors within a voxel chunk [S1, unofficial]. It solves discontinuous lighting at chunk boundaries and provides smoothed shading for voxel engines by aggregating neighbor data [S1, unofficial]. It differs from its parent [fast_shade1](5608-fast-shade1.md) by explicitly handling inter-chunk neighbor lookups and boundary conditions [S1, unofficial].

## How it works
**Inputs:**
- `voxel`: The target `ChunkVoxel` for which lighting is calculated [S1, unofficial].
- `chunk`: The voxel chunk containing the target voxel, providing access to neighbor chunks and local coordinate mapping [S1, unofficial].

**Outputs:**
- `neighborhood`: An array of size `NEIGHBOR_COUNT` (26) containing the light intensity (`Option<u8>`) of each neighbor [S1, unofficial].

**Data Structures:**
- `neighborhood`: An array of length 26. Each element stores the light intensity of a neighbor [S1, unofficial]. If a neighbor is inaccessible or invalid, the value is `None` or a default max intensity [S1, unofficial].
- `IVec3`: A 3D integer vector type representing voxel coordinates $(x, y, z)$ [S1, unofficial].
- `IVec2`: A 2D integer vector type used for mapping coordinates across chunk boundaries [S1, unofficial].

**Parameters:**
- `NEIGHBOR_COUNT`: `usize = 26`. Calculated as $(3 \times 3 \times 3) - 1$, representing all voxels in a $3 \times 3 \times 3$ cube centered on the target voxel, excluding the center itself [S1, unofficial].
- `MAX_NATURAL_INTENSITY`: A constant representing the maximum possible natural light intensity, used as a fallback for out-of-bounds or missing neighbors [S1, unofficial].

**Steps:**
1. Initialize a mutable array `neighborhood` of size `NEIGHBOR_COUNT` with default values (`None`) [S1, unofficial].
2. Retrieve the base chunk's light and kind storage using `get_light` and `get_kind` [S1, unofficial].
3. Convert the input `voxel` (`ChunkVoxel`) to an `IVec3` base coordinate, denoted as `base_voxel` [S1, unofficial].
4. Iterate through neighbor offsets using three nested loops: `y` from -1 to 1, `z` from -1 to 1, `x` from -1 to 1 [S1, unofficial].
5. Construct a direction vector `dir = IVec3::new(x, y, z)` [S1, unofficial].
6. If `dir` is the zero vector $(0, 0, 0)$, skip to the next iteration [S1, unofficial].
7. Calculate the neighbor voxel coordinate: `side_voxel = base_voxel + dir` [S1, unofficial].
8. Determine if `side_voxel` is within the current chunk's horizontal bounds. The source specifies checking if `y == 0` for horizontal bounds, which implies a specific coordinate system orientation where the Y-axis is vertical and X/Z are horizontal [S1, unofficial].
   - **If out of bounds horizontally:**
     - Calculate the neighbor chunk using `chunk.neighbor(dir)` [S1, unofficial].
     - Calculate the local voxel coordinate in that chunk using `chunk::overlap_voxel(voxel, IVec2::new(dir.x, dir.z))` [S1, unofficial].
     - Retrieve light and kind data from the neighbor chunk [S1, unofficial].
     - If the neighbor chunk does not exist or light/kind data is unavailable, set intensity to `MAX_NATURAL_INTENSITY` [S1, unofficial].
     - Otherwise, apply the same opaque/zero check used for internal voxels to determine the final intensity [S1, unofficial].
   - **If within bounds:**
     - Retrieve light and kind data from the current chunk's storage [S1, unofficial].
     - Apply the opaque/zero check to determine the intensity [S1, unofficial].
9. Store the calculated `intensity` (`Option<u8>`) into the `neighborhood` array at the current index `i` and increment `i` [S1, unofficial].
10. After iterating through all 26 neighbors, return the populated `neighborhood` array [S1, unofficial].

**Pseudocode:**
```python
from typing import List, Optional, Tuple

# Standard vector types as defined in the source context [G]
IVec3 = Tuple[int, int, int]
IVec2 = Tuple[int, int]

def gather_neighborhood_light(voxel: 'ChunkVoxel', chunk: 'VoxelChunk') -> List[Optional[int]]:
    NEIGHBOR_COUNT = 26
    MAX_NATURAL_INTENSITY = 255  # Value not specified in sources [G]
    neighborhood: List[Optional[int]] = [None] * NEIGHBOR_COUNT
    i = 0

    base_voxel: IVec3 = voxel.to_ivec3()
    light_storage = chunk.get_light()
    kind_storage = chunk.get_kind()

    for y in range(-1, 2):
        for z in range(-1, 2):
            for x in range(-1, 2):
                if x == 0 and y == 0 and z == 0:
                    continue

                dir: IVec3 = (x, y, z)
                side_voxel: IVec3 = (base_voxel[0] + dir[0], base_voxel[1] + dir[1], base_voxel[2] + dir[2])

                intensity: Optional[int] = None

                # Check horizontal bounds condition from source [S1, unofficial]
                if side_voxel[1] == 0:  # y == 0 check per source notes
                    neighbor_chunk = chunk.neighbor(dir)
                    if neighbor_chunk is None:
                        intensity = MAX_NATURAL_INTENSITY
                    else:
                        local_coord: IVec2 = (dir[0], dir[2])
                        n_light = neighbor_chunk.get_light()
                        n_kind = neighbor_chunk.get_kind()
                        if n_light is None or n_kind is None:
                            intensity = MAX_NATURAL_INTENSITY
                        else:
                            # Opaque/zero check logic not detailed in sources [G]
                            intensity = n_light if n_kind > 0 else 0
                else:
                    c_light = light_storage.get(side_voxel)
                    c_kind = kind_storage.get(side_voxel)
                    if c_light is None or c_kind is None:
                        intensity = MAX_NATURAL_INTENSITY
                    else:
                        # Opaque/zero check logic not detailed in sources [G]
                        intensity = c_light if c_kind > 0 else 0

                neighborhood[i] = intensity
                i += 1

    return neighborhood
```

**Edge Cases and Pitfalls:**
- **Chunk Boundaries:** The method must correctly handle neighbors that lie in adjacent chunks using `chunk.neighbor(dir)` and `chunk::overlap_voxel` [S1, unofficial].
- **Missing Neighbors:** If a neighbor chunk does not exist or light/kind data is unavailable, the intensity defaults to `MAX_NATURAL_INTENSITY` [S1, unofficial].
- **Coordinate System:** The source's mention of `y == 0` for horizontal bounds is specific to the engine's coordinate system [S1, unofficial].
- **Opaque/Zero Check:** The exact logic for the opaque/zero check is not detailed in the source [S1, unofficial]. Implementers should define it based on their voxel kind definitions [G].

## Operating characteristics
- **Time Complexity:** $O(1)$ per voxel, as it always checks a fixed number of 26 neighbors [G].
- **Memory Complexity:** $O(1)$ per voxel, requiring storage for 26 neighbor intensities [G].
- **Strengths:** Simple to implement, fast, handles chunk boundaries explicitly [G].
- **Limitations:** Limited to local lighting effects, may not capture global lighting phenomena like shadows or reflections accurately [G].

## Background
Voxel Neighborhood Light Gathering is part of the "projekto" project by afonsolage [S1, unofficial]. It is designed for voxel engines that use chunk-based data structures and require efficient, local lighting calculations [S1, unofficial]. The method builds on the assumptions of [fast_shade1](5608-fast-shade1.md) but extends it to handle inter-chunk lighting more robustly [S1, unofficial].
