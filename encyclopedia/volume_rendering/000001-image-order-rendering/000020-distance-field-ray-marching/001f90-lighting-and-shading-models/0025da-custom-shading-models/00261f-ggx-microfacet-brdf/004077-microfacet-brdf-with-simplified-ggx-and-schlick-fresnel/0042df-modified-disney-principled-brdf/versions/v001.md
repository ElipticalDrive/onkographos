# Modified Disney Principled BRDF

Also called: ABSDF Base Material, Base Material Model

## Overview
A simplified material model based on the Disney Principled BRDF, modified specifically to enable analytical factorization for Absorption-Based Scene Diffusion (ABSDF) rendering [S1, unofficial]. It differs from the original Disney model by replacing the empirical diffuse lobe with a Lambertian model, omitting sheen and clearcoat, and assuming double-sided surfaces to facilitate mathematical decomposition into separable components [S1, unofficial].

## How it works
**Inputs and Outputs:**
*   **Inputs:** Incoming light direction $\omega_i$, outgoing view direction $\omega_o$, surface normal $n$, half vector $\omega_h = \frac{\omega_i + \omega_o}{\|\omega_i + \omega_o\|}$, and material parameters $\beta_B = (\alpha, \beta_c, \beta_m, \beta_s)$.
    *   $\alpha$: Roughness.
    *   $\beta_c$: Base color (diffuse albedo).
    *   $\beta_m$: Metallic factor.
    *   $\beta_s$: Specular intensity (dielectric reflectance).
*   **Output:** Bidirectional Reflectance Distribution Function (BRDF) value $f_{disney}(\omega_i, \omega_o)$.

**Data Structures:**
The material state is defined by the parameter tuple $\beta_B$. In the context of ABSDF, these parameters may be spatially varying, represented by their joint probability density function $p(\beta_c, \beta_m)$ and normal distribution $p_N(n)$ [S1, unofficial].

**Formulas:**
The total BRDF is the sum of diffuse and specular components:
$$ f_{disney}(\omega_i, \omega_o) = f_d(\omega_i, \omega_o) + f_s(\omega_i, \omega_o) $$

1.  **Diffuse Component ($f_d$):**
    Uses a Lambertian model scaled by the base color and modulated by the metallic factor:
    $$ f_d(\omega_i, \omega_o) = \frac{(1 - \beta_m)\beta_c}{\pi} $$
    [S1, unofficial]

2.  **Specular Component ($f_s$):**
    Combines metallic and dielectric Fresnel reflections using the microfacet model:
    $$ f_s(\omega_i, \omega_o) = \frac{D(\omega_h; \alpha)G(\omega_i, \omega_o; \alpha)}{4|n \cdot \omega_o||n \cdot \omega_i|} \left[ \beta_m F(\omega_h, \omega_o; \beta_c) + (1 - \beta_m)F(\omega_h, \omega_o; \beta_s) \right] $$
    [S1, unofficial]

    *   **Microfacet Distribution ($D$):** Trowbridge-Reitz (GGX) distribution [S1, unofficial].
    *   **Shadowing-Masking ($G$):** Standard geometry function [S1, unofficial].
    *   **Fresnel Term ($F$):** Schlick Fresnel approximation:
        $$ F(\omega_h, \omega_o; r_0) = r_0 (1 - F_c) + F_c $$
        $$ F_c = (1 - |\omega_h \cdot \omega_o|)^5 $$
        where $r_0$ is the normal incidence reflectance. For the metallic lobe, $r_0 = \beta_c$. For the dielectric lobe, $r_0 = \beta_s$ [S1, unofficial].

**Pseudocode:**
```python
def modified_disney_brdf(omega_i, omega_o, n, alpha, beta_c, beta_m, beta_s):
    # Calculate half vector
    h = normalize(omega_i + omega_o)
    cos_theta_o = dot(n, omega_o)
    cos_theta_i = dot(n, omega_i)
    
    # Handle double-sided assumption: use absolute dot products
    abs_cos_o = abs(cos_theta_o)
    abs_cos_i = abs(cos_theta_i)
    
    # Diffuse component: Lambertian
    # f_d = (1 - beta_m) * beta_c / pi
    diffuse = ((1.0 - beta_m) * beta_c) / PI
    
    # Specular component
    # 1. Fresnel
    # F_c = (1 - |h . o|)^5
    # Note: h . o is equivalent to h . i due to symmetry
    cos_h_o = abs(dot(h, omega_o))
    F_c = pow(1.0 - cos_h_o, 5.0)
    
    # Metallic Fresnel: r0 = beta_c
    F_metal = beta_c * (1.0 - F_c) + F_c
    
    # Dielectric Fresnel: r0 = beta_s
    F_diel = beta_s * (1.0 - F_c) + F_c
    
    # 2. Microfacet Distribution D (GGX)
    # D(alpha, h) = alpha^2 / (pi * ((cos_theta_h^2 * (alpha^2 - 1) + 1)^2))
    # cos_theta_h = dot(n, h)
    cos_theta_h = dot(n, h)
    alpha_sq = alpha * alpha
    denom = (cos_theta_h * cos_theta_h) * (alpha_sq - 1.0) + 1.0
    D = (alpha_sq) / (PI * denom * denom)
    
    # 3. Geometry Function G
    # Standard Smith geometry for GGX
    # G(kappa, cos_theta) = cos_theta / (cos_theta * (1 - kappa) + kappa)
    # where kappa is derived from alpha. 
    # For implementation completeness, we assume a standard GGX G function.
    # G_total = G(lambda(omega_i)) * G(lambda(omega_o))
    # lambda(v) = (-1 + sqrt(alpha^2 + (v . n)^2) / (v . n)) / 2
    # This part is standard GGX and not explicitly detailed in the source text 
    # beyond referencing G(wi, wo; alpha).
    
    # Placeholder for standard GGX Geometry function G
    G = ggx_geometry(alpha, omega_i, omega_o, n)
    
    # Specular BRDF
    # f_s = D * G / (4 * |n.o| * |n.i|) * [beta_m * F_m + (1-beta_m) * F_d]
    specular = (D * G) / (4.0 * abs_cos_o * abs_cos_i)
    fresnel_mix = beta_m * F_metal + (1.0 - beta_m) * F_diel
    specular *= fresnel_mix
    
    return diffuse + specular
```
[G] The source text references $G(\omega_i, \omega_o; \alpha)$ but does not provide the explicit Smith geometry formula. The pseudocode includes a placeholder `ggx_geometry` which must be implemented using the standard Smith geometry function for GGX distributions to be complete.

## Subtopics

### Diffuse ABSDF Factorization
A mathematical technique applied to the diffuse component of the Modified Disney BRDF to enable efficient rendering. It assumes $\beta_c$ and $\beta_m$ are orientation-independent to split the integral into parameter moments and geometric terms. The parameter integral reduces to $E[\beta_c] - E[\beta_m \beta_c]$, while the geometric term $\langle n \cdot \omega_i \rangle \langle n \cdot \omega_o \rangle$ is approximated by a Spherical Gaussian (SG) product $c \cdot SG(\omega_h; n, \kappa)$ to allow closed-form convolution with the SGGX distribution [S1, unofficial].

## Operating characteristics
*   **Complexity:** The base evaluation is $O(1)$ per shading point. The ABSDF factorization enables $O(1)$ aggregation for specific rendering techniques by precomputing moments and SG approximations.
*   **Strengths:** Simplified analytical form allows for efficient factorization and integration in ABSDF pipelines. Supports spatially varying parameters.
*   **Limitations:** Lacks the visual fidelity of the full Disney model due to the omission of sheen, clearcoat, and the empirical retro-reflection diffuse lobe. Not suitable for materials requiring sharp specular highlights or iridescence.
*   **Use Cases:** Best suited for real-time or large-scale rendering where the underlying asset uses the Disney Principled BRDF and requires efficient scene aggregation or level-of-detail rendering [S1, unofficial].

## Background
The model originates from the work on "Efficient Scene Appearance Aggregation for Level-of-Detail Rendering" [S1, unofficial]. It was developed to support the widest applicability by targeting the Disney Principled BRDF [Burley 2012], which is common in production assets. The modifications were made to facilitate the ABSDF factorization method, allowing the complex Disney model to be decomposed into analytically tractable components for efficient rendering [S1, unofficial].
