# Aggregated Microfacet Distribution Approximation

Also called: Beta Distribution Fitting, Roughness Aggregation

## Overview
This method approximates the statistical aggregation of microfacet distributions over a distribution of roughness values, enabling efficient rendering of scenes with material variation. It solves the problem of computing the expectation of a microfacet distribution $D_{mic}$ when the roughness parameter $\alpha$ is not a single value but follows a probability density function $p_A(\alpha)$. Unlike single-lobed approximations that simply average roughness, this method uses a two-lobed weighted sum to capture the statistical spread, providing higher accuracy while maintaining computational efficiency [S1, unofficial].

## How it works
**Inputs:**
- The shape parameters $a$ and $b$ of the Beta distribution $B(\alpha; a, b)$ modeling the roughness distribution $p_A(\alpha)$ [S1, unofficial].
- The microfacet distribution function $D_{mic}(\omega_h; \alpha)$ (typically GGX) [S1, unofficial].

**Outputs:**
- A weighted two-lobe approximation $\hat{D}_{mic}(\omega_h)$ defined by weights $m_1, m_2$ and roughness values $\alpha_1, \alpha_2$ [S1, unofficial].

**Data Structures:**
- A 2D lookup table storing the mapping $(m_1, \alpha_1, \alpha_2) = M_2(a, b)$ for discrete values of shape parameters $a$ and $b$ [S1, unofficial].

**Steps:**
1. Model the roughness distribution $p_A(\alpha)$ using a Beta distribution $B(\alpha; a, b)$, acknowledging that $\alpha$ is bounded in $[0, 1]$ [S1, unofficial].
2. Define the aggregated microfacet distribution as the expectation:
   $$ \hat{D}_{mic}(\omega_h) = \int_0^1 D_{mic}(\omega_h; \alpha) p_A(\alpha) d\alpha $$
3. Approximate the integral using a weighted sum of two microfacet lobes:
   $$ \hat{D}_{mic}(\omega_h) \approx m_1 D_{mic}(\omega_h; \alpha_1) + m_2 D_{mic}(\omega_h; \alpha_2) $$
   where $m_1 + m_2 = 1$ [S1, unofficial].
4. Perform a nonlinear least-square fit to find the mapping $(m_1, \alpha_1, \alpha_2) = M_2(a, b)$ that minimizes the error between the approximation and the ground-truth integral for given $a, b$ [S1, unofficial].
5. Store the resulting mapping in a 2D table indexed by $a$ and $b$ for runtime retrieval [S1, unofficial].

## Subtopics

### [Aggregated Microfacet Distribution via Beta Distribution](10888-aggregated-microfacet-distribution-via-beta-distribution.md)
This variant explicitly models the aggregated microfacet roughness distribution $p_A(\alpha)$ using a Beta distribution $B(\alpha; a, b)$ to estimate the statistical spread of roughness values $\alpha$ from asset data. It is chosen over Gaussian approximations because the Beta distribution is naturally bounded within the valid $[0, 1]$ range of $\alpha$, preventing the invalid range errors that occur when Gaussian tails exceed these bounds.

### [Aggregated Bidirectional Scattering Distribution Function (ABSDF)](13367-aggregated-bidirectional-scattering-distribution-function-ab.md)
The Aggregated Bidirectional Scattering Distribution Function (ABSDF) is a method for efficient scene appearance aggregation for Level-of-Detail (LoD) rendering, designed to handle scenes with high geometric complexity and instancing. It defines a 4D function of incident and outgoing directions that describes the far-field appearance of a scene aggregate by integrating the 8D light transport function over positions, effectively capturing the aggregated appearance of all surfaces within a volume. Unlike explicit geometry rendering, ABSDF precomputes aggregated visibility and material properties, allowing the renderer to avoid tracing explicit geometry and shadow rays, thereby reducing the sample count required for convergence. It builds on Aggregated Microfacet Distribution Approximation by providing a closed-form factorization that supports all-frequency and view-dependent effects.

### 2-Lobe Microfacet Distribution Fit
A method to fit aggregated microfacet distributions using a 2-lobe weighted sum, compared against ground-truth and single-lobe fits with simple averaged roughness [S1, unofficial]. The 2-lobe fit is overall more accurate and guaranteed to be never worse than simple fits [S1, unofficial].

## Operating characteristics
**Time and Memory Complexity:**
- Runtime cost is dominated by the evaluation of two microfacet distributions and a table lookup, making it $O(1)$ with respect to the number of roughness samples, compared to $O(N)$ for numerical integration [S1, unofficial].
- Memory usage is determined by the size of the 2D lookup table for $M_2(a, b)$, which depends on the resolution of $a$ and $b$ discretization [S1, unofficial].

**Measured Performance:**
- The method provides a good balance between cost and accuracy, with $k=2$ lobes being sufficient for most cases [S1, unofficial].
- It is more accurate than single-lobe fits with simple averaged roughness and is guaranteed to be never worse than such simple fits [S1, unofficial].

**Strengths and Limitations:**
- **Strengths:** Handles roughness variation efficiently; avoids invalid ranges for $\alpha$; more accurate than simple averaging.
- **Limitations:** Requires offline fitting and storage of a lookup table; accuracy depends on the quality of the Beta distribution fit and the resolution of the table [S1, unofficial].

**When to Use:**
- Use when rendering scenes with material variation or aggregated microfacet distributions where efficiency is critical and simple averaging is insufficient [S1, unofficial].

**When Not to Use:**
- Avoid if the roughness distribution is known to be a single value (no aggregation needed) or if higher accuracy is required than what a 2-lobe approximation can provide [S1, unofficial].

## Background
The method originates from research on efficient scene appearance aggregation for Level-of-Detail rendering [S1, unofficial]. It addresses the need to represent complex material variations without explicit geometry, leveraging statistical approximations of microfacet distributions [S1, unofficial].
