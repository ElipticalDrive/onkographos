# Microfacet BRDF with Simplified GGX and Schlick Fresnel

Also called: NeRV BRDF, Walter et al. BRDF with Filament/Unreal simplifications

## Overview
This method defines a microfacet Bidirectional Reflectance Distribution Function (BRDF) that combines the GGX normal distribution with Schlick Fresnel approximation and a simplified Smith geometry function, as used in the NeRV renderer [S1]. It differs from standard implementations by incorporating specific algebraic simplifications from the Filament and Unreal Engine renderers to facilitate analytical factorization for Absorption-Based Scene Diffusion (ABSDF) rendering [S1]. The primary distinction is the inclusion of the Lambert cosine term $(\mathbf{n} \cdot \boldsymbol{\omega}_i)$ directly within the specular component's structure to simplify downstream mathematical decomposition, resulting in a non-standard separable form [S1].

## How it works
**Inputs:**
- $\mathbf{x}$: 3D surface location.
- $\boldsymbol{\omega}_i$: Incoming light direction (unit vector).
- $\boldsymbol{\omega}_o$: Outgoing view direction (unit vector).
- $\mathbf{n}$: Surface normal at $\mathbf{x}$ (unit vector).
- $\gamma$: Roughness parameter (scalar, $\gamma \ge 0$).
- $\mathbf{a}$: Diffuse albedo (scalar, $0 \le \mathbf{a} \le 1$).
- $F_0$: Fresnel reflectance at normal incidence (scalar, default $0.04$ for dielectrics) [S1].

**Outputs:**
- $R(\mathbf{x}, \boldsymbol{\omega}_i, \boldsymbol{\omega}_o)$: Reflectance value (scalar).

**Data Structures:**
No complex data structures are required; the method relies on vector dot products and scalar arithmetic.

**Steps:**
1. Compute the half-vector $\mathbf{h}$:
   $$ \mathbf{h} = \frac{\boldsymbol{\omega}_o + \boldsymbol{\omega}_i}{\|\boldsymbol{\omega}_o + \boldsymbol{\omega}_i\|} $$
2. Compute the auxiliary roughness parameter $\rho$:
   $$ \rho = \gamma^2 $$
3. Compute the auxiliary geometry parameter $k$:
   $$ k = \frac{\gamma^4}{2} $$
4. Compute the dot products:
   - $n_h = \mathbf{n} \cdot \mathbf{h}$
   - $n_i = \mathbf{n} \cdot \boldsymbol{\omega}_i$
   - $n_o = \mathbf{n} \cdot \boldsymbol{\omega}_o$
   - $h_i = \boldsymbol{\omega}_i \cdot \mathbf{h}$
5. Compute the Normal Distribution Function $D(\mathbf{h}, \mathbf{n}, \gamma)$:
   $$ D = \frac{\rho^2}{\pi \left( n_h^2 (\rho^2 - 1) + 1 \right)^2} $$
6. Compute the Fresnel Function $F(\boldsymbol{\omega}_i, \mathbf{h})$ using Schlick's approximation:
   $$ F = F_0 + (1 - F_0)(1 - h_i)^5 $$
7. Compute the Geometry Function $G(\boldsymbol{\omega}_i, \boldsymbol{\omega}_o, \gamma)$:
   $$ G = \frac{n_o n_i}{\left( n_o (1 - k) + k \right) \left( n_i (1 - k) + k \right)} $$
8. Compute the final BRDF $R$:
   $$ R = \frac{D \cdot F \cdot G}{4 n_o} + n_i (1 - F) \frac{\mathbf{a}}{\pi} $$

**Pseudocode:**
```python
def microfacet_brdf_simplified_ggx_schlick(
    n: Vector3, 
    wi: Vector3, 
    wo: Vector3, 
    gamma: float, 
    a: float, 
    F0: float = 0.04
) -> float:
    # Step 1: Half vector
    h = normalize(wo + wi)
    
    # Step 2 & 3: Auxiliary parameters
    rho = gamma * gamma
    k = (gamma ** 4) / 2.0
    
    # Step 4: Dot products
    n_dot_h = dot(n, h)
    n_dot_i = dot(n, wi)
    n_dot_o = dot(n, wo)
    h_dot_i = dot(h, wi)
    
    # Step 5: Normal Distribution D
    # D = rho^2 / (pi * (n_dot_h^2 * (rho^2 - 1) + 1)^2)
    denom_D = n_dot_h * n_dot_h * (rho * rho - 1.0) + 1.0
    D = (rho * rho) / (math.pi * denom_D * denom_D)
    
    # Step 6: Fresnel F
    # F = F0 + (1 - F0) * (1 - h_dot_i)^5
    F = F0 + (1.0 - F0) * ((1.0 - h_dot_i) ** 5)
    
    # Step 7: Geometry G
    # G = (n_dot_o * n_dot_i) / ((n_dot_o * (1 - k) + k) * (n_dot_i * (1 - k) + k))
    term_o = n_dot_o * (1.0 - k) + k
    term_i = n_dot_i * (1.0 - k) + k
    G = (n_dot_o * n_dot_i) / (term_o * term_i)
    
    # Step 8: Final BRDF
    # Note: The specular term includes n_dot_i in the numerator structure 
    # effectively via G, but the formula divides by 4*n_dot_o.
    # The diffuse term is n_dot_i * (1 - F) * (a / pi)
    
    specular_term = (D * F * G) / (4.0 * n_dot_o)
    diffuse_term = n_dot_i * (1.0 - F) * (a / math.pi)
    
    return specular_term + diffuse_term
```

**Edge Cases and Pitfalls:**
- The definition includes the multiplication by the Lambert cosine term $(\mathbf{n} \cdot \boldsymbol{\omega}_i)$ implicitly in the structure of the equations to simplify the main paper's derivations [S1]. This means the geometric term $G$ and the diffuse term are structured differently than standard separable forms, which may cause integration errors if used in standard Monte Carlo estimators without adjustment [S1].
- If $\boldsymbol{\omega}_o + \boldsymbol{\omega}_i$ is near zero (opposing directions), normalization of $\mathbf{h}$ becomes unstable.
- $F_0$ is set to $0.04$ for dielectrics; for conductors, this value should be replaced with the complex index of refraction derived reflectance [S1].

## Subtopics

### [Modified Disney Principled BRDF](10860-modified-disney-principled-brdf.md)
A simplified material model based on the Disney Principled BRDF, modified specifically to enable analytical factorization for Absorption-Based Scene Diffusion (ABSDF) rendering. It differs from the original Disney model by replacing the empirical diffuse lobe with a Lambertian model, omitting sheen and clearcoat, and assuming double-sided surfaces to facilitate mathematical decomposition into separable components.

## Operating characteristics
- **Time Complexity:** $O(1)$ per shading point. The computation involves a fixed number of vector operations, dot products, and polynomial evaluations.
- **Memory Complexity:** $O(1)$ auxiliary storage.
- **Strengths:** The simplifications allow for analytical factorization, which is beneficial for methods like Absorption-Based Scene Diffusion (ABSDF) [S1]. It balances physical plausibility with computational efficiency.
- **Limitations:** The non-standard inclusion of the cosine term in the specular formulation limits direct compatibility with standard path tracing integrators that assume standard BRDF definitions [S1].
- **When to use:** When implementing NeRV or similar neural radiance field methods that require analytical factorization of the reflectance function [S1].
- **When not to use:** For standard physically based rendering pipelines where strict adherence to standard microfacet BRDF definitions is required for energy conservation and consistency with other shading models.

## Background
The method originates from the NeRV (Neural Reflectance and Visibility Fields) paper, which utilizes the standard microfacet BRDF described by Walter et al. [55] but incorporates simplifications from the Filament [15] and Unreal Engine [20] rendering engines [S1]. It was introduced to facilitate the analytical factorization required for the NeRV method's specific rendering approach [S1].
