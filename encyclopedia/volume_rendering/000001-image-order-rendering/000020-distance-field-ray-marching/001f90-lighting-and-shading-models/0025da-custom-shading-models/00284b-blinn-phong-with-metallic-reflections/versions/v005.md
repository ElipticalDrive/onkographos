# Blinn-Phong with Metallic Reflections

Also called: Neon City Lighting, Wet Asphalt Shader

## Overview
A custom shading model for ray-marched signed distance fields that extends the classic Blinn-Phong approximation with environment reflections and emissive contributions to simulate urban night scenes [S1, unofficial]. It distinguishes itself from standard Blinn-Phong by modulating specular intensity, power, and reflection weight based on a material's metallic property, and from GGX microfacet models by using a simplified Schlick-like Fresnel term rather than a full microfacet distribution [S1, unofficial].

## How it works
**Inputs:**
- Surface point $\mathbf{p}$ in world space [S1, unofficial].
- Ray direction $\mathbf{rd}$ (from camera to $\mathbf{p}$, normalized) [S1, unofficial].
- Material structure `sf` containing `albedo` (base color), `metal` (float in $[0, 1]$), and `emissive` (self-illuminated color) [S1, unofficial].
- Scene functions: `calcNormal(p)`, `softShadow(p, l, radius)`, `calcAO(p, n)`, `skyColor(r)` [S1, unofficial].

**Outputs:**
- Final color `vec3` [S1, unofficial].

**Data Structures:**
The material structure `sf` is determined by a material ID derived from the SDF evaluation (e.g., via hashing cell coordinates) [S1, unofficial].

**Steps:**
1. Calculate normal $\mathbf{n} = \text{calcNormal}(\mathbf{p})$ [S1, unofficial].
2. Determine surface properties (`sf.albedo`, `sf.metal`, `sf.emissive`) based on material ID [S1, unofficial].
3. Define light direction $\mathbf{l} = \text{normalize}(\text{vec3}(-0.5, 0.8, -0.25))$ and light color $\mathbf{c}_L = \text{vec3}(0.5, 0.65, 1.0)$ [S1, unofficial].
4. Calculate diffuse factor $d = \max(\mathbf{n} \cdot \mathbf{l}, 0.0)$ [S1, unofficial].
5. Calculate shadow factor $s = \text{softShadow}(\mathbf{p} + \mathbf{n} \cdot 0.03, \mathbf{l}, 12.0)$ [S1, unofficial].
6. Apply shadow to diffuse: $d \leftarrow d \cdot s$ [S1, unofficial].
7. Calculate half-vector $\mathbf{h} = \text{normalize}(\mathbf{l} - \mathbf{rd})$ [S1, unofficial].
8. Calculate specular intensity $\text{spec} = \text{pow}(\max(\mathbf{n} \cdot \mathbf{h}, 0.0), \text{mix}(32.0, 140.0, \text{sf.metal})) \cdot s$ [S1, unofficial].
9. Calculate ambient occlusion $\text{ao} = \text{calcAO}(\mathbf{p}, \mathbf{n})$ [S1, unofficial].
10. Calculate base color $\mathbf{c}_{\text{base}} = \text{sf.albedo} \cdot (\text{ambient} \cdot \text{ao}) + \text{sf.albedo} \cdot \mathbf{c}_L \cdot d + \mathbf{c}_L \cdot \text{spec} \cdot \text{mix}(0.4, 2.0, \text{sf.metal})$ [S1, unofficial].
11. Calculate Fresnel term $F = \text{pow}(1.0 - \max(\mathbf{n} \cdot (-\mathbf{rd}), 0.0), 5.0)$ [S1, unofficial].
12. Calculate reflected color $\mathbf{c}_{\text{refl}} = \text{skyColor}(\text{reflect}(\mathbf{rd}, \mathbf{n}))$ [S1, unofficial].
13. Add reflection contribution: $\mathbf{c}_{\text{base}} \leftarrow \mathbf{c}_{\text{base}} + \mathbf{c}_{\text{refl}} \cdot \text{mix}(0.03, 0.6, \text{sf.metal}) \cdot (0.25 + 0.75 \cdot F) \cdot \text{ao}$ [S1, unofficial].
14. Add emissive contribution: $\mathbf{c}_{\text{final}} = \mathbf{c}_{\text{base}} + \text{sf.emissive}$ [S1, unofficial].

**Pseudocode:**
```python
def mix(a, b, t):
    return a + t * (b - a)

def reflect(I, N):
    return I - 2.0 * dot(I, N) * N

def blinn_phong_metallic(p, rd, sf, ambient=0.16):
    n = calcNormal(p)
    l = normalize(vec3(-0.5, 0.8, -0.25))
    cL = vec3(0.5, 0.65, 1.0)
    d = max(dot(n, l), 0.0)
    s = softShadow(p + n * 0.03, l, 12.0)
    d = d * s
    h = normalize(l - rd)
    spec = pow(max(dot(n, h), 0.0), mix(32.0, 140.0, sf.metal)) * s
    ao = calcAO(p, n)
    c_base = sf.albedo * (ambient * ao) + sf.albedo * cL * d + cL * spec * mix(0.4, 2.0, sf.metal)
    F = pow(1.0 - max(dot(n, -rd), 0.0), 5.0)
    c_refl = skyColor(reflect(rd, n))
    c_base = c_base + c_refl * mix(0.03, 0.6, sf.metal) * (0.25 + 0.75 * F) * ao
    c_final = c_base + sf.emissive
    return c_final
```

**Parameters:**
- Light Direction: $\text{vec3}(-0.5, 0.8, -0.25)$ [S1, unofficial]
- Light Color: $\text{vec3}(0.5, 0.65, 1.0)$ [S1, unofficial]
- Ambient Intensity: $0.16$ [S1, unofficial]
- Specular Power: Interpolated between $32.0$ (non-metal) and $140.0$ (metal) [S1, unofficial]
- Specular Intensity Multiplier: Interpolated between $0.4$ (non-metal) and $2.0$ (metal) [S1, unofficial]
- Fresnel Power: $5.0$ [S1, unofficial]
- Reflection Intensity: Interpolated between $0.03$ (non-metal) and $0.6$ (metal) [S1, unofficial]
- Fresnel Reflection Weight: $0.25 + 0.75 \cdot F$ [S1, unofficial]

**Edge Cases:**
- If $\mathbf{n}$ is zero (degenerate SDF), the normal must be clamped or defaulted to $\text{vec3}(0,1,0)$ to avoid division by zero in normalization [G].
