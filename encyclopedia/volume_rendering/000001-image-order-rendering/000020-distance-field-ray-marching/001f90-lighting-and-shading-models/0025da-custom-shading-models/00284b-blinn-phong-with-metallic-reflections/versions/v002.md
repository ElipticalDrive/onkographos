# Blinn-Phong with Metallic Reflections

Also called: Neon City Lighting, Wet Asphalt Shader

## Overview
A custom shading model combining Blinn-Phong diffuse/specular components, metallic environment reflections weighted by a Schlick-like Fresnel term, and emissive contributions for neon effects [S1, unofficial]. It distinguishes itself from standard Blinn-Phong by introducing material-dependent specular power and intensity [S1, unofficial].

## How it works
**Inputs:**
- Surface point $p$ and view ray direction $rd$ (normalized) [S1, unofficial].
- Surface normal $n$ (normalized) [S1, unofficial].
- Material properties: albedo (RGB), metalness ($m \in [0,1]$), emissive (RGB) [S1, unofficial].
- Ambient color constant [S1, unofficial].
- Sky color function $C_{sky}(d)$ [S1, unofficial].

**Outputs:**
- Final surface color $C_{out}$ [S1, unofficial].

**Data Structures:**
- `sf` (Surface Field): Struct containing `albedo` (RGB vector), `metal` (float), `emissive` (RGB vector) [S1, unofficial].

**Parameters:**
- Light direction: $L = (-0.5, 0.8, -0.25)$ [S1, unofficial].
- Light color: $C_L = (0.5, 0.65, 1.0)$ [S1, unofficial].
- Ambient intensity: $C_{amb} = 0.16$ [S1, unofficial].
- Specular power range: $32.0$ (non-metal) to $140.0$ (metal) [S1, unofficial].
- Specular intensity range: $0.4$ (non-metal) to $2.0$ (metal) [S1, unofficial].
- Fresnel power: $5.0$ [S1, unofficial].
- Reflection intensity range: $0.03$ (non-metal) to $0.6$ (metal) [S1, unofficial].
- Fresnel reflection weight: $0.25 + 0.75 \times f$ [S1, unofficial].
- Shadow offset: $0.03$ [S1, unofficial].
- Shadow max distance/step limit: $12.0$ [S1, unofficial].

**Steps:**
1. Calculate normal $n = \text{calcNormal}(p)$ [S1, unofficial].
2. Determine surface properties (albedo, metalness $m$, emissive) based on material ID at $p$ [S1, unofficial].
3. Define light direction $L = \text{normalize}(-0.5, 0.8, -0.25)$ and light color $C_L = (0.5, 0.65, 1.0)$ [S1, unofficial].
4. Calculate diffuse term: $diff = \max(\text{dot}(n, L), 0.0)$ [S1, unofficial].
5. Calculate shadow factor $S = \text{softShadow}(p + n \times 0.03, L, 12.0)$ [S1, unofficial].
6. Apply shadow to diffuse: $diff = diff \times S$ [S1, unofficial].
7. Calculate half-vector: $h = \text{normalize}(L - rd)$ [S1, unofficial].
8. Calculate specular term base: $spec = \text{pow}(\max(\text{dot}(n, h), 0.0), \text{mix}(32.0, 140.0, m)) \times S$ [S1, unofficial].
9. Calculate ambient occlusion $ao = \text{calcAO}(p, n)$ [S1, unofficial].
10. Calculate base color: $C = sf.albedo \times (C_{amb} \times ao) + sf.albedo \times C_L \times diff + C_L \times spec \times \text{mix}(0.4, 2.0, m)$ [S1, unofficial].
11. Calculate Fresnel factor: $f = \text{pow}(1.0 - \max(\text{dot}(n, -rd), 0.0), 5.0)$ [S1, unofficial].
12. Calculate reflection direction: $r = \text{reflect}(rd, n)$ [S1, unofficial].
13. Calculate reflected contribution: $C = C + \text{skyColor}(r) \times \text{mix}(0.03, 0.6, m) \times (0.25 + 0.75 \times f) \times ao$ [S1, unofficial].
14. Add emissive contribution: $C = C + sf.emissive$ [S1, unofficial].
15. Return $C$ [S1, unofficial].

**Pseudocode:**
```python
import math

class Vec3:
    def __init__(self, x, y, z):
        self.x, self.y, self.z = x, y, z
    def __add__(self, v): return Vec3(self.x+v.x, self.y+v.y, self.z+v.z)
    def __sub__(self, v): return Vec3(self.x-v.x, self.y-v.y, self.z-v.z)
    def __mul__(self, s): return Vec3(self.x*s, self.y*s, self.z*s)
    def dot(self, v): return self.x*v.x + self.y*v.y + self.z*v.z
    def length(self): return math.sqrt(self.x**2 + self.y**2 + self.z**2)
    def normalize(self):
        l = self.length()
        return Vec3(self.x/l, self.y/l, self.z/l) if l > 0 else Vec3(0,0,0)
    def reflect(self, n):
        d = 2 * self.dot(n)
        return Vec3(self.x - d*n.x, self.y - d*n.y, self.z - d*n.z)

def mix(a, b, t):
    return a + t * (b - a)

def blinn_phong_metallic(p, rd, n, sf, calcNormal, softShadow, calcAO, skyColor):
    # 1. Normal calculation
    # n = calcNormal(p) # Assumed pre-calculated or provided
    albedo = sf.albedo
    metal = sf.metal
    emissive = sf.emissive

    # 2. Light setup
    light_dir = Vec3(-0.5, 0.8, -0.25).normalize()
    light_col = Vec3(0.5, 0.65, 1.0)
    ambient = 0.16

    # 3. Diffuse
    diff = max(n.dot(light_dir), 0.0)

    # 4. Shadow
    # softShadow implementation not provided in sources [G]
    shadow = softShadow(p + n * 0.03, light_dir, 12.0)
    diff = diff * shadow

    # 5. Specular
    half_vec = (light_dir - rd).normalize()
    spec_pow = mix(32.0, 140.0, metal)
    spec = max(n.dot(half_vec), 0.0) ** spec_pow * shadow

    # 6. Ambient Occlusion
    # calcAO implementation not provided in sources [G]
    ao = calcAO(p, n)

    # 7. Base Color
    spec_int = mix(0.4, 2.0, metal)
    color = albedo * (ambient * ao) + albedo * light_col * diff + light_col * spec * spec_int

    # 8. Fresnel
    fresnel = (1.0 - max(n.dot(-rd), 0.0)) ** 5.0

    # 9. Reflection
    refl_dir = rd.reflect(n)
    refl_int = mix(0.03, 0.6, metal)
    fresnel_weight = 0.25 + 0.75 * fresnel
    reflected = skyColor(refl_dir)
    color = color + reflected * refl_int * fresnel_weight * ao

    # 10. Emissive
    color = color + emissive

    return color
```

## Operating characteristics
- **Time Complexity:** $O(1)$ per pixel, dominated by shadow ray marching ($12.0$ max distance/step limit) and AO calculation.
- **Memory Complexity:** $O(1)$ auxiliary memory.
- **Strengths:** Fast execution; provides stylized "neon" aesthetic with high-contrast specular highlights and wet-surface reflections.
- **Limitations:** Not physically based; specular power is fixed per material type rather than derived from microfacet theory; Fresnel term is a power approximation, not Schlick's exact formula.
- **When to use:** Stylized real-time rendering, voxel engines, or ray marching demos where performance is critical and artistic control over "wet" or "metallic" look is desired.
- **When not to use:** Physically based rendering (PBR) pipelines requiring energy conservation or accurate material response.
