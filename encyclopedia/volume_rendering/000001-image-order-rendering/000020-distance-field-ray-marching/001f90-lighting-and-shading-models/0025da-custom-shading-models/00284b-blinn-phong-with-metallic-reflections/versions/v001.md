# Blinn-Phong with Metallic Reflections

Also called: Neon City Lighting, Wet Asphalt Shader

## Overview
A custom shading model combining Blinn-Phong diffuse/specular components, metallic environment reflections weighted by a Schlick-like Fresnel term, and emissive contributions for neon effects [S1, unofficial]. It distinguishes itself from standard Blinn-Phong by introducing material-dependent specular power and intensity, and from GGX microfacet models by using a simplified power-law specular lobe and analytic sky reflection rather than complex microfacet distribution functions [S1, unofficial].

## How it works
**Inputs:**
- Surface point $p$ and view ray direction $rd$ (normalized).
- Surface normal $n$ (normalized).
- Material properties: albedo (RGB), metalness ($m \in [0,1]$), emissive (RGB).
- Ambient color constant.
- Sky color function $C_{sky}(d)$.

**Outputs:**
- Final surface color $C_{out}$.

**Data Structures:**
- `sf` (Surface Field): Struct containing `albedo` (vec3), `metal` (float), `emissive` (vec3).

**Parameters:**
- Light direction: $L = (-0.5, 0.8, -0.25)$ [S1, unofficial].
- Light color: $C_L = (0.5, 0.65, 1.0)$ [S1, unofficial].
- Ambient intensity: $C_{amb} = 0.16$ [S1, unofficial].
- Specular power base: $P_{low} = 32.0$ [S1, unofficial].
- Specular power metal: $P_{high} = 140.0$ [S1, unofficial].
- Specular intensity base: $I_{low} = 0.4$ [S1, unofficial].
- Specular intensity metal: $I_{high} = 2.0$ [S1, unofficial].
- Fresnel power: $F_{pow} = 5.0$ [S1, unofficial].
- Reflection intensity base: $R_{low} = 0.03$ [S1, unofficial].
- Reflection intensity metal: $R_{high} = 0.6$ [S1, unofficial].
- Fresnel reflection weight base: $W_{low} = 0.25$ [S1, unofficial].
- Fresnel reflection weight metal: $W_{high} = 0.75$ [S1, unofficial].
- Shadow sample count: $N_{shadow} = 12$ [S1, unofficial].
- Shadow offset: $0.03$ [S1, unofficial].

**Steps:**
1. Calculate normal $n = \text{calcNormal}(p)$.
2. Determine surface properties (albedo, metalness $m$, emissive) based on material ID at $p$.
3. Define light direction $L = \text{normalize}(-0.5, 0.8, -0.25)$ and light color $C_L = (0.5, 0.65, 1.0)$.
4. Calculate diffuse term: $diff = \max(\text{dot}(n, L), 0.0)$.
5. Calculate shadow factor $S = \text{softShadow}(p + n \times 0.03, L, 12.0)$.
6. Apply shadow to diffuse: $diff = diff \times S$.
7. Calculate half-vector: $h = \text{normalize}(L - rd)$.
8. Calculate specular power: $P = \text{mix}(32.0, 140.0, m)$.
9. Calculate specular intensity: $I = \text{mix}(0.4, 2.0, m)$.
10. Calculate specular term: $spec = \text{pow}(\max(\text{dot}(n, h), 0.0), P) \times S \times I$.
11. Calculate ambient occlusion $ao = \text{calcAO}(p, n)$.
12. Calculate base color: $C = sf.albedo \times (C_{amb} \times ao) + sf.albedo \times C_L \times diff + C_L \times spec$.
13. Calculate Fresnel factor: $f = \text{pow}(1.0 - \max(\text{dot}(n, -rd), 0.0), 5.0)$.
14. Calculate reflection direction: $r = \text{reflect}(rd, n)$.
15. Calculate reflection intensity: $R = \text{mix}(0.03, 0.6, m)$.
16. Calculate Fresnel reflection weight: $W = 0.25 + 0.75 \times f$.
17. Add reflected contribution: $C = C + C_{sky}(r) \times R \times W \times ao$.
18. Add emissive contribution: $C = C + sf.emissive$.
19. Return $C$.

**Pseudocode:**
```python
def blinn_phong_metallic(p, rd, n, sf, calcNormal, softShadow, calcAO, skyColor):
    # 1. Normal calculation (assumed external or pre-calculated)
    # n = calcNormal(p)
    
    # 2. Material properties from sf
    albedo = sf.albedo
    metal = sf.metal
    emissive = sf.emissive
    
    # 3. Light setup
    light_dir = normalize(vec3(-0.5, 0.8, -0.25))
    light_col = vec3(0.5, 0.65, 1.0)
    ambient = 0.16
    
    # 4. Diffuse
    diff = max(dot(n, light_dir), 0.0)
    
    # 5. Shadow
    shadow = softShadow(p + n * 0.03, light_dir, 12.0)
    diff = diff * shadow
    
    # 6. Specular
    half_vec = normalize(light_dir - rd)
    spec_pow = mix(32.0, 140.0, metal)
    spec_int = mix(0.4, 2.0, metal)
    spec = pow(max(dot(n, half_vec), 0.0), spec_pow) * shadow * spec_int
    
    # 7. Ambient Occlusion
    ao = calcAO(p, n)
    
    # 8. Base Color
    color = albedo * (ambient * ao) + albedo * light_col * diff + light_col * spec
    
    # 9. Fresnel
    fresnel = pow(1.0 - max(dot(n, -rd), 0.0), 5.0)
    
    # 10. Reflection
    refl_dir = reflect(rd, n)
    refl_int = mix(0.03, 0.6, metal)
    fresnel_weight = 0.25 + 0.75 * fresnel
    reflected = skyColor(refl_dir)
    color = color + reflected * refl_int * fresnel_weight * ao
    
    # 11. Emissive
    color = color + emissive
    
    return color
```

## Operating characteristics
- **Time Complexity:** $O(1)$ per pixel, dominated by shadow ray marching ($N_{shadow}$ steps) and AO calculation.
- **Memory Complexity:** $O(1)$ auxiliary memory.
- **Strengths:** Fast execution; provides stylized "neon" aesthetic with high-contrast specular highlights and wet-surface reflections.
- **Limitations:** Not physically based; specular power is fixed per material type rather than derived from microfacet theory; Fresnel term is a power approximation, not Schlick's exact formula.
- **When to use:** Stylized real-time rendering, voxel engines, or ray marching demos where performance is critical and artistic control over "wet" or "metallic" look is desired.
- **When not to use:** Physically based rendering (PBR) pipelines requiring energy conservation or accurate material response.

## Background
Originated in the "neon-raymarcher" project by PIGJET, this model is designed for ray-marched cityscapes with neon aesthetics [S1, unofficial]. It adapts the classic Blinn-Phong model to support metallic reflections via a simplified Fresnel term and environment mapping, suitable for the "Wet Asphalt" look in cyberpunk-style scenes.
