# Gradient-Based Shading

Also called: DVR.shader, Front-to-Back DVR with Gradient-Based Shading, VolumeDVR

## Overview

Gradient-Based Shading is a discrete volume rendering (DVR) method that renders a 3D texture using front-to-back accumulation, shading voxels using a pseudo-normal estimated from the volume gradient and a directional light model [S1, unofficial]. It sets itself apart from sibling methods like [GGX Microfacet BRDF](3715-ggx-microfacet-brdf.md) by using a simplified Lambertian diffuse model driven by finite-difference normals rather than complex microfacet distributions, and differs from [Voxel Shading Pipeline](3898-voxel-shading-pipeline.md) by performing shading calculations directly within the raymarching loop in the fragment shader rather than a separate post-processing or pipeline stage [S1, unofficial].

## How it works

**Inputs and Outputs:**
*   **Input:** A 3D volume texture (`_VolumeTex`) containing single-channel `float32` data, and a 2D transfer function texture (`_TFTex`) mapping intensity/label to RGBA.
*   **Output:** A `float4` color value representing the accumulated ray color and opacity.

**Data Structures:**
*   **Volume Texture (`_VolumeTex`):** 3D texture, format `RFloat` (single channel `float32`). Dimensions defined by metadata. Memory order is x-fast, then y, then z [S1, unofficial].
*   **Transfer Function Texture (`_TFTex`):** 2D texture, format `RGBAFloat`. Dimensions 256x1. The U coordinate maps to normalized intensity or label, and the V coordinate is fixed at 0.5 [S1, unofficial].

**Parameters:**
*   `_StepSize`: Distance advanced along the ray per sample. Range: 0.0005 to 0.02. Default: 0.003 [S1, unofficial].
*   `_Brightness`: Global multiplier applied to accumulated RGB color. Range: 0 to 5. Default: 1.5 [S1, unofficial].
*   `_AlphaScale`: Multiplier applied to sampled alpha before accumulation. Range: 0 to 2. Default: 0.5 [S1, unofficial].
*   `_LightDir`: Direction of the light source in world space. Default: `(0, 0, 1, 0)` [S1, unofficial].
*   `_LightIntensity`: Intensity of the diffuse lighting component. Range: 0 to 5. Default: 1.0 [S1, unofficial].
*   `_Ambient`: Ambient lighting constant. Range: 0 to 1. Default: 0.2 [S1, unofficial].
*   `_IsLabelMap`: Integer flag (1 or 0). If 1, volume values are discrete labels; if 0, continuous intensities [S1, unofficial].
*   `_P1`: Lower bound percentile for normalizing continuous values. Used when `_IsLabelMap` is 0 [S1, unofficial].
*   `_P99`: Upper bound percentile for normalizing continuous values. Used when `_IsLabelMap` is 0 [S1, unofficial].
*   `MAX_STEPS`: Maximum samples per ray. Set to 2048 [S1, unofficial].

**Numbered Steps:**

1.  **Ray Setup:** In the fragment shader, reconstruct the camera position and fragment position in object space (cube `[-0.5, +0.5]^3`). Compute the ray direction as the normalized difference between the fragment position and camera position in object space. Transform the world-space light direction to object space (`Lobj`) [S1, unofficial].
2.  **Ray-Box Intersection:** Intersect the ray with the object-space bounding box `[-0.5, 0.5]^3`. If no intersection is found, return transparent black `(0, 0, 0, 0)` [S1, unofficial].
3.  **Initialization:** Set the current distance `t` to `max(tEnter, 0.0)`. Initialize accumulators `accRGB = (0, 0, 0)` and `accA = 0.0` [S1, unofficial].
4.  **Raymarching Loop:** Iterate `step` from 0 to `MAX_STEPS`. Break the loop if `t > tExit` or if `accA >= 0.9999` [S1, unofficial].
5.  **Sample Position:** Compute the current object-space position: `pObj = camPosObj + rayDirObj * t` [S1, unofficial].
6.  **Texture Coordinates:** Convert `pObj` to `[0, 1]^3` UVW coordinates: `uvw = pObj + 0.5`. If any coordinate is outside `[0, 1]`, break the loop [S1, unofficial].
7.  **Voxel Sampling:** Sample the volume texture at `uvw`. Extract the red channel as the voxel value `val` [S1, unofficial].
8.  **Transfer Function Sampling:**
    *   If `_IsLabelMap` is 1: Round `val` to the nearest integer, clamp to `[0, 255]`, normalize to `[0, 1]` by dividing by 255, and sample `_TFTex` at `(u, 0.5)` [S1, unofficial].
    *   If `_IsLabelMap` is 0: Normalize `val` using percentiles: `normVal = (val - _P1) / max(_P99 - _P1, 1e-6)`. Clamp `normVal` to `[0, 1]`. Sample `_TFTex` at `(normVal, 0.5)` [S1, unofficial].
    *   Let the sampled result be `tf.rgb` and `tf.a` [S1, unofficial].
9.  **Alpha Scaling:** Calculate `aSample = tf.a * _AlphaScale` [S1, unofficial].
10. **Shading:** If `aSample > 0.001`:
    *   Estimate the normal `N` at `pObj` using finite differences (see Formula below) [S1, unofficial].
    *   Compute Lambertian diffuse: `lambert = saturate(dot(normalize(N), normalize(Lobj)))` [S1, unofficial].
    *   Compute lighting: `lighting = _Ambient + _LightIntensity * lambert` [S1, unofficial].
    *   Compute lit color: `litColor = tf.rgb * lighting` [S1, unofficial].
11. **Front-to-Back Accumulation:** If `aSample > 0.001`:
    *   Calculate remaining opacity: `remain = 1.0 - accA` [S1, unofficial].
    *   Update color: `accRGB += remain * litColor * aSample` [S1, unofficial].
    *   Update alpha: `accA += remain * aSample` [S1, unofficial].
12. **Step Advance:** Increment `t` by `_StepSize` [S1, unofficial].
13. **Final Output:** Multiply `accRGB` by `_Brightness`. Return `float4(accRGB, accA)` [S1, unofficial].

**Formulas:**

*   **Normal Estimation:**
    $$ N = \frac{[V(x+\epsilon, y, z) - V(x-\epsilon, y, z), V(x, y+\epsilon, z) - V(x, y-\epsilon, z), V(x, y, z+\epsilon) - V(x, y, z-\epsilon)]}{\sqrt{\max(\|grad\|^2, 10^{-6})}} $$
    Where $\epsilon = 0.002$ in object space, and the denominator is clamped to $10^{-6}$ before the square root to prevent division by zero [S1, unofficial].

*   **Continuous Normalization:**
    $$ u = \text{saturate}\left(\frac{val - P1}{\max(P99 - P1, 10^{-6})}\right) $$
    [S1, unofficial]

*   **Discrete Label Mapping:**
    $$ u = \frac{\text{clamp}(\text{round}(val), 0, 255)}{255} $$
    [S1, unofficial]

**Pseudocode:**

```python
def gradient_based_shading(camPosObj, rayDirObj, lightDirWorld, volumeTex, tfTex, params):
    # 1. Transform light direction to object space
    lightDirObj = transform_to_object_space(lightDirWorld)
    
    # 2. Ray-Box Intersection with [-0.5, 0.5]^3
    tEnter, tExit = intersect_box(rayDirObj, camPosObj, bounds_min=(-0.5, -0.5, -0.5), bounds_max=(0.5, 0.5, 0.5))
    if tEnter > tExit:
        return (0.0, 0.0, 0.0, 0.0)
    
    t = max(tEnter, 0.0)
    accRGB = (0.0, 0.0, 0.0)
    accA = 0.0
    
    MAX_STEPS = 2048
    step_size = params._StepSize
    alpha_scale = params._AlphaScale
    brightness = params._Brightness
    is_label_map = params._IsLabelMap
    p1 = params._P1
    p99 = params._P99
    ambient = params._Ambient
    light_intensity = params._LightIntensity
    
    for step in range(MAX_STEPS):
        if t > tExit or accA >= 0.9999:
            break
            
        # 5. Sample Position
        pObj = camPosObj + rayDirObj * t
        
        # 6. Texture Coordinates
        uvw = pObj + 0.5
        if not (0.0 <= uvw.x <= 1.0 and 0.0 <= uvw.y <= 1.0 and 0.0 <= uvw.z <= 1.0):
            break
            
        # 7. Voxel Sampling
        val = volumeTex.sample(uvw).r
        
        # 8. Transfer Function Sampling
        if is_label_map == 1:
            u = clamp(round(val), 0, 255) / 255.0
        else:
            denom = max(p99 - p1, 1e-6)
            u = clamp((val - p1) / denom, 0.0, 1.0)
            
        tf_sample = tfTex.sample((u, 0.5))
        tf_rgb = tf_sample.rgb
        tf_a = tf_sample.a
        
        # 9. Alpha Scaling
        a_sample = tf_a * alpha_scale
        
        # 10. Shading
        if a_sample > 0.001:
            # Estimate Normal
            N = estimate_normal(volumeTex, pObj)
            N = normalize(N)
            L = normalize(lightDirObj)
            
            lambert = max(dot(N, L), 0.0)
            lighting = ambient + light_intensity * lambert
            lit_color = tf_rgb * lighting
            
            # 11. Front-to-Back Accumulation
            remain = 1.0 - accA
            accRGB = accRGB + remain * lit_color * a_sample
            accA = accA + remain * a_sample
            
        # 12. Step Advance
        t += step_size
        
    # 13. Final Output
    accRGB = accRGB * brightness
    return (accRGB.r, accRGB.g, accRGB.b, accA)

def estimate_normal(volumeTex, pObj):
    eps = 0.002
    # Finite differences in object space
    # Note: volumeTex.sample expects UVW [0,1], so we convert pObj to UVW
    uvw = pObj + 0.5
    
    # Sample neighbors
    # x-neighbor
    uvw_x_minus = (uvw.x - eps, uvw.y, uvw.z)
    # x+neighbor
    uvw_x_plus = (uvw.x + eps, uvw.y, uvw.z)
    # y-neighbor
    uvw_y_minus = (uvw.x, uvw.y - eps, uvw.z)
    # y+neighbor
    uvw_y_plus = (uvw.x, uvw.y + eps, uvw.z)
    # z-neighbor
    uvw_z_minus = (uvw.x, uvw.y, uvw.z - eps)
    # z+neighbor
    uvw_z_plus = (uvw.x, uvw.y, uvw.z + eps)
    
    # Clamp coordinates to [0,1] for sampling if necessary, though logic assumes valid bounds
    # The source implies direct sampling at these offsets
    
    dx = volumeTex.sample(uvw_x_plus).r - volumeTex.sample(uvw_x_minus).r
    dy = volumeTex.sample(uvw_y_plus).r - volumeTex.sample(uvw_y_minus).r
    dz = volumeTex.sample(uvw_z_plus).r - volumeTex.sample(uvw_z_minus).r
    
    grad_sq = dx*dx + dy*dy + dz*dz
    length = sqrt(max(grad_sq, 1e-6))
    
    return (dx/length, dy/length, dz/length)
```

## Operating characteristics

*   **Time Complexity:** Linear with respect to the number of samples per ray (`MAX_STEPS`) and the number of rays (pixels). Each sample involves texture lookups and arithmetic operations.
*   **Memory Complexity:** Dominated by the storage of the 3D volume texture and the 2D transfer function texture.
*   **Performance:** Using callback functions or complex shading logic in the fragment shader can lead to significant performance degradation compared to simpler lookup table methods or pre-computed shading [S1, unofficial]. The use of finite differences for normals increases the number of texture samples per voxel significantly (6 samples per normal estimation).
*   **Strengths:** Provides basic 3D shape perception through shading, which helps distinguish foreground from background and reveals surface details. It is relatively simple to implement within a standard raymarching shader.
*   **Limitations:** The pseudo-normal estimation is an approximation and may be noisy or inaccurate in regions with low contrast or discontinuities. The Lambertian model is a simplification and does not account for specular highlights or complex material properties. Performance is sensitive to `MAX_STEPS` and `_StepSize`.
*   **When to use:** Suitable for real-time volume rendering where basic shading cues are desired and computational resources are limited, such as in medical visualization or scientific data exploration.
*   **When not to use:** When high-fidelity material rendering (e.g., specular highlights, subsurface scattering) is required, or when the volume data is extremely large and performance is critical, simpler shading or pre-computed techniques might be preferred.

## Background

This method is implemented in the `VolumeDVR.shader` component of the VRDF SDK, a tool for real-time volume rendering of 3D medical or scientific volumes [S1, unofficial]. The VRDF SDK provides a compact binary container format (`.vrdf`) and a Unity runtime that integrates this shading model into a raymarching pipeline [S1, unofficial]. The approach of using volume gradients for shading in DVR is a well-established technique in computer graphics, often referred to as gradient-based shading or normal estimation for volume rendering. The specific implementation details, including the use of finite differences with a fixed epsilon and the integration with a transfer function, are characteristic of modern real-time volume rendering engines.
