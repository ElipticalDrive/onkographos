# Interval Raymarching


## Overview
Interval Raymarching is a technique for accelerating Signed Distance Field (SDF) raymarching by evaluating the SDF over an interval of the ray using affine or interval arithmetic, rather than at a single point [S1, unofficial]. It solves the problem of slow convergence in standard sphere tracing by enabling reliable linear interpolation to find surface intersections, aiming for the $\phi$ degree of convergence instead of the linear convergence of sphere tracing [S1, unofficial]. Unlike sphere tracing, which guarantees safety via Lipschitz constraints, Interval Raymarching relies on conservative-estimate SDFs to ensure correctness when leaping across potential intersections [S1, unofficial].

## How it works
**Inputs:**
- Ray $r(t) = \mathbf{o} + t\mathbf{d}$, where $\mathbf{o}$ is the origin and $\mathbf{d}$ is the normalized direction vector [G].
- Conservative SDF function $f(\mathbf{p})$ that must be an underestimate of the true distance to avoid missing intersections [S1, unofficial].
- Initial interval $[t_{min}, t_{max}]$ along the ray [G].

**Outputs:**
- Intersection distance $t^*$ where $f(r(t^*)) \approx 0$ [G].
- Surface normal $\mathbf{n}$ derived from the affine coefficients [S1, unofficial].

**Data Structures:**
- **Affine Form:** Represents the SDF over a chosen ray interval as a linear function of the position along the ray plus an error bound [S1, unofficial].

**Steps:**
1. **Interval Evaluation:** Evaluate the SDF over the current ray interval $[t_a, t_b]$ using affine arithmetic to obtain an affine form [S1, unofficial].
2. **Zero Check:** Determine if the interval includes zero by checking the affine bounds [S1, unofficial].
3. **Subdivision (Optional):** If multiple zeros are possible or precision is insufficient, subdivide the interval $[t_a, t_b]$ into smaller subintervals [S1, unofficial].
4. **Secant Interpolation:** Use the affine form to reliably linearly interpolate to find the zero of the SDF [S1, unofficial].
5. **Termination:** Stop when the interval width is below a threshold $\epsilon$ or the zero is found within the desired precision [S1, unofficial].

**Parameters:**
- $\epsilon$: Epsilon size for gradient approximation, comparable to the projected pixel size to attenuate aliasing of surface bumps with pixel sampling [S1, unofficial].

**Pitfalls:**
- **Underestimation:** If the SDF is not a conservative estimate (i.e., it underestimates the true distance), the algorithm may fail to detect intersections [S1, unofficial].
- **Precision:** Interval arithmetic can suffer from overestimation of uncertainty, leading to excessive subdivision; reduced affine arithmetic helps mitigate this [S1, unofficial].

## Operating characteristics
- **Convergence:** Aims for $\phi$ degree of convergence (golden ratio) via secant method, compared to linear convergence in sphere tracing [S1, unofficial].
- **Performance:** Potentially significantly faster than sphere tracing due to larger steps and faster convergence [S1, unofficial].
- **Memory:** Requires storage for affine coefficients, which may be larger than simple scalar values [S1, unofficial].
- **Strengths:** Faster convergence, inherent gradient approximation for lighting [S1, unofficial].
- **Limitations:** Requires conservative SDFs, potential for overestimation in interval arithmetic, complexity of implementation [S1, unofficial].

## Background
Interval Raymarching was proposed by Kragen Javier Sitaker in 2019, drawing on concepts from affine and interval arithmetic [S1, unofficial]. Related work includes Jorge Eliecer Florez Diaz's dissertation on interval arithmetic for raytracing implicit functions and Duff's 1992 work on interval arithmetic for CSG [S1, unofficial].
