# Scene-Space Normal Estimation

Also called: Höhne and Bernstein Normal Estimation

## Overview
Scene-Space Normal Estimation is a surface rendering method that uses ray-casting and binary segmentation to determine object boundary locations and estimate normals in scene space [S1]. It is characterized by the expression $R_{bs}(S_{bl}, I_s)$ [S1]. Volume-rendering methods that utilize scene space normals can be described by similar composite expressions [S1].

## How it works
**Inputs and Outputs:**
*   Input: A scene $D$ (volume or surface data) [S1].
*   Output: A rendered image with surface normals estimated in scene space [S1].

**Data Structures:**
The method relies on the composition of basic imaging transforms where the order of operation is right-to-left [S1]. The scene $D$ is transformed via filtering $F_s$ and interpolation $I_s$ [S1].

**Steps:**
1.  **Preprocessing (Optional):** The input scene $D$ may be preprocessed to produce $D_1$ or $D_2$ [S1].
    *   $D_1 = I_s(F_s(D))$: Apply filtering $F_s$ then interpolation $I_s$ [S1].
    *   $D_2 = F_s(I_s(D))$: Apply interpolation $I_s$ then filtering $F_s$ [S1].
2.  **Ray-Casting and Binary Segmentation:** The method uses ray-casting to traverse the scene [S1]. Binary segmentation ($B_s$) is applied to determine object boundary locations [S1].
3.  **Normal Estimation:** The normal estimation is performed in scene space using the boundary locator $S_{bl}$ and interpolation $I_s$ [S1].
4.  **Rendering:** The final rendering combines the segmented surface information with the interpolated scene data, expressed as $R_{bs}(S_{bl}, I_s)(D) = R_{bs}(S_{bl}(D), I_s(D))$ [S1].

**Pseudocode:**
```python
def scene_space_normal_estimation(scene_D, F_s, I_s, B_s, S_bl):
    # Preprocessing variants (optional) [S1]
    D1 = I_s(F_s(scene_D))
    D2 = F_s(I_s(scene_D))
    # Select processed scene (D1, D2, or original D) [S1]
    processed_D = D1
    # Apply boundary locator and interpolation [S1]
    surface_info = S_bl(processed_D)
    interp_scene = I_s(processed_D)
    # Render using binary segmentation [S1]
    image = B_s(surface_info, interp_scene)
    return image
```

**Parameters:**
*   $F_s$: Scene filtering operator (e.g., smoothing) [S1].
*   $I_s$: Scene interpolation operator [S1].
*   $B_s$: Binary segmentation/surface detector [S1].
*   $S_{bl}$: Surface boundary locator [S1].

**Edge Cases and Pitfalls:**
*   If $F_s$ is a smoothing filter, the threshold for binary segmentation must be determined from knowledge of the low ($L$) and high ($H$) bounds of the data [S1].
*   The right-to-left composition order of transforms must be strictly maintained to match the defined imaging pipeline [S1].

## Subtopics

### Scene Preprocessing Composite
This variant involves creating composite operators by combining basic imaging transforms [S1]. Specifically, it refers to the generation of $D_1 = I_s(F_s(D))$ or $D_2 = F_s(I_s(D))$ to preprocess the scene before normal estimation [S1]. This allows for the application of object/surface filtering where the filtered object $Q'$ is determined from the filtered scene $F_s(G_o(Q))$ using a threshold operator, or the filtered surface $S'$ is determined from the filtered scene using a surface detector $B_s$ [S1].

## Background
Scene-space normal estimation was introduced by Höhne and Bernstein for surface rendering [S1]. It is characterized by expression (7) $R_{bs}(S_{bl}, I_s)$ [S1]. The method has been used in later surface rendering techniques (expression 8) and has also been improved further [S1]. It is part of a broader framework of imaging transforms used in visualization, manipulation, and analysis of 3D structures [S1].
