# Gradient-Based Diffuse Shading

Also called: Smooth gradient shading using interpolation

## Overview
Gradient-Based Diffuse Shading computes the diffuse lighting intensity for a voxel by estimating the local surface normal via finite differences and applying a dot product with a light direction vector [S1, unofficial]. It sets itself apart from standard volume rendering by explicitly deriving surface geometry from the density gradient to simulate diffuse reflection, rather than relying solely on opacity or color transfer functions [S1, unofficial].

## How it works
**Inputs and Outputs**
- **Input**: A 3D voxel grid `view` with dimensions `height`, `width`, `depth`, a current voxel position $(x, y, z)$, its density value `currentVoxel`, the previous voxel's density `prevVoxel`, the previous ray position `prevRay`, a light source X-coordinate `lightSourceX`, a boolean flag `isGradientInterpolation`, and a threshold constant `BONE_VALUE` [S1, unofficial].
- **Output**: A scalar diffuse lighting value in the range $[0, 1]$ [S1, unofficial].

**Data Structures**
- The voxel data is accessed via a 3D array indexed by $(x, y, z)$ [G].
- `BONE_VALUE` represents the density threshold for the surface boundary [S1, unofficial].

**Steps**
1. **Estimate Surface Normal**: Compute the surface normal $\mathbf{n}$ at $(x, y, z)$ using a finite difference method on the local density field [S1, unofficial].
2. **Light Source Position**: Define the light source position $\mathbf{L}_{pos}$ with components $L_x = \text{lightSourceX}$ (controlled by a user slider), $L_y = \text{ctScan.getCT\_z\_axis()} / 4$, and $L_z = \text{ctScan.getCT\_x\_axis()}$ [S1, unofficial].
3. **Light Direction**: Calculate the light direction vector $\mathbf{l}$ from the intersection point $\mathbf{I}$ to the light source: $\mathbf{l} = \mathbf{L}_{pos} - \mathbf{I}$ [S1, unofficial]. Normalize $\mathbf{l}$ and $\mathbf{n}$: $\hat{\mathbf{l}} = \frac{\mathbf{l}}{\|\mathbf{l}\|}$ and $\hat{\mathbf{n}} = \frac{\mathbf{n}}{\|\mathbf{n}\|}$ [S1, unofficial].
4. **Gradient Interpolation**: If `isGradientInterpolation` is true, `currentVoxel` $\neq$ `BONE_VALUE`, and $z > 0$, find the exact intersection $z$-coordinate $z_{exact}$ via linear interpolation between `prevVoxel` and `currentVoxel` along `prevRay` [S1, unofficial]. Recalculate the surface normal $\mathbf{n}'$ and intersection point $\mathbf{I}'$ at $z_{exact}$ [S1, unofficial]. Update $\mathbf{l}$ using $\mathbf{I}'$ and re-normalize [S1, unofficial].
5. **Compute Diffuse Intensity**: Calculate the diffuse lighting value $D = \max(0, \hat{\mathbf{n}} \cdot \hat{\mathbf{l}})$ and return $D$ [S1, unofficial].

**Parameters**
- `lightSourceX`: X-axis position of the light source, controlled by a slider [S1, unofficial].
- `isGradientInterpolation`: Boolean flag enabling smooth gradient shading via sub-voxel intersection estimation [S1, unofficial].

**Edge Cases and Pitfalls**
- Gradient interpolation is skipped when `currentVoxel` equals `BONE_VALUE` or when $z \le 0$ [S1, unofficial].
- The normal estimation must handle boundary conditions where neighbors are out of bounds [G].
- The light source position depends on the CT scan's axis definitions, which may vary between datasets [S1, unofficial].

**Pseudocode**
```python
def gradient_based_diffuse_shading(view, x, y, z, height, width, depth,
                                   currentVoxel, prevVoxel, prevRay,
                                   lightSourceX, isGradientInterpolation,
                                   BONE_VALUE, ct_z_axis, ct_x_axis):
    # Step 1: Estimate surface normal via finite differences [G]
    surfaceNormal = estimate_normal(view, x, y, z, height, width, depth)

    # Step 2: Define light source position [S1, unofficial]
    light_pos = (lightSourceX, ct_z_axis / 4, ct_x_axis)

    # Intersection point I (initially current voxel position)
    intersection = (x, y, z)

    # Step 4: Gradient Interpolation (Optional) [S1, unofficial]
    if isGradientInterpolation and currentVoxel != BONE_VALUE and z > 0:
        # Linear interpolation to find exact intersection z
        # t = (BONE_VALUE - prevVoxel) / (currentVoxel - prevVoxel) [G]
        t = (BONE_VALUE - prevVoxel) / (currentVoxel - prevVoxel)
        # Interpolate ray position to find exact intersection point
        exact_z = prevRay[2] + t * (z - prevRay[2])
        exact_x = prevRay[0] + t * (x - prevRay[0])
        exact_y = prevRay[1] + t * (y - prevRay[1])
        intersection = (exact_x, exact_y, exact_z)

        # Recalculate surface normal at exact intersection [S1, unofficial]
        surfaceNormal = estimate_normal(view, exact_x, exact_y, exact_z, height, width, depth)

    # Step 3: Compute light direction [S1, unofficial]
    light_dir = (light_pos[0] - intersection[0],
                 light_pos[1] - intersection[1],
                 light_pos[2] - intersection[2])

    # Normalize light direction and surface normal [S1, unofficial]
    light_len = sqrt(light_dir[0]**2 + light_dir[1]**2 + light_dir[2]**2)
    normal_len = sqrt(surfaceNormal[0]**2 + surfaceNormal[1]**2 + surfaceNormal[2]**2)

    if light_len == 0 or normal_len == 0:
        return 0.0

    light_dir_norm = (light_dir[0] / light_len, light_dir[1] / light_len, light_dir[2] / light_len)
    normal_norm = (surfaceNormal[0] / normal_len, surfaceNormal[1] / normal_len, surfaceNormal[2] / normal_len)

    # Step 5: Compute diffuse intensity [S1, unofficial]
    dot_product = normal_norm[0] * light_dir_norm[0] + \
                  normal_norm[1] * light_dir_norm[1] + \
                  normal_norm[2] * light_dir_norm[2]
    return max(0.0, dot_product)

def estimate_normal(view, x, y, z, height, width, depth):
    # Standard 3D finite difference normal estimation [G]
    # Handles boundary conditions by clamping indices
    def get_val(dx, dy, dz):
        nx = max(0, min(width - 1, x + dx))
        ny = max(0, min(height - 1, y + dy))
        nz = max(0, min(depth - 1, z + dz))
        return view[nz][ny][nx]
    # Central differences
    nx = get_val(1, 0, 0) - get_val(-1, 0, 0)
    ny = get_val(0, 1, 0) - get_val(0, -1, 0)
    nz = get_val(0, 0, 1) - get_val(0, 0, -1)
    return (nx, ny, nz)
```

## Subtopics

### [Binary Gradient Shading](16370-binary-gradient-shading.md)
Binary Gradient Shading is a technique for computing diffuse or specular lighting on binary voxel models by approximating surface normals using 6-connected (face-adjacent) neighbors. It sets itself apart from general gradient shading by restricting normal estimation to binary data, allowing for a compact 5-bit encoding of the 26 possible normal directions and enabling hardware-accelerated lookup table (LUT) based lighting calculations.

## Operating characteristics
- **Time and Memory Complexity**: $O(1)$ per voxel for normal estimation and lighting calculation [G].
- **Measured Performance**: Not given in the sources.
- **Scaling**: Not given in the sources.
- **Strengths**: Provides smooth, continuous shading by using sub-voxel interpolation, reducing the blocky appearance of standard voxel rendering [S1, unofficial].
- **Limitations**: Requires access to previous voxel data for interpolation, increasing memory traffic [S1, unofficial]. The light source position is fixed relative to the CT scan axes, which may not be optimal for all viewing angles [S1, unofficial].
- **When to use**: When smooth, diffuse lighting is desired for volumetric data [S1, unofficial].
- **When not to use**: Not given in the sources.

## Background
The method originates from the `joshcodd/volume-rendering` project, an unofficial implementation of volume rendering techniques [S1, unofficial]. It is part of a broader effort to enhance the visual quality of volume-rendered CT scans by incorporating surface-based shading models [S1, unofficial].
