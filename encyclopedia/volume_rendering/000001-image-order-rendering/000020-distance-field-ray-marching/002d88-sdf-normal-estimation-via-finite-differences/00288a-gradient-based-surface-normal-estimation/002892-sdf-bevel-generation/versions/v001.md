# SDF Bevel Generation
Also called: Distance Field Bevel, SDF Surface Normal Estimation
## Overview
SDF Bevel Generation is a technique for estimating 3D surface normals for lighting by sampling a Signed Distance Function (SDF) height field at four cardinal offsets, computing finite differences, and applying bevel shaping parameters to smooth sharp edges [S1, unofficial]. It differs from standard gradient estimation by introducing explicit control over edge rounding and thickness, making it suitable for stylized or physically plausible beveled geometry in ray marching [S1, unofficial]. It builds on [SDF Normal Estimation via Finite Differences](4619-sdf-normal-estimation-via-finite-differences.md).
## How it works
### Inputs and Outputs
- **Input**: SDF texture (or volume), UV coordinates (or 3D position mapped to texture space), texture dimensions (`textureWidth`, `textureHeight`), and bevel parameters (`_Bevel`, `_BevelOffset`, `_BevelWidth`, `_BevelRoundness`, `_BevelClamp`, `_GradientScale`).
- **Output**: Surface normal vector `n`.

### Data Structures
- **SDF Sample Array `h`**: A vector of 4 floats storing the sampled SDF values at the cardinal offsets.
  - `h.x`: SDF at `uv - delta.xz`
  - `h.y`: SDF at `uv + delta.xz`
  - `h.z`: SDF at `uv - delta.zy`
  - `h.w`: SDF at `uv + delta.zy`

### Parameters
- `_Bevel` (float, default 0.5): Enables bevel generation when > 0 [S1, unofficial].
- `_BevelOffset` (float, default 0): Shifts the sampled height field values [S1, unofficial].
- `_BevelWidth` (float, default 0): Controls bevel thickness, clamped to min 0.01 [S1, unofficial].
- `_BevelRoundness` (float, default 0): Controls edge rounding via sine interpolation [S1, unofficial].
- `_BevelClamp` (float, default 0): Clamps bevel height to prevent over-extrusion artifacts [S1, unofficial].
- `_GradientScale` (float): Scaling factor for the final gradient magnitude [S1, unofficial].

### Steps
1. **Compute Delta**: Calculate the step size in texture space.
   $$ \delta = \left( \frac{1.0}{\text{textureWidth}}, \frac{1.0}{\text{textureHeight}}, 0.0 \right) $$
2. **Sample SDF**: Sample the SDF at four cardinal offsets relative to the current UV `uv`.
   - $h_x = \text{SampleSDF}(uv - \delta.xz)$
   - $h_y = \text{SampleSDF}(uv + \delta.xz)$
   - $h_z = \text{SampleSDF}(uv - \delta.zy)$
   - $h_w = \text{SampleSDF}(uv + \delta.zy)$
   Store in array `h = [h_x, h_y, h_z, h_w]`.
3. **Apply Offset**: Add `_BevelOffset` to all values in `h`.
4. **Normalize Width**: Divide all values in `h` by $\max(0.01, \text{_BevelWidth})$.
5. **Apply Roundness**: If `_BevelRoundness` > 0, apply sine interpolation to smooth edges.
   $$ h_i = \text{lerp}(h_i, \sin(h_i \cdot \frac{\pi}{2}), \text{_BevelRoundness}) $$
   for each $i \in \{x, y, z, w\}$.
6. **Clamp**: Clamp the values in `h` using `_BevelClamp` to prevent over-extrusion.
7. **Scale Gradient**: Scale the height differences by `_BevelAmount * _BevelWidth * _GradientScale * -2.0`. Note: `_BevelAmount` is not explicitly defined in the parameter list but is used in the scaling factor [S1, unofficial].
8. **Compute Tangents**: Calculate two tangent vectors $v_a$ and $v_b$ from the finite differences.
   $$ v_a = \text{normalize}(-1, 0, h_y - h_x) $$
   $$ v_b = \text{normalize}(0, 1, h_w - h_z) $$
9. **Compute Normal**: Calculate the cross product of $v_a$ and $v_b$, then apply a flip factor $f$ based on face orientation.
   $$ n = (v_a \times v_b) \cdot f $$
   where $f = (1, 1, -1)$ for front faces and $f = (1, 1, 1)$ for back faces [S1, unofficial].

### Pseudocode
```python
def sdf_bevel_generation(uv, texture_width, texture_height, sdf_sample, params):
    # Unpack parameters
    bevel = params.get('_Bevel', 0.5)
    bevel_offset = params.get('_BevelOffset', 0.0)
    bevel_width = params.get('_BevelWidth', 0.0)
    bevel_roundness = params.get('_BevelRoundness', 0.0)
    bevel_clamp = params.get('_BevelClamp', 0.0)
    gradient_scale = params.get('_GradientScale', 1.0)
    bevel_amount = params.get('_BevelAmount', 1.0) # Assumed default if not specified
    
    # Step 1: Compute delta
    delta_x = 1.0 / texture_width
    delta_y = 1.0 / texture_height
    
    # Step 2: Sample SDF at cardinal offsets
    # uv - delta.xz means uv - (delta_x, 0, 0) in 2D UV space
    h_x = sdf_sample(uv.x - delta_x, uv.y)
    h_y = sdf_sample(uv.x + delta_x, uv.y)
    h_z = sdf_sample(uv.x, uv.y - delta_y)
    h_w = sdf_sample(uv.x, uv.y + delta_y)
    
    h = [h_x, h_y, h_z, h_w]
    
    # Step 3: Add offset
    h = [val + bevel_offset for val in h]
    
    # Step 4: Divide by max width
    effective_width = max(0.01, bevel_width)
    h = [val / effective_width for val in h]
    
    # Step 5: Apply roundness
    if bevel_roundness > 0:
        pi_over_2 = 3.141592 / 2.0
        h = [lerp(val, sin(val * pi_over_2), bevel_roundness) for val in h]
        
    # Step 6: Clamp
    if bevel_clamp > 0:
        h = [clamp(val, -bevel_clamp, bevel_clamp) for val in h]
        
    # Step 7: Scale by gradient factor
    # Note: The source mentions _BevelAmount * bevelWidth * _GradientScale * -2.0
    # This scaling is applied to the differences in the next step conceptually,
    # but the source code applies it to the gradient calculation.
    # We will apply it to the final normal or intermediate tangents as per source logic.
    # The source code: nornmal = cross(va, vb) * f;
    # The scaling factor is mentioned in step 7 but not explicitly in the code snippet for va/vb.
    # However, step 7 says "Scale by ...". Let's assume it scales the height differences before tangent calc.
    scale_factor = bevel_amount * bevel_width * gradient_scale * -2.0
    h = [val * scale_factor for val in h]
    
    # Step 8: Compute gradients
    # va = normalize(-1, 0, h.y - h.x)
    # vb = normalize(0, 1, h.w - h.z)
    dy_dx = h[1] - h[0] # h.y - h.x
    dy_dy = h[3] - h[2] # h.w - h.z
    
    va = normalize(vec3(-1.0, 0.0, dy_dx))
    vb = normalize(vec3(0.0, 1.0, dy_dy))
    
    # Step 9: Cross product and flip
    # f = (1, 1, -1) for front faces, (1, 1, 1) for back faces
    # isFront is assumed to be determined by ray direction or geometry
    is_front = True # Placeholder for face orientation check
    f = vec3(1.0, 1.0, -1.0) if is_front else vec3(1.0, 1.0, 1.0)
    
    normal = cross(va, vb) * f
    
    return normal
```

### Edge Cases and Pitfalls
- **Zero Width**: `_BevelWidth` is clamped to a minimum of 0.01 to prevent division by zero [S1, unofficial].
- **Backface Orientation**: The normal must be flipped for backfaces to ensure correct lighting orientation [S1, unofficial].
- **Precision**: Floating-point precision issues may arise with very small `_BevelWidth` values, mitigated by the clamping.
- **Degenerate Input**: If the SDF is constant, the gradient will be zero, resulting in a undefined normal. This is a general SDF issue.

## Operating characteristics
- **Time Complexity**: O(1) per pixel, as it involves a fixed number of texture samples and arithmetic operations.
- **Memory Complexity**: O(1) auxiliary memory.
- **Strengths**: Provides explicit control over edge appearance (bevel width and roundness), which is useful for stylized rendering.
- **Limitations**: Relies on texture sampling, which may introduce aliasing if the texture resolution is low. The quality depends on the accuracy of the SDF texture.
- **When to Use**: When stylized beveled edges are desired in ray-marched SDF rendering.
- **When Not to Use**: When high-precision, smooth normals are required without stylization, or when the SDF is not available as a texture.

## Background
This method is derived from the Unity NanoVDB renderer implementation, which uses SDFs for volume rendering and ray marching [S1, unofficial]. It is part of a suite of techniques for normal estimation in distance-field based rendering.
