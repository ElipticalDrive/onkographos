# Normal Estimation based on 4D Linear Regression

Also called: 4D Linear Regression Normal Estimation

## Overview
This method estimates surface normals for volume rendering by fitting a linear function to a local neighborhood of voxels, integrating filtering and gradient computation into a single process [S1, unofficial]. It addresses staircase artifacts caused by low sampling rates in shear-warp projection, where standard trilinear interpolation is unsupported or insufficient [S1, unofficial]. Unlike [SDF Normal Estimation via Finite Differences](4619-sdf-normal-estimation-via-finite-differences.md), which relies on point-wise differences, this approach uses a least-squares fit over a neighborhood to produce a smooth approximated gradient function [S1, unofficial].

## How it works
**Inputs:** A 3D scalar volume $V$ (e.g., density or distance field), a target voxel center $\mathbf{x}_0 = (x_0, y_0, z_0)$, and a neighborhood radius $r$ defining the set of neighboring voxels $\mathcal{N}$.
**Outputs:** An estimated normal vector $\mathbf{n} = (n_x, n_y, n_z)$ at $\mathbf{x}_0$.

**Data Structures:**
The method solves a linear system $A\mathbf{c} = \mathbf{b}$ for coefficients $\mathbf{c} = [c_0, c_x, c_y, c_z]^T$.
- $A$: A $4 \times 4$ symmetric matrix.
- $\mathbf{b}$: A $4 \times 1$ vector.
- $\mathbf{c}$: The coefficient vector, where $c_0$ is the interpolated value and $[c_x, c_y, c_z]$ is the gradient.

**Steps:**
1. Define the neighborhood $\mathcal{N}$ as all voxels $\mathbf{x}_i = (x_i, y_i, z_i)$ within distance $r$ from $\mathbf{x}_0$.
2. For each $\mathbf{x}_i \in \mathcal{N}$, compute the relative coordinates $\Delta x_i = x_i - x_0$, $\Delta y_i = y_i - y_0$, $\Delta z_i = z_i - z_0$, and the scalar value $v_i = V(\mathbf{x}_i)$.
3. Construct the matrix $A$ and vector $\mathbf{b}$ by summing over $\mathcal{N}$:
   $$
   A = \begin{bmatrix}
   N & \sum \Delta x_i & \sum \Delta y_i & \sum \Delta z_i \\
   \sum \Delta x_i & \sum \Delta x_i^2 & \sum \Delta x_i \Delta y_i & \sum \Delta x_i \Delta z_i \\
   \sum \Delta y_i & \sum \Delta x_i \Delta y_i & \sum \Delta y_i^2 & \sum \Delta y_i \Delta z_i \\
   \sum \Delta z_i & \sum \Delta x_i \Delta z_i & \sum \Delta y_i \Delta z_i & \sum \Delta z_i^2
   \end{bmatrix}, \quad
   \mathbf{b} = \begin{bmatrix}
   \sum v_i \\
   \sum v_i \Delta x_i \\
   \sum v_i \Delta y_i \\
   \sum v_i \Delta z_i
   \end{bmatrix}
   $$
   where $N = |\mathcal{N}|$.
4. Solve the linear system for $\mathbf{c}$. The gradient is $\nabla V = (c_x, c_y, c_z)$.
5. Normalize the gradient to obtain the normal: $\mathbf{n} = \frac{\nabla V}{\|\nabla V\|}$.

**Pseudocode:**
```python
def estimate_normal_4d_linear_regression(volume, center, radius):
    # center: (x0, y0, z0)
    # volume: 3D array or function V(x,y,z)
    # radius: integer or float defining neighborhood extent
    
    neighbors = []
    x0, y0, z0 = center
    
    # Identify neighbors within radius
    # Note: Implementation detail [G] - iterate over bounding box and check distance
    for x in range(max(0, int(x0 - radius)), min(volume.shape[0], int(x0 + radius) + 1)):
        for y in range(max(0, int(y0 - radius)), min(volume.shape[1], int(y0 + radius) + 1)):
            for z in range(max(0, int(z0 - radius)), min(volume.shape[2], int(z0 + radius) + 1)):
                dx = x - x0
                dy = y - y0
                dz = z - z0
                if dx*dx + dy*dy + dz*dz <= radius*radius:
                    neighbors.append((dx, dy, dz, volume[x, y, z]))
    
    if not neighbors:
        return [0, 0, 0] # Fallback [G]

    # Initialize sums
    sum_x = 0; sum_y = 0; sum_z = 0
    sum_xx = 0; sum_yy = 0; sum_zz = 0
    sum_xy = 0; sum_xz = 0; sum_yz = 0
    sum_v = 0; sum_vx = 0; sum_vy = 0; sum_vz = 0
    N = len(neighbors)
    
    for dx, dy, dz, v in neighbors:
        sum_x += dx
        sum_y += dy
        sum_z += dz
        sum_xx += dx*dx
        sum_yy += dy*dy
        sum_zz += dz*dz
        sum_xy += dx*dy
        sum_xz += dx*dz
        sum_yz += dy*dz
        sum_v += v
        sum_vx += v*dx
        sum_vy += v*dy
        sum_vz += v*dz
        
    # Construct A and b
    A = [
        [N, sum_x, sum_y, sum_z],
        [sum_x, sum_xx, sum_xy, sum_xz],
        [sum_y, sum_xy, sum_yy, sum_yz],
        [sum_z, sum_xz, sum_yz, sum_zz]
    ]
    b = [sum_v, sum_vx, sum_vy, sum_vz]
    
    # Solve A * c = b for c = [c0, cx, cy, cz]
    # Using Cramer's rule or Gaussian elimination [G]
    c = solve_linear_system(A, b)
    
    gradient = [c[1], c[2], c[3]]
    norm = math.sqrt(gradient[0]**2 + gradient[1]**2 + gradient[2]**2)
    
    if norm == 0:
        return [0, 0, 0]
        
    return [g / norm for g in gradient]
```

**Parameters:**
- Radius $r$: Determines the neighborhood size. Larger $r$ increases smoothing but reduces local detail. Not given in the sources.

**Edge Cases:**
- If the neighborhood is empty or degenerate (e.g., all voxels have identical values), the matrix $A$ may be singular. A fallback normal (e.g., zero or previous frame) is required [G].
- Discretization artifacts: Exact surface normals are unavailable after discretization, so the method estimates inclination based on the discrete neighborhood [S1, unofficial].

## Operating characteristics
**Time Complexity:** $O(N)$ per voxel, where $N$ is the number of voxels in the neighborhood. Solving the $4 \times 4$ system is constant time.
**Memory Complexity:** $O(1)$ auxiliary memory per voxel (storing sums).
**Strengths:** Provides a smooth approximated gradient function, compensating for staircase artifacts in shear-warp projection [S1, unofficial]. Integrates filtering and normal computation [S1, unofficial].
**Limitations:** Computationally more expensive than simple finite differences. Requires access to a neighborhood of voxels.

## Background
Originated in the context of fast volume rendering algorithms using shear-warp projection, where trilinear interpolation super-sampling is not supported [S1, unofficial]. The method was proposed to compensate for the disadvantages of rare resampling and low sampling rates [S1, unofficial]. It is particularly relevant for medical CT scans where exact normal vectors are unknown [S1, unofficial].
