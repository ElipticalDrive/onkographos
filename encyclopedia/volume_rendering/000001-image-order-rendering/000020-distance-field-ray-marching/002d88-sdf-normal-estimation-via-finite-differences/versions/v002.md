# SDF Normal Estimation via Finite Differences

Also called: SDF Gradient Normal Estimation via Finite Differences, Normal Estimation via Finite Differences, Finite Difference Normal Estimation, SDF Gradient, SDF Gradient Normal, Inigo Quilez's Normal Method

## Overview
This method estimates the surface normal $\mathbf{n}$ at a point $\mathbf{p}$ on a Signed Distance Field (SDF) by computing the numerical gradient of the SDF function $f$ at that point [S1][S10, unofficial][S35, unofficial]. It solves the problem of shading implicit surfaces that lack explicit mesh normals, allowing for realistic diffuse and specular lighting without polygonization artifacts [S4, unofficial][S5, unofficial]. Unlike sibling methods that may use analytic normals, tetrahedral interpolation, or regularization, this method relies on finite-difference or analytic gradient estimation of the scalar field $f$ (or $\phi$) at the hit point [S3, unofficial]. It builds on [Distance-field ray marching](21-distance-field-ray-marching.md).

## How it works
**Inputs:**
- Query point $\mathbf{p} = (x, y, z)$ on or near the SDF surface [S1][S12, unofficial].
- SDF function $f(\mathbf{p})$ that returns the signed distance [S2, S5, unofficial].
- Step size (epsilon) $\epsilon$, a small scalar offset [S4, S12, unofficial].

**Outputs:**
- Normalized surface normal vector $\mathbf{n}$ [S2, unofficial][S6].

**Data Structures:**
- None required beyond standard 3D vectors and scalar floats.

**Steps:**
1.  **Define Step Size:** Choose a small positive value $\epsilon$ [S4, S12, unofficial]. Typical values range from $0.0001$ to $0.01$, depending on the scale of the scene and the precision of the SDF [S12, S15, S27, S34, unofficial].
2.  **Sample Neighbors:** Evaluate the SDF at six points offset from $\mathbf{p}$ along the three coordinate axes [S1][S12, unofficial]:
    -   $f_x^+ = f(\mathbf{p} + (\epsilon, 0, 0))$
    -   $f_x^- = f(\mathbf{p} - (\epsilon, 0, 0))$
    -   $f_y^+ = f(\mathbf{p} + (0, \epsilon, 0))$
    -   $f_y^- = f(\mathbf{p} - (0, \epsilon, 0))$
    -   $f_z^+ = f(\mathbf{p} + (0, 0, \epsilon))$
    -   $f_z^- = f(\mathbf{p} - (0, 0, \epsilon))$
    [S1][S12, S33, unofficial].
3.  **Compute Gradient Components:** Calculate the partial derivatives using central finite differences [S1][S12, unofficial]:
    $$ \frac{\partial f}{\partial x} \approx \frac{f_x^+ - f_x^-}{2\epsilon} $$
    $$ \frac{\partial f}{\partial y} \approx \frac{f_y^+ - f_y^-}{2\epsilon} $$
    $$ \frac{\partial f}{\partial z} \approx \frac{f_z^+ - f_z^-}{2\epsilon} $$
    [S15, S32, unofficial].
    *Note:* Since the normal is normalized immediately after, the division by $2\epsilon$ can be omitted for performance, as it cancels out during normalization [S46, unofficial].
4.  **Construct Gradient Vector:** Form the gradient vector $\nabla f(\mathbf{p})$ [S2, unofficial][S6]:
    $$ \nabla f(\mathbf{p}) = \begin{bmatrix} f_x^+ - f_x^- \\ f_y^+ - f_y^- \\ f_z^+ - f_z^- \end{bmatrix} $$
    [S30, S35, unofficial].
5.  **Normalize:** Compute the unit normal vector $\mathbf{n}$ [S2, unofficial][S6]:
    $$ \mathbf{n} = \frac{\nabla f(\mathbf{p})}{\|\nabla f(\mathbf{p})\|} $$
    [S1][S10, unofficial].
    *Edge Case:* If $\|\nabla f(\mathbf{p})\|$ is zero or extremely small (e.g., $< 0.0001$), the normal is undefined. In this case, return a default normal (e.g., $(0, 0, 1)$) or handle as a degenerate surface [S17, unofficial].

**Pseudocode:**
```python
def estimate_normal(p: Vector3, sdf: Callable[[Vector3], float], epsilon: float = 0.001) -> Vector3:
    """
    Estimates the surface normal at point p using central finite differences.
    
    Args:
        p: The query point (x, y, z).
        sdf: The signed distance function.
        epsilon: The step size for finite differences.
        
    Returns:
        The normalized surface normal vector.
    """
    # Define offset vectors for each axis
    offset_x = Vector3(epsilon, 0.0, 0.0)
    offset_y = Vector3(0.0, epsilon, 0.0)
    offset_z = Vector3(0.0, 0.0, epsilon)
    
    # Evaluate SDF at perturbed positions
    # Note: Division by 2*epsilon is omitted as it cancels during normalization
    grad_x = sdf(p + offset_x) - sdf(p - offset_x)
    grad_y = sdf(p + offset_y) - sdf(p - offset_y)
    grad_z = sdf(p + offset_z) - sdf(p - offset_z)
    
    # Construct gradient vector
    gradient = Vector3(grad_x, grad_y, grad_z)
    
    # Normalize
    length = gradient.length()
    if length < 1e-6:
        # Handle degenerate case where gradient is zero
        return Vector3(0.0, 0.0, 1.0) # Default normal [G]
        
    return gradient / length
```

**Parameters:**
-   $\epsilon$ (epsilon): The step size for finite differences. Typical values are $0.0001$ to $0.001$ [S12, S27, S34, unofficial]. Too large a value causes inaccurate normals due to non-linearity of the SDF; too small a value causes numerical instability due to floating-point precision limits [S32, S45, unofficial].

## Subtopics

### SDF Normal Estimation via Backpropagation
Estimates mesh vertex normals by computing the negative gradient of the occupancy output with respect to the vertex positions using automatic differentiation (backpropagation) [S59, unofficial]. It differs from standard finite differences by avoiding explicit SDF queries at offset points, instead relying on the computational graph of the neural network or implicit function [S59, unofficial].

### Normal Estimation based on 4D Linear Regression
A normal estimation scheme that integrates filtering and normal computation into one process to provide a smooth approximated gradient function, compensating for staircase artifacts caused by low sampling rates in shear-warp projection [S60, unofficial]. It differs from finite differences by using a local neighborhood regression rather than point-wise differences [S60, unofficial].

### Specular Highlight via Gradient Normal
Computes specular highlights by finding the volume surface intersection, estimating the surface normal via finite differences of the volume texture, and applying a Blinn-Phong shading model [S61, unofficial]. It uses the same finite difference normal estimation but applies it specifically to volume textures for specular lighting [S61, unofficial].

## Operating characteristics
**Time Complexity:** $O(1)$ per query, requiring exactly 6 SDF evaluations (or 4 if optimized variants like tetrahedral are used, but this method is strictly 6) [S1][S12, unofficial].
**Memory Complexity:** $O(1)$, no additional storage required beyond the SDF function itself [S1].
**Measured Performance:** The method is computationally inexpensive but requires 6 texture/function lookups per normal estimation [S2, unofficial]. In GPU implementations, this can be a bottleneck if normals are needed for every shaded pixel [S2, unofficial].
**Strengths:** Simple to implement; works with any SDF, including those defined by complex CSG operations where analytical gradients are difficult to derive [S40, unofficial]; provides smooth normals for smooth SDFs [S15, unofficial].
**Limitations:** Approximation error increases with larger $\epsilon$; numerical noise increases with smaller $\epsilon$ [S32, S45, unofficial]; does not handle sharp edges (cusps) well, leading to jittery normals [S1]; requires 6 SDF evaluations, which is more expensive than analytic normals if available [S2, unofficial].
**When to use:** When analytical normals are unavailable or too complex to compute; for smooth SDFs; in real-time rendering where simplicity is prioritized [S1][S40, unofficial].
**When not to use:** When high performance is critical and analytical normals are available; when sharp edges require precise normal handling without regularization [S1].

## Background
The method originates from the fundamental property of Signed Distance Fields that the gradient of the distance function at a point on the surface is perpendicular to the surface [S1][S10, unofficial]. This technique was popularized in the context of ray marching and SDF rendering by Inigo Quilez and others in the demoscene and real-time graphics community [S5, S33, unofficial]. It is widely used in real-time ray marching shaders for lighting and shading [S5, S16, unofficial].
