# Principal Curvature Direction Estimation

Also called: Discrete Curvature Estimation (Monga et al.), Monga's algorithm

## Overview
A method to compute principal curvature directions in 3D scalar fields faster than extremal value quadratic forms, by computing an orthonormal basis for the gradient and solving for the angle $\theta$ [S1, unofficial].

## How it works
**Inputs:**
- Scalar field $F(x, y, z)$ [S1, unofficial].
- Gradient vector $G = \nabla F = (g_0, g_1, g_2)^T$ [S1, unofficial].
- Hessian matrix $D^2 F$ containing second partial derivatives of $F$ [S1, unofficial].

**Outputs:**
- Principal curvature direction vector in the plane orthogonal to $G$ [S1, unofficial].
- Angle $\theta$ defining the direction within that plane [S1, unofficial].

**Data Structures:**
- Gradient vector $G$: 3 floats [G].
- Scalar $\gamma$: 1 float [G].
- Orthonormal matrix $P$: 3×3 floats [G].
- Angle $\theta$: 1 float [G].

**Steps:**
1. Compute the horizontal gradient magnitude and full gradient norm:
   $$ \gamma = \sqrt{g_0^2 + g_1^2} $$
   $$ \|G\| = \sqrt{g_0^2 + g_1^2 + g_2^2} $$
   [S1, unofficial]

2. Handle degenerate cases:
   - If $\gamma = 0$, the matrix construction fails; use a standard basis instead [S1, unofficial].
   - If $\|G\| = 0$, the point is a critical point and curvature is undefined [G].

3. Construct orthonormal basis vectors $h$ and $f$ spanning the plane orthogonal to $G$:
   $$ h = \begin{pmatrix} \frac{g_1}{\gamma} \\ -\frac{g_0}{\gamma} \\ 0 \end{pmatrix}, \quad f = \begin{pmatrix} \frac{g_2 \cdot g_0}{\gamma \cdot \|G\|} \\ \frac{g_2 \cdot g_1}{\gamma \cdot \|G\|} \\ \frac{\gamma}{\|G\|} \end{pmatrix} $$
   [S1, unofficial]

4. Form the orthonormal matrix $P$ whose columns are $G/\|G\|$, $h$, and $f$ [S1, unofficial].

5. Express any vector $v$ in the orthogonal complement of $G$ as a linear combination:
   $$ v = h \cdot \cos \theta + f \cdot \sin \theta $$
   [S1, unofficial]

6. Solve for $\theta$ by setting the first derivative of the directional curvature $\kappa_v$ with respect to $\theta$ to zero:
   $$ \tan 2\theta = \frac{2 \cdot h^T (D^2 F) f}{h^T (D^2 F) h - f^T (D^2 F) f} $$
   where the prime notation in the source denotes matrix transpose [S1, unofficial].

7. Resolve orientation flips during path line tracing using a heuristic with a globally defined reference field (e.g., cylindrical) to align directions consistently [S1, unofficial].

**Pseudocode:**
```python
import math

def principal_curvature_direction(g0, g1, g2, hess_hh, hess_hf, hess_ff):
    gamma = math.sqrt(g0**2 + g1**2)
    norm_G = math.sqrt(g0**2 + g1**2 + g2**2)
    epsilon = 1e-9
    
    if gamma == 0.0:
        # Sources do not specify fallback implementation [S1, unofficial]
        return ((1.0, 0.0, 0.0), 0.0)
    if norm_G == 0.0:
        return None  # Critical point, curvature undefined [G]
        
    h = (g1 / gamma, -g0 / gamma, 0.0)
    f = (g2 * g0 / (gamma * norm_G), g2 * g1 / (gamma * norm_G), gamma / norm_G)
    
    denom = hess_hh - hess_ff
    if abs(denom) < epsilon:
        # Sources do not specify filter width adjustment [S1, unofficial]
        pass
        
    theta = 0.5 * math.atan2(2.0 * hess_hf, denom)
    direction = (h[0]*math.cos(theta) + f[0]*math.sin(theta),
                 h[1]*math.cos(theta) + f[1]*math.sin(theta),
                 h[2]*math.cos(theta) + f[2]*math.sin(theta))
    return direction, theta
```

**Pitfalls:**
- If $\gamma = 0$, the matrix construction fails; use a standard basis instead [S1, unofficial].
- At umbilical points (locally flat or spherical surfaces), the denominator vanishes [S1, unofficial].
- The algorithm only solves for $\theta$ in $(-\pi/2, +\pi/2)$, causing curvature directions to flip 180 degrees along field lines, preventing consistent orientation for tracing [S1, unofficial].

## Subtopics

### [Discrete Gaussian Curvature Estimation](14915-discrete-gaussian-curvature-estimation.md)
This method classifies surface vertices as elliptic (local extrema) or hyperbolic (saddle/blending regions) by evaluating the sign of the discrete Gaussian curvature.

## Operating characteristics
**Time Complexity:** Faster than extremal value quadratic forms [S1, unofficial].
**Memory Complexity:** Not given in the sources [S1, unofficial].
**Measured Performance:** Not given in the sources [S1, unofficial].
**Scaling:** Not given in the sources [S1, unofficial].
**Strengths:** Considerably faster method for computing principal directions in three-dimensional scalar fields [S1, unofficial].
**Limitations:** Only solves for $\theta \in (-\pi/2, +\pi/2)$, resulting in curvature fields that are not oriented consistently [S1, unofficial].
**Limitations:** Curvature directions might flip about 180 degrees along a particular field line [S1, unofficial].

## Background
Monga et al. derived this method for computing principal directions in three-dimensional scalar fields [S1, unofficial]. It is applied to surface hatching and rendering oriented strokes [S1, unofficial].
