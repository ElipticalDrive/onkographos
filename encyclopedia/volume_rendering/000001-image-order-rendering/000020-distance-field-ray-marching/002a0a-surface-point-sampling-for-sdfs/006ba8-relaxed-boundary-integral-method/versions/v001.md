# Relaxed Boundary Integral Method

Also called: Differentiable SDF Rendering via Boundary Relaxation

## Overview
The Relaxed Boundary Integral Method computes the gradient of rendered images with respect to scene parameters by approximating the boundary integral term in the differentiable rendering equation. It solves the problem of accurately estimating derivatives for rays that graze the surface (silhouette rays), where standard ray marching fails due to discontinuous visibility changes. It sets itself apart from sibling methods by relaxing the strict surface intersection condition ($SDF=0$) to a band ($0 < SDF < \epsilon$), yielding more uniform samples around the silhouette compared to relaxing the directional derivative condition, which produces tangential intersections sensitive to curvature [S1].

## How it works
**Inputs:** Ray origin $\mathbf{o}$, ray direction $\boldsymbol{\omega}$, Signed Distance Field (SDF) function $S(\mathbf{x})$, SDF threshold $\epsilon$, maximum ray depth.
**Outputs:** Radiance contribution $L$, gradient of radiance w.r.t. scene parameters $\frac{\partial L}{\partial \theta}$.

**Data Structures:**
*   **Ray State:** $\mathbf{x}$ (current position, $\mathbb{R}^3$), $t$ (distance along ray, float), $S_{val}$ (SDF value at $\mathbf{x}$, float), $S'_{val}$ (directional derivative at $\mathbf{x}$, float).
*   **Boundary Normal:** $\mathbf{n}(\mathbf{x}) = \frac{\nabla S(\mathbf{x})}{\|\nabla S(\mathbf{x})\|}$ (outward-pointing unit normal).
*   **Scalar Normal Velocity:** $v_\perp(\mathbf{x}) = \langle \mathbf{v}(\mathbf{x}), \mathbf{n}(\mathbf{x}) \rangle$, where $\mathbf{v}(\mathbf{x}) = \frac{\partial \mathbf{x}}{\partial \theta}$ is the velocity of the point with respect to the parameter $\theta$ [S1].

**Parameters:**
*   $\epsilon$: SDF threshold defining the width of the relaxed boundary band. Typical value: $0.002$ [S1].
*   $N_{iter}$: Number of bisection iterations. Typical value: $12$ [S1].

**Steps:**
1.  **Sphere Tracing with Derivative Tracking:** Perform sphere tracing along the ray. At each step $i$, compute $S(\mathbf{x}_i)$ and the directional derivative $S'(\mathbf{x}_i) = \langle \nabla S(\mathbf{x}_i), \boldsymbol{\omega} \rangle$.
2.  **Local Minimum Detection:** Check if the directional derivative changes sign from negative to positive between step $i-1$ and $i$ ($S'_{i-1} < 0$ and $S'_i > 0$). This indicates a local minimum of the SDF along the ray has been passed [S1].
3.  **Initial Guess Selection:** Among all steps where a local minimum was detected, select the step with the smallest SDF value $S(\mathbf{x}_i)$ as the initial guess $\mathbf{x}_{init}$ for the relaxed silhouette point [S1].
4.  **Refinement via Bisection:** Refine $\mathbf{x}_{init}$ to find the relaxed silhouette point $\mathbf{x}^*$ such that $S(\mathbf{x}^*) = \epsilon$ (or the specific boundary condition defined by the relaxation). Use the bisection method for $N_{iter}$ iterations. The bisection interval is defined by the previous step (where $S < \epsilon$) and the current step (where $S > \epsilon$ or vice versa, depending on the specific relaxation logic, but typically targeting the band $0 < S < \epsilon$) [S1].
5.  **Boundary Integral Approximation:** If a valid relaxed silhouette point $\mathbf{x}^*$ exists on the ray segment, compute the boundary term contribution. The approximation is given by:
    $$ I_A = \frac{1}{\epsilon} \int_{S^2} v_\perp(\mathbf{x}^*) \Delta f(\boldsymbol{\omega}) \mathbb{1}_A(\boldsymbol{\omega}) d\sigma(\boldsymbol{\omega}) $$
    where $\Delta f(\boldsymbol{\omega})$ is the change in radiance and $\mathbb{1}_A$ is an indicator function for the area of interest [S1]. In practice, this is evaluated analytically after sphere tracing for the ray intersection process, while the interior integral is estimated using automatic differentiation [S1].
6.  **Gradient Estimation:** Add the boundary term to the gradient estimate if $\mathbf{x}^*$ exists. For shadow rays, only one side of the visibility boundary is occluded, so the shading evaluation at $\mathbf{x}^*$ is not required [S1].

**Pseudocode:**

```python
def relaxed_boundary_integral(ray_origin, ray_direction, sdf_func, grad_sdf_func, theta, epsilon=0.002, max_steps=128, bisection_iters=12):
    """
    Computes the boundary integral contribution for a ray using the Relaxed Boundary Integral Method.
    
    Args:
        ray_origin: (3,) float array, origin of the ray.
        ray_direction: (3,) float array, normalized direction of the ray.
        sdf_func: function(x) -> float, returns SDF value at x.
        grad_sdf_func: function(x) -> (3,) float array, returns gradient of SDF at x.
        theta: scalar, scene parameter to differentiate w.r.t.
        epsilon: float, SDF threshold for relaxation.
        max_steps: int, maximum number of sphere tracing steps.
        bisection_iters: int, number of bisection iterations for refinement.
        
    Returns:
        boundary_term: float, the computed boundary integral contribution.
        x_star: (3,) float array or None, the relaxed silhouette point.
    """
    x = ray_origin
    t = 0.0
    prev_sdf_prime = None
    best_x_init = None
    best_sdf_val = float('inf')
    
    # Step 1 & 2: Sphere tracing with derivative tracking
    for i in range(max_steps):
        sdf_val = sdf_func(x)
        grad = grad_sdf_func(x)
        sdf_prime = dot(grad, ray_direction)
        
        # Check for local minimum (derivative changes from negative to positive)
        if prev_sdf_prime is not None and prev_sdf_prime < 0 and sdf_prime > 0:
            # We passed a local minimum. Check if it's within the relaxed band.
            # The sources indicate selecting the step with the smallest SDF value
            # among those where a minimum was detected.
            if sdf_val < best_sdf_val:
                best_sdf_val = sdf_val
                best_x_init = x
        
        # Move along the ray
        step_size = max(sdf_val, 1e-4) # Avoid zero division
        t += step_size
        x = ray_origin + t * ray_direction
        prev_sdf_prime = sdf_prime
        
        if sdf_val < 1e-4: # Standard intersection, handle separately or break
            break
            
    # Step 3 & 4: Refine the relaxed silhouette point
    x_star = None
    if best_x_init is not None:
        # Bisection method to find x* such that SDF(x*) = epsilon (or within band)
        # The interval is roughly around best_x_init. 
        # We need a lower bound where SDF < epsilon and upper bound where SDF > epsilon.
        # For simplicity, assume best_x_init is close. We refine based on the condition 0 < SDF < epsilon.
        # The source says "pinpoint the relaxed silhouette point" using bisection for 12 iterations.
        # We assume the bisection is performed on the distance t along the ray.
        
        t_low = t - step_size
        t_high = t
        sdf_low = sdf_func(ray_origin + t_low * ray_direction)
        sdf_high = sdf_func(ray_origin + t_high * ray_direction)
        
        # Ensure the interval brackets the target value epsilon
        # Note: The source implies relaxing SDF condition to 0 < SDF < epsilon.
        # We target SDF(x) = epsilon for the boundary of the band.
        
        for _ in range(bisection_iters):
            t_mid = (t_low + t_high) / 2.0
            x_mid = ray_origin + t_mid * ray_direction
            sdf_mid = sdf_func(x_mid)
            
            if sdf_mid > epsilon:
                t_high = t_mid
                sdf_high = sdf_mid
            else:
                t_low = t_mid
                sdf_low = sdf_mid
                
        x_star = ray_origin + ((t_low + t_high) / 2.0) * ray_direction
        
    # Step 5: Compute boundary term
    boundary_term = 0.0
    if x_star is not None:
        # Compute normal velocity v_perp
        grad_star = grad_sdf_func(x_star)
        n_star = grad_star / norm(grad_star)
        # v(x) is the derivative of x w.r.t theta. 
        # If x depends on theta, v = dx/dtheta. 
        # In many differentiable rendering contexts, this is computed via auto-diff.
        # Here we assume v_theta is available or computed.
        # For a translation parameter theta in x-direction, v = (1, 0, 0).
        # This is a placeholder for the actual velocity computation which depends on the scene graph.
        v_theta = compute_velocity(x_star, theta) # [G] Helper to get dx/dtheta
        v_perp = dot(v_theta, n_star)
        
        # The integral approximation involves v_perp and the change in radiance.
        # The source formula: I_A = (1/epsilon) * integral ...
        # In implementation, this is often a discrete term added to the gradient.
        # We assume delta_f is the radiance difference or visibility change.
        # For a simple visibility boundary, delta_f might be the radiance of the occluded side.
        # This part requires context from the specific renderer's radiance calculation.
        # The source states: "adds a boundary term if a relaxed silhouette point y* exists".
        
        # Placeholder for the actual boundary term calculation logic which depends on 
        # the specific radiance estimator (e.g., direct lighting vs path tracing).
        # The source mentions "estimate the interior integral ... using automatic differentiation 
        # except for the ray intersection process, whose derivatives are computed analytically".
        # So the boundary term is the analytical derivative of the intersection.
        
        boundary_term = v_perp # Simplified representation of the boundary term contribution
        
    return boundary_term, x_star
```

## Operating characteristics
*   **Time Complexity:** Dominated by sphere tracing and the bisection refinement. The bisection adds a constant overhead (12 iterations) per ray that grazes the surface.
*   **Memory Complexity:** Low, requiring only storage for the ray state and a few temporary variables.
*   **Measured Performance:** Achieves higher PSNR than SDF Convolution, SDF Reparameterization, and Mesh Projective Sampling under different area light sizes, using a 512x512 resolution and 1024 spp direct integrator on an NVIDIA RTX 3090 [S1].
*   **Strengths:** More uniform samples around the silhouette compared to relaxing the directional derivative condition. Less sensitive to curvature.
*   **Limitations:** Requires computing the directional derivative during sphere tracing. The choice of $\epsilon$ affects the accuracy and stability.
*   **When to use:** When differentiable rendering of SDFs is required, especially for silhouette derivatives.
*   **When not to use:** When SDF gradients are expensive to compute or unavailable.

## Background
The method was introduced in "A Simple Approach to Differentiable Rendering of SDFs" [S1]. It is implemented in the Mitsuba3 Python package with CUDA and LLVM backends. It is used for forward derivatives of rendered images w.r.t. translation parameters and inverse rendering tasks [S1]. The method addresses the difficulty of sampling silhouette points by relaxing the SDF condition to a band $0 < SDF < \epsilon$, which produces rays that graze the surface with no intersection, leading to more uniform samples [S1].
