# Surface Point Sampling for SDFs

Also called: Forplane Rendering Procedure, Sphere Tracing Surface Sampling

## Overview
Surface Point Sampling for SDFs generates training or rendering data points distributed around the implicit surface defined by a Signed Distance Function (SDF). Unlike standard sphere tracing which samples along a ray to find a single intersection, this method actively constructs a point cloud $P$ that approximates the surface geometry by combining uniform background sampling, near-surface perturbations, and projection-based refinement. It sets itself apart from its siblings by focusing on the *distribution* of points for representation learning or high-fidelity extraction rather than just ray intersection, often integrating these points into neural field queries or power diagram computations.

## How it works
The method constructs a set of sample points $P$ from a ray $r(t) = r_o + t \cdot d$ and scene parameters. The core challenge is ensuring points lie sufficiently close to the zero-level set (the surface) to capture geometry accurately without excessive computational cost.

### Inputs and Outputs
**Inputs:**
*   Ray origin $r_o$ and direction $d$ (normalized).
*   SDF function $S(p)$ returning distance and sign.
*   Optional: Indicator grid $G_o$ (for filtering), MLP $\theta$ (for feature prediction), or Power Diagram parameters.
*   Sampling parameters: $\sigma$ (noise std dev), $\text{MAX\_STEPS}$, $\text{HIT\_THRESHOLD}$.

**Outputs:**
*   Point set $P = \{p_i\}$ with associated attributes (position, normal, features, density).
*   Rendered color $\hat{C}$ and depth $\hat{D}$ if used in a rendering context.

### Data Structures
*   **Point $p$**: 3D vector $(x, y, z)$.
*   **Feature Vector $v$**: Concatenation of coordinate encoding $b(p)$ and interpolated grid features.
*   **Indicator Grid $G_o$**: A sparse or dense grid marking regions near the surface, used to filter uniform samples.

### Steps

1.  **Uniform Background Sampling (Optional):**
    Sample points uniformly in the bounding volume $B = [-1, 1]^3$ to form a set $P_u$ [S1, S2]. This ensures coverage of empty space or background [S1].

2.  **Surface Hit Detection via Sphere Tracing:**
    For a given ray, perform sphere tracing to find the surface intersection [S1].
    *   Initialize $p = r_o$.
    *   Iterate: $d = S(p)$. If $d < 0$, penetration detected [S6]. If $d \le \text{HIT\_THRESHOLD}$, hit detected [S1]. Else, $p \leftarrow p + d \cdot d$ (step size).
    *   If a hit is found at $t_{hit}$, record the point $p_{hit} = r_o + t_{hit} \cdot d$ [S1].

3.  **Near-Surface Perturbation:**
    To enrich the surface representation, take existing surface samples (from step 2 or mesh vertices) and perturb them with Gaussian noise [S1].
    *   $p_{perturbed} = p_{surface} + \mathcal{N}(0, \sigma^2 I)$
    *   Typical value: $\sigma = 0.01$ [S1].
    *   This creates "near-surface" points that help the SDF learn the gradient and thickness of the boundary [S1].

4.  **Indicator Grid Filtering (Forplane/Neural Plane Context):**
    Pass uniform samples $P_u$ through an indicator grid $G_o$ to retain only those likely near the surface, forming the refined set $P$ [S2]. This reduces noise in regions far from the geometry.

5.  **Feature Extraction and MLP Query (Neural Context):**
    For each point $p_i \in P$:
    *   Initialize feature vector $v(p_i) = 1$ [S2].
    *   Iterate over static and dynamic field levels $\{V^s_{3d}, V^d_{3d}\}_4$ and dimension pairs $(xy, xz, x\tau, yz, y\tau, z\tau)$ [S2].
    *   Perform bi-linear interpolation $B(G, i, j)$ on each grid $G$ for the dimension pair $ij$ [S2].
    *   Update features: $v(p_i) \leftarrow v(p_i) \odot B(G, i, j)$ [S2].
    *   Concatenate positional encoding $b(p_i)$ with features $v(p_i)$ [S2].
    *   Pass through tiny MLP $\theta$ to predict color $c_i$ and density $\sigma_i$ [S2].

6.  **Projection Point Integration (Power Diagram Context):**
    For high-fidelity extraction, incorporate projection points derived from gradient information [S3].
    *   Compute gradient $\nabla S(p)$ at sampling points.
    *   Project points onto the surface along the gradient direction to correct topological defects [S3].
    *   These points are especially valuable for thin structures, sharp edges, and high curvature regions [S3].

7.  **Rendering Integration (Optional):**
    Integrate radiance along the ray using the sampled points and predicted densities [S2]:
    $$ \hat{C} = \int_{t_n}^{t_f} w(t) \cdot c(r(t)) \, dt $$
    $$ \hat{D} = \int_{t_n}^{t_f} w(t) \cdot t \, dt $$
    Where $w(t) = \exp\left(-\int_{t_n}^{t} \sigma(r(s)) \, ds\right) \sigma(r(t))$ [S2].

### Pseudocode

```python
import numpy as np

def sample_surface_points(ray_origin, ray_dir, sdf_func, max_steps=64, hit_threshold=0.001, sigma=0.01):
    """
    Samples points near the surface defined by sdf_func along a ray.
    Returns a list of points with attributes.
    """
    points = []
    p = ray_origin
    
    # 1. Sphere Tracing to find surface hit
    for i in range(max_steps):
        dist = sdf_func(p)
        
        # Check for penetration or hit
        if dist < 0:
            # Penetrated surface; record hit point (approximate)
            hit_point = p - ray_dir * dist # Backtrack to surface
            points.append({'pos': hit_point, 'type': 'hit'})
            break
        elif dist <= hit_threshold:
            # Hit surface
            points.append({'pos': p, 'type': 'hit'})
            break
        
        # Advance
        p = p + ray_dir * dist
        
        # Optional: Check max range
        if np.linalg.norm(p - ray_origin) > 100.0:
            break
            
    # 2. Near-Surface Perturbation
    # If we found a hit, generate near-surface samples
    if points:
        base_point = points[0]['pos']
        # Generate N near-surface points with Gaussian noise
        for _ in range(10): # Example count
            noise = np.random.normal(0, sigma, 3)
            perturbed_point = base_point + noise
            points.append({'pos': perturbed_point, 'type': 'near_surface'})
            
    return points

def neural_plane_feature_query(point, grids, positional_encoding):
```

### Parameters and Edge Cases
*   **$\sigma$ (Noise Std Dev):** Controls the spread of near-surface points. $\sigma=0.01$ is typical [S1]. Too large causes points to fall into empty space; too small provides no gradient information.
*   **HIT_THRESHOLD:** Epsilon for surface detection. Must be small enough to avoid gaps but large enough to avoid precision issues [S1].
*   **Precision:** Floating-point errors in sphere tracing can cause jitter. Using double precision or adaptive step sizes can mitigate this [G].
*   **Degenerate Input:** If the SDF is undefined or returns NaN, the sampling loop should terminate and return empty results.

## Subtopics

### [Surfel Parameterization from Mesh Sampling](4501-surfel-parameterization-from-mesh-sampling.md)
Estimates full parameter sets (position, normal, tangent, scales) for surfel representations from triangle meshes. It differs by deriving tangent scales from local point cloud neighborhood structure rather than mesh connectivity, offering isotropic (performance) and anisotropic (quality) variants.

### Near-Surface Point Sampling
Perturbs existing surface samples with Gaussian noise ($\sigma=0.01$) to create points near the surface, aiding in learning the SDF gradient and boundary thickness [S1].

### Projection Point Integration
Incorporates projection points derived from gradient information into power diagram computations. It is chosen for reconstructing thin structures, sharp edges, and high-curvature regions where discrete sampling alone fails, preserving topological integrity [S3].

### Surface Interaction Construction
Constructs a `SurfaceInteraction3f` structure from ray intersections, computing normals, frames, and other properties without SDF autodiff support. It sets the interaction time, position, and local frame for shading [S4, unofficial].

## Operating characteristics
*   **Time Complexity:** Depends on the number of samples $N$ and the cost of SDF evaluation $O(S)$. For neural methods, MLP evaluation adds $O(M)$. Total: $O(N \cdot (S + M))$.
*   **Memory Complexity:** $O(N)$ to store points and features. Grid-based methods add $O(G)$ for grid storage.
*   **Performance:** Efficient for real-time rendering if the number of samples is limited. Neural plane methods can be slower due to multiple grid lookups and MLP inference [S2].
*   **Strengths:** High geometric fidelity, handles complex topology with projection points, integrates well with neural fields.
*   **Limitations:** Requires careful tuning of noise and thresholds. Projection points add computational overhead.

## Background
Originating from neural implicit representations, surface point sampling has evolved from simple uniform sampling to sophisticated strategies involving near-surface perturbations and projection-based refinement. Key developments include Neural Geometric Level of Detail (NGLOD) which uses uniform, surface, and near-surface samples [S1], and Efficient Deformable Tissue Reconstruction which uses indicator grids and neural planes [S2]. Power Diagram Enhanced Adaptive Isosurface Extraction integrates projection points for topological accuracy [S3].
