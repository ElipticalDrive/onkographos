# Surface Point Sampling for SDFs

Also called: Forplane Rendering Procedure, Sphere Tracing Surface Sampling

## Overview
Surface Point Sampling for SDFs generates a set of 3D points distributed around the implicit surface defined by a Signed Distance Function (SDF) to serve as input for neural rendering or geometric reconstruction pipelines [S1, S2]. Unlike standard sphere tracing which terminates at a single hit point, this method samples multiple points along rays or within the volume to capture surface geometry and local features for subsequent feature extraction [S1, S2]. It differs from its sibling [Distance-field ray marching](21-distance-field-ray-marching.md) by focusing on generating a dense, structured point cloud $P$ from a uniform set $P_u$ via an indicator grid, rather than just finding a single intersection [S2]. It is distinct from [SDF Primitive Definitions](1578-sdf-primitive-definitions.md) which define the geometry, and [SDF Normal Estimation via Finite Differences](4619-sdf-normal-estimation-via-finite-differences.md) which computes derivatives at a point, by providing the spatial distribution of points themselves [S1, S2].

## How it works
The method consists of two primary phases: point generation (sampling) and feature encoding (rendering preparation). The inputs are a ray $r(t) = \mathbf{o} + t\mathbf{d}$, a bounding volume $B$, and an SDF $f(\mathbf{p})$. The outputs are a set of sample points $P$ with associated features, or rendered color/depth if integrated immediately.

### Data Structures
1.  **Uniform Point Set ($P_u$)**: A set of points uniformly distributed in the bounding volume $B = [-1, 1]^3$ or along the ray $r(t)$ [S1, S2].
2.  **Indicator Grid ($G_o$)**: A data structure (e.g., a hash grid or voxel grid) that maps points to their proximity to the surface, used to filter $P_u$ into surface-adjacent points $P$ [S2].
3.  **Feature Vector ($v$)**: For each point $\mathbf{p} \in P$, a vector initialized to 1, updated by interpolating values from static and dynamic fields [S2].
4.  **Static/Dynamic Fields ($\{V^s_{3d}, V^d_{3d}\}_4$)**: Four levels of 3D fields storing geometric or temporal information [S2].
5.  **Tiny MLP ($\theta$)**: A small neural network taking concatenated coordinates and features to predict color $c_i$ and density $\sigma_i$ [S2].

### Algorithm Steps

#### Phase 1: Point Sampling
1.  **Generate Uniform Samples**: Create a set of points $P_u$ uniformly distributed in the bounding volume $B$ or along the ray $r(t)$ [S1, S2].
2.  **Filter via Indicator Grid**: Pass $P_u$ through the indicator grid $G_o$ to obtain the final sample set $P$. Points in $P$ are distributed around the surface [S2].
    *   *Alternative Surface Sampling*: For mesh-based SDFs, sample uniformly distributed points in $B$, choose random points on a sphere to form ray directions, and test for hits using sphere tracing. Continue until enough rays hit the surface [S1].
    *   *Near-Surface Perturbation*: To capture near-surface geometry, take existing surface samples and perturb the vector with random Gaussian noise with standard deviation $\sigma = 0.01$ [S1].

#### Phase 2: Feature Encoding and Rendering (Forplane Rendering Procedure)
For each point $\mathbf{p} = (x, y, z, \tau)$ in $P$ (where $\tau$ is time):

1.  **Initialize Feature Vector**: Set $v(x, y, z, \tau) = 1$ [S2].
2.  **Interpolate Fields**: Iterate over the 4 levels of static and dynamic fields $\{V^s_{3d}, V^d_{3d}\}_4$ and corresponding dimension pairs $(xy, xz, x\tau, yz, y\tau, z\tau)$ [S2].
    *   For each grid $G$ and dimension pair $ij$, perform bi-linear interpolation $B(G, i, j)$ [S2].
    *   Update $v$ via element-wise multiplication: $v \leftarrow v \odot B(G, i, j)$ [S2].
3.  **Concatenate Encoding**: Concatenate the coordinate-time encoding $b(x, y, z, \tau)$ with the interpolated features $v(x, y, z, \tau)$ [S2]. The encoding $b$ uses one-blob encoding separately on each coordinate value [S2].
4.  **Predict Properties**: Pass the features through the tiny MLP $\theta$ to predict color $c_i$ and density $\sigma_i$:
    $$ (c_i, \sigma_i) = \theta(\text{concat}(b, v)) $$
    [S2].
5.  **Volume Rendering Integration**: Render expected color $\hat{C}$ and depth $\hat{D}$ by integrating radiance and density along the ray using standard volume rendering equations [S2]:
    $$ \hat{C} = \int_{t_n}^{t_f} w(t) \cdot c(r(t), \mathbf{d}) \, dt $$
    $$ \hat{D} = \int_{t_n}^{t_f} w(t) \cdot t \, dt $$
    where the weight function is:
    $$ w(t) = \sigma(r(t)) \exp \left( -\int_{t_n}^{t} \sigma(r(s)) \, ds \right) $$
    [S2].

### Parameters and Edge Cases
*   **Bounding Volume $B$**: Typically $[-1, 1]^3$ [S1].
*   **Noise Standard Deviation $\sigma$**: $0.01$ for near-surface perturbation [S1].
*   **Indicator Grid**: The specific resolution and structure of $G_o$ are not given in the sources [S2].
*   **Precision**: Floating-point precision issues may arise when $f(\mathbf{p})$ is very small, affecting the accuracy of the indicator grid filtering [G].
*   **Degenerate Input**: If the ray does not intersect the surface, $P$ will be empty, and the method should return a background color [S2].

## Subtopics

### Near-Surface Point Sampling
This method perturbs existing surface samples with random Gaussian noise ($\sigma = 0.01$) to capture geometry close to the surface [S1]. It is chosen when fine details near the surface are critical, such as in neural rendering of thin structures. It differs from uniform sampling by focusing density near the implicit boundary [S1].

### Projection Point Integration
This method incorporates projection points derived from gradient information into power diagram computation to accurately capture the underlying surface, particularly in regions with complex topology or fine details [S3]. It is chosen when topological integrity is crucial, as it preserves features like thin structures and sharp edges better than baseline sampling [S3]. It differs from standard sampling by using gradient-based projections to guide the power diagram construction [S3].

### Surface Interaction Construction
This method constructs a `SurfaceInteraction3f` structure from a ray and intersection time, computing normal, frame, and other interaction properties without SDF autodiff support [S4, unofficial]. It is chosen when explicit interaction data is needed for shading or physics, and autodiff is unavailable [S4, unofficial]. It differs from other sampling methods by focusing on the construction of a complete interaction object rather than just point positions [S4, unofficial].

## Operating characteristics
*   **Time Complexity**: The sampling phase is $O(N)$ where $N$ is the number of uniform points [S2]. The feature encoding phase involves iterating over 4 levels and 6 dimension pairs per point, making it $O(N \cdot L \cdot D)$ where $L=4$ and $D=6$ [S2]. The MLP inference is $O(N \cdot M)$ where $M$ is the MLP size [S2].
*   **Memory Complexity**: Requires storing the indicator grid, static/dynamic fields, and the point set $P$ [S2].
*   **Performance**: The method is designed for real-time rendering, using a "tiny MLP" to reduce computational cost [S2].
*   **Strengths**: Captures surface details and temporal dynamics efficiently [S2].
*   **Limitations**: Relies on the quality of the indicator grid and the MLP [S2].

## Background
The method originates from research on neural geometric level of detail and efficient deformable tissue reconstruction [S1, S2]. It was developed to enable real-time rendering of implicit 3D shapes by combining sphere tracing with neural feature encoding [S1, S2]. The "Forplane Rendering Procedure" is specifically associated with the Efficient Deformable Tissue Reconstruction paper [S2].
