# Surface Point Sampling for SDFs

Also called: Forplane Rendering Procedure, Sphere Tracing Surface Sampling

## Overview
Surface Point Sampling for SDFs generates a set of 3D points distributed around the implicit surface defined by a Signed Distance Function (SDF) to serve as input for neural rendering or geometric reconstruction pipelines [S1, S2]. Unlike standard sphere tracing which terminates at a single hit point, this method samples multiple points along rays or within the volume to capture surface geometry and local features for subsequent processing [S1, S2]. It differs from its sibling [Sphere Tracing with SDFs](6223-sphere-tracing-with-sdfs.md) by focusing on generating a dense, structured point cloud for neural field training or rendering, rather than just determining visibility or shading for a single pixel [S1, S2]. It is distinct from [Near-Surface Point Sampling](2910-near-surface-point-sampling.md) in that it often includes uniform background sampling to learn the free space volume, not just the immediate vicinity of the surface [S1].

## How it works
The method generates sample points by casting rays and querying the SDF, filtering for points near the zero-level set, and optionally enriching them with feature information.

### Inputs and Outputs
**Inputs:**
*   SDF function $f(\mathbf{p})$ returning signed distance [S1, S2].
*   Bounding volume $B$, typically $[-1, 1]^3$ [S1].
*   Ray origin $\mathbf{o}$ and direction $\mathbf{d}$ [S1, S2].
*   (Optional) Indicator grid $G_o$ and neural fields $\{V^s_{3d}, V^d_{3d}\}$ for feature extraction [S2].
*   (Optional) Tiny MLP $\theta$ for color/density prediction [S2].

**Outputs:**
*   Point set $P$ containing coordinates and potentially features (color, density, gradients) [S1, S2].
*   Rendered color $\hat{C}$ and depth $\hat{D}$ if used in a rendering loop [S2].

### Data Structures
*   **Point Set $P_u$**: Uniformly sampled points in space or along rays.
*   **Point Set $P$**: Filtered points near the surface. Each point $\mathbf{p} \in P$ has coordinates $(x, y, z)$ and optionally time $\tau$ [S2].
*   **Feature Vector $v$**: Initialized to 1, updated via interpolation from grid fields [S2].
*   **Indicator Grid $G_o$**: A sparse or dense grid used to filter points near the surface [S2].

### Steps
1.  **Uniform Sampling**: Generate a set of uniformly distributed points $P_u$ within the bounding volume $B$ [S1, S2]. Alternatively, generate rays by choosing random points on a sphere for the origin and random directions [S1].
2.  **Sphere Tracing**: For each ray, perform sphere tracing to find the intersection with the SDF surface [S1]. The ray $r(t) = \mathbf{o} + t\mathbf{d}$ is advanced by $\Delta t = f(\mathbf{p}_i)$ until $f(\mathbf{p}_i) < \epsilon$ or max steps are reached [S1, S2].
3.  **Surface Filtering**: Pass the sampled points $P_u$ through an indicator grid $G_o$ to obtain sample points $P$ distributed around the surface [S2]. Points are retained if they are sufficiently close to the surface (i.e., $|f(\mathbf{p})| < \epsilon$) [S1, S2].
4.  **Feature Extraction (Optional)**: For each point $\mathbf{p}(x, y, z, \tau)$ in $P$:
    a. Initialize feature vector $v(x, y, z, \tau) = 1$ [S2].
    b. Iterate over 4 levels of static and dynamic fields $\{V^s_{3d}, V^d_{3d}\}_4$ and dimension pairs $(xy, xz, x\tau, yz, y\tau, z\tau)$ [S2].
    c. Perform bi-linear interpolation $B(G, i, j)$ on each grid $G$ for the dimension pair $ij$ [S2].
    d. Update $v$ via element-wise multiplication: $v \leftarrow v \odot B(G, i, j)$ [S2].
5.  **Encoding and Prediction**: Concatenate the coordinate-time encoding $b(x, y, z, \tau)$ with the interpolated features $v(x, y, z, \tau)$ [S2]. Pass through a tiny MLP $\theta$ to predict color $c_i$ and density $\sigma_i$ [S2].
6.  **Rendering (Optional)**: Integrate radiance and density along the ray using standard volume rendering equations to compute expected color $\hat{C}$ and depth $\hat{D}$ [S2]:
    $$ \hat{C} = \int_{t_n}^{t_f} w(t) \cdot c(r(t), \mathbf{d}) \, dt, \quad \hat{D} = \int_{t_n}^{t_f} w(t) \cdot t \, dt $$
    where $w(t) = \exp\left(-\int_{t_n}^{t} \sigma(r(s)) \, ds\right) \sigma(r(t))$ [S2].

### Pseudocode
```python
def surface_point_sampling(sdf, bounding_volume, num_rays, epsilon=0.001, max_steps=64):
    """
    Generates surface points by ray marching through an SDF.
    
    Args:
        sdf: Function returning signed distance for a point p.
        bounding_volume: Tuple (min, max) defining the box, e.g., (-1, 1).
        num_rays: Number of rays to cast.
        epsilon: Convergence threshold for surface hit.
        max_steps: Maximum sphere tracing steps.
        
    Returns:
        points: List of 3D points near the surface.
    """
    points = []
    
    for _ in range(num_rays):
        # 1. Generate random ray
        # Origin: random point in bounding volume
        o = random_point_in_box(bounding_volume)
        # Direction: random point on unit sphere
        d = random_unit_vector()
        
        # 2. Sphere Tracing
        t = 0.0
        p = o
        hit = False
        
        for step in range(max_steps):
            dist = sdf(p)
            
            # Check for surface hit
            if abs(dist) < epsilon:
                hit = True
                break
            
            # Check for escape (optional, based on bounding volume)
            if t > bounding_volume[1] * 2.0: # Heuristic max distance
                break
                
            # Advance ray
            t += dist
            p = o + t * d
            
        # 3. Filter points
        if hit:
            points.append(p)
            
    return points

def neural_surface_sampling(sdf, indicator_grid, static_fields, dynamic_fields, mlp, num_samples=10000):
    """
    Generates points with neural features for rendering/training.
    
    Args:
        sdf: SDF function.
        indicator_grid: Grid to filter surface points.
        static_fields: List of 4 static 3D fields.
        dynamic_fields: List of 4 dynamic 3D fields.
        mlp: Neural network for color/density.
        num_samples: Number of initial uniform samples.
        
    Returns:
        rendered_color, rendered_depth
    """
    # 1. Uniform Sampling
    P_u = uniform_sample_points(num_samples, bounding_volume=(-1, 1))
    
    # 2. Filter via Indicator Grid
    P = []
    for p in P_u:
        # Check if point is near surface using indicator grid or SDF
        if indicator_grid.query(p) or abs(sdf(p)) < 0.01:
            P.append(p)
            
    # 3. Feature Extraction and Rendering
    # Note: In practice, this is done per-ray or per-point batch
    total_color = 0.0
    total_depth = 0.0
    total_weight = 0.0
    
    for p in P:
        x, y, z, tau = p.coords, p.time
        
        # Initialize feature vector
        v = 1.0
        
        # Interpolate from fields
        fields = static_fields + dynamic_fields
        dim_pairs = [(0,1), (0,2), (0,3), (1,2), (1,3), (2,3)] # xy, xz, xtau, yz, ytau, ztau
        
        for field in fields:
            for i, j in dim_pairs:
                # Bi-linear interpolation on grid
                val = bilinear_interpolate(field, x, y, z, i, j)
                v = v * val
                
        # Concatenate with positional encoding
        b = one_blob_encoding(x, y, z, tau)
        features = concatenate(b, v)
        
        # Predict color and density
        c, sigma = mlp.forward(features)
        
        # Integrate (simplified single-step for illustration)
        # In full volume rendering, integrate along ray
        weight = sigma * exp(-sigma * 0.01) # Approximation
        total_color += weight * c
        total_depth += weight * p.distance
        total_weight += weight
        
    rendered_color = total_color / total_weight if total_weight > 0 else 0.0
    rendered_depth = total_depth / total_weight if total_weight > 0 else 0.0
    
    return rendered_color, rendered_depth
```

### Parameters
*   **$\epsilon$**: Convergence threshold, typically $0.001$ [S1, S2].
*   **Max Steps**: Prevents infinite loops, typically 64-128 [S1, S2].
*   **Batch Size**: For training, typically 512 points [S1].
*   **Learning Rate**: For MLP training, typically $0.001$ [S1].

### Edge Cases and Pitfalls
*   **Precision**: Small $\epsilon$ may miss thin structures; large $\epsilon$ may include off-surface points [S3].
*   **Thin Structures**: Standard sampling may miss thin features; projection points are recommended [S3].
*   **Degenerate Input**: Empty SDFs or invalid bounding volumes should be handled [G].

## Subtopics

### [Near-Surface Point Sampling](2910-near-surface-point-sampling.md)
This method samples points in the immediate vicinity of the surface by perturbing surface samples with Gaussian noise ($\sigma = 0.01$). It is chosen when the model needs to learn the sharp transition of the SDF near the zero-level set, complementing uniform and surface samples.

### Projection Point Integration
This variant incorporates projection points derived from gradient information into the power diagram computation [S3]. It is used to accurately capture complex topology, thin structures, and sharp edges that discrete SDF sampling might miss [S3]. It preserves topological integrity better than baseline sampling [S3].

### Surface Interaction Construction
This method constructs a `SurfaceInteraction3f` structure from a ray and intersection time, computing normal, frame, and other properties without SDF autodiff [S4, unofficial]. It is used in rendering engines to provide interaction data for shading models [S4, unofficial].

## Operating characteristics
*   **Time Complexity**: $O(N \cdot S)$ where $N$ is the number of rays/samples and $S$ is the number of sphere tracing steps per ray [S1, S2]. Feature extraction adds $O(N \cdot L \cdot D)$ where $L$ is the number of field levels and $D$ is the number of dimension pairs [S2].
*   **Memory Complexity**: $O(N)$ to store the point set and features [S2].
*   **Performance**: Depends heavily on SDF evaluation cost and network size. Neural fields can be slow if not optimized [S1, S2].
*   **Strengths**: Captures detailed geometry; suitable for neural rendering [S1, S2].
*   **Limitations**: Computationally expensive for high-resolution scenes; sensitive to $\epsilon$ [S1, S3].

## Background
The method originates from neural implicit representation research, specifically Neural Geometric Level of Detail (Neural GLOD) [S1] and Efficient Deformable Tissue Reconstruction via Orthogonal Neural Plane [S2]. It builds on sphere tracing [S21-distance-field-ray-marching.md] and extends it to generate training data for neural networks [S1, S2].
