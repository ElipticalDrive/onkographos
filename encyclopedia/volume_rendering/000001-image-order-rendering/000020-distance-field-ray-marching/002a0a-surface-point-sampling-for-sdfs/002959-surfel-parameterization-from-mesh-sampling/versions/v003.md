# Surfel Parameterization from Mesh Sampling

Also called: Point Cloud Surfel Estimation, Surfel Parameterization

## Overview
This method estimates the full parameter set (position, normal, tangent vectors, and scales) for a surfel representation starting from a triangle mesh [S1, unofficial]. It solves the problem of defining local tangent frames and anisotropic kernel shapes for point clouds sampled from meshes, where positions and normals are known but geometric extent is not [S1, unofficial]. It differs from sibling methods by deriving tangent scales from the local point cloud neighborhood structure rather than mesh connectivity or fixed heuristics, offering two variants: isotropic scaling for performance and anisotropic scaling for quality [S1, unofficial].

## How it works
**Inputs:** A triangle mesh (vertices and faces) [S1, unofficial].
**Outputs:** A point cloud where each point carries position $\mathbf{p}$, normal $\mathbf{n}$, two tangent vectors $\mathbf{t}_1, \mathbf{t}_2$, and two scale parameters $s_1, s_2$ [S1, unofficial].

**Data Structures:**
*   **Point Cloud:** List of points. Each point stores:
    *   $\mathbf{p} \in \mathbb{R}^3$: Position.
    *   $\mathbf{n} \in \mathbb{R}^3$: Face normal (unit length).
    *   $\mathbf{t}_1, \mathbf{t}_2 \in \mathbb{R}^3$: Orthonormal tangent vectors.
    *   $s_1, s_2 \in \mathbb{R}$: Tangent scales.
*   **Spatial Acceleration Structure:** A neighbor search structure (e.g., KD-tree or grid) built on the sampled points to support orientation-aware nearest neighbor queries, shared with optimization initialization and splitting criteria [S1, unofficial].

**Steps:**

1.  **Sampling:** Sample points from the triangle mesh. For each sample, record the position $\mathbf{p}$ and the face normal $\mathbf{n}$ directly from the mesh geometry [S1, unofficial].
2.  **Neighbor Selection:** For each point $\mathbf{p}_i$ with normal $\mathbf{n}_i$, query the spatial acceleration structure to find a set of nearest neighbors $\mathcal{N}_i$ [S1, unofficial]. The selection must be "orientation-aware," meaning neighbors are filtered or weighted based on normal compatibility (e.g., $\mathbf{n}_j \cdot \mathbf{n}_i > \epsilon$) [G].
3.  **Parameter Estimation:** Choose one of the following strategies to estimate $\mathbf{t}_1, \mathbf{t}_2, s_1, s_2$ [S1, unofficial].

    **Strategy A: Isotropic Scaling**
    *   **Tangent Vectors:** Construct an orthonormal frame $\{\mathbf{t}_1, \mathbf{t}_2\}$ from $\mathbf{n}_i$ using a standard orthonormal basis construction [S1, unofficial].
    *   **Scales:** Compute the mean distance $d_{\text{mean}}$ to the orientation-aware nearest neighbors in $\mathcal{N}_i$. Set the tangent scale isotropically to $d_{\text{mean}}$ [S1, unofficial].

    **Strategy B: Anisotropic Scaling**
    *   **Projection:** Identify neighbors $\mathcal{N}_i^{\text{compat}}$ that share a compatible normal orientation with $\mathbf{n}_i$ [S1, unofficial]. Project these neighbors' positions onto the tangent plane defined by $\mathbf{n}_i$ [S1, unofficial]. Let $\mathbf{p}_j^{\text{proj}}$ be the projection of neighbor $\mathbf{p}_j$:
        $$ \mathbf{p}_j^{\text{proj}} = \mathbf{p}_j - (\mathbf{p}_j \cdot \mathbf{n}_i)\mathbf{n}_i $$
        [G].
    *   **PCA:** Compute the $2 \times 2$ covariance matrix $C$ of the projected coordinates in the tangent plane [S1, unofficial]. To do this, first define a local 2D basis $\{\mathbf{u}, \mathbf{v}\}$ for the tangent plane (derived from $\mathbf{t}_1, \mathbf{t}_2$) [G]. Compute the 2D coordinates $(x_j, y_j)$ of each projected point in this basis [G]. Then:
        $$ C = \frac{1}{|\mathcal{N}_i^{\text{compat}}|} \sum_{j \in \mathcal{N}_i^{\text{compat}}} \begin{bmatrix} x_j \\ y_j \end{bmatrix} \begin{bmatrix} x_j & y_j \end{bmatrix} $$
        [G].
    *   **Eigendecomposition:** Compute the eigenvalues $\lambda_1, \lambda_2$ and eigenvectors $\mathbf{e}_1, \mathbf{e}_2$ of $C$ [S1, unofficial].
    *   **Tangent Vectors:** Set $\mathbf{t}_1$ and $\mathbf{t}_2$ to the 3D vectors corresponding to $\mathbf{e}_1$ and $\mathbf{e}_2$ mapped back into 3D space using the tangent basis $\{\mathbf{u}, \mathbf{v}\}$ [G].
    *   **Scales:** Use the corresponding eigenvalues to determine anisotropic scales that adapt the kernel shape to the local point distribution [S1, unofficial].

**Pseudocode:**

```python
import numpy as np

def estimate_tangent_frame_isotropic(p_i, normal, neighbors_positions, neighbors_normals):
    """Estimates isotropic tangent frame and scale from orientation-aware neighbors."""
    # Filter compatible neighbors based on normal orientation
    dot_products = np.dot(neighbors_normals, normal)
    compatible_mask = dot_products > 0.0  # Threshold not given in sources [G]
    compatible_positions = neighbors_positions[compatible_mask]

    if len(compatible_positions) == 0:
        # Fallback if no compatible neighbors [G]
        return _standard_orthonormal_frame(normal), 0.0

    # Compute mean distance to orientation-aware nearest neighbors
    distances = np.linalg.norm(compatible_positions - p_i, axis=1)
    mean_dist = np.mean(distances)

    # Construct orthonormal frame from normal
    t1, t2 = _standard_orthonormal_frame(normal)

    return t1, t2, mean_dist

def estimate_tangent_frame_anisotropic(p_i, normal, neighbors_positions, neighbors_normals):
    """Estimates anisotropic tangent frame and scales via 2D PCA on projected neighbors."""
    # Filter compatible neighbors based on normal orientation
    dot_products = np.dot(neighbors_normals, normal)
    compatible_mask = dot_products > 0.0  # Threshold not given in sources [G]
    compatible_positions = neighbors_positions[compatible_mask]

    if len(compatible_positions) == 0:
        # Fallback to isotropic frame [G]
        t1, t2 = _standard_orthonormal_frame(normal)
        return t1, t2, 0.0, 0.0

    # Project positions onto tangent plane defined by normal
    # p_proj = p - (p . n) * n
    projections = compatible_positions - np.dot(compatible_positions, normal)[:, None] * normal

    # Construct local 2D basis {u, v} for the tangent plane from normal [G]
    u, v = _standard_orthonormal_frame(normal)

    # Compute 2D coordinates (x_j, y_j) of each projected point in this basis
    x_coords = np.dot(projections, u)
    y_coords = np.dot(projections, v)

    # Center coordinates for PCA
    x_coords = x_coords - np.mean(x_coords)
    y_coords = y_coords - np.mean(y_coords)

    # Compute 2x2 covariance matrix C
    N = len(x_coords)
    if N == 0:
        t1, t2 = _standard_orthonormal_frame(normal)
        return t1, t2, 0.0, 0.0

    cov_xx = np.mean(x_coords**2)
    cov_yy = np.mean(y_coords**2)
    cov_xy = np.mean(x_coords * y_coords)
    C = np.array([[cov_xx, cov_xy], [cov_xy, cov_yy]])

    # Eigendecomposition of C
    eigenvalues, eigenvectors = np.linalg.eigh(C)

    # Sort by eigenvalue descending
    idx = eigenvalues.argsort()[::-1]
    eigenvalues = eigenvalues[idx]
    eigenvectors = eigenvectors[:, idx]

    # Scales are determined from eigenvalues [S1, unofficial]
    s1 = eigenvalues[0]
    s2 = eigenvalues[1]

    # Tangent vectors are eigenvectors mapped back to 3D using basis {u, v} [G]
    t1 = eigenvectors[0, 0] * u + eigenvectors[1, 0] * v
    t2 = eigenvectors[0, 1] * u + eigenvectors[1, 1] * v

    return t1, t2, s1, s2

def _standard_orthonormal_frame(normal):
    """Constructs an orthonormal frame {t1, t2} from normal n [G]."""
    up = np.array([0.0, 0.0, 1.0])
    if np.abs(np.dot(normal, up)) > 0.9:
        up = np.array([1.0, 0.0, 0.0])
    t1 = np.cross(normal, up)
    t1 = t1 / np.linalg.norm(t1)
    t2 = np.cross(normal, t1)
    t2 = t2 / np.linalg.norm(t2)
    return t1, t2
```

**Parameters:**
*   `normal_threshold`: Threshold for normal compatibility in neighbor selection. Not given in the sources. [G]
*   `neighbor_count`: Number of nearest neighbors to query. Not given in the sources. [G]

**Edge Cases and Pitfalls:**
*   **Sharp Edges:** Isotropic scaling produces minor visual artifacts at sharp geometric edges because the isotropic kernel does not conform to local surface curvature [S1, unofficial].
*   **Degenerate Neighbors:** If no compatible neighbors are found, fallback strategies (e.g., isotropic frame with zero scale or default scale) must be implemented [G].
*   **Computational Cost:** Anisotropic scaling requires eigendecomposition, which increases computational overhead and memory consumption compared to isotropic scaling [S1, unofficial].

## Subtopics

### Isotropic Surfel Parameterization
Uses a fixed orthonormal frame and mean neighbor distance for scales. Chosen when performance is critical. [Isotropic Surfel Parameterization](52-isotropic-surfel-parameterization.md)

### Anisotropic Surfel Parameterization
Uses PCA on projected neighbors for scales and frame. Chosen for quality, eliminating edge artifacts. [Anisotropic Surfel Parameterization](52-anisotropic-surfel-parameterization.md)

## Operating characteristics
*   **Time Complexity:** Dominated by neighbor search (logarithmic with KD-tree) and, for anisotropic, eigendecomposition (constant time per point, $O(1)$ for fixed neighbor count) [G]. Isotropic is faster due to simpler scale calculation [S1, unofficial].
*   **Memory Complexity:** Requires storing the spatial acceleration structure and neighbor data. Anisotropic requires temporary storage for projections and covariance matrix [G].
*   **Performance:** Anisotropic variant is used for quality in experiments; isotropic is a drop-in replacement for performance-critical applications [S1, unofficial].
*   **Strengths:** Anisotropic scaling adapts to local point distribution, eliminating edge artifacts. Isotropic scaling is computationally efficient [S1, unofficial].
*   **Limitations:** Anisotropic scaling has higher overhead. Isotropic scaling fails to capture anisotropy at edges [S1, unofficial].

## Background
This method is part of the 3DSS (3D Surface Splatting for Inverse Rendering) framework [S1, unofficial]. It was developed to enable fully textured mesh representation for relighting and material editing in standard rendering engines [S1, unofficial].
