# Surfel Parameterization from Mesh Sampling

Also called: Point Cloud Surfel Estimation, Surfel Parameterization

## Overview
Surfel parameterization from mesh sampling estimates surfel parameters (tangent vectors and scales) for a point cloud sampled from a triangle mesh, where point positions and face normals are obtained directly from sampling, and remaining parameters are estimated from the local neighborhood structure [S1, unofficial].

## How it works
**Inputs:** A triangle mesh.
**Outputs:** A point cloud with surfel parameters.

**Data Structures:**
*   **Point Cloud:** A list of points. Each point stores a 3D position, a face normal, two tangent vectors, and two scale parameters defining the surfel kernel.
*   **Spatial Acceleration Structure:** A spatial index (e.g., KD-tree, octree) built on the sampled points to enable efficient nearest-neighbor queries. The same structure is shared with optimization initialization and splitting criteria [S1, unofficial].

**Steps:**

1.  **Sample Points and Normals:** Obtain point positions and face normals directly from the mesh sampling procedure [S1, unofficial].
2.  **Estimate Tangent Vectors and Scales:** For each sampled point, estimate the tangent frame and scales from the local neighborhood structure using one of two strategies: isotropic scaling or anisotropic scaling [S1, unofficial].

    **Strategy A: Isotropic Scaling**
    1.  **Construct Tangent Vectors:** Build an orthonormal basis for the tangent plane directly from the sampled normal direction using a standard orthonormal frame construction [S1, unofficial].
    2.  **Estimate Scale:** Set the tangent scale isotropically to the mean distance to orientation-aware nearest neighbors. This uses the same mechanism as optimization initialization and the splitting criterion, sharing the spatial acceleration structure [S1, unofficial].

    **Strategy B: Anisotropic Scaling**
    1.  **Identify Compatible Neighbors:** Query the spatial acceleration structure for neighboring points and filter for those sharing a compatible normal orientation with the sample [S1, unofficial].
    2.  **Project to Tangent Plane:** Project the compatible neighboring points onto the tangent plane defined by the sample normal [S1, unofficial].
    3.  **2D PCA:** Perform a 2D principal component analysis (PCA) on the projected coordinates [S1, unofficial].
    4.  **Define Tangents and Scales:** Use the eigenvectors of the resulting $2 \times 2$ covariance matrix to define the tangent directions, and use the corresponding eigenvalues to determine anisotropic scales that adapt the kernel shape to the local point distribution [S1, unofficial].

**Pseudocode:**
```python
def estimate_surfel_parameters(points, normals, spatial_index, strategy='anisotropic'):
    for i in range(len(points)):
        p_i = points[i]
        n_i = normals[i]
        
        if strategy == 'isotropic':
            # Standard orthonormal frame construction from normal [G]
            t1, t2 = _standard_orthonormal_frame(n_i)
            
            # Query orientation-aware nearest neighbors [S1, unofficial]
            neighbors = spatial_index.query_orientation_aware(p_i, n_i)
            distances = [math.sqrt(sum((p_j - p_i)**2 for p_j in neighbors))]
            scale = sum(distances) / len(distances)
            scales = (scale, scale)
            
        elif strategy == 'anisotropic':
            # Identify neighbors with compatible normal orientation [S1, unofficial]
            neighbors = spatial_index.query_compatible(p_i, n_i)
            
            # Project to tangent plane defined by sample normal [S1, unofficial]
            projected = [p_j - dot(p_j - p_i, n_i) * n_i for p_j in neighbors]
            
            # Construct local 2D basis for tangent plane [G]
            u1, u2 = _standard_orthonormal_frame(n_i)
            
            # Compute 2D coordinates for PCA [S1, unofficial]
            coords = [(dot(v, u1), dot(v, u2)) for v in projected]
            cov_matrix = _compute_2x2_covariance(coords)
            
            # Eigendecomposition of 2x2 covariance matrix [S1, unofficial]
            eigenvalues, eigenvectors = _eig_2x2(cov_matrix)
            
            # Eigenvectors define tangent directions in 3D [S1, unofficial]
            t1 = eigenvectors[0][0] * u1 + eigenvectors[0][1] * u2
            t2 = eigenvectors[1][0] * u1 + eigenvectors[1][1] * u2
            
            # Eigenvalues determine anisotropic scales [S1, unofficial]
            scales = (math.sqrt(eigenvalues[0]), math.sqrt(eigenvalues[1]))
            
        points[i].tangents = (t1, t2)
        points[i].scales = scales

def _standard_orthonormal_frame(n):
    # Standard robust frame construction [G]
    if abs(n[2]) < 0.9:
        a = (0, 0, 1)
    else:
        a = (1, 0, 0)
    t1 = normalize(a - dot(a, n) * n)
    t2 = cross(n, t1)
    return t1, t2

def _compute_2x2_covariance(coords):
    n = len(coords)
    mean_x = sum(c[0] for c in coords) / n
    mean_y = sum(c[1] for c in coords) / n
    var_x = sum((c[0] - mean_x)**2 for c in coords) / n
    var_y = sum((c[1] - mean_y)**2 for c in coords) / n
    cov_xy = sum((c[0] - mean_x) * (c[1] - mean_y) for c in coords) / n
    return [[var_x, cov_xy], [cov_xy, var_y]]

def _eig_2x2(M):
    # Closed-form eigendecomposition for 2x2 symmetric matrix [G]
    tr = M[0][0] + M[1][1]
    det = M[0][0] * M[1][1] - M[0][1] * M[1][0]
    disc = math.sqrt(max(0, (tr/2)**2 - det))
    l1 = tr/2 + disc
    l2 = tr/2 - disc
    # Eigenvectors for symmetric 2x2
    if abs(M[0][1]) > 1e-8:
        e1 = normalize((M[0][1], l1 - M[0][0]))
        e2 = normalize((M[0][1], l2 - M[0][0]))
    else:
        e1 = (1, 0)
        e2 = (0, 1)
    return (l1, l2), (e1, e2)
```

**Parameters:**
*   Neighbor count for spatial queries: Not given in the sources.
*   Normal compatibility threshold: Not given in the sources.
*   Scale multiplier for eigenvalues: Not given in the sources.

**Edge Cases and Pitfalls:**
*   **Sharp Edges:** Isotropic scaling can produce minor visual artifacts at sharp geometric edges where an isotropic kernel does not conform well to the local surface curvature [S1, unofficial].
*   **Computational Cost:** Anisotropic scaling has higher computational overhead and memory consumption due to the eigendecomposition and neighbor filtering [S1, unofficial].

## Subtopics

### Local Differential Geometry Computation
A method to compute curvatures (Gaussian and Mean) and local differential geometry for a visible oriented point $(p, v)$ using only the directional distance field $d(p, v)$ and its derivatives with respect to $p$ [S2]. It constructs a local coordinate system at the surface point $q = p + d(p, v)v$ by choosing two tangent vectors $t_x, t_y \in T_q(S)$ such that $||t_\alpha||_2 = 1$ and $t_x^T t_y = 0$. In practice, this is done by sampling Gaussian vectors and extracting an orthogonal tangent basis [S2]. The surface is reparameterized near $q_0$ via $S(x, y) = q_0 + x t_x + y t_y + f_S(x, y)n_0$, where $x$ and $y$ control position on the tangent plane, or equivalently $p(u) = p_0 + x t_x + y t_y$ where $u = (x, y)$ [S2]. The first-order derivatives of the surface at $u=0$ are $\partial_i S|_{u=0} = t_i + (\nabla_p d(p, v_0) t_i) v_0$, where $i \in \{x, y\}$ [S2]. The metric tensor (first fundamental form) is $g_{ij} = \partial_i S^T \partial_j S = \delta_{ij} + c_i c_j + c_i v_0^T t_j + c_j v_0^T t_i$, where $c_k = \nabla_p d t_k$. In theory, since $\nabla_p d$ is parallel to normal $n$ and orthogonal to tangents, $c_x = c_y = 0$, so $g_{ij} = \delta_{ij}$. In practice, use the theoretical value $g = I_2$ [S2]. The shape tensor (second fundamental form) is $\Pi_{ij} = (t_j^T H_p[d] t_i) n_0^T v_0$, where $H_p[d]$ is the Hessian of $d$ with respect to $p$ at $u=0$, and $n_0$ is the surface normal at $q_0$ [S2]. Gaussian curvature is $C_K = \det(\Pi) / \det(g)$ and Mean curvature is $C_H = \text{tr}(\Pi g^{-1})$ [S2].

## Operating characteristics
*   **Performance:** The isotropic variant is computationally efficient and available as a drop-in replacement when performance is critical [S1, unofficial]. The anisotropic variant is used for quality in experiments but incurs higher overhead [S1, unofficial].
*   **Strengths:** Anisotropic scaling eliminates edge artifacts observed with isotropic kernels by adapting the kernel shape to the local point distribution [S1, unofficial].
*   **Limitations:** Isotropic scaling produces artifacts at sharp edges. Anisotropic scaling is slower and uses more memory due to eigendecomposition [S1, unofficial].

## Background
The method originates from the 3DSS (3D Surface Splatting for Inverse Rendering) paper [S1, unofficial]. It is used in inverse rendering pipelines to prepare point clouds for splatting-based rendering and relighting. The local differential geometry computation is described in the context of Probabilistic Directed Distance Fields for Ray-Based Shape Representations [S2].
