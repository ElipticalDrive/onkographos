# Exponential Weighting for Surface Sampling

Also called: Exponential Weighting, Integrated Loss with Importance Sampling, Weighted Integral Loss

## Overview
Exponential Weighting for Surface Sampling is a training strategy for neural implicit surface representations that minimizes an $L_1$ loss integrated over $\mathbb{R}^3$ using importance sampling. It solves the inefficiency of uniform sampling in bounding volumes, where most samples fall in empty space and contribute little to surface accuracy. It sets itself apart from uniform box sampling by concentrating samples near the zero-level set of the signed distance function (SDF), and from mesh-based vertex sampling by avoiding bias toward dense vertex regions or face centers.

## How it works
The method defines the total training loss as a weighted integral over all space, then approximates this integral using importance sampling to avoid numerical underflow associated with high weighting values far from the surface.

### Inputs and Outputs
- **Inputs**:
  - Neural network parameters $\theta$ defining the implicit function $f_\theta(\vec{x})$.
  - Ground truth SDF values $g_S(\vec{x})$ for a target shape $S$.
  - Decay parameter $\beta \ge 0$.
  - Pool size $N_{pool}$ (e.g., $10^7$) and subset size $N_{sub}$ (e.g., $10^6$).
- **Outputs**:
  - Gradient updates for $\theta$ based on the sampled loss.

### Data Structures
- **Sample Pool**: A list of $N_{pool}$ 3D points $\{\vec{x}_i\}_{i=1}^{N_{pool}}$ uniformly distributed within a loose bounding sphere enclosing the shape.
- **Weights**: A list of $N_{pool}$ scalar weights $\{w_i\}_{i=1}^{N_{pool}}$ computed for each point.
- **Indices**: A list of $N_{sub}$ indices into the sample pool, selected via weighted random sampling with replacement.

### Formulas
The total loss is defined as:
$$ L(\theta) = \int_{\mathbb{R}^3} w(\vec{x}) |f_\theta(\vec{x}) - g_S(\vec{x})| d\vec{x} $$
where $w: \mathbb{R}^3 \to \mathbb{R}_{\ge 0}$ is a non-negative weighting function with a finite integral over $\mathbb{R}^3$ [S1, unofficial].

The weighting function is exponential with respect to the distance from the surface:
$$ w(\vec{x}) = e^{-\beta|g_S(\vec{x})|} $$
where $\beta \ge 0$ controls the decay rate [S1, unofficial].

The loss is approximated by sampling from a distribution $D_w$ with probabilities proportional to $w(\vec{x})$:
$$ L(\theta) \approx \sum_{\vec{x} \in D_w} |f_\theta(\vec{x}) - g_S(\vec{x})| $$
Note that the weight $w(\vec{x})$ is absorbed into the sampling distribution, so the summand is the absolute error without the weight factor [S1, unofficial].

### Parameters
- **$\beta$**: Decay parameter.
  - $\beta = 0$: Uniform sampling (weight is constant).
  - $\beta \to \infty$: Surface-only sampling.
  - Typical value: $\beta = 30$ [S1, unofficial].

### Steps
1. **Generate Pool**: Generate $N_{pool}$ points $\{\vec{x}_i\}$ uniformly within a loose bounding sphere around the shape [S1, unofficial].
2. **Compute Weights**: For each point $\vec{x}_i$, compute the ground truth distance $d_i = |g_S(\vec{x}_i)|$ and the weight $w_i = e^{-\beta d_i}$ [S1, unofficial].
3. **Normalize**: Compute the sum of weights $W = \sum_{i=1}^{N_{pool}} w_i$. Compute probabilities $p_i = w_i / W$ [S1, unofficial].
4. **Resample**: Select $N_{sub}$ indices $\{idx_j\}_{j=1}^{N_{sub}}$ from the pool with replacement, where the probability of selecting index $i$ is $p_i$ [S1, unofficial].
5. **Compute Loss**: For each selected index $idx_j$, retrieve point $\vec{x}_{idx_j}$. Compute the absolute error $e_j = |f_\theta(\vec{x}_{idx_j}) - g_S(\vec{x}_{idx_j})|$. Sum these errors to get the approximate loss $L(\theta) \approx \sum_{j=1}^{N_{sub}} e_j$ [S1, unofficial].
6. **Backpropagate**: Compute gradients of $L(\theta)$ with respect to $\theta$ and update parameters [S1, unofficial].

### Pseudocode
```python
import numpy as np

def exponential_weighting_surface_sampling(
    theta, 
    ground_truth_sdf, 
    beta=30.0, 
    pool_size=10_000_000, 
    subset_size=1_000_000, 
    bounding_sphere_radius=1.0
):
    """
    Implements Exponential Weighting for Surface Sampling.
    
    Args:
        theta: Neural network parameters.
        ground_truth_sdf: Function returning g_S(x) for a point x.
        beta: Decay parameter for exponential weighting.
        pool_size: Number of initial uniform samples.
        subset_size: Number of samples after importance resampling.
        bounding_sphere_radius: Radius of the loose bounding sphere.
        
    Returns:
        loss: The approximate integrated L1 loss.
    """
    # Step 1: Generate a large pool of uniform samples within a loose bounding sphere
    # Assuming uniform distribution in a cube, then filtering or scaling to sphere is standard.
    # For simplicity, we generate in a cube and treat it as the loose bound, 
    # or generate in sphere directly. The source says "loose bounding sphere".
    # Generating uniform in sphere:
    points = np.random.normal(size=(pool_size, 3))
    norms = np.linalg.norm(points, axis=1, keepdims=True)
    points = points / norms * np.random.uniform(0, bounding_sphere_radius, size=(pool_size, 1))
    
    # Step 2: Compute weights
    # Compute ground truth distance for all points
    # Note: ground_truth_sdf should return absolute distance |g_S(x)| for the weight calculation
    distances = np.abs(ground_truth_sdf(points))
    
    # Compute exponential weights
    weights = np.exp(-beta * distances)
    
    # Step 3: Normalize weights to get probabilities
    weight_sum = np.sum(weights)
    if weight_sum == 0:
        # Fallback to uniform if all weights are zero (e.g., beta is very high and points are far)
        probabilities = np.ones(pool_size) / pool_size
    else:
        probabilities = weights / weight_sum
        
    # Step 4: Resample with replacement
    indices = np.random.choice(pool_size, size=subset_size, p=probabilities)
    
    # Step 5: Compute loss
    # Retrieve selected points
    selected_points = points[indices]
    
    # Compute neural network prediction
    # f_theta(selected_points) returns the predicted SDF values
    predicted_sdf = evaluate_network(theta, selected_points)
    
    # Compute ground truth SDF values for the selected points
    # Note: The loss term is |f_theta(x) - g_S(x)|. 
    # We need the signed distance g_S(x) for the error calculation, not just absolute distance.
    # The weight used |g_S(x)|, but the loss uses the signed difference.
    true_sdf_values = ground_truth_sdf_signed(selected_points)
    
    # Calculate absolute error
    errors = np.abs(predicted_sdf - true_sdf_values)
    
    # Sum errors to approximate the integral
    # The approximation is sum_{x in D_w} |f(x) - g(x)|
    loss = np.sum(errors)
    
    return loss
```

### Edge Cases and Pitfalls
- **Numerical Underflow**: Direct sampling of the integrand with high $\beta$ leads to numerical underflow. For $\beta=30$, a point unit distance away has weight $w \approx 9 \times 10^{-14}$, which is near the machine double precision limit, causing samples to have little numerical effect [S1, unofficial]. Importance sampling mitigates this by avoiding the direct evaluation of the weighted integrand for distant points.
- **Degenerate Input**: If the bounding sphere is too tight, points near the surface might be missed, leading to poor sampling. A "loose" bounding sphere is recommended [S1, unofficial].

## Operating characteristics
- **Time Complexity**: Dominated by the generation of the initial pool ($O(N_{pool})$) and the evaluation of the ground truth SDF and neural network for the subset ($O(N_{sub})$). Resampling is $O(N_{pool})$ for weight computation and $O(N_{sub})$ for selection.
- **Memory Complexity**: $O(N_{pool})$ to store the pool of points and weights.
- **Measured Performance**: Validation on 1000 Thingi10k geometries showed convergence in 96 epochs with a surface error of 0.00231. Convergence speed matches Park et al. (2019) at 86 epochs, with a ~5% improvement in surface error [S1, unofficial].
- **Strengths**: Avoids wasting samples in empty space compared to uniform sampling. Avoids bias near dense vertex regions and inaccuracy in the middle of faces compared to mesh vertex sampling. Provides flexibility to bias sampling toward regions of high curvature, minimum feature size, or user annotations [S1, unofficial].
- **Limitations**: Requires access to ground truth SDF values for weight computation. High $\beta$ values require careful handling to avoid underflow if not using importance sampling.
- **When to Use**: When training neural implicit surfaces and computational efficiency is a concern, especially for complex geometries where uniform sampling is wasteful.
- **When Not to Use**: When ground truth SDF is not available or expensive to compute for every sample.

## Background
The method was introduced in "On the Effectiveness of Weight-Encoded Neural Implicit 3D Shapes" [S1, unofficial]. It builds on the observation that uniform sampling in a bounding box is wasteful for surface reconstruction [S1, unofficial]. It applies importance sampling to an integrated loss function, a technique rooted in statistical estimation [S1, unofficial].
