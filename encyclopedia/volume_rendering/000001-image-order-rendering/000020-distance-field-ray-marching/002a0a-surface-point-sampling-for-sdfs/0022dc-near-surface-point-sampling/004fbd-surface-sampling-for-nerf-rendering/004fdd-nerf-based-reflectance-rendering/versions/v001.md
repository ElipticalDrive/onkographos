# NeRF-Based Reflectance Rendering

Also called: ObjectReflectanceNeRF Rendering

## Overview
NeRF-Based Reflectance Rendering is a technique that modifies the base color of a 3D object's surface by applying a neural network reflectance model. It operates on points sampled from visible surfaces to account for view-dependent and light-dependent color variations. It differs from standard NeRF rendering by focusing on surface-level reflectance modification rather than volumetric density and color estimation, building on [Surface Sampling for NeRF Rendering](14054-surface-sampling-for-nerf-rendering.md).

## How it works
**Inputs:**
- `camera_position`: 3D vector.
- `light_position`: 3D vector.
- `object_3d`: 3D object containing visible surfaces (triangles) with vertices and normals.
- `resolution`: Tuple `(height, width)`.
- `f`: Focal length (implicit in projection formula).

**Outputs:**
- `buffer`: Image of shape `(height, width, 3)` containing modified colors.

**Data Structures:**
- `Surface`: Contains `vertices` (N, 3), `normals` (N, 3), and `faces`.
- `ObjectReflectanceNeRF`: A neural network model.

**Steps:**
1. Initialize `buffer` of shape `(height, width, 3)` with zeros.
2. Identify visible surfaces from `object_3d` relative to `camera_position`.
3. For each visible surface:
    a. Sample 80 points on the surface. [S1, unofficial]
    b. Compute view directions: `view_dirs = camera_position - points`. Normalize along the last axis.
    c. Compute light directions: `light_dirs = light_position - points`. Normalize along the last axis.
    d. Interpolate normals. [G] Note: A common pitfall is interpolating by taking the mean of all surface normals and tiling, which ignores local geometry variation. [S1, unofficial]
    e. Convert `points`, `normals`, `view_dirs`, and `base_colors` to PyTorch tensors.
    f. Pass tensors through the `ObjectReflectanceNeRF` model (or `ReflectanceNeRF`) within a `torch.no_grad()` block to get `modified_colors`.
    g. Project each point to image coordinates:
       $$d = point - camera\_position$$
       $$x = \text{int}(f \cdot d[0] / d[2] + width / 2)$$
       $$y = \text{int}(f \cdot d[1] / d[2] + height / 2)$$
    h. If $0 \le x < width$ and $0 \le y < height$, set `buffer[y, x] = modified_color`.

**Pseudocode:**
```python
import torch
import numpy as np

def render_reflectance_nerf(model, object_3d, camera_position, light_position, resolution, f):
    height, width = resolution
    buffer = np.zeros((height, width, 3))
    
    # Get visible surfaces and sample points
    # Note: Actual surface sampling logic depends on VectorObject implementation
    points_list = []
    view_dirs_list = []
    light_dirs_list = []
    base_colors_list = []
    
    for surface in object_3d.visible_surfaces(camera_position):
        # Sample 80 points on the surface [S1, unofficial]
        points = sample_points_on_surface(surface, num_samples=80)
        
        # Compute directions
        view_dirs = camera_position - points
        view_dirs = view_dirs / np.linalg.norm(view_dirs, axis=-1, keepdims=True)
        
        light_dirs = light_position - points
        light_dirs = light_dirs / np.linalg.norm(light_dirs, axis=-1, keepdims=True)
        
        # Interpolate normals [G]
        # Pitfall: Avoid simple mean tiling [S1, unofficial]
        normals = interpolate_normals(surface, points)
        
        # Get base colors (e.g., from vertex colors or texture) [G]
        base_colors = get_base_colors(surface, points)
        
        points_list.append(points)
        view_dirs_list.append(view_dirs)
        light_dirs_list.append(light_dirs)
        base_colors_list.append(base_colors)
        
    if not points_list:
        return buffer
        
    # Concatenate all points
    all_points = np.concatenate(points_list)
    all_view_dirs = np.concatenate(view_dirs_list)
    all_light_dirs = np.concatenate(light_dirs_list)
    all_base_colors = np.concatenate(base_colors_list)
    
    # Convert to tensors
    positions = torch.FloatTensor(all_points)
    view_dirs = torch.FloatTensor(all_view_dirs)
    light_dirs = torch.FloatTensor(all_light_dirs)
    base_colors = torch.FloatTensor(all_base_colors)
    
    # Render
    with torch.no_grad():
        modified_colors = model(positions, view_dirs, light_dirs, base_colors)
        modified_colors = modified_colors.numpy()
        
    # Project and fill buffer
    d = all_points - camera_position
    xs = (f * d[:, 0] / d[:, 2] + width / 2).astype(int)
    ys = (f * d[:, 1] / d[:, 2] + height / 2).astype(int)
    
    for i in range(len(all_points)):
        x, y = xs[i], ys[i]
        if 0 <= x < width and 0 <= y < height:
            buffer[y, x] = modified_colors[i]
            
    return buffer
```

## Subtopics

### ObjectReflectanceNeRF
A variant that separates geometric/lighting feature encoding from color modification using a two-branch MLP architecture. It decouples spatial/lighting feature extraction from color modulation, allowing the base color to only affect the final color modifier stage rather than the initial feature encoding. [S1, unofficial]
- **Layout**: Encoder input is `(N, 9)` [position(3), view_dir(3), light_dir(3)]. Encoder output is `(N, 256)`. Color network input is `(N, 259)` [encoder_output(256), base_color(3)]. Color network output is `(N, 3)`. [S1, unofficial]
- **Step**: Concatenate encoder output (256D) with base color (3D) to form a 259D vector. Return the Sigmoid output directly as the modified color. [S1, unofficial]
- **Parameter**: `hidden_dim`: Number of neurons per hidden layer. Default is 256. [S1, unofficial]

## Operating characteristics
**Time and Memory Complexity:**
- Time complexity is dominated by the neural network inference for each sampled point. With 80 points per surface and potentially many surfaces, this can be computationally expensive compared to simple shading. [S1, unofficial]
- Memory usage is proportional to the number of sampled points and the size of the render buffer. [S1, unofficial]

**Strengths and Limitations:**
- **Strengths**: Captures complex view-dependent and light-dependent reflectance properties. [S1, unofficial]
- **Limitations**: Interpolation of normals by taking the mean of all surface normals and tiling ignores local geometry variation, leading to artifacts. [S1, unofficial]
- **When to use**: When accurate reflectance modeling is required for synthetic data generation or specific material rendering. [S1, unofficial]
- **When not to use**: When real-time performance is critical or when simple shading suffices. [S1, unofficial]

## Background
Originated from the `NeRF-Renderer` project by matthxie. [S1, unofficial] It extends the concept of Neural Radiance Fields (NeRF) to specifically model reflectance on surfaces rather than volumetric properties. [S1, unofficial]
