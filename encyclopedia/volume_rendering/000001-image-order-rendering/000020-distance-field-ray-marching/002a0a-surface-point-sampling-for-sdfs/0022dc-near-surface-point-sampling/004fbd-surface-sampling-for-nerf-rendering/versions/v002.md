# Surface Sampling for NeRF Rendering

Also called: Random point sampling on mesh triangles for NeRF input

## Overview
Generates random points on the surface of a 3D object (specifically on triangles) to be used as input for a neural network reflectance model [S1, unofficial].

## How it works
**Inputs:** A mesh defined by vertices and triangular faces [S1, unofficial].
**Outputs:** A list of 3D points on the surface [S1, unofficial].

**Data Structures:**
- `vertices`: Array of shape $(N, 3)$, where $N$ is the number of vertices [G].
- `faces`: Array of shape $(M, 3)$, where $M$ is the number of triangles [G]. Each row contains indices into `vertices` [S1, unofficial].

**Steps:**
1. For each face in the surface, extract vertices $v_1, v_2, v_3$ [S1, unofficial].
2. Generate two random numbers $a$ and $b$ between 0 and 1 [S1, unofficial].
3. If $a + b > 1$, swap them: $a, b = 1 - a, 1 - b$ [S1, unofficial].
4. Calculate $c = 1 - a - b$ [S1, unofficial].
5. Compute the point as a convex combination of the vertices: $point = a \cdot v_1 + b \cdot v_2 + c \cdot v_3$ [S1, unofficial].
6. Append the point to the list [S1, unofficial].
7. Repeat for the specified number of samples per face [S1, unofficial].

**Pseudocode:**
```python
import numpy as np

def sample_surface_points(vertices, faces, samples_per_face):
    """
    Generate random points uniformly distributed on the surface of a mesh.
    
    Args:
        vertices: np.ndarray of shape (N, 3)
        faces: np.ndarray of shape (M, 3) with vertex indices
        samples_per_face: int, number of points to sample per triangle
        
    Returns:
        np.ndarray of shape (M * samples_per_face, 3)
    """
    all_points = []
    
    for face in faces:
        v1 = vertices[face[0]]
        v2 = vertices[face[1]]
        v3 = vertices[face[2]]
        
        for _ in range(samples_per_face):
            # Generate two random numbers between 0 and 1
            a = np.random.rand()
            b = np.random.rand()
            
            # Ensure uniform distribution over the triangle
            if a + b > 1:
                a = 1 - a
                b = 1 - b
                
            c = 1 - a - b
            
            # Convex combination
            point = a * v1 + b * v2 + c * v3
            all_points.append(point)
            
    return np.array(all_points)
```

**Parameters:**
- `samples_per_face`: Number of points to generate per triangle. Not given in the sources.

**Edge Cases and Pitfalls:**
- Precision: Floating point errors in random number generation are negligible for typical mesh scales [G].
- Boundaries: The method assumes valid triangle geometry (non-degenerate faces) [G].

### Surface Sampling for NeRF Rendering with Spherical Coordinate Encoding
Creates a training dataset by sampling points on surfaces, computing their colors via ray tracing, and encoding view/light directions as spherical coordinates (theta, phi) [S1, unofficial].

**Steps:**
1. For each visible surface, sample 20 points [S1, unofficial].
2. For each point, compute the color using `ray_tracer.calculate_color_at_point` [S1, unofficial].
3. Compute camera difference vector $cam\_diff = camera\_position - point$ [S1, unofficial].
4. Calculate $\theta_{cam}$: $\theta_{cam} = \text{degrees}(\arctan2(cam\_diff[1], cam\_diff[0]))$ [S1, unofficial].
5. Calculate $\phi_{cam}$: $\phi_{cam} = \text{degrees}(\arctan2(cam\_diff[2], \sqrt{cam\_diff[0]^2 + cam\_diff[1]^2}))$ [S1, unofficial].
6. Compute light difference vector $light\_diff = light.position - point$ [S1, unofficial].
7. Calculate $\theta_{light}$: $\theta_{light} = \text{degrees}(\arctan2(light\_diff[1], light\_diff[0]))$ [S1, unofficial].
8. Calculate $\phi_{light}$: $\phi_{light} = \text{degrees}(\arctan2(light\_diff[2], \sqrt{light\_diff[0]^2 + light\_diff[1]^2}))$ [S1, unofficial].
9. Append the point, view directions $[\theta_{cam}, \phi_{cam}]$, light directions $[\theta_{light}, \phi_{light}]$, and color to their respective lists [S1, unofficial].

**Pseudocode:**
```python
import numpy as np

def encode_spherical_directions(point, camera_position, light_position):
    """
    Encode view and light directions as spherical coordinates (theta, phi).
    
    Args:
        point: np.ndarray of shape (3,)
        camera_position: np.ndarray of shape (3,)
        light_position: np.ndarray of shape (3,)
        
    Returns:
        tuple: (view_dirs, light_dirs) where each is np.ndarray of shape (2,)
    """
    # Camera direction
    cam_diff = camera_position - point
    theta_cam = np.degrees(np.arctan2(cam_diff[1], cam_diff[0]))
    phi_cam = np.degrees(np.arctan2(cam_diff[2], np.sqrt(cam_diff[0]**2 + cam_diff[1]**2)))
    view_dirs = np.array([theta_cam, phi_cam])
    
    # Light direction
    light_diff = light_position - point
    theta_light = np.degrees(np.arctan2(light_diff[1], light_diff[0]))
    phi_light = np.degrees(np.arctan2(light_diff[2], np.sqrt(light_diff[0]**2 + light_diff[1]**2)))
    light_dirs = np.array([theta_light, phi_light])
    
    return view_dirs, light_dirs
```
