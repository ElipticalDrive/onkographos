# Sizing Field Construction

Also called: Lipschitz sizing field

## Overview
The sizing field construction generates a scalar field $h(\mathbf{x})$ that controls particle distribution density to ensure $\varepsilon$-sampling and smooth triangle gradation for isosurface meshing [S1]. It differs from raw geometric sampling by enforcing a $\delta$-Lipschitz continuity constraint on the field, preventing abrupt changes in triangle size that would degrade mesh quality [S1]. This method builds on the medial axis detection provided by [Medial Axis Detection via Foot Point Method](10987-medial-axis-detection-via-foot-point-method.md) by utilizing the resulting local feature size to initialize the field [S1].

## How it works
**Inputs:**
*   Implicit surface function $F(\mathbf{x})$ and its Hessian matrix $\mathbf{H}_F$ [S1].
*   Local feature size field $\lambda(\mathbf{x})$ derived from the medial axis detection [S1].
*   Sampling parameter $\varepsilon$ [S1].
*   Gradient limit parameter $\delta$ [S1].
*   Time step $\Delta t$ for the iterative update [G].
*   Convergence threshold $\tau$ (default $10^{-5}$) [S1].

**Outputs:**
*   Discrete sizing field $h_{ijk}$ defined on a 3D grid lattice [S1].

**Data Structures:**
*   Grid: 3D array of floats `h[Nx][Ny][Nz]` [G].
*   Hessian: 3x3 symmetric matrix per grid node for curvature calculation [S1].
*   LFS Field: 3D array of floats `lambda[Nx][Ny][Nz]` [S1].

**Steps:**

1.  **Compute Maximum Curvature:** For each grid node $\mathbf{x}_{ijk}$ in the narrow band around the isosurface, compute the maximum curvature $\kappa_{max}(\mathbf{x})$ from the Hessian of $F$ [S1]. The radius of curvature is $r(\mathbf{x}) = 1/|\kappa_{max}(\mathbf{x})|$ [S1].
2.  **Initialize Field:** Compute the initial sizing field $h_0(\mathbf{x})$ using Equation (1):
    $$ h_0(\mathbf{x}) = C \min(\lambda(\mathbf{x}), 1/|\kappa_{max}(\mathbf{x})|) $$
    where $C = 2\varepsilon$ [S1].
3.  **Iterative Gradient Limiting:** Update the field iteratively to enforce the $\delta$-Lipschitz condition using Equation (2):
    $$ h_{ijk}^{n+1} = h_{ijk}^n + \Delta t \cdot \min(0, \delta - \Delta_{ijk}^+) $$
    where $\Delta_{ijk}^+$ is the discrete gradient magnitude defined in Equation (3) [S1].
4.  **Convergence Check:** Repeat Step 3 until the maximum relative change in $h$ across all nodes is less than $\tau$ [S1].

**Formulas:**

*   **Initial Field (Eq. 1):**
    $$ h_0(\mathbf{x}) = C \min(\lambda(\mathbf{x}), 1/|\kappa_{max}(\mathbf{x})|) $$
    *   $\lambda(\mathbf{x})$: Local feature size at $\mathbf{x}$ [S1].
    *   $\kappa_{max}(\mathbf{x})$: Maximum principal curvature at $\mathbf{x}$ [S1].
    *   $C$: Constant, typically $2\varepsilon$ [S1].

*   **Update Rule (Eq. 2):**
    $$ h_{ijk}^{n+1} = h_{ijk}^n + \Delta t \cdot \min(0, \delta - \Delta_{ijk}^+) $$
    *   $\Delta t$: Time step for the discrete operator [G].
    *   $\delta$: Maximum allowed gradient magnitude [S1].

*   **Gradient Magnitude (Eq. 3):**
    $$ \Delta_{ijk}^+ = \sqrt{ \max(D_x^+ h_{ijk}^n, 0)^2 + \min(D_x^- h_{ijk}^n, 0)^2 + \max(D_y^+ h_{ijk}^n, 0)^2 + \min(D_y^- h_{ijk}^n, 0)^2 + \max(D_z^+ h_{ijk}^n, 0)^2 + \min(D_z^- h_{ijk}^n, 0)^2 } $$
    *   $D_x^+, D_x^-$: Forward and backward difference operators in the x-direction [S1].
    *   $D_y^+, D_y^-$: Forward and backward difference operators in the y-direction [S1].
    *   $D_z^+, D_z^-$: Forward and backward difference operators in the z-direction [S1].

**Parameters:**
*   $\varepsilon$: Sampling parameter. Controls the fraction of local feature size. Literature suggests $\varepsilon = 0.5$ as a loose upper bound [S1].
*   $\delta$: Gradient limit. Controls the smoothness of triangle size transition. $\delta < \varepsilon$ generally produces well-shaped triangles [S1].
*   $\Delta t$: Time step. Not explicitly defined in sources, but required for the iterative solver [G].
*   $\tau$: Convergence threshold. Default $10^{-5}$ [S1].

**Edge Cases and Pitfalls:**
*   **Zero Curvature:** If $\kappa_{max}(\mathbf{x}) = 0$, the radius of curvature is infinite. The `min` function with $\lambda(\mathbf{x})$ handles this, but numerical stability should be ensured [G].
*   **Boundary Conditions:** The method operates on a narrow band around the isosurface. Nodes outside this band may not be updated or initialized [S1].
*   **Convergence:** The iterative process must converge. If $\Delta t$ is too large, the update may oscillate or diverge [G].

**Pseudocode:**

```python
import math

def compute_max_eigenvalue(H):
    """Compute the maximum eigenvalue of a 3x3 symmetric matrix using power iteration [G]."""
    v = [1.0, 0.0, 0.0]
    for _ in range(100):
        Hv = [
            H[0][0]*v[0] + H[0][1]*v[1] + H[0][2]*v[2],
            H[1][0]*v[0] + H[1][1]*v[1] + H[1][2]*v[2],
            H[2][0]*v[0] + H[2][1]*v[1] + H[2][2]*v[2]
        ]
        norm = math.sqrt(Hv[0]**2 + Hv[1]**2 + Hv[2]**2)
        if norm == 0: return 0.0
        v = [Hv[0]/norm, Hv[1]/norm, Hv[2]/norm]
    # Rayleigh quotient
    Hv = [
        H[0][0]*v[0] + H[0][1]*v[1] + H[0][2]*v[2],
        H[1][0]*v[0] + H[1][1]*v[1] + H[1][2]*v[2],
        H[2][0]*v[0] + H[2][1]*v[1] + H[2][2]*v[2]
    ]
    return Hv[0]*v[0] + Hv[1]*v[1] + Hv[2]*v[2]

def compute_sizing_field(lambda_field, hessian_field, epsilon, delta, dt, tolerance=1e-5):
    """
    Computes the (epsilon, delta)-sizing field.
    
    Args:
        lambda_field: 3D array of local feature sizes.
        hessian_field: 3D array of 3x3 Hessian matrices.
        epsilon: Sampling parameter.
        delta: Gradient limit parameter.
        dt: Time step for iterative update.
        tolerance: Convergence threshold.
        
    Returns:
        h: 3D array of the sizing field.
    """
    C = 2 * epsilon
    Nx, Ny, Nz = lambda_field.shape
    h = [[0.0]*Nz for _ in range(Ny)]
    for i in range(Nx):
        for j in range(Ny):
            for k in range(Nz):
                h[j][i][k] = 0.0
                
    # Step 1 & 2: Initialize field
    for i in range(Nx):
        for j in range(Ny):
            for k in range(Nz):
                H = hessian_field[i][j][k]
                kappa_max = compute_max_eigenvalue(H)
                
                if kappa_max < 1e-10:
                    radius_curv = 1e10
                else:
                    radius_curv = 1.0 / kappa_max
                
                h[j][i][k] = C * min(lambda_field[i][j][k], radius_curv)
    
    # Step 3 & 4: Iterative gradient limiting
    while True:
        max_rel_change = 0.0
        h_new = [[0.0]*Nz for _ in range(Ny)]
        for i in range(Nx):
            for j in range(Ny):
                for k in range(Nz):
                    # Forward differences
                    dx_plus = h[j][i+1][k] - h[j][i][k] if i < Nx-1 else 0.0
                    dy_plus = h[j+1][i][k] - h[j][i][k] if j < Ny-1 else 0.0
                    dz_plus = h[j][i][k+1] - h[j][i][k] if k < Nz-1 else 0.0
                    
                    # Backward differences
                    dx_minus = h[j][i][k] - h[j][i-1][k] if i > 0 else 0.0
                    dy_minus = h[j][i][k] - h[j-1][i][k] if j > 0 else 0.0
                    dz_minus = h[j][i][k] - h[j][i][k-1] if k > 0 else 0.0
                    
                    # Gradient magnitude delta_plus
                    term_x = max(dx_plus, 0.0)**2 + min(dx_minus, 0.0)**2
                    term_y = max(dy_plus, 0.0)**2 + min(dy_minus, 0.0)**2
                    term_z = max(dz_plus, 0.0)**2 + min(dz_minus, 0.0)**2
                    
                    delta_plus = math.sqrt(term_x + term_y + term_z)
                    
                    # Update rule
                    update = dt * min(0.0, delta - delta_plus)
                    h_new[j][i][k] = h[j][i][k] + update
                    
                    # Track max relative change
                    current_val = h[j][i][k]
                    if abs(current_val) > 1e-10:
                        rel_change = abs(update / current_val)
                    else:
                        rel_change = abs(update)
                    if rel_change > max_rel_change:
                        max_rel_change = rel_change
        
        # Update grid
        for i in range(Nx):
            for j in range(Ny):
                for k in range(Nz):
                    h[j][i][k] = h_new[j][i][k]
        
        if max_rel_change < tolerance:
            break
            
    return h
```

## Subtopics

### Local Feature Size (LFS) Estimation
Provides the $\lambda(\mathbf{x})$ field used in the initialization. It is derived from the medial axis and represents the distance to the nearest feature [G]. [LFS Estimation](link-to-lfs-article.md).

### Curvature Computation
The method for computing $\kappa_{max}$ from the Hessian of the implicit function [S1]. [Curvature Computation](link-to-curvature-article.md).

## Operating characteristics
*   **Time Complexity:** Not given in the sources.
*   **Memory Complexity:** Not given in the sources.
*   **Performance:** Smaller values of $\varepsilon$ produce more geometrically accurate meshes, while smaller values of $\delta$ generate more regular triangulations; smaller values of either parameter inherently increase the overall number of triangles [S1].
*   **Strengths:** Ensures $\varepsilon$-sampling and smooth triangle gradation. The $\delta$-Lipschitz property prevents poor-quality triangles [S1].
*   **Limitations:** Requires computation of the Hessian and local feature size [S1].
*   **When to Use:** Not given in the sources.
*   **When Not to Use:** Not given in the sources.

## Background
The sizing field construction was introduced in the context of dynamic particle systems for isosurface meshing [S1]. It builds upon the work of Persson on $\delta$-Lipschitz fields [S1]. The method is designed to adapt particle distribution to local geometric features, ensuring both accuracy and mesh quality [S1].
