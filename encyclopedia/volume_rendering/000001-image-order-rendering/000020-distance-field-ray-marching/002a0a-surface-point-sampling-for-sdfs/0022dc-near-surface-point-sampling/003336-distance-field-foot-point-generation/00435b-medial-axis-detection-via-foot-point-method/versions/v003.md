# Medial Axis Detection via Foot Point Method
Also called: Foot Point Method for Medial Axis
## Overview
This method detects the medial axis (MA) of a general implicit surface by analyzing characteristic lines (normals) and detecting changes in foot points, providing subgrid accuracy without thinning or post-processing [S1]. It differs from its parent [Distance Field Foot Point Generation](6946-distance-field-foot-point-generation.md) by identifying the locus of centers of maximal inscribed spheres (the medial axis) to compute the Local Feature Size (LFS) field [S1].
## How it works
**Inputs:**
- Implicit surface function $F(\mathbf{x}) = 0$ [S1].
- Grid of query points $\mathcal{Q}$ [S1].

**Outputs:**
- Set of medial axis points $\mathcal{M}$ [S1].
- Local Feature Size (LFS) field $\lambda(\mathbf{x})$ at grid nodes bounding the isosurface [S1].

**Data Structures:**
- **Medial Axis Set $\mathcal{M}$**: A list of 3D points $\mathbf{m} \in \mathbb{R}^3$ [S1].
- **LFS Field $\lambda$**: A scalar field defined on grid nodes $\mathbf{x}_g$ that bound the isosurface [S1].

**Parameters:**
- Threshold angle $\alpha$: Defined by $\cos(\alpha) = 0.9$ [S1].

**Steps:**

1. **Grid Processing**: Iterate over each grid point $\mathbf{q} \in \mathcal{Q}$ [S1].
2. **Find Foot Point $\mathbf{p}$**: Compute the nearest point $\mathbf{p}$ on the surface $F(\mathbf{x})=0$ to $\mathbf{q}$ using gradient descent [S1]. The segment $\overline{\mathbf{p}\mathbf{q}}$ is perpendicular to the surface and forms part of a characteristic line [S1].
3. **Find Far Point $\mathbf{q}^*$**: Extend the characteristic line from $\mathbf{p}$ through $\mathbf{q}$ (away from the surface) to find the point $\mathbf{q}^*$ that intersects the far face of the current voxel [S1].
4. **Find Far Foot Point $\mathbf{p}^*$**: Compute the foot point $\mathbf{p}^*$ on the surface corresponding to $\mathbf{q}^*$ using gradient descent [S1].
5. **Check MA Crossing**: Calculate the angle between the line segments $\overline{\mathbf{p}\mathbf{q}}$ and $\overline{\mathbf{p}^*\mathbf{q}^*}$ [S1].
   - If the angle between the line segments $\overline{\mathbf{p}\mathbf{q}}$ and $\overline{\mathbf{p}^*\mathbf{q}^*}$ is greater than $\alpha$ (i.e., $\cos(\theta) < 0.9$), the segment $\overline{\mathbf{p}\mathbf{p}^*}$ crosses the medial axis [S1].
6. **Estimate MA Position**: If a crossing is detected, estimate the position of the medial axis point $\mathbf{m}$ along the segment $\overline{\mathbf{p}\mathbf{p}^*}$ using a first-order (tangent plane) approximation to the surface at $\mathbf{p}^*$ [S1].
7. **Construct LFS Field**: After processing all grid points, construct the LFS field $\lambda(\mathbf{x})$ [S1]. For each grid node $\mathbf{x}_g$ bounding the isosurface, set $\lambda(\mathbf{x}_g)$ to the distance to the closest medial axis point $\mathbf{m} \in \mathcal{M}$ [S1].

**Pseudocode:**

```python
import math

def dot(a, b):
    return a[0]*b[0] + a[1]*b[1] + a[2]*b[2]

def sub(a, b):
    return (a[0]-b[0], a[1]-b[1], a[2]-b[2])

def add(a, b):
    return (a[0]+b[0], a[1]+b[1], a[2]+b[2])

def scale(a, s):
    return (a[0]*s, a[1]*s, a[2]*s)

def norm(a):
    return math.sqrt(dot(a, a))

def find_foot_point(q, F, grad_F, max_iter=100, tol=1e-6):
    p = q
    for _ in range(max_iter):
        f_val = F(p)
        if abs(f_val) < tol:
            break
        g = grad_F(p)
        g_norm = norm(g)
        if g_norm < 1e-10:
            break
        step = f_val / g_norm
        p = add(p, scale(g, -step))
    return p

def ray_box_intersection(origin, direction, voxel_min, voxel_max):
    t_min = (voxel_min[0] - origin[0]) / direction[0] if direction[0] != 0 else -float('inf')
    t_max = (voxel_max[0] - origin[0]) / direction[0] if direction[0] != 0 else float('inf')
    if t_min > t_max: t_min, t_max = t_max, t_min
    
    ty_min = (voxel_min[1] - origin[1]) / direction[1] if direction[1] != 0 else -float('inf')
    ty_max = (voxel_max[1] - origin[1]) / direction[1] if direction[1] != 0 else float('inf')
    if ty_min > ty_max: ty_min, ty_max = ty_max, ty_min
    
    if t_min > ty_max or ty_min > t_max: return None
    
    if ty_min > t_min: t_min = ty_min
    if ty_max < t_max: t_max = ty_max
    
    tz_min = (voxel_min[2] - origin[2]) / direction[2] if direction[2] != 0 else -float('inf')
    tz_max = (voxel_max[2] - origin[2]) / direction[2] if direction[2] != 0 else float('inf')
    if tz_min > tz_max: tz_min, tz_max = tz_max, tz_min
    
    if t_min > tz_max or tz_min > t_max: return None
    
    if tz_min > t_min: t_min = tz_min
    if tz_max < t_max: t_max = tz_max
    
    t_exit = max(t_min, t_max)
    return add(origin, scale(direction, t_exit))

def intersect_lines(p1, d1, p2, d2):
    # Returns point on line 1 closest to line 2
    d1d2 = dot(d1, d2)
    d1d1 = dot(d1, d1)
    d2d2 = dot(d2, d2)
    p1p2 = sub(p1, p2)
    d1p2 = dot(d1, p1p2)
    d2p2 = dot(d2, p1p2)
    denom = d1d1 * d2d2 - d1d2 * d1d2
    if abs(denom) < 1e-12:
        return p1
    t = (d1d2 * d2p2 - d2d2 * d1p2) / denom
    return add(p1, scale(d1, t))

def detect_medial_axis(grid_points, voxel_bounds, F, grad_F):
    medial_axis_points = []
    cos_alpha = 0.9
    
    for q in grid_points:
        p = find_foot_point(q, F, grad_F)
        
        vec_pq = sub(q, p)
        pq_norm = norm(vec_pq)
        if pq_norm < 1e-10:
            continue
        dir_char = scale(vec_pq, 1.0 / pq_norm)
        
        q_star = ray_box_intersection(p, dir_char, voxel_bounds[0], voxel_bounds[1])
        if q_star is None:
            continue
            
        p_star = find_foot_point(q_star, F, grad_F)
        
        vec_p_star_q_star = sub(q_star, p_star)
        p_star_q_star_norm = norm(vec_p_star_q_star)
        if p_star_q_star_norm < 1e-10:
            continue
        dir_p_star_q_star = scale(vec_p_star_q_star, 1.0 / p_star_q_star_norm)
        
        cos_theta = dot(dir_char, dir_p_star_q_star)
        
        if cos_theta < cos_alpha:
            n_star = grad_F(p_star)
            n_star_norm = norm(n_star)
            if n_star_norm < 1e-10:
                continue
            n_star = scale(n_star, 1.0 / n_star_norm)
            
            # MA is intersection of characteristic from p (line pp*) and characteristic from p* (normal at p*)
            m = intersect_lines(p, sub(p_star, p), p_star, n_star)
            medial_axis_points.append(m)
            
    return medial_axis_points

def compute_lfs_field(grid_nodes, medial_axis_points):
    lfs_field = {}
    for x in grid_nodes:
        min_dist = float('inf')
        for m in medial_axis_points:
            dist = norm(sub(x, m))
            if dist < min_dist:
                min_dist = dist
        lfs_field[x] = min_dist
    return lfs_field
```

**Edge Cases and Pitfalls:**
- **Gradient Descent Failure**: If the gradient is zero or the surface is not smooth, `find_foot_point` may fail or converge to a local minimum [G]. Ensure the implicit function is differentiable and use a robust solver with fallbacks [G].
- **Voxel Intersection**: Determining the "far face" of the voxel for $\mathbf{q}^*$ requires precise ray-box intersection logic [G]. Use a standard ray-box intersection algorithm (e.g., slab method) to find the exact exit point of the ray from the voxel containing $\mathbf{q}$ [G].
- **Degenerate Normals**: If the normal at $\mathbf{p}$ or $\mathbf{p}^*$ is near-zero, the tangent plane approximation is invalid [G]. Check for small norms before division.
- **Singular Points**: The method detects the MA proper, not the singular points where the MA terminates (e.g., vertices of a polyhedron) [S1].

## Subtopics

### [Sizing Field Construction](10996-sizing-field-construction.md)
The sizing field construction generates a scalar field $h(\mathbf{x})$ that controls particle distribution density to ensure $\varepsilon$-sampling and smooth triangle gradation for isosurface meshing. It differs from raw geometric sampling by enforcing a $\delta$-Lipschitz continuity constraint on the field, preventing abrupt changes in triangle size that would degrade mesh quality. This method builds on the medial axis detection provided by [Medial Axis Detection via Foot Point Method](10987-medial-axis-detection-via-foot-point-method.md) by utilizing the resulting local feature size to initialize the field.
