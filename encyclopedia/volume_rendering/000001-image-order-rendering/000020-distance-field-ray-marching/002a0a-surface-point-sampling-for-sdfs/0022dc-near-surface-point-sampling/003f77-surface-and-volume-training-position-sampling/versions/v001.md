# Surface and Volume Training Position Sampling

Also called: Efficient Sampling of 3D Training Positions

## Overview
A method to distribute training positions for neural implicit surface reconstruction by combining uniform volume samples, uniform surface samples, and perturbed surface samples to ensure coverage of the object and its immediate vicinity [S1]. It sets itself apart from siblings like [Distance Field Foot Point Generation](6946-distance-field-foot-point-generation.md) by explicitly mixing volumetric background data with surface-localized data, and from [Primary Edge Sampling](7168-primary-edge-sampling.md) by using area-weighted triangle selection rather than edge-centric heuristics.

## How it works
**Inputs:** A triangle mesh (for surface sampling), a bounding radius $r$ of the mesh, and a total count $N$ of training positions to generate.
**Outputs:** An array of $N$ 3D positions $\{x_i\}_{i=1}^N$.

**Data Structures:**
1.  **Triangle CDF Array:** A 1D array of size $T$ (number of triangles). The $i$-th element stores the cumulative sum of normalized triangle areas. Let $A_i$ be the area of triangle $i$. The CDF at index $i$ is $C_i = \frac{\sum_{j=0}^{i} A_j}{\sum_{k=0}^{T-1} A_k}$.
2.  **Random Number Generator:** A GPU-compatible PRNG, specifically PCG32 [S1].

**Parameters:**
*   Volume sample ratio: $1/8$ of $N$.
*   Surface sample ratio: $4/8$ of $N$.
*   Perturbed surface sample ratio: $3/8$ of $N$.
*   Logistic distribution standard deviation: $\sigma = r/1024$.

**Steps:**
1.  **Generate Uniform Volume Samples:** Generate $N/8$ positions uniformly distributed in the unit cube $[0,1]^3$ using the PCG32 PRNG [S1].
2.  **Preprocess Mesh for Surface Sampling:** Compute the area $A_i$ for each triangle $i$ in the mesh. Normalize these areas to form a probability distribution and compute the Cumulative Distribution Function (CDF) array $C$ [S1].
3.  **Generate Uniform Surface Samples:** For $4N/8$ samples:
    a. Draw a uniform random number $u \in [0,1]$ from the PRNG.
    b. Perform a binary search on the CDF array $C$ to find the triangle index $t$ such that $C_{t-1} < u \le C_t$ (with $C_{-1}=0$). This selects a triangle proportional to its area [S1].
    c. Sample a uniformly random position on triangle $t$ using standard sample warping [S1, Pharr et al. 2016].
4.  **Generate Perturbed Surface Samples:** For $3N/8$ samples:
    a. Repeat steps 3a-3c to select a base position $x_{base}$ on the mesh surface.
    b. Draw three independent random values $d_x, d_y, d_z$ from a logistic distribution with standard deviation $\sigma = r/1024$ [S1].
    c. Compute the perturbed position $x = x_{base} + (d_x, d_y, d_z)$ [S1].

**Pseudocode:**
```python
import numpy as np
from typing import List, Tuple

# Assume PCG32 is available as a standard GPU PRNG interface
# Assume triangle_mesh is a list of triangles, each with vertices v0, v1, v2
# Assume get_triangle_area(tri) returns the area
# Assume sample_triangle_uniform(tri) returns a point on the triangle

def generate_training_positions(triangle_mesh: List, bounding_radius: float, N: int) -> List[Tuple[float, float, float]]:
    # 1. Preprocess: Compute CDF of triangle areas
    areas = [get_triangle_area(tri) for tri in triangle_mesh]
    total_area = sum(areas)
    cdf = []
    current_sum = 0.0
    for area in areas:
        current_sum += area / total_area
        cdf.append(current_sum)
    
    n_volume = N // 8
    n_surface = 4 * (N // 8)
    n_perturbed = 3 * (N // 8)
    
    positions = []
    
    # 2. Uniform Volume Samples
    for _ in range(n_volume):
        # Generate uniform in unit cube [0,1]^3
        x = pcg32_uniform()
        y = pcg32_uniform()
        z = pcg32_uniform()
        positions.append((x, y, z))
        
    # Helper for binary search on CDF
    def select_triangle_index(u: float) -> int:
        # Binary search for first index i where cdf[i] >= u
        low = 0
        high = len(cdf) - 1
        while low < high:
            mid = (low + high) // 2
            if cdf[mid] < u:
                low = mid + 1
            else:
                high = mid
        return low

    # 3. Uniform Surface Samples
    for _ in range(n_surface):
        u = pcg32_uniform()
        tri_idx = select_triangle_index(u)
        tri = triangle_mesh[tri_idx]
        pos = sample_triangle_uniform(tri)
        positions.append(pos)
        
    # 4. Perturbed Surface Samples
    sigma = bounding_radius / 1024.0
    for _ in range(n_perturbed):
        u = pcg32_uniform()
        tri_idx = select_triangle_index(u)
        tri = triangle_mesh[tri_idx]
        base_pos = sample_triangle_uniform(tri)
        
        # Logistic distribution sampling
        # Note: Standard logistic sampling requires inverse CDF: x = ln(u/(1-u))
        # However, the source specifies "drawn independently from a logistic distribution"
        # We assume a standard logistic sampler is available or implemented via inverse CDF
        dx = sample_logistic(sigma)
        dy = sample_logistic(sigma)
        dz = sample_logistic(sigma)
        
        perturbed_pos = (base_pos[0] + dx, base_pos[1] + dy, base_pos[2] + dz)
        positions.append(perturbed_pos)
        
    return positions

def sample_logistic(sigma: float) -> float:
    """
    Samples from a logistic distribution with standard deviation sigma.
    The standard logistic distribution (mu=0, s=1) has variance pi^2/3.
    To get standard deviation sigma, we scale by s = sigma * sqrt(3) / pi.
    """
    import math
    s = sigma * math.sqrt(3) / math.pi
    u = pcg32_uniform()
    # Inverse CDF of standard logistic: ln(u / (1 - u))
    return s * math.log(u / (1 - u))
```

## Subtopics

### Octree Sampling for NGLOD
A specialized sampling routine for NeRF-based methods (NGLOD) that ensures training positions are generated within octree leaf nodes to avoid invalid queries, replacing the uniform unit cube sampling [S1]. It works by rejection sampling a uniformly random leaf node from the array of all octree nodes, then generating a uniform random position within the voxel of the selected leaf node [S1]. A key pitfall is that perturbed surface samples might fall outside the octree leaf nodes; this is handled by using the small perturbation standard deviation ($r/1024$), which is small enough to almost never leave the octree, so the surface sampling routine does not need modification [S1].

## Operating characteristics
**Time Complexity:** Surface sampling involves a binary search over the triangle CDF, which is $O(\log T)$ per sample, where $T$ is the number of triangles. Volume sampling is $O(1)$ per sample.
**Memory Complexity:** Requires storing the CDF array of size $T$ and the triangle mesh data.
**Strengths:** Ensures that training data covers both the object surface and the immediate surrounding volume, which is critical for neural implicit surface reconstruction to resolve the signed distance field correctly near the boundary [S1]. The use of a logistic distribution for perturbation is computationally cheaper than a Gaussian while providing a similar shape [S1].
**Limitations:** The method assumes the mesh is available for preprocessing. The fixed ratios (1/8, 4/8, 3/8) may not be optimal for all scene types.
**When to use:** When training neural implicit surfaces (like Instant Neural Graphics Primitives) where both surface proximity and volumetric context are needed for the SDF network [S1].

## Background
Originated in the "Instant Neural Graphics Primitives with a Multiresolution Hash Encoding" paper by Mueller et al. [S1]. The method addresses the need for efficient and effective sampling strategies for training neural networks that represent 3D geometry as implicit signed distance fields. It builds on standard techniques for uniform sampling on triangles [Pharr et al. 2016] and PRNGs [O'Neill 2014].
