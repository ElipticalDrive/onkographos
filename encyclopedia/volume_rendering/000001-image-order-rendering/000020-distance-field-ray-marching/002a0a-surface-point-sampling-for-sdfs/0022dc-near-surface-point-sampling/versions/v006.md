# Near-Surface Point Sampling

Also called: DeepSDF sampling, Non-Uniform Surface Sampling

## Overview
Near-Surface Point Sampling generates a non-uniform distribution of query points for training implicit surface representations, specifically Signed Distance Fields (SDFs) [S2, unofficial]. It samples points non-uniformly near the surface, where most points are close to the surface and some are sampled uniformly [S2, unofficial].

## How it works
**Inputs:**
- A watertight mesh $M$ with correct face normals [S2, unofficial].
- Number of points $N$ (default 500,000) [S2, unofficial].
- Standard deviation for noise $\sigma$ (default 0.01) [S1][S2, unofficial].
- Bounding radius $R$ (default 1.0, unit sphere) [S2, unofficial].

**Outputs:**
- A set of $N$ 3D points $P = \{p_1, \dots, p_N\}$ [G].
- Corresponding SDF values $D = \{d_1, \dots, d_N\}$ and signs $S = \{s_1, \dots, s_N\}$ [G].

**Data Structures:**
- Surface Point Cloud: A set of points on the mesh surface, stored in a kd-tree for nearest-neighbor queries [S2, unofficial].

**Steps:**
1. **Mesh Normalization:** Transform the mesh $M$ so that it fits inside a unit sphere centered at the origin [S2, unofficial].
2. **Surface Sampling:** Generate a set of points $P_{surf}$ uniformly distributed on the surface of $M$. The number of surface points is determined by the desired split ratio. According to the DeepSDF paper, a 2:2:1 split is used for surface, near, and uniform samples, meaning $N_{surf} = N_{near} = \frac{2}{5}N$ and $N_{uniform} = \frac{1}{5}N$ [S1].
3. **Near-Surface Perturbation:** For each point $p \in P_{surf}$, generate a perturbed point $p'$ by adding Gaussian noise:
   $$ p' = p + \epsilon, \quad \epsilon \sim \mathcal{N}(0, \sigma^2 I) $$
   where $\sigma = 0.01$ [S1][S2, unofficial]. These points form the set $P_{near}$.
4. **Uniform Volume Sampling:** Generate $N_{uniform}$ points uniformly distributed within the bounding volume $B$ [S1]. These points form the set $P_{uniform}$.
5. **SDF Calculation:** For all points in $P_{near} \cup P_{uniform}$, calculate the SDF value and sign:
   - **Value:** Find the closest point $q$ on the surface point cloud using a kd-tree. The distance is $d = \|p' - q\|$ [S2, unofficial].
   - **Sign:** Determine if the point is inside or outside the surface.
     - *Normal Method:* Compute the dot product of the vector $(p' - q)$ and the normal $n_q$ at $q$ [S2, unofficial].
     - *Depth Method:* Project the point into the camera frame of each scan. If the point's depth is greater than the depth buffer value for any camera, it is outside (positive sign) [S2, unofficial].
6. **Validation:** Check the fraction of points inside the shape (negative SDF). If this fraction is less than `min_size` (default 0), throw an exception [S2, unofficial].

**Pseudocode:**
```python
import numpy as np

def normalize_to_unit_sphere(vertices):
    scale = np.max(np.linalg.norm(vertices, axis=1))
    return vertices / scale

def sample_mesh_surface(vertices, faces, count):
    areas = np.linalg.norm(np.cross(
        vertices[faces[:, 1]] - vertices[faces[:, 0]],
        vertices[faces[:, 2]] - vertices[faces[:, 0]]
    ), axis=1) / 2.0
    probs = areas / np.sum(areas)
    face_indices = np.random.choice(len(faces), size=count, p=probs)
    u = np.random.random(count)
    v = np.random.random(count)
    sqrt_u = np.sqrt(u)
    b1 = 1.0 - sqrt_u
    b2 = sqrt_u * (1.0 - v)
    b3 = sqrt_u * v
    p0 = vertices[faces[face_indices, 0]]
    p1 = vertices[faces[face_indices, 1]]
    p2 = vertices[faces[face_indices, 2]]
    return p0 * b1[:, None] + p1 * b2[:, None] + p2 * b3[:, None]

def sample_uniform_in_sphere(R, count):
    points = np.random.uniform(-R, R, size=(count * 2, 3))
    valid = np.sum(points**2, axis=1) <= R**2
    while np.sum(valid) < count:
        extra = np.random.uniform(-R, R, size=((count - np.sum(valid)) * 2, 3))
        valid = np.concatenate([valid, np.sum(extra**2, axis=1) <= R**2])
        points = np.vstack([points, extra])
    return points[valid][:count]

def get_surface_point_cloud(vertices, faces, method='sample'):
    cloud_pts = sample_mesh_surface(vertices, faces, 1000000)
    normals = np.zeros_like(cloud_pts)
    for i in range(len(cloud_pts)):
        f = faces[np.random.randint(len(faces))]
        v0, v1, v2 = vertices[f]
        n = np.cross(v1 - v0, v2 - v0)
        norm = np.linalg.norm(n)
        normals[i] = n / norm if norm > 0 else np.array([0.0, 0.0, 0.0])
    return cloud_pts, normals

def near_surface_point_sampling(vertices, faces, N=500000, sigma=0.01, R=1.0, min_size=0.0):
    vertices = normalize_to_unit_sphere(vertices)
    N_surf = int(2/5 * N)
    N_near = int(2/5 * N)
    N_uniform = N - N_surf - N_near
    
    P_surf = sample_mesh_surface(vertices, faces, N_surf)
    noise = np.random.normal(0, sigma, (N_near, 3))
    P_near = P_surf[:N_near] + noise
    P_uniform = sample_uniform_in_sphere(R, N_uniform)
    P_all = np.vstack([P_near, P_uniform])
    
    cloud_pts, normals = get_surface_point_cloud(vertices, faces, method='sample')
    dists = np.linalg.norm(P_all[:, None, :] - cloud_pts[None, :, :], axis=2)
    idx = np.argmin(dists, axis=1)
    D = np.min(dists, axis=1)
    
    q = cloud_pts[idx]
    n = normals[idx]
    vec = P_all - q
    S = np.sign(np.dot(vec, n))
    
    fraction_inside = np.sum(S == -1.0) / N
    if fraction_inside < min_size:
        raise Exception(f"Too few points inside shape: {fraction_inside} < {min_size}")
        
    return P_all, D, S
```

**Edge Cases and Pitfalls:**
- **Non-watertight meshes:** The sampling method requires watertight meshes with correct face normals [S2, unofficial].
- **Sign determination:** The normal method can produce "bubble" artifacts in concave regions or near holes. The depth method avoids these artifacts but is less accurate [S2, unofficial].

## Subtopics

### [Distance Field Foot Point Generation](6946-distance-field-foot-point-generation.md)
Generates surface points (foot points) from a clamped signed distance field volume by projecting grid voxels onto the isosurface along the gradient direction. It differs by relying on the unit-length gradient property for single-step projection without iterative refinement. Choose it when working with discrete grid volumes rather than explicit meshes.

### [Primary Edge Sampling](7168-primary-edge-sampling.md)
Generates sample points on the primary boundary curve of an implicit surface, defined as the intersection of the surface function and the orientation function. It differs by explicitly targeting visibility discontinuities (silhouettes) where the surface normal is perpendicular to the view vector. Choose it for differentiable rendering of silhouette edges.

### [Surface and Volume Training Position Sampling](9996-surface-and-volume-training-position-sampling.md)
Distributes training positions for neural implicit surface reconstruction by combining uniform volume samples, uniform surface samples, and perturbed surface samples. It differs by using explicit mixing strategies and area-weighted triangle selection to ensure coverage of the object and its immediate vicinity. Choose it when balanced surface and volume coverage is required for training.

### [Spot Noise (Motion Blurred Particles near Contour Surfaces)](13068-spot-noise-motion-blurred-particles-near-contour-surfaces.md)
Visualizes 3D velocity fields in a thickened region around a contour surface by rendering motion-blurred ellipsoidal particles. It differs by operating on contour surfaces of scalar functions generally unrelated to the velocity vectors, without requiring surface parameterization. Choose it for interactive visualization of volumetric flows near implicit boundaries.

### [Surface Sampling for NeRF Rendering](14054-surface-sampling-for-nerf-rendering.md)
Generates random points on the surface of a 3D object (specifically on triangles) for neural network reflectance models. It differs by focusing on uniform spatial distribution over mesh geometry for training data generation. Choose it for NeRF training pipelines requiring explicit surface point clouds.

### [Exponential Weighting for Surface Sampling](18167-exponential-weighting-for-surface-sampling.md)
A training strategy that minimizes an $L_1$ loss integrated over $\mathbb{R}^3$ using importance sampling. It differs by concentrating samples near the zero-level set of the SDF to avoid empty space, and by avoiding bias toward dense vertex regions. Choose it when uniform box sampling proves inefficient for implicit surface training.

### Loose µ-Sample
A set of points $E$ is a loose $\mu$-sample of a surface $S$ if: 1) For all $x \in S \cap V(E)$, the ball $B(x, \mu \times \text{lfs}(x))$ contains a point from $E$ (radius of all surface Delaunay balls is less than $\mu$). 2) The Delaunay triangulation of $E$ restricted to $S$ has vertices on all connected components of $S$ [S3, unofficial]. It differs by providing a formal geometric sampling criterion for mesh generation refinement. Choose it when constructing isotopic surface meshes via Delaunay refinement. Parameter: $\mu$ (scaling factor for local feature size) [S3, unofficial].

## Operating characteristics
- **Time Complexity:** Not given in the sources.
- **Memory Complexity:** Not given in the sources.
- **Performance:** Training is performed on NVIDIA Tesla V100 GPUs using PyTorch with a batch size of 512 [S1].
- **Strengths:** Provides high-density samples near the surface, which improves the accuracy of the learned SDF [S1].
- **Limitations:** Requires a watertight mesh and correct normals for the sampling method [S2, unofficial]. The normal sign method can produce "bubble" artifacts in concave regions or near holes [S2, unofficial].

## Background
The method was proposed in the DeepSDF paper [S2, unofficial]. It is used in neural implicit surface reconstruction to provide training data that emphasizes the surface boundary. The implementation is available in the `mesh_to_sdf` repository [S2, unofficial].
