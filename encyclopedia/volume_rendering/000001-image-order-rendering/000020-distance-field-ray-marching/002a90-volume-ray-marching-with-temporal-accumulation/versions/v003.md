# Volume Ray Marching with Temporal Accumulation

Also called: HZL Fluid Effects Volume Rendering [S1, unofficial]

## Overview
Volume Ray Marching with Temporal Accumulation is a direct volume rendering technique that marches rays through a 3D density field to accumulate color and opacity, enhanced by blending the current frame's result with a history texture to reduce noise and stabilize the image over time [S1, unofficial]. It distinguishes itself from standard fixed-step ray marching by incorporating temporal feedback, allowing for lower sampling rates or higher visual fidelity in dynamic scenes by leveraging temporal coherence [S1, unofficial].

## How it works
### Inputs and Outputs
**Inputs:**
- `densityTexture`: 3D texture storing density values [S1, unofficial].
- `temperatureTexture`, `fireTexture`: Optional textures for specific field modes [S1, unofficial].
- `sceneDepthTexture`: 2D depth texture of opaque geometry to clip volume rays [S1, unofficial].
- `historyTexture`: 2D texture storing the accumulated result from the previous frame [S1, unofficial].
- `inverseViewProjection`: Inverse of the combined view and projection matrices [S1, unofficial].
- `cameraPosition`: World-space position of the camera [S1, unofficial].
- Uniforms: `stepSize`, `maximumSteps`, `densityScale`, `absorption`, `lightDirection`, `lightIntensity`, `emissionStrength`, `fieldMode`, `temporalEnabled`, `historyWeight`, `frameIndex`, `jitterEnabled`, `selfShadowingEnabled` [S1, unofficial].

**Outputs:**
- `m_colorTexture`: Final rendered image (GL_RGBA8) [S1, unofficial].
- `m_depthTexture`: Depth buffer for the current frame (GL_DEPTH_COMPONENT24) [S1, unofficial].

### Data Structures
The implementation uses OpenGL textures with specific formats and filtering:
- `m_colorTexture`: `GL_RGBA8`, filtering `GL_LINEAR`, wrap `GL_CLAMP_TO_EDGE` [S1, unofficial].
- `m_depthTexture`: `GL_DEPTH_COMPONENT24`, filtering `GL_NEAREST`, wrap `GL_CLAMP_TO_EDGE` [S1, unofficial].
- `m_sceneDepthTexture`: `GL_DEPTH_COMPONENT24`, filtering `GL_NEAREST`, wrap `GL_CLAMP_TO_EDGE` [S1, unofficial].
- `m_historyTexture`: `GL_RGBA8`, filtering `GL_LINEAR`, wrap `GL_CLAMP_TO_EDGE` [S1, unofficial].
- `densityTexture`: Sampled at `position * 0.5 + 0.5` to map world space $[-1, 1]$ to texture space $[0, 1]$ [S1, unofficial].

### Algorithm Steps

1.  **Initialization**: Allocate and clear `m_colorTexture`, `m_depthTexture`, `m_sceneDepthTexture`, and `m_historyTexture` (set history to zero initially) [S1, unofficial].
2.  **Ray Setup**: Convert screen texture coordinate `textureCoordinate` to clip space: $\text{clipPosition} = \text{textureCoordinate} \times 2.0 - 1.0$ [S1, unofficial]. Unproject the far plane point to world space: $\text{farWorld} = \text{inverseViewProjection} \times \text{clipPosition}$, then $\text{farWorld} = \text{farWorld} / \text{farWorld}.w$ [S1, unofficial]. Calculate ray direction: $\text{rayDirection} = \text{normalize}(\text{farWorld} - \text{cameraPosition})$ [S1, unofficial].
3.  **Box Intersection**: Intersect ray with unit cube $[-1, 1]^3$ using `intersectBox`: $\text{inverseDirection} = 1.0 / \text{rayDirection}$, $\text{first} = (-1.0 - \text{cameraPosition}) \times \text{inverseDirection}$, $\text{second} = (1.0 - \text{cameraPosition}) \times \text{inverseDirection}$, $\text{minimum} = \min(\text{first}, \text{second})$, $\text{maximum} = \max(\text{first}, \text{second})$, $\text{intersection} = \text{vec2}(\max(\text{minimum}.xyz), \min(\text{maximum}.xyz))$ [S1, unofficial]. Initialize `distanceAlongRay = max(intersection.x, 0.0)` [S1, unofficial].
4.  **Scene Clipping**: Sample `sceneDepthTexture` at `textureCoordinate` to get `sceneDepth` [S1, unofficial]. If `sceneDepth < 1.0`, unproject scene point to world space, calculate `sceneDistance` along `rayDirection`, and update `intersection.y = min(intersection.y, sceneDistance)` [S1, unofficial].
5.  **Discard Check**: If `intersection.y <= distanceAlongRay`, discard the fragment (ray does not hit volume) [S1, unofficial].
6.  **Jitter**: If `jitterEnabled`, add random offset: $\text{distanceAlongRay} += \text{random}(gl\_FragCoord.xy, \text{frameIndex}) \times \text{stepSize}$ [S1, unofficial].
7.  **Accumulation Initialization**: Set `accumulated = vec4(0.0)` [S1, unofficial].
8.  **Ray Marching Loop**: Loop `index` from 0 to 767 [S1, unofficial]. Break if `index >= maximumSteps` or `distanceAlongRay >= intersection.y` [S1, unofficial]. Calculate position: $\text{position} = \text{cameraPosition} + \text{rayDirection} \times \text{distanceAlongRay}$ [S1, unofficial]. Sample density: $\text{fieldValue} = \text{texture}(densityTexture, \text{position} \times 0.5 + 0.5).r$, $\text{density} = \text{fieldValue}$ [S1, unofficial]. Detect volume entry: If `!foundVolume` and `density > 0.01`, set `representativePosition = position` and `foundVolume = true` [S1, unofficial]. Compute Color based on `fieldMode`: Mode 0 samples `temperatureTexture` and `fireTexture`, computes `lightTransmittance`, ambient (`vec3(0.12, 0.15, 0.20)`), direct light (`vec3(1.0, 0.88, 0.72) * lightIntensity * lightTransmittance`), mixes smoke color based on `position.y`, computes `flameColor` from temperature, and `emittedLight = flameColor * fire * emissionStrength` [S1, unofficial]. Mode 1: `smokeColor = mix(vec3(0.3, 0.04, 0.01), vec3(1.0, 0.65, 0.08), fieldValue)` [S1, unofficial]. Mode 2/3: `density = abs(fieldValue - 0.5) * 2.0`, `smokeColor = vec3(1.0, 0.0, 0.0)` if `fieldValue >= 0.5` else `vec3(0.0, 0.0, 1.0)` [S1, unofficial]. Accumulate: $\alpha = 1.0 - \exp(-\text{density} \times \text{stepSize})$, $\text{color} = \text{smokeColor} \times \alpha$, $\text{accumulated}.rgb += \text{color} \times (1.0 - \text{accumulated}.a)$, $\text{accumulated}.a += \alpha \times (1.0 - \text{accumulated}.a)$ [S1, unofficial]. Advance `distanceAlongRay += stepSize` [S1, unofficial].
9.  **Light Transmittance Calculation** (if `selfShadowingEnabled`): March 20 steps in direction `-normalize(lightDirection + vec3(0.0001))` with step size 0.08 [S1, unofficial]. Accumulate `opticalDepth = texture(densityTexture, position * 0.5 + 0.5).r * shadowStep` [S1, unofficial]. Break if `abs(position) > 1.0` [S1, unofficial]. Return $\text{transmittance} = \exp(-\text{opticalDepth} \times \text{absorption} \times \text{densityScale} \times 3.0)$ [S1, unofficial].
10. **Temporal Accumulation**: If `temporalEnabled`, blend current `accumulated` with `historyTexture` using `historyWeight` [S1, unofficial]. Else, `finalColor = accumulated` [S1, unofficial].
11. **Output**: Write `finalColor` to `m_colorTexture` and depth to `m_depthTexture` [S1, unofficial].

### Pseudocode

```python
def volume_ray_marching_with_temporal_accumulation(
    texture_coordinate,
    inverse_view_projection,
    camera_position,
    scene_depth_texture,
    density_texture,
    temperature_texture,
    fire_texture,
    history_texture,
    uniforms
):
    # Unpack uniforms
    step_size = uniforms.step_size
    maximum_steps = uniforms.maximum_steps
    density_scale = uniforms.density_scale
    absorption = uniforms.absorption
    light_direction = uniforms.light_direction
    light_intensity = uniforms.light_intensity
    emission_strength = uniforms.emission_strength
    field_mode = uniforms.field_mode
    temporal_enabled = uniforms.temporal_enabled
    history_weight = uniforms.history_weight
    frame_index = uniforms.frame_index
    jitter_enabled = uniforms.jitter_enabled
    self_shadowing_enabled = uniforms.self_shadowing_enabled

    # 1. Ray Setup
    clip_position = texture_coordinate * 2.0 - 1.0
    far_point_w = inverse_view_projection * vec4(clip_position.x, clip_position.y, 1.0, 1.0)
    far_world = vec3(far_point_w.x, far_point_w.y, far_point_w.z) / far_point_w.w
    ray_direction = normalize(far_world - camera_position)
    
    # Guard against zero division
    if any(ray_direction == 0.0):
        return vec4(0.0)

    inverse_direction = 1.0 / ray_direction
    
    # 2. Box Intersection
    first = (-1.0 - camera_position) * inverse_direction
    second = (1.0 - camera_position) * inverse_direction
    minimum = min(first, second)
    maximum = max(first, second)
    intersection = vec2(max(minimum.x, minimum.y, minimum.z), min(maximum.x, maximum.y, maximum.z))
    
    distance_along_ray = max(intersection.x, 0.0)
    
    # 3. Scene Clipping
    scene_depth = scene_depth_texture.sample(texture_coordinate).r
    if scene_depth < 1.0:
        scene_clip = vec4(texture_coordinate * 2.0 - 1.0, scene_depth, 1.0)
        scene_world_w = inverse_view_projection * scene_clip
        scene_world = vec3(scene_world_w.x, scene_world_w.y, scene_world_w.z) / scene_world_w.w
        scene_distance = dot(scene_world - camera_position, ray_direction)
        intersection.y = min(intersection.y, scene_distance)
        
    # 4. Discard Check
    if intersection.y <= distance_along_ray:
        return vec4(0.0)
        
    # 5. Jitter
    if jitter_enabled:
        jitter = random_gl_frag_coord(gl_FragCoord.xy, frame_index)
        distance_along_ray += jitter * step_size
        
    # 6. Initialize Accumulation
    accumulated = vec4(0.0)
    found_volume = False
    
    # 7. Ray Marching Loop
    for index in range(768): # Max steps limit
        if index >= maximum_steps or distance_along_ray >= intersection.y:
            break
            
        position = camera_position + ray_direction * distance_along_ray
        texture_coord = position * 0.5 + 0.5
        
        # Clamp texture coordinates to avoid edge artifacts
        texture_coord = clamp(texture_coord, 0.0, 1.0)
        
        field_value = density_texture.sample(texture_coord).r
        density = field_value
        
        # Detect volume entry
        if not found_volume and density > 0.01:
            representative_position = position
            found_volume = True
            
        # Compute Color
        smoke_color = vec3(0.0)
        emitted_light = vec3(0.0)
        
        if field_mode == 0:
            temp = temperature_texture.sample(texture_coord).r
            fire_val = fire_texture.sample(texture_coord).r
            
            # Light Transmittance
            if self_shadowing_enabled:
                transmittance = compute_light_transmittance(position, light_direction, density_texture, absorption, density_scale)
            else:
                transmittance = 1.0
                
            ambient = vec3(0.12, 0.15, 0.20)
            direct = vec3(1.0, 0.88, 0.72) * light_intensity * transmittance
            light = ambient + direct
            
            # Mix smoke color based on position.y (exact formula not provided in sources)
            smoke_color = mix(vec3(0.1), vec3(0.5), position.y)
            
            flame_color = temp
            emitted_light = flame_color * fire_val * emission_strength
            
        elif field_mode == 1:
            smoke_color = mix(vec3(0.3, 0.04, 0.01), vec3(1.0, 0.65, 0.08), field_value)
            
        elif field_mode in [2, 3]:
            density = abs(field_value - 0.5) * 2.0
            smoke_color = vec3(1.0, 0.0, 0.0) if field_value >= 0.5 else vec3(0.0, 0.0, 1.0)
            
        # Accumulate
        alpha = 1.0 - exp(-density * step_size)
        color = smoke_color * alpha
        accumulated.rgb += color * (1.0 - accumulated.a)
        accumulated.a += alpha * (1.0 - accumulated.a)
        
        distance_along_ray += step_size
        
    # 8. Temporal Accumulation
    if temporal_enabled:
        history_color = history_texture.sample(texture_coordinate).rgb
        final_color = mix(accumulated.rgb, history_color, history_weight)
    else:
        final_color = accumulated.rgb
        
    return vec4(final_color, accumulated.a)

def compute_light_transmittance(position, light_direction, density_texture, absorption, density_scale):
    shadow_dir = -normalize(light_direction + vec3(0.0001))
    shadow_step = 0.08
    optical_depth = 0.0
    
    for _ in range(20):
        position += shadow_dir * shadow_step
        optical_depth += density_texture.sample(position * 0.5 + 0.5).r * shadow_step
        if abs(position) > 1.0:
            break
            
    return exp(-optical_depth * absorption * density_scale * 3.0)

def random_gl_frag_coord(coord, frame_index):
    value = fract(vec3(coord.xyx) * 0.1031)
    value += dot(value, value.yzx + 33.33 + float(frame_index) * 0.01)
    return fract((value.x + value.y) * value.z)
```

### Edge Cases and Pitfalls
- **Division by Zero**: `intersectBox` uses `1.0 / rayDirection` [S1, unofficial]. If `rayDirection` is zero, this results in infinity/NaN [S1, unofficial]. The code relies on the caller to provide valid normalized directions [S1, unofficial].
- **Light Direction Normalization**: A small epsilon (0.0001) is added to `lightDirection` before normalization to prevent issues if the light direction is exactly zero [S1, unofficial].
- **Density Texture Coordinate Mapping**: The density texture is sampled at `position * 0.5 + 0.5` [S1, unofficial]. If `position` is outside $[-1, 1]$, texture coordinates go out of bounds [S1, unofficial]. Wrap mode `GL_CLAMP_TO_EDGE` handles this, but values may be incorrect at boundaries [S1, unofficial].

## Operating characteristics
- **Time Complexity**: $O(N \cdot M)$, where $N$ is the number of pixels and $M$ is the number of ray steps (up to 768 or `maximumSteps`) [S1, unofficial]. Temporal accumulation reduces the need for high $M$ by reusing previous frames [S1, unofficial].
- **Memory Complexity**: $O(N \cdot M_{texture})$ for textures [S1, unofficial]. Requires storing `densityTexture`, `historyTexture`, `sceneDepthTexture`, and `colorTexture` [S1, unofficial].
- **Measured Performance**: Not given in the sources.
- **Scaling**: Performance scales linearly with resolution and step count [S1, unofficial]. Temporal accumulation allows for lower step counts or higher quality at the cost of temporal latency [S1, unofficial].
- **Strengths**: Reduces noise and flickering in dynamic scenes [S1, unofficial]. Stabilizes the image over time [S1, unofficial]. Supports various field modes for different visual effects [S1, unofficial].
- **Limitations**: Temporal accumulation introduces ghosting if motion is not correctly handled [S1, unofficial]. Shadow ray marching is expensive if enabled [S1, unofficial]. Fixed step size may lead to aliasing or slow convergence in sparse volumes [S1, unofficial].
- **When to Use**: Dynamic volumetric scenes where noise reduction is critical and temporal coherence can be exploited [S1, unofficial].
- **When Not to Use**: Static scenes where single-frame quality is paramount without temporal constraints [S1, unofficial]. Scenes with rapid, non-coherent motion where ghosting is unacceptable [S1, unofficial].
