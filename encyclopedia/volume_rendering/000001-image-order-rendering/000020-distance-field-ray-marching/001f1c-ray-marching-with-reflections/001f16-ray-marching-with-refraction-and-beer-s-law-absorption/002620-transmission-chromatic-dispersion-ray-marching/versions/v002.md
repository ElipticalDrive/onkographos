# Transmission & Chromatic Dispersion Ray Marching
Also called: Chromatic Dispersion Ray Marching

## Overview
This method extends [Ray Marching with Refraction and Beer's Law Absorption](1947-ray-marching-with-refraction-and-beer-s-law-absorption.md) by simulating chromatic dispersion, where the index of refraction varies by wavelength [S1, unofficial]. It handles light transmission through transparent surfaces using refraction, optionally splitting rays into Red, Green, and Blue channels based on an IOR spread [S1, unofficial].

## How it works
**Inputs:** Ray origin $O$, direction $D$, surface normal $N$, view direction $V$, transmission $T$, index of refraction $n$, dispersion factor $d$, hit position `hitPos`, epsilon `hitEpsAtHit`, scene parameters `throughHitPos`, `throughHitRes`, `transmissionSamples`, ambient light `ambientLight`, base transmission `throughBase`, and emission `throughEmission` [S1, unofficial].
**Outputs:** Transmitted color $C_{trans} = [R, G, B]$ [S1, unofficial].
**Data Structures:** Material struct fields relevant to this step: `transmission` (float), `ior` (float), `dispersion` (float) [S1, unofficial].

**Steps:**
1. If $T > 0.001$, compute incident vector $I = -V$ [S1, unofficial].
2. If $d \le 10^{-4}$, compute $\eta = 1.0/\max(n, 1.0001)$, compute refracted direction $D_{refr} = \text{refract}(I, N, \eta)$, and if $\|D_{refr}\|^2 < 10^{-6}$, replace $D_{refr}$ with the reflected fallback direction [S1, unofficial].
3. March the refracted ray: `marchSceneTransmission(hitPos + D_{refr} * (hitEpsAtHit * 6.0), D_{refr}, throughHitPos, throughHitRes, transmissionSamples)` [S1, unofficial].
4. If a hit occurs, compute transmitted color: $C_{trans} = \text{ambientLight} \times \text{throughBase} + \text{throughEmission}$ [S1, unofficial].
5. If $d > 10^{-4}$, compute channel IORs ($n_R, n_G, n_B$), refract $I$ and $N$ for each channel, and apply the same TIR fallback if $\|D_{refr,c}\|^2 < 10^{-6}$ [S1, unofficial].
6. March each refracted ray independently [S1, unofficial].
7. Combine the transmitted R, G, B channels [S1, unofficial].

**Pseudocode:**
```python
def refract(I, N, eta):
    cos_theta = dot(-I, N)
    r = eta * eta * (1.0 - cos_theta * cos_theta)
    if r > 1.0:
        return vec3(0.0)
    return eta * I + (eta * cos_theta - sqrt(1.0 - r)) * N

def march_chromatic_dispersion(hit_pos, normal, view_dir, transmission, ior, dispersion, hitEpsAtHit, throughHitPos, throughHitRes, transmissionSamples, ambientLight, throughBase, throughEmission):
    # 1. Check transmission
    if transmission <= 0.001:
        return vec3(0.0) # Not given in the sources.

    I = -view_dir
    refracted_dirs = []

    # 2 & 5. Dispersion handling
    if dispersion <= 1e-4:
        eta = 1.0 / max(ior, 1.0001)
        refracted = refract(I, normal, eta)
        if dot(refracted, refracted) < 1e-6:
            refracted = reflect(I, normal) # reflectedFallback [G]
        refracted_dirs.append(refracted)
    else:
        ior_spread = dispersion * 0.35
        ior_vals = [ior + ior_spread, ior, ior - ior_spread] # iorR, iorG, iorB
        for ior_val in ior_vals:
            eta = 1.0 / max(ior_val, 1.0001)
            refracted = refract(I, normal, eta)
            if dot(refracted, refracted) < 1e-6:
                refracted = reflect(I, normal) # reflectedFallback [G]
            refracted_dirs.append(refracted)

    # 3 & 6. March each refracted ray independently
    transmitted_colors = []
    for refr_dir in refracted_dirs:
        start_pos = hit_pos + refr_dir * (hitEpsAtHit * 6.0)
        # marchSceneTransmission(start_pos, refr_dir, throughHitPos, throughHitRes, transmissionSamples)
        # [G] Ray marching implementation details are not provided in the sources.
        hit = True # Assumed for the accumulation step per evidence
        if hit:
            # 4. Accumulate
            transmitted = ambientLight * throughBase + throughEmission
            transmitted_colors.append(transmitted)

    # 7. Combine
    return vec3(transmitted_colors[0], transmitted_colors[1], transmitted_colors[2])
```

**Parameters:**
- `dispersion`: Chromatic dispersion factor, typically in $[0, 1]$ [S1, unofficial].
- `ior`: Index of refraction, clamped to $\ge 1.0$ [S1, unofficial].

**Edge Cases:**
- **Total Internal Reflection (TIR):** Detected by checking if the squared length of the refracted direction is less than $10^{-6}$ [S1, unofficial]. If true, the refracted ray is replaced with the reflected fallback direction to prevent NaN or invalid directions [S1, unofficial].
