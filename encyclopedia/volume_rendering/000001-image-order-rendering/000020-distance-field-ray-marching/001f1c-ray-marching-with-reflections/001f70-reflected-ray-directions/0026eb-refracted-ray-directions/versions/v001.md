# Refracted Ray Directions

Also called: refract

## Overview
Calculates the direction of a ray after it passes through an interface between two media with different refractive indices, handling both entry and exit scenarios for spherical objects. It differs from [Reflected Ray Directions](2028-reflected-ray-directions.md) by computing transmission rather than reflection, and serves as the geometric foundation for [Fresnel Reflection/Refraction](9067-fresnel-reflection-refraction.md) which determines the energy split between the two.

## How it works
**Inputs:**
- `ob`: The intersected object (must support `getType()`, `getRefractive()`, and `surfaceNormal()`).
- `point`: The 3D intersection point.
- `ray`: The incident ray direction (normalized).
- `from`: The ray origin (used to determine surface orientation relative to the ray).
- `ref`: The current medium's refractive index (passed by reference, updated on exit).

**Outputs:**
- `Vector3`: The normalized refracted ray direction.
- `ref`: Updated to the object's refractive index.

**Data Structures:**
- `Vector3`: A 3D vector with components `x`, `y`, `z` and methods `dot()`, `normalize()`, and scalar multiplication.
- `float`: Standard 32-bit floating point.

**Steps:**
1. Calculate the surface normal $N$ at `point` using `surfaceNormal(ob, point, from)`.
2. Set $n_1$ to the current refractive index `ref`.
3. Set $n_2$ to the object's refractive index via `ob->getRefractive()`.
4. Calculate the dot product $s = \text{dot}(\text{ray}, N)$.
5. If the object is a sphere and $s > 0$ (indicating the ray is exiting the sphere), swap $n_1$ and $n_2$. [S1, unofficial]
6. Calculate the ratio $n = n_1 / n_2$.
7. Calculate the refracted direction using the vector form of Snell's Law:
   $$ \text{refracted} = n \cdot (\text{ray} - s \cdot N) - N \cdot \sqrt{1 - n^2 \cdot (1 - s^2)} $$
8. Normalize the result.
9. Update `ref` to $n_2$.

**Pseudocode:**
```python
def refract(ob, point, ray, from, ref):
    # Get surface normal
    N = surface_normal(ob, point, from)
    
    # Refractive indices
    n1 = ref
    n2 = ob.get_refractive()
    
    # Dot product of ray and normal
    s = dot(ray, N)
    
    # Handle exit from sphere: swap indices if exiting
    if ob.get_type() == "sphere" and s > 0:
        n1, n2 = n2, n1
    
    # Ratio of indices
    n = n1 / n2
    
    # Snell's Law vector calculation
    # term1 = n * (ray - s * N)
    term1 = scale_vector(subtract_vectors(ray, scale_vector(N, s)), n)
    
    # term2 = N * sqrt(1 - n^2 * (1 - s^2))
    # Note: 1 - s^2 is equivalent to 1 - dot(ray, N)^2
    # This represents the squared magnitude of the tangential component
    discriminant = 1.0 - n * n * (1.0 - s * s)
    
    # Guard against numerical errors causing negative discriminant (total internal reflection)
    if discriminant < 0:
        discriminant = 0.0
        
    term2 = scale_vector(N, sqrt(discriminant))
    
    refracted = subtract_vectors(term1, term2)
    
    # Normalize result
    refracted = normalize(refracted)
    
    # Update current refractive index
    ref = n2
    
    return refracted
```

**Parameters:**
- `ref`: Initial refractive index of the medium the ray is traveling in. Typical value: 1.0 (air).
- `ob->getRefractive()`: Refractive index of the object. Typical value: 1.5 (glass).

**Edge Cases:**
- **Total Internal Reflection:** If $n_1 > n_2$ and the angle of incidence is large, the term under the square root becomes negative. The pseudocode clamps this to 0.0, which may result in a non-physical direction or require a fallback to reflection logic. [G]
- **Sphere Exit Detection:** The check `s > 0` specifically identifies exiting a sphere. For other shapes, this logic may not apply or may require different handling. [S1, unofficial]

## Subtopics

### [Fresnel Reflection/Refraction](9067-fresnel-reflection-refraction.md)
Calculates the Fresnel reflectance for unpolarized light at an interface between two media with different indices of refraction. Determines the probability of reflection vs. refraction.

## Operating characteristics
- **Time Complexity:** $O(1)$ per intersection. Requires one normal evaluation, a few dot products, a square root, and vector operations.
- **Memory Complexity:** $O(1)$.
- **Strengths:** Handles both entry and exit for spheres correctly by swapping indices. Vector formulation avoids explicit angle calculations.
- **Limitations:** The sphere-specific exit check (`s > 0`) is not generalizable to all primitives without modification. Does not handle total internal reflection explicitly (clamps discriminant). [S1, unofficial]
- **When to use:** When simulating transparent objects like glass or water in ray marching or ray tracing.
