# Spin Shader
Also called: Spin Shading

## Overview
The Spin Shader visualizes surface geometry by mapping surface normals and camera orientation to a cyclic color field, mimicking spin-1/2 behavior where a 360-degree rotation reverses the texture orientation [S1, unofficial].

## How it works
**Inputs and Outputs:**
- `surface_normals`: A tensor of shape $(N, 3)$ containing unit surface normal vectors $\mathbf{n} = (x, y, z)$ [S1, unofficial].
- `camera_orientation_conj`: A tensor of shape $(N, 4)$ containing the conjugate of the camera orientation quaternion $\overline{q}$ [S1, unofficial].
- `cyclic_colourmap`: A lookup table or function mapping points on the unit circle $\mathbb{S}^1$ to RGB values [S1, unofficial].
- `degree`: An integer parameter (typically 1) passed to the domain colouring function [S1, unofficial].
- **Output:** `color`: A tensor of shape $(N, 3)$ containing RGB pixel values [S1, unofficial].

**Data Structures:**
- Quaternions are represented as 4-element vectors $(w, x, y, z)$ [G].
- Surface normals are treated as pure-imaginary quaternions $0 + xi + yj + zk$ [S1, unofficial].

**Steps:**
1. **Embed Normal as Pure Quaternion:** Convert the surface normal $\mathbf{n} = (x, y, z)$ into a pure-imaginary quaternion $N_p$ by setting the real part to zero:
   $$ N_p = 0 + xi + yj + zk $$
   [S1, unofficial]
2. **Rotate by Camera Conjugate:** Compute the product of the conjugate camera orientation quaternion $\overline{q}$ and the normal quaternion $N_p$ to rotate the normal into the camera's local coordinate frame:
   $$ q' = \overline{q} N_p = a + bi + cj + dk \in \mathbb{S}^3 $$
   [S1, unofficial]
3. **Map to $\mathbb{S}^1$:** Transform the resulting quaternion $q'$ into a point on the unit circle $\mathbb{S}^1$ by computing the real and imaginary parts of the squared quaternion mapping:
   $$ \text{real} = a^2 - |\mathbf{v}|^2 $$
   $$ \text{imag} = 2a|\mathbf{v}| $$
   where $\mathbf{v} = (b, c, d)$ and $|\mathbf{v}| = \sqrt{b^2 + c^2 + d^2}$ [S1, unofficial]. The sequence of mappings is $\mathbb{S}^3 \times \mathbb{S}^2 \to \mathbb{S}^3 \to \mathbb{S}^1 \to \mathbb{R}^3_{\geq 0}$ [S1, unofficial].
4. **Domain Colouring:** Map the point $(\text{imag}, \text{real})$ from $\mathbb{S}^1$ to an RGB color using a cyclic colormap [S1, unofficial].

**Pseudocode:**
```python
import torch
import torch.nn.functional as F

def spin_shader(surface_normals: torch.Tensor, 
                camera_orientation_conj: torch.Tensor, 
                cyclic_colourmap: torch.Tensor, 
                degree: int = 1) -> torch.Tensor:
    # Step 1: Embed normal as pure-imaginary quaternion (0, x, y, z)
    n_pure = F.pad(surface_normals, [1, 0], value=0.0)
    
    # Step 2: Multiply conjugate camera quaternion with pure normal quaternion
    value = quaternion_multiply(n_pure, camera_orientation_conj)
    
    # Unpack result q' = a + bi + cj + dk
    a = value[..., 0]
    bcd = value[..., 1:]
    
    # Step 3: Map to S^1
    norm_bcd = torch.norm(bcd, dim=-1, p=2)
    real_part = a.pow(2) - norm_bcd.pow(2)
    imag_part = norm_bcd.mul(a).mul(2)
    
    # Step 4: Domain colouring
    return domain_colouring(imag_part, real_part, cyclic_colourmap, degree)

def quaternion_multiply(q1: torch.Tensor, q2: torch.Tensor) -> torch.Tensor:
    w1, x1, y1, z1 = q1[..., 0], q1[..., 1], q1[..., 2], q1[..., 3]
    w2, x2, y2, z2 = q2[..., 0], q2[..., 1], q2[..., 2], q2[..., 3]
    w = w1*w2 - x1*x2 - y1*y2 - z1*z2
    x = w1*x2 + x1*w2 + y1*z2 - z1*y2
    y = w1*y2 - x1*z2 + y1*w2 + z1*x2
    z = w1*z2 + x1*y2 - y1*x2 + z1*w2
    return torch.stack([w, x, y, z], dim=-1)

def domain_colouring(imag: torch.Tensor, real: torch.Tensor, cmap: torch.Tensor, degree: int) -> torch.Tensor:
    # Standard cyclic colormap lookup [G]
    angle = torch.atan2(imag, real)
    t = (angle / (2 * torch.pi) + 1) % 1
    idx = (t * (cmap.shape[0] - 1)).long()
    return cmap[idx]
```

## Background
The Spin Shader originates from ray marching and signed distance function (SDF) rendering, specifically within the context of visualizing quaternion-based transformations [S1, unofficial]. The method draws inspiration from the mathematical concept of spinors in physics, where a 360-degree rotation results in a sign change, effectively reversing the "texture" or phase of the object [S1, unofficial].
