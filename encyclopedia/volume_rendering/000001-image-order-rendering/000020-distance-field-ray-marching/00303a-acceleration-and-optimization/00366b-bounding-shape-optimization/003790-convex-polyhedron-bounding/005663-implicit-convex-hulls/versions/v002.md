# Implicit Convex Hulls

Also called: Convex Hull Bounding Volumes, Simplified Convex Hulls

## Overview
Implicit Convex Hulls construct a compact convex bounding volume for the point set generated by Sphere Carving, representing it as an intersection of a reduced set of oriented half-spaces [S1]. By clustering half-space orientations and projecting cluster centers back to the original hull, the method preserves the convex bounding property while enabling significantly more efficient distance evaluation than the full-resolution hull [S1].

## How it works
**Inputs:**
- $S$: Final sphere set from Sphere Carving [S1].
- $P$: Point set generated by $S$ [S1].
- $H$: Full set of half-spaces $\{\Pi_i\}$ defining the convex hull $H(P)$ [S1].
- $m$: Target number of half-spaces for the simplified volume (typical value: 20) [S1].

**Outputs:**
- $H_e$: Reduced set of half-spaces defining the simplified bounding volume $\mathcal{B}$ [S1].
- $d(\mathbf{p}, \mathcal{B})$: Distance from query point $\mathbf{p}$ to $\mathcal{B}$ [S1].

**Data Structures:**
- Half-space $\Pi_i$: Defined by unit normal vector $\mathbf{n}_i$ and scalar offset $d_i$, representing the inequality $\mathbf{n}_i \cdot \mathbf{x} + d_i \le 0$ for all $\mathbf{x} \in H$ [S1].

**Steps:**
1. Extract the normal vectors $\{\mathbf{n}_i\}$ from the full half-space set $H$ [S1].
2. Apply a k-means clustering algorithm to the set of orientations $\{\mathbf{n}_i\}$ to find $m$ clusters [S1].
3. Compute the cluster centers (mean vectors) for each cluster [S1].
4. Project each cluster center onto the existing half-spaces in $H$ by selecting the half-space whose normal $\mathbf{n}_k$ maximizes the dot product with the center [S1].
5. Form the reduced set $H_e$ from the selected half-spaces, preserving the convex bounding property [S1].
6. Evaluate distance: $d(\mathbf{p}, \mathcal{B}) = \max_{\Pi_i \in H_e} (\mathbf{n}_i \cdot \mathbf{p} + d_i)$ [S1].
7. Compute the final field value: $\tilde{f} = d(\mathbf{p}, \mathcal{B})$ if $d(\mathbf{p}, \mathcal{B}) > \varepsilon$, otherwise $\tilde{f} = f(\mathbf{p})$ [S1].

**Pseudocode:**
```python
import math

def dot(a, b):
    return sum(ai * bi for ai, bi in zip(a, b))

def normalize(v):
    mag = math.sqrt(dot(v, v))
    return tuple(vi / mag for vi in v) if mag > 0 else (0.0, 0.0, 0.0)

def argmax_index(values):
    best_idx = 0
    best_val = values[0]
    for i, v in enumerate(values):
        if v > best_val:
            best_val = v
            best_idx = i
    return best_idx

def initialize_centroids(normals, m):
    # Deterministic initialization: pick first m normals [G]
    return [tuple(n) for n in normals[:m]]

def compute_simplified_convex_hull(half_spaces, m):
    normals = [hs[0] for hs in half_spaces]
    centroids = initialize_centroids(normals, m)
    max_iterations = 100
    tolerance = 1e-6

    for _ in range(max_iterations):
        assignments = [[] for _ in range(m)]
        for i, n in enumerate(normals):
            scores = [dot(n, c) for c in centroids]
            best_idx = argmax_index(scores)
            assignments[best_idx].append(i)

        new_centroids = []
        for cluster_indices in assignments:
            if not cluster_indices:
                new_centroids.append(centroids[0])
            else:
                mean_n = [0.0, 0.0, 0.0]
                for idx in cluster_indices:
                    mean_n = [mean_n[j] + normals[idx][j] for j in range(3)]
                new_centroids.append(normalize(mean_n))

        converged = all(math.sqrt(sum((c[j] - nc[j])**2 for j in range(3))) < tolerance for c, nc in zip(centroids, new_centroids))
        centroids = new_centroids
        if converged:
            break

    simplified_half_spaces = []
    for centroid in centroids:
        scores = [dot(centroid, hs[0]) for hs in half_spaces]
        best_idx = argmax_index(scores)
        simplified_half_spaces.append(half_spaces[best_idx])
    return simplified_half_spaces

def distance_to_simplified_hull(p, simplified_half_spaces):
    max_dist = -float('inf')
    for n, d in simplified_half_spaces:
        dist = dot(n, p) + d
        if dist > max_dist:
            max_dist = dist
    return max_dist
```

**Edge Cases:**
- Empty clusters: Re-initialized to the first centroid to avoid undefined centroids [G].
- Degenerate input: Collinear or coplanar points yield fewer unique normals; the algorithm naturally handles reduced $N$ [G].
- Precision: Dot product comparisons use a tolerance threshold; epsilon $\varepsilon$ in the distance check prevents z-fighting artifacts [G].

## Subtopics

### Convex Hull Bounding Volume
A bounding volume $\mathcal{B}$ constructed as the geometric convex hull $H(P)$ of the point set $P$ generated by Sphere Carving, represented as an intersection of oriented half-spaces [S1]. This serves as the base representation before simplification [S1].

## Operating characteristics
- Construction time: $O(N \cdot m \cdot I)$, where $N$ is the number of half-spaces in $H$, $m$ is the cluster count, and $I$ is the number of k-means iterations [S1].
- Distance query time: $O(m)$, requiring one dot product and addition per half-space in $H_e$ [S1].
- Memory: $O(m)$ for the simplified volume versus $O(N)$ for the full hull [S1].
- Using $m \approx 20$ half-spaces yields a shape almost equivalent to the full resolution (e.g., 768 half-spaces) while significantly improving distance evaluation efficiency [S1].
- The evaluation cost remains negligible compared to the underlying SDF function $f$ [S1].
- Strengths: Compact representation, preserves convex bounding property, fast queries for ray marching [S1].
- Limitations: Approximation error increases as $m$ decreases; preprocessing adds clustering overhead [S1].
- Use when a tight convex bound is needed for acceleration and the SDF is expensive [S1].
- Avoid when exact bounding is required or the scene is highly non-convex [S1].

## Background
The method originates from the Sphere Carving algorithm, which produces a final sphere set $S$ and an associated point set $P$ [S1]. The convex hull of $P$ bounds the object and is exploited to build efficient bounding volumes [S1]. Clustering half-space orientations was introduced to address the computational intensity of evaluating distance against a high-resolution convex hull [S1].
