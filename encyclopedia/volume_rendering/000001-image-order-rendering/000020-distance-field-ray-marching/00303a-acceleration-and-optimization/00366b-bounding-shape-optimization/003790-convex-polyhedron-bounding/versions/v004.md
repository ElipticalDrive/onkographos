# Convex Polyhedron Bounding

Also called: PARC (Polygon assisted ray casting)

## Overview
Convex Polyhedron Bounding is a space-leaping technique for direct volume rendering that accelerates ray traversal by enclosing objects within a convex polyhedron [S1, unofficial]. It solves the problem of inefficiently stepping through empty space by allowing rays to skip large volumes of non-data voxels [S1, unofficial]. The method is specifically recommended for volumes containing only a few objects [S1, unofficial].

## How it works
**Inputs and Outputs:**
*   **Input:** A volumetric dataset containing one or few distinct objects [S1, unofficial].
*   **Output:** A convex polyhedron that encloses the object, used to cull empty space during ray marching [S1, unofficial].

**Data Structures:**
The exact layout is not specified in the sources [S1, unofficial].

**Steps:**
1.  **Object Identification:** Identify the voxels belonging to the object(s) in the volume [S1, unofficial].
2.  **Polyhedron Construction:** Compute a convex polyhedron that encloses all identified object voxels [S1, unofficial].
3.  **Ray Traversal Setup:** For each ray, determine the entry and exit points of the ray with respect to the convex polyhedron [S1, unofficial].
4.  **Space Leaping:** If the ray does not intersect the polyhedron, skip the ray entirely [S1, unofficial]. If it intersects, traverse only the segment within the polyhedron using standard volume rendering techniques [S1, unofficial].

**Formulas:**
The exact mathematical formulation is not given in the sources [S1, unofficial].

**Parameters:**
*   **Number of Objects:** The method is recommended for volumes with "few objects" [S1, unofficial].

**Edge Cases and Pitfalls:**
*   **Multiple Objects:** If the volume contains many objects, the convex hull may become too large or complex, reducing efficiency [S1, unofficial].
