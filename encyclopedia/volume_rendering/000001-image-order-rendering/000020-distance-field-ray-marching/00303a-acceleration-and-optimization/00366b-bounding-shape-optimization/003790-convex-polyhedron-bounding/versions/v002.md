# Convex Polyhedron Bounding
Also called: PARC (Polygon assisted ray casting)
## Overview
Convex Polyhedron Bounding, also known as PARC, constructs a convex polyhedron around volumetric objects to enable space-leaping during ray traversal [S1, unofficial]. It is applied to volumes containing few objects, where the overhead of polyhedron construction is justified by reduced density evaluations [S1, unofficial].
## How it works
**Inputs and Outputs:**
- Input: Volumetric dataset containing one or more objects.
- Output: A convex polyhedron enclosing the object(s) for space-leaping [S1, unofficial].

**Data Structures:**
- Convex Polyhedron: Encloses the object voxels. The exact internal representation is not given in the sources [S1, unofficial].

**Steps:**
1. Identify voxels belonging to the target object(s) within the volume dataset [S1, unofficial].
2. Build a convex polyhedron around the identified object voxels [S1, unofficial].
3. Use the polyhedron for space-leaping during ray traversal [S1, unofficial].

## Background
The PARC (Polygon assisted ray casting) method was introduced as a technique for direct volume rendering to improve performance by using convex polyhedra for space-leaping [S1, unofficial]. It is part of a broader set of optimization techniques for volume rendering, including adaptive ray traversal and proximity clouds [S1, unofficial]. The method is particularly relevant for volumes with few objects, where the overhead of constructing and using the polyhedron is justified by the reduction in density evaluations [S1, unofficial].
