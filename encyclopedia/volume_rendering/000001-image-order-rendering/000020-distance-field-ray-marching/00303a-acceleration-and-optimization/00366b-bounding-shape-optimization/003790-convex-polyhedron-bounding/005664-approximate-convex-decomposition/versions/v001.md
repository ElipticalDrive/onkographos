# Approximate Convex Decomposition

Also called: Plane Cutting Decomposition, Recursive Convex Decomposition

## Overview
Approximate Convex Decomposition (ACD) is a post-processing method that decomposes a point set $P$ (generated by Sphere Carving) into a union of tighter convex bounding volumes by recursively cutting the set with planes [S1]. Unlike a single convex hull, which can be loose for concave shapes, ACD creates a union of simpler convex shapes that conform more closely to the object's surface [S1]. It sets itself apart from siblings like [Bounding Volume Extrusion](8410-bounding-volume-extrusion.md) and [Implicit Convex Hulls](15694-implicit-convex-hulls.md) by explicitly using a cutting-plane strategy inspired by mesh decomposition to minimize the total volume of the resulting hulls [S1].

## How it works
**Inputs:**
*   Point set $P$: A dense set of points close to the object surface, generated by Sphere Carving.
*   Sphere set $S$: The set of spheres used in the preceding Sphere Carving step.
*   $V_0$: The volume of the initial bounding volume.
*   $n_i$: Number of iterations used in Sphere Carving (determines point cloud density) [S1].

**Outputs:**
*   A set of convex polyhedra (or ellipsoids) whose union bounds the object $\mathcal{O}$ [S1].

**Data Structures:**
*   $P$: List of 3D points.
*   $S$: List of spheres (center, radius).
*   $\Pi$: Cutting plane defined by normal $\mathbf{n}$ and distance $d$ from origin, or implicitly by the infinite sphere $S_\infty$.

**Steps:**

1.  **Sampling:** Sample a set of candidate cutting planes $\{\Pi_i\}$ (typically hundreds) from the space surrounding the point set $P$ [S1].
2.  **Selection:** For each candidate plane $\Pi_i$, split $P$ into two disjoint subsets $\mathcal{L}$ (left) and $\mathcal{R}$ (right) based on the signed distance $d(\Pi_i, \mathbf{p})$ [S1]:
    $$ \mathcal{L} = \{\mathbf{p} \in P, d(\Pi_i, \mathbf{p}) < 0\} $$
    $$ \mathcal{R} = \{\mathbf{p} \in P, d(\Pi_i, \mathbf{p}) \geq 0\} $$
    Compute the score $\sigma(P, \Pi_i)$ as the sum of the volumes of the convex hulls of these subsets:
    $$ \sigma(P, \Pi_i) = V(H(\mathcal{L})) + V(H(\mathcal{R})) $$
    where $V$ is the volume function and $H$ is the convex hull operator [S1].
    Select the plane $\Pi$ that minimizes this score:
    $$ \Pi = \arg \min_i \sigma(P, \Pi_i) $$
3.  **Bounding Maintenance (Infinite Sphere):** To ensure the resulting hulls bound the object, the cutting plane $\Pi$ is treated as an infinite sphere $S_\infty$ added to the sphere set $S$ [S1]. The convex hull created by trilaterating the extended sphere set $\mathcal{S} \cup S_\infty$ bounds the intersection of the object and the plane:
    $$ H(\widetilde{T}(\mathcal{S} \cup S_\infty)) \supset \mathcal{O} \cap \Pi $$
    where $\widetilde{T}$ denotes the trilateration operation [S1].
4.  **Finite Sphere Replacement:** Replace $S_\infty$ with a large finite sphere tangent to $\Pi$.
    *   **Radius:** Set to the size of $V_0$ (the initial volume) [S1].
    *   **Center:** Located on the line perpendicular to $\Pi$ passing through the centroid of the subset ($\mathcal{L}$ or $\mathcal{R}$) [S1].
    *   This replacement maintains the bounding guarantee and allows reuse of Sphere Carving intersection calculations [S1].
5.  **Recursion:** Recursively apply steps 2-4 to subsets $\mathcal{L}$ and $\mathcal{R}$ until a user-defined number of convex parts is reached or a stopping criterion is met [S1].

    # S_L = S + {sphere_L}
    # S_R = S + {sphere_R}

    # In recursion, we must pass the relevant sphere context.

    hulls_R = approximate_convex_decomposition(best_R, S + [sphere_R], V0, max_parts)
    
    return hulls_L + hulls_R

**Edge Cases and Pitfalls:**
*   **Precision:** The cutting plane selection requires multiple convex hull computations, which is computationally expensive and can be sensitive to numerical precision in volume calculations [S1].
*   **Boundaries:** Simply taking the convex hull of split point sets $\mathcal{L}$ and $\mathcal{R}$ is *not* sufficient to guarantee the bounding property ($\mathcal{O} \not\subset H(\mathcal{L}) \cup H(\mathcal{R})$) [S1]. The sphere intersection logic is mandatory.
*   **Degenerate Input:** If the point set $P$ is not dense enough (too few iterations $n_i$ in Sphere Carving), the decomposition may not accurately capture the shape, leading to loose bounds [S1].

## Operating characteristics
*   **Time Complexity:** The cutting plane selection step is the bottleneck, requiring multiple convex hull computations for hundreds of candidate planes [S1]. The decomposition process usually takes a few seconds to complete [S1].
*   **Memory Complexity:** Depends on the number of points in $P$ and the number of convex parts generated. The sphere set $S$ grows with each recursive step if not managed carefully, though the implementation reuses calculations [S1].
*   **Measured Performance:** For models like "House" (17 iterations, 4 parts), decomposition took 2.7 seconds. For "Amphora" (7 iterations, 29 parts), it took 49.9 seconds [S1].
*   **Strengths:** Produces tighter bounding volumes than a single convex hull, leveraging the detailed information in the point set $P$ [S1]. Maintains the bounding guarantee [S1].
*   **Limitations:** Slow due to the exhaustive search for the optimal cutting plane [S1]. The method draws inspiration from mesh decomposition and could be replaced with more efficient methods [S1].
*   **When to use:** When tighter bounds are needed for ray marching acceleration and the object has significant concavity. Suitable for real-time applications if the pre-processing time is acceptable [S1].

## Background
Approximate Convex Decomposition in this context is a post-processing step for the Sphere Carving algorithm [S1]. It draws inspiration from approximate convex decomposition methods typically applied to meshes, specifically citing [Thul et al. 2018] [S1]. The method was introduced in the paper "Sphere Carving: Bounding Volumes for Signed Distance Fields" [S1].
