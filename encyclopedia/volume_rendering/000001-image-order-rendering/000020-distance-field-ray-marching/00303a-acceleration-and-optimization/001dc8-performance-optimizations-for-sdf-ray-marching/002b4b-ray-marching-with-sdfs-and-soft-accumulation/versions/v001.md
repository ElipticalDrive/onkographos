# Ray Marching with SDFs and Soft Accumulation

Also called: Jellyfish Ray Marching with Soft Accumulation, Soft Accumulation for Thin Geometry

## Overview
A rendering technique for hair-thin geometry (such as jellyfish tentacles or hair) that prevents flickering and aliasing by accumulating soft contributions based on distance to the Signed Distance Function (SDF) surface, rather than performing hard intersections. Unlike standard SDF ray marching which stops at the first hit, this method integrates opacity along the ray, fading in smoothly as the ray passes near thin strands. It sets itself apart from siblings like [Aggressive Ray Marching with SDF](2326-aggressive-ray-marching-with-sdf.md) by prioritizing visual stability for sub-pixel features over raw speed, and from [Subsurface Scattering Approximation via Local Thickness](1946-subsurface-scattering-approximation-via-local-thickness.md) by focusing on anti-aliasing thin geometry rather than volumetric light transport.

## How it works
**Inputs and Outputs:**
- **Inputs:** Ray origin $o$, ray direction $d$, time $t$, phase $\phi$, scene parameters (bell radius, tentacle length, school count), and SDF evaluation functions for the bell ($sdBell$), tentacles ($sdTentacles$), and arms ($sdArms$).
- **Outputs:** Final color $col$ for the pixel.

**Data Structures:**
- **Ray State:** `travel` (float, accumulated distance), `trans` (float, transparency, initialized to 1.0), `strands` (float, accumulated strand contribution), `rad` (vec3, accumulated radial color).
- **SDF Values:** `db` (distance to bell), `dt` (distance to tentacles), `da` (distance to arms).

**Parameters:**
- `MARCH_STEPS`: Maximum marching iterations. Value: 120 [S1, unofficial].
- `TENT_LEN`: Maximum tentacle length along negative Y. Value: 3.0 [S1, unofficial].
- `ARM_LEN`: Maximum arm length along negative Y. Value: 1.5 [S1, unofficial].
- `SCHOOL`: Number of jellyfish in the school. Value: 5 [S1, unofficial].
- `GLOW`, `HOT`: Color intensity multipliers (implementation-specific constants, typically derived from scene aesthetics).

**Steps:**

1. **Initialization:**
   For each jellyfish in the school:
   - Compute center position with sinusoidal drift.
   - Transform ray origin: $o = (ro - centre) / data.w$.
   - Apply tilt rotations to $o.xy$ and $o.zy$.
   - Compute marching bounds via ray-sphere intersection:
     $$bo = o - vec3(0.0, -1.4, 0.0)$$
     $$b = dot(bo, d)$$
     $$disc = b^2 - dot(bo, bo) + 2.7^2$$
     $$t_{max} = -b + \sqrt{disc}$$
   - Initialize state:
     $$pc = pulse(t \cdot 0.42 + \phi \cdot 0.37)$$
     $$travel = \max(-b - \sqrt{disc}, 0.0) + dither$$
     $$trans = 1.0$$
     $$strands = 0.0$$
     $$rad = vec3(0.0)$$

2. **Ray Marching Loop:**
   Iterate $s$ from 0 to `MARCH_STEPS` - 1:
   - If $travel > t_{max}$ or $trans < 0.05$, break.
   - Compute current position: $p = o + d \cdot travel$.
   - Evaluate SDFs:
     $$db = sdBell(p, pc, t, \phi)$$
     $$dt = sdTentacles(p, pc, t, \phi)$$
     $$da = sdArms(p, t, \phi)$$
   - Compute step size (stride):
     $$stride = clamp(\min(db, \min(dt, da)) \cdot 0.70, 0.010, 0.18)$$

3. **Soft Accumulation for Strands:**
   - Compute taper factor to fade strands near the base:
     $$taper = 1.0 - smoothstep(0.55, 1.05, -p.y / TENT\_LEN)$$
   - Add tentacle contribution:
     $$strands += \exp(-\max(dt, 0.0) \cdot 95.0) \cdot stride \cdot 8.5 \cdot taper$$
   - Add arm contribution:
     $$strands += \exp(-\max(da, 0.0) \cdot 45.0) \cdot stride \cdot 3.0$$

4. **Bell Surface Shading:**
   - If $db < 0.012$:
     - Compute normal $n$ via finite differences with $e = vec3(0.0035, 0.0)$.
     - Compute Fresnel term:
       $$fres = pow(1.0 - |dot(n, -d)|, 2.4)$$
     - Compute lighting angle:
       $$lam = 0.35 + 0.65 \cdot |dot(n, normalize(vec3(-0.35, 1.0, 0.45)))|$$
     - Compute rib pattern:
       $$ribs = pow(0.5 + 0.5 \cdot \cos(16.0 \cdot atan(p.z, p.x)), 14.0)$$
     - Compute opacity:
       $$op = 0.075 + 0.42 \cdot fres + ribs \cdot 0.12$$
     - Add color contribution:
       $$rad += trans \cdot op \cdot (GLOW \cdot (0.75 + 1.15 \cdot lam) + HOT \cdot (fres \cdot 1.30 + ribs \cdot 0.60))$$
     - Update transparency:
       $$trans *= 1.0 - op$$
     - Force small stride for surface detail:
       $$stride = 0.026$$

5. **Advance Ray:**
   - $$travel += stride$$

6. **Final Composition:**
   - Apply fog:
     $$fog = \exp(-0.055 \cdot \max(length(ro - centre) - 3.0, 0.0))$$
   - Add accumulated color:
     $$col += (rad + GLOW \cdot strands \cdot 0.16 + HOT \cdot strands^2 \cdot 0.006) \cdot fog$$

**Pseudocode:**

```python
def ray_march_sdf_soft_accumulation(ro, d, t, phi, school_count=5, march_steps=120, tent_len=3.0):
    col = vec3(0.0)
    
    for i in range(school_count):
        # 1. Initialization
        centre = compute_jellyfish_center(i, t, phi)
        o = (ro - centre) / data.w
        o.xy = rot(tilt.x) * o.xy
        o.zy = rot(tilt.y) * o.zy
        
        bo = o - vec3(0.0, -1.4, 0.0)
        b = dot(bo, d)
        disc = b * b - dot(bo, bo) + 2.7 * 2.7
        tmax = -b + sqrt(disc)
        
        pc = pulse(t * 0.42 + phi * 0.37)
        travel = max(-b - sqrt(disc), 0.0) + dither
        trans = 1.0
        strands = 0.0
        rad = vec3(0.0)
        
        # 2. Ray Marching Loop
        for s in range(march_steps):
            if travel > tmax or trans < 0.05:
                break
                
            p = o + d * travel
            
            db = sdBell(p, pc, t, phi)
            dt = sdTentacles(p, pc, t, phi)
            da = sdArms(p, t, phi)
            
            stride = clamp(min(db, min(dt, da)) * 0.70, 0.010, 0.18)
            
            # 3. Soft Accumulation for Strands
            taper = 1.0 - smoothstep(0.55, 1.05, -p.y / tent_len)
            strands += exp(-max(dt, 0.0) * 95.0) * stride * 8.5 * taper
            strands += exp(-max(da, 0.0) * 45.0) * stride * 3.0
            
            # 4. Bell Surface Shading
            if db < 0.012:
                n = bellNormal(p, pc, t, phi)
                fres = pow(1.0 - abs(dot(n, -d)), 2.4)
                lam = 0.35 + 0.65 * abs(dot(n, normalize(vec3(-0.35, 1.0, 0.45))))
                ribs = pow(0.5 + 0.5 * cos(16.0 * atan(p.z, p.x)), 14.0)
                op = 0.075 + 0.42 * fres + ribs * 0.12
                
                rad += trans * op * (GLOW * (0.75 + 1.15 * lam) + HOT * (fres * 1.30 + ribs * 0.60))
                trans *= 1.0 - op
                stride = 0.026
                
            # 5. Advance Ray
            travel += stride
            
        # 6. Final Composition
        fog = exp(-0.055 * max(length(ro - centre) - 3.0, 0.0))
        col += (rad + GLOW * strands * 0.16 + HOT * strands * strands * 0.006) * fog
        
    return col

def pulse(x):
    x = fract(x)
    if x < 0.28:
        return smoothstep(0.0, 1.0, x / 0.28)
    else:
        return 1.0 - smoothstep(0.0, 1.0, (x - 0.28) / 0.72)
```

## Operating characteristics
- **Time Complexity:** Linear with respect to `MARCH_STEPS` and the number of jellyfish in the school. Each step involves multiple SDF evaluations and exponential calculations.
- **Memory Complexity:** Constant per ray, storing only a few floating-point accumulators.
- **Performance:** On integrated graphics, rendering roughly one minute of output takes about 10 seconds [S1, unofficial]. Single frames are near-instant for iteration.
- **Strengths:** Eliminates flickering and aliasing artifacts common in hard-intersection SDF rendering of hair-thin geometry. Provides smooth, fluid motion for dynamic thin structures.
- **Limitations:** Computationally more expensive than hard intersection due to accumulation over many steps. Requires careful tuning of exponential falloff constants (95.0, 45.0) to balance visibility and performance.
- **When to use:** Rendering hair, tentacles, or other sub-pixel thin geometry where temporal stability is critical.
- **When not to use:** When performance is paramount and geometry is thick enough to be reliably captured by hard intersections.

## Background
Originated in the context of procedural jellyfish rendering using GLSL shaders and Manim for timeline management [S1, unofficial]. The technique addresses the specific visual artifact of "flickering" that occurs when hair-thin strands slip between sample points in standard ray marching. It was developed as part of a project combining mathematical visualization with real-time shader rendering.
