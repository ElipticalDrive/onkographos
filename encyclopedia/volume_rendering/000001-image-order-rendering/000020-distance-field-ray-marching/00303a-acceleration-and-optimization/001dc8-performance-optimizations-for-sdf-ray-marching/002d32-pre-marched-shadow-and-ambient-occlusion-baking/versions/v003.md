# Pre-marched Shadow and Ambient Occlusion Baking

Also called: Baked shadow ray, Pre-marched ambient occlusion

## Overview
A technique to improve visual fidelity and performance by pre-calculating shadow and ambient occlusion data into the volume texture, leveraging the static nature of the cloud volume [S1, unofficial]. It sets itself apart from real-time ray marching by trading runtime compute for a one-time or event-driven baking cost, avoiding expensive per-frame camera renders [S1, unofficial]. It builds on [Performance Optimizations for SDF Ray Marching](1629-performance-optimizations-for-sdf-ray-marching.md).

## How it works
**Inputs and Outputs:**
*   **Input:** A static signed distance field (SDF) volume representing the cloud geometry.
*   **Output:** A 3D volume texture containing baked shadow and ambient occlusion attenuation factors [S1, unofficial].

**Data Structures:**
*   **Baked Volume Texture:** A 3D texture where each voxel stores pre-computed lighting attenuation factors [S1, unofficial]. The resolution is typically low, matching the base cloud volume resolution [S1, unofficial].

**Steps:**
1.  **Bake Shadow:** Pre-march a shadow ray through the volume for each voxel [S1, unofficial]. This involves casting rays in the direction of the light source(s) to determine occlusion [S1, unofficial]. Due to the low volume resolution, this can be done in real-time during the baking phase [S1, unofficial]. A typical implementation uses 4 shadow samples per cloud sample [S1, unofficial]. Because the baking is computationally feasible in real-time, the shadow data can be regenerated to allow for dynamic changes in the sun's position (time-of-day) without runtime cost [S1, unofficial].
2.  **Bake Ambient Occlusion:** Pre-march ambient occlusion rays into the volume texture [S1, unofficial]. This adds shading based on local geometry density without runtime cost [S1, unofficial].
3.  **Runtime Lookup:** During rendering, retrieve the volumetric cloud shadow using a single `tex3D` lookup on the baked texture [S1, unofficial]. This ensures the shadow perfectly matches the cloud geometry [S1, unofficial].

**Pseudocode:**
```python
def bake_shadow_and_ao(sdf_volume, resolution, light_direction):
    shadow_texture = [[[1.0 for _ in range(resolution.z)] for _ in range(resolution.y)] for _ in range(resolution.x)]
    ao_texture = [[[1.0 for _ in range(resolution.z)] for _ in range(resolution.y)] for _ in range(resolution.x)]

    for x in range(resolution.x):
        for y in range(resolution.y):
            for z in range(resolution.z):
                pos = [x, y, z]  # Normalized voxel coordinates [G]

                # Bake Shadow: Pre-march shadow ray through volume [S1, unofficial]
                shadow_factor = 1.0
                num_shadow_samples = 4  # [S1, unofficial]
                step_size = 1.0
                for i in range(num_shadow_samples):
                    sample_pos = [pos[0] + light_direction[0] * (i + 1) * step_size,
                                  pos[1] + light_direction[1] * (i + 1) * step_size,
                                  pos[2] + light_direction[2] * (i + 1) * step_size]
                    if sdf_volume(sample_pos) < 0:
                        shadow_factor = 0.0
                        break
                shadow_texture[x][y][z] = shadow_factor

                # Bake Ambient Occlusion: Pre-march AO into volume texture [S1, unofficial]
                ao_factor = 1.0
                # Exact AO march directions and step counts are not specified in the source [Comment]
                for _ in range(4):
                    sample_pos = [pos[0] + 0.5, pos[1] + 0.5, pos[2] + 0.5]
                    if sdf_volume(sample_pos) < 0:
                        ao_factor *= 0.5
                        break
                ao_texture[x][y][z] = ao_factor

    return shadow_texture, ao_texture

def render_voxel(x, y, z, shadow_texture, ao_texture):
    # Runtime Lookup: single tex3D lookup on baked texture [S1, unofficial]
    shadow = shadow_texture[x][y][z]
    ao = ao_texture[x][y][z]
    base_color = 1.0  # Base cloud color from SDF pass [G]
    return base_color * shadow * ao
```

**Parameters:**
*   **Shadow Samples per Cloud Sample:** 4 [S1, unofficial].
*   **Volume Resolution:** Low, matching the base cloud volume [S1, unofficial].

**Edge Cases and Pitfalls:**
*   **Static Assumption:** This method relies on the volume being static [S1, unofficial].
*   **Memory:** Storing attenuation factors in the volume texture increases memory usage, though the low resolution mitigates this [S1, unofficial].

### [Occlusion Caching](14832-occlusion-caching.md)
Occlusion caching is a performance optimization for static volumetric lighting that pre-calculates shadow and ambient occlusion data into volume textures, avoiding expensive per-frame camera renders. It sets itself apart from real-time ray marching by trading runtime compute for a one-time or event-driven baking cost, leveraging the static nature of most cloud volumes and occluders.

## Operating characteristics
*   **Time Complexity:** Baking time is proportional to the number of voxels times the number of shadow/AO samples [S1, unofficial]. Since volume resolution is low, baking can be done in real-time during the bake phase [S1, unofficial]. Runtime cost is O(1) per voxel for texture lookup [S1, unofficial].
*   **Memory Complexity:** O(N) where N is the number of voxels, for storing the baked volume texture [S1, unofficial].
*   **Performance:** Significantly reduces runtime cost by eliminating per-frame shadow and AO ray marching [S1, unofficial].
*   **Strengths:** Perfect shadow alignment with cloud geometry, low runtime cost, supports dynamic time-of-day if baked dynamically [S1, unofficial].
*   **Limitations:** Requires static geometry, increased memory for baked textures, baking cost (though feasible in real-time for low res) [S1, unofficial].
*   **When to Use:** Static volumetric clouds where high-quality shadows and AO are desired without runtime cost [S1, unofficial].
*   **When Not to Use:** Dynamic volumes where geometry changes frequently [S1, unofficial].
