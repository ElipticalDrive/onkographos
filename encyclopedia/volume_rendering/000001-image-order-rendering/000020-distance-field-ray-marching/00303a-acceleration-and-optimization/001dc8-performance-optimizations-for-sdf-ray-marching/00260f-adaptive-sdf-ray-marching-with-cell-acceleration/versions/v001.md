# Adaptive SDF Ray Marching with Cell Acceleration


## Overview
This method accelerates Signed Distance Field (SDF) ray marching by combining spatial acceleration structures with adaptive step sizing and sign-change detection for surface refinement [S1, unofficial]. It solves the problem of inefficient traversal through empty space and missed thin geometry by skipping non-intersecting regions via cell bounds and refining intersections when the SDF sign flips between steps [S1, unofficial]. It sets itself apart from standard sphere tracing by using lower-bound estimates from acceleration cells to skip large distances, and from aggressive marching by ensuring precision through exact evaluation triggers and bisection refinement [S1, unofficial].

## How it works
**Inputs:**
- Ray origin $r_o$ and direction $r_d$ (normalized).
- Scene SDF function $SDF(p)$.
- Acceleration structure providing cell data for a point $p$.
- Scene bounding box $[boundsEnter, boundsExit]$.
- Parameters: $MAX\_DIST$, $MAX\_STEPS$, $SPHERE\_TRACE\_SAFETY$, $ACCEL\_EXACT\_REFINE\_DIST$, $ACCEL\_MIN\_CELL\_EXIT\_REFINE$, $overRelax$ [G].

**Outputs:**
- Hit distance $dist$.
- Termination code: 0 (no hit), 1 (surface hit via epsilon), 2 (surface hit via sign change).

**Data Structures:**
- `AccelCell`: Contains `accelStart`, `accelCount`, and potentially `cellExit` distance. Layout details for the acceleration structure itself are not given in the sources [S1, unofficial]. The cell query returns whether a cell exists for the hit position and whether a full scan is forced [S1, unofficial].

**Parameters:**
- $SPHERE\_TRACE\_SAFETY$: Multiplier for sphere tracing step size to prevent overshooting. Typical value: 1.0 or slightly greater [G].
- $ACCEL\_EXACT\_REFINE\_DIST$: Threshold for the lower bound distance $d_{Lower}$ to trigger exact SDF evaluation [S1, unofficial].
- $ACCEL\_MIN\_CELL\_EXIT\_REFINE$: Threshold for cell exit distance to trigger refinement [S1, unofficial].
- $overRelax$: Over-relaxation factor for step size. Typical value: 1.0 [G].

**Steps:**
1. Compute ray origin $r_o$ and direction $r_d$.
2. Intersect scene bounds to get $boundsEnter$ and $boundsExit$.
3. Initialize $marchDist = boundsEnter$, $marchEnd = \min(MAX\_DIST, boundsExit)$.
4. Initialize $havePrev = false$, $prevDist = 0.0$, $prevT = 0.0$.
5. Loop $i$ from 0 to $MAX\_STEPS$:
   a. If $i \ge marchLimit$, break.
   b. Compute $hitPos = r_o + r_d \cdot marchDist$.
   c. Query acceleration cell: $(cell, forceFullScan) = getAccelCellData(hitPos, cell, accelStart, accelCount, forceFullScan)$.
   d. Determine $d_{Scene}$:
      i. If cell found and $!forceFullScan$:
         - Compute $cellExit$.
         - If $accelCount > 0$, get $d_{Lower} = sceneSDFDistanceLowerBoundForAccelRange(...)$.
         - If $d_{Lower} \le ACCEL\_EXACT\_REFINE\_DIST$ or $cellExit \le ACCEL\_MIN\_CELL\_EXIT\_REFINE$, $d_{Scene} = sceneSDFDistanceExact(hitPos)$.
         - Else, $d_{Scene} = d_{Lower}$.
      ii. Else (no cell or forceFullScan), $d_{Scene} = sceneSDFDistanceExact(hitPos)$.
   e. Compute $hitEps = getAdaptiveHitEpsilon(marchDist)$.
   f. If $|d_{Scene}| < hitEps$, hit detected: set $dist = marchDist$, $terminationCode = 1$, break.
   g. If $havePrev$ and $prevDist > 0.0$ and $d_{Scene} < 0.0$, refine surface crossing:
      - Call $refineSurfaceCrossing(r_o, r_d, prevT, marchDist)$.
      - Set $dist$, $terminationCode = 2$, break.
   h. Compute $stepDist = \max(|d_{Scene}| \cdot SPHERE\_TRACE\_SAFETY \cdot overRelax, hitEps \cdot 0.33)$.
   i. If in cell, $stepDist = \min(stepDist, cellExit + hitEps \cdot 0.5)$.
   j. Update $havePrev = true$, $prevDist = d_{Scene}$, $prevT = marchDist$.
   k. $marchDist += stepDist$.
   l. If $marchDist > marchEnd$, break.

**Pseudocode:**
```python
def adaptive_sdf_ray_marching(r_o, r_d, scene_sdf, accel_query, bounds_enter, bounds_exit, max_dist, max_steps, sphere_trace_safety, accel_exact_refine_dist, accel_min_cell_exit_refine, over_relax=1.0):
    march_dist = bounds_enter
    march_end = min(max_dist, bounds_exit)
    have_prev = False
    prev_dist = 0.0
    prev_t = 0.0
    
    for i in range(max_steps):
        if i >= max_steps:
            break
            
        hit_pos = r_o + r_d * march_dist
        
        # Query acceleration structure
        cell, force_full_scan = accel_query(hit_pos)
        
        # Determine scene distance
        if cell is not None and not force_full_scan:
            cell_exit = cell.get_exit_distance(hit_pos)
            if cell.get_count() > 0:
                d_lower = scene_sdf.get_lower_bound_for_range(cell)
                if d_lower <= accel_exact_refine_dist or cell_exit <= accel_min_cell_exit_refine:
                    d_scene = scene_sdf.evaluate(hit_pos)
                else:
                    d_scene = d_lower
            else:
                d_scene = cell_exit
        else:
            d_scene = scene_sdf.evaluate(hit_pos)
            
        hit_eps = get_adaptive_hit_epsilon(march_dist)
        
        # Check for direct hit
        if abs(d_scene) < hit_eps:
            return march_dist, 1
            
        # Check for sign change (surface crossing)
        if have_prev and prev_dist > 0.0 and d_scene < 0.0:
            dist, _ = refine_surface_crossing(r_o, r_d, prev_t, march_dist)
            return dist, 2
            
        # Compute step size
        step_dist = max(abs(d_scene) * sphere_trace_safety * over_relax, hit_eps * 0.33)
        
        if cell is not None:
            cell_exit = cell.get_exit_distance(hit_pos)
            step_dist = min(step_dist, cell_exit + hit_eps * 0.5)
            
        have_prev = True
        prev_dist = d_scene
        prev_t = march_dist
        march_dist += step_dist
        
        if march_dist > march_end:
            break
            
    return -1.0, 0

def get_adaptive_hit_epsilon(march_dist):
    # [G] Standard adaptive epsilon based on distance
    return 1e-4 + 1e-5 * march_dist

def refine_surface_crossing(r_o, r_d, t_prev, t_curr):
    # [G] Bisection search between t_prev and t_curr
    t_low = t_prev
    t_high = t_curr
    for _ in range(10):
        t_mid = (t_low + t_high) / 2.0
        hit_pos = r_o + r_d * t_mid
        d = scene_sdf.evaluate(hit_pos)
        if d > 0:
            t_low = t_mid
        else:
            t_high = t_mid
    return (t_low + t_high) / 2.0, 2
```

## Operating characteristics
- **Time Complexity:** Depends on the acceleration structure query cost and the number of steps. Cell acceleration reduces steps in empty space, but exact evaluation is triggered near surfaces or thin geometry.
- **Memory Complexity:** Depends on the acceleration structure size.
- **Performance:** Accelerates empty space traversal. Sign-change detection ensures precision but adds overhead for tracking previous values.
- **Strengths:** Handles empty space efficiently, prevents missed thin geometry.
- **Limitations:** Requires an acceleration structure. Exact evaluation triggers can increase cost near complex surfaces.
- **When to use:** Scenes with large empty spaces and thin geometry.
- **When not to use:** Scenes without acceleration structure support or where exact evaluation is too costly.

## Background
Originated in the context of real-time ray marching for SDF scenes, specifically in the [TeoGrajqevci/RayMarching_tool](https://github.com/TeoGrajqevci/RayMarching_tool) repository [S1, unofficial]. It combines standard sphere tracing with spatial acceleration and robust surface detection.
