# SH Degree Truncation

Also called: SH Capping, Spherical Harmonics Degree Reduction

## Overview
SH Degree Truncation is a preprocessing step that reduces the spherical harmonics (SH) degree of loaded splats to match a target parameter, thereby lowering memory and compute requirements [S1, unofficial]. It differs from dynamic degree selection methods by performing a static, in-place reduction of the SH coefficients at load time rather than during rendering or training [S1, unofficial].

## How it works
**Inputs and Outputs:**
*   **Input:** A splat data structure containing SH coefficients up to a maximum loaded degree $L_{loaded}$, and a target degree parameter $L_{target}$ (where $L_{target} \ge 0$).
*   **Output:** The same splat data structure with SH coefficients truncated to degree $L_{target}$. Coefficients for degrees $> L_{target}$ are discarded.

**Data Structures:**
The splat data structure stores SH coefficients in a flat array or tensor. For a given Gaussian primitive $i$, the coefficients are typically stored in row-major order by degree $l$ and order $m$.
*   Degree $l$ has $2l+1$ coefficients.
*   Total coefficients for degree $L$ is $\sum_{l=0}^{L} (2l+1) = (L+1)^2$.
*   For 3D colors, each coefficient is a 3-component vector (RGB).

**Steps:**
1.  Retrieve the target SH degree $L_{target}$ from the rendering parameters.
2.  Retrieve the maximum SH degree $L_{loaded}$ currently stored in the splat data.
3.  If $L_{target} < L_{loaded}$, truncate the coefficients:
    *   For each Gaussian primitive, keep only the coefficients corresponding to degrees $l \in [0, L_{target}]$.
    *   Discard coefficients for degrees $l > L_{target}$.
4.  If $L_{target} \ge L_{loaded}$, no truncation is performed (or the structure may be padded if a fixed buffer size is required, though standard truncation implies reduction).

**Pseudocode:**
```python
def truncate_sh_degree(splat_data, target_degree):
    """
    Truncates the spherical harmonics coefficients of a splat to a target degree.
    
    Args:
        splat_data: Object containing 'sh_coeffs' (tensor of shape [N, (L_max+1)^2, 3])
                     and 'max_sh_degree' (int).
        target_degree: Integer, the desired maximum SH degree.
    """
    # Get current max degree from the splat data
    current_max_degree = splat_data.get_max_sh_degree()
    
    # Check if truncation is necessary
    if target_degree < 0:
        raise ValueError("Target SH degree must be >= 0")
        
    if target_degree >= current_max_degree:
        # No truncation needed, or data is already lower degree
        return splat_data
        
    # Calculate the number of coefficients to keep per color channel
    # Number of coefficients for degree L is (L+1)^2
    coeffs_to_keep = (target_degree + 1) ** 2
    
    # Access the SH coefficients tensor
    # Assuming shape: [num_gaussians, num_coeffs, 3]
    sh_coeffs = splat_data.sh_coeffs
    
    # Truncate: keep only the first (target_degree + 1)^2 coefficients
    # This corresponds to keeping all coefficients for degrees 0 to target_degree
    truncated_coeffs = sh_coeffs[:, :coeffs_to_keep, :]
    
    # Update the splat data in-place
    splat_data.sh_coeffs = truncated_coeffs
    
    # Update the metadata to reflect the new max degree
    splat_data.max_sh_degree = target_degree
    
    return splat_data
```

**Parameters:**
*   `target_degree`: The maximum SH degree to retain. Typical values are 0, 1, 2, or 3. Value 0 retains only base color (DC). Value 1 retains up to linear terms. [S1, unofficial]

**Edge Cases and Pitfalls:**
*   **Precision:** Truncation is a lossy operation. High-frequency details (specular highlights, sharp shadows) are lost. [S2, unofficial]
*   **Boundary:** If `target_degree` is less than 0, the operation is invalid. [S1, unofficial]
*   **Degenerate Input:** If the splat data has no SH coefficients (degree -1 or 0 stored as empty), truncation to 0 should preserve the base color if present.

## Subtopics

### Monte Carlo Specular Energy Aggregation
A variant approach for reducing SH degree (specifically from 3rd to 1st order) by aggregating the residual energy of higher-order terms into a compact latent representation rather than simply discarding coefficients. It samples $K$ unit direction vectors $d_k$ on the sphere using spherical coordinates: $\phi_k \sim U(0, 2\pi)$, $\theta_k = \arccos(1 - 2\xi_k)$, $\xi_k \sim U(0, 1)$, then converts to Cartesian $d_k = [\sin \theta_k \cos \phi_k, \sin \theta_k \sin \phi_k, \cos \theta_k]$ [S2, unofficial]. It evaluates the photometric residual $c_{res}(d_k) = c_i(d_k) - c^2_i(d_k)$ between the 3rd-order SH radiance $c_i$ and 2nd-order SH radiance $c^2_i$ [S2, unofficial]. The energy magnitude is $E_{mag} = \max(0, c_{res}(d_k))$ and the directional energy is $E_{dir} = \frac{1}{K} \sum_{k=1}^{K} d_k \otimes E_{mag}$ [S2, unofficial]. The Gaussian position $\hat{\mu}$ is normalized via $f(\hat{\mu}) = \hat{\mu}$ if $\|\hat{\mu}\|_2 \le 1$, else $f(\hat{\mu}) = \frac{2-1}{\|\hat{\mu}\|_2} \frac{\hat{\mu}}{\|\hat{\mu}\|_2}$ [S2, unofficial]. A Multi-Layer Perceptron (MLP) $\Psi$ maps the base color $c_{dc}$, $E_{dir}$, and $f(\hat{\mu})$ to first-order SH coefficients $c'$ [S2, unofficial]. This eliminates expensive distillation and reduces SH storage memory overhead compared to 3rd-order baselines, with no per-frame decoding overhead as coefficients are decoded once before inference [S2, unofficial].

## Operating characteristics
*   **Time Complexity:** $O(N \cdot L_{loaded}^2)$ for the truncation step, where $N$ is the number of Gaussians. This is a one-time preprocessing cost.
*   **Memory Complexity:** Reduces memory usage from $O(N \cdot L_{loaded}^2)$ to $O(N \cdot L_{target}^2)$. For example, reducing from degree 3 to 1 reduces coefficient count from 16 to 4 per channel (64% reduction in SH storage).
*   **Measured Performance:** Not given in the sources.
*   **Strengths:** Simple to implement; significant reduction in memory footprint and rendering compute (fewer SH evaluations per ray); deterministic.
*   **Limitations:** Loss of high-frequency visual detail; static reduction cannot adapt to view-dependent complexity.
*   **When to use:** When memory or compute is constrained, and high-frequency specular details are not critical.
*   **When not to use:** When high-fidelity view-dependent effects are required.

## Background
SH Degree Truncation is a standard technique in Gaussian Splatting and radiance field rendering to manage the computational cost of spherical harmonics. It is commonly used in real-time rendering applications where the full degree of SH (often 3 or 4) is too expensive. The method is explicitly mentioned in the context of the LichtFeld-Studio repository [S1, unofficial]. A more advanced variant, Monte Carlo Specular Energy Aggregation, is proposed in Mobile-4DGS to preserve high-frequency details while reducing degree [S2, unofficial].
