# Ray Tracing Backward Pass

Also called: Backward Ray Tracing with Spherical Harmonics, Plenoxel Ray Tracing (Backward), volume_render_cuvol_backward [S1, unofficial][S2, unofficial][S3, unofficial]

## Overview
The Ray Tracing Backward Pass computes the gradients of a differentiable volume rendering loss with respect to the scene representation (spherical harmonic coefficients and density) and auxiliary parameters, given the rendered image and ground truth [S1, unofficial][S2, unofficial]. It serves as the differentiable counterpart to the forward ray casting pass, enabling end-to-end training of volumetric models like Plenoxels [S2, unofficial]. Unlike the forward pass which accumulates color and transmittance, this method propagates error signals backward through the ray integration, handling RGB normalization and optional regularization losses (beta, sparsity) [S1, unofficial][S2, unofficial].

## How it works
**Inputs:**
- `grad_output`: Gradient of the loss with respect to the rendered RGB color (shape: $[N, 3]$ or flattened) [S1, unofficial][S2, unofficial].
- `color_cache`: Cached accumulated color components from the forward pass (shape: $[N, 3]$ or similar structure storing intermediate accumulation terms) [S1, unofficial].
- `ray_spec`: Ray origins and directions [S2, unofficial].
- `grid`: Volumetric grid containing density data and spherical harmonic coefficients [S1, unofficial][S2, unofficial].
- `beta_loss`: Scalar weight for beta distribution sparsity loss [S1, unofficial][S2, unofficial].
- `sparsity_loss`: Scalar weight for sparsity loss [S1, unofficial][S2, unofficial].
- `log_transmit_in`: Logarithm of transmittance at the start of the ray segment [S1, unofficial][S2, unofficial].
- `opt`: Configuration options (e.g., `grad_out_is_rgb`, `basis_dim`, `sh_data_dim`) [S2, unofficial][S3, unofficial].

**Outputs:**
- `grads`: Gradients for spherical harmonic coefficients and density [S1, unofficial][S2, unofficial].
- `accum_out` (optional): Accumulated gradient values [S1, unofficial].
- `log_transmit_out` (optional): Gradient of log transmittance [S1, unofficial].

**Data Structures:**
- `sphfunc_val`: Shared memory array storing spherical harmonic function values for the current ray [S2, unofficial][S3, unofficial].
- `grad_sphfunc_val`: Shared memory array storing gradients of SH function values [S2, unofficial][S3, unofficial].
- `ray_spec`: Struct containing ray origin ($\mathbf{o}$) and direction ($\mathbf{v}$) [S2, unofficial].
- `temp_storage`: Warp-level reduction buffer [S2, unofficial][S3, unofficial].

**Steps:**
1. Compute the initial gradient accumulator `accum` from the color cache and output gradient: `accum = color_cache[0]*grad_output[0] + color_cache[1]*grad_output[1] + color_cache[2]*grad_output[2]` [S1, unofficial].
2. Calculate global thread ID and derive `ray_id`, `ray_blk_id`, and `lane_id` (warp lane index) [S2, unofficial][S3, unofficial]. If `lane_id >= grid.sh_data_dim`, return early, as this thread does not contribute to SH gradient computation [S2, unofficial].
3. If `beta_loss > 0`, compute `transmit_in = exp(log_transmit_in)` and update `beta_loss *= (1 - transmit_in / (1 - transmit_in + 1e-3))`, then add to `accum` [S1, unofficial].
4. Initialize shared memory arrays `sphfunc_val`, `grad_sphfunc_val`, `ray_spec`, and `temp_storage` for warp reduction [S2, unofficial].
5. Set `ray_spec` from origins and directions, extracting the direction vector $\mathbf{v}_{\text{dir}}$ [S2, unofficial].
6. If `ray.tmin > ray.tmax`, the ray is invalid. Write `accum` to `*accum_out` (if not null) and `0` to `*log_transmit_out` (if not null), then return [S1, unofficial].
7. Compute gradient output: if `grad_out_is_rgb`, calculate `resid = color_cache - grad_output`, then `grad_out[i] = resid * norm_factor` where `norm_factor = 2.f / (3 * Q)`; otherwise `grad_out[i] = grad_output[i]` [S2, unofficial][S3, unofficial].
8. Synchronize warps within the SH data dimension mask to ensure shared memory consistency [S2, unofficial][S3, unofficial].
9. Call `trace_ray_cuvol_backward` with `grad_out`, `color_cache`, `ray_spec`, `opt`, `lane_id`, `sphfunc_val`, `grad_sphfunc_val`, `temp_storage`, `log_transmit_in`, `beta_loss`, `sparsity_loss`, `grads`, and optional output pointers [S2, unofficial][S3, unofficial]. This function performs the core integration of gradients along the ray, interpolating density and SH coefficients, and computing gradients for the grid parameters [S1, unofficial].
10. Call `calc_sphfunc_backward` to compute the gradients for the spherical harmonic basis coefficients based on the accumulated gradients in `grad_sphfunc_val` [S2, unofficial][S3, unofficial].

**Pseudocode:**
```python
def render_ray_backward_kernel(
    grad_output,      # Tensor [N, 3]
    color_cache,      # Tensor [N, 3]
    ray_spec,         # Struct with origin, direction, tmin, tmax
    grid,             # Object with density_data, sh_coeffs, sh_data_dim, basis_dim
    beta_loss,        # Float
    sparsity_loss,    # Float
    log_transmit_in,  # Float
    opt,              # Struct with grad_out_is_rgb, sh_data_dim, etc.
    accum_out,        # Optional pointer/tensor
    log_transmit_out  # Optional pointer/tensor
):
    # 1. Initialize Accumulation
    accum = 0.0
    for i in range(3):
        accum += color_cache[i] * grad_output[i]

    # 2. Thread Identification
    # Derived from global thread ID: ray_id = tid >> 5, ray_blk_id = thread_id >> 5, lane_id = thread_id & 0x1F
    lane_id = thread_id & 0x1F
    if lane_id >= grid.sh_data_dim:
        return

    # 3. Beta Loss Gradient
    if beta_loss > 0.0:
        transmit_in = exp(log_transmit_in)
        beta_grad = beta_loss * (1.0 - transmit_in / (1.0 - transmit_in + 1e-3))
        accum += beta_grad

    # 4. Shared Memory Init
    # Layout: sphfunc_val[RAY_PER_BLOCK][9], grad_sphfunc_val[RAY_PER_BLOCK][9], ray_spec[RAY_PER_BLOCK], temp_storage[RAY_PER_BLOCK]
    sphfunc_val = [0.0] * grid.basis_dim
    grad_sphfunc_val = [0.0] * grid.basis_dim
    temp_storage = [0.0] * 32  # Warp reduction buffer

    # 5. Ray Setup
    vdir = ray_spec.direction

    # 6. Degenerate Ray Check
    if ray_spec.tmin > ray_spec.tmax:
        if accum_out is not None:
            accum_out[0] = accum
        if log_transmit_out is not None:
            log_transmit_out[0] = 0.0
        return

    # 7. Gradient Output Normalization
    if opt.grad_out_is_rgb:
        resid = [color_cache[i] - grad_output[i] for i in range(3)]
        norm_factor = 2.0 / (3.0 * Q)
        grad_out = [r * norm_factor for r in resid]
    else:
        grad_out = grad_output

    # 8. Warp Sync
    # Synchronize threads in the warp based on the SH data dimension mask
    # (CUDA __syncwarp primitive)

    # 9. Core Backward Trace
    # Sources do not provide the internal implementation of this function.
    # It performs trilinear interpolation of density and SH values,
    # and accumulation of gradients along the ray.
    trace_ray_cuvol_backward(
        grid=grid,
        grad_out=grad_out,
        color_cache=color_cache,
        ray_spec=ray_spec,
        opt=opt,
        lane_id=lane_id,
        sphfunc_val=sphfunc_val,
        grad_sphfunc_val=grad_sphfunc_val,
        temp_storage=temp_storage,
        log_transmit_in=log_transmit_in,
        beta_loss=beta_loss,
        sparsity_loss=sparsity_loss,
        grads=grid.grads,
        accum_out=accum_out,
        log_transmit_out=log_transmit_out
    )

    # 10. SH Gradient Computation
    # Sources do not provide the internal implementation of this function.
    # It computes gradients for the spherical harmonic basis coefficients based on
    # the accumulated gradients in grad_sphfunc_val.
    calc_sphfunc_backward(
        grid=grid,
        lane_id=lane_id,
        ray_id=ray_id,
        vdir=vdir,
        sphfunc_val=sphfunc_val,
        grad_sphfunc_val=grad_sphfunc_val,
        grad_basis_out=grid.grads.grad_basis_out
    )
```

**Parameters:**
- `beta_loss`: Scalar weight for beta distribution sparsity loss. If $> 0$, gradient contribution is added to `accum` [S1, unofficial][S2, unofficial].
- `sparsity_loss`: Scalar weight for sparsity loss. Passed to `trace_ray_cuvol_backward` [S1, unofficial][S2, unofficial].
- `Q`: Scaling factor used in RGB normalization [S2, unofficial][S3, unofficial].

**Edge Cases:**
- If `ray.tmin > ray.tmax`, the kernel returns early, writing zero to `log_transmit_out` [S1, unofficial].
- Numerical stability is handled by adding $\epsilon = 10^{-3}$ in the beta loss denominator [S1, unofficial].

## Subtopics

### [Background Rendering Backward Pass](5974-background-rendering-backward-pass.md)
The Background Rendering Backward Pass computes the gradients of the loss with respect to the background volumetric field (typically a sparse grid of spherical harmonic coefficients or density values) and the accumulated transmittance, given the rendered background color, ground truth, and ray parameters. It serves as the differentiable counterpart to the concentric sphere sampling and trilinear interpolation used in the forward background rendering pass. Unlike the foreground ray casting which traverses a dense or sparse voxel grid, this method specifically handles the unbounded background field, often using a separate sparse grid structure. It is distinct from the general Ray Tracing Backward Pass by isolating the gradient computation for the background component, allowing for specialized handling of RGB normalization and sparsity regularization specific to the background layer.

## Background
The Ray Tracing Backward Pass is part of the svox2 library, developed by Alex Yu and others. [S2, unofficial] It is designed to support differentiable volume rendering with spherical harmonics, enabling efficient training of neural radiance fields and related representations. [S2, unofficial] The method is integrated into the NeRF-Factory framework by POSTECH, KAIST, and Kakao Brain Corp. [S1, unofficial]
