# Spherical Harmonics Raycaster (Shell Density)

Also called: SH Shell Volume Rendering, Shell Density Raycasting

## Overview
A volumetric raycasting method that renders a shell-shaped density field defined by spherical harmonics (specifically $Y_{l3,m0}$), using additive color accumulation, normalization, and saturation-based early termination [S1, unofficial]. It differs from general SH volume rendering by restricting the density function to a specific harmonic degree and using a binary shell thickness model rather than continuous density gradients [S1, unofficial].

## How it works
**Inputs and Outputs:**
*   **Inputs:** Camera position (`camPos`), ray direction (`rayDirection`), ray start distance (`startT`), ray end distance (`endT`), step size (`stepSize`), shell thickness (`thickness`), saturation threshold (`saturationThreshold`).
*   **Outputs:** Final color (`finalColor`), a `float4` with normalized RGB and alpha=1.0.

**Data Structures:**
*   `finalColor`: `float4` (R, G, B, A).
*   `location`: `float3` representing the current ray position.
*   `current_t`: `float` representing the current distance along the ray.
*   `isSaturated`: `bool` flag for early termination.

**Spherical Harmonics Definitions:**
The density field is based on the spherical harmonic $Y_{l3,m0}$. The general form for $Y_{l,0}$ depends on the polar angle $\theta$. The specific functions used are [S1, unofficial]:

$$ Y_{l1,m0}(\theta) = \frac{1}{2} \sqrt{\frac{3}{\pi}} \cos(\theta) $$

$$ Y_{l2,m0}(\theta) = \frac{1}{4} \sqrt{\frac{5}{\pi}} (3\cos^2(\theta) - 1) $$

$$ Y_{l3,m0}(\theta) = \frac{1}{4} \sqrt{\frac{7}{\pi}} (5\cos^3(\theta) - 3\cos(\theta)) $$

**Parameters:**
*   `thickness`: `float`, default `0.4f`. Defines the radial thickness of the shell around the $Y_{l3,m0}$ surface [S1, unofficial].
*   `saturationThreshold`: `int` (used as float comparison), default `0`. Used to stop raymarching when any RGB channel exceeds this value [S1, unofficial].

**Algorithm Steps:**
1.  Initialize `finalColor` to `(0, 0, 0, 0)`.
2.  Initialize `location` to `camPos + startT * rayDirection`.
3.  Initialize `current_t` to `startT`.
4.  Initialize `isSaturated` to `false`.
5.  Loop while `current_t < endT` and `!isSaturated`:
    a. Update `location` by adding `stepSize * rayDirection`.
    b. Increment `current_t` by `stepSize`.
    c. Check if `location` is inside the rendering extent (bounding box/sphere). If not, continue to next iteration.
    d. Transform `location` to spherical coordinates $(r, \theta, \phi)$:
        $$ r = \| \text{location} \| $$
        $$ \theta = \arccos\left(\frac{\text{location}.z}{r}\right) $$
        $$ \phi = \operatorname{atan2}(\text{location}.y, \text{location}.x) $$
    e. Compute the harmonic value: `val` = $Y_{l3,m0}(\theta)$.
    f. Compute density using `densityFunc(val, thickness)`:
        $$ \text{density} = \begin{cases} \operatorname{sign}(\text{val}) & \text{if } |2|\text{val}| - r| < \text{thickness} \\ 0 & \text{otherwise} \end{cases} $$
        *Note: The source formula `|2*|val| - r| < thickness` is interpreted as the condition for being inside the shell. The term `2*|val|` likely refers to a scaling factor or specific implementation detail where the harmonic value is scaled. Given the standard definition, `val` is the harmonic value. The condition checks if the point is within `thickness` of the surface defined by the harmonic. However, the source explicitly states `val = Y_l3_m0(theta)` and the condition `|2*|val| - r| < thickness`. This implies the shell surface is defined by $r = 2|Y_{l3,m0}(\theta)|$. We follow the source literally.*
    g. Compute color using `colorFunc(density)`:
        *   If `density > 0`: return `float4(0, 0, 1, 1)` (Blue).
        *   If `density < 0`: return `float4(1, 1, 0, 1)` (Yellow).
        *   Else: return `float4(0, 0, 0, 1)` (Black).
    h. Add computed color to `finalColor`: `finalColor += color`.
    i. Check saturation:
        $$ \text{isSaturated} = (\text{finalColor}.R > \text{saturationThreshold}) \lor (\text{finalColor}.G > \text{saturationThreshold}) \lor (\text{finalColor}.B > \text{saturationThreshold}) $$
6.  Normalize `finalColor`:
    $$ \text{normalizer} = \max(1.0f, \max(\text{finalColor}.R, \max(\text{finalColor}.G, \text{finalColor}.B))) $$
    $$ \text{finalColor} = \text{finalColor} / \text{normalizer} $$
    $$ \text{finalColor}.A = 1.0f $$
7.  Return `finalColor`.

**Pseudocode:**

```python
import math

def spherical_harmonic_l3_m0(theta):
    """
    Computes Y_l3_m0(theta) = (1/4) * sqrt(7/pi) * (5*cos^3(theta) - 3*cos(theta))
    """
    cos_theta = math.cos(theta)
    return 0.25 * math.sqrt(7.0 / math.pi) * (5.0 * cos_theta**3 - 3.0 * cos_theta)

def density_func(val, r, thickness):
    """
    Computes density based on the shell condition.
    Shell surface is defined by r = 2 * |val|.
    """
    # Condition from source: |2*|val| - r| < thickness
    if abs(2.0 * abs(val) - r) < thickness:
        return math.copysign(1.0, val) # sign(val)
    return 0.0

def color_func(density):
    """
    Returns color based on density sign.
    """
    if density > 0:
        return (0.0, 0.0, 1.0, 1.0) # Blue
    elif density < 0:
        return (1.0, 1.0, 0.0, 1.0) # Yellow
    else:
        return (0.0, 0.0, 0.0, 1.0) # Black

def raycast(cam_pos, ray_dir, start_t, end_t, step_size, thickness, saturation_threshold):
    """
    Renders the SH Shell Volume.
    """
    final_color = [0.0, 0.0, 0.0, 0.0]
    location = [
        cam_pos[0] + start_t * ray_dir[0],
        cam_pos[1] + start_t * ray_dir[1],
        cam_pos[2] + start_t * ray_dir[2]
    ]
    current_t = start_t
    is_saturated = False
    
    # Note: 'isInside(extent, location)' check is assumed to be handled by 
    # the caller or a bounding volume check. For this implementation, 
    # we assume the ray is already within the extent or the check is implicit.
    # If the source implies a bounding box, it is not specified. 
    # We proceed with the spherical coordinate conversion which assumes 
    # the point is valid.
    
    while current_t < end_t and not is_saturated:
        # Update location
        location = [
            location[0] + step_size * ray_dir[0],
            location[1] + step_size * ray_dir[1],
            location[2] + step_size * ray_dir[2]
        ]
        current_t += step_size
        
        # Convert to spherical coordinates
        r = math.sqrt(location[0]**2 + location[1]**2 + location[2]**2)
        
        # Avoid division by zero
        if r == 0:
            continue
            
        theta = math.acos(location[2] / r)
        phi = math.atan2(location[1], location[0])
        
        # Compute harmonic value
        val = spherical_harmonic_l3_m0(theta)
        
        # Compute density
        density = density_func(val, r, thickness)
        
        # Compute color
        color = color_func(density)
        
        # Additive accumulation
        final_color[0] += color[0]
        final_color[1] += color[1]
        final_color[2] += color[2]
        # Alpha is not accumulated in the loop, only normalized at the end
        
        # Check saturation
        if (final_color[0] > saturation_threshold or 
            final_color[1] > saturation_threshold or 
            final_color[2] > saturation_threshold):
            is_saturated = True
            
    # Normalize
    max_val = max(1.0, max(final_color[0], max(final_color[1], final_color[2])))
    final_color[0] /= max_val
    final_color[1] /= max_val
    final_color[2] /= max_val
    final_color[3] = 1.0
    
    return final_color
```

**Edge Cases and Pitfalls:**
*   **Camera Inside Sphere:** If the camera is inside the sphere and the ray intersects the sphere boundary at `t1 > 0` but `t0 <= 0`, the raymarch should start at `t=0.0` instead of `t0` [S1, unofficial].
*   **Zero Radius:** If `r=0` (camera at origin), `acos` is undefined. The code should handle this by skipping or returning a default value [G].
*   **Precision:** Floating point precision in `acos` and `atan2` can affect the shell boundary detection.

## Operating characteristics
*   **Time Complexity:** $O(N)$ where $N$ is the number of steps along the ray. Early termination via saturation can reduce this.
*   **Memory Complexity:** $O(1)$ per ray. No large data structures are stored per pixel.
*   **Strengths:** Simple implementation, fast evaluation of the density function, early termination improves performance for opaque regions.
*   **Limitations:** Limited to a specific harmonic shape ($Y_{l3,m0}$), additive blending does not account for occlusion in the traditional sense (no alpha compositing with background), saturation threshold is a crude early termination method.
*   **When to use:** When a specific shell-like volumetric effect is desired and performance is critical.
*   **When not to use:** When complex lighting, occlusion, or arbitrary density fields are required.

## Background
This method is derived from the `VolumetricRayCasting-GL` repository by Balázs Banto [S1, unofficial]. It is part of a broader set of techniques for volumetric rendering using spherical harmonics. The specific use of $Y_{l3,m0}$ for shell density is a specialized application within this framework.
