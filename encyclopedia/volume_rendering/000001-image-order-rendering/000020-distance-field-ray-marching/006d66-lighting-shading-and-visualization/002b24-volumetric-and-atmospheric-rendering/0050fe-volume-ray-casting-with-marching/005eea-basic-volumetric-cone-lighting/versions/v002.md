# Basic Volumetric Cone Lighting

Also called: First light ray, Volumetric raymarching loop, Depth-Based Stopping, Scene depth culling

## Overview
Basic Volumetric Cone Lighting is a post-processing technique that renders a volumetric light beam shaped like a cone originating from a light position and pointing in a specific direction, using screen-space raymarching [S1, unofficial]. It solves the problem of rendering visible light shafts in real-time by accumulating light density along rays cast from the camera into the scene [S1, unofficial].

## How it works
**Inputs and Outputs:**
*   **Inputs:** `inputColor` (current frame buffer color), `uv` (screen coordinates), `depthBuffer` (scene depth texture), `cameraPosition` (world space), `cameraFar` (max render distance), `lightPosition` (world space), `lightDirection` (normalized world space vector), `coneAngle` (aperture in degrees), `STEP_SIZE` (march increment), `NUM_STEPS` (loop count) [S1, unofficial].
*   **Outputs:** `outputColor` (final pixel color) [S1, unofficial].

**Data Structures:**
*   `depthBuffer`: Texture containing depth values for each pixel [S1, unofficial].
*   `projectionMatrixInverse`: Inverse of the camera's projection matrix, used to convert coordinates from clip-space to view-space [S1, unofficial].
*   `viewMatrixInverse`: Inverse of the camera's view matrix (world matrix), used to convert coordinates from view-space to world-space [S1, unofficial].

**Pseudocode:**
```python
def mainImage(inputColor, uv, depthBuffer, cameraFar, projectionMatrixInverse, viewMatrixInverse, cameraPosition, lightPosition, lightDirection, coneAngle, STEP_SIZE, NUM_STEPS):
    # 1. Sample depth and reconstruct world position
    depth = readDepth(depthBuffer, uv)
    worldPosition = getWorldPosition(uv, depth, projectionMatrixInverse, viewMatrixInverse)
    
    # 2. Define ray parameters
    rayOrigin = cameraPosition
    rayDir = normalize(worldPosition - rayOrigin)
    lightPos = lightPosition
    lightDir = normalize(lightDirection)
    
    # 3. Calculate scene depth for culling
    sceneDepth = length(worldPosition - cameraPosition)
    
    # 4. Initialize lighting variables
    coneAngleRad = radians(coneAngle)
    halfConeAngleRad = coneAngleRad * 0.5
    fogAmount = 0.0
    lightIntensity = 1.0
    t = STEP_SIZE
    
    # 5. Raymarching loop
    for i in range(NUM_STEPS):
        # Calculate current sample position
        samplePos = rayOrigin + rayDir * t
        
        # Depth-based stopping: break if beyond scene geometry or camera far plane
        if t > sceneDepth or t > cameraFar:
            break
            
        # Cone shape check: calculate angle between sample-to-light vector and light direction
        toSample = normalize(samplePos - lightPos)
        cosAngle = dot(toSample, lightDir)
        
        # Skip samples outside the cone aperture
        if cosAngle < cos(halfConeAngleRad):
            t += STEP_SIZE
            continue
            
        # Attenuation based on distance to light source
        distanceToLight = length(samplePos - lightPos)
        attenuation = exp(-0.05 * distanceToLight)
        
        # Accumulate light
        fogAmount += attenuation * lightIntensity
        
        # Advance ray
        t += STEP_SIZE
        
    # 6. Combine with input color
    outputColor = inputColor + fogAmount
    return outputColor

def readDepth(depthBuffer, uv):
    return depthBuffer[uv]

def getWorldPosition(uv, depth, projectionMatrixInverse, viewMatrixInverse):
    clip_x = uv[0] * 2.0 - 1.0
    clip_y = uv[1] * 2.0 - 1.0
    clip_y = -clip_y
    view_space = [clip_x, clip_y, -1.0, 1.0]
    view_space = mat_mul(projectionMatrixInverse, view_space)
    view_space = [v / view_space[3] for v in view_space[:3]]
    world_space = mat_mul(viewMatrixInverse, [view_space[0], view_space[1], view_space[2], 1.0])
    return (world_space[0], world_space[1], world_space[2])

def mat_mul(matrix, vector):
    return tuple(sum(matrix[r][c] * vector[c] for c in range(4)) for r in range(4))

def normalize(v):
    mag = length(v)
    return (v[0]/mag, v[1]/mag, v[2]/mag)

def length(v):
    return (v[0]**2 + v[1]**2 + v[2]**2)**0.5

def dot(a, b):
    return a[0]*b[0] + a[1]*b[1] + a[2]*b[2]

import math
def radians(deg): return deg * math.pi / 180.0
def cos(x): return math.cos(x)
def exp(x): return math.exp(x)
```

**Parameters:**
*   `cameraFar`: Depth limit beyond which nothing is visible or rendered [S1, unofficial].
*   `coneAngle`: Represents how wide the spotlight aperture is [S1, unofficial].
*   `STEP_SIZE`: Step size for raymarching [S1, unofficial].
*   `NUM_STEPS`: Number of steps in the raymarching loop [S1, unofficial].
*   `0.05`: Exponential decay constant for light attenuation [S1, unofficial].

**Edge Cases and Pitfalls:**
*   **Through-wall leakage:** Without depth-based stopping, the light ray continues marching beyond visible geometry, causing light to appear through walls and objects, breaking realism and wasting performance on intensive raymarching beyond visible areas [S1, unofficial].

## Background
The technique is described in "On Shaping Light: Real-Time Volumetric Lighting with Post-Processing and Raymarching" by Maxime Heckel, which details the implementation of volumetric lighting effects using raymarching in fragment shaders [S1, unofficial]. The method builds on the principles of screen-space raymarching and depth buffer reconstruction [S1, unofficial].
