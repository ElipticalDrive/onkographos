# Linear Depth Cueing

Also called: Atmospheric Attenuation Depth Cuing, Color attenuation, Depth-based Attenuation, depth cuing

## Overview
Linear Depth Cueing is a technique to simulate atmospheric attenuation, blending the colors of distant objects with a background color to indicate distance and enhance depth perception [S1, S2]. It differs from [Exponential Depth Cueing](3708-exponential-depth-cueing.md) by using a linear interpolation factor based on depth rather than an exponential decay function.

## How it works
**Inputs and Outputs:**
*   **Inputs:** Original color intensity $I$, background color intensity $I_{bg}$, current fragment depth $z$, maximum scene depth $z_{\max}$, and a depth cueing parameter `depth` [S1].
*   **Outputs:** Modified color intensity $I'$ [S1].

**Data Structures:**
No specific complex data structures are required beyond standard scalar values for depth and color components. The implementation relies on computing a scalar blending factor $s$ [S1].

**Steps:**
1.  Determine the maximum depth $z_{\max}$ for the scene [S1].
2.  For each fragment at depth $z$, calculate the blending factor $s$ using the linear formula [S1]:
    $$s = \frac{1 + \text{depth} \times z}{1 + z_{\max}}$$
3.  Compute the final color intensity $I'$ by blending the original intensity $I$ with the background intensity $I_{bg}$ using $s$ [S1]:
    $$I' = sI + (1 - s)I_{bg}$$

**Parameters:**
*   `depth`: A non-zero argument specifying whether depth cuing is used. If zero, attenuation is not applied [S1]. Typical values observed in examples include 0.3 [S1].
*   $z_{\max}$: The maximal z-value in the scene, computed by the rendering code [S1].

**Edge Cases and Pitfalls:**
*   If `depth` is zero, the blending factor $s$ becomes $\frac{1}{1 + z_{\max}}$, which may not result in the expected "no cueing" behavior if the formula is applied blindly without a conditional check. The source implies a conditional: "if depth is non-zero then... sets [formula]" [S1].
*   Precision issues may arise if $z_{\max}$ is very large or very small relative to $z$ and `depth`.
*   The method assumes $z$ and $z_{\max}$ are in the same coordinate system [S1].

**Pseudocode:**
```python
def linear_depth_cueing(I, I_bg, z, z_max, depth_param):
    """
    Applies linear depth cueing to a color intensity.
    
    Args:
        I: Original color intensity (scalar or vector).
        I_bg: Background color intensity.
        z: Current fragment depth.
        z_max: Maximum depth in the scene.
        depth_param: Depth cueing strength parameter.
        
    Returns:
        Modified color intensity.
    """
    # If depth_param is zero, no cueing is applied [S1]
    if depth_param == 0:
        return I
    
    # Calculate blending factor s [S1]
    s = (1 + depth_param * z) / (1 + z_max)
    
    # Blend original intensity with background intensity [S1]
    I_prime = s * I + (1 - s) * I_bg
    
    return I_prime
```

## Subtopics

### Exponential Depth Cueing
Uses an exponential function for non-linear depth progression, offering different visual characteristics than linear blending. See [Exponential Depth Cueing](3708-exponential-depth-cueing.md).

## Operating characteristics
*   **Time Complexity:** $O(1)$ per fragment for the color blending calculation [S1].
*   **Memory Complexity:** $O(1)$ additional memory for storing $z_{\max}$ and the blending factor [S1].
*   **Strengths:** Simple to implement; effectively simulates atmospheric haze or fog to enhance depth perception [S1, S2].
*   **Limitations:** Linear progression may not accurately model real-world atmospheric scattering, which is often exponential [S1, S2]. Performance impact is negligible [S1].
*   **When to use:** When a simple, computationally inexpensive method is needed to enhance depth perception in volume or surface rendering [S1, S2].
*   **When not to use:** When high-fidelity atmospheric scattering is required, or when the scene depth range is extremely large, making linear interpolation less perceptually accurate [S1, S2].

## Background
Linear Depth Cueing was introduced in the context of computing and displaying isosurfaces in R, specifically for visualizing elevation data such as the Maunga Whau volcano [S1]. It is also discussed in the context of dense geometric flow visualization, where it is combined with desaturation and darkening techniques to enhance depth perception in vector field data [S2].
