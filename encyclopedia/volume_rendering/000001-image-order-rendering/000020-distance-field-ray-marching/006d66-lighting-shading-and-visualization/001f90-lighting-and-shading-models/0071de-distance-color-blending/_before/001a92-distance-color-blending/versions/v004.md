# Distance Color Blending

Also called: Depth encoding, Depth-Based Shading, Depth-Cued Colors, Exponential fog, Intensity Depth-Cuing, Intensity and color based depth queues, Linear color blending fog, aerial perspective

## Overview
Distance Color Blending is a shading technique that enhances depth perception in volume rendering by dimming distant voxels and shifting their color toward a background hue, simulating aerial perspective [S2, S6][S7, unofficial]. It solves the problem of foreground/background distinction in dense volumetric data by applying a non-linear transparency falloff based on normalized depth [S1, unofficial]. Unlike simple intensity depth-cuing which only reduces brightness, this method modulates the color spectrum (typically adding blue) to exploit the human visual tendency for cool colors to recede [S2][S7, unofficial]. It is distinct from [Ambient Occlusion via SDF](1631-ambient-occlusion-via-sdf.md) as it relies on view-dependent distance rather than local geometric curvature, and from [Multi-Layer Shading / OmniShader](2511-multi-layer-shading-omnishader.md) by being a post-compositing or per-sample color modulation rather than a complex multi-pass lighting integration.

## How it works
**Inputs:**
- $c_v$: The original voxel color (RGB) at the current sample point.
- $c_b$: The background color (RGB), typically a shade of blue or gray.
- $d_v$: The fractional distance of the sample through the volume, normalized to $[0, 1]$.
- $k_{ds}$: The size/magnitude of the blending effect (default 1.0) [S6][S7, unofficial].
- $k_{de}$: The rate of application (exponent) for the depth falloff (default 0.5) [S6][S7, unofficial].

**Outputs:**
- $c_d$: The final depth-cued color (RGB).

**Data Structures:**
No specific complex data structures are required beyond the standard ray-marching state (current position, accumulated color, step size). The fractional depth $d_v$ is maintained as a scalar accumulator.

**Steps:**
1. **Calculate Fractional Depth:** Determine the total length of the ray segment traversing the volume ($L_{total}$) and the current distance traveled from the camera origin ($L_{current}$). Compute $d_v = L_{current} / L_{total}$. If the total length is zero, set $d_v = 0$ [G].
2. **Compute Blending Factor:** Calculate the blending weight $B$ using the exponential power function:
   $$ B = k_{ds} \cdot d_v^{k_{de}} $$
   Clamp $B$ to the range $[0, 1]$ to prevent overflow or negative values due to precision errors [G].
3. **Blend Colors:** Interpolate between the original voxel color $c_v$ and the background color $c_b$ using $B$:
   $$ c_d = (1 - B) c_v + B c_b $$
4. **Output:** Use $c_d$ as the color contribution for the current sample in the volume integration loop.

**Pseudocode:**
```python
def distance_color_blending(c_v, c_b, d_v, k_ds=1.0, k_de=0.5):
    """
    Applies distance color blending to a voxel color.
    
    Args:
        c_v: vec3, original voxel color.
        c_b: vec3, background color (e.g., blue or gray).
        d_v: float, fractional distance through volume [0.0, 1.0].
        k_ds: float, magnitude of blending effect.
        k_de: float, exponent for depth falloff.
        
    Returns:
        vec3, the depth-cued color.
    """
    # Calculate blending factor B = k_ds * d_v ^ k_de
    # Clamp d_v to [0, 1] to handle edge cases where ray extends slightly beyond bounds
    d_v_clamped = max(0.0, min(1.0, d_v))
    
    # Compute B
    B = k_ds * (d_v_clamped ** k_de)
    
    # Clamp B to [0, 1]
    B = max(0.0, min(1.0, B))
    
    # Blend colors: c_d = (1 - B) * c_v + B * c_b
    c_d = (1.0 - B) * c_v + B * c_b
    
    return c_d
```

**Parameters:**
- $k_{ds}$: Controls the size of the color blending effect. Typical value: 1.0 [S6][S7, unofficial].
- $k_{de}$: Controls the rate of application of color blending. Typical value: 0.5 [S6][S7, unofficial].
- $c_b$: Background color. If $c_b$ is a shade of gray ($a, a, a$), only intensity depth-cuing (dimming) occurs. If $c_b$ is blue-shifted ($a, b, c$ with $c > a, b$), it introduces a cool shift in distant regions [S6][S7, unofficial]. Example: $c_b = (0, 0, 0.15)$ [S7, unofficial].

**Edge Cases and Pitfalls:**
- **Hard Transfer Functions:** This technique avoids the information loss associated with hard transfer functions by modulating existing colors rather than masking them [S6].
- **Precision:** Ensure $d_v$ is correctly normalized. If the ray does not fully traverse the volume (e.g., clipped by near/far planes), $d_v$ should reflect the fraction of the *visible* segment or the absolute distance relative to a global max depth, depending on implementation [S10, unofficial].
- **Color Perception:** Using a non-gray background color significantly alters the perceived depth. A blue background simulates atmospheric haze, while a gray background only simulates fog density [S7, unofficial].

## Subtopics

### [Exponential Depth Cueing](3708-exponential-depth-cueing.md)
Exponential Depth Cueing is a shading technique that simulates atmospheric fog to enhance depth perception in volume rendering by dimming distant voxels. It solves the problem of foreground/background distinction in dense volumetric data by applying a non-linear transparency falloff based on normalized depth. Unlike linear cueing, it uses an exponential function to control how rapidly objects recede into darkness, allowing for more natural aerial perspective effects. See [Exponential Depth Cueing](3708-exponential-depth-cueing.md).

### Linear Depth Cueing
A technique to simulate atmospheric attenuation as depth cuing, blending colors of distant objects with the background color to indicate distance [S11]. The blending factor $s$ is calculated as:
$$ s = \frac{1 + \text{depth} \times z}{1 + z_{\max}} $$
where `depth` is the attenuation parameter, $z$ is the z-value of the fragment, and $z_{\max}$ is the maximal z-value in the scene [S11]. The final color intensity $I$ is modified to:
$$ sI + (1 - s)I_{bg} $$
where $I$ is the original intensity and $I_{bg}$ is the background color intensity [S11]. This method is simpler but less perceptually accurate than exponential variants for large depth ranges [S10, unofficial].

### Pseudo Chromadepth
A color modification technique based on the eye's lens refracting colored light at different angles to enhance depth perception in angiography images [S12, unofficial]. It assigns reddish tones to closer objects and blueish tones to further ones, leveraging the chromatic aberration of the human eye [S12, unofficial].

## Operating characteristics
**Time and Memory Complexity:**
The time complexity of the blending calculation is $O(1)$ per sample, as it involves only basic arithmetic operations (power, multiplication, addition) [S10, unofficial]. The memory complexity is $O(1)$ as no additional buffers are required beyond the standard ray-marching state [S10, unofficial].

**Measured Performance:**
Performance is independent of the number of light sources and geometry complexity, depending only on the resolution of the input image or the number of volume samples [S10, unofficial]. It is highly efficient and suitable for real-time rendering [S10, unofficial].

**Strengths and Limitations:**
- **Strengths:** Enhances depth perception significantly with minimal computational cost; avoids the "flat" look of un-cued volumes; works well with any lighting model [S6][S7, unofficial].
- **Limitations:** It is an empirical approximation and does not simulate true physical light scattering (participating media) [S10, unofficial]. The effect is view-dependent and may not accurately represent the physical density of the volume [S10, unofficial].

**When to Use:**
Use when depth perception is critical and computational resources are limited, or when a stylized "aerial perspective" look is desired [S2][S7, unofficial].

**When Not to Use:**
Do not use when physically accurate light transport (e.g., volumetric shadows, scattering) is required, as this method only modulates color and intensity [S10, unofficial].

## Background
Distance Color Blending is an extension of intensity depth-cuing, a technique documented by Segal and Akeley in the specification of the first version of OpenGL [S10, unofficial]. It was adapted for volume rendering by Interrante et al. to enhance the perception of depth in medical and scientific visualization [S6][S7, unofficial]. The method relies on the artistic principle of aerial perspective, where distant objects appear cooler and less saturated, a technique used by painters for centuries [S7, unofficial]. It is commonly used in medical imaging (e.g., OCT, CT) to distinguish overlapping structures [S2][S7, unofficial].
