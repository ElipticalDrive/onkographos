# Tri-Planar Mapping with Centroid Normals

Also called: Tri-Planar-Mapping mit Zentroid-Normalen, Triplanar Mapping for Voxel Texturing, Voxel Texturing, Voxel-Texturierung mit Einheitskreis-Normalen

## Overview
This method applies tri-planar texture projection to voxel-based geometry while replacing standard face-aligned normals with normals derived from the voxel's centroid [S1, unofficial]. It solves the problem of hard edges and texture discontinuities that occur when distinct 2D texture slices are mapped to the six faces of a voxel cube [S1, unofficial]. By using centroid-based normals, the method creates smooth material transitions and avoids the visible seams inherent in standard AABB texturing [S1, unofficial]. It differs from standard tri-planar mapping by dynamically computing the projection weights based on the geometric relationship between the ray intersection point and the voxel center, rather than relying on pre-computed or face-averaged normals [S1, unofficial].

## How it works
**Inputs:** Ray origin $O$, direction $D$, voxel center $C$, voxel size $s$, texture resolution $R$, texture sampling function $T(u,v)$ [G].
**Outputs:** Albedo color $C_{albedo}$ and normal vector $N_{new}$ [G].
**Data Structures:** Standard ray-marching state; voxel center $C$ is derived from integer coordinates $(i,j,k)$ and size $s$ as $C = (i + 0.5, j + 0.5, k + 0.5) \times s$ [G].

**Steps:**
1. **Ray-Voxel Intersection:** Determine the intersection point $P$ of the ray with the voxel surface using a standard slab method [G].
2. **Compute Centroid Normal:** Calculate the vector from the voxel center $C$ to the intersection point $P$ [S1, unofficial]. Normalize this vector to obtain the new normal $N_{new}$:
   $$ V = P - C $$
   $$ N_{new} = \frac{V}{\|V\|} $$
   This normal points radially outward from the voxel center, effectively approximating a sphere-like surface within the cubic voxel [S1, unofficial].
3. **Tri-Planar Projection Weights:** Compute the absolute components of $N_{new}$ to determine the blending weights for the three projection planes (XY, XZ, YZ):
   $$ w_x = |N_{new}.x| $$
   $$ w_y = |N_{new}.y| $$
   $$ w_z = |N_{new}.z| $$
   Normalize the weights to ensure they sum to 1.0:
   $$ W = w_x + w_y + w_z $$
   $$ w_x \leftarrow \frac{w_x}{W}, \quad w_y \leftarrow \frac{w_y}{W}, \quad w_z \leftarrow \frac{w_z}{W} $$
   [G] If $W$ is zero (degenerate case where $P=C$), default to $w_x=1/3, w_y=1/3, w_z=1/3$.
4. **Texture Coordinate Generation:** Generate 2D texture coordinates for each plane based on the intersection point $P$ and the voxel size $s$ [G]. For a voxel at integer coordinates $(i,j,k)$, the local position is $P_{local} = P - C$ [G]. The coordinates are:
   - XY Plane (projected along Z): $u_{xy} = \frac{P_{local}.x + h}{2h} \times R$, $v_{xy} = \frac{P_{local}.y + h}{2h} \times R$ [G]
   - XZ Plane (projected along Y): $u_{xz} = \frac{P_{local}.x + h}{2h} \times R$, $v_{xz} = \frac{-P_{local}.z + h}{2h} \times R$ [G]
   - YZ Plane (projected along X): $u_{yz} = \frac{-P_{local}.y + h}{2h} \times R$, $v_{yz} = \frac{P_{local}.z + h}{2h} \times R$ [G]
   [G] Ensure coordinates are clamped or wrapped appropriately for texture sampling.
5. **Texture Sampling:** Sample the texture for each plane:
   $$ C_{xy} = T(u_{xy}, v_{xy}) $$
   $$ C_{xz} = T(u_{xz}, v_{xz}) $$
   $$ C_{yz} = T(u_{yz}, v_{yz}) $$
6. **Blend Colors:** Combine the sampled colors using the weights:
   $$ C_{albedo} = w_x C_{xy} + w_y C_{xz} + w_z C_{yz} $$
7. **Shading:** Use $N_{new}$ for lighting calculations (diffuse, specular) instead of the face normal [G].

**Pseudocode:**
```python
def triplanar_centroid_normal(ray_origin, ray_dir, voxel_center, voxel_size, texture_sample):
    # 1. Ray-AABB Intersection (slab method) [G]
    t_min = (voxel_center[0] - voxel_size/2 - ray_origin[0]) / ray_dir[0]
    t_max = (voxel_center[0] + voxel_size/2 - ray_origin[0]) / ray_dir[0]
    if t_min > t_max: t_min, t_max = t_max, t_min
    t_y_min = (voxel_center[1] - voxel_size/2 - ray_origin[1]) / ray_dir[1]
    t_y_max = (voxel_center[1] + voxel_size/2 - ray_origin[1]) / ray_dir[1]
    if t_y_min > t_y_max: t_y_min, t_y_max = t_y_max, t_y_min
    if t_min > t_y_max or t_y_min > t_max: return None, None
    t_min = max(t_min, t_y_min)
    t_max = min(t_max, t_y_max)
    t_z_min = (voxel_center[2] - voxel_size/2 - ray_origin[2]) / ray_dir[2]
    t_z_max = (voxel_center[2] + voxel_size/2 - ray_origin[2]) / ray_dir[2]
    if t_z_min > t_z_max: t_z_min, t_z_max = t_z_max, t_z_min
    if t_min > t_z_max or t_z_min > t_max: return None, None
    t = max(t_min, t_z_min)
    P = (ray_origin[0] + ray_dir[0]*t, ray_origin[1] + ray_dir[1]*t, ray_origin[2] + ray_dir[2]*t)

    # 2. Compute Centroid Normal
    V = (P[0]-voxel_center[0], P[1]-voxel_center[1], P[2]-voxel_center[2])
    len_V = (V[0]**2 + V[1]**2 + V[2]**2)**0.5
    if len_V == 0: return None, None
    N_new = (V[0]/len_V, V[1]/len_V, V[2]/len_V)

    # 3. Tri-Planar Weights
    w_x = abs(N_new[0])
    w_y = abs(N_new[1])
    w_z = abs(N_new[2])
    W = w_x + w_y + w_z
    if W > 0:
        w_x /= W; w_y /= W; w_z /= W
    else:
        w_x, w_y, w_z = 1/3, 1/3, 1/3

    # 4. Texture Coordinate Generation
    P_local = (P[0]-voxel_center[0], P[1]-voxel_center[1], P[2]-voxel_center[2])
    h = voxel_size / 2
    u_xy, v_xy = (P_local[0] + h) / (2*h), (P_local[1] + h) / (2*h)
    u_xz, v_xz = (P_local[0] + h) / (2*h), (-P_local[2] + h) / (2*h)
    u_yz, v_yz = (-P_local[1] + h) / (2*h), (P_local[2] + h) / (2*h)

    # 5. Texture Sampling
    C_xy = texture_sample(u_xy, v_xy)
    C_xz = texture_sample(u_xz, v_xz)
    C_yz = texture_sample(u_yz, v_yz)

    # 6. Blend Colors
    C_albedo = w_x * C_xy + w_y * C_xz + w_z * C_yz

    return C_albedo, N_new
```

**Pitfalls:**
- **Unity Shader Graph Limitation:** Unity's Shader Graph does not support a geometry pass, necessitating a custom shader for smooth material transitions [S2, unofficial].
- **Degenerate Normals:** If the ray intersection point coincides exactly with the voxel center, the normal is undefined [G]. Guard against division by zero in weight normalization [G].
- **Precision Artifacts:** Floating-point precision errors are noted in shadow casting contexts, but not specifically for normal calculation [S1, unofficial].

- **Strengths:** Eliminates hard edges between voxel faces, providing a smoother, more organic appearance [S1, unofficial].
- **Limitations:** Requires custom shader implementation in some engines (e.g., Unity Shader Graph) [S2, unofficial].
- **When to use:** When a smooth, continuous surface appearance is desired for voxel-based geometry [S1, unofficial].
- **When not to use:** When the aesthetic requires sharp, distinct voxel faces [S1, unofficial].

## Background
This technique was developed to address the visual artifacts of hard edges in voxel texturing [S1, unofficial]. It was described in the context of raycasting-based voxel rendering, where standard tri-planar mapping was adapted to use centroid-derived normals to smooth out the appearance of voxel surfaces [S1, unofficial]. The implementation details, including the need for custom shaders in Unity, were further documented in community projects focusing on voxel terrain generation [S2, unofficial].
