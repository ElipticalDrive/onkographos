# Voxel-Specific Shading Pipelines
## Overview
Voxel-Specific Shading Pipelines compute illumination for data stored in discrete 3D voxel grids, handling both surface-like boundaries and volumetric density [G]. They differ from continuous surface shading by operating on discrete voxel coordinates and neighbor-dependent lighting calculations [G], and include [Voxel Shading Pipeline](3898-voxel-shading-pipeline.md), [Fast Shading for Voxel Engines](5606-fast-shading-for-voxel-engines.md), [Voxel Shader Volumetric Ray Marching](16930-voxel-shader-volumetric-ray-marching.md), and [Voxmat Path Tracer](21082-voxmat-path-tracer.md).
## Shared principles
All methods operate on a 3D voxel grid indexed by integer coordinates $(x, y, z)$ [G]. Lighting calculations frequently depend on immediate neighboring voxels to determine occlusion or shading factors, rather than casting long-distance rays for every sample, except in explicit ray-marching variants [G]. Inputs include block types, palette indices, or continuous scalar/vector fields stored in the voxel cells [G].
## Subtopics

### [Voxel Shading Pipeline](3898-voxel-shading-pipeline.md)
Computes final voxel color by combining albedo sampling, Lambertian diffuse lighting, rim lighting, and specular integration. It differs by operating on discrete voxel coordinates and using hard shadow rays with per-voxel specular highlights rather than smooth surface approximations. Choose this for foundational voxel-specific rendering where discrete neighbor dependence is required.

### [Fast Shading for Voxel Engines](5606-fast-shading-for-voxel-engines.md)
A CPU-based lighting algorithm that modifies voxel palette indices to simulate lighting by checking immediate neighbors, assuming vertical sun rays. It differs by using fewer neighbor checks and operating on palettes grouped into dark-to-light gradients, making it faster but less visually detailed than geometric pipelines. Choose this for performance-critical voxel engines where speed is prioritized over visual fidelity.

### [Voxel Shader Volumetric Ray Marching](16930-voxel-shader-volumetric-ray-marching.md)
A shading method for volumetric data (fire, smoke) that reads voxel grid data from simulators or volume grids. It differs by explicitly tracing camera and shadow rays through the grid with configurable step sizes and sampling filters, supporting both pure volumetric ray marching and procedural geometry modes. Choose this for rendering volumetric effects where standard surface materials cannot shade directly.

### [Voxmat Path Tracer](21082-voxmat-path-tracer.md)
A real-time path tracer for per-voxel physically based rendering and global illumination. It differs by performing full path tracing (including specular reflections and refractions) on a per-voxel basis using a pre-computed irradiance cache for indirect diffuse lighting, rather than relying on static shading or simple ray marching. Choose this for physically accurate voxel rendering with global illumination.
