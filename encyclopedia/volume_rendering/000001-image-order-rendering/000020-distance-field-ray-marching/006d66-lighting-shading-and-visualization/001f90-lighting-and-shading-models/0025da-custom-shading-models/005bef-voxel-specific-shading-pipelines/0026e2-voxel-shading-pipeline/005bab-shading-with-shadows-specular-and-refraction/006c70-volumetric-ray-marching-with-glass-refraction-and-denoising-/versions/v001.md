# Volumetric Ray Marching with Glass Refraction and Denoising Guides

Also called: dielectric guide, voxmat shading loop

## Overview
A recursive ray marching loop for volumetric rendering that handles opaque surfaces, diffuse irradiance caching, GGX specular microfacet reflection, and glass refraction, including a specific guide generation step for denoising refracted pixels [S1, unofficial]. It differs from standard volumetric shading by explicitly decoupling the denoising guide computation from the radiance accumulation, tracing refracted rays through glass blocks to find the first surface behind them to provide accurate albedo and normal data to the denoiser [S1, unofficial].

## How it works

### Inputs and Outputs
**Inputs:**
*   `u_resolution`: `vec2` (width, height) of the output buffer.
*   `u_forward`, `u_right`, `u_up`: `vec3` camera basis vectors.
*   `u_aspect`: `float` camera aspect ratio.
*   `u_tan_half_fov`: `float` tangent of half the vertical field of view.
*   `u_frame`: `uint` current frame number.
*   `u_gi_scale`: `float` scale factor for irradiance cache contribution.
*   `u_gi`: `sampler2D` irradiance cache texture.
*   `u_accum`: `sampler2D` temporal accumulation buffer.
*   `gAlbedo`, `gNormal`: `image2D` (or equivalent) for writing denoising guides.

**Outputs:**
*   `f_color`: `vec4` final color output.
*   `gAlbedo`, `gNormal`: Updated denoising guide textures.

### Data Structures
*   **Material**: Contains `id` (int), `name` (string), `albedo` (`vec3`), `metallic` (`float`), `roughness` (`float`), `transmission` (`float`), `ior` (`float`).
*   **Voxel Hit**: Returns `cell` (`ivec3`), `normal` (`vec3`), `hitDistance` (`float`).
*   **Medium March**: Returns `exitDistance` (`float`), `exitNormal` (`vec3`), `beyondCell` (`ivec3`), `exitToEmpty` (`bool`).

def dielectric_guide(hit_point, ray_dir, cell, normal, material, g_albedo_img, g_normal_img):
    """
    Traces a refracted ray through a glass block to find the first surface behind it.
    Provides albedo and normal to the denoiser to prevent blurring of the refracted image.
    """
    # Orient normal against ray direction
    entry_normal = normal
    if dot(ray_dir, entry_normal) < 0.0:
        entry_normal = -entry_normal
    
    # Refract ray
    # ior is material.ior
    dir = refract(ray_dir, entry_normal, 1.0 / material.ior)
    
    # Check for total internal reflection (TIR)
    if dot(dir, dir) < 1e-6:
        g_albedo_img[cell] = material.albedo
        g_normal_img[cell] = entry_normal
        return

    # March through medium to find exit
    exit_distance = 0.0
    exit_normal = vec3(0.0)
    beyond_cell = ivec3(0)
    exit_to_empty = False
    
    # march_medium is a helper that advances along dir until exit
    march_medium(hit_point + dir * 1e-6, dir, material_row(cell), 
                 exit_distance, exit_normal, beyond_cell, exit_to_empty)
    
    exit_point = hit_point + dir * 1e-6 + dir * exit_distance
    
    # Determine exit direction
    if exit_to_empty:
        out_dir = refract(dir, -exit_normal, material.ior)
    else:
        out_dir = dir
        
    # Handle TIR at exit
    if dot(out_dir, out_dir) < 1e-6:
        out_dir = reflect(dir, exit_normal)
        
    # Trace voxel from exit point
    gc = ivec3(0)
    gn = vec3(0.0)
    gt = 0.0
    
    if trace_voxel(exit_point + out_dir * 1e-6, out_dir, beyond_cell, False, gc, gn, gt):
        g_albedo_img[gc] = fetch_material(gc).albedo
        g_normal_img[gc] = gn
    else:
        # Sky
        g_albedo_img[gc] = vec3(1.0)
        g_normal_img[gc] = out_dir

def shade(hit_point, ray_dir, cell, normal, material, rng):
    """
    Computes radiance for a single bounce.
    """
    color = vec3(0.0)
    throughput = vec3(1.0)
    
    # View vector and Fresnel
    view = -ray_dir
    ndv = max(dot(normal, view), 1e-4)
    fresnel_f0 = mix(vec3(0.04), material.albedo, material.metallic)
    
    # Diffuse term
    view_fresnel = fresnel_schlick(ndv, fresnel_f0)
    diffuse = (1.0 - view_fresnel) * (1.0 - material.metallic) * material.albedo
    
    # Add diffuse irradiance from cache
    # atlas_coord maps cell and face to 2D UV
    gi_uv = atlas_coord(cell, face_of(normal))
    color += throughput * diffuse * texel_fetch(u_gi, gi_uv).rgb * u_gi_scale
    
    # Specular term (GGX)
    micro_normal = ggx_sample(normal, material.roughness, rng)
    light_dir = reflect(ray_dir, micro_normal)
    
    # Check if light direction is below horizon
    if dot(light_dir, normal) <= 0.0:
        return color
        
    ndl = max(dot(normal, light_dir), 1e-4)
    ndh = max(dot(normal, micro_normal), 1e-4)
    vdh = max(dot(view, micro_normal), 1e-4)
    
    # Specular weight
    weight = fresnel_schlick(vdh, fresnel_f0) * smith_g(ndv, ndl, material.roughness) * vdh / (ndv * ndh)
    
    # Clamp throughput to prevent fireflies
    throughput *= min(weight, vec3(4.0))
    
    # Break if throughput is negligible
    if max(throughput.r, max(throughput.g, throughput.b)) < 0.01:
        return color
        
    # Trace next voxel hit along light direction
    next_cell = ivec3(0)
    next_normal = vec3(0.0)
    next_distance = 0.0
    
    if not trace_voxel(hit_point + normal * 1e-6, light_dir, cell, False, next_cell, next_normal, next_distance):
        # Escape to sky
        color += throughput * sample_env(light_dir)
        return color
        
    # Advance hit point and update state
    hit_point = hit_point + normal * 1e-6 + light_dir * next_distance
    cell = next_cell
    normal = next_normal
    material = fetch_material(next_cell)
    ray_dir = light_dir
    
    # Recursive call or loop continuation?
    # The source implies a loop structure for bounces, but shade() is called once per pixel in the main loop.
    # However, the notes describe a "recursive ray marching loop".
    # Let's assume shade() handles one bounce and the main loop handles recursion,
    # OR shade() is iterative. Given the structure, it's likely iterative within the main loop.
    # But the pseudocode below shows the main loop handling the recursion.
    
    return color

def main():

    rng = uint(gl_FragCoord.x) * 1973u + uint(gl_FragCoord.y) * 9277u + uint(u_frame) * 26699u + 1u
    
    # Compute jittered NDC and ray direction
    jitter = vec2(random01(rng), random01(rng)) - 0.5
    ndc = ((gl_FragCoord.xy + jitter) / u_resolution) * 2.0 - 1.0
    ray_dir = normalize(u_forward + u_right * (ndc.x * u_aspect * u_tan_half_fov) + u_up * (ndc.y * u_tan_half_fov))
    
    # Trace initial voxel hit
    cell = ivec3(-9999)
    normal = vec3(0.0)
    hit_distance = 0.0
    
    if not trace_voxel(vec3(0.0), ray_dir, ivec3(-9999), False, cell, normal, hit_distance):
        color = sample_env(ray_dir)
    else:
        material = fetch_material(cell)
        hit_point = vec3(0.0) + ray_dir * hit_distance
        
        # Generate denoising guide
        if material.transmission > 0.0:
            dielectric_guide(hit_point, ray_dir, cell, normal, material, gAlbedo, gNormal)
        else:
            gAlbedo[cell] = material.albedo
            gNormal[cell] = normal
            
        # Shade
        color = shade(hit_point, ray_dir, cell, normal, material, rng)
        
    # Temporal accumulation
    prev = vec3(0.0)
    if u_frame > 0:
        prev = texel_fetch(u_accum, ivec2(gl_FragCoord.xy), 0).rgb
        
    f_color = vec4(prev + max(color, vec3(0.0)), 1.0)

### Steps
1.  **Initialize RNG**: Seed the random number generator using fragment coordinates and frame number [S1, unofficial].
2.  **Compute Ray**: Calculate jittered normalized device coordinates (NDC) and transform to world space ray direction [S1, unofficial].
3.  **Trace Initial Hit**: Cast a ray from the camera origin. If no hit, sample the environment and return [S1, unofficial].
4.  **Fetch Material**: Retrieve material properties for the hit voxel [S1, unofficial].
5.  **Generate Guide**:
    *   If the material is dielectric (`transmission > 0.0`), call `dielectric_guide` to trace the refracted ray through the glass block and write the albedo/normal of the first surface behind it to the guide buffers [S1, unofficial].
    *   If opaque, write the surface albedo and normal directly to the guide buffers [S1, unofficial].
6.  **Shade**: Call the `shade` function to compute radiance for the current hit, including diffuse irradiance from cache and GGX specular reflection [S1, unofficial].
7.  **Accumulate**: Add the computed color to the temporal accumulation buffer using nearest neighbor fetch to avoid drift [S1, unofficial].

### Subtopics
*   **Dielectric Guide**: A helper function that traces a refracted ray through a glass block to find the first surface behind it, providing albedo and normal to the denoiser to prevent blurring of the refracted image [S1, unofficial]. Choose this when rendering transparent/translucent materials in a denoised pipeline.
*   **GGX Specular**: Uses importance sampling of the GGX microfacet normal distribution and Schlick Fresnel for specular reflection [S1, unofficial]. Choose this for realistic metallic/dielectric surfaces.
*   **Irradiance Cache**: Uses a precomputed irradiance cache for diffuse lighting, sampled based on voxel position and surface normal [S1, unofficial]. Choose this for performance in scenes with static lighting.

### Operating characteristics
*   **Time Complexity**: Linear in the number of bounces and voxel traversal steps. The `dielectric_guide` adds an additional traversal for dielectric materials.
*   **Memory Complexity**: Depends on the size of the irradiance cache and the denoising guide buffers.
*   **Strengths**: Handles complex glass refraction with denoising support; efficient diffuse lighting via irradiance cache.
*   **Limitations**: Requires precomputed irradiance cache; guide generation adds overhead for dielectrics.
*   **When to use**: Real-time or interactive volumetric rendering with glass and denoising.
*   **When not to use**: Offline path tracing where full integration is required; scenes without denoising needs where simpler shading suffices.

## Background
Originated in the Voxmat project by HollaFoil [S1, unofficial]. It is part of a custom shading pipeline for volumetric rendering, specifically designed to handle dielectric materials and integrate with denoisers.
