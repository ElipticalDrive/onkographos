# Voxel Shader Volumetric Ray Marching

Also called: Phoenix Volumetric Rendering, V-Ray Volume Grid Shading

## Overview
Voxel Shader Volumetric Ray Marching is a shading method for Fire/Smoke simulations and meshes that reads voxel grid data from a Phoenix Simulator or V-Ray Volume Grid to handle volumetric shading, as standard Maya materials cannot shade volumetrics directly [S1]. It distinguishes itself from its siblings by providing specific rollouts for Fire, Smoke Color, and Smoke Opacity, and by supporting both pure volumetric ray marching and "Render as Geometry" procedural geometry modes [S1]. Unlike [Voxel Shading Pipeline](3898-voxel-shading-pipeline.md) which may rely on discrete neighbor dependence for lighting, this method explicitly traces camera and shadow rays through the grid with configurable step sizes and sampling filters [S1].

## How it works
**Inputs and Outputs:**
*   **Inputs:** Voxel grid data (Temperature, Smoke, Speed, Fuel, Velocity, etc.), camera position/direction, light sources, and shader parameters (Step %, Sampler Type, Surface Channel, etc.) [S1].
*   **Outputs:** Colored pixel values, optionally with Render Elements (Normals, Velocity, Z-Depth, Material ID) if "Render as Geometry" is enabled [S1].

**Data Structures:**
The method operates on a 3D voxel grid indexed by integer coordinates $(x, y, z)$ [G]. Each cell contains scalar or vector fields (e.g., Temperature, Smoke density, Velocity vector) [S1]. The grid is accessed via ray marching, where continuous ray positions are mapped to grid cells [S1].

**Numbered Steps:**
1.  **Ray Initialization:** For each pixel, cast a primary camera ray into the scene [S1].
2.  **Cutter Check:** If `rendUseGizmo` is enabled, restrict rendering to inside the selected geometric object's volume; if `rendInvGizmo` is enabled, restrict to outside and shade rays that do not intersect the cutter [S1].
3.  **Ray Marching Loop:** Determine step size $s = C \cdot \frac{P}{100}$ where $C$ is cell size and $P$ is `Step %` [S1]. If `Step %` > 100, cells are skipped causing artifacts [S1]. Advance ray by $s$ along its direction. Sample the voxel grid at the current ray position using the selected `Sampler Type` (Box, Linear, or Spherical) [S1]. Accumulate optical depth and color based on sampled values and lighting [S1]. Repeat until the ray exits the grid or reaches a maximum distance [S1].
4.  **Shadow Ray Marching:** For each light source, cast a shadow ray from the current shading point to the light [S1]. Determine shadow step size $s_{shadow} = C \cdot \frac{P_{shadow}}{100}$ where $P_{shadow}$ is `Shadow Step %` [S1]. March along the shadow ray, accumulating opacity; higher `Shadow Step %` speeds up rendering, especially with dome and area lights [S1].
5.  **Surface Shading:** If "Render as Geometry" (`geommode`) is enabled, the volume is converted to procedural geometry made of multiple transparent layers [S1]. Otherwise, if a `Surface Channel` (`sarg`) is defined, compute the isosurface using `rendSurfLevel_*` thresholds [S1]. Apply displacement based on `rendDispltSurf` type (Gradient driven, Surface driven, Vector, or Advection) [S1].
6.  **Heat Haze:** If `rendHeatHaze` > 0, perturb the ray direction according to the gradient of the `Surface Channel` [S1].
7.  **Motion Blur:** If `volMoblurMethod` is "Ray-traced", sample velocity at multiple time steps [S1]. If "Grid-based", use a pre-pass to generate streaks [S1]. If `rendVelTexture` is set, use its RGB values (Y/Z flipped to Blue/Green) as velocity vectors to stretch simulation content [S1]. Apply `mbmult` multiplier to blur strength [S1].
8.  **Border Fade:** If the ray is within `borderFade` distance of the grid boundary, fade opacity to transparent to prevent sharp edges [S1].
9.  **Compositing:** Combine fire and smoke colors/opacities; `emIgnoreAlpha` determines if fire uses smoke opacity, is fully visible (additive blending), or uses custom opacity [S1].

**Formulas:**
*   **Step Size:** $s = C \cdot \frac{P}{100}$, where $C$ is cell size, $P$ is Step % [S1].
*   **Velocity Texture Mapping:** $v_y = -T_b$, $v_z = -T_g$, where $T_b, T_g$ are Blue and Green texture components [S1].
*   **Heat Haze Perturbation:** $\vec{d}_{new} = \vec{d}_{old} + k \cdot \nabla S$, where $k$ is `rendHeatHaze` value, $S$ is Surface channel [S1].

**Parameters with Typical Values:**
*   `Step %` (`rendstep`): Recommended $\ge 90\%$ [S1].
*   `Shadow Step %` (`rendshadstep`): Typically higher than Step % [S1].
*   `Isosurface Level` (`rendSurfLevel_*`): Default 0.5 [S1].
*   `Heat Haze` (`rendHeatHaze`): 1 approximates normal heat haze [S1].
*   `Sampler Type`: Box (fastest), Linear (20-30% faster than Spherical), Spherical (smoothest) [S1].

**Edge Cases and Pitfalls:**
*   **Step % > 100:** Causes cell skipping and artifacts [S1].
*   **Step % < 90%:** Required for render curves or texture maps to capture details smaller than a voxel, but increases render time [S1].
*   **Render as Geometry:** Slows down rendering significantly [S1].
*   **Grid-based Motion Blur:** Requires pre-pass, uses more memory, and only affects Volumetric/Volumetric Geometry/Volumetric Heat Haze modes [S1].
*   **Velocity Texture:** Y/Z components are flipped (Blue/Green channels) [S1].
*   **Fire Opacity:** "Fully Visible" mode uses additive blending and is not suitable for fire+smoke mix [S1].

import math
from typing import List, Tuple

def ray_aabb_intersect(origin: List[float], direction: List[float], 
                       bounds_min: List[float], bounds_max: List[float]) -> Tuple[float, float]:
    """Returns (t_min, t_max) for ray-AABB intersection. Returns (inf, -inf) if no hit."""
    t_min, t_max = 0.0, float('inf')
    for i in range(3):
        if abs(direction[i]) < 1e-8:
            if origin[i] < bounds_min[i] or origin[i] > bounds_max[i]:
                return float('inf'), -float('inf')
        else:
            t1 = (bounds_min[i] - origin[i]) / direction[i]
            t2 = (bounds_max[i] - origin[i]) / direction[i]
            t_min = max(t_min, min(t1, t2))
            t_max = min(t_max, max(t1, t2))
    return t_min, t_max

def voxel_shader_volumetric_ray_marching(ray_origin: List[float], ray_direction: List[float],
                                         grid_bounds_min: List[float], grid_bounds_max: List[float],
                                         cell_size: float, params: dict) -> Tuple[List[float], float]:
    """
    ray_origin: vec3
    ray_direction: vec3 (normalized)
    grid_bounds_min/max: vec3 defining the voxel grid extent
    cell_size: float
    params: dict containing all shader parameters
    Returns: (accumulated_color, accumulated_opacity)
    """
    step_pct = params['rendstep']
    shadow_step_pct = params['rendshadstep']
    border_fade_dist = params['borderFade']
    sampler_type = params['sampler']
    surface_channel = params['sarg']
    heat_haze_strength = params['rendHeatHaze']
    velocity_texture = params['rendVelTexture']
    motion_blur_method = params['volMoblurMethod']
    mb_mult = params['mbmult']
    use_cutter = params['rendUseGizmo']
    invert_cutter = params['rendInvGizmo']
    cutter_bounds = params['cutter_bounds']
    render_as_geometry = params['geommode']
    fire_opacity_mode = params['emIgnoreAlpha']
    smoke_color_source = params['difSource']
    fire_emission_source = params['emSource']
    
    step_size = cell_size * (step_pct / 100.0)
    if step_pct > 100:
        # Artifacts may appear, but we proceed as per source [S1]
        pass

    # Grid entry/exit distances
    t_min, t_max = ray_aabb_intersect(ray_origin, ray_direction, grid_bounds_min, grid_bounds_max)
    if t_min > t_max:
        return [0.0, 0.0, 0.0], 0.0

    # Cutter check [S1]
    if use_cutter:
        c_min, c_max = ray_aabb_intersect(ray_origin, ray_direction, cutter_bounds, cutter_bounds)
        if invert_cutter:
            if c_min <= t_max:  # Ray intersects cutter
                return [0.0, 0.0, 0.0], 0.0
        else:
            if c_min > t_max:  # Ray does not intersect cutter
                return [0.0, 0.0, 0.0], 0.0

    accumulated_color = [0.0, 0.0, 0.0]
    accumulated_opacity = 0.0
    t = t_min
    
    while t < t_max and accumulated_opacity < 1.0:
        current_pos = [ray_origin[i] + t * ray_direction[i] for i in range(3)]
        
        # Border fade [S1]
        dist_to_boundary = min(
            min(current_pos[i] - grid_bounds_min[i] for i in range(3)),
            min(grid_bounds_max[i] - current_pos[i] for i in range(3))
        )
        fade_factor = 1.0
        if dist_to_boundary < border_fade_dist:
            fade_factor = dist_to_boundary / border_fade_dist

        # Sampling [S1]
        if sampler_type == 'Box':
            voxel_value = grid_get_scalar_at_position(current_pos)
        elif sampler_type == 'Linear':
            voxel_value = grid_get_linear_interpolated_scalar(current_pos)
        elif sampler_type == 'Spherical':
            voxel_value = grid_get_spherical_weighted_scalar(current_pos)
        else:
            voxel_value = 0.0

        # Heat Haze [S1]
        if heat_haze_strength > 0:
            surface_gradient = grid_get_gradient_of_surface_channel(current_pos, surface_channel)
            ray_direction = normalize([ray_direction[i] + heat_haze_strength * surface_gradient[i] for i in range(3)])

        # Accumulate [S1]
        smoke_density = grid_get_scalar('Smoke', current_pos)
        temperature = grid_get_scalar('Temperature', current_pos)
        
        smoke_color = compute_smoke_color(smoke_density, temperature, smoke_color_source, params)
        fire_color = compute_fire_emission(temperature, fire_emission_source, params)
        
        # Shadow ray march [S1]
        shadow_step_size = cell_size * (shadow_step_pct / 100.0)
        shadow_pos = current_pos
        shadow_dir = normalize([params['light_pos'][i] - current_pos[i] for i in range(3)])
        shadow_opacity = 0.0
        while shadow_pos_inside_grid(shadow_pos) and shadow_opacity < 1.0:
            shadow_pos = [shadow_pos[i] + shadow_step_size * shadow_dir[i] for i in range(3)]
            shadow_opacity += grid_get_scalar('Smoke', shadow_pos) * shadow_step_size

        contribution = [(smoke_color[i] * (1.0 - shadow_opacity) + fire_color[i]) * smoke_density * step_size for i in range(3)]
        alpha_contribution = smoke_density * step_size
        
        accumulated_color = [accumulated_color[i] + contribution[i] * (1.0 - accumulated_opacity) for i in range(3)]
        accumulated_opacity += alpha_contribution
        
        t += step_size

    # Apply border fade to final result [S1]
    accumulated_color = [accumulated_color[i] * fade_factor for i in range(3)]
    
    # Fire Opacity Mode [S1]
    if fire_opacity_mode == 'Fully Visible':
        return accumulated_color, 1.0
    else:
        return accumulated_color, accumulated_opacity

## Subtopics

### Smoke Color Mapping
Smoke Color Mapping determines the diffuse color of the smoke volume [S1]. It requires external light to become visible if GI is enabled [S1]. The `Based on` (`difSource`) parameter specifies the source channel: Constant Color (default), Temperature, Smoke, Speed, Texture, RGB, or Fuel [S1]. If `Based on` is not Texture, the color can be modulated by a texture map (`difModulate`) [S1]. The `Scattering` (`difScattering`) parameter controls light ray scattering, with options for Ray-traced (GI only, slowest, most realistic), Disabled (uses Diffuse Multiplier for brightness), and Approximate [S1].

## Operating characteristics
*   **Time Complexity:** Depends on the number of ray steps, which is inversely proportional to `Step %` and `Shadow Step %` [S1].
*   **Memory Complexity:** Proportional to the size of the voxel grid and any additional textures (Velocity, Displacement) [S1]. Grid-based motion blur requires a pre-pass and more memory [S1].
*   **Measured Performance:** Box sampler is fastest [S1]. Linear is 20-30% faster than Spherical [S1]. Spherical is smoothest but slowest [S1]. "Render as Geometry" slows down rendering significantly [S1]. Grid-based motion blur is slower than Ray-traced due to pre-pass [S1].
*   **Scaling:** Performance degrades with higher resolution grids and lower step percentages [S1].
*   **Strengths:** Supports complex volumetric shading, motion blur, displacement, and render elements (via Render as Geometry) [S1].
*   **Limitations:** "Render as Geometry" is slow [S1]. Grid-based motion blur requires more memory [S1]. Step % < 90% increases render time [S1].
*   **When to Use:** For Fire/Smoke simulations where volumetric shading is required and standard materials cannot be used [S1].
*   **When Not to Use:** When deep images or render elements are needed, use "Render as Geometry" as the default volumetric mode does not support them [S1].

## Background
The Voxel Shader is part of the Phoenix FD plugin for Maya, developed by Chaos Group [S1]. It was created to address the limitation that Maya materials cannot shade volumetrics directly, providing specific rollouts for Fire, Smoke Color, and Smoke Opacity [S1]. It supports rendering from Phoenix Simulator data and V-Ray Volume Grids [S1].
