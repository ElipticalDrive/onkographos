# Shading with Shadows, Specular, and Refraction

Also called: Voxel Shading with Shadows, Specular, and Refraction

## Overview
This method computes the final color of a hit voxel by combining diffuse and specular lighting from multiple light sources, handling shadow casting to occlude lights, and managing refraction through volumetric structures [S1, unofficial]. It extends the basic voxel shading pipeline by adding shadow ray casting, Phong-like specular highlights, and recursive or discrete refraction bounces [S1, unofficial]. It is distinguished from simpler shading models by its support for recursive light transport through semi-transparent volumes and its specific handling of voxel-space coordinate offsets for shadow and refraction ray origins [S1, unofficial].

## How it works

### Inputs and Outputs
**Inputs:**
- `rendering_attributes`: Contains `light_count`, an array of light sources (each with `diffuse` and `specular` color vectors), `ambient_colour`, and flags for shadow/refraction enablement [S1, unofficial].
- `hit`: The hit point structure from the ray marcher, containing `hit_pos` (world position), `hit_scale` (log2 of voxel size or similar scale factor), and `hit_t` (distance along ray) [S1, unofficial].
- `shading_attributes`: Contains `normal` (surface normal at hit point), `colour` (RGBA color sampled from voxel, where `a` is alpha), and `refractive_index` (material refractive index) [S1, unofficial].
- `eye_ray`: The primary ray, containing `direction` (view direction) [S1, unofficial].
- `tree`: The volume data structure for ray casting [S1, unofficial].
- `stack`: Auxiliary stack for recursive ray casting [S1, unofficial].
- `incident_refractive_index`: Refractive index of the medium the ray is currently traveling through [S1, unofficial].
- `recursions`: Current recursion depth counter [S1, unofficial].
- `shadows_enabled`, `refraction_enabled`, `refraction_mode`, `refraction_discrete_steps_max`, `refraction_discrete_step`: Configuration flags and parameters controlling shadow casting, refraction mode (`CONTINUOUS` or `DISCRETE`), and discrete stepping limits [S1, unofficial].

**Outputs:**
- `out`: A `vec4` representing the final computed color (RGB + alpha, though alpha handling in output is implicit in the accumulation logic) [S1, unofficial].

### Data Structures
The method relies on structures defined in the parent [Voxel Shading Pipeline](3898-voxel-shading-pipeline.md) and the ray marcher [S1, unofficial]. Key fields include:
- `hit.hit_scale`: Used to compute geometric offsets. `MAX_SCALE` is a constant defining the maximum scale (smallest voxel). `HALF_SQRT_2` is a constant $\frac{\sqrt{2}}{2}$ [S1, unofficial].
- `shading_attributes.colour.a`: Alpha value of the hit voxel [S1, unofficial].
- `refraction_mode`: Enum indicating `CONTINUOUS` or `DISCRETE` refraction [S1, unofficial].
- `refraction_discrete_steps_max`: Maximum number of steps for discrete refraction [S1, unofficial].
- `refraction_discrete_step`: Step size for discrete refraction [S1, unofficial].

```python
import math

# Standard vector/math helpers [G]
def vec3(x, y, z): return (x, y, z)
def vec4(x, y, z, w): return (x, y, z, w)
def vec3_add(a, b): return vec3(a[0]+b[0], a[1]+b[1], a[2]+b[2])
def vec3_sub(a, b): return vec3(a[0]-b[0], a[1]-b[1], a[2]-b[2])
def vec3_mul(a, s): return vec3(a[0]*s, a[1]*s, a[2]*s)
def vec4_add(a, b): return vec4(a[0]+b[0], a[1]+b[1], a[2]+b[2], a[3]+b[3])
def vec4_mul(a, s): return vec4(a[0]*s, a[1]*s, a[2]*s, a[3]*s)
def dot(a, b): return a[0]*b[0] + a[1]*b[1] + a[2]*b[2]
def normalize(v):
    l = math.sqrt(dot(v, v))
    return vec3(v[0]/l, v[1]/l, v[2]/l) if l > 1e-8 else v
def reflect(I, N): return vec3(I[0] - 2*dot(I, N)*N[0], I[1] - 2*dot(I, N)*N[1], I[2] - 2*dot(I, N)*N[2])
def refract(I, N, eta):
    cos_theta = min(dot(-I, N), 1.0)
    r_out_perp = vec3(eta*(I[0] + N[0]*cos_theta), eta*(I[1] + N[1]*cos_theta), eta*(I[2] + N[2]*cos_theta))
    r_out_parallel = vec3(-N[0]*math.sqrt(max(1.0 - dot(r_out_perp, r_out_perp), 0.0)),
                          -N[1]*math.sqrt(max(1.0 - dot(r_out_perp, r_out_perp), 0.0)),
                          -N[2]*math.sqrt(max(1.0 - dot(r_out_perp, r_out_perp), 0.0)))
    return vec3_add(r_out_perp, r_out_parallel)
def exp2f(x): return 2.0 ** x
def max_val(a, b): return a if a > b else b
def min_val(a, b): return a if a < b else b

def shade(rendering_attributes, eye_ray, hit, shading_attributes, stack, tree, incident_refractive_index, recursions):
    MAX_SCALE = 23.0
    HALF_SQRT_2 = math.sqrt(2.0) / 2.0
    MIN_FLOAT = exp2f(-MAX_SCALE)

    # 1. Normalize normal
    normal = normalize(shading_attributes.normal)

    # 2. Initialize output and view direction
    out = vec4(0.0, 0.0, 0.0, 0.0)
    view_dir = eye_ray.direction

    # 3. Iterate over lights
    for i in range(rendering_attributes.light_count):
        light = rendering_attributes.lights[i]
        light_dir = normalize(vec3_sub(light.position, hit.hit_pos))
        light_distance = exp2f(23.0)
        attenuation = 1.0

        # 4. Shadow Ray Casting
        if shadows_enabled and dot(light_dir, normal) < 0.0:
            shadow_ray_dir = vec3_mul(light_dir, -1.0)
            shadow_ray_origin = vec3_add(hit.hit_pos, vec3_mul(shadow_ray_dir, HALF_SQRT_2 * exp2f(hit.hit_scale - MAX_SCALE)))
            shadow_hit = raycast(tree, shadow_ray_origin, shadow_ray_dir, stack)

            # Boundary Conditions: The check shadow_hit.hit_scale < MAX_SCALE ensures that only valid voxel hits are considered for occlusion [S1, unofficial].
            if shadow_hit.hit_scale < MAX_SCALE and shadow_hit.hit_t < light_distance:
                continue

        # 5. Diffuse Contribution
        diffuse_factor = attenuation * max_val(0.0, dot(normal, vec3_mul(light_dir, -1.0)))
        diffuse_colour = vec3_mul(shading_attributes.colour.rgb, light.diffuse)
        out = vec4_add(out, vec4(vec3_mul(diffuse_factor, diffuse_colour), 0.0))

        # 6. Specular Contribution
        if dot(normal, light_dir) < 0.0:
            reflection = reflect(light_dir, normal)
            specular_factor = pow(max_val(0.0, dot(reflection, view_dir)), 32.0)
            spec_colour = vec3_mul(shading_attributes.colour.rgb, light.specular)
            out = vec4_add(out, vec4(vec3_mul(specular_factor, spec_colour), 0.0))

    # 7. Refraction Handling
    if refraction_enabled and shading_attributes.colour.a < 1.0:
        one_minus_alpha = 1.0 - shading_attributes.colour.a
        out = vec4_mul(out, shading_attributes.colour.a)

        refract_normal = normal
        if dot(normal, eye_ray.direction) > 0.0:
            refract_normal = vec3_mul(normal, -1.0)

        eta = incident_refractive_index / shading_attributes.refractive_index
        refract_dir = refract(eye_ray.direction, refract_normal, eta)
        refract_ray_origin = vec3_add(hit.hit_pos, vec3_mul(refract_dir, HALF_SQRT_2 * exp2f(hit.hit_scale - MAX_SCALE)))

        if refraction_mode != "CONTINUOUS":
            # Discrete Refraction
            current_refractive_index = shading_attributes.refractive_index
            discrete_ray_origin = vec3_add(refract_ray_origin, vec3_mul(refract_dir, HALF_SQRT_2 * exp2f(hit.hit_scale - MAX_SCALE)))
            discrete_ray_dir = vec3_mul(refract_dir, -1.0)
            refracted_times = 0

            for step in range(refraction_discrete_steps_max):
                refraction_hit = raycast(tree, discrete_ray_origin, discrete_ray_dir, stack)

                if refraction_hit.hit_scale == MAX_SCALE or refraction_hit.hit_t <= MIN_FLOAT:
                    break

                refraction_attachment = lookup_attachment(tree, refraction_hit)

                if refraction_attachment.refractive_index != current_refractive_index:
                    refracted_times += 1
                    eta = current_refractive_index / refraction_attachment.refractive_index

                    ref_normal = normalize(refraction_hit.normal)
                    if dot(ref_normal, refract_dir) > 0.0:
                        ref_normal = vec3_mul(ref_normal, -1.0)

                    refract_dir = refract(refract_dir, ref_normal, eta)
                    discrete_ray_dir = vec3_mul(refract_dir, -1.0)
                    current_refractive_index = refraction_attachment.refractive_index

                discrete_ray_origin = vec3_add(discrete_ray_origin, vec3_mul(refract_dir, refraction_discrete_step))
        else:
            # Continuous Refraction
            refraction_hit = raycast(tree, refract_ray_origin, refract_dir, stack)

            if refraction_hit.hit_scale >= MAX_SCALE:
                out = vec4_add(out, vec4(vec3_mul(one_minus_alpha, rendering_attributes.ambient_colour), 0.0))
            else:
                refraction_attachment = lookup_attachment(tree, refraction_hit)

                ref_normal = normalize(refraction_hit.normal)
                if dot(ref_normal, refract_dir) > 0.0:
                    ref_normal = vec3_mul(ref_normal, -1.0)

                eta = refraction_attachment.refractive_index / incident_refractive_index
                refract_dir = refract(refract_dir, ref_normal, eta)

                refract_ray_origin = vec3_add(refraction_hit.hit_pos, vec3_mul(refract_dir, HALF_SQRT_2 * exp2f(refraction_hit.hit_scale - MAX_SCALE)))
                refraction_hit = raycast(tree, refract_ray_origin, refract_dir, stack)

                if refraction_hit.hit_scale < MAX_SCALE:
                    out = vec4_add(out, shade(rendering_attributes, refract_ray_origin, refraction_hit, shading_attributes, stack, tree, refraction_attachment.refractive_index, recursions + 1))

    return out
```

### Parameters and Typical Values
- `MAX_SCALE`: Constant defining the smallest voxel scale. `exp2f(MAX_SCALE)` is the minimum voxel size [S1, unofficial].
- `HALF_SQRT_2`: Constant $\frac{\sqrt{2}}{2} \approx 0.7071$ [S1, unofficial].
- `32.0`: Exponent for specular highlight (Shininess) [S1, unofficial].
- `exp2f(23)`: Approximation for infinity in shadow ray distance checks [S1, unofficial].
- `refraction_discrete_steps_max`: Number of steps for discrete refraction. Not given in the sources.
- `refraction_discrete_step`: Step size for discrete refraction. Not given in the sources.

### Edge Cases and Pitfalls
- **Precision**: The use of `exp2f` for scale calculations requires careful handling of floating-point precision, especially for very small or large scales [S1, unofficial].
- **Boundary Conditions**: The check `shadow_hit.hit_scale < MAX_SCALE` ensures that only valid voxel hits are considered for occlusion. Hits at `MAX_SCALE` (empty space) are ignored [S1, unofficial].
- **Normal Orientation**: The normal must be reversed if the dot product with the view/refraction direction is positive, indicating the ray is exiting the surface [S1, unofficial].
- **Recursion Depth**: The method supports recursive bounces up to a template parameter. Deep recursion can lead to performance issues or stack overflow [S1, unofficial].
- **Discrete Refraction Logic**: The source code negates the direction in discrete refraction (`discrete_refraction_ray.direction = -refraction_ray.direction`). This appears to be a specific implementation detail that may need verification against the intended physics [S1, unofficial].

It differs from standard volumetric shading by explicitly decoupling the denoising guide computation from the radiance accumulation, tracing refracted rays through glass blocks to find the first surface behind them to provide accurate albedo and normal data to the denoiser.

## Operating characteristics

### Time and Memory Complexity
- **Time Complexity**: $O(L \cdot (1 + R))$, where $L$ is the number of lights and $R$ is the number of refraction bounces. Each light requires a shadow ray cast. Refraction adds recursive ray casts [G].
- **Memory Complexity**: $O(R)$ for the recursion stack, where $R$ is the maximum refraction depth [G].

### Measured Performance
Not given in the sources.

### Scaling
Performance scales linearly with the number of lights and refraction depth. High refraction depths can significantly impact performance [G].

### Strengths and Limitations
- **Strengths**: Supports complex lighting effects including shadows, specular highlights, and refraction. Handles semi-transparent volumes [S1, unofficial].
- **Limitations**: Recursive refraction can be computationally expensive. Discrete refraction logic is complex and may not accurately model continuous refraction [S1, unofficial].

### When to Use
Use when realistic lighting with shadows and refraction is required for volumetric data. Avoid for real-time applications with strict performance constraints and high refraction depths [S1, unofficial].
