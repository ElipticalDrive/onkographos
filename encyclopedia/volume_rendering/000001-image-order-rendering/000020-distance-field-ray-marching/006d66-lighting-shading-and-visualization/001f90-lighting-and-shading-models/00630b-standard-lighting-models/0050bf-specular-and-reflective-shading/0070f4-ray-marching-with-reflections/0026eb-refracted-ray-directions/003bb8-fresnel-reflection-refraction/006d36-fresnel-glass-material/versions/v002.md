# Fresnel Glass Material

Also called: Dielectric Scattering, Glass scattering, Refraction with Schlick approximation

## Overview
The Fresnel Glass Material is a shading model for transparent dielectric objects that simulates light bending (refraction) and partial reflection at boundaries like glass or water [S1, unofficial]. It dynamically adjusts the ratio of refracted to reflected light based on the angle of incidence using the Fresnel equations [S2, unofficial]. Unlike basic glass models that ignore angular dependence, this method produces characteristic darkening of glass sides at low-incidence viewing angles and more accurate caustics beneath the base [S2, unofficial].

## How it works
### Inputs and Outputs
- **Inputs**: Incident ray direction, surface normal, index of refraction ($n$), and a random number generator [S1, unofficial].
- **Outputs**: A new ray direction (either reflected or refracted) and attenuation color (default white) [S1, unofficial].

### Data Structures
- **hit_record**: Stores the intersection point $p$, the surface normal $\vec{n}$, the distance $t$, a material pointer, and a boolean `front_face` indicating if the ray hit from outside or inside [S1, unofficial].
- **ray**: Defined by an origin point and a direction vector [S1, unofficial].

### Parameters
- **$n$ (Index of Refraction)**: A double-precision floating-point value. Typical values are 1.5 for glass, 1.33 for water, and 2.4 for diamond [S1, unofficial].

### Algorithm Steps
1. Set attenuation to white.
2. Determine refraction ratio: $1.0/n$ if front face, $n$ if back face.
3. Compute unit direction $\vec{u}$.
4. Calculate $\cos\theta$ clamped to $1.0$.
5. Compute $\sin\theta = \sqrt{1 - \cos^2\theta}$.
6. Check for total internal reflection (TIR): if $\text{refraction\_ratio} \times \sin\theta > 1.0$, TIR occurs.
7. Compute Schlick reflectance: $R_0 = \left(\frac{1 - n}{1 + n}\right)^2$, Reflectance $= R_0 + (1 - R_0)(1 - \cos\theta)^5$.
8. If TIR or Schlick reflectance $>$ random double, reflect; else refract.
9. Create new ray with the computed direction.

### Pseudocode
```python
def dot(a, b):
    return a[0]*b[0] + a[1]*b[1] + a[2]*b[2]

def normalize(v):
    s = (v[0]**2 + v[1]**2 + v[2]**2)**0.5
    return (v[0]/s, v[1]/s, v[2]/s)

class Ray:
    def __init__(self, origin, direction):
        self.origin = origin
        self.direction = direction

def fresnel_glass_material(ray, hit_record, n, rng):
    # 1. Set attenuation to white (implicit)
    
    # 2. Determine refraction ratio
    refraction_ratio = 1.0 / n if hit_record.front_face else n

    # 3. Compute unit direction
    u = normalize(ray.direction)

    # 4. Calculate cos_theta clamped to 1.0
    effective_normal = hit_record.normal if hit_record.front_face else (-hit_record.normal[0], -hit_record.normal[1], -hit_record.normal[2])
    cos_theta = dot(u, effective_normal)
    cos_theta = min(cos_theta, 1.0)

    # 5. Compute sin_theta
    sin_theta = (1.0 - cos_theta * cos_theta)**0.5

    # 6. Check for TIR
    is_tir = (refraction_ratio * sin_theta > 1.0)

    # 7. Compute Schlick reflectance
    r0 = ((1.0 - n) / (1.0 + n)) ** 2
    reflectance = r0 + (1.0 - r0) * (1.0 - cos_theta) ** 5

    # 8. Probabilistic decision
    if is_tir or rng() > reflectance:
        # Reflect: d_new = u - 2(u . n)n
        direction = u - 2.0 * dot(u, effective_normal) * effective_normal
    else:
        # Refract: standard vector formula
        discriminant = 1.0 - refraction_ratio * refraction_ratio * (1.0 - cos_theta * cos_theta)
        if discriminant < 0.0:
            direction = u - 2.0 * dot(u, effective_normal) * effective_normal
        else:
            direction = refraction_ratio * u - (refraction_ratio * cos_theta + discriminant**0.5) * effective_normal

    # 9. Create new ray
    new_origin = (ray.origin[0] + direction[0]*1e-4, ray.origin[1] + direction[1]*1e-4, ray.origin[2] + direction[2]*1e-4)
    return Ray(new_origin, direction)
```

### Edge Cases and Pitfalls
- **Grazing Angles**: At grazing angles, reflectance approaches 1.0. The Schlick approximation handles this probabilistically, ensuring realistic darkening of edges [S1, unofficial].
- **Total Internal Reflection**: Must be handled explicitly. If the condition $\text{refraction\_ratio} \times \sin\theta > 1.0$ is met, the ray falls back to pure reflection [S1, unofficial].
- **Numerical Precision**: Clamping $\cos\theta$ to $1.0$ prevents invalid square root calculations when computing sine [S1, unofficial].

## Operating characteristics
- **Time Complexity**: $O(1)$ per intersection for the shading calculation [G].
- **Memory Complexity**: $O(1)$ additional memory [G].
- **Strengths**: Produces visually accurate glass with realistic edge darkening and caustics [S2, unofficial]. Computationally efficient due to the Schlick approximation [G].
- **When to use**: For rendering transparent dielectric objects like glass, water, or plastic where surface reflections and refractions are dominant [G].
- **When not to use**: For materials with significant internal scattering or absorption without extension [G].

## Background
The Fresnel Glass Material is based on the principles of optics, specifically the Fresnel equations, which describe the reflection and transmission of light at an interface between two media [S2, unofficial]. The Schlick approximation is a widely used simplification for computational efficiency [G]. This model was notably implemented in ray tracers to improve the realism of glass objects, such as martini glasses, by capturing the darkening of sides at low-incidence angles and accurate caustics [S2, unofficial].
