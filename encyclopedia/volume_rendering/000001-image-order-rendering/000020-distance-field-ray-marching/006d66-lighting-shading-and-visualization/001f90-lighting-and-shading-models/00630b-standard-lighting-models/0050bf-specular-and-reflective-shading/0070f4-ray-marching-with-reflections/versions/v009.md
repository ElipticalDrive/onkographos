# Ray Marching with Reflections

Also called: GLSL reflect function for raymarching, Metal Material Scattering, Ray Marching with Recursive Reflections, Reflection and Refraction in Raymarching, Spherical Marching with Reflections, raytraced reflections, renderReflection

## Overview
Ray Marching with Reflections extends distance-field ray marching by iteratively scattering rays specularly upon surface intersection to simulate mirror-like or metallic materials [S1, unofficial]. Unlike standard ray marching which terminates at the first hit, this method continues the ray path in the reflected direction, accumulating color contributions weighted by material reflectivity [S4, unofficial]. It distinguishes itself from [Approximate Refraction](3072-approximate-refraction.md) by handling surface reflection rather than transmission, and from [Screen-Space Reflections](9698-screen-space-reflections.md) by operating in full 3D volume space rather than restricted screen-space depth buffers [G].

## How it works
**Inputs and Outputs:**
*   **Input:** Initial ray origin $\mathbf{r}_o$ and direction $\mathbf{r}_d$; Signed Distance Function (SDF) $f(\mathbf{x})$; reflection coefficient $c_{\text{refl}}$; maximum reflection bounces $N_{\text{max}}$ [S5, unofficial].
*   **Output:** Final accumulated color $\mathbf{C}_{\text{out}}$ [S5, unofficial].

**Data Structures:**
*   **Ray:** Struct containing `origin` (vec3) and `direction` (vec3) [S1, unofficial].
*   **HitRecord:** Struct containing `t` (distance to hit, float), `hit_point` (vec3), `normal` (vec3), and `material` properties [S2, unofficial].

**Steps:**
1.  **Initialization:** Set accumulated color $\mathbf{C}_{\text{acc}} = \mathbf{0}$, transmission mask $\mathbf{M} = \mathbf{1}$, and current ray $\mathbf{r} = (\mathbf{r}_o, \mathbf{r}_d)$ [S5, unofficial].
2.  **Loop:** For bounce index $i$ from $0$ to $N_{\text{max}}-1$:
    a.  **March:** Perform SDF ray marching along $\mathbf{r}$ to find the closest intersection distance $t$ [S5, unofficial].
    b.  **Hit Handling:**
        i.  If intersection found ($t \ge 0$):
            1.  Compute intersection point: $\mathbf{p} = \mathbf{r}.\text{origin} + t \cdot \mathbf{r}.\text{direction}$ [S5, unofficial].
            2.  Compute surface normal $\mathbf{n}$ using the SDF gradient:
                $$ \mathbf{n} = \frac{\nabla f(\mathbf{p})}{\|\nabla f(\mathbf{p})\|} $$
                where $\nabla f(\mathbf{p})$ is estimated via finite differences [S5, unofficial].
            3.  Compute direct illumination $\mathbf{C}_{\text{light}}$ at $\mathbf{p}$ using $\mathbf{n}$, view direction, and light sources [S5, unofficial].
            4.  Accumulate color: $\mathbf{C}_{\text{acc}} \leftarrow \mathbf{C}_{\text{acc}} + \mathbf{M} \odot \mathbf{C}_{\text{light}}$ [S5, unofficial].
            5.  Update mask: $\mathbf{M} \leftarrow \mathbf{M} \cdot c_{\text{refl}}$ [S5, unofficial].
            6.  Check termination: If $\|\mathbf{M}\| < \epsilon$ (e.g., $0.001$), break loop [S7, unofficial].
            7.  Prepare next ray:
                *   Compute reflected direction: $\mathbf{r}_{\text{new\_d}} = \mathbf{r}.\text{direction} - 2(\mathbf{r}.\text{direction} \cdot \mathbf{n})\mathbf{n}$ [S3, unofficial].
                *   Guard against degenerate normals: If $\|\mathbf{r}_{\text{new\_d}}\| < 10^{-8}$, set $\mathbf{r}_{\text{new\_d}} = \mathbf{n}$ [S1, unofficial].
                *   Offset origin to prevent self-intersection (shadow acne): $\mathbf{p}_{\text{new}} = \mathbf{p} + \mathbf{n} \cdot \delta$, where $\delta = 0.05$ [S5, unofficial] or $\delta = 0.001$ [S7, unofficial].
                *   Set $\mathbf{r} = (\mathbf{p}_{\text{new}}, \mathbf{r}_{\text{new\_d}})$ [S5, unofficial].
        ii. If no intersection found:
            1.  If $i=0$ (primary ray missed), set $\mathbf{C}_{\text{acc}} = (0.3, 0.2, 0.8)$ [S5, unofficial].
            2.  Else, add background contribution: $\mathbf{C}_{\text{acc}} \leftarrow \mathbf{C}_{\text{acc}} + \mathbf{M} \odot \mathbf{C}_{\text{background}}(\mathbf{r})$ [S7, unofficial].
            3.  Break loop [S7, unofficial].
3.  **Post-Processing:**
    a.  Apply tone mapping: $\mathbf{C}_{\text{acc}} = \frac{\mathbf{C}_{\text{acc}}}{\mathbf{C}_{\text{acc}} + \mathbf{1}}$ [S5, unofficial].
    b.  Apply gamma correction: $\mathbf{C}_{\text{out}} = \mathbf{C}_{\text{acc}}^{(1/\gamma)}$, typically $\gamma = 1.1$ [S5, unofficial].

**Pseudocode:**
```python
def ray_march_with_reflections(ray_origin, ray_direction, sdf_func, max_bounces, c_refl, epsilon=0.001):
    """
    ray_origin: vec3
    ray_direction: vec3 (normalized)
    sdf_func: function(x) -> float
    max_bounces: int
    c_refl: float (reflection coefficient, 0.0 to 1.0)
    epsilon: float (transmittance threshold)
    """
    accum = vec3(0.0)
    mask = vec3(1.0)
    curr_ray_origin = ray_origin
    curr_ray_dir = ray_direction
    MAX_DIST = 100.0
    
    for i in range(max_bounces):
        # 1. March
        hit_dist = march_sdf(curr_ray_origin, curr_ray_dir, sdf_func, MAX_DIST)
        
        if hit_dist is not None:
            # 2. Hit Found
            p = curr_ray_origin + hit_dist * curr_ray_dir
            
            # 3. Compute Normal
            grad = compute_sdf_gradient(p, sdf_func)
            n = normalize(grad)
            
            # 4. Direct Illumination [G]
            light_dir = normalize(vec3(1.0, 1.0, 1.0))
            diff = max(dot(n, light_dir), 0.0)
            color = vec3(0.8) * diff
            
            # 5. Accumulate
            accum = accum + mask * color
            
            # 6. Update Mask
            mask = mask * c_refl
            
            # 7. Termination Check
            if length(mask) < epsilon:
                break
                
            # 8. Prepare Next Ray
            new_dir = curr_ray_dir - 2.0 * dot(curr_ray_dir, n) * n
            
            # Guard degenerate case
            if length(new_dir) < 1e-8:
                new_dir = n
                
            # Offset origin to prevent self-intersection
            delta = 0.05 
            new_origin = p + n * delta
            
            curr_ray_origin = new_origin
            curr_ray_dir = new_dir
        else:
            # 9. Miss
            if i == 0:
                accum = vec3(0.3, 0.2, 0.8) # Sky color
            else:
                bg_color = vec3(0.1, 0.1, 0.1) # Background color [G]
                accum = accum + mask * bg_color
            break
            
    # 10. Post-processing
    accum = accum / (accum + vec3(1.0))
    gamma = 1.1
    accum = pow(accum, vec3(1.0/gamma))
    
    return accum

def march_sdf(origin, direction, sdf_func, max_dist):
    t = 0.0
    max_steps = 64
    for _ in range(max_steps):
        p = origin + t * direction
        d = sdf_func(p)
        if d < 0.001:
            return t
        if t > max_dist:
            return None
        t += d
    return None

def compute_sdf_gradient(p, sdf_func):
    eps = 0.001
    x = vec3(1, 0, 0)
    y = vec3(0, 1, 0)
    z = vec3(0, 0, 1)
    dx = sdf_func(p + x * eps) - sdf_func(p - x * eps)
    dy = sdf_func(p + y * eps) - sdf_func(p - y * eps)
    dz = sdf_func(p + z * eps) - sdf_func(p - z * eps)
    return vec3(dx, dy, dz) / (2 * eps)
```

**Parameters:**
*   $c_{\text{refl}}$: Reflection coefficient multiplier. Controls the attenuation of color per bounce. Default value: $0.3$ [S5, unofficial].
*   $N_{\text{max}}$: Number of reflection bounces. If $1$, uses a single bounce path. Default value: $0$ (no recursion) [S5, unofficial] or $1$ [S7, unofficial].
*   $\epsilon$: Transmittance threshold. Stops recursion when mask magnitude drops below this value. Default value: $0.001$ [S7, unofficial].
*   $\delta$: Offset distance for ray origin. Prevents self-intersection. Value: $0.05$ [S5, unofficial] or $0.001$ [S7, unofficial].

**Edge Cases and Pitfalls:**
*   **Self-Intersection (Shadow Acne):** Casting a ray from the exact intersection point causes the ray to immediately hit the same surface. Mitigated by offsetting the origin along the normal by $\delta$ [S5, unofficial].
*   **Degenerate Normals:** If the reflection vector becomes near-zero (e.g., grazing angles or numerical instability), it should be clamped to the normal direction to prevent undefined behavior [S1, unofficial].
*   **Infinite Recursion:** Without a termination condition based on transmittance ($\epsilon$) or max bounces, reflective scenes can cause stack overflows or infinite loops [S7, unofficial].

## Subtopics

### Raytracing Extension (Reflections)
Extends basic raycasting by continuing the ray path after intersection to realize reflections, distinguishing raytracing (interaction continuation) from raycasting (single throw) [S8, unofficial].

### Chromatic Dispersion Glass Rendering
Renders glass with Fresnel reflection and per-channel refraction for chromatic dispersion ($n = 1.48/1.50/1.52$) [S9, unofficial]. Falls back to reflected ray on total-internal-reflection and applies distance-compounding tint. The 3-trace dispersion path is gated to grazing angles [S9, unofficial].

### Reflection Blending
Interpolates between specular lighting and environment reflection color based on a blend factor. Computes environment reflection color via an environment map and mixes it with specular sum, resetting specular sum and light Y to 1.0 after blending [S10, unofficial].

## Background
Originating from the generalization of raycasting to raytracing, this method allows for the simulation of light interaction with surfaces beyond the first hit [S8, unofficial]. It is commonly implemented in GLSL-based raymarchers using the `reflect` function [S3, unofficial].
