# Fresnel Reflection/Refraction

Also called: Fresnel Reflection

## Overview
Calculates the Fresnel reflectance for unpolarized light at an interface between two media with different indices of refraction [S1, unofficial]. It determines the ratio of reflected to refracted light based on the angle of incidence, enabling realistic rendering of transparent and reflective surfaces [S1, unofficial]. Unlike basic glass models that ignore angular dependence, this method produces characteristic darkening of glass sides at grazing angles and more accurate caustics beneath the object [S1, unofficial]. It serves as the core weighting function for combining reflected and refracted ray contributions in path tracing and ray marching [S1, unofficial].

## How it works
**Inputs:**
- `incom`: Incoming light direction or view direction (normalized vector).
- `normal`: Surface normal at the intersection point (normalized vector).
- `index_internal`: Refractive index of the internal medium (scalar).
- `index_external`: Refractive index of the external medium (scalar).

**Outputs:**
- `reflectance`: Scalar value between 0.0 and 1.0 representing the fraction of light reflected.

**Data Structures:**
None required beyond standard scalar and vector types.

**Steps:**
1. Calculate the ratio of indices of refraction:
   $$ \eta = \frac{\text{index\_internal}}{\text{index\_external}} $$
2. Calculate the cosine of the angle of incidence ($\theta_1$):
   $$ \cos\theta_1 = \text{dot}(\text{incom}, \text{normal}) $$
   Note: The sign of `dot` depends on whether `incom` points towards or away from the surface relative to the normal. Standard implementations often assume `incom` is the view direction pointing out, or handle the sign explicitly. The source uses `dot(incom, normal)` directly.
3. Calculate the squared cosine of the angle of refraction ($\theta_2$) using Snell's law derived identity:
   $$ \cos^2\theta_2 = 1.0 - \eta^2 \cdot (1.0 - \cos\theta_1 \cdot \cos\theta_1) $$
4. Check for Total Internal Reflection (TIR):
   - If $\cos^2\theta_2 < 0.0$, return $1.0$ (all light is reflected).
5. Calculate the cosine of the angle of refraction:
   $$ \cos\theta_2 = \sqrt{\cos^2\theta_2} $$
6. Calculate the Fresnel s-polarized reflectance term ($r_s$):
   $$ r_s = \frac{\text{index\_internal} \cdot \cos\theta_1 - \text{index\_external} \cdot \cos\theta_2}{\text{index\_internal} \cdot \cos\theta_1 + \text{index\_external} \cdot \cos\theta_2} $$
7. Calculate the Fresnel p-polarized reflectance term ($r_p$):
   $$ r_p = \frac{\text{index\_internal} \cdot \cos\theta_2 - \text{index\_external} \cdot \cos\theta_1}{\text{index\_internal} \cdot \cos\theta_2 + \text{index\_external} \cdot \cos\theta_1} $$
8. Return the average reflectance for unpolarized light:
   $$ \text{reflectance} = \frac{r_s^2 + r_p^2}{2} $$

**Pseudocode:**
```python
def fresnel_reflectance(incom: Vec3, normal: Vec3, index_internal: float, index_external: float) -> float:
    # 1. Calculate eta
    eta = index_internal / index_external
    
    # 2. Calculate cos_theta1
    cos_theta1 = dot(incom, normal)
    
    # 3. Calculate cos_theta2 squared
    # Using identity: sin^2(theta2) = eta^2 * sin^2(theta1)
    # cos^2(theta2) = 1 - sin^2(theta2)
    cos_theta2_sq = 1.0 - (eta * eta) * (1.0 - cos_theta1 * cos_theta1)
    
    # 4. Check for Total Internal Reflection
    if cos_theta2_sq < 0.0:
        return 1.0
    
    # 5. Calculate cos_theta2
    cos_theta2 = sqrt(cos_theta2_sq)
    
    # 6. Calculate Fresnel s-polarized reflectance term
    numerator_s = index_internal * cos_theta1 - index_external * cos_theta2
    denominator_s = index_internal * cos_theta1 + index_external * cos_theta2
    fresnel_rs = numerator_s / denominator_s
    
    # 7. Calculate Fresnel p-polarized reflectance term
    numerator_p = index_internal * cos_theta2 - index_external * cos_theta1
    denominator_p = index_internal * cos_theta2 + index_external * cos_theta1
    fresnel_rp = numerator_p / denominator_p
    
    # 8. Return average reflectance for unpolarized light
    return (fresnel_rs * fresnel_rs + fresnel_rp * fresnel_rp) * 0.5
```

**Usage in Shading:**
In a fragment shader or path tracer, the Fresnel factor $k_R$ is used to blend reflected and refracted colors:
1. Calculate $k_R = \text{fresnel\_reflectance}(-\text{eye}, \text{normal}, 1.0, \text{IOR})$ [S1, unofficial].
2. Calculate transmission factor $k_T = 1.0 - k_R$ [S1, unofficial].
3. Combine colors: $\text{color} = k_R \cdot \text{reflectColor} + k_T \cdot \text{refractColor}$ [S1, unofficial].

**Parameters:**
- `incom`: Incoming light direction (or view direction) [S1, unofficial].
- `normal`: Surface normal [S1, unofficial].
- `index_internal`: Refractive index of the internal medium [S1, unofficial].
- `index_external`: Refractive index of the external medium [S1, unofficial].

## Subtopics

### [Fresnel Glass Material](21285-fresnel-glass-material.md)
The Fresnel Glass Material is a shading model for transparent dielectric objects (such as glass, water, or diamond) that simulates the bending of light (refraction) and partial reflection at boundaries. It solves the problem of rendering realistic transparent surfaces by dynamically adjusting the ratio of reflected to refracted light based on the angle of incidence, using the Schlick approximation. Unlike basic glass models that ignore angular dependence, this method produces characteristic darkening of glass sides at grazing angles and more accurate caustics beneath the object.

### [Window Refraction and Fresnel Transmission](21372-window-refraction-and-fresnel-transmission.md)
This method models light transmission through a planar window (a medium with a refractive index between two parallel surfaces) in a ray-marching context. It calculates the refracted ray direction using Snell's law and applies Fresnel coefficients to determine the transmission loss, updating the ray's luminosity accordingly. It is distinct from simple transmission models by explicitly accounting for the angular dependence of reflectance at the interface boundaries.

### Complex-Indexed Fresnel Tint
An OpenPBR-style edge coloring technique for metals using complex-indexed Fresnel calculations, allowing for non-white edge highlights [S2, unofficial]. It uses an `edgeTint` parameter to control the color of the edge tint; a white value reproduces the Schlick approximation exactly [S2, unofficial]. A key pitfall is that standard real-index Fresnel must not be used; complex-indexed Fresnel calculations are required to correctly model metallic edge colors [S2, unofficial].

### Glass Block Transmission
Traces a ray through a homogeneous glass block, handling entry refraction, Beer-Lambert absorption, exit refraction, and total internal reflection (TIR) [S3, unofficial]. It determines the oriented normal, refracts the ray, marches through the medium to find the exit, applies absorption based on `u_glass_density`, and refracts the ray out upon exit [S3, unofficial]. If the ray exits to a different solid, it sets the landing state; if the depth limit is exhausted, it returns false [S3, unofficial].
