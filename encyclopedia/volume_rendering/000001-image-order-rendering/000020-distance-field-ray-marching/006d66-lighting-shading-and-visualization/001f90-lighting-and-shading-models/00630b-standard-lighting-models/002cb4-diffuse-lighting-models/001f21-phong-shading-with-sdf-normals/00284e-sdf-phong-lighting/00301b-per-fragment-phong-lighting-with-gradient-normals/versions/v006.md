# Per-Fragment Phong Lighting with Gradient Normals

Also called: Gradient-based Phong Shading, Phong Lighting with Gradient Normals, Phong Shading with Gradient Normals

## Overview
Per-fragment Phong Lighting with Gradient Normals is a volume rendering shading technique that enhances the visual perception of internal structures by applying Phong or Gouraud shading models to voxels based on normals derived from the scalar field's gradient [S1, S2]. It distinguishes itself from standard threshold-based shading by providing a "realistic" 3D view through dynamic lighting calculations that interact with the volume's internal density variations, rather than relying solely on surface boundaries [S2].

## How it works
**Inputs and Outputs:**
*   **Input:** A 3D scalar field (density values), a light vector, and rendering parameters including a threshold value, an interpolation mode, and a highlight toggle [S2].
*   **Output:** A 2D image where each fragment's color is modulated by the Phong lighting model [S2].

**Data Structures:**
*   **Scalar Field:** A 3D grid of density values stored with 12-bit precision, ranging from 0 to 4095 [S2].
*   **Light Vector:** A 3D vector $(L_x, L_y, L_z)$ that dynamically moves with the view vector [S2].
*   **Normal Vector:** A 3D vector $(N_x, N_y, N_z)$ calculated per fragment from the scalar field gradient [S1, S2].

**Steps:**
1.  **Ray Marching:** Cast rays through the volume and sample the scalar field at each step [S2].
2.  **Gradient Calculation:** For each sample point, compute the gradient of the scalar field to estimate the surface normal [S1, S2]. Use the selected interpolation mode (nearest neighbor or trilinear) to retrieve density values for the finite difference calculation [S2].
3.  **Normalization:** Normalize the resulting gradient vector to unit length [G].
4.  **Threshold Check:** Compare the sampled density value $\phi$ against the user-defined threshold $T$ [S2]. If $\phi < T$, skip shading for this step [S2]. If $\phi \ge T$, proceed to lighting calculation [S2].
5.  **Lighting Calculation:** Compute the shading color using the Phong or Gouraud model with the estimated normal and the light vector [S2]. If the highlight toggle is enabled, include the specular component in the calculation [S2].
6.  **Compositing:** Blend the shaded color and opacity along the ray using front-to-back alpha blending [G].

**Parameters:**
*   **Threshold Value ($T$):** Selects the density region for shading [S2]. Range: 0 to 4095 [S2]. Typical values: ~400 for skin, ~1700 for bones, 3200 for teeth [S2].
*   **Light Vector:** Moves with the view vector [S2].
*   **Interpolation Mode:** Nearest neighbor or trilinear [S2].
*   **Highlight Toggle:** Boolean to enable or disable specular highlights [S2].

**Pseudocode:**
```python
def per_fragment_phong_gradient_normal(scalar_field, ray_origin, ray_direction, max_distance, step_size, threshold, interpolation_mode, enable_highlights):
    # Initialize accumulated color and opacity
    acc_color = [0.0, 0.0, 0.0]
    acc_opacity = 0.0

    t = 0.0
    while t < max_distance:
        pos = [ray_origin[i] + t * ray_direction[i] for i in range(3)]
        density = sample_scalar_field(scalar_field, pos, interpolation_mode)

        # Threshold check
        if density < threshold:
            t += step_size
            continue

        # Calculate normal from gradient
        grad = compute_gradient(scalar_field, pos, interpolation_mode)
        normal = normalize(grad)

        # View and Light vectors
        view_vector = normalize([-ray_direction[i] for i in range(3)])
        light_vector = get_light_vector(view_vector)

        # Phong Lighting Model
        diff = max(0.0, dot(normal, light_vector))
        spec = 0.0
        if enable_highlights:
            reflection = reflect(light_vector, normal)
            spec = pow(max(0.0, dot(reflection, view_vector)), 32.0) # Standard shininess [G]

        # Combine lighting
        shading_factor = 0.2 + 0.8 * diff + 0.5 * spec # Standard ambient/diffuse/specular weights [G]

        # Get base color and opacity from transfer function
        base_color = transfer_function_color(density)
        base_opacity = transfer_function_opacity(density)

        # Apply shading to color
        shaded_color = [base_color[i] * shading_factor for i in range(3)]

        # Alpha compositing (front-to-back)
        alpha = base_opacity * step_size
        acc_color = [acc_color[i] + shaded_color[i] * alpha * (1.0 - acc_opacity) for i in range(3)]
        acc_opacity = acc_opacity + alpha * (1.0 - acc_opacity)

        if acc_opacity >= 1.0:
            break
        t += step_size

    return acc_color

def sample_scalar_field(field, pos, mode):
    # [G] Standard grid sampling with boundary clamping
    ix, iy, iz = int(pos[0]), int(pos[1]), int(pos[2])
    if mode == 'nearest':
        return field[ix][iy][iz]
    elif mode == 'trilinear':
        # [G] Trilinear interpolation implementation
        fx, fy, fz = pos[0] - ix, pos[1] - iy, pos[2] - iz
        c000 = field[ix][iy][iz]
        c100 = field[ix+1][iy][iz]
        c010 = field[ix][iy+1][iz]
        c110 = field[ix+1][iy+1][iz]
        c001 = field[ix][iy][iz+1]
        c101 = field[ix+1][iy][iz+1]
        c011 = field[ix][iy+1][iz+1]
        c111 = field[ix+1][iy+1][iz+1]
        lerp1 = c000 * (1-fx) + c100 * fx
        lerp2 = c010 * (1-fx) + c110 * fx
        lerp3 = c001 * (1-fx) + c101 * fx
        lerp4 = c011 * (1-fx) + c111 * fx
        lerp5 = lerp1 * (1-fy) + lerp2 * fy
        lerp6 = lerp3 * (1-fy) + lerp4 * fy
        return lerp5 * (1-fz) + lerp6 * fz
    return 0.0

def compute_gradient(field, pos, mode):
    h = 1.0 # [G] Grid spacing assumption
    # Central differences
    gx = (sample_scalar_field(field, [pos[0]+h, pos[1], pos[2]], mode) - sample_scalar_field(field, [pos[0]-h, pos[1], pos[2]], mode)) / (2.0*h)
    gy = (sample_scalar_field(field, [pos[0], pos[1]+h, pos[2]], mode) - sample_scalar_field(field, [pos[0], pos[1]-h, pos[2]], mode)) / (2.0*h)
    gz = (sample_scalar_field(field, [pos[0], pos[1], pos[2]+h], mode) - sample_scalar_field(field, [pos[0], pos[1], pos[2]-h], mode)) / (2.0*h)
    return [gx, gy, gz]

def normalize(v):
    mag = (v[0]**2 + v[1]**2 + v[2]**2)**0.5
    if mag == 0: return [0.0, 0.0, 0.0]
    return [v[0]/mag, v[1]/mag, v[2]/mag]

def dot(v1, v2):
    return v1[0]*v2[0] + v1[1]*v2[1] + v1[2]*v2[2]

def reflect(light, normal):
    return [2.0*dot(normal, light)*normal[i] - light[i] for i in range(3)]

def get_light_vector(view):
    # [G] Light vector moves with view vector, typically opposite to view for front lighting
    return normalize([-view[0], -view[1], -view[2]])

def transfer_function_color(density):
    # [G] Simple linear mapping from density to grayscale color
    v = density / 4095.0
    return [v, v, v]

def transfer_function_opacity(density):
    # [G] Simple linear mapping from density to opacity
    return density / 4095.0
```

## Subtopics

### [Diffuse Lighting for Volume Ray Casting](6760-diffuse-lighting-for-volume-ray-casting.md)
Diffuse Lighting for Volume Ray Casting illuminates a volume by calculating normals for every voxel using finite differences of the scalar field, then applying a diffuse lighting model. It provides geometric cues that allow standard diffuse lighting models to interact with the volume's internal structure.

### [Phong Shading with Boundary Enhancement and Facing Subtraction](15408-phong-shading-with-boundary-enhancement-and-facing-subtracti.md)
This method extends per-fragment Phong lighting by applying two alpha-modulation techniques to enhance the visual perception of volume boundaries: boundary enhancement via absorption approximation and facing subtraction for silhouette definition. It distinguishes itself from standard gradient-based Phong shading by explicitly modifying the fragment alpha based on the gradient magnitude and the view direction relative to the surface normal.

## Operating characteristics
*   **Time Complexity:** $O(N)$ where $N$ is the number of samples along all rays [G]. Gradient calculation requires additional samples depending on the finite difference scheme [G].
*   **Memory Complexity:** $O(V)$ where $V$ is the volume of the scalar field, required to store the density values [G].
*   **Performance:** The method is interactive when combined with transfer function pre-integration [S1].
*   **Strengths:** Provides a realistic 3D impression by leveraging internal density gradients, not just surfaces [S2]. Allows selective shading of specific tissue types via thresholding [S2].
*   **Limitations:** Can only visualize one tissue type at a time if using a single threshold, unlike full volume rendering which assigns opacity to all tissues [S2]. Gradient noise can lead to noisy normals if the scalar field is not smooth [G].
*   **When to use:** When a realistic, shaded appearance of specific internal structures (e.g., bones, skin) is desired, and the user wants to control which density ranges are illuminated [S2].
*   **When not to use:** When simultaneous visualization of multiple tissue types with varying opacities is required (use full Volume Rendering instead) [S2].

## Background
This method originates from early volume visualization applications, specifically the "VOLUME RENDERING Application" by Thomas Lidy (2001–2002) [S2]. It was designed to provide a "realistic" view of medical datasets (human skin, bones, teeth) by applying Phong or Gouraud shading to density gradients [S2]. It was later referenced in the context of flexible transfer function design tools, where it served as a shading option for volume exploration [S1]. The technique relies on the principle that the gradient of a scalar field approximates the surface normal, even for implicit surfaces defined by the field [S1, S2].
