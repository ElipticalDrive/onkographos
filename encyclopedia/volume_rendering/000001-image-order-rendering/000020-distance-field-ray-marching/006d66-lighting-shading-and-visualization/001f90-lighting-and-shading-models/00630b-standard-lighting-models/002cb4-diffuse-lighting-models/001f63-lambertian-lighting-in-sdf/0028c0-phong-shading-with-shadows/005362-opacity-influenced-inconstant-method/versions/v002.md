# Opacity Influenced Inconstant Method

Also called: Hololighting shading method, new hololighting style, proposed shading method

## Overview
The Opacity Influenced Inconstant Method is a shading technique for 3D holographic pyramid rendering that extends Phong shading by introducing an opacity variable to enhance depth cues and reveal the internal structure of 3D models [S1]. It differs from its parent, [Phong Shading with Shadows](4356-phong-shading-with-shadows.md), by modulating diffuse and ambient lighting with opacity to create a transparent, holographic appearance, and by using a specific multi-light configuration to maximize shape perception without casting shadows [S1]. Unlike [Lighting Transfer Function](6468-lighting-transfer-function.md) which focuses on energy conservation, this method prioritizes visual depth cues for holographic displays [S1]. The method achieves hologram views by dividing the screen into nine segments using `glViewport` in OpenGL to provide four views (right, left, front, back) [S1].

## How it works
The method modifies the standard Phong lighting model by adding an opacity component and adjusting the light source configuration [S1]. It is designed for rendering 3D objects on holographic pyramid displays, where the screen is divided into segments to provide multiple views [S1].

### Inputs and Outputs
*   **Inputs:**
    *   3D model geometry (vertices, normals) [S1].
    *   Material properties: Ambient color ($I_a$), Diffuse color ($h_d$), Specular color ($I_s$) [S1].
    *   Camera position (fixed at eye position $(0,0,0)$ relative to the object for maximum opacity impact) [S1].
    *   Six point light source positions: Above, Upper Left, Upper Right, Bottom, Lower Left, Lower Right [S1].
*   **Outputs:**
    *   Final pixel color intensity ($I$) for each view segment [S1].

### Formulas and Definitions
1.  **Opacity ($I_o$):** Calculated as the dot product of the view vector ($V$) and the surface normal ($N$) [S1].
    $$I_o = V \cdot N$$
    *   $V$: Unit vector from the surface point to the camera (view vector).
    *   $N$: Unit normal vector at the surface point.
    *   Note: The viewing point must be parallel to the object (at eye position $(0,0,0)$) to achieve the highest impact of opacity [S1].

2.  **Light Attenuation ($att$):** Uses a linear attenuation model [S1]. The quadratic factor is removed because it is insignificant at small distances compared to the linear factor [S1].
    $$att = \frac{1.0}{K_c + K_l \cdot d}$$
    *   $d$: Distance between the light source and the surface point.
    *   $K_c$: Constant factor, never smaller than 1 [S1].
    *   $K_l$: Linear attenuation factor [S1].

3.  **Diffuse Component ($I_d$):**
    $$I_d = att \cdot h_d (L \cdot N)$$
    *   $L$: Unit vector from the surface point to the light source.
    *   $h_d$: Diffuse material color/intensity [S1].
    *   $(L \cdot N)$: Dot product of light direction and normal.

4.  **Specular Component ($I_s$):** Calculated using the standard Phong reflection model (dot product between view vector $V$ and reflection vector $R$), though the specific exponent is not detailed in the source text [S1]. The source notes that the specular impression is decreased from the "upper right" and "above" lights, and the impact of the three lights under the object is omitted, preserving only the "upper left" light's full influence [S1].

5.  **Final Intensity ($I$):** The sum over all lights $i$ of the ambient and diffuse components multiplied by opacity, plus the specular component [S1].
    $$I = \sum_{i=1}^{lights} ((I_a + I_d) \cdot I_o) + I_s$$
    *   $I_a$: Ambient color/intensity [S1].
    *   $I_o$: Opacity calculated per surface point [S1].
    *   $I_s$: Specular contribution [S1].

### Parameters and Configuration
*   **Light Sources:** Six point lights are used [S1]:
    1.  Above
    2.  Upper Left
    3.  Upper Right
    4.  Bottom
    5.  Lower Left
    6.  Lower Right
*   **Light Weighting:**
    *   The specular contribution from the "Upper Right" and "Above" lights is decreased to provide adequate shining [S1].
    *   The impact of the three lights under the object (Bottom, Lower Left, Lower Right) is omitted for specular highlights, except the "Upper Left" light preserves its full influence [S1].
    *   Shadows are not calculated; the method ensures shadows do not appear [S1].
*   **Attenuation Constants:**
    *   $K_c \ge 1$ [S1].
    *   $K_l$: Linear factor (value not specified) [S1].
    *   $K_q = 0$ (Quadratic factor removed) [S1].
*   **Viewing Position:** The camera/viewer must be at the eye position $(0,0,0)$ relative to the object to maximize the opacity effect [S1].

### Pseudocode
```python
class Vec3:
    def __init__(self, x, y, z): self.x, self.y, self.z = x, y, z
    def __add__(self, o): return Vec3(self.x+o.x, self.y+o.y, self.z+o.z)
    def __sub__(self, o): return Vec3(self.x-o.x, self.y-o.y, self.z-o.z)
    def __mul__(self, s): return Vec3(self.x*s, self.y*s, self.z*s)
    def dot(self, o): return self.x*o.x + self.y*o.y + self.z*o.z
    def length(self): return (self.x**2 + self.y**2 + self.z**2)**0.5
    def normalize(self):
        l = self.length()
        return Vec3(self.x/l, self.y/l, self.z/l) if l > 0 else Vec3(0,0,0)
    def reflect(self, n):
        d = 2 * self.dot(n)
        return Vec3(self.x - d*n.x, self.y - d*n.y, self.z - d*n.z)
    def max(self, v): return Vec3(max(self.x, v), max(self.y, v), max(self.z, v))
    def pow(self, e): return Vec3(self.x**e, self.y**e, self.z**e)

def opacity_influenced_inconstant_shading(surface_point, normal, view_vector, material, lights):
    # material contains: Ia (ambient color), h_d (diffuse color), Is (specular color), shininess
    # lights is a list of 6 Light objects with attributes: position, name
    Io = view_vector.dot(normal)
    final_color = Vec3(0.0, 0.0, 0.0)
    for light in lights:
        L = (light.position - surface_point).normalize()
        d = (light.position - surface_point).length()
        Kc = 1.0 # Source states Kc is never smaller than 1
        Kl = 0.5 # Not given in the sources.
        att = 1.0 / (Kc + Kl * d)
        diffuse_term = max(0.0, L.dot(normal))
        Id = att * material.h_d * diffuse_term
        R = (-L).reflect(normal)
        specular_term = max(0.0, view_vector.dot(R)).pow(material.shininess)
        Is = material.Is * specular_term
        # Apply light-specific specular weighting
        if light.name in ["Upper Right", "Above"]:
            Is = Is * 0.5 # Not given in the sources.
        elif light.name in ["Bottom", "Lower Left", "Lower Right"]:
            Is = Vec3(0.0, 0.0, 0.0) # Omitted
        elif light.name == "Upper Left":
            pass # Preserves full influence
        # Combine according to formula: I = sum(((Ia + Id) * Io) + Is)
        final_color = final_color + ((material.Ia + Id) * Io) + Is
    return final_color
```

### Edge Cases and Pitfalls
*   **Viewing Angle:** The opacity calculation $I_o = V \cdot N$ relies on the view vector [S1]. If the camera is not at the designated eye position $(0,0,0)$ or if the object is rotated such that the view vector is not parallel to the object as intended, the opacity impact may vanish or become incorrect [S1].
*   **Rotation Method:** When generating hologram views, the object must be rotated 90 degrees around the camera, not the camera around the object [S1]. Rotating the camera causes the opacity impact to vanish in side views because the opacity calculation depends on the view vector relative to the normal [S1].
*   **Degenerate Normals:** If the normal is perpendicular to the view vector, $I_o$ becomes 0, making the object completely transparent for ambient and diffuse components [S1]. This is the intended behavior for "inner view" but may cause visual artifacts if not handled correctly in compositing [S1].

## Operating characteristics
*   **Time Complexity:** Linear with respect to the number of pixels and the number of light sources ($O(P \cdot L)$), where $P$ is the number of pixels and $L$ is the number of lights (6) [S1].
*   **Memory Complexity:** Not given in the sources.
*   **Performance:** Tested on Windows 10 with a Core i7 2.50 GHz processor and 16 GB RAM using C++ and OpenGL [S1]. Specific frame rates are not provided [S1].
*   **Strengths:**
    *   Provides clear depth cues and shape perception for holographic displays [S1].
    *   Allows viewing of inner object structures through opacity modulation [S1].
    *   User study showed 94.35% of respondents perceived real depth/volume with this method [S1].
    *   90.3% of respondents preferred this method over traditional Phong shading for depth cues on hologram pyramid displays [S1].
*   **Limitations:**
    *   Requires specific camera positioning (eye position $(0,0,0)$) for optimal opacity effect [S1].
    *   Designed specifically for 3D holographic pyramid rendering [S1].
    *   Lacks shadow calculation, which may reduce realism in non-holographic contexts [S1].

## Background
The Opacity Influenced Inconstant Method was proposed for 3D holographic pyramid rendering to address the need for better depth cues and the ability to view the inside of 3D models [S1]. It extends the Phong shading model by adding an opacity variable [S1]. The method was implemented in C++ and OpenGL and evaluated through user studies involving students [S1]. The research was published in the Al-Mustansiriyah Journal of Science in 2019 [S1].
