# Phong Shading with SDF Normals

Also called: Phong Shading using SDF Gradients, normal vector interpolation shading

## Overview
Phong Shading with SDF Normals is a lighting model for ray-marched Signed Distance Fields (SDFs) that applies the Phong reflection model using surface normals estimated from the SDF gradient [S2, unofficial]. Unlike [Lambertian Lighting in SDF](2023-lambertian-lighting-in-sdf.md), which computes only diffuse illumination, this method includes specular highlights, providing a shinier appearance [S2, unofficial]. It differs from [Blinn-Phong Shading in Volume Rendering](2809-blinn-phong-shading-in-volume-rendering.md) by using the exact reflection vector $\mathbf{r}$ rather than the half-vector, and from [Gouraud Shading](4645-gouraud-shading.md) by computing lighting per-fragment using interpolated or gradient-derived normals rather than interpolating pre-computed vertex colors [S1].

## How it works
**Inputs:**
*   Surface point $\mathbf{p}$ (position in world space).
*   SDF function $f(\mathbf{x})$.
*   Light positions $\mathbf{l}_j$ and intensities $\vec{i}_j$ (RGB vectors) for $j=1 \dots N$.
*   Material properties: diffuse coefficient $\vec{k}_d$ (RGB), specular coefficient $\vec{k}_s$ (RGB), shininess $\alpha$ (scalar).
*   Camera position $\mathbf{c}$.

**Outputs:**
*   Final color $\vec{C}$ (RGB vector).

**Data Structures:**
*   Vectors are 3D floats.
*   Dot products yield scalars.
*   Element-wise multiplication ($\odot$) applies to RGB vectors.

**Steps:**

1.  **Compute Normal:** Estimate the surface normal $\hat{\mathbf{n}}$ at $\mathbf{p}$ using the SDF gradient $\nabla f(\mathbf{p})$. As per the parent [Diffuse Lighting Models](5343-diffuse-lighting-models.md), this is typically done via finite differences:
    $$ \hat{\mathbf{n}} = \frac{\nabla f(\mathbf{p})}{\|\nabla f(\mathbf{p})\|} $$
    [G] Ensure $\nabla f(\mathbf{p})$ is not zero to avoid division by zero; if zero, use a default normal (e.g., $\mathbf{0}$ or $\mathbf{1}$) or skip lighting.

2.  **Compute Directions:**
    *   View direction: $\hat{\mathbf{v}} = \frac{\mathbf{c} - \mathbf{p}}{\|\mathbf{c} - \mathbf{p}\|}$.
    *   For each light $j$:
        *   Light direction: $\hat{\mathbf{l}}_j = \frac{\mathbf{l}_j - \mathbf{p}}{\|\mathbf{l}_j - \mathbf{p}\|}$.
        *   Reflection direction: $\hat{\mathbf{r}}_j = 2(\hat{\mathbf{n}} \cdot \hat{\mathbf{l}}_j)\hat{\mathbf{n}} - \hat{\mathbf{l}}_j$.

3.  **Accumulate Lighting:** Initialize total color $\vec{C} = \vec{0}$. For each light $j$:
    *   Compute diffuse term: $D_j = \max(0, \hat{\mathbf{n}} \cdot \hat{\mathbf{l}}_j)$.
    *   Compute specular term: $S_j = \max(0, \hat{\mathbf{r}}_j \cdot \hat{\mathbf{v}})^\alpha$.
    *   [S2, unofficial] If either dot product is negative, the term is clipped to zero.
    *   Compute contribution: $\vec{C}_j = (D_j \odot \vec{k}_s \odot \vec{i}_j) + (S_j \odot \vec{k}_d \odot \vec{i}_j)$.
    *   [S2, unofficial] Note: The source formula [S2, unofficial] assigns $\vec{k}_s$ to the diffuse dot product and $\vec{k}_d$ to the specular dot product, which is non-standard (typically $\vec{k}_d$ is diffuse, $\vec{k}_s$ is specular). However, the source explicitly states: "contribute a term $(\hat{L} \cdot \hat{N})(\vec{k}_s \odot \vec{i}) + (\hat{R} \cdot \hat{V})^\alpha (\vec{k}_d \odot \vec{i})$". We follow the source's explicit formula [S2, unofficial].
    *   $\vec{C} \leftarrow \vec{C} + \vec{C}_j$.

4.  **Return Color:** Return $\vec{C}$.

**Pseudocode:**
```python
def phong_shading_sdf(p, sdf_func, lights, material, camera_pos):
    # 1. Compute Normal
    eps = 1e-4
    grad = vec3(
        sdf_func(p + vec3(eps, 0, 0)) - sdf_func(p - vec3(eps, 0, 0)),
        sdf_func(p + vec3(0, eps, 0)) - sdf_func(p - vec3(0, eps, 0)),
        sdf_func(p + vec3(0, 0, eps)) - sdf_func(p - vec3(0, 0, eps))
    ) / (2 * eps)
    n_hat = normalize(grad)
    
    # 2. View Direction
    v_hat = normalize(camera_pos - p)
    
    color = vec3(0.0)
    
    for light in lights:
        # 3. Light Directions
        l_hat = normalize(light.position - p)
        r_hat = reflect(-l_hat, n_hat) # reflect(vector, normal) computes 2*(N.L)*N - L
        
        # 4. Dot Products
        nl = dot(n_hat, l_hat)
        rv = dot(r_hat, v_hat)
        
        # Clip negative values
        nl = max(nl, 0.0)
        rv = max(rv, 0.0)
        
        # 5. Phong Contribution (per source [S2, unofficial] formula)
        # Note: Source swaps k_s and k_d roles compared to standard convention
        diffuse_term = nl * (material.k_s * light.intensity)
        specular_term = pow(rv, material.alpha) * (material.k_d * light.intensity)
        
        color += diffuse_term + specular_term
        
    return color
```

**Parameters:**
*   $\vec{k}_s$: Specular reflection coefficient (RGB vector) [S2, unofficial].
*   $\vec{k}_d$: Diffuse reflection coefficient (RGB vector) [S2, unofficial].
*   $\alpha$: Shininess exponent (scalar) [S2, unofficial].
*   $\vec{i}$: Light intensity (RGB vector) [S2, unofficial].

**Edge Cases:**
*   **Zero Gradient:** If $\nabla f(\mathbf{p}) \approx \mathbf{0}$, the normal is undefined. [G] Return ambient color or black.
*   **Negative Dot Products:** Terms with negative dot products are ignored (clipped to zero) [S2, unofficial].

## Subtopics

### [SDF Phong Lighting](4260-sdf-phong-lighting.md)
Applies directional diffuse and specular lighting to SDF text using estimated normals and configurable light angles. It builds on this method by computing lighting contributions per fragment based on the Phong reflection model.

## Operating characteristics
*   **Time Complexity:** $O(N)$ per fragment, where $N$ is the number of lights. Each light requires gradient estimation (constant time, 6 SDF queries for finite differences) and vector operations.
*   **Memory Complexity:** $O(1)$ auxiliary memory per fragment.
*   **Performance:** Computationally more expensive than Lambertian shading due to specular calculations and multiple light loops [S2, unofficial]. Gradient estimation adds overhead compared to analytic normals.
*   **Strengths:** Provides realistic specular highlights for SDF surfaces; simple to implement.
*   **Limitations:** Normal estimation via finite differences can be noisy or inaccurate for complex SDFs; performance scales linearly with light count.
*   **When to use:** When specular highlights are desired for SDF-rendered objects and performance allows for multiple light evaluations.
*   **When not to use:** For real-time applications with many lights where performance is critical, or when analytic normals are available.

## Background
Phong shading was originally developed by Bui Tuong Phong for polygonal meshes, computing interpolated normals across facets [S1]. In the context of SDFs, it adapts this concept by deriving normals from the SDF gradient [S2, unofficial]. The specific formula provided in [S2, unofficial] appears in a university project writeup (COS 426 Final Project) and may not reflect standard textbook definitions, particularly regarding the assignment of $\vec{k}_s$ and $\vec{k}_d$ to diffuse and specular terms respectively.
