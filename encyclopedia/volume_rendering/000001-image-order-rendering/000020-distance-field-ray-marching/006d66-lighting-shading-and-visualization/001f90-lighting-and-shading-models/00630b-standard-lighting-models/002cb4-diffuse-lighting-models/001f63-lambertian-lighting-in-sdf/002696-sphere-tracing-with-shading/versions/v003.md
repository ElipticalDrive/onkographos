# Sphere Tracing with Shading


## Overview
Sphere Tracing with Shading is a shading extension of the sphere tracing system that derives surface normals from the Signed Distance Field (SDF) using finite differences, calculates diffuse lighting in world space, and combines a base color with the computed light [S1, unofficial]. It builds on [Sphere Tracing Basics](52-sphere-tracing-basics.md) by replacing the simple base color return with a material function that applies lighting, distinguishing it from unshaded variants.

## How it works
**Inputs and Outputs:**
*   **Input:** Fragment shader input containing local position and view direction; global shader properties `_Color` (base color), `_LightColor0` (light color), `_WorldSpaceLightPos0` (light position/direction); SDF function `scene(pos)`.
*   **Output:** Final fragment color (RGBA).

**Data Structures:**
*   **Constants:**
    *   `MAX_STEPS`: Integer, value 10. Maximum ray marching iterations [S1, unofficial].
    *   `THICKNESS`: Float, value 0.01. SDF distance threshold for a surface hit [S1, unofficial].
    *   `NORMAL_EPSILON`: Float, value 0.01. Offset distance used in finite-difference normal sampling [S1, unofficial].
*   **Global Variables:**
    *   `unity_ObjectToWorld`: 4x4 matrix transforming local object coordinates to world space [S1, unofficial].
    *   `_Color`: `float4` base color of the object [S1, unofficial].
    *   `_LightColor0`: `float4` color and intensity of the main directional light [S1, unofficial].
    *   `_WorldSpaceLightPos0`: `float4` position of the main directional light (xyz component used as direction for directional lights) [S1, unofficial].

**Method Steps:**

1.  **Ray Marching Loop:**
    Initialize `progress = 0`. Iterate `iter` from 0 to `MAX_STEPS`:
    a. Calculate sample point: `samplePoint = pos + dir * progress`.
    b. Evaluate SDF: `distance = scene(samplePoint)`.
    c. Check for hit: If `distance < THICKNESS`, return `material(samplePoint)`.
    d. Advance ray: `progress += distance`.
    e. Check for miss: If `iter == MAX_STEPS`, discard fragment.

2.  **Normal Calculation (`normal(position)`):**
    a. Compute central differences in local object space:
       $$ \Delta_x = \text{scene}(pos + (\epsilon, 0, 0)) - \text{scene}(pos - (\epsilon, 0, 0)) $$
       $$ \Delta_y = \text{scene}(pos + (0, \epsilon, 0)) - \text{scene}(pos - (0, \epsilon, 0)) $$
       $$ \Delta_z = \text{scene}(pos + (0, 0, \epsilon)) - \text{scene}(pos - (0, 0, \epsilon)) $$
       where $\epsilon = \text{NORMAL\_EPSILON}$ [S1, unofficial].
    b. Form gradient vector: `grad = float3(changeX, changeY, changeZ)` [S1, unofficial].
    c. Transform to world space: `worldGrad = mul(unity_ObjectToWorld, float4(grad, 0))`. The w-component is 0 to exclude translation [S1, unofficial].
    d. Normalize: `surfaceNormal = normalize(worldGrad.xyz)` [S1, unofficial].

3.  **Lighting Calculation (`lightColor(position)`):**
    a. Get normal: `surfaceNormal = normal(position)` [S1, unofficial].
    b. Get light direction: `lightDirection = normalize(_WorldSpaceLightPos0.xyz)` [S1, unofficial].
    c. Compute diffuse intensity: `diffuse = saturate(dot(surfaceNormal, lightDirection))` [S1, unofficial].
    d. Return lit color: `return diffuse * _LightColor0` [S1, unofficial].

4.  **Material Composition (`material(position)`):**
    a. Compute lighting: `litColor = lightColor(position)` [S1, unofficial].
    b. Apply base color: `output = _Color * litColor` [S1, unofficial].
    c. Return `output` [S1, unofficial].

**Pseudocode:**

```python
# Constants
MAX_STEPS = 10
THICKNESS = 0.01
NORMAL_EPSILON = 0.01

# Global Properties
# _Color: float4
# _LightColor0: float4
# _WorldSpaceLightPos0: float4
# unity_ObjectToWorld: float4x4

# Scene SDF (from Sphere Tracing Basics)
def scene(pos):
    return length(pos) - 0.5

# Normal Calculation
def normal(position):
    # Central differences in local space
    changeX = scene(position + float3(NORMAL_EPSILON, 0, 0)) - scene(position - float3(NORMAL_EPSILON, 0, 0))
    changeY = scene(position + float3(0, NORMAL_EPSILON, 0)) - scene(position - float3(0, NORMAL_EPSILON, 0))
    changeZ = scene(position + float3(0, 0, NORMAL_EPSILON)) - scene(position - float3(0, 0, NORMAL_EPSILON))
    
    # Gradient in local space
    grad_local = float3(changeX, changeY, changeZ)
    
    # Transform to world space (w=0 for direction)
    grad_world = mul(unity_ObjectToWorld, float4(grad_local, 0))
    
    # Normalize
    return normalize(grad_world.xyz)

# Lighting Calculation
def lightColor(position):
    surfaceNormal = normal(position)
    lightDirection = normalize(_WorldSpaceLightPos0.xyz)
    diffuse = saturate(dot(surfaceNormal, lightDirection))
    return diffuse * _LightColor0

# Material Composition
def material(position):
    return _Color * lightColor(position)

# Fragment Shader
def frag(v2f_input):
    pos = v2f_input.localPosition
    dir = normalize(v2f_input.viewDirection)
    progress = 0
    
    for iter in range(MAX_STEPS):
        samplePoint = pos + dir * progress
        distance = scene(samplePoint)
        
        if distance < THICKNESS:
            return material(samplePoint)
        
        progress += distance
    
    # Discard if max steps exceeded
    discard
```

**Parameters:**
*   `MAX_STEPS`: 10 [S1, unofficial].
*   `THICKNESS`: 0.01 [S1, unofficial].
*   `NORMAL_EPSILON`: 0.01 [S1, unofficial].

**Edge Cases and Pitfalls:**
*   **Depth Buffer:** Sphere-traced geometry does not write correct hardware depth. It must be placed in the `Transparent` render queue with `ZWrite Off` to prevent incorrect occlusion by rasterized geometry [S1, unofficial].
*   **Batching:** Static/dynamic batching breaks because the vertex shader constructs the ray by reading `unity_WorldToObject`, which is only valid per-object. `DisableBatching` must be set to `True` [S1, unofficial].

## Subtopics

### Local Shading with Smooth Mirrors
A shading technique for Kernel-Reflection Sequences (KRS) that uses surface normals derived from the gradient of distance functions, with a smoothing method for discontinuities at mirror planes [S2]. It computes the shading normal using the gradient of the distance function at the sphere-traced surface point and performs lighting computation in either world space or kernel space [S2]. If computing in world space, the transformation matrix for the complete chain must be maintained throughout the iteration to transform kernel gradients to world space [S2]. Discontinuities are smoothed by interpolating between the kernel-to-world-space matrices on the two sides of a mirror when the shaded point is found near a mirror plane during iteration [S2]. The shading algorithm runs only once, after sphere tracing has found the intersection point [S2]. A visible discontinuity of surface normals occurs where the plane of reflection intersects the mirrored geometry if kernel separation is not upheld [S2].

## Operating characteristics
*   **Time Complexity:** Linear with respect to `MAX_STEPS` [S1, unofficial]. Each step involves one SDF evaluation, plus one hit involves six additional SDF evaluations for normal calculation [S1, unofficial].
*   **Memory Complexity:** Constant, requiring only a few scalar variables and matrices [S1, unofficial].
*   **Strengths:** Provides simple, efficient diffuse lighting for SDF objects without requiring explicit mesh normals [S1, unofficial].
*   **Limitations:** Normal estimation via finite differences is approximate and sensitive to `NORMAL_EPSILON` [S1, unofficial]. The method does not support shadows or specular highlights in its basic form [S1, unofficial]. Performance is limited by the number of ray marching steps [S1, unofficial].
*   **When to use:** When simple diffuse shading for procedural SDF geometry is needed and explicit normals are unavailable [S1, unofficial].
*   **When not to use:** When high-precision normals, shadows, or specular reflections are required, or when batching performance is critical [S1, unofficial].
