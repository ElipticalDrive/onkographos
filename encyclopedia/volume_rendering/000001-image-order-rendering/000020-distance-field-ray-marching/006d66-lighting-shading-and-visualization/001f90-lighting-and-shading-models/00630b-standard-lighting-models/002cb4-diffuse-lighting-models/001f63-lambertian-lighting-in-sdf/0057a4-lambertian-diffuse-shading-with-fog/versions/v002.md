# Lambertian Diffuse Shading with Fog

Also called: Lambertian Diffuse with Fog, Lambertian Fog Shading

## Overview
This method computes lighting using Lambertian diffuse reflection, ambient light, and exponential fog, then maps the result to terminal colors with optional gamma correction [S1, unofficial].

## How it works
**Inputs:**
- `materialColor`: A 3-component vector (X, Y, Z) representing the base surface color [S1, unofficial].
- `normal`: The surface normal vector at the hit point [S1, unofficial].
- `LightDirection`: A normalized vector pointing to the light source. Default: `(0.5, 1.0, -0.3)` [S1, unofficial].
- `distance`: The raymarch distance from the camera to the hit point [S1, unofficial].
- `FogDensity`: A scalar parameter controlling fog thickness. Default: `0.03f` [S1, unofficial].
- `EnableFog`: A boolean flag to toggle fog application [S1, unofficial].
- `settings.MapColorsWithGamma`: A boolean flag to toggle gamma correction [S1, unofficial].
- `lighting`: An initial intensity value, typically initialized with the diffuse term or ambient light intensity `0.25f` [S1, unofficial].

**Outputs:**
- An ANSI escape sequence string representing the colored character to be printed to the console [S1, unofficial].

**Data Structures:**
- `materialColor`: 3-component vector with components `X`, `Y`, `Z` [S1, unofficial].
- `normal`: 3-component vector [S1, unofficial].
- `LightDirection`: 3-component vector [S1, unofficial].

**Steps:**
1. Compute the Lambertian diffuse factor:
   $$ \text{diffuse} = \max(0, \text{dot}(\text{normal}, \text{LightDirection})) $$
   where `dot` is the standard dot product [S1, unofficial].
2. Initialize `lighting` with the diffuse term (or add ambient light intensity `0.25f` if required by the implementation) [S1, unofficial].
3. Compute the fog factor using exponential decay:
   $$ \text{fogFactor} = 1.0 - \exp(-\text{distance} \times \text{FogDensity}) $$
   where `exp` is the natural exponential function [S1, unofficial].
4. Apply fog attenuation if enabled:
   $$ \text{lighting} = \text{lighting} \times (1.0 - \text{fogFactor}) \quad \text{if } \text{EnableFog} \text{ is true} $$
   [S1, unofficial].
5. Compute the average material brightness:
   $$ \text{colorIntensity} = \frac{\text{materialColor.X} + \text{materialColor.Y} + \text{materialColor.Z}}{3.0} $$
   [S1, unofficial].
6. Modulate the lighting intensity:
   $$ \text{lighting} = \text{lighting} \times (0.7 + \text{colorIntensity} \times 0.3) $$
   [S1, unofficial].
7. Map the computed lighting to a color:
   - If `!settings.MapColorsWithGamma`, call `MapToColor(lighting, materialColor, theme)` [S1, unofficial].
   - Else, call `MapToColorWithGamma(lighting, materialColor, theme)` [S1, unofficial].
8. In `MapToColor`:
   - `finalColor = materialColor * intensity` (where `intensity` is the final `lighting` value) [S1, unofficial].
   - Clamp each component of `finalColor` to $[0, 1]$ [S1, unofficial].
   - Multiply each component by 255 and round to the nearest integer to get `r`, `g`, `b` [S1, unofficial].
   - Return the ANSI escape sequence `"\u001b[38;2;{r};{g};{b}m"` [S1, unofficial].
9. In `MapToColorWithGamma`:
   - `finalColor = materialColor * intensity` [S1, unofficial].
   - Clamp each component of `finalColor` to $[0, 1]$ [S1, unofficial].
   - Apply gamma correction with gamma value $0.8$:
     $$ r = \text{pow}(\text{clamped\_X}, 1.0 / 0.8) $$
     $$ g = \text{pow}(\text{clamped\_Y}, 1.0 / 0.8) $$
     $$ b = \text{pow}(\text{clamped\_Z}, 1.0 / 0.8) $$
     [S1, unofficial].
   - Multiply each component by 255 and cast to integer [S1, unofficial].
   - Return the ANSI escape sequence `"\u001b[38;2;{r};{g};{b}m"` [S1, unofficial].

**Pseudocode:**
```python
import math

def lambertian_diffuse_shading_with_fog(material_color, normal, light_direction, distance, fog_density, enable_fog, use_gamma):
    # 1. Compute diffuse lighting
    diffuse = max(0.0, math.fsum(normal) * math.fsum(light_direction) if not hasattr(normal, 'dot') else normal.dot(light_direction))
    
    # 2. Initialize lighting with diffuse term
    lighting = diffuse 
    
    # 3. Apply fog attenuation
    if enable_fog:
        fog_factor = 1.0 - math.exp(-distance * fog_density)
        lighting = lighting * (1.0 - fog_factor)
        
    # 4. Modulate by material color intensity
    color_intensity = (material_color.x + material_color.y + material_color.z) / 3.0
    lighting = lighting * (0.7 + color_intensity * 0.3)
    
    # 5. Map to Color
    final_color = (material_color.x * lighting, material_color.y * lighting, material_color.z * lighting)
    
    # Clamp to [0, 1]
    r = max(0.0, min(1.0, final_color[0]))
    g = max(0.0, min(1.0, final_color[1]))
    b = max(0.0, min(1.0, final_color[2]))
    
    if use_gamma:
        gamma = 0.8
        r = math.pow(r, 1.0 / gamma)
        g = math.pow(g, 1.0 / gamma)
        b = math.pow(b, 1.0 / gamma)
        
    # Convert to 0-255 integer
    r_int = int(round(r * 255))
    g_int = int(round(g * 255))
    b_int = int(round(b * 255))
    
    # Return ANSI code
    return f"\u001b[38;2;{r_int};{g_int};{b_int}m"
```

**Parameters:**
- `LightDirection`: Normalized vector. Default: `(0.5, 1.0, -0.3)` [S1, unofficial].
- `AmbientLightIntensity`: Scalar. Default: `0.25f` [S1, unofficial].
- `FogDensity`: Scalar. Default: `0.03f` [S1, unofficial].
- `Gamma`: Scalar. Default: `0.8f` [S1, unofficial].

**Edge Cases and Pitfalls:**
- **Boundary Conditions**: If `distance` is 0, `fogFactor` is 0, so no fog attenuation occurs [S1, unofficial].
- **Precision**: Standard IEEE 754 floating-point arithmetic is sufficient for `exp` and `pow` operations [G].
- **Clamping**: Values outside $[0, 1]$ are clamped before integer conversion to prevent overflow [G].

## Operating characteristics
- **Time Complexity**: O(1) per hit point [G].
- **Memory Complexity**: O(1) [G].
- **Measured Performance**: Not given in the sources.
- **Strengths**: Simple arithmetic operations; provides basic atmospheric depth perception via exponential fog [S1, unofficial].
- **Limitations**: The fog model is a simple exponential decay without light scattering or multiple bounces [G].
- **When to use**: Real-time ASCII raymarching where performance is critical and visual fidelity is secondary to readability [G].
- **When not to use**: High-fidelity rendering or scenes requiring physically accurate light transport [G].
