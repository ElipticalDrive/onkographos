# Realtime Smoke Volume (Ex1604)


## Overview
Realtime Smoke Volume (Ex1604) is a hybrid rendering technique that combines low-resolution velocity projection with high-resolution density advection to visualize smoke in real-time [S1]. It solves the performance bottleneck of simulating and rendering dense volumetric smoke by decoupling the fluid dynamics resolution from the visual density resolution [S1]. It projects velocity on a coarse grid, advects a finer density field, and ray marches the density in a volume pixel shader [S1].

## How it works
**Inputs and Outputs:**
- Input: Low-resolution velocity field, high-resolution density field.
- Output: Rendered smoke volume via ray marching in a pixel shader.

**Data Structures:**
- Velocity Field: Stored on a low-resolution 3D grid.
- Density Field: Stored on a high-resolution 3D grid.

**Steps:**
1. **Velocity Projection:** Perform a projection step on the low-resolution velocity field to ensure divergence-free conditions [S1].
2. **Density Advection:** Advect the high-resolution density field using the low-resolution velocity field [S1].
3. **Ray Marching:** In the volume pixel shader, ray march through the high-resolution density field to compute the final color and opacity [S1].

**Pitfalls:**
- **DiffUpSample Misconception:** The `DiffUpSample` technique reflects low-resolution differences to the high-resolution field before or after projection; it is not a physical diffusion solve [S1].

**Pseudocode:**
```python
def realtime_smoke_volume_step(low_res_velocity, high_res_density, dt):
    # 1. Project low-resolution velocity field to ensure divergence-free conditions [S1]
    # [G] Standard projection: compute divergence, solve pressure Poisson equation, subtract pressure gradient
    low_res_velocity = project_velocity(low_res_velocity)
    
    # 2. Advect high-resolution density field using the low-resolution velocity field [S1]
    # [G] Interpolate low-res velocity to high-res grid, then apply advection scheme
    high_res_density = advect_density(high_res_density, low_res_velocity, dt)
    
    # 3. Return updated density for ray marching in a volume pixel shader [S1]
    return high_res_density

def project_velocity(velocity):
    # [G] Standard projection algorithm assumed as not detailed in [S1]
    divergence = compute_divergence(velocity)
    pressure = solve_poisson_equation(divergence)
    velocity = velocity - compute_gradient(pressure)
    return velocity

def advect_density(density, velocity, dt):
    # [G] Advection scheme not detailed in [S1]; standard semi-Lagrangian or MacCormack used
    # Trace back along velocity, interpolate, and update density
    return density - dt * compute_divergence(density * velocity)
```

## Subtopics

### Smoke Simulation Step
A simulation step that updates the smoke density field by adding external sources, optionally diffusing, advecting, and applying a fixed per-cell decay [S2, unofficial]. Use this when physical accuracy (diffusion, decay) is required rather than just visual advection [S2, unofficial].
- **Definition:** Updates density field via source addition, optional diffusion, optional advection, and fixed decay [S2, unofficial].
- **Steps:**
  1. Add external sources: `AddSource(sd, _density)` [S2, unofficial].
  2. If compiled with `DIFFUSE`, swap `_densityTmp` and `_density`, then diffuse: `Diffuse(0, _densityTmp, _density, diffusion)` [S2, unofficial].
  3. If compiled with `ADVECT`, swap `_densityTmp` and `_density`, then advect using velocity components: `Advect(0, _densityTmp, _density, _velX, _velY, _velZ)` [S2, unofficial].
  4. Iterate over all cells, subtract 0.001 from density, and clamp to zero if negative: `FOR_ALL_CELL { _density[_I(k,j,i)] -= 0.001; if(_density[_I(k,j,i)] < 0) _density[_I(k,j,i)] = 0; } END_FOR` [S2, unofficial].

## Operating characteristics
- **Time Complexity:** Not given in the sources. The method combines low-resolution velocity projection with high-resolution density advection [S1].
- **Memory Complexity:** Requires storage for both low-resolution velocity and high-resolution density fields [S1].
- **Measured Performance:** Storyboard times are 4.025s, 13.417s, and 22.808s for Ex1604 frames [S1].
- **Strengths:** Combines low-resolution velocity projection with high-resolution density advection for real-time visualization [S1].
- **Limitations:** DiffUpSample reflects low-resolution differences to the high-resolution field before or after projection and is not a physical diffusion solve [S1].
- **When to Use:** Real-time visualization of smoke [S1].
- **When Not to Use:** Not given in the sources.
