# GPU-based Eulerian Fluid Solver

Also called: Dense Eulerian Fluid Solver, Eulerian Fluid Simulation, Ignis Solver

## Overview
A GPU-based Eulerian fluid solver that simulates and renders volumetrics at VR resolutions and refresh rates by using operator splitting to approximately solve the Navier-Stokes equations [S1]. It distinguishes itself by integrating a custom injection kernel for source terms and a geometric multigrid pressure solver optimized for half-precision 3D textures, enabling interactive frame rates on consumer hardware [S1].

## How it works
**Inputs and Outputs:**
*   **Inputs:** Voxel position, timestep ($\Delta t$), and source definitions for density, temperature, and forces [S1].
*   **Outputs:** Updated velocity, density, and temperature fields stored in 3D textures.

**Data Structures:**
*   State is tracked at each grid cell center [S1].
*   Fields: Velocity ($\mathbf{u}$), Density ($\rho$), Temperature ($T$).
*   Storage: 3D textures with 16-bit float formats (half-precision) [S1].
*   Voxel scale: 1.5 cm [S1].

**Steps:**

1.  **Injection:** A custom kernel receives voxel position and timestep [S1]. It adds density and temperature to the simulation and applies arbitrary forces, such as buoyancy [S1].
2.  **Advection:** Uses semi-Lagrangian advection with a MacCormack backtrace [S1]. Linear sampling is used for velocity during the backtrace [S1]. Cubic interpolation is used for the final resample of all advected properties [S1]. Vorticity confinement force is optionally applied [S1].
3.  **Projection:** Pressure projection is solved using geometric multigrid with a single V-cycle [S1]. The V-cycle uses 1 pre-smooth and 2 post-smooth passes [S1]. Full-weight and trilinear transfer operators are used [S1]. Jacobi iteration is used for smoothing [S1]. On the 3rd, coarsest grid, red-black Gauss-Seidel with successive over-relaxation (SOR) is used [S1].

**Pseudocode:**

```python
def solve_step(grid, dt):
    # 1. Injection
    for voxel in grid.active_voxels:
        grid.density[voxel] += source_density(voxel.pos, dt)
        grid.temperature[voxel] += source_temperature(voxel.pos, dt)
        grid.velocity[voxel] += force_buoyancy(grid.temperature[voxel], dt)

    # 2. Advection
    old_velocity = grid.velocity.copy()
    for voxel in grid:
        trace_pos = voxel.pos - old_velocity[voxel] * dt
        grid.velocity[voxel] = trilinear_interpolate(grid.velocity, trace_pos)

    for field in [grid.density, grid.temperature]:
        old_field = field.copy()
        for voxel in grid:
            trace_pos = voxel.pos - grid.velocity[voxel] * dt
            field[voxel] = tricubic_interpolate(old_field, trace_pos)

    if apply_vorticity_confinement:
        # Standard vorticity confinement force calculation [G]
        pass

    # 3. Projection
    jacobi_smooth(grid, iterations=1)
    coarse_grids = restrict_full_weight(grid, levels=3)
    red_black_gauss_seidel_sor(coarse_grids[2])
    for i in range(2, 0, -1):
        prolongate_trilinear(coarse_grids[i], coarse_grids[i-1])
        jacobi_smooth(coarse_grids[i-1], iterations=2)
    apply_pressure_correction(grid, coarse_grids[0])

def jacobi_smooth(grid, iterations):
    for _ in range(iterations):
        for voxel in grid:
            grid.pressure[voxel] = jacobi_update(grid.pressure, voxel)

def red_black_gauss_seidel_sor(grid):
    for color in ['red', 'black']:
        for voxel in grid.get_voxels_by_color(color):
            grid.pressure[voxel] = gauss_seidel_sor_update(grid.pressure, voxel)

def restrict_full_weight(grid, levels):
    # Standard full-weight restriction operator [G]
    return [grid] + [restrict_level(grid, i) for i in range(1, levels)]

def prolongate_trilinear(coarse, fine):
    # Standard trilinear prolongation operator [G]
    fine.pressure += trilinear_interpolate(coarse.pressure, fine.voxel_centers)

def apply_pressure_correction(grid, coarse_pressure):
    grid.velocity -= gradient_trilinear(coarse_pressure)
```

## Subtopics

### [FluidX12 Simulation Pipeline](16601-fluidx12-simulation-pipeline.md)
FluidX12 is a real-time volume rendering pipeline that simulates smoke using an Eulerian grid method to solve the Navier-Stokes equations. It distinguishes itself by integrating viewport-resolution independent anti-aliased ray marching on interior faces in cube-map space, allowing for high-quality volumetric rendering at interactive frame rates. Unlike standard fluid solvers that output static data, this pipeline couples the simulation state directly with a specialized ray-marching renderer that supports both 2D and 3D domains.

## Operating characteristics
*   **Performance:** On an NVIDIA RTX 3080, the solver achieves frame times well within the 11.11ms budget for 90 Hz VR [S1].
    *   Smoke Rings (232x232x160): 9.63ms total [S1].
    *   Dust Devil (160x256x160): 9.65ms total [S1].
    *   Wall of Fire (200x200x200): 9.73ms total [S1].
*   **Memory:** Uses half-precision (16-bit float) 3D textures for velocity, density, and temperature, effectively doubling performance on bandwidth-constrained portions [S1].
*   **Limitations:** Primarily limited by low simulation resolution necessary to run in VR on current hardware [S1].

## Background
The method is presented in "Ignis: Eulerian Fluid Simulation and Rendering at VR Frame Rates" by Charlie Shenton (SIGGRAPH Asia 2023 Posters) [S1]. It builds on operator splitting [Stam 1999] and MacCormack backtrace advection [Selle et al. 2008] as cited in the source [S1].
