# FluidX12 Simulation Pipeline

Also called: Eulerian Grid Smoke Simulation, FluidEZ

## Overview
FluidX12 is a real-time volume rendering pipeline that simulates smoke using an Eulerian grid method to solve the Navier-Stokes equations [S1, unofficial]. It distinguishes itself by integrating viewport-resolution independent anti-aliased ray marching on interior faces in cube-map space, allowing for high-quality volumetric rendering at interactive frame rates [S1, unofficial].

## How it works

### Inputs and Outputs
**Inputs:**
*   Grid dimensions: $N_x, N_y, N_z$ (default 128, 128, 128) [S1, unofficial].
*   Camera parameters: Eye position, View matrix, Projection matrix [S1, unofficial].
*   Lighting parameters: Light position, Light color, Ambient light [S1, unofficial].
*   Simulation parameters: Time step, Base seed for noise [S1, unofficial].
*   Rendering parameters: Maximum ray samples ($N_{ray}$, default 192), Maximum light samples ($N_{light}$, default 64) [S1, unofficial].

**Outputs:**
*   Rendered image: 8-bit RGBA texture [S1, unofficial].
*   Updated fluid state: Velocity and density/color fields for the next frame [S1, unofficial].

### Data Structures

**Simulation Buffers (Ping-Pong):**
*   `m_velocities[2]`: `Texture3D`, format `R16G16B16A16_FLOAT`, dimensions $(N_x, N_y, N_z)$, flags `ALLOW_UNORDERED_ACCESS` [S1, unofficial].
*   `m_colors[2]`: `Texture3D`, format `R16G16B16A16_FLOAT`, dimensions $(N_x, N_y, N_z)$, flags `ALLOW_UNORDERED_ACCESS` [S1, unofficial].
*   `m_frameParity`: Integer (0 or 1) tracking the current read/write buffer index [S1, unofficial].

**Auxiliary Textures:**
*   `m_incompress`: `Texture3D`, format `R32_FLOAT`, dimensions $(N_x, N_y, N_z)$ [S1, unofficial].
*   `m_lightMap`: `Texture3D`, format `R11G11B10_FLOAT`, dimensions $(N_x, N_y, N_z)$, flags `ALLOW_SIMULTANEOUS_ACCESS` [S1, unofficial].
*   `m_cubeMap`: `TextureCube`, format `R8G8B8A8_UNORM`, 6 faces, 5 mipmap levels [S1, unofficial].

**Constant Buffers:**
*   `CBSimulation`: `TimeStep` (`float`), `BaseSeed` (`uint32_t`) [S1, unofficial].
*   `CBPerFrame`: `EyePos` (`XMFLOAT4`), `LightPos` (`XMFLOAT4`), `LightColor` (`XMFLOAT4`), `Ambient` (`XMFLOAT4`) [S1, unofficial].
*   `CBPerObject`: `WorldViewProjI` (`XMFLOAT4X4`), `WorldViewProj` (`XMFLOAT4X4`), `WorldI` (`XMFLOAT3X4`), `World` (`XMFLOAT3X4`) [S1, unofficial].
*   `CBSampleRes`: `NumSamples` (`uint32_t`), `HasLightProbes` (`uint32_t`), `NumLightSamples` (`uint32_t`) [S1, unofficial].

### Algorithm Steps

1.  **Initialization**:
    *   Create the Direct3D 12 device, command queues, and swap chain [S1, unofficial].
    *   Initialize `m_velocities` and `m_colors` ping-pong buffers with zero or initial smoke density [S1, unofficial].
    *   Initialize auxiliary textures (`m_incompress`, `m_lightMap`, `m_cubeMap`) [S1, unofficial].
    *   Set default parameters: $N_{ray}=192$, $N_{light}=64$, world scale $10.0$ [S1, unofficial].

2.  **Simulation Update (Per Frame)**:
    *   **Advection Pass**:
        *   Dispatch compute shader `CS_ADVECT`.
        *   Write to: `m_velocities[1]`, `m_colors[m_frameParity]` [S1, unofficial].
        *   Read from: `m_velocities[0]`, `m_colors[!m_frameParity]` [S1, unofficial].
        *   Thread group dimensions: $(\lceil N_x/8 \rceil, \lceil N_y/8 \rceil, N_z)$ [S1, unofficial].
    *   **Projection Pass**:
        *   Determine dimensionality: If $N_z > 1$, use 3D projection; else use 2D projection [S1, unofficial].
        *   Dispatch compute shader `CS_PROJECT_3D` or `CS_PROJECT_2D` [S1, unofficial].
        *   Write to: `m_velocities[0]` (or appropriate buffer based on parity swap) [S1, unofficial].
    *   **Buffer Swap**:
        *   Toggle `m_frameParity` to swap read/write buffers for the next frame [S1, unofficial].

3.  **Rendering (Per Frame)**:
    *   Update constant buffers with current camera, light, and simulation parameters [S1, unofficial].
    *   Dispatch ray marching compute shader or pixel shader [S1, unofficial].
    *   The renderer samples the fluid density from the grid textures along view rays [S1, unofficial].
    *   Apply anti-aliasing via viewport-resolution independent techniques on interior faces [S1, unofficial].
    *   Integrate lighting using `m_lightMap` and `m_cubeMap` if enabled [S1, unofficial].

    def __init__(self):
        self.NumSamples = 0
        self.HasLightProbes = 0
        self.NumLightSamples = 0

def simulate_and_render(grid_size, max_ray_samples, max_light_samples, world_scale, dt, seed, eye_pos, light_pos, light_color, ambient, wvp, wvp_inv, world, world_inv, has_light_probes):
    # Initialization
    velocities = [Texture3D(grid_size, "R16G16B16A16_FLOAT", ["ALLOW_UNORDERED_ACCESS"]) for _ in range(2)]
    colors = [Texture3D(grid_size, "R16G16B16A16_FLOAT", ["ALLOW_UNORDERED_ACCESS"]) for _ in range(2)]
    incompress = Texture3D(grid_size, "R32_FLOAT")
    light_map = Texture3D(grid_size, "R11G11B10_FLOAT", ["ALLOW_SIMULTANEOUS_ACCESS"])
    cube_map = TextureCube("R8G8B8A8_UNORM", 6, 5)
    frame_parity = 0

    # 1. Simulation Step
    # Advection: Read from old buffers, write to new buffers
    # UAVs: velocities[1], colors[frame_parity]
    # SRVs: velocities[0], colors[!frame_parity]
    dispatch_cs("CS_ADVECT",
                num_threads_x=(grid_size[0] + 7) // 8,
                num_threads_y=(grid_size[1] + 7) // 8,
                num_threads_z=grid_size[2])

    # Projection: Enforce incompressibility
    if grid_size[2] > 1:
        dispatch_cs("CS_PROJECT_3D",
                    num_threads_x=(grid_size[0] + 7) // 8,
                    num_threads_y=(grid_size[1] + 7) // 8,
                    num_threads_z=grid_size[2])
    else:
        dispatch_cs("CS_PROJECT_2D",
                    num_threads_x=(grid_size[0] + 7) // 8,
                    num_threads_y=(grid_size[1] + 7) // 8)

    # Swap parity for next frame
    frame_parity = 1 - frame_parity

    # 2. Rendering Step
    # Update Constant Buffers
    cb_simulation = CBSimulation()
    cb_per_frame = CBPerFrame()
    cb_per_object = CBPerObject()
    cb_sample_res = CBSampleRes()

    cb_simulation.TimeStep = dt
    cb_simulation.BaseSeed = seed
    cb_per_frame.EyePos = eye_pos
    cb_per_frame.LightPos = light_pos
    cb_per_frame.LightColor = light_color
    cb_per_frame.Ambient = ambient
    cb_per_object.WorldViewProj = wvp
    cb_per_object.WorldViewProjI = wvp_inv
    cb_per_object.World = world
    cb_per_object.WorldI = world_inv
    cb_sample_res.NumSamples = max_ray_samples
    cb_sample_res.HasLightProbes = has_light_probes
    cb_sample_res.NumLightSamples = max_light_samples

    # Dispatch Ray Marching
    # The ray marcher samples velocities[0] and colors[0] (since parity was swapped)
    # to render the volume.
    dispatch_cs("CS_RAY_MARCH",
                num_threads_x=(1920 + 7) // 8,
                num_threads_y=(1080 + 7) // 8,
                num_threads_z=1)

### Edge Cases and Pitfalls
*   **Grid Dimensions**: The projection pass switches between 2D and 3D logic based on $N_z > 1$ [S1, unofficial].
*   **Precision**: Velocity and color are stored in `R16G16B16A16_FLOAT` [S1, unofficial].
*   **Ray Sampling**: The default `maxRaySamples` (192) and `maxLightSamples` (64) are specified [S1, unofficial].
*   **World Transform**: The `m_volumeWorld` scale is initialized to $10.0$ in each dimension [S1, unofficial].
*   **Not given in the sources**: Exact performance scaling curves, memory footprint calculations, and numerical diffusion characteristics.

## Operating characteristics

*   **Time Complexity**: Not given in the sources.
*   **Memory Complexity**: Not given in the sources.
*   **Performance**: Designed for real-time performance at viewport resolution on modern GPUs using DirectX 12 [S1, unofficial].
*   **Strengths**: Real-time capability, integration of advanced ray marching anti-aliasing, support for both 2D and 3D simulations [S1, unofficial].
*   **Limitations**: The specific implementation is tied to DirectX 12 and the XUSG framework [S1, unofficial].

## Background

FluidX12 is an implementation of the techniques presented in the SIGGRAPH Asia 2021 Technical Communications paper "Viewport-Resolution Independent Anti-Aliased Ray Marching on Interior Faces in Cube-Map Space" [S1, unofficial]. It was developed by StarsX as a demo application to showcase real-time volume rendering of smoke simulations using Eulerian grid methods [S1, unofficial]. The project relies on the XUSG (Xbox Unified Shader Graphics) framework for DirectX 12 abstraction [S1, unofficial].
