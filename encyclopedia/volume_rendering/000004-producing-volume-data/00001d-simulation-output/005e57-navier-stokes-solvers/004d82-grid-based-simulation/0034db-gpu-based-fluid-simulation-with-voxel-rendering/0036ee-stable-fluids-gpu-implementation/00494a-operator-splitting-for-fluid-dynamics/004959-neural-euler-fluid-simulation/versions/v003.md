# Neural Euler Fluid Simulation
Also called: Neural Pressure Projection Fluid Simulation
## Overview
Neural Euler Fluid Simulation replaces the traditional linear solver for the pressure projection step in incompressible fluid dynamics with a convolutional neural network (ConvNet) [S1, unofficial]. While standard methods solve a Poisson equation to enforce divergence-free velocity, this method regresses the velocity correction directly from the intermediate velocity and a volume field representation [S1, unofficial]. It is distinguished by its ability to handle free-surface flows (fluid and air) explicitly through the volume field input and by integrating differentiable rendering for inverse simulation [S1, unofficial].
## How it works
### Inputs and Outputs
**Inputs:**
*   Velocity field at previous time step: $u_{t-1}$ (3D vector field) [S1, unofficial].
*   Volume field at previous time step: $V_{t-1}$ (scalar field, range [0, 1]) [S1, unofficial].
*   Time step: $\Delta t$ [S1, unofficial].
*   Gravitational acceleration: $g$ (3D vector) [S1, unofficial].
*   Container boundary geometry (used to compute distance features) [S1, unofficial].

**Outputs:**
*   Velocity field at current time step: $u_t$ (3D vector field) [S1, unofficial].
*   Volume field at current time step: $V_t$ (scalar field) [S1, unofficial].

### Data Structures
*   **Grid:** The simulation domain is discretized into a 3D grid [S1, unofficial].
*   **Velocity Field ($u$):** Stores 3-component vectors per grid cell [S1, unofficial].
*   **Volume Field ($V$):** Stores a scalar per grid cell [S1, unofficial].
*   **Feature Vector:** Each grid cell includes an additional input feature representing the distance to the container boundary [S1, unofficial].

### Steps
1.  **Advection of Volume:** Advect the volume field $V_{t-1}$ using the velocity field $u_{t-1}$ to obtain $V_t$ [S1, unofficial].
    $$V_t = \text{advect}(u_{t-1}, \Delta t, V_{t-1})$$
2.  **Advection of Velocity:** Advect the velocity field $u_{t-1}$ using itself to obtain the intermediate velocity $u^*$ [S1, unofficial]. The source specifies using the Maccormack method to reduce numerical viscosity [S1, unofficial].
    $$u^* = \text{advect}(u_{t-1}, \Delta t, u_{t-1})$$
3.  **External Force Application:** Apply gravity to $u^*$ to obtain $u^{**}$ [S1, unofficial].
    $$u^{**} = u^* + g \Delta t$$
4.  **Neural Pressure Projection:** Input $u^{**}$, $V_t$, and boundary distance features into the ConvNet $F_\Theta$ to regress the pressure-induced velocity difference $\Delta u$ [S1, unofficial].
    $$\Delta u = F_\Theta(u^{**}, V_t, \text{distances})$$
5.  **Velocity Update:** Add $\Delta u$ to $u^{**}$ to obtain the final divergence-free velocity $u_t$ [S1, unofficial].
    $$u_t = u^{**} + \Delta u$$

### Pseudocode
```python
def neural_euler_step(u_prev, V_prev, dt, gravity, container_boundary, conv_net):
    """Performs one time step of Neural Euler Fluid Simulation."""
    # Step 1: Advect volume field
    V_curr = advect(V_prev, u_prev, dt)
    # Step 2: Advect velocity field
    u_star = advect(u_prev, u_prev, dt)
    # Step 3: Apply external force (gravity)
    u_double_star = u_star + gravity * dt
    # Step 4: Compute boundary distance features
    distances = compute_boundary_distances(container_boundary)
    # Step 5: Neural Pressure Projection
    delta_u = conv_net(u_double_star, V_curr, distances)
    # Step 6: Update velocity
    u_curr = u_double_star + delta_u
    return u_curr, V_curr

def advect(field, velocity_field, dt):
    """Semi-Lagrangian advection with backtracing and interpolation [G]."""
    result = zeros_like(field)
    for x in range(field.shape[0]):
        for y in range(field.shape[1]):
            for z in range(field.shape[2]):
                vx, vy, vz = velocity_field[x, y, z]
                x_back = x - vx * dt
                y_back = y - vy * dt
                z_back = z - vz * dt
                result[x, y, z] = trilinear_interpolate(field, x_back, y_back, z_back)
    return result

def compute_boundary_distances(container_boundary):
    """Computes distance from each grid cell to the container boundary [G]."""
    distances = zeros_like(container_boundary.shape)
    for x in range(distances.shape[0]):
        for y in range(distances.shape[1]):
            for z in range(distances.shape[2]):
                distances[x, y, z] = distance_to_surface((x, y, z), container_boundary)
    return distances
```

### Edge Cases and Pitfalls
*   **Volume Loss:** Incompressible simulation may suffer from volume loss [S1, unofficial].
*   **Free Surface Handling:** The explicit volume field $V_t$ is crucial for identifying the fluid-air interface, which aids both the pressure projection and the subsequent neural rendering [S1, unofficial].
## Operating characteristics
*   **Time Complexity:** Not given in the sources [S1, unofficial].
*   **Memory Complexity:** Not given in the sources [S1, unofficial].
*   **Strengths:** Handles free-surface flows naturally via the volume field; differentiable, allowing for inverse simulation (learning dynamics from visual data) [S1, unofficial].
*   **Limitations:** Requires training data; precision depends on the ConvNet's capacity and training [S1, unofficial].
*   **When to use:** When differentiable simulation is required for inverse rendering or parameter learning [S1, unofficial].
## Background
The method was introduced in the paper "Inferring Fluid Dynamics via Inverse Rendering" [S1, unofficial]. It builds on the operator splitting framework for fluid dynamics, specifically replacing the pressure projection step [S1, unofficial]. The approach leverages the differentiability of neural networks to infer fluid dynamics from visual observations, bridging the gap between physical simulation and neural rendering [S1, unofficial].
