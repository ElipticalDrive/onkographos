# Heat Diffusion Simulator via Finite Volume Method

Also called: Inverse-crime mitigation, Synthetic Dataset Generation with PhiFlow

## Overview
This method generates ground-truth volumetric data for thermal tomography by simulating heat diffusion using an independent finite-volume engine (PhiFlow) [S1, unofficial]. It solves the transient heat equation on a structured grid to create synthetic datasets that avoid "inverse crimes," where reconstruction algorithms are evaluated against data generated by their own discretization [S1, unofficial]. By decoupling the forward simulation (explicit finite volume) from the inverse solver (implicit neural field), it ensures the evaluation metric reflects true physical fidelity rather than discretization artifacts [S1, unofficial].

## How it works
The simulator evolves the temperature field $T(\mathbf{x}, t)$ over a 3D domain using an explicit finite-volume scheme with adaptive substepping to maintain stability at high resolutions [S1, unofficial].

### Inputs and Outputs
*   **Inputs**:
    *   Domain geometry $\Omega$.
    *   Grid resolution $(N_x, N_y, N_z)$.
    *   Material diffusivity field $\alpha(\mathbf{x})$, sampled from uniform distributions for bulk and defect regions.
    *   Time step $\Delta t$ and total frames $N_t$.
    *   Boundary conditions (periodic lateral, adiabatic vertical).
*   **Outputs**:
    *   A sequence of temperature fields $T_k(\mathbf{x})$ for $k=0 \dots N_t$.

### Data Structures
The simulation uses a structured 3D grid.
*   **Grid**: Uniform Cartesian grid with dimensions $N_x \times N_y \times N_z$.
*   **Spacing**: Lateral spacing $\Delta x = \Delta y$, vertical spacing $\Delta z$.
*   **State**: Temperature array $T \in \mathbb{R}^{N_x \times N_y \times N_z}$.
*   **Material**: Diffusivity array $\alpha \in \mathbb{R}^{N_x \times N_y \times N_z}$.

### Parameters
*   **Domain**: Unitless slab $\Omega = [0, 10]^2 \times [0, 1]$ [S1, unofficial].
*   **Resolution**: $64 \times 64 \times 16$ [S1, unofficial].
*   **Spacing**: $\Delta x = \Delta y = 0.156$, $\Delta z = 0.0625$ [S1, unofficial].
*   **Time Step**: $\Delta t = 0.05$ [S1, unofficial].
*   **Frames**: $N_t = 100$ [S1, unofficial].
*   **Diffusivity**:
    *   Bulk: $\alpha_{base} \sim U(0.1, 0.2)$ [S1, unofficial].
    *   Defect: $\alpha_{defect} \sim U(0.005, 0.015)$ [S1, unofficial].
    *   Ratio: Defect-to-bulk $\approx 1:20$ [S1, unofficial].
*   **Defects**: 1–4 subsurface ellipsoidal, cylindrical, or box-shaped defects at varying depths [S1, unofficial].
*   **Configurations**: Homogeneous (constant $\alpha_{base}$) or Layered (3–4 bulk strata along $z$) [S1, unofficial].

### Formulas
The stability limit for the explicit scheme is determined by the maximum diffusivity $\alpha_{max}$ in the batch and spatial dimension $D \in \{2, 3\}$ [S1, unofficial]:

$$
\Delta t_{stable} \approx \frac{\Delta x^2}{2 D \alpha_{max}}
$$

To satisfy this constraint while recording at $\Delta t$, an adaptive substepping routine calculates the number of substeps $N_{sub}$ per frame [S1, unofficial]:

$$
N_{sub} = \max \left( 10, \left\lceil \frac{\Delta t}{\Delta t_{stable}} \times 2.0 \right\rceil \right)
$$

### Steps
1.  **Initialize**: Create grid with spacing $\Delta x, \Delta z$. Initialize temperature $T$ and diffusivity $\alpha$ based on sampled material properties and defect geometry [S1, unofficial].
2.  **Calculate Stability**: Compute $\alpha_{max}$ for the current batch. Calculate $\Delta t_{stable}$ using the formula above [S1, unofficial].
3.  **Determine Substeps**: Calculate $N_{sub}$ using the adaptive formula [S1, unofficial].
4.  **Loop Frames**: For each frame $k$ from $0$ to $N_t-1$:
    a.  **Substep Loop**: Repeat $N_{sub}$ times:
        i.  Compute fluxes across cell faces using the explicit finite-volume discretization of the heat equation $\frac{\partial T}{\partial t} = \nabla \cdot (\alpha \nabla T)$ [S1, unofficial].
        ii. Update $T$ using the computed fluxes and a time step $\Delta t_{sub} = \Delta t / N_{sub}$ [G].
        iii. Apply boundary conditions: Periodic for $x, y$; Adiabatic Neumann ($\frac{\partial T}{\partial z} = 0$) for $z$ faces [S1, unofficial].
    b.  **Record**: Store $T$ as the output for frame $k$ [S1, unofficial].

### Pseudocode
```python
def simulate_heat_diffusion(domain_size, resolution, dt, num_frames, alpha_field, defect_field):
    """
    Simulates heat diffusion using explicit finite volume with adaptive substepping.
    
    Args:
        domain_size: Tuple (Lx, Ly, Lz)
        resolution: Tuple (Nx, Ny, Nz)
        dt: Time step per recorded frame
        num_frames: Number of frames to record
        alpha_field: 3D array of diffusivity values
        defect_field: 3D array marking defect locations (optional, used for alpha sampling)
        
    Returns:
        List of 3D temperature arrays
    """
    Nx, Ny, Nz = resolution
    Lx, Ly, Lz = domain_size
    
    # Calculate grid spacing
    dx = Lx / Nx
    dy = Ly / Ny
    dz = Lz / Nz
    
    # Initialize temperature field (e.g., uniform initial temperature)
    T = np.ones((Nx, Ny, Nz))
    
    # Determine maximum diffusivity for stability check
    alpha_max = np.max(alpha_field)
    
    # Spatial dimension D (3 for 3D simulation)
    D = 3
    
    # Calculate stable time step
    dt_stable = (dx ** 2) / (2 * D * alpha_max)
    
    # Calculate number of substeps
    # Using ceiling function for integer steps
    import math
    N_sub = max(10, math.ceil((dt / dt_stable) * 2.0))
    
    dt_sub = dt / N_sub
    
    frames = []
    
    for frame_idx in range(num_frames):
        # Perform N_sub substeps
        for _ in range(N_sub):
            # Compute fluxes
            # Flux in x-direction
            flux_x = alpha_field * (T[1:, :, :] - T[:-1, :, :]) / dx
            # Flux in y-direction
            flux_y = alpha_field * (T[:, 1:, :] - T[:, :-1, :]) / dy
            # Flux in z-direction
            flux_z = alpha_field * (T[:, :, 1:] - T[:, :, :-1]) / dz
            
            # Update temperature
            # Divergence of fluxes
            div_flux_x = (flux_x[1:, :, :] - flux_x[:-1, :, :]) / dx
            div_flux_y = (flux_y[:, 1:, :] - flux_y[:, :-1, :]) / dy
            div_flux_z = (flux_z[:, :, 1:] - flux_z[:, :, :-1]) / dz
            
            T = T - dt_sub * (div_flux_x + div_flux_y + div_flux_z)
            
            # Apply Boundary Conditions
            # Periodic in x
            T[0, :, :] = T[-1, :, :]
            T[-1, :, :] = T[0, :, :]
            # Periodic in y
            T[:, 0, :] = T[:, -1, :]
            T[:, -1, :] = T[:, 0, :]
            # Adiabatic Neumann in z (zero gradient)
            T[:, :, 0] = T[:, :, 1]
            T[:, :, -1] = T[:, :, -2]
            
        frames.append(T.copy())
        
    return frames
```

### Edge Cases and Pitfalls
*   **Explicit Stability**: At fine grid resolutions, $\Delta t_{stable}$ becomes very small. Failure to use adaptive substepping or sufficient substeps leads to numerical instability and divergence [S1, unofficial].
*   **Inverse Crime**: Using the same discretization for forward simulation and inverse reconstruction leads to overfitting to numerical artifacts. Using an independent engine (PhiFlow) with explicit scheme vs. implicit neural solver prevents this [S1, unofficial].
*   **Defect Geometry**: Defects must be properly embedded in the grid. Discretization errors near defect boundaries can affect the accuracy of the generated ground truth [S1, unofficial].

## Operating characteristics
*   **Time Complexity**: $O(N_x N_y N_z \cdot N_t \cdot N_{sub})$ [G]. $N_{sub}$ scales with $\Delta t / \Delta x^2$, making fine-grid simulations computationally expensive [S1, unofficial].
*   **Memory Complexity**: $O(N_x N_y N_z)$ for storing the temperature and diffusivity fields [G].
*   **Performance**: The explicit scheme requires many substeps per frame. For a $64 \times 64 \times 16$ grid, dozens of substeps are executed per recorded frame [S1, unofficial].
*   **Strengths**: Avoids inverse crimes by using an independent forward solver; simple to implement; generates physically consistent data [S1, unofficial].
*   **Limitations**: Explicit stability constraint limits efficiency at high resolutions; requires careful tuning of substeps [S1, unofficial].
*   **When to Use**: Generating synthetic datasets for training neural fields where avoiding discretization bias is critical [S1, unofficial].
*   **When Not to Use**: Real-time simulation or applications where computational efficiency is paramount over ground-truth independence [G].

## Background
The method originates from the work on Neural Field Thermal Tomography (NeFTY), where synthetic data generation is crucial for evaluating reconstruction algorithms [S1, unofficial]. The use of PhiFlow, an independent finite-volume engine, was introduced to mitigate inverse crimes, a common pitfall in differentiable physics simulations [S1, unofficial]. The approach builds on the principles of grid-based simulation, mapping physical sources into discrete volumetric representations [Parent].
