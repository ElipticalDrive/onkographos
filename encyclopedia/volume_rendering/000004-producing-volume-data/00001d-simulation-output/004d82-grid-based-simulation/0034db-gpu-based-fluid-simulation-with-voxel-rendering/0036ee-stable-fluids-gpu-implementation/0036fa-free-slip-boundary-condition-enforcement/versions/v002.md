# Free-Slip Boundary Condition Enforcement

Also called: Dynamic Obstacle Handling with Free-Slip Boundary

## Overview
This method enforces a free-slip boundary condition for fluid simulations involving dynamic obstacles represented as voxelized solids [S1, unofficial]. It ensures that fluid velocity normal to the obstacle surface matches the solid's normal velocity, allowing tangential slip, while preventing mass leakage into solid interiors [S1, unofficial]. It differs from no-slip conditions by retaining tangential fluid velocity and from static boundary handling by explicitly updating obstacle velocity fields and modifying the pressure solver to ignore solid cell contributions [S1, unofficial].

## How it works
**Inputs:**
- Fluid velocity field $\mathbf{u}$ (3D texture) [S1, unofficial].
- Pressure field $p$ (3D texture) [S1, unofficial].
- Divergence field $d$ (3D texture) [S1, unofficial].
- Obstacle mask texture `obstacles` (3D texture, scalar) [S1, unofficial].
- Obstacle velocity texture `obstaclevelocity` (3D texture, vector) [S1, unofficial].
- Simulation parameters: time step $\Delta t$, fluid density $\rho$, cell spacing $\Delta x$ [S1, unofficial].

**Outputs:**
- Updated fluid velocity field $\mathbf{u}'$ [S1, unofficial].
- Updated pressure field $p'$ [S1, unofficial].

**Data Structures:**
- `obstacles`: 3D texture where a texel value $> 0.9$ indicates a solid cell [S1, unofficial].
- `obstaclevelocity`: 3D texture storing the velocity vector of the solid at each cell location [S1, unofficial].

**Algorithm Steps:**

1.  **Obstacle Masking:** Define a helper function `IsSolidCell(coords)` which returns true if `obstacles.Sample(coords).r > 0.9` [S1, unofficial].
2.  **Pressure Solve (Jacobi Iteration):** When solving the discrete pressure-Poisson equation for a fluid cell $(i,j,k)$, neighbors that are solid must not contribute to the pressure gradient [S1, unofficial]. The discrete system is:
    $$ \frac{\Delta t}{\rho \Delta x^2} \left( \left| F_{i,j,k} \right| p_{i,j,k} - \sum_{n \in F_{i,j,k}} p_n \right) = -d_{i,j,k} $$
    where $F_{i,j,k}$ is the set of adjacent fluid cell indices [S1, unofficial]. In practice, during Jacobi iteration, if a neighbor cell is solid, its pressure value $p_n$ is replaced by the center cell's pressure $p_C$ to nullify the solid's contribution to the Laplacian [S1, unofficial].
3.  **Divergence Computation:** When computing the divergence of the velocity field, if a neighboring cell is solid, sample the velocity from `obstaclevelocity` instead of the fluid velocity field [S1, unofficial].
4.  **Post-Projection Enforcement:** After the pressure projection step, explicitly enforce the free-slip condition [S1, unofficial]. For fluid cells adjacent to solid boundaries, compute the obstacle's velocity component normal to the boundary and replace the fluid velocity's normal component at the center cell [S1, unofficial]. The condition is:
    $$ \mathbf{u} \cdot \mathbf{n} = \mathbf{u}_{\text{solid}} \cdot \mathbf{n} $$
    where $\mathbf{n}$ is the surface normal [S1, unofficial]. Since solid-fluid boundaries are aligned with voxel faces, $\mathbf{n}$ is axis-aligned, making the projection a simple component selection [S1, unofficial]. The tangential components of the fluid velocity are retained [S1, unofficial]. If two opposing faces of a fluid cell are solid boundaries, selecting one face's normal velocity is sufficient for acceptable results [S1, unofficial].
5.  **Advection Constraint:** During advection of any quantity (e.g., density, temperature), ensure no quantity is advected into the interior of an obstacle [S1, unofficial]. If the trace point of an advection step lands inside a solid cell, the advected quantity is set to zero [S1, unofficial].

**Pseudocode:**

```python
# Standard grid offsets
LEFT  = (-1, 0, 0)
RIGHT = ( 1, 0, 0)
BOTTOM= ( 0,-1, 0)
TOP   = ( 0, 1, 0)
DOWN  = ( 0, 0,-1)
UP    = ( 0, 0, 1)

def is_solid_cell(coords, obstacle_texture):
    """Returns True if the cell at coords is solid."""
    return obstacle_texture.sample(coords).r > 0.9

def get_obstacle_velocity(coords, obstacle_velocity_texture):
    """Returns the velocity of the solid at coords."""
    return obstacle_velocity_texture.sample(coords)

def solve_pressure_jacobi_obstacle(pressure_texture, divergence_texture, obstacle_texture, nx, ny, nz, num_iterations):
    """
    Solves the pressure Poisson equation with free-slip boundary conditions.
    Solid cells are ignored in the stencil by replacing their pressure with the center cell's pressure.
    """
    p = pressure_texture.copy()
    d = divergence_texture
    
    for _ in range(num_iterations):
        new_p = [[0.0] * nz for _ in range(ny)]
        for i in range(1, nx - 1):
            for j in range(1, ny - 1):
                for k in range(1, nz - 1):
                    if is_solid_cell((i, j, k), obstacle_texture):
                        continue
                    
                    p_center = p[i][j][k]
                    d_val = d[i][j][k]
                    
                    # Sample neighbors
                    p_left  = p[i-1][j][k]
                    p_right = p[i+1][j][k]
                    p_bottom = p[i][j-1][k]
                    p_top    = p[i][j+1][k]
                    p_down   = p[i][j][k-1]
                    p_up     = p[i][j][k+1]
                    
                    # Nullify solid neighbors
                    if is_solid_cell((i-1, j, k), obstacle_texture): p_left = p_center
                    if is_solid_cell((i+1, j, k), obstacle_texture): p_right = p_center
                    if is_solid_cell((i, j-1, k), obstacle_texture): p_bottom = p_center
                    if is_solid_cell((i, j+1, k), obstacle_texture): p_top = p_center
                    if is_solid_cell((i, j, k-1), obstacle_texture): p_down = p_center
                    if is_solid_cell((i, j, k+1), obstacle_texture): p_up = p_center
                    
                    # Jacobi update
                    new_p[i][j][k] = (p_left + p_right + p_bottom + p_top + p_down + p_up - d_val) / 6.0
        
        p = new_p
    
    return p

def compute_divergence_obstacle(velocity_texture, obstacle_texture, obstacle_velocity_texture, dx):
    """
    Computes divergence of velocity, using obstacle velocity for solid neighbors.
    Uses standard central difference discretization [G].
    """
    divergence = [[0.0] * nz for _ in range(ny)]
    for i in range(1, nx - 1):
        for j in range(1, ny - 1):
            for k in range(1, nz - 1):
                if is_solid_cell((i, j, k), obstacle_texture):
                    divergence[i][j][k] = 0.0
                    continue
                    
                # Get velocities from neighbors
                v_left  = velocity_texture.sample((i-1, j, k))
                v_right = velocity_texture.sample((i+1, j, k))
                v_bottom = velocity_texture.sample((i, j-1, k))
                v_top    = velocity_texture.sample((i, j+1, k))
                v_down   = velocity_texture.sample((i, j, k-1))
                v_up     = velocity_texture.sample((i, j, k+1))
                
                # Replace solid neighbor velocities with obstacle velocities
                if is_solid_cell((i-1, j, k), obstacle_texture): v_left = get_obstacle_velocity((i-1, j, k), obstacle_velocity_texture)
                if is_solid_cell((i+1, j, k), obstacle_texture): v_right = get_obstacle_velocity((i+1, j, k), obstacle_velocity_texture)
                if is_solid_cell((i, j-1, k), obstacle_texture): v_bottom = get_obstacle_velocity((i, j-1, k), obstacle_velocity_texture)
                if is_solid_cell((i, j+1, k), obstacle_texture): v_top = get_obstacle_velocity((i, j+1, k), obstacle_velocity_texture)
                if is_solid_cell((i, j, k-1), obstacle_texture): v_down = get_obstacle_velocity((i, j, k-1), obstacle_velocity_texture)
                if is_solid_cell((i, j, k+1), obstacle_texture): v_up = get_obstacle_velocity((i, j, k+1), obstacle_velocity_texture)
                
                # Standard central difference divergence [G]
                div = (v_right.x - v_left.x + v_top.y - v_bottom.y + v_up.z - v_down.z) / (2.0 * dx)
                divergence[i][j][k] = div
                
    return divergence

def enforce_free_slip_boundary(velocity_texture, obstacle_texture, obstacle_velocity_texture, nx, ny, nz):
    """
    Explicitly enforces u . n = u_solid . n after pressure projection.
    """
    for i in range(1, nx - 1):
        for j in range(1, ny - 1):
            for k in range(1, nz - 1):
                if is_solid_cell((i, j, k), obstacle_texture):
                    continue
                    
                v = velocity_texture.sample((i, j, k))
                solid_vel = get_obstacle_velocity((i, j, k), obstacle_velocity_texture)
                
                # Check each face and enforce normal component match
                if is_solid_cell((i-1, j, k), obstacle_texture): v.x = solid_vel.x
                if is_solid_cell((i+1, j, k), obstacle_texture): v.x = solid_vel.x
                if is_solid_cell((i, j-1, k), obstacle_texture): v.y = solid_vel.y
                if is_solid_cell((i, j+1, k), obstacle_texture): v.y = solid_vel.y
                if is_solid_cell((i, j, k-1), obstacle_texture): v.z = solid_vel.z
                if is_solid_cell((i, j, k+1), obstacle_texture): v.z = solid_vel.z
                
                velocity_texture.set((i, j, k), v)

def advect_with_obstacle_constraint(field_texture, velocity_texture, obstacle_texture, dt, dx, nx, ny, nz):
    """
    Advection step that prevents leaking into solids.
    """
    new_field = [[0.0] * nz for _ in range(ny)]
    for i in range(1, nx - 1):
        for j in range(1, ny - 1):
            for k in range(1, nz - 1):
                if is_solid_cell((i, j, k), obstacle_texture):
                    new_field[i][j][k] = 0.0
                    continue
                    
                # Backtrace
                vel = velocity_texture.sample((i, j, k))
                trace_pos = (i - vel.x * dt / dx, j - vel.y * dt / dx, k - vel.z * dt / dx)
                
                # Check if trace point is inside a solid
                if is_solid_cell(trace_pos, obstacle_texture):
                    new_field[i][j][k] = 0.0
                else:
                    # Trilinear interpolation from field_texture at trace_pos [G]
                    val = field_texture.sample_bilinear(trace_pos)
                    new_field[i][j][k] = val
                    
    return new_field
```

**Edge Cases and Pitfalls:**
- **Large Time Steps:** Quantities can "leak" through boundaries during advection if $\Delta t$ is large [S1, unofficial]. The advection constraint (Step 5) is critical to prevent this [S1, unofficial].
- **Opposing Boundaries:** If a fluid cell is bounded by solids on opposite faces, averaging the normal velocities from both sides is an option, but selecting one is sufficient and simpler [S1, unofficial].

## Operating characteristics
- **Time Complexity:** Adds constant overhead per cell for texture lookups and conditional checks during pressure solve, divergence, and advection [S1, unofficial]. The nullification trick maintains the sparsity of the matrix [S1, unofficial].
- **Memory Complexity:** Requires two additional 3D textures: `obstacles` (scalar) and `obstaclevelocity` (vector) [S1, unofficial].
- **Strengths:** Handles dynamic obstacles efficiently on GPU; allows tangential slip which is physically appropriate for many fluid scenarios; simple to implement using texture sampling [S1, unofficial].
- **Limitations:** Requires pre-computed obstacle velocity field [S1, unofficial].

## Background
This method is described in "Real-Time Simulation and Rendering of 3D Fluids" [S1, unofficial]. It extends fluid simulation to dynamic obstacles using a voxel-based inside-outside representation [S1, unofficial]. The approach is designed for real-time performance on GPUs, leveraging texture sampling for boundary checks [S1, unofficial].
