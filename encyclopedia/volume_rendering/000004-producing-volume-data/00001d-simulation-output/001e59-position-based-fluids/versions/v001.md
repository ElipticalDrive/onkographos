# Position Based Fluids


## Overview
Position Based Fluids (PBF) is a particle-based fluid simulation method that enforces incompressibility by correcting particle positions based on density constraints, allowing real-time simulation without meshing [S1, unofficial]. It differs from traditional Smoothed Particle Hydrodynamics (SPH) by solving for positions directly rather than pressures, which stabilizes the simulation and prevents density drift [S1, unofficial].

## How it works
**Inputs:** Particle positions, velocities, boundary definitions, smoothing radius $h$, rest density $\rho_0$, time step $\Delta t$, and iteration counts.
**Outputs:** Updated particle positions and velocities.

**Data Structures:**
*   `positions`: Array of vectors, size $N$ (number of particles).
*   `velocities`: Array of vectors, size $N$.
*   `old_positions`: Array of vectors, size $N$ (used for velocity update).
*   `position_deltas`: Array of vectors, size $N$.
*   `lambdas`: Array of scalars, size $N$ (Lagrange multipliers for density constraints).
*   `neighbors`: Spatial hash or grid structure mapping particle indices to neighbor indices.

def spiky_gradient(pos, h):
    """Standard SPH spiky kernel gradient."""
    # Formula: -32 / (pi * h^5) * (h - |r|)^2 * r_hat
    r = pos.length()

**Edge Cases and Pitfalls:**
*   Vorticity confinement and XSPH correction are disabled because cross products cannot be performed in 2D contexts, although the code is 3D [S1, unofficial]. This implies a limitation or specific configuration choice where 2D operations are forced or 3D vector operations are restricted [S1, unofficial].
*   Boundary confinement must be robust to prevent particles from escaping the simulation domain [S1, unofficial].
*   Precision issues may arise if `position_deltas` are not normalized correctly by $\rho_0$ [S1, unofficial].

## Operating characteristics
*   **Time Complexity:** $O(N \cdot k)$ per iteration, where $N$ is the number of particles and $k$ is the average number of neighbors. The total time is $O(N \cdot k \cdot \text{iters})$.
*   **Memory Complexity:** $O(N)$ for particle data structures.
*   **Measured Performance:** Not given in the sources.
*   **Strengths:** Real-time simulation capability; no meshing required; stable incompressibility enforcement [S1, unofficial].
*   **Limitations:** Disabled vorticity confinement and XSPH correction in certain contexts; potential precision issues if not implemented carefully [S1, unofficial].
*   **When to use:** Real-time fluid simulation where visual fidelity is prioritized over physical accuracy of vorticity [S1, unofficial].
*   **When not to use:** When accurate vorticity dynamics are critical and 3D cross products are available [S1, unofficial].

## Background
Position Based Fluids was introduced as a particle-based method to address the instability of pressure-based methods in real-time applications [S1, unofficial]. It is used in real-time rendering engines and interactive simulations [S1, unofficial].
