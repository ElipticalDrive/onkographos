# Position Based Fluids

Also called: PBF, Position-Based Dynamics Fluids

## Overview
Position Based Fluids (PBF) is a Lagrangian particle-based fluid simulation method that enforces incompressibility by directly correcting particle positions to satisfy density constraints [S1, unofficial][S2]. It differs from pressure-based solvers by using constraint projection within a Position-Based Dynamics framework, which stabilizes the simulation and avoids density drift [S2]. It builds on [Simulation output](15-simulation-output.md) and is distinct from [Gaussian Splashing](1387-gaussian-splashing.md) and [Smoke Advection](4639-smoke-advection.md) by decoupling simulation from rendering and operating entirely in particle space [S2].

## How it works
**Inputs:** Particle positions, velocities, boundary definitions, smoothing radius $h$, rest density $\rho_0$, time step $\Delta t$, iteration counts, particle masses $m_j$, and kernel radius $r$ [S1, unofficial][S2].
**Outputs:** Updated particle positions and velocities [S1, unofficial].

**Data Structures:**
*   `positions`: Array of vectors, size $N$ (number of particles).
*   `velocities`: Array of vectors, size $N$.
*   `old_positions`: Array of vectors, size $N$ (used for velocity update).
*   `position_deltas`: Array of vectors, size $N$.
*   `lambdas`: Array of scalars, size $N$ (Lagrange multipliers for density constraints).
*   `neighbors`: Flat array or list per particle with a `-1` terminator marking the end of the neighbor list [S1, unofficial].

**Pseudocode:**
```python
import math

class Vec3:
    def __init__(self, x=0.0, y=0.0, z=0.0):
        self.x, self.y, self.z = x, y, z
    def __add__(self, other): return Vec3(self.x + other.x, self.y + other.y, self.z + other.z)
    def __sub__(self, other): return Vec3(self.x - other.x, self.y - other.y, self.z - other.z)
    def __mul__(self, s): return Vec3(self.x * s, self.y * s, self.z * s)
    def __truediv__(self, s): return Vec3(self.x / s, self.y / s, self.z / s)
    def length(self): return math.sqrt(self.x**2 + self.y**2 + self.z**2)
    def normalize(self):
        l = self.length()
        return Vec3(self.x/l, self.y/l, self.z/l) if l > 0 else Vec3()

def spiky_gradient(pos: Vec3, h: float) -> Vec3:
    # Standard SPH spiky kernel gradient [G]
    r = pos.length()
    if 0 < r < h:
        factor = -32.0 / (math.pi * h**5) * (h - r)**2
        return factor * (pos / r)
    return Vec3()

def compute_scorr(pos_ji: Vec3, h: float) -> float:
    # Standard neighbor distance correction term [G]
    return max(0.0, h - pos_ji.length())

def confine_position_to_boundary(pos: Vec3, bounds) -> Vec3:
    # Clamp position to simulation domain boundaries [G]
    return Vec3(
        max(bounds[0][0], min(bounds[0][1], pos.x)),
        max(bounds[1][0], min(bounds[1][1], pos.y)),
        max(bounds[2][0], min(bounds[2][1], pos.z))
    )

def pbf_substep(positions, old_positions, velocities, neighbors, lambdas, h, rho0, dt, bounds):
    n = len(positions)
    # Save old positions for velocity update before modifying positions
    old_positions[:] = positions[:]
    position_deltas = [Vec3() for _ in range(n)]

    for i in range(n):
        pos_i = positions[i]
        position_deltas[i] = Vec3()
        for j in neighbors[i]:
            if j < 0:
                break
            pos_j = positions[j]
            pos_ji = pos_i - pos_j
            lambda_j = lambdas[j]
            lambda_i = lambdas[i]
            scorr_ij = compute_scorr(pos_ji, h)
            position_deltas[i] = position_deltas[i] + (lambda_i + lambda_j + scorr_ij) * spiky_gradient(pos_ji, h)
        position_deltas[i] = position_deltas[i] / rho0

    for i in range(n):
        positions[i] = positions[i] + position_deltas[i]

    for i in range(n):
        positions[i] = confine_position_to_boundary(positions[i], bounds)

    for i in range(n):
        velocities[i] = (positions[i] - old_positions[i]) / dt

def run_simulation(positions, velocities, old_positions, neighbors, lambdas, h, rho0, dt, bounds, num_iters):
    # Prologue setup [G]
    for _ in range(num_iters):
        pbf_substep(positions, old_positions, velocities, neighbors, lambdas, h, rho0, dt, bounds)
    # Epilogue cleanup [G]
```

**Formulas:**
*   Density constraint: $C_{i\rho} = \frac{1}{\rho_0} \sum_j m_j W(p_i - p_j, r) - 1 = 0$, where $m_j$ is particle mass, $\rho_0$ is rest density, $W$ is the SPH kernel, and $r$ is kernel radius [S2].
*   Cubic SPH kernel $W(p, r)$: $\frac{8}{\pi r^3} (6q^2(q-1)+1)$ for $0 \le q \le 0.5$; $\frac{16}{\pi r^3} (1-q)^3$ for $0.5 < q \le 1$; $0$ otherwise, where $q = \frac{\|p\|}{r}$ [S2].
*   Kernel gradient $\nabla_p W(p, r)$: $\frac{48}{\pi r^5} (3q-2)p$ for $0 \le \|p\|/r \le 0.5$; $-\frac{48}{\pi r^5} q p$ for $0.5 < \|p\|/r \le 1$; $0$ otherwise [S2].
*   Surface normal: $n_i = \text{normalize}(-\nabla_{p_i} C_{i\rho})$ [S2].
*   Area constraint: $C_{iA} = \sum_{t \in T(i)} \frac{1}{2} \|(p_{t2} - p_{t1}) \times (p_{t3} - p_{t1})\|$, where $T(i)$ is the set of neighboring triangles [S2].
*   Distance constraint: $C_{ij\_D} = \min\{0, \|p_i - p_j\| - d_0\}$, where $d_0$ is the distance threshold [S2].

**Parameters:**
*   $h$: Smoothing radius. Typical value: particle spacing $\times$ 1.25 (implied by `delta = h * 0.8` in initialization, suggesting particle spacing is $0.8h$) [S1, unofficial].
*   $\rho_0$: Rest density. Not given in the sources [S1, unofficial][S2].
*   `num_iters`: Number of PBF iterations per substep. Not given in the sources [S1, unofficial][S2].
*   $\Delta t$: Time step size. Not given in the sources [S1, unofficial][S2].
*   $d_0$: Distance threshold for particle repulsion [S2].
*   Surface particle update frequency: Surface particles are updated every two time steps [S2].

**Edge Cases and Pitfalls:**
*   Vorticity confinement and XSPH correction are disabled because cross products cannot be performed in 2D contexts, although the code is 3D [S1, unofficial]. This implies a limitation or specific configuration choice where 2D operations are forced or 3D vector operations are restricted [S1, unofficial].
*   Boundary confinement must be robust to prevent particles from escaping the simulation domain [S1, unofficial].
*   Precision issues may arise if `position_deltas` are not normalized correctly by $\rho_0$ [S1, unofficial].
*   Surface particles are updated every two time steps, which may affect temporal consistency in fast-moving flows [S2].

## Subtopics

### [XPBD Simulation Loop](7968-xpbd-simulation-loop.md)
A simulation method treating a dynamic system as $N$ vertices and $M$ constraints, converting variational optimization into constraint projections to minimize system energy. It serves as the underlying solver framework for PBF constraint projection steps. See [XPBD Simulation Loop](7968-xpbd-simulation-loop.md).

### Surface Tension Application
A minor variant that applies tension to minimize local surface area on detected surface particles [S2]. It begins by calculating the normal $n_i$ for surface particle $i$ as $n_i = \text{normalize}(-\nabla_{p_i} C_{i\rho})$ [S2]. Neighboring surface particles are projected onto a plane perpendicular to $n_i$ and triangularized [S2]. The area constraint $C_{iA}$ is then built to pull particles together, while distance constraints $C_{ij\_D}$ push apart particles that are too close [S2]. The Jacobians for the area constraint with respect to triangle vertices $t_1$, $t_2$, and $t_3$ are computed as:
$\nabla_{t_1} C_{tA}(p) = \frac{(p_{t2} - p_{t1}) \times (p_{t3} - p_{t1}) \times (p_{t3} - p_{t2})}{2 \|(p_{t2} - p_{t1}) \times (p_{t3} - p_{t1})\|}$,
$\nabla_{t_2} C_{tA}(p) = \frac{(p_{t3} - p_{t2}) \times (p_{t1} - p_{t2}) \times (p_{t1} - p_{t3})}{2 \|(p_{t3} - p_{t2}) \times (p_{t1} - p_{t2})\|}$,
$\nabla_{t_3} C_{tA}(p) = \frac{(p_{t1} - p_{t3}) \times (p_{t2} - p_{t3}) \times (p_{t2} - p_{t1})}{2 \|(p_{t1} - p_{t3}) \times (p_{t2} - p_{t3})\|}$ [S2].

## Operating characteristics
*   **Time Complexity:** Not given in the sources [S1, unofficial][S2].
*   **Memory Complexity:** Not given in the sources [S1, unofficial][S2].
*   **Measured Performance:** Not given in the sources [S1, unofficial][S2].
*   **Strengths:** Real-time simulation capability without meshing; stable incompressibility enforcement via direct position correction [S1, unofficial][S2].
*   **Limitations:** Vorticity confinement and XSPH correction are disabled in 2D contexts; surface tension requires local triangulation per particle which adds computational overhead [S1, unofficial][S2].
*   **When to use:** Real-time fluid synthesis where visual fidelity and stability are prioritized [S1, unofficial][S2].
*   **When not to use:** When accurate vorticity dynamics are required and the implementation supports 3D cross products, as the method disables vorticity confinement in 2D contexts [S1, unofficial].

## Background
Position Based Fluids is based on Position-Based Dynamics (PBD) [S2]. It is used in the Gaussian Splashing pipeline for unified particle motion synthesis and rendering [S2].
