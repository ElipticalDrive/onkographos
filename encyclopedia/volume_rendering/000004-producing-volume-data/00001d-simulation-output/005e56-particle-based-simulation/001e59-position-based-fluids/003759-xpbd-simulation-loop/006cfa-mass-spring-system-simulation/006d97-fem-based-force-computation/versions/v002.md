# FEM-based Force Computation
Also called: FEM Force Model, Finite Element Force Computation

## Overview
FEM-based Force Computation computes internal forces on a tetrahedral mesh using Finite Element Method principles, chosen over mass-spring systems to provide a more precise representation of triangles by accounting for all surface contributions [S1, unofficial]. It sets itself apart from its parent [Mass-Spring System Simulation](21252-mass-spring-system-simulation.md) by utilizing element stiffness matrices and local frame rotations rather than simple spring constants between nodes [S1, unofficial].

## How it works
**Inputs:**
- $x$: Current positions of the sampling points (vertices) of element $j$.
- $x_0$: Initial (rest) positions of the sampling points of element $j$.
- $K_j$: Stiffness matrix of element $j$.
- $R_j$: Rotation matrix of the local frame attached to element $j$, updated at each frame.

**Outputs:**
- $f_j(x)$: Force vector acting on the sampling points of element $j$.

**Data Structures:**
- $K_j$: Stiffness matrix of element $j$. Exact dimensions are Not given in the sources.
- $R_j$: Rotation matrix encoding the local frame's orientation relative to its initial state. Exact dimensions are Not given in the sources.
- $x, x_0$: Position vectors for current and initial sampling points. Exact dimensions are Not given in the sources.

**Steps:**
1. Compute the rotated displacement term: $v = R_j^T x - x_0$.
2. Apply the stiffness matrix: $f_{local} = K_j v$.
3. Rotate the result back to the global frame: $f_j(x) = R_j f_{local}$.

**Formula:**
The force $f_j(x)$ for element $j$ is given by:
$$ f_j(x) = R_j K_j (R_j^T x - x_0) $$
[S1, unofficial].

**Parameters:**
- $K_j$: Stiffness matrix of element $j$. Precomputed [S1, unofficial].
- $R_j$: Rotation matrix of the local frame. Updated at each frame [S1, unofficial].

**Edge Cases and Pitfalls:**
- **Ghost Torques:** Precomputing stiffness matrices can introduce "ghost torques" [S1, unofficial]. However, in this quasi-static integration approach, velocities are not conserved, so the effect of ghost torques is limited [S1, unofficial].
- **Inversion:** Forces of inverted elements are modified so that they fall back to an uninverted state, mixing approaches from [17] and [23] [S1, unofficial]. The local frame is chosen such that its third vertex (assimilated as the inverted one) has the smallest height [S1, unofficial].

**Pseudocode:**
```python
def compute_fem_force(x, x0, K_j, R_j):
    """
    Compute FEM-based force for element j.
    Implements f_j(x) = R_j @ K_j @ (R_j.T @ x - x0) exactly as cited.
    @ denotes standard matrix multiplication.
    """
    # Step 1: Compute rotated displacement term
    term = R_j.T @ x - x0
    
    # Step 2: Apply stiffness matrix
    f_local = K_j @ term
    
    # Step 3: Rotate force back to global frame
    f = R_j @ f_local
    
    return f
```

## Subtopics

### [Inversion Force Recovery](21516-inversion-force-recovery.md)
A method to modify forces of inverted elements so they fall back to an uninverted state, mixing approaches from [17] and [23]. It sets apart from standard FEM force computation by detecting geometric inversion and applying a corrective local frame rotation to restore physical plausibility, whereas standard methods simply compute forces based on the current deformed state.

## Operating characteristics
- **Time Complexity:** $O(1)$ per element for the matrix-vector multiplications, as $K_j$ is small for tetrahedra [G].
- **Memory Complexity:** $O(N)$ for storing $K_j$ and $R_j$ per element, where $N$ is the number of elements [G].
- **Measured Performance:** Not given in the sources.
- **Strengths:** More precise triangle representation than mass-spring systems; efficient if stiffness matrices are precomputed [S1, unofficial].
- **Limitations:** Precomputed stiffness matrices can introduce "ghost torques" [S1, unofficial].
- **When to use:** When a better representation of triangles is needed than mass-spring systems allow, and perfect mechanical simulation is not required [S1, unofficial].
- **When not to use:** When velocity conservation is critical due to ghost torques [S1, unofficial].

## Background
The method is based on the Finite Element Method (FEM) approach for modeling forces and force derivatives. It was chosen over mass-spring systems for better triangle representation [S1, unofficial]. The specific efficient FEM-based method presented in [23] was used, resulting in equation 3 [S1, unofficial]. The approach is based on a quasi-static integration, where velocities are not conserved [S1, unofficial].
