# Synthetic Active Region Generation
Also called: Mode C, Synthetic Bipole
## Overview
Synthetic Active Region Generation creates a synthetic bipolar active region magnetogram by summing Gaussian flux concentrations, satellite flux, polarity inversion line (PIL) shear, diffuse background, and instrument noise [S1, unofficial]. It solves the problem of generating realistic, volumetric magnetic field data for visualization by converting parametric tube geometry into a discrete set of 3D points with associated vector field values and intensity [S1, unofficial]. It differs from direct field evaluation methods by explicitly tracing a path with a restoring force and random walk, rather than sampling a static analytical field at grid points [S1, unofficial].
## How it works
**Inputs:**
- `seed`: Integer seed for the random number generator.
- `GRID_SIZE` ($g$): Integer resolution of the output grid (e.g., 1024).

**Outputs:**
- `bz`: A 2D numpy array of shape $(g, g)$ with `dtype=np.float32`, representing the magnetic field strength.

**Data Structures:**
- `rng`: A `numpy.random.Generator` instance initialized with `seed`.
- `XX`, `YY`: 2D arrays of shape $(g, g)$ created via `np.meshgrid`, containing the x and y coordinates of each grid cell. The coordinates range from -4.0 to 4.0.

**Steps:**

1.  **Initialize RNG and Grid:**
    Create the random number generator and coordinate grids.
    ```python
    rng = np.random.default_rng(seed)
    g = GRID_SIZE
    x = np.linspace(-4.0, 4.0, g)
    y = np.linspace(-4.0, 4.0, g)
    XX, YY = np.meshgrid(x, y)
    ```

2.  **Initialize Bz Grid:**
    Create a zero-filled grid for the magnetic field.
    ```python
    bz = np.zeros((g, g), dtype=np.float32)
    ```

3.  **Add Primary Positive Bipole:**
    Sample parameters for the positive flux concentration and add a Gaussian.
    - `pos_peak`: Sampled from uniform distribution $[1200, 1800]$.
    - `pos_sigma`: Sampled from uniform distribution $[0.60, 0.85]$.
    - `pos_cx`, `pos_cy`: Fixed centers at $(-1.35, 0.10)$.
    - Formula:
      $$ bz \ += \ pos\_peak \cdot \exp\left(-\frac{(XX - pos\_cx)^2 + (YY - pos\_cy)^2}{2 \cdot pos\_sigma^2}\right) $$

4.  **Add Primary Negative Bipole:**
    Sample parameters for the negative flux concentration and add a Gaussian.
    - `neg_peak`: Sampled from uniform distribution $[-1400, -900]$ (note: source specifies `-rng.uniform(900, 1400)`).
    - `neg_sigma`: Sampled from uniform distribution $[0.75, 1.00]$.
    - `neg_cx`, `neg_cy`: Fixed centers at $(1.50, -0.05)$.
    - Formula:
      $$ bz \ += \ neg\_peak \cdot \exp\left(-\frac{(XX - neg\_cx)^2 + (YY - neg\_cy)^2}{2 \cdot neg\_sigma^2}\right) $$

5.  **Add Satellite Flux:**
    Generate 3 to 6 satellite flux concentrations (inclusive).
    - `n_satellites`: Sampled from integers $[3, 7)$.
    - For each satellite:
      - `sc_x`: Sampled from uniform distribution $[-3.0, 3.0]$.
      - `sc_y`: Sampled from uniform distribution $[-2.5, 2.5]$.
      - `sc_peak`: Sampled as $\pm \text{uniform}(80, 350)$, where the sign is chosen randomly from $\{-1, 1\}$.
      - `sc_sig`: Sampled from uniform distribution $[0.20, 0.50]$.
      - Formula:
        $$ bz \ += \ sc\_peak \cdot \exp\left(-\frac{(XX - sc\_x)^2 + (YY - sc\_y)^2}{2 \cdot sc\_sig^2}\right) $$

6.  **Add PIL Shear:**
    Add a shear component modulated by a Gaussian envelope.
    - `pil_shear`: Sampled from uniform distribution $[0.08, 0.25]$.
    - `pil_warp`: Calculated as $\tanh((XX + pil\_shear \cdot YY) \cdot 1.5) \cdot \text{uniform}(30, 80)$.
    - Formula:
      $$ bz \ += \ pil\_warp \cdot \exp\left(-\frac{XX^2 + YY^2}{8.0}\right) $$

7.  **Add Diffuse Background:**
    Add a diffuse background noise term.
    - `bg_val`: Sampled from uniform distribution $[-40, 40]$.
    - Formula:
      $$ bz \ += \ bg\_val \cdot \exp\left(-\frac{XX^2 + YY^2}{12.0}\right) $$

8.  **Add Instrument Noise:**
    Add Gaussian noise to simulate instrument error.
    - `noise`: Sampled from normal distribution $\mathcal{N}(0, 15.0)$ with shape $(g, g)$, cast to `float32`.
    - Formula:
      $$ bz \ += \ noise $$

9.  **Apply Boundary Apodisation:**
    Smoothly fade the field to zero at the boundaries to prevent artifacts.
    - `r2`: Calculated as $(XX / 4.2)^2 + (YY / 4.2)^2$.
    - `apod`: Calculated as $\sqrt{\max(0, 1.0 - r2)}$.
    - Formula:
      $$ bz \ *= \ apod $$

**Pseudocode:**
```python
import numpy as np

def generate_active_region(seed, GRID_SIZE):
    # 1. Initialize RNG and Grid
    rng = np.random.default_rng(seed)
    g = GRID_SIZE
    x = np.linspace(-4.0, 4.0, g)
    y = np.linspace(-4.0, 4.0, g)
    XX, YY = np.meshgrid(x, y)
    
    # 2. Initialize Bz Grid
    bz = np.zeros((g, g), dtype=np.float32)
    
    # 3. Add Primary Positive Bipole
    pos_peak = rng.uniform(1200, 1800)
    pos_sigma = rng.uniform(0.60, 0.85)
    pos_cx, pos_cy = -1.35, 0.10
    bz += pos_peak * np.exp(-((XX - pos_cx)**2 + (YY - pos_cy)**2) / (2 * pos_sigma**2))
    
    # 4. Add Primary Negative Bipole
    neg_peak = -rng.uniform(900, 1400)
    neg_sigma = rng.uniform(0.75, 1.00)
    neg_cx, neg_cy = 1.50, -0.05
    bz += neg_peak * np.exp(-((XX - neg_cx)**2 + (YY - neg_cy)**2) / (2 * neg_sigma**2))
    
    # 5. Add Satellite Flux
    n_satellites = rng.integers(3, 7)
    for _ in range(n_satellites):
        sc_x = rng.uniform(-3.0, 3.0)
        sc_y = rng.uniform(-2.5, 2.5)
        sc_sign = rng.choice([-1, 1])
        sc_peak = sc_sign * rng.uniform(80, 350)
        sc_sig = rng.uniform(0.20, 0.50)
        bz += sc_peak * np.exp(-((XX - sc_x)**2 + (YY - sc_y)**2) / (2 * sc_sig**2))
        
    # 6. Add PIL Shear
    pil_shear = rng.uniform(0.08, 0.25)
    pil_warp = np.tanh((XX + pil_shear * YY) * 1.5) * rng.uniform(30, 80)
    bz += pil_warp * np.exp(-(XX**2 + YY**2) / 8.0)
    
    # 7. Add Diffuse Background
    bg_val = rng.uniform(-40, 40)
    bz += bg_val * np.exp(-(XX**2 + YY**2) / 12.0)
    
    # 8. Add Instrument Noise
    noise = rng.normal(0, 15.0, (g, g)).astype(np.float32)
    bz += noise
    
    # 9. Apply Boundary Apodisation
    r2 = (XX / 4.2)**2 + (YY / 4.2)**2
    apod = np.clip(1.0 - r2, 0, 1)**0.5
    bz *= apod
    
    return bz
```

**Edge Cases and Pitfalls:**
- **Precision:** The use of `float32` for the grid and noise may introduce quantization artifacts in low-intensity regions, though this matches the source specification [S1, unofficial].
- **Boundaries:** The apodisation factor becomes zero when $r2 \ge 1$, effectively masking the field outside the radius of 4.2 units. Points exactly on the boundary are handled by `np.clip`.
- **Degenerate Input:** If `GRID_SIZE` is too small, the Gaussian peaks may not be resolved, leading to aliasing. The source does not specify a minimum resolution.

## Subtopics

### [Flux Tube Filament Generation](12011-flux-tube-filament-generation.md)
Flux Tube Filament Generation is a procedural algorithm that traces sample points along magnetic field lines (filaments) within a synthetic flux tube volume, incorporating radial convergence and stochastic noise to simulate magnetic field line wandering. It solves the problem of generating structured, volumetric magnetic field data for visualization by converting a parametric tube geometry into a discrete set of 3D points with associated vector field values and intensity. It differs from direct field evaluation methods by explicitly tracing a path with a restoring force and random walk, rather than sampling a static analytical field at grid points.

## Operating characteristics
- **Time Complexity:** $O(g^2)$ per Gaussian addition, where $g$ is the grid size. With a constant number of Gaussians (2 primary, 3-6 satellites, 1 shear, 1 background), the total time is linear in the number of pixels.
- **Memory Complexity:** $O(g^2)$ for the `bz` grid and coordinate arrays.
- **Measured Performance:** Not given in the sources.
- **Strengths:** Fast to generate; produces visually realistic bipolar structures with shear and noise.
- **Limitations:** The output is a 2D magnetogram, not a full 3D volume, though it serves as input for 3D generation methods. The parameters are hardcoded ranges, limiting fine control over specific physical properties.
- **When to use:** When a quick, realistic synthetic magnetogram is needed for testing or visualization pipelines.
- **When not to use:** When precise physical accuracy or 3D volumetric data is required directly from this step.
