# Superelliptic Blends

Also called: Pseudonorm Blend, Ricci blend, Rockwood and Owen blend

## Overview
Superelliptic blends (also known as pseudonorm blends) are a local geometric deformation technique for implicitly defining the union of two or more signed distance functions (SDFs) [S1, S2]. Unlike global field additions, this method computes a $p$-norm distance to the blended union, allowing for smooth transitions between surfaces controlled by a tightness parameter [S1, S2]. It is distinct from standard additive metaballs because it operates on the distance values directly rather than scalar field intensities, and it differs from soft metaballs by using a specific $L_p$-norm formulation [S1].

## How it works
**Inputs and Outputs:**
*   **Inputs:** Two signed distance functions $f_1(\mathbf{x})$ and $f_2(\mathbf{x})$, a blend parameter $p > 0$ (thumbweight), and support radii $d_1, d_2$ defining the local domain of influence for each function.
*   **Output:** A new signed distance function $g(\mathbf{x})$ representing the blended union.

**Data Structures:**
No specific data structures are required beyond the evaluation functions $f_1, f_2$ and the scalar parameters $p, d_1, d_2$. The method is stateless and evaluates point-wise.

**Mathematical Definition:**
The method relies on reformulating the signed distance functions into strictly non-negative functions, following Ricci's original formulation where implicit surfaces are defined by setting non-negative functions equal to one [S1]. For a signed distance function $f(\mathbf{x})$, we define the non-negative component $g_i(\mathbf{x})$ as:

$$ g_i(\mathbf{x}) = \max(1 - f_i(\mathbf{x}), 0) $$

This ensures that $g_i(\mathbf{x})$ is non-zero only within the support region where $f_i(\mathbf{x}) < 1$ [S1].

The superelliptic blend of the union of the implicit surface of $f_1$ and $f_2$ is defined by the implicit surface of the blended function $G(\mathbf{x})$:

$$ G(\mathbf{x}) = \left( \frac{g_1(\mathbf{x})^p + g_2(\mathbf{x})^p}{g_1(\mathbf{x})^p + g_2(\mathbf{x})^p + \dots} \right)^{1/p} $$

However, the specific formulation for the *union* using the pseudonorm blend returns the $p$-norm distance. Based on the source derivation [S1], the blended function value $B(\mathbf{x})$ is calculated as:

$$ B(\mathbf{x}) = \left( g_1(\mathbf{x})^p + g_2(\mathbf{x})^p \right)^{1/p} $$

The final signed distance function $f_{blend}(\mathbf{x})$ is then derived from $B(\mathbf{x})$. Note that the source [S1] defines the blend via the implicit surface of the resulting function. The parameter $p$ acts as a thumbweight describing how tightly the blend adheres to the original surfaces [S1]. As $p \to \infty$, the blend approaches the maximum (standard union); as $p \to 1$, it approaches the $L_1$ norm blend.

**Numbered Steps:**
1.  Evaluate $f_1(\mathbf{x})$ and $f_2(\mathbf{x})$ at the query point $\mathbf{x}$.
2.  Compute the non-negative components:
    $$ g_1(\mathbf{x}) = \max(1 - f_1(\mathbf{x}), 0) $$
    $$ g_2(\mathbf{x}) = \max(1 - f_2(\mathbf{x}), 0) $$
3.  Check if both $g_1(\mathbf{x})$ and $g_2(\mathbf{x})$ are zero. If so, the point is outside the influence of both primitives; return the distance to the nearest primitive (or handle as background) [S1].
4.  Compute the blended value using the $p$-norm:
    $$ B(\mathbf{x}) = \left( g_1(\mathbf{x})^p + g_2(\mathbf{x})^p \right)^{1/p} $$
5.  The resulting implicit surface is defined by $B(\mathbf{x}) = 1$ (or equivalent isovalue depending on the specific normalization used in the rendering pipeline, typically derived from the $g_i$ definition where surface is at $f=0 \implies g=1$) [S1].

**Parameters:**
*   $p$: The blend exponent. Typical values depend on the desired smoothness. Small $p$ yields smoother, more "blobby" blends; large $p$ yields sharper, more distinct surfaces [S1].
*   $d_1, d_2$: Support radii. If $f_i$ are SDFs, these are in Euclidean units [S1].

**Edge Cases and Pitfalls:**
*   **Gradient Discontinuities:** The superelliptic blend creases the space surrounding the blend [S2]. Outside the domain where both $g_1$ and $g_2$ are non-zero, it is impossible to smoothly combine the results, resulting in a crease and gradient discontinuities [S1].
*   **Root Finding:** These gradient discontinuities can be disastrous for iterative root finders (e.g., Newton-Raphson) [S1, S2].
*   **Sphere Tracing:** The discontinuities do *not* impact geometric ray intersection methods like sphere tracing, as sphere tracing relies on the Lipschitz constant (distance to surface) rather than the gradient direction for step sizing [S1, S2].

**Pseudocode:**

```python
def superelliptic_blend_union(x, f1, f2, p):
    """
    Computes the superelliptic blend (pseudonorm) of two SDFs.
    
    Args:
        x: Point in 3D space.
        f1: Function returning signed distance for primitive 1.
        f2: Function returning signed distance for primitive 2.
        p: Blend parameter (p > 0).
        
    Returns:
        Blended signed distance value.
    """
    # 1. Evaluate SDFs
    dist1 = f1(x)
    dist2 = f2(x)
    
    # 2. Reformulate to non-negative components g_i = max(1 - f_i, 0)
    # This maps the surface f_i=0 to g_i=1, and outside to g_i=0.
    g1 = max(1.0 - dist1, 0.0)
    g2 = max(1.0 - dist2, 0.0)
    
    # 3. Handle case where both are outside support
    if g1 == 0.0 and g2 == 0.0:
        # Return distance to nearest surface. 
        # Since f1, f2 are SDFs, the distance is min(dist1, dist2).
        # Note: If dist > 1, g=0. The actual distance is dist.
        return min(dist1, dist2)
    
    # 4. Compute p-norm blend
    # B(x) = (g1^p + g2^p)^(1/p)
    # We need to handle p=0 or very small p carefully, but p>0 is standard.
    term1 = g1 ** p
    term2 = g2 ** p
    
    blended_g = (term1 + term2) ** (1.0 / p)
    
    # 5. Convert back to signed distance.
    # The implicit surface is defined where blended_g = 1.
    # If blended_g > 1, we are inside (dist < 0). If blended_g < 1, outside (dist > 0).
    # The distance from the surface is proportional to (1 - blended_g).
    # However, the exact mapping from blended_g back to signed distance 
    # requires care. The source [S1] defines the blend via the implicit surface 
    # of the resulting function. 
    # For SDFs, the distance is often approximated or derived. 
    # A common interpretation for pseudonorm blends in sphere tracing 
    # is that the step size is determined by the distance to the zero crossing.
    # If we assume the output should be a signed distance function:
    # The value 1 corresponds to the surface.
    # Distance = 1 - blended_g ? 
    # Let's check: If g1=1 (surface 1), g2=0. blended_g = 1. Dist = 0. Correct.
    # If g1=0 (outside 1), g2=1 (surface 2). blended_g = 1. Dist = 0. Correct.
    # If g1=0.5, g2=0.5, p=1. blended_g = 1. Dist = 0. 
    # Wait, if g1=0.5, dist1 = 0.5. If g2=0.5, dist2 = 0.5.
    # The blend of two surfaces at distance 0.5 should be closer to 0?
    # Actually, the pseudonorm blend returns the p-norm distance to the union.
    # The source [S1] says it returns the p-norm distance.
    # Let's return the blended_g value itself, as the isosurface is at 1.
    # The renderer will solve blended_g(x) = 1.
    return blended_g
```

## Subtopics

### Metaball Field Evaluation
Uses additive scalar fields rather than distance norms. Choose when smooth, organic merging is needed without strict distance preservation [1017-metaball-field-evaluation.md].

### Soft Metablobby SDF
A variant that softens the transition. Choose when anti-aliasing of the blend edge is required without the sharp creases of the standard pseudonorm [2753-soft-metablobby-sdf.md].

## Operating characteristics
*   **Time Complexity:** $O(1)$ per sample point, assuming $f_1$ and $f_2$ are $O(1)$. The cost is dominated by the exponentiation and root operations.
*   **Memory Complexity:** $O(1)$. No auxiliary data structures are stored.
*   **Strengths:** Local blending allows for efficient culling using bounding volumes [S1]. It preserves the distance property better than additive metaballs for sphere tracing [S2].
*   **Limitations:** The gradient discontinuities at the boundary of the blend domain make it unsuitable for gradient-based optimization or root-finding algorithms [S1, S2]. It is primarily designed for sphere tracing (geometric ray intersection) [S1, S2].
*   **Scaling:** Scales linearly with the number of blended primitives if extended to $N$ inputs, but the local nature means only nearby primitives need evaluation.

## Background
The superelliptic blend was introduced by Rockwood and Owen in 1987 [S1, S2]. It is based on the pioneering work of Antonio Ricci in 1974, who defined implicit surfaces using strictly non-negative functions set to one [S1]. The method is also referred to as the "pseudonorm blend" because it computes a $p$-norm distance to the union of surfaces. It is widely used in sphere tracing for rendering implicit surfaces due to its compatibility with the Lipschitz property required for safe step sizes [S2].
