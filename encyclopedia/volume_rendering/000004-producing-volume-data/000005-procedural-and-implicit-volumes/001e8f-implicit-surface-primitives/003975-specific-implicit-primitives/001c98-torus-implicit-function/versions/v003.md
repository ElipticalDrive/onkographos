# Torus Implicit Function

Also called: Signed Distance Field (SDF) Torus Primitive, Signed Distance Function (SDF) for Torus, Torus SDF, Torus Scalar Field, Torus distance, sdTorus

## Overview
The Torus Implicit Function computes the signed distance from a query point to the surface of a torus, defined by a major radius and a minor radius [S1, unofficial][S6]. It solves the problem of evaluating the scalar field for a specific implicit primitive within procedural volume rendering or ray marching [S5, unofficial]. It is distinguished from generic quadric approximations by providing an exact analytical distance (in its standard form) or a robust first-order gradient approximation for specific implementations, avoiding the numerical instability of general polynomial solvers [S2, unofficial][S6].

## How it works
### Inputs and Outputs
- **Input**: A 3D query point $p = (p_x, p_y, p_z)$ and torus parameters.
- **Output**: A scalar value $d$ representing the signed distance. $d < 0$ indicates the point is inside the torus, $d > 0$ indicates it is outside, and $d = 0$ lies on the surface [S5, unofficial].

### Data Structures
- **Point $p$**: A 3D vector $(p_x, p_y, p_z)$.
- **Parameters**:
  - Standard form: Major radius $R$ and minor radius $r$ [S1, unofficial][S6].
  - Alternative form (diameter/thickness): $t_x$ (diameter, $2R$) and $t_y$ (thickness, $2r$) [S5, unofficial].

### Formulas and Steps
There are two primary formulations found in the sources: the exact analytical distance (most common) and a first-order Taylor approximation.

#### 1. Exact Analytical Distance (Standard)
This method computes the exact Euclidean distance to the torus surface [S1, S4, S5, unofficial][S6].

1.  **Project to the plane of the torus ring**:
    Calculate the distance from the query point to the central axis of the torus. For a torus aligned with the Y-axis (ring in the XZ plane), compute the radial distance $\rho$:
    $$ \rho = \sqrt{p_x^2 + p_z^2} $$
    [S1, S3, S5, unofficial]

2.  **Define the 2D cross-section point**:
    Map the 3D point to a 2D plane containing the torus's center and the query point's radial projection. Let $q$ be a 2D vector:
    $$ q = (\rho - R, p_y) $$
    If using diameter/thickness parameters ($t_x, t_y$):
    $$ q = (\sqrt{p_x^2 + p_z^2} - t_x, p_y) $$
    [S1, S4, S5, unofficial]

3.  **Compute the distance**:
    The signed distance is the distance from the origin to $q$, minus the minor radius:
    $$ d = \|q\| - r $$
    Or explicitly:
    $$ d = \sqrt{(\rho - R)^2 + p_y^2} - r $$
    [S1, unofficial][S6]

    *Note on Orientation*: If the torus is aligned with the Z-axis (ring in the XY plane), swap $p_y$ and $p_z$ in the calculation of $\rho$ and $q$ [S6].

#### 2. First-Order Approximation (Gradient-Based)
Some implementations use a first-order Taylor approximation of the implicit function $f(p)$ to estimate the distance, particularly when gradients are needed for shading or marching [S2, unofficial].

1.  **Define the implicit function**:
    $$ f(p) = (\sqrt{p_x^2 + p_y^2} - R)^2 + p_z^2 - r^2 $$
    (Assuming alignment with Z-axis as per [S3, unofficial]).
    [S3, unofficial]

2.  **Compute Gradient Components**:
    Calculate the partial derivatives $\nabla f = (df/dx, df/dy, df/dz)$.
    Let $\rho = \sqrt{p_x^2 + p_y^2}$. To handle the singularity at $\rho=0$, use a safe epsilon:
    $$ \text{safe\_}\rho = \max(\rho, \epsilon), \quad \epsilon = 10^{-12} $$
    $$ \text{factor} = \frac{2(\rho - R)}{\text{safe\_}\rho} $$
    $$ \frac{\partial f}{\partial x} = \text{factor} \cdot p_x $$
    $$ \frac{\partial f}{\partial y} = \text{factor} \cdot p_y $$
    $$ \frac{\partial f}{\partial z} = 2 p_z $$
    [S3, unofficial]

3.  **Approximate Distance**:
    The signed distance is approximated by dividing the implicit function value by the gradient magnitude:
    $$ d \approx \frac{f(p)}{\|\nabla f\|} $$
    [S2, unofficial]

    *Note*: Source [S2, unofficial] provides a generalized quadric approximation formula $f_0/f_1$ which applies to tori represented as quadrics, but the specific gradient calculation in [S3, unofficial] is more direct for the standard torus implicit form.

### Pseudocode
The following implementation uses the exact analytical distance, which is the standard for ray marching and SDF rendering [S5, unofficial]. It assumes the torus is centered at the origin, aligned with the Y-axis (major radius in XZ plane).

```python
import math

def sd_torus(p: tuple, major_radius: float, minor_radius: float) -> float:
    """
    Computes the signed distance from point p to a torus.
    
    Args:
        p: (px, py, pz) query point coordinates.
        major_radius: Distance from the center of the tube to the center of the torus (R).
        minor_radius: Radius of the tube (r).
        
    Returns:
        Signed distance. Negative if inside, positive if outside.
    """
    px, py, pz = p
    
    # 1. Project point to the plane of the torus ring (XZ plane)
    # Calculate radial distance from the Y-axis
    rho = math.sqrt(px * px + pz * pz)
    
    # 2. Define the 2D point q in the cross-sectional plane
    # q_x is the distance from the ring center line
    # q_y is the height along the torus axis
    qx = rho - major_radius
    qy = py
    
    # 3. Compute the distance from the origin to q, minus the tube radius
    distance = math.sqrt(qx * qx + qy * qy) - minor_radius
    
    return distance

def sd_torus_approx(p: tuple, major_radius: float, minor_radius: float) -> float:
    """
    First-order approximation of the signed distance using gradient.
    Useful if implicit function value and gradient are already computed.
    """
    px, py, pz = p
    
    # Implicit function f(p) for torus aligned with Z-axis (adjust coords if Y-axis aligned)
    # Note: This example assumes Z-axis alignment for f(p) as per [S3, unofficial]
    # For Y-axis alignment, swap y and z in rho calculation
    rho = math.sqrt(px * px + py * py)
    safe_rho = max(rho, 1e-12)
    
    # f(p) = (rho - R)^2 + z^2 - r^2
    f_val = (safe_rho - major_radius)**2 + pz**2 - minor_radius**2
    
    # Gradient
    factor = 2.0 * (rho - major_radius) / safe_rho
    df_dx = factor * px
    df_dy = factor * py
    df_dz = 2.0 * pz
    
    grad_mag = math.sqrt(df_dx**2 + df_dy**2 + df_dz**2)
    
    # Avoid division by zero
    if grad_mag < 1e-12:
        return 0.0
        
    return f_val / grad_mag
```

### Parameters
- **$R$ (Major Radius)**: The distance from the center of the torus to the center of the tube. Default often 1.0 [S3, unofficial][S6].
- **$r$ (Minor Radius)**: The radius of the tube. Default often 0.3 [S3, unofficial][S6].
- **$t_x$ (Diameter)**: $2R$. Used in some implementations [S5, unofficial].
- **$t_y$ (Thickness)**: $2r$. Used in some implementations [S5, unofficial].

### Edge Cases and Pitfalls
- **Singularity at Axis**: When the query point lies on the central axis of the torus ($\rho = 0$), the term $\frac{\rho - R}{\rho}$ in the gradient calculation becomes undefined. A safe epsilon (e.g., $10^{-12}$) must be used in the denominator [S3, unofficial].
- **Approximation Failure**: The first-order approximation fails or becomes inaccurate near the torus center or when the gradient magnitude approaches zero, as it involves division by the gradient norm [S2, unofficial]. The exact analytical method does not suffer from this division issue.
- **Orientation**: The formula depends on the torus's alignment. The standard formula provided assumes the torus ring lies in the XZ plane (axis along Y). If the torus is aligned with the Z-axis, $p_y$ and $p_z$ must be swapped in the radial calculation [S6].

## Operating characteristics
- **Time Complexity**: $O(1)$. The calculation involves a constant number of arithmetic operations and square roots.
- **Memory Complexity**: $O(1)$. No auxiliary data structures are required.
- **Strengths**: Provides an exact signed distance (in the standard form), which guarantees convergence for sphere tracing/ray marching. It is computationally cheap.
- **Limitations**: The exact formula assumes a perfect torus. The first-order approximation is less robust near singularities.
- **When to use**: When rendering a torus shape using ray marching or voxelizing a torus volume.
- **When not to use**: When the torus is heavily deformed or non-uniform, as the analytical solution no longer applies.

## Background
The signed distance function for a torus is a fundamental primitive in implicit surface rendering. It was popularized by Inigo Quilez in his articles on distance functions [S5, unofficial][S6]. The exact analytical solution relies on the geometric property that a torus is the locus of points at a constant distance from a circle. The first-order approximation approach relates to general quadric surface handling in ray tracing [S2, unofficial]. The method is widely used in real-time graphics, VFX, and procedural geometry generation.
