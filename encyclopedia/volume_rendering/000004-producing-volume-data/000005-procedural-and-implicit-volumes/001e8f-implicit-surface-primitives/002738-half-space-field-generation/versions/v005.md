# Half-Space Field Generation

Also called: Binary Half-Volume, Level Set Domain Definition, Level Set Masking, Step Function Field

## Overview
Half-Space Field Generation creates a binary volume mask by assigning values to voxels based on a spatial or level-set condition, effectively gating simulation or rendering computations [S1, unofficial][S2, unofficial]. It differs from continuous implicit primitives by discretizing the domain boundary into a hard binary mask rather than evaluating a smooth scalar field for isosurface extraction [G]. This method restricts physical simulation (such as pressure solving or force application) to active regions, ignoring empty space like air [S2, unofficial].

## How it works
**Inputs and Outputs:**
- Input: A 3D grid domain defined by dimensions $(xSize, ySize, zSize)$ and a logical condition defining the active region (e.g., $y \ge ySize/2$ or $\phi < 0$) [S1, unofficial][S2, unofficial].
- Output: A 3D array of floats with the same dimensions, containing binary values (0 or 1) [S1, unofficial].

**Data Structures:**
- `volume`: A 3D array of size $(xSize, ySize, zSize)$ [S1, unofficial].
- Data type: Typically 32-bit float or 16-bit float for GPU compatibility [S2, unofficial].

**Steps:**
1. Initialize the 3D float array `volume` of size $(xSize, ySize, zSize)$ to zero [S1, unofficial].
2. Iterate through voxel coordinates $(x, y, z)$ where $0 \le x < xSize$, $0 \le z < zSize$, and $0 \le y < ySize$ [G].
3. Apply the half-space condition. In the canonical example, the domain is split by the Y-axis: if $y \ge ySize/2$, set `volume[x, y, z] = 1`; otherwise set to 0 [S1, unofficial].
4. For general level-set based generation, evaluate the level set function $\phi(\vec{x})$ [S2, unofficial]. If $\phi(\vec{x}) < 0$ (inside fluid), mark the cell as active; otherwise mark it as inactive [S2, unofficial].
5. Use the resulting binary mask in shaders or solvers to gate computations [S2, unofficial]. For example, set pressure to zero outside the liquid ($\phi \ge 0$) before solving [S2, unofficial].

**Formulas:**
- Half-space condition: $y \ge \frac{ySize}{2}$ [S1, unofficial].
- Level-set condition: $\phi(\vec{x}) < 0$ [S2, unofficial].
- Pressure masking: $P_{masked}(\vec{x}) = P(\vec{x}) \cdot M(\vec{x})$, where $M(\vec{x}) \in \{0, 1\}$ [G].

**Pseudocode:**
```python
def generate_half_space_volume(xSize, ySize, zSize):
    """Generates a binary 3D volume mask based on the canonical Y-axis split."""
    volume = [[[0.0] * xSize for _ in range(zSize)] for _ in range(ySize)]
    for y in range(ySize // 2, ySize):
        for z in range(zSize):
            for x in range(xSize):
                volume[y][z][x] = 1.0
    for y in range(ySize // 2):
        for z in range(zSize):
            for x in range(xSize):
                volume[y][z][x] = 0.0
    return volume

def apply_mask_to_pressure(pressure_field, mask_field):
    """Sets pressure to zero where the mask field is 0."""
    ySize = len(pressure_field)
    zSize = len(pressure_field[0])
    xSize = len(pressure_field[0][0])
    for y in range(ySize):
        for z in range(zSize):
            for x in range(xSize):
                if mask_field[y][z][x] == 0:
                    pressure_field[y][z][x] = 0.0
    return pressure_field
```

**Parameters:**
- `split_threshold`: The fractional position of the boundary (e.g., 0.5 for the middle) [S1, unofficial].
- `threshold` for level sets: A small epsilon value to determine $\phi \ge 0$ vs $\phi < 0$ [S2, unofficial].

**Edge Cases and Pitfalls:**
- **Precision:** Using 32-bit floating-point textures for storage yields roughly half the performance of 16-bit textures due to bandwidth issues [S2, unofficial].
- **Boundary Conditions:** Forces such as gravity must not be applied outside the liquid domain to avoid numerical artifacts [S2, unofficial].
- **GPU Flow Control:** Checking the level set value in shaders requires dynamic flow control [S2, unofficial]. If the GPU lacks this, performance degrades [S2, unofficial].

## Operating characteristics
- **Time Complexity:** $O(N)$ where $N = xSize \times ySize \times zSize$, as every voxel must be visited to set the binary value [G].
- **Memory Complexity:** $O(N)$ for storing the 3D array [G].
- **Performance:** Bandwidth is a major factor. Storing the mask in 16-bit textures improves performance compared to 32-bit [S2, unofficial].
- **Strengths:** Simple to implement; effectively culls empty space in simulations (e.g., air) [S2, unofficial].
- **Alternatives:** For GPUs without dynamic flow control, use z-culling to eliminate cells or sparse data structures instead of a dense binary mask [S2, unofficial].

## Background
The technique is widely used in real-time fluid simulation to define the domain of the solver [S2, unofficial]. It allows the simulation to ignore air ($\phi \ge 0$) and only compute pressure and forces within the liquid ($\phi < 0$) [S2, unofficial]. The approach is detailed in *GPU Gems 3* regarding real-time 3D fluid simulation [S2, unofficial].
