# Script-to-Shader SDF Preprocessor

Also called: SDF Script Compiler, loadTxtFragFile

## Overview
The Script-to-Shader SDF Preprocessor is a C++ function that parses a custom script language to generate GLSL code for SDF scene composition, including loops, boolean operations, materials, and lights [S1, unofficial]. It solves the problem of manually writing verbose GLSL for complex implicit surfaces by translating a simplified script into shader source code, operating at the text-generation level rather than producing volumetric texture data like sibling methods [S1, unofficial].

## How it works
**Inputs and Outputs:**
*   **Input:** A dummy FRAG shader string (`realCode`) containing placeholders, and a custom script string (`psCode`) defining scene geometry and logic [S1, unofficial].
*   **Output:** The modified `realCode` string containing the complete GLSL fragment shader [S1, unofficial].

**Data Structures:**
The method uses string indices, parsed parameters, and lambda functions within a C++ context [S1, unofficial].

**Numbered Steps:**
1.  **Load Files:** Read the dummy FRAG shader into `realCode` and the custom script into `psCode` [S1, unofficial].
2.  **Environment Setup (`setUpEnv`):** Define a lambda `setUpEnv(envName)` that finds `!(envName)` in `realCode`, scans `psCode` for `#envName`, extracts content between `{` and `}`, inserts it into `realCode`, and updates `!(lightCnt)` if `envName` is `"light"` [S1, unofficial].
3.  **Initialize Environments:** Call `setUpEnv("material")` and `setUpEnv("light")` [S1, unofficial].
4.  **Identify Insertion Point:** Find `!(sceneSDF)` in `realCode` as the insertion point [S1, unofficial].
5.  **Function Parser (`findFunc`):** Define a lambda `findFunc` that parses `#` markers, handles `opU` (union), `opS`/`opI` (subtract/intersect), and `opUs` (smooth union with parameter `k`), converting script syntax to GLSL function calls [S1, unofficial].
6.  **Main Loop:** Scan `psCode` for `@i`, `#`, and `!` markers [S1, unofficial]. Handle `@i` as `for` loop generation, `#` as function definition, and `!` as direct line insertion [S1, unofficial].
7.  **Injection:** Insert the generated code at the `sceneR` position in `realCode` [S1, unofficial].
8.  **Return:** Return the modified `realCode` string [S1, unofficial].

**Formulas:**
*   **Smooth Union:** The smooth union of two SDFs $a$ and $b$ with smoothness parameter $k$ is calculated as [S1, unofficial]:
    $$ f = \min(a, b) - k \cdot \max(0, \min(a, b)) $$

**Parameters:**
*   `k`: Smoothness parameter for `opUs`, parsed via `sscanf(..., "#k%f", &k)` [S1, unofficial].
*   `prefix`: Directory prefix for shader files, formatted as `shaders/%s/%s.glsl` [S1, unofficial].

**Pitfalls and Edge Cases:**
*   **Syntax Conflict:** The script parser uses fixed string markers (`@i`, `#`, `!`) which can conflict with standard GLSL syntax if not carefully escaped or structured [S1, unofficial].
*   **Marker Assumptions:** The `findSubFunc` lambda assumes specific marker formats (`m` for matrix, `v` for vector) in the script arguments and may break if the script deviates [S1, unofficial].
*   **Placeholder Dependency:** The method relies entirely on the presence of specific placeholders (`!(envName)`, `!(sceneSDF)`) in the dummy GLSL file [S1, unofficial].

**Pseudocode:**
```python
def preprocess_sdf(real_code: str, ps_code: str) -> str:
    """
    Parses a custom SDF script and injects generated GLSL into a dummy shader.
    """
    light_cnt = 0
    
    # Step 2: Environment Setup Lambda
    def set_up_env(env_name: str):
        nonlocal light_cnt
        placeholder = f"!( {env_name} )"
        if placeholder not in real_code:
            return
        marker = f"#{env_name}"
        start_idx = ps_code.find(marker)
        if start_idx == -1:
            return
        brace_start = ps_code.find('{', start_idx)
        brace_end = ps_code.find('}', brace_start)
        if brace_start == -1 or brace_end == -1:
            return
        content = ps_code[brace_start+1 : brace_end]
        real_code = real_code.replace(placeholder, content)
        if env_name == "light":
            light_cnt += 1

    # Step 3: Initialize Environments
    set_up_env("material")
    set_up_env("light")
    
    # Step 4: Identify Insertion Point
    scene_sdf_marker = "!(sceneSDF)"
    if scene_sdf_marker not in real_code:
        raise ValueError("!(sceneSDF) not found in real_code")
    
    generated_code = ""
    i = 0
    
    # Step 5 & 6: Main Loop and Function Parser
    while i < len(ps_code):
        # Handle @i marker for loop generation
        if ps_code[i:i+2] == '@i':
            generated_code += "for (int i = 0; i < 10; i++) {\n" # Loop body generation [G]
            i += 2
            continue
        # Handle # marker for function definitions/operations
        elif ps_code[i] == '#':
            if ps_code[i:].startswith("#opU"):
                # Union: opU(mint, vec2(fSDF(arg1), mtlNo))
                arg_start = i + 4
                arg_end = ps_code.find(' ', arg_start) if ' ' in ps_code[arg_start:] else len(ps_code)
                arg1 = ps_code[arg_start:arg_end]
                generated_code += f"opU(mint, vec2(fSDF({arg1}), 0));\n"
                i = arg_end
            elif ps_code[i:].startswith("#opS") or ps_code[i:].startswith("#opI"):
                # Subtract/Intersect: opU(mint, arg1(vec2(fSDF(arg2), mtlNo)), vec2(fSDF(arg3), mtlNo))
                arg1 = ps_code[i+4 : ps_code.find(' ', i+4)]
                arg2 = ps_code[ps_code.find(' ', i+4)+1 : ps_code.find(' ', ps_code.find(' ', i+4)+1)]
                arg3 = ps_code[ps_code.find(' ', ps_code.find(' ', i+4)+1)+1 : len(ps_code)]
                generated_code += f"opU(mint, {arg1}(vec2(fSDF({arg2}), 0)), vec2(fSDF({arg3}), 0));\n"
                i = len(ps_code)
            elif ps_code[i:].startswith("#opUs"):
                # Smooth Union with k parameter
                k = 0.1 # Default smoothness [G]
                k_match = ps_code.find("#k", i+6)
                if k_match != -1:
                    k = float(ps_code[k_match+2 : k_match+6])
                arg1 = ps_code[i+6 : ps_code.find(' ', i+6)]
                arg2 = ps_code[ps_code.find(' ', i+6)+1 : len(ps_code)]
                generated_code += f"min({arg1}, {arg2}) - {k} * max(0.0, min({arg1}, {arg2}));\n"
                i = len(ps_code)
            else:
                # Generic function definition
                generated_code += ps_code[i+1 : ps_code.find('\n', i)] + "\n"
                i += 1
        # Handle ! marker for direct line insertion
        elif ps_code[i] == '!':
            end = ps_code.find('\n', i)
            if end == -1:
                generated_code += ps_code[i+1:]
                i = len(ps_code)
            else:
                generated_code += ps_code[i+1:end] + "\n"
                i = end
        else:
            i += 1
            
    # Step 7: Injection at sceneR position (anchored to sceneSDF marker)
    scene_r_pos = real_code.find(scene_sdf_marker)
    final_code = real_code[:scene_r_pos] + generated_code + real_code[scene_r_pos + len(scene_sdf_marker):]
    
    # Step 8: Return
    return final_code
```
