# NeUDF

Also called: Neural Unsigned Distance Fields, NeUDF*

## Overview
NeUDF is a neural rendering framework that reconstructs surfaces with arbitrary topologies, including open surfaces, from multi-view 2D image supervision by leveraging the Unsigned Distance Function (UDF) as the implicit surface representation [S1]. Unlike its sibling [Volume SDF Rendering](1344-volume-sdf-rendering.md), which is limited to closed (watertight) surfaces, NeUDF resolves the ambiguity of surface orientation in open structures by introducing a specialized "Udensity" probability density function and a normal regularization strategy [S1]. It differs from naive extensions of SDF-based rendering by avoiding spurious surfaces in void regions through an unbiased, occlusion-aware weighting paradigm tailored for UDFs [S1].

## How it works
**Inputs and Outputs:**
*   **Inputs:** A set of multi-view 2D images $\{I_k\}$ with known camera parameters (origin $o$, view direction $v$) [S1].
*   **Outputs:** A neural network $\psi$ that predicts the unsigned distance $d$ and color $c$ for any spatial location $x$ along a ray, and the reconstructed surface $\mathcal{S}_{\mathcal{O}}$ defined by the zero-level set of $d$ [S1].

**Data Structures:**
*   **Neural Network $\psi$:** A differentiable network (e.g., MLP) that maps ray direction and spatial location to UDF and color [S1].
    *   **Input:** View direction $v \in \mathbb{S}^2$ and spatial location $x \in \mathbb{R}^3$ [S1].
    *   **Output:** Unsigned distance $d \in \mathbb{R}^+$ and color $c \in [0, 1]^3$ [S1].
    *   **Signature:** $(d, c) = \psi(v, x) : \mathbb{S}^2 \times \mathbb{R}^3 \mapsto (\mathbb{R}^+, [0, 1]^3)$ [S1].
*   **Udensity Function $\varsigma_r(\cdot)$:** A cumulative distribution function (CDF) parameterized by a learnable scalar $r$ that maps the UDF value $d$ to a probability mass [S1].
    *   **Constraints:**
        1.  $\varsigma_r(0) = 0$ [S1].
        2.  $\lim_{d \rightarrow +\infty} \varsigma_r(d) = 1$ [S1].
        3.  First derivative $\varsigma_r'(d) > 0$ for $d > 0$ [S1].
        4.  Second derivative $\varsigma_r''(d) < 0$ for $d > 0$ (concave) [S1].
    *   **Implementation Note:** The exact functional form is not specified in the source, but a valid implementation must satisfy the boundary and convexity conditions [S1]. A standard choice satisfying these constraints is $\varsigma_r(d) = 1 - e^{-rd}$ [G].

**Numbered Steps:**

1.  **Ray Sampling:** For each pixel, cast a ray from camera origin $o$ with direction $v$. Sample points $p(t)$ along the ray at parameter $t \in [0, +\infty)$ [S1].
2.  **Network Query:** For each sample point $p(t)$, query the neural network $\psi$ using the ray direction $v$ and position $p(t)$ to obtain the unsigned distance $d = \Psi(p(t))$ and color $c$ [S1]. The predicted surface is defined as $\mathcal{S}_{\mathcal{O}} = \{x \in \mathbb{R}^3 | d = 0, (d, c) = \psi(v, x)\}$ [S1].
3.  **Udensity Calculation:** Compute the opaque density $\tau_r(t)$ using the Udensity function $\varsigma_r$ and the chain rule for the derivative along the ray [S1]:
    $$ \tau_r(t) = \left| \frac{\frac{\partial(\varsigma_r \circ \Psi \circ p)}{\partial t}(t)}{\varsigma_r \circ \Psi \circ p(t)} \right| $$
    Here, $\circ$ denotes function composition. The term $\varsigma_r \circ \Psi \circ p(t)$ represents $\varsigma_r(d(t))$ [S1]. By the chain rule, the numerator expands to $\varsigma_r'(d(t)) \cdot \frac{dd}{dt}$ [G].
4.  **Weight Calculation:** Compute the rendering weight $w_r(t)$ using the standard volume rendering accumulation formula with the opaque density $\tau_r(t)$ [S1]:
    $$ w_r(t) = \tau_r(t) e^{-\int_0^t \tau_r(u) du} $$
    This weight function is unbiased and occlusion-aware [S1].
5.  **Color Integration:** Integrate the color along the ray to produce the final pixel color $C(o, v)$ [S1]:
    $$ C(o, v) = \int_0^{+\infty} w_r(t) c(p(t), v) dt $$
6.  **Optimization:** Minimize the distance between the rendered images $I'_k$ and ground-truth images $I_k$ [S1].
7.  **Normal Regularization:** To resolve surface orientation ambiguity inherent in UDFs (where in/out tests are invalid for open surfaces), apply a normal regularization strategy [S1]. This enhances gradient consistency by leveraging normal information in the surface neighborhood [S1].
8.  **Importance Sampling:** Use a customized importance sampling strategy to accommodate the proposed weighting function $w_r(t)$ and ensure high-quality reconstruction of non-watertight surfaces [S1].

import numpy as np

def udensity_cdf(d, r):
    """Computes Udensity CDF value. Satisfies cdf(0)=0, cdf(inf)=1, cdf'>0, cdf''<0 [S1]."""
    return 1.0 - np.exp(-r * d)

def udensity_pdf(d, r):
    """Computes Udensity PDF (derivative of CDF) [S1]."""
    return r * np.exp(-r * d)

def render_neudf(ray_origin, ray_direction, network, t_min, t_max, num_samples, r):
    """Renders a single ray using NeUDF [S1]."""
    # Sample points along the ray [S1]
    t_values = np.linspace(t_min, t_max, num_samples)
    dt = t_values[1] - t_values[0]
    positions = ray_origin + t_values[:, np.newaxis] * ray_direction
    
    # Query network for d and c [S1]
    d_values, color_values = network(ray_direction, positions)
    
    # Compute Udensity CDF and PDF values [S1]
    cdf_values = udensity_cdf(d_values, r)
    pdf_values = udensity_pdf(d_values, r)
    
    # Handle division by zero at d=0 where cdf=0 [G]
    epsilon = 1e-8
    cdf_safe = np.maximum(cdf_values, epsilon)
    
    # Compute derivative of d along ray: d'(t) [G]
    d_dot = np.gradient(d_values, dt)
    
    # Compute opaque density tau_r(t) = | (d/dt varsigma_r(d(t))) / varsigma_r(d(t)) | [S1]
    # d/dt varsigma_r(d(t)) = pdf(d(t)) * d_dot(t)
    numerator = pdf_values * d_dot
    tau = np.abs(numerator / cdf_safe)
    
    # Compute transmittance T(t) = exp(- integral_0^t tau(u) du) [S1]
    tau_integral = np.cumsum(tau) * dt
    transmittance = np.exp(-tau_integral)
    
    # Compute weights w(t) = tau(t) * T(t) [S1]
    weights = tau * transmittance
    
    # Render color C = int w(t) c(t) dt [S1]
    rendered_color = np.sum(weights[:, np.newaxis] * color_values, axis=0) * dt
    return rendered_color

**Parameters:**
*   $r$: Learnable parameter in the Udensity function $\varsigma_r(d)$ controlling the density distribution [S1].
*   $\epsilon$: Small threshold for defining the surface $\mathcal{S}_{\mathcal{O}}$ (mentioned in definition of $UDF_O$) [S1].

**Edge Cases and Pitfalls:**
*   **Spurious Surfaces:** Naively extending SDF-based weighting to UDF generates spurious surfaces because the SDF-based weighting function triggers undesirable local maxima in the void region [S1]. NeUDF avoids this via the Udensity formulation [S1].
*   **Open Surfaces:** Standard in/out tests are invalid for open surfaces. NeUDF resolves this ambiguity using normal regularization [S1].
*   **Boundary Conditions:** The Udensity function must satisfy $\varsigma_r(0)=0$ and $\lim_{d \to \infty} \varsigma_r(d)=1$. Failure to satisfy these leads to incorrect density accumulation [S1].

## Operating characteristics
*   **Time Complexity:** Depends on the number of samples per ray and the depth of the neural network $\psi$ [G]. The integration requires evaluating the Udensity function and its derivative for each sample [S1].
*   **Memory Complexity:** Dominated by the storage of the neural network parameters [G].
*   **Strengths:** Capable of reconstructing surfaces with arbitrary topologies, including open surfaces, which SDF-based methods cannot handle [S1]. Outperforms state-of-the-art methods on challenging datasets like DTU, MGN, and Deep Fashion 3D [S1].
*   **Limitations:** Requires multi-view 2D image supervision. The naive extension of SDF methods fails, necessitating the complex Udensity formulation [S1].
*   **When to use:** When reconstructing non-watertight or open-surface objects from multi-view images [S1].
*   **When not to use:** When only closed surfaces are expected and SDF-based methods (like [Volume SDF Rendering](1344-volume-sdf-rendering.md)) are sufficient, as they may be simpler [G].

## Background
NeUDF was introduced in the paper "NeUDF: Leaning Neural Unsigned Distance Fields with Volume Rendering" [S1]. It is the first attempt to reconstruct surfaces with arbitrary topologies solely from 2D image supervision [S1]. The method was evaluated on public datasets including DTU [21], MGN [5], Deep Fashion 3D [61], and BMVS [56] [S1]. It builds upon the differentiable volume rendering framework inspired by NeuS [53] [S1].
