# VolSDF Volume Rendering

Also called: VolumeSDFRenderer

## Overview
VolSDF Volume Rendering synthesizes images from a neural implicit surface representation by converting Signed Distance Function (SDF) values into volumetric density [G]. It solves the problem of rendering continuous 3D surfaces without explicit mesh extraction by treating the zero-level set of the SDF as a volumetric boundary [G]. It sets itself apart from its parent [SDF to Density Conversion](1282-sdf-to-density-conversion.md) by providing the complete rendering pipeline (sampling, transmittance, aggregation) rather than just the conversion function, and from its sibling [Volume SDF Rendering](1344-volume-sdf-rendering.md) by using a differentiable neural SDF with stratified sampling and alpha-compositing rather than discrete voxel rasterization [S1, unofficial][S2, unofficial].

## How it works
**Inputs:**
- `ray_bundle`: Contains sample points along rays (`sample_points`, shape $N \times \text{ppr} \times 3$) and sample lengths (`sample_lengths`, shape $N \times \text{ppr} \times 1$) [S1, unofficial].
- `implicit_fn`: A neural network or function capable of returning the signed distance and color at a given 3D point [S1, unofficial].
- `alpha`, `beta`: Parameters for the SDF-to-density conversion function [S1, unofficial].
- `white_background`: Boolean flag determining if the background is white (1.0) or black (0.0) [S1, unofficial].

**Outputs:**
- `final_color`: Rendered image with shape $(N, 3)$ [S1, unofficial].

**Data Structures:**
- `density`: Tensor of shape $(N, \text{ppr}, 1)$ representing volumetric density at each sample point [S1, unofficial].
- `color`: Tensor of shape $(N, \text{ppr}, 3)$ representing the color at each sample point [S1, unofficial].
- `deltas`: Tensor of shape $(N, \text{ppr}, 1)$ representing the distance between adjacent sample points [S1, unofficial].
- `T`: Tensor of shape $(N, \text{ppr}, 1)$ representing transmittance [S1, unofficial].
- `W`: Tensor of shape $(N, \text{ppr}, 1)$ representing the rendering weight for each sample [S1, unofficial].

**Steps:**
1. **Sampling:** Get the number of points per ray (`ppr`) from the sampler [S1, unofficial]. Sample points along the rays using a stratified sampler (e.g., `StratifiedRaysampler`) to obtain `ray_bundle.sample_points` and `ray_bundle.sample_lengths` [S1, unofficial].
2. **Implicit Query:** Query the implicit surface function for distance and color at all sample points:
   $$ \text{distance}, \text{color} = \text{implicit\_fn.get\_distance\_color}(\text{ray\_bundle.sample\_points}) $$
   Shapes are $(N \times \text{ppr}, 1)$ and $(N \times \text{ppr}, 3)$ respectively [S1, unofficial].
3. **SDF to Density Conversion:** Convert the signed distance values to density using the parent method [SDF to Density Conversion](1282-sdf-to-density-conversion.md):
   $$ \text{density} = \text{sdf\_to\_density}(\text{distance}, \alpha, \beta) $$
   Reshape density to $(N, \text{ppr}, 1)$ [S1, unofficial].
4. **Delta Calculation:** Extract the depth from `ray_bundle.sample_lengths[..., 0]` [S1, unofficial]. Compute the distances between adjacent samples (`deltas`) using `get_deltas_from_depth(depth)` [S1, unofficial]. Shape is $(N, \text{ppr}, 1)$.
5. **Transmittance Calculation:** Compute transmittance $T$ from `deltas` and `density` [S1, unofficial]. The transmittance represents the probability of light passing through the volume up to a certain point [G].
   $$ T_i = \exp\left(-\sum_{j=1}^{i-1} \text{density}_j \cdot \text{deltas}_j\right) $$
   Shape is $(N, \text{ppr}, 1)$ [S1, unofficial].
6. **Weight Calculation:** Compute the weight $W$ for each sample, which determines its contribution to the final color [S1, unofficial]. A small epsilon ($10^{-10}$) is added for numerical stability [S1, unofficial].
   $$ W_i = T_i \times (1.0 - \exp(-\text{density}_i \times \text{deltas}_i + 10^{-10})) $$
   Shape is $(N, \text{ppr}, 1)$ [S1, unofficial].
7. **Color Aggregation:** Reshape the queried color to $(N, \text{ppr}, \text{color\_channels})$ [S1, unofficial]. Aggregate the color using the weights:
   $$ \text{final\_color} = \sum_{i=1}^{\text{ppr}} W_i \times \text{color}_i $$
   If `white_background` is true, add the remaining transmittance multiplied by the background color (1.0) to the final color:
   $$ \text{final\_color} = \text{final\_color} + T_{\text{last}} \times \text{background\_color} $$
   Result shape is $(N, 3)$ [S1, unofficial].

**Pseudocode:**
```python
import math

def volsdf_render(ray_bundle, implicit_fn, alpha, beta, white_background=False):
    # ray_bundle.sample_points: shape (N, ppr, 3)
    # ray_bundle.sample_lengths: shape (N, ppr, 1)
    N = len(ray_bundle.sample_points)
    ppr = len(ray_bundle.sample_points[0])
    final_color = [[0.0, 0.0, 0.0] for _ in range(N)]

    for n in range(N):
        # 1. Implicit Query
        distances = []
        colors = []
        for i in range(ppr):
            d, c = implicit_fn.get_distance_color(ray_bundle.sample_points[n][i])
            distances.append(d)
            colors.append(c)

        # 2. SDF to Density Conversion [G]
        densities = sdf_to_density(distances, alpha, beta)

        # 3. Delta Calculation
        depths = [ray_bundle.sample_lengths[n][i][0] for i in range(ppr)]
        deltas = get_deltas_from_depth(depths)

        # 4. Transmittance Calculation
        T = compute_transmittance(deltas, densities)

        # 5. Weight Calculation
        weights = compute_weights(T, densities, deltas)

        # 6. Color Aggregation
        acc_color = [0.0, 0.0, 0.0]
        for i in range(ppr):
            for k in range(3):
                acc_color[k] += weights[i] * colors[i][k]
        final_color[n] = acc_color

        # 7. Background
        if white_background:
            T_last = T[-1] if T else 0.0
            for k in range(3):
                final_color[n][k] += T_last * 1.0

    return final_color

def sdf_to_density(distances, alpha, beta):
    # Standard VolSDF mapping: sigma = alpha * phi_beta(f) [G]
    return [alpha * (1.0 - math.exp(-beta * abs(d))) for d in distances]

def get_deltas_from_depth(depths):
    deltas = [depths[0]]
    for i in range(1, len(depths)):
        deltas.append(depths[i] - depths[i-1])
    return deltas

def compute_transmittance(deltas, densities):
    T = [1.0]
    optical_depth = 0.0
    for i in range(1, len(deltas)):
        optical_depth += densities[i-1] * deltas[i-1]
        T.append(math.exp(-optical_depth))
    return T

def compute_weights(T, densities, deltas):
    weights = []
    for i in range(len(T)):
        alpha_val = 1.0 - math.exp(-(densities[i] * deltas[i] + 1e-10))
        weights.append(T[i] * alpha_val)
    return weights
```

**Parameters:**
- `alpha`: Parameter for SDF-to-density conversion. Typical value from `cfg.alpha` [S1, unofficial].
- `beta`: Parameter for SDF-to-density conversion. Typical value from `cfg.beta` [S1, unofficial].
- `white_background`: Boolean flag for background color. Default `False` [S1, unofficial].

**Edge Cases and Pitfalls:**
- **Precision:** A small epsilon ($10^{-10}$) is added to the exponent in the weight calculation to prevent numerical instability when density or delta is zero [S1, unofficial].
- **Boundaries:** The transmittance calculation assumes the ray starts outside the volume or handles the initial segment correctly [G]. If `sample_lengths` represents intervals, `deltas` must be computed carefully to avoid zero-length intervals causing division by zero or NaNs in other contexts (though here it is used in an exponent) [G].
- **Degenerate Input:** If `implicit_fn` returns NaNs or Infs, the rendering will fail [G]. Input validation or clamping may be required in practice [G].

## Subtopics

### [NeuS Weight Function](3238-neus-weight-function.md)
The NeuS weight function derives an unbiased, occlusion-aware weight from an SDF to reconstruct surfaces from multi-view images without explicit 3D supervision. It sets itself apart from its siblings by explicitly deriving an opaque density that peaks at the zero-level set, and is chosen when unbiased surface reconstruction from signed distances is required.

### [U-density Function](3695-u-density-function.md)
The U-density function is a rendering weight function designed for Unsigned Distance Fields (UDF) to ensure globally unbiased volume rendering. It sets itself apart from its siblings by concentrating rendering weight near the first surface intersection to prevent weight leakage to invisible surfaces, and is chosen when rendering unsigned distance fields without floating artifacts.

### SDF-based Voxel Rendering
SDF-based Voxel Rendering determines voxel visibility by evaluating a Signed Distance Function (SDF) at each voxel center; draws voxel if SDF <= 0 [S2, unofficial].
**Steps:**
1. Evaluate SDF for given shape at point $p$ [S2, unofficial].
2. If SDF result $\le 0.0f$, call `voxie_drawvox(vf, p.x, p.y, p.z, 0x00ff00);` [S2, unofficial].
**Formula:**
Voxel emission condition: $SDF(p) \le 0$ [S2, unofficial].

### Adaptive Surfaceness Finetuning
Adaptive Surfaceness Finetuning is a method to improve SDF correctness by spatially adapting the $\beta$ parameter in the SDF-to-density conversion [S3].
**Steps:**
1. Collect per-sample triplets $(\mathbf{x}, \eta, w)$ rendered during the finetuning process [S3].
2. Accumulate these triplets over multiple training iterations (5,000) [S3].
3. Partition the accumulated triplets across the voxels of the surfaceness grid [S3]. Let $\Lambda_v$ be the subset associated with voxel $v$ corresponding to $\beta_v$ [S3].
4. Increase $\beta_v$ by a fixed increment (100) if the weighted average Eikonal loss for samples in voxel $v$ is below threshold $\bar{\gamma}$ [S3].
**Formula:**
Increase $\beta_v$ if:
$$ \frac{\sum_{(\mathbf{x}, \boldsymbol{\eta}, w) \in \Lambda_{v}} w \eta (\|\nabla f(\mathbf{x})\| - 1)^2}{\sum_{(\dots, w) \in \Lambda_{v}} w} < \bar{\gamma} $$
[S3]
**Parameters:**
- $\bar{\gamma} = 0.25$ is the predefined threshold for increasing surfaceness [S3].
- The fixed increment for $\beta_v$ is 100 [S3].
**Pitfall:**
Directly optimizing $\beta(\mathbf{x})$ via gradient descent overly relaxes the SDF correctness constraint, causing $f(\mathbf{x})$ to predict arbitrary density values like original NeRF [S3]. Instead, Eikonal loss is used as an indicator to only increase surfaceness where the model fails to reconstruct via SDF [S3].

## Operating characteristics
- **Time Complexity:** Linear with respect to the number of rays $N$ and points per ray $\text{ppr}$ [G]. The dominant cost is the neural network inference for `implicit_fn` and the accumulation of transmittance/weights [G].
- **Memory Complexity:** Linear with respect to $N \times \text{ppr}$ for storing distances, colors, densities, and transmittance [G].
- **Measured Performance:** Not given in the sources [G].
- **Scaling:** Scales with batch size $N$ and sampling density $\text{ppr}$ [G]. Higher $\text{ppr}$ improves quality but increases memory and compute [G].
- **Strengths:** Differentiable, supports gradient-based optimization for training implicit surfaces, handles complex geometries via neural SDFs [G].
- **Limitations:** Computationally expensive due to neural network queries per sample [G]. Sensitive to $\alpha$ and $\beta$ parameters [G].
- **When to use:** When training neural implicit surfaces from multi-view images and needing differentiable rendering [G].
- **When not to use:** When real-time rendering of static meshes is required, or when memory is severely constrained [G].

## Background
VolSDF Volume Rendering builds on the principles of VolSDF, which uses SDFs for volume rendering [S1, unofficial]. The method is also related to HybridNeRF, which introduces adaptive surfaceness finetuning [S3]. SDF-based voxel rendering is a simpler, non-differentiable approach demonstrated in holographic_fractals [S2, unofficial].
