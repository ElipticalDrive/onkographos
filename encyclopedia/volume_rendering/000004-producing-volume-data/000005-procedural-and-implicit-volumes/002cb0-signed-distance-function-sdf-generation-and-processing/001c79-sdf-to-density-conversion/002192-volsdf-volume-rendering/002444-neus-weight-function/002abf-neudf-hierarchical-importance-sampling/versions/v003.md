# NeUDF Hierarchical Importance Sampling

Also called: NeUDF sampling, ws(t)

## Overview
NeUDF Hierarchical Importance Sampling is a two-stage ray sampling strategy for Unsigned Distance Function (UDF) volume rendering that balances surface reconstruction accuracy with Eikonal loss regularization [S1]. Unlike [Naive UDF Solution (NeuS-based)](6015-naive-udf-solution-neus-based.md) which relies on uniform or simple heuristic sampling, this method hierarchically refines point distribution by first establishing a baseline and then concentrating samples where the UDF value indicates proximity to the surface, ensuring well-balanced gradients on both sides of the implicit surface [S1].

## How it works
**Inputs and Outputs:**
*   **Input:** A ray defined by origin $\mathbf{o}$ and direction $\mathbf{d}$; a UDF network $f(\mathbf{x})$; a transformation function $\Psi$; a monotonic density function $\zeta_s$; a position mapping $p(t)$; and the number of initial samples $N_{init}=64$ and importance samples $N_{imp}=64$ [S1].
*   **Output:** A set of 128 sample points $\{t_i\}_{i=0}^{127}$ along the ray and their corresponding normalized sampling weights $\{w_s''(t_i)\}$ [S1].

**Data Structures:**
*   **Sample Points:** An array of 128 floating-point distances $t$ along the ray.
*   **Weights:** An array of 128 floating-point values representing the normalized importance weights.

**Steps:**

1.  **Uniform Initialization:** Sample $N_{init}=64$ points uniformly along the ray within the bounding volume (typically the unit sphere or masked region) [S1]. Let these points be $t_0, \dots, t_{63}$ [S1].
2.  **Density Calculation:** For each sample point $t_i$, compute the UDF value $d_i = f(p(t_i))$ [S1]. Apply the transformation $\Psi$ to $d_i$ to get $\Psi(d_i)$ [S1]. Then, compute the view-invariant sampling density $\tau_s(t_i)$ using the monotonically decreasing function $\zeta_s$:
    $$ \tau_s(t_i) = \zeta_s(\Psi(d_i)) $$
    The function $\zeta_s$ must satisfy $\zeta_s(d) > 0$ and $\zeta'_s(d) < 0$ for all $d > 0$, ensuring higher density for smaller UDF values (closer to surface) [S1].
3.  **Base Weight Computation:** Compute the unnormalized sampling weight $w_s(t_i)$ for each point using the volume rendering accumulation formula:
    $$ w_s(t_i) = \tau_s(t_i) e^{-\int_0^{t_i} \tau_s(s) ds} $$
    In practice, the integral is approximated by the sum of densities of previous points multiplied by the step size [S1].
4.  **Neighbor Maximization:** Modify the weights to prevent local minima from suppressing valid samples. For each $i$, compute the modified weight $w'_s(t_i)$:
    $$ w'_s(t_i) = \max\{w_s(t_{i+k}) \mid k \in \{-1, 0, 1\}\} $$
    This takes the maximum of the current weight and its immediate neighbors [S1].
5.  **Normalization:** Normalize the modified weights so they sum to one:
    $$ w_s''(t_i) = \frac{w'_s(t_i)}{\sum_{j=0}^{N_{init}-1} w'_s(t_j)} $$
    This yields the importance sampling distribution for the second stage [S1].
6.  **Importance Sampling:** Perform importance sampling using the distribution $w_s''(t_i)$ to select $N_{imp}=64$ new points. These points are added to the initial 64, resulting in a total of 128 points per ray [S1].
7.  **Boundary Handling:** If no masks are provided, randomly sample 32 additional points outside the unit sphere to represent the background scene, bringing the total to 160 points. These background points are handled using a NeRF++ representation [S1].

**Pseudocode:**

```python
def neudf_hierarchical_sampling(ray_origin, ray_direction, udf_net, psi_func, zeta_s_func, num_init=64, num_imp=64):
    # Step 1: Uniform sampling
    t_uniform = sample_uniform(ray_origin, ray_direction, num_init)
    
    # Step 2 & 3: Compute density and base weights
    densities = []
    for t in t_uniform:
        pos = ray_origin + t * ray_direction
        udf_val = udf_net(pos)
        transformed = psi_func(udf_val)
        tau = zeta_s_func(transformed)
        densities.append(tau)
        
    # Compute unnormalized weights w_s(t)
    # Approximating integral: exp(-sum(tau_prev * dt))
    weights_s = []
    cum_sum = 0.0
    for i, tau in enumerate(densities):
        if i > 0:
            dt = t_uniform[i] - t_uniform[i-1]
            cum_sum += tau * dt
        w_s = tau * math.exp(-cum_sum)
        weights_s.append(w_s)
        
    # Step 4: Neighbor maximization
    weights_prime = []
    for i in range(num_init):
        max_w = weights_s[i]
        if i > 0:
            max_w = max(max_w, weights_s[i-1])
        if i < num_init - 1:
            max_w = max(max_w, weights_s[i+1])
        weights_prime.append(max_w)
        
    # Step 5: Normalization
    sum_weights = sum(weights_prime)
    weights_norm = [w / sum_weights for w in weights_prime]
    
    # Step 6: Importance sampling for additional points
    t_imp = sample_importance(weights_norm, t_uniform, num_imp)
    
    # Combine points
    all_t = t_uniform + t_imp
    
    # Step 7: Boundary handling (if no mask)
    if no_mask_provided:
        t_bg = sample_random_outside_sphere(32)
        all_t = all_t + t_bg
        
    return all_t
```

**Parameters:**
*   `num_init`: 64 (initial uniform samples) [S1].
*   `num_imp`: 64 (importance samples) [S1].
*   `zeta_s`: Monotonically decreasing function with $\zeta_s(d) > 0$ and $\zeta'_s(d) < 0$ [S1].
*   `Psi`: Transformation function applied to UDF values [S1].

**Edge Cases:**
*   **No Mask:** Requires 32 extra random samples outside the unit sphere for background representation [S1].
*   **Degenerate UDF:** The condition $\zeta'_s(d) < 0$ ensures density remains positive and decreases with distance, preventing singularities at large distances [S1].

## Subtopics

### [Importance Points Sampling](5914-importance-points-sampling.md)
Provides the specific mathematical formulation for the sampling density $\tau_s(t)$ used in the second stage of the hierarchy. It sets itself apart by distributing weights *before* intersection points to balance Eikonal loss gradients, unlike the parent method which focuses on the hierarchical refinement structure itself.

## Operating characteristics
*   **Complexity:** $O(N)$ per ray where $N=128$ (or 160 with background). The importance sampling step requires sorting or cumulative sum computation, adding a constant factor overhead to the uniform sampling.
*   **Performance:** The two-stage approach (64 + 64) provides a balance between computational cost and sampling quality. The neighbor maximization step is negligible in cost but crucial for stability [S1].
*   **Strengths:** Improves UDF quality by preventing unbalanced gradient magnitudes on either side of the surface, which is a common issue in UDF rendering [S1]. View-invariant density reduces sensitivity to camera position [S1].
*   **Limitations:** Requires careful tuning of $\zeta_s$ and $\Psi$. The background handling relies on NeRF++, adding complexity if background modeling is not needed [S1].

## Background
NeUDF Hierarchical Importance Sampling was introduced in the NeUDF paper (2023) to address the challenges of training Unsigned Distance Fields with volume rendering [S1]. It builds on the NeuS weight function [3238-neus-weight-function.md] but adapts it for UDFs, where the distance is unsigned, requiring specific handling of the Eikonal loss regularization [S1].
