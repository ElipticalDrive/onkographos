# Terrain Skinning via Perturbation Function

Also called: Base Surface + Altitude Map, Freeform Surface Terrain Representation

## Overview
Terrain Skinning via Perturbation Function represents terrain as a scalar field defined by a base surface $P$ and a 2D altitude map (perturbation function) $h$. It solves the problem of defining complex terrain geometry within a volume rendering pipeline by decoupling the global shape from local details. Unlike [Terrain Generation via Noise](2412-terrain-generation-via-noise.md) which generates height directly, or [Smooth Terrain Grid](5026-smooth-terrain-grid.md) which modifies vertex positions on a fixed grid, this method projects points onto a simple base surface (plane, ellipsoid, cylinder) and displaces them along the surface normal using interpolated values from a discrete table [S1].

## How it works

### Inputs and Outputs
*   **Inputs**:
    *   Base surface $P$: A simple surface defined in 3D space (e.g., plane, ellipsoid, cylinder) [S1].
    *   Perturbation domain $D_P$: A 2D rectangular domain in the coordinate system of the base surface [S1].
    *   Altitude map (table): A 2D grid of scalar values representing height deviations [S1].
    *   Transformation $G$: A mapping from 3D space to the 2D map coordinate system, typically a parallel projection [S1].
*   **Outputs**:
    *   A 3D surface $F$ defined by the vector equation for any point $v \in \mathbb{R}^3$ [S1].

### Data Structures
*   **Table**: A 2D array of floating-point numbers. Let the table dimensions be $W \times H$. The element at integer indices $(m_u, m_v)$ is denoted `table[m_u][m_v]` [S1].
*   **Base Surface Normal**: For a given point $v$, the normal vector $n$ to the base surface $P$ at the projected location [S1].

### Steps
1.  **Define Base Surface**: Choose a simple surface $P$ (e.g., a plane for the Volcano Bandai example) [S1].
2.  **Define Transformation**: Establish the transformation $G: \mathbb{R}^3 \to \mathbb{R}^2$ from the 3D coordinate system to the 2D map coordinate system. This is usually a parallel projection directed opposite to the normal vector of the base surface [S1].
3.  **Store Altitude Map**: Populate a 2D table with altitude values over the perturbation domain $D_P$ [S1].
4.  **Project Point**: For a query point $d_F$ on the resulting surface $F$, calculate its projection $v = G(d_F)$ in the map coordinate system [S1].
5.  **Check Domain**: Determine if $v$ lies within the perturbation domain $D_P$.
    *   If $v \notin D_P$, the perturbation is zero. The point on the surface is simply the projection of $v$ back onto the base surface $P$.
    *   If $v \in D_P$, proceed to interpolation [S1].
6.  **Interpolate Height**: Calculate the altitude $h(u,v)$ at coordinates $(u,v)$ using bilinear interpolation of the table values [S1].
7.  **Compute Final Position**: Calculate the final position on the surface $F$ using the vector equation [S1]:
    $$ F = G(v) + n \cdot h(G(v)) $$
    where $n$ is the normal to the base surface at the projected point [S1].

### Formulas
The final surface position is given by [S1]:
$$ F(v) = G(v) + n \cdot h(G(v)) \quad \forall v \in \mathbb{R}^3 $$
If $v$ is outside the perturbation domain $D_P$, then $n \cdot h(G(v)) = 0$ [S1].

The perturbation function $h(u,v)$ is calculated via bilinear interpolation [S1]:
$$ h(u,v) = f_0 + (f_1 - f_0)(v - m_v) $$
where:
*   $m_u = \lfloor u \rfloor$ (integer part of $u$)
*   $m_v = \lfloor v \rfloor$ (integer part of $v$)
*   $f_0 = (1 - (u - m_u)) \cdot \text{table}[m_u][m_v] + (u - m_u) \cdot \text{table}[m_u+1][m_v]$
*   $f_1 = (1 - (u - m_u)) \cdot \text{table}[m_u][m_v+1] + (u - m_u) \cdot \text{table}[m_u+1][m_v+1]$

### Parameters
*   **Base Surface Type**: Simple surfaces such as planes, ellipsoids, or cylinders. In the cited example (Volcano Bandai), a plane is used [S1].
*   **Transformation**: Parallel projection [S1].

### Edge Cases and Pitfalls
*   **Out-of-Bounds**: If the vector $v$ is outside the perturbation domain $D_P$, the term $n \cdot h(G(v))$ becomes zero, and the surface $F$ coincides exactly with the base surface $P$ [S1].
*   **Precision**: The interpolation relies on the integer parts $m_u$ and $m_v$. Care must be taken with boundary conditions of the table to avoid index out-of-bounds errors when $u$ or $v$ are near the edges of $D_P$ [S1].

### Pseudocode

```python
def terrain_skinning(v, base_surface, normal_func, transformation, altitude_table, domain_bounds):
    """
    Computes the position on the terrain surface F for a given 3D point v.
    
    Args:
        v: 3D vector (float, float, float) - Query point in 3D space.
        base_surface: Object defining the base surface P.
        normal_func: Function that returns the normal vector n at a point on P.
        transformation: Function G that projects 3D point to 2D map coordinates.
        altitude_table: 2D list/array of floats representing the altitude map.
        domain_bounds: Tuple (min_u, max_u, min_v, max_v) defining the perturbation domain D_P.
        
    Returns:
        3D vector representing the point on the surface F.
    """
    
    # Step 4: Project point to 2D map coordinates
    u, v_coord = transformation(v)
    
    # Step 5: Check if point is within perturbation domain
    min_u, max_u, min_v, max_v = domain_bounds
    
    if not (min_u <= u <= max_u and min_v <= v_coord <= max_v):
        # Outside domain: perturbation is zero, return point on base surface
        # G(v) projects v back to the base surface geometry
        return transformation.inverse(v) # Or base_surface.project(v) depending on G definition
        
    # Step 6: Interpolate height h(u, v_coord)
    m_u = int(u)
    m_v = int(v_coord)
    
    # Handle boundary indices if necessary (clamp or wrap, not specified in source)
    # Assuming table is large enough or indices are valid
    u_frac = u - m_u
    v_frac = v_coord - m_v
    
    # Bilinear interpolation
    # f0: interpolation along u at row m_v
    val_00 = altitude_table[m_u][m_v]
    val_10 = altitude_table[m_u + 1][m_v]
    f0 = (1 - u_frac) * val_00 + u_frac * val_10
    
    # f1: interpolation along u at row m_v + 1
    val_01 = altitude_table[m_u][m_v + 1]
    val_11 = altitude_table[m_u + 1][m_v + 1]
    f1 = (1 - u_frac) * val_01 + u_frac * val_11
    
    h = f0 + (f1 - f0) * v_frac
    
    # Step 7: Calculate final position
    # G(v) is the projection of v onto the base surface. 
    # In the source, G maps 3D to 2D, but the formula uses G(v) as the base point.
    # The source states: "F = G(v) + n * h(G(v))". 
    # Context implies G(v) here refers to the point on the base surface corresponding to the projection.
    # Let's assume base_point is the point on P closest to v or projected by G.
    base_point = transformation.inverse(v) # Reversing the parallel projection to get point on P
    
    # Get normal at the base point
    n = normal_func(base_point)
    
    final_position = base_point + n * h
    
    return final_position
```

## Subtopics

### Terrain Generation via Noise
Generates terrain height using procedural noise functions directly, without a separate base surface projection. Use when local detail is more important than global geometric consistency with a base shape. [Link](2412-terrain-generation-via-noise.md)

### Procedural Terrain Feature Generation
Focuses on adding specific features (ridges, valleys) to terrain. Use when specific geological features are required rather than general skinning. [Link](2572-procedural-terrain-feature-generation.md)

### Smooth Terrain Grid
Modifies vertex positions on a fixed grid to smooth terrain. Use when working with explicit mesh representations rather than implicit scalar fields. [Link](5026-smooth-terrain-grid.md)

### Heightmap generation via circular displacements
Uses circular displacement patterns for heightmap generation. Use when radial symmetry or specific circular patterns are desired. [Link](5186-heightmap-generation-via-circular-displacements.md)

## Operating characteristics

*   **Time Complexity**: $O(1)$ per point evaluation, dominated by the projection, table lookup, and bilinear interpolation [S1].
*   **Memory Complexity**: $O(W \times H)$ for the altitude map table, where $W$ and $H$ are the dimensions of the perturbation domain [S1].
*   **Strengths**: Allows for easy modification of terrain details by editing the 2D altitude map without altering the global base surface. Efficient for volume rendering as it defines a scalar field [S1].
*   **Limitations**: Limited to simple base surfaces. The perturbation is constrained to the 2D domain $D_P$, meaning terrain outside this domain is flat (or follows the base surface exactly) [S1].
*   **When to use**: When terrain needs to be defined relative to a simple geometric base (like a sphere or plane) and local variations are best described by a 2D height map. Suitable for volume rendering of functionally defined objects [S1].
*   **When not to use**: When the terrain has complex global topology that cannot be represented by a simple base surface + perturbation, or when the terrain extends far beyond a defined 2D domain.

## Background

The method originates from research on GPU-based volume-oriented rendering of functionally defined objects. It was used to represent the terrain of Volcano Bandai, utilizing a plane as the base surface and a parallel projection for the transformation [S1]. The approach treats terrain as a "simple surface" or "freeform surface" defined by a scalar field [S1].
