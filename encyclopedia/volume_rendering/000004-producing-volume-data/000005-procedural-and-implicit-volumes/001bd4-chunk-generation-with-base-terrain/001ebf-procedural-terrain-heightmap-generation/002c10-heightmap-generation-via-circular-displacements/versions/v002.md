# Heightmap generation via circular displacements


## Overview
This method generates a procedural terrain heightmap by iteratively applying overlapping circular displacement functions to a flat vertex grid [S1, unofficial]. It constructs height by accumulating discrete, localized perturbations defined by random centers, radii, and signs [S1, unofficial].

## How it works

### Inputs and outputs
**Inputs:** Grid dimensions `MAP_SIZE` and `MAP_NUM_VERTICES`, displacement parameters `MAX_CIRCLE_SIZE`, `MAX_DISPLACEMENT`, `DISPLACEMENT_SIGN_LIMIT`, `MAX_ITER`, `NUM_ITER_AT_A_TIME`, and a random number generator [S1, unofficial].
**Outputs:** A vertex grid `map_vertices` and a list of triangle indices [S1, unofficial].

### Data structures
The vertex buffer uses a layout `map_vertices[component][vertex_index]` where component 0 stores the x-coordinate, component 1 stores the y-coordinate (height), and component 2 stores the z-coordinate [S1, unofficial]. The total number of vertices is `MAP_NUM_TOTAL_VERTICES = MAP_NUM_VERTICES * MAP_NUM_VERTICES` [S1, unofficial].

### Parameters
Typical values from the reference implementation are `MAP_SIZE = 10.0f`, `MAP_NUM_VERTICES = 80`, `MAX_CIRCLE_SIZE = 5.0f`, `MAX_DISPLACEMENT = 1.0f`, `DISPLACEMENT_SIGN_LIMIT = 0.3f`, `MAX_ITER = 200`, and `NUM_ITER_AT_A_TIME = 1` [S1, unofficial].

### Steps
1. **Initialize Grid:** Create a flat grid of `MAP_NUM_TOTAL_VERTICES` vertices with x and z coordinates spaced by `MAP_SIZE / (MAP_NUM_VERTICES - 1)`, and y = 0.0f [S1, unofficial].
2. **Generate Indices:** Generate line indices for a grid fan: close top edge, close right edge, then for each cell (i, j) with `ref = i * MAP_NUM_VERTICES + j`, add indices for `(ref, ref+1)`, `(ref, ref+MAP_NUM_VERTICES)`, `(ref, ref+MAP_NUM_VERTICES+1)` [S1, unofficial].
3. **Iterative Displacement:** Repeat `MAX_ITER` times:
   a. Generate random circle parameters: `center_x` and `center_z` uniformly in `[0, MAP_SIZE]`, `circle_size` in `[0, MAX_CIRCLE_SIZE]`, `sign = -1.0f` if `rand()/RAND_MAX < DISPLACEMENT_SIGN_LIMIT` else `1.0f`, `disp = sign * (MAX_DISPLACEMENT * rand()/RAND_MAX)` [S1, unofficial].
   b. For each vertex `ii`, compute `dx = center_x - map_vertices[0][ii]` and `dz = center_z - map_vertices[2][ii]` [S1, unofficial].
   c. Compute `pd = (2.0f * sqrt(dx*dx + dz*dz)) / circle_size` [S1, unofficial].
   d. If `fabs(pd) <= 1.0f`, compute `new_height = disp + cos(pd * 3.14f) * disp`, and update `map_vertices[1][ii] += new_height` [S1, unofficial].

### Pseudocode
```python
import math
import random

def generate_heightmap(map_size, map_num_vertices, max_circle_size, max_displacement, displacement_sign_limit, max_iter):
    num_vertices = map_num_vertices * map_num_vertices
    spacing = map_size / (map_num_vertices - 1)
    
    # map_vertices layout: [component][vertex_index]
    vertices_x = [0.0] * num_vertices
    vertices_y = [0.0] * num_vertices
    vertices_z = [0.0] * num_vertices
    
    for i in range(map_num_vertices):
        for j in range(map_num_vertices):
            idx = i * map_num_vertices + j
            vertices_x[idx] = j * spacing
            vertices_z[idx] = i * spacing
            vertices_y[idx] = 0.0
            
    indices = []
    # "close top edge, close right edge" is not specified in the sources [G]
    for i in range(map_num_vertices - 1):
        for j in range(map_num_vertices - 1):
            ref = i * map_num_vertices + j
            indices.append(ref)
            indices.append(ref + 1)
            indices.append(ref + map_num_vertices)
            indices.append(ref)
            indices.append(ref + map_num_vertices)
            indices.append(ref + map_num_vertices + 1)
            
    for _ in range(max_iter):
        center_x = random.uniform(0, map_size)
        center_z = random.uniform(0, map_size)
        circle_size = random.uniform(0, max_circle_size)
        
        if circle_size == 0:
            continue
            
        rand_val = random.random()
        sign = -1.0 if rand_val < displacement_sign_limit else 1.0
        disp = sign * (max_displacement * random.random())
        
        for ii in range(num_vertices):
            dx = center_x - vertices_x[ii]
            dz = center_z - vertices_z[ii]
            pd = (2.0 * math.sqrt(dx * dx + dz * dz)) / circle_size
            
            if abs(pd) <= 1.0:
                new_height = disp + math.cos(pd * math.pi) * disp
                vertices_y[ii] += new_height
                
    return vertices_x, vertices_y, vertices_z, indices
```

### Edge cases and pitfalls
A zero `circle_size` causes division by zero in the `pd` calculation; the implementation must skip such iterations [G]. Not given in the sources for other edge cases.

## Operating characteristics
Time complexity is $O(MAX\_ITER \cdot MAP\_NUM\_TOTAL\_VERTICES)$ [G]. Memory complexity is $O(MAP\_NUM\_TOTAL\_VERTICES)$ for vertex storage and indices [G]. Measured performance, scaling, strengths, limitations, and usage recommendations are Not given in the sources.

## Background
This method originates from the `voxel-engine` project by EmaMaker [S1, unofficial]. It is used in the context of procedural chunk generation for voxel-based games [S1, unofficial].
