# Terrain Chunk Generation

Also called: FBM Terrain Synthesis, terrainChunk

## Overview
Generates a voxel chunk using two layers of fractal Brownian motion (fBm) noise: one for surface height and one for cave depth [S1, unofficial]. It assigns materials based on vertical distance from the surface and absolute Y position [S1, unofficial]. This method builds on [Procedural Cave Height and Layer Generation](3202-procedural-cave-height-and-layer-generation.md) by providing the specific procedural implementation for the terrain layer.

## How it works
**Inputs:**
- `seed`: number (default 1337). Deterministic seed for noise generation [S1, unofficial].
- `size`: number (default `CHUNK_SIZE`). Dimensions of the cubic chunk ($size \times size \times size$) [S1, unofficial].
- `materials`: number (default 4). Number of material layers. When set to 1, forces single-material output for benchmarking sensitivity [S1, unofficial].

**Outputs:**
- A `VoxelChunk` data structure filled with material IDs.

**Data Structures:**
- `VoxelChunk`: A 3D array or flat buffer of size $size^3$. Stores integer material IDs.
- Noise Generators: Two independent fBm noise functions, `surface` and `cave`.

**Steps:**
1. Initialize `surface` noise generator with `seed`.
2. Initialize `cave` noise generator with `seed ^ 0x9e3779b9` (XOR with the golden ratio constant) [S1, unofficial].
3. Set cave noise to 3 octaves [S1, unofficial].
4. Iterate $z$ from 0 to $size-1$.
5. Iterate $x$ from 0 to $size-1$.
6. Compute surface height:
   $$ height = \lfloor (0.55 + surface(\frac{x}{size} \cdot 3.5, \frac{z}{size} \cdot 3.5) \cdot 0.32) \cdot size \rfloor $$
   where $surface$ is the fBm noise function [S1, unofficial].
7. Iterate $y$ from 0 to $\min(height, size)-1$.
8. Check for cave occlusion:
   - Compute cave value: $c = cave(\frac{x}{size} \cdot 5, \frac{z}{size} \cdot 5 + y \cdot 0.21)$ [S1, unofficial].
   - If $y > 2$ AND $c > 0.45$, skip this voxel (it is inside a cave) [S1, unofficial].
9. Compute depth: $depth = height - y$ [S1, unofficial].
10. Assign material based on `materials` count and `depth`:
    - If `materials` == 1: material = 1 [S1, unofficial].
    - Else if $depth \le 1$: material = 1 [S1, unofficial].
    - Else if $depth \le 4$: material = 2 [S1, unofficial].
    - Else if $y < 4$: material = 4 [S1, unofficial].
    - Else: material = 3 [S1, unofficial].
11. Set voxel at $(x, y, z)$ to the assigned material.

**Pitfalls:**
- Cave noise uses a different seed and 3 octaves to drill into the chunk, creating inner surfaces [S1, unofficial].
- The $y$-offset in cave sampling ($y \cdot 0.21$) ensures caves are not perfectly vertical columns, allowing culling tests to distinguish between outer and inner faces [S1, unofficial].

```python
def generate_terrain_chunk(seed=1337, size=64, materials=4):
    # Initialize noise generators
    # Note: Exact fBm implementation details (octaves, lacunarity, gain) 
    # are not specified in the source beyond "3 octaves" for cave.
    # [G] Assuming a standard fBm implementation for surface and cave.
    surface_noise = create_fb_m_noise(seed, octaves=3)
    cave_noise = create_fb_m_noise(seed ^ 0x9e3779b9, octaves=3)
    
    chunk = VoxelChunk(size)
    
    for z in range(size):
        for x in range(size):
            # Compute surface height
            # Normalized coordinates
            nx = x / size
            nz = z / size
            
            # Surface noise value
            s_val = surface_noise(nx * 3.5, nz * 3.5)
            
            # Height formula
            height = int((0.55 + s_val * 0.32) * size)
            
            # Clamp height to chunk bounds
            if height >= size:
                height = size - 1
            if height < 0:
                height = 0
                
            for y in range(min(height, size)):
                # Cave occlusion check
                if y > 2:
                    # Cave noise sampling with y-offset
                    cx = x / size
                    cz = z / size
                    # Cave noise input: x scaled by 5, z scaled by 5 + y * 0.21
                    c_val = cave_noise(cx * 5, cz * 5 + y * 0.21)
                    
                    if c_val > 0.45:
                        # Skip voxel (inside cave)
                        continue
                
                # Compute depth
                depth = height - y
                
                # Assign material
                if materials == 1:
                    mat = 1
                elif depth <= 1:
                    mat = 1
                elif depth <= 4:
                    mat = 2
                elif y < 4:
                    mat = 4
                else:
                    mat = 3
                    
                chunk.set(x, y, z, mat)
                
    return chunk
```
