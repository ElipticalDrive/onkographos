# Procedural Cave Height and Layer Generation

Also called: Cave Height and Layer Generation, Cave layer generation, FunctionMakeCaveLayer, Procedural Cave Layer Generation

## Overview
Modifies voxel density to create a horizontal cave layer with variable height, stalactites, and Perlin noise displacement [S1, unofficial]. It builds on [Terrain Generation via Noise](2412-terrain-generation-via-noise.md) by introducing a Z-axis dependent noise profile that carves out a specific elevation band, distinct from the surface height generation.

## How it works
**Inputs:**
- `Density`: Initial voxel density (float, typically [0, 1]).
- `WorldPos`: 3D world position $(X, Y, Z)$ of the voxel center.

**Outputs:**
- `Result`: Modified density value (float, clamped to [0, 1]).

**Parameters:**
- `BaseCaveLevel`: 7000.0f. The central Z-coordinate for the cave layer [S1, unofficial].
- `BaseCaveHeight`: 400.0f. Fixed vertical thickness of the cave layer [S1, unofficial].
- `ExtraCaveHeightMultiplier`: 490.0f. Amplitude for height variation noise [S1, unofficial].
- `ExtraCaveLevelMultiplier`: 1000.0f. Amplitude for Z-level displacement noise [S1, unofficial].
- `ScaleStalactite`: 0.005f. Spatial frequency for stalactite noise [S1, unofficial].
- `ScaleGeneral`: 0.001f. Spatial frequency for general cave noise [S1, unofficial].

**Data Structures:**
- No persistent data structures. The method is stateless and evaluates per-voxel.

**Steps:**

1.  **Initialize Result:**
    $$ \text{Result} = \text{Density} $$

2.  **Calculate Base Cave Height Variation:**
    Compute a 3D Perlin noise value using scaled X and Y coordinates, ignoring Z for the base height variation:
    $$ v_3 = (X \cdot 0.001, Y \cdot 0.001, 0) $$
    $$ \text{Noise3} = \text{PerlinNoise}(v_3) $$
    $$ \text{ExtraCaveHeight} = 490 \cdot \text{Noise3} $$
    $$ \text{CaveHeight} = \max(0, 400 + \text{ExtraCaveHeight}) $$

3.  **Calculate Cave Level Displacement:**
    Compute a 3D Perlin noise value using scaled X and Y coordinates with a fixed Z offset:
    $$ v_4 = (X \cdot 0.00025, Y \cdot 0.00025, 10) $$
    $$ \text{Noise4} = \text{PerlinNoise}(v_4) $$
    $$ \text{ExtraCaveLevel} = 1000 \cdot \text{Noise4} $$
    $$ \text{CaveLevel} = 7000 + \text{ExtraCaveLevel} $$

4.  **Calculate Cave Layer Falloff:**
    Compute a Gaussian-like falloff based on the distance from the voxel's Z position to the calculated `CaveLevel`, normalized by `CaveHeight`:
    $$ \text{CaveHeightF} = \text{CaveHeight} \cdot 160 $$
    $$ \text{CaveLayer} = 1 - \exp\left( -\frac{(Z + \text{CaveLevel})^2}{\text{CaveHeightF}} \right) $$
    *Note: The source formula uses `WorldPos.Z + CaveLevel`. Given `BaseCaveLevel` is 7000 and typical terrain heights are lower, this implies `CaveLevel` might be defined as a negative offset or the coordinate system places the cave deep in negative Z. However, the source explicitly writes `WorldPos.Z + CaveLevel`. We follow the source literally.*

5.  **Calculate Stalactite Noise:**
    $$ v_0 = (X \cdot 0.005, Y \cdot 0.005, Z \cdot 0.0002) $$
    $$ \text{Noise0} = \text{PerlinNoise}(v_0) $$

6.  **Calculate General Noise:**
    $$ v_1 = (X \cdot 0.001, Y \cdot 0.001, Z \cdot 0.001) $$
    $$ \text{Noise1} = \text{PerlinNoise}(v_1) $$

7.  **Blend Density in Cave Zone:**
    If the voxel's Z coordinate is within the range $[-(7000 - 1200), -(7000 + 1200)]$, i.e., $[-8200, -5800]$, blend the result:
    $$ \text{CaveLayerN} = 1 - \text{CaveLayer} $$
    $$ \text{Result} = \text{Result} \cdot (\text{CaveLayer} + \text{CaveLayerN} \cdot \text{Noise0} \cdot 0.5 + \text{Noise1} \cdot 0.75) $$

8.  **Clamp Result:**
    $$ \text{Result} = \max(0, \min(1, \text{Result})) $$

**Pseudocode:**

```python
def make_cave_layer(density: float, world_pos: Vector3) -> float:
    x, y, z = world_pos.x, world_pos.y, world_pos.z
    
    # Parameters
    base_cave_level = 7000.0
    base_cave_height = 400.0
    extra_height_mult = 490.0
    extra_level_mult = 1000.0
    
    # Step 2: Base Cave Height Variation
    v3 = Vector3(x * 0.001, y * 0.001, 0.0)
    noise3 = perlin_noise(v3)
    extra_cave_height = extra_height_mult * noise3
    cave_height = max(0.0, base_cave_height + extra_cave_height)
    
    # Step 3: Cave Level Displacement
    v4 = Vector3(x * 0.00025, y * 0.00025, 10.0)
    noise4 = perlin_noise(v4)
    extra_cave_level = extra_level_mult * noise4
    cave_level = base_cave_level + extra_cave_level
    
    # Step 4: Cave Layer Falloff
    cave_height_f = cave_height * 160.0
    # Note: Source uses (WorldPos.Z + CaveLevel). 
    # If CaveLevel is ~7000 and Z is negative (e.g. -7000), this centers the cave.
    dist_sq = (z + cave_level) ** 2
    cave_layer = 1.0 - math.exp(-dist_sq / cave_height_f)
    
    # Step 5: Stalactite Noise
    v0 = Vector3(x * 0.005, y * 0.005, z * 0.0002)
    noise0 = perlin_noise(v0)
    
    # Step 6: General Noise
    v1 = Vector3(x * 0.001, y * 0.001, z * 0.001)
    noise1 = perlin_noise(v1)
    
    # Step 7: Blend Density in Cave Zone
    result = density
    min_z = -(base_cave_level - 1200.0) # -5800
    max_z = -(base_cave_level + 1200.0) # -8200
    
    # Check if Z is within [-8200, -5800]
    if min_z <= z <= max_z:
        cave_layer_n = 1.0 - cave_layer
        result = result * (cave_layer + cave_layer_n * noise0 * 0.5 + noise1 * 0.75)
        
    # Step 8: Clamp
    result = max(0.0, min(1.0, result))
    
    return result
```

**Edge Cases and Pitfalls:**
- **Precision:** The Z-coordinates involved (around -7000 to -8200) are large. Ensure floating-point precision is sufficient for the noise sampling at these scales.
- **Coordinate System:** The formula `WorldPos.Z + CaveLevel` suggests that `CaveLevel` is a positive offset added to a negative Z position to center the cave. If the coordinate system places the cave at positive Z, this formula will fail to center the cave correctly. The source implies a specific coordinate convention where the cave is deep in the negative Z direction.
- **Degenerate Input:** If `CaveHeight` is 0, `CaveHeightF` becomes 0, leading to division by zero in the exponential term. The `max(0, ...)` in Step 2 ensures `CaveHeight` is non-negative, but if it is exactly 0, the division by zero must be handled (e.g., by capping `CaveHeightF` to a small epsilon or skipping the blend). The source does not explicitly handle this, but it is a critical implementation detail [G].

## Subtopics

### [Terrain Chunk Generation](3653-terrain-chunk-generation.md)
Generates a voxel chunk using two layers of fractal Brownian motion (fBm) noise: one for surface height and one for cave depth. It assigns materials based on vertical distance from the surface and absolute Y position. This method builds on [Procedural Cave Height and Layer Generation](3202-procedural-cave-height-and-layer-generation.md) by providing the specific procedural implementation for the terrain layer.

## Operating characteristics
- **Time Complexity:** O(1) per voxel. The method involves a constant number of noise evaluations (3) and basic arithmetic operations.
- **Memory Complexity:** O(1). No additional memory is required beyond local variables.
- **Performance:** The method is computationally lightweight, suitable for real-time voxel generation. The primary cost is the Perlin noise evaluation.
- **Strengths:** Simple to implement, efficient, and provides visually distinct cave structures with stalactites.
- **Limitations:** The cave layer is strictly horizontal and Z-centered, which may not suit all terrain types. The coordinate system dependency (negative Z) is a significant constraint.
- **When to use:** When a distinct, horizontal cave layer is desired in a voxel terrain, particularly in a coordinate system where the cave is located at negative Z values.
- **When not to use:** When the terrain uses a different coordinate convention (e.g., positive Z for depth) or when more complex, non-horizontal cave structures are needed.

## Background
Originating from the UE4VoxelTerrain project, this method is part of a procedural terrain generation pipeline [S1, unofficial]. It is designed to create underground cave systems by modifying the density field based on noise-driven height and level variations.
