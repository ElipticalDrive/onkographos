# Chunk Filling with Height Map
Also called: FillChunk with HeightMap
## Overview
This method populates a 3D voxel chunk with solid material based on a 2D height map, treating the height map as a surface above which voxels are empty and below which are filled [S1, unofficial]. It converts procedural terrain surface data into volumetric data for downstream rendering [G].
## How it works
### Inputs and outputs
- `chunk_start_y`: The world Y coordinate of the chunk's minimum corner [S1, unofficial].
- `dims`: A 3D vector $(x, y, z)$ representing the voxel count along each axis [S1, unofficial].
- `heights`: A 1D array of height values, provided as `std::span<const int>` or `std::span<const float>` [S1, unofficial].
- `func`: A function $func(x, y, z)$ that returns the material or density value for a filled voxel [S1, unofficial].
- `stride_z`: The Z-dimension stride used for height map indexing [S1, unofficial].
- `range_min`, `range_max`: The valid Y range of the height map [S1, unofficial].
- **Outputs**: A 3D array of voxel data for the chunk [S1, unofficial].
### Data structures
- **Height Map**: A 1D array indexed by $i = x \cdot \text{stride\_z} + z$ [S1, unofficial].
- **Chunk Grid**: A 3D grid of size $Dims.x \times Dims.y \times Dims.z$ [S1, unofficial].
### Steps
1. **Boundary Check**: If `chunk_start_y + dims.y <= range_min` or `chunk_start_y >= range_max`, return early without processing [S1, unofficial].
2. **Height Conversion**: If `heights` contains floats, convert each element to an integer using a helper function $GetHeight$, storing the result in a temporary integer array, then proceed with the integer array [S1, unofficial].
3. **Iterate Voxels**: Loop over $y$ from $0$ to $Dims.y - 1$, $z$ from $0$ to $Dims.z - 1$, and $x$ from $0$ to $Dims.x - 1$ [S1, unofficial].
4. **Index Calculation**: For each $(x, z)$, calculate the height map index $i = x \cdot \text{stride\_z} + z$ [S1, unofficial].
5. **Fill Condition**: If $y < heights[i] - chunk\_start\_y$, the voxel is below the terrain surface [S1, unofficial].
6. **Assign Material**: Set the voxel at $(x, y, z)$ to $func(x, y, z)$ if the condition is met, otherwise mark it as empty [S1, unofficial].
### Pseudocode
```python
def FillChunk(chunk_start_y, dims, heights, func, stride_z, range_min, range_max):
    # Boundary check: early exit if chunk Y range is outside height map range [S1, unofficial]
    if chunk_start_y + dims.y <= range_min or chunk_start_y >= range_max:
        return []

    # Initialize chunk data with empty voxels
    chunk_data = [[[0 for _ in range(dims.x)] for _ in range(dims.z)] for _ in range(dims.y)]

    # If heights are floats, convert to int via GetHeight first [S1, unofficial]
    
    for y in range(dims.y):
        for z in range(dims.z):
            for x in range(dims.x):
                i = x * stride_z + z
                if y < heights[i] - chunk_start_y:
                    chunk_data[y][z][x] = func(x, y, z)
                else:
                    chunk_data[y][z][x] = 0
    return chunk_data
```
### Parameters
- `SEA`: Sea level threshold used in shoreline variants [S2, unofficial].
- `3.5`: Depth in blocks over which the shoreline fades from land to water [S2, unofficial].
### Edge cases and pitfalls
- **Boundary Check**: The function includes an early exit if the chunk's Y range is completely outside the height map's valid range, preventing unnecessary computation [S1, unofficial].
- **Precision**: Float heights must be converted to integers before the core filling logic if the implementation expects integer heights [S1, unofficial].
## Subtopics

### Shoreline Texture Generation
Generates a 1-byte-per-sample texture indicating land (1) fading to water (0) over ~3.5 blocks depth [S2, unofficial]. For each sample, calculate height $h = \lfloor gen.heightAt(x_0 + i \cdot step + 1, z_0 + j \cdot step + 1) \rfloor + 1$ [S2, unofficial]. If $h > SEA$, set $sh = 1$ [S2, unofficial]. Else, set $sh = \min(1, \max(0, 1 - \frac{SEA - h}{3.5}))$ [S2, unofficial]. Store $sh \cdot 255$ [S2, unofficial]. The fade formula is $S = \max(0, \min(1, 1 - \frac{SEA - h}{3.5}))$ for $h \le SEA$, else 1 [S2, unofficial].
