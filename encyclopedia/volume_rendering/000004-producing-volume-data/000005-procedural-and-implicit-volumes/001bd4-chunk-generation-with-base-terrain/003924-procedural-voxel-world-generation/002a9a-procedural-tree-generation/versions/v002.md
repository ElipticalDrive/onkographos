# Procedural Tree Generation
## Overview
Procedural tree generation populates a voxel world with vegetation by algorithmically placing trunk and leaf blocks at valid surface coordinates [S1, unofficial][S2, unofficial]. It differs from [Biome and Voxel Layer Determination](4167-biome-and-voxel-layer-determination.md) by operating on top of the static ground layer to inject vertical structures [G]. It differs from [Procedural Voxel World Generation](3891-procedural-voxel-world-generation.md) by focusing on the geometric construction of individual entities rather than global terrain noise [G].

## How it works
The method determines tree placement validity, generates the trunk, and constructs the leaf canopy using one of several geometric primitives [S1, unofficial][S2, unofficial].

**Inputs and Outputs:**
- **Inputs:** Chunk coordinates $(x, z)$, surface height $y$, random seed/state, tree parameters (height, radius, probability) [S1, unofficial][S2, unofficial].
- **Outputs:** Modified voxel array where trunk and leaf block IDs are written [S1, unofficial].

**Data Structures:**
- `voxels`: A 1D array or 3D grid of `uint8` block IDs [S1, unofficial].
- `get_index(x, y, z)`: Helper to map 3D coordinates to the 1D array index [G].
- `RandomChance(p)`: Returns true with probability $p$ [S2, unofficial].

**Parameters:**
- `TREE_PROBABILITY`: Chance a valid grass block spawns a tree. Typical value: Not given in the sources.
- `TREE_HEIGHT`: Height of the trunk. Typical value: Not given in the sources.
- `radius`: Radius of the leaf canopy. Typical value: Not given in the sources.
- `leafBlock`, `fruitBlock`, `wood`, `dirt`: Block IDs [S1, unofficial][S2, unofficial].

**Algorithm Steps (Base Variant):**
1. **Validation:** Check if the voxel at $(x, y, z)$ is GRASS. Perform a random check `rnd > TREE_PROBABILITY`; if it fails, abort. Verify bounds: $y + TREE\_HEIGHT$ and $x, z$ must be within chunk/world limits [S1, unofficial].
2. **Trunk Base:** Set `voxels[get_index(x, y, z)] = DIRT` [S1, unofficial].
3. **Canopy Generation:** Use nested loops for height $iy$, x-offset $ix$, and z-offset $iz$. Calculate a shaping variable $m$ based on iteration $n$. Apply a pattern check: `(ix + iz) % 4`. If conditions are met, set the block to LEAVES [S1, unofficial].
4. **Trunk Body:** Loop $iy$ from 1 to $TREE\_HEIGHT - 2$. Set `voxels[get_index(x, y + iy, z)] = WOOD` [S1, unofficial].
5. **Canopy Top:** Set `voxels[get_index(x, y + TREE_HEIGHT - 2, z)] = LEAVES` [S1, unofficial].

**Pseudocode (Base Variant):**
```python
# Self-contained constants and helpers
GRASS = 2
DIRT = 3
WOOD = 4
LEAVES = 5
AIR = 0
CHUNK_W = 16
CHUNK_H = 256
CHUNK_D = 16

def get_index(x, y, z):
    return x + CHUNK_W * z + CHUNK_W * CHUNK_D * y

def set_block(voxels, x, y, z, block_id):
    voxels[get_index(x, y, z)] = block_id

def get_block(voxels, x, y, z):
    return voxels[get_index(x, y, z)]

def is_in_bounds(x, y, z):
    return 0 <= x < CHUNK_W and 0 <= y < CHUNK_H and 0 <= z < CHUNK_D

import random as rng

def place_tree_base(voxels, x, y, z, TREE_HEIGHT, TREE_PROBABILITY, radius):
    # 1. Validation
    if get_block(voxels, x, y, z) != GRASS:
        return
    if not (rng.random() > TREE_PROBABILITY):  # Random check fails
        return
    if not is_in_bounds(x, y + TREE_HEIGHT, z):
        return

    # 2. Trunk Base
    set_block(voxels, x, y, z, DIRT)

    # 3. Canopy Generation (per source order)
    # Note: Exact loop bounds and 'm' calculation are not specified in the sources [G]
    for iy in range(0, TREE_HEIGHT):
        for ix in range(-radius, radius + 1):
            for iz in range(-radius, radius + 1):
                # Shaping variable m based on iteration n is not detailed in sources [G]
                if (ix + iz) % 4 == 0:
                    set_block(voxels, x + ix, y + iy, z + iz, LEAVES)

    # 4. Trunk Body
    for iy in range(1, TREE_HEIGHT - 1):
        set_block(voxels, x, y + iy, z, WOOD)

    # 5. Canopy Top
    set_block(voxels, x, y + TREE_HEIGHT - 2, z, LEAVES)
```

**Edge Cases and Pitfalls:**
- **Boundary Checks:** Failure to check chunk/world boundaries when placing blocks at $y + TREE\_HEIGHT$ can cause out-of-bounds memory access [S1, unofficial].
- **Degenerate Input:** If `TREE_HEIGHT` is less than 3, the trunk loop range may be invalid or empty [G].

## Subtopics

### PlaceTreeBall
Generates a tree with a spherical leaf canopy by checking the squared Euclidean distance from the center of the leaf volume [S2, unofficial]. Trunk generation loops $y$ from $baseY$ to $baseY + height$ (exclusive), setting block at $(baseX, y, baseZ)$ to ID 6 [S2, unofficial]. Leaf generation loops $y$ from $baseY + height - radius$ to $baseY + height + radius$ (inclusive), $x$ from $baseX - radius$ to $baseX + radius$, and $z$ from $baseZ - radius$ to $baseZ + radius$ [S2, unofficial]. Logic calculates squared distances: $xDistSq = (baseX - x)^2$, $zDistSq = (baseZ - z)^2$, $yDistSq = (baseY + height - y)^2$. If $xDistSq + zDistSq + yDistSq \le radius^2$ and the block is air (ID 0), apply `RandomChance` for leaf and fruit blocks [S2, unofficial].

### PlaceTreeBox
Generates a tree with a rectangular prism leaf canopy by iterating over a 3D box centered on the trunk and placing leaf blocks probabilistically [S2, unofficial]. Trunk generation loops $y$ from $baseY$ to $baseY + trunkHeight$ (exclusive), setting block at $(baseX, y, baseZ)$ to ID 6 [S2, unofficial]. Leaf generation loops $x$ from $baseX - leafWidth$ to $baseX + leafWidth$, $y$ from $baseY + trunkHeight$ to $baseY + trunkHeight + leafHeight$, and $z$ from $baseZ - leafWidth$ to $baseZ + leafWidth$ [S2, unofficial]. Logic checks if target block is air (ID 0), then calls `RandomChance(leafPercent)` (default 7) for leaves and `RandomChance(fruitPercent)` (default 18) for fruit [S2, unofficial].

### PlaceTreeCone
Generates a tree with a conical leaf canopy where the radius decreases linearly with height, using a circular cross-section check [S2, unofficial]. Trunk generation loops $y$ from $baseY$ to $baseY + height$ (exclusive), setting block at $(baseX, y, baseZ)$ to ID 6 [S2, unofficial]. Leaf generation loops $y$ from $baseY + leafBase$ to $baseY + height + 1$ (inclusive) [S2, unofficial]. Logic calculates radial gradient: $radGradient = (baseY + height + 1 - y) / height$. Calculates current width: $thisWidth = \text{round}(radGradient \times radius)$. Iterates $x$ and $z$ within this width. If inside the circle and block is air (ID 0), applies `RandomChance` for leaf and fruit blocks [S2, unofficial].
