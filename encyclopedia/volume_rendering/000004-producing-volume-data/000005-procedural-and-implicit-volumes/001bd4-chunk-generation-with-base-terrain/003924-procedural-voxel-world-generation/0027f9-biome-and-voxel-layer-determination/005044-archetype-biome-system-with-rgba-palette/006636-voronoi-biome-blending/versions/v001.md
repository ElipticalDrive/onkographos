# Voronoi Biome Blending

Also called: Voronoi Cell Biome Generation

## Overview
Voronoi Biome Blending is a procedural terrain generation technique that uses Voronoi cells to define macro-biomes and smoothstep interpolation to create seamless transitions between them [S1, unofficial]. It builds on the [Archetype Biome System with RGBA Palette](14171-archetype-biome-system-with-rgba-palette.md) by determining biome selection through macro noise (temperature, moisture, height hint) rather than simple distance, ensuring contiguous macro-climates [S1, unofficial].

## How it works
**Inputs:** Global world coordinate $(globalX, globalZ)$, world seed, `VORONOI_CELL_SIZE`, `BLEND_RADIUS`.
**Outputs:** Blended terrain height and color (RGBA) for the target coordinate.

**Data Structures:**
*   **Voronoi Point Cache:** A map or array storing the offset $(ox, oz)$ for each cell center $(cx, cz)$. The offset is generated once per cell using a PRNG seeded with `seed + key`.
*   **Biome Data:** Per-cell data containing height parameters and RGBA color palettes, derived from the Archetype Biome System.

**Parameters:**
*   `VORONOI_CELL_SIZE`: Size of Voronoi cells in world units. Typical value: 256 [S1, unofficial].
*   `BLEND_RADIUS`: Distance over which biome blending occurs. Typical value: 64.0 [S1, unofficial].

**Steps:**
1.  **Generate Voronoi Points:** For each cell $(cx, cz)$ in the relevant grid area, generate a random offset $(ox, oz)$ using a PRNG seeded with `seed + key`. Store these offsets. [S1, unofficial]
2.  **Find Nearest Cells:** For the target global coordinate $(globalX, globalZ)$, identify the 9 surrounding cells defined by $dx, dz \in \{-1, 0, 1\}$. Calculate the distance from $(globalX, globalZ)$ to the center of each cell plus its offset. Track the closest point ($minDist1$) and the second closest point ($minDist2$). [S1, unofficial]
3.  **Calculate Blend Factor:** Compute the difference $diff = minDist2 - minDist1$. Calculate the raw factor $factor = \min(diff / BLEND\_RADIUS, 1.0)$. Apply smoothstep to get $factor_{smooth} = factor^2 (3 - 2 \cdot factor)$. [S1, unofficial]
4.  **Determine Weights:** The weight for the closest biome is $w1 = 0.5 + 0.5 \cdot factor_{smooth}$. The weight for the second closest biome is $w2 = 1.0 - w1$. [S1, unofficial]
5.  **Interpolate:** If $w1 = 1.0$ (only one biome is dominant), use its height and color directly. Otherwise, interpolate the terrain height and color between the two biomes using weights $w1$ and $w2$. [S1, unofficial]

**Pseudocode:**
```python
import math

def voronoi_biome_blend(global_x, global_z, seed, cell_size=256.0, blend_radius=64.0):
    # 1. Determine surrounding cells
    # Cell centers are multiples of cell_size
    cx_start = math.floor(global_x / cell_size) - 1
    cz_start = math.floor(global_z / cell_size) - 1
    
    min_dist1 = float('inf')
    min_dist2 = float('inf')
    closest_biome = None
    second_biome = None
    
    # 2. Find two closest Voronoi points among 9 surrounding cells
    for dx in range(-1, 2):
        for dz in range(-1, 2):
            cx = cx_start + dx
            cz = cz_start + dz
            
            # Generate offset for this cell
            # Note: In implementation, this offset should be cached
            offset_x, offset_z = get_voronoi_offset(cx, cz, seed)
            
            cell_center_x = cx * cell_size
            cell_center_z = cz * cell_size
            
            point_x = cell_center_x + offset_x
            point_z = cell_center_z + offset_z
            
            dist_sq = (global_x - point_x)**2 + (global_z - point_z)**2
            dist = math.sqrt(dist_sq)
            
            # Update closest and second closest
            if dist < min_dist1:
                min_dist2 = min_dist1
                second_biome = closest_biome
                min_dist1 = dist
                closest_biome = get_biome_data(cx, cz)
            elif dist < min_dist2:
                min_dist2 = dist
                second_biome = get_biome_data(cx, cz)
                
    # 3. Calculate blend factor
    diff = min_dist2 - min_dist1
    factor = min(diff / blend_radius, 1.0)
    factor_smooth = factor**2 * (3 - 2 * factor)
    
    # 4. Determine weights
    w1 = 0.5 + 0.5 * factor_smooth
    w2 = 1.0 - w1
    
    # 5. Interpolate
    if w1 == 1.0:
        return closest_biome.height, closest_biome.color
    
    height = w1 * closest_biome.height + w2 * second_biome.height
    color = lerp_color(closest_biome.color, second_biome.color, w2)
    
    return height, color
```

**Edge Cases:**
*   **Precision:** Floating point precision may affect distance calculations for very large world coordinates. [G]
*   **Boundaries:** Ensure the cache or PRNG generation handles negative cell indices correctly. [G]
*   **Degenerate Input:** If `BLEND_RADIUS` is 0, blending is disabled. If `VORONOI_CELL_SIZE` is 0, division by zero occurs. [G]

## Operating characteristics
*   **Time Complexity:** $O(1)$ per query, as it only checks 9 cells. [S1, unofficial]
*   **Memory Complexity:** $O(N)$ for the cache of Voronoi points, where $N$ is the number of unique cells accessed. [S1, unofficial]
*   **Strengths:** Smooth transitions between biomes; contiguous macro-climates due to macro noise integration. [S1, unofficial]
*   **Limitations:** Requires caching or efficient generation of Voronoi offsets; blending radius affects performance if not optimized. [S1, unofficial]
*   **When to Use:** When smooth biome transitions are desired over sharp boundaries. [S1, unofficial]
*   **When Not to Use:** When sharp, distinct biome boundaries are required. [S1, unofficial]

## Background
Voronoi Biome Blending is used in procedural voxel world generation, specifically in the CubWrldJS project, to create visually appealing and contiguous terrain biomes [S1, unofficial]. It extends the Archetype Biome System by adding spatial blending capabilities.
