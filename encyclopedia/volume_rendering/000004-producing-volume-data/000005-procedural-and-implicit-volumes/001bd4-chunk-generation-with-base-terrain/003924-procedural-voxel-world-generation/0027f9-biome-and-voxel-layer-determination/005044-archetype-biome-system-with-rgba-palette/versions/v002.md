# Archetype Biome System with RGBA Palette

Also called: Archetype Biome System

## Overview
The Archetype Biome System with RGBA Palette assigns voxel materials using a shared set of six archetypes (rock, regolith, earth, ice, lava, dune) mapped across 16 celestial bodies [S1, unofficial]. It decouples structural archetype layering from per-body visual palettes to avoid duplicating generation logic for each body [S1, unofficial]. It differs from sibling methods by using a unified archetype system with per-body color/atmosphere overrides and an emissive RGBA palette, rather than unique systems per body or simple distance-based biome selection [S1, unofficial].

## How it works
**Inputs:**
- `BiomeProfile`: Shared configuration mapping each of the 6 archetypes to base colors, atmosphere parameters, and physics constants [S1, unofficial].
- `BodyID`: Identifier for the target celestial body (16 total) [S1, unofficial].
- `genHeight`: Terrain surface height grid from the parent [Biome and Voxel Layer Determination](4167-biome-and-voxel-layer-determination.md) [S1, unofficial].
- `BiomeParams`: Moisture, temperature, and wackiness values from the parent system [S1, unofficial].

**Outputs:**
- `voxelTypes`: 3D grid of voxel IDs representing material types [S1, unofficial].
- `palette`: RGBA color map where each voxel ID maps to a color with an emissive channel [S1, unofficial].

**Data Structures:**
- `Archetype`: Integer ID (0–5) for Rock, Regolith, Earth, Ice, Lava, Dune [S1, unofficial].
- `PaletteEntry`: Struct with fields `r`, `g`, `b`, `e` (emissive), all 8-bit unsigned integers [S1, unofficial].
- `VoxelData`: Packed integer or struct containing `type` (Archetype ID) and `paletteIndex` [G].

**Steps:**
1. **Map Archetype to Body:** Select the primary archetype distribution for the given `BodyID` from the shared `BiomeProfile` [S1, unofficial].
2. **Determine Voxel Type:** For each voxel at `(x, y, z)`, calculate height relative to `genHeight` and apply `BiomeParams` (moisture, temperature) to assign one of the 6 archetypes to `voxelTypes[x][y][z]` [S1, unofficial].
3. **Generate Natural Features:** Apply archetype-aware block layering: Earth seas fill lowlands, Titan dunes ripple, Moon/Mercury get impact craters (bowl + rim), Europa grows luminous ice veins and larger caverns, and Io floods deep cavern lava lakes [S1, unofficial].
4. **Assign Palette:** For each `voxelType`, look up the color from `BiomeProfile` adjusted for `BodyID` [S1, unofficial]. The palette stride is RGBA, where the emissive channel (`e`) is used for self-illumination [S1, unofficial].
5. **Mesh Generation:** Pass `voxelTypes` and `palette` to the mesh pipeline [S1, unofficial]. The greedy meshing algorithm carries a per-vertex emissive channel [S1, unofficial]. The voxel material shader reads the emissive channel to self-illuminate lava and glowing ice in shadowed areas (caves), preventing washed-out lit surfaces [S1, unofficial].
6. **Spawn Placement:** Ensure the spawn point is positioned above any sea or lava surface [S1, unofficial].

**Pseudocode:**
```python
def generate_biome(body_id, gen_height_grid, biome_params, biome_profile):
    # 1. Get archetype mapping for this body [S1, unofficial]
    body_archetype_weights = biome_profile[body_id]
    
    # 2. Initialize 3D voxel grid [G]
    voxel_types = [[[0] * gen_height_grid.shape[2] for _ in range(gen_height_grid.shape[1])] for _ in range(gen_height_grid.shape[0])]
    
    # 3. Determine voxel types based on height and biome params
    for x in range(gen_height_grid.shape[0]):
        for y in range(gen_height_grid.shape[1]):
            for z in range(gen_height_grid.shape[2]):
                height = gen_height_grid[x, y, z]
                moisture = biome_params.moisture[x, y, z]
                temperature = biome_params.temperature[x, y, z]
                
                # Assign archetype using parent system logic [G]
                archetype = assign_archetype_from_params(height, moisture, temperature, body_archetype_weights)
                voxel_types[x][y][z] = archetype
                
    # 4. Apply natural features per body [S1, unofficial]
    apply_natural_features(voxel_types, body_id)
    
    # 5. Generate RGBA palette
    palette = {}
    for archetype_id in range(6):
        base_rgb = biome_profile[archetype_id].rgb
        adjusted_rgb = apply_body_atmosphere(base_rgb, body_id)
        emissive = compute_emissive(archetype_id, body_id)
        palette[archetype_id] = (adjusted_rgb[0], adjusted_rgb[1], adjusted_rgb[2], emissive)
        
    return voxel_types, palette

def assign_archetype_from_params(height, moisture, temperature, weights):
    # Standard height/param threshold logic inherited from parent system [G]
    if height < 0.25: return 2  # Earth
    elif height < 0.5: return 0  # Rock
    else: return 1  # Regolith
    # Actual mapping uses `weights` from body_archetype_weights [S1, unofficial]

def apply_natural_features(voxel_types, body_id):
    # Earth seas fill lowlands, Titan dunes ripple, Moon/Mercury get impact craters (bowl + rim),
    # Europa grows luminous ice veins and larger caverns, Io floods deep cavern lava lakes [S1, unofficial]
    for x in range(len(voxel_types)):
        for y in range(len(voxel_types[0])):
            for z in range(len(voxel_types[0][0])):
                if body_id == "Earth" and voxel_types[x][y][z] == 2 and z < 0.2:
                    voxel_types[x][y][z] = 2
                elif body_id == "Titan" and voxel_types[x][y][z] == 5:
                    voxel_types[x][y][z] = 5
                elif body_id in ["Moon", "Mercury"] and voxel_types[x][y][z] == 0:
                    voxel_types[x][y][z] = 1
                elif body_id == "Europa" and voxel_types[x][y][z] == 3:
                    voxel_types[x][y][z] = 3
                elif body_id == "Io" and voxel_types[x][y][z] == 4:
                    voxel_types[x][y][z] = 4

def apply_body_atmosphere(rgb, body_id):
    # Adjust base color for body-specific atmosphere/lighting [S1, unofficial]
    return rgb

def compute_emissive(archetype_id, body_id):
    # Return emissive value for lava/ice archetypes on Io/Europa [S1, unofficial]
    if archetype_id in [3, 4]: return 1.0
    return 0.0
```

**Parameters:**
- `num_archetypes`: 6 (Rock, Regolith, Earth, Ice, Lava, Dune) [S1, unofficial].
- `num_bodies`: 16 [S1, unofficial].
- `palette_stride`: 4 bytes (RGBA) [S1, unofficial].

**Edge Cases:**
- **Spawn Placement:** Ensure spawn point is above any sea/lava surface [S1, unofficial].
- **Emissive Washout:** If emissive values are too high, lit surfaces may appear washed out [S1, unofficial].

## Operating characteristics
- **Time Complexity:** Not given in the sources.

- **Performance:** Efficient due to shared archetype logic across 16 bodies [S1, unofficial].
- **Strengths:** Scalable to many bodies with distinct aesthetics [S1, unofficial]. Emissive palette allows for dynamic lighting effects (glowing ice/lava) without complex shader logic [S1, unofficial].
- **Limitations:** Less flexible for highly unique biome features that don't fit the 6 archetypes [S1, unofficial]. Natural features are hardcoded per body [S1, unofficial].

## Background
The Archetype Biome System with RGBA Palette was introduced in Phase 9 of the Solar System voxel exploration project [S1, unofficial]. It was designed to allow 16 landable bodies to be explorable with matching voxel biomes, using 6 archetypes differentiated by per-body color, atmosphere, and physics [S1, unofficial]. The system was implemented to avoid creating a unique system per body, reducing development overhead [S1, unofficial]. The emissive RGBA palette was added to support self-illumination of lava and glowing ice, allowing Io and Europa to glow without washing out lit surfaces [S1, unofficial].
