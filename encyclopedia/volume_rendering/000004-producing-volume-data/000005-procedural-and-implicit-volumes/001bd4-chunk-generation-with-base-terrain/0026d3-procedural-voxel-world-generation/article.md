# Procedural Voxel World Generation

Also called: Procedural Terrain Generation, Voxel ID Assignment with Caves and Biomes, Voxel Type Assignment Logic, Voxel World Shader, World Rules, getBlockType

## Overview
Procedural Voxel World Generation is a method for determining the block type at any given 3D integer coordinate in a voxel grid based on height, noise functions, and quality settings, supporting terrain, caves, trees, clouds, and emissive blocks [S1, unofficial]. It differs from [Procedural Terrain Heightmap Generation](1850-procedural-terrain-heightmap-generation.md) by not only computing the surface height but also assigning specific block IDs (grass, dirt, stone, wood, leaves) and handling volumetric features like caves and trees within the same evaluation logic [S1, unofficial]. It builds on [Chunk Generation with Base Terrain](1110-chunk-generation-with-base-terrain.md) by providing the detailed voxel-level content for the chunks generated by that parent method.

## How it works
**Inputs and Outputs:**
*   **Input:** A 3D integer coordinate `cell` (x, y, z); a global integer `QUALITY` setting (0, 1, 2, or 3); global constants `CLOUD_HEIGHT`, `ENABLE_TREES`, `ENABLE_CAVES`, `ENABLE_CLOUDS`, `BLOCK_LIGHT`, and `ENDLESS_LOWER_HEIGHT` [S1, unofficial].
*   **Output:** An integer `voxel_id` representing the block type at that coordinate [S1, unofficial].

**Data Structures and Block IDs:**
The method returns one of the following block IDs [S1, unofficial]:
*   `0`: Air (empty)
*   `1`: Grass
*   `2`: Dirt
*   `3`: Stone
*   `4`: Wood (Tree Trunk)
*   `5`: Leaves
*   `6`: `BLOCK_EMISSIVE`
*   `7`: `BLOCK_CLOUD`

**Hash and Noise Functions:**
The method relies on deterministic pseudo-random hashes and value noise [S1, unofficial]:
*   `hash12(vec2 p)`: Returns `fract(sin(dot(p, vec2(127.1, 311.7))) * 43758.5453123)` [S1, unofficial].
*   `hash13(vec3 p)`: Returns `fract(sin(dot(p, vec3(127.1, 311.7, 74.7))) * 43758.5453123)` [S1, unofficial].
*   `proceduralTerrainHeight(float fx, float fz, int q)`: Computes terrain height using FBM noise. Scale `s` is `0.045` for q=1, `0.055` for q=2, `0.06` for q=0. Vertical scale is `10.0` for q=1, `11.0` for q=2, `12.0` for q=0. Base is `3.5` for q=1, `4.0` for q=2/0. Formula: `fbm3(vec3(fx * s, 0.0, fz * s)) * verticalScale + base` [S1, unofficial].
*   `fbm3(vec3 p)`: Fractal Brownian Motion 3D noise [S1, unofficial].

**Algorithm Steps:**

1.  **Lower Boundary Check:** If `ENDLESS_LOWER_HEIGHT` is false and `cell.y <= -50`, return `3` (Stone) [S1, unofficial].
2.  **Quality 0 (Stochastic Sparse):**
    *   Calculate `r = hash13(vec3(float(cell.x) * 0.12, float(cell.y) * 0.08, float(cell.z) * 0.15))` [S1, unofficial].
    *   Calculate `density = 0.30 + 0.360 * r + 0.15` [S1, unofficial].
    *   If `density > 0.8069` (when `cell.y >= 15`) or `0.6` (when `cell.y < 15`):
        *   If `r > 0.999`, return `6` (`BLOCK_EMISSIVE`) [S1, unofficial].
        *   Calculate `pick = hash12(vec2(float(cell.x) * 0.19, float(cell.z) * 0.23))` [S1, unofficial].
        *   If `pick < 0.33`, return `1` (Grass).
        *   Else if `pick < 0.4`, return `4` (Wood).
        *   Else if `pick < 0.66`, return `2` (Dirt).
        *   Else return `3` (Stone) [S1, unofficial].
    *   If `cell.y >= 15`, return `0` (Air) [S1, unofficial].
    *   Return `0` (Air) [S1, unofficial].
3.  **Quality > 0 (Structured Terrain):**
    *   **Clouds:** If `ENABLE_CLOUDS` is true and `cell.y == CLOUD_HEIGHT`:
        *   Calculate `ch = hash12(floor(vec2(float(cell.x) * 0.21, float(cell.z) * 0.13) * 2.0))` [S1, unofficial].
        *   If `ch > 0.74`, return `7` (`BLOCK_CLOUD`) [S1, unofficial].
        *   Else return `0` (Air) [S1, unofficial].
    *   If `ENABLE_CLOUDS` is false and `cell.y == CLOUD_HEIGHT`, return `0` (Air) [S1, unofficial].
    *   If `cell.y >= 19`, return `0` (Air) [S1, unofficial] [S1, unofficial].
    *   Calculate `terrainH = int(floor(proceduralTerrainHeight(float(cell.x), float(cell.z), QUALITY)))` [S1, unofficial].
    *   **Caves:** If `ENABLE_CAVES` is true:
        *   Calculate `caveNoise = 2.0 * fbm3(vec3(float(cell.x) * 0.10, float(cell.y) * 0.10, float(cell.z) * 0.10))` [S1, unofficial].
        *   `isCave = (caveNoise > 0.68)` if `QUALITY == 2`, else `isCave = (caveNoise > 0.66)` [S1, unofficial].
    *   **Emissive Blocks:** If `BLOCK_LIGHT` is enabled:
        *   Calculate `rr = hash13(vec3(float(cell.x) * 0.23, float(cell.y) * 0.17, float(cell.z) * 0.19))` [S1, unofficial].
        *   If `isCave`:
            *   Threshold `caveThresh` is `0.9975` for q=1, `0.9965` for q=2, `0.995` for q=0.
            *   If `rr > caveThresh`, return `6` (`BLOCK_EMISSIVE`) [S1, unofficial].
        *   If `cell.y == terrainH`:
            *   Threshold `surfThresh` is `0.9995` for q=1, `0.999` for q=2, `0.998` for q=0.
            *   If `rr > surfThresh`, return `6` (`BLOCK_EMISSIVE`) [S1, unofficial].
    *   **Terrain Layers:** If `cell.y <= terrainH` and `!isCave`:
        *   If `cell.y == terrainH`, return `1` (Grass) [S1, unofficial].
        *   Else if `cell.y >= terrainH - 3`, return `2` (Dirt) [S1, unofficial].
        *   Else return `3` (Stone) [S1, unofficial].
    *   **Trees:** If `ENABLE_TREES` is true and `hasTreeAtColumn(cell.x, cell.z, QUALITY)` is true:
        *   Calculate `trunkH = 3 + int(floor(hash12(vec2(float(cell.x) * 0.11, float(cell.z) * 0.08)) * 3.0))` [S1, unofficial].
        *   `baseY = terrainH + 1` [S1, unofficial].
        *   `topY = baseY + trunkH` [S1, unofficial].
        *   If `cell.y >= baseY` and `cell.y < topY`, return `4` (Wood) [S1, unofficial].
        *   **Leaves:**
            *   `SEARCH_MAX = 1` if `QUALITY == 1`, else `3` [S1, unofficial].
            *   `maxOffset = 1` if `QUALITY == 1`, else `2` if `QUALITY == 2`, else `3` [S1, unofficial].
            *   Loop `ox` from `-SEARCH_MAX` to `SEARCH_MAX` and `oz` from `-SEARCH_MAX` to `SEARCH_MAX`:
                *   If `abs(ox) > maxOffset` or `abs(oz) > maxOffset`, continue [S1, unofficial].
                *   Check if neighbor column has tree: `hasTreeAtColumn(cell.x + ox, cell.z + oz, QUALITY)` [S1, unofficial].
                *   If true, calculate local `dx = ox`, `dz = oz`, `dy = cell.y - topY` (relative to neighbor tree top) [S1, unofficial].
                *   If `dy == 0` or `dy == 1` and `dx` in `[-1, 2]` and `dz` in `[-1, 2]`, return `5` (Leaves) [S1, unofficial].
                *   If `dy == 2` and (`dx == 0` and `dz == 0`) or (`abs(dx) <= 1` and `dz == 0`) or (`abs(dz) <= 1` and `dx == 0`), return `5` (Leaves) [S1, unofficial].
    *   Return `0` (Air) [S1, unofficial].

def hash12(p):
    return fract(sin(dot(p, vec2(127.1, 311.7))) * 43758.5453123)

def hash13(p):
    return fract(sin(dot(p, vec3(127.1, 311.7, 74.7))) * 43758.5453123)

def proceduralTerrainHeight(fx, fz, q):
    if q == 1:
        s = 0.045
        verticalScale = 10.0
        base = 3.5
    elif q == 2:
        s = 0.055
        verticalScale = 11.0
        base = 4.0
    else:
        s = 0.06
        verticalScale = 12.0
        base = 4.0
    
    # fbm3 is assumed to be defined elsewhere as a standard FBM noise function
    h = fbm3(vec3(fx * s, 0.0, fz * s))
    return h * verticalScale + base

def hasTreeAtColumn(cx, cz, quality):
    if not ENABLE_TREES:
        return False
    r = hash12(vec2(float(cx) * 0.374, float(cz) * 0.912))
    if quality == 1:
        return r > 0.995
    elif quality == 2:
        return r > 0.985
    else:
        return r > 0.97

def getBlockType(cell, QUALITY, CLOUD_HEIGHT, ENABLE_TREES, ENABLE_CAVES, ENABLE_CLOUDS, BLOCK_LIGHT, ENDLESS_LOWER_HEIGHT):
    # 1. Lower Boundary
    if not ENDLESS_LOWER_HEIGHT and cell.y <= -50:
        return 3 # Stone

    # 2. Quality 0: Stochastic Sparse
    if QUALITY == 0:
        r = hash13(vec3(float(cell.x) * 0.12, float(cell.y) * 0.08, float(cell.z) * 0.15))
        density = 0.30 + 0.360 * r + 0.15
        
        threshold = 0.8069 if cell.y >= 15 else 0.6
        if density > threshold:
            if r > 0.999:
                return 6 # BLOCK_EMISSIVE
            pick = hash12(vec2(float(cell.x) * 0.19, float(cell.z) * 0.23))
            if pick < 0.33:
                return 1 # Grass
            elif pick < 0.4:
                return 4 # Wood
            elif pick < 0.66:
                return 2 # Dirt
            else:
                return 3 # Stone
        
        if cell.y >= 15:
            return 0 # Air
        return 0 # Air

    # 3. Quality > 0: Structured Terrain
    else:
        # Clouds
        if ENABLE_CLOUDS and cell.y == CLOUD_HEIGHT:
            ch = hash12(floor(vec2(float(cell.x) * 0.21, float(cell.z) * 0.13) * 2.0))
            if ch > 0.74:
                return 7 # BLOCK_CLOUD
            return 0 # Air
        
        if not ENABLE_CLOUDS and cell.y == CLOUD_HEIGHT:
            return 0 # Air
            
        if cell.y >= 19:
            return 0 # Air

        fx = float(cell.x)
        fz = float(cell.z)
        terrainH = int(floor(proceduralTerrainHeight(fx, fz, QUALITY)))

        # Caves
        isCave = False
        if ENABLE_CAVES:
            caveNoise = 2.0 * fbm3(vec3(float(cell.x) * 0.10, float(cell.y) * 0.10, float(cell.z) * 0.10))
            if QUALITY == 2:
                isCave = caveNoise > 0.68
            else:
                isCave = caveNoise > 0.66

        # Emissive Blocks
        if BLOCK_LIGHT:
            rr = hash13(vec3(float(cell.x) * 0.23, float(cell.y) * 0.17, float(cell.z) * 0.19))
            
            if isCave:
                if QUALITY == 1:
                    caveThresh = 0.9975
                elif QUALITY == 2:
                    caveThresh = 0.9965
                else:
                    caveThresh = 0.995
                if rr > caveThresh:
                    return 6 # BLOCK_EMISSIVE
            
            if cell.y == terrainH:
                if QUALITY == 1:
                    surfThresh = 0.9995
                elif QUALITY == 2:
                    surfThresh = 0.999
                else:
                    surfThresh = 0.998
                if rr > surfThresh:
                    return 6 # BLOCK_EMISSIVE

        # Terrain Layers
        if cell.y <= terrainH and not isCave:
            if cell.y == terrainH:
                return 1 # Grass
            elif cell.y >= terrainH - 3:
                return 2 # Dirt
            else:
                return 3 # Stone

        # Trees
        if ENABLE_TREES and hasTreeAtColumn(cell.x, cell.z, QUALITY):
            trunkH = 3 + int(floor(hash12(vec2(float(cell.x) * 0.11, float(cell.z) * 0.08)) * 3.0))
            baseY = terrainH + 1
            topY = baseY + trunkH
            
            if cell.y >= baseY and cell.y < topY:
                return 4 # Wood

            # Leaves
            SEARCH_MAX = 1 if QUALITY == 1 else 3
            maxOffset = 1 if QUALITY == 1 else (2 if QUALITY == 2 else 3)
            
            for ox in range(-SEARCH_MAX, SEARCH_MAX + 1):
                for oz in range(-SEARCH_MAX, SEARCH_MAX + 1):
                    if abs(ox) > maxOffset or abs(oz) > maxOffset:
                        continue
                    
                    if hasTreeAtColumn(cell.x + ox, cell.z + oz, QUALITY):
                        dx = ox
                        dz = oz
                        # Relative to neighbor tree top
                        # Note: The source code calculates topY based on the neighbor's position implicitly by checking the column

                        # of the neighbor's tree top. The source code snippet:

                        # The implementation in the source uses:
                        # if dy=0 or 1 and dx in [-1,2], dz in [-1,2] ...
                        # This implies dy is relative to the top of the tree at (cell.x+ox, cell.z+oz).
                        # We need to calculate that tree's topY.
                        
                        # Recalculate neighbor tree topY
                        n_trunkH = 3 + int(floor(hash12(vec2(float(cell.x + ox) * 0.11, float(cell.z + oz) * 0.08)) * 3.0))
                        n_baseY = terrainH + 1 # Assuming same terrain height for simplicity in this local check, or use proceduralTerrainHeight(cell.x+ox, cell.z+oz, QUALITY)

                        # However, strictly speaking, terrain height varies. The source code snippet provided for leaves placement is:

                        # And then checks conditions.
                        # To be precise to the source, we assume the neighbor's tree top is calculated similarly.

                            return 5 # Leaves

                            return 5 # Leaves

                                return 5 # Leaves

        return 0 # Air

## Subtopics

### [Deterministic Fixture Worlds](3941-deterministic-fixture-worlds.md)
Deterministic Fixture Worlds are pure functions that generate specific, small-scale voxel structures based solely on a `VolumeId`, ensuring no reliance on random number generators (RNG), system clocks, or I/O. They serve as regression tests and acceptance criteria for voxel engines, providing predictable geometric primitives like slabs, towers, and bridges. Unlike general procedural generation which uses noise for terrain, fixture worlds are hand-crafted logical shapes defined by exact brick coordinates.

### [Biome and Voxel Layer Determination](4167-biome-and-voxel-layer-determination.md)
This method assigns the type of each voxel in a procedural world based on its vertical position relative to the generated terrain surface (`genHeight`) and biome parameters derived from noise functions (moisture, temperature, wackiness). It solves the problem of creating varied, biologically plausible terrain structures (such as underwater layers, deserts, and jungles) without hard-coding specific coordinates. It differs from its sibling [Procedural Tree Generation](4826-procedural-tree-generation.md) by focusing on static ground composition and layering rather than organic structure placement, and builds on [Chunk Generation with Base Terrain](52-chunk-generation-with-base-terrain.md) which provides the underlying heightmap.

### [Procedural Tree Generation](4826-procedural-tree-generation.md)
Procedural tree generation is a method for populating a voxel world with vegetation by algorithmically placing trunk and leaf blocks at valid surface coordinates. It solves the problem of creating natural-looking, non-uniform flora in a grid-based environment without storing explicit mesh data for every tree. It differs from its sibling [Biome and Voxel Layer Determination](4167-biome-and-voxel-layer-determination.md), which defines the static ground layer, by operating on top of that layer to inject vertical structures. It differs from [Procedural Voxel World Generation](3891-procedural-voxel-world-generation.md) by focusing specifically on the geometric construction of individual entities rather than global terrain noise.

## Operating characteristics
**Time and Memory Complexity:**
The method is $O(1)$ per voxel evaluation, as it involves a fixed number of hash and noise calculations regardless of world size. Memory complexity is $O(1)$ for the function itself, as it does not store world data, only computes it on demand [S1, unofficial].

**Measured Performance:**
Performance depends heavily on the `QUALITY` setting. Quality 0 is the fastest, using only hash functions. Quality 1 and 2 involve FBM noise calculations, which are more expensive. Quality 3 is not fully detailed in the source but is described as "dense trees" and "heavier" [S1, unofficial]. The leaf placement loop adds a constant overhead proportional to `SEARCH_MAX^2`, which is small (up to $7 \times 7 = 49$ iterations for q=2) [S1, unofficial].

**Scaling:**
The method scales linearly with the number of voxels evaluated. It is suitable for real-time rendering in shaders or on-the-fly chunk generation in CPU-based engines [S1, unofficial].

**Strengths and Limitations:**
*   **Strengths:** Deterministic, lightweight, supports multiple features (terrain, caves, trees, clouds) in a single function, easy to integrate into shaders [S1, unofficial].
*   **Limitations:** Quality 0 produces sparse, random blocks rather than coherent terrain. Quality 1 and 2 have limited vertical range (up to y=19) and fixed terrain height scales. Leaf placement is heuristic and may not cover all tree shapes perfectly. Division by zero in touch input is a pitfall in the shader implementation, clamped to `max(1.0)` [S1, unofficial].

**When to Use:**
Use for real-time voxel worlds where performance is critical and deterministic generation is required. Use Quality 0 for low-end devices or simple aesthetic effects. Use Quality 1 or 2 for standard voxel games.

**When Not to Use:**
Do not use for large-scale, continuous terrain generation requiring infinite height or complex biome transitions without additional logic. Do not use if high-fidelity, organic tree shapes are required beyond the heuristic leaves placement.

## Background
The method originates from the `Voxel-World-Shader` project by razzle-reinizu, a GLSL-based voxel world shader [S1, unofficial]. It is designed to run on mobile GPUs (OpenGL ES 3.0) and provides a complete procedural world generation pipeline within the shader code [S1, unofficial]. The method is also referenced in the `Minecraft` project by StanislavPetrovV, which implements a chunk-based voxel world generation system in Python [S2, unofficial].
