# Voxel Octree Terrain Generation and Meshing

Also called: Octree Chunk Generation, Octree-based Voxel Terrain Generation

## Overview
This method generates a terrain volume by traversing a hierarchical octree structure, populating voxel grids based on procedural height maps, and converting visible chunks into triangle meshes for rendering [S1, unofficial]. It distinguishes itself from sibling methods by using an explicit, manual octree traversal with fine-grained memory pooling and generation state management, rather than relying on standard library tree structures or simple heightmap-to-mesh conversion [S1, unofficial]. It builds on [Chunk Generation with Base Terrain](1110-chunk-generation-with-base-terrain.md) by adding LOD-based hierarchical culling and meshing.

## How it works
**Inputs:** Camera position, chunk size ($CS$), maximum octree depth ($MaxDepth$), terrain LOD threshold ($lod\_thresh$), and a procedural height map function.
**Outputs:** GPU buffer handles for visible chunk meshes, updated octree node states.

**Data Structures:**
*   **Node:** Represents an octree cell. Fields include `mesh_handle` (GPU buffer handle), `generation` (uint32_t, incremented on invalidation), `flags` (bitmask), and child pointers/masks.
*   **NodeQueueItem:** Used for traversal. Fields: `node_idx` (uint32_t), `pos` (vec3), `lod` (uint32_t), `generation` (uint32_t) [S1, unofficial].
*   **HeightMap:** Cached height data for a chunk column. Accessed via a map keyed by `{x, z, lod}` [S1, unofficial].
*   **ChunkMeshUpload:** Struct for GPU upload. Fields: `stale` (bool), `staging_copy_idx` (uint32_t), `pos` (ivec4), `mult` (uint32_t, scaling factor), `vertex_counts` (array of uints) [S1, unofficial].
*   **Buffers:** `chunk_pool_` (1000 nodes), `height_map_pool_` (50000 maps), `mesh_alg_buf_` (1000), `mesher_output_data_buf_` (1000) [S1, unofficial].

**Parameters:**
*   $CS$: Chunk Size. Default 62 [S1, unofficial].
*   $MaxDepth$: Maximum octree depth. Default 5 [S1, unofficial].
*   $lod\_thresh$: LOD threshold. Default 10.0 [S1, unofficial].
*   $max\_tasks$: Number of generation tasks. $std::thread::hardware\_concurrency() \times 4$ [S1, unofficial].

**Steps:**

1.  **Initialization:** Reserve bounds, initialize task queues, pools, and buffers. Set previous camera chunk position to infinity. Initialize noise generator [S1, unofficial].
2.  **Octree Traversal (Update):**
    *   Calculate current camera chunk position: $curr\_cam\_chunk\_pos = \lfloor cam\_pos / CS \rfloor$.
    *   If chunk position changed or time since last update > 1ms, clear dirty flags and push root node to `node_queue_` [S1, unofficial].
    *   While `node_queue_` not empty:
        *   Pop `NodeQueueItem`.
        *   If node is not dirty and has no solid voxels, continue.
        *   If `ShouldMeshChunk(pos, lod)` is true:
            *   If $lod < MaxDepth$, call `FreeChildren` to clear lower levels.
            *   If node needs generation/meshing, clear flag and push to `to_mesh_queue_`.
            *   Else if $lod < MaxDepth$, iterate children, allocate if needed, and push to `node_queue_` [S1, unofficial].
3.  **Height Map Processing:**
    *   For each chunk in `to_mesh_queue_`, retrieve or allocate a height map for its `{x, z, lod}`.
    *   Calculate scale: $scale = 2^{(MaxDepth - lod)}$ [S1, unofficial].
    *   Iterate grid cells $(x, y, z)$. Calculate adjacent Y: $adj\_y = y \times scale + chunk.pos.y$.
    *   If $adj\_y < height\_map.heights[i]$, set grid cell to a color value ($lod \times 30$) [S1, unofficial].
4.  **Mesh Generation:**
    *   Dispatch tasks from `to_mesh_queue_` to `terrain_tasks_` thread pool.
    *   Worker thread:
        *   Allocate algorithm and output buffers.
        *   Call `GenerateMesh` on the populated grid.
        *   If vertex count > 0, copy vertices to staging buffer and record `staging_copy_idx` and `vert_counts` [S1, unofficial].
5.  **Mesh Upload:**
    *   Collect completed tasks.
    *   For each task, create `ChunkMeshUpload`. Set `stale = !mesh_curr_test`.
    *   If not stale, set `mult = 2^{(MaxDepth - lod)}` and add to upload list.
    *   Call `ChunkMeshManager::UploadChunkMeshes`.
    *   On success, assign `mesh_handle` to the node [S1, unofficial].
6.  **Cleanup:**
    *   Free stale meshes via `ChunkMeshManager::FreeMeshes`.
    *   Clear old height maps (age > 1000ms) from the pool [S1, unofficial].

**Pseudocode:**

```python
# Data Structures
struct NodeQueueItem:
    node_idx: uint32
    pos: vec3
    lod: uint32
    generation: uint32

struct ChunkMeshUpload:
    stale: bool
    staging_copy_idx: uint32
    pos: ivec4
    mult: uint32
    vertex_counts: array<uint, 8>

# Helper Functions
def get_offset(depth: int, CS: int) -> int:
    return (2 << (depth - 1)) * CS

def should_mesh_chunk(pos: vec3, lod: int, lod_thresh: float) -> bool:
    # Simplified logic based on distance and LOD
    return lod < lod_thresh

def free_children(node: Node, max_depth: int, target_depth: int):
    stack = [node]
    while stack:
        curr = stack.pop()
        if curr.depth != max_depth and (curr.flags & 0xFF) != 0:
            continue
        for i in range(8):
            if curr.is_set(i):
                child = curr.get_child(i)
                stack.append(NodeQueueItem(
                    node_idx=child.idx,
                    pos=curr.pos + child.offset,
                    lod=curr.lod + 1,
                    generation=curr.generation
                ))
        curr.clear_mask()
        if curr.depth != target_depth:
            if curr.mesh_handle:
                free_mesh(curr.mesh_handle)
            free_node(curr)

def reset_octree(root: Node, max_depth: int):
    node_q = [NodeQueueItem(node_idx=0, pos=vec3(0), lod=0, generation=0)]
    to_free = []
    while node_q:
        item = node_q.pop()
        node = get_node(item.node_idx)
        if node.mesh_handle:
            to_free.append(node.mesh_handle)
        if item.lod < max_depth and node.flags != 0:
            raise Error("Non-empty node at max depth")
        elif item.lod < max_depth:
            for i in range(8):
                if node.is_set(i):
                    child = node.get_child(i)
                    node_q.append(NodeQueueItem(
                        node_idx=child.idx,
                        pos=item.pos + child.offset,
                        lod=item.lod + 1,
                        generation=item.generation
                    ))
    free_meshes(to_free)
    clear_all_nodes()
    alloc_node(0)
    clear_height_maps()

def update_octree(cam_pos: vec3, CS: int, MaxDepth: int, lod_thresh: float):
    curr_cam_chunk_pos = ivec3(cam_pos) // CS
    if chunk_pos_dirty or time_since_last_update > 1ms:
        clear_dirty_flags()
        node_queue = [NodeQueueItem(node_idx=0, pos=vec3(0), lod=0, generation=0)]
        while node_queue:
            item = node_queue.pop()
            node = get_node(item.node_idx)
            if not node.dirty and node.num_solid == 0:
                continue
            if should_mesh_chunk(item.pos, item.lod, lod_thresh):
                if item.lod < MaxDepth:
                    free_children(node, MaxDepth, item.lod)
                if node.needs_gen_or_mesh:
                    node.clear_flag()
                    to_mesh_queue.append(node)
                elif item.lod < MaxDepth:
                    if node.mesh_handle:
                        meshes_to_free.append(node.mesh_handle)
                        node.needs_gen_or_mesh = True
                        node.generation += 1
                        node.mesh_handle = None
                    for i in range(8):
                        if not node.is_set(i):
                            alloc_child(node, i)
                        child = node.get_child(i)
                        node_queue.append(NodeQueueItem(
                            node_idx=child.idx,
                            pos=item.pos + child.offset,
                            lod=item.lod + 1,
                            generation=item.generation
                        ))

def process_terrain_task(chunk: Chunk):
    clear_grid(chunk.grid)
    hm = get_height_map(chunk.pos.x, chunk.pos.z, chunk.lod)
    if not hm:
        return
    scale = 1 << (MaxDepth - chunk.lod)
    color = chunk.lod * 30
    for y in range(chunk.size):
        for z in range(chunk.size):
            for x in range(chunk.size):
                adj_y = y * scale + chunk.pos.y
                if adj_y < hm.heights[x * chunk.size + z]:
                    chunk.grid.set(x, y, z, color)

def process_mesh_gen_task(chunk: Chunk):
    alg_data = alloc_alg_buffer()
    data = alloc_output_buffer()
    alg_data.mask = compute_mask(chunk.grid)
    vert_count = generate_mesh(chunk.grid.grid, alg_data, data)
    if vert_count > 0:
        staging_idx = copy_to_staging(data, vert_count)
        task.vert_counts = get_face_vertex_lengths(data)
        task.staging_copy_idx = staging_idx

def upload_meshes(uploads: list[ChunkMeshUpload]):
    if not uploads:
        return
    reserve_upload_buffer()
    handles = upload_chunk_meshes(uploads)
    j = 0
    for upload in uploads:
        if not upload.stale:
            node = get_node_by_pos(upload.pos)
            node.mesh_handle = handles[j]
            j += 1
    clear_upload_buffers()

def clear_old_height_maps():
    lock_mutex(height_map_mtx)
    now = get_time()
    for key, hm in height_maps.items():
        if now - hm.access_time > 1000ms:
            free_pool_handle(hm)
            height_maps.erase(key)
        else:
            hm.access_time = now
    unlock_mutex(height_map_mtx)
```

## Subtopics

### Procedural Terrain Heightmap Generation
Generates the base height data used by this method. Choose when you need simple 2D height maps instead of full volumetric noise. [Procedural Terrain Heightmap Generation](1850-procedural-terrain-heightmap-generation.md)

### Voxel Evaluation with AABB Culling
Provides the culling logic for determining if a chunk is visible. Choose when you need efficient frustum/culling checks before traversal. [Voxel Evaluation with AABB Culling](2415-voxel-evaluation-with-aabb-culling.md)

### Chunk-Based Voxel Terrain Generation
A simpler, flat-chunk approach. Choose this when you do not need hierarchical LOD or octree memory savings. [Chunk-Based Voxel Terrain Generation](4140-chunk-based-voxel-terrain-generation.md)

## Operating characteristics
*   **Time Complexity:** Traversal is $O(N)$ where $N$ is the number of visible nodes. Mesh generation is proportional to the surface area of the chunk.
*   **Memory Complexity:** $O(2^{3 \times MaxDepth})$ in the worst case, but significantly reduced by sparse storage and pooling. The source uses pools for nodes (1000), height maps (50000), and mesh buffers (1000) [S1, unofficial].
*   **Performance:** Before optimization, mean chunk draw GPU time was 1.31ms [S1, unofficial].
*   **Strengths:** Fine-grained control over memory and generation state via manual octree management. Efficient LOD culling.
*   **Limitations:** Complex implementation. Stale mesh handling requires careful state tracking to avoid GPU errors [S1, unofficial].
*   **When to use:** Large terrains requiring LOD and efficient memory usage.
*   **When not to use:** Small, static terrains where a flat grid suffices.

## Background
This method originates from the `vulkan_voxels` project by tonadr1022, a Vulkan-based voxel renderer [S1, unofficial]. It was developed to provide a performant, hierarchical terrain system for real-time rendering, leveraging Vulkan's compute and transfer capabilities for mesh generation and upload.
