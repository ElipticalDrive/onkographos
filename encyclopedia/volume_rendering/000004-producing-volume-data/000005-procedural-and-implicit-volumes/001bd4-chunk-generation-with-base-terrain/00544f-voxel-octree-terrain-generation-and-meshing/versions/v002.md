# Voxel Octree Terrain Generation and Meshing

Also called: Octree Chunk Generation, Octree-based Voxel Terrain Generation

## Overview
This method generates a sparse voxel terrain representation by recursively subdividing an octree based on surface intersection tests, solving the problem of efficiently managing memory for procedural terrain by only allocating nodes that contain or intersect the terrain surface [S1, unofficial]. It differs from dense voxelization by using adaptive depth, though this introduces specific edge cases regarding noise-induced gaps that require careful handling of subdivision criteria [S1, unofficial]. It builds on [Chunk Generation with Base Terrain](1110-chunk-generation-with-base-terrain.md) by introducing explicit octree traversal and LOD-based meshing.

## How it works
**Inputs:** Camera position, chunk size ($CS$), maximum octree depth ($MaxDepth$), terrain generation task pool size, and a noise function for height evaluation.
**Outputs:** A set of GPU-uploaded mesh handles for visible chunks, associated with octree nodes.

**Data Structures:**
*   **Node:** Represents an octree cell. Fields include `mesh_handle` (GPU buffer offset), `generation` (integrity counter), `flags` (state bits), and child pointers/masks.
*   **NodeQueueItem:** Used for traversal. Fields: `node_idx` (`uint32_t`), `pos` (`vec3`), `lod` (`uint32_t`), `generation` (`uint32_t`).
*   **HeightMapPool:** Maps `{x, z, lod}` to height data. Protected by `height_map_mtx_`.
*   **ChunkMeshManager:** Manages GPU buffer allocations (`chunk_quad_buffer_`) and staging transfers.
*   **Terrain Tasks:** Thread pool for parallel mesh generation.

**Parameters:**
*   $CS$: Chunk Size (e.g., 62).
*   $MaxDepth$: Maximum octree depth (e.g., 5).
*   $lod\_thresh$: LOD threshold (default 10.0) [S1, unofficial].
*   $max\_tasks$: Number of generation threads, calculated as `std::thread::hardware_concurrency() * 4` [S1, unofficial].

**Steps:**

1.  **Initialization:**
    *   Reserve `lod_bounds_` for $MaxDepth$.
    *   Initialize `terrain_tasks_` with $max\_tasks$.
    *   Initialize `chunk_pool_` (size 1000), `height_map_pool_` (size 50000), `mesh_alg_buf_` (size 1000), and `mesher_output_data_buf_` (size 1000) [S1, unofficial].
    *   Set `prev_cam_chunk_pos_` to `ivec3{INT_MAX}`.
    *   Allocate root node at depth 0.

2.  **Octree Traversal (Update Phase):**
    *   Calculate `new_cam_chunk_pos` = `ivec3(cam_pos) / CS`.
    *   If `chunk_pos_dirty` (camera moved to new chunk):
        *   Clear `node_queue_`.
        *   Push root node to `node_queue_` with `lod=0`, `pos=vec3{0}`, `generation=0`.
        *   While `node_queue_` is not empty:
            *   Pop `item`. Get `node`.
            *   If `node` is not dirty and `num_solid == 0`, continue.
            *   If `ShouldMeshChunk(pos, lod)` is true:
                *   If $lod < MaxDepth$, call `FreeChildren(node)`.
                *   If node needs generation/meshing: clear flag, push to `to_mesh_queue_`.
                *   Else if $lod < MaxDepth$:
                    *   If `mesh_handle` exists, add to `meshes_to_free`, set `needs_gen/meshing` true, increment `generation`, clear `mesh_handle`.
                    *   Iterate children (x,y,z from 0 to 1). If child is set, allocate if needed, push to `node_queue_`.
            *   Else if $lod < MaxDepth$:
                *   Iterate children. If child is set, push to `node_queue_`.

3.  **FreeChildren (Recursive Cleanup):**
    *   Push `node` to `child_free_stack_`.
    *   While stack not empty:
        *   Pop `item`. Get `node`.
        *   Assert $depth \neq MaxDepth$ or low byte of `flags` is 0.
        *   Iterate $i$ from 0 to 7 (children).
        *   If `node->IsSet(i)`:
            *   Push child to stack with updated `pos`, $depth+1$, and `generation`.
        *   Clear `node` mask.
        *   If $depth \neq target\_depth$, free mesh if `handle` exists, then `FreeNode`.

4.  **Mesh Processing (Task Dispatch & Execution):**
    *   Dispatch tasks from `to_mesh_queue_` to `terrain_tasks_`.
    *   For each completed task:
        *   Decrement `InFlight`.
        *   Get `chunk`.
        *   Check `MeshCurrTest`.
        *   If `vert_count > 0`:
            *   Create `ChunkMeshUpload`.
            *   Set `stale = !mesh_curr_test`.
            *   Set `staging_copy_idx`.
            *   If not stale, `memcpy` `vert_counts`, set `pos`, set `mult = 1 << (MaxDepth - lod)`.
            *   Add to `chunk_mesh_uploads_` and `chunk_mesh_node_keys_`.

5.  **Height Map Evaluation (ProcessTerrainTask):**
    *   Get `chunk`. Clear grid.
    *   Get `height_map` for `{chunk.pos.x, chunk.pos.z, lod}`.
    *   If not in range, return.
    *   Set `color = lod * 30`.
    *   Set `scale = 1 << (MaxDepth - lod)`.
    *   Iterate $y, z, x$:
        *   Calculate `adj_y = y * scale + chunk.pos.y`.
        *   If `adj_y < hm.heights[i]`, set `grid` cell to `color`.

6.  **Mesh Generation (ProcessMeshGenTask):**
    *   Get `chunk`. Allocate `alg_data` and `data` from buffers.
    *   Set `alg_data->mask`.
    *   Call `GenerateMesh(chunk.grid.grid.grid, *alg_data, *data)`.
    *   Set `task.vert_count`.
    *   If `vertex_count > 0`:
        *   Copy vertices to staging buffer, get `staging_copy_idx`.
        *   Copy `face_vertex_lengths` to `task.vert_counts`.

7.  **Mesh Upload:**
    *   Assert sizes match.
    *   If uploads exist: reserve `mesh_handle_upload_buffer_`.
    *   Call `ChunkMeshManager::UploadChunkMeshes`.
    *   Iterate uploads: if not stale, get `node`, set `node->mesh_handle = buffer[j]`, increment $j$.
    *   Clear buffers.

8.  **Cleanup:**
    *   If `meshes_to_free_` not empty, call `ChunkMeshManager::FreeMeshes`, clear vector.
    *   If time since last cleanup > 1000ms: call `ClearOldHeightMaps`.
    *   `ClearOldHeightMaps`: Lock mutex. Iterate `height_maps_`. If age > 1000ms, free pool handle, erase from map. Else, increment iterator.

**Pseudocode:**

```python
def update_octree(renderer, camera_pos, chunk_size, max_depth):
    new_cam_chunk_pos = ivec3(camera_pos) / chunk_size
    if new_cam_chunk_pos != renderer.prev_cam_chunk_pos_:
        renderer.chunk_pos_dirty = True
        renderer.prev_cam_chunk_pos_ = new_cam_chunk_pos

    if renderer.chunk_pos_dirty:
        renderer.chunk_pos_dirty = False
        node_queue = []
        node_queue.append(NodeQueueItem(node_idx=0, pos=vec3(0,0,0), lod=0, generation=0))
        
        while node_queue:
            item = node_queue.pop(0)
            node = renderer.get_node(item.node_idx)
            
            if not node.dirty and node.num_solid == 0:
                continue
                
            if should_mesh_chunk(item.pos, item.lod):
                if item.lod < max_depth:
                    free_children(node, item.lod)
                
                if node.needs_gen_or_meshing:
                    node.flags &= ~NEEDS_GEN_MESHING
                    renderer.to_mesh_queue_.append(node)
                elif item.lod < max_depth:
                    if node.mesh_handle:
                        renderer.meshes_to_free_.append(node.mesh_handle)
                        node.mesh_handle = None
                        node.generation += 1
                        node.needs_gen_or_meshing = True
                    
                    for i in range(8):
                        if node.is_set(i):
                            child = get_or_alloc_child(node, i)
                            node_queue.append(NodeQueueItem(
                                node_idx=child.idx, 
                                pos=item.pos + child_offset(i), 
                                lod=item.lod + 1, 
                                generation=node.generation
                            ))
            elif item.lod < max_depth:
                for i in range(8):
                    if node.is_set(i):
                        child = get_or_alloc_child(node, i)
                        node_queue.append(NodeQueueItem(
                            node_idx=child.idx, 
                            pos=item.pos + child_offset(i), 
                            lod=item.lod + 1, 
                            generation=node.generation
                        ))

def process_mesh_task(chunk, max_depth):
    grid = chunk.grid
    height_map = get_height_map(chunk.pos.x, chunk.pos.z, chunk.lod)
    if not height_map:
        return
    
    scale = 1 << (max_depth - chunk.lod)
    color = chunk.lod * 30
    
    for y in range(chunk.size):
        for z in range(chunk.size):
            for x in range(chunk.size):
                adj_y = y * scale + chunk.pos.y
                if adj_y < height_map.heights[x, z]:
                    grid.set(x, y, z, color)

def generate_mesh(chunk, alg_data, data):
    alg_data.mask = 0xFF
    vert_count = generate_mesh_from_grid(chunk.grid.grid.grid, alg_data, data)
    if vert_count > 0:
        copy_to_staging(data.vertices, vert_count)
        return vert_count, data.face_vertex_lengths
    return 0, []

def free_children(node, target_depth):
    stack = [node]
    while stack:
        curr = stack.pop()
        if curr.depth == target_depth and (curr.flags & 0x01):
            continue
        
        for i in range(8):
            if curr.is_set(i):
                child = curr.get_child(i)
                stack.append(child)
        
        curr.clear_mask()
        if curr.depth != target_depth:
            if curr.mesh_handle:
                free_gpu_mesh(curr.mesh_handle)
            free_node(curr)
```

### [Octree-based Voxel Terrain Voxelization](17471-octree-based-voxel-terrain-voxelization.md)
Constructs a voxel terrain representation by recursively subdividing an octree based on surface intersection tests. It solves the problem of efficiently generating a sparse voxel grid for procedural terrain by only allocating memory for nodes that contain or intersect the terrain surface, rather than filling a dense volume. It differs from dense voxelization by using adaptive depth, though this introduces specific edge cases regarding noise-induced gaps that require careful handling of subdivision criteria.

## Operating characteristics
*   **Time Complexity:** Traversal is proportional to the number of visible nodes. Mesh generation is parallelized via `terrain_tasks_` (size $max\_tasks$).
*   **Memory Complexity:** Sparse. Only nodes intersecting the surface or below are allocated. `chunk_pool_` (1000), `height_map_pool_` (50000) provide pre-allocated buffers.
*   **Performance:** Before optimization, mean chunk draw GPU time was 1.31ms [S1, unofficial].
*   **Strengths:** Efficient memory usage for large terrains; adaptive LOD; explicit control over memory pooling and generation state via manual octree traversal [S1, unofficial].
*   **Limitations:** Requires careful handling of stale meshes and concurrency (height map access protected by mutex); noise-induced gaps may require specific subdivision criteria [S1, unofficial].
*   **When to use:** Large-scale procedural terrain where memory efficiency and LOD are critical.
*   **When not to use:** Small, dense voxel worlds where overhead of octree management outweighs benefits.

## Background
This method is derived from a Vulkan-based voxel renderer implementation [S1, unofficial]. It utilizes a manual octree traversal with explicit child management (`IsSet`, `SetData`) rather than a standard library tree, allowing fine-grained control over memory pooling and generation state [S1, unofficial]. The implementation includes a `ChunkMeshManager` for GPU buffer management and a thread pool for terrain generation tasks.
