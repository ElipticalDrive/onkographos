# Voxel Octree Terrain Generation and Meshing

Also called: Octree Chunk Generation, Octree-based Voxel Terrain Generation

## Overview
This method generates a sparse voxel terrain representation by managing terrain chunks via an octree structure, generating height maps, populating voxel grids based on height, and generating triangle meshes for visible chunks using a multi-threaded task system [S1, unofficial]. It builds on [Chunk Generation with Base Terrain](1110-chunk-generation-with-base-terrain.md) by introducing explicit octree traversal and LOD-based meshing [S1, unofficial].

## How it works
**Inputs:** Camera position, chunk size ($CS$), maximum octree depth ($MaxDepth$), terrain generation task pool size, and a noise function for height evaluation [S1, unofficial].
**Outputs:** A set of GPU-uploaded mesh handles for visible chunks, associated with octree nodes [S1, unofficial].

**Data Structures:**
*   **Node:** Represents an octree cell. Fields include `mesh_handle` (GPU buffer offset), `generation` (integrity counter), `flags` (state bits), and child pointers/masks [S1, unofficial].
*   **NodeQueueItem:** Used for traversal. Fields: `node_idx` (`uint32_t`), `pos` (`vec3`), `lod` (`uint32_t`), `generation` (`uint32_t`) [S1, unofficial].
*   **HeightMapPool:** Maps `{x, z, lod}` to height data. Protected by `height_map_mtx_` [S1, unofficial].
*   **ChunkMeshManager:** Manages GPU buffer allocations (`chunk_quad_buffer_`) and staging transfers [S1, unofficial].
*   **Terrain Tasks:** Thread pool for parallel mesh generation [S1, unofficial].

**Parameters:**
*   $CS$: Chunk Size (e.g., 62) [S1, unofficial].
*   $MaxDepth$: Maximum octree depth (e.g., 5) [S1, unofficial].
*   $lod\_thresh$: LOD threshold (default 10.0) [S1, unofficial].
*   $max\_tasks$: Number of generation threads, calculated as `std::thread::hardware_concurrency() * 4` [S1, unofficial].

**Steps:**

1.  **Initialization:** Reserve `lod_bounds_` for $MaxDepth$. Initialize `terrain_tasks_` with $max\_tasks$. Initialize `chunk_pool_` (size 1000), `height_map_pool_` (size 50000), `mesh_alg_buf_` (size 1000), and `mesher_output_data_buf_` (size 1000) [S1, unofficial]. Set `prev_cam_chunk_pos_` to `ivec3{INT_MAX}`. Call `FreeChildren` and `Reset` during updates [S1, unofficial].
2.  **Octree Traversal:** Clear `node_queue_`. Set `curr_cam_pos_`. Calculate `new_cam_chunk_pos = ivec3(cam_pos) / CS`. Check `chunk_pos_dirty`. If time > 1ms and `to_mesh_queue_` empty: set `last_octree_update_time_`. If `chunk_pos_dirty`: clear flag. Push root (`0`, `vec3{0}`, `0`, `generation`) to `node_queue_`. Loop while queue not empty: pop item. Get node. Assert node. If node not dirty and `num_solid == 0`, continue. If `ShouldMeshChunk(pos, lod)`: if $lod < MaxDepth$, `FreeChildren`. Get node. If needs gen/meshing, clear flag, push to `to_mesh_queue_`. Else if $lod < MaxDepth$: if `mesh_handle` exists, add to `meshes_to_free`, set needs gen/meshing true, increment generation, clear `mesh_handle`. Iterate children, allocate if needed, push to `node_queue_` [S1, unofficial].
3.  **Mesh Processing:** Dispatch tasks. Loop through `terrain_tasks_.done_tasks`: dequeue task. Dec `InFlight`. Get chunk. Check `MeshCurrTest`. If `vert_count > 0`: create `ChunkMeshUpload`. Set `stale = !mesh_curr_test`. Set `staging_copy_idx`. If not stale, `memcpy` `vert_counts`, set `pos`, set `mult = 1 << (MaxDepth - lod)`. Add to `chunk_mesh_uploads_` and `chunk_mesh_node_keys_` [S1, unofficial].
4.  **Mesh Upload:** Assert sizes match. If uploads exist: reserve `mesh_handle_upload_buffer_`. Call `ChunkMeshManager::UploadChunkMeshes`. Iterate uploads: if not stale, get node, set `node->mesh_handle = buffer[j]`, increment $j$. Clear buffers [S1, unofficial].
5.  **Free Meshes:** If `meshes_to_free_` not empty, call `ChunkMeshManager::FreeMeshes`, clear vector [S1, unofficial].
6.  **Height Map Cleanup:** If time since last cleanup > 1000ms: call `ClearOldHeightMaps`, update last time [S1, unofficial].
7.  **ClearOldHeightMaps:** Lock mutex. Iterate `height_maps_`. If age > 1000ms: free pool handle, erase from map. Else: increment iterator [S1, unofficial].
8.  **ProcessTerrainTask:** Get chunk. Clear grid. Get height map. If not in range, return. Set `color = lod * 30`. Set `scale = 1 << (MaxDepth - lod)`. Iterate $y, z, x$. Calculate `adj_y = y * scale + chunk.pos.y`. If `adj_y < hm.heights[i]`, set grid cell to `color` [S1, unofficial].
9.  **ProcessMeshGenTask:** Get chunk. Allocate `alg_data` and `data` from buffers. Set `alg_data->mask`. Call `GenerateMesh(chunk.grid.grid.grid, *alg_data, *data)`. Set `task.vert_count`. If vertex count > 0: copy vertices to staging buffer, get `staging_copy_idx`. Copy `face_vertex_lengths` to `task.vert_counts` [S1, unofficial].
10. **GetHeightMap:** Lock mutex. Search map by `{x, z, lod}`. If found, update access time, return map. Else: alloc handle from pool. Get map. Calculate `scale = 1 << (MaxDepth - lod)` [S1, unofficial].

**Pitfalls:**
*   Stale Meshes: If a mesh is generated but the node becomes stale (e.g., LOD change or culling), the mesh handle must be freed and the node marked for regeneration. The code tracks this via `stale` flag in `ChunkMeshUpload` and `mesh_handle` reset [S1, unofficial].
*   Concurrency: Height map access is protected by `height_map_mtx_`. Mesh generation tasks use a thread pool (`terrain_tasks_`) [S1, unofficial].

**Pseudocode:**

```python
from dataclasses import dataclass
from typing import List, Optional, Tuple

@dataclass
class NodeQueueItem:
    node_idx: int
    pos: Tuple[float, float, float]
    lod: int
    generation: int

@dataclass
class Chunk:
    pos: Tuple[float, float, float]
    lod: int
    grid: List[List[List[int]]]
    mesh_handle: Optional[int] = None
    generation: int = 0
    flags: int = 0
    dirty: bool = False
    num_solid: int = 0
    needs_gen_or_meshing: bool = False
    is_set: List[bool] = None

    def __post_init__(self):
        if self.is_set is None:
            self.is_set = [False] * 8

class VoxelRenderer:
    def __init__(self, max_depth: int, chunk_size: int):
        self.max_depth = max_depth
        self.chunk_size = chunk_size
        self.prev_cam_chunk_pos = (float('inf'), float('inf'), float('inf'))
        self.chunk_pos_dirty = False
        self.node_queue: List[NodeQueueItem] = []
        self.to_mesh_queue: List[Chunk] = []
        self.meshes_to_free: List[int] = []
        self.chunk_mesh_uploads: List[dict] = []
        self.chunk_mesh_node_keys: List[int] = []
        self.height_maps: dict = {}
        self.last_cleanup_time = 0
        self.last_octree_update_time = 0
        self.nodes: dict = {0: Chunk(pos=(0,0,0), lod=0, grid=[[[0]]])}

    def update_octree(self, camera_pos: Tuple[float, float, float], time_ms: int):
        new_cam_chunk_pos = (camera_pos[0] // self.chunk_size, camera_pos[1] // self.chunk_size, camera_pos[2] // self.chunk_size)
        if new_cam_chunk_pos != self.prev_cam_chunk_pos:
            self.chunk_pos_dirty = True
            self.prev_cam_chunk_pos = new_cam_chunk_pos

        if time_ms - self.last_octree_update_time > 1 and not self.to_mesh_queue:
            self.last_octree_update_time = time_ms

        if self.chunk_pos_dirty:
            self.chunk_pos_dirty = False
            self.node_queue = []
            self.node_queue.append(NodeQueueItem(node_idx=0, pos=(0,0,0), lod=0, generation=0))

            while self.node_queue:
                item = self.node_queue.pop(0)
                node = self.nodes[item.node_idx]

                if not node.dirty and node.num_solid == 0:
                    continue

                if self.should_mesh_chunk(item.pos, item.lod):
                    if item.lod < self.max_depth:
                        self.free_children(item.node_idx, item.lod)
                        node = self.nodes[item.node_idx]

                    if node.needs_gen_or_meshing:
                        node.flags &= ~0x01
                        self.to_mesh_queue.append(node)
                    elif item.lod < self.max_depth:
                        if node.mesh_handle is not None:
                            self.meshes_to_free.append(node.mesh_handle)
                            node.mesh_handle = None
                            node.generation += 1
                            node.needs_gen_or_meshing = True

                        for i in range(8):
                            if node.is_set[i]:
                                child_idx = self.get_or_alloc_child(item.node_idx, i)
                                child_pos = (item.pos[0] + (i & 1) * (self.chunk_size >> (item.lod + 1)),
                                             item.pos[1] + ((i >> 1) & 1) * (self.chunk_size >> (item.lod + 1)),
                                             item.pos[2] + ((i >> 2) & 1) * (self.chunk_size >> (item.lod + 1)))
                                self.node_queue.append(NodeQueueItem(node_idx=child_idx, pos=child_pos, lod=item.lod + 1, generation=node.generation))
                elif item.lod < self.max_depth:
                    for i in range(8):
                        if node.is_set[i]:
                            child_idx = self.get_or_alloc_child(item.node_idx, i)
                            child_pos = (item.pos[0] + (i & 1) * (self.chunk_size >> (item.lod + 1)),
                                         item.pos[1] + ((i >> 1) & 1) * (self.chunk_size >> (item.lod + 1)),
                                         item.pos[2] + ((i >> 2) & 1) * (self.chunk_size >> (item.lod + 1)))
                            self.node_queue.append(NodeQueueItem(node_idx=child_idx, pos=child_pos, lod=item.lod + 1, generation=node.generation))

    def free_children(self, node_idx: int, target_depth: int):
        stack = [(node_idx, self.nodes[node_idx].lod, self.nodes[node_idx].generation)]
        while stack:
            curr_idx, depth, gen = stack.pop()
            curr = self.nodes[curr_idx]
            if depth == self.max_depth and (curr.flags & 0x01):
                continue

            for i in range(8):
                if curr.is_set[i]:
                    child_idx = self.get_or_alloc_child(curr_idx, i)
                    stack.append((child_idx, depth + 1, gen))

            curr.is_set = [False] * 8
            if depth != target_depth:
                if curr.mesh_handle is not None:
                    self.free_gpu_mesh(curr.mesh_handle)
                self.free_node(curr_idx)

    def process_terrain_task(self, chunk: Chunk):
        for y in range(len(chunk.grid)):
            for z in range(len(chunk.grid[0])):
                for x in range(len(chunk.grid[0][0])):
                    chunk.grid[y][z][x] = 0

        hm = self.get_height_map(chunk.pos[0], chunk.pos[2], chunk.lod)
        if not hm:
            return

        color = chunk.lod * 30
        scale = 1 << (self.max_depth - chunk.lod)

        for y in range(len(chunk.grid)):
            for z in range(len(chunk.grid[0])):
                for x in range(len(chunk.grid[0][0])):
                    adj_y = y * scale + chunk.pos[1]
                    if adj_y < hm.heights[x]:
                        chunk.grid[y][z][x] = color

    def process_mesh_gen_task(self, chunk: Chunk):
        alg_data = {"mask": 0xFF}
        data = {"vertices": [], "face_vertex_lengths": []}
        vert_count = self.generate_mesh_from_grid(chunk.grid, alg_data, data)
        chunk.task_vert_count = vert_count
        if vert_count > 0:
            chunk.staging_copy_idx = self.copy_to_staging(data["vertices"], vert_count)
            chunk.task_vert_counts = data["face_vertex_lengths"]
        return chunk

    def upload_meshes(self):
        if not self.chunk_mesh_uploads:
            return
        j = 0
        for upload in self.chunk_mesh_uploads:
            if not upload["stale"]:
                node = self.nodes[upload["node_idx"]]
                node.mesh_handle = j
                j += 1
        self.chunk_mesh_uploads = []
        self.chunk_mesh_node_keys = []

    def free_meshes(self):
        if self.meshes_to_free:
            for h in self.meshes_to_free:
                self.free_gpu_mesh(h)
            self.meshes_to_free = []

    def clear_old_height_maps(self, time_ms: int):
        if time_ms - self.last_cleanup_time > 1000:
            self.last_cleanup_time = time_ms
            keys_to_remove = [k for k, v in self.height_maps.items() if time_ms - v["access_time"] > 1000]
            for k in keys_to_remove:
                self.free_height_map_pool_handle(k)
                del self.height_maps[k]

    def get_height_map(self, x: float, z: float, lod: int):
        key = (x, z, lod)
        if key in self.height_maps:
            self.height_maps[key]["access_time"] = 0
            return self.height_maps[key]["map"]
        handle = self.alloc_height_map_pool_handle()
        scale = 1 << (self.max_depth - lod)
        self.height_maps[key] = {"map": {"heights": [0]}, "access_time": 0, "handle": handle}
        return self.height_maps[key]["map"]

    def should_mesh_chunk(self, pos, lod): return True
    def get_or_alloc_child(self, parent_idx, i): return parent_idx * 8 + i + 1
    def free_gpu_mesh(self, handle): pass
    def free_node(self, idx): del self.nodes[idx]
    def generate_mesh_from_grid(self, grid, alg_data, data): return 10
    def copy_to_staging(self, verts, count): return 0
    def alloc_height_map_pool_handle(self): return 0
    def free_height_map_pool_handle(self, key): pass
```

## Subtopics

### [Octree-based Voxel Terrain Voxelization](17471-octree-based-voxel-terrain-voxelization.md)
Constructs a voxel terrain representation by recursively subdividing an octree based on surface intersection tests. It solves the problem of efficiently generating a sparse voxel grid for procedural terrain by only allocating memory for nodes that contain or intersect the terrain surface, rather than filling a dense volume. It differs from dense voxelization by using adaptive depth, though this introduces specific edge cases regarding noise-induced gaps that require careful handling of subdivision criteria.

## Operating characteristics
*   **Time Complexity:** Traversal is proportional to the number of visible nodes. Mesh generation is parallelized via `terrain_tasks_` (size $max\_tasks$) [S1, unofficial].
*   **Memory Complexity:** Sparse. Only nodes intersecting the surface or below are allocated. `chunk_pool_` (1000), `height_map_pool_` (50000) provide pre-allocated buffers [S1, unofficial].
*   **Performance:** Before optimization, mean chunk draw GPU time was 1.31ms [S1, unofficial].
*   **Strengths:** Efficient memory usage for large terrains; adaptive LOD; explicit control over memory pooling and generation state via manual octree traversal [S1, unofficial].
*   **Limitations:** Requires careful handling of stale meshes and concurrency (height map access protected by mutex) [S1, unofficial].
*   **When to use:** Large-scale procedural terrain where memory efficiency and LOD are critical [S1, unofficial].
*   **When not to use:** Small, dense voxel worlds where overhead of octree management outweighs benefits [G].

## Background
This method is derived from a Vulkan-based voxel renderer implementation [S1, unofficial]. It utilizes a manual octree traversal with explicit child management (`IsSet`, `SetData`) rather than a standard library tree, allowing fine-grained control over memory pooling and generation state [S1, unofficial]. The implementation includes a `ChunkMeshManager` for GPU buffer management and a thread pool for terrain generation tasks [S1, unofficial].
