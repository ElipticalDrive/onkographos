# Chunk Redundancy for Seamless Normals


## Overview
This method generates chunks with redundant voxels beyond their render bounds to allow seamless normal calculation inside the shader [S1, unofficial]. It enables parallel chunk production without seams by expanding the generation domain relative to the rendering domain [S1, unofficial].

## How it works
**Inputs:**
*   Chunk ID and global seed for deterministic procedural generation [S1, unofficial].
*   Render bounds for the current chunk [S1, unofficial].
*   Redundancy factor $R$ [S1, unofficial].

**Outputs:**
*   A voxel grid containing density and material data [S1, unofficial].
*   Normal vectors calculated per-voxel inside the shader [S1, unofficial].

**Data Structures:**
*   **Voxel Grid:** A 3D array or 3D texture [G].
*   **Dimensions:** The grid dimensions $D_{gen}$ are scaled by a redundancy factor $R$ relative to the render dimensions $D_{render}$ [S1, unofficial].
    $$ D_{gen} = \lceil R \times D_{render} \rceil $$
    Typical value for $R$ is 1.25 [S1, unofficial].

**Steps:**
1.  **Generate Voxels:** Generate voxels for each chunk at $R$ times the render dimensions [S1, unofficial].
2.  **Render Pass:** Render only within the chunk's original bounds [S1, unofficial].
3.  **Normal Calculation:** Calculate normals seamlessly inside the shader using the redundant voxels [S1, unofficial].

**Pseudocode:**
```python
def generate_chunk(chunk_id, render_w, render_h, render_d, redundancy_factor=1.25):
    # 1. Calculate expanded dimensions
    gen_w = int(render_w * redundancy_factor)
    gen_h = int(render_h * redundancy_factor)
    gen_d = int(render_d * redundancy_factor)
    
    # 2. Initialize voxel grid
    voxel_grid = [[[None for _ in range(gen_w)] for _ in range(gen_h)] for _ in range(gen_d)]
    
    # 3. Evaluate procedural function for all voxels in generation bounds
    for z in range(gen_d):
        for y in range(gen_h):
            for x in range(gen_w):
                # Map local voxel coordinate to world/object space [G]
                world_pos = (x, y, z)
                # Evaluate density and material deterministically based on chunk ID and seed [G]
                density = 0.0
                material = 0.0
                voxel_grid[z][y][x] = (density, material)
                
    return voxel_grid, gen_w, gen_h, gen_d

def calculate_normal(voxel_grid, x, y, z):
    # 5. Seamless normal calculation using redundant data
    # Sample neighbors. Because grid is oversized, neighbors at boundary
    # are valid data from the overlapping generation region [S1, unofficial].
    dx = voxel_grid[z][y][x + 1][0] - voxel_grid[z][y][x - 1][0]
    dy = voxel_grid[z][y + 1][x][0] - voxel_grid[z][y - 1][x][0]
    dz = voxel_grid[z + 1][y][x][0] - voxel_grid[z - 1][y][x][0]
    length = (dx*dx + dy*dy + dz*dz)**0.5
    normal = (dx/length, dy/length, dz/length)
    return normal
```

## Subtopics

### Toroidal Volume Tiling
This variant applies to volumetric fur or microgeometry where the volume wraps around a model surface [S2, unofficial]. Instead of spatial redundancy, it tiles the volume toroidally across the UV map of the model to ensure seamless projection without seams [S2, unofficial]. It requires careful generation to avoid boundary artifacts and relies on UV mapping that minimizes distortion to ensure smooth fur without local distortions [S2, unofficial].

## Operating characteristics
Parallel chunk generation is enabled [S1, unofficial]. The redundancy factor trades seamlessness for performance [S1, unofficial]. Not given in the sources.

## Background
This method was described in the context of the VoxelQuest engine, where it was used to generate seamless normals for procedural chunks in a top-down voxel generation pipeline [S1, unofficial]. The approach leverages the deterministic nature of procedural generation to allow overlapping generation domains [S1, unofficial].
