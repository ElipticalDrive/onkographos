# Chi-Square Goodness-of-Fit Test for Noise

Also called: Chi-Square Goodness-of-Fit Test for Noise Quality, Chi-Square Noise Quality Metric

## Overview
The Chi-Square Goodness-of-Fit Test for Noise is a statistical method used to measure the quality of the amplitude distribution of a procedural noise function [S1, S2]. It operates by comparing the histogram of sampled noise values against an expected theoretical distribution (typically Gaussian) [S1]. It is distinguished from sibling methods like the Autocorrelation Periodicity Test and Band-Pass Test by focusing exclusively on the statistical fidelity of the amplitude values rather than spatial frequency characteristics or periodicity [S1, S2].

## How it works
**Inputs and Outputs:**
*   **Input:** A set of $N$ noise samples $\{x_1, x_2, \dots, x_N\}$ drawn from the noise function.
*   **Input:** A target probability distribution (typically Gaussian) with mean $\mu$ and variance $\sigma^2$ [S1].
*   **Output:** A chi-square statistic $\chi^2$ indicating the deviation between the observed histogram and the expected distribution.

**Data Structures:**
*   **Histogram:** A binning of the noise samples. Let $B$ be the number of bins.
*   **Observed Counts:** An array $O_i$ for $i=1 \dots B$, where $O_i$ is the count of samples falling into bin $i$.
*   **Expected Counts:** An array $E_i$ for $i=1 \dots B$, where $E_i$ is the expected number of samples in bin $i$ based on the target distribution.

**Steps:**
1.  **Sample:** Collect $N$ independent samples from the noise function over the domain of interest [S1].
2.  **Define Bins:** Partition the range of possible noise values into $B$ equal-width bins.
3.  **Compute Observed Counts:** For each sample $x_j$, determine which bin $i$ it falls into and increment $O_i$.
4.  **Compute Expected Counts:** Calculate the probability $p_i$ that a random variable from the target distribution falls into bin $i$. Set $E_i = N \cdot p_i$ [S1].
    *   If the variance is known, use it directly. If not, estimate the variance from the samples [S1].
5.  **Calculate Statistic:** Compute the chi-square statistic:
    $$ \chi^2 = \sum_{i=1}^{B} \frac{(O_i - E_i)^2}{E_i} $$
6.  **Interpret:** A lower $\chi^2$ value indicates a better fit to the expected distribution. The degrees of freedom are typically $B - 1 - k$, where $k$ is the number of estimated parameters (e.g., $k=2$ for mean and variance) [G].

**Parameters:**
*   **Number of Bins ($B$):** Not given in the sources.
*   **Target Distribution:** Typically Gaussian [S1].

**Edge Cases and Pitfalls:**
*   **Empty Bins:** If $E_i = 0$, the term is undefined. Bins with very low expected counts should be merged or excluded [G].
*   **Sample Size:** $N$ must be sufficiently large for the chi-square approximation to be valid [G].

**Pseudocode:**
```python
def chi_square_noise_quality(samples, num_bins, target_mean, target_variance):
    """
    Computes the chi-square goodness-of-fit statistic for noise amplitude distribution.
    
    Args:
        samples: List of float noise values.
        num_bins: Integer number of histogram bins.
        target_mean: Float mean of the expected Gaussian distribution.
        target_variance: Float variance of the expected Gaussian distribution.
        
    Returns:
        Float chi-square statistic.
    """
    import math
    
    n = len(samples)
    if n == 0:
        return 0.0
        
    # Determine range for binning
    min_val = min(samples)
    max_val = max(samples)
    
    # Add small epsilon to avoid edge issues
    min_val -= 1e-9
    max_val += 1e-9
    
    bin_width = (max_val - min_val) / num_bins
    
    # Initialize observed counts
    observed = [0] * num_bins
    
    # Populate histogram
    for x in samples:
        bin_index = int((x - min_val) / bin_width)
        # Clamp to last bin if exactly on boundary
        if bin_index == num_bins:
            bin_index = num_bins - 1
        observed[bin_index] += 1
        
    # Calculate expected counts based on Gaussian PDF
    expected = [0.0] * num_bins
    for i in range(num_bins):
        # Probability mass in this bin
        # Using cumulative distribution function approximation or integration
        # For simplicity, assume uniform probability if not specified, 
        # but Gaussian is standard [S1].
        # Lower and upper bounds of the bin
        lower = min_val + i * bin_width
        upper = lower + bin_width
        
        # Approximate probability using PDF at center * width
        # This is an approximation; exact integration is better [G]
        center = (lower + upper) / 2.0
        pdf_val = (1.0 / math.sqrt(2 * math.pi * target_variance)) * \
                  math.exp(-0.5 * ((center - target_mean) ** 2) / target_variance)
        expected[i] = n * pdf_val * bin_width
        
    # Compute chi-square statistic
    chi2 = 0.0
    for i in range(num_bins):
        if expected[i] > 0:
            chi2 += ((observed[i] - expected[i]) ** 2) / expected[i]
        else:
            # Handle zero expected count
            if observed[i] > 0:
                chi2 += float('inf')
                
    return chi2
```

## Operating characteristics
*   **Time Complexity:** $O(N + B)$, where $N$ is the number of samples and $B$ is the number of bins.
*   **Memory Complexity:** $O(B)$ for storing histogram bins.
*   **Strengths:** Simple to implement; provides a single scalar metric for distribution fidelity [S1, S2].
*   **Limitations:** Only assesses amplitude distribution, not spatial coherence or frequency content [S1]. Sensitive to binning choices [G].
*   **When to Use:** When optimizing noise functions for statistical correctness of amplitude values [S1, S2].
*   **When Not to Use:** When spatial properties (periodicity, band-pass) are the primary concern.

## Background
The Chi-Square Goodness-of-Fit Test for Noise was presented by Yoon et al. in [YLC04] and [YL08] as part of a suite of analysis tools for measuring the quality of noise within an optimization procedure [S1, S2]. It is cited in surveys of procedural noise functions as a method for evaluating amplitude distribution quality [S1, S2].
