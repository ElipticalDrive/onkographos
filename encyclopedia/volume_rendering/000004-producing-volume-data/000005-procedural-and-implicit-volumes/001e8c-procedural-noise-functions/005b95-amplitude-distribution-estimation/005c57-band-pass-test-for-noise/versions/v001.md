# Band-Pass Test for Noise
Also called: Band-Pass Test, Yoon et al. Band-Pass Noise Metric
## Overview
The Band-Pass Test for Noise measures the spectral characteristics of a procedural noise function by quantifying how "band-pass" it is, based on the difference between the noise and a down-up-sampled version of itself [S1, S2]. Inspired by wavelet noise, it serves as a quality metric within optimization procedures to evaluate noise properties [S1, S2]. It is distinct from sibling methods like the Chi-Square Goodness-of-Fit Test, which evaluates amplitude distribution, and the Autocorrelation Periodicity Test, which detects repeating patterns [S1, S2].
## How it works
The method evaluates the noise by comparing the original signal to a version that has been downsampled and then upsampled (reconstructed). The core intuition is that band-pass noise, which lacks low-frequency components, will exhibit significant differences when subjected to this down-up sampling process, whereas low-frequency noise would remain relatively stable [S1, S2].

**Inputs and Outputs:**
- Input: A noise function $N(x, y, z)$ and a domain of evaluation.
- Output: A scalar metric representing the band-pass quality (typically the magnitude of the difference).

**Data Structures:**
- Not specified in the sources. Implementation typically requires storing noise values in a grid or evaluating them on the fly.

**Steps:**
1. Evaluate the noise function $N$ at a set of points $\{p_i\}$ to obtain the original signal $S_{orig}$.
2. Downsample the signal $S_{orig}$ to a coarser resolution. This involves selecting a subset of points or averaging blocks of the original grid. Let the downsampled signal be $S_{down}$.
3. Upsample the signal $S_{down}$ back to the original resolution $\{p_i\}$. This involves interpolating or replicating the downsampled values to fill the original grid points. Let the reconstructed signal be $S_{recon}$.
4. Compute the difference between the original signal and the reconstructed signal: $D = S_{orig} - S_{recon}$.
5. Calculate a metric from the difference $D$. The sources do not specify the exact aggregation function (e.g., mean squared error, L2 norm), but the magnitude of this difference indicates the band-pass nature. A higher difference suggests the noise is more band-pass [S1, S2].

**Formulas:**
Let $N(p)$ be the noise value at point $p$.
Let $D_{down}$ be the downsampling operator and $D_{up}$ be the upsampling operator.
The reconstructed noise is $N_{recon}(p) = D_{up}(D_{down}(N))(p)$.
The difference is $\Delta(p) = N(p) - N_{recon}(p)$.
The metric is derived from $\Delta(p)$. [S1, S2]

**Parameters:**
- The downsampling factor (ratio between original and downsampled resolution) is not specified in the sources. [G] A common choice would be a factor of 2.

**Edge Cases and Pitfalls:**
- The choice of upsampling method (nearest neighbor, linear, etc.) affects the result. [G] Nearest neighbor is the simplest reconstruction.
- The sources do not specify how to handle boundary conditions. [G] Standard boundary handling (clamping or wrapping) should be applied.

**Pseudocode:**
```python
def band_pass_test(noise_func, grid_size, downsample_factor):
    """
    Computes the band-pass metric for a noise function.
    
    Args:
        noise_func: A callable that returns noise value for a 3D point.
        grid_size: The resolution of the evaluation grid (e.g., 64).
        downsample_factor: The factor by which to downsample (e.g., 2).
        
    Returns:
        A scalar metric representing the band-pass quality.
    """
    # Step 1: Evaluate original noise
    original_grid = []
    for x in range(grid_size):
        for y in range(grid_size):
            for z in range(grid_size):
                # Normalize coordinates to [0, 1] or appropriate domain
                p = (x / grid_size, y / grid_size, z / grid_size)
                original_grid.append(noise_func(p))
    
    # Step 2: Downsample
    # Select every downsample_factor-th point
    downsampled_grid = []
    for x in range(0, grid_size, downsample_factor):
        for y in range(0, grid_size, downsample_factor):
            for z in range(0, grid_size, downsample_factor):
                idx = (x * grid_size * grid_size + y * grid_size + z)
                downsampled_grid.append(original_grid[idx])
                
    # Step 3: Upsample (Nearest Neighbor Reconstruction)
    # Map each original point to the nearest downsampled point
    reconstructed_grid = []
    for x in range(grid_size):
        for y in range(grid_size):
            for z in range(grid_size):
                # Find the corresponding downsampled index
                dx = (x // downsample_factor) * downsample_factor
                dy = (y // downsample_factor) * downsample_factor
                dz = (z // downsample_factor) * downsample_factor
                idx = (dx * grid_size * grid_size + dy * grid_size + dz)
                reconstructed_grid.append(downsampled_grid[idx // (downsample_factor * downsample_factor * downsample_factor)]) # Note: index mapping needs care for 3D strides
                
    # Corrected Upsampling Logic for 3D grid
    reconstructed_grid = []
    downsampled_stride = grid_size // downsample_factor
    for x in range(grid_size):
        for y in range(grid_size):
            for z in range(grid_size):
                dx = (x // downsample_factor)
                dy = (y // downsample_factor)
                dz = (z // downsample_factor)
                # Index in the flattened downsampled grid
                d_idx = dz * downsampled_stride * downsampled_stride + dy * downsampled_stride + dx
                reconstructed_grid.append(downsampled_grid[d_idx])

    # Step 4: Compute difference
    diff_sum = 0.0
    count = 0
    for i in range(len(original_grid)):
        diff = original_grid[i] - reconstructed_grid[i]
        diff_sum += diff * diff
        count += 1
        
    # Step 5: Return metric (Mean Squared Error)
    return diff_sum / count
```

## Operating characteristics
- Time Complexity: $O(N)$ where $N$ is the number of sample points, as it involves a single pass for evaluation, downsampling, upsampling, and difference calculation.
- Memory Complexity: $O(N)$ to store the original, downsampled, and reconstructed grids.
- Strengths: Simple to implement; directly relates to the band-pass nature of noise; inspired by wavelet noise theory.
- Limitations: Does not provide a full spectral analysis; sensitive to the downsampling/upsampling strategy; less comprehensive than full power spectrum estimation.
- When to use: When optimizing noise functions for band-pass characteristics or comparing noise types based on this specific metric.
- When not to use: When full spectral information is required or when amplitude distribution is the primary concern.
## Background
The Band-Pass Test was presented by Yoon et al. in [YLC04, YL08]. It is inspired by wavelet noise [CD05]. It was used as one of several analysis tools for measuring the quality of noise within an optimization procedure, alongside the Chi-square goodness-of-fit test and the autocorrelation periodicity test [S1, S2].
