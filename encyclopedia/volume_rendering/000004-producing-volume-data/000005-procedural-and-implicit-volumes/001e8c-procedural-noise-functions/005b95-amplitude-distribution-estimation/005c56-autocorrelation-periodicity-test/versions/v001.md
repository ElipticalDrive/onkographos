# Autocorrelation Periodicity Test

Also called: Autocorrelation Test for Periodicity, Yoon’s Autocorrelation Test

## Overview
The Autocorrelation Periodicity Test is a statistical method used to detect unwanted periodic artifacts in procedural noise functions [S1, S2]. It operates by analyzing the spatial correlation of noise samples to identify repeating patterns that indicate a lack of randomness [S1, S2]. It is distinguished from sibling methods like the Chi-Square Goodness-of-Fit Test, which evaluates amplitude distribution, and the Band-Pass Test, which measures spectral bandwidth, by focusing specifically on spatial recurrence [S1, S2].

## How it works
The test computes the autocorrelation function of the noise field to identify peaks that deviate from the expected behavior of a random field [S1, S2].

**Inputs and Outputs:**
- Input: A set of $N$ noise samples $n_i$ sampled at positions $\mathbf{p}_i$ within a domain.
- Output: A scalar metric indicating the presence of periodicity, or a correlation profile used for visual inspection [S1, S2].

**Data Structures:**
- Array of noise values: $V = [v_0, v_1, \dots, v_{N-1}]$, where $v_i = n(\mathbf{p}_i)$ [S1, S2].
- Array of displacement vectors: $D = [\mathbf{d}_0, \mathbf{d}_1, \dots, \mathbf{d}_{M-1}]$, representing the lags or offsets between sample pairs [G].

**Steps:**
1. **Center the Data:** Compute the mean $\mu$ of the noise samples and subtract it from each sample to create a zero-mean signal $x_i = v_i - \mu$ [G].
2. **Compute Autocorrelation:** For a set of lag vectors $\mathbf{d}$, compute the normalized autocorrelation $R(\mathbf{d})$ [S1, S2]:
   $$ R(\mathbf{d}) = \frac{\sum_{i} x_i x_{i+\Delta}}{\sum_{i} x_i^2} $$
   where $\Delta$ is the index offset corresponding to the spatial lag $\mathbf{d}$, and the sum is over all valid indices $i$ such that $i+\Delta < N$ [G].
3. **Analyze Peaks:** Identify local maxima in $R(\mathbf{d})$ for non-zero lags $\mathbf{d}$ [S1, S2].
4. **Determine Periodicity:** If significant peaks exist at specific non-zero lags, the noise exhibits periodicity at the corresponding spatial frequencies [S1, S2].

**Parameters:**
- Sampling resolution: Not given in the sources.
- Lag range: Not given in the sources.

**Edge Cases and Pitfalls:**
- Boundary effects: Samples near the edge of the domain have fewer pairs for correlation, potentially skewing results [G].
- Mean estimation: Incorrect mean subtraction can introduce artificial correlations [G].

**Pseudocode:**
```python
def autocorrelation_periodicity_test(noise_samples, lags):
    """
    Detect periodicity in noise samples using autocorrelation.
    
    Args:
        noise_samples: List of float values n(p_i).
        lags: List of integer offsets (or spatial vectors if implemented in 3D).
        
    Returns:
        correlation_values: List of normalized autocorrelation values for each lag.
    """
    n = len(noise_samples)
    if n == 0:
        return []
    
    # Step 1: Center the data
    mean_val = sum(noise_samples) / n
    centered = [x - mean_val for x in noise_samples]
    
    # Step 2: Compute autocorrelation for each lag
    correlation_values = []
    for lag in lags:
        if lag == 0:
            # Autocorrelation at lag 0 is always 1.0 for normalized data
            correlation_values.append(1.0)
            continue
        
        # Calculate sum of products for this lag
        # Only sum over valid indices where i + lag < n
        sum_products = 0.0
        count = 0
        for i in range(n - lag):
            sum_products += centered[i] * centered[i + lag]
            count += 1
        
        if count == 0:
            correlation_values.append(0.0)
            continue
            
        # Normalize by the variance (sum of squares of centered data)
        # Note: Using the full sum of squares as denominator is standard for normalized autocorrelation
        variance = sum(x * x for x in centered)
        
        if variance == 0:
            correlation_values.append(0.0)
        else:
            r = sum_products / variance
            correlation_values.append(r)
            
    return correlation_values
```

## Operating characteristics
- Time Complexity: $O(N \cdot M)$, where $N$ is the number of samples and $M$ is the number of lags tested [G].
- Memory Complexity: $O(N)$ to store the noise samples and centered values [G].
- Strengths: Directly detects spatial repetition, which is a common artifact in poorly optimized noise functions [S1, S2].
- Limitations: Requires a sufficient number of samples to be statistically significant [G]. Performance depends on the sampling density and domain size [G].
- When to use: When optimizing noise functions and needing to verify that the output does not exhibit visible grid-like or repeating patterns [S1, S2].
- When not to use: When the primary concern is amplitude distribution (use Chi-Square) or spectral bandwidth (use Band-Pass) [S1, S2].

## Background
The Autocorrelation Periodicity Test was presented by Yoon et al. in 2004 and 2008 as part of a suite of analysis tools for measuring the quality of procedural noise during optimization procedures [S1, S2]. It is cited in surveys of procedural noise functions as one of the key methods for detecting periodicity [S1, S2].
