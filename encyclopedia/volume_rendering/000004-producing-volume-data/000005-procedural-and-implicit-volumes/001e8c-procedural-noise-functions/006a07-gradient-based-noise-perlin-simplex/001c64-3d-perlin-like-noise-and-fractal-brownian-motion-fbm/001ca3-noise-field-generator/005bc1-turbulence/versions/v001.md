# Turbulence

Also called: Turbulent Noise

## Overview
Turbulence is a noise basis function that creates the visual impression of Brownian motion or turbulent flow by summing absolute values of noise at decreasing frequencies [S2, book]. It differs from standard Fractal Brownian Motion (FBM) by applying the absolute value operator to each octave, which introduces discontinuities in the gradient and reflects the underlying noise vectors [S2, book]. This method is chosen when a "carved" or fragmented texture appearance is desired, as opposed to the smoother, continuous variations of standard FBM [S2, book].

## How it works
**Inputs and Outputs**
- Input: A 3D position vector `pos` ($\mathbb{R}^3$).
- Output: A scalar value representing the accumulated turbulent noise magnitude.

**Data Structures**
The implementation relies on a modified noise function, `mnoise`, which returns a scalar. The specific implementation of `mnoise` cited uses a hash-based lookup with bilinear interpolation [S1, unofficial]. However, the Turbulence algorithm itself is independent of the specific noise generator, provided it returns a signed scalar.

**Parameters**
- `octives`: Integer constant, typically 4. Defines the number of octaves to accumulate [S1, unofficial].
- `lacunarity`: Float constant, typically 2.0. Multiplier for frequency in each subsequent octave [S1, unofficial].
- `gain`: Float constant, typically 0.5. Multiplier for amplitude in each subsequent octave [S1, unofficial].

**Algorithm Steps**
1. Initialize `sum` to 0.0, `freq` to 1.0, and `amp` to 1.0.
2. Loop `i` from 0 to `octives - 1`:
   a. Evaluate the base noise function at the scaled position: `n = mnoise(pos * freq)`.
   b. Take the absolute value of the noise result: `abs_n = |n|`.
   c. Add the weighted absolute noise to the sum: `sum += abs_n * amp`.
   d. Update frequency: `freq *= lacunarity`.
   e. Update amplitude: `amp *= gain`.
3. Return `sum`.

**Formula**
The mathematical definition for $N$ octaves is:
$$ T(\mathbf{p}) = \sum_{i=0}^{N-1} | \mathcal{N}( \mathbf{p} \cdot \lambda^i ) \cdot g^i | $$
Where:
- $\mathbf{p}$ is the input position.
- $\mathcal{N}$ is the base noise function (e.g., Simplex or Perlin).
- $\lambda$ is the lacunarity (typically 2.0).
- $g$ is the gain (typically 0.5).
- $N$ is the number of octives (typically 4).

**Pseudocode**
```python
def turbulence(pos: Vector3, octives: int = 4, lacunarity: float = 2.0, gain: float = 0.5) -> float:
    """
    Computes turbulent noise by summing absolute values of noise octaves.
    
    Args:
        pos: 3D position vector.
        octives: Number of octaves to accumulate.
        lacunarity: Frequency multiplier per octave.
        gain: Amplitude multiplier per octave.
        
    Returns:
        Scalar turbulent noise value.
    """
    sum_val = 0.0
    freq = 1.0
    amp = 1.0
    
    for i in range(octives):
        # Evaluate base noise at current frequency
        # Note: mnoise is the underlying noise function (e.g., Simplex, Perlin)
        noise_val = mnoise(pos * freq)
        
        # Apply absolute value to introduce discontinuities
        sum_val += abs(noise_val) * amp
        
        # Update frequency and amplitude for next octave
        freq *= lacunarity
        amp *= gain
        
    return sum_val
```

**Edge Cases and Pitfalls**
- **Discontinuities**: The use of `abs()` creates sharp corners in the noise field where the original noise crosses zero. This is intentional for the "turbulent" look but can cause aliasing artifacts if the frequency is too high relative to the sampling rate [S2, book].
- **Precision**: Accumulating many octaves with high lacunarity can lead to precision loss in the lower bits if fixed-point arithmetic is used. Floating-point is recommended.
- **Range**: The output range is not bounded to $[0, 1]$ or $[-1, 1]$ like the base noise. It grows with the number of octaves. For standard use, normalization or clamping may be required downstream.

## Operating characteristics
- **Time Complexity**: $O(N)$, where $N$ is the number of octives. Each octave requires one evaluation of the base noise function.
- **Memory Complexity**: $O(1)$ auxiliary space.
- **Performance**: The cost is dominated by the base noise function `mnoise`. The `abs()` operation is negligible.
- **Strengths**: Creates visually distinct, fragmented textures that mimic turbulent fluids or rough surfaces. Simple to implement.
- **Limitations**: The discontinuities from `abs()` can look unnatural if not tuned correctly. It lacks the smoothness of standard FBM.
- **When to use**: When simulating solid textures with a "carved" appearance, or when the visual style requires sharp transitions in noise gradients [S2, book].
- **When not to use**: When smooth, continuous variation is required (use standard FBM instead).

## Background
The turbulence basis function was introduced in the context of solid texturing for volume rendering. It is described in the book *Volume Visualization and Volume Graphics* [S2, book], where it is noted for giving the impression of Brownian motion. The specific implementation using `mnoise` (a modified noise function) is found in the *VolumetricFire* project [S1, unofficial]. The technique relies on the self-similar $1/f$ pattern introduced by summing noise at decreasing frequencies, with the absolute value function reflecting the gradient vectors to create discontinuities [S2, book].
