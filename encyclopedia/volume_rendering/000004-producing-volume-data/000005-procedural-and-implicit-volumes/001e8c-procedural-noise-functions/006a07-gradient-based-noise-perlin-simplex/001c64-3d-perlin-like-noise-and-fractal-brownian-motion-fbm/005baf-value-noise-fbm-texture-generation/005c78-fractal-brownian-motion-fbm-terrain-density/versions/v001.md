# Fractal Brownian Motion (FBM) Terrain Density

Also called: Octave Noise Terrain Generation

## Overview
Generates 3D terrain density fields by summing multiple octaves of simplex noise, modified by a base surface plane, terracing, and bedrock layers [S1, unofficial]. It differs from standard value-noise FBM by transforming the raw noise output into peaks at zero-crossings and valleys at extrema, creating distinct topological features suitable for voxel-based terrain generation [S1, unofficial].

## How it works
**Inputs:**
- `center`: World position of the chunk center [S1, unofficial].
- `id`: Vertex ID (integer vector) [S1, unofficial].
- `chunkSize`: Size of the chunk in world units [S1, unofficial].
- `vertSpacing`: Distance between vertices [S1, unofficial].
- `offset`: Global offset for noise evaluation [S1, unofficial].
- `octaveOffsetBuffer`: Array of 3D vectors, one per octave, providing phase shifts [S1, unofficial].
- `numberOfOctaves`: Number of noise layers to sum [S1, unofficial].
- `scale`: Initial frequency multiplier [S1, unofficial].
- `lacunarity`: Frequency multiplier per octave [S1, unofficial].
- `persistence`: Amplitude multiplier per octave [S1, unofficial].
- `weight`: Multiplier for the noise density component [S1, unofficial].
- `weightMultiplier`: Controls decay of octave weight based on previous value [S1, unofficial].
- `surfaceOffset`: Vertical offset for the base surface plane [S1, unofficial].
- `bedrockHeight`: Y-coordinate threshold for bedrock layer [S1, unofficial].
- `bedrockWeight`: Density value added below bedrock height [S1, unofficial].
- `terracing`: Vector3 where `x` is terrace height step, `y` is terrace weight, `z` is enabled flag [S1, unofficial].
- `mapSize`: Dimensions of the volume map [S1, unofficial].
- `solidifyEdges`: Boolean flag to solidify chunk boundaries [S1, unofficial].

**Outputs:**
- `vertexBuffer`: Array of vertex positions [S1, unofficial].
- `densityBuffer`: Array of density values [S1, unofficial].

**Data Structures:**
The method is typically implemented in a parallel job struct containing the fields listed in Inputs, plus `vertexBuffer` and `densityBuffer` as writeable arrays [S1, unofficial].

**Steps:**
1.  **Calculate Position:**
    Compute the vertex position in world space:
    $$ \text{offsetPos} = (1, 1, 1) \times \frac{\text{chunkSize}}{2} $$
    $$ \text{position} = \text{center} - \text{offsetPos} + \text{id} \times \text{vertSpacing} $$
    [S1, unofficial]

2.  **Initialize FBM State:**
    $$ \text{density} = 0 $$
    $$ \text{frequency} = \frac{\text{scale}}{100} $$
    $$ \text{amplitude} = 1 $$
    $$ \text{octaveWeight} = 1 $$
    [S1, unofficial]

3.  **Sum Octaves:**
    Loop $i$ from $0$ to $\text{numberOfOctaves} - 1$:
    a. Evaluate simplex noise:
    $$ \text{val} = \text{SimplexNoise}(\text{position} \times \text{frequency} + \text{octaveOffsetBuffer}[i] + \text{offset}) $$
    [S1, unofficial]
    b. Transform value to create peaks at zero and valleys at extrema:
    $$ \text{val} = 1 - |\text{val}| $$
    $$ \text{val} = \text{val}^2 $$
    [S1, unofficial]
    c. Apply octave weight:
    $$ \text{val} = \text{val} \times \text{octaveWeight} $$
    [S1, unofficial]
    d. Add to density:
    $$ \text{density} = \text{density} + \text{val} \times \text{amplitude} $$
    [S1, unofficial]
    e. Update octave weight for next iteration:
    $$ \text{octaveWeight} = \max(\min(\text{val} \times \text{weightMultiplier}, 1), 0) $$
    [S1, unofficial]
    f. Update amplitude:
    $$ \text{amplitude} = \text{amplitude} \times \text{persistence} $$
    [S1, unofficial]
    g. Update frequency:
    $$ \text{frequency} = \text{frequency} \times \text{lacunarity} $$
    [S1, unofficial]

4.  **Combine with Surface Plane:**
    $$ \text{density} = -(\text{position}.y + \text{surfaceOffset}) + \text{density} \times \text{weight} $$
    [S1, unofficial]

5.  **Apply Terracing (if enabled):**
    If $\text{terracing}.z > 0$:
    $$ \text{density} = \text{density} + (\text{position}.y \pmod{\text{terracing}.x}) \times \text{terracing}.y $$
    [S1, unofficial]

6.  **Apply Bedrock Layer:**
    If $\text{position}.y < \text{bedrockHeight}$:
    $$ \text{density} = \text{density} + \text{bedrockWeight} $$
    [S1, unofficial]

7.  **Solidify Edges (if enabled):**
    If $\text{solidifyEdges}$ is true:
    $$ \text{edgeOffset} = (|\text{position}.x|, |\text{position}.y|, |\text{position}.z|) - \frac{\text{mapSize}}{2} $$
    If $\text{edgeOffset}.x \ge 0$ OR $\text{edgeOffset}.y \ge 0$ OR $\text{edgeOffset}.z \ge 0$:
    $$ \text{density} = -100 $$
    [S1, unofficial]

8.  **Store Results:**
    $$ \text{vertexBuffer}[\text{id}] = \text{position} $$
    $$ \text{densityBuffer}[\text{id}] = \text{density} $$
    [S1, unofficial]

**Pseudocode:**
```python
def evaluate_terrain_density(center, id, chunk_size, vert_spacing, offset, octave_offset_buffer, 
                             num_octaves, scale, lacunarity, persistence, weight, weight_multiplier,
                             surface_offset, bedrock_height, bedrock_weight, terracing, map_size, 
                             solidify_edges):
    # Step 1: Calculate Position
    offset_pos = Vector3(1, 1, 1) * (chunk_size / 2)
    position = center - offset_pos + (id * vert_spacing)
    
    # Step 2: Initialize FBM State
    density = 0.0
    frequency = scale / 100.0
    amplitude = 1.0
    octave_weight = 1.0
    
    # Step 3: Sum Octaves
    for i in range(num_octaves):
        # Evaluate noise
        noise_input = (position * frequency) + octave_offset_buffer[i] + offset
        val = simplex_noise.evaluate(noise_input)
        
        # Transform value
        val = 1.0 - abs(val)
        val = val * val
        
        # Apply weight
        val = val * octave_weight
        
        # Add to density
        density += val * amplitude
        
        # Update parameters for next octave
        octave_weight = max(min(val * weight_multiplier, 1.0), 0.0)
        amplitude *= persistence
        frequency *= lacunarity
        
    # Step 4: Combine with Surface Plane
    density = -(position.y + surface_offset) + (density * weight)
    
    # Step 5: Apply Terracing
    if terracing.z > 0:
        terrace_step = terracing.x
        terrace_weight = terracing.y
        # Modulo operation for floating point
        terrace_offset = position.y - floor(position.y / terrace_step) * terrace_step
        density += terrace_offset * terrace_weight
        
    # Step 6: Apply Bedrock Layer
    if position.y < bedrock_height:
        density += bedrock_weight
        
    # Step 7: Solidify Edges
    if solidify_edges:
        edge_offset_x = abs(position.x) - (map_size.x / 2)
        edge_offset_y = abs(position.y) - (map_size.y / 2)
        edge_offset_z = abs(position.z) - (map_size.z / 2)
        
        if edge_offset_x >= 0 or edge_offset_y >= 0 or edge_offset_z >= 0:
            density = -100.0
            
    return position, density
```

## Operating characteristics
**Time Complexity:** $O(N \times O)$, where $N$ is the number of vertices and $O$ is the number of octaves. Each vertex requires $O$ simplex noise evaluations.
**Memory Complexity:** $O(N)$ for storing vertex positions and density values, plus $O(O)$ for octave offsets.
**Strengths:** The transformation $1 - |\text{val}|$ squared creates sharp peaks and deep valleys, which is useful for generating distinct terrain features like mountains and caves in voxel engines. The modular structure allows easy addition of bedrock and terracing.
**Limitations:** The specific transformation is non-standard for FBM and may not produce natural-looking terrain without careful tuning of `weightMultiplier` and `persistence`. The edge solidification logic is specific to chunk-based generation and may not generalize to infinite worlds without boundary handling.
**When to use:** When generating voxel terrain with distinct topological features (peaks/valleys) and needing to integrate bedrock/terracing layers directly into the density field.
**When not to use:** For smooth, naturalistic terrain where standard FBM or Perlin noise is preferred, or for infinite worlds without chunk-based boundary logic.

## Background
Originated in the `tcgj/terrain-generator` repository, an unofficial project for generating voxel terrain [S1, unofficial]. It adapts standard FBM concepts but introduces specific value transformations and structural layers (bedrock, terracing) tailored for voxel-based game development.
