# Gradient-based Noise (Perlin/Simplex)

Also called: Gradient Noise, Perlin Noise, Simplex Noise

## Overview
Gradient-based noise generates smooth, continuous scalar fields by interpolating dot products of pseudo-random gradient vectors assigned to lattice points. It solves the problem of creating organic, non-repetitive procedural textures for volume rendering, avoiding the blocky artifacts of value noise and the directional bias of simple linear interpolation. It is distinguished from [Value Noise](4008-value-noise.md) by using gradient vectors at lattice corners rather than scalar values, providing higher frequency detail and $C^1$ continuity [S1].

## Shared principles
The family shares the following mechanism, terms, and math:

1.  **Gradient Assignment**: Each integer lattice point (vertex) in the domain is assigned a pseudo-random gradient vector $\mathbf{g}$. In 3D, common sets include 12 face diagonals of a cube or 12 axis-aligned vectors [S1][S2, unofficial].
2.  **Dot Product Contribution**: The noise value at a query point $\mathbf{P}$ is derived from the dot product between the gradient vector $\mathbf{g}_i$ at a lattice corner $i$ and the distance vector $\mathbf{d}_i = \mathbf{P} - \mathbf{V}_i$ from that corner to $\mathbf{P}$:
    $$ n_i = \mathbf{g}_i \cdot \mathbf{d}_i $$
3.  **Smoothing/Fade Function**: To ensure smooth transitions ($C^1$ continuity), the fractional coordinates of $\mathbf{P}$ within the cell are passed through a fade function $f(t)$ before interpolation. The quintic function $f(t) = 6t^5 - 15t^4 + 10t^3$ is standard for Perlin variants, while Simplex uses a different geometric approach [S1][S2, unofficial].
4.  **Interpolation**: The contributions from the cell corners are combined using linear interpolation (`lerp`) along the axes, weighted by the fade values [S1][S2, unofficial].
5.  **Hashing**: Integer coordinates are mapped to gradient indices using a permutation table to avoid modulo operations and ensure uniform distribution [S1][S2, unofficial].

## Subtopics

### [Simplex Noise](978-simplex-noise.md)
Simplex Noise maps input coordinates to a skewed simplex lattice (triangles in 2D, tetrahedra in 3D) to reduce directional artifacts and computational complexity. Unlike standard Perlin Noise which uses a square grid and requires four gradient evaluations in 2D, Simplex Noise 2D uses a triangular grid and requires only three gradient evaluations, lowering complexity and eliminating undesired directional artifacts. It scales to higher dimensions ($n$) with complexity $O(n^2)$ compared to $O(n 2^n)$ for classic noise.

### [3D Perlin-like Noise and Fractal Brownian Motion (FBM)](1260-3d-perlin-like-noise-and-fractal-brownian-motion-fbm.md)
3D Perlin-like Noise generates smooth scalar values on a 3D unit lattice using gradient interpolation, while FBM constructs multi-scale, self-similar detail by summing multiple octaves with increasing frequency and decreasing amplitude. It is distinguished from [Simplex Noise](978-simplex-noise.md) by its reliance on a cubic grid and trilinear interpolation, and from [Value-Noise FBM Texture Generation](16950-value-noise-fbm-texture-generation.md) by using gradient vectors instead of scalar values.

### [Improved Perlin Noise (4D)](3723-improved-perlin-noise-4d.md)
Improved Perlin Noise (4D) extends the 3D algorithm to four dimensions, primarily to support time-varying texture generation by treating time as the fourth spatial axis. Unlike its 3D sibling, it requires handling 16 corners and 4D gradient vectors, often optimized for graphics hardware using texture-based lookup tables to avoid branching.

### [Perlin Noise 2D](4211-perlin-noise-2d.md)
Perlin Noise 2D operates on a square grid and relies on a quintic fade function and specific gradient sets to achieve $C^1$ continuity. Unlike its sibling [Simplex Noise](978-simplex-noise.md), which uses a triangular grid to reduce directional artifacts, Perlin Noise 2D is simpler to implement but exhibits axis-aligned anisotropy.

### [Perlin Gradient and Interpolation Functions](5415-perlin-gradient-and-interpolation-functions.md)
This article defines the core mathematical primitives—gradient selection, fading (smoothing), and linear interpolation—used to construct gradient-based noise functions. It differs from sibling methods primarily in its specific choice of the quintic fade polynomial and the 12-gradient vector set for 3D, whereas Simplex noise uses a different lattice structure and interpolation geometry.

### [Curl Noise](17018-curl-noise.md)
Curl noise is a procedural noise function designed to generate time-varying, incompressible turbulent velocity fields. Unlike standard gradient noise which produces scalar fields, curl noise produces vector fields where the divergence is identically zero, ensuring the flow is solenoidal.

### Hash-based Value Noise
#### definition
- [S2, unofficial] A simpler 3D noise function using 1D hash interpolation, often called Simplex-like or Value Noise.
#### step
- [S2, unofficial] Define `step = float3(110, 241, 171)`. Compute integer part `i = floor(x)` and fractional part `f = frac(x)`.
- [S2, unofficial] Compute smooth interpolation weights: `u = f * f * (3.0 - 2.0 * f)`.
- [S2, unofficial] Perform 3D trilinear interpolation of hash values at the 8 corners of the unit cube using `hash(n + dot(step, float3(x,y,z)))`.

### Perlin-Worley Blend
#### definition
- [S3, unofficial] A hybrid noise technique that blends Perlin and Worley noise using a non-linear step function based on a weight parameter.
#### step
- [S3, unofficial] Calculate the Perlin component using fBm with its specific parameters: `float perlin = fBm(getPerlinNoise, channelConfig.seed, pos, glm::vec3(1.0f), channelConfig.perlinOctaveCount, channelConfig.perlinFrequency, channelConfig.perlinLacunarity, channelConfig.perlinPersistence);`
- [S3, unofficial] Calculate the Worley component using fBm and invert it: `float worley = 1.0 - fBm(getWorleyNoise, channelConfig.seed, pos, glm::vec3(1.0f), channelConfig.worleyOctaveCount, channelConfig.worleyFrequency, channelConfig.worleyLacunarity, channelConfig.worleyPersistence);`
- [S3, unofficial] Compute the final noise value using a linear step function: `noise = linearStep((1.0f - worley) * channelConfig.worleyWeight, 1.0f, perlin);`
#### parameter
- [S3, unofficial] worleyWeight: A float parameter controlling the blend between Perlin and Worley noise.

## Background
Gradient-based noise was introduced by Ken Perlin in 1985 for the movie *Tron* [S1]. Simplex Noise was later introduced by Perlin in 2001 to address the directional artifacts and high computational cost of the original grid-based approach . The method is widely used in procedural generation for terrain, clouds, and fluid simulations in computer graphics [S3, unofficial].
