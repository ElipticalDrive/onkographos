# Symmetric Function Transformation

Also called: Symmetric functions approach, Logistic transformation for Perlin noise

## Overview
A method to modify Perlin noise octaves while preserving the mean value by using functions that satisfy a specific symmetry condition around zero [S1, unofficial]. It sets apart from alternatives by enforcing a mathematical constraint on the transformation function itself, rather than compensating for the mean shift after the fact [S1, unofficial]. This ensures the resulting distribution has a predictable mean without requiring post-hoc normalization or pre-computed sampling [S1, unofficial].

## How it works
**Inputs and Outputs:**
- Input: A Perlin noise value $x$ (assumed to be symmetric around 0) and parameters for the transformation function.
- Output: A transformed noise value $y = f(x)$ with a mean of $f(0)$.

**Data Structures:**
- No specific data structures required; operates on scalar values.

**Steps:**
1. Select a transformation function $f(x)$ that satisfies the symmetry rule:
   $$ f(-x) = 2 \cdot f(0) - f(x) $$
   [S1, unofficial]
2. Set the midpoint parameter $x_0 = 0$. This is necessary for the function to satisfy the symmetry rule for all $x$ [S1, unofficial].
3. Set the carrying capacity parameter $L = 2$. This ensures that $f(0) = 1$, which keeps the mean of the resulting noise at 1 [S1, unofficial].
4. Apply the function $f(x)$ to the Perlin noise input $x$.

**Formula:**
The symmetry condition is:
$$ f(-x) = 2 \cdot f(0) - f(x) $$
[S1, unofficial]

The recommended function is the Logistic function:
$$ f(x) = \frac{L}{1 + e^{-k(x - x_0)}} $$
[S1, unofficial]

Where:
- $L$ is the carrying capacity (upper bound).
- $x_0$ is the x-value of the midpoint.
- $k$ is the steepness of the curve.

**Parameters:**
- $L$: Carrying capacity. Typical value: 2. This value is chosen to ensure $f(0) = 1$, keeping the mean of the noise at 1 [S1, unofficial].
- $x_0$: Midpoint x-value. Required value: 0. This is necessary for the Logistic function to follow the symmetry rule [S1, unofficial].
- $k$: Steepness of the curve. Controls contrast. Can be negative (equivalent to positive $k$ with input multiplied by -1) [S1, unofficial].

**Pitfalls:**
- The set of functions satisfying the symmetry rule is very limited, leading to poor expressive range and lack of control for the user [S1, unofficial].
- The method relies on the assumption that the Perlin noise distribution is symmetric around 0, which is an approximation [S1, unofficial].

**Pseudocode:**
```python
def symmetric_function_transformation(x, k):
    """
    Applies the symmetric function transformation to a Perlin noise value.
    
    Args:
        x (float): The Perlin noise value.
        k (float): The steepness parameter controlling contrast.
        
    Returns:
        float: The transformed noise value with mean 1.
    """
    # Parameters
    L = 2.0  # Carrying capacity to ensure f(0) = 1
    x0 = 0.0 # Midpoint to satisfy symmetry rule
    
    # Logistic function
    # f(x) = L / (1 + exp(-k * (x - x0)))
    exponent = -k * (x - x0)
    result = L / (1.0 + math.exp(exponent))
    
    return result
```
[G] `math.exp` is a standard mathematical operation.

## Subtopics

### Sampling-Based Mean Compensation
A method to compensate for mean shift by pre-computing the mean of a transformed noise sample and using it as a normalization factor [S1, unofficial]. It differs from Symmetric Function Transformation by not requiring the function to satisfy a strict symmetry rule, allowing for a wider range of functions, but at the cost of requiring pre-computation [S1, unofficial]. Choose this when you need more expressive control over the transformation function and can afford the pre-computation step [S1, unofficial].
- **Definition:** A method to compensate for mean shift by pre-computing the mean of a transformed noise sample and using it as a normalization factor [S1, unofficial].
- **Steps:**
    1. Choose the function $f(x)$ to apply. If it has parameters, set them to specific values beforehand [S1, unofficial].
    2. Sample a Perlin noise and apply the function $f(x)$ to the sample [S1, unofficial].
    3. Compute the mean of the obtained sample [S1, unofficial].
    4. Normalize any further use of the function on Perlin noise by dividing the result by the estimated mean [S1, unofficial].
- **Pitfalls:** Requires pre-computation, complicating use in procedural settings, especially if function parameters change frequently [S1, unofficial]. The applied function must be positive [S1, unofficial].

## Operating characteristics
- **Time Complexity:** $O(1)$ per noise value for the transformation itself [S1, unofficial].
- **Memory Complexity:** $O(1)$ [S1, unofficial].
- **Measured Performance:** Not given in the sources.
- **Scaling:** Not given in the sources.
- **Strengths:** Simple handles for the user; smooth way of increasing contrast by concentrating values near the upper and lower bounds [S1, unofficial].
- **Limitations:** Poor expressive range; lack of control for the user; limited set of functions that satisfy the symmetry rule [S1, unofficial].
- **When to use:** When a simple, smooth contrast adjustment is needed and the user is willing to accept limited control over the transformation function [S1, unofficial].
- **When not to use:** When high expressive range or complex transformations are required [S1, unofficial].

## Background
Originated in the context of procedural multiplicative Perlin noise models for dust cloud generation [S1, unofficial]. The method was proposed as a way to address the mean shift issue in Perlin noise distributions by leveraging the symmetry of the noise distribution around zero [S1, unofficial].
