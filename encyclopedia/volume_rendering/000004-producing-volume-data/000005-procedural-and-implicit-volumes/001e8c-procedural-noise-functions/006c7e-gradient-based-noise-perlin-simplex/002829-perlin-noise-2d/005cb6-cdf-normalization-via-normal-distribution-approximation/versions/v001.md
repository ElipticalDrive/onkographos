# CDF Normalization via Normal Distribution Approximation

Also called: Normal Distribution Approximation for Perlin Noise, Perlin Noise CDF Normalization

## Overview
This method compensates for mean shifts introduced by non-linear transformations on Perlin noise by approximating the noise distribution as a normal distribution, mapping it to a uniform distribution via the Cumulative Distribution Function (CDF), applying the desired transformation, and normalizing the result. It sets itself apart from sibling methods like [Symmetric Function Transformation](17210-symmetric-function-transformation.md) by allowing arbitrary transformation functions $f(x)$ rather than requiring specific symmetry conditions, and from [Fractal Brownian Motion (fBm) with Perlin Noise](4253-fractal-brownian-motion-fbm-with-perlin-noise.md) by operating on the statistical distribution of values rather than frequency composition.

## How it works
**Inputs:** A scalar Perlin noise value $x$, the transformation function $f(x)$ to be applied.
**Outputs:** A normalized transformed noise value $y$.

**Data Structures:**
No complex data structures are required. The method relies on scalar arithmetic and standard mathematical functions.

**Parameters:**
*   $\mu = 0$: The mean of the Perlin noise distribution [S1, unofficial].
*   $\sigma \approx 0.1995$: The standard deviation of the Perlin noise distribution, estimated by sampling [S1, unofficial].

**Steps:**
1.  **Estimate Parameters:** Use $\mu = 0$ and $\sigma \approx 0.1995$ [S1, unofficial].
2.  **Map to Uniform Distribution:** Apply the CDF of the normal distribution $F(x)$ to the input noise $x$ to obtain a value $u$ in the range $[0, 1]$ [S1, unofficial].
    $$ u = F(x) = 0.5 \left( 1 + \text{erf}\left( \frac{x - \mu}{\sigma \sqrt{2}} \right) \right) $$
    Where $\text{erf}(z)$ is the error function:
    $$ \text{erf}(z) = \frac{2}{\sqrt{\pi}} \int_0^z e^{-t^2} dt $$
3.  **Apply Transformation:** Compute the transformed value $v$ using the desired function $f$ on the uniform value $u$:
    $$ v = f(u) $$
4.  **Normalize:** Calculate the normalization constant $C$, which is the integral of $f(x)$ over the range $[0, 1]$:
    $$ C = \int_0^1 f(x) dx $$
    The final output $y$ is:
    $$ y = \frac{v}{C} = \frac{f(u)}{\int_0^1 f(x) dx} $$

**Pseudocode:**
```python
import math

def erf_approx(z):
    """
    Approximation of the error function.
    Source [S1, unofficial] defines erf(z) = (2/sqrt(pi)) * integral from 0 to z of e^(-t^2) dt.
    Standard library math.erf is used for implementation.
    """
    return math.erf(z)

def cdf_normal(x, mu, sigma):
    """
    Cumulative Distribution Function for a normal distribution.
    Formula: F(x) = 0.5 * (1 + erf((x - mu) / (sigma * sqrt(2))))
    """
    z = (x - mu) / (sigma * math.sqrt(2))
    return 0.5 * (1 + erf_approx(z))

def normalize_transformed_noise(x, f, integral_f):
    """
    Applies CDF normalization via normal distribution approximation.
    
    Args:
        x: Input Perlin noise value.
        f: Transformation function f(u) taking a value in [0, 1].
        integral_f: The analytical integral of f(x) from 0 to 1.
        
    Returns:
        Normalized transformed value.
    """
    # Step 1 & 2: Map Perlin noise to uniform distribution [0, 1]
    # Parameters from [S1, unofficial]: mu = 0, sigma = 0.1995
    mu = 0.0
    sigma = 0.1995
    
    u = cdf_normal(x, mu, sigma)
    
    # Step 3: Apply transformation
    v = f(u)
    
    # Step 4: Normalize by the integral of f
    # The mean of the new distribution is integral_0^1 f(x) dx [S1, unofficial]
    # We divide by this integral to ensure the mean is 1 (assuming f is positive)
    if integral_f == 0:
        return 0.0 # Guard against division by zero
        
    y = v / integral_f
    
    return y
```

**Edge Cases and Pitfalls:**
*   **Negative Values:** The function $f(x)$ must be positive on the range $[0, 1]$. Negative values are invalid for density fields [S1, unofficial].
*   **Integrability:** The integral $\int_0^1 f(x) dx$ must be computable analytically [S1, unofficial].
*   **Approximation Error:** Perlin noise is bounded, whereas the normal distribution is not. This makes the approximation imperfect, particularly in the tails of the distribution [S1, unofficial].

## Subtopics

### [Symmetric Function Transformation](17210-symmetric-function-transformation.md)
A method that relies on functions satisfying $f(-x) = 2f(0) - f(x)$ to preserve the mean without explicit normalization. Choose this when $f(x)$ is symmetric around zero and an analytical integral is difficult or unnecessary.

## Operating characteristics
*   **Time Complexity:** $O(1)$ per noise value, assuming the integral is pre-computed analytically. The cost includes evaluating the error function and the transformation function.
*   **Memory Complexity:** $O(1)$.
*   **Strengths:** Allows for arbitrary non-linear transformations (e.g., $1 - |x|$) while maintaining a mean of 1. It provides a theoretical basis for normalization rather than empirical sampling.
*   **Limitations:** Relies on the assumption that Perlin noise follows a normal distribution, which is an approximation. The bounded nature of Perlin noise is ignored. Requires the integral of the transformation function to be known analytically.
*   **When to use:** When applying non-linear transformations to Perlin noise for density fields where maintaining a specific mean (e.g., 1) is critical, and the transformation function has a known integral.
*   **When not to use:** When high precision in the distribution tails is required, or when the transformation function does not have an analytical integral.

## Background
This method originates from research into procedural multiplicative noise models for dust cloud generation. It addresses the issue of mean shift when applying non-linear functions to Perlin noise, such as $1 - |x|$ [S1, unofficial]. The approach leverages the property that applying the CDF of a distribution to a random variable from that distribution yields a uniform distribution. By approximating Perlin noise with a normal distribution, the method enables easier analytical compensation of mean shifts. The standard deviation $\sigma \approx 0.1995$ was determined by sampling Perlin noise values [S1, unofficial].
