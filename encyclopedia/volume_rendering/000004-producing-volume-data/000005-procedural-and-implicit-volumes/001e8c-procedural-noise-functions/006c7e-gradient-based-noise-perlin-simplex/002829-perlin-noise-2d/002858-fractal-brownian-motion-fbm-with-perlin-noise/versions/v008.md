# Fractal Brownian Motion (fBm) with Perlin Noise

Also called: FBM Noise, Fractal Brownian Motion (FBM) for Volume Noise, Fractal Noise, Fractional Brownian Motion (fBm), Multi-octave Perlin Noise, Organic Fog, Perlin noise summation

## Overview
Fractal Brownian Motion (fBm) with Perlin Noise is a procedural technique that generates complex, self-similar noise patterns by summing multiple octaves of a base gradient noise function (typically Perlin Noise) with increasing frequency and decreasing amplitude [S1, S2, unofficial][S3, unofficial][S5, unofficial]. It solves the problem of creating natural-looking, detailed volumetric structures (such as terrain, smoke, or clouds) that simple Perlin noise cannot provide due to its lack of multi-scale detail [S2, unofficial][S9, unofficial]. Unlike standard Perlin noise, which produces a single scale of variation, fBm mimics natural fractal phenomena by layering fine details over coarse structures [S2, unofficial][S9, unofficial].

## How it works
**Inputs:**
- `p`: Input coordinate (vector of dimension $d$, typically 2D or 3D).
- `octaves`: Integer number of noise layers to sum ($N$).
- `persistence`: Float amplitude decay factor per octave ($A$).
- `lacunarity`: Float frequency increase factor per octave ($L$).
- `base_noise`: A gradient noise function (e.g., Perlin Noise 2D/3D) returning values in $[-1, 1]$ or $[0, 1]$ [S1, S2, unofficial][S3, unofficial][S8, unofficial].

**Outputs:**
- `value`: The summed fBm noise value [S2, unofficial][S3, unofficial].

**Data Structures:**
No complex data structures are required beyond the state variables for the loop [G]. The base noise function requires a permutation table (for Perlin) or hash function, as defined in [Perlin Noise 2D](4211-perlin-noise-2d.md) [G].

**Parameters:**
- `octaves`: Typical range 1–8 [S2, unofficial][S3, unofficial], or up to 12 for high detail [S4, unofficial].
- `persistence`: Typically 0.5 (halving amplitude) [S2, unofficial][S7][S9, unofficial].
- `lacunarity`: Typically 2.0 (doubling frequency) [S2, unofficial][S7][S9, unofficial]. Note: For tiling textures, lacunarity must be a power of 2 [S6].

**Steps:**
1. Initialize `value = 0.0`, `amplitude = 1.0`, `frequency = 1.0` [S2, unofficial][S3, unofficial][S8, unofficial].
2. Loop `i` from 0 to `octaves - 1`:
   a. Evaluate the base noise function at the scaled coordinate: `n = base_noise(p * frequency)` [S6][S8, unofficial].
   b. Add the weighted noise to the sum: `value += amplitude * n` [S6][S8, unofficial].
   c. Update amplitude: `amplitude *= persistence` [S2, unofficial][S3, unofficial][S8, unofficial].
   d. Update frequency: `frequency *= lacunarity` [S2, unofficial][S3, unofficial][S8, unofficial].
3. (Optional) Normalize the result. If the base noise is in $[-1, 1]$, the theoretical max is $\sum amplitude_i$ [S1, unofficial]. Normalization ensures consistent output range [S2, unofficial][S6].
4. Return `value` [S2, unofficial][S3, unofficial].

**Formulas:**
The general form is a weighted sum of band-pass noise functions [S6]:
$$ \text{FBM}(\mathbf{x}) = \sum_{i=0}^{N-1} w_i N(2^i \mathbf{x}) $$
Where $N$ is the base noise function, $w_i$ is the weight of octave $i$, and $2^i$ represents the frequency scaling [S6]. With constant persistence $A$ and lacunarity $L=2$, this expands to [S12]:
$$ \text{FBM} = A \cdot N(\mathbf{p}) + A^2 \cdot N(2\mathbf{p}) + A^3 \cdot N(4\mathbf{p}) + \dots $$

**Pseudocode:**
```python
def fbm_perlin(p, octaves, persistence, lacunarity, base_noise_func):
    value = 0.0
    amplitude = 1.0
    frequency = 1.0
    max_value = 0.0
    
    for i in range(octaves):
        max_value += amplitude
        amplitude *= persistence
        
    amplitude = 1.0
    frequency = 1.0
    
    for i in range(octaves):
        noise_val = base_noise_func(p * frequency)
        value += amplitude * noise_val
        amplitude *= persistence
        frequency *= lacunarity
        
    if max_value > 0:
        value /= max_value
        
    return value
```

**Edge Cases and Pitfalls:**
- **High Octave Counts:** Significantly reduce performance due to nested loop complexity in raymarchers [S4, unofficial].
- **Frequency Cutoff:** The summation must stop when the frequency becomes too high for the noise to be properly represented between neighboring pixels (aliasing) [S9, unofficial].
- **Tiling:** If the resulting volume or texture must tile, lacunarity must be a power of 2 [S6].
- **Negative Weights:** Negative weights cannot cancel energy from a frequency band because noise has random phase; the primitive noise function must be band-pass rather than merely band-limited [S5, unofficial].
- **Turbulence Variant:** Using `abs(noise)` instead of signed noise creates a "turbulence" effect (white-noise-like) rather than cloudy patterns [S1, unofficial].

## Subtopics

### [Turbulence Function](16932-turbulence-function.md)
A variant that sums multiple octaves of base gradient noise with increasing frequency and decreasing amplitude, specifically applied to simulating natural fractal phenomena like fire and smoke, often using M-Noise for GPU efficiency.

## Operating characteristics
- **Time Complexity:** $O(N \cdot C)$, where $N$ is the number of octaves and $C$ is the cost of the base noise function (typically $O(1)$ for fixed-grid Perlin, but involves hashing and interpolation) [G].
- **Memory Complexity:** $O(1)$ auxiliary space, excluding the permutation table of the base noise function [G].
- **Performance:** High octave counts significantly reduce frame rates in real-time raymarching due to the nested evaluation of the noise function [S4, unofficial].
- **Strengths:** Produces self-similar, organic detail at multiple scales, mimicking natural terrain and volumetric effects [S2, unofficial][S9, unofficial].
- **Limitations:** Can appear repetitive if not combined with other techniques (e.g., domain warping) [S4, unofficial]. Aliasing occurs if frequencies exceed the Nyquist limit of the sampling grid [S9, unofficial].

## Background
Fractal Brownian Motion was introduced by Ken Perlin in 1985 [S5, unofficial][S8, unofficial]. It was designed to generate rougher, more natural-looking noise by composing multiple layers of band-pass noise [S1, unofficial][S5, unofficial]. The technique exploits the spectral properties of noise, where weights $w_i = 1/2^i$ produce $1/f$ spectral content [S5, unofficial]. It is widely used in procedural generation for terrain, textures, and volumetric effects in computer graphics [S2, unofficial][S4, unofficial][S9, unofficial]. Goldberg et al. later utilized dynamic weights to cancel mapping distortions [S5, unofficial].
