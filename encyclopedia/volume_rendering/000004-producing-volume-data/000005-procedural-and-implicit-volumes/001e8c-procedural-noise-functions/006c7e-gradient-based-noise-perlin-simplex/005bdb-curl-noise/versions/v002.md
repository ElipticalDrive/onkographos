# Curl Noise

Also called: Bridson Curl Noise

## Overview
Curl noise is a procedural noise function designed to generate time-varying, incompressible turbulent velocity fields [S2, S3]. It solves the problem of creating visually plausible fluid-like motion by constructing a divergence-free vector field from a scalar potential.

## How it works
Curl noise constructs a divergence-free vector field by taking the curl of a vector potential derived from independent scalar noise fields.

**Inputs and Outputs:**
- Input: Query point $\mathbf{P} = (x, y, z)$, time $t$, noise scale $s$.
- Output: Velocity vector $\mathbf{v} = (v_x, v_y, v_z)$.

**Data Structures:**
- Permutation table $P$: Array of size 512 (or 1024) containing integers $0..255$ to map coordinates to gradient indices [G].
- Gradient vectors $\mathbf{g}$: For 3D Perlin noise, typically 12 face diagonals of a cube: $(\pm 1, \pm 1, 0)$ and permutations [G].

**Steps:**
1.  **Generate Vector Potential:** Compute three independent scalar noise values at $\mathbf{P}$ with distinct spatial offsets to form a vector potential $\mathbf{A} = (A_x, A_y, A_z)$.
    $$ A_x = \text{PerlinNoise}(x, y, z, t) $$
    $$ A_y = \text{PerlinNoise}(x + \text{offset}_x, y + \text{offset}_y, z + \text{offset}_z, t) $$
    $$ A_z = \text{PerlinNoise}(x + \text{offset}'_x, y + \text{offset}'_y, z + \text{offset}'_z, t) $$
    The offsets must be large enough to ensure statistical independence between $A_x, A_y, A_z$ but small enough to maintain spatial coherence. Common practice uses offsets like $(100, 200, 300)$ or distinct phase shifts [G].

2.  **Compute Curl:** Calculate the curl of $\mathbf{A}$ to obtain the velocity field $\mathbf{v}$.
    $$ \mathbf{v} = \nabla \times \mathbf{A} = \begin{pmatrix} \frac{\partial A_z}{\partial y} - \frac{\partial A_y}{\partial z} \\ \frac{\partial A_x}{\partial z} - \frac{\partial A_z}{\partial x} \\ \frac{\partial A_y}{\partial x} - \frac{\partial A_x}{\partial y} \end{pmatrix} $$

3.  **Numerical Derivatives:** Since Perlin noise is interpolated, derivatives are computed using finite differences or analytical derivatives of the gradient contributions from the surrounding lattice points [G].

**Pseudocode:**
```python
def curl_noise(p: Vec3, time: float, scale: float) -> Vec3:
    s = p / scale
    eps = 1e-4
    offset1 = Vec3(100.0, 200.0, 300.0)
    offset2 = Vec3(300.0, 100.0, 200.0)
    
    # Evaluate scalar potential components
    ax = perlin_noise(s, time)
    ay = perlin_noise(s + offset1, time)
    az = perlin_noise(s + offset2, time)
    
    # Finite difference derivatives for curl
    def dN_dx(N_func, pos):
        return (N_func(pos + Vec3(eps, 0, 0)) - N_func(pos - Vec3(eps, 0, 0))) / (2 * eps)
    def dN_dy(N_func, pos):
        return (N_func(pos + Vec3(0, eps, 0)) - N_func(pos - Vec3(0, eps, 0))) / (2 * eps)
    def dN_dz(N_func, pos):
        return (N_func(pos + Vec3(0, 0, eps)) - N_func(pos - Vec3(0, 0, eps))) / (2 * eps)
        
    # Curl calculation: v = curl(A)
    vx = dN_dy(az, s + offset2) - dN_dz(ay, s + offset1)
    vy = dN_dz(ax, s) - dN_dx(az, s + offset2)
    vz = dN_dx(ay, s + offset1) - dN_dy(ax, s)
    
    return Vec3(vx, vy, vz)

def perlin_noise(p: Vec3, time: float) -> float:
    # Standard gradient noise evaluation [G]
    ix, iy, iz = floor(p)
    fx, fy, fz = p - Vec3(ix, iy, iz)
    ux, uy, uz = fade(fx), fade(fy), fade(fz)
    A = perm[ix] + iy; AA = perm[A] + iz; AB = perm[A + 1] + iz
    B = perm[ix + 1] + iy; BA = perm[B] + iz; BB = perm[B + 1] + iz
    g = lambda idx: gradients[idx % len(gradients)]
    n000 = dot(g(AA), p - Vec3(ix, iy, iz))
    n100 = dot(g(BA), p - Vec3(ix + 1, iy, iz))
    n010 = dot(g(AB), p - Vec3(ix, iy + 1, iz))
    n110 = dot(g(BB), p - Vec3(ix + 1, iy + 1, iz))
    n001 = dot(g(AA + 1), p - Vec3(ix, iy, iz + 1))
    n101 = dot(g(BA + 1), p - Vec3(ix + 1, iy, iz + 1))
    n011 = dot(g(AB + 1), p - Vec3(ix, iy + 1, iz + 1))
    n111 = dot(g(BB + 1), p - Vec3(ix + 1, iy + 1, iz + 1))
    return lerp(lerp(lerp(n000, n100, ux), lerp(n010, n110, ux), uy),
                lerp(lerp(n001, n101, ux), lerp(n011, n111, ux), uy), uz)

def fade(t: float) -> float:
    return 6 * t**5 - 15 * t**4 + 10 * t**3

def lerp(a: float, b: float, t: float) -> float:
    return a + t * (b - a)

def dot(v1: Vec3, v2: Vec3) -> float:
    return v1.x * v2.x + v1.y * v2.y + v1.z * v2.z

# Standard data structures [G]
perm = list(range(256)) * 2
gradients = [Vec3(1,1,0), Vec3(-1,1,0), Vec3(1,-1,0), Vec3(-1,-1,0),
             Vec3(1,0,1), Vec3(-1,0,1), Vec3(1,0,-1), Vec3(-1,0,-1),
             Vec3(0,1,1), Vec3(0,-1,1), Vec3(0,1,-1), Vec3(0,-1,-1)]
```

**Edge Cases and Pitfalls:**
- **Correlation:** If offsets between the three noise components are too small, the resulting field may not be sufficiently turbulent or may exhibit artifacts. If too large, local coherence is lost [G].
- **Precision:** Computing derivatives of interpolated noise requires careful handling of the fade function derivatives or finite difference step size to maintain $C^1$ continuity and avoid numerical noise [G].

## Operating characteristics
- **Time Complexity:** $O(1)$ per query, proportional to the number of lattice points in the cell (8 for 3D Perlin) times the number of noise components (3) [G].
- **Memory Complexity:** $O(1)$ for the permutation table and gradient set [G].
- **Strengths:** Produces incompressible flow naturally; visually pleasing turbulence; efficient to evaluate.
- **Limitations:** Requires careful tuning of offsets and scale to balance independence and coherence [G].

## Background
Curl noise was presented by Bridson et al. [S2, S3]. It is based on the mathematical property that the curl of any vector field is divergence-free [G].
