# Flow Noise

Also called: Advection Noise, Perlin Flow Noise

## Overview
Flow Noise is a procedural noise function designed to generate time-varying, swirling, and advected textures for physically-based simulations [S1, S2]. It differs from static noise by applying a time-dependent advection step to displace sampling coordinates, creating continuous flow motion rather than frozen patterns [S1, S2].

## How it works
**Inputs:** Spatial position $P \in \mathbb{R}^3$, time $t \in \mathbb{R}$, spatial frequency $scale \in \mathbb{R}$, advection speed $speed \in \mathbb{R}$ [G].
**Outputs:** Scalar noise value $f \in \mathbb{R}$ [G].
**Data Structures:** Not given in the sources.
**Steps:**
1. Compute an advection velocity vector $V$ at position $P$ and time $t$. The exact formulation for $V$ is not given in the sources [G].
2. Advect the sampling coordinates linearly using the velocity and time: $P' = P + V \cdot speed \cdot t$ [G].
3. Evaluate the base Perlin noise function at the advected position scaled by the spatial frequency: $f = \text{PerlinNoise}(P' \cdot scale)$ [G].
**Formulas:** $P' = P + V \cdot speed \cdot t$, where $P'$ is the advected position, $V$ is the advection velocity, $speed$ is the advection magnitude, and $t$ is time [G]. $f = \text{PerlinNoise}(P' \cdot scale)$, where $f$ is the output scalar and $scale$ is the spatial frequency [G].
**Parameters:** $scale$ controls spatial frequency and $speed$ controls advection magnitude [G]. Typical values are not given in the sources.
**Edge cases:** Not given in the sources.
**Pseudocode:**
```python
def flow_noise(P, t, scale=1.0, speed=1.0):
    # Step 1: Compute advection velocity V at position P and time t.
    # The exact formulation for V is not given in the sources.
    V = (0.0, 0.0, 0.0)  # Not given in the sources.
    
    # Step 2: Advect coordinates linearly
    P_advected = (P[0] + V[0] * speed * t, P[1] + V[1] * speed * t, P[2] + V[2] * speed * t)
    
    # Step 3: Evaluate standard Perlin noise at the advected position
    # perlin_noise is defined in the parent article [Perlin Gradient and Interpolation Functions](5415-perlin-gradient-and-interpolation-functions.md)
    return perlin_noise(P_advected[0] * scale, P_advected[1] * scale, P_advected[2] * scale)
```

## Background
Flow Noise was presented by Perlin and Neyret [PN01] as a Perlin-like noise function for generating time-varying flow textures with swirling and advection [S1, S2]. It was developed to simulate dynamic phenomena in computer graphics where static noise functions are insufficient [S1, S2].
