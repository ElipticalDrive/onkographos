# Improved Perlin Noise

Also called: Better Gradient Noise, KKS08 Perlin Noise, Kensler Noise

## Overview
Improved Perlin Noise, introduced by Kensler et al. [KKS08], is a lattice gradient noise function that applies three mutually orthogonal improvements to the original Perlin noise [Per85, Per02] to address axial decorrelation, band-limitation, and surface noise quality [S1, S2, S3]. It distinguishes itself from standard Perlin noise by replacing the hash and reconstruction kernels with optimized variants that reduce directional artifacts and provide better spectral control [S1, S2, S3].

## How it works
**Inputs and Outputs:**
*   **Input:** A point in space $\mathbf{x} \in \mathbb{R}^d$ (typically $d=3$) [S1, S2].
*   **Output:** A scalar noise value $n(\mathbf{x})$ [S1, S2].

**Data Structures:**
*   **Gradient Table:** A separate table of gradient vectors, distinct from the hash indices [S1, S2].
*   **Storage Layout:** The method requires $O(dN)$ storage, where $N$ is the period and $d$ is the number of dimensions [S3]. Exact bit-packing or table indexing layout is Not given in the sources [S1, S2, S3].

**Steps:**
1.  Apply a modified hash function combined with a separate gradient table to improve axial decorrelation [S1, S2, S3].
2.  Use a different reconstruction kernel to improve band-limitation [S1, S2, S3].
3.  Apply a projection method to improve the quality of noise on 2D surfaces using solid noise [S1, S2, S3].

**Formulas:**
The noise is computed as a weighted sum of gradient contributions to achieve spectral control [S3]. Exact kernel weights, hash functions, and projection formulas are Not given in the sources [S1, S2, S3].

**Parameters:**
*   **Period $N$:** Influences the $O(dN)$ storage complexity [S3].
*   **Reconstruction Kernel:** Specific kernel parameters are Not given in the sources [S1, S2, S3].

**Edge Cases and Pitfalls:**
*   The method is generally slower than standard Perlin noise [S3].
*   Additional precision or boundary pitfalls are Not given in the sources [S1, S2, S3].

## Subtopics

### [3D Perlin Noise](11323-3d-perlin-noise.md)
Standard 3D implementation of Perlin noise. It lacks the axial decorrelation and spectral control improvements of Improved Perlin Noise. Choose it when maximum performance is required and directional artifacts are acceptable.

### [Flow Noise](17017-flow-noise.md)
Noise that varies with a flow field. It differs from Improved Perlin Noise by coupling the noise value to a velocity vector rather than evaluating it on a static lattice. Choose it for simulating fluid-like or directional phenomena.

### [GPU-Optimized Perlin Noise (BBS)](18928-gpu-optimized-perlin-noise-bbs.md)
GPU-optimized variant of Perlin noise. It differs from Improved Perlin Noise by prioritizing hardware execution speed over the axial decorrelation and solid noise features. Choose it for real-time rasterization where performance outweighs the specific quality improvements of KKS08.

## Operating characteristics
*   **Time Complexity:** Generally slower than Perlin noise [S3].
*   **Memory Complexity:** $O(dN)$ storage requirements, where $N$ is the period and $d$ is the number of dimensions [S3].
*   **Strengths:** Improved axial decorrelation, better band-limitation, improved surface noise quality via solid noise, supports isotropic filtering, and achieves spectral control via a weighted sum [S1, S2, S3].
*   **Limitations:** Slower performance compared to standard Perlin noise [S3].
*   **When to use:** When visual quality, particularly regarding axial artifacts and spectral properties, is prioritized over raw performance [S3].

## Background
Improved Perlin Noise was presented by Kensler et al. in 2008 [KKS08] as a set of three mutually orthogonal improvements to the original Perlin noise [Per85, Per02] [S1, S2, S3]. It is categorized as a lattice gradient noise function [S3]. The improvements apply to several lattice gradient noises, not just Perlin noise [S1, S2, S3].
