# Fractal Simplex Noise

Also called: Octaved Simplex Noise, Simplex Noise FBM

## Overview
Fractal Simplex Noise generates multi-scale procedural volume data by summing multiple octaves of Simplex Noise, building on [Fractal Brownian Motion (fBm) via Octave Summation](16998-fractal-brownian-motion-fbm-via-octave-summation.md) [S1, unofficial]. The method terminates early when the feature size (scale) becomes smaller than one pixel, determined by the inverse of the derivative `du` [S1, unofficial].

## How it works
**Inputs:**
- `pos`: Input 3D position vector [S1, unofficial].
- `scale`: Initial frequency scale [S1, unofficial].
- `seed`: Random seed for the Simplex Noise generator [S1, unofficial].
- `du`: Derivative value used to determine the pixel-scale threshold [S1, unofficial].
- `n`: Maximum number of octaves [S1, unofficial].
- `lacunarity`: Factor by which scale is multiplied each octave [S1, unofficial].
- `decay`: Factor by which amplitude is multiplied each octave [S1, unofficial].

**Outputs:**
- `result`: The accumulated fractal noise value [S1, unofficial].

**Data Structures:**
- `acc`: Floating-point accumulator, initialized to `0.0` [S1, unofficial].
- `amp`: Floating-point amplitude, initialized to `1.0` [S1, unofficial].
- `rdu`: Reciprocal derivative, calculated as `1.0 / du` [S1, unofficial].

**Numbered Steps:**
1. Initialize `acc = 0.0`, `amp = 1.0`, and `rdu = 1.0 / du` [S1, unofficial].
2. Loop for `i` from `0` to `n - 1`:
   a. Compute the scaled position: `scaled_pos = (pos.x * scale, pos.y * scale, pos.z * scale)` [S1, unofficial].
   b. Add the weighted noise to the accumulator: `acc += simplex_noise(scaled_pos, 1.0, seed * (i + 1)) * amp` [S1, unofficial].
   c. Update parameters: `scale *= lacunarity` and `amp *= decay` [S1, unofficial].
   d. Check termination: If `scale > rdu`, break the loop [S1, unofficial].
3. Return `acc` [S1, unofficial].

**Formulas:**
The accumulated value $A$ is computed as:
$$ A = \sum_{i=0}^{k-1} \text{Simplex}(\mathbf{p} \cdot \text{scale} \cdot \text{lacunarity}^i, \mathbf{s}_i) \cdot \text{decay}^i $$
Where:
- $\mathbf{p}$ is the input position [S1, unofficial].
- $\text{scale}$ is the initial frequency scale [S1, unofficial].
- $\text{lacunarity}$ is the frequency multiplier [S1, unofficial].
- $\text{decay}$ is the amplitude multiplier [S1, unofficial].
- $\mathbf{s}_i$ is the seed for octave $i$, computed as $\text{seed} \times (i + 1)$ [S1, unofficial].
- $k$ is the number of octaves actually computed, determined by $\text{scale} \cdot \text{lacunarity}^k \le \frac{1}{du}$ [S1, unofficial].

**Parameters:**
- `pos`: Input 3D position vector [S1, unofficial].
- `scale`: Initial frequency scale [S1, unofficial].
- `seed`: Random seed for noise generation [S1, unofficial].
- `du`: Derivative value used to determine pixel-scale threshold [S1, unofficial].
- `n`: Maximum number of octaves [S1, unofficial].
- `lacunarity`: Factor by which scale is multiplied each octave [S1, unofficial].
- `decay`: Factor by which amplitude is multiplied each octave [S1, unofficial].

**Edge Cases and Pitfalls:**
- **Division by Zero:** If `du` is `0`, `rdu` becomes infinite, potentially causing an infinite loop if `n` is not strictly enforced. Guard against `du == 0` [G].
- **Seed Collision:** Using `seed * (i + 1)` can lead to correlated noise if the seed has specific bit patterns. Ensure the seed is sufficiently random [G].
- **Precision Loss:** At high octaves, `amp` may underflow to zero [G].

**Pseudocode:**
```python
def fractal_simplex_noise(pos, scale, seed, du, n, lacunarity, decay):
    acc = 0.0
    amp = 1.0
    rdu = 1.0 / du
    for i in range(n):
        scaled_pos = (pos.x * scale, pos.y * scale, pos.z * scale)
        acc += simplex_noise(scaled_pos, 1.0, seed * (i + 1)) * amp
        scale *= lacunarity
        amp *= decay
        if scale > rdu:
            break
    return acc
# simplex_noise refers to the base Simplex Noise implementation defined in the parent article [S1, unofficial].
```

## Subtopics

### Absolute Value Simplex fBm
A variant of fBm using Simplex noise where the absolute value of each octave is taken before summation [S1, unofficial]. The loop adds `abs(simplexNoise(...)) * amp * 0.35f` to the accumulator [S1, unofficial]. After summation, the result is mapped back to the standard `[-1, 1]` range using a `mapToSigned` function [S1, unofficial].
