# Surface Noise (Sparse Convolution)
Also called: Sparse Convolution Noise, Sparse Convolution Surface Noise

## Overview
Surface Noise defines procedural noise directly on a surface geometry so that features flow along curvatures and adapt to topology changes, without requiring global planar mapping or texture coordinates [S1, S2]. Unlike [Simplex Noise](978-simplex-noise.md) which generates a 3D scalar field, this method evaluates 2D noise patterns intrinsically on the surface, allowing anisotropic textures (e.g., fibers) to wrap around objects naturally [S1, S2].

## How it works
**Inputs:**
1.  A 3D point $P$ on the surface.
2.  The surface normal $N$ at $P$.
3.  (Optional) A direction field $D$ at $P$ for anisotropic textures [S1, S2].

**Outputs:**
*   A scalar noise value $n(P)$ representing the texture intensity at $P$ [S1, S2].

**Data Structures:**
*   **Kernel:** A sparse convolution kernel $K$ defined in a local 2D tangent space. The kernel is splatted locally at sample points on the surface [S1, S2].
*   **Direction Field:** A vector field $D(x)$ defined over the surface, providing orientation for anisotropic features [S1, S2].

**Steps:**
1.  **Local Frame Construction:** Construct a local 2D coordinate system (tangent plane) at point $P$ using the normal $N$. Let $u$ and $v$ be orthonormal basis vectors spanning the tangent plane such that $\{u, v, N\}$ forms a right-handed basis [S1, S2].
2.  **Kernel Splatting:** The noise is generated by locally splatting kernels onto the surface. This avoids global parameterization [S1, S2].
3.  **Evaluation:** Evaluate the noise function using the 3D point coordinates and the surface normal. For anisotropic textures, incorporate the direction field $D$ to orient the kernel [S1, S2].
4.  **Anisotropic Orientation:** If a direction field is provided, align the kernel's principal axis with $D$ within the tangent plane [S1, S2].

**Pseudocode:**
```python
def evaluate_surface_noise(P, N, D=None):
    """
    Evaluate surface noise at point P with normal N.
    D is an optional direction vector for anisotropic textures.
    """
    # Construct local tangent basis
    # Choose an arbitrary vector not parallel to N
    if abs(N.x) < 0.9:
        tangent1 = normalize(cross(N, (1.0, 0.0, 0.0)))
    else:
        tangent1 = normalize(cross(N, (0.0, 1.0, 0.0)))
    
    tangent2 = cross(N, tangent1)
    
    # If direction field is provided, align kernel with it
    # Otherwise, use tangent1 as the primary axis
    if D is not None:
        # Project D onto tangent plane
        D_proj = D - dot(D, N) * N
        if length(D_proj) > 0:
            primary_axis = normalize(D_proj)
        else:
            primary_axis = tangent1
    else:
        primary_axis = tangent1
        
    secondary_axis = cross(N, primary_axis)
    
    # The noise evaluation relies on sparse convolution kernels
    # splatted in this local frame. The specific kernel function
    # and sample distribution are implementation-specific details
    # of the sparse convolution noise generator [S1, S2].
    # [G] In practice, this involves querying a hash grid or
    # spatial structure of kernel centers projected into the
    # (primary_axis, secondary_axis) plane.
    
    # Placeholder for the core sparse convolution evaluation
    # which maps the local 2D coordinates (dot(P, primary_axis), dot(P, secondary_axis))
    # to a noise value using splatted kernels.
    noise_value = sparse_convolution_eval(primary_axis, secondary_axis, P)
    
    return noise_value
```

**Edge Cases and Pitfalls:**
*   **Degenerate Normals:** If $N$ is zero or undefined, the tangent basis cannot be constructed. Guard against singularities at poles or degenerate geometry [S1, S2].
*   **Direction Field Discontinuities:** If $D$ is not smoothly varying, texture orientation may exhibit abrupt jumps. Methods for designing smooth fields are referenced in [FSDH07] [S1].

## Subtopics

### Anisotropic Surface Noise
Extends the base method by incorporating a direction field $D$ to orient fibers or grains. Sets it apart by allowing textures to "flow" around objects rather than being fixed in space. Choose when texturing woven cloth, straw, or hair [S1, S2].

### Isotropic Surface Noise
Uses no direction field. Sets it apart by providing uniform texture orientation relative to the surface curvature. Choose for general surface detail where orientation is irrelevant [S1, S2].

## Operating characteristics
*   **Time Complexity:** Depends on the sparse convolution evaluation. Typically efficient as it avoids global parameterization and relies on local kernel splatting [S1, S2].
*   **Memory Complexity:** Low, as it does not store texture coordinates or global parameterization maps. Requires storage for the sparse convolution kernel data structure [S1, S2].
*   **Strengths:** No texture coordinates needed; features adapt to topology changes; anisotropic textures flow naturally around objects [S1, S2].
*   **Limitations:** Requires access to surface normals and potentially a direction field; may be computationally more expensive per sample than simple 3D noise if the sparse convolution structure is not optimized [S1, S2].
*   **When to use:** Texturing objects made of fibers (straw baskets, woven cloth) where orientation matters [S1, S2].
*   **When not to use:** When a "solid" feel is desired (use [Simplex Noise](978-simplex-noise.md) instead) or when surface normals are unavailable [S1, S2].

## Background
Developed by Lagae et al. [LLDD09a], building on hints from [Cha07, 5.2]. It was introduced as an alternative to solid texturing and surface parameterization-based noise, enabling procedural generation of noise patterns directly on surfaces without preprocessing [S1, S2].
