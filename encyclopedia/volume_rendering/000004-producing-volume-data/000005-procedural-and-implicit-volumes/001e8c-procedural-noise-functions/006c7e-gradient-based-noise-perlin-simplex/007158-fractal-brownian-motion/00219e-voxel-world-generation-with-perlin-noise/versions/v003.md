# Voxel World Generation with Perlin Noise

Also called: Blobby Cave Generation, Procedural Voxel Generation, Voxel Density Field Generation with Perlin Noise, World Generation

## Overview
This method generates a 3D voxel-based world by evaluating fractal Brownian motion (fBm) noise against a threshold to determine voxel existence and material type (stone, dirt, grass) [S1, unofficial]. It solves the problem of creating coherent, organic volumetric structures (such as 'blobby' cave systems) from procedural noise, similar to Dungeon Generation (DRG) techniques [S3, unofficial]. It differs from simple binary voxel placement by incorporating multi-directional noise sampling and spatial constraints (like a central spawn room) to ensure playable geometry [S3, unofficial].

## How it works
**Inputs:**
*   World dimensions: `worldWidth`, `worldHeight` (from `SceneData`) [S1, unofficial].
*   Noise parameters: `seed`, `frequency`, `gain`, `threshold` (from `WorldGenerationData`) [S1, unofficial].
*   Spatial constraints: `spawnRoomRadius` for the central empty area [S3, unofficial].
*   Noise function: A 3D Perlin-like noise function `snoise` (or equivalent) [S1, unofficial].

**Outputs:**
*   A 3D texture `texture_storage_3d<r32uint, read_write>` storing packed voxel data [S1, unofficial].
*   Each 32-bit `uint` stores 4 voxels packed in (x,z) pairs within a single texel [S1, unofficial].

**Data Structures:**
*   `WorldGenerationData`:
    *   `arity`: f32
    *   `gain`: f32
    *   `frequency`: f32
    *   `threshold`: f32
    *   `seed`: f32 [S1, unofficial]
*   `SceneData`:
    *   `screenWidth`: u32, `screenHeight`: u32
    *   `worldWidth`: u32, `worldHeight`: u32
    *   `octantSize`: u32, `octreeHighestLevel`: u32
    *   `tonemap`: u32, `rayBounces`: u32, `screenFilter`: u32
    *   `sunEnabled`: u32, `antiSmearEnabled`: u32
    *   `mousePosX`: u32, `mousePosY`: u32
    *   `sunDirX`: f32, `sunDirY`: f32, `sunDirZ`: f32
    *   `sunIntensity`: f32, `time`: f32, `denoiseStrength`: f32 [S1, unofficial]
*   Voxel Packing Layout (within a 32-bit `uint`):
    *   Bits 0-7: Voxel at (x, z) offset (0,0) relative to texel [S1, unofficial].
    *   Bits 8-15: Voxel at (0,1) [S1, unofficial].
    *   Bits 16-23: Voxel at (1,0) [S1, unofficial].
    *   Bits 24-31: Voxel at (1,1) [S1, unofficial].
    *   Each voxel entry contains:
        *   Bits 0-3: Material index [S1, unofficial].
        *   Bits 4-7: Albedo/Color index [S1, unofficial].

**Algorithm Steps:**

1.  **Initialize Noise Offset:** Generate a random 3D offset to shift the noise field, ensuring unique world generation per seed.
    ```python
    noiseOffset = Vector3(
        rng.Next(-9999, 9999),
        rng.Next(-9999, 9999),
        rng.Next(-9999, 9999)
    )
    ```
    [S3, unofficial]

2.  **Compute Workgroup Mapping:** In a compute shader, map the global invocation ID to voxel coordinates. The workgroup size is typically (8, 4, 8) [S1, unofficial]. The voxel position is derived from the texel position:
    ```python
    voxelPos.x = texelPos.x * 2
    voxelPos.y = texelPos.y
    voxelPos.z = texelPos.z * 2
    ```
    [S1, unofficial]

3.  **Iterate Voxel Block:** Loop over the 2x2 block of voxels in the x and z dimensions corresponding to the current texel:
    ```python
    for x in range(2):
        for z in range(2):
            offsetVoxelPos = vec3<u32>(voxelPos.x + x, voxelPos.y, voxelPos.z + z)
            # Process voxel at offsetVoxelPos
    ```
    [S1, unofficial]

4.  **Calculate Distance and Spawn Room Factor:**
    *   Calculate Euclidean distance from the world origin (0,0,0) to the voxel location:
        $$d = \text{distance}(\text{ivec3}(0,0,0), \text{location})$$
        [S2, unofficial]
    *   Compute a 'room' factor to guarantee an empty spawn area in the center. This uses `SmoothStep` and `InverseLerp` based on `spawnRoomRadius`:
        ```python
        room = Mathf.SmoothStep(0f, 1f, Mathf.InverseLerp(spawnRoomRadius - 2f, spawnRoomRadius + 2f, distToCenter))
        ```
        [S3, unofficial]

5.  **Evaluate Noise Density:**
    *   If distance $d > 10$, generate noise value. Otherwise, the voxel is empty (return `false` or 0) [S2, unofficial].
    *   Compute the base density $d$ using the 3D noise function. The noise function can be implemented as a custom 3D noise averaging six 2D Perlin samples with phase offsets [S3, unofficial]:
        ```python
        noise = Noise3D((p + noiseOffset) * caveNoiseScale)
        ```
        Where `Noise3D` is:
        ```python
        def Noise3D(p):
            xy = Mathf.PerlinNoise(p.x, p.y)
            yz = Mathf.PerlinNoise(p.y, p.z)
            xz = Mathf.PerlinNoise(p.x, p.z)
            yx = Mathf.PerlinNoise(p.y + 31.7f, p.x + 17.3f)
            zy = Mathf.PerlinNoise(p.z + 11.9f, p.y + 47.1f)
            zx = Mathf.PerlinNoise(p.z + 5.3f, p.x + 23.5f)
            return (xy + yz + xz + yx + zy + zx) / 6f
        ```
        [S3, unofficial]
    *   Alternatively, use fBm with `snoise` (see [S1, unofficial] for `snoise` implementation details):
        ```python
        noise_val = fbm(pos, octaves, lacunarity, gain, base_frequency, seed)
        ```
        [S1, unofficial]
    *   Clamp the density $d$ to the minimum of the noise-derived density and the room factor:
        $$d = \text{Min}(d, \text{room})$$
        [S3, unofficial]
    *   Calculate final density value:
        $$d = \text{Clamp01}(0.62 + (noise - 0.5) \times 1.6)$$
        [S3, unofficial]

6.  **Determine Voxel Existence and Material:**
    *   Check if voxel exists: If `noise > threshold` AND `voxelPos.y < worldGenerationData.ceiling`, the voxel is occupied. Otherwise, set to 0 (air) and continue [S1, unofficial].
    *   If distance $d \le 10$, return `false` (empty) [S2, unofficial].
    *   If noise value $val > 0.5$, return `true` (occupied) [S2, unofficial].
    *   Determine material color:
        *   Default `voxelColor` = 1u (stone) [S1, unofficial].
        *   Check 5 voxels above (y+1 to y+5). If any fail the noise/ceiling check, set `voxelColor` = 3u (dirt) [S1, unofficial].
        *   If the immediate voxel above (y+1) fails OR current y is `ceiling-1`, set `voxelColor` = 7u (grass) [S1, unofficial].
    *   Border Check: If the voxel is on the border (defined by `IsBorder`), set density to 1.0 to create an indestructible outer shell [S3, unofficial].

7.  **Pack and Store Voxel Data:**
    *   Pack voxel data:
        ```python
        voxelData = (u32(voxelColor) << 4u) | u32(voxelMaterial)
        ```
        [S1, unofficial]
    *   Store in the 3D texture using bit manipulation to update the specific 8-bit slot within the 32-bit uint [S1, unofficial]:
        ```python
        def SetVoxel(voxelPos, voxelType):
            texelPos = vec3<u32>(voxelPos.x >> 1, voxelPos.y, voxelPos.z >> 1)
            packedVoxel = textureLoad(voxels, texelPos).r
            mask = 0xFF
            xOdd = voxelPos.x & 0x1
            zOdd = (voxelPos.z & 0x1) << 1
            shiftCount = (xOdd | zOdd) * 8
            mask = mask << shiftCount
            mask = ~mask
            packedVoxel &= mask
            packedVoxel |= voxelType << shiftCount
            textureStore(voxels, texelPos, vec4<u32>(packedVoxel, 0, 0, 0))
        ```
        [S1, unofficial]

**Pseudocode for Noise Functions:**

The core noise function `snoise` (3D Perlin-like) is implemented as follows [S1, unofficial]:
```python
def snoise(v: vec3<f32>) -> f32:
    C = vec2<f32>(1.0 / 6.0, 1.0 / 3.0)
    D = vec4<f32>(0.0, 0.5, 1.0, 2.0)
    i = floor(v + dot(v, C.yyy))
    x0 = v - i + dot(i, C.xxx)
    g = step(x0.yzx, x0.xyz)
    l = vec3<f32>(1.0) - g
    i1 = min(g.xyz, l.zxy)
    i2 = max(g.xyz, l.zxy)
    x1 = x0 - i1 + C.xxx
    x2 = x0 - i2 + C.yyy
    x3 = x0 - D.yyy
    i = mod289(i)
    p = permute(permute(permute(i.z + vec4<f32>(0.0, i1.z, i2.z, 1.0)) + i.y + vec4<f32>(0.0, i1.y, i2.y, 1.0)) + i.x + vec4<f32>(0.0, i1.x, i2.x, 1.0))
    n_ = 0.142857142857
    ns = n_ * D.wyz - D.xzx
    j = p - 49.0 * floor(p * ns.z * ns.z)
    x_ = floor(j * ns.z)
    y_ = floor(j - 7.0 * x_)
    x = x_ * ns.x + ns.yyyy
    y = y_ * ns.x + ns.yyyy
    h = vec4<f32>(1.0) - abs(x) - abs(y)
    b0 = vec4<f32>(x.xy, y.xy)
    b1 = vec4<f32>(x.zw, y.zw)
    s0 = floor(b0) * 2.0 + vec4<f32>(1.0)
    s1 = floor(b1) * 2.0 + vec4<f32>(1.0)
    sh = -step(h, vec4<f32>(0.0))
    a0 = b0.xzyw + s0.xzyw * sh.xxyy
    a1 = b1.xzyw + s1.xzyw * sh.zzww
    p0 = vec3<f32>(a0.xy, h.x)
    p1 = vec3<f32>(a0.zw, h.y)
    p2 = vec3<f32>(a1.xy, h.z)
    p3 = vec3<f32>(a1.zw, h.w)
    norm = taylorInvSqrt(vec4<f32>(dot(p0, p0), dot(p1, p1), dot(p2, p2), dot(p3, p3)))
    p0 *= norm.x
    p1 *= norm.y
    p2 *= norm.z
    p3 *= norm.w
    m = max(0.5 - vec4<f32>(dot(x0, x0), dot(x1, x1), dot(x2, x2), dot(x3, x3)), vec4<f32>(0.0))
    m = m * m
    return 105.0 * dot(m * m, vec4<f32>(dot(p0, x0), dot(p1, x1), dot(p2, x2), dot(p3, x3)))
```
[S1, unofficial]

The fBm summation is:
```python
def fbm(pos: vec3<f32>, octaves: u32, lacunarity: f32, gain: f32, base_frequency: f32, seed: f32) -> f32:
    amplitude = 1.0
    frequency = base_frequency
    sum = 0.0
    p = pos
    for i in range(octaves):
        sum += amplitude * snoise_seeded(p * frequency, seed)
        frequency *= lacunarity
        amplitude *= gain
    return sum
```
[S1, unofficial]

**Edge Cases and Pitfalls:**
*   **Precision:** The use of `mod289` in `snoise` requires careful handling of floating-point precision for large coordinates. [S1, unofficial]
*   **Boundaries:** The outer shell border check ensures the world does not leak, but `IsBorder` must be correctly defined relative to world dimensions. [S3, unofficial]
*   **Degenerate Input:** If `spawnRoomRadius` is larger than the world size, the entire world may be empty. [S3, unofficial]

## Operating characteristics
*   **Time Complexity:** $O(W \times H \times D)$ where $W, H, D$ are world dimensions, as each voxel is evaluated once. The noise evaluation is $O(1)$ per voxel. [S1, S2, S3, unofficial]
*   **Memory Complexity:** $O(W \times H \times D / 4)$ due to packing 4 voxels per 32-bit uint. [S1, unofficial]
*   **Measured Performance:** Not given in the sources.
*   **Scaling:** Scales linearly with world size. The use of compute shaders allows parallel evaluation of voxels. [S1, unofficial]
*   **Strengths:** Generates organic, cave-like structures; efficient packing reduces memory usage; flexible material assignment. [S1, S3, unofficial]
*   **Limitations:** May require post-processing for smooth surfaces (e.g., Marching Cubes); noise artifacts can appear at boundaries if not handled. [S3, unofficial]
*   **When to use:** When generating voxel-based worlds with organic caves and varied terrain. [S1, S3, unofficial]
*   **When not to use:** When smooth, continuous surfaces are required without post-processing; when deterministic, non-procedural layouts are needed.

## Background
This method originates from procedural generation techniques used in voxel-based games and simulations. The use of fBm and Perlin noise for voxel density is a common approach in indie game development, as seen in projects like `webgpu-voxel-raymarching` [S1, unofficial], `RayTracer` [S2, unofficial], and `UnityVoxelTerrain` [S3, unofficial]. The specific 'blobby' cave generation technique is inspired by Dungeon Generation (DRG) methods [S3, unofficial].
