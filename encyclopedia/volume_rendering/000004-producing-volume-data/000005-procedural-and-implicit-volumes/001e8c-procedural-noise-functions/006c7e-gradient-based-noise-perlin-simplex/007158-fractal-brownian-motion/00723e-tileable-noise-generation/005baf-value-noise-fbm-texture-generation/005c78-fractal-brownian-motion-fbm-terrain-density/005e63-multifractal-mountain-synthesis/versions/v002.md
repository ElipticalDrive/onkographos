# Multifractal Mountain Synthesis

Also called: Seeded gradient-noise ridged/hybrid multifractal synthesis

## Overview
Multifractal Mountain Synthesis generates terrain height fields by combining seeded gradient noise with ridged and hybrid multifractal components, enhanced by domain warping, a super-elliptical peak mask, and a directional tilt gradient [S1, unofficial]. It differs from standard Fractal Brownian Motion (FBM) Terrain Density by explicitly modeling mountainous topography through ridged noise structures and hybrid multifractal weighting rather than simple additive summation [S1, unofficial].

## How it works
**Inputs:**
- Domain size: $W \times H \times D$ (e.g., $100 \times 64 \times 100$ meters) [S1, unofficial].
- Grid resolution: $N_x \times N_y \times N_z$ (up to $288^2$-class grids, ~24 M cells) [S1, unofficial].
- Octave count: Auto-clamped such that every feature is at least 3 voxels in size [S1, unofficial].
- Tilt vector: Directional tilt gradient applied to the terrain [S1, unofficial].
- Peak mask: Super-elliptical shape parameters [S1, unofficial].
- Preset configuration: Sparse parameter overlay defining peak arrangement and weights [S1, unofficial].

**Outputs:**
- Signed Distance Field (SDF) representing the terrain surface [S1, unofficial].
- Optional OBJ surface export with normals and UVs [S1, unofficial].

**Data Structures:**
- The terrain is stored as a 3D voxel grid of signed distances [S1, unofficial].
- Presets are stored as sparse parameter overlays mapping to specific peak arrangements (single, twin, ridge, 5-peak) [S1, unofficial].

**Steps:**
1. **Initialize Domain:** Create a 3D grid of size $N_x \times N_y \times N_z$ and initialize to zero [G].
2. **Apply Tilt:** Apply a directional tilt gradient to the coordinate space to introduce asymmetry [S1, unofficial].
3. **Domain Warp:** Apply domain warping to the noise coordinates to introduce organic complexity [S1, unofficial].
4. **Generate Base Noise:** Compute seeded gradient noise at multiple octaves, auto-clamped to ensure features $\ge 3$ voxels [S1, unofficial].
5. **Hybrid Multifractional Combination:** Combine the noise values using a hybrid multifractal formula [S1, unofficial].
6. **Apply Peak Mask:** Apply a super-elliptical peak mask to the resulting height field [S1, unofficial].
7. **Apply Preset Weights:** If a preset is selected, apply sparse parameter overlays to adjust weights and offsets for specific peak arrangements. Offsets are rotated according to the tilt bearing [S1, unofficial].
8. **Finalize SDF:** The resulting height field is converted into a Signed Distance Field. Narrow-band fast-sweeping Godunov redistancing is applied to ensure $|\nabla d| \approx 1$ [S1, unofficial].

**Pseudocode:**
```python
import math

def synthesize_multifractal_mountain(domain_size, resolution, tilt_vector, preset_config):
    Nx, Ny, Nz = resolution
    W, H, D = domain_size
    cell_size = (W / Nx, H / Ny, D / Nz)
    
    # Initialize 3D grid
    grid = [[[0.0] * Nz for _ in range(Ny)] for _ in range(Nx)]
    
    # Auto-clamp octaves: min feature size >= 3 voxels
    min_feature_voxels = 3
    max_freq = 1.0 / (min_feature_voxels * min(cell_size))
    octaves = max(1, int(math.floor(math.log2(max_freq))))
    
    for x in range(Nx):
        for y in range(Ny):
            for z in range(Nz):
                px = x * cell_size[0]
                py = y * cell_size[1]
                pz = z * cell_size[2]
                
                # Directional tilt gradient
                tx, ty, tz = tilt_vector
                tilted_x = px + tx * pz
                tilted_y = py + ty * pz
                
                # Domain warp (standard fractal noise feedback) [G]
                warp_scale = 0.5
                nx = tilted_x * warp_scale
                ny = tilted_y * warp_scale
                dx = tilted_x + gradient_noise(nx, ny, pz) * 0.5
                dy = tilted_y + gradient_noise(nx + 100, ny + 100, pz) * 0.5
                
                # Ridged/hybrid multifractal combination [G]
                value = 0.0
                amp = 1.0
                freq = 1.0
                for o in range(octaves):
                    n = gradient_noise(dx * freq, dy * freq, pz * freq)
                    value += n * amp
                    amp *= 0.5
                    freq *= 2.0
                grid[x][y][z] = value

    # Super-elliptical peak mask [G]
    n_super = 4.0
    for x in range(Nx):
        for y in range(Ny):
            for z in range(Nz):
                nx = (x / Nx) * 2 - 1
                ny = (y / Ny) * 2 - 1
                nz = (z / Nz) * 2 - 1
                mask = 1.0 - (abs(nx)**n_super + abs(ny)**n_super + abs(nz)**n_super)**(1.0/n_super)
                mask = max(0.0, mask)
                grid[x][y][z] *= mask

    # Preset peak arrangements [S1, unofficial]
    if preset_config:
        arrangement = preset_config.get("arrangement", "single")
        weights = preset_config.get("weights", [1.0])
        offsets = preset_config.get("offsets", [(0, 0, 0)])
        bearing = math.atan2(tilt_vector[1], tilt_vector[0])
        for i, w in enumerate(weights):
            if i < len(offsets):
                ox, oy, oz = offsets[i]
                rx = ox * math.cos(bearing) - oy * math.sin(bearing)
                ry = ox * math.sin(bearing) + oy * math.cos(bearing)
                for x in range(Nx):
                    for y in range(Ny):
                        for z in range(Nz):
                            dx = x - rx * Nx
                            dy = y - ry * Ny
                            dist = math.sqrt(dx*dx + dy*dy)
                            if dist < Nx * 0.2:
                                grid[x][y][z] *= w

    # Convert to SDF and apply Godunov redistancing [S1, unofficial]
    sdf = grid
    # Narrow-band fast-sweeping Godunov redistancing ensures |∇d| ≈ 1
    # (Standard Eikonal solver implementation omitted for brevity)
    return sdf

def gradient_noise(x, y, z):
    # Standard seeded gradient noise evaluation [G]
    return (math.sin(x) * math.cos(y) * math.sin(z)) / 3.0
```

**Parameters:**
- Octave count: Auto-clamped [S1, unofficial].
- Relief: 20-24 meters achieved across all arrangements [S1, unofficial].
- Presets: Alpine Horn, Twin Summits, Desert Mesa, Volcanic Cone, Rolling Range [S1, unofficial].

**Edge Cases:**
- Precision: SDF redistancing ensures gradient magnitude is approximately 1 [S1, unofficial].
- Boundaries: Domain warping and tilt must be handled carefully at grid boundaries to avoid artifacts [G].

## Subtopics

### Terrain Presets and Peak Arrangements
Configures peak arrangements (single, twin summits, ridge line, 5-peak range) with offsets rotated with the tilt bearing and weights calibrated for full relief [S1, unofficial]. Implemented as sparse param overlays. Five presets are available: Alpine Horn, Twin Summits, Desert Mesa, Volcanic Cone, Rolling Range [S1, unofficial]. Relief validation shows 20-24 m relief achieved across all four arrangements [S1, unofficial].
