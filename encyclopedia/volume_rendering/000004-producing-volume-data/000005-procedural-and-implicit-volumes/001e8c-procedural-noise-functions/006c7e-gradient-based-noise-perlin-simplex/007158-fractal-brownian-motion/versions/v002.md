# Fractal Brownian Motion

Also called: 3D Perlin Noise with Fractal Brownian Motion (FBM), 3D Perlin-like Noise, 3D Perlin-like Noise and Fractal Brownian Motion (FBM), Fractional Brownian Motion, Octave Perlin Noise

## Overview
Fractal Brownian Motion (FBM) is a procedural noise construction that generates self-similar, multi-scale stochastic patterns by summing multiple octaves of a base noise function with increasing frequency and decreasing amplitude [S4][S7, S9, unofficial]. It solves the problem of creating fractal-like noise with many frequencies by combining variations of a single base noise function whose parameters are scaled differently [S4]. Unlike its sibling [Simplex Noise](978-simplex-noise.md) or [Value Noise](4008-value-noise.md), which define the local interpolation behavior, FBM defines the spectral summation strategy across scales [22470-tileable-noise-generation.md].

## How it works
FBM constructs a fractal noise field by evaluating a base gradient noise function (such as [Perlin Noise](3860-gradient-based-noise-perlin-simplex.md)) at multiple scales and summing the results [S4]. The base noise provides smooth, continuous values, while the summation introduces high-frequency detail [S11, unofficial].

### Inputs and Outputs
- **Input**: A 3D query point $\mathbf{p} \in \mathbb{R}^3$, the number of octaves $n$, the lacunarity parameter $\beta$ (typically 1), and the base noise function $noise(\mathbf{p})$ which returns values in $[-1, 1]$ [S4].
- **Output**: A scalar value $B_n(\mathbf{p})$ representing the fractal noise at $\mathbf{p}$ [S4].

### Data Structures
The method requires no persistent data structures beyond those of the underlying base noise function (e.g., a permutation table and gradient vectors as defined in [Gradient-based Noise (Perlin/Simplex)](3860-gradient-based-noise-perlin-simplex.md)) [S12, unofficial].

### Parameters
- **Octaves ($n$)**: The number of noise layers to sum. Typical values are 4–7 [S10, S14, S19, unofficial].
- **Lacunarity ($\beta$)**: Controls the rate of frequency increase and amplitude decay. $\beta=1$ corresponds to $1/f$ noise, common in nature [S4].
- **Persistence**: The amplitude decay factor per octave. Typically $0.5$ (halving amplitude each octave) [S7, S19, unofficial].
- **Frequency Multiplier**: The factor by which the input coordinate is scaled each octave. Typically $2.0$ [S10, S19, unofficial].
- **Seed**: Used to initialize the base noise permutation table [S22, unofficial].

### Steps
1. **Initialize**: Set `sum = 0.0`, `amplitude = 0.5`, and `position = p` [S9, S19, unofficial].
2. **Loop Octaves**: For $i$ from $0$ to $n-1$:
   a. Evaluate the base noise at the current position: $val = noise(position)$ [S9, S19, unofficial].
   b. Add the weighted contribution to the sum: $sum += amplitude \times val$ [S9, S19, unofficial].
   c. Update the position for the next octave: $position = position \times lacunarity$ [S9, S19, unofficial].
   d. Update the amplitude: $amplitude = amplitude \times persistence$ [S9, S19, unofficial].
3. **Return**: Return `sum` [S9, S19, unofficial].

### Formula
The formal definition of FBM with $n$ octaves is [S4]:

$$ B_n(\mathbf{p}) = \sum_{i=1}^n o_i(\mathbf{p}), \quad \text{with} \quad o_i(\mathbf{p}) = \frac{noise(2^{i-1}\mathbf{p})}{2^{\beta(i-1)}} $$

Where:
- $noise(\mathbf{p}) \in [-1, 1]$ is the base noise function [S4].
- $\beta \in [0, 2]$ is the lacunarity parameter [S4].
- $n \in \mathbb{N}^+$ is the number of octaves [S4].

For $\beta=1$, this simplifies to summing $noise(2^{i-1}\mathbf{p}) / 2^{i-1}$, which corresponds to halving the amplitude and doubling the frequency each octave [S4].

### Pseudocode
```python
def fbm(p, octaves, base_noise_func, persistence=0.5, lacunarity=2.0):
    """
    Computes Fractal Brownian Motion.
    
    Args:
        p: vec3, query point.
        octaves: int, number of octaves.
        base_noise_func: function, takes vec3, returns float in [-1, 1].
        persistence: float, amplitude decay per octave.
        lacunarity: float, frequency multiplier per octave.
        
    Returns:
        float, the FBM value.
    """
    total = 0.0
    amplitude = 0.5
    position = p
    
    for _ in range(octaves):
        total += amplitude * base_noise_func(position)
        position = position * lacunarity
        amplitude = amplitude * persistence
        
    return total
```

### Edge Cases and Pitfalls
- **Single Octave Limit**: A single-octave implementation (e.g., `fbm3` returning `0.5 * noise3(p)`) lacks the multi-scale detail of true FBM [S1, S14, unofficial].
- **Precision**: High octave counts with high lacunarity can lead to floating-point precision issues at large coordinates [G]. Using modulo arithmetic or tiling techniques can mitigate this [22470-tileable-noise-generation.md].
- **Boundary Conditions**: Standard FBM is not periodic [22470-tileable-noise-generation.md]. For tileable volumes, the base noise must be tileable (e.g., using Fourier-domain techniques or coordinate wrapping) [22470-tileable-noise-generation.md].
- **Division by Zero**: If the base noise function involves vector normalization, ensure the gradient vector is not zero to avoid division by zero errors [S14, unofficial].

## Subtopics

### [Noise Field Generator](1302-noise-field-generator.md)
Creates a 3D scalar field by summing multiple octaves of layered Simplex noise, offset by a linear vertical gradient [1302-noise-field-generator.md]. It distinguishes itself by explicitly incorporating a vertical bias and Simplex variants, rather than generic Perlin noise [1302-noise-field-generator.md].

### [Global Cloud Cover with Curl Noise](1711-global-cloud-cover-with-curl-noise.md)
Generates global cloud patterns by applying procedural noise to volumetric air blocks, creating 2D cloud patterns on a spherical surface by combining octaves of mixed Perlin and Worley noise [1711-global-cloud-cover-with-curl-noise.md].

### [3D Perlin-Worley Noise Texture Generation](2355-3d-perlin-worley-noise-texture-generation.md)
Generates volumetric density maps by combining low-frequency Perlin noise for broad mass with inverted Worley (cellular) noise to carve hollows, producing a puffy cumulus appearance [2355-3d-perlin-worley-noise-generation.md]. It uses fBm principles to sum multiple noise octaves.

### [Voxel World Generation with Perlin Noise](2556-voxel-world-generation-with-perlin-noise.md)
Generates 3D voxel worlds by evaluating fBm noise against a threshold to determine voxel existence and material type, creating organic structures like cave systems [2556-voxel-world-generation-with-perlin-noise.md].

### [Ridged Multifractal](4249-ridged-multifractal.md)
Generates sharp, ridge-like structures by applying a non-linear transformation to the absolute value of base noise, combined with inter-octave feedback [4249-ridged-multifractal.md]. It builds on FBM by replacing linear summation with a ridge-specific kernel and multiplicative feedback.

### [Tileable Noise Generation](22470-tileable-noise-generation.md)
Produces procedural noise fields that are spatially periodic, ensuring seamless continuity when repeated [22470-tileable-noise-generation.md]. It differs from FBM by enforcing strict modulo arithmetic or Fourier techniques for periodicity, whereas FBM defines the spectral summation [22470-tileable-noise-generation.md].

### FBM BVH Construction
A specific application of the Bounding Volume Hierarchy (BVH) method to FBM, where octaves are presorted by range and have analytic bounds, requiring no memory storage for bounds [S4]. It uses analytic expressions for $\Delta_i$ and $s(i,n)$ to compute bounds, with $\beta=1$ ensuring all octaves share the same Lipschitz constant [S4].

### High Frequency Surface Noise Remapping
Introduces high-frequency noise on cloud surfaces by remapping the noise value using a range defined by low-frequency noise, used by Guerilla Games [S24, unofficial].

### Derivative Erosion FBM
Accumulates derivatives across octaves, dampening amplitude via `1/(1+|grad|^2)` to create realistic erosion patterns where steep slopes stay smooth [S25].

### Perlin Noise Erosion
Erodes the surface of an SDF by adding negative Perlin noise values to the signed distance, effectively pushing the surface outward where noise is negative [S26, unofficial].

## Operating characteristics
- **Time Complexity**: $O(n)$ per query point, where $n$ is the number of octaves. Each octave requires one evaluation of the base noise function [S4].
- **Memory Complexity**: $O(1)$ additional memory beyond the base noise function's storage (e.g., permutation table) [S4].
- **Performance**: The method is computationally inexpensive per sample but can be costly in raymarching due to the high number of samples required for volumetric rendering [S20, unofficial].
- **Strengths**: Produces natural, multi-scale detail; simple to implement; widely supported [S4].
- **Limitations**: Not inherently periodic; high-frequency artifacts may appear if lacunarity is too high; single-octave implementations lack detail [S1, S14, unofficial].
- **When to Use**: Generating stochastic patterns with details at potentially many different scales [S4].
- **When Not to Use**: When strict periodicity is required without additional tiling techniques [22470-tileable-noise-generation.md].

## Background
FBM has been extensively used in computer graphics to create stochastic patterns with details at potentially many different scales [S4]. The method is a standard technique in procedural generation for volume rendering, terrain synthesis, and texture mapping [S4].
