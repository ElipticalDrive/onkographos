# Gradient-based Noise (Perlin/Simplex)
Also called: Gradient Noise, Value Gradient Noise
## Overview
Gradient-based noise generates continuous scalar fields by interpolating dot products of random gradient vectors and distance vectors from grid vertices [S1][S2, unofficial][S4, unofficial][S10, unofficial]. It solves the problem of generating natural-looking volumetric textures (e.g., clouds, terrain, smoke) that lack the repetitive, uniform appearance of single-layer white noise [S3][S4, unofficial]. It differs from [Value Noise](4008-value-noise.md) by using gradient vectors and dot products rather than scalar values at lattice points, and from [Worley Noise](1726-worley-noise.md) by producing smooth, correlated fields rather than cellular patterns [S1][S2, unofficial][S4, unofficial].
## Shared principles
All gradient-based noise functions share a common mechanism:
1.  **Lattice Definition:** The space is tiled by a regular grid (cubic for Perlin, simplex/tetrahedral for Simplex) [S1][S2, unofficial][S4, S6, unofficial].
2.  **Gradient Assignment:** Each lattice vertex is assigned a fixed, pre-computed gradient vector (or hash-derived index into a gradient set) [S1][S2, unofficial][S5, unofficial].
3.  **Dot Product Contribution:** For an input point $p$, the contribution of each surrounding vertex $V_i$ is calculated as the dot product between the vertex's gradient vector $g_i$ and the vector $d_i = p - V_i$ [S1][S2, unofficial][S4, unofficial].
4.  **Interpolation:** The contributions are interpolated using a smoothing function (e.g., Hermite cubic for Perlin, polynomial falloff for Simplex) based on the distance of $p$ from the vertices [S1][S2, unofficial][S3, unofficial].
5.  **Normalization:** The final result is scaled to a standard range, typically $[-1, 1]$ [S3][S5, unofficial].
## Subtopics

### [Simplex Noise](978-simplex-noise.md)
Simplex Noise generates continuous scalar fields by interpolating contributions from the corners of a simplex grid (tetrahedra in 3D). It solves the directional artifacts inherent in cubic-grid noise (like classic Perlin noise) by using a skewed triangular/tetrahedral lattice. It scales to higher dimensions with $O(n^2)$ complexity, compared to $O(n 2^n)$ for classic noise, and requires fewer multiplications.

### [3D Perlin-like Noise and Fractal Brownian Motion (FBM)](1260-3d-perlin-like-noise-and-fractal-brownian-motion-fbm.md)
3D Perlin-like Noise generates smooth pseudo-random scalar values on a 3D unit lattice using hash-derived gradient vectors, Hermite smoothing, and trilinear interpolation. Fractal Brownian Motion (FBM) constructs multi-scale fractal noise by summing multiple octaves of a base noise function (such as Perlin noise) with scaled frequency and amplitude. Together, they solve the problem of generating natural-looking volumetric textures (e.g., clouds, terrain, smoke) that lack the repetitive, uniform appearance of single-layer noise. They differ from [Simplex Noise](978-simplex-noise.md) by using a cubic lattice with trilinear interpolation rather than a simplex grid with tetrahedral interpolation, and from [Improved Perlin Noise (4D)](3723-improved-perlin-noise-4d.md) by operating in 3D space with standard cubic smoothing functions.

### [Improved Perlin Noise (4D)](3723-improved-perlin-noise-4d.md)
A GPU-based implementation of 4D Perlin noise using texture-based permutation and gradient tables to avoid branching and improve performance over traditional array-based lookup.

### [Perlin Noise 2D](4211-perlin-noise-2d.md)
A gradient noise function that generates smooth random values by interpolating dot products of gradient vectors and distance vectors at grid corners.

### Gradient Displacement Noise
#### definition
Simulates fluid transport by displacing coordinates using per-octave gradient vectors derived from noise [S1].
#### step
Loop from $i = 1.0$ to $7.0$. Compute gradient vector $gr$ using `gradn` with time-modulated position. Scale gradient by a matrix generated by `makem2` with time-modulated parameters. Update position $p$ by adding half the gradient. Accumulate result $rz$ using a sinusoidal function of noise at $p$, divided by $z$. Mix current position $p$ with base position $bp$ using factor $0.77$. Specifically: 1. Compute gradient `gr = gradn(i * p * 0.34 + time * 1.0)` using finite differences of noise. 2. Rotate gradient using `makem2`. 3. Displace `p += gr * GRAD_SCALE`. 4. Accumulate sinusoidal ridged noise. 5. Mix displaced `p` with base `bp` using `ADVECTION`. 6. Scale `z`, `p`, and `bp` for next octave [S1].
#### parameter
$FLOW\_SPEED=0.6$, $BASE\_SPEED=1.9$, $ADVECTION=0.77$, $GRAD\_SCALE=0.5$ [S1].

### Perlin Gradient and Interpolation Functions
#### step
Gradient selection uses `hash & 15` to pick one of 12 gradient directions in 3D, mapping to x, y, or z with sign flips based on bits 0 and 1 [S2, unofficial].
#### formula
Fade function: $Fade(t) = t \cdot t \cdot t \cdot (t \cdot (t \cdot 6 - 15) + 10)$; smooth interpolation polynomial applied to fractional coordinates [S2, unofficial].
Lerp function: $Lerp(a, b, t) = a + (b - a) \cdot t$; standard linear interpolation [S2, unofficial].
Grad function: $Grad(hash, x, y, z)$: $h = hash \& 15$; $u = h < 8 ? x : y$; $v = h < 4 ? y : h == 12 || h == 14 ? x : z$; return $((h \& 1) == 0 ? u : -u) + ((h \& 2) == 0 ? v : -v)$; computes dot product of gradient vector and distance vector [S2, unofficial].

## Background
Gradient noise was introduced by Ken Perlin in 1985 for the movie *Tron* [S1][S2, unofficial][S4, unofficial]. It was later improved in 2002 to reduce directional artifacts (Improved Perlin Noise) [S4, unofficial]. Simplex Noise was introduced by Ken Perlin in 2001 to address the high computational cost and artifacts of cubic-grid noise in higher dimensions [S4][S6, unofficial]. These methods are standard in procedural generation for volume rendering, terrain synthesis, and texture mapping [S3][S4, unofficial].
