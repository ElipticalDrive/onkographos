# Gradient-based Noise (Perlin/Simplex)

Also called: Gradient Noise, Gradient-based Procedural Noise

## Overview
Gradient-based noise generates smooth, continuous scalar fields by interpolating dot products of random gradient vectors assigned to grid vertices [S1][S2, unofficial]. It solves the problem of creating coherent, non-periodic procedural textures for volume rendering by ensuring $C^1$ continuity across cell boundaries, eliminating the blocky artifacts of value noise [S1, S3, unofficial]. It is distinguished from [Value Noise](4008-value-noise.md) by using gradient vectors and dot products rather than scalar values, and from [Worley Noise](1726-worley-noise.md) by its reliance on grid topology rather than distance to nearest feature points.

## Shared principles
All gradient-based noise methods share the core mechanism of mapping a query point $P = (x, y, z)$ to a scalar value $V$ through deterministic mathematical operations, ensuring that nearby points yield similar values (coherence) or structured differences, depending on the variant [S1, S2, S3, S4, S5, unofficial][S7].

1.  **Coordinate Normalization:** Input coordinates are often normalized or wrapped to fit specific grid or periodic structures. For grid-based noise, integer cell coordinates are derived via floor operations, while fractional parts determine interpolation weights or distance vectors [S1, S4, S5, unofficial].
2.  **Hashing and Randomness:** To introduce pseudo-randomness without storing large lookup tables, integer coordinates are hashed into floating-point values. Common hash functions use trigonometric operations (e.g., `sin(dot(p, float2(12.9898, 78.233))) * 43758.5453`) or linear congruential generators to produce uniform random values in $[0, 1]$ or $[-1, 1]$ [S4, unofficial][S7].
3.  **Interpolation and Smoothing:** When using grid-based values, smooth transitions are achieved via Hermite interpolation or polynomial falloff functions (e.g., $3t^2 - 2t^3$) to eliminate visible grid artifacts [S5, unofficial][S7].
4.  **Fractal Brownian Motion (FBM):** Complex detail is often generated by summing multiple octaves of a base noise function at different frequencies and amplitudes: $V = \sum_{i=0}^{n} a_i \cdot \text{noise}(f_i \cdot P)$, where $a_i$ is the amplitude and $f_i$ is the frequency (lacunarity) of octave $i$ [S5, S6, unofficial][S7].
5.  **Domain Warping and Advection:** To simulate motion or turbulence, the input coordinates to the noise function are displaced by another noise field or a flow vector, creating non-linear distortions in the resulting density field [S1, S5, unofficial][S7].

## Subtopics

### [Simplex Noise](978-simplex-noise.md)
Simplex Noise is a gradient-based procedural noise function that generates smooth, continuous scalar fields in 2D, 3D, and 4D space. It solves the directional artifacts inherent in earlier grid-based noise functions (like Perlin Noise) by using a skewed simplex grid (triangles in 2D, tetrahedra in 3D) instead of a cubic grid, which reduces computational complexity and improves isotropy. It is primarily used for terrain generation, texture synthesis, and as a density function $f(x,y,z)$ for implicit surfaces or voxel terrain.

### [3D Perlin-like Noise and Fractal Brownian Motion (FBM)](1260-3d-perlin-like-noise-and-fractal-brownian-motion-fbm.md)
3D Perlin-like Noise generates smooth, pseudo-random scalar values on a 3D unit lattice using hash-derived corner values, Hermite smoothing, and trilinear interpolation. Fractal Brownian Motion (FBM) constructs complex, multi-scale detail by summing multiple octaves of this base noise function at increasing frequencies and decreasing amplitudes. Unlike [Simplex Noise](978-simplex-noise.md), which uses a tetrahedral grid to reduce directional artifacts, 3D Perlin-like Noise relies on a cubic grid and standard trilinear interpolation, making it computationally simpler but potentially more prone to grid-aligned artifacts. It serves as the foundational procedural density generator for volumetric phenomena such as clouds, fog, and terrain.

### [Improved Perlin Noise (4D)](3723-improved-perlin-noise-4d.md)
Improved Perlin Noise (4D) is a procedural noise function that generates smooth, coherent scalar values in four dimensions by interpolating dot products of gradient vectors at the corners of a 4D hypercube. It extends the 3D Improved Perlin Noise method to support time-varying texture generation and volumetric animation by treating the fourth dimension as time or an additional spatial axis. It is distinguished from its 3D sibling [3D Perlin-like Noise and Fractal Brownian Motion (FBM)](1260-3d-perlin-like-noise-and-fractal-brownian-motion-fbm.md) by its ability to produce seamless temporal evolution without spatial artifacts, and from [Simplex Noise](978-simplex-noise.md) by its reliance on a regular hypercubic grid rather than a simplex lattice.

### [Perlin Noise 2D](4211-perlin-noise-2d.md)
Perlin Noise 2D is a gradient noise function that generates smooth, continuous random scalar values by interpolating dot products of gradient vectors and distance vectors at the corners of the grid cell containing the query point. It builds on [Gradient-based Noise (Perlin/Simplex)](3860-gradient-based-noise-perlin-simplex.md) by specializing the general framework to two dimensions. Unlike [Simplex Noise](978-simplex-noise.md), which uses a simplex grid to reduce directional artifacts, Perlin Noise 2D operates on a standard square grid, relying on specific smooth interpolation functions to maintain coherence.

### [Perlin Gradient and Interpolation Functions](5415-perlin-gradient-and-interpolation-functions.md)
This article defines the core mathematical primitives of classic 3D Perlin noise: the gradient vector selection, the dot product computation, and the quintic fade (smoothing) function used to interpolate between gradient contributions. It solves the problem of generating coherent, continuous scalar fields from discrete grid points by ensuring $C^1$ continuity (smooth first derivatives) across cell boundaries, which eliminates visible grid artifacts in the resulting volume density. It differs from Simplex noise by using a cubic grid topology and from improved 4D Perlin noise by focusing on the specific 3D gradient set and quintic interpolation curve.

## Background
Gradient-based noise was introduced by Ken Perlin in 1985 to improve upon earlier value noise methods by providing better continuity and fewer artifacts [S1][S2, unofficial]. Simplex Noise was later developed by Perlin in 2001 to address the grid-aligned artifacts and computational inefficiency of the original cubic grid approach [S2, unofficial]. These methods are foundational in procedural generation for computer graphics, widely used in terrain synthesis, texture mapping, and volumetric rendering for clouds and smoke [S3, S16, unofficial].
