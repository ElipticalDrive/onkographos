# Gradient-based Noise (Perlin/Simplex)

Also called: Gradient Noise, Perlin Noise, Simplex Noise

## Overview
Gradient-based noise functions generate smooth, continuous scalar fields by interpolating dot products of pseudo-random gradient vectors assigned to grid vertices [S1][S2, unofficial]. This family solves the problem of creating coherent, deterministic procedural textures and density fields for volume rendering, terrain generation, and implicit surfaces, avoiding the blocky artifacts of value noise [S1][S2, unofficial]. It is distinguished from sibling methods like Worley Noise (distance-based) and Sine-based generation (analytic periodicity) by its reliance on local gradient interpolation to ensure $C^1$ or $C^2$ continuity across cell boundaries [S1][S2, unofficial].

## Shared principles
All gradient-based noise methods share the core mechanism of mapping a query point $P$ to a scalar value $V$ through deterministic mathematical operations, ensuring that nearby points yield similar values (coherence) [S1][S2, unofficial].

1.  **Grid Localization:** The input space is partitioned into a regular grid (hypercube for Perlin, simplex for Simplex). The integer coordinates of the cell containing $P$ are identified, and the relative position within the cell is computed [S1][S2, unofficial].
2.  **Gradient Assignment:** Each grid vertex is associated with a pseudo-random gradient vector. These vectors are selected via a permutation table (hash) that maps integer coordinates to a fixed set of directions [S1][S2, unofficial].
3.  **Dot Product Evaluation:** The contribution of each vertex is calculated as the dot product between its gradient vector $\mathbf{g}$ and the distance vector $\mathbf{d}$ from the vertex to the query point $P$: $D = \mathbf{g} \cdot \mathbf{d}$ [S1][S2, unofficial].
4.  **Smooth Interpolation:** The vertex contributions are blended using a smooth interpolation function (fade curve) applied to the fractional coordinates. Common fade functions include Hermite ($3t^2 - 2t^3$) and Quintic ($6t^5 - 15t^4 + 10t^3$) to eliminate directional artifacts and ensure derivative continuity [S1][S2, unofficial].
5.  **Permutation Tables:** To avoid storing large lookup tables for gradients, integer coordinates are hashed using a permutation table (typically a shuffled array of $0..255$ doubled to $512$ for overflow handling) to select gradient indices [S1][S2, unofficial].

## Subtopics

### [Simplex Noise](978-simplex-noise.md)
Simplex Noise uses a skewed simplex grid (triangles in 2D, tetrahedra in 3D) instead of a cubic grid. This reduces computational complexity from $O(2^d)$ to $O(d \cdot 2^{d-1})$ and eliminates directional artifacts inherent in Perlin Noise. It is chosen for high-performance terrain and texture synthesis where isotropy is critical.

### [3D Perlin-like Noise and Fractal Brownian Motion (FBM)](1260-3d-perlin-like-noise-and-fractal-brownian-motion-fbm.md)
This method uses the standard orthogonal grid with quintic interpolation and explicit permutation tables for gradient hashing. It is the foundational technique for organic volumetric structures like clouds and fog. Unlike Simplex Noise, it relies on trilinear interpolation of 8 corners. FBM extends this by summing multiple octaves at increasing frequencies and decreasing amplitudes to generate multi-scale detail.

### [Improved Perlin Noise (4D)](3723-improved-perlin-noise-4d.md)
Extends 3D Improved Perlin Noise to 4D by treating the fourth dimension as time or an additional spatial axis. It retains the orthogonal grid structure but optimizes permutation lookup for GPU execution using 2D texture-based tables for 2D hash combinations. It is distinct from Simplex Noise in its grid topology and is used for time-varying volumetric animation.

### [Perlin Noise 2D](4211-perlin-noise-2d.md)
A 2D variant using a fixed square grid with 8 specific gradient directions and quintic interpolation. It is computationally simpler than Simplex Noise but more prone to directional artifacts. It is used for 2D texture synthesis and terrain heightmaps.

### [Perlin Gradient and Interpolation Functions](5415-perlin-gradient-and-interpolation-functions.md)
Defines the core mathematical primitives: gradient vector selection via bit manipulation of hash values, dot product evaluation, and polynomial interpolation (fade/lerp). It ensures $C^1$ continuity across cell boundaries in the foundational 3D implementation.

### Gradient Displacement Noise
#### definition
Simulates fluid transport by displacing coordinates using per-octave gradient vectors derived from noise [S1].
#### step
1.  Loop from $i = 1.0$ to $7.0$ [S1].
2.  Compute gradient vector $\mathbf{gr}$ using finite differences of noise: $\mathbf{gr} = \text{gradn}(i \cdot \mathbf{p} \cdot 0.34 + \text{time} \cdot 1.0)$ [S1].
3.  Rotate gradient using a matrix generated by `makem2` with time-modulated parameters [S1].
4.  Displace position $\mathbf{p}$ by adding half the gradient: $\mathbf{p} += \mathbf{gr} \cdot \text{GRAD\_SCALE}$ [S1].
5.  Accumulate result using a sinusoidal function of noise at $\mathbf{p}$, divided by $z$ [S1].
6.  Mix current position $\mathbf{p}$ with base position $\mathbf{bp}$ using factor $0.77$ [S1].
#### parameter
$\text{FLOW\_SPEED}=0.6$, $\text{BASE\_SPEED}=1.9$, $\text{ADVECTION}=0.77$, $\text{GRAD\_SCALE}=0.5$ [S1].

### Hash-based Value Noise
#### definition
A simpler 3D noise function using 1D hash interpolation, often called Simplex-like or Value Noise [S2, unofficial].
#### step
1.  Define step vector $\text{step} = \text{float3}(110, 241, 171)$ [S2, unofficial].
2.  Compute integer part $\mathbf{i} = \lfloor \mathbf{x} \rfloor$ and fractional part $\mathbf{f} = \text{frac}(\mathbf{x})$ [S2, unofficial].
3.  Compute smooth interpolation weights: $u = f \cdot f \cdot (3.0 - 2.0 \cdot f)$ [S2, unofficial].
4.  Perform 3D trilinear interpolation of hash values at the 8 corners of the unit cube using $\text{hash}(\mathbf{n} + \text{dot}(\text{step}, \text{float3}(x,y,z)))$ [S2, unofficial].

## Background
Gradient noise was introduced by Ken Perlin in 1985 ("Improving Noise") to generate natural textures for the movie *Tron* [S1][S2, unofficial]. Simplex Noise was later developed by Perlin in 2001 to address the directional artifacts and computational inefficiency of the original grid-based approach [S2, unofficial]. These methods are standard in computer graphics for procedural texture synthesis, terrain generation, and volumetric density modeling [S3, unofficial].
