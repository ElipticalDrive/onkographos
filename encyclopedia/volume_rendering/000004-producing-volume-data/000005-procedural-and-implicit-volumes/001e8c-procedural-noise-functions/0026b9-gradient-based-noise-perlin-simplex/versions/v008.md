# Gradient-based Noise (Perlin/Simplex)

Also called: Gradient Noise, Perlin Noise, Simplex Noise

## Overview
Gradient-based noise functions generate smooth, continuous scalar fields by interpolating dot products of pseudo-random gradient vectors assigned to grid vertices [S1][S2, unofficial]. This family solves the problem of creating organic, non-repeating volumetric structures (such as clouds, terrain, or smoke) without storing large texture maps, while avoiding the directional artifacts and grid-aligned seams inherent in earlier value noise methods [S1][S2, unofficial]. It is distinguished from sibling methods like [Worley Noise](1726-worley-noise.md) (which uses distance to cell centers) and [Value Noise](4008-value-noise.md) (which interpolates scalar values) by relying on vector gradients and dot products to ensure $C^1$ continuity and isotropy [S1][S2, unofficial].

## Shared principles
The family shares the following mechanism, terms, and math:

1.  **Gradient Assignment**: Each integer lattice point (vertex) in the domain is assigned a pseudo-random gradient vector $\mathbf{g}$. In 3D, common sets include 12 face diagonals of a cube or 12 axis-aligned vectors [S1][S2, unofficial].
2.  **Dot Product Contribution**: The noise value at a query point $\mathbf{P}$ is derived from the dot product between the gradient vector $\mathbf{g}_i$ at a lattice corner $i$ and the distance vector $\mathbf{d}_i = \mathbf{P} - \mathbf{V}_i$ from that corner to $\mathbf{P}$:
    $$ n_i = \mathbf{g}_i \cdot \mathbf{d}_i $$
3.  **Smoothing/Fade Function**: To ensure smooth transitions ($C^1$ continuity), the fractional coordinates of $\mathbf{P}$ within the cell are passed through a fade function $f(t)$ before interpolation. The quintic function $f(t) = 6t^5 - 15t^4 + 10t^3$ is standard for Perlin variants, while Simplex uses a different geometric approach [S1][S2, unofficial].
4.  **Interpolation**: The contributions from the cell corners are combined using linear interpolation (`lerp`) along the axes, weighted by the fade values [S1][S2, unofficial].
5.  **Hashing**: Integer coordinates are mapped to gradient indices using a permutation table to avoid modulo operations and ensure uniform distribution [S1][S2, unofficial].

## Subtopics

### [Simplex Noise](978-simplex-noise.md)
Simplex Noise uses a skewed simplex grid (triangles in 2D, tetrahedra in 3D) to reduce directional artifacts and computational complexity compared to cubic grids. It is chosen for terrain generation and texture synthesis where isotropy is critical.

### [3D Perlin-like Noise and Fractal Brownian Motion (FBM)](1260-3d-perlin-like-noise-and-fractal-brownian-motion-fbm.md)
This method uses the standard cubic grid with quintic or Hermite interpolation and is commonly combined with FBM to generate multi-scale organic detail. It is distinguished from Simplex by its reliance on the cubic topology and from 4D Perlin by its specific 3D lattice structure.

### [Improved Perlin Noise (4D)](3723-improved-perlin-noise-4d.md)
Extends the 3D method to four dimensions by interpolating dot products at the corners of a 4D hypercube, treating the fourth dimension as time for seamless animation. It is distinguished from 3D Perlin by its temporal coherence and from Simplex by its regular hypercubic grid.

### [Perlin Noise 2D](4211-perlin-noise-2d.md)
Specializes the general framework to two dimensions using a standard square grid and specific gradient selection logic based on hash bits. Unlike Simplex, it relies on the square grid topology.

### [Perlin Gradient and Interpolation Functions](5415-perlin-gradient-and-interpolation-functions.md)
Defines the core primitives of classic 3D Perlin noise, including the 12-gradient set and quintic fade function, ensuring $C^1$ continuity across cell boundaries. It differs from Simplex by using a cubic grid and from 4D Perlin by focusing on the 3D gradient set.

### Gradient Displacement Noise
Simulates fluid transport by displacing coordinates using per-octave gradient vectors derived from noise [S1].
- **Step**: Loop from $i = 1.0$ to $7.0$. Compute gradient vector $\mathbf{gr}$ using `gradn` with time-modulated position. Scale gradient by a matrix generated by `makem2` with time-modulated parameters. Update position $\mathbf{p}$ by adding half the gradient. Accumulate result $rz$ using a sinusoidal function of noise at $\mathbf{p}$, divided by $z$. Mix current position $\mathbf{p}$ with base position $\mathbf{bp}$ using factor $0.77$ [S1].
- **Parameters**: `FLOW_SPEED=0.6`, `BASE_SPEED=1.9`, `ADVECTION=0.77`, `GRAD_SCALE=0.5` [S1].

### Hash-based Value Noise
A simpler 3D noise function using 1D hash interpolation, often called Simplex-like or Value Noise [S2, unofficial].
- **Step**: Define `step = float3(110, 241, 171)`. Compute integer part `i = floor(x)` and fractional part `f = frac(x)`. Compute smooth interpolation weights: `u = f * f * (3.0 - 2.0 * f)`. Perform 3D trilinear interpolation of hash values at the 8 corners of the unit cube using `hash(n + dot(step, float3(x,y,z)))` [S2, unofficial].

## Background
Gradient noise was introduced by Ken Perlin in 1985 with his original 2D and 3D noise functions, later improved in 2002 with the "Improved Noise" paper which introduced the quintic fade function and better gradient sets [S1][S2, unofficial]. Simplex Noise was introduced by Perlin in 2001 to address the grid-aligned artifacts of the original Perlin noise [S2, unofficial]. These methods are foundational in procedural generation for volume rendering, used to create density fields for clouds, smoke, and terrain [S3, unofficial].
