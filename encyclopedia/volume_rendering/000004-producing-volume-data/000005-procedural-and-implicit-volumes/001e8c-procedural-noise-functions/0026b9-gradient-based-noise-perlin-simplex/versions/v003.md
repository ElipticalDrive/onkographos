# Gradient-based Noise (Perlin/Simplex)
## Overview
Gradient-based noise generates continuous scalar fields by interpolating dot products of random gradient vectors and distance vectors from grid vertices [S1]. It solves the problem of generating natural-looking volumetric textures (e.g., clouds, terrain, smoke) that lack the repetitive, uniform appearance of single-layer white noise [G]. It differs from [Value Noise](4008-value-noise.md) by using gradient vectors and dot products rather than scalar values at lattice points, and from [Worley Noise](1726-worley-noise.md) by producing smooth, correlated fields rather than cellular patterns [S1].

## Subtopics

### [Simplex Noise](978-simplex-noise.md)
Simplex Noise is a gradient-based procedural noise function that generates continuous scalar fields by interpolating contributions from the corners of a simplex grid (tetrahedra in 3D) [see [Simplex Noise](978-simplex-noise.md)]. It reduces directional artifacts inherent in cubic-grid noise by using a skewed triangular/tetrahedral lattice [see [Simplex Noise](978-simplex-noise.md)]. It scales to higher dimensions with $O(n^2)$ complexity, compared to $O(n 2^n)$ for classic noise, and requires fewer multiplications [see [Simplex Noise](978-simplex-noise.md)].

### [3D Perlin-like Noise and Fractal Brownian Motion (FBM)](1260-3d-perlin-like-noise-and-fractal-brownian-motion-fbm.md)
3D Perlin-like Noise generates smooth pseudo-random scalar values on a 3D unit lattice using hash-derived corner values, Hermite smoothing, and trilinear interpolation [see [3D Perlin-like Noise and Fractal Brownian Motion (FBM)](1260-3d-perlin-like-noise-and-fractal-brownian-motion-fbm.md)]. Fractal Brownian Motion (FBM) constructs multi-scale fractal noise by summing multiple octaves of a base noise function with scaled frequency and amplitude [see [3D Perlin-like Noise and Fractal Brownian Motion (FBM)](1260-3d-perlin-like-noise-and-fractal-brownian-motion-fbm.md)]. Together, they solve the problem of generating natural-looking volumetric textures (e.g., clouds, terrain, smoke) that lack the repetitive, uniform appearance of single-layer noise [see [3D Perlin-like Noise and Fractal Brownian Motion (FBM)](1260-3d-perlin-like-noise-and-fractal-brownian-motion-fbm.md)]. They differ from [Simplex Noise](978-simplex-noise.md) by using a cubic lattice with trilinear interpolation rather than a simplex grid with tetrahedral interpolation, and from [Improved Perlin Noise (4D)](3723-improved-perlin-noise-4d.md) by operating in 3D space with standard cubic smoothing functions [see [3D Perlin-like Noise and Fractal Brownian Motion (FBM)](1260-3d-perlin-like-noise-and-fractal-brownian-motion-fbm.md)].

### [Improved Perlin Noise (4D)](3723-improved-perlin-noise-4d.md)
Improved Perlin Noise (4D) is a procedural noise function that generates smooth, continuous random values in four dimensions by interpolating dot products of gradient vectors at the corners of a 4D hypercube [see [Improved Perlin Noise (4D)](3723-improved-perlin-noise-4d.md)]. It extends the 3D Improved Perlin Noise algorithm to support time-varying texture generation and 4D volume data synthesis, where the fourth dimension typically represents time [see [Improved Perlin Noise (4D)](3723-improved-perlin-noise-4d.md)]. Unlike its 3D sibling, it utilizes a 4D gradient set and a specific permutation hashing strategy optimized for GPU texture lookups to maintain performance [see [Improved Perlin Noise (4D)](3723-improved-perlin-noise-4d.md)].

### [Perlin Noise 2D](4211-perlin-noise-2d.md)
Perlin Noise 2D is a gradient noise function that generates smooth, continuous random values by interpolating dot products of gradient vectors and distance vectors at the corners of a 2D grid cell [see [Perlin Noise 2D](4211-perlin-noise-2d.md)]. It is the foundational 2D primitive for procedural texture generation and terrain heightmaps, distinguished from its sibling [Simplex Noise](978-simplex-noise.md) by its use of a square lattice and cubic Hermite interpolation, which results in directional artifacts along the axes but offers simpler implementation [see [Perlin Noise 2D](4211-perlin-noise-2d.md)].

### Gradient Displacement Noise
#### definition
Simulates fluid transport by displacing coordinates using per-octave gradient vectors derived from noise [S1].
#### step
Loop from $i = 1.0$ to $7.0$. Compute gradient vector $gr$ using `gradn` with time-modulated position [S1]. Scale gradient by a matrix generated by `makem2` with time-modulated parameters [S1]. Update position $p$ by adding half the gradient [S1]. Accumulate result $rz$ using a sinusoidal function of noise at $p$, divided by $z$ [S1]. Mix current position $p$ with base position $bp$ using factor $0.77$ [S1]. Specifically: 1. Compute gradient `gr = gradn(i * p * 0.34 + time * 1.0)` using finite differences of noise [S1]. 2. Rotate gradient using `makem2` [S1]. 3. Displace `p += gr * GRAD_SCALE` [S1]. 4. Accumulate sinusoidal ridged noise [S1]. 5. Mix displaced `p` with base `bp` using `ADVECTION` [S1]. 6. Scale `z`, `p`, and `bp` for next octave [S1].
#### parameter
$FLOW\_SPEED=0.6$, $BASE\_SPEED=1.9$, $ADVECTION=0.77$, $GRAD\_SCALE=0.5$ [S1].

### Hash-based Value Noise
#### definition
A simpler 3D noise function using 1D hash interpolation, often called Simplex-like or Value Noise [S2, unofficial].
#### step
Define `step = float3(110, 241, 171)`. Compute integer part `i = floor(x)` and fractional part `f = frac(x)` [S2, unofficial]. Compute smooth interpolation weights: `u = f * f * (3.0 - 2.0 * f)` [S2, unofficial]. Perform 3D trilinear interpolation of hash values at the 8 corners of the unit cube using `hash(n + dot(step, float3(x,y,z)))` [S2, unofficial].
