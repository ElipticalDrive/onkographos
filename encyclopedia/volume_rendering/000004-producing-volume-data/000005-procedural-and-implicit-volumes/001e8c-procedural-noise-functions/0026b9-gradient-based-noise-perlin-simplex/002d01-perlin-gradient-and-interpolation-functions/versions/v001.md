# Perlin Gradient and Interpolation Functions

Also called: Fade, Grad, Lerp

## Overview
This method defines the core mathematical primitives for gradient-based noise: linear interpolation (`Lerp`), the smoothing/fade function (`Fade`), and the gradient dot-product calculation (`Grad`). It solves the problem of smoothly blending between random gradient vectors assigned to grid vertices to produce continuous scalar fields. It is distinguished from its siblings by its reliance on a cubic Hermite interpolation curve (or its quintic variant) for coordinate remapping, whereas [Simplex Noise](978-simplex-noise.md) uses a simplex lattice and linear interpolation, and [Improved Perlin Noise (4D)](3723-improved-perlin-noise-4d.md) extends the gradient selection to higher dimensions.

## How it works
**Inputs:**
- `hash`: An integer hash value associated with a grid vertex.
- `x, y, z`: Floating-point coordinates of the point relative to the grid vertex (typically in $[0, 1]$).
- `a, b`: Floating-point values to interpolate.
- `t`: Interpolation factor in $[0, 1]$.

**Outputs:**
- `Fade(t)`: Remapped coordinate in $[0, 1]$ with zero first derivative at boundaries.
- `Lerp(a, b, t)`: Interpolated value.
- `Grad(hash, x, y, z)`: Dot product of the gradient vector and the distance vector.

**Data Structures:**
- `hash`: Integer. In 3D, typically derived from a permutation table lookup. The lower 4 bits are used for gradient selection.

**Formulas:**

1.  **Linear Interpolation (`Lerp`):**
    $$ \text{Lerp}(a, b, t) = a + (b - a) \cdot t $$

2.  **Fade (Smoothing) Function:**
    The standard improved fade function is a quintic polynomial:
    $$ \text{Fade}(t) = t^3 (t (t \cdot 6 - 15) + 10) $$
    $$ \text{Fade}(t) = 6t^5 - 15t^4 + 10t^3 $$
    [S1, S3, unofficial]

3.  **Gradient Selection and Dot Product (`Grad`):**
    The gradient vector is selected from a set of 12 directions in 3D space based on the hash.
    $$ h = \text{hash} \ \& \ 15 $$
    $$ u = \begin{cases} x & \text{if } h < 8 \\ y & \text{otherwise} \end{cases} $$
    $$ v = \begin{cases} y & \text{if } h < 4 \\ z & \text{if } h == 12 \text{ or } h == 14 \\ x & \text{otherwise} \end{cases} $$
    $$ \text{Grad}(hash, x, y, z) = \begin{cases} u & \text{if } (h \ \& \ 1) == 0 \\ -u & \text{otherwise} \end{cases} + \begin{cases} v & \text{if } (h \ \& \ 2) == 0 \\ -v & \text{otherwise} \end{cases} $$
    [S1, unofficial]

**Parameters:**
- The hash mask `15` (binary `1111`) is standard for 3D Perlin noise to select from 16 indices, mapping to 12 unique gradient directions. [S1, unofficial]

**Edge Cases and Pitfalls:**
- **Boundary Continuity:** The original smoothing function $3t^2 - 2t^3$ only provides $C^1$ continuity. The quintic function provides $C^2$ continuity, eliminating visible artifacts in derivatives. [S2][S3, unofficial]
- **Hash Range:** The `Grad` function assumes `hash & 15` is used. Using a larger mask without adjusting the logic in `v` will select invalid gradient directions. [S1, unofficial]

**Pseudocode:**

```python
def lerp(a: float, b: float, t: float) -> float:
    """Standard linear interpolation."""
    return a + (b - a) * t

def fade(t: float) -> float:
    """
    Quintic interpolation polynomial.
    Maps t in [0, 1] to [0, 1] with zero first and second derivatives at boundaries.
    """
    return t * t * t * (t * (t * 6.0 - 15.0) + 10.0)

def grad(hash_val: int, x: float, y: float, z: float) -> float:
    """
    Computes the dot product between the gradient vector and the distance vector (x, y, z).
    Selects one of 12 gradient directions in 3D based on the lower 4 bits of hash_val.
    """
    h = hash_val & 15
    
    # Select u component
    if h < 8:
        u = x
    else:
        u = y
        
    # Select v component
    if h < 4:
        v = y
    elif h == 12 or h == 14:
        v = x
    else:
        v = z
        
    # Apply sign flips based on bits 0 and 1
    if h & 1:
        u = -u
    if h & 2:
        v = -v
        
    return u + v
```

## Subtopics

### Quintic Noise
A variant using the quintic interpolation function to achieve $C^2$ continuity, eliminating visible grid artifacts in derivatives compared to the standard $C^1$ Hermite interpolation. It computes analytical derivatives for the noise value. [S2]
**Steps:**
1. Compute fractional coordinates $f$ and remapped coordinates $u = \text{fade}(f)$.
2. Compute derivative of fade: $du = 30 f^2 (f^2 - 2f + 1)$. [S2]
3. Retrieve hashes for the four surrounding vertices in 2D: $a, b, c, d$.
4. Compute coefficients: $k_0 = a$, $k_1 = b - a$, $k_2 = c - a$, $k_3 = a - b - c + d$.
5. Value: $k_0 + k_1 u_x + k_2 u_y + k_3 u_x u_y$.
6. Derivatives: $du \cdot (k_1 + k_3 u_y, k_2 + k_3 u_x)$. [S2]

### Improved Smoothing Function
Refers to the replacement of the original Perlin smoothing function $f(x) = 3x^2 - 2x^3$ with the quintic $f(x) = 6x^5 - 15x^4 + 10x^3$. This change improves the curve of the function and achieves better visual results by providing higher-order continuity. [S3, unofficial]

## Operating characteristics
- **Time Complexity:** $O(1)$ per noise evaluation. The fade function requires 5 multiplications and 3 additions. The grad function requires bitwise operations and comparisons.
- **Memory Complexity:** $O(1)$ for the functions themselves. Requires a permutation table (typically 512 or 1024 entries) for hash generation, which is external to these specific primitives.
- **Strengths:** The quintic fade function provides superior smoothness ($C^2$) compared to the cubic original, reducing artifacts in applications requiring derivative information (e.g., terrain erosion, fluid simulation). [S2][S3, unofficial]
- **Limitations:** The quintic function is slightly more computationally expensive than the cubic function (5 multiplications vs 3). [S3, unofficial]

## Background
The original Perlin noise used a cubic Hermite interpolation ($3t^2 - 2t^3$) for smoothing. [S3, unofficial] Later improvements, notably cited in procedural terrain generation literature, replaced this with the quintic polynomial ($6t^5 - 15t^4 + 10t^3$) to improve visual quality and continuity. [S3, unofficial] The specific gradient selection logic using `hash & 15` to pick from 12 directions is a standard implementation detail found in various 3D noise implementations. [S1, unofficial]
