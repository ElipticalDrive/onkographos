# Perlin Gradient and Interpolation Functions

Also called: Fade, Grad, Lerp

## Overview
This article defines the core mathematical primitives—gradient selection, linear interpolation, and smooth fade curves—used to construct classic Perlin noise. It solves the problem of blending directional dot-product contributions from grid vertices into a continuous scalar field. It differs from [Simplex Noise](978-simplex-noise.md) by using a hypercubic grid and axis-aligned gradients, and from [Improved Perlin Noise (4D)](3723-improved-perlin-noise-4d.md) by focusing on the foundational 3D/2D implementations rather than higher-dimensional or specific optimized variants.

## How it works
**Inputs:**
- Query point $P = (x, y, z)$ (or $(x, y)$ for 2D).
- Permutation table $P_{table}$ of size 512 (typically a shuffled $0..255$ array doubled for overflow handling) [S1, unofficial][S2].
- Gradient set: 12 specific vectors in 3D, derived from permutations [S1, unofficial].

**Outputs:**
- Scalar noise value $V$.
- Optional gradient (derivative) vector $\nabla V$ [S2].

**Data Structures:**
- `PermutationTable`: Array of 512 integers. Index $i$ maps to gradient index $P_{table}[i \pmod{256}]$ [S1, unofficial][S2].

**Steps:**

1.  **Grid Localization:**
    Compute integer coordinates $I = \lfloor P \rfloor$ and fractional coordinates $F = P - I$. $F \in [0, 1)^n$ [S1, unofficial][S2].

2.  **Gradient Selection (`Grad`):**
    For each corner of the cell, compute a hash index $h = P_{table}[I_x + P_{table}[I_y + P_{table}[I_z]]]$ (for 3D) [S1, unofficial].
    Select the gradient vector $\mathbf{g}$ based on $h \pmod{16}$ [S1, unofficial]:
    - Let $u, v$ be components of the distance vector $\mathbf{d} = P - I_{corner}$.
    - If $h < 8$, $u$ is the x-component, else y-component.
    - If $h < 4$, $v$ is the y-component; if $h == 12$ or $h == 14$, $v$ is the x-component; else z-component.
    - Sign of $u$ is negative if $h \& 1$ is true.
    - Sign of $v$ is negative if $h \& 2$ is true.
    - $\mathbf{g} = (\text{sign}_u \cdot u, \text{sign}_v \cdot v, \text{sign}_w \cdot w)$ where $w$ is the remaining component [S1, unofficial].

3.  **Dot Product Evaluation:**
    Compute contribution $D = \mathbf{g} \cdot \mathbf{d}$ for each of the $2^n$ corners [S1, unofficial][S2].

4.  **Smooth Interpolation (`Fade`):**
    Apply a fade function to $F$ to obtain interpolation weights $U = \text{Fade}(F)$ [S1, unofficial][S3, unofficial].
    - **Hermite (Classic):** $f(t) = 3t^2 - 2t^3$ [S3, unofficial].
    - **Quintic (Improved):** $f(t) = 6t^5 - 15t^4 + 10t^3$ [S2][S3, unofficial].

5.  **Linear Interpolation (`Lerp`):**
    Blend the dot products using $U$ via $n(a, b, t) = a + (b - a)t$ [S1, unofficial].
    - In 1D: $n = \text{Lerp}(D_0, D_1, U)$.
    - In 2D: $n = \text{Lerp}(\text{Lerp}(D_{00}, D_{10}, U_x), \text{Lerp}(D_{01}, D_{11}, U_x), U_y)$.
    - In 3D: Extend similarly across the z-axis [S1, unofficial].

**Pseudocode (3D, Classic Perlin):**

```python
def fade(t):
    # Classic Hermite fade: 3t^2 - 2t^3
    return t * t * t * (t * (t * 6.0 - 15.0) + 10.0)

def lerp(a, b, t):
    return a + (b - a) * t

def grad(hash_val, x, y, z):
    # Select gradient from 12 directions based on hash & 15
    h = hash_val & 15
    u = x if h < 8 else y
    v = y if h < 4 else (x if h == 12 or h == 14 else z)
    
    # Apply sign based on bits 0 and 1
    if h & 1:
        u = -u
    if h & 2:
        v = -v
        
    return u + v

def perlin_3d(x, y, z, perm_table):
    # 1. Grid Localization
    xi = int(x) & 255
    yi = int(y) & 255
    zi = int(z) & 255
    
    xf = x - int(x)
    yf = y - int(y)
    zf = z - int(z)
    
    # 2. Fade
    u = fade(xf)
    v = fade(yf)
    w = fade(zf)
    
    # 3. Hashing corners
    A = perm_table[xi] + yi
    AA = perm_table[A] + zi
    AB = perm_table[A + 1] + zi
    B = perm_table[xi + 1] + yi
    BA = perm_table[B] + zi
    BB = perm_table[B + 1] + zi
    
    # 4. Dot Products
    d000 = grad(perm_table[AA], xf, yf, zf)
    d100 = grad(perm_table[BA], xf - 1, yf, zf)
    d010 = grad(perm_table[AB], xf, yf - 1, zf)
    d110 = grad(perm_table[BB], xf - 1, yf - 1, zf)
    d001 = grad(perm_table[AA + 1], xf, yf, zf - 1)
    d101 = grad(perm_table[BA + 1], xf - 1, yf, zf - 1)
    d011 = grad(perm_table[AB + 1], xf, yf - 1, zf - 1)
    d111 = grad(perm_table[BB + 1], xf - 1, yf - 1, zf - 1)
    
    # 5. Interpolation
    x1 = lerp(d000, d100, u)
    x2 = lerp(d010, d110, u)
    y1 = lerp(x1, x2, v)
    
    x1 = lerp(d001, d101, u)
    x2 = lerp(d011, d111, u)
    y2 = lerp(x1, x2, v)
    
    return lerp(y1, y2, w)
```

**Parameters:**
- Permutation table size: 512 integers [S1, unofficial][S2].
- Gradient set size: 12 vectors in 3D [S1, unofficial].

**Edge Cases:**
- Boundary conditions: The permutation table is doubled to 512 to handle index overflow when computing $P_{table}[i+1]$ at the boundary of the 256-element cycle [S1, unofficial][S2].
- Precision: Floating point errors in $F$ calculation can cause discontinuities if not handled; using `floor` and subtraction as shown avoids this [G].

## Subtopics

### Quintic Noise
Uses the quintic interpolation function $f(t) = 6t^5 - 15t^4 + 10t^3$ instead of Hermite. This provides $C^2$ continuity (continuous second derivative), eliminating visible grid artifacts in derivatives compared to Hermite's $C^1$ continuity [S2]. It allows for exact analytical derivative computation, useful for erosion simulations or gradient-based effects [S2]. Choose this when smooth derivatives are required for physical simulation or higher-order visual effects. Link: [Improved Smoothing Function](3723-improved-perlin-noise-4d.md) (conceptually related via smoothing).

### Improved Smoothing Function
Refers specifically to the replacement of the classic $3t^2 - 2t^3$ fade curve with $6t^5 - 15t^4 + 10t^3$. This change improves the curve's shape and visual results by reducing directional artifacts more effectively than the cubic Hermite spline [S3, unofficial]. It is a direct parameter/variant choice within the Perlin framework.

## Operating characteristics
- **Time Complexity:** $O(1)$ per query point, but with a high constant factor due to multiple hash lookups, dot products, and interpolations. 3D Perlin requires 8 gradient evaluations and 15 linear interpolations [S1, unofficial].
- **Memory Complexity:** $O(1)$ auxiliary space, plus the fixed 512-integer permutation table [S1, unofficial].
- **Performance:** Slower than Simplex Noise due to the hypercubic grid requiring $2^n$ evaluations in $n$ dimensions (8 in 3D vs 4 in Simplex) [S3, unofficial].
- **Strengths:** Simple to implement, widely supported, good visual coherence [S1, unofficial].
- **Limitations:** Directional artifacts (grid lines) are visible if the fade function is not smooth enough (hence the move to Quintic) [S3, unofficial]. Computational cost grows exponentially with dimensionality [S3, unofficial].

## Background
Originated with Ken Perlin's 1985 paper "Improving Noise" and later refined in "The Perlin Noise" (1985/2002). The original smoothing function was $3x^2 - 2x^3$. Perlin later improved it to $6x^5 - 15x^4 + 10x^3$ to reduce artifacts [S3, unofficial]. The gradient selection method using 12 vectors in 3D was introduced to ensure isotropy and reduce directional bias [S1, unofficial]. It is the standard for procedural texture generation in volume rendering and terrain mapping [S3, unofficial].
