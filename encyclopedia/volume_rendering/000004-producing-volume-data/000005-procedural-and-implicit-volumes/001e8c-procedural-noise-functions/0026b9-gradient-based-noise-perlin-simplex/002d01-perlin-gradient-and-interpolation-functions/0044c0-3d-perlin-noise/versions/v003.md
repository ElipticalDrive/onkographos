# 3D Perlin Noise
Also called: BasicPerlinNoise::noise3D

## Overview
3D Perlin Noise generates a continuous scalar value for 3D space using gradient vectors at lattice points, interpolated via cubic smoothing functions [S1, unofficial].

## How it works
**Inputs and Outputs**
- Input: A 3D point $(x, y, z)$ [G].
- Output: A scalar noise value $N(x, y, z)$ [G].

**Data Structures**
- Permutation Table: An array of 256 integers used to map integer coordinates to gradient indices [S1, unofficial].
- Gradient Vectors: Selected by the permutation table index [S1, unofficial]. The standard selection logic for 3D uses the lower bits of the index to choose from permutations of $(\pm 1, \pm 1, 0)$, $(\pm 1, 0, \pm 1)$, and $(0, \pm 1, \pm 1)$ [G].

**Algorithm Steps**
1. **Integer and Fractional Parts**: Compute the integer coordinates of the lattice cube and the fractional offset within the cube [G]. Let $ix = \lfloor x \rfloor$, $iy = \lfloor y \rfloor$, $iz = \lfloor z \rfloor$, and the fractional parts be $fx = x - ix$, $fy = y - iy$, $fz = z - iz$ [G].
2. **Fade Functions**: Apply the cubic smoothing function to the fractional parts to ensure $C^1$ continuity [S1, unofficial]. The standard fade function is $t \mapsto 6t^5 - 15t^4 + 10t^3$ [G]. Let the faded values be $u = \text{fade}(fx)$, $v = \text{fade}(fy)$, $w = \text{fade}(fz)$ [G].
3. **Permutation Lookup**: Determine the indices of the 8 corners of the unit cube using the permutation table $P$ [S1, unofficial]. The indices are computed as [S1, unofficial]:
   $A = (P[ix \& 255] + iy) \& 255$
   $B = (P[(ix + 1) \& 255] + iy) \& 255$
   $AA = (P[A] + iz) \& 255$
   $AB = (P[(A + 1) \& 255] + iz) \& 255$
   $BA = (P[B] + iz) \& 255$
   $BB = (P[(B + 1) \& 255] + iz) \& 255$
4. **Gradient Dot Products**: Compute the dot product of the gradient vector at each corner with the distance vector from that corner to the sample point [S1, unofficial]. The gradient indices are retrieved via $P[AA]$, etc., and the distance vectors are $(fx, fy, fz)$, $(fx-1, fy, fz)$, etc. [S1, unofficial]:
   $p_0 = \text{Grad}(P[AA], fx, fy, fz)$ [S1, unofficial]
   $p_1 = \text{Grad}(P[BA], fx - 1, fy, fz)$ [S1, unofficial]
   $p_2 = \text{Grad}(P[AB], fx, fy - 1, fz)$ [S1, unofficial]
   $p_3 = \text{Grad}(P[BB], fx - 1, fy - 1, fz)$ [S1, unofficial]
   $p_4 = \text{Grad}(P[(AA + 1) \& 255], fx, fy, fz - 1)$ [S1, unofficial]
   $p_5 = \text{Grad}(P[(BA + 1) \& 255], fx - 1, fy, fz - 1)$ [S1, unofficial]
   $p_6 = \text{Grad}(P[(AB + 1) \& 255], fx, fy - 1, fz - 1)$ [S1, unofficial]
   $p_7 = \text{Grad}(P[(BB + 1) \& 255], fx - 1, fy - 1, fz - 1)$ [S1, unofficial]
5. **Interpolation**: Interpolate the 8 gradient contributions along the X, Y, and Z axes using the fade values $u, v, w$ [S1, unofficial]:
   $q_0 = \text{Lerp}(p_0, p_1, u)$, $q_1 = \text{Lerp}(p_2, p_3, u)$, $q_2 = \text{Lerp}(p_4, p_5, u)$, $q_3 = \text{Lerp}(p_6, p_7, u)$ [S1, unofficial]
   $r_0 = \text{Lerp}(q_0, q_1, v)$, $r_1 = \text{Lerp}(q_2, q_3, v)$ [S1, unofficial]
   $N(x, y, z) = \text{Lerp}(r_0, r_1, w)$ [S1, unofficial]
   Where $\text{Lerp}(a, b, t) = a + t(b - a)$ [G].

**Pseudocode**
```python
import math

def fade(t):
    # Cubic smoothing function [G]
    return t * t * t * (t * (t * 6 - 15) + 10)

def lerp(a, b, t):
    # Linear interpolation [G]
    return a + t * (b - a)

def grad(hash_val, x, y, z):
    # Select gradient vector based on hash_val (0-11) [G]
    h = hash_val & 15
    u = x if h < 8 else y
    v = y if h < 4 else (x if h == 12 or h == 14 else y)
    
    # Determine sign based on the least significant bit [G]
    if (h & 1) == 0:
        u = -u
    if (h & 2) == 0:
        v = -v
        
    return u + v

def perlin_noise_3d(x, y, z, perm_table):
    # 1. Integer and fractional parts [G]
    ix = int(math.floor(x))
    iy = int(math.floor(y))
    iz = int(math.floor(z))
    
    fx = x - ix
    fy = y - iy
    fz = z - iz
    
    # 2. Fade values [G]
    u = fade(fx)
    v = fade(fy)
    w = fade(fz)
    
    # 3. Permutation lookups [S1, unofficial]
    A = (perm_table[ix & 255] + iy) & 255
    B = (perm_table[(ix + 1) & 255] + iy) & 255
    
    AA = (perm_table[A] + iz) & 255
    AB = (perm_table[(A + 1) & 255] + iz) & 255
    BA = (perm_table[B] + iz) & 255
    BB = (perm_table[(B + 1) & 255] + iz) & 255
    
    # 4. Gradient dot products [S1, unofficial]
    p0 = grad(perm_table[AA], fx, fy, fz)
    p1 = grad(perm_table[BA], fx - 1, fy, fz)
    p2 = grad(perm_table[AB], fx, fy - 1, fz)
    p3 = grad(perm_table[BB], fx - 1, fy - 1, fz)
    
    p4 = grad(perm_table[(AA + 1) & 255], fx, fy, fz - 1)
    p5 = grad(perm_table[(BA + 1) & 255], fx - 1, fy, fz - 1)
    p6 = grad(perm_table[(AB + 1) & 255], fx, fy - 1, fz - 1)
    p7 = grad(perm_table[(BB + 1) & 255], fx - 1, fy - 1, fz - 1)
    
    # 5. Interpolation [S1, unofficial]
    q0 = lerp(p0, p1, u)
    q1 = lerp(p2, p3, u)
    q2 = lerp(p4, p5, u)
    q3 = lerp(p6, p7, u)
    
    r0 = lerp(q0, q1, v)
    r1 = lerp(q2, q3, v)
    
    return lerp(r0, r1, w)
```
