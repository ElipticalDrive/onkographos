# 3D Perlin Noise
Also called: BasicPerlinNoise::noise3D

## Overview
3D Perlin Noise generates a continuous scalar value for 3D space using gradient vectors at lattice points, interpolated via cubic smoothing functions [S1, unofficial]. Not given in the sources how it compares to sibling methods.

## How it works
**Inputs and Outputs**
- Input: A 3D point $(x, y, z)$ [G].
- Output: A scalar noise value $N(x, y, z)$ [G].

**Data Structures**
- Permutation Table: An array used to map integer coordinates to gradient indices [S1, unofficial].
- Gradient Vectors: Selected by the permutation table index [S1, unofficial]. The standard selection logic for 3D uses the lower bits of the index to choose from permutations of $(\pm 1, \pm 1, 0)$ and $(\pm 1, 0, \pm 1)$ and $(0, \pm 1, \pm 1)$ [G].

**Algorithm Steps**
1. **Integer and Fractional Parts**: Compute the integer coordinates of the lattice cube and the fractional offset within the cube [G]. Let $X = \lfloor x \rfloor$, $Y = \lfloor y \rfloor$, $Z = \lfloor z \rfloor$, and the fractional parts be $fx = x - X$, $fy = y - Y$, $fz = z - Z$ [G].
2. **Fade Functions**: Apply the cubic smoothing function to the fractional parts to ensure $C^1$ continuity [G]. The standard fade function is $t \mapsto 6t^5 - 15t^4 + 10t^3$ [G]. Let the faded values be $u = \text{fade}(fx)$, $v = \text{fade}(fy)$, $w = \text{fade}(fz)$ [G].
3. **Permutation Lookup**: Determine the indices of the 8 corners of the unit cube using the permutation table $P$ [S1, unofficial]. The indices are computed as [S1, unofficial]:
   $A = (P[X \& 255] + Y) \& 255$
   $B = (P[(X + 1) \& 255] + Y) \& 255$
   $AA = (P[A] + Z) \& 255$
   $AB = (P[(A + 1) \& 255] + Z) \& 255$
   $BA = (P[B] + Z) \& 255$
   $BB = (P[(B + 1) \& 255] + Z) \& 255$
4. **Gradient Dot Products**: Compute the dot product of the gradient vector at each corner with the distance vector from that corner to the sample point [S1, unofficial]. The gradient indices are retrieved via $P[AA]$, etc., and the distance vectors are $(fx, fy, fz)$, $(fx-1, fy, fz)$, etc. [S1, unofficial]:
   $p_0 = \text{Grad}(P[AA], fx, fy, fz)$
   $p_1 = \text{Grad}(P[BA], fx - 1, fy, fz)$
   $p_2 = \text{Grad}(P[AB], fx, fy - 1, fz)$
   $p_3 = \text{Grad}(P[BB], fx - 1, fy - 1, fz)$
   $p_4 = \text{Grad}(P[(AA + 1) \& 255], fx, fy, fz - 1)$
   $p_5 = \text{Grad}(P[(BA + 1) \& 255], fx - 1, fy, fz - 1)$
   $p_6 = \text{Grad}(P[(AB + 1) \& 255], fx, fy - 1, fz - 1)$
   $p_7 = \text{Grad}(P[(BB + 1) \& 255], fx - 1, fy - 1, fz - 1)$
5. **Interpolation**: Interpolate the 8 gradient contributions along the X, Y, and Z axes using the fade values $u, v, w$ [S1, unofficial]:
   $q_0 = \text{Lerp}(p_0, p_1, u)$, $q_1 = \text{Lerp}(p_2, p_3, u)$, $q_2 = \text{Lerp}(p_4, p_5, u)$, $q_3 = \text{Lerp}(p_6, p_7, u)$
   $r_0 = \text{Lerp}(q_0, q_1, v)$, $r_1 = \text{Lerp}(q_2, q_3, v)$
   $N(x, y, z) = \text{Lerp}(r_0, r_1, w)$
   Where $\text{Lerp}(a, b, t) = a + t(b - a)$ [G].

**Pseudocode**
```python
import math

def fade(t):
    # Cubic smoothing function
    return t * t * t * (t * (t * 6 - 15) + 10)

def lerp(t, a, b):
    return a + t * (b - a)

def grad(hash_val, x, y, z):
    # Select gradient vector based on hash_val (0-11)
    # Standard 3D gradients: permutations of (1,1,0), (1,0,1), (0,1,1), etc. [G]
    h = hash_val & 15
    u = x if h < 8 else y
    v = y if h < 4 else (x if h == 12 or h == 14 else y)
    
    # Determine sign based on the least significant bit
    if (h & 1) == 0:
        u = -u
    if (h & 2) == 0:
        v = -v
        
    return u + v

def perlin_noise_3d(x, y, z, perm_table):
    # 1. Integer and fractional parts
    X = int(math.floor(x))
    Y = int(math.floor(y))
    Z = int(math.floor(z))
    
    fx = x - X
    fy = y - Y
    fz = z - Z
    
    # 2. Fade values
    u = fade(fx)
    v = fade(fy)
    w = fade(fz)
    
    # 3. Permutation lookups
    # Masking with 255 is equivalent to modulo 256 for positive indices [S1, unofficial]
    A = (perm_table[X & 255] + Y) & 255
    B = (perm_table[(X + 1) & 255] + Y) & 255
    
    AA = (perm_table[A] + Z) & 255
    AB = (perm_table[(A + 1) & 255] + Z) & 255
    BA = (perm_table[B] + Z) & 255
    BB = (perm_table[(B + 1) & 255] + Z) & 255
    
    # 4. Gradient dot products [S1, unofficial]
    p0 = grad(perm_table[AA], fx, fy, fz)
    p1 = grad(perm_table[BA], fx - 1, fy, fz)
    p2 = grad(perm_table[AB], fx, fy - 1, fz)
    p3 = grad(perm_table[BB], fx - 1, fy - 1, fz)
    
    p4 = grad(perm_table[(AA + 1) & 255], fx, fy, fz - 1)
    p5 = grad(perm_table[(BA + 1) & 255], fx - 1, fy, fz - 1)
    p6 = grad(perm_table[(AB + 1) & 255], fx, fy - 1, fz - 1)
    p7 = grad(perm_table[(BB + 1) & 255], fx - 1, fy - 1, fz - 1)
    
    # 5. Interpolation [S1, unofficial]
    q0 = lerp(u, p0, p1)
    q1 = lerp(u, p2, p3)
    q2 = lerp(u, p4, p5)
    q3 = lerp(u, p6, p7)
    
    r0 = lerp(v, q0, q1)
    r1 = lerp(v, q2, q3)
    
    return lerp(w, r0, r1)
```
