# TGorillaVolumetricNoise

Also called: Volumetric Noise, cloud / smoke / fog body

## Overview
TGorillaVolumetricNoise is a procedural volumetric component that generates 3D fractal noise to create physically based emission-absorption media, such as clouds, smoke, or fog [S1]. It distinguishes itself from sibling methods by baking a smooth 0–1 density gradient into the voxel data while applying opacity via a Beer-Lambert absorption model at render time, thereby eliminating the "terracing" or hard saturation shells that occur when density is baked directly into linear blend values [S1]. It builds on [3D Perlin-like Noise and Fractal Brownian Motion (FBM)](1260-3d-perlin-like-noise-and-fractal-brownian-motion-fbm.md) for the underlying noise synthesis [S1].

## How it works
**Inputs and Outputs:**
*   **Inputs:** 3D spatial coordinates $(x, y, z)$, noise parameters (Frequency, Octaves, Persistence, Lacunarity, Seed), shaping parameters (Coverage, EdgeFalloff, Billowy), and animation offset [S1].
*   **Outputs:** A 3D texture (voxel grid) storing a smooth density gradient in the range $[0, 1]$, and a render-time absorption coefficient derived from the `Density` parameter [S1].

**Data Structures:**
The component maintains a 3D voxel grid with a configurable resolution, defaulting to $64^3$ and offering a performance preset of $32^3$ [S1]. Each voxel stores a single scalar value representing the normalized density gradient [S1]. The data is regenerated on the CPU and uploaded to the GPU upon calling `Regenerate` [S1].

**Parameters:**
*   `Frequency` (Single): Base noise scale. Higher values increase the number of noise cycles spanning the volume [S1].
*   `Octaves` (Integer): Number of FBM octaves summed. More octaves produce finer detail but increase generation cost [S1].
*   `Persistence` (Single): Amplitude falloff per octave, range $[0, 1]$. Lower values yield smoother noise; higher values yield rougher noise [S1].
*   `Lacunarity` (Single): Frequency growth factor per octave. Typically $\approx 2.0$ [S1].
*   `Coverage` (Single): Soft threshold for carving the body, range $[0, 1]$. A value of 1 keeps the whole body; lower values separate it into puffs [S1].
*   `EdgeFalloff` (Single): Radial fade toward the volume border, range $[0, 1]$. Creates a rounded blob shape instead of a cube [S1].
*   `Billowy` (Boolean): If true, applies `abs()` to the noise value to create puffy cumulus/smoke shapes; if false, produces smooth haze [S1].
*   `Density` (Single): Overall opacity/absorption strength. Applied at render time, not baked into voxels [S1].
*   `RenderInside` (Boolean): Default `True`. Allows the camera to move inside the volume with correct compositing [S1].
*   `UseLighting` (Boolean): Default `False`. The medium is emission-absorption, not a lit surface [S1].
*   `Offset` (Point3D): Translation vector for animation [S1].
*   `Seed` (LongWord): Random seed for the Perlin generator [S1].

**Algorithm Steps:**

1.  **Initialization:** Create the instance, set the parent viewport, and assign `FrontFaceRenderPass` and `BackFaceRenderPass` [S1]. Set `RenderInside` to `True` and `UseLighting` to `False` by default [S1].
2.  **Noise Sampling:** For each voxel at position $\mathbf{p}$ in the grid:
    a.  Apply the animation offset: $\mathbf{p}' = \mathbf{p} + \text{Offset}$ [S1].
    b.  Compute the base Perlin noise value $N$ at $\mathbf{p}' \times \text{Frequency}$ using the specified `Seed` [S1].
    c.  If `Billowy` is true, apply `abs()` to the noise value [S1].
    d.  Compute the Fractal Brownian Motion (FBM) value $V_{\text{fbm}}$ by summing octaves:
        $$ V_{\text{fbm}} = \sum_{i=0}^{\text{Octaves}-1} \text{Persistence}^i \cdot N(\mathbf{p}' \times \text{Frequency} \times \text{Lacunarity}^i) $$
        [S1]
    e.  Apply `Coverage` as a soft threshold to carve the body into separate puffs [S1].
    f.  Apply `EdgeFalloff` as a radial fade toward the border so the body forms a rounded blob [S1].
    g.  Clamp the final density $D$ to the range $[0, 1]$ [S1].
3.  **Storage:** Store $D$ in the voxel grid. This value is a smooth gradient, not the final opacity [S1].
4.  **Rendering:** When rendering, use the stored $D$ as the density for an emission-absorption blend [S1]. The `Density` parameter acts directly as the absorption strength in the blend [S1].
5.  **Animation:** To animate, update `Offset` and call `Regenerate` to re-sample the volume on the CPU and upload the new data [S1].

**Pseudocode:**

```python
import math

def generate_volumetric_noise(width, height, depth, frequency, octaves, persistence, lacunarity, seed, coverage, edge_falloff, billowy, offset):
    """
    Generates the 3D density texture for TGorillaVolumetricNoise.
    Returns a 3D array of floats in [0, 1].
    """
    # Standard 3D Perlin noise implementation (hash + trilinear interpolation) [G]
    def perlin3d(x, y, z, seed):
        # Simple hash-based gradient noise for self-containment
        def hash_val(x, y, z):
            h = seed + x * 374761393 + y * 668265263 + z * 1274126177
            h = (h ^ (h >> 13)) & 0xFFFFFFFF
            h = (h * 1103515245 + 12345) & 0xFFFFFFFF
            return (h & 0x7FFFFFFF) / 0x7FFFFFFF
        
        def grad(x, y, z, h):
            u = x if h < 4 else y
            v = y if h < 4 else z
            return (u + v) * (1.0 if h < 2 else -1.0)
        
        ix, iy, iz = int(math.floor(x)), int(math.floor(y)), int(math.floor(z))
        fx, fy, fz = x - ix, y - iy, z - iz
        ux, uy, uz = fx * fx * (3.0 - 2.0 * fx), fy * fy * (3.0 - 2.0 * fy), fz * fz * (3.0 - 2.0 * fz)
        
        h000 = hash_val(ix, iy, iz)
        h100 = hash_val(ix+1, iy, iz)
        h010 = hash_val(ix, iy+1, iz)
        h110 = hash_val(ix+1, iy+1, iz)
        h001 = hash_val(ix, iy, iz+1)
        h101 = hash_val(ix+1, iy, iz+1)
        h011 = hash_val(ix, iy+1, iz+1)
        h111 = hash_val(ix+1, iy+1, iz+1)
        
        n000 = grad(fx, fy, fz, h000)
        n100 = grad(fx-1, fy, fz, h100)
        n010 = grad(fx, fy-1, fz, h010)
        n110 = grad(fx-1, fy-1, fz, h110)
        n001 = grad(fx, fy, fz-1, h001)
        n101 = grad(fx-1, fy, fz-1, h101)
        n011 = grad(fx, fy-1, fz-1, h011)
        n111 = grad(fx-1, fy-1, fz-1, h111)
        
        x1 = n000 + ux * (n100 - n000)
        x2 = n010 + ux * (n110 - n010)
        y1 = x1 + uy * (x2 - x1)
        x1 = n001 + ux * (n101 - n001)
        x2 = n011 + ux * (n111 - n011)
        y2 = x1 + uy * (x2 - x1)
        return y1 + uz * (y2 - y1)

    inv_w = 1.0 / width
    inv_h = 1.0 / height
    inv_d = 1.0 / depth
    
    density_grid = [[[0.0 for _ in range(depth)] for _ in range(height)] for _ in range(width)]
    
    for x in range(width):
        for y in range(height):
            for z in range(depth):
                nx = x * inv_w
                ny = y * inv_h
                nz = z * inv_d
                
                ox = nx + offset.x
                oy = ny + offset.y
                oz = nz + offset.z
                
                fbm_value = 0.0
                amp = 1.0
                freq = frequency
                
                for i in range(octaves):
                    noise_val = perlin3d(ox * freq, oy * freq, oz * freq, seed)
                    if billowy:
                        noise_val = abs(noise_val)
                    fbm_value += amp * noise_val
                    amp *= persistence
                    freq *= lacunarity
                
                # Coverage: soft threshold carving [G]
                threshold = 1.0 - coverage
                if fbm_value < threshold:
                    fbm_value = 0.0
                else:
                    fbm_value = (fbm_value - threshold) / (1.0 - threshold) if coverage < 1.0 else fbm_value
                
                # EdgeFalloff: radial fade from center to border [G]
                dx = nx - 0.5
                dy = ny - 0.5
                dz = nz - 0.5
                dist = math.sqrt(dx*dx + dy*dy + dz*dz)
                max_dist = math.sqrt(0.75)
                norm_dist = dist / max_dist if max_dist > 0 else 0.0
                edge_factor = max(0.0, 1.0 - norm_dist * edge_falloff)
                
                density = fbm_value * edge_factor
                density = max(0.0, min(1.0, density))
                
                density_grid[x][y][z] = density
                
    return density_grid
```

**Edge Cases and Pitfalls:**
*   **Terracing Artifacts:** Baking density directly into voxel data and using linear blending causes hard saturation "shells" or step terraces when viewed from inside [S1]. This is avoided by storing a smooth 0–1 gradient and applying opacity at render time via emission-absorption blend [S1].
*   **Resolution Independence:** The `Density` parameter is resolution-independent [S1]. A cloud at $32^3$ resolution looks comparably dense to one at $64^3$ for the same `Density` value [S1].
*   **Performance:** `Regenerate` is expensive as it re-samples the whole volume on the CPU [S1]. For animation, use a smaller resolution ($32^3$) and update on a timer (e.g., ~100 ms) rather than every frame [S1].
*   **Lighting:** `UseLighting` should remain `False` for standard volumetric noise [S1]. Lit clouds require a separate "light-marching" feature [S1].

## Operating characteristics
*   **Time Complexity:** Generation scales linearly with the number of voxels $N = W \times H \times D$ [G]. Each voxel requires $O(\text{Octaves})$ noise evaluations [G].
*   **Memory Complexity:** $O(N)$ to store the 3D texture [G]. The default resolution is $64^3$ voxels, with a performance preset of $32^3$ [S1].
*   **Measured Performance:** Regenerating the volume on the CPU is the bottleneck [S1]. Updating `Density` is cheap as it only rebuilds the blend function [S1].
*   **Strengths:** Physically based emission-absorption model prevents internal artifacts [S1]. Resolution-independent density [S1]. Easy-to-use presets [S1]. Fly-through capability [S1].
*   **Limitations:** CPU-bound generation makes high-resolution animation expensive [S1]. No built-in lighting (requires separate feature) [S1]. Grayscale density by default [S1].
*   **When to Use:** Static or slowly drifting clouds, smoke, and fog where physical accuracy and fly-through are required [S1].
*   **When Not to Use:** High-speed animation requiring high resolution [S1]. Scenes requiring direct surface lighting on the volume (use light-marching instead) [S1].

## Background
TGorillaVolumetricNoise is part of the Gorilla3D Framework [S1]. It is designed to provide a ready-to-use cloud, smoke, or fog body without requiring external data files or custom shader code [S1]. It is a subclass of `TGorillaVolumetricMesh` [S1].
