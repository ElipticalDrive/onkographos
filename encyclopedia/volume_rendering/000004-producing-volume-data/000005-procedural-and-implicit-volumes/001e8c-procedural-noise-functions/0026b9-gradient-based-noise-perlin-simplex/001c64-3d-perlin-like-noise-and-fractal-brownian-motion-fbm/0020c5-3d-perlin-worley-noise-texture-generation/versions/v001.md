# 3D Perlin-Worley Noise Texture Generation

Also called: Multi-Octave Worley, Noise-based Density Sampling, Perlin-Worley Hybrid, Volumetric Density Map Generation

## Overview
This method generates 3D volumetric density maps for procedural textures, specifically targeting cloud-like structures, by combining low-frequency Perlin noise for broad mass with inverted Worley (cellular) noise to carve hollows [S1, S2, unofficial]. It differs from pure Perlin noise by introducing cellular erosion for puffy cumulus appearances and from pure Worley by retaining large-scale continuity [S2, unofficial]. It builds on [3D Perlin-like Noise and Fractal Brownian Motion (FBM)](1260-3d-perlin-like-noise-and-fractal-brownian-motion-fbm.md) by adding a secondary Worley noise layer for detail erosion.

## How it works
**Inputs:**
- Input position $P \in \mathbb{R}^3$.
- Texture resolution (for compute shader coordinate mapping).
- Noise parameters: frequencies and amplitudes for Perlin and Worley components.

**Outputs:**
- A 3D density value $D \in [0, 1]$ or a 3D texture image with `rgba8` layout [S2, unofficial].

**Data Structures:**
- `image3D u_NoiseTexture`: Bound as `layout(rgba8, binding = 0) writeonly uniform image3D` in the compute shader [S2, unofficial].
- Perlin noise samples $P_i$ at 6 octaves.
- Worley noise sample $W$ at frequency 1.0.

**Steps:**
1. **Coordinate Transformation:** Add an offset to the input position and scale it to control the spatial frequency [S1, unofficial].
2. **Perlin Noise FBM:** Compute a fractal Brownian motion (fBm) sum using Perlin noise at 6 specific frequencies and amplitudes [S1, unofficial]:
   - Octave 1: Frequency 1.0, Amplitude 8.0
   - Octave 2: Frequency 2.0, Amplitude 4.0
   - Octave 3: Frequency 4.0, Amplitude 2.0
   - Octave 4: Frequency 8.0, Amplitude 1.0
   - Octave 5: Frequency 16.0, Amplitude 0.5
   - Octave 6: Frequency 32.0, Amplitude 0.25
   Sum these values to get $P_{sum} = \sum_{i=1}^{6} P_i$ [S1, unofficial].
3. **Worley Noise:** Sample Worley noise at frequency 1.0 and amplitude 1.0. Invert the result (e.g., $1 - W$ or $-W$) and scale to the range $[-1, 1]$ to create $W_{inv}$ [S1, unofficial]. This inverted Worley noise carves hollows into the density [S2, unofficial].
4. **Density Calculation:** Combine the Perlin sum and inverted Worley noise, subtract a threshold of 0.2, and clamp the result to 0 [S1, unofficial]:
   $$ D = \max(0, P_{sum} + W_{inv} - 0.2) $$
   [S1, unofficial]
5. **Multi-Octave Worley (Optional Detail):** For additional erosion detail, store three octaves of Worley noise in separate color channels (G, B, A) of the output texture at varying frequencies [S2, unofficial].
6. **Output:** Write the computed density to the 3D texture using `imageStore()` in a compute shader, using fractional coordinates derived from `gl_GlobalInvocationID / texture_size` [S2, unofficial].

**Pseudocode:**
```python
def generate_perlin_worley_density(position, offset, scale):
    # Step 1: Transform position
    pos = (position + offset) * scale
    
    # Step 2: Perlin FBM Sum
    # Frequencies: [1, 2, 4, 8, 16, 32]
    # Amplitudes:  [8, 4, 2, 1, 0.5, 0.25]
    perlin_sum = 0.0
    freqs = [1, 2, 4, 8, 16, 32]
    amps = [8, 4, 2, 1, 0.5, 0.25]
    
    for i in range(6):
        # Sample Perlin noise at current frequency
        # Note: Actual Perlin implementation details are assumed from parent article
        p = perlin_noise(pos * freqs[i])
        perlin_sum += p * amps[i]
        
    # Step 3: Worley Noise
    # Sample Worley noise at frequency 1.0
    w = worley_noise(pos * 1.0)
    # Invert and scale to [-1, 1]
    # Assuming Worley returns [0, 1], invert to [0, 1] then scale
    w_inv = (1.0 - w) * 2.0 - 1.0  # Maps [0,1] to [-1,1]
    
    # Step 4: Combine and Threshold
    density = perlin_sum + w_inv - 0.2
    density = max(0.0, density)
    
    return density
```

**Edge Cases:**
- If the camera is inside the cloud layer, the ray start point must be clamped to the camera position [S2, unofficial].
- Precision issues may arise if the Perlin sum exceeds expected ranges; ensure amplitude scaling is consistent [S1, unofficial].
- The threshold of 0.2 is critical for defining the cloud base density; lower values increase cloud volume, higher values reduce it [S1, unofficial].

## Subtopics

### Multi-Octave Worley
Stores three octaves of Worley noise in separate color channels (G, B, A) for detail erosion. Choose when fine cellular detail is needed beyond the base Perlin-Worley hybrid [S2, unofficial].

### Noise-based Density Sampling
Uses the generated density map for raymarching. Choose when integrating with existing volumetric raymarchers [S2, unofficial].

## Operating characteristics
- **Time Complexity:** Linear with respect to the number of voxels in the 3D texture volume. Each voxel requires 6 Perlin noise evaluations and 1 Worley noise evaluation [S1, S2, unofficial].
- **Memory Complexity:** $O(N^3)$ for the 3D texture, where $N$ is the resolution. Uses `rgba8` format, so 4 bytes per voxel [S2, unofficial].
- **Performance:** GPU compute shaders are used for generation, allowing parallel processing of voxels [S2, unofficial].
- **Strengths:** Produces realistic cloud-like structures with both large-scale mass and fine-scale erosion [S2, unofficial].
- **Limitations:** Requires pre-computation of the 3D texture, which can be memory-intensive for high resolutions [S2, unofficial].

## Background
This method was developed for real-time volumetric cloud rendering in OpenGL, combining Perlin noise for structure and Worley noise for erosion [S2, unofficial]. It was implemented in WebGL and OpenGL contexts for procedural sky and cloud generation [S1, S2, unofficial].
