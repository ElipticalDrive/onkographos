# Domain Warped FBM

Also called: 2D Clouds, Domain Warping, Inigo Quilez Domain Warping

## Overview
Domain Warped FBM is a procedural noise technique where the output of a noise function is fed back as a coordinate offset to distort the sampling domain, creating organic, fluid-like patterns [S1]. It differs from standard FBM by introducing non-linear spatial distortion that mimics turbulent flow, whereas standard FBM simply layers noise at different scales [S1].

## How it works
**Inputs and Outputs:**
- Input: 2D or 3D coordinate `p` (or `uv`), time `t` (optional), warp strength `WARP_STRENGTH`.
- Output: Scalar value `f` representing the noise intensity.

**Data Structures:**
- `fbm(p)`: Returns a scalar value from a multi-octave noise summation.
- `fbm2(p)`: Returns a 2D vector `vec2` from two orthogonal noise octaves.
- `fbm4(p)`: Returns a scalar from a 4-octave noise summation.
- `fbm4_2(p)`: Returns a `vec2` from two 4-octave noise sums with phase offsets.
- `fbm6_2(p)`: Returns a `vec2` from two 6-octave noise sums.

**Parameters:**
- `WARP_STRENGTH`: Controls the intensity of the distortion. Typical values range from 0.2 to 2.0 depending on the desired turbulence [S1].
- `time`: A scalar for animation, often scaled by small factors (e.g., 0.1) [S1].

**Steps:**
The method typically follows a cascade structure to increase complexity. The following implementation uses the classic three-level cascade described in the sources [S1]:

1.  **Compute Base Warp Field (`o`):**
    Calculate two orthogonal noise values to form a 2D offset vector `o`.
    $$ o = 0.5 + 0.5 \times \text{fbm4\_2}(q) $$
    Where $\text{fbm4\_2}(q)$ returns:
    $$ \text{vec2}(\text{fbm4}(q + \text{vec2}(1.0)), \text{fbm4}(q + \text{vec2}(6.2))) $$
    Here, $q$ is the initial input coordinate.

2.  **Compute Secondary Warp Field (`n`):**
    Calculate a second 2D offset vector `n` using the result `o`.
    $$ n = \text{fbm6\_2}(4.0 \times o) $$
    Where $\text{fbm6\_2}$ returns two orthogonal 6-octave noise sums.

3.  **Compute Warped Coordinate (`p`):**
    Offset the original coordinate $q$ by the secondary warp field `n`.
    $$ p = q + 2.0 \times n + 1.0 $$

4.  **Compute Final Noise Value (`f`):**
    Sample the final noise field using the warped coordinate $p$.
    $$ f = 0.5 + 0.5 \times \text{fbm4}(2.0 \times p) $$

5.  **Modulate Output:**
    Mix the final value with a cubic function weighted by the magnitude of the secondary warp field `n`.
    $$ f = \text{mix}(f, f^3 \times 3.5, f \times |n.x|) $$

**Pseudocode:**
```python
def domain_warped_fbm(q, warp_strength=1.0):
    # Step 1: Compute base warp field o
    # fbm4_2 returns two orthogonal 4-octave noise values with phase offsets
    o_x = fbm4(q + vec2(1.0))
    o_y = fbm4(q + vec2(6.2))
    o = vec2(0.5 + 0.5 * o_x, 0.5 + 0.5 * o_y)
    
    # Step 2: Compute secondary warp field n
    # fbm6_2 returns two orthogonal 6-octave noise values
    n = fbm6_2(4.0 * o)
    
    # Step 3: Compute warped coordinate p
    p = q + 2.0 * n + 1.0
    
    # Step 4: Compute final noise value f
    f = 0.5 + 0.5 * fbm4(2.0 * p)
    
    # Step 5: Modulate output
    # Mix f with f^3 * 3.5 weighted by f * |n.x|
    weight = f * abs(n.x)
    f = mix(f, f * f * f * 3.5, weight)
    
    return f
```

**Edge Cases and Pitfalls:**
- **Precision:** The cascade involves multiple noise evaluations. Ensure the underlying noise function has sufficient precision to avoid banding or artifacts in the offset vectors [S1].
- **Boundaries:** The addition of constants (e.g., `+ 1.0`, `+ vec2(1.0)`) shifts the sampling domain. Ensure the noise function handles these shifted coordinates correctly without wrapping issues if periodicity is not intended [S1].
- **Degenerate Input:** If `WARP_STRENGTH` is zero, the method degrades to standard FBM. If `n` is zero, the modulation step has no effect [S1].

## Operating characteristics
- **Time Complexity:** $O(k \cdot m)$ where $k$ is the number of cascade levels (typically 3) and $m$ is the number of octaves per FBM call. This is significantly more expensive than standard FBM due to the nested noise evaluations.
- **Memory Complexity:** $O(1)$ auxiliary memory, as it relies on the noise function's internal state.
- **Strengths:** Produces highly organic, fluid-like structures suitable for clouds, smoke, and lava [S1].
- **Limitations:** Computationally intensive; may exhibit instability if warp strength is too high, leading to chaotic or noisy results [S1].

## Background
Domain Warping was popularized by Inigo Quilez in the context of shader programming for procedural textures [S1]. It is a variant of Fractal Brownian Motion (FBM) that introduces non-linear distortion to the noise field [S1].
