# Terrain Heightmap Generation via Noise

Also called: GetHeightAtWorldLocation, Heightmap Generation via Noise, Perlin Noise Height Generation, Procedural terrain heightmap, World Height Noise

## Overview
This method generates a 2D terrain heightmap by sampling a 3D scalar noise field at a fixed vertical coordinate, effectively projecting the noise onto the X-Y plane. It solves the problem of creating continuous, procedural ground geometry for voxel-based or mesh-based worlds without requiring pre-baked height data. It differs from its parent, the [Noise Field Generator](1302-noise-field-generator.md), by collapsing the 3D gradient-based noise into a single 2D function $H(X, Y)$, removing the vertical gradient offset and the Z-dimension sampling, to produce a flat-bottomed or offset heightmap suitable for terrain placement.

## How it works
**Inputs:**
- `WorldX`, `WorldY`: The 2D world-space coordinates for which to compute height.
- `Settings`: A configuration struct containing noise parameters (Seed, Scale, Octaves, Persistence, Lacunarity, HeightScale, BaseHeight).

**Outputs:**
- `Height`: A single floating-point value representing the terrain elevation at `(WorldX, WorldY)`.

**Data Structures:**
The `Settings` struct contains the following fields:
- `Seed` (int32): Random seed for permutation table initialization. Default: 1337.
- `Scale` (float): World units per noise cell. Controls spatial frequency. Default: 2000.0f.
- `Octaves` (int32): Number of noise layers. Range: 1–8. Default: 4.
- `Persistence` (float): Amplitude decay per octave. Range: 0.0–1.0. Default: 0.5f.
- `Lacunarity` (float): Frequency multiplier per octave. Default: 2.0f.
- `HeightScale` (float): Vertical amplitude multiplier. Default: 500.0f.
- `BaseHeight` (float): Vertical offset. Default: 0.0f.

**Algorithm Steps:**

1.  **Scale Normalization**: Compute the normalized noise coordinates by dividing world coordinates by the scale factor. A minimum scale floor is applied to prevent division by zero.
    $$
    Scale_{eff} = \max(Settings.Scale, \epsilon)
    $$
    $$
    NoiseX = \frac{WorldX}{Scale_{eff}}, \quad NoiseY = \frac{WorldY}{Scale_{eff}}
    $$
    Where $\epsilon$ is a small number (e.g., $10^{-6}$) [G].

2.  **Fractal Noise Evaluation**: Compute the raw fractal Brownian motion (FBM) value using 2D Perlin noise. This involves summing multiple octaves of noise with increasing frequency and decreasing amplitude.
    $$
    Noise = \text{FractalPerlin2D}(NoiseX, NoiseY, Settings)
    $$
    The result is normalized to approximately $[-1, 1]$ [S1, unofficial].

3.  **Remapping**: Map the normalized noise value to the target vertical range defined by `BaseHeight` and `HeightScale`.
    $$
    Height = BaseHeight + (Noise \times HeightScale)
    $$

**Pseudocode:**

```python
def GenerateHeight(WorldX: float, WorldY: float, Settings: NoiseSettings) -> float:
    # 1. Scale Normalization
    # Guard against division by zero [G]
    scale = max(Settings.Scale, 1e-6)
    noise_x = WorldX / scale
    noise_y = WorldY / scale

    # 2. Fractal Noise Evaluation
    raw_noise = FractalPerlin2D(noise_x, noise_y, Settings)

    # 3. Remapping
    height = Settings.BaseHeight + (raw_noise * Settings.HeightScale)
    return height

def FractalPerlin2D(X: float, Y: float, Settings: NoiseSettings) -> float:
    total = 0.0
    frequency = 1.0
    amplitude = 1.0
    max_value = 0.0
    
    # Clamp octaves to valid range [1, 8]
    octaves = max(1, min(Settings.Octaves, 8))
    
    for i in range(octaves):
        # Sample raw 2D Perlin noise at current frequency
        # Note: RawPerlin2D implementation details are inherited from parent Noise Field Generator
        # but adapted for 2D input.
        sample = RawPerlin2D(X * frequency, Y * frequency, Settings.Seed)
        
        total += sample * amplitude
        max_value += amplitude
        
        # Update amplitude and frequency for next octave
        amplitude *= Settings.Persistence
        frequency *= Settings.Lacunarity
        
    # Normalize to [-1, 1] range
    if max_value > 0:
        return total / max_value
    else:
        return 0.0

def RawPerlin2D(X: float, Y: float, Seed: int) -> float:
    """
    Standard 2D Perlin Noise implementation.
    Uses a permutation table derived from Seed.
    Returns value roughly in [-1, 1].
    """
    # 1. Find unit square
    xi = int(floor(X)) & 255
    yi = int(floor(Y)) & 255
    
    # 2. Find relative x, y in unit square
    xf = X - floor(X)
    yf = Y - floor(Y)
    
    # 3. Fade curves
    u = fade(xf)
    v = fade(yf)
    
    # 4. Hashing corners
    # P is the permutation table initialized with Seed
    # AA, AB, BA, BB are hash values for the four corners
    aa = p[p[xi] + yi]
    ab = p[p[xi] + yi + 1]
    ba = p[p[xi + 1] + yi]
    bb = p[p[xi + 1] + yi + 1]
    
    # 5. Gradient contributions
    # grad(hash, x, y) computes dot product of gradient vector and distance vector
    x1 = lerp(grad(aa, xf, yf), grad(ba, xf - 1, yf), u)
    x2 = lerp(grad(ab, xf, yf - 1), grad(bb, xf - 1, yf - 1), u)
    
    # 6. Interpolation
    return lerp(x1, x2, v)

def fade(t: float) -> float:
    return t * t * t * (t * (t * 6 - 15) + 10)

def lerp(t: float, a: float, b: float) -> float:
    return a + t * (b - a)

def grad(hash_val: int, x: float, y: float) -> float:
    # Simplified 2D gradient for Perlin noise
    # Typically uses a set of 4 or 8 gradient vectors
    h = hash_val & 3
    if h == 0: return x + y
    elif h == 1: return -x + y
    elif h == 2: return x - y
    else: return -x - y
```

**Edge Cases and Pitfalls:**
- **Division by Zero**: If `Settings.Scale` is 0, the normalization step fails. A minimum epsilon floor is required [G].
- **Precision Loss**: At very large world coordinates, floating-point precision in `WorldX/Scale` may cause noise artifacts. Wrapping coordinates or using double precision may be necessary for infinite worlds [G].
- **Discontinuities**: If the permutation table is not properly seeded or if `Seed` is not handled consistently across chunks, seams may appear at chunk boundaries.

## Subtopics

### Fractal Brownian Motion (FBM)
The underlying noise summation technique. It creates detail by layering noise at different frequencies. Choose this when you need multi-scale terrain features (large mountains + small rocks). See [3D Perlin-like Noise and Fractal Brownian Motion (FBM)](1303-3d-perlin-like-noise-and-fbm.md).

### Perlin Noise
The base gradient noise function. It provides smooth, continuous interpolation. Choose this over value noise for smoother terrain slopes. See [Gradient-based Noise (Perlin/Simplex)](1301-gradient-based-noise-perlin-simplex.md).

## Operating characteristics
- **Time Complexity**: $O(O)$, where $O$ is the number of octaves. Each octave requires a constant number of hash lookups and interpolations.
- **Memory Complexity**: $O(1)$ per query. The permutation table is precomputed and stored once.
- **Performance**: Very fast. Suitable for real-time generation during chunk loading or on-the-fly terrain modification.
- **Strengths**: Deterministic (given same seed), continuous, easy to tune via parameters.
- **Limitations**: 2D projection loses vertical variation details that 3D noise might provide. Not suitable for caves or overhangs without additional 3D processing.

## Background
This method is derived from procedural generation techniques used in voxel games like Minecraft. The specific implementation is found in the UE5 Minecraft Clone project by Manolo94, which adapts standard Perlin noise for world height generation [S1, unofficial]. It builds on the [Noise Field Generator](1302-noise-field-generator.md) by simplifying the 3D field into a 2D heightmap.
