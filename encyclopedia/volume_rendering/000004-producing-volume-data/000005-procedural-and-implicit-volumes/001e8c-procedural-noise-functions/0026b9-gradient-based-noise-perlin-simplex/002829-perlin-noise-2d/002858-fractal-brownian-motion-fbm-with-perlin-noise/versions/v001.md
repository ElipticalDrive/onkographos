# Fractal Brownian Motion (fBm) with Perlin Noise

Also called: Fractal Brownian Motion (FBM), FractalPerlin2D, Layered Perlin Noise, Multi-octave Perlin Noise, Turbulence

## Overview
Fractal Brownian Motion (fBm) with Perlin Noise is a procedural technique that generates rougher, more natural-looking noise by summing multiple octaves of base Perlin noise with increasing frequency and decreasing amplitude [S1, S2, S3, unofficial]. It builds on [Perlin Noise 2D](4211-perlin-noise-2d.md) to produce self-similar detail at multiple scales, mimicking natural phenomena like terrain or clouds [S2, unofficial]. Unlike simple Perlin noise, fBm creates a hierarchical structure where fine details are layered over coarse shapes [S2, unofficial].

## How it works
**Inputs:**
- `p`: Input coordinate (2D vector `float2` or 3D vector `float3`).
- `octaves`: Number of noise layers (integer, typically 1–8) [S2, S3, unofficial].
- `persistence`: Factor by which amplitude decreases per octave (float, typically 0.5) [S2, unofficial].
- `lacunarity`: Factor by which frequency increases per octave (float, typically 2.0) [S2, unofficial].
- `seed`: Integer seed for the Perlin noise permutation table [S2, unofficial].
- `shift`: Optional 3D vector added to coordinates to break symmetry (e.g., `float3(100, 100, 100)`) [S3, unofficial].

**Outputs:**
- `value`: The final fBm value. Range depends on implementation: typically normalized to `[-1, 1]` or `[0, 1]` [S2, S3, unofficial].

**Data Structures:**
- Permutation table: Array of 256 integers (or 512 for wrapping) used by Perlin Noise 2D [S2, unofficial].
- Accumulators: `Total` (sum of weighted noise), `MaxValue` (sum of amplitudes for normalization), `Frequency` (current frequency multiplier), `Amplitude` (current amplitude multiplier) [S2, unofficial].

**Steps:**
1. Initialize `Total = 0.0`, `Frequency = 1.0`, `Amplitude = 1.0`, and `MaxValue = 0.0` [S2, unofficial].
2. Loop `i` from `0` to `octaves - 1`:
   a. Compute the base noise value `n` using Perlin Noise 2D at coordinate `p * Frequency` with the given `seed` [S2, unofficial].
   b. Add weighted noise to total: `Total += n * Amplitude` [S2, unofficial].
   c. Accumulate max possible value: `MaxValue += Amplitude` [S2, unofficial].
   d. Update amplitude: `Amplitude *= persistence` [S2, unofficial].
   e. Update frequency: `Frequency *= lacunarity` [S2, unofficial].
   f. Update position: `p = p * lacunarity + shift` (if shift is used) [S3, unofficial].
3. Normalize result: If `MaxValue > 0`, return `Total / MaxValue`; else return `0.0` [S2, unofficial].
   - *Note:* Some implementations use `abs(n)` instead of `n` to create "turbulence" (white-noise-like texture) rather than signed noise (cloudy texture) [S1, unofficial]. If using `abs`, the range becomes `[0, 1]` after normalization [S1, unofficial].
   - *Note:* Another variant returns `v * 2 - 1` to normalize range to `[-1, 1]` if the base noise is in `[0, 1]` [S3, unofficial].

**Pseudocode:**
```python
def fractal_perlin_2d(p: float2, octaves: int, persistence: float, lacunarity: float, seed: int, shift: float3 = None) -> float:
    """
    Computes Fractal Brownian Motion using Perlin Noise 2D.
    
    Args:
        p: Input 2D coordinate.
        octaves: Number of octaves (1-8).
        persistence: Amplitude decay factor (typically 0.5).
        lacunarity: Frequency increase factor (typically 2.0).
        seed: Permutation seed.
        shift: Optional 3D shift vector (ignored if p is 2D, but kept for compatibility with 3D variants).
        
    Returns:
        Normalized fBm value in [-1, 1] or [0, 1] depending on abs() usage.
    """
    total = 0.0
    frequency = 1.0
    amplitude = 1.0
    max_value = 0.0
    
    # Current position for noise sampling
    current_p = p
    
    for i in range(octaves):
        # Sample Perlin Noise 2D
        # RawPerlin2D returns value roughly in [-1, 1]
        noise_val = raw_perlin_2d(current_p.x, current_p.y, seed)
        
        # Optional: Use abs() for turbulence (white-noise-like)
        # noise_val = abs(noise_val)
        
        total += noise_val * amplitude
        max_value += amplitude
        
        # Update parameters for next octave
        amplitude *= persistence
        frequency *= lacunarity
        current_p = current_p * lacunarity
        
        # Optional: Add shift to break symmetry
        if shift is not None:
            # Note: shift is typically 3D, but p is 2D. 
            # In 3D implementations, shift is added to the 3D position.
            # Here, we assume shift.x and shift.y are used if available, or ignored.
            # For strict 2D, shift might not be applicable.
            pass
            
    # Normalize
    if max_value > 0:
        return total / max_value
    else:
        return 0.0

def raw_perlin_2d(x: float, y: float, seed: int) -> float:
    """
    Simplified Perlin Noise 2D implementation.
    Assumes a permutation table is built from seed.
    Returns value in [-1, 1].
    """
    # Build permutation table if not cached
    # ... (see Perlin Noise 2D article) ...
    
    # Hashing
    xi = int(x) & 255
    yi = int(y) & 255
    xf = x - int(x)
    yf = y - int(y)
    
    # Fade functions
    u = fade(xf)
    v = fade(yf)
    
    # Gradient indices
    aa = perm_table[perm_table[xi] + yi]
    ab = perm_table[perm_table[xi] + yi + 1]
    ba = perm_table[perm_table[xi + 1] + yi]
    bb = perm_table[perm_table[xi + 1] + yi + 1]
    
    # Gradient values
    g_aa = grad(aa, xf, yf)
    g_ba = grad(ba, xf - 1.0, yf)
    g_ab = grad(ab, xf, yf - 1.0)
    g_bb = grad(bb, xf - 1.0, yf - 1.0)
    
    # Interpolation
    x1 = lerp(u, g_aa, g_ba)
    x2 = lerp(u, g_ab, g_bb)
    result = lerp(v, x1, x2)
    
    return result

def fade(t: float) -> float:
    return t * t * t * (t * (t * 6.0 - 15.0) + 10.0)

def lerp(t: float, a: float, b: float) -> float:
    return a + t * (b - a)

def grad(hash_val: int, x: float, y: float) -> float:
    h = hash_val & 7
    u = x if h < 4 else y
    v = y if h < 4 else x
    return (u if (h & 1) == 0 else -u) + (v if (h & 2) == 0 else -v)
```

**Parameters:**
- `octaves`: Number of noise layers. Range: 1 to 8. Default: from Settings [S2, unofficial].
- `persistence`: Factor by which amplitude decreases per octave. Typical value: 0.5 [S2, unofficial].
- `lacunarity`: Factor by which frequency increases per octave. Typical value: 2.0 [S2, unofficial].
- `shift`: Optional 3D vector added to coordinates to break symmetry. Typical value: `float3(100, 100, 100)` [S3, unofficial].

**Edge Cases and Pitfalls:**
- **Precision:** High octaves with high lacunarity can lead to floating-point precision issues at large coordinates. Use wrapping or modular arithmetic for coordinates if necessary [S2, unofficial].
- **Normalization:** If `MaxValue` is 0 (e.g., 0 octaves), return 0.0 to avoid division by zero [S2, unofficial].
- **Turbulence vs. Signed Noise:** Using `abs()` changes the texture from cloudy to white-noise-like. Choose based on desired visual effect [S1, unofficial].
- **Shift Vector:** If using a shift vector, ensure it is applied consistently across octaves to avoid artifacts [S3, unofficial].

## Operating characteristics
- **Time Complexity:** $O(octaves)$ per sample, where each octave requires one Perlin noise evaluation [S2, unofficial].
- **Memory Complexity:** $O(1)$ additional memory per sample, assuming permutation table is precomputed [S2, unofficial].
- **Performance:** Fast for low octaves (1-4). Performance degrades linearly with octaves [S2, unofficial].
- **Strengths:** Produces natural-looking, self-similar detail. Easy to implement. [S2, unofficial].
- **Limitations:** Can appear repetitive if shift is not used. High octaves can be computationally expensive [S2, unofficial].
- **When to Use:** Terrain generation, cloud textures, procedural materials [S2, unofficial].
- **When Not to Use:** When strict mathematical Brownian motion is required (fBm is an approximation) [S1, unofficial].

## Background
Fractal Brownian Motion (fBm) is a technique used in procedural generation to create natural-looking textures. It was popularized in computer graphics for terrain and cloud generation [S2, unofficial]. The method sums multiple octaves of noise, each with increasing frequency and decreasing amplitude, to create a fractal-like structure [S1, S2, S3, unofficial].
