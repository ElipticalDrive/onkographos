# Fractal Brownian Motion (fBm) with Perlin Noise

Also called: Fractal Brownian Motion, Fractal Noise, Octave Noise, Multi-octave Perlin Noise

## Overview
Fractal Brownian Motion (fBm) with Perlin Noise is a procedural technique that generates rougher, more natural-looking noise by summing multiple octaves of a base gradient noise function with decreasing amplitude and increasing frequency [S1, S2, S4, unofficial][S6]. It solves the problem of simple noise appearing too synthetic or lacking fine detail by introducing self-similar detail at multiple scales, mimicking natural phenomena like terrain or clouds [S2, unofficial][S6]. It sets itself apart from standard Perlin noise by producing a hierarchical structure of detail, and from other fBm variants by retaining the connectedness and billowiness characteristic of gradient-based interpolation [S6].

## How it works
### Inputs and Outputs
- `p`: The input coordinate (2D vector for base Perlin) [S2, S4, unofficial].
- `octaves`: The number of noise layers to sum (integer) [S2, S5, unofficial].
- `persistence`: The factor by which amplitude decreases per octave (float) [S2, S5, unofficial].
- `lacunarity`: The factor by which frequency increases per octave (float) [S2, unofficial].
- `seed`: Optional seed for the underlying Perlin noise permutation table [S2, unofficial].
- Output: A single scalar value representing the fractal noise at `p` [S4, unofficial]. The range depends on normalization; implementations typically normalize to $[-1, 1]$ or $[0, 1]$ [S2, S3, unofficial].

### Data Structures
- Permutation Table: An array of 256 integers (or 512 to avoid wrapping logic) used by the underlying Perlin Noise 2D to map grid coordinates to gradient vectors [S2, unofficial].
- Settings Object: A structure containing `Octaves` (default varies, often 5-8), `Persistence` (default 0.5), and `Lacunarity` (default 2.0) [S2, S3, unofficial].

### Formulas
The general mathematical definition of fBm is a summation of noise functions at different scales [S6]:

$$ \text{FBM}(p) = \sum_{i=0}^{N-1} A_i \cdot \text{Noise}(p \cdot F_i) $$

Where:
- $N$ is the number of octaves.
- $A_i$ is the amplitude of octave $i$.
- $F_i$ is the frequency of octave $i$.
- $\text{Noise}$ is the base Perlin Noise 2D function [S2, S4, unofficial].

Typical parameter relationships [S6]:
- $A_i = A_0 \cdot \text{Persistence}^i$
- $F_i = F_0 \cdot \text{Lacunarity}^i$

Common default values are $A_0 = 1.0$ (or 0.5 depending on normalization strategy), $\text{Persistence} = 0.5$, and $\text{Lacunarity} = 2.0$ [S2, S4, S5, unofficial].

### Parameters
- **Octaves**: Number of layers. Range: 1 to 8 (typical). Default: 5 [S2, S3, unofficial].
- **Persistence**: Amplitude decay factor. Typical value: 0.5 [S2, S4, S5, unofficial].
- **Lacunarity**: Frequency multiplier. Typical value: 2.0 [S2, unofficial].

### Steps
1. Initialize `total_value = 0.0`, `frequency = 1.0`, `amplitude = 1.0`, and `max_value = 0.0` [S2, unofficial].
2. Loop `i` from 0 to `octaves - 1` (clamped between 1 and 8) [S2, unofficial].
3. Calculate the scaled position: `scaled_p = p * frequency` [S4, unofficial].
4. Evaluate the base Perlin Noise 2D at `scaled_p`: `noise_val = Perlin2D(scaled_p, seed)` [S2, unofficial].
5. Add the weighted noise to the total: `total_value += amplitude * noise_val` [S2, unofficial].
6. Update the maximum possible value for normalization: `max_value += amplitude` [S2, unofficial].
7. Update amplitude for the next octave: `amplitude *= persistence` [S2, unofficial].
8. Update frequency for the next octave: `frequency *= lacunarity` [S2, unofficial].
9. Normalize the result: `result = total_value / max_value` if `max_value > 0`, else 0 [S2, unofficial].
10. Return `result` [S2, unofficial].

### Pseudocode
```python
def fractal_perlin_2d(p, octaves, persistence=0.5, lacunarity=2.0, seed=0):
    """
    Computes Fractal Brownian Motion using Perlin Noise 2D.
    Args:
        p: tuple (x, y) - Input coordinate.
        octaves: int - Number of octaves (1-8 typical).
        persistence: float - Amplitude decay factor (default 0.5).
        lacunarity: float - Frequency multiplier (default 2.0).
        seed: int - Seed for Perlin noise generation.
    Returns:
        float - Normalized fBm value.
    """
    # Clamp octaves to typical range [S2, unofficial]
    octaves = max(1, min(octaves, 8))
    
    total_value = 0.0
    frequency = 1.0
    amplitude = 1.0
    max_value = 0.0
    
    # Build permutation table from seed [S2, unofficial]
    perm = list(range(256))
    # Deterministic shuffle for reproducibility [G]
    for i in range(255, 0, -1):
        j = (seed * (i + 1)) % (i + 1)
        perm[i], perm[j] = perm[j], perm[i]
    perm = perm + perm  # Double for wrapping [S2, unofficial]
    
    for _ in range(octaves):
        # Scale position [S4, unofficial]
        x = p[0] * frequency
        y = p[1] * frequency
        
        # Perlin 2D evaluation [S2, S4, unofficial]
        xi = int(x) & 255
        yi = int(y) & 255
        xf = x - int(x)
        yf = y - int(y)
        
        # Smoothstep interpolation [S4, unofficial]
        u = xf * xf * (3.0 - 2.0 * xf)
        v = yf * yf * (3.0 - 2.0 * yf)
        
        # Hash corners [S2, S4, unofficial]
        aa = perm[perm[xi] + yi]
        ab = perm[perm[xi] + yi + 1]
        ba = perm[perm[xi + 1] + yi]
        bb = perm[perm[xi + 1] + yi + 1]
        
        # Gradient dot products [S2, unofficial]
        def grad(hash_val, dx, dy):
            h = hash_val & 7
            if h == 0: return dx + dy
            elif h == 1: return dx - dy
            elif h == 2: return -dx + dy
            elif h == 3: return -dx - dy
            elif h == 4: return dx
            elif h == 5: return -dx
            elif h == 6: return dy
            else: return -dy
        
        # Bilinear interpolation [S4, unofficial]
        noise_val = (v * (u * grad(aa, xf, yf) + (1.0 - u) * grad(ba, xf - 1.0, yf)) +
                     (1.0 - v) * (u * grad(ab, xf, yf - 1.0) + (1.0 - u) * grad(bb, xf - 1.0, yf - 1.0)))
        
        # Accumulate [S2, unofficial]
        total_value += amplitude * noise_val
        max_value += amplitude
        
        # Update parameters [S2, unofficial]
        amplitude *= persistence
        frequency *= lacunarity
        
        # Pitfall: Stop if frequency is too high to be represented between pixels [S6]
        if frequency > 1000.0:
            break
            
    # Normalize result [S2, unofficial]
    if max_value > 0:
        return total_value / max_value
    else:
        return 0.0
```

### Edge Cases and Pitfalls
- **Aliasing**: The fractal summation must be cut off when the frequency becomes too large for the noise to be properly represented between neighboring pixels [S6].
- **Turbulence vs. Standard FBM**: Using `abs(noise)` instead of signed noise creates a "turbulence" effect, resulting in a white-noise-like texture rather than a cloudy one [S1, unofficial]. The standard implementation uses signed noise.
- **Normalization**: If the base Perlin noise range is not exactly $[-1, 1]$ or if amplitudes do not sum to 1, the output range may vary. Normalization by `max_value` ensures consistent output range regardless of persistence [S2, unofficial].
- **Precision**: At very high frequencies, floating-point precision errors in the Perlin noise interpolation may become visible [G].

## Subtopics

### Turbulence
A variant of fBm that uses the absolute value of the noise function (`abs(noise)`) at each octave. This creates a white-noise-like texture with sharp peaks, distinct from the cloudy, signed noise of standard fBm [S1, unofficial].

### Worley fBm
Uses Worley noise instead of Perlin noise as the base function. This results in cellular patterns rather than smooth gradients, useful for different types of procedural textures [S6].

## Operating characteristics
- **Time Complexity**: $O(O \cdot C)$, where $O$ is the number of octaves and $C$ is the cost of a single Perlin noise evaluation (constant for fixed grid size). Linear with respect to octaves.
- **Memory Complexity**: $O(1)$ additional memory beyond the permutation table of the base Perlin noise.
- **Measured Performance**: Performance is dominated by the base Perlin noise evaluation. On modern CPUs, a single Perlin 2D evaluation is very fast. The loop overhead is negligible for small $O$ (e.g., 5-8).
- **Scaling**: Scales linearly with the number of octaves. Increasing lacunarity does not change computational cost but affects visual detail.
- **Strengths**: Produces natural-looking, multi-scale detail; simple to implement; computationally inexpensive.
- **Limitations**: Can alias at high frequencies; requires careful tuning of persistence and lacunarity for desired aesthetic; not strictly self-similar in a mathematical sense (unlike true Brownian motion) but approximates it visually.
- **When to use**: Procedural terrain generation, cloud density, wood grain, marble textures.
- **When not to use**: When strict mathematical self-similarity is required, or when performance is critical and only a single scale of noise is needed.

## Background
Fractal Brownian Motion (fBm) is a technique inspired by the mathematical concept of Brownian motion, adapted for procedural texture generation. It was popularized in computer graphics by Ken Perlin and others in the 1980s and 1990s for generating natural-looking textures. The specific combination with Perlin Noise leverages the smoothness and continuity of Perlin's gradient noise to create coherent, multi-scale structures. It is widely used in volume rendering for cloud simulation, terrain heightmaps, and material shading [S1, S2, unofficial][S6].
