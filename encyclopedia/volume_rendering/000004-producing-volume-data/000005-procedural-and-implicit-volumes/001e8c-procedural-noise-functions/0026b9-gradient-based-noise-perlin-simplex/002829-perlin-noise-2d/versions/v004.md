# Perlin Noise 2D

Also called: 2D Perlin Noise, RawPerlin2D

## Overview
Perlin Noise 2D is a gradient-based procedural noise function that generates smooth, continuous scalar values by interpolating dot products of gradient vectors and distance vectors at the corners of a unit grid cell [S1, unofficial]. It solves the problem of creating coherent, non-repeating natural-looking textures or heightmaps in 2D space, distinguishing itself from its siblings by using an axis-aligned square grid and quintic interpolation [S1, unofficial]. Unlike Simplex Noise, it does not use triangular tiling, making it susceptible to directional artifacts along the axes if lower-order fade functions are used [S1, unofficial].

## How it works
**Inputs:**
- Query point coordinates $(X, Y)$ as floating-point values.
- A seed value (integer) to initialize the permutation table.

**Outputs:**
- A scalar noise value $V$ typically in the range $[-1, 1]$ or $[0, 1]$ depending on normalization.

**Data Structures:**
- **Permutation Table:** An array `P` of 512 `uint8` values. It is constructed by shuffling indices $0..255$ and duplicating them to handle boundary overflow without modulo operations.
  - Layout: `P[i]` for $0 \le i < 256$ contains a shuffled permutation. `P[i+256]` is a copy of `P[i]`.

**Steps:**
1. **Build Permutation Table:** Initialize a temporary array `P` with values $0..255$. Shuffle it using a seeded random number generator (e.g., Fisher-Yates). Copy the first 256 entries into indices $0..255$ and $256..511$ of the output table [S1, unofficial].
2. **Grid Localization:** Compute the integer coordinates of the cell containing $(X, Y)$:
   $$ XI = \lfloor X \rfloor \pmod{256} $$
   $$ YI = \lfloor Y \rfloor \pmod{256} $$
   Compute the fractional coordinates within the cell:
   $$ XF = X - \lfloor X \rfloor $$
   $$ YF = Y - \lfloor Y \rfloor $$
   [S1, unofficial]
3. **Fade Calculation:** Apply the quintic fade function to the fractional coordinates to ensure smooth derivatives:
   $$ U = \text{Fade}(XF) = 6XF^5 - 15XF^4 + 10XF^3 $$
   $$ V = \text{Fade}(YF) = 6YF^5 - 15YF^4 + 10YF^3 $$
   [S1, unofficial]
4. **Gradient Index Lookup:** Determine the hash values for the four corners of the cell using the permutation table. The indices are calculated as follows:
   $$ AA = P[P[XI] + YI] $$
   $$ AB = P[P[XI] + YI + 1] $$
   $$ BA = P[P[XI + 1] + YI] $$
   $$ BB = P[P[XI + 1] + YI + 1] $$
   [S1, unofficial]
5. **Gradient Dot Products:** Calculate the contribution of each corner. The gradient function `Grad` selects one of 8 predefined 2D vectors based on the low 3 bits of the hash index:
   $$ \text{Grad}(Hash, X, Y) = \begin{cases} X + Y & \text{if } Hash \& 7 == 0 \\ X - Y & \text{if } Hash \& 7 == 1 \\ -X + Y & \text{if } Hash \& 7 == 2 \\ -X - Y & \text{if } Hash \& 7 == 3 \\ X & \text{if } Hash \& 7 == 4 \\ -X & \text{if } Hash \& 7 == 5 \\ Y & \text{if } Hash \& 7 == 6 \\ -Y & \text{otherwise} \end{cases} $$
   Compute the dot products for the four corners relative to their respective distance vectors:
   $$ G_{AA} = \text{Grad}(AA, XF, YF) $$
   $$ G_{BA} = \text{Grad}(BA, XF - 1, YF) $$
   $$ G_{AB} = \text{Grad}(AB, XF, YF - 1) $$
   $$ G_{BB} = \text{Grad}(BB, XF - 1, YF - 1) $$
   [S1, unofficial]
6. **Interpolation:** Interpolate the results along the X axis, then the Y axis:
   $$ L_X = \text{Lerp}(U, G_{AA}, G_{BA}) $$
   $$ L_Y = \text{Lerp}(U, G_{AB}, G_{BB}) $$
   $$ V = \text{Lerp}(V, L_X, L_Y) $$
   Where $\text{Lerp}(T, A, B) = A + T(B - A)$ [S1, unofficial].

**Pseudocode:**
```python
def perlin_noise_2d(x: float, y: float, seed: int) -> float:
    # 1. Build Permutation Table (cached or generated)
    # P is size 512, initialized with shuffled 0-255 duplicated
    P = build_permutation_table(seed)

    # 2. Grid Localization
    xi = int(x) & 255
    yi = int(y) & 255
    
    xf = x - int(x)
    yf = y - int(y)

    # 3. Fade Calculation
    u = fade(xf)
    v = fade(yf)

    # 4. Gradient Index Lookup
    aa = P[P[xi] + yi]
    ab = P[P[xi] + yi + 1]
    ba = P[P[xi + 1] + yi]
    bb = P[P[xi + 1] + yi + 1]

    # 5. Gradient Dot Products
    g_aa = grad(aa, xf, yf)
    g_ba = grad(ba, xf - 1.0, yf)
    g_ab = grad(ab, xf, yf - 1.0)
    g_bb = grad(bb, xf - 1.0, yf - 1.0)

    # 6. Interpolation
    l_x = lerp(u, g_aa, g_ba)
    l_y = lerp(u, g_ab, g_bb)
    result = lerp(v, l_x, l_y)

    return result

def build_permutation_table(seed: int) -> list:
    p = list(range(256))
    # Simple seeded shuffle (Fisher-Yates)
    rng = Random(seed)
    for i in range(255, 0, -1):
        j = rng.randint(0, i)
        p[i], p[j] = p[j], p[i]
    
    # Duplicate for overflow handling
    out = p + p
    return out

def fade(t: float) -> float:
    return t * t * t * (t * (t * 6.0 - 15.0) + 10.0)

def lerp(t: float, a: float, b: float) -> float:
    return a + t * (b - a)

def grad(hash_val: int, x: float, y: float) -> float:
    h = hash_val & 7
    u = x if h < 4 else y
    v = y if h < 4 else x
    return (u if (h & 1) == 0 else -u) + (v if (h & 2) == 0 else -v)
```
[G] `Random` is a standard pseudo-random number generator initialized with `seed`. The bitwise operations in `grad` map the 3-bit hash to the 8 specific gradient vectors defined by Ken Perlin.

## Subtopics

### [Fractal Brownian Motion (fBm) with Perlin Noise](4253-fractal-brownian-motion-fbm-with-perlin-noise.md)
Fractal Brownian Motion (fBm) with Perlin Noise is a procedural technique that generates rougher, more natural-looking noise by summing multiple octaves of base Perlin noise with increasing frequency and decreasing amplitude. It builds on [Perlin Noise 2D](4211-perlin-noise-2d.md) to produce self-similar detail at multiple scales, mimicking natural phenomena like terrain or clouds. Unlike simple Perlin noise, fBm creates a hierarchical structure where fine details are layered over coarse shapes.

## Operating characteristics
- **Time Complexity:** $O(1)$ per query. The number of operations is constant regardless of grid resolution, as it only accesses 4 corners and performs fixed arithmetic.
- **Memory Complexity:** $O(1)$ for the permutation table (512 bytes). No spatial data structure is stored for the noise field itself.
- **Performance:** Extremely fast on CPU and GPU. The primary cost is the permutation table lookup and arithmetic operations.
- **Strengths:** Smooth continuity ($C^1$ or higher with quintic fade), easy to implement, deterministic.
- **Limitations:** Directional artifacts (grid-aligned streaks) are visible if the fade function is not sufficiently smooth (e.g., using linear or quadratic interpolation). The square grid topology is less isotropic than simplex noise [S1, unofficial].
- **When to use:** When isotropy is not critical, or when implementing classic Perlin-style textures. When higher performance is needed than simplex noise allows, or when compatibility with existing Perlin-based pipelines is required.
- **When not to use:** When high isotropy is required (use Simplex Noise) or when generating 3D+ volumes where simplex noise's reduced corner count is beneficial.

## Background
Perlin Noise was introduced by Ken Perlin in 1985 for the movie *Tron* [S1, unofficial]. The 2D version described here uses the "Improved Perlin Noise" formulation, which replaced the original cubic interpolation with a quintic fade function ($6t^5 - 15t^4 + 10t^3$) to eliminate directional artifacts [S1, unofficial]. The specific gradient set and permutation table doubling technique are standard implementations found in graphics programming literature and open-source repositories [S1, unofficial].
