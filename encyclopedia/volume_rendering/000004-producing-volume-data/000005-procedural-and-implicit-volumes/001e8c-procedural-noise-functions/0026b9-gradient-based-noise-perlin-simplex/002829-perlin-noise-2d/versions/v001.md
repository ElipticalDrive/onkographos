# Perlin Noise 2D

Also called: 2D Perlin Noise, RawPerlin2D

## Overview
Perlin Noise 2D is a gradient noise function that generates smooth, continuous random values by interpolating dot products of gradient vectors and distance vectors at the corners of a 2D grid cell [S1, unofficial]. It is the foundational 2D primitive for procedural texture generation and terrain heightmaps, distinguished from its sibling [Simplex Noise](978-simplex-noise.md) by its use of a square lattice and cubic Hermite interpolation, which results in directional artifacts along the axes but offers simpler implementation [S1, unofficial].

## How it works
**Inputs:** A 2D point $(X, Y)$ and a seed integer for permutation table generation.
**Outputs:** A scalar noise value $N \in [-1, 1]$.

**Data Structures:**
*   **Permutation Table:** An array `P` of 512 `uint8` values. Indices 0–255 contain a shuffled permutation of 0–255. Indices 256–511 are a duplicate of 0–255 to handle boundary conditions without modulo arithmetic [S1, unofficial].

**Steps:**
1.  **Initialize Permutation Table:** Create a table `P` of size 256 containing integers 0–255. Shuffle `P` using a seeded random number generator. Duplicate the table to size 512: `P[i+256] = P[i]` for $i \in [0, 255]$ [S1, unofficial].
2.  **Grid Coordinates:** Compute integer grid coordinates `XI = floor(X) & 255` and `YI = floor(Y) & 255`. Compute fractional coordinates `XF = X - floor(X)` and `YF = Y - floor(Y)` [S1, unofficial].
3.  **Fade Values:** Compute smooth interpolation weights `U = Fade(XF)` and `V = Fade(YF)` [S1, unofficial].
4.  **Gradient Indices:** Lookup four gradient indices from the permutation table:
    *   `AA = P[P[XI] + YI]`
    *   `AB = P[P[XI] + YI + 1]`
    *   `BA = P[P[XI + 1] + YI]`
    *   `BB = P[P[XI + 1] + YI + 1]` [S1, unofficial].
5.  **Dot Products:** Compute the dot product contribution for each corner using the `Grad` function:
    *   $G_{AA} = \text{Grad}(AA, XF, YF)$
    *   $G_{BA} = \text{Grad}(BA, XF - 1, YF)$
    *   $G_{AB} = \text{Grad}(AB, XF, YF - 1)$
    *   $G_{BB} = \text{Grad}(BB, XF - 1, YF - 1)$ [S1, unofficial].
6.  **Interpolation:**
    *   Interpolate along X: $L_1 = \text{Lerp}(U, G_{AA}, G_{BA})$ and $L_2 = \text{Lerp}(U, G_{AB}, G_{BB})$.
    *   Interpolate along Y: $N = \text{Lerp}(V, L_1, L_2)$ [S1, unofficial].

**Formulas:**
*   **Fade:** $F(t) = 6t^5 - 15t^4 + 10t^3$ [S1, unofficial].
*   **Lerp:** $\text{Lerp}(t, a, b) = a + t(b - a)$ [S1, unofficial].
*   **Grad:** The function $\text{Grad}(hash, x, y)$ uses the lowest 3 bits of `hash` to select one of 8 gradient vectors:
    *   If $hash \& 7 == 0$: $x + y$
    *   If $hash \& 7 == 1$: $x - y$
    *   If $hash \& 7 == 2$: $-x + y$
    *   If $hash \& 7 == 3$: $-x - y$
    *   If $hash \& 7 == 4$: $x$
    *   If $hash \& 7 == 5$: $-x$
    *   If $hash \& 7 == 6$: $y$
    *   Otherwise: $-y$ [S1, unofficial].

**Pitfalls:**
*   The permutation table must be doubled to 512 entries to avoid modulo operations when accessing `XI+1` or `YI+1` at the boundary of the 0–255 range [S1, unofficial].

**Pseudocode:**
```python
def build_permutation_table(seed: int) -> list[int]:
    """Builds a 512-entry permutation table from a seed."""
    p = list(range(256))
    # Simple seeded shuffle (Fisher-Yates)
    rng = Random(seed)
    for i in range(255, 0, -1):
        j = rng.randint(0, i)
        p[i], p[j] = p[j], p[i]
    
    # Duplicate to 512
    table = p + p
    return table

def fade(t: float) -> float:
    """Smooth interpolation curve."""
    return t * t * t * (t * (t * 6.0 - 15.0) + 10.0)

def lerp(t: float, a: float, b: float) -> float:
    """Linear interpolation."""
    return a + t * (b - a)

def grad(hash_val: int, x: float, y: float) -> float:
    """Compute dot product of gradient and distance vector."""
    h = hash_val & 7
    u = x if (h & 1) == 0 else -x
    v = y if (h & 2) == 0 else -y
    if (h & 4) == 0:
        return u + v
    else:
        return u - v

def perlin_2d(x: float, y: float, perm_table: list[int]) -> float:
    """
    Computes 2D Perlin noise.
    perm_table: 512-entry permutation table.
    """
    # 1. Grid and fractional coordinates
    xi = int(x) & 255
    yi = int(y) & 255
    
    xf = x - int(x)
    yf = y - int(y)
    
    # 2. Fade values
    u = fade(xf)
    v = fade(yf)
    
    # 3. Gradient indices
    aa = perm_table[perm_table[xi] + yi]
    ab = perm_table[perm_table[xi] + yi + 1]
    ba = perm_table[perm_table[xi + 1] + yi]
    bb = perm_table[perm_table[xi + 1] + yi + 1]
    
    # 4. Dot products
    g_aa = grad(aa, xf, yf)
    g_ba = grad(ba, xf - 1.0, yf)
    g_ab = grad(ab, xf, yf - 1.0)
    g_bb = grad(bb, xf - 1.0, yf - 1.0)
    
    # 5. Interpolation
    x_lerp_1 = lerp(u, g_aa, g_ba)
    x_lerp_2 = lerp(u, g_ab, g_bb)
    
    result = lerp(v, x_lerp_1, x_lerp_2)
    
    return result
```

## Operating characteristics
**Time Complexity:** $O(1)$ per sample, involving a fixed number of arithmetic operations and table lookups.
**Memory Complexity:** $O(1)$ if the permutation table is cached; $O(1)$ for the table itself (512 bytes).
**Strengths:** Simple to implement; produces visually smooth results suitable for organic textures.
**Limitations:** Exhibits directional artifacts (grid-aligned lines) due to the square lattice structure [S1, unofficial].
**When to use:** When implementation simplicity is prioritized over isotropy, or when integrating with existing systems expecting standard Perlin noise.
**When not to use:** When isotropic noise is critical (use [Simplex Noise](978-simplex-noise.md)) or when higher-dimensional continuity is required (use [3D Perlin-like Noise](1260-3d-perlin-like-noise-and-fractal-brownian-motion-fbm.md)).

## Background
The algorithm was introduced by Ken Perlin in 1985 for generating procedural textures in the film *Tron* [S1, unofficial]. The specific implementation detailed here, including the 8-direction gradient set and quintic fade function, is a common variant found in game development and open-source repositories [S1, unofficial].
