# 2D Octaved Noise with Memoization

Also called: 2D OpenSimplex Noise with Memoization, Fractal Noise with Caching, Octave Noise, Perlin-like Noise Generation

## Overview
A fractal noise generator that sums multiple octaves of a base 2D noise function with decreasing amplitude and increasing frequency, caching results to avoid redundant calculations [S2, unofficial]. It differs from standard octaved noise by explicitly memoizing the final accumulated result per coordinate and octave count, trading memory for repeated computation avoidance [S2, unofficial]. It builds on a base 2D noise function [S2, unofficial].

## How it works
**Inputs:**
- Coordinates $(a, b)$ in 2D space [S2, unofficial].
- Number of octaves $n_{octaves}$ [S2, unofficial].
- Wavelength $\lambda$ (spatial scale factor) [S2, unofficial].
- Base amplitude $A_{base}$ [S2, unofficial].
- Cache storage for previous evaluations [S2, unofficial].

**Outputs:**
- A single normalized noise value [S2, unofficial].

**Data Structures:**
- **Noise Data Array:** A `std::vector<float>` storing the base noise values, accessed via helper functions `get()` and `set()` which map 2D coordinates $(x, y)$ to a 1D index $x \cdot \text{width} + y$ [S1, unofficial].
- **Cache:** A hash map or dictionary storing keys of the form `${a},${b},${n_{octaves}}` mapped to the computed noise result [S2, unofficial].

**Steps:**
1. **Check Cache:** Construct the cache key from inputs $a, b, n_{octaves}$ as `${a},${b},${n_{octaves}}$` [S2, unofficial]. If the key exists in the cache, return the stored value immediately [S2, unofficial].
2. **Initialize Accumulators:** Set `res = 0.0` and `sum_amp = 0.0` [S2, unofficial].
3. **Iterate Octaves:** For each octave $o$ from $0$ to $n_{octaves} - 1$:
   a. **Calculate Local Amplitude:** $amp_{local} = \frac{A_{base}}{o + 1}$ [S2, unofficial]. (The source uses `1/oct`, which implies 1-based indexing or a bug at $o=0$; this implementation uses $o+1$ to prevent division by zero [G].)
   b. **Accumulate Amplitude:** `sum_amp += amp_local` [S2, unofficial].
   c. **Compute Base Noise:** Call the base 2D noise function with scaled coordinates: $x' = o \cdot \frac{a}{\lambda}$, $y' = o \cdot \frac{b}{\lambda}$ [S2, unofficial].
   d. **Add to Result:** `res += amp_local * noise(x', y')` [S2, unofficial].
4. **Normalize:** Calculate final result $ans = \frac{res}{sum\_amp}$ [S2, unofficial].
5. **Cache and Return:** Store $ans$ in the cache with the key and return $ans$ [S2, unofficial].

**Sub-routine: `generateSmoothNoise` (for base noise generation if not using a library):**
1. Determine period $P = 2^o$ and frequency $f = 1.0/P$ [S1, unofficial].
2. Identify sample points $(i_0, j_0), (i_1, j_0), (i_0, j_1), (i_1, j_1)$ based on the period and wrap coordinates using modulo width/height [S1, unofficial].
3. Perform bilinear interpolation: first horizontally between top-left and top-right, then horizontally between bottom-left and bottom-right, then vertically between the two results [S1, unofficial].

**Pseudocode:**
```python
def generate_octaved_noise(a, b, n_octaves, wavelength, base_amplitude, cache):
    """
    Computes fractal noise with memoization.
    
    Args:
        a, b: Input coordinates.
        n_octaves: Number of octaves to sum.
        wavelength: Spatial scale factor.
        base_amplitude: Amplitude of the first octave.
        cache: Dictionary for storing results.
        
    Returns:
        Normalized noise value.
    """
    # Step 1: Check Cache
    key = f"{a},{b},{n_octaves}"
    if key in cache:
        return cache[key]
    
    # Step 2: Initialize Accumulators
    res = 0.0
    sum_amp = 0.0
    
    # Step 3: Iterate Octaves
    for o in range(n_octaves):
        # Source uses `1/oct`, which implies 1-based indexing or a bug at o=0.
        # We use (o + 1) to prevent division by zero and match decreasing amplitude intent [G].
        amp_local = base_amplitude / (o + 1)
        
        sum_amp += amp_local
        
        # Calculate scaled coordinates per source: oct * (a / wavelength)
        x_scaled = o * (a / wavelength)
        y_scaled = o * (b / wavelength)
        
        # Base 2D noise function (e.g., Simplex or Perlin) is called here [G].
        noise_val = base_noise_func(x_scaled, y_scaled)
        
        res += amp_local * noise_val
        
    # Step 4: Normalize
    if sum_amp == 0:
        ans = 0.0
    else:
        ans = res / sum_amp
        
    # Step 5: Cache and Return
    cache[key] = ans
    return ans
```

**Edge Cases and Pitfalls:**
- **Division by Zero:** If the loop index $o$ starts at $0$ and the amplitude formula is strictly $1/o$, a division by zero occurs [S2, unofficial]. The implementation must adjust the index or formula [G].
- **Cache Key Precision:** Floating-point coordinates $a, b$ should be quantized or hashed carefully to ensure consistent cache hits [G].
- **Cache Invalidation:** Cache invalidation is not described in the sources [S2, unofficial].

## Subtopics

### Normalized Octave Noise
Scales the octave noise result by the maximum possible amplitude to ensure the output range is consistent regardless of the number of octaves or persistence value [S3, unofficial]. Formula: $result = \frac{octave3D(x, y, z, octaves, persistence)}{MaxAmplitude(octaves, persistence)}$ [S3, unofficial]. $MaxAmplitude$ is a helper function that calculates the sum of amplitudes for the given number of octaves and persistence, used for normalization [S3, unofficial].
