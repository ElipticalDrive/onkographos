# Volume Cloud Generation Pipeline


## Overview
The Volume Cloud Generation Pipeline generates a 3D volumetric density field representing clouds by applying procedural noise functions with domain warping, boundary envelopes, and style-specific shaping [S1, unofficial]. It solves the problem of creating physically plausible, non-repeating cloud patches with controlled edge softness and vertical structure [S1, unofficial]. It differs from its parent [Volumetric Density Generation](4894-volumetric-density-generation.md) by incorporating multi-scale domain warping, specific boundary fade functions, and distinct "realistic" vs. "cartoon" style pipelines, rather than relying solely on a power function and threshold on a single noise field [S1, unofficial].

## How it works
**Inputs:**
- `params`: Configuration object containing `resolution` (int, $N$), `seed` (int), `cloud_type_id` (int), `style` (str: "realistic" or "cartoon"), `disturbance_strength` (float), `detail` (float), `resolved_allow_boundary_overlap` (bool) [S1, unofficial].
- `cloud`: Definition object containing `default_allow_boundary_overlap` (bool) and `LAYER_CLOUD_TYPE_IDS` (set of ints) [S1, unofficial].

**Outputs:**
- `density`: 3D `uint8` array of shape $(N, N, N)$, values in $[0, 255]$ representing density [S1, unofficial].
- `disturbance`: 3D `uint8` array of shape $(N, N, N)$, representing flow [S1, unofficial].
- `metadata`: Dictionary containing encoding version, dimensions, tile layout (cols=$N$, rows=1), axis order (Z,Y,X), cloud type info, parameters, style, noise profile, and channel meanings (R=density, G=flow, B=0, A=255) [S1, unofficial].

**Data Structures:**
- **Noise Lattice**: 3D `float32` array of shape $(F, F, F)$, values uniformly distributed in $[0, 1]$ [S1, unofficial].
- **Coordinate Grids**: 2D `float32` arrays `x` and `y` of shape $(N, N)$, generated via `np.linspace(-1.0, 1.0, N, dtype=np.float32)` and `np.meshgrid` [S1, unofficial].
- **Cartoon Noise Set**: Container holding four tuples of noise lattices (macro, body, edge, flow) [S1, unofficial].

**Algorithm Steps:**
1. Allocate `density` and `disturbance` as $(N, N, N)$ `uint8` arrays. Handle `MemoryError` by raising `VolumeMemoryPressureError` [S1, unofficial].
2. Generate coordinate grids: `axis = np.linspace(-1.0, 1.0, N, dtype=np.float32)`, `x, y = np.meshgrid(axis, axis, indexing="xy")` [S1, unofficial].
3. Initialize noise lattices: `density_lattices` from `seed+101` with scales `(2,3,5,8,13)`, `flow_lattices` from `seed+7919` with scales `(2,4,7,11)`, `boundary_lattices` from `seed+12113` with scales `(1,2,3,5)` [S1, unofficial].
4. If `style == "cartoon"`, generate `cartoon_noise_set` from `seed` and `shape_variation` from `seed` and `cloud_type_id` [S1, unofficial].
5. Determine `uses_natural_finite_edge`: `True` if `not params.resolved_allow_boundary_overlap` AND `cloud.default_allow_boundary_overlap` AND `params.cloud_type_id in cloud.LAYER_CLOUD_TYPE_IDS` [S1, unofficial].
6. If `uses_natural_finite_edge`, generate boundary noise fields for finite edges: `top_surface_noise`, `bottom_surface_noise`, `thickness_noise` using `boundary_lattices` at Z offsets `-0.61`, `0.27`, `0.83` respectively, scaled by `detail_strength * 0.22/0.26/0.18` [S1, unofficial].
7. Calculate `xy_distance` as `np.minimum.reduce((x + 1.0, 1.0 - x, y + 1.0, 1.0 - y))`. Calculate `discrete_cloud_edge_guard` using `_safe_edge_fade(xy_distance, 0.0, 0.045)` [S1, unofficial].
8. Loop over `z_index` from `0` to `N-1`. Let `z = axis[z_index]`.
   - If `style == "cartoon"`, call `_cartoon_noise_fields` to get `macro`, `body`, `edge`, `cartoon_flow`. Call `_cartoon_density_slice` to get `raw_density`. Call `_cartoon_flow_noise` to get `flow` [S1, unofficial].
   - If `style == "realistic"`, generate `density_noise` and `flow_noise` using `_fractal_value_noise` with respective lattices. Call `_density_slice` to get `raw_density`. Set `flow = 0.5 + (flow_noise - 0.5) * params.disturbance_strength` [S1, unofficial].
   - Calculate Z fade: `z_distance = min(float(z + 1.0), float(1.0 - z))`. Apply `_safe_edge_fade(z_distance, SAFE_EMPTY_BORDER_Z, SAFE_FADE_WIDTH_Z)` to get `z_fade` (constants not given in the sources) [S1, unofficial].
   - If `uses_natural_finite_edge`: Calculate `side_edge_noise` using `boundary_lattices` with offset `x + z*0.16, y - z*0.11, z*1.75+0.19`. Calculate `natural_xy_edge` via `_natural_xy_edge_envelope`. Calculate `vertical_envelope` via `_finite_layer_vertical_envelope`. Calculate `fixed_vertical` via `_fixed_layer_vertical_profile` (min 0.075). Multiply `raw_density` by `natural_xy_edge * (vertical_envelope / fixed_vertical)` [S1, unofficial].
   - If not `uses_natural_finite_edge` but `not params.resolved_allow_boundary_overlap`, multiply `raw_density` by `discrete_cloud_edge_guard` [S1, unofficial].
   - Apply Z fade: `raw_density *= z_fade`. Store result in `density[z_index]` by clipping `raw_density` to $[0,1]$, multiplying by 255, rounding, and casting to `uint8`. Store `flow` in `disturbance[z_index]` similarly [S1, unofficial].
9. Construct `metadata` dictionary [S1, unofficial].
10. Return `VolumeResult` containing `density`, `disturbance`, and `metadata` [S1, unofficial].

**Pseudocode:**
```python
import numpy as np

def volume_cloud_generation_pipeline(params, cloud):
    N = params.resolution
    try:
        density = np.zeros((N, N, N), dtype=np.uint8)
        disturbance = np.zeros((N, N, N), dtype=np.uint8)
    except MemoryError:
        raise VolumeMemoryPressureError("Insufficient memory for volume allocation.")

    axis = np.linspace(-1.0, 1.0, N, dtype=np.float32)
    x, y = np.meshgrid(axis, axis, indexing="xy")

    density_lattices = _make_noise_lattices(params.seed + 101, (2, 3, 5, 8, 13))
    flow_lattices = _make_noise_lattices(params.seed + 7919, (2, 4, 7, 11))
    boundary_lattices = _make_noise_lattices(params.seed + 12113, (1, 2, 3, 5))

    cartoon_noise_set = None
    shape_variation = None
    if params.style == "cartoon":
        cartoon_noise_set = _make_cartoon_noise_set(params.seed)
        shape_variation = _generate_shape_variation(params.seed, params.cloud_type_id)

    uses_natural_finite_edge = (not params.resolved_allow_boundary_overlap and 
                                cloud.default_allow_boundary_overlap and 
                                params.cloud_type_id in cloud.LAYER_CLOUD_TYPE_IDS)

    xy_distance = np.minimum.reduce((x + 1.0, 1.0 - x, y + 1.0, 1.0 - y))
    discrete_cloud_edge_guard = _safe_edge_fade(xy_distance, 0.0, 0.045)

    SAFE_EMPTY_BORDER_Z = 0.0  # Not given in the sources
    SAFE_FADE_WIDTH_Z = 0.045  # Not given in the sources

    for z_idx in range(N):
        z = axis[z_idx]

        if params.style == "realistic":
            density_noise = _fractal_value_noise(density_lattices, x, y, z, params.detail)
            flow_noise = _fractal_value_noise(flow_lattices, x, y, z, params.detail)
            raw_density = _density_slice(density_noise, z)
            flow = 0.5 + (flow_noise - 0.5) * params.disturbance_strength
        else:
            macro, body, edge, cartoon_flow = _cartoon_noise_fields(cartoon_noise_set, x, y, z, params.detail, params.disturbance_strength)
            raw_density = _cartoon_density_slice(macro, body, edge, z)
            flow = _cartoon_flow_noise(cartoon_flow, z)

        z_distance = np.minimum(z + 1.0, 1.0 - z)
        z_fade = _safe_edge_fade(z_distance, SAFE_EMPTY_BORDER_Z, SAFE_FADE_WIDTH_Z)

        if uses_natural_finite_edge:
            side_edge_noise = _value_noise_slice(boundary_lattices[0], x + z*0.16, y - z*0.11, z*1.75 + 0.19)
            natural_xy_edge = _natural_xy_edge_envelope(side_edge_noise, shape_variation)
            vertical_envelope = _finite_layer_vertical_envelope(params.cloud_type_id, z)
            fixed_vertical = _fixed_layer_vertical_profile(params.cloud_type_id, z)
            fixed_vertical = max(fixed_vertical, 0.075)
            raw_density *= natural_xy_edge * (vertical_envelope / fixed_vertical)
        elif not params.resolved_allow_boundary_overlap:
            raw_density *= discrete_cloud_edge_guard

        raw_density *= z_fade

        density[z_idx] = np.rint(np.clip(raw_density, 0.0, 1.0) * 255.0).astype(np.uint8)
        disturbance[z_idx] = np.rint(np.clip(flow, 0.0, 1.0) * 255.0).astype(np.uint8)

    metadata = {
        "encoding_version": 1,
        "dimensions": (N, N, N),
        "tile_layout": {"cols": N, "rows": 1},
        "axis_order": "Z,Y,X",
        "cloud_type_id": params.cloud_type_id,
        "style": params.style,
        "channels": {"R": "density", "G": "flow", "B": 0, "A": 255}
    }

    return VolumeResult(density, disturbance, metadata)

def _smoothstep(t):
    t = np.clip(t, 0.0, 1.0)
    return t * t * (3.0 - 2.0 * t)

def _safe_edge_fade(distance, empty_border, fade_width):
    return _smoothstep(np.maximum(distance - empty_border, 0.0) / fade_width)

def _fade(t):
    return t * t * (t * (t * (6.0 * t - 15.0) + 10.0))

def _make_noise_lattices(seed, frequencies):
    generator = np.random.default_rng(seed)
    return tuple(generator.random((f, f, f), dtype=np.float32) for f in frequencies)

def _value_noise_slice(lattice, x, y, z):
    frequency = lattice.shape[0]
    px = (x + 1.0) * 0.5 * frequency
    py = (y + 1.0) * 0.5 * frequency
    pz = (z + 1.0) * 0.5 * frequency
    ix = np.floor(px).astype(np.intp) % frequency
    iy = np.floor(py).astype(np.intp) % frequency
    iz = np.floor(pz).astype(np.intp) % frequency
    fx, fy, fz = _fade(px - np.floor(px)), _fade(py - np.floor(py)), _fade(pz - np.floor(pz))
    ix1, iy1, iz1 = (ix + 1) % frequency, (iy + 1) % frequency, (iz + 1) % frequency
    c00 = lattice[iz, iy, ix] * (1.0 - fx) + lattice[iz, iy, ix1] * fx
    c10 = lattice[iz, iy1, ix] * (1.0 - fx) + lattice[iz, iy1, ix1] * fx
    c01 = lattice[iz1, iy, ix] * (1.0 - fx) + lattice[iz1, iy, ix1] * fx
    c11 = lattice[iz1, iy1, ix] * (1.0 - fx) + lattice[iz1, iy1, ix1] * fx
    lower = c00 * (1.0 - fy) + c10 * fy
    upper = c01 * (1.0 - fy) + c11 * fy
    return lower * (1.0 - fz) + upper * fz

def _fractal_value_noise(lattices, x, y, z, detail):
    warp_strength = 0.12 + 0.08 * np.clip(detail, 0.0, 1.0)
    lattice_x, lattice_y, lattice_z = lattices[0], lattices[1], lattices[2]
    warp_x = _value_noise_slice(lattice_x, x + y, y - z, z + x) - 0.5
    warp_y = _value_noise_slice(lattice_y, 2.0 * x - y, x + z, y + z) - 0.5
    warp_z = _value_noise_slice(lattice_z, x - z, 2.0 * y + z, x + y - z) - 0.5
    warped_x, warped_y, warped_z = x + warp_strength * warp_x, y + warp_strength * warp_y, z + warp_strength * warp_z
    transforms = (
        (warped_x, warped_y, warped_z),
        (warped_x + warped_y, warped_y + warped_z, warped_z + warped_x),
        (2.0 * warped_x - warped_y, warped_x + 2.0 * warped_y, warped_z + warped_y),
        (warped_x - warped_z, 2.0 * warped_y + warped_z, warped_x + warped_y - warped_z),
        (2.0 * warped_x + warped_z, warped_y - warped_x, 2.0 * warped_z + warped_y),
    )
    samples = [_value_noise_slice(lattices[i % len(lattices)], *transforms[i % len(transforms)]) for i in range(len(lattices))]
    weights = [1.0]
    for i in range(1, len(samples)):
        weights.append((0.52 + detail * 0.16) ** i)
    total = sum(w * s for w, s in zip(weights, samples))
    return np.clip(total / sum(weights), 0.0, 1.0)

def _make_cartoon_noise_set(seed):
    return {
        "macro_lattices": _make_noise_lattices(seed + 20101, (1, 2, 3)),
        "body_lattices": _make_noise_lattices(seed + 20503, (2, 3, 5)),
        "edge_lattices": _make_noise_lattices(seed + 20907, (3, 5, 7)),
        "flow_lattices": _make_noise_lattices(seed + 21301, (2, 3, 5, 8))
    }

def _cartoon_noise_fields(noise_set, x, y, z, detail, disturbance):
    macro = _fractal_value_noise(noise_set["macro_lattices"], x, y, z, detail * 0.10)
    body = _fractal_value_noise(noise_set["body_lattices"], x, y, z, detail * 0.30)
    edge = _fractal_value_noise(noise_set["edge_lattices"], x, y, z, detail * 0.55)
    flow = _fractal_value_noise(noise_set["flow_lattices"], x, y, z, disturbance * 0.25)
    return macro, body, edge, flow

def _density_slice(noise, z):
    return np.clip(noise, 0.0, 1.0)  # Standard threshold/power mapping [G]

def _cartoon_density_slice(macro, body, edge, z):
    return np.clip(macro * 0.5 + body * 0.3 + edge * 0.2, 0.0, 1.0)  # Standard composite mapping [G]

def _cartoon_flow_noise(flow, z):
    return np.clip(flow, 0.0, 1.0)  # Standard flow mapping [G]

def _generate_shape_variation(seed, cloud_type_id):
    rng = np.random.default_rng(seed + cloud_type_id)
    return {"center_x": rng.uniform(-0.5, 0.5), "center_y": rng.uniform(-0.5, 0.5), "angle_radians": rng.uniform(0, 2 * np.pi)}

def _natural_xy_edge_envelope(side_edge_noise, shape_variation):
    local_x, local_y = x - shape_variation["center_x"], y - shape_variation["center_y"]
    cos_a, sin_a = np.cos(shape_variation["angle_radians"]), np.sin(shape_variation["angle_radians"])
    rot_x, rot_y = cos_a * local_x + sin_a * local_y, -sin_a * local_x + cos_a * local_y
    return _smoothstep(1.0 - np.sqrt(rot_x**2 + rot_y**2) + side_edge_noise * 0.2)

def _finite_layer_vertical_envelope(type_id, z):
    return _smoothstep(1.0 - abs(z) * 0.5)  # Standard vertical falloff [G]

def _fixed_layer_vertical_profile(type_id, z):
    return 0.1  # Standard fixed profile [G]
```

## Subtopics

### [Redshift Clouds Object](10707-redshift-clouds-object.md)
The Redshift Clouds Object generates entire procedural skies, distinguishing itself from general noise functions by providing a complete sky generation pipeline that supports both a fast, non-volumetric background mode and a fully volumetric mode where geometry (such as skyscrapers or aircraft) can pierce the cloud layer and interact with its lighting. It builds on the Volume Cloud Generation Pipeline [8286-volume-cloud-generation-pipeline.md].

## Background
The Volume Cloud Generation Pipeline is derived from procedural noise techniques used in computer graphics for generating natural phenomena [S1, unofficial]. The specific implementation is from the `Noise-Cloud` project by mingtu149411 [S1, unofficial]. It builds upon the principles of fractal Brownian motion (fBm) and domain warping to create volumetric density fields, serving as a child of the general [Volumetric Density Generation](4894-volumetric-density-generation.md) method [S1, unofficial].
