# Redshift Clouds Object
Also called: Redshift Clouds
## Overview
The Redshift Clouds Object generates entire procedural skies, offering a fast mode that renders the cloud deck as a clever background and a fully volumetric mode in which a skyscraper or an aircraft can pierce the cloud layer and be lit by it [S1]. It distinguishes itself from voxel-based volume objects by generating clouds procedurally rather than reading external VDB data [S1].
## How it works
Inputs and outputs: The object takes procedural parameters to define cloud appearance and depth, outputting a sky layer that can be rendered as a background or a volumetric medium [S1].
Data structures: Not given in the sources.
Numbered steps:
1. Initialize the procedural sky generation based on the selected mode (fast background or fully volumetric) [S1].
2. In fast mode, render the cloud deck as a background layer [S1].
3. In fully volumetric mode, allow geometry such as skyscrapers or aircraft to pierce the cloud layer while maintaining lighting interactions [S1].

## Subtopics

### Redshift Environment Object
Used for homogeneous volumes (uniform media such as atmospheric haze and fog) which do not need voxel data [S1]. It fills the scene, or a height limited layer of it, with a scattering medium [S1]. It is also used for volumetric lighting, specifically for creating visible god rays in dusty air [S1].

Strengths and limitations: The fast mode provides efficient background rendering, while the volumetric mode supports complex interactions like piercing geometry [S1].
When to use it and when not: Use for procedural skies where geometry interaction is required; use the Redshift Environment Object for uniform haze/fog without procedural cloud detail [S1].
