# Cartoon Noise Lattice Generation

Also called: Cartoon Noise Set Generation, Macro/Body/Edge/Flow Lattice Generation

## Overview
Cartoon Noise Lattice Generation produces independent, tileable noise lattices for cartoon-style cloud rendering by separating noise into four distinct functional groups: macro (outline), body (fill), edge (detail), and flow (disturbance) [S1, unofficial]. The method generates multiple specialized lattices with specific frequency constraints to ensure stability and avoid fixed-direction ripple artifacts, building on [Gradient-based Noise (Perlin/Simplex)](3860-gradient-based-noise-perlin-simplex.md) [S1, unofficial].

## How it works
**Inputs and Outputs:**
- **Inputs:** A `MaskParameters` object containing resolution (512, 1024, or 2048), global height bounds (`global_min_cm`, `global_max_cm`), weather type, seed, coverage percentage, cloud region count, and optional `CloudHeightRule` configurations [S1, unofficial].
- **Outputs:** A `_CartoonNoiseSet` dataclass containing four tuples of numpy arrays: `macro_lattices`, `body_lattices`, `edge_lattices`, and `flow_lattices` [S1, unofficial].

**Data Structures:**
1.  **`MaskParameters`**:
    -   `resolution`: `int` (512, 1024, or 2048) [S1, unofficial].
    -   `global_min_cm`, `global_max_cm`: `int` defining the vertical volume bounds [S1, unofficial].
    -   `seed`: `int` for deterministic generation [S1, unofficial].
    -   `cloud_region_count`: `int` (1–500) [S1, unofficial].
    -   `cloud_height_rules`: `tuple[CloudHeightRule, ...]` [S1, unofficial].
2.  **`CloudHeightRule`**:
    -   `type_id`: `int` [S1, unofficial].
    -   `center_min_cm`, `center_max_cm`: `int` defining the target center height range [S1, unofficial].
    -   `height_delta_min_cm`, `height_delta_max_cm`: `int` defining the minimum and maximum height difference for the volume box [S1, unofficial].
3.  **`_CartoonNoiseSet`**:
    -   `macro_lattices`: `tuple[np.ndarray, ...]` [S1, unofficial].
    -   `body_lattices`: `tuple[np.ndarray, ...]` [S1, unofficial].
    -   `edge_lattices`: `tuple[np.ndarray, ...]` [S1, unofficial].
    -   `flow_lattices`: `tuple[np.ndarray, ...]` [S1, unofficial].

**Algorithm Steps:**
1.  **Validate Parameters:** Ensure `resolution` is in {512, 1024, 2048}, `global_max_cm > global_min_cm`, and `0 <= coverage_percent <= 100` [S1, unofficial].
2.  **Generate Height Rules:** For each cloud type, determine vertical bounds [S1, unofficial]. If a `CloudHeightRule` is provided, sample `center_min_cm` and `center_max_cm` via `rng.integers` [S1, unofficial]. Otherwise, derive bounds from legacy constants: `(0.62, 0.92)` for `type_id == 10`, `(0.22, 0.58)` for others [S1, unofficial]. Calculate `delta_min` and `delta_max` using `VOLUME_BOX_HEIGHT_MULTIPLIER` applied to the span [S1, unofficial].
3.  **Generate Lattices:** Call `_make_noise_lattices` for each of the four groups (macro, body, edge, flow) with specific frequencies to ensure they are small, stable, and avoid fixed-direction ripple artifacts [S1, unofficial].
4.  **Construct Set:** Pack the resulting tuples into the `_CartoonNoiseSet` dataclass [S1, unofficial].

**Edge Cases and Pitfalls:**
-   **Resolution Constraints:** Only 512, 1024, and 2048 are supported [S1, unofficial].
-   **Height Bounds:** `global_max_cm` must be strictly greater than `global_min_cm` [S1, unofficial].
-   **Artifact Avoidance:** Frequencies must be carefully selected per group to prevent fixed-direction ripple artifacts [S1, unofficial].

## Subtopics

### Cartoon Flow Noise Generation
A variant that computes a coherent flow field by combining the generated lattices [S1, unofficial]. It clips the weighted sum of flow, macro, and body noise channels: `coherent = np.clip(0.58 * flow + 0.27 * macro + 0.15 * body, 0.0, 1.0)` [S1, unofficial]. It then modulates this coherent flow around the center value 0.5 by a strength parameter: `return np.clip(0.5 + (coherent - 0.5) * strength, 0.0, 1.0)` [S1, unofficial]. This output drives disturbance in the cloud volume [S1, unofficial].
