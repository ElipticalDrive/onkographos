# Spherical Density Ramp with Noise

Also called: ramp-confined turbulence gas, steam_slab1 confined gas modeling

## Overview
Spherical Density Ramp with Noise is a procedural volume density function that confines gas to a slab region using a spherical distance ramp and an offset table, simulating steam rising from a source [S1, unofficial]. It differs from its parent, [Procedural Noise Functions](1799-procedural-noise-functions.md), by adding spatial confinement and vertical falloff to the base turbulence, and from [Worley Noise](1726-worley-noise.md) by using a deterministic distance-based ramp rather than cell-based proximity [S1, unofficial].

## How it works
**Inputs and Outputs:**
- `pnt`: Point in solid texture space (used for turbulence).
- `pnt_world`: Point in world space (used for spatial confinement).
- `*density`: Input density (from turbulence), output density (modulated by ramp).
- `*parms`: Parameter array. `parms[1]` is the exponent for the power function; `parms[2]` is the exponent for the power function for gas shaping (Note: Source [S1, unofficial] lists `parms[2]` as exponent for power function in `basic_gas` and `parms[1]` as exponent in `steam_slab1` context, but the code uses `parms[1]` and `parms[2]` consistently in the power table calculation. We follow the code: `parms[1]` scales the input, `parms[2]` is the exponent). `parms[3]` is the randomness multiplier for the offset table.
- `vol`: Volume structure containing `shape.center` and `shape.inv_rad_sq.y`.

**Data Structures:**
- `pow_table[POW_TABLE_SIZE]`: Precomputed table of power function values.
- `ramp[RAMP_SIZE]`: Precomputed table of cosine falloff values.
- `offset[OFFSET_SIZE]`: Precomputed table of random numbers used to add noise to the ramp off of the density.

**Steps:**
1. **Precomputation (once per image):**
   - Compute `pow_table`: For `i` from `POW_TABLE_SIZE-1` down to `0`:
     $$ pow\_table[i] = \left( \frac{i}{POW\_TABLE\_SIZE - 1} \times parms[1] \times 2.0 \right)^{parms[2]} $$
   - Compute `ramp`: For `i` from `0` to `RAMP_SIZE-1`:
     $$ dist = \frac{i}{RAMP\_SIZE - 1.0} $$
     $$ ramp[i] = \frac{\cos(dist \times \pi) + 1.0}{2.0} $$

2. **Base Turbulence:**
   - Evaluate turbulence: `turb = fast_turbulence(pnt)`.
   - Map to base density:
     $$ *density = pow\_table[\lfloor turb \times 0.5 \times (POW\_TABLE\_SIZE - 1) \rfloor] $$

3. **Spherical Confinement:**
   - Calculate squared distance from the point to the volume center:
     $$ diff = pnt\_world - vol.shape.center $$
     $$ dist\_sq = diff \cdot diff $$
   - Compute initial density scaling factor:
     $$ density\_max = dist\_sq \times vol.shape.inv\_rad\_sq.y $$

4. **Noise Addition:**
   - Calculate index into random offset table:
     $$ indx = \lfloor (pnt.x + pnt.y + pnt.z) \times 100 \rfloor \ \& \ (OFFSET\_SIZE - 1) $$
   - Add noise to density scaling factor:
     $$ density\_max += parms[3] \times offset[indx] $$

5. **Ramp Application:**
   - If `density_max >= 0.25`:
     - Calculate ramp index:
       $$ i = \lfloor (density\_max - 0.25) \times \frac{4}{3} \times RAMP\_SIZE \rfloor $$
     - Clamp `i` to `[0, RAMP_SIZE-1]`.
     - Apply ramp:
       $$ density\_max = ramp[i] $$
     - Modulate density:
       $$ *density *= density\_max $$

**Parameters:**
- `vol.shape.center`: 3D center point of the volume slab [S1, unofficial].
- `vol.shape.inv_rad_sq.y`: Inverse squared radius factor for the slab [S1, unofficial].
- `parms[1]`: Exponent for the power function for gas shaping [S1, unofficial].
- `parms[2]`: Exponent for the power function for gas shaping (Note: Source [S1, unofficial] code uses `parms[2]` as exponent, text says `parms[2]` is exponent. We use `parms[2]` as exponent).
- `parms[3]`: Multiplier for the offset table values (amount of randomness) [S1, unofficial].

**Edge Cases and Pitfalls:**
- `density_max` must be checked against `0.25` before applying the ramp to avoid negative indices or incorrect falloff [S1, unofficial].
- The index `i` for the ramp table must be clamped to `RAMP_SIZE-1` to prevent out-of-bounds access [S1, unofficial].
- `fast_turbulence` must return a value in a range that maps correctly to `pow_table` indices (typically 0 to 1) [S1, unofficial].

## Subtopics

### [NoiseTexture value evaluation](3448-noisetexture-value-evaluation.md)
Computes volumetric color/density using normalized coordinates, radial/vertical fading, double warping via FBM, and sinusoidal noise modulation [3448-noisetexture-value-evaluation.md].

### Vertical Exponential Density Ramp
Applies an exponential falloff to density based on vertical distance from the volume center. If the vertical distance `dist = pnt_world.y - vol.shape.center.y` is greater than 0.0, it is normalized with noise: `dist = (dist + offset[indx]*0.1) * vol.shape.inv_rad.y`. If `dist > 0.05`, an exponential ramp is applied: `offset2 = (dist - 0.05) * 1.111111`, then `offset2 = 1 - (exp(offset2) - 1.0) / 1.718282`, then `offset2 *= parms[1]`, and finally `*density *= offset2` [S1, unofficial].

### Radial Exponential Density Ramp
Applies a radial exponential falloff if `ZoneIndex` is `(0, 0, -1)`. It calculates radial distance `r = sqrt(P.X^2 + P.Y^2 + P.Z^2)` and then `t = 1 - exp(-pow(r, 2) / (MaxR * 100))` where `MaxR = 1000`. The density is multiplied by `t`. If `IsCaveLayerZone(ZoneIndex.Z)` is true, the function currently returns the density unchanged [S2, unofficial].

## Operating characteristics
- **Time Complexity:** O(1) per point for the ramp calculation, assuming precomputed tables. The turbulence function `fast_turbulence` dominates the cost.
- **Memory Complexity:** O(POW_TABLE_SIZE + RAMP_SIZE + OFFSET_SIZE) for precomputed tables.
- **Strengths:** Efficiently confines gas to a specific region and simulates rising steam with natural falloff.
- **Limitations:** Relies on precomputed tables which may not adapt well to dynamic scenes without recomputation. The noise is static and based on a simple offset table.
- **When to use:** Simulating confined gases like steam or smoke from a source.
- **When not to use:** When dynamic, large-scale volumetric effects are required without precomputation.

## Background
The method was introduced by David Ebert in "Procedural Modeling, Animation, and Rendering of Gases, Fluids, and Textures" [S1, unofficial]. It was developed to address the limitations of basic turbulence functions, which did not confine gas to a specific region or simulate the natural rise and falloff of steam. The method uses a spherical distance ramp and an offset table to achieve this effect.
