# Bristorbrot Fractal Generation

Also called: Bristorbrot

## Overview
Bristorbrot is a 3D fractal generation method that produces a volumetric structure using a specific iterative polynomial mapping in Cartesian coordinates [S1, unofficial]. It differs from the Mandelbulb by employing a distinct algebraic iteration rule that does not rely on polar coordinate power transformations, resulting in a unique geometric topology [S1, unofficial].

## How it works
**Inputs:** A 3D point $p$ (the voxel center or ray origin), `max_iterations` (integer), `max_distance` (float).
**Outputs:** A boolean indicating if the point belongs to the fractal set (inside), or the escape iteration count.

**Data Structures:**
*   `point3d`: A structure containing three floating-point fields: `x`, `y`, `z`.
*   `float`: Standard 32-bit or 64-bit floating-point number.

**Parameters:**
*   `max_iterations`: Default 30 [S1, unofficial].
*   `max_distance`: Default 200 [S1, unofficial].

**Steps:**
1.  Initialize the iteration state $z$ to the input point $p_{in}$:
    $$z = p_{in}$$
2.  Initialize the squared distance accumulator $z_{dist}$:
    $$z_{dist} = x^2 + y^2 + z^2$$
3.  Loop $i$ from 0 to `max_iterations` - 1:
    a. Compute the new coordinates $p_{new}$ based on the current $z$:
    $$p_{new}.x = z.x^2 - z.y^2 - z.z^2$$
    $$p_{new}.y = z.y \cdot (2.0 \cdot z.x - z.z)$$
    $$p_{new}.z = z.z \cdot (2.0 \cdot z.x + z.y)$$
    b. Update $z$ by adding the input point $p_{in}$ to the new coordinates:
    $$z = p_{new} + p_{in}$$
    c. Update the squared distance:
    $$z_{dist} = z.x^2 + z.y^2 + z.z^2$$
    d. Check for escape: If $z_{dist} > \text{max\_distance}$, break the loop.
4.  If the loop completes all `max_iterations` without breaking, the point is considered part of the fractal set.

**Pseudocode:**
```python
def bristorbrot(p_in, max_iterations=30, max_distance=200):
    z = p_in
    z_dist = z.x**2 + z.y**2 + z.z**2
    
    for i in range(max_iterations):
        # Compute new coordinates
        new_x = z.x**2 - z.y**2 - z.z**2
        new_y = z.y * (2.0 * z.x - z.z)
        new_z = z.z * (2.0 * z.x + z.y)
        
        # Update z = new_p + p_in
        z.x = new_x + p_in.x
        z.y = new_y + p_in.y
        z.z = new_z + p_in.z
        
        # Update distance
        z_dist = z.x**2 + z.z.y**2 + z.z**2
        
        # Check escape
        if z_dist > max_distance:
            return i
            
    return max_iterations
```

**Edge Cases and Pitfalls:**
*   **Precision:** Squaring large coordinates can lead to overflow if `max_distance` is set excessively high. The default of 200 is safe for standard float precision.
*   **Boundaries:** The method assumes a bounded volume. Points far from the origin will escape quickly.
*   **Degenerate Input:** If $p_{in}$ is $(0,0,0)$, $z$ remains $(0,0,0)$ and the point is always inside.

## Subtopics

### Knot Fractal Generation
A fractal distance function representing a knot shape, constructed by iterating and transforming a base curve [S2, unofficial]. It differs from Bristorbrot by using a parametric curve transformation with angular offsets rather than a polynomial iteration in Cartesian space [S2, unofficial]. Choose this when a knotted topology is required.

**Definition:**
Generates a distance field for a knot fractal using iterative angular transformations [S2, unofficial].

**Steps:**
1.  Initialize `r = length(p.xz)`, `ang = atan(p.z, p.x)`, `y = p.y`, `d = HUGEVAL`.
2.  Loop `n` from 0 to `ITERATIONS` - 1:
    a. Create `p = vec3(r, y, ang + 2.0 * PI * float(n))`.
    b. Subtract `offset.z` from `p.x`.
    c. Calculate `ra = (p.z + time) * clamp.x / clamp.z` and `raz = p.z * clamp.y / clamp.z`.
    d. Update distance `d = min(d, length(p.xy - vec2(offset.y*cos(ra)+offset.z, offset.y*sin(raz)+offset.z)) - offset.x)`.

**Parameters:**
*   `ITERATIONS`: 3 [S2, unofficial].
*   `offset`: `vec3(0.07, 0.29, 0.43)` [S2, unofficial].
*   `clamp`: `vec3(-2.0, -4.0, 3.0)` [S2, unofficial].

## Operating characteristics
*   **Time Complexity:** $O(N \cdot I)$, where $N$ is the number of voxels/pixels and $I$ is `max_iterations`. Each iteration involves constant-time arithmetic operations.
*   **Memory Complexity:** $O(1)$ per point evaluation. No auxiliary data structures are required beyond the current state $z$.
*   **Performance:** The method is computationally lightweight per iteration compared to high-power Mandelbulb calculations, but requires more iterations (30 vs 5-10) to converge visually [S1, unofficial].
*   **Strengths:** Simple algebraic structure allows for efficient parallelization across voxels or pixels.
*   **Limitations:** The resulting geometry is dense and may require significant post-processing or ray-marching refinement for clear surface definition.

## Background
The Bristorbrot fractal is defined in the context of procedural volume rendering experiments, specifically within the `holographic_fractals` repository [S1, unofficial]. It is presented as an alternative to the Mandelbulb, utilizing a specific Cartesian polynomial mapping to generate 3D fractal structures.
