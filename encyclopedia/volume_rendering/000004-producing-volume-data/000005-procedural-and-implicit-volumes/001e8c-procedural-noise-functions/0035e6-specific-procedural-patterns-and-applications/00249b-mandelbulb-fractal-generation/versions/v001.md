# Mandelbulb Fractal Generation

Also called: Mandelbulb

## Overview
Generates a 3D fractal by iteratively applying a polar coordinate power transformation to a complex 3D point [S1, unofficial]. It differs from standard 2D Mandelbrot sets by extending the iteration into three dimensions using spherical coordinate manipulation, creating a solid, organic-looking volumetric structure suitable for ray marching or voxel generation [S1, unofficial].

## How it works
**Inputs:**
- Query point $P = (x, y, z)$ in Cartesian coordinates.
- `max_iterations`: Integer limit for the escape radius check (default 5) [S1, unofficial].
- `power`: Exponent for the polar transformation (default 8.0) [S1, unofficial].
- `max_distance`: Escape radius threshold (default 20.0) [S1, unofficial].

**Outputs:**
- Boolean or distance value indicating if the point is inside the fractal (or its distance for ray marching). In the provided voxel context, it returns a boolean indicating if the point is part of the solid [S1, unofficial].

**Data Structures:**
- `point3d`: A structure or tuple containing three floating-point fields: `x`, `y`, `z`.
- `z_dist`: A single floating-point value representing the squared Euclidean distance of the current iteration point from the origin.

**Steps:**
1.  Initialize the iteration point $z$ to the input point $P$.
2.  Calculate the initial squared distance $z\_dist = \|z\|^2 = x^2 + y^2 + z^2$.
3.  Loop $i$ from 0 to `max_iterations` - 1:
    a.  Convert $z$ to spherical coordinates $(r, \theta, \phi)$, where $r = \sqrt{z\_dist}$, $\theta$ is the polar angle (from z-axis), and $\phi$ is the azimuthal angle (in xy-plane).
    b.  Apply the power transformation:
        $$r_{new} = r^{power}$$
        $$\theta_{new} = \theta \times power$$
        $$\phi_{new} = \phi \times power$$
    c.  Convert back to Cartesian coordinates $(x', y', z')$:
        $$x' = r_{new} \sin(\theta_{new}) \cos(\phi_{new})$$
        $$y' = r_{new} \sin(\phi_{new}) \sin(\theta_{new})$$
        $$z' = r_{new} \cos(\theta_{new})$$
    d.  Update $z$ by adding the original input point $P$ to the transformed point:
        $$z_{new} = (x' + P_x, y' + P_y, z' + P_z)$$
    e.  Update $z\_dist = \|z_{new}\|^2$.
    f.  Check escape: If $z\_dist > max\_distance$, break the loop.
4.  If the loop completes all `max_iterations` without breaking, the point is considered inside the fractal.

**Pseudocode:**

```python
import math

def mandelbulb_iter(p_in, max_iterations, power, max_distance):
    """
    Determines if point p_in is inside the Mandelbulb fractal.
    Returns True if inside, False if escaped.
    """
    # Initialize z to input point
    z_x = p_in[0]
    z_y = p_in[1]
    z_z = p_in[2]
    
    # Calculate initial squared distance
    z_dist = z_x**2 + z_y**2 + z_z**2
    
    # Check initial escape
    if z_dist > max_distance:
        return False

    for i in range(max_iterations):
        # Convert to spherical coordinates
        r = math.sqrt(z_dist)
        
        # Avoid division by zero or invalid angles for origin
        if r == 0:
            # Origin is typically inside, but depends on specific definition. 
            # Standard Mandelbulb keeps origin.
            continue
            
        theta = math.acos(z_z / r)
        phi = math.atan2(z_y, z_x)
        
        # Apply power transformation
        r_new = r ** power
        theta_new = theta * power
        phi_new = phi * power
        
        # Convert back to Cartesian
        sin_theta_new = math.sin(theta_new)
        cos_theta_new = math.cos(theta_new)
        sin_phi_new = math.sin(phi_new)
        cos_phi_new = math.cos(phi_new)
        
        new_x = r_new * sin_theta_new * cos_phi_new
        new_y = r_new * sin_phi_new * sin_theta_new
        new_z = r_new * cos_theta_new
        
        # Update z by adding original input point
        z_x = new_x + p_in[0]
        z_y = new_y + p_in[1]
        z_z = new_z + p_in[2]
        
        # Update distance
        z_dist = z_x**2 + z_y**2 + z_z**2
        
        # Check escape
        if z_dist > max_distance:
            return False
            
    return True
```

**Parameters:**
- `power`: 8.0 [S1, unofficial].
- `max_iterations`: 5 [S1, unofficial].
- `max_distance`: 20.0 [S1, unofficial].

**Edge Cases and Pitfalls:**
- **Origin:** If $P=(0,0,0)$, $r=0$. The spherical conversion involves $\cos^{-1}(1)$ and $\tan^{-1}(0,0)$. The code must handle $r=0$ to avoid NaNs or crashes. In the provided C code, `length3d2` is used, and if $z$ is zero, the loop continues or breaks based on distance. The pseudocode above skips the transformation if $r=0$, effectively keeping the point at the origin, which is inside the set.
- **Precision:** High power values can lead to rapid divergence or underflow/overflow in floating-point arithmetic.
- **Boundary:** The `max_distance` threshold determines the sensitivity of the escape test. A larger value allows more iterations before declaring "outside", potentially capturing finer details but increasing computation time.

## Subtopics

### [Bristorbrot Fractal Generation](3328-bristorbrot-fractal-generation.md)
Generates a 3D fractal using a specific iterative polynomial mapping in Cartesian coordinates [3328-bristorbrot-fractal-generation.md]. It is chosen when a different geometric structure than the spherical Mandelbulb is desired, often resulting in more angular or distinctively shaped fractals.

### [Menger Sponge Fractal Generation](3550-menger-sponge-fractal-generation.md)
Generates a 3D voxel grid representing a Menger sponge by iteratively dividing space into 3x3x3 subcubes and removing those where two or more coordinates fall into the middle third [3550-menger-sponge-fractal-generation.md]. It is chosen for creating highly porous, self-similar structures with exact geometric boundaries, unlike the smooth escape-radius based Mandelbulb.

### Quaternion Fractal Generation
A fractal distance function based on quaternion iteration, similar to Mandelbrot sets but in 3D [S2, unofficial]. It uses a 4D quaternion representation $v = (v_x, v_y, v_z, v_w)$ and iterates using quaternion multiplication rules to compute a distance estimate. It is chosen when a mathematically rigorous distance estimator for ray marching is required, as it provides a closed-form distance approximation $0.5 \cdot r \cdot \log(r) / \|d\|$ where $r = \|v\|$ and $d$ is the derivative quaternion [S2, unofficial].

## Operating characteristics
- **Time Complexity:** $O(I)$ per voxel, where $I$ is `max_iterations`. The number of floating-point operations per iteration is constant (sine, cosine, power, multiplication).
- **Memory Complexity:** $O(1)$ auxiliary space per voxel query.
- **Performance:** The default parameters (5 iterations, power 8) are very fast. Increasing iterations or power significantly increases computation time.
- **Strengths:** Produces visually complex, organic 3D shapes from simple equations. Easy to implement in shaders or voxel generators.
- **Limitations:** No exact distance estimator in the basic version (requires ray marching with small steps or bounding boxes). The "inside" test is binary based on escape, which can be noisy for rendering without marching.

## Background
The Mandelbulb was discovered in 2009 by Daniel Shapero and others, aiming to create a 3D analogue of the Mandelbrot set [S1, unofficial]. It gained popularity in the procedural generation and fractal art communities. The provided implementation is a voxel-based generator using a simple escape-time algorithm [S1, unofficial].
