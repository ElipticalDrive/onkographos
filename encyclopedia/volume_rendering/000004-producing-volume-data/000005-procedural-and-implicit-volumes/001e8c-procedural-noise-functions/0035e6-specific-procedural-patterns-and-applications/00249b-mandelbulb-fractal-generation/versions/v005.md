# Mandelbulb Fractal Generation

Also called: Mandelbulb

## Overview
Generates a 3D fractal by iteratively applying a polar coordinate power transformation to a complex 3D point [S1, unofficial]. It differs from its siblings by using continuous polar coordinate exponentiation rather than discrete modulo arithmetic (Menger Sponge) or simple polynomial mappings (Bristorbrot) [S1, unofficial][S2, unofficial].

## How it works
**Inputs:** Query point $\mathbf{p}$, maximum iterations $N_{max}$, power exponent $P$, escape radius $R_{max}$.
**Outputs:** Boolean indicating if the point is inside the fractal (bounded orbit).

**Data Structures:**
- $\mathbf{z}$: Current 3D point (float3).
- $\mathbf{p}_{in}$: Original query point (float3).
- $r, \theta, \phi$: Polar coordinates of $\mathbf{z}$ (float).

**Steps:**
1. Initialize $\mathbf{z} = \mathbf{p}_{in}$.
2. Calculate initial distance squared $z_{dist} = \|\mathbf{z}\|^2$.
3. Loop $i$ from $0$ to $N_{max}-1$:
    a. Convert $\mathbf{z}$ to spherical coordinates $(r, \theta, \phi)$.
    b. Apply power transformation:
       $$ r_{new} = r^P $$
       $$ \theta_{new} = \theta \times P $$
       $$ \phi_{new} = \phi \times P $$
    c. Convert back to Cartesian coordinates $\mathbf{z}_{new}$:
       $$ \mathbf{z}_{new}.x = r_{new} \sin(\theta_{new}) \cos(\phi_{new}) $$
       $$ \mathbf{z}_{new}.y = r_{new} \sin(\phi_{new}) \sin(\theta_{new}) $$
       $$ \mathbf{z}_{new}.z = r_{new} \cos(\theta_{new}) $$
    d. Update $\mathbf{z} = \mathbf{z}_{new} + \mathbf{p}_{in}$.
    e. Update $z_{dist} = \|\mathbf{z}\|^2$.
    f. If $z_{dist} > R_{max}$, break loop (escape).
4. If loop completes all $N_{max}$ iterations without escaping, the point is inside the fractal.

**Parameters:**
- $P = 8.0$ (default) [S1, unofficial].
- $N_{max} = 5$ (default) [S1, unofficial].
- $R_{max} = 20$ (default) [S1, unofficial].

**Pseudocode:**
```python
def mandelbulb(p_in, max_iterations=5, power=8.0, max_distance=20.0):
    z = p_in
    z_dist_sq = length_sq(z)
    
    for i in range(max_iterations):
        # Convert to spherical
        r = sqrt(z_dist_sq)
        theta = acos(z.z / r) if r > 0 else 0.0
        phi = atan2(z.y, z.x)
        
        # Power transformation
        r_new = pow(r, power)
        theta_new = theta * power
        phi_new = phi * power
        
        # Convert back to Cartesian
        z_new_x = r_new * sin(theta_new) * cos(phi_new)
        z_new_y = r_new * sin(phi_new) * sin(theta_new)
        z_new_z = r_new * cos(theta_new)
        
        # Add original point
        z.x = z_new_x + p_in.x
        z.y = z_new_y + p_in.y
        z.z = z_new_z + p_in.z
        
        z_dist_sq = length_sq(z)
        
        if z_dist_sq > max_distance:
            return False # Escaped
            
    return True # Inside
```

## Subtopics

### [Bristorbrot Fractal Generation](3328-bristorbrot-fractal-generation.md)
Generates a 3D fractal using a specific iterative polynomial mapping in Cartesian coordinates. It computes an escape-time field for voxel rendering by iterating a fixed 3D polynomial and checking against a distance threshold.

### [Menger Sponge Fractal Generation](3550-menger-sponge-fractal-generation.md)
Generates a 3D voxel grid or Signed Distance Field (SDF) representing a Menger sponge by iteratively dividing space into $3 \times 3 \times 3$ subcubes and removing those where two or more coordinates fall into the middle third. It differs from its parent [Mandelbulb Fractal Generation](3327-mandelbulb-fractal-generation.md), which uses polar coordinate power transformations, by relying on discrete coordinate modulo arithmetic and axis-aligned box subtraction.

### Quaternion Fractal Generation
A fractal distance function based on quaternion iteration, similar to Mandelbrot sets but in 3D [S2, unofficial].
**Steps:**
1. Initialize $v = \text{vec4}(p, 0.0)$ and $d = \text{vec4}(1.0, 0.0, 0.0, 0.0)$.
2. Loop $n$ from $1$ to $ITERATIONS-1$:
   Update $d = 2.0 \times \text{vec4}(v.x \cdot d.x - \text{dot}(v.xzw, d.yzw), v.x \cdot d.yzw + d.x \cdot v.yzw + \text{cross}(v.yzw, d.yzw))$.
   Update $v = \text{vec4}(v.x^2 - \text{dot}(v.yzw, v.yzw), \text{vec3}(2.0 \cdot v.x \cdot v.yzw)) + c$.
3. Check divergence: if $\text{dot}(v, v) > 10.0$, break loop.
**Formula:** Final distance: $0.5 \times r \times \log(r) / \|d\|$ where $r = \|v\|$.
**Parameters:** $ITERATIONS = 5$; $c = \text{vec4}(0.18, 0.88, 0.24, 0.16)$ [S2, unofficial].

## Operating characteristics
Time complexity is $O(N_{max})$ per voxel. Memory complexity is $O(1)$ per voxel evaluation. Performance scales linearly with iteration count. The method is computationally intensive due to trigonometric functions and power operations. It is suitable for static fractal generation but may be slow for real-time ray marching without optimization [S1, unofficial][S2, unofficial].

## Background
Originated from the holographic fractals project [S1, unofficial]. The Mandelbulb is a 3D analogue of the Mandelbrot set, constructed using polar coordinate transformations [S1, unofficial]. It is used in procedural geometry generation and voxel art [S1, unofficial].
