# Mandelbulb Fractal Generation

Also called: Mandelbulb

## Overview
Generates a 3D fractal by iteratively applying a polar coordinate power transformation to a 3D point [S1, unofficial]. It differs from its siblings, such as [Sine-based procedural voxel generation](2477-sine-based-procedural-voxel-generation.md) and [Spherical Density Ramp with Noise](2610-spherical-density-ramp-with-noise.md), by mapping coordinates through continuous spherical power functions rather than trigonometric sampling or radial ramps [S1, unofficial].

## How it works
**Inputs:** Query point $P = (x, y, z)$, maximum iteration count $N_{\text{max}}$, escape radius $R_{\text{max}}$, and power exponent $E$.
**Outputs:** Boolean indicating if the point is inside the fractal (does not escape) [S1, unofficial].

**Data Structures:**
*   `point3d`: A structure or tuple containing three floating-point fields: `x`, `y`, `z`.
*   `float`: Standard 32-bit or 64-bit floating-point number.

**Steps:**
1.  **Initialization:**
    *   Set current point $z = P$.
    *   Set initial distance $z_{\text{dist}} = \|z\| = \sqrt{x^2 + y^2 + z^2}$.
2.  **Iteration Loop:**
    For $i$ from $0$ to $N_{\text{max}} - 1$:
    *   **Convert to Polar Coordinates:**
        *   Calculate radius $r = z_{\text{dist}}$.
        *   Calculate polar angle $\theta = \arccos(z / r)$.
        *   Calculate azimuthal angle $\phi = \operatorname{atan2}(y, x)$. [G]
    *   **Apply Power Transformation:**
        *   Update radius: $r_{\text{new}} = r^E$.
        *   Update angles: $\theta_{\text{new}} = \theta \times E$, $\phi_{\text{new}} = \phi \times E$. [S1, unofficial]
    *   **Convert Back to Cartesian Coordinates:**
        *   $x_{\text{new}} = r_{\text{new}} \sin(\theta_{\text{new}}) \cos(\phi_{\text{new}})$
        *   $y_{\text{new}} = r_{\text{new}} \sin(\phi_{\text{new}}) \sin(\theta_{\text{new}})$
        *   $z_{\text{new}} = r_{\text{new}} \cos(\theta_{\text{new}})$ [S1, unofficial]
    *   **Update Point:**
        *   $z = (x_{\text{new}}, y_{\text{new}}, z_{\text{new}}) + P$ [S1, unofficial]
    *   **Update Distance & Escape Check:**
        *   $z_{\text{dist}} = \|z\|$.
        *   If $z_{\text{dist}} > R_{\text{max}}$, break loop [S1, unofficial].
3.  **Result:**
    *   If the loop completes all $N_{\text{max}}$ iterations without breaking, the point is inside the fractal [S1, unofficial].

**Parameters:**
*   $E = 8.0$ (Default power exponent [S1, unofficial]).
*   $N_{\text{max}} = 5$ (Default maximum iterations [S1, unofficial]).
*   $R_{\text{max}} = 20.0$ (Default escape radius [S1, unofficial]).

**Edge Cases and Pitfalls:**
*   **Singularity at Origin:** When $r=0$, $\theta$ is undefined. If $P=(0,0,0)$, iterations remain at the origin; a guard should return True or handle division by zero [G].
*   **Precision:** Floating-point precision limits the maximum useful iteration count. Higher powers $E$ cause faster divergence, requiring careful handling of large numbers [G].
*   **Boundary:** The escape radius $R_{\text{max}}$ determines the cutoff for "inside" vs "outside". Points with $\|z\| > R_{\text{max}}$ are outside [S1, unofficial].

**Pseudocode:**
```python
import math

def mandelbulb_iterate(p, power=8.0, max_iterations=5, max_distance=20.0):
    """
    Determines if point p is inside the Mandelbulb fractal using escape-time iteration.
    
    Args:
        p: tuple (x, y, z) representing the query point.
        power: The exponent E for the polar transformation.
        max_iterations: Maximum number of iterations N_max.
        max_distance: Escape radius R_max.
        
    Returns:
        bool: True if the point is inside (does not escape), False otherwise.
    """
    x, y, z = p
    z_dist = math.sqrt(x*x + y*y + z*z)
    
    for i in range(max_iterations):
        # Convert to spherical coordinates
        if z_dist == 0.0:
            # Singularity at origin; point stays at origin
            x_new, y_new, z_new = 0.0, 0.0, 0.0
        else:
            theta = math.acos(z / z_dist)
            phi = math.atan2(y, x)
            
            # Apply power transformation
            r_new = z_dist ** power
            theta_new = theta * power
            phi_new = phi * power
            
            # Convert back to Cartesian
            x_new = r_new * math.sin(theta_new) * math.cos(phi_new)
            y_new = r_new * math.sin(phi_new) * math.sin(theta_new)
            z_new = r_new * math.cos(theta_new)
            
        # Update z = new_p + p_in
        x = x_new + p[0]
        y = y_new + p[1]
        z = z_new + p[2]
        
        # Update distance and check escape
        z_dist = math.sqrt(x*x + y*y + z*z)
        if z_dist > max_distance:
            return False
            
    return True
```

## Subtopics

### [Bristorbrot Fractal Generation](3328-bristorbrot-fractal-generation.md)
Bristorbrot generates a 3D fractal using a specific iterative polynomial mapping in Cartesian coordinates. It computes an escape-time field for voxel rendering by iterating a fixed 3D polynomial and checking against a distance threshold.

### [Menger Sponge Fractal Generation](3550-menger-sponge-fractal-generation.md)
Generates a 3D voxel grid or Signed Distance Field (SDF) representing a Menger sponge by iteratively dividing space into $3 \times 3 \times 3$ subcubes and removing those where two or more coordinates fall into the middle third. It differs from its parent [Mandelbulb Fractal Generation](3327-mandelbulb-fractal-generation.md), which uses polar coordinate power transformations, by relying on discrete coordinate modulo arithmetic and axis-aligned box subtraction.

### Quaternion Fractal Generation
A fractal distance function based on quaternion iteration, similar to Mandelbrot sets but in 3D [S2, unofficial].
**Definition:** Uses quaternion algebra to iterate points in 4D space, projecting to 3D [S2, unofficial].
**Steps:**
1. Initialize $v = (p_x, p_y, p_z, 0.0)$ and derivative $d = (1.0, 0.0, 0.0, 0.0)$ [S2, unofficial].
2. Loop $n$ from $1$ to $ITERATIONS-1$:
   * Update derivative: $d = 2.0 \times (v_x d_x - \text{dot}(v_{yzw}, d_{yzw}), v_x d_{yzw} + d_x v_{yzw} + \text{cross}(v_{yzw}, d_{yzw}))$ [S2, unofficial].
   * Update value: $v = (v_x^2 - \text{dot}(v_{yzw}, v_{yzw}), 2.0 v_x v_{yzw}) + c$ [S2, unofficial].
3. Check divergence: If $\text{dot}(v, v) > 10.0$, break [S2, unofficial].
**Formula:** Final distance estimate: $0.5 \times r \times \log(r) / \|d\|$, where $r = \|v\|$ [S2, unofficial].
**Parameters:** $ITERATIONS = 5$, $c = (0.18, 0.88, 0.24, 0.16)$ [S2, unofficial].

## Operating characteristics
*   **Time Complexity:** $O(N_{\text{max}})$ per voxel, where $N_{\text{max}}$ is the maximum iteration count. Each iteration involves trigonometric functions and vector operations [S1, unofficial].
*   **Memory Complexity:** $O(1)$ auxiliary space per voxel query [G].
*   **Performance:** The use of trigonometric functions (`sin`, `cos`, `acos`, `atan2`) makes each iteration computationally expensive compared to polynomial-only fractals. Typical default parameters ($N_{\text{max}}=5, E=8$) are relatively fast, but increasing iterations or power significantly increases render time [S1, unofficial].
*   **Strengths:** Produces highly detailed, organic-looking 3D fractal structures with self-similarity [S1, unofficial].
*   **Limitations:** High computational cost per voxel. The escape radius and power parameter heavily influence the visual result and convergence speed [S1, unofficial].
*   **When to use:** When generating static 3D fractal models or high-quality offline renders [G].
*   **When not to use:** When real-time performance is critical and simpler noise functions suffice [G].

## Background
The Mandelbulb is a 3D fractal discovered in 2009 by Daniel Shapira and others, inspired by the 2D Mandelbrot set [G]. It extends the concept of complex number iteration to 3D using spherical coordinates [S1, unofficial]. The method described here follows the implementation details found in procedural fractal generation code [S1, unofficial]. It is used in computer graphics for generating complex, natural-looking 3D shapes and textures [S1, unofficial].
