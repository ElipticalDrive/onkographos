# Random Heightmap Terrain Generation
Also called: Random Terrain Grid

## Overview
Random Heightmap Terrain Generation creates a voxel terrain mesh by assigning independent, uniformly distributed random heights to vertices on a 2D grid [S1, unofficial].

## How it works
**Inputs:**
- `xWidth`: Width of the terrain grid in world units [S1, unofficial].
- `zWidth`: Depth of the terrain grid in world units [S1, unofficial].
- `xDetail`: Number of segments along the X axis [S1, unofficial].
- `zDetail`: Number of segments along the Z axis [S1, unofficial].
- `height`: Maximum absolute height of random vertices [S1, unofficial].

**Outputs:**
- A mesh defined by a list of faces. Each face is an object containing vertex indices `A`, `B`, `C` and normal components `NX`, `NY`, `NZ` [S1, unofficial].

**Data Structures:**
- `vertices`: An array of size $(xDetail + 1) \times (zDetail + 1)$ [S1, unofficial]. Each element stores the 3D coordinates $(x, y, z)$ of a vertex [G].
- `faces`: An array of face objects [S1, unofficial].

**Steps:**
1. Initialize the `vertices` array with size $(xDetail + 1) \times (zDetail + 1)$ [S1, unofficial].
2. Iterate over grid indices $i_Z$ from $0$ to $zDetail$ and $i_X$ from $0$ to $xDetail$ [S1, unofficial].
3. Calculate the linear index `currIndex` for the current vertex: $\text{currIndex} = (i_Z \times xVerts) + i_X$, where $xVerts = xDetail + 1$ [S1, unofficial].
4. Calculate the world coordinates for the vertex [S1, unofficial]:
   $$ \text{tempX} = \left(\frac{i_X}{xDetail}\right) \times xWidth - \frac{xWidth}{2} $$
   $$ \text{tempZ} = \left(\frac{i_Z}{zDetail}\right) \times zWidth - \frac{zWidth}{2} $$
   $$ \text{tempY} = \text{height} \times (2 \times (\text{Math.random()} - 0.5)) $$
   Store the vertex at `vertices[currIndex]` with coordinates $(\text{tempX}, \text{tempY}, \text{tempZ})$ [S1, unofficial].
5. Iterate over grid cells $i_Z$ from $0$ to $zDetail-1$ and $i_X$ from $0$ to $xDetail-1$ [S1, unofficial].
6. For each cell, identify the four corner vertices using the current `currIndex` (calculated as in Step 3 for the top-left corner of the cell) [S1, unofficial]:
   - Upper triangle vertices: $A = \text{currIndex}$, $B = \text{currIndex} + 1$, $C = \text{currIndex} + xVerts + 1$ [S1, unofficial].
   - Lower triangle vertices: $A = \text{currIndex}$, $B = \text{currIndex} + xVerts$, $C = \text{currIndex} + xVerts + 1$ [S1, unofficial].
7. Compute the face normal for each triangle using the cross product of edge vectors $\vec{U}$ and $\vec{V}$ [S1, unofficial]. For a triangle with vertices $A, B, C$:
   $$ \vec{U} = \text{vertices}[B] - \text{vertices}[A] $$
   $$ \vec{V} = \text{vertices}[C] - \text{vertices}[A] $$
   $$ \vec{N} = \vec{U} \times \vec{V} $$
   Normalize $\vec{N}$ to get $(NX, NY, NZ)$ [G].
8. Store the face data (indices $A, B, C$ and normal $NX, NY, NZ$) in the `faces` array [S1, unofficial].

**Pseudocode:**
```python
import random as _random

class Vector3:
    def __init__(self, x, y, z): self.x, self.y, self.z = x, y, z
    def __sub__(self, other): return Vector3(self.x - other.x, self.y - other.y, self.z - other.z)

def cross(u, v): return Vector3(u.y*v.z - u.z*v.y, u.z*v.x - u.x*v.z, u.x*v.y - u.y*v.x)

def normalize(v):
    mag = (v.x**2 + v.y**2 + v.z**2)**0.5
    return Vector3(v.x/mag, v.y/mag, v.z/mag) if mag > 0 else Vector3(0, 0, 0)

def generate_random_heightmap(xWidth, zWidth, xDetail, zDetail, height):
    xVerts = xDetail + 1
    zVerts = zDetail + 1
    vertices = [None] * (xVerts * zVerts)

    for iZ in range(zVerts):
        for iX in range(xVerts):
            currIndex = (iZ * xVerts) + iX
            tempX = (iX / xDetail) * xWidth - (xWidth / 2)
            tempZ = (iZ / zDetail) * zWidth - (zWidth / 2)
            tempY = height * (2 * (_random.random() - 0.5))
            vertices[currIndex] = Vector3(tempX, tempY, tempZ)

    faces = []
    for iZ in range(zDetail):
        for iX in range(xDetail):
            currIndex = (iZ * xVerts) + iX

            # Upper triangle
            A = vertices[currIndex]
            B = vertices[currIndex + 1]
            C = vertices[currIndex + xVerts + 1]
            U1 = B - A
            V1 = C - A
            N1 = cross(U1, V1)
            N1 = normalize(N1)
            faces.append({'A': currIndex, 'B': currIndex + 1, 'C': currIndex + xVerts + 1, 'NX': N1.x, 'NY': N1.y, 'NZ': N1.z})

            # Lower triangle
            A2 = vertices[currIndex]
            B2 = vertices[currIndex + xVerts]
            C2 = vertices[currIndex + xVerts + 1]
            U2 = B2 - A2
            V2 = C2 - A2
            N2 = cross(U2, V2)
            N2 = normalize(N2)
            faces.append({'A': currIndex, 'B': currIndex + xVerts, 'C': currIndex + xVerts + 1, 'NX': N2.x, 'NY': N2.y, 'NZ': N2.z})

    return faces
```

**Parameters:**
- `xWidth`, `zWidth`: Define the physical extent of the terrain [S1, unofficial].
- `xDetail`, `zDetail`: Control the resolution (grid density) [S1, unofficial].
- `height`: Controls the vertical amplitude of the noise [S1, unofficial].

**Edge Cases:**
- `xDetail` or `zDetail` equal to 0 results in no faces [G].
- `height` equal to 0 results in a flat plane [G].
- Random number generator seeding is not specified in the source, but reproducibility requires it [G].

## Subtopics

### [Midpoint Displacement Fractal](16935-midpoint-displacement-fractal.md)
Generates a 2D noise grid using recursive midpoint displacement to create a fractal terrain or noise map. It differs from its parent, Random Heightmap Terrain Generation, by imposing spatial correlation through recursive averaging and roughening, rather than assigning independent random heights to all vertices. This method is chosen when a continuous, fractal-like heightmap is required for procedural voxel generation.
