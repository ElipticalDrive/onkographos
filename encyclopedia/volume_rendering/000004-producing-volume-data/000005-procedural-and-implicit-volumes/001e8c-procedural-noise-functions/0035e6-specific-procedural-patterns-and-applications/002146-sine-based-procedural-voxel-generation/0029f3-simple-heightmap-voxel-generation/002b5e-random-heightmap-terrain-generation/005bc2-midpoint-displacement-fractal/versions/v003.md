# Midpoint Displacement Fractal

Also called: Mid-point Displacement, Plasma fractal grid generation, Stochastic subdivision

## Overview
Midpoint Displacement Fractal generates a 2D noise grid using recursive midpoint displacement to create a fractal terrain or noise map [S2, unofficial]. It differs from its parent, Random Heightmap Terrain Generation, by imposing spatial correlation through recursive averaging and roughening, rather than assigning independent random heights to all vertices [S1, unofficial].

## How it works
**Inputs:**
- `width` (int): Width of the output grid [S2, unofficial].
- `height` (int): Height of the output grid [S2, unofficial].
- `roughness` (float): Controls fractal roughness [S2, unofficial].

**Outputs:**
- `grid_`: A 2D float array of size `[width][height]` containing the generated height values [S2, unofficial].

**Data Structures:**
- `grid_[width][height]`: Stores the height value for each cell [S2, unofficial].
- `roughness_`: Internal parameter, calculated as `roughness / width` [S2, unofficial].

**Algorithm Steps:**

1.  **Initialization**:
    - Calculate `roughness_ = roughness / width` [S2, unofficial].
    - Allocate `grid_[width][height]` [S2, unofficial].
    - Set the random number generator seed [S2, unofficial].
    - Set the four corner points to random values in the range `[-0.5, 0.5]`:
      - `grid_[0][0]`
      - `grid_[0][height-1]`
      - `grid_[width-1][0]`
      - `grid_[width-1][height-1]`
    - Call `generate(0, 0, width-1, height-1)` [S2, unofficial].

2.  **Recursive Generation (`generate(xl, yl, xh, yh)`)**:
    - Compute midpoints:
      - `xm = (xl + xh) / 2`
      - `ym = (yl + yh) / 2`
    - **Base Case**: If `xl == xm` and `yl == ym`, return [S2, unofficial].
    - **Edge Midpoints**: Compute the unroughened midpoints of the four edges by averaging the adjacent corners:
      - `grid_[xm][yl] = 0.5 * (grid_[xl][yl] + grid_[xh][yl])` [S2, unofficial]
      - `grid_[xm][yh] = 0.5 * (grid_[xl][yh] + grid_[xh][yh])` [S2, unofficial]
      - `grid_[xl][ym] = 0.5 * (grid_[xl][yl] + grid_[xl][yh])` [S2, unofficial]
      - `grid_[xh][ym] = 0.5 * (grid_[xh][yl] + grid_[xh][yh])` [S2, unofficial]
    - **Center Point**: Compute the center point by averaging the two horizontal edge midpoints:
      - `center_val = 0.5 * (grid_[xm][yl] + grid_[xm][yh])` [S2, unofficial]
      - Roughen the center value and assign it to `grid_[xm][ym]` [S2, unofficial].
    - **Roughen Edges**: Roughen the four edge midpoints using `roughen()` with appropriate span parameters:
      - `grid_[xm][yl] = roughen(grid_[xm][yl], xl, xh)` [S2, unofficial]
      - `grid_[xm][yh] = roughen(grid_[xm][yh], xl, xh)` [S2, unofficial]
      - `grid_[xl][ym] = roughen(grid_[xl][ym], yl, yh)` [S2, unofficial]
      - `grid_[xh][ym] = roughen(grid_[xh][ym], yl, yh)` [S2, unofficial]
    - **Recurse**: Call `generate()` on the four sub-quadrants:
      - `generate(xl, yl, xm, ym)`
      - `generate(xm, yl, xh, ym)`
      - `generate(xl, ym, xm, yh)`
      - `generate(xm, ym, xh, yh)`

3.  **Roughening Function (`roughen(v, l, h)`)**:
    - Generate Gaussian noise `n` with mean 0 and standard deviation proportional to the span `(h - l)` and `roughness_` [S2, unofficial].
    - Return `v + n` [S2, unofficial].

**Pseudocode:**

```python
import random

class MidpointDisplacement:
    def __init__(self, width, height, roughness):
        self.width = width
        self.height = height
        self.roughness_ = roughness / width
        self.grid = [[0.0 for _ in range(height)] for _ in range(width)]
        self._initialize()

    def _initialize(self):
        self.grid[0][0] = random.uniform(-0.5, 0.5)
        self.grid[0][self.height - 1] = random.uniform(-0.5, 0.5)
        self.grid[self.width - 1][0] = random.uniform(-0.5, 0.5)
        self.grid[self.width - 1][self.height - 1] = random.uniform(-0.5, 0.5)
        self._generate(0, 0, self.width - 1, self.height - 1)

    def _generate(self, xl, yl, xh, yh):
        xm = (xl + xh) // 2
        ym = (yl + yh) // 2
        if xl == xm and yl == ym:
            return
        self.grid[xm][yl] = 0.5 * (self.grid[xl][yl] + self.grid[xh][yl])
        self.grid[xm][yh] = 0.5 * (self.grid[xl][yh] + self.grid[xh][yh])
        self.grid[xl][ym] = 0.5 * (self.grid[xl][yl] + self.grid[xl][yh])
        self.grid[xh][ym] = 0.5 * (self.grid[xh][yl] + self.grid[xh][yh])
        center_val = 0.5 * (self.grid[xm][yl] + self.grid[xm][yh])
        self.grid[xm][ym] = self._roughen(center_val, xl, xh)
        self.grid[xm][yl] = self._roughen(self.grid[xm][yl], xl, xh)
        self.grid[xm][yh] = self._roughen(self.grid[xm][yh], xl, xh)
        self.grid[xl][ym] = self._roughen(self.grid[xl][ym], yl, yh)
        self.grid[xh][ym] = self._roughen(self.grid[xh][ym], yl, yh)
        self._generate(xl, yl, xm, ym)
        self._generate(xm, yl, xh, ym)
        self._generate(xl, ym, xm, yh)
        self._generate(xm, ym, xh, yh)

    def _roughen(self, v, l, h):
        span = h - l
        noise = random.gauss(0, span * self.roughness_)
        return v + noise
```

**Parameters:**
- `roughness`: Float controlling fractal roughness [S2, unofficial].
- `width`, `height`: Integers defining the grid dimensions [S2, unofficial].

**Edge Cases and Pitfalls:**
- Produces directional artifacts and requires a known fixed-size domain, making it unsuitable for random-access batch generation or parallel processing without visible seams [S1, unofficial].

## Subtopics

### [Diamond-Square Algorithm (Chunk-based Midpoint Displacement)](21580-diamond-square-algorithm-chunk-based-midpoint-displacement.md)
The Diamond-Square Algorithm is a procedural world generation method that recursively subdivides a 2D grid into squares and diamonds to compute new cell values as the average of surrounding cells plus a scaled random perturbation. It operates asynchronously on chunks to generate a continuous, infinite world model, distinguishing itself from standard implementations by its spatial partitioning and lazy evaluation strategy.

## Operating characteristics
Subdivision based methods are obviously very simple and fast compared to noise functions [S1, unofficial]. Intermediate values have to be held in memory during computation [S1, unofficial]. Exact performance metrics are not given in the sources [S1, unofficial].

## Background
The method was introduced by Fournier et al. in 1982 [S3]. It was generalized by Lewis to arbitrary autocorrelation functions [S3]. It is used in a simple voxel framework for rendering cubes in jMonkeyEngine 3 [S2, unofficial].
