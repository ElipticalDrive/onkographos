# Chunk Noise Generation

Also called: NoiseJob

## Overview
Chunk Noise Generation is a procedural noise generation method that computes a 3D density field using layered Perlin noise with surface constraints, executed in parallel jobs [S1, unofficial]. It differs from standard gradient-based noise by incorporating a 2D surface noise check to constrain the 3D volume generation to specific height-based regions, effectively creating terrain-like or cloud-like density masks [S1, unofficial].

## How it works
**Inputs and Outputs**
*   **Input**: A `NoiseJob` struct containing parameters for noise generation, including `surfaceLevel`, `offset` (float3), `seed` (float3), `ampl` (float), `freq` (float), `oct` (int), and `size` (int).
*   **Output**: A `WriteOnly NativeArray<float>` named `noiseMap` containing the computed density values [S1, unofficial].

**Data Structures**
The `NoiseJob` struct layout is defined as follows [S1, unofficial]:
*   `surfaceLevel`: `float`
*   `offset`: `float3`
*   `seed`: `float3`
*   `ampl`: `float`
*   `freq`: `float`
*   `oct`: `int`
*   `noiseMap`: `WriteOnly NativeArray<float>`
*   `size`: `int`

**Algorithm Steps**
The generation process evaluates each voxel position `pos` in parallel. The core logic involves three noise functions: `SurfaceNoise2D`, `PerlinNoise3D`, and `PerlinNoise3DSnake`.

1.  **Surface Constraint Check**: Evaluate two 2D noise functions at the horizontal position `(pos.x, pos.z)`.
    *   Condition A: `SurfaceNoise2D(pos.x, pos.z) > pos.y + offset.y - surfaceLevel`
    *   Condition B: `SurfaceNoise2D(pos.x + seed.x, pos.z + seed.z) > -pos.y - offset.y - surfaceLevel`
    *   If both conditions are true, initialize `value = 1.0f - PerlinNoise3D(pos)`.
    *   If the resulting `value < 1.0f`, add `PerlinNoise3DSnake(pos)` to `value`.
    *   Finally, negate `value` to produce the final density.
    *   If conditions are not met, the density is implicitly 0 (or handled by the parallel job's default initialization, though the source implies the `value` variable is the result of this conditional block) [S1, unofficial].

2.  **PerlinNoise3D Evaluation**:
    *   Initialize `total = 0`.
    *   Loop `i` from 0 to `oct - 1`:
        *   Calculate scaled coordinates:
            $$ x' = (x + offset.x + seed.x) \times freq $$
            $$ y' = (y + offset.y + seed.y) \times freq $$
            $$ z' = (z + offset.z + seed.z) \times freq $$
        *   Add the noise contribution:
            $$ total \leftarrow total + noise.snoise(float3(x', y', z')) \times ampl $$
        *   Update parameters for the next octave:
            $$ ampl \leftarrow ampl \times 2 $$
            $$ freq \leftarrow freq \times 0.5 $$
    *   After the loop, subtract the modulo:
        $$ total \leftarrow total - (total \pmod{2.5}) $$
    *   Return `total` [S1, unofficial].

3.  **PerlinNoise3DSnake Evaluation**:
    *   Identical to `PerlinNoise3D`, but the initial `freq` is set to `this.freq + 0.03f` [S1, unofficial].

4.  **SurfaceNoise2D Evaluation**:
    *   Initialize `total = 0`.
    *   Loop `i` from 0 to `oct - 1`:
        *   Calculate scaled coordinates:
            $$ x' = (x + offset.x + seed.x) \times freq $$
            $$ z' = (z + offset.z + seed.z) \times freq $$
        *   Add the noise contribution:
            $$ total \leftarrow total + noise.snoise(float2(x', z')) \times ampl $$
        *   Update parameters for the next octave:
            $$ ampl \leftarrow ampl \times 2 $$
            $$ freq \leftarrow freq \times 0.5 $$
    *   After the loop, return `total % 5` [S1, unofficial].

**Pseudocode**

def surface_noise_2d(x, z, offset, seed, ampl, freq, oct):
    total = 0.0
    for i in range(oct):
        x_scaled = (x + offset.x + seed.x) * freq
        z_scaled = (z + offset.z + seed.z) * freq
        total += noise_snoise_float2(x_scaled, z_scaled) * ampl
        ampl *= 2.0
        freq *= 0.5
    return total % 5.0

def perlin_noise_3d(x, y, z, offset, seed, ampl, freq, oct):
    total = 0.0
    for i in range(oct):
        x_scaled = (x + offset.x + seed.x) * freq
        y_scaled = (y + offset.y + seed.y) * freq
        z_scaled = (z + offset.z + seed.z) * freq
        total += noise_snoise_float3(x_scaled, y_scaled, z_scaled) * ampl
        ampl *= 2.0
        freq *= 0.5
    return total - (total % 2.5)

    # job contains surfaceLevel, offset, seed, ampl, freq, oct

    s2 = surface_noise_2d(pos.x + job.seed.x, pos.z + job.seed.z, job.offset, job.seed, job.ampl, job.freq, job.oct)
    
    threshold1 = pos.y + job.offset.y - job.surfaceLevel
    threshold2 = -pos.y - job.offset.y - job.surfaceLevel

**Parameters**
*   `oct`: Number of octaves for noise fractal summation. Typical value not specified in sources [S1, unofficial].
*   `ampl`: Amplitude multiplier for noise. Doubles each octave [S1, unofficial].
*   `freq`: Frequency multiplier for noise. Halves each octave [S1, unofficial].

**Edge Cases and Pitfalls**
*   The modulo operations (`% 2.5` and `% 5`) are non-standard for noise functions and may introduce discontinuities or unexpected value ranges if not handled carefully [S1, unofficial].
*   The surface constraint logic relies on specific comparisons between 2D noise and the Y-coordinate, which may require tuning `surfaceLevel` and `offset` for desired density shapes [S1, unofficial].

## Operating characteristics
*   **Time Complexity**: Linear with respect to the number of voxels $N$ and the number of octaves $O$. Each voxel requires $O(O)$ noise evaluations.
*   **Memory Complexity**: $O(N)$ for the output `noiseMap`.
*   **Performance**: Executed in parallel jobs, suitable for GPU or multi-threaded CPU execution.
*   **Strengths**: Efficiently generates constrained 3D noise fields suitable for terrain or cloud masking.
*   **Limitations**: The specific modulo operations and surface constraint logic are non-standard and may not generalize to other noise applications without modification.

## Background
Chunk Noise Generation originates from the "Fast-Unity-Marching-Cubes" project, an unofficial implementation for procedural terrain generation in Unity [S1, unofficial]. It is designed to work with marching cubes algorithms to extract meshes from voxel data.
