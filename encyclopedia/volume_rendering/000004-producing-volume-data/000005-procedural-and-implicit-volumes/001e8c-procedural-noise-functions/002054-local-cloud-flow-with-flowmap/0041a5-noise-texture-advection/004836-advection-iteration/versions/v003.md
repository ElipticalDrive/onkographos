# Advection Iteration

Also called: LIC-like Advection

## Overview
Advection Iteration is a GPU-based technique for visualizing tensor fields by iteratively advecting a noise texture along eigenvector directions [S1, unofficial]. It solves the problem of generating coherent flow-like structures from static tensor data by leveraging the depth buffer for edge detection, thereby avoiding the overhead of separate depth textures [S1, unofficial]. Unlike its parent method, Noise Texture Advection, which uses simple Euler integration, this method specifically handles the lack of orientation in eigenvectors by sampling in both forward and backward directions and averaging the results [S1, unofficial].

## How it works
The method operates in two phases: a CPU-controlled loop that manages texture ping-ponging and a GPU shader that performs the per-pixel advection logic [S1, unofficial].

### Inputs and Outputs
**Inputs:**
*   `edgeTexture`: Output from the silhouette detection step [S1, unofficial].
    *   Channel G: Depth value [S1, unofficial].
    *   Channel R: Edge intensity [S1, unofficial].
    *   Channel B: Original noise value [S1, unofficial].
*   `eigenvectorColormap`: Output from the projection step [S1, unofficial].
    *   Channels R, G: First eigenvector ($ev_1$) components [S1, unofficial].
    *   Channels B, A: Second eigenvector ($ev_2$) components [S1, unofficial].
*   `advectionInput`: Texture from the previous iteration (or initial noise) [S1, unofficial].
    *   Channel R: Advected noise for $ev_1$ [S1, unofficial].
    *   Channel G: Advected noise for $ev_2$ [S1, unofficial].

**Outputs:**
*   `advectionOutput`: Texture for the current iteration [S1, unofficial].
    *   Channel R: Final advected noise for $ev_1$ [S1, unofficial].
    *   Channel G: Final advected noise for $ev_2$ [S1, unofficial].
    *   Channel B: Unused (0.0) [S1, unofficial].
    *   Channel A: 1.0 [S1, unofficial].

### Data Structures and Layout
The implementation uses a ping-pong buffer strategy with two textures, `advection1` and `advection2`, to alternate between input and output roles [S1, unofficial].
*   **edgeTexture**: `RGBA` texture [S1, unofficial]. `G` stores depth, `R` stores edge intensity, `B` stores original noise [S1, unofficial].
*   **eigenvectorColormap**: `RGBA` texture [S1, unofficial]. `(R, G)` stores $ev_1$, `(B, A)` stores $ev_2$ [S1, unofficial]. Values are stored in $[0, 1]$ range [S1, unofficial].
*   **advectionInput/Output**: `RGBA` textures [S1, unofficial]. `R` stores $ev_1$ noise, `G` stores $ev_2$ noise [S1, unofficial].

### Parameters
*   `MAX`: Maximum number of advection iterations per frame [S1, unofficial].
*   `k`: Ratio parameter from Definition 4.9, controlling the blend between advected noise and original noise [S1, unofficial].
*   `edgeBlend`: Constant defining the edge intensity contribution during advection [S1, unofficial].
*   `s`: Step size used for sampling positions along eigenvectors [S1, unofficial].

### Algorithm Steps

#### CPU Initialization
1.  Bind `edgeTexture` and `eigenvectorColormap` [S1, unofficial].
2.  Create two textures: `advection1` and `advection2` for ping-ponging [S1, unofficial].
3.  Set `advectionInput` to the initial noise texture (e.g., `reactionDiffusionTexture`) [S1, unofficial].

#### CPU Loop
Iterate $i$ from 1 to `MAX`:
1.  Bind `advectionInput` as the input texture [S1, unofficial].
2.  Determine the output texture based on the iteration parity:
    *   If $i$ is even: Set `advection1` as the output texture [S1, unofficial].
    *   Update `advectionInput` to `advection1` for the next iteration [S1, unofficial].
    *   If $i$ is odd: Set `advection2` as the output texture [S1, unofficial].
    *   Update `advectionInput` to `advection2` for the next iteration [S1, unofficial].
3.  Render a full-screen quad to the Framebuffer Object (FBO) associated with the selected output texture [S1, unofficial].

**Note:** If the iteration is broken early for framerate reasons, the textures and framebuffer objects must not be destroyed at the end of the frame to allow continuation in the next frame [S1, unofficial].

#### GPU Shader (Per Pixel)
For each pixel at texture coordinate $t$:

1.  **Data Extraction**:
    *   Extract depth: $d = \text{edgeTexture}[t].G$ [S1, unofficial].
    *   Extract edge intensity: $e = \text{edgeTexture}[t].R$ [S1, unofficial].
    *   Extract tensor eigenvectors: $V = \text{eigenvectorColormap}[t].RGBA$ [S1, unofficial].

2.  **Vector Unscaling**:
    Unscale tensor values from $[0, 1]$ to $[-1, 1]$:
    $$ V' = (V - 0.5) \times 2.0 $$ [S1, unofficial].

3.  **Vector Scaling to Texture Space**:
    Scale eigenvectors to texture space coordinates [S1, unofficial]. Let $W$ be texture width and $H$ be texture height [S1, unofficial].
    $$ ev_1 = \left( \frac{V'.R}{W}, \frac{V'.G}{H} \right) $$ [S1, unofficial].
    $$ ev_2 = \left( \frac{V'.B}{W}, \frac{V'.A}{H} \right) $$ [S1, unofficial].

4.  **Discard Check**:
    If `discardable(d, ev_1, ev_2)` returns true, output black $(0, 0, 0, 1)$ and terminate [S1, unofficial].
    *   `discardable` checks if both directions and anti-directions of $ev_1$ and $ev_2$ point to fragments without geometry using the depth buffer [S1, unofficial].

5.  **Position Calculation**:
    Calculate forward and backward sample positions for both eigenvectors [S1, unofficial]. Since eigenvectors lack orientation, advection occurs in both directions [S1, unofficial].
    $$ a_1 = t - s \cdot ev_1 $$ [S1, unofficial].
    $$ a_2 = t - s \cdot ev_2 $$ [S1, unofficial].
    $$ a_{1n} = t + s \cdot ev_1 $$ [S1, unofficial].
    $$ a_{2n} = t + s \cdot ev_2 $$ [S1, unofficial].

6.  **Noise Sampling**:
    Sample `advectionInput` at the calculated positions [S1, unofficial]. Average the forward and backward samples for each eigenvector [S1, unofficial].
    $$ \text{aNoise}_1 = 0.5 \times (\text{advectionInput}[a_1].R + \text{advectionInput}[a_{1n}].R) $$ [S1, unofficial].
    $$ \text{aNoise}_2 = 0.5 \times (\text{advectionInput}[a_2].G + \text{advectionInput}[a_{2n}].G) $$ [S1, unofficial].

7.  **Final Output**:
    Blend the averaged advected noise with the original noise (weighted by $k$) and add the edge contribution (weighted by `edgeBlend`) [S1, unofficial].
    $$ \text{out} = \begin{pmatrix} \text{aNoise}_1 \\ \text{aNoise}_2 \\ 0.0 \\ 1.0 \end{pmatrix} (1.0 - k) + \begin{pmatrix} \text{noise} \\ \text{noise} \\ \text{noise} \\ 1.0 \end{pmatrix} k + \begin{pmatrix} e \\ e \\ e \\ 1.0 \end{pmatrix} \text{edgeBlend} $$ [S1, unofficial].
    Where $\text{noise} = \text{edgeTexture}[t].B$ [S1, unofficial].

### Pseudocode
```python
def init_advection():
    edge_texture = allocate_texture()
    eigenvector_colormap = allocate_texture()
    advection1 = allocate_texture()
    advection2 = allocate_texture()
    advection_input = allocate_texture() # Populated with reactionDiffusionTexture
    return edge_texture, eigenvector_colormap, advection1, advection2, advection_input

def run_advection_loop(edge_texture, eigenvector_colormap, advection1, advection2, advection_input, MAX, s, k, edge_blend, width, height):
    current_input = advection_input
    for i in range(1, MAX + 1):
        bind_texture(current_input)
        if i % 2 == 0:
            output_texture = advection1
            next_input = advection1
        else:
            output_texture = advection2
            next_input = advection2
        render_quad_offscreen(output_texture, edge_texture, eigenvector_colormap, current_input, s, k, edge_blend, width, height)
        current_input = next_input
    return current_input

def render_quad_offscreen(output, edge_tex, eig_vec, adv_in, s, k, edge_blend, w, h):
    for y in range(output.height):
        for x in range(output.width):
            t = vec2(x / w, y / h)
            output[x, y] = advect_iteration_shader(t, edge_tex, eig_vec, adv_in, s, k, edge_blend, w, h)

def advect_iteration_shader(t, edge_tex, eig_vec, adv_in, s, k, edge_blend, w, h):
    depth = edge_tex[t].G
    edge = edge_tex[t].R
    tensor = eig_vec[t].RGBA
    tensor_unscaled = (tensor - vec4(0.5)) * 2.0
    ev1 = vec2(tensor_unscaled.R / w, tensor_unscaled.G / h)
    ev2 = vec2(tensor_unscaled.B / w, tensor_unscaled.A / h)
    if discardable(depth, ev1, ev2):
        return vec4(0.0, 0.0, 0.0, 1.0)
    a1 = t - s * ev1
    a2 = t - s * ev2
    a1n = t + s * ev1
    a2n = t + s * ev2
    aNoise1 = 0.5 * (adv_in[a1].R + adv_in[a1n].R)
    aNoise2 = 0.5 * (adv_in[a2].G + adv_in[a2n].G)
    noise = edge_tex[t].B
    out_r = aNoise1 * (1.0 - k) + noise * k + edge * edge_blend
    out_g = aNoise2 * (1.0 - k) + noise * k + edge * edge_blend
    out_b = noise * k + edge * edge_blend
    out_a = 1.0 + edge_blend
    return vec4(out_r, out_g, out_b, out_a)

# discardable(depth, ev1, ev2): Checks if both directions and anti-directions point to fragments without geometry using the depth buffer [G]. Sources do not provide implementation.
```

### Edge Cases and Pitfalls
*   **Texture Management**: When breaking iteration early for framerate, textures and framebuffer objects must not be destroyed at the end of each frame to allow continuation in the next frame [S1, unofficial].
*   **Input Binding Count**: Due to data merging in the prior step, only three input texture bindings are needed per iteration (depth/edge, eigenvector colormap, previous advection output) instead of four [S1, unofficial].
*   **Eigenvector Orientation**: Eigenvectors lack orientation [S1, unofficial]. The method must sample in both forward and backward directions and average the results to avoid directional bias [S1, unofficial].

## Operating characteristics
*   **Time Complexity**: Linear with respect to the number of iterations `MAX` and the number of pixels [S1, unofficial]. Each iteration involves a constant number of texture lookups and arithmetic operations per pixel [S1, unofficial].
*   **Memory Complexity**: Requires storage for two ping-pong textures (`advection1`, `advection2`) plus the input textures (`edgeTexture`, `eigenvectorColormap`) [S1, unofficial].
*   **Performance**: Allows breaking iteration after a fixed number of passes to ensure higher framerates and a smoother user experience [S1, unofficial].
*   **Strengths**: Avoids separate depth texture overhead by using the depth buffer directly for edge detection [S1, unofficial]. Efficiently handles tensor field visualization without complex geometry mapping for near-planar geometry [S1, unofficial].
*   **Limitations**: Dependent on the quality of the eigenvector colormap and silhouette detection [S1, unofficial]. The step size `s` must be chosen carefully to balance coherence and detail [S1, unofficial].

## Background
Advection Iteration is described in the context of image-space tensor field visualization using a LIC-like (Line Integral Convolution) method [S1, unofficial]. It is part of a pipeline that includes silhouette detection, projection, and advection [S1, unofficial]. The method was introduced in the paper "Image-Space Tensor Field Visualization Using a LIC-like Method" [S1, unofficial].
