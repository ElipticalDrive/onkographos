# Sawtooth Replication Function
Also called: FRep Cellular Structure Replication
## Overview
The Sawtooth Replication Function is a basic periodic replication function used to generate infinite cellular structures from a unit cell defined by a continuous real function [S1]. It is the fundamental component of the Periodic Cellular Structure Replication method [19927-periodic-cellular-structure-replication.md]. Unlike its sibling, the Triangle Wave Replication Function, the Sawtooth function typically results in C0-discontinuous functions on cell faces unless the unit cell possesses full connectivity [S1].
## How it works
The method maps a continuous input coordinate $t$ to a periodic value within a specific range, creating a sawtooth wave pattern that repeats every period $a$.

**Inputs and Outputs:**
- Input: A real-valued coordinate $t$.
- Output: A real-valued periodic coordinate $g(t)$.

**Parameters:**
- $a$: The period of the sawtooth wave. Typical values depend on the desired cell size, but the source does not specify a default [S1].

**Data Structures:**
- No complex data structures are required; the function is stateless and computed per-vertex or per-pixel.

**Formula:**
The replication function $g(t)$ is defined as:
$$g(t) = \frac{1}{2} + \frac{1}{a} \left( t - \text{floor}\left(\frac{t}{a} + \frac{1}{2}\right) \right)$$
where $\text{floor}(x)$ returns the greatest integer less than or equal to $x$ [S1].

**Steps:**
1. Calculate the shifted normalized position: $u = \frac{t}{a} + \frac{1}{2}$.
2. Compute the integer part: $k = \text{floor}(u)$.
3. Compute the fractional remainder: $r = t - k \cdot a$.
4. Add the offset: $g(t) = \frac{1}{2} + \frac{r}{a}$.

**Pseudocode:**
```python
def sawtooth_replication(t: float, a: float) -> float:
    """
    Computes the sawtooth replication function value.
    
    Args:
        t: Input coordinate.
        a: Period of the sawtooth wave.
        
    Returns:
        The replicated coordinate value.
    """
    # Calculate the term inside the floor function
    shifted = t / a + 0.5
    
    # Compute floor of the shifted value
    k = floor(shifted)
    
    # Compute the remainder relative to the period
    remainder = t - k * a
    
    # Apply the formula: 1/2 + remainder / a
    result = 0.5 + remainder / a
    
    return result
```

**Edge Cases and Pitfalls:**
- **Discontinuity:** Due to the nature of the sawtooth function, the resulting cellular model has geometric discontinuity on the faces of the cells if the unit cell has no connectivity property [S1].
- **C0 Discontinuity:** Even if the unit cell has geometric connectivity, the resulting function can be C0-discontinuous on the faces of each cell [S1]. Full unit cell connectivity is required to obtain C0-continuous functions [S1].
- **Precision:** The use of `floor` can introduce precision issues near boundaries where $t/a + 1/2$ is an integer. Standard floating-point arithmetic should be used, but care must be taken with boundary conditions in high-precision rendering [G].

## Subtopics

### Triangle Wave Replication Function
A replication function used to obtain C1-continuous functions for unit cells symmetric with respect to planes parallel to faces and passing through their center [S1]. It is chosen when higher continuity is required compared to the basic sawtooth function. The formula is:
$$g(t) = 1 + \frac{2}{\pi} \arcsin[\sin(\pi(t - \frac{1}{2}))]$$
[S1]

## Operating characteristics
- **Time Complexity:** O(1) per evaluation, involving basic arithmetic operations and a floor function.
- **Memory Complexity:** O(1), as no storage is required.
- **Strengths:** Simple to implement; provides a basis for generating infinite periodic structures [S1].
- **Limitations:** Results in C0-discontinuities on cell faces unless specific connectivity conditions are met [S1]. Less smooth than the Triangle Wave variant [S1].
- **When to use:** When generating basic cellular structures where C0 continuity is acceptable or when full connectivity is present [S1].
- **When not to use:** When C1 continuity is required or when the unit cell lacks connectivity [S1].
## Background
The Sawtooth Replication Function is described in the context of procedural function-based modelling of volumetric microstructures [S1]. It is part of a family of replication functions used to create infinite cellular structures by applying periodic replication to a unit cell [S1]. The approach allows for the creation of complex geometries that are infinite in space and can be combined with arbitrary geometric objects [S1].
