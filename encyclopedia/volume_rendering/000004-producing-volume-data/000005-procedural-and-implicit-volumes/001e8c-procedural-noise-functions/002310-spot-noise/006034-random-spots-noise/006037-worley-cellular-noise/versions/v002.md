# Worley Cellular Noise

Also called: Cellular Noise, Voronoi Noise

## Overview
Worley Cellular Noise is a procedural noise function that calculates the distance to the nearest feature point in a 3D grid, returning a value in $[-1, 1]$ [S1, unofficial].

## How it works
**Inputs and Outputs**
- Input: Query point $(x, y, z)$, feature size `size` [S1, unofficial].
- Output: Scalar value $v \in [-1, 1]$ [S1, unofficial].

**Data Structures**
- The function is stateless and computes values on the fly without persistent data structures [S1, unofficial].

**Parameters**
- `size`: Feature size [S1, unofficial]. If `size` < EPSILON, the function returns $0.0$ [S1, unofficial].

**Algorithm Steps**
1. **Grid Decomposition**: Compute the integer grid coordinates $(i_x, i_y, i_z)$ and the fractional coordinates $(u, v, w)$ of the query point [S1, unofficial].
2. **Initialization**: Initialize `minDist` to a large value, specifically $1000000.0$ [S1, unofficial].
3. **Neighborhood Search**: Iterate through the 3x3x3 neighborhood of grid cells surrounding the query point [S1, unofficial]. The loop indices $dx, dy, dz$ range from $-1$ to $1$ [S1, unofficial].
4. **Feature Point Generation**: For each neighbor cell $(i_x+dx, i_y+dy, i_z+dz)$, determine the number of feature points contained within that cell using a deterministic random seed derived from the cell coordinates [S1, unofficial].
5. **Distance Calculation**: For each feature point in the current neighbor cell, calculate its squared distance from the query point in local coordinates [S1, unofficial].
6. **Minimum Distance Update**: Update `minDist` if the current point's distance is smaller [S1, unofficial].
7. **Normalization**: Return the normalized result using the formula $v = \text{saturate}(\text{minDist}) \times 2.0 - 1.0$, where $\text{saturate}(x)$ clamps $x$ to $[0, 1]$ [S1, unofficial].

**Pseudocode**
```python
import math

def worley_cellular_noise(x, y, z, size):
    EPSILON = 1e-6
    if size < EPSILON:
        return 0.0

    # 1. Grid decomposition
    ix = math.floor(x)
    iy = math.floor(y)
    iz = math.floor(z)
    u = x - ix
    v = y - iy
    w = z - iz

    # 2. Initialization
    min_dist = 1000000.0

    # 3. Neighborhood search (-1 to 1)
    for dx in range(-1, 2):
        for dy in range(-1, 2):
            for dz in range(-1, 2):
                # 4. Deterministic seed from cell coordinates [G]
                seed = (ix + dx) * 73856093 ^ (iy + dy) * 19349663 ^ (iz + dz) * 83492791
                # Number of points in cell [G]
                num_points = (seed & 0xFF) + 1
                
                for p in range(num_points):
                    # Feature point in local cell coordinates [G]
                    fx = ((seed * (p + 1) * 2654435761) >> 24) / 256.0
                    fy = ((seed * (p + 2) * 2654435761) >> 24) / 256.0
                    fz = ((seed * (p + 3) * 2654435761) >> 24) / 256.0
                    
                    # Global coordinates
                    gx = ix + dx + fx
                    gy = iy + dy + fy
                    gz = iz + dz + fz
                    
                    # 5. Squared distance calculation
                    dist_sq = (x - gx)**2 + (y - gy)**2 + (z - gz)**2
                    
                    # 6. Update minimum
                    if dist_sq < min_dist:
                        min_dist = dist_sq

    # 7. Normalization per source [S1, unofficial]
    if min_dist > 1.0:
        min_dist = 1.0
    if min_dist < 0.0:
        min_dist = 0.0
    return min_dist * 2.0 - 1.0
```

**Edge Cases and Pitfalls**
- **Boundaries**: The 3x3x3 neighborhood ensures that the nearest feature point is found even if it lies in an adjacent cell [S1, unofficial].
- **Degenerate Input**: If `size` is less than EPSILON, the function returns $0.0$ to avoid undefined behavior [S1, unofficial].
