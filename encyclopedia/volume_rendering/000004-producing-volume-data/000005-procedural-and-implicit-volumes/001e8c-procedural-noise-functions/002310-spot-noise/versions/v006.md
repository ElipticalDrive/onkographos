# Spot Noise

Also called: Impulse convolution noise, Sparse convolution noise

## Overview
Spot noise is a procedural texture synthesis method that generates structured patterns by convolving a uniform distribution of impulses with an arbitrary spatially defined kernel [S2, unofficial]. It solves the problem of creating flow-aligned or structured surface details by simulating the accumulation of many tiny drops over a domain [S1, unofficial]. Unlike gradient-based noise which relies on lattice interpolation, Spot noise is a sparse convolution method where the pattern emerges from the spatial arrangement of discrete events [S2, unofficial].

## How it works
**Inputs:**
*   Domain size and resolution [G].
*   Impulse density parameter (average number of impulses per unit area/volume) [G].
*   Kernel function $K(\mathbf{x})$, typically an elliptical Gaussian [S2, unofficial].
*   Vector field $\mathbf{V}(\mathbf{x})$ (optional, for orientation) [S1, unofficial].

**Outputs:**
*   Scalar field value $N(\mathbf{P})$ at query point $\mathbf{P}$ [G].

**Data Structures:**
*   Impulse list: A set of points $\{\mathbf{I}_j\}$ with associated attributes (position, orientation, scale) [G]. In standard Spot Noise, these are generated via jittered pseudorandom sampling to maintain a uniform distribution [S2, unofficial].

**Steps:**
1.  **Impulse Generation:** Generate impulse locations $\mathbf{I}_j$ across the domain using jittered pseudorandom sampling to ensure a uniform distribution [S2, unofficial].
2.  **Kernel Definition:** Define the kernel $K(\mathbf{x})$ spatially, typically as an elliptical Gaussian [S2, unofficial]. If a vector field is present, the kernel may be oriented along the field direction [S1, unofficial].
3.  **Convolution:** For a query point $\mathbf{P}$, compute the noise value by summing the contributions of all impulses:
    $$ N(\mathbf{P}) = \sum_{j} K(\mathbf{P} - \mathbf{I}_j) $$
4.  **Spectral Approach (Alternative):** Van Wijk presented a spectral approach to achieving this as well [S1, unofficial].

**Parameters:**
*   Impulse density: Controls the granularity of the pattern [G].
*   Kernel width: Controls the spread of each impulse [G].

**Edge Cases:**
*   High curvature or vorticity in the vector field can cause spots to blur out the flow structure [S1, unofficial].
*   Boundary conditions for impulse generation must be handled to avoid edge artifacts [G].

**Pseudocode:**
```python
import math

def spot_noise(p, impulses, kernel_width):
    """
    Compute Spot Noise value at point p.
    :param p: Query point (list/tuple of floats)
    :param impulses: List of impulse positions (list of lists/tuples of floats)
    :param kernel_width: Standard deviation of the Gaussian kernel [G]
    :return: Scalar noise value
    """
    value = 0.0
    sigma_sq = 2.0 * kernel_width * kernel_width
    for impulse_pos in impulses:
        dist_vec = [p[i] - impulse_pos[i] for i in range(len(p))]
        dist_sq = sum(d * d for d in dist_vec)
        contribution = math.exp(-dist_sq / sigma_sq)
        value += contribution
    return value
```

## Subtopics

### [Locally Controlled Spot Noise](4599-locally-controlled-spot-noise.md)
Extends standard Spot Noise by using a non-uniform distribution of impulses and allowing spatial control over kernel orientation and scale via underlying data fields, enabling structured texture synthesis with varying feature density.

## Operating characteristics
*   **Time Complexity:** Not given in the sources. [G]
*   **Memory Complexity:** Not given in the sources. [G]
*   **Strengths:** Flexible kernel formulation allows for arbitrary pattern shapes; suitable for structured texture synthesis [S2, unofficial].
*   **Limitations:** For high curvature or vorticity, the spots tend to blur out the flow structure [S1, unofficial].

## Background
Spot noise was introduced by van Wijk [vW91] and further developed by de Lavergtelle et al. [dLvL97] as a sparse convolution noise method [Lew89] [S2, unofficial]. It is based on the idea of developing a pattern after many thousands of tiny drops, representing a flow field [S1, unofficial]. The method is defined as a sparse convolution noise with a flexible kernel formulation where a uniform distribution of impulses is convolved with an arbitrary kernel spatially defined [S2, unofficial].
