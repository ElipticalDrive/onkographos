# Spot Noise

Also called: Impulse convolution noise, Sparse convolution noise

## Overview
Spot noise is a procedural texture synthesis method that generates structured patterns by convolving a uniform distribution of impulses with an arbitrary spatially defined kernel [S2, unofficial]. It solves the problem of creating flow-aligned or structured surface details (such as ink drops or cloud textures) by simulating the accumulation of many tiny drops over a domain [S1, unofficial]. Unlike gradient-based noise which relies on lattice interpolation, Spot noise is a sparse convolution method where the pattern emerges from the spatial arrangement of discrete events [S2, unofficial].

## How it works
**Inputs:**
*   Domain size and resolution.
*   Impulse density parameter (average number of impulses per unit area/volume).
*   Kernel function $K(\mathbf{x})$, typically an elliptical Gaussian [S2, unofficial].
*   Vector field $\mathbf{V}(\mathbf{x})$ (optional, for orientation) [S1, unofficial].

**Outputs:**
*   Scalar field value $N(\mathbf{P})$ at query point $\mathbf{P}$.

**Data Structures:**
*   Impulse list: A set of points $\{\mathbf{I}_j\}$ with associated attributes (position, orientation, scale). In standard Spot Noise, these are generated via jittered Poisson or uniform random sampling [S2, unofficial].

**Steps:**
1.  **Impulse Generation:** Generate a uniform distribution of impulse locations $\mathbf{I}_j$ across the domain using jittered random sampling [S2, unofficial].
2.  **Kernel Definition:** Define the kernel $K(\mathbf{x})$. For standard Spot Noise, this is often a Gaussian function. If a vector field is present, the kernel may be oriented along the field direction [S1, unofficial].
3.  **Convolution:** For a query point $\mathbf{P}$, compute the noise value by summing the contributions of all impulses within a certain radius or all impulses if the domain is small:
    $$ N(\mathbf{P}) = \sum_{j} K(\mathbf{P} - \mathbf{I}_j) $$
4.  **Spectral Approach (Alternative):** Van Wijk presented a spectral approach to achieve the result, which involves generating the noise in the frequency domain to control the power spectrum more precisely [S1, unofficial].

**Parameters:**
*   Impulse density: Controls the granularity of the pattern. Higher density yields smoother, finer textures [S2, unofficial].
*   Kernel width: Controls the spread of each impulse.

**Edge Cases:**
*   High curvature or vorticity in the vector field can cause spots to blur out the flow structure [S1, unofficial].
*   Boundary conditions for impulse generation must be handled to avoid edge artifacts [G].

**Pseudocode:**
```python
def spot_noise(p, impulses, kernel_width):
    """
    Compute Spot Noise value at point p.
    :param p: Query point (vector)
    :param impulses: List of impulse positions (list of vectors)
    :param kernel_width: Standard deviation of the Gaussian kernel
    :return: Scalar noise value
    """
    value = 0.0
    for impulse_pos in impulses:
        # Calculate distance vector
        dist_vec = p - impulse_pos
        # Calculate squared distance
        dist_sq = dot(dist_vec, dist_vec)
        # Gaussian kernel contribution
        # K(x) = exp(-|x|^2 / (2 * sigma^2))
        contribution = exp(-dist_sq / (2.0 * kernel_width * kernel_width))
        value += contribution
    return value
```

## Subtopics

### [Locally Controlled Spot Noise](4599-locally-controlled-spot-noise.md)
Extends standard Spot Noise by using a non-uniform distribution of impulses and allowing spatial control over kernel orientation and scale via underlying data fields, enabling structured texture synthesis with varying feature density.

## Operating characteristics
*   **Time Complexity:** $O(N \cdot M)$ where $N$ is the number of query points and $M$ is the number of impulses. Can be optimized with spatial hashing or grid-based neighbor search to $O(N)$ with a constant factor depending on kernel support [G].
*   **Memory Complexity:** $O(M)$ to store the impulse list.
*   **Strengths:** Flexible kernel formulation allows for arbitrary pattern shapes; good for simulating physical processes like ink spreading or cloud formation [S2, unofficial].
*   **Limitations:** Performance degrades with high impulse density; spectral approach may be complex to implement [S1, unofficial].

## Background
Spot noise was introduced by van Wijk [vW91] and further developed by de Lavergtelle et al. [dLvL97] as a sparse convolution noise method [Lew89]. It is based on the idea of developing a pattern after many thousands of tiny drops, representing a flow field [S1, unofficial]. The method has been used in volumetric texture synthesis and flow visualization [S2, unofficial].
