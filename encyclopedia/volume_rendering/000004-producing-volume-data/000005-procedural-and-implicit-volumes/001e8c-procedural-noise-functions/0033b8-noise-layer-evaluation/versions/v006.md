# Noise Layer Evaluation

Also called: Procedural Noise Layer Evaluation

## Overview
Evaluates a single procedural noise layer for volume or terrain shading, supporting multiple noise primitives, positional distortion, power scaling, and inversion [S1, unofficial]. Builds on [Procedural Noise Functions](1799-procedural-noise-functions.md) [S1, unofficial].

## How it works
**Inputs and Outputs**
- **Inputs**: `noiseSamplePosition` (vec3), `noiseLayerData` (vec4), `positionDistortion` (float), `invert` (bool), `enabled` (bool) [S1, unofficial].
- **Output**: `value` (float), the final noise layer contribution [S1, unofficial].

**Data Structures**
- `noiseLayerData`: A `vec4` encoding layer parameters:
  - `x`: `noiseScale` (float)
  - `y`: `noisePower` (float)
  - `z`: `angleOffset` (float)
  - `w`: `noiseType` (int, cast from float) [S1, unofficial].

**Steps**
1. **Enable Check**: If `enabled` is false, return `1.0` immediately [S1, unofficial].
2. **Distortion**: Compute `distortionStrength = 0.1 * positionDistortion` [S1, unofficial]. If `distortionStrength > 0`, sample `cnoise` at `distortionStrength * noiseSamplePosition`, cast the result to `vec3`, and add it to `noiseSamplePosition` [S1, unofficial].
3. **Unpack Parameters**: Extract `noiseScale`, `noisePower`, `angleOffset`, and `noiseType` from `noiseLayerData` [S1, unofficial].
4. **Noise Sampling**: Initialize `sampledNoiseValue = 0.0` [S1, unofficial]. Based on `noiseType`, sample the corresponding noise function at `noiseSamplePosition * noiseScale`: `0` for `cnoise`, `1` for `snoise`, `2` for `voronoi(noiseSamplePosition * noiseScale, angleOffset, noiseScale)`, `3` for `nebulaNoise` [S1, unofficial].
5. **Clamping**: Clamp `sampledNoiseValue` to `[0.0, 1.0]` and store in `value` [S1, unofficial].
6. **Inversion**: If `invert` is true, overwrite `value` with `1.0 - sampledNoiseValue`, bypassing the clamp applied in Step 5 [S1, unofficial].
7. **Power Scaling**: Take the absolute value of `noisePower` [S1, unofficial]. Compute `finalValue = pow(value, noisePower)` [S1, unofficial].

**Pseudocode**
```python
def evaluate_noise_layer(noise_sample_position, noise_layer_data, position_distortion, invert, enabled, depth):
    # Step 1: Enable Check
    if not enabled:
        return 1.0

    # Step 2: Distortion
    distortion_strength = 0.1 * position_distortion
    if distortion_strength > 0:
        # cnoise is a standard GLSL continuous noise function [G]
        distortion_offset = cnoise(distortion_strength * noise_sample_position)
        noise_sample_position = noise_sample_position + vec3(distortion_offset)

    # Step 3: Unpack Parameters
    noise_scale = noise_layer_data.x
    noise_power = noise_layer_data.y
    angle_offset = noise_layer_data.z
    noise_type = int(noise_layer_data.w)

    # Step 4: Noise Sampling
    sampled_noise_value = 0.0
    if noise_type == 0:
        sampled_noise_value = cnoise(noise_sample_position * noise_scale)
    elif noise_type == 1:
        sampled_noise_value = snoise(noise_sample_position * noise_scale)
    elif noise_type == 2:
        # voronoi is a standard GLSL cellular noise function [G]
        sampled_noise_value = voronoi(noise_sample_position * noise_scale, angle_offset, noise_scale)
    elif noise_type == 3:
        # nebulaNoise is a standard GLSL noise function [G]
        sampled_noise_value = nebulaNoise(noise_sample_position * noise_scale)

    # Step 5: Clamping
    value = clamp(sampled_noise_value, 0.0, 1.0)

    # Step 6: Inversion
    if invert:
        # Pitfall: Uses sampled_noise_value (pre-clamp) instead of value, bypassing the clamp [S1, unofficial]
        value = 1.0 - sampled_noise_value

    # Step 7: Power Scaling
    final_value = pow(abs(noise_power), value)

    return final_value

# Standard GLSL noise functions are assumed available [G]
def cnoise(p): pass
def snoise(p): pass
def voronoi(p, angle_offset, scale): pass
def nebulaNoise(p): pass

class vec3:
    def __init__(self, x, y, z):
        self.x, self.y, self.z = x, y, z
    def __mul__(self, scalar):
        return vec3(self.x * scalar, self.y * scalar, self.z * scalar)
    def __add__(self, other):
        return vec3(self.x + other.x, self.y + other.y, self.z + other.z)

def clamp(val, min_val, max_val):
    return max(min_val, min(val, max_val))
```

**Parameters**
- `noiseLayerData` (vec4): Encoded layer parameters [S1, unofficial].
- `positionDistortion` (float): Scales the offset applied to the sample position before noise evaluation [S1, unofficial].
- `invert` (bool): When true, inverts the noise value before power application [S1, unofficial].
- `enabled` (bool): When false, forces the layer output to 1.0 and skips evaluation [S1, unofficial].
- `densityMult` (float): Default 1.0, range [0.0, 1.0], step 0.001. Multiplies volume density in the raymarching loop [S1, unofficial].
- `maxSteps` (int): Default 70, range [40, 256], step 1. Maximum number of raymarching steps per ray [S1, unofficial].
- `stepSize` (float): Default 0.01, range [0.00001, 0.1], step 0.000001. Distance between consecutive sample positions along the ray [S1, unofficial].

**Edge Cases and Pitfalls**
- **Inversion Bypass**: The inversion branch uses `sampledNoiseValue` instead of the clamped `value`, meaning the clamp applied in Step 5 is ignored when inversion is active [S1, unofficial].
- **Unused Depth Parameter**: The `depth` parameter is declared in the function signature but is never referenced or used in the function body [S1, unofficial].
- **Degenerate Distortion**: If `positionDistortion` is 0, distortion is skipped, which is the standard behavior [S1, unofficial].

## Subtopics

### [Noise Position Calculation](16945-noise-position-calculation.md)
Calculates the 3D or 4D position in noise space for each triangle fragment to apply procedural noise and turbulence functions. It maps spatial coordinates to a noise field supporting animation and instance uniqueness, distinct from standard 2D texture mapping. It prepares the input for turbulence evaluation and subsequent color lookup.

### [Procedural Terrain JSON Schema](18504-procedural-terrain-json-schema.md)
The Procedural Terrain JSON Schema defines a data structure for storing the minimal set of parameters required to reproduce a designed procedural terrain in external applications. It serves as an export format that decouples terrain design from rendering, allowing the same terrain to be synthesized using different base noise implementations or rendering engines. Unlike [Noise Layer Evaluation](7076-noise-layer-evaluation.md), which describes the runtime evaluation of a single layer, this schema defines the persistent storage format for a collection of layers and their global bounds.

### Automatic Layer Masking
Determines which parts of a noise layer are active based on the value ranges of underlying reference layers, allowing multiple noise layers to add detail to specific terrain features [S2, unofficial]. Reference height map layers are evaluated from top to bottom; an underlying layer masks a top layer if the top layer does not span the whole value range of the underlying layer [S2, unofficial]. The masked range is continuous, determined by the minimum and maximum value where the top reference layer overlaps the layer under it [S2, unofficial]. The mask range is saved in the processed noise function, and outside this range, the elevation change evaluates to zero [S2, unofficial]. Smoothstepping is used instead of simple clamping near mask range edges to make seams less visible [S2, unofficial]. Binary masking limits control, and a partial mask altering values using learned distributions would be beneficial but is computationally expensive and non-trivial to determine from example data [S2, unofficial].

### Base Noise Frequency Estimation
Estimates the base frequency of a noise layer by matching the average peak values per row of the reference data [S2, unofficial]. The reference height map array is traversed horizontally and vertically, counting points where the value trend changes from increasing to decreasing (peak values); for masked layers, only visible values are considered [S2, unofficial]. A single scalar, the row average of peak counts, is calculated [S2, unofficial]. The noise frequency is iteratively adjusted using a heuristic search until the peak count matches the reference data, relying on the fact that the number of peak values increases with frequency [S2, unofficial]. The implementation is a naive approximation, very sensitive to unwanted high-frequency noise in the reference data, and only works for height maps with intended patterns representable by a single noise layer [S2, unofficial].
