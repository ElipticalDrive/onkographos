# Noise Layer Evaluation

Also called: Procedural Noise Layer Evaluation

## Overview
Noise Layer Evaluation is a procedural shading technique that computes a single noise layer value for volume or terrain rendering, supporting multiple noise primitives, positional distortion, power scaling, and inversion [S1, unofficial].

## How it works
**Inputs and Outputs**
*   **Input:** `noiseSamplePosition` (vec3), `noiseLayerData` (vec4), `positionDistortion` (float), `invert` (bool), `enabled` (bool) [S1, unofficial].
*   **Output:** `finalValue` (float) [S1, unofficial].

**Data Structures**
*   `noiseLayerData`: A 4-component vector encoding layer parameters:
    *   `x`: `noiseScale` (float)
    *   `y`: `noisePower` (float)
    *   `z`: `angleOffset` (float)
    *   `w`: `noiseType` (integer, cast from float) [S1, unofficial].

**Numbered Steps**
1.  **Enable Check:** If `enabled` is false, set `finalValue` to 1.0 and return immediately [S1, unofficial].
2.  **Distortion Calculation:** Compute `distortionStrength` as $0.1 \times \text{positionDistortion}$ [S1, unofficial]. If `distortionStrength` > 0, sample a noise function `cnoise` at `distortionStrength * noiseSamplePosition`, then add the resulting 3D vector to `noiseSamplePosition` to create a distorted position [S1, unofficial].
3.  **Parameter Unpacking:** Extract `noiseScale`, `noisePower`, `angleOffset`, and `noiseType` from `noiseLayerData` [S1, unofficial].
4.  **Noise Sampling:** Initialize `sampledNoiseValue` to 0.0 [S1, unofficial]. Select the noise function based on `noiseType` and evaluate it at `noiseSamplePosition * noiseScale`: 0 = `cnoise`, 1 = `snoise`, 2 = `voronoi(noiseSamplePosition * noiseScale, angleOffset, noiseScale)`, 3 = `nebulaNoise` [S1, unofficial].
5.  **Clamping and Inversion:** Clamp `sampledNoiseValue` to the range $[0.0, 1.0]$ and store in `value` [S1, unofficial]. If `invert` is true, overwrite `value` with $1.0 - \text{sampledNoiseValue}$, which bypasses the previous clamp [S1, unofficial].
6.  **Power Scaling:** Compute `absNoisePower` as $|\text{noisePower}|$ [S1, unofficial]. Calculate `finalValue` as $\text{value}^{\text{absNoisePower}}$ [S1, unofficial].

**Pseudocode**
```python
def evaluate_noise_layer(noise_sample_position, noise_layer_data, position_distortion, invert, enabled, depth):
    # Standard noise primitives [G]
    def cnoise(p): return 0.0
    def snoise(p): return 0.0
    def voronoi(p, angle, scale): return 0.0
    def nebula_noise(p): return 0.0

    # Step 1: Enable Check
    if not enabled:
        return 1.0

    # Step 2: Distortion
    distortion_strength = 0.1 * position_distortion
    if distortion_strength > 0:
        distortion_offset = cnoise(distortion_strength * noise_sample_position)
        distorted_position = noise_sample_position + distortion_offset
    else:
        distorted_position = noise_sample_position

    # Step 3: Unpack Parameters
    noise_scale = noise_layer_data.x
    noise_power = noise_layer_data.y
    angle_offset = noise_layer_data.z
    noise_type = int(noise_layer_data.w)

    # Step 4: Noise Sampling
    sampled_noise_value = 0.0
    scaled_position = distorted_position * noise_scale

    if noise_type == 0:
        sampled_noise_value = cnoise(scaled_position)
    elif noise_type == 1:
        sampled_noise_value = snoise(scaled_position)
    elif noise_type == 2:
        sampled_noise_value = voronoi(scaled_position, angle_offset, noise_scale)
    elif noise_type == 3:
        sampled_noise_value = nebula_noise(scaled_position)
    else:
        sampled_noise_value = 0.0

    # Step 5: Clamping and Inversion
    value = max(0.0, min(1.0, sampled_noise_value))

    if invert:
        # Pitfall: Inversion uses original sampled value, bypassing clamp
        value = 1.0 - sampled_noise_value

    # Step 6: Power Scaling
    abs_noise_power = abs(noise_power)
    final_value = pow(value, abs_noise_power)

    return final_value
```

**Parameters**
*   `noiseLayerData` (vec4): Encoded layer parameters. `x`=scale, `y`=power, `z`=angle offset, `w`=noise type (integer 0-3) [S1, unofficial].
*   `positionDistortion` (float): Scales the offset applied to the sample position [S1, unofficial].
*   `invert` (bool): When true, inverts the noise value before power application [S1, unofficial].
*   `enabled` (bool): When false, forces the layer output to 1.0 [S1, unofficial].
*   `densityMult` (float): Default 1.0, range $[0.0, 1.0]$, step 0.001. Multiplies volume density in the raymarching loop [S1, unofficial].
*   `maxSteps` (int): Default 70, range $[40, 256]$, step 1. Maximum number of raymarching steps per ray [S1, unofficial].
*   `stepSize` (float): Default 0.01, range $[0.00001, 0.1]$, step 0.000001. Distance between consecutive sample positions along the ray [S1, unofficial].

**Edge Cases and Pitfalls**
*   **Inversion Bypass:** The inversion branch uses `sampledNoiseValue` instead of the clamped `value`. This means if `invert` is true, the clamp applied in Step 5 is ignored, potentially allowing values outside $[0.0, 1.0]$ to be inverted and raised to a power [S1, unofficial].
*   **Unused Depth Parameter:** The function signature includes a `depth` parameter which is declared but never referenced or used in the function body [S1, unofficial].

## Operating characteristics
*   **Time Complexity:** $O(1)$ per layer evaluation, assuming constant-time noise primitives [G].
*   **Memory Complexity:** $O(1)$ auxiliary memory [G].
*   **Strengths:** Unified handling of multiple noise types and post-processing effects (distortion, inversion, power) in a single pass [G].
*   **Limitations:** The inversion logic bypasses the clamp, which can lead to unexpected artifacts if not accounted for [S1, unofficial]. Performance depends heavily on the underlying noise primitives (`cnoise`, `snoise`, etc.) [S1, unofficial].
*   **When to use:** When a procedural volume requires flexible noise layering with distortion and non-linear scaling [G].
*   **When not to use:** When strict bounded output $[0.0, 1.0]$ is required regardless of inversion settings [G].

## Background
This method is derived from the procedural noise layer evaluation logic found in the Texturinator project, an unofficial implementation for 3D volume previewing [S1, unofficial]. It integrates standard gradient-based noise primitives (like Simplex and Curl noise) with a specific layer management system used in real-time volume rendering applications [G].
