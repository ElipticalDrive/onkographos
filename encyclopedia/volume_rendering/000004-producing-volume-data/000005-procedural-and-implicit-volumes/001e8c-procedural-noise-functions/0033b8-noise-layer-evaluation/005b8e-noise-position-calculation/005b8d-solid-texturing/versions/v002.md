# Solid Texturing

Also called: 3D Map Texturing, Procedural Solid Texturing, Sampling a solid noise, Sampling solid noise

## Overview
Solid texturing applies a 3D procedural noise function at every surface point or spatial coordinate to texture an object, making it appear carved out of a continuous block of matter [S1, S2]. It solves the seam and distortion problems of 2D UV mapping while maintaining low memory consumption by avoiding pre-computed 3D texture tables [S1]. Unlike surface noise, which lets anisotropic textures flow around an object, solid texturing fixes the texture orientation in space, producing a unique sculpted appearance [S1].

## How it works
**Inputs and Outputs:**
*   **Input:** A 3D procedural noise function $N(x, y, z)$ (e.g., Perlin noise) and a set of 3D coordinates $\mathbf{p}$ representing either surface points, voxel centers, or ray sampling locations [S1][S3, book].
*   **Output:** A scalar value or color assigned to each coordinate, representing the material property or color at that location [S3, book].

**Data Structures:**
*   **Noise Function:** Typically implemented as a hash-based interpolation of gradient vectors at predetermined lattice points [S3, book]. Explicit pre-computed 3D tables are avoided to prevent large memory costs [S1].
*   **Coordinates:** 3D vectors $(x, y, z)$ in world or object space [S1].

**Steps:**
1.  **Generalize Noise to 3D:** Ensure the base noise function accepts 3D input coordinates. All standard noise functions are easily generalized to 3D and higher dimensions [S1].
2.  **Evaluate Noise:** Evaluate the 3D noise function at the 3D coordinates of each surface point [S2].
3.  **Voxelization:** During the voxelization phase, assign a value to each voxel belonging to the object using the texturing function or 3D map, storing it as part of the voxel information [S3, book].
4.  **Volume Enrichment:** If used to enrich a volume dataset without increasing stored resolution, evaluate the texturing function during rendering time at the ray sampling locations [S3, book].

**Formulas:**
The power spectrum of the noise on the surface, $P_{\text{surface}}(u, v)$, is related to the power spectrum of the solid noise, $P_{\text{solid}}(u, v, w)$, by the slice-projection theorem [S1, S2]:
$$ P_{\text{surface}}(u, v) = \int_{-\infty}^{\infty} P_{\text{solid}}(u, v, w) \, dw $$
This integration occurs because evaluating a 3D noise along a surface corresponds to slicing the 3D domain [S2].

**Pitfalls and Edge Cases:**
*   **Loss of Band-Pass Properties:** Slicing a 3D band-pass noise along a surface does not result in a band-pass noise on the surface due to the slice-projection theorem [S1, S2]. The resulting power spectrum is not band-pass anymore, which can alter frequency characteristics [S1].
*   **Memory Costs:** Explicit noises that rely on pre-computed 3D tables induce large memory costs and are generally avoided in favor of procedural generation [S1].
*   **Alternative Surface Definition:** Defining noise directly on the surface so features flow along curvatures is difficult in general but possible with sparse convolution noises [S1].

**Pseudocode:**
```python
def evaluate_solid_texture(points, noise_func):
    """
    Evaluates a 3D procedural noise function at given 3D coordinates.
    Supports surface points, voxel centers, or ray sampling locations.
    """
    values = []
    for p in points:
        # Step 1 & 2: Generalize noise to 3D and evaluate at coordinates
        value = noise_func(p.x, p.y, p.z)
        values.append(value)
    return values

# Note: For voxelization, call evaluate_solid_texture with voxel centers during the voxelization phase [S3, book].
# Note: For volume enrichment, call evaluate_solid_texture with ray sampling locations during rendering [S3, book].
```

### [Coupled Modeling of Solid Textures and Implicit Shapes](19914-coupled-modeling-of-solid-textures-and-implicit-shapes.md)
Coupled Modeling of Solid Textures and Implicit Shapes is a technique for texturing implicit surfaces by using similar functions for both implicit surfaces and solid textures, ensuring uniform textures that conform to any orientable 2-manifold shapes with no obvious stretch. It sets itself apart from general implicit modeling by guaranteeing interactivity regardless of shape complexity, as function computation during construction does not depend on shape complexity. ## Operating characteristics
*   **Memory:** Low memory consumption compared to explicit 3D texture maps, as the noise is generated procedurally [S1].
*   **Visual Quality:** Produces a natural, continuous material appearance that is difficult to achieve with 2D texturing [S1].
*   **When to Use:** When a natural, continuous material appearance is desired and memory is a constraint [S1].
*   **When Not to Use:** When the loss of band-pass properties on surfaces is unacceptable without additional correction [S1].

## Background
The idea of sampling 3D noise on surfaces was introduced by Perlin [Per85] and Peachy [Pea85] and popularized as solid texturing [S1]. It has been widely used in computer graphics for creating procedural textures and modeling solid materials [S1][S3, book]. A comprehensive overview of solid texturing can be found in Dischler and Ghazanfarpour [DG01] [S1]. The slice-projection theorem, which explains the spectral properties of sliced noise, was established by Braun [Bra99] and Mallat [Mal93] [S1].
