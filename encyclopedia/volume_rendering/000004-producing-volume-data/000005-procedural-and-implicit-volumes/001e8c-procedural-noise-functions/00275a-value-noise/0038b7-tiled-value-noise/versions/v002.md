# Tiled Value Noise
Also called: Periodic 3D Value Noise
## Overview
Tiled Value Noise is a procedural noise generation method that produces seamless, periodic 3D scalar fields by wrapping the lattice indices of a standard value noise implementation [S1, unofficial]. It solves the problem of visible discontinuities and directional stripe artifacts that occur when standard value noise is tiled or repeated [S1, unofficial]. Unlike standard value noise, which assumes an infinite domain, Tiled Value Noise constrains the signal to a fixed integer period, ensuring that the noise pattern matches perfectly at the boundaries of the tile [S1, unofficial]. It serves as the foundational noise primitive for higher-level techniques such as Fractal Value Noise with Domain Warping, where seamless tiling is required to avoid visible seams in the warped domain [8323-fractal-value-noise-with-domain-warping.md].
## How it works
**Inputs:** Input coordinates $(x, y, z)$, a single integer `frequency` defining the tile period in lattice units, and a pre-generated 3D `lattice` array [S1, unofficial].
**Outputs:** A scalar value $N(x, y, z)$ in the range $[0, 1]$ [S1, unofficial].
**Data Structures:** `lattice` is a 3D array of shape `(frequency, frequency, frequency)` containing random floats in $[0, 1]$ stored as `np.float32` [S1, unofficial].
**Algorithm Steps:**
1. **Lattice Generation**: Create the tiled random lattice using a random number generator [S1, unofficial].
2. **Coordinate Mapping**: Map input coordinates to lattice space: $p_x = (x + 1.0) \cdot 0.5 \cdot f$, $p_y = (y + 1.0) \cdot 0.5 \cdot f$, $p_z = (z + 1.0) \cdot 0.5 \cdot f$ [S1, unofficial].
3. **Integer Index Calculation**: Compute integer grid indices with modulo for periodicity: $i_x = \lfloor p_x \rfloor \pmod f$, $i_y = \lfloor p_y \rfloor \pmod f$, $i_z = \lfloor p_z \rfloor \pmod f$ [S1, unofficial].
4. **Fractional Parts and Fade**: Compute fractional parts and apply Perlin's quintic fade: $f_x = \text{fade}(p_x - \lfloor p_x \rfloor)$, $f_y = \text{fade}(p_y - \lfloor p_y \rfloor)$, $f_z = \text{fade}(p_z - \lfloor p_z \rfloor)$ [S1, unofficial].
5. **Next Indices**: Compute next indices with modulo: $i_{x1} = (i_x + 1) \pmod f$, $i_{y1} = (i_y + 1) \pmod f$, $i_{z1} = (i_z + 1) \pmod f$ [S1, unofficial].
6. **X-Axis Interpolation**: Interpolate along X for four corners: $c_{00} = \text{lattice}[i_z, i_y, i_x] \cdot (1.0 - f_x) + \text{lattice}[i_z, i_y, i_{x1}] \cdot f_x$, $c_{10} = \text{lattice}[i_z, i_{y1}, i_x] \cdot (1.0 - f_x) + \text{lattice}[i_z, i_{y1}, i_{x1}] \cdot f_x$, $c_{01} = \text{lattice}[i_{z1}, i_y, i_x] \cdot (1.0 - f_x) + \text{lattice}[i_{z1}, i_y, i_{x1}] \cdot f_x$, $c_{11} = \text{lattice}[i_{z1}, i_{y1}, i_x] \cdot (1.0 - f_x) + \text{lattice}[i_{z1}, i_{y1}, i_{x1}] \cdot f_x$ [S1, unofficial].
7. **Y-Axis Interpolation**: Interpolate along Y: $\text{lower} = c_{00} \cdot (1.0 - f_y) + c_{10} \cdot f_y$, $\text{upper} = c_{01} \cdot (1.0 - f_y) + c_{11} \cdot f_y$ [S1, unofficial].
8. **Z-Axis Interpolation**: Interpolate along Z: $N(x, y, z) = \text{lower} \cdot (1.0 - f_z) + \text{upper} \cdot f_z$ [S1, unofficial].
**Formula:** Fade function $f(v) = v^2 (v (6v - 15) + 10)$ [S1, unofficial].
**Pseudocode:**
```python
import numpy as np

def fade(v):
    """Perlin's quintic fade function."""
    return v * v * v * (v * (v * 6.0 - 15.0) + 10.0)

def tiled_value_noise(x, y, z, frequency, lattice):
    """Generate tiled 3D value noise."""
    # Map input coordinates to lattice space [0, frequency]
    px = (x + 1.0) * 0.5 * frequency
    py = (y + 1.0) * 0.5 * frequency
    pz = (z + 1.0) * 0.5 * frequency
    
    # Compute integer grid indices with modulo for periodicity
    ix = int(np.floor(px)) % frequency
    iy = int(np.floor(py)) % frequency
    iz = int(np.floor(pz)) % frequency
    
    # Compute fractional parts and apply fade
    fx = fade(px - np.floor(px))
    fy = fade(py - np.floor(py))
    fz = fade(pz - np.floor(pz))
    
    # Compute next indices with modulo
    ix1 = (ix + 1) % frequency
    iy1 = (iy + 1) % frequency
    iz1 = (iz + 1) % frequency
    
    # Interpolate along X axis for four corners
    c00 = lattice[iz, iy, ix] * (1.0 - fx) + lattice[iz, iy, ix1] * fx
    c10 = lattice[iz, iy1, ix] * (1.0 - fx) + lattice[iz, iy1, ix1] * fx
    c01 = lattice[iz1, iy, ix] * (1.0 - fx) + lattice[iz1, iy, ix1] * fx
    c11 = lattice[iz1, iy1, ix] * (1.0 - fx) + lattice[iz1, iy1, ix1] * fx
    
    # Interpolate along Y axis
    lower = c00 * (1.0 - fy) + c10 * fy
    upper = c01 * (1.0 - fy) + c11 * fy
    
    # Interpolate along Z axis
    return lower * (1.0 - fz) + upper * fz
```
**Edge Cases and Pitfalls:** Directional stripes are avoided by using only integer coefficients in coordinate transforms and periodic lattice sampling, eliminating the need for sine/cosine functions [S1, unofficial]. Boundary precision is handled naturally: when an input coordinate maps exactly to the tile boundary (e.g., $p_x = f$), the floor and modulo operations wrap the index to $0$, ensuring continuity [S1, unofficial].
## Subtopics

### [Fractal Value Noise with Domain Warping](8323-fractal-value-noise-with-domain-warping.md)
A multi-scale, domain-warped value noise technique that produces seamless tiled noise without fixed-direction periodic stripes, using independent lattices for warping and sampling. It builds on Tiled Value Noise to ensure that the domain warping itself does not introduce visible seams [8323-fractal-value-noise-with-domain-warping.md].

## Operating characteristics
Time complexity is $O(1)$ per sample due to a fixed number of arithmetic operations and array lookups [G]. Memory complexity is $O(f^3)$ for the lattice storage [G]. Not given in the sources.
## Background
Tiled Value Noise is a variation of value noise designed for procedural generation where seamless repetition is required [S1, unofficial]. It leverages periodic boundary conditions to avoid tiling artifacts common in standard noise functions [S1, unofficial].
