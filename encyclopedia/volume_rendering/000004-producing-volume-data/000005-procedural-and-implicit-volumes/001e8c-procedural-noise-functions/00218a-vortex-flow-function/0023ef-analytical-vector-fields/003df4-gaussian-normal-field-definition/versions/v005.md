# Gaussian Normal Field Definition

Also called: Definition 3, Gaussian Normal Field, Gaussian vector field, Normalized Gaussian vector field, Proposition 3

## Overview
The Gaussian Normal Field Definition is a method for deriving an explicit surface normal field from a Gaussian Splatting representation of a scene [S1]. It solves the problem of extracting geometric normals from the stochastic surface defined by oriented Gaussians, which is necessary for supervising training to enforce proper surface wrapping and for mesh extraction [S1]. It differs from sibling methods like [Curl Noise Generation](10372-curl-noise-generation.md) by providing a deterministic, closed-form normal estimate based on the gradient of the log-vacancy, rather than procedural noise patterns.

## How it works
The method constructs a vector field $V$ as the gradient of the log-vacancy and normalizes it to obtain the normal field $\mathcal{N}$ [S1].

**Inputs:**
- $N$: Number of oriented Gaussians.
- For each Gaussian $i \in \{1, \dots, N\}$:
  - $\mu_i \in \mathbb{R}^3$: Mean position.
  - $n_i \in S^2$: Normal vector orientation.
  - $G_i(x)$: The Gaussian density function value at position $x$.

**Outputs:**
- $\mathcal{N}(x) \in \mathbb{R}^3$: The estimated surface normal at position $x$.

**Data Structures:**
- The implementation requires access to the parameters of the $N$ Gaussians. No additional global data structures are specified beyond the list of Gaussian parameters [S1].

**Formulas:**
1.  **Gaussian Vector Field ($V$):**
    The vector field is defined as the sum of the gradients of the log-vacancy for each Gaussian, restricted to the half-space defined by the Gaussian's normal [S1]:
    $$ V(x) = \sum_{i=1}^N \mathbb{1}_{n_i^T(x-\mu_i) \geq 0} \nabla \log(1 - G_i(x)) $$
    where:
    - $\mathbb{1}_{condition}$ is the indicator function, equal to 1 if the condition is true, 0 otherwise.
    - $n_i^T(x-\mu_i) \geq 0$ ensures the contribution is only from the "front" side of the Gaussian relative to its normal.
    - $\nabla \log(1 - G_i(x))$ is the gradient of the logarithm of the vacancy (1 minus the Gaussian density).

2.  **Gaussian Normal Field ($\mathcal{N}$):**
    The normal field is the normalized vector field [S1]:
    $$ \mathcal{N}(x) = \begin{cases} \frac{V(x)}{\|V(x)\|} & \text{if } \|V(x)\| > 0 \\ 0 & \text{otherwise} \end{cases} $$

**Steps:**
1.  Initialize the vector field accumulator $V(x) = \mathbf{0}$.
2.  For each Gaussian $i$ from 1 to $N$:
    a. Calculate the displacement vector $d = x - \mu_i$.
    b. Check the orientation condition: if $n_i \cdot d \geq 0$:
        i. Compute the gradient of the log-vacancy for this Gaussian: $g_i = \nabla \log(1 - G_i(x))$.
        ii. Add $g_i$ to the accumulator: $V(x) \leftarrow V(x) + g_i$.
3.  Calculate the magnitude $\|V(x)\|$.
4.  If $\|V(x)\| > 0$, return $\mathcal{N}(x) = V(x) / \|V(x)\|$.
5.  Otherwise, return $\mathcal{N}(x) = \mathbf{0}$.

**Pseudocode:**
```python
import numpy as np

def gaussian_normal_field(x, gaussians):
    """
    Compute the Gaussian Normal Field at position x.
    
    Args:
        x: numpy array, shape (3,), position in 3D space.
        gaussians: list of dicts, each containing:
            - 'mu': numpy array, shape (3,), mean position.
            - 'n': numpy array, shape (3,), normal vector.
            - 'G': callable, function returning G_i(x) density value.
            - 'grad_log_vacancy': callable, function returning grad(log(1 - G_i(x))).
            
    Returns:
        numpy array, shape (3,), the normal vector.
    """
    V = np.zeros(3)
    
    for g in gaussians:
        mu = g['mu']
        n = g['n']
        
        # Check orientation condition: n^T (x - mu) >= 0
        displacement = x - mu
        if np.dot(n, displacement) >= 0:
            # Compute gradient of log-vacancy for this Gaussian
            # Note: The source defines V as sum of grad(log(1-G_i)).
            # We assume the helper function provides this specific gradient.
            grad_term = g['grad_log_vacancy'](x)
            V = V + grad_term
            
    norm_V = np.linalg.norm(V)
    
    if norm_V > 0:
        return V / norm_V
    else:
        return np.zeros(3)
```

**Parameters:**
- The condition $\|V(x)\| > 0$ determines if the normal is computed; if zero, the normal is 0 [S1].
- Typical values for $N$ depend on the scene complexity and Gaussian Splatting representation [S1].

**Edge Cases and Pitfalls:**
- **Zero Vector Field:** If $\|V(x)\| = 0$, the normal is undefined. The method returns the zero vector [S1]. This occurs in regions far from any Gaussian or where contributions cancel out exactly.
- **Sign Ambiguity:** The derivation assumes that locally, each term in the sum has the same sign as the total gradient or is zero. This "wrapping assumption" allows removing absolute values from the sum [S1]. If this assumption fails (e.g., in complex occlusion scenarios not covered by the stochastic surface model), the result may be inaccurate.
- **Gradient Computation:** The term $\nabla \log(1 - G_i(x))$ requires computing the gradient of the Gaussian density. Standard Gaussian Splatting implementations provide $G_i(x)$, but the gradient of the log-vacancy must be derived or approximated.

## Operating characteristics
- **Time Complexity:** $O(N)$ per query point $x$, where $N$ is the number of Gaussians. Each Gaussian requires a dot product, a conditional check, and a gradient evaluation.
- **Memory Complexity:** $O(N)$ to store the Gaussian parameters.
- **Strengths:** Provides an explicit, differentiable normal field directly from the Gaussian Splatting representation, enabling surface supervision and mesh extraction [S1].
- **Limitations:** Relies on the "wrapping assumption" for correctness. Performance degrades linearly with the number of Gaussians.
- **When to use:** When extracting normals from a trained Gaussian Splatting model for surface reconstruction or training supervision.
- **When not to use:** When high-performance real-time normal estimation is required for very large scenes without spatial acceleration structures, or when the wrapping assumption is violated.

## Background
The Gaussian Normal Field Definition was introduced in "From Blobs to Spokes: High-Fidelity Surface Reconstruction via Oriented Gaussians" [S1]. It builds on the concept of Objects as Volumes (OaV) [S1], which provides an expression for the gradient of the log-vacancy. The method leverages this gradient field to derive an explicit normal field on the stochastic surface, serving to supervise oriented Gaussians during training and extract meshes [S1].
