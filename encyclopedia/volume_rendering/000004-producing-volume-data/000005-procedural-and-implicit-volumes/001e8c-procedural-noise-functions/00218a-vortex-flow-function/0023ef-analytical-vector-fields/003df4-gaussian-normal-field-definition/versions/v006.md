# Gaussian Normal Field Definition

Also called: Definition 3, Gaussian Normal Field, Gaussian vector field, Normalized Gaussian vector field, Proposition 3

## Overview
The Gaussian Normal Field Definition derives an explicit surface normal field from a Gaussian Splatting representation of a scene [S1]. It extracts geometric normals from the stochastic surface defined by oriented Gaussians to supervise training for proper surface wrapping and to enable mesh extraction [S1].

## How it works
The method constructs a vector field $V$ as the gradient of the log-vacancy and normalizes it to obtain the normal field $\mathcal{N}$ [S1].

**Inputs:**
- $N$: Number of oriented Gaussians [S1].
- For each Gaussian $i \in \{1, \dots, N\}$: mean position $\mu_i \in \mathbb{R}^3$, normal orientation $n_i \in S^2$, and Gaussian density function $G_i(x)$ [S1].

**Outputs:**
- $\mathcal{N}(x) \in \mathbb{R}^3$: The estimated surface normal at position $x$ [S1].

**Data Structures:**
- The implementation requires access to the parameters of the $N$ Gaussians [S1].

**Formulas:**
1. **Gaussian Vector Field ($V$):** The vector field is defined as the gradient of the log-vacancy, summing contributions from each Gaussian restricted to its front half-space [S1]:
   $$ V(x) = \sum_{i=1}^N \mathbb{1}_{n_i^T(x-\mu_i) \geq 0} \nabla \log(1 - G_i(x)) $$
   where $\mathbb{1}_{condition}$ is the indicator function (1 if true, 0 otherwise) [S1], and $\nabla \log(1 - G_i(x))$ is the gradient of the logarithm of the vacancy [S1].
2. **Gaussian Normal Field ($\mathcal{N}$):** The normal field is the normalized vector field [S1]:
   $$ \mathcal{N}(x) = \begin{cases} \frac{V(x)}{\|V(x)\|} & \text{if } \|V(x)\| > 0 \\ 0 & \text{otherwise} \end{cases} $$
   In a neighborhood of the surface, $\|V\| > 0$ and $\mathcal{N}$ coincides with the true normal field of the expected stochastic surface [S1].

**Steps:**
1. Initialize the vector field accumulator $V(x) = \mathbf{0}$ [S1].
2. For each Gaussian $i$ from 1 to $N$:
   a. Calculate the displacement vector $d = x - \mu_i$ [S1].
   b. Check the orientation condition: if $n_i \cdot d \geq 0$:
      i. Compute the gradient of the log-vacancy for this Gaussian: $g_i = \nabla \log(1 - G_i(x))$ [S1].
      ii. Add $g_i$ to the accumulator: $V(x) \leftarrow V(x) + g_i$ [S1].
3. Calculate the magnitude $\|V(x)\|$ [S1].
4. If $\|V(x)\| > 0$, return $\mathcal{N}(x) = V(x) / \|V(x)\|$ [S1].
5. Otherwise, return $\mathcal{N}(x) = \mathbf{0}$ [S1].

**Pseudocode:**
```python
import numpy as np

def gaussian_normal_field(x, gaussians):
    """
    Compute the Gaussian Normal Field at position x.
    Args:
        x: numpy array, shape (3,), position in 3D space.
        gaussians: list of dicts, each containing:
            - 'mu': numpy array, shape (3,), mean position.
            - 'n': numpy array, shape (3,), normal vector.
            - 'G': callable, function returning G_i(x) density value.
            - 'grad_G': callable, function returning gradient of G_i(x).
    Returns:
        numpy array, shape (3,), the normal vector.
    """
    V = np.zeros(3)
    for g in gaussians:
        mu = g['mu']
        n = g['n']
        displacement = x - mu
        if np.dot(n, displacement) >= 0:
            # Compute gradient of log-vacancy: grad(log(1-G)) = -grad(G) / (1-G)
            # Exact Gaussian parameterization (covariance) is not given in the sources.
            G_val = g['G'](x)
            grad_G_val = g['grad_G'](x)
            grad_log_vacancy = -grad_G_val / (1.0 - G_val)
            V = V + grad_log_vacancy
    norm_V = np.linalg.norm(V)
    if norm_V > 0:
        return V / norm_V
    else:
        return np.zeros(3)
```

**Parameters:**
- The condition $\|V(x)\| > 0$ determines if the normal is computed; if zero, the normal is 0 [S1].

**Edge Cases and Pitfalls:**
- **Zero Vector Field:** If $\|V(x)\| = 0$, the normal is undefined and the method returns the zero vector [S1].
- **Sign Ambiguity:** The derivation assumes that locally, each term in the sum has the same sign as the total gradient or is zero [S1]. This "wrapping assumption" allows removing absolute values from the sum [S1]. If this assumption fails, the result may be inaccurate [S1].

## Operating characteristics
- Time and memory complexity: Not given in the sources.
- Strengths and limitations: Provides an explicit, differentiable normal field directly from the Gaussian Splatting representation, enabling surface supervision and mesh extraction [S1]. Relies on the "wrapping assumption" for correctness [S1].
- When to use: When extracting normals from a trained Gaussian Splatting model for surface reconstruction or training supervision [S1].
- When not to use: Not given in the sources.

## Background
The Gaussian Normal Field Definition was introduced in "From Blobs to Spokes: High-Fidelity Surface Reconstruction via Oriented Gaussians" [S1]. It builds on the concept of Objects as Volumes (OaV), which provides an expression for the gradient of the log-vacancy [S1]. The method leverages this gradient field to derive an explicit normal field on the stochastic surface, serving to supervise oriented Gaussians during training and extract meshes [S1].
