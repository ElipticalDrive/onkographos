# Curl Noise Generation

Also called: Curl texture generation, Divergence-free vector field from noise derivatives

## Overview
Curl noise generation produces a divergence-free vector field by computing the curl of a scalar noise field, typically Perlin or Simplex noise [S1, unofficial][S2]. This ensures the resulting velocity field has no sources or sinks, creating smooth, swirling flow patterns suitable for particle advection and volumetric effects [S2]. It differs from standard noise functions by outputting a vector field directly derived from spatial derivatives, guaranteeing incompressibility ($\nabla \cdot \mathbf{u} = 0$) [S1, unofficial][S2].

## How it works
**Inputs:**
*   Position $\mathbf{p} = (x, y, z)$ [S1, unofficial].
*   Time $t$ (optional, if noise is time-dependent) [S1, unofficial].
*   Noise seed and periodicity parameters for the underlying scalar noise function [S1, unofficial].
*   Step size $h$ for finite differences (e.g., $10^{-3}$) [S1, unofficial].

**Outputs:**
*   A 3D velocity vector $\mathbf{u}$ [S1, unofficial].
*   Alternatively, a 2D curl texture with 2 or 3 channels, stored in formats like `RGFloat` (range [-1, 1]) or `RGBA32` (encoded to [0, 1]) [S2].

**Data Structures:**
*   Scalar Noise Field: A function $F(\mathbf{p})$ returning a scalar value [S1, unofficial].
*   Vector Noise Field: A function $\mathbf{F}(\mathbf{p})$ returning a 3D vector $(F_x, F_y, F_z)$ [S2].

**Method:**
The curl of a vector field $\mathbf{F}$ is defined as:
$$ \nabla \times \mathbf{F} = \left( \frac{\partial F_z}{\partial y} - \frac{\partial F_y}{\partial z}, \frac{\partial F_x}{\partial z} - \frac{\partial F_z}{\partial x}, \frac{\partial F_y}{\partial x} - \frac{\partial F_x}{\partial y} \right) $$
[S2]

1.  **Define Step Size:** Set a small constant $h$ (e.g., $10^{-3}$) [S1, unofficial].
2.  **Compute Partial Derivatives:** Use central finite differences to approximate the derivatives of the noise field components.
    *   For $x$-derivatives:
        $$ \frac{\partial F}{\partial x} \approx \frac{F(\mathbf{p} + (h, 0, 0)) - F(\mathbf{p} - (h, 0, 0))}{2h} $$
        [S1, unofficial]
    *   For $y$-derivatives:
        $$ \frac{\partial F}{\partial y} \approx \frac{F(\mathbf{p} + (0, h, 0)) - F(\mathbf{p} - (0, h, 0))}{2h} $$
        [S1, unofficial]
    *   For $z$-derivatives:
        $$ \frac{\partial F}{\partial z} \approx \frac{F(\mathbf{p} + (0, 0, h)) - F(\mathbf{p} - (0, 0, h))}{2h} $$
        [S1, unofficial]
3.  **Calculate Curl Components:** Combine the derivatives to form the velocity vector $\mathbf{u}$:
    $$ u_x = \frac{\partial F_z}{\partial y} - \frac{\partial F_y}{\partial z} $$
    $$ u_y = \frac{\partial F_x}{\partial z} - \frac{\partial F_z}{\partial x} $$
    $$ u_z = \frac{\partial F_y}{\partial x} - \frac{\partial F_x}{\partial y} $$
    [S1, unofficial][S2]

**Simplifications:**
*   **2D Curl Texture:** If the field is assumed independent of $z$ ($\partial/\partial z = 0$), the curl simplifies to $(\frac{\partial F_z}{\partial y}, -\frac{\partial F_z}{\partial x}, \frac{\partial F_y}{\partial x} - \frac{\partial F_x}{\partial y})$ [S2].
*   **2-Channel Output:** If only the $F_z$ component is non-zero, the curl becomes $(\frac{\partial F_z}{\partial y}, -\frac{\partial F_z}{\partial x}, 0)$, requiring only a single scalar noise channel [S2].
*   **Texture Space Derivatives:** When generating from 2D textures, derivatives are approximated over pixel distances: $\frac{\partial Tex}{\partial x} \approx \frac{Tex(x+1, y) - Tex(x-1, y)}{2/width}$ [S2].

**Normalization and Encoding:**
*   The resulting velocity vector is often normalized by dividing by $\sqrt{2}$ and scaled/biased to the range $[0, 1]$ for storage or rendering: $\mathbf{u}_{final} = \frac{\mathbf{u}}{\sqrt{2}} \cdot 0.5 + 0.5$ [S1, unofficial].
*   If storing in 8-bit formats (e.g., `RGBA32`), values in $[-1, 1]$ must be encoded: $encoded = 0.5 \cdot (value + 1)$, and decoded: $decoded = 2 \cdot encoded - 1$ [S2].

**Pseudocode:**
```python
def curl_noise(pos, noise_func, h=1e-3):
    """
    Computes the curl of a vector noise field at position pos.
    noise_func(p) returns a vec3 (Fx, Fy, Fz).
    """
    # Define perturbation vectors
    dx = vec3(h, 0.0, 0.0)
    dy = vec3(0.0, h, 0.0)
    dz = vec3(0.0, 0.0, h)

    # Evaluate noise field at perturbed positions
    F_pos = noise_func(pos)
    F_dx = noise_func(pos + dx)
    F_dx_neg = noise_func(pos - dx)
    F_dy = noise_func(pos + dy)
    F_dy_neg = noise_func(pos - dy)
    F_dz = noise_func(pos + dz)
    F_dz_neg = noise_func(pos - dz)

    # Compute partial derivatives using central differences
    # dF/dx = (F(x+h) - F(x-h)) / 2h
    dFdx = (F_dx - F_dx_neg) / (2.0 * h)
    dFdy = (F_dy - F_dy_neg) / (2.0 * h)
    dFdz = (F_dz - F_dz_neg) / (2.0 * h)

    # Extract components
    Fx = F_pos.x; Fy = F_pos.y; Fz = F_pos.z
    dFxdx = dFdx.x; dFxdy = dFdx.y; dFxdz = dFdx.z
    dFydx = dFdy.x; dFydy = dFdy.y; dFydz = dFdy.z
    dFzdx = dFdz.x; dFzdy = dFdz.y; dFzdz = dFdz.z

    # Calculate curl components
    # curl = (dFz/dy - dFy/dz, dFx/dz - dFz/dx, dFy/dx - dFx/dy)
    curl_x = dFzdy - dFydz
    curl_y = dFxdz - dFzdx
    curl_z = dFydx - dFxdy

    velocity = vec3(curl_x, curl_y, curl_z)

    # Optional: Normalize and scale to [0, 1]
    # velocity = velocity / sqrt(2.0)
    # velocity = velocity * 0.5 + 0.5

    return velocity
```

## Operating characteristics
*   **Complexity:** $O(1)$ per evaluation, requiring 7 evaluations of the underlying noise function (1 at center, 6 for neighbors) [S1, unofficial].
*   **Memory:** Minimal, as it is an analytical function. If pre-computed as a texture, memory depends on resolution and channel count (e.g., 3 channels for full 3D curl, 2 for simplified 2D) [S2].
*   **Strengths:** Guarantees divergence-free flow, resulting in visually smooth and physically plausible fluid-like motion without simulation [S2].
*   **Limitations:** The approximation of derivatives via finite differences can introduce artifacts if $h$ is too large or too small (precision issues) [S1, unofficial]. The resulting flow is static unless time is varied [S2].
*   **Use Cases:** Particle advection, cloud movement, smoke visualization [S2].

## Background
Curl noise was introduced as a method to generate divergence-free vector fields for visual effects, particularly in computer graphics for simulating fluid-like motion [S2]. It leverages the mathematical property that the curl of any vector field is divergence-free [S1, unofficial][S2]. The technique is often implemented using Perlin or Simplex noise as the base scalar field [S2].
