# Vortex Flow Function

Also called: Helical Path Animation, Spiral Vortex Function, helical turbulence, swirling gas animation, vortex function

## Overview
The Vortex Flow Function is a procedural technique for generating gas animation by moving sample points through a static noise space along a helical or rotational path, optionally modified by noise to simulate turbulence [S1, unofficial]. It solves the problem of creating convincing swirling, rising, or rolling gas motion (such as steam, fog, or smoke) without requiring expensive fluid simulation data [S1, unofficial]. It sets itself apart from static procedural volumes by introducing time-dependent spatial deformation, and from other flow methods like [Spot Noise](2959-spot-noise.md) by explicitly modeling rotational dynamics around an axis rather than just advection along a fixed vector field.

## How it works
The method consists of two primary variants described in the sources: a **Helical Path Animation** (for rising/rolling gas) and a **Rotational Vortex Function** (for localized swirling vortices). Both variants use a base noise function (e.g., turbulence) evaluated at a displaced position to determine density or flow.

### Inputs and Outputs
*   **Inputs:**
    *   `pnt` or `pt`: The 3D input point (float3).
    *   `frame_num`: The current animation frame index (integer).
    *   `ff->center`: The center position of the vortex (float3).
    *   `ff->axis`: The axis of rotation (float3, typically normalized).
    *   `ff->distance`: The maximum radius of vortex influence (float).
    *   `ff->falloff_start`: The distance inside which the vortex has full strength (float).
    *   `ff->parms`: An array of parameters controlling behavior (see Parameters).
    *   `fast_noise(pnt)`: A fast noise function returning a scalar value.
    *   `fast_turbulence(dir)`: A turbulence function returning a scalar value.
*   **Outputs:**
    *   `*density`: The resulting density value (float).
    *   `path`: A direction vector representing the flow displacement (float3).
    *   `*percent_to_use`: A falloff factor for the vortex strength (float).
    *   `*velocity`: A velocity multiplier (float).

### Data Structures
*   **Precomputed Tables:**
    *   `pow_table[POW_TABLE_SIZE]`: Maps turbulence values to density using a power curve.
    *   `ramp[RAMP_SIZE]`: Maps radial distance from the volume center to a falloff factor.
    *   `offset[OFFSET_SIZE]`: A static array used for vertical ramping variation.
*   **State Variables (Static/Per-Frame):**
    *   `theta`: Current rotation angle.
    *   `down`: Vertical offset for helical path.
    *   `cos_theta2`, `sin_theta2`: Precomputed elliptical path components.
    *   `calcd`: Boolean flag indicating if static tables have been initialized.

### Parameters
*   `SWIRL_FRAMES`: Number of frames for one full 360-degree swirl cycle.
*   `SWIRL`: Constant scaling factor for the swirl angle.
*   `RAD1`, `RAD2`: Constants determining the elliptical shape of the swirling path.
*   `DOWN`: Constant scaling factor for vertical movement.
*   `ff->parms[0]`: Coefficient for the rotation angle calculation (base speed).
*   `ff->parms[1]`: Exponent for the distance-based rotation angle falloff (also used as vertical ramp multiplier in Helical variant).
*   `ff->parms[2]`: Maximum strength of the vortex.
*   `ff->parms[3]`: Coefficient for vertical offset variation.
*   `ff->parms[4]`: Frame number at which the vortex strength begins to increase.
*   `ff->parms[5]`: Frame number at which the vortex strength reaches its maximum.
*   `ff->distance`: Maximum radius of vortex influence.
*   `ff->falloff_start`: Distance inside which vortex has full strength.

### Steps: Helical Path Animation
This variant creates upward (or downward) swirling movement by displacing the sample point along a helix before evaluating noise.

1.  **Initialization (Static, once):**
    *   Compute `theta = (frame_num % SWIRL_FRAMES) * SWIRL`.
    *   Compute `down = frame_num * DOWN * 3.0 + 4.0`.
    *   Compute `cos_theta2 = RAD1 * cos(theta) + 2.0`.
    *   Compute `sin_theta2 = RAD2 * sin(theta) - 2.0`.
    *   Populate `pow_table`: For `i` from `POW_TABLE_SIZE-1` down to `0`:
        $$ pow\_table[i] = \left( \frac{i}{POW\_TABLE\_SIZE - 1} \times parms[1] \times 2.0 \right)^{parms[2]} $$
    *   Populate `ramp` table using `make_ramp_table(ramp)`.

2.  **Calculate Displacement Direction:**
    *   Get noise value: `tmp = fast_noise(pnt)`.
    *   Compute direction vector:
        $$ direction.x = pnt.x + cos\_theta2 + tmp $$
        $$ direction.y = pnt.y - down + tmp $$
        $$ direction.z = pnt.z + sin\_theta2 + tmp $$

3.  **Evaluate Turbulence:**
    *   `turb = fast_turbulence(direction)`.

4.  **Map to Density:**
    *   `*density = pow_table[(int)(turb * 0.5 * (POW_TABLE_SIZE - 1))]`.

5.  **Apply Radial Falloff:**
    *   Calculate distance squared from volume center: `XYZ_SUB(diff, vol.shape.center, pnt_world)`, `dist_sq = DOT_XYZ(diff, diff)`.
    *   `density_max = dist_sq * vol.shape.inv_rad_sq.y`.
    *   Add variation: `indx = (int)((pnt.x + pnt.y + pnt.z) * 100) & (OFFSET_SIZE - 1)`, `density_max += parms[3] * offset[indx]`.
    *   If `density_max >= 0.25`:
        *   `i = (density_max - 0.25) * 4 / 3 * RAMP_SIZE`.
        *   `i = MIN(i, RAMP_SIZE - 1)`.
        *   `density_max = ramp[i]`.
        *   `*density *= density_max`.

6.  **Apply Vertical Falloff:**
    *   `dist = pnt_world.y - vol.shape.center.y`.
    *   If `dist > 0.0`:
        *   `dist = (dist + offset[indx] * 0.1) * vol.shape.inv_rad.y`.
        *   If `dist > 0.05`:
            *   `offset2 = (dist - 0.05) * 1.111111`.
            *   `offset2 = 1 - (exp(offset2) - 1.0) / 1.718282`.
            *   `offset2 *= parms[1]`.
            *   `*density *= offset2`.

### Steps: Rotational Vortex Function
This variant calculates a flow vector (`path`) based on rotation around a vortex axis, suitable for wake effects or localized vortices.

1.  **Calculate Distance from Center:**
    *   `XYZ_SUB(diff, pt, ff->center)`.
    *   `dist = sqrt(DOT_XYZ(diff, diff))`.
    *   `dist2 = dist / ff->distance`.

2.  **Calculate Rotation Angle:**
    *   $$ theta = \frac{ff->parms[0] \times (1 + 0.001 \times frame\_num)}{pow(0.1 + dist2 \times 0.9, ff->parms[1])} $$
    *   *Note: A more physically realistic variant uses conservation of angular momentum where $theta = C / r$ [S1, unofficial].*

3.  **Transform Point:**
    *   Generate rotation matrix `mat` about `ff->axis` using angle `theta`: `calc_rot_mat(theta, ff->axis, mat)`.
    *   Transform point: `transform_XYZ(1, mat, pt, &pt2)`.

4.  **Calculate Path Vector:**
    *   `XYZ_SUB(dir, pt2, pt)`.
    *   `path->x = dir.x; path->y = dir.y; path->z = dir.z;`.

5.  **Calculate Strength Ramp (Time):**
    *   If `frame_num < ff->parms[4]`: `ratio_mult = 0`.
    *   Else if `frame_num <= ff->parms[5]`:
        $$ ratio\_mult = \frac{frame\_num - ff->parms[4]}{ff->parms[5] - ff->parms[4]} \times ff->parms[2] $$
    *   Else: `ratio_mult = ff->parms[2]`.

6.  **Calculate Falloff Factor (Space):**
    *   If `dist > ff->distance`:
        *   `*percent_to_use = 0`.
        *   `*velocity = 1`.
    *   Else if `dist < ff->falloff_start`:
        *   `*percent_to_use = 1.0 * ratio_mult`.
        *   `*velocity = 1.0 + (1.0 - (dist / ff->falloff_start))`.
    *   Else:
        *   `d2 = (dist - ff->falloff_start) / (ff->distance - ff->falloff_start)`.
        *   `*percent_to_use = (cos(d2 * \pi) + 1.0) * 0.5 * ratio_mult`.
        *   `*velocity = 1.0 + (1.0 - (dist / ff->falloff_start))`.

import math

def vortex_helical(pnt, frame_num, parms, vol_shape, fast_noise, fast_turbulence):
    """
    Helical Path Animation variant.
    """
    # Constants (assumed global or passed)
    SWIRL_FRAMES = 60
    SWIRL = 2 * math.pi / SWIRL_FRAMES
    RAD1 = 1.0
    RAD2 = 1.0
    DOWN = 0.1
    POW_TABLE_SIZE = 256
    RAMP_SIZE = 64
    OFFSET_SIZE = 256
    
    # Static state
    if not hasattr(vortex_helical, 'initialized'):
        vortex_helical.initialized = True
        vortex_helical.pow_table = [0.0] * POW_TABLE_SIZE
        vortex_helical.ramp = [0.0] * RAMP_SIZE
        vortex_helical.offset = [0.0] * OFFSET_SIZE
        # Initialize tables (simplified)
        for i in range(POW_TABLE_SIZE):
            val = (i / (POW_TABLE_SIZE - 1)) * parms[1] * 2.0
            vortex_helical.pow_table[i] = val ** parms[2]
        # make_ramp_table(vortex_helical.ramp) # Implementation not provided
        # fill_offset(vortex_helical.offset) # Implementation not provided

    theta = (frame_num % SWIRL_FRAMES) * SWIRL
    down = frame_num * DOWN * 3.0 + 4.0
    cos_theta2 = RAD1 * math.cos(theta) + 2.0
    sin_theta2 = RAD2 * math.sin(theta) - 2.0

    tmp = fast_noise(pnt)
    direction = (
        pnt.x + cos_theta2 + tmp,
        pnt.y - down + tmp,
        pnt.z + sin_theta2 + tmp
    )
    
    turb = fast_turbulence(direction)
    density = vortex_helical.pow_table[int(turb * 0.5 * (POW_TABLE_SIZE - 1))]

    # Radial Falloff
    diff = (vol_shape.center.x - pnt.x, vol_shape.center.y - pnt.y, vol_shape.center.z - pnt.z)
    dist_sq = diff[0]**2 + diff[1]**2 + diff[2]**2
    density_max = dist_sq * vol_shape.inv_rad_sq.y
    
    indx = int((pnt.x + pnt.y + pnt.z) * 100) & (OFFSET_SIZE - 1)
    density_max += parms[3] * vortex_helical.offset[indx]
    
    if density_max >= 0.25:
        i = int((density_max - 0.25) * 4 / 3 * RAMP_SIZE)
        i = min(i, RAMP_SIZE - 1)
        density_max = vortex_helical.ramp[i]
        density *= density_max

    # Vertical Falloff
    dist_y = pnt.y - vol_shape.center.y
    if dist_y > 0.0:
        dist_y_norm = (dist_y + vortex_helical.offset[indx] * 0.1) * vol_shape.inv_rad.y
        if dist_y_norm > 0.05:
            offset2 = (dist_y_norm - 0.05) * 1.111111
            offset2 = 1 - (math.exp(offset2) - 1.0) / 1.718282
            offset2 *= parms[1]
            density *= offset2
            
    return density

def vortex_rotational(pt, frame_num, ff, fast_noise):

    # Rotation Matrix (Simplified 3D rotation about axis)

    pt2 = pt # [G] Placeholder: Actual rotation logic depends on specific matrix library or function
    
    dir_vec = (pt2.x - pt.x, pt2.y - pt.y, pt2.z - pt.z)
    path = dir_vec
    
    # Strength Ramp
    if frame_num < ff.parms[4]:
        ratio_mult = 0
    elif frame_num <= ff.parms[5]:
        ratio_mult = ((frame_num - ff.parms[4]) / (ff.parms[5] - ff.parms[4])) * ff.parms[2]
    else:
        ratio_mult = ff.parms[2]
        
    # Falloff
    if dist > ff.distance:
        percent_to_use = 0
        velocity = 1
    elif dist < ff.falloff_start:
        percent_to_use = 1.0 * ratio_mult
        velocity = 1.0 + (1.0 - (dist / ff.falloff_start))
    else:
        d2 = (dist - ff.falloff_start) / (ff.distance - ff.falloff_start)
        percent_to_use = (math.cos(d2 * math.pi) + 1.0) * 0.5 * ratio_mult
        velocity = 1.0 + (1.0 - (dist / ff.falloff_start))
        
    return path, percent_to_use, velocity

### Edge Cases and Pitfalls
*   **Division by Zero:** In the rotational variant, `dist` is used in the denominator of the velocity calculation if `ff->falloff_start` is 0. Ensure `ff->falloff_start` is non-zero or handle `dist=0` explicitly.
*   **Precision:** The `pow_table` index calculation `(int)(turb * 0.5 * (POW_TABLE_SIZE - 1))` assumes `turb` is in the range `[0, 1]`. If `fast_turbulence` returns values outside this range, clamp the index or the input.
*   **Helical Path Direction:** A downward helical path (negative `DOWN` or inverted signs) produces gas rising and swirling in the opposite direction [S1, unofficial].
*   **Angular Momentum Variant:** The standard formula uses frame number and distance. For more realistic motion, replace the angle calculation with $theta = C / r$ (conservation of angular momentum) [S1, unofficial].

Creates a single column of rising smoke by deforming a vertical cylinder, simulating dispersion, turbulence, and swirling motion. ## Operating characteristics
*   **Time Complexity:** $O(1)$ per sample point, as it involves a fixed number of mathematical operations and table lookups.
*   **Memory Complexity:** $O(N)$ for precomputed tables (`pow_table`, `ramp`, `offset`), where $N$ is the table size (e.g., 256).
*   **Performance:** Very fast due to the use of precomputed tables and simple trigonometric functions. Suitable for real-time rendering or high-resolution volume generation.
*   **Strengths:** Produces visually convincing swirling gas effects with minimal computational cost compared to fluid simulation. Easy to animate by varying frame number.
*   **Limitations:** Not a true physical simulation; turbulence is approximated by noise. The "conservation of angular momentum" variant is more realistic but requires careful tuning of constants.
*   **When to Use:** Ideal for steam, smoke, fog, and swirling gas effects where performance is critical and exact physical accuracy is not required.
*   **When Not to Use:** When realistic turbulent flow characteristics (e.g., Karman vortex streets) are needed, as these require complex simulation [S1, unofficial].

## Background
The Vortex Flow Function was introduced in the context of procedural modeling and animation of gases, fluids, and textures. It builds on techniques for creating still images of steam and extends them to animation using helical paths. The method utilizes techniques by Karl Sims [S1, unofficial]. It is part of a family of procedural noise functions used to generate complex visual effects without explicit simulation data.
