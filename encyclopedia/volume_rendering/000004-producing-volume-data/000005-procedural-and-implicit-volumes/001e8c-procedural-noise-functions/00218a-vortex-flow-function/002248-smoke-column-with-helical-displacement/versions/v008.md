# Smoke Column with Helical Displacement


## Overview
Creates a single column of rising smoke by deforming a vertical cylinder, simulating natural dispersion, turbulence, and swirling motion [S1, unofficial]. It differs from its parent [Vortex Flow Function](2538-vortex-flow-function.md) by explicitly combining a height-dependent density falloff and turbulence increase with a vertical helical displacement field to bend and swirl the column, rather than relying solely on rotational flow around a static axis [S1, unofficial].

## How it works
**Inputs:**
- Point position $P = (x, y, z)$ in world or local space [G].
- Cylinder axis direction (typically $Z$ or $Y$) [G].
- Cylinder base radius $R_0$ [G].
- Column height $H$ [G].
- Time parameter $t$ (for animation) [G].
- Helix tightness $k$ and rotation speed $\omega$ [G].
- Procedural noise function $N(x, y, z, t)$ [G].

**Outputs:**
- Density value $\rho$ at point $P$ [G].

**Data Structures:**
- Stateless procedural evaluation; no auxiliary data structures or grids required [G].

**Steps:**
1. **Height Normalization:** Compute normalized height $h = z / H$. If $z < 0$ or $z > H$, return $\rho = 0$ [G].
2. **Helical Displacement:** Apply a vertical helix to displace the point's horizontal coordinates before calculating the distance from the center of the cylinder [S1, unofficial]. Compute radial distance $r = \sqrt{x^2 + y^2}$ and azimuth $\phi = \operatorname{atan2}(y, x)$. Calculate angular offset $\Delta\theta = k \cdot h + \omega \cdot t$. The displaced azimuth is $\phi' = \phi + \Delta\theta$. Because rotation around the cylinder axis preserves radial distance, the distance from the center is $d = r$ [G].
3. **Turbulence:** Increase turbulence as a function of height to simulate air currents [S1, unofficial]. Scale the noise evaluation $N(x, y, z, t)$ by $h$ and add it to the radial distance to simulate turbulent dispersion [G].
4. **Density Calculation:** Decrease density as a function of height to simulate dispersion [S1, unofficial]. Compute $\rho = (1 - h) \cdot \exp\left(-\frac{d_{\text{eff}}^2}{2 R_0^2}\right)$, where $d_{\text{eff}} = r + h \cdot N(x, y, z, t)$ [G].
5. **Boundary Handling:** Points outside the vertical bounds or with negative height return zero density [G].

**Pseudocode:**
```python
import math

def smoke_column_density(P, R0, H, k, omega, t, noise_func):
    x, y, z = P
    if z < 0 or z > H:
        return 0.0
    h = z / H
    r = math.sqrt(x * x + y * y)
    phi = math.atan2(y, x)
    delta_theta = k * h + omega * t
    # Rotation preserves radial distance from the cylinder axis
    d = r
    # Turbulence increases with height to simulate air currents
    noise_val = noise_func(x, y, z, t)
    d_effective = d + h * noise_val
    # Density decreases with height to simulate dispersion
    height_falloff = 1.0 - h
    radial_falloff = math.exp(-(d_effective * d_effective) / (2 * R0 * R0))
    return height_falloff * radial_falloff
```

**Parameters:**
- $R_0$: Base radius. Typical value: Not given in the sources.
- $H$: Column height. Typical value: Not given in the sources.
- $k$: Helix tightness. Typical value: Not given in the sources.
- $\omega$: Rotation speed. Typical value: Not given in the sources.
- Noise function: Procedural noise (e.g., Perlin or simplex noise). Typical value: Not given in the sources [G].

**Pitfalls:**
- Precision at the cylinder axis ($r=0$): `atan2` handles the singularity robustly without division by zero [G].
- Density falloff: Ensure the radial Gaussian width scales appropriately with $R_0$ to avoid overly sharp or diffuse edges [G].

### Gradient Driven Displacement
A displacement technique requiring a monochrome texture map [S3]. The displacement amount is the texture's brightness at each point [S3]. Each point of the fluid is shifted along the gradient of the Surface channel, meaning each point in space could have a different displacement direction [S3]. Suitable for smoke and fire [S3]. The parameter `displ2` specifies the displacement technique, with 'Gradient driven' being one option [S3].

## Operating characteristics
- **Time Complexity:** $O(1)$ per sample, as it is a procedural function [G].
- **Memory Complexity:** $O(1)$, no data structures required [G].
- **Performance:** Fast to evaluate; noise and trigonometric operations add minor overhead compared to simple radial falloffs [G].
- **Strengths:** Simple to implement, produces realistic swirling smoke columns, easily animatable via time parameter [G].
- **Limitations:** Lacks complex internal structures (e.g., eddies) unless enhanced with noise. The helical displacement may not accurately simulate all types of turbulent flow [G].
- **When to use:** When a simple, animated smoke column with swirling motion is needed [G].
- **When not to use:** When complex, non-helical turbulence or detailed internal structures are required [G].

## Background
Described in procedural modeling of gases and fluids [S1, unofficial]. The method is similar to steam rising procedures but adapted for smoke with added helical displacement for bending and swirling [S1, unofficial]. It is used in computer graphics for simulating smoke columns in animations and visual effects [G].
