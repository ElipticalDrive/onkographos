# Procedural Flame Density & Color Shader

Also called: Helical Flame Shader, Ebert Flame Shader

## Overview
This method computes the density and color of a procedural flame volume by deforming a base helical flow path with height-scaled turbulence and applying spatial attenuation ramps. It builds on [Smoke Column with Helical Displacement](2743-smoke-column-with-helical-displacement.md) by adding complex shaping via sine waves and a lookup table, while explicitly handling vertical fading and minimum density thresholds to create a realistic fire appearance. It differs from its parent by introducing a multi-stage attenuation process (horizontal and vertical) and a direct density-to-color mapping that shifts from yellow to red based on density values.

## How it works
### Inputs and Outputs
**Inputs:**
- `pnt`: 3D sampling point in local space.
- `pnt_w`: 3D sampling point in world space.
- `vol`: Volume object containing shape metadata (`b_box.center`, `b_box.inv_rad`, `b_box.inv_rad_sq`, `inv_rad`, `rad`, `shapecenter`) and output color (`color`).
- `parms`: Array of parameters.
  - `parms[1]`: Base density scale / normalization factor.
  - `parms[2]`: Power exponent for the lookup table.
  - `parms[3]`: Offset magnitude for horizontal attenuation.
  - `parms[4]`: Minimum density threshold (below which density is zeroed).
  - `parms[6]`: Vertical range factor for minimum density area.
  - `parms[7]`: Minimum density value for the base area.
  - `parms[8]`: Frequency multiplier for sine shaping.
- `frame_num`: Current animation frame.
- `DOWN_FIRE`: Constant controlling vertical flow speed.
- `POW_TABLE_SIZE`: Size of the power lookup table.
- `OFFSET_SIZE`: Size of the offset lookup table (bitwise mask `OFFSET_SIZE - 1`).

**Outputs:**
- `*density`: Computed scalar density value.
- `vol->color`: RGB color structure.

### Data Structures
- `pow_table`: Array of floats of size `POW_TABLE_SIZE`. Precomputed values for the power function.
- `ramp`: Array of floats of size 200. Precomputed horizontal attenuation values.
- `offset`: Array of floats of size `OFFSET_SIZE`. Spatial offset values.
- `colr`: RGB structure with fields `r`, `g`, `b`.

### Pseudocode
```python
def compute_flame(pnt, pnt_w, vol, parms, frame_num, DOWN_FIRE, POW_TABLE_SIZE, OFFSET_SIZE):
    # 1. Precompute constants for the frame
    theta_fire = 0.0  # Not given in sources; assumed constant or derived from context. 
                      # [G] In the source, theta_fire is used but not defined in the snippet. 
                      # We assume it is a constant or global variable.
    sin_theta = sin(theta_fire)
    cos_theta = cos(theta_fire)
    down = frame_num * DOWN_FIRE - 4.0
    
    cos_theta2 = 0.09 * cos_theta + 2.0
    sin_theta2 = 0.06 * sin_theta - 2.0
    
    # 2. Initialize Power Lookup Table (if not already done)
    # [G] This loop is typically done once per initialization or when parms[2] changes.
    # For a per-sample shader, this table is assumed pre-computed.
    # pow_table[i] = pow((i / (POW_TABLE_SIZE - 1)) * parms[1] * 2.0, parms[2])
    
    # 3. Calculate Turbulence Scaling
    height_ratio = (pnt_w.y - vol.shape.b_box.center.y) * vol.shape.b_box.inv_rad.y
    
    if height_ratio < 0:
        height_ratio = 0.0
    else:
        height_ratio = ease(height_ratio, 0.4, 0.6)
        
    # 4. Perturb Sampling Coordinates
    pnt2_x = pnt.x * 1.75
    pnt2_y = pnt.y * 0.5
    pnt2_z = pnt.z * 0.75
    
    turb_amount = new_turbulence_three(Vector3(pnt2_x, pnt2_y, pnt2_z)) * height_ratio
    
    # 5. Compute Helical Path Direction
    # Note: 'tmp' is used here. In the source, 'tmp' was set to fast_noise(pnt) earlier.
    # [G] The source snippet shows 'tmp' being used in hel_path calculation before it is 
    # re-assigned later. We assume tmp = fast_noise(pnt) at this stage.
    tmp = fast_noise(pnt)
    
    hel_path_x = cos_theta2 + tmp + turb_amount
    hel_path_y = -down - tmp - turb_amount
    hel_path_z = sin_theta2 + tmp + turb_amount
    
    hel_len = norm_xyz(Vector3(hel_path_x, hel_path_y, hel_path_z))
    
    # Add helical path to point to get direction vector
    direction = Vector3(pnt.x, pnt.y, pnt.z) + Vector3(hel_path_x, hel_path_y, hel_path_z)
    
    # 6. Apply Flame Shaping
    tmp = new_turbulence_three(direction)
    
    term1 = (sin((direction.x + tmp) * parms[8]) + 1.25) * 0.4444444444444
    term2 = (sin((direction.z + tmp) * 2.0 * parms[8]) + 1.0) * 0.5
    
    tmp = term1 * term2
    
    # 7. Lookup Density from Power Table
    index = int(tmp * 0.5 * (POW_TABLE_SIZE - 1))
    # Clamp index to table bounds if necessary, though source implies valid range
    density = pow_table[index]
    
    # 8. Horizontal Attenuation
    center = vol.shapecenter
    diff = Vector3(center.x - pnt_w.x, center.y - pnt_w.y, center.z - pnt_w.z)
    dist_sq = dot_xyz(diff, diff)
    density_max = dist_sq * vol.shape.b_box.inv_rad_sq.y
    
    indx = int((pnt.x + pnt.y + pnt.z) * 100) & (OFFSET_SIZE - 1)
    density_max += parms[3] * offset[indx]
    
    if density_max >= 0.25:
        i = int((density_max - 0.25) * 266.66)
        if i > 199:
            i = 199
        density_max = ramp[i]
        density *= density_max
        
    # 9. Vertical Attenuation
    tmp2 = 2.0 * (pnt_w.y - center.y)
    
    if tmp2 > 0.0:
        tmp2 = (tmp2 + offset[indx] * parms[3]) * vol.shape.inv_rad.y
        if tmp2 > 1.0:
            tmp2 = 1.0
            
        if tmp2 > 0.05:
            offset3 = (tmp2 - 0.05) * 1.111111
            offset3 = 1.0 - (exp(offset3) - 1.0) / 1.718282
            density = offset3 * parms[1]
            
    # 10. Zero out density below threshold
    if density < parms[4]:
        density = 0.0
        
    # 11. Handle Minimum Density Area
    if density < parms[7]:
        if pnt_w.y < center.y - parms[6] * vol.shape.rad.y:
            begin_ramp = pnt_w.y - (center.y - parms[6] * vol.shape.rad.y * 0.5)
            
            if begin_ramp > 0:
                begin_ramp = begin_ramp * (vol.shape.b_box.inv_rad.y * 2.0)
                ease_amt = ease(begin_ramp, 0.4, 0.6)
                density = density * ease_amt + (1.0 - ease_amt) * parms[7] * density_max
            else:
                density = parms[7] * density_max
                
    # 12. Calculate Flame Color
    d_color = 1.0 - density * 1.5 / parms[1]
    if d_color < 0.0:
        d_color = 0.0
        
    compl = 1.0 - d_color
    colr_r = 1.0
    colr_g = d_color * 0.2 + compl * 0.85
    colr_b = d_color * 0.2 + compl * 0.5
    
    vol.color = Color(colr_r, colr_g, colr_b)
    
    return density
```

### Edge Cases and Pitfalls
- **Negative Height Ratios:** If `pnt_w.y` is below the bounding box center, `height_ratio` becomes negative, leading to invalid turbulence scaling. Clamped to 0 [S1, unofficial].
- **Horizontal Attenuation Index Overflow:** The index `i` calculated from `density_max` can exceed 199. Clamped to 199 [S1, unofficial].
- **Vertical Attenuation Factor Overflow:** `tmp2` can exceed 1.0. Clamped to 1.0 [S1, unofficial].
- **Low Density Regions:** In the lower region of the flame, density may drop below `parms[7]`. A blending ramp is applied to ensure a minimum density floor, preventing holes in the flame base [S1, unofficial].
- **Undefined `theta_fire`:** The source code uses `theta_fire` but does not define its value or source. [G] It is likely a constant or derived from a global state not shown in the snippet.

## Operating characteristics
- **Time Complexity:** O(1) per sample, assuming lookup tables and noise functions are O(1).
- **Memory Complexity:** O(1) per sample, plus O(POW_TABLE_SIZE + OFFSET_SIZE) for precomputed tables.
- **Strengths:** Produces realistic flame shapes with natural turbulence and fading. Efficient due to lookup tables.
- **Limitations:** Relies on precomputed tables which may not adapt well to dynamic changes in parameters without regeneration. The `theta_fire` dependency is unclear.
- **When to use:** For procedural fire effects in volumetric rendering where performance is critical and static or slowly varying parameters are acceptable.
- **When not to use:** For physically based fire simulation requiring accurate heat transfer or chemical reaction modeling.

## Background
This method originates from David Ebert's work on procedural modeling of gases and fluids. It is part of a series of techniques described in "Procedural Modeling, Animation, and Rendering of Gases, Fluids, and Textures" [S1, unofficial]. The method builds upon earlier helical flow functions and smoke column models, adding complexity through turbulence and attenuation ramps to achieve visual realism.
