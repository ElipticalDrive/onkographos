# Cartoon Cloud Density Generation

Also called: Procedural Cloud Shape

## Overview
Cartoon Cloud Density Generation is a procedural method for generating stylized, cartoon-style cloud densities by combining independent noise sets for macro structure, body puffs, edge details, and flow, combined with geometric envelopes for specific cloud types [S1, unofficial]. It differs from its sibling [Perlin-Worley Noise for Cloud Density](7139-perlin-worley-noise-for-cloud-density.md) by relying on a multi-layered noise composition and explicit geometric shapes (lobes, clusters) rather than a single unified noise field, allowing for distinct stylized appearances consistent with voxel-based games [S1, unofficial].

## How it works
**Inputs and Outputs:**
*   **Inputs:** 3D query point $\mathbf{P} = (x, y, z)$, cloud type identifier `type_id` (integer 1–9), resolution parameters, and strength/detail/disturbance multipliers [S1, unofficial].
*   **Outputs:** A scalar density value in $[0.0, 1.0]$ [S1, unofficial].

**Data Structures:**
*   `_CartoonNoiseSet`: Contains four independent sets of lattice gradient vectors: `macro_lattices`, `body_lattices`, `edge_lattices`, and `flow_lattices` [S1, unofficial]. These are pre-generated and stored for reuse [S1, unofficial].
*   `VolumeResult`: Contains the resulting `density` and `disturbance` arrays as 8-bit linear data [S1, unofficial].

**Steps:**
1.  **Generate Noise Fields:** Compute four fractal value noise fields using the independent lattice sets [S1, unofficial]. The frequencies are scaled by multipliers: macro at $0.10$, body at $0.30$, edge at $0.55$, and flow at $0.25 \times \text{disturbance}$ [S1, unofficial].
2.  **Compute Base Shapes:** Apply `smoothstep` to normalize and threshold the noise fields [S1, unofficial]. `smoothstep(t)` is defined as $3t^2 - 2t^3$ for $t \in [0,1]$, clamped to $[0,1]$ [S1, unofficial].
    *   Broad structure: $\text{broad} = \text{smoothstep}\left(\frac{\text{macro} - 0.27}{0.52}\right)$ [S1, unofficial].
    *   Puffs (body + macro mix): $\text{puffs} = \text{smoothstep}\left(\frac{0.56 \times \text{macro} + 0.44 \times \text{body} - 0.37}{0.38}\right)$ [S1, unofficial].
    *   Rim/Edge detail: $\text{rim} = \text{smoothstep}\left(\frac{\text{edge} - 0.33}{0.48}\right)$ [S1, unofficial].
3.  **Compute Fluffy Composite:** Combine the base shapes into a unified "fluffy" density field [S1, unofficial].
    *   $\text{fluffy} = \text{clip}(0.62 \times \text{puffs} + 0.23 \times \text{broad} + 0.15 \times \text{rim}, 0.0, 1.0)$ [S1, unofficial].
4.  **Compute Vertical Profiles:** Define Gaussian vertical profiles based on the $z$ coordinate [S1, unofficial]. These determine the thickness and height of different cloud layers [S1, unofficial].
    *   Thin (high altitude): $\text{thin} = \exp\left(-\left(\frac{z + 0.04}{0.13}\right)^2\right)$ [S1, unofficial].
    *   Middle: $\text{middle} = \exp\left(-\left(\frac{z + 0.10}{0.30}\right)^2\right)$ [S1, unofficial].
    *   Low: $\text{low} = \exp\left(-\left(\frac{z + 0.28}{0.23}\right)^2\right)$ [S1, unofficial].
5.  **Compute Horizontal Footprint and Clusters:** If the cloud has a finite boundary, use `_broad_footprint(x, y, variation)`; otherwise, use ones (infinite) [S1, unofficial]. Generate 3D lobe clusters using `_lobe_cluster(x, y, z, variation)` and wisp clusters using `_wisp_cluster(x, y, z, variation)` [S1, unofficial]. These use the Soft Union function [S1, unofficial].
6.  **Combine Based on Cloud Type (`type_id`):** The density is assembled differently for each of the 9 cloud types [S1, unofficial].
    *   **Type 1 (Cirrus):** $\text{density} = \text{thin} \times \text{wisps} \times \text{smoothstep}\left(\frac{0.72 \times \text{body} + 0.28 \times \text{edge} - 0.56}{0.30}\right)$ [S1, unofficial].
    *   **Type 9 (Cumulus):** $\text{base} = \text{CumulusBaseShape}(x, y, z)$, $\text{surface} = \text{smoothstep}\left(\frac{0.58 \times \text{fluffy} + 0.42 \times \text{broad} - 0.20}{0.70}\right)$, $\text{density} = \text{SoftUnion}(\text{cluster} \times (0.22 + 0.78 \times \text{fluffy}), 0.68 \times \text{base} \times (0.30 + 0.70 \times \text{surface}))$ [S1, unofficial].
    *   **Cumulonimbus (Else branch):** $\text{anvil} = \text{footprint} \times \exp\left(-\left(\frac{z - 0.48}{0.16}\right)^2\right)$, $\text{density} = \text{SoftUnion}(\text{cluster}, 0.82 \times \text{anvil}) \times (0.40 + 0.60 \times \text{fluffy})$ [S1, unofficial].
7.  **Final Shaping and Quantization:** Apply smoothstep to maintain continuous density and avoid concentric shell artifacts [S1, unofficial]. Quantize into 5 discrete cartoon levels (mapped to 0-1 range) [S1, unofficial]. Blend stepped and shaped densities, apply strength and rim/detail modulation, then clip to $[0.0, 1.0]$ [S1, unofficial].

```python
def smoothstep(t):
    t = max(0.0, min(1.0, t))
    return 3.0 * t**2 - 2.0 * t**3

def soft_union(fields):
    total = max(0.0, min(1.0, sum(fields)))
    return max(0.0, min(1.0, 1.0 - math.exp(-1.12 * total)))

    # Computes weighted sum of Gaussian lobes using Soft Union [G]

        field_sum += w * math.exp(-(dx**2 + dy**2 + dz**2))
    return max(0.0, min(1.0, 1.0 - math.exp(-1.18 * field_sum)))

def cartoon_cloud_density(x, y, z, type_id, strength, detail, disturbance, variation, finite_boundary):
    # 1. Generate noise fields [S1, unofficial]
    macro = fractal_value_noise(x, y, z, variation.macro_lattices, detail * 0.10)
    body = fractal_value_noise(x, y, z, variation.body_lattices, detail * 0.30)
    edge = fractal_value_noise(x, y, z, variation.edge_lattices, detail * 0.55)
    flow = fractal_value_noise(x, y, z, variation.flow_lattices, disturbance * 0.25)

    # 2. Compute base shapes [S1, unofficial]
    broad = smoothstep((macro - 0.27) / 0.52)
    puffs = smoothstep((0.56 * macro + 0.44 * body - 0.37) / 0.38)
    rim = smoothstep((edge - 0.33) / 0.48)

    # 3. Compute fluffy composite [S1, unofficial]
    fluffy = max(0.0, min(1.0, 0.62 * puffs + 0.23 * broad + 0.15 * rim))

    # 4. Compute vertical profiles [S1, unofficial]
    thin = math.exp(-((z + 0.04) / 0.13) ** 2)
    middle = math.exp(-((z + 0.10) / 0.30) ** 2)
    low = math.exp(-((z + 0.28) / 0.23) ** 2)

    # 5. Compute horizontal footprint and clusters [S1, unofficial]
    footprint = variation.broad_footprint(x, y) if finite_boundary else 1.0
    cluster = lobe_cluster(x, y, z, variation)
    wisps = lobe_cluster(x, y, z, variation.wisp_specs)

    # 6. Combine based on cloud type [S1, unofficial]
    if type_id == 1:  # Cirrus
        density = thin * wisps * smoothstep((0.72 * body + 0.28 * edge - 0.56) / 0.30)
    elif type_id == 9:  # Cumulus
        base = variation.cumulus_base_shape(x, y, z)
        surface = smoothstep((0.58 * fluffy + 0.42 * broad - 0.20) / 0.70)
        density = soft_union([cluster * (0.22 + 0.78 * fluffy), 0.68 * base * (0.30 + 0.70 * surface)])
    else:  # Cumulonimbus
        anvil = footprint * math.exp(-((z - 0.48) / 0.16) ** 2)
        density = soft_union([cluster, 0.82 * anvil]) * (0.40 + 0.60 * fluffy)

    # 7. Final shaping and quantization [S1, unofficial]
    shaped = smoothstep((density - 0.07) / 0.62)
    stepped = math.floor(max(0.0, min(1.0, shaped)) * 4.0 + 0.20) / 4.0
    return max(0.0, min(1.0, (0.12 * stepped + 0.88 * shaped) * strength * (0.94 + 0.06 * detail * rim)))
```

**Formulas:**
*   **Soft Union:** Used to merge multiple density fields smoothly [S1, unofficial].
    $$ S(F_1, F_2, \dots) = \text{clip}\left(1 - \exp\left(-1.12 \times \text{clip}\left(\sum F_i, 0, 1\right)\right), 0, 1\right) $$ [S1, unofficial].
*   **Lobe Cluster:** A specific instance of soft union for geometric lobes [S1, unofficial].
    $$ L = \text{clip}\left(1 - \exp\left(-1.18 \times \sum (w_i \times \exp(-\text{dist}_i^2))\right), 0, 1\right) $$ [S1, unofficial].

**Parameters:**
*   **Detail Multiplier:** 0.10 (macro), 0.30 (body), 0.55 (edge), 0.25 * disturbance (flow) [S1, unofficial].
*   **Strength:** Typically in range $[0.0, 2.0]$ [S1, unofficial].
*   **Disturbance:** Typically in range $[0.0, 2.0]$ [S1, unofficial].

**Edge Cases and Pitfalls:**
*   **Concentric Shells:** To avoid artifacts in volume rendering, the texture body must maintain continuous density [S1, unofficial]. Quantization should only be applied in the final shading stage if needed [S1, unofficial].
*   **Boundary Conditions:** For finite cloud regions, the footprint function must handle boundaries to prevent infinite column artifacts along the Z-axis [S1, unofficial].

## Subtopics

### [Blocky Volumetric Clouds](12303-blocky-volumetric-clouds.md)
Blocky Volumetric Clouds is a procedural rendering technique that generates cartoon-style cloud densities by sampling a 2D texture at the cloud layer's Y-coordinate, creating a distinct "blocky" appearance compared to noise-based realistic clouds. It solves the problem of rendering volumetric clouds in a style consistent with voxel-based games while providing simplified lighting calculations. It differs from its sibling [Cartoon Cloud Density Generation](8309-cartoon-cloud-density-generation.md) by relying on a static 2D density map rather than multi-octave noise functions for the base structure.

## Operating characteristics
*   **Time Complexity:** Not given in the sources [S1, unofficial].
*   **Memory Complexity:** Not given in the sources [S1, unofficial].
*   **Strengths:** Produces distinct, stylized cloud shapes suitable for non-photorealistic rendering [S1, unofficial]. The separation of macro, body, and edge noise allows for fine-tuned artistic control [S1, unofficial].
*   **Limitations:** More complex to implement than single-noise methods [S1, unofficial]. The geometric clusters require careful tuning of parameters for different cloud types [S1, unofficial].
*   **When to Use:** Stylized games, voxel-based environments, or any application requiring non-realistic, cartoon-like clouds [S1, unofficial].
