# Cartoon Cloud Density Generation

Also called: Procedural Cloud Shape

## Overview
Cartoon Cloud Density Generation is a procedural method for generating cartoon-style cloud densities using independent noise sets for macro structure, body puffs, edge details, and flow, combined with geometric envelopes for specific cloud types [S1, unofficial]. It differs from its sibling [Blocky Volumetric Clouds](12303-blocky-volumetric-clouds.md) by relying on multi-octave noise functions for the base structure rather than a static 2D density map [S1, unofficial].

## How it works
**Inputs and Outputs:**
- `x, y, z`: Normalized 3D coordinates in the cloud volume.
- `type_id`: Integer identifier for the cloud type (1–9) [S1, unofficial].
- `variation`: Seed or parameter set controlling shape variation and lobe positions [S1, unofficial].
- `strength`: Global density multiplier, typically $0.0 \le strength \le 2.0$ [S1, unofficial].
- `disturbance`: Flow disturbance intensity, typically $0.0 \le disturbance \le 2.0$ [S1, unofficial].
- `detail`: Detail intensity, typically $0.0 \le detail \le 2.0$ [S1, unofficial].
- `finite_boundary`: Boolean indicating if the cloud is constrained within a finite weather region [S1, unofficial].
- Output: `density`, a scalar value in $[0.0, 1.0]$ representing the final cartoon cloud density [S1, unofficial].

**Data Structures:**
- `_CartoonNoiseSet`: Contains four independent, non-overlapping noise lattice sets: `macro_lattices`, `body_lattices`, `edge_lattices`, `flow_lattices` [S1, unofficial]. Each lattice is a tuple of vectors defining the noise field structure [S1, unofficial].
- `CloudShapeVariation`: Contains parameters for lobe cluster positions, wisp cluster positions, and footprint shape parameters [S1, unofficial].

**Numbered Steps:**
1. Generate four noise fields using fractal value noise with specific frequency multipliers: `macro` (detail × 0.10), `body` (detail × 0.30), `edge` (detail × 0.55), and `flow` (disturbance × 0.25) [S1, unofficial].
2. Compute three base shapes using smoothstep thresholds: `broad` from `macro`, `puffs` from a weighted combination of `macro` and `body`, and `rim` from `edge` [S1, unofficial].
3. Combine the base shapes into a `fluffy` composite density using weights 0.62, 0.23, and 0.15, clipped to $[0.0, 1.0]$ [S1, unofficial].
4. Compute three Gaussian vertical profiles (`thin`, `middle`, `low`) centered at different normalized $z$ coordinates [S1, unofficial].
5. Compute the `footprint` (1.0 if not finite boundary, otherwise `_broad_footprint`), `cluster`, and `wisps` [S1, unofficial].
6. Combine the components into a base `density` based on `type_id`: Type 1 uses `thin`, `wisps`, and a body/edge blend; Type 9 uses a cumulus base, surface smoothstep, and a soft union of cluster and base; other types use a cumulonimbus anvil profile combined with cluster and fluffy [S1, unofficial].
7. Apply a final smoothstep to `density` to maintain continuous density, quantize the result into 5 discrete cartoon levels, blend it back with the continuous version, scale by `strength` and a rim/detail factor, and clip to $[0.0, 1.0]$ [S1, unofficial].

**Formulas:**
- **Soft Union:** $S(F_1, F_2, \dots) = \text{clip}\left(1 - \exp\left(-1.12 \times \text{clip}\left(\sum F_i, 0, 1\right)\right), 0, 1\right)$ [S1, unofficial].
- **Lobe Cluster:** $L = \text{clip}\left(1 - \exp\left(-1.18 \times \sum (w_i \times \exp(-\text{dist}_i^2))\right), 0, 1\right)$, where $w_i$ and $\text{dist}_i$ are derived from `variation` [S1, unofficial].

**Parameters:**
- `detail`: Controls noise frequency. Typical range $[0.0, 2.0]$ [S1, unofficial].
- `disturbance`: Controls flow noise frequency. Typical range $[0.0, 2.0]$ [S1, unofficial].
- `strength`: Global density multiplier. Typical range $[0.0, 2.0]$ [S1, unofficial].

**Edge Cases and Pitfalls:**
- **Concentric Shells:** Volume rendering artifacts (concentric sphere shells) are avoided by keeping the texture body as continuous density and applying quantization only in the final stage [S1, unofficial].
- **Finite Boundaries:** When `finite_boundary` is true, the footprint must be computed to prevent infinite cloud columns along the Z-axis [S1, unofficial].

**Pseudocode:**
```python
import math
import numpy as np

def _smoothstep(t):
    t = np.clip(t, 0.0, 1.0)
    return t * t * (3.0 - 2.0 * t)

def _soft_union(f1, f2):
    total = np.clip(f1 + f2, 0.0, 1.0)
    return np.clip(1.0 - np.exp(-total * 1.12), 0.0, 1.0)

def _lobe_cluster(x, y, z, variation):
    # Positions and weights are drawn from variation; standard Gaussian lobe summation
    field_sum = 0.0
    for pos, weight in variation.lobe_params:
        dist_sq = (x - pos[0])**2 + (y - pos[1])**2 + (z - pos[2])**2
        field_sum += weight * math.exp(-dist_sq)
    return np.clip(1.0 - np.exp(-field_sum * 1.18), 0.0, 1.0)

def _fractal_value_noise(lattices, scale):
    # Standard fractal Brownian motion using provided lattices and scale [G]
    return sum(math.sin(p[0] * scale + p[1]) * p[2] for p in lattices)

def cartoon_cloud_density(x, y, z, type_id, variation, strength, disturbance, detail, finite_boundary):
    # 1. Generate noise fields
    macro = _fractal_value_noise(variation.macro_lattices, detail * 0.10)
    body = _fractal_value_noise(variation.body_lattices, detail * 0.30)
    edge = _fractal_value_noise(variation.edge_lattices, detail * 0.55)
    flow = _fractal_value_noise(variation.flow_lattices, disturbance * 0.25)

    # 2. Compute base shapes
    broad = _smoothstep((macro - 0.27) / 0.52)
    puffs = _smoothstep((0.56 * macro + 0.44 * body - 0.37) / 0.38)
    rim = _smoothstep((edge - 0.33) / 0.48)

    # 3. Compute fluffy composite
    fluffy = np.clip(0.62 * puffs + 0.23 * broad + 0.15 * rim, 0.0, 1.0)

    # 4. Compute vertical profiles
    thin = np.exp(-((z + 0.04) / 0.13) ** 2)
    middle = np.exp(-((z + 0.10) / 0.30) ** 2)
    low = np.exp(-((z + 0.28) / 0.23) ** 2)

    # 5. Compute footprint and clusters
    footprint = np.ones_like(x) if not finite_boundary else variation.broad_footprint(x, y)
    cluster = _lobe_cluster(x, y, z, variation)
    wisps = variation.wisp_cluster(x, y, z)

    # 6. Combine based on type_id
    if type_id == 1:  # Cirrus
        density = thin * wisps * _smoothstep((0.72 * body + 0.28 * edge - 0.56) / 0.30)
    elif type_id == 9:  # Cumulus
        base = variation.cumulus_base(x, y, z)
        surface = _smoothstep((0.58 * fluffy + 0.42 * broad - 0.20) / 0.70)
        density = _soft_union(cluster * (0.22 + 0.78 * fluffy), 0.68 * base * (0.30 + 0.70 * surface))
    else:  # Cumulonimbus / others
        anvil = footprint * np.exp(-((z - 0.48) / 0.16) ** 2)
        density = _soft_union(cluster, 0.82 * anvil) * (0.40 + 0.60 * fluffy)

    # 7. Final shaping and quantization
    shaped = _smoothstep((density - 0.07) / 0.62)
    stepped = np.floor(np.clip(shaped, 0.0, 1.0) * 4.0 + 0.20) / 4.0
    return np.clip((0.12 * stepped + 0.88 * shaped) * strength * (0.94 + 0.06 * detail * rim), 0.0, 1.0)
```

## Subtopics

### [Blocky Volumetric Clouds](12303-blocky-volumetric-clouds.md)
A procedural rendering technique that generates cartoon-style cloud densities by sampling a 2D texture at the cloud layer's Y-coordinate, creating a distinct "blocky" appearance. Choose it when rendering volumetric clouds in a style consistent with voxel-based games while prioritizing simplified lighting calculations over noise-based detail.

### [Procedural Volume Rendering with Noise Perturbation](1370-procedural-volume-rendering-with-noise-perturbation.md)
Uses noise perturbation for realistic clouds. Choose it when realism is desired over stylized or cartoon aesthetics.
