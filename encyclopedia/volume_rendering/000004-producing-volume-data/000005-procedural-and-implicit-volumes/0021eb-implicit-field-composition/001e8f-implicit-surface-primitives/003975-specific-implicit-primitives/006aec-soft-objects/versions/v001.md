# Soft Objects

Also called: Wyvill Soft Objects

## Overview
Soft Objects are a class of implicit surface primitives defined by a bounded, exponentially-decaying field function attributed to the Wyvill brothers [S1, unofficial]. They solve the problem of creating smooth, organic shapes that can be easily morphed and deformed by adjusting control primitive attributes [S1, unofficial]. Unlike Meta balls, which require square root computations for distance normalization, Soft Objects rely solely on squared distances, offering a slight computational advantage [S1, unofficial].

## How it works
**Inputs and Outputs:**
*   **Input:** A query point $\vec{x}$ in 3D space, and parameters for a control primitive: scaling factor $a$ and maximum influence distance $b$.
*   **Output:** A scalar field value $f(\vec{x})$ representing the contribution of the primitive to the total volume field.

**Data Structures:**
No complex data structures are required for the primitive evaluation itself. The field is computed directly via formula.

**Method:**
The field function is derived from the first few terms of a series expansion of an exponential function, truncated to ensure the field becomes zero beyond a specific distance [S1, unofficial].

1.  Calculate the squared Euclidean distance $d^2$ between the query point $\vec{x}$ and the center of the control primitive $\vec{c}$:
    $$ d^2 = \|\vec{x} - \vec{c}\|^2 $$
2.  Check if the distance exceeds the maximum influence range $b$. If $d^2 > b^2$, the contribution is zero:
    $$ f(\vec{x}) = 0 $$
3.  Otherwise, compute the field value using the scaling factor $a$ and the squared distance:
    $$ f(\vec{x}) = a \left( 1 - \frac{d^2}{b^2} \right)^2 $$
    *Note: The source describes this as "the first few terms in a series expansion of an exponential truncated to restrict the range of influence" [S1, unofficial]. While the explicit polynomial form $(1 - d^2/b^2)^2$ is the standard interpretation of this truncated exponential approximation in this context, the source explicitly states it uses squares of distance to avoid square roots [S1, unofficial].*

**Parameters:**
*   $a$: Scaling factor. Determines the magnitude of the field contribution. Can be negative to subtract volume [S1, unofficial].
*   $b$: Maximum distance. The control primitive has no influence after distance $b$ [S1, unofficial].

**Edge Cases and Pitfalls:**
*   **Precision:** The use of squared distances avoids the computational cost and potential precision issues of square roots required by Meta balls [S1, unofficial].
*   **Boundaries:** The function is continuous and smoothly changing, ensuring no discontinuities at the boundary $d=b$ [S1, unofficial].
*   **Subtraction:** Setting $a < 0$ turns the primitive into a subtractive volume, allowing for constructive geometry operations [S1, unofficial].

**Pseudocode:**
```python
def soft_object_field(x, c, a, b):
    """
    Compute the scalar field value for a Soft Object primitive.
    
    Args:
        x: Query point (vector)
        c: Center of the control primitive (vector)
        a: Scaling factor (scalar)
        b: Maximum influence distance (scalar)
        
    Returns:
        Scalar field value f(x)
    """
    # Calculate squared distance
    dx = x[0] - c[0]
    dy = x[1] - c[1]
    dz = x[2] - c[2]
    d_squared = dx*dx + dy*dy + dz*dz
    
    # Check if outside influence range
    b_squared = b * b
    if d_squared > b_squared:
        return 0.0
    
    # Compute field value using squared distance
    # Formula derived from truncated exponential series expansion
    ratio = d_squared / b_squared
    return a * (1.0 - ratio) * (1.0 - ratio)
```

### [Coral Growth Algorithm](20863-coral-growth-algorithm.md)
A procedural method for generating organic, branching volume data by constructing a hierarchical tree of spheres. It uses Soft Objects for contouring, distinguishing itself by its layer-by-layer generation process governed by collision constraints based on genealogical proximity.

## Operating characteristics
*   **Time Complexity:** $O(1)$ per primitive evaluation, as it involves only basic arithmetic operations (subtraction, multiplication, division).
*   **Memory Complexity:** $O(1)$ per primitive, storing only the center, scaling factor, and influence radius.
*   **Strengths:** Smooth, continuous surfaces; easy morphing and deformation; computationally efficient due to avoidance of square roots; bounded support simplifies culling.
*   **Limitations:** Limited to shapes that can be approximated by the sum of such primitives; less flexible than higher-order implicit functions for complex topologies.
*   **When to use:** Ideal for organic, blob-like shapes requiring smooth transitions and efficient rendering.
*   **When not to use:** When precise distance metrics are required (Meta balls might be preferred for strict SDF properties) or when complex geometric primitives are needed.

## Background
Soft Objects were investigated by the Wyvill brothers and their graduate students in Canada and New Zealand [S1, unofficial]. They explored approximations of Gaussians, animation, and other ideas related to implicit surfaces [S1, unofficial]. While similar to the "blobbies" or "metaballs" developed by others (such as Blinn and Max), the Wyvill group termed their creations "soft objects" [S1, unofficial]. The field function is based on a truncated exponential series expansion, providing a bounded influence range [S1, unofficial].
