# Torus Implicit Function

Also called: Torus SDF, Signed Distance Function (SDF) for Torus, Signed Distance Field (SDF) Torus Primitive, Torus distance, Torus Scalar Field, sdTorus

## Overview
The Torus Implicit Function defines a torus as the zero-level set of a scalar field, typically providing the exact signed Euclidean distance from a query point to the surface of a torus centered at the origin [S1, S6, unofficial][S7].

## How it works
### Inputs and Outputs
- **Input**: A query point $\vec{p} = (p_x, p_y, p_z) \in \mathbb{R}^3$ and torus parameters [S1, S5, S6, unofficial].
- **Output**: A scalar value $d \in \mathbb{R}$ representing the signed distance [S6, unofficial]. $d < 0$ indicates the point is inside the torus, $d > 0$ indicates outside, and $d = 0$ lies on the surface [S6, unofficial].

### Data Structures
No persistent data structures are required for evaluation [G]. The function is stateless and computes the value on-demand [G].

### Parameters
The torus is defined by two radii:
1. **Major Radius ($R$)**: The distance from the center of the torus to the center of the tube [S2, S4, unofficial][S7].
2. **Minor Radius ($r$)**: The radius of the tube itself [S4, unofficial][S7].

Some implementations use diameter and thickness instead of radii [S6, unofficial]. If $t_x$ is the diameter and $t_y$ is the thickness, then $R = t_x / 2$ and $r = t_y / 2$ [S6, unofficial].

### Formula
The exact signed distance $d$ is computed by projecting the point onto the plane of the torus's major ring and measuring the distance to the minor ring's center [S1, S6, unofficial][S7].

Let $\rho$ be the distance of the point's projection onto the plane of the major ring from the axis of revolution [G]. For a torus aligned with the Y-axis (lying in the XZ plane):
$$ \rho = \sqrt{p_x^2 + p_z^2} $$

Define an intermediate 2D vector $\vec{q}$ in the plane containing the axis of revolution and the point's projection:
$$ q_x = \rho - R $$
$$ q_y = p_y $$

The signed distance is the Euclidean distance from $\vec{q}$ to the origin, minus the minor radius:
$$ d = \sqrt{q_x^2 + q_y^2} - r $$

Substituting the definitions:
$$ d = \sqrt{(\sqrt{p_x^2 + p_z^2} - R)^2 + p_y^2} - r $$

If the torus is aligned with the Z-axis (lying in the XY plane), swap $p_y$ and $p_z$ in the $\rho$ calculation or the final distance calculation accordingly [S7].

### Pseudocode
The following implementation computes the exact signed distance for a torus centered at the origin, aligned with the Y-axis (major ring in XZ plane) [S1, S5, S6, unofficial].

```python
import math

def sd_torus(p_x, p_y, p_z, R, r):
    """
    Compute the signed distance from point p to a torus.
    
    Args:
        p_x, p_y, p_z: Coordinates of the query point.
        R: Major radius (distance from torus center to tube center).
        r: Minor radius (tube radius).
        
    Returns:
        Signed distance. Negative if inside, positive if outside.
    """
    # 1. Calculate distance from the Y-axis (projection onto XZ plane)
    rho = math.sqrt(p_x * p_x + p_z * p_z)
    
    # 2. Construct the 2D vector q in the radial plane
    q_x = rho - R
    q_y = p_y
    
    # 3. Calculate Euclidean distance to the tube center line
    dist_to_center_line = math.sqrt(q_x * q_x + q_y * q_y)
    
    # 4. Subtract minor radius to get signed distance to surface
    return dist_to_center_line - r
```

### Edge Cases and Pitfalls
1. **Singularity at Axis**: When $\rho = 0$ (the point lies on the axis of revolution), the term $\sqrt{p_x^2 + p_z^2}$ is zero [G]. The distance formula remains numerically stable because it does not involve division by $\rho$ [G]. However, naive gradient implementations that divide by $\rho$ (e.g., $\frac{x}{\rho}$) will fail [S4, unofficial].
2. **Approximation Failure**: First-order Taylor approximations of the implicit function (e.g., $f(\vec{x}) = (\sqrt{x^2+y^2}-R)^2 + z^2 - r^2$) require normalization by the gradient magnitude [S2, unofficial]. If the gradient magnitude approaches zero (near the center of the torus hole or at specific symmetry points), the approximation becomes inaccurate or undefined [S2, unofficial]. The exact SDF formula avoids this division [G].
3. **Coordinate System Alignment**: The formula depends on the axis of revolution [G]. The sources generally assume the torus lies in the XZ plane (aligned with the Y-axis) or XY plane depending on the coordinate system used in the specific code snippet [S1, S5, S6, unofficial][S7].

## Operating characteristics
- **Time Complexity**: $O(1)$. The evaluation involves a constant number of arithmetic operations, square roots, and absolute values [G].
- **Memory Complexity**: $O(1)$. No storage is required beyond the parameters $R$ and $r$ [G].
- **Strengths**: Provides the exact Euclidean distance, which is crucial for stable sphere tracing and accurate normal estimation via the gradient of the SDF [G].
- **Limitations**: Requires a square root operation, which is more expensive than simple polynomial evaluations, though modern hardware handles this efficiently [G]. It is only applicable to perfect tori; deformed tori require different methods [G].

## Background
The signed distance function for a torus is a standard primitive in Signed Distance Field (SDF) rendering and ray marching [G]. It was popularized in the computer graphics community by Inigo Quilez, who provided efficient implementations and geometric derivations for common primitives [S6, unofficial]. The geometric derivation relies on the torus being the product of two circles, allowing the distance to be decomposed into radial and axial components [S7].
