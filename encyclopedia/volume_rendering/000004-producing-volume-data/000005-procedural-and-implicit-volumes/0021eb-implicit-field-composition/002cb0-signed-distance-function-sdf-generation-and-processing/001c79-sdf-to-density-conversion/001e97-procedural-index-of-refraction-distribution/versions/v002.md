# Procedural Index of Refraction Distribution

Also called: Mirage Simulation via Non-Uniform IOR

## Overview
Procedural Index of Refraction Distribution generates a spatially varying index of refraction (IOR) field to simulate optical phenomena such as mirages, where IOR decreases with increasing temperature [S1, unofficial]. It builds on [SDF to Density Conversion](1282-sdf-to-density-conversion.md) by explicitly modeling refractive properties rather than just absorption or emission, enabling ray bending effects [S1, unofficial][S2].

## How it works
**Inputs:**
- A 3D grid of vertical coordinates $z$ [G].

**Outputs:**
- A 3D scalar field $n(x, y, z)$ representing the index of refraction at each point [G].

**Steps:**
1. **Define Normal Lapse Layer:**
   Compute the normal lapse profile where the IOR decreases exponentially with height $z$ using the formula:
   $$ n_{\text{normal}}(z) = 0.95 \times 2^z $$
   This profile models the standard atmospheric temperature gradient [S1, unofficial].

2. **Define Inversion Layer:**
   Compute the inversion profile using the formula:
   $$ n_{\text{inversion}}(z) = 0.8^z $$
   This profile models a temperature inversion layer [S1, unofficial].

3. **Combine Layers:**
   Compute the final IOR profile by taking the element-wise minimum of the two layers at each height $z$:
   $$ n_{\text{combined}}(z) = \min(n_{\text{normal}}(z), n_{\text{inversion}}(z)) $$
   This combination enforces the physical constraints of both atmospheric models [S1, unofficial].

4. **Apply Ground Boundary Condition:**
   For any position where $z < 0$ (below ground level), clamp the IOR to $1.0$:
   $$ n(x, y, z) = \begin{cases} 1.0 & \text{if } z < 0 \\ n_{\text{combined}}(z) & \text{if } z \ge 0 \end{cases} $$
   This prevents unphysical refraction values in the ground region [S1, unofficial].

**Pseudocode:**
```python
def compute_ior_field(z_grid):
    """
    Computes the procedural index of refraction distribution from a 3D grid of vertical coordinates.
    
    Args:
        z_grid: 3D array-like of vertical coordinates.
        
    Returns:
        3D array of index of refraction values.
    """
    ior_field = []
    for i in range(len(z_grid)):
        row = []
        for j in range(len(z_grid[i])):
            col = []
            for k in range(len(z_grid[i][j])):
                z = z_grid[i][j][k]
                if z < 0:
                    col.append(1.0)
                else:
                    normal_layer = 0.95 * (2.0 ** z)
                    inversion_layer = 0.8 ** z
                    col.append(min(normal_layer, inversion_layer))
            row.append(col)
        ior_field.append(row)
    return ior_field
```

**Parameters:**
- Base coefficients: $0.95$ for normal lapse and $0.8$ for inversion [S1, unofficial].
- Exponent bases: $2$ for normal lapse and $0.8$ for inversion [S1, unofficial].
- Ground threshold: $z = 0$ [S1, unofficial].

**Edge Cases:**
- **Ground Transition:** The hard clamp at $z = 0$ creates a discontinuity in the IOR gradient, which may require careful handling during ray marching to avoid numerical artifacts [S1, unofficial].

## Subtopics

### Extinction and Refraction Reconstruction
This variant reconstructs extinction coefficients per wavelength and refractive index to match target images, implicitly defining volume shape via varying refractive index [S2]. Refraction indices are generated using a random process restricted to the inside of a glass sphere [S2]. Per-pixel weights concentrate importance on main parts of user images, leading to less constrained boundaries and more variable shapes [S2]. The volume does not scatter or emit light ($L_m = 0$) [S2]. A pitfall is that intermediate views appear randomly colored during optimization due to refraction [S2]. It is used to demonstrate complex shape construction and compatibility with bent rays [S2].

## Operating characteristics
- **Time Complexity:** Not given in the sources.
- **Memory Complexity:** Not given in the sources.
- **Strengths:** Efficiently simulates mirage-like effects without explicit particle systems [S1, unofficial]. Compatible with continuous refraction models [S2].
- **Limitations:** Random color artifacts can occur in intermediate views during optimization [S2].
- **When to use:** When simulating atmospheric mirages or stylized refractive volumes with simple geometric constraints [S1, unofficial][S2].

## Background
The method originates from techniques for simulating mirages by creating a non-uniform distribution of the index of refraction in air, where IOR decreases with increasing temperature [S1, unofficial]. It has been adapted for volume stylization, where refraction indices are generated via random processes to match target images, demonstrating the expressiveness of refractive volumes in computer graphics [S2].
