# Hierarchical Volume Sampling for UDFs

Also called: UDF importance sampling, VRP-UDF hierarchical sampling

## Overview
Hierarchical Volume Sampling for UDFs upsamples points along a ray for Unsigned Distance Function (UDF) volume rendering to mitigate sampling bias inherent in standard importance sampling methods [S1]. Unlike Signed Distance Functions (SDFs), UDFs lack an explicit zero-level set distinction, causing standard sampling weight functions to concentrate points erroneously before the actual ray-surface intersection due to cumulative multiplicative effects [S1]. This method mitigates that bias by introducing an auxiliary point sampling prior to refine sampling densities and a uniform upsampling strategy to ensure even point distribution within intervals, thereby improving 3D perception and rendering efficiency [S1].

## How it works
**Inputs:**
- Original sampled points along a ray: $\{q_n\}_{n=1}^{N_1}$ [S1].
- UDF values at these points: $f_u(q_n)$ [S1].
- Interval lengths: $\delta_n = \|q_{n+1} - q_n\|$ [S1].
- Fixed standard deviation parameter: $s$ [S1].
- Number of points to upsample: $N_2$ [S1].
- Auxiliary point sampling prior network: $f_{wp}$ (optional, for bias mitigation) [S1].

**Outputs:**
- Set of $N_2$ upsampled points $\{q'_m\}_{m=1}^{N_2}$ distributed along the ray [S1].

**Data Structures:**
- Array of original points $Q = [q_1, ..., q_{N_1}]$ [S1].
- Array of sampling densities $\tau = [\tau_1, ..., \tau_{N_1}]$ [S1].
- Array of cumulative probabilities $\Omega = [\Omega_1, ..., \Omega_{N_1}]$ [S1].
- Array of uniform random numbers $U = [u_1, ..., u_{N_2}]$ where $u_i \sim \text{Uniform}[0, 1]$ [S1].

**Parameters:**
- $s$: Fixed standard deviation parameter [S1].

**Steps:**
1. **Compute Sampling Densities ($\tau_n$):** For each original point $q_n$, calculate the sampling density $\tau_n$ using the UDF value $f_u(q_n)$ and the fixed standard deviation $s$: $\tau_n = \frac{s \cdot e^{-s \cdot f_u(q_n)}}{(1 + e^{-s \cdot f_u(q_n)})^2}$ [S1].
2. **Refine Densities with Auxiliary Prior (Optional):** If using the auxiliary point sampling prior $f_{wp}$ to mitigate bias, input a window of UDF values around $q_n$ into $f_{wp}$ to obtain a mask value $m_n \in [0, 1]$, representing the probability that the window contains a ray-surface intersection [S1]. Multiply the refined sampling densities $\{\tau_n\}$ by the mask value for subsequent hierarchical sampling [S1]. The network is trained separately using mask images as optimizing objectives to produce binary-like outputs, avoiding circular dependency with the volume rendering prior training [S1].
3. **Compute Cumulative Probabilities ($\Omega_n$):** Calculate the cumulative probability $\Omega_n$ that a new point falls between $q_n$ and $q_{n+1}$: $\Omega(n) = (1 - e^{-\tau_n \delta_n}) \times \prod_{n'=1}^{n-1} e^{-\tau_{n'} \delta_{n'}}$ [S1]. Compute the product term iteratively to avoid numerical underflow [G].
4. **Inverse Transform Sampling:** Generate $N_2$ uniform random numbers $u_m \sim \text{Uniform}[0, 1]$ [S1]. Determine the positions of the $N_2$ upsampled points using $F^{-1}_{\Omega}(u_m)$, where $F^{-1}_{\Omega}$ is the inverse CDF of the sampling weights $\Omega$ [S1].
5. **Uniform Upsampling Strategy:** To correct the non-smooth distribution caused by discrete inverse transform sampling, group the upsampled points that fall within the same interval $[q_n, q_{n+1}]$ into sets $\{q'_{n,1}, q'_{n,2}, ..., q'_{n,m}\}$, where $m$ is the number of points in that interval [S1]. Re-order these $m$ points to be evenly distributed within the interval such that the distance between consecutive points is $\frac{\delta_n}{m+1}$ [S1]. Specifically, for $j=1$ to $m$: $q'_{n,j} = q_n + \frac{j}{m+1} \delta_n$ [S1].

**Pseudocode:**
```python
def hierarchical_volume_sampling_udf(Q, f_u, s, N2, f_wp=None):
    N1 = len(Q)
    tau = [0.0] * N1
    
    # Step 1: Compute sampling densities
    for n in range(N1):
        val = exp(-s * f_u(Q[n]))
        tau[n] = (s * val) / (1 + val)**2

    # Step 2: Refine densities with auxiliary prior
    if f_wp is not None:
        for n in range(N1):
            # Extract local UDF window around q_n [G]
            mask = f_wp(extract_udf_window(Q, n))
            tau[n] *= mask

    # Step 3: Compute cumulative probabilities
    Omega = [0.0] * (N1 - 1)
    prod_term = 1.0
    for n in range(N1 - 1):
        delta_n = norm(Q[n+1] - Q[n])
        Omega[n] = (1 - exp(-tau[n] * delta_n)) * prod_term
        prod_term *= exp(-tau[n] * delta_n)

    # Step 4: Inverse transform sampling
    U = [random.uniform(0, 1) for _ in range(N2)]
    upsampled_points = []
    for u in U:
        cum_prob = 0.0
        for k in range(N1 - 1):
            cum_prob += Omega[k]
            if u <= cum_prob:
                # Linear interpolation within interval [Q[k], Q[k+1]] [G]
                local_u = (u - (cum_prob - Omega[k])) / Omega[k]
                point = Q[k] + local_u * (Q[k+1] - Q[k])
                upsampled_points.append(point)
                break

    # Step 5: Uniform upsampling strategy
    intervals = [[] for _ in range(N1 - 1)]
    for p in upsampled_points:
        for k in range(N1 - 1):
            if Q[k] <= p <= Q[k+1]:
                intervals[k].append(p)
                break

    final_points = []
    for k in range(N1 - 1):
        m = len(intervals[k])
        if m == 0:
            continue
        delta_k = norm(Q[k+1] - Q[k])
        for j in range(1, m + 1):
            final_points.append(Q[k] + (j / (m + 1)) * delta_k)

    return final_points
```

**Edge Cases and Pitfalls:**
- **Sampling Bias:** Standard hierarchical sampling without the auxiliary prior concentrates points erroneously before the intersection due to the cumulative multiplicative effect of high sampling densities in non-intersection regions [S1].
- **Non-Uniform Distribution:** Inverse transform sampling on discrete intervals results in a non-smooth step function for the inverse CDF, leading to highly uneven point distribution and perception degeneration [S1]. The uniform upsampling strategy addresses this [S1].
- **Circular Dependency:** Cannot directly use the trained volume rendering prior for $\tau_n$ because its training relies on hierarchical sampling, which itself suffers from bias. The auxiliary prior $f_{wp}$ is trained independently using mask images [S1].

## Subtopics

### Auxiliary Point Sampling Prior
An auxiliary neural network $f_{wp}$ that acts as a mask function for sampling densities [S1]. It takes a window of UDFs as input and outputs the probability that the window contains a ray-surface intersection [S1]. It is trained similarly to the volume rendering prior but uses mask images as optimizing objectives to produce binary outputs [S1]. The mask value is multiplied with the refined sampling densities $\{\tau_n\}$ for subsequent hierarchical sampling [S1]. Unlike standard hierarchical sampling which concentrates points erroneously before intersection, this prior effectively concentrates upsampled points near the actual intersection [S1].

### Uniform Upsampling Strategy
A post-processing step for inverse transform sampling results [S1]. It groups upsampled points falling within the same interval formed by original sampled points and re-orders them to evenly distribute them within the interval [S1]. This prevents perception degeneration caused by the non-smooth nature of the inverse CDF in discrete sampling [S1].

## Background
Hierarchical volume sampling for UDFs was introduced in the VRP-UDF paper [S1]. It addresses the limitations of NeuS, which uses S-density functions with fixed standard deviations for importance sampling, a method that becomes complex and biased when applied to UDFs due to the lack of an explicit zero-level set [S1]. VRP-UDF identified significant bias in prior tailored weight functions and introduced the auxiliary point sampling prior and uniform upsampling strategy to mitigate it [S1].
