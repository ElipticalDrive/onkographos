# NeUDF Hierarchical Importance Sampling

Also called: NeUDF sampling, ws(t)

## Overview
NeUDF Hierarchical Importance Sampling is a two-stage ray sampling strategy for Unsigned Distance Function (UDF) volume rendering that balances surface reconstruction accuracy with Eikonal loss regularization [S1]. Unlike [Naive UDF Solution (NeuS-based)](6015-naive-udf-solution-neus-based.md) which relies on uniform or simple heuristic sampling, this method hierarchically refines point distribution by first establishing a baseline and then concentrating samples where the UDF value indicates proximity to the surface, ensuring well-balanced gradients on both sides of the implicit surface [S1].

## How it works
**Inputs and Outputs:**
*   **Input:** A ray defined by origin $\mathbf{o}$ and direction $\mathbf{d}$; a UDF network $f(\mathbf{x})$; a transformation function $\Psi$; a monotonic density function $\zeta_s$; a position mapping $p(t)$; $N_{init}=64$ initial samples; $N_{imp}=64$ importance samples; and a mask flag indicating background handling [S1].
*   **Output:** A set of 128 sample points $\{t_i\}_{i=0}^{127}$ along the ray and their corresponding normalized sampling weights $\{w_s''(t_i)\}$ [S1]. If no masks are provided, 32 additional points are returned [S1].

**Data Structures:**
*   **Sample Points:** An array of 128 floating-point distances $t$ along the ray [S1].
*   **Weights:** An array of 128 floating-point values representing the normalized importance weights [S1].

**Steps:**

1.  **Uniform Initialization:** Sample $N_{init}=64$ points uniformly along the ray within the bounding volume [S1].
2.  **Density Calculation:** For each sample point $t_i$, compute the position $p(t_i)$ and apply the transformation $\Psi$ to obtain $\Psi(p(t_i))$ [S1]. Compute the view-invariant sampling density $\tau_s(t_i)$ using the monotonically decreasing function $\zeta_s$:
    $$ \tau_s(t_i) = \zeta_s(\Psi(p(t_i))) $$
    The function $\zeta_s$ satisfies $\zeta_s(d) > 0$ and $\zeta'_s(d) < 0$ for all $d > 0$, ensuring higher density for smaller distances [S1].
3.  **Base Weight Computation:** Compute the unnormalized sampling weight $w_s(t_i)$ for each point using the volume rendering accumulation formula:
    $$ w_s(t_i) = \tau_s(t_i) e^{-\int_0^{t_i} \tau_s(s) ds} $$
    In discrete form, the integral is computed cumulatively from the ray origin [G].
4.  **Neighbor Maximization:** Modify the weights to prevent local minima from suppressing valid samples. For each $i$, compute the modified weight $w'_s(t_i)$:
    $$ w'_s(t_i) = \max\{w_s(t_{i+k}) \mid k \in \{-1, 0, 1\}\} $$
    This takes the maximum of the current weight and its immediate neighbors [S1].
5.  **Normalization:** Normalize the modified weights so they sum to one:
    $$ w_s''(t_i) = \frac{w'_s(t_i)}{\sum_{j=0}^{N_{init}-1} w'_s(t_j)} $$
    This yields the importance sampling distribution for the second stage [S1].
6.  **Importance Sampling:** Perform importance sampling using the distribution $w_s''(t_i)$ to select $N_{imp}=64$ new points [S1].
7.  **Boundary Handling:** If no masks are provided, randomly sample 32 additional points outside the unit sphere to represent the background scene, bringing the total to 160 points [S1].

**Pseudocode:**

```python
import math
import random

def neudf_hierarchical_sampling(ray_origin, ray_direction, udf_net, psi_func, zeta_s_func, num_init=64, num_imp=64, use_mask=True):
    # Step 1: Uniform sampling
    t_uniform = sorted([random.uniform(0.0, 1.0) for _ in range(num_init)])
    
    # Step 2 & 3: Compute density and base weights
    densities = []
    for t in t_uniform:
        pos = [ray_origin[j] + t * ray_direction[j] for j in range(3)]
        transformed = psi_func(pos)
        tau = zeta_s_func(transformed)
        densities.append(tau)
        
    # Compute unnormalized weights w_s(t)
    weights_s = []
    cum_sum = 0.0
    for i, tau in enumerate(densities):
        if i > 0:
            dt = t_uniform[i] - t_uniform[i-1]
            cum_sum += densities[i-1] * dt
        w_s = tau * math.exp(-cum_sum)
        weights_s.append(w_s)
        
    # Step 4: Neighbor maximization
    weights_prime = []
    for i in range(num_init):
        max_w = weights_s[i]
        if i > 0:
            max_w = max(max_w, weights_s[i-1])
        if i < num_init - 1:
            max_w = max(max_w, weights_s[i+1])
        weights_prime.append(max_w)
        
    # Step 5: Normalization
    sum_weights = sum(weights_prime)
    weights_norm = [w / sum_weights for w in weights_prime]
    
    # Step 6: Importance sampling for additional points
    # Build cumulative distribution for discrete sampling
    cdf = []
    acc = 0.0
    for w in weights_norm:
        acc += w
        cdf.append(acc)
        
    t_imp = []
    for _ in range(num_imp):
        r = random.random()
        idx = 0
        while idx < len(cdf) - 1 and cdf[idx] < r:
            idx += 1
        t_imp.append(t_uniform[idx])
        
    # Combine points
    all_t = t_uniform + t_imp
    
    # Step 7: Boundary handling (if no mask)
    if not use_mask:
        t_bg = []
        for _ in range(32):
            # Sample point outside unit sphere
            theta = random.uniform(0, 2 * math.pi)
            phi = random.uniform(0, math.pi)
            r = 1.0 + random.uniform(0.1, 0.5)
            x = r * math.sin(phi) * math.cos(theta)
            y = r * math.sin(phi) * math.sin(theta)
            z = r * math.cos(phi)
            bg_pos = [x, y, z]
            dist = math.sqrt(sum((bg_pos[j] - ray_origin[j])**2 for j in range(3)))
            t_bg.append(dist)
        all_t = all_t + t_bg
        
    return all_t
```

**Parameters:**
*   `num_init`: 64 (initial uniform samples) [S1].
*   `num_imp`: 64 (importance samples) [S1].
*   `zeta_s`: Monotonically decreasing function with $\zeta_s(d) > 0$ and $\zeta'_s(d) < 0$ [S1].
*   `Psi`: Transformation function applied to position or UDF values [S1].

**Edge Cases:**
*   **No Mask:** Requires 32 extra random samples outside the unit sphere for background representation [S1].
*   **Degenerate UDF:** The condition $\zeta'_s(d) < 0$ ensures density remains positive and decreases with distance, preventing singularities at large distances [S1].

## Subtopics

### [Importance Points Sampling](5914-importance-points-sampling.md)
Provides the specific mathematical formulation for the sampling density $\tau_s(t)$ used in the second stage of the hierarchy. It sets itself apart by distributing weights *before* intersection points to balance Eikonal loss gradients, unlike the parent method which focuses on the hierarchical refinement structure itself.

## Operating characteristics
*   **Complexity:** $O(N)$ per ray where $N=128$ (or 160 with background) [S1].
*   **Performance:** The two-stage approach (64 + 64) provides a balance between computational cost and sampling quality [S1].
*   **Strengths:** Improves UDF quality by preventing unbalanced gradient magnitudes on either side of the surface, which is a common issue in UDF rendering [S1]. View-invariant density reduces sensitivity to camera position [S1].
*   **Limitations:** Requires careful tuning of $\zeta_s$ and $\Psi$ [S1].

## Background
NeUDF Hierarchical Importance Sampling was introduced in the NeUDF paper (2023) to address the challenges of training Unsigned Distance Fields with volume rendering [S1].
