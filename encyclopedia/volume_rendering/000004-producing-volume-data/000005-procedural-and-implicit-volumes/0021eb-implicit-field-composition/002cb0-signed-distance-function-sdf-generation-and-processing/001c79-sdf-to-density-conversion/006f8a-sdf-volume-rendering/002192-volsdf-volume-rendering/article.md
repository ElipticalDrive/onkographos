# VolSDF Volume Rendering

Also called: VolSDF Density Transformation, VolumeSDFRenderer

## Overview
VolSDF Volume Rendering performs volume integration using Signed Distance Functions (SDFs) as the underlying geometric representation instead of raw density fields [S2, unofficial]. It addresses optimization instability by converting SDF values into volumetric densities using learnable scaling and shrinking coefficients before applying standard alpha compositing [S4]. Unlike [Volume SDF Rendering](1344-volume-sdf-rendering.md), VolSDF explicitly learns these coefficients to ensure alpha-invariance, meaning the magnitude of the volume density function is globally tied to its sharpness [S4].

## How it works
**Inputs:**
- Ray bundle containing sample points along rays, typically generated by a stratified sampler [S3, unofficial].
- Implicit function (neural network) capable of returning distance and color at query points [S3, unofficial].
- Configuration parameters: `alpha` (scaling), `beta` (sharpness/shrinking), and `white_background` (boolean, default False) [S3, unofficial].

**Outputs:**
- Aggregated color tensor of shape $(N, 3)$ where $N$ is the number of rays [S3, unofficial].
- Optional geometry output (e.g., depth or normals) [S2, unofficial].

**Data Structures:**
- `sample_points`: Tensor of shape $(N \times ppr, 3)$ containing 3D coordinates of samples along $N$ rays with $ppr$ points per ray [S3, unofficial].
- `distances`: Tensor of shape $(N \times ppr, 1)$ containing SDF values [S3, unofficial].
- `colors`: Tensor of shape $(N \times ppr, 3)$ containing RGB colors predicted by the implicit function [S3, unofficial].
- `depth`: Tensor of shape $(N, ppr, 1)$ containing the metric distance from the camera origin to each sample [S3, unofficial].
- `deltas`: Tensor of shape $(N, ppr, 1)$ containing the step size between adjacent samples [S3, unofficial].
- `density`: Tensor of shape $(N, ppr, 1)$ containing the converted volumetric density [S3, unofficial].
- `weights`: Tensor of shape $(N, ppr, 1)$ containing the rendering weights [S3, unofficial].
- `transmittance`: Tensor of shape $(N, ppr, 1)$ containing the accumulated transmittance [S3, unofficial].

**Steps:**

1.  **Sampling:** Generate sample points along the rays using a stratified sampler [S3, unofficial].
2.  **Implicit Query:** Query the implicit function for the signed distance and color at each sample point:
    $$ \text{distance}, \text{color} = \text{implicit\_fn.get\_distance\_color}(\text{sample\_points}) $$
    The output shapes are $(N \times ppr, 1)$ for distance and $(N \times ppr, 3)$ for color [S3, unofficial].
3.  **Depth and Delta Computation:**
    - Extract the depth of each sample from the ray bundle: $\text{depth} = \text{ray\_bundle.sample\_lengths}[\dots, 0]$ with shape $(N, ppr, 1)$ [S3, unofficial].
    - Compute the step size (delta) between adjacent samples along the ray:
      $$ \text{deltas} = \text{get\_deltas\_from\_depth}(\text{depth}) $$
      Shape is $(N, ppr, 1)$ [S3, unofficial].
4.  **SDF to Density Conversion:** Convert the signed distance values to volumetric density using the `sdf_to_density` function with parameters `alpha` and `beta`:
    $$ \text{density} = \text{sdf\_to\_density}(\text{distance}, \alpha, \beta) $$
    The result is reshaped to $(N, ppr, 1)$ [S3, unofficial].
5.  **Weight and Transmittance Computation:**
    - Compute the transmittance $T$ from the deltas and density [S3, unofficial].
    - Compute the rendering weights $W$ using the formula:
      $$ W = T \times (1.0 - \exp(-\text{density} \times \text{deltas} + 10^{-10})) $$
      Shape is $(N, ppr, 1)$ [S3, unofficial].
6.  **Color Aggregation:**
    - Reshape the color tensor to $(N, ppr, C)$ where $C$ is the number of color channels (typically 3) [S3, unofficial].
    - Aggregate the final color $C_{\text{final}}$ using the computed weights and the reshaped colors:
      $$ C_{\text{final}} = \sum_{i=1}^{ppr} W_i \times \text{color}_i $$
      Result shape is $(N, 3)$ [S3, unofficial].
7.  **Background Handling:** If `white_background` is True, add the background color (white) multiplied by the final transmittance to the aggregated color [S3, unofficial].

**Pseudocode:**

```python
import torch

def volsdf_render(implicit_fn, ray_bundle, alpha, beta, white_background=False):
    """
    Renders a scene using VolSDF volume rendering.
    
    Args:
        implicit_fn: Object with method get_distance_color(points) returning (dist, color).
        ray_bundle: Object containing sample_points, sample_lengths, n_pts_per_ray.
        alpha: Scaling parameter for SDF to density conversion.
        beta: Sharpness/shrinking parameter for SDF to density conversion.
        white_background: Boolean flag for background color.
        
    Returns:
        color: Tensor of shape (N, 3) with aggregated RGB colors.
    """
    # 1. Sample points are already provided in ray_bundle.sample_points
    # Shape: (N * ppr, 3)
    sample_points = ray_bundle.sample_points
    
    # 2. Query implicit function for distance and color
    # Shape: (N * ppr, 1) for dist, (N * ppr, 3) for color
    dist_flat, color_flat = implicit_fn.get_distance_color(sample_points)
    
    # 3. Extract depth and compute deltas
    # sample_lengths shape: (N, ppr, 2) or similar, we take the first component as depth
    depth = ray_bundle.sample_lengths[..., 0] # Shape: (N, ppr, 1)
    
    # Compute deltas between adjacent samples
    deltas = torch.zeros_like(depth)
    if depth.shape[1] > 1:
        deltas[:, 1:, :] = depth[:, 1:, :] - depth[:, :-1, :]
    # deltas[:, 0, :] remains 0, which correctly contributes zero to the first step's alpha accumulation
    
    # 4. Reshape flat tensors to (N, ppr, 1) and (N, ppr, 3)
    dist = dist_flat.view(-1, ray_bundle.n_pts_per_ray, 1)
    color = color_flat.view(-1, ray_bundle.n_pts_per_ray, color_flat.shape[-1])
    
    # 5. SDF to Density Conversion
    # [G] Standard VolSDF conversion formula: sigma = alpha * exp(-beta * |d|)
    density = alpha * torch.exp(-beta * torch.abs(dist)) # Shape: (N, ppr, 1)
    
    # 6. Compute Transmittance and Weights
    # Compute accumulated density * delta
    alpha_comp = density * deltas # Shape: (N, ppr, 1)
    
    # Cumulative sum for transmittance
    cum_alpha = torch.cumsum(alpha_comp, dim=1)
    
    # Transmittance before each sample: T[i] = exp(-sum_{j=0}^{i-1} alpha_comp[j])
    # Shift cum_alpha to the right and prepend 0
    shifted_cum_alpha = torch.cat([torch.zeros_like(cum_alpha[:, :1, :]), cum_alpha[:, :-1, :]], dim=1)
    transmittance = torch.exp(-shifted_cum_alpha) # Shape: (N, ppr, 1)
    
    # Weights: W[i] = T[i] * (1 - exp(-density[i] * deltas[i]))
    weights = transmittance * (1.0 - torch.exp(-alpha_comp + 1e-10)) # Shape: (N, ppr, 1)
    
    # 7. Color Aggregation
    # Final color = sum(W[i] * color[i])
    color_agg = torch.sum(weights * color, dim=1) # Shape: (N, 3)
    
    # 8. Background Handling
    if white_background:
        # Total transmittance after all samples
        final_transmittance = 1.0 - torch.sum(weights, dim=1) # Shape: (N, 1)
        background_color = torch.ones_like(color_agg) # White background
        color_agg = color_agg + final_transmittance * background_color
        
    return color_agg
```

**Parameters:**
- `alpha`: Scaling parameter for SDF to density conversion. Defined in config as `cfg.alpha` [S2, unofficial][S3, unofficial].
- `beta`: Sharpness/shrinking parameter for SDF to density conversion. Defined in config as `cfg.beta` [S2, unofficial][S3, unofficial].
- `white_background`: Boolean flag for background color, default False if not in `cfg` [S3, unofficial].

**Edge Cases and Pitfalls:**
- **Precision:** Add epsilon ($10^{-10}$) to the exponent in weight computation to avoid numerical instability when density or delta is zero [S3, unofficial].
- **Boundaries:** Ensure `deltas` are computed correctly for the first sample (typically 0) and last sample [S3, unofficial].
- **Degenerate Input:** If `ppr` is 1, deltas may be undefined; handle by setting a default step size or skipping integration [G].

## Subtopics

### [NeuS Weight Function](3238-neus-weight-function.md)
The NeuS weight function is a volume rendering technique that derives an unbiased and occlusion-aware weight function $w(t)$ from a Signed Distance Function (SDF) $f(\mathbf{x})$ to reconstruct surfaces from multi-view images without explicit 3D supervision. It solves the problem of geometric bias inherent in standard volume rendering formulations when applied to SDFs, ensuring that the volume-rendered surface aligns precisely with the geometric SDF zero-crossing. Unlike its sibling [U-density Function](3695-u-density-function.md), which focuses on Unsigned Distance Fields, this method specifically addresses the asymmetry of SDFs to prevent the weight function from peaking before the actual surface intersection.

### [U-density Function](3695-u-density-function.md)
The U-density function is a rendering weight function designed for Unsigned Distance Fields (UDF) to ensure globally unbiased volume rendering. It solves the volume-surface gap inherent in naive extensions of Signed Distance Field (SDF) techniques to UDFs, specifically preventing redundant floating faces and irregular noises caused by improper weight distribution. Unlike the NeuS weight function, which violates the unbiased property for UDFs by allowing weight leakage to invisible surfaces, the U-density function concentrates rendering weight near the first surface intersection, ensuring the final color is derived solely from the visible surface geometry.

### [Adaptive Surfaceness Finetuning](4844-adaptive-surfaceness-finetuning.md)
Adaptive Surfaceness Finetuning is a method for refining the density representation in Signed Distance Function (SDF) based volume rendering by making the sharpness parameter $\beta$ spatially adaptive. It solves the problem where a uniform $\beta$ degrades rendering quality near fine-grained or transparent structures by allowing $\beta(\mathbf{x})$ to vary across the scene. Unlike siblings that optimize $\beta$ directly or use fixed functions, this method uses the Eikonal loss as an indicator to increase surfaceness only where the SDF constraint is violated, preventing the model from collapsing into arbitrary density predictions. It builds on [VolSDF Volume Rendering](2551-volsdf-volume-rendering.md).

### [SDF-based Voxel Rendering](3728-sdf-based-voxel-rendering.md)
SDF-based Voxel Rendering determines voxel visibility by evaluating a Signed Distance Function (SDF) at each voxel center; a voxel is drawn if the SDF value is less than or equal to zero. It differs from ray-marching volume rendering by using a discrete grid traversal with a binary occupancy test based on the implicit field, rather than continuous integration of density along rays.

### [Distance-Adjusted Eikonal Loss](5827-distance-adjusted-eikonal-loss.md)
Distance-Adjusted Eikonal Loss is a regularization technique used in Signed Distance Function (SDF) based neural rendering to enforce the geometric validity of the SDF while preventing the regularization from degrading background reconstruction quality. It modifies the standard Eikonal loss by applying per-sample weights inversely proportional to the square of the sample's distance from the camera, thereby downweighting the constraint in far-field regions. This approach allows the model to maintain well-defined surfaces in the foreground while behaving like a standard volume renderer in the background, avoiding the artifacts associated with uniform Eikonal regularization.

## Operating characteristics
- **Time Complexity:** Linear with respect to the number of rays and samples per ray, $O(N \times ppr)$, due to the sequential nature of alpha compositing [S3, unofficial].
- **Memory Complexity:** $O(N \times ppr)$ to store intermediate tensors for distance, color, density, transmittance, and weights [S3, unofficial].

## Background
VolSDF was introduced as a method to improve the optimization of neural implicit surfaces by leveraging the properties of Signed Distance Functions [S4]. It addresses the issue of "fuzzier" volume rendering by learning scaling and shrinking coefficients on the distance-transformed densities [S4]. The method is part of a broader family of neural surface rendering techniques that include NeuS and others [S4]. It is commonly used in 3D reconstruction and novel view synthesis tasks where explicit surface extraction is desired [S2, unofficial].
