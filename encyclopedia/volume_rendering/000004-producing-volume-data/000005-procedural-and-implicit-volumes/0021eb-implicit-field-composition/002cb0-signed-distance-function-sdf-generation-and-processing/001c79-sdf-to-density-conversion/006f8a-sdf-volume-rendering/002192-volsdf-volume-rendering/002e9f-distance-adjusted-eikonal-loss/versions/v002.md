# Distance-Adjusted Eikonal Loss

Also called: Distance-weighted Eikonal Regularization, SDF Radiance Field Parameterization, VolSDF density parameterization, Weighted Eikonal Loss

## Overview
Distance-Adjusted Eikonal Loss is a regularization technique used in Signed Distance Function (SDF) based neural rendering to enforce the geometric validity of the SDF while preventing the regularization from degrading background reconstruction quality [S1, S2]. It modifies the standard Eikonal loss by applying per-sample weights inversely proportional to the square of the sample's distance from the camera, thereby downweighting the constraint in far-field regions [S1]. This approach allows the model to maintain well-defined surfaces in the foreground while behaving like a standard volume renderer in the background, avoiding the artifacts associated with uniform Eikonal regularization [S1].

## How it works
The method operates on a neural network that outputs a signed distance value $d(x)$ for any 3D query point $x$ [S2]. The core mechanism is the application of a weighted Eikonal loss during training [S1, S2].

**Inputs and Outputs:**
*   **Input:** A set of 3D query points $\{x_i\}$ sampled along camera rays, where each $x_i$ has an associated metric distance $d_i$ from the camera origin along the ray [S1, S2].
*   **Output:** A scalar loss value $L_{Eikonal}$ used for backpropagation [S1, S2].

**Data Structures:**
*   **Query Points:** A list or tensor of 3D coordinates $x_i \in \mathbb{R}^3$ [G].
*   **Distances:** A list or tensor of scalar distances $d_i \in \mathbb{R}^+$ corresponding to each $x_i$ [G].
*   **SDF Values:** The network output $d(x_i) \in \mathbb{R}$ [S2].

**Numbered Steps:**
1.  **Sampling:** Efficiently approximate the expectation of the loss by performing stratified sampling across the bounding volume of the scene [S2].
2.  **Distance Calculation:** For each sampled point $x_i$, calculate its metric distance $d_i$ from the camera origin along the viewing ray [S1].
3.  **Weight Calculation:** Compute the per-sample weight $\eta_i$ using the inverse square of the distance:
    $$ \eta_i = d_i^{-2} $$
    [S1]
4.  **Gradient Computation:** Compute the gradient of the SDF output with respect to the input query point $x_i$, denoted as $\nabla_x d(x_i)$ [S2]. This requires double differentiation with respect to the input query points [S2].
5.  **Loss Calculation:** Compute the Eikonal loss for each sample as the squared difference between the norm of the gradient and 1, scaled by the weight $\eta_i$:
    $$ L_{Eikonal} = \sum_i \eta_i \left( \|\nabla_x d(x_i)\| - 1 \right)^2 $$
    [S1, S2]
    *Note: The source [S2] defines the expectation form $L_{Eikonal} = E_x [ (\|\nabla_x d(x)\| - 1)^2 ]$, which is approximated by the summation over samples.*

**Pseudocode:**
```python
import math

def vector_norm(v):
    """Computes the Euclidean norm of a vector."""
    return math.sqrt(sum(x * x for x in v))

def compute_gradient(f, x):
    """Computes the gradient of scalar output f(x) w.r.t. input vector x.
    Requires automatic differentiation support in the network implementation [G]."""
    pass  # Standard autograd engine call

def distance_adjusted_eikonal_loss(sdf_network, query_points, camera_origin):
    """
    Computes the distance-adjusted Eikonal loss.
    Args:
        sdf_network: Callable returning SDF value d(x) for input x.
        query_points: List of 3D coordinates x_i.
        camera_origin: 3D coordinate of the camera.
    Returns:
        loss: Scalar loss value.
    """
    total_loss = 0.0
    for x in query_points:
        # 1. Compute SDF value and its gradient w.r.t. x [S2]
        d_x = sdf_network(x)
        grad_d = compute_gradient(sdf_network, x)
        grad_norm = vector_norm(grad_d)

        # 2. Compute metric distance from camera origin along the ray [S1]
        ray_vec = [x[i] - camera_origin[i] for i in range(3)]
        d_i = vector_norm(ray_vec)

        # 3. Compute weight eta_i = d_i^-2 [S1]
        epsilon = 1e-8
        eta_i = 1.0 / (d_i + epsilon) ** 2

        # 4. Accumulate weighted Eikonal term (||grad|| - 1)^2 [S1, S2]
        total_loss += eta_i * (grad_norm - 1.0) ** 2

    return total_loss
```

**Parameters:**
*   **Weight Exponent:** The exponent in the distance weight is fixed at 2 (i.e., $d_i^{-2}$) [S1].
*   **Initialization:** The SDF is initialized to a unit sphere via pre-training to provide a valid starting geometry [S2].

**Edge Cases and Pitfalls:**
*   **Double Differentiation:** The method requires computing the gradient of the SDF with respect to the input coordinates, which in turn requires the gradient of the network's output with respect to its input. This necessitates a custom bilinear sampling implementation or a network architecture that supports double differentiation with respect to input query points [S2].
*   **Background Artifacts:** Using standard uniform Eikonal weights ($\eta_i=1$) negatively affects background reconstruction [S1]. Applying Eikonal loss in contracted space affects the foreground [S1]. Omitting the loss entirely causes the model to revert to standard NeRF behavior, resulting in poor foreground surface reconstruction [S1].
*   **Precision:** Care must be taken with numerical precision when computing gradients, especially for points far from the camera where distances are large and weights are small [S1, S2].

## Subtopics

### Ray-Eikonal Loss
A ray-based Eikonal regularizer implemented only for the naive baseline SVRaster+SDF [S3, unofficial]. It penalizes deviations from the expected SDF slope along ray segments [S3, unofficial]. For each ray segment intersecting a voxel, it determines the entry $p_{in}$ and exit $p_{out}$ coordinates, evaluates the SDF values $f(p_{in})$ and $f(p_{out})$ via trilinear interpolation of the voxel’s corner SDFs, and computes the directional gradient along the ray as $\frac{f(p_{out}) - f(p_{in})}{\|p_{out} - p_{in}\|_2}$ [S3, unofficial]. The weight for this loss is set to $\lambda_{re} = 10^{-3}$ [S3, unofficial].

## Operating characteristics
*   **Time Complexity:** The method adds a computational overhead proportional to the number of samples $N$ due to the gradient computation [G].
*   **Strengths:** Improves background reconstruction quality without degrading foreground surface quality [S1]. It allows a single model to handle both foreground (SDF) and background (volume) effectively [S1].
*   **Limitations:** Requires careful implementation of gradient computation (double differentiation) [S2]. The choice of weight exponent ($d^{-2}$) is specific to the method and may not be optimal for all scenes [S1].
*   **When to use:** When using SDF-based neural rendering and experiencing background artifacts or poor surface definition due to uniform Eikonal regularization [S1].
*   **When not to use:** When computational resources are extremely limited and the overhead of double differentiation is prohibitive, or when the scene does not have a clear foreground/background distinction requiring different regularization strengths [S1].

## Background
The Distance-Adjusted Eikonal Loss was introduced in the context of neural rendering methods that use Signed Distance Functions (SDFs) to represent surfaces [S1, S2]. It was proposed to address the limitations of standard Eikonal regularization, which tends to negatively impact background reconstruction [S1]. The method builds upon the VolSDF approach, which parameterizes the object surface as an SDF to facilitate surface extraction and provide analytical normals [S2]. The specific distance-adjusted weighting scheme was detailed in HybridNeRF [S1], while the broader context of SDF representation and Eikonal loss in radiance field inversion was presented in [S2].
