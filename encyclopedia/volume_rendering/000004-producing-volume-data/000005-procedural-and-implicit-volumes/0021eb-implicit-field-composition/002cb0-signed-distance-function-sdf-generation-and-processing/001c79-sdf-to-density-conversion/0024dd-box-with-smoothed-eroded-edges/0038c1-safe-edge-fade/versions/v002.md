# Safe Edge Fade

Also called: Continuous Edge Protection, Smoothstep Edge Fade

## Overview
Safe Edge Fade is a boundary condition technique that applies a continuous smoothing function to fade volume density to zero at the edges of a bounding box, preventing the appearance of rectangular blank bands or hard discontinuities [S1, unofficial]. It ensures that the outermost voxels are strictly zero while maintaining continuous attenuation across the transition zone [S1, unofficial].

## How it works
**Inputs and Outputs:**
- Input: A 3D density field and boundary parameters [S1, unofficial].
- Output: A modified density field where density is smoothly interpolated to zero near the boundaries [S1, unofficial].

**Data Structures:**
- The density field is stored as a 3D array [S1, unofficial].
- Parameters are scalar values: `empty_border` and `fade_width` [S1, unofficial].

**Steps:**
1. Calculate the distance from each voxel to the nearest volume boundary: `distance_to_edge` [S1, unofficial].
2. Apply the `smoothstep` function to the normalized distance: `return _smoothstep((np.maximum(distance_to_edge - empty_border, 0.0)) / fade_width)` [S1, unofficial].
3. The `smoothstep` function is defined as: `clipped = np.clip(value, 0.0, 1.0); return clipped * clipped * (3.0 - 2.0 * clipped)` [S1, unofficial].

**Formula:**
The core smoothing function is the standard `smoothstep`:
$$fade = \text{smoothstep}\left(\frac{\max(\text{distance\_to\_edge} - \text{empty\_border}, 0.0)}{\text{fade\_width}}\right)$$
where $\text{smoothstep}(x) = x^2(3-2x)$ [S1, unofficial].

**Parameters:**
- `empty_border`: The distance from the edge within which density is forced to zero [S1, unofficial].
- `fade_width`: The width of the transition zone where density fades from full to zero [S1, unofficial].

**Typical Values:**
- For XY boundaries: `SAFE_EMPTY_BORDER_XY` = 0.0, `SAFE_FADE_WIDTH_XY` = 0.0 [S1, unofficial].
- For Z boundaries: `SAFE_EMPTY_BORDER_Z` = 0.0, `SAFE_FADE_WIDTH_Z` = 0.13 [S1, unofficial].
- Alternative generic values cited: Empty border = 0.0, Fade width = 0.045 [S1, unofficial].

**Pseudocode:**
```python
import numpy as np

def safe_edge_fade(density: np.ndarray, shape: tuple, empty_border: float, fade_width: float) -> np.ndarray:
    D, H, W = shape
    z, y, x = np.meshgrid(np.arange(D), np.arange(H), np.arange(W), indexing='ij')
    dist_x = np.minimum(x, W - 1 - x)
    dist_y = np.minimum(y, H - 1 - y)
    dist_z = np.minimum(z, D - 1 - z)
    distance_to_edge = np.minimum(np.minimum(dist_x, dist_y), dist_z)
    if fade_width == 0.0:
        return density
    normalized_dist = np.maximum(distance_to_edge - empty_border, 0.0) / fade_width
    clipped = np.clip(normalized_dist, 0.0, 1.0)
    fade_factor = clipped * clipped * (3.0 - 2.0 * clipped)
    return density * fade_factor
```

**Edge Cases and Pitfalls:**
- If `fade_width` is 0.0, division by zero occurs; the implementation must handle this case (e.g., by returning the original density) [G].
- Precision issues may arise if `fade_width` is very small relative to voxel size [G].

## Subtopics

### Spherical Ring Density Fall-off
A boundary condition technique for spherical volumes that creates a ring around the sphere where density smoothly interpolates from the interior value to zero, preventing hard edges [S2, unofficial]. It identifies the spherical boundary, defines a ring region near the surface, and interpolates density within the ring to zero at the outer edge, setting density to zero outside the ring [S2, unofficial]. Density bounds are 0 (full transparency) to 1 (full opacity) [S2, unofficial].
