# SDF Fusion

Also called: Projective TSDF Fusion, Single Layer TSDF Update (as the specific integration step within the broader fusion process)

## Overview
SDF Fusion integrates multi-view depth and normal data into a global Truncated Signed Distance Function (TSDF) volume and a weighted color volume by raycasting from camera viewpoints to voxel centers [S1, unofficial]. It differs from algebraic voxelization by using explicit geometric projections from sensor data rather than volumetric back-projection of image pixels, allowing for efficient handling of surface normals and view-dependent weighting to filter out occluded or poorly visible surfaces [S1, unofficial].

## How it works
**Inputs and Outputs:**
*   **Inputs:**
    *   `vol`: A 3D volume of type `BoundedVolume<SDF_t>` storing the current TSDF values and weights.
    *   `colorVol`: A 3D volume of type `BoundedVolume<float>` (or `float4` for RGB) storing the accumulated color values.
    *   `depth`: An image of depth values.
    *   `norm`: An image of surface normal vectors.
    *   `T_cw`: A $3 \times 4$ matrix representing the camera-to-world transformation.
    *   `K`: Camera intrinsic matrix.
    *   `img`: An image of color data (optional, used for color volume update).
    *   `T_iw`: An $3 \times 4$ matrix representing the image/world transformation (if different from camera).
    *   `Kimg`: Image intrinsic matrix.
    *   `trunc_dist`: The truncation threshold for the signed distance.
    *   `max_w`: The maximum allowable weight for a voxel.
    *   `mincostheta`: The minimum cosine of the angle between the view direction and the surface normal.
*   **Outputs:**
    *   Updated `vol` with fused TSDF values.
    *   Updated `colorVol` with fused color values.

**Data Structures:**
*   `SDF_t`: A struct containing:
    *   `d`: A signed distance value (float).
    *   `w`: A weight value (float).
    *   Operations: Constructor `SDF_t(d, w)` that clamps `d` to `[-trunc_dist, trunc_dist]`. Operator `+=` for accumulation. Method `LimitWeight(max_w)` to cap the weight.
*   `BoundedVolume<T>`: A 3D array structure accessed via `vol(x, y, z)`.

**Algorithm Steps:**
1.  **Initialization:** Reset the TSDF volume `vol` such that every voxel is initialized to `SDF_t(trunc_dist, 0)`. This represents an empty space with maximum distance and zero weight [S1, unofficial].
2.  **Iteration:** For each voxel $(x, y, z)$ within the bounded volume:
    a.  **Raycasting:** Cast a ray from the camera center through the voxel center to the depth image.
    b.  **Sampling:** Retrieve the depth $d_{depth}$ and normal $\mathbf{n}$ from the depth/normal images at the intersection point.
    c.  **Distance Calculation:** Compute the signed distance $sd$ from the voxel to the surface. This is typically the difference between the voxel's depth along the ray and the measured depth $d_{depth}$, projected onto the surface normal.
    d.  **Weight Calculation:** Calculate the weight $w$ based on the viewing angle. Specifically, compute the cosine of the angle $\theta$ between the view direction vector $\mathbf{v}$ and the surface normal $\mathbf{n}$: $\cos \theta = \mathbf{v} \cdot \mathbf{n}$.
    e.  **Validation:** Check if $sd$ is finite, $w$ is finite, and $\cos \theta > mincostheta$. If not, skip the update [S1, unofficial].
    f.  **Truncation:** If $|sd| > trunc\_dist$, skip the update [S1, unofficial].
    g.  **Accumulation:**
        i.  Retrieve current volume value: `curvol = vol(x, y, z)`.
        ii. Create new SDF value: `new_sdf = SDF_t(clamp(sd, -trunc_dist, trunc_dist), w)`.
        iii. Add to current: `accumulated = new_sdf + curvol`.
        iv. Limit weight: `final_sdf = accumulated.LimitWeight(max_w)`.
        v.  Store result: `vol(x, y, z) = final_sdf`.
    h.  **Color Update:** If color data is available:
        i.  Retrieve current color: `cur_color = colorVol(x, y, z)`.
        ii. Compute weighted average: `new_color = (w * c + cur_color * curvol.w) / (w + curvol.w)`, where $c$ is the color at the intersection point.
        iii. Store result: `colorVol(x, y, z) = new_color`.

**Pseudocode:**
```python
def sdf_fusion(vol, color_vol, depth_img, norm_img, T_cw, K, img, T_iw, Kimg, trunc_dist, max_w, mincostheta):
    # Step 1: Reset volume
    # Initialize all voxels to (trunc_dist, 0)
    for x, y, z in vol.bounds():
        vol[x, y, z] = SDF_t(trunc_dist, 0)

    # Step 2: Fuse each voxel
    for x, y, z in vol.bounds():
        # Raycast from camera to voxel
        voxel_world_pos = vol.index_to_world(x, y, z)
        ray_origin = T_cw[0:3, 3] # Camera center in world
        ray_direction = voxel_world_pos - ray_origin
        ray_direction = normalize(ray_direction)
        
        # Intersect ray with depth image to get depth and normal
        # This involves projecting the ray into image space and sampling
        depth_val, normal_vec, color_val, valid = raycast_depth_image(
            ray_origin, ray_direction, depth_img, norm_img, img, T_cw, K, T_iw, Kimg
        )
        
        if not valid:
            continue
            
        # Calculate signed distance
        # sd is the distance from voxel to the surface along the normal
        # Assuming depth_val is the distance from camera to surface along ray
        # The voxel is at distance d_voxel from camera along ray
        # sd = (d_voxel - depth_val) * dot(ray_direction, normal_vec)
        # Note: Exact formula depends on coordinate system conventions.
        # A common approach: sd = dot(voxel_world_pos - surface_point, normal_vec)
        surface_point = ray_origin + depth_val * ray_direction
        sd = dot(voxel_world_pos - surface_point, normal_vec)
        
        # Calculate weight based on viewing angle
        costheta = dot(ray_direction, normal_vec)
        
        # Validation checks
        if not is_finite(sd) or not is_finite(costheta):
            continue
        if costheta < mincostheta:
            continue
        if abs(sd) > trunc_dist:
            continue
            
        # Accumulate SDF
        curvol = vol[x, y, z]
        new_sdf = SDF_t(clamp(sd, -trunc_dist, trunc_dist), costheta) # Weight is often cos(theta) or derived from it
        accumulated = new_sdf + curvol
        final_sdf = accumulated.limit_weight(max_w)
        vol[x, y, z] = final_sdf
        
        # Accumulate Color
        cur_color = color_vol[x, y, z]
        total_weight = new_sdf.w + curvol.w
        if total_weight > 0:
            new_color = (new_sdf.w * color_val + curvol.w * cur_color) / total_weight
            color_vol[x, y, z] = new_color
```

**Parameters:**
*   `trunc_dist`: Typical values depend on the scene scale and voxel resolution. Not given in the sources.
*   `max_w`: Not given in the sources.

**Edge Cases and Pitfalls:**
*   If the signed distance is further than `trunc_dist`, the voxel is not updated [S1, unofficial].
*   The update only proceeds if the signed distance, weight, and viewing angle cosine are finite [S1, unofficial].
*   Views with poor visibility (low `costheta`) are filtered out using `mincostheta` [S1, unofficial].

## Operating characteristics
*   **Time Complexity:** $O(V)$, where $V$ is the number of voxels in the bounded volume. Each voxel is processed once per camera view.
*   **Memory Complexity:** $O(V)$ for the TSDF and color volumes.
*   **Performance:** The method is efficient for real-time reconstruction on GPUs due to the parallelizable nature of the voxel updates [S1, unofficial].
*   **Strengths:** Handles surface normals for better quality, filters out noisy or occluded data, integrates color information.
*   **Limitations:** Requires accurate depth and normal data. Performance depends on the volume resolution and size.

## Background
SDF Fusion is a technique used in real-time 3D reconstruction from RGB-D or stereo data. It is part of the broader family of TSDF fusion methods. The specific implementation described here is from an unofficial GitHub repository [S1, unofficial].
