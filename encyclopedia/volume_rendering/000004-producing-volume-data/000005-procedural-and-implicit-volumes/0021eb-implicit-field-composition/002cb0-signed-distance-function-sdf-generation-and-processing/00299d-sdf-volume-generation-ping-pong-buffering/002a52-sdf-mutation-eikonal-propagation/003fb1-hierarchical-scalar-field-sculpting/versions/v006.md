# Hierarchical Scalar Field Sculpting

Also called: Resolution Adaptive Volume Sculpting, ntree subdivision

## Overview
Hierarchical Scalar Field Sculpting is an interactive modeling technique that modifies a scalar field representing volumetric material density using user-defined tools [S1]. It solves the problem of maintaining interactivity during the creation of topologically complex, high-detail objects by adaptively refining the sampling resolution only where the tool influences the field [S1]. It sets itself apart from fixed-resolution sculpting by allowing local refinement without global re-meshing, and from delta-based multiresolution schemes by storing absolute field values at each level, ensuring vertical independence [S1].

## How it works
**Inputs and Outputs:**
*   **Input:** A hierarchical scalar field representation (the `ntree`), a `Tool` (a scalar field function), and an `Action` (a combination rule) [S1].
*   **Output:** A modified scalar field with updated vertex values and potentially subdivided cells [S1].

**Data Structures:**
1.  **Vertex:** Stores the scalar field value, field gradient, and color [S1].
2.  **ntree Cell:** A hierarchical structure where a Cell is enriched with its sub-cells (children) rather than replaced [S1]. The subdivision factor is $n=4$ per dimension [S1]. Cells share `Vertex` nodes on common faces or edges with adjacent cells at the same level [S1].
3.  **Vertex Cache:** An STL hash map indexed by memory addresses of `Vertex` objects [S1]. It maps the `Vertex` state prior to the current tool's modification [S1]. One cache is created per Tool-Action application pair [S1].

**Parameters:**
*   **Field Clamping Range:** $[0, 3]$ [S1].
*   **Iso-value:** $1.5$ [S1].
*   **Min Resolution:** The smallest cell size allowed, derived from the tool's minimum security cell size [S1].
*   **Max Resolution:** The smallest cell size not to overpass, derived from the tool's scale to prevent infinite subdivision loops [S1].
*   **Acceptable Discrepancy:** A threshold for `estimateDiscrepancy()` [S1].

**Algorithm Steps:**

1.  **Initialization:** Create a `Vertex Cache` for the current Tool-Action pair [S1]. Store the current state of all affected vertices in the cache before applying the tool [S1].
2.  **Apply Tool (Recursive):** For each `Cell` in the hierarchy, iterate over all `Vertex` nodes $v$ [S1]. Compute the tool's contribution $T(v)$ at the vertex location [S1]. Apply the `Action` to update the vertex attributes [S1]. For an `AddAction`, add the tool's field value to the vertex field value, use these values as weights to sum attributes (gradient, color), and clamp the field value between 0 and 3 [S1]. If the cell has no children, call `checkSubdivide(t)` [S1]. If the cell has children, recursively call `apply(t, a)` on each child [S1].
3.  **Subdivision Check:** For a leaf `Cell` with size $s$ and tool $t$: if $s > t.\text{getMinResolution}()$, subdivide the cell [S1]. If $s < t.\text{getMaxResolution}()$, calculate `estimateDiscrepancy()` [S1]. If the discrepancy exceeds `acceptableDiscrepancy`, subdivide the cell [S1].
4.  **Subdivision Process:** Create sub-cells with subdivision factor $n=4$ [S1]. Share `Vertex` nodes among common faces/edges of adjacent new cells [S1]. Initialize new vertices by interpolating field values from the parent cell's state prior to the current tool application (retrieved from the `Vertex Cache`) [S1]. This ensures the tool's modification is added correctly to the pre-existing field [S1].
5.  **Simplification (Idle Pass):** At idle moments, perform a simplification pass over the whole field [S1]. Destroy any `Cell` that does not cross the surface (iso-value 1.5) and whose children also do not cross the surface [S1].

**Pseudocode:**

```python
class Vertex:
    def __init__(self, position, field_value, gradient, color):
        self.position = position
        self.field_value = field_value
        self.gradient = gradient
        self.color = color
        self.last_update_time = 0

class Cell:
    def __init__(self, size, vertices, children=None):
        self.size = size
        self.vertices = vertices
        self.children = children if children else []
        self.has_children_flag = children is not None

    def has_children(self):
        return self.has_children_flag

    def get_min_resolution(self):
        # Returns tool's minimum security cell size [S1]
        return 0.01

    def get_max_resolution(self):
        # Returns tool's maximum resolution (smallest cell size) [S1]
        return 0.001

    def estimate_discrepancy(self):
        # Returns estimated field variation across the cell [S1]
        return 0.05

    def acceptable_discrepancy(self):
        return 0.1

    def subdivide(self):
        # Creates n=4 sub-cells, shares vertices, initializes from cache [S1]
        new_children = []
        for i in range(4):
            for j in range(4):
                for k in range(4):
                    new_children.append(Cell(self.size / 4, [], []))
        self.children = new_children
        self.has_children_flag = True
        # Standard grid vertex sharing logic [G]
        self.vertices = create_shared_vertices(new_children)
        # Initialize new vertices from cached pre-update state [S1]
        for new_vertex in self.vertices:
            cached_vertex = vertex_cache.get(id(new_vertex))
            if cached_vertex:
                new_vertex.field_value = cached_vertex.field_value
                new_vertex.gradient = cached_vertex.gradient
                new_vertex.color = cached_vertex.color
            else:
                # Interpolate from parent's cached vertices [G]
                new_vertex.field_value = interpolate_cached_values(new_vertex.position, vertex_cache)

class Tool:
    def evaluate(self, position):
        # Wyvill's field function: f(p) = 3*(1 - 2/9*d^2 + 17/9*d^4 - 4/9*d^6) for d<1, else 0 [S1]
        d2 = sum((position[i] - self.center[i])**2 for i in range(3))
        if d2 >= 1.0:
            return 0.0
        return 3.0 * (1.0 - (2.0/9.0)*d2 + (17.0/9.0)*d2**2 - (4.0/9.0)*d2**3)

class Action:
    def update(self, tool_value, vertex):
        old_val = vertex.field_value
        new_val = max(0.0, min(3.0, old_val + tool_value))
        weight_old = old_val / (old_val + tool_value + 1e-9)
        weight_new = tool_value / (old_val + tool_value + 1e-9)
        vertex.field_value = new_val
        vertex.gradient = weight_old * vertex.gradient + weight_new * tool_value
        vertex.color = weight_old * vertex.color + weight_new * tool_value

def apply_tool_to_cell(cell, tool, action, vertex_cache, time_stamp):
    for vertex in cell.vertices:
        if vertex.last_update_time < time_stamp:
            tool_value = tool.evaluate(vertex.position)
            action.update(tool_value, vertex)
            vertex.last_update_time = time_stamp
            vertex_cache[id(vertex)] = Vertex(vertex.position, vertex.field_value, vertex.gradient, vertex.color)
    if not cell.has_children():
        if cell.size > tool.get_min_resolution():
            cell.subdivide()
        elif cell.size < tool.get_max_resolution():
            if cell.estimate_discrepancy() > cell.acceptable_discrepancy():
                cell.subdivide()
    else:
        for child in cell.children:
            apply_tool_to_cell(child, tool, action, vertex_cache, time_stamp)

def simplify_field(root_cell, iso_value):
    # Destroys cells that do not cross the surface and whose children do not [S1]
    if not root_cell.has_children():
        if root_cell.field_value < iso_value:
            return True # Mark for destruction
    else:
        children_destroyed = True
        for child in root_cell.children:
            if not simplify_field(child, iso_value):
                children_destroyed = False
        if children_destroyed:
            return True
    return False
```

**Edge Cases and Pitfalls:**
*   **Clamping:** Field values must be clamped to $[0, 3]$ to prevent negative values (which block material creation) or excessive positive values (which block material removal) [S1].
*   **Infinite Subdivision:** Subtractive tools can create discontinuities [S1]. A `Max Resolution` (smallest cell size) is required to stop subdivision [S1].
*   **Reversibility:** Field clamping makes the operation non-reversible [S1]. A `Vertex Cache` is mandatory to store pre-update states for interpolation during subdivision and for undo operations [S1].
*   **Update Order:** Coarser levels must be updated first to provide interactive visual feedback [S1]. This requires careful initialization of new vertices from the cache [S1].

## Subtopics

### [Volume Sculpting](11209-volume-sculpting.md)
Volume sculpting is a free-form interactive modeling technique based on the metaphor of sculpting and painting a voxel-based solid material, such as a block of marble or wood. It solves the difficulty of modeling topologically complex and highly-detailed objects in traditional CAD systems and enables scientists and physicians to explore inner structures of volumetric datasets by gradually removing material. It sets itself apart from surface-based sculpting by operating directly on the volume buffer, allowing for localized rendering updates and Boolean operations between independent volume buffers.

## Operating characteristics
*   **Time Complexity:** Not given in the sources.
*   **Memory Complexity:** Higher than fixed-resolution grids due to the hierarchical structure and vertex sharing overhead [S1]. The `ntree` structure precludes classical octree storage optimizations because successors are enriched rather than replaced [S1].
*   **Strengths:** Interactive visual feedback, local refinement, smooth blending of tools (C1 variations), computationally cheap tool evaluation using squared distance [S1].
*   **Limitations:** Simplification is drastic and deferred to idle moments [S1]. Direct subsampling is used rather than delta-based storage [S1]. Undo mechanism relies on caching all modified vertices [S1].
*   **When to use:** Interactive modeling of complex organic shapes where local detail is needed [S1].
*   **When not to use:** Not given in the sources.

## Background
Hierarchical Scalar Field Sculpting was introduced by Eric Ferley, Marie-Paule Cani, and Jean-Dominique Gascuel in the paper "Resolution Adaptive Volume Sculpting" [S1]. It builds on Wyvill's field function for smooth blending and extends the concept of adaptive subdivision to volume sculpting [S1]. The method was developed to address the limitations of fixed-resolution voxel-based sculpting, allowing for interactive editing of high-detail models [S1].
