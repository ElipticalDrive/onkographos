# Height Fog

Also called: Exponential Height Fog

## Overview
Height fog is a procedural volumetric effect where density falls exponentially with height, filling space to fade the horizon and fill valleys [S1, unofficial]. It simulates a dense, flat atmospheric volume by blending voxel colors with a height fog color based on a submersion factor and a visibility curve [S2, unofficial]. Unlike distance-based fog which fades objects uniformly, height fog creates a stratified atmosphere that interacts with terrain geometry [S1, unofficial].

## How it works
**Inputs:**
- `z_centers`: Array of Z-coordinates for the sampled points (or voxels).
- `colors`: Array of base colors at the sampled points.
- `fog_density`: Scalar controlling fog strength.
- `fog_max_z`: Scalar, the maximum Z height for the fog effect.
- `fog_fade`: Scalar, minimum denominator for submersion calculation.
- `HEIGHT_FOG_RGB`: Scalar or vector, the color of the fog.

**Outputs:**
- `final_colors`: The fog-blended colors.

**Data Structures:**
- Arrays are assumed to be NumPy-style multidimensional arrays. `z_centers` and `colors` share spatial dimensions. `colors` shape is `(H, W, C)` or `(N, C)`.

**Steps:**
1.  **Early Exit:** If `fog_density <= 0`, return `colors` immediately [S2, unofficial].
2.  **Calculate Submersion:**
    - Compute raw submersion: `sub = fog_max_z - z_centers` [S2, unofficial].
    - Clip to `[0.0, inf)`: `sub = max(0.0, sub)` [S2, unofficial].
    - Normalize by fade: `sub = sub / max(0.1, fog_fade)` [S2, unofficial].
    - Clip to `[0.0, 1.0]`: `submersion = min(1.0, sub)` [S2, unofficial].
3.  **Calculate Visibility:**
    - `vis = 1.0 - submersion` [S2, unofficial].
    - Apply density exponent: `vis = vis ** (fog_density * 4.0)` [S2, unofficial].
4.  **Desaturate (Washout):**
    - Compute washout factor: `washout = vis ** 2` [S2, unofficial].
    - Compute average luminance per pixel: `avg_lum = mean(colors, axis=-1)` [S2, unofficial].
    - Blend: `colors = colors * washout + avg_lum[..., None] * (1.0 - washout)` [S2, unofficial].
5.  **Blend with Fog Color:**
    - `vis_mask = vis` [S2, unofficial].
    - `final_colors = colors * vis_mask + HEIGHT_FOG_RGB * (1.0 - vis_mask)` [S2, unofficial].

**Pseudocode:**
```python
import numpy as np

def height_fog(z_centers: np.ndarray, colors: np.ndarray, 
               fog_density: float, fog_max_z: float, 
               fog_fade: float, height_fog_rgb: np.ndarray) -> np.ndarray:
    """
    Applies exponential height fog to colors based on Z-height.
    
    Args:
        z_centers: Z-coordinates of the samples.
        colors: Base colors (N, C) or (H, W, C).
        fog_density: Strength of the fog.
        fog_max_z: Max Z height for fog.
        fog_fade: Minimum denominator for submersion.
        height_fog_rgb: Color of the fog.
        
    Returns:
        Fog-blended colors.
    """
    if fog_density <= 0:
        return colors

    # 1. Calculate Submersion
    sub = fog_max_z - z_centers
    sub = np.maximum(0.0, sub)
    sub = sub / np.maximum(0.1, fog_fade)
    submersion = np.minimum(1.0, sub)

    # 2. Calculate Visibility
    vis = 1.0 - submersion
    vis = np.power(vis, fog_density * 4.0)

    # 3. Desaturate
    washout = np.power(vis, 2)
    # Calculate mean luminance along the color axis (last axis)
    avg_lum = np.mean(colors, axis=-1, keepdims=True)
    colors = colors * washout[..., None] + avg_lum * (1.0 - washout[..., None])

    # 4. Blend with Height Fog Color
    vis_mask = vis[..., None] if vis.ndim < colors.ndim else vis
    final_colors = colors * vis_mask + height_fog_rgb * (1.0 - vis_mask)

    return final_colors
```

**Parameters:**
- `fog_density`: Controls the strength of the fog effect [S2, unofficial].
- `fog_max_z`: Maximum Z height for the fog effect [S2, unofficial].
- `fog_fade`: Minimum denominator for submersion calculation (`max(0.1, fog_fade)`) [S2, unofficial].

**Edge Cases:**
- If `fog_density <= 0`, the function returns immediately [S2, unofficial].
- Division by zero is prevented by `max(0.1, fog_fade)` [S2, unofficial].
- Submersion is clipped to `[0.0, 1.0]` to ensure valid visibility values [S2, unofficial].

## Subtopics

### Ground Fog
A technique building on exponential height fog that adds noise to simulate random particle movement, causing some areas to appear denser than others [S3, unofficial]. Fog density is defined by sampling fBm (fractional Brownian motion) noise [S3, unofficial].

## Background
Height fog is implemented in MagicaVoxel as part of its "style voxel" preset, which includes ACES, bloom, vignette, a sun, atmospheric sky, ground, bounce caps, and transparent shadows [S1, unofficial]. It is also used in the Pyvorengi SDK demo for voxel rendering [S2, unofficial]. The concept of using noise to enhance procedural fog is discussed in the context of PlayCanvas and Magnopus Web Renderer [S3, unofficial].
