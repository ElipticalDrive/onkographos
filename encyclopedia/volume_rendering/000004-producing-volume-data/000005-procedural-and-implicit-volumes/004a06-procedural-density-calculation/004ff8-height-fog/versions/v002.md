# Height Fog

Also called: Exponential Height Fog
## Overview
Height fog is a procedural volumetric effect where density falls exponentially with height, filling space to fade the horizon and fill valleys [S1, unofficial]. It simulates a dense, flat atmospheric volume by blending voxel colors with a height fog color based on a submersion factor and a visibility curve [S2, unofficial]. In voxel-based systems, it often serves as the analytical component for sun light without dynamic shadows, applied to everything outside the ray-marching range [S3]. It is distinguished from general procedural density calculation by its specific exponential falloff and closed-form sampling, and from particle fog by its continuous, noise-free (in the base form) density field [S2, S4, unofficial].

## How it works
**Inputs:**
- `z_centers`: Array of Z-coordinates for the sampled points or voxels.
- `colors`: Array of RGB colors at the sampled points.
- `fog_max_z`: Maximum Z height for the fog effect [S2, unofficial][S3].
- `fog_fade`: Minimum denominator for submersion calculation [S2, unofficial].
- `fog_density`: Scalar controlling the strength of the fog effect [S2, unofficial].
- `HEIGHT_FOG_RGB`: The base color of the fog [S2, unofficial].

**Outputs:**
- `final_colors`: The fog-blended RGB colors.

**Data Structures:**
- Standard floating-point arrays for coordinates and colors. No complex bit-packing is required for the basic analytical calculation.

**Steps:**

1.  **Check Density:** If `fog_density <= 0`, return the input `colors` immediately [S2, unofficial].
2.  **Calculate Submersion:**
    - Compute raw submersion: `submersion_raw = fog_max_z - z_centers` [S2, unofficial].
    - Clip to `[0.0, inf)`: `submersion_raw = max(0.0, submersion_raw)` [S2, unofficial].
    - Compute denominator: `denom = max(0.1, fog_fade)` [S2, unofficial].
    - Normalize: `submersion = submersion_raw / denom` [S2, unofficial].
    - Clip to `[0.0, 1.0]`: `submersion = min(1.0, max(0.0, submersion))` [S2, unofficial].
3.  **Calculate Visibility:**
    - Compute base visibility: `vis = 1.0 - submersion` [S2, unofficial].
    - Apply density falloff: `vis = vis ** (fog_density * 4.0)` [S2, unofficial].
4.  **Desaturate Colors (Washout):**
    - Compute washout factor: `washout = vis ** 2` [S2, unofficial].
    - Compute average luminance of input colors: `avg_lum = mean(colors, axis=1)` [S2, unofficial].
    - Blend: `colors = colors * washout + avg_lum * (1.0 - washout)` [S2, unofficial].
5.  **Blend with Fog Color:**
    - Compute visibility mask (same as `vis`): `vis_mask = vis` [S2, unofficial].
    - Final blend: `final_colors = colors * vis_mask + HEIGHT_FOG_RGB * (1.0 - vis_mask)` [S2, unofficial].

**Pseudocode:**

```python
import numpy as np

def apply_height_fog(z_centers: np.ndarray, colors: np.ndarray, 
                     fog_max_z: float, fog_fade: float, 
                     fog_density: float, height_fog_rgb: np.ndarray) -> np.ndarray:
    """
    Applies exponential height fog to a set of colors based on their Z-height.
    
    Args:
        z_centers: Array of Z-coordinates for each point/voxel.
        colors: Array of RGB colors (N, 3) for each point/voxel.
        fog_max_z: Maximum Z height for the fog effect.
        fog_fade: Minimum denominator for submersion calculation.
        fog_density: Controls the strength of the fog effect.
        height_fog_rgb: The base color of the fog (3,).
        
    Returns:
        Final colors with height fog applied.
    """
    # Step 1: Check density
    if fog_density <= 0.0:
        return colors

    # Step 2: Calculate Submersion
    # submersion_raw = fog_max_z - z_centers
    # Clip to [0.0, inf)
    submersion_raw = np.maximum(0.0, fog_max_z - z_centers)
    
    # Denominator
    denom = max(0.1, fog_fade)
    
    # Normalize and clip to [0.0, 1.0]
    submersion = np.clip(submersion_raw / denom, 0.0, 1.0)
    
    # Step 3: Calculate Visibility
    vis = 1.0 - submersion
    vis = np.power(vis, fog_density * 4.0)
    
    # Step 4: Desaturate Colors (Washout)
    washout = np.power(vis, 2.0)
    
    # Compute average luminance per point
    # Assuming colors are in RGB, simple mean is used as per source
    avg_lum = np.mean(colors, axis=1, keepdims=True)
    
    # Blend colors with their average luminance
    colors = colors * washout[:, np.newaxis] + avg_lum * (1.0 - washout[:, np.newaxis])
    
    # Step 5: Blend with Fog Color
    vis_mask = vis
    final_colors = colors * vis_mask[:, np.newaxis] + height_fog_rgb * (1.0 - vis_mask[:, np.newaxis])
    
    return final_colors
```

**Parameters with Typical Values:**
- `fog_density`: Controls strength. Not given in the sources.
- `fog_max_z`: Maximum Z height. Not given in the sources.
- `fog_fade`: Minimum denominator. Not given in the sources.
- `HEIGHT_FOG_RGB`: Fog color. Not given in the sources.

**Edge Cases and Pitfalls:**
- If `fog_density` is negative or zero, the fog is disabled [S2, unofficial].
- Division by zero is prevented by `max(0.1, fog_fade)` [S2, unofficial].
- Submersion is clipped to `[0.0, 1.0]` to prevent invalid visibility values [S2, unofficial].
- Precision issues may arise if `vis` becomes extremely small due to high `fog_density`, potentially causing underflow in floating-point representations [G].

## Subtopics

### Ground Fog
A technique building on exponential height fog that adds noise to simulate random particle movement, causing some areas to appear denser than others [S4, unofficial]. Fog density is defined by sampling fBm (fractional Brownian motion) noise [S4, unofficial]. It is chosen when a more natural, varied, and less uniform fog appearance is desired compared to the smooth exponential falloff of standard height fog [S4, unofficial].

### Analytical Volumetric Fog
A component of voxel-based systems that handles sun light without dynamic shadows and exponential height fog density, applied to everything outside the ray-marching range [S3]. It is distinguished from ray-marching fog by its analytical, closed-form calculation which is faster but lacks dynamic shadowing [S3]. It is used for distant fog effects where performance is critical and dynamic shadows are not required [S3].

## Operating characteristics
- **Time Complexity:** O(N) where N is the number of sampled points or voxels, as it involves simple arithmetic operations per point [S2, unofficial].
- **Memory Complexity:** O(N) to store the input and output color arrays [S2, unofficial].
- **Measured Performance:** Not given in the sources.
- **Scaling:** Scales linearly with the number of samples. Suitable for real-time applications due to its closed-form nature [S1, unofficial][S3].
- **Strengths:** Fast, simple to implement, provides a smooth and realistic horizon fade [S1, unofficial].
- **Limitations:** Does not account for dynamic shadows or complex light interactions within the fog volume [S3]. The base form lacks the natural variation of noise-based fog [S4, unofficial].
- **When to use:** For atmospheric fog effects in voxel-based or real-time rendering where performance is key and dynamic shadows are handled separately or not required [S3].
- **When not to use:** When realistic, varied fog density is needed (use Ground Fog) [S4, unofficial], or when dynamic shadows within the fog are required (use Ray-marching Volumetric Fog) [S3].

## Background
Height fog, also known as exponential height fog, originated as a technique in voxel-based rendering systems, such as MagicaVoxel, to provide atmospheric depth [S1, unofficial]. It is a standard component in game engines like CRYENGINE for handling distant atmospheric effects analytically [S3]. The concept of adding noise to create ground fog has been explored in web-based rendering contexts to enhance realism [S4, unofficial].
