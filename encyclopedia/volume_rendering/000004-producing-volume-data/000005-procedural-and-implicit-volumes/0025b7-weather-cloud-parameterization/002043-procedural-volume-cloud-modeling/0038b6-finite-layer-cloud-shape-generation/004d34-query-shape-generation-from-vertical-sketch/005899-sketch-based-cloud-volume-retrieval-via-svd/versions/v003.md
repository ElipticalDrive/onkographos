# Sketch-based Cloud Volume Retrieval via SVD

Also called: SVD-based Cloud Retrieval

## Overview
Sketch-based Cloud Volume Retrieval via SVD is a method for retrieving realistic 3D cloud volumes from a pre-simulated database by matching a user-sketched 2D shape to 3D data using Singular Value Decomposition (SVD) basis vectors for efficient similarity calculation [S1]. It differs from direct voxel comparison by projecting both the query and database volumes into a low-dimensional subspace, reducing the computational cost of similarity search from proportional to the total number of voxels $M$ to proportional to the number of basis vectors $K$ [S1]. The method converts the generated query shape into a volumetric representation suitable for database matching by creating a bounding box and subdividing it into a uniform grid [S1].

## How it works
**Inputs:**
1.  User sketch of the cloud bottom shape on a 2D screen [S1].
2.  User-specified height for the cloud bottom [S1].
3.  A database of pre-simulated 3D cloud volumes, each normalized to a $20 \times 20 \times 20$ grid [S1].
4.  Pre-computed SVD basis vectors $u_k$ derived from the database volumes [S1].

**Outputs:**
1.  The 3D cloud volume data from the database with the smallest similarity score to the query shape [S1].

**Data Structures:**
*   **Cloud Plane Grid:** A 2D uniform grid representing the cloud bottom plane. [S1]
*   **Initial Query Volume ($D_0$):** A 3D uniform grid (bounding box of the query shape) where each cell contains a binary value: 1 if inside the query shape, 0 otherwise [S1].
*   **Query Vector ($x_0$):** A 1D vector containing the voxel values of $D_0$ [S1].
*   **Basis Vectors ($u_k$):** Pre-computed vectors representing the principal components of the database volumes [S1].
*   **Database Volumes ($D_n$):** Normalized to a $20 \times 20 \times 20$ grid [S1].

**Parameters:**
*   $K$: The number of basis vectors used for SVD approximation. In experiments, $K = M/114$, where $M$ is the total number of voxels in the volume data [S1].
*   $M$: The total number of voxels in the volume data (e.g., $20^3 = 8000$ for the normalized grid) [S1].

**Steps:**
1.  **Generate Cloud Plane:** The user specifies the height of the cloud bottom. The system generates a horizontal plane (cloud plane) at that height [S1].
2.  **Grid Subdivision:** The cloud plane is subdivided into a uniform 2D grid [S1].
3.  **Project Sketch:** The user sketches the shape of the cloud bottom on the screen. This 2D shape is projected onto the cloud plane grid [S1].
4.  **Binary Mask Creation:** For each grid point on the cloud plane, assign a value of 1 if the point is inside the projected shape, and 0 otherwise, creating a binary image [S1].
5.  **Distance Transform:** Apply a distance transform to the binary image to compute the Euclidean distance from each grid point to the boundary of the projected shape [S1].
6.  **Query Shape Height Generation:** Create the 3D query shape by assuming the cloud height at each grid point $(x, y)$ equals the distance value obtained from the distance transform at that point [S1].
7.  **Bounding Box and Volume Creation:** Create a bounding box for the query shape. [S1] Subdivide this bounding box into a uniform 3D grid to form the initial query volume $D_0$. [S1] Assign 1 to grid points inside the shape and 0 to points outside [S1].
8.  **Vectorization:** Represent the initial query volume $D_0$ as a vector $x_0$ of voxel values [S1].
9.  **SVD Approximation of Query:** Approximate $x_0$ as a linear combination of the $K$ pre-computed SVD basis vectors $u_k$:
    $$ x_0 \approx \sum_{k=1}^{K} w_{k0} u_k $$
    where $w_{k0}$ are the projection coefficients [S1].
10. **Calculate Query Coefficients:** Compute the coefficients $w_{k0}$ for the query vector:
    $$ w_{k0} = x_0 \cdot u_k $$
    where $\cdot$ denotes the dot product [S1].
11. **Retrieve Database Volumes:** For each cloud volume $D_n$ in the database:
    a. Represent $D_n$ as a vector $x_n$.
    b. Compute the pre-calculated coefficients $w_{nk}$ for $D_n$:
        $$ w_{nk} = x_n \cdot u_k $$
    c. Calculate the approximate similarity score:
        $$ score_n \approx \sum_{k=1}^{K} (w_{k0} - w_{nk})^2 $$
    [S1].
12. **Select Best Match:** Extract the volume data from the database with the smallest similarity score $score_n$ and display it to the user [S1].

**Pseudocode:**
```python
def retrieve_cloud_volume(user_sketch_points, cloud_bottom_height, database_volumes, basis_vectors, grid_size=64):
    # Step 1-2: Cloud plane grid
    cloud_plane = [[0.0] * grid_size for _ in range(grid_size)]

    # Step 3-4: Project sketch & binary mask
    binary_mask = [[0] * grid_size for _ in range(grid_size)]
    for y in range(grid_size):
        for x in range(grid_size):
            if point_in_polygon(x, y, user_sketch_points):
                binary_mask[y][x] = 1

    # Step 5: Distance transform [G]
    distance_map = compute_distance_transform(binary_mask, grid_size)

    # Step 6-7: Query shape & D0
    # Find bounding box of non-zero distances
    min_x = min_y = grid_size
    max_x = max_y = -1
    for y in range(grid_size):
        for x in range(grid_size):
            if distance_map[y][x] > 0:
                min_x, max_x = min(min_x, x), max(max_x, x)
                min_y, max_y = min(min_y, y), max(max_y, y)
    if max_x == -1:
        min_x, max_x, min_y, max_y = 0, grid_size - 1, 0, grid_size - 1

    width = max_x - min_x + 1
    height_dim = max_y - min_y + 1
    max_h = int(max(distance_map[y][x] for y in range(grid_size) for x in range(grid_size)))
    D0 = [[[0] * max_h for _ in range(width)] for _ in range(height_dim)]

    for y in range(min_y, max_y + 1):
        for x in range(min_x, max_x + 1):
            h = int(distance_map[y][x])
            for z in range(h):
                D0[y - min_y][x - min_x][z] = 1

    # Step 8: Vectorize D0
    x0 = [D0[y][x][z] for y in range(height_dim) for x in range(width) for z in range(max_h)]

    # Step 9-10: Query coefficients
    K = len(basis_vectors)
    w_k0 = [dot_product(x0, u_k) for u_k in basis_vectors]

    # Step 11: Retrieve
    best_score = float('inf')
    best_volume = None
    for volume in database_volumes:
        xn = [voxel for layer in volume for row in layer for voxel in row]
        w_nk = [dot_product(xn, u_k) for u_k in basis_vectors]
        score = sum((w_k0[k] - w_nk[k])**2 for k in range(K))
        if score < best_score:
            best_score = score
            best_volume = volume

    return best_volume

def point_in_polygon(x, y, polygon):
    n = len(polygon)
    inside = False
    p1x, p1y = polygon[0]
    for i in range(1, n + 1):
        p2x, p2y = polygon[i % n]
        if y > min(p1y, p2y):
            if y <= max(p1y, p2y):
                if x <= max(p1x, p2x):
                    if p1y != p2y:
                        xinters = (y - p1y) * (p2x - p1x) / (p2y - p1y) + p1x
                    if p1x == p2x or x <= xinters:
                        inside = not inside
        p1x, p1y = p2x, p2y
    return inside

def dot_product(v1, v2):
    return sum(a * b for a, b in zip(v1, v2))

def compute_distance_transform(binary_mask, size):
    # Standard Euclidean distance transform [G]
    dist = [[float('inf')] * size for _ in range(size)]
    for y in range(size):
        for x in range(size):
            if binary_mask[y][x] == 1:
                dist[y][x] = 0.0
    for y in range(size):
        for x in range(size):
            if dist[y][x] == 0.0:
                continue
            min_d = float('inf')
            for dy in range(-size, size + 1):
                for dx in range(-size, size + 1):
                    ny, nx = y + dy, x + dx
                    if 0 <= ny < size and 0 <= nx < size:
                        d = (dx**2 + dy**2)**0.5
                        if d < min_d:
                            min_d = d
            dist[y][x] = min_d
    return dist
```

**Edge Cases and Pitfalls:**
*   **Insufficient Database Size:** If the database size is insufficient to cover the shape space, generated clouds may not perfectly match the user's sketch [S1].
*   **Precision:** The approximation using SVD basis vectors introduces error. The exact similarity score is $|x_0 - x_n|^2$, while the approximate score is $\sum_{k=1}^{K} (w_{k0} - w_{nk})^2$ [S1]. The error depends on $K$.

## Operating characteristics
*   **Time Complexity:** The similarity calculation cost using SVD is proportional to $K$, whereas direct voxel comparison is proportional to $M$ [S1]. With $K = M/114$, the computational cost is reduced by a factor of 114 [S1].
*   **Memory Complexity:** Requires storing the database volumes and the pre-computed SVD basis vectors [S1].
*   **Measured Performance:** In experiments, the method was used to retrieve clouds from databases of size 137 (from a $96 \times 96 \times 128$ simulation grid) and 83 (from a $256 \times 128 \times 128$ simulation grid) [S1].
*   **Strengths:** Efficient retrieval due to dimensionality reduction via SVD [S1].
*   **Limitations:** Relies on the diversity and size of the pre-simulated database. May not perfectly match user sketches if the database is small [S1].

## Background
The method was proposed by [S1] as part of a sketch-based system for cloud volume retrieval from a simulated dataset for realistic image synthesis. It builds on the idea that cumulus/cumulonimbus clouds have characteristic features: a flat bottom on a plane at a certain height, and vertical thickness larger around the center than the boundary [S1]. The system was used in Autodesk Maya 2016 for rendering final images [S1]. The database was constructed by simulating dynamic cumulus clouds using computational fluid dynamics [S1].
