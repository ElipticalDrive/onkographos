# Finite Layer Cloud Shape Generation

Also called: Layer Cloud Side Profile, Natural XY Edge Envelope

## Overview
Finite Layer Cloud Shape Generation is a procedural method for constructing the 3D volume shapes of layer cloud types (Cirrus, Altostratus, Nimbostratus, Stratocumulus, Stratus) by assembling a chain of connected 3D ellipsoidal lobes [S1, unofficial]. It solves the geometric problem of ensuring that layer clouds do not degenerate into simple vertical cylinders along the Z-axis, which is a common artifact when extruding 2D contours into volumes [S1, unofficial]. Unlike its sibling [Cumulonimbus and Cumulus Shape Generation](8296-cumulonimbus-and-cumulus-shape-generation.md), which targets irregular, convective structures, this method produces the characteristic horizontal spread and vertical variation of stratiform clouds [S1, unofficial].

## How it works
**Inputs:**
- Cloud type ID (`type_id`): Integer identifier for the cloud type. Must be in `LAYER_CLOUD_TYPE_IDS` (3, 5, 6, 7, 8) [S1, unofficial]. If not, defaults to type 5 (Stratocumulus) [S1, unofficial].
- Resolution: Grid dimensions $(X, Y, Z)$ for the output volume field.
- Random seed/state: For procedural variation [S1, unofficial].

**Outputs:**
- A 3D density field (float32) representing the cloud shape envelope.

**Data Structures:**
- `LAYER_CLOUD_TYPE_IDS`: `frozenset({3, 5, 6, 7, 8})` [S1, unofficial].
- `Persistent Support Map`: Dictionary mapping `type_id` to a float scalar: `{3: 0.36, 5: 0.40, 6: 0.50, 7: 0.24, 8: 0.44}` [S1, unofficial].
- `Lobe Spec Tuple`: `(center_x, center_y, radius_x, radius_y, weight, lobe_z, lobe_z_radius)` [S1, unofficial].

**Parameters:**
- `major_length`: Uniform random in $[0.45, 0.72]$ [S1, unofficial].
- `cross_width`: Uniform random in $[0.22, 0.46]$ [S1, unofficial].
- `radius_x`: Uniform random in $[0.14, 0.30]$ [S1, unofficial].
- `radius_y`: Uniform random in $[0.12, 0.28]$ [S1, unofficial].
- `lobe_weight`: Uniform random in $[0.54, 0.98]$ [S1, unofficial].
- `lobe_z_offset`: Uniform random in $[-0.48, 0.48]$ [S1, unofficial].
- `lobe_z_radius_scale`: Uniform random in $[0.58, 1.04]$ [S1, unofficial].
- `side_along_range`: Uniform random in $[-0.58, 0.58]$ [S1, unofficial].
- `side_cross_scale`: Uniform random in $[0.60, 1.18]$ [S1, unofficial].
- `edge_noise_scale_base`: $0.62$ [S1, unofficial].
- `edge_noise_scale_variation`: $0.30$ [S1, unofficial].
- `smoothstep_threshold`: $0.30$ [S1, unofficial].
- `smoothstep_range`: $0.48$ [S1, unofficial].
- `final_guard_width`: $0.045$ [S1, unofficial].

**Steps:**

1. **Determine Orientation:**
   Generate `major_angle` uniformly from $[-\pi, \pi]$.
   Calculate direction vector $\vec{d} = (\cos(\text{major\_angle}), \sin(\text{major\_angle}))$.
   Calculate perpendicular vector $\vec{p} = (-\vec{d}_y, \vec{d}_x)$.

2. **Retrieve Shape Profile:**
   Get `center_z` and `half_height` from the shape profile for `type_id`.
   For Nimbostratus (type 6): `center_z` = -0.03, `half_height` = 0.58 [S1, unofficial].
   Get `horizontal_taper` and `side_variation` from the profile [S1, unofficial].

3. **Generate Main Lobe Chain:**
   Generate `count` positions (uniformly chosen between 7 and 13) along the major axis:
   $$ \text{positions\_along}_i = \text{linspace}(-0.88, 0.88, \text{count}) + \mathcal{N}(0, 0.09) $$
   For each position $i$:
   - Calculate offset along major axis: $a_i = \text{positions\_along}_i \times \text{major\_length}$.
   - Calculate offset along perpendicular axis: $c_i = \mathcal{N}(0, \text{cross\_width} \times 0.62)$.
   - Calculate lobe center in XY: $\vec{pos}_i = \vec{p}_{center} + a_i \vec{d} + c_i \vec{p}$, where $\vec{p}_{center}$ is the region center (typically $(0,0)$ in local space) [S1, unofficial].
   - Set radii: $r_{x,i} \sim U(0.14, 0.30)$, $r_{y,i} \sim U(0.12, 0.28)$.
   - Set Z parameters: $z_i = \text{center\_z} + \mathcal{N}(0, 0.48) \times \text{half\_height}$, $r_{z,i} = \mathcal{N}(0.58, 1.04) \times \text{half\_height}$ [S1, unofficial].
   - Set weight: $w_i \sim U(0.54, 0.98)$ [S1, unofficial].
   - Append spec $(\vec{pos}_i, r_{x,i}, r_{y,i}, w_i, z_i, r_{z,i})$ to `main_lobe_specs`.

4. **Generate Side Lobes:**
   Generate 1 to 3 side lobes to prevent circular degeneracy [S1, unofficial].
   For each side lobe:
   - $a_{side} \sim U(-0.58, 0.58) \times \text{major\_length}$.
   - $c_{side} = \text{choice}(-1, 1) \times U(0.60, 1.18) \times \text{cross\_width}$.
   - $\vec{pos}_{side} = \vec{p}_{center} + a_{side} \vec{d} + c_{side} \vec{p}$.
   - Generate $r_x, r_y, w, z, r_z$ using similar random distributions as main lobes.
   - Append to `side_lobe_specs`.

5. **Evaluate Density Field:**
   Initialize `lobe_field` to zeros with shape $(X, Y, Z)$ [S1, unofficial].
   For each voxel $(x, y, z)$:
   - Rotate coordinates to lobe-aligned space: $(x', y') = \text{rotate}(x, y, \text{major\_angle})$ [S1, unofficial].
   - Initialize `voxel_value` = 0.
   - For each lobe spec $(cx, cy, rx, ry, w, cz, rz)$ in `main_lobe_specs` and `side_lobe_specs`:
     - Rotate lobe center: $(cx', cy') = \text{rotate}(cx, cy, \text{major\_angle})$ [S1, unofficial].
     - Calculate 2D Gaussian lobe:
       $$ L = \exp\left( - \left( \frac{x' - cx'}{rx \times 1.15} \right)^2 - \left( \frac{y' - cy'}{ry \times 1.15} \right)^2 \right) $$
     - Calculate vertical presence:
       Let $P$ be the persistent support for `type_id` (e.g., 0.50 for type 6) [S1, unofficial].
       $$ V = P + (1.0 - P) \times \exp\left( - \left( \frac{z - cz}{\max(rz, 0.001)} \right)^2 \right) $$
     - Add to field: `voxel_value` += $w \times V \times L$ [S1, unofficial].
   - `lobe_field[x,y,z]` = `voxel_value`.

6. **Apply Horizontal Taper:**
   Calculate normalized height: $h_{norm} = \frac{|z - \text{center\_z}|}{\max(\text{half\_height}, 0.001)}$ [S1, unofficial].
   Calculate cap taper: $T = \text{horizontal\_taper} \times \text{smoothstep}\left( \frac{h_{norm} - 0.12}{0.88} \right)$ [S1, unofficial].
   Subtract taper: `lobe_field` -= $T$ [S1, unofficial].

7. **Apply Edge Noise and Smoothstep:**
   Generate edge noise field `edge_noise` (uniform $[0, 1]$ or similar, scaled by variation) [S1, unofficial].
   Calculate contour:
   $$ C = \text{lobe\_field} + (\text{edge\_noise} - 0.5) \times (0.62 + 0.30 \times \text{side\_variation}) - T $$
   Apply smoothstep to create organic edges:
   $$ O = \text{smoothstep}\left( \frac{C - 0.30}{0.48} \right) $$

8. **Apply Final Guard:**
   Calculate screen distance from boundary: $d_{screen} = \min(x+1, 1-x, y+1, 1-y)$ [S1, unofficial].
   Apply safe edge fade: $G = \text{safe\_edge\_fade}(d_{screen}, 0.0, 0.045)$ [S1, unofficial].
   Final result: $F = O \times G$ [S1, unofficial].

**Pseudocode:**

```python
import numpy as np

def smoothstep(edge0, edge1, x):
    t = np.clip((x - edge0) / (edge1 - edge0), 0.0, 1.0)
    return t * t * (3 - 2 * t)

def safe_edge_fade(distance, min_val, max_val):
    # Linear fade from 1.0 at distance > max_val to 0.0 at distance < min_val
    # Assuming distance is in [0, 1]
    t = np.clip((distance - min_val) / (max_val - min_val), 0.0, 1.0)
    return 1.0 - t

def rotated_xy(x, y, angle):
    cos_a = np.cos(angle)
    sin_a = np.sin(angle)
    local_x = x * cos_a - y * sin_a
    local_y = x * sin_a + y * cos_a
    return local_x, local_y

def finite_layer_cloud_shape_generation(type_id, resolution, rng):
    # 1. Determine Orientation
    major_angle = rng.uniform(-np.pi, np.pi)
    direction = np.array([np.cos(major_angle), np.sin(major_angle)])
    perpendicular = np.array([-direction[1], direction[0]])
    
    # 2. Retrieve Shape Profile
    # Default to type 5 if not in layer IDs
    if type_id not in {3, 5, 6, 7, 8}:
        type_id = 5
        
    # Profile parameters (example for type 6, others vary)
    if type_id == 6:
        center_z = -0.03
        half_height = 0.58
        horizontal_taper = 0.39
        side_variation = 1.10
    else:
        # Placeholder for other types; in implementation, fetch from profile map
        center_z = 0.0
        half_height = 0.5
        horizontal_taper = 0.3
        side_variation = 1.0
        
    persistent_support = {3: 0.36, 5: 0.40, 6: 0.50, 7: 0.24, 8: 0.44}[type_id]
    
    # 3. Generate Main Lobe Chain
    count = rng.integers(7, 14)
    positions_along = np.linspace(-0.88, 0.88, count) + rng.normal(0.0, 0.09, size=count)
    
    major_length = rng.uniform(0.45, 0.72)
    cross_width = rng.uniform(0.22, 0.46)
    
    main_lobe_specs = []
    for pos in positions_along:
        along = pos * major_length
        cross = rng.normal(0.0, cross_width * 0.62)
        position = direction * along + perpendicular * cross
        
        radius_x = rng.uniform(0.14, 0.30)
        radius_y = rng.uniform(0.12, 0.28)
        lobe_z = center_z + rng.uniform(-0.48, 0.48) * half_height
        lobe_z_radius = rng.uniform(0.58, 1.04) * half_height
        weight = rng.uniform(0.54, 0.98)
        
        main_lobe_specs.append((position[0], position[1], radius_x, radius_y, weight, lobe_z, lobe_z_radius))
        
    # 4. Generate Side Lobes
    side_lobe_specs = []
    num_side_lobes = rng.integers(1, 4)
    for _ in range(num_side_lobes):
        along = rng.uniform(-0.58, 0.58) * major_length
        cross_sign = rng.choice([-1, 1])
        cross = cross_sign * rng.uniform(0.60, 1.18) * cross_width
        position = direction * along + perpendicular * cross
        
        radius_x = rng.uniform(0.14, 0.30)
        radius_y = rng.uniform(0.12, 0.28)
        lobe_z = center_z + rng.uniform(-0.48, 0.48) * half_height
        lobe_z_radius = rng.uniform(0.58, 1.04) * half_height
        weight = rng.uniform(0.54, 0.98)
        
        side_lobe_specs.append((position[0], position[1], radius_x, radius_y, weight, lobe_z, lobe_z_radius))
        
    all_lobe_specs = main_lobe_specs + side_lobe_specs
    
    # 5. Evaluate Density Field
    x, y, z = np.meshgrid(
        np.linspace(-1, 1, resolution[0]),
        np.linspace(-1, 1, resolution[1]),
        np.linspace(-1, 1, resolution[2]),
        indexing='ij'
    )
    
    lobe_field = np.zeros_like(x, dtype=np.float32)
    
    for cx, cy, rx, ry, w, cz, rz in all_lobe_specs:
        local_x, local_y = rotated_xy(x, y, major_angle)
        lobe_center_x, lobe_center_y = rotated_xy(cx, cy, major_angle)
        
        # 2D Gaussian
        dx = (local_x - lobe_center_x) / (rx * 1.15)
        dy = (local_y - lobe_center_y) / (ry * 1.15)
        lobe = np.exp(-(dx**2 + dy**2))
        
        # Vertical presence
        dz = (z - cz) / np.maximum(rz, 0.001)
        vertical_presence = persistent_support + (1.0 - persistent_support) * np.exp(-dz**2)
        
        lobe_field += w * vertical_presence * lobe
        
    # 6. Apply Horizontal Taper
    normalized_height = np.abs(z - center_z) / np.maximum(half_height, 0.001)
    cap_taper = horizontal_taper * smoothstep((normalized_height - 0.12) / 0.88)
    lobe_field -= cap_taper
    
    # 7. Apply Edge Noise and Smoothstep
    # Assuming edge_noise is pre-generated or generated here
    edge_noise = rng.uniform(0.0, 1.0, size=resolution)
    contour = lobe_field + (edge_noise - 0.5) * (0.62 + 0.30 * side_variation) - cap_taper
    organic = smoothstep((contour - 0.30) / 0.48)
    
    # 8. Apply Final Guard
    screen_distance = np.minimum.reduce([x + 1.0, 1.0 - x, y + 1.0, 1.0 - y])
    final_guard = safe_edge_fade(screen_distance, 0.0, 0.045)
    
    return organic * final_guard
```

## Subtopics

### [Cumulonimbus and Cumulus Shape Generation](8296-cumulonimbus-and-cumulus-shape-generation.md)
Generates non-spherical, multi-lobed shapes for convective clouds (Cumulus, Cumulonimbus). Use when generating vertical development clouds. Differs from parent by targeting irregular tops/bases rather than ellipsoidal chains.

### [Query Shape Generation from Vertical Sketch](13408-query-shape-generation-from-vertical-sketch.md)
Generates 3D query shapes from 2D sketches by extruding into ellipsoidal volumes. Use for sketch-based cloud retrieval. Differs from parent by deriving shape from a single vertical curve rather than a randomized lobe chain.

## Operating characteristics
- **Time Complexity:** Linear with respect to the number of voxels $V$ and the number of lobes $L$. $O(V \times L)$.
- **Memory Complexity:** $O(V)$ for the output density field.
- **Performance:** Efficient for real-time or pre-baking due to simple Gaussian evaluations. No complex ray marching or iterative solvers required.
- **Strengths:** Produces natural-looking layer cloud shapes without cylindrical artifacts. Highly configurable via type-specific parameters.
- **Limitations:** Relies on randomization for variation; may require tuning for specific artistic styles. The final guard only clears the outermost voxels, relying on the contour to naturally decay [S1, unofficial].

## Background
Originated in the Noise-Cloud project [S1, unofficial]. Designed to address the limitations of simple 2D contour extrusion for layer clouds, which often resulted in unnatural cylindrical volumes. The method uses a chain of ellipsoidal lobes to better approximate the natural spread and vertical variation of stratiform clouds.
