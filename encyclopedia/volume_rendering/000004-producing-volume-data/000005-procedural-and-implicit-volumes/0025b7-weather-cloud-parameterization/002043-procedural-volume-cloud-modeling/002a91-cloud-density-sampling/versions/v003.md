# Cloud Density Sampling

Also called: Base Cloud Density Generation, Low-Frequency Cloud Density, SampleCloudDensity, Schneider's Cloud Noise

## Overview
Cloud Density Sampling generates the base volumetric density of clouds by combining low-frequency 3D noise textures using a weighted sum (Fractal Brownian Motion, FBM) and remapping the result to control cloud shape and coverage [S1, unofficial]. It differs from [Procedural 3D Worley-Perlin Fractal Noise Density](5267-procedural-3d-worley-perlin-fractal-noise-density.md) by relying on pre-computed multi-channel 3D textures rather than procedural Worley noise generation, and from [Full Cloud Density Function](5875-full-cloud-density-function.md) by handling the core density evaluation logic (including wind skew and basic height gradients) within this specific sampling routine rather than delegating to a higher-level composite function.

## How it works
**Inputs:**
- `samplepoint`: `vec3`, world or texture space coordinate for density evaluation.
- `weather_data`: `vec4`, containing weather parameters (e.g., `r` for cloud coverage).
- `relativeHeight`: `float`, normalized height of the sample point within the atmosphere.
- `ischeap`: `bool`, if `true`, skips high-frequency detail sampling.
- `Time`: `float`, global time variable for animation.
- `wind_direction`: `vec3`, default `(1.0, 0.0, 0.0)`.
- `cloud_speed`: `float`, default `10.0`.
- `cloud_top_offset`: `float`, default `5.0`.

**Data Structures:**
- `lowFrequencyTexture`: `sampler3D`. A pre-computed 3D texture where:
  - Channel `R`: Base noise values.
  - Channel `G`: Component weighted by 0.625 in FBM.
  - Channel `B`: Component weighted by 0.250 in FBM.
  - Channel `A`: Component weighted by 0.125 in FBM.
- `highFrequencyTexture`: `sampler3D`, used only if `!ischeap`.
- `curlNoiseTexture`: `sampler2D` (or `sampler3D` projected to XY), used only if `!ischeap`.

**Steps:**
1. **Wind Skew:** Adjust the sample point based on height and wind.
   $$ \mathbf{p}_{skewed} = \mathbf{p} + \text{relativeHeight} \cdot \text{wind\_direction} \cdot \text{cloud\_top\_offset} \cdot 0.005 $$
2. **Time Movement:** Animate the sample point.
   $$ \mathbf{p}_{animated} = \mathbf{p}_{skewed} + (\text{wind\_direction} + \text{vec3}(0.0, 1.0, 0.0)) \cdot \text{Time} \cdot \text{cloud\_speed} \cdot 0.001 $$
3. **Low-Frequency Sampling:** Sample the low-frequency texture.
   $$ \mathbf{N}_{low} = \text{SampleLowFrequencyTexture}(\mathbf{p}_{animated}) $$
4. **Low-Frequency FBM:** Compute the weighted sum of G, B, and A channels.
   $$ F_{low} = \mathbf{N}_{low}.g \cdot 0.625 + \mathbf{N}_{low}.b \cdot 0.250 + \mathbf{N}_{low}.a \cdot 0.125 $$
5. **Base Cloud Remap:** Remap the R channel to create the base cloud density.
   $$ \text{base\_cloud} = \text{Remap}(\mathbf{N}_{low}.r, -(1.0 - F_{low}), 1.0, 0.0, 1.0) $$
   Where $\text{Remap}(v, v_{min}, v_{max}, u_{min}, u_{max}) = u_{min} + \frac{v - v_{min}}{v_{max} - v_{min}}(u_{max} - u_{min})$.
6. **Height Gradient:** Calculate vertical attenuation.
   $$ \text{density\_height\_gradient} = \text{GetDensityHeightGradientForPoint}(\mathbf{p}_{animated}, \text{weather\_data}, \text{relativeHeight}) $$
   Apply gradient:
   $$ \text{base\_cloud} \leftarrow \text{base\_cloud} \cdot \text{density\_height\_gradient} $$
7. **Coverage Masking:** Apply global cloud coverage from weather data.
   $$ \text{cloud\_coverage} = \text{weather\_data}.r $$
   $$ \text{base\_cloud\_with\_coverage} = \text{Remap}(\text{base\_cloud}, \text{cloud\_coverage}, 1.0, 0.0, 1.0) $$
   Clamp result:
   $$ \text{base\_cloud\_with\_coverage} = \text{clamp}(\text{base\_cloud\_with\_coverage}, 0.0, 1.0) $$
8. **Aesthetic Enhancement:** Boost density based on coverage.
   $$ \text{base\_cloud\_with\_coverage} \leftarrow \text{base\_cloud\_with\_coverage} \cdot \text{cloud\_coverage} \cdot 4.0 $$
9. **High-Frequency Details (if `!ischeap` and `base_cloud_with_coverage > 0.0`):**
   a. Sample curl noise and displace UVs:
      $$ \mathbf{C} = \text{SampleCurlNoiseTexture}(\mathbf{p}_{animated}.xy) $$
      $$ \mathbf{p}_{displaced}.xy = \mathbf{p}_{animated}.xy + \mathbf{C}.xy \cdot (1.0 - \text{relativeHeight}) $$
   b. Sample high-frequency texture:
      $$ \mathbf{N}_{high} = \text{SampleHighFrequencyTexture}(\mathbf{p}_{displaced} \cdot 0.1) $$
   c. Compute high-frequency FBM:
      $$ F_{high} = \mathbf{N}_{high}.r \cdot 0.625 + \mathbf{N}_{high}.g \cdot 0.250 + \mathbf{N}_{high}.b \cdot 0.125 $$
   d. Compute modifier:
      $$ \text{high\_freq\_noise\_modifier} = \text{mix}(F_{high}, 1.0 - F_{high}, \text{clamp}(\text{relativeHeight} \cdot 10.0, 0.0, 1.0)) $$
   e. Erode and clamp:
      $$ \text{final\_cloud} = \text{Remap}(\text{base\_cloud\_with\_coverage}, 0.2 \cdot \text{high\_freq\_noise\_modifier}, 1.0, 0.0, 1.0) $$
      Return `final_cloud`.
10. If `ischeap` or `base_cloud_with_coverage == 0.0`, return `base_cloud_with_coverage`.

**Pseudocode:**
```python
def SampleCloudDensity(samplepoint, weather_data, relativeHeight, ischeap, Time, wind_direction, cloud_speed, cloud_top_offset):
    # 1. Wind Skew
    p = samplepoint + relativeHeight * wind_direction * cloud_top_offset * 0.005
    
    # 2. Time Movement
    p = p + (wind_direction + vec3(0.0, 1.0, 0.0)) * Time * cloud_speed * 0.001
    
    # 3. Low-Frequency Sampling
    N_low = SampleLowFrequencyTexture(p)
    
    # 4. Low-Frequency FBM
    F_low = N_low.g * 0.625 + N_low.b * 0.250 + N_low.a * 0.125
    
    # 5. Base Cloud Remap
    v_min = -(1.0 - F_low)
    v_max = 1.0
    u_min = 0.0
    u_max = 1.0
    base_cloud = u_min + (N_low.r - v_min) / (v_max - v_min) * (u_max - u_min)
    
    # 6. Height Gradient
    density_height_gradient = GetDensityHeightGradientForPoint(p, weather_data, relativeHeight)
    base_cloud = base_cloud * density_height_gradient
    
    # 7. Coverage Masking
    cloud_coverage = weather_data.r
    v_min_cov = cloud_coverage
    v_max_cov = 1.0
    base_cloud_with_coverage = u_min + (base_cloud - v_min_cov) / (v_max_cov - v_min_cov) * (u_max - u_min)
    base_cloud_with_coverage = clamp(base_cloud_with_coverage, 0.0, 1.0)
    
    # 8. Aesthetic Enhancement
    base_cloud_with_coverage = base_cloud_with_coverage * cloud_coverage * 4.0
    
    # 9. High-Frequency Details
    if not ischeap and base_cloud_with_coverage > 0.0:
        # Curl Noise Displacement
        curl_noise = SampleCurlNoiseTexture(p.xy)
        p_displaced = p
        p_displaced.xy = p.xy + curl_noise.xy * (1.0 - relativeHeight)
        
        # High-Freq Sampling
        N_high = SampleHighFrequencyTexture(p_displaced * 0.1)
        
        # High-Freq FBM
        F_high = N_high.r * 0.625 + N_high.g * 0.250 + N_high.b * 0.125
        
        # Modifier
        mix_factor = clamp(relativeHeight * 10.0, 0.0, 1.0)
        high_freq_noise_modifier = mix(F_high, 1.0 - F_high, mix_factor)
        
        # Erode
        v_min_ero = 0.2 * high_freq_noise_modifier
        v_max_ero = 1.0
        final_cloud = u_min + (base_cloud_with_coverage - v_min_ero) / (v_max_ero - v_min_ero) * (u_max - u_min)
        return final_cloud
        
    return base_cloud_with_coverage
```

**Edge Cases and Pitfalls:**
- **Division by Zero:** In the `Remap` function, if $v_{max} = v_{min}$, division by zero occurs. In step 5, $v_{max}=1.0$ and $v_{min}=-(1-F_{low})$. Since $F_{low}$ is a weighted sum of texture samples (typically in $[0,1]$), $v_{min}$ is in $[-1, 0]$. Thus $v_{max} \neq v_{min}$ holds. In step 7, if `cloud_coverage` is 1.0, $v_{min}=v_{max}=1.0$, causing division by zero. The implementation must handle this case, likely returning `u_max` (1.0) or `u_min` (0.0) depending on the value of `base_cloud` relative to 1.0 [G].
- **Precision:** The remapping in step 5 involves subtracting $1.0 - F_{low}$ from $N_r$. If $F_{low}$ is close to 1.0, $v_{min}$ is close to 0. If $N_r$ is also small, precision loss may occur.
- **Boundary Conditions:** `GetDensityHeightGradientForPoint` and `GetRelativeHeightInAtmosphere` (used in variants) must handle points outside the atmosphere bounds gracefully [G].

## Subtopics

### [Procedural 3D Worley-Perlin Fractal Noise Density](5267-procedural-3d-worley-perlin-fractal-noise-density.md)
Generates billowy cloud shapes by synthesizing cloud density $\rho(\mathbf{x})$ procedurally using inverted Worley fractal Brownian motion (FBM), vertical gradient attenuation, and coverage thresholding. It differs from standard Perlin-based cloud noise by using the distance-to-nearest-cell metric of Worley noise, inverted to create bright, puffy "billowy" structures characteristic of cumulus clouds, rather than the smooth, turbulent gradients of Perlin noise.

### [Full Cloud Density Function](5875-full-cloud-density-function.md)
The Full Cloud Density Function computes the volumetric density at a specific 3D point by combining large-scale coverage, vertical atmospheric profiles, and multi-scale noise. It differs from [Procedural 3D Worley-Perlin Fractal Noise Density](5267-procedural-3d-worley-perlin-fractal-noise-density.md) by explicitly incorporating a global coverage mask and a vertical height profile to control cloud shape and altitude, rather than relying solely on raw fractal noise.

### Cone Tracing Cloud Sampling
Samples cloud density along a cone by iterating through a pre-generated noise kernel, transforming positions to weather map coordinates, and summing densities [S1, unofficial]. It initializes `density_along_cone = 0.0`, loops `i` from 0 to 5, calculates `lightpos = posInAtm + (cone_spread_multiplier * noise_kernel[i] * float(i))`, gets weather map coordinates via `GetRelativePointToWeatherMap`, samples weather data, gets relative height, gets atmosphere position `p`, and accumulates density by calling `SampleCloudDensity(p, weather_data, relativeHeight, false)` [S1, unofficial].

## Operating characteristics
- **Time Complexity:** $O(1)$ per sample for the base low-frequency pass. $O(1)$ for the high-frequency pass if enabled. Cone tracing is $O(k)$ where $k$ is the number of cone samples (e.g., 6).
- **Memory Complexity:** Depends on the size of `lowFrequencyTexture` and `highFrequencyTexture`. Typically stored in VRAM as 3D textures.
- **Performance:** The method is optimized for real-time rendering by using pre-computed textures instead of procedural noise generation at runtime. The `ischeap` flag allows skipping high-frequency details for distant clouds or lower-priority rendering passes.
- **Strengths:** Efficient, flexible, integrates well with weather data systems.
- **Limitations:** Requires pre-computed texture assets. The specific weighting scheme (0.625, 0.250, 0.125) is hardcoded and may not suit all artistic styles.

## Background
This method is derived from the implementation in the `realtime-volumetric-cloudscapes` repository [S1, unofficial]. It represents a common approach in real-time cloud rendering where density is evaluated via texture sampling rather than pure procedural noise, allowing for complex, pre-baked cloud structures.
