# Full Cloud Density Function


## Overview
The Full Cloud Density Function computes the volumetric density at a specific 3D point by combining large-scale coverage, vertical atmospheric profiles, and multi-scale noise. It differs from [Procedural 3D Worley-Perlin Fractal Noise Density](5267-procedural-3d-worley-perlin-fractal-noise-density.md) by explicitly incorporating a global coverage mask and a vertical height profile to control cloud shape and altitude, rather than relying solely on raw fractal noise.

## How it works
**Inputs:**
- `point`: 3D world-space position vector.
- `lod`: Level of detail parameter for high-frequency noise.

**Parameters:**
- `radius`: Radius of the cloud volume.
- `cloud_scale`: Scaling factor for large-scale Perlin noise.
- `gradient`, `multiplier`, `threshold`: Linear transformation constants for the coverage mask.
- `detail_scale`: Scaling factor for high-frequency noise.
- `cap`: Maximum density value.
- `powder_decay`: Decay rate for the powder sugar effect (used in scattering, not density calculation itself).

**Data Structures:**
- `cover`: A cubemap texture (e.g., 6x512x512) storing global cloud coverage.
- `cloud_profile`: A vertical profile texture (e.g., 10 values) mapping height to base density.

**Steps:**
1. **Large-Scale Shape:** Compute `clouds` using Perlin octaves on the normalized point scaled by `radius / cloud_scale`.
2. **Vertical Profile:** Compute `profile` using the vertical profile texture sampled at the point's height.
3. **Coverage Mask:** Sample the `cover` cubemap at `point`. Apply linear transformation: `cover_sample = texture(cover, point).r * gradient + clouds * multiplier - threshold`.
4. **Base Density:** Multiply coverage by vertical profile: `base = cover_sample * profile`.
5. **High-Frequency Detail:** Compute `noise` using Worley/Perlin octaves scaled by `detail_scale` and `lod`.
6. **Final Density:** Remap `noise` from `[1 - base, 1.0]` to `[0.0, cap]` and clamp to `[0.0, cap]`.

**Formulas:**
- `remap(value, original_min, original_max, new_min, new_max) = new_min + (value - original_min) / (original_max - original_min) * (new_max - new_min)`
- `density = clamp(remap(noise, 1 - base, 1.0, 0.0, cap), 0.0, cap)`

**Pseudocode:**
```python
def cloud_density(point: vec3, lod: float) -> float:
    # 1. Large-scale shape
    normalized_point = normalize(point)
    clouds = perlin_octaves(normalized_point * radius / cloud_scale)
    
    # 2. Vertical profile
    profile = cloud_profile(point)
    
    # 3. Coverage mask
    cover_sample = texture(cover, point).r * gradient + clouds * multiplier - threshold
    
    # 4. Base density
    base = cover_sample * profile
    
    # 5. High-frequency detail
    noise = cloud_octaves(point / detail_scale, lod)
    
    # 6. Final density
    # Remap noise from [1 - base, 1.0] to [0.0, cap]
    remapped = remap(noise, 1.0 - base, 1.0, 0.0, cap)
    density = clamp(remapped, 0.0, cap)
    
    return density

def remap(value: float, original_min: float, original_max: float, new_min: float, new_max: float) -> float:
    return new_min + (value - original_min) / (original_max - original_min) * (new_max - new_min)
```

**Edge Cases:**
- If `base` is 0, the remap range becomes `[1.0, 1.0]`, which may cause division by zero in `remap`. The source code does not explicitly handle this, but logically density should be 0 if base is 0. [G]
- The source notes an update removing clamping for the cover sample noise, but the final code snippet retains clamping for the final density.

## Subtopics

## Operating characteristics
- **Performance:** Rendered at 28.5 fps on an AMD Ryzen 7 4700U (PassMark 2034) at 640x480 resolution.
- **Memory:** Used 3 deep opacity maps, one 512x512 offset layer, a 7x512x512 transmittance array, and a 6x512x512 cubemap.
- **Noise:** 5 octaves of 64x64x64 Worley noise for detail; 3 octaves of 64x64x64 Perlin-Worley noise for horizontal shapes.
- **Strengths:** Efficiently combines global coverage with local detail.
- **Limitations:** Performance scales with resolution and noise complexity.

## Background
Originated by Jan Wedekind in an unofficial blog post describing procedural volumetric clouds. The method uses a combination of Perlin and Worley noise, vertical profiles, and cubemap coverage to generate realistic cloud densities.
