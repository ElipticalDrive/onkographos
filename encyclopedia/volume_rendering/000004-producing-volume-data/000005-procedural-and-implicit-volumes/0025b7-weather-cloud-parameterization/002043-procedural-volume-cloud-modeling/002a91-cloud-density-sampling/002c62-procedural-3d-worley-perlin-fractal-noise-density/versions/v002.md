# Procedural 3D Worley-Perlin Fractal Noise Density

Also called: Billowy fractal cumulus noise, Inverted Worley FBM Cloud Density, Multi-Octave Inverted Worley FBM

## Overview
Generates billowy cloud shapes by synthesizing cloud density $\rho(\mathbf{x})$ procedurally using inverted Worley fractal Brownian motion (FBM), vertical gradient attenuation, and coverage thresholding [S1, unofficial]. It differs from standard Perlin-based cloud noise by using the distance-to-nearest-cell metric of Worley noise, inverted to create bright, puffy "billowy" structures characteristic of cumulus clouds, rather than the smooth, turbulent gradients of Perlin noise [S1, unofficial].

## How it works
**Inputs:**
- World position $\mathbf{x} = (x, y, z)$ [S1, unofficial].
- Cloud volume bounds: `cloudBottom` and `cloudTop` (Y-coordinates) [S1, unofficial].
- Cloud coverage parameter `coverage` (float, typically 0.52) [S1, unofficial].
- Extinction coefficient $\sigma_t$ (float, typically 0.035) [S1, unofficial].
- FBM parameters: `octaves` (default 3), `scale` (default 0.0008) [S1, unofficial].

**Outputs:**
- Cloud density $\rho(\mathbf{x})$ [S1, unofficial].

**Data Structures:**
No persistent data structures are required; the method is stateless and procedural [S1, unofficial].

**Steps:**
1. Initialize FBM accumulators: `sum = 0.0`, `freq = 1.0`, `amp = 1.0`, `totalAmp = 0.0` [S1, unofficial].
2. Loop `i` from 0 to `octaves` (default 3): compute inverted Worley value $w = 1.0 - \text{worley3D}(x \cdot \text{freq}, y \cdot \text{freq}, z \cdot \text{freq})$, add to sum `sum += w * amp`, accumulate amplitude `totalAmp += amp`, update frequency `freq *= 2.0`, update amplitude `amp *= 0.5` [S1, unofficial].
3. Return normalized FBM sum: `sum / totalAmp` [S1, unofficial].
4. Check height bounds: if world Y coordinate $y$ is outside `[cloudBottom, cloudTop]`, return density $0.0$ [S1, unofficial].
5. Scale coordinates: `scale = 0.0008`, compute `baseNoise = worleyFBM(x * scale, y * scale, z * scale, octaves)` [S1, unofficial].
6. Compute height normalization: $h = \frac{y - \text{cloudBottom}}{\text{cloudTop} - \text{cloudBottom}}$ [S1, unofficial].
7. Compute height gradient: `heightGrad = sin(π * h)` [S1, unofficial].
8. Compute raw density: `rawDensity = (baseNoise * heightGrad) - (1.0 - coverage)` [S1, unofficial].
9. Return clamped and normalized density: `max(0.0, rawDensity / (coverage + 1e-4)) * σ_t` [S1, unofficial].

**Formulas:**
The normalized height $h$ is defined as:
$$ h = \frac{y - \text{cloudBottom}}{\text{cloudTop} - \text{cloudBottom}} $$

The final density $\rho(\mathbf{x})$ is:
$$ \rho(\mathbf{x}) = \max\left(0, \frac{\text{FBM}(\mathbf{x}) \cdot \sin(\pi h) - (1 - \text{coverage})}{\text{coverage}}\right) \cdot \sigma_t $$

Where $\text{FBM}(\mathbf{x})$ is the multi-octave inverted Worley noise value [S1, unofficial].

**Pseudocode:**

```python
import math

def hash_3d(x: int, y: int, z: int) -> float:
    """Deterministic integer hash mapped to [0, 1). Standard implementation detail [G]."""
    h = (x * 374761393 + y * 668265263 + z * 1274126177) & 0xFFFFFFFF
    h = (h ^ (h >> 13)) * 1274126177
    h = h ^ (h >> 16)
    return abs(h) / 4294967296.0

def worley3D(x: float, y: float, z: float) -> float:
    """Distance to the nearest cell center in a 3x3x3 grid."""
    ix, iy, iz = math.floor(x), math.floor(y), math.floor(z)
    min_dist_sq = float('inf')
    for dx in range(-1, 2):
        for dy in range(-1, 2):
            for dz in range(-1, 2):
                rx = hash_3d(ix + dx, iy + dy, iz + dz)
                ry = hash_3d(iy + dy, iz + dz, ix + dx)
                rz = hash_3d(iz + dz, ix + dx, iy + dy)
                dist_sq = (x - rx)**2 + (y - ry)**2 + (z - rz)**2
                if dist_sq < min_dist_sq:
                    min_dist_sq = dist_sq
    return math.sqrt(min_dist_sq)

def worleyFBM(x: float, y: float, z: float, octaves: int = 3) -> float:
    """Multi-octave inverted Worley FBM."""
    sum_val = 0.0
    freq = 1.0
    amp = 1.0
    total_amp = 0.0
    for _ in range(octaves):
        w = 1.0 - worley3D(x * freq, y * freq, z * freq)
        sum_val += w * amp
        total_amp += amp
        freq *= 2.0
        amp *= 0.5
    return sum_val / total_amp if total_amp != 0 else 0.0

def compute_cloud_density(x: float, y: float, z: float, 
                          cloud_bottom: float, cloud_top: float, 
                          coverage: float, sigma_t: float,
                          scale: float = 0.0008, octaves: int = 3) -> float:
    """Procedural 3D Worley-Perlin Fractal Noise Density."""
    if y < cloud_bottom or y > cloud_top:
        return 0.0
    base_noise = worleyFBM(x * scale, y * scale, z * scale, octaves)
    h_norm = (y - cloud_bottom) / (cloud_top - cloud_bottom)
    height_grad = math.sin(math.pi * h_norm)
    raw_density = (base_noise * height_grad) - (1.0 - coverage)
    epsilon = 1e-4
    normalized_density = max(0.0, raw_density / (coverage + epsilon))
    return normalized_density * sigma_t
```

**Edge Cases and Pitfalls:**
- **Height Culling:** Check if the world Y-coordinate $y$ is within `[cloudBottom, cloudTop]` [S1, unofficial].
- **Division by Zero:** The normalization step divides by `coverage` [S1, unofficial]. If `coverage` is 0, the result is undefined [S1, unofficial]. A small epsilon ($10^{-4}$) is added to the denominator to prevent division by zero [S1, unofficial].
- **Height Normalization:** If `cloudBottom` equals `cloudTop`, the height normalization $h$ is undefined [S1, unofficial].

## Subtopics

### Worley Noise
A cell-based noise function that uses the distance to the nearest seed point [S1, unofficial]. It produces cellular, puffy structures ideal for clouds [S1, unofficial].

### Fractal Brownian Motion (FBM)
A technique of summing multiple octaves of noise at different frequencies and amplitudes to create detailed, self-similar structures [S1, unofficial].

### Inverted Worley
Subtracting the Worley distance from 1.0 transforms the dark "cells" into bright "puffs," matching the visual appearance of cumulus clouds [S1, unofficial].
