# IsimCloudTexture density evaluation

Also called: Cloud texture generation, IsimCloudTexture, Procedural Cloud Density Generation

## Overview
IsimCloudTexture density evaluation computes the volumetric density of a cloud at a given point in space by combining geometric primitives (text segments or implicit cloud bodies), fractal Brownian motion (FBM) noise, and depth-based fading [S1, S2, unofficial]. It differs from general procedural gas modeling by focusing on specific cloud structures and from simple cloud density sampling by generating the density field procedurally via direct evaluation or CUDA kernels [S1, S2, unofficial]. The method outputs a grayscale density value replicated to an RGB vector suitable for volume rendering [S1, unofficial].

## How it works
The method implements two distinct evaluation approaches: a text-segment-based approach and a CUDA-generated implicit body approach. Both evaluate density at a point $p$ or grid index $(x,y,z)$.

### Inputs and Outputs
*   **Inputs**:
    *   Point $p = (p.x, p.y, p.z)$ in world or local space [S1, unofficial].
    *   Grid indices $(x, y, z)$ and dimensions $(width, height, depth)$ for the CUDA approach [S2, unofficial].
    *   Volume bounds $box_{min}$ and $box_{max}$ [S1, unofficial].
    *   Text segments defining letter shapes for the text-based approach [S1, unofficial].
    *   Noise generator instance with FBM capability [S1, S2, unofficial].
    *   Parameters: $cloud\_scale$, $letter\_radius$, $smooth\_width$, $segments$ (text-based); thread block size, grid size (CUDA) [S1, S2, unofficial].
*   **Outputs**:
    *   Density value $d \in [0, 1]$ [S1, S2, unofficial].
    *   RGB vector $(d, d, d)$ [S1, unofficial].
    *   Written to a 3D texture/surface object [S2, unofficial].

### Data Structures
*   **Point3/Vector3**: 3D vector with components $x, y, z$ [S1, unofficial].
*   **Segment**: Defined by endpoints, used for distance calculation [S1, unofficial].
*   **3D Texture/Surface**: Output container for the computed density field [S2, unofficial].

### Steps

#### Method 1: Text Segment Based
1.  **Boundary Check**: If $p$ is outside $box_{min}$ and $box_{max}$, return $(0, 0, 0)$ [S1, unofficial].
2.  **Text Density Calculation**:
    *   Initialize $text\_density = 0.0$ [S1, unofficial].
    *   For each segment in $segments$:
        *   Compute squared distance $d_{sq}$ from $p$ to the segment [S1, unofficial].
        *   If $d_{sq} < (letter\_radius + smooth\_width)^2$:
            *   Compute $d = \sqrt{d_{sq}}$ [S1, unofficial].
            *   Update $text\_density = \max(text\_density, \text{smoothstep}(letter\_radius + smooth\_width, letter\_radius, d))$ [S1, unofficial].
    *   If $text\_density < 0.001$, return $(0, 0, 0)$ [S1, unofficial].
3.  **Noise Evaluation**:
    *   Compute $n = \text{noise\_}.fbm(p \times cloud\_scale, 5)$ [S1, unofficial].
    *   Compute $cloud\_noise = \text{clamp}((n - 0.3) \times 3.0, 0.0, 1.0)$ [S1, unofficial].
4.  **Combine**:
    *   $final\_density = text\_density \times cloud\_noise$ [S1, unofficial].
5.  **Depth Fading**:
    *   Compute $center\_z = (box_{min}.z + box_{max}.z) \times 0.5$ [S1, unofficial].
    *   Compute $depth\_fade = \text{smoothstep}(1.5, 0.5, |p.z - center\_z|)$ [S1, unofficial].
    *   $final\_density = final\_density \times depth\_fade$ [S1, unofficial].
6.  **Return**: $(final\_density, final\_density, final\_density)$ [S1, unofficial].

#### Method 2: CUDA Implicit Body
1.  **Coordinate Normalization**:
    *   Calculate normalized device coordinates $px, py, pz \in [-1, 1]$ from thread indices $(x, y, z)$ and dimensions $(width, height, depth)$:
        $$px = 2.0 \times \frac{x}{width - 1} - 1.0$$
        $$py = 2.0 \times \frac{y}{height - 1} - 1.0$$
        $$pz = 2.0 \times \frac{z}{depth - 1} - 1.0$$
    [S2, unofficial]
2.  **Upper Cloud Body**:
    *   Calculate warped coordinates:
        $$upperX = px - 0.18 \times \sin(4.0 \times py)$$
        $$upperZ = pz - 0.12 \times \cos(5.0 \times py)$$
    [S2, unofficial]
    *   Compute upper cloud density:
        $$upperCloud = \exp(-8.0 \times (upperX^2 + upperZ^2) - 3.5 \times (py - 0.35)^2)$$
    [S2, unofficial]
3.  **Lower Cloud Body**:
    *   Compute lower cloud density:
        $$lowerCloud = \exp(-4.5 \times (px^2 + pz^2) - 2.2 \times (py + 0.25)^2)$$
    [S2, unofficial]
4.  **Detail Noise**:
    *   Compute detail factor:
        $$detail = 0.68 + 0.20 \times \sin(11.0 \times px + 7.0 \times py) \times \sin(9.0 \times pz - 5.0 \times py) + 0.12 \times \sin(23.0 \times (px + pz))$$
    [S2, unofficial]
5.  **Boundary Fade**:
    *   Compute boundary fade factor:
        $$boundaryFade = \text{saturate}((1.0 - \max(|px|, |py|, |pz|)) \times 8.0)$$
        where $\text{saturate}(v) = \min(\max(v, 0.0), 1.0)$ [S2, unofficial].
6.  **Final Density**:
    *   Combine components:
        $$density = \text{saturate}((0.85 \times lowerCloud + 0.75 \times upperCloud - 0.18) \times detail \times boundaryFade)$$
    [S2, unofficial]
7.  **Write Output**:
    *   Write $density$ to the 3D output texture at $(x, y, z)$ [S2, unofficial].

### Pseudocode
```python
import math

def smoothstep(edge0, edge1, x):
    if edge1 == edge0:
        return 0.0
    t = max(0.0, min(1.0, (x - edge0) / (edge1 - edge0)))
    return t * t * (3.0 - 2.0 * t)

def clamp(v, min_val, max_val):
    return max(min_val, min(v, max_val))

def saturate(v):
    return max(0.0, min(v, 1.0))

def distance_point_to_segment(p, seg_start, seg_end):
    seg_vec = (seg_end[0] - seg_start[0], seg_end[1] - seg_start[1], seg_end[2] - seg_start[2])
    p_vec = (p[0] - seg_start[0], p[1] - seg_start[1], p[2] - seg_start[2])
    seg_len_sq = seg_vec[0]**2 + seg_vec[1]**2 + seg_vec[2]**2
    if seg_len_sq == 0:
        return math.sqrt(p_vec[0]**2 + p_vec[1]**2 + p_vec[2]**2)
    t = clamp((p_vec[0]*seg_vec[0] + p_vec[1]*seg_vec[1] + p_vec[2]*seg_vec[2]) / seg_len_sq, 0.0, 1.0)
    projection = (seg_start[0] + seg_vec[0]*t, seg_start[1] + seg_vec[1]*t, seg_start[2] + seg_vec[2]*t)
    diff = (p[0]-projection[0], p[1]-projection[1], p[2]-projection[2])
    return math.sqrt(diff[0]**2 + diff[1]**2 + diff[2]**2)

def fbm_noise(p, scale, octaves):
    # [G] Standard 3D value noise with trilinear interpolation
    value = 0.0
    amplitude = 0.5
    frequency = 1.0
    for _ in range(octaves):
        value += amplitude * hash_3d_noise(p[0]*frequency*scale, p[1]*frequency*scale, p[2]*frequency*scale)
        amplitude *= 0.5
        frequency *= 2.0
    return value

def hash_3d_noise(x, y, z):
    ix, iy, iz = int(math.floor(x)), int(math.floor(y)), int(math.floor(z))
    fx, fy, fz = x - ix, y - iy, z - iz
    u = fx*fx*(3.0 - 2.0*fx)
    v = fy*fy*(3.0 - 2.0*fy)
    w = fz*fz*(3.0 - 2.0*fz)
    def h(a, b, c): return (hash((a, b, c)) & 0x7fffffff) / 0x7fffffff
    a, b, c, d = h(ix, iy, iz), h(ix+1, iy, iz), h(ix, iy+1, iz), h(ix+1, iy+1, iz)
    e, f, g, h_val = h(ix, iy, iz+1), h(ix+1, iy, iz+1), h(ix, iy+1, iz+1), h(ix+1, iy+1, iz+1)
    return a + u*(b-a) + v*(c-a-(b-a)) + w*(e-a-(c-a)-(b-a)+(b-a))

def evaluate_isimcloud_text(p, box_min, box_max, segments, letter_radius, smooth_width, cloud_scale):
    if not (box_min[0] <= p[0] <= box_max[0] and box_min[1] <= p[1] <= box_max[1] and box_min[2] <= p[2] <= box_max[2]):
        return (0.0, 0.0, 0.0)
    text_density = 0.0
    for seg in segments:
        d = distance_point_to_segment(p, seg[0], seg[1])
        if d < (letter_radius + smooth_width):
            density_val = smoothstep(letter_radius + smooth_width, letter_radius, d)
            if density_val > text_density:
                text_density = density_val
    if text_density < 0.001:
        return (0.0, 0.0, 0.0)
    n = fbm_noise(p, cloud_scale, 5)
    cloud_noise = clamp((n - 0.3) * 3.0, 0.0, 1.0)
    final_density = text_density * cloud_noise
    center_z = (box_min[2] + box_max[2]) * 0.5
    depth_fade = smoothstep(1.5, 0.5, abs(p[2] - center_z))
    final_density *= depth_fade
    return (final_density, final_density, final_density)

def evaluate_isimcloud_cuda(x, y, z, width, height, depth):
    px = 2.0 * x / (width - 1) - 1.0
    py = 2.0 * y / (height - 1) - 1.0
    pz = 2.0 * z / (depth - 1) - 1.0
    upperX = px - 0.18 * math.sin(4.0 * py)
    upperZ = pz - 0.12 * math.cos(5.0 * py)
    upperCloud = math.exp(-8.0 * (upperX**2 + upperZ**2) - 3.5 * (py - 0.35)**2)
    lowerCloud = math.exp(-4.5 * (px**2 + pz**2) - 2.2 * (py + 0.25)**2)
    detail = 0.68 + 0.20 * math.sin(11.0 * px + 7.0 * py) * math.sin(9.0 * pz - 5.0 * py) + 0.12 * math.sin(23.0 * (px + pz))
    max_abs = max(abs(px), abs(py), abs(pz))
    boundaryFade = saturate((1.0 - max_abs) * 8.0)
    density = saturate((0.85 * lowerCloud + 0.75 * upperCloud - 0.18) * detail * boundaryFade)
    return density
```

### Parameters
*   **cloud_scale**: Scales input position for noise evaluation [S1, unofficial].
*   **letter_radius**: Radius for text segment influence, typically 0.25 [S1, unofficial].
*   **smooth_width**: Smoothness width for text segments, typically 0.2 [S1, unofficial].
*   **segments**: Vector of line segments defining letter shapes [S1, unofficial].
*   **box_min, box_max**: Volume bounds [S1, unofficial].
*   **Thread block size**: 8x8x8 threads (dim3 threads{8, 8, 8}) [S2, unofficial].
*   **Grid size**: $\lceil width/8 \rceil \times \lceil height/8 \rceil \times \lceil depth/8 \rceil$ blocks [S2, unofficial].

### Edge Cases and Pitfalls
*   **Division by Zero**: In `smoothstep`, if `edge0 == edge1`, division by zero occurs; the sources assume valid ranges where `edge0 < edge1` [S1, unofficial].
*   **Null Vector**: Normalization operations throw if the vector norm is zero [S1, unofficial].
*   **Boundary Conditions**: Points outside the bounding box return zero density immediately [S1, unofficial].
*   **Precision**: CUDA implementation uses `float` (32-bit) while C++ implementation uses `double` (64-bit) for intermediate calculations [S1, S2, unofficial].

## Operating characteristics
*   **Time Complexity**: $O(S)$ per point for the text-segment approach, where $S$ is the number of segments. $O(1)$ per voxel for the CUDA implicit body approach [S1, S2, unofficial].
*   **Memory Complexity**: $O(S)$ for storing segments in the text-segment approach. $O(1)$ auxiliary memory for the CUDA approach, plus output texture storage [S1, S2, unofficial].
*   **Performance**: The CUDA approach is optimized for GPU execution via 8x8x8 thread blocks [S2, unofficial].
*   **Strengths**: Procedural generation allows infinite resolution and easy parameter tweaking [S1, S2, unofficial].
*   **Limitations**: The text-segment approach requires explicit segment definitions. The CUDA approach is hardcoded to specific implicit shapes [S1, S2, unofficial].

## Background
The method is implemented in two unofficial GitHub repositories: "Volumetric-Path-Tracing" by TakTikFR and "HZL-fluidEffectsStudio" by pvasbob [S1, S2, unofficial]. It is used in procedural volume cloud modeling to generate density fields for visualization [S1, S2, unofficial].
