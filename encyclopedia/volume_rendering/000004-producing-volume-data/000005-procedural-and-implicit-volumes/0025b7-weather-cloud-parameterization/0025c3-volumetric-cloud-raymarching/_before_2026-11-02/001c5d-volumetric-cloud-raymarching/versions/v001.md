# Volumetric Cloud Raymarching

Also called: Cloud Raymarching, Cloud Volume Rendering, Real-Time Volumetric Cloud Rendering, Volumetric Cloud Rendering

## Overview
Volumetric cloud raymarching is a technique for rendering volumetric clouds by tracing a ray through a 3D density field, accumulating color based on density, light scattering, and transmittance [S3, unofficial]. It differs from solid geometry ray marching by accumulating color and transmittance over a fixed number of steps or until transmittance drops below a threshold, rather than breaking on the first hit [S1, unofficial]. Unlike billboard or particle clouds, it represents true 3D density fields that interact with light realistically [S3, unofficial].

## How it works
**Inputs and Outputs:**
*   **Inputs:** Camera position, camera ray direction, cloud volume bounds (min/max), light direction/color, 3D noise textures (base shape, detail/fBm, erosion), and parameters (step size, extinction, scattering coefficients).
*   **Outputs:** Final pixel color (RGB) and alpha/transmittance.

**Data Structures:**
*   **Cloud Volume Bounds:** `boundsMin` (float3), `boundsMax` (float3) defining the axis-aligned box containing the clouds [S2, unofficial].
*   **Noise Textures:** 3D textures (`Texture3D`) storing density values. Common formats include `ARGBFloat` with dimensions like 128x128x128 [S3, unofficial]. Textures may include base shape noise, high-resolution detail noise, and erosion noise [S3, unofficial].
*   **Uniforms/Constants:** Parameters such as `uCloudExtinction`, `uCloudLightStep`, `uCloudLightAtt`, `uCloudScatterMin`, `uCloudScatterMax`, `uCloudBrightness`, `uCloudStepMult`, `cloudCenter`, `cloudRadius`, `cloudDensity`, `noiseScale`, `boundsMin`, `boundsMax`, `cloud_densityThr`, `cloud_densityMul`, `cloud_offset`, `offsetSpeed`, `volume_march_steps`, `light_march_steps`, `detail_scale`, `detail_offset`, `detail_weight`, `frwrd_scatter`, `back_scatter`, `base_brightness`, `phase_factor`, `random_sample`, `optimized_march`, `lightAbsorptionThroughCloud`, `darknessThreshold` [S1, S2, unofficial].

**Numbered Steps:**

1.  **Ray-Volume Intersection:**
    Calculate the intersection of the camera ray with the cloud volume.
    *   *Sphere Intersection (Alternative):* If the volume is spherical, calculate `oc = ro - cloudCenter`, `b = dot(oc, rd)`, `c = dot(oc, oc) - cloudRadius * cloudRadius`, `disc = b*b - c`. If `disc < 0`, return transparent. Entry `t0 = max(0.0, -b - sqrt(disc))`, Exit `t1 = min(maxDist, -b + sqrt(disc))` [S1, unofficial].
    *   *Box Intersection (Standard):* Compute `t0 = (boundsMin - rayOrigin) / rayDir` and `t1 = (boundsMax - rayOrigin) / rayDir`. Determine `dstToBox = max(0.0f, max(max(tmin.x, tmin.y), tmin.z))` and `dstInsideObj = max(0.0f, min(tmax.x, min(tmax.y, tmax.z)) - dstToBox)` [S2, unofficial]. If `dstInsideObj <= 0`, return transparent.

2.  **Initialization:**
    Initialize step size, loop variable `t` (or `dstTravelled`), accumulated color `col` (or `result`), and transmittance `trans` (or `transmittance`) to 1.0 [S1, S2, S3, unofficial].
    *   *Step Size:* `step = (t1 - t0) / (96.0 * uCloudStepMult)` [S1, unofficial] or `stepSize = aDistance / volume_march_steps` [S2, unofficial] or fixed `100.0` [S3, unofficial].
    *   *Entry Point:* `entryPoint = rayOrigin + rayDir * dstToObj` [S2, unofficial].

3.  **Marching Loop:**
    Iterate for a fixed number of steps (e.g., 96 [S1, unofficial], `volume_march_steps` [S2, unofficial], or 128 [S3, unofficial]) or until `transmittance < 0.01` [S1, S2, S3, unofficial].
    *   *Position:* `p = ro + rd * t` [S1, unofficial] or `rayPos = anEntryPoint + aRayDir * dstTravelled` [S2, S3, unofficial].
    *   *Density Sampling:* Sample the density field at `p`.
        *   *Simple Method:* `density = SampleCloudDensity(p)` [S3, unofficial].
        *   *Advanced Method:* Sample low-res shape noise, apply threshold and multiplier, sample high-res detail noise (fBm), trim cloud using erosion and falloff functions [S2, unofficial].
            *   `uvw = (size * 0.5f + aPos) * baseScale * base_Scale` [S2, unofficial].
            *   `shapeNoise = shapeNoiseTex.Sample(uvw + cloud_offset * offsetSpeed).r` [S2, unofficial].
            *   `density = (shapeNoise - cloud_densityThr) * cloud_densityMul` [S2, unofficial].
            *   `detailFBM = SampleHighRes(uvw)` [S2, unofficial].
            *   `trimmedCloud = TrimCloud(aPos, density, detailFBM)` [S2, unofficial].
            *   `density = trimmedCloud * EdgeFallof(aPos) * HeightFallof(aPos)` [S2, unofficial].
    *   *Lighting Calculation:* If `density > 0` (or threshold like 0.001 [S1, unofficial], 0.01 [S3, unofficial]):
        *   *Shadow Ray:* Trace towards the light source to compute light attenuation.
            *   *Simple:* Loop 6 times, sampling density along light direction `L`, accumulating `lightSample += cloudDensityField(lp)`. `lightAtt = exp(-lightSample * uCloudLightAtt)` [S1, unofficial].
            *   *Advanced:* Call `LightMarch(rayPos, cosAngle)` which performs a box intersection with the cloud volume and accumulates optical depth using `MultipleOctaveScattering` [S2, unofficial].
        *   *Scatter Factor:* `scatter = mix(uCloudScatterMin, uCloudScatterMax, lightAtt)` [S1, unofficial] or compute phase function using Henyey-Greenstein [S2, unofficial].
    *   *Color Accumulation:*
        *   `cloudColor = vec3(uCloudBrightness) * scatter` [S1, unofficial] or `lightEnergy += density * stepSize * transmittance * lightTransmittance * phaseVal` [S2, unofficial].
        *   `col += trans * cloudColor * d * 0.5` [S1, unofficial] or `result += density * light * transmittance` [S3, unofficial].
        *   *Transmittance Update:* `trans *= exp(-d * uCloudExtinction)` [S1, unofficial] or `transmittance *= exp(-density * stepSize * 0.02)` [S3, unofficial] or `transmittance *= BeersLaw(density * stepSize * lightAbsorptionThroughCloud)` [S2, unofficial].
    *   *Early Exit:* If `transmittance < 0.01`, break loop [S1, S2, S3, unofficial].
    *   *Advance:* `t += step` [S1, unofficial] or `dstTravelled += stepSize` [S2, S3, unofficial].

4.  **Final Output:**
    Return `vec4(col, 1.0 - trans)` [S1, unofficial] or `float4(col, transmittance)` [S2, S3, unofficial].

**Formulas:**
*   **Density Field:** `shape = smoothstep(1.2, 0.6, sphere) * flatBottom`, where `sphere = length(vec3(q.x, q.y * 0.55, q.z))`, `flatBottom = smoothstep(-0.2, 0.0, q.y)`, `q = (p - cloudCenter) / cloudRadius`. Final `d = shape * detail * cloudDensity` [S1, unofficial].
*   **Beer's Law:** $T = e^{-aDist}$, where $aDist$ is the optical depth [S2, S3, unofficial].
*   **Powder Function:** $P = 1 - e^{-2 \times aDist}$ [S2, unofficial].
*   **Henyey-Greenstein Phase Function:** $P(g, \cos\theta) = \frac{1 - g^2}{4 \pi (1 + g^2 - 2 g \cos\theta)^{1.5}}$ [S2, unofficial].
*   **Remap:** $v_{new} = minNew + (v_{old} - minOld) \times \frac{maxNew - minNew}{maxOld - minOld}$ [S2, unofficial].
*   **Density Composition:** `density = BaseNoise - Erosion` [S3, unofficial].

**Pseudocode:**

```python
def render_volumetric_clouds(ray_origin, ray_dir, bounds_min, bounds_max, noise_textures, params):
    # 1. Ray-Box Intersection
    t0 = (bounds_min - ray_origin) / ray_dir
    t1 = (bounds_max - ray_origin) / ray_dir
    t_min = min(t0, t1)
    t_max = max(t0, t1)
    
    dst_to_box = max(0.0, max(t_min.x, max(t_min.y, t_min.z)))
    dst_inside = max(0.0, min(t_max.x, min(t_max.y, t_max.z)) - dst_to_box)
    
    if dst_inside <= 0.0:
        return float4(0.0, 0.0, 0.0, 1.0)
    
    # 2. Initialization
    step_size = dst_inside / params.volume_march_steps
    ray_pos = ray_origin + ray_dir * dst_to_box
    transmittance = 1.0
    accumulated_color = float3(0.0, 0.0, 0.0)
    
    # Pre-calculate light direction and phase
    dir_to_light = normalize(params.light_position - ray_origin)
    cos_angle = dot(ray_dir, dir_to_light)
    phase_val = henyey_greenstein_phase(cos_angle, params.frwrd_scatter, params.back_scatter, params.base_brightness, params.phase_factor)
    
    # 3. Marching Loop
    for i in range(params.volume_march_steps):
        if transmittance < 0.01:
            break
            
        density = sample_cloud_density(ray_pos, noise_textures, params)
        
        if density > 0.0:
            # Compute light transmittance (shadowing)
            light_transmittance = compute_light_march(ray_pos, dir_to_light, bounds_max, bounds_min, noise_textures, params)
            
            # Accumulate scattered light
            light_energy = density * step_size * transmittance * light_transmittance * phase_val
            accumulated_color += light_energy
            
            # Update transmittance
            transmittance *= exp(-density * step_size * params.lightAbsorptionThroughCloud)
            
        ray_pos += ray_dir * step_size
        
    # 4. Final Color
    # Apply fog/atmospheric scattering if needed (simplified here)
    final_color = accumulated_color + (1.0 - transmittance) * params.ambient_color
    
    return float4(final_color, transmittance)

def sample_cloud_density(pos, textures, params):
    # Simple method from [S3, unofficial]
    uvw = pos * 0.0005
    base_noise = textures['base'].sample(uvw).r
    erosion = textures['erosion'].sample(uvw * 0.5).r
    density = base_noise - erosion * 0.6
    return saturate(density)

def compute_light_march(pos, dir_to_light, bounds_min, bounds_max, textures, params):
    # Simple shadow march from [S3, unofficial]
    light = 1.0
    step = 300.0
    current_pos = pos
    for _ in range(6):
        current_pos += dir_to_light * step
        d = sample_cloud_density(current_pos, textures, params)
        light *= exp(-d * 0.1)
    return light

def henyey_greenstein_phase(cos_theta, g_front, g_back, base_bright, phase_fac):
    # Simplified phase function
    hg_front = henyey_greenstein(g_front, cos_theta)
    hg_back = henyey_greenstein(-g_back, cos_theta)
    return base_bright + (hg_front * 0.3 + hg_back * 0.7) * phase_fac

def henyey_greenstein(g, cos_theta):
    g2 = g * g
    return (1 - g2) / (4 * 3.14159 * pow(1 + g2 - 2 * g * cos_theta, 1.5))
```

**Edge Cases and Pitfalls:**
*   **Light Marching Vector Bug:** In some implementations, adding a vector (`dirToLight * stepSize`) to a scalar (`dstTravelled`) and a scalar to a vector (`aPos`) is a logic error [S2, unofficial].
*   **Edge Falloff Bug:** Using `dstFromEdgeX` twice in the `min` function for edge weight ignores the Z-axis falloff [S2, unofficial].
*   **Precision:** Floating point precision issues may arise in large coordinate spaces; using local coordinates or normalized UVs helps [S3, unofficial].
*   **Degenerate Input:** If the ray does not intersect the volume, return transparent immediately [S1, S2, unofficial].

## Operating characteristics
*   **Time Complexity:** Linear with respect to the number of raymarch steps ($O(N)$ where $N$ is `volume_march_steps` or fixed iterations like 96/128) [S1, S3, unofficial]. Lighting calculations add a secondary loop ($O(M)$ where $M$ is `light_march_steps` or 6) [S1, S3, unofficial].
*   **Memory Complexity:** Depends on the size of the 3D noise textures. A 128x128x128 `ARGBFloat` texture consumes approximately 8 MB [S3, unofficial].
*   **Measured Performance:** Rendering at quarter resolution with TAA upscale is common in AAA games to mitigate performance costs [S3, unofficial]. Typical step counts range from 64 to 128 [S3, unofficial].
*   **Strengths:** Realistic light interaction (volumetric shadows, subsurface scattering approximation), true 3D structure, smooth transitions [S3, unofficial].
*   **Limitations:** Computationally expensive due to multiple texture samples and lighting calculations per pixel [S3, unofficial]. Sensitive to noise artifacts if steps are too few [S3, unofficial].
*   **When to Use:** When realistic volumetric lighting and 3D cloud structure are required [S3, unofficial].
*   **When Not to Use:** When performance is critical and simple billboards or sprites are sufficient [S3, unofficial].

## Background
Volumetric cloud rendering has evolved from simple billboards to complex raymarched density fields. Modern real-time implementations often use 3D noise textures (Perlin, Worley) combined with raymarching to approximate atmospheric scattering [S3, unofficial]. The technique is widely used in modern game engines to achieve cinematic quality skies [S3, unofficial].
