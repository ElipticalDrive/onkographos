# Fixed-Step Raymarching with Beer's Law

Also called: Fixed-Step Raymarcher, MarchDensity, Volumetric Cloud Density Marching, Volumetric Cloud Renderer

## Overview
Fixed-Step Raymarching with Beer's Law is a real-time volumetric rendering technique that simulates cloud-like structures by tracing rays through a 3D density field and integrating light attenuation using Beer's Law [S1, S2, unofficial]. It differs from its parent [Volumetric Cloud Raymarching](1248-volumetric-cloud-raymarching.md) by explicitly decoupling density sampling (via Worley and Perlin noise) from radiative transfer, applying a fixed step size for deterministic traversal rather than adaptive stepping [S1, S2, unofficial]. It differs from its child [Volumetric Ray Marching with Noise](2562-volumetric-ray-marching-with-noise.md) by relying on scalar density thresholds and Beer's Law for transmittance, whereas the child uses normalized noise vectors to modulate density and light accumulation directly [S1, unofficial].

## How it works
**Inputs:**
- Camera position, ray direction ($\vec{d}$) derived from UV coordinates [S1, S2, unofficial].
- Cloud volume bounding box (AABB) defined by $\vec{B}_{min}$ and $\vec{B}_{max}$ [S1, S2, unofficial].
- Sun direction ($\vec{S}_{dir}$) and Sun color ($C_{sun}$) [S2, unofficial].
- Noise textures or procedural functions for Worley ($N_W$) and Perlin ($N_P$) noise [S1, S2, unofficial].
- Parameters: $STEP\_SIZE$, $LIGHT\_STEP\_SIZE$, $MAX\_STEPS$, $uUserDensity$, $\vec{uUserScale}$, $\_DensityThreshold$, $\_AbsorptionCoefficient$, $\_ScatterFactor$, $\_CloudScale$, $\_OctaveCount$ [S1, S2, unofficial].

**Outputs:**
- Final pixel color and alpha/transmittance [S1, S2, unofficial]. Source [S1, unofficial] returns a fixed alpha of 1.0, while source [S2, unofficial] returns alpha as $1 - T_{final}$ [S1, S2, unofficial].

**Data Structures:**
- `ray`: Struct containing origin ($\vec{o}$) and direction ($\vec{d}$) [S1, unofficial].
- `hitData`: Struct containing entry distance ($t_{entry}$) and exit distance ($t_{exit}$) from AABB intersection [S1, unofficial].

**Steps:**

1.  **Ray Initialization:**
    Calculate the view ray direction $\vec{d}$ from the camera position and screen UV coordinates. Apply any camera rotation matrix if required [S1, unofficial].

2.  **AABB Intersection:**
    Intersect the view ray with the cloud volume AABB.
    - If no intersection, return the sky color [S1, unofficial].
    - Let $t_{entry}$ and $t_{exit}$ be the distances to the entry and exit points along the ray [S1, S2, unofficial].
    - *Edge Case:* If the camera is inside the volume, the march starts from the camera position or the calculated entry point [S1, unofficial].

3.  **Initialization:**
    - Initialize `densityTotal` = 0.0 [S2, unofficial].
    - Initialize `brightness` = 0.0 [S2, unofficial].
    - Initialize `globalTransmittance` = 1.0 [S1, unofficial].
    - Initialize `cloudColor` = $(0, 0, 0)$ [S1, unofficial].
    - Initialize `distanceTravelled` = $t_{entry}$ [S2, unofficial].

4.  **Main Raymarch Loop:**
    Loop for $i$ from 0 to `stepLimit` (exclusive) [S2, unofficial]:
    - *Check Exit:* If `distanceTravelled` > $t_{exit}$, break loop [S2, unofficial].
    - *Check Max Steps:* If $i \ge MAX\_STEPS$, break loop [S1, unofficial].
    - Calculate current march point: $\vec{p}_{march} = \vec{o} + \vec{d} \cdot \text{distanceTravelled}$ [S2, unofficial].

    4.1. **Density Sampling:**
    - Calculate world-scaled position: $\vec{p}_{world} = \vec{p}_{march} \cdot \_CloudScale$ [S2, unofficial].
    - Accumulate Worley noise over octaves: initialize `worleyDensity` = 0.0, `amplitude` = 1.0, `frequency` = 1.0, `amplitudeTotal` = 0.0 [S2, unofficial].
    - Loop octave from 0 to `_OctaveCount` (exclusive) [S2, unofficial]:
      - Accumulate `worleyDensity` by adding the red channel of the noise texture sampled at $\vec{p}_{world} \cdot \text{frequency}$, multiplied by `amplitude` [S2, unofficial].
      - Accumulate `amplitudeTotal` by adding `amplitude` [S2, unofficial].
      - Halve `amplitude` (`amplitude` *= 0.5) [S2, unofficial].
      - Double `frequency` (`frequency` *= 2.0) [S2, unofficial].
    - Normalize `worleyDensity` by dividing by `amplitudeTotal` if `amplitudeTotal` > 0, else set to 0.0 [S2, unofficial].
    - Sample Perlin noise $N_P$ at $\vec{p}_{world}$ [S2, unofficial].
    - Calculate final density: $\rho = N_W \cdot N_P$ [S2, unofficial].
    - Normalize density: $\rho = \rho / uUserDensity$ [S1, S2, unofficial].

    4.2. **Density Thresholding:**
    - If $\rho < 0.05$, skip to next step (continue) [S1, S2, unofficial].
    - If $\rho < \_DensityThreshold$, skip accumulation [S2, unofficial].

    4.3. **Accumulate Density:**
    - `densityTotal` += $\rho \cdot STEP\_SIZE$ [S2, unofficial].

    4.4. **Light Ray Marching (Secondary Ray):**
    - Define light ray origin: $\vec{o}_{light} = \vec{p}_{march}$ [S1, unofficial].
    - Define light ray direction: $\vec{d}_{light} = \text{normalize}(\vec{S}_{dir})$ [S1, S2, unofficial].
    - Intersect light ray with AABB to find max light distance $t_{light\_max}$ [S1, unofficial].
    - Initialize `currentLightRayT` = 1.0 [S1, unofficial].
    - Loop for light step $lS$ from $STEP\_SIZE$ to $MAX\_STEPS$ with increment $LIGHT\_STEP\_SIZE$ [S1, unofficial]:
      - If $lS \ge t_{light\_max}$, break [S1, unofficial].
      - Calculate light march point: $\vec{p}_{light} = \vec{o}_{light} + \vec{d}_{light} \cdot lS$ [S1, unofficial].
      - Sample density $\rho_{light}$ at $\vec{p}_{light}$ (using same noise/scale logic) [S1, unofficial].
      - If $\rho_{light} < 0.05$, continue [S1, unofficial].
      - Update light transmittance: `currentLightRayT` *= $\exp(-\rho_{light} \cdot LIGHT\_STEP\_SIZE)$ [S1, unofficial].

    4.5. **Scattering and Color Accumulation:**
    - Calculate local transmittance: $T_{local} = \exp(-\rho \cdot STEP\_SIZE)$ [S1, unofficial].
    - Calculate scattering term: S1 uses $S = (1.0 - T_{local}) \cdot \text{currentLightRayT}$ [S1, unofficial]. S2 uses Henyey-Greenstein phase function $HG(\vec{d}, \vec{S}_{dir}, \_ScatterFactor)$ and Beer's Law: $T_{cam} = \exp(-\text{densityTotal} \cdot \_AbsorptionCoefficient)$ [S2, unofficial].
    - Accumulate brightness: S1 adds `globalTransmittance * S * C_sun` [S1, unofficial]. S2 adds $\rho \cdot \text{currentLightRayT} \cdot T_{cam} \cdot S \cdot STEP\_SIZE \cdot 0.5$ [S2, unofficial].
    - Update `globalTransmittance` *= $T_{local}$ [S1, unofficial].

    4.6. **Step Increment:**
    - `distanceTravelled` += $STEP\_SIZE$ [S2, unofficial].

5.  **Final Compositing:**
    - S1 calculates `col = cloudColor + col * globalTransmittance` (where `col` is initialized to sky color) and returns `vec4(col, 1.0)` [S1, unofficial].
    - S2 calculates `cloudColour = brightness * C_sun`, `cloudTransmittance = exp(-densityTotal * _AbsorptionCoefficient)`, and returns `float4(cloudColour, 1 - cloudTransmittance)` [S2, unofficial].
    - *Pitfall:* If the dot product of the view direction and sun direction is $> 0.9995$, mix in a special sun glare color [S1, unofficial].

**Pseudocode:**

```python
def fixed_step_raymarch(ray_origin, ray_direction, box_min, box_max, sun_dir, sun_color, noise_func, params):
    """
    ray_origin: vec3
    ray_direction: vec3
    box_min: vec3
    box_max: vec3
    sun_dir: vec3
    sun_color: vec3
    noise_func: function(vec3) -> float (returns density value)
    params: dict containing stepSize, stepLimit, lightStepSize, maxSteps, uUserDensity, 
            densityThreshold, absorptionCoefficient, scatterFactor, cloudScale, octaveCount
    """
    
    # Helper: Standard AABB intersection
    def intersect_aabb(origin, direction, bmin, bmax):
        tmin = (bmin - origin) / direction
        tmax = (bmax - origin) / direction
        t_entry = max(min(tmin.x, tmax.x), min(tmin.y, tmax.y), min(tmin.z, tmax.z))
        t_exit = min(max(tmin.x, tmax.x), max(tmin.y, tmax.y), max(tmin.z, tmax.z))
        if t_entry > t_exit: return None
        return {'t_entry': t_entry, 't_exit': t_exit}

    sky_color = vec3(0.0)
    hit = intersect_aabb(ray_origin, ray_direction, box_min, box_max)
    if hit is None:
        return sky_color

    t_entry = hit['t_entry']
    t_exit = hit['t_exit']
    distance_travelled = t_entry
    
    step_size = params['stepSize']
    step_limit = params['stepLimit']
    light_step_size = params['lightStepSize']
    max_steps = params['maxSteps']
    density_threshold = params['densityThreshold']
    absorption_coeff = params['absorptionCoefficient']
    cloud_scale = params['cloudScale']
    user_density = params['uUserDensity']
    octave_count = params['octaveCount']

    density_total = 0.0
    brightness = 0.0
    global_transmittance = 1.0
    cloud_color = vec3(0.0)

    for i in range(step_limit):
        if distance_travelled > t_exit:
            break
        if i >= max_steps:
            break
            
        march_pos = ray_origin + ray_direction * distance_travelled
        world_pos = march_pos * cloud_scale

        # Worley noise accumulation
        worley_density = 0.0
        amplitude = 1.0
        frequency = 1.0
        amplitude_total = 0.0
        for octave in range(octave_count):
            worley_density += noise_func(world_pos * frequency) * amplitude
            amplitude_total += amplitude
            amplitude *= 0.5
            frequency *= 2.0
        if amplitude_total > 0:
            worley_density /= amplitude_total
        else:
            worley_density = 0.0

        perlin_density = noise_func(world_pos)
        density = worley_density * perlin_density
        density /= user_density

        if density < 0.05:
            distance_travelled += step_size
            continue
        if density < density_threshold:
            distance_travelled += step_size
            continue
            
        density_total += density * step_size

        # Secondary Light Ray
        light_origin = march_pos
        light_dir = normalize(sun_dir)
        light_hit = intersect_aabb(light_origin, light_dir, box_min, box_max)
        max_light_dist = light_hit['t_exit'] if light_hit else 0.0
        
        light_transmittance = 1.0
        light_t = step_size
        while light_t < max_steps and light_t < max_light_dist:
            light_pos = light_origin + light_dir * light_t
            light_density_raw = noise_func(light_pos * cloud_scale) / user_density
            if light_density_raw >= 0.05:
                light_transmittance *= exp(-light_density_raw * light_step_size)
            light_t += light_step_size
            
        local_transmittance = exp(-density * step_size)
        scattering = (1.0 - local_transmittance) * light_transmittance
        cloud_color += global_transmittance * scattering * sun_color
        global_transmittance *= local_transmittance
        
        distance_travelled += step_size

    # S2-style final output
    cloud_colour = brightness * sun_color
    cloud_transmittance = exp(-density_total * absorption_coeff)
    return vec4(cloud_colour, 1.0 - cloud_transmittance)
```

## Operating characteristics
- **Time Complexity:** $O(N \cdot M)$ per pixel, where $N$ is the number of steps in the main raymarch loop and $M$ is the number of steps in the secondary light raymarch loop [S1, S2, unofficial].
- **Memory Complexity:** $O(V)$ for storing 3D noise textures, where $V$ is the texture volume resolution, plus $O(1)$ per pixel for raymarching state [S2, unofficial].
- **Performance:** Real-time capable on modern GPUs. Performance scales with resolution and the number of steps. Higher quality settings increase `stepLimit` and decrease `stepSize`, significantly increasing cost [S2, unofficial].
- **Strengths:** Deterministic step size simplifies implementation and debugging. Beer's Law provides physically plausible attenuation. Noise-based density allows for detailed, organic cloud structures without large 3D textures [S1, S2, unofficial].
- **Limitations:** Fixed step size may lead to aliasing or missing thin cloud details if steps are too large. Requires careful tuning of `STEP_SIZE` and `LIGHT_STEP_SIZE` to balance quality and performance. The secondary light ray adds computational cost proportional to the number of light march steps [S1, S2, unofficial].
- **When to use:** Real-time cloud rendering in games or interactive applications where performance is critical but visual quality needs to be higher than simple billboard clouds [S1, S2, unofficial].
- **When not to use:** Offline rendering requiring high-fidelity global illumination or very large-scale atmospheric effects where adaptive stepping or pre-computed lighting might be more efficient [S1, S2, unofficial].

## Background
The technique originates from real-time WebGL volumetric cloud rendering projects, specifically those utilizing fixed-step raymarchers to simulate cloud-like structures [S1, unofficial]. It builds upon the principles of volumetric rendering and Beer's Law, adapting them for real-time execution by using procedural noise (Worley and Perlin) for density definition [S1, S2, unofficial]. The specific implementation details, such as the use of Worley and Perlin noise combination and the fixed-step light marching, are documented in unofficial GitHub repositories [S1, S2, unofficial].
