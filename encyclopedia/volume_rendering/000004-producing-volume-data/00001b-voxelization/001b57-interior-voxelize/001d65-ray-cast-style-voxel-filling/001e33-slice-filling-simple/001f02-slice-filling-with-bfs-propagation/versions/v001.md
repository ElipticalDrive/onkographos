# Slice Filling with BFS Propagation
Also called: FillXY2, FillXZ2, FillYZ2

## Overview
Slice Filling with BFS Propagation extends simple slice filling by propagating filled voxels to adjacent neighbors within the slice plane using a Breadth-First Search (BFS) if the neighbor is also empty in both the main voxel grid and the current buffer. It sets bits in a buffer for empty space until it hits an existing solid voxel, then stops that direction. It differs from [Slice Filling (Simple)](1691-slice-filling-simple.md) by using BFS to fill connected empty regions in the 2D slice plane rather than just scanning linearly from the edges.

## How it works
**Inputs and outputs:**
- Input: A 3D voxel grid (`voxels_`) representing the scene geometry, where each voxel has a state (solid or empty).
- Input: A 2D slice buffer (`voxels_buffer_`) for the current slice being processed, initialized to empty.
- Input: Slice bounds ($l_x, u_x, l_y, u_y, l_z, u_z$) defining the region to process.
- Input: The axis along which the slice is taken (X, Y, or Z).
- Output: Updated `voxels_buffer_` with filled voxels indicating empty space up to the first solid voxel encountered from the slice boundaries.

**Data structures:**
- `voxels_`: 3D array or hash map storing voxel states. Each voxel is either solid or empty.
- `voxels_buffer_`: 2D array or hash map for the current slice, storing the filled status.
- `DI_4`: A set of 4 offset vectors defining the 4-connected neighborhood in the slice plane. For example, in the YZ plane, `DI_4` might be $\{(0, 1), (0, -1), (1, 0), (-1, 0)\}$ corresponding to Y and Z directions.

**Numbered steps:**
1. Initialize `voxels_buffer_` for the current slice to all empty.
2. Determine the iteration order based on the slice axis:
   - For `FillYZ2(x)` (slice along X): Iterate $y$ from $l_y$ to $u_y$, then $z$ from $l_z$ to $u_z$.
   - For `FillXZ2(y)` (slice along Y): Iterate $z$ from $l_z$ to $u_z$, then $x$ from $l_x$ to $u_x$.
   - For `FillXY2(z)` (slice along Z): Iterate $x$ from $l_x$ to $u_x$, then $y$ from $l_y$ to $u_y$.
3. For each voxel $(x, y, z)$ in the iteration order:
   a. Compute the voxel index in the 3D grid.
   b. Load the state from `voxels_`.
   c. If the voxel is solid, break the forward scan for this direction.
   d. If the voxel is empty, check its 4 neighbors in the slice plane using `DI_4` offsets.
   e. For each neighbor $(nx, ny, nz)$ within bounds:
      i. Compute the neighbor's index.
      ii. Load the combined state from `voxels_` and `voxels_buffer_`.
      iii. If the neighbor is not solid, call `BfsSolid` on that neighbor index.
4. Perform a backward scan in the same iteration order (e.g., for `FillYZ2(x)`, iterate $z$ from $u_z$ down to $l_z$):
   a. Compute the voxel index.
   b. Load the state from `voxels_`.
   c. If the voxel is solid, break the backward scan.
   d. If the voxel is empty, check its 4 neighbors in the slice plane.
   e. For each neighbor within bounds, load the combined state. If not solid, call `BfsSolid`.

**Formulas:**
- Voxel index calculation depends on the grid layout. For a 3D grid with dimensions $W, H, D$ and voxel $(x, y, z)$, the index might be $x + y \cdot W + z \cdot W \cdot H$.
- Neighbor index calculation: For a neighbor offset $(dx, dy, dz)$, the neighbor index is $(x+dx) + (y+dy) \cdot W + (z+dz) \cdot W \cdot H$.

**Parameters:**
- `BfsSolid`: A function that performs BFS propagation from a voxel index. It marks the voxel and its connected empty neighbors in the slice plane as filled in `voxels_buffer_`.

**Edge cases and pitfalls:**
- Boundary checks: Ensure neighbor indices are within the slice bounds.
- Precision: Use integer arithmetic for voxel indices to avoid floating-point errors.
- Degenerate input: Handle cases where the slice is entirely empty or entirely solid.

## Operating characteristics
- Time complexity: $O(N \cdot M)$, where $N$ is the number of voxels in the slice and $M$ is the average size of connected empty regions.
- Memory complexity: $O(N)$ for the slice buffer and BFS queue.
- Measured performance: Not given in the sources.
- Scaling: Scales linearly with the number of voxels in the slice.
- Strengths: Efficiently fills connected empty regions in the slice plane.
- Limitations: May be slower than simple slice filling for scenes with many small empty regions.
- When to use: When the scene has large connected empty regions in the slice plane.
- When not to use: When the scene has many small empty regions or is mostly solid.
