# Slice Filling (Simple)
Also called: FillXY, FillXZ, FillYZ
## Overview
Slice Filling (Simple) is a voxelization method that fills the interior of a mesh by processing 2D slices of the voxel grid along one of the three principal axes. It solves the problem of determining which voxels inside the mesh bounds are interior by scanning each slice from both ends toward the center, marking voxels as filled until an existing solid voxel is encountered. It differs from [Solid Voxelization](1695-solid-voxelization.md) by relying on linear edge-to-center scanning within slices rather than global connectivity or flood-fill algorithms, and it serves as the base case for [Slice Filling with BFS Propagation](1909-slice-filling-with-bfs-propagation.md), which extends this linear scan with neighbor propagation.
## How it works
**Inputs and Outputs:**
- Input: A mesh voxelization range defined by lower bounds `mesh_vox_lb_` and upper bounds `mesh_vox_ub_`.
- Input: A voxel grid `voxels_` containing existing solid voxels.
- Output: A buffer `voxels_buffer_` containing bits set for newly filled interior voxels.

**Data Structures:**
- `voxels_`: An atomic array of voxel states, accessed in batches of `kBatchSize`.
- `voxels_buffer_`: A buffer for newly filled voxels, used to mark empty space until a solid voxel is hit.
- `mesh_vox_lb_`: Lower bounds of the mesh voxelization range (3D vector).
- `mesh_vox_ub_`: Upper bounds of the mesh voxelization range (3D vector).
- Macros:
  - `GETBIT(batch, index)`: Checks if a specific bit is set in a voxel batch.
  - `SETBIT(buffer, index)`: Sets a specific bit in the voxel buffer.
  - `INDEX(x, y, z)`: Computes the linear index from x, y, z coordinates.

**Steps:**
The algorithm iterates over slices along one axis. For each slice, it performs two linear scans: a forward scan from the lower bound to the upper bound, and a backward scan from the upper bound to the lower bound.

1. **Forward Scan:** Iterate from the lower bound to the upper bound along the primary axis of the slice. For each position, iterate along the secondary axis. Compute the voxel index. Load the current voxel state from `voxels_`. If the voxel is solid, break the forward scan. Otherwise, set the bit in `voxels_buffer_`. If the secondary axis reaches its upper bound + 1, continue to the next position in the primary axis.
2. **Backward Scan:** Iterate from the upper bound down to the lower bound along the primary axis. For each position, iterate along the secondary axis in reverse. Compute the voxel index. Load the current voxel state. If the voxel is solid, break the backward scan. Otherwise, set the bit in `voxels_buffer_`.

**Edge Cases and Pitfalls:**
- If a slice contains no solid voxels, the entire slice will be filled.
- If a slice is entirely solid, no voxels will be filled in that slice.
- Precision issues may arise if the mesh bounds are not aligned with the voxel grid.
- The algorithm assumes that the voxel grid is already populated with surface voxels from a previous step.

## Subtopics

### Parallel Solid Task Execution
Parallel Solid Task Execution extends simple slice filling by running the filling tasks in parallel using a thread pool. It creates a thread pool with `num_thread` threads and submits the filling tasks for each slice along the x, y, and z axes to the thread pool. It differs from simple slice filling by utilizing multi-threading to speed up the filling process. It is chosen when performance is critical and the hardware supports multi-threading. The implementation uses a `ThreadPool` class that supports `Run()` and `Stop()` methods. Two variants are provided: `RunSolidTask` and `RunSolidTask2`, which differ in the order of submitting tasks for different axes.

## Operating characteristics
**Time and Memory Complexity:**
- Time Complexity: O(N) where N is the number of voxels in the mesh voxelization range. The parallel version reduces the wall-clock time by a factor proportional to the number of threads, assuming no contention.
- Memory Complexity: O(N) for the voxel grid and buffer.

**Measured Performance:**
- Not given in the sources.

**Scaling:**
- The parallel version scales with the number of threads, but performance may be limited by memory bandwidth and cache coherence.

**Strengths and Limitations:**
- Strengths: Simple to implement, efficient for sparse meshes, parallelizable.
- Limitations: May fill voxels incorrectly if the mesh has complex topology or self-intersections, relies on accurate surface voxelization.

**When to Use:**
- Use when the mesh is relatively simple and the voxel grid is sparse.
- Use when performance is critical and multi-threading is available.

**When Not to Use:**
- Do not use when the mesh has complex topology or self-intersections.
- Do not use when the voxel grid is dense and memory bandwidth is a bottleneck.

## Background
Slice Filling (Simple) is part of the voxelizer library by topskychen, which provides tools for voxelizing 3D meshes. The library uses a ray-casting approach to determine surface voxels and then fills the interior using slice filling. The method is designed to be efficient and easy to implement, making it suitable for applications such as 3D printing, collision detection, and volume rendering.
