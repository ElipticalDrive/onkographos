# Slice Filling (Simple)
Also called: FillXY, FillXZ, FillYZ
## Overview
Slice Filling (Simple) is a voxelization method that fills the interior of a mesh by processing 2D slices of the voxel grid along one of the three principal axes [S1, unofficial]. It solves the problem of determining which voxels inside the mesh bounds are interior by scanning each slice from both ends toward the center, marking voxels as filled until an existing solid voxel is encountered [S1, unofficial]. It differs from [Solid Voxelization](1695-solid-voxelization.md) by relying on linear edge-to-center scanning within slices rather than global connectivity or flood-fill algorithms, and it serves as the base case for [Slice Filling with BFS Propagation](1909-slice-filling-with-bfs-propagation.md), which extends this linear scan with neighbor propagation [S1, unofficial].
## How it works
**Inputs and Outputs:**
- Input: A mesh voxelization range defined by lower bounds `mesh_vox_lb_` and upper bounds `mesh_vox_ub_` [S1, unofficial].
- Input: A voxel grid `voxels_` containing existing solid voxels [S1, unofficial].
- Output: A buffer `voxels_buffer_` containing bits set for newly filled interior voxels [S1, unofficial].

**Data Structures:**
- `voxels_`: An atomic array of voxel states, accessed in batches of `kBatchSize` [S1, unofficial].
- `voxels_buffer_`: A buffer for newly filled voxels, used to mark empty space until a solid voxel is hit [S1, unofficial].
- `mesh_vox_lb_`: Lower bounds of the mesh voxelization range (3D vector) [S1, unofficial].
- `mesh_vox_ub_`: Upper bounds of the mesh voxelization range (3D vector) [S1, unofficial].
- `GETBIT(batch, bit_idx)`: Macro/function to check if a specific bit is set in a voxel batch [S1, unofficial].
- `SETBIT(buffer, bit_idx)`: Macro/function to set a specific bit in the voxel buffer [S1, unofficial].
- `INDEX(x, y, z)`: Macro/function to compute the linear index from x, y, z coordinates [S1, unofficial].

**Steps:**
The algorithm iterates over slices along one axis [S1, unofficial]. For each slice, it performs two linear scans: a forward scan from the lower bound to the upper bound, and a backward scan from the upper bound to the lower bound [S1, unofficial].

1. **Forward Scan:** Iterate from the lower bound to the upper bound along the primary axis of the slice [S1, unofficial]. For each position, iterate along the secondary axis [S1, unofficial]. Compute the voxel index [S1, unofficial]. Load the current voxel state from `voxels_` [S1, unofficial]. If the voxel is solid, break the forward scan [S1, unofficial]. Otherwise, set the bit in `voxels_buffer_` [S1, unofficial]. If the secondary axis reaches its upper bound + 1, continue to the next position in the primary axis [S1, unofficial].
2. **Backward Scan:** Iterate from the upper bound down to the lower bound along the primary axis [S1, unofficial]. For each position, iterate along the secondary axis in reverse [S1, unofficial]. Compute the voxel index [S1, unofficial]. Load the current voxel state [S1, unofficial]. If the voxel is solid, break the backward scan [S1, unofficial]. Otherwise, set the bit in `voxels_buffer_` [S1, unofficial].

**Pseudocode:**
```python
def fill_yz(x, mesh_vox_lb, mesh_vox_ub, voxels, voxels_buffer, kBatchSize):
    ly = mesh_vox_lb[1]
    uy = mesh_vox_ub[1]
    lz = mesh_vox_lb[2]
    uz = mesh_vox_ub[2]
    
    # Forward scan
    for y in range(ly, uy + 1):
        for z in range(lz, uz + 1):
            voxel_index = INDEX(x, y, z)
            if GETBIT(voxels, voxel_index, kBatchSize):
                break
            SETBIT(voxels_buffer, voxel_index, kBatchSize)
            
    # Backward scan
    for y in range(ly, uy + 1):
        for z in range(uz, lz - 1, -1):
            voxel_index = INDEX(x, y, z)
            if GETBIT(voxels, voxel_index, kBatchSize):
                break
            SETBIT(voxels_buffer, voxel_index, kBatchSize)

def fill_xz(y, mesh_vox_lb, mesh_vox_ub, voxels, voxels_buffer, kBatchSize):
    lx = mesh_vox_lb[0]
    ux = mesh_vox_ub[0]
    lz = mesh_vox_lb[2]
    uz = mesh_vox_ub[2]
    
    # Forward scan
    for z in range(lz, uz + 1):
        for x in range(lx, ux + 1):
            voxel_index = INDEX(x, y, z)
            if GETBIT(voxels, voxel_index, kBatchSize):
                break
            SETBIT(voxels_buffer, voxel_index, kBatchSize)
            
    # Backward scan
    for z in range(lz, uz + 1):
        for x in range(ux, lx - 1, -1):
            voxel_index = INDEX(x, y, z)
            if GETBIT(voxels, voxel_index, kBatchSize):
                break
            SETBIT(voxels_buffer, voxel_index, kBatchSize)

def fill_xy(z, mesh_vox_lb, mesh_vox_ub, voxels, voxels_buffer, kBatchSize):
    lx = mesh_vox_lb[0]
    ux = mesh_vox_ub[0]
    ly = mesh_vox_lb[1]
    uy = mesh_vox_ub[1]
    
    # Forward scan
    for x in range(lx, ux + 1):
        for y in range(ly, uy + 1):
            voxel_index = INDEX(x, y, z)
            if GETBIT(voxels, voxel_index, kBatchSize):
                break
            SETBIT(voxels_buffer, voxel_index, kBatchSize)
            
    # Backward scan
    for x in range(lx, ux + 1):
        for y in range(uy, ly - 1, -1):
            voxel_index = INDEX(x, y, z)
            if GETBIT(voxels, voxel_index, kBatchSize):
                break
            SETBIT(voxels_buffer, voxel_index, kBatchSize)

def GETBIT(voxels, voxel_index, kBatchSize):
    batch_idx = voxel_index // kBatchSize
    bit_idx = voxel_index % kBatchSize
    return (voxels[batch_idx] >> bit_idx) & 1

def SETBIT(buffer, voxel_index, kBatchSize):
    batch_idx = voxel_index // kBatchSize
    bit_idx = voxel_index % kBatchSize
    buffer[batch_idx] |= (1 << bit_idx)
```

**Parameters:**
- `kBatchSize`: The number of voxels per batch in the atomic array `voxels_` [S1, unofficial].
- `num_thread`: Number of threads for parallel execution [S1, unofficial].

**Edge Cases and Pitfalls:**
- If a slice contains no solid voxels, the entire slice will be filled [S1, unofficial].
- If a slice is entirely solid, no voxels will be filled in that slice [S1, unofficial].
- Precision issues may arise if the mesh bounds are not aligned with the voxel grid [G].
- The algorithm assumes that the voxel grid is already populated with surface voxels from a previous step [G].
## Subtopics

### Parallel Solid Task Execution
Parallel Solid Task Execution extends simple slice filling by running the filling tasks in parallel using a thread pool [S1, unofficial]. It creates a thread pool with `num_thread` threads and submits the filling tasks for each slice along the x, y, and z axes to the thread pool [S1, unofficial]. It differs from simple slice filling by utilizing multi-threading to speed up the filling process [S1, unofficial]. It is chosen when performance is critical and the hardware supports multi-threading [S1, unofficial]. The implementation uses a `ThreadPool` class that supports `Run()` and `Stop()` methods [S1, unofficial]. Two variants are provided: `RunSolidTask` iterates x from lx to ux submitting FillYZ(x), y from ly to uy submitting FillXZ(y), and z from lz to uz submitting FillXY(z) [S1, unofficial]. `RunSolidTask2` iterates x from lx to ux submitting FillYZ2(x), z from lz to uz submitting FillXY2(z), and y from ly to uy submitting FillXZ2(y) [S1, unofficial].

## Background
Slice Filling (Simple) is part of the voxelizer library by topskychen, which provides tools for voxelizing 3D meshes [S1, unofficial]. The library uses a ray-casting approach to determine surface voxels and then fills the interior using slice filling [S1, unofficial]. The method is designed to be efficient and easy to implement, making it suitable for applications such as 3D printing, collision detection, and volume rendering [S1, unofficial].
