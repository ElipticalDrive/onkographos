# Splat-to-Voxel Transfer

Also called: Gaussian Splat Voxelization, Gaussian to Voxel Grid Conversion

## Overview
Splat-to-Voxel Transfer is a method for converting continuous 3D Gaussian primitives into a structured, discrete voxel grid representation. It solves the problem of aggregating point-based splat attributes (features and geometry) into a dense spatial proxy, enabling subsequent processing by voxel-based neural networks [S1]. Unlike sibling methods that may focus on direct voxel format generation or kernel interpolation without hierarchical culling, this method explicitly constructs a coarse-to-fine hierarchy and applies weight-based sparsification to reduce computational load for downstream transformers [S1].

## How it works
The method converts a set of Gaussian primitives into a sparse voxel grid through three main phases: Splat Depositing, Splat Fusion, and Coarse-to-Fine Sparsification.

**Inputs and Outputs**
*   **Input**: A set of $K$ Gaussian primitives $\{G_k\}_{k=1}^K$. Each primitive $G_k$ is defined by its mean position $\mu_k$, opacity $\alpha_k$, feature vector $F_k$, and other Gaussian parameters (e.g., covariance, spherical harmonics coefficients) collectively denoted as $G_k$.
*   **Output**: A sparse voxel grid containing refined Gaussian primitives $\{G'_j\}$ associated with active fine-level voxels.

**Data Structures**
*   **Voxel Grid**: A 3D grid with resolution $R \times R \times R$ (high-resolution). Each voxel $V_j$ stores an attribute vector $E_j$ and a weight $W_j$.
*   **Coarse Grid**: A downsampled grid with resolution $R/d \times R/h \times R/w$. Each coarse voxel $V_i^c$ corresponds to a block $N_i$ of $d \times h \times w$ fine voxels.
*   **Token**: A 1D vector representation of a coarse voxel feature used as input to the Transformer.

**Parameters**
*   **Nearest Voxels**: The implementation uses the adjacent 8 voxels for each splat [S1].
*   **Sparsification Ratio**: Top 20% of coarse voxels by weight are retained [S1].
*   **Kernel Function**: $\mathcal{K}$, a distance kernel (specific function not detailed in the primary text, but referenced in supplementary material [S1]).

**Algorithm Steps**

1.  **Splat Depositing**:
    For each Gaussian primitive $G_k$ with mean $\mu_k$:
    a. Identify the set $\{\mathbf{M}_k\}$ of nearest voxels to $\mu_k$. In the cited implementation, this is the 8 adjacent voxels [S1].
    b. For each voxel $V_j \in \{\mathbf{M}_k\}$, compute the interpolation weight $w_{jk}$:
       $$w_{jk} = \frac{\mathcal{K}(\mu_k - \mathbf{x}_j)}{\sum_{j' \in \{\mathbf{M}_k\}} \mathcal{K}(\mu_k - \mathbf{x}_{j'})}$$
       where $\mathbf{x}_j$ is the center of voxel $V_j$.
    c. Set $w_{jk} = 0$ for all voxels not in $\{\mathbf{M}_k\}$ [S1].

2.  **Splat Fusion**:
    For each voxel $V_j$ in the high-resolution grid:
    a. Compute the total accumulated weight $W_j$ from all contributing Gaussians:
       $$W_j = \sum_{k \in \{\mathbf{M}_k\}} w_{jk} \alpha_k$$
       where the sum iterates over all Gaussian primitives $k$ that influence voxel $j$ [S1].
    b. Compute the voxel attribute $E_j$ as the normalized weighted sum of concatenated features and Gaussian parameters:
       $$E_j = \frac{1}{W_j} \sum_{k \in \{\mathbf{M}_k\}} w_{jk} \alpha_k [\mathbf{F}_k; \mathbf{G}_k]$$
       where $[\mathbf{F}_k; \mathbf{G}_k]$ denotes the concatenation of the feature vector and Gaussian attributes [S1].
    c. If $W_j = 0$, the voxel is empty.

3.  **Coarse-to-Fine Hierarchy Construction**:
    a. Downsample the high-resolution voxel grid by factors $[d, h, w]$ to create a coarse grid [S1].
    b. Each coarse voxel $V_i^c$ corresponds to a block $N_i$ of $d \times h \times w$ fine voxels.
    c. Compute coarse voxel features $E_i^c$ using a shallow Multi-Layer Perceptron (MLP) on the concatenation of the fine features $E_j$ for $j \in N_i$ and set coarse voxel weights $W_i$ [S1]. *Note: The exact MLP architecture is not specified in the provided text, only that it operates on concatenated fine features.*

4.  **Voxel Sparsification**:
    a. Sort coarse-level voxels by their weight $W_i$.
    b. Retain only the top 20% of coarse voxels with the largest weights [S1].
    c. Cull corresponding high-resolution fine-level voxels if their parent coarse voxel is culled. This reduces the input token count to fewer than 10K [S1].

**Pseudocode**

```python
import numpy as np

def splat_to_voxel_transfer(gaussians, voxel_grid_shape, kernel_func, d, h, w, sparsify_ratio=0.2):
    """
    Converts Gaussian primitives to a sparse voxel grid.
    
    Args:
        gaussians: List of dicts with keys 'mu' (3D pos), 'alpha' (float), 
                   'F' (feature vector), 'G' (other params).
        voxel_grid_shape: Tuple (R, R, R) for high-res grid.
        kernel_func: Function K(dist) returning scalar weight.
        d, h, w: Downsampling factors for coarse grid.
        sparsify_ratio: Fraction of coarse voxels to retain.
        
    Returns:
        sparse_voxels: List of dicts with keys 'pos' (voxel center), 'G_prime' (refined params).
                       Note: G_prime generation requires the Transformer step (see Sparse Voxel Transformer).
                       This function returns the pre-transformer sparse structure.
    """
    R = voxel_grid_shape[0]
    # Initialize high-res grid attributes
    # E_j: attribute vector, W_j: scalar weight
    # Using a dictionary for sparse storage of active voxels
    fine_voxels = {} 
    
    # Step 1 & 2: Splat Depositing and Fusion
    for k, g in enumerate(gaussians):
        mu_k = g['mu']
        alpha_k = g['alpha']
        F_k = g['F']
        G_k = g['G']
        
        # Identify 8 adjacent voxels (G)
        # Assuming voxel centers are at integer coordinates or grid-aligned
        # Calculate min/max indices for the 8 neighbors
        coords = np.floor(mu_k).astype(int)
        # Adjust for boundary conditions if necessary [G]
        neighbors = []
        for dx in [0, 1]:
            for dy in [0, 1]:
                for dz in [0, 1]:
                    idx = coords + np.array([dx, dy, dz])
                    if 0 <= idx[0] < R and 0 <= idx[1] < R and 0 <= idx[2] < R:
                        neighbors.append(idx)
        
        # Compute weights for these 8 neighbors
        weights = []
        for j_idx in neighbors:
            x_j = j_idx.astype(float) # Voxel center
            dist = mu_k - x_j
            w_jk = kernel_func(dist)
            weights.append(w_jk)
            
        sum_weights = sum(weights)
        if sum_weights == 0:
            continue
            
        # Normalize weights
        norm_weights = [w / sum_weights for w in weights]
        
        # Deposit into voxels
        for j_idx, w_jk in zip(neighbors, norm_weights):
            j_key = tuple(j_idx)
            if j_key not in fine_voxels:
                fine_voxels[j_key] = {'E': np.zeros_like(F_k), 'W': 0.0}
            
            # Concatenate F_k and G_k
            # Note: G_k structure depends on implementation. Assuming vectorizable.
            combined_attr = np.concatenate([F_k, G_k])
            
            # Accumulate weighted sum
            fine_voxels[j_key]['E'] += w_jk * alpha_k * combined_attr
            fine_voxels[j_key]['W'] += w_jk * alpha_k

    # Normalize attributes
    for j_key in fine_voxels:
        if fine_voxels[j_key]['W'] > 0:
            fine_voxels[j_key]['E'] /= fine_voxels[j_key]['W']
        else:
            del fine_voxels[j_key]

    # Step 3: Coarse-to-Fine Hierarchy
    # Downsample to coarse grid
    coarse_voxels = {}
    for j_key, data in fine_voxels.items():
        # Map fine voxel to coarse voxel index
        c_idx = (j_key[0] // d, j_key[1] // h, j_key[2] // w)
        if c_idx not in coarse_voxels:
            coarse_voxels[c_idx] = []
        coarse_voxels[c_idx].append((j_key, data))

    # Compute coarse features using MLP (Placeholder for MLP logic)
    # The source states: "derive coarse voxel features using a shallow MLP on the concatenation 
    # of the fine features and set coarse voxel weights"
    coarse_voxel_data = {}
    for c_idx, fine_block in coarse_voxels.items():
        # Collect fine features and weights for the block
        fine_feats = [d['E'] for _, d in fine_block]
        fine_weights = [d['W'] for _, d in fine_block]
        
        # Concatenate fine features and weights
        # Note: Exact concatenation strategy for MLP input is not specified [G]
        # Assuming simple concatenation of all fine voxel attributes in the block
        # This is a simplification; the actual MLP might aggregate differently.
        input_to_mlp = np.concatenate([f for f in fine_feats] + [np.array(fine_weights)])
        
        # Apply MLP (Not defined in source, placeholder)
        # E_c_i = MLP(input_to_mlp)
        # W_i = sum(fine_weights) or similar aggregation
        # For the purpose of sparsification, we need W_i.
        # Source says "geometric cues from coarse voxel weights Wi ... encapsulate spatial distribution"
        # We assume W_i is derived from the sum or max of fine weights.
        W_i = sum(fine_weights)
        
        coarse_voxel_data[c_idx] = {'E_c': None, 'W': W_i, 'fine_indices': [f[0] for f in fine_block]}

    # Step 4: Voxel Sparsification
    # Sort coarse voxels by weight
    sorted_coarse = sorted(coarse_voxel_data.items(), key=lambda item: item[1]['W'], reverse=True)
    
    # Retain top 20%
    num_retain = int(len(sorted_coarse) * sparsify_ratio)
    retained_coarse_indices = set()
    for i in range(num_retain):
        retained_coarse_indices.add(sorted_coarse[i][0])
        
    # Filter fine voxels
    sparse_fine_voxels = {}
    for c_idx, data in coarse_voxel_data.items():
        if c_idx in retained_coarse_indices:
            for j_key in data['fine_indices']:
                sparse_fine_voxels[j_key] = fine_voxels[j_key]
                
    return sparse_fine_voxels, coarse_voxel_data
```

## Subtopics

### Sparse Voxel Transformer
A Transformer network that processes coarse voxel features as tokens to fuse information in a canonical 3D space and produce refined splats [S1]. It treats each coarse voxel feature as a token, reshapes them to 1D vectors, and processes them via $\{\mathbf{O}^c\} = \text{Transformer}_{voxel}(\{\mathbf{E}^c\})$ [S1]. The processed latent features $\mathbf{O}^c$ are then replicated from the coarse voxel grids to their corresponding fine voxel grids to produce fine-level latent features $\mathbf{O}_j$ [S1]. Finally, a shallow MLP generates refined Gaussian primitives $\mathbf{G}'_j = \text{MLP}_{fine}([\mathbf{O}_j, \mathbf{E}_j])$, where $\mathbf{G}'_j \in \mathbb{R}^l$ and $l$ is the number of rendering parameters [S1].

## Operating characteristics
*   **Performance**: The sparsification step reduces the input token count to fewer than 10K, allowing the downstream voxel transformer to run in 15 ms [S1].
*   **Memory**: By culling empty and insignificant regions based on coarse voxel weights, the method manages memory usage for the dense high-resolution grid [S1].
*   **Strengths**: Provides a structured spatial proxy for aggregating splats, enabling the use of efficient Transformer architectures in 3D space [S1].
*   **Limitations**: Requires a two-stage process (transfer then transformer) and depends on the quality of the kernel function and sparsification ratio [S1].

## Background
The method is part of the "Fuse-and-Refine" module proposed in the paper "Learning Efficient Fuse-and-Refine for Feed-Forward 3D Gaussian Splatting" [S1]. It was introduced to improve reconstruction performance by adopting a hybrid Splat-Voxel representation [S1]. The approach leverages geometric cues from coarse voxel weights to efficiently cull empty regions, addressing the computational bottleneck of processing dense Gaussian splats with 3D Transformers [S1].
