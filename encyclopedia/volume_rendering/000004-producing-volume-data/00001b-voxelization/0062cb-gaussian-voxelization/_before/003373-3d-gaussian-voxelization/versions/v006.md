# 3D Gaussian Voxelization

Also called: Voxelization of 3D Gaussians

## Overview
3D Gaussian Voxelization converts a continuous set of 3D Gaussian primitives into a discrete set of unique voxels and their associated features, enabling efficient processing by 3D neural networks [S1, unofficial].

## How it works
**Inputs and Outputs:**
*   **Input:** A list of 3D Gaussians, where each Gaussian is a dictionary containing parameters such as position, scale, orientation, and feature attributes. A `grid_size` float defining the physical size of each voxel cell [S1, unofficial].
*   **Output:** `uni_voxels_xyz` (List[Tuple[float, float, float]]), `uni_voxel_feats` (List), `inverse_indices` (List[int]), and `num_voxels_per_g` (List[int]) [S1, unofficial].

**Data Structures:**
The method relies on three sequential processing stages that transform the input Gaussian list into the output structures:
1.  `count_voxels_per_g(gaussians, grid_size)`: Returns a list of integers specifying the voxel count per Gaussian.
2.  `compose_voxel_features(gaussians, num_voxels_per_g)`: Returns two parallel lists containing all generated voxel coordinates and their corresponding feature vectors.
3.  `return_unique_voxels(voxels_xyz, voxel_feats)`: Returns the deduplicated coordinate list, aggregated feature list, and the inverse index mapping.

**Numbered Steps:**
1.  Determine the number of voxels required for each Gaussian using `count_voxels_per_g(gaussians, grid_size)` [S1, unofficial].
2.  Generate voxel coordinates and features for all Gaussians using `compose_voxel_features(gaussians, num_voxels_per_g)` [S1, unofficial].
3.  Deduplicate the generated voxels using `return_unique_voxels(voxels_xyz, voxel_feats)` to obtain unique coordinates, aggregated features, and an inverse index mapping from original voxels to the unique list [S1, unofficial].

**Formulas:**
Not given in the sources.

**Parameters:**
*   `SAMPLE_SHAPE`: Literal type `["volume", "tri-plane", "tri-line", "center"]`, default `"center"`. Controls the geometric shape used for sampling voxels around each Gaussian [S1, unofficial].
*   `grid_size`: Float. Hyperparameter defining the physical size of each voxel cell [S1, unofficial].

**Edge Cases and Pitfalls:**
*   **Precision:** Floating-point coordinates for voxel centers must be handled consistently to avoid splitting identical voxels due to minor numerical differences [G].
*   **Boundary Conditions:** Gaussians extending beyond the defined grid boundaries must be clipped or ignored to prevent out-of-bounds indexing [G].
*   **Feature Aggregation:** When multiple Gaussians contribute to the same voxel, the aggregation method (sum, mean, max) significantly impacts the resulting feature representation; the source notes do not specify the default aggregation strategy within `return_unique_voxels` [S1, unofficial].

**Pseudocode:**
```python
from typing import List, Tuple
from typing_extensions import Literal

# Global configuration
SAMPLE_SHAPE: Literal["volume", "tri-plane", "tri-line", "center"] = "center"

def count_voxels_per_g(gaussians: List[dict], grid_size: float) -> List[int]:
    """Determines the number of voxels for each Gaussian based on SAMPLE_SHAPE and grid_size."""
    # Exact sampling logic is not specified in the sources [G].
    return [1 for _ in gaussians]

def compose_voxel_features(gaussians: List[dict], num_voxels_per_g: List[int]) -> Tuple[List[Tuple[float, float, float]], List]:
    """Generates voxel coordinates and feature attributes for all Gaussians."""
    # Exact coordinate generation and feature distribution logic is not specified in the sources [G].
    all_xyz: List[Tuple[float, float, float]] = []
    all_feats: List = []
    for g, n in zip(gaussians, num_voxels_per_g):
        for _ in range(n):
            pos = g.get("position", (0.0, 0.0, 0.0))
            all_xyz.append((pos[0], pos[1], pos[2]))
            all_feats.append(g.get("features", []))
    return all_xyz, all_feats

def return_unique_voxels(voxels_xyz: List[Tuple[float, float, float]], voxel_feats: List) -> Tuple[List[Tuple[float, float, float]], List, List[int]]:
    """Deduplicates voxels, aggregates features, and builds inverse index map."""
    # Exact aggregation strategy is not specified in the sources [G].
    seen: dict = {}
    uni_xyz: List[Tuple[float, float, float]] = []
    uni_feats: List = []
    inverse_indices: List[int] = []
    for i, (xyz, feat) in enumerate(zip(voxels_xyz, voxel_feats)):
        if xyz not in seen:
            seen[xyz] = len(uni_xyz)
            uni_xyz.append(xyz)
            uni_feats.append(feat)
        inverse_indices.append(seen[xyz])
    return uni_xyz, uni_feats, inverse_indices

def voxelization(gaussians: List[dict], grid_size: float) -> Tuple[List[Tuple[float, float, float]], List, List[int], List[int]]:
    """Convert a set of 3D Gaussians into a set of unique voxels and their associated features."""
    num_voxels_per_g = count_voxels_per_g(gaussians, grid_size)
    all_voxels_xyz, all_voxel_feats = compose_voxel_features(gaussians, num_voxels_per_g)
    uni_voxels_xyz, uni_voxel_feats, inverse_indices = return_unique_voxels(all_voxels_xyz, all_voxel_feats)
    return uni_voxels_xyz, uni_voxel_feats, inverse_indices, num_voxels_per_g
```

## Subtopics

### GaGS
GaGS voxelizes a set of Gaussian distributions and employs sparse convolutions to extract geometry-aware features for deformation learning in dynamic scenes [S2]. It is chosen when the goal is to model spatial-temporal deformation using an implicit deformation field (e.g., an MLP) rather than static rendering [S2]. Unlike static voxelization, GaGS integrates the voxelization step directly into a learning pipeline for dynamic 3D Gaussians [S2].

## Operating characteristics
*   **Time Complexity:** Dominated by the voxel generation and deduplication steps. The complexity depends on the number of Gaussians, the average number of voxels per Gaussian (determined by `SAMPLE_SHAPE` and scale), and the efficiency of the deduplication algorithm [S1, unofficial].
*   **Memory Complexity:** Proportional to the total number of generated voxels before deduplication, and the number of unique voxels after deduplication. Sparse storage is implied by the use of unique voxel lists [S1, unofficial].
*   **Strengths:** Enables the use of efficient 3D convolutional networks on Gaussian representations. Reduces the computational burden of processing continuous Gaussians by discretizing them into a grid structure [S1, unofficial].
*   **Limitations:** The choice of `SAMPLE_SHAPE` and `grid_size` critically affects the fidelity of the representation. Coarse grids may lose detail, while fine grids increase memory usage. The method is primarily designed for feature embedding for neural networks, not for direct differentiable rendering [S1, unofficial].
*   **When to use:** When integrating 3D Gaussians into 3D CNNs or sparse convolutional networks for tasks like deformation learning or feature extraction [S1, unofficial][S2].
*   **When not to use:** For direct rasterization-based rendering where splatting is more appropriate, or when high-fidelity continuous representation is required without discretization loss [G].

## Background
The method was introduced in the context of "Quantile Rendering: Efficiently Embedding High-dimensional Feature on 3D Gaussian Splatting" [S1, unofficial]. It addresses the need to process 3D Gaussian Splatting data with 3D neural networks, which typically operate on voxel grids. The approach was also utilized in GaGS for dynamic scene modeling, where voxelization facilitates the extraction of geometry-aware features for deformation learning [S2].
