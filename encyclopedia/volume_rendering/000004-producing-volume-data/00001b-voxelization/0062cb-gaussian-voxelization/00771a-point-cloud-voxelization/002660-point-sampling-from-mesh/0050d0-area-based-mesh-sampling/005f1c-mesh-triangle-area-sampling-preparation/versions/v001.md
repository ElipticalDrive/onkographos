# Mesh Triangle Area Sampling Preparation


## Overview
This method prepares the geometric and material state required for area-based mesh sampling by iterating over all mesh objects in a collection, evaluating their geometry, and computing triangle areas to determine sampling weights. It differs from the actual sampling step by focusing solely on data extraction, caching, and validation, ensuring that degenerate triangles are excluded and material/texture data is interned for efficient access during the subsequent point generation phase.

## How it works
**Inputs:** A collection of 3D objects, a dependency graph for evaluation, and a target surface density parameter (implicit in the state structure).
**Outputs:** A `PointSamplingState` object containing lists of triangles, cumulative areas, total area, sample counts, random seeds, and interned material/image data.

**Data Structures:**
*   `PointSamplingState`:
    *   `triangles`: List of triangle data (vertices, UVs, material index).
    *   `cumulative_areas`: List of floats, where `cumulative_areas[i]` is the sum of areas of triangles `0` to `i`.
    *   `total_area`: Float, sum of all valid triangle areas.
    *   `sample_count`: Integer, total number of points to generate.
    *   `random_seed`: Integer, seed for random number generation.
    *   `materials`: List of `PlainMaterialData`.
    *   `images`: List of `PlainImageData`.
*   `PlainMaterialData`:
    *   `base_color`: Tuple of floats (RGB).
    *   `image_index`: Integer index into `images` list, or `None`.
*   `PlainImageData`:
    *   `image`: Reference to the image data.

**Steps:**
1.  Initialize empty lists for `triangles`, `materials`, `images`, and dictionaries for lookups (`material_lookup`, `image_lookup`). Initialize `total_area = 0.0` and `fallback_triangle_count = 0`.
2.  Iterate through each `obj` in `collection.all_objects`.
3.  If `obj.type != "MESH"`, skip to the next object.
4.  Evaluate the object's geometry: `evaluated_obj = obj.evaluated_get(depsgraph)`.
5.  Convert to mesh: `mesh = evaluated_obj.to_mesh(preserve_all_data_layers=True, depsgraph=depsgraph)`. If `mesh` is `None`, skip.
6.  Compute loop triangles: `mesh.calc_loop_triangles()`. If `not mesh.loop_triangles`, skip.
7.  Extract the active UV layer: `uv_layer = mesh.uv_layers.active.data` if `mesh.uv_layers.active` exists, else `None`.
8.  Resolve material information for each mesh material and intern them using `_intern_plain_material` (see below).
9.  Iterate over each `triangle` in `mesh.loop_triangles`:
    a.  Compute `area = float(triangle.area)`.
    b.  If `area <= 0.0`, skip this triangle [S1, unofficial]. This prevents degenerate sampling or division-by-zero errors.
    c.  Determine `material_index` from `triangle.material_index`.
    d.  Retrieve `material_info` from the resolved material map. If invalid, use a fallback.
    e.  Intern the material using `_intern_plain_material(material_info, materials, material_lookup, images, image_lookup, diagnostics)`. Let the result be `interned_material_index`.
    f.  If `material_info.fallback_code is not None`, increment `fallback_triangle_count` and `fallback_material_triangle_counts[material_info.material_name]` [S1, unofficial].
    g.  Append triangle data (vertices, UVs if `uv_layer` is not `None`, `interned_material_index`) to `triangles`.
    h.  Update `total_area += area`.
10. Compute `cumulative_areas` by accumulating `total_area` values from `triangles`.
11. Calculate `sample_count` based on `total_area` and the target density parameter.
12. Construct and return the `PointSamplingState`.

**Pseudocode:**
```python
def prepare_mesh_sampling_state(collection, depsgraph, target_density):
    triangles = []
    materials = []
    images = []
    material_lookup = {}
    image_lookup = {}
    total_area = 0.0
    fallback_triangle_count = 0
    fallback_material_triangle_counts = {}
    diagnostics = DiagnosticsSession()

    for obj in collection.all_objects:
        if obj.type != "MESH":
            continue

        evaluated_obj = obj.evaluated_get(depsgraph)
        mesh = evaluated_obj.to_mesh(preserve_all_data_layers=True, depsgraph=depsgraph)
        if mesh is None:
            continue

        mesh.calc_loop_triangles()
        if not mesh.loop_triangles:
            continue

        uv_layer = mesh.uv_layers.active.data if mesh.uv_layers.active else None

        # Resolve and intern materials for this mesh
        # Note: _intern_plain_material handles caching and returns interned index
        material_infos = resolve_material_infos(mesh) 

        for triangle in mesh.loop_triangles:
            area = float(triangle.area)
            if area <= 0.0:
                continue

            material_index = triangle.material_index
            material_info = material_infos.get(material_index)
            
            # Fallback logic if material_info is invalid
            if material_info is None:
                material_info = get_fallback_material_info()
                fallback_triangle_count += 1
                fallback_material_triangle_counts[material_info.material_name] = \
                    fallback_material_triangle_counts.get(material_info.material_name, 0) + 1

            interned_material_index = _intern_plain_material(
                material_info, materials, material_lookup, images, image_lookup, diagnostics
            )

            # Extract triangle data
            verts = triangle.verts
            # Assuming verts is a tuple of indices, fetch actual coordinates
            # This is a simplification; real implementation fetches mesh.vertices[verts[i]].co
            coords = [mesh.vertices[i].co for i in verts]
            
            uv = None
            if uv_layer is not None:
                uv = uv_layer[triangle.loop_indices[0]].uv # Simplified UV extraction

            triangles.append({
                'coords': coords,
                'uv': uv,
                'material_index': interned_material_index,
                'area': area
            })
            total_area += area

    # Compute cumulative areas
    cumulative_areas = []
    current_sum = 0.0
    for t in triangles:
        current_sum += t['area']
        cumulative_areas.append(current_sum)

    sample_count = int(total_area * target_density)
    random_seed = 42 # [G] Default seed; source does not specify dynamic seed logic

    return PointSamplingState(
        triangles=triangles,
        cumulative_areas=cumulative_areas,
        total_area=total_area,
        sample_count=sample_count,
        random_seed=random_seed,
        materials=materials,
        images=images
    )

def _intern_plain_material(material_info, materials, material_lookup, images, image_lookup, diagnostics):
    image_index = _intern_plain_image(material_info.image, images, image_lookup, diagnostics)
    material_key = (material_info.base_color, image_index)
    cached_index = material_lookup.get(material_key)
    if cached_index is not None:
        return cached_index

    material_index = len(materials)
    materials.append(PlainMaterialData(base_color=material_info.base_color, image_index=image_index))
    material_lookup[material_key] = material_index
    return material_index

def _intern_plain_image(image, images, image_lookup, diagnostics):
    if image is None:
        return None
    image_id = id(image)
    if image_id in image_lookup:
        return image_lookup[image_id]
    
    image_index = len(images)
    images.append(PlainImageData(image=image))
    image_lookup[image_id] = image_index
    return image_index
```

**Parameters:**
*   `target_density`: Points per square unit. Typical values depend on the desired resolution (e.g., 100-1000 points/m²). Not given in the sources.

**Edge Cases and Pitfalls:**
*   Triangles with `area <= 0.0` are skipped to prevent degenerate sampling or division-by-zero errors during point generation [S1, unofficial].
*   Missing UV layers result in `None` UVs for triangles, which may affect texture-based sampling if not handled downstream.
*   Material resolution failures lead to fallback materials, tracked in `fallback_triangle_count`.

## Subtopics

### [Point Sampling State Preparation](17814-point-sampling-state-preparation.md)
Extracts mesh geometry, materials, and textures from a target collection to build the state required for point sampling. It serves as the initialization phase for generating point clouds from mesh surfaces, ensuring that all necessary data (triangles, materials, textures) is loaded and cached before the actual sampling execution begins. It distinguishes itself by managing the lifecycle of the sampling state, including caching, asynchronous worker spawning, and memory release, rather than performing the geometric sampling itself.

## Operating characteristics
*   **Time Complexity:** $O(N \cdot M)$, where $N$ is the number of objects and $M$ is the average number of triangles per mesh. Each triangle is processed once.
*   **Memory Complexity:** $O(T)$, where $T$ is the total number of valid triangles. Storage includes triangle data, cumulative areas, and interned materials/images.
*   **Strengths:** Efficiently handles material deduplication via internment, reducing memory overhead for repeated materials. Explicitly filters degenerate triangles.
*   **Limitations:** Requires full mesh evaluation and loop triangle computation, which can be memory-intensive for high-poly scenes. Does not perform the actual sampling, requiring a subsequent step.
*   **When to use:** When preparing for area-based sampling where material and texture data must be pre-loaded and cached.
*   **When not to use:** When memory is extremely constrained and lazy loading is preferred, or when uniform sampling is sufficient (no area weighting needed).

## Background
This method is part of the `3dgs-dataset-builder` toolchain, which generates point cloud datasets from mesh surfaces for 3D Gaussian Splatting applications [S1, unofficial]. It addresses the need for robust, area-weighted sampling by ensuring that the underlying geometric and material data is correctly prepared and validated before the stochastic sampling process begins.
