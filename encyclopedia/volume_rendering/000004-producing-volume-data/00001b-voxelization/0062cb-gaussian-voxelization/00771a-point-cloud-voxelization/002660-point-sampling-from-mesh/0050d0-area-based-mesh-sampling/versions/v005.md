# Area-Based Mesh Sampling

Also called: Area-Based sampling

## Overview
Area-Based Mesh Sampling generates points on a mesh surface where the number of points per triangle is determined by the triangle's area and a surface density parameter [S1]. It differs from [KD-Tree Guided Point Cloud Sampling](4715-kd-tree-guided-point-cloud-sampling.md) by relying on area-proportional probability rather than spatial proximity constraints to determine sampling density [S1].

## How it works
**Inputs:**
* A mesh defined by a set of triangles [S1].
* A surface density parameter $\rho$ (points per square unit) [S1].

**Outputs:**
* A set of sampled points on the mesh surface [S1].

**Data Structures:**
* Triangle list: Each triangle $T_i$ has vertices $v_1, v_2, v_3$ and a precomputed area $A_i$ [S1].

**Steps:**
1. For each triangle $T_i$ with area $A_i$, calculate the expected number of points $m_i$:
    $$ m_i = \rho \cdot A_i $$
2. Determine the integer number of points $k_i = \lfloor m_i \rfloor$ [S1].
3. Calculate the fractional part $f_i = m_i - k_i$ [S1].
4. Compare a uniform random number to $f_i$; if the random number is less than $f_i$, increment the point count for this triangle to $k_i + 1$ [S1].
5. Distribute the final number of points within the triangle using a standard barycentric coordinate method [G].

**Parameters:**
* $\rho$: Surface density parameter (points per square unit) [S1]. Typical values are not given in the sources [S1].

**Edge Cases and Pitfalls:**
* If $m_i < 1$, the triangle may receive 0 or 1 point depending on the fractional probability [S1].
* Floating-point precision issues in area calculation or random number generation may affect the uniformity of the distribution [G].

**Pseudocode:**
```python
import random
import math

def area_based_mesh_sampling(triangles, density):
    """
    triangles: List of triangles, each represented as a tuple of 3 vertices (v1, v2, v3).
    density: Float, points per square unit (rho).
    Returns: List of sampled points (3D coordinates).
    """
    sampled_points = []
    
    for tri in triangles:
        v1, v2, v3 = tri
        # Calculate triangle area
        ax, ay, az = v2[0]-v1[0], v2[1]-v1[1], v2[2]-v1[2]
        bx, by, bz = v3[0]-v1[0], v3[1]-v1[1], v3[2]-v1[2]
        cross_x = ay*bz - az*by
        cross_y = az*bx - ax*bz
        cross_z = ax*by - ay*bx
        area = 0.5 * math.sqrt(cross_x**2 + cross_y**2 + cross_z**2)
        
        # Expected number of points
        m = density * area
        
        # Integer part
        k = math.floor(m)
        
        # Fractional part
        f = m - k
        
        # Probabilistic additional point
        if random.random() < f:
            k += 1
            
        # Standard barycentric coordinate sampling [G]
        for _ in range(k):
            r1 = random.random()
            r2 = random.random()
            if r1 + r2 > 1:
                r1 = 1 - r1
                r2 = 1 - r2
            u = r1
            v = r2
            w = 1 - u - v
            
            x = u*v1[0] + v*v2[0] + w*v3[0]
            y = u*v1[1] + v*v2[1] + w*v3[1]
            z = u*v1[2] + v*v2[2] + w*v3[2]
            sampled_points.append((x, y, z))
            
    return sampled_points
```

## Subtopics

### [Poisson Disk Sampling](14313-poisson-disk-sampling.md)
Poisson disk sampling is a surface sampling method that uniformly distributes points on a mesh's surface with a minimum geodesic distance constraint of $2r$ between them, given a disk of radius $r$. It utilizes blue noise properties to reduce the effects of aliasing in the later steps of the resulting model. It differs from its parent, Area-Based Mesh Sampling, by enforcing a strict minimum distance constraint rather than relying solely on area-proportional probability.

### [Mesh Triangle Area Sampling Preparation](17804-mesh-triangle-area-sampling-preparation.md)
This method prepares the geometric and material state required for area-based mesh sampling by extracting, validating, and caching mesh data from a collection of objects [G]. It solves the problem of efficiently converting raw scene graph data into a flat, contiguous structure of triangles with associated material and texture references, ensuring that subsequent sampling steps have deterministic access to surface area and material properties [G]. It differs from [Area-Based Mesh Sampling](14310-area-based-mesh-sampling.md) by focusing solely on data extraction and validation rather than the stochastic generation of points, and from [Point Sampling State Preparation](17814-point-sampling-state-preparation.md) by implementing the specific logic for triangle iteration and area calculation within the Blender context [G].

### GeoSplatting Vertex-Sampling
A temporary sampling strategy used during the first 5% of training to reduce memory costs when FlexiCubes isovalues are randomly initialized and produce excessive triangle slices [S2]. For each mesh vertex $v$ with normal $n_v$, it samples a single Gaussian point with mean $\mu=v$, normal $n=n_v$, scaling $s_x=s_y=\sqrt{\frac{k}{3}\sum_{F_i \in \text{Star}(v)} \text{Area}(F_i)}$, scaling $s_z=\delta_{jk}$, rotation $r_x=(0,0,1) \times n_v$, rotation $r_y=n_v \times r_x$, and rotation $r_z=n_v$ [S2]. After the first 5% of training, it switches from vertex-sampling to face-sampling [S2].

## Operating characteristics
Time and memory complexity are not given in the sources [S1, S2]. Measured performance, scaling behavior, strengths, limitations, and specific usage conditions are not given in the sources [S1, S2]. The method is deterministic for area calculation but stochastic for point count selection due to the fractional probability step [S1].

## Background
Area-Based Mesh Sampling is described in "A Comparative Assessment Of Implicit and Explicit Plenoptic Scene Representations" [S1]. It is used in the context of creating Plenoptic Point Clouds for view-dependent rendering [S1].
