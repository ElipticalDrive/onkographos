# Object Coarse Geometry Prediction

Also called: Coarse Geometry Prediction, Object pose initialization

## Overview
Object Coarse Geometry Prediction initializes the 6-DoF pose (rotation and translation) and scale of individual objects within a scene by fitting a parametric mesh to an approximate point cloud derived from image segmentation [S1]. It serves as the initialization step for differentiable rendering optimization, ensuring that subsequent gradient-based refinement starts from a geometrically plausible state rather than a random or poorly scaled configuration [S1]. It differs from sibling methods by explicitly decoupling scale initialization (via median-based radius matching) from rotational initialization (via discrete search over vertical-axis rotations), and by incorporating heuristic constraints for floor contact and floating objects to stabilize the optimization landscape [S1].

## How it works
**Inputs:**
*   $P_{obj}$: Approximate point cloud for the object [S1].
*   $M_{obj}$: CAD mesh or bounding box geometry with known center $c_{mesh}$ and radius $r_{mesh}$ [S1].
*   $W_{obj}$: Image-space segmentation mask for the object [S1].
*   Floor plane and floor segmentation mask $Mask_{floor}$ [S1].
*   Other object masks for floating detection [S1].

**Outputs:**
*   Initial pose parameters $(R_0, t_0, s_0)$ [S1].

**Data Structures:**
*   Point Cloud: List of $(x, y, z)$ coordinates [S1].
*   Bounding Box: Defined by center $c$ and extents [S1].
*   Mask: Binary image or set of pixel coordinates [S1].

**Steps:**

1.  **Compute Object Center:** Calculate the center $c_{pc}$ as the median value of the point cloud coordinates over the three axes [S1].
    $$ c_{pc} = \text{median}(P_{obj}) $$
2.  **Compute Scaling Factor:** Determine the scale factor $s_0$ by matching the mesh radius to half the point cloud radius [S1]. Define the point cloud radius $r_{pc}$ as the median distance from each point to the center [S1]:
    $$ r_{pc} = \text{median}_{p \in P_{obj}} (\| p - c_{pc} \|_2) $$
    Compute scale $s_0$ to match the mesh radius to half the point cloud radius [S1]:
    $$ s_0 = \frac{r_{mesh}}{r_{pc}} $$
3.  **Initialize Translation:** Align the mesh bounding box center $c_{mesh}$ to the point cloud median $c_{pc}$ [S1].
    $$ t_{init} = c_{pc} - s_0 \cdot c_{mesh} $$
4.  **Align Vertical Axis:** Make the vertical axis for each object orthogonal to the room floor [S1].
5.  **Initialize Rotation:** Try a number of rotations around the vertical axis [S1]. Pick the initial rotation $R_0$ that has the minimum mean L1 difference between the rendered mask and the object segmented mask [S1].
6.  **Apply Heuristic Constraints:** If the bottom face of the object’s bounding box and the floor are close (distance $< 0.1$) and the mask edge is close enough to the floor mask (distance $< 20$px), mark the object as “on the floor” and use a floor-distance loss when optimizing [S1]. If an object is floating, search if the object mask edge is close enough (distance $< 20$px) of another object edge on the floor; if so, enforce the floating object to stay on top of the parent object [S1].

**Pseudocode:**
```python
def coarse_geometry_prediction(P_obj, mesh, W_obj, floor_mask):
    # 1. Compute center as median over three axes [S1]
    c_pc = np.median(P_obj, axis=0)
    # 2. Compute radius as median distance to center [S1]
    r_pc = np.median(np.linalg.norm(P_obj - c_pc, axis=1))
    r_mesh = mesh.radius
    # Match mesh radius to half point cloud radius [S1]
    s_0 = r_mesh / r_pc
    # 3. Align mesh center to point cloud median [S1]
    t_init = c_pc - s_0 * mesh.center
    # 4. Make vertical axis orthogonal to room floor [S1]
    # [G] Compute rotation aligning mesh up vector to floor normal
    R_vert = compute_alignment_rotation(mesh.up_vector, floor_normal)
    # 5. Discrete rotation search around vertical axis [S1]
    best_R, min_loss = None, np.inf
    for angle in np.linspace(0, 2*np.pi, 36):
        R_cand = rotation_matrix_z(angle) @ R_vert
        # [G] Render binary mask with current pose and scale
        W_render = render_object_mask(mesh, R_cand, t_init, s_0)
        loss = np.mean(np.abs(W_render - W_obj))
        if loss < min_loss:
            min_loss = loss
            best_R = R_cand
    R_0 = best_R
    # 6. Heuristic constraints [S1]
    on_floor = False
    if bounding_box_bottom_dist(mesh, floor_plane) < 0.1 and mask_edge_distance(W_obj, floor_mask) < 20:
        on_floor = True
    return R_0, t_init, s_0, on_floor
```

**Pitfalls:**
*   **Scale Initialization:** The method intentionally initializes objects to be smaller than reality and allows them to grow during optimization, which makes the optimization better behaved than trying to initialize the scale accurately [S1].
*   **Vertical Axis Assumption:** The heuristic of making the vertical axis orthogonal to the floor is appropriate for most indoor objects [S1].

## Operating characteristics
*   **Time Complexity:** Not given in the sources.
*   **Memory Complexity:** Not given in the sources.
*   **Strengths:** Uses median-based statistics for scale and center, which is robust to outliers [S1]. Decouples scale and rotation initialization [S1]. Heuristic constraints for floor contact and floating objects stabilize the optimization landscape [S1].
*   **Limitations:** Relies on accurate image-space segmentation masks [S1]. Assumes vertical alignment with the floor [S1]. Uses discrete rotation search which may miss the global optimum if steps are coarse [S1].
*   **When to use:** Initializing differentiable rendering for indoor scenes with segmented object masks and approximate point clouds [S1].
*   **When not to use:** Not given in the sources.

## Background
The method originates from the cited research on single-photo scene reconstruction using differentiable rendering [S1]. It addresses initializing object poses when only coarse geometric priors and 2D segmentation masks are available [S1]. The approach leverages median-based statistics for robust scale and center estimation, combined with a discrete image-space metric for rotational initialization [S1].
