# Principal Axes Alignment
## Overview
Principal Axes Alignment computes a $4 \times 4$ SE(3) transform that aligns a point cloud to its principal axes of covariance while centering it at the median [S1, unofficial]. It differs from mean-based centering methods by using the median, which provides robustness against outliers in the point distribution [S1, unofficial].

## How it works
**Inputs and Outputs**
- Input: An $N \times 3$ point cloud matrix $P$, where each row is a 3D coordinate.
- Output: A $4 \times 4$ homogeneous transformation matrix $T$ (SE(3)) that aligns the point cloud to its principal axes and centers it at the median [S1, unofficial].

**Data Structures**
- $P$: $N \times 3$ float array of point coordinates.
- $C$: $1 \times 3$ centroid vector.
- $\Sigma$: $3 \times 3$ covariance matrix.
- $E$: $3 \times 3$ matrix of eigenvectors (columns).
- $\Lambda$: $1 \times 3$ vector of eigenvalues.
- $T$: $4 \times 4$ identity matrix initialized, then modified.

**Steps**
1. **Compute Centroid**: Calculate the median of the point cloud along the point axis.
   $$ C = \text{median}(P, \text{axis}=0) $$
   [S1, unofficial]
2. **Translate to Centroid**: Subtract the centroid from all points to center the cloud at the origin.
   $$ P' = P - C $$
   [S1, unofficial]
3. **Compute Covariance Matrix**: Calculate the covariance matrix of the centered points.
   $$ \Sigma = \text{cov}(P', \text{rowvar}=False) $$
   [S1, unofficial]
4. **Eigen Decomposition**: Compute eigenvalues and eigenvectors of $\Sigma$.
   $$ \Lambda, E = \text{eigh}(\Sigma) $$
   [S1, unofficial]
   Note: `eigh` returns eigenvalues in ascending order.
5. **Sort Eigenvectors**: Sort the eigenvectors corresponding to eigenvalues in descending order so the z-axis corresponds to the smallest eigenvalue.
   $$ \text{sort\_indices} = \text{argsort}(\Lambda)[::-1] $$
   $$ E_{sorted} = E[:, \text{sort\_indices}] $$
   [S1, unofficial]
6. **Ensure Right-Handed System**: Check the determinant of the eigenvector matrix. If $\det(E_{sorted}) < 0$, flip the sign of the first eigenvector to ensure a right-handed coordinate system.
   $$ \text{if } \det(E_{sorted}) < 0: \quad E_{sorted}[:, 0] *= -1 $$
   [S1, unofficial]
7. **Construct Transform**: Build the $4 \times 4$ SE(3) transform. The rotation part is $R = E_{sorted}^T$. The translation part maps the original centroid to the origin.
   $$ R = E_{sorted}^T $$
   $$ T = \begin{bmatrix} R & -R C \\ 0 & 1 \end{bmatrix} $$
   [S1, unofficial]

**Pseudocode**
```python
import numpy as np

def principal_axes_alignment(point_cloud: np.ndarray) -> np.ndarray:
    """
    Aligns a point cloud to its principal axes and centers it at the median.
    
    Args:
        point_cloud: (N, 3) array of points.
        
    Returns:
        T: (4, 4) SE(3) transformation matrix.
    """
    # Step 1: Compute centroid as median
    centroid = np.median(point_cloud, axis=0)
    
    # Step 2: Translate point cloud to centroid
    translated_point_cloud = point_cloud - centroid
    
    # Step 3: Compute covariance matrix
    covariance_matrix = np.cov(translated_point_cloud, rowvar=False)
    
    # Step 4: Compute eigenvectors and eigenvalues
    eigenvalues, eigenvectors = np.linalg.eigh(covariance_matrix)
    
    # Step 5: Sort eigenvectors by eigenvalues in descending order
    # The z-axis is the principal axis with the smallest eigenvalue
    sort_indices = eigenvalues.argsort()[::-1]
    eigenvectors = eigenvectors[:, sort_indices]
    
    # Step 6: Ensure right-handed coordinate system
    if np.linalg.det(eigenvectors) < 0:
        eigenvectors[:, 0] *= -1
        
    # Step 7: Create rotation matrix and SE(3) transform
    rotation_matrix = eigenvectors.T
    transform = np.eye(4)
    transform[:3, :3] = rotation_matrix
    transform[:3, 3] = -rotation_matrix @ centroid
    
    return transform
```

It serves as the initialization step for differentiable rendering optimization, ensuring that subsequent gradient-based refinement starts from a geometrically plausible state rather than a random or poorly scaled configuration.
