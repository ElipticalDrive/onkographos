# Point Resampling with Neighbor Masking

Also called: Point Resampling

## Overview
Point Resampling with Neighbor Masking selectively reduces point cloud or tetrahedral grid density by discarding inactive points based on their topological relationship to active regions [S1, unofficial]. It solves the compression problem by preserving geometric fidelity while reducing file size, as demonstrated by compressing a model from 1.0MB to 345.5kB [S1, unofficial]. It supports partial, percentage, and full resampling strategies [S1, unofficial].

## How it works
**Inputs and Outputs:**
- Input: A set of points `x_nx3` (shape $N \times 3$), a Signed Distance Field `sdf`, and a tetrahedral mesh `tets` (indices of vertices forming tetrahedra) [S1, unofficial].
- Output: A boolean mask `mask` of length $N$, where `True` indicates a point to be kept (resampled) and `False` indicates a point to be discarded [S1, unofficial].

**Data Structures:**
- `mask`: A boolean array of size $N$ [S1, unofficial].
- `neighbor_active_points_ids`: Indices of points adjacent to active tetrahedra [S1, unofficial].
- `active_points_ids`: Indices of points currently active (e.g., inside or near the isosurface) [S1, unofficial].

**Steps:**
The method supports three strategies: Partial, Percentage, and Full resampling [S1, unofficial].

1. **Partial Resampling:**
   - Identify neighbor points: Call `neighbor_active_points(sdf, tets)` to get `neighbor_active_points_ids` [S1, unofficial].
   - Create mask: Initialize `mask` of size $N$ with `False` [S1, unofficial].
   - Set `mask[neighbor_active_points_ids] = True` [S1, unofficial].
   - The number of resampled points is the count of `True` values in `mask` [S1, unofficial].

2. **Percentage Resampling:**
   - Identify active points: Call `get_active_points(sdf, tets)` to get `active_points_ids` [S1, unofficial].
   - Identify neighbor points: Call `neighbor_active_points(sdf, tets)` to get `neighbor_active_points_ids` [S1, unofficial].
   - Create mask: Initialize `mask` of size $N$ with `False` [S1, unofficial].
   - Set `mask[active_points_ids] = True` [S1, unofficial].
   - Find indices where mask is `True`: `true_indices = where(mask == True)` [S1, unofficial].
   - Add neighbors: Set `mask[neighbor_active_points_ids] = True` [S1, unofficial].
   - Update `true_indices` to reflect all `True` positions in the updated mask [S1, unofficial].
   - Shuffle `true_indices` randomly [S1, unofficial].
   - Flip the first 90% of shuffled indices to `False` in the mask [S1, unofficial].
   - The number of resampled points is the count of `True` values in `mask` [S1, unofficial].

3. **Full Resampling:**
   - Set `nb_resampled_points = x_nx3.shape[0]` [S1, unofficial].
   - Create `mask` of size $N$ with all `False` [S1, unofficial].
   - The all-False mask indicates that no points are discarded, effectively keeping all input points [S1, unofficial].

**Pseudocode:**
```python
import random

def resample_points(x_nx3, sdf, tets, strategy='partial', percentage=0.9):
    """
    Resample points based on neighbor masking.
    
    Args:
        x_nx3: Array of shape (N, 3) containing point coordinates.
        sdf: Signed Distance Field function or grid.
        tets: Array of tetrahedron vertex indices.
        strategy: 'partial', 'percentage', or 'full'.
        percentage: Fraction of active+neighbor points to keep (for 'percentage' strategy).
        
    Returns:
        mask: Boolean array of shape (N,) where True means keep the point.
    """
    N = len(x_nx3)
    mask = [False] * N
    
    if strategy == 'partial':
        neighbor_ids = neighbor_active_points(sdf, tets)  # [G] External lookup
        for idx in neighbor_ids:
            mask[idx] = True
            
    elif strategy == 'percentage':
        active_ids = get_active_points(sdf, tets)  # [G] External lookup
        neighbor_ids = neighbor_active_points(sdf, tets)  # [G] External lookup
        
        for idx in active_ids:
            mask[idx] = True
        for idx in neighbor_ids:
            mask[idx] = True
            
        true_indices = [i for i, v in enumerate(mask) if v]
        random.shuffle(true_indices)
        
        num_to_flip = int(percentage * len(true_indices))
        for i in range(num_to_flip):
            mask[true_indices[i]] = False
            
    elif strategy == 'full':
        nb_resampled_points = N
        
    return mask
```

**Parameters:**
- `strategy`: String, one of `'partial'`, `'percentage'`, `'full'` [S1, unofficial].
- `percentage`: Float, fraction of points to keep in percentage mode. Default: `0.9` [S1, unofficial].

**Edge Cases and Pitfalls:**
- **Precision:** SDF evaluation must be precise to correctly identify active vs. inactive regions [G].
- **Boundaries:** Points on the boundary of the domain may have fewer neighbors, affecting the mask density [G].
- **Degenerate Input:** If `tets` is empty or `sdf` is undefined, the helper functions will fail [G]. Ensure `tets` and `sdf` are valid before calling.

## Subtopics

### [Error-Driven Point Resampling & Grid Aggregation](5425-error-driven-point-resampling-grid-aggregation.md)
Accumulates per-pixel rendering errors into a 3D voxel grid to compute mean error density, which guides point resampling for tetrahedral grid refinement. It distinguishes itself from this method by driving resampling probability based on quantitative rendering error rather than topological neighbor status. Choose it when geometric fidelity must be tied to view-dependent rendering artifacts.

### [Random Point Subsampling](6215-random-point-subsampling.md)
Selects a random subset of points from a given set without replacement. It distinguishes itself from this method by ignoring spatial distribution or error metrics, treating all input points as equally probable candidates for retention. Choose it as a baseline strategy for reducing point cloud density when spatial structure is irrelevant.

### [A-buffer Sampling Method](12360-a-buffer-sampling-method.md)
Maps scattered input data points onto a rectangular grid by accumulating weighted contributions from all nearby points instead of selecting a single nearest neighbor. It distinguishes itself from this method by preserving data accuracy through weighted averaging rather than binary neighbor masking, producing more accurate images at the cost of higher computational time. Choose it when converting unstructured point clouds to structured voxel grids requires high fidelity over speed.

## Operating characteristics
- **Time Complexity:** Depends on the cost of `get_active_points` and `neighbor_active_points`, which typically involve traversing the tetrahedral mesh and evaluating the SDF. For $N$ points and $T$ tetrahedra, neighbor identification is $O(T)$ or $O(N)$ depending on implementation. Shuffling is $O(N)$ [G].
- **Memory Complexity:** $O(N)$ for the mask and indices [G].
- **Performance:** The method is efficient for compression, reducing file size significantly (e.g., from 1.0MB to 345.5kB in the cited example) by discarding inactive points [S1, unofficial].
- **Strengths:** Preserves geometric structure by keeping neighbors of active regions. Simple to implement [G].
- **Limitations:** Relies on the quality of the SDF and tetrahedral mesh. May not preserve fine details if the percentage is too low [G].
- **When to use:** When compressing point clouds or tetrahedral grids for storage or transmission while maintaining structural integrity [S1, unofficial].
- **When not to use:** When uniform random sampling is sufficient or when error-driven refinement is required [G].

## Background
The method originates from the TetWeave project, which focuses on isosurface extraction using on-the-fly Delaunay tetrahedral grids for gradient-based mesh optimization [S1, unofficial]. It was developed by Alexandre Binninger, Ruben Wiersma, Philipp Herholz, and Olga Sorkine-Hornung for SIGGRAPH 2025 [S1, unofficial]. The technique is part of a pipeline that includes compression via discarding inactive points and converting values to `float16` [S1, unofficial].
