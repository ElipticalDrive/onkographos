# Global Feature Volume Construction

Also called: Fv Construction, Global Feature Volume Construction via Voxelization and U-Net

## Overview
Global Feature Volume Construction builds a dense 3D feature volume $F_v$ from multi-view 2D features to provide global contextual information for downstream volume rendering tasks [S1][S2, unofficial]. It differs from local feature aggregation by first lifting 2D features into a 3D grid via projection and statistical pooling, then regularizing the result with a 3D U-Net [S1][S2, unofficial].

## How it works
**Inputs:**
- $N$: Number of source views [S1][S2, unofficial].
- $\{F_i\}_{i=1}^N$: 2D feature maps from source views, each of spatial resolution $H \times W$ and channel depth $C$ [S2, unofficial].
- $K$: Resolution of the global feature volume grid per dimension [S1][S2, unofficial].
- Bounding volume: The 3D region containing the scene [S1][S2, unofficial].

**Outputs:**
- $F_v$: The global feature volume [S1][S2, unofficial].

**Data Structures:**
- Voxel Grid: A regular grid of $K^3$ voxels covering the bounding volume [S1].
- Voxel Feature: A vector constructed for each voxel by concatenating the mean and variance of projected features [S1][S2, unofficial].

**Steps:**
1. **Voxelization:** Divide the bounding volume into a grid of $K^3$ voxels [S1][S2, unofficial].
2. **Projection and Interpolation:** For each voxel center, project it onto the 2D feature map of each source view [S1][S2, unofficial]. Obtain the feature vector using bilinear interpolation [S1][S2, unofficial].
3. **Statistical Aggregation:** For each voxel, compute the mean and variance across the $N$ interpolated features [S1][S2, unofficial].
4. **Feature Concatenation:** Concatenate the mean and variance vectors to form the initial voxel feature [S1][S2, unofficial].
5. **Regularization:** Input the voxel features into a 3D U-Net to regularize and aggregate information, producing $F_v$ [S1][S2, unofficial].

**Pseudocode:**
```python
def construct_global_feature_volume(feature_maps, K, bounding_volume):
    """
    feature_maps: List of N arrays, each shape (H, W, C)
    K: Integer, resolution of the output volume
    bounding_volume: Dict with keys min_x, max_x, min_y, max_y, min_z, max_z
    """
    N = len(feature_maps)
    C = feature_maps[0].shape[2]
    
    step_x = (bounding_volume['max_x'] - bounding_volume['min_x']) / K
    step_y = (bounding_volume['max_y'] - bounding_volume['min_y']) / K
    step_z = (bounding_volume['max_z'] - bounding_volume['min_z']) / K
    
    voxel_features = []
    for i in range(K):
        for j in range(K):
            for k in range(K):
                cx = bounding_volume['min_x'] + (i + 0.5) * step_x
                cy = bounding_volume['min_y'] + (j + 0.5) * step_y
                cz = bounding_volume['min_z'] + (k + 0.5) * step_z
                
                view_features = []
                for v in range(N):
                    u, v_coord = project_3d_to_2d(cx, cy, cz, feature_maps[v].camera_params)
                    u = max(0, min(u, feature_maps[v].width - 1))
                    v_coord = max(0, min(v_coord, feature_maps[v].height - 1))
                    f = bilinear_interpolate(feature_maps[v].data, u, v_coord)
                    view_features.append(f)
                
                mean_feat = [sum(view_features[n][c] for n in range(N)) / N for c in range(C)]
                var_feat = [sum((view_features[n][c] - mean_feat[c])**2 for n in range(N)) / N for c in range(C)]
                
                voxel_features.append(mean_feat + var_feat)
    
    # Reshape flat list to (K, K, K, 2*C)
    voxel_grid = [voxel_features[i * K * (2*C) + j * (2*C) + k] 
                  for i in range(K) for j in range(K) for k in range(2*C)]
    # Note: In practice, this is a contiguous tensor reshape
    
    Fv = UNet3D(voxel_grid)
    return Fv

def project_3d_to_2d(x, y, z, camera_params):
    u = camera_params.fx * (x / z) + camera_params.cx
    v = camera_params.fy * (y / z) + camera_params.cy
    return u, v

def bilinear_interpolate(image, u, v):
    u0, u1 = int(u), int(u) + 1
    v0, v1 = int(v), int(v) + 1
    u0, u1 = max(0, min(u0, image.width - 1)), max(0, min(u1, image.width - 1))
    v0, v1 = max(0, min(v0, image.height - 1)), max(0, min(v1, image.height - 1))
    w00, w01, w10, w11 = (u1 - u) * (v1 - v), (u - u0) * (v1 - v), (u1 - u) * (v - v0), (u - u0) * (v - v0)
    return [w00 * image[v0][u0][c] + w01 * image[v0][u1][c] + w10 * image[v1][u0][c] + w11 * image[v1][u1][c] for c in range(len(image[0][0]))]
```

**Parameters:**
- $K$: Number of voxels per dimension. Typical value: $K=96$ [S2, unofficial].
- $N$: Number of source views [S1][S2, unofficial].

**Edge Cases:**
- Precision: Bilinear interpolation requires accurate 3D-to-2D projection coordinates [G].
- Boundaries: Voxels outside the scene geometry receive features based on the bounding volume; the 3D U-Net regularizes these values [S1][S2, unofficial].

## Operating characteristics
- **Time Complexity:** Dominated by the projection and interpolation step for all $K^3$ voxels and $N$ views, i.e., $O(K^3 \cdot N)$ [G]. The 3D U-Net adds overhead proportional to its depth and channel dimensions [G].
- **Memory Complexity:** Scales with $K^3$ for the voxel grid and U-Net activations [G].
- **Performance:** Using $K=96$ balances detail and computational cost [S2, unofficial].
- **Strengths:** Provides global context to resolve appearance-geometry ambiguities common in NeRF-based methods [S1][S2, unofficial].
- **Limitations:** Requires significant memory for large $K$ and $N$ [G].

## Background
- **Origin:** Introduced in VolRecon (Ren et al., CVPR 2023) [S1][S2, unofficial].
- **Development:** Builds on earlier works using global feature volumes for generalizable reconstruction [S1][S2, unofficial].
- **Usage:** Used in VolRecon for generalizable multi-view reconstruction to complement Signed Ray Distance Functions (SRDF) [S1].
