# Sparse Point Probability Octree


## Overview
The Sparse Point Probability Octree is a hierarchical spatial data structure that replaces explicit persistent point positions with a probabilistic volume representation for radiance field rendering [S1]. It solves the problem of managing a fixed budget of sampled points by allowing point clouds to be extracted on demand from a multinomial distribution defined by leaf node probabilities [S1].

## How it works
**Inputs and Outputs:**
- **Input:** A sparse octree where each leaf node $i$ maintains a probability $p_i$ and a subdivision metric $q_i$, initialized from a uniform 3D voxel grid or an optional point cloud prior [S1].
- **Output:** An updated octree with refined leaf nodes, used to sample point positions for rendering [S1].

**Data Structures:**
- **Sparse Octree:** A tree where each node has a bounding volume and up to eight children [G].
- **Leaf Node Fields:**
  - $p_i$: Float, point probability for leaf $i$ [S1].
  - $q_i$: Float, subdivision metric for leaf $i$ [S1].
  - children: List of up to 8 child nodes or null if leaf [G].

**Numbered Steps:**

1. **Initialization:** Create a uniform 3D voxel grid as the initial set of leaf nodes [S1]. Set $p_i$ to a uniform value for all leaves to ensure equal sampling probability [S1]. Set $q_i = 0$ for all initial leaves [S1]. Optionally incorporate a point cloud prior to improve initial convergence [S1].

2. **Rendering and Weight Extraction:** For each leaf node $i$, extract $n$ points [S1]. Compute the transmitted blending weight $b_j$ for each point $j$ using the rasterizer: $b_j = \alpha_j T_j$, where $\alpha_j$ is the opacity and $T_j$ is the transmittance [S1]. Let $\{b_0, ..., b_n\}$ be the set of these weights for leaf $i$ [S1].

3. **Probability Update:** If the current iteration is less than 100, skip probability updates [S1]. Otherwise, update $p_i$ using exponential decay and the maximum blending weight:
   $$p_i = \max (\lambda_u \cdot p_i, \max (\{b_0, ..., b_n\}))$$
   Here, $\lambda_u$ is the exponential decay factor [S1]. This imposes a visibility prior where occluded points (lower $T_j$) receive less probability mass [S1].

4. **Subdivision Metric Update:** Update $q_i$ to track the difference between the largest and smallest blending weights:
   $$q_i = \max (\lambda_u \cdot q_i, \max (\{b_0, ..., b_n\}) - \min (\{b_0, ..., b_n\}))$$
   This identifies partially unoccupied voxels [S1].

5. **Subdivision:** If the current iteration is a multiple of 500: For each leaf node $i$ where $q_i > \tau_s$: Check if the resulting number of leaves after subdivision is less than $256^3$. If not, skip subdivision due to numerical precision limits in multinomial sampling [S1]. Subdivide leaf $i$ into 8 new children [S1]. Created leaves inherit their parent's probability, and the initial value of $q_i$ for new leaves is set to 0 [S1].

6. **Pruning:** If the current iteration is a multiple of 100 and greater than 500: For each leaf node $i$ where $p_i < \tau_p$: Remove leaf node $i$ from the octree [S1].

**Parameters:**
- $\lambda_u$: Exponential decay factor. Typical value: 0.9968 [S1].
- $\tau_s$: Threshold for subdivision. Typical value: 0.5 [S1].
- $\tau_p$: Threshold for pruning. Typical value: 0.01 [S1].

**Pitfalls:**
- **Numerical Precision:** Multinomial sampling has precision limitations. Do not subdivide if the total number of leaves exceeds $256^3$ [S1].
- **Early Iterations:** Skip probability updates for the first 100 iterations because the appearance network lacks reliable information [S1].
- **Pruning Stability:** Do not start pruning until after the first 500 iterations to ensure stability [S1].

**Pseudocode:**

```python
def update_sparse_point_probability_octree(octree, iteration, lambda_u, tau_s, tau_p):
    MAX_LEAVES = 256**3

    class LeafNode:
        def __init__(self, p=0.0, q=0.0, children=None):
            self.p = p
            self.q = q
            self.children = children if children is not None else []
            self.is_leaf = len(self.children) == 0

    def get_all_leaves(node):
        if node.is_leaf:
            return [node]
        leaves = []
        for child in node.children:
            leaves.extend(get_all_leaves(child))
        return leaves

    def count_total_leaves(node):
        return len(get_all_leaves(node))

    def extract_points_from_leaf(leaf):
        # Source does not specify extraction; typically a rasterizer assigns points to leaves [G]
        return []

    def find_parent(root, target):
        if root.is_leaf:
            return None
        for child in root.children:
            if child is target:
                return root
            parent = find_parent(child, target)
            if parent is not None:
                return parent
        return None

    def update_leaf(leaf):
        points = extract_points_from_leaf(leaf)
        if not points:
            return
        weights = [p.opacity * p.transmittance for p in points]
        max_b = max(weights)
        min_b = min(weights)
        if iteration >= 100:
            leaf.p = max(lambda_u * leaf.p, max_b)
        leaf.q = max(lambda_u * leaf.q, max_b - min_b)

    def subdivide_leaf(leaf):
        if count_total_leaves(octree) + 7 >= MAX_LEAVES:
            return
        children = [LeafNode(p=leaf.p, q=0.0) for _ in range(8)]
        leaf.is_leaf = False
        leaf.children = children

    def prune_leaf(leaf, parent):
        if parent is not None:
            parent.children.remove(leaf)
            if not parent.children:
                parent.is_leaf = True

    leaves = get_all_leaves(octree)
    for leaf in leaves:
        update_leaf(leaf)

    if iteration > 0 and iteration % 500 == 0:
        leaves_to_subdivide = [l for l in leaves if l.q > tau_s]
        for leaf in leaves_to_subdivide:
            subdivide_leaf(leaf)
        leaves = get_all_leaves(octree)

    if iteration > 500 and iteration % 100 == 0:
        leaves_to_prune = [l for l in leaves if l.p < tau_p]
        for leaf in leaves_to_prune:
            parent = find_parent(octree, leaf)
            prune_leaf(leaf, parent)
```

## Subtopics

### [Viewpoint-Specific Sampling](18302-viewpoint-specific-sampling.md)
Viewpoint-Specific Sampling is a strategy for generating point clouds from a sparse point probability octree tailored to a specific camera viewpoint. It solves the problem of inefficient or low-quality reconstruction by ensuring samples are placed only within the view frustum, biased towards foreground regions, and adjusted for voxel size. It sets itself apart from uniform sampling by incorporating visibility, depth, and subdivision level into the probability distribution, and from static sampling by being dynamic to the camera pose.

### Viewpoint-Independent Sampling
Viewpoint-Independent Sampling is a strategy to pre-extract a global point cloud for all viewpoints to increase temporal stability and rendering performance during inference, avoiding per-frame sampling [S1]. It uses multinomial sampling with replacement but omits the visibility ($1_{\text{visible}}$) and depth ($d_i$) factors [S1]. It uses the 3D Halton sequence to determine the final position of each sample within the leaf to increase stability [S1].

## Operating characteristics
- **Memory Complexity:** The memory usage is proportional to the number of leaves, capped at $256^3$ due to numerical precision constraints [S1].
- **Measured Performance:** The method allows for accurate reconstruction of fine geometric structures by refining partially unoccupied voxels [S1].
- **Strengths:** Replaces explicit point positions with a probabilistic representation, enabling on-demand sampling and efficient memory usage [S1]. The visibility prior helps in handling occluded points [S1].
- **Limitations:** Limited by the $256^3$ leaf count due to multinomial sampling precision [S1]. Requires careful tuning of thresholds $\tau_s$ and $\tau_p$ [S1].
- **When to use:** When rendering radiance fields with a fixed budget of sampled points and needing to reconstruct fine geometry [S1].
- **When not to use:** When the scene requires more than $256^3$ distinct leaf nodes for accurate representation [S1].

## Background
The Sparse Point Probability Octree was introduced in the INPC (Implicit Neural Point Clouds) method for radiance field rendering [S1]. It addresses the limitations of fixed voxel size in regular occupancy grids by using a sparse octree to store point probabilities [S1]. The method builds on the idea of sampling high-quality point clouds using an implicit octree-based point position estimator [S1].
