# Voxel Downsampling Registration

Also called: ICP Registration with Voxel Downsampling, ICP with Voxel Downsampling

## Overview
Voxel Downsampling Registration aligns a source point cloud to a target point cloud by first reducing point density via voxel grid sampling and then applying Iterative Closest Point (ICP) [S1, S2, unofficial]. It differs from standard ICP by incorporating a voxel-based spatial reduction step before correspondence matching [S1, S2, unofficial]. It builds on [Point Cloud Cropping and Downsampling](7057-point-cloud-cropping-and-downsampling.md) for the spatial reduction step [G].

## How it works
**Inputs:**
- Source point cloud $P_s$ [S1, S2, unofficial].
- Target (ground truth) point cloud $P_t$ [S1, S2, unofficial].
- Crop volume $V$ (bounding box or region of interest) [G].
- Voxel size $d_v$ [S1, unofficial].
- ICP distance threshold $\tau$ [S1, S2, unofficial].
- Initial transformation matrix $T_{init}$ (typically $4 \times 4$ identity or a coarse estimate) [S1, S2, unofficial].
- Maximum ICP iterations $N_{max}$ [S1, S2, unofficial].
- Convergence tolerance $\epsilon = 10^{-6}$ [S1, S2, unofficial].

**Outputs:**
- Final transformation matrix $T_{final}$ that aligns $P_s$ to $P_t$ [S1, S2, unofficial].
- Registration result object containing convergence metrics [S1, S2, unofficial].

**Data Structures:**
- **Point Cloud:** List of 3D coordinates $(x, y, z)$ [G].
- **Voxel Grid:** Implicit hash map or 3D array mapping voxel indices $(i, j, k)$ to a single representative point (centroid or first point) from the input cloud [G].
- **Transformation Matrix:** $4 \times 4$ homogeneous transformation matrix [G].

**Steps:**
1. **Configuration:** If verbose mode is enabled, print $d_v$ and $\tau$, and set library verbosity to Debug [S1, unofficial].
2. **Source Downsampling:** Apply voxel downsampling to $P_s$ using $V$ and $d_v$, optionally applying $T_{init}$ during the crop/downsample operation if the source needs pre-alignment before voxelization [S1, unofficial]. Let the result be $P'_s$.
3. **Target Downsampling:** Apply voxel downsampling to $P_t$ using $V$ and $d_v$. Let the result be $P'_t$. Note that $T_{init}$ is not applied to the target in the standard workflow [S1, S2, unofficial].
4. **ICP Execution:** Run ICP between $P'_s$ and $P'_t$ using threshold $\tau$, initial guess $I$ (identity matrix), point-to-point distance metric, convergence tolerance $\epsilon = 10^{-6}$, and max iterations $N_{max}$ [S1, S2, unofficial]. Let the resulting transformation be $T_{icp}$ [S1, S2, unofficial].
5. **Transformation Composition:** Combine the ICP result with the initial transformation: $T_{final} = T_{icp} \times T_{init}$ [S1, S2, unofficial].
6. **Return:** Return $T_{final}$ and registration statistics [S1, unofficial].

**Pseudocode:**
```python
import numpy as np

def voxel_downsampling_registration(source, target, crop_volume, voxel_size, threshold, init_trans, max_itr):
    # Step 1: Configuration
    # If verbose: print(voxel_size, threshold)
    # Set library verbosity to Debug

    # Step 2: Downsample source
    source_down = _voxel_downsample(source, crop_volume, voxel_size, init_trans)

    # Step 3: Downsample target
    target_down = _voxel_downsample(target, crop_volume, voxel_size, None)

    # Step 4: Perform ICP
    reg = _icp_registration(source_down, target_down, threshold, np.identity(4), max_itr, 1e-6)

    # Step 5: Update transformation
    final_transformation = np.matmul(reg.transformation, init_trans)

    # Step 6: Return
    return final_transformation, reg

def _voxel_downsample(points, crop_volume, voxel_size, trans):
    # Apply transformation if provided
    if trans is not None:
        points = (trans @ np.vstack([points.T, np.ones(len(points))]))[:3].T
    # Filter by crop volume (axis-aligned bounding box)
    min_pt, max_pt = crop_volume.min, crop_volume.max
    mask = np.all((points >= min_pt) & (points <= max_pt), axis=1)
    points = points[mask]
    # Map to voxel grid and compute centroids
    voxel_indices = np.floor((points - min_pt) / voxel_size).astype(int)
    unique_indices, inverse = np.unique(voxel_indices, axis=0, return_inverse=True)
    centroids = np.array([points[inverse == i].mean(axis=0) for i in range(len(unique_indices))])
    return centroids

def _icp_registration(src, tgt, threshold, init_T, max_itr, tol):
    # Standard point-to-point ICP loop [G]
    T = init_T.copy()
    src_transformed = src @ T[:3, :3].T + T[:3, 3]
    for _ in range(max_itr):
        # Find correspondences within threshold
        dists = np.linalg.norm(src_transformed[:, None, :] - tgt[None, :, :], axis=2)
        min_dists = np.min(dists, axis=1)
        corr_indices = np.argmin(dists, axis=1)
        if np.all(min_dists > threshold):
            break
        # Point-to-point least squares (SVD)
        A = src_transformed
        B = tgt[corr_indices]
        centroid_A = A.mean(axis=0)
        centroid_B = B.mean(axis=0)
        H = (A - centroid_A).T @ (B - centroid_B)
        U, _, Vt = np.linalg.svd(H)
        R = Vt.T @ U.T
        if np.linalg.det(R) < 0:
            Vt[-1, :] *= -1
            R = Vt.T @ U.T
        t = centroid_B - R @ centroid_A
        T[:3, :3] = R
        T[:3, 3] = t
        src_transformed = src @ R.T + t
        if np.linalg.norm(t) < tol:
            break
    class RegResult:
        def __init__(self, transformation):
            self.transformation = transformation
    return RegResult(T)
```

**Parameters:**
- `voxel_size`: The side length of the voxel grid. Required [S1, unofficial].
- `threshold`: The maximum distance for point correspondences in ICP [S1, S2, unofficial].
- `max_itr`: Maximum number of ICP iterations [S1, unofficial].
- `init_trans`: Initial $4 \times 4$ transformation matrix [S1, S2, unofficial].

**Edge Cases:**
- Degenerate input (empty point clouds) after downsampling will cause ICP to fail [S1, unofficial].
