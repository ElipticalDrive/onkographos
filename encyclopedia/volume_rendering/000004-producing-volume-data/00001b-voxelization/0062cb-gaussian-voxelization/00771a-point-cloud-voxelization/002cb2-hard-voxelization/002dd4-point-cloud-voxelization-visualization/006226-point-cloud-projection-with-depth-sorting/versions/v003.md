# Point Cloud Projection with Depth Sorting
## Overview
Point Cloud Projection with Depth Sorting renders a voxelized point cloud into a 2D image by quantizing 3D coordinates, applying user-controlled panning, and resolving visual overlaps via depth comparison [S1]. It builds on [Point Cloud Voxelization Visualization](5628-point-cloud-voxelization-visualization.md) by providing a deterministic projection pipeline for simultaneous reference and distorted content comparison [S1].

## How it works
**Inputs:**
- Reference point cloud: List of points $P_{\text{ref}} = \{(x_i, y_i, z_i, r_i, g_i, b_i)\}$ [S1].
- Distorted point cloud: List of points $P_{\text{dist}} = \{(x_j, y_j, z_j, r_j, g_j, b_j)\}$ [S1].
- User parameters: Panning shift $(\Delta x, \Delta y)$, applied identically to both clouds [S1].

**Outputs:**
- Reference image: 2D array of RGB values [S1].
- Distorted image: 2D array of RGB values [S1].

**Data Structures:**
- Image buffer: 2D array `Image[W][H]` initialized to default color [S1].
- Point structure: Tuple `(x, y, z, r, g, b)` [S1].

**Steps:**
1. **Initialization**: Create two image buffers, `Image_ref` and `Image_dist`, of dimensions $W \times H$. Initialize every pixel in both buffers to the default neutral gray value $(127, 127, 127)$ [S1].
2. **Quantization and Panning**: For each point in the reference and distorted clouds, quantize the spatial coordinates $(x, y, z)$ to integer values. Apply the user-defined panning shift $(\Delta x, \Delta y)$ to the $x$ and $y$ coordinates:
   $$ \hat{x} = \text{round}(x) + \Delta x $$
   $$ \hat{y} = \text{round}(y) + \Delta y $$
   The $z$ coordinate remains as the distance metric from the projection plane [S1].
3. **Projection and Depth Sorting**: Iterate through all points in the reference cloud. For each point with quantized coordinates $(\hat{x}, \hat{y})$ and depth $z$:
   - If the pixel `Image_ref[$\hat{x}$][$\hat{y}$]` is unoccupied (still default gray) or the current point has a smaller $z$ (closer to the projection plane) than the point currently stored at that pixel, update the pixel color to $(r, g, b)$ of the current point [S1].
   - If multiple points share identical $(\hat{x}, \hat{y})$ and identical $z$ (coinciding coordinates after rotation, quantization, and panning), compute the pixel value as the average of the color values of all such points [S1].
4. **Repeat for Distorted Cloud**: Perform steps 2 and 3 for the distorted point cloud to generate `Image_dist`, using the same panning shift $(\Delta x, \Delta y)$ [S1].

**Pseudocode:**
```python
def project_point_cloud(points, width, height, pan_x, pan_y, default_color=(127, 127, 127)):
    # Initialize image buffer with default color
    image = [[default_color for _ in range(height)] for _ in range(width)]
    
    # Group points by quantized pixel coordinates (x_hat, y_hat)
    pixel_groups = {}
    for point in points:
        x, y, z, r, g, b = point
        x_hat = round(x) + pan_x
        y_hat = round(y) + pan_y
        
        # Check bounds
        if 0 <= x_hat < width and 0 <= y_hat < height:
            if (x_hat, y_hat) not in pixel_groups:
                pixel_groups[(x_hat, y_hat)] = []
            pixel_groups[(x_hat, y_hat)].append((z, r, g, b))
    
    # Resolve depth and average colors for each pixel
    for (x_hat, y_hat), group in pixel_groups.items():
        # Find minimum z (closest to projection plane)
        min_z = min(p[0] for p in group)
        # Get all points with the minimum z
        closest_points = [p for p in group if p[0] == min_z]
        # Average colors of closest points
        avg_r = sum(p[1] for p in closest_points) / len(closest_points)
        avg_g = sum(p[2] for p in closest_points) / len(closest_points)
        avg_b = sum(p[3] for p in closest_points) / len(closest_points)
        
        # Round to integer RGB and assign to image
        image[x_hat][y_hat] = (round(avg_r), round(avg_g), round(avg_b))
        
    return image

def render_pair(ref_points, dist_points, width, height, pan_x, pan_y):
    ref_image = project_point_cloud(ref_points, width, height, pan_x, pan_y)
    dist_image = project_point_cloud(dist_points, width, height, pan_x, pan_y)
    return ref_image, dist_image
```

**Parameters:**
- Panning shift $(\Delta x, \Delta y)$: User-defined integer offset applied to $x$ and $y$ coordinates, issued simultaneously on reference and distorted contents [S1].
- Default pixel color: $(127, 127, 127)$ in RGB space, representing neutral gray [S1].

**Edge Cases and Pitfalls:**
- Multiple points sharing identical $(x, y)$ but different $z$: Resolved by depth comparison, keeping the point with the smaller distance to the projection plane [S1].
- Multiple points sharing identical $(x, y, z)$ after transformations: Resolved by averaging their color values for the target pixel [S1].

## Subtopics

### [Orthographic Voxelization and Projection](18550-orthographic-voxelization-and-projection.md)
Converts 3D point clouds into a discrete voxel grid and projects them onto 2D planes using orthographic projection to enable objective quality assessment via standard 2D metrics. Unlike this method, it exploits the one-to-one correspondence between visible voxels and pixels along principal axes, eliminating the need for interpolation or post-processing. Choose it when perceptual quality assessment requires bridging 3D geometric data with established 2D image quality metrics.

### [Surfel Rendering with Depth Shading and Soft Shadows](21584-surfel-rendering-with-depth-shading-and-soft-shadows.md)
Renders a 3D point cloud as 2D surfels using per-point sprites, applies depth-based color shading, and composites a soft projected floor shadow. It builds on this method by adding explicit shadow compositing and depth-aware sprite scaling, distinguishing itself through perspective-scaled soft shadows and continuous depth shading rather than hard voxel boundaries. Choose it when visual grounding and soft shadows are required without altering point locations or semantic colors.

## Background
Originating from the methodology for quality assessment of voxelized point clouds, this technique was developed to facilitate simultaneous visualization of reference and distorted point clouds from the same angle [S1]. It leverages a preprocessing workflow including voxelization, scaling, translation, and encoding to prepare content for comparison [S1]. The method is used in experiments involving diverse static contents such as human bodies and inanimate objects with varying levels of geometry and color details [S1].
