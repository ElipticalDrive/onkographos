# Point Cloud Voxelization with Adjacency Cleanup

Also called: Open3DUE5Module::VoxelizedArrFromPoints with Cleanup, Point Cloud 3D Reconstruction with DEFTET

## Overview
This method converts a set of 3D points into a fixed-size voxel grid by assigning each point to a discrete voxel based on its coordinates and a specified voxel size, then removes isolated, non-connected voxels to clean up noise [S2, unofficial]. It builds on [Hard Voxelization (Deterministic)](3321-hard-voxelization-deterministic.md) by adding a topological cleanup phase [S2, unofficial].

## How it works
**Inputs:**
- `Points`: Array of 3D coordinates.
- `Transform`: Transformation matrix applied to points.
- `bSubtractive`: Boolean flag; if true, inverts `Settings.DistanceDivisor` by multiplying it by -1 to handle subtractive voxelization [S2, unofficial].
- `Settings`: Configuration object containing `VoxelSize` (double/float) and `DistanceDivisor` [S2, unofficial].

**Outputs:**
- `Asset`: A voxel data asset containing the final grid, position offset, and subtractive flag [S2, unofficial].
- Return value: Boolean indicating success or failure [S2, unofficial].

**Data Structures:**
- `Data`: 3D array (grid) accessed via `SetValue(X, Y, Z, value)` and `GetValue(X, Y, Z, value)`, with size managed by `SetSize(FIntVector, bool)` [S2, unofficial].
- `FVoxelValue`: Enum with states `Empty()`, `Full()`, and `Special()` [S2, unofficial].
- `VoxelFilledArr`: Array of integer coordinates `(X, Y, Z)` representing occupied voxels returned by the core voxelization module [S2, unofficial].
- `RealSize`: 3D integer vector defining the dimensions of the output grid [S2, unofficial].
- `OutOffset`: 3D integer vector representing the minimum coordinate offset of the grid in world space [S2, unofficial].

**Steps:**
1. **Validation**: If `Points` is empty, return `false` [S2, unofficial].
2. **Subtractive Adjustment**: If `bSubtractive` is true, multiply `Settings.DistanceDivisor` by -1 [S2, unofficial].
3. **Transformation**: Transform each point in `Points` using `Transform.TransformPosition` and store the results in `RealPoints` [S2, unofficial].
4. **Core Voxelization**: Call `FOpen3DUE5Module::VoxelizedArrFromPoints(RealPoints, (double)Settings.VoxelSize, VoxelFilledArr, RealSize)` to compute occupied voxel indices and grid dimensions [S2, unofficial].
5. **Bounding Box Calculation**: Iterate over `RealPoints`, subtract the transformed zero point, and accumulate the minimum and maximum coordinates into `Box` [S2, unofficial].
6. **Constraint Check**: If `RealSize.X * RealSize.Y * RealSize.Z >= 2147483647` or equals 0, return an error [S2, unofficial].
7. **Offset Calculation**: Compute `OutOffset = int(round(Box.Min / Settings.VoxelSize))` [S2, unofficial].
8. **Initialization**: Initialize `Data` with size `RealSize` [S2, unofficial].
9. **Clear Grid**: Loop over all X, Y, Z in `RealSize` and set each voxel to `FVoxelValue::Empty()` [S2, unofficial].
10. **Mark Voxels**: Loop over `VoxelFilledArr`. For each coordinate `AVoxelLocation`, if it is within bounds `[0, RealSize)`, set `Data->SetValue(AVoxelLocation.X, AVoxelLocation.Y, AVoxelLocation.Z, FVoxelValue::Full())` [S2, unofficial]. If out of bounds, log a warning but proceed, risking out-of-bounds access [S2, unofficial].
11. **Cleanup**: Call `CleanUpAloneVoxels(Data, 2)` to remove isolated voxels [S2, unofficial].
12. **Asset Creation**: Create `UVoxelDataAsset`, set `bSubtractiveAsset = bSubtractive`, set `PositionOffset = OutOffset`, attach `Data`, and return `true` [S2, unofficial].

**Pseudocode:**
```python
import math
from enum import Enum

class FVoxelValue(Enum):
    Empty = 0
    Full = 1
    Special = 2

class VoxelGrid:
    def __init__(self, size_x, size_y, size_z):
        self.size = (size_x, size_y, size_z)
        self.data = [[[FVoxelValue.Empty for _ in range(size_z)] for _ in range(size_y)] for _ in range(size_x)]
    def SetValue(self, x, y, z, val):
        self.data[x][y][z] = val
    def GetValue(self, x, y, z, default=FVoxelValue.Special()):
        if 0 <= x < self.size[0] and 0 <= y < self.size[1] and 0 <= z < self.size[2]:
            return self.data[x][y][z]
        return default
    def GetSize(self):
        return self.size

class Transform:
    def TransformPosition(self, p): return p

class Settings:
    def __init__(self):
        self.DistanceDivisor = 1.0
        self.VoxelSize = 1.0

class VoxelDataAsset:
    pass

def voxelized_arr_from_points(points, voxel_size):
    # Not given in the sources: exact discretization logic for core voxelization
    if not points: return [], (0, 0, 0)
    xs = [int(math.floor(p[0] / voxel_size)) for p in points]
    ys = [int(math.floor(p[1] / voxel_size)) for p in points]
    zs = [int(math.floor(p[2] / voxel_size)) for p in points]
    arr = list(set(zip(xs, ys, zs)))
    size = (max(xs) + 1, max(ys) + 1, max(zs) + 1)
    return arr, size

def point_cloud_voxelization_with_cleanup(Points, Transform, bSubtractive, Settings):
    if not Points:
        return False, None

    distance_divisor = Settings.DistanceDivisor
    if bSubtractive:
        distance_divisor *= -1

    RealPoints = [Transform.TransformPosition(p) for p in Points]

    VoxelFilledArr, RealSize = voxelized_arr_from_points(RealPoints, Settings.VoxelSize)

    BoxMin = (float('inf'), float('inf'), float('inf'))
    BoxMax = (float('-inf'), float('-inf'), float('-inf'))
    for p in RealPoints:
        p_local = (p[0], p[1], p[2])
        BoxMin = tuple(min(a, b) for a, b in zip(BoxMin, p_local))
        BoxMax = tuple(max(a, b) for a, b in zip(BoxMax, p_local))

    if RealSize[0] * RealSize[1] * RealSize[2] >= 2147483647 or RealSize[0] * RealSize[1] * RealSize[2] == 0:
        return False, None

    OutOffset = (int(round(BoxMin[0] / Settings.VoxelSize)),
                 int(round(BoxMin[1] / Settings.VoxelSize)),
                 int(round(BoxMin[2] / Settings.VoxelSize)))

    Data = VoxelGrid(RealSize[0], RealSize[1], RealSize[2])

    for x in range(RealSize[0]):
        for y in range(RealSize[1]):
            for z in range(RealSize[2]):
                Data.SetValue(x, y, z, FVoxelValue.Empty)

    for loc in VoxelFilledArr:
        if 0 <= loc[0] < RealSize[0] and 0 <= loc[1] < RealSize[1] and 0 <= loc[2] < RealSize[2]:
            Data.SetValue(loc[0], loc[1], loc[2], FVoxelValue.Full)
        else:
            print(f"Warning: Voxel location out of bounds: {loc}")

    clean_up_alone_voxels(Data, 2)

    Asset = VoxelDataAsset()
    Asset.bSubtractiveAsset = bSubtractive
    Asset.PositionOffset = OutOffset
    Asset.Data = Data
    return True, Asset

def voxel_surrounded_check(Data, X, Y, Z):
    count = 1
    for i in range(-1, 2):
        for j in range(-1, 2):
            for k in range(-1, 2):
                # Source code bug: uses Y+k and Z+k. Fixed to Y+j, Z+k for correct 3D neighbor check.
                if Data.GetValue(X + i, Y + j, Z + k) == FVoxelValue.Full:
                    count += 1
    return count > 5

def clean_up_alone_voxels(Data, IterNum):
    ToRemove = []
    for _ in range(IterNum):
        ToRemove = []
        for x in range(Data.GetSize()[0]):
            for y in range(Data.GetSize()[1]):
                for z in range(Data.GetSize()[2]):
                    if not voxel_surrounded_check(Data, x, y, z):
                        ToRemove.append((x, y, z))
        for coord in ToRemove:
            Data.SetValue(coord[0], coord[1], coord[2], FVoxelValue.Empty)
```

**Parameters:**
- `IterNum`: Integer specifying the number of cleanup passes. Hardcoded to 2 in the main call [S2, unofficial].
- `Settings.VoxelSize`: Double/float value defining the physical size of each voxel [S2, unofficial].

**Edge Cases and Pitfalls:**
- **Out-of-Bounds Access**: If `VoxelFilledArr` contains indices outside `[0, RealSize)`, the code logs a warning but proceeds to call `Data->SetValue`, risking out-of-bounds memory access [S2, unofficial].
- **Grid Size Limits**: Grid dimensions exceeding `MAX_int32` (2,147,483,647) or resulting in zero volume abort the process with an error [S2, unofficial].
- **Neighbor Check Bug**: The source code for `VoxelSurroundedCheck` uses `Data->GetValue(X + i, Y + k, Z + k)`, indexing Y and Z with the same loop variable `k` [S2, unofficial]. This is a typo in the source; the pseudocode corrects it to `Y + j, Z + k` for a proper 3D neighbor check.

## Background
This method is implemented in the `PointCloudVoxelizerBase` class within the Unreal Engine 5 Open3D plugin ecosystem, specifically in the `PointCloudToVoxelTest` repository [S2, unofficial]. It leverages the `FOpen3DUE5Module` for the core voxelization step and custom C++ utilities for the cleanup phase [S2, unofficial].
