# Probabilistic Voxel Representation

Also called: OpenVox, OpenVox Probabilistic Voxel Representation

## Overview
Probabilistic Voxel Representation is a real-time, instance-level open-vocabulary mapping method that enhances robustness in incremental 3D reconstruction by modeling voxel occupancy and semantic identity through probabilistic distributions [S1]. Unlike deterministic hard-voxel approaches that suffer from compounding errors due to segmentation inaccuracies, this method uses Maximum Likelihood Estimation (MLE) for instance association and Maximum A Posteriori (MAP) estimation for map evolution, allowing it to handle under-segmentation and poor viewing angles gracefully [S1]. It builds on [Probabilistic Raytracing Occupancy Update](12215-probabilistic-raytracing-occupancy-update.md) by extending probabilistic modeling from binary occupancy to multi-instance semantic vectors and codebook features [G].

## How it works
The method operates in a loop of **Instance Association** and **Live Map Evolution** for each incoming frame observation $Q_t = \{ \{m_{ti}, f_{ti}\}, D_t, P_t \}$, where $m_{ti}$ is a 2D instance mask, $f_{ti}$ is its feature embedding, $D_t$ is the depth image, and $P_t$ is the camera pose [S1].

### Inputs and Outputs
*   **Inputs**: Current frame masks $\{m_{ti}\}$, mask features $\{f_{ti}\}$, depth map $D_t$, camera pose $P_t$, camera intrinsics $K$, and existing map $M_{t-1} = \{V_{t-1}, B_{t-1}\}$ [S1].
*   **Outputs**: Updated map $M_t = \{V_t, B_t\}$ and instance assignments $I_t$ [S1].

### Data Structures
1.  **Voxel Map $V$**: A 3D grid with resolution $0.04\text{m}$ [S1]. Each voxel $v_j$ stores a probabilistic instance ID vector $\theta_j = \{ \theta_{j,\gamma} \mid \gamma \in \Gamma \}$, where $\Gamma$ is the set of known instance IDs [S1].
    *   $\theta_{j,\gamma} > 0$ and $\sum_{\gamma \in \Gamma} \theta_{j,\gamma} = 1$ [S1].
    *   $\theta_{j,\gamma}$ represents the probability that voxel $v_j$ belongs to instance $\gamma$ [S1].
2.  **Embedding Codebook $B$**: Associates each instance ID $\gamma$ with a fused caption feature vector $f_\gamma$ and a cumulative weight $W_\gamma$ [S1].

### Parameters
*   **Voxel Resolution**: $0.04\text{m}$ [S1].
*   **Similarity Threshold**: Fixed threshold for association validity (exact value not specified in sources) [S1].
*   **Prior Probability**: Assumed uniform across all existing instances $\Gamma_{t-1}$ for MLE [S1].

### Algorithm Steps

1.  **Voxel Region Projection**:
    For each mask $m_{ti}$ with pixel coordinates $[u, v]$, project the mask into the voxel map using depth $D_t$ and camera intrinsics $K$:
    $$ V_{m_{ti}} = \text{Vox}( D_t[u,v] \cdot P_t \cdot K^{-1} \cdot [u, v]^T \mid [u, v] \in m_{ti} ) $$
    where $\text{Vox}(\cdot)$ transforms 3D points to voxel indices [S1].

2.  **Instance Association**:
    *   **Unobserved Region**: If $V_{m_{ti}}$ contains no voxels with existing instance information, add a new instance ID $\gamma_{new}$ to $\Gamma_{t-1}$ and initialize its embedding in $B_{t-1}$ using $f_{ti}$ [S1].
    *   **Observed Region**: If $V_{m_{ti}}$ contains voxels with instance information, determine the best matching existing instance $\gamma \in \Gamma_{t-1}$:
        1.  **Geometric Similarity ($SI_{geo}$)**: Compute the average likelihood probability of the voxels in $V_{m_{ti}}$ for instance $\gamma$. To avoid numerical underflow from multiplying probabilities, use the law of large numbers by averaging:
            $$ SI_{geo}^{i=\gamma} = \mathbb{E}(\{ \theta_{m_i}^j [\gamma] \}) = \frac{1}{|V_{m_{ti}}|} \sum_{v_j \in V_{m_{ti}}} \theta_{j,\gamma} $$
            where $\theta_{j,\gamma}$ is the probability of voxel $v_j$ belonging to instance $\gamma$ from the previous map [S1].
        2.  **Feature Similarity ($SI_{fea}$)**: Compute the cosine similarity between the mask feature $f_{ti}$ and the codebook feature $f_\gamma$ of instance $\gamma$ [S1].
        3.  **Association Probability ($A$)**: Fuse the similarities via weighted fusion (specific weights not provided in sources) [S1].
        4.  **Decision**: If $\max_{\gamma} (A_{I_{ti}=\gamma})$ exceeds the similarity threshold, associate $m_{ti}$ with the corresponding instance ID $I_{ti}$. Otherwise, initialize a new instance [S1].

3.  **Live Map Evolution (Voxel Update)**:
    Update the probabilistic instance vector $\theta_j$ for each voxel $v_j \in V_{m_{ti}}$ using MAP estimation with a Dirichlet conjugate prior [S1].
    *   Let $\alpha_{t-1, j, \gamma}$ be the prior parameter for voxel $v_j$ and instance $\gamma$ [S1].
    *   Let $y_{tj, \gamma}$ be a one-hot encoded measurement tuple indicating the association of the current frame's instance $I_{ti}$ to instance $\gamma$ (i.e., $y_{tj, I_{ti}} = 1$, others $0$) [S1].
    *   Update the parameter $\alpha$:
        $$ \alpha_{t, j, \gamma} = \alpha_{t-1, j, \gamma} + y_{tj, \gamma} $$
    *   Compute the new probabilistic instance vector $\theta_{t, j}$ as the expected value of the posterior Dirichlet distribution:
        $$ \theta_{t, j, \gamma} = \frac{\alpha_{t, j, \gamma}}{\sum_{\tau \in \Gamma} \alpha_{t, j, \tau}} $$
        This model is referred to as the "instance counting sensor model" [S1].

4.  **Live Map Evolution (Codebook Update)**:
    Update the embedding codebook $B$ for the associated instance $I_{ti}$ [S1].
    *   **Visibility Ratio ($R_{ti}$)**: Calculate the proportion of the instance's size observed by the current mask relative to the total instance size. This prevents contamination from poor viewing angles (e.g., only a corner visible) [S1].
    *   **Credibility Weight ($w_{ti}$)**:
        $$ w_{ti} = A_{I_{ti}} \cdot R_{ti} $$
        where $A_{I_{ti}}$ is the association probability for the chosen instance [S1].
    *   **Weight Update**:
        $$ W_{t}^{I_{ti}} = W_{t-1}^{I_{ti}} + w_{ti} $$
    *   **Feature Update**:
        $$ f_{t}^{I_{ti}} = \frac{W_{t-1}^{I_{ti}} f_{t-1}^{I_{ti}} + w_{ti} f_{ti}}{W_{t}^{I_{ti}}} $$
        For instances not associated with the current mask, $W$ and $f$ remain unchanged [S1].

### Pseudocode

```python
import math
from typing import List, Dict, Tuple, Set, Any

def probabilistic_voxel_representation_step(
    frame_masks: List[List[Tuple[int, int]]],
    frame_features: List[List[float]],
    depth_map: List[List[float]],
    camera_pose: List[List[float]],
    camera_intrinsics: List[List[float]],
    existing_map: Tuple[List[Dict[str, float]], Dict[str, Tuple[List[float], float]], Set[str], Dict[Tuple[int, str], float]],
    resolution: float = 0.04,
    similarity_threshold: float = 0.5
) -> Tuple[List[Dict[str, float]], Dict[str, Tuple[List[float], float]], Set[str], Dict[Tuple[int, str], float]]:
    """
    Performs one step of probabilistic voxel mapping.
    Args:
        frame_masks: List of 2D masks, each mask is a list of (u, v) pixel coordinates.
        frame_features: List of feature vectors f_ti corresponding to masks.
        depth_map: Depth image D_t as 2D list.
        camera_pose: Camera pose P_t as 4x4 matrix.
        camera_intrinsics: Camera intrinsics K as 3x3 matrix.
        existing_map: Tuple (V, B, Gamma, alpha)
            V: List of voxels, each voxel is a dict mapping instance_id -> theta probability.
            B: Dict mapping instance_id -> (feature_vector, weight).
            Gamma: Set of existing instance IDs.
            alpha: Dict mapping (voxel_idx, instance_id) -> alpha_param.
        resolution: Voxel grid resolution in meters.
        similarity_threshold: Threshold for association decision.
    Returns:
        updated_map: Tuple (V, B, Gamma, alpha)
    """
    V, B, Gamma, alpha = existing_map
    # Deep copy structures to avoid in-place mutation during read
    new_V = [dict(v) for v in V]
    new_B = {k: (list(f), w) for k, (f, w) in B.items()}
    new_Gamma = set(Gamma)
    new_alpha = dict(alpha)

    for i, (mask, feature) in enumerate(zip(frame_masks, frame_features)):
        # 1. Project mask to voxel region
        voxel_indices_in_mask = []
        for u, v in mask:
            d = depth_map[v][u]
            if d is None or d <= 0:
                continue
            point_3d = _project_pixel_to_world(u, v, d, camera_intrinsics, camera_pose)
            voxel_idx = _voxelize_point(point_3d, resolution)
            voxel_indices_in_mask.append(voxel_idx)

        if not voxel_indices_in_mask:
            continue

        # 2. Instance Association
        is_unobserved = True
        for v_idx in voxel_indices_in_mask:
            if v_idx < len(new_V) and any(g in new_V[v_idx] for g in Gamma):
                is_unobserved = False
                break

        if is_unobserved:
            new_instance_id = f"instance_{len(new_Gamma)}"
            new_Gamma.add(new_instance_id)
            new_B[new_instance_id] = (list(feature), 0.0)
            associated_instance_id = new_instance_id
        else:
            best_gamma = None
            best_score = -1.0

            for gamma in Gamma:
                # Geometric Similarity
                geo_sim = 0.0
                count = 0
                for v_idx in voxel_indices_in_mask:
                    if v_idx < len(new_V) and gamma in new_V[v_idx]:
                        geo_sim += new_V[v_idx][gamma]
                        count += 1
                geo_sim = geo_sim / count if count > 0 else 0.0

                # Feature Similarity
                if gamma in new_B:
                    feat_sim = _cosine_similarity(feature, new_B[gamma][0])
                else:
                    feat_sim = 0.0

                # Association Probability (Weighted Fusion)
                # Source mentions weighted fusion but does not specify weights [G]
                score = 0.5 * geo_sim + 0.5 * feat_sim

                if score > best_score:
                    best_score = score
                    best_gamma = gamma

            if best_score > similarity_threshold:
                associated_instance_id = best_gamma
            else:
                new_instance_id = f"instance_{len(new_Gamma)}"
                new_Gamma.add(new_instance_id)
                new_B[new_instance_id] = (list(feature), 0.0)
                associated_instance_id = new_instance_id

        # 3. Live Map Evolution: Voxel Update
        for v_idx in voxel_indices_in_mask:
            if v_idx >= len(new_V):
                continue

            # Initialize alpha for new instances if needed
            for gamma in new_Gamma:
                key = (v_idx, gamma)
                if key not in new_alpha:
                    new_alpha[key] = 0.0

            # Update alpha with one-hot measurement y_tj
            for gamma in new_Gamma:
                key = (v_idx, gamma)
                y_tj_gamma = 1.0 if gamma == associated_instance_id else 0.0
                new_alpha[key] = new_alpha[key] + y_tj_gamma

            # Recompute theta for this voxel
            total_alpha = sum(new_alpha.get((v_idx, g), 0.0) for g in new_Gamma)
            if total_alpha > 0:
                for gamma in new_Gamma:
                    key = (v_idx, gamma)
                    new_V[v_idx][gamma] = new_alpha[key] / total_alpha
            else:
                uniform_prob = 1.0 / len(new_Gamma) if new_Gamma else 0.0
                for gamma in new_Gamma:
                    new_V[v_idx][gamma] = uniform_prob

        # 4. Live Map Evolution: Codebook Update
        if associated_instance_id in new_B:
            # Visibility Ratio R_ti
            # Source: proportion of instance's size observed. Implementation detail not specified [G]
            R_ti = _estimate_visibility_ratio(associated_instance_id, voxel_indices_in_mask, new_V)

            # Credibility weight w_ti
            w_ti = best_score * R_ti

            # Update Weight
            current_feat, current_weight = new_B[associated_instance_id]
            new_weight = current_weight + w_ti

            # Update Feature
            new_feat = [(current_weight * current_feat[k] + w_ti * feature[k]) / new_weight for k in range(len(current_feat))]

            new_B[associated_instance_id] = (new_feat, new_weight)

    return (new_V, new_B, new_Gamma, new_alpha)

def _project_pixel_to_world(u: int, v: int, depth: float, K: List[List[float]], P: List[List[float]]) -> List[float]:
    # Standard pinhole projection inverse
    fx, fy = K[0][0], K[1][1]
    cx, cy = K[0][2], K[1][2]
    x_cam = (u - cx) / fx * depth
    y_cam = (v - cy) / fy * depth
    z_cam = depth
    X_cam = [x_cam, y_cam, z_cam, 1.0]
    X_world = [sum(P[r][c] * X_cam[c] for c in range(4)) for r in range(4)]
    return X_world[:3]

def _voxelize_point(point: List[float], resolution: float) -> int:
    # Simple linear hashing for voxel index
    return int((point[0] / resolution) + (point[1] / resolution) * 1000 + (point[2] / resolution) * 1000000)

def _cosine_similarity(v1: List[float], v2: List[float]) -> float:
    dot = sum(a * b for a, b in zip(v1, v2))
    norm1 = math.sqrt(sum(a * a for a in v1))
    norm2 = math.sqrt(sum(b * b for b in v2))
    return dot / (norm1 * norm2) if norm1 > 0 and norm2 > 0 else 0.0
```

### Edge Cases and Pitfalls
*   **Numerical Underflow**: Multiplying likelihood probabilities of independent voxels causes underflow. Mitigated by averaging likelihood probabilities (geometric similarity) [S1].
*   **Poor Viewing Contamination**: Features from partial views (e.g., only a corner visible) can corrupt the global codebook. Mitigated by weighting updates with the visibility ratio $R_{ti}$ [S1].
*   **Inaccurate Segmentation**: If the front-end segmentation is inaccurate or under-segmented, deterministic methods fail. Probabilistic modeling provides robustness by allowing soft associations [S1].

## Operating characteristics
*   **Time Complexity**: Depends on the number of voxels in the mask region and the number of instances in $\Gamma$. The MLE step iterates over all instances for each mask, and the voxel update iterates over all voxels in the mask region. Real-time performance is claimed on an RTX 4090 [S1].
*   **Memory Complexity**: Proportional to the number of voxels times the number of instances (for $\theta$ vectors) plus the size of the codebook. The voxel resolution of $0.04\text{m}$ balances precision and memory [S1].
*   **Strengths**: Robust to segmentation errors, handles open-vocabulary semantics via LLM captions, real-time capable [S1].
*   **Limitations**: Requires accurate depth and camera poses. Performance degrades if visibility ratio estimation is poor [S1].
*   **When to use**: Incremental mapping where robustness to segmentation errors is critical, and open-vocabulary semantic understanding is required [S1].
*   **When not to use**: Resource-constrained environments where memory for large instance vectors is prohibitive, or when high-precision geometric reconstruction is prioritized over semantic robustness [S1].

## Background
Probabilistic Voxel Representation, as implemented in OpenVox, addresses limitations of previous incremental mapping methods like ConceptGraphs, which are prone to compounding errors from inaccurate segmentation [S1]. The method leverages probabilistic modeling (Dirichlet priors) for instance association and fusion, inspired by semantic counting sensor models [S1]. It is implemented in PyTorch and tested on robotics platforms [S1].
