# Voxel Hashing and Mean Aggregation

Also called: Hash-based Voxelization, Scatter Mean Voxelization

## Overview
This method converts a set of 3D points into a sparse voxel grid by mapping points to unique voxel identifiers via hashing and aggregating features using mean scattering [S1, unofficial].

## How it works
**Inputs:**
- `points`: Tensor of shape $(N, 3)$ containing 3D coordinates.
- `batch_ids`: Tensor of shape $(N,)$ identifying point cloud batches.
- `voxel_size`: Scalar defining the physical size of a voxel.
- `bounding_boxes`: Tensor or list defining the spatial extent for voxelization.
- `feats`: Tensor of shape $(N, C)$ containing point features.
- `colors`: Optional tensor of shape $(N, 3)$ for RGB colors.
- `depth_conf`: Optional tensor of shape $(N,)$ for depth confidence values.

**Outputs:**
- `voxel_features`: Tensor of shape $(M, C)$, where $M$ is the number of unique voxels.
- `voxel_centers`: Tensor of shape $(M, 3)$ representing the center coordinates of each voxel.
- `voxel_indices`: Tensor of shape $(M, 3)$ containing the discrete grid indices for each voxel.
- `unique_hash`: Tensor of shape $(M,)$ containing unique hash identifiers.

**Data Structures:**
- `voxel_hash`: 1D integer tensor of shape $(N,)$ storing hash identifiers for each point.
- `inverse_id`: 1D integer tensor of shape $(N,)$ mapping each point to its unique voxel ID in `unique_hash` [S1, unofficial].
- `first_occurrence_indices`: 1D integer tensor of shape $(M,)$ storing the index in the original point array for the first point assigned to each unique voxel [G].

**Steps:**
1. **Compute Voxel Indices**: Calculate the discrete grid index for each point based on its coordinates, `voxel_size`, and `bounding_boxes`. Batch IDs are concatenated to ensure unique indices across batches [S1, unofficial].
2. **Hash Indices**: Map the 3D voxel indices to a 1D unique hash identifier using a hash function [S1, unofficial].
3. **Identify Unique Voxels**: Find the unique hash values and map each point to its corresponding unique voxel ID using `torch.unique` with `return_inverse=True` [S1, unofficial].
4. **Aggregate Features**: Scatter mean aggregation is performed along the point dimension using `inverse_id` as the scatter index for features, colors, and depth confidence [S1, unofficial].
5. **Compute Voxel Centers**: Calculate the center coordinates for each unique voxel, optionally using `depth_conf` for weighted averaging [S1, unofficial].
6. **Retrieve Representative Indices**: Find the first occurrence index for each unique voxel ID to retrieve representative voxel indices. Initialize a tensor with a large value, then use `scatter_reduce` with `reduce='amin'` on `inverse_id` using the original point indices. Finally, index into the voxel indices tensor [S1, unofficial].

**Parameters:**
- `cat_batch_ids`: Boolean, default `True`. If True, batch IDs are included in the voxel index calculation to ensure uniqueness across batches [S1, unofficial].
- `voxel_size`: Scalar. Not given in the sources.
- `bounding_boxes`: Defines the spatial range. Not given in the sources.

**Pseudocode:**
```python
import torch

def voxel_hashing_and_mean_aggregation(points, batch_ids, voxel_size, bounding_boxes, feats, colors=None, depth_conf=None):
    # Step 1: Compute voxel indices
    voxel_indices = get_vox_indices(points, batch_ids, voxel_size, bounding_boxes, shift=False, cat_batch_ids=True)
    
    # Step 2: Hash voxel indices
    voxel_hash = hash_voxel_indices(voxel_indices)
    
    # Step 3: Identify unique hashes and map points to unique voxel IDs
    unique_hash, inverse_id = torch.unique(voxel_hash, return_inverse=True)
    M = unique_hash.shape[0]
    
    # Step 4: Aggregate features using scatter mean
    voxel_features = torch.zeros((M, feats.shape[1]), dtype=feats.dtype, device=feats.device)
    scatter_indices = inverse_id.unsqueeze(1).expand(-1, feats.shape[1])
    voxel_features.scatter_reduce_(0, scatter_indices, feats, reduce='mean')
    
    voxel_colors = None
    if colors is not None:
        voxel_colors = torch.zeros((M, 3), dtype=colors.dtype, device=colors.device)
        voxel_colors.scatter_reduce_(0, inverse_id.unsqueeze(1).expand(-1, 3), colors, reduce='mean')
        
    voxel_depth_conf = None
    if depth_conf is not None:
        voxel_depth_conf = torch.zeros((M, 1), dtype=depth_conf.dtype, device=depth_conf.device)
        voxel_depth_conf.scatter_reduce_(0, inverse_id.unsqueeze(1), depth_conf, reduce='mean')
        
    # Step 5: Compute voxel centers
    voxel_centers = get_vox_centers_from_points(points, depth_conf, inverse_id, M)
    
    # Step 6: Retrieve representative voxel indices
    original_indices = torch.arange(points.shape[0], dtype=torch.long, device=points.device)
    min_original_indices_per_unique_id = torch.full((M,), float('inf'), dtype=torch.long, device=points.device)
    min_original_indices_per_unique_id.scatter_reduce_(0, inverse_id, original_indices, reduce='amin')
    
    voxel_indices = voxel_indices[min_original_indices_per_unique_id]
    
    return voxel_features, voxel_centers, voxel_indices, unique_hash

def get_vox_indices(points, batch_ids, voxel_size, bounding_boxes, shift=False, cat_batch_ids=True):
    # [G] Standard voxel index computation
    min_coord = bounding_boxes[0]
    max_coord = bounding_boxes[1]
    coords = points - min_coord if shift else points
    indices = (coords / voxel_size).long()
    indices = torch.clamp(indices, 0, ((max_coord - min_coord) / voxel_size).long())
    if cat_batch_ids:
        # Offset indices per batch to ensure uniqueness
        batch_counts = torch.bincount(batch_ids, minlength=torch.max(batch_ids) + 1)
        batch_offsets = torch.zeros_like(batch_ids)
        batch_offsets[1:] = torch.cumsum(batch_counts[:-1], dim=0)
        indices = indices + batch_offsets.unsqueeze(1)
    return indices

def hash_voxel_indices(voxel_indices):
    # [G] Deterministic linearization of 3D indices to 1D hash
    return voxel_indices[:, 0] * 1000000 + voxel_indices[:, 1] * 1000 + voxel_indices[:, 2]

def get_vox_centers_from_points(points, depth_conf, inverse_id, num_voxels):
    # [G] Compute voxel centers, optionally weighted by depth_conf
    voxel_centers = torch.zeros((num_voxels, 3), dtype=points.dtype, device=points.device)
    if depth_conf is not None:
        weights = depth_conf.unsqueeze(1)
        voxel_centers.scatter_add_(0, inverse_id.unsqueeze(1).expand(-1, 3), points * weights)
        voxel_weights = torch.zeros((num_voxels, 1), dtype=points.dtype, device=points.device)
        voxel_weights.scatter_add_(0, inverse_id.unsqueeze(1), weights)
        voxel_centers = voxel_centers / voxel_weights.clamp(min=1e-6)
    else:
        voxel_centers.scatter_add_(0, inverse_id.unsqueeze(1).expand(-1, 3), points)
        voxel_counts = torch.zeros((num_voxels, 1), dtype=points.dtype, device=points.device)
        voxel_counts.scatter_add_(0, inverse_id.unsqueeze(1), torch.ones_like(inverse_id).unsqueeze(1).float())
        voxel_centers = voxel_centers / voxel_counts.clamp(min=1)
    return voxel_centers
```
