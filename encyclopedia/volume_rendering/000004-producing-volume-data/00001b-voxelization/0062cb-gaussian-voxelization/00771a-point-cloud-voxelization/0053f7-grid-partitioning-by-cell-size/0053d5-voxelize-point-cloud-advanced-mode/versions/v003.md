# Voxelize Point Cloud (Advanced Mode)
Also called: Advanced partitioning mode
## Overview
Voxelize Point Cloud (Advanced Mode) is a voxelization method that maps a 3D point cloud to a regular grid using a user-defined cell length parameter [S1, unofficial]. Unlike the Existing Image Geometry path, which rejects zero spacing with error -45983, Advanced Mode allows zero spacing, resulting in a silent failure where all points are skipped [S1, unofficial].

## How it works
**Inputs:**
*   Point cloud geometry (e.g., `VertexGeom`) [S1, unofficial].
*   Cell length parameter $s$ [S1, unofficial].
*   Grid origin $o$ [S1, unofficial].
*   Grid dimensions $D_x, D_y, D_z$ [S1, unofficial].

**Outputs:**
*   A binary mask or data array associated with the grid geometry [S1, unofficial].
*   The tuple shape is $\{D_z, D_y, D_x\}$ [S1, unofficial].

**Data Structures:**
*   The output is an image geometry with dimensions $D_x, D_y, D_z$ [S1, unofficial].
*   The mask is a 1D array of tuples with shape $\{D_z, D_y, D_x\}$ [S1, unofficial].

**Steps:**
1.  **Validate Input:** Check if the cell length $s$ is negative. `DataCheckCellLength` only rejects negative values [S1, unofficial].
2.  **Calculate Spacing:** Set spacing $s_{calc} = s$. If $s = 0$, $s_{calc} = 0$ [S1, unofficial].
3.  **Compute Inverse Spacing:** Calculate $s_{inv} = 1.0 / s_{calc}$. If $s_{calc} = 0$, $s_{inv}$ becomes $\infty$ or `NaN` [S1, unofficial].
4.  **Map Points to Voxels:** For each point $p = (p_x, p_y, p_z)$, calculate voxel coordinates $v_i = (p_i - o_i) \times s_{inv}$. If $s_{calc} = 0$, $v_i$ becomes $\infty$ or `NaN` [S1, unofficial].
5.  **Index and Clamp:** Convert $v_i$ to integer indices $(v_x, v_y, v_z)$ and clamp to grid bounds $[0, D_i-1]$. If $v_i$ is $\infty$ or `NaN`, the point is skipped [G].
6.  **Set Mask:** Set the corresponding voxel in the output mask to 1 (or relevant data) [G].
7.  **Finalize:** If all points were skipped (e.g., due to $s=0$), the output mask is all zeros. A warning is issued, but the filter completes successfully [S1, unofficial].

**Pseudocode:**
```python
import math

def voxelize_point_cloud_advanced(points, origin, cell_length, dimensions):
    """
    Voxelize point cloud using Advanced Mode.
    Args:
        points: List of 3D coordinates (x, y, z).
        origin: Tuple (ox, oy, oz) of grid origin.
        cell_length: Float cell length s.
        dimensions: Tuple (Dx, Dy, Dz) of grid dimensions.
    Returns:
        mask: 3D boolean array of shape (Dx, Dy, Dz).
        warning: String warning message if cell_length is 0.
    """
    if cell_length < 0:
        raise ValueError("Cell length must be non-negative.")
    
    spacing = cell_length
    inv_spacing = 1.0 / spacing if spacing != 0 else float('inf')
    
    if spacing == 0:
        warning = "Spacing is zero. All points will be skipped."
    else:
        warning = None
    
    mask = [[[False for _ in range(dimensions[2])] for _ in range(dimensions[1])] for _ in range(dimensions[0])]
    
    for p in points:
        vx = int(math.floor((p[0] - origin[0]) * inv_spacing))
        vy = int(math.floor((p[1] - origin[1]) * inv_spacing))
        vz = int(math.floor((p[2] - origin[2]) * inv_spacing))
        
        if math.isinf(vx) or math.isnan(vx) or \
           math.isinf(vy) or math.isnan(vy) or \
           math.isinf(vz) or math.isnan(vz):
            continue
            
        vx = max(0, min(vx, dimensions[0] - 1))
        vy = max(0, min(vy, dimensions[1] - 1))
        vz = max(0, min(vz, dimensions[2] - 1))
        
        mask[vx][vy][vz] = True
    return mask, warning
```

**Pitfalls:**
*   **Zero Spacing:** If $s=0$, the division $1.0/0$ results in infinity/NaN, causing all points to be skipped. The filter produces an all-zero mask and only a warning, unlike the Existing Partition Grid path which errors out [S1, unofficial].
*   **Negative Spacing:** Rejected by `DataCheckCellLength` [S1, unofficial].
*   **Origin/Spacing Mismatch:** A sign error on origin subtraction, a swapped inverse spacing component, or a units mistake can lead to incorrect voxel mapping [S1, unofficial].

## Subtopics

### Voxelize Point Cloud (Bounding Box Mode)
A voxelization mode that accepts min/max bounding box coordinates to determine grid extent [S1, unofficial]. If min equals max on any axis, the spacing becomes zero, causing all points to be skipped [S1, unofficial]. `DataCheckBoundingBoxCoords` only rejects min > max [S1, unofficial]. If min == max, spacing is 0, `CalculateImageVoxelMask` calculates `1.0f / 0 = inf`, causing coordinates to become inf or NaN, skipping all points [S1, unofficial]. The filter completes with an all-zero mask and only a warning [S1, unofficial].

## Background
This mode is part of the Voxelize Point Cloud filter family in the simplnx library [S1, unofficial]. The behavior regarding zero spacing was noted in code review discussions, highlighting a discrepancy with the Existing Partition Grid path [S1, unofficial].
