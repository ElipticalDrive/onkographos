# Smart Seed Preparation

Also called: Seed Region Classification, Texture T_EXp Generation

## Overview
Smart Seed Preparation generates a preparation texture ($T_{EXp}$) that classifies fragments of a mesh into specific seed regions (Core, Halo, Contact) to guide subsequent line search algorithms for vector field visualization [S1]. It differs from basic voxelization by encoding semantic region data and permeability factors directly into texture channels, allowing for seamless stroke generation that prevents merging [S1].

## How it works
**Inputs:**
- Mesh $M$ with geometry and normals.
- Vector field $\mathbf{k}$ defined on the mesh.
- Grid cell size $c_s$.
- View vector $\mathbf{v}$ and camera parameters.

**Outputs:**
- Preparation texture $T_{EXp}$ (RGB format).
  - Red channel ($R$): Stroke color/region ID.
  - Green channel ($G$): Permeability factor $\rho$.
  - Blue channel ($B$): Not specified in sources [G: assumed unused or depth].

**Data Structures:**
- $T_{EXp}$: 2D texture mapping screen-space fragments to mesh properties.

**Parameters:**
- $c_s$: Cell size, chosen dependent on field magnitude $F$ and mesh-to-camera distance [S1].
- $s_r$: Seed radius, set to $s_r = \frac{1}{4} c_s$ [S1].
- $\beta$: Contact region factor, set to $\beta = 1.8$ [S1].

**Steps:**
1. **Render Mesh:** Render mesh $M$ into $T_{EXp}$ using a fragment shader.
2. **Project Geometry:** For each fragment with 3D location $\mathbf{p}$ and normal $\mathbf{n}$:
   - Project $\mathbf{p}$ based on its normal to get projected point $\mathbf{p}_0$ [S1].
   - Project the normalized vector $\mathbf{k}(\mathbf{p})$ onto the corresponding grid cell face to yield normalized vector $\mathbf{k}_0(\mathbf{p})$ [S1].
   - Let $\mathbf{c}$ be the center of the grid cell face [S1].
3. **Trimming Validation:**
   - Calculate intermediate points:
     $$ \mathbf{q}_1 = \mathbf{c} + \frac{s_r \cdot \mathbf{k}_0(\mathbf{p})}{4} $$
     $$ \mathbf{q}_2 = \mathbf{c} - \frac{s_r \cdot \mathbf{k}_0(\mathbf{p})}{4} $$
   - Calculate dot products:
     $$ d_1 = \langle \mathbf{k}_0(\mathbf{p}), \mathbf{q}_1 - \mathbf{p}_0 \rangle $$
     $$ d_2 = \langle \mathbf{k}_0(\mathbf{p}), \mathbf{q}_2 - \mathbf{p}_0 \rangle $$
   - If $d_1$ and $d_2$ have the same sign, the fragment is invalid and discarded [S1].
4. **Modify Seed Radius:**
   - Calculate modified seed radius $s_{rm}$ for faces turning away from the viewer:
     $$ s_{rm} = s_r (2 - |\langle \mathbf{v}, \mathbf{n} \rangle|) $$
     where $\mathbf{v}$ is the view vector and $\mathbf{n}$ is the normal [S1].
5. **Classify Region:**
   - Calculate distance $d = \|\mathbf{p}_0 - \mathbf{c}\|$ [S1].
   - Classify region $C \in \{\text{Core}, \text{Halo}, \text{Contact}\}$ based on $d$ and $s_{rm}$ (or $s_r$ if not modified, though sources imply $s_{rm}$ is used for validity, classification boundaries use $s_r$):
     - **Core:** $d < \frac{1}{2} s_r$ [S1].
     - **Halo:** $\frac{1}{2} s_r \le d < s_r$ [S1].
     - **Contact:** $s_r \le d < \beta \cdot s_r$ [S1].
     - **Outside:** $d \ge \beta \cdot s_r$ [S1].
6. **Encode Channels:**
   - **Red Channel ($R$):**
     - Core: $R = 0$ [S1].
     - Halo: $R = 0.6$ (typical value) [S1].
     - Contact: $R = 1$ (background color, no stroke) [S1].
   - **Green Channel ($G$):** Permeability factor $\rho$.
     - Core/Halo: $\rho = 0$ [S1].
     - Contact:
       $$ \rho = \frac{\|\mathbf{p}_0 - \mathbf{c}\| - s_r}{s_r \cdot (\beta - s_r)} $$
       This creates a smooth gradient from the contact region edge to the halo edge [S1].
     - Outside: $\rho$ not explicitly defined, but $R=1$ implies no stroke [G].

**Edge Cases and Pitfalls:**
- **Invalid Fragments:** If $d_1$ and $d_2$ have the same sign, the fragment is discarded [S1].
- **Precision:** The gradient for $\rho$ in the Contact region requires careful handling near the boundaries to avoid division by zero or NaNs [G].
- **View Vector:** The modified seed radius $s_{rm}$ depends on the view vector, requiring consistent camera state [S1].

## Operating characteristics
- **Time Complexity:** Linear with respect to the number of fragments rendered [S1].
- **Memory Complexity:** Proportional to the resolution of $T_{EXp}$ [S1].
- **Strengths:** Prevents stroke merging via permeability factors; adapts to vector field direction via trimming [S1].
- **Limitations:** Requires rendering pass; dependent on camera position for $s_{rm}$ [S1].

## Background
Smart Seed Preparation was introduced in the Sline paper for seamless line illustration in biomedical visualization [S1]. It is part of a pipeline that includes line search and stroke generation [S1].
