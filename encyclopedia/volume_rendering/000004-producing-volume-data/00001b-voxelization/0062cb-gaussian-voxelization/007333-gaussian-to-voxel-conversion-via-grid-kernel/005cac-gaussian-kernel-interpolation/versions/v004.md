# Gaussian Kernel Interpolation

Also called: voxelize via Gaussian kernel interpolation

## Overview
Gaussian Kernel Interpolation (GKI) is a method to voxelize a point-cloud variable by interpolating values from scattered points to voxel centers using a Gaussian weight function based on distance [S1, unofficial]. It produces smoother results than Nearest Neighbor (NN) interpolation, as the scatter plot of NN versus GKI values deviates from the identity line [S1, unofficial].

## How it works
**Inputs and Outputs**
- **Input**: A point cloud dataset consisting of positions $P = \{p_1, \dots, p_N\}$ and associated scalar variables $V = \{v_1, \dots, v_N\}$, where $p_i \in \mathbb{R}^3$ and $v_i \in \mathbb{R}$ [S1, unofficial].
- **Input**: Voxel grid parameters: `shape` (dimensions in meters), `voxel_width` (side length of cubic voxels), `sigma` (kernel standard deviation), and `k` (number of nearest neighbors) [S1, unofficial].
- **Output**: A 3D voxel grid array `var_gki` of dimensions determined by `shape` and `voxel_width`, containing interpolated values at each voxel center [S1, unofficial].

**Data Structures**
- **Voxel Centers (`vxl`)**: A 2D array of shape $(M, 3)$, where $M$ is the total number of voxels [S1, unofficial]. Each row contains the $(x, y, z)$ coordinates of a voxel center [S1, unofficial].
- **KD-Tree**: A spatial index structure built from the input point cloud positions $P$ to enable efficient nearest-neighbor queries [S1, unofficial].

**Parameters**
- `voxel_width`: The side length of the cubic voxels. Typical value: 0.25 meters (25 cm) [S1, unofficial].
- `sigma`: The standard deviation of the Gaussian kernel. It is set to half the voxel width: $\sigma = \text{voxel\_width} / 2$ [S1, unofficial].
- `k`: The number of nearest neighbors queried from the KD-Tree for each voxel center. Typical value: 20 [S1, unofficial].

**Steps**
1. **Define Voxel Bounds**: Create linear spaces for each dimension from 0 to `shape[d]` with step `voxel_width` [S1, unofficial]. The number of intervals is $\lfloor \text{shape}[d] / \text{voxel\_width} \rfloor + 1$ [S1, unofficial].
2. **Calculate Voxel Centers**: For each dimension, compute the center of each interval by averaging adjacent bounds: $c_j = (b_{j} + b_{j-1}) / 2$ [S1, unofficial]. Use a 3D meshgrid to generate coordinate arrays $(vxc, vyc, vzc)$, then ravel them into a single list of 3D points `vxl` of shape $(M, 3)$ [S1, unofficial].
3. **Build KD-Tree**: Construct a KD-Tree from the input point cloud positions $P$ [S1, unofficial].
4. **Query Nearest Neighbors**: For each voxel center in `vxl`, query the KD-Tree for the $k$ nearest neighbors [S1, unofficial]. This returns distances $D \in \mathbb{R}^{M \times k}$ and indices $I \in \mathbb{Z}^{M \times k}$ [S1, unofficial].
5. **Compute Weights**: For each voxel $m$ and neighbor $n$, calculate the Gaussian weight:
   $$ w_{m,n} = \exp\left(-\frac{r_{m,n}^2}{2\sigma^2}\right) $$
   where $r_{m,n}$ is the distance from voxel $m$ to its $n$-th nearest neighbor [S1, unofficial].
6. **Retrieve Variable Values**: Using indices $I$, retrieve the variable values $V_{neighbors} \in \mathbb{R}^{M \times k}$ corresponding to the $k$ nearest neighbors for each voxel [S1, unofficial].
7. **Interpolate**: Compute the weighted sum for each voxel and normalize by the sum of weights:
   $$ V_{voxel, m} = \frac{\sum_{n=1}^{k} v_{m,n} w_{m,n}}{\sum_{n=1}^{k} w_{m,n}} $$
   [S1, unofficial].
8. **Reshape**: Reshape the resulting 1D array of interpolated values to match the 3D voxel grid dimensions $(N_x, N_y, N_z)$ [S1, unofficial].

**Pseudocode**
```python
import numpy as np
from scipy.spatial import cKDTree as kdtree

def gaussian_kernel_interpolation(pts, var, shape, voxel_width, k=20):
    # 1. Define Voxel Bounds
    vxb = np.linspace(0, shape[2], int(shape[2]/voxel_width)+1)
    vyb = np.linspace(0, shape[1], int(shape[1]/voxel_width)+1)
    vzb = np.linspace(0, shape[0], int(shape[0]/voxel_width)+1)

    # 2. Calculate Voxel Centers
    vyc, vzc, vxc = np.meshgrid(
        (vyb[1:] + vyb[:-1]) / 2,
        (vzb[1:] + vzb[:-1]) / 2,
        (vxb[1:] + vxb[:-1]) / 2
    )
    vxl = np.c_[vxc.ravel(), vyc.ravel(), vzc.ravel()]

    # 3. Build KD-Tree
    tree = kdtree(pts)

    # 4. Query Nearest Neighbors
    dd, ii = tree.query(vxl, k=k)

    # 5. Compute Weights
    sigma = voxel_width / 2
    wi = np.exp(-dd**2 / (2 * sigma**2))

    # 6. Retrieve Variable Values
    vi = var[ii]

    # 7. Interpolate
    numerator = np.sum(vi * wi, axis=1)
    denominator = np.sum(wi, axis=1)
    var_gki_flat = numerator / denominator

    # 8. Reshape
    var_gki = var_gki_flat.reshape(vzc.shape)

    return var_gki
```

**Edge Cases and Pitfalls**
- **Non-uniform Point Distribution**: Using a fixed number of nearest neighbors ($k$) instead of a spherical radius neighborhood means the neighbors might not form a sphere, potentially biasing the interpolation if the point distribution is non-uniform [S1, unofficial].

## Operating characteristics
- **Time Complexity**: Not given in the sources [S1, unofficial].
- **Memory Complexity**: Not given in the sources [S1, unofficial].
- **Measured Performance**: Not given in the sources [S1, unofficial].
- **Strengths**: Produces smoother results than Nearest Neighbor interpolation [S1, unofficial].
- **Limitations**: Sensitive to the choice of $k$ and $\sigma$ [S1, unofficial]. Biased by non-uniform point distributions when using fixed $k$ [S1, unofficial].
- **When to Use**: When smooth interpolation of scattered point data to a regular grid is required [S1, unofficial].
- **When Not to Use**: When point distribution is highly non-uniform and a fixed $k$ leads to significant bias [S1, unofficial].
