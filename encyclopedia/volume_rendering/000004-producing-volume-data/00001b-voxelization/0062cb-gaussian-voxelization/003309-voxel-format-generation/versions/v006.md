# Voxel Format Generation

Also called: Collision Mesh Generation, Splat Transform Voxelizer

## Overview
Voxel Format Generation converts 3D Gaussian Splats into a sparse voxel octree for collision detection, outputting metadata (`.voxel.json`) and binary data (`.voxel.bin`) [S1]. It optionally generates a watertight `.collision.glb` mesh using either marching cubes with lossless coplanar merge or direct voxel-boundary faces [S1]. It builds on [Gaussian Voxelization](8884-gaussian-voxelization.md) by adding semantic processing steps like cluster filtering, exterior sealing, and navigable space carving [S1].

## How it works
**Inputs and Outputs:**
*   **Input:** A Gaussian Splat file (PLY, SPLAT, KSPLAT, SOG) [S1].
*   **Outputs:** 
    *   `.voxel.json`: Metadata containing grid resolution, bounds, and voxel attributes [S1].
    *   `.voxel.bin`: Binary representation of the sparse voxel octree [S1].
    *   `.collision.glb` (optional): A mesh derived from the voxel grid [S1].

**Data Structures:**
The voxel grid is a sparse octree [S1]. The binary format stores the octree data [S1]. The JSON file stores `voxelResolution`, `opacityCutoff`, `bounds`, and `navCapsule` [S1].

**Steps:**
1.  **Filtering:** Run `--filter-cluster` with `--seed-pos` to isolate the central scene geometry and discard stray floaters [S1].
2.  **Voxelization:** Map the filtered Gaussians to the sparse voxel grid [S1]. Voxels with aggregated opacity below `opacityCutoff` are marked empty [S1].
3.  **Scene Sealing (Optional):**
    *   **Interior:** Use `--voxel-external-fill` to seal the void around the room interior [S1]. It verifies enclosure by checking if the `--seed-pos` is reachable from outside; if reachable, fill is skipped [S1].
    *   **Exterior:** Use `--voxel-floor-fill` to fill voxel columns upward from the bottom until hitting solid geometry [S1]. It identifies "interior" XZ columns by dilating solid columns by `floorFillDilation`; empty XZ areas larger than `2 * floorFillDilation` from any solid column are treated as exterior and filled [S1].
4.  **Navigation Carving (Optional):** Use `--voxel-carve` with `navCapsule` (height, radius) [S1]. Height `0` disables carve [S1].
5.  **Mesh Generation (Optional):** Use `--collision-mesh` to generate a mesh from the voxel data [S1].
    *   `smooth`: Uses marching cubes with lossless coplanar merge for smoother geometry [S1].
    *   `faces`: Generates direct watertight voxel-boundary faces [S1].

**Parameters:**
*   `voxelResolution`: Size of each voxel in world units. Default: `0.05` [S1].
*   `opacityCutoff`: Opacity threshold for solid voxels. Voxels below this are empty. Default: `0.1` [S1].
*   `navExteriorRadius`: Exterior fill radius in world units. Enables exterior fill. Requires `navSeed` [S1].
*   `floorFill`: Boolean to fill voxel columns upward from bottom until hitting solid. Runs before carve. Default: `false` [S1].
*   `floorFillDilation`: Dilation radius in world units to identify 'interior' XZ columns. Empty XZ areas larger than `2 * floorFillDilation` from any solid column are treated as exterior. Default: `0` [S1].
*   `navCapsule`: Object `{height, radius}` for carve dimensions. Height `0` disables carve. Requires `navSeed` [S1].
*   `--seed-pos <x,y,z>`: Seed position for voxel fill/carve and `--filter-cluster`. Default: `0,0,0` [S1].

**Pseudocode:**
```python
def generate_voxel_format(input_path, output_json_path, options):
    # 1. Load splats
    splats = load_splats_from_file(input_path)  # [G] standard file I/O for PLY/SPLAT/KSPLAT/SOG
    
    # 2. Filter cluster
    if options.get('filter_cluster'):
        seed = options['seed_pos']
        # [G] flood fill / connectivity check to isolate main cluster
        splats = filter_by_connectivity(splats, seed)
        
    # 3. Voxelize
    voxel_res = options.get('voxelResolution', 0.05)
    opacity_cutoff = options.get('opacityCutoff', 0.1)
    octree = {}  # sparse dict mapping (x,y,z) to voxel data
    
    for g in splats:
        # [G] compute bounding box of Gaussian support region
        min_c, max_c = compute_gaussian_bounds(g, voxel_res)
        for x in range(min_c[0], max_c[0]):
            for y in range(min_c[1], max_c[1]):
                for z in range(min_c[2], max_c[2]):
                    key = (x, y, z)
                    if key not in octree:
                        octree[key] = {'opacity': 0.0, 'color': [0.0, 0.0, 0.0]}
                    # Aggregate contribution based on Gaussian density
                    weight = gaussian_density(g, voxel_center(key, voxel_res))
                    octree[key]['opacity'] += g['opacity'] * weight
                    octree[key]['color'] += g['color'] * weight
                    
    # Threshold voxels
    for key in list(octree.keys()):
        if octree[key]['opacity'] < opacity_cutoff:
            del octree[key]
            
    # 4. Scene sealing
    if options.get('voxel_external_fill'):
        if is_seed_reachable_from_outside(octree, options['seed_pos'], voxel_res):
            pass  # Skip fill
        else:
            seal_external_void(octree, options['seed_pos'], voxel_res)  # [G] standard flood fill
            
    if options.get('voxel_floor_fill'):
        dilation = options.get('floorFillDilation', 0)
        fill_floor_columns(octree, dilation, voxel_res)  # [G] standard column scan & fill
        
    # 5. Navigation carving
    if options.get('voxel_carve'):
        capsule = options.get('navCapsule', {'height': 1.6, 'radius': 0.2})
        carve_navigable_space(octree, options['seed_pos'], capsule, voxel_res)  # [G] capsule flood fill
        
    # 6. Output
    meta = {
        'voxelResolution': voxel_res,
        'opacityCutoff': opacity_cutoff,
        'navCapsule': options.get('navCapsule')
    }
    write_json(output_json_path, meta)
    write_binary_octree(octree, output_json_path.replace('.json', '.bin'))
    
    if options.get('collision_mesh'):
        mesh_type = options['collision_mesh']
        if mesh_type == 'smooth':
            mesh = marching_cubes(octree)  # [G] standard algorithm with coplanar merge
        else:
            mesh = voxel_boundary_faces(octree)  # [G] standard voxel boundary extraction
        write_glb(mesh, output_json_path.replace('.json', '.collision.glb'))

def gaussian_density(g, center):
    # [G] Standard Gaussian density weight based on distance
    dist_sq = sum((g['mean'][i] - center[i])**2 for i in range(3))
    return math.exp(-dist_sq / (2 * g['variance']))

def voxel_center(key, voxel_res):
    # [G] Convert grid index to world coordinates
    return [key[i] * voxel_res for i in range(3)]
```

## Subtopics

### Splat Transform CLI
A command-line tool for converting between various splat formats (PLY, SPLAT, KSPLAT, SOG, HTML) and generating voxel/collision data [S1]. It provides the implementation for the Voxel Format Generation method [S1]. It supports advanced features like decimation, spherical harmonic filtering, and camera track rendering [S1]. The voxel generation is invoked via specific flags (`--voxel-external-fill`, `--voxel-carve`, etc.) within the CLI workflow [S1].

## Background
Originated from the `playcanvas/splat-transform` project [S1]. It addresses the need for interoperability between neural rendering formats and traditional game engine components like collision meshes [S1]. The method was developed to provide a robust pipeline for generating navigation and collision data from unstructured Gaussian splat clouds [S1].
