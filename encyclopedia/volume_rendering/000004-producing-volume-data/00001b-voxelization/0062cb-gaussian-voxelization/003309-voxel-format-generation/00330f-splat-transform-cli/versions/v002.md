# Splat Transform CLI

Also called: Splat Transform Voxelizer

## Overview
A command-line utility for converting between various Gaussian splat formats (PLY, SPLAT, KSPLAT, SOG, HTML) and generating voxel/collision data for downstream processing [S1]. It distinguishes itself from in-memory converters by supporting out-of-core processing pipelines for large datasets, ensuring scalability for scenes exceeding available system RAM [S1].

## How it works
**Inputs and Outputs:**
- **Inputs:** Source splat files (PLY, SPLAT, KSPLAT, SOG, HTML) and optional configuration parameters.
- **Outputs:** Converted splat formats, `.voxel.json` (metadata), `.voxel.bin` (binary voxel data), and optionally `.collision.glb` (mesh) [S1].

**Data Structures:**
- **Voxel Grid:** Defined by `--voxel-size` and `--voxel-opacity`. The grid resolution is determined by the scene bounds and voxel size. Opacity thresholds determine voxel inclusion [S1].
- **Collision Mesh:** Generated as a GLB file, optionally smoothed [S1].

**Parameters:**
- `--voxel-size <n>`: Voxel size for `.voxel.json` output. Default: `0.05` [S1].
- `--voxel-opacity <n>`: Voxel opacity threshold for `.voxel.json`. Default: `0.1` [S1].
- `--voxel-floor-fill [size]`: Fills columns upward from the bottom until hitting solid geometry for exterior scenes. Patches XZ areas surrounded by floor within `2*size`. Default size: `1.6` [S1].
- `--voxel-carve [h,r]`: Carves navigable space using capsule flood fill from the seed position. Default: height=`1.6`, radius=`0.2` [S1].
- `--seed-pos <x,y,z>`: Seed position for voxel fill/carve and `--filter-cluster`. Default: `0,0,0` [S1].
- `--collision-mesh [smooth|faces]`: Generates collision mesh (`.collision.glb`). Default: `smooth` [S1].

**Steps:**
1. **Input Parsing:** Read the source splat file and parse Gaussian parameters (position, covariance, opacity, spherical harmonics) [S1].
2. **Voxelization:** Project Gaussians onto a 3D grid. Determine voxel occupancy based on `--voxel-opacity` [S1].
3. **External Fill Logic:** Use `--seed-pos` to verify volume enclosure. If the seed position is reachable from outside the voxel volume, the fill operation is skipped [S1].
4. **Floor Fill (Optional):** If `--voxel-floor-fill` is specified, fill columns upward from the bottom of the grid until solid geometry is encountered, patching XZ areas surrounded by floor within `2*size` [S1].
5. **Carving (Optional):** If `--voxel-carve` is specified, perform a capsule flood fill from `--seed-pos` with the given height and radius to carve out navigable space [S1].
6. **Collision Mesh Generation (Optional):** If `--collision-mesh` is specified, generate a GLB mesh from the voxel data, optionally smoothing the surface [S1].
7. **Output:** Write `.voxel.json` and `.voxel.bin` [S1].

**Pseudocode:**
```python
def splat_transform_cli(input_file, output_dir, options):
    # Parse input file
    splats = load_splats(input_file)
    
    # Determine voxel grid parameters
    voxel_size = options.get('voxel_size', 0.05)
    voxel_opacity = options.get('voxel_opacity', 0.1)
    seed_pos = options.get('seed_pos', (0, 0, 0))
    
    # Create voxel grid
    voxel_grid = create_voxel_grid(splats, voxel_size, voxel_opacity)
    
    # External fill logic
    if options.get('external_fill_check', True):
        if is_reachable_from_outside(voxel_grid, seed_pos):
            # Skip fill if seed is reachable from outside
            pass
        else:
            # Perform fill
            voxel_grid = fill_voxels(voxel_grid, seed_pos)
    
    # Floor fill
    if options.get('voxel_floor_fill'):
        floor_fill_size = options.get('floor_fill_size', 1.6)
        voxel_grid = fill_floor_columns(voxel_grid, floor_fill_size)
    
    # Carving
    if options.get('voxel_carve'):
        carve_height = options.get('carve_height', 1.6)
        carve_radius = options.get('carve_radius', 0.2)
        voxel_grid = carve_navigable_space(voxel_grid, seed_pos, carve_height, carve_radius)
    
    # Collision mesh generation
    if options.get('collision_mesh'):
        mesh_type = options.get('collision_mesh_type', 'smooth')
        collision_mesh = generate_collision_mesh(voxel_grid, mesh_type)
        save_mesh(collision_mesh, join(output_dir, 'collision.glb'))
    
    # Save voxel data
    save_voxel_metadata(voxel_grid, join(output_dir, 'voxel.json'))
    save_voxel_data(voxel_grid, join(output_dir, 'voxel.bin'))
    
    # Convert to other formats if requested
    if options.get('convert_to'):
        for fmt in options['convert_to']:
            convert_splats(splats, fmt, join(output_dir, f'output.{fmt}'))
```

A file conversion pipeline that processes large PLY Gaussian splat files into tiled, chunked RAD LOD format using an out-of-core bucketed builder to avoid RAM exhaustion.
