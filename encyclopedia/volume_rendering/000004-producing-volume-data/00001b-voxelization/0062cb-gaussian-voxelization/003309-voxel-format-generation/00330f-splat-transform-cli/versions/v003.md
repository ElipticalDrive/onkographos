# Splat Transform CLI

Also called: Splat Transform Voxelizer

## Overview
A command-line utility for converting between various Gaussian splat formats (PLY, SPLAT, KSPLAT, SOG, HTML) and generating voxel/collision data for downstream processing [S1]. It focuses on format translation and spatial data generation rather than in-memory scene rendering [S1].

## How it works
**Inputs and Outputs:**
- **Inputs:** Source splat files (PLY, SPLAT, KSPLAT, SOG, HTML) and optional configuration parameters [S1].
- **Outputs:** Converted splat formats (CSV, compressed PLY, standalone/unbundled HTML), `.voxel.json` (metadata), `.voxel.bin` (binary voxel data), and optionally `.collision.glb` (mesh) [S1].

**Data Structures:**
- **Voxel Grid:** A 3D occupancy grid defined by `--voxel-size` and `--voxel-opacity`. Voxel inclusion is determined by the opacity threshold [S1].
- **Collision Mesh:** A GLB file representing navigable space, optionally smoothed [S1].

**Parameters:**
- `--voxel-size <n>`: Voxel size for `.voxel.json` output. Default: `0.05` [S1].
- `--voxel-opacity <n>`: Voxel opacity threshold for `.voxel.json`. Default: `0.1` [S1].
- `--voxel-floor-fill [size]`: Fills columns upward from the bottom until hitting solid geometry for exterior scenes. Patches XZ areas surrounded by floor within `2*size`. Default size: `1.6` [S1].
- `--voxel-carve [h,r]`: Carves navigable space using capsule flood fill from the seed position. Default: height=`1.6`, radius=`0.2` [S1].
- `--seed-pos <x,y,z>`: Seed position for voxel fill/carve and `--filter-cluster`. Default: `0,0,0` [S1].
- `--collision-mesh [smooth|faces]`: Generates collision mesh (`.collision.glb`). Default: `smooth` [S1].

**Steps:**
1. **Input Parsing:** Read the source splat file and extract format-specific data [S1].
2. **Voxelization:** Project splats onto a 3D grid. Determine voxel occupancy based on `--voxel-opacity` [S1].
3. **External Fill Logic:** Use `--seed-pos` to verify volume enclosure. If the seed position is reachable from outside the voxel volume, the fill operation is skipped [S1].
4. **Floor Fill (Optional):** If `--voxel-floor-fill` is specified, fill columns upward from the bottom of the grid until solid geometry is encountered, patching XZ areas surrounded by floor within `2*size` [S1].
5. **Carving (Optional):** If `--voxel-carve` is specified, perform a capsule flood fill from `--seed-pos` with the given height and radius to carve out navigable space [S1].
6. **Collision Mesh Generation (Optional):** If `--collision-mesh` is specified, generate a GLB mesh from the voxel data, optionally smoothing the surface [S1].
7. **Output:** Write `.voxel.json` and `.voxel.bin` [S1].

**Pseudocode:**
```python
def splat_transform_cli(input_file, output_dir, args):
    # 1. Parse input file
    splats = read_splat_file(input_file)  # [G] Standard parser for PLY/SPLAT/KSPLAT/SOG/HTML formats

    # 2. Extract parameters with defaults
    voxel_size = args.get('voxel_size', 0.05)
    voxel_opacity = args.get('voxel_opacity', 0.1)
    seed_pos = args.get('seed_pos', (0.0, 0.0, 0.0))
    floor_fill_size = args.get('voxel_floor_fill', 1.6)
    carve_h, carve_r = args.get('voxel_carve', (1.6, 0.2))
    collision_mode = args.get('collision_mesh', 'smooth')

    # 3. Voxelization: project splats onto 3D grid, filter by opacity threshold
    voxel_grid = {}
    for s in splats:
        grid_coords = (int(s.position.x / voxel_size), int(s.position.y / voxel_size), int(s.position.z / voxel_size))
        if s.opacity >= voxel_opacity:
            voxel_grid[grid_coords] = s

    # 4. External fill logic: verify volume enclosure
    boundary_cells = get_grid_boundary(voxel_grid)  # [G] Cells on the min/max extents of the grid
    reachable = flood_fill_from(boundary_cells, voxel_grid)  # [G] BFS/DFS traversal through occupied cells
    if seed_pos not in reachable:
        voxel_grid = flood_fill_from(seed_pos, voxel_grid)  # [G] Fill enclosed voids

    # 5. Floor fill (optional)
    if 'voxel_floor_fill' in args:
        for x, z in grid_xz_columns(voxel_grid):  # [G] Iterate over unique (x, z) coordinates
            min_y = min(y for y in grid_y_column(x, z, voxel_grid))
            fill_upward_from(voxel_grid, x, min_y, z, floor_fill_size)  # [G] Extend column upward until solid hit

    # 6. Carving (optional)
    if 'voxel_carve' in args:
        carve_region = capsule_flood_fill(seed_pos, carve_h, carve_r, voxel_grid)  # [G] Capsule-shaped traversal from seed
        voxel_grid = remove_cells(voxel_grid, carve_region)  # [G] Remove carved cells from grid

    # 7. Collision mesh generation (optional)
    if 'collision_mesh' in args:
        mesh = voxel_grid_to_mesh(voxel_grid, collision_mode)  # [G] Convert voxel occupancy to GLB mesh geometry
        save_file(output_dir + '/collision.glb', mesh)

    # 8. Output voxel data
    save_file(output_dir + '/voxel.json', voxel_grid.metadata)
    save_file(output_dir + '/voxel.bin', voxel_grid.binary_data)

    # 9. Format conversion (if requested)
    if 'convert_to' in args:
        for fmt in args['convert_to']:
            save_file(output_dir + '/output.' + fmt, convert_format(splats, fmt))  # [G] Standard format serializer
```
