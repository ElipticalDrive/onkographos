# 3DGS Voxelizer

Also called: 3DGS to OpenUSD PointInstancer Voxelizer

## Overview
The 3DGS Voxelizer converts a 3D Gaussian Splatting scan into colored voxel blocks represented as OpenUSD `PointInstancer` data, enabling visualization and physics collision in NVIDIA Omniverse [S1, unofficial]. It differs from general-purpose voxelizers by specifically handling 3DGS spherical harmonics decoding and SPZ binary formats, and by outputting a USD-native instancer rather than a dense volume texture [S1, unofficial].

## How it works
**Inputs and Outputs**
- Input: A 3DGS scan file in `.ply` (ASCII or binary) or `.spz` (gzip-compressed binary) format [S1, unofficial].
- Output: An OpenUSD stage containing a `PointInstancer` prim representing the voxelized scene [S1, unofficial].

**Data Structures**
The core intermediate representation is the `PointCloud` dataclass [S1, unofficial]:
- `positions`: `np.ndarray` of shape `(N, 3)`, dtype `float32` [S1, unofficial].
- `colors`: `np.ndarray` of shape `(N, 3)`, dtype `uint8` (optional) [S1, unofficial].
- `opacities`: `np.ndarray` of shape `(N,)`, dtype `float32` (optional, sigmoid-activated logits) [S1, unofficial].
- `is_3dgs`: `bool` indicating if the source is a 3DGS scan [S1, unofficial].

**Parameters**
- `resolution`: The physical size of each voxel block [S1, unofficial]. Smaller values increase detail and block count [S1, unofficial].
- `min_opacity`: Threshold to filter faint splats [S1, unofficial]. Only applicable for `.ply` files where opacities are sigmoid-activated logits [S1, unofficial].
- `density_threshold`: Minimum number of splats required to create a voxel [S1, unofficial]. Default is 1 [S1, unofficial].
- `unit_scale`: Handles unit mismatches (e.g., USD Composer uses centimeters, Isaac Sim uses meters) [S1, unofficial].

**Steps**
1. **Load Point Cloud**: Parse the input file into a `PointCloud` object [S1, unofficial].
2. **Voxelize**: Compute voxel centers and colors based on resolution, thresholds, and input data using vectorized numpy operations [S1, unofficial].
3. **Author USD**: Create a `PointInstancer` prim in the USD stage using the computed centers, colors, and resolution [S1, unofficial].

**Formulas**
- **Color Extraction (3DGS DC Spherical Harmonics)**:
  $$C = \text{clip}((0.5 + SH\_C0 \cdot dc) \cdot 255.0, 0, 255)$$
  where $SH\_C0 = 0.28209479177387814$ and $dc$ is the stacked DC coefficient vector [S1, unofficial].
- **Opacity Activation**:
  $$O = \frac{1}{1 + e^{-\text{opacity}}}$$
  where `opacity` is the sigmoid-activated logit from the 3DGS data [S1, unofficial].
- **SPZ Color Recovery**:
  $$f\_dc = \frac{dc\_u8 / 255.0 - 0.5}{\_SPZ\_COLOR\_SCALE}$$
  $$C = \text{clip}((0.5 + SH\_C0 \cdot f\_dc) \cdot 255.0, 0, 255)$$
  where $\_SPZ\_COLOR\_SCALE = 0.15$ [S1, unofficial].
- **SPZ Position Decoding**:
  $$pos = \frac{\text{vals}}{2^{frac\_bits}}$$
  where $\text{vals}$ is reconstructed from 3 bytes $b_0, b_1, b_2$ as $b_0 | (b_1 \ll 8) | (b_2 \ll 16)$, adjusted for signedness if $\ge 0x800000$ [S1, unofficial].

**Pseudocode**
```python
import numpy as np
import gzip
import struct
from dataclasses import dataclass
from typing import Tuple, Optional

SH_C0 = 0.28209479177387814
SPZ_COLOR_SCALE = 0.15

@dataclass
class PointCloud:
    positions: np.ndarray            # (N, 3) float32
    colors: Optional[np.ndarray]     # (N, 3) uint8
    opacities: Optional[np.ndarray]  # (N,) float32
    is_3dgs: bool = False

def load_pointcloud(filepath: str) -> PointCloud:
    """Load a .ply or .spz file into a PointCloud dataclass."""
    if filepath.endswith('.spz'):
        return _load_spz(filepath)
    elif filepath.endswith('.ply'):
        return _load_ply(filepath)
    else:
        raise ValueError(f"Unsupported file format: {filepath}")

def _load_spz(filepath: str) -> PointCloud:
    """Decode SPZ format."""
    with gzip.open(filepath, 'rb') as f:
        data = f.read()
    
    # Decode positions (24-bit fixed-point)
    num_points = len(data) // 9  # 3 components * 3 bytes
    positions = np.zeros((num_points, 3), dtype=np.float32)
    for i in range(num_points):
        for j in range(3):
            byte_offset = i * 9 + j * 3
            b0 = data[byte_offset]
            b1 = data[byte_offset + 1]
            b2 = data[byte_offset + 2]
            val = b0 | (b1 << 8) | (b2 << 16)
            if val >= 0x800000:
                val -= 0x1000000
            positions[i, j] = val / (2 ** 16)  # frac_bits not given in sources [G]
    
    # Decode colors (DC coefficients)
    colors_u8 = np.frombuffer(data, dtype=np.uint8, offset=num_points * 9).reshape(-1, 3)
    f_dc = (colors_u8.astype(np.float32) / 255.0 - 0.5) / SPZ_COLOR_SCALE
    colors = np.clip((0.5 + SH_C0 * f_dc) * 255.0, 0, 255).astype(np.uint8)
    
    return PointCloud(positions=positions, colors=colors, is_3dgs=True)

def _load_ply(filepath: str) -> PointCloud:
    """Load PLY format (ASCII or binary)."""
    with open(filepath, 'rb') as f:
        header_lines = []
        for _ in range(10000):  # Limit to prevent infinite loop on missing end_header [S1, unofficial]
            line = f.readline()
            if line.startswith(b'end_header'):
                break
            header_lines.append(line)
        
        # Not given in the sources: detailed PLY binary/ASCII parsing logic [G]
        # Standard implementation would parse header keywords to find element counts,
        # then read vertex arrays for positions, colors, and opacities.
        positions = np.zeros((0, 3), dtype=np.float32)
        colors = np.zeros((0, 3), dtype=np.uint8)
        opacities = np.zeros((0,), dtype=np.float32)
        
        return PointCloud(positions=positions, colors=colors, opacities=opacities, is_3dgs=True)

def voxelize(pc: PointCloud, resolution: float, min_opacity: float = 0.0, density_threshold: int = 1) -> Tuple[np.ndarray, np.ndarray]:
    """Voxelize a PointCloud into voxel centers and colors."""
    positions = pc.positions
    colors = pc.colors if pc.colors is not None else np.zeros((len(positions), 3), dtype=np.uint8)
    
    if pc.is_3dgs and pc.opacities is not None:
        opacities = 1.0 / (1.0 + np.exp(-pc.opacities))
        mask = opacities >= min_opacity
        positions = positions[mask]
        colors = colors[mask]
    
    # Compute voxel centers
    voxel_centers = np.floor(positions / resolution) * resolution
    
    # Aggregate by voxel center (vectorized)
    # Not given in the sources: exact aggregation logic for density_threshold [G]
    # Standard approach: np.unique(voxel_centers, axis=0, return_index=True) followed by
    # np.bincount or np.add.at for color/opacity accumulation, filtering by count >= density_threshold.
    unique_centers, indices = np.unique(voxel_centers, axis=0, return_index=True)
    counts = np.bincount(np.searchsorted(unique_centers, voxel_centers))
    valid_mask = counts >= density_threshold
    final_centers = unique_centers[valid_mask]
    final_colors = colors[indices][valid_mask]
    
    return final_centers, final_colors

def author_voxel_instancer(stage, centers: np.ndarray, colors: np.ndarray, resolution: float, unit_scale: float = 1.0) -> None:
    """Author a PointInstancer prim in the USD stage."""
    from pxr import UsdGeom, UsdPhysics, Vt
    
    # Create root Xform with unit scale
    root = UsdGeom.Xform.Define(stage, "/VoxelRoot")
    root.AddScaleOp().Set(Gf.Vec3f(unit_scale, unit_scale, unit_scale))
    
    # Create PointInstancer
    instancer = UsdGeom.PointInstancer.Define(stage, "/VoxelRoot/Voxels")
    instancer.CreatePrototypeBinding().Set("/VoxelRoot/VoxelPrototype")
    
    # Define prototype shape
    prototype = UsdGeom.Xform.Define(stage, "/VoxelRoot/VoxelPrototype")
    cube = UsdGeom.Gprim.Define(stage, "/VoxelRoot/VoxelPrototype/Cube")
    cube.CreateExtentAttr().Set([[-resolution/2, -resolution/2, -resolution/2], [resolution/2, resolution/2, resolution/2]])
    
    # Set instancer arrays
    instancer.CreatePositionsAttr().Set(Vt.Vec3fArray.FromNumpy(np.ascontiguousarray(centers, dtype=np.float32)))
    instancer.CreateColorsAttr().Set(Vt.Vec3fArray.FromNumpy(np.ascontiguousarray(colors.astype(np.float32) / 255.0, dtype=np.float32)))
    
    # Enable physics collision on prototype
    UsdPhysics.CollisionAPI.Apply(prototype)
```

**Pitfalls**
- PLY files missing the `end_header` marker cause infinite loops during ASCII parsing; the implementation limits header reads to 10,000 lines [S1, unofficial].
- SPZ files must be gzip-compressed; opening non-gzip files raises an error [S1, unofficial].
- USD Composer uses centimeters while Isaac Sim uses meters; a `unit_scale` parameter handles this mismatch [S1, unofficial].

## Operating characteristics
- **Time Complexity**: Not given in the sources. Voxelization uses vectorized numpy operations to prevent UI thread stalls with multi-million point splats [S1, unofficial].
- **Memory Complexity**: Not given in the sources.
- **Strengths**: Integrates directly with NVIDIA Omniverse for visualization and physics; handles 3DGS-specific formats (SPZ, PLY with SH); undoable commands in Kit [S1, unofficial].
- **Limitations**: Requires Kit SDK 106 or newer; limited to USD output [S1, unofficial].

## Background
The 3DGS Voxelizer is an unofficial extension for NVIDIA Omniverse, developed by danci [S1, unofficial]. It was created to bridge the gap between 3D Gaussian Splatting scans and USD-based workflows, enabling use in tools like USD Composer and Isaac Sim [S1, unofficial].
