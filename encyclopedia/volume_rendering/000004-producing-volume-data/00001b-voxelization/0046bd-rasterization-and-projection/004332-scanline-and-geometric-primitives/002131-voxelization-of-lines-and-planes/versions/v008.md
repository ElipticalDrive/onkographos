# Voxelization of Lines and Planes
Also called: Slab-based Voxelization, N-separating Voxelization, 6-separating voxelization, 26-separating voxelization, 26-Separating Plane Voxelization

## Overview
This method generates a discrete, topologically correct representation of 2D lines and 3D planes by defining a slab of voxels around the geometric primitive. It solves the problem of ensuring **N-separability** (preventing N-connected ray paths from penetrating the surface) and **N-minimality** (excluding redundant voxels) simultaneously, a guarantee that earlier scan-conversion algorithms lacked [S2]. It sets itself apart from sibling methods like [3D Scan-conversion](1895-3d-scan-conversion.md) by deriving a specific thickness parameter $t$ from the surface normal and grid resolution, rather than relying on fixed thresholds or simple center-point inclusion [S2].

## How it works
**Inputs:**
*   Geometric primitive: A 2D line or 3D plane defined by coefficients.
*   Grid resolution: Voxel width $L$ (assumed uniform).
*   Separability type $N \in \{4, 8\}$ for 2D lines, $N \in \{6, 26\}$ for 3D planes.

**Outputs:**
*   A set of voxel coordinates $\tilde{S}$ representing the discretized primitive.

**Data Structures:**
*   The output is a set of integer coordinates $(x, y, z)$ or $(x, y)$.
*   For mesh extensions, voxels are classified into Vertex Voxels, Edge Voxels, and Body Voxels [S2].

**Parameters:**
*   $L$: Voxel width (grid spacing).
*   $t_N$: Thickness threshold for separability $N$.
*   $\alpha$: Angle between the voxel diagonal and the plane normal (for 3D).
*   $\beta$: Angle between the pixel diagonal and the line normal (for 2D).

**Steps:**

1.  **Define the Primitive Equation:**
    For a 3D plane, define the equation:
    $$ A_p X + B_p Y + C_p Z + D_p = 0 $$
    The normal vector $(A_p, B_p, C_p)$ must be normalized. Sources state the normalization condition as $\sqrt{A_p^2 + B_p^2 + C_p^2} = 1$ [S2]. Note: One source text contains a typo suggesting division by 2, but standard normalization and the context of distance calculation imply unit length [S2].

2.  **Calculate Thickness $t_N$:**
    Compute the slab thickness based on the desired separability and grid size.
    *   For 26-separating planes:
        $$ t_{26} = \frac{L}{2 \sqrt{3} \cos \alpha} $$
        where $\alpha$ is the angle between the voxel diagonal $K$ and the plane normal $N$ [S2].
    *   For 6-separating planes:
        $$ t_6 = \frac{L}{2 \cos \beta} $$
        where $\beta$ is the angle between the normal to the voxel face and the plane normal [S2].
    *   For 8-separating lines:
        $$ t_8 = \frac{L}{2 \cos \alpha} $$
        where $\alpha$ is the angle between the normal and the pixel diagonal [S2].
    *   For 4-separating lines:
        $$ t_4 = \frac{L}{2 \cos \beta} $$
        where $\beta$ is the angle between the normal and the pixel diagonal [S2].

3.  **Define Slab Boundaries:**
    Construct two parallel planes (or lines in 2D) offset from the original primitive by distance $t_N$. Their equations are:
    $$ A_p X + B_p Y + C_p Z + D_p \pm t_N = 0 $$
    [S2]

4.  **Voxel Inclusion Test:**
    For each voxel center $(x, y, z)$ within the bounding volume of the primitive:
    Calculate the signed distance value:
    $$ val = A_p x + B_p y + C_p z + D_p $$
    Include the voxel in $\tilde{S}$ if:
    $$ -t_N \leq val \leq t_N $$
    [S2]

5.  **Handle Degeneracies:**
    If the primitive passes exactly through a voxel corner, edge, or face, use infinitesimal perturbation to ensure the intersection occurs strictly inside a voxel, never exactly on the boundary [S1, unofficial]. This prevents ambiguity in connectivity.

6.  **Mesh Extension (Optional):**
    For polygon meshes, classify voxels into three sets:
    *   $\tilde{S}_v$: Vertex Voxels (within radius $R_c$ of vertices).
    *   $\tilde{S}_e$: Edge Voxels (within radius $R_c$ of edges).
    *   $\tilde{S}_b$: Body Voxels (from the plane slab method).
    Combine these sets to form the final mesh representation [S2].

**Pseudocode:**

```python
import math

def voxelize_plane(Ap, Bp, Cp, Dp, L, N, bounds):
    """
    Voxelize a 3D plane for N-separability.
    
    Args:
        Ap, Bp, Cp, Dp: Plane equation coefficients Ax + By + Cz + D = 0.
        L: Voxel width.
        N: Separability type (6 or 26).
        bounds: Tuple (min_x, max_x, min_y, max_y, min_z, max_z) defining the grid region to check.
        
    Returns:
        List of voxel coordinates (x, y, z) included in the slab.
    """
    # Normalize normal vector
    norm_len = math.sqrt(Ap**2 + Bp**2 + Cp**2)
    Ap /= norm_len
    Bp /= norm_len
    Cp /= norm_len
    
    # Calculate thickness t_N
    # Angle alpha: angle between voxel diagonal and plane normal
    # Voxel diagonal vector K can be (1, 1, 1) in local grid space
    # Normal vector N is (Ap, Bp, Cp)
    # cos(alpha) = |K . N| / (|K| * |N|)
    # |K| = sqrt(3), |N| = 1
    # Dot product = |Ap + Bp + Cp|
    
    # Note: The source defines alpha specifically for the worst-case diagonal.
    # For 26-separability, we use the diagonal that makes the smallest angle with the normal
    # to ensure no 26-holes. The formula uses cos(alpha).
    # If the normal is (Ap, Bp, Cp), the max projection onto a diagonal direction (signs of Ap, Bp, Cp)
    # is |Ap| + |Bp| + |Cp|.
    # However, the source formula is t_26 = L / (2 * sqrt(3) * cos(alpha)).
    # Let's derive cos(alpha) from the normal.
    # The angle between the normal and the diagonal (1,1,1) is alpha.
    # cos(alpha) = (Ap*1 + Bp*1 + Cp*1) / (sqrt(3)*1) = (Ap + Bp + Cp) / sqrt(3) ?
    # Actually, to guarantee separation, we must consider the diagonal most aligned with the normal.
    # The source states: "alpha is the angle between the voxel diagonal K and the plane normal N".
    # And t_26 = L / (2 * sqrt(3) * cos(alpha)).
    # If we assume K is the specific diagonal aligned with the normal's octant:
    # cos_alpha = (|Ap| + |Bp| + |Cp|) / math.sqrt(3)
    
    cos_alpha = (abs(Ap) + abs(Bp) + abs(Cp)) / math.sqrt(3)
    
    if N == 26:
        t_N = L / (2 * math.sqrt(3) * cos_alpha)
    elif N == 6:
        # For 6-separability, beta is angle between normal and face normal.
        # The worst case is the face normal most aligned with the plane normal.
        # cos(beta) = max(|Ap|, |Bp|, |Cp|)
        cos_beta = max(abs(Ap), abs(Bp), abs(Cp))
        t_N = L / (2 * cos_beta)
    else:
        raise ValueError("N must be 6 or 26 for 3D planes")

    voxels = []
    min_x, max_x, min_y, max_y, min_z, max_z = bounds
    
    for x in range(min_x, max_x + 1):
        for y in range(min_y, max_y + 1):
            for z in range(min_z, max_z + 1):
                # Signed distance from voxel center to plane
                # Assuming voxel centers are at integer coordinates
                val = Ap * x + Bp * y + Cp * z + Dp
                
                if -t_N <= val <= t_N:
                    voxels.append((x, y, z))
                    
    return voxels

def voxelize_line(Ap, Bp, Dp, L, N, bounds):
    """
    Voxelize a 2D line for N-separability.
    
    Args:
        Ap, Bp, Dp: Line equation Ax + By + D = 0.
        L: Grid square size.
        N: Separability type (4 or 8).
        bounds: Tuple (min_x, max_x, min_y, max_y).
        
    Returns:
        List of pixel coordinates (x, y).
    """
    # Normalize
    norm_len = math.sqrt(Ap**2 + Bp**2)
    Ap /= norm_len
    Bp /= norm_len
    
    if N == 8:
        # alpha is angle between normal and pixel diagonal
        # cos(alpha) = (|Ap| + |Bp|) / sqrt(2)
        cos_alpha = (abs(Ap) + abs(Bp)) / math.sqrt(2)
        t_N = L / (2 * cos_alpha)
    elif N == 4:
        # beta is angle between normal and pixel axis (face normal equivalent)
        # cos(beta) = max(|Ap|, |Bp|)
        cos_beta = max(abs(Ap), abs(Bp))
        t_N = L / (2 * cos_beta)
    else:
        raise ValueError("N must be 4 or 8 for 2D lines")

    voxels = []
    min_x, max_x, min_y, max_y = bounds
    
    for x in range(min_x, max_x + 1):
        for y in range(min_y, max_y + 1):
            val = Ap * x + Bp * y + Dp
            if -t_N <= val <= t_N:
                voxels.append((x, y))
                
    return voxels
```

## Subtopics

### [4-Separating Line Voxelization](2502-4-separating-line-voxelization.md)
A method to generate a discrete representation of a 2D line that is 4-separating (contains no 4-holes) and 4-minimal. It sets the thickness parameter $t_4$ based on the line's angle relative to the grid, ensuring that every pixel intersected by the line is included while excluding those that do not contribute to 4-connectivity. It differs from 8-separating methods by enforcing stricter connectivity constraints, resulting in a thinner but more robust representation for 4-connected contexts.
*   [6-Separating Plane Voxelization]: Generates a 6-separating (face-connected) and 6-minimal representation of a 3D plane. It uses a thickness $t_6$ derived from the angle between the plane normal and the voxel face normals. It is sparser than 26-separating voxelization and sufficient for 6-connected ray marching.
*   [26-Separating Plane Voxelization]: Generates a 26-separating (vertex/edge/face-connected) and 26-minimal representation. It uses a thickness $t_{26}$ derived from the angle between the plane normal and the voxel diagonal. It produces significantly more Vertex and Edge voxels than 6-separating methods but guarantees no 26-connected ray paths penetrate the surface.

## Operating characteristics
*   **Time Complexity:** $O(V)$, where $V$ is the number of voxels in the bounding volume. The method iterates over all candidate voxels and performs a constant-time distance check [S2].
*   **Memory Complexity:** $O(V_{out})$, where $V_{out}$ is the number of voxels in the output set $\tilde{S}$. For mesh extensions, linked lists are used to store voxels, incurring overhead proportional to the voxel count [S2].
*   **Performance:** Measured in VPM (Voxels Per Millisecond). Performance decreases as the number of voxels increases due to linked list maintenance costs [S2]. Non-optimized implementations are slow; efficient incremental algorithms are recommended for production [S2].
*   **Strengths:** Guarantees topological correctness (separability and minimality) for both lines and planes. Eliminates artifacts at edges and vertices when extended to meshes. Visually indistinguishable from 6-separating models despite topological differences [S2].
*   **Limitations:** 26-separating voxelization produces significantly more voxels (especially Vertex and Edge voxels) than 6-separating voxelization [S2]. Requires careful handling of degeneracies (perturbation) [S1, unofficial].
*   **When to use:** When topological correctness is critical (e.g., ray casting where penetration must be strictly prevented). Use 6-separating for visualization where speed is prioritized and 6-connected paths are sufficient. Use 26-separating for robust collision detection or ray tracing against thin surfaces.

## Background
The method originates from the need to provide a comprehensive treatment of separability and minimality in voxelization, which earlier algorithms failed to guarantee simultaneously, especially for polygon meshes [S2]. Key theoretical foundations were laid by Cohen-Or and Kaufman [COK97, COK95], who analyzed 26-connected ray paths and 26-separating covers [S1, unofficial]. The specific slab-based thickness derivation for N-separating planes and lines was presented in "An Accurate Method for Voxelizing Polygon Meshes" [S2]. The approach uses the Jordan curve theorem to prove that connecting voxel corners via 1D intersection targets guarantees 26-separation for effectively 2D inputs [S1, unofficial].
