# 4-Separating Line Voxelization

Also called: 4-separating line representation, 4-minimal line voxelization

## Overview
A method to generate a discrete representation of a 2D line that is 4-separating (contains no 4-holes) and 4-minimal (contains no redundant voxels) [S1]. It sets the thickness parameter $t_4$ based on the line's angle relative to the grid, ensuring that every pixel intersected by the line is included while excluding those that do not contribute to 4-connectivity [S1]. It differs from 8-separating methods by enforcing stricter connectivity constraints, resulting in a thinner but more robust representation for 4-connected contexts [S1].

## How it works
**Inputs:**
- Line equation coefficients $A_p, B_p, D_p$ defining the line $A_p x + B_p y + D_p = 0$ [S1].
- Grid voxel size $L$ [S1].
- Pixel/voxel center coordinates $(x, y)$ [S1].

**Outputs:**
- A set of pixels $\tilde{\mathcal{S}}$ representing the line [S1].

**Data Structures:**
- $\tilde{\mathcal{S}}$: A set of integer coordinate pairs $(x, y)$ [S1].

**Parameters:**
- $t_4$: The threshold for inclusion. Calculated as $t_4 = \frac{L}{2\sqrt{2}\cos\alpha}$ [S1].
- $\alpha$: The angle between the normal to the line from the pixel center $C$ and the diagonal of the pixel [S1]. Note: The source text implies $\alpha$ is related to the orientation of the line relative to the grid axes. Specifically, the proof involves the angle between the normal $N$ and the voxel diagonal $K$ in 3D, but for 2D lines, $\alpha$ determines the effective thickness. The source states $t_4 = \frac{L}{2\sqrt{2}\cos\alpha}$ [S1].

**Steps:**
1. Calculate the threshold $t_4$ using the line's orientation angle $\alpha$ and voxel size $L$ [S1].
2. For each pixel $(x, y)$ in the bounding box of the line:
   a. Calculate the signed distance from the pixel center to the line: $d = A_p x + B_p y + D_p$ [S1].
   b. If $-t_4 \leq d \leq t_4$, include $(x, y)$ in $\tilde{\mathcal{S}}$ [S1].

**Formula:**
The set of pixels is defined as:
$$ \tilde{\mathcal{S}} = \{(x, y) \mid -t_4 \leq A_p x + B_p y + D_p \leq t_4\} $$
where $t_4 = \frac{L}{2\sqrt{2}\cos\alpha}$ [S1].

**Edge Cases and Pitfalls:**
- If the threshold $t_4$ is not calculated correctly based on the angle $\alpha$, pixels that should be included might be excluded, creating 4-holes [S1].
- The proof shows that if a pixel is intersected by the line but excluded, it leads to a contradiction regarding the distance from the center $C$ to the line [S1].
- Minimality is guaranteed because removing any pixel from the representation would introduce an 8-hole, affecting separability [S1].

## Subtopics

## Operating characteristics
- **Time Complexity:** Linear with respect to the number of pixels in the bounding box of the line [S1].
- **Memory Complexity:** Proportional to the number of voxels in the representation [S1].
- **Strengths:** Guarantees 4-separability and 4-minimality, preventing gaps in 4-connected representations [S1].
- **Limitations:** Requires precise calculation of the angle $\alpha$ to avoid 4-holes [S1].

## Background
Originated in the context of accurate polygon mesh voxelization, specifically addressing the need for discrete representations that maintain topological properties like separability and minimality [S1]. The method is part of a broader framework for voxelizing geometric primitives, extending 2D line voxelization to 3D plane voxelization [S1].
