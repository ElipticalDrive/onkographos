# Mesh to Voxel Generation via AABB-Triangle Intersection

Also called: MeshToVoxel, Triangle Mesh Voxelization, Voxelizer

## Overview
This method converts a 3D triangle mesh into a solid, non-hollow voxel grid suitable for deep physical simulations such as heat diffusion, fracture, and soft physics [S1, unofficial][S2, unofficial]. It operates in two distinct phases: first, it identifies the surface shell by testing every voxel in the mesh's bounding box against all triangles using an Axis-Aligned Bounding Box (AABB) vs. Triangle intersection test based on the Separating Axis Theorem (SAT) [S3, unofficial]; second, it fills the interior volume using a scanline fill algorithm that determines inside/outside parity by analyzing triangle normals relative to a horizontal ray [S1, unofficial][S2, unofficial]. Unlike [Fake Voxelization via Triangle-Cube Intersection](6951-fake-voxelization-via-triangle-cube-intersection.md) which outputs only surface voxels, this method produces a solid occupancy grid [S3, unofficial]. It differs from [Level 1 Triangle-Voxel Classification](4872-level-1-triangle-voxel-classification.md) by explicitly performing a full interior fill rather than just classifying candidate voxels [S1, unofficial].

## How it works
**Inputs:** A triangle mesh defined by vertices and indices, and a voxel size parameter `_unitSize` (default `0.05f` [S3, unofficial]).
**Outputs:** A 3D integer array `_voxels` of dimensions $[N_y, N_z, N_x]$ where values are `0` (empty), `1` (surface intersected), or `2` (solid/filled) [S3, unofficial].

**Data Structures:**
*   `Triangle`: Contains three `Vector3` fields `p1`, `p2`, `p3` representing vertices in world space [S3, unofficial].
*   `_voxels`: A 3D array `int[,,]` indexed as `[y, z, x]` [S3, unofficial].
*   `_bounds`: A bounding box defined by `min` and `max` vectors in world space [S3, unofficial].

**Parameters:**
*   `_unitSize`: Side length of each voxel cube. Default `0.05f` [S3, unofficial].
*   Grid dimensions: Calculated from the bounding box size rounded up to the nearest multiple of `_unitSize` [S1, unofficial][S2, unofficial].

**Steps:**

1.  **Transform and Bound:** Retrieve mesh vertices and transform them to world space using the model's transformation matrix [S3, unofficial]. Compute the world-space bounding box by finding the minimum and maximum coordinates of all transformed vertices [S3, unofficial].
2.  **Grid Alignment:** Round the bounding box `min` down to the nearest multiple of `_unitSize` and `max` up to the nearest multiple of `_unitSize` [S3, unofficial]. If any dimension of `max` equals `min` after rounding, add `_unitSize` to `max` to ensure non-zero dimensions [S3, unofficial].
3.  **Allocate Grid:** Calculate grid dimensions $N_x, N_y, N_z$ from the aligned bounding box size divided by `_unitSize`, rounded to integers [S3, unofficial]. Allocate `_voxels` with these dimensions [S3, unofficial].
4.  **Shell Generation (Intersection):** For each voxel $(x, y, z)$ in the grid:
    a. Compute the voxel center in world space:
       $$ \text{center} = (x \cdot \text{\_unitSize} + \frac{\text{\_unitSize}}{2}, y \cdot \text{\_unitSize} + \frac{\text{\_unitSize}}{2}, z \cdot \text{\_unitSize} + \frac{\text{\_unitSize}}{2}) + \text{\_bounds.min} $$
       [S3, unofficial]
    b. Iterate through all triangles in the mesh. For each triangle, perform an AABB-Triangle intersection test using the voxel center and `_unitSize` [S3, unofficial].
    c. If an intersection is detected, set `_voxels[y, z, x] = 1` and break the triangle loop [S3, unofficial].
5.  **Interior Fill (Scanline):** Process the voxel grid slice by slice (e.g., by Z), and within each slice, row by row (e.g., by Y). For each row (varying X):
    a. Initialize a `pen` state to `Up` (not filling) [S1, unofficial][S2, unofficial].
    b. Iterate through each voxel in the row from left to right (increasing X).
    c. If the current voxel is empty (`0`), continue to the next voxel without changing the `pen` state [S1, unofficial].
    d. If the current voxel is part of the shell (`1`):
       i. Cast a horizontal ray from left to right through the center of the voxel to find all intersecting triangles [S1, unofficial][S2, unofficial].
       ii. Identify the "last" triangle $T_{last}$ intersected by the ray (the one with the largest X-coordinate intersection or furthest along the ray direction) [S2, unofficial].
       iii. Let $n_x$ be the X-component of the normal of $T_{last}$ [S2, unofficial].
       iv. Update `pen` state: If $n_x < 0$ (normal faces left, outward from interior relative to scan), set `pen = Down`. If $n_x > 0$ (normal faces right), set `pen = Up` [S2, unofficial].
    e. If `pen` is `Down`, mark the current voxel as solid (`2`) [S2, unofficial]. If `pen` is `Up`, leave it empty (`0`) [S2, unofficial].
6.  **Finalization:** Mark all voxels with value `1` as `2` to complete the solid model [S3, unofficial].

**AABB-Triangle Intersection Test (SAT):**
The function `AABBTriangleOverlaped(voxelCenter, voxelSize, triangle)` implements the Separating Axis Theorem [S3, unofficial]:
1.  Transform triangle vertices $v_1, v_2, v_3$ relative to the box center: $v_i' = v_i - \text{voxelCenter}$ [S3, unofficial].
2.  Compute edge vectors: $e_1 = v_2 - v_1$, $e_2 = v_3 - v_2$, $e_3 = v_1 - v_3$ [S3, unofficial].
3.  Define half-box size $h = \text{voxelSize} / 2$ [S3, unofficial].
4.  Test separation axes:
    *   **Axis-Aligned Axes (X, Y, Z):** Project vertices and box onto axis. For X-axis, separation if `min(v1'.x, v2'.x, v3'.x) > h.x` or `max(...) < -h.x` [S3, unofficial].
    *   **Edge-Cross-Axis:** For each edge $e_i$ and axis $A \in \{X, Y, Z\}$, compute projection interval for the triangle and the box.
        *   Triangle projection: $min_T = \min(e_i \cdot A, \dots)$, $max_T = \max(\dots)$ (using vertex projections).
        *   Box projection radius: $rad = |e_i.y| \cdot h.z + |e_i.z| \cdot h.y$ (for X-axis test) [S3, unofficial].
        *   Separation if $min_T > rad$ or $max_T < -rad$ [S3, unofficial].
    *   **Triangle Normal:** Compute normal $n = e_1 \times e_2$ [S3, unofficial].
        *   Plane equation: $d = -\text{Dot}(n, v_1)$ [S3, unofficial].
        *   Find extremal points of the box along $n$: $v_{min}$ and $v_{max}$ [S3, unofficial].
        *   Separation if $\text{Dot}(n, v_{min}) + d > 0$ [S3, unofficial].
        *   Intersection if $\text{Dot}(n, v_{max}) + d \ge 0$ [S3, unofficial].
5.  If no separating axis is found, the AABB and triangle intersect [S3, unofficial].

**Pseudocode:**

```python
def mesh_to_voxel(mesh_vertices, mesh_indices, unit_size=0.05):
    # 1. Transform and Bound
    world_vertices = [transform_point(v) for v in mesh_vertices]
    min_coord = Vector3(float('inf'), float('inf'), float('inf'))
    max_coord = Vector3(float('-inf'), float('-inf'), float('-inf'))
    
    for v in world_vertices:
        min_coord = Vector3(min(min_coord.x, v.x), min(min_coord.y, v.y), min(min_coord.z, v.z))
        max_coord = Vector3(max(max_coord.x, v.x), max(max_coord.y, v.y), max(max_coord.z, v.z))
        
    # 2. Grid Alignment
    min_coord = round_down(min_coord, unit_size)
    max_coord = round_up(max_coord, unit_size)
    
    # Handle zero-size dimensions
    if max_coord.x == min_coord.x: max_coord.x += unit_size
    if max_coord.y == min_coord.y: max_coord.y += unit_size
    if max_coord.z == min_coord.z: max_coord.z += unit_size
    
    bounds_min = min_coord
    bounds_max = max_coord
    
    # 3. Allocate Grid
    size = bounds_max - bounds_min
    nx = int(round(size.x / unit_size))
    ny = int(round(size.y / unit_size))
    nz = int(round(size.z / unit_size))
    
    voxels = [[[0 for _ in range(nx)] for _ in range(nz)] for _ in range(ny)]
    
    # Build triangle list
    triangles = []
    for i in range(0, len(mesh_indices), 3):
        p1 = world_vertices[mesh_indices[i]]
        p2 = world_vertices[mesh_indices[i+1]]
        p3 = world_vertices[mesh_indices[i+2]]
        triangles.append(Triangle(p1, p2, p3))
        
    unit_size_half = unit_size * 0.5
    
    # 4. Shell Generation
    for y in range(ny):
        for z in range(nz):
            for x in range(nx):
                center = Vector3(
                    x * unit_size + unit_size_half,
                    y * unit_size + unit_size_half,
                    z * unit_size + unit_size_half
                ) + bounds_min
                
                for tri in triangles:
                    if aabb_triangle_overlap(center, unit_size, tri):
                        voxels[y][z][x] = 1
                        break
                        
    # 5. Interior Fill
    for z in range(nz):
        for y in range(ny):
            pen = 'Up'
            for x in range(nx):
                if voxels[y][z][x] == 0:
                    continue
                    
                # Voxel is part of shell (1)
                # Cast horizontal ray through center
                ray_origin = Vector3(x * unit_size + unit_size_half, y * unit_size + unit_size_half, z * unit_size + unit_size_half) + bounds_min
                ray_direction = Vector3(1, 0, 0)
                
                # Find last intersected triangle
                last_tri = None
                max_t = float('-inf')
                
                for tri in triangles:
                    t = ray_triangle_intersection(ray_origin, ray_direction, tri)
                    if t is not None and t > max_t:
                        max_t = t
                        last_tri = tri
                        
                if last_tri is not None:
                    nx_normal = last_tri.normal.x
                    if nx_normal < 0:
                        pen = 'Down'
                    else:
                        pen = 'Up'
                        
                if pen == 'Down':
                    voxels[y][z][x] = 2
                else:
                    voxels[y][z][x] = 0
                    
    # 6. Finalization: Convert remaining 1s to 2s
    for y in range(ny):
        for z in range(nz):
            for x in range(nx):
                if voxels[y][z][x] == 1:
                    voxels[y][z][x] = 2
                    
    return voxels

def aabb_triangle_overlap(center, size, tri):
    half_size = size * 0.5
    v1 = tri.p1 - center
    v2 = tri.p2 - center
    v3 = tri.p3 - center
    
    e1 = v2 - v1
    e2 = v3 - v2
    e3 = v1 - v3
    
    # Test X, Y, Z axes
    if test_axis(v1, v2, v3, Vector3(1,0,0), half_size): return False
    if test_axis(v1, v2, v3, Vector3(0,1,0), half_size): return False
    if test_axis(v1, v2, v3, Vector3(0,0,1), half_size): return False
    
    # Test Edge x Axis axes
    if test_edge_axis(e1, v1, v2, v3, Vector3(1,0,0), half_size): return False
    if test_edge_axis(e1, v1, v2, v3, Vector3(0,1,0), half_size): return False
    if test_edge_axis(e1, v1, v2, v3, Vector3(0,0,1), half_size): return False
    if test_edge_axis(e2, v1, v2, v3, Vector3(1,0,0), half_size): return False
    if test_edge_axis(e2, v1, v2, v3, Vector3(0,1,0), half_size): return False
    if test_edge_axis(e2, v1, v2, v3, Vector3(0,0,1), half_size): return False
    if test_edge_axis(e3, v1, v2, v3, Vector3(1,0,0), half_size): return False
    if test_edge_axis(e3, v1, v2, v3, Vector3(0,1,0), half_size): return False
    if test_edge_axis(e3, v1, v2, v3, Vector3(0,0,1), half_size): return False
    
    # Test Triangle Normal
    normal = cross(e1, e2)
    d = -dot(normal, v1)
    
    # Box extremal points along normal
    vmin = Vector3(0,0,0)
    vmax = Vector3(0,0,0)
    if normal.x > 0: vmax.x = half_size.x; vmin.x = -half_size.x
    else: vmax.x = -half_size.x; vmin.x = half_size.x
    if normal.y > 0: vmax.y = half_size.y; vmin.y = -half_size.y
    else: vmax.y = -half_size.y; vmin.y = half_size.y
    if normal.z > 0: vmax.z = half_size.z; vmin.z = -half_size.z
    else: vmax.z = -half_size.z; vmin.z = half_size.z
    
    if dot(normal, vmin) + d > 0: return False
    if dot(normal, vmax) + d < 0: return False
    
    return True

def test_axis(v1, v2, v3, axis, half_size):
    p1 = dot(v1, axis)
    p2 = dot(v2, axis)
    p3 = dot(v3, axis)
    min_p = min(p1, p2, p3)
    max_p = max(p1, p2, p3)
    rad = half_size.x if axis.x != 0 else (half_size.y if axis.y != 0 else half_size.z)
    if min_p > rad or max_p < -rad:
        return True
    return False

def test_edge_axis(edge, v1, v2, v3, axis, half_size):
    # Project vertices
    p1 = dot(v1, axis)
    p2 = dot(v2, axis)
    p3 = dot(v3, axis)
    min_p = min(p1, p2, p3)
    max_p = max(p1, p2, p3)
    
    # Box radius
    if axis.x != 0: rad = abs(edge.y) * half_size.z + abs(edge.z) * half_size.y
    elif axis.y != 0: rad = abs(edge.x) * half_size.z + abs(edge.z) * half_size.x
    else: rad = abs(edge.x) * half_size.y + abs(edge.y) * half_size.x
    
    if min_p > rad or max_p < -rad:
        return True
    return False
```

## Subtopics

### [Level 1 Triangle-Voxel Classification](4872-level-1-triangle-voxel-classification.md)
Classifies input triangles into a coarse 3D voxel grid by mapping vertices to voxel indices and testing overlap with all candidate voxels the triangle spans. It identifies candidate voxels via vertex mapping rather than testing every voxel against every triangle, enabling parallel processing where each thread handles one triangle.

### [Tessellation-based Voxelization](5430-tessellation-based-voxelization.md)
GPU-accelerated method for generating 3D voxel grids from triangle meshes by leveraging the hardware tessellation pipeline to subdivide geometry before rasterization. It differs from fixed-function or CPU-based voxelizers by enabling adaptive triangle density and displacement mapping during the generation phase, allowing for higher fidelity in complex regions.

### [Fake Voxelization via Triangle-Cube Intersection](6951-fake-voxelization-via-triangle-cube-intersection.md)
A surface-only voxelization technique that digitizes a triangulated mesh by independently testing each triangle against a grid of axis-aligned cubes (voxels). Unlike solid voxelization methods that fill the interior volume using Constructive Solid Geometry (CSG), this approach outputs only the voxels intersected by the mesh surface, making it computationally simpler and suitable for generating surface representations. It is distinguished from its siblings by its independence from tessellation depth and its reliance on a template-based intersection test to control topological separability (6- or 26-connectivity).

### [Robust Mesh Voxelization via Exact Predicates](8770-robust-mesh-voxelization-via-exact-predicates.md)
A mesh-native voxelizer that produces an occupancy grid or a signed-distance field (SDF) over a Piecewise Linear Complex (PLC)'s bounding box, using exact-predicate classification to avoid epsilon-ray speckle. Unlike [Level 1 Triangle-Voxel Classification](4872-level-1-triangle-voxel-classification.md) which may rely on approximate ray casting, this method uses Shewchuk's exact predicates for geometric calculations to ensure robust classification of watertight meshes in single precision. It differs from [Tessellation-based Voxelization](5430-tessellation-based-voxelization.md) by operating directly on the input triangle mesh without prior subdivision, and from [Fake Voxelization via Triangle-Cube Intersection](6951-fake-voxelization-via-triangle-cube-intersection.md) by providing true inside/outside parity checks rather than mere intersection counts.

### [Triangle Subdivision for Voxelization](11480-triangle-subdivision-for-voxelization.md)
This method is a pre-processing step that sequentially consumes a triangle soup to apply a subdivision scheme, aiming to create triangles that are homogeneous regarding the number of voxels generated per triangle and the compactness of their Morton index range. It sets it apart from siblings by explicitly targeting the variance in voxel count and spatial locality (Morton index spread) to optimize subsequent out-of-core batch processing, rather than just geometric fidelity or simple coverage.

### Mesh-based VCP Grid Generation
Computes the Vector-to-Closest-Point (VCP) from a grid point to the mesh triangles using barycentric coordinates of the perpendicular projection [S4, unofficial]. If the projection falls outside the triangle, it computes the closest point on the edges [S4, unofficial]. Triangles are inserted into an empty grid by updating grid points within the triangle's bounding box if they are empty or point to a triangle with a greater VCP distance [S4, unofficial]. The data is expanded using a region growing algorithm that iterates over grid points, updating pointers to neighboring triangles if the VCP distance is shorter [S4, unofficial].

### Exact Voxelization Method
An alternative voxelization method implemented in binvox, written by Eric Haines, using triangle overlap code by Tomas Akenine-Möller [S5]. It is noted for specific historical bugs, such as triangles at max coordinates not being voxelized correctly in version 1.17, and triangles being voxelized too thickly in version 1.02 with the `-e` option [S5].

## Operating characteristics
*   **Time Complexity:** The shell generation step is $O(N_v \cdot N_t)$ where $N_v$ is the number of voxels and $N_t$ is the number of triangles, as every voxel tests against every triangle [S3, unofficial]. This is computationally expensive for high-resolution grids. The scanline fill is $O(N_v)$.
*   **Memory Complexity:** $O(N_v)$ to store the voxel grid [S3, unofficial].
*   **Performance:** The naive implementation in [S3, unofficial] uses parallel tasks for voxel iteration but still iterates all triangles per voxel. Performance scales poorly with triangle count.
*   **Strengths:** Produces watertight, solid voxel models suitable for physics simulations [S1, unofficial]. Simple to implement [S1, unofficial].
*   **Limitations:** Slow for large meshes due to the $O(N_v \cdot N_t)$ intersection test [S3, unofficial]. Precision issues may arise if grid dimensions do not divide evenly by unit size, though `Mathf.RoundToInt` handles allocation [S3, unofficial].
*   **When to use:** When a solid, non-hollow voxel representation is required for simulation [S1, unofficial].
*   **When not to use:** When only surface representation is needed (use [Fake Voxelization via Triangle-Cube Intersection](6951-fake-voxelization-via-triangle-cube-intersection.md)) or when performance is critical for large meshes (use spatial acceleration structures or GPU-based methods).

## Background
The method was described by David Rosen in a 2009 blog post on Wolfire Games, detailing its use for automatic skinning and physical simulations in game development [S1, unofficial]. It was also discussed in a Game Developer article [S2, unofficial]. An implementation in Unity was shared on Qiita in 2017 [S3, unofficial]. The exact voxelization variant is part of the binvox tool, with contributions from Eric Haines and Tomas Akenine-Möller [S5].
