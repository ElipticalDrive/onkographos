# Mesh to Voxel Generation via AABB-Triangle Intersection

Also called: MeshToVoxel, Triangle Mesh Voxelization, Voxelizer

## Overview
This method converts a 3D triangle mesh into a solid voxel model by explicitly testing for geometric intersection between mesh triangles and axis-aligned bounding boxes (AABBs) representing voxels [S1, S2, unofficial]. It differs from rasterization-based approaches by operating in world space using exact geometric overlap tests rather than projecting geometry onto a screen [S1, S2, unofficial]. The process consists of two distinct phases: creating a surface shell by marking voxels that intersect with any triangle, and filling the interior using a scanline algorithm that determines solid vs. empty space based on ray-triangle intersection parity [S1, unofficial].

## How it works
**Inputs and Outputs:**
*   **Input:** A triangle mesh defined by vertices and indices, and a voxel grid resolution defined by a unit size (voxel side length) and a bounding box.
*   **Output:** A 3D integer array representing the voxel grid, where values indicate occupancy status (empty, shell, or solid) [S2, unofficial].

**Data Structures:**
*   **Triangle:** A structure containing three 3D vectors (`p1`, `p2`, `p3`) representing the mesh vertices in world space [S2, unofficial].
*   **Voxel Grid (`_voxels`):** A 3D integer array with dimensions `[y, z, x]` corresponding to the grid resolution [S2, unofficial].
    *   Value `0`: Empty (not intersected).
    *   Value `1`: Shell (intersected by a triangle surface).
    *   Value `2`: Solid (filled interior) [S2, unofficial].
*   **Bounds:** A bounding box defined by `min` and `max` coordinates in world space, aligned to the voxel grid [S2, unofficial].

**Parameters:**
*   `_unitSize`: The physical side length of a voxel cube. Default value is `0.05f` [S2, unofficial].
*   `grid_dimensions`: The number of voxels per axis, calculated from the bounding box size divided by `_unitSize` [S1, S2, unofficial].

**Algorithm Steps:**

1.  **Coordinate Mapping and Bounds Calculation:**
    *   Transform all mesh vertices to world space [S2, unofficial].
    *   Compute the world-space bounding box by finding the minimum and maximum coordinates of all transformed vertices [S2, unofficial].
    *   Round the bounding box `min` down to the nearest multiple of `_unitSize` and `max` up to the nearest multiple of `_unitSize` [S2, unofficial].
    *   Ensure non-zero dimensions: if any dimension of `max` equals `min`, add `_unitSize` to `max` for that dimension [S2, unofficial].
    *   Calculate grid dimensions: $N_x = \lfloor \frac{max_x - min_x}{unitSize} \rfloor$, etc. [S2, unofficial].

2.  **Shell Creation (Surface Detection):**
    *   Iterate through every voxel in the grid (indices $i, j, k$).
    *   Compute the voxel center in world space:
        $$ center = (i \cdot unitSize + \frac{unitSize}{2}, j \cdot unitSize + \frac{unitSize}{2}, k \cdot unitSize + \frac{unitSize}{2}) + bounds.min $$
    *   For each voxel, iterate through all triangles in the mesh.
    *   Perform an AABB-Triangle intersection test between the voxel (defined by `center` and `unitSize`) and the triangle [S2, unofficial].
    *   If an intersection is detected, set `_voxels[j, k, i] = 1` and break the triangle loop for that voxel [S2, unofficial].

3.  **Scanline Fill (Interior Filling):**
    *   Process the voxel grid slice by slice (e.g., along the Z-axis), and each slice row by row (e.g., along the X-axis) [S1, unofficial].
    *   Initialize a `Pen` state to `Up` at the start of each row [S1, unofficial].
    *   Iterate through each voxel in the row:
        *   If the current voxel is marked as shell (`1`):
            *   Cast a horizontal ray from left to right through the voxel center [S1, unofficial].
            *   Identify the **last** triangle intersected by this ray ($T_{last}$) [S1, unofficial].
            *   Let $n_x$ be the x-component of the normal of $T_{last}$.
            *   Update Pen state:
                *   If $n_x < 0$ (normal faces left), set `Pen = Down`.
                *   If $n_x > 0$ (normal faces right), set `Pen = Up` [S1, unofficial].
        *   Apply Pen state:
            *   If `Pen == Down`, mark the current voxel as solid (`_voxels[j, k, i] = 2`) [S1, unofficial].
            *   If `Pen == Up`, leave the voxel empty (or keep as `0`) [S1, unofficial].

**AABB-Triangle Intersection Test (SAT):**
The intersection test `AABBTriangleOverlaped(center, unitSize, triangle)` uses the Separating Axis Theorem (SAT) [S2, unofficial]:
1.  Transform triangle vertices relative to the box center: $v_i' = v_i - center$ [S2, unofficial].
2.  Compute edge vectors: $e_1 = v_2 - v_1$, $e_2 = v_3 - v_2$, $e_3 = v_1 - v_3$ [S2, unofficial].
3.  Test separation axes:
    *   **Axis-Aligned Axes (X, Y, Z):** Project triangle vertices and the box onto the axis. The box projection interval is $[-\frac{unitSize}{2}, \frac{unitSize}{2}]$. If the triangle's projection interval does not overlap with this range, they are separated [S2, unofficial].
    *   **Edge Cross Axes:** Compute cross products of each edge with the X, Y, and Z axes ($e_i \times \hat{x}, e_i \times \hat{y}, e_i \times \hat{z}$). Project both the triangle and the box onto these axes. Separation occurs if the projections do not overlap [S2, unofficial].
    *   **Triangle Normal:** Compute the triangle normal $n = e_1 \times e_2$. Project the triangle vertices and the box onto $n$.
        *   Plane equation: $d = -n \cdot v_1$.
        *   Find extremal points of the box along $n$ ($v_{min}, v_{max}$).
        *   Separation if $n \cdot v_{min} + d > 0$. Intersection if $n \cdot v_{max} + d \ge 0$ [S2, unofficial].

**Pseudocode:**

```python
def mesh_to_voxel(mesh_vertices, mesh_indices, unit_size=0.05):
    # 1. Transform and Bounds
    world_vertices = [transform_point(v) for v in mesh_vertices]
    min_coord = Vector3(float('inf'), float('inf'), float('inf'))
    max_coord = Vector3(float('-inf'), float('-inf'), float('-inf'))
    
    for v in world_vertices:
        min_coord = min(min_coord, v)
        max_coord = max(max_coord, v)
        
    # Round bounds to grid
    min_coord = round_down(min_coord, unit_size)
    max_coord = round_up(max_coord, unit_size)
    
    # Ensure non-zero size
    for axis in ['x', 'y', 'z']:
        if max_coord[axis] == min_coord[axis]:
            max_coord[axis] += unit_size
            
    bounds_min = min_coord
    bounds_max = max_coord
    bounds_size = bounds_max - bounds_min
    
    # Grid dimensions
    dim_x = int(round(bounds_size.x / unit_size))
    dim_y = int(round(bounds_size.y / unit_size))
    dim_z = int(round(bounds_size.z / unit_size))
    
    # Initialize voxel grid: 0=empty, 1=shell, 2=solid
    voxels = [[[0 for _ in range(dim_x)] for _ in range(dim_z)] for _ in range(dim_y)]
    
    # Build triangle list
    triangles = []
    for i in range(0, len(mesh_indices), 3):
        p1 = world_vertices[mesh_indices[i]]
        p2 = world_vertices[mesh_indices[i+1]]
        p3 = world_vertices[mesh_indices[i+2]]
        triangles.append(Triangle(p1, p2, p3))
        
    unit_size_half = unit_size * 0.5
    
    # 2. Shell Creation
    for y in range(dim_y):
        for z in range(dim_z):
            for x in range(dim_x):
                center = Vector3(
                    x * unit_size + unit_size_half + bounds_min.x,
                    y * unit_size + unit_size_half + bounds_min.y,
                    z * unit_size + unit_size_half + bounds_min.z
                )
                
                for tri in triangles:
                    if aabb_triangle_overlap(center, unit_size, tri):
                        voxels[y][z][x] = 1
                        break
                        
    # 3. Scanline Fill
    # Iterate slices (z), rows (x), and fill along y (or any axis, here we assume filling along X for simplicity in description, 
    # but S1 describes filling along a row within a slice. Let's follow S1: slice by slice, row by row, pen moves along X)
    # Note: S1 says "horizontal ray from left to right", implying X-axis traversal for the pen.
    
    for z in range(dim_z):
        for y in range(dim_y):
            pen_state = 'Up' # Initialize pen up for each row
            
            for x in range(dim_x):
                if voxels[y][z][x] == 1:
                    # Ray intersection test along X axis through voxel center
                    ray_origin = Vector3(x * unit_size + unit_size_half + bounds_min.x,
                                         y * unit_size + unit_size_half + bounds_min.y,
                                         z * unit_size + unit_size_half + bounds_min.z)
                    ray_direction = Vector3(1, 0, 0)
                    
                    last_tri = None
                    max_t = -1
                    
                    for tri in triangles:
                        t = ray_triangle_intersect(ray_origin, ray_direction, tri)
                        if t is not None and t > 0 and t > max_t:
                            max_t = t
                            last_tri = tri
                            
                    if last_tri is not None:
                        nx = last_tri.normal.x
                        if nx < 0:
                            pen_state = 'Down'
                        elif nx > 0:
                            pen_state = 'Up'
                            
                if pen_state == 'Down':
                    voxels[y][z][x] = 2
                    
    return voxels

def aabb_triangle_overlap(box_center, box_size, tri):
    half_size = box_size * 0.5
    box_half = Vector3(half_size, half_size, half_size)
    
    # Transform vertices relative to box center
    v1 = tri.p1 - box_center
    v2 = tri.p2 - box_center
    v3 = tri.p3 - box_center
    
    # Edges
    e1 = v2 - v1
    e2 = v3 - v2
    e3 = v1 - v3
    
    # Test axes
    axes = [
        Vector3(1, 0, 0), Vector3(0, 1, 0), Vector3(0, 0, 1),
        cross(e1, Vector3(1, 0, 0)), cross(e1, Vector3(0, 1, 0)), cross(e1, Vector3(0, 0, 1)),
        cross(e2, Vector3(1, 0, 0)), cross(e2, Vector3(0, 1, 0)), cross(e2, Vector3(0, 0, 1)),
        cross(e3, Vector3(1, 0, 0)), cross(e3, Vector3(0, 1, 0)), cross(e3, Vector3(0, 0, 1)),
        cross(e1, e2) # Normal
    ]
    
    for axis in axes:
        if axis.length() == 0: continue
        axis = axis.normalize()
        
        # Project triangle
        p1 = dot(v1, axis)
        p2 = dot(v2, axis)
        p3 = dot(v3, axis)
        tri_min = min(p1, p2, p3)
        tri_max = max(p1, p2, p3)
        
        # Project box
        # Box is axis aligned, so projection is sum of abs components of half-size along axis
        box_proj = abs(axis.x) * half_size + abs(axis.y) * half_size + abs(axis.z) * half_size
        
        if tri_max < -box_proj or tri_min > box_proj:
            return False
            
    return True
```

## Subtopics

### [Level 1 Triangle-Voxel Classification](4872-level-1-triangle-voxel-classification.md)
Level 1 Triangle-Voxel Classification is a coarse-grained method for mapping mesh triangles to a 3D voxel grid by determining which voxels a triangle spans. It serves as the initial filtering stage in hierarchical voxelization, reducing the search space for subsequent fine-grained classification. Unlike Tessellation-based Voxelization, which relies on GPU tessellation hardware, this method uses explicit geometric overlap tests on a CPU/GPU hybrid or pure GPU pipeline to assign triangles to coarse voxels.

### [Tessellation-based Voxelization](5430-tessellation-based-voxelization.md)
Tessellation-based Voxelization is a GPU-accelerated method for generating 3D voxel grids from triangle meshes by leveraging the hardware tessellation pipeline to subdivide geometry before rasterization. It differs from fixed-function or CPU-based voxelizers by enabling adaptive triangle density and displacement mapping during the generation phase, allowing for higher fidelity in complex regions.

### Fake Voxelization via Triangle-Cube Intersection
Fake Voxelization via Triangle-Cube Intersection is a voxelization approach that voxelize every triangle of a mesh independently, checking for intersection between each triangle and axis-aligned cubes (voxels). It produces a surface representation rather than a solid interior fill, avoiding complex Constructive Solid Geometry (CSG) operations [S3, unofficial]. The naive implementation iterates through every triangle and every cube in the bounding volume, marking cubes as full if an intersection is detected [S3, unofficial]. Optimization involves limiting the cube iteration to the bounding box of each triangle [S3, unofficial].

## Operating characteristics
*   **Time Complexity:** $O(N_v \cdot N_t)$, where $N_v$ is the number of voxels and $N_t$ is the number of triangles. This is because every voxel potentially checks every triangle [S2, unofficial].
*   **Memory Complexity:** $O(N_v)$ for the voxel grid storage [S2, unofficial].
*   **Performance:** The method is computationally expensive for high-resolution grids due to the nested loops over voxels and triangles [S2, unofficial]. Parallelization (e.g., using tasks or GPU) can mitigate this, as voxel checks are independent [S2, unofficial].
*   **Strengths:** Exact geometric intersection; produces solid, watertight volumes suitable for physics or simulation [S1, unofficial].
*   **Limitations:** Slow for large meshes or high resolutions without acceleration structures (like BVH or grids) to cull triangle checks [S2, unofficial]. The scanline fill adds complexity and assumes manifold geometry [S1, unofficial].
*   **When to use:** When exact solid voxelization is required and mesh complexity is moderate [S1, unofficial].
*   **When not to use:** For very large meshes or real-time applications where performance is critical; consider rasterization-based or sparse methods instead [S1, S2, unofficial].

## Background
The method was described by David Rosen in a 2012 Game Developer article, outlining a two-step process for converting triangle meshes to voxel models for game development purposes, such as bone attachment [S1, unofficial]. An implementation in Unity using C# and the Separating Axis Theorem for intersection testing was published by @fukaken5050 in 2017, demonstrating the use of parallel tasks for performance [S2, unofficial]. The concept of "fake" voxelization via simple triangle-cube intersection was discussed on Stack Overflow in 2012 as a simpler alternative to CSG-based solid voxelization [S3, unofficial].
