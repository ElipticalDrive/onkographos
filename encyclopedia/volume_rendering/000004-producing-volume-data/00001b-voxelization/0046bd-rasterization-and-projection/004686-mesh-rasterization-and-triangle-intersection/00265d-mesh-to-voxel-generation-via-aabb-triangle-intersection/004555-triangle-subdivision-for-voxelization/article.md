# Triangle Subdivision for Voxelization

Also called: Adaptive Triangle Subdivision, Homogeneous Triangle Subdivision

## Overview
This method is a pre-processing step that sequentially consumes a triangle soup to apply a subdivision scheme, aiming to create triangles that are homogeneous regarding the number of voxels generated per triangle and the compactness of their Morton index range [S1]. It sets it apart from siblings by explicitly targeting the variance in voxel count and spatial locality (Morton index spread) to optimize subsequent out-of-core batch processing, rather than just geometric fidelity or simple coverage [S1].

## How it works
**Inputs and Outputs:**
*   **Input:** A triangle soup $\{T_i\}$, a maximum allowed ratio of projected bounding box area to voxel face area $K_{vox/tri}^{max}$, and the voxel edge length $L$ [S1].
*   **Output:** A refined set of triangles $\{T_i\}$ where each triangle satisfies the area constraint defined in Eq. 1 [S1].

**Data Structures:**
*   **Queue $Q$:** Stores triangles pending subdivision. Initially contains all input triangles.
*   **Result Set $R$:** Stores triangles that satisfy the stopping criterion. Initially empty.
*   **Triangle Object:** Contains vertices, edge lengths $T.a, T.b, T.c$ (sorted such that $T.a \le T.b \le T.c$), and methods for splitting/subdividing.

**Formulas:**
1.  **Voxel Face Area:** $A_{vox} = L^2$ [S1].
2.  **Stopping Criterion:** A triangle $T_i$ is accepted if its bounding box area $A_{bbox}(T_i)$ satisfies:
    $$ A_{bbox}(T_i) \le K_{vox/tri}^{max} \cdot A_{vox} \quad \text{(Eq. 1)} $$
3.  **Upper Bound of Voxels:** The maximum number of voxels generated by triangle $T_i$, denoted $N_{vox/tri}^{max}(T_i)$, is determined by discretizing the projected bounding box of the triangle to voxel resolution to count enclosed projected voxels, then multiplying by 3 (since a planar triangle creates a maximum of three voxels along the projection direction) [S1].

**Parameters:**
*   $K_{vox/tri}^{max}$: User-defined parameter representing the maximum allowed ratio of projected bounding box area to voxelface area for a triangle before subdivision is required [S1].
*   $L$: Length of a voxel edge [S1].

**Algorithm Steps:**
1.  Initialize $A_{vox} \leftarrow L^2$.
2.  Initialize Queue $Q$ with all input triangles $\{T_i\}$.
3.  Initialize Result Set $R$ as empty.
4.  While $Q$ is not empty:
    a. Dequeue triangle $T$ from $Q$.
    b. Calculate $A_{bbox}(T)$.
    c. If $A_{bbox}(T) \le K_{vox/tri}^{max} \cdot A_{vox}$:
        i. Enqueue $T$ into $R$.
    d. Else:
        i. Sort edges of $T$ such that $T.a \le T.b \le T.c$.
        ii. Apply subdivision logic based on edge lengths:
            *   **Case 1:** If $T.a \le T.b \le T.c$ and $(T.a + T.b) < 2 \cdot T.c$:
                *   This handles long thin triangles with angles larger than $\sim 90^\circ$.
                *   Split triangle $T$ into two triangles.
                *   Append the resulting triangles to $Q$.
            *   **Case 2:** If $T.a \le T.b \le T.c$ and $3 \cdot T.a < T.b$:
                *   This handles long thin triangles with angles smaller than $\sim 20^\circ$.
                *   Subdivide $T$ to generate approximately equilateral triangles by cutting the short edge $T.a$ off the long edges and splitting the resulting quadrilateral.
                *   Append the resulting triangles to $Q$.
            *   **Case 3 (Regular):** Otherwise:
                *   Subdivide $T$ directly such that it fulfills Eq. 1.
                *   Compute the subdivision factor as $\sqrt{A_{bbox}(T) / (K_{vox/tri}^{max} \cdot A_{vox})}$.
                *   Enqueue the resulting triangles into $R$.
5.  Set $\{T_i\} \leftarrow R$. The resulting set of triangles satisfies Eq. 1 [S1].

**Pseudocode:**

```python
def triangle_subdivision(triangles, K_max, L):
    """
    Subdivides triangles to ensure homogeneous voxel generation and Morton index compactness.
    
    Args:
        triangles: List of Triangle objects.
        K_max: Maximum allowed ratio of projected bounding box area to voxel face area.
        L: Voxel edge length.
        
    Returns:
        List of subdivided Triangle objects satisfying the area constraint.
    """
    A_vox = L * L
    Q = list(triangles)  # Queue of triangles to process
    R = []              # Result list of accepted triangles
    
    while Q:
        T = Q.pop(0)  # Dequeue
        
        # Calculate bounding box area of T
        # Note: Implementation detail for A_bbox depends on triangle representation.
        # Assuming T has a method or property to compute bounding box area.
        A_bbox = T.get_bbox_area()
        
        if A_bbox <= K_max * A_vox:
            R.append(T)
        else:
            # Sort edges: a <= b <= c
            edges = sorted(T.get_edge_lengths())
            a, b, c = edges[0], edges[1], edges[2]
            
            if (a + b) < 2 * c:
                # Case 1: Long thin triangle, angles > ~90 degrees
                # Split into two triangles
                new_triangles = T.split()
                Q.extend(new_triangles)
            elif 3 * a < b:
                # Case 2: Long thin triangle, angles < ~20 degrees
                # Subdivide to generate approximately equilateral triangles
                new_triangles = T.subdivide_equilateral()
                Q.extend(new_triangles)
            else:
                # Case 3: Regular triangle
                # Subdivide directly to meet area constraint
                # Subdivision factor = sqrt(A_bbox / (K_max * A_vox))
                factor = (A_bbox / (K_max * A_vox)) ** 0.5
                new_triangles = T.regular_subdivide(factor)
                R.extend(new_triangles)
                
    return R
```

**Edge Cases and Pitfalls:**
*   **Precision:** The comparison $(T.a + T.b) < 2 \cdot T.c$ and $3 \cdot T.a < T.b$ relies on floating-point arithmetic. Degenerate triangles (zero area) should be handled or filtered out before processing [S1].
*   **Boundaries:** The subdivision logic assumes a valid triangle with non-zero area. If $A_{bbox}(T)$ is calculated incorrectly, the loop may not terminate or may produce invalid triangles [S1].
*   **Morton Index Compactness:** The primary goal is to minimize $(m_{max}(T_i) - m_{min}(T_i)) / N_{vox/tri}(T_i)$. If subdivision is too aggressive, the number of triangles increases significantly, potentially impacting memory overhead for the Morton queue [S1].

## Operating characteristics
*   **Time Complexity:** Linear in the number of triangles, but with a multiplier depending on the subdivision depth required to satisfy Eq. 1. The subdivision process is sequential on the CPU [S1].
*   **Memory Complexity:** Proportional to the number of triangles after subdivision. The subdivision increases the triangle count, which must be stored in $Q$ and $R$ [S1].
*   **Measured Performance:** Not given in the sources.
*   **Scaling:** The method is designed to work with out-of-core voxelization, where batches of triangles are processed to prevent memory overflow. The subdivision ensures that each batch has a predictable number of voxels, aiding in memory management [S1].
*   **Strengths:** Homogenizes voxel count per triangle, improving GPU utilization. Compact Morton indices reduce fragmentation in the out-of-core queue [S1].
*   **Limitations:** Sequential CPU processing may become a bottleneck for very large meshes. The subdivision logic is specific to the criteria of voxel count and Morton index compactness, not necessarily geometric accuracy [S1].
*   **When to use:** When performing out-of-core voxelization on GPU, where batch size and memory fragmentation are critical concerns.
*   **When not to use:** When real-time voxelization is required and CPU preprocessing is too slow, or when geometric fidelity is more important than voxel count homogeneity.

## Background
The method originates from the work on grid-free out-of-core voxelization to sparse voxel octrees on GPU [S1]. It was developed to address the challenges of processing large triangle soups on GPU by ensuring that batches of triangles are processed efficiently, with minimal memory fragmentation and optimal GPU utilization [S1]. The subdivision scheme is a key component in achieving homogeneous voxel generation, which is essential for the out-of-core processing pipeline [S1].
