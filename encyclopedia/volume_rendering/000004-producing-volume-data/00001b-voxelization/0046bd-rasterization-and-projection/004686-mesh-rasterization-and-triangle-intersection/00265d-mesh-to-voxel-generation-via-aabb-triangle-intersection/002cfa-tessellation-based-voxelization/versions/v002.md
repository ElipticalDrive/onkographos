# Tessellation-based Voxelization
Also called: VoxelizationByTessellationPass

## Overview
Tessellation-based Voxelization generates a 3D voxel grid from a triangle mesh by routing geometry through the hardware tessellation pipeline before rasterization [S1, unofficial]. It differs from fixed-function or CPU-based voxelizers by enabling adaptive triangle subdivision and displacement mapping during the generation phase [S1, unofficial].

## How it works
**Inputs and Outputs:**
- **Input:** A triangle mesh defined by an index buffer and vertex data [S1, unofficial].
- **Output:** A 3D voxel grid stored in a Unordered Access View (UAV), where each voxel stores occupancy or density information [S1, unofficial].

**Data Structures:**
The method relies on a Direct3D 12 pipeline layout named `PASS_VOXELIZE_TESS` [S1, unofficial]. The descriptor ranges are defined as follows:
- **Range 0:** Constant Buffer View (CBV), count 1, offset 0, flags `DATA_STATIC` [S1, unofficial].
- **Range 1:** Constant Buffer View (CBV), count 1, offset 0, flags `DATA_STATIC` [S1, unofficial].
- **Range 2:** Unordered Access View (UAV), count `numUAVs`, offset 0, flags `DATA_STATIC_WHILE_SET_AT_EXECUTE` [S1, unofficial].
- **Range 3:** Constant Buffer View (CBV), count 1, offset 0, flags `DATA_STATIC` [S1, unofficial].

**Numbered Steps:**
1. Bind the pipeline layout `PASS_VOXELIZE_TESS` with the descriptor ranges specified above [S1, unofficial].
2. Bind the pipeline state object configured with the vertex, hull, domain, and pixel shaders [S1, unofficial].
3. Set the primitive topology type to `CONTROL_POINT3_PATCHLIST` [S1, unofficial].
4. Force the instance count to 1 [S1, unofficial].
5. Execute the draw call `DrawIndexed(m_numIndices, instanceCount, 0, 0, 0)` [S1, unofficial].

## Subtopics

### Level 1 Triangle-Voxel Classification
A sibling method that classifies triangles against voxels using a simpler, non-tessellation approach. Choose this when hardware tessellation is unavailable or when the mesh is static and low-poly. See [Level 1 Triangle-Voxel Classification](4872-level-1-triangle-voxel-classification.md).

### Fake Voxelization via Triangle-Cube Intersection
A sibling method that approximates voxel coverage by intersecting triangles with axis-aligned cubes rather than performing exact subdivision. Choose this when performance is prioritized over geometric accuracy. See [Fake Voxelization via Triangle-Cube Intersection](6951-fake-voxelization-via-triangle-cube-intersection.md).

### Robust Mesh Voxelization via Exact Predicates
A sibling method that uses exact arithmetic predicates to avoid floating-point inaccuracies during triangle-voxel intersection tests. Choose this when numerical stability is critical for thin or degenerate geometry. See [Robust Mesh Voxelization via Exact Predicates](8770-robust-mesh-voxelization-via-exact-predicates.md).
