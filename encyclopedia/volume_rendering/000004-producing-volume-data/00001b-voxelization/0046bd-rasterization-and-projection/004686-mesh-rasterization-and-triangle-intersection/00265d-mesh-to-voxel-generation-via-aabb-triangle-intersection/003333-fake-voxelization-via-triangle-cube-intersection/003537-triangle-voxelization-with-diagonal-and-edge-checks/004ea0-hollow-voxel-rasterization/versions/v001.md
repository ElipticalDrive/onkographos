# Hollow Voxel Rasterization

Also called: Hollow Voxelization, Voxel Shell Calculation, hollow

## Overview
Hollow Voxel Rasterization is a fast, memory-efficient method for generating a voxel shell (hollow interior) from an arbitrary polyhedron, rather than a solid volume. It is specifically suited for shapes intended to be hollow or meshes with fine structures at low target resolutions. Unlike solid voxelization methods that fill the interior, this approach inverts the containment test: it marks a voxel as part of the mesh if any mesh face lies inside the voxel's bounding box, effectively capturing the surface geometry without occupying internal voxels.

## How it works
**Inputs and Outputs:**
- **Input:** An arbitrary polyhedron defined by a vertex array and an index buffer (triangles), and a target voxel grid dimension `dim` (`glm::ivec3`).
- **Output:** A 3D buffer of `uint8_t` values (`_voxels`) of size `dim`, where non-zero values indicate shell voxels. The output structure also retains the original polyhedron data.

**Data Structures:**
The output is encapsulated in a struct `raster_results<buffer3d<uint8_t>, mesh::polyhedron<base_t>>` containing:
- `_arr_dim`: The dimensions of the voxel grid (`glm::vec3`).
- `_voxels`: A 3D buffer of `uint8_t` representing the voxel shell.
- `_mesh`: The input `mesh::polyhedron<base_t>`, which contains `_vertices._vertex_arr` (positions) and `_indices._buffer` (triangle indices).

**Parameters:**
- `dim`: Target voxel grid dimensions. Used to scale the polyhedron and allocate the output buffer.

**Algorithm Steps:**

1.  **Normalization and Scaling:**
    Normalize the input polyhedron and scale it to fit the target voxel dimensions `dim`. This ensures the mesh coordinates align with the voxel grid.

2.  **Iteration Setup:**
    Iterate over each triangle face of the polyhedron. For each face, compute its 3D bounding box in voxel space:
    $$ l_{min} = \lfloor \min(\text{face vertices}) \rfloor - 0.5 $$
    $$ l_{max} = \lceil \max(\text{face vertices}) \rceil + 0.5 $$
    $$ l_{steps} = l_{max} - l_{min} $$
    Shift the face vertices relative to $l_{min}$ to work in local bounding box coordinates.

3.  **Voxel Loop:**
    Iterate over all voxels within the computed bounding box using three nested loops for $x, y, z$ from $0$ to $l_{steps}.x/y/z$.
    Calculate global voxel coordinates:
    $$ n_x = x + l_{min}.x $$
    $$ n_y = y + l_{min}.y $$
    $$ n_z = z + l_{min}.z $$

4.  **Skip Check:**
    Check if the voxel at $(n_x, n_y, n_z)$ is already marked (non-zero). If it is, skip further processing for this voxel to avoid double-counting [S1, unofficial].

5.  **Shell Intersection Test:**
    Determine if the current face intersects the voxel hexahedron. This is done by checking if the face is inside the voxel's bounding box.
    - Calculate `half_box_size` = voxel size / 2.
    - Use a separating axis test (SAT) or similar geometric check (`face_in_hexahedron`) with a half-voxel offset to determine if the face penetrates the voxel volume [S1, unofficial].
    - If the test returns true, mark the voxel as a shell voxel (set `_voxels[n_x, n_y, n_z]` to a non-zero value, e.g., 1).

**Pseudocode:**

```python
def hollow_voxel_rasterization(polyhedron, dim):
    """
    polyhedron: object with _vertices._vertex_arr (list of vec3) and _indices._buffer (list of ints)
    dim: tuple (x, y, z) of integers
    Returns: 3D array of uint8_t
    """
    # 1. Normalize and scale polyhedron to dim
    # Implementation detail: scale vertices so they fit within [0, dim]
    scaled_vertices = normalize_and_scale(polyhedron._vertices._vertex_arr, dim)
    
    # Initialize output buffer
    voxels = zeros(dim, dtype=uint8)
    
    # Get indices stride (typically 3 for triangles)
    stride = polyhedron._indices._stride
    
    # 2. Iterate over each face
    num_faces = len(polyhedron._indices._buffer) // stride
    for face_id in range(num_faces):
        # Retrieve vertex indices for the current triangle
        idx_start = face_id * stride
        vid1 = polyhedron._indices._buffer[idx_start]
        vid2 = polyhedron._indices._buffer[idx_start + 1]
        vid3 = polyhedron._indices._buffer[idx_start + 2]
        
        # Get vertex positions
        v1 = scaled_vertices[vid1]
        v2 = scaled_vertices[vid2]
        v3 = scaled_vertices[vid3]
        
        # 3. Compute bounding box in voxel space
        min_coords = floor(min(v1, v2, v3)) - 0.5
        max_coords = ceil(max(v1, v2, v3)) + 0.5
        steps = max_coords - min_coords
        
        # 4. Iterate over voxels in bounding box
        for x in range(steps.x):
            for y in range(steps.y):
                for z in range(steps.z):
                    nx = x + min_coords.x
                    ny = y + min_coords.y
                    nz = z + min_coords.z
                    
                    # Skip if already marked
                    if voxels[nx, ny, nz] != 0:
                        continue
                    
                    # 5. Test if face is inside voxel bounding box
                    # Voxel center is at (nx + 0.5, ny + 0.5, nz + 0.5) assuming unit voxels
                    # half_box_size is 0.5 for unit voxels
                    half_box_size = 0.5
                    voxel_center = vec3(nx + 0.5, ny + 0.5, nz + 0.5)
                    
                    if face_in_hexahedron(v1, v2, v3, voxel_center, half_box_size):
                        voxels[nx, ny, nz] = 1
                        
    return voxels

def face_in_hexahedron(v1, v2, v3, voxel_center, half_box_size):
    """
    Checks if a triangle face is inside the voxel hexahedron defined by center and half_size.
    Uses Separating Axis Theorem (SAT) logic as described in sources.
    """
    # Define edges
    e0 = v2 - v1
    e1 = v3 - v2
    e2 = v1 - v3
    
    # Define vectors from voxel center to vertices
    p1 = v1 - voxel_center
    p2 = v2 - voxel_center
    p3 = v3 - voxel_center
    
    # Test axes: normals of faces (X, Y, Z) and cross products of edges
    
    # Face normals (X, Y, Z axes)
    # Check if all vertices are on one side of a plane outside the voxel
    # e.g., if all x > max_x or all x < min_x
    max_x = voxel_center.x + half_box_size.x
    min_x = voxel_center.x - half_box_size.x
    if all(v.x >= max_x for v in [v1, v2, v3]): return False
    if all(v.x <= min_x for v in [v1, v2, v3]): return False
    
    max_y = voxel_center.y + half_box_size.y
    min_y = voxel_center.y - half_box_size.y
    if all(v.y >= max_y for v in [v1, v2, v3]): return False
    if all(v.y <= min_y for v in [v1, v2, v3]): return False
    
    max_z = voxel_center.z + half_box_size.z
    min_z = voxel_center.z - half_box_size.z
    if all(v.z >= max_z for v in [v1, v2, v3]): return False
    if all(v.z <= min_z for v in [v1, v2, v3]): return False
    
    # Edge axes (cross products of edges with coordinate axes)
    # This part corresponds to the axis_test functions in the source
    # For brevity, we assume a generic SAT check for triangle vs box
    
    # Check cross products of edges with X, Y, Z axes
    axes = []
    for edge in [e0, e1, e2]:
        axes.append(cross(edge, vec3(1, 0, 0)))
        axes.append(cross(edge, vec3(0, 1, 0)))
        axes.append(cross(edge, vec3(0, 0, 1)))
        
    for axis in axes:
        if axis == vec3(0,0,0): continue # Skip degenerate axes
        
        # Project triangle and box onto axis
        # Triangle projection
        proj_min = dot(v1, axis)
        proj_max = proj_min
        for v in [v2, v3]:
            p = dot(v, axis)
            if p < proj_min: proj_min = p
            if p > proj_max: proj_max = p
            
        # Box projection
        # Box corners are voxel_center +/- half_box_size
        # Project all 8 corners or use formula: center_proj +/- sum(|half_size * axis|)
        center_proj = dot(voxel_center, axis)
        extent = abs(axis.x * half_box_size.x) + abs(axis.y * half_box_size.y) + abs(axis.z * half_box_size.z)
        
        box_min = center_proj - extent
        box_max = center_proj + extent
        
        # Check for separation
        if proj_max < box_min or proj_min > box_max:
            return False
            
    return True
```

**Edge Cases and Pitfalls:**
- **Double-counting:** Voxels intersected by multiple faces are marked only once. The check `if voxels[nx, ny, nz] != 0` prevents redundant processing [S1, unofficial].
- **Precision:** Floating-point precision in bounding box calculations and intersection tests can lead to gaps or overlaps in the shell, especially at low resolutions.
- **Degenerate Input:** Triangles with zero area or collinear vertices may cause issues in the intersection test. The source implies robust handling via the SAT approach, but degenerate cases should be filtered or handled explicitly [G].

## Operating characteristics
- **Time Complexity:** $O(F \cdot V_{local})$, where $F$ is the number of faces and $V_{local}$ is the average number of voxels in the bounding box of a face. In the worst case, this is $O(F \cdot N^3)$, but typically much less due to bounding box culling.
- **Memory Complexity:** $O(N^3)$ for the output voxel buffer, where $N$ is the grid dimension. This is significantly less than solid voxelization if the interior is not stored, but the buffer size is fixed by $N$.
- **Performance:** On an Intel i7 4770k (4 physical cores), rasterizing a Stanford Bunny mesh (112k faces) at $1024^3$ resolution takes 1956 ms in `--hollow` mode [S1, unofficial].
- **Scaling:** Performance scales linearly with the number of faces and cubically with resolution. The `--hollow` mode is consistently faster than `--fast` (solid) mode at higher resolutions (e.g., 1956 ms vs 2918 ms at $1024^3$) [S1, unofficial].
- **Strengths:** Very fast, memory-efficient for shell-only representations, suitable for fine structures at low resolutions.
- **Limitations:** Does not provide interior volume data. Accuracy depends on resolution; fine details may be lost if the voxel grid is too coarse.
- **When to use:** When only the surface shell is needed, or for meshes with fine structures where solid voxelization would be too memory-intensive.
- **When not to use:** When interior volume information is required, or for high-fidelity solid models.

## Background
Hollow Voxel Rasterization is implemented in the `3DStuff/voxelizer` project [S1, unofficial]. It is presented as an alternative to solid voxelization methods (`--fast`, `--safe`), offering a trade-off between performance and memory usage. The method is particularly useful for applications where the interior of the voxelized object is not needed, such as in certain rendering or simulation contexts where only the surface geometry matters.
