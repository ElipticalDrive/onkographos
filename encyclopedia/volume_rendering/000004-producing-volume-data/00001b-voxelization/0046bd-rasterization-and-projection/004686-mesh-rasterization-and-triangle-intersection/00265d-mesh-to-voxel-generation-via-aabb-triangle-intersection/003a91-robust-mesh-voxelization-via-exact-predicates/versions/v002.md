# Robust Mesh Voxelization via Exact Predicates

Also called: Mesh-Native Voxelization with Exact Predicates, add-voxelization, cmg::voxelize, cmg::voxelize::voxelize, mesh-native voxelizer, voxelize(PLC, opts)

## Overview
A mesh-native voxelizer that produces an occupancy grid or a signed-distance field (SDF) over a Piecewise Linear Complex (PLC)'s bounding box, using exact-predicate classification to avoid epsilon-ray speckle [S1, unofficial][S2]. Unlike approximate ray-casting methods, this method uses Shewchuk's exact predicates for geometric calculations to ensure robust classification of watertight meshes in single precision [S2]. It differs from CAD kernels like OCCT by classifying against the input tessellation rather than exact analytic surfaces, meaning fidelity is bounded by the input faceting accuracy [S1, unofficial][S2].

## How it works
**Inputs and Outputs:**
*   **Input:** A Piecewise Linear Complex (PLC), defined as a triangle mesh [S2].
*   **Parameters:**
    *   `resolution`: Grid density (default 64) [S1, unofficial].
    *   `mode`: Output type, either "occupancy" or "sdf" [S1, unofficial].
    *   `pad`: Boundary padding value (default 1) [S1, unofficial].
*   **Output:** A `VoxelGrid` data structure containing `origin`, `spacing`, `dims`, and `data` [S2]. The `data` is exposed as a NumPy array with shape `(nx, ny, nz)` and dtype `uint8` for occupancy or `float32` for SDF [S1, unofficial][S2].

**Data Structures:**
*   **CarveGrid:** A boundary-triangle spatial index used for xy-projection bucketing and spatial queries [S2].
*   **VoxelGrid:** Contains `origin` (3D vector), `spacing` (scalar), `dims` (3D integer vector), and `data` (1D array reshaped to 3D) [S2].

**Algorithm Steps:**
1.  **Initialization:** Compute the bounding box of the input PLC [G]. Determine grid dimensions `(nx, ny, nz)` based on `resolution` and bounding box size [G]. Initialize the `VoxelGrid` with `origin`, `spacing`, and `dims` [S1, unofficial][S2].
2.  **Spatial Indexing:** Build the `CarveGrid` spatial index from the input triangles to bucket them by xy-projection [S2].
3.  **Column Processing:** Iterate over each xy-column `(x, y)` in the grid [G]. Retrieve the list of triangles intersecting the column's xy-projection from `CarveGrid` [S1, unofficial][S2].
4.  **Exact-Predicate Classification:** For each column, cast a vertical scanline [G]. Count crossings against the fan-triangulated boundary using `cmg::robust::orient3d` [S1, unofficial]. The predicate determines plane-side sign change and matching edge orientations [S1, unofficial]. If `orient3d` returns exactly 0 (grazing case), apply a deterministic `(x, y)` nudge to the scanline to ensure robustness [S1, unofficial].
5.  **Occupancy Calculation:** A cell is inside if an odd number of crossings lie above its center [S1, unofficial].
6.  **SDF Calculation:** If `mode` is "sdf", compute the exact point-to-triangle distance for each cell center using Ericson's method [S1, unofficial]. Sign the distance by the parity (negative inside, positive outside) [S1, unofficial].
7.  **Output:** Return the populated `VoxelGrid` [S2].

**Pseudocode:**
```python
import numpy as np
from typing import List, Tuple

class VoxelGrid:
    def __init__(self, origin: np.ndarray, spacing: float, dims: Tuple[int, int, int], data: np.ndarray):
        self.origin = origin
        self.spacing = spacing
        self.dims = dims
        self.data = data

def orient3d(ax: float, ay: float, az: float, bx: float, by: float, bz: float, cx: float, cy: float, cz: float, dx: float, dy: float, dz: float) -> int:
    """Shewchuk's exact predicate determinant for 3D orientation [G]."""
    det = (dx - ax) * ((by - ay) * (cz - az) - (bz - az) * (cy - ay)) - \
          (dy - ay) * ((bx - ax) * (cz - az) - (bz - az) * (cx - ax)) + \
          (dz - az) * ((bx - ax) * (cy - ay) - (by - ay) * (cx - ax))
    return 1 if det > 0 else (-1 if det < 0 else 0)

def point_triangle_distance(p: np.ndarray, tri: np.ndarray) -> float:
    """Ericson's exact point-to-triangle distance [G]."""
    v0, v1, v2 = tri[0], tri[1], tri[2]
    e1 = v1 - v0
    e2 = v2 - v0
    d = p - v0
    a = np.dot(e1, e1)
    b = np.dot(e1, e2)
    c = np.dot(e2, e2)
    d1 = np.dot(e1, d)
    d2 = np.dot(e2, d)
    det = a * c - b * b
    u, v = 0.0, 0.0
    if det <= 1e-9:
        u = max(0, d1 / a) if a > 1e-9 else 0
        v = max(0, d2 / c) if c > 1e-9 else 0
    else:
        u = (c * d1 - b * d2) / det
        v = (a * d2 - b * d1) / det
    u = max(0, min(1, u))
    v = max(0, min(1, v))
    closest = v0 + u * e1 + v * e2
    return float(np.linalg.norm(p - closest))

def voxelize(plc_triangles: List[np.ndarray], resolution: int = 64, mode: str = "occupancy", pad: int = 1) -> VoxelGrid:
    # 1. Compute bounding box and dimensions
    all_verts = np.vstack(plc_triangles)
    bbox_min = all_verts.min(axis=0)
    bbox_max = all_verts.max(axis=0)
    dims = np.array([resolution, resolution, resolution], dtype=int)
    origin = bbox_min
    spacing = (bbox_max - bbox_min) / dims

    # 2. Initialize output grid
    data = np.zeros(dims, dtype=np.uint8 if mode == "occupancy" else np.float32)

    # 3. Bucket triangles by xy-projection (CarveGrid simulation)
    col_triangles = [[[] for _ in range(dims[1])] for _ in range(dims[0])]
    for tri in plc_triangles:
        min_x = int(np.floor((np.min(tri[:, 0]) - origin[0]) / spacing[0]))
        max_x = int(np.floor((np.max(tri[:, 0]) - origin[0]) / spacing[0]))
        min_y = int(np.floor((np.min(tri[:, 1]) - origin[1]) / spacing[1]))
        max_y = int(np.floor((np.max(tri[:, 1]) - origin[1]) / spacing[1]))
        for x in range(min_x, max_x + 1):
            for y in range(min_y, max_y + 1):
                if 0 <= x < dims[0] and 0 <= y < dims[1]:
                    col_triangles[x][y].append(tri)

    # 4. Process columns
    for x in range(dims[0]):
        for y in range(dims[1]):
            cx = origin[0] + (x + 0.5) * spacing[0]
            cy = origin[1] + (y + 0.5) * spacing[1]
            crossings = 0
            nudge = 0.0

            for tri in col_triangles[x][y]:
                p1, p2, p3 = tri
                n = np.cross(p2 - p1, p3 - p1)
                denom = n[2]
                if abs(denom) < 1e-9:
                    continue
                ray_t = (n[0] * (p1[0] - cx) + n[1] * (p1[1] - cy)) / denom
                if ray_t < 0:
                    continue

                # Check if intersection point is inside triangle using orient3d
                o1 = orient3d(cx, cy, 0, cx, cy, ray_t, p1[0], p1[1], p1[2], p2[0], p2[1], p2[2])
                o2 = orient3d(cx, cy, 0, cx, cy, ray_t, p2[0], p2[1], p2[2], p3[0], p3[1], p3[2])
                o3 = orient3d(cx, cy, 0, cx, cy, ray_t, p3[0], p3[1], p3[2], p1[0], p1[1], p1[2])

                # Handle grazing cases with deterministic nudge
                if o1 == 0 or o2 == 0 or o3 == 0:
                    nudge = 1e-7
                    o1 = orient3d(cx + nudge, cy, 0, cx + nudge, cy, ray_t, p1[0], p1[1], p1[2], p2[0], p2[1], p2[2])
                    o2 = orient3d(cx + nudge, cy, 0, cx + nudge, cy, ray_t, p2[0], p2[1], p2[2], p3[0], p3[1], p3[2])
                    o3 = orient3d(cx + nudge, cy, 0, cx + nudge, cy, ray_t, p3[0], p3[1], p3[2], p1[0], p1[1], p1[2])

                if o1 > 0 and o2 > 0 and o3 > 0:
                    crossings += 1

            is_inside = (crossings % 2) == 1

            # 5 & 6. Fill grid
            for z in range(dims[2]):
                if mode == "occupancy":
                    data[x, y, z] = 1 if is_inside else 0
                else:
                    vz = origin[2] + (z + 0.5) * spacing[2]
                    center = np.array([cx, cy, vz])
                    dist = point_triangle_distance(center, tri)
                    data[x, y, z] = -dist if is_inside else dist

    return VoxelGrid(origin, spacing, tuple(dims), data)
```

**Edge Cases and Pitfalls:**
*   **Grazing Cases:** When `orient3d` returns exactly 0, a deterministic `(x, y)` nudge must be applied to the scanline to avoid ambiguity [S1, unofficial].
*   **Curved Inputs:** The method only sees the triangle mesh, so curved inputs (e.g., from STEP/IGES) are only as accurate as their faceting [S1, unofficial][S2].
*   **Non-Watertight Input:** The method does not handle non-watertight input; it assumes a watertight PLC [S1, unofficial].

## Operating characteristics
*   **Time Complexity:** Approximately $O(\text{cells} + \text{triangles})$ due to bucketing triangles by xy-projection [S1, unofficial].
*   **Memory Complexity:** Proportional to the number of voxels in the grid, $O(nx \cdot ny \cdot nz)$ [S1, unofficial][S2].
*   **Performance:** Fast, parallel spatial-grid classifier [S2].
*   **Strengths:** Robust classification in single precision, no epsilon-ray speckle, mesh-native (no CAD dependency) [S1, unofficial][S2].
*   **Limitations:** Fidelity bounded by input tessellation, does not handle B-Rep/exact-surface voxelization, does not heal non-watertight input [S1, unofficial][S2].
*   **When to Use:** When robust voxelization of a triangle mesh is required, especially in single precision, and CAD kernel integration is not desired [S2].
*   **When Not to Use:** When exact curved-surface fidelity is required (use OCCT instead) [S1, unofficial][S2].

## Background
Proposed by leonardoaraujosantos in Pull Request #20 to the CyberdyneCorp/CyberMeshGenerator repository on July 4, 2026 [S2]. The method is part of the CyberMeshGenerator (cmg) library, a modern C++20 library for generating tetrahedral meshes [S2]. It was designed to provide a mesh-native voxelizer that reuses existing point-in-solid classifiers and spatial indices within the cmg ecosystem [S2]. The method explicitly positions itself against OCCT, noting that while OCCT provides exact curved-surface fidelity, cmg offers speed, smaller footprint, and better integration with meshing tools [S1, unofficial][S2].
