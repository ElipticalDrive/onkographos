# Hierarchical Inside/Outside Propagation

Also called: Solid Voxelization Propagation, X-Direction Bit Flip Propagation

## Overview
After level-0 voxelization, the method hierarchically propagates bit flips in the +x direction to achieve a solid voxelization [S1, S2]. It resolves inconsistencies between adjacent nodes by aggregating boundary crossings up the octree hierarchy and then distributing the final inside/outside status downward [S1, S2].

## How it works
### Inputs and Outputs
*   **Input**: An octree where level-0 nodes have been voxelized (bits set for occupied voxels) [S1, S2].
*   **Output**: The `inside` flag of every node is correctly set [S1, S2]. A level-$i$ node without children is inside the solid object if its `inside` flag is set, and outside otherwise [S1, S2].

### Data Structures
*   **Node**:
    *   `level`: Integer, $0 \le level \le L_{max}$.
    *   `inside`: Boolean, initialized to zero/false [S1, S2].
    *   `flip`: Boolean, used only for levels $>0$, initialized to zero/false [S1, S2].
    *   `children`: Array of 8 child nodes (if not leaf) [S1, S2].
    *   `x_neighbor`: Pointer to the immediate +x neighbor node at the same level (if it exists) [S1, S2].
    *   `-x_neighbor`: Pointer to the immediate -x neighbor node at the same level (if it exists) [G].
    *   `sg_voxels`: Bitmask or array of 64 bits for level-0 nodes [S1, S2].
    *   `index`: Integer identifier for parity checks [G].

### Steps
1.  Initialize `inside` and `flip` flags to zero/false for all nodes [S1, S2].
2.  Loop over all (even-indexed) level-0 nodes in parallel, identifying those with no level-0 -x neighbor (head nodes) [S1, S2].
3.  Starting at head nodes, navigate along the +x-neighbor pointers, propagating bit flips to the next node [S1, S2]. If the last bit in a level-0 node's SG voxel column is set, all SG voxels in the same column belonging to nodes in +x direction must be flipped [S1, S2].
4.  At the end of node strings where no more level-0 nodes abut, all four level-0 nodes with the same level-1 parent have all their SG voxels with local x index 3 in agreement [S1, S2].
5.  Propagate flip information to level-1 parent nodes: keep a `flip` propagation flag and an `inside` flag for each level-1 node, initializing both to zero [S1, S2]. If a level-1 node's child is at the end of an x-linked node string and its SG voxels with local x index 3 are set, set the flip flag [S1, S2].
6.  Propagate flip information along x-linked level-1 node strings, starting at level-1 head nodes [S1, S2]. If a node's flip flag is set, flip both the flip and the inside flag of its +x neighbor [S1, S2].
7.  Propagation to the next coarser level and then within this level is performed analogously for the remaining levels [S1, S2].
8.  Propagate the inside flag information from the top level down to the level-0 nodes [S1, S2]. For each node of level $i$ that has its inside flag set and has children, flip these child nodes' inside flags or their SG voxels, respectively [S1, S2].
9.  A level-$i$ node without children is inside the solid object if its inside flag is set, and outside otherwise [S1, S2].

### Pseudocode
```python
def hierarchical_inside_outside_propagation(nodes):
    """
    Propagates inside/outside status hierarchically according to [S1, S2].
    nodes: list of node objects with attributes: level, inside, flip, x_neighbor, -x_neighbor, 
           children, sg_voxels, index.
    """
    # Step 1: Initialize flags
    for node in nodes:
        node.inside = False
        if node.level > 0:
            node.flip = False

    # Step 2 & 3: Level-0 Flip Propagation
    for node in nodes:
        if node.level == 0 and node.index % 2 == 0 and node.x_neighbor is None:
            current = node
            while current is not None:
                # Check if last bit in SG voxel column (local x index 3) is set
                # Assumes x is the fastest varying dimension; bit 3 corresponds to x=3 [G]
                if (current.sg_voxels >> 3) & 1:
                    if current.x_neighbor is not None:
                        current.x_neighbor.inside = not current.x_neighbor.inside
                current = current.x_neighbor

    # Step 4 & 5: Aggregation to Level-1
    for node in nodes:
        if node.level == 1:
            node.flip = False
            for child in node.children:
                if child.level == 0 and child.x_neighbor is None and (child.sg_voxels >> 3) & 1:
                    node.flip = True
                    break

    # Step 6: Level-1 Flip Propagation
    for node in nodes:
        if node.level == 1 and node.x_neighbor is None:
            current = node
            while current is not None:
                if current.flip:
                    if current.x_neighbor is not None:
                        current.x_neighbor.flip = not current.x_neighbor.flip
                        current.x_neighbor.inside = not current.x_neighbor.inside
                current = current.x_neighbor

    # Step 7: Repeat for higher levels
    max_level = max(n.level for n in nodes)
    for level in range(1, max_level):
        # Aggregate flip from level+1 to level
        for node in nodes:
            if node.level == level:
                node.flip = False
                for child in node.children:
                    if child.level == level + 1 and child.x_neighbor is None and child.flip:
                        node.flip = True
                        break
        # Propagate flip within level
        for node in nodes:
            if node.level == level and node.x_neighbor is None:
                current = node
                while current is not None:
                    if current.flip:
                        if current.x_neighbor is not None:
                            current.x_neighbor.flip = not current.x_neighbor.flip
                            current.x_neighbor.inside = not current.x_neighbor.inside
                    current = current.x_neighbor

    # Step 8: Downward Inside Propagation
    root = next(n for n in nodes if n.level == max_level)
    stack = [root]
    while stack:
        node = stack.pop()
        if node.children is not None:
            for child in node.children:
                if node.inside:
                    if child.level == 0:
                        # Flip SG voxels directly for leaves [S1, S2]
                        child.sg_voxels ^= 0xFFFFFFFFFFFFFFFF
                    else:
                        # Flip inside flag for internal nodes [S1, S2]
                        child.inside = not child.inside
                stack.append(child)
```

### Parameters and Edge Cases
*   **Bit Packing**: The definition of "last bit in SG voxel column" depends on the bit packing order. The sources do not specify the exact bit layout, only that it corresponds to local x index 3 [S1, S2]. Implementers must align the bit mask with their voxelization's packing scheme [G].
*   **Boundary Conditions**: Nodes at the boundary of the voxelization domain may not have +x or -x neighbors. The algorithm handles this by checking for `None` pointers before traversal or flag updates [S1, S2].
*   **Parallelism**: The identification of head nodes and the traversal of x-linked strings can be parallelized across level-0 nodes [S1, S2].

## Operating characteristics
*   **Time Complexity**: Linear in the number of octree nodes, $O(N)$, as each node is visited a constant number of times during upward aggregation and downward propagation [S1, S2].
*   **Memory Complexity**: $O(N)$ for storing the octree structure and the `inside`/`flip` flags [S1, S2].
*   **Strengths**: Highly parallelizable on GPUs; avoids per-voxel ray queries for consistency by relying on local neighbor relationships and hierarchical aggregation [S1, S2].
*   **Limitations**: Requires x-linked neighbor pointers, which increase memory overhead; correctness depends on the initial level-0 voxelization and accurate head-node identification [S1, S2].

## Background
The method was introduced in the 2010 paper "Fast Parallel Surface and Solid Voxelization on GPUs" by Michael Schwarz et al. [S1, S2]. It serves as a post-processing consistency step within a broader GPU-based voxelization framework that initially determines solid/empty status via ray casting and refines it through hierarchical bit-flip propagation [S1, S2].
