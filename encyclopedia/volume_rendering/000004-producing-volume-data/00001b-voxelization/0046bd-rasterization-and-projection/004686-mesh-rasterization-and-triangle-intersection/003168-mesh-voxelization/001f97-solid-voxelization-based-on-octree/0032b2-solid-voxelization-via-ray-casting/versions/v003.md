# Solid Voxelization via Ray Casting
## Overview
A method to convert a triangle mesh into a solid voxel representation (octree) by casting rays through the mesh to determine occupied voxel intervals along the Z-axis [S1, unofficial]. It differs from sibling methods by explicitly computing solid intervals per pixel via ray-mesh intersection rather than relying solely on spatial partitioning pruning or robust topological checks for inside/outside status [S1, unofficial].

## How it works
**Inputs and outputs:**
- Input: Triangle mesh, voxel resolution `res`, camera rotation matrix `M` [S1, unofficial].
- Output: A set of solid voxel segments (intervals along Z) for each `(x, y)` coordinate in the voxel grid [S1, unofficial].

**Data structures:**
- `segment_cache`: A local list of segments `{x, y, z_min, z_max}` for the current block [S1, unofficial].
- `segments`: A global vector of segments for the final output [S1, unofficial].
- `curr_block`: An atomic counter for work distribution [S1, unofficial].

**Parameters:**
- `res`: Voxel resolution (e.g., $2^{\text{voxelization\_level}}$) [S1, unofficial].
- `block_size`: Maximum block dimension for parallel processing, typically 16 pixels [S1, unofficial].
- `scale`: Grid scaling factor, calculated as $2.0 / \text{res}$ [S1, unofficial].
- `eps`: Epsilon for ray marching to prevent self-intersection, calculated as $\max(\text{scale} / 64.0, 1\text{e-}5)$ [S1, unofficial].

**Steps:**
1. Initialize a thread pool with `num_workers = std::thread::hardware_concurrency()` and a shared atomic counter `curr_block = 0` [S1, unofficial].
2. Calculate grid parameters: `scale = 2.0f / res`, `eps = max(scale / 64.0f, 1e-5f)`, `block_size = min(res, 16u)`, `blocks_per_edge = (res + block_size - 1u) / block_size` [S1, unofficial].
3. For each worker thread, loop over blocks using `curr_block++` [S1, unofficial]. For each block:
   - Determine `x_offset` and `y_offset` based on the block index [S1, unofficial].
   - Iterate `y` from `y_offset` to `y_offset + block_size` and `x` from `x_offset` to `x_offset + block_size` [S1, unofficial].
   - Construct ray origin `ray_hit.ray.o` by transforming $(dx, dy, 2.0f, 1.0f)$ with matrix $M$, where $dx = (x + 0.5f) \times \text{scale} - 1.0f$ and $dy = (y + 0.5f) \times \text{scale} - 1.0f$ [S1, unofficial].
   - Set ray direction `ray_dir = glm::mat3{M} * glm::vec3{0.0f, 0.0f, -1.0f}` [S1, unofficial].
   - Enter an infinite loop to find intersections:
     - Set `ray_hit.ray.t_min = ray_hit.ray.t_max + eps` and `ray_hit.ray.t_max = infinity` [S1, unofficial].
     - Call `mesh.trace_closest(&ray_hit)` [S1, unofficial].
     - If `ray_hit.hit.geom_id == EmbreeHit::invalid` (ray exits scene):
       - Check if `counter > 0`. If so, create a segment from `t_start` to current exit, clamp Z to $[0, \text{res}-1]$, add to cache, and break loop [S1, unofficial].
     - If `c < 0.0f` (front face):
       - Increment `counter` and record `t_start = ray_hit.ray.t_max` [G].
     - If `c > 0.0f` (back face):
       - Decrement `counter` [S1, unofficial].
       - If `counter == 0`, a segment is closed:
         - Calculate $z\_range = (1.5f - \text{glm::vec2}\{\text{ray\_hit.ray.t\_max}, t\_start\} \times 0.5f) \times \text{res\_f}$ [S1, unofficial].
         - Clamp $z$ to $[0, \text{res}-1]$ [S1, unofficial].
         - If $z.x \le z.y$, add segment $\{x, y, z.x, z.y\}$ to cache [S1, unofficial].
4. After processing all pixels in a block, lock mutex and copy `segment_cache` to global `segments` vector [S1, unofficial].

**Pseudocode:**
```python
import math
import threading
import os

# Global state
segments = []
segments_mutex = threading.Lock()
curr_block = 0
num_workers = os.cpu_count() or 1  # [G] Standard replacement for hardware_concurrency()

def process_block(block_idx, res, scale, eps, block_size, M, mesh):
    local_segments = []
    blocks_per_edge = (res + block_size - 1) // block_size
    x_block = block_idx % blocks_per_edge
    y_block = block_idx // blocks_per_edge
    x_offset = x_block * block_size
    y_offset = y_block * block_size

    for y in range(y_offset, min(y_offset + block_size, res)):
        for x in range(x_offset, min(x_offset + block_size, res)):
            dx = (x + 0.5) * scale - 1.0
            dy = (y + 0.5) * scale - 1.0
            point = [dx, dy, 2.0, 1.0]
            # Transform point with 4x4 matrix M
            ray_o = [sum(M[i][j] * point[j] for j in range(4)) for i in range(4)]
            # Extract 3x3 rotation part for direction
            rot_part = [M[i][j] for i in range(3) for j in range(3)]
            ray_dir = [
                rot_part[0]*0 + rot_part[1]*0 + rot_part[2]*(-1),
                rot_part[3]*0 + rot_part[4]*0 + rot_part[5]*(-1),
                rot_part[6]*0 + rot_part[7]*0 + rot_part[8]*(-1)
            ]

            t_max = float('inf')
            t_start = float('inf')  # [G] Initialized to infinity; set on front face hit
            counter = 0

            while True:
                t_min = t_max + eps
                t_max = float('inf')
                hit = mesh.trace_closest(ray_o, ray_dir, t_min, t_max)

                if hit.geom_id == "invalid":
                    if counter > 0:
                        z_exit = (1.5 - t_max * 0.5) * res
                        z_entry = (1.5 - t_start * 0.5) * res
                        z_min = max(0, min(res - 1, z_entry))
                        z_max = max(0, min(res - 1, z_exit))
                        if z_min <= z_max:
                            local_segments.append((x, y, z_min, z_max))
                    break

                if hit.c < 0.0:  # Front face
                    counter += 1
                    t_start = hit.t  # [G] Record entry distance
                elif hit.c > 0.0:  # Back face
                    counter -= 1
                    if counter == 0:
                        z_exit = (1.5 - hit.t * 0.5) * res
                        z_entry = (1.5 - t_start * 0.5) * res
                        z_min = max(0, min(res - 1, z_entry))
                        z_max = max(0, min(res - 1, z_exit))
                        if z_min <= z_max:
                            local_segments.append((x, y, z_min, z_max))

    with segments_mutex:
        segments.extend(local_segments)

def worker_loop(res, scale, eps, block_size, M, mesh):
    global curr_block
    blocks_per_edge = (res + block_size - 1) // block_size
    total_blocks = blocks_per_edge * blocks_per_edge
    while True:
        block_idx = curr_block
        curr_block += 1
        if block_idx >= total_blocks:
            break
        process_block(block_idx, res, scale, eps, block_size, M, mesh)

def voxelize(mesh, res, camera_rotation_to_world):
    global segments, curr_block
    segments = []
    curr_block = 0
    scale = 2.0 / res
    eps = max(scale / 64.0, 1e-5)
    block_size = min(res, 16)
    M = camera_rotation_to_world
    threads = [threading.Thread(target=worker_loop, args=(res, scale, eps, block_size, M, mesh)) for _ in range(num_workers)]
    for t in threads:
        t.start()
    for t in threads:
        t.join()
```

**Edge cases and pitfalls:**
- Precision issues near surfaces can cause gaps or overlaps; `eps` is used to mitigate self-intersection [S1, unofficial].
- Boundary conditions for Z-clamping must be handled to ensure voxels stay within $[0, \text{res}-1]$ [S1, unofficial].
- Degenerate input (empty mesh) should result in no segments [S1, unofficial].
