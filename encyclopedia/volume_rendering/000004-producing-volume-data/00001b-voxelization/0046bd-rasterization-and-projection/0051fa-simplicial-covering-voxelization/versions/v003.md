# Simplicial Covering Voxelization

Also called: P-Buffer method, Solid Voxelization via Simplicial Covering, Voxelization of solids using simplicial coverings

## Overview
Simplicial Covering Voxelization is a method to rasterize and voxelize 3D solids by decomposing their surface into tetrahedra connected to an origin, then using a presence buffer (P-buffer) to toggle voxel states [S1, unofficial]. Unlike boundary-only methods such as [Voxel Carving](1213-voxel-carving.md) or [Sramek's method](1213-voxel-carving.md), this approach produces a complete solid voxelization in a single pass by exploiting the parity of tetrahedron coverage [S1, unofficial]. It differs from [Implicit Surface Voxelization](2379-implicit-surface-voxelization.md) by operating directly on polygonal meshes without requiring implicit field evaluation [S1, unofficial].

## How it works
**Inputs and Outputs:**
- **Input:** A 3D solid defined by a set of planar faces (manifold or non-manifold, with or without holes), represented as a set of triangles [S1, unofficial]. A coordinate origin $O$ (typically the centroid or arbitrary point) [S1, unofficial].
- **Output:** A 3D voxel grid (P-buffer) where each voxel stores a presence bit (0 or 1) indicating if it is inside the solid [S1, unofficial]. Optionally, a framebuffer with colors applied [S1, unofficial].

**Data Structures:**
- **P-buffer:** A 3D array of bits. Each position $(x_i, y_i, z_i)$ stores a single bit: 0 (outside) or 1 (inside) [S1, unofficial].
- **Vertices:** Points $A, B, C$ defining the base triangle of a tetrahedron.
- **Slopes:** Precomputed incremental slope pairs $m_{XY} = (m_{XY}^x, m_{XY}^z)$ for edges (OA, OB, OC, AB, AC, BC), representing the change in $x$ and $z$ per unit step in $y$ [S1, unofficial].

**Algorithm Steps:**

1.  **Tetrahedron Construction:** For every triangle of the covering of each face of the solid, construct a tetrahedron by joining the triangle vertices ($A, B, C$) with the origin $O$ [S1, unofficial].

2.  **Sweeping Plane Determination:** Determine the sweeping direction by finding the maximum absolute value of the coordinates of the normal vector of the base triangle [S1, unofficial]. The method assumes rasterization with respect to the Y-direction [S1, unofficial]. If the maximum is negative, invert the tetrahedron with respect to the Y coordinate; at the end, invert the resulting voxel coordinates $(x_i, y_i, z_i)$ to $(x_i, -y_i, z_i)$ [S1, unofficial].

3.  **Initialization:**
    - Initialize the voxel matrix (P-buffer) to 0 [S1, unofficial].
    - Sort vertices $A, B, C$ by their Y-coordinate [S1, unofficial]. Let $A$ be the vertex with the maximum Y [S1, unofficial].
    - Set current $y = A_y$.
    - Initialize triangle vertices for the current slice: $A_i = A$, $B_i = B$, $C_i = C$ [S1, unofficial].
    - Compute initial slopes: $m_B = m_{AB}$, $m_C = m_{AC}$ [S1, unofficial].

4.  **Iterative Rasterization (Sweep):**
    While $y > 0$:
    - **Update Edge Vertices:**
        - If $B_y = y$, set $B_i = B$ and $m_B = m_{OB}$. Else, set $m_B = m_{AB}$ and $B_i = A_i + (B - A) \cdot m_B$ [S1, unofficial].
        - If $C_y = y$, set $C_i = C$ and $m_C = m_{OC}$. Else, set $m_C = m_{AC}$ and $C_i = A_i + (C - A) \cdot m_C$ [S1, unofficial].
    - **Rasterize Primary Triangle:** Call `Rasterize2D(A_i, B_i, C_i)` to flip presence values for voxels inside the triangle slice at current $y$ [S1, unofficial].
    - **Handle Quadrilateral Slice:** If $B_y > y > C_y$, the intersection is a quadrilateral [S1, unofficial]. Compute the intersection point $D_i = B + (C - B) \cdot m_{BC}$ [S1, unofficial]. Call `Rasterize2D(B_i, D_i, C_i)` to handle the second triangle of the quadrilateral [S1, unofficial].
    - **Decrement and Update:**
        - Decrement $y$.
        - If $y < B_y$, update $m_B = m_{OB}$.
        - If $y < C_y$, update $m_C = m_{OC}$.
        - Update $A_i, B_i, C_i$ with the corresponding incremental slopes for the next $y$-slice [S1, unofficial].

5.  **Finalization:** Transfer all positions from the P-buffer with presence value equal to 1 to the framebuffer, applying a color function that returns the corresponding color of the solid at that point [S1, unofficial].

**Pseudocode:**

```python
def simplicial_covering_voxelization(solid_triangles, origin, grid_bounds):
    # Initialize P-buffer with 0s
    # grid_bounds is (min_x, max_x, min_y, max_y, min_z, max_z)
    width = grid_bounds[1] - grid_bounds[0] + 1
    height = grid_bounds[3] - grid_bounds[2] + 1
    depth = grid_bounds[5] - grid_bounds[4] + 1
    p_buffer = [[ [False for _ in range(depth)] for _ in range(height)] for _ in range(width)]
    
    def flip_bit(x, y, z):
        if 0 <= x < width and 0 <= y < height and 0 <= z < depth:
            p_buffer[x][y][z] = not p_buffer[x][y][z]
            
    def rasterize_2d_triangle(v1, v2, v3, y_idx):
        # Sort vertices by x
        verts = sorted([v1, v2, v3], key=lambda v: v[0])
        v1, v2, v3 = verts[0], verts[1], verts[2]
        
        # Compute slopes for edges in x-z plane
        m12 = (v2[2] - v1[2]) / (v2[0] - v1[0]) if v2[0] != v1[0] else 0
        m23 = (v3[2] - v2[2]) / (v3[0] - v2[0]) if v3[0] != v2[0] else 0
        m13 = (v3[2] - v1[2]) / (v3[0] - v1[0]) if v3[0] != v1[0] else 0
        
        x = v1[0]
        z_left = v1[2]
        z_right = v1[2]
        
        # Upper triangle (v1 to v2)
        while x < v2[0]:
            for z in range(int(z_left), int(z_right) + 1):
                flip_bit(int(x), y_idx, z)
            x += 1
            z_left += m12
            z_right += m13
            
        # Lower triangle (v2 to v3)
        while x <= v3[0]:
            for z in range(int(z_left), int(z_right) + 1):
                flip_bit(int(x), y_idx, z)
            x += 1
            z_left += m23
            z_right += m13

    for triangle in solid_triangles:
        A, B, C = triangle
        # Step 2: Determine sweeping direction (assumed Y for this implementation)
        # If normal's max abs coord is negative, invert tetrahedron Y and final voxels
        
        # Step 3: Sort vertices by Y
        vertices = sorted([A, B, C], key=lambda v: v[1], reverse=True)
        A, B, C = vertices[0], vertices[1], vertices[2]
        
        y = A[1]
        Ai = list(A)
        Bi = list(B)
        Ci = list(C)
        
        # Compute initial slopes
        # Slope m_XY = (X - Y) / (X.y - Y.y)
        m_AB = [(B[0]-A[0])/(B[1]-A[1]), (B[2]-A[2])/(B[1]-A[1])]
        m_AC = [(C[0]-A[0])/(C[1]-A[1]), (C[2]-A[2])/(C[1]-A[1])]
        m_BC = [(C[0]-B[0])/(C[1]-B[1]), (C[2]-B[2])/(C[1]-B[1])]
        m_OA = [(A[0]-origin[0])/(A[1]-origin[1]), (A[2]-origin[2])/(A[1]-origin[1])]
        m_OB = [(B[0]-origin[0])/(B[1]-origin[1]), (B[2]-origin[2])/(B[1]-origin[1])]
        m_OC = [(C[0]-origin[0])/(C[1]-origin[1]), (C[2]-origin[2])/(C[1]-origin[1])]
        
        mB = m_AB
        mC = m_AC
        
        # Step 4: Iterative Rasterization
        while y > 0:
            # Update Edge Vertices
            if B[1] == y:
                Bi = list(B)
                mB = m_OB
            else:
                mB = m_AB
                Bi = [Ai[0] + (B[0]-A[0])*mB[0], Ai[1], Ai[2] + (B[2]-A[2])*mB[1]]
            
            if C[1] == y:
                Ci = list(C)
                mC = m_OC
            else:
                mC = m_AC
                Ci = [Ai[0] + (C[0]-A[0])*mC[0], Ai[1], Ai[2] + (C[2]-A[2])*mC[1]]
            
            # Rasterize Primary Triangle
            rasterize_2d_triangle(Ai, Bi, Ci, y)
            
            # Handle Quadrilateral Slice
            if B[1] > y > C[1]:
                # Intersection point Di on edge BC
                Di = [B[0] + (C[0]-B[0])*m_BC[0], B[1], B[2] + (C[2]-B[2])*m_BC[1]]
                rasterize_2d_triangle(Bi, Di, Ci, y)
            
            # Decrement and Update
            y -= 1
            
            if y < B[1]:
                mB = m_OB
            if y < C[1]:
                mC = m_OC
            
            # Update Ai, Bi, Ci with incremental slopes for next slice
            Ai = [Ai[0] + m_OA[0], Ai[1], Ai[2] + m_OA[1]]
            Bi = [Bi[0] + mB[0], Bi[1], Bi[2] + mB[1]]
            Ci = [Ci[0] + mC[0], Ci[1], Ci[2] + mC[1]]

    return p_buffer
```

**Parameters:**
- **P-buffer:** Stores presence values as a single bit (0 or 1) [S1, unofficial].
- **Color:** For homogeneous solids, all voxels have the same color. For heterogeneous solids, color depends on solid properties at the point [S1, unofficial].

**Edge Cases and Pitfalls:**
- **Quadrilateral Slices:** When $B_y > y_i > C_y$, the slice is a quadrilateral, not a triangle. This is handled by decomposing it into two triangles using the intersection point $D_i$ on edge $BC$ [S1, unofficial].
- **Aliasing:** The main problem is aliasing, appearing by using integer arithmetic on floating objects. This minimizes but does not eliminate the effect [S1, unofficial].
- **Boundary-Only:** To obtain boundary-only rasterization, consider only spans between $B_i$ and $C_i$ (or $D_i$ and $C_i$ when $B_y > y > C_y$) [S1, unofficial].

## Operating characteristics
- **Time Complexity:** Depends on the number of faces of the solid and the resolution [S1, unofficial]. Performance tests on a Pentium III 1GHz, 768 MB RAM showed that for a solid with 100,250 vertices and 202,520 faces at resolution 512, the method took 24.635 seconds, while Sramek's method took 237.601 seconds [S1, unofficial]. For boundary-only rasterization at 512 resolution, it took 4.715 seconds vs Sramek's 244.893 seconds [S1, unofficial].
- **Memory Complexity:** Requires a P-buffer of size proportional to the voxel grid resolution [S1, unofficial].
- **Strengths:** Obtains a complete voxelization of the solid in one pass. Simple and robust, suitable for graphic hardware implementation as it does not use additional data structures or complex operations [S1, unofficial].
- **Limitations:** Aliasing effects due to integer arithmetic. Performance depends on the number of faces, unlike Sramek's method which depends only on resolution and volume [S1, unofficial].

## Background
The method was presented in [S1, unofficial]. It is designed for 3D displays and voxelization of solids delimited by planar faces, including those with holes, manifold or non-manifold structures [S1, unofficial].
