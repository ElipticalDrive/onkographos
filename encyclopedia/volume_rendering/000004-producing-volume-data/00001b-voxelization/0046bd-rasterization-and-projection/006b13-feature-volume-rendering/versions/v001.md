# Feature Volume Rendering

Also called: Neural Volume Rendering with Feature Volumes, Volume Rendering to 2D Feature Map, Volumetric Rendering in Feature Space

## Overview
Feature Volume Rendering projects a 3D voxel grid containing high-level semantic or structural feature vectors onto a 2D feature map using volumetric integration, rather than directly rendering RGB colors. It solves the problem of decoupling scene representation from appearance, allowing a downstream 2D convolutional neural network (CNN) to decode the final image. It differs from standard NeRF by outputting a feature map instead of an RGB image, and from implicit surface voxelization by operating on a dense voxel grid with explicit feature storage.

## How it works
**Inputs:**
*   Camera pose $\kappa$ (origin $o$ and direction $d$).
*   Voxel grid $V$ containing density $\sigma$ and feature vectors $f$ at voxel centers.

**Outputs:**
*   2D feature map $F_{2D}$.
*   Expected depth $\hat{\rho}$.

**Data Structures:**
*   **Voxel Grid $V$**: A 3D array. Each voxel stores a scalar density $\sigma$ and a feature vector $f$ (dimension $D$).
*   **Sampling Points**: Points $r(t)$ along rays.

**Steps:**
1.  **Ray Casting**: For each pixel, define a ray $r(t) = o + td$ [S1].
2.  **Sampling**: Sample $N$ points $t_n$ along the ray within the scene bounds $[t_n, t_f]$ [S1].
3.  **Interpolation**: For each sample point $r(t)$, trilinearly interpolate the density $\sigma(r(t))$ and feature vector $f(r(t))$ from the voxel grid $V$ [S2].
4.  **Accumulation**: Compute transmittance $T(t)$ and accumulated feature vector $F(r)$ and depth $\hat{\rho}$ using volumetric rendering equations [S1, S2].
5.  **Decoding**: Feed the resulting 2D feature map into a CNN decoder to produce the output image $\hat{i}$ [S2].

**Formulas:**
Ray equation:
$$ r(t) = o + td $$
[S1]

Transmittance (probability of light passing through previous points):
$$ T(t) = \exp\left(-\int_{t_n}^{t} \sigma(r(s)) ds\right) $$
[S1]

Accumulated Feature Vector $F(r)$ for a ray:
$$ F(r) = \int_{t_n}^{t_f} T(t) \sigma(r(t)) f(r(t)) dt $$
Derived from [S1] (color accumulation) and [S2] (feature pooling). The sources describe combining feature vectors and density values via volumetric rendering to form a feature map.

Accumulated Depth $\hat{\rho}$:
$$ \hat{\rho} = \int_{t_n}^{t_f} T(t) \sigma(r(t)) t dt $$
Derived from [S2] ("get the expected depth $\hat{\rho}$ along each ray from the volume rendering process").

**Parameters:**
*   Number of samples $N$: Not given in the sources.
*   Feature vector dimension $D$: Not given in the sources.
*   Integration bounds $[t_n, t_f]$: Not given in the sources.

**Pseudocode:**
```python
def feature_volume_rendering(voxel_grid, camera_pose, num_samples):
    """
    Renders a 2D feature map from a voxel grid and camera pose.
    
    Args:
        voxel_grid: 3D array storing (density, feature_vector) per voxel.
        camera_pose: Tuple (origin, direction).
        num_samples: Integer, number of points to sample along the ray.
        
    Returns:
        feature_map: 2D array of feature vectors.
        depth_map: 2D array of expected depths.
    """
    origin, direction = camera_pose
    feature_map = zeros_like(output_shape)
    depth_map = zeros_like(output_shape)
    
    # Define ray bounds [t_n, t_f]
    # Note: Exact bounds not provided in sources [G]
    t_n = 0.0
    t_f = 10.0 
    
    t_values = linspace(t_n, t_f, num_samples)
    
    for each pixel in image:
        accumulated_feature = zeros(feature_dim)
        accumulated_weight = 0.0
        accumulated_depth = 0.0
        transmittance = 1.0
        
        for t in t_values:
            # 1. Ray equation
            point = origin + t * direction
            
            # 2. Trilinear interpolation from voxel grid
            # Note: Implementation of trilinear interpolation is standard [G]
            sigma, feature = trilinear_interpolate(voxel_grid, point)
            
            # 3. Compute alpha (contribution weight)
            # alpha = 1 - exp(-sigma * delta_t) is standard for discrete approximation
            # Sources use continuous integral form. We approximate integral with sum.
            delta_t = t_values[1] - t_values[0] if len(t_values) > 1 else 0.0
            alpha = 1.0 - exp(-sigma * delta_t)
            
            # 4. Accumulate
            weight = transmittance * alpha
            accumulated_feature += weight * feature
            accumulated_depth += weight * t
            accumulated_weight += weight
            
            # 5. Update transmittance
            transmittance *= (1.0 - alpha)
            
        # Normalize accumulated features by total weight to get mean feature
        # Note: [S2] mentions "simply take the mean of the pooled features"
        if accumulated_weight > 0:
            feature_map[pixel] = accumulated_feature / accumulated_weight
            depth_map[pixel] = accumulated_depth / accumulated_weight
        else:
            feature_map[pixel] = zeros(feature_dim)
            depth_map[pixel] = 0.0
            
    return feature_map, depth_map
```

## Subtopics

### Implicit Surface Voxelization
Uses neural networks to define density implicitly, whereas Feature Volume Rendering uses an explicit voxel grid for features. [Link](2379-implicit-surface-voxelization.md)

### Parametric Surface Voxelization
Represents surfaces with parametric functions; Feature Volume Rendering uses a dense grid of feature vectors. [Link](6032-parametric-surface-voxelization.md)

### Rasterization and GPU Shaders
Projects geometry directly to pixels; Feature Volume Rendering integrates features along rays. [Link](11755-rasterization-and-gpu-shaders.md)

### Multi-Plane Projection Voxelization and Aggregation
Projects features onto planes; Feature Volume Rendering projects onto a 2D feature map via 3D volumetric integration. [Link](12100-multi-plane-projection-voxelization-and-aggregation.md)

### Simplicial Covering Voxelization
Uses tetrahedral meshes; Feature Volume Rendering uses a regular voxel grid. [Link](14628-simplicial-covering-voxelization.md)

### Forward Projection
General term for projecting 3D data to 2D; Feature Volume Rendering is a specific volumetric integration method. [Link](18234-forward-projection.md)

### Scanline Projection (Nearest Neighbor)
Uses nearest voxel; Feature Volume Rendering uses trilinear interpolation. [Link](19549-scanline-projection-nearest-neighbor.md)

### Cylindrical Projection for Volumetric Approximation
Uses cylindrical coordinates; Feature Volume Rendering uses standard Euclidean rays. [Link](22715-cylindrical-projection-for-volumetric-approximation.md)

## Operating characteristics
*   **Time Complexity**: $O(N \cdot P)$, where $N$ is the number of samples per ray and $P$ is the number of pixels. Trilinear interpolation is $O(1)$ per sample.
*   **Memory Complexity**: $O(V)$, where $V$ is the number of voxels, storing both density and feature vectors.
*   **Strengths**: Decouples geometry/structure (in the voxel grid) from appearance (in the CNN decoder). Allows for efficient decoding of multiple views or styles.
*   **Limitations**: Requires explicit storage of feature vectors in voxels, which can be memory-intensive for high-dimensional features.
*   **When to use**: When the scene structure is better represented by explicit features and a separate decoder is desired.
*   **When not to use**: When memory is constrained or when implicit representations are sufficient.

## Background
Feature Volume Rendering is based on the concept of Neural Radiance Fields (NeRF) [S1]. While standard NeRF outputs RGB colors directly, this variant outputs feature vectors, which are then decoded by a CNN [S1, S2]. The approach allows for the learning of abstract high-level concepts within the scene [S1]. It is used in scene auto-encoding pipelines and hierarchical latent diffusion models [S2].
