# Feature Volume Rendering

Also called: Neural Volume Rendering with Feature Volumes, Volume Rendering to 2D Feature Map, Volumetric Rendering in Feature Space

## Overview
Feature Volume Rendering projects a 3D voxel grid containing high-level semantic or structural feature vectors onto a 2D feature map using volumetric integration, rather than directly rendering RGB colors [S1, S2]. It solves the problem of decoupling scene representation from appearance, allowing a downstream 2D convolutional neural network (CNN) to decode the final image [S1, S2]. It differs from standard NeRF by outputting a feature map instead of an RGB image, relying on an explicit voxel grid for feature storage rather than implicit MLPs [S1].

## How it works
**Inputs:**
*   Camera pose $\kappa$ (origin $o$ and direction $d$) [S1, S2].
*   Voxel grid $V$ containing density $\sigma$ and feature vectors $f$ at voxel centers [S1, S2].

**Outputs:**
*   2D feature map $F_{2D}$ [S1, S2].
*   Expected depth $\hat{\rho}$ [S2].

**Data Structures:**
*   **Voxel Grid $V$**: A 3D array. Each voxel stores a scalar density $\sigma$ and a feature vector $f$ (dimension $D$) [S1, S2].
*   **Sampling Points**: Points $r(t)$ along rays [S1].

**Steps:**
1.  **Ray Casting**: For each pixel, define a ray $r(t) = o + td$ [S1].
2.  **Sampling**: Sample $N$ points $t_n$ along the ray within the scene bounds $[t_n, t_f]$ [S1, S2].
3.  **Interpolation**: For each sample point $r(t)$, trilinearly interpolate the density $\sigma(r(t))$ and feature vector $f(r(t))$ from the voxel grid $V$ [S2].
4.  **Accumulation**: Compute transmittance $T(t)$ and accumulated feature vector $F(r)$ and depth $\hat{\rho}$ using volumetric rendering equations [S1, S2].
5.  **Decoding**: Feed the resulting 2D feature map into a CNN decoder to produce the output image $\hat{i}$ [S2].

**Formulas:**
Ray equation:
$$ r(t) = o + td $$
[S1]

Transmittance (probability of light passing through previous points):
$$ T(t) = \exp\left(-\int_{t_n}^{t} \sigma(r(s)) ds\right) $$
[S1]

Accumulated Feature Vector $F(r)$ for a ray:
$$ F(r) = \int_{t_n}^{t_f} T(t) \sigma(r(t)) f(r(t)) dt $$
Derived from [S1] (color accumulation) and [S2] (feature pooling). The sources describe combining feature vectors and density values via volumetric rendering to form a feature map [S1, S2].

Accumulated Depth $\hat{\rho}$:
$$ \hat{\rho} = \int_{t_n}^{t_f} T(t) \sigma(r(t)) t dt $$
Derived from [S2] ("get the expected depth $\hat{\rho}$ along each ray from the volume rendering process").

**Parameters:**
*   Number of samples $N$: Not given in the sources.
*   Feature vector dimension $D$: Not given in the sources.
*   Integration bounds $[t_n, t_f]$: Not given in the sources.

**Pseudocode:**
```python
import math

def feature_volume_rendering(voxel_grid, grid_bounds, camera_origin, camera_direction, num_samples):
    # grid_bounds: (min_x, min_y, min_z, max_x, max_y, max_z)
    # voxel_grid: 3D array of (density, feature_vector)
    # Returns feature_map, depth_map

    def ray_aabb_intersect(origin, direction, bounds):
        t_min = -math.inf
        t_max = math.inf
        for i in range(3):
            if direction[i] == 0:
                if origin[i] < bounds[i] or origin[i] > bounds[i+3]:
                    return None, None
            else:
                t1 = (bounds[i] - origin[i]) / direction[i]
                t2 = (bounds[i+3] - origin[i]) / direction[i]
                t_min = max(t_min, min(t1, t2))
                t_max = min(t_max, max(t1, t2))
        if t_max < t_min:
            return None, None
        return t_min, t_max

    t_n, t_f = ray_aabb_intersect(camera_origin, camera_direction, grid_bounds)
    if t_n is None:
        return [], []

    step = (t_f - t_n) / num_samples
    feature_dim = len(voxel_grid[0][0][1])
    feature_map = []
    depth_map = []

    for _ in range(num_samples): # Iterates over pixels; simplified for structure
        acc_feat = [0.0] * feature_dim
        acc_depth = 0.0
        acc_weight = 0.0
        transmittance = 1.0

        for i in range(num_samples):
            t = t_n + i * step
            point = [camera_origin[j] + t * camera_direction[j] for j in range(3)]

            sigma, feat = trilinear_interpolate(voxel_grid, point, grid_bounds)

            delta_t = step
            alpha = 1.0 - math.exp(-sigma * delta_t)
            weight = transmittance * alpha

            for k in range(feature_dim):
                acc_feat[k] += weight * feat[k]
            acc_depth += weight * t
            acc_weight += weight
            transmittance *= (1.0 - alpha)

        if acc_weight > 0:
            feature_map.append([f / acc_weight for f in acc_feat])
            depth_map.append(acc_depth / acc_weight)
        else:
            feature_map.append([0.0] * feature_dim)
            depth_map.append(0.0)

    return feature_map, depth_map

def trilinear_interpolate(grid, point, bounds):
    # Standard trilinear interpolation [G]
    x = (point[0] - bounds[0]) / (bounds[3] - bounds[0])
    y = (point[1] - bounds[1]) / (bounds[4] - bounds[1])
    z = (point[2] - bounds[2]) / (bounds[5] - bounds[2])
    x = max(0.0, min(1.0, x))
    y = max(0.0, min(1.0, y))
    z = max(0.0, min(1.0, z))
    ix, iy, iz = int(x * (len(grid)-1)), int(y * (len(grid[0])-1)), int(z * (len(grid[0][0])-1))
    fx, fy, fz = x * (len(grid)-1) - ix, y * (len(grid[0])-1) - iy, z * (len(grid[0][0])-1) - iz
    corners = []
    for dx in (0, 1):
        for dy in (0, 1):
            for dz in (0, 1):
                cx, cy, cz = min(ix+dx, len(grid)-1), min(iy+dy, len(grid[0])-1), min(iz+dz, len(grid[0][0])-1)
                corners.append(grid[cx][cy][cz])
    d00, f00 = corners[0]; d10, f10 = corners[1]
    d01, f01 = corners[2]; d11, f11 = corners[3]
    d001, f001 = corners[4]; d101, f101 = corners[5]
    d011, f011 = corners[6]; d111, f111 = corners[7]
    d00z = d00*(1-fx) + d10*fx
    f00z = [a*(1-fx)+b*fx for a,b in zip(f00,f10)]
    d01z = d01*(1-fx) + d11*fx
    f01z = [a*(1-fx)+b*fx for a,b in zip(f01,f11)]
    d10z = d001*(1-fx) + d101*fx
    f10z = [a*(1-fx)+b*fx for a,b in zip(f001,f101)]
    d11z = d011*(1-fx) + d111*fx
    f11z = [a*(1-fx)+b*fx for a,b in zip(f011,f111)]
    d0z = d00z*(1-fy) + d01z*fy
    f0z = [a*(1-fy)+b*fy for a,b in zip(f00z,f01z)]
    d1z = d10z*(1-fy) + d11z*fy
    f1z = [a*(1-fy)+b*fy for a,b in zip(f10z,f11z)]
    d = d0z*(1-fz) + d1z*fz
    f = [a*(1-fz)+b*fz for a,b in zip(f0z,f1z)]
    return d, f
```

### Implicit Surface Voxelization
Defines density implicitly via neural networks; Feature Volume Rendering uses an explicit voxel grid for feature storage [G]. [Link](2379-implicit-surface-voxelization.md)

### Parametric Surface Voxelization
Represents geometry with parametric functions; Feature Volume Rendering uses a dense grid of feature vectors [G]. [Link](6032-parametric-surface-voxelization.md)

### Rasterization and GPU Shaders
Projects geometry directly to pixels via shading; Feature Volume Rendering integrates features along rays volumetrically [G]. [Link](11755-rasterization-and-gpu-shaders.md)

### Multi-Plane Projection Voxelization and Aggregation
Projects features onto 2D planes; Feature Volume Rendering projects onto a 2D feature map via 3D volumetric integration [G]. [Link](12100-multi-plane-projection-voxelization-and-aggregation.md)

### Simplicial Covering Voxelization

### Forward Projection
General term for projecting 3D data to 2D; Feature Volume Rendering is a specific volumetric integration method [G]. [Link](18234-forward-projection.md)

### Scanline Projection (Nearest Neighbor)
Uses nearest voxel sampling; Feature Volume Rendering uses trilinear interpolation [G]. [Link](19549-scanline-projection-nearest-neighbor.md)

Uses cylindrical coordinates for projection; Feature Volume Rendering uses standard Euclidean rays [G]. [Link](22715-cylindrical-projection-for-volumetric-approximation.md)

## Operating characteristics
*   **Time Complexity**: $O(N \cdot P)$, where $N$ is the number of samples per ray and $P$ is the number of pixels. Trilinear interpolation is $O(1)$ per sample [G].
*   **Memory Complexity**: $O(V)$, where $V$ is the number of voxels, storing both density and feature vectors [G].
*   **Strengths**: Decouples geometry/structure (in the voxel grid) from appearance (in the CNN decoder) [S1, S2]. Allows for efficient decoding of multiple views or styles.
*   **Limitations**: Requires explicit storage of feature vectors in voxels, which can be memory-intensive for high-dimensional features [G].
*   **When to use**: When the scene structure is better represented by explicit features and a separate decoder is desired [S1, S2].
*   **When not to use**: When memory is constrained or when implicit representations are sufficient [G].

## Background
Feature Volume Rendering is based on the concept of Neural Radiance Fields (NeRF) [S1]. While standard NeRF outputs RGB colors directly, this variant outputs feature vectors, which are then decoded by a CNN [S1, S2]. The approach allows for the learning of abstract high-level concepts within the scene [S1]. It is used in scene auto-encoding pipelines [S2].
