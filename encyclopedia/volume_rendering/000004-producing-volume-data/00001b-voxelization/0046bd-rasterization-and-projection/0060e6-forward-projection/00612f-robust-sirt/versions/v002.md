# Robust SIRT

Also called: Students-T robust SIRT, StudentsT

## Overview
Robust SIRT is an iterative reconstruction method that uses ASTRA's projector with a `student` flag enabled to apply robust weighting during updates [S1, unofficial]. It builds on [Forward Projection](18234-forward-projection.md) by leveraging subset processing for memory efficiency [S1, unofficial]. Unlike standard SIRT, it down-weights large residuals to handle impulsive noise or artifacts [S1, unofficial].

## How it works
**Inputs and Outputs:**
- **Inputs:** `proj` (projection data), `vol_rec` (initial volume estimate), `geom` (geometry object defining ray paths and voxel grid), `iterations` (number of SIRT steps, $K$) [S1, unofficial].
- **Outputs:** `vol_rec` (reconstructed volume) [S1, unofficial].

**Data Structures:**
The method relies on the ASTRA projectors' internal settings object [S1, unofficial]. Key fields include:
- `subsets`: Integer controlling the number of subsets for memory efficiency [S1, unofficial].
- `student`: Boolean flag enabling the robust weighting mode [S1, unofficial].

**Parameters:**
- `subsets`: Set to 10 [S1, unofficial].
- `iterations` ($K$): Number of update steps [S1, unofficial].
- `student`: Set to `True` [S1, unofficial].

**Steps:**
1. Set `projector.settings.subsets = 10` [S1, unofficial].
2. Enable robust mode: `projector.settings.student = True` [S1, unofficial].
3. Call `projector.SIRT(proj, vol_rec, geom, iterations=K)` [S1, unofficial].
The projector handles the internal forward projection, residual calculation, robust weighting, back-projection, and normalization [S1, unofficial].

**Pseudocode:**
```python
def robust_sirt(proj, vol_rec, geom, iterations=100):
    """
    Perform Robust SIRT reconstruction using ASTRA-style projector settings.
    
    Args:
        proj: Array of projection measurements.
        vol_rec: Initial volume estimate.
        geom: Geometry object containing ray definitions and voxel grid.
        iterations: Number of SIRT iterations.
        
    Returns:
        vol_rec: Reconstructed volume.
    """
    # Initialize volume if not provided
    if vol_rec is None:
        vol_rec = [0.0] * geom.volume_size
        
    # Step 1: Set projector settings
    projector_settings = {'subsets': 10, 'student': True}
    
    # Step 2: Enable robust mode
    projector_settings['student'] = True
    
    # Step 3: Execute SIRT loop
    # The projector handles forward projection, robust weighting, back-projection, and normalization internally.
    for _ in range(iterations):
        # Forward project current volume estimate
        proj_est = [0.0] * len(proj)
        for i in range(len(proj)):
            for j in range(len(vol_rec)):
                proj_est[i] += geom.ray_weights[i][j] * vol_rec[j]
        
        # Compute residuals
        residuals = [proj[i] - proj_est[i] for i in range(len(proj))]
        
        # Apply robust weighting (Student's t)
        # [G] ASTRA applies weighting based on the 'student' flag.
        weighted_residuals = [r / (1.0 + r**2) for r in residuals]
        
        # Back-project weighted residuals
        vol_update = [0.0] * len(vol_rec)
        for j in range(len(vol_rec)):
            for i in range(len(proj)):
                vol_update[j] += geom.ray_weights[i][j] * weighted_residuals[i]
        
        # Normalize by column sums (standard SIRT)
        # [G] ASTRA stores normalization factors in geom.
        norm = [sum(geom.ray_weights[i][j] for i in range(len(proj))) + 1e-8 for j in range(len(vol_rec))]
        vol_rec = [vol_rec[j] + vol_update[j] / norm[j] for j in range(len(vol_rec))]
        
    return vol_rec
```

**Edge Cases and Pitfalls:**
- **Precision:** The Student's t-distribution weighting can lead to numerical instability if residuals are extremely large or small. [G] Clipping residuals or using a minimum threshold for weights is recommended.
- **Boundaries:** Ray tracing artifacts at the volume boundaries can create outliers. Robust SIRT mitigates this, but extreme boundary effects may still require masking. [G] Apply a boundary mask if the geometry supports it.
- **Degenerate Input:** If projection data is entirely zero or constant, the robust weighting may not converge to a meaningful solution. [G] Check for zero-variance projections before iteration.

## Subtopics

### Component Averaging Method (CAV)
A SIRT variant using a diagonal sparsity scaling matrix to scale updates based on the intersection density of line-of-sight rays [S2, unofficial]. The modified row norm for the weighting is defined as $||S_M F_{i,*}||^2_2 = \sum_j s_j F_{i,j}^2$, where $s_j$ is the number of non-zero elements in the $j$-th column of the forward operator $F$ [S2, unofficial]. Weighting matrices: $T$ is the identity matrix ($T_{j,j} = 1$), and $M$ has diagonal elements $M_{i,i} = ||S_M F_{i,*}||^{-2}_2$ [S2, unofficial].

### Cimmino Method
A SIRT variant where the weighting depends on the number of measurements related to the spray layer [S2, unofficial]. Weighting matrices: $T$ is the identity matrix ($T_{j,j} = 1$), and $M$ has diagonal elements $M_{i,i} = m^{-1} ||F_{i,*}||^{-2}_2$, where $m$ is the number of measurements and $||F_{i,*}||_2$ is the L2-norm of the $i$-th row of $F$ [S2, unofficial].

## Operating characteristics
- **Time Complexity:** Not given in the sources.
- **Memory Complexity:** ASTRA's subset mode reduces peak memory usage by processing subsets of rays [S1, unofficial].
- **Measured Performance:** Not given in the sources for Robust SIRT specifically. [S2, unofficial] reports 1000 iterations for convergence in comparable iterative methods.
- **Strengths:** Resilient to outliers and impulsive noise; better convergence in noisy environments compared to standard SIRT [S1, unofficial].
- **Limitations:** Slower convergence than non-robust methods in clean data scenarios; requires careful tuning of robustness parameters if exposed [G].
- **When to Use:** Noisy projection data, data with artifacts, or sparse views with outliers [G].
- **When Not to Use:** Clean data where standard SIRT or FBP is sufficient and speed is critical [G].

## Background
The method is implemented in the ASTRA toolbox and utilized in frameworks like flexTOMO [S1, unofficial]. It is applied in tomographic reconstruction where robust weighting is required [S1, unofficial]. The variants CAV and Cimmino are discussed in the context of axisymmetric spray tomography [S2, unofficial].
