# Solid Voxelization based on Octree

Also called: Polygon-to-Octree Rasterization, RFVoxelOctreeBuilder, voxelization via bounding box overlap

## Overview
Solid Voxelization based on Octree converts a polygon mesh (specifically OBJ format) into a hierarchical octree representation to determine the solid, empty, and distance-to-surface status of leaf nodes [S1, S2, unofficial]. It differs from fixed-grid voxelization by using adaptive spatial subdivision, allowing for efficient representation of sparse scenes or high-resolution details where a uniform grid would be prohibitively large [S2, unofficial]. Unlike [Solid Voxelization via Ray Casting](6829-solid-voxelization-via-ray-casting.md), which casts rays per pixel to find intervals, this method recursively partitions space and assigns triangles to nodes, using ray sampling only for ambiguous internal empty leaves [S2, unofficial].

## How it works
**Inputs and Outputs:**
*   **Input:** A triangular mesh in OBJ format (vertices, faces). Note: Only supports OBJ files with vertices ordered in triangles [v0,v1,v2] [S2, unofficial].
*   **Output:** An octree structure where each leaf node contains a distance to the surface (negative for inside, positive for outside) and type (Empty, Internal, Leaf) [S1, S2, unofficial].

**Data Structures:**

1.  **Octree Node (`RFVoxelOctreeNode`)** [S2, unofficial]:
    *   `m_kWorldAabb`: Axis-aligned bounding box in world space (`RFAABB3d`).
    *   `m_kBuildAabb`: Axis-aligned bounding box in build/grid space (`RFAABB3d` with integer min/max).
    *   `m_pkChildren`: Array of 8 pointers to child nodes.
    *   `m_eNodeType`: Enum indicating `NT_EMPTY_LEAF`, `NT_LEAF`, or `NT_INTERNAL`.
    *   `m_fDistanceToSurface`: Double precision distance to the closest triangle surface.
    *   *Alternative Layout ([S1, unofficial]):* `vx_node` uses `uint32_t child_pointers[8]`, `uint8_t valid_masks`, `uint8_t leaf_mask`, `uint16_t padding`.

2.  **Octree Container (`RFVoxelOctree`)** [S2, unofficial]:
    *   `m_uiOctreeDim`: Dimension of the voxelization grid (next power of two).
    *   `m_fVoxelSize`: Size of a single voxel.
    *   `m_kOctreeOrigin`: World space origin of the octree.
    *   `m_kDataDimension`: Integer dimensions (`RFVector3i`).
    *   `m_pkRoot`: Pointer to the root node.
    *   `m_uiNumberOfLeafs`, `m_uiNumberOfEmptyLeafs`, `m_uiNumberOfInternalNodes`: Counters [S2, unofficial].

3.  **Voxel Data (`vx_voxel`)** [S1, unofficial]:
    *   `int8_t normals[3]`: Normal vector multiplied by 128.
    *   `uint8_t colors[4]`: Color (typically white 255,255,255,255).
    *   Padding fields.

**Parameters:**
*   `kOctreeDim` (or `detail`): The requested dimension of the voxelization grid. Default is 64 [S2, unofficial]. In [S1, unofficial], `detail` is the logarithmic resolution; typical value is 8.
*   `fMinCoverage`: Threshold for ray coverage to classify an internal empty leaf as solid. Default is 0.9 (header) or 0.8 (implementation) [S2, unofficial].
*   `fBorderSize`: Default 0.0, not used in provided logic [S2, unofficial].

**Algorithm Steps:**

1.  **Parse Mesh:** Read the OBJ file. Count vertices, UVs, normals, and faces. Track the bounding box min/max coordinates. Load vertices and faces into memory arrays. Decrement face indices by 1 to convert from 1-based OBJ indices to 0-based array indices [S1, S2, unofficial].
2.  **Calculate Grid Dimensions:**
    *   Find the longest axis of the mesh AABB: $kDim = kMax - kMin$ [S2, unofficial].
    *   Calculate the next power of two for the octree dimension ($m\_uiOctreeDim$). If input is 0, return 2. Otherwise, decrement, then bitwise OR with right shifts of 16, 8, 4, 2, and 1 bits, then increment [S2, unofficial].
    *   Calculate voxel size: $m\_fVoxelSize = fMaxDim / m\_uiOctreeDim$ [S2, unofficial].
    *   Calculate world size: $fOctreeWorldSize = m\_uiOctreeDim \times m\_fVoxelSize$ [S2, unofficial].
    *   Set origin: $m\_kOctreeOrigin = kMeshAabb.GetCenter() - RFVector3d(fOctreeWorldSize / 2.0f)$ [S2, unofficial].
    *   *Alternative Normalization ([S1, unofficial]):* Calculate offset and scale to normalize model into unit cube $[0,1]^3$: $offset = -min$, $scale = 1.0 / max(width, height, depth)$. Grid step size: $step = 1.0 / (1 \ll detail)$ [S1, unofficial].
3.  **Initialize Root Node:**
    *   Create root `RFVoxelOctreeNode`.
    *   Set `m_kWorldAabb` from `m_kOctreeOrigin` to `m_kOctreeOrigin + RFVector3d(fOctreeWorldSize)` [S2, unofficial].
    *   Set `m_kBuildAabb.kMin` to $(0,0,0)$ and `kMax` to $(m\_uiOctreeDim, m\_uiOctreeDim, m\_uiOctreeDim)$ [S2, unofficial].
    *   Set `m_kDataDimension` to `RFVector3i(m_uiOctreeDim)` [S2, unofficial].
    *   *Alternative ([S1, unofficial]):* Initialize with allocated size 4096, size 1, leaf_mask and valid_masks to 0.
4.  **Recursive Subdivision and Triangle Assignment:**
    For a parent node, create 8 children (octants $x,y,z \in \{0,1\}$) [S2, unofficial].
    *   **Child AABB:**
        *   Build AABB: $kMin = parent.kMin + (iAabbDim \cdot x, iAabbDim \cdot y, iAabbDim \cdot z)$, $kMax = kMin + iAabbDim$ [S2, unofficial].
        *   World AABB: Calculate using `m_kOctreeOrigin` and `m_fVoxelSize` [S2, unofficial].
    *   **Triangle Assignment:**
        *   For each triangle in the parent's list, check if `TriangleAabbIntersects(kTriangleVerts, kWorldAabb)`. If true, add the triangle index to the child's list [S2, unofficial].
        *   *Alternative ([S1, unofficial]):* Expand triangle bounding box by one step size. Iterate through grid cells within the expanded box. Check overlap using `triBoxOverlap`. If overlapping, retrieve or create the voxel.
5.  **Classify Child Node:**
    *   If child triangle list is empty: Set type to `NT_EMPTY_LEAF` [S2, unofficial].
    *   If `iAabbDim == 1` (leaf level): Set type to `NT_LEAF` and call `UpdateLeafNodeDistanceValue` [S2, unofficial].
    *   Otherwise: Set type to `NT_INTERNAL` and recursively call `Subdivide` [S2, unofficial].
6.  **Update Leaf Distance Value (`NT_LEAF`):**
    *   Initialize $fMinDist$ to max double [S2, unofficial].
    *   For each triangle in the leaf's list:
        *   Compute normal: $kNormal = VectorCross(kTriangleVerts[2] - kTriangleVerts[0], kTriangleVerts[1] - kTriangleVerts[0])$ [S2, unofficial].
        *   Find closest point on triangle to leaf center: $kClosestPoint = ClosestPointOnTriangle(kTriangleVerts, leaf\_center)$ [S2, unofficial].
        *   Compute delta: $kDelta = kClosestPoint - leaf\_center$ [S2, unofficial].
        *   Compute sign: $fSign = (VectorDot(kDelta, kNormal) < 0.0f) ? -1.0f : 1.0f$ [S2, unofficial].
        *   Compute distance: $fDist = VectorLength(kDelta)$ [S2, unofficial].
        *   If $fDist < |fMinDist|$, set $fMinDist = fDist \times fSign$ [S2, unofficial].
    *   Store $fMinDist$ in `m_fDistanceToSurface` [S2, unofficial].
7.  **Update Internal Empty Leaf Signs (`NT_EMPTY_LEAF`):**
    *   For `NT_INTERNAL` nodes, recurse to children [S2, unofficial].
    *   For `NT_EMPTY_LEAF` nodes:
        *   Cast rays from node center using precomputed sample directions (200 directions generated via Hammersley2D and UniformSphericalSampling) [S2, unofficial].
        *   Count hits (`uiCoverage`) and misses (`uiMisses`) [S2, unofficial].
        *   **Stopping Heuristic:** Stop if `uiMisses >= size/4` (25% of total samples) [S2, unofficial].
        *   Calculate coverage: $fCoverage = uiCoverage / size$ [S2, unofficial].
        *   If $fCoverage \ge fMinCoverage$, set `m_fDistanceToSurface = -1.0f` (solid/inside) [S2, unofficial].
        *   Else, set `m_fDistanceToSurface = 1.0f` (empty/outside) [S2, unofficial].

**Pseudocode:**

```python
import math

class AABB:
    def __init__(self, min_pt, max_pt):
        self.min = min_pt
        self.max = max_pt

class Node:
    def __init__(self):
        self.world_aabb = None
        self.build_aabb = None
        self.children = [None] * 8
        self.triangles = []
        self.node_type = None
        self.distance_to_surface = 0.0

NT_EMPTY_LEAF = 0
NT_LEAF = 1
NT_INTERNAL = 2

def next_power_of_two(n):
    if n == 0:
        return 2
    n -= 1
    n |= n >> 16
    n |= n >> 8
    n |= n >> 4
    n |= n >> 2
    n |= n >> 1
    return n + 1

def radical_inverse_vdC(n):
    n = ((n & 0x55555555) << 1) | ((n & 0xAAAAAAAA) >> 1)
    n = ((n & 0x33333333) << 2) | ((n & 0xCCCCCCCC) >> 2)
    n = ((n & 0x0F0F0F0F) << 4) | ((n & 0xF0F0F0F0) >> 4)
    n = ((n & 0x00FF00FF) << 8) | ((n & 0xFF00FF00) >> 8)
    n = ((n & 0x0000FFFF) << 16) | ((n & 0xFFFF0000) >> 16)
    return n * 2.3283064365386963e-10

def hammersley_2d(i, N):
    return (i / N, radical_inverse_vdC(i))

def uniform_spherical_sampling(u, v):
    phi = v * 2.0 * math.pi
    cos_theta = 1.0 - u
    sin_theta = math.sqrt(1.0 - cos_theta * cos_theta)
    return (math.cos(phi) * sin_theta, math.sin(phi) * sin_theta, cos_theta)

def closest_point_on_triangle(p, v0, v1, v2):
    e0 = (v1[0]-v0[0], v1[1]-v0[1], v1[2]-v0[2])
    e1 = (v2[0]-v0[0], v2[1]-v0[1], v2[2]-v0[2])
    d = (v0[0]-p[0], v0[1]-p[1], v0[2]-p[2])
    a = e0[0]*e0[0] + e0[1]*e0[1] + e0[2]*e0[2]
    b = e0[0]*e1[0] + e0[1]*e1[1] + e0[2]*e1[2]
    c = e1[0]*e1[0] + e1[1]*e1[1] + e1[2]*e1[2]
    d0 = e0[0]*d[0] + e0[1]*d[1] + e0[2]*d[2]
    d1 = e1[0]*d[0] + e1[1]*d[1] + e1[2]*d[2]
    denom = a * c - b * b
    if denom == 0:
        return v0
    u = (b * c - d1 * b) / denom
    v = (a * d1 - b * d0) / denom
    if u < 0.0:
        u = 0.0
        v = max(0.0, -d0 / a)
    elif v < 0.0:
        v = 0.0
        u = max(0.0, -d1 / c)
    if u + v > 1.0:
        t = (d0 + d1) / (a + c - 2.0 * b)
        t = max(0.0, min(1.0, t))
        return (v0[0]+e0[0]*t, v0[1]+e0[1]*t, v0[2]+e0[2]*t) if a > c else (v0[0]+e1[0]*t, v0[1]+e1[1]*t, v0[2]+e1[2]*t)
    return (v0[0]+e0[0]*u+e1[0]*v, v0[1]+e0[1]*u+e1[1]*v, v0[2]+e0[2]*u+e1[2]*v)

def triangle_aabb_intersects(tri_verts, aabb):
    # Standard axis-aligned bounding box vs triangle overlap test [G]
    # Returns True if the triangle's bounding box overlaps the AABB
    tri_min = (min(v[0] for v in tri_verts), min(v[1] for v in tri_verts), min(v[2] for v in tri_verts))
    tri_max = (max(v[0] for v in tri_verts), max(v[1] for v in tri_verts), max(v[2] for v in tri_verts))
    return not (tri_max[0] < aabb.min[0] or tri_min[0] > aabb.max[0] or
                tri_max[1] < aabb.min[1] or tri_min[1] > aabb.max[1] or
                tri_max[2] < aabb.min[2] or tri_min[2] > aabb.max[2])

def ray_hits_mesh(origin, direction, triangles):
    # Standard ray-triangle intersection test [G]
    # Returns True if ray intersects any triangle in the list
    for tri in triangles:
        v0, v1, v2 = tri
        e1 = (v1[0]-v0[0], v1[1]-v0[1], v1[2]-v0[2])
        e2 = (v2[0]-v0[0], v2[1]-v0[1], v2[2]-v0[2])
        h = (direction[1]*e2[2]-direction[2]*e2[1], direction[2]*e2[0]-direction[0]*e2[2], direction[0]*e2[1]-direction[1]*e2[0])
        a = e1[0]*h[0] + e1[1]*h[1] + e1[2]*h[2]
        if a > -0.0000001 and a < 0.0000001:
            continue
        f = 1.0 / a
        d = (origin[0]-v0[0], origin[1]-v0[1], origin[2]-v0[2])
        u = f * (d[0]*h[0] + d[1]*h[1] + d[2]*h[2])
        if u < 0.0 or u > 1.0:
            continue
        q = (d[0]*e1[2]-d[2]*e1[0], d[2]*e1[1]-d[1]*e1[0], d[1]*e1[2]-d[0]*e1[1])
        v = f * (direction[0]*q[0] + direction[1]*q[1] + direction[2]*q[2])
        if v < 0.0 or u + v > 1.0:
            continue
        t = f * (e1[0]*q[0] + e1[1]*q[1] + e1[2]*q[2])
        if t > 0.0000001:
            return True
    return False

def solid_voxelization(mesh_vertices, mesh_faces, octree_dim):
    # 1. Parse and Normalize
    min_coord = (min(v[0] for v in mesh_vertices), min(v[1] for v in mesh_vertices), min(v[2] for v in mesh_vertices))
    max_coord = (max(v[0] for v in mesh_vertices), max(v[1] for v in mesh_vertices), max(v[2] for v in mesh_vertices))
    width = max_coord[0] - min_coord[0]
    height = max_coord[1] - min_coord[1]
    depth = max_coord[2] - min_coord[2]
    max_dim = max(width, height, depth)
    
    dim = next_power_of_two(octree_dim)
    voxel_size = max_dim / dim
    world_size = dim * voxel_size
    origin = ((min_coord[0]+max_coord[0])/2.0, (min_coord[1]+max_coord[1])/2.0, (min_coord[2]+max_coord[2])/2.0)
    origin = (origin[0] - world_size/2.0, origin[1] - world_size/2.0, origin[2] - world_size/2.0)
    
    # 2. Initialize Root
    root = Node()
    root.world_aabb = AABB(origin, (origin[0]+world_size, origin[1]+world_size, origin[2]+world_size))
    root.build_aabb = AABB((0,0,0), (dim, dim, dim))
    root.triangles = mesh_faces
    
    # 3. Subdivide
    subdivide(root, dim)
    
    return root

def subdivide(node, current_dim):
    if current_dim == 1:
        update_leaf_distance(node)
        node.node_type = NT_LEAF
        return

    children = []
    half_dim = current_dim // 2
    for x in range(2):
        for y in range(2):
            for z in range(2):
                child = Node()
                child.dim = half_dim
                
                build_min = (node.build_aabb.min[0] + half_dim*x, node.build_aabb.min[1] + half_dim*y, node.build_aabb.min[2] + half_dim*z)
                build_max = (build_min[0] + half_dim, build_min[1] + half_dim, build_min[2] + half_dim)
                child.build_aabb = AABB(build_min, build_max)
                
                child.world_aabb = AABB(
                    (node.world_aabb.min[0] + build_min[0]*voxel_size, node.world_aabb.min[1] + build_min[1]*voxel_size, node.world_aabb.min[2] + build_min[2]*voxel_size),
                    (node.world_aabb.min[0] + build_max[0]*voxel_size, node.world_aabb.min[1] + build_max[1]*voxel_size, node.world_aabb.min[2] + build_max[2]*voxel_size)
                )
                
                for tri_idx in node.triangles:
                    tri_verts = [mesh_faces[tri_idx][0], mesh_faces[tri_idx][1], mesh_faces[tri_idx][2]]
                    if triangle_aabb_intersects(tri_verts, child.world_aabb):
                        child.triangles.append(tri_idx)
                
                children.append(child)

    for child in children:
        if not child.triangles:
            child.node_type = NT_EMPTY_LEAF
            update_empty_leaf_sign(child)
        else:
            child.node_type = NT_INTERNAL
            subdivide(child, child.dim)
        
        node.children.append(child)

def update_leaf_distance(node):
    leaf_center = ((node.build_aabb.min[0]+node.build_aabb.max[0])/2.0, (node.build_aabb.min[1]+node.build_aabb.max[1])/2.0, (node.build_aabb.min[2]+node.build_aabb.max[2])/2.0)
    leaf_center_world = (node.world_aabb.min[0] + leaf_center[0]*voxel_size, node.world_aabb.min[1] + leaf_center[1]*voxel_size, node.world_aabb.min[2] + leaf_center[2]*voxel_size)
    min_dist = float('inf')
    
    for tri_idx in node.triangles:
        v0, v1, v2 = mesh_faces[tri_idx]
        normal = (v2[1]-v0[1], v2[2]-v0[2], v2[0]-v0[0]) # Cross product placeholder for brevity; standard cross(v2-v0, v1-v0) [G]
        normal = (v1[1]-v0[1], v1[2]-v0[2], v1[0]-v0[0]) # Corrected cross product logic inline
        normal = ((v2[1]-v0[1])*(v1[2]-v0[2]) - (v2[2]-v0[2])*(v1[1]-v0[1]),
                  (v2[2]-v0[2])*(v1[0]-v0[0]) - (v2[0]-v0[0])*(v1[2]-v0[2]),
                  (v2[0]-v0[0])*(v1[1]-v0[1]) - (v2[1]-v0[1])*(v1[0]-v0[0]))
        closest = closest_point_on_triangle(leaf_center_world, v0, v1, v2)
        delta = (closest[0]-leaf_center_world[0], closest[1]-leaf_center_world[1], closest[2]-leaf_center_world[2])
        sign = -1.0 if (delta[0]*normal[0] + delta[1]*normal[1] + delta[2]*normal[2]) < 0.0 else 1.0
        dist = math.sqrt(delta[0]**2 + delta[1]**2 + delta[2]**2)
        
        if dist < abs(min_dist):
            min_dist = dist * sign
            
    node.distance_to_surface = min_dist

def update_empty_leaf_sign(node):
    samples = []
    for i in range(200):
        u, v = hammersley_2d(i, 200)
        samples.append(uniform_spherical_sampling(u, v))
        
    center = ((node.build_aabb.min[0]+node.build_aabb.max[0])/2.0, (node.build_aabb.min[1]+node.build_aabb.max[1])/2.0, (node.build_aabb.min[2]+node.build_aabb.max[2])/2.0)
    center_world = (node.world_aabb.min[0] + center[0]*voxel_size, node.world_aabb.min[1] + center[1]*voxel_size, node.world_aabb.min[2] + center[2]*voxel_size)
    coverage = 0
    misses = 0
    
    for direction in samples:
        if ray_hits_mesh(center_world, direction, node.triangles):
            coverage += 1
        else:
            misses += 1
            
        if misses >= 200 / 4:
            break
            
    f_coverage = coverage / 200
    if f_coverage >= 0.8:
        node.distance_to_surface = -1.0
    else:
        node.distance_to_surface = 1.0
```

## Subtopics

### [Octree-based 3D Voxelization with SAT Pruning](2588-octree-based-3d-voxelization-with-sat-pruning.md)
Uses Separating Axis Theorem for pruning empty bounding volumes instead of simple AABB intersection, offering robustness and performance improvements.

### [Robust Inside and Outside Solid Voxelization](3376-robust-inside-and-outside-solid-voxelization.md)
Handles non-watertight meshes using cube map rendering and visibility propagation, replacing the ray-casting sign test with a GPU-accelerated heuristic.

### [Solid Voxelization via Ray Casting](6829-solid-voxelization-via-ray-casting.md)
Computes solid intervals per pixel via ray-mesh intersection, differing by explicitly finding intervals rather than relying on spatial partitioning pruning.

### [Hierarchical Inside/Outside Propagation](9772-hierarchical-inside-outside-propagation.md)
Post-processing step that corrects inside/outside status by propagating boundary crossings along the +x direction, ensuring consistency without per-voxel ray queries.

### [Solid Voxelization based on Quadtree](13750-solid-voxelization-based-on-quadtree.md)
Uses 2D quadtree structures on projected planes to store intersection distances, reducing memory usage for huge models or high resolutions.

## Operating characteristics
*   **Time Complexity:** Depends on the number of triangles and octree depth. Subdivision is recursive, and triangle assignment requires AABB intersection tests for each triangle at each level. Leaf distance calculation requires closest-point tests for all triangles in the leaf.
*   **Memory Complexity:** Adaptive. Uses an octree structure, which is more memory-efficient than a fixed grid for sparse scenes but requires overhead for node pointers and metadata [S2, unofficial].
*   **Performance:** On an Apple M1 Pro, building the octree for `Armadillo.obj` at dimension 64 took ~484ms before optimization and ~77ms after output optimization (total build time not explicitly separated after optimization, but output was 77ms) [S2, unofficial].
*   **Strengths:** Adaptive resolution, handles large bounding boxes efficiently, supports OBJ format directly.
*   **Limitations:** Only supports OBJ files with triangle-ordered vertices. Empty leaf classification uses a heuristic that may be inaccurate for nodes near the surface (early stop if misses > 25%) [S2, unofficial]. Bounding box expansion by 'step' is required to avoid precision issues at boundaries [S1, unofficial].

## Background
The method originates from work by Peter Trier Mikkelsen, with tutorials available via Alexandra [S2, unofficial]. It builds on [Mesh Voxelization](6514-mesh-voxelization.md) by providing a specific octree-based implementation for solid voxelization.
