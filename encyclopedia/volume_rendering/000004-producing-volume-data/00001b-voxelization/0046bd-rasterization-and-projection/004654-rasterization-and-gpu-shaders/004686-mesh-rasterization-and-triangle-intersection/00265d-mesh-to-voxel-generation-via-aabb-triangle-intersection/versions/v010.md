# Mesh to Voxel Generation via AABB-Triangle Intersection

Also called: AABB-Triangle Voxelization, Triangle Voxelization via AABB-Triangle SAT, Voxelization via Triangle-Cube Intersection, Triangle-Cube Intersection Voxelization, Triangle-to-Voxel Conversion, Triangle Mesh Voxelization, Bounding Box Voxelization

## Overview
This method converts a triangle mesh into a solid 3D voxel grid by iterating over the Axis-Aligned Bounding Box (AABB) of each triangle and testing for intersection with every voxel cube within that box using the Separating Axis Theorem (SAT) [S2, S4, S5, unofficial]. It differs from [Template-based Voxelization](7964-template-based-voxelization.md) by using explicit geometric intersection tests rather than precomputed templates, and from [Fake Voxelization via Triangle-Cube Intersection](6951-fake-voxelization-via-triangle-cube-intersection.md) by typically being followed by a scanline fill to produce a solid interior rather than just a surface shell [S1, S3, unofficial].

## How it works
**Inputs and Outputs:**
*   **Input:** A triangle mesh (vertices and indices), a world-space transformation matrix, a voxel size $s$ (float), and a bounding box for the output grid [S3, S5, unofficial].
*   **Output:** A 3D occupancy grid (voxel array) where each cell is marked as empty or solid [S2, unofficial].

**Data Structures:**
*   `Triangle`: Struct containing three 3D vector fields ($p_1, p_2, p_3$) representing vertices in world space [S5, unofficial].
*   `_voxels`: A 3D integer array `int[y, z, x]` with dimensions derived from the bounding box and voxel size. Values are `0` (empty), `1` (intersected/shell), or `2` (occupied/filled) [S5, unofficial]. Alternatively, a `HashSet<UVec3>` can be used to store unique voxel coordinates [S3, unofficial].
*   `Bounds`: A bounding box defined by `min` and `max` vectors in world space [S5, unofficial].

**Steps:**

1.  **Grid Initialization:**
    *   Transform all mesh vertices to world space using the transformation matrix [S3, S5, unofficial].
    *   Compute the world-space bounding box of the transformed vertices by finding the component-wise minimum ($v_{min}$) and maximum ($v_{max}$) of all vertices [S3, S5, unofficial].
    *   Round $v_{min}$ down to the nearest multiple of $s$ and $v_{max}$ up to the nearest multiple of $s$ [S5, unofficial].
    *   If any dimension of the bounding box is zero (i.e., $max_i == min_i$), add $s$ to $max_i$ to ensure non-zero grid dimensions [S5, unofficial].
    *   Calculate the grid dimensions $(N_x, N_y, N_z)$ as $\lceil (max - min) / s \rceil$ [S1, S5, unofficial].
    *   Initialize the `_voxels` array with zeros [S5, unofficial].

2.  **Shell Generation (Surface Voxelization):**
    *   Iterate through each triangle in the mesh [S2, S4, unofficial].
    *   Compute the triangle's bounding box in world space [S3, unofficial].
    *   Determine the range of voxel indices $[x_{min}, x_{max}] \times [y_{min}, y_{max}] \times [z_{min}, z_{max}]$ that overlap with the triangle's bounding box by translating the bounding box min by subtracting the grid origin and dividing by $s$, then flooring/ceiling [S3, unofficial].
    *   For each voxel index $(ix, iy, iz)$ in this range:
        *   Compute the voxel center in world space:
            $$ c = (ix \cdot s + s/2, iy \cdot s + s/2, iz \cdot s + s/2) + bounds.min $$
            [S3, unofficial]
        *   Perform an **AABB-Triangle Intersection Test** using the Separating Axis Theorem (SAT) [S5, unofficial].
            *   Translate triangle vertices relative to the voxel center: $v_i \leftarrow v_i - c$ [S3, unofficial].
            *   Compute edge vectors: $e_1 = v_2 - v_1$, $e_2 = v_3 - v_2$, $e_3 = v_1 - v_3$ [S3, unofficial].
            *   Compute the triangle normal: $n_{tri} = e_1 \times e_2$ [S3, unofficial].
            *   Define AABB axes: $u_0=(1,0,0)$, $u_1=(0,1,0)$, $u_2=(0,0,1)$ [S3, unofficial].
            *   Test separation along 13 axes:
                1.  **AABB Face Normals ($u_0, u_1, u_2$):**
                    *   Project triangle vertices onto axis $u$: $p_i = v_i \cdot u$ for $i \in \{0,1,2\}$ [S3, unofficial].
                    *   Compute the radius of the AABB projection: $r = s/2 \cdot (|u \cdot u_0| + |u \cdot u_1| + |u \cdot u_2|)$ [S3, unofficial]. Note: Since $u$ is a basis vector, $r = s/2$.
                    *   Separation condition: $\max(\min(p_0,p_1,p_2), -\max(p_0,p_1,p_2)) > r$ [S3, unofficial]. If true, the axis separates the triangle from the AABB [S3, unofficial].
                2.  **Edge Cross Products ($u_k \times e_j$):**
                    *   Compute 9 cross-product axes $a_{kj} = u_k \times e_j$ for $k,j \in \{0,1,2\}$ [S3, unofficial].
                    *   For each axis $a$, compute the projection interval of the triangle: $[min_p, max_p]$ where $min_p = \min(v_i \cdot a)$ and $max_p = \max(v_i \cdot a)$ [S5, unofficial].
                    *   Compute the radius of the AABB projection: $r_a = s/2 \cdot (|a \cdot u_0| + |a \cdot u_1| + |a \cdot u_2|)$ [S3, unofficial].
                    *   Separation condition: $min_p > r_a$ or $max_p < -r_a$ [S5, unofficial].
                3.  **Triangle Normal ($n_{tri}$):**
                    *   Project triangle vertices onto $n_{tri}$: $p_i = v_i \cdot n_{tri}$ [S3, unofficial].
                    *   Compute the radius of the AABB projection along $n_{tri}$: $r_n = s/2 \cdot (|n_{tri} \cdot u_0| + |n_{tri} \cdot u_1| + |n_{tri} \cdot u_2|)$ [S3, unofficial].
                    *   Separation condition: $\max(\min(p_0,p_1,p_2), -\max(p_0,p_1,p_2)) > r_n$ [S3, unofficial].
            *   If all 13 axes pass the SAT test (no separation), the triangle intersects the voxel [S3, unofficial].
        *   If an intersection is found, mark `_voxels[iy, iz, ix] = 1` and break the triangle loop for this voxel (optimization: one intersection is sufficient to mark the voxel as part of the shell) [S5, unofficial].

3.  **Solid Fill (Scanline Fill):**
    *   Process the voxel grid slice by slice (e.g., along the Z-axis), and each slice row by row (e.g., along the X-axis) [S1, S4, unofficial].
    *   Initialize a 'pen' state to 'Up' (not filling) for each row [S1, S4, unofficial].
    *   For each voxel in the row:
        *   If the voxel is empty (`_voxels == 0`), continue to the next voxel without changing the pen state [S1, unofficial].
        *   If the voxel is part of the shell (`_voxels == 1`):
            *   Cast a horizontal ray from left to right through the center of the voxel to find all intersecting triangles [S1, S4, unofficial].
            *   Identify the 'last' triangle $T_{last}$ intersected by the ray (the one with the largest intersection parameter or furthest in the ray direction) [S1, S4, unofficial].
            *   Determine the orientation of $T_{last}$ relative to the scan direction (X-axis) [S1, S4, unofficial]. Let $n_x$ be the x-component of the normal of $T_{last}$ [S4, unofficial].
            *   **Pen State Update:**
                *   If $n_x < 0$ (normal faces left, i.e., outward from the model's interior relative to the scan direction), set Pen = Down [S1, S4, unofficial].
                *   If $n_x > 0$ (normal faces right, i.e., inward or exiting), set Pen = Up [S1, S4, unofficial].
            *   Mark the current voxel as solid (`_voxels = 2`) if the pen is Down [S4, unofficial].
        *   If the pen is Down, mark subsequent empty voxels as solid (`_voxels = 2`) as the scan moves to the right [S1, S4, unofficial].
        *   If the pen is Up, leave empty voxels empty [S1, S4, unofficial].
    *   Repeat for every row in the slice, and every slice in the volume [S1, S4, unofficial].

**Pseudocode:**

```python
import math

class Vec3:
    def __init__(self, x, y, z): self.x, self.y, self.z = x, y, z
    def __add__(self, o): return Vec3(self.x+o.x, self.y+o.y, self.z+o.z)
    def __sub__(self, o): return Vec3(self.x-o.x, self.y-o.y, self.z-o.z)
    def __mul__(self, s): return Vec3(self.x*s, self.y*s, self.z*s)
    def __rmul__(self, s): return self.__mul__(s)
    def __getitem__(self, i): return (self.x, self.y, self.z)[i]
    def __setitem__(self, i, v): (self.x, self.y, self.z)[i] = v
    def length_sq(self): return self.x**2 + self.y**2 + self.z**2

def dot(a, b): return a.x*b.x + a.y*b.y + a.z*b.z
def cross(a, b): return Vec3(a.y*b.z - a.z*b.y, a.z*b.x - a.x*b.z, a.x*b.y - a.y*b.x)
def abs_vec(v): return Vec3(abs(v.x), abs(v.y), abs(v.z))

def mesh_to_voxel(mesh, transform, voxel_size):
    # 1. Grid Initialization
    vertices_world = [transform * v for v in mesh.vertices]
    min_bound = Vec3(min(v.x for v in vertices_world), min(v.y for v in vertices_world), min(v.z for v in vertices_world))
    max_bound = Vec3(max(v.x for v in vertices_world), max(v.y for v in vertices_world), max(v.z for v in vertices_world))
    
    min_bound = Vec3(math.floor(min_bound.x / voxel_size) * voxel_size, math.floor(min_bound.y / voxel_size) * voxel_size, math.floor(min_bound.z / voxel_size) * voxel_size)
    max_bound = Vec3(math.ceil(max_bound.x / voxel_size) * voxel_size, math.ceil(max_bound.y / voxel_size) * voxel_size, math.ceil(max_bound.z / voxel_size) * voxel_size)
    
    for i in range(3):
        if max_bound[i] == min_bound[i]:
            max_bound[i] += voxel_size
            
    bounds_min = min_bound
    bounds_max = max_bound
    bounds_size = bounds_max - bounds_min
    
    Nx = int(math.ceil(bounds_size.x / voxel_size))
    Ny = int(math.ceil(bounds_size.y / voxel_size))
    Nz = int(math.ceil(bounds_size.z / voxel_size))
    
    voxels = [[[0 for _ in range(Nx)] for _ in range(Nz)] for _ in range(Ny)]
    
    # 2. Shell Generation
    for triangle in mesh.triangles:
        v1, v2, v3 = [transform * p for p in triangle.vertices]
        
        t_min = Vec3(min(v1.x, v2.x, v3.x), min(v1.y, v2.y, v3.y), min(v1.z, v2.z, v3.z))
        t_max = Vec3(max(v1.x, v2.x, v3.x), max(v1.y, v2.y, v3.y), max(v1.z, v2.z, v3.z))
        
        x_min = int(math.floor((t_min.x - bounds_min.x) / voxel_size))
        x_max = int(math.ceil((t_max.x - bounds_min.x) / voxel_size))
        y_min = int(math.floor((t_min.y - bounds_min.y) / voxel_size))
        y_max = int(math.ceil((t_max.y - bounds_min.y) / voxel_size))
        z_min = int(math.floor((t_min.z - bounds_min.z) / voxel_size))
        z_max = int(math.ceil((t_max.z - bounds_min.z) / voxel_size))
        
        x_min = max(0, x_min); x_max = min(Nx - 1, x_max)
        y_min = max(0, y_min); y_max = min(Ny - 1, y_max)
        z_min = max(0, z_min); z_max = min(Nz - 1, z_max)
        
        for ix in range(x_min, x_max + 1):
            for iy in range(y_min, y_max + 1):
                for iz in range(z_min, z_max + 1):
                    center = Vec3(
                        (ix + 0.5) * voxel_size + bounds_min.x,
                        (iy + 0.5) * voxel_size + bounds_min.y,
                        (iz + 0.5) * voxel_size + bounds_min.z
                    )
                    
                    if aabb_triangle_intersect(center, voxel_size, v1, v2, v3):
                        voxels[iy][iz][ix] = 1
                        break 
    
    # 3. Solid Fill
    for iz in range(Nz):
        for iy in range(Ny):
            pen_down = False
            for ix in range(Nx):
                if voxels[iy][iz][ix] == 0:
                    if pen_down:
                        voxels[iy][iz][ix] = 2
                    continue
                
                if voxels[iy][iz][ix] == 1:
                    ray_origin = Vec3(
                        bounds_min.x + ix * voxel_size + voxel_size/2,
                        bounds_min.y + iy * voxel_size + voxel_size/2,
                        bounds_min.z + iz * voxel_size + voxel_size/2
                    )
                    ray_direction = Vec3(1, 0, 0)
                    
                    last_triangle = None
                    max_t = -float('inf')
                    
                    for triangle in mesh.triangles:
                        v1, v2, v3 = [transform * p for p in triangle.vertices]
                        t = ray_triangle_intersect(ray_origin, ray_direction, v1, v2, v3)
                        if t is not None and t > max_t:
                            max_t = t
                            last_triangle = triangle
                    
                    if last_triangle:
                        n = cross(last_triangle.v2 - last_triangle.v1, last_triangle.v3 - last_triangle.v1)
                        if n.x < 0:
                            pen_down = True
                        else:
                            pen_down = False
                    
                    voxels[iy][iz][ix] = 2
                else:
                    pass
                    
    return voxels

def aabb_triangle_intersect(center, size, v1, v2, v3):
    v1 = v1 - center
    v2 = v2 - center
    v3 = v3 - center
    
    e1 = v2 - v1
    e2 = v3 - v2
    e3 = v1 - v3
    
    n_tri = cross(e1, e2)
    if n_tri.length_sq() < 1e-8: return False  # Guard for degenerate triangles [G]
    
    u0 = Vec3(1, 0, 0)
    u1 = Vec3(0, 1, 0)
    u2 = Vec3(0, 0, 1)
    
    axes = [u0, u1, u2, 
            cross(u0, e1), cross(u0, e2), cross(u0, e3),
            cross(u1, e1), cross(u1, e2), cross(u1, e3),
            cross(u2, e1), cross(u2, e2), cross(u2, e3),
            n_tri]
            
    half_size = size / 2.0
    
    for axis in axes:
        p0 = dot(v1, axis)
        p1 = dot(v2, axis)
        p2 = dot(v3, axis)
        
        min_p = min(p0, p1, p2)
        max_p = max(p0, p1, p2)
        
        r = half_size * (abs(axis.x) + abs(axis.y) + abs(axis.z))
        
        if min_p > r or max_p < -r:
            return False
            
    return True

def ray_triangle_intersect(origin, direction, v1, v2, v3):
    e1 = v2 - v1
    e2 = v3 - v1
    h = cross(direction, e2)
    a = dot(e1, h)
    if abs(a) < 1e-8:
        return None
    f = 1.0 / a
    s = origin - v1
    u = f * dot(s, h)
    if u < 0.0 or u > 1.0:
        return None
    q = cross(s, e1)
    v = f * dot(direction, q)
    if v < 0.0 or u + v > 1.0:
        return None
    t = f * dot(e2, q)
    if t > 1e-8:
        return t
    return None
```

## Subtopics

### [Level 1 Triangle-Voxel Classification](4872-level-1-triangle-voxel-classification.md)
Level 1 Triangle-Voxel Classification classifies input triangles into a coarse 3D voxel grid by mapping vertices to voxel indices and testing overlap with all candidate voxels the triangle spans. It identifies candidate voxels via vertex mapping rather than testing every voxel against every triangle, enabling parallel processing where each thread handles one triangle.

### [Tessellation-based Voxelization](5430-tessellation-based-voxelization.md)
Tessellation-based Voxelization is a GPU-accelerated method for generating 3D voxel grids from triangle meshes by leveraging the hardware tessellation pipeline to subdivide geometry before rasterization. It differs from fixed-function or CPU-based voxelizers by enabling adaptive triangle density and displacement mapping during the generation phase, allowing for higher fidelity in complex regions.

### [Fake Voxelization via Triangle-Cube Intersection](6951-fake-voxelization-via-triangle-cube-intersection.md)
Fake Voxelization via Triangle-Cube Intersection is a surface-only voxelization technique that digitizes a triangulated mesh by independently testing each triangle against a grid of axis-aligned cubes (voxels). Unlike solid voxelization methods that fill the interior volume using Constructive Solid Geometry (CSG), this approach outputs only the voxels intersected by the mesh surface, making it computationally simpler and suitable for generating surface representations. It is distinguished from its siblings by its independence from tessellation depth and its reliance on a template-based intersection test to control topological separability (6- or 26-connectivity).

### [Robust Mesh Voxelization via Exact Predicates](8770-robust-mesh-voxelization-via-exact-predicates.md)
A mesh-native voxelizer that produces an occupancy grid or a signed-distance field (SDF) over a Piecewise Linear Complex (PLC)'s bounding box, using exact-predicate classification to avoid epsilon-ray speckle. Unlike [Level 1 Triangle-Voxel Classification](4872-level-1-triangle-voxel-classification.md) which may rely on approximate ray casting, this method uses Shewchuk's exact predicates for geometric calculations to ensure robust classification of watertight meshes in single precision. It differs from [Tessellation-based Voxelization](5430-tessellation-based-voxelization.md) by operating directly on the input triangle mesh without prior subdivision, and from [Fake Voxelization via Triangle-Cube Intersection](6951-fake-voxelization-via-triangle-cube-intersection.md) by providing true inside/outside parity checks rather than mere intersection counts.

### [Triangle Subdivision for Voxelization](11480-triangle-subdivision-for-voxelization.md)
Triangle Subdivision for Voxelization is a pre-processing method that recursively splits mesh triangles to ensure they are small enough to be voxelized efficiently and predictably. It solves the problem of variable voxel counts per triangle, which complicates memory allocation and parallel processing in out-of-core or batch-based voxelization pipelines. Unlike general-purpose mesh smoothing or tessellation, this method is geometry-driven, targeting specific edge-length or area thresholds relative to the voxel resolution to guarantee homogeneous voxel generation and compact Morton index ranges. It differs from [Level 1 Triangle-Voxel Classification](4872-level-1-triangle-voxel-classification.md) by actively modifying the mesh geometry rather than just classifying existing triangles, and from [Tessellation-based Voxelization](5430-tessellation-based-voxelization.md) by using a deterministic, CPU/GPU-friendly iterative queue rather than hardware tessellation pipelines.

### [Voxel Plane Intersection via Vertex Weights](15504-voxel-plane-intersection-via-vertex-weights.md)
This method determines which voxels within a triangle's Axis-Aligned Bounding Box (AABB) are intersected by the triangle's plane and its edge tangent planes. It serves as the final rasterization step in mesh-to-voxel generation, refining the candidate voxels identified by coarse AABB tests. It is distinguished from sibling methods by its reliance on a discrete vertex-weight summation algorithm rather than continuous geometric intersection tests or tessellation, offering a brute-force but highly parallelizable approach suitable for CPU implementation.

### Mesh-based VCP Grid Generation
Mesh-based VCP Grid Generation computes a Vector-to-Closest-Point (VCP) from each grid point to the mesh triangles using barycentric coordinates of the perpendicular projection [S7, unofficial]. If the projection is outside the triangle, it computes the closest point on the edges [S7, unofficial]. Triangles are inserted into an empty grid, updating grid points if they are empty or point to a triangle with a greater VCP distance [S7, unofficial]. The VCP data is then expanded using region growing, where grid points adopt the triangle of their neighbors if it results in a shorter VCP distance [S7, unofficial].

### Exact Voxelization Method
An alternative voxelization method implemented in binvox, written by Eric Haines, using triangle overlap code by Tomas Akenine-Möller [S8]. A bug existed in version 1.17 where triangles completely at max x/y/z were not voxelized correctly [S8]. In version 1.02, the -e option caused triangles to be voxelized too thick [S8]. When using the -e method with .obj to .schematic conversion, the -mb parameter can be used to specify block IDs in material names [S8].

## Operating characteristics
*   **Time Complexity:** $O(N_t \cdot N_v)$ in the worst case, where $N_t$ is the number of triangles and $N_v$ is the number of voxels in the bounding box of each triangle [G]. With the SAT test, each intersection check is constant time but involves 13 axis tests [S3, unofficial]. The scanline fill is $O(N_{voxels})$ [G].
*   **Memory Complexity:** $O(N_x \cdot N_y \cdot N_z)$ for the voxel grid [G].
*   **Performance:** The method is straightforward to implement and parallelize (e.g., per-voxel or per-triangle parallelism) [S5, unofficial]. However, it can be slow for high-resolution grids or complex meshes due to the large number of intersection tests [G].
*   **Strengths:** Produces solid, watertight voxel models suitable for physics simulations [S1, unofficial]. The SAT test is robust and handles arbitrary triangle orientations [G].
*   **Limitations:** The brute-force intersection testing can be computationally expensive. The scanline fill requires ray casting for each shell voxel, which adds overhead [S4, unofficial].
*   **When to use:** When a solid, volumetric representation is required for simulation (e.g., heat diffusion, fracture) [S1, unofficial].
*   **When not to use:** When only a surface representation is needed (use [Fake Voxelization via Triangle-Cube Intersection](6951-fake-voxelization-via-triangle-cube-intersection.md)) [G]. When performance is critical and the mesh is very complex (consider [Tessellation-based Voxelization](5430-tessellation-based-voxelization.md) or [Robust Mesh Voxelization via Exact Predicates](8770-robust-mesh-voxelization-via-exact-predicates.md)) [G].

## Background
The method was popularized by David Rosen in a 2009 blog post describing voxelization for automatic skinning and physical simulations in games [S1, S4, unofficial]. It is based on the principle of solidifying a surface shell and then filling the interior using a scanline algorithm [S1, S4, unofficial]. The AABB-Triangle intersection test using the Separating Axis Theorem is a standard technique in computer graphics for collision detection and has been adapted for voxelization [S5, unofficial]. The method is used in various game development contexts for creating destructible environments and physics bodies [S1, unofficial].
