# Parallel Chunk Voxelization with Early Quit

Also called: Rayon Chunk Voxelization, Threaded Batch Voxelization

## Overview
This method distributes per-chunk voxelization across multiple threads using the Rayon parallel iterator library, with atomic counters tracking early termination conditions and a channel to stream results to the main thread [S1, unofficial]. It skips chunks that contain no geometry or produce empty voxel batches via early-quit checks [S1, unofficial]. It builds on [Triangle Voxelization with Diagonal and Edge Checks](7477-triangle-voxalization-with-diagonal-and-edge-checks.md) for the actual intersection logic within each chunk [G].

## How it works
**Inputs and Outputs:**
- **Input:** A list of chunk world positions (`chunk_positions`), a mapping from chunk positions to triangle face indices (`chunk_face_map`), a list of mesh vertices (`vertices`), and model parameters (`depth`, `chunk_world_size`, `voxel_size`, `voxels_per_axis`, `mesh_min`) [S1, unofficial].
- **Output:** A stream of processed chunks, where each chunk is a pair of its world position (`IVec3`) and a voxel batch (`Batch<i32>`) containing the voxelized data (patches) [S1, unofficial].

**Data Structures:**
- `chunk_face_map`: A hash map (`FxHashMap<IVec3, Vec<IVec3>>`) mapping each chunk's world position to a list of face indices belonging to that chunk [S1, unofficial].
- `Batch<i32>`: A structure representing the voxel data for a chunk, containing patches. It has a method `has_patches()` to check if it contains valid data [S1, unofficial].
- `IVec3`: A 3D integer vector type representing chunk coordinates [G].
- `AtomicUsize`: Used for thread-safe counters [S1, unofficial].
- `AtomicBool`: Used for the stop signal [S1, unofficial].
- `Channel`: A bounded channel (capacity 1024) for sending `(IVec3, Batch<i32>)` pairs from worker threads to the main thread [S1, unofficial].

**Parameters:**
- `chunk_face_map`: Maps chunk positions to face indices [S1, unofficial].
- `depth`: LOD depth used to query `voxels_per_axis` and `chunk_world_size` from the model [S1, unofficial].
- `chunk_world_size`: Size of a chunk in world units [G].
- `voxel_size`: Size of a single voxel [G].
- `voxels_per_axis`: Number of voxels along one axis in a chunk [G].
- `mesh_min`: Minimum bounding box of the mesh [G].
- `stop_signal`: A boolean flag to signal threads to terminate [S1, unofficial].

**Numbered Steps:**
1. Initialize atomic counters: `early_quit_no_faces`, `early_quit_empty_faces`, `early_quit_empty_batch`, `processed_chunks` (all `Arc<AtomicUsize>`), and `stop_signal` (`Arc<AtomicBool>`) [S1, unofficial].
2. Create a bounded channel `(tx, rx)` with capacity 1024 for `(IVec3, Batch<i32>)` pairs [S1, unofficial].
3. Spawn worker threads using Rayon's parallel iterator: `chunk_positions.par_iter().for_each(|chunk_position| { ... })` [S1, unofficial].
4. Inside the parallel loop for each `chunk_position`:
   a. Check `stop_signal_clone.load(Ordering::Relaxed)`. If true, return immediately [S1, unofficial].
   b. Look up `faces` in `chunk_face_map` for `chunk_position`. If not found (`None`), increment `early_quit_no_faces` and return [S1, unofficial].
   c. If `faces.is_empty()`, increment `early_quit_empty_faces` and return [S1, unofficial].
   d. Call `Self::voxelize_chunk(chunk_position, depth, chunk_world_size, voxel_size, voxels_per_axis, mesh_min, faces, &vertices)` [S1, unofficial].
   e. If the resulting `batch` has no patches (`!batch.has_patches()`), increment `early_quit_empty_batch` and return [S1, unofficial].
   f. If `batch` has patches, increment `processed_chunks` and send `(*chunk_position, batch)` through `tx` [S1, unofficial].
5. In the main thread:
   a. Drop `tx` to close the channel [S1, unofficial].
   b. Iterate over `rx.iter()` [S1, unofficial].
   c. For each `(chunk_position, batch)`, call `self.model.get_or_create_chunk(chunk_position).apply_batch(&mut interner, &batch)` to integrate the voxel data into the model [S1, unofficial].

**Pseudocode:**
```python
import threading
from collections import deque
from typing import List, Tuple, Dict, Any

def parallel_chunk_voxelization(
    chunk_positions: List[Tuple[int, int, int]],
    chunk_face_map: Dict[Tuple[int, int, int], List[int]],
    depth: int,
    chunk_world_size: float,
    voxel_size: float,
    voxels_per_axis: int,
    mesh_min: Tuple[float, float, float],
    vertices: List[Tuple[float, float, float]],
    model: Any,
    interner: Any
) -> Dict[str, int]:
    early_quit_no_faces = [0]
    early_quit_empty_faces = [0]
    early_quit_empty_batch = [0]
    processed_chunks = [0]
    stop_signal = [False]
    counter_lock = threading.Lock()

    capacity = 1024
    channel = deque(maxlen=capacity)
    channel_lock = threading.Lock()

    def process_chunk(chunk_position):
        if stop_signal[0]:
            return
        faces = chunk_face_map.get(chunk_position)
        if faces is None:
            with counter_lock:
                early_quit_no_faces[0] += 1
            return
        if not faces:
            with counter_lock:
                early_quit_empty_faces[0] += 1
            return
        batch = voxelize_chunk(chunk_position, depth, chunk_world_size, voxel_size, voxels_per_axis, mesh_min, faces, vertices)
        if not batch.has_patches():
            with counter_lock:
                early_quit_empty_batch[0] += 1
            return
        with counter_lock:
            processed_chunks[0] += 1
        with channel_lock:
            channel.append((chunk_position, batch))

    # Parallel iteration over chunk_positions (equivalent to Rayon's par_iter().for_each)
    import concurrent.futures
    with concurrent.futures.ThreadPoolExecutor() as executor:
        executor.map(process_chunk, chunk_positions)

    # Main thread collects results (drop tx equivalent)
    while channel:
        with channel_lock:
            if channel:
                chunk_position, batch = channel.popleft()
            else:
                break
        model.get_or_create_chunk(chunk_position).apply_batch(interner, batch)

    return {
        "early_quit_no_faces": early_quit_no_faces[0],
        "early_quit_empty_faces": early_quit_empty_faces[0],
        "early_quit_empty_batch": early_quit_empty_batch[0],
        "processed_chunks": processed_chunks[0]
    }

def voxelize_chunk(chunk_position, depth, chunk_world_size, voxel_size, voxels_per_axis, mesh_min, faces, vertices):
```

**Edge Cases and Pitfalls:**
- **Precision:** Not given in the sources. [G]
- **Boundaries:** Not given in the sources. [G]
- **Degenerate Input:** If `chunk_positions` is empty, the parallel loop does nothing, and the main thread receives no results. [S1, unofficial]
- **Channel Blocking:** Capacity of 1024 mitigates blocking if the main thread is slow to consume results. [S1, unofficial]
- **Stop Signal:** Checked at the beginning of each iteration to allow for graceful termination. [S1, unofficial]
