# Triangle Voxelization with Diagonal and Edge Checks

Also called: Line-Plane Collision Voxelization, numpy.stl Voxelization

## Overview
This method determines if a voxel is intersected by a triangle by checking if the voxel's diagonals cross the triangle's plane within the triangle bounds, and handling edge cases where the triangle lies entirely within or touches the voxel faces [S1, unofficial]. It is a specific implementation of [Fake Voxelization via Triangle-Cube Intersection](6951-fake-voxelization-via-triangle-cube-intersection.md) that avoids complex Constructive Solid Geometry (CSG) operations by treating each triangle independently [S1, unofficial].

## How it works
**Inputs and Outputs:**
- Input: A triangle defined by three vertices $P_0, P_1, P_2$ in 3D space [G].
- Output: A set of voxel coordinates $(x, y, z)$ that are intersected by the triangle [G].

**Data Structures:**
- Triangle vertices: Array of 3 vectors, each with 3 floats $(x, y, z)$ [G].
- Voxel coordinates: Integer triplets $(x, y, z)$ [G].
- Plane normal: 3D vector $\mathbf{n}$ [S1, unofficial].

**Steps:**

1. **Compute Bounding Box:**
   Calculate the minimum and maximum coordinates of the triangle vertices [S1, unofficial].
   $$
   \begin{aligned}
   \text{minx} &= \lfloor \min(P_{0x}, P_{1x}, P_{2x}) \rfloor \\
   \text{maxx} &= \lceil \max(P_{0x}, P_{1x}, P_{2x}) \rceil \\
   \text{miny} &= \lfloor \min(P_{0y}, P_{1y}, P_{2y}) \rfloor \\
   \text{maxy} &= \lceil \max(P_{0y}, P_{1y}, P_{2y}) \rceil \\
   \text{minz} &= \lfloor \min(P_{0z}, P_{1z}, P_{2z}) \rfloor \\
   \text{maxz} &= \lceil \max(P_{0z}, P_{1z}, P_{2z}) \rceil
   \end{aligned}
   $$
   Iterate through all integer voxel coordinates $(x, y, z)$ such that $\text{minx} \le x \le \text{maxx}$, $\text{miny} \le y \le \text{maxy}$, and $\text{minz} \le z \le \text{maxz}$ [S1, unofficial].

2. **Compute Triangle Plane:**
   Calculate the plane normal $\mathbf{n}$ and a point on the plane (e.g., $P_0$) [S1, unofficial].
   $$
   \begin{aligned}
   \mathbf{v}_0 &= P_1 - P_0 \\
   \mathbf{v}_3 &= P_2 - P_0 \\
   \mathbf{n} &= \mathbf{v}_0 \times \mathbf{v}_3
   \end{aligned}
   $$

3. **Diagonal Intersection Check:**
   For each voxel $(x, y, z)$, check if any of the 4 main diagonals of the voxel cube intersect the triangle plane inside the triangle bounds [S1, unofficial]. The voxel cube is centered at $(x, y, z)$ with side length 1, extending from $x-0.5$ to $x+0.5$, etc. [G]. The 4 diagonals connect opposite corners [S1, unofficial]. The specific diagonals checked in the reference implementation are:
   - From $(x-0.5, y-0.5, z-0.5)$ to $(x, y, z)$ with direction $(1, 1, 1)$ [S1, unofficial].
   - From $(x+0.5, y+0.5, z-0.5)$ to $(x, y, z)$ with direction $(-1, -1, 1)$ [S1, unofficial].
   - From $(x+0.5, y-0.5, z-0.5)$ to $(x, y, z)$ with direction $(-1, 1, 1)$ [S1, unofficial].
   - From $(x-0.5, y+0.5, z-0.5)$ to $(x, y, z)$ with direction $(1, -1, 1)$ [S1, unofficial].
   
   For each diagonal, perform a line-plane intersection test [S1, unofficial]. If the intersection point lies within the voxel bounds and inside the triangle, the voxel is marked as intersected [S1, unofficial].

4. **Edge Case Check:**
   If all diagonal checks fail, check for edge cases where the triangle might be completely inside the voxel or touch its faces without crossing the main diagonals in a detectable way [S1, unofficial]. This involves:
   - Checking if the triangle intersects the faces of the voxel [S1, unofficial].
   - Checking if a triangle vertex (origin) is completely inside the voxel bounds [S1, unofficial].

**Formulas:**

**Line-Plane Intersection:**
Given a ray defined by origin $\mathbf{r}_0$ and direction $\mathbf{d}$, and a plane defined by normal $\mathbf{n}$ and point $\mathbf{p}_0$:
$$
\begin{aligned}
\mathbf{w} &= \mathbf{r}_0 - \mathbf{p}_0 \\
\text{ndotu} &= \mathbf{n} \cdot \mathbf{d} \\
\text{If } |\text{ndotu}| < \epsilon, & \text{ the ray is parallel to the plane. Return False.} \\
si &= -\frac{\mathbf{n} \cdot \mathbf{w}}{\text{ndotu}} \\
\mathbf{P}_{si} &= \mathbf{w} + si \cdot \mathbf{d} + \mathbf{p}_0
\end{aligned}
$$
Where $\epsilon = 10^{-6}$ [S1, unofficial].

**Point-in-Triangle Test:**
A point $\mathbf{p}$ is inside triangle $abc$ if it is on the same side of each edge as the opposite vertex [S1, unofficial].
$$
\begin{aligned}
\text{SameSide}(p_1, p_2, a, b) &= (\mathbf{b} - \mathbf{a}) \times (\mathbf{p}_1 - \mathbf{a}) \cdot (\mathbf{b} - \mathbf{a}) \times (\mathbf{p}_2 - \mathbf{a}) \ge 0 \\
\text{PointInTriangle}(\mathbf{p}, abc) &= \text{SameSide}(\mathbf{p}, a, b, c) \land \text{SameSide}(\mathbf{p}, b, a, c) \land \text{SameSide}(\mathbf{p}, c, a, b)
\end{aligned}
$$
[S1, unofficial]

**Pseudocode:**

```python
import numpy as np

def triangle_voxalize(triangle):
    """
    Voxelize a single triangle using diagonal and edge checks.
    triangle: list of 3 numpy arrays, each shape (3,) representing P0, P1, P2
    Returns: list of voxel coordinates (x, y, z)
    """
    p0 = np.array(triangle[0], dtype=float)
    p1 = np.array(triangle[1], dtype=float)
    p2 = np.array(triangle[2], dtype=float)

    # Compute plane normal
    v0 = p1 - p0
    v3 = p2 - p0
    plane_normal = np.cross(v0, v3)

    # Compute bounding box
    trix = [p0[0], p1[0], p2[0]]
    triy = [p0[1], p1[1], p2[1]]
    triz = [p0[2], p1[2], p2[2]]
    
    minx = int(np.floor(np.min(trix)))
    maxx = int(np.ceil(np.max(trix)))
    miny = int(np.floor(np.min(triy)))
    maxy = int(np.ceil(np.max(triy)))
    minz = int(np.floor(np.min(triz)))
    maxz = int(np.ceil(np.max(triz)))

    points = []

    # Iterate through voxels in bounding box
    for x in range(minx, maxx + 1):
        for y in range(miny, maxy + 1):
            for z in range(minz, maxz + 1):
                # Check 4 diagonals
                # Diagonal 1: (x-0.5, y-0.5, z-0.5) to (x, y, z)
                if line_plane_collision(triangle, plane_normal, p0, np.array([1, 1, 1]), 
                                        np.array([x-0.5, y-0.5, z-0.5]), np.array([x, y, z])):
                    points.append([x, y, z])
                    continue
                
                # Diagonal 2: (x+0.5, y+0.5, z-0.5) to (x, y, z)
                if line_plane_collision(triangle, plane_normal, p0, np.array([-1, -1, 1]), 
                                        np.array([x+0.5, y+0.5, z-0.5]), np.array([x, y, z])):
                    points.append([x, y, z])
                    continue

                # Diagonal 3: (x+0.5, y-0.5, z-0.5) to (x, y, z)
                if line_plane_collision(triangle, plane_normal, p0, np.array([-1, 1, 1]), 
                                        np.array([x+0.5, y-0.5, z-0.5]), np.array([x, y, z])):
                    points.append([x, y, z])
                    continue

                # Diagonal 4: (x-0.5, y+0.5, z-0.5) to (x, y, z)
                if line_plane_collision(triangle, plane_normal, p0, np.array([1, -1, 1]), 
                                        np.array([x-0.5, y+0.5, z-0.5]), np.array([x, y, z])):
                    points.append([x, y, z])
                    continue

                # Edge case check
                if check_edge_cases(triangle, plane_normal, p0, x, y, z):
                    points.append([x, y, z])

    return points

def line_plane_collision(triangle, plane_normal, plane_point, ray_direction, ray_point, voxel_center, epsilon=1e-6):
    """
    Check if a ray intersects the triangle plane within the triangle bounds and voxel.
    """
    ndotu = np.dot(plane_normal, ray_direction)
    if abs(ndotu) < epsilon:
        return False

    w = ray_point - plane_point
    si = -np.dot(plane_normal, w) / ndotu
    psi = w + si * ray_direction + plane_point

    # Check if intersection point is within the voxel cube
    if (abs(psi[0] - voxel_center[0]) <= 0.5 and 
        abs(psi[1] - voxel_center[1]) <= 0.5 and 
        abs(psi[2] - voxel_center[2]) <= 0.5):
        
        # Check if point is inside the triangle
        if point_in_triangle(psi, triangle):
            return True
    return False

def point_in_triangle(p, triangle):
    """
    Check if point p is inside triangle defined by 3 vertices.
    """
    a, b, c = triangle
    return same_side(p, a, b, c) and same_side(p, b, a, c) and same_side(p, c, a, b)

def same_side(p1, p2, a, b):
    """
    Check if p1 and p2 are on the same side of edge ab.
    """
    cp1 = np.cross(b - a, p1 - a)
    cp2 = np.cross(b - a, p2 - a)
    return np.dot(cp1, cp2) >= 0

def check_edge_cases(triangle, plane_normal, p0, x, y, z):
    """
    Check edge cases: triangle intersects voxel faces or is completely inside.
    """
    # Check if triangle origin is inside voxel bounds
    if (x - 0.5 <= p0[0] <= x + 0.5 and
        y - 0.5 <= p0[1] <= y + 0.5 and
        z - 0.5 <= p0[2] <= z + 0.5):
        return True
        
    # Check line-plane collisions on voxel faces (x, y, z faces)
    face_normals = [np.array([1,0,0]), np.array([-1,0,0]),
                    np.array([0,1,0]), np.array([0,-1,0]),
                    np.array([0,0,1]), np.array([0,0,-1])]
    face_coords = [x+0.5, x-0.5, y+0.5, y-0.5, z+0.5, z-0.5]
    
    for normal, coord in zip(face_normals, face_coords):
        ray_dir = normal
        if np.array_equal(normal, np.array([1,0,0])) or np.array_equal(normal, np.array([-1,0,0])):
            ray_pt = np.array([coord, y, z])
        elif np.array_equal(normal, np.array([0,1,0])) or np.array_equal(normal, np.array([0,-1,0])):
            ray_pt = np.array([x, coord, z])
        else:
            ray_pt = np.array([x, y, coord])
            
        if line_plane_collision(triangle, plane_normal, p0, ray_dir, ray_pt, np.array([x,y,z])):
            return True
    return False
```

**Parameters:**
- Epsilon: $10^{-6}$, used to determine if the ray direction is parallel to the plane [S1, unofficial].

**Edge Cases and Pitfalls:**
- If the triangle is completely inside the voxel or touches its faces, diagonal checks might miss it [S1, unofficial]. The `check_edge_cases` function handles this by checking line-plane collisions on the voxel faces (x, y, z faces) and checking if the triangle origin is within the voxel bounds [S1, unofficial].
- Precision issues may arise when the triangle is nearly parallel to the voxel faces or diagonals [G].

## Subtopics

### [Hollow Voxel Rasterization](13746-hollow-voxel-rasterization.md)
Hollow Voxel Rasterization is a fast, memory-efficient method for generating a voxel shell (hollow interior) from an arbitrary polyhedron, rather than a solid volume. It is specifically suited for shapes intended to be hollow or meshes with fine structures at low target resolutions. Unlike solid voxelization methods that fill the interior, this approach inverts the containment test: it marks a voxel as part of the mesh if any mesh face lies inside the voxel's bounding box, effectively capturing the surface geometry without occupying internal voxels.

### Dachille and Kaufman Anti-aliased Triangle Voxelization
Dachille and Kaufman devised a more accurate software method that employs fast incremental arithmetic for rapid voxelization of poly-meshes on a per-triangle basis [S2, book]. The algorithm voxelize a triangle by scanning a bounding box of the triangle in raster order [S2, book]. For each voxel in the bounding box, a filter equation (linear function of distance from triangle) is evaluated and stored [S2, book]. Voxels within the translucent surface are updated with values corresponding to the distance to the triangle surface, using the max operator for storage [S2, book]. The result is stored in a volumetric texture map, enabling hardware-based voxelization [S2, book].

## Operating characteristics
- **Time Complexity:** $O(N \cdot V)$, where $N$ is the number of triangles and $V$ is the number of voxels in the bounding box of each triangle [G].
- **Memory Complexity:** $O(V_{total})$, where $V_{total}$ is the total number of voxels in the output volume [G].
- **Measured Performance:** Not given in the sources.
- **Strengths:** Simple to implement, avoids complex CSG operations, suitable for surface representation [S1, unofficial].
- **Limitations:** May miss intersections in edge cases if not handled properly, performance degrades with high-resolution meshes and large bounding boxes [G].
- **When to use:** When a surface representation is sufficient and CSG is too complex or expensive [S1, unofficial].
- **When not to use:** When a solid volume fill is required or when high precision is needed for thin structures [G].
