# Triangle Subdivision Voxelization
Also called: Barycentric Rasterization to Voxel Grid, Subdivision-based Voxelization

## Overview
A rasterization technique that subdivides triangle edges based on grid resolution and accuracy, sampling points and interpolated normals across the triangle surface to populate a 3D voxel grid [S1, unofficial].

## How it works
**Inputs:** Triangle vertices $p_1, p_2, p_3$, vertex normals $n_1, n_2, n_3$, grid dimensions $v_x, v_y, v_z$, and boolean flag `octree_render` [S1, unofficial].

**Outputs:** Voxel coordinates $(voxel\_x, voxel\_y, voxel\_z)$ and optionally quantized normal colors $(color\_x, color\_y, color\_z)$ [S1, unofficial].

**Data Structures:** The voxel grid is addressed by integer coordinates derived from continuous positions; normal storage uses 8-bit signed integers mapped to a specific range when `octree_render` is true [S1, unofficial].

**Pseudocode:**
```python
def triangle_subdivision_voxelization(p1, p2, p3, n1, n2, n3, vx, vy, vz, octree_render):
    d1 = p2 - p1
    d2 = p3 - p1
    temp = cross(d1 * 10.0, d2 * 10.0)
    length_temp = length(temp)
    if length_temp > 0:
        normal = temp * (1.0 / length_temp)
    else:
        return  # Skip degenerate triangle [G]
    
    vm = max(vx, vy, vz)
    if vx < 512:
        accuracy = 4
    elif vx < 1024:
        accuracy = 3
    else:
        accuracy = 2
        
    c = max(length(d1), length(d2)) * vm * accuracy
    
    for i in range(c + 1):
        a = i / c
        x1 = p1 + d1 * a
        x2 = p1 + d2 * a
        dx = x2 - x1
        xn1 = n1 + (n2 - n1) * a
        xn2 = n1 + (n3 - n1) * a
        dnx = xn2 - xn1
        
        d = length(dx) * vm * accuracy
        for j in range(d + 1):
            b = j / d
            p = x1 + dx * b
            n = xn1 + dnx * b
            
            voxel_x = p.x * vx
            voxel_y = (1.0 - p.y) * vy
            voxel_z = p.z * vz
            
            if octree_render:
                color_x = int(n.x * 127 + 128) & 0xfc
                color_y = int(n.y * 127 + 128)
                color_z = int(n.z * 127 + 128)
                # Populate voxel grid at (voxel_x, voxel_y, voxel_z) with position p and optional color [G]
            else:
                # Populate voxel grid at (voxel_x, voxel_y, voxel_z) with position p only [G]
```

**Parameters:** $v_x, v_y, v_z$ are integer grid dimensions; $accuracy$ is a subdivision multiplier (4 if $v_x < 512$, 3 if $512 \le v_x < 1024$, 2 otherwise); `octree_render` controls whether quantized normals are passed to the voxel setter [S1, unofficial].

**Edge Cases and Pitfalls:** Degenerate triangles ($len \le 0$) must be skipped to prevent division by zero during normalization [G]. Floating-point interpolation and grid mapping require boundary checks to avoid off-by-one voxel indexing errors [G]. The Y-axis mapping uses $(1.0 - p.y)$, inverting the input Y coordinate relative to the grid space [S1, unofficial].
