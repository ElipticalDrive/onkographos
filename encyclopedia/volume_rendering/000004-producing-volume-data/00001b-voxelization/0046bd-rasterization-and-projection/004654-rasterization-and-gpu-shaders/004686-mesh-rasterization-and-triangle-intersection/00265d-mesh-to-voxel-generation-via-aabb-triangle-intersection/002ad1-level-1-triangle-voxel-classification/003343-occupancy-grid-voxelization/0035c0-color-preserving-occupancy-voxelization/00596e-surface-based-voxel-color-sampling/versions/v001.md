# Surface-based Voxel Color Sampling

Also called: Surface Voxel Color Assignment

## Overview
Surface-based Voxel Color Sampling assigns colors to voxels by sampling the nearest point on the mesh surface rather than the voxel center, avoiding color errors when voxel centers fall inside empty space [S1, unofficial]. It differs from center-based sampling by ensuring that surface voxels (those intersecting the mesh boundary) receive colors derived from the actual geometry intersection, not potentially empty interior points [S1, unofficial].

## How it works
**Inputs:**
- A filled voxel grid (occupancy mask) from [Color-Preserving Occupancy Voxelization](7557-color-preserving-occupancy-voxelization.md).
- A triangular mesh with optional vertex colors or texture UVs.
- Voxel grid parameters: resolution, origin, and pitch (voxel size).

**Outputs:**
- A color array (RGB) for each surface voxel.
- Voxels not on the surface (interior or exterior) are typically left uncolored or assigned a default.

**Data Structures:**
- `filled_mask`: Boolean array of shape $(R, R, R)$ where $R$ is resolution. True if voxel intersects mesh.
- `surface_mask`: Boolean array of same shape. True if voxel intersects mesh surface.
- `world_points`: Array of $(x, y, z)$ coordinates in world space for each surface voxel center.
- `closest_points`: Array of $(x, y, z)$ coordinates on the mesh surface closest to each `world_point`.
- `face_indices`: Array of integers indicating which triangle face contains each `closest_point`.
- `colors`: Array of RGB values for each surface voxel.

**Steps:**

1. **Identify Surface Voxels:**
   Erode the `filled_mask` by one voxel in all directions to get `eroded_mask`. Compute:
   $$ \text{surface\_mask} = \text{filled\_mask} \land \neg \text{eroded\_mask} $$
   This isolates voxels that intersect the mesh boundary [S1, unofficial].

2. **Convert to World Coordinates:**
   For each voxel index $(i, j, k)$ where `surface_mask[i, j, k]` is true:
   $$ \text{world\_point} = [i, j, k] \times \text{pitch} + \text{voxel\_origin} + \frac{\text{pitch}}{2} $$
   This calculates the center of the voxel in world space [S1, unofficial].

3. **Nearest Surface Query:**
   For each `world_point`, find the closest point on the mesh surface:
   $$ (\text{closest\_point}, \text{distance}, \text{face\_index}) = \text{mesh.nearest.on\_surface}(\text{world\_point}) $$
   This returns the 3D point on the mesh and the index of the triangle face containing it [S1, unofficial].

4. **Color Assignment:**
   - **Vertex Colors:** If the mesh has vertex colors, average the colors of the three vertices of the triangle at `face_index`:
     $$ \text{color} = \text{mean}(\text{vertex\_colors}[\text{face\_index}]) $$
     Convert to `uint8` [S1, unofficial].
   - **Texture UVs:** If the mesh has UVs, average the UV coordinates of the face vertices:
     $$ \text{avg\_uv} = \text{mean}(\text{uv\_coords}[\text{face\_index}]) $$
     Map to texture pixel coordinates:
     $$ p_x = \text{int}(\text{clip}(\text{avg\_uv}[0] \times T_w, 0, T_w - 1)) $$
     $$ p_y = \text{int}(\text{clip}((1 - \text{avg\_uv}[1]) \times T_h, 0, T_h - 1)) $$
     Sample the texture at $(p_x, p_y)$ [S1, unofficial].
   - **No Visual Data:** Assign default RGB $(180, 180, 180)$ gray [S1, unofficial].

5. **Store Colors:**
   Assign the computed color to the voxel at $(i, j, k)$ in the output color array.

**Pseudocode:**

```python
import numpy as np

def surface_based_voxel_color_sampling(filled_mask, mesh, voxel_origin, pitch, texture=None):
    """
    Assign colors to surface voxels by sampling the nearest point on the mesh surface.
    
    Args:
        filled_mask: Boolean array (R, R, R) indicating occupied voxels.
        mesh: Mesh object with nearest_on_surface method and optional vertex_colors/uv_coords.
        voxel_origin: 3D vector (x, y, z) of the voxel grid origin in world space.
        pitch: Scalar, size of one voxel.
        texture: Optional texture image array (H, W, 3) for UV sampling.
        
    Returns:
        colors: Array of shape (N, 3) with RGB values for each surface voxel.
        surface_indices: List of (i, j, k) indices for surface voxels.
    """
    # Step 1: Identify surface voxels
    # Erode by 1 voxel in all directions
    eroded_mask = np.zeros_like(filled_mask, dtype=bool)
    eroded_mask[1:-1, 1:-1, 1:-1] = filled_mask[:-2, :-2, :-2] & \
                                     filled_mask[:-2, :-2, 2:] & \
                                     filled_mask[:-2, 2:, :-2] & \
                                     filled_mask[:-2, 2:, 2:] & \
                                     filled_mask[2:, :-2, :-2] & \
                                     filled_mask[2:, :-2, 2:] & \
                                     filled_mask[2:, 2:, :-2] & \
                                     filled_mask[2:, 2:, 2:]
    # Handle boundaries: eroded is False at boundaries if filled is True
    # Simplified erosion: any neighbor is False -> eroded is False
    # More robust: use scipy.ndimage.binary_erosion or manual check
    # Manual check for all 26 neighbors is expensive; assume simple 6-neighbor or full 26-neighbor
    # For correctness, we check if any neighbor is empty.
    # Let's use a simple 6-neighbor erosion for speed, or full 26 for accuracy.
    # The source implies a standard morphological erosion.
    from scipy.ndimage import binary_erosion
    eroded_mask = binary_erosion(filled_mask, structure=np.ones((3,3,3)))
    
    surface_mask = filled_mask & ~eroded_mask
    
    # Get indices of surface voxels
    surface_indices = np.argwhere(surface_mask)
    
    if len(surface_indices) == 0:
        return np.empty((0, 3), dtype=np.uint8), []
    
    # Step 2: Convert to world coordinates
    # world_points = indices * pitch + voxel_origin + pitch / 2
    world_points = surface_indices.astype(np.float64) * pitch + voxel_origin + pitch / 2.0
    
    # Step 3: Find closest point on mesh surface
    # mesh.nearest.on_surface returns (closest_points, distances, face_indices)
    # Assuming mesh object has this method
    closest_points, distances, face_indices = mesh.nearest_on_surface(world_points)
    
    # Step 4: Assign colors
    colors = np.zeros((len(surface_indices), 3), dtype=np.uint8)
    
    # Check if mesh has vertex colors
    if hasattr(mesh, 'vertex_colors') and mesh.vertex_colors is not None:
        # Average vertex colors for each face
        face_vertex_colors = mesh.vertex_colors[mesh.faces[face_indices]] # shape (N, 3, 3)
        colors = face_vertex_colors.mean(axis=1).astype(np.uint8)
    elif hasattr(mesh, 'uv_coords') and mesh.uv_coords is not None and texture is not None:
        # Sample texture using averaged UVs
        face_uv_coords = mesh.uv_coords[mesh.faces[face_indices]] # shape (N, 3, 2)
        avg_uvs = face_uv_coords.mean(axis=1) # shape (N, 2)
        
        tw, th = texture.shape[1], texture.shape[0]
        
        px = np.clip((avg_uvs[:, 0] * tw).astype(np.int32), 0, tw - 1)
        py = np.clip(((1 - avg_uvs[:, 1]) * th).astype(np.int32), 0, th - 1)
        
        # Sample texture
        # Assuming texture is (H, W, 3)
        colors = texture[py, px].astype(np.uint8)
    else:
        # Default gray color
        colors[:] = [180, 180, 180]
        
    return colors, surface_indices
```

**Parameters:**
- `pitch`: Voxel size. Typical values depend on resolution and scene bounds.
- `voxel_origin`: Origin of the voxel grid.
- `resolution`: Grid dimension $R$. Default 32 [S1, unofficial].
- Default color: RGB $(180, 180, 180)$ if no visual data [S1, unofficial].

**Edge Cases and Pitfalls:**
- Voxel centers may land inside empty space if center-based sampling is used, causing incorrect colors [S1, unofficial].
- Precision issues in nearest-neighbor queries for very small features.
- Degenerate triangles or invalid UVs may cause sampling errors.

## Operating characteristics
- **Time Complexity:** $O(N)$ where $N$ is the number of surface voxels, dominated by nearest-neighbor queries.
- **Memory Complexity:** $O(N)$ for storing surface voxel data and colors.
- **Performance:** On an M4 Pro, ~5 seconds per emoji at resolution 32, with GPU bottleneck in prior stages [S1, unofficial].
- **Strengths:** Accurate color assignment for surface voxels; avoids empty space sampling errors.
- **Limitations:** Requires mesh surface queries; slower than center-based sampling if mesh is complex.
- **When to Use:** When color accuracy on the surface is critical and voxel centers may not align with surface geometry.
- **When Not to Use:** For interior voxels or when performance is critical and approximate colors are acceptable.

## Background
Originating from the `image-to-voxel` pipeline by Mohamed Mansour, this method is used in generating voxel assets from images or emojis [S1, unofficial]. It addresses the limitation of center-based sampling in preserving surface color fidelity.
