# Bolt

Also called: Bypass expensive BVH query for exterior voxels

## Overview
Bolt is an optimization for solid mesh voxelization that skips the expensive Boundary Volume Hierarchy (BVH) distance query for voxels determined to be exterior to the mesh, assigning them a placeholder infinite distance instead [S1, unofficial]. It sets itself apart from standard voxelization by leveraging the parity check result to avoid redundant geometric calculations for points that are guaranteed to be discarded in solid mode [S1, unofficial].

## How it works
**Inputs and outputs:**
- Input: A voxel center point in local mesh coordinates (`point_3d`), a boolean indicating if the point is inside the mesh (`is_inside`), and an optional narrow band radius (`narrow_band`).
- Output: A signed distance field (SDF) value (`distance`) for the voxel.

**Data structures:**
- `is_inside`: Boolean result from a parity check (ray casting or similar) determining if the voxel center is inside the mesh boundary.
- `narrow_band`: Optional parameter. If `None`, the optimization is active. If `Some(radius)`, the BVH query is performed regardless of interior/exterior status.
- `point_3d`: 3D vector representing the voxel center in the mesh's local coordinate system.

**Steps:**
1. Determine if the voxel is exterior using the `is_inside` flag.
2. Check if `narrow_band` is disabled (i.e., `None`).
3. If the voxel is exterior (`!is_inside`) AND `narrow_band` is `None`:
   - Assign `distance = f32::INFINITY`.
   - Skip the BVH query.
4. Otherwise (if `narrow_band` is specified OR the voxel is interior):
   - Compute the exact distance to the mesh surface using the BVH query: `self.mesh.distance_to_local_point(&point_3d, false)`.
   - Cast the result to `f32`.

**Pseudocode:**
```python
def compute_distance(point_3d, is_inside, narrow_band, mesh):
    """
    Compute SDF distance for a voxel center.
    
    Args:
        point_3d: Vector3, voxel center in local mesh coordinates.
        is_inside: bool, result of parity check (True if inside mesh).
        narrow_band: Optional[float], if present, forces distance calculation.
        mesh: Object with method distance_to_local_point.
        
    Returns:
        float: Signed distance value.
    """
    # Bolt optimization: Skip BVH query for exterior voxels when narrow_band is not specified
    if not is_inside and narrow_band is None:
        return float('inf')
    else:
        # Compute exact distance using BVH
        # Note: distance_to_local_point returns a float/double; cast to f32
        exact_dist = mesh.distance_to_local_point(point_3d, False)
        return float(exact_dist)
```

**Parameters:**
- `narrow_band`: Optional. When `None`, the optimization is active. When `Some`, the BVH query is performed regardless of interior/exterior status [S1, unofficial].
- `is_inside`: Boolean result from a parity check that determines if a voxel is inside the mesh [S1, unofficial].

**Edge cases and pitfalls:**
- Points exactly on the mesh surface may be classified as outside by the parity test if the implementation uses `partition_point(|&hx| hx <= x)` which excludes hits at the same x coordinate [S1, unofficial].
- Previously, these boundary samples received `distance == 0` and passed the `sdf <= 0.0` filter. With this optimization, they receive `+inf` and are dropped [S1, unofficial].
- This can remove valid boundary voxels or cause small meshes to produce no solid particles on aligned/coarse grids [S1, unofficial].

## Operating characteristics
- **Time Complexity:** Reduces processing time for solid voxelization by ~2-5% [S1, unofficial].
- **Measured Performance:** In benchmarks comparing `voxelize_surface` and `voxelize_solid`, solid voxelization dropped from ~32ms to ~30-31ms per loop over 100 sample passes [S1, unofficial].
- **Scaling:** Improvement is more significant for high-resolution solid grids where a large percentage of sampled voxels reside outside the target mesh bounds [S1, unofficial].
- **Strengths:** Significant reduction in voxelization processing time, especially for high-resolution solid grids [S1, unofficial].
- **Limitations:** Potential loss of valid boundary voxels if the parity test misclassifies surface points as exterior, particularly on aligned/coarse grids [S1, unofficial].
- **When to use:** When `narrow_band` is not specified and performance is critical for solid voxelization of large meshes [S1, unofficial].
- **When not to use:** When `narrow_band` is specified, or when precise boundary representation is critical and parity test inaccuracies are a concern [S1, unofficial].

## Background
Bolt was introduced as a pull request by `lhemerly` in the `voxelizer-rs` repository [S1, unofficial]. It addresses the inefficiency of computing exact SDF distances for exterior voxels in solid mode, where these distances are ultimately discarded [S1, unofficial].
