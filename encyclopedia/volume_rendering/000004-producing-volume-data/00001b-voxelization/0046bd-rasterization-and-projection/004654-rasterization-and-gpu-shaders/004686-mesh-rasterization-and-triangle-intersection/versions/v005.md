# Mesh Rasterization and Triangle Intersection

Also called: Triangle Rasterization, Triangle-Grid Intersection

## Overview
This family converts continuous triangle meshes into discrete volumetric representations (voxel grids) by determining the occupancy of grid cells relative to triangle geometry [S1, unofficial]. It differs from [Rasterization-based Voxelization](908-rasterization-based-voxalization.md) by explicitly separating surface shell generation (via AABB-triangle intersection) from volume filling (via scanlines) to ensure watertight interiors [S1, unofficial], and from [Mesh-to-Voxel Geometry Shader](2800-mesh-to-voxel-geometry-shader.md) by relying on CPU-side geometric tests rather than GPU shader pipelines for topological correctness .

## Shared principles
All methods in this family map a conceptual or physical source into a discrete or analytic volumetric representation suitable for rendering [G]. The core mechanism involves:
1. **Domain Definition**: Establishing a spatial domain, typically a 3D grid with resolution $(N_x, N_y, N_z)$ and bounding box, or an infinite analytic space [G].
2. **Value Assignment**: Determining the value (density, distance, color) for each point in the domain based on the source method (geometric intersection, function evaluation, or physical state) [G].
3. **Storage/Access**: Either storing the result in a discrete array (voxelization, simulation) or providing an interface to compute it on-the-fly (procedural) [G].

## Subtopics

### [Mesh to Voxel Generation via AABB-Triangle Intersection](3775-mesh-to-voxel-generation-via-aabb-triangle-intersection.md)
This method converts a 3D triangle mesh into a solid, non-hollow voxel grid by first identifying surface voxels via Axis-Aligned Bounding Box (AABB) vs. Triangle intersection tests, and then filling the interior using a scanline fill algorithm. It differs from its siblings by explicitly separating the surface shell generation (using SAT-based intersection) from the volume filling (using parity-based scanlines), ensuring watertight interiors suitable for deep physical simulations like heat diffusion or fracture. Unlike [Fake Voxelization via Triangle-Cube Intersection](6951-fake-voxelization-via-triangle-cube-intersection.md) which outputs only surface voxels, this method produces a solid volume. See [Mesh to Voxel Generation via AABB-Triangle Intersection](3775-mesh-to-voxel-generation-via-aabb-triangle-intersection.md).

### [Mesh Voxelization](6514-mesh-voxelization.md)
Mesh Voxelization converts a continuous polygon mesh (typically STL or OBJ) into a discrete 3D grid of voxels, determining the occupancy (solid/empty) and optionally the signed distance field (SDF) for each cell. It solves the problem of discretizing surface geometry for volume rendering, simulation, or 3D printing preparation. Unlike [Mesh to Voxel Generation via AABB-Triangle Intersection](3775-mesh-to-voxel-generation-via-aabb-triangle-intersection.md), which relies on bounding box overlap, or [Template-based Voxelization](7964-template-based-voxelization.md), which uses precomputed patterns, this method uses ray casting to robustly determine topological inside/outside status, handling complex concavities and open meshes via multi-directional sampling. See [Mesh Voxelization](6514-mesh-voxelization.md).

### [Template-based Voxelization](7964-template-based-voxelization.md)
Template-based Voxelization computes the digitization of a continuous triangle or mesh by determining if a voxel belongs to the digitization based on whether a geometric template centered at the voxel intersects the triangle. It converts a continuous surface mesh into a discrete set of voxels (DigitalSet). This method is distinguished from sibling methods like AABB-triangle intersection by its reliance on topological separation properties (6- or 26-connectivity) to define the boundary, ensuring that the resulting digital surface separates the interior from the exterior in the specified connectivity sense. See [Template-based Voxelization](7964-template-based-voxelization.md).

### [Triangle Rendering with Thickness](12908-triangle-rendering-with-thickness.md)
Triangle Rendering with Thickness renders a triangle as a volumetric shell by voxelizing grid points that lie within a specified distance from the triangle's plane or edges. It differs from solid triangle rasterization by including points outside the triangle boundary (up to the thickness limit) and from sphere-based thickness methods by using planar geometry defined by three vertices. This method is a specialized case of mesh rasterization where the primitive is a polygon. See [Triangle Rendering with Thickness](12908-triangle-rendering-with-thickness.md).

### Visibility Tensor Rasterization
#### definition
- [S1, unofficial] A tensor indicating the extent to which a given triangle covers a given pixel, computed by checking if directed distances from the pixel to each edge are positive, smoothed via sigmoid.
#### step
- [S1, unofficial] For each edge $e=(v_1,v_2)$ of triangle $T$, calculate the directed distance from pixel $(p_x,p_y)$ to the edge. Apply sigmoid $\sigma$ to this distance scaled by steepness $s$. Multiply the results for all three edges to get $V$.
- [S1, unofficial] To make the visibility tensor orientation invariant, add the term computed with negative directed distances (or sum over $a \in \{-1,1\}$ as per the formula).
#### formula
- [S1, unofficial] $V(p_x, p_y, T) := \prod_{e=(v_1,v_2)\in T} \sigma\left( \frac{v_{x,2}-v_{x,1}}{s} (v_{y,1}-p_y) + \frac{v_{y,2}-v_{y,1}}{s} (v_{x,1}-p_x) \right)$
- [S1, unofficial] $V_{orient.inv.}(p_x, p_y, T) = \sum_{a\in\{-1,1\}} \prod_{e=(v_1,v_2)\in T} \sigma\left( a \cdot \frac{(v_{x,2}-v_{x,1})(v_{y,1}-p_y) - (v_{y,2}-v_{y,1})(v_{x,1}-p_x)}{s} \right)$
#### parameter
- [S1, unofficial] $s$: Steepness hyper-parameter for the sigmoid function in the visibility tensor calculation.

## Background
Origin: The foundational concepts of mesh rasterization and triangle-grid intersection are rooted in computer graphics literature, specifically differentiable rendering and voxelization techniques. The visibility tensor approach was introduced in "Pix2Vex: Image-to-Geometry Reconstruction using a Smooth Differentiable Renderer" [S1, unofficial]. The AABB-triangle intersection and scanline fill methods are common in voxelization implementations [S1, unofficial]. Ray casting for mesh voxelization is a standard technique in computational geometry . Template-based voxelization relies on digital topology and separation properties [S1, unofficial].
