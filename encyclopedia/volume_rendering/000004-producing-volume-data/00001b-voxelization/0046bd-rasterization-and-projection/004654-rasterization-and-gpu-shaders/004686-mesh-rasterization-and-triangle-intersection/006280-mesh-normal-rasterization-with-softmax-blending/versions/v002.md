# Mesh Normal Rasterization with Softmax Blending

Also called: Barycentric Normal Interpolation, GT Normal Rendering, Mesh Normal Rasterization with Barycentric Interpolation and Softmax Blending

## Overview
This method renders ground-truth normal maps by interpolating per-vertex normals across rasterized faces using barycentric coordinates, then blending overlapping faces per pixel via a softmax function [S1, unofficial].

## How it works
**Inputs:**
*   `vertex_normals`: Tensor of shape $(V, 3)$ containing per-vertex normals, where $V$ is the number of vertices.
*   `faces_packed`: Tensor of shape $(F, 3)$ containing face indices, where $F$ is the number of triangles.
*   `fragments`: Rasterization output containing `pix_to_face` (indices of faces overlapping each pixel) and `barycentric_coords` (barycentric coordinates of each pixel relative to overlapping faces) [S1, unofficial].
*   `blend_params`: Configuration for the blending process, including `blur_radius`, `faces_per_pixel`, and `perspective_correct` [S1, unofficial].

**Outputs:**
*   `images`: Tensor of shape $(H, W, 3)$ containing the blended normal map.

**Data Structures:**
*   **Vertex Textures**: Stored as RGB values. Before interpolation, normals are encoded into this texture space [S1, unofficial].
*   **Face Textures**: Derived from vertex textures using face indices [S1, unofficial].
*   **Fragments**: Contains the mapping from pixel coordinates to triangle indices and the interpolation weights (barycentric coordinates) [S1, unofficial].

**Steps:**
1.  **Encode and Normalize Vertex Normals**: Transform the raw normal vectors $(n_x, n_y, n_z)$ by adding 1 to X/Y and dividing by 2, adding 3 to Z and dividing by 4, then L2-normalize across the channel dimension [S1, unofficial].
2.  **Map to Face Textures**: Index the normalized vertex textures using packed face indices: `faces_textures = vertex_textures[faces_packed]` [S1, unofficial].
3.  **Interpolate Attributes**: For each pixel, interpolate the face textures across the overlapping faces using the provided barycentric coordinates [S1, unofficial].
4.  **Softmax Blending**: Blend the contributions of overlapping faces per pixel using a softmax function over the RGB channels [S1, unofficial]. The `blur_radius` parameter in `blend_params` controls the soft edge blending radius; set to $0.0$ for hard edges [S1, unofficial].

**Pseudocode:**
```python
def render_normals(vertex_normals, faces, fragments, blend_params):
    # Step 1: Encode and normalize vertex normals
    vertex_textures = vertex_normals.clone()
    vertex_textures[:, 0] = (vertex_textures[:, 0] + 1.0) / 2.0
    vertex_textures[:, 1] = (vertex_textures[:, 1] + 1.0) / 2.0
    vertex_textures[:, 2] = (vertex_textures[:, 2] + 3.0) / 4.0
    norms = torch.norm(vertex_textures, p=2, dim=-1, keepdim=True)
    norms = torch.clamp(norms, min=1e-8)
    vertex_textures = vertex_textures / norms

    # Step 2: Map to face textures
    faces_textures = vertex_textures[faces]

    # Step 3: Interpolate face attributes
    # fragments.pix_to_face: (H, W, K), fragments.barycentric_coords: (H, W, K, 3)
    texels = torch.zeros(fragments.pix_to_face.shape[:-1] + (3,), device=vertex_textures.device)
    for h in range(texels.shape[0]):
        for w in range(texels.shape[1]):
            for k in range(texels.shape[2]):
                face_idx = fragments.pix_to_face[h, w, k]
                bary = fragments.barycentric_coords[h, w, k]
                v0, v1, v2 = faces_textures[face_idx]
                texels[h, w, k] = bary[0] * v0 + bary[1] * v1 + bary[2] * v2

    # Step 4: Softmax blend
    # Blend overlapping face contributions per pixel using softmax over RGB channels
    # Sources do not specify exact weighting for softmax blending [G]
    images = softmax_rgb_blend(texels, blend_params)
    return images

def softmax_rgb_blend(texels, blend_params):
    # texels: (H, W, K, 3)
    # Apply softmax over the channel dimension (dim=-1) for each pixel and face
    # Then sum across faces (dim=-2) to blend
    exp_vals = torch.exp(texels)
    sum_exp = torch.sum(exp_vals, dim=-2, keepdim=True)
    sum_exp = torch.clamp(sum_exp, min=1e-8)
    images = torch.sum(exp_vals / sum_exp * texels, dim=-2)
    return images
```

**Parameters:**
*   `blur_radius`: Controls soft edge blending radius. Set to $0.0$ for hard edges [S1, unofficial].
*   `faces_per_pixel`: Number of faces considered per pixel. Default is $1$ [S1, unofficial].
*   `perspective_correct`: Enables perspective-correct interpolation. Default is `True` [S1, unofficial].

**Edge Cases and Pitfalls:**
*   **Zero Normals**: If a vertex normal is zero, the normalization step will result in NaNs. A small epsilon should be added to the norm denominator [G].
*   **Degenerate Triangles**: Triangles with zero area may produce undefined barycentric coordinates. The rasterizer should handle or filter these [G].
*   **Precision**: The encoding step $(n+1)/2$ maps $[-1, 1]$ to $[0, 1]$, but the subsequent normalization changes the magnitude. Ensure the downstream renderer expects normalized vectors [G].

## Operating characteristics
*   **Time Complexity**: Not given in the sources.
*   **Memory Complexity**: Not given in the sources.
*   **Strengths**: Provides smooth, differentiable normal maps suitable for training neural rendering models [S1, unofficial].
*   **Limitations**: Softmax blending can blur sharp edges if `blur_radius` is large.
*   **When to Use**: Training differentiable rendering pipelines, normal map generation for neural fields [S1, unofficial].
*   **When Not to Use**: Real-time rendering where performance is critical, or when hard edges are required [G].

## Subtopics

### Hard-Edge Rasterization
Uses nearest-face or first-hit logic without blending. Choose when performance is critical and normal continuity is not required. Link to [Mesh Rasterization and Triangle Intersection](11783-mesh-rasterization-and-triangle-intersection.md). [G]

### Depth-Based Normal Estimation
Computes normals from depth gradients. Choose when mesh geometry is unavailable but depth maps are present. Link to [Triangle Rendering with Thickness](12908-triangle-rendering-with-thickness.md). [G]

## Background
This method is used in the `dn-splatter` project for differentiable normal splatting [S1, unofficial]. It builds on standard rasterization techniques but adapts them for differentiable training by using softmax blending to handle overlapping geometry smoothly.
