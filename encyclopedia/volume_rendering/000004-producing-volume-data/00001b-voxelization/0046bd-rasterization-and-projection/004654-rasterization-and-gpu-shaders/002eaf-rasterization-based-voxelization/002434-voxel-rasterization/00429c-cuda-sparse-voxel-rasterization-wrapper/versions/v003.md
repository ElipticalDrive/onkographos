# CUDA Sparse Voxel Rasterization Wrapper

Also called: PyTorch autograd wrapper for CUDA sparse voxel rasterization

## Overview
This method provides a PyTorch autograd wrapper for a CUDA extension that rasterizes sparse voxels into image space, supporting differentiable rendering with depth, normal, and distortion outputs [S1, unofficial]. It distinguishes itself from standard rasterization by enabling gradient-based optimization of voxel geometry and appearance through simultaneous multi-channel outputs [S1, unofficial].

## How it works
**Inputs and Outputs**
* **Inputs:** `vox_centers` (`[N, 3]`), `geos` (`[N, 8]`), `rgbs` (`[N, 3]`), `subdiv_p` (`[N, 1]`), `n_samp_per_vox` (int), `RasterSettings` object, and camera matrices (`w2c_matrix`, `c2w_matrix`) [S1, unofficial].
* **Outputs:** `out_color`, `out_depth`, `out_normal`, `out_T`, and `max_w` [S1, unofficial].

**Data Structures**
The `RasterSettings` NamedTuple contains the following fields [S1, unofficial]: `color_mode` (str), `n_samp_per_vox` (int), `image_width` (int), `image_height` (int), `tanfovx` (float), `tanfovy` (float), `cx` (float), `cy` (float), `w2c_matrix` (torch.Tensor), `c2w_matrix` (torch.Tensor), `bg_color` (float, default 0), `near_plane` (float, default 0.02), `need_depth` (bool), `need_normal` (bool), `track_max_w` (bool), `lambda_R_concen` (float), `lambda_ascending` (float), `lambda_dist` (float), `gt_color` (torch.Tensor, default empty), `debug` (bool).

**Algorithm Steps**
1. Validate input types and shapes: `n_samp_per_vox` must be in `[1, _C.MAX_N_SAMP]`, `vox_centers` must be `[N, 3]`, `geos` must be `[N, 8]`, `rgbs` must be `[N, 3]`, `subdiv_p` must be `[N, 1]` [S1, unofficial].
2. Preprocess octree geometry via C++ extension: `n_duplicates, geomBuffer = _C.rasterize_preprocess(...)` passing camera matrices, dimensions, and voxel data [S1, unofficial].
3. Identify voxels in frustum: `in_frusts_idx = torch.where(n_duplicates > 0)[0]` [S1, unofficial].
4. Forward voxel parameters to GPU: `vox_params = vox_fn(in_frusts_idx, cam_pos, raster_settings.color_mode)` extracting `geos`, `rgbs`, `subdiv_p` [S1, unofficial].
5. Invoke differentiable rasterization: `num_rendered, binningBuffer, imgBuffer, out_color, out_depth, out_normal, out_T, max_w = _C.rasterize_voxels(*args)` [S1, unofficial].
6. Save tensors for backward pass: `ctx.save_for_backward(octree_paths, vox_centers, vox_lengths, geos, rgbs, geomBuffer, binningBuffer, imgBuffer, out_T, out_depth, out_normal)` [S1, unofficial].
7. Mark `max_w` as non-differentiable: `ctx.mark_non_differentiable(max_w)` [S1, unofficial].
