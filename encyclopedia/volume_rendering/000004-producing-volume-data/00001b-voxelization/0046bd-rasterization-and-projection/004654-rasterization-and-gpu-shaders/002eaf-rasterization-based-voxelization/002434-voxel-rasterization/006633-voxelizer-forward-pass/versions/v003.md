# Voxelizer Forward Pass

Also called: CUDA Gaussian Voxelization and Rendering, CudaVoxelizer::Voxelizer::forward

## Overview
The Voxelizer Forward Pass is a CUDA-based voxelization and rendering pipeline that processes 3D Gaussians into a volume [S1, unofficial]. It computes radii, generates tile/depth keys for sorting, identifies tile ranges, and renders the volume by blending Gaussians per tile [S1, unofficial].

## How it works
### Inputs and Outputs
**Inputs:**
- `P`: Number of input 3D Gaussians [S1, unofficial].
- `means3D`: Array of $P$ 3D mean positions (world space) [S1, unofficial].
- `opacities`: Array of $P$ opacity values [S1, unofficial].
- `scales`: Array of $P$ scale vectors [S1, unofficial].
- `scale_modifier`: Scalar multiplier for scales [S1, unofficial].
- `rotations`: Array of $P$ quaternions [S1, unofficial].
- `cov3D_precomp`: Optional pre-computed 3D covariance matrices (or `nullptr` to compute internally) [S1, unofficial].
- `prefiltered`: Boolean flag indicating if Gaussians are pre-filtered [S1, unofficial].
- `nVoxel_x, nVoxel_y, nVoxel_z`: Dimensions of the voxel grid (number of tiles in each dimension) [S1, unofficial].
- `sVoxel_x, sVoxel_y, sVoxel_z`: Scale/size of each voxel/tile in world units [S1, unofficial].
- `center_x, center_y, center_z`: Center coordinates of the voxel grid in world space [S1, unofficial].

**Outputs:**
- `out_volume`: Output buffer for the rendered volume data [S1, unofficial].
- `num_rendered`: Total number of rendered Gaussian instances (duplicates included) [S1, unofficial].

### Data Structures
The method uses three main state structures allocated via callbacks (`geometryBuffer`, `imageBuffer`, `binningBuffer`) [S1, unofficial].

**GeometryState** (size $P$):
- `depths`: `float[P]` – Computed depth of each Gaussian.
- `internal_radii`: `int[P]` – Radius of each Gaussian in tile units.
- `means3D_norm`: `vec3[P]` – Normalized mean positions.
- `cov3D`: `float[P*6]` – Covariance matrices (6 floats per Gaussian, symmetric upper triangle).
- `conic_opacity`: `float[P*7]` – Conic matrix (6 floats) + opacity (1 float).
- `tiles_touched`: `int[P]` – Count of tiles touched by each Gaussian.
- `point_offsets`: `int[P]` – Prefix sum of `tiles_touched`, used for indexing duplicated Gaussians.
- `scanning_space`: `void*` – Temporary allocation space.
- `scan_size`: `size_t` – Size of scanning space. [S1, unofficial]

**ImageState** (size $N$, where $N = nVoxel_x \times nVoxel_y \times nVoxel_z$):
- `n_contrib`: `int[N]` – Number of Gaussians contributing to each tile.
- `ranges`: `uint2[N]` – Start and end indices in the sorted `point_list` for each tile. [S1, unofficial]

**BinningState** (size $num\_rendered$):
- `point_list`: `int[P]` – Sorted Gaussian indices.
- `point_list_unsorted`: `int[P]` – Unsorted Gaussian indices.
- `point_list_keys`: `uint64_t[P]` – Sorted tile/depth keys.
- `point_list_keys_unsorted`: `uint64_t[P]` – Unsorted tile/depth keys.
- `list_sorting_space`: `void*` – Temporary allocation space.
- `sorting_size`: `size_t` – Size of sorting space. [S1, unofficial]

### Steps
1. **Allocate GeometryState**: Allocate buffers for `GeometryState` using `geometryBuffer` callback with size `required<GeometryState>(P)` [S1, unofficial].
2. **Initialize GeometryState**: Initialize fields `depths` (P floats), `internal_radii` (P ints), `means3D_norm` (P vec3), `cov3D` (P*6 floats), `conic_opacity` (P*7 floats), and `tiles_touched` (P ints) [S1, unofficial].
3. **Preprocess Gaussians**: Launch `FORWARD::preprocess` kernel to compute radii, normalized means, depths, covariances, conic matrices, and count touched tiles per Gaussian [S1, unofficial].
4. **Compute Offsets**: Compute inclusive prefix sum of `tiles_touched` to determine offsets for duplicated Gaussians. Store result in `point_offsets` [S1, unofficial].
5. **Allocate ImageState**: Allocate `ImageState` buffers using `imageBuffer` callback with size `required<ImageState>(nVoxel_x * nVoxel_y * nVoxel_z)`. Fields: `n_contrib` (N ints), `ranges` (N uint2) [S1, unofficial].
6. **Retrieve Render Count**: Retrieve total number of rendered Gaussian instances (`num_rendered`) from the last element of `point_offsets` [S1, unofficial].
7. **Allocate BinningState**: Allocate `BinningState` buffers using `binningBuffer` callback with size `required<BinningState>(num_rendered)`. Fields: `point_list` (P ints), `point_list_unsorted` (P ints), `point_list_keys` (uint64_t[P]), `point_list_keys_unsorted` (uint64_t[P]) [S1, unofficial].
8. **Duplicate and Key Generation**: Launch `duplicateWithKeys2` kernel. For each Gaussian with radius > 0, compute bounding cube `[cube_min, cube_max]` using `getCube`. For each tile $(x,y,z)$ in the cube, generate key = $(z \cdot grid.y \cdot grid.x + y \cdot grid.x + x) \ll 32 \mid depth\_bits$. Store key and Gaussian index (`idx`) in unsorted buffers at offset determined by `point_offsets` [S1, unofficial].
9. **Calculate Sort Bits**: Calculate bit depth for radix sort: $bit = \text{getHigherMsb2}(tile\_grid.x \cdot tile\_grid.y \cdot tile\_grid.z)$ [S1, unofficial].
10. **Sort**: Sort pairs `(keys, values)` using CUB radix sort. Sort keys from bit 0 to $32+bit$. Output sorted keys to `point_list_keys` and sorted values (Gaussian indices) to `point_list` [S1, unofficial].
11. **Zero Ranges**: Zero out `imgState.ranges` buffer [S1, unofficial].
12. **Identify Tile Ranges**: If `num_rendered > 0`, launch `identifyTileRanges2` kernel. For each index `idx` in sorted list, read tile ID from `key >> 32`. If `idx==0`, set range start to 0. If tile ID changes from previous, set previous tile's end to `idx` and current tile's start to `idx`. If `idx==L-1`, set current tile's end to `L` [S1, unofficial].
13. **Render**: Launch `FORWARD::render` kernel. Pass `tile_grid`, `block`, `imgState.ranges`, `binningState.point_list`, voxel dimensions, `means3D_norm`, `conic_opacity`, `n_contrib`, and `out_volume` [S1, unofficial].
14. **Return**: Return `num_rendered` [S1, unofficial].

def voxelizer_forward_pass(
    means3D: list, opacities: list, scales: list, scale_modifier: float,
    rotations: list, cov3D_precomp: list, prefiltered: bool,
    nVoxel_x: int, nVoxel_y: int, nVoxel_z: int,
    sVoxel_x: float, sVoxel_y: float, sVoxel_z: float,
    center_x: float, center_y: float, center_z: float
) -> tuple:
    P = len(means3D)
    N = nVoxel_x * nVoxel_y * nVoxel_z

    # 1. Allocate GeometryState [S1, unofficial]
    geo = {
        'depths': [0.0] * P,
        'internal_radii': [0] * P,
        'means3D_norm': [(0.0, 0.0, 0.0)] * P,
        'cov3D': [0.0] * (P * 6),
        'conic_opacity': [0.0] * (P * 7),
        'tiles_touched': [0] * P,
        'point_offsets': [0] * P
    }

    # 2. Initialize GeometryState fields [S1, unofficial]
    # (Initialized above)

    # 3. Preprocess Gaussians [S1, unofficial]
    # Launch FORWARD::preprocess kernel to compute radii, normalized means, depths, covariances, conic matrices, and count touched tiles per Gaussian.

    # 4. Compute Offsets [S1, unofficial]
    geo['point_offsets'] = inclusive_prefix_sum(geo['tiles_touched'])

    # 5. Allocate ImageState [S1, unofficial]
    img = {
        'n_contrib': [0] * N,
        'ranges': [(0, 0)] * N
    }

    # 6. Retrieve num_rendered [S1, unofficial]
    num_rendered = geo['point_offsets'][P - 1]

    # 7. Allocate BinningState [S1, unofficial]
    bin_state = {
        'point_list': [0] * num_rendered,
        'point_list_unsorted': [0] * num_rendered,
        'point_list_keys': [0] * num_rendered,
        'point_list_keys_unsorted': [0] * num_rendered
    }

    # 8. Duplicate and Key Generation [S1, unofficial]
    off = 0
    for idx in range(P):
        if geo['internal_radii'][idx] > 0:
            # Compute bounding cube [cube_min, cube_max] using getCube [S1, unofficial]
            cube_min, cube_max = get_cube(geo['means3D_norm'][idx], geo['internal_radii'][idx], nVoxel_x, nVoxel_y, nVoxel_z)
            for z in range(cube_min[2], cube_max[2] + 1):
                for y in range(cube_min[1], cube_max[1] + 1):
                    for x in range(cube_min[0], cube_max[0] + 1):
                        key = (z * nVoxel_y * nVoxel_x + y * nVoxel_x + x) << 32
                        # Bitcast depths[idx] to uint32_t [S1, unofficial]
                        depth_bits = int.from_bytes(struct.pack('f', geo['depths'][idx]), 'little') & 0xFFFFFFFF
                        key |= depth_bits
                        bin_state['point_list_keys_unsorted'][off] = key
                        bin_state['point_list_unsorted'][off] = idx
                        off += 1

    # 9. Calculate Sort Bits [S1, unofficial]
    bit = get_higher_msb(nVoxel_x * nVoxel_y * nVoxel_z)

    # 10. Sort [S1, unofficial]
    # Sort pairs (keys, values) using radix sort from bit 0 to 32+bit.
    combined = sorted(zip(bin_state['point_list_keys_unsorted'], bin_state['point_list_unsorted']), key=lambda x: x[0])
    bin_state['point_list_keys'] = [x[0] for x in combined]
    bin_state['point_list'] = [x[1] for x in combined]

    # 11. Zero Ranges [S1, unofficial]
    img['ranges'] = [(0, 0)] * N

    # 12. Identify Tile Ranges [S1, unofficial]
    if num_rendered > 0:
        for idx in range(num_rendered):
            key = bin_state['point_list_keys'][idx]
            currtile = key >> 32
            if idx == 0:
                img['ranges'][currtile] = (0, img['ranges'][currtile][1])
            else:
                prevtile = bin_state['point_list_keys'][idx - 1] >> 32
                if currtile != prevtile:
                    img['ranges'][prevtile] = (img['ranges'][prevtile][0], idx)
                    img['ranges'][currtile] = (idx, img['ranges'][currtile][1])
            if idx == num_rendered - 1:
                img['ranges'][currtile] = (img['ranges'][currtile][0], num_rendered)

    # 13. Render [S1, unofficial]
    # Launch FORWARD::render kernel with tile_grid, block, imgState.ranges, binningState.point_list, voxel dimensions, means3D_norm, conic_opacity, n_contrib, and out_volume.
    out_volume = [0.0] * (N * 4)

    # 14. Return [S1, unofficial]
    return num_rendered, out_volume

def inclusive_prefix_sum(arr):
    result = [0] * len(arr)
    acc = 0
    for i, val in enumerate(arr):
        acc += val
        result[i] = acc
    return result

def get_higher_msb(n):
    return n.bit_length()

### Edge Cases and Pitfalls
- **Zero Radius**: Gaussians with `internal_radii[i] == 0` are skipped during duplication [S1, unofficial].
- **Precision**: Depth bits are packed into the lower 32 bits of the key. Ensure `depths` are normalized or scaled appropriately to fit within 32 bits without collision [S1, unofficial].
- **Boundary Conditions**: The `identifyTileRanges2` kernel handles the last tile explicitly by setting its end range to `L` (total number of rendered instances) [S1, unofficial].
