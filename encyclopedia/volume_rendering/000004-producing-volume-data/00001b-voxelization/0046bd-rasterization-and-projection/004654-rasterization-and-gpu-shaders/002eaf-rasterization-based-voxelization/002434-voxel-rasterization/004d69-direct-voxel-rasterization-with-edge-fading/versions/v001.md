# Direct Voxel Rasterization with Edge Fading

Also called: Max-blend voxel rasterization, Voxel-based sphere rendering

## Overview
Direct Voxel Rasterization with Edge Fading renders 3D spheres into a voxel grid by iterating over axis-aligned bounding boxes, computing Euclidean distance to the sphere center, applying a linear edge fade, and blending colors using maximum blending [S1, unofficial]. It differs from standard binary voxelization by introducing anti-aliased edges via intensity falloff, and from ray-marching volume rendering by using a direct, iterative rasterization approach that is computationally lightweight and suitable for real-time updates [S1, unofficial].

## How it works
**Inputs and Outputs:**
*   **Input:** A list of spheres, each defined by a 3D position $(x, y, z)$, a radius $r$, and an RGB color $(C_r, C_g, C_b)$.
*   **Output:** A 4D voxel grid `raster.data` of dimensions $(L, H, W)$, where $L$ is length (z-axis), $H$ is height (y-axis), and $W$ is width (x-axis). Each voxel stores an RGB color value.

**Data Structures:**
*   `raster.data`: A 4D array indexed as `[z, y, x, channel]`.
    *   Channel 0: Red
    *   Channel 1: Green
    *   Channel 2: Blue
    *   Dimensions correspond to `(length, height, width)` [S1, unofficial].

**Parameters:**
*   `RENDER_FADE_MARGIN`: A float controlling the width of the edge fade region relative to the sphere radius. Typical value: $0.2$ [S1, unofficial].
*   `dt`: Fixed timestep for physics updates (not part of rasterization itself, but used in the simulation loop). Typical value: $1.0 / 60.0$ [S1, unofficial].

**Algorithm Steps:**
1.  **Sphere Validation:** If a sphere's radius $r \le 0.1$, skip it to avoid degenerate bounding boxes [S1, unofficial].
2.  **Bounding Box Calculation:** For each sphere with center $(c_x, c_y, c_z)$ and radius $r$:
    *   Compute integer bounds:
        $$
        \begin{aligned}
        x_{min} &= \max(0, \lfloor c_x - r \rfloor) \\
        x_{max} &= \min(W - 1, \lfloor c_x + r \rfloor) \\
        y_{min} &= \max(0, \lfloor c_y - r \rfloor) \\
        y_{max} &= \min(H - 1, \lfloor c_y + r \rfloor) \\
        z_{min} &= \max(0, \lfloor c_z - r \rfloor) \\
        z_{max} &= \min(L - 1, \lfloor c_z + r \rfloor)
        \end{aligned}
        $$
    *   Clamp coordinates to prevent out-of-bounds access [S1, unofficial].
3.  **Voxel Iteration:** Iterate $z$ from $z_{min}$ to $z_{max}$, $y$ from $y_{min}$ to $y_{max}$, and $x$ from $x_{min}$ to $x_{max}$.
4.  **Distance Calculation:** For each voxel $(x, y, z)$:
    *   Compute deltas: $dx = x - c_x$, $dy = y - c_y$, $dz = z - c_z$.
    *   Compute Euclidean distance: $d = \sqrt{dx^2 + dy^2 + dz^2}$.
5.  **Intensity and Color Calculation:**
    *   Define fade start threshold: $d_{fade} = r \times (1.0 - \text{RENDER\_FADE\_MARGIN})$.
    *   If $d \le r$:
        *   Intensity $I = 1.0$.
    *   Else if $d \le d_{fade}$:
        *   Intensity $I = 1.0 - \frac{d - d_{fade}}{r \times \text{RENDER\_FADE\_MARGIN}}$.
    *   Else:
        *   Intensity $I = 0.0$ (skip blending).
    *   Compute new color components:
        $$
        \begin{aligned}
        C'_r &= \lfloor C_r \times I \rfloor \\
        C'_g &= \lfloor C_g \times I \rfloor \\
        C'_b &= \lfloor C_b \times I \rfloor
        \end{aligned}
        $$
6.  **Maximum Blending:** Update the voxel at `[z, y, x]` using maximum blending for each channel:
    $$
    \begin{aligned}
    \text{raster.data}[z, y, x, 0] &= \max(\text{raster.data}[z, y, x, 0], C'_r) \\
    \text{raster.data}[z, y, x, 1] &= \max(\text{raster.data}[z, y, x, 1], C'_g) \\
    \text{raster.data}[z, y, x, 2] &= \max(\text{raster.data}[z, y, x, 2], C'_b)
    \end{aligned}
    $$

**Pseudocode:**
```python
import math

def rasterize_spheres(spheres, raster_width, raster_height, raster_length, fade_margin=0.2):
    """
    Renders spheres into a voxel grid using direct rasterization with edge fading.
    
    Args:
        spheres: List of dicts with keys 'x', 'y', 'z', 'radius', 'color' (dict with 'r', 'g', 'b').
        raster_width: Width of the voxel grid (x-dimension).
        raster_height: Height of the voxel grid (y-dimension).
        raster_length: Length of the voxel grid (z-dimension).
        fade_margin: Controls the width of the edge fade region (default 0.2).
        
    Returns:
        A 4D numpy-like array of shape (length, height, width, 3) with uint8 values.
    """
    # Initialize raster data with zeros. Layout: [z, y, x, channel]
    # Channel 0: Red, 1: Green, 2: Blue
    raster = [[[[0, 0, 0] for _ in range(raster_width)] 
               for _ in range(raster_height)] 
              for _ in range(raster_length)]
    
    fade_factor = fade_margin
    
    for sphere in spheres:
        cx = sphere['x']
        cy = sphere['y']
        cz = sphere['z']
        r = sphere['radius']
        cr = sphere['color']['r']
        cg = sphere['color']['g']
        cb = sphere['color']['b']
        
        # Pitfall: Skip degenerate spheres
        if r <= 0.1:
            continue
            
        # Calculate bounding box
        x_min = max(0, int(cx - r))
        x_max = min(raster_width - 1, int(cx + r))
        y_min = max(0, int(cy - r))
        y_max = min(raster_height - 1, int(cy + r))
        z_min = max(0, int(cz - r))
        z_max = min(raster_length - 1, int(cz + r))
        
        # Precompute fade start distance
        fade_start = r * (1.0 - fade_factor)
        fade_denominator = r * fade_factor
        
        # Iterate over bounding box
        for z in range(z_min, z_max + 1):
            for y in range(y_min, y_max + 1):
                for x in range(x_min, x_max + 1):
                    # Calculate distance
                    dx = x - cx
                    dy = y - cy
                    dz = z - cz
                    dist = math.sqrt(dx*dx + dy*dy + dz*dz)
                    
                    # Calculate intensity
                    if dist <= r:
                        intensity = 1.0
                    elif dist <= fade_start:
                        intensity = 1.0 - (dist - fade_start) / fade_denominator
                    else:
                        continue # Outside fade region, no contribution
                    
                    # Calculate new color values
                    new_r = int(cr * intensity)
                    new_g = int(cg * intensity)
                    new_b = int(cb * intensity)
                    
                    # Maximum blending
                    if new_r > raster[z][y][x][0]:
                        raster[z][y][x][0] = new_r
                    if new_g > raster[z][y][x][1]:
                        raster[z][y][x][1] = new_g
                    if new_b > raster[z][y][x][2]:
                        raster[z][y][x][2] = new_b
                        
    return raster
```

## Operating characteristics
*   **Time Complexity:** $O(N \cdot R^3)$, where $N$ is the number of spheres and $R$ is the average radius in voxels. This is because each sphere iterates over its bounding box volume.
*   **Memory Complexity:** $O(L \cdot H \cdot W)$ for the voxel grid storage.
*   **Performance:** The method is CPU-friendly and simple to implement, but lacks the parallelization efficiency of GPU-based ray marching or sparse voxel octrees for large scenes. It is suitable for moderate-resolution grids and a limited number of spheres [S1, unofficial].
*   **Strengths:** Simple logic, no complex data structures (like BVH or Octrees) required, produces smooth edges via fading.
*   **Limitations:** Maximum blending can cause color bleeding if not handled carefully; performance degrades quickly with large radii or high voxel counts; no support for transparency or alpha blending in the basic form [S1, unofficial].

## Background
This method is derived from the `volumetric-display` project by fughilli, which aims to render volumetric data for LED cube displays [S1, unofficial]. It is a practical approach for real-time visualization on hardware-constrained devices where full ray-tracing is infeasible. The technique combines basic geometric rasterization with anti-aliasing techniques (edge fading) to improve visual quality on discrete voxel grids.
