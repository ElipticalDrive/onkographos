# Voxelizer Backward Pass

Also called: CUDA Rasterizer Backward Kernel, CudaVoxelizer::Voxelizer::backward

## Overview
The Voxelizer Backward Pass computes the gradients of the loss function with respect to the 3D Gaussian parameters (mean position, covariance/scale/rotation, and opacity) during the training of voxel-based Gaussian splatting methods [S1, S2, unofficial]. It serves as the differentiable counterpart to the forward voxelization and rasterization pass, enabling end-to-end optimization of the scene representation [S1, S2, unofficial]. It is implemented as a CUDA kernel launched from the host-side `Voxelizer::backward` function [S1, S2, unofficial].

## How it works
The method reconstructs the state objects from pre-allocated device buffers, determines the appropriate covariance pointers, and launches two distinct backward CUDA kernels: one for the rasterization step (computing gradients w.r.t. normalized means, conic matrices, and opacity) and one for the preprocessing step (computing gradients w.r.t. means, scales, and rotations) [S1, S2, unofficial].

**Inputs:**

*   `nVoxel_x`, `nVoxel_y`, `nVoxel_z`: Integer dimensions of the voxel grid [S2, unofficial].
*   `sVoxel_x`, `sVoxel_y`, `sVoxel_z`: Float scales of the voxels [S2, unofficial].
*   `center_x`, `center_y`, `center_z`: Float coordinates of the voxel grid center [S2, unofficial].
*   `means3D`: 3D mean positions of the Gaussians [S2, unofficial].
*   `scales`: Gaussian scales [S2, unofficial].
*   `scale_modifier`: Scale multiplier [S2, unofficial].
*   `rotations`: Gaussian rotations [S2, unofficial].
*   `cov3D_precomp`: Pre-computed covariances [S2, unofficial].
*   `radii`: Gaussian radii [S2, unofficial].
*   `dL_dpix`: Gradient of the loss with respect to the pixel values [S2, unofficial].

**Outputs:**
*   `dL_dmean3D_norm`: Gradient w.r.t. normalized 3D means [S2, unofficial].
*   `dL_dconic3D`: Gradient w.r.t. conic matrices [S2, unofficial].

*   `dL_drot`: Gradient w.r.t. rotations [S2, unofficial].

### Data Structures
The state objects are reconstructed from flat buffers using a `fromChunk` method [S1, unofficial]. The exact internal layout of `GeometryState`, `BinningState`, and `ImageState` is not specified in the sources [S1, S2, unofficial].

### Steps
1.  **Reconstruct State Objects**:
    *   `GeometryState geomState = GeometryState::fromChunk(geom_buffer, P)` [S1, unofficial].
    *   `BinningState binningState = BinningState::fromChunk(binning_buffer, R)` [S1, unofficial].
    *   `ImageState imgState = ImageState::fromChunk(img_buffer, nVoxel_x * nVoxel_y * nVoxel_z)` [S1, unofficial].
    *   `P` and `R` are parameters passed to `fromChunk`, likely representing pitch or stride [S1, unofficial].
2.  **Handle Radii**:
    *   If `radii` is `nullptr`, set it to `geomState.internal_radii` [S2, unofficial].
3.  **Calculate Tile Grid and Block Dimensions**:
    *   Compute tile grid and block dimensions using the same logic as the forward pass [S1, S2, unofficial].
4.  **Select Covariance Pointer**:
    *   `const float* cov3D_ptr = (cov3D_precomp != nullptr) ? cov3D_precomp : geomState.cov3D` [S1, unofficial].
5.  **Launch Backward Render Kernel**:
    *   Call `BACKWARD::render` to compute gradients w.r.t. normalized means, conic matrices, and opacity [S1, S2, unofficial].
6.  **Launch Backward Preprocess Kernel**:
    *   Call `BACKWARD::preprocess` to compute gradients w.r.t. means, covariances, scales, and rotations [S1, S2, unofficial].

### Edge Cases and Pitfalls
*   **Null Radii**: If `radii` is `nullptr`, the method falls back to `geomState.internal_radii` [S2, unofficial].
*   **Pre-computed Covariances**: If `cov3D_precomp` is provided, it is used instead of `geomState.cov3D` [S1, unofficial].

## Background
The Voxelizer Backward Pass is part of the CUDA Rasterizer implementation in the `r2_gaussian` and `x2-gaussian` projects, which are unofficial implementations of Gaussian splatting methods [S1, S2, unofficial]. The `r2_gaussian` project focuses on volumetric rendering and optimization, while `x2-gaussian` extends the method with dynamic deformation and multi-resolution voxel grids [S1, S2, unofficial]. The backward pass is essential for training these models, as it allows gradients to flow from the loss function back to the 3D Gaussian parameters [S1, S2, unofficial].
