# GPU-based Voxelization via Compute Shader

Also called: PGP-Voxelize

## Overview
A technique to convert 3D triangle meshes into a voxel grid representation using a GPU compute shader [S1, unofficial]. It solves the problem of generating a 3D boolean occupancy grid from mesh geometry by offloading the marking logic to the GPU [S1, unofficial]. Unlike CPU-based voxelization, this method leverages parallel compute shaders to mark occupied cells in a global grid buffer [S1, unofficial].

## How it works
**Inputs and Outputs:**
- **Input:** A 3D model file (OBJ format) containing vertices (`v`) and faces (`f`), and a user-defined `resolution` parameter representing the number of voxels along the X-axis [S1, unofficial].
- **Output:** A 3D boolean grid indicating occupied voxels and a list of world positions for those occupied cells [S1, unofficial].

**Data Structures:**
1.  **Model Data:**
    -   `vertices`: List of 3D points (float x, y, z) [S1, unofficial].
    -   `triangles`: List of vertex indices forming faces [S1, unofficial].
    -   `boundbox_min`, `boundbox_max`: Axis-aligned bounding box of the mesh [S1, unofficial].
2.  **GPU Buffers:**
    -   **SSBO 0 (Binding Point 0):** Stores triangle vertex data [S1, unofficial].
    -   **SSBO 1 (Binding Point 1):** Voxel grid [S1, unofficial]. Type: array of 32-bit integers (`GLint`) [S1, unofficial]. Size: `grid_size * sizeof(GLint)` where `grid_size = width * height * depth` [S1, unofficial]. Initialized to zero [S1, unofficial].

**Parameters:**
-   `resolution`: User-defined integer, voxels along X-axis [S1, unofficial].
-   `step`: Voxel size (float) [S1, unofficial].
-   `width`, `height`, `depth`: Grid dimensions (integers) [S1, unofficial].

**Steps:**
1.  **Parse Model:** Read OBJ file. Extract vertices and faces. Calculate `boundbox_min` and `boundbox_max` [S1, unofficial].
2.  **Calculate Grid Dimensions:**
    -   `step = (boundbox_max.x - boundbox_min.x) / resolution` [S1, unofficial].
    -   `width = resolution` [S1, unofficial].
    -   `height = ceil((boundbox_max.y - boundbox_min.y) / step)` [S1, unofficial].
    -   `depth = ceil((boundbox_max.z - boundbox_min.z) / step)` [S1, unofficial].
3.  **Upload Data:** Upload vertex data to SSBO 0 [S1, unofficial]. Allocate and zero-initialize SSBO 1 for the voxel grid [S1, unofficial].
4.  **Dispatch Compute Shader:**
    -   Dispatch size in X: `vbo_size + 32 - (vbo_size % 32)` (rounded up to multiple of 32) [S1, unofficial].
    -   Dispatch size in Y: 1 [S1, unofficial].
    -   Dispatch size in Z: 1 [S1, unofficial].
    -   The compute shader iterates over the input data and marks occupied voxels in SSBO 1 [S1, unofficial].
5.  **Memory Barrier:** Ensure writes to SSBO 1 are visible to subsequent host reads [S1, unofficial].
6.  **Readback:** Map SSBO 1 to host memory. Iterate through the 3D grid (z, y, x). If `voxels[z*height*width + y*width + x] == 1`, compute world position: `boundbox_min + (x*step, y*step, z*step)` [S1, unofficial].

**Pseudocode:**
```python
import math

class WPVector:
    def __init__(self, x=0.0, y=0.0, z=0.0):
        self.x, self.y, self.z = x, y, z
    def __add__(self, other):
        if isinstance(other, tuple):
            return WPVector(self.x + other[0], self.y + other[1], self.z + other[2])
        return WPVector(self.x + other.x, self.y + other.y, self.z + other.z)

def voxelize(obj_path, resolution):
    # 1. Parse Model
    vertices = []
    triangles = []
    boundbox_min = WPVector(float('inf'), float('inf'), float('inf'))
    boundbox_max = WPVector(float('-inf'), float('-inf'), float('-inf'))

    with open(obj_path, 'r') as f:
        for line in f:
            parts = line.split()
            if not parts: continue
            if parts[0] == 'v':
                x, y, z = float(parts[1]), float(parts[2]), float(parts[3])
                vertices.append(WPVector(x, y, z))
                if x < boundbox_min.x: boundbox_min.x = x
                if y < boundbox_min.y: boundbox_min.y = y
                if z < boundbox_min.z: boundbox_min.z = z
                if x > boundbox_max.x: boundbox_max.x = x
                if y > boundbox_max.y: boundbox_max.y = y
                if z > boundbox_max.z: boundbox_max.z = z
            elif parts[0] == 'f':
                triangles.append([int(idx.split('/')[0]) - 1 for idx in parts[1:4]])

    # 2. Calculate Grid Dimensions
    step = (boundbox_max.x - boundbox_min.x) / resolution
    width = resolution
    height = math.ceil((boundbox_max.y - boundbox_min.y) / step)
    depth = math.ceil((boundbox_max.z - boundbox_min.z) / step)
    grid_size = width * height * depth

    # 3. Setup GPU Buffers
    vbo_size = len(vertices)
    # SSBO 0: Vertex data (uploaded to GPU)
    ssbo_vertices = vertices
    # SSBO 1: Voxel grid (allocated and zero-initialized on GPU)
    ssbo_grid = [0] * grid_size

    # 4. Dispatch Compute Shader
    dispatch_x = vbo_size + 32 - (vbo_size % 32)
    dispatch_y = 1
    dispatch_z = 1
    # The compute shader kernel runs here, iterating over triangles/vertices
    # and marking occupied voxels in ssbo_grid. Exact rasterization logic is not provided.

    # 5. Memory Barrier
    # Host waits for GPU completion and ensures SSBO 1 visibility.

    # 6. Readback and Extract Voxels
    occupied_voxels = []
    for z in range(depth):
        for y in range(height):
            for x in range(width):
                index = z * height * width + y * width + x
                if ssbo_grid[index] == 1:
                    pos = boundbox_min + (x * step, y * step, z * step)
                    occupied_voxels.append(pos)

    return occupied_voxels
```

**Edge Cases and Pitfalls:**
-   **Precision:** Floating-point calculations for `step` and bounding box extents may introduce small errors. [G] Ensure consistent rounding modes when mapping grid indices to world coordinates.
-   **Boundary Conditions:** The `ceil` function for `height` and `depth` ensures full coverage but may create empty voxels at the edges if the bounding box extents are not perfectly divisible by `step`. [S1, unofficial]
-   **Dispatch Alignment:** The dispatch size is rounded up to a multiple of 32 for wavefront/warp alignment. If `vbo_size` is small, this may lead to idle threads. [S1, unofficial]

## Operating characteristics
-   **Time Complexity:** The compute shader dispatch is proportional to the number of vertices (rounded to a multiple of 32) [S1, unofficial]. Host readback is proportional to the grid size [S1, unofficial].
-   **Memory Complexity:** `O(grid_size)` for the voxel grid SSBO [S1, unofficial].
-   **Performance:** Not given in the sources. [S1, unofficial]
-   **Strengths:** Leverages GPU parallelism for marking occupied cells [S1, unofficial]. Simple implementation structure [S1, unofficial].
-   **Limitations:** Uses a dense grid representation, which is memory intensive for large volumes [S1, unofficial]. No anti-aliasing or coverage information is mentioned [S1, unofficial].
