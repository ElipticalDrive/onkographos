# GPU Voxelization via Projection and Bitmasking

Also called: hpsoar/voxelizer

## Overview
This method converts a triangle mesh into a 3D voxel grid on the GPU by rasterizing triangles into a bitmask representation [S1, unofficial]. It projects triangles onto 2D planes, tests voxel occupancy against triangle edges using plane equations, and updates a 32-bit integer bitmask per voxel to represent occupancy along the depth axis (Z) [S1, unofficial]. It is distinguished from its sibling [GPU Mesh Voxelization via Plane/Projection Tests](6744-gpu-mesh-voxelization-via-plane-projection-tests.md) by using a compact bitmask per voxel to store depth occupancy, reducing memory usage compared to storing a boolean or float per voxel, which is efficient for sparse or thin geometry [S1, unofficial].

## How it works
**Inputs:**
- Triangle mesh vertices (`vertices`): array of floats, size $3 \times N_{verts}$.
- Triangle mesh indices (`triangles`): array of integers, size $3 \times N_{tris}$.
- Voxel grid parameters:
  - `bbox0`: minimum bounds of the voxel grid (float[3]).
  - `delta`: voxel size (float[3]).
  - `inv_delta`: inverse voxel size (float[3]).
  - `stride`: stride for accessing voxels in memory (int[3]).
  - `vols`: pointer to the voxel grid array (int*).

**Outputs:**
- `vols`: array of integers representing the voxel grid. Each voxel is a 32-bit integer. The bitmask at index $(x, y, z)$ corresponds to the $z$-th bit of the integer at `voxel(x, y, z)`.

**Data Structures:**
- `vols`: `int*` array. The layout is linearized 3D. Access to voxel $(x, y, z)$ is calculated as `vols + z * stride[Z] + y * stride[Y] + x * stride[X]`.
- `tri_bbox0`, `tri_bbox1`: bounding box of the current triangle in world space (float[3]).

**Steps:**

1.  **Compute Triangle Bounding Box:** For each triangle, determine its axis-aligned bounding box in world space, `tri_bbox0` and `tri_bbox1`.

2.  **Map to Voxel Indices:** Calculate the voxel grid range $[start, end]$ for the triangle using the inverse voxel size.
    $$ start[i] = (tri\_bbox0[i] - bbox0[i]) \times inv\_delta[i] $$
    $$ end[i] = (tri\_bbox1[i] - bbox0[i]) \times inv\_delta[i] $$
    where $i \in \{X, Y, Z\}$. These values are floats representing the fractional voxel indices.

3.  **Calculate Integer and Bit Indices:** Determine the range of 32-bit integer blocks along the Z-axis.
    $$ int\_begin = \lfloor start[Z] \rfloor \gg 5 $$
    $$ bit\_begin = \lfloor start[Z] \rfloor \ \& \ 31 $$
    $$ int\_end = \lfloor end[Z] \rfloor \gg 5 $$
    $$ bit\_end = \lfloor end[Z] \rfloor \ \& \ 31 $$
    Note: The source code uses `start[Z] >> 5` which implies integer division by 32. Since `start` is float, it is cast to int (truncated) before shifting.

4.  **Preprocess for Optimization:** Determine the primary axis (X, Y, or Z) for optimization based on the bounding box dimensions.
    - If $start[X] == end[X]$, the triangle is degenerate in X.
    - If $start[Y] == end[Y]$, the triangle is degenerate in Y.
    - If $start[Z] == end[Z]$, the triangle is degenerate in Z.
    The preprocessing logic sets an `axis` flag and handles degenerate cases by setting bits directly or returning early [S1, unofficial].

5.  **Iterate 2D Range:** If not degenerate, iterate over the 2D range perpendicular to the primary axis. For a standard case, this involves iterating over $x$ and $y$ within $[start[X], end[X]]$ and $[start[Y], end[Y]]$.

6.  **Projection Test:** For each voxel $(x, y)$ in the 2D range, perform a projection test to determine if the voxel's column intersects the triangle's projection on the XY plane.
    - Compute edge vectors: $e_0 = v_1 - v_0$, $e_1 = v_2 - v_1$, $e_2 = v_0 - v_2$.
    - Compute plane distances for the triangle normal $n$ and edges.
    - The projection test checks if the point $(x, y)$ is inside the triangle's 2D projection. This is done by evaluating the sign of the cross product or plane equation for each edge.
    - Specifically, the code computes `n_d_xy` for each edge, which represents the plane equation parameters for the projection.
    - If the projection test fails, skip this voxel.

7.  **Compute Bitmask:** If the voxel is inside the triangle's projection, compute the bitmask of occupied voxels along the depth axis (Z).
    - Iterate $z$ from $start[Z]$ to $end[Z]$.
    - For each $z$, check if the point $p = (x, y, z)$ is inside the triangle in 3D.
    - The condition is: $(n \cdot p + d_1) \times (n \cdot p + d_2) \le 0$, where $d_1$ and $d_2$ are distances computed from the triangle vertices and normal.
    - Additionally, perform projection tests on the YZ and ZX planes to ensure the point is within the triangle's extent in all dimensions.
    - If the point is inside, set the $z$-th bit in the bitmask.

8.  **Atomic Update:** Atomically OR the computed bitmask into the voxel's integer in the `vols` array.
    $$ atomicOr(vol\_ptr, bits) $$

**Pseudocode:**

```python
# Constants
X = 0
Y = 1
Z = 2

def dot3(a, b):
    return a[0]*b[0] + a[1]*b[1] + a[2]*b[2]

def minus3(a, b, c):
    c[0] = a[0] - b[0]
    c[1] = a[1] - b[1]
    c[2] = a[2] - b[2]
    return c

def compute_plane_d(v, delta, x, y, z, n_d_xy):
    # n_d_xy[z] = -dot(n_d_xy[x:y], v[x:y])
    n_d_xy[z] = -(n_d_xy[x]*v[x] + n_d_xy[y]*v[y])
    tmp = delta[x] * n_d_xy[x]
    if tmp > 0:
        n_d_xy[z] += tmp
    tmp = delta[y] * n_d_xy[y]
    if tmp > 0:
        n_d_xy[z] += tmp

def compute_plane_n_d_0(v, e, x, y, z, delta, n_d_xy):
    n_d_xy[x] = e[y]
    n_d_xy[y] = -e[x]
    compute_plane_d(v, delta, x, y, z, n_d_xy)

def compute_plane_n_d_1(v, e, x, y, z, delta, n_d_xy):
    n_d_xy[x] = -e[y]
    n_d_xy[y] = e[x]
    compute_plane_d(v, delta, x, y, z, n_d_xy)

def compute_plane_n_d(v, e, x, y, z, n, delta, n_d_xy):
    if n[z] < 0:
        compute_plane_n_d_0(v, e, x, y, z, delta, n_d_xy)
    else:
        compute_plane_n_d_1(v, e, x, y, z, delta, n_d_xy)

def projection_test(p, x, y, z, n_d_xy):
    # Check if point p is on the correct side of the plane defined by n_d_xy
    # n_d_xy represents the plane equation: n_d_xy[x]*p[x] + n_d_xy[y]*p[y] + n_d_xy[z] >= 0
    return n_d_xy[x]*p[x] + n_d_xy[y]*p[y] + n_d_xy[z] >= 0

def process_range(begin, end, p, x, y, z, delta_z, n, d1, d2, n_d_xy, n_d_yz, n_d_zx):
    bits = 0
    for i in range(begin, end):
        p[z] = p[z] # p[z] is updated in the loop in the source, but here we assume p is passed by reference or updated externally
        # In the source, p[Z] is updated in the loop: p[Z] += delta_z
        # But here we iterate z indices, so we need to compute p[Z]
        # Let's assume p is updated in the caller
        
        # Evaluate Eq. 1: (n . p + d1) * (n . p + d2) <= 0
        n_dot_p = dot3(n, p)
        if (n_dot_p + d1) * (n_dot_p + d2) > 0:
            continue
        
        # Check projection tests on YZ and ZX planes
        if projection_test(p, Y, Z, X, n_d_yz) and projection_test(p, Z, X, Y, n_d_zx):
            bit = 1 << i
            bits |= bit
    return bits

def process_simple(int_begin, int_end, bit_begin, bit_end, vol_stride, vols, start, end, axis):
    # Handle degenerate cases where the triangle spans only one integer block or is degenerate in one axis
    if int_begin == int_end:
        # Set range [bit_begin, bit_end]
        if bit_end == 31:
            bits = 0xffffffff
        else:
            bits = (1 << (bit_end + 1)) - 1
        vol_ptr = vols + int_begin * vol_stride[Z] + start[Y] * vol_stride[Y] + start[X] * vol_stride[X]
        atomicOr(vol_ptr, bits)
    else:
        # First block
        if bit_end == 31:
            bits = 0xffffffff
        else:
            bits = (1 << (bit_end + 1)) - 1
        vol_ptr = vols + int_begin * vol_stride[Z] + start[Y] * vol_stride[Y] + start[X] * vol_stride[X]
        atomicOr(vol_ptr, bits)
        
        # Middle blocks
        for i in range(int_begin + 1, int_end):
            bits = 0xffffffff
            vol_ptr += vol_stride[Z]
            atomicOr(vol_ptr, bits)
            
        # Last block
        if bit_end == 31:
            bits = 0xffffffff
        else:
            bits = (1 << (bit_end + 1)) - 1
        vol_ptr += vol_stride[Z]
        atomicOr(vol_ptr, bits)

def voxelize_kernel(tri_idx, vertices, triangles, N, tri_bbox0, tri_bbox1, bbox0, delta, inv_delta, stride, vols):
    # Get triangle vertices
    v0 = vertices[3*triangles[tri_idx]]
    v1 = vertices[3*triangles[tri_idx + N]]
    v2 = vertices[3*triangles[tri_idx + 2*N]]
    
    # Compute triangle normal
    e0 = [v1[0]-v0[0], v1[1]-v0[1], v1[2]-v0[2]]
    e1 = [v2[0]-v1[0], v2[1]-v1[1], v2[2]-v1[2]]
    n = [e0[1]*e1[2]-e0[2]*e1[1], e0[2]*e1[0]-e0[0]*e1[2], e0[0]*e1[1]-e0[1]*e1[0]]
    
    # Compute bounding box
    tri_bbox0 = [min(v0[0], v1[0], v2[0]), min(v0[1], v1[1], v2[1]), min(v0[2], v1[2], v2[2])]
    tri_bbox1 = [max(v0[0], v1[0], v2[0]), max(v0[1], v1[1], v2[1]), max(v0[2], v1[2], v2[2])]
    
    # Map to voxel indices
    start = [(tri_bbox0[i] - bbox0[i]) * inv_delta[i] for i in range(3)]
    end = [(tri_bbox1[i] - bbox0[i]) * inv_delta[i] for i in range(3)]
    
    # Calculate integer and bit indices
    int_begin = int(start[Z]) >> 5
    bit_begin = int(start[Z]) & 31
    int_end = int(end[Z]) >> 5
    bit_end = int(end[Z]) & 31
    
    # Preprocess
    axis = -1
    flag = 0
    if start[X] == end[X]:
        flag += 1
        axis = X
    if start[Y] == end[Y]:
        if flag > 0:
            # Set all along Z
            process_simple(int_begin, int_end, bit_begin, bit_end, stride, vols, start, end, Z)
            return
        flag += 1
        axis = Y
    if start[Z] == end[Z]:
        if flag > 0:
            # Set all along other axis
            bits = 1 << bit_begin
            vol = vols + int_begin * stride[Z] + start[Y] * stride[Y] + start[X] * stride[X]
            other_axis = 1 - axis
            for i in range(start[other_axis], end[other_axis] + 1):
                atomicOr(vol, bits)
                vol += stride[other_axis]
            return
        flag += 1
        axis = Z # Fallback, though this case is handled by the loop below
    
    # Compute plane distances
    # d1 = dot(n, c - v0)
    # d2 = dot(n, delta - c - v0)
    # c is a vector with components delta[i] if n[i] > 0 else 0
    c = [delta[i] if n[i] > 0 else 0 for i in range(3)]
    d1 = dot3(n, [c[i] - v0[i] for i in range(3)])
    d2 = dot3(n, [delta[i] - c[i] - v0[i] for i in range(3)])
    
    # Compute plane equations for projections
    n_d_xy = [[0,0,0] for _ in range(3)]
    n_d_yz = [[0,0,0] for _ in range(3)]
    n_d_zx = [[0,0,0] for _ in range(3)]
    
    # Edges
    edges = [e0, e1, [v0[0]-v2[0], v0[1]-v2[1], v0[2]-v2[2]]]
    
    for i in range(3):
        compute_plane_n_d([v0, v1, v2], edges, X, Y, Z, n, delta, n_d_xy[i])
        compute_plane_n_d([v0, v1, v2], edges, Y, Z, X, n, delta, n_d_yz[i])
        compute_plane_n_d([v0, v1, v2], edges, Z, X, Y, n, delta, n_d_zx[i])
        
    # Iterate over 2D range
    for x in range(int(start[X]), int(end[X]) + 1):
        for y in range(int(start[Y]), int(end[Y]) + 1):
            # Check projection test on XY plane
            p = [x * delta[X] + bbox0[X], y * delta[Y] + bbox0[Y], 0]
            # Simple projection test: check if (x,y) is inside triangle projection
            # This is a simplified check; the actual code uses n_d_xy
            inside = True
            for i in range(3):
                if not projection_test(p, X, Y, Z, n_d_xy[i]):
                    inside = False
                    break
            if not inside:
                continue
            
            # Compute bitmask
            p_start = [x * delta[X] + bbox0[X], y * delta[Y] + bbox0[Y], start[Z] * delta[Z] + bbox0[Z]]
            vol_ptr = vols + int_begin * stride[Z] + y * stride[Y] + x * stride[X]
            
            bits = process_range(bit_begin, bit_end + 1, p_start, X, Y, Z, delta[Z], n, d1, d2, n_d_xy, n_d_yz, n_d_zx)
            
            atomicOr(vol_ptr, bits)
```

**Edge Cases and Pitfalls:**
- When `int_begin == int_end`, the triangle spans only one integer block along Z. The bit range is restricted to `[bit_begin, bit_end]`.
- When `int_begin != int_end`, the first block uses `[bit_begin, 31]`, middle blocks use `[0, 31]`, and the last block uses `[0, bit_end]`.
- Precision issues may arise when triangle vertices lie exactly on voxel boundaries. The use of `>= 0` in projection tests helps, but degenerate triangles (area 0) should be skipped.

## Operating characteristics
- **Time Complexity:** $O(N_{tris} \times B_{xy})$, where $B_{xy}$ is the number of voxels in the 2D bounding box of the triangle. The bitmask computation is $O(B_z)$, where $B_z$ is the number of voxels along the Z-axis.
- **Memory Complexity:** $O(V)$, where $V$ is the number of voxels in the grid. Each voxel stores a 32-bit integer.
- **Measured Performance:** Not given in the sources.
- **Scaling:** Scales linearly with the number of triangles and the size of their bounding boxes.
- **Strengths:** Efficient for sparse or thin geometry due to bitmask representation. Reduces memory usage compared to storing a boolean or float per voxel.
- **Limitations:** Limited to 32 voxels per column due to 32-bit integer bitmask. Not suitable for dense geometry where many voxels per column are occupied.
- **When to use:** Sparse meshes, thin geometry, real-time voxelization on GPU.
- **When not to use:** Dense geometry, large number of voxels per column, need for sub-voxel precision.

## Background
This method is implemented in the `hpsoar/voxelizer` repository [S1, unofficial]. It is a GPU-based technique that uses compute shaders to rasterize triangles into a 3D voxel grid. The method is designed for efficiency on modern GPUs, leveraging atomic operations and bitmasking to reduce memory bandwidth and storage requirements.
