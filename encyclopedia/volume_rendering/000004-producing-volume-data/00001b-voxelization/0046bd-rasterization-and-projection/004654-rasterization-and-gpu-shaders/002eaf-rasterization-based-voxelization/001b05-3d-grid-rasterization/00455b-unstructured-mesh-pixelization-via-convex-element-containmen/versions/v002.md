# Unstructured Mesh Pixelization via Convex Element Containment


## Overview
A pixelization routine that transforms variable-resolution unstructured mesh values into an image buffer by depositing values through nearest-neighbor interpolation with anti-aliasing, decoupling the pixelization step from the underlying data model [S1]. It differs from standard rasterization by using a geometric containment test based on dot product signs relative to element centroids, which eliminates the requirement for consistent vertex winding order (CW/CCW) [S1].

## How it works
**Inputs:**
- A set of unstructured mesh elements (e.g., hexahedra, tetrahedra, wedges) [S1].
- Field data defined at element centroids [S1].
- An interpolation kernel (initially nearest-neighbor) [S1].
- Image plane dimensions and view parameters [S1].

**Outputs:**
- An image buffer containing deposited values [S1].

**Data Structures:**
- **Element:** Defined by a centroid position $\mathbf{c}$ and a set of face normal vectors $\{\mathbf{n}_i\}$ [S1].
- **Containment Signatures:** For each element, a precomputed array of signs $s_i = \text{sign}(\mathbf{c} \cdot \mathbf{n}_i)$ for each face $i$ [S1].
- **Image Buffer:** A 2D array corresponding to the image plane pixels [S1].

**Steps:**
1. **Bounding Box Culling:** Apply coarse bounding box checks to the image plane and all supplied elements to filter out elements that do not intersect the view frustum [S1].
2. **Precompute Element Signatures:** For each element, compute the sign of the dot product between the element centroid $\mathbf{c}$ and each normal vector $\mathbf{n}_i$ defining its faces, storing these signs to determine internal containment without requiring clockwise/counter-clockwise vertex ordering [S1].
3. **Iterate Mesh Types:** Iterate over each mesh type separately to deposit their fields in sequence, enabling interoperation of fields between mesh types without requiring uniform size [S1].
4. **Pixel Containment Test:** For each pixel in the image plane that passed the bounding box check for a given element:
   a. Calculate the pixel's position $\mathbf{p}$ in the same coordinate system as the element [S1].
   b. Calculate the sign of the dot product between the pixel's position and each face normal vector: $s'_i = \text{sign}(\mathbf{p} \cdot \mathbf{n}_i)$ [S1].
   c. Compare the pixel's sign array with the element's stored signature [S1].
   d. If all the signs match, classify the pixel as internal to the convex element [S1].
5. **Value Deposition:** If the pixel is internal, evaluate the appropriate interpolation kernel for the internal point and deposit the resulting value into the image plane [S1].

**Pseudocode:**
```python
def dot(a, b):
    return sum(x * y for x, y in zip(a, b))

def sign(x):
    return 1 if x >= 0 else -1

def zeros(shape):
    return [[0.0 for _ in range(shape[1])] for _ in range(shape[0])]

def unstructured_mesh_pixelization(elements, image_width, image_height, kernel, view_bounds):
    """
    Pixels values from unstructured mesh elements to an image buffer.
    """
    image_buffer = zeros((image_height, image_width))

    # Step 1: Bounding box culling
    # Filter elements that do not intersect the view frustum/image plane bounds.
    # Exact frustum math is implementation-dependent based on the coordinate handler.
    visible_elements = [e for e in elements if not (e['bbox_max'][0] < view_bounds[0] or e['bbox_min'][0] > view_bounds[3] or
                                                     e['bbox_max'][1] < view_bounds[1] or e['bbox_min'][1] > view_bounds[4] or
                                                     e['bbox_max'][2] < view_bounds[2] or e['bbox_min'][2] > view_bounds[5])]

    # Step 3: Iterate over mesh types (simplified here as a single loop over elements)
    for element in visible_elements:
        centroid = element['centroid']
        normals = element['normals']
        value = element['value']

        # Step 2: Precompute element containment signature
        element_signatures = [sign(dot(centroid, n)) for n in normals]

        # Step 4: Iterate over pixels in the image plane
        for y in range(image_height):
            for x in range(image_width):
                # Map pixel coordinates to world space (simplified linear mapping)
                pixel_pos = (x, y, 0.0)

                # Calculate pixel containment signature
                pixel_signatures = [sign(dot(pixel_pos, n)) for n in normals]

                # Check if all signs match
                if all(ps == es for ps, es in zip(pixel_signatures, element_signatures)):
                    # Step 5: Deposit value
                    image_buffer[y][x] = kernel(pixel_pos, centroid, value)

    return image_buffer

def kernel(pixel_pos, centroid, value):
    # Nearest-neighbor interpolation kernel
    return value
```

**Parameters:**
- `interpolation_kernel`: The kernel used for value deposition; initially supports only nearest-neighbor [S1].
- `field_definition_location`: The location where field data is defined within the element; initially supports only centroids, with edge and face support planned [S1].

**Edge Cases and Pitfalls:**
- The containment test assumes convex elements; non-convex elements may fail the sign-matching test [S1].
- Vertex ordering (CW/CCW) is not required for the containment test because it relies on dot product signs relative to the centroid [S1].

## Background
This method is described in YTEP-0031, an enhancement proposal for the yt unstructured mesh handling capabilities [S1]. It was developed to address the need for flexible pixelization of variable-resolution unstructured mesh data, allowing for the interoperation of fields between different mesh types without requiring uniform size [S1].
