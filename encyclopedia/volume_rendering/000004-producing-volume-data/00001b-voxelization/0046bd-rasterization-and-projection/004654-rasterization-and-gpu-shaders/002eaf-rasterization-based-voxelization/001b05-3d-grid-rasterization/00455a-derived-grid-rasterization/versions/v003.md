# Derived Grid Rasterization

Also called: Derived Grid for Unstructured Volume Rendering, DerivedGrid, DerivedGrid construction, Tetrahedral Grid Construction, Unstructured Volume Grid, Unstructured Volume to Structured Grid Conversion, cell-to-voxel mapping

## Overview
Derived Grid Rasterization converts an unstructured 3D volume mesh (e.g., tetrahedra, hexahedra) into a dense, regular 3D voxel grid spanning the mesh's Axis-Aligned Bounding Box (AABB) [S1, unofficial]. It maps each voxel to its owning unstructured cell and local tetrahedron index, enabling direct structured lookup for volume ray-marching and axis-aligned slice planes [S1, unofficial]. Unlike sibling methods that produce sparse structures or rely on different rasterization primitives, this method explicitly stores cell connectivity per voxel for subsequent rendering [S1, unofficial].

## How it works
**Inputs:**
- Unstructured mesh with volume cells (tetrahedra, hexahedra, etc.) [S1, unofficial].
- Scalar field data associated with points or cells [S1, unofficial].
- Parameters: `maxDim` (default 192), `maxVoxels` (default $16 \ll 20$ or 16 Mi) [S1, unofficial].

**Outputs:**
- `DerivedGrid`: Structured grid containing voxel-to-cell mappings and occupancy [S1, unofficial].
- `ScalarGrid`: Structured scalar field values with occupancy mask and slice min/max bounds [S1, unofficial].

**Data Structures:**

`DerivedGrid` layout:
- `dimX`, `dimY`, `dimZ`: `int`, grid dimensions in voxels [S1, unofficial].
- `origin`, `extent`: `glm::dvec3`, AABB origin and size in world units [S1, unofficial].
- `cellId`: `std::vector<uint32_t>`, size `dimX * dimY * dimZ`. Stores the ID of the unstructured cell containing the voxel center. Empty voxels store `kEmpty` ($0xFFFFFFFFu$) [S1, unofficial].
- `tet`: `std::vector<uint8_t>`, size `dimX * dimY * dimZ`. Stores the local tetrahedron index within the owning cell [S1, unofficial].
- `cellVoxelStart`: `std::vector<uint32_t>`, size `numCells + 1`. CSR-style start indices for voxel lists per cell [S1, unofficial].
- `cellVoxels`: `std::vector<uint32_t>`, flattened list of voxel indices grouped by cell ID [S1, unofficial].
- `kEmpty`: Constant `0xFFFFFFFFu` [S1, unofficial].

`ScalarGrid` layout:
- `value`: `std::vector<float>`, size `dimX * dimY * dimZ`. Scalar values, valid where `occupancy` is true [S1, unofficial].
- `occupancy`: `std::vector<std::uint8_t>`, boolean mask for occupied voxels [S1, unofficial].
- `planeMin`, `planeMax`: `std::array<std::vector<float>, 3>`, per-axis slice min/max values for occupied voxels, used for early ray termination [S1, unofficial].

**Steps:**

1. **Eligibility Check:**
   - Reject if vertices are empty, no unstructured volume cells exist, topology is invalid (e.g., CSR inconsistent), or bounding box extents are non-positive or zero within epsilon (rejects 2D meshes) [S1, unofficial].

2. **Grid Dimension Calculation:**
   - Compute spacing from the longest AABB extent and `maxDim` [S1, unofficial].
   - Iterate to find dimensions such that total voxels $\le$ `maxVoxels` [S1, unofficial].
   - Clamp each dimension between 2 and `maxDim` [S1, unofficial].
   - If spacing becomes non-positive or infinite, fail [S1, unofficial].

3. **Cell Decomposition:**
   - For each volume cell, decompose it into tetrahedra using `cell_topology::tets` [S1, unofficial].
   - Skip cells if decomposition fails or returns empty [S1, unofficial].

4. **Degeneracy Check:**
   - Compute scale-relative volume epsilon based on the maximum corner distance cubed [S1, unofficial].
   - Skip tetrahedra with determinant magnitude $\le$ `volumeEps` to avoid ill-conditioned barycentric solves [S1, unofficial].

5. **Voxel Intersection (Rasterization):**
   - For each tetrahedron, compute its bounding box in grid coordinates:
     $$ tmin[a] = \min(p_0[a], p_1[a], p_2[a], p_3[a]) $$
     $$ tmax[a] = \max(p_0[a], p_1[a], p_2[a], p_3[a]) $$
     where $p_i$ are the cell's vertex positions [S1, unofficial].
   - Calculate grid indices covering the bounding box:
     $$ f0[a] = \frac{tmin[a] - origin[a]}{step[a]} - 0.5 $$
     $$ i0[a] = \text{clamp}(\lfloor f0[a] \rfloor, 0, dim[a] - 1) $$
     $$ i1[a] = \text{clamp}(\lfloor \frac{tmax[a] - origin[a]}{step[a]} - 0.5 \rfloor, 0, dim[a] - 1) $$
   - Iterate over all voxels $(x, y, z)$ in $[i0, i1]$ [S1, unofficial].
   - Compute voxel center in world space:
     $$ point = origin + (x + 0.5, y + 0.5, z + 0.5) \times \frac{extent}{dims} $$
     This mapping matches the volume shader's UVW calculation: $uvw = (pos - origin) / extent$ [S1, unofficial].
   - Compute barycentric coordinates $w$ of `point` relative to the tetrahedron vertices [S1, unofficial].
   - If any weight $w_i < -kInsideTol$ or $\sum w_i \neq 1.0$ (within tolerance), the voxel is outside. If all weights satisfy the condition, the voxel is inside [S1, unofficial].
   - Mark voxel as occupied: `cellId[idx] = cellID`, `tet[idx] = tetIndex` [S1, unofficial].

6. **Pin Thin Cells:**
   - For cells that are thinner than one voxel (do not contain any voxel center), pin them to the voxel containing their geometric center [S1, unofficial].
   - Assign `cellId` and `tet` index 0 to that voxel [S1, unofficial].

7. **Counting Sort (CSR Construction):**
   - Count occurrences of each cell ID in `cellId`: `++cellVoxelStart[id + 1]` [S1, unofficial].
   - Compute prefix sums: `cellVoxelStart[c] += cellVoxelStart[c - 1]` [S1, unofficial].
   - Scatter voxel indices into `cellVoxels` using cursors initialized from `cellVoxelStart`: `cellVoxels[cursor[id]++] = i` [S1, unofficial].

8. **Scalar Scattering:**
   - Scatter field values into `ScalarGrid.value` [S1, unofficial].
   - If `cellPlacement` is false, remap point data from pre-split vertex space to post-split vertex space using `vertexSourceIndex` [S1, unofficial].
   - If `cellPlacement` is true, treat values as one per cell [S1, unofficial].
   - Compute per-slice min/max for occupied voxels into `planeMin` and `planeMax` [S1, unofficial].

**Pseudocode:**

```python
import math
from typing import List, Tuple, Any

class DerivedGrid:
    def __init__(self, dimX, dimY, dimZ, origin, extent, cellId, tet, cellVoxelStart, cellVoxels):
        self.dimX, self.dimY, self.dimZ = dimX, dimY, dimZ
        self.origin = origin
        self.extent = extent
        self.cellId = cellId
        self.tet = tet
        self.cellVoxelStart = cellVoxelStart
        self.cellVoxels = cellVoxels
        self.kEmpty = 0xFFFFFFFF

class ScalarGrid:
    def __init__(self, value, occupancy, planeMin, planeMax):
        self.value = value
        self.occupancy = occupancy
        self.planeMin = planeMin
        self.planeMax = planeMax

def compute_aabb(vertices):
    min_v = [float('inf')] * 3
    max_v = [float('-inf')] * 3
    for v in vertices:
        for a in range(3):
            if v[a] < min_v[a]: min_v[a] = v[a]
            if v[a] > max_v[a]: max_v[a] = v[a]
    return min_v, max_v

def compute_grid_dims(extent, max_dim, max_voxels):
    max_extent = max(extent)
    spacing = max_extent / max_dim
    if spacing <= 0 or math.isinf(spacing):
        raise ValueError("Invalid spacing")
    dims = [max(2, min(max_dim, int(math.floor(e / spacing)))) for e in extent]
    while dims[0] * dims[1] * dims[2] > max_voxels:
        max_idx = dims.index(max(dims))
        dims[max_idx] = max(2, dims[max_idx] - 1)
    return dims

def decompose_cell_to_tets(cell_verts):
    # Sources do not specify the exact cell-to-tet decomposition algorithm.
    # Standard approach: split polyhedra into tetrahedra via fan or dual-triangulation.
    return []

def barycentric(point, tet_verts):
    v0, v1, v2, v3 = tet_verts
    mat = [[v0[0]-v3[0], v1[0]-v3[0], v2[0]-v3[0]],
           [v0[1]-v3[1], v1[1]-v3[1], v2[1]-v3[1]],
           [v0[2]-v3[2], v1[2]-v3[2], v2[2]-v3[2]]]
    vec = [point[0]-v3[0], point[1]-v3[1], point[2]-v3[2]]
    det = (mat[0][0]*(mat[1][1]*mat[2][2]-mat[1][2]*mat[2][1]) -
           mat[0][1]*(mat[1][0]*mat[2][2]-mat[1][2]*mat[2][0]) +
           mat[0][2]*(mat[1][0]*mat[2][1]-mat[1][1]*mat[2][0]))
    if abs(det) < 1e-9: return [0, 0, 0, 0]
    w0 = ((vec[0]*(mat[1][1]*mat[2][2]-mat[1][2]*mat[2][1]) - mat[0][1]*(vec[1]*mat[2][2]-mat[1][2]*vec[2]) + mat[0][2]*(vec[1]*mat[2][1]-mat[1][1]*vec[2])) / det)
    w1 = ((mat[0][0]*(vec[1]*mat[2][2]-mat[1][2]*vec[2]) - vec[0]*(mat[1][0]*mat[2][2]-mat[1][2]*mat[2][0]) + mat[0][2]*(mat[1][0]*vec[2]-vec[1]*mat[2][0])) / det)
    w2 = ((mat[0][0]*(mat[1][1]*vec[2]-vec[1]*mat[2][1]) - mat[0][1]*(mat[1][0]*vec[2]-vec[1]*mat[2][0]) + vec[0]*(mat[1][0]*mat[2][1]-mat[1][1]*mat[2][0])) / det)
    w3 = 1.0 - w0 - w1 - w2
    return [w0, w1, w2, w3]

def compute_centroid(vertices):
    return [sum(v[a] for v in vertices) / len(vertices) for a in range(3)]

def scatter_scalars(mesh, cell_id, occupancy, origin, extent, dims, cell_placement, vertex_source_index, point_data, cell_data):
    num_voxels = dims[0] * dims[1] * dims[2]
    value = [0.0] * num_voxels
    occupancy_mask = [False] * num_voxels
    plane_min = [[float('inf')] * dims[a] for a in range(3)]
    plane_max = [[float('-inf')] * dims[a] for a in range(3)]

    for idx in range(num_voxels):
        if not occupancy[idx]: continue
        occupancy_mask[idx] = True
        cid = cell_id[idx]
        if cell_placement:
            val = cell_data[cid]
        else:
            # Remap point data using vertexSourceIndex as per source notes.
            # Exact indexing depends on mesh data layout.
            val = point_data[cid] 
        value[idx] = val
        for a in range(3):
            if a == 0: ax = idx % dims[0]
            elif a == 1: ax = (idx // dims[0]) % dims[1]
            else: ax = idx // (dims[0] * dims[1])
            if val < plane_min[a][ax]: plane_min[a][ax] = val
            if val > plane_max[a][ax]: plane_max[a][ax] = val
    return ScalarGrid(value, occupancy_mask, plane_min, plane_max)

def derive_grid(mesh, max_dim=192, max_voxels=16 << 20, k_inside_tol=1e-6):
    if not mesh.vertices or not mesh.cells:
        raise ValueError("Empty mesh")
    bbox_min, bbox_max = compute_aabb(mesh.vertices)
    extent = [bbox_max[a] - bbox_min[a] for a in range(3)]
    if any(e <= 0 for e in extent):
        raise ValueError("Degenerate AABB")

    dims = compute_grid_dims(extent, max_dim, max_voxels)
    origin = bbox_min
    step = [extent[a] / dims[a] for a in range(3)]

    num_voxels = dims[0] * dims[1] * dims[2]
    cell_id = [0xFFFFFFFF] * num_voxels
    tet_idx = [0] * num_voxels
    occupancy = [False] * num_voxels

    for c, cell_verts in mesh.cells.items():
        tets = decompose_cell_to_tets(cell_verts)
        if not tets: continue

        # Degeneracy check: compute scale-relative volume epsilon based on max corner distance cubed.
        # Skip tetrahedra with determinant magnitude <= volumeEps.
        
        cell_bbox_min, cell_bbox_max = compute_aabb(cell_verts)
        f0 = [(cell_bbox_min[a] - origin[a]) / step[a] - 0.5 for a in range(3)]
        i0 = [max(0, min(dims[a] - 1, math.floor(f))) for a, f in enumerate(f0)]
        f1 = [(cell_bbox_max[a] - origin[a]) / step[a] - 0.5 for a in range(3)]
        i1 = [max(0, min(dims[a] - 1, math.floor(f))) for a, f in enumerate(f1)]

        touched = False
        for x in range(i0[0], i1[0] + 1):
            for y in range(i0[1], i1[1] + 1):
                for z in range(i0[2], i1[2] + 1):
                    idx = x + y * dims[0] + z * dims[0] * dims[1]
                    point = [origin[a] + (coord + 0.5) * step[a] for a, coord in enumerate([x, y, z])]

                    for t_idx, tet in enumerate(tets):
                        w = barycentric(point, tet)
                        if all(w_i > -k_inside_tol for w_i in w) and abs(sum(w) - 1.0) < k_inside_tol:
                            cell_id[idx] = c
                            tet_idx[idx] = t_idx
                            occupancy[idx] = True
                            touched = True
                            break

        if not touched:
            center = compute_centroid(cell_verts)
            cx = max(0, min(dims[0] - 1, math.floor((center[0] - origin[0]) / step[0] - 0.5)))
            cy = max(0, min(dims[1] - 1, math.floor((center[1] - origin[1]) / step[1] - 0.5)))
            cz = max(0, min(dims[2] - 1, math.floor((center[2] - origin[2]) / step[2] - 0.5)))
            idx = cx + cy * dims[0] + cz * dims[0] * dims[1]
            cell_id[idx] = c
            tet_idx[idx] = 0
            occupancy[idx] = True

    cell_voxel_start = [0] * (mesh.num_cells + 1)
    for idx in range(num_voxels):
        cid = cell_id[idx]
        if cid != 0xFFFFFFFF:
            cell_voxel_start[cid + 1] += 1
    for c in range(1, len(cell_voxel_start)):
        cell_voxel_start[c] += cell_voxel_start[c - 1]

    cell_voxels = [0] * sum(cell_voxel_start[:-1])
    cursor = cell_voxel_start.copy()
    for idx in range(num_voxels):
        cid = cell_id[idx]
        if cid != 0xFFFFFFFF:
            cell_voxels[cursor[cid]] = idx
            cursor[cid] += 1

    scalar_grid = scatter_scalars(mesh, cell_id, occupancy, origin, extent, dims,
                                  mesh.cell_placement, mesh.vertex_source_index,
                                  mesh.point_data, mesh.cell_data)

    return DerivedGrid(dims[0], dims[1], dims[2], origin, extent, cell_id, tet_idx, cell_voxel_start, cell_voxels), scalar_grid
```

**Edge Cases and Pitfalls:**
- Empty voxels (outside every volume cell) are marked with `kEmpty` ($0xFFFFFFFFu$) so that shaders can skip them, preventing fogging of the entire bounding box [S1, unofficial].
- The derived grid is static geometry; it does not change when the scalar field changes. Transient frames only re-scatter the field data into the grid structure [S1, unofficial].
- 2D mesh rejection: Meshes with zero z-extent (triangles/quads) are rejected by eligibility check to prevent degenerate 3D rasterization [S1, unofficial].
- Vertex index remapping: Point data may be indexed in pre-split vertex space (original mesh vertices) but rendered in post-split space (one value per rendered vertex). Use `vertexSourceIndex` to remap [S1, unofficial].

## Operating characteristics
- **Time Complexity:** $O(C \cdot T \cdot V)$ where $C$ is the number of cells, $T$ is the average number of tetrahedra per cell, and $V$ is the average number of voxels in a tetrahedron's bounding box. Grid construction (CSR, scattering) is $O(V_{total})$ [S1, unofficial].
- **Memory Complexity:** $O(V_{total})$ for the dense grid arrays (`cellId`, `tet`, `occupancy`, `value`). The CSR structures add $O(C + V_{occupied})$ [S1, unofficial].
- **Performance:** The method is static; the grid structure does not change when the scalar field changes, allowing transient frames to only re-scatter field data [S1, unofficial]. Performance is limited by the dense nature of the grid; large `maxVoxels` can lead to high memory usage and cache misses during ray-marching if the volume is sparse.
- **Strengths:** Provides a simple, structured lookup for volume rendering. Efficient for dense volumes. Compatible with standard volume shaders.
- **Limitations:** Inefficient for sparse volumes due to dense grid storage. Sensitive to grid resolution; too fine a grid increases memory, too coarse loses detail. 2D meshes are explicitly rejected [S1, unofficial].
- **When to use:** When the volume is dense and fits within memory limits, and simple structured access is preferred.
- **When not to use:** For highly sparse volumes where sparse voxel octrees (like [Adaptive Sparse Voxelization](1686-adaptive-sparse-voxelization-with-bounding-box-thickness-cas.md)) would be more efficient.

## Background
Derived Grid Rasterization is implemented in SciRender, an open-source scientific visualization tool [S1, unofficial]. It is designed to handle unstructured volume meshes (like those from CFD simulations) by converting them into a format suitable for real-time volume rendering in OpenGL. The method addresses the need for structured data access in volume ray-marching shaders when the underlying data is unstructured [S1, unofficial].
