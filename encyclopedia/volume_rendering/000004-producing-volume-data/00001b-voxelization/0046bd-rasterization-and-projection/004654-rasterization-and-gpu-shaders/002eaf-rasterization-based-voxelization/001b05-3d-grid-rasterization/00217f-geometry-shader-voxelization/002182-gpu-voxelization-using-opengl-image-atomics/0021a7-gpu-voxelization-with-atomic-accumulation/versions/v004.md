# GPU Voxelization with Atomic Accumulation

Also called: Atomic RGBA8 Averaging, Atomic Average for Voxelization, Atomic RGBA8 average voxelization, Atomic Voxelization with Averaging, Atomic Running Average Voxelization, Voxelization with Atomic Running Average, Voxelization via Fragment Shader with Image Atomic Operations

## Overview
A fragment-shader-based voxelization technique that accumulates per-fragment lighting and material properties into a 3D texture using hardware atomic operations to resolve race conditions and compute a moving average of samples per voxel [S1, S2, unofficial]. It differs from its parent, [GPU Voxelization Using OpenGL Image Atomics](2544-gpu-voxelization-using-opengl-image-atomics.md), by explicitly implementing a moving average via `imageAtomicCompSwap` loops to prevent flickering when multiple primitives overwrite the same voxel, rather than relying solely on conservative rasterization or simple max operations [S1, S4, unofficial].

## How it works
**Inputs:**
- 3D triangle mesh geometry.
- Material properties (diffuse color, emission, transparency mode).
- Light sources (position, color, intensity).
- Scene parameters (voxel resolution, view matrices, shadow maps).

**Outputs:**
- A 3D texture (or array of 3D textures) storing voxel data in `RGBA8` format (packed into `uint`).
- A sparse list of occupied voxel coordinates.

**Data Structures:**

1.  **VoxelData** (Internal struct):
    - `color`: `vec4` (RGBA8 scaled to 0-1).
    - `light`: `uint` (4-bit shadow flag).
    - `count`: `uint` (4-bit sample counter).

2.  **Packed Voxel Value** (`uint`):
    - Bits 28-31: `light` (4 bits).
    - Bits 24-27: `count` (4 bits).
    - Bits 16-23: `R` (8 bits).
    - Bits 8-15: `G` (8 bits).
    - Bits 0-7: `B` (8 bits).
    - *Note: Alpha is stored separately or implied by the averaging logic in some variants, but the primary packing for accumulation focuses on RGB, Light, and Count.*

3.  **Sparse List Entry** (`uint`):
    - Packed XYZ coordinates using `packRG11B10`:
      - R: 11 bits.
      - G: 11 bits.
      - B: 10 bits.

**Numbered Steps:**

1.  **Rasterization and Voxel Coordinate Calculation:**
    - Project geometry along a dominant axis (e.g., X, Y, or Z) to generate fragments.
    - Calculate base voxel coordinates in texture space:
      $$ \text{baseVoxel} = \text{uvec3}(\text{floor}(\min(\text{In.posTexSpace}, \text{vec3}(0.999)) \times \text{voxelTexSize})) $$
    - Clamp position to `0.999` to prevent floating-point errors from mapping to the maximum voxel index (out of bounds) [S3, S4, unofficial].
    - Determine `voxelCoord` based on the dominant direction index (`domInd`):
      - If `domInd == 0`: `(depthCoord, gl_FragCoord.y, res - gl_FragCoord.x)`
      - If `domInd == 1`: `(gl_FragCoord.x, depthCoord, res - gl_FragCoord.y)`
      - If `domInd == 2`: `(gl_FragCoord.x, gl_FragCoord.y, depthCoord)`
      - Where `depthCoord = gl_FragCoord.z * res` and `res` is the voxel resolution [S2, unofficial].

2.  **Lighting and Material Computation:**
    - Compute diffuse color from texture/material:
      $$ \text{diffColor} = \text{texture}(\text{diffuseTex}, \text{vec2}(\text{In.uv.x}, 1.0 - \text{In.uv.y})) $$
      If no texture, use `material.diffuseColor`.
    - Compute lighting per fragment:
      - Loop over `num_lights = min(point_light_count, MAX_POINT_LIGHTS)`.
      - Direction: $\text{dir} = \text{normalize}(\text{light\_pos} - \text{world\_pos})$.
      - Distance: $d = \|\text{light\_pos} - \text{world\_pos}\|$.
      - Attenuation: $a = 1.0 / (1.0 + d \times d)$.
      - Diffuse contribution: $\text{cos\_surf} = \max(\text{dot}(\text{normalize}(\text{normal}), \text{dir}), 0.0)$.
      - Accumulate: $\text{color} += \text{cos\_surf} \times a \times \text{light.color} \times \text{light.intensity}$.
    - Combine with material: $\text{color} = (\text{diffuse} \times \text{color}) + \text{emission}$.
    - Handle transparency: If `illum` is 4, 6, 7, or 9, set `final_trans = transmittance` and `alpha = dissolve`; otherwise `final_trans = vec3(1.0)` and `alpha = 1.0` [S1, unofficial].
    - Clamp and convert: $\text{final\_color} = \text{clamp}(\text{vec4}(\text{final\_trans} \times \text{color}, \text{alpha}), 0, 1)$.

3.  **Shadow Calculation:**
    - Transform light coordinates: $\text{lightCoord} = (\text{shadowCoord.xyz} / 2.0) + 0.5$.
    - Sample shadow map: $\text{shadowDepth} = \text{texture}(\text{shadowMap}, \text{lightCoord.xy}).r$.
    - Calculate bias: $\text{bias} = \text{clamp}(0.005 \times \tan(\arccos(\text{clamp}(\text{dot}(\text{normalize}(\text{exNormal}), \text{normalize}(\text{scene.lightDir})), 0.0, 1.0))), 0.0, 0.01)$.
    - If $\text{shadowDepth} > \text{lightCoord.z} - \text{bias}$ AND $\text{dot}(\text{lightDir}, \text{normal}) > 0.0$, set `data.light = 0x8` [S2, unofficial].

4.  **Atomic Accumulation (Moving Average):**
    - Pack `final_color` into RGBA8 bytes.
    - Initialize sample counter $n=1$.
    - Loop with `imageAtomicCompSwap` (max 16 iterations, or `MAX_NUM_AVG_ITERATIONS` = 100) [S3, S4, unofficial]:
      - Call `imageAtomicCompSwap(tex3D, voxel_pos, current_val, new_val)`.
      - If successful (returned `current_val` equals expected old value):
        - Compute new average: $\text{rval} = (\text{rval} \times n + \text{val}) / ++n$.
        - Round to even: $\text{rval} = \text{round}(\text{rval} / 2) \times 2$.
        - Repack and store.
      - If failed (value changed):
        - Reload previous value.
        - Retry loop.
    - This resolves flickering caused by multiple primitives overwriting the same voxel [S4, unofficial].

5.  **Sparse List Update:**
    - If the voxel was empty (`prevData == 0`):
      - Atomically add 1 to `drawCmd[0].instanceCount`.
      - Calculate `nextIndex` from the atomic add result.
      - Pack `voxelCoord` using `packRG11B10` and store in `sparseList[nextIndex + drawCmd[0].baseInstance]`.
      - Update compute work group sizes if necessary [S2, unofficial].

**Pseudocode:**

```python
# Pseudocode for Fragment Shader Main Function
# Assumes access to: scene, material, shadowMap, voxelTextures, sparseList, drawCmd

def main():
    # 1. Initialize VoxelData
    # GetColor() returns diffuse color or texture sample
    color_data = GetColor()
    data = VoxelData(color=color_data, light=0x0, count=0x8)
    
    # 2. Calculate Voxel Coordinates
    res = float(scene.voxelRes)
    depth_coord = gl_FragCoord.z * res
    
    if scene.domInd == 0:
        voxel_coord = ivec3(depth_coord, gl_FragCoord.y, res - gl_FragCoord.x)
    elif scene.domInd == 1:
        voxel_coord = ivec3(gl_FragCoord.x, depth_coord, res - gl_FragCoord.y)
    else:
        voxel_coord = ivec3(gl_FragCoord.x, gl_FragCoord.y, depth_coord)
        
    # Clamp to prevent out-of-bounds access
    voxel_coord = clamp(voxel_coord, ivec3(0), ivec3(res - 1))

    # 3. Compute Lighting
    final_color = vec4(0.0)
    num_lights = min(scene.point_light_count, 10) # MAX_POINT_LIGHTS
    
    for i in range(num_lights):
        light = scene.point_lights[i]
        dir = normalize(light.position - world_pos)
        d = length(light.position - world_pos)
        a = 1.0 / (1.0 + d * d)
        cos_surf = max(dot(normalize(normal), dir), 0.0)
        final_color.rgb += cos_surf * a * light.color * light.intensity
        
    # Combine with material
    final_color.rgb = (material.diffuse * final_color.rgb) + material.emission
    
    # Handle transparency
    if material.illum in [4, 6, 7, 9]:
        final_color.rgb = material.transmittance * final_color.rgb
        final_color.a = material.dissolve
    else:
        final_color.rgb = vec3(1.0)
        final_color.a = 1.0
        
    final_color = clamp(final_color, 0.0, 1.0)

    # 4. Shadow Calculation
    light_coord = shadow_coord.xyz / 2.0 + 0.5
    shadow_depth = texture(shadowMap, light_coord.xy).r
    cos_theta = clamp(dot(normalize(ex_normal), normalize(scene.light_dir)), 0.0, 1.0)
    bias = clamp(0.005 * tan(acos(cos_theta)), 0.0, 0.01)
    
    if shadow_depth > light_coord.z - bias and dot(normalize(scene.light_dir), normalize(ex_normal)) > 0.0:
        data.light = 0x8

    # 5. Atomic Average Accumulation
    # Pack initial value for comparison
    out_data = packARGB8(data, final_color)
    
    # Loop for atomic average
    prev_data = 0
    n = 1
    for iter in range(16): # Max iterations
        # imageAtomicCompSwap returns the previous value
        prev_data = imageAtomicCompSwap(voxelTextures, voxel_coord, prev_data, out_data)
        
        if prev_data == out_data:
            # Success: value didn't change, we wrote our average
            break
        else:
            # Conflict: reload, re-average, retry
            # Decode prev_data to get current average and count
            curr_val = unpackARGB8(prev_data)
            # Re-average with new sample
            # Note: Simplified logic; real implementation requires careful unpacking/packing
            # rval = (rval * n + val) / ++n
            # Repack and update out_data
            out_data = packARGB8(data, re_average(curr_val, final_color))
            n += 1
            
    # 6. Sparse List Update if voxel was new
    if prev_data == 0:
        next_index = atomicAdd(drawCmd[0].instanceCount, 1)
        sparseList[next_index + drawCmd[0].baseInstance] = packRG11B10(uvec3(voxel_coord))

def packARGB8(data, color):
    # light: 4 bits, count: 4 bits, color: 8 bits per channel
    r = uint(color.r * 31.0 * data.count) & 0xFF
    g = uint(color.g * 31.0 * data.count) & 0xFF
    b = uint(color.b * 31.0 * data.count) & 0xFF
    return (data.light & 0x0F) << 28 | (data.count & 0x0F) << 24 | r << 16 | g << 8 | b

def packRG11B10(coord):
    return (coord.r & 0x7FF) << 21 | (coord.g & 0x7FF) << 10 | (coord.b & 0x3FF)
```

## Subtopics

### [GPU Voxelization with Lighting Accumulation](2925-gpu-voxelization-with-lighting-accumulation.md)
A variant that calculates direct light per fragment and stores it directly into a sparse 3D texture, approximating only indirect diffuse lighting, using hardware conservative rasterization and geometry shader projection to resolve overlaps and gaps, rather than using compute-shader-based atomic operations to resolve race conditions and compute moving averages.

## Operating characteristics
- **Time Complexity:** $O(N \times I)$, where $N$ is the number of fragments and $I$ is the average number of iterations in the atomic average loop. Contention increases $I$.
- **Memory Complexity:** $O(V)$ for the 3D texture, where $V$ is the voxel grid volume. Sparse list adds $O(O)$ where $O$ is the number of occupied voxels.
- **Performance:** The atomic average loop can be expensive under high contention (many fragments hitting the same voxel). However, it produces flicker-free results compared to simple overwriting [S4, unofficial].
- **Strengths:** Resolves flickering from multiple primitives overwriting the same voxel. Works with standard fragment shaders.
- **Limitations:** No atomic operations for floats in OpenGL, limiting HDR voxel storage to integer formats (RGBA8) or requiring software emulation [S4, unofficial]. High contention can lead to shader execution stalls.
- **When to use:** When flicker-free voxelization is required and the scene has significant overlap or transparency.
- **When not to use:** When HDR voxel storage is critical and atomic float operations are not available, or when performance is paramount and flicker is acceptable.

## Background
Originating from voxel cone tracing techniques, this method was developed to address the flickering artifacts inherent in simple rasterization-based voxelization where multiple triangles map to the same voxel [S4, unofficial]. It leverages OpenGL's image atomic operations (`imageAtomicCompSwap`) to implement a moving average, a technique adapted from GPU computing to the fragment shader stage [S1, S2, S3, unofficial].
