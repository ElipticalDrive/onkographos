# GPU Mesh Voxelization via AABB-Triangle Intersection

Also called: GPU Voxelizer, VoxelizeMesh

## Overview
A GPU-based brute-force method to convert a triangle mesh into a set of voxel points by dispatching one compute thread per grid cell and testing each cell's Axis-Aligned Bounding Box (AABB) against all mesh triangles [S1, unofficial]. It differs from [Geometry Shader Voxelization](2566-geometry-shader-voxelization.md) by using a compute shader with explicit AABB-triangle intersection tests rather than rasterization, and from [GPU Mesh Voxelization via Axis-Aligned Projection](2561-gpu-mesh-voxelization-via-axis-aligned-projection.md) by iterating all triangles per voxel rather than projecting triangles into grid slices [S1, unofficial].

## How it works
**Inputs and Outputs**
*   **Input Mesh**: Defined by vertex positions and triangle indices [S1, unofficial].
*   **Grid Parameters**: Voxel half-size ($\text{halfSize}$), mesh bounding box extents, and minimum corner [S1, unofficial].
*   **Output**: A structured buffer of `float4` values representing voxel corners and occupancy status [S1, unofficial].

**Data Structures**
*   `_MeshVertices`: `StructuredBuffer<float3>`. Contains vertex positions of the input mesh [S1, unofficial].
*   `_MeshTriangleIndices`: `StructuredBuffer<int>`. Contains triangle indices (3 ints per triangle) referencing `_MeshVertices` [S1, unofficial].
*   `_VoxelGridPoints`: `RWStructuredBuffer<float4>`. Stores output voxel data. Layout: $x, y, z$ are the world position of the voxel corner, $w$ is $1.0$ if intersected, $0.0$ otherwise [S1, unofficial].
*   **Grid Dimensions**:
    *   $\text{xGridSize} = \lceil \text{bounds.extents.x} / \text{halfSize} \rceil$ [S1, unofficial].
    *   $\text{yGridSize} = \lceil \text{bounds.extents.y} / \text{halfSize} \rceil$ [S1, unofficial].
    *   $\text{zGridSize} = \lceil \text{bounds.extents.z} / \text{halfSize} \rceil$ [S1, unofficial].

**Parameters**
*   `_halfSize`: The half-extent of each voxel cell (radius). Typical value: $0.05f$ [S1, unofficial].
*   `_GridWidth`, `_GridHeight`, `_GridDepth`: Integer dimensions of the voxel grid, calculated as $\lceil \text{bounds.extents} / \text{halfSize} \rceil$ [S1, unofficial].
*   `_TriangleCount`: Total number of indices in the mesh buffer (3 indices per triangle) [S1, unofficial].
*   `_BoundsMin`: The minimum corner of the mesh bounding box in local space [S1, unofficial].

**Algorithm Steps**
1.  **Calculate Grid Dimensions**: Compute $\text{xGridSize}$, $\text{yGridSize}$, and $\text{zGridSize}$ based on mesh bounds and `_halfSize` [S1, unofficial].
2.  **Dispatch Compute Shader**: Launch a compute kernel with thread groups sized to cover the grid. Group size is $[4, 4, 4]$. Number of groups: [S1, unofficial]
    *   $\text{numGroupsX} = \lceil \text{xGridSize} / 4 \rceil$ [S1, unofficial].
    *   $\text{numGroupsY} = \lceil \text{yGridSize} / 4 \rceil$ [S1, unofficial].
    *   $\text{numGroupsZ} = \lceil \text{zGridSize} / 4 \rceil$ [S1, unofficial].
3.  **Thread Execution**: For each thread with ID $(id.x, id.y, id.z)$ within grid bounds:
    a.  Calculate the voxel AABB center:
        $$ \text{centerPos} = (\text{id.x} \cdot \text{cellSize} + \text{halfSize} + \text{BoundsMin}.x, \quad \text{id.y} \cdot \text{cellSize} + \text{halfSize} + \text{BoundsMin}.y, \quad \text{id.z} \cdot \text{cellSize} + \text{halfSize} + \text{BoundsMin}.z) $$
        where $\text{cellSize} = 2 \cdot \text{halfSize}$ [S1, unofficial].
    b.  Define the voxel AABB: $\text{center} = \text{centerPos}$, $\text{extents} = (\text{halfSize}, \text{halfSize}, \text{halfSize})$ [S1, unofficial].
    c.  Initialize `intersects = false` [G].
    d.  Iterate through all triangles in the mesh buffer (loop $i$ from $0$ to $\text{TriangleCount}$ with step $3$). For each triangle, extract vertices $a, b, c$ from `_MeshVertices` using indices from `_MeshTriangleIndices` [S1, unofficial].
    e.  Test intersection between the voxel AABB and the triangle using the Separating Axis Theorem (SAT). If intersection is found, set `intersects = true` and break the loop [S1, unofficial].
    f.  Write result to `_VoxelGridPoints` at index $(id.x + \text{GridWidth} \cdot (id.y + \text{GridHeight} \cdot id.z))$. Value is $\text{float4}(\text{cornerX}, \text{cornerY}, \text{cornerZ}, \text{intersects} ? 1.0 : 0.0)$, where corner coordinates are $\text{BoundsMin} + \text{id} \cdot \text{cellSize}$ [S1, unofficial].

**Intersection Test (SAT)**
The intersection test checks 15 separating axes: 3 cross products of edges with X/Y/Z axes (9 axes), the 3 X/Y/Z axes themselves, and the triangle's normal (cross(ab, bc)) [S1, unofficial].

The helper function `IntersectsTriangleAabbSat` projects the triangle vertices and AABB onto an axis:
$$ p_0 = \mathbf{v}_0 \cdot \mathbf{axis}, \quad p_1 = \mathbf{v}_1 \cdot \mathbf{axis}, \quad p_2 = \mathbf{v}_2 \cdot \mathbf{axis} $$
$$ r = \text{aabbExtents}.x \cdot |\mathbf{axis} \cdot (1,0,0)| + \text{aabbExtents}.y \cdot |\mathbf{axis} \cdot (0,1,0)| + \text{aabbExtents}.z \cdot |\mathbf{axis} \cdot (0,0,1)| $$
$$ \text{maxP} = \max(p_0, \max(p_1, p_2)), \quad \text{minP} = \min(p_0, \min(p_1, p_2)) $$
Return true if $\max(-\text{maxP}, \text{minP}) \le r$ [S1, unofficial].

The main function `IntersectsTriangleAabb` normalizes edge vectors $\mathbf{ab}, \mathbf{bc}, \mathbf{ca}$, shifts the triangle relative to the AABB center, and checks all 15 axes [S1, unofficial].

**Pseudocode**
```python
# Global buffers and parameters (bound by compute shader)
_MeshVertices: list[float3]
_MeshTriangleIndices: list[int]
_VoxelGridPoints: list[float4]
_TriangleCount: int
_BoundsMin: float3
_CellHalfSize: float
_GridWidth: int
_GridHeight: int
_GridDepth: int

class float3:
    x: float
    y: float
    z: float
    def __add__(self, other): return float3(self.x + other.x, self.y + other.y, self.z + other.z)
    def __sub__(self, other): return float3(self.x - other.x, self.y - other.y, self.z - other.z)
    def __mul__(self, s): return float3(self.x * s, self.y * s, self.z * s)
    def dot(self, other): return self.x * other.x + self.y * other.y + self.z * other.z
    def cross(self, other): return float3(self.y * other.z - self.z * other.y, self.z * other.x - self.x * other.z, self.x * other.y - self.y * other.x)
    def abs(self): return float3(abs(self.x), abs(self.y), abs(self.z))

class float4:
    x: float
    y: float
    z: float
    w: float

class AABB:
    center: float3
    extents: float3

class Triangle:
    a: float3
    b: float3
    c: float3

def normalize(v: float3) -> float3:
    length = (v.dot(v)) ** 0.5
    return float3(v.x / length, v.y / length, v.z / length)

def VoxelizeMesh(id: int3):
    # id is SV_DispatchThreadID (uint3 in HLSL)
    if id.x >= _GridWidth or id.y >= _GridHeight or id.z >= _GridDepth:
        return

    cell_size = _CellHalfSize * 2.0
    
    # Calculate voxel AABB center and corner
    center_pos = float3(
        id.x * cell_size + _CellHalfSize + _BoundsMin.x,
        id.y * cell_size + _CellHalfSize + _BoundsMin.y,
        id.z * cell_size + _CellHalfSize + _BoundsMin.z
    )
    
    voxel_aabb = AABB(center=center_pos, extents=float3(_CellHalfSize, _CellHalfSize, _CellHalfSize))
    corner = float3(_BoundsMin.x + id.x * cell_size, _BoundsMin.y + id.y * cell_size, _BoundsMin.z + id.z * cell_size)
    
    intersects = False
    
    # Iterate through all triangles
    # _TriangleCount is the total number of indices (3 per triangle)
    for i in range(0, _TriangleCount, 3):
        idx_a = _MeshTriangleIndices[i]
        idx_b = _MeshTriangleIndices[i+1]
        idx_c = _MeshTriangleIndices[i+2]
        
        tri = Triangle(
            a=_MeshVertices[idx_a],
            b=_MeshVertices[idx_b],
            c=_MeshVertices[idx_c]
        )
        
        if IntersectsTriangleAabb(tri, voxel_aabb):
            intersects = True
            break
            
    # Write result
    index = id.x + _GridWidth * (id.y + _GridHeight * id.z)
    _VoxelGridPoints[index] = float4(corner.x, corner.y, corner.z, 1.0 if intersects else 0.0)

def IntersectsTriangleAabb(tri: Triangle, aabb: AABB) -> bool:
    # Shift triangle vertices relative to AABB center
    a = float3(tri.a.x - aabb.center.x, tri.a.y - aabb.center.y, tri.a.z - aabb.center.z)
    b = float3(tri.b.x - aabb.center.x, tri.b.y - aabb.center.y, tri.b.z - aabb.center.z)
    c = float3(tri.c.x - aabb.center.x, tri.c.y - aabb.center.y, tri.c.z - aabb.center.z)
    
    # Edge vectors
    ab = normalize(float3(b.x - a.x, b.y - a.y, b.z - a.z))
    bc = normalize(float3(c.x - b.x, c.y - b.y, c.z - b.z))
    ca = normalize(float3(a.x - c.x, a.y - c.y, a.z - c.z))
    
    # Generate 15 separating axes
    axes = []
    
    # Cross products of edges with X, Y, Z axes
    axes.append(float3(0.0, -ab.z, ab.y))
    axes.append(float3(0.0, -bc.z, bc.y))
    axes.append(float3(0.0, -ca.z, ca.y))
    axes.append(float3(ab.z, 0.0, -ab.x))
    axes.append(float3(bc.z, 0.0, -bc.x))
    axes.append(float3(ca.z, 0.0, -ca.x))
    axes.append(float3(-ab.y, ab.x, 0.0))
    axes.append(float3(-bc.y, bc.x, 0.0))
    axes.append(float3(-ca.y, ca.x, 0.0))
    
    # X, Y, Z axes
    axes.append(float3(1, 0, 0))
    axes.append(float3(0, 1, 0))
    axes.append(float3(0, 0, 1))
    
    # Triangle normal
    axes.append(ab.cross(bc))
    
    # Check separation on each axis
    for axis in axes:
        if IsSeparated(a, b, c, aabb.extents, axis):
            return False
            
    return True

def IsSeparated(v0: float3, v1: float3, v2: float3, aabb_extents: float3, axis: float3) -> bool:
    p0 = v0.dot(axis)
    p1 = v1.dot(axis)
    p2 = v2.dot(axis)
    
    max_p = max(p0, max(p1, p2))
    min_p = min(p0, min(p1, p2))
    
    # Project AABB extents onto axis
    r = (aabb_extents.x * abs(axis.x) +
         aabb_extents.y * abs(axis.y) +
         aabb_extents.z * abs(axis.z))
         
    # Separating axis if the triangle's projection interval [min_p, max_p]
    # does not overlap with the AABB's projection interval [-r, r]
    if max(-max_p, min_p) > r:
        return True
        
    return False
```

**Edge Cases and Pitfalls**
*   **Degenerate Triangles**: The SAT implementation normalizes edge vectors ($\mathbf{ab}, \mathbf{bc}, \mathbf{ca}$). If a triangle has zero area (degenerate), normalization may produce NaNs or infinities, potentially causing incorrect intersection results or GPU errors [S1, unofficial].
*   **Missing Axes**: The intersection test checks 15 separating axes. Missing any axis can lead to false positives [S1, unofficial].

## Operating characteristics
*   **Time Complexity**: $O(N_{\text{cells}} \cdot N_{\text{triangles}})$ per voxelization pass, where $N_{\text{cells}}$ is the number of voxels and $N_{\text{triangles}}$ is the number of triangles in the mesh. This is brute-force and does not use spatial acceleration structures [S1, unofficial].
*   **Memory Complexity**: $O(N_{\text{cells}})$ for the output grid, plus $O(N_{\text{vertices}} + N_{\text{indices}})$ for the input mesh buffers [G].
*   **Strengths**: Simple implementation; no complex spatial data structures required; parallelizable across voxels [G].
*   **Limitations**: Performance degrades linearly with mesh complexity and grid resolution; unsuitable for very high-poly meshes or large grids without optimization [G].

## Background
This method is implemented as part of the "UnityGpuMeshVoxelizer" project by bzgeb, designed for use in Unity [S1, unofficial]. It provides a GPU-accelerated alternative to CPU-based voxelization, leveraging compute shaders for parallel processing [S1, unofficial].
