# NGLE Triangle Voxelization

Also called: N-gle

## Overview
NGLE Triangle Voxelization is a rasterization-based algorithm that converts a triangle mesh into a sparse voxel DAG by classifying each triangle's axis-aligned bounding box (AABB) thickness into nine cases (1D, 2D, or 3D) and applying optimized plane and projection tests to determine intersected grid cells [S1, unofficial]. It distinguishes itself from general 3D clipping methods by reducing the intersection test to 2D edge tests along the dominant normal axis for thin bounding boxes, thereby optimizing column casting for sparse storage [S1, unofficial][S2].

## How it works
**Inputs:**
- Triangle vertices $v_0, v_1, v_2$ in world space.
- `unitlength`: The side length of a voxel in world units [S1, unofficial].
- `morton_start`, `morton_end`: The range of Morton codes allocated for the partition [S1, unofficial].
- `voxels`: A boolean array (for binary voxelization) or a size_t array with a parallel `vector<VoxelData>` (for data-rich voxelization) [S1, unofficial].

**Outputs:**
- Marked voxels in the sparse grid corresponding to the triangle's intersection.
- Optional voxel data (normal, average color) stored in `voxel_data` [S1, unofficial].

**Data Structures:**
- `VoxelData`: Contains `normal` (vec3) and `color` (vec3, computed as the average of the triangle's vertex colors) [S1, unofficial].
- Grid coordinates are integers derived from world coordinates by multiplying by `1.0f/unitlength` and casting to `int` [S1, unofficial].

**Steps:**

1. **Initialize Voxel Array:**
   Clear the voxel array for the range `[morton_start, morton_end)` to `EMPTY_VOXEL` [S1, unofficial].

2. **Compute Partition Bounding Box:**
   Decode `morton_start` and `morton_end - 1` into grid coordinates to determine `p_bbox_grid.min` and `p_bbox_grid.max` [S1, unofficial].

3. **Compute Triangle Grid Bounding Box:**
   - Compute the world-space AABB of the triangle, $t\_bbox\_world$.
   - Convert to grid coordinates: $t\_bbox\_grid = \text{cast\_int}(t\_bbox\_world \times \frac{1.0}{\text{unitlength}})$ [S1, unofficial].
   - Clamp $t\_bbox\_grid$ to `p_bbox_grid` to stay within the partition [S1, unofficial].

4. **Determine Bounding Box Thickness:**
   Compute a boolean vector `one_thick` where `one_thick[axis]` is 1 if $t\_bbox\_grid.min[axis] == t\_bbox\_grid.max[axis]$, and 0 otherwise [S1, unofficial].

5. **Compute Triangle Geometry:**
   - Edges: $e_0 = v_1 - v_0$, $e_1 = v_2 - v_1$, $e_2 = v_0 - v_2$ [S1, unofficial].
   - Normal: $n = \text{normalize}(e_0 \times e_1)$ [S1, unofficial].

6. **Handle 2D Bounding Box Cases (Cases 4-6):**
   If `one_thick.sum() == 1`, the triangle is thin in one dimension. Identify the dominant axis (where `one_thick` is 1) and perform a 2D projection test on the plane perpendicular to it [S1, unofficial].

   - **Case 4 (Thin in X, Thick in Y, Z):**
     - Project onto YZ plane.
     - Compute edge normals in 2D: $n_{yz\_e0} = (-e_0[Z], e_0[Y])$, etc. [S1, unofficial].
     - If $n[X] < 0$, negate all $n_{yz\_ei}$ [S1, unofficial].
     - Compute offsets: $d_{yz\_ei} = -1.0 \cdot (n_{yz\_ei} \cdot \text{vec2}(v_i[Y], v_i[Z])) + \max(0.0, \text{unitlength} \cdot n_{yz\_ei}[0]) + \max(0.0, \text{unitlength} \cdot n_{yz\_ei}[1])$ [S1, unofficial].
     - Iterate $y, z$ in $t\_bbox\_grid$. Fixed $x = t\_bbox\_grid.min[X]$.
     - For a point $p_{yz} = (y, z)$, if $(n_{yz\_ei} \cdot p_{yz} + d_{yz\_ei}) < 0$ for all $i \in \{0,1,2\}$, skip. Otherwise, mark voxel [S1, unofficial].

   - **Case 5 (Thin in Y, Thick in X, Z):**
     - Project onto ZX plane.
     - Compute edge normals: $n_{zx\_e0} = (-e_0[X], e_0[Z])$, etc. [S1, unofficial].
     - If $n[Y] < 0$, negate all $n_{zx\_ei}$ [S1, unofficial].
     - Compute offsets $d_{zx\_ei}$ similarly.
     - Iterate $z, x$ in $t\_bbox\_grid$. Fixed $y = t\_bbox\_grid.min[Y]$.
     - Skip if projection test fails for all edges [S1, unofficial].

   - **Case 6 (Thin in Z, Thick in X, Y):**
     - Project onto XY plane.
     - Compute edge normals: $n_{xy\_e0} = (-e_0[Y], e_0[X])$, etc. [S1, unofficial].
     - If $n[Z] < 0$, negate all $n_{xy\_ei}$ [S1, unofficial].
     - Compute offsets $d_{xy\_ei}$ similarly.
     - Iterate $x, y$ in $t\_bbox\_grid$. Fixed $z = t\_bbox\_grid.min[Z]$.
     - Skip if projection test fails for all edges [S1, unofficial].

7. **Handle 3D Bounding Box Cases (Cases 7-9):**
   If `one_thick.sum() == 0`, the triangle spans multiple voxels in all dimensions. Determine the dominant axis of $n$ (axis with largest absolute component) [S1, unofficial].
   - Compute critical point $c$: $c[axis] = \text{unitlength}$ if $n[axis] > 0$, else $0$ [S1, unofficial].
   - Compute plane distances: $d_1 = n \cdot (c - v_0)$ and $d_2 = n \cdot ((\Delta p - c) - v_0)$, where $\Delta p = (\text{unitlength}, \text{unitlength}, \text{unitlength})$ [S1, unofficial].
   - Setup projection tests for all three planes (XY, YZ, ZX) as in Cases 4-6 [S1, unofficial].
   - Iterate $x, y, z$ in $t\_bbox\_grid$.
   - **Plane Test:** If $(n \cdot p + d_1) \cdot (n \cdot p + d_2) > 0.0$, skip. This checks if the voxel center is entirely on one side of the triangle plane [S1, unofficial].
   - **Projection Tests:** If any of the three 2D projection tests fails, skip [S1, unofficial].
   - Otherwise, mark voxel [S1, unofficial].

**Pseudocode:**

```python
def ngle_voxelize(triangle, unitlength, morton_start, morton_end, voxels, voxel_data=None):
    # 1. Initialize
    # Clear voxels for range [morton_start, morton_end)
    for i in range(morton_start, morton_end):
        voxels[i] = False
        if voxel_data is not None:
            voxel_data[i] = None

    # 2. Partition Bounding Box
    p_min = decode_morton(morton_start)
    p_max = decode_morton(morton_end - 1)
    p_bbox_grid = GridBox(p_min, p_max)

    # 3. Triangle Grid Bounding Box
    t_bbox_world = compute_world_bbox(triangle.v0, triangle.v1, triangle.v2)
    t_bbox_grid = clamp(
        cast_int(t_bbox_world * (1.0 / unitlength)),
        p_bbox_grid.min,
        p_bbox_grid.max
    )

    # 4. Thickness
    one_thick = [
        1 if t_bbox_grid.min[i] == t_bbox_grid.max[i] else 0
        for i in range(3)
    ]
    thickness_sum = sum(one_thick)

    # 5. Geometry
    e0 = triangle.v1 - triangle.v0
    e1 = triangle.v2 - triangle.v1
    e2 = triangle.v0 - triangle.v2
    n = normalize(cross(e0, e1))

    if thickness_sum == 1:
        # Cases 4-6: 2D Projection
        dominant_axis = one_thick.index(1)
        if dominant_axis == 0: # Case 4: Thin X, Project YZ
            process_2d_projection(triangle, e0, e1, e2, n, unitlength, 
                                  t_bbox_grid, fixed_axis=0, fixed_val=t_bbox_grid.min[0],
                                  axes=(1, 2), voxels, voxel_data)
        elif dominant_axis == 1: # Case 5: Thin Y, Project ZX
            process_2d_projection(triangle, e0, e1, e2, n, unitlength,
                                  t_bbox_grid, fixed_axis=1, fixed_val=t_bbox_grid.min[1],
                                  axes=(2, 0), voxels, voxel_data)
        else: # Case 6: Thin Z, Project XY
            process_2d_projection(triangle, e0, e1, e2, n, unitlength,
                                  t_bbox_grid, fixed_axis=2, fixed_val=t_bbox_grid.min[2],
                                  axes=(0, 1), voxels, voxel_data)
    else:
        # Cases 7-9: 3D Bounding Box
        # Determine dominant axis of normal
        abs_n = [abs(n[i]) for i in range(3)]
        dominant_normal_axis = abs_n.index(max(abs_n))
        
        c = [0.0, 0.0, 0.0]
        c[dominant_normal_axis] = unitlength if n[dominant_normal_axis] > 0 else 0.0
        
        delta_p = [unitlength, unitlength, unitlength]
        d1 = dot(n, [c[i] - triangle.v0[i] for i in range(3)])
        d2 = dot(n, [(delta_p[i] - c[i]) - triangle.v0[i] for i in range(3)])

        # Precompute 2D projection params for all 3 planes
        proj_xy = compute_2d_params(triangle, e0, e1, e2, n, unitlength, axis=2)
        proj_yz = compute_2d_params(triangle, e0, e1, e2, n, unitlength, axis=0)
        proj_zx = compute_2d_params(triangle, e0, e1, e2, n, unitlength, axis=1)

        for z in range(t_bbox_grid.min[2], t_bbox_grid.max[2] + 1):
            for y in range(t_bbox_grid.min[1], t_bbox_grid.max[1] + 1):
                for x in range(t_bbox_grid.min[0], t_bbox_grid.max[0] + 1):
                    p = [x, y, z]
                    
                    # Plane Test
                    n_dot_p = dot(n, p)
                    if (n_dot_p + d1) * (n_dot_p + d2) > 0.0:
                        continue
                    
                    # Projection Tests
                    if not is_inside_2d(p, proj_xy, axes=(0, 1)):
                        continue
                    if not is_inside_2d(p, proj_yz, axes=(1, 2)):
                        continue
                    if not is_inside_2d(p, proj_zx, axes=(2, 0)):
                        continue
                    
                    # Mark Voxel
                    morton = encode_morton(p)
                    voxels[morton] = True
                    if voxel_data is not None:
                        voxel_data[morton] = VoxelData(normal=n, color=average_color(triangle))

def process_2d_projection(triangle, e0, e1, e2, n, unitlength, t_bbox_grid, fixed_axis, fixed_val, axes, voxels, voxel_data):
    # axes is a tuple of the two active axes, e.g., (1, 2) for YZ
    axis0, axis1 = axes
    
    # Compute 2D edge normals
    # For plane perpendicular to fixed_axis, edge e = (ex, ey, ez)
    # 2D normal in (axis0, axis1) plane: (-e[axis1], e[axis0])
    edges = [e0, e1, e2]
    n_2d = []
    for e in edges:
        n_2d.append([-e[axis1], e[axis0]])
    
    # Flip if normal points away
    if n[fixed_axis] < 0:
        n_2d = [[-v for v in vec] for vec in n_2d]
        
    # Compute d values
    d_2d = []
    for i, e in enumerate(edges):
        # p_2d is (v[axis0], v[axis1])
        p_2d = [triangle.v0[axis0], triangle.v0[axis1]] # Using v0 as reference for d calculation logic from source
        # Source formula: d = -1.0 * (n_2d_ei . vec2(vi[axis0], vi[axis1])) + max(0, unitlength*n_2d_ei[0]) + max(0, unitlength*n_2d_ei[1])
        # Note: The source uses vi for each edge. We must iterate vertices.
        pass 

    # Re-implementing the loop structure from source notes for clarity
    # We need to iterate vertices to get correct d for each edge
    verts = [triangle.v0, triangle.v1, triangle.v2]
    n_2d_final = []
    d_2d_final = []
    
    for i in range(3):
        e = edges[i]
        v = verts[i]
        nx = -e[axis1]
        ny = e[axis0]
        
        if n[fixed_axis] < 0:
            nx = -nx
            ny = -ny
            
        n_2d_final.append([nx, ny])
        
        # d calculation
        term1 = -1.0 * (nx * v[axis0] + ny * v[axis1])
        term2 = max(0.0, unitlength * nx)
        term3 = max(0.0, unitlength * ny)
        d_2d_final.append(term1 + term2 + term3)

    # Iterate grid
    for a0 in range(t_bbox_grid.min[axis0], t_bbox_grid.max[axis0] + 1):
        for a1 in range(t_bbox_grid.min[axis1], t_bbox_grid.max[axis1] + 1):
            p_2d = [a0, a1]
            inside = False
            for j in range(3):
                val = n_2d_final[j][0] * p_2d[0] + n_2d_final[j][1] * p_2d[1] + d_2d_final[j]
                if val >= 0.0:
                    inside = True
                    break
            
            if inside:
                p = [0, 0, 0]
                p[axis0] = a0
                p[axis1] = a1
                p[fixed_axis] = fixed_val
                morton = encode_morton(p)
                voxels[morton] = True
                if voxel_data is not None:
                    voxel_data[morton] = VoxelData(normal=n, color=average_color(triangle))

def compute_2d_params(triangle, e0, e1, e2, n, unitlength, axis):
    # Helper to precompute 2D params for a specific projection axis
    # axis is the normal axis (0=X, 1=Y, 2=Z)
    if axis == 0: # YZ plane
        axes = (1, 2)
    elif axis == 1: # ZX plane
        axes = (2, 0)
    else: # XY plane
        axes = (0, 1)
        
    axis0, axis1 = axes
    edges = [e0, e1, e2]
    verts = [triangle.v0, triangle.v1, triangle.v2]
    
    n_2d = []
    d_2d = []
    
    for i in range(3):
        e = edges[i]
        v = verts[i]
        nx = -e[axis1]
        ny = e[axis0]
        
        if n[axis] < 0:
            nx = -nx
            ny = -ny
            
        n_2d.append([nx, ny])
        
        term1 = -1.0 * (nx * v[axis0] + ny * v[axis1])
        term2 = max(0.0, unitlength * nx)
        term3 = max(0.0, unitlength * ny)
        d_2d.append(term1 + term2 + term3)
        
    return {'n_2d': n_2d, 'd_2d': d_2d, 'axes': axes}

def is_inside_2d(p, proj, axes):
    axis0, axis1 = axes
    p_2d = [p[axis0], p[axis1]]
    for j in range(3):
        val = proj['n_2d'][j][0] * p_2d[0] + proj['n_2d'][j][1] * p_2d[1] + proj['d_2d'][j]
        if val >= 0.0:
            return True
    return False
```

## Subtopics

### Triangle-to-Grid Insertion
A simpler variant that determines overlapped cells by bounding box overlap and adds a triangle reference to each [S2]. It is less accurate than NGLE but significantly faster, as the exact triangle-in-box test reduces references by only a few percent after mailboxing while increasing rebuild cost [S2]. It is suitable for scenes without dominantly long, skinny, diagonal triangles [S2].

## Operating characteristics
- **Time Complexity:** Linear with respect to the number of voxels in the triangle's bounding box, with constant-time per-voxel tests.
- **Memory Complexity:** Proportional to the number of intersected voxels.
- **Strengths:** Optimized for sparse storage via Morton codes; handles 2D cases efficiently by reducing dimensionality; robust for general triangle orientations.
- **Limitations:** Conservative for 2D cases (may include voxels slightly outside the triangle if not careful with edge cases, though the projection test is exact for the grid cells); 3D cases require more tests.
- **When to use:** When building a sparse voxel DAG for ray tracing or volume rendering where performance is critical and the scene contains varied triangle orientations.
- **When not to use:** For scenes with very long, skinny, diagonal triangles where bounding box overlap is highly inaccurate and exact tests might be justified [S2].

## Background
NGLE Triangle Voxelization is part of the Sparse Voxel DAG (SVO) builder implementation found in the INF584 High Resolution Sparse Voxel DAGs project [S1, unofficial]. It builds on the concept of adaptive sparse voxelization with bounding box thickness cases [1686-adaptive-sparse-voxelization-with-bounding-box-thickness-cas]. The method is designed to efficiently rasterize triangles into a sparse grid structure for subsequent ray traversal.
