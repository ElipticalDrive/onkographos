# GPU Mesh Voxelization via AABB-Triangle Intersection

Also called: ComputeVoxelizer, GPU Mesh Voxelization via Triangle-AABB Intersection, GPU Voxelizer, Triangle-to-Voxel Rasterization, VoxelizeMesh

## Overview
This method voxelizes a polygonal mesh by dispatching one compute shader thread per voxel grid cell, which then tests its Axis-Aligned Bounding Box (AABB) against every triangle in the mesh using the Separating Axis Theorem (SAT) [S1, unofficial][S2, unofficial][S3, unofficial]. It differs from [Geometry Shader Voxelization](2566-geometry-shader-voxelization.md) by avoiding the overhead of generating geometry primitives and from [GPU Voxelization Using OpenGL Image Atomics](2544-gpu-voxelization-using-opengl-image-atomics.md) by relying on explicit geometric intersection tests rather than rasterization coverage [S2, unofficial]. It is a brute-force approach that does not use spatial acceleration structures [S2, unofficial].

## How it works
**Inputs and Outputs:**
*   **Input:** A triangle mesh defined by a vertex buffer (`_MeshVertices`) and an index buffer (`_MeshTriangleIndices`), and a 3D voxel grid defined by dimensions `_GridWidth`, `_GridHeight`, `_GridDepth`, cell half-size `_CellHalfSize`, and world-space minimum corner `_BoundsMin` [S1, unofficial][S2, unofficial][S3, unofficial].
*   **Output:** A structured buffer `_Voxels` (or `_VoxelGridPoints`) where each entry corresponds to a voxel, containing its position and a boolean `isSolid` (or `intersects`) flag [S1, unofficial][S2, unofficial].

**Data Structures:**
*   `Triangle`: `float3 a, b, c` (36 bytes) [S1, unofficial][S3, unofficial].
*   `AABB`: `float3 center`, `float3 extents` (24 bytes) [S1, unofficial][S3, unofficial].
*   `Voxel`: `float3 position`, `float isSolid` (16 bytes) [S1, unofficial][S3, unofficial].
*   `_MeshVertices`: `StructuredBuffer<float3>` [S1, unofficial][S2, unofficial].
*   `_MeshTriangleIndices`: `StructuredBuffer<int>` [S1, unofficial][S2, unofficial].
*   `_Voxels`: `RWStructuredBuffer<Voxel>` [S1, unofficial][S3, unofficial].

**Parameters:**
*   `_CellHalfSize`: Half the side length of a voxel. Typical value: 0.05f [S2, unofficial][S3, unofficial].
*   `_WorldToLocalMatrix`: Transforms world-space coordinates to local mesh space for intersection tests [S1, unofficial][S3, unofficial].
*   `_TriangleCount`: Total number of triangle indices in the mesh [S1, unofficial][S3, unofficial].

**Algorithm Steps:**
1.  **Grid Setup:** Calculate grid dimensions from the mesh bounds and `_CellHalfSize`:
    $$xGridSize = \lceil bounds.extents.x / _CellHalfSize \rceil$$
    $$yGridSize = \lceil bounds.extents.y / _CellHalfSize \rceil$$
    $$zGridSize = \lceil bounds.extents.z / _CellHalfSize \rceil$$ [S2, unofficial][S3, unofficial].
2.  **Dispatch:** Dispatch the compute shader with thread groups of size $(4, 4, 4)$ covering the grid:
    $$numGroupsX = \lceil xGridSize / 4 \rceil, \quad numGroupsY = \lceil yGridSize / 4 \rceil, \quad numGroupsZ = \lceil zGridSize / 4 \rceil$$ [S2, unofficial][S3, unofficial].
3.  **Thread Execution:** For each thread with ID $(id.x, id.y, id.z)$:
    a.  **Bounds Check:** If $id.x \ge _GridWidth$ or $id.y \ge _GridHeight$ or $id.z \ge _GridDepth$, return [S1, unofficial][S3, unofficial].
    b.  **Voxel AABB Construction:** Calculate the voxel center in world space:
        $$centerPos = (id.x \cdot cellSize + _CellHalfSize + _BoundsMin.x, \quad id.y \cdot cellSize + _CellHalfSize + _BoundsMin.y, \quad id.z \cdot cellSize + _CellHalfSize + _BoundsMin.z)$$
        where $cellSize = _CellHalfSize \cdot 2.0$ [S1, unofficial][S2, unofficial][S3, unofficial].
        Define the voxel AABB: $aabb.center = centerPos$, $aabb.extents = (_CellHalfSize, _CellHalfSize, _CellHalfSize)$ [S1, unofficial][S2, unofficial][S3, unofficial].
        Transform the AABB center to local mesh space if required by the intersection function: $aabb.center = mul(_WorldToLocalMatrix, centerPos)$ [S3, unofficial].
    c.  **Triangle Intersection Test:** Iterate through all triangles in the mesh (step 3) [S2, unofficial]. For each triangle $T$ with vertices $a, b, c$:
        i.  Test intersection between $T$ and $aabb$ using the Separating Axis Theorem (SAT) [S2, unofficial][S3, unofficial].
        ii. If an intersection is found, set $isSolid = 1.0$ and break the loop [S1, unofficial][S2, unofficial][S3, unofficial].
    d.  **Output:** Calculate the linear voxel index:
        $$voxelIndex = id.x + _GridWidth \cdot (id.y + _GridHeight \cdot id.z)$$ [S1, unofficial][S3, unofficial].
        Store the voxel position and $isSolid$ in `_Voxels[voxelIndex]` [S1, unofficial][S3, unofficial].

**Pseudocode:**
```python
# Compute Shader Kernel: VoxelizeMesh
# Inputs: _MeshVertices, _MeshTriangleIndices, _WorldToLocalMatrix, _TriangleCount, _BoundsMin, _CellHalfSize, _GridWidth, _GridHeight, _GridDepth
# Output: _Voxels (RWStructuredBuffer<Voxel>)

class Vec3:
    def __init__(self, x, y, z):
        self.x, self.y, self.z = x, y, z
    def __sub__(self, o): return Vec3(self.x-o.x, self.y-o.y, self.z-o.z)
    def __isub__(self, o): self.x-=o.x; self.y-=o.y; self.z-=o.z; return self
    def __mul__(self, s): return Vec3(self.x*s, self.y*s, self.z*s)
    def dot(self, o): return self.x*o.x + self.y*o.y + self.z*o.z
    def cross(self, o): return Vec3(self.y*o.z-self.z*o.y, self.z*o.x-self.x*o.z, self.x*o.y-self.y*o.x)
    def normalize(self):
        l = (self.x**2 + self.y**2 + self.z**2)**0.5
        return Vec3(self.x/l, self.y/l, self.z/l) if l > 0 else self

class Triangle:
    def __init__(self, a, b, c): self.a, self.b, self.c = a, b, c

class AABB:
    def __init__(self, center, extents): self.center, self.extents = center, extents

class Voxel:
    def __init__(self, position, isSolid): self.position, self.isSolid = position, isSolid

def VoxelizeMesh(id_x, id_y, id_z):
    if id_x >= _GridWidth or id_y >= _GridHeight or id_z >= _GridDepth:
        return

    cellSize = _CellHalfSize * 2.0
    centerPos = Vec3(
        id_x * cellSize + _CellHalfSize + _BoundsMin.x,
        id_y * cellSize + _CellHalfSize + _BoundsMin.y,
        id_z * cellSize + _CellHalfSize + _BoundsMin.z
    )
    
    aabb = AABB(center=centerPos, extents=Vec3(_CellHalfSize, _CellHalfSize, _CellHalfSize))
    
    intersects = False
    
    for i in range(0, _TriangleCount, 3):
        tri = Triangle(
            a=_MeshVertices[_MeshTriangleIndices[i]],
            b=_MeshVertices[_MeshTriangleIndices[i+1]],
            c=_MeshVertices[_MeshTriangleIndices[i+2]]
        )
        
        if IntersectsTriangleAabb(tri, aabb):
            intersects = True
            break
            
    voxelIndex = id_x + _GridWidth * (id_y + _GridHeight * id_z)
    _Voxels[voxelIndex] = Voxel(position=centerPos, isSolid=1.0 if intersects else 0.0)

def IntersectsTriangleAabb(tri, aabb):
    tri.a -= aabb.center
    tri.b -= aabb.center
    tri.c -= aabb.center
    
    ab = (tri.b - tri.a).normalize()
    bc = (tri.c - tri.b).normalize()
    ca = (tri.a - tri.c).normalize()
    
    axes = []
    axes.append(Vec3(0.0, -ab.z, ab.y))
    axes.append(Vec3(0.0, -bc.z, bc.y))
    axes.append(Vec3(0.0, -ca.z, ca.y))
    axes.append(Vec3(ab.z, 0.0, -ab.x))
    axes.append(Vec3(bc.z, 0.0, -bc.x))
    axes.append(Vec3(ca.z, 0.0, -ca.x))
    axes.append(Vec3(-ab.y, ab.x, 0.0))
    axes.append(Vec3(-bc.y, bc.x, 0.0))
    axes.append(Vec3(-ca.y, ca.x, 0.0))
    axes.append(Vec3(1, 0, 0))
    axes.append(Vec3(0, 1, 0))
    axes.append(Vec3(0, 0, 1))
    axes.append(ab.cross(bc))
    
    for axis in axes:
        if not IntersectsTriangleAabbSat(tri.a, tri.b, tri.c, aabb.extents, axis):
            return False
    return True

def IntersectsTriangleAabbSat(v0, v1, v2, aabbExtents, axis):
    p0 = v0.dot(axis)
    p1 = v1.dot(axis)
    p2 = v2.dot(axis)
    
    maxP = max(p0, max(p1, p2))
    minP = min(p0, min(p1, p2))
    
    r = aabbExtents.x * abs(axis.x) + aabbExtents.y * abs(axis.y) + aabbExtents.z * abs(axis.z)
    
    if max(-maxP, minP) > r:
        return False
    return True
```

**Edge Cases and Pitfalls:**
*   **Degenerate Triangles:** The SAT implementation normalizes edge vectors. If a triangle has zero area, normalization produces NaNs or infinities, potentially causing incorrect results or GPU errors [S2, unofficial].
*   **Missing Axes:** The SAT test checks the separating axes (9 cross products of edges with coordinate axes, 3 coordinate axes, and 1 triangle normal). Missing any axis can lead to false positives [S2, unofficial].
*   **Race Conditions:** If multiple triangles write to the same voxel, the last thread to execute wins, as there is no atomic blend logic [S4, unofficial].

## Subtopics

### [OpenCL-based Voxelization](15037-opencl-based-voxelization.md)
This method converts a triangular mesh into a voxel grid by dispatching compute threads to test for intersections between mesh facets and voxel cubes. It distinguishes itself from CPU-based approaches by leveraging OpenCL for parallel execution, achieving up to 260 times faster computation. It builds on [GPU Mesh Voxelization via AABB-Triangle Intersection](2541-gpu-mesh-voxelization-via-aabb-triangle-intersection.md) by optimizing memory access patterns for the specific geometry of triangular facets.

## Operating characteristics
*   **Time Complexity:** $O(N_{cells} \cdot N_{triangles})$ per voxelization pass, where $N_{cells}$ is the number of voxels and $N_{triangles}$ is the number of triangles [S2, unofficial]. This is a brute-force approach without spatial acceleration structures [S2, unofficial].
*   **Memory Complexity:** $O(N_{cells})$ for the output voxel buffer, plus $O(N_{vertices} + N_{indices})$ for input buffers [S1, unofficial][S2, unofficial].
*   **Performance:** Performance scales linearly with grid size and triangle count. It is efficient for moderate-resolution grids and meshes but becomes prohibitive for high-resolution grids or complex meshes due to the $O(N^2)$ nature [S2, unofficial].
*   **Strengths:** Simple implementation, no spatial data structure maintenance, fully parallelizable at the voxel level [S2, unofficial].
*   **Limitations:** Poor scalability for large scenes or high-resolution grids; no culling of empty space [S2, unofficial].

## Background
This method is part of the Unity GPU Mesh Voxelizer series by bzgeb, introduced in 2021 [S2, unofficial][S3, unofficial]. It is designed for real-time voxelization in game engines, leveraging compute shaders for parallel intersection testing [S2, unofficial][S3, unofficial].
