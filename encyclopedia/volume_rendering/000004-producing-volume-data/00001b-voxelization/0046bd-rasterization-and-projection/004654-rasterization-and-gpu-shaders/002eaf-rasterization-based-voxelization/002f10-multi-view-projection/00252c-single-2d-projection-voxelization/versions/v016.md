# Single 2D Projection Voxelization

Also called: Dominant axis voxelization, Thin voxelization via single projection

## Overview
Single 2D Projection Voxelization is a method that produces 6-separating (tunnel-free) voxelization using only one 2D projection along the dominant axis of a triangle's normal vector [S1, unofficial]. It leverages the "thinness" property of voxelization to avoid the computational cost of multi-axis projections [S1, unofficial]. Unlike [Orthographic Multi-View Voxelization](3892-orthographic-multi-view-voxelization.md) which projects along all three axes, this method projects only along the axis where the triangle is most "face-on," relying on edge-crossing tests to ensure topological correctness [S1, unofficial].

## How it works
**Inputs:** A planar triangle defined by its vertices; the target voxel grid resolution $R = (R_x, R_y, R_z)$; the scene's axis-aligned bounding box (AABB) defined by $bb_{min}$ and $bb_{max}$.
**Outputs:** A set of occupied voxels in the 3D grid.

**Data Structures:**
*   **Voxel Grid:** A 3D array or texture of size $R_x \times R_y \times R_z$. Each voxel is identified by integer indices $(i, j, k)$.
*   **Triangle:** Defined by vertices $v_0, v_1, v_2$ in 3D space.
*   **Normal:** The geometric normal vector $\mathbf{n}$ of the triangle.

**Steps:**

1.  **Identify Dominant Axis:** Compute the geometric normal $\mathbf{n} = (n_x, n_y, n_z)$ of the triangle. Determine the dominant axis $A \in \{x, y, z\}$ corresponding to the component of $\mathbf{n}$ with the largest absolute magnitude. Project the triangle onto the 2D plane perpendicular to $A$ [S1, unofficial].

2.  **Rasterize and Center Test:** Rasterize the projected triangle into a 2D buffer. For each pixel $(u, v)$ covered by the projection:
    *   Check if the pixel center lies inside the projected triangle [S1, unofficial].
    *   If yes, evaluate the depth $d_{tri}$ of the triangle at the pixel center in 3D space.
    *   Map the pixel center and depth to the voxel grid. The voxel index $(i, j, k)$ is determined by mapping the 3D point $(u, v, d_{tri})$ to the grid coordinates using the scale and offset derived from the AABB and resolution $R$ [Parent, G].
    *   Output the voxel whose center depth is closest to $d_{tri}$ [S1, unofficial]. This corresponds to intersecting the triangle against the crosshair segment parallel to the projection axis [S1, unofficial].

3.  **Edge Crossing Test (Horizontal):** For pixels where the projected triangle covers part of the pixel but does *not* contain the pixel center (i.e., the triangle edge passes through the pixel):
    *   Define a horizontal line bisecting the pixel (constant $v$, varying $u$).
    *   Find the intersection extents of the triangle with this line. Let these be $u_{min}$ and $u_{max}$ [S1, unofficial].
    *   Clamp $u_{min}$ and $u_{max}$ to the horizontal pixel extents $[u_{pixel\_min}, u_{pixel\_max}]$ [S1, unofficial].
    *   Evaluate the depth of the triangle at these two clamped points, $d_{min}$ and $d_{max}$ [S1, unofficial].
    *   Let $d_{vox}$ be the depth of the center of the voxel column corresponding to this pixel.
    *   If $d_{min}$ and $d_{max}$ are on different sides of $d_{vox}$ (i.e., $(d_{min} - d_{vox}) \times (d_{max} - d_{vox}) < 0$), output the corresponding voxel [S1, unofficial].

4.  **Edge Crossing Test (Vertical):** If the horizontal test fails (the depths are not on different sides of the voxel center):
    *   Define a vertical line bisecting the pixel (constant $u$, varying $v$).
    *   Repeat the process: find triangle extents, clamp to pixel vertical extents, evaluate depths $d'_{min}$ and $d'_{max}$ [S1, unofficial].
    *   If $d'_{min}$ and $d'_{max}$ are on different sides of $d_{vox}$, output the corresponding voxel [S1, unofficial].

**Pseudocode:**

```python
def single_2d_projection_voxelization(triangle, grid_resolution, bb_min, bb_max):
    # 1. Identify dominant axis
    normal = compute_normal(triangle)
    abs_normal = abs(normal)
    dominant_axis = argmax(abs_normal) # 0 for x, 1 for y, 2 for z
    
    # 2. Project and Rasterize
    # Project triangle vertices onto the 2D plane perpendicular to dominant_axis
    projected_vertices = project_2d(triangle, dominant_axis)
    
    # Rasterize projected triangle to get list of covered pixels
    covered_pixels = rasterize(projected_vertices)
    
    for pixel in covered_pixels:
        pixel_center_2d = pixel.center
        pixel_bounds = pixel.bounds
        
        # Check if pixel center is inside projected triangle
        if point_in_triangle(pixel_center_2d, projected_vertices):
            # Map pixel center to 3D point on triangle
            point_3d = map_2d_to_3d(pixel_center_2d, triangle, dominant_axis)
            voxel_idx = map_to_voxel_grid(point_3d, grid_resolution, bb_min, bb_max)
            grid[voxel_idx] = OCCUPIED
        else:
            # Edge crossing test
            voxel_center_depth = get_voxel_column_center_depth(pixel, dominant_axis, grid_resolution, bb_min, bb_max)
            
            # Horizontal test
            h_extents = get_triangle_line_extents(triangle, dominant_axis, line='horizontal', y=pixel.center.y)
            h_clamped = clamp(h_extents, pixel_bounds.x_min, pixel_bounds.x_max)
            h_depths = [evaluate_triangle_depth(triangle, dominant_axis, point) for point in h_clamped]
            
            if are_on_different_sides(h_depths[0], h_depths[1], voxel_center_depth):
                voxel_idx = map_to_voxel_grid_from_pixel(pixel, dominant_axis, h_depths[0], grid_resolution, bb_min, bb_max)
                grid[voxel_idx] = OCCUPIED
            else:
                # Vertical test
                v_extents = get_triangle_line_extents(triangle, dominant_axis, line='vertical', x=pixel.center.x)
                v_clamped = clamp(v_extents, pixel_bounds.y_min, pixel_bounds.y_max)
                v_depths = [evaluate_triangle_depth(triangle, dominant_axis, point) for point in v_clamped]
                
                if are_on_different_sides(v_depths[0], v_depths[1], voxel_center_depth):
                    voxel_idx = map_to_voxel_grid_from_pixel(pixel, dominant_axis, v_depths[0], grid_resolution, bb_min, bb_max)
                    grid[voxel_idx] = OCCUPIED

def are_on_different_sides(d1, d2, d_center):
    return (d1 - d_center) * (d2 - d_center) < 0
```

## Operating characteristics
*   **Time Complexity:** $O(N \cdot P)$ where $N$ is the number of triangles and $P$ is the number of pixels covered by the projection. Significantly faster than multi-view methods as it performs only one rasterization pass per triangle.
*   **Memory Complexity:** $O(R_x \cdot R_y \cdot R_z)$ for the voxel grid. The 2D buffer is $O(R_{proj}^2)$ where $R_{proj}$ is the resolution of the projection plane.
*   **Strengths:** High performance due to single projection; produces 6-separating (tunnel-free) voxelization [S1, unofficial].
*   **Limitations:** Relies on the "thinness" property, which assumes the triangle is relatively thin or the voxel resolution is fine enough to capture the geometry without significant aliasing artifacts along the non-dominant axes [S1, unofficial]. Performance degrades if triangles are nearly perpendicular to the dominant axis (though the dominant axis selection mitigates this).
*   **When to use:** When performance is critical and the geometry is not extremely complex or highly anisotropic in a way that violates the thinness assumption. Suitable for real-time voxelization.

## Background
This method is derived from the topological approach to voxelization, specifically leveraging the equivalence of 3-axis rasterization with the crosshairs target [S1, unofficial]. It was presented in the context of producing 6-separating voxelization efficiently [S1, unofficial]. The method builds on the observation that for a planar triangle, projecting along the dominant normal axis is sufficient to capture all voxels that would be captured by other axes, provided edge crossings are handled correctly [S1, unofficial].
