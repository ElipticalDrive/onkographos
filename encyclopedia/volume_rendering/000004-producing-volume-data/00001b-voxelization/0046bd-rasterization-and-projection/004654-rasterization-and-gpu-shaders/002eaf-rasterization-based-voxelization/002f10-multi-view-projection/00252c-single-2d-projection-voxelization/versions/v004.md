# Single 2D Projection Voxelization

Also called: Dominant axis voxelization, Thin voxelization via single projection

## Overview
Single 2D Projection Voxelization is a method that produces 6-separating voxelization using only one 2D projection along the dominant axis of a triangle's normal vector, leveraging the thinness property to reduce computational cost [S1, unofficial]. Unlike [Orthographic Multi-View Voxelization](3892-orthographic-multi-view-voxelization.md) which requires three passes, this method relies on the fact that for pixels where the projected triangle contains the pixel center, the dominant axis projection is sufficient to determine the unique voxel, while edge cases are handled by testing crosshair segments perpendicular to the projection axis [S1, unofficial].

## How it works
**Inputs:** A planar triangle defined by its vertices and geometric normal vector; a voxel grid with defined resolution and origin.
**Outputs:** A set of voxels representing the triangle, ensuring 6-separation.

**Data Structures:**
*   **Triangle:** Defined by vertices $\mathbf{v}_0, \mathbf{v}_1, \mathbf{v}_2$ and normal $\mathbf{n} = (n_x, n_y, n_z)$.
*   **Voxel Grid:** Discrete 3D grid. Voxels are identified by integer coordinates $(i, j, k)$.
*   **Pixel Buffer:** 2D array corresponding to the projection plane.

**Steps:**
1.  **Identify Dominant Axis:** Determine the axis of the geometric normal vector $\mathbf{n}$ with the largest absolute component. Let this axis be $A$ (e.g., if $|n_z|$ is maximal, $A=Z$). The projection direction is along $A$.
2.  **Rasterize Projection:** Project the triangle onto the 2D plane perpendicular to $A$. Rasterize this 2D projection to identify covered pixels.
3.  **Center Test:** For each pixel where the projected triangle contains the pixel center:
    *   Evaluate the depth of the triangle at the pixel center.
    *   Output the voxel whose center depth is closest to this evaluated depth [S1, unofficial].
    *   This step corresponds to intersecting the triangle against the crosshair segment parallel to the projection axis [S1, unofficial].
4.  **Edge Test (Horizontal):** For pixels that contain an edge of the triangle but where the triangle does not overlap the center:
    *   Find the extents of the triangle on a horizontal line bisecting the pixel.
    *   Clamp these horizontal extents to the horizontal pixel extents.
    *   Evaluate the depth of the triangle at these two clamped points.
    *   If the evaluated depths are on different sides of a voxel's center depth, output the corresponding voxel [S1, unofficial].
5.  **Edge Test (Vertical):** If the horizontal test fails (values are not on different sides of the voxel center depth):
    *   Repeat the test for the vertical direction (vertical line bisecting the pixel) [S1, unofficial].
    *   This corresponds to testing the triangle against the two crosshair segments perpendicular to the projection axis [S1, unofficial].

**Pseudocode:**
```python
def single_2d_projection_voxelization(triangle, voxel_grid):
    # 1. Identify dominant axis
    n = triangle.normal
    abs_n = [abs(n.x), abs(n.y), abs(n.z)]
    dominant_axis = argmax(abs_n)
    
    # 2. Project and rasterize
    # Project triangle onto plane perpendicular to dominant_axis
    projected_triangle = project(triangle, dominant_axis)
    pixels = rasterize(projected_triangle)
    
    for pixel in pixels:
        # 3. Center Test
        if pixel.center_in_triangle:
            depth_at_center = evaluate_depth(triangle, pixel.center)
            voxel = find_closest_voxel(depth_at_center, dominant_axis)
            voxel_grid.set(voxel, 1)
        else:
            # 4. Edge Test (Horizontal)
            # Find extents on horizontal bisector
            h_extents = get_triangle_extents_on_line(triangle, pixel.horizontal_bisector)
            # Clamp to pixel horizontal extents
            h_extents = clamp(h_extents, pixel.horizontal_bounds)
            
            # Evaluate depth at clamped points
            d1 = evaluate_depth(triangle, h_extents[0])
            d2 = evaluate_depth(triangle, h_extents[1])
            
            # Check if depths are on different sides of voxel center
            # Note: 'voxel' here refers to the potential voxel in the column
            # determined by the pixel's 2D position and the dominant axis
            voxel_candidate = get_voxel_candidate(pixel, dominant_axis)
            
            if is_on_different_sides(d1, d2, voxel_candidate.center_depth):
                voxel_grid.set(voxel_candidate, 1)
            else:
                # 5. Edge Test (Vertical)
                v_extents = get_triangle_extents_on_line(triangle, pixel.vertical_bisector)
                v_extents = clamp(v_extents, pixel.vertical_bounds)
                
                d3 = evaluate_depth(triangle, v_extents[0])
                d4 = evaluate_depth(triangle, v_extents[1])
                
                if is_on_different_sides(d3, d4, voxel_candidate.center_depth):
                    voxel_grid.set(voxel_candidate, 1)
```

**Parameters:**
*   **Dominant Axis Selection:** Based on the geometric normal vector. Not given in the sources.
*   **Clamping:** Extents are clamped to pixel extents. Not given in the sources.

**Edge Cases and Pitfalls:**
*   **Degeneracy:** Triangles parallel to the projection direction may project as lines. The method relies on the dominant axis selection to avoid this for the primary projection, but edge tests handle remaining ambiguities [S1, unofficial].
*   **Precision:** Depth evaluation must be precise to determine if values are on different sides of a voxel center [S1, unofficial].

## Operating characteristics
*   **Time Complexity:** Proportional to the number of pixels covered by the projected triangle. One rasterization pass instead of three.
*   **Memory Complexity:** Same as standard rasterization-based voxelization, storing the voxel grid.
*   **Strengths:** Reduces the number of 2D projections from three to one, potentially improving performance.
*   **Limitations:** Relies on the thinness property and correct identification of the dominant axis. May require careful handling of edge cases where the triangle is nearly parallel to the projection plane [S1, unofficial].

## Background
This method is derived from the thinness property and the equivalence of 3-axis rasterization with the crosshairs target [S1, unofficial]. It was presented in "A Topological Approach to Voxelization" by Laine et al. [S1, unofficial]. The approach simplifies the voxelization process by exploiting the fact that the dominant axis projection is sufficient for most pixels, with edge tests handling the rest.
