# Volumetric Representation via Depth Map Registration

Also called: Sparse Non-Lambertian Multi-view Volume Construction, Volume Initialization

## Overview
This method constructs a 3D volume from a set of multi-view images by registering estimated depth maps into a voxel grid, specifically handling non-Lambertian reflections by using individual minimum cost per view rather than a global threshold [S1]. It represents scene geometry as a sparse voxel cloud where voxel values indicate the number of views mapping to that location, serving as the initialization phase for subsequent volume refinement and color selection [S1].

## How it works
**Inputs:** A set of $N$ reference views, each with associated camera parameters and an estimated depth map.
**Outputs:** A 3D voxel grid where each voxel $(i, j, k)$ holds an integer value $\delta_{ijk}$ representing the count of views mapping to that voxel.

**Data Structures:**
*   **Voxel Grid:** A 3D array or sparse hash map.
*   **Voxel Value ($\delta_{ijk}$):** An integer counter.
*   **Depth Map:** A 2D array of depth values $d$ and associated weights $\delta$.

**Steps:**

1.  **Depth Estimation with Non-Lambertian Compensation:**
    For each reference view, search along its own geometry to estimate a depth map. To compensate for non-Lambertian reflections, use the individual minimum cost for that specific view rather than a global threshold [S1].

2.  **Volume Initialization (Registration):**
    Register the estimated depth maps into the 3D volume. For each voxel at location $(i, j, k)$, determine its value $\delta_{ijk}$ based on whether a depth is registered to it [S1]:
    $$
    \delta_{ijk} =
    \begin{cases}
    n, & \text{if registering depth} \\
    0, & \text{otherwise}
    \end{cases}
    $$
    where $n$ is the number of views mapping to voxel $\mathbf{x}$, with $n \in \{1, 2, \dots, N\}$ and $N$ being the total number of reference views [S1].

3.  **Isolated Voxel Removal and Depth Refinement:**
    Detect isolated voxels that have no neighbors. Project the volume back to the reference view geometry to build new depth maps, which removes errors from the previous step [S1].
    *   If multiple depth values exist for a pixel, consider the front cluster of depths.
    *   Calculate the proper depth value $d$ for a particular pixel using the following formula [S1]:
        $$
        d =
        \begin{cases}
        d_n, & \text{if only one depth has } \delta_n = \max(\delta_K) \\
        \left(\sum_{k=1}^{K} \delta_k d_k\right) / \left(\sum_{k=1}^{K} \delta_k\right), & \text{otherwise}
        \end{cases}
        $$
        where $K$ is the number of depth values in the front cluster, $d_k$ is the depth value, and $\delta_k$ is the voxel weight. The depth value projected from the voxel containing the maximum $\delta$ is selected. If the maximum $\delta$ appears in two or more depth values, the fit depth value is calculated from the average of all depth values of the front cluster with weighted coefficient $\delta$ [S1].

4.  **Volume Reconstruction and Interpolation:**
    Reconstruct the volume again using the refined depths. Interpolate voxels to connect the surface of the volume among near voxels [S1].

**Pseudocode:**

```python
def initialize_volume(reference_views):
    """
    Constructs initial volume by registering depth maps.
    reference_views: List of view objects, each containing camera params and depth_map.
    Returns: 3D voxel grid (sparse dict or array) with delta values.
    """
    voxel_grid = {} # Key: (i, j, k), Value: count n

    # Step 1 & 2: Register depths
    for view in reference_views:
        depth_map = view.get_depth_map() # Estimated depth map
        for pixel in depth_map:
            # Project pixel depth to 3D voxel coordinates (i, j, k)
            # using view's camera parameters and coordinate transformation
            voxel_coords = project_to_voxel(pixel.depth, view.camera)
            
            if voxel_coords is not None:
                i, j, k = voxel_coords
                # Increment count for this voxel
                voxel_grid[(i, j, k)] = voxel_grid.get((i, j, k), 0) + 1

    # Step 3: Remove isolated voxels and refine depths
    # Identify isolated voxels (no neighbors)
    isolated_voxels = find_isolated_voxels(voxel_grid)
    
    # Project volume back to views to build new depth maps
    refined_depth_maps = {}
    for view in reference_views:
        new_depth_map = {}
        for pixel in view.original_depth_map:
            # Get all depth values projected to this pixel from the volume
            depth_cluster = get_depth_cluster_at_pixel(pixel, voxel_grid)
            
            if not depth_cluster:
                continue
                
            K = len(depth_cluster)
            # Find max delta in cluster
            max_delta = max(d.delta for d in depth_cluster)
            candidates = [d for d in depth_cluster if d.delta == max_delta]
            
            if len(candidates) == 1:
                d = candidates[0].depth
            else:
                # Weighted average
                numerator = sum(d.delta * d.depth for d in depth_cluster)
                denominator = sum(d.delta for d in depth_cluster)
                d = numerator / denominator if denominator != 0 else 0
            
            new_depth_map[pixel] = d
        refined_depth_maps[view] = new_depth_map

    # Step 4: Reconstruct volume with interpolated voxels
    final_voxel_grid = {}
    for view in reference_views:
        depth_map = refined_depth_maps[view]
        for pixel in depth_map:
            voxel_coords = project_to_voxel(pixel.depth, view.camera)
            if voxel_coords is not None:
                i, j, k = voxel_coords
                final_voxel_grid[(i, j, k)] = final_voxel_grid.get((i, j, k), 0) + 1
    
    # Interpolate voxels to connect surface among near voxels
    final_voxel_grid = interpolate_surface_voxels(final_voxel_grid)
    
    return final_voxel_grid
```

## Subtopics

### Iterative Volume Refinement
An iterative algorithm to refine the shape of the volume by removing scattering voxels and smoothing sharp corners to increase coding gain [S1]. It compares reconstructed views against original reference images to identify and correct geometry errors [S1].
*   **Step 1:** Temporarily define voxel colors by taking the median of color values from all visible views [S1].
*   **Step 2:** Iterate through reference views (e.g., from furthest left to furthest right). For each view, calculate the Mean Square Error (MSE) between the reconstructed view and the original reference image [S1].
*   **Step 3:** If the MSE exceeds a threshold, remove the old depth and its associated voxel. Investigate a new depth derived from neighboring pixels based on a smooth surface assumption [S1].
*   **Step 4:** If the new depth value meets color constraints for all visible views, generate the new associated voxel. Use a window-based computation (e.g., 3x3 pixels) for error calculation to handle inaccurate camera calibration and unequal resolutions [S1].
*   **Step 5:** Iteratively reconstruct images if voxels are removed or generated, as voxel position changes affect visibility. Repeat until no new voxels are generated and no old voxels are removed [S1].

## Operating characteristics
*   **Time Complexity:** Not given in the sources. The iterative refinement step depends on the number of iterations (e.g., 26 iterations for five-view Leo sequence) and the number of views [S1].
*   **Memory Complexity:** Sparse representation. The volume is stored as a sparse voxel cloud, where only voxels with $\delta > 0$ are stored [S1].
*   **Strengths:** Simple and fast registration; handles non-Lambertian reflections by exploiting individual minimum cost; provides good representation for natural scenery; iterative refinement removes scattering voxels and smooths sharp corners [S1].
*   **Limitations:** Initial volume may contain scattering voxels; requires accurate depth estimation; sensitive to camera calibration inaccuracies and unequal resolutions (mitigated by window-based MSE calculation) [S1].
*   **When to use:** When initializing a volume for multi-view synthesis where non-Lambertian reflections are present and sparse representation is desired [S1].
*   **When not to use:** When dense, high-fidelity geometry is required without iterative refinement overhead, or when camera calibration is highly inaccurate and cannot be mitigated by window-based error calculation [S1].

## Background
The method was proposed in the context of color volumetric compression for realistic view synthesis applications [S1]. It builds on the principle that depth registration methods give a good representation for natural scenery [S1]. The approach includes three steps: Volume initialization, Volume refinement, and Colour selection [S1].
