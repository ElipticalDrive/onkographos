# Single 2D Projection Voxelization

Also called: Dominant axis voxelization, Thin voxelization via single projection

## Overview
Single 2D Projection Voxelization is an algorithm that produces 6-separating (tunnel-free) voxelization using only one 2D projection along the dominant axis of a triangle's normal vector [S1, unofficial]. It leverages the "thinness" property of voxelization to avoid the computational cost of multi-axis projections. Unlike [Orthographic Multi-View Voxelization](3892-orthographic-multi-view-voxelization.md), which projects along all three axes, this method relies on a single projection combined with edge-crossing tests to ensure topological correctness [S1, unofficial].

## How it works
**Inputs:** A planar triangle defined by its three vertices in world space; the target voxel resolution $(V_x, V_y, V_z)$; the voxel space transformation matrix mapping world coordinates to voxel indices.
**Outputs:** A set of occupied voxel coordinates.

**Data Structures:**
*   **Voxel Grid:** A 3D array or hash map storing occupancy status.
*   **Triangle:** Defined by vertices $\mathbf{v}_0, \mathbf{v}_1, \mathbf{v}_2$.

**Steps:**

1.  **Identify Dominant Axis:** Compute the geometric normal vector $\mathbf{n}$ of the triangle. Determine the dominant axis $A \in \{x, y, z\}$ corresponding to the component of $\mathbf{n}$ with the largest absolute magnitude. This axis defines the projection direction.
2.  **Project and Rasterize:** Project the triangle vertices onto the 2D plane perpendicular to axis $A$. Rasterize this 2D projection to identify covered pixels.
3.  **Center Test:** For each pixel covered by the projection:
    *   If the pixel center lies inside the projected triangle, evaluate the depth of the triangle at the pixel center in the 3D space.
    *   Output the voxel whose center depth is closest to this evaluated depth [S1, unofficial].
4.  **Edge Test:** For pixels where the triangle covers part of the pixel but does *not* contain the pixel center:
    *   Find the intersection of the triangle with the horizontal line bisecting the pixel. Determine the extents (min/max coordinates) of the triangle along this line within the pixel bounds.
    *   Clamp these extents to the horizontal pixel boundaries.
    *   Evaluate the depth of the triangle at these two clamped points.
    *   If the evaluated depths lie on different sides of the voxel's center depth (i.e., one is shallower and one is deeper than the voxel center), output the corresponding voxel [S1, unofficial].
5.  **Vertical Fallback:** If the horizontal test fails (depths are on the same side of the voxel center), repeat the test using the vertical line bisecting the pixel. Find the vertical extents, clamp to pixel boundaries, evaluate depths, and output the voxel if the depths straddle the voxel center depth [S1, unofficial].

**Pseudocode:**

```python
def single_2d_projection_voxelization(triangle, voxel_grid, resolution):
    # 1. Identify dominant axis
    normal = compute_normal(triangle)
    abs_normal = abs(normal)
    if abs_normal.x >= abs_normal.y and abs_normal.x >= abs_normal.z:
        axis = 'x'
        plane_coords = ('y', 'z')
    elif abs_normal.y >= abs_normal.x and abs_normal.y >= abs_normal.z:
        axis = 'y'
        plane_coords = ('x', 'z')
    else:
        axis = 'z'
        plane_coords = ('x', 'y')

    # 2. Project and rasterize
    projected_vertices = project(triangle, axis)
    covered_pixels = rasterize(projected_vertices, resolution)

    for pixel in covered_pixels:
        pixel_center = get_pixel_center(pixel, resolution)
        
        # 3. Center Test
        if point_in_triangle(pixel_center, projected_vertices):
            depth_at_center = evaluate_depth(triangle, pixel_center, axis)
            voxel_index = get_voxel_index(pixel_center, depth_at_center, axis, resolution)
            voxel_grid.set(voxel_index, True)
            continue

        # 4. Edge Test - Horizontal
        h_line = get_horizontal_bisector(pixel, resolution)
        h_extents = intersect_triangle_line(triangle, h_line, axis)
        clamped_h = clamp_to_pixel(h_extents, pixel, resolution)
        
        d1 = evaluate_depth(triangle, clamped_h[0], axis)
        d2 = evaluate_depth(triangle, clamped_h[1], axis)
        
        voxel_center_depth = get_voxel_center_depth(pixel, axis, resolution)
        
        if straddle(d1, d2, voxel_center_depth):
            voxel_index = get_voxel_index(pixel, voxel_center_depth, axis, resolution)
            voxel_grid.set(voxel_index, True)
            continue

        # 5. Vertical Fallback
        v_line = get_vertical_bisector(pixel, resolution)
        v_extents = intersect_triangle_line(triangle, v_line, axis)
        clamped_v = clamp_to_pixel(v_extents, pixel, resolution)
        
        d3 = evaluate_depth(triangle, clamped_v[0], axis)
        d4 = evaluate_depth(triangle, clamped_v[1], axis)
        
        if straddle(d3, d4, voxel_center_depth):
            voxel_index = get_voxel_index(pixel, voxel_center_depth, axis, resolution)
            voxel_grid.set(voxel_index, True)
```

**Parameters:**
*   **Resolution:** $(V_x, V_y, V_z)$.
*   **Straddle Condition:** $d_{min} < d_{voxel} < d_{max}$ or $d_{max} < d_{voxel} < d_{min}$.

**Edge Cases:**
*   **Degenerate Triangles:** If the triangle normal is zero, the dominant axis is undefined. [Not given in the sources.]
*   **Precision:** Floating-point errors in depth evaluation may cause incorrect straddle decisions. [G] Use epsilon comparisons for straddle tests.

## Operating characteristics
*   **Time Complexity:** $O(N \cdot R)$, where $N$ is the number of triangles and $R$ is the number of pixels covered by the projection. Significantly faster than multi-view methods as it performs only one rasterization pass per triangle.
*   **Memory Complexity:** $O(V_x \cdot V_y \cdot V_z)$ for the voxel grid.
*   **Strengths:** High performance due to single projection; produces 6-separating voxelization.
*   **Limitations:** Relies on the "thinness" property, which may not hold for all geometries or resolutions. [Not given in the sources.]
*   **When to use:** When performance is critical and the geometry is well-behaved (thin).
*   **When not to use:** For thick geometries where the dominant axis projection may miss voxels that would be captured by other axes.

## Background
This method is derived from the topological approach to voxelization, specifically leveraging the equivalence of 3-axis rasterization with the crosshairs target [S1, unofficial]. It was presented in the context of producing tunnel-free voxelization efficiently. The concept builds on earlier work by Laine et al. [FBP09, CNS*11] regarding crosshair-based voxelization.
