# Voxelization Pass

Also called: Voxelization Rendering Pass, Voxelizer Pass

## Overview
The Voxelization Pass renders scene geometry into a 3D texture to produce a volumetric representation of the scene [S1, unofficial]. It differs from standard rasterization by writing directly to a 3D image buffer rather than a 2D color buffer [S1, unofficial]. It builds on [Position Map FBO Setup](2749-position-map-fbo-setup.md) which prepares the framebuffer targets [S1, unofficial].

## How it works
**Inputs:** Scene geometry, `tex_size`, `scene_scale`, `voxelizer_camera_`, and `tex3D` [S1, unofficial].
**Outputs:** `tex3D`, a 3D texture of format `GL_RGBA8` containing the voxelized scene data [S1, unofficial].
**Data Structures:** `tex3D` is a write-only image texture bound at unit 0 [S1, unofficial]. `voxelizer_camera_` defines an orthographic frustum of `(-1, 1, -1, 1, 1, -1)` [S1, unofficial].
**Steps:**
1. Set viewport to `tex_size` $\times$ `tex_size` and bind default framebuffer [S1, unofficial].
2. Clear color and depth buffers [S1, unofficial].
3. Disable face culling and depth testing [S1, unofficial].
4. Bind `tex3D` as a write-only image texture at unit 0 with `GL_RGBA8` format [S1, unofficial].
5. Activate `shader_voxelization_` and set uniforms `voxelImage` to 0 and `sceneScale` to `scene_scale` [S1, unofficial].
6. Render the scene using `voxelizer_camera_` [S1, unofficial].
7. Insert a memory barrier for texture fetches and generate mipmaps [S1, unofficial].
**Pseudocode:**
```python
def voxelization_pass(scene, tex_size, scene_scale, voxelizer_camera, tex3D):
    # 1. Set viewport to tex_size x tex_size and bind default framebuffer
    viewport = (0, 0, tex_size, tex_size)
    framebuffer_binding = 0
    
    # 2. Clear color and depth buffers
    color_buffer = [0.0, 0.0, 0.0, 0.0]
    depth_buffer = cleared
    
    # 3. Disable face culling and depth testing
    culling_enabled = False
    depth_test_enabled = False
    
    # 4. Bind tex3D as write-only image texture at unit 0 with GL_RGBA8 format
    texture_unit = 0
    texture_format = "RGBA8"
    access_mode = "WRITE_ONLY"
    
    # 5. Activate shader_voxelization_ and set uniforms
    shader_program = "shader_voxelization_"
    uniforms = {"voxelImage": 0, "sceneScale": scene_scale}
    
    # 6. Render scene using voxelizer_camera_
    render_geometry(scene, voxelizer_camera)
    
    # 7. Insert memory barrier for texture fetches and generate mipmaps
    barrier_type = "IMAGE_FETCH"
    mipmap_generation = True

# Helper definitions for self-containment
def render_geometry(mesh, camera): pass
```
**Edge Cases and Pitfalls:**
- Depth testing and face culling must be disabled to ensure all geometry fragments are written to the 3D texture without occlusion culling [S1, unofficial].
- The orthographic frustum bounds `(-1, 1, -1, 1, 1, -1)` define the projection space [S1, unofficial]. Implementers should verify the coordinate system convention matches their renderer [G].
