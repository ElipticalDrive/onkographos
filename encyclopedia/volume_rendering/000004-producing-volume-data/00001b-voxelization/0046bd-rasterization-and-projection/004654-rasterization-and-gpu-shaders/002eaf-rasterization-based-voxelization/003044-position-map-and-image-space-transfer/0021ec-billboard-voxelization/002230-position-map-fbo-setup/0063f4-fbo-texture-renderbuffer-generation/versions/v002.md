# FBO Texture & Renderbuffer Generation

Also called: Dynamic FBO Allocation, Framebuffer Attachment Setup

## Overview
Allocates and attaches 2D textures and depth renderbuffers to framebuffers, handling cleanup and dynamic viewport resizing [S1, unofficial]. Unlike static allocation, this method dynamically adjusts texture and renderbuffer dimensions to match the current viewport [S1, unofficial].

## How it works
**Inputs and outputs:**
- `viewport_width`, `viewport_height`: Integer dimensions of the current viewport [S1, unofficial].
- `textureID`: Pointer or reference to the existing color texture ID [S1, unofficial].
- `depthBuffer`: Pointer or reference to the existing depth renderbuffer ID [S1, unofficial].
- `attachmentID`: The attachment point index for the framebuffer [S1, unofficial].

**Data structures:**
- 2D Texture: Internal format `GL_RGBA16F`, dimensions `viewport_width` × `viewport_height`, with `GL_LINEAR` minification/magnification filters and `GL_CLAMP_TO_EDGE` wrapping [S1, unofficial].
- Depth Renderbuffer: Format `GL_DEPTH_COMPONENT`, dimensions `viewport_width` × `viewport_height` [S1, unofficial].

**Steps:**
1. **Depth Buffer Management:** If `depthBuffer` is greater than zero, delete the existing renderbuffer [S1, unofficial]. Generate a new renderbuffer ID [S1, unofficial]. Bind the new renderbuffer [S1, unofficial]. Allocate storage with format `GL_DEPTH_COMPONENT` using `viewport_width` and `viewport_height` [S1, unofficial].
2. **Color Texture Management:** If `textureID` is not zero, bind the texture target to zero, then delete the existing texture [S1, unofficial]. Generate a new texture ID [S1, unofficial]. Bind the new texture to the `GL_TEXTURE_2D` target [S1, unofficial]. Allocate storage with internal format `GL_RGBA16F`, width `viewport_width`, height `viewport_height`, pixel format `GL_RGBA`, and type `GL_FLOAT`, using `NULL` for initial data [S1, unofficial]. Set `GL_TEXTURE_MIN_FILTER` and `GL_TEXTURE_MAG_FILTER` to `GL_LINEAR` [S1, unofficial]. Set `GL_TEXTURE_WRAP_S` and `GL_TEXTURE_WRAP_T` to `GL_CLAMP_TO_EDGE` [S1, unofficial]. Unbind the texture target [S1, unofficial].
3. **Framebuffer Attachment:** Bind the target framebuffer [S1, unofficial]. Attach the new texture to the framebuffer at `attachmentID` using target `GL_TEXTURE_2D` and level `0` [S1, unofficial].

**Pseudocode:**
```python
# Standard GPU memory operations (self-contained)
def delete_renderbuffer(id): ...
def create_renderbuffer(): ...
def bind_renderbuffer(id): ...
def allocate_renderbuffer_storage(format, width, height): ...
def bind_texture_target(target): ...
def delete_texture(id): ...
def create_texture(): ...
def bind_texture(target, texture): ...
def allocate_texture_storage(target, level, internal_format, width, height, border, pixel_format, pixel_type, data): ...
def set_texture_parameter(target, param, value): ...
def bind_framebuffer(target): ...
def attach_texture_to_framebuffer(framebuffer, attachment, target, texture, level): ...

def generate_fbo_attachments(viewport_width, viewport_height, textureID, depthBuffer, attachmentID):
    # 1. Depth Buffer Management
    if depthBuffer > 0:
        delete_renderbuffer(depthBuffer)
    
    new_depth_buffer = create_renderbuffer()
    bind_renderbuffer(new_depth_buffer)
    allocate_renderbuffer_storage(format="GL_DEPTH_COMPONENT", width=viewport_width, height=viewport_height)
    
    # 2. Color Texture Management
    if textureID != 0:
        bind_texture_target(target=0)
        delete_texture(textureID)
        
    new_texture = create_texture()
    bind_texture(target="GL_TEXTURE_2D", texture=new_texture)
    
    allocate_texture_storage(
        target="GL_TEXTURE_2D", level=0, internal_format="GL_RGBA16F",
        width=viewport_width, height=viewport_height, border=0,
        pixel_format="GL_RGBA", pixel_type="GL_FLOAT", data=None
    )
    
    set_texture_parameter(target="GL_TEXTURE_2D", param="GL_TEXTURE_MIN_FILTER", value="GL_LINEAR")
    set_texture_parameter(target="GL_TEXTURE_2D", param="GL_TEXTURE_MAG_FILTER", value="GL_LINEAR")
    set_texture_parameter(target="GL_TEXTURE_2D", param="GL_TEXTURE_WRAP_S", value="GL_CLAMP_TO_EDGE")
    set_texture_parameter(target="GL_TEXTURE_2D", param="GL_TEXTURE_WRAP_T", value="GL_CLAMP_TO_EDGE")
    
    bind_texture_target(target=0)
    
    # 3. Framebuffer Attachment
    bind_framebuffer(target="GL_FRAMEBUFFER")
    attach_texture_to_framebuffer(
        framebuffer="GL_FRAMEBUFFER", attachment=attachmentID,
        target="GL_TEXTURE_2D", texture=new_texture, level=0
    )
    
    return new_texture, new_depth_buffer
```

**Parameters:**
- `viewport_width`, `viewport_height`: Integer dimensions used for renderbuffer and texture allocation, updated on resize [S1, unofficial].

**Edge cases and pitfalls:**
- Textures must be bound to target zero before deletion to avoid OpenGL errors [S1, unofficial].
