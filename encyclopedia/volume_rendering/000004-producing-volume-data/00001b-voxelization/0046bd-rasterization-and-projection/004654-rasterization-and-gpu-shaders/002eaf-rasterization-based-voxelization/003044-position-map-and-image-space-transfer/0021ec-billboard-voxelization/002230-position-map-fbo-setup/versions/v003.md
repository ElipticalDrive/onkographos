# Position Map FBO Setup
Also called: initPositionFBO
## Overview
Creates a Framebuffer Object (FBO) with a color attachment (position map) and a depth attachment for voxelization rendering [S1, unofficial]. It prepares the framebuffer targets required by the Voxelization Pass [S1, unofficial].
## How it works
**Inputs and outputs:**
*   Input: Window dimensions (width $W$, height $H$).
*   Output: A configured FBO ID, a 2D texture ID (position map), and a renderbuffer ID (depth).

**Data structures:**
1.  **Position Map Texture:**
    *   Type: 2D Texture.
    *   Internal Format: `GL_RGBA32F` (32-bit floating point per channel, 4 channels).
    *   Dimensions: Width $W$, Height $H$.
    *   Filtering: Nearest (`GL_NEAREST`).
    *   Wrapping: Clamp to Edge (`GL_CLAMP_TO_EDGE`).
2.  **Depth Attachment:**
    *   Type: Renderbuffer.
    *   Format: `GL_DEPTH_COMPONENT`.
    *   Dimensions: Width $W$, Height $H$.

**Steps:**
1.  Generate a Framebuffer Object ID using `glGenFramebuffers`.
2.  Bind the FBO using `glBindFramebuffer(GL_FRAMEBUFFER, id)`.
3.  Generate a 2D Texture ID using `glGenTextures`.
4.  Bind the texture using `glBindTexture(GL_TEXTURE_2D, texId)`.
5.  Allocate storage for the texture using `glTexImage2D` with format `GL_RGBA`, type `GL_FLOAT`, and dimensions $W \times H$.
6.  Set texture parameters:
    *   `GL_TEXTURE_MIN_FILTER` to `GL_NEAREST`.
    *   `GL_TEXTURE_MAG_FILTER` to `GL_NEAREST`.
    *   `GL_TEXTURE_WRAP_S` to `GL_CLAMP_TO_EDGE`.
    *   `GL_TEXTURE_WRAP_T` to `GL_CLAMP_TO_EDGE`.
7.  Attach the texture to the FBO at `GL_COLOR_ATTACHMENT0` using `glFramebufferTexture2D`.
8.  Generate a Renderbuffer ID using `glGenRenderbuffers`.
9.  Bind the renderbuffer using `glBindRenderbuffer(GL_RENDERBUFFER, rbId)`.
10. Allocate storage for the renderbuffer using `glRenderbufferStorage` with format `GL_DEPTH_COMPONENT` and dimensions $W \times H$.
11. Attach the renderbuffer to the FBO at `GL_DEPTH_ATTACHMENT` using `glFramebufferRenderbuffer`.
12. Verify FBO completeness using `glCheckFramebufferStatus`. If incomplete, handle error.
13. Unbind the FBO.

**Pseudocode:**
```python
def setup_position_map_fbo(window_width, window_height):
    # 1. Generate FBO
    fbo_id = glGenFramebuffers(1)
    glBindFramebuffer(GL_FRAMEBUFFER, fbo_id)

    # 2. Generate and configure Position Map Texture
    tex_id = glGenTextures(1)
    glBindTexture(GL_TEXTURE_2D, tex_id)
    
    # Allocate RGBA32F storage
    glTexImage2D(
        GL_TEXTURE_2D, 0, GL_RGBA32F, 
        window_width, window_height, 
        0, GL_RGBA, GL_FLOAT, None
    )
    
    # Set parameters: Nearest filtering, Clamp to Edge
    glTexParameteri(GL_TEXTURE_2D, GL_TEXTURE_MIN_FILTER, GL_NEAREST)
    glTexParameteri(GL_TEXTURE_2D, GL_TEXTURE_MAG_FILTER, GL_NEAREST)
    glTexParameteri(GL_TEXTURE_2D, GL_TEXTURE_WRAP_S, GL_CLAMP_TO_EDGE)
    glTexParameteri(GL_TEXTURE_2D, GL_TEXTURE_WRAP_T, GL_CLAMP_TO_EDGE)
    
    # Attach to Color Attachment 0
    glFramebufferTexture2D(
        GL_FRAMEBUFFER, GL_COLOR_ATTACHMENT0, 
        GL_TEXTURE_2D, tex_id, 0
    )

    # 3. Generate and configure Depth Renderbuffer
    rb_id = glGenRenderbuffers(1)
    glBindRenderbuffer(GL_RENDERBUFFER, rb_id)
    
    # Allocate Depth Component storage
    glRenderbufferStorage(
        GL_RENDERBUFFER, GL_DEPTH_COMPONENT, 
        window_width, window_height
    )
    
    # Attach to Depth Attachment
    glFramebufferRenderbuffer(
        GL_FRAMEBUFFER, GL_DEPTH_ATTACHMENT, 
        GL_RENDERBUFFER, rb_id
    )

    # 4. Check completeness
    status = glCheckFramebufferStatus(GL_FRAMEBUFFER)
    if status != GL_FRAMEBUFFER_COMPLETE:
        raise RuntimeError(f"Framebuffer incomplete: {status}")

    # 5. Cleanup bindings
    glBindRenderbuffer(GL_RENDERBUFFER, 0)
    glBindTexture(GL_TEXTURE_2D, 0)
    glBindFramebuffer(GL_FRAMEBUFFER, 0)

    return fbo_id, tex_id, rb_id
```

**Parameters:**
*   `window_width`, `window_height`: Must match the viewport dimensions used during the subsequent rendering pass [S1, unofficial].

**Edge cases and pitfalls:**
*   **Viewport Mismatch:** If the viewport dimensions change, the FBO attachments must be reallocated to match the new dimensions to ensure the position map resolution matches the rendering target [S1, unofficial].
*   **Incomplete FBO:** Failure to attach both color and depth attachments correctly will result in an incomplete framebuffer status [S1, unofficial].
*   **Precision:** Using `GL_RGBA32F` ensures high-precision position storage, critical for accurate voxel position initialization [S1, unofficial].

## Subtopics

### [Voxelization Pass](13160-voxelization-pass.md)
Renders scene geometry into a 3D texture to produce a volumetric representation. It differs from standard rasterization by writing directly to a 3D image buffer. It builds on this setup.

### [FBO Texture & Renderbuffer Generation](19015-fbo-texture-renderbuffer-generation.md)
Allocates and attaches 2D textures and depth renderbuffers to FBOs, handling cleanup and dynamic viewport resizing. Unlike static allocation, this method dynamically adjusts texture dimensions to match the current viewport.

## Operating characteristics
*   **Time Complexity:** $O(1)$ for setup, proportional to the number of attachments.
*   **Memory Complexity:** $O(W \times H)$ for the position map texture and depth renderbuffer.
*   **Strengths:** Provides a high-precision buffer for storing voxel positions in screen space.
*   **Limitations:** Requires dynamic reallocation if viewport dimensions change [S1, unofficial].
*   **When to use:** When performing rasterization-based voxelization that requires a position map to initialize voxel data.

## Background
Originated in the context of GPU-based voxelization techniques, specifically within the Cloud-Renderer project [S1, unofficial]. It is part of a two-pass voxelization technique where the first pass renders billboards into a position map FBO to initialize voxel positions [S1, unofficial].
