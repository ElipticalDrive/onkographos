# Explicit Surface to TSDF Conversion

Also called: Explicit Geometry to TSDF, Mesh to TSDF

## Overview
This method converts explicit geometry, such as triangle meshes or oriented point clouds, into a Truncated Signed Distance Field (TSDF) voxel grid by computing the closest-surface distance for each voxel center and assigning a sign based on surface normals or an offset fallback [S1]. It differs from [Projective TSDF Fusion](3649-mesh-to-tsdf-sequence-encoding-pipeline.md) by operating directly on geometric primitives rather than depth images, making it suitable for inputs from upstream reconstruction pipelines where calibrated camera poses are unavailable or unnecessary [S1].

## How it works
**Inputs:** A triangle mesh $\mathcal{T}$ (set of triangles with vertices $a,b,c$ and normals $\mathbf{n}$) or an oriented point cloud; a global voxel grid definition (origin, resolution, truncation band $\tau$) [S1].
**Outputs:** A TSDF volume where each voxel stores a truncated signed distance value and a validity flag [S1].

**Data Structures:**
*   **Voxel Grid:** A sparse or dense array of blocks. Each block contains $N \times N \times N$ voxels (e.g., $8 \times 8 \times 8$) [S1].
*   **Voxel Entry:** Contains a float value (signed distance) and a boolean valid flag [S1].
*   **Triangle:** Defined by vertices $a, b, c \in \mathbb{R}^3$ and unit normal $\mathbf{n}$ [S1].

**Steps:**
1.  **Iterate Voxels:** For each voxel center $\mathbf{p}$ in the global grid [S1].
2.  **Find Closest Surface:** Compute the closest point $\Pi_{\tau\star}(\mathbf{p})$ on the surface $\mathcal{T}$ to $\mathbf{p}$ [S1].
    *   For a mesh, $\Pi_{\tau\star}(\mathbf{p})$ is the closest point on the closest triangle $\tau\star$ [S1].
    *   To find the closest point on a triangle, check if the orthogonal projection of $\mathbf{p}$ lies inside the triangle. If so, that projection is the closest point. Otherwise, project $\mathbf{p}$ onto the three edge segments and take the nearest point [S1].
    *   The barycentric form of a point on a triangle is $q(v, w) = a + v(b-a) + w(c-a)$, subject to $v \geq 0, w \geq 0, v + w \leq 1$ [S1].
3.  **Compute Unsigned Distance:** Calculate the Euclidean distance $d(\mathbf{p}) = \|\mathbf{p} - \Pi_{\tau\star}(\mathbf{p})\|_2$ [S1].
4.  **Assign Sign:**
    *   **Watertight/Oriented Case:** If the mesh is watertight with consistent orientation, or if the input is an oriented point cloud with reliable normals, compute the sign using the local point-to-plane test:
        $$s(\mathbf{p}) = \text{sign}((\mathbf{p} - \Pi_{\tau\star}(\mathbf{p}))^\top \mathbf{n}_{\tau\star}) d(\mathbf{p})$$
        where $\mathbf{n}_{\tau\star}$ is the unit normal of the closest triangle (or point) [S1].
    *   **Non-Watertight/Unreliable Case:** If the surface is non-watertight, contains thin sheets, or normals are unreliable, use the unsigned-distance offset fallback:
        $$s(\mathbf{p}) = d(\mathbf{p}) - \delta$$
        where $\delta \approx 1\text{--}2$ voxel sizes [S1]. This creates a stable zero level set around the geometry without requiring a global inside/outside convention [S1].
5.  **Truncate and Store:** If $|s(\mathbf{p})| \leq \tau$, store $s(\mathbf{p})$ in the voxel and mark it valid. Otherwise, mark it invalid or store a default value [S1].

**Pseudocode:**
```python
def convert_mesh_to_tsdf(mesh, voxel_grid, truncation_band, is_watertight):
    """
    Converts a mesh to a TSDF volume.
    mesh: List of triangles, each triangle is (a, b, c, n) where a,b,c are vertices and n is normal.
    voxel_grid: Object providing voxel centers and storage.
    truncation_band: Float, the truncation threshold tau.
    is_watertight: Boolean, whether the mesh is watertight with consistent orientation.
    """
    for voxel_center in voxel_grid.centers():
        closest_triangle, closest_point = find_closest_triangle_and_point(mesh, voxel_center)
        dist = sqrt(dot(voxel_center - closest_point, voxel_center - closest_point))
        
        if is_watertight:
            normal = closest_triangle.normal
            sign_val = dot(voxel_center - closest_point, normal)
            signed_dist = (1.0 if sign_val >= 0 else -1.0) * dist
        else:
            delta = 1.5 * voxel_grid.voxel_size
            signed_dist = dist - delta
            
        if abs(signed_dist) <= truncation_band:
            voxel_grid.set_value(voxel_center, signed_dist, valid=True)
        else:
            voxel_grid.set_value(voxel_center, 0.0, valid=False)

def find_closest_triangle_and_point(mesh, p):
    min_dist = float('inf')
    best_triangle = None
    best_point = None
    for triangle in mesh:
        a, b, c, n = triangle
        closest_point_on_tri = closest_point_on_triangle(p, a, b, c)
        dist = sqrt(dot(p - closest_point_on_tri, p - closest_point_on_tri))
        if dist < min_dist:
            min_dist = dist
            best_triangle = triangle
            best_point = closest_point_on_tri
    return best_triangle, best_point

def closest_point_on_triangle(p, a, b, c):
    ap = p - a
    ab = b - a
    ac = c - a
    ab_ab = dot(ab, ab)
    ac_ac = dot(ac, ac)
    ab_ac = dot(ab, ac)
    ap_ab = dot(ap, ab)
    ap_ac = dot(ap, ac)
    denom = ab_ab * ac_ac - ab_ac * ab_ac
    if denom == 0:
        return a
    v = (ac_ac * ap_ab - ab_ac * ap_ac) / denom
    w = (ab_ab * ap_ac - ab_ac * ap_ab) / denom
    if v >= 0 and w >= 0 and (v + w) <= 1:
        return a + v * ab + w * ac
    t_ab = max(0.0, min(1.0, dot(ap, ab) / ab_ab))
    closest_ab = a + t_ab * ab
    dist_ab = sqrt(dot(p - closest_ab, p - closest_ab))
    bp = p - b
    bc = c - b
    t_bc = max(0.0, min(1.0, dot(bp, bc) / dot(bc, bc)))
    closest_bc = b + t_bc * bc
    dist_bc = sqrt(dot(p - closest_bc, p - closest_bc))
    cp = p - c
    ca = a - c
    t_ca = max(0.0, min(1.0, dot(cp, ca) / dot(ca, ca)))
    closest_ca = c + t_ca * ca
    dist_ca = sqrt(dot(p - closest_ca, p - closest_ca))
    if dist_ab <= dist_bc and dist_ab <= dist_ca:
        return closest_ab
    elif dist_bc <= dist_ca:
        return closest_bc
    else:
        return closest_ca
```

**Parameters:**
*   **Truncation Band ($\tau$):** The maximum distance for which TSDF values are stored. Typical values depend on the application, often 1-2 voxel sizes [S1].
*   **Offset ($\delta$):** Used in the fallback case. Typically $1\text{--}2$ voxel sizes [S1].

**Edge Cases and Pitfalls:**
*   **Non-watertight Surfaces:** Global inside/outside signs are ill-defined. The unsigned-distance offset fallback is required [S1].
*   **Thin Sheets:** Similar to non-watertight surfaces, normals may not provide a consistent global sign. Use the offset fallback [S1].
*   **Unreliable Normals:** If normals are noisy or unoriented, the point-to-plane sign test may be incorrect. Use the offset fallback [S1].
*   **Degenerate Triangles:** Handle zero-area triangles in `closest_point_on_triangle` by returning a vertex or skipping [G].

## Subtopics

### Projective TSDF Fusion
A method to compute signed distance values for voxels from calibrated depth images by projecting voxel centers into the camera frame and comparing projected depth with observed depth [S1]. It differs from direct mesh conversion by using depth measurements from multiple views, fused by weighted averaging, rather than explicit geometric primitives [S1]. Choose this when input is from calibrated depth cameras (e.g., Kinect) rather than a reconstructed mesh [S1].

**Steps:**
1.  Transform voxel center $\mathbf{p}$ to camera frame: $\mathbf{p}_c = R^\top (\mathbf{p} - \mathbf{t}) = (x, y, z)^\top$ [S1].
2.  Project to 2D image coordinates: $u = f_x \frac{x}{z} + c_x, \quad v = f_y \frac{y}{z} + c_y$ [S1].
3.  If $z > 0$ and $(u,v)$ is valid, read observed depth $\hat{z}$ and compute $s(\mathbf{p}) = \hat{z} - z$ [S1].
4.  Fuse measurements from multiple views by weighted averaging [S1].

**Formulas:**
*   Camera frame transformation: $\mathbf{p}_c = R^\top (\mathbf{p} - \mathbf{t})$ [S1].
*   Pinhole projection: $u = f_x \frac{x}{z} + c_x, \quad v = f_y \frac{y}{z} + c_y$ [S1].
*   Signed distance: $s(\mathbf{p}) = \hat{z} - z$ [S1].

## Operating characteristics
*   **Time Complexity:** Not given in the sources [S1].
*   **Memory Complexity:** Not given in the sources [S1].
*   **Strengths:** Directly handles explicit geometry; robust to non-watertight surfaces with the offset fallback; compatible with compression pipelines designed for TSDF [S1].
*   **Limitations:** Computationally expensive for high-resolution meshes without acceleration; sign ambiguity for non-watertight surfaces requires fallback [S1].
*   **When to Use:** When input is a mesh or point cloud from a reconstruction pipeline, and camera poses are not available or relevant [S1].
*   **When Not to Use:** When input is raw depth images from calibrated cameras; use Projective TSDF Fusion instead [S1].

## Background
Originating from volumetric fusion systems like KinectFusion [Newcombe et al. 2011] and voxel hashing [Nießner et al. 2013], TSDF representation has become standard for integrating depth data [S1]. The explicit surface conversion path was formalized to support codecs and compression pipelines that accept explicit geometry (meshes/point clouds) as input, alongside depth images [S1]. It addresses the need to handle non-watertight and noisy scans common in real-world reconstruction by providing a robust fallback for sign assignment [S1].
