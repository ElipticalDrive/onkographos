# Mask Cache Lookup
## Overview
Mask Cache Lookup looks up occupancy information in a 3D boolean grid for a set of 3D points, converting world coordinates to grid indices [S1, unofficial]. It differs from [Point-in-Box Inclusion Test](1400-point-in-box-inclusion-test.md) by using a discrete grid structure rather than continuous bounding volumes, and from [Voxel Filled Check](1705-voxel-filled-check.md) by explicitly handling the coordinate transformation and bounds checking in a single pass [G].
## How it works
**Inputs:**
- `world`: 3D boolean grid of shape `(sz_i, sz_j, sz_k)` [S1, unofficial].
- `xyz`: Array of shape `(n_pts, 3)` containing world coordinates $(x, y, z)$ for $n_{pts}$ points [S1, unofficial].
- `xyz2ijk_scale`: Array of shape `(3)` containing scaling factors $(s_x, s_y, s_z)$ [S1, unofficial].
- `xyz2ijk_shift`: Array of shape `(3)` containing shift offsets $(t_x, t_y, t_z)$ [S1, unofficial].

**Outputs:**
- `out`: Boolean array of shape `(n_pts)`, where `out[i]` is true if the $i$-th point is inside an occupied voxel [S1, unofficial].

**Data Structures:**
- The `world` grid is stored in row-major order [S1, unofficial].
- The linear index for a voxel at $(i, j, k)$ is calculated as $i \cdot sz_j \cdot sz_k + j \cdot sz_k + k$ [S1, unofficial].

**Algorithm:**
1. For each point $p$ with world coordinates $(x, y, z)$ in `xyz`:
   a. Calculate grid indices $(i, j, k)$ using the scale and shift parameters: $i = \text{round}(x \cdot s_x + t_x)$, $j = \text{round}(y \cdot s_y + t_y)$, $k = \text{round}(z \cdot s_z + t_z)$ [S1, unofficial].
   b. Check bounds: $0 \le i < sz_i$, $0 \le j < sz_j$, $0 \le k < sz_k$ [S1, unofficial].
   c. If in bounds, lookup the boolean value: `out[p] = world[i * sz_j * sz_k + j * sz_k + k]` [S1, unofficial].
   d. If out of bounds, set `out[p]` to `False` [G].

**Pseudocode:**
```python
def mask_cache_lookup(world, xyz, xyz2ijk_scale, xyz2ijk_shift, sz_i, sz_j, sz_k):
    n_pts = xyz.shape[0]
    out = [False] * n_pts
    stride_jk = sz_j * sz_k
    stride_k = sz_k
    for p in range(n_pts):
        x, y, z = xyz[p, 0], xyz[p, 1], xyz[p, 2]
        i = round(x * xyz2ijk_scale[0] + xyz2ijk_shift[0])
        j = round(y * xyz2ijk_scale[1] + xyz2ijk_shift[1])
        k = round(z * xyz2ijk_scale[2] + xyz2ijk_shift[2])
        if 0 <= i < sz_i and 0 <= j < sz_j and 0 <= k < sz_k:
            out[p] = world[i * stride_jk + j * stride_k + k]
    return out
```

**Parameters:**
- `sz_i`, `sz_j`, `sz_k`: Dimensions of the 3D boolean world grid [S1, unofficial].

**Edge Cases:**
- Points outside the grid bounds result in `False` [G].
- Precision issues in coordinate transformation may cause points near voxel boundaries to be assigned to incorrect voxels if rounding is not handled consistently with the grid generation [G].

## Subtopics

### CPU-side 3D Boolean Grid
A variant where the occupancy grid is stored and accessed on the CPU using nested vectors (`vector<vector<vector<bool>>>`) [S2, unofficial]. The grid is iterated explicitly to transfer occupancy data to chunks: `c.filled[i][j][k] = Grid[i][j][k]` for `i`, `j`, `k` from `0` to `dim` [S2, unofficial]. The resolution `dim` sets grid resolution with typical values of 32, 64, 128, 256, 512, where higher values increase computation time [S2, unofficial].

### Mask Cache Lookup with Ray Bounding Box Check
A variant that checks whether rays intersect with the currently solved coarse geometry mask [S3, unofficial]. It reshapes ray origins and directions to `[-1, 3]` and makes them contiguous, then calculates step distance as `stepsize * voxel_size` [S3, unofficial]. It calls `render_utils_cuda.sample_pts_on_rays` to obtain ray points, a bounding box mask, and ray IDs [S3, unofficial]. It identifies points inside the bounding box, initializes a boolean hit tensor of length `len(rays_o)`, and marks rays as hit if the corresponding query points are inside the bounding box and pass the mask cache check [S3, unofficial].
