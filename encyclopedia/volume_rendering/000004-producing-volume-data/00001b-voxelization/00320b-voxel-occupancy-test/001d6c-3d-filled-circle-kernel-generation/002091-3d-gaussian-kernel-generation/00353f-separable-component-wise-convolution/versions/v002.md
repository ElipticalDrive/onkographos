# Separable Component-Wise Convolution

Also called: Separable component-wise convolution on decomposed low-rank tensor

## Overview
Separable Component-Wise Convolution is a method for applying 3D Gaussian smoothing to volumes represented as decomposed low-rank tensors, enabling spectrum limiting in coarse-to-fine training schedules without reconstructing the full 3D volume [S1, unofficial]. It differs from traditional separated kernel convolution by exploiting the separability of the input signal's tensor components rather than just the kernel, thereby preserving the space compression advantage of the low-rank representation [S1, unofficial].

## How it works
**Inputs and Outputs:**
*   **Input:** A decomposed low-rank tensor volume $T$ of rank $R$, defined by vector components $\tilde{v}$ and matrix components $\tilde{M}$ for each rank $r \in \{1, \dots, R\}$. The volume has spatial dimensions $I, J, K$. A 3D Gaussian kernel $N_{3d}$, defined as the outer product of 1D and 2D kernels ($N_{3d} = N_{1d} \otimes N_{2d}$).
*   **Output:** The convoluted tensor volume $\tilde{T}_\sigma$ (for density) or $\tilde{T}_c$ (for color), represented in the same decomposed low-rank format.

**Data Structures:**
The input tensor is stored as a list of $R$ components. Each component $r$ consists of:
*   $\tilde{v}_{r}^X$: A vector of size $I$ (along X-axis).
*   $\tilde{M}_{r}^{Y,Z}$: A matrix of size $J \times K$ (along Y,Z plane).
*   $\tilde{v}_{r}^Y$: A vector of size $J$ (along Y-axis).
*   $\tilde{M}_{r}^{X,Z}$: A matrix of size $I \times K$ (along X,Z plane).
*   $\tilde{v}_{r}^Z$: A vector of size $K$ (along Z-axis).
*   $\tilde{M}_{r}^{X,Y}$: A matrix of size $I \times J$ (along X,Y plane).

**Steps:**
1.  **Decompose:** Ensure the input volume $T$ is represented in the decomposed low-rank format with $R$ components.
2.  **Convolve Components:** For each rank $r$ from $1$ to $R$:
    *   Apply 1D Gaussian convolution ($N_{1d}$) to each vector component ($\tilde{v}_{r}^X, \tilde{v}_{r}^Y, \tilde{v}_{r}^Z$). Let the results be $\tilde{v}_{\sigma,r}^X, \tilde{v}_{\sigma,r}^Y, \tilde{v}_{\sigma,r}^Z$.
    *   Apply 2D Gaussian convolution ($N_{2d}$) to each matrix component ($\tilde{M}_{r}^{Y,Z}, \tilde{M}_{r}^{X,Z}, \tilde{M}_{r}^{X,Y}$). Let the results be $\tilde{M}_{\sigma,r}^{Y,Z}, \tilde{M}_{\sigma,r}^{X,Z}, \tilde{M}_{\sigma,r}^{X,Y}$.
    *   *Note:* The 2D convolution is assumed to be separated into two 1D convolutions for computational efficiency.
3.  **Reconstruct (Density):** Compute the convoluted density tensor $\tilde{T}_\sigma$ using the following identity (Theorem 4):
    $$ \tilde{T}_\sigma = \sum_{r=1}^{R} \left( \tilde{v}_{\sigma,r}^X \otimes \tilde{M}_{\sigma,r}^{Y,Z} + \tilde{v}_{\sigma,r}^Y \otimes \tilde{M}_{\sigma,r}^{X,Z} + \tilde{v}_{\sigma,r}^Z \otimes \tilde{M}_{\sigma,r}^{X,Y} \right) $$
    where $\otimes$ denotes the outer product.
4.  **Reconstruct (Color):** For color fields, combine the convoluted components with basis vectors $b_r$ to form $\tilde{T}_c$:
    $$ \tilde{T}_c = \sum_{r=1}^{R} \left( \tilde{v}_{c,r}^X \otimes \tilde{M}_{c,r}^{Y,Z} \otimes b_r + \tilde{v}_{c,r}^Y \otimes \tilde{M}_{c,r}^{X,Z} \otimes b_r + \tilde{v}_{c,r}^Z \otimes \tilde{M}_{c,r}^{X,Y} \otimes b_r \right) $$
    The spectral restricted color field is then obtained as $\vec{F}_c(x, \vec{d}) = S(\tilde{T}_c(x), \vec{d})$, where $S$ is a spectral function.

**Pseudocode:**
```python
def separable_component_wise_convolution(tensor_components, kernel_1d, kernel_2d):
    """
    Performs separable component-wise convolution on a decomposed low-rank tensor.
    
    Args:
        tensor_components: List of R components. Each component is a dict with keys:
            'vX': array of size I
            'M_YZ': array of size JxK
            'vY': array of size J
            'M_XZ': array of size IxK
            'vZ': array of size K
            'M_XY': array of size IxJ
        kernel_1d: 1D Gaussian kernel array.
        kernel_2d: 2D Gaussian kernel array.
        
    Returns:
        convoluted_components: List of R components in the same structure, 
        representing the convoluted tensor.
    """
    convoluted_components = []
    
    for r in range(len(tensor_components)):
        comp = tensor_components[r]
        
        # Convolve vector components with 1D kernel
        vX_conv = convolve_1d(comp['vX'], kernel_1d)
        vY_conv = convolve_1d(comp['vY'], kernel_1d)
        vZ_conv = convolve_1d(comp['vZ'], kernel_1d)
        
        # Convolve matrix components with 2D kernel
        # Assuming 2D convolution is implemented as two 1D convolutions
        M_YZ_conv = convolve_2d(comp['M_YZ'], kernel_2d)
        M_XZ_conv = convolve_2d(comp['M_XZ'], kernel_2d)
        M_XY_conv = convolve_2d(comp['M_XY'], kernel_2d)
        
        convoluted_components.append({
            'vX': vX_conv,
            'M_YZ': M_YZ_conv,
            'vY': vY_conv,
            'M_XZ': M_XZ_conv,
            'vZ': vZ_conv,
            'M_XY': M_XY_conv
        })
        
    return convoluted_components

def convolve_1d(signal, kernel):
    """Standard 1D convolution."""
    # Implementation details of 1D convolution are assumed standard
    # Padding and boundary conditions should be handled consistently
    # with the kernel definition.
    result = [0] * len(signal)
    k_len = len(kernel)
    half_k = k_len // 2
    for i in range(len(signal)):
        acc = 0.0
        for j in range(k_len):
            idx = i - half_k + j
            if 0 <= idx < len(signal):
                acc += signal[idx] * kernel[j]
            else:
                # Boundary handling: assume zero-padding or replication
                # Not specified in source, using zero-padding as common default [G]
                acc += 0.0 * kernel[j]
        result[i] = acc
    return result

def convolve_2d(matrix, kernel):
    """2D convolution implemented as two 1D convolutions."""
    # Convolve along rows
    rows, cols = matrix.shape
    row_conv = [[0.0] * cols for _ in range(rows)]
    for r in range(rows):
        row_conv[r] = convolve_1d(matrix[r], kernel)
        
    # Convolve along columns
    col_conv = [[0.0] * cols for _ in range(rows)]
    for c in range(cols):
        col = [row_conv[r][c] for r in range(rows)]
        col_result = convolve_1d(col, kernel)
        for r in range(rows):
            col_conv[r][c] = col_result[r]
            
    return col_conv
```

**Parameters:**
*   $R$: Rank of the decomposed tensor. Typical values depend on the desired accuracy and compression ratio.
*   $L_N$: Size of the 1D Gaussian kernel in each dimension. Not given in the sources.
*   $I, J, K$: Spatial dimensions of the volume.

**Edge Cases and Pitfalls:**
*   **Naive Convolution:** Applying 3D convolution directly to the reconstructed volume destroys the space compression advantage, resulting in time complexity $O(I \cdot J \cdot K \cdot L_N^3)$ and space complexity $O(I \cdot J \cdot K)$ [S1, unofficial].
*   **Boundary Conditions:** The pseudocode assumes zero-padding for boundary conditions, but the source does not specify the exact boundary handling. Implementers must choose a consistent strategy (e.g., replication, reflection) [G].
*   **Kernel Separability:** The method relies on the 3D Gaussian kernel being separable into $N_{1d} \otimes N_{2d}$. If the kernel is not separable, this method cannot be applied directly [S1, unofficial].

## Operating characteristics
*   **Time Complexity:** The time complexity for computing the convoluted components is $O(I \cdot J \cdot L_N + J \cdot K \cdot L_N + K \cdot I \cdot L_N)$, assuming the 2D Gaussian convolution on matrix components is separated into 1D convolutions. The time complexity for each query sample is $O(R)$ [S1, unofficial].
*   **Space Complexity:** The space complexity is $O(R \cdot (I + J \cdot K + J + I \cdot K + K + I \cdot J))$ to store the decomposed components, which is significantly less than the $O(I \cdot J \cdot K)$ required for the full 3D volume [S1, unofficial].
*   **Comparison:** Traditional separated kernel convolution only separates the 3D kernel without utilizing the input signal's separability, requiring three sequential 1D convolutions on the 3D volume with time complexity $O(I \cdot J \cdot K \cdot L_N)$ and space complexity $O(I \cdot J \cdot K)$ [S1, unofficial].
*   **Strengths:** Preserves space compression of low-rank tensors; computationally efficient for large volumes; suitable for coarse-to-fine training schedules.
*   **Limitations:** Requires the input to be in decomposed low-rank format; relies on kernel separability; accuracy depends on the rank $R$.

## Background
The method was proposed in the context of improving robustness for joint optimization of camera poses and decomposed low-rank tensorial radiance fields [S1, unofficial]. It addresses the issue of suboptimal reconstruction quality and inaccurate poses caused by the lack of internal bias that limits the spectrum of the learned signal. The method leverages an identity (Theorem 4) to distribute 3D Gaussian convolution across individual components of the decomposed low-rank tensor, enabling efficient filtering of 3D radiance fields [S1, unofficial].
