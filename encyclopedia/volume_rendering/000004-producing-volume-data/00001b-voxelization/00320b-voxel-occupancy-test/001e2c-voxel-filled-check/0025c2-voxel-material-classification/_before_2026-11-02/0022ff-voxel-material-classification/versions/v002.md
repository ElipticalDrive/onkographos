# Voxel Material Classification

Also called: ClassifyVoxel

## Overview
Voxel Material Classification determines the physical interaction type of a voxel by unpacking its packed integer representation and mapping it to a discrete collision status [S1, unofficial]. It solves the problem of efficiently querying voxel behavior (solid, liquid, or air) for physics and rendering pipelines without storing redundant metadata [S1, unofficial].

## How it works
**Inputs and Outputs:**
- Input: A single 32-bit unsigned integer (`uint32_t`) representing a packed voxel [S1, unofficial].
- Output: An enumeration `CollisionSampleStatus` with values `KnownAir`, `KnownSolid`, `KnownLiquid`, or `UnknownBlocked` [S1, unofficial].

**Data Structures:**
The method delegates material extraction to a helper function `Utils::UnpackMaterial`, which accepts the packed `uint32_t` voxel and returns a `uint8_t` material identifier [S1, unofficial].

**Steps:**
1. Unpack the material identifier from the packed voxel using `Utils::UnpackMaterial` [S1, unofficial].
2. If the unpacked material equals `Utils::Material::Air`, return `KnownAir` [S1, unofficial].
3. If the unpacked material equals `Utils::Material::Water`, `Utils::Material::Lava`, or `Utils::Material::Oil`, return `KnownLiquid` [S1, unofficial].
4. For any other material value, return `KnownSolid` [S1, unofficial].

**Pseudocode:**
```python
def classify_voxel(voxel: int) -> int:
    # Unpack material type from packed voxel data (provided by engine) [G]
    material = Utils.unpack_material(voxel)
    if material == Utils.Material.Air:
        return CollisionSampleStatus.KnownAir
    if material in (Utils.Material.Water, Utils.Material.Lava, Utils.Material.Oil):
        return CollisionSampleStatus.KnownLiquid
    return CollisionSampleStatus.KnownSolid
```

**Edge Cases and Pitfalls:**
- Unknown Materials: Any material ID not explicitly listed as Air or Liquid defaults to Solid [S1, unofficial].
- Unpack Implementation: The correctness of classification depends entirely on `Utils::UnpackMaterial` correctly extracting the material field from the packed voxel [G].

## Subtopics

## Operating characteristics
The time complexity is $O(1)$ per voxel, involving a single unpack call and a few integer comparisons [G]. The memory complexity is $O(1)$, with no additional memory allocated per call [G]. The method offers extremely fast execution, making it suitable for real-time physics and collision detection loops where latency is critical [G]. The method is limited to three broad categories (Air, Liquid, Solid) and does not resolve granular material properties [G].

## Background
This method is part of the voxel rendering pipeline described in the `asajid2-cell/voxelrender` repository [S1, unofficial]. It serves as a foundational step for chunk generation and simulation tests, ensuring that voxels are correctly categorized before further processing [S1, unofficial].
