# Sample Uniform and Occupied Cells


## Overview
This method generates a mixed set of voxel indices for volume rendering by combining uniformly sampled cells with cells known to be occupied by geometry. It addresses the need to balance exploration of empty space with focused sampling of visible geometry, filtering out cells with invalid density values (specifically -1) [S1, unofficial]. It differs from pure uniform sampling by ensuring coverage of occupied regions, and from exhaustive occupancy iteration by limiting the total sample count to a fixed budget $n$ per level [S1, unofficial].

## How it works
**Inputs:**
- `self.levels`: Integer, number of resolution levels in the grid hierarchy.
- `self.cells_per_lvl`: Integer, number of voxels per level (assumed constant across levels for this implementation).
- `self.device`: Target device for tensor operations (e.g., CUDA).
- `n`: Integer, number of samples to generate per level.
- `self.occs`: 1D tensor of shape `(total_voxels,)`, containing density or occupancy values. Cells with value `-1` are considered invalid/empty.
- `self.binaries`: List of 2D tensors, one per level. `self.binaries[lvl]` is a boolean or integer tensor representing the occupancy mask for level `lvl`.

**Outputs:**
- `lvl_indices`: List of 1D tensors. `lvl_indices[lvl]` contains `n` linear indices for level `lvl`.

**Data Structures:**
- Linear index calculation: $idx = lvl \times cells\_per\_lvl + local\_idx$.
- Invalid density marker: `-1` [S1, unofficial].

**Steps:**
1. Initialize an empty list `lvl_indices`.
2. Iterate `lvl` from `0` to `self.levels - 1`:
    a. Generate `n` random integers in range `[0, self.cells_per_lvl)` using a uniform distribution. Store as `uniform_indices` [S1, unofficial].
    b. Compute global linear indices for these uniform samples:
       $$cell\_ids = lvl \times self.cells\_per\_lvl + uniform\_indices$$
    c. Filter `uniform_indices` to keep only those where `self.occs[cell_ids] >= 0.0`. Let the filtered count be $k$.
    d. Retrieve all occupied indices for the current level:
       $$occupied\_indices = \text{nonzero}(\text{flatten}(self.binaries[lvl]))[:, 0]$$
       Let the count of occupied indices be $m$.
    e. **Pseudocode:**
```python
def sample_uniform_and_occupied_cells(self, n):
    lvl_indices = []
    for lvl in range(self.levels):
        # 1. Generate uniform samples
        uniform_indices = torch.randint(self.cells_per_lvl, (n,), device=self.device)
        
        # 2. Compute global IDs for uniform samples
        cell_ids = lvl * self.cells_per_lvl + uniform_indices
        
        # 3. Filter uniform samples based on occupancy/density
        # Keep indices where density is not -1
        valid_mask = self.occs[cell_ids] >= 0.0
        uniform_indices = uniform_indices[valid_mask]
        
        # 4. Get all occupied indices for this level
        # Assuming self.binaries[lvl] is a tensor where non-zero/True indicates occupancy
        occupied_flat = self.binaries[lvl].flatten()
        occupied_indices = torch.nonzero(occupied_flat).squeeze(1)
        
        # 5. Select occupied indices
        num_occupied = len(occupied_indices)
        if n < num_occupied:
            # Select n random indices from occupied_indices
            selected_occupied = occupied_indices[torch.randint(num_occupied, (n,), device=self.device)]
        else:
            # Take all occupied indices
            selected_occupied = occupied_indices
            
        # 6. Concatenate
        indices = torch.cat([uniform_indices, selected_occupied], dim=0)
        
        # 7. Append to results
        lvl_indices.append(indices)
        
    return lvl_indices
```

**Edge Cases:**
- **Empty Level:** If `self.binaries[lvl]` has no occupied cells, `occupied_indices` is empty. The result contains only filtered uniform samples.
- **All Invalid Density:** If `self.occs` contains only `-1`, `uniform_indices` becomes empty. The result contains only occupied indices.
- **Precision:** `torch.nonzero` returns indices. Ensure `squeeze(1)` handles the case where only one index is found (shape `(1,)` vs `(1,1)`). [G]

## Subtopics

### Grid Cell Collection via Occupancy Filtering
This variant returns *all* valid cells in the grid, filtering out cells with -1 density. It does not limit the sample count to $n$. It iterates through all grid indices, computes global IDs, and filters based on `self.occs`. It is used when exhaustive coverage of visible geometry is required rather than a fixed budget [S1, unofficial].

## Operating characteristics
- **Time Complexity:** $O(L \cdot (n + M))$ where $L$ is the number of levels, $n$ is the sample budget, and $M$ is the number of occupied cells per level. Generating random indices is $O(n)$. Filtering is $O(n)$. Finding occupied indices is $O(V)$ where $V$ is voxels per level (via `nonzero`). Selection is $O(n)$.
- **Memory Complexity:** $O(n + M)$ per level to store the resulting indices.
- **Performance:** Efficient on GPU due to vectorized tensor operations (`torch.randint`, `torch.nonzero`). [S1, unofficial]
- **Strengths:** Ensures occupied regions are sampled; balances uniform exploration with geometry focus.
- **Limitations:** The total number of samples per level is not strictly $n$ (it is $k + \min(n, M)$). If $M$ is very large, memory usage for `occupied_indices` can be high.

## Background
This method is part of the `faster-occgrid` implementation, designed for efficient volume rendering using occupancy grids. It leverages PyTorch tensor operations for GPU acceleration. The approach is common in neural radiance fields (NeRF) and occupancy grid-based rendering where balancing sample efficiency and coverage is critical. [S1, unofficial]
