# Sample Uniform and Occupied Cells
## Overview
This method generates a mixed set of voxel indices for volume rendering by combining uniformly sampled cells with cells known to be occupied by geometry [S1, unofficial]. It filters out cells with invalid density values (specifically -1) [S1, unofficial].

## How it works
**Inputs:**
- `self.levels`: Integer, number of resolution levels in the grid hierarchy [S1, unofficial].
- `self.cells_per_lvl`: Integer, number of voxels per level [S1, unofficial].
- `self.occs`: 1D array/tensor of density or occupancy values [S1, unofficial].
- `self.binaries`: List of arrays/tensors, one per level, representing occupancy masks [S1, unofficial].
- `n`: Integer, number of uniform samples to generate per level [S1, unofficial].
- `self.device`: Target device for computation [S1, unofficial].

**Outputs:**
- `lvl_indices`: List of 1D arrays/tensors, one per level, containing linear indices [S1, unofficial].

**Data Structures:**
- Linear index calculation: $idx = lvl \times cells\_per\_lvl + local\_idx$ [S1, unofficial].
- Cells with value `-1` are considered invalid/empty [S1, unofficial].

**Steps:**
1. Initialize `lvl_indices` as an empty list [S1, unofficial].
2. For each `lvl` in `range(self.levels)`:
    a. Generate `n` random integers in range `[0, self.cells_per_lvl)` using a uniform distribution [S1, unofficial].
    b. Compute global linear indices for these uniform samples: $cell\_ids = lvl \times self.cells\_per\_lvl + uniform\_indices$ [S1, unofficial].
    c. Filter `uniform_indices` to keep only those where `self.occs[cell_ids] >= 0.0` [S1, unofficial].
    d. Retrieve all occupied indices for the current level by flattening `self.binaries[lvl]` and collecting indices where the value is non-zero [S1, unofficial].
    e. Let $m$ be the number of occupied indices [S1, unofficial]. If $n < m$, select $n$ random indices from `occupied_indices` using a uniform random integer generator over `[0, m)` [S1, unofficial]. Otherwise, use all `occupied_indices` [S1, unofficial].
    f. Concatenate the filtered `uniform_indices` and the selected `occupied_indices` [S1, unofficial].
    g. Append the concatenated array to `lvl_indices` [S1, unofficial].
3. Return `lvl_indices` [S1, unofficial].

**Pseudocode:**
```python
def sample_uniform_and_occupied_cells(self, n):
    lvl_indices = []
    for lvl in range(self.levels):
        # 1. Generate n random integers in [0, self.cells_per_lvl)
        uniform_indices = [random.randint(0, self.cells_per_lvl - 1) for _ in range(n)]
        
        # 2. Compute global linear indices
        cell_ids = [lvl * self.cells_per_lvl + idx for idx in uniform_indices]
        
        # 3. Filter uniform samples where density >= 0.0
        uniform_indices = [idx for idx, cid in zip(uniform_indices, cell_ids) if self.occs[cid] >= 0.0]
        
        # 4. Get all occupied indices for this level
        occupied_indices = [i for i, v in enumerate(self.binaries[lvl].flatten()) if v != 0]
        
        # 5. Select occupied indices
        if n < len(occupied_indices):
            selected = [random.randint(0, len(occupied_indices) - 1) for _ in range(n)]
            occupied_subset = [occupied_indices[i] for i in selected]
        else:
            occupied_subset = occupied_indices
            
        # 6. Concatenate
        indices = uniform_indices + occupied_subset
        
        # 7. Append to results
        lvl_indices.append(indices)
        
    return lvl_indices
```

**Edge Cases:**
- **Empty Level:** If `self.binaries[lvl]` has no occupied cells, `occupied_indices` is empty and the result contains only filtered uniform samples [S1, unofficial].
- **All Invalid Density:** If `self.occs` contains only `-1`, `uniform_indices` becomes empty and the result contains only occupied indices [S1, unofficial].
- **Selection with Replacement:** `torch.randint` (or equivalent uniform integer generator) selects indices with replacement, meaning the same occupied cell may be sampled multiple times [S1, unofficial].

## Subtopics

### Grid Cell Collection via Occupancy Filtering
This variant returns all valid cells in the grid, filtering out cells with -1 density [S1, unofficial]. It does not limit the sample count to $n$ [S1, unofficial]. It iterates through all grid indices, computes global IDs via $cell\_ids = lvl \times self.cells\_per\_lvl + self.grid\_indices$, and filters based on `self.occs[cell_ids] >= 0.0` [S1, unofficial]. It initializes an empty list, appends the filtered indices for each level, and returns the list [S1, unofficial].
