# Support Below Search

Also called: FindSupportBelow

## Overview
Support Below Search determines if a voxel position has structural support directly beneath it within a specified vertical drop distance [S1, unofficial]. It solves the problem of identifying valid standing positions for entities or objects in a voxel world by finding the first non-empty voxel (solid, liquid, or blocked unknown) below a given footprint [S1, unofficial]. It differs from [Sparse AABB Sweep Test](5413-sparse-aabb-sweep-test.md) by iterating through a defined volume to find the *first* support rather than sweeping for *any* collision along a path, and builds on [Sparse AABB Collision Test](3047-sparse-aabb-collision-test.md) by utilizing its collision sample semantics [G].

## How it works
**Inputs:**
- `footprintAabb`: A `SparseCollisionAabb` defining the XZ bounds of the search area and the starting Y coordinate [S1, unofficial].
- `maxDrop`: A float specifying the maximum downward distance to search [S1, unofficial].
- `liquidsSupport`: A boolean indicating whether liquid voxels count as valid support [S1, unofficial].

**Outputs:**
- A result structure containing:
  - `found`: Boolean indicating if support was found [S1, unofficial].
  - `supportX`, `supportY`, `supportZ`: The voxel coordinates of the found support [S1, unofficial].
  - `voxel`: The voxel data of the support [S1, unofficial].
  - `fromEdit`: Boolean indicating if the voxel was from an edit operation [S1, unofficial].
  - `sampledVoxels`: Count of voxels checked [S1, unofficial].
  - `solidVoxels`: Count of solid voxels checked [S1, unofficial].
  - `liquidVoxels`: Count of liquid voxels checked [S1, unofficial].

**Data Structures:**
- `SparseCollisionAabb`: Defines the axis-aligned bounding box for the search footprint in X and Z, and the starting Y [S1, unofficial].
- `CollisionSample`: Returned by `SampleWithColumn`, containing `status` (enum: `KnownSolid`, `KnownLiquid`, `UnknownBlocked`), `voxel` data, and `fromEdit` flag [S1, unofficial].
- `colHeight` / `colRelief`: Precomputed per-column terrain height and relief arrays for the XZ footprint, used to optimize sampling [S1, unofficial].

**Parameters:**
- `kMaxCollisionSupportSamples`: Constant `uint64_t` set to 32768, limiting the maximum number of samples to prevent infinite loops or excessive computation [S1, unofficial].

**Steps:**
1. Validate that the footprint AABB bounds are finite and `maxDrop >= 0.0f`. If invalid, return an empty result [S1, unofficial].
2. Convert the footprint's X and Z bounds to voxel indices (`minX`, `maxX`, `minZ`, `maxZ`). Convert the Y bounds to voxel indices, calculating `startY` from the AABB and `endY = startY - maxDrop` [S1, unofficial].
3. Check if `endY > startY` or if the total sample count would exceed `kMaxCollisionSupportSamples`. If so, return an empty result [S1, unofficial].
4. Precompute per-column terrain height and relief for the XZ footprint [S1, unofficial].
5. Iterate Y from `startY` down to `endY`. For each Y, iterate Z from `minZ` to `maxZ`, and X from `minX` to `maxX` [S1, unofficial].
6. Sample the voxel at `(x, y, z)` using `SampleWithColumn`, passing the precomputed column height and relief [S1, unofficial].
7. Increment `result.sampledVoxels` [S1, unofficial].
8. If `sample.status` is `KnownSolid`: increment `result.solidVoxels`, set `result.found = true`, record `supportX`, `supportY`, `supportZ`, `voxel`, and `fromEdit`, then return the result [S1, unofficial].
9. If `sample.status` is `KnownLiquid`: increment `result.liquidVoxels`. If `liquidsSupport` is true, set `result.found = true`, record `supportX`, `supportY`, `supportZ`, `voxel`, and `fromEdit`, then return the result [S1, unofficial].
10. If `sample.status` is `UnknownBlocked`: set `result.found = true`, record `supportX`, `supportY`, `supportZ`, `voxel`, and `fromEdit`, then return the result [S1, unofficial].
11. If the loop completes without finding support, return an empty result [S1, unofficial].

**Pseudocode:**
```python
import math

def support_below_search(footprint_aabb, max_drop, liquids_support):
    # 1. Validate inputs
    if not all(math.isfinite(v) for v in [footprint_aabb.min_x, footprint_aabb.max_x, footprint_aabb.min_y, footprint_aabb.max_y, footprint_aabb.min_z, footprint_aabb.max_z]) or max_drop < 0.0:
        return {'found': False, 'sampledVoxels': 0, 'solidVoxels': 0, 'liquidVoxels': 0, 'supportX': 0, 'supportY': 0, 'supportZ': 0, 'voxel': None, 'fromEdit': False}

    # 2. Convert bounds to voxel indices
    start_y = footprint_aabb.start_y
    end_y = start_y - max_drop
    min_x = math.floor(footprint_aabb.min_x)
    max_x = math.ceil(footprint_aabb.max_x)
    min_z = math.floor(footprint_aabb.min_z)
    max_z = math.ceil(footprint_aabb.max_z)

    # 3. Check limits
    if end_y > start_y:
        return {'found': False, 'sampledVoxels': 0, 'solidVoxels': 0, 'liquidVoxels': 0, 'supportX': 0, 'supportY': 0, 'supportZ': 0, 'voxel': None, 'fromEdit': False}
    
    span_x = max_x - min_x + 1
    span_z = max_z - min_z + 1
    span_y = start_y - end_y + 1
    total_samples = span_x * span_z * span_y
    
    if total_samples > 32768:
        return {'found': False, 'sampledVoxels': 0, 'solidVoxels': 0, 'liquidVoxels': 0, 'supportX': 0, 'supportY': 0, 'supportZ': 0, 'voxel': None, 'fromEdit': False}

    # 4. Precompute column data
    # Precompute per-column terrain height and relief for the XZ footprint [S1, unofficial]
    col_height = [0.0] * (span_x * span_z)
    col_relief = [0.0] * (span_x * span_z)

    result = {
        'found': False,
        'sampledVoxels': 0,
        'solidVoxels': 0,
        'liquidVoxels': 0,
        'supportX': 0,
        'supportY': 0,
        'supportZ': 0,
        'voxel': None,
        'fromEdit': False
    }

    # 5. Iterate Y, Z, X
    for y in range(start_y, end_y - 1, -1):
        for z in range(min_z, max_z + 1):
            for x in range(min_x, max_x + 1):
                # Calculate index for column data
                idx = (x - min_x) + (z - min_z) * span_x
                
                # 6. Sample voxel
                # Sample the voxel at (x, y, z) using SampleWithColumn, passing the precomputed column height and relief [S1, unofficial]
                # Implementation not given in sources
                sample = {'status': 'Unknown', 'voxel': None, 'from_edit': False}
                result['sampledVoxels'] += 1

                # 7. Check KnownSolid
                if sample['status'] == 'KnownSolid':
                    result['solidVoxels'] += 1
                    result['found'] = True
                    result['supportX'] = x
                    result['supportY'] = y
                    result['supportZ'] = z
                    result['voxel'] = sample['voxel']
                    result['fromEdit'] = sample['from_edit']
                    return result

                # 8. Check KnownLiquid
                if sample['status'] == 'KnownLiquid':
                    result['liquidVoxels'] += 1
                    if liquids_support:
                        result['found'] = True
                        result['supportX'] = x
                        result['supportY'] = y
                        result['supportZ'] = z
                        result['voxel'] = sample['voxel']
                        result['fromEdit'] = sample['from_edit']
                        return result

                # 9. Check UnknownBlocked
                if sample['status'] == 'UnknownBlocked':
                    result['found'] = True
                    result['supportX'] = x
                    result['supportY'] = y
                    result['supportZ'] = z
                    result['voxel'] = sample['voxel']
                    result['fromEdit'] = sample['from_edit']
                    return result

    # 11. No support found
    return result
```

**Edge Cases and Pitfalls:**
- Invalid bounds or sample limit exceeded return immediately without sampling [S1, unofficial].
- Boundary precision uses `nextafter` implicitly via `TryBuildVoxelRange` [S1, unofficial].

## Operating characteristics
**Time Complexity:** Not given in the sources.
**Memory Complexity:** Not given in the sources.
**Strengths:** Efficiently finds the first support below a position; handles liquids and unknown blocks as configurable support types [S1, unofficial].
**Limitations:** Limited by `kMaxCollisionSupportSamples` (32768); may miss support if the drop distance is too large or the footprint is too wide [S1, unofficial].
**When to use:** When determining if an entity can stand on terrain below a specific position [G].
**When not to use:** When sweeping for any collision along a path is required (use [Sparse AABB Sweep Test](5413-sparse-aabb-sweep-test.md)) [G].
