# Morphological Dilation

Also called: Dilate

## Overview
Morphological dilation expands the set of foreground voxels in a voxel grid by incorporating neighboring voxels based on a defined connectivity kernel [S1, unofficial]. The operation iterates through internal voxels, checks their neighborhood according to a connectivity flag, and updates the grid where a dilation condition is met [S1, unofficial].

## How it works
**Inputs:**
- A 3D voxel grid represented as a 1D array of size $N = D_x \times D_y \times D_z$, where foreground voxels are marked as `1` and background as `0` [S1, unofficial].
- A connectivity parameter `is26` (boolean) determining the neighborhood definition [S1, unofficial].

**Outputs:**
- The updated voxel grid where foreground regions have expanded into adjacent background voxels [S1, unofficial].

**Data Structures:**
- **Voxel Grid:** A 1D array of integers (or bits) representing the volume, indexed linearly as $i + j \cdot D_x + k \cdot D_x \cdot D_y$ [S1, unofficial].
- **Neighbor Offsets:** An array of integer offsets `k` [S1, unofficial].
    - For **6-connectivity** (`is26 = false`): Contains 6 offsets corresponding to face neighbors: $\pm 1$, $\pm D_x$, $\pm D_x \cdot D_y$ [S1, unofficial].
    - For **26-connectivity** (`is26 = true`): Contains 26 offsets corresponding to all neighbors in a $3 \times 3 \times 3$ cube excluding the center $(0,0,0)$, generated by iterating $x, y, z \in \{-1, 0, 1\}$ and excluding $(0,0,0)$ [S1, unofficial].

**Algorithm Steps:**
1. Generate the neighbor offsets array based on the `is26` flag [S1, unofficial].
2. Initialize a binary mask array of the same size as the input grid, filled with zeros [S1, unofficial].
3. Iterate through all internal voxels. The iteration range for each dimension $d$ is $1$ to $D_d - 2$ (inclusive) [S1, unofficial].
4. For each voxel at linear index `idx`:
    a. Iterate through each neighbor offset `n` in the offsets array.
    b. Check if the input grid value at `idx + n` is greater than `0` [S1, unofficial].
    c. If any neighbor is foreground, set `mask[idx] = 1` and break the neighbor loop [S1, unofficial].
5. Update the image: iterate through all indices, and if `mask[i] == 1`, set `grid[i] = 1` [S1, unofficial].

**Pseudocode:**
> **Unverified code.** The code below did not pass a test run against a reference implementation, or no test fits it, so it may contain errors.

```python
def morphological_dilation(grid, nx, ny, nz, is26):
    # Generate neighbor offsets for 1D array layout
    offsets = []
    if is26:
        for x in [-1, 0, 1]:
            for y in [-1, 0, 1]:
                for z in [-1, 0, 1]:
                    if x == 0 and y == 0 and z == 0:
                        continue
                    offsets.append(x + y * nx + z * nx * ny)
    else:
        offsets = [1, -1, nx, -nx, nx * ny, -nx * ny]
    
    # Initialize mask
    mask = [0] * (nx * ny * nz)
    
    # Iterate internal voxels (1 to dim-2)
    for z in range(1, nz - 1):
        for y in range(1, ny - 1):
            for x in range(1, nx - 1):
                idx = x + y * nx + z * nx * ny
                for off in offsets:
                    if grid[idx + off] > 0:
                        mask[idx] = 1
                        break
    
    # Update image where mask is 1
    for i in range(nx * ny * nz):
        if mask[i] == 1:
            grid[i] = 1
    return grid
```

**Parameters:**
- `is26`: Boolean. `True` for 26-connectivity (corner/edge/face neighbors), `False` for 6-connectivity (face neighbors only) [S1, unofficial].

**Edge Cases and Pitfalls:**
- **Boundary Voxels:** The algorithm explicitly iterates only internal voxels ($1$ to $dim-2$) [S1, unofficial]. Boundary voxels (indices $0$ and $dim-1$) are skipped during the dilation pass [S1, unofficial].
- **Precision:** The operation is logical and binary, so values are clamped to $0$ or $1$ [G].

### Bounding Box Expansion
Expands the bounding box of a mesh by half a voxel size in all directions to account for voxel extent [S2, unofficial].
**Steps:**
1. Retrieve the voxel size from the density field: `voxel_size = d.getVoxelSize()` [S2, unofficial].
2. Create an expansion vector: `expansion = (0.5f * voxel_size, 0.5f * voxel_size, 0.5f * voxel_size)` [S2, unofficial].
3. Subtract the expansion from the box lower bound: `box.lo = box.lo - expansion` [S2, unofficial].
4. Add the expansion to the box upper bound: `box.hi = box.hi + expansion` [S2, unofficial].

## Operating characteristics
- **Time Complexity:** $O(N \cdot K)$, where $N$ is the number of internal voxels and $K$ is the number of neighbors ($6$ or $26$) [G].
- **Memory Complexity:** $O(V)$, where $V$ is the volume of the voxel grid, for storing the output mask [G].
- **Performance:** Not given in the sources.
- **Strengths:** Simple to implement; effective for expanding discrete foreground regions [G].
- **Limitations:** Does not preserve exact geometric boundaries; boundary handling requires care to avoid edge effects [G].

## Background
Morphological dilation is a fundamental operation in mathematical morphology, originally developed for binary image processing [G]. In the context of volume rendering and voxelization, it is used to refine discrete representations of continuous meshes [G]. The specific implementation details for voxel grids, including neighbor offset generation and internal voxel iteration, are documented in community resources [S1, unofficial]. Bounding box expansion techniques are used in mesh-to-voxel conversion pipelines to ensure complete coverage [S2, unofficial].
