# Sparse Filtering (Smooth, Correlate, Morphology)

Also called: sc.filters.correlate, sc.filters.maximum, sc.filters.minimum, sc.filters.smooth

## Overview
Sparse filtering applies spatial filters—such as Gaussian smoothing, correlation, and morphological max/min operations—to sparse voxel sets with associated values [S1, unofficial]. It solves the problem of efficiently computing neighborhood aggregations on sparse data without allocating dense memory for the entire bounding box [S1, unofficial]. Unlike its sibling [Sparse Voxel Morphology (Dilate/Erode)](20127-sparse-voxel-morphology-dilate-erode.md), which modifies the geometry of the voxel set, sparse filtering computes new values for voxels while potentially expanding the support set [S1, unofficial]. It mimics the behavior of `scipy.ndimage` with `mode='constant'` and `cval=0`, treating absent voxels as zero [S1, unofficial].

## How it works
The method operates on a sparse voxel set represented as an $(N, 3)$ integer array of coordinates and an associated value array of length $N$ [S1, unofficial]. The core logic involves expanding the voxel set to cover the kernel support, computing weighted aggregations, and pruning the result [S1, unofficial].

### Inputs and Outputs
*   **Input**: `voxels`: $(N, 3)$ integer array of voxel coordinates. `values`: Array of length $N$ containing scalar values for each voxel. `sigma`: Standard deviation for Gaussian smoothing (float or length-3 array). `truncate`: Float controlling kernel support size. `epsilon`: Pruning threshold. `connectivity`: Integer (6, 18, or 26) defining neighbor adjacency [S1, unofficial].
*   **Output**: `out_voxels`: Filtered $(M, 3)$ integer array. `out_values`: Array of length $M$ containing filtered values [S1, unofficial].

### Data Structures
The implementation relies on packed 64-bit integer keys for efficient sorted-array lookups, as established in [Sparse Voxel Morphology (Dilate/Erode)](20127-sparse-voxel-morphology-dilate-erode.md) [S1, unofficial].
*   **Packed Key**: A single `int64` value encoding 3D coordinates [S1, unofficial]. Assuming 21 bits per axis, the key is constructed as:
    $$ key = (x \ll 42) + (y \ll 21) + z $$
    where $x, y, z$ are non-negative coordinates relative to a shared origin shifted by a margin [S1, unofficial].
*   **Neighbor Offsets**: Precomputed arrays of $(dx, dy, dz)$ tuples based on connectivity:
    *   6-connectivity: Face neighbors only ($|dx|+|dy|+|dz|=1$) [S1, unofficial].
    *   18-connectivity: Face and edge neighbors ($|dx|+|dy|+|dz| \le 2$) [S1, unofficial].
    *   26-connectivity: All neighbors ($|dx|+|dy|+|dz| \le 3$, excluding origin) [S1, unofficial].

### Steps
1.  **Determine Kernel Support**: Calculate the radius $r$ and support dimensions based on `sigma` and `truncate` [S1, unofficial].
2.  **Expand Voxel Set (Growth)**: Generate all voxels within distance $r$ of existing voxels [S1, unofficial]. This creates a "grown" set that includes both original voxels and empty space where values might be non-zero due to convolution [S1, unofficial].
3.  **Compute Aggregation**: For each voxel in the expanded set, compute the filtered value [S1, unofficial].
    *   **Correlation/Smooth**:
        $$ out[m] = \sum_{j} w[j] \cdot in[m+j] $$
        where $w[j]$ are kernel weights and $in[m+j]$ are values at neighbor positions [S1, unofficial]. Absent voxels contribute 0 [S1, unofficial].
    *   **Maximum/Minimum**: Compute the max/min value among all neighbors in the kernel support [S1, unofficial].
4.  **Prune**: Remove voxels from the output set if their computed value is below `epsilon` times the peak value or is exactly zero [S1, unofficial].
5.  **Return**: Output the pruned voxel coordinates and their corresponding values [S1, unofficial].

### Pseudocode
```python
import numpy as np
import math

def sparse_filter(voxels, values, sigma, truncate, epsilon=1e-4, connectivity=26):
    # Guard empty input
    if len(voxels) == 0:
        return np.empty((0, 3), dtype=np.int64), np.empty(0, dtype=values.dtype)

    # 1. Determine kernel support
    half_width = int(truncate * sigma)
    
    # Generate offsets based on connectivity (L1 distance)
    offsets = []
    for dx in range(-half_width, half_width + 1):
        for dy in range(-half_width, half_width + 1):
            for dz in range(-half_width, half_width + 1):
                if dx == 0 and dy == 0 and dz == 0:
                    continue
                l1 = abs(dx) + abs(dy) + abs(dz)
                if connectivity == 6 and l1 > 1:
                    continue
                if connectivity == 18 and l1 > 2:
                    continue
                offsets.append((dx, dy, dz))

    # Compute Gaussian weights for these offsets
    weights = []
    sigma_sq = sigma * sigma
    for dx, dy, dz in offsets:
        w = math.exp(-0.5 * (dx*dx + dy*dy + dz*dz) / sigma_sq)
        weights.append(w)
    total_w = sum(weights)
    weights = [w / total_w for w in weights]

    # 2. Expand voxel set (Growth)
    margin = half_width
    shift = np.min(voxels, axis=0) - margin
    shifted_voxels = voxels - shift
    keys = (shifted_voxels[:, 0] << 42) + (shifted_voxels[:, 1] << 21) + shifted_voxels[:, 2]
    value_map = dict(zip(keys, values))

    expanded_keys = set(keys)
    for k in keys:
        x, y, z = unpack_key(k, shift)
        for dx, dy, dz in offsets:
            nx, ny, nz = x + dx, y + dy, z + dz
            nkey = pack_key(nx, ny, nz, shift)
            expanded_keys.add(nkey)

    # 3. Compute aggregation
    out_voxels = []
    out_values = []
    peak = max(values) if len(values) > 0 else 0.0

    for k in expanded_keys:
        x, y, z = unpack_key(k, shift)
        acc = 0.0
        for i, (dx, dy, dz) in enumerate(offsets):
            nx, ny, nz = x + dx, y + dy, z + dz
            nkey = pack_key(nx, ny, nz, shift)
            acc += weights[i] * value_map.get(nkey, 0.0)

        # 4. Prune
        if acc != 0.0 and abs(acc) >= epsilon * peak:
            out_voxels.append([x, y, z])
            out_values.append(acc)

    return np.array(out_voxels), np.array(out_values)

def pack_key(x, y, z, shift):
    sx, sy, sz = x - shift[0], y - shift[1], z - shift[2]
    return (sx << 42) + (sy << 21) + sz

def unpack_key(key, shift):
    z = key & ((1 << 21) - 1)
    y = (key >> 21) & ((1 << 21) - 1)
    x = (key >> 42) & ((1 << 21) - 1)
    return x + shift[0], y + shift[1], z + shift[2]
```

### Parameters
*   **sigma**: Float or length-3 array. Gaussian standard deviation in voxels. Use `sigma / spacing` for physical units [S1, unofficial].
*   **truncate**: Float. Controls Gaussian support size. Support grows as $(2 \cdot \text{truncate} \cdot \sigma + 1)^3$ [S1, unofficial]. Lower values prune negligible tails [S1, unofficial].
*   **epsilon**: Float. Pruning threshold. Values below `epsilon` times peak are dropped [S1, unofficial]. Default pruning at $10^{-4}$ drops ~40% support with small error [S1, unofficial].
*   **connectivity**: Integer (6, 18, or 26). Defines neighbor adjacency [S1, unofficial].

### Edge Cases and Pitfalls
*   **Memory Explosion**: Most filters (smooth, correlate) grow the voxel set, potentially causing memory explosion if the bounding box is large [S1, unofficial].
*   **Minimum Filter**: `minimum` is the exception as it only shrinks support [S1, unofficial].
*   **Absent Voxels**: Treated as zero [S1, unofficial].
*   **Range Check**: Coordinates must fit within the packed key's per-axis range (21 bits) [S1, unofficial]. If the extent plus margin exceeds this, an error is raised [S1, unofficial].

## Subtopics

### Gaussian Filtering
Performs Gaussian filtering using $\sigma$ (standard deviation in physical units, default 1.0 Å); different $\sigma_x, \sigma_y, \sigma_z$ can be specified [S2]. If `invert` is true, it sharpens the map by amplifying high frequencies (opposite of smoothing) [S2]. Alternatively, width can be specified with `bfactor` $B$, where $B = 8\pi^2\sigma^2$ [S2]. `valueType` defaults to current type but supports int8/16/32, uint8/16/32, float32/64 [S2]. Sharpening with $\sigma$ values smaller than pixel size is most useful; larger values overemphasize high frequencies and amplify noise [S2]. It is fastest for data sizes that are powers of 2 and can be very slow with insufficient memory [S2]. Although it uses FFT, it does not use map periodicity; values outside boundaries are treated as zero [S2].

## Operating characteristics
*   **Time Complexity**: Sort-bound. The complexity is dominated by sorting and merging key arrays [S1, unofficial].
*   **Memory Complexity**: Proportional to the grown support volume $M$, not the bounding box volume $V$ [S1, unofficial].
*   **Performance**: On the Neuron benchmark (39.5k voxels, 29M bounding box), Sparse smooth at sigma=0.5 took 0.05s vs Dense 0.23s (4.9x faster) [S1, unofficial]. At sigma=4.0, Dense (0.74s) won over Sparse (1.58s) [S1, unofficial].
*   **Scaling**: Sparse filtering wins when $M \cdot \log M < V$, where $M$ is the grown support volume and $V$ is the bounding box volume [S1, unofficial]. Dense filtering wins when the bounding box fits in memory and is small, as scipy is C-optimized and memory-bandwidth-bound, while sparse is sort-bound [S1, unofficial].
*   **Strengths**: Efficient for sparse data with small kernels [S1, unofficial].
*   **Limitations**: Inefficient for dense data or large kernels where the support volume approaches the bounding box volume [S1, unofficial].

## Background
Provides a sparse alternative to `scipy.ndimage` functions for voxel data [S1, unofficial]. Designed to handle large, sparse voxel sets common in fields where dense grids are impractical [S1, unofficial].
