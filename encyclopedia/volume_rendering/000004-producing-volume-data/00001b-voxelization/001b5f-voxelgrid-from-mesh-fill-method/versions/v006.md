# VoxelGrid from Mesh (Fill Method)
## Overview
This method converts a triangular mesh into a dense voxel grid by computing surface occupancy and filling internal voids using morphological operations [S1, unofficial]. It differs from standard surface-only voxelization by producing a solid, filled volume representation [S1, unofficial].
## How it works
**Inputs and outputs:**
- Input: A mesh (vertices and faces) and a target resolution $(N_x, N_y, N_z)$ [S1, unofficial].
- Output: A 3D boolean array `occ` of shape $(N_x, N_y, N_z)$, where `True` indicates a filled voxel [S1, unofficial].
**Data structures:**
- `occ`: A 3D boolean array [S1, unofficial].
**Steps:**
1. **Validate Bounds**: Check if any mesh bound is outside $[-0.5, 0.5]$; raise a `ValueError` if true [S1, unofficial].
2. **Compute Surface Occupancy**: Determine which voxels intersect the mesh geometry [S1, unofficial].
3. **Fill Holes**: Apply a binary morphological fill operation to the surface occupancy grid to fill enclosed voids [S1, unofficial].

def voxelize_fill(mesh, resolution):
    bounds = mesh.get_bounds()
    if np.any(np.abs(bounds) >= 0.5):
        raise ValueError("Bounds must be within [-0.5, 0.5]")
    occ_surface = voxelize_surface(mesh, resolution)
    occ = ndimage.morphology.binary_fill_holes(occ_surface)
    return occ

**Edge cases and pitfalls:**
- Out-of-bounds mesh: The method explicitly checks for bounds outside $[-0.5, 0.5]$ and raises an error [S1, unofficial].
- Boundary precision: The validation uses `np.abs(bounds) >= 0.5`, which treats exactly $0.5$ as out of bounds [S1, unofficial].
