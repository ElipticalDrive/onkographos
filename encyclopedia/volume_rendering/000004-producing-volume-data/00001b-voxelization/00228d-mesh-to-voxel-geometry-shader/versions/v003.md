# Mesh-to-Voxel Geometry Shader

Also called: DirectX geometry shader voxelization, Mesh to voxel shaders

## Overview
The Mesh-to-Voxel Geometry Shader is a real-time DirectX technique that converts mesh objects into voxel-like cubes by iterating over integer grid positions within a triangle's bounding box and emitting explicit cube geometry for grid cells close to the triangle plane [S1, unofficial]. Unlike rasterization-based voxelization which fills pixels, this method explicitly generates the 3D geometry of every intersecting voxel, resulting in significantly higher vertex and triangle counts [S1, unofficial].

## How it works
**Inputs and Outputs:**
The method operates on a triangle primitive input in clip space [S1, unofficial]. It outputs a stream of triangle strips representing the faces of the generated voxel cubes [S1, unofficial]. The input vertex structure `appdata` contains `Position` (float3), `UV` (float4), `Normal` (float4), `Tangent` (float4), and `Binormal` (float4) [S1, unofficial]. The geometry shader output structure `geoOutput` contains `HPosition` (float4), `UV` (float2), and `Color` (float4) [S1, unofficial].

**Data Structures:**
The algorithm uses a fixed-size array `cubes` of 100 elements to store valid voxel centers and their distances [S1, unofficial]. Each element is a `float4` where the RGB components represent the integer grid coordinates $(x, y, z)$ and the W component stores the distance metric ($1 - \text{tempDist}$) [S1, unofficial].

**Parameters:**
*   `size`: Half-extent of the generated voxel cubes. Hardcoded to $0.5$ [S1, unofficial].
*   `Lamp0Pos`: World-space position of the point light source. Default: $\{-0.5, 2.0, 1.25\}$ [S1, unofficial].
*   `Lamp0Color`: Color/intensity of the point light source. Default: $\{2.0, 2.0, 2.0\}$ [S1, unofficial].

**Steps:**
1.  **Transform Vertices:** Transform the three input triangle vertices ($In[0], In[1], In[2]$) from clip space to world space using the `WorldXf` matrix to obtain $wpos1, wpos2, wpos3$ [S1, unofficial].
2.  **Calculate Bounding Box:** Compute the axis-aligned bounding box (AABB) of the triangle in world space. The minimum coordinates $(Ax, Ay, Az)$ and maximum coordinates $(Bx, By, Bz)$ are determined by comparing the world-space vertex coordinates. The source code implicitly casts float world positions to `int` variables, which truncates towards zero [S1, unofficial].
3.  **Compute Triangle Normal:** Calculate the world-space normal $wNormal$ by normalizing the cross product of two edge vectors: $edgeA = wpos2 - wpos1$ and $edgeB = wpos3 - wpos1$ [S1, unofficial].
4.  **Compute Plane Delta:** Calculate the plane constant $\delta$ using the formula:
    $$ \delta = \text{dot}(wpos1, wNormal) $$
    where $wpos1$ is a vertex on the triangle plane and $wNormal$ is the normalized plane normal [S1, unofficial].
5.  **Iterate Grid Positions:** Iterate through all integer grid positions $(x, y, z)$ within the bounding box defined by $[Ax, Bx]$, $[Ay, By]$, and $[Az, Bz]$ [S1, unofficial].
6.  **Project and Distance Check:** For each grid point $curPos = (x, y, z)$:
    *   Project $curPos$ onto the triangle plane to get $tempPos$:
        $$ tempPos = curPos + (\delta - \text{dot}(curPos, wNormal)) \times wNormal $$
    *   Calculate the Euclidean distance $tempDist$ between $curPos$ and $tempPos$:
        $$ tempDist = \text{distance}(curPos, tempPos) $$
    *   If $tempDist < 1$, proceed to check if the point is inside the triangle [S1, unofficial].
7.  **Point-in-Triangle Test:** If the distance check passes, determine if $curPos$ lies inside the triangle using a `PointInTriangle` function [S1, unofficial].
8.  **Store Valid Voxels:** If the point is inside the triangle, store the voxel center and distance in the `cubes` array. The source code stores `float4(curPos, 1 - tempDist)` [S1, unofficial].
9.  **Generate Cube Geometry:** For each valid voxel center stored in `cubes`:
    *   Define the 8 vertices of a cube with half-extent `size` ($0.5$) centered at the voxel position. The vertices are calculated as offsets from the center position [S1, unofficial].
    *   Calculate diffuse lighting for each of the 6 faces of the cube. For each face, compute the face normal via the cross product of its edges, compute the light vector from the voxel position to `Lamp0Pos`, and calculate:
        $$ diffuseValue = \max(\text{dot}(lightVector, wNormal), 0.0) $$
    *   Compute the color for each face:
        $$ couleur = Lamp0Color \times couleur \times diffuseValue $$
        where `couleur` is a uniform color $\{1, 1, 1\}$ [S1, unofficial].
    *   Assign colors to the 12 triangles forming the cube. Each triangle's color is the average of the diffuse colors of the 3 faces it belongs to, multiplied by the uniform color and light color. Alpha is hardcoded to 1 [S1, unofficial].
    *   Transform the cube vertices to clip space using `ViewIXf` (defined as a ViewProjection matrix) and append them to the `TriStream` [S1, unofficial].
10. **Restart Strip:** Call `TriStream.RestartStrip()` after processing all cubes for the input triangle to end the primitive strip [S1, unofficial].

**Pseudocode:**
```python
def mesh_to_voxel_geometry_shader(triangle_vertices_clip, world_matrix, view_proj_matrix, lamp_pos, lamp_color):
    """
    Converts a single triangle into voxel cube geometry.
    """
    # Step 1: Transform vertices to world space
    wpos1 = mul_vec_mat(triangle_vertices_clip[0], world_matrix)
    wpos2 = mul_vec_mat(triangle_vertices_clip[1], world_matrix)
    wpos3 = mul_vec_mat(triangle_vertices_clip[2], world_matrix)
    
    # Step 2: Calculate Bounding Box (Integer Truncation)
    Ax, Bx = min(int(wpos1.x), int(wpos2.x), int(wpos3.x)), max(int(wpos1.x), int(wpos2.x), int(wpos3.x))
    Ay, By = min(int(wpos1.y), int(wpos2.y), int(wpos3.y)), max(int(wpos1.y), int(wpos2.y), int(wpos3.y))
    Az, Bz = min(int(wpos1.z), int(wpos2.z), int(wpos3.z)), max(int(wpos1.z), int(wpos2.z), int(wpos3.z))
    
    # Step 3: Compute Triangle Normal
    edgeA = sub_vec(wpos2, wpos1)
    edgeB = sub_vec(wpos3, wpos1)
    wNormal = normalize(cross(edgeA, edgeB))
    
    # Step 4: Compute Plane Delta
    delta = dot(wpos1, wNormal)
    
    # Step 5-8: Iterate and Find Intersecting Voxels
    cubes = []
    for x in range(Ax, Bx + 1):
        for y in range(Ay, By + 1):
            for z in range(Az, Bz + 1):
                curPos = Vector3(x, y, z)
                tempPos = add_vec(curPos, scale_vec(wNormal, delta - dot(curPos, wNormal)))
                tempDist = distance(curPos, tempPos)
                
                if tempDist < 1.0:
                    if point_in_triangle(curPos, wpos1, wpos2, wpos3):
                        cubes.append((curPos, 1.0 - tempDist))
    
    # Step 9: Generate Cube Geometry
    output_triangles = []
    size = 0.5
    
    for voxel_center, _ in cubes:
        # Define 8 vertices relative to center
        v = [
            voxel_center + Vector3(-size, size, -size),   # pos1
            voxel_center + Vector3(-size, -size, -size),  # pos2
            voxel_center + Vector3(size, size, -size),    # pos3
            voxel_center + Vector3(size, -size, -size),   # pos4
            voxel_center + Vector3(-size, size, size),    # pos5
            voxel_center + Vector3(-size, -size, size),   # pos6
            voxel_center + Vector3(size, size, size),     # pos7
            voxel_center + Vector3(size, -size, size)     # pos8
        ]
        
        # Compute face normals and diffuse colors for 6 faces
        n1 = normalize(cross(sub_vec(v[1], v[0]), sub_vec(v[2], v[0])))
        c1 = lamp_color * max(dot(normalize(sub_vec(lamp_pos, voxel_center)), n1), 0.0)
        
        n2 = normalize(cross(sub_vec(v[6], v[2]), sub_vec(v[3], v[2])))
        c2 = lamp_color * max(dot(normalize(sub_vec(lamp_pos, voxel_center)), n2), 0.0)
        
        n3 = normalize(cross(sub_vec(v[4], v[0]), sub_vec(v[5], v[0])))
        c3 = lamp_color * max(dot(normalize(sub_vec(lamp_pos, voxel_center)), n3), 0.0)
        
        n4 = normalize(cross(sub_vec(v[5], v[3]), sub_vec(v[6], v[3])))
        c4 = lamp_color * max(dot(normalize(sub_vec(lamp_pos, voxel_center)), n4), 0.0)
        
        n5 = normalize(cross(sub_vec(v[2], v[0]), sub_vec(v[6], v[0])))
        c5 = lamp_color * max(dot(normalize(sub_vec(lamp_pos, voxel_center)), n5), 0.0)
        
        n6 = normalize(cross(sub_vec(v[6], v[4]), sub_vec(v[5], v[4])))
        c6 = lamp_color * max(dot(normalize(sub_vec(lamp_pos, voxel_center)), n6), 0.0)
        
        # Assign colors to 12 triangles (averaging 3 faces per triangle)
        triangles = [
            ([v[3], v[1], v[2]], (c1 + c2 + c3) / 3.0),
            ([v[1], v[7], v[2]], (c1 + c3 + c5) / 3.0),
            ([v[2], v[1], v[3]], (c1 + c2 + c4) / 3.0),
            ([v[2], v[7], v[3]], (c2 + c4 + c6) / 3.0),
            ([v[3], v[1], v[7]], (c1 + c3 + c4) / 3.0),
            ([v[3], v[7], v[5]], (c4 + c5 + c6) / 3.0),
            ([v[4], v[0], v[6]], (c3 + c5 + c6) / 3.0),
            ([v[4], v[6], v[0]], (c3 + c5 + c6) / 3.0),
            ([v[0], v[4], v[2]], (c1 + c3 + c5) / 3.0),
            ([v[0], v[2], v[4]], (c1 + c3 + c5) / 3.0),
            ([v[6], v[4], v[0]], (c3 + c5 + c6) / 3.0),
            ([v[4], v[6], v[2]], (c3 + c5 + c6) / 3.0)
        ]
        
        for verts, color in triangles:
            clip_verts = [mul_vec_mat(v, view_proj_matrix) for v in verts]
            output_triangles.append((clip_verts, color))
            
    return output_triangles

def point_in_triangle(p, a, b, c):
    def same_side(p1, p2, a, b):
        cp1 = cross(sub_vec(b, a), sub_vec(p1, a))
        cp2 = cross(sub_vec(b, a), sub_vec(p2, a))
        return dot(cp1, cp2) >= 0
    return same_side(p, a, b, c) and same_side(p, b, a, c) and same_side(p, c, a, b)
```

**Edge Cases and Pitfalls:**
*   **Bounding Box Truncation:** The bounding box calculation uses integer casting which truncates towards zero. This may cause voxels to be missed if the triangle spans negative coordinates or if the bounding box is not tightly aligned with the grid [S1, unofficial].
*   **Distance Threshold:** The distance threshold for voxel inclusion is hardcoded to 1. This means voxels are included if their center is within distance 1 of the triangle plane, regardless of the voxel size (0.5) [S1, unofficial].

## Operating characteristics
*   **Time Complexity:** Not given in the sources.
*   **Memory Complexity:** Not given in the sources.
*   **Strengths:** Real-time execution on DirectX hardware; generates explicit 3D geometry suitable for further processing or rendering with standard rasterization pipelines [S1, unofficial].
*   **Limitations:** High vertex and triangle counts; fixed limit on voxels per triangle; bounding box truncation issues; hardcoded parameters [S1, unofficial].

## Background
The Mesh-to-Voxel Geometry Shader was developed by Jonathan Lessard as a real-time DirectX geometry shader technique [S1, unofficial]. It is part of a collection of experimental graphics shaders and scripts aimed at converting mesh objects into voxel-like cubes for real-time applications [S1, unofficial].
