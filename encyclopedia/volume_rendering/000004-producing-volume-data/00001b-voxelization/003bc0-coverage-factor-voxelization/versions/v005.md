# Coverage Factor Voxelization

Also called: 64x Supersampling Coverage, Coverage Factor Computation, Scalar Voxelization

## Overview
Coverage Factor Voxelization computes a scalar-valued volumetric representation where each voxel stores the percentage of its volume covered by a geometric object, rather than a binary inside/outside flag [S1, S2]. It derives these coverage values from a finer-resolution binary solid voxelization [S1, S2]. It is distinguished from sibling methods like [Interior Voxelize](995-interior-voxelize.md) by providing continuous density estimates via an octree-based aggregation of sub-voxel samples, offering 64× supersampling [S1, S2].

## How it works
**Inputs and Outputs:**
*   **Input:** An indexed triangle set transformed into voxel space, and an octree-based binary solid voxelization initialized with zeroes [S1, S2].
*   **Output:** A scalar-valued voxelization where each node stores a coverage factor $C \in [0, 1]$ representing the percentage of the voxel covered by the object [S1, S2].

**Data Structures:**
*   **Octree Node:** Contains an `inside` flag (boolean) and a list of children (for non-leaf nodes) [S1, S2].
*   **Leaf Node (Level-0):** Contains a sub-grid of binary voxels [S1, S2].
*   **Coverage Factor:** A scalar value stored in each node, representing the covered volume fraction [S1, S2].

**Steps:**
1.  **Initialize:** Transform input triangle vertices to voxel space and initialize the voxel grid/octree with zeroes [S1, S2]. Perform binary solid voxelization to populate the leaf-level sub-grids with set bits (1) if covered, unset (0) otherwise [S1, S2].
2.  **Compute Level-0 Coverage:** For each leaf node (level-0), calculate the coverage factor $C_0$ as the fraction of set bits in its voxel sub-grid [S1, S2].
    $$ C_0 = \frac{\text{Number of set bits in sub-grid}}{\text{Total number of voxels in sub-grid}} $$
3.  **Compute Higher-Level Coverage (Bottom-Up):** For each node at level $i > 0$:
    *   If the node has children, calculate its coverage factor $C_i$ as the average of the coverage factors of its children [S1, S2].
        $$ C_i = \frac{1}{M} \sum_{j=1}^{M} C_{child_j} $$
        where $M$ is the number of children [S1, S2].
    *   If the node has no children, its coverage factor is defined by its `inside` flag [S1, S2].
        $$ C_i = \begin{cases} 1.0 & \text{if inside flag is set} \\ 0.0 & \text{otherwise} \end{cases} $$
4.  **Iterate:** Apply step 3 iteratively for all remaining levels up to the root [S1, S2].

**Pseudocode:**
```python
def compute_coverage_factors(node):
    """
    Computes coverage factors for all nodes in an octree-based binary solid voxelization.
    Processes nodes bottom-up (leaves to root) via recursive post-order traversal.
    """
    if node.is_leaf():
        # Leaf node: coverage is fraction of set bits in sub-grid
        set_bits = sum(1 for voxel in node.sub_grid if voxel == 1)
        total_voxels = len(node.sub_grid)
        node.coverage_factor = set_bits / total_voxels
    else:
        # Non-leaf node: recursively process children first
        if node.children is not None and len(node.children) > 0:
            for child in node.children:
                compute_coverage_factors(child)
            sum_coverage = sum(child.coverage_factor for child in node.children)
            node.coverage_factor = sum_coverage / len(node.children)
        else:
            # Node has no children: coverage defined by inside flag
            node.coverage_factor = 1.0 if node.inside_flag else 0.0
```

**Parameters:**
*   **Supersampling Factor:** The method offers 64× supersampling [S1, S2].

**Edge Cases and Pitfalls:**
*   **Precision:** The coverage factor is a fraction. Floating-point precision should be sufficient for the computed ratios [G].
*   **Boundary Conditions:** The `inside` flag for nodes without children must be correctly set during the initial binary voxelization step [S1, S2].
*   **Empty Sub-grids:** If a sub-grid has no set bits, coverage is 0. If all are set, coverage is 1 [G].
