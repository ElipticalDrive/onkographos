# Voxel Coloring

Also called: Photorealistic Scene Reconstruction by Voxel Coloring, Voxel Colouring Reconstruction, Voxel-based 3D reconstruction

## Overview
Voxel Coloring is a volumetric reconstruction technique that computes photo-realistic 3D models from multiple color images by assigning colors (radiances) to voxels in a 3D volume, guaranteeing consistency with the input images [S1]. It distinguishes itself from other reconstruction methods by using a "carving" approach: it initializes an opaque volume and iteratively removes (makes transparent) voxels that fail a color consistency test across views [S2, unofficial]. Unlike [Space Carving](link-to-space-carving), which handles arbitrary camera arrangements through multiple scans, Voxel Coloring relies on an ordinal visibility constraint to allow reconstruction in a single scan [S2, unofficial].

## How it works
**Inputs:**
- A set of $n+1$ color images $V_0, \dots, V_n$ [S1].
- Camera parameters for each image: position, focal angles (vertical and horizontal) [S1].
- Depth information accompanying the images (e.g., from a modified ray casting or stereo matching) [S1].
- A correlation error threshold `thresh` [S1].

**Outputs:**
- A 3D grid of voxels where each voxel has an associated color and alpha value [S1].

**Data Structures:**
- **Voxel Grid:** A 3D array representing the scene volume. Each voxel stores:
  - `color`: A 3-component vector (RGB) [S1].
  - `alpha`: An integer value, typically 0 (transparent) or 255 (opaque) [S1].
- **Pixel Map ($\pi$):** A set or mask marking which pixels in the input images have been processed to ensure coverage [S1].

**Parameters:**
- `thresh`: The maximum allowable correlation error. A low value yields precise but potentially incomplete reconstruction; a larger value yields a more complete reconstruction but may include false voxels [S1].

**Algorithm Steps:**

1. **Initialization:**
   - Construct a 3D grid of transparent voxels where the initial alpha value is 0 [S1].
   - Alternatively, initialize a reconstruction volume of voxels as opaque (alpha = 255) to define the initial bounding volume of the scene [S2, unofficial].

2. **Camera Space Transformation:**
   - For each camera, compute the change of scale matrix $M$ between object space and camera space [S1].
   - The matrix is defined as $M = R_X \times R_Y \times T$ [S1].
   - $R_X$ and $R_Y$ are rotation matrices that bring the vision vector to the OZ axis [S1].
   - $T$ is the translation matrix that brings the camera to the center of the scene [S1].

3. **Voxel Projection and Coloring (Forward Pass):**
   - Traverse the voxel grid. For each voxel, determine if it corresponds to a visible surface point in any input image.
   - Using the depth information $\lambda$ and the ray direction $D$ from the camera origin $O$, compute the 3D position $P$ of the point:
     $$ P = O + \lambda \times D $$
     where $D$ is the normalized vector of the ray direction and $\lambda$ is the depth of the point [S1].
   - Map $P$ to the corresponding voxel in the grid.
   - Assign the color of the pixel from the input image to the voxel.
   - Set the voxel's alpha value to 255 (opaque) [S1].
   - Mark the corresponding pixel in the image as processed (add to $\pi$) [S1].

4. **Color Consistency Testing (Carving):**
   - Traverse the opaque voxels in a monotonic order (near-to-far relative to the cameras) to ensure correct visibility handling [S2, unofficial].
   - For each opaque voxel, project it into all input images.
   - Compare the voxel's color with the color of the corresponding pixel in each image.
   - Calculate the correlation error or color difference.
   - If the error exceeds the threshold `thresh` for any view, the voxel is considered inconsistent.

5. **Carving:**
   - Make inconsistent voxels transparent (set alpha to 0) [S2, unofficial].

6. **Termination:**
   - Repeat the consistency testing and carving steps until all remaining opaque voxels are color consistent across all views [S2, unofficial].

**Pseudocode:**

```python
def voxel_coloring(images, camera_params, depth_maps, thresh, grid_bounds, resolution):
    """
    Reconstructs a 3D volume using Voxel Coloring.
    
    Args:
        images: List of color images V_0...V_n.
        camera_params: List of camera parameters (position, rotation, translation).
        depth_maps: List of depth maps corresponding to images.
        thresh: Maximum allowable correlation error.
        grid_bounds: Bounding box of the scene.
        resolution: (Nx, Ny, Nz) grid dimensions.
        
    Returns:
        voxel_grid: 3D array of voxels with color and alpha.
    """
    # Initialize voxel grid: 0 = transparent, 255 = opaque
    # Initialize colors to black or undefined
    voxel_grid = initialize_voxel_grid(resolution, grid_bounds, alpha=0)
    
    # Step 1: Project depth maps to color the volume (Forward Coloring)
    for i, (image, depth_map, cam_param) in enumerate(zip(images, depth_maps, camera_params)):
        # Compute transformation matrix M = Rx * Ry * T
        M = compute_camera_matrix(cam_param)
        
        # Iterate over pixels in the image
        for y in range(image.height):
            for x in range(image.width):
                # Get depth lambda for this pixel
                lambda_val = depth_map[y, x]
                
                # Compute ray origin O and direction D in object space
                # Note: D must be transformed by M or computed in object space directly
                O, D = get_ray_from_pixel(x, y, cam_param, M)
                
                # Compute 3D position P = O + lambda * D
                P = O + lambda_val * D
                
                # Map P to voxel coordinates
                voxel_coords = world_to_voxel(P, grid_bounds, resolution)
                
                if is_inside_grid(voxel_coords, resolution):
                    # Assign color and set alpha to opaque
                    voxel_grid[voxel_coords].color = image[y, x]
                    voxel_grid[voxel_coords].alpha = 255
                    
    # Step 2: Carve inconsistent voxels
    # Traverse in monotonic order (e.g., sorted by distance to camera center)
    opaque_voxels = get_opaque_voxels(voxel_grid)
    sorted_voxels = sort_by_distance(opaque_voxels, camera_params[0].position) # Simplified ordering
    
    changed = True
    while changed:
        changed = False
        for voxel in sorted_voxels:
            if voxel.alpha == 0:
                continue
                
            is_consistent = True
            for image, cam_param in zip(images, camera_params):
                # Project voxel center to image plane
                u, v = project_voxel_to_image(voxel.center, cam_param)
                
                if is_pixel_valid(u, v, image.width, image.height):
                    # Get pixel color
                    pixel_color = image[v, u]
                    
                    # Compute color difference/correlation error
                    error = compute_color_error(voxel.color, pixel_color)
                    
                    if error > thresh:
                        is_consistent = False
                        break
            
            if not is_consistent:
                voxel.alpha = 0
                changed = True
                
    return voxel_grid

def compute_camera_matrix(cam_param):
    """
    Computes M = Rx * Ry * T.
    Rx, Ry: Rotation matrices to align vision vector with OZ axis.
    T: Translation to center of scene.
    """
    # Implementation details depend on specific camera model
    # [G] Standard rotation and translation matrix multiplication
    Rx = compute_rotation_x(cam_param)
    Ry = compute_rotation_y(cam_param)
    T = compute_translation(cam_param)
    return Rx @ Ry @ T

def compute_color_error(color1, color2):
    """
    Computes the correlation error or distance between two colors.
    [G] Typically Euclidean distance or normalized cross-correlation.
    """
    # Example: Euclidean distance
    return sum((c1 - c2)**2 for c1, c2 in zip(color1, color2))
```

**Edge Cases and Pitfalls:**
- **Ordinal Visibility Constraint:** Cameras must be arranged such that voxels can be visited in a single near-to-far scan relative to every camera. This prevents cameras from surrounding the scene, meaning surfaces not visible in any image cannot be reconstructed [S2, unofficial].
- **Threshold Selection:** A low `thresh` yields precise but incomplete reconstruction; a larger `thresh` yields complete reconstruction with potential false voxels [S1].
- **Precision:** Depth information accuracy directly impacts the initial coloring step. Errors in depth maps lead to misaligned voxels [S1].

## Operating characteristics
- **Time Complexity:** Depends on the number of voxels $N_v$, number of images $n$, and resolution. The carving step requires iterating over opaque voxels and projecting them into $n$ images. In the worst case, this is $O(N_v \cdot n)$. However, the monotonic traversal and early termination of consistency checks can reduce this.
- **Memory Complexity:** $O(N_v)$ to store the voxel grid. The size of the grid is determined by the resolution and bounding box.
- **Strengths:** Produces photo-realistic results directly from color images. Simple to implement. Single-scan efficiency due to ordinal visibility constraint.
- **Limitations:** Requires depth information or stereo matching to initialize the volume. Cannot reconstruct occluded surfaces not visible in any input image. Sensitive to camera calibration errors and noise. The ordinal visibility constraint limits camera placement.
- **When to Use:** When high-quality photo-realistic reconstruction is needed from a set of calibrated images with known depth or stereo correspondence, and camera positions allow for a monotonic scan.
- **When Not to Use:** When cameras surround the scene (use Space Carving instead) or when depth information is unavailable/unreliable.

## Background
Voxel Coloring was introduced by Seitz and Dyer in 1997 in the paper "Photorealistic Scene Reconstruction by Voxel Coloring" [S1]. It is a foundational technique in volumetric 3D reconstruction, using color consistency to distinguish object surface voxels from background [S2, unofficial]. The method builds on the concept of space carving but optimizes for efficiency under specific camera constraints. It is widely used in computer vision for 3D modeling from multi-view imagery.
