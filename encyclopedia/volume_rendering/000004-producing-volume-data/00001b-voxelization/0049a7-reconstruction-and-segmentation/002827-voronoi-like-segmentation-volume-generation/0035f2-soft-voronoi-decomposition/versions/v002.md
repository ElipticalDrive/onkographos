# Soft Voronoi Decomposition

Also called: Differentiable Voronoi Diagram, SoftVoronoi

## Overview
Soft Voronoi Decomposition is a differentiable spatial partitioning method that decomposes a scene into $N$ regions defined by $N$ sites $\phi \in \mathbb{R}^{N \times 3}$ [S1]. It approximates a hard Voronoi diagram with smooth gradients to allow optimization of site positions during training [S1]. Unlike MLP-based softmax decomposition, it provides spatial coherence and cache-friendly memory access patterns for efficient rendering head compositing [S1].

## How it works
**Inputs:**
*   A set of $N$ Voronoi sites $\phi = [\phi_1, \dots, \phi_N]$, where each $\phi_n \in \mathbb{R}^3$ [S1].
*   A query point $x \in \mathbb{R}^3$ [S1].
*   A temperature parameter $\beta \in \mathbb{R}^+$ [S1].

**Outputs:**
*   A weight vector $w_\phi(x) \in \mathbb{R}^N$, where each component $w_{\phi_n}(x)$ represents the soft assignment of point $x$ to site $\phi_n$ [S1].

**Data Structures:**
*   $\phi$: A matrix of shape $(N, 3)$ containing the coordinates of the Voronoi sites [S1].
*   $w_\phi(x)$: A vector of shape $(N)$ containing the computed weights [S1].

**Parameters:**
*   $\beta$: Temperature parameter controlling the softness of the Voronoi approximation [S1]. Typical value: $10^9$ [S1].

**Steps:**
1.  Scale the scene coordinate system such that $\phi \in [-1, 1]^{N \times 3}$ to ensure training invariance with respect to variable magnitude when using optimizers like ADAM [S1].
2.  Schedule $\beta$ over training by starting at a sufficiently low value where $w_i(x) \approx w_j(x)$ for all $i, j$ [S1]. Exponentially increase $\beta$ during training until it reaches a high value (e.g., $10^9$) [S1]. This ensures that at convergence, $w_i(x) \approx 1$ or $w_i(x) \approx 0$ for all $i$, making the decomposition indistinguishable from a hard Voronoi diagram [S1].
3.  For each query point $x$ and each site $\phi_n$, compute the weight using the soft Voronoi formula [S1].

**Formula:**
$$
w_{\phi_n}(x) = \frac{\exp(-\beta\|x - \phi_n\|^2)}{\sum_{j=1}^{N} \exp(-\beta\|x - \phi_j\|^2)}
$$
Where $\| \cdot \|$ denotes the Euclidean norm [S1].

**Edge Cases and Pitfalls:**
*   If $\beta$ is too low, the decomposition is not spatially distinct, resulting in overlapping regions with similar weights [S1].
*   If $\beta$ is too high too early in training, gradients may become zero or unstable, preventing effective learning of site positions [S1]. The exponential scheduling strategy resolves this by starting low and increasing gradually [S1].
*   Without scaling $\phi$ to $[-1, 1]$, training with common optimizers may fail due to magnitude invariance issues [S1].

**Pseudocode:**
```python
import numpy as np

def soft_voronoi_weights(phi, x, beta):
    """Compute soft Voronoi weights for a set of sites phi at query point x."""
    # phi: (N, 3), x: (3,), beta: scalar
    diff = phi - x  # Broadcasting: (N, 3)
    dist_sq = np.sum(diff ** 2, axis=1)  # Squared L2 norms: (N,)
    exp_term = np.exp(-beta * dist_sq)  # Unnormalized weights: (N,)
    sum_exp = np.sum(exp_term)  # Normalization constant: scalar
    if sum_exp == 0:  # Guard against underflow when beta is large
        return np.ones(len(phi)) / len(phi)  # Fallback to uniform distribution [G]
    return exp_term / sum_exp  # Normalized weights: (N,)

def schedule_beta(step, start_beta=1e-3, end_beta=1e9, total_steps=10000):
    """Exponentially schedule beta from start_beta to end_beta."""
    if step >= total_steps:
        return end_beta  # Clamp to maximum [G]
    progress = step / total_steps  # Linear progress: [0, 1)
    return start_beta * (end_beta / start_beta) ** progress  # Exponential interpolation [G]
```

## Subtopics

### [Adjustable Center Point for Voronoi Partitioning](9851-adjustable-center-point-for-voronoi-partitioning.md)
A modification to the Voronoi partitioning where the center point of the barycentric triangle/simplex is adjusted to better handle specific material distributions, such as T-intersections. It sets itself apart by localizing the partition geometry to material boundaries rather than relying on fixed site positions. Choose this variant when material distributions require localized simplex adjustments to maintain partition accuracy. ### Tetrahedral Site Insertion
A strategy to insert new Voronoi sites by forming a regular tetrahedron aligned with the spatial SDF gradient at an existing site, scaling the tetrahedron to avoid crossing the zero-level set [S2]. For each new site $\mathbf{s}'_{i,k}$, compute its SDF value $\phi(\mathbf{s}'_{i,k})$ using a linear approximation based on the original site's SDF value and gradient: $\phi(\mathbf{s}'_{i,k}) \approx \phi(\mathbf{s}_i) + \nabla \phi_i^\top (\mathbf{s}'_{i,k} - \mathbf{s}_i)$ [S2]. The new sites are placed via $\mathbf{s}'_{i,k} = \mathbf{s}_i + \frac{\rho_i}{4} \mathbf{T}_i \mathbf{d}_k$, where $\mathbf{s}'_{i,k}$ are the new sites, $\mathbf{s}_i$ is the original site, $\rho_i$ is the local spacing, $\mathbf{T}_i \in \mathbb{R}^{3\times3}$ is the local frame at $\mathbf{s}_i$, and $\{\mathbf{d}_k\}_{k=1}^4$ are the canonical tetrahedral directions [S2]. The factor $1/4$ scales the tetrahedron to avoid adding new sites that cross the zero-level set [S2].

## Operating characteristics
*   **Time Complexity:** The computation of weights for a single point $x$ requires $O(N)$ operations to compute distances and the softmax normalization [S1].
*   **Memory Complexity:** Requires storing $N$ sites $\phi \in \mathbb{R}^{N \times 3}$ [S1].
*   **Measured Performance:** DeRF models using Soft Voronoi decomposition exhibit significantly better runtime scaling compared to MLP-based decomposition methods as the number of heads increases [S1]. This is because Soft Voronoi enables cache-friendly memory access patterns, whereas MLP methods suffer from random memory access during integration [S1].
*   **Strengths:** Differentiable with respect to site positions $\phi$; provides smooth gradients; spatially coherent; compatible with the Painter’s Algorithm for efficient compositing [S1].
*   **Limitations:** Requires careful scheduling of $\beta$ to balance differentiability and spatial distinctness; sensitive to the magnitude of $\phi$ without proper scaling [S1].
*   **When to use:** When training neural radiance fields or similar models that require decomposing the scene into multiple heads with differentiable spatial partitioning [S1].
*   **When not to use:** When a hard, non-differentiable partition is sufficient and training overhead is a concern; when memory access patterns are not a bottleneck and simplicity is preferred [S1].

## Background
Soft Voronoi Decomposition was introduced in the context of Decomposed Radiance Fields (DeRF) [S1]. The method builds on the solution proposed in [22] (cited in [S1]) to define a differentiable Voronoi diagram. It addresses the limitations of naive decomposition strategies, such as regular grids and MLP-based softmax decompositions, by providing a spatially coherent and computationally efficient alternative [S1]. The approach enables efficient compositing of rendering heads using the Painter’s Algorithm [S1].
