# Polyhedron Rasterization Voxelization

Also called: 3D Polyhedron to Voxel Conversion, 3D Solid-to-Voxel Stage 1, Stage 1 (3D)

## Overview
Polyhedron Rasterization Voxelization converts 3D polyhedral boundaries into a discrete voxel grid by projecting planar faces onto a 2D plane and rasterizing them to determine vertical extents [S1]. It serves as the first stage of a two-stage solid voxelization pipeline, producing a sparse boundary grid that encodes surface intersections via XOR operations [S1]. Unlike methods that fill volumes directly or use ray casting, this approach explicitly represents only the faces separating solids or background, deferring the determination of interior solid values to a subsequent prefix-scan stage [S1].

## How it works
**Inputs:** A set of 3D polyhedra defined by planar faces (vertices with $(x,y,z)$ coordinates) and a background value (typically 0). A target 3D grid resolution and bounding box.
**Outputs:** A 3D voxel grid where each voxel contains an integer value representing the XOR difference between adjacent solids or between a solid and the background.

**Data Structures:**
*   **3D Grid:** A 3D array of integers. Dimensions are determined by the dataset extent and desired resolution. Initialized to zero.
*   **2D Projection Grid:** A temporary 2D array used for rasterizing individual faces.

**Steps:**
1.  **Initialize Grid:** Create an empty 3D grid filled with zeros, sized to cover the spatial extent of the input geometry at the target resolution [S1].
2.  **Iterate Faces:** Process each planar face of the input polyhedra individually [S1].
3.  **Project and Rasterize:**
    *   Determine the bounding box of the face's vertices in the $(x,y)$ plane.
    *   Create a 2D grid covering this extent.
    *   Rasterize the 2D polygon projection into this grid, filling the interior with 1s and the exterior with 0s, following standard 2D rasterization rules [S1].
4.  **Map to 3D:** Shift the $(row, column)$ coordinates of the 2D rasterized face to the corresponding $(x,y)$ indices in the 3D grid [S1].
5.  **Calculate Z-Coordinate:** For each $(x,y)$ position occupied by the face, calculate the vertical grid coordinate $z$ using the plane equation derived from the face's 3D vertices [S1].
    *   Let the plane equation be $Ax + By + Cz + D = 0$.
    *   Solve for $z$: $z = -(Ax + By + D) / C$ (assuming $C \neq 0$).
    *   Convert the continuous $z$ to the discrete grid index.
6.  **Insert XOR Value:** At the resulting 3D index $(x,y,z)$, update the grid value. The new value is the XOR of the values of the two regions separated by the face (e.g., Solid A and Background, or Solid A and Solid B). If a value already exists at that index, XOR the new value with the existing one [S1].
    *   Formula: $Grid[x,y,z] = Grid[x,y,z] \oplus (Value_{solid1} \oplus Value_{solid2})$ [S1].
7.  **Handle Non-Planar Primitives:** For primitives like hemispheres, parametrize them (center $x_0, y_0, z_0$, radius $R$, vertical scale $e$, value $v$). For each $(x,y)$ within distance $R$ from $(x_0, y_0)$, calculate $z$ using the scaled hemisphere equation: $z = z_0 + e \cdot \sqrt{R^2 - (x-x_0)^2 - (y-y_0)^2}$. Insert $v \oplus Background$ at $(x,y,z)$ [S1].

**Parameters:**
*   **Scan Direction:** The method typically uses a top-to-bottom scan direction for the vertical axis, though left-to-right or front-to-back are possible [S1].
*   **Solid Values:** Integer identifiers for each solid region.

**Edge Cases and Pitfalls:**
*   **Vertical Walls:** In a top-to-bottom scan, vertical walls do not appear explicitly in the sparse boundary grid. They are represented solely by their top and bottom XOR values [S1].
*   **Non-Planar Faces:** The core algorithm requires planar faces. Non-planar surfaces must be approximated or parametrized as described above [S1].
*   **Precision:** Floating-point to integer conversion for $z$ coordinates must be handled consistently to avoid gaps or overlaps [G].

**Pseudocode:**
```python
def polyhedron_rasterization_voxelization(faces, grid_dims, background_value=0):
    # Initialize 3D grid with zeros
    grid = [[[0 for _ in range(grid_dims[2])] for _ in range(grid_dims[1])] for _ in range(grid_dims[0])]
    
    for face in faces:
        # Get vertices of the face
        vertices = face.vertices
        
        # Determine 2D bounding box in x,y
        min_x = min(v.x for v in vertices)
        max_x = max(v.x for v in vertices)
        min_y = min(v.y for v in vertices)
        max_y = max(v.y for v in vertices)
        
        # Create 2D rasterization grid for this face
        width = max_x - min_x + 1
        height = max_y - min_y + 1
        face_grid = [[0 for _ in range(width)] for _ in range(height)]
        
        # Rasterize 2D polygon into face_grid (fill with 1s)
        rasterize_2d_polygon(vertices, face_grid, min_x, min_y)
        
        # Calculate plane equation from 3D vertices
        # Assuming vertices are coplanar
        p1, p2, p3 = vertices[0], vertices[1], vertices[2]
        normal = cross_product(vector(p2, p1), vector(p3, p1))
        A, B, C = normal.x, normal.y, normal.z
        D = -dot_product(normal, p1)
        
        # Iterate over rasterized pixels
        for dy in range(height):
            for dx in range(width):
                if face_grid[dy][dx] == 1:
                    # Map to 3D grid coordinates
                    x = min_x + dx
                    y = min_y + dy
                    
                    # Calculate z from plane equation
                    if C == 0:
                        # Vertical face, skip or handle as edge case
                        continue
                    z_float = -(A * x + B * y + D) / C
                    z = round(z_float)
                    
                    # Check bounds
                    if 0 <= x < grid_dims[0] and 0 <= y < grid_dims[1] and 0 <= z < grid_dims[2]:
                        # Determine XOR value
                        # Assuming face separates solid_id from background or another solid
                        # For simplicity, assume face has a 'solid_value' attribute
                        solid_value = face.solid_value
                        xor_val = solid_value ^ background_value
                        
                        # XOR into grid
                        grid[x][y][z] ^= xor_val
                        
    return grid
```

## Operating characteristics
*   **Time Complexity:** Proportional to the number of faces times the area of their projections in voxels. Rasterization is $O(A)$ where $A$ is the projected area.
*   **Memory Complexity:** $O(N_x N_y N_z)$ for the full grid, but the output is sparse, storing only boundary voxels.
*   **Strengths:** Explicitly handles complex solid boundaries; efficient for sparse boundaries; clear separation of surface representation from volume filling.
*   **Limitations:** Requires planar faces; vertical walls are not explicitly stored in the boundary grid; requires a second stage to resolve solid interiors.
*   **When to Use:** When explicit boundary representation is needed before volume filling; for CAD-like models with planar faces.
*   **When Not to Use:** For non-planar surfaces without parametrization; when immediate solid volume is required without post-processing.

## Background
The method was described in the context of rasterizing and voxelizing two- and three-dimensional space partitionings, particularly for land use maps and building models [S1]. It extends 2D rasterization techniques to 3D by using faces as boundaries between solids [S1]. The approach was demonstrated on a historical land use map of Adelaide, Australia, containing 192 polygons and 1296 vertices [S1].
