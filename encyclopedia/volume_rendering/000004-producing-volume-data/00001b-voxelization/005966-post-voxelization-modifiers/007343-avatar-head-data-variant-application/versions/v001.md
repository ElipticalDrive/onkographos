# Avatar Head Data Variant Application

Also called: Head Variant Voxel Rewriting

## Overview
This method modifies a base head voxel data array to apply specific hair variants (short, buzz, or long) by rewriting specific voxel value markers [S1, unofficial]. It solves the problem of dynamically changing character appearance without re-voxelizing the underlying geometry, allowing for iterative refinement or user-driven adjustments post-generation [S1, unofficial]. It is distinct from general [Voxel Editing Tools](17731-voxel-editing-tools.md) by focusing exclusively on semantic hair type substitution within the head region using predefined integer markers.

## How it works
**Inputs and Outputs:**
- Input: A voxel data array representing the head, where specific integer values denote hair types.
- Output: A modified voxel data array with updated hair variant markers.

**Data Structures:**
The voxel data is a 1D or 3D array of integers. The relevant voxel value constants are defined as:
- `V_SKIN`: 1 (representing skin) [S1, unofficial].
- `V_HAIR`: 2 (representing standard hair) [S1, unofficial].
- `V_HAIR_LONG`: 10 (marker for long-only drape) [S1, unofficial].
- `V_HAIR_VOL`: 11 (marker for hair volume shaved by buzz cut) [S1, unofficial].

**Steps:**
1. Create a copy of the source voxel data array to avoid mutating the original [S1, unofficial].
2. Determine the target value for long hair (`longV`):
   - If the requested variant is `'long'`, set `longV = V_HAIR` (2).
   - Otherwise, set `longV = 0` (empty/transparent) [S1, unofficial].
3. Determine the target value for volume hair (`volV`):
   - If the requested variant is `'buzz'`, set `volV = V_SKIN` (1).
   - Otherwise, set `volV = V_HAIR` (2) [S1, unofficial].
4. Iterate through all voxels in the array:
   - If a voxel's value is `V_HAIR_LONG` (10), replace it with `longV` [S1, unofficial].
   - If a voxel's value is `V_HAIR_VOL` (11), replace it with `volV` [S1, unofficial].
5. Return the modified array [S1, unofficial].

**Pseudocode:**
```python
def apply_head_variant(voxel_data, variant):
    """
    Applies a hair variant to a head voxel array.
    
    Args:
        voxel_data (list[int]): The input voxel array.
        variant (str): One of 'short', 'buzz', 'long'.
        
    Returns:
        list[int]: The modified voxel array.
    """
    # Constants defined in source [S1, unofficial]
    V_SKIN = 1
    V_HAIR = 2
    V_HAIR_LONG = 10
    V_HAIR_VOL = 11
    
    # Step 1: Copy data
    new_data = list(voxel_data)
    
    # Step 2 & 3: Determine target values
    if variant == 'long':
        longV = V_HAIR
    else:
        longV = 0
        
    if variant == 'buzz':
        volV = V_SKIN
    else:
        volV = V_HAIR
        
    # Step 4: Iterate and replace
    for i in range(len(new_data)):
        val = new_data[i]
        if val == V_HAIR_LONG:
            new_data[i] = longV
        elif val == V_HAIR_VOL:
            new_data[i] = volV
            
    # Step 5: Return result
    return new_data
```

**Edge Cases and Pitfalls:**
- If `variant` is neither `'long'` nor `'buzz'` (e.g., `'short'`), `longV` becomes 0 and `volV` becomes `V_HAIR`. This effectively removes long hair markers and keeps volume hair as standard hair, resulting in a short cut [S1, unofficial].
- Precision issues are not applicable as integer markers are used.
- Boundary conditions: The method assumes the input array contains only valid markers. If other values are present, they are ignored [S1, unofficial].

## Subtopics

### Avatar Model Assembly
Constructs a complete avatar model object by sanitizing input, mapping color indices to hex values, deriving shades, and swapping the head voxel data for the chosen hair variant [S1, unofficial]. It sanitizes the input avatar object to ensure valid color indices and hair variant, retrieves the base model and its palette $P$, and constructs a new palette array [S1, unofficial]. Entries 1 (skin), 2 (hair), 4 (hoodie main), 6 (jeans main), 8 (sneaker), 10 (hair long), 11 (hair buzz) use the main hex colors. Entries 5 (hoodie shade), 7 (jeans shade), 13 (skin shade) use `shadeHex(mainHex)`. Entries 3, 9, 12, 14, 15 are fixed from base palette $P$ [S1, unofficial]. The head part's data in the base model parts array is replaced with `buildHeadData(p.data, a.hair)`, and the new model object with the updated palette and parts is returned [S1, unofficial]. The shade color calculation is defined as:
$$ \text{shadeHex}(\text{mainHex}) = \text{sRGB\_to\_hex}( \text{linear\_to\_sRGB}( \text{linear}(\text{mainHex}) \times \text{shadeFactor} ) ) $$
[S1, unofficial].

## Operating characteristics
Time complexity is linear with respect to the number of voxels in the head array, $O(N)$, where $N$ is the total voxel count [S1, unofficial]. Memory complexity is $O(N)$ for the copy of the voxel data [S1, unofficial]. The method is efficient as it avoids re-computing geometric intersections. It is suitable for real-time applications where character appearance changes frequently. Limitations include the assumption of predefined voxel markers; if the voxelization process does not produce these specific markers, the method will not work as intended [S1, unofficial].

## Background
Originated in the context of voxel-based avatar systems, specifically within the `voxel-demolition` project [S1, unofficial]. It allows for dynamic character customization without the computational cost of re-voxelization. The method relies on a pre-defined set of integer markers for hair types, which are established during the initial voxelization phase [S1, unofficial].
