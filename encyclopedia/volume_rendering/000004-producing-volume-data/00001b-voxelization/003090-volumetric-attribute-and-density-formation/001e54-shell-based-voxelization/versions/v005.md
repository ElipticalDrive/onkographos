# Shell-based Voxelization

Also called: AABB Expansion Voxelization, Mark Boundary Voxels

## Overview
Shell-based Voxelization identifies and marks all voxels in a discrete grid that lie within a specified `shell_radius` of any geometric primitive (such as triangles or polygons) in a source mesh [S1, unofficial]. It serves as a spatial support determination step for subsequent voxelization operations, ensuring that only voxels near the surface are processed or stored [S1, unofficial]. Unlike [Interior Voxelize](995-interior-voxelize.md), which determines occupancy based on ray casting or point-in-polyhedron tests, this method relies on geometric proximity via bounding box expansion [S1, unofficial]. It differs from [Coverage Factor Voxelization](9079-coverage-factor-voxelization.md) by producing a binary mask of potential surface influence rather than a continuous density or coverage value [S1, unofficial].

## How it works
**Inputs:**
- `vertices`: Array of vertex positions, layout `Float[N]` per vertex, size `num_vertices * N` [S1, unofficial].
- `simplices`: Array of vertex indices, layout `uint32_t[N]` per primitive, size `num_simplices * N` [S1, unofficial].
- `num_simplices`: Count of primitives [S1, unofficial].
- `grid`: Grid extent `Extent<N>`, storing dimensions `[width, height, depth]` (for $N=3$) or `[width, height]` (for $N=2$) [S1, unofficial].
- `voxel_size`: Vector `Vector<Float, N>` defining the physical size of a single voxel [S1, unofficial].
- `shell_radius`: Scalar `Float` defining the expansion distance around each primitive [S1, unofficial].
- `mask`: A bitset or boolean array of size equal to the total number of voxels in the grid, initialized to false [G].

**Outputs:**
- `mask`: Updated such that `mask[i]` is true if voxel `i` intersects the expanded bounding box of any primitive, false otherwise [S1, unofficial].

**Data Structures:**
- `Extent<N>`: Struct containing `uint32_t extents[N]`. Index 0 is width, 1 is height, 2 is depth [S1, unofficial].
- `Bitset`: A dynamic array of bits or integers supporting `set(index)` operations [S1, unofficial].
- `AABB`: Axis-Aligned Bounding Box defined by `min` and `max` vectors of type `Vector<Float, N>` [S1, unofficial].

**Grid Coordinate Conversion:**
The grid spans a world space defined by the voxel size and origin [S1, unofficial]. The conversion from world coordinate $x$ to grid coordinate is given by [S1, unofficial]:
$$ grid\_coord = \frac{x - (-1)}{voxel\_size} + 0 $$
Assuming the grid spans $[-1, 1]$ in world space, the voxel size for a grid extent $E$ (where $E$ is the dimension length in voxels) is calculated as [S1, unofficial]:
$$ voxel\_size = \frac{2}{E} $$

**Algorithm Steps:**
1. Initialize `mask` with all bits set to 0 [G].
2. For each primitive index $p$ from $0$ to $num\_simplices - 1$:
    a. Extract the vertex indices for primitive $p$ from `simplices` [S1, unofficial].
    b. Initialize an empty `AABB` for dimension $N$ [S1, unofficial].
    c. For each vertex index $v\_idx$ in the primitive:
        i. Retrieve the vertex position $V_i$ from `vertices` [S1, unofficial].
        ii. Expand `AABB` to include $V_i$ (update `min` and `max` components) [S1, unofficial].
    d. Expand the `AABB` by `shell_radius`:
        $$ AABB.min_i = AABB.min_i - shell\_radius $$
        $$ AABB.max_i = AABB.max_i + shell\_radius $$
        for all dimensions $i \in [0, N-1]$ [S1, unofficial].
    e. Convert the expanded `AABB.min` and `AABB.max` to grid coordinates using the formula above [S1, unofficial].
    f. Compute integer bounds for iteration:
        $$ min\_coord_i = \lfloor grid\_coord(AABB.min_i) \rfloor $$
        $$ max\_coord_i = \lfloor grid\_coord(AABB.max_i) \rfloor $$
        The implementation uses `floor` to convert grid coordinates to integer indices [S1, unofficial].
    g. Iterate over all voxel indices within the range $[min\_coord, max\_coord]$:
        i. Clamp indices to the grid boundaries $[0, grid.extent_i - 1]$ [S1, unofficial].
        ii. Convert the clamped grid coordinates to a linear index $L$ [S1, unofficial].
        iii. Set `mask[L]` to 1 [S1, unofficial].

**Pseudocode:**
```python
import math

def shell_based_voxelization(vertices, simplices, num_simplices, grid_extent, voxel_size, shell_radius):
    """
    Marks voxels within shell_radius of any simplex.
    vertices: list of [x, y, z] floats
    simplices: list of [v0, v1, v2] uint32 indices
    grid_extent: tuple (width, height, depth)
    voxel_size: float
    shell_radius: float
    """
    width, height, depth = grid_extent
    total_voxels = width * height * depth
    mask = [0] * total_voxels
    
    # Helper to convert world coord to grid index: (x + 1) / voxel_size
    def world_to_grid(world_coord):
        return (world_coord + 1.0) / voxel_size

    for p in range(num_simplices):
        # 1. Construct AABB for primitive
        indices = simplices[p]
        # Initialize AABB min/max to infinity/minus infinity
        aabb_min = [float('inf')] * 3
        aabb_max = [float('-inf')] * 3
        
        for v_idx in indices:
            v_pos = vertices[v_idx]
            for d in range(3):
                if v_pos[d] < aabb_min[d]:
                    aabb_min[d] = v_pos[d]
                if v_pos[d] > aabb_max[d]:
                    aabb_max[d] = v_pos[d]
        
        # 2. Expand AABB by shell_radius
        for d in range(3):
            aabb_min[d] -= shell_radius
            aabb_max[d] += shell_radius
            
        # 3. Convert to grid coordinates and floor
        min_grid = [int(math.floor(world_to_grid(aabb_min[d]))) for d in range(3)]
        max_grid = [int(math.floor(world_to_grid(aabb_max[d]))) for d in range(3)]
        
        # 4. Iterate and mark
        # Clamp to grid boundaries [0, extent - 1]
        start_x = max(0, min_grid[0])
        end_x = min(width - 1, max_grid[0])
        start_y = max(0, min_grid[1])
        end_y = min(height - 1, max_grid[1])
        start_z = max(0, min_grid[2])
        end_z = min(depth - 1, max_grid[2])
        
        for z in range(start_z, end_z + 1):
            for y in range(start_y, end_y + 1):
                for x in range(start_x, end_x + 1):
                    linear_index = x + y * width + z * width * height
                    mask[linear_index] = 1
                    
    return mask
```
*Note: The source implementation uses hardcoded loops for $N=2$ and $N=3$ and lacks a generic grid iterator, limiting scalability to higher dimensions [S1, unofficial].*

**Edge Cases and Pitfalls:**
- **Precision:** Floating point errors in `world_to_grid` may cause off-by-one errors at boundaries [G].
- **Dimensionality:** The source implementation uses hardcoded loops for $N=2$ and $N=3$ and lacks a generic grid iterator, limiting scalability to higher dimensions [S1, unofficial].
- **Shell Radius Zero:** If `shell_radius` is 0, only voxels strictly intersecting the primitive's AABB are marked [S1, unofficial].

## Subtopics

### Shell-based Voxelization with Boundary Likelihood
A variant that creates a scene representing boundary likelihood rather than a binary mask [S2]. It defines a shell $V_1$ around a boundary of interest, finds an optimal boundary within $V_1$, and assigns the boundary likelihood value to voxels in $V_1$ while assigning 0 to voxels outside $V_1$ [S2].

## Operating characteristics
- **Time Complexity:** Not given in the sources.
- **Memory Complexity:** Not given in the sources.
- **Performance:** Highly dependent on the ratio of shell radius to voxel size and the density of primitives [G].
- **Strengths:** Simple to implement; robust against geometric gaps in meshes; provides a clear spatial support for further operations [G].
- **Limitations:** Does not provide density or coverage information; binary output may be insufficient for smooth rendering without further processing; inefficient for sparse grids if the shell is large relative to the object size [G].

## Background
The method is implemented in differentiable voxelization frameworks [S1, unofficial] and relates to imaging transforms for visualizing surfaces and volumes [S2]. It was developed to facilitate the creation of volumetric representations from surface meshes by defining a spatial support region [S1, unofficial]. The concept of using a shell around a boundary for likelihood assignment was explored in the context of imaging transforms [S2].
