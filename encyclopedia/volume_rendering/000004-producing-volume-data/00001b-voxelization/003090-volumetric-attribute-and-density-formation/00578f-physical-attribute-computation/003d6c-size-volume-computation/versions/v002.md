# Size Volume Computation

Also called: Correa and Ma Size Volume, Size Attribute, Tamanho

## Overview
Size Volume Computation generates a tertiary volumetric attribute representing the local scale or "size" of features within a dataset, enabling size-based transfer functions in Direct Volume Rendering (DVR) [S2, unofficial]. It addresses the difficulty of defining mathematical descriptors for size variations, which are visually intuitive but mathematically complex [S1, unofficial].

## How it works
**Inputs and Outputs:**
- Input: A scalar volume $V$ with dimensions $(N_x, N_y, N_z)$ [S2, unofficial]. Optionally, an intensity range $[I_{min}, I_{max}]$ to restrict scale-space computation to specific features [S2, unofficial].
- Output: A size volume $S$ with the same dimensions, where each voxel contains the size value of the largest detected feature at that location [S2, unofficial].

**Data Structures:**
- Input Volume $V$: 3D array of floats [S2, unofficial].
- Size Volume $S$: 3D array of floats, initialized to zero [S2, unofficial].
- Blob List: A list of tuples $(x, y, z, t)$, where $(x, y, z)$ are voxel coordinates and $t$ is the detected scale value [S2, unofficial].

**Steps:**
1. **Scale-Space Computation**: Construct a scale space from the input volume using anisotropic diffusion to create the scale space with better localization [S2, unofficial]. Let $V_0 = V$. For each scale level $i$, compute $V_i$ by applying anisotropic diffusion to $V_{i-1}$ [S2, unofficial]. The scale space is a 4D structure $V(x, y, z, t)$.
2. **Scale Detection**: Detect blobs as local maxima in both spatial and scale domains using the classical normalized Laplacian kernel [S2, unofficial]. For each voxel $(x, y, z)$ and scale $t$, compute the Laplacian $\nabla^2 V(x, y, z, t)$ and normalize it [G]. Identify local maxima in the 4D space. Store detected blobs as tuples $(x, y, z, t)$ in the Blob List [S2, unofficial].
3. **Back Projection**: For each voxel $(x, y, z)$ in the output volume $S$, determine the size value by back-projecting the detected blobs [S2, unofficial]. Use Shepard's interpolation with Wendland polynomials to assign the size value $t$ from the detected blobs to the voxel [S2, unofficial]. The interpolation weight $w_i$ for a blob $i$ at distance $d_i$ is computed using a Wendland polynomial $w(d_i)$, and the interpolated size is $S(x, y, z) = \frac{\sum w_i t_i}{\sum w_i}$ [G]. If no blob is detected near a voxel, $S(x, y, z)$ remains at its initial value.
4. **Masking**: For each voxel, if multiple blobs are detected at different scales, keep only the largest size value $t_{max}$ and mask out smaller features [S2, unofficial]. This ensures that each voxel represents the dominant feature size [S2, unofficial].

**Parameters:**
- Scale levels: Number of scale steps in the anisotropic diffusion process. Not given in the sources.
- Intensity range: Optional $[I_{min}, I_{max}]$ to restrict scale-space computation to specific intensity values, preventing smaller features from being masked by larger ones in different intensity ranges [S2, unofficial].

**Edge Cases and Pitfalls:**
- Smaller features get masked out by larger ones if they share the same spatial location but different scales [S2, unofficial]. Mitigation: Use intensity-range-specific scale spaces [S2, unofficial].

**Pseudocode:**
```python
def compute_size_volume(V, intensity_range=None):
    # Step 1: Scale-Space Computation
    # Apply anisotropic diffusion to create scale space with better localization [S2, unofficial]
    # Standard iterative anisotropic diffusion implementation [G]
    V_scale = anisotropic_diffusion(V)

    # Step 2: Scale Detection
    # Detect blobs as local maxima in spatial and scale domains using classical normalized Laplacian [S2, unofficial]
    blob_list = []
    for x in range(V.shape[0]):
        for y in range(V.shape[1]):
            for z in range(V.shape[2]):
                for t in range(V_scale.shape[3]):
                    lap_val = compute_laplacian(V_scale, x, y, z, t)
                    norm_val = lap_val / (t + 1e-9) # Standard scale normalization [G]
                    if is_local_maxima(V_scale, x, y, z, t, norm_val):
                        blob_list.append((x, y, z, t))

    # Step 3 & 4: Back Projection and Masking
    S = [[[0.0 for _ in range(V.shape[2])] for _ in range(V.shape[1])] for _ in range(V.shape[0])]
    for x in range(V.shape[0]):
        for y in range(V.shape[1]):
            for z in range(V.shape[2]):
                weights = []
                values = []
                for bx, by, bz, bt in blob_list:
                    d = euclidean_distance((x, y, z), (bx, by, bz))
                    w = wendland_polynomial(d)
                    weights.append(w)
                    values.append(bt)
                if weights:
                    interpolated_size = sum(w * v for w, v in zip(weights, values)) / sum(weights)
                    if interpolated_size > S[x][y][z]:
                        S[x][y][z] = interpolated_size # Keep only largest size value [S2, unofficial]
    return S

def anisotropic_diffusion(V):
    # Iteratively apply anisotropic diffusion to create scale space [S2, unofficial]
    # Standard edge-preserving diffusion loop [G]
    V_out = [layer[:] for layer in V]
    for _ in range(10):
        for x in range(1, V.shape[0]-1):
            for y in range(1, V.shape[1]-1):
                for z in range(1, V.shape[2]-1):
                    grad_x = V[x+1][y][z] - V[x-1][y][z]
                    grad_y = V[x][y+1][z] - V[x][y-1][z]
                    grad_z = V[x][y][z+1] - V[x][y][z-1]
                    grad_mag = sqrt(grad_x**2 + grad_y**2 + grad_z**2)
                    c = exp(-1.0 / (grad_mag**2 + 1e-9))
                    lap = V[x+1][y][z] + V[x-1][y][z] + V[x][y+1][z] + V[x][y-1][z] + V[x][y][z+1] + V[x][y][z-1] - 6*V[x][y][z]
                    V_out[x][y][z] += c * lap
    return V_out

def compute_laplacian(V, x, y, z, t):
    return V[x+1][y][z][t] + V[x-1][y][z][t] + V[x][y+1][z][t] + V[x][y-1][z][t] + V[x][y][z+1][t] + V[x][y][z-1][t] - 6*V[x][y][z][t]

def is_local_maxima(V, x, y, z, t, val):
    for dx in [-1, 0, 1]:
        for dy in [-1, 0, 1]:
            for dz in [-1, 0, 1]:
                for dt in [-1, 0, 1]:
                    if dx == 0 and dy == 0 and dz == 0 and dt == 0:
                        continue
                    nx, ny, nz, nt = x+dx, y+dy, z+dz, t+dt
                    if 0 <= nx < V.shape[0] and 0 <= ny < V.shape[1] and 0 <= nz < V.shape[2] and 0 <= nt < V.shape[3]:
                        if V[nx][ny][nz][nt] > val:
                            return False
    return True

def wendland_polynomial(d):
    # Standard Wendland C2 radial basis function [G]
    r = d / 1.0
    if r < 1.0:
        return (1.0 - r)**4 * (4.0 * r + 1.0)
    return 0.0

def euclidean_distance(p1, p2):
    return sqrt(sum((a - b)**2 for a, b in zip(p1, p2)))
```

## Operating characteristics
- **Time Complexity**: Depends on the number of scale levels and voxels. Not given in the sources.
- **Memory Complexity**: Requires storing the 4D scale space and blob list. Not given in the sources.
- **Strengths**: Provides intuitive size-based transfer functions for feature categorization [S1, unofficial].
- **Limitations**: Smaller features may be masked by larger ones [S2, unofficial].
- **When to Use**: When size-based feature distinction is critical, such as in medical imaging [S1, unofficial].
- **When Not to Use**: Not given in the sources.

## Background
Originated from Correa and Ma (2008), who adapted size concepts from computer vision to DVR context [S1, unofficial]. The method analyzes multiscale fields and pyramid schemes to categorize objects in a volume [S1, unofficial]. It is used in medical imaging, such as brain MRI for aneurysm detection, where size-based transfer functions help distinguish tumors from blood vessels [S1, unofficial].
