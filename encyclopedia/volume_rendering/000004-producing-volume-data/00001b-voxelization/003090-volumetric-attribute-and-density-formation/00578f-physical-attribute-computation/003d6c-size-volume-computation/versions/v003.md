# Size Volume Computation

Also called: Correa and Ma Size Volume, Size Attribute, Tamanho

## Overview
Size Volume Computation is a method for generating a tertiary volumetric attribute representing the characteristic size of local structures, used to drive transfer functions in Direct Volume Rendering (DVR) [S1, S2, unofficial]. It addresses the difficulty of defining mathematical descriptors for size variations in multiscale fields [S1, unofficial]. Unlike siblings that compute scalar intensity or velocity, this method categorizes objects by their spatial extent, allowing users to distinguish features based on scale rather than just value [S1, unofficial].

## How it works
The method, proposed by Correa and Ma, computes a size volume $S$ from an input volume $V$ in three steps: scale-space computation, scale detection, and back projection [S2, unofficial].

**Inputs:**
- Input volume $V(x, y, z)$ with intensity values.
- Optional intensity range $[I_{min}, I_{max}]$ to restrict scale-space computation to specific features [S2, unofficial].

**Outputs:**
- Size volume $S(x, y, z)$, where each voxel stores the detected size of the largest feature at that location.

**Data Structures:**
- **Input Volume:** 3D grid of floats.
- **Scale Space:** 4D grid $L(x, y, z, t)$, where $t$ is the scale parameter.
- **Blob Tuple:** Detected local maxima stored as $(x, y, z, t)$, where $t$ represents the size scale.
- **Size Volume:** 3D grid of floats, initialized to zero or background.

**Parameters:**
- Scale range: Not given in the sources.
- Anisotropic diffusion parameters: Not given in the sources.
- Shepard interpolation weights: Not given in the sources.

**Steps:**

1. **Scale-Space Computation:**
   Compute a scale space using anisotropic diffusion to achieve better localization of features compared to standard Gaussian smoothing [S2, unofficial]. Let $L(x, y, z, t)$ be the result at scale $t$. If an intensity range $[I_{min}, I_{max}]$ is specified, the diffusion is applied only to voxels within this range to avoid masking smaller features by larger ones [S2, unofficial].

2. **Scale Detection:**
   Detect blobs by finding local maxima in both the spatial domain $(x, y, z)$ and the scale domain $t$ using the classical normalized Laplacian kernel [S2, unofficial]. This identifies a set of blob tuples $B = \{(x_i, y_i, z_i, t_i)\}$, where $t_i$ corresponds to the detected size scale [S2, unofficial].

3. **Back Projection:**
   For each voxel $(x, y, z)$ in the output volume, determine its size value by back-projecting the detected blobs using Shepard's interpolation with Wendland polynomials [S2, unofficial]. The interpolated value is based on the distances to the detected blob centers $(x_i, y_i, z_i)$ and their associated scales $t_i$.

4. **Max Size Selection:**
   If a voxel is influenced by multiple detected blobs (features with multiple sizes), keep only the largest size value $t$ and mask out smaller features [S2, unofficial].

**Edge Cases and Pitfalls:**
- **Masking:** Smaller features can be masked out by larger ones if they share the same spatial location. To avoid this, the user should specify an intensity range to compute the scale space specifically for that range [S2, unofficial].

- **When to choose:** When visualizing flow dynamics rather than structural size.

## Operating characteristics
- **Time Complexity:** Not given in the sources. Depends on the scale space depth and the number of detected blobs.
- **Memory Complexity:** Requires storage for the 4D scale space and the output size volume. Not given in the sources.
- **Strengths:** Provides intuitive size-based categorization for DVR; anisotropic diffusion improves localization [S1, S2, unofficial].
- **Limitations:** Smaller features may be masked by larger ones; requires careful parameter tuning for intensity ranges [S2, unofficial].
- **When to use:** When distinguishing structures by their physical size is more important than intensity [S1, unofficial].
- **When not to use:** When features are densely packed with varying sizes at the same location without intensity separation [S2, unofficial].

## Background
The concept of size was adapted by Correa and Ma (2008) to the Direct Volume Rendering (DVR) context [S1, unofficial]. In Computer Vision, it is difficult to define mathematical descriptors that recognize size variations, although it is visually intuitive [S1, unofficial]. The technique analyzes multiscale fields and pyramid schemes to categorize objects inserted in a volume [S1, unofficial]. It has been used in medical imaging, such as brain MRI and vascular datasets, to emphasize regions like tumors and blood vessels based on size [S1, S2, unofficial].
