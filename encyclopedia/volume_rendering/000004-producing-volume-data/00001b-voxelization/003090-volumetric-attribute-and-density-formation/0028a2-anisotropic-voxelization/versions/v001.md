# Anisotropic Voxelization

Also called: Directional Voxelization, Face-based Voxelization

## Overview
Anisotropic voxelization improves rendering quality by storing directional data (such as surface normals or radiance) in separate grids for each of the six faces of a voxel cube, rather than averaging them into a single isotropic value [S1, unofficial]. This method specifically addresses the cancellation of surface normals in thin models (e.g., cloth) and reduces light leaks where isotropic voxels incorrectly illuminate surfaces facing away from light sources [S1, unofficial]. It is chosen when directional fidelity is critical for thin geometry or accurate lighting, at the cost of sixfold memory usage and increased atomic operation overhead during voxelization [S1, unofficial].

## How it works
**Inputs and Outputs**
*   **Input:** A stream of triangle fragments from rasterization, each containing position, surface normal, and attribute value (e.g., color, albedo).
*   **Output:** Six separate voxel grids (one for each axis direction: $+x, -x, +y, -y, +z, -z$), storing weighted attribute values.

**Data Structures**
The method requires six distinct voxel grids. If an isotropic grid uses a single value per voxel, the anisotropic structure uses six values per voxel coordinate $(i, j, k)$.
*   **Grid Layout:** Six arrays of size $W \times H \times D$.
*   **Voxel Content:** Each voxel stores a weighted sum of attributes and a weight sum (for normalization) for each of the 6 faces.
*   **Fields:** For each face $f \in \{+x, -x, +y, -y, +z, -z\}$:
    *   `weighted_value`: Accumulator for the attribute (e.g., color).
    *   `weight`: Accumulator for the dot product magnitude (used for normalization).

**Steps**
1.  **Rasterize:** Project triangles onto the voxel grid using a standard rasterization pipeline.
2.  **Identify Faces:** For each fragment covering a voxel, determine which of the 6 voxel faces the fragment's normal contributes to.
3.  **Compute Weight:** Calculate the dot product between the fragment's surface normal $\mathbf{n}$ and the axis vector $\mathbf{a}_f$ of the target face.
    $$ w_f = \max(\mathbf{a}_f \cdot \mathbf{n}, 0.0) $$
    *   For the $-x$ face, $\mathbf{a}_{-x} = (-1, 0, 0)$, so $w_{-x} = \max(-n_x, 0.0)$.
    *   For the $+x$ face, $\mathbf{a}_{+x} = (1, 0, 0)$, so $w_{+x} = \max(n_x, 0.0)$.
    *   Similar logic applies to $y$ and $z$ axes.
4.  **Accumulate:** Atomically add the weighted attribute to the corresponding face grid.
    $$ \text{grid}_f.\text{weighted\_value} \leftarrow \text{grid}_f.\text{weighted\_value} + (\text{attribute} \times w_f) $$
    $$ \text{grid}_f.\text{weight} \leftarrow \text{grid}_f.\text{weight} + w_f $$
5.  **Normalize (Post-process):** After all triangles are processed, normalize the stored values by dividing the weighted sum by the weight sum for each face.
    $$ \text{final\_value}_f = \frac{\text{weighted\_value}_f}{\text{weight}_f + \epsilon} $$
    *   $\epsilon$ is a small constant to prevent division by zero.

**Pseudocode**
```python
# Initialization
# six_grids: Array of 6 voxel grids, each with fields 'weighted_value' and 'weight'
# initialized to 0.0

def anisotropic_voxelization(triangles, voxel_dimensions):
    # 1. Rasterize triangles to fragments
    fragments = rasterize(triangles, voxel_dimensions)
    
    for frag in fragments:
        normal = frag.normal
        color = frag.color
        voxel_pos = frag.voxel_position
        
        # 2. Determine contributions to each of the 6 faces
        # Axis vectors for +x, -x, +y, -y, +z, -z
        axes = [
            (1, 0, 0),   # +x
            (-1, 0, 0),  # -x
            (0, 1, 0),   # +y
            (0, -1, 0),  # -y
            (0, 0, 1),   # +z
            (0, 0, -1)   # -z
        ]
        
        face_indices = [0, 1, 2, 3, 4, 5]
        
        for idx, axis in zip(face_indices, axes):
            # 3. Compute weight: max(dot(axis, normal), 0.0)
            # Dot product calculation
            dot_product = axis[0]*normal.x + axis[1]*normal.y + axis[2]*normal.z
            weight = max(dot_product, 0.0)
            
            # Skip if contribution is negligible or zero
            if weight < 1e-6:
                continue
            
            # 4. Atomic accumulation
            # Note: In a real implementation, this requires atomic operations
            # on the voxel grid memory
            grid = six_grids[idx]
            atomic_add(grid[voxel_pos].weighted_value, color * weight)
            atomic_add(grid[voxel_pos].weight, weight)

    # 5. Normalize grids
    for idx in range(6):
        grid = six_grids[idx]
        for voxel in grid:
            if voxel.weight > 1e-6:
                voxel.final_value = voxel.weighted_value / voxel.weight
            else:
                voxel.final_value = 0.0
```

**Parameters**
*   **Memory Multiplier:** 6x the memory of isotropic voxelization [S1, unofficial].
*   **Epsilon:** Small value for normalization stability (e.g., $10^{-6}$) [G].

**Edge Cases and Pitfalls**
*   **Thin Models:** In isotropic voxelization, normals from opposite sides of a thin surface (like cloth) average to zero, causing lighting failures. Anisotropic voxelization stores them separately, preventing cancellation [S1, unofficial].
*   **Light Leaks:** Isotropic voxels assign the same radiance to all 6 directions, potentially lighting surfaces facing away from light sources. Anisotropic voxelization restricts radiance to the correct face, reducing this artifact [S1, unofficial].
*   **Performance:** The need for atomic operations across 6 grids increases contention and reduces voxelization performance [S1, unofficial].
*   **MSAA:** Using Multi-Sample Anti-Aliasing (MSAA) render targets during the rasterization phase can further improve quality by handling sub-voxel coverage more accurately [S1, unofficial].

## Operating characteristics
*   **Memory Complexity:** $O(6 \cdot N)$, where $N$ is the number of voxels. Memory usage is six times that of isotropic voxelization [S1, unofficial].
*   **Time Complexity:** $O(F \cdot 6)$, where $F$ is the number of fragments. Each fragment performs 6 dot products and 6 atomic updates.
*   **Performance:** The voxelization stage is slower due to atomic averaging across 6 grids [S1, unofficial].
*   **Strengths:** Eliminates normal cancellation in thin geometry; significantly reduces light leaks; improves directional fidelity for anisotropic materials.
*   **Limitations:** High memory bandwidth and storage requirements; increased CPU/GPU load during voxelization due to atomic operations.
*   **When to Use:** Thin geometry (cloth, leaves), scenes with significant light leak artifacts in isotropic methods, or when directional normal data is critical for shading.
*   **When Not to Use:** Memory-constrained environments, simple homogeneous materials where directional data is less critical, or real-time applications where voxelization performance is a bottleneck.

## Background
Anisotropic voxelization was introduced as an improvement over isotropic voxelization methods to address specific artifacts in real-time ray-traced voxel global illumination. It is particularly noted in the context of Nvidia's research on voxel-based GI, where it was shown to significantly improve visual quality for thin surfaces and reduce light leaking [S1, unofficial]. The method trades increased memory and computational cost for higher fidelity in directional data storage.
