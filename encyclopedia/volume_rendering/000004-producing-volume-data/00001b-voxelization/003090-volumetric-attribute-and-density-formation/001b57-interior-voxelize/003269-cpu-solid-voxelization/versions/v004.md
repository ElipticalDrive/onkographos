# CPU Solid Voxelization

Also called: CPU Triangle Voxelization (Y-Z Plane Sweep), Solid Voxelization (Schwarz-Seidel)

## Overview
CPU Solid Voxelization is a deterministic, rasterization-based algorithm that converts a closed, watertight triangle mesh into a solid voxel grid by projecting triangles onto the Y-Z plane and sweeping along the X-axis [S1, unofficial]. It solves the problem of generating a dense interior volume representation on a CPU by iterating over the 2D projected bounding box of each triangle, testing voxel centers for point-in-triangle inclusion, and filling the corresponding X-axis voxels up to the surface intersection [S1, unofficial].

## How it works
**Inputs:** A closed, watertight triangle mesh (vertices and faces), a voxel grid resolution (`gridsize`), voxel unit size (`unit`), and a boolean flag for Morton ordering (`morton_order`) [S1, unofficial].
**Outputs:** A `voxel_table` array of `unsigned int` values, where each bit represents a voxel in the grid [S1, unofficial].

**Data Structures:**
*   `voxinfo`: A struct containing `gridsize` (int3: x, y, z dimensions), `unit` (float3: voxel width, height, depth), and `morton_order` (bool) [S1, unofficial].
*   `voxel_table`: A flat array of `unsigned int`. The size is `ceil(gridsize.x * gridsize.y * gridsize.z / 32.0f)` [S1, unofficial]. Bits are indexed from 0 to $N-1$. Bit $i$ corresponds to voxel index $i$. The bit position within an integer is calculated as `31 - (index % 32)` to align with standard bit-masking conventions where the least significant bit is index 0 [S1, unofficial].

**Parameters:**
*   `float_error`: $1.0 \times 10^{-6}$. Tolerance for skipping degenerate triangles with near-zero X-normal [S1, unofficial].

**Steps:**

1.  **Preprocessing:**
    *   Compute the bounding box of the mesh [S1, unofficial].
    *   Translate all mesh vertices so the bounding box minimum is at the origin by subtracting `bbox_min` from all vertices [S1, unofficial].
    *   *Note:* Some implementations pad the bounding box by $1/10001$ of its total length on all sides to mitigate numerical instability when triangles lie exactly on voxel edges [S1, unofficial].

2.  **Triangle Processing Loop:**
    For each triangle with vertices $v_0, v_1, v_2$:
    *   **Normal Calculation:** Compute edge vectors $e_0 = v_1 - v_0$, $e_1 = v_2 - v_1$, $e_2 = v_0 - v_2$. Compute the normal $n = \text{normalize}(\text{cross}(e_0, e_1))$ [S1, unofficial].
    *   **Degeneracy Check:** If $|n.x| < \text{float\_error}$, skip the triangle. This prevents division by zero or instability when calculating the X-coordinate of the intersection, as the triangle is nearly perpendicular to the X-axis [S1, unofficial].
    *   **Projection:** Project vertices to the Y-Z plane: $v_{0\_yz} = (v_0.y, v_0.z)$, $v_{1\_yz} = (v_1.y, v_1.z)$, $v_{2\_yz} = (v_2.y, v_2.z)$ [S1, unofficial].
    *   **Winding Order:** Ensure counter-clockwise (CCW) winding in the Y-Z plane. Compute the 2D cross product of edges: $result = (v_{1\_yz}.x - v_{0\_yz}.x)(v_{2\_yz}.y - v_{0\_yz}.y) - (v_{2\_yz}.x - v_{0\_yz}.x)(v_{1\_yz}.y - v_{0\_yz}.y)$. If $result \le 0$, swap $v_{1\_yz}$ and $v_{2\_yz}$ [S1, unofficial].
    *   **Bounding Box:** Compute the 2D bounding box of the projected triangle in world coordinates:
        $$bbox\_min = \min(v_{0\_yz}, v_{1\_yz}, v_{2\_yz})$$
        $$bbox\_max = \max(v_{0\_yz}, v_{1\_yz}, v_{2\_yz})$$
    *   **Grid Conversion:** Convert the world bounding box to grid indices:
        $$bbox\_min\_grid.y = \lceil \frac{bbox\_min.x}{unit.y} - 0.5 \rceil$$
        $$bbox\_min\_grid.z = \lceil \frac{bbox\_min.y}{unit.z} - 0.5 \rceil$$
        $$bbox\_max\_grid.y = \lfloor \frac{bbox\_max.x}{unit.y} - 0.5 \rfloor$$
        $$bbox\_max\_grid.z = \lfloor \frac{bbox\_max.y}{unit.z} - 0.5 \rfloor$$
        *(Note: The source code uses `info.unit.y` for the Y-axis grid conversion and `info.unit.z` for the Z-axis, mapping the Y-Z projection to grid columns and rows respectively)* [S1, unofficial].

3.  **Sweep and Fill:**
    Iterate $y$ from $bbox\_min\_grid.y$ to $bbox\_max\_grid.y$, and $z$ from $bbox\_min\_grid.z$ to $bbox\_max\_grid.z$:
    *   **Voxel Center:** Calculate the center point of the current voxel in world coordinates:
        $$point.y = (y + 0.5) \times unit.y$$
        $$point.z = (z + 0.5) \times unit.z$$
        *(Note: In the source, `point.x` corresponds to the Y-world coordinate and `point.y` to the Z-world coordinate, consistent with the Y-Z projection)* [S1, unofficial].
    *   **Point-in-Triangle Test:** Test if `point` is inside the projected triangle. The source uses a specific logic involving `checknum` and `TopLeftEdge` [S1, unofficial].
        *   Compute edge tests to determine `checknum` (0, 1, 2, or 3) indicating which edge or interior the point is relative to [S1, unofficial].
        *   The condition to proceed to filling is:
            $$(checknum == 1 \land TopLeftEdge(v_{0\_yz}, v_{1\_yz})) \lor (checknum == 2 \land TopLeftEdge(v_{1\_yz}, v_{2\_yz})) \lor (checknum == 3 \land TopLeftEdge(v_{2\_yz}, v_{0\_yz})) \lor (checknum == 0)$$
        *   `TopLeftEdge(v_a, v_b)` returns true if $v_b.y < v_a.y$ or ($v_b.y == v_a.y$ and $v_a.x > v_b.x$) [S1, unofficial].
    *   **X-Coordinate Calculation:** If the point is inside, calculate the maximum X grid index intersected by the triangle plane at this Y-Z position [S1, unofficial].
        *   The plane equation is $n \cdot (P - v_0) = 0$. Solving for $x$ given $y, z$:
            $$x_{coord} = v_0.x - \frac{n.y \cdot point.y + n.z \cdot point.z}{n.x}$$
            *(Derived from $n_x(x-v_{0x}) + n_y(y-v_{0y}) + n_z(z-v_{0z}) = 0$)* [S1, unofficial].
        *   Convert to grid index:
            $$xmax = \lfloor \frac{x_{coord}}{unit.x} - 0.5 \rfloor$$
    *   **Voxel Filling:** Iterate $x$ from $0$ to $xmax$ [S1, unofficial].
        *   Calculate the linear memory location. If `morton_order` is true, use a Morton code lookup table `mortonEncode_LUT(x, y, z)`. Otherwise, use linear indexing:
            $$index = x + y \times gridsize.y + z \times gridsize.y \times gridsize.z$$
        *   Set the bit in `voxel_table`. The source code uses `setBit` for surface marking but `setBitXor` for solid filling (flipping the bit state) to handle overlapping triangles correctly [S1, unofficial].

**Pseudocode:**

```python
import math

def cpu_solid_voxelization(mesh, gridsize, unit, morton_order=False):
    """
    mesh: list of triangles, each triangle is [(x,y,z), (x,y,z), (x,y,z)]
    gridsize: (gx, gy, gz)
    unit: (ux, uy, uz)
    morton_order: bool
    """
    total_voxels = gridsize[0] * gridsize[1] * gridsize[2]
    table_size = math.ceil(total_voxels / 32)
    voxel_table = [0] * table_size

    min_x = min(v[0] for tri in mesh for v in tri)
    min_y = min(v[1] for tri in mesh for v in tri)
    min_z = min(v[2] for tri in mesh for v in tri)
    
    translated_mesh = []
    for tri in mesh:
        new_tri = [(v[0]-min_x, v[1]-min_y, v[2]-min_z) for v in tri]
        translated_mesh.append(new_tri)

    float_error = 0.000001

    for v0, v1, v2 in translated_mesh:
        e0 = (v1[0]-v0[0], v1[1]-v0[1], v1[2]-v0[2])
        e1 = (v2[0]-v1[0], v2[1]-v1[1], v2[2]-v1[2])
        
        nx = e0[1]*e1[2] - e0[2]*e1[1]
        ny = e0[2]*e1[0] - e0[0]*e1[2]
        nz = e0[0]*e1[1] - e0[1]*e1[0]
        
        len_n = math.sqrt(nx*nx + ny*ny + nz*nz)
        if len_n == 0: continue
        
        nx, ny, nz = nx/len_n, ny/len_n, nz/len_n
        
        if abs(nx) < float_error:
            continue

        v0_yz = (v0[1], v0[2])
        v1_yz = (v1[1], v1[2])
        v2_yz = (v2[1], v2[2])

        cross_2d = (v1_yz[0]-v0_yz[0])*(v2_yz[1]-v0_yz[1]) - (v2_yz[0]-v0_yz[0])*(v1_yz[1]-v0_yz[1])
        if cross_2d <= 0:
            v1_yz, v2_yz = v2_yz, v1_yz

        bbox_min_yz = (min(v0_yz[0], v1_yz[0], v2_yz[0]), min(v0_yz[1], v1_yz[1], v2_yz[1]))
        bbox_max_yz = (max(v0_yz[0], v1_yz[0], v2_yz[0]), max(v0_yz[1], v1_yz[1], v2_yz[1]))

        bbox_min_grid_y = math.ceil(bbox_min_yz[0] / unit[1] - 0.5)
        bbox_min_grid_z = math.ceil(bbox_min_yz[1] / unit[2] - 0.5)
        bbox_max_grid_y = math.floor(bbox_max_yz[0] / unit[1] - 0.5)
        bbox_max_grid_z = math.floor(bbox_max_yz[1] / unit[2] - 0.5)

        for y in range(bbox_min_grid_y, bbox_max_grid_y + 1):
            for z in range(bbox_min_grid_z, bbox_max_grid_z + 1):
                point_y = (y + 0.5) * unit[1]
                point_z = (z + 0.5) * unit[2]
                
                checknum = check_point_triangle(v0_yz, v1_yz, v2_yz, (point_y, point_z))
                
                def topleft(va, vb):
                    return (vb[1] < va[1]) or (vb[1] == va[1] and va[0] > vb[0])
                
                if not ((checknum == 1 and topleft(v0_yz, v1_yz)) or 
                        (checknum == 2 and topleft(v1_yz, v2_yz)) or 
                        (checknum == 3 and topleft(v2_yz, v0_yz)) or 
                        (checknum == 0)):
                    continue

                x_coord = v0[0] - (ny * (point_y - v0[1]) + nz * (point_z - v0[2])) / nx
                xmax = math.floor(x_coord / unit[0] - 0.5)
                
                for x in range(0, xmax + 1):
                    if morton_order:
                        index = morton_encode(x, y, z)
                    else:
                        index = x + y * gridsize[1] + z * gridsize[1] * gridsize[2]
                    
                    int_loc = index // 32
                    bit_pos = 31 - (index % 32)
                    mask = 1 << bit_pos
                    voxel_table[int_loc] ^= mask

    return voxel_table

def check_point_triangle(v0, v1, v2, p):
    d0 = (v1[0]-v0[0])*(p[1]-v0[1]) - (v1[1]-v0[1])*(p[0]-v0[0])
    d1 = (v2[0]-v1[0])*(p[1]-v1[1]) - (v2[1]-v1[1])*(p[0]-v1[0])
    d2 = (v0[0]-v2[0])*(p[1]-v2[1]) - (v0[1]-v2[1])*(p[0]-v2[0])
    if d0 >= 0 and d1 >= 0 and d2 >= 0: return 0
    if d0 < 0: return 1
    if d1 < 0: return 2
    return 3

def morton_encode(x, y, z):
    # Standard 3D Morton code bit-interleaving [G]
    def interleave_bits(n):
        n = (n | (n << 16)) & 0x0003000F
        n = (n | (n << 8))  & 0x0300F00F
        n = (n | (n << 4))  & 0x30C30C30
        n = (n | (n << 2))  & 0x49249249
        return n
    return interleave_bits(x) | (interleave_bits(y) << 1) | (interleave_bits(z) << 2)
```

## Subtopics

### [Direct, triangle-parallel solid voxelization](9073-direct-triangle-parallel-solid-voxelization.md)
Direct, triangle-parallel solid voxelization is a data-parallel algorithm that determines all voxels inside a closed, watertight mesh by processing every triangle in parallel, dedicating one thread (or thread group) per triangle. It solves the problem of generating a dense voxel grid representation of a mesh on a GPU by projecting triangles onto the YZ plane, testing voxel columns for overlap, and using atomic operations to set the interior bits along the X axis. It differs from its sibling [Tile-Based Solid Voxelization](9087-tile-based-solid-voxelization.md) by grouping work by input primitive (triangles) rather than by spatial location (tiles), which avoids memory bandwidth bottlenecks and atomic serialization costs at the expense of warp underutilization.

## Background
The method is based on the Schwarz-Seidel algorithm, a classic solid voxelization technique [S1, unofficial]. It was implemented in the `cuda_voxelizer` project by Jeroen Baert as a CPU fallback for the primary CUDA-based voxelization methods [S1, unofficial]. The algorithm relies on the principle that a solid volume can be constructed by projecting surfaces onto a 2D plane and filling the interior along the projection axis [S1, unofficial].
