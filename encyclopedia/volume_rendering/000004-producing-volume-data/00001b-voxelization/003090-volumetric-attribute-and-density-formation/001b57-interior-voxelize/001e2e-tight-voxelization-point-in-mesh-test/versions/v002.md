# Tight Voxelization (Point-in-Mesh Test)
Also called: Interior Voxel Verification, Point-in-Mesh Test, Tetrahedron Point-Inclusion Test

## Overview
Tight Voxelization is an optional post-processing step that verifies if the center point of each voxel is inside or outside the mesh, removing voxels determined to be outside [S1, unofficial]. It is primarily used for volume meshes defined by tetrahedra, employing a point-in-tetrahedron test to distinguish it from surface mesh approaches [S2]. Unlike [Stochastic Ray-Casting Voxelization](1067-stochastic-ray-casting-voxelization.md) which probabilistically determines occupancy, this method provides a deterministic geometric check on the voxel center [S2].

## How it works
**Inputs and Outputs:**
- Input: A set of candidate voxels and a volume mesh defined by tetrahedra [S1, unofficial][S2].
- Output: A refined set of voxels where only those with centers inside the mesh are retained [S1, unofficial].

**Data Structures:**
- **Voxel Center:** A 3D point $P = (x, y, z)$ representing the center of a voxel [S2].
- **Tetrahedron:** Defined by four vertices $A, B, C, D$ [S2].
- **Triangle:** A face of the tetrahedron defined by three vertices [S2].

**Algorithm Steps:**
The method checks if a point $P$ is inside a tetrahedron defined by vertices $A, B, C, D$ [S2].
1. **Decompose Tetrahedron:** Identify the four triangular faces that make up the surface of the tetrahedron [S2].
2. **Calculate Normals:** For each of the four triangles, calculate its normal vector [S2].
3. **Verify Orientation:** Verify that the calculated normals point away from the center of the tetrahedron [S2].
4. **Plane Test:** Check if point $P$ is on the opposite side of the plane for each of the four triangles [S2].
5. **Classification:** If $P$ is on the opposite side of the plane for all four triangles, classify $P$ as inside the tetrahedron [S2].

**Parameters:**
- `--tight`: A command-line flag to enable this verification. Default is `false` [S1, unofficial].

**Edge Cases and Pitfalls:**
- **Performance Cost:** This option is time-consuming [S1, unofficial].
- **Orientation Dependency:** The test requires consistent outward-facing normals for the tetrahedron faces [S2].
- **Boundary Precision:** Points exactly on a face may be misclassified due to floating-point precision [G].

**Pseudocode:**
```python
def is_point_in_tetrahedron(P, A, B, C, D):
    """
    Checks if point P is inside tetrahedron ABCD.
    Assumes vertices are ordered such that face normals point outward.
    """
    # Define the four faces of the tetrahedron
    faces = [
        (A, B, C),
        (A, B, D),
        (A, C, D),
        (B, C, D)
    ]
    
    for V1, V2, V3 in faces:
        # Calculate normal vector for the triangle
        edge1 = [V2[i] - V1[i] for i in range(3)]
        edge2 = [V3[i] - V1[i] for i in range(3)]
        normal = [
            edge1[1] * edge2[2] - edge1[2] * edge2[1],
            edge1[2] * edge2[0] - edge1[0] * edge2[2],
            edge1[0] * edge2[1] - edge1[1] * edge2[0]
        ]
        
        # Vector from vertex on plane to point P
        vec_to_P = [P[i] - V1[i] for i in range(3)]
        
        # Dot product to determine side of the plane
        dot_product = sum(normal[i] * vec_to_P[i] for i in range(3))
        
        # If normals point outward, an interior point yields a negative dot product.
        # If dot_product >= 0, P is on the outside or on the plane.
        if dot_product >= 0:
            return False
            
    return True

def tight_voxelization(voxels, tetrahedra):
    """
    Filters voxels based on whether their center is inside the mesh.
    Iterates through candidate voxels and tests containment against mesh tetrahedra.
    """
    valid_voxels = []
    for voxel in voxels:
        center = voxel.center
        inside = False
        # Test against each tetrahedron in the volume mesh
        for tet in tetrahedra:
            if is_point_in_tetrahedron(center, *tet.vertices):
                inside = True
                break
        if inside:
            valid_voxels.append(voxel)
    return valid_voxels
```

## Operating characteristics
- **Performance:** The operation is noted as time-consuming [S1, unofficial].
- **Strengths:** Provides a deterministic check for volume meshes (tetrahedral) [S2].
- **Limitations:** High computational cost [S1, unofficial]. Only applicable to volume meshes or requires decomposition for surface meshes [S2].
- **Time Complexity:** Not given in the sources.
- **Memory Complexity:** Not given in the sources.

## Background
This method is implemented in the `CudaVox` library, which is part of the `cad2vox` project [S2]. It is designed for volume meshes based on tetrahedrons, contrasting with the surface mesh voxelization methods (like those by Schwarz and Seidel) also supported by `CudaVox` [S2]. The approach is a straightforward geometric inclusion test [S2].
