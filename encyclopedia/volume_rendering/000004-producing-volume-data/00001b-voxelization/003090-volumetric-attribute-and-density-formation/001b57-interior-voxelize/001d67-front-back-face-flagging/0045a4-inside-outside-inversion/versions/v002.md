# Inside/Outside Inversion

Also called: Invert Volume, Swap Inside/Outside

## Overview
Inside/Outside Inversion is a configuration step in volumetric rendering that swaps the semantic definition of "interior" and "exterior" relative to a surface threshold [S1]. It solves the problem of ambiguous or inverted volume data where the default assumption (values above threshold are inside) does not match the physical or logical reality of the dataset [G]. It distinguishes itself from [Inside-Outside Voxelization](3081-inside-outside-voxelization.md) by operating on the scalar field interpretation rather than the geometric voxelization process itself [G].

## How it works
**Inputs and Outputs:**
The input is a scalar volume grid $V$ and a threshold value $T$ [G]. The output is a modified interpretation of the volume where the boolean classification of voxels as "inside" or "outside" is inverted [G].

**Data Structures:**
No new data structures are created. The method modifies the evaluation logic or a boolean mask $M$ derived from $V$ [G].
- $V$: 3D array of scalar values.
- $T$: Scalar threshold (isosurface level).
- $M$: Boolean mask where $M_{ijk} = \text{Inside}(V_{ijk}, T)$.

**Steps:**
1. Evaluate the scalar value $v$ at the current voxel.
2. Compare $v$ against the threshold $T$.
3. Apply the inversion logic:
   - Default: If $v > T$, the voxel is Inside [S1].
   - Inverted: If $v \le T$, the voxel is Inside [S1].

**Formulas:**
Let $I(v, T)$ be the indicator function for the inside region.
Default:
$$ I_{default}(v, T) = \begin{cases} 1 & \text{if } v > T \\ 0 & \text{otherwise} \end{cases} $$
Inverted:
$$ I_{inverted}(v, T) = \begin{cases} 1 & \text{if } v \le T \\ 0 & \text{otherwise} \end{cases} $$

**Parameters:**
- `invert`: Boolean flag. Default `false` [S1].

**Edge Cases and Pitfalls:**
- **Precision:** Floating point comparisons near $T$ must be consistent. Using strict inequality ($>$) vs non-strict ($\ge$) affects boundary voxels [G]. The source [S1] specifies "above the surface level" as internal, implying strict inequality for the default.
- **Significance:** Inversion is critical when the sign of the data carries meaning (e.g., electrostatic potential), where "outside" is not simply "low value" but depends on the polarity relative to the threshold [S2].

**Pseudocode:**
```python
def evaluate_voxel_inside(v, threshold, invert=False):
    """
    Determines if a voxel is inside the volume based on its scalar value.
    
    Args:
        v (float): Scalar value of the voxel.
        threshold (float): The isosurface level.
        invert (bool): If True, swaps inside/outside definitions.
        
    Returns:
        bool: True if the voxel is considered 'inside'.
    """
    if not invert:
        # Default: values above threshold are internal
        return v > threshold
    else:
        # Inverted: values at or below threshold are internal
        # Note: Source [S1] says "swaps the inside and outside"
        # Default inside is v > T. Inverted inside is v <= T.
        return v <= threshold
```

## Subtopics

### Normal Flipping
A configuration option that inverts the definition of 'outside' specifically for lighting and culling purposes, useful for data where the sign of the scalar field is meaningful (e.g., electrostatic potential) [S2]. It differs from simple volume inversion by affecting surface normal orientation for shading rather than just the binary inside/outside mask for ray marching or voxelization [G].

**Step:**
1. Check the `flipNormals` flag.
2. If `flipNormals` is true:
   - If threshold $T < 0$: Treat the side toward larger/more positive values as outside [S2].
   - If threshold $T > 0$: Treat the side toward smaller/more negative values as outside [S2].
3. If `flipNormals` is false:
   - Always treat the side toward smaller/more negative data values as outside [S2].

## Operating characteristics
**Time and Memory Complexity:**
$O(1)$ per voxel evaluation. No additional memory is required beyond the flag [G].

**Measured Performance:**
Not given in the sources.

**Scaling:**
Linear with the number of voxels evaluated [G].

**Strengths and Limitations:**
- **Strengths:** Allows correct rendering of signed scalar fields without modifying the underlying data [G].
- **Limitations:** Can cause visual artifacts if the threshold is chosen poorly relative to the data distribution [G].

**When to use it:**
Use when the default "high value = inside" assumption is physically incorrect for the dataset [G].

## Background
The concept is implemented as a configuration option in volume rendering software packages such as Phoenix for 3ds Max [S1] and UCSF ChimeraX [S2]. It is commonly used in scientific visualization where scalar fields represent physical quantities with inherent signs (positive/negative) [G].
