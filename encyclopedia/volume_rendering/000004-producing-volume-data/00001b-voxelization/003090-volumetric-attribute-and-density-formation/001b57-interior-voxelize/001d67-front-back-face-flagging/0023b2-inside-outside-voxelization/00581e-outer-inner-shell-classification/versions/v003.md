# Outer/Inner Shell Classification

Also called: Six outerShell coplanaires et un innerShell géométrique, VXL-045 Outer/Inner Shell Classification

## Overview
Outer/Inner Shell Classification is a voxelization preprocessing step that partitions polygonal geometry into boundary-aligned outer shells and internal inner shells to optimize occlusion culling and rendering [S1]. It separates polygons into six groups based on coplanarity with the voxel grid boundaries ($X=0$, $X=1000$, $Y=0$, $Y=1000$, $Z=0$, $Z=1000$) and one group for all other internal geometry [S1]. Unlike methods that project all geometry for boundary occlusion, this method restricts 2D boundary masks to only those polygons coplanar with the boundaries, preventing interior polygons from incorrectly occluding the shell [S1].

## How it works
**Inputs:** A polygonal mesh (Shape) defined in a local coordinate space with boundaries at $X \in [0, 1000]$, $Y \in [0, 1000]$, $Z \in [0, 1000]$ [S1].
**Outputs:** Six outerShell coverage masks (2D bitmasks of size $1000 \times 1000$) and a list of retained innerShell 3D polygons [S1].

**Data Structures:**
*   `outerShell_masks`: A dictionary or array of six 2D boolean arrays (or bitmasks), each of size $1000 \times 1000$ [S1]. Indices correspond to $(X, Y)$, $(X, Z)$, or $(Y, Z)$ projections depending on the boundary plane [S1].
*   `innerShell_polygons`: A list of 3D polygon objects (vertices, normals, etc.) [S1].
*   `aabb_unions`: Axis-Aligned Bounding Boxes computed for each outerShell group to optimize mask generation [S1].

**Steps:**
1.  **Classification:** Iterate through every polygon $P$ in the input Shape [S1].
    *   Check if $P$ is coplanar with any of the six boundary planes: $X=0$, $X=1000$, $Y=0$, $Y=1000$, $Z=0$, or $Z=1000$ [S1].
    *   If coplanar, assign $P$ to the corresponding `outerShell` group [S1].
    *   If not coplanar with any boundary plane, assign $P$ to the `innerShell` group [S1].
    *   A polygon belongs to the innerShell group if it is not fully coplanar with any of the six boundary planes [S1].

2.  **OuterShell Mask Generation:**
    *   For each of the six outerShell groups:
        *   Compute the 2D projection of the polygons in that group onto the relevant boundary plane [S1].
        *   Generate a 2D coverage mask of resolution $1000 \times 1000$ [S1].
        *   Compute the Axis-Aligned Bounding Box (AABB) union of the projected polygons to limit the area of mask computation [S1].
        *   Fill the mask bits corresponding to the projected area [S1].
    *   *Constraint:* Do **not** project innerShell geometry into these masks [S1]. Only coplanar outerShell polygons contribute to boundary occlusion information [S1].

3.  **InnerShell Retention:**
    *   Retain all polygons classified as `innerShell` in the output list [S1].
    *   Do not discard innerShell polygons based on outerShell visibility or presence [S1]. A Shape with only innerShell polygons has six empty outerShell coverages but is not considered an empty Shape [S1].

**Parameters:**
*   Grid Resolution: Fixed at $1000 \times 1000$ for the 2D masks [S1].
*   Boundary Coordinates: Fixed at $0$ and $1000$ for X, Y, and Z axes [S1].

**Edge Cases and Pitfalls:**
*   **Precision:** The guaranteed precision is that of the grid, not sub-pixel precision [S1].
*   **Occlusion Error:** Do not use projections of interior (innerShell) polygons as boundary occlusion masks [S1]. This prevents incorrect occlusion of the shell by internal geometry [S1].
*   **Empty Shapes:** A Shape composed exclusively of innerShell polygons results in six empty outerShell coverages but must still be processed for its inner geometry [S1].
*   **Unspecified Details:** Exact rules for filling, border handling, slot separation, caching, rectangle decomposition, and mesh generation are not specified in the source [S1].

## Subtopics

### Conditional InnerShell Emission
This variant (VXL-046) defines the visibility rule for innerShell polygons [S1]. It states that innerShell emission does not depend on the presence or visibility of the outerShell in the current cell [S1]. Instead, it depends on the complete opaque closure of the six boundaries by neighboring cells [S1]. An isolated Shape without outerShell retains its innerShell [S1]. However, a Shape enclosed by six neighbors that are fully opaque omits its innerShell during the bake process [S1].

## Operating characteristics
*   **Time Complexity:** Linear with respect to the number of polygons for classification [S1]. Mask generation is proportional to the area of the $1000 \times 1000$ grid, optimized by AABB unions [S1].
*   **Memory Complexity:** Requires storage for six $1000 \times 1000$ masks and the list of innerShell polygons [S1].
*   **Strengths:** Reduces boundary occlusion noise by ignoring non-coplanar interior geometry [S1]. Optimizes rendering by conditionally emitting innerShell geometry based on neighbor occlusion [S1].
*   **Limitations:** Fixed grid resolution ($1000$) may not suit all scenes [S1]. Unspecified details for mesh generation and caching may require implementation decisions [S1].
*   **When to use:** When accurate boundary occlusion is required without false occlusion from internal geometry, and when neighbor-based culling of internal surfaces is beneficial [S1].

## Background
This method is part of the Voxel Engine design specification (VXL-045 and VXL-046) developed by EreliaStudio for the Sparkle engine [S1].
