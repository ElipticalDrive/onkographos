# Interior Voxelize

Also called: Naive Model Filling, fillNaive

## Overview
Interior Voxelize determines which voxels in a discrete 3D grid lie inside a target mesh by sampling points within the grid volume and testing for geometric containment [S1, unofficial][S2, unofficial][S3, unofficial]. It solves the problem of converting a continuous surface representation into a solid volumetric occupancy field. It differs from its siblings [Shell-based Voxelization](1748-shell-based-voxelization.md) and [Ray-Cast Style Voxel Filling](1502-ray-cast-style-voxel-filling.md) by relying on direct point-in-mesh queries rather than ray intersection counts or boundary shell extraction [S1, unofficial][S2, unofficial][S3, unofficial].

## How it works
**Inputs and Outputs:**
*   **Input:** A closed 3D mesh and a target grid resolution $N$ (typically along the maximum bounding box dimension) [S3, unofficial].
*   **Output:** A 3D boolean grid (Bitmap) where `true` indicates the voxel center is inside the mesh, and `false` indicates it is outside [S3, unofficial].

**Data Structures:**
1.  **Spatial Index:** An AABB tree built over the input mesh triangles to accelerate point-in-mesh queries [S3, unofficial].
2.  **Grid Indexer:** A mapping structure (e.g., `ShiftGridIndexer3`) that converts integer grid coordinates $(i, j, k)$ to world-space coordinates $(x, y, z)$ based on the mesh's bounding box and cell size [S3, unofficial].
3.  **Bitmap:** A 3D array of booleans with dimensions $(N, N, N)$ [S3, unofficial].

**Parameters:**
*   `numcells` ($N$): The resolution of the voxel grid along the longest axis of the bounding box. Typical value: 32 [S3, unofficial].
*   `numVoxelizationSamples`: In sampling-based implementations, the number of points used. Calculated as $Volume(AABB) \times 10000$ [S1, unofficial].

**Steps:**
1.  **Build Spatial Index:** Construct a spatial acceleration structure (e.g., `DMeshAABBTree3`) from the input mesh with auto-build enabled [S3, unofficial].
2.  **Compute Bounds:** Determine the axis-aligned bounding box (AABB) of the mesh, denoted as $B_{min}$ and $B_{max}$ [S3, unofficial].
3.  **Calculate Cell Size:** Compute the voxel edge length $s$ using the maximum dimension of the bounding box:
    $$ s = \frac{\max(B_{max} - B_{min})}{N} $$
    [S3, unofficial]
4.  **Initialize Indexer:** Create a grid indexer mapping grid indices to world space using $B_{min}$ and $s$ [S3, unofficial].
5.  **Initialize Bitmap:** Create a 3D boolean array `bmp` of size $(N, N, N)$ [S3, unofficial].
6.  **Iterate and Test:** For each grid index $(i, j, k)$ in the bitmap:
    a. Map the index to a world-space point $P$ using the indexer: $P = \text{Indexer.FromGrid}(i, j, k)$ [S3, unofficial].
    b. Query the spatial index to determine if $P$ is inside the mesh: $inside = \text{Spatial.IsInside}(P)$ [S3, unofficial].
    c. Set `bmp[i, j, k] = inside` [S3, unofficial].

**Alternative Implementation (Point Sampling):**
1. Calculate total samples $S = Volume(AABB) \times 10000$ [S1, unofficial].
2. Sample $S$ points from the model using a sampling function [S1, unofficial].
3. Map each point to a grid index [S1, unofficial].
4. Mark the corresponding grid cell as VOXEL_FREE if the point is inside [S1, unofficial].
*Note:* S2 uses a regular grid with added noise and normalization to $[-0.5, 0.5]$ before containment checks [S2, unofficial].

**Edge Cases and Pitfalls:**
*   **Resolution:** Low resolution (e.g., $N=32$) results in blocky approximations of curved surfaces [S3, unofficial].
*   **Precision:** Floating-point errors in `IsInside` queries near the surface may cause isolated false positives or negatives [G].

**Pseudocode:**
```python
def interior_voxelize(mesh, numcells=32):
    # Step 1: Compute Bounds
    bounds_min = mesh.bounds_min
    bounds_max = mesh.bounds_max

    # Step 2: Calculate Cell Size
    max_dim = max(bounds_max.x - bounds_min.x,
                  bounds_max.y - bounds_min.y,
                  bounds_max.z - bounds_min.z)
    cell_size = max_dim / numcells

    # Step 3: Initialize Bitmap
    bitmap = [[False] * numcells for _ in range(numcells * numcells)]

    # Step 4: Iterate and Test
    for i in range(numcells):
        for j in range(numcells):
            for k in range(numcells):
                # Map grid index to world coordinate (ShiftGridIndexer3 logic)
                world_x = bounds_min.x + (i + 0.5) * cell_size
                world_y = bounds_min.y + (j + 0.5) * cell_size
                world_z = bounds_min.z + (k + 0.5) * cell_size

                # Step 5: Query Containment
                # Standard operation: point-in-mesh test via spatial index
                is_inside = standard_point_in_mesh_query(world_x, world_y, world_z, mesh)
                bitmap[i * numcells * numcells + j * numcells + k] = is_inside

    return bitmap
```
