# Slice Filling with BFS Propagation

Also called: FillXY2, FillXZ2, FillYZ2

## Overview
Slice Filling with BFS Propagation extends [Slice Filling (Simple)](1691-slice-filling-simple.md) by propagating filled voxels to adjacent neighbors within the slice plane using a Breadth-First Search (BFS) [S1, unofficial]. It solves the problem of ensuring contiguous solid regions in a 2D slice are fully filled, rather than just marking the boundary voxels hit by rays. It differs from its parent by actively searching for and filling empty neighbors that are not solid in either the main voxel grid or the current buffer [S1, unofficial].

## How it works
**Inputs and Outputs:**
*   **Input:** A 3D voxel grid (`voxels_`), a 2D buffer for the current slice (`voxels_buffer_`), and the bounding box of the slice (defined by min/max coordinates along the three axes, e.g., $lx, ux, ly, uy, lz, uz$).
*   **Output:** The `voxels_buffer_` is updated to include all voxels filled by the BFS propagation.

**Data Structures:**
*   `voxels_`: The main 3D voxel grid storing the state of each voxel (solid or empty).
*   `voxels_buffer_`: A 2D buffer corresponding to the current slice being processed.
*   `BfsSolid`: A helper function that performs the BFS propagation from a given voxel index.

**Steps:**
The algorithm iterates through the slice plane along two axes. For each axis, it performs a forward scan and a backward scan.

1.  **Forward Scan:**
    *   Iterate through the slice plane along the primary axis (e.g., $y$ for $FillYZ2(x)$).
    *   For each position, iterate through the secondary axis (e.g., $z$ for $FillYZ2(x)$).
    *   Compute the voxel index for the current position.
    *   Load the state from `voxels_`.
    *   If the voxel is solid, break the forward scan for this direction.
    *   If the voxel is not solid, check its 4 neighbors in the slice plane (using predefined offsets, e.g., $DI\_4$).
    *   For each neighbor within bounds:
        *   Compute the neighbor's index.
        *   Load the combined state from `voxels_` and `voxels_buffer_`.
        *   If the neighbor is not solid, call `BfsSolid` on the neighbor's index.

2.  **Backward Scan:**
    *   Iterate through the slice plane along the primary axis in reverse (e.g., $z$ from $uz$ down to $lz$ for $FillYZ2(x)$).
    *   Compute the voxel index for the current position.
    *   Load the state from `voxels_`.
    *   If the voxel is solid, break the backward scan for this direction.
    *   If the voxel is not solid, check its 4 neighbors in the slice plane.
    *   For each neighbor within bounds:
        *   Load the combined state from `voxels_` and `voxels_buffer_`.
        *   If the neighbor is not solid, call `BfsSolid` on the neighbor's index.

**Pseudocode:**
The following pseudocode illustrates the logic for $FillYZ2(x)$, where the slice is fixed at a specific $x$ coordinate. The logic for $FillXZ2(y)$ and $FillXY2(z)$ is analogous, adjusting the axes and neighbor offsets accordingly.

```python
def FillYZ2(x, ly, uy, lz, uz, voxels_, voxels_buffer_, BfsSolid):
    # Forward scan: Iterate y from ly to uy
    for y in range(ly, uy + 1):
        # Inner loop: Iterate z from lz to uz
        for z in range(lz, uz + 1):
            voxel_index = compute_index(x, y, z)
            
            # Load state from main voxel grid
            is_solid = voxels_[voxel_index].is_solid
            
            if is_solid:
                # Break forward scan if a solid voxel is encountered
                break
            
            # Check 4 neighbors in the YZ plane
            # Assuming DI_4 provides offsets for (dy, dz) pairs: (0,1), (0,-1), (1,0), (-1,0)
            for dy, dz in DI_4:
                ny = y + dy
                nz = z + dz
                
                # Check bounds
                if ly <= ny <= uy and lz <= nz <= uz:
                    neighbor_index = compute_index(x, ny, nz)
                    
                    # Load combined state from main grid and buffer
                    is_solid_main = voxels_[neighbor_index].is_solid
                    is_solid_buffer = voxels_buffer_[neighbor_index].is_solid
                    
                    if not is_solid_main and not is_solid_buffer:
                        # Call BFS propagation if neighbor is not solid
                        BfsSolid(neighbor_index, voxels_, voxels_buffer_)

    # Backward scan: Iterate z from uz down to lz
    for z in range(uz, lz - 1, -1):
        # Inner loop: Iterate y from uy down to ly
        for y in range(uy, ly - 1, -1):
            voxel_index = compute_index(x, y, z)
            
            # Load state from main voxel grid
            is_solid = voxels_[voxel_index].is_solid
            
            if is_solid:
                # Break backward scan if a solid voxel is encountered
                break
            
            # Check 4 neighbors in the YZ plane
            for dy, dz in DI_4:
                ny = y + dy
                nz = z + dz
                
                # Check bounds
                if ly <= ny <= uy and lz <= nz <= uz:
                    neighbor_index = compute_index(x, ny, nz)
                    
                    # Load combined state from main grid and buffer
                    is_solid_main = voxels_[neighbor_index].is_solid
                    is_solid_buffer = voxels_buffer_[neighbor_index].is_solid
                    
                    if not is_solid_main and not is_solid_buffer:
                        # Call BFS propagation if neighbor is not solid
                        BfsSolid(neighbor_index, voxels_, voxels_buffer_)
```

**Parameters:**
*   `BfsSolid`: A function that performs BFS propagation from a voxel index. It typically adds the voxel to a queue, marks it as filled, and processes its neighbors. The exact implementation of `BfsSolid` is not detailed in the sources [S1, unofficial].

**Edge Cases and Pitfalls:**
*   **Bounds Checking:** Neighbors must be checked against the slice boundaries ($ly, uy, lz, uz$) to avoid out-of-bounds access.
*   **Solid Voxels:** The scan breaks when a solid voxel is encountered in the main grid. This prevents propagation through solid objects.
*   **Combined State:** The decision to propagate depends on the voxel being empty in *both* the main grid and the buffer. If it is solid in either, propagation stops for that neighbor.

## Subtopics

### [BFS Light Propagation](2164-bfs-light-propagation.md)
BFS Light Propagation is a voxel-based lighting algorithm that propagates light levels from emitters across a padded voxel chunk using a Breadth-First Search (BFS). It solves the problem of efficiently illuminating non-opaque blocks in a voxel grid while attenuating light intensity with distance. It differs from its parent, [Slice Filling with BFS Propagation](1909-slice-filling-with-bfs-propagation.md), by operating on the full 3D padded chunk rather than just the slice plane, and by explicitly modeling light attenuation per step.
