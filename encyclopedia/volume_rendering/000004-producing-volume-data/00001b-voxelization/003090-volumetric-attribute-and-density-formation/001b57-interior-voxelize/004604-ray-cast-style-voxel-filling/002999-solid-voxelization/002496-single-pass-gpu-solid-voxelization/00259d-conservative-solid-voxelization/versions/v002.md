# Conservative Solid Voxelization
Also called: Conservative Interior Voxelization

## Overview
Conservative Solid Voxelization is a technique to fill voxels that are partially interior, addressing the issue where thin geometry misses voxel centers and is annihilated by XOR blending [S1, unofficial][S2, unofficial]. It builds on [Single-pass GPU Solid Voxelization](3323-single-pass-gpu-solid-voxelization.md) by adding a conservative boundary pass to ensure no surface-touching voxels are lost, resulting in a conservative solid voxelization [S1, unofficial][S2, unofficial].

## How it works
**Inputs:** Scene geometry, voxel grid resolution.
**Outputs:** Conservative solid voxelization buffer. Optionally, a conservative interior-only buffer.
**Data Structures:** A framebuffer or texture for the voxelization grid, and a small 1D bitmask texture used to encode depth intervals [S1, unofficial][S2, unofficial]. Exact layouts, fields, sizes, and bit packing are not given in the sources.
**Steps:**
1. Render the scene once with the standard single-pass solid voxelization algorithm [S1, unofficial][S2, unofficial].
2. Perform a conservative boundary voxelization [38] and add it to the same texture [S1, unofficial][S2, unofficial].
3. Blend the result into the buffer using an OR operation (not XOR) to create the conservative boundary [S1, unofficial][S2, unofficial].
4. Keep the solid voxelization in the framebuffer before adding the hull to obtain the final conservative solid voxelization [S1, unofficial][S2, unofficial].
5. Optional: To derive conservative interior only (no boundary), compute the conservative overestimate and subtract the conservative boundary voxelization using XOR blending [S1, unofficial][S2, unofficial]. This delivers the conservative interior without boundary in three passes [S1, unofficial][S2, unofficial].
**Implementation Details:**
- Use the small 1D bitmask texture to transform depth extremes into a bitmask [S1, unofficial][S2, unofficial].
- Shift the farther depth value by one voxel distance, leaving the near value unmodified [S1, unofficial][S2, unofficial].
- Compute the XOR of the corresponding bitmasks in the shader (or subtraction for older cards) to activate voxels between the extents [S1, unofficial][S2, unofficial].
- The offset applied to the farther depth value ensures that all voxels lying partially between these two extremes are activated [S1, unofficial][S2, unofficial].
**Formula:**
To get conservative interior only (no boundary), subtract the conservative boundary voxelization from the conservative overestimate using XOR:
$$ Result = ConservativeInterior \text{ XOR } ConservativeBoundary $$
[S1, unofficial][S2, unofficial]
**Parameters:**
- Depth shift: One voxel distance for the farther depth value [S1, unofficial][S2, unofficial].
**Edge Cases and Pitfalls:**
- Depth range derivation is currently problematic [S1, unofficial][S2, unofficial].
- Thin geometry may miss voxel centers and be annihilated by XOR, which this method addresses [S1, unofficial][S2, unofficial].
- Hardware compatibility: Use subtraction instead of XOR for older cards [S1, unofficial][S2, unofficial].

## Background
Conservative Solid Voxelization is described in the context of single-pass GPU solid voxelization for real-time applications [S1, unofficial][S2, unofficial]. It is used for applications like conservative visibility testing [S1, unofficial][S2, unofficial].
