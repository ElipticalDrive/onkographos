# Solid Voxelization

Also called: BfsSolid, Bulk Voxelization, Two-Level Model Voxelization

## Overview
Solid Voxelization fills the interior volume of a mesh with voxels, producing a dense volumetric representation rather than a surface shell [S1, S2, unofficial]. It builds on [Ray-Cast Style Voxel Filling](1502-ray-cast-style-voxel-filling.md) by first identifying surface voxels and then propagating that information into the interior [S1, S2, unofficial]. It is distinguished from [Slice Filling (Simple)](1691-slice-filling-simple.md) by its use of a two-level grid model, bitset compression, and explicit boundary checks (via BFS or filter-and-refine) to handle non-watertight inputs or complex topologies [S1, S2, unofficial].

## How it works
The method operates in two phases: surface identification (typically GPU-accelerated) and interior filling (CPU or GPU-based BFS or filter-and-refine) [S1, S2, unofficial]. The implementation uses a two-level grid model with bitset compression to store voxel states efficiently [S1, S2, unofficial].

### Inputs and Outputs
- **Input**: A triangle mesh defined by vertices, indices, and a bounding box; a physical voxel size `gridVoxelSize` [S1, unofficial].
- **Output**: A 3D boolean grid where `true` indicates a solid voxel inside the mesh [S1, S2, unofficial].

### Data Structures
**Mesh Data (CPU/GPU Transfer)** [S1, unofficial]:
- `MeshDataDevice`:
  - `bbox[6]`: `float` array, min/max x, y, z of the mesh bounding box [S1, unofficial].
  - `vertices`: Array of `Vector3Df` (x, y, z) [S1, unofficial].
  - `triangles`: Array of `Triangle` structs [S1, unofficial].
  - `trianglesNo`: `int*`, count of triangles [S1, unofficial].
  - `_bottom`, `_top`: `Vector3Df`, bounding box corners of individual triangles [S1, unofficial].
- `Triangle`:
  - `_idx1`, `_idx2`, `_idx3`: `int`, indices into `vertices` [S1, unofficial].
  - `_bottom`, `_top`: `Vector3Df`, local bounding box [S1, unofficial].

**Voxel Grid** [S1, S2, unofficial]:
- `voxels_`: Bitset array representing the final solid state [S2, unofficial].
- `voxels_buffer_`: Bitset array used during computation (e.g., BFS queue or filter results) [S2, unofficial].
- `voxel_metas_`: Optional metadata array (e.g., `Surface()` flag) [S1, unofficial].
- `kBatchSize`: Constant for bitset indexing (e.g., 64 or 32, depending on implementation) [S2, unofficial].

### Parameters
- `gridVoxelSize`: Physical size of one voxel side [S1, unofficial].
- `num_thread`: Number of threads for parallel execution [S1, S2, unofficial].
- `WithMeta`: Boolean flag to enable metadata updates (solid marking) [S1, unofficial].

### Algorithm Steps

#### Phase 1: Setup and Surface Voxelization (GPU) [S1, unofficial]
1. **Preprocessing**: Compute `globalTranslation` from `meshData->bbox[0..2]` [S1, unofficial].
2. **Grid Setup**: Compute grid dimensions using `ops::computeTwoLevelSizes(meshData->bbox, gridVoxelSize)` [S1, unofficial].
3. **Memory Allocation**: Allocate `gpuData` of type `MeshDataDevice` on the GPU [S1, unofficial].
4. **Data Transfer**: Copy `meshData` to `gpuData` using `copyMeshData2Device->copyData` [S1, unofficial].
5. **Kernel Launch**: Launch `solidVoxelGpu` with `numBlocks = ceil(totNumThreads / 256)` and `numThreads = 256`, where `totNumThreads` equals the number of triangles [S1, unofficial].
6. **Triangle Voxelization**: Each thread processes one triangle via `voxelizeTriangleSolidGpu`, which iterates over the triangle's bounding box, computes edge normals, applies distance tests, and flips the corresponding bit in `grid->vTable1` [S1, unofficial].

#### Phase 2: Interior Filling
Two variants exist for filling the interior after surface voxels are marked [S1, S2, unofficial].

**Variant A: BFS with Two-Level Model [S1, S2, unofficial]**
1. **Slice Fill**: Launch `fillBulkVoxelGpu` with `totNumThreads = gridSize^2` [S1, unofficial]. Each thread processes a Y-slice, identifies surface voxels, and fills bits from the first surface voxel to the end of the slice [S1, unofficial].
2. **BFS Initialization**: Select a `start_index` (typically an exterior voxel) and call `BfsSolid(start_index)` [S2, unofficial].
3. **BFS Execution**: The BFS traverses 6-connected neighbors, marking voxels in `voxels_buffer_` if they are not already marked in `voxels_` or `voxels_buffer_` [S2, unofficial].
4. **Final Inversion**: Iterate `i` from `0` to `compressed_total_size - 1` and update `voxels_[i] = voxels_buffer_[i] ^ (~0)` to invert the buffer and mark interior voxels [S2, unofficial].
5. **Metadata Update (Optional)**: If `WithMeta()` is true, iterate all voxels; if a bit is set and `Surface()` is false, call `SetSolid()` [S1, unofficial].

**Variant B: Filter-and-Refine [S2, unofficial]**
1. **Filter Step**: For each axis, fix the other two coordinates and enumerate voxels along the axis [S2, unofficial]. If a voxel is occupied (by surface voxelization), stop filling in that direction [S2, unofficial]. Mark all visible voxels as filled in a temporary buffer [S2, unofficial].
2. **Refine Step**: Identify "holes" (voxels not marked as visible along any axis) and perform a standard flood fill (BFS) only on these remaining empty voxels [S2, unofficial].
3. **Merge**: Combine surface voxels, filter-filled voxels, and hole-filled voxels into the final solid grid [S2, unofficial].

#### Phase 3: Finalization [S1, unofficial]
1. Synchronize CUDA device: `cudaDeviceSynchronize()` [S1, unofficial].
2. Free GPU mesh data: `copyMeshData2Device->deleteMeshDataDevice(gpuData)` [S1, unofficial].

### Pseudocode
```python
def solid_voxelization(mesh_data, gridVoxelSize):
    # Phase 1: Setup & Surface Voxelization
    global_translation = mesh_data.bbox[0:3]
    grid_size = compute_two_level_sizes(mesh_data.bbox, gridVoxelSize)
    gpu_data = allocate_gpu_memory(MeshDataDevice)
    copy_mesh_data_to_device(gpu_data, mesh_data)
    
    tot_num_threads = len(mesh_data.triangles)
    num_blocks = ceil(tot_num_threads / 256)
    launch_kernel(solidVoxelGpu, num_blocks, 256, gpu_data, grid, tot_num_threads)
    
    # Phase 2: Interior Filling (Variant A)
    launch_kernel(fillBulkVoxelGpu, ceil(grid_size**2 / 256), 256, grid_size, grid.vTableBulk)
    
    start_index = find_exterior_voxel(grid)
    bfs_solid(start_index, grid.voxels_, grid.voxels_buffer_, grid.kBatchSize)
    
    compressed_total_size = grid.total_voxel_size
    for i in range(compressed_total_size):
        grid.voxels_[i] = grid.voxels_buffer_[i] ^ (~0)
        
    if with_meta:
        update_solid_meta(grid.voxels_, grid.voxel_metas_, grid.kBatchSize)
        
    # Phase 3: Finalization
    synchronize_device()
    free_gpu_memory(gpu_data)

def solidVoxelGpu(thread_id, GPUMeshData, grid, totNumThreads):
    if thread_id >= totNumThreads: return
    mesh_bbox = GPUMeshData.bbox
    tri = GPUMeshData.triangles[thread_id]
    idx1, idx2, idx3 = 3*tri._idx1, 3*tri._idx2, 3*tri._idx3
    V0 = GPUMeshData.vertices[idx1] - mesh_bbox[0:3]
    V1 = GPUMeshData.vertices[idx2] - mesh_bbox[0:3]
    V2 = GPUMeshData.vertices[idx3] - mesh_bbox[0:3]
    tri_bbox = [tri._bottom.x - mesh_bbox[0], tri._bottom.y - mesh_bbox[1], tri._bottom.z - mesh_bbox[2],
                tri._top.x - mesh_bbox[0], tri._top.y - mesh_bbox[1], tri._top.z - mesh_bbox[2]]
    voxelize_triangle_solid(grid, mesh_bbox, tri_bbox, V0, V1, V2, thread_id)

def voxelize_triangle_solid(grid, mesh_bbox, tri_bbox, V0, V1, V2, thread_id):
    e0, e1, e2 = V1-V0, V2-V1, V0-V2
    n = cross(e0, e1)
    delta_p = (gridVoxelSize, gridVoxelSize)
    
    # XY plane normals & distances
    n_xy_e0 = (-e0.y, e0.x); n_xy_e1 = (-e1.y, e1.x); n_xy_e2 = (-e2.y, e2.x)
    if n.z < 0: n_xy_e0 *= -1; n_xy_e1 *= -1; n_xy_e2 *= -1
    d_xy_e0 = -dot2D(n_xy_e0, (V0.x, V0.y)) + max(0, delta_p.x*n_xy_e0.x) + max(0, delta_p.y*n_xy_e0.y)
    d_xy_e1 = -dot2D(n_xy_e1, (V1.x, V1.y)) + max(0, delta_p.x*n_xy_e1.x) + max(0, delta_p.y*n_xy_e1.y)
    d_xy_e2 = -dot2D(n_xy_e2, (V2.x, V2.y)) + max(0, delta_p.x*n_xy_e2.x) + max(0, delta_p.y*n_xy_e2.y)
    
    # XZ plane normals & distances
    n_zx_e0 = (-e0.x, e0.z); n_zx_e1 = (-e1.x, e1.z); n_zx_e2 = (-e2.x, e2.z)
    if n.y < 0: n_zx_e0 *= -1; n_zx_e1 *= -1; n_zx_e2 *= -1
    d_xz_e0 = -dot2D(n_zx_e0, (V0.z, V0.x)) + max(0, delta_p.x*n_zx_e0.x) + max(0, delta_p.z*n_zx_e0.y)
    d_xz_e1 = -dot2D(n_zx_e1, (V1.z, V1.x)) + max(0, delta_p.x*n_zx_e1.x) + max(0, delta_p.z*n_zx_e1.y)
    d_xz_e2 = -dot2D(n_zx_e2, (V2.z, V2.x)) + max(0, delta_p.x*n_zx_e2.x) + max(0, delta_p.z*n_zx_e2.y)
    
    # YZ plane normals & distances
    n_yz_e0 = (-e0.y, e0.z); n_yz_e1 = (-e1.y, e1.z); n_yz_e2 = (-e2.y, e2.z)
    d_yz_e0 = -dot2D(n_yz_e0, (V0.y, V0.z)) + max(0, delta_p.y*n_yz_e0.y) + max(0, delta_p.z*n_yz_e0.z)
    d_yz_e1 = -dot2D(n_yz_e1, (V1.y, V1.z)) + max(0, delta_p.y*n_yz_e1.y) + max(0, delta_p.z*n_yz_e1.z)
    d_yz_e2 = -dot2D(n_yz_e2, (V2.y, V2.z)) + max(0, delta_p.y*n_yz_e2.y) + max(0, delta_p.z*n_yz_e2.z)
    
    # t_bbox_grid_min/max: grid-aligned bounding box of the triangle [G]
    for z in range(t_bbox_grid_min.z, t_bbox_grid_max.z + 1):
        for y in range(t_bbox_grid_min.y, t_bbox_grid_max.y + 1):
            p_yz = ((y + 0.5)*gridVoxelSize, (z + 0.5)*gridVoxelSize)
            cond1 = (dot2D(n_yz_e0, p_yz) + d_yz_e0 > 0) or (dot2D(n_yz_e0, p_yz) + d_yz_e0 == 0 and (n_yz_e0.x > 0 or (n_yz_e0.x == 0 and n_yz_e0.y < 0)))
            cond2 = (dot2D(n_yz_e1, p_yz) + d_yz_e1 > 0) or (dot2D(n_yz_e1, p_yz) + d_yz_e1 == 0 and (n_yz_e1.x > 0 or (n_yz_e1.x == 0 and n_yz_e1.y < 0)))
            cond3 = (dot2D(n_yz_e2, p_yz) + d_yz_e2 > 0) or (dot2D(n_yz_e2, p_yz) + d_yz_e2 == 0 and (n_yz_e2.x > 0 or (n_yz_e2.x == 0 and n_yz_e2.y < 0)))
            if not (cond1 and cond2 and cond3): continue
            
            for x in range(t_bbox_grid_min.x, t_bbox_grid_max.x + 1):
                p_xy = (x*gridVoxelSize, y*gridVoxelSize)
                if dot2D(n_xy_e0, p_xy) + d_xy_e0 < 0: continue
                if dot2D(n_xy_e1, p_xy) + d_xy_e1 < 0: continue
                if dot2D(n_xy_e2, p_xy) + d_xy_e2 < 0: continue
                
                p_zx = (z*gridVoxelSize, x*gridVoxelSize)
                if dot2D(n_zx_e0, p_zx) + d_xz_e0 < 0: continue
                if dot2D(n_zx_e1, p_zx) + d_xz_e1 < 0: continue
                if dot2D(n_zx_e2, p_zx) + d_xz_e2 < 0: continue
                
                p = (x*gridVoxelSize, y*gridVoxelSize, z*gridVoxelSize)
                nDOTp = dot(n, p)
                # d1, d2: plane distances for the triangle [G]
                if ((nDOTp + d1) * (nDOTp + d2)) > 0: continue
                
                location = x + (y * grid.gridSizeY) + (z * grid.gridSizeY * grid.gridSizeZ)
                flip_bit(grid.vTable1, location)
                break

def fillBulkGpu(i_thr, gridSize, vTableBulk):
    numPoints = 0
    locRastPoints = []
    for i in range(gridSize):
        location = i + gridSize * i_thr
        if check_bit(vTableBulk, location):
            numPoints += 1
            locRastPoints.append(i)
    if numPoints > 1:
        for m in range(numPoints):
            for i in range(locRastPoints[m], gridSize):
                location = i + gridSize * i_thr
                flip_bit(vTableBulk, location)

def bfs_solid(start_index, voxels_, voxels_buffer_, kBatchSize):
    voxel_index = start_index
    tmp = voxels_[voxel_index // kBatchSize].load() | voxels_buffer_[voxel_index // kBatchSize].load()
    if get_bit(tmp, voxel_index): return
    q = Queue()
    q.push(voxel_index)
    while not q.empty():
        voxel_index = q.front()
        tmp = voxels_[voxel_index // kBatchSize].load() | voxels_buffer_[voxel_index // kBatchSize].load()
        q.pop()
        top_voxel = conv_index_to_voxel(voxel_index)
        if not get_bit(tmp, voxel_index):
            set_bit(voxels_buffer_, voxel_index)
            for i in range(6):
                newVoxel = top_voxel + D_6[i]
                if not in_range(newVoxel, mesh_vox_lb, mesh_vox_ub): continue
                voxel_index = conv_voxel_to_index(newVoxel)
                tmp = voxels_[voxel_index // kBatchSize].load() | voxels_buffer_[voxel_index // kBatchSize].load()
                if not get_bit(tmp, voxel_index): q.push(voxel_index)

def update_solid_meta(voxels_, voxel_metas_, kBatchSize):
    solid_cnt = 0
    for voxel_index in range(total_voxel_size()):
        tmp = voxels_[voxel_index // kBatchSize].load()
        if get_bit(tmp, voxel_index) and not voxel_metas_[voxel_index].Surface():
            solid_cnt += 1
            voxel_metas_[voxel_index].SetSolid()
```

### Edge Cases and Pitfalls
- **Planar Test Precision**: When $\text{dot}(n, p) + d = 0$, inclusion is determined by normal direction: $n.x > 0$ or ($n.x = 0$ and $n.y < 0$) [S1, unofficial].
- **Normal Flipping**: Edge normals for the XY plane are flipped if $n.z < 0$, and edge normals for the ZX plane are flipped if $n.y < 0$ [S1, unofficial].
- **Holes in Filter Step**: The filter step alone does not fill the entire interior; holes remain for voxels occluded from all axis-aligned viewing directions [S2, unofficial].
- **Non-Watertight Meshes**: Basic flood fill may fail on non-watertight meshes if the exterior is not properly defined [S2, unofficial]. The filter-and-refine method or explicit exterior marking is required [S2, unofficial].

## Subtopics

### Solid Voxelization via Filter-and-Refine
A technique to fill the interior of a mesh using a filter-and-refine strategy to optimize basic flood fill, avoiding the need for watertight meshes [S2, unofficial]. It uses a filter step to fill voxels visible along each axis, followed by a refine step to flood fill remaining "holes" [S2, unofficial]. Advantage over basic flood fill is efficiency due to lightweight filter operations [S2, unofficial]. Time complexity is $O(n)$ where $n$ is the total number of voxels in the bounding box [S2, unofficial].

## Operating characteristics
- **Time Complexity**: Surface voxelization runs in $O(m \cdot c)$, where $m$ is the number of triangles and $c$ is the number of voxels in the triangle's bounding box or constant overhead [S2, unofficial]. Interior filling runs in $O(n)$, where $n$ is the total number of voxels in the mesh bounding box [S2, unofficial].
- **Memory Complexity**: $O(n)$ for the voxel grid and bitsets [S1, S2, unofficial].
- **Strengths**: Handles non-watertight meshes (with filter-and-refine), efficient parallelization on GPU [S1, S2, unofficial].
- **Limitations**: Requires careful handling of edge cases in triangle-voxel intersection [S1, unofficial]. BFS can be slow for meshes with many internal holes if not optimized [S2, unofficial].

## Background
The GPU-based implementation described in [S1, unofficial] implements the algorithm from doi:10.1145/1882261.1866201. The filter-and-refine optimization [S2, unofficial] addresses the limitations of basic flood fill, particularly for non-watertight meshes.
