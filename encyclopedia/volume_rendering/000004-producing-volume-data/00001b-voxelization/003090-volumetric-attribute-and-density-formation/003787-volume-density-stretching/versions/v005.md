# Volume Density Stretching


## Overview
Volume Density Stretching adjusts density values based on spatial deformation to simulate mass conservation [S1, unofficial]. When particles are stretched over a greater distance, the density decreases [S1, unofficial]. Without this feature, thicker parts allow less light through; with it, smaller radius areas become denser and vice versa [S1, unofficial].

## How it works
**Inputs and Outputs:**
*   **Input:** A parametric volume definition (e.g., a spline tube) where a point is mapped from parametric coordinates $(u, v, \theta)$ to world space [S1, unofficial]. The base density function $\rho_0$ defined in the undeformed parametric space [G].
*   **Output:** The stretched density value $\rho$ at the sampled point [S1, unofficial].

**Data Structures:**
*   Parametric coordinates $(u, v, \theta)$ representing position along the tube axis, radial distance, and angular position [S1, unofficial].
*   Local scaling factor $S$ derived from the deformation mapping [G].

**Method:**
1.  **Map to World Space:** Compute the world position $\mathbf{P}$ from parametric coordinates using the volume's transformation function [S1, unofficial].
2.  **Compute Local Stretching:** Determine the local scaling factor $S$ resulting from the deformation [G]. For a tube with varying radius $R(u)$, the stretching is related to the change in cross-sectional area or arc length [S1, unofficial]. If the volume expands, $S > 1$; if it contracts, $S < 1$ [G].
3.  **Apply Mass Conservation:** Adjust the base density $\rho_0$ by the inverse of the stretching factor to conserve mass [S1, unofficial]. The stretched density $\rho$ is calculated as:
    $$ \rho = \frac{\rho_0}{S} $$
4.  **Sample Noise (Optional):** If procedural noise (e.g., Perlin noise) is used, evaluate the noise in the parametric space before or after stretching depending on the desired anisotropy [S1, unofficial]. Stretching the noise field anisotropically creates filamentary structures [S1, unofficial].

**Parameters:**
*   $\rho_0$: Base density value [G].
*   $S$: Local scaling factor [G].

**Edge Cases and Pitfalls:**
*   **Singularity:** If $S \to 0$ (extreme compression), density may become unbounded. A clamp or minimum density threshold is required [G].
*   **Precision:** Standard floating-point precision is sufficient for typical shader implementations [G].

**Pseudocode:**
```python
def compute_stretched_density(u, v, theta, base_density_func, curve_func, radius_func, noise_func):
    """
    Computes density with mass conservation stretching.
    u: parametric coordinate along axis
    v: radial coordinate
    theta: angular coordinate
    base_density_func: function returning rho_0(u, v, theta)
    curve_func: function returning (world_position, tangent_vector) at u
    radius_func: function returning tube radius R(u) at u
    noise_func: function returning noise value at (u, v, theta)
    """
    # 1. Map to world space and compute local scale factor S
    P, tangent = curve_func(u)
    R = radius_func(u)
    # Local scale factor S is computed from the tangent magnitude and radius change [G]
    S = abs(tangent) * (1.0 + R)
    
    # Guard against division by zero or extreme compression
    if S < 1e-6:
        S = 1e-6
        
    # 2. Apply mass conservation: rho = rho_0 / S
    rho_0 = base_density_func(u, v, theta)
    rho = rho_0 / S
    
    # 3. Optional: Apply noise for filaments
    # Noise is evaluated in parametric space, then the resulting field is stretched
    noise_val = noise_func(u, v, theta)
    rho = rho * (1.0 + noise_val)
    
    return rho
```

## Operating characteristics
*   **Time Complexity:** $O(1)$ per sample, assuming mapping and noise evaluation are constant time [G].
*   **Memory Complexity:** $O(1)$, as it is a procedural method requiring no voxel grid storage [G].
*   **Performance:** Implemented in WebGL/GLSL on Shadertoy for real-time rendering [S1, unofficial]. Performance depends on Bezier curve evaluation and noise function complexity [S1, unofficial].
*   **Strengths:** Physically plausible density for deforming volumes; creates realistic filamentary structures with noise [S1, unofficial].
*   **Limitations:** Requires a parametric volume definition; not directly applicable to static voxel grids without inverse mapping [G].

## Background
Originated in the context of real-time procedural rendering of interstellar dust clouds and solar flares [S1, unofficial]. The method was implemented in WebGL/GLSL for Shadertoy, leveraging the ability to compute parametric mappings and noise on the GPU [S1, unofficial]. It addresses the visual artifact where undeformed density values cause thicker parts of a stretched volume to appear unnaturally opaque [S1, unofficial].
