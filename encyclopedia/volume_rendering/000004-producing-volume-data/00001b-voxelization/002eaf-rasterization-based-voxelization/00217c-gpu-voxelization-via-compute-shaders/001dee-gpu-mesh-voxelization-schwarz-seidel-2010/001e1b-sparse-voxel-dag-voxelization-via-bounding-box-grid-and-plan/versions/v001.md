# Sparse Voxel DAG Voxelization via Bounding Box Grid and Plane Projections

Also called: Morton-coded Voxel Filling, Triangle Voxelization with XY/ZX/YZ Projection Tests

## Overview
This method voxelizes a triangle mesh into a Sparse Voxel DAG (Directed Acyclic Graph) by rasterizing triangles into a Morton-coded voxel subgrid. It iterates over a 2D grid (XY) within a triangle's bounding box, determines the Z-range of voxels intersecting the triangle plane, and fills only those voxels that pass containment tests in the XY, ZX, and YZ projections [S1, unofficial]. It differs from its parent method, [GPU Mesh Voxelization (Schwarz & Seidel 2010)](1633-gpu-mesh-voxelization-schwarz-seidel-2010.md), by operating on a pre-partitioned Morton subgrid range rather than iterating a 2D grid with projection containment tests, allowing for out-of-core processing of large meshes [S1, unofficial].

## How it works
**Inputs:**
- A triangle $t$ with vertices $v_0, v_1, v_2$ and associated colors $c_0, c_1, c_2$.
- A global bounding box grid $p\_bbox\_grid$ defining the voxelization domain $[min[Z], max[Z]]$ in Z.
- A partition bounding box grid $t\_bbox\_grid$ defining the current subgrid range $[min[X], max[X]]$ and $[min[Y], max[Y]]$.
- `unitlength`: The size of a single voxel in world units.
- `morton_start`: An offset added to the Morton index to map it to the correct position in the voxels array.
- `voxels`: A sparse array or bitfield where `EMPTY_VOXEL` indicates an unoccupied cell.
- `voxel_data`: A list to store non-binary voxel information (optional, for binary voxelization this step is skipped).

**Outputs:**
- Updated `voxels` array with filled entries.
- Updated `voxel_data` list (if non-binary).
- `nfilled`: Count of newly filled voxels.

**Data Structures:**
- `VoxelData`: Struct containing:
  - `morton`: `uint_fast64_t`
  - `color`: `glm::vec3` (3 floats)
  - `normal`: `glm::vec3` (3 floats)
  - Total size: `sizeof(uint_fast64_t) + 2 * (3 * sizeof(float))` [S1, unofficial].
- `AABox`: Axis-aligned bounding box defined by `min` and `max` vectors.

**Pseudocode:**

```python
def voxelize_triangle(t, t_bbox_grid, p_bbox_grid, unitlength, morton_start, voxels, voxel_data, nfilled):
    """
    Voxelize a single triangle into the sparse voxel structure.
    """
    # 1. Iterate over the 2D XY grid within the triangle's bounding box
    for x in range(t_bbox_grid.min[0], t_bbox_grid.max[0] + 1):
        for y in range(t_bbox_grid.min[1], t_bbox_grid.max[1] + 1):
            
            # 2. Calculate 2D position in world space
            p_xy = vec2(x * unitlength, y * unitlength)
            
            # 3. XY Plane Containment Test
            # Check if p_xy is inside the triangle in the XY projection
            # Edges e0, e1, e2 with normals n_xy_ei and distances d_xy_ei
            inside_xy = True
            for i in range(3):
                # Edge normal in XY plane: perpendicular to edge vector projected on XY
                # Assuming edge e_i goes from v_i to v_{i+1}
                # Normal calculation depends on specific winding, but generally:
                # n_xy_ei = (-e_i[Y], e_i[X]) normalized or scaled
                # Distance d_xy_ei calculated based on vertex position
                if dot(n_xy_ei[i], p_xy) + d_xy_ei[i] < 0.0:
                    inside_xy = False
                    break
            
            if not inside_xy:
                continue

            # 4. Determine min and max corners in XY plane for the current voxel
            min_corner = vec3(p_xy[0], p_xy[1], 0.0)
            max_corner = vec3(p_xy[0] + unitlength, p_xy[1] + unitlength, 0.0)
            
            # 5. Swap min/max components if triangle normal components are negative
            # This ensures correct projection bounds for ZX and YZ tests
            if t.normal[0] < 0:
                swap(min_corner[0], max_corner[0])
            if t.normal[1] < 0:
                swap(min_corner[1], max_corner[1])
            
            # 6. Calculate world Z coordinates for min and max corners using plane equation
            # Plane equation: n[X]*x + n[Y]*y + n[Z]*z + d = 0
            # z = -(n[X]*x + n[Y]*y + d) / n[Z]
            # Note: Division by zero if n[Z] is 0 (triangle parallel to XY plane) [S1, unofficial]
            denom = -1.0 * t.normal[2]
            if abs(denom) < 1e-9:
                continue # Skip degenerate case or handle separately
            
            z_min_world = (t.normal[0] * min_corner[0] + t.normal[1] * min_corner[1] + t.plane_d) / denom
            z_max_world = (t.normal[0] * max_corner[0] + t.normal[1] * max_corner[1] + t.plane_d) / denom
            
            # 7. Convert world Z to voxel indices
            z_min = int(z_min_world / unitlength)
            z_max = int(z_max_world / unitlength)
            
            # 8. Clamp z_min and z_max to global bounding box grid Z range
            # Pitfall: Code may contain bug where z_max is clamped using z_min as lower bound
            # Correct implementation:
            z_min = clamp(z_min, p_bbox_grid.min[2], p_bbox_grid.max[2])
            z_max = clamp(z_max, p_bbox_grid.min[2], p_bbox_grid.max[2])
            
            # 9. Handle case where z_min == z_max
            if z_min == z_max:
                index = morton_encode_LUT(z_min, y, x)
                if voxels[index - morton_start] != EMPTY_VOXEL:
                    continue
                
                # Mark voxel as filled
                voxels[index - morton_start] = FILLED # Or store index in voxel_data
                nfilled += 1
                
                # If non-binary, store data
                if not BINARY_VOXELIZATION:
                    avg_color = average3Vec(t.v0_color, t.v1_color, t.v2_color)
                    voxel_data.append(VoxelData(morton=index, color=avg_color, normal=t.normal))
                continue

            # 10. Setup ZX Plane Projection Tests
            # Calculate edge normals in ZX plane: n_zx_ei = (-e_i[X], e_i[Z])
            # Flip normals if t.normal[Y] < 0 to ensure consistent winding/orientation
            n_zx_ei = []
            d_xz_ei = []
            for i in range(3):
                e_i = t.vertices[(i+1)%3] - t.vertices[i]
                n_zx = vec2(-e_i[0], e_i[2])
                if t.normal[1] < 0:
                    n_zx = -n_zx
                n_zx_ei.append(n_zx)
                
                # Distance calculation
                # d_xz_ei = -1.0 * dot(n_zx, (t.v_i[Z], t.v_i[X])) + max(0.0, unitlength*n_zx[0]) + max(0.0, unitlength*n_zx[1])
                # Note: The formula uses t.v_i[Z] and t.v_i[X] for the dot product part
                d_xz = -1.0 * dot(n_zx, vec2(t.vertices[i][2], t.vertices[i][0]))
                d_xz += max(0.0, unitlength * n_zx[0])
                d_xz += max(0.0, unitlength * n_zx[1])
                d_xz_ei.append(d_xz)

            # 11. Setup YZ Plane Projection Tests
            # Calculate edge normals in YZ plane: n_yz_ei = (-e_i[Z], e_i[Y])
            # Flip normals if t.normal[X] < 0
            n_yz_ei = []
            d_yz_ei = []
            for i in range(3):
                e_i = t.vertices[(i+1)%3] - t.vertices[i]
                n_yz = vec2(-e_i[2], e_i[1])
                if t.normal[0] < 0:
                    n_yz = -n_yz
                n_yz_ei.append(n_yz)
                
                # Distance calculation
                # d_yz_ei = -1.0 * dot(n_yz, (t.v_i[Y], t.v_i[Z])) + max(0.0, unitlength*n_yz[0]) + max(0.0, unitlength*n_yz[1])
                d_yz = -1.0 * dot(n_yz, vec2(t.vertices[i][1], t.vertices[i][2]))
                d_yz += max(0.0, unitlength * n_yz[0])
                d_yz += max(0.0, unitlength * n_yz[1])
                d_yz_ei.append(d_yz)

            # 12. Iterate over Z range
            for z in range(z_min, z_max + 1):
                index = morton_encode_LUT(z, y, x)
                if voxels[index - morton_start] != EMPTY_VOXEL:
                    continue
                
                # 13. YZ Projection Test
                p_yz = vec2(y * unitlength, z * unitlength)
                inside_yz = True
                for i in range(3):
                    if dot(n_yz_ei[i], p_yz) + d_yz_ei[i] < 0.0:
                        inside_yz = False
                        break
                if not inside_yz:
                    continue
                
                # 14. ZX Projection Test
                p_zx = vec2(z * unitlength, x * unitlength)
                inside_zx = True
                for i in range(3):
                    if dot(n_zx_ei[i], p_zx) + d_xz_ei[i] < 0.0:
                        inside_zx = False
                        break
                if not inside_zx:
                    continue
                
                # 15. Mark voxel as filled
                voxels[index - morton_start] = FILLED
                nfilled += 1
                
                if not BINARY_VOXELIZATION:
                    avg_color = average3Vec(t.v0_color, t.v1_color, t.v2_color)
                    voxel_data.append(VoxelData(morton=index, color=avg_color, normal=t.normal))
```

**Parameters:**
- `unitlength`: The size of a single voxel in world units. Typical values depend on the scene scale and desired resolution [S1, unofficial].
- `morton_start`: An offset added to the Morton index to map it to the correct position in the voxels array. This is used when processing partitions [S1, unofficial].

**Edge Cases and Pitfalls:**
- **Division by Zero:** The calculation of $z_{min\_world}$ and $z_{max\_world}$ involves division by $-n[Z]$. If $n[Z]$ is zero, the triangle is parallel to the XY plane, resulting in infinity or NaN. This case must be handled or skipped [S1, unofficial].
- **Clamping Bug:** The source code contains a bug where $z_{max}$ is clamped using $z_{min}$ as the lower bound argument: `clampval<int>(z_min, p_bbox_grid.min[Z], p_bbox_grid.max[Z])`. The intent is to clamp both $z_{min}$ and $z_{max}$ to the grid bounds, so the correct call should be `clampval<int>(z_max, p_bbox_grid.min[Z], p_bbox_grid.max[Z])` [S1, unofficial].
- **Winding and Normal Orientation:** The flipping of edge normals in ZX and YZ projections depends on the sign of the triangle's normal components ($n[Y]$ and $n[X]$). Incorrect handling leads to false negatives in containment tests [S1, unofficial].

## Subtopics

### [Huang et al. Voxelization Method](1684-huang-et-al-voxelization-method.md)
This method voxelizes a triangle mesh into a Sparse Voxel DAG by rasterizing triangles into a Morton-coded voxel subgrid using a three-stage overlap test consisting of vertex spheres, edge cylinders, and a plane-barycentric check. It differs from its parent method by operating on a pre-partitioned Morton subgrid range rather than iterating a 2D grid with projection containment tests, allowing for out-of-core processing of large meshes.

## Operating characteristics
- **Time Complexity:** The complexity is proportional to the number of voxels in the triangle's bounding box in the XY plane, multiplied by the depth of the triangle in the Z direction. For each voxel, a constant number of plane tests are performed.
- **Memory Complexity:** Depends on the number of filled voxels and the size of the `VoxelData` structure if non-binary voxelization is used. The sparse nature of the DAG allows for efficient storage of empty space.
- **Strengths:** Optimized for sparse voxel grids using Morton codes. Explicit projection tests in XY, ZX, and YZ planes provide robust culling. Suitable for out-of-core processing when combined with partitioning.
- **Limitations:** Degenerate cases (parallel triangles) require special handling. Potential for bugs in clamping and normal orientation if not carefully implemented.
- **When to Use:** When voxelizing large triangle meshes into a sparse structure where memory efficiency is critical and out-of-core processing is beneficial.
- **When Not to Use:** For dense voxelizations or when signed distance fields/ray casting are more appropriate for the downstream application.

## Background
This method is part of the implementation for "High Resolution Sparse Voxel DAGs" by Zheng et al., as seen in the GitHub repository [leonzheng2/INF584-High_Resolution_Sparse_Voxel_DAGs](https://github.com/leonzheng2/INF584-High_Resolution_Sparse_Voxel_DAGs) [S1, unofficial]. It builds on the concepts of GPU mesh voxelization and extends them with Morton coding and partitioning for scalability.
