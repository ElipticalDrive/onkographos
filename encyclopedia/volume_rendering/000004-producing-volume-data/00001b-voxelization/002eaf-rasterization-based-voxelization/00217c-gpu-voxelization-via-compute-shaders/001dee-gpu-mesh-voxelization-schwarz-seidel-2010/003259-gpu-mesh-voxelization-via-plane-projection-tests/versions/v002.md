# GPU Mesh Voxelization via Plane/Projection Tests

Also called: GPU Voxelization via Plane and 2D Projection Tests, Solid Voxelization via Triangle Projection

## Overview
This method converts a triangle mesh into a solid voxel grid by testing each voxel within a triangle's bounding box against the triangle's plane equation and its 2D orthogonal projections on the XY, YZ, and ZX planes [S2, unofficial]. It differs from its sibling [Sparse Voxel DAG Voxelization via Bounding Box Grid and Plane Projections](1680-sparse-voxel-dag-voxelization-via-bounding-box-grid-and-plan.md) by using a dense bit-packed voxel table and explicit 3D plane tests rather than a hierarchical DAG structure, and from [Surface Voxelization](1683-surface-voxelization.md) by filling the interior of the mesh volume rather than marking only surface-adjacent cells [S2, unofficial].

## How it works
### Inputs and Outputs
**Inputs:**
- `triangle_data`: A flat array of `float` values containing vertex coordinates. Each triangle consists of 9 floats ($v_{0x}, v_{0y}, v_{0z}, v_{1x}, v_{1y}, v_{1z}, v_{2x}, v_{2y}, v_{2z}$) [S2, unofficial].
- `info`: A structure containing:
  - `bbox`: An axis-aligned bounding box (`min` and `max` components) defining the global mesh bounds [S2, unofficial].
  - `gridsize`: A 3D integer vector ($N_x, N_y, N_z$) defining the voxel grid resolution [S2, unofficial].
  - `n_triangles`: The total number of triangles [S2, unofficial].
  - `unit`: A 3D float vector representing the physical size of a single voxel cell, calculated as $(bbox.max - bbox.min) / gridsize$ [S2, unofficial].
- `voxel_table`: A pointer to an array of `unsigned int` (32-bit) representing the voxel grid [S2, unofficial].
- `morton_order`: Boolean flag determining whether to use Morton codes (Z-order curve) or linear row-major indexing for voxel storage [S2, unofficial].

**Outputs:**
- `voxel_table`: Modified such that bits corresponding to occupied voxels are set to 1 [S2, unofficial].

### Data Structures
- **Voxel Table Layout:** The grid is stored as a linear array of 32-bit unsigned integers. Each bit represents one voxel. Global voxel index $i$ corresponds to word index $w = \lfloor i / 32 \rfloor$ and bit position $b = 31 - (i \pmod{32})$ [S2, unofficial]. Bits are set using atomic OR operations [S2, unofficial].
- **Morton Encoding:** If `morton_order` is true, voxel indices are encoded using Morton codes. This requires three device-constant lookup tables (`morton256_x`, `morton256_y`, `morton256_z`), each containing 256 `uint32_t` elements, mapping 8-bit coordinate chunks to interleaved bits [S2, unofficial].

### Algorithm Steps
The algorithm processes triangles in parallel using CUDA threads. For each triangle, it computes a bounding box, clamps it to grid coordinates, and tests every voxel in that box against the triangle using plane and projection tests to determine if the voxel is filled [S1, unofficial].

1. **Thread Initialization:** Calculate `thread_id = threadIdx.x + blockIdx.x * blockDim.x` and `stride = blockDim.x * gridDim.x` [S2, unofficial].
2. **Triangle Loop:** While `thread_id < info.n_triangles`:
   a. **Vertex Loading:** Calculate offset `t = thread_id * 9`. Transform vertices to local coordinates relative to `info.bbox.min`: $v_i = v_i - info.bbox.min$ for $i \in \{0, 1, 2\}$ [S2, unofficial].
   b. **Geometry Calculation:** Compute edge vectors: $e_0 = v_1 - v_0$, $e_1 = v_2 - v_1$, $e_2 = v_0 - v_2$. Compute the triangle normal: $n = \text{normalize}(\text{cross}(e_0, e_1))$ [S2, unofficial].
   c. **Bounding Box Calculation:** Compute the world-space bounding box of the triangle: $t\_bbox\_world.min = \min(v_0, v_1, v_2)$, $t\_bbox\_world.max = \max(v_0, v_1, v_2)$. Convert to grid coordinates: $t\_bbox\_grid.min = \text{clamp}(\lfloor t\_bbox\_world.min / info.unit \rfloor, \mathbf{0}, info.gridsize - \mathbf{1})$, similarly for max (Note: Source uses `float3_to_int3` which truncates; clamping ensures bounds safety) [S2, unofficial].
   d. **Plane Test Preparation:** Compute offset vector $c$ based on the normal's sign: If $n.x > 0$, $c.x = info.unit.x$, else $c.x = 0$. Similarly for $y$ and $z$ components. Compute plane test distances: $d_1 = \text{dot}(n, c - v_0)$, $d_2 = \text{dot}(n, (info.unit - c) - v_0)$ [S2, unofficial].
   e. **Projection Test Preparation:** For each projection plane (XY, YZ, ZX), compute 2D edge normals and distances.
      - **XY Projection:** 2D edge normals: $n_{xy\_e0} = (-e_{0y}, e_{0x})$, $n_{xy\_e1} = (-e_{1y}, e_{1x})$, $n_{xy\_e2} = (-e_{2y}, e_{2x})$. If $n.z < 0$, negate all $n_{xy\_e*}$. Distances: $d_{xy\_e0} = -\text{dot}(n_{xy\_e0}, (v_{0x}, v_{0y})) + \max(0, info.unit.x \cdot n_{xy\_e0.x}) + \max(0, info.unit.y \cdot n_{xy\_e0.y})$ (Similarly for $e_1, e_2$) [S2, unofficial].
      - **YZ Projection:** 2D edge normals: $n_{yz\_e0} = (-e_{0z}, e_{0y})$, etc. If $n.x < 0$, negate all. Distances computed similarly [S2, unofficial].
      - **ZX Projection:** 2D edge normals: $n_{zx\_e0} = (-e_{0x}, e_{0z})$, etc. If $n.y < 0$, negate all. Distances computed similarly [S2, unofficial].
   f. **Voxel Loop:** Iterate $z$ from $t\_bbox\_grid.min.z$ to $t\_bbox\_grid.max.z$, $y$ from $min.y$ to $max.y$, $x$ from $min.x$ to $max.x$:
      1. Compute voxel center: $p = (x \cdot info.unit.x, y \cdot info.unit.y, z \cdot info.unit.z)$ [S2, unofficial].
      2. **Plane Test:** $nDOTp = \text{dot}(n, p)$. If $(nDOTp + d_1) \cdot (nDOTp + d_2) > 0$, continue (voxel is outside the slab) [S2, unofficial].
      3. **XY Projection Test:** $p_{xy} = (p.x, p.y)$. If $\text{dot}(n_{xy\_e0}, p_{xy}) + d_{xy\_e0} < 0$ OR $\text{dot}(n_{xy\_e1}, p_{xy}) + d_{xy\_e1} < 0$ OR $\text{dot}(n_{xy\_e2}, p_{xy}) + d_{xy\_e2} < 0$, continue [S2, unofficial].
      4. **YZ and ZX Projection Tests:** Apply similar dot-product checks against the respective 2D edge normals and distances [S2, unofficial].
      5. **Mark Voxel:** Calculate global index $i = x + y \cdot N_x + z \cdot (N_y \cdot N_x)$. If `morton_order` is true, use `mortonEncode_LUT(x, y, z)`. Set bit in `voxel_table` at $i$ using atomic OR [S2, unofficial].
   g. Increment `thread_id` by `stride` [S2, unofficial].

### Pseudocode
```python
def voxelize(triangle_data, info, voxel_table, morton_order):
    # triangle_data: flat list of floats, 9 per triangle
    # info: dict with bbox, gridsize, n_triangles, unit
    # voxel_table: list of unsigned ints
    # morton_order: bool
    
    thread_id = 0 # Simulating parallel execution
    stride = 1
    
    while thread_id < info['n_triangles']:
        t = thread_id * 9
        # Load and transform vertices
        v0 = make_float3(triangle_data[t:t+3]) - info['bbox'].min
        v1 = make_float3(triangle_data[t+3:t+6]) - info['bbox'].min
        v2 = make_float3(triangle_data[t+6:t+9]) - info['bbox'].min
        
        # Geometry
        e0 = v1 - v0
        e1 = v2 - v1
        e2 = v0 - v2
        n = normalize(cross(e0, e1))
        
        # Bounding box
        t_bbox_world_min = min(v0, v1, v2)
        t_bbox_world_max = max(v0, v1, v2)
        t_bbox_grid_min = clamp(int3(t_bbox_world_min / info['unit']), 0, info['gridsize'] - 1)
        t_bbox_grid_max = clamp(int3(t_bbox_world_max / info['unit']), 0, info['gridsize'] - 1)
        
        # Plane test prep
        c = float3(
            info['unit'].x if n.x > 0 else 0.0,
            info['unit'].y if n.y > 0 else 0.0,
            info['unit'].z if n.z > 0 else 0.0
        )
        d1 = dot(n, c - v0)
        d2 = dot(n, (info['unit'] - c) - v0)
        
        # Projection tests prep
        # XY
        n_xy_e0 = float2(-e0.y, e0.x)
        n_xy_e1 = float2(-e1.y, e1.x)
        n_xy_e2 = float2(-e2.y, e2.x)
        if n.z < 0: n_xy_e0, n_xy_e1, n_xy_e2 = -n_xy_e0, -n_xy_e1, -n_xy_e2
        d_xy_e0 = -dot(n_xy_e0, float2(v0.x, v0.y)) + max(0, info['unit'].x * n_xy_e0.x) + max(0, info['unit'].y * n_xy_e0.y)
        d_xy_e1 = -dot(n_xy_e1, float2(v1.x, v1.y)) + max(0, info['unit'].x * n_xy_e1.x) + max(0, info['unit'].y * n_xy_e1.y)
        d_xy_e2 = -dot(n_xy_e2, float2(v2.x, v2.y)) + max(0, info['unit'].x * n_xy_e2.x) + max(0, info['unit'].y * n_xy_e2.y)
        
        # YZ and ZX similarly...
        
        # Voxel loop
        for z in range(t_bbox_grid_min.z, t_bbox_grid_max.z + 1):
            for y in range(t_bbox_grid_min.y, t_bbox_grid_max.y + 1):
                for x in range(t_bbox_grid_min.x, t_bbox_grid_max.x + 1):
                    p = float3(x * info['unit'].x, y * info['unit'].y, z * info['unit'].z)
                    
                    # Plane test
                    nDOTp = dot(n, p)
                    if (nDOTp + d1) * (nDOTp + d2) > 0: continue
                    
                    # Projection tests
                    p_xy = float2(p.x, p.y)
                    if dot(n_xy_e0, p_xy) + d_xy_e0 < 0 or dot(n_xy_e1, p_xy) + d_xy_e1 < 0 or dot(n_xy_e2, p_xy) + d_xy_e2 < 0: continue
                    # ... YZ, ZX checks ...
                    
                    # Mark voxel
                    idx = x + y * info['gridsize'].x + z * (info['gridsize'].y * info['gridsize'].x)
                    if morton_order:
                        idx = morton_encode(idx) # Simplified
                    set_bit(voxel_table, idx)
        
        thread_id += stride
```

### Parameters
- `morton_order`: Boolean flag determining whether to use Morton code (Z-order curve) for voxel indexing or linear indexing [S2, unofficial].
- `voxel_table`: Pointer to an array of unsigned integers representing the voxel grid, where each bit corresponds to a voxel [S2, unofficial].

### Edge Cases and Pitfalls
- **Parallel Triangles:** If the triangle normal's X component is near zero ($|n.x| < \epsilon$), the triangle is parallel to the YZ projection plane. The algorithm skips such triangles to avoid division by zero or invalid intersection calculations [S2, unofficial].
- **Boundary Handling:** In some implementations, voxels outside the projected triangle are included for robust boundary filling [S2, unofficial].
- **Precision:** Floating-point comparisons for plane tests and point-in-triangle tests should account for epsilon errors, though exact epsilon values are not specified in the source [S2, unofficial].

## Operating characteristics
- **Time Complexity:** $O(N_t \cdot N_{bbox})$, where $N_t$ is the number of triangles and $N_{bbox}$ is the average number of voxels in a triangle's bounding box. Each voxel requires constant-time plane and projection tests [S2, unofficial].
- **Memory Complexity:** $O(N_x N_y N_z / 32)$ for the voxel table, plus $O(N_t)$ for triangle data [S2, unofficial].
- **Performance:** The method is GPU-accelerated using CUDA compute shaders. It requires a CUDA device with compute capability 2.0 or higher for atomic operations [S2, unofficial].
- **Strengths:** Parallelizable, produces solid voxel grids suitable for ray marching [S2, unofficial].
- **Limitations:** Dense storage can be memory-intensive for large grids. Variant 2 may fill voxels outside the mesh if the projection logic is not strictly conservative [S2, unofficial].
