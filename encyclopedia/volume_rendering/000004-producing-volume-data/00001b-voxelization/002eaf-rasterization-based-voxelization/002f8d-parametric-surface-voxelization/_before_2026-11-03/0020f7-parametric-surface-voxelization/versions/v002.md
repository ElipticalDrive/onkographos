# Parametric Surface Voxelization
Also called: Parametric field rasterization

## Overview
Parametric surface voxelization is a GPU-based technique that converts parametric surface patches directly into a voxel grid by rasterizing point primitives generated in the parametric domain [S1, unofficial]. It differs from standard triangle rasterization by operating in the 2D parameter space of the surface definition, allowing for the voxelization of complex implicit or free-form surfaces that lack explicit triangular meshes [S1, unofficial]. This method enables real-time voxelization of complex models by leveraging the vertex shader to map 2D texture coordinates to 3D world positions [S1, unofficial].

## How it works
**Inputs and Outputs:**
*   **Input:** A parametric surface function $S(u, v)$ mapping 2D parameters to 3D space, a structured set of 2D points covering the parametric domain, and voxel grid dimensions/bounds [S1, G, unofficial].
*   **Output:** A voxel grid (worksheet) where occupied voxels correspond to the surface [S1, unofficial].

**Data Structures:**
*   **Parametric Boodle:** A structured set of 2D points $(u_i, v_i)$ covering the parametric domain of the surface patch [S1, unofficial].
*   **Voxel Grid (Worksheet):** A 3D texture or buffer representing the volume, indexed by integer coordinates $(i, j, l)$ [G].

**Steps:**
1.  **Generate Parametric Points:** Build a boodle of points that cover the parametric field [S1, unofficial].
2.  **Vertex Shader Processing:** Consider each point as a vertex processed in the vertex shader [S1, unofficial].
3.  **3D Position Calculation:** Use texture coordinates in the parametric domain to calculate positions in 3D space [S1, unofficial].
    $$ \mathbf{p}_k = S(u_k, v_k) $$
4.  **Transcoding to Worksheet:** Transcode these positions to the worksheet immediately [S1, unofficial].
    $$ i = \left\lfloor \frac{x_k - x_{\min}}{\Delta x} \right\rfloor, \quad j = \left\lfloor \frac{y_k - y_{\min}}{\Delta y} \right\rfloor, \quad l = \left\lfloor \frac{z_k - z_{\min}}{\Delta z} \right\rfloor $$
    Mark the voxel at $(i, j, l)$ as occupied [G].

**Parameters:**
*   **Sampling Density:** The number of points in the parametric boodle. Not given in the sources.
*   **Voxel Resolution:** The dimensions of the output worksheet. Not given in the sources.

**Edge Cases and Pitfalls:**
*   **Shader Instruction Limits:** The method assumes the shader program supports sufficient instruction slots for complex surface evaluations [S1, unofficial].
*   **Precision and Boundaries:** Floating-point precision during surface evaluation and coordinate transformation can affect voxel placement, and parametric domain boundaries must be handled to ensure complete coverage [G].

**Pseudocode:**
```python
def parametric_surface_voxelization(S, resolution, bounds, parametric_resolution):
    x_min, y_min, z_min = bounds[0]
    x_max, y_max, z_max = bounds[1]
    dx = (x_max - x_min) / resolution[0]
    dy = (y_max - y_min) / resolution[1]
    dz = (z_max - z_min) / resolution[2]

    # Not given in the sources: voxel grid initialization
    voxel_grid = [[[False for _ in range(resolution[2])] for _ in range(resolution[1])] for _ in range(resolution[0])]

    # Step 1: Build a boodle of points covering the parametric field
    u_coords = [i / parametric_resolution for i in range(parametric_resolution + 1)]
    v_coords = [j / parametric_resolution for j in range(parametric_resolution + 1)]

    # Step 2 & 3: Process each point as a vertex in the vertex shader
    # Step 4: Transcode positions to the worksheet immediately
    for u in u_coords:
        for v in v_coords:
            # Calculate 3D position
            p = S(u, v)
            x, y, z = p[0], p[1], p[2]

            # Convert to voxel indices
            ix = int((x - x_min) / dx)
            iy = int((y - y_min) / dy)
            iz = int((z - z_min) / dz)

            # Clamp indices to avoid out-of-bounds access
            ix = max(0, min(ix, resolution[0] - 1))
            iy = max(0, min(iy, resolution[1] - 1))
            iz = max(0, min(iz, resolution[2] - 1))

            # Mark voxel as occupied
            voxel_grid[ix][iy][iz] = True

    return voxel_grid
```

## Subtopics

### [Recursive Parameter Space Voxelization for Catmull-Clark Subdivision Surfaces](2533-recursive-parameter-space-voxelization-for-catmull-clark-sub.md)
This method converts a free-form object represented by a Catmull-Clark subdivision surface (CCSS) into a voxel grid by recursively subdividing the 2D parameter space of surface patches and sampling 3D points, rather than subdividing 3D object space. It ensures leak-free results for closed objects when a 3D flooding operation is performed by guaranteeing that voxels generated from a single patch satisfy specific N-adjacency properties. Unlike 3D space subdivision techniques which are computationally expensive due to distance computations between 3D points, this method performs subdivision in 2D parameter space, avoiding expensive 3D distance computations.

## Background
The method was introduced in the context of real-time voxelization for complex models, specifically addressing the challenge of voxelizing parametric surfaces [S1, unofficial]. It builds on the idea of using GPU shaders to perform geometric transformations and rasterization in a flexible manner, extending point-based rasterization to parametric domains [S1, unofficial]. The approach is particularly relevant for applications requiring rapid voxelization of non-polygonal geometry, such as transparent illustration and collision detection in complex scenes [S1, unofficial]. For CSG models, the method voxelizes nodes into respective worksheets and applies boolean operations from bottom to top automatically in image space, leveraging GPU blending operations [S1, unofficial].
