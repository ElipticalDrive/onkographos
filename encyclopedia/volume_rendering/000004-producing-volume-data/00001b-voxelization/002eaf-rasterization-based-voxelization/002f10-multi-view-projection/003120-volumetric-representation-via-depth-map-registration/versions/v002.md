# Volumetric Representation via Depth Map Registration

Also called: Sparse Non-Lambertian Multi-view Volume Construction, Volume Initialization

## Overview
This method constructs a 3D volume from a set of multi-view images by registering estimated depth maps into a voxel grid. It solves the problem of non-Lambertian reflections by using individual minimum cost per view rather than a global threshold, and represents the scene geometry as a sparse voxel cloud where voxel values indicate the number of views mapping to that location. It differs from [Orthographic Multi-View Voxelization](3892-orthographic-multi-view-voxelization.md) by explicitly handling non-Lambertian surfaces through per-view depth estimation costs and by refining the volume shape iteratively to remove scattering voxels and smooth sharp corners, which [Single 2D Projection Voxelization](3482-single-2d-projection-voxelization.md) does not address.

## How it works
**Inputs:** A set of $N$ reference views (images and camera parameters), estimated depth maps for each view.
**Outputs:** A 3D voxel grid where each voxel $(i, j, k)$ has a weight $\delta_{ijk}$ representing the count of views mapping to it, and optionally refined geometry.

**Data Structures:**
*   **Voxel Grid:** A 3D array or sparse hash map.
*   **Voxel Value:** Integer $\delta_{ijk} \in \{0, 1, \dots, N\}$.
*   **Depth Cluster:** For each pixel in a reference view, a list of candidate depths $(d_k, \delta_k)$ from the initial registration.

**Steps:**

1.  **Volume Initialization:**
    For each reference view, estimate a depth map by searching along the view's geometry. Compensate for non-Lambertian reflection by exploiting the individual minimum cost for that view instead of a global threshold. Register these depth maps into the 3D volume. For each voxel at location $(i, j, k)$, set its value $\delta_{ijk}$ to $n$ if a depth is registered to it, where $n$ is the count of views mapping to that voxel; otherwise set it to 0 [S1].
    $$
    \delta_{ijk} = \begin{cases} n, & \text{if registering depth} \\ 0, & \text{otherwise} \end{cases}
    $$
    where $n \in \{1, 2, \dots, N\}$ and $N$ is the total number of reference views [S1].

2.  **Isolated Voxel Removal and Depth Selection:**
    Detect isolated voxels with no neighbors. Project the volume back to the reference view geometry to build new depth maps, removing errors from the previous step. If multiple depth values exist for a pixel, consider the front cluster of depths. The proper depth value $d$ of a particular pixel is determined by [S1]:
    $$
    d = \begin{cases} d_n, & \text{if only one depth has } \delta_n = \max(\delta_K) \\ \left(\sum_{k=1}^K \delta_k d_k\right) / \left(\sum_{k=1}^K \delta_k\right), & \text{otherwise} \end{cases}
    $$
    where $K$ is the number of depth values in the front cluster, $d_k$ is the depth value, and $\delta_k$ is the voxel weight. The depth value projected from the voxel that contains the maximum $\delta$ is selected. If the maximum $\delta$ appears in two or more depth values, the fit depth value is calculated from the average of all depth values of the front cluster with weighted coefficient $\delta$ [S1].

3.  **Surface Interpolation:**
    Reconstruct the volume again. Interpolate voxels to connect the surface of the volume among the near voxels [S1].

4.  **Iterative Volume Refinement:**
    Refine the shape of the volume by removing scattering voxels and smoothing sharp corners to increase coding gain. Compare reconstructed views against original reference images to identify and correct geometry errors [S1].
    *   **Step 1:** Temporarily define voxel colors by taking the median of color values from all visible views [S1].
    *   **Step 2:** Iterate through reference views (e.g., from furthest left to furthest right). For each view, calculate the Mean Square Error (MSE) between the reconstructed view and the original reference image [S1].
    *   **Step 3:** If the MSE exceeds a threshold, remove the old depth and its associated voxel. Investigate a new depth derived from neighboring pixels based on a smooth surface assumption [S1].
    *   **Step 4:** If the new depth value meets color constraints for all visible views, generate the new associated voxel. Use a window-based computation (e.g., 3x3 pixels) for error calculation to handle inaccurate camera calibration and unequal resolutions [S1].
    *   **Step 5:** Iteratively reconstruct images if voxels are removed or generated, as voxel position changes affect visibility. Repeat until no new voxels are generated and no old voxels are removed [S1].

    """
    Step 2: Isolated Voxel Removal and Depth Selection

    refined_depth_maps = []

        for y in range(resolution.height):
            for x in range(resolution.width):
                # Project pixel back to 3D rays and query voxel grid
                # Get all voxels along the ray that have weight > 0
                candidate_depths = []
                for voxel in voxel_grid.query_ray(camera_matrix, x, y):
                    if voxel.weight > 0:
                        candidate_depths.append((voxel.depth, voxel.weight))
                
                if not candidate_depths:
                    continue
                    
                # Sort by depth (front to back)
                candidate_depths.sort(key=lambda k: k[0])
                
                # Identify front cluster (contiguous depths with high weights)
                # Note: The exact definition of "front cluster" from noise dispersion
                # is heuristic. We assume the first K depths with significant weight.
                front_cluster = []
                for d, w in candidate_depths:
                    # Heuristic: include if weight is significant relative to max
                    if w > 0: 
                        front_cluster.append((d, w))
                    else:
                        break # Stop at first zero weight or gap
                
                K = len(front_cluster)
                if K == 0:
                    continue
                
                # Find max weight in cluster
                max_weight = max(w for _, w in front_cluster)
                max_weight_count = sum(1 for _, w in front_cluster if w == max_weight)
                
                if max_weight_count == 1:
                    # Only one depth has max weight
                    d_n = next(d for d, w in front_cluster if w == max_weight)
                    depth_map[y, x] = d_n
                else:
                    # Weighted average of all depths in front cluster
                    numerator = sum(w * d for d, w in front_cluster)
                    denominator = sum(w for _, w in front_cluster)
                    if denominator > 0:
                        depth_map[y, x] = numerator / denominator
                    else:
                        depth_map[y, x] = front_cluster[0][0]
                        
        refined_depth_maps.append(depth_map)
        
    return refined_depth_maps

## Subtopics

### Iterative Volume Refinement
An iterative algorithm to refine the shape of the volume by removing scattering voxels and smoothing sharp corners to increase coding gain. It compares reconstructed views against original reference images to identify and correct geometry errors. It is chosen when the initial volume contains significant noise or sharp corners that reduce coding gain. It differs from the basic initialization by actively optimizing the volume structure based on view synthesis error.

## Operating characteristics
*   **Time Complexity:** The initialization step is $O(N \cdot H \cdot W)$ where $N$ is the number of views and $H, W$ are image dimensions. The refinement step is iterative and depends on the number of voxels and views, potentially $O(I \cdot N \cdot V)$ where $I$ is iterations and $V$ is voxels.
*   **Memory Complexity:** Proportional to the number of voxels in the sparse grid.
*   **Performance:** The method is simple and fast for initialization. Refinement improves accuracy but increases computational cost.
*   **Strengths:** Handles non-Lambertian reflections well. Removes isolated noise. Smooths sharp corners.
*   **Limitations:** Requires accurate initial depth maps. Iterative refinement can be slow. Sensitive to camera calibration errors (mitigated by window-based MSE).
*   **When to use:** When non-Lambertian surfaces are present and high-quality volume initialization is needed for view synthesis.
*   **When not to use:** When real-time performance is critical and iterative refinement is too slow.

## Background
Originated in the context of color volumetric compression for realistic view synthesis applications. The method was proposed to address issues with non-Lambertian reflections and scattering voxels in multi-view volume construction. It builds on the principle that depth registration methods provide a good representation for natural scenery.
