# Volumetric Representation via Depth Map Registration

Also called: Sparse Non-Lambertian Multi-view Volume Construction, Volume Initialization

## Overview
This method constructs a 3D sparse voxel volume from a set of multi-view images by registering estimated depth maps into a voxel grid [S1]. It solves the problem of volume initialization for view synthesis by handling non-Lambertian reflections through per-view minimum cost selection rather than global thresholds, representing geometry as a sparse cloud where voxel values indicate the count of views mapping to that location [S1]. It differs from [Orthographic Multi-View Voxelization](3892-orthographic-multi-view-voxelization.md) by explicitly using depth estimation and registration to handle view-dependent appearance and by including an iterative refinement step to remove scattering noise and smooth corners, which [Orthographic Multi-View Voxelization](3892-orthographic-multi-view-voxelization.md) does not inherently provide [S1].

## How it works
**Inputs:** A set of $N$ reference views (images and camera parameters).
**Outputs:** A 3D sparse voxel grid where each active voxel $(i, j, k)$ stores a weight $\delta_{ijk}$ (view count) and associated depth/color data.

**Data Structures:**
*   **Voxel Grid:** A sparse 3D structure. Each active voxel entry contains:
    *   `location`: Integer coordinates $(i, j, k)$.
    *   `weight` ($\delta$): Integer count of views mapping to this voxel.
    *   `depths`: A list of depth values $d_k$ corresponding to the views that mapped to this voxel.
    *   `colors`: A list of color values from the visible views.
*   **Depth Map Buffer:** A 2D array storing estimated depth values for each reference view.

**Algorithm Steps:**

1.  **Depth Estimation with Non-Lambertian Compensation:**
    For each reference view $v \in \{1, \dots, N\}$, estimate a depth map. To handle non-Lambertian reflections, search along the view's geometry for the depth value that minimizes a cost function specific to that view, rather than applying a global threshold [S1]. Let $D_v(u, v)$ be the estimated depth at pixel $(u, v)$ for view $v$.

2.  **Volume Initialization (Registration):**
    Register the estimated depth maps into the 3D volume. For each pixel $(u, v)$ in each view $v$, project the depth $D_v(u, v)$ into the 3D voxel grid to determine voxel coordinates $(i, j, k)$.
    Update the voxel weight $\delta_{ijk}$:
    $$
    \delta_{ijk} = \begin{cases} 
    n & \text{if registering depth, where } n \text{ is the count of views mapping to } (i, j, k) \\
    0 & \text{otherwise}
    \end{cases}
    $$
    [S1]

3.  **Isolated Voxel Removal and Depth Re-estimation:**
    Detect isolated voxels that have no neighbors (i.e., $\delta_{ijk} = 1$ and no adjacent voxels are active). Project the current volume back to the reference view geometry to build new depth maps. This step removes errors from the previous registration by incorporating depth information from other views [S1].
    
    If multiple depth values exist for a single pixel in the projected view, consider the "front cluster" of depths. The proper depth value $d$ for a pixel is calculated as:
    $$
    d = \begin{cases} 
    d_n & \text{if only one depth has } \delta_n = \max(\delta_K) \\
    \frac{\sum_{k=1}^{K} \delta_k d_k}{\sum_{k=1}^{K} \delta_k} & \text{otherwise}
    \end{cases}
    $$
    where $K$ is the number of depth values in the front cluster, $d_k$ is the depth value, and $\delta_k$ is the voxel weight associated with that depth [S1]. If the maximum $\delta$ appears in two or more depth values, the fit depth value is calculated from the average of all depth values of the front cluster weighted by $\delta$ [S1].

4.  **Volume Reconstruction and Interpolation:**
    Reconstruct the volume using the refined depth maps. Interpolate voxels to connect the surface of the volume among near voxels, filling gaps where isolated voxels were removed [S1].

5.  **Iterative Volume Refinement:**
    Refine the shape of the volume by removing scattering voxels and smoothing sharp corners to increase coding gain [S1].
    *   **Color Assignment:** Temporarily define voxel colors by taking the median of color values from all visible views for that voxel [S1].
    *   **Iteration Loop:** Iterate through reference views (e.g., from furthest left to furthest right).
        1.  Calculate the Mean Square Error (MSE) between the reconstructed view and the original reference image. Use a window-based computation (e.g., 3x3 pixels) for error calculation to handle inaccurate camera calibration and unequal resolutions [S1].
        2.  If the MSE exceeds a threshold:
            *   Remove the old depth and its associated voxel.
            *   Investigate a new depth derived from neighboring pixels based on a smooth surface assumption.
            *   If the new depth value meets color constraints for all visible views, generate the new associated voxel.
        3.  If voxels are removed or generated, iteratively reconstruct images because changes in voxel position affect visibility (an invisible point may become visible and vice versa) [S1].
    *   **Termination:** Repeat until no new voxels are generated and no old voxels are removed [S1].

**Pseudocode:**

```python
def volumetric_representation_via_depth_map_registration(reference_views):
    """
    reference_views: List of View objects, each containing image, camera matrix, and intrinsic parameters.
    Returns: SparseVoxelGrid
    """
    N = len(reference_views)
    voxel_grid = SparseVoxelGrid()
    
    # Step 1: Depth Estimation
    depth_maps = []
    for view in reference_views:
        # Estimate depth map using per-view minimum cost to handle non-Lambertian reflections
        depth_map = estimate_depth_per_view_minimum_cost(view)
        depth_maps.append(depth_map)
        
    # Step 2: Volume Initialization
    for view_idx, (view, depth_map) in enumerate(zip(reference_views, depth_maps)):
        for u, v in depth_map.non_zero_pixels():
            depth_val = depth_map[u, v]
            # Project depth into 3D voxel coordinates
            voxel_coords = project_to_voxel_grid(view, depth_val)
            voxel_grid.increment_weight(voxel_coords)
            voxel_grid.add_depth(voxel_coords, depth_val)
            
    # Step 3: Isolated Voxel Removal and Depth Re-estimation
    refined_depth_maps = []
    for view_idx, view in enumerate(reference_views):
        # Project volume back to view geometry
        projected_depths = project_volume_to_view(voxel_grid, view)
        
        # Resolve multiple depths per pixel using front cluster weighting
        final_depth_map = resolve_front_cluster_depths(projected_depths, voxel_grid)
        refined_depth_maps.append(final_depth_map)
        
    # Step 4: Volume Reconstruction and Interpolation
    voxel_grid.clear()
    for view_idx, (view, depth_map) in enumerate(zip(reference_views, refined_depth_maps)):
        for u, v in depth_map.non_zero_pixels():
            depth_val = depth_map[u, v]
            voxel_coords = project_to_voxel_grid(view, depth_val)
            voxel_grid.increment_weight(voxel_coords)
            voxel_grid.add_depth(voxel_coords, depth_val)
            
    # Interpolate to connect surface
    voxel_grid.interpolate_near_voxels()
    
    # Step 5: Iterative Volume Refinement
    while True:
        changed = False
        # Assign temporary colors (median of visible views)
        voxel_grid.assign_temporary_colors(reference_views)
        
        for view in reference_views:
            # Reconstruct view from current volume
            reconstructed_view = reconstruct_view(voxel_grid, view)
            
            # Calculate MSE using 3x3 window
            mse = calculate_windowed_mse(reconstructed_view, view.image, window_size=3)
            
            if mse > threshold:
                # Remove old depth and associated voxel
                old_depth = get_depth_from_view(view)
                voxel_coords = project_to_voxel_grid(view, old_depth)
                voxel_grid.remove_voxel(voxel_coords)
                changed = True
                
                # Investigate new depth from neighbors (smooth surface assumption)
                new_depth = estimate_new_depth_from_neighbors(view, voxel_coords)
                
                # Check color constraints for all visible views
                if meets_color_constraints(new_depth, voxel_coords, reference_views):
                    new_voxel_coords = project_to_voxel_grid(view, new_depth)
                    voxel_grid.add_voxel(new_voxel_coords, new_depth)
                    changed = True
                    
        if not changed:
            break
            
    return voxel_grid
```

## Subtopics

### Iterative Volume Refinement
An iterative algorithm to refine the shape of the volume by removing scattering voxels and smoothing sharp corners to increase coding gain [S1]. It compares reconstructed views against original reference images to identify and correct geometry errors [S1]. It is chosen when the initial volume contains significant noise or sharp corners that reduce coding efficiency [S1]. It differs from the initialization phase by focusing on error minimization (MSE) and topological smoothing rather than initial registration [S1].

## Operating characteristics
*   **Time Complexity:** The initialization phase is linear with respect to the number of pixels in the reference views and the number of views $N$. The iterative refinement phase is non-linear and depends on the number of iterations required for convergence (e.g., 26 iterations for the five-view Leo sequence) [S1].
*   **Memory Complexity:** Proportional to the number of active voxels in the sparse grid. The sparse representation allows for efficient storage of scenes with large empty spaces [S1].
*   **Strengths:** Handles non-Lambertian reflections effectively by using per-view costs [S1]. Removes isolated noise and smooths corners, improving coding gain for compression [S1]. Robust to inaccurate camera calibration and unequal resolutions due to window-based error calculation [S1].
*   **Limitations:** Computationally expensive due to iterative reconstruction and refinement [S1]. Performance depends on the quality of the initial depth estimation [S1].
*   **When to use:** When high-quality volume initialization is required for view synthesis, especially in the presence of non-Lambertian surfaces and when compression efficiency is a priority [S1].
*   **When not to use:** When real-time performance is critical and the iterative refinement step is too slow [S1].

## Background
The method was proposed in the context of color volumetric compression for realistic view synthesis applications [S1]. It builds on the principle that depth registration methods provide a good representation for natural scenery [S1]. The approach addresses limitations of global thresholding in depth estimation by exploiting individual minimum costs per view [S1].
