# Volumetric Representation via Depth Map Registration

Also called: Sparse Non-Lambertian Multi-view Volume Construction, Volume Initialization

## Overview
This method constructs a 3D volume from multi-view images by registering estimated depth maps into a voxel grid, specifically handling non-Lambertian reflections by using individual minimum cost per view rather than a global threshold [S1]. It represents scene geometry as a sparse voxel cloud where voxel values indicate the number of views mapping to that location, distinguishing it from sibling methods that may rely on global thresholds or simple occupancy accumulation [S1].

## How it works
**Inputs:** A set of $N$ reference views (images and camera parameters) and a target 3D bounding box.
**Outputs:** A 3D voxel grid where each voxel $(i, j, k)$ holds an integer weight $\delta_{ijk}$ representing the count of views mapping to it, and a refined depth map for each reference view.

**Data Structures:**
*   **Voxel Grid:** A 3D array indexed by $(i, j, k)$. Each element stores an integer $\delta_{ijk} \in \{0, 1, \dots, N\}$.
*   **Depth Map:** A 2D array for each reference view, storing a single depth value $d$ per pixel.

**Steps:**

1.  **Depth Estimation:** For each reference view, search along its geometry to estimate a depth map. Use an individual minimum cost function for each view to compensate for non-Lambertian reflections, avoiding a global threshold [S1].
2.  **Volume Initialization (Registration):** Register the estimated depth maps into the 3D volume. For each voxel at location $(i, j, k)$, calculate its value $\delta_{ijk}$:
    $$
    \delta_{ijk} = \begin{cases} 
    n & \text{if registering depth} \\
    0 & \text{otherwise}
    \end{cases}
    $$
    where $n$ is the number of views that map to voxel $\vec{x}$, and $n \in \{1, 2, \dots, N\}$ [S1].
3.  **Noise Removal and Refinement:**
    *   Detect isolated voxels with no neighbors.
    *   Project the volume back to the reference view geometry to build new depth maps. This step removes errors from the previous registration by incorporating depth information from other views [S1].
    *   If multiple depth values exist for a pixel in the projected view, consider only the front cluster of depths. The proper depth value $d$ for a pixel is calculated as:
        $$
        d = \begin{cases} 
        d_n & \text{if only one depth has } \delta_n = \max(\delta_K) \\
        \left(\sum_{k=1}^K \delta_k d_k\right) / \left(\sum_{k=1}^K \delta_k\right) & \text{otherwise}
        \end{cases}
        $$
        where $K$ is the number of depth values in the front cluster, $d_k$ is the depth value, and $\delta_k$ is the voxel weight. The depth value projected from the voxel containing the maximum $\delta$ is selected. If the maximum $\delta$ appears in two or more depth values, the fit depth value is calculated from the weighted average of all depth values in the front cluster [S1].
4.  **Volume Reconstruction:** Reconstruct the volume again using the refined depth maps. Interpolate voxels to connect the surface of the volume among near voxels [S1].

            for x in range(depth_map.width):

                if d is not None:
                    # Project 2D pixel (x, y) and depth d to 3D voxel (i, j, k)

                    if is_inside_bounds(i, j, k, resolution):

    # Step 3: Noise Removal and Refinement
    # Detect isolated voxels and project back to build new depth maps
    refined_depth_maps = []
    for view_idx, view in enumerate(reference_views):
        # Project volume back to view geometry
        projected_depths = project_volume_to_view(voxel_grid, view.camera_matrix, resolution, bounding_box)
        
        # Handle multiple depth values per pixel using front cluster
        new_depth_map = zeros((view.height, view.width))
        for y in range(view.height):
            for x in range(view.width):
                depths_in_cluster = get_front_cluster_depths(projected_depths[y, x])
                if not depths_in_cluster:
                    continue
                    
                # Calculate weighted average or select max delta depth
                # depths_in_cluster is a list of (depth_value, voxel_weight)
                max_delta = max(w for _, w in depths_in_cluster)
                max_delta_depths = [d for d, w in depths_in_cluster if w == max_delta]
                
                if len(max_delta_depths) == 1:
                    new_depth_map[y, x] = max_delta_depths[0]
                else:
                    # Weighted average of all depths in the front cluster
                    total_weight = sum(w for _, w in depths_in_cluster)
                    weighted_sum = sum(d * w for d, w in depths_in_cluster)
                    new_depth_map[y, x] = weighted_sum / total_weight
        refined_depth_maps.append(new_depth_map)
        
    # Step 4: Volume Reconstruction
    # Re-initialize grid to zero before re-registration
    voxel_grid = zeros((resolution[0], resolution[1], resolution[2]), dtype=int)
    for view_idx, depth_map in enumerate(refined_depth_maps):
        for y in range(depth_map.height):
            for x in range(depth_map.width):
                d = depth_map[y, x]
                if d is not None:
                    i, j, k = project_to_voxel(x, y, d, reference_views[view_idx].camera_matrix, bounding_box, resolution)
                    if is_inside_bounds(i, j, k, resolution):
                        voxel_grid[i, j, k] += 1
                        
    # Interpolate voxels to connect surface
    voxel_grid = interpolate_voxels(voxel_grid)
    
    return voxel_grid, refined_depth_maps

## Operating characteristics
*   **Time Complexity:** Dominated by depth estimation and projection steps. Registration is $O(N \cdot H \cdot W)$ where $H, W$ are image dimensions. Refinement involves re-projection and interpolation.
*   **Memory Complexity:** $O(X \cdot Y \cdot Z)$ for the voxel grid, where $X, Y, Z$ are resolution dimensions. Sparse representation is implied by the weight-based storage.
*   **Strengths:** Handles non-Lambertian reflections effectively via per-view cost minimization. Provides a good representation for natural scenery. Simple and fast registration.
*   **Limitations:** May produce isolated voxels requiring refinement. Sharp corners may reduce coding gain in compression applications, requiring smoothing [S1].
*   **When to use:** When multi-view images are available and non-Lambertian effects are significant. Suitable for volume initialization in view synthesis pipelines.

## Background
The method was proposed in "Colour volumetric compression for realistic view synthesis applications" [S1]. It addresses the challenge of constructing accurate 3D volumes from multi-view images, particularly in the presence of non-Lambertian reflections. The approach builds on the principle that depth registration methods provide a good representation for natural scenery [S1]. It is used in the context of volume initialization for view synthesis applications.
