# Single 2D Projection Voxelization

Also called: Dominant axis voxelization, Thin voxelization via single projection

## Overview
Single 2D Projection Voxelization is a method for producing 6-separating (tunnel-free) voxelizations of planar triangles using only a single 2D rasterization pass along the dominant axis of the triangle's normal vector [S1, unofficial]. It leverages the "thinness" property of voxelization to prove that projecting along the dominant axis is sufficient to capture all voxels intersected by the triangle, eliminating the need for multi-view synthesis required by siblings like [Orthographic Multi-View Voxelization](3892-orthographic-multi-view-voxalization.md) or [Volumetric Representation via Depth Map Registration](6435-volumetric-representation-via-depth-map-registration.md).

## How it works
**Inputs:** A planar triangle defined by three vertices in 3D space; a voxel grid with known resolution and origin.
**Outputs:** A set of voxel indices $(i, j, k)$ representing the 6-separating voxelization of the triangle.

**Data Structures:**
*   **Voxel Grid:** A 3D array or hash map mapping integer coordinates $(i, j, k)$ to boolean occupancy or depth values.
*   **Triangle:** Defined by vertices $\mathbf{v}_0, \mathbf{v}_1, \mathbf{v}_2$.
*   **Normal:** $\mathbf{n} = (\mathbf{v}_1 - \mathbf{v}_0) \times (\mathbf{v}_2 - \mathbf{v}_0)$, normalized.

**Steps:**

1.  **Identify Dominant Axis:** Determine the axis aligned with the maximum absolute component of the geometric normal vector $\mathbf{n} = (n_x, n_y, n_z)$. Let this axis be $A_{dom}$ and the projection plane be the orthogonal plane (e.g., if $A_{dom}=Z$, project onto the XY plane).
2.  **Rasterize:** Project the triangle onto the 2D plane orthogonal to $A_{dom}$. Rasterize this 2D projection to identify all pixels (screen-space coordinates) covered by the triangle.
3.  **Process Pixels with Center Intersection:** For each rasterized pixel where the triangle's projection contains the pixel center:
    *   Evaluate the depth of the triangle at the pixel center.
    *   Output the voxel in the column corresponding to the pixel whose center depth is closest to the evaluated triangle depth. This corresponds to intersecting the triangle against the crosshair segment parallel to the projection axis [S1, unofficial].
4.  **Process Pixels with Edge Intersection (Crosshair Test):** For pixels where the triangle's projection contains an edge but does *not* contain the pixel center:
    *   **Horizontal Test:** Find the intersection extents of the triangle on the horizontal line bisecting the pixel. Clamp these extents to the horizontal pixel boundaries. Evaluate the triangle depth at these two clamped points. If the depths lie on different sides of the voxel's center depth, output the corresponding voxel.
    *   **Vertical Test:** If the horizontal test fails (depths are on the same side), repeat the test using the vertical line bisecting the pixel and clamping to vertical pixel boundaries. If the depths lie on different sides of the voxel's center depth, output the corresponding voxel. These tests correspond to intersecting the triangle against the two crosshair segments perpendicular to the projection axis [S1, unofficial].

**Pseudocode:**

```python
def single_2d_projection_voxelization(triangle, voxel_grid):
    """
    Voxelize a triangle using a single 2D projection along the dominant normal axis.
    
    Args:
        triangle: List of 3 vertices, each a tuple (x, y, z).
        voxel_grid: Object with methods to set voxel occupancy at (i, j, k).
    
    Returns:
        None (modifies voxel_grid in place).
    """
    v0, v1, v2 = triangle
    
    # 1. Calculate Normal and Dominant Axis
    n = cross(v1 - v0, v2 - v0)
    abs_n = [abs(n.x), abs(n.y), abs(n.z)]
    
    # Determine dominant axis index (0=x, 1=y, 2=z)
    dom_axis_idx = argmax(abs_n)
    
    # Define projection plane axes based on dominant axis
    if dom_axis_idx == 0: # Dominant is X, project onto YZ
        p1, p2 = 1, 2
        depth_axis = 0
    elif dom_axis_idx == 1: # Dominant is Y, project onto XZ
        p1, p2 = 0, 2
        depth_axis = 1
    else: # Dominant is Z, project onto XY
        p1, p2 = 0, 1
        depth_axis = 2
        
    # 2. Rasterize 2D Projection
    # Get bounding box of projected triangle in screen space
    proj_v0 = (v0[p1], v0[p2])
    proj_v1 = (v1[p1], v1[p2])
    proj_v2 = (v2[p1], v2[p2])
    
    pixels = rasterize_triangle(proj_v0, proj_v1, proj_v2)
    
    # 3. Process Pixels
    for pixel in pixels:
        center = pixel.center
        bounds = pixel.bounds # (min_p1, min_p2, max_p1, max_p2)
        
        # Check if center is inside triangle
        if point_in_triangle(center, proj_v0, proj_v1, proj_v2):
            # Step 3: Center Intersection
            depth_at_center = evaluate_triangle_depth(triangle, center, depth_axis, p1, p2)
            voxel_idx = get_voxel_index_at_depth(center, depth_at_center, depth_axis)
            voxel_grid.set(voxel_idx, True)
        else:
            # Step 4: Edge Intersection (Crosshair Tests)
            voxel_found = False
            
            # Horizontal Test (along p1 axis, bisecting p2)
            # Line: p2 = center.p2, p1 varies within pixel bounds
            h_min_p1 = bounds.min_p1
            h_max_p1 = bounds.max_p1
            
            # Clamp to pixel bounds (already done by bounds)
            # Evaluate depth at horizontal extents
            pt1 = (h_min_p1, center.p2)
            pt2 = (h_max_p1, center.p2)
            
            d1 = evaluate_triangle_depth(triangle, pt1, depth_axis, p1, p2)
            d2 = evaluate_triangle_depth(triangle, pt2, depth_axis, p1, p2)
            
            # Check if depths are on different sides of voxel center depth
            # Note: 'voxel center depth' implies the depth of the voxel grid plane at this pixel
            # For simplicity, we assume we are checking against the voxel slice center
            voxel_center_depth = get_voxel_center_depth_at_pixel(center, depth_axis)
            
            if (d1 - voxel_center_depth) * (d2 - voxel_center_depth) < 0:
                voxel_idx = get_voxel_index_at_depth(center, voxel_center_depth, depth_axis)
                voxel_grid.set(voxel_idx, True)
                voxel_found = True
                
            if not voxel_found:
                # Vertical Test (along p2 axis, bisecting p1)
                # Line: p1 = center.p1, p2 varies within pixel bounds
                v_min_p2 = bounds.min_p2
                v_max_p2 = bounds.max_p2
                
                pt3 = (center.p1, v_min_p2)
                pt4 = (center.p1, v_max_p2)
                
                d3 = evaluate_triangle_depth(triangle, pt3, depth_axis, p1, p2)
                d4 = evaluate_triangle_depth(triangle, pt4, depth_axis, p1, p2)
                
                if (d3 - voxel_center_depth) * (d4 - voxel_center_depth) < 0:
                    voxel_idx = get_voxel_index_at_depth(center, voxel_center_depth, depth_axis)
                    voxel_grid.set(voxel_idx, True)

    """
    Intersect a ray from screen_pt along the depth_axis with the triangle.
    Returns the coordinate along the depth_axis.
    """
    v0, v1, v2 = triangle
    # Ray origin in 3D
    ray_origin = [0, 0, 0]
```

**Edge Cases and Pitfalls:**
*   **Degenerate Triangles:** If the triangle normal is zero (degenerate triangle), the dominant axis is undefined. The algorithm assumes non-degenerate input.
*   **Precision:** Floating-point precision in depth evaluation and intersection tests can lead to tunneling if not handled carefully. The "different sides" check relies on strict inequality, which may be sensitive to epsilon errors.
*   **Boundary Conditions:** Clamping extents to pixel bounds must be exact to avoid missing voxels at pixel edges.

## Operating characteristics
*   **Time Complexity:** $O(N)$ where $N$ is the number of pixels covered by the triangle's projection. Significantly faster than multi-view methods as it requires only one rasterization pass.
*   **Memory Complexity:** $O(1)$ auxiliary space per pixel, plus the storage for the voxel grid.
*   **Strengths:** High performance due to single-pass rasterization; produces 6-separating (tunnel-free) voxelizations.
*   **Limitations:** Only applicable to planar triangles. Requires careful handling of edge cases to maintain topological correctness. Not suitable for curved surfaces without tessellation.
*   **When to Use:** When performance is critical and the input geometry consists of planar triangles.
*   **When Not to Use:** For curved surfaces or when multi-view consistency is required for non-planar geometry without prior tessellation.

## Background
This method is derived from the topological approach to voxelization, specifically leveraging the "thinness" property of voxelization [S1, unofficial]. It was presented as a corollary to the equivalence of 3-axis rasterization with the crosshairs target. The method simplifies the voxelization process by reducing the number of required projections from three (or more) to one, based on the geometric properties of the triangle's normal vector.
