# Single 2D Projection Voxelization

Also called: Dominant axis voxelization, Thin voxelization via single projection

## Overview
Single 2D Projection Voxelization is a method that produces 6-separating (tunnel-free) voxel grids from planar triangles using only one 2D rasterization pass along the dominant axis of the triangle's normal [S1, unofficial]. It leverages the "thinness" property of voxelization to avoid redundant projections, relying on a single projection for the bulk of the volume and edge-crossing tests for boundary voxels. It differs from [Orthographic Multi-View Voxelization](3892-orthographic-multi-view-voxelization.md) by eliminating the need for multiple camera views and from [Volumetric Representation via Depth Map Registration](6435-volumetric-representation-via-depth-map-registration.md) by operating directly on triangle geometry rather than depth maps.

## How it works
**Inputs:** A triangle defined by three vertices in 3D space; a voxel grid resolution and bounding box.
**Outputs:** A 6-separating voxel grid where occupied voxels represent the triangle.

**Data Structures:**
*   **Voxel Grid:** A 3D array of booleans or signed distance values. Indices $(i, j, k)$ map to world coordinates via $P_{world} = P_{min} + (i+0.5, j+0.5, k+0.5) \times \Delta$, where $\Delta$ is voxel size.
*   **Triangle:** Defined by vertices $V_0, V_1, V_2$.

**Steps:**
1.  **Dominant Axis Selection:** Compute the geometric normal $\mathbf{n}$ of the triangle. Identify the axis $A \in \{X, Y, Z\}$ with the largest absolute component $|n_A|$. This is the projection axis.
2.  **2D Projection:** Project the triangle vertices onto the plane perpendicular to $A$. This yields a 2D triangle.
3.  **Rasterization:** Rasterize the 2D triangle. For each pixel $(u, v)$ covered by the projection:
    *   **Case 1: Pixel Center Inside.** If the pixel center $(u+0.5, v+0.5)$ lies inside the 2D projected triangle:
        *   Evaluate the 3D depth $d_{tri}$ of the triangle at the pixel center's 3D position (projecting the center back to 3D along axis $A$).
        *   Determine the voxel index $k$ along axis $A$ such that the voxel center depth $d_{vox}$ is closest to $d_{tri}$.
        *   Mark voxel $(u, v, k)$ as occupied.
    *   **Case 2: Edge Crossing (Pixel Center Outside).** If the pixel center is outside the 2D triangle but the pixel is intersected by the triangle boundary:
        *   **Horizontal Test:** Find the intersection points of the triangle edges with the horizontal line bisecting the pixel ($y = v+0.5$). Let these be $x_{left}$ and $x_{right}$.
        *   Clamp $x_{left}$ and $x_{right}$ to the pixel's horizontal extents $[u, u+1]$.
        *   Evaluate the 3D depth of the triangle at these two clamped 3D points. Let them be $d_{left}$ and $d_{right}$.
        *   If $d_{left}$ and $d_{right}$ lie on different sides of the center depth of any voxel along the column (i.e., $(d_{left} - d_{vox})(d_{right} - d_{vox}) < 0$ for some $k$), mark those voxels as occupied.
        *   **Vertical Test:** If the horizontal test yields no voxels (or fails to capture the topology), repeat the process using the vertical line bisecting the pixel ($x = u+0.5$) to find $y_{top}, y_{bottom}$, clamp to $[v, v+1]$, evaluate depths, and mark voxels if depths straddle a voxel center.

**Pseudocode:**
```python
def single_2d_projection_voxelization(triangle, grid_res, grid_min, grid_max):
    # 1. Dominant Axis
    n = cross(triangle.v1 - triangle.v0, triangle.v2 - triangle.v0)
    abs_n = abs(n)
    if abs_n.x >= abs_n.y and abs_n.x >= abs_n.z:
        axis = 'x'
        proj_plane = 'yz'
    elif abs_n.y >= abs_n.x and abs_n.y >= abs_n.z:
        axis = 'y'
        proj_plane = 'xz'
    else:
        axis = 'z'
        proj_plane = 'xy'

    # 2. Project to 2D
    tri_2d = project(triangle, axis)
    
    # 3. Rasterize
    for u, v in pixels_covered_by(tri_2d):
        pixel_center_2d = (u + 0.5, v + 0.5)
        
        if point_in_triangle(pixel_center_2d, tri_2d):
            # Case 1: Center inside
            p_3d = unproject(pixel_center_2d, axis, triangle)
            d_tri = depth_of_triangle(p_3d, axis)
            k = voxel_index_for_depth(d_tri, axis, grid_min, grid_max)
            grid.set(u, v, k, True)
        else:
            # Case 2: Edge crossing
            # Horizontal test
            y_bisect = v + 0.5
            x_intersects = intersect_triangle_horizontal(tri_2d, y_bisect)
            if x_intersects:
                x1, x2 = clamp(x_intersects[0], u, u+1), clamp(x_intersects[1], u, u+1)
                p1_3d = unproject((x1, y_bisect), axis, triangle)
                p2_3d = unproject((x2, y_bisect), axis, triangle)
                d1 = depth_of_triangle(p1_3d, axis)
                d2 = depth_of_triangle(p2_3d, axis)
                mark_voxels_straddling(d1, d2, axis, u, v, grid_min, grid_max, grid)
            
            # Vertical test if horizontal failed or for robustness
            x_bisect = u + 0.5
            y_intersects = intersect_triangle_vertical(tri_2d, x_bisect)
            if y_intersects:
                y1, y2 = clamp(y_intersects[0], v, v+1), clamp(y_intersects[1], v, v+1)
                p1_3d = unproject((x_bisect, y1), axis, triangle)
                p2_3d = unproject((x_bisect, y2), axis, triangle)
                d1 = depth_of_triangle(p1_3d, axis)
                d2 = depth_of_triangle(p2_3d, axis)
                mark_voxels_straddling(d1, d2, axis, u, v, grid_min, grid_max, grid)

def mark_voxels_straddling(d1, d2, axis, u, v, grid_min, grid_max, grid):
    # Determine voxel centers along the projection axis
    # Check if d1 and d2 straddle any voxel center depth
    for k in range(grid_min[axis], grid_max[axis]):
        d_voxel_center = voxel_center_depth(k, axis, grid_min, grid_max)
        if (d1 - d_voxel_center) * (d2 - d_voxel_center) < 0:
            grid.set(u, v, k, True)
```

**Parameters:**
*   **Dominant Axis Selection:** Based on normal components. No tuning required.
*   **Clamping:** Strictly clamp intersection points to pixel boundaries $[u, u+1]$ to ensure tests are local to the pixel.

**Edge Cases:**
*   **Degenerate Triangles:** If the triangle normal is zero (degenerate), the dominant axis is undefined. The method assumes non-degenerate input.
*   **Precision:** Floating-point comparisons for "straddling" should use a small epsilon to avoid missing voxels due to precision errors at exact boundaries.
*   **Boundary Pixels:** Pixels partially outside the grid should be handled by clamping or ignoring, depending on whether the grid is padded.

## Subtopics

### Crosshairs Target Equivalence
This method is equivalent to the crosshairs target approach but optimized for single-axis projection. The pixel center test corresponds to the crosshair segment parallel to the projection axis, while the edge tests correspond to the perpendicular segments [S1, unofficial].

### Thin Voxelization
The resulting voxelization is "thin," meaning no voxel is redundant; removing any occupied voxel would change the silhouette or topology. This property ensures 6-separation.

## Operating characteristics
*   **Time Complexity:** $O(N \cdot R)$, where $N$ is the number of triangles and $R$ is the number of pixels covered by the 2D projection. Significantly faster than multi-view methods which require $3 \times$ projections.
*   **Memory Complexity:** $O(V)$ for the voxel grid, where $V$ is the number of voxels.
*   **Strengths:** High performance due to single pass; produces topologically correct (6-separating) results; simple implementation.
*   **Limitations:** Relies on the "thinness" property which holds for planar triangles; may require careful handling of edge cases to avoid tunnels.
*   **When to Use:** When performance is critical and the input consists of planar triangles. Not suitable for non-planar surfaces without tessellation.

## Background
The method is derived from the topological approach to voxelization, specifically the observation that 3-axis rasterization is equivalent to a crosshairs target [S1, unofficial]. It was presented in the context of NVIDIA's research on efficient voxelization for volume rendering. The key insight is that the dominant axis projection covers all voxels intersected by the triangle's interior, and only the edges require additional testing to ensure topological correctness.
