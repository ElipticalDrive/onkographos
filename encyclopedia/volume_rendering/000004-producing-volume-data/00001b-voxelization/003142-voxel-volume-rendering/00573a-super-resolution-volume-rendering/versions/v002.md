# Super resolution volume rendering

Also called: Gradient-based super resolution, Intermediate difference volume gradient rendering

## Overview
Super resolution volume rendering is a technique that visualizes sharp surfaces located between voxels by calculating and shading the intermediate difference volume gradient at re-sampling locations, rather than interpolating voxel opacities [S1, unofficial]. It solves the problem of low perceived resolution in standard voxel volume rendering, where classification at voxel locations causes semi-transparent artifacts and limits detail to the voxel size [S1, unofficial]. It sets itself apart from [Voxel Volume Rendering](6488-voxel-volume-rendering.md) by performing classification and shading at arbitrary re-sampling locations on the ray instead of at discrete voxel centers, and from [Simple Shader (3D Texture Mapping)](12431-simple-shader-3d-texture-mapping.md) by explicitly computing volume gradients for shading at these intermediate points [S1, unofficial].

## How it works
**Inputs and Outputs:**
*   **Input:** A 3D scalar voxel dataset $V$, an opacity function $T(v)$, a re-sampling distance $d_s$, and a ray defined by origin $\mathbf{o}$ and direction $\mathbf{d}$ [S1, unofficial].
*   **Output:** A color value $C$ for each pixel [G].

**Data Structures:**
*   **Voxel Data:** A 3D array of scalar values [G].
*   **Pre-computed Gradients:** A 3D array of 3D vectors $\mathbf{G}_{\text{voxel}}$, where each vector is the central difference gradient at a voxel center [S1, unofficial]. If not pre-computed, gradients are calculated on the fly using central differences:
    $$ \mathbf{G}(x,y,z) = \left( \frac{V(x+1,y,z)-V(x-1,y,z)}{2}, \frac{V(x,y+1,z)-V(x,y-1,z)}{2}, \frac{V(x,y,z+1)-V(x,y,z-1)}{2} \right) $$
    [G: Assumes unit voxel spacing; scale by voxel dimensions if spacing differs].

**Parameters:**
*   **Opacity Function $T(v)$:** A step function where $T(v) = 0$ if $v < \text{threshold}$ and $T(v) = 1$ if $v \ge \text{threshold}$ [S1, unofficial].
*   **Re-sampling Distance $d_s$:** The distance between sample points on the ray, typically equal to or smaller than the voxel distance (e.g., $d_s = \text{voxel\_size} / 10$) [S1, unofficial].

**Steps:**
1.  **Ray Marching:** For each pixel, cast a ray through the volume [G].
2.  **Re-sampling:** Sample the volume at positions $\mathbf{p}$ along the ray with spacing $d_s$ [S1, unofficial].
3.  **Gradient Interpolation:** At each re-sampling location $\mathbf{p}$, compute the volume gradient vector $\mathbf{G}(\mathbf{p})$ by tri-linearly interpolating the pre-computed voxel gradients $\mathbf{G}_{\text{voxel}}$ at the eight surrounding voxel centers [S1, unofficial]. This approach is a three-dimensional extension to Phong normal interpolation [S1, unofficial].
4.  **Opacity Classification:** Apply the opacity function $T(V(\mathbf{p}))$ at the re-sampling location $\mathbf{p}$ using the interpolated scalar value $V(\mathbf{p})$ [S1, unofficial].
5.  **Shading:** If the opacity is non-zero, calculate the shading (color) using the interpolated gradient $\mathbf{G}(\mathbf{p})$ as the surface normal [S1, unofficial].
6.  **Compositing:** Composite the color and opacity along the ray using standard front-to-back accumulation [G].

**Pseudocode:**
```python
def super_resolution_volume_render(ray_origin, ray_direction, volume, voxel_size, threshold, resample_distance, near_plane=0.0, far_plane=100.0):
    # volume: list of lists of lists, shape (D, H, W)
    D, H, W = len(volume), len(volume[0]), len(volume[0][0])
    
    # Pre-compute voxel gradients using central differences
    G_voxels = [[[None for _ in range(W)] for _ in range(H)] for _ in range(D)]
    for z in range(D):
        for y in range(H):
            for x in range(W):
                gx = (volume[z][y][x+1] - volume[z][y][x-1]) / 2.0 if 0 < x < W-1 else 0.0
                gy = (volume[z][y+1][x] - volume[z][y-1][x]) / 2.0 if 0 < y < H-1 else 0.0
                gz = (volume[z+1][y][x] - volume[z-1][y][x]) / 2.0 if 0 < z < D-1 else 0.0
                G_voxels[z][y][x] = (gx, gy, gz)

    color = (0.0, 0.0, 0.0)
    alpha = 0.0
    t = near_plane

    while t < far_plane:
        # Re-sampling location in world space
        p = (ray_origin[0] + ray_direction[0]*t,
             ray_origin[1] + ray_direction[1]*t,
             ray_origin[2] + ray_direction[2]*t)

        # Convert world position to voxel coordinates
        vz = p[0] / voxel_size
        vy = p[1] / voxel_size
        vx = p[2] / voxel_size

        # Clamp to valid range for interpolation to prevent out-of-bounds
        vz_c = max(0.0, min(float(D-1), vz))
        vy_c = max(0.0, min(float(H-1), vy))
        vx_c = max(0.0, min(float(W-1), vx))

        # 1. Interpolate scalar value at p
        v_val = trilinear_interpolate(volume, vz_c, vy_c, vx_c, D, H, W)

        # 2. Apply opacity function
        opacity = 1.0 if v_val >= threshold else 0.0

        if opacity > 0.0:
            # 3. Interpolate gradient at p for shading
            g_vec = trilinear_interpolate_gradient(G_voxels, vz_c, vy_c, vx_c, D, H, W)

            # 4. Calculate shading (simplified diffuse lighting)
            gx, gy, gz = g_vec
            norm = (gx**2 + gy**2 + gz**2)**0.5
            if norm > 0:
                gx, gy, gz = gx/norm, gy/norm, gz/norm
            # Assume light direction (0,0,1) for simplicity
            diffuse = max(0.0, gz)
            pixel_color = (diffuse, diffuse, diffuse)

            # 5. Composite (front-to-back)
            contribution = (1.0 - alpha) * opacity
            color = (color[0] + contribution * pixel_color[0],
                     color[1] + contribution * pixel_color[1],
                     color[2] + contribution * pixel_color[2])
            alpha = alpha + contribution * opacity

            # Optimization: If opaque, break early
            if alpha >= 1.0:
                break

        # Advance ray
        t += resample_distance

    return color, alpha

def trilinear_interpolate(data, z, y, x, D, H, W):
    z0, z1 = int(z), min(int(z)+1, D-1)
    y0, y1 = int(y), min(int(y)+1, H-1)
    x0, x1 = int(x), min(int(x)+1, W-1)
    dz, dy, dx = z-z0, y-y0, x-x0
    c00 = data[z0][y0][x0]*(1-dz)*(1-dy)*(1-dx) + data[z0][y0][x1]*(1-dz)*(1-dy)*dx + \
          data[z0][y1][x0]*(1-dz)*dy*(1-dx) + data[z0][y1][x1]*(1-dz)*dy*dx
    c10 = data[z1][y0][x0]*dz*(1-dy)*(1-dx) + data[z1][y0][x1]*dz*(1-dy)*dx + \
          data[z1][y1][x0]*dz*dy*(1-dx) + data[z1][y1][x1]*dz*dy*dx
    return c00*(1-dz) + c10*dz

def trilinear_interpolate_gradient(grads, z, y, x, D, H, W):
    z0, z1 = int(z), min(int(z)+1, D-1)
    y0, y1 = int(y), min(int(y)+1, H-1)
    x0, x1 = int(x), min(int(x)+1, W-1)
    dz, dy, dx = z-z0, y-y0, x-x0
    def lerp3d(g000, g001, g010, g011, g100, g101, g110, g111):
        c00 = g000*(1-dz)*(1-dy)*(1-dx) + g001*(1-dz)*(1-dy)*dx + g010*(1-dz)*dy*(1-dx) + g011*(1-dz)*dy*dx
        c10 = g100*dz*(1-dy)*(1-dx) + g101*dz*(1-dy)*dx + g110*dz*dy*(1-dx) + g111*dz*dy*dx
        return c00*(1-dz) + c10*dz
    gx = lerp3d(grads[z0][y0][x0][0], grads[z0][y0][x1][0], grads[z0][y1][x0][0], grads[z0][y1][x1][0],
                 grads[z1][y0][x0][0], grads[z1][y0][x1][0], grads[z1][y1][x0][0], grads[z1][y1][x1][0])
    gy = lerp3d(grads[z0][y0][x0][1], grads[z0][y0][x1][1], grads[z0][y1][x0][1], grads[z0][y1][x1][1],
                 grads[z1][y0][x0][1], grads[z1][y0][x1][1], grads[z1][y1][x0][1], grads[z1][y1][x1][1])
    gz = lerp3d(grads[z0][y0][x0][2], grads[z0][y0][x1][2], grads[z0][y1][x0][2], grads[z0][y1][x1][2],
                 grads[z1][y0][x0][2], grads[z1][y0][x1][2], grads[z1][y1][x0][2], grads[z1][y1][x1][2])
    return (gx, gy, gz)
```

**Edge Cases and Pitfalls:**
*   **Stack of Slices Artifact:** If the re-sampling distance equals the voxel distance, the rendered object may appear as a stack of 2-D slices [S1, unofficial]. This is caused by gradient discontinuity when neighboring rays find the surface at different discrete depth locations [S1, unofficial].
*   **Mitigation:** Use a smaller re-sampling distance (e.g., ten times smaller than the voxel distance) to reduce this artifact [S1, unofficial].
*   **Gradient Calculation Cost:** Gradient calculations are expensive but are only performed at re-sampling locations with non-zero opacity [S1, unofficial].

## Operating characteristics
*   **Time Complexity:** Gradient calculations scale with image resolution rather than dataset volume [S1, unofficial]. For a $256 \times 256$ image hitting an opaque surface, it requires ~64,000 gradient calculations regardless of dataset size, whereas Levoy’s method requires 16 million for a $256^3$ dataset [S1, unofficial].
*   **Memory Complexity:** Requires storage for the voxel data and optionally pre-computed voxel gradients [S1, unofficial].
*   **Performance:** Rendering speed is only marginally influenced by gradient calculation when an opaque surface is rendered, because the gradient is calculated only once per ray that hits the surface [S1, unofficial].
*   **Strengths:** Renders sharp surfaces between voxels, achieving perceived resolution much higher than voxel resolution [S1, unofficial].
*   **Limitations:** More expensive than simple interpolation methods due to gradient computation [S1, unofficial]. Sensitive to re-sampling distance; poor choice leads to slicing artifacts [S1, unofficial].
*   **When to Use:** When visualizing sharp surfaces in voxel data and high perceived resolution is required [S1, unofficial].

## Background
Super resolution volume rendering was introduced by Bos et al. in 1995 [S1, unofficial]. It was developed to address the low perceived quality of voxel space volume rendering algorithms, which suffer from classification at voxel locations [S1, unofficial]. The method is based on the idea of oversampling data and applying classification functions on higher resolution data [S1, unofficial]. It is a three-dimensional extension to Phong normal interpolation [S1, unofficial].
