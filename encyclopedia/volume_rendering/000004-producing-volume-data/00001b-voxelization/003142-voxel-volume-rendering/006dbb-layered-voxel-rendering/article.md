# Layered Voxel Rendering


## Overview
Layered Voxel Rendering is a real-time rendering technique that converts a 3D voxel scene into a stack of 2D pre-shaded image slices, which are then composited from bottom to top to simulate 3D depth [S1, unofficial]. It distinguishes itself from standard ray-marched voxel rendering by decoupling the expensive volumetric shading and occlusion calculations into a static pre-processing phase, allowing the final render to be performed using simple 2D image transformations (scaling and rotation) [S1, unofficial].

## How it works
### Inputs and Outputs
**Inputs:**
1.  **Scene Definition:** A collection of primitive shapes (e.g., heightmaps, cones, cylinders) defined by bounding boxes and sampling functions [S1, unofficial].
2.  **Voxel Density:** A scalar parameter controlling the solidity of shapes (e.g., for vegetation) [S1, unofficial].
3.  **Render Parameters:** The vertical height of the render area (number of layers) and the camera pitch angle [S1, unofficial].

**Outputs:**
1.  **Layer Stack:** A list of 2D images (textures), where each image represents a horizontal slice of the voxel world at a specific vertical coordinate [S1, unofficial].
2.  **Rendered Frame:** The final composite image generated by transforming and drawing the layer stack [S1, unofficial].

### Data Structures
*   **Shape Object:**
    *   `bounding_box`: A 3D axis-aligned bounding box (min/max coordinates) [S1, unofficial].
    *   `sample(x, y, z)`: A function that returns `None` if no voxel exists at `(x, y, z)`, or a `Voxel` object if it does [S1, unofficial].
*   **Voxel Object:**
    *   `color`: A pre-shaded color value (RGB) [S1, unofficial].
    *   `normal`: The surface normal of the nearest surface at the voxel's position, used for shading calculation [S1, unofficial].
*   **Layer (Image):**
    *   `width`: Width of the 2D slice in pixels/voxels [S1, unofficial].
    *   `height`: Height of the 2D slice in pixels/voxels (typically 1, representing the vertical slice thickness, or the full width of the scene if the "layer" is a horizontal plane) [S1, unofficial]. *Note: The source describes layers as "2D images" created by splitting the scene into vertical layers, but also states "for every vertical layer of voxels, a slice is created... resulting in a 2D image per layer." In the context of "drawing from bottom to top" and "scaling down vertically," the layers are horizontal planes (slices) stacked vertically. Each layer is a 2D texture representing the X-Z plane at a specific Y coordinate.*
    *   `data`: A 2D array of colors, where empty voxels are transparent or omitted [S1, unofficial].

### Steps
1.  **Define Shapes:** Populate the scene with primitive shapes. Each shape must define a bounding box and a sampling function that determines voxel existence and returns a pre-shaded color [S1, unofficial].
2.  **Pre-shade Voxels:** When sampling a shape at a coordinate, calculate the surface normal of the nearest surface. Apply lighting/shading to the base color using this normal. Store the resulting color in the voxel object [S1, unofficial]. This ensures that occluded voxels retain correct shading if they peek between layers [S1, unofficial].
3.  **Create Layers:**
    *   Determine the vertical range (min/max Y) of the scene.
    *   Create a list of 2D images, one for each integer Y coordinate in the range. The width and height of each image correspond to the X and Z dimensions of the scene [S1, unofficial].
4.  **Populate Layers:**
    *   For each Y coordinate (layer):
        *   For each X coordinate in the layer's width:
            *   For each Z coordinate in the layer's height:
                *   Query all shapes in the scene.
                *   If a shape's bounding box contains `(X, Y, Z)` and its sampling function returns a voxel, assign the voxel's pre-shaded color to the pixel at `(X, Z)` in the current layer's image [S1, unofficial].
                *   If multiple shapes overlap, the source implies a simple overwrite or first-come-first-served basis, though it notes that occluded voxels must retain their shading to prevent artifacts when peeking [S1, unofficial].
5.  **Optimize Layers:**
    *   Crop empty space from each layer image to reduce memory and rendering cost [S1, unofficial].
    *   Omit layers entirely if they contain no voxels [S1, unofficial].
6.  **Render:**
    *   For each layer in the stack, from bottom (lowest Y) to top (highest Y):
        *   Apply vertical scaling to the layer image. The scale factor $S_y$ is determined by the camera pitch angle $\theta$. Scaling down vertically ($S_y < 1$) simulates a camera looking towards the horizon [S1, unofficial].
        *   Apply horizontal rotation to the layer image around the vertical axis to simulate camera yaw [S1, unofficial].
        *   Draw the transformed layer image onto the screen [S1, unofficial].

    """
    Returns a pre-shaded color for a voxel at (x, y, z) if it exists in the shape.
    """
    if not shape.bounding_box.contains(x, y, z):
        return None
    
    voxel = shape.sample(x, y, z)
    if voxel is None:
        return None
    
    # Calculate normal of the nearest surface
    normal = shape.get_surface_normal(x, y, z)

def create_layers(shapes, scene_bounds, voxel_density):

    """
    min_y, max_y = scene_bounds.y_min, scene_bounds.y_max
    min_x, max_x = scene_bounds.x_min, scene_bounds.x_max
    min_z, max_z = scene_bounds.z_min, scene_bounds.z_max
    
    layers = []
    
    for y in range(min_y, max_y + 1):
        # Create a 2D image for this layer (X-Z plane)
        width = max_x - min_x + 1
        height = max_z - min_z + 1
        layer_image = create_empty_image(width, height)

            for z in range(min_z, max_z + 1):

                if is_omitted_by_density(voxel_density):
                    continue

                color = None
                for shape in shapes:
                    c = pre_shade_shape(shape, x, y, z)
                    if c is not None:
                        color = c
                        break # Assume first hit or overwrite logic
                
                if color is not None:
                    layer_image.set_pixel(x - min_x, z - min_z, color)
        
        # Crop empty space
        layer_image = crop_layer(layer_image)
        
        # Omit empty layers
        if layer_image.has_voxels():
            layers.append(layer_image)
            
    return layers

def render_layers(layers, camera_pitch, camera_yaw):
    """
    Renders the layers from bottom to top with transformations.
    """
    screen = create_screen()
    
    # Sort layers by Y (bottom to top)
    layers.sort(key=lambda l: l.y_coordinate)
    
    for layer in layers:
        # Vertical scaling based on camera pitch
        # Scaling down points camera towards horizon
        scale_y = calculate_vertical_scale(camera_pitch)

        rotation_matrix = calculate_rotation_matrix(camera_yaw, axis='y')

### Parameters
*   **Voxel Density:** A value between 0 and 1. Lower values omit more voxels, creating porous effects suitable for plants and trees [S1, unofficial].
*   **Camera Pitch:** Controls the vertical scaling factor of the layers. A horizontal pitch (looking at the horizon) requires significant vertical scaling down [S1, unofficial].
*   **Camera Yaw:** Controls the rotation of the layers around the vertical axis [S1, unofficial].

### Pitfalls and Edge Cases
*   **Camera Pitch Limit:** If the camera is pitched too far horizontally, the vertical scaling becomes extreme, causing users to see "under" the layers. This reveals voxels that should be occluded, creating messy visual artifacts [S1, unofficial].
*   **Dynamic Objects:** Since layers are pre-rendered, dynamic objects require a separate rendering pass. Large moving objects can cause performance bottlenecks [S1, unofficial]. A depth buffer can be used to insert dynamic objects as traditional 3D models after the voxel layers are rendered [S1, unofficial].
*   **Occlusion Artifacts:** If occluded voxels are not pre-shaded with their nearest surface normal, they may appear incorrectly lit when they peek between layers [S1, unofficial].

## Operating characteristics
*   **Time Complexity:** Pre-processing is $O(V \cdot S)$, where $V$ is the number of voxels in the bounding box and $S$ is the number of shapes. Rendering is $O(L)$, where $L$ is the number of layers, as it involves simple 2D image draws [S1, unofficial].
*   **Memory Complexity:** $O(V)$ to store the pre-shaded voxel colors in the layer images. This can be optimized by cropping empty space and omitting empty layers [S1, unofficial].
*   **Performance:** Faster than real-time ray marching for static scenes because shading is done offline. Slower than traditional triangle-based rendering for dynamic scenes due to the need for pre-rendering and potential depth buffer management [S1, unofficial].
*   **Strengths:** Real-time rendering of static voxel scenes; compact storage if empty space is cropped; lighting model does not require normal calculation during rendering [S1, unofficial].
*   **Limitations:** Poor handling of dynamic objects; limited camera pitch range; higher storage requirements than triangle meshes for dense scenes [S1, unofficial].

## Background
Layered Voxel Rendering was proposed by Job Talle in 2019 as a method for real-time voxel rendering in web-based environments (JavaScript/Three.js) [S1, unofficial]. It addresses the high storage and rendering costs associated with traditional voxel representations by leveraging 2D image compositing [S1, unofficial].
