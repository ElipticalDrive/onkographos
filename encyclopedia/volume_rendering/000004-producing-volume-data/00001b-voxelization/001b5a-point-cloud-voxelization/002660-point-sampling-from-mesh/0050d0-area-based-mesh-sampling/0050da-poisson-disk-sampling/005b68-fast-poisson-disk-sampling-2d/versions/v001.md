# Fast Poisson Disk Sampling (2D)

Also called: Bridson algorithm, FPDS, Grid-based Poisson Disk Sampling, Poisson Disk Sampling (Grid-based), Poisson sampling

## Overview
Fast Poisson Disk Sampling (2D) is a point sampling algorithm that generates a set of points within a given 2D domain such that the minimum distance between any two points is at least `r` [S1, unofficial]. It solves the problem of uniformly distributing points with blue-noise properties to reduce aliasing in rendering and simulation [S1, unofficial]. It sets itself apart from naive rejection sampling by using a spatial grid to accelerate neighbor checks and an active list to manage the search process, achieving linear time complexity relative to the number of samples [S1, unofficial].

## How it works
**Inputs and Outputs:**
- **Input:** A 2D domain defined by width $W$ and height $H$, a minimum separation distance $r$, and a maximum number of candidate attempts $k$ (default 30) [S1, unofficial].
- **Output:** A list of valid sample points `point_list` and the grid structure used for validation [S1, unofficial].

**Data Structures:**
1.  **Grid:** A 2D array of integers representing cells.
    -   `cell_size`: The side length of each square cell, calculated as $r / \sqrt{2.0}$ [S1, unofficial].
    -   `grid_width`: $\lceil W / \text{cell\_size} \rceil$ [S1, unofficial].
    -   `grid_height`: $\lceil H / \text{cell\_size} \rceil$ [S1, unofficial].
    -   `grid_data`: A 1D vector of size `grid_width * grid_height`, initialized to `NO_SAMPLE` (-1) [S1, unofficial].
    -   Indexing: Cell $(x, y)$ maps to `grid_data[x + grid_width * y]` [S1, unofficial].
2.  **point_list:** A list storing the world coordinates (2D vectors) of all valid samples [S1, unofficial].
3.  **active_list:** A list storing indices into `point_list` for points that are still being processed to find neighbors [S1, unofficial].

**Parameters:**
-   `r`: Minimum separation distance between samples [S1, unofficial].
-   `k`: Maximum number of candidate points to test around each active sample before rejection; default is 30 [S1, unofficial].

**Algorithm Steps:**
1.  **Initialize Grid:** Calculate `cell_size`, `grid_width`, and `grid_height`. Allocate `grid_data` and fill with `NO_SAMPLE` (-1) [S1, unofficial].
2.  **Seed Sample:** Generate a random point $P_0$ uniformly within the domain bounds $[0, W] \times [0, H]$ [S1, unofficial].
3.  **Seed Processing:**
    -   Convert $P_0$ to grid coordinates $(gx, gy)$ [S1, unofficial].
    -   Set `grid_data[gx + grid_width * gy]` to the index of $P_0$ (initially 0) [S1, unofficial].
    -   Append $P_0$ to `point_list` [S1, unofficial].
    -   Append index 0 to `active_list` [S1, unofficial].
4.  **Sampling Loop:** While `active_list` is not empty:
    -   Pick a random index $i$ from `active_list` [S1, unofficial].
    -   Let $P$ be `point_list[i]` [S1, unofficial].
    -   Set `found_sample = false` [S1, unofficial].
    -   **Candidate Generation:** Loop $j$ from 0 to $k-1$:
        -   Generate a random angle $\theta \in [0, 2\pi]$ and a random radius $\rho \in [r, 2r]$ [S1, unofficial].
        -   Compute candidate coordinates:
            $$
            \begin{aligned}
            x_c &= P.x + \rho \cos(\theta) \\
            y_c &= P.y + \rho \sin(\theta)
            \end{aligned}
            $$
        -   **Boundary Check:** If $x_c < 0$ or $x_c \ge W$ or $y_c < 0$ or $y_c \ge H$, continue to the next candidate [S1, unofficial].
        -   **Grid Lookup:** Convert $(x_c, y_c)$ to grid coordinates $(gx_c, gy_c)$ [S1, unofficial].
        -   **Occupancy Check:** If `grid_data[gx_c + grid_width * gy_c]` is not `NO_SAMPLE`, continue to the next candidate [S1, unofficial].
        -   **Neighborhood Check:** Iterate over all 8 adjacent cells in the 3x3 neighborhood centered at $(gx_c, gy_c)$ (excluding the center cell itself) [S1, unofficial]. For each occupied neighbor cell:
            -   Retrieve the sample index $idx$ from the grid cell [S1, unofficial].
            -   Retrieve the sample point $S$ from `point_list[idx]` [S1, unofficial].
            -   Calculate the Euclidean distance $d$ between $S$ and $(x_c, y_c)$ [S1, unofficial].
            -   If $d < r$, the candidate is invalid. Set `valid_sample = false` and break the neighborhood check [S1, unofficial].
        -   If the candidate passed all checks:
            -   Set `valid_sample = true` [S1, unofficial].
            -   Record the candidate in the grid: `grid_data[gx_c + grid_width * gy_c] = current_sample_index` [S1, unofficial].
            -   Append $(x_c, y_c)$ to `point_list` [S1, unofficial].
            -   Append `current_sample_index` to `active_list` [S1, unofficial].
            -   Increment `current_sample_index` [S1, unofficial].
            -   Set `found_sample = true` [S1, unofficial].
            -   Break the candidate generation loop [S1, unofficial].
    -   If `found_sample` is false, remove index $i$ from `active_list` [S1, unofficial].

**Pseudocode:**

```python
import math
import random

def fast_poisson_disk_sampling_2d(width, height, r, k=30):
    # 1. Initialize Grid
    cell_size = r / math.sqrt(2.0)
    grid_width = math.ceil(width / cell_size)
    grid_height = math.ceil(height / cell_size)
    grid_data = [-1] * (grid_width * grid_height)
    
    point_list = []
    active_list = []
    sample_index = 0
    
    # Helper to convert world to grid
    def world_to_grid(x, y):
        gx = int(x / cell_size)
        gy = int(y / cell_size)
        return gx, gy

    # Helper to check distance
    def dist_sq(p1, p2):
        return (p1[0] - p2[0])**2 + (p1[1] - p2[1])**2

    # 2. Seed Sample
    x0 = random.uniform(0, width)
    y0 = random.uniform(0, height)
    point_list.append((x0, y0))
    
    gx0, gy0 = world_to_grid(x0, y0)
    grid_data[gx0 + grid_width * gy0] = sample_index
    active_list.append(sample_index)
    sample_index += 1
    
    # 4. Sampling Loop
    while active_list:
        # Pick random index from active list
        idx = random.choice(active_list)
        p = point_list[idx]
        found_sample = False
        
        # Candidate Generation
        for _ in range(k):
            # Generate random angle and radius
            theta = random.uniform(0, 2 * math.pi)
            rho = random.uniform(r, 2 * r)
            
            # Compute candidate
            xc = p[0] + rho * math.cos(theta)
            yc = p[1] + rho * math.sin(theta)
            
            # Boundary Check
            if xc < 0 or xc >= width or yc < 0 or yc >= height:
                continue
            
            # Grid Lookup
            gxc, gyc = world_to_grid(xc, yc)
            
            # Occupancy Check
            if grid_data[gxc + grid_width * gyc] != -1:
                continue
            
            # Neighborhood Check
            valid_sample = True
            # Iterate 3x3 neighborhood excluding center
            for dx in [-1, 0, 1]:
                for dy in [-1, 0, 1]:
                    if dx == 0 and dy == 0:
                        continue
                    
                    nx = gxc + dx
                    ny = gyc + dy
                    
                    # Check bounds for neighbor cells
                    if nx < 0 or nx >= grid_width or ny < 0 or ny >= grid_height:
                        continue
                        
                    neighbor_idx = grid_data[nx + grid_width * ny]
                    if neighbor_idx != -1:
                        neighbor_point = point_list[neighbor_idx]
                        if dist_sq(neighbor_point, (xc, yc)) < r * r:
                            valid_sample = False
                            break
                if not valid_sample:
                    break
            
            if valid_sample:
                # Record candidate
                grid_data[gxc + grid_width * gyc] = sample_index
                point_list.append((xc, yc))
                active_list.append(sample_index)
                sample_index += 1
                found_sample = True
                break
        
        if not found_sample:
            # Remove from active list
            active_list.remove(idx)
            
    return point_list
```

**Edge Cases and Pitfalls:**
-   **Boundary Conditions:** Candidate points falling outside the domain bounds are discarded immediately to prevent out-of-bounds memory access or invalid sampling [S1, unofficial].
-   **Grid Bounds:** Test points pushed out of grid bounds during neighbor checks must be skipped [S1, unofficial].
-   **Duplicates:** Grid cells already containing samples are skipped to avoid duplicates [S1, unofficial].
-   **Proximity:** Samples too close to existing neighbors (distance < r) are rejected [S1, unofficial].

## Operating characteristics
-   **Time Complexity:** $O(N)$ where $N$ is the number of samples, due to the constant-time grid lookups and bounded neighborhood checks [S1, unofficial].
-   **Memory Complexity:** $O(W \cdot H / r^2)$ for the grid storage, proportional to the area divided by the cell area [S1, unofficial].
-   **Strengths:** Fast generation, uniform distribution, blue noise spectrum [S1, unofficial].
-   **Limitations:** Requires a defined domain; performance degrades if $r$ is very small relative to the domain size due to grid overhead [S1, unofficial].
-   **When to use:** When uniform point distribution with a minimum separation distance is required for texture generation, cloud rendering, or voxelization [S1, unofficial].
-   **When not to use:** When points must lie exactly on a complex surface geometry without projection artifacts, or when the domain is not a simple rectangle [S1, unofficial].

## Background
The algorithm is based on the work by Robert Bridson, titled "Fast Poisson Disk Sampling in Arbitrary Dimensions," presented at SIGGRAPH 2007 [S1, unofficial]. It is widely used in computer graphics for generating blue noise patterns, such as in the Nubis cloud system from Horizon Zero Dawn by Guerrilla Games [S1, unofficial].
