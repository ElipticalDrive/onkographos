# Area-Based Mesh Sampling
Also called: Area-Based sampling
## Overview
Area-Based Mesh Sampling is a point cloud generation method where the number of sampled points per triangle is proportional to the triangle's area, determined by a surface density parameter [S1]. It differs from uniform sampling by respecting geometric scale and from KD-Tree guided sampling by relying solely on area metrics rather than spatial distribution constraints [S1, 4715-kd-tree-guided-point-cloud-sampling.md].
## How it works
**Inputs:** A triangle mesh (list of vertices and faces), a surface density parameter $\rho$ (points per square unit).
**Outputs:** A set of 3D points sampled on the mesh surface.

**Data Structures:**
- Triangle: Defined by vertices $v_0, v_1, v_2$.
- Point: 3D coordinate $(x, y, z)$.

**Steps:**
1. For each triangle $T$ in the mesh:
   a. Calculate the area $A_T$ of the triangle.
   b. Calculate the required number of points $m$ for this triangle:
      $$m = A_T \times \rho$$
   c. Determine the integer count $k = \lfloor m \rfloor$.
   d. Sample $k$ points uniformly within the triangle.
   e. Let $f = m - k$ be the fractional part.
   f. Generate a random number $r \in [0, 1)$.
   g. If $r < f$, sample one additional point uniformly within the triangle and add it to the output set [S1].

**Pseudocode:**
```python
import random
import math

def sample_triangle_uniform(v0, v1, v2):
    """Sample one point uniformly on a triangle defined by vertices v0, v1, v2."""
    r1 = random.random()
    r2 = random.random()
    # Ensure uniform distribution using sqrt for the second barycentric coordinate
    if r1 + r2 > 1:
        r1 = 1 - r1
        r2 = 1 - r2
    # Barycentric coordinates
    u = r1
    v = r2
    w = 1 - u - v
    return w * v0 + u * v1 + v * v2

def area_based_mesh_sampling(mesh_vertices, mesh_faces, density):
    """
    mesh_vertices: list of [x, y, z]
    mesh_faces: list of [i0, i1, i2] indices
    density: float, points per unit area
    """
    points = []
    
    for face in mesh_faces:
        v0 = mesh_vertices[face[0]]
        v1 = mesh_vertices[face[1]]
        v2 = mesh_vertices[face[2]]
        
        # Calculate triangle area
        # Vector cross product magnitude / 2
        ax, ay, az = v1[0]-v0[0], v1[1]-v0[1], v1[2]-v0[2]
        bx, by, bz = v2[0]-v0[0], v2[1]-v0[1], v2[2]-v0[2]
        
        cross_x = ay * bz - az * by
        cross_y = az * bx - ax * bz
        cross_z = ax * by - ay * bx
        
        area = 0.5 * math.sqrt(cross_x**2 + cross_y**2 + cross_z**2)
        
        # Calculate required points
        m = area * density
        k = int(math.floor(m))
        fractional_part = m - k
        
        # Sample integer part
        for _ in range(k):
            points.append(sample_triangle_uniform(v0, v1, v2))
            
        # Sample fractional part with probability
        if random.random() < fractional_part:
            points.append(sample_triangle_uniform(v0, v1, v2))
            
    return points
```

**Parameters:**
- $\rho$: Surface density. Typical values depend on the target voxel resolution or desired point cloud density [S1].

**Edge Cases:**
- Zero-area triangles (degenerate): $m=0$, no points sampled.
- Very small triangles: $m < 1$, sampled with probability $m$.
- Precision: Floating point errors in area calculation may affect $m$ slightly [S1].

## Subtopics

### Poisson Disk Sampling
A surface sampling method that uniformly distributes points on a mesh's surface with a minimum geodesic distance constraint of $2r$ between them, given a disk of radius $r$ [S1]. It utilizes blue noise properties to reduce aliasing effects in later processing steps [S1]. Unlike Area-Based sampling, it enforces spatial regularity rather than area proportionality.

## Operating characteristics
- **Time Complexity:** Linear with respect to the number of triangles, $O(N)$, where $N$ is the number of faces. Each triangle is processed independently [S1].
- **Memory Complexity:** Linear with respect to the number of output points.
- **Strengths:** Simple to implement; ensures denser sampling on larger geometric features [S1].
- **Limitations:** Does not guarantee uniform spatial distribution or minimum distance between points, potentially leading to clustering in large triangles [S1].
- **When to use:** When area-proportional sampling is sufficient and computational simplicity is preferred over spatial uniformity [S1].
- **When not to use:** When aliasing reduction via blue noise properties is required (use Poisson Disk Sampling instead) [S1].

## Background
Originating from comparative assessments of implicit and explicit plenoptic scene representations, this method is used to discretize meshes directly into voxel volumes or point clouds [S1]. It is cited as one of several methods for generating point clouds from mesh geometry, specifically noted for its dependency on triangle area [S1].
