# Point Cloud Normalization

## Overview
Point Cloud Normalization standardizes the spatial distribution of 3D points to a canonical coordinate system and scale for downstream voxelization or neural rendering pipelines [S1, unofficial]. It differs from simple bounding-box normalization by offering multiple scaling strategies (average distance, max coordinate, or warp-based) to handle varying point densities and shapes [S1, unofficial]. This method prepares ground truth data for KD-Tree guided sampling by centering objects and constraining their extent [Parent](4715-kd-tree-guided-point-cloud-sampling.md).

## How it works
**Inputs:**
- `pts1`: Array of shape $(N_1, 3)$ containing $x, y, z$ coordinates.
- `pts2`: Optional array of shape $(N_2, 3)$ (e.g., for paired data or augmentation).
- `norm_mode`: String specifying normalization strategy. Format: `<norm_type>-<dist_type>` or just `<norm_type>` [S1, unofficial].

**Outputs:**
- Normalized `pts1` and `pts2` (if present), scaled and centered [S1, unofficial].

**Data Structures:**
- Points are stored as float32 arrays.
- Masks for valid points are used to handle invalid entries (converted to zeros before mean calculation) [S1, unofficial].

**Steps:**

1. **Handle Invalid Points:**
   Identify invalid points in `pts1` and `pts2` using valid masks. Convert invalid points to zeros using valid masks if `norm_mode` is `'avg'` [S1, unofficial].

2. **Centering (Translation):**
   Calculate the mean of x, y, and z coordinates for each point cloud: `x_mean = point_cloud[:, 0].mean()`, `y_mean = point_cloud[:, 1].mean()`, `z_mean = point_cloud[:, 2].mean()` [S2, unofficial]. Subtract the mean from each coordinate: `point_cloud[:, 0] -= x_mean`, `point_cloud[:, 1] -= y_mean`, `point_cloud[:, 2] -= z_mean` [S1, unofficial].

3. **Global Statistics (if `norm_mode` is `'avg'`):**
   Concatenate `pts1` and `pts2` (if present) into `all_pts` [S1, unofficial]. Compute distance to origin: $all\_dis = \|all\_pts\|$ [S1, unofficial].

4. **Distance Transformation (if `dis_mode` is `'log1p'`):**
   Transform distances: $all\_dis = \log(1 + all\_dis)$ [S1, unofficial].

5. **Scaling:**
   Find the maximum absolute value in the normalized coordinates: `max_value = point_cloud[:, :3].max()` [S2, unofficial]. Scale the coordinates by dividing by `max_value * 2` [S2, unofficial].

6. **Warp Transformation (if `dis_mode` is `'warp-log1p'`):**
   Compute warp factor $warp\_factor = \frac{\log(1 + all\_dis)}{\max(10^{-8}, all\_dis)}$ [S1, unofficial]. Apply warp to `pts1` and `pts2` [S1, unofficial]. Translate the coordinates by adding 0.5 to center the object in the $[0.5, 1.5]$ range [S2, unofficial].

7. **Normalization Factor (if `norm_mode` is `'avg'`):**
   Compute norm factor: $norm\_factor = \frac{\sum all\_dis}{nnz1 + nnz2 + 10^{-8}}$ [S1, unofficial].

**Pseudocode:**

```python
import numpy as np

def normalize_pointcloud(pts1, pts2=None, norm_mode='avg'):
    """
    Normalize point clouds based on norm_mode.
    
    Args:
        pts1: np.ndarray of shape (N, 3)
        pts2: np.ndarray of shape (M, 3) or None
        norm_mode: str, e.g., 'avg', 'avg-dis', 'avg-log1p', 'avg-warp-log1p'
        
    Returns:
        normalized_pts1, normalized_pts2 (if provided), norm_factor (if avg mode)
    """
    # Parse mode
    if '-' in norm_mode:
        norm_type, dis_type = norm_mode.split('-')
    else:
        norm_type = norm_mode
        dis_type = 'dis'
        
    # Step 1: Handle invalid points (convert to zeros using valid masks)
    valid_mask1 = np.isfinite(pts1).all(axis=1)
    pts1[~valid_mask1] = 0.0
    if pts2 is not None:
        valid_mask2 = np.isfinite(pts2).all(axis=1)
        pts2[~valid_mask2] = 0.0
    else:
        valid_mask2 = np.ones(pts2.shape[0], dtype=bool) if pts2 is not None else np.array([])

    # Step 2: Centering
    x_mean1, y_mean1, z_mean1 = np.mean(pts1[:, 0]), np.mean(pts1[:, 1]), np.mean(pts1[:, 2])
    pts1[:, 0] -= x_mean1
    pts1[:, 1] -= y_mean1
    pts1[:, 2] -= z_mean1
    
    if pts2 is not None:
        x_mean2, y_mean2, z_mean2 = np.mean(pts2[:, 0]), np.mean(pts2[:, 1]), np.mean(pts2[:, 2])
        pts2[:, 0] -= x_mean2
        pts2[:, 1] -= y_mean2
        pts2[:, 2] -= z_mean2

    # Step 3: Global Statistics (if norm_type is 'avg')
    if norm_type == 'avg':
        all_pts = np.concatenate([pts1, pts2], axis=0) if pts2 is not None else pts1
        all_dis = np.linalg.norm(all_pts, axis=1)

        # Step 4: Distance Transformation
        if dis_type == 'log1p':
            all_dis = np.log1p(all_dis)

        # Step 5: Scaling
        max_value = np.max(np.abs(all_pts))
        scale_factor = max_value * 2
        pts1 /= scale_factor
        if pts2 is not None:
            pts2 /= scale_factor

        # Step 6: Warp Transformation
        if dis_type == 'warp-log1p':
            warp_factor = np.log1p(all_dis) / np.maximum(1e-8, all_dis)
            pts1 = pts1 * warp_factor[:len(pts1)].reshape(-1, 1)
            pts2 = pts2 * warp_factor[len(pts1):].reshape(-1, 1)
            pts1 += 0.5
            pts2 += 0.5
            return pts1, pts2

        # Step 7: Normalization Factor
        nnz1 = np.sum(valid_mask1)
        nnz2 = np.sum(valid_mask2) if pts2 is not None else 0
        norm_factor = np.sum(all_dis) / (nnz1 + nnz2 + 1e-8)
        return pts1, pts2, norm_factor
    else:
        return pts1, pts2
```

**Parameters:**
- `norm_mode`: String split into `norm_mode` and `dis_mode`. Options for `dis_mode`: `'dis'`, `'log1p'`, `'warp-log1p'` [S1, unofficial]. Default: `'avg'` [S1, unofficial].

**Edge Cases:**
- **Division by Zero:** When computing `warp_factor`, if `all_dis` is 0, use $\max(10^{-8}, all\_dis)$ to prevent division by zero [S1, unofficial].
- **Invalid Points:** Points with NaN or Inf values must be handled (converted to 0) before mean calculation to avoid propagating invalid statistics [S1, unofficial].

## Subtopics

### Principal Axes Alignment
Computes a 4x4 SE(3) transform that aligns a point cloud to its principal axes of covariance, centering it at the median [S3, unofficial]. It computes the centroid as the median of the point cloud, translates the cloud to the centroid, computes the covariance matrix, and extracts eigenvectors [S3, unofficial]. Eigenvectors are sorted by eigenvalues in descending order so the z-axis corresponds to the principal axis with the smallest eigenvalue [S3, unofficial]. A rotation matrix is formed from the eigenvectors, and an SE(3) transform is constructed [S3, unofficial]. If the determinant of the eigenvector matrix is negative, the sign of the first eigenvector is flipped to ensure a right-handed coordinate system [S3, unofficial].

## Operating characteristics
- **Time Complexity:** $O(N)$ for mean and distance calculations, $O(N)$ for covariance matrix computation (if used in variants), $O(1)$ for eigendecomposition of a 3x3 matrix [S3, unofficial]. Overall linear with respect to the number of points $N$ [S3, unofficial].
- **Memory Complexity:** $O(N)$ to store the point cloud and intermediate arrays [S3, unofficial].
- **Strengths:** Robust to scale variations; `warp-log1p` handles sparse or dense regions differently, potentially preserving local structure better than uniform scaling [S1, unofficial].
- **Limitations:** `avg` mode assumes a roughly symmetric distribution around the mean. `warp-log1p` is more complex and may introduce non-linear distortions [S1, unofficial].
- **When to use:** When preparing point clouds for voxelization or neural rendering where consistent scale and centering are critical [S1, unofficial]. Use `warp-log1p` if the point cloud has significant variation in density or extent [S1, unofficial].

## Background
Originating from implementations in neural rendering pipelines like InstantSplat and mrGSplat, point cloud normalization is a standard preprocessing step [S1, S3, unofficial]. It ensures that input data is in a canonical space, facilitating stable training and evaluation of 3D reconstruction models [S1, unofficial]. The specific variants (`avg`, `log1p`, `warp-log1p`) are designed to handle different statistical properties of the input point clouds [S1, unofficial].
