# KD-Tree Guided Point Cloud Sampling

Also called: sigma-based point cloud augmentation

## Overview
This method augments ground truth point clouds by generating samples near the original points, where the noise magnitude is scaled by local point density estimated via KD-tree nearest neighbor distances. It solves the problem of sparse or unevenly distributed input points by creating a denser, noise-perturbed dataset for downstream voxelization or rendering tasks. It differs from uniform sampling by adapting noise to local geometry density, ensuring samples cluster more tightly in sparse regions and spread out in dense regions.

## How it works
**Inputs:** Ground truth point cloud (file: `.ply`, `.xyz`, or `.npy`).
**Outputs:** `.npz` file containing three arrays:
- `sample`: Augmented points.
- `point`: Original ground truth points.
- `sample_near`: For each sample, the index of the nearest ground truth point.

**Data Structures:**
- Point cloud: Array of shape $(N, 3)$, dtype `float32` or `float64`.
- KD-tree: Spatial index structure built on ground truth points for nearest neighbor queries.

**Parameters:**
- `K`: Number of nearest neighbors to query. Default: 51.
- `CHUNK_SIZE`: Number of points processed per KD-tree query to manage memory. Default: 100 (chunks of 60 points? We will implement a batched approach.
- `QUERY_EACH`: Number of augmentation passes. Calculated as `1000000 // POINT_NUM_GT` if `POINT_NUM_GT <= 1000000`, else `1`.
- `MAX_POINTS`: Limit for `QUERY_EACH` calculation. Default: 1,000,000.

**Steps:**
1. **Load and Normalize:**
   - Load the point cloud $P_{gt}$ of size $N$.
   - Compute center $C = \text{mean}(P_{gt})$.
   - Compute max dimension $D = \max(\text{max}(P_{gt}) - \text{min}(P_{gt}))$.
   - Normalize: $P_{norm} = (P_{gt} - C) / D$. This maps points to a unit cube.

2. **Build KD-Tree:**
   - Construct a KD-tree from $P_{norm}$.

3. **Calculate Local Sigma:**
   - For each point $p_i \in P_{norm}$, query the KD-tree for the $K=51$ nearest neighbors.
   - Let $d_{50}$ be the distance to the 50th nearest neighbor (index 50 in the sorted list of distances, assuming 0-indexed and excluding the point itself if it returns itself as the 1st neighbor).
   - Set $\sigma_i = d_{50}$.

4. **Generate Augmented Samples:**
   - Calculate `QUERY_EACH` = $\min(1, \lfloor 1,000,000 / N \rfloor)$ if $N > 1,000,000$ else $\lfloor 1,000,000 / N \rfloor$.
   - Initialize empty list `samples`.
   - For `pass` in range(`QUERY_EACH`):
     - For each point $p_i$ in $P_{norm}$:
       - Generate noise $\epsilon \sim \mathcal{N}(0, 1)$ with shape $(3,)$.
       - Compute sample: $p_{sample} = p_i + \sigma_i \cdot \epsilon$.
       - Add $p_{sample}$ to `samples`.
   - Note: The source mentions splitting into chunks of 60. This likely applies to the iteration over points to manage memory during the noise generation or KD-tree query if done in batches. We will iterate in batches of 60 points.

5. **Find Nearest Ground Truth Points:**
   - For each $p_{sample}$ in `samples`, query the KD-tree for the nearest neighbor in $P_{norm}$.
   - Store the index of the nearest ground truth point in `sample_near`.

6. **Save Output:**
   - Save `sample`, `point` (original $P_{norm}$), and `sample_near` to an `.npz` file.

**Formula:**
$$ p_{\text{sample}} = p_{\text{point}} + \sigma \cdot \mathcal{N}(0, 1) $$
Where:
- $p_{\text{sample}}$ is the augmented point.
- $p_{\text{point}}$ is the original ground truth point.
- $\sigma$ is the distance to the 50th nearest neighbor of $p_{\text{point}}$.
- $\mathcal{N}(0, 1)$ is a random vector drawn from a standard normal distribution.

**Pitfalls:**
- **Memory Overflow:** KD-tree queries for large point clouds can exceed memory. Split the point cloud into chunks (e.g., 100 chunks or 60 points per batch) when querying neighbors.
- **Precision:** Use `float32` for storage but `float64` for intermediate calculations if high precision is needed, though the source uses `float32` for the final output.
- **Boundary Conditions:** Normalization to unit cube ensures points are within $[-0.5, 0.5]$ or $[0, 1]$ depending on implementation. Ensure consistent coordinate system.

**Pseudocode:**
```python
import numpy as np
from scipy.spatial import KDTree

def kd_tree_guided_sampling(point_cloud_path, output_path, k_neighbors=51, chunk_size=60):
    # 1. Load point cloud
    # Assume loader returns (N, 3) array
    points = load_point_cloud(point_cloud_path)
    N = points.shape[0]
    
    # 2. Normalize to unit cube
    center = np.mean(points, axis=0)
    max_dim = np.max(np.ptp(points, axis=0)) # ptp = max - min
    points_norm = (points - center) / max_dim
    
    # 3. Build KD-tree
    tree = KDTree(points_norm)
    
    # 4. Calculate local sigma (distance to 50th nearest neighbor)
    # Query all points at once if memory allows, or in chunks
    # Source says "KD-tree query is split into 100 chunks"
    # We will split the points into chunks for querying
    num_chunks = 100
    chunk_size_points = N // num_chunks
    if chunk_size_points == 0:
        chunk_size_points = N
        
    sigma = np.zeros(N, dtype=np.float32)
    
    for i in range(0, N, chunk_size_points):
        end = min(i + chunk_size_points, N)
        indices = np.arange(i, end)
        # Query k_neighbors + 1 to include the point itself if it's the nearest
        # Usually KDTree returns the point itself as the first neighbor
        distances, _ = tree.query(points_norm[indices], k=k_neighbors + 1)
        # Distance to 50th neighbor (index 50 in 0-indexed list of k_neighbors+1 neighbors)
        # If k_neighbors=51, we get 52 neighbors. The 50th neighbor is at index 50.
        sigma[i:end] = distances[:, k_neighbors].astype(np.float32)
        
    # 5. Generate augmented samples
    # QUERY_EACH calculation
    if N > 1000000:
        query_each = 1
    else:
        query_each = 1000000 // N
        
    samples = []
    sample_near_indices = []
    
    # Process in chunks of 60 points for noise generation
    for _ in range(query_each):
        for i in range(0, N, chunk_size):
            end = min(i + chunk_size, N)
            batch_points = points_norm[i:end]
            batch_sigma = sigma[i:end]
            
            # Generate noise
            noise = np.random.normal(0, 1, size=(end - i, 3)).astype(np.float32)
            
            # Augment
            batch_samples = batch_points + batch_sigma[:, np.newaxis] * noise
            
            # Find nearest ground truth point for each sample
            # Query the KD-tree for the nearest neighbor
            _, nearest_indices = tree.query(batch_samples, k=1)
            
            samples.append(batch_samples)
            sample_near_indices.append(nearest_indices)
            
    samples = np.vstack(samples)
    sample_near_indices = np.concatenate(sample_near_indices)
    
    # 6. Save output
    np.savez(output_path, 
             sample=samples, 
             point=points_norm, 
             sample_near=sample_near_indices)

```

## Subtopics

### [Point Cloud Normalization](7023-point-cloud-normalization.md)
Point Cloud Normalization standardizes the spatial distribution of 3D points to a canonical coordinate system, ensuring consistent scale and centering for downstream voxelization or rendering tasks. It differs from simple bounding-box normalization by offering multiple distance-based scaling modes ('dis', 'log1p', 'warp-log1p') to handle varying point densities and outlier sensitivity.

## Operating characteristics
- **Time Complexity:** $O(N \log N)$ for building the KD-tree, $O(N \cdot K \log N)$ for querying neighbors, where $N$ is the number of points and $K$ is the number of neighbors.
- **Memory Complexity:** $O(N)$ for storing points and sigma values. The KD-tree itself takes $O(N)$ space.
- **Performance:** Efficient for point clouds up to a few million points, provided memory is managed via chunking.
- **Strengths:** Adapts to local density, providing more samples in sparse regions.
- **Limitations:** Computationally expensive for very large point clouds due to KD-tree queries. Sensitive to the choice of $K$.
