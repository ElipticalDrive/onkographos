# Statistical Outlier Removal

Also called: Open3D Statistical Outlier Removal, Outlier Vertex Removal, Outlier Vertex Removal and Poisson Surface Reconstruction

## Overview
Statistical Outlier Removal identifies and removes outlier vertices in a point cloud based on their proximity to other vertices [S1, unofficial]. It solves the problem of unwanted points (e.g., backgrounds or floors) being incorporated into generated meshes during point cloud to mesh conversion [S1, unofficial]. Unlike sibling methods that rely on learned opacity or fixed distance metrics, this method leverages local neighborhood density statistics [Parent](8464-point-cloud-filtering-and-noise-removal.md).

## How it works
**Inputs:** A point cloud $P = \{p_1, p_2, ..., p_N\}$ where each $p_i \in \mathbb{R}^3$.
**Outputs:** A cleaned point cloud $P_{clean} \subset P$.
**Parameters:**
- $k$: Number of nearest neighbors to consider for statistical analysis. Not given in the sources.
- $\mu_{threshold}$: Mean distance threshold multiplier. Not given in the sources.
- $\sigma_{threshold}$: Standard deviation threshold for outlier removal. Determined heuristically via experimentation [S1, unofficial].

**Data Structures:**
- Adjacency list or k-d tree for efficient nearest neighbor search.
- Array of distances $D$ of size $N$.

**Steps:**
1. For each point $p_i \in P$:
   a. Find the $k$ nearest neighbors of $p_i$ in $P$.
   b. Calculate the mean distance $\bar{d}_i$ from $p_i$ to its $k$ neighbors.
   c. Store $\bar{d}_i$ in $D[i]$.
2. Calculate the global mean $\mu_D$ and standard deviation $\sigma_D$ of all values in $D$.
3. Identify outliers: A point $p_i$ is an outlier if $\bar{d}_i > \mu_D + \sigma_{threshold} \cdot \sigma_D$.
4. Remove all identified outliers from $P$ to form $P_{clean}$.
5. [G] Apply Poisson surface reconstruction to $P_{clean}$ to generate a mesh [S1, unofficial].
6. [G] Remove mesh parts with density lower than a certain quantile to acquire the final 3D mesh [S1, unofficial].

**Pseudocode:**
```python
def statistical_outlier_removal(points, k, sigma_threshold):
    """
    points: List of 3D coordinates (N, 3)
    k: Number of nearest neighbors
    sigma_threshold: Standard deviation threshold multiplier
    Returns: Cleaned points list
    """
    import numpy as np
    from scipy.spatial import KDTree
    
    # Build KD-tree for efficient neighbor search
    tree = KDTree(points)
    
    # Calculate mean distance to k nearest neighbors for each point
    # Query k+1 neighbors because the first is the point itself
    distances, indices = tree.query(points, k=k+1)
    
    # Exclude the point itself (distance 0) and calculate mean of remaining k neighbors
    # distances shape: (N, k+1)
    neighbor_distances = distances[:, 1:]  # Shape: (N, k)
    mean_distances = np.mean(neighbor_distances, axis=1)  # Shape: (N,)
    
    # Calculate global statistics
    mu_D = np.mean(mean_distances)
    sigma_D = np.std(mean_distances)
    
    # Identify outliers based on threshold
    # A point is an outlier if its mean neighbor distance exceeds mu_D + sigma_threshold * sigma_D
    threshold = mu_D + sigma_threshold * sigma_D
    outlier_mask = mean_distances > threshold
    
    # Remove outliers
    cleaned_points = points[~outlier_mask]
    
    return cleaned_points
```

**Edge Cases and Pitfalls:**
- **Precision:** Floating point errors in distance calculations may affect boundary cases.
- **Boundaries:** Points on the boundary of the object may have fewer neighbors or larger distances, potentially being incorrectly removed if $k$ is not chosen carefully.
- **Degenerate Input:** If the point cloud is too sparse, the statistical distribution may not be well-defined.

## Subtopics

### [Alpha-based Point Cleaning](19085-alpha-based-point-cleaning.md)
Alpha-based Point Cleaning is a post-processing and iterative optimization strategy used in neural point rendering to remove outlier points from a point cloud based on their learned opacity (alpha) values. It solves the problem of noisy initial reconstructions (e.g., from COLMAP) or spurious points generated during training (e.g., from spawning mechanisms) by explicitly identifying points with low confidence. Unlike sibling methods that rely on geometric density or distance metrics, this method leverages the neural optimization process itself, where valid geometry converges to high opacity while outliers converge to zero. It is a child of Statistical Outlier Removal, specifically utilizing the alpha parameter rather than statistical distance [Parent](17819-statistical-outlier-removal.md).

## Operating characteristics
- **Time Complexity:** $O(N \log N)$ for building the KD-tree and $O(N \cdot k)$ for querying neighbors, where $N$ is the number of points and $k$ is the number of neighbors.
- **Memory Complexity:** $O(N)$ for storing the point cloud and distance arrays.
- **Measured Performance:** Not given in the sources.
- **Scaling:** Scales linearly with the number of points for the filtering step, but the KD-tree construction is $O(N \log N)$.
- **Strengths:** Effective at removing isolated noise points and background artifacts. Simple to implement.
- **Limitations:** Requires heuristic tuning of parameters ($k$, $\sigma_{threshold}$). May remove valid points in sparse regions.
- **When to use:** When preprocessing point clouds for mesh generation to remove background noise.
- **When not:** When preserving sparse but valid geometry is critical, or when computational resources are extremely limited.

## Background
Originated in the context of 3D model generation from text, specifically in the DITTO-NeRF method [S1, unofficial]. The method was used to circumvent the inclusion of unwanted points (backgrounds or floors) in the generated mesh during the conversion of the point cloud to mesh [S1, unofficial]. The values of the thresholds were determined heuristically via experimentation [S1, unofficial].
