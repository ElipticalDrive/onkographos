# Point Cloud Cropping and Downsampling

Also called: Crop and Downsample Point Cloud

## Overview
This method reduces the density of a point cloud by first restricting the points to a specific spatial volume (cropping) and then reducing the point count via either voxel-based binning or uniform random sampling [S1, unofficial]. It serves as a preprocessing step for voxelization and registration, balancing computational load against geometric fidelity. It differs from [Octree Construction for Point Clouds](1070-octree-construction-for-point-clouds.md) by producing a flat list of points rather than a hierarchical structure, and from [Point Resampling with Neighbor Masking](2710-point-resampling-with-neighbor-masking.md) by using simpler spatial or uniform selection criteria rather than neighbor-aware masking.

## How it works
**Inputs:**
- `points`: Array of shape $(N, 3)$ containing 3D coordinates.
- `crop_volume`: Axis-aligned bounding box defined by minimum $(x_{min}, y_{min}, z_{min})$ and maximum $(x_{max}, y_{max}, z_{max})$ coordinates.
- `down_sample_method`: String, either `'voxel'` or `'uniform'`. Default: `'voxel'` [S1, unofficial].
- `voxel_size`: Float, side length of the voxel grid for downsampling. Default: $0.01$ [S1, unofficial].
- `max_point_number`: Integer, maximum number of points allowed before uniform downsampling is triggered. Value not specified in code snippet [S1, unofficial].

**Outputs:**
- `cropped_points`: Array of shape $(M, 3)$ where $M \le N$, containing points inside the crop volume.
- `indices`: Array of indices mapping `cropped_points` back to `points`.

**Data Structures:**
- **Voxel Grid**: A hash map or dense array mapping voxel coordinates $(v_x, v_y, v_z)$ to a single representative point (typically the first point encountered or the centroid). Voxel coordinates are calculated as $\lfloor p / \text{voxel\_size} \rfloor$.

**Steps:**

1. **Cropping**:
   Iterate through all points $p_i$ in `points`. Keep point $p_i$ if:
   $$ x_{min} \le p_i.x \le x_{max} \land y_{min} \le p_i.y \le y_{max} \land z_{min} \le p_i.z \le z_{max} $$
   Store the indices of kept points.

2. **Downsampling**:
   If the number of cropped points $M$ exceeds `max_point_number` (if defined) or based on `down_sample_method`:

   **Case A: Voxel Downsampling (`down_sample_method == 'voxel'`)**
   1. Initialize an empty dictionary `voxel_map`.
   2. For each point $p_i$ in the cropped set:
      a. Calculate voxel index:
         $$ v_x = \lfloor p_i.x / \text{voxel\_size} \rfloor $$
         $$ v_y = \lfloor p_i.y / \text{voxel\_size} \rfloor $$
         $$ v_z = \lfloor p_i.z / \text{voxel\_size} \rfloor $$
      b. Key $k = (v_x, v_y, v_z)$.
      c. If $k$ not in `voxel_map`, store $p_i$ (or its index) in `voxel_map[k]`.
   3. Collect all points stored in `voxel_map`.

   **Case B: Uniform Downsampling (`down_sample_method == 'uniform'`)**
   1. If `max_point_number` is defined and $M > \text{max\_point\_number}$:
      a. Select a random subset of size `max_point_number` from the cropped points without replacement.
   2. Else, return all cropped points.

**Parameters:**
- `voxel_size`: Controls the resolution of the voxel grid. Smaller values preserve more detail but increase memory and computation. Default: $0.01$ [S1, unofficial].
- `down_sample_method`: Determines the strategy. Default: `'voxel'` [S1, unofficial].

**Edge Cases and Pitfalls:**
- **Empty Crop**: If no points fall within `crop_volume`, return empty arrays.
- **Precision**: Floating-point division in voxel index calculation should use floor. Boundary conditions (points exactly on the voxel edge) are handled by the floor function, ensuring consistent binning.
- **Max Point Number**: If `max_point_number` is not provided in the source implementation, uniform downsampling may not trigger automatically, relying solely on voxel downsampling or the method choice [S1, unofficial].

**Pseudocode:**

```python
import numpy as np

def crop_and_downsample(points, crop_volume, down_sample_method='voxel', voxel_size=0.01, max_point_number=None):
    """
    Crops a point cloud using a volume and downsamples it.
    
    Args:
        points: np.array of shape (N, 3)
        crop_volume: tuple (x_min, y_min, z_min, x_max, y_max, z_max)
        down_sample_method: 'voxel' or 'uniform'
        voxel_size: float, size of voxel for downsampling
        max_point_number: int, max points for uniform downsampling
        
    Returns:
        cropped_points: np.array of shape (M, 3)
        indices: np.array of shape (M,)
    """
    x_min, y_min, z_min, x_max, y_max, z_max = crop_volume
    
    # Step 1: Cropping
    x = points[:, 0]
    y = points[:, 1]
    z = points[:, 2]
    
    mask = (
        (x >= x_min) & (x <= x_max) &
        (y >= y_min) & (y <= y_max) &
        (z >= z_min) & (z <= z_max)
    )
    
    cropped_points = points[mask]
    indices = np.where(mask)[0]
    
    M = cropped_points.shape[0]
    
    # If no points, return empty
    if M == 0:
        return np.empty((0, 3)), np.empty((0,), dtype=int)
    
    # Step 2: Downsampling
    if down_sample_method == 'voxel':
        # Voxel Downsampling
        # Calculate voxel indices
        voxel_indices = np.floor(cropped_points / voxel_size).astype(int)
        
        # Create a unique key for each voxel
        # Using a dictionary to map voxel key to the first point index in the cropped set
        voxel_map = {}
        result_indices = []
        
        for i, v_idx in enumerate(voxel_indices):
            key = tuple(v_idx)
            if key not in voxel_map:
                voxel_map[key] = i
                result_indices.append(i)
        
        selected_indices = np.array(result_indices)
        final_points = cropped_points[selected_indices]
        final_global_indices = indices[selected_indices]
        
    elif down_sample_method == 'uniform':
        # Uniform Downsampling
        if max_point_number is not None and M > max_point_number:
            # Randomly select max_point_number indices
            selected_indices = np.random.choice(M, max_point_number, replace=False)
            selected_indices.sort()
            final_points = cropped_points[selected_indices]
            final_global_indices = indices[selected_indices]
        else:
            final_points = cropped_points
            final_global_indices = indices
    else:
        raise ValueError(f"Unknown down_sample_method: {down_sample_method}")
        
    return final_points, final_global_indices
```

## Subtopics

### [Adaptive Point Cloud Downsampling based on Geometry and Texture Complexity](10729-adaptive-point-cloud-downsampling-based-on-geometry-and-text.md)
This method reduces point cloud density by selecting a subset of points based on local geometric curvature and color texture complexity, ensuring visually or structurally significant regions are preserved [10729-adaptive-point-cloud-downsampling-based-on-geometry-and-text.md]. It differs from uniform voxel downsampling by using probabilistic sampling weighted by complexity metrics rather than simple spatial binning, and from uniform random downsampling by biasing selection toward high-complexity areas. It builds on [Point Cloud Cropping and Downsampling](7057-point-cloud-cropping-and-downsampling.md).

### Farthest Point Sampling (FPS)
A method that operates in continuous Euclidean space, defining convolution weights at specific kernel points influenced by a linear correlation function [S2]. It is used to extract hierarchical features by performing downsampling, often enhancing robustness to variation in point density when combined with grid subsampling or partition-based grid pooling [S2].

### Voxel Downsampling Registration
Performs ICP registration between source and ground truth target point clouds using voxel downsampling, with an initial transformation [S1, unofficial]. It requires `voxel_size` as a parameter and uses ICP convergence criteria of tolerance $10^{-6}$ and max iterations `max_itr` [S1, unofficial].

### Uniform Registration
Performs ICP registration between source and ground truth target point clouds using uniform downsampling, with an initial transformation [S1, unofficial]. It uses a `max_size` parameter (default $4 \times \text{MAX\_POINT\_NUMBER}$, though not used in current implementation) and ICP convergence criteria of tolerance $10^{-6}$ and max iterations `max_itr` [S1, unofficial].

### Point Cloud Filtering and Noise Removal
Removes clear floaters from unprojected point clouds for each frame using a 3D statistical filter from Open3D [S3]. It uses 20 neighbors and a standard deviation ratio of 2.0 [S3].

## Operating characteristics
- **Time Complexity**: Cropping is $O(N)$. Voxel downsampling is $O(M)$ where $M$ is the number of cropped points, assuming hash map operations are $O(1)$. Uniform downsampling is $O(M)$ for selection.
- **Memory Complexity**: $O(M)$ for storing cropped points. Voxel grid storage is proportional to the number of occupied voxels.
- **Strengths**: Simple to implement; voxel downsampling provides a regularized point distribution suitable for grid-based methods; uniform downsampling is fast and preserves global distribution if density is uniform.
- **Limitations**: Voxel downsampling may lose fine details if `voxel_size` is too large; uniform downsampling may cluster points in dense regions; cropping requires accurate bounding box definition.
- **When to use**: Preprocessing for voxelization, registration, or rendering where point count reduction is needed.
- **When not to use**: When preserving exact geometric fidelity is critical and downsampling artifacts are unacceptable; when point density varies significantly and uniform/voxel methods would bias the result.

## Background
Originating from standard point cloud processing pipelines, this method is commonly used in 3D reconstruction and registration tasks [S1, unofficial]. It is implemented in libraries such as Open3D and used in Gaussian Splatting pipelines for efficient rendering and training [S1, unofficial][S3]. The method addresses the computational bottleneck of processing large point clouds by reducing data volume while maintaining essential geometric information.
