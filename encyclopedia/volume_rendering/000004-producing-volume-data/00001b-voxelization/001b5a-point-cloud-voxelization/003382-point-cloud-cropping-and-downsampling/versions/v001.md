# Point Cloud Cropping and Downsampling
Also called: Crop and Downsample Point Cloud

## Overview
Crops a point cloud using a defined volume and downsamples it using either voxel-based or uniform methods [S1, unofficial]. It differs from sibling methods like [Hard Voxelization](5345-hard-voxelization.md) by operating on the raw point set prior to voxel grid construction, reducing data size while preserving geometric distribution, whereas [Point Cloud Voxelization](1000-point-cloud-voxelization.md) focuses on the aggregation step itself.

## How it works
**Inputs:**
- Point cloud $P = \{p_i\}_{i=1}^N$, where $p_i \in \mathbb{R}^3$ are coordinates.
- Bounding volume $V$ (axis-aligned box or arbitrary convex hull) for cropping.
- Downsampling method $M \in \{\text{'voxel'}, \text{'uniform'}\}$. Default: 'voxel' [S1, unofficial].
- Voxel size $s$ for voxel downsampling. Default: $0.01$ [S1, unofficial].
- Maximum point count $N_{max}$ to trigger uniform downsampling if $M=\text{'uniform'}$. Value not specified in sources [S1, unofficial].

**Outputs:**
- Downsampled and cropped point cloud $P'$.

**Data Structures:**
- Input: List or array of $N$ points.
- Intermediate: Cropped point set $P_{crop}$.
- Output: Array of $N'$ points.

**Steps:**
1. **Cropping:** Filter $P$ to retain only points $p_i$ inside volume $V$.
   $$ P_{crop} = \{ p_i \in P \mid p_i \in V \} $$
   Let $N_{crop} = |P_{crop}|$ [S1, unofficial].

2. **Downsampling:**
   - If $M = \text{'voxel'}$:
     1. Define a 3D grid with cell size $s$.
     2. Map each point $p \in P_{crop}$ to grid cell $(x, y, z)$:
        $$ x = \lfloor p_x / s \rfloor, \quad y = \lfloor p_y / s \rfloor, \quad z = \lfloor p_z / s \rfloor $$
     3. For each occupied cell, select one representative point (e.g., the first encountered or centroid) [S1, unofficial].
     4. Collect representatives into $P'$ [S1, unofficial].
   - If $M = \text{'uniform'}$:
     1. If $N_{crop} > N_{max}$, select $N_{max}$ points uniformly at random from $P_{crop}$ without replacement [S1, unofficial].
     2. If $N_{crop} \le N_{max}$, $P' = P_{crop}$ [S1, unofficial].

**Pseudocode:**
```python
def crop_and_downsample(points, volume, method='voxel', voxel_size=0.01, max_points=None):
    # Step 1: Crop
    cropped = []
    for p in points:
        if is_inside_volume(p, volume): # [G] Helper to check bounds
            cropped.append(p)
    
    # Step 2: Downsample
    if method == 'voxel':
        grid = {} # Map from (ix, iy, iz) to point
        for p in cropped:
            ix = int(p.x / voxel_size)
            iy = int(p.y / voxel_size)
            iz = int(p.z / voxel_size)
            key = (ix, iy, iz)
            if key not in grid:
                grid[key] = p
        result = list(grid.values())
    elif method == 'uniform':
        if max_points is not None and len(cropped) > max_points:
            indices = random.sample(range(len(cropped)), max_points)
            result = [cropped[i] for i in indices]
        else:
            result = cropped
    else:
        raise ValueError("Unknown method")
        
    return result
```

**Edge Cases:**
- Empty input or no points inside volume: Returns empty set [S1, unofficial].
- Precision: Floating point division for voxel indices may cause boundary errors if not handled consistently (e.g., using floor vs. truncation) [G].

## Subtopics

### Farthest Point Sampling (FPS)
A method operating in continuous Euclidean space, defining convolution weights at specific kernel points influenced by a linear correlation function [S2]. It is used to extract hierarchical features by performing downsampling to ensure robustness to variation in point density, often enhancing grid subsampling or partition-based grid pooling [S2]. Choose this when uniform distribution of points is required for neural network feature extraction rather than simple density reduction [S2].

## Operating characteristics
- **Time Complexity:** Cropping is $O(N)$. Voxel downsampling is $O(N_{crop})$ assuming hash map operations are $O(1)$. Uniform downsampling is $O(N_{crop})$ for sampling.
- **Memory Complexity:** $O(N_{crop})$ for intermediate storage.
- **Strengths:** Simple, fast, effective for reducing redundancy in dense regions [S1, unofficial].
- **Limitations:** Voxel method may lose fine details if $s$ is too large; uniform method ignores spatial distribution [S1, unofficial].
- **When to use:** Pre-processing for voxel-based rendering or neural networks where point count is a bottleneck [S1, unofficial].

## Background
Originated in point cloud processing pipelines for 3D reconstruction and rendering. The specific implementation details are found in the 2D Gaussian Splatting codebase [S1, unofficial]. Farthest Point Sampling is a classical technique in point set processing [S2].
