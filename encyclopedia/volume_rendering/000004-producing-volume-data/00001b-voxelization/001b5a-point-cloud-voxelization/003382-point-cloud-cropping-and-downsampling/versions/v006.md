# Point Cloud Cropping and Downsampling

Also called: Crop and Downsample Point Cloud, Voxel Grid Filtering, VoxelGrid Filter

## Overview
This method reduces the density of a point cloud by first restricting it to a specific spatial volume and then applying a downsampling algorithm, either voxel-based or uniform [S1, unofficial]. It solves the problem of excessive point count in large datasets, which increases memory usage and computational cost for downstream tasks like registration or rendering [S1, unofficial]. It sets itself apart from sibling methods like [Hard Voxelization](5345-hard-voxelization.md) by explicitly offering a choice between geometric preservation via voxel averaging and simple cardinality reduction via uniform sampling, and from [Farthest Point Sampling](7182-farthest-point-sampling-fps.md) by relying on spatial binning or random selection rather than distance maximization.

## How it works
**Inputs:**
- `point_cloud`: A list or array of 3D points $(x, y, z)$.
- `crop_volume`: A bounding box or region defining the spatial extent to keep.
- `down_sample_method`: String, either `'voxel'` or `'uniform'`. Default: `'voxel'` [S1, unofficial].
- `leaf_size` or `voxel_size`: The dimensions of the voxel grid cells. Default: $(0.025, 0.025, 0.025)$ meters for `leaf_size` [S2, unofficial] or $0.01$ for `voxel_size` [S1, unofficial].
- `max_point_number`: Maximum number of points before uniform downsampling is triggered. Value not specified in code snippet [S1, unofficial].

**Outputs:**
- `filtered_cloud`: The resulting point cloud after cropping and downsampling.

**Data Structures:**
- The implementation typically uses a library such as Open3D, which internally manages a `VoxelGrid` data structure. This structure maps 3D coordinates to voxel indices based on the `leaf_size`.
- Points are stored as 3D vectors. NaN values are filtered out prior to processing [S2, unofficial].

**Steps:**
1. **Preprocessing:** Remove any points with NaN coordinates from the input cloud [S2, unofficial].
2. **Cropping:** Filter the point cloud to retain only points within the `crop_volume`.
3. **Downsampling Selection:**
   - If `down_sample_method` is `'voxel'`:
     1. Instantiate a `VoxelGrid` filter.
     2. Set the input cloud to the filter.
     3. Configure the `leaf_size` (e.g., $0.025$ m) [S2, unofficial].
     4. Apply the filter. The filter computes the centroid of all points falling into each voxel and replaces the points in that voxel with this single centroid point.
   - If `down_sample_method` is `'uniform'`:
     1. Check if the number of points exceeds `MAX_POINT_NUMBER` [S1, unofficial].
     2. If it does, randomly select a subset of points to reduce the count to `MAX_POINT_NUMBER`.
     3. If it does not, retain all points.
4. **Output:** Return the resulting point cloud.

**Pseudocode:**
```python
def crop_and_downsample(point_cloud, crop_volume, down_sample_method='voxel', leaf_size=0.025, max_point_number=None):
    """
    Crops a point cloud using a volume and downsamples it.
    
    Args:
        point_cloud: List of 3D points (x, y, z).
        crop_volume: Bounding box or region for cropping.
        down_sample_method: 'voxel' or 'uniform'.
        leaf_size: Size of voxel grid cells in meters.
        max_point_number: Max points for uniform downsampling.
        
    Returns:
        filtered_cloud: List of 3D points.
    """
    # Step 1: Remove NaN values [S2, unofficial]
    valid_points = [p for p in point_cloud if not any(is_nan(c) for c in p)]
    
    # Step 2: Crop to volume
    cropped_cloud = [p for p in valid_points if is_inside_volume(p, crop_volume)]
    
    # Step 3: Downsample
    if down_sample_method == 'voxel':
        # Voxel Grid Filtering [S2, unofficial]
        # Create a map from voxel index to list of points
        voxel_map = {}
        for p in cropped_cloud:
            # Compute voxel index
            vx = floor(p.x / leaf_size)
            vy = floor(p.y / leaf_size)
            vz = floor(p.z / leaf_size)
            key = (vx, vy, vz)
            if key not in voxel_map:
                voxel_map[key] = []
            voxel_map[key].append(p)
        
        # Compute centroids
        filtered_cloud = []
        for key, points in voxel_map.items():
            avg_x = sum(p.x for p in points) / len(points)
            avg_y = sum(p.y for p in points) / len(points)
            avg_z = sum(p.z for p in points) / len(points)
            filtered_cloud.append((avg_x, avg_y, avg_z))
            
    elif down_sample_method == 'uniform':
        # Uniform Downsampling [S1, unofficial]
        if max_point_number is not None and len(cropped_cloud) > max_point_number:
            # Randomly sample max_point_number points
            import random
            filtered_cloud = random.sample(cropped_cloud, max_point_number)
        else:
            filtered_cloud = cropped_cloud
            
    return filtered_cloud
```

**Parameters with Typical Values:**
- `leaf_size`: $0.025$ meters [S2, unofficial].
- `voxel_size`: $0.01$ meters [S1, unofficial].
- `max_point_number`: Not specified in code snippet [S1, unofficial].

**Edge Cases and Pitfalls:**
- **NaN Values:** Points with NaN coordinates must be removed before processing to avoid errors in centroid calculation or volume checks [S2, unofficial].
- **Empty Voxels:** If a voxel contains no points, it is ignored.
- **Precision:** Floating-point precision in voxel index calculation can lead to boundary artifacts if not handled consistently.
- **Uniform Downsampling Limit:** If `max_point_number` is not provided, uniform downsampling may not trigger, leading to no reduction if the cloud is large [S1, unofficial].

## Subtopics

### [Farthest Point Sampling (FPS)](7182-farthest-point-sampling-fps.md)
Farthest Point Sampling (FPS) is a deterministic (after initial random seed) algorithm for selecting a subset of points from a point cloud such that the selected points are maximally spread out in Euclidean space, ensuring maximum spatial coverage. It solves the problem of uniform downsampling where simple random sampling may leave gaps or cluster points, and grid-based methods may lose fine geometric details. It sets itself apart from sibling methods like [Adaptive Point Cloud Downsampling based on Geometry and Texture Complexity](10729-adaptive-point-cloud-downsampling-based-on-geometry-and-text.md) by relying purely on geometric distance metrics rather than local feature complexity or texture density.

### [Point Cloud Filtering and Noise Removal](8464-point-cloud-filtering-and-noise-removal.md)
Removes statistical outliers from a point cloud to clean noise and artifacts. It sets itself apart from sibling downsampling methods by focusing on geometric consistency and density rather than spatial coverage or surface complexity. Unlike [Farthest Point Sampling](7182-farthest-point-sampling-fps.md) which maximizes coverage, this method minimizes error by discarding points that deviate significantly from local density.

### [Adaptive Point Cloud Downsampling based on Geometry and Texture Complexity](10729-adaptive-point-cloud-downsampling-based-on-geometry-and-text.md)
This method reduces the density of a point cloud by selecting a subset of points based on local geometric curvature and color texture complexity, ensuring that visually or structurally significant regions are preserved during downsampling. It differs from uniform voxel downsampling by using probabilistic sampling weighted by complexity metrics rather than simple spatial binning, and from uniform random downsampling by biasing selection toward high-complexity areas. It builds on [Point Cloud Cropping and Downsampling](7057-point-cloud-cropping-and-downsampling.md).

## Operating characteristics
- **Time Complexity:** Voxel downsampling is $O(N)$ where $N$ is the number of points, as each point is assigned to a voxel and centroids are computed in a single pass. Uniform downsampling is $O(N)$ for filtering and $O(K)$ for sampling, where $K$ is the target size.
- **Memory Complexity:** $O(N)$ for storing the input and output clouds. Voxel grid storage is proportional to the number of occupied voxels.
- **Measured Performance:** Not given in the sources.
- **Scaling:** Voxel downsampling scales well with large point clouds as it reduces data density uniformly. Uniform downsampling is efficient but does not preserve spatial structure.
- **Strengths:** Simple to implement, reduces data size significantly, voxel method preserves local geometry via centroids.
- **Limitations:** Voxel method may lose fine details if leaf size is too large. Uniform method may create clusters or gaps.
- **When to use:** Use voxel downsampling when preserving local geometric structure is important. Use uniform downsampling when only cardinality reduction is needed.
- **When not to use:** Do not use if fine geometric details are critical and cannot be approximated by centroids.

## Background
The method is commonly implemented in point cloud processing libraries such as Open3D [S1, unofficial][S2, unofficial]. It is used in applications like 3D reconstruction, registration, and rendering to manage data size. The voxel grid filter is a standard technique in point cloud processing for downsampling [S2, unofficial].
