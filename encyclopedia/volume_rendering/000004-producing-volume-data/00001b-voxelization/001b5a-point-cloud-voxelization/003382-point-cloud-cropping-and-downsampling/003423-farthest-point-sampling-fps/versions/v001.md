# Farthest Point Sampling (FPS)
Also called: Furthest Point Sampling (FPS), KPConv, Point Cloud Downsampling via Farthest Point Sampling

## Overview
Farthest Point Sampling (FPS) is an algorithm that selects a subset of points from a point cloud such that the selected points are maximally spread out, effectively maximizing the minimum distance between any two selected points [S2, unofficial]. It is primarily used for point cloud downsampling to ensure uniform spatial coverage, often serving as a preprocessing step for hierarchical feature extraction in point-based neural networks [S1]. Unlike uniform voxel downsampling which bins points into grid cells, FPS operates directly in continuous Euclidean space to guarantee geometric distribution [S1][S2, unofficial].

## How it works
**Inputs:**
- `points`: An array of shape $(N, 3)$ containing the 3D coordinates of $N$ points.
- `sample_count`: The target number of points to select (integer).

**Outputs:**
- `indices`: An array of shape $(sample\_count,)$ containing the indices of the selected points from the original `points` array.

**Data Structures:**
- `points_index`: Integer array of shape $(N,)$ initialized to $[0, 1, \dots, N-1]$.
- `A`: List or array of selected indices.
- `B`: List or array of candidate indices (initially all indices not in `A`).
- `min_dis_B2A`: Array of shape $(|B|,)$ storing the squared Euclidean distance from each point in `B` to its nearest neighbor in `A`.

**Algorithm Steps:**
1. Initialize `points_index` as integers from $0$ to $N-1$.
2. Select one random index from `points_index` as the first element of set `A`.
3. Set `B` to contain all indices in `points_index` except those in `A`.
4. Compute the squared Euclidean distance from each point in `B` to the single point in `A` (index `A[0]`). Store these distances in `min_dis_B2A`.
5. While the size of `A` is less than `sample_count`:
    a. Find the index in `B` with the maximum value in `min_dis_B2A`. This is the point in `B` furthest from the current set `A`.
    b. Add this point's index to `A` and remove it from `B` and `min_dis_B2A`.
    c. For each remaining point in `B`, compute its distance to the newly added point in `A` (the last element of `A`). Update the stored distance in `min_dis_B2A` to be the minimum of the old distance and the new distance.

**Pseudocode:**
```python
import numpy as np
import math

def distance_point3d(p0, p1):
    """
    Computes the Euclidean distance between two 3D points.
    Note: The source implementation [S2, unofficial] contains a bug where it calculates
    (p0[2] - p0[2])**2 instead of (p0[2] - p1[2])**2. This implementation corrects that.
    """
    dx = p0[0] - p1[0]
    dy = p0[1] - p1[1]
    dz = p0[2] - p1[2]
    return math.sqrt(dx*dx + dy*dy + dz*dz)

def furthest_point_sample(points, sample_count):
    """
    Selects sample_count points from points using Farthest Point Sampling.
    
    Args:
        points: numpy array of shape (N, 3)
        sample_count: int, number of points to select
        
    Returns:
        indices: numpy array of shape (sample_count,)
    """
    N = points.shape[0]
    
    # Initialize index array
    points_index = np.arange(N, dtype=np.int64)
    
    # Select one random index as the first element of A
    first_idx = np.random.choice(points_index)
    A = np.array([first_idx], dtype=np.int64)
    
    # B contains all indices except those in A
    B = np.setdiff1d(points_index, A)
    
    # Compute initial distances from B to A[0]
    # min_dis_B2A stores the minimum distance from each point in B to any point in A
    min_dis_B2A = np.zeros(len(B), dtype=np.float64)
    
    for i in range(len(B)):
        Pb_index = B[i]
        Pa_index = A[0]
        Pa = points[Pa_index]
        Pb = points[Pb_index]
        min_dis_B2A[i] = distance_point3d(Pa, Pb)
    
    # Iteratively select the farthest point
    while len(A) < sample_count:
        # Find the index in B with the maximum distance to A
        longest_points_in_B_index = np.argmax(min_dis_B2A)
        longest_points_index = B[longest_points_in_B_index]
        
        # Update A and B
        A = np.append(A, longest_points_index)
        B = np.delete(B, longest_points_in_B_index)
        min_dis_B2A = np.delete(min_dis_B2A, longest_points_in_B_index)
        
        # Update min_dis_B2A: for each remaining point in B, 
        # update distance to be min(old_distance, distance_to_new_point_in_A)
        new_point_idx = A[-1]
        new_point = points[new_point_idx]
        
        for i in range(len(B)):
            Pb_index = B[i]
            Pb = points[Pb_index]
            dist = distance_point3d(new_point, Pb)
            if dist < min_dis_B2A[i]:
                min_dis_B2A[i] = dist
                
    return A
```

**Parameters:**
- `sample_count`: The target number of points to select. Typical values depend on the application, e.g., 4096 points for downsampling [S2, unofficial].

**Edge Cases and Pitfalls:**
- **Precision:** The distance calculation must use squared Euclidean distance or careful square root handling to avoid numerical instability. The source implementation [S2, unofficial] contains a bug in `distance_point3d` where it calculates `(p0[2] - p0[2])**2` instead of `(p0[2] - p1[2])**2`, effectively ignoring the Z-axis difference. This must be corrected in implementation [S2, unofficial].
- **Boundaries:** The algorithm assumes the input `points` array is non-empty and `sample_count` is less than or equal to $N$.
- **Degenerate Input:** If `points` has duplicate coordinates, the distance may be zero, but the algorithm will still proceed, potentially selecting redundant points if not handled.

## Operating characteristics
- **Time Complexity:** $O(N \cdot K)$, where $N$ is the number of input points and $K$ is the `sample_count`. Each iteration requires scanning all remaining points in `B` to update distances.
- **Memory Complexity:** $O(N)$ to store the distance array `min_dis_B2A` and index arrays.
- **Strengths:** Guarantees that selected points are well-distributed across the point cloud, which is beneficial for neural network feature extraction [S1].
- **Limitations:** Computationally expensive for large $N$ compared to uniform voxel downsampling. Sensitive to the bug in distance calculation if not corrected [S2, unofficial].
- **When to use:** When uniform spatial coverage is critical for downstream tasks like point-based neural networks [S1].
- **When not to use:** When computational efficiency is paramount and uniform distribution is not required; consider voxel downsampling instead.

## Background
Farthest Point Sampling is a fundamental technique in point cloud processing, often used in conjunction with point-based neural networks like KPConv [S1]. It was popularized in the context of learning on point sets to address the challenge of processing unordered point clouds with consistent spatial sampling [S1]. The method is referenced in recent surveys on 3D representations [S1] and implemented in various open-source voxelization and point cloud processing repositories [S2, unofficial].
