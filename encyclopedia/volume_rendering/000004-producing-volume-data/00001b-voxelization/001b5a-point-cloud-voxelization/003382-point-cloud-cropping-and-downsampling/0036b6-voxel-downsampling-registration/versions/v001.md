# Voxel Downsampling Registration

Also called: ICP Registration with Voxel Downsampling, ICP with Voxel Downsampling

## Overview
Voxel Downsampling Registration aligns a source point cloud to a target point cloud by first reducing the density of both clouds via voxel grid sampling and then applying Iterative Closest Point (ICP) [S1, S2, unofficial]. It differs from standard ICP by mitigating computational cost and sensitivity to noise through pre-registration downsampling [S1, S2, unofficial]. It builds on [Point Cloud Cropping and Downsampling](7057-point-cloud-cropping-and-downsampling.md) for the spatial reduction step.

## How it works
**Inputs:**
- Source point cloud $P_s$.
- Target (ground truth) point cloud $P_t$.
- Crop volume $V$ (bounding box or region of interest).
- Voxel size $d_v$.
- ICP distance threshold $\tau$.
- Initial transformation matrix $T_{init}$ (typically $4 \times 4$ identity or a coarse estimate).
- Maximum ICP iterations $N_{max}$.
- Convergence tolerance $\epsilon$ (typically $10^{-6}$).

**Outputs:**
- Final transformation matrix $T_{final}$ that aligns $P_s$ to $P_t$.
- Registration result object containing convergence metrics.

**Data Structures:**
- **Point Cloud:** List of 3D coordinates $(x, y, z)$.
- **Voxel Grid:** Implicit hash map or 3D array mapping voxel indices $(i, j, k)$ to a single representative point (centroid or first point) from the input cloud.
- **Transformation Matrix:** $4 \times 4$ homogeneous transformation matrix.

**Steps:**
1. **Configuration:** If verbose mode is enabled, print $d_v$ and $\tau$, and set library verbosity to Debug [S1, unofficial].
2. **Source Downsampling:** Apply voxel downsampling to $P_s$ using $V$ and $d_v$, optionally applying $T_{init}$ during the crop/downsample operation if the source needs pre-alignment before voxelization [S1, unofficial]. Let the result be $P'_s$.
3. **Target Downsampling:** Apply voxel downsampling to $P_t$ using $V$ and $d_v$. Let the result be $P'_t$. Note that $T_{init}$ is not applied to the target in the standard workflow [S1, S2, unofficial].
4. **ICP Execution:** Run ICP between $P'_s$ and $P'_t$ using:
   - Distance threshold $\tau$.
   - Initial guess $T_{start} = I$ (identity matrix) [S1, S2, unofficial].
   - Point-to-point distance metric [S1, S2, unofficial].
   - Convergence criteria: tolerance $\epsilon = 10^{-6}$ and max iterations $N_{max}$ [S1, S2, unofficial].
   - Let the resulting transformation from this step be $T_{icp}$ [S1, S2, unofficial].
5. **Transformation Composition:** Combine the ICP result with the initial transformation. The final transformation is $T_{final} = T_{icp} \times T_{init}$ [S1, S2, unofficial].
6. **Return:** Return $T_{final}$ and registration statistics.

**Pseudocode:**
```python
def voxel_downsampling_registration(source, target, crop_volume, voxel_size, threshold, init_trans, max_itr):
    # Step 1: Configuration
    # If verbose: print(voxel_size, threshold)
    # Set library verbosity to Debug

    # Step 2: Downsample source
    # crop_and_downsample applies the crop_volume and voxel_size
    # The 'trans' parameter applies init_trans before or during voxelization
    source_down = crop_and_downsample(source, crop_volume, 'voxel', voxel_size, trans=init_trans)

    # Step 3: Downsample target
    # No initial transformation applied to target
    target_down = crop_and_downsample(target, crop_volume, 'voxel', voxel_size)

    # Step 4: Perform ICP
    # Use identity as initial guess for the ICP step itself
    # TransformationEstimationPointToPoint(True) indicates point-to-point metric
    # ICPConvergenceCriteria(1e-6, max_itr) sets tolerance and max iterations
    reg = registration_icp(
        source_down,
        target_down,
        threshold,
        np.identity(4),
        TransformationEstimationPointToPoint(True),
        ICPConvergenceCriteria(1e-6, max_itr)
    )

    # Step 5: Update transformation
    # Compose the ICP result with the initial transformation
    # Note: Matrix multiplication order depends on convention (here: reg.transformation * init_trans)
    final_transformation = np.matmul(reg.transformation, init_trans)

    # Step 6: Return
    return final_transformation, reg
```

**Parameters:**
- `voxel_size`: The side length of the voxel grid. Required [S1, unofficial].
- `threshold`: The maximum distance for point correspondences in ICP [S1, S2, unofficial].
- `max_itr`: Maximum number of ICP iterations [S1, unofficial].
- `init_trans`: Initial $4 \times 4$ transformation matrix [S1, S2, unofficial].

**Edge Cases:**
- If `voxel_size` is too large, significant geometric detail is lost, potentially causing ICP convergence failure.
- If `threshold` is too small, few correspondences are found, leading to instability.
- Degenerate input (empty point clouds) after downsampling will cause ICP to fail.

Selects points based on geometric spread rather than grid occupancy. Choose when uniform spatial distribution is preferred over grid-aligned simplification.

Varies sampling density based on local surface complexity. Choose when uniform voxel size leads to over-sampling flat regions and under-sampling complex areas.

## Operating characteristics
- **Time Complexity:** Dominated by ICP convergence, which is typically $O(N \log N)$ or $O(N)$ per iteration depending on spatial indexing, where $N$ is the number of points after downsampling. Voxel downsampling is $O(N)$ [S1, S2, unofficial].
- **Memory Complexity:** $O(N)$ for storing the downsampled point clouds [S1, S2, unofficial].
- **Strengths:** Reduces computational load of ICP by decreasing point count; improves robustness to noise and outliers by averaging points within voxels [S1, S2, unofficial].
- **Limitations:** Loss of fine geometric details; performance depends heavily on the choice of `voxel_size` and `threshold` [S1, S2, unofficial].
- **When to use:** When point clouds are dense and noisy, and a coarse initial alignment is available [S1, S2, unofficial].
- **When not to use:** When high-frequency geometric details are critical for alignment [S1, S2, unofficial].

## Background
This method is implemented in the 2D Gaussian Splatting [S1, unofficial] and PGSR [S2, unofficial] repositories. It leverages the Open3D library for voxelization and ICP execution [S1, S2, unofficial]. The approach combines spatial cropping, voxel-based downsampling, and iterative closest point registration to achieve efficient alignment [S1, S2, unofficial].
