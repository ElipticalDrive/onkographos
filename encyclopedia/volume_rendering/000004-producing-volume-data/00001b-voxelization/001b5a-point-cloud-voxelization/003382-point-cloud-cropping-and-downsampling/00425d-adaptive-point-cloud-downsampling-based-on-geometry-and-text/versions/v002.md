# Adaptive Point Cloud Downsampling based on Geometry and Texture Complexity

## Overview
This method reduces the density of a point cloud by selecting a subset of points based on local geometric curvature and color texture complexity, ensuring that visually or structurally significant regions are preserved during downsampling [S1, unofficial]. It differs from uniform voxel downsampling by using probabilistic sampling weighted by complexity metrics rather than simple spatial binning, and from uniform random downsampling by biasing selection toward high-complexity areas [S1, unofficial]. It builds on [Point Cloud Cropping and Downsampling](7057-point-cloud-cropping-and-downsampling.md) [S1, unofficial].

## How it works
**Inputs:** `pointcloud_path` (path to input PLY), `target_num` (integer, desired output point count), `chunk_size` (integer, processing chunk size), `k_neighbors` (integer, neighbor count for local estimation), `geo_weight` (float, geometric complexity weight), `tex_weight` (float, texture complexity weight) [S1, unofficial].

**Outputs:** `output_path` (path to save downsampled PLY), structured array with fields `x,y,z` (f4), `nx,ny,nz` (f4), `r,g,b` (u1), `geo` (f4), `tex` (f4) [S1, unofficial].

**Data Structures:** `points` (N, 3) float32, `normals` (N, 3) float32 or None, `colors` (N, 3) float32 in Lab space or None, `geo_scores` (N,) float32, `tex_scores` (N,) float32, `combined_scores` (N,) float32, `probabilities` (N,) float32, `selected_indices` (target_num,) int64 [S1, unofficial].

**Steps:**
1. **Load and Preprocess:** Read point cloud from `pointcloud_path` using Open3D [S1, unofficial]. Extract points as `points` (N, 3) float32 [S1, unofficial]. Check for existence of colors and normals [S1, unofficial]. If colors exist, scale RGB to 0-255 uint8, convert using `cv2.cvtColor` with `cv2.COLOR_RGB2LAB`, convert to float32, normalize L channel by dividing by 100, normalize a,b channels by adding 128 and dividing by 255 [S1, unofficial]. If no colors, set `colors=None` and disable texture computation [S1, unofficial]. If normals do not exist, estimate them using Open3D's `estimate_normals` with a hybrid KDTree search parameter (radius=0.1, max_nn=k_neighbors) [S1, unofficial]. Build a `cKDTree` spatial index on `points` [S1, unofficial].
2. **Initialize Scores:** Initialize `geo_scores` and `tex_scores` arrays of size `num_points` with zeros if respective computations are enabled [S1, unofficial]. Initialize `combined_scores` to zeros [S1, unofficial].
3. **Compute Complexity Scores (Chunked):** Process points in chunks of size `chunk_size` [S1, unofficial]. For each chunk, query k-nearest neighbors (k_neighbors+1 to include self) from the KDTree, obtaining `distances` and `neighbor_indices` [S1, unofficial]. Get neighbor points for each point in the chunk [S1, unofficial]. Compute difference vectors `diffs` between neighbors and their mean [S1, unofficial]. Compute covariance matrices `covs` using einsum: `np.einsum('nki,nkj->nij', diffs, diffs) / k_neighbors` [S1, unofficial]. Compute eigenvalues of covariances using `np.linalg.eigvalsh` [S1, unofficial]. Calculate curvature as `eigenvalues[:, 0] / (eigenvalues.sum(axis=1) + 1e-6)` (smallest eigenvalue divided by sum of eigenvalues) [S1, unofficial]. Store in `geo_scores` [S1, unofficial]. Get neighbor colors [S1, unofficial]. Compute center color as the first neighbor (self) [S1, unofficial]. Compute L2 norm of difference between neighbor colors and center color for each neighbor [S1, unofficial]. Average these norms across neighbors for each point [S1, unofficial]. Store in `tex_scores` [S1, unofficial].
4. **Normalize and Combine Scores:** For each enabled score type (geo, tex), normalize to [0,1] using `(score - min) / (max - min + 1e-6)` [S1, unofficial]. Combine normalized scores using weighted sum: `combined_scores += weight * score` for each score/weight pair [S1, unofficial]. If no scores, set `combined_scores` to ones [S1, unofficial].
5. **Probabilistic Sampling:** Compute sampling probabilities: `probabilities = combined_scores / combined_scores.sum()` [S1, unofficial]. Select `target_num` points using `np.random.choice` with these probabilities, without replacement [S1, unofficial].
6. **Output:** Select downsampled points, normals, colors, and scores using the selected indices [S1, unofficial]. Construct a structured numpy array for PLY output with fields: `x,y,z` (f4), `nx,ny,nz` (f4), `r,g,b` (u1), `geo` (f4), `tex` (f4) [S1, unofficial]. Write to `output_path` as text PLY [S1, unofficial].

**Pseudocode:**
```python
import numpy as np
import open3d as o3d
import cv2
from scipy.spatial import cKDTree

def adaptive_downsample(pointcloud_path, target_num, chunk_size=1000, k_neighbors=10, geo_weight=1.0, tex_weight=1.0, output_path="output.ply"):
    # 1. Load and Preprocess
    pcd = o3d.io.read_point_cloud(pointcloud_path)
    points = np.asarray(pcd.points).astype(np.float32)
    num_points = len(points)
    
    has_colors = pcd.has_colors()
    has_normals = pcd.has_normals()
    
    colors = None
    if has_colors:
        rgb_uint8 = (np.asarray(pcd.colors) * 255).astype(np.uint8).reshape(-1, 1, 3)
        lab_uint8 = cv2.cvtColor(rgb_uint8, cv2.COLOR_RGB2LAB)
        lab_float = lab_uint8.astype(np.float32)
        L = lab_float[:, :, 0] / 100.0
        ab = (lab_float[:, :, 1:] + 128) / 255.0
        colors = np.concatenate([L.reshape(-1, 1), ab], axis=1)
    
    if not has_normals:
        pcd.estimate_normals(search_param=o3d.geometry.KDTreeSearchParamHybrid(radius=0.1, max_nn=k_neighbors))
        normals = np.asarray(pcd.normals).astype(np.float32)
    else:
        normals = np.asarray(pcd.normals).astype(np.float32)
        
    tree = cKDTree(points)
    
    geo_scores = np.zeros(num_points, dtype=np.float32)
    tex_scores = np.zeros(num_points, dtype=np.float32)
    
    # 2. Compute Complexity Scores (Chunked)
    for start in range(0, num_points, chunk_size):
        end = min(start + chunk_size, num_points)
        
        # Query k-nearest neighbors (k_neighbors+1 to include self)
        distances, neighbor_indices = tree.query(points[start:end], k=k_neighbors+1)
        
        # Geometric Complexity
        if geo_weight > 0:
            neighbor_points = points[neighbor_indices]
            mean_neighbors = np.mean(neighbor_points, axis=1, keepdims=True)
            diffs = neighbor_points - mean_neighbors
            covs = np.einsum('nki,nkj->nij', diffs, diffs) / k_neighbors
            eigenvalues = np.linalg.eigvalsh(covs)
            curvature = eigenvalues[:, 0] / (eigenvalues.sum(axis=1) + 1e-6)
            geo_scores[start:end] = curvature
            
        # Texture Complexity
        if tex_weight > 0 and colors is not None:
            neighbor_colors = colors[neighbor_indices]
            center_color = neighbor_colors[:, 0, :]
            diffs_colors = neighbor_colors - center_color[:, np.newaxis, :]
            l2_norms = np.linalg.norm(diffs_colors, axis=2)
            avg_norm = np.mean(l2_norms, axis=1)
            tex_scores[start:end] = avg_norm
            
    # 3. Normalize and Combine Scores
    combined_scores = np.zeros(num_points, dtype=np.float32)
    
    if geo_weight > 0:
        min_geo = np.min(geo_scores)
        max_geo = np.max(geo_scores)
        norm_geo = (geo_scores - min_geo) / (max_geo - min_geo + 1e-6)
        combined_scores += geo_weight * norm_geo
        
    if tex_weight > 0 and colors is not None:
        min_tex = np.min(tex_scores)
        max_tex = np.max(tex_scores)
        norm_tex = (tex_scores - min_tex) / (max_tex - min_tex + 1e-6)
        combined_scores += tex_weight * norm_tex
        
    if combined_scores.sum() == 0:
        combined_scores = np.ones(num_points, dtype=np.float32)
        
    # 4. Probabilistic Sampling
    probabilities = combined_scores / combined_scores.sum()
    selected_indices = np.random.choice(num_points, size=target_num, replace=False, p=probabilities)
    
    # 5. Output
    selected_points = points[selected_indices]
    selected_normals = normals[selected_indices]
    selected_geo = geo_scores[selected_indices]
    selected_tex = tex_scores[selected_indices]
    
    selected_colors_rgb = np.zeros((target_num, 3), dtype=np.uint8)
    if colors is not None:
        selected_colors = colors[selected_indices]
        L_back = selected_colors[:, 0] * 100.0
        ab_back = (selected_colors[:, 1:] * 255.0) - 128
        lab_uint8 = np.stack([L_back, ab_back[:, 0], ab_back[:, 1]], axis=1).astype(np.uint8).reshape(1, -1, 3)
        rgb_uint8 = cv2.cvtColor(lab_uint8, cv2.COLOR_LAB2RGB)
        selected_colors_rgb = rgb_uint8.reshape(-1, 3)
        
    ply_data = np.zeros(target_num, dtype=[
        ('x', '<f4'), ('y', '<f4'), ('z', '<f4'),
        ('nx', '<f4'), ('ny', '<f4'), ('nz', '<f4'),
        ('r', 'u1'), ('g', 'u1'), ('b', 'u1'),
        ('geo', '<f4'), ('tex', '<f4')
    ])
    ply_data['x'] = selected_points[:, 0]
    ply_data['y'] = selected_points[:, 1]
    ply_data['z'] = selected_points[:, 2]
    ply_data['nx'] = selected_normals[:, 0]
    ply_data['ny'] = selected_normals[:, 1]
    ply_data['nz'] = selected_normals[:, 2]
    ply_data['r'] = selected_colors_rgb[:, 0]
    ply_data['g'] = selected_colors_rgb[:, 1]
    ply_data['b'] = selected_colors_rgb[:, 2]
    ply_data['geo'] = selected_geo
    ply_data['tex'] = selected_tex
    
    # Write to output_path as text PLY
    with open(output_path, 'w') as f:
        f.write("ply\n")
        f.write("format ascii 1.0\n")
        f.write("element vertex %d\n" % target_num)
        f.write("property float x\nproperty float y\nproperty float z\n")
        f.write("property float nx\nproperty float ny\nproperty float nz\n")
        f.write("property uchar red\nproperty uchar green\nproperty uchar blue\n")
        f.write("property float geo\nproperty float tex\n")
        f.write("end_header\n")
        for i in range(target_num):
            f.write("%f %f %f %f %f %f %d %d %d %f %f\n" % (
                ply_data['x'][i], ply_data['y'][i], ply_data['z'][i],
                ply_data['nx'][i], ply_data['ny'][i], ply_data['nz'][i],
                ply_data['r'][i], ply_data['g'][i], ply_data['b'][i],
                ply_data['geo'][i], ply_data['tex'][i]
            ))
```

**Parameters with typical values:** Not given in the sources.

**Edge cases and pitfalls:** If `target_num` exceeds `num_points`, `np.random.choice` raises an error [S1, unofficial]. If all scores are zero, `combined_scores.sum()` is zero, causing division by zero in probability normalization; the method initializes `combined_scores` to ones when no scores are enabled to prevent this [S1, unofficial]. Precision issues in eigenvalue computation are mitigated by using `np.linalg.eigvalsh` for symmetric matrices [S1, unofficial]. The k-NN approach with `k_neighbors+1` avoids boundary conditions where radius search might find fewer than 3 neighbors [S1, unofficial].

## Operating characteristics
- **Time Complexity:** $O(N \log N)$ for KDTree construction and $O(N \cdot k)$ for complexity scoring, where $N$ is point count and $k$ is `k_neighbors` [S1, unofficial]. Sampling is $O(N)$ [S1, unofficial].
- **Memory Complexity:** $O(N)$ for points, scores, and KDTree [S1, unofficial].
- **Measured Performance:** Not given in the sources.
- **Scaling:** Linear with $N$ for scoring, assuming efficient KDTree queries [S1, unofficial].
- **Strengths:** Preserves geometric and texture details better than uniform downsampling by biasing selection toward high-complexity areas [S1, unofficial].
- **Limitations:** Computationally more expensive than uniform downsampling and requires normals and colors for full functionality [S1, unofficial].
- **When to use:** When preserving visual and geometric fidelity is important and the point cloud is large enough to benefit from intelligent downsampling [S1, unofficial].
- **When not to use:** When computational resources are limited or the point cloud is already small [S1, unofficial].

## Background
This method originates from the AVM-GS project, which focuses on adaptive volume rendering [S1, unofficial]. It is designed to prepare point clouds for further processing, such as voxelization or rendering, by reducing redundancy while maintaining key features [S1, unofficial].
