# Global Feature Volume Construction

Also called: Fv Construction, Global Feature Volume Construction via Voxelization and U-Net

## Overview
Global Feature Volume Construction builds a dense 3D feature volume $F_v$ from multi-view 2D features to provide global contextual information for downstream volume rendering tasks [S1][S2, unofficial]. It differs from local feature aggregation by first lifting 2D features into a 3D grid via projection and statistical pooling, then regularizing the sparse result with a 3D U-Net [S1][S2, unofficial].

## How it works
**Inputs:**
- $N$: Number of source views [S1][S2, unofficial].
- $\{F_i\}_{i=1}^N$: 2D feature maps from source views, where $F_i \in \mathbb{R}^{H \times W \times C}$ [S2, unofficial].
- $K$: Resolution of the global feature volume grid per dimension [S1][S2, unofficial].
- Bounding volume: The 3D region containing the scene [S1][S2, unofficial].

**Outputs:**
- $F_v$: The global feature volume, a 3D tensor of shape $\mathbb{R}^{K \times K \times K \times D}$, where $D$ is the output dimension of the 3D U-Net [S1][S2, unofficial].

**Data Structures:**
- Voxel Grid: A regular grid of $K^3$ voxels covering the bounding volume. Each voxel is identified by integer coordinates $(x, y, z)$ where $x, y, z \in \{0, \dots, K-1\}$ [S1][S2, unofficial].
- Voxel Feature: A vector constructed for each voxel by concatenating the mean and variance of projected features [S1][S2, unofficial].

**Steps:**
1. **Voxelization:** Divide the scene's bounding volume into a grid of $K^3$ voxels [S1][S2, unofficial].
2. **Projection and Interpolation:** For each voxel center $p_{xyz}$, project it onto the 2D feature map $F_i$ of each source view $i \in \{1, \dots, N\}$ [S1][S2, unofficial]. Obtain the feature vector $f_{i, xyz}$ using bilinear interpolation [S1][S2, unofficial].
3. **Statistical Aggregation:** For each voxel, compute the mean $\mu_{xyz}$ and variance $\sigma^2_{xyz}$ across the $N$ interpolated features $\{f_{i, xyz}\}_{i=1}^N$ [S1][S2, unofficial].
4. **Feature Concatenation:** Concatenate $\mu_{xyz}$ and $\sigma^2_{xyz}$ to form the initial voxel feature vector $v_{xyz}$ [S1][S2, unofficial].
5. **Regularization:** Input the sparse voxel features into a 3D U-Net to regularize and aggregate information, producing the final global feature volume $F_v$ [S1][S2, unofficial].

**Pseudocode:**
```python
def construct_global_feature_volume(feature_maps, K, bounding_volume):
    """
    feature_maps: List of N tensors, each shape (H, W, C)
    K: Integer, resolution of the output volume
    bounding_volume: Object defining the 3D bounds (min_x, max_x, min_y, max_y, min_z, max_z)
    """
    N = len(feature_maps)
    C = feature_maps[0].shape[2]
    
    # Initialize storage for voxel features before U-Net
    # Shape: (K, K, K, 2*C) to store mean and variance concatenation
    voxel_features = []
    
    # Define voxel grid coordinates
    grid_x = torch.linspace(bounding_volume.min_x, bounding_volume.max_x, K)
    grid_y = torch.linspace(bounding_volume.min_y, bounding_volume.max_y, K)
    grid_z = torch.linspace(bounding_volume.min_z, bounding_volume.max_z, K)
    
    # Create meshgrid for all voxel centers
    # This creates coordinates for all K^3 voxels
    centers = torch.stack(torch.meshgrid(grid_x, grid_y, grid_z, indexing='ij'), dim=-1) # Shape: (K, K, K, 3)
    
    for x in range(K):
        for y in range(K):
            for z in range(K):
                p = centers[x, y, z] # 3D point in world space
                
                # Step 2: Project and Interpolate
                features_per_view = []
                for i in range(N):
                    # Project p onto feature map F_i
                    # This requires inverse projection from 3D to 2D image coordinates
                    # Assuming a standard pinhole camera model or similar projection matrix is available
                    u, v = project_3d_to_2d(p, feature_maps[i].camera_params)
                    
                    # Bilinear interpolation
                    f_interp = bilinear_interpolate(feature_maps[i].data, u, v)
                    features_per_view.append(f_interp)
                
                # Stack features from all views: Shape (N, C)
                features_per_view = torch.stack(features_per_view, dim=0)
                
                # Step 3 & 4: Compute Mean, Variance, and Concatenate
                mean_feat = torch.mean(features_per_view, dim=0) # Shape (C,)
                var_feat = torch.var(features_per_view, dim=0, unbiased=False) # Shape (C,)
                
                voxel_feature = torch.cat([mean_feat, var_feat], dim=0) # Shape (2*C,)
                voxel_features.append(voxel_feature)
    
    # Reshape to (K, K, K, 2*C)
    voxel_features = torch.stack(voxel_features, dim=0).reshape(K, K, K, 2*C)
    
    # Step 5: 3D U-Net Regularization
    # The U-Net takes the voxel features as input and outputs the regularized volume
    Fv = UNet3D(voxel_features)
    
    return Fv
```

**Parameters:**
- $K$: Number of voxels per dimension. Typical value: $K=96$ [S2, unofficial].
- $N$: Number of source views [S1][S2, unofficial].

**Edge Cases:**
- Precision: Bilinear interpolation requires accurate 3D-to-2D projection coordinates. Errors in camera parameters or bounding volume alignment will lead to incorrect feature sampling [S1][S2, unofficial].
- Boundaries: Voxels outside the scene geometry may still receive features if the bounding volume is large. The 3D U-Net helps regularize these, but the initial mean/variance calculation includes all voxels in the grid [S1][S2, unofficial].

## Operating characteristics
- **Time Complexity:** Dominated by the projection and interpolation step for all $K^3$ voxels and $N$ views, i.e., $O(K^3 \cdot N)$. The 3D U-Net adds a constant overhead relative to $K$ and $N$ but depends on its depth and channel dimensions.
- **Memory Complexity:** $O(K^3 \cdot C)$ for storing intermediate voxel features before U-Net, and $O(K^3 \cdot D)$ for the output volume $F_v$ [S1][S2, unofficial].
- **Performance:** Using $K=96$ provides a balance between detail and computational cost [S2, unofficial].
- **Strengths:** Provides global context, which helps resolve ambiguities in appearance and geometry common in NeRF-based methods [S1][S2, unofficial].
- **Limitations:** Requires significant memory for large $K$ and $N$. The 3D U-Net adds inference latency.

## Background
- **Origin:** Introduced in VolRecon (Ren et al., CVPR 2023) [S1][S2, unofficial].
- **Development:** Builds on earlier works that use global feature volumes for generalizable reconstruction [S1][S2, unofficial].
- **Usage:** Used in VolRecon for generalizable multi-view reconstruction, specifically to complement Signed Ray Distance Functions (SRDF) [S1].
