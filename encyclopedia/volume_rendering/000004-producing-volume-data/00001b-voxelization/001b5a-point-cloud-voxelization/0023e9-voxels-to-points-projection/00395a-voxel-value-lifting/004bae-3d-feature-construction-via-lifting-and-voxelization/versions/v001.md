# 3D Feature Construction via Lifting and Voxelization

Also called: Lifting to 3D feature, Point Cloud Voxelization for Feature Aggregation

## Overview
This method constructs a structured 3D feature volume from unstructured point clouds derived from multi-view images. It solves the problem of aggregating per-pixel image features into a spatially coherent volumetric representation suitable for 3D neural networks. It differs from [Voxel Value Lifting](8461-voxel-value-lifting.md) by operating in the forward direction: it lifts 2D image features into 3D space via depth unprojection and voxelization, whereas the parent method maps existing voxel values back to point rows.

## How it works
**Inputs:**
- Predicted depth maps $D_i(u, v)$ for $N$ source views.
- Camera intrinsics $K$ and extrinsics $(R_i, T_i)$ for each view $i$.
- Image feature maps $F_i$ corresponding to each view.
- Voxel size $v_s$.

**Outputs:**
- A 3D voxel grid $V$ where each voxel $(i, j, k)$ contains an aggregated feature vector $V_{i,j,k}$.

**Data Structures:**
- **Point Cloud $P$**: An unstructured list of 3D points. Each point $p$ has coordinates $(x_p, y_p, z_p)$ and an associated feature vector $f_p$ from the source image.
- **Voxel Grid**: A 3D array indexed by integer coordinates $(i, j, k)$. The size is determined by the bounding volume of the scene divided by $v_s$.
- **Aggregation Buffer**: For each voxel, a list or accumulator for features $f_p$ of all points $p$ falling into that voxel.

**Steps:**

1. **Unproject to Camera Coordinates:**
   For each pixel $(u, v)$ in each source view $i$, compute the 3D point in the camera coordinate frame $P_{cam}$ using the predicted depth $D_i(u, v)$ and intrinsics $K$:
   $$
   P_{cam} = D_i(u, v) K^{-1} \begin{bmatrix} u \\ v \\ 1 \end{bmatrix}
   $$
   [S1]

2. **Transform to World Coordinates:**
   Transform $P_{cam}$ to the world coordinate system $P_{world}$ using the view's rotation matrix $R_i$ and translation vector $T_i$:
   $$
   P_{world} = R_i P_{cam} + T_i
   $$
   [S1]

3. **Voxelization:**
   For each 3D point $p = (x_p, y_p, z_p)$ in the resulting dense point cloud, compute the integer voxel indices $(i, j, k)$ by dividing by the voxel size $v_s$ and rounding to the nearest integer:
   $$
   i = \text{rnd}\left(\frac{x_p}{v_s}\right), \quad j = \text{rnd}\left(\frac{y_p}{v_s}\right), \quad k = \text{rnd}\left(\frac{z_p}{v_s}\right)
   $$
   where $\text{rnd}(\cdot)$ denotes rounding to the nearest integer. [S1]

4. **Feature Aggregation:**
   Let $S_{i,j,k}$ be the set of all points falling into voxel $(i, j, k)$. Aggregate the features $f_p$ associated with each point $p \in S_{i,j,k}$ by averaging along the channel dimension to produce the voxel feature $V_{i,j,k}$:
   $$
   V_{i,j,k} = \frac{1}{|S_{i,j,k}|} \sum_{p \in S_{i,j,k}} f_p
   $$
   [S1]

**Parameters:**
- $v_s$: Voxel size. Not given in the sources.
- $K$: Number of voxels per dimension (used in Global Feature Volume variant). [S2]
- $N$: Number of source views. [S2]

**Edge Cases and Pitfalls:**
- **Empty Voxels:** If $|S_{i,j,k}| = 0$, the voxel is empty. The aggregation formula is undefined. Implementation must handle this by initializing empty voxels to zero or a background value. [G]
- **Precision:** Rounding errors in voxel index calculation can cause points near voxel boundaries to be assigned incorrectly. [S1]
- **Memory:** The dense point cloud size is $|S| = H \times W \times N$. This can be large for high-resolution images and many views. [S1]

**Pseudocode:**

```python
import numpy as np

def lift_and_voxelize(depth_maps, intrinsics, extrinsics, image_features, voxel_size):
    """
    depth_maps: List of N depth maps, shape (H, W)
    intrinsics: 3x3 matrix K
    extrinsics: List of N tuples (R_i, T_i), R_i is 3x3, T_i is 3x1
    image_features: List of N feature maps, shape (H, W, C)
    voxel_size: float vs
    
    Returns:
    voxel_grid: 3D array of shape (X, Y, Z, C)
    """
    # 1. Unproject and Transform
    points = []
    features = []
    
    for i in range(len(depth_maps)):
        D = depth_maps[i]
        R, T = extrinsics[i]
        F = image_features[i]
        H, W = D.shape
        
        # Create pixel grid
        u, v = np.meshgrid(np.arange(W), np.arange(H))
        u = u.flatten()
        v = v.flatten()
        z = D.flatten()
        
        # Homogeneous coordinates in camera frame
        cam_coords_hom = np.vstack([u, v, np.ones_like(u)])
        
        # Unproject: P_cam = z * K^-1 * [u, v, 1]^T
        K_inv = np.linalg.inv(intrinsics)
        cam_coords = (K_inv @ cam_coords_hom).T * z[:, np.newaxis]
        
        # Transform to world: P_world = R * P_cam + T
        world_coords = (R @ cam_coords.T).T + T.T
        
        # Flatten features
        feat_flat = F.reshape(-1, F.shape[-1])
        
        points.append(world_coords)
        features.append(feat_flat)
        
    all_points = np.vstack(points)
    all_features = np.vstack(features)
    
    # 2. Voxelization
    # Compute voxel indices
    voxel_indices = np.floor(all_points / voxel_size).astype(int)
    
    # Determine grid bounds
    min_idx = voxel_indices.min(axis=0)
    max_idx = voxel_indices.max(axis=0)
    grid_shape = max_idx - min_idx + 1
    
    # Initialize voxel grid with zeros
    # Note: In practice, sparse structures might be used, but dense array is assumed for simplicity
    voxel_grid = np.zeros((*grid_shape, all_features.shape[1]))
    
    # Offset indices to be non-negative
    voxel_indices -= min_idx
    
    # 3. Aggregation
    # Use bincount or similar to aggregate
    # Flatten voxel indices for bincount
    flat_voxel_indices = voxel_indices[:, 0] * grid_shape[1] * grid_shape[2] + \
                         voxel_indices[:, 1] * grid_shape[2] + \
                         voxel_indices[:, 2]
    
    # Initialize sums and counts
    voxel_sums = np.zeros((grid_shape[0] * grid_shape[1] * grid_shape[2], all_features.shape[1]))
    voxel_counts = np.zeros(grid_shape[0] * grid_shape[1] * grid_shape[2])
    
    # Accumulate
    np.add.at(voxel_sums, flat_voxel_indices, all_features)
    np.add.at(voxel_counts, flat_voxel_indices, 1)
    
    # Avoid division by zero
    voxel_counts = np.maximum(voxel_counts, 1)
    
    # Average
    voxel_means = voxel_sums / voxel_counts[:, np.newaxis]
    
    # Reshape to 3D grid
    voxel_grid = voxel_means.reshape(grid_shape + (all_features.shape[1],))
    
    return voxel_grid
```

## Subtopics

### Global Feature Volume Construction
This variant constructs a global feature volume by dividing the scene bounding volume into $K^3$ voxels. For each voxel, its center point is projected onto the feature map of each of the $N$ source views, and the feature is obtained via bilinear interpolation. The mean and variance of these $N$ features are computed and concatenated to form the voxel feature. Finally, a 3D U-Net is used for regularization to produce the global feature volume $F_v$. [S2] Parameters: $K$ is the number of voxels per dimension, and $N$ is the number of source views. [S2]

## Operating characteristics
- **Time Complexity:** Dominated by the unprojection and voxelization steps, which are $O(H \times W \times N)$ for $N$ views of resolution $H \times W$. Aggregation is linear in the number of points. [S1]
- **Memory Complexity:** Requires storing the dense point cloud ($O(H \times W \times N)$) and the voxel grid. The voxel grid size depends on the scene bounding volume and $v_s$. [S1]
- **Strengths:** Provides a structured 3D representation from unstructured point clouds, enabling the use of 3D convolutions. [S1]
- **Limitations:** Memory intensive for high-resolution images and many views. Sensitive to depth prediction errors. [S1]
- **When to use:** When a structured 3D feature volume is needed for downstream 3D neural network processing, such as 3D Gaussian Splatting or volumetric rendering. [S1]

## Background
This method is used in feed-forward 3D Gaussian Splatting frameworks to construct voxel-aligned features for prediction. It was introduced in VolSplat. [S1] The Global Feature Volume variant is used in VolRecon for generalizable multi-view reconstruction. [S2]
