# Voxel Fragmentation via Grid Clustering

Also called: RegularGrid::queryCluster, Voxel-based Face Clustering

## Overview
Voxel Fragmentation via Grid Clustering assigns a specific voxel cluster ID to each triangle face in a mesh by statistically sampling intersections with a regular voxel grid. It solves the problem of determining which discrete voxel value (cluster) a continuous surface fragment primarily occupies, enabling the conversion of triangle meshes into sparse voxel grids for volume rendering. It differs from deterministic ray-casting by using Monte Carlo sampling to handle ambiguity at voxel boundaries and faces shared by multiple clusters.

## How it works
The method operates on a GPU using compute shaders. It processes faces in batches to respect GPU buffer size limits, sampling each face against the voxel grid to determine cluster occupancy.

### Inputs and Outputs
**Inputs:**
- `faces`: List of triangle faces.
- `grid`: Regular voxel grid defined by `aabbMin`, `cellSize`, and `gridDims`.
- `numSamples`: Number of random samples per face (default 1000) [S1, unofficial].
- `numFragments`: Number of distinct voxel values (clusters) in the grid, determined by `countValues()` [S1, unofficial].

**Outputs:**
- `clusterIdx`: Vector of cluster IDs for each face. Negative values indicate boundary faces [S1, unofficial].
- `faceClusterOccupancy`: Map of cluster IDs to normalized occupancy counts for each face [S1, unofficial].

### Data Structures
The implementation uses the following layouts [S1, unofficial]:

1.  **count**: `std::vector<GLuint>` of size `maxFaces * numFragments`. Stores raw intersection counts for each face-cluster pair.
2.  **boundary**: `std::vector<unsigned>` of size `maxFaces * numFragments`. Used by the GPU for boundary flags or intermediate IDs.
3.  **clusterIdx**: `std::vector<float>` of size `faces.size()`. Stores the final cluster index. Negative values indicate boundary faces.
4.  **faceClusterOccupancy**: `std::vector<std::unordered_map<unsigned, float>>` of size `faces.size()`. Maps cluster ID to normalized occupancy count.
5.  **noiseBuffer**: `std::vector<float>` of size `numSamples * numSamples`. Stores random values for the compute shader.

### Parameters
- `numSamples`: Default 1000 [S1, unofficial].
- `maxFaces`: Calculated as `min(faces.size(), floor(getMaxSSBOSize(sizeof(GLuint)) / numFragments))` to respect GPU SSBO limits [S1, unofficial].

### Algorithm Steps
1.  **Initialization**:
    - Initialize `clusterIdx` with `-1.0f` for all faces [S1, unofficial].
    - Fill `noiseBuffer` with random values of size `numSamples * numSamples` [S1, unofficial].
    - Calculate `maxFaces` based on GPU SSBO size limits [S1, unofficial].

2.  **Buffer Binding**:
    - Bind `countSSBO` (read/write), `vertexSSBO` (read), `gridSSBO` (read), `boundarySSBO` (read/write), `noiseSSBO` (read), and `clusterSSBO` (read/write) [S1, unofficial].

3.  **Counting Phase**:
    - Execute `_countVoxelTriangleShader` with uniforms: `aabbMin`, `cellSize`, `gridDims`, `numFragments`, `numSamples`, `numFaces` [S1, unofficial].
    - This shader populates the `count` array with raw intersection counts [S1, unofficial].

4.  **Assignment Phase**:
    - Execute `_pickVoxelTriangleShader` with uniforms: `numFragments`, `numFaces` [S1, unofficial].
    - This shader assigns cluster IDs to faces based on the counts [S1, unofficial].

5.  **Post-Processing**:
    - Read count data from the GPU and populate `faceClusterOccupancy`. For each face and cluster, if count > 0, store the count in the map [S1, unofficial].
    - Normalize occupancy counts by dividing by `numSamples` [S1, unofficial].
    - Read final cluster IDs from `clusterSSBO`.
    - If `clusterIdx[idx] < 0.0f`, it is a boundary face; push the index to `boundaryFaces` and negate the value to store a positive ID [S1, unofficial].

### Pseudocode
```python
def voxel_fragmentation_via_grid_clustering(faces, grid, num_samples=1000):
    # 1. Calculate max faces based on GPU SSBO limits [S1, unofficial]
    max_ssbo_size = get_max_ssbo_size(sizeof(GLuint))
    num_fragments = count_values(grid) # Number of distinct clusters [S1, unofficial]
    max_faces = min(len(faces), floor(max_ssbo_size / num_fragments))
    
    # 2. Initialize data structures [S1, unofficial]
    cluster_idx = [-1.0f] * len(faces)
    noise_buffer = generate_random_noise(num_samples * num_samples)
    count_ssbo = allocate_buffer(max_faces * num_fragments, dtype=GLuint)
    boundary_ssbo = allocate_buffer(max_faces * num_fragments, dtype=unsigned)
    cluster_ssbo = allocate_buffer(max_faces, dtype=float)
    
    face_cluster_occupancy = [{} for _ in range(len(faces))]
    boundary_faces = []
    
    # 3. Batch processing loop [S1, unofficial]
    processed = 0
    while processed < len(faces):
        batch_size = min(len(faces) - processed, max_faces)
        
        # Bind buffers [S1, unofficial]
        bind_ssbo(count_ssbo, target=GL_SHADER_STORAGE_BUFFER, usage=GL_READ_WRITE)
        bind_ssbo(grid_ssbo, target=GL_SHADER_STORAGE_BUFFER, usage=GL_READ_ONLY)
        bind_ssbo(boundary_ssbo, target=GL_SHADER_STORAGE_BUFFER, usage=GL_READ_WRITE)
        bind_ssbo(noise_ssbo, target=GL_SHADER_STORAGE_BUFFER, usage=GL_READ_ONLY)
        bind_ssbo(cluster_ssbo, target=GL_SHADER_STORAGE_BUFFER, usage=GL_READ_WRITE)
        
        # Execute Count Shader [S1, unofficial]
        dispatch_compute(
            shader=_countVoxelTriangleShader,
            uniforms={
                'aabbMin': grid.aabbMin,
                'cellSize': grid.cellSize,
                'gridDims': grid.gridDims,
                'numFragments': num_fragments,
                'numSamples': num_samples,
                'numFaces': batch_size
            }
        )
        
        # Execute Pick Shader [S1, unofficial]
        dispatch_compute(
            shader=_pickVoxelTriangleShader,
            uniforms={
                'numFragments': num_fragments,
                'numFaces': batch_size
            }
        )
        
        # 4. Read and Process Results [S1, unofficial]
        counts = read_ssbo(count_ssbo, size=batch_size * num_fragments)
        
        for i in range(batch_size):
            face_idx = processed + i
            for c in range(num_fragments):
                count = counts[i * num_fragments + c]
                if count > 0:
                    # Normalize occupancy [S1, unofficial]
                    occupancy = count / num_samples
                    face_cluster_occupancy[face_idx][c] = occupancy
            
            # Read final cluster ID [S1, unofficial]
            final_id = read_ssbo(cluster_ssbo, offset=i, size=1)[0]
            
            if final_id < 0.0f:
                # Boundary face handling [S1, unofficial]
                boundary_faces.append(face_idx)
                cluster_idx[face_idx] = -final_id # Negate to store positive ID
            else:
                cluster_idx[face_idx] = final_id
        
        processed += batch_size
        
    return cluster_idx, face_cluster_occupancy, boundary_faces
```

### Edge Cases and Pitfalls
- **SSBO Size Limits**: The number of faces may exceed the GPU's maximum SSBO size for the count array. Batch processing is required [S1, unofficial].
- **Boundary Faces**: Identified by negative cluster indices in the output buffer. The algorithm negates them to store positive IDs while tracking them separately [S1, unofficial].
- **Precision**: Floating point comparisons for `clusterIdx[idx] < 0.0f` should account for potential precision errors, though the source specifies exact `-1.0f` initialization [S1, unofficial].

## Operating characteristics
- **Time Complexity**: $O(N \cdot S)$, where $N$ is the number of faces and $S$ is the number of samples per face. Batch processing adds a factor of $N / maxFaces$.
- **Memory Complexity**: $O(maxFaces \cdot numFragments)$ for the count buffer, plus $O(N)$ for the output arrays.
- **Strengths**: Handles ambiguous boundary cases via statistical sampling; efficient on GPU via parallel compute shaders.
- **Limitations**: Requires batch processing for large meshes; stochastic nature may lead to slight variations if random seeds are not fixed.
- **When to use**: When converting triangle meshes to sparse voxel grids for volume rendering, especially when faces span multiple voxel clusters.

## Background
The method is part of the VoxelFragmentML project, an unofficial implementation for writing vox files to support world mode editors, initially created for the "SdfMesher" procedural software [S1, unofficial]. It was developed by AlfonsoLRz.
