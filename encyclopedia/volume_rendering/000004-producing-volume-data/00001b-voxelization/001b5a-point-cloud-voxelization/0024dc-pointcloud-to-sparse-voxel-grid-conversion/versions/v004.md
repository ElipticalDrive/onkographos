# Pointcloud to Sparse Voxel Grid Conversion

Also called: Open3D Voxel Grid Creation, Point Cloud Voxelization with pyntcloud, Pyntcloud Voxel Grid Creation, add_structure voxelgrid

## Overview
Pointcloud to Sparse Voxel Grid Conversion converts a continuous 3D point cloud into a discrete, sparse voxel grid representation by mapping input points to voxel indices and storing only occupied voxels [S1, S2, S3, unofficial]. It differs from dense voxelization by avoiding memory allocation for empty space, and from [Hard Voxelization](5345-hard-voxelization.md) by typically supporting feature aggregation (e.g., mean, max) rather than binary occupancy [S2, unofficial]. It serves as a foundational step for downstream rendering or reconstruction tasks [S1, unofficial].

## How it works
**Inputs:**
- `points`: A tensor or array of shape $[N, 3]$ containing 3D coordinates $(x, y, z)$ [S2, S3, S4, unofficial].
- `features` (optional): A tensor or array of shape $[N, F]$ containing per-point attributes (e.g., color, normal) [S2, unofficial].
- `voxel_size` or `grid_cell_size`: A scalar or vector $[s_x, s_y, s_z]$ defining the dimensions of each voxel cube [S1, S2, S4, unofficial].
- `origin` or `start_location` (optional): The minimum coordinate bound of the voxel grid. If not provided, it is computed as $\min(points)$ [S2, unofficial].

**Outputs:**
- `voxel_indices`: A sparse set of integer indices $(i, j, k)$ identifying occupied voxels [S2, S3, unofficial].
- `voxel_features` (optional): Aggregated features for each occupied voxel, shape $[N', F]$ where $N'$ is the number of occupied voxels [S2, unofficial].
- `voxel_centers`: The world coordinates of the center of each occupied voxel [S1, unofficial].

**Data Structures:**
- **Voxel Index**: A 3-tuple $(i, j, k)$ or a flattened integer ID.
- **Sparse Grid**: Implemented via hash maps (e.g., Python `dict`, TensorFlow `tf.TensorArray`) or sparse tensor formats to store only occupied entries [S2, S3, unofficial].
- **Open3D VoxelGrid**: A geometry object storing `origin`, `voxel_size`, and a list of `grid_index` tuples [S1, S3, unofficial].
- **PyntCloud Structures**: A dictionary-like attribute `structures` mapping structure names (e.g., "voxelgrid") to arrays of voxel IDs [S3, unofficial].

**Steps:**

1. **Load and Preprocess Point Cloud**:
   - Load points from supported formats (`.ply`, `.pcd`, `.xyz`, `.csv`, etc.) into a numerical array [S1, S3, S4, unofficial].
   - Validate input: Raise error if points are empty or lack 3 coordinates [S1, unofficial].
   - Optional: Downsample using voxel grid downsampling with `downsample_size` [S1, unofficial].
   - Optional: Remove statistical outliers using neighbor count `nb_neighbors` and standard deviation ratio `std_ratio` [S1, unofficial].

2. **Determine Grid Bounds and Origin**:
   - Compute `start_location` (origin) as the minimum coordinate of the point cloud:
     $$ \text{origin} = \min_{p \in \text{points}} p $$
     [S2, unofficial].
   - Define `end_location` or bounds if specified; otherwise, infer from point extent [S2, S4, unofficial].

3. **Map Points to Voxel Indices**:
   - For each point $p_n = (x_n, y_n, z_n)$, compute its voxel index $(i_n, j_n, k_n)$ using floor division:
     $$ i_n = \left\lfloor \frac{x_n - \text{origin}_x}{s_x} \right\rfloor, \quad j_n = \left\lfloor \frac{y_n - \text{origin}_y}{s_y} \right\rfloor, \quad k_n = \left\lfloor \frac{z_n - \text{origin}_z}{s_z} \right\rfloor $$
     [S2, unofficial].
   - Handle negative coordinates if `origin` is not the global minimum (e.g., if grid is centered) by adding an offset [G].

4. **Aggregate Features (Optional)**:
   - Group points by their voxel index.
   - Apply an aggregation function `segment_func` (e.g., mean, max, sum) to features within each voxel:
     $$ \text{voxel\_features}_v = \text{segment\_func}(\{ \text{features}_n \mid \text{index}_n = v \}) $$
     [S2, unofficial].
   - Compute unique voxel indices and their corresponding aggregated features [S2, unofficial].

5. **Construct Sparse Representation**:
   - Store only voxels with at least one point.
   - For Open3D: Create `VoxelGrid` object and add voxels [S1, S3, unofficial].
   - For PyntCloud: Call `add_structure("voxelgrid", ...)` to generate IDs [S3, unofficial].
   - For TensorFlow: Return sparse tensors or hash maps [S2, unofficial].
   - For Topogenesis: Create a `lattice` object with unit dimensions and bounds [S4, unofficial].

6. **Compute Voxel Centers (Optional)**:
   - For each occupied voxel index $(i, j, k)$, compute the world center:
     $$ c_x = \text{origin}_x + (i + 0.5) \cdot s_x $$
     $$ c_y = \text{origin}_y + (j + 0.5) \cdot s_y $$
     $$ c_z = \text{origin}_z + (k + 0.5) \cdot s_z $$
     [S1, unofficial].

**Pseudocode (Python-like, TensorFlow/NumPy hybrid):**

```python
import numpy as np
import tensorflow as tf

def pointcloud_to_sparse_voxel_grid(points, features=None, grid_cell_size=1.0, segment_func=tf.math.unsorted_segment_mean):
    """
    Converts a point cloud to a sparse voxel grid.
    
    Args:
        points: tf.float32 tensor of shape [N, 3].
        features: tf.float32 tensor of shape [N, F] (optional).
        grid_cell_size: float or tf.float32 tensor of shape [3].
        segment_func: Aggregation function for features.
        
    Returns:
        voxel_indices: tf.int32 tensor of shape [N', 3] (unique voxel indices).
        voxel_features: tf.float32 tensor of shape [N', F] (aggregated features).
        segment_ids: tf.int32 tensor of shape [N] (mapping points to voxels).
        voxel_start_location: tf.float32 tensor of shape [3] (origin).
    """
    # 1. Ensure inputs are tensors
    points = tf.convert_to_tensor(points, dtype=tf.float32)
    grid_cell_size = tf.convert_to_tensor(grid_cell_size, dtype=tf.float32)
    
    # 2. Compute origin (start location)
    voxel_start_location = tf.reduce_min(points, axis=0)
    
    # 3. Compute voxel indices for each point
    # Offset points by origin, then divide by cell size, then floor
    voxel_xyz_indices = tf.cast(
        tf.math.floordiv(points - voxel_start_location, grid_cell_size),
        dtype=tf.int32
    )
    
    # 4. Flatten indices to 1D segment IDs for aggregation
    # Assuming a 3D grid, flatten (i, j, k) to a single integer
    # This requires knowing grid dimensions or using a hash map. 
    # For unbatched sparse output, we use unsorted_segment operations with a large enough num_segments 
    # or a hash-based approach. Here we assume a dense-to-sparse mapping via segment IDs.
    # Note: In practice, for sparse grids, one might use a dictionary or sparse tensor.
    # This pseudocode follows the TensorFlow utility pattern [S2, unofficial].
    
    # Compute a unique ID for each voxel index (simplified for dense-to-sparse mapping)
    # In a real sparse implementation, this would be a hash map lookup.
    # For this example, we assume we can map to a large enough integer space or use 
    # tf.unique or similar. However, the source [S2, unofficial] uses unsorted_segment_max/mean 
    # which requires segment_ids. We generate segment_ids as the flattened voxel index.
    
    # Flatten 3D index to 1D ID. 
    # This is a simplification; in high-dimensional spaces, a hash map is preferred.
    # We assume grid_cell_size is uniform for simplicity in flattening, or use a tuple key.
    # TensorFlow's unsorted_segment_* works on 1D segment IDs.
    
    # Let's assume we map (i,j,k) to a unique integer ID. 
    # This is not directly possible without knowing bounds. 
    # The source [S2, unofficial] uses `compute_pooled_voxel_indices` which likely handles this.
    # We will simulate the segment ID generation.
    
    # For the purpose of this pseudocode, we assume `voxel_xyz_indices` are mapped to 
    # a 1D segment ID via a hash or pre-computed mapping. 
    # In the absence of a hash map in pure TF without custom ops, we might use 
    # tf.unique on the rows of voxel_xyz_indices.
    
    unique_indices, inverse_indices = tf.unique(tf.reshape(voxel_xyz_indices, [-1]))
    # This is a simplification. The actual implementation [S2, unofficial] uses a helper 
    # `compute_pooled_voxel_indices` to generate `voxel_single_number_indices`.
    
    # Let's use the direct segment ID from the source logic:
    # voxel_single_number_indices is generated by flattening the 3D index.
    # We assume a function `flatten_voxel_index` exists.
    
    # Re-implementing the core logic from [S2, unofficial] more faithfully:
    # voxel_xyz_indices is [N, 3].
    # We need to group by these indices.
    
    # Step 4 (Corrected): Use tf.unique to find unique voxels and map points to them.
    # This is a common pattern for sparse voxelization in TF.
    flat_indices = tf.reshape(voxel_xyz_indices, [-1])
    unique_flat, inverse_indices = tf.unique(flat_indices)
    
    # However, tf.unique on 3D points requires reshaping. 
    # A more robust way is to use a hash map or dictionary in Python.
    # Since we must write valid Python, we'll use a dictionary for the sparse mapping.
    
    voxel_map = {}
    segment_ids = np.zeros(points.shape[0], dtype=np.int32)
    current_id = 0
    
    for idx, point_idx in enumerate(voxel_xyz_indices.numpy()):
        key = tuple(point_idx)
        if key not in voxel_map:
            voxel_map[key] = current_id
            current_id += 1
        segment_ids[idx] = voxel_map[key]
        
    segment_ids = tf.constant(segment_ids, dtype=tf.int32)
    num_segments = current_id
    
    # 5. Aggregate features
    if features is not None:
        features = tf.convert_to_tensor(features, dtype=tf.float32)
        voxel_features = segment_func(
            data=features, 
            segment_ids=segment_ids, 
            num_segments=num_segments
        )
    else:
        voxel_features = None
        
    # 6. Get unique voxel indices
    voxel_indices = tf.constant(list(voxel_map.keys()), dtype=tf.int32)
    
    return voxel_indices, voxel_features, segment_ids, voxel_start_location
```

**Parameters:**
- `voxel_size`: Default 0.05 in Open3D GUI [S1, unofficial].
- `downsample_size`: Default 0.03 [S1, unofficial].
- `nb_neighbors`: Default 20 [S1, unofficial].
- `std_ratio`: Default 2.0 [S1, unofficial].
- `grid_cell_size`: Can be a scalar or vector $[s_x, s_y, s_z]$ [S2, S4, unofficial].

**Edge Cases and Pitfalls:**
- Empty point clouds raise `ValueError` [S1, unofficial].
- CSV/TXT files with fewer than 3 numeric columns raise `ValueError` [S1, unofficial].
- Large coordinate values (e.g., $10^5$) with small voxel sizes can lead to large integer indices; ensure data types support this [S4, unofficial].
- Precision issues in floor division for points near voxel boundaries [G].

## Operating characteristics
- **Time Complexity**: $O(N)$ for mapping points to voxels, where $N$ is the number of points. Aggregation is $O(N)$ on average with hash maps.
- **Memory Complexity**: $O(V)$, where $V$ is the number of occupied voxels. Sparse representation avoids $O(R^3)$ for resolution $R$.
- **Performance**: Efficient for sparse scenes. Dense scenes may approach dense voxelization memory usage.
- **Strengths**: Memory efficient for sparse data; supports feature aggregation.
- **Limitations**: Voxel size is fixed; may lose fine details if too large. Hash map overhead in some implementations.
- **When to use**: When point cloud is sparse or when feature aggregation is needed.
- **When not to use**: When dense occupancy is required or when voxel size is not appropriate for the scale of features.

## Background
Originating from early 3D graphics and robotics for spatial representation [S1, unofficial], this method is widely used in Open3D [S1, S3, unofficial], TensorFlow 3D utilities [S2, unofficial], PyntCloud [S3, unofficial], and Topogenesis [S4, unofficial]. It is a standard preprocessing step for 3D deep learning and rendering pipelines.
