# Multi-Plane Point Cloud Voxelization and Weight Aggregation

Also called: MPP Aggregation, MPP Voxelization, Pre-processing for Neural Point Cloud Rendering via Multi-Plane Projection

## Overview
A pre-processing pipeline that projects a 3D point cloud onto multiple parallel planes (voxels) based on depth, groups points by their projected 2D grid location and depth bin, and computes aggregation weights for rendering [S1, unofficial]. It solves the problem of efficiently organizing sparse point cloud data for multi-plane projection rendering by reducing outliers and grouping points spatially [S1, unofficial]. Unlike standard point cloud rasterization which may suffer from z-fighting or require complex sorting, this method aggregates points into discrete depth bins and blends them front-to-back using a visibility mask [S1, unofficial].

## How it works
**Inputs:**
- Point cloud file (PLY format) containing positions $(x, y, z)$ and colors $(r, g, b)$.
- Camera intrinsics matrices for color and depth cameras (`intrinsic_color.txt`, `intrinsic_depth.txt`).
- Camera extrinsics matrices for color and depth cameras (`extrinsic_color.txt`, `extrinsic_depth.txt`).
- Pose index file (`index.txt`).
- Target image resolution $(W, H)$ (default 640x480).
- Number of planes $N$ (default 32).
- Hyperparameters $a$ (parallel distance weight, default 1) and $b$ (vertical distance weight, default 1).

**Outputs:**
- NPZ file containing:
  - `u`, `v`: float32, pixel coordinates.
  - `d`: float32, depth.
  - `select_index`: int64, original point indices.
  - `group_belongs`: int64, group ID.
  - `index_in_each_group`: uint16, index within group.
  - `distance`: float32, parallel distance.
  - `each_split_max_num`: uint16, max points per plane.
  - `delta`: float32, plane depth differences.

**Data Structures:**
- Points are stored as arrays of shape $(N_{pts}, 4)$ for positions (homogeneous $[x, y, z, 1]$) and $(N_{pts}, 3)$ for colors (BGR).
- Camera matrices are $4 \times 4$ float32 arrays.
- Depth boundaries are stored as an array of size $N+1$.

**Steps:**

1. **Load Point Cloud:**
   Parse the PLY file. Skip lines until `end_header`. For each subsequent line, split by space. Extract position as $[x, y, z, 1.0]$ and color as $[b, g, r]$ (converting RGB to BGR by reordering indices 3, 4, 5 to 5, 4, 3). Return transposed numpy arrays for positions and colors [S1, unofficial].

2. **Load and Adjust Camera Parameters:**
   Read intrinsic and extrinsic matrices from text files. Each file contains 4 lines of space-separated floats, reshaped into $4 \times 4$ float32 arrays. If image resizing is enabled, adjust intrinsic matrices. Calculate scale factors:
   $$
   s_{1c} = \frac{1296 - 1}{W - 1}, \quad s_{2c} = \frac{968 - 1}{H - 1}
   $$
   for color, and similar $s_{1d}, s_{2d}$ for depth. Divide the first two rows of the intrinsic matrices by these scales to map from original resolution (1296x968 or 640x480) to target resolution $(W, H)$ [S1, unofficial].

3. **Project to Image Space:**
   Compute the projection matrix $P = K \cdot E^{-1}$, where $K$ is the intrinsic matrix and $E$ is the extrinsic matrix. Transform points:
   $$
   P_{img} = P \cdot P_{world}
   $$
   Extract depth $z_{all} = P_{img}[2, :]$. Compute pixel coordinates:
   $$
   u_{all} = \frac{P_{img}[0, :]}{z_{all} + \epsilon}, \quad v_{all} = \frac{P_{img}[1, :]}{z_{all} + \epsilon}
   $$
   where $\epsilon = 10^{-10}$ to prevent division by zero [S1, unofficial].

4. **Filter Valid Points:**
   Identify valid indices where:
   - $0 \le u_{all} < W$
   - $0 \le v_{all} < H$
   - $d_{near} < z_{all} < d_{far}$
   Intersect these conditions to get `valid_position`. Sort selected points by depth in descending order using `np.argsort(-selected_depth)` [S1, unofficial].

5. **Remove Outliers:**
   From the sorted indices, remove the 100 furthest and 50 nearest points to reduce outlier influence:
   $$
   \text{index} = \text{index}[100:-50]
   $$
   [S1, unofficial].

   Round $u$ and $v$ to nearest integer:
   $$

   $$

7. **Define Depth Bins:**
   Get $d_{min}$ and $d_{max}$ from the sorted valid depths. Create $N+1$ linearly spaced boundaries:
   $$
   \text{depth\_tmp} = \text{linspace}(d_{max}, d_{min}, N+1)
   $$
   Randomly sample one boundary per plane bin:
   $$
   \text{tmp}[bin] = \text{uniform}(\text{depth\_tmp}[bin], \text{depth\_tmp}[bin+1])
   $$
   Compute delta for each plane:
   $$
   \delta[bin] = \text{tmp}[bin] - \text{tmp}[bin+1]
   $$
   for $bin \in [0, N-2]$, then flip delta [S1, unofficial].

8. **Assign Points to Planes:**
   Initialize `up_boundary` with `tmp`. Iterate through sorted points. For each point with depth $z_i$, find the plane index $p_i$ such that:
   $$
   z_i \ge \text{up\_boundary}[cnt]
   $$
   Increment `cnt` and check subsequent boundaries until the condition is met. The plane index is $N - cnt - 1$ [S1, unofficial].

9. **Group Points by Voxel:**
   Compute group key:
   $$
   \text{key} = u_{sorted} + v_{sorted} \cdot W + p_i \cdot W \cdot H
   $$
   Sort points by this key. Assign group IDs: iterate through sorted groups. When the key changes, assign the current group ID to all points in the previous group. Store start indices. Assign sequential indices within each group [S1, unofficial].

10. **Compute Aggregation Weights:**
    For each group, calculate:
    - Parallel weight: $w_1 = (1 - \text{distance})^a$
    - Vertical weight: $w_2 = \frac{1}{(1 + \text{distance}_1)^b}$, where $\text{distance}_1$ is the vertical distance to the minimum depth in the group.
    - Renewed weight: $w_{renew} = w_1 \cdot w_2$
    Normalize weights per group by dividing by the sum of weights in the group [S1, unofficial].

```python
import numpy as np

def load_ply(ply_path):
    position = []
    color = []
    with open(ply_path, 'r') as f:
        begin = False
        for line in f:
            line = line.strip('\n')
            if not line:
                break
            parts = line.split(' ')
            if parts[0] == 'end_header':
                begin = True
                continue
            if begin:
                # PLY format: x y z r g b ...
                # Convert RGB to BGR
                pos = [float(parts[0]), float(parts[1]), float(parts[2]), 1.0]
                col = [float(parts[5]), float(parts[4]), float(parts[3])]
                position.append(pos)
                color.append(col)
    return np.array(position).T, np.array(color).T

def load_camera_params(intrinsic_path, extrinsic_path):
    # Load 4x4 matrices from text files
    K = np.loadtxt(intrinsic_path).reshape(4, 4).astype(np.float32)
    E = np.loadtxt(extrinsic_path).reshape(4, 4).astype(np.float32)
    # Camera coordinate system transformation
    E[:, [1, 2]] = E[:, [1, 2]] * (-1.0)
    return K, E

def adjust_intrinsics(K, target_w, target_h, orig_w=1296, orig_h=968):
    s1 = (orig_w - 1) / (target_w - 1)
    s2 = (orig_h - 1) / (target_h - 1)
    K[0, :] /= s1
    K[1, :] /= s2
    return K

def project_and_filter(positions, colors, K, E, W, H, d_near, d_far, num_planes=32, a=1, b=1):
    # Project
    P = K @ np.linalg.inv(E)
    pos_img = P @ positions
    z_all = pos_img[2, :]
    eps = 1e-10
    u_all = pos_img[0, :] / (z_all + eps)
    v_all = pos_img[1, :] / (z_all + eps)
    
    # Filter
    valid_u = (u_all >= 0) & (u_all < W)
    valid_v = (v_all >= 0) & (v_all < H)
    valid_d = (z_all > d_near) & (z_all < d_far)
    valid_idx = np.where(valid_u & valid_v & valid_d)[0]
    
    if len(valid_idx) == 0:
        return None
        
    selected_pos = positions[:, valid_idx]
    selected_col = colors[:, valid_idx]
    selected_z = z_all[valid_idx]
    selected_u = u_all[valid_idx]
    selected_v = v_all[valid_idx]
    
    # Sort by depth descending
    sort_idx = np.argsort(-selected_z)
    selected_z = selected_z[sort_idx]
    selected_u = selected_u[sort_idx]
    selected_v = selected_v[sort_idx]
    selected_pos = selected_pos[:, sort_idx]
    selected_col = selected_col[:, sort_idx]
    
    # Remove outliers
    if len(selected_z) > 150:
        selected_z = selected_z[100:-50]
        selected_u = selected_u[100:-50]
        selected_v = selected_v[100:-50]
        selected_pos = selected_pos[:, 100:-50]
        selected_col = selected_col[:, 100:-50]
        valid_idx = valid_idx[sort_idx][100:-50]
    else:
        valid_idx = valid_idx[sort_idx]
        
    # Round coordinates
    u_sorted = np.uint32(np.rint(selected_u))
    v_sorted = np.uint32(np.rint(selected_v))
    
    # Parallel distance (assuming image center)
    center_u = W / 2.0
    center_v = H / 2.0
    distance = np.sqrt((u_sorted - center_u)**2 + (v_sorted - center_v)**2)
    
    # Depth bins
    d_min = np.min(selected_z)
    d_max = np.max(selected_z)
    depth_tmp = np.linspace(d_max, d_min, num_planes + 1)
    tmp = np.zeros(num_planes)
    for bin_idx in range(num_planes):
        tmp[bin_idx] = np.random.uniform(depth_tmp[bin_idx], depth_tmp[bin_idx+1])
        
    delta = np.zeros(num_planes - 1)
    for bin_idx in range(num_planes - 1):
        delta[bin_idx] = tmp[bin_idx] - tmp[bin_idx+1]
    delta = np.flip(delta)
    
    # Assign planes
    d_position = np.zeros(len(selected_z), dtype=np.int32)
    up_boundary = tmp
    for i in range(len(selected_z)):
        cnt = 0
        while cnt < num_planes:
            if selected_z[i] >= up_boundary[cnt]:
                d_position[i] = num_planes - cnt - 1
                break
            cnt += 1
            
    # Grouping
    group_key = u_sorted + v_sorted * W + d_position * W * H
    sort_key_idx = np.argsort(group_key)
    sorted_key = group_key[sort_key_idx]
    
    group_belongs = np.zeros(len(selected_z), dtype=np.int64)
    index_in_group = np.zeros(len(selected_z), dtype=np.uint16)
    
    current_group_id = 0
    group_begin = 0
    for i in range(1, len(sorted_key)):
        if sorted_key[i] != sorted_key[i-1]:
            # Assign group ID to previous group
            count = i - group_begin
            group_belongs[sort_key_idx[group_begin:i]] = current_group_id
            index_in_group[sort_key_idx[group_begin:i]] = np.arange(count, dtype=np.uint16)
            current_group_id += 1
            group_begin = i
            
    # Last group
    count = len(sorted_key) - group_begin
    group_belongs[sort_key_idx[group_begin:]] = current_group_id
    index_in_group[sort_key_idx[group_begin:]] = np.arange(count, dtype=np.uint16)
    
    # Weights
    # Vertical distance to min depth in group
    # This requires grouping logic to find min depth per group
    # Simplified: assume distance_1 is relative depth within group
    # Source says: distance_1 is vertical distance to minimum depth in the group
    # We need to compute min depth per group
    
    unique_groups = np.unique(group_belongs)
    vertical_distances = np.zeros(len(selected_z))
    
    for g in unique_groups:
        mask = group_belongs == g
        group_z = selected_z[mask]
        min_z = np.min(group_z)
        vertical_distances[mask] = selected_z[mask] - min_z
        
    weight_1 = (1 - distance)**a
    weight_2 = 1.0 / (1 + vertical_distances)**b
    weight_renew = weight_1 * weight_2
    
    # Normalize per group
    for g in unique_groups:
        mask = group_belongs == g
        sum_w = np.sum(weight_renew[mask])
        if sum_w > 0:
            weight_renew[mask] /= sum_w
            
    # Output
    return {
        'u': selected_u,
        'v': selected_v,
        'd': selected_z,
        'select_index': valid_idx,
        'group_belongs': group_belongs,
        'index_in_each_group': index_in_group,
        'distance': distance,
        'delta': delta
    }
```

## Subtopics

### [Multi-Plane Image (MPI) Rendering from Point Clouds](12104-multi-plane-image-mpi-rendering-from-point-clouds.md)
Multi-Plane Image (MPI) Rendering from Point Clouds is a technique that converts a 3D point cloud into a set of 2D image planes (MPI) to enable efficient rendering with occlusion handling. It solves the problem of projecting sparse 3D data onto a 2D target grid while resolving depth conflicts between planes. Unlike standard point cloud rasterization which may suffer from z-fighting or require complex sorting, this method aggregates points into discrete depth bins and blends them front-to-back using a visibility mask.

### [Frustum Voxelization and Feature Aggregation](15511-frustum-voxelization-and-feature-aggregation.md)
Frustum Voxelization and Feature Aggregation is a pre-processing method that maps a 3D point cloud into a structured 3D volume aligned with the camera frustum to facilitate multi-plane rendering. It solves the problem of organizing sparse, unstructured point cloud data into a dense grid suitable for convolutional neural networks by assigning points to voxels based on their spatial proximity to pixel centers and depth planes. It differs from its parent method, [Multi-Plane Point Cloud Voxelization and Weight Aggregation](12101-multi-plane-point-cloud-voxelization-and-weight-aggregation.md), by explicitly defining the voxel grid boundaries using the camera's near and far clipping planes and calculating aggregation weights based on both parallel (pixel-space) and vertical (depth) distances, rather than simple depth binning.

## Operating characteristics
- **Time Complexity:** Dominated by sorting points by depth and grouping keys, $O(N \log N)$ where $N$ is the number of valid points.
- **Memory Complexity:** $O(N)$ for storing point attributes and group indices.
- **Performance:** Efficient for sparse point clouds. Reduces outlier influence by trimming nearest/farthest points.
- **Strengths:** Simple implementation, handles sparse data well, reduces z-fighting by discretizing depth.
- **Limitations:** Discrete depth bins may cause aliasing if not randomized. Sensitive to camera calibration errors.
- **When to use:** Pre-processing for neural rendering pipelines like PCMP-NeRF.
- **When not to use:** When continuous depth representation is required or for dense meshes.
