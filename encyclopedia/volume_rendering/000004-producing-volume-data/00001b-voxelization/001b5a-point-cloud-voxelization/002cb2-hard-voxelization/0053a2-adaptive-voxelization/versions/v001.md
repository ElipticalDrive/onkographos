# Adaptive Voxelization
Also called: Adaptive Voxelization for 3DGS
## Overview
Adaptive Voxelization is a discretization technique for 3D Gaussian Splatting (3DGS) data that dynamically adjusts voxel resolution based on Gaussian volume and spatial redundancy to reduce the number of Gaussians and encoding bitrate [S1]. Unlike uniform voxelization, which applies a fixed maximum octree depth to all regions, this method assigns high resolution to large-volume Gaussians and low resolution to dense regions of small Gaussians, avoiding the large positional errors and excessive bitrate associated with uniform approaches [S1].
## How it works
### Inputs and Outputs
**Inputs:**
- A set of $N$ 3D Gaussians $\{G_i\}_{i=1}^N$, where each $G_i$ is defined by mean $\mu_i$, covariance $\Sigma_i$, spherical harmonics coefficients, and opacity [S1].
- Bounding box side length $W$ (assuming a cubic bounding box $W \times W \times W$) [S1].
- Parameters: $J_{high}$ (maximum octree depth), $J_{low}$ (minimum octree depth for uniform phase), $v$ (percentage of largest Gaussians), $\tau_1$ (count threshold), $\tau_2$ (distance threshold) [S1].

**Outputs:**
- A pruned octree structure where each leaf node contains a single representative Gaussian $G^*$ (mean $\mu^*$, covariance $\Sigma^*$, etc.) derived from the merged Gaussians in that voxel [S1].
- The total number of Gaussians is reduced compared to the input set [S1].

### Data Structures
The method uses an octree structure. Each node in the octree represents a voxel.
- **Node:** Contains a list of assigned Gaussian indices or a merged Gaussian if it is a leaf.
- **Leaf Node:** Represents a voxel at a specific depth $J$. The voxel volume is $(W/2^J)^3$ [S1].
- **Gaussian Attributes:** Mean $\mu_i$, covariance $\Sigma_i$ (or scale $s_i$), SH coefficients, opacity [S1].

### Parameters and Typical Values
- $J_{high}$: Maximum octree depth. Typical values: 16 or 18 [S1].
- $J_{low}$: Minimum octree depth for the uniform phase. Typical values: 8 [S1].
- $v$: Percentage of largest Gaussians (by volume) assigned to $J_{high}$. Not given in the sources.
- $\tau_1$: Threshold for the number of Gaussians in a voxel to trigger further partitioning. Typical value: 5 [S1].
- $\tau_2$: Threshold for the distance of original Gaussian means to the voxel center. Defined as half the voxel size: $W/2^{J+1}$, where $J$ is the current depth [S1].

### Steps
1. **Volume Calculation:** Compute the volume $V_i$ for each Gaussian $G_i$. The volume is calculated as $V_i = s_i^{(x)} \times s_i^{(y)} \times s_i^{(z)}$, where $s_i^{(x)}, s_i^{(y)}, s_i^{(z)}$ are the scale parameters along the axes [S1].
2. **High-Resolution Assignment:** Identify the largest $v\%$ of Gaussians based on volume $V_i$. Assign these Gaussians to the highest possible resolution $J_{high}$ [S1].
3. **Uniform Voxelization (Low Resolution):** Voxelize the remaining Gaussians uniformly up to a depth of $J_{low}$ [S1]. This involves mapping each Gaussian to a voxel at depth $J_{low}$ using the coordinate mapping formula from Hard Voxelization [S1, S2, S3, unofficial].
4. **Adaptive Partitioning:** For voxels at depths greater than $J_{low}$, determine if further partitioning is needed based on two criteria [S1]:
    - **Count Criterion:** If the number of Gaussians in the voxel exceeds $\tau_1$.
    - **Distance Criterion:** If the distance of the original Gaussian means to the voxel center is larger than $\tau_2 = W/2^{J+1}$, where $J$ is the current depth [S1].
    - If either criterion is met, partition the voxel into 8 sub-voxels (increasing depth by 1) and reassign the Gaussians to the sub-voxels. Repeat the criteria check for the sub-voxels until the maximum depth $J_{high}$ is reached or criteria are not met.
5. **Merging:** For each leaf voxel in the final octree, merge the assigned Gaussians into a single representative Gaussian $G^* \sim \mathcal{N}(\mu^*, \Sigma^*)$. The mean $\mu^*$ is the centroid of the assigned Gaussians: $\mu^* = \frac{1}{k} \sum_{i=1}^k \mu_i$, where $k$ is the number of Gaussians in the voxel [S1]. The covariance $\Sigma^*$ is approximated or computed using simpler criteria to avoid the computationally expensive iterative algorithm for the 2-Wasserstein barycenter [S1]. The SH coefficients and opacity are averaged [S1].

### Edge Cases and Pitfalls
- **Uniform Voxelization Errors:** Uniform voxelization introduces large errors by producing large displacements in high-volume Gaussians while spending excessive bitrate in dense regions containing low-volume Gaussians [S1].
- **Computational Cost:** Computing the 2-Wasserstein barycenter for covariance merging is computationally expensive. This method avoids it by using simpler criteria (volume, count, distance) [S1].
- **Boundary Handling:** Points with coordinates outside the bounding box are discarded [S1, S2, unofficial].

## Operating characteristics
- **Time Complexity:** The method is more efficient than computing the 2-Wasserstein barycenter, reducing runtime by approximately a factor of 15 [S1]. The complexity depends on the number of Gaussians and the depth of the octree.
- **Memory Complexity:** The output is a reduced set of Gaussians, leading to lower memory usage compared to the input.
- **Performance:** Bitrate savings of up to 13.42% for the Playroom scene and 12.64% for the Truck scene compared to uniform voxelization [S1]. Average PSNR gain of 0.08 dB for Playroom and 0.19 dB for Truck [S1].
- **Strengths:** Reduces the number of Gaussians and bitrate while preserving rendering quality. Adapts to non-uniform point density and Gaussian volume [S1].
- **Limitations:** Requires tuning of parameters ($J_{high}, J_{low}, v, \tau_1, \tau_2$). The approximation of covariance may introduce some error compared to the optimal W2-Barycenter [S1].

## Background
Adaptive Voxelization was proposed in the paper "Adaptive Voxelization for Transform Coding of 3D Gaussian Splatting Data" [S1]. It addresses the inefficiencies of uniform voxelization used in point cloud codecs (like GPCC) and post-training 3DGS compression approaches [S1]. The method is tailored to 3DGS data, considering the relative importance of Gaussians based on their volume [S1].
