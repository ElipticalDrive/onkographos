# Point Cloud Simplification via Voxel-based Probabilistic Sub-sampling

Also called: Uniform voxel sampling, Voxel-based point cloud downsampling

## Overview
This method reduces point cloud density by grouping points into a 3D grid and probabilistically selecting a fixed number of points per voxel [S1, unofficial]. It addresses the computational bottleneck of processing large-scale point clouds in volume rendering pipelines by ensuring uniform spatial distribution while preserving local density characteristics [S1, unofficial]. Unlike deterministic hard voxelization which may arbitrarily discard points or retain all, this approach guarantees a controlled output size per voxel through random sampling weighted by the inverse of the local point count [S1, unofficial].

## How it works
**Inputs and Outputs:**
- **Input:** A point cloud dataset containing positions $(x, y, z)$ and optional features (e.g., RGB color, descriptors). The data is typically stored in ASCII `.ply` format with headers specifying vertex counts and property types (float32 for coordinates, uchar for color) [S1, unofficial].
- **Parameters:**
  - `side_len`: Voxel side length in meters. Typical value is 0.01 m, though 0.02, 0.03, 0.05, and 0.1 are used depending on scene scale [S1, unofficial].
  - `num_in_each_voxel` (code: `num_in_each_box`): The maximum number of points to retain per voxel. Typical value is 20, with examples showing 30, 15, 5, 3, 2, or 1 [S1, unofficial].
- **Output:** A simplified point cloud with reduced density, maintaining the original feature structure for retained points [S1, unofficial].

**Data Structures:**
- `position_color`: Array of shape $(N, D)$, where $N$ is the number of input points and $D$ is the dimensionality of position plus features (e.g., 6 for XYZ + RGB) [S1, unofficial].
- `index`: Integer array of shape $(N)$ storing the computed voxel index for each point [S1, unofficial].
- `select_probabilities`: Float array of shape $(N)$ storing the probability of selection for each point [S1, unofficial].
- `random`: Float array of shape $(N)$ storing uniform random numbers for comparison [S1, unofficial].

**Steps:**
1. **Compute Bounding Box:** Determine the minimum and maximum coordinates along each axis ($x_{min}, x_{max}, y_{min}, y_{max}, z_{min}, z_{max}$) from the input point cloud [S1, unofficial].
2. **Calculate Grid Dimensions:** Compute the number of voxels along each axis. Using the side length `side_len`:
   $$
   \text{num}_x = \max(\lfloor \frac{x_{max} - x_{min}}{\text{side\_len}} \rfloor) + 1
   $$
   Similarly for $\text{num}_y$ and $\text{num}_z$. Note: The source code uses `np.rint` (round to nearest integer) on the normalized coordinates before summation, effectively implementing a floor-like behavior for positive offsets relative to min [S1, unofficial].
3. **Compute Voxel Indices:** For each point $i$ with coordinates $(x_i, y_i, z_i)$, calculate a unique linear voxel index:
   $$
   \text{index}_i = \text{round}\left(\frac{x_i - x_{min}}{\text{side\_len}}\right) + \text{round}\left(\frac{y_i - y_{min}}{\text{side\_len}}\right) \cdot \text{num}_x + \text{round}\left(\frac{z_i - z_{min}}{\text{side\_len}}\right) \cdot \text{num}_x \cdot \text{num}_y
   $$
   [S1, unofficial]. This maps 3D coordinates to a 1D array index for efficient sorting.
4. **Sort Points:** Sort the points based on their voxel indices to group points belonging to the same voxel contiguously in memory. Apply the same permutation to the `position_color` array [S1, unofficial].
5. **Initialize Probabilities:** Create an array `select_probabilities` of size $N$ initialized to zero [S1, unofficial].
6. **Assign Selection Probabilities:** Iterate through the sorted points to identify ranges belonging to each voxel. For a voxel containing $C$ points (from index $cnt\_l$ to $cnt\_r$ in the sorted array), set the selection probability for all points in that range to:
   $$
   P = \frac{\text{num\_in\_each\_voxel}}{C}
   $$
   If $P > 1$, it is capped or handled such that all points are selected (though the source implies the formula is applied directly, and random sampling handles the rest) [S1, unofficial]. Specifically, the code sets `select_probabilities[cnt_l:cnt_r] = num_in_each_box / (cnt_r - cnt_l)` [S1, unofficial].
7. **Generate Random Numbers:** Create an array `random` of size $N$ with values drawn from a uniform distribution $U(0, 1)$ [S1, unofficial].
8. **Select Points:** Iterate through the sorted points. If `select_probabilities[i] > random[i]`, retain the point. Copy retained points to the output array and increment a counter [S1, unofficial].

**Pseudocode:**
```python
import numpy as np

def voxel_probabilistic_subsampling(position_color, side_len, num_in_each_voxel):
    """
    Simplifies a point cloud using voxel-based probabilistic subsampling.
    
    Args:
        position_color: np.array of shape (N, D), where D >= 3. 
                        Columns 0-2 are x, y, z coordinates.
        side_len: float, voxel side length in meters.
        num_in_each_voxel: int, max points to keep per voxel.
        
    Returns:
        simplified_position_color: np.array of shape (M, D), simplified point cloud.
    """
    N = position_color.shape[0]
    if N == 0:
        return np.empty((0, position_color.shape[1]))

    # 1. Compute Bounding Box
    coords = position_color[:, :3]
    min_x, min_y, min_z = np.min(coords, axis=0)
    max_x, max_y, max_z = np.max(coords, axis=0)

    # 2. Calculate Grid Dimensions
    # Using rint as per source code logic for index calculation consistency
    num_x = int(np.max(np.rint((max_x - min_x) / side_len))) + 1
    num_y = int(np.max(np.rint((max_y - min_y) / side_len))) + 1
    num_z = int(np.max(np.rint((max_z - min_z) / side_len))) + 1

    # 3. Compute Voxel Indices
    # Note: Source uses np.rint for coordinate normalization
    x_idx = np.rint((coords[:, 0] - min_x) / side_len).astype(int)
    y_idx = np.rint((coords[:, 1] - min_y) / side_len).astype(int)
    z_idx = np.rint((coords[:, 2] - min_z) / side_len).astype(int)
    
    index = x_idx + y_idx * num_x + z_idx * num_x * num_y

    # 4. Sort Points by Voxel Index
    sort_indices = np.argsort(index)
    index = index[sort_indices]
    sorted_position_color = position_color[sort_indices]

    # 5. Initialize Probability Array
    select_probabilities = np.zeros(N)

    # 6. Assign Selection Probabilities
    # Iterate through sorted points to find boundaries of each voxel group
    cnt_l = 0
    while cnt_l < N:
        # Find the end of the current voxel group
        # Since points are sorted by index, identical indices are contiguous
        # We need to find the first index different from index[cnt_l]
        current_idx = index[cnt_l]
        
        # Binary search or linear scan for the end of the group
        # Linear scan is safer for correctness in this context
        cnt_r = cnt_l
        while cnt_r < N and index[cnt_r] == current_idx:
            cnt_r += 1
            
        # Number of points in this voxel
        count_in_voxel = cnt_r - cnt_l
        
        # Probability is num_in_each_voxel / count_in_voxel
        # If count_in_voxel <= num_in_each_voxel, probability is >= 1, 
        # meaning all points are selected (since random < 1).
        prob = num_in_each_voxel / count_in_voxel
        
        # Assign probability to all points in this voxel group
        select_probabilities[cnt_l:cnt_r] = prob
        
        cnt_l = cnt_r

    # 7. Generate Random Numbers
    random_vals = np.random.uniform(0, 1, N)

    # 8. Select Points
    # Condition: select_probability > random[i]
    # Note: If prob >= 1, it is always > random[i] (since random[i] < 1), so all selected.
    # If prob < 1, it is selected with probability prob.
    mask = select_probabilities > random_vals
    
    simplified_position_color = sorted_position_color[mask]

    return simplified_position_color
```

**Edge Cases and Pitfalls:**
- **Out of Memory:** Large scenes with high resolution (`side_len` too small) or high point density can cause excessive voxel counts or array sizes, leading to memory errors. The recommended mitigation is dividing the scene into smaller parts and processing them separately [S1, unofficial].
- **Last Voxel Group:** The iteration loop must correctly handle the final voxel group. The source code uses an `else` branch or loop termination condition to ensure the last group is processed without index out-of-bounds errors [S1, unofficial].
- **Precision:** Using `np.rint` instead of `np.floor` may affect boundary handling. Implementers should ensure consistency with the source's rounding behavior if exact reproducibility is required [S1, unofficial].

## Operating characteristics
- **Time Complexity:** Dominated by the sorting step, $O(N \log N)$ for $N$ points. The subsequent linear scan and random generation are $O(N)$ [S1, unofficial].
- **Memory Complexity:** $O(N)$ for storing position, color, index, and probability arrays [S1, unofficial].
- **Performance:** Effective for reducing point cloud size while maintaining spatial uniformity. Performance scales with the number of points and the complexity of the scene (number of occupied voxels) [S1, unofficial].
- **Strengths:** Guarantees a bounded number of points per voxel, which is beneficial for downstream neural network inputs that expect fixed-size or bounded-size features. Preserves local density information probabilistically.
- **Limitations:** Introduces randomness, so results are not deterministic across runs unless a fixed seed is used. May discard points in dense regions if the random draw is unfavorable, though the probability weighting mitigates this. Not suitable for applications requiring exact geometric preservation of every point.

## Background
This method was introduced in the context of "Rendering via Multi-plane NeRF" by Dongmei Ma, Juan Cao, and Zhonggui Chen (CGI 2023) [S1, unofficial]. It is part of a preprocessing pipeline for large-scale point cloud data used in neural radiance field (NeRF) rendering, specifically for datasets like ScanNet [S1, unofficial]. The technique is implemented in the GitHub repository `Mayxmu/PCMP-NeRF` [S1, unofficial].
