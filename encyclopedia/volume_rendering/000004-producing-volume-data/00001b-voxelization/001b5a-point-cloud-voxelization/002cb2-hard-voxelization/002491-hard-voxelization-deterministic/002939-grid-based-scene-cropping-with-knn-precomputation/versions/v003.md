# Grid-based Scene Cropping with KNN Precomputation

Also called: scene_crop_pointcloud dataset, voxel KNN grouping

## Overview
This method generates cropped point cloud datasets by dividing a normalized 3D scene into a structured grid, applying padding, and precomputing K-nearest neighbor (KNN) relationships for both input points and grid voxels to facilitate local feature grouping [S1, unofficial]. It solves the problem of preparing fixed-size, spatially coherent data structures with relative coordinate offsets for deep learning models [S1, unofficial]. It differs from its siblings, [Fast Deterministic GPU Voxelization (Sort-Scatter)](3806-fast-deterministic-gpu-voxelization-sort-scatter.md) and [Grid Pooling (Max Pooling over Points)](4327-grid-pooling-max-pooling-over-points.md), by explicitly precomputing KNN indices and relative coordinates for both points and voxels within a cropped region [S1, unofficial].

## How it works
**Inputs and Outputs:**
* **Input:** A set of 3D points normalized to a unit cube $[-1, 1]^3$.
* **Outputs:**
    * `pc_KNN_idx`: 1D array of shape $[N_{pc} \times K]$, storing indices of KNN points [S1, unofficial].
    * `pc_KNN_xyz`: 1D array of shape $[N_{pc} \times K, 3]$, storing relative coordinates of KNN points to the query point [S1, unofficial].
    * `voxel_xyz_int`: 1D array of shape $[N_{vox}]$, storing integer coordinates of active voxels [S1, unofficial].
    * `voxel_KNN_idx`: 1D array of shape $[N_{vox} \times K]$, storing indices of KNN points for each active voxel [S1, unofficial].
    * `voxel_KNN_xyz`: 1D array of shape $[N_{vox} \times K, 3]$, storing relative coordinates of KNN points to each voxel [S1, unofficial].

**Parameters:**
* `input_point_num`: Number of points to sample per crop for training [S1, unofficial].
* `output_grid_size`: Base grid resolution per crop dimension (e.g., 32 or 64) [S1, unofficial].
* `KNN_num`: Number of nearest neighbors to query ($K$) [S1, unofficial].
* `pooling_radius`: Radius for morphological dilation of the voxel grid to expand active cells [S1, unofficial].
* `block_padding`: Padding added to crop bounds in grid units [S1, unofficial].

**Steps:**
1. **Normalization and Grid Setup:** Normalize input points to the unit cube. Scale coordinates by `block_num_per_dim` and multiply by `output_grid_size` to determine grid dimensions [S1, unofficial].
2. **Crop Extraction:** For each grid index $(i, j, k)$, extract points within the bounds defined by the grid cell extended by `block_padding`. The condition for a point $p$ to be included in crop $(i, j, k)$ is:
   $$
   \begin{aligned}
   & i \cdot G - P < p_x < (i+1) \cdot G + P \\
   & j \cdot G - P < p_y < (j+1) \cdot G + P \\
   & k \cdot G - P < p_z < (k+1) \cdot G + P
   \end{aligned}
   $$
   where $G$ is `output_grid_size` and $P$ is `block_padding` [S1, unofficial].
3. **Empty Check:** If the number of extracted points is less than 100, return arrays of shape $[1]$ filled with zeros to avoid empty batches [S1, unofficial].
4. **Local Coordinate Shift:** Shift extracted points to local coordinates relative to the crop origin [S1, unofficial].
5. **Sampling:** Shuffle the extracted points and sample `input_point_num` points [S1, unofficial].
6. **Voxel Grid Construction:** Create a 3D boolean grid of size `output_grid_size`. Assign points to voxels by converting their local coordinates to integer indices [S1, unofficial].
7. **Morphological Dilation:** Expand the active voxel region using `pooling_radius`. For each iteration in the radius, perform a 3D dilation by OR-ing the grid with its shifted neighbors [S1, unofficial].
8. **KNN Precomputation:** Build a KDTree on the sampled points. Query KNN for each sampled point to get `pc_KNN_idx` and `pc_KNN_xyz`. Query KNN for each active voxel center to get `voxel_KNN_idx` and `voxel_KNN_xyz` [S1, unofficial].

**Pseudocode:**
```python
import numpy as np
from scipy.spatial import KDTree

def grid_based_scene_cropping(points, output_grid_size, KNN_num, pooling_radius, block_padding, input_point_num):
    """
    points: N x 3 array, normalized to [-1, 1]
    Returns: pc_KNN_idx, pc_KNN_xyz, voxel_xyz_int, voxel_KNN_idx, voxel_KNN_xyz
    """
    # 1. Normalize and Scale (Assuming points are already normalized to [-1,1])
    # Scale to grid units. Note: The source implies a specific scaling logic involving block_num_per_dim.
    # For implementation, we assume points are in a space where grid_size defines the resolution.
    
    # 2. Extract Crop (Simplified for single crop logic as per source snippet)
    # Bounds calculation
    min_x = -block_padding
    max_x = output_grid_size + block_padding
    min_y = -block_padding
    max_y = output_grid_size + block_padding
    min_z = -block_padding
    max_z = output_grid_size + block_padding
    
    mask = (points[:, 0] > min_x) & (points[:, 0] < max_x) & \
           (points[:, 1] > min_y) & (points[:, 1] < max_y) & \
           (points[:, 2] > min_z) & (points[:, 2] < max_z)
    
    crop_points = points[mask]
    
    # 3. Empty Check
    if len(crop_points) < 100:
        pc_KNN_idx = np.zeros(1, dtype=np.int32)
        pc_KNN_xyz = np.zeros((1, 3), dtype=np.float32)
        voxel_xyz_int = np.zeros(1, dtype=np.int32)
        voxel_KNN_idx = np.zeros(1, dtype=np.int32)
        voxel_KNN_xyz = np.zeros((1, 3), dtype=np.float32)
        return pc_KNN_idx, pc_KNN_xyz, voxel_xyz_int, voxel_KNN_idx, voxel_KNN_xyz

    # 4. Local Coordinate Shift
    local_points = crop_points - np.array([min_x, min_y, min_z])
    
    # 5. Sampling
    if len(local_points) > input_point_num:
        indices = np.random.choice(len(local_points), input_point_num, replace=False)
        sampled_points = local_points[indices]
    else:
        sampled_points = local_points

    # 6. Voxel Grid Construction
    grid_size = output_grid_size
    tmp_grid = np.zeros((grid_size, grid_size, grid_size), dtype=np.uint8)
    
    # Convert to integer indices and clip to valid array bounds [0, grid_size-1]
    pc_xyz_int = np.floor(local_points).astype(np.int32)
    pc_xyz_int[:, 0] = np.clip(pc_xyz_int[:, 0], 0, grid_size - 1)
    pc_xyz_int[:, 1] = np.clip(pc_xyz_int[:, 1], 0, grid_size - 1)
    pc_xyz_int[:, 2] = np.clip(pc_xyz_int[:, 2], 0, grid_size - 1)
    
    # Assign to grid
    tmp_grid[pc_xyz_int[:, 0], pc_xyz_int[:, 1], pc_xyz_int[:, 2]] = 1

    # 7. Morphological Dilation
    for _ in range(pooling_radius):
        tmp_mask = np.copy(tmp_grid)
        dilated = np.zeros_like(tmp_mask)
        for i in range(3):
            for j in range(3):
                for k in range(3):
                    dilated[i:grid_size-1+i, j:grid_size-1+j, k:grid_size-1+k] |= tmp_mask
        tmp_grid = dilated

    # Identify active voxels and store as 1D index array to match [num_voxels] shape
    active_voxels = np.argwhere(tmp_grid > 0)
    voxel_xyz_int = active_voxels[:, 0] + active_voxels[:, 1] * grid_size + active_voxels[:, 2] * grid_size**2
    
    # 8. KNN Precomputation
    tree = KDTree(sampled_points)
    
    dist_pc, idx_pc = tree.query(sampled_points, k=KNN_num)
    pc_KNN_idx = idx_pc.flatten()
    
    K = KNN_num
    N = len(sampled_points)
    pc_KNN_xyz = np.zeros((N * K, 3), dtype=np.float32)
    for i in range(N):
        neighbors = idx_pc[i]
        for k in range(K):
            neighbor_idx = neighbors[k]
            pc_KNN_xyz[i * K + k] = sampled_points[neighbor_idx] - sampled_points[i]
            
    voxel_coords_3d = np.unravel_index(voxel_xyz_int, (grid_size, grid_size, grid_size))
    voxel_coords_3d = np.stack(voxel_coords_3d, axis=1).astype(np.float32)
    
    dist_v, idx_v = tree.query(voxel_coords_3d, k=KNN_num)
    voxel_KNN_idx = idx_v.flatten()
    
    voxel_KNN_xyz = np.zeros((len(voxel_coords_3d) * K, 3), dtype=np.float32)
    for i in range(len(voxel_coords_3d)):
        neighbors = idx_v[i]
        for k in range(K):
            neighbor_idx = neighbors[k]
            voxel_KNN_xyz[i * K + k] = sampled_points[neighbor_idx] - voxel_coords_3d[i]
            
    return pc_KNN_idx, pc_KNN_xyz, voxel_xyz_int, voxel_KNN_idx, voxel_KNN_xyz
```

## Background
This method originates from the NDC (Neural Distance Field) project, specifically the `scene_crop_pointcloud` dataset generation code [S1, unofficial]. It is designed to facilitate the training of neural networks for 3D shape representation by providing structured local patches with precomputed neighbor relationships [S1, unofficial].
