# Voxel Hashing and Mean Aggregation

Also called: Hash-based Voxelization, Scatter Mean Voxelization

## Overview
This method converts a set of 3D points into a sparse voxel grid by mapping points to unique voxel identifiers via hashing and aggregating point features using mean scattering [S1, unofficial]. It dynamically allocates storage only for occupied voxels, avoiding pre-allocated dense memory for empty space [S1, unofficial].

## How it works
**Inputs:**
- `points`: Tensor of shape $(N, 3)$ containing 3D coordinates.
- `batch_ids`: Tensor of shape $(N,)$ identifying point cloud batches.
- `voxel_size`: Scalar defining the physical size of a voxel.
- `bounding_boxes`: Tensor of shape $(2, 3)$ defining the minimum and maximum spatial extent.
- `feats`: Tensor of shape $(N, C)$ containing point features.
- `colors`: Optional tensor of shape $(N, 3)$ for RGB colors.
- `depth_conf`: Optional tensor of shape $(N,)$ for depth confidence values.

**Outputs:**
- `voxel_features`: Tensor of shape $(M, C)$, where $M$ is the number of unique voxels.
- `voxel_centers`: Tensor of shape $(M, 3)$ representing the center coordinates of each voxel.
- `unique_voxel_indices`: Tensor of shape $(M, D)$ containing the discrete grid indices for each voxel, where $D$ is the dimensionality after concatenation.
- `unique_hash`: Tensor of shape $(M,)$ containing unique hash identifiers.

**Data Structures:**
- `voxel_hash`: 1D integer tensor of shape $(N,)$ storing the hash identifier for each point.
- `inverse_id`: 1D integer tensor of shape $(N,)$ mapping each point to its unique voxel ID in `unique_hash` [S1, unofficial].
- `first_occurrence_indices`: 1D integer tensor of shape $(M,)$ storing the index in the original point array for the first point assigned to each unique voxel [S1, unofficial].

**Steps:**
1. **Compute Voxel Indices**: Calculate the discrete grid index for each point based on its coordinates, `voxel_size`, and `bounding_boxes`. Batch IDs are concatenated to ensure unique indices across batches [S1, unofficial].
   $$ \text{voxel\_indices}_i = \left\lfloor \frac{\text{points}_i - \text{min\_coord}}{\text{voxel\_size}} \right\rfloor $$
   If `cat_batch_ids` is True, the batch ID is appended to the index calculation to prevent collisions between batches [S1, unofficial].
2. **Hash Indices**: Map the voxel indices to a 1D unique hash identifier using a hash function $H$ [S1, unofficial].
   $$ \text{voxel\_hash}_i = H(\text{voxel\_indices}_i) $$
3. **Identify Unique Voxels**: Find the unique hash values and map each point to its corresponding unique voxel ID [S1, unofficial].
   $$ \text{unique\_hash}, \text{inverse\_id} = \text{unique}(\text{voxel\_hash}, \text{return\_inverse}=\text{True}) $$
   Here, `inverse_id` is a tensor of shape $(N,)$ where `inverse_id[i]` is the index in `unique_hash` corresponding to the voxel containing point $i$ [S1, unofficial].
4. **Aggregate Features**: Scatter mean aggregation is performed along the point dimension using `inverse_id` as the scatter index [S1, unofficial].
   $$ \text{voxel\_features} = \text{scatter\_mean}(\text{feats}, \text{inverse\_id}, \text{dim}=0) $$
   If `colors` are provided:
   $$ \text{voxel\_colors} = \text{scatter\_mean}(\text{colors}, \text{inverse\_id}, \text{dim}=0) $$
   If `depth_conf` is provided:
   $$ \text{voxel\_depth\_conf} = \text{scatter\_mean}(\text{depth\_conf}, \text{inverse\_id}, \text{dim}=0) $$
5. **Compute Voxel Centers**: Calculate the center coordinates for each unique voxel, optionally weighted by `depth_conf` [S1, unofficial].
   $$ \text{voxel\_centers}_j = \frac{\sum_{i: \text{inverse\_id}_i = j} \text{points}_i \cdot w_i}{\sum_{i: \text{inverse\_id}_i = j} w_i} $$
   where $w_i$ is the depth confidence if provided, otherwise $w_i=1$ [G].
6. **Retrieve Representative Indices**: To get the discrete grid indices for each unique voxel, find the first occurrence of each unique hash in the original point list [S1, unofficial].
   - Initialize `min_original_indices_per_unique_id` with a large value [S1, unofficial].
   - Use `scatter_reduce` with `reduce='amin'` on `inverse_id` using the original point indices:
     $$ \text{first\_occurrence\_indices}[j] = \min \{ i \mid \text{inverse\_id}_i = j \} $$
   - Retrieve the voxel indices for each unique voxel:
     $$ \text{unique\_voxel\_indices}_j = \text{voxel\_indices}[\text{first\_occurrence\_indices}[j]] $$

**Parameters:**
- `cat_batch_ids`: Boolean, default `True`. If True, batch IDs are included in the voxel index calculation to ensure uniqueness across batches [S1, unofficial].
- `voxel_size`: Scalar, typical values depend on the scene scale. Not given in the sources.
- `bounding_boxes`: Defines the spatial range. Not given in the sources.

**Edge Cases and Pitfalls:**
- **Precision**: Floating-point precision in coordinate-to-index conversion may cause points near voxel boundaries to be assigned to different voxels [G].
- **Empty Voxels**: The method only creates voxels for points that exist; empty space is not represented [S1, unofficial].

**Pseudocode:**
```python
import torch

def voxel_hashing_and_mean_aggregation(points, batch_ids, voxel_size, bounding_boxes, feats, colors=None, depth_conf=None):
    """
    Voxelizes points using hashing and mean aggregation.
    
    Args:
        points: (N, 3) Tensor of point coordinates.
        batch_ids: (N,) Tensor of batch IDs.
        voxel_size: Scalar. Size of each voxel.
        bounding_boxes: (2, 3) Tensor with [min_coord, max_coord].
        feats: (N, C) Tensor of point features.
        colors: (N, 3) Tensor of RGB colors (optional).
        depth_conf: (N,) Tensor of depth confidence (optional).
        
    Returns:
        voxel_features: (M, C) Aggregated features.
        voxel_centers: (M, 3) Voxel centers.
        unique_voxel_indices: (M, D) Discrete voxel indices.
        unique_hash: (M,) Unique hash identifiers.
    """
    # Step 1: Compute voxel indices
    voxel_indices = get_vox_indices(points, batch_ids, voxel_size, bounding_boxes, shift=False, cat_batch_ids=True)
    
    # Step 2: Hash voxel indices
    voxel_hash = hash_voxel_indices(voxel_indices)
    
    # Step 3: Identify unique hashes and map points to unique voxel IDs
    unique_hash, inverse_id = torch.unique(voxel_hash, return_inverse=True)
    M = unique_hash.shape[0]
    
    # Step 4: Aggregate features using scatter mean
    voxel_features = torch.zeros((M, feats.shape[1]), dtype=feats.dtype, device=feats.device)
    scatter_idx = inverse_id.unsqueeze(1).expand(-1, feats.shape[1])
    voxel_features.scatter_reduce_(0, scatter_idx, feats, reduce='mean')
    
    voxel_colors = None
    if colors is not None:
        voxel_colors = torch.zeros((M, 3), dtype=colors.dtype, device=colors.device)
        scatter_idx_c = inverse_id.unsqueeze(1).expand(-1, 3)
        voxel_colors.scatter_reduce_(0, scatter_idx_c, colors, reduce='mean')
        
    voxel_depth_conf = None
    if depth_conf is not None:
        voxel_depth_conf = torch.zeros((M, 1), dtype=depth_conf.dtype, device=depth_conf.device)
        scatter_idx_d = inverse_id.unsqueeze(1)
        voxel_depth_conf.scatter_reduce_(0, scatter_idx_d, depth_conf, reduce='mean')
        
    # Step 5: Compute voxel centers
    voxel_centers = get_vox_centers_from_points(points, depth_conf, inverse_id, M)
    
    # Step 6: Retrieve representative voxel indices
    original_indices = torch.arange(points.shape[0], dtype=torch.long, device=points.device)
    min_original_indices_per_unique_id = torch.full((M,), float('inf'), dtype=torch.long, device=points.device)
    min_original_indices_per_unique_id.scatter_reduce_(0, inverse_id, original_indices, reduce='amin')
    
    unique_voxel_indices = voxel_indices[min_original_indices_per_unique_id]
    
    return voxel_features, voxel_centers, unique_voxel_indices, unique_hash

def get_vox_indices(points, batch_ids, voxel_size, bounding_boxes, shift=False, cat_batch_ids=True):
    """Computes voxel indices for points."""
    min_coord = bounding_boxes[0]
    pts = points - min_coord if shift else points
    indices = torch.floor(pts / voxel_size).long()
    max_indices = ((bounding_boxes[1] - bounding_boxes[0]) / voxel_size).long()
    indices = torch.clamp(indices, 0, max_indices)
    if cat_batch_ids:
        indices = torch.cat([indices, batch_ids.unsqueeze(1)], dim=1)
    return indices

def hash_voxel_indices(voxel_indices):
    """Hashes voxel indices to unique identifiers."""
    # Standard linearization for variable-dimensional indices [G]
    stride = torch.cumprod(torch.cat([torch.tensor([1], device=voxel_indices.device), voxel_indices.max(dim=0)[0] + 2]), dim=0)[:-1]
    return (voxel_indices * stride).sum(dim=1)

def get_vox_centers_from_points(points, depth_conf, inverse_id, num_voxels):
    """Computes voxel centers from points."""
    voxel_centers = torch.zeros((num_voxels, 3), dtype=points.dtype, device=points.device)
    voxel_counts = torch.zeros((num_voxels, 1), dtype=points.dtype, device=points.device)
    scatter_idx = inverse_id.unsqueeze(1).expand(-1, 3)
    voxel_centers.scatter_add_(0, scatter_idx, points)
    voxel_counts.scatter_add_(0, inverse_id.unsqueeze(1), torch.ones_like(inverse_id).unsqueeze(1).float())
    if depth_conf is not None:
        weights = depth_conf.unsqueeze(1)
        weighted_sum = torch.zeros((num_voxels, 3), dtype=points.dtype, device=points.device)
        weighted_sum.scatter_add_(0, scatter_idx, points * weights)
        weight_counts = torch.zeros((num_voxels, 1), dtype=points.dtype, device=points.device)
        weight_counts.scatter_add_(0, inverse_id.unsqueeze(1), weights)
        voxel_centers = weighted_sum / weight_counts.clamp(min=1e-6)
    else:
        voxel_centers = voxel_centers / voxel_counts.clamp(min=1)
    return voxel_centers
```

## Operating characteristics
- **Time Complexity**: Not given in the sources.
- **Memory Complexity**: $O(N)$ for intermediate tensors and $O(M)$ for the output grid, where $M$ is the number of unique voxels [S1, unofficial].
- **Strengths**: Dynamically allocates only for occupied voxels, supports multi-feature aggregation, and is deterministic [S1, unofficial].
- **Limitations**: Mean aggregation may blur high-frequency features; hash collisions can merge distinct voxels if the hash function is not collision-free [G].
- **When to Use**: When processing sparse point clouds and mean feature aggregation is required [S1, unofficial].
- **When Not to Use**: When dense grid representation, max pooling, or exact boundary preservation is required [G].

## Background
This method is implemented in the VGVGGT repository for 3D vision tasks [S1, unofficial]. It builds on deterministic hard voxelization by replacing fixed grid allocation with hash-based sparse indexing [S1, unofficial].
