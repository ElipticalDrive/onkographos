# Voxel Hashing and Mean Aggregation

Also called: Hash-based Voxelization, Scatter Mean Voxelization

## Overview
This method converts a set of 3D points into a sparse voxel grid by mapping points to unique voxel identifiers via hashing and aggregating features using mean scattering [S1, unofficial]. It differs from fixed-grid approaches by avoiding pre-allocated dense memory for empty space, instead dynamically allocating only for occupied voxels [S1, unofficial]. It is chosen when memory efficiency for sparse point clouds is critical and mean aggregation is the desired feature reduction strategy [S1, unofficial].

## How it works
**Inputs:**
- `points`: Tensor of shape $(N, 3)$ containing 3D coordinates.
- `batch_ids`: Tensor of shape $(N,)$ identifying point cloud batches.
- `voxel_size`: Scalar defining the physical size of a voxel.
- `bounding_boxes`: List or tensor defining the spatial extent for voxelization.
- `feats`: Tensor of shape $(N, C)$ containing point features.
- `colors`: Optional tensor of shape $(N, 3)$ for RGB colors.
- `depth_conf`: Optional tensor of shape $(N,)$ for depth confidence values.

**Outputs:**
- `voxel_features`: Tensor of shape $(M, C)$, where $M$ is the number of unique voxels.
- `voxel_centers`: Tensor of shape $(M, 3)$ representing the center coordinates of each voxel.
- `voxel_indices`: Tensor of shape $(M, 3)$ containing the discrete grid indices for each voxel.
- `voxel_hash`: Tensor of shape $(M,)$ containing unique hash identifiers.

**Data Structures:**
- `voxel_hash`: 1D integer tensor of unique hash values.
- `inverse_id`: 1D integer tensor of shape $(N,)$ mapping each point to its unique voxel ID in `voxel_hash`.
- `first_occurrence_indices`: 1D integer tensor of shape $(M,)$ storing the index in the original point array for the first point assigned to each unique voxel.

**Steps:**
1. **Compute Voxel Indices**: Calculate the discrete grid index for each point based on its coordinates, `voxel_size`, and `bounding_boxes`. Batch IDs are concatenated to ensure unique indices across batches [S1, unofficial].
   $$ \text{voxel\_indices}_i = \left\lfloor \frac{\text{points}_i - \text{min\_coord}}{\text{voxel\_size}} \right\rfloor $$
   If `cat_batch_ids` is True, the batch ID is appended to the index calculation to prevent collisions between batches [S1, unofficial].

2. **Hash Indices**: Map the 3D voxel indices to a 1D unique hash identifier using a hash function $H$.
   $$ \text{voxel\_hash}_i = H(\text{voxel\_indices}_i) $$

3. **Identify Unique Voxels**: Find the unique hash values and map each point to its corresponding unique voxel ID.
   $$ \text{unique\_hash}, \text{inverse\_id} = \text{unique}(\text{voxel\_hash}, \text{return\_inverse}=\text{True}) $$
   Here, `inverse_id` is a tensor of shape $(N,)$ where `inverse_id[i]` is the index in `unique_hash` corresponding to the voxel containing point $i$.

4. **Aggregate Features**: Scatter mean aggregation is performed along the point dimension using `inverse_id` as the scatter index.
   $$ \text{voxel\_features} = \text{scatter\_mean}(\text{feats}, \text{inverse\_id}, \text{dim}=0) $$
   If `colors` are provided:
   $$ \text{voxel\_colors} = \text{scatter\_mean}(\text{colors}, \text{inverse\_id}, \text{dim}=0) $$
   If `depth_conf` is provided:
   $$ \text{voxel\_depth\_conf} = \text{scatter\_mean}(\text{depth\_conf}, \text{inverse\_id}, \text{dim}=0) $$

5. **Compute Voxel Centers**: Calculate the center coordinates for each unique voxel. This is often done by averaging the coordinates of points assigned to the voxel, weighted by `depth_conf` if available, or simply by averaging the point coordinates [S1, unofficial].
   $$ \text{voxel\_centers}_j = \frac{1}{|\{i | \text{inverse\_id}_i = j\}|} \sum_{i: \text{inverse\_id}_i = j} \text{points}_i $$
   *Note: The source mentions `get_vox_centers_from_points` which may use `depth_conf` for weighted averaging [S1, unofficial].*

6. **Retrieve Representative Indices**: To get the discrete grid indices for each unique voxel, find the first occurrence of each unique hash in the original point list.
   - Initialize `min_original_indices_per_unique_id` with a large value (e.g., infinity).
   - Use `scatter_reduce` with `reduce='amin'` on `inverse_id` using the original point indices.
     $$ \text{first\_occurrence\_indices}[j] = \min \{ i | \text{inverse\_id}_i = j \} $$
   - Retrieve the voxel indices for each unique voxel:
     $$ \text{voxel\_indices}_j = \text{voxel\_indices}[\text{first\_occurrence\_indices}[j]] $$

**Parameters:**
- `cat_batch_ids`: Boolean, default `True`. If True, batch IDs are included in the voxel index calculation to ensure uniqueness across batches [S1, unofficial].
- `voxel_size`: Scalar, typical values depend on the scene scale (e.g., 0.1 to 0.5 meters for autonomous driving).
- `bounding_boxes`: Defines the spatial range. Not given in the sources.

**Edge Cases and Pitfalls:**
- **Hash Collisions**: If the hash function is not collision-free, points from different voxels may be merged. The source uses `torch.unique` on the hash, implying a perfect hash or a hash that is unique per voxel index [S1, unofficial].
- **Empty Voxels**: The method only creates voxels for points that exist. Empty space is not represented [S1, unofficial].
- **Precision**: Floating-point precision in coordinate-to-index conversion may cause points near voxel boundaries to be assigned to different voxels [G].

        bounding_boxes: Tensor or list defining the bounding box.

        colors: (N, 3) Tensor of RGB colors (optional).
        depth_conf: (N,) Tensor of depth confidence (optional).
        
    Returns:
        voxel_features: (M, C) Aggregated features.

    voxel_indices = get_vox_indices(points, batch_ids, voxel_size, bounding_boxes, shift=False, cat_batch_ids=True)
    
    # Step 2: Hash voxel indices
    # Assuming a hash function that maps 3D indices to 1D unique IDs
    # In practice, this could be a simple linearization or a hash function
    # For deterministic behavior, we assume a perfect hash or unique mapping
    voxel_hash = hash_voxel_indices(voxel_indices)
    
    # Step 3: Identify unique hashes and map points to unique voxel IDs
    unique_hash, inverse_id = torch.unique(voxel_hash, return_inverse=True)
    
    # Step 4: Aggregate features using scatter mean
    voxel_features = torch.zeros((unique_hash.shape[0], feats.shape[1]), dtype=feats.dtype, device=feats.device)

    voxel_depth_conf = None

        voxel_depth_conf = torch.zeros((unique_hash.shape[0], 1), dtype=depth_conf.dtype, device=depth_conf.device)

    # Step 6: Retrieve representative voxel indices
    # Find the first occurrence index for each unique voxel ID
    # Initialize with a large value
    min_original_indices_per_unique_id = torch.full((unique_hash.shape[0],), float('inf'), dtype=torch.long, device=points.device)
    original_indices = torch.arange(points.shape[0], dtype=torch.long, device=points.device)
    
    # Use scatter_reduce to find the minimum original index for each unique ID
    min_original_indices_per_unique_id.scatter_reduce_(0, inverse_id, original_indices, reduce='amin')
    
    # Retrieve unique voxel indices using the first occurrence indices
    voxel_indices = voxel_indices[min_original_indices_per_unique_id]
    
    return voxel_features, voxel_centers, voxel_indices, unique_hash

def get_vox_centers_from_points(points, depth_conf, inverse_id, num_voxels):
    """
    Computes voxel centers from points.

    # Compute the mean of points for each unique voxel ID
    voxel_centers = torch.zeros((num_voxels, 3), dtype=points.dtype, device=points.device)
    voxel_counts = torch.zeros((num_voxels, 1), dtype=points.dtype, device=points.device)
    
    # Scatter add points and counts

## Operating characteristics
- **Time Complexity**: $O(N \log N)$ or $O(N)$ depending on the hash function and unique operation. The `torch.unique` operation is typically $O(N \log N)$ [S1, unofficial].
- **Memory Complexity**: $O(M)$, where $M$ is the number of unique voxels. This is more memory-efficient than dense grids for sparse point clouds [S1, unofficial].
- **Performance**: Efficient for sparse point clouds. Performance depends on the hash function and the efficiency of the scatter operations [S1, unofficial].
- **Strengths**: Memory efficient for sparse data, simple implementation, supports feature aggregation [S1, unofficial].
- **Limitations**: Hash collisions can occur if the hash function is not perfect, mean aggregation may blur features [S1, unofficial].
- **When to Use**: When dealing with sparse point clouds and memory is a constraint [S1, unofficial].
- **When Not to Use**: When dense grid representation is required or when max pooling is preferred over mean [S1, unofficial].

## Background
This method is derived from the VGVGGT repository, which implements voxelization for 3D vision tasks [S1, unofficial]. It is commonly used in autonomous driving and 3D object detection pipelines where point clouds are converted to voxel grids for further processing [S1, unofficial].
