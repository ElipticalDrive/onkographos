# Nearest Neighbour Interpolation for Voxelization
Also called: KDTree-based nearest neighbour voxelization

## Overview
This method assigns attribute values (e.g., intensity, color) to voxel centers by identifying the single closest point in the original point cloud to each voxel center, rather than aggregating all points within the voxel volume [S1, unofficial]. It is used when a specific point's value is preferred over an average, distinguishing it from histogramming methods that sum or average all points falling within a voxel [S1, unofficial]. It builds on [Hard Voxelization (Deterministic)](3321-hard-voxelization-deterministic.md) by replacing volume-based aggregation with spatial nearest-neighbor lookup.

## How it works
**Inputs and Outputs:**
*   **Input:** A point cloud array `ar` of shape $(N, 4)$ containing coordinates $(x, y, z)$ and an attribute value (e.g., amplitude/intensity) in the 4th column [S1, unofficial]. A voxel grid structure `vxl` of shape $(4, n, m, p)$ containing the coordinates of the voxel centers in the first three dimensions [S1, unofficial]. A voxel width `vwidth` [S1, unofficial].
*   **Output:** An array `pnt_ofs` of shape $(4, n, m, p)$ where the first three dimensions are the voxel coordinates and the fourth dimension contains the interpolated attribute values [S1, unofficial].

**Data Structures:**
*   `ar`: 2D NumPy array. Columns 0, 1, 2 are $x, y, z$. Column 3 is the attribute $a$ [S1, unofficial].
*   `vxl`: 4D NumPy array. `vxl[0]`, `vxl[1]`, `vxl[2]` are 3D arrays of shape $(n, m, p)$ representing the $x, y, z$ coordinates of each voxel center. `vxl[3]` is the target for attribute storage [S1, unofficial].
*   `tree`: A KDTree data structure built from the point cloud coordinates [S1, unofficial].

**Parameters:**
*   `vwidth`: The side length of a voxel. In the source example, `0.7` is used [S1, unofficial].

**Steps:**
1.  Extract coordinates and attributes from the input point cloud `ar` [S1, unofficial].
    $$ x = ar[:, 0], \quad y = ar[:, 1], \quad z = ar[:, 2], \quad a = ar[:, 3] $$
2.  Construct a KDTree from the point cloud coordinates [S1, unofficial].
    $$ \text{tree} = \text{cKDTree}(\text{np.c\_}[x, y, z]) $$
3.  Flatten the voxel center coordinate arrays to query all voxel centers at once [S1, unofficial].
    $$ \text{centers} = \text{np.c\_}[ \text{vxl}[0].\text{ravel}(), \text{vxl}[1].\text{ravel}(), \text{vxl}[2].\text{ravel}() ] $$
4.  Query the KDTree for the nearest neighbor ($k=1$) to each voxel center [S1, unofficial].
    $$ dd, ii = \text{tree.query}(\text{centers}, k=1) $$
    Where $dd$ is the distance to the nearest neighbor and $ii$ is the index of the nearest neighbor in the original point cloud [S1, unofficial].
5.  Filter out points that are too far away. If the distance $dd$ is greater than or equal to half the voxel width ($vwidth/2$), the point is considered too distant to represent the voxel center reliably [S1, unofficial]. Set the corresponding attribute values to `NaN` [S1, unofficial].
    $$ a[ii[dd \ge vwidth/2]] = \text{np.nan} $$
6.  Reshape the retrieved attribute values to match the voxel grid shape [S1, unofficial].
    $$ \text{vann} = a[ii].\text{reshape}(\text{vxl}[0].\text{shape}) $$
7.  Stack the voxel coordinates and the interpolated attribute values into the output array [S1, unofficial].
    $$ \text{pnt\_ofs} = \text{np.stack}((\text{vxl}[0], \text{vxl}[1], \text{vxl}[2], \text{vann})) $$

**Pseudocode:**
```python
import numpy as np
from scipy.spatial import cKDTree

def nearest_neighbour_voxelization(ar, vxl, vwidth):
    """
    Assigns attribute values to voxel centers using nearest neighbour interpolation.
    
    Parameters:
    ar : numpy.ndarray, shape (N, 4)
        Point cloud data. Columns 0-2 are x, y, z coordinates. Column 3 is the attribute.
    vxl : numpy.ndarray, shape (4, n, m, p)
        Voxel grid structure. vxl[0], vxl[1], vxl[2] are the x, y, z coordinates of voxel centers.
    vwidth : float
        The width (side length) of a voxel.
        
    Returns:
    pnt_ofs : numpy.ndarray, shape (4, n, m, p)
        Voxel grid with interpolated attributes in the 4th dimension.
    """
    # 1. Extract coordinates and attributes
    x = ar[:, 0]
    y = ar[:, 1]
    z = ar[:, 2]
    a = ar[:, 3]
    
    # 2. Construct KDTree
    tree = cKDTree(np.c_[x, y, z])
    
    # 3. Flatten voxel centers
    voxel_centers = np.c_[vxl[0].ravel(), vxl[1].ravel(), vxl[2].ravel()]
    
    # 4. Query nearest neighbor
    dd, ii = tree.query(voxel_centers, k=1)
    
    # 5. Filter by distance threshold
    # Points further than half voxel width are set to NaN
    a[ii[dd >= vwidth / 2]] = np.nan
    
    # 6. Reshape attributes to voxel grid shape
    vann = a[ii].reshape(vxl[0].shape)
    
    # 7. Stack coordinates and attributes
    pnt_ofs = np.stack((vxl[0], vxl[1], vxl[2], vann))
    
    return pnt_ofs
```

**Edge Cases and Pitfalls:**
*   **Distance Threshold:** The threshold $vwidth/2$ is critical [S1, unofficial]. Points exactly at the boundary are excluded [S1, unofficial]. If the point cloud is sparse, many voxels may become `NaN` [S1, unofficial].
*   **Precision:** Floating-point precision in distance calculations may affect which point is selected as the nearest neighbor in dense regions [G].
*   **Empty Voxels:** Voxels with no points within $vwidth/2$ will have `NaN` values [S1, unofficial]. Downstream processing must handle `NaN` appropriately [G].

## Subtopics

### Soft Voxelization with Trilinear Interpolation
A technique where tiny dots of density and color are baked into a voxel grid one by one using antialiasing by smearing the dot across eight neighboring voxels [S2, unofficial]. For a dot at position $x_{dot}$ with density $\rho_{dot}$ and color $c_{dot}$, the 8 nearest voxels are identified by indices $\{x_{abc} | a=i, i+1, b=j, j+1, c=k, k+1\}$ where $(i,j,k)$ is the voxel index containing $x_{dot}$ [S2, unofficial]. The density and color are updated using trilinear interpolation weights $\omega_{abc}$:
$$ \rho_{abc} += \rho_{dot} \cdot \omega_{abc} $$
$$ c_{abc} += c_{dot} \cdot \omega_{abc} $$
This method is used in the 'Steps to Grow Point Wisps' algorithm to bake particle density and color into a voxel grid [S2, unofficial].

This method is described in the context of point cloud voxelization using Python (numpy & scipy) [S1, unofficial]. It is presented as a simple alternative to histogramming for assigning attribute values (like intensity) to voxel grids [S1, unofficial]. The approach leverages the `scipy.spatial.cKDTree` for efficient nearest neighbor search [S1, unofficial].
