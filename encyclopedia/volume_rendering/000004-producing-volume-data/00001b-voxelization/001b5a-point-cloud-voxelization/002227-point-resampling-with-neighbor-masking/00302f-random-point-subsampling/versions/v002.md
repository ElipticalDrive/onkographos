# Random Point Subsampling
Also called: Random Subset Selection, Shuffle and Slice
## Overview
Random Point Subsampling selects a fixed-size random subset of points from an input set without replacement [S1, unofficial]. It serves as a downsampling primitive within the Point Resampling with Neighbor Masking pipeline [Point Resampling with Neighbor Masking](2710-point-resampling-with-neighbor-masking.md). It differs from sibling methods like [Error-Driven Point Resampling & Grid Aggregation](5425-error-driven-point-resampling-grid-aggregation.md) and [A-buffer Sampling Method](12360-a-buffer-sampling-method.md) by ignoring spatial distribution in favor of uniform random selection [S1, unofficial].
## How it works
**Inputs:**
- `points`: A tensor of points, typically shape $(M, 3)$ [S1, unofficial].
- `n_points`: The number of points to select [S1, unofficial].
**Outputs:**
- A tensor containing the selected subset of points [S1, unofficial].
**Data Structures:**
- The input `points` tensor is stored in contiguous memory [S1, unofficial].
**Steps:**
1. Generate a random permutation of indices for the input points tensor [S1, unofficial].
2. Index the points tensor with the random permutation to shuffle the points [S1, unofficial].
3. Reshape the shuffled points tensor to ensure it is 2D (shape $(-1, 3)$) [S1, unofficial].
4. Return the selected subset of points [S1, unofficial].
**Pseudocode:**
```python
import torch

def random_point_subsampling(points: torch.Tensor, n_points: int) -> torch.Tensor:
    """
    Selects a random subset of points without replacement.
    
    Args:
        points: Tensor of shape (M, 3).
        n_points: Number of points to select.
        
    Returns:
        Tensor of the selected subset.
    """
    M = points.shape[0]
    # [G] Clamp n_points to M to prevent out-of-bounds indexing during permutation
    N = min(M, n_points)
    
    # Generate random permutation of indices [0, M-1]
    perm = torch.randperm(M, device=points.device)
    
    # Select first N indices
    selected_indices = perm[:N]
    
    # Index the points tensor with the random permutation to shuffle
    shuffled_points = points[selected_indices]
    
    # Reshape the shuffled points tensor to ensure it is 2D (shape (-1, 3))
    sampled_points = shuffled_points.view(-1, 3)
    
    return sampled_points
```
**Parameters:**
- `n_points`: The number of points to select [S1, unofficial].

## Subtopics

### Near Sampling
A site placement strategy where a proportion of sites are placed close to uniformly subsampled input point cloud data [S2]. It is used in methods like DCCVT to initialize site distributions before optimization [S2]. It is chosen when a hybrid approach of uniform grid initialization and point-cloud proximity is desired [S2]. It differs from pure random subsampling by biasing selection toward existing point locations rather than uniform space [S2].
