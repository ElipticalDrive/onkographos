# Error-Driven Point Resampling & Grid Aggregation


## Overview
This method accumulates per-pixel rendering errors from multiple camera views into a 3D voxel grid to compute mean error density, which guides point resampling for tetrahedral grid refinement [S1, unofficial]. It distinguishes itself from its parent [Point Resampling with Neighbor Masking](2710-point-resampling-with-neighbor-masking.md) by driving the resampling probability based on quantitative rendering error rather than topological neighbor status [S1, unofficial].

## How it works
**Inputs:**
- Input points, camera views, `voxel_resolution`, `resolution`, `aggregation_method`, `resampled_points_method`, and `device` [S1, unofficial].

**Outputs:**
- A refined set of points distributed according to the computed error density, and a voxel grid containing mean error values per voxel [S1, unofficial].

**Data Structures:**
- `Grid`: A 3D voxel grid structure initialized with `Grid(voxel_resolution, -1.0, 2.0)` [S1, unofficial].

**Steps:**
1. Initialize grid with `Grid(voxel_resolution, -1.0, 2.0)` [S1, unofficial].
2. For each camera, render positions and masks via `render_pos_mask` [S1, unofficial].
3. Filter pixels where `current_mask.squeeze(-1) > 0.5` [S1, unofficial].
4. Convert filtered positions to voxel indices via `grid.point_voxel_idx` [S1, unofficial].
5. Validate indices against grid bounds [S1, unofficial].
6. Flatten indices and scatter-add errors and counts to 1D tensors [S1, unofficial].
7. Reshape back to 3D and accumulate across cameras [S1, unofficial].
8. Compute mean error: `grid_point_errors = torch.where(grid_point_counts > 0, grid_point_errors / grid_point_counts, grid_point_errors)` [S1, unofficial].
9. Assign to `grid.density` and sample points via `grid.sample_points` [S1, unofficial].

```python
def error_driven_resampling(points, cameras, voxel_resolution=32, resolution=[1024, 1024], 
                            aggregation_method='interpolation', resampled_points_method='partial', 
                            device='cuda'):
    # 1. Initialize grid
    grid = Grid(voxel_resolution, -1.0, 2.0)
    grid_point_errors = torch.zeros(voxel_resolution**3, device=device)
    grid_point_counts = torch.zeros(voxel_resolution**3, dtype=torch.int, device=device)
    
    for camera in cameras:
        # 2. Render positions and masks
        positions, current_mask = render_pos_mask(points, camera, resolution)
        
        # 3. Filter pixels
        valid_mask = current_mask.squeeze(-1) > 0.5
        valid_positions = positions[valid_mask]
        valid_errors = compute_error(points, camera, valid_positions)
        
        # 4. Convert to voxel indices
        voxel_indices = grid.point_voxel_idx(valid_positions)
        
        # 5. Validate indices
        valid_idx_mask = (voxel_indices >= 0).all(dim=1) & (voxel_indices < voxel_resolution).all(dim=1)
        valid_indices = voxel_indices[valid_idx_mask]
        valid_errors = valid_errors[valid_idx_mask]
        
        if len(valid_indices) == 0:
            continue
            
        # 6. Flatten and scatter-add
        flattened_indices = valid_indices.flatten()
        grid_point_errors.scatter_add_(0, flattened_indices, valid_errors)
        grid_point_counts.scatter_add_(0, flattened_indices, torch.ones_like(flattened_indices, dtype=torch.int))
        
    # 7. Reshape back to 3D and accumulate across cameras (accumulation happens in loop)
    # 8. Compute mean error
    grid_point_errors = torch.where(grid_point_counts > 0, grid_point_errors / grid_point_counts.float(), grid_point_errors)
    
    # 9. Assign density and resample
    grid.density = grid_point_errors.reshape(voxel_resolution, voxel_resolution, voxel_resolution)
    new_points = grid.sample_points(resampled_points_method)
    
    return new_points
```

**Parameters:**
- `voxel_resolution`: int, default 32. Grid resolution in each dimension [S1, unofficial].
- `resolution`: list, default [1024, 1024]. Camera image resolution [S1, unofficial].
- `aggregation_method`: str, default 'interpolation'. Method for aggregating sampled points [S1, unofficial].
- `resampled_points_method`: str, default 'partial'. Strategy for point resampling [S1, unofficial].
- `device`: str, default 'cuda'. Compute device [S1, unofficial].

**Edge Cases and Pitfalls:**
- **Zero Counts:** Voxels with no valid pixel projections have zero counts, requiring division-by-zero handling via `torch.where` [S1, unofficial].
- **Boundary Validation:** Voxel indices must be strictly validated against grid bounds to prevent out-of-bounds memory access during scatter operations [S1, unofficial].
