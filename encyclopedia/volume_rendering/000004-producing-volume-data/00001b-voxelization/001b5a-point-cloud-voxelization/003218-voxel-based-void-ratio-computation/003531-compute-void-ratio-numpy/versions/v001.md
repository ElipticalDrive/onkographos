# Compute Void Ratio (NumPy)

## Overview
Computes the void ratio (volume of empty space divided by volume of solid) for each voxel in a point cloud by binning particle centers into cubic voxels, calculating the solid volume via sphere-box intersection integration, and adjusting boundary voxels to prevent overestimation of empty space [S1, unofficial]. It differs from the plain Python variant by using vectorized NumPy operations for performance, and serves as the primary data source for the [Face-Reconstructed Gauss Smoothing](7532-face-reconstructed-gauss-smoothing.md) method.

## How it works
**Inputs:**
- `points`: Array of shape $(N, 3)$ containing particle center coordinates.
- `radii`: Array of shape $(N,)$ containing particle radii.
- `target_particles_per_voxel`: Float, target density for voxel sizing.
- `sphere_clip_order`: Integer, Gauss quadrature order for sphere-box intersection (typically 2, 4, or 8).

**Outputs:**
- `void_by_particle`: Array of shape $(N,)$ void ratio per particle.
- `smoothed_void_by_particle`: Array of shape $(N,)$ smoothed void ratio per particle.
- `stats`: Dictionary with metadata.
- `voxel_data`: Dictionary with voxel-level arrays.

**Data Structures:**
- `voxel_indices`: Array of shape $(M, 3)$, integer coordinates of occupied voxels.
- `box_min`, `box_max`: Arrays of shape $(M, 3)$, float coordinates of voxel boundaries.
- `void_by_voxel`: Array of shape $(M,)$, computed void ratio.
- `solid_by_voxel`: Array of shape $(M,)$, integrated solid volume.
- `measurement_volume`: Array of shape $(M,)$, effective voxel volume.

**Steps:**

1.  **Voxel Sizing:** Determine voxel size $v$ using binary search (45 iterations) to match `target_particles_per_voxel`. Compute global bounds `mins` and `maxs`, and grid dimensions `dims` [S1, unofficial].
2.  **Indexing:** Map each point to a voxel index:
    $$ i = \left\lfloor \frac{p - \text{mins}}{v} \right\rfloor $$
    Clamp $i$ to $[0, \text{dims}-1]$. Compute linear index $L = i_x + \text{dims}_x(i_y + \text{dims}_y i_z)$. Use `np.unique` to find occupied voxels and `np.bincount` to count particles per voxel [S1, unofficial].
3.  **Local Bounds:** For each occupied voxel, compute the minimum and maximum extents of all particles within it using `np.minimum.at` and `np.maximum.at` on the sphere extents ($p \pm r$) [S1, unofficial].
4.  **Boundary Adjustment:** For voxels on the grid boundary (index 0 or `dims-1` in any axis), adjust `box_min` and `box_max` to use the local particle extents instead of the nominal grid bounds. This prevents measuring empty space outside the particle cloud [S1, unofficial].
5.  **Measurement Volume:** Calculate the volume of the adjusted bounding box for each voxel:
    $$ V_{\text{meas}} = \prod_{axis \in \{x,y,z\}} (\text{box\_max}_{axis} - \text{box\_min}_{axis}) $$
    Identify adjusted boundary voxels where $V_{\text{meas}} < v^3$ [S1, unofficial].
6.  **Solid Volume:** Integrate the volume of intersection between each sphere and its voxel's bounding box using Gauss quadrature. The integration is performed over the clipped sphere-box region [S1, unofficial].
7.  **Void Ratio:** Compute the void ratio for each occupied voxel:
    $$ e = \frac{V_{\text{meas}} - V_{\text{solid}}}{V_{\text{solid}}} $$
8.  **Smoothing:** Apply [Face-Reconstructed Gauss Smoothing](7532-face-reconstructed-gauss-smoothing.md) with 8 Gauss points to the voxel void ratios [S1, unofficial].
9.  **Assignment:** Map the voxel void ratios back to particles using the inverse index map from Step 2 [S1, unofficial].

**Pseudocode:**

```python
import numpy as np

def compute_void_ratio_numpy(points, radii, target_particles_per_voxel, sphere_clip_order):
    # 1. Voxel Sizing
    mins, maxs, best = choose_voxel_size_numpy(points, target_particles_per_voxel)
    voxel_size, dims, occupied, average = best
    nominal_voxel_volume = voxel_size ** 3

    # 2. Indexing
    indices = np.floor((points - mins) / voxel_size).astype(np.int64)
    indices = np.minimum(indices, dims - 1)
    linear = indices[:, 0] + dims[0] * (indices[:, 1] + dims[1] * indices[:, 2])

    unique_linear, unique_first, inverse = np.unique(
        linear, return_index=True, return_inverse=True
    )
    voxel_indices = indices[unique_first]
    counts_by_voxel = np.bincount(inverse)

    # 3. Local Bounds
    lower_sphere_extent = points - radii[:, None]
    upper_sphere_extent = points + radii[:, None]
    local_min = np.full((len(unique_linear), 3), np.inf, dtype=np.float64)
    local_max = np.full((len(unique_linear), 3), -np.inf, dtype=np.float64)
    for axis in range(3):
        np.minimum.at(local_min[:, axis], inverse, lower_sphere_extent[:, axis])
        np.maximum.at(local_max[:, axis], inverse, upper_sphere_extent[:, axis])

    # 4. Boundary Adjustment
    box_min = np.full((len(unique_linear), 3), mins, dtype=np.float64)
    box_max = np.full((len(unique_linear), 3), maxs, dtype=np.float64)
    
    for axis in range(3):
        nominal_low = mins[axis] + voxel_indices[:, axis] * voxel_size
        nominal_high = nominal_low + voxel_size
        
        low_boundary = voxel_indices[:, axis] == 0
        high_boundary = voxel_indices[:, axis] == dims[axis] - 1
        
        box_min[low_boundary, axis] = np.maximum(
            nominal_low[low_boundary], local_min[low_boundary, axis]
        )
        box_max[high_boundary, axis] = np.minimum(
            nominal_high[high_boundary], local_max[high_boundary, axis]
        )

    # 5. Measurement Volume
    measurement_volume_by_voxel = np.prod(box_max - box_min, axis=1)
    adjusted_boundary_voxels = int(
        np.count_nonzero(measurement_volume_by_voxel < nominal_voxel_volume)
    )

    # 6. Solid Volume
    solid_by_voxel = accumulate_clipped_solid_numpy(
        points, radii, mins, voxel_size, dims, unique_linear, box_min, box_max, sphere_clip_order
    )

    # 7. Void Ratio
    void_by_voxel = (measurement_volume_by_voxel - solid_by_voxel) / solid_by_voxel
    
    # 8. Smoothing
    smoothed_void_by_voxel = face_reconstructed_gauss_smooth_numpy(
        voxel_indices, void_by_voxel, dims
    )

    # 9. Assignment
    void_by_particle = void_by_voxel[inverse]
    smoothed_void_by_particle = smoothed_void_by_voxel[inverse]

    # Output Construction
    voxel_data = {
        "box_min": box_min,
        "box_max": box_max,
        "void_ratio": void_by_voxel,
        "void_ratio_smoothed": smoothed_void_by_voxel,
        "particle_count": counts_by_voxel,
        "solid_volume": solid_by_voxel,
        "measurement_volume": measurement_volume_by_voxel,
        "voxel_indices": voxel_indices,
    }

    stats = {
        "point_count": int(points.shape[0]),
        "bounds_min": [float(v) for v in mins],
        "bounds_max": [float(v) for v in maxs],
        "extents": [float(v) for v in (maxs - mins)],
        "target_particles_per_voxel": float(target_particles_per_voxel),
        "voxel_size": float(voxel_size),
        "nominal_voxel_volume": float(nominal_voxel_volume),
        "min_measurement_volume": float(measurement_volume_by_voxel.min()),
        "median_measurement_volume": float(np.median(measurement_volume_by_voxel)),
        "max_measurement_volume": float(measurement_volume_by_voxel.max()),
        "adjusted_boundary_voxels": adjusted_boundary_voxels,
        "dims": [int(v) for v in dims],
        "total_voxels": int(dims[0] * dims[1] * dims[2]),
        "occupied_voxels": int(occupied),
        "average_particles_per_occupied_voxel": float(average),
        "min_particles_per_occupied_voxel": int(counts_by_voxel.min()),
        "max_particles_per_occupied_voxel": int(counts_by_voxel.max()),
        "min_void_ratio": float(void_by_voxel.min()),
        "median_void_ratio": float(np.median(void_by_voxel)),
        "max_void_ratio": float(void_by_voxel.max()),
        "negative_void_ratio_voxels": int(np.count_nonzero(void_by_voxel < 0.0)),
        "smooth_method": "face_reconstructed_two_point_gauss",
        "gauss_point_count": 8,
        "sphere_clip_order": int(sphere_clip_order),
        "min_smoothed_void_ratio": float(smoothed_void_by_voxel.min()),
        "median_smoothed_void_ratio": float(np.median(smoothed_void_by_voxel)),
        "max_smoothed_void_ratio": float(smoothed_void_by_voxel.max()),
        "unique_linear_voxels": unique_linear,
    }
    
    return void_by_particle, smoothed_void_by_particle, stats, voxel_data
```

**Parameters:**
- `sphere_clip_order`: 2, 4, or 8. Higher orders increase accuracy of the sphere-box intersection integral [S1, unofficial].
- `target_particles_per_voxel`: Controls resolution. Typical values depend on point cloud density [S1, unofficial].

**Edge Cases:**
- If `max_extent <= 0.0`, raise `RuntimeError` [S1, unofficial].
- Boundary voxels (index 0 or `dims-1`) are adjusted to use local particle extents, preventing negative void ratios due to over-measurement [S1, unofficial].
- Negative void ratios can occur if `measurement_volume < solid_volume` due to numerical precision or tight clipping [S1, unofficial].

## Subtopics

### Compute Void Ratio (Plain)
A plain Python implementation of void ratio computation, using dictionaries and loops instead of NumPy. It calculates mins, maxs, and extents, raising `RuntimeError` if `max_extent <= 0.0`. It uses binary search (45 iterations) for voxel sizing, maps points to voxel keys, and accumulates counts, solid volume, and local bounds per voxel. It adjusts box bounds for boundary voxels and calculates measurement volume. It uses `accumulate_clipped_solid_plain` for solid volume integration [S1, unofficial].

## Operating characteristics
- **Time Complexity:** Dominated by the binary search for voxel size and the accumulation of solid volume. The NumPy version uses vectorized operations for indexing and bounds, making it significantly faster than the plain Python version for large $N$.
- **Memory Complexity:** $O(N + M)$, where $N$ is the number of points and $M$ is the number of occupied voxels.
- **Strengths:** Handles boundary effects accurately; provides both raw and smoothed void ratios; efficient for large point clouds via NumPy.
- **Limitations:** Requires NumPy; sensitive to `target_particles_per_voxel` choice; sphere-box intersection integration can be computationally expensive for high `sphere_clip_order`.
- **When to use:** When processing legacy ASCII VTK particle point clouds and needing accurate void ratio fields for volume rendering.
- **When not to use:** When memory is extremely constrained (use plain version with lower resolution) or when real-time performance is critical without GPU acceleration.
