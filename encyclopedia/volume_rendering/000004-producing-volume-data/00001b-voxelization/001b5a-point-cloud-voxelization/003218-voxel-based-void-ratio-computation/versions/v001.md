# Voxel-based Void Ratio Computation

Also called: Particle Voxelization, Void Ratio Field Computation

## Overview
This method computes a void ratio field from a legacy ASCII VTK particle point cloud by binning particle centers into cubic voxels, calculating the void ratio for each occupied voxel, and assigning that value to all particles within the voxel [S1, unofficial]. It differs from sibling methods like [Hard Voxelization](5345-hard-voxelization.md) by explicitly handling partial sphere-voxel intersections for volume accumulation and providing a smoothed field via face-reconstructed Gauss quadrature, rather than simple binary occupancy [S1, unofficial].

## How it works
**Inputs and Outputs:**
- **Input:** A legacy ASCII VTK `POLYDATA` file containing particle positions and a scalar array for particle radii [S1, unofficial].
- **Output (Default):** A VTK `POLYDATA` file with the computed void ratio stored as `POINT_DATA` on the original particles [S1, unofficial].
- **Output (Optional):** A VTK `UNSTRUCTURED_GRID` file containing `VTK_VOXEL` cells for each occupied voxel, with fields `void_ratio`, `void_ratio_smoothed`, `particle_count`, `solid_volume`, and `measurement_volume` stored as `CELL_DATA` [S1, unofficial].

**Data Structures:**
- **Voxel Grid:** Implicitly managed via a hash map or dictionary mapping voxel indices $(i, j, k)$ to computed values.
- **Voxel Index:** Computed as $indices = \lfloor (points - mins) / size \rfloor$, where $points$ are particle centers, $mins$ are the minimum bounds of the point cloud, and $size$ is the voxel dimension [S1, unofficial].

**Parameters:**
- `-n` (`--particles-per-voxel`): Target average number of particles per occupied voxel. Larger values result in larger voxels [S1, unofficial].
- `--sphere-clip-order`: Gauss-Legendre quadrature order for estimating sphere/voxel intersection volumes. Default is 4. Higher values increase accuracy but also computational cost [S1, unofficial].
- `--smoothed-void-field`: Name of the face-reconstructed Gauss field written to the output. Default: `void_ratio_smoothed` [S1, unofficial].
- `--void-field`: Name of the raw void-ratio field. Default: `void_ratio` [S1, unofficial].
- `--voxel-output`: Path for an additional VTK file containing actual voxel cells [S1, unofficial].
- `--allow-other-vtk`: Flag to bypass the strict VTK 7.1 version check [S1, unofficial].

**Steps:**
1. **Read Input:** Load particle positions and radius scalar array from the VTK file. Ensure all scalar, vector, tensor, and normal arrays are read by enabling `ReadAll*On` methods, as legacy readers may skip arrays not explicitly requested [S1, unofficial].
2. **Calculate Voxel Size:** Determine the voxel size based on the target number of particles per voxel and the total volume of the point cloud extents [S1, unofficial].
3. **Bin Particles:** Assign each particle to a voxel index using the formula $indices = \lfloor (points - mins) / size \rfloor$ [S1, unofficial].
4. **Compute Solid Volume:** For each occupied voxel, calculate the solid volume by summing the volumes of particle spheres clipped to the voxel boundaries. This is done using Gauss-Legendre quadrature [S1, unofficial].
5. **Compute Void Ratio:** Calculate the void ratio $e$ for each voxel using the formula:
   $$e = \frac{V_{voxel} - \sum(V_{sphere\ particles\ in\ voxel})}{\sum(V_{sphere})}$$
   where $V_{voxel}$ is the voxel volume, and the sums are over the clipped volumes of spheres and total sphere volumes of particles within the voxel, respectively [S1, unofficial].
6. **Assign Values:** Assign the computed void ratio to all particles belonging to that voxel [S1, unofficial].
7. **Smooth Field (Optional):** Compute a smoothed void ratio field using face-reconstructed Gauss quadrature. This involves averaging the voxel value with its six neighbors to estimate face values, then applying two-point Gauss quadrature within each voxel [S1, unofficial].
8. **Write Output:** Write the results to the specified VTK files [S1, unofficial].

**Pseudocode:**

```python
import math
import numpy as np

def sphere_box_intersection_volume_numpy(center, radius, box_min, box_max, nodes, weights):
    """
    Computes the volume of intersection between a sphere and a box using Gauss-Legendre quadrature.
    
    Args:
        center: (x, y, z) center of the sphere.
        radius: Radius of the sphere.
        box_min: (x, y, z) minimum corner of the box.
        box_max: (x, y, z) maximum corner of the box.
        nodes: 1D array of Gauss-Legendre nodes.
        weights: 1D array of Gauss-Legendre weights.
        
    Returns:
        Float volume of intersection.
    """
    sphere_min = center - radius
    sphere_max = center + radius
    clipped_min = np.maximum(box_min, sphere_min)
    clipped_max = np.minimum(box_max, sphere_max)
    
    # Check for no intersection
    if np.any(clipped_max <= clipped_min):
        return 0.0
    
    # Check for full containment
    if np.all(box_min <= sphere_min) and np.all(box_max >= sphere_max):
        return (4.0 / 3.0) * math.pi * radius ** 3
    
    # Transform to local coordinates relative to sphere center
    x0, y0, z0 = clipped_min - center
    x1, y1, z1 = clipped_max - center
    
    x_mid = 0.5 * (x0 + x1)
    y_mid = 0.5 * (y0 + y1)
    x_half = 0.5 * (x1 - x0)
    y_half = 0.5 * (y1 - y0)
    
    # Create grid for quadrature
    x = x_mid + x_half * nodes
    y = y_mid + y_half * nodes
    xx = x[:, None]
    yy = y[None, :]
    
    # Calculate remaining radius squared in xy plane
    remaining = radius * radius - xx * xx - yy * yy
    valid = remaining > 0.0
    
    # Calculate z-radius for valid points
    z_radius = np.zeros_like(remaining)
    z_radius[valid] = np.sqrt(remaining[valid])
    
    # Clip z-range to box and sphere
    z_low = np.maximum(z0, -z_radius)
    z_high = np.minimum(z1, z_radius)
    
    # Calculate height of intersection
    height = np.maximum(z_high - z_low, 0.0)
    
    # Integrate using weights
    return float(x_half * y_half * np.sum((weights[:, None] * weights[None, :]) * height))

def evaluate_face_reconstruction_at_gauss_plain(e0, face_values):
    """
    Evaluates the smoothed void ratio at the center of a voxel using face values.
    
    Args:
        e0: Void ratio at the voxel center.
        face_values: Array of 6 face values [ex_minus, ex_plus, ey_minus, ey_plus, ez_minus, ez_plus].
        
    Returns:
        Smoothed void ratio value.
    """
    ex_minus, ex_plus, ey_minus, ey_plus, ez_minus, ez_plus = face_values
    
    ax = 0.5 * (ex_plus - ex_minus)
    bx = 0.5 * (ex_plus + ex_minus) - e0
    ay = 0.5 * (ey_plus - ey_minus)
    by = 0.5 * (ey_plus + ey_minus) - e0
    az = 0.5 * (ez_plus - ez_minus)
    bz = 0.5 * (ez_plus + ez_minus) - e0
    
    gp = 1.0 / math.sqrt(3.0)
    total = 0.0
    count = 0
    
    # Two-point Gauss quadrature in 3D
    for xi in (-gp, gp):
        for eta in (-gp, gp):
            for zeta in (-gp, gp):
                total += (
                    e0
                    + ax * xi + bx * xi * xi
                    + ay * eta + by * eta * eta
                    + az * zeta + bz * zeta * zeta
                )
                count += 1
                
    return total / float(count)

def face_reconstructed_gauss_smooth_plain(voxel_keys, values_by_voxel):
    """
    Computes the smoothed void ratio for all occupied voxels.
    
    Args:
        voxel_keys: List of voxel indices (tuples).
        values_by_voxel: Dictionary mapping voxel indices to void ratio values.
        
    Returns:
        Dictionary mapping voxel indices to smoothed void ratio values.
    """
    voxel_keys = list(voxel_keys)
    occupied = set(voxel_keys)
    smoothed = {}
    
    for key in voxel_keys:
        e0 = values_by_voxel[key]
        face_values = []
        
        # Get face values from neighbors
        for axis, step in ((0, -1), (0, 1), (1, -1), (1, 1), (2, -1), (2, 1)):
            neighbor = list(key)
            neighbor[axis] += step
            neighbor = tuple(neighbor)
            if neighbor in occupied:
                face_values.append(0.5 * (e0 + values_by_voxel[neighbor]))
            else:
                face_values.append(e0)
                
        smoothed[key] = evaluate_face_reconstruction_at_gauss_plain(e0, face_values)
        
    return smoothed

def compute_void_ratio(point_cloud, voxel_size, quadrature_order):
    """
    Main function to compute void ratio field.
    
    Args:
        point_cloud: Dictionary or array of particle positions and radii.
        voxel_size: Size of each voxel.
        quadrature_order: Order of Gauss-Legendre quadrature.
        
    Returns:
        Dictionary mapping voxel indices to void ratio values.
    """
    # 1. Read Input
    # (Implementation details depend on VTK reader)
    
    # 2. Calculate Voxel Size
    # (Determined by --particles-per-voxel parameter)
    
    # 3. Bin Particles
    mins = np.min(point_cloud['positions'], axis=0)
    indices = np.floor((point_cloud['positions'] - mins) / voxel_size).astype(int)
    
    # Group particles by voxel
    voxels = {}
    for i, idx in enumerate(indices):
        key = tuple(idx)
        if key not in voxels:
            voxels[key] = []
        voxels[key].append(i)
        
    # 4. Compute Solid Volume and Void Ratio
    # Get Gauss-Legendre nodes and weights
    nodes, weights = np.polynomial.legendre.leggauss(quadrature_order)
    
    void_ratios = {}
    for key, particle_indices in voxels.items():
        # Define voxel boundaries
        box_min = mins + key * voxel_size
        box_max = box_min + voxel_size
        
        total_solid_volume = 0.0
        total_sphere_volume = 0.0
        
        for idx in particle_indices:
            pos = point_cloud['positions'][idx]
            radius = point_cloud['radii'][idx]
            
            # Compute clipped sphere volume
            v_sphere = sphere_box_intersection_volume_numpy(pos, radius, box_min, box_max, nodes, weights)
            total_solid_volume += v_sphere
            total_sphere_volume += (4.0 / 3.0) * math.pi * radius ** 3
            
        voxel_volume = voxel_size ** 3
        if total_sphere_volume == 0:
            void_ratios[key] = 0.0
        else:
            void_ratios[key] = (voxel_volume - total_solid_volume) / total_sphere_volume
            
    return void_ratios
```

**Edge Cases and Pitfalls:**
- **VTK Version:** VTK 7.1 is required because newer versions mishandle the file in the workflow. Use `--allow-other-vtk` to override if necessary [S1, unofficial].
- **Data Loading:** VTK legacy readers do not always load every point-data array unless explicitly asked via `ReadAll*On` methods. This is critical because the radius array may appear after several vector arrays [S1, unofficial].
- **Degenerate Extents:** If the point cloud extents are degenerate (max_extent <= 0.0), the voxel size calculation raises a `RuntimeError` [S1, unofficial].

## Operating characteristics
- **Time Complexity:** Depends on the number of particles $N$, the number of occupied voxels $V$, and the quadrature order $Q$. Binning is $O(N)$. Volume computation is $O(V \cdot Q^2)$ per particle on average, assuming constant particles per voxel. Smoothing is $O(V)$.
- **Memory Complexity:** $O(N)$ to store particle data and voxel indices. $O(V)$ to store voxel values.
- **Strengths:** Provides a physically meaningful void ratio field that accounts for partial sphere overlaps. The smoothed field helps visualize gradients.
- **Limitations:** Computationally expensive for high quadrature orders or large point clouds. Requires VTK 7.1 for reliable reading.
- **When to Use:** When analyzing granular materials or particle systems where void ratio is a key metric and partial volume effects are significant.
- **When Not to Use:** When real-time performance is critical or when only binary occupancy is needed.
