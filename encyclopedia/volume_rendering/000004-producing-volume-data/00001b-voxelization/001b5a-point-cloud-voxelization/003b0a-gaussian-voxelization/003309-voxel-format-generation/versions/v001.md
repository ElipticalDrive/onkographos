# Voxel Format Generation

Also called: Collision Mesh Generation, Splat Transform Voxelizer

## Overview
Voxel Format Generation converts 3D Gaussian Splats into a sparse voxel octree optimized for collision detection and navigation, outputting metadata (`.voxel.json`) and binary data (`.voxel.bin`), and optionally generating a `.collision.glb` mesh [S1]. It distinguishes itself from general-purpose voxelization by integrating scene topology analysis (interior vs. exterior) and agent-based navigation carving directly into the voxelization pipeline, rather than treating them as separate post-processing steps [S1].

## How it works
**Inputs and Outputs:**
- Input: A 3D Gaussian Splat file (PLY, SPLAT, KSPLAT, SOG, or HTML) [S1].
- Outputs:
  - `.voxel.json`: Metadata describing the octree structure, resolution, and bounds [S1].
  - `.voxel.bin`: Binary representation of the sparse voxel octree [S1].
  - `.collision.glb` (optional): A mesh derived from the voxel grid [S1].

**Data Structures:**
The output relies on a sparse voxel octree. The binary format (`.voxel.bin`) stores the octree nodes, while the JSON file (`.voxel.json`) stores metadata including the voxel resolution and bounding box [S1]. The specific bit-packing of the binary octree nodes is not detailed in the sources [S1].

**Parameters:**
- `voxelResolution`: Size of each voxel in world units. Default: 0.05 [S1].
- `opacityCutoff`: Opacity threshold for solid voxels. Voxels with opacity below this value are treated as empty. Default: 0.1 [S1].
- `navExteriorRadius`: Exterior fill radius in world units. Enables exterior fill logic. Requires `navSeed` [S1].
- `floorFill`: Boolean to fill voxel columns upward from the bottom until hitting a solid surface. Runs before carving. Default: false [S1].
- `floorFillDilation`: Dilation radius in world units to identify 'interior' XZ columns. Empty XZ areas larger than $2 \times \text{floorFillDilation}$ from any solid column are treated as exterior. Default: 0 [S1].
- `navCapsule`: Object `{height, radius}` defining the dimensions for the navigation carve. Height 0 disables carving. Requires `navSeed` [S1].
- `--seed-pos <x,y,z>`: Seed position for voxel fill/carve and cluster filtering. Default: 0,0,0 [S1].

**Algorithm Steps:**
1. **Filter Cluster:** Isolate the central scene and discard stray floaters. This requires a `--seed-pos` to define the interior [S1].
2. **Scene Classification & Fill:**
   - **Interior Scenes:** Use `--voxel-external-fill` to seal the void around the room interior. This step verifies volume enclosure using the seed position; if the seed is reachable from outside, the fill is skipped [S1].
   - **Exterior Scenes:** Use `--voxel-floor-fill` to fill the ground beneath surfaces. This fills voxel columns upward from the bottom until hitting a solid surface. It uses `floorFillDilation` to distinguish interior XZ columns from exterior ones [S1].
3. **Carve Navigation Space:** Use `--voxel-carve` to hollow out navigable space using a capsule flood fill from the seed position. The capsule dimensions are defined by `navCapsule` [S1].
4. **Generate Collision Mesh (Optional):** Use `--collision-mesh` to generate a mesh from the voxel grid. Two shapes are supported:
   - `smooth`: Uses marching cubes with lossless coplanar merge for smoother geometry [S1].
   - `faces`: Provides direct watertight voxel-boundary faces [S1].

**Pseudocode:**
```python
def generate_voxel_format(input_splat_path, output_voxel_json_path, options):
    # 1. Load and Filter
    splats = load_splats(input_splat_path)
    seed_pos = options.get('seed_pos', (0, 0, 0))
    
    # Filter cluster: isolate central scene, discard floaters
    if options.get('filter_cluster', False):
        splats = filter_cluster(splats, seed_pos)
    
    # 2. Voxelization
    voxel_resolution = options.get('voxel_resolution', 0.05)
    opacity_cutoff = options.get('opacity_cutoff', 0.1)
    
    # Initialize sparse octree
    octree = SparseVoxelOctree(resolution=voxel_resolution)
    
    # Insert splats into octree
    for splat in splats:
        if splat.opacity > opacity_cutoff:
            octree.insert(splat)
            
    # 3. Scene Processing (Fill and Carve)
    is_interior = options.get('is_interior', False)
    
    if is_interior:
        # Seal void around room interior
        # Verify seed is enclosed; if reachable from outside, skip fill
        if is_seed_enclosed(octree, seed_pos):
            octree.external_fill(seed_pos)
    else:
        # Fill ground beneath surfaces
        floor_fill = options.get('floor_fill', False)
        floor_fill_dilation = options.get('floor_fill_dilation', 0)
        
        if floor_fill:
            octree.floor_fill(dilation_radius=floor_fill_dilation)
            
    # Carve navigation space
    nav_capsule = options.get('nav_capsule', {'height': 1.6, 'radius': 0.2})
    if nav_capsule['height'] > 0:
        octree.carve_navigation(seed_pos, nav_capsule)
        
    # 4. Output
    write_voxel_metadata(octree, output_voxel_json_path, {
        'resolution': voxel_resolution,
        'opacity_cutoff': opacity_cutoff
    })
    write_voxel_binary(octree, output_voxel_json_path.replace('.json', '.bin'))
    
    # 5. Optional Collision Mesh
    if options.get('collision_mesh'):
        mesh_shape = options.get('collision_mesh_shape', 'smooth')
        if mesh_shape == 'smooth':
            mesh = marching_cubes_with_coplanar_merge(octree)
        elif mesh_shape == 'faces':
            mesh = voxel_boundary_faces(octree)
        else:
            raise ValueError(f"Unknown mesh shape: {mesh_shape}")
        write_glb(mesh, output_voxel_json_path.replace('.json', '.collision.glb'))
```

## Subtopics

### Splat Transform CLI
A command-line tool for converting between various splat formats (PLY, SPLAT, KSPLAT, SOG, HTML) and generating voxel/collision data [S1]. It supports additional operations such as scaling, translating, rotating, filtering (NaN/Inf removal, opacity thresholding, harmonic stripping, decimation), and statistics generation [S1]. The voxel external fill logic uses `--seed-pos` to verify volume enclosure; if the seed is reachable from outside, the fill is skipped [S1]. Key parameters include `--voxel-size` (default 0.05), `--voxel-opacity` (default 0.1), `--voxel-floor-fill` (default size 1.6), `--voxel-carve` (default height 1.6, radius 0.2), and `--collision-mesh` (default 'smooth') [S1].

**Strengths and Limitations:**
- **Strengths:** Integrates collision mesh generation and navigation carving directly into the voxelization pipeline, handling both interior and exterior scenes with specific fill strategies [S1]. Supports multiple input and output formats including compressed PLY and SOG [S1].
- **Limitations:** The binary octree format details are not specified, potentially limiting interoperability with other engines [S1]. The tool is currently in beta for generator scripts [S1].

**When to Use:**
Use when you need to convert 3D Gaussian Splats into a format suitable for collision detection and navigation in a game engine or simulation, particularly when using the PlayCanvas ecosystem [S1].

**When Not to Use:**
Avoid if you require a dense voxel representation or if you need to integrate with engines that do not support the specific `.voxel.json` and `.voxel.bin` format [S1].

## Background
Voxel Format Generation is part of the `splat-transform` tool developed by PlayCanvas [S1]. It is designed to bridge the gap between 3D Gaussian Splatting data and traditional collision detection systems by generating sparse voxel octrees [S1]. The tool supports various splat formats and provides utilities for scene analysis and mesh generation [S1].
