# 3D Gaussian Voxelization

Also called: Voxelization of 3D Gaussians

## Overview
3D Gaussian Voxelization converts a set of 3D Gaussians into a set of unique voxels and their associated features to enable efficient processing by 3D neural networks [S1, unofficial]. It differs from hard voxelization by sampling voxel locations based on the geometric extent of each Gaussian rather than simply rasterizing points, allowing for denser feature embedding [S1, unofficial]. This method builds on [Point Cloud Voxelization](1000-point-cloud-voxelization.md) by adapting the sampling strategy to continuous Gaussian distributions.

## How it works
**Inputs:**
- `gaussians`: A list of 3D Gaussian parameters. Each element is typically a dictionary containing at least a "scale" key, and potentially position or other attributes required by the sampling logic [S1, unofficial].
- `grid_size`: A float defining the physical size of each voxel cell [S1, unofficial].

**Outputs:**
- `uni_voxels_xyz`: A list of tuples `(float, float, float)` representing the coordinates of unique voxels [S1, unofficial].
- `uni_voxel_feats`: A list of feature vectors corresponding to each unique voxel [S1, unofficial].
- `inverse_indices`: A list of integers mapping each original generated voxel to its index in the unique voxel list [S1, unofficial].
- `num_voxels_per_g`: A list of integers indicating the number of voxels sampled from each 3D Gaussian [S1, unofficial].

**Parameters:**
- `SAMPLE_SHAPE`: A literal string controlling the geometric shape used for sampling voxels around each Gaussian. Options include `"volume"`, `"tri-plane"`, `"tri-line"`, and `"center"`. The default value is `"center"` [S1, unofficial].

**Algorithm:**
1. **Count Voxels:** Determine the number of voxels required for each Gaussian based on its scale and the `SAMPLE_SHAPE` using `count_voxels_per_g(gaussians, grid_size)` [S1, unofficial].
2. **Compose Features:** Generate voxel coordinates and associated features for all Gaussians using `compose_voxels_per_g(gaussians, num_voxels_per_g)` [S1, unofficial].
3. **Deduplicate:** Remove duplicate voxels from the generated set. This step produces the unique voxel coordinates, aggregated features, and an inverse index mapping from the original generated voxels to the unique list using `return_unique_voxels(voxels_xyz, voxel_feats)` [S1, unofficial].

**Pseudocode:**
```python
from typing import List, Tuple
from typing_extensions import Literal

# Global variable indicating the shape to be sampled
SAMPLE_SHAPE: Literal["volume", "tri-plane", "tri-line", "center"] = "center"

def voxelization(gaussians: List[dict], grid_size: float) -> Tuple[List[Tuple[float, float, float]], List, List[int], List[int]]:
    """
    Convert a set of 3D Gaussians into a set of unique voxels and their associated features.
    
    Args:
        gaussians : List[dict]
            A list of 3D Gaussian parameters. Each Gaussian is typically a dictionary
            containing at least a "scale" key (and possibly position or other attributes)
            needed by the downstream functions.
        grid_size : float
            A hyperparameter defining the size of each voxel.
            
    Returns:
        uni_voxels_xyz : List[Tuple[float, float, float]]
            The (x, y, z) coordinates of the unique voxels.
        uni_voxel_feats : List
            The feature vectors corresponding to each unique voxel.
        inverse_indices : List[int]
            A list of indices that maps each original voxel back to its corresponding
            index in the unique voxel list.
        num_voxels_per_g: List[int]
            A list of number of voxels that are sampled from each 3D Gaussian.
    """
    # Step 1: Count how many voxels will be needed for each Gaussian
    # based on the current SAMPLE_SHAPE (e.g., "volume", "tri-plane", etc.)
    num_voxels_per_g = count_voxels_per_g(gaussians, grid_size)
    
    # Step 2: Generate voxel coordinates and features for all Gaussians
    # Produces the (x, y, z) coordinates and associated features for each sampled voxel
    voxels_xyz, voxel_feats = compose_voxel_features(gaussians, num_voxels_per_g)
    
    # Step 3: Remove duplicates, resulting in a unique set of voxel coordinates,
    # their corresponding features, and an index map that indicates how each original
    # voxel maps to the new unique list.
    uni_voxels_xyz, uni_voxel_feats, inverse_indices = return_unique_voxels(voxels_xyz, voxel_feats)
    
    return uni_voxels_xyz, uni_voxel_feats, inverse_indices, num_voxels_per_g

# Helper functions are assumed to be defined elsewhere in the implementation:
# def count_voxels_per_g(gaussians, grid_size): ...
# def compose_voxel_features(gaussians, num_voxels_per_g): ...
# def return_unique_voxels(voxels_xyz, voxel_feats): ...
```

**Edge Cases and Pitfalls:**
- The definition of `gaussians` as a list of dictionaries implies that the structure of each Gaussian object must be consistent and accessible by the helper functions [S1, unofficial].
- The `SAMPLE_SHAPE` parameter significantly affects the number of voxels generated and the spatial distribution of features; choosing an inappropriate shape may lead to inefficient memory usage or loss of geometric fidelity [S1, unofficial].
- Precision issues may arise if `grid_size` is very small relative to the Gaussian scales, leading to a large number of voxels [G].

## Subtopics

### [De-voxelization](8432-de-voxelization.md)
Aggregates network predictions from unique voxels back to full voxel predictions, then reduces them into per-Gaussian predictions using scatter operations.

## Operating characteristics
Time and memory complexity are not explicitly given in the sources. The method's efficiency depends on the number of Gaussians, their scales, and the chosen `SAMPLE_SHAPE` [S1, unofficial]. The deduplication step is critical for reducing redundancy, especially when Gaussians overlap significantly [S1, unofficial].

## Background
This method is described in the context of "Quantile Rendering: Efficiently Embedding High-dimensional Feature on 3D Gaussian Splatting" [S1, unofficial]. It is used to facilitate the embedding of high-dimensional features onto 3D Gaussian Splatting representations by converting them into a voxel grid suitable for 3D neural network processing [S1, unofficial].
