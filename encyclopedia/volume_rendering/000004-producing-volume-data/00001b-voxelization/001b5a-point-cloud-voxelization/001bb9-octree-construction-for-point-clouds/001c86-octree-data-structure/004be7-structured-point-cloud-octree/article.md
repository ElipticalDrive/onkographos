# Structured Point Cloud Octree

Also called: Octree Acceleration Structure (SPC-based), OctreeAS

## Overview
The Structured Point Cloud (SPC) Octree is an acceleration structure for neural fields that uses a Structured Point Cloud representation to encode a sparse octree [S1, unofficial]. It enables efficient querying of cell occupancy and fast ray tracing against the volume for raymarching [S1, unofficial]. It differs from standard octree implementations by storing topology in a compact, batch-friendly tensor format optimized for GPU execution, specifically designed to support the high-throughput queries required by neural radiance fields (NeRF) and similar implicit representations [S1, unofficial].

## How it works
### Inputs and Outputs
**Inputs:**
- `octree`: A tensor representing the initial octree state.
- `mesh` (optional): A mesh defined by vertices and faces, used to generate occupancy.
- `pointcloud` (optional): A set of 3D points in normalized space `[-1, 1]`.
- `quantized_points` (optional): Integer coordinates in `[0, 2^level]`.
- `rays`: Ray origins and directions for tracing.
- `coords`: Query coordinates for occupancy checks.
- `level`: The depth of the octree. If `None`, defaults to `self.max_level` [S1, unofficial].

**Outputs:**
- `self.points`, `self.pyramid`, `self.prefix`: Tensors representing the SPC structure.
- `ASQueryResults`: Contains `pidx` (indices into point hierarchy). If `with_parents` is True, shape is `[num_query, level+1]` [S1, unofficial].
- `ASRaytraceResults`: Contains `ridx` (ray indices), `pidx` (point indices), and `depth` [S1, unofficial].

### Data Structures
The SPC topology is stored in `self.octree` as a `torch.ByteTensor` [S1, unofficial].
- **Layout**: Each byte represents a single octree cell's occupancy. Each bit of that byte represents the occupancy status of a child octree cell (8 bits for 8 children) [S1, unofficial].
- **Auxiliary Tensors**: The structure maintains `self.points`, `self.pyramid`, and `self.prefix` tensors, generated by `wisp_spc_ops.octree_to_spc` [S1, unofficial].
- **Max Level**: Calculated as `self.max_level = self.pyramid.shape[-1] - 2` [S1, unofficial].

### Building the Octree
The octree can be initialized from various sources using specific operations from the `wisp_spc_ops` library [S1, unofficial].

1. **From Octree Tensor**:
   - Call `wisp_spc_ops.octree_to_spc(octree)` to generate `self.points`, `self.pyramid`, and `self.prefix` [S1, unofficial].

2. **From Mesh**:
   - Load the OBJ file using `mesh_ops.load_obj` [S1, unofficial].
   - Normalize vertices and faces to a sphere using `mesh_ops.normalize(vertices, faces, 'sphere')` [S1, unofficial].
   - Generate the octree using `wisp_spc_ops.mesh_to_octree(vertices, faces, level, num_samples_on_mesh)` [S1, unofficial].
   - Store vertices and faces in `accel_struct.extent` [S1, unofficial].
   - *Pitfall*: This conversion is not deterministic because it relies on sampling. It may not reproduce a perfect mesh structure without 'holes', though it achieves a good approximation with high probability [S1, unofficial].

3. **From Point Cloud**:
   - Call `wisp_spc_ops.pointcloud_to_octree(pointcloud, level, dilate=0)` where `pointcloud` is shape `[num_coords, 3]` in normalized space `[-1, 1]` [S1, unofficial].

4. **From Quantized Points**:
   - Call `spc_ops.unbatched_points_to_octree(quantized_points, level, sorted=False)` where `quantized_points` is shape `[num_coords, 3]` in integer coordinate space `[0, 2**level]` [S1, unofficial].

5. **Dense Octree**:
   - Call `wisp_spc_ops.create_dense_octree(level)` to initialize full occupancy of all cells [S1, unofficial].

### Querying Occupancy
To query cell occupancy:
1. Call `spc_ops.unbatched_query(self.octree, self.prefix, coords, level, with_parents)` [S1, unofficial].
2. If `level` is `None`, it defaults to `self.max_level` [S1, unofficial].
3. Returns `ASQueryResults` containing `pidx` (indices into point hierarchy) [S1, unofficial].
4. If `with_parents` is True, the result shape is `[num_query, level+1]` [S1, unofficial].

### Ray Tracing
To trace rays against the volume:
1. Call `spc_render.unbatched_raytrace(self.octree, self.points, self.pyramid, self.prefix, rays.origins, rays.dirs, level, return_depth=True, with_exit=with_exit)` [S1, unofficial].
2. If `level` is `None`, it defaults to `self.max_level` [S1, unofficial].
3. Returns `ASRaytraceResults` with `ridx` (ray indices), `pidx` (point indices), and `depth` [S1, unofficial].

```python
import torch
from typing import Tuple

class StructuredPointCloudOctree:
    def __init__(self, octree: torch.Tensor):
        """
        Initialize the SPC Octree from an octree tensor.
        """
        # Generate SPC components from the octree tensor
        self.points, self.pyramid, self.prefix = wisp_spc_ops.octree_to_spc(octree)
        # Calculate max level from pyramid shape
        self.max_level = self.pyramid.shape[-1] - 2

    def build_from_mesh(self, obj_path: str, level: int, num_samples_on_mesh: int = 100000000):
        """
        Build the octree from a mesh file.
        """
        # Load mesh
        vertices, faces = mesh_ops.load_obj(obj_path)
        
        # Normalize to sphere
        vertices, faces = mesh_ops.normalize(vertices, faces, 'sphere')
        
        # Generate octree
        octree_tensor = wisp_spc_ops.mesh_to_octree(vertices, faces, level, num_samples_on_mesh)
        
        # Initialize parent class logic
        self.points, self.pyramid, self.prefix = wisp_spc_ops.octree_to_spc(octree_tensor)
        self.max_level = self.pyramid.shape[-1] - 2
        
        # Store mesh info for extent
        self.extent = {'vertices': vertices, 'faces': faces}

    def build_from_pointcloud(self, pointcloud: torch.Tensor, level: int, dilate: int = 0):
        """
        Build the octree from a point cloud in normalized space [-1, 1].
        """
        octree_tensor = wisp_spc_ops.pointcloud_to_octree(pointcloud, level, dilate)
        self.points, self.pyramid, self.prefix = wisp_spc_ops.octree_to_spc(octree_tensor)
        self.max_level = self.pyramid.shape[-1] - 2

    def query(self, coords: torch.Tensor, level: int = None, with_parents: bool = False):
        """
        Query occupancy for given coordinates.
        """
        if level is None:
            level = self.max_level
        results = spc_ops.unbatched_query(self.octree, self.prefix, coords, level, with_parents)
        return results

    def raytrace(self, rays_origins: torch.Tensor, rays_dirs: torch.Tensor, level: int = None, with_exit: bool = False):
        """
        Trace rays against the octree.
        """
        if level is None:
            level = self.max_level
        results = spc_render.unbatched_raytrace(
            self.octree, 
            self.points, 
            self.pyramid, 
            self.prefix, 
            rays_origins, 
            rays_dirs, 
            level, 
            return_depth=True, 
            with_exit=with_exit
        )
        return results

def fast_filter_method(mask_idx: torch.Tensor, depth: torch.Tensor, deltas: torch.Tensor, samples: torch.Tensor, num_samples: int, num_rays: int, device: torch.device) -> Tuple[torch.Tensor, torch.Tensor, torch.Tensor, torch.Tensor]:
    """
    Helper method to filter samples based on mask indices.
    """
    depth_samples = depth[mask_idx[:, 0], mask_idx[:, 1]][:, None]
    deltas = deltas[mask_idx[:, 0], mask_idx[:, 1]].reshape(-1, 1)
    samples = samples[mask_idx[:, 0], mask_idx[:, 1], :]
    ridx = torch.arange(0, num_rays, device=device)
    ridx = ridx[..., None].repeat(1, num_samples)[mask_idx[:, 0], mask_idx[:, 1]]
    return depth_samples, deltas, samples, ridx
```

### Parameters
- `level`: The depth of the octree (number of occupancy levels), used by the acceleration structure for fast raymarching. It determines the resolution of the sparse voxel grid [S1, unofficial].
- `num_samples_on_mesh`: The number of samples generated on the mesh surface to populate octree cells. Default is 100,000,000. Higher values produce more faithful occupancy but require more processing time [S1, unofficial].

### Edge Cases and Pitfalls
- **Non-determinism**: Mesh-to-octree conversion is not deterministic because it relies on sampling. It may not reproduce a perfect mesh structure without 'holes', though it achieves a good approximation with high probability [S1, unofficial].
- **Level Defaulting**: If `level` is not specified during query or raytrace, it defaults to `self.max_level`. Implementers must ensure `self.max_level` is correctly calculated from `self.pyramid.shape[-1] - 2` [S1, unofficial].

## Operating characteristics
- **Time Complexity**: Not given in the sources.

- **Strengths**: Optimized for GPU execution via CUDA extensions; supports batched operations; efficient for neural field raymarching [S1, unofficial].
- **Limitations**: Mesh conversion is non-deterministic; requires CUDA for full functionality (CPU support is limited) [S1, unofficial].
- **When to use**: When rendering neural fields or sparse volumes on GPU where fast ray tracing and occupancy queries are critical [S1, unofficial].
- **When not to use**: When deterministic mesh-to-voxel conversion is required; when running on CPU-only hardware [S1, unofficial].

## Background
The Structured Point Cloud Octree is part of the Kaolin-Wisp library, developed by NVIDIA [S1, unofficial]. It was introduced as an acceleration structure for neural fields, leveraging the efficiency of structured point clouds to represent sparse octrees [S1, unofficial]. The library is authored by Towaki Takikawa and licensed under the NVIDIA Source Code License [S1, unofficial].
