# Composite Reference Volume Generation

Also called: ALL volume, ALL/ANY Volumes, ANY volume, Intersection/Union Composite Volumes

## Overview
Composite Reference Volume Generation creates two binary composite volumes (ALL and ANY) from a set of reference expert volumes to define the maximal and minimal boundaries of expert performance [S1]. These composites serve as the ground truth against which resident test volumes are compared, accounting for variation in expert performance [S1]. Unlike [Occupancy Ground Truth Computation](18297-occupancy-ground-truth-computation.md), which computes occupancy for arbitrary coordinates via ray casting, this method aggregates a fixed set of discrete reference volumes using set-theoretic operations to establish mandatory and allowed removal zones [S1].

## How it works
**Inputs and Outputs**
*   **Input:** A set of reference volumes $R = \{V_1, V_2, ..., V_N\}$, where each $V_i$ is a binary volume of identical dimensions.
*   **Output:** Two composite binary volumes: $ALL$ and $ANY$, with the same dimensions as the input volumes.

**Data Structures**
*   **Reference Volume ($V$):** A 3D grid of voxels. Each voxel is binary: occupied (1) or empty (0).
*   **Composite Volumes ($ALL, ANY$):** 3D grids of the same dimensions as $V$, initialized to empty (0).

**Parameters**
*   **Reference Set Size ($N$):** The number of reference volumes in $R$. Typical value: 4 [S1].
*   **Volume Type:** Binary [S1].

**Algorithm**
1.  Initialize the $ALL$ volume grid to all zeros (empty).
2.  Initialize the $ANY$ volume grid to all zeros (empty).
3.  Iterate through every voxel position $(x, y, z)$ in the grid dimensions:
    a.  Check the occupancy of the voxel at $(x, y, z)$ in all reference volumes $V \in R$.
    b.  Compute the state for the $ALL$ volume:
        $$ ALL(x,y,z) = \bigwedge_{V \in R} V(x,y,z) $$
        The voxel is occupied in $ALL$ if and only if it is occupied in **all** reference volumes in $R$ [S1].
    c.  Compute the state for the $ANY$ volume:
        $$ ANY(x,y,z) = \bigvee_{V \in R} V(x,y,z) $$
        The voxel is occupied in $ANY$ if and only if it is occupied in **any** (at least one) reference volume in $R$ [S1].

**Pseudocode**
```python
def generate_composite_volumes(reference_volumes):
    """
    Generates ALL and ANY composite volumes from a set of reference binary volumes.
    
    Args:
        reference_volumes: List of 3D numpy arrays or similar grid structures.
                           Each array represents a binary volume (1 for occupied, 0 for empty).
                           All arrays must have the same shape.
                           
    Returns:
        all_volume: 3D binary array representing the intersection of all reference volumes.
        any_volume: 3D binary array representing the union of all reference volumes.
    """
    if not reference_volumes:
        raise ValueError("Reference set R cannot be empty.")
        
    # Assume all reference volumes have the same shape
    shape = reference_volumes[0].shape
    num_volumes = len(reference_volumes)
    
    # Initialize output volumes with zeros (empty)
    all_volume = np.zeros(shape, dtype=np.uint8)
    any_volume = np.zeros(shape, dtype=np.uint8)
    
    # Stack volumes into a single 4D array for efficient vectorized operations
    # Shape: (num_volumes, depth, height, width)
    stacked_volumes = np.stack(reference_volumes, axis=0)
    
    # Compute ALL volume: Intersection (logical AND across all reference volumes)
    # A voxel is occupied if it is 1 in ALL reference volumes
    # np.all returns True/False, cast to uint8 for binary volume
    all_volume = np.all(stacked_volumes == 1, axis=0).astype(np.uint8)
    
    # Compute ANY volume: Union (logical OR across all reference volumes)
    # A voxel is occupied if it is 1 in ANY reference volume
    # np.any returns True/False, cast to uint8 for binary volume
    any_volume = np.any(stacked_volumes == 1, axis=0).astype(np.uint8)
    
    return all_volume, any_volume
```

**Edge Cases and Pitfalls**
*   **Empty Reference Set:** The method requires at least one reference volume. If $R$ is empty, the intersection is undefined (or universally true depending on convention) and the union is universally false. The sources imply $N \ge 1$ [S1].
*   **Dimension Mismatch:** All reference volumes must have identical dimensions. If they do not, voxel-wise comparison is invalid [S1].
*   **Binary Assumption:** The method assumes binary inputs. If inputs are probabilistic or multi-label, the logical AND/OR operations must be adapted (e.g., thresholding first) [S1].

## Subtopics

## Operating characteristics
*   **Time Complexity:** $O(N \cdot D \cdot H \cdot W)$, where $N$ is the number of reference volumes, and $D, H, W$ are the depth, height, and width of the volume. Each voxel is visited once per reference volume.
*   **Memory Complexity:** $O((N + 2) \cdot D \cdot H \cdot W)$ to store the input reference volumes and the two output composite volumes.
*   **Strengths:** Simple, deterministic, and computationally inexpensive. It provides a clear, conservative (ALL) and permissive (ANY) boundary for expert performance [S1].
*   **Limitations:** It does not account for the frequency of expert agreement beyond binary presence/absence. It assumes all reference experts are equally valid. It is sensitive to registration errors between reference volumes [S1].
*   **When to use:** When a set of expert annotations is available and a binary ground truth range (mandatory vs. allowed) is needed for evaluating test subjects [S1].
*   **When not to use:** When expert performance varies in quality or when probabilistic ground truth is required [S1].

## Background
The method was introduced in the context of virtual mastoidectomy performance evaluation [S1]. It was developed to compare surgical resident performances (test set) against known expert performances (reference set) [S1]. The authors used 130 test volumes and 4 reference volumes to demonstrate the system's utility [S1]. The ALL volume represents mandatory bone removal areas (where all experts removed bone), and the ANY volume represents allowed removal areas (where at least one expert removed bone) [S1]. This approach accounts for variation in expert performance by defining maximal and minimal boundaries of the reference set [S1].
