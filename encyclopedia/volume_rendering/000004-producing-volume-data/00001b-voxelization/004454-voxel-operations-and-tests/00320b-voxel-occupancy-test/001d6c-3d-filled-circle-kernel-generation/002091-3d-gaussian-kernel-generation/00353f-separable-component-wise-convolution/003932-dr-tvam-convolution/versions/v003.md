# Dr. TVAM Convolution
Also called: Separable 3D Convolution with Gaussian Diffusion Kernels

## Overview
A separable 3D convolution method using Gaussian diffusion kernels, implemented via Dr.Jit's `dr.convolve` function for tomographic volumetric additive manufacturing simulations [S1, unofficial]. It builds on [Separable Component-Wise Convolution](7446-separable-component-wise-convolution.md) by applying specific Gaussian diffusion kernels rather than generic low-rank tensor decompositions [S1, unofficial].

## How it works
**Inputs:**
- Volumetric data tensor $r$ (shape: $N_z \times N_x \times N_y$) [S1, unofficial].
- Spatial spacing per axis: $s_z, s_x, s_y$ [S1, unofficial].
- Kernel radius per axis: $R_z, R_x, R_y$ (default 10) [S1, unofficial].
- Diffusion coefficient: $D$ [S1, unofficial].
- Time step: $\Delta t$ [S1, unofficial].

**Outputs:**
- Convolved volumetric data tensor $r'$ [S1, unofficial].

**Data Structures:**
- 1D Gaussian kernel arrays $k_z, k_x, k_y$ of length $2R + 2$ for each axis [S1, unofficial].

**Steps:**
1. **Generate 1D Gaussian Diffusion Kernel:**
   For each axis $a \in \{z, x, y\}$ with spacing $s_a$ and radius $R_a$:
   a. Create index array $i$ ranging from $-R_a$ to $R_a + 1$ [S1, unofficial].
   b. Compute coordinates: $c_i = i \cdot s_a$ [S1, unofficial].
   c. Compute unnormalized kernel values: $g_i = \exp\left(-\frac{c_i^2}{4 D \Delta t}\right)$ [S1, unofficial].
   d. Normalize: $k_{a,i} = \frac{g_i}{\sum_{j=-R_a}^{R_a+1} g_j}$ [S1, unofficial].

2. **Apply Separable Convolution:**
   The 3D convolution is decomposed into three sequential 1D convolutions along each axis using the generated kernels [S1, unofficial].
   a. Convolve along Z-axis: $r^{(1)} = \text{dr.convolve}(r, \text{filter}=k_z, \text{filter\_radius}=R_z, \text{axis}=0)$ [S1, unofficial].
   b. Convolve along X-axis: $r^{(2)} = \text{dr.convolve}(r^{(1)}, \text{filter}=k_x, \text{filter\_radius}=R_x, \text{axis}=1)$ [S1, unofficial].
   c. Convolve along Y-axis: $r' = \text{dr.convolve}(r^{(2)}, \text{filter}=k_y, \text{filter\_radius}=R_y, \text{axis}=2)$ [S1, unofficial].

**Pseudocode:**
```python
import drjit as dr

def generate_gaussian_kernel_1d(radius, spacing, diffusion_D, delta_t):
    """Generates a 1D Gaussian diffusion kernel matching the source specification."""
    indices = dr.arange(dr.int32, 2 * radius + 2) - radius
    coords = indices * spacing
    exponent = -(coords * coords) / (4.0 * diffusion_D * delta_t)
    values = dr.exp(exponent)
    kernel = values / dr.sum(values)
    return kernel

def dr_tvam_convolution(volume, spacing_z, spacing_x, spacing_y,
                        diffusion_D, delta_t,
                        radius_z=10, radius_x=10, radius_y=10):
    """Performs separable 3D convolution with Gaussian diffusion kernels."""
    kernel_z = generate_gaussian_kernel_1d(radius_z, spacing_z, diffusion_D, delta_t)
    kernel_x = generate_gaussian_kernel_1d(radius_x, spacing_x, diffusion_D, delta_t)
    kernel_y = generate_gaussian_kernel_1d(radius_y, spacing_y, diffusion_D, delta_t)

    r_temp1 = dr.convolve(volume, filter=kernel_z, filter_radius=radius_z, axis=0)
    r_temp2 = dr.convolve(r_temp1, filter=kernel_x, filter_radius=radius_x, axis=1)
    r_out = dr.convolve(r_temp2, filter=kernel_y, filter_radius=radius_y, axis=2)

    return r_out
```

**Parameters:**
- `spacingz`, `spacingx`, `spacingy`: Spatial spacing for each axis in the kernel coordinate calculation [S1, unofficial].
- `radiusz`, `radiusx`, `radiusy`: Kernel radius for each axis. Default value is 10 [S1, unofficial].
- `diffusion_D`: Diffusion coefficient [S1, unofficial].
- `delta_t`: Time step [S1, unofficial].

**Edge Cases and Pitfalls:**
- **Precision:** The exponential function may underflow for large negative exponents, resulting in zero weights. This is handled by the normalization step, but extremely small values might lead to numerical instability if not handled by the underlying `dr.convolve` implementation [G].
- **Boundaries:** The `dr.convolve` function must handle boundary conditions. The sources do not specify the boundary handling mode (e.g., zero-padding, replication, reflection) [S1, unofficial]. [G] Standard practice in such simulations often uses zero-padding or reflection, but the exact behavior depends on the Dr.Jit implementation.
- **Degenerate Input:** If `diffusion_D` or `delta_t` is zero, the exponent becomes undefined or infinite. The sources do not specify handling for these cases [S1, unofficial].

## Subtopics

### [Separable 3D Gaussian Filter](8956-separable-3d-gaussian-filter.md)
A 3D Gaussian filter implemented as three consecutive 1D filters to leverage separability for interactive performance. It serves as a low-pass filter that reduces high-frequency elements in volume data, often used to compute spatial importance maps for volume illustration. It sets itself apart from non-linear alternatives like the [Bilateral Filter](8983-bilateral-filter.md) by relying solely on spatial distance rather than value similarity, making it computationally faster but less effective at edge preservation.

## Operating characteristics
- **Time Complexity:** $O(N \cdot R)$, where $N$ is the number of voxels and $R$ is the kernel radius [G]. This is significantly faster than the $O(N \cdot R^3)$ complexity of a non-separable 3D convolution [G].
- **Memory Complexity:** $O(N)$ for the input and output volumes, plus $O(R)$ for the temporary kernels [G].
- **Strengths:** Computational efficiency due to separability; suitability for tomographic volumetric additive manufacturing simulations [S1, unofficial].
- **Limitations:** Requires the kernel to be separable (Gaussian kernels are separable); performance depends on the efficiency of the underlying `dr.convolve` implementation [G].
- **When to Use:** When performing tomographic volumetric additive manufacturing simulations where Gaussian diffusion is a valid model for the physical process [S1, unofficial].
- **When Not to Use:** When the kernel is not separable or when non-Gaussian diffusion models are required [G].

## Background
The method originates from research on tomographic volumetric additive manufacturing simulations [S1, unofficial]. It was developed to efficiently simulate the physical forward model in these simulations by applying Gaussian diffusion kernels to volumetric data [S1, unofficial].
