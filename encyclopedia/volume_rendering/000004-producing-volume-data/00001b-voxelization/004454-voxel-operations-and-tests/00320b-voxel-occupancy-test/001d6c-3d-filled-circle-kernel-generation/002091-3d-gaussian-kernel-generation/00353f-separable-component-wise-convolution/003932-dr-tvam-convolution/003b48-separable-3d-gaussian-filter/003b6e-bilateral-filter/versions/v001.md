# Bilateral Filter
Also called: Bilateral Filtering, Filtro bilateral
## Overview
A non-linear filter used to reduce noise while preserving edges by weighting pixels based on both spatial proximity and value similarity [S1, unofficial]. Unlike the [Separable 3D Gaussian Filter](8956-separable-3d-gaussian-filter.md) which only uses spatial distance, the Bilateral filter also uses value similarity, preserving edges better [S1, unofficial].

## How it works
**Inputs and Outputs:**
- Input: An image or volume data $I$, where $I_p$ is the value at pixel/voxel $p$.
- Output: The filtered value $BF(p)$ at each location $p$.
- Domain: A neighborhood $S$ (typically a square window) centered at $p$.

**Data Structures:**
- The filter operates on a grid. No complex data structures are required beyond the input data array and a temporary buffer for the output.

**Formulas:**
The bilateral filter output $BF(p)$ is defined as a weighted average of neighboring values [S1, unofficial]:

$$
BF(p) = \frac{1}{W_p} \sum_{q \in S} G_{\sigma_s}(\|p - q\|) G_{\sigma_r}(\|I_p - I_q\|) I_q
$$

Where the normalization factor $W_p$ is:

$$
W_p = \sum_{q \in S} G_{\sigma_s}(\|p - q\|) G_{\sigma_r}(\|I_p - I_q\|)
$$

The spatial Gaussian kernel $G_{\sigma_s}$ is defined as [S1, unofficial]:

$$
G_{\sigma_s}(x) = \frac{1}{\sqrt{2\pi}\sigma_s} e^{-\frac{x^2}{2\sigma_s^2}}
$$

Note: The source [S1, unofficial] provides the 1D Gaussian formula $G_\sigma(x) = \frac{1}{\sqrt{2\pi}\sigma} e^{-\frac{x^2}{2\sigma^2}}$ (Eq. 12). In the bilateral context, $\|p-q\|$ is the Euclidean distance in spatial coordinates, and $\|I_p - I_q\|$ is the difference in intensity/value. The normalization constant $\frac{1}{\sqrt{2\pi}\sigma}$ is often omitted in both numerator and denominator as it cancels out, but the source includes it in the definition of $G_\sigma$. We retain the full definition for correctness.

**Parameters:**
- $\sigma_s$: Spatial standard deviation. Controls the decrease in influence based on distance [S1, unofficial]. Typical value: 4 [S1, unofficial].
- $\sigma_r$: Range standard deviation. Controls the decrease in influence based on value difference [S1, unofficial]. Typical value: 0.2 [S1, unofficial].

**Steps:**
1. For each pixel/voxel $p$ in the output domain:
2. Initialize $sum\_val = 0$ and $sum\_weight = 0$.
3. For each neighbor $q$ in the neighborhood $S$ centered at $p$:
    a. Calculate spatial distance $d_s = \|p - q\|$.
    b. Calculate range difference $d_r = |I_p - I_q|$ (assuming scalar intensity) or $\|I_p - I_q\|$ for vector data.
    c. Compute spatial weight $w_s = G_{\sigma_s}(d_s)$.
    d. Compute range weight $w_r = G_{\sigma_r}(d_r)$.
    e. Compute combined weight $w = w_s \times w_r$.
    f. Update $sum\_val \leftarrow sum\_val + w \times I_q$.
    g. Update $sum\_weight \leftarrow sum\_weight + w$.
4. If $sum\_weight > 0$, $BF(p) = sum\_val / sum\_weight$. Else, $BF(p) = I_p$.

**Pseudocode:**

```python
import math

def gaussian(x, sigma):
    """Compute 1D Gaussian kernel value."""
    return (1.0 / (math.sqrt(2 * math.pi) * sigma)) * math.exp(-(x ** 2) / (2 * sigma ** 2))

def bilateral_filter(image, sigma_s, sigma_r, window_size):
    """
    Apply bilateral filter to an image.
    
    Args:
        image: 2D array of pixel values.
        sigma_s: Spatial standard deviation.
        sigma_r: Range standard deviation.
        window_size: Size of the square neighborhood (e.g., 5 for a 5x5 window).
        
    Returns:
        Filtered image.
    """
    height, width = image.shape
    output = [[0.0 for _ in range(width)] for _ in range(height)]
    
    half_w = window_size // 2
    
    for y in range(height):
        for x in range(width):
            sum_val = 0.0
            sum_weight = 0.0
            center_val = image[y][x]
            
            for dy in range(-half_w, half_w + 1):
                for dx in range(-half_w, half_w + 1):
                    ny = y + dy
                    nx = x + dx
                    
                    # Boundary check
                    if 0 <= ny < height and 0 <= nx < width:
                        # Spatial distance (Euclidean)
                        dist_s = math.sqrt(dx**2 + dy**2)
                        
                        # Range difference (absolute intensity difference)
                        diff_r = abs(image[ny][nx] - center_val)
                        
                        # Weights
                        w_s = gaussian(dist_s, sigma_s)
                        w_r = gaussian(diff_r, sigma_r)
                        
                        w = w_s * w_r
                        
                        sum_val += w * image[ny][nx]
                        sum_weight += w
            
            if sum_weight > 0:
                output[y][x] = sum_val / sum_weight
            else:
                output[y][x] = center_val
                
    return output
```

**Edge Cases and Pitfalls:**
- **Boundaries:** The neighborhood $S$ may extend outside the image boundaries. The implementation must handle these cases, typically by clamping coordinates or ignoring out-of-bounds pixels [G].
- **Precision:** Floating-point precision issues may arise if weights are very small, leading to division by zero or NaNs. A small epsilon should be added to the denominator if necessary [G].
- **Degenerate Input:** If $\sigma_s$ or $\sigma_r$ is zero, the Gaussian becomes a delta function. $\sigma_s=0$ implies only the center pixel contributes. $\sigma_r=0$ implies only pixels with identical intensity contribute.

## Subtopics

### KNN Noise Reduction Filter
A complex Gaussian blur filter applied to the final LDR MC estimate at every iteration to reduce high-frequency noise, where pixel weights are determined by color similarity of neighboring pixels [S2]. It is used in the Exposure Render framework to suppress noise from Monte Carlo simulation of light transport [S2]. Unlike the standard bilateral filter which uses a fixed window, this variant blends between reconstructed and original pixels using the `lerpC` parameter, controlled by the mean running sample variance [S2]. As the sample variance decreases, the influence of the KNN filter decreases [S2]. It uses a window size of 7x7 pixels [S2]. A pitfall is that in the first iteration, noise reduction causes slightly increased blurring [S2]. The mean sample variance is computed using a numerically stable algorithm [S2].

## Operating characteristics
- **Time Complexity:** $O(N \cdot K^2)$ where $N$ is the number of pixels/voxels and $K$ is the window size. The bilateral filter is non-separable, so it cannot be optimized via separable convolution like the Gaussian filter.
- **Memory Complexity:** $O(N)$ for the input and output buffers.
- **Performance:** The filter runs efficiently on CUDA-enabled hardware [S2].
- **Strengths:** Preserves edges while smoothing noise [S1, unofficial]. Effective for reducing high-frequency noise in volume rendering estimates [S2].
- **Limitations:** Computationally more expensive than Gaussian filtering due to non-separability [S1, unofficial]. May cause slight blurring in early iterations of progressive rendering [S2].
- **When to use:** When edge preservation is critical and noise reduction is needed, such as in final image processing or progressive volume rendering [S1, unofficial][S2].
- **When not to use:** When real-time performance is critical and edges are not a concern, or when the data is already smooth [S1, unofficial].

## Background
The bilateral filter was introduced as a method to reduce noise while preserving edges [S1, unofficial]. It is based on the idea of weighting pixels based on both spatial proximity and value similarity [S1, unofficial]. The source [S1, unofficial] is a thesis from 2026 discussing sparse voxel octree compression and global illumination, where the bilateral filter is applied to images to reduce noise [S1, unofficial]. The KNN variant is used in the Exposure Render framework for interactive photo-realistic volume rendering [S2].
