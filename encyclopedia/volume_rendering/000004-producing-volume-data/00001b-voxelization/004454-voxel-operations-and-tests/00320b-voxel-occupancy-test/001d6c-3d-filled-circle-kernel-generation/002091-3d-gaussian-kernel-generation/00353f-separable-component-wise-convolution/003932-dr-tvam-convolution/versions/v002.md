# Dr. TVAM Convolution
Also called: Separable 3D Convolution with Gaussian Diffusion Kernels

## Overview
A separable 3D convolution method using Gaussian diffusion kernels, implemented via Dr.Jit's `dr.convolve` function for tomographic volumetric additive manufacturing simulations [S1, unofficial]. It sets itself apart from non-separable 3D convolutions by leveraging axis-aligned separability to reduce computational complexity, allowing for interactive rates on CUDA hardware [S1, unofficial]. It builds on [Separable Component-Wise Convolution](7446-separable-component-wise-convolution.md) by applying specific Gaussian diffusion kernels rather than generic low-rank tensor decompositions.

## How it works
**Inputs:**
- Volumetric data tensor $r$ (shape: $N_z \times N_x \times N_y$).
- Spatial spacing per axis: $s_z, s_x, s_y$.
- Kernel radius per axis: $R_z, R_x, R_y$ (default 10).
- Diffusion coefficient: $D$.
- Time step: $\Delta t$.

**Outputs:**
- Convolved volumetric data tensor $r'$.

**Data Structures:**
- 1D Gaussian kernel arrays $k_z, k_x, k_y$ of length $2R + 1$ for each axis.

**Steps:**
1. **Generate 1D Gaussian Diffusion Kernel:**
   For each axis $a \in \{z, x, y\}$ with spacing $s_a$ and radius $R_a$:
   a. Create index array $i$ ranging from $-R_a$ to $R_a$.
   b. Compute coordinates: $c_i = i \cdot s_a$.
   c. Compute unnormalized kernel values: $g_i = \exp\left(-\frac{c_i^2}{4 D \Delta t}\right)$.
   d. Normalize: $k_{a,i} = \frac{g_i}{\sum_{j=-R_a}^{R_a} g_j}$.

2. **Apply Separable Convolution:**
   The 3D convolution is decomposed into three sequential 1D convolutions along each axis using the generated kernels. The order of axes does not affect the final result due to the commutative property of convolution, but the implementation applies them sequentially.
   a. Convolve along Z-axis: $r^{(1)} = \text{dr.convolve}(r, \text{filter}=k_z, \text{filter\_radius}=R_z, \text{axis}=0)$.
   b. Convolve along X-axis: $r^{(2)} = \text{dr.convolve}(r^{(1)}, \text{filter}=k_x, \text{filter\_radius}=R_x, \text{axis}=1)$.
   c. Convolve along Y-axis: $r' = \text{dr.convolve}(r^{(2)}, \text{filter}=k_y, \text{filter\_radius}=R_y, \text{axis}=2)$.

**Pseudocode:**
```python
import drjit as dr
import numpy as np

def generate_gaussian_kernel_1d(radius, spacing, diffusion_D, delta_t):
    """
    Generates a 1D Gaussian diffusion kernel.
    
    Args:
        radius (int): Kernel radius.
        spacing (float): Spatial spacing for the axis.
        diffusion_D (float): Diffusion coefficient.
        delta_t (float): Time step.
        
    Returns:
        dr.array: Normalized 1D kernel array.
    """
    # Indices from -radius to radius
    indices = dr.arange(dr.int32, 2 * radius + 1) - radius
    
    # Coordinates
    coords = indices * spacing
    
    # Unnormalized Gaussian values
    # Formula: exp(-coords^2 / (4 * diffusion_D * delta_t))
    exponent = -(coords * coords) / (4.0 * diffusion_D * delta_t)
    values = dr.exp(exponent)
    
    # Normalize
    kernel = values / dr.sum(values)
    return kernel

def dr_tvam_convolution(volume, spacing_z, spacing_x, spacing_y, 
                        diffusion_D, delta_t, 
                        radius_z=10, radius_x=10, radius_y=10):
    """
    Performs separable 3D convolution with Gaussian diffusion kernels.
    
    Args:
        volume (dr.array): Input 3D volume tensor (Nz, Nx, Ny).
        spacing_z, spacing_x, spacing_y (float): Spatial spacing for each axis.
        diffusion_D (float): Diffusion coefficient.
        delta_t (float): Time step.
        radius_z, radius_x, radius_y (int): Kernel radii for each axis.
        
    Returns:
        dr.array: Convolved 3D volume tensor.
    """
    # Step 1: Generate 1D kernels for each axis
    kernel_z = generate_gaussian_kernel_1d(radius_z, spacing_z, diffusion_D, delta_t)
    kernel_x = generate_gaussian_kernel_1d(radius_x, spacing_x, diffusion_D, delta_t)
    kernel_y = generate_gaussian_kernel_1d(radius_y, spacing_y, diffusion_D, delta_t)
    
    # Step 2: Apply separable convolution sequentially
    # Convolve along Z-axis (axis 0)
    r_temp1 = dr.convolve(volume, filter=kernel_z, filter_radius=radius_z, axis=0)
    
    # Convolve along X-axis (axis 1)
    r_temp2 = dr.convolve(r_temp1, filter=kernel_x, filter_radius=radius_x, axis=1)
    
    # Convolve along Y-axis (axis 2)
    r_out = dr.convolve(r_temp2, filter=kernel_y, filter_radius=radius_y, axis=2)
    
    return r_out
```

**Parameters:**
- `spacingz`, `spacingx`, `spacingy`: Spatial spacing for each axis in the kernel coordinate calculation.
- `radiusz`, `radiusx`, `radiusy`: Kernel radius for each axis. Default value is 10.
- `diffusion_D`: Diffusion coefficient. Not given in the sources.
- `delta_t`: Time step. Not given in the sources.

**Edge Cases and Pitfalls:**
- **Precision:** The exponential function may underflow for large negative exponents, resulting in zero weights. This is handled by the normalization step, but extremely small values might lead to numerical instability if not handled by the underlying `dr.convolve` implementation.
- **Boundaries:** The `dr.convolve` function must handle boundary conditions. The sources do not specify the boundary handling mode (e.g., zero-padding, replication, reflection). [G] Standard practice in such simulations often uses zero-padding or reflection, but the exact behavior depends on the Dr.Jit implementation.
- **Degenerate Input:** If `diffusion_D` or `delta_t` is zero, the exponent becomes undefined or infinite. The sources do not specify handling for these cases.

## Subtopics

### [Separable 3D Gaussian Filter](8956-separable-3d-gaussian-filter.md)
A 3D Gaussian filter implemented as three consecutive 1D filters to leverage separability for interactive performance. It serves as a low-pass filter to reduce high-frequency elements (noise) in volumetric data, often used to compute spatial importance maps for volume illustration. It sets itself apart from non-separable 3D convolutions by reducing computational complexity, allowing for interactive rates on CUDA hardware.

## Operating characteristics
- **Time Complexity:** $O(N \cdot R)$, where $N$ is the number of voxels and $R$ is the kernel radius. This is significantly faster than the $O(N \cdot R^3)$ complexity of a non-separable 3D convolution.
- **Memory Complexity:** $O(N)$ for the input and output volumes, plus $O(R)$ for the temporary kernels.
- **Measured Performance:** The method allows for interactive rates on CUDA hardware [S1, unofficial].
- **Strengths:** Computational efficiency due to separability; suitability for tomographic volumetric additive manufacturing simulations.
- **Limitations:** Requires the kernel to be separable (Gaussian kernels are separable); performance depends on the efficiency of the underlying `dr.convolve` implementation.
- **When to Use:** When performing tomographic volumetric additive manufacturing simulations where Gaussian diffusion is a valid model for the physical process.
- **When Not to Use:** When the kernel is not separable or when non-Gaussian diffusion models are required.

## Background
The method originates from the Dr. TVAM project, which focuses on inverse rendering for tomographic volumetric additive manufacturing [S1, unofficial]. It was developed to efficiently simulate the physical forward model in these simulations by applying Gaussian diffusion kernels to volumetric data.
