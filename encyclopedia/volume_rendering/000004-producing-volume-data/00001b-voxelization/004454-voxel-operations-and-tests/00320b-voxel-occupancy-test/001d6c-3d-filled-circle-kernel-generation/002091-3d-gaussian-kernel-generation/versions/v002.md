# 3D Gaussian Kernel Generation
Also called: 3D Gaussian Smoothing Kernel, Zero-Center Gaussian Kernel

## Overview
Generates a 3D Gaussian kernel for smoothing operations, with the center element explicitly set to zero [S1, unofficial]. It differs from its parent [3D Filled Circle Kernel Generation](1520-3d-filled-circle-kernel-generation.md) by using continuous probability density values rather than binary occupancy, and from siblings [Sphere Carving](2377-sphere-carving.md) and [3D Binary Sphere Kernel Generation](4654-3d-binary-sphere-kernel-generation.md) by providing weighted smoothing rather than hard masks.

## How it works
**Inputs:** `size` (integer, kernel dimension), `sigma` (float, standard deviation).
**Outputs:** 3D tensor of shape `(size, size, size)` containing normalized Gaussian weights with a zero at the center.

**Data Structures:**
- `coords`: 3D array of shape `(size, size, size)` containing floating-point coordinates.
- `kernel`: 3D array of shape `(size, size, size)` containing float weights.

**Steps:**
1. Define the range of indices from $-(size // 2)$ to $size // 2$.
2. Generate a 3D meshgrid of coordinates centered at the origin. Let $x, y, z$ be the coordinate arrays.
3. Compute the squared radial distance $d^2$ from the center for each element:
   $$ d^2 = x^2 + y^2 + z^2 $$
4. Compute the unnormalized Gaussian values:
   $$ g = \exp\left(-\frac{d^2}{2\sigma^2}\right) $$
5. Set the center element (where $x=0, y=0, z=0$) to 0.
6. Normalize the kernel by dividing all elements by the sum of all elements in the kernel.

**Parameters:**
- `size`: Kernel dimension. Default is 3 [S1, unofficial].
- `sigma`: Standard deviation of Gaussian. Default is 1.0 [S1, unofficial].

**Pseudocode:**
```python
import numpy as np

def generate_3d_gaussian_kernel(size=3, sigma=1.0):
    # 1. Create linear space from -(size//2) to size//2
    half_size = size // 2
    coords = np.arange(-half_size, half_size + 1, dtype=np.float32)
    
    # 2. Generate 3D meshgrid of coordinates
    x, y, z = np.meshgrid(coords, coords, coords, indexing='ij')
    
    # 3. Compute radial distance d from center
    d_sq = x**2 + y**2 + z**2
    
    # 4. Compute Gaussian values: exp(-d^2 / (2*sigma^2))
    kernel = np.exp(-d_sq / (2 * sigma**2))
    
    # 5. Set center element to 0
    center_idx = half_size
    kernel[center_idx, center_idx, center_idx] = 0.0
    
    # 6. Normalize by sum of all elements
    kernel_sum = np.sum(kernel)
    if kernel_sum > 0:
        kernel = kernel / kernel_sum
    
    return kernel
```

**Edge Cases:**
- If `size` is even, the center is ambiguous; the code uses integer division `size // 2` to pick the index, which may not be the geometric center. [G]
- If `sigma` is 0, division by zero occurs. [G] Guard against `sigma <= 0`.
- If all weights are zero (e.g., `sigma` is extremely small relative to grid spacing), normalization fails. [G]

### [Elliptical Gaussian Light Source Generation](5806-elliptical-gaussian-light-source-generation.md)
Generates spatially distributed light sources using either Poisson disk or uniform sampling, then constructs a luminance field by evaluating scaled multivariate Gaussian probability density functions (PDFs) at query points. It differs from its parent [3D Gaussian Kernel Generation](2297-3d-gaussian-kernel-generation.md) by treating the Gaussian as an emission model for light sources rather than a smoothing kernel, and by supporting spatially varying elliptical covariances via eigen-decomposition.

## Operating characteristics
Time complexity: $O(size^3)$ for meshgrid and exponentiation. Memory complexity: $O(size^3)$ for the kernel tensor.
Strengths: Simple, differentiable, smooth falloff.
Limitations: Center zeroing breaks symmetry and may introduce artifacts in low-frequency smoothing. Not given in the sources: performance on GPU vs CPU.

Origin: Unofficial implementation in the Plenoxels repository [S1, unofficial]. History: Used in neural radiance field variants for efficient volume rendering.
