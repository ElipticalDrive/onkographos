# Separable 3D Gaussian Filter

Also called: 3D Gaussian Filter via Separable 1D Filters, Gaussian filter

## Overview
A 3D Gaussian filter implemented as three consecutive 1D filters to leverage separability for interactive performance [S1, unofficial]. It serves as a low-pass filter that reduces high-frequency elements in volume data, often used to compute spatial importance maps for volume illustration [S1, unofficial].

## How it works
**Inputs and Outputs:**
- Input: A 3D scalar volume $V$ of dimensions $D_x \times D_y \times D_z$ [G].
- Input: Filter radius $R$ and standard deviation $\sigma$ [S1, unofficial].
- Output: A filtered 3D volume $V'$ [S1, unofficial].

**Data Structures:**
- The volume is stored as a 3D array of floating-point values [G].
- The 1D Gaussian kernel $G(x)$ is precomputed for the range $[-R, R]$ [G].

**Formulas:**
The 1D Gaussian function is defined as [S1, unofficial]:
$$ G(x) = \frac{1}{\sqrt{2\pi}\sigma} e^{-\frac{x^2}{2\sigma^2}} $$
where $x$ is the distance from the origin and $\sigma$ is the standard deviation [S1, unofficial]. The 3D Gaussian kernel is the product of three 1D Gaussians, one per direction [S1, unofficial]. Due to separability, the 3D convolution is equivalent to three consecutive 1D convolutions [S1, unofficial].

**Parameters:**
- $R$: Filter radius. The sampling rate is controlled by specifying the number of standard deviations spanning the filter radius, allowing frequency adjustment without changing the radius [S2, unofficial].
- $\sigma$: Standard deviation [S1, unofficial].

**Steps:**
1. **Axis 1 Convolution:** Apply 1D Gaussian convolution along the first axis [S1, unofficial].
2. **Axis 2 Convolution:** Apply 1D Gaussian convolution along the second axis [S1, unofficial].
3. **Axis 3 Convolution:** Apply 1D Gaussian convolution along the third axis [S1, unofficial].
4. **Subtraction:** Subtract the original volume from the filtered volume [S1, unofficial].

**Pseudocode:**
```python
import math

def separable_3d_gaussian_filter(volume, radius, sigma):
    """
    Applies a 3D Gaussian filter via separable 1D convolutions and subtracts the original.
    
    Args:
        volume: 3D list of lists of lists (Dx, Dy, Dz)
        radius: int, half-width of the kernel
        sigma: float, standard deviation of the Gaussian
        
    Returns:
        3D list of lists of lists, the filtered volume minus the original
    """
    # Precompute 1D Gaussian kernel
    x_vals = list(range(-radius, radius + 1))
    kernel_1d = [math.exp(-(x**2) / (2 * sigma**2)) for x in x_vals]
    norm = sum(kernel_1d)
    kernel_1d = [k / norm for k in kernel_1d]
    
    Dx, Dy, Dz = len(volume), len(volume[0]), len(volume[0][0])
    
    # Step 1: Convolve along axis 0 (x)
    temp1 = [[[0.0 for _ in range(Dz)] for _ in range(Dy)] for _ in range(Dx)]
    for i in range(Dx):
        for j in range(Dy):
            for k in range(Dz):
                acc = 0.0
                for r in range(-radius, radius + 1):
                    idx = k + r
                    if 0 <= idx < Dz:
                        acc += volume[i][j][idx] * kernel_1d[r + radius]
                    else:
                        acc += volume[i][j][k] * kernel_1d[r + radius] # Clamp boundary [G]
                temp1[i][j][k] = acc
                
    # Step 2: Convolve along axis 1 (y)
    temp2 = [[[0.0 for _ in range(Dz)] for _ in range(Dy)] for _ in range(Dx)]
    for i in range(Dx):
        for j in range(Dy):
            for k in range(Dz):
                acc = 0.0
                for r in range(-radius, radius + 1):
                    idx = j + r
                    if 0 <= idx < Dy:
                        acc += temp1[i][idx][k] * kernel_1d[r + radius]
                    else:
                        acc += temp1[i][j][k] * kernel_1d[r + radius] # Clamp boundary [G]
                temp2[i][j][k] = acc
                
    # Step 3: Convolve along axis 2 (z)
    temp3 = [[[0.0 for _ in range(Dz)] for _ in range(Dy)] for _ in range(Dx)]
    for i in range(Dx):
        for j in range(Dy):
            for k in range(Dz):
                acc = 0.0
                for r in range(-radius, radius + 1):
                    idx = k + r
                    if 0 <= idx < Dz:
                        acc += temp2[i][j][idx] * kernel_1d[r + radius]
                    else:
                        acc += temp2[i][j][k] * kernel_1d[r + radius] # Clamp boundary [G]
                temp3[i][j][k] = acc
                
    # Step 4: Subtract original volume
    result = [[[temp3[i][j][k] - volume[i][j][k] for k in range(Dz)] for j in range(Dy)] for i in range(Dx)]
    
    return result
```

**Edge Cases and Pitfalls:**
- It is still necessary to determine the distance of neighboring data points to determine the data frequency and set filter parameters [S2, unofficial].

## Subtopics

### [Bilateral Filter](8983-bilateral-filter.md)
A non-linear filter used to reduce noise while preserving edges by weighting pixels based on both spatial proximity and value similarity. Unlike the [Separable 3D Gaussian Filter](8956-separable-3d-gaussian-filter.md) which only uses spatial distance, the Bilateral filter also uses value similarity, preserving edges better.

## Operating characteristics
- A CUDA implementation is used to obtain interactive rates [S1, unofficial].
- For a CT body (256 × 256 × 415), the total time includes 3 convolutions, subtraction, and memory allocations [S1, unofficial].
- For a CT head (512 × 512 × 297) and a salmon dataset (336 × 173 × 511), performance scales with volume dimensions and kernel radius [S1, unofficial].
- Time complexity: Not given in the sources.
- Memory complexity: Not given in the sources.

## Background
The method was introduced in the context of interactive volume illustration, where it is used to compute spatial importance maps for modulating color and opacity transfer functions [S1, unofficial]. The separability of the Gaussian filter allows for efficient implementation on GPUs using CUDA [S1, unofficial]. The approach is part of a pipeline that includes stipple rendering and transfer function modulation [S1, unofficial].
