# Separable 3D Gaussian Filter
Also called: 3D Gaussian Filter via Separable 1D Filters
## Overview
A 3D Gaussian filter implemented as three consecutive 1D filters to leverage separability for interactive performance [S1, unofficial]. It serves as a low-pass filter to reduce high-frequency elements in volume data, often used to compute spatial importance maps for volume illustration [S1, unofficial]. It sets itself apart from non-linear variants like the [Bilateral Filter](8983-bilateral-filter.md) by relying solely on spatial distance rather than value similarity, making it computationally cheaper but less effective at edge preservation [S1, unofficial].
## How it works
**Inputs and Outputs:**
- Input: A 3D scalar volume $V$ of dimensions $W \times H \times D$.
- Output: A filtered 3D scalar volume $V_{filtered}$.

**Data Structures:**
- The volume is stored as a 3D array of floating-point values.
- The 1D Gaussian kernel $G(x)$ is defined by the standard deviation $\sigma$.

**Formulas:**
The 1D Gaussian function is defined as [S1, unofficial]:
$$ G(x) = \frac{1}{\sqrt{2\pi\sigma^2}} e^{-\frac{x^2}{2\sigma^2}} $$
where $x$ is the distance from the origin and $\sigma$ is the standard deviation. The 3D Gaussian kernel is the product of three 1D Gaussians, one per direction [S1, unofficial].

**Parameters:**
- $\sigma$: Standard deviation of the Gaussian distribution. Not given in the sources.
- Kernel Radius ($R$): Determines the support of the kernel. Typical values are provided in performance tables for specific datasets [S1, unofficial].

**Steps:**
1. Apply 1D Gaussian convolution along the first axis (e.g., X).
2. Apply 1D Gaussian convolution along the second axis (e.g., Y).
3. Apply 1D Gaussian convolution along the third axis (e.g., Z).
4. Subtract the original volume from the filtered volume [S1, unofficial].

## Subtopics

### [Bilateral Filter](8983-bilateral-filter.md)
A non-linear filter used to reduce noise while preserving edges by weighting pixels based on both spatial proximity and value similarity. Unlike the [Separable 3D Gaussian Filter](8956-separable-3d-gaussian-filter.md) which only uses spatial distance, the Bilateral filter also uses value similarity, preserving edges better.

## Operating characteristics
**Time and Memory Complexity:**
- Time Complexity: $O(N)$ where $N$ is the number of voxels, due to the separability of the Gaussian kernel. The cost is proportional to the number of voxels and the kernel radius [S1, unofficial].
- Memory Complexity: $O(N)$ for storing the volume and intermediate results [S1, unofficial].

**Measured Performance:**
- Performance data is provided for CT body (256 × 256 × 415), CT head (512 × 512 × 297), and salmon (336 × 173 × 511) datasets with different kernel radii [S1, unofficial].
- The total time includes 3 convolutions, subtraction, and additional operations like memory allocations and transfers [S1, unofficial].
- Specific times are reported in milliseconds in Table 1 of the source [S1, unofficial].

**Strengths and Limitations:**
- Strengths: Interactive performance due to separability and CUDA implementation [S1, unofficial].
- Limitations: Does not preserve edges as well as non-linear filters like the Bilateral filter [S1, unofficial].

**When to Use:**
- Use when computational efficiency is critical and edge preservation is not the primary concern [S1, unofficial].
- Use for computing spatial importance maps in volume illustration [S1, unofficial].

**When Not to Use:**
- Do not use when edge preservation is crucial [S1, unofficial].
## Background
The method is described in the context of interactive volume illustration, where it is used to compute spatial importance maps to modulate color and opacity assigned by transfer functions [S1, unofficial]. The approach leverages the separability of the Gaussian kernel to achieve interactive rates using a CUDA implementation [S1, unofficial].
