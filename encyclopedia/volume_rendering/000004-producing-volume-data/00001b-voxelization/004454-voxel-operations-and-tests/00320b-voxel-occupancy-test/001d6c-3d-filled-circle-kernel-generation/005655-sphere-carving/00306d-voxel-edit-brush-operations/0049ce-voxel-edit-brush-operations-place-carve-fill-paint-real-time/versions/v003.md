# Voxel Edit Brush Operations — Place/Carve/Fill/Paint, Real-time Voxel Editing, VoxelEdit

Also called: FragmentSdfShaderPatch, Voxel Carving via Shader Patching

## Overview
This method implements real-time voxel editing on an unbounded voxel grid by injecting a binary occupancy mask into a fragment shader via shader patching [S1, unofficial]. It solves the problem of performing crisp, axis-aligned carve operations on volumetric data (specifically 3D Gaussian Splatting) without modifying the underlying geometry or splat primitives [S1, unofficial]. Unlike standard eraser tools that remove voxels through the entire depth of the volume, this approach limits removal to a specific spatial region defined by a 3D texture mask, enabling efficient, GPU-accelerated sculpting [S1, unofficial].

## How it works
The method operates by maintaining a 3D texture (`uCarveMask`) that stores the binary state of each voxel cell (carved or uncarved) [S1, unofficial]. This texture is sampled in the fragment shader to discard fragments that fall within carved regions [S1, unofficial]. The system manages the state of these carves using a key-value store and updates the shader uniforms dynamically [S1, unofficial].

### Inputs and Outputs
*   **Input:** World-space coordinates of the brush center, brush radius, and current voxel grid parameters (origin, size, counts) [S1, unofficial].
*   **Output:** Modified fragment shader pipeline that discards pixels corresponding to carved voxels [S1, unofficial].

### Data Structures
1.  **Carve Mask Texture (`uCarveMask`):**
    *   Type: `sampler3D` (backed by a `Uint8Array` or `bytearray`) [S1, unofficial].
    *   Layout: 1 byte per voxel. Value `255` indicates a carved voxel; `0` indicates an uncarved (solid) voxel [S1, unofficial].
    *   Dimensions: `voxel_counts.x * voxel_counts.y * voxel_counts.z` [S1, unofficial].
2.  **Carve State Map:**
    *   A dictionary mapping unique keys to voxel indices `(i, j, k)` [S1, unofficial].
    *   Used to track active carves for `uncarve` operations [S1, unofficial].
3.  **Uniforms Injected into Fragment Shader:**
    *   `sampler3D uCarveMask`: The occupancy texture [S1, unofficial].
    *   `vec3 uVoxelOrigin`: World-space origin of the voxel grid [S1, unofficial].
    *   `float uVoxelSizeInv`: Inverse of the voxel size (for coordinate conversion) [S1, unofficial].
    *   `vec3 uVoxelCountsInv`: Inverse of the voxel counts (for normalization) [S1, unofficial].
    *   `vec3 uCarveBoundsMin`: Minimum world-space coordinates of the union of all active carves [S1, unofficial].
    *   `vec3 uCarveBoundsMax`: Maximum world-space coordinates of the union of all active carves [S1, unofficial].
    *   `int uCarveCount`: Number of active carves [S1, unofficial].
4.  **Uniforms Injected into Vertex Shader:**
    *   `mat4 uClipToLocal`: Transformation matrix from clip space to local voxel space [S1, unofficial].
    *   `out vec3 vWorldPos`: Output world position of the vertex [S1, unofficial].

### Numbered Steps

1.  **Carve Operation (`carve(key, i, j, k)`):**
    *   Validate that `key` is not already in the Carve State Map [S1, unofficial].
    *   Validate that indices `i, j, k` are within the grid bounds `[0, counts-1]` [S1, unofficial].
    *   Calculate the linear index in the 3D texture: `idx = 1 + 2*w + 3*w*h` (where `w` and `h` are grid dimensions) [S1, unofficial].
    *   Set the texel at `idx` in `uCarveMask` to `255` [S1, unofficial].
    *   Increment `patch.count` [S1, unofficial].
    *   Update the union AABB (`uCarveBoundsMin`, `uCarveBoundsMax`) to include the voxel center (`voxel_origin + (i+0.5)*size, ...`) [S1, unofficial].
    *   Increment `tex.version` to trigger a texture update [S1, unofficial].

2.  **Uncarve Operation (`uncarve(key)`):**
    *   Validate that `key` exists in the Carve State Map [S1, unofficial].
    *   Retrieve the stored indices `(i, j, k)` [S1, unofficial].
    *   Set the texel at the corresponding linear index in `uCarveMask` to `0` [S1, unofficial].
    *   Decrement `patch.count` [S1, unofficial].
    *   Update the union AABB [S1, unofficial].
    *   Increment `tex.version` [S1, unofficial].

3.  **Shader Compilation (`compile(shader)`):**
    *   Inject fragment shader code containing a single texture lookup to `uCarveMask` [S1, unofficial].
    *   Gate the lookup on a union AABB check (`uCarveBoundsMin/Max`) for early-out [S1, unofficial].
    *   Move world-position computation to the vertex shader using `uClipToLocal` [S1, unofficial].

### Formulas
*   **Voxel Index to World Position:**
    $$ P_{world} = P_{origin} + (P_{index} + 0.5) \times S_{voxel} $$
    Where $P_{origin}$ is `uVoxelOrigin`, $P_{index}$ is the integer voxel coordinate, and $S_{voxel}$ is the voxel size [S1, unofficial].
*   **Linear Index in 3D Texture:**
    $$ idx = 1 + 2 \times w + 3 \times w \times h $$
    Where $w$ and $h$ are grid dimensions, as specified by the source [S1, unofficial].
*   **AABB Check:**
    $$ \text{if } (P_{world}.x < uCarveBoundsMin.x \lor P_{world}.x > uCarveBoundsMax.x \lor \dots) \text{ skip texture lookup} $$
    Fragments outside the union AABB skip the texture sample entirely with three float compares [S1, unofficial].

### Parameters
*   `uVoxelOrigin`: World-space origin of the voxel grid [S1, unofficial].
*   `uVoxelSizeInv`: Inverse voxel size for coordinate normalization [S1, unofficial].
*   `uVoxelCountsInv`: Inverse voxel counts for normalization [S1, unofficial].
*   `uCarveBoundsMin/Max`: Bounding box of all active carves [S1, unofficial].
*   `uCarveCount`: Number of active carves [S1, unofficial].

### Edge Cases and Pitfalls
*   **Out-of-Bounds Indices:** Clamped safely by returning false and writing nothing [S1, unofficial].
*   **Missing Anchors:** Throws if expected fragment anchors are missing in the shader [S1, unofficial].
*   **Shader Fragility:** Anchor-based string injection is fragile to upstream changes in the rendering engine (e.g., Spark) [S1, unofficial].
*   **Carve Capacity:** Limited by the voxel grid size ($counts.x \cdot counts.y \cdot counts.z$ bytes). No per-session cap on number of carves, but memory scales cubically with resolution [S1, unofficial].
*   **2DGS Interaction:** Carves while 2DGS is enabled may mis-mask due to different `vNdc` assignment forms [S1, unofficial].

### Pseudocode

```python
import math

class Vec3:
    def __init__(self, x, y, z):
        self.x, self.y, self.z = x, y, z
    def __add__(self, other): return Vec3(self.x + other.x, self.y + other.y, self.z + other.z)
    def __sub__(self, other): return Vec3(self.x - other.x, self.y - other.y, self.z - other.z)
    def __mul__(self, scalar): return Vec3(self.x * scalar, self.y * scalar, self.z * scalar)

def vec3_min(a, b): return Vec3(min(a.x, b.x), min(a.y, b.y), min(a.z, b.z))
def vec3_max(a, b): return Vec3(max(a.x, b.x), max(a.y, b.y), max(a.z, b.z))

class VoxelEditBrush:
    def __init__(self, voxel_counts, voxel_origin, voxel_size):
        self.voxel_counts = voxel_counts
        self.voxel_origin = voxel_origin
        self.voxel_size = voxel_size
        self.voxel_size_inv = 1.0 / voxel_size
        self.voxel_counts_inv = 1.0 / voxel_counts
        self.carve_mask = bytearray(voxel_counts.x * voxel_counts.y * voxel_counts.z)
        self.carve_map = {}
        self.patch_count = 0
        self.bounds_min = Vec3(math.inf, math.inf, math.inf)
        self.bounds_max = Vec3(-math.inf, -math.inf, -math.inf)
        self.tex_version = 0

    def linear_index(self, w, h):
        return 1 + 2 * w + 3 * w * h

    def update_bounds(self, i, j, k, is_add):
        center = self.voxel_origin + Vec3(i + 0.5, j + 0.5, k + 0.5) * self.voxel_size
        if is_add:
            self.bounds_min = vec3_min(self.bounds_min, center - Vec3(0.5) * self.voxel_size)
            self.bounds_max = vec3_max(self.bounds_max, center + Vec3(0.5) * self.voxel_size)
        else:
            self.bounds_min = Vec3(math.inf, math.inf, math.inf)
            self.bounds_max = Vec3(-math.inf, -math.inf, -math.inf)
            for _, (ci, cj, ck) in self.carve_map.items():
                c_center = self.voxel_origin + Vec3(ci + 0.5, cj + 0.5, ck + 0.5) * self.voxel_size
                self.bounds_min = vec3_min(self.bounds_min, c_center - Vec3(0.5) * self.voxel_size)
                self.bounds_max = vec3_max(self.bounds_max, c_center + Vec3(0.5) * self.voxel_size)

    def carve(self, key, i, j, k):
        if key in self.carve_map:
            return False
        if not (0 <= i < self.voxel_counts.x and 0 <= j < self.voxel_counts.y and 0 <= k < self.voxel_counts.z):
            return False
        idx = self.linear_index(self.voxel_counts.x, self.voxel_counts.y)
        self.carve_mask[idx] = 255
        self.carve_map[key] = (i, j, k)
        self.patch_count += 1
        self.update_bounds(i, j, k, True)
        self.tex_version += 1
        return True

    def uncarve(self, key):
        if key not in self.carve_map:
            return False
        i, j, k = self.carve_map.pop(key)
        idx = self.linear_index(self.voxel_counts.x, self.voxel_counts.y)
        self.carve_mask[idx] = 0
        self.patch_count -= 1
        self.update_bounds(i, j, k, False)
        self.tex_version += 1
        return True

    def compile_shader(self, shader_source):
        uniforms = """
        uniform sampler3D uCarveMask;
        uniform vec3 uVoxelOrigin;
        uniform float uVoxelSizeInv;
        uniform vec3 uVoxelCountsInv;
        uniform vec3 uCarveBoundsMin;
        uniform vec3 uCarveBoundsMax;
        uniform int uCarveCount;
        uniform mat4 uClipToLocal;
        """
        vertex_injection = """
        out vec3 vWorldPos;
        void main() {
            vec4 clipPos = gl_Position;
            vec4 localPos = uClipToLocal * clipPos;
            vWorldPos = localPos.xyz;
        }
        """
        fragment_injection = """
        in vec3 vWorldPos;
        void main() {
            if (vWorldPos.x < uCarveBoundsMin.x || vWorldPos.x > uCarveBoundsMax.x ||
                vWorldPos.y < uCarveBoundsMin.y || vWorldPos.y > uCarveBoundsMax.y ||
                vWorldPos.z < uCarveBoundsMin.z || vWorldPos.z > uCarveBoundsMax.z) {
                return;
            }
            vec3 voxelCoord = (vWorldPos - uVoxelOrigin) * uVoxelSizeInv - 0.5;
            voxelCoord = clamp(voxelCoord, vec3(0.0), uVoxelCountsInv - 1.0);
            float isCarved = texture(uCarveMask, voxelCoord).r;
            if (isCarved > 0.5) {
                discard;
            }
        }
        """
        shader_source = shader_source.replace("// VoxelEditUniforms", uniforms)
        shader_source = shader_source.replace("// VoxelEditVertex", vertex_injection)
        shader_source = shader_source.replace("// VoxelEditFragment", fragment_injection)
        return shader_source
```

## Subtopics

### [FSDigger](13678-fsdigger.md)
FSDigger is a fragment shader implementation of the 2D Digger tool for real-time volume sculpting, designed to carve semi-spherical holes into a volume starting from the first surface intersection along the line of sight. Unlike the Eraser tool which removes voxels through the entire depth of the volume, FSDigger limits removal to a depth determined by the cursor radius and viewing geometry, effectively creating a "dug" cavity rather than a tunnel. It builds on [Voxel Edit Brush Operations — Place/Carve/Fill/Paint, Real-time Voxel Editing, VoxelEdit](12596-voxel-edit-brush-operations-place-carve-fill-paint-real-time.md) by injecting specific carving logic into the fragment shader pipeline.

## Operating characteristics
*   **Time Complexity:** O(1) per fragment for the mask lookup, regardless of the number of carves [S1, unofficial]. The AABB check is also O(1) [S1, unofficial].
*   **Memory Complexity:** O(N) where N is the total number of voxels in the grid ($counts.x \cdot counts.y \cdot counts.z$) [S1, unofficial]. At default resolution (64^3), this is 262 KB [S1, unofficial].
*   **Performance:** ~4 × splat count / frame instead of ~pixels / frame for carving logic [S1, unofficial].
*   **Strengths:** Crisp, axis-aligned carving; efficient GPU-based discard; no need to modify underlying geometry [S1, unofficial].
*   **Limitations:** Memory scales cubically with resolution; fragile to shader engine changes; limited to binary (carved/uncarved) states [S1, unofficial].
*   **When to Use:** Real-time voxel sculpting in web-based 3DGS viewers where crisp, axis-aligned cuts are required [S1, unofficial].
*   **When Not to Use:** When smooth, continuous SDF-based carving is needed, or when memory constraints prevent storing a full 3D texture [S1, unofficial].

## Background
The method was introduced by stevekwon211 in the `splatcarve` project [S1, unofficial]. It leverages the `Material.onBeforeCompile` hook from Spark 2.0 to inject a voxel-cell-resolution occupancy mask into the fragment stage of a 3D Gaussian Splatting rasterizer [S1, unofficial]. It is described as the first public open-source browser-based 3DGS demo to apply this technique for crisp, axis-aligned `discard`-based carves [S1, unofficial]. The closest prior art, Santos & Soares (SVR 2025), targets modulation effects inside an SDF region rather than crisp removal [S1, unofficial].
