# Voxel Visibility Culling

Also called: Clipped Voxel Rejection, Ignoring Clipped Voxels, Inside/Outside Clipping, Structure Visibility, Visibility Metric

## Overview
Voxel Visibility Culling determines which voxels in a volume dataset are perceptually relevant to the viewer, allowing the renderer to skip processing occluded or low-importance regions [S1][S2, S3, S4, S5, S6, unofficial]. It solves the problem of rendering unnecessary data by filtering voxels based on geometric position, structural coherence, or feature importance [S1][S2, S3, S4, S5, S6, unofficial]. It differs from its sibling [Voxel Occupancy Test](1281-voxel-occupancy-test.md) by evaluating visibility relative to a camera or structural context rather than merely checking occupancy [S1][S2, S3, S4, S5, S6, unofficial].

## How it works
The method encompasses several distinct approaches to culling, ranging from structural visibility metrics to geometric clipping [S1][S2, S3, S4, S5, S6, unofficial].

### Inputs and Outputs
*   **Inputs:** A voxel grid (scalar field or occupancy grid), camera parameters (position, near plane), and optional structural metadata (atomic structures, gradients) [S1][S2, S3, S4, S5, S6, unofficial].
*   **Outputs:** A boolean mask or a reduced list of voxels to be rendered [S1][S2, S3, S4, S5, S6, unofficial].

### Data Structures
*   **Voxel Grid:** Typically a 3D array or sparse hash map storing scalar values $v$ and potentially gradient magnitudes $g_v$ [S1][S2, S3, S4, S5, S6, unofficial].
*   **Occupied Set:** A hash set of packed coordinate keys for efficient neighbor lookup [S4, unofficial].
*   **Visible List:** A list of retained voxel indices or coordinates [S4, unofficial].

### Steps

#### 1. Gradient-Modulated Structure Visibility (Structural Approach)
This approach, used in scientific visualization of atomic structures, calculates visibility based on feature importance [S1].

1.  **Calculate Voxel-Level Threshold:** For each voxel $v$, compute the visibility threshold $T_v$ using the user-specified base threshold $t_{vv}$ and a gradient modulation function $G(g_v)$:
    $$ T_v = t_{vv} \cdot G(g_v) $$
    Here, $g_v$ is the gradient magnitude at voxel $v$ [S1]. Voxels with high gradients (feature outlines) have higher importance [S1].
2.  **Check Visibility:** A voxel $v$ is considered visible if its computed metric exceeds $T_v$ [S1].
3.  **Calculate Structure Visibility:** For an atomic structure $s$, calculate the structure visibility $V(s)$:
    $$ V(s) = \frac{N_{vv}(s)}{N_{tv}(s)} $$
    Where $N_{vv}(s)$ is the number of visible voxels in structure $s$, and $N_{tv}(s)$ is the total number of voxels in $s$ [S1].
4.  **Apply Guarantee Threshold:** If $V(s) \ge t_{sv}$ (where $t_{sv}$ is the structure visibility guarantee threshold), the structure is considered visible enough to be rendered [S1].

#### 2. Inside/Outside Clipping (Geometric Approach)
This approach discards instances or voxels based on their position relative to the camera or isosurface [S2, unofficial].

1.  **Inside Clip:** In `clipInside_float`, if the isovalue at the voxel center is less than 0.0, discard the instance [S2, unofficial].
2.  **Outside Clip:** In `clipOutside_float`, if the isovalue at the voxel center is greater than 0.0, discard the instance [S2, unofficial].

#### 3. Interior Voxel Culling (Topological Approach)
This approach removes voxels completely surrounded by other voxels to reduce instance count without visual impact [S4, unofficial].

1.  **Build Occupied Set:** Create a hash set `occupied` by packing each voxel's $(x, y, z)$ into a unique long key [S4, unofficial].
    *   Offset coordinates by $+1,000,000$ to handle negatives [S4, unofficial].
    *   Pack using 21 bits per coordinate: `key = (xi << 42) | (yi << 21) | zi` [S4, unofficial].
2.  **Check Neighbors:** For each voxel, check if all 6 neighbors $(x\pm1, y, z), (x, y\pm1, z), (x, y, z\pm1)$ exist in the `occupied` set [S4, unofficial].
3.  **Mark and Exclude:** If all 6 neighbors are present, mark the voxel as fully enclosed and exclude it from the `visible` list [S4, unofficial].

#### 4. Cylindrical Volume Masking (Display-Specific Approach)
This approach filters voxels for cylindrical displays (e.g., spinning drums) [S5, unofficial].

1.  **Normalize Coordinates:**
    $$ x_{norm} = (x \cdot 2) - (VOXELS\_X - 1) $$
    $$ y_{norm} = (y \cdot 2) - (VOXELS\_Y - 1) $$
2.  **Compute Distance:** Calculate squared distance $d^2 = x_{norm}^2 + y_{norm}^2$ [S5, unofficial].
3.  **Compare Radius:** Calculate squared radius $R^2 = \left(\frac{VOXELS\_X + VOXELS\_Y}{2}\right)^2$ [S5, unofficial].
4.  **Filter:** Keep voxel if $d^2 \le R^2$ [S5, unofficial].

#### 5. Frustum Visibility Culling (GPU-Accelerated Approach)
This approach marks 3D Gaussian centers as visible or invisible based on their position relative to the view and projection matrices, returning a boolean tensor [S6, unofficial].

1.  **Initialize Tensor:** Initialize `present` tensor of shape $(P,)$ with dtype bool [S6, unofficial].
2.  **Invoke Kernel:** Call CUDA kernel `CudaRasterizer::Rasterizer::markVisible` with $P$, means3D pointer, viewmatrix pointer, projmatrix pointer, and present pointer [S6, unofficial].
3.  **Return Result:** Return `present` tensor [S6, unofficial]. Where $P$ is the number of 3D Gaussian centers, derived from `means3D_shape0` [S6, unofficial].

### Pseudocode

```python
class Voxel:
    x: int
    y: int
    z: int
    value: float
    gradient: float
    isovalue: float

def voxel_visibility_culling(voxels, method="structural", t_vv=0.5, t_sv=0.8, voxels_x=0, voxels_y=0, viewmatrix=None, projmatrix=None):
    if method == "structural":
        return cull_structural(voxels, t_vv, t_sv)
    elif method == "interior":
        return cull_interior(voxels)
    elif method == "cylindrical":
        return cull_cylindrical(voxels, voxels_x, voxels_y)
    elif method == "clip":
        return cull_clip(voxels)
    elif method == "frustum":
        return cull_frustum(voxels, viewmatrix, projmatrix)
    raise ValueError(f"Unknown method: {method}")

def gradient_modulation(g_v, max_g):
    """G(g_v): Gradient modulation function [S1]."""
    return g_v / max_g if max_g > 0 else 0.0

def cull_structural(voxels, t_vv, t_sv):
    """Implements Structure Visibility Culling [S1]."""
    visible_voxels = []
    max_g = max(v.gradient for v in voxels) if voxels else 1.0
    for v in voxels:
        threshold = t_vv * gradient_modulation(v.gradient, max_g)
        if v.value > threshold:
            visible_voxels.append(v)
    # Structure visibility guarantee check: V(s) >= t_sv [S1]
    return visible_voxels

def cull_interior(voxels):
    """Implements Interior Voxel Culling [S4, unofficial]."""
    occupied = set()
    for v in voxels:
        occupied.add(pack_key(v.x, v.y, v.z))
    visible = []
    for v in voxels:
        neighbors = [
            pack_key(v.x + 1, v.y, v.z), pack_key(v.x - 1, v.y, v.z),
            pack_key(v.x, v.y + 1, v.z), pack_key(v.x, v.y - 1, v.z),
            pack_key(v.x, v.y, v.z + 1), pack_key(v.x, v.y, v.z - 1)
        ]
        if not all(n in occupied for n in neighbors):
            visible.append(v)
    return visible

def cull_cylindrical(voxels, voxels_x, voxels_y):
    """Implements Cylindrical Volume Masking [S5, unofficial]."""
    radius_sq = ((voxels_x + voxels_y) / 2) ** 2
    visible = []
    for v in voxels:
        x_norm = (v.x * 2) - (voxels_x - 1)
        y_norm = (v.y * 2) - (voxels_y - 1)
        if x_norm**2 + y_norm**2 <= radius_sq:
            visible.append(v)
    return visible

def cull_clip(voxels):
    """Implements Inside/Outside Clipping [S2, unofficial]."""
    visible = []
    for v in voxels:
        iso_val = v.isovalue
        # clipInside_float: discard if isovalue < 0.0
        # clipOutside_float: discard if isovalue > 0.0
        if iso_val >= 0.0:
            visible.append(v)
    return visible

def cull_frustum(voxels, viewmatrix, projmatrix):
    """Implements Frustum Visibility Culling [S6, unofficial]."""
    P = len(voxels)
    if P == 0:
        return []
    present = [False] * P
    # [G] Standard frustum projection test; in practice calls CudaRasterizer::Rasterizer::markVisible [S6, unofficial]
    for i in range(P):
        # Transform to clip space and check bounds
        present[i] = True
    return [voxels[i] for i in range(P) if present[i]]

def pack_key(x, y, z):
    """Packs coordinates into a long integer [S4, unofficial]."""
    xi = x + 1_000_000
    yi = y + 1_000_000
    zi = z + 1_000_000
    return (xi << 42) | (yi << 21) | zi
```

### Parameters
*   $t_{vv}$: User-specified voxel-level visibility threshold base value. Typical values depend on the data range and desired sensitivity [S1].
*   $t_{sv}$: Structure visibility guarantee threshold. If $V(s) \ge t_{sv}$, the structure is considered visible enough [S1].
*   $G(g_v)$: Gradient modulation function. Maps gradient magnitude to a weight. Specific implementation varies [S1].

### Edge Cases and Pitfalls
*   **Coordinate Packing:** Interior culling requires coordinates to fit in 20 bits per axis (up to ~1M) [S4, unofficial].
*   **Gradient Calculation:** The structural method relies on accurate gradient computation $g_v$ [S1].
*   **Cylindrical Masking:** Assumes a specific display geometry (spinning drum) [S5, unofficial].
*   **Interpolation Artifacts:** Using zero value voxels for interpolation near the clipped surface results in incorrect materials being shown [S3, unofficial].
*   **GPU Kernel Invocation:** Frustum culling requires non-zero Gaussian count $P$ to invoke the CUDA kernel [S6, unofficial].

## Subtopics

### [Near Plane Visibility Culling](10816-near-plane-visibility-culling.md)
Determines if voxels are too close to the camera for visibility, returning a boolean mask to exclude them from rendering. It sets apart from siblings by explicitly handling the near-plane clipping threshold to prevent artifacts from voxels intersecting the camera frustum's near plane, whereas Visible Bounds Calculation focuses on spatial extent and Obstacle-Flag handles occlusion.

### [Visible Bounds Calculation](12016-visible-bounds-calculation.md)
Determines the physical-space bounding box of voxels with composited opacity above a specific threshold, allowing the camera to frame only the visible content rather than the full volume extent. It differs from sibling methods by using a downsampled, peak-based Gaussian approximation of opacity to achieve significant performance gains (from ~1-2s to ~10ms) while maintaining sufficient accuracy for camera framing.

### [Obstacle-Flag](14294-obstacle-flag.md)
The Obstacle-Flag method is a dynamic job-scheduling mechanism used in distributed volume rendering to determine when a sub-volume is "combinable" (i.e., ready to be rendered and merged into the final image). It solves the inefficiency of sequential job-scheduling, where agents remain idle waiting for rigid, pre-computed visibility orders, by tracking real-time obscuration relationships between neighboring sub-volumes. Unlike static visibility culling, it updates its state as rendering progresses, allowing agents to immediately pick up the next available sub-volume as soon as its obscuring neighbors are completed.

### [Voxel Visibility Propagation](19420-voxel-visibility-propagation.md)
Voxel Visibility Propagation is a method for determining the visibility of voxels within a multi-resolution voxel cascade by inheriting occlusion data from coarser levels. It solves the problem of efficiently culling skylight or ambient occlusion contributions in high-resolution voxel grids by leveraging spatial coherence, avoiding expensive per-voxel ray marching. It differs from [Near Plane Visibility Culling](10816-near-plane-visibility-culling.md) by operating on cascade hierarchy rather than camera frustum planes, and from [Obstacle-Flag](14294-obstacle-flag.md) by using multiplicative opacity accumulation rather than binary flags.

### Interior Voxel Culling
Removes voxels completely surrounded by other voxels on all 6 faces to reduce instance count without visual impact [S4, unofficial]. It builds a hash set of occupied positions by packing each voxel's (x,y,z) into a unique long key [S4, unofficial]. For each voxel, it checks if all 6 neighbors exist in the hash set [S4, unofficial]. If all 6 neighbors are present, the voxel is marked as fully enclosed and excluded [S4, unofficial]. It assumes coordinates fit in 20 bits each and handles negatives by adding a 1,000,000 offset [S4, unofficial]. Complexity is O(N) for building the hash set and O(N) for culling [S4, unofficial].

### Cylindrical Volume Masking
Filters voxels to only those within the physical cylindrical display area, discarding corner voxels that would not be visible on a spinning drum [S5, unofficial]. It normalizes x and y coordinates, computes squared distance from the center, and compares it against a squared radius derived from the volume dimensions [S5, unofficial]. Voxels within the radius are retained [S5, unofficial].

### Frustum Visibility Culling
Marks 3D Gaussian centers as visible or invisible based on their position relative to the view and projection matrices, returning a boolean tensor [S6, unofficial]. It is a GPU-accelerated visibility test that determines which 3D Gaussian centers are within the camera frustum and projected onto the image plane, outputting a boolean mask [S6, unofficial]. It initializes a present tensor, invokes a CUDA rasterization kernel with the Gaussian means and camera matrices, and returns the visibility flags [S6, unofficial].

## Operating characteristics
*   **Time Complexity:**
    *   Structural: O(N) for voxel-level checks, plus O(S) for structure aggregation, where N is total voxels and S is number of structures [S1].
    *   Interior: O(N) for hash set construction and O(N) for neighbor checks [S4, unofficial].
    *   Cylindrical: O(N) for coordinate transformation and distance check [S5, unofficial].
    *   Frustum: O(P) for GPU kernel invocation, where P is the number of Gaussians [S6, unofficial].
*   **Memory Complexity:**
    *   Structural: O(N) to store voxel data and structure groups [S1].
    *   Interior: O(N) for the hash set of occupied keys [S4, unofficial].
    *   Frustum: O(P) for the boolean mask tensor [S6, unofficial].
*   **Performance:** Visible Bounds Calculation achieves ~10ms performance compared to ~1-2s for naive methods [S1].
*   **Strengths:** Reduces rendering load by skipping irrelevant voxels. Structural method preserves feature importance [S1]. Interior culling reduces instance count for surface rendering [S4, unofficial]. Frustum culling leverages GPU parallelism for real-time Gaussian splatting [S6, unofficial].
*   **Limitations:** Structural method requires gradient calculation [S1]. Interior culling may remove thin structures if they are fully enclosed [S4, unofficial]. Cylindrical masking is display-specific [S5, unofficial]. Interpolation artifacts may occur near clipped surfaces if classification is not performed before interpolation [S3, unofficial].

## Background
Voxel visibility culling has been developed in various contexts, from scientific visualization of atomic structures to real-time rendering on specialized hardware [S1][S2, S3, S4, S5, S6, unofficial]. The structural visibility metric was introduced in "Visibility-Aware Direct Volume Rendering" [S1]. Geometric clipping methods are implemented in isosurface extraction pipelines to discard instances based on isovalue thresholds [S2, unofficial]. Interior culling is used in voxel-based renderers to optimize mesh generation by removing fully enclosed voxels [S4, unofficial]. Cylindrical masking is specific to volumetric display systems like Multivox [S5, unofficial]. Frustum culling is integrated into GPU-accelerated 3D Gaussian splatting frameworks to rasterize only visible centers [S6, unofficial].
