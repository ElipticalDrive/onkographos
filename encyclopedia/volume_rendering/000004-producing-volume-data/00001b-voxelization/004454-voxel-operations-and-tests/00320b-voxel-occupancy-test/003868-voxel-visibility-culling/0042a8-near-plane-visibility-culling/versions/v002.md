# Near Plane Visibility Culling

Also called: Maskout Near Camera Voxels, Near Plane Visibility Check (mark_near)

## Overview
Near Plane Visibility Culling determines if voxels are too close to the camera for visibility, returning a boolean mask to exclude them from rendering [S2, S1, unofficial]. It sets apart from siblings by explicitly handling the near-plane clipping threshold to prevent artifacts from voxels intersecting the camera frustum's near plane, whereas [Visible Bounds Calculation](12016-visible-bounds-calculation.md) focuses on spatial extent and [Obstacle-Flag](14294-obstacle-flag.md) handles occlusion [S2, S1, unofficial].

## How it works
**Inputs:**
- `self_grid_xyz`: Tensor of voxel grid point coordinates (shape: $N \times 3$) [S1, unofficial].
- `cam_o`: Camera origin coordinates (tensor) [S1, unofficial].
- `vox_centers`: Center coordinates of active voxels (tensor) [S2, unofficial].
- `vox_lengths`: Lengths of voxels (tensor) [S2, unofficial].
- `cam_lookat`: Camera look-at vector (tensor) [S2, unofficial].
- `cam_position`: Camera position coordinates (tensor) [S2, unofficial].
- `near_plane`: Threshold for near-plane culling (float, default 0.2) [S2, unofficial].
- `near_clip`: Distance threshold for masking voxels near the camera (float) [S1, unofficial].
- `n_duplicates`: Count of duplicates per voxel (tensor, used to identify visible voxels) [S2, unofficial].
- `octree_paths_len`: Number of octree paths (integer) [S2, unofficial].
- `density_grid`: Density values tensor to be masked (tensor) [S1, unofficial].

**Outputs:**
- `is_near`: Boolean tensor of size `octree_paths_len` indicating if each voxel is too near [S2, unofficial].
- `density_grid`: Updated density values with near voxels masked to -100 [S1, unofficial].

**Data Structures:**
- `self_grid_xyz`: Tensor generated via `torch.meshgrid` of `linspace` from `xyz_min` to `xyz_max` for each dimension, stacked at the last axis [S1, unofficial].
- `is_near`: Boolean tensor initialized to `False` on CUDA [S2, unofficial].

**Steps:**
1. Generate `self_grid_xyz` using `torch.meshgrid` of `linspace` from `xyz_min` to `xyz_max` for each dimension, stacked at -1 [S1, unofficial].
2. Initialize `is_near` tensor of size `len(octree_paths)` with `False` on CUDA [S2, unofficial].
3. Calculate nearest distance from each grid point to each camera origin: `nearest_dist = amin(0) of amin(-1) of sqrt(sum((self_grid_xyz.unsqueeze(-2) - co)^2))` for `co` in `cam_o.split(100)` [S1, unofficial].
4. Identify visible voxels where `n_duplicates > 0`: `vis_idx = torch.where(n_duplicates > 0)[0]` [S2, unofficial].
5. Set `density.grid` values to -100 where `nearest_dist[None,None] <= near_clip` [S1, unofficial].
6. Calculate z-distance from voxel centers to camera position along the lookat vector: `zdist = ((vox_centers[vis_idx] - cam.position) * cam.lookat).sum(-1)` [S2, unofficial].
7. Mark voxels as near if `zdist <= near_plane + vox_lengths.squeeze(1)[vis_idx]`: `is_near[vis_idx] |= (zdist <= near_plane + vox_lengths.squeeze(1)[vis_idx])` [S2, unofficial].

**Pseudocode:**
```python
import torch

def mark_near(self_grid_xyz, cam_o, vox_centers, vox_lengths, cam_lookat, cam_position, near_plane, near_clip, n_duplicates, octree_paths_len, density_grid):
    # Step 2: Initialize is_near tensor of size len(octree_paths) with False on CUDA
    is_near = torch.zeros(octree_paths_len, dtype=torch.bool, device=self_grid_xyz.device)

    # Step 3: Calculate nearest distance from each grid point to each camera origin
    # Split camera origins into batches of 100 to manage memory
    cam_o_split = cam_o.split(100)
    nearest_dist = None
    for co in cam_o_split:
        # co shape: (M, 3)
        # self_grid_xyz shape: (N, 3)
        # diff shape: (N, M, 3)
        diff = self_grid_xyz.unsqueeze(-2) - co.unsqueeze(-3)
        dist = torch.sqrt(torch.sum(diff ** 2, dim=-1))  # (N, M)
        # amin(-1) computes the minimum distance over all cameras for each voxel
        # [G] The source notes mention amin(0) of amin(-1); amin(0) on a 1D tensor reduces to a scalar,
        # so amin(-1) is used here to correctly compute per-voxel minimum distance.
        batch_min = torch.amin(dist, dim=-1)  # (N,)
        if nearest_dist is None:
            nearest_dist = batch_min
        else:
            nearest_dist = torch.minimum(nearest_dist, batch_min)

    # Step 4: Identify visible voxels where n_duplicates > 0
    vis_idx = torch.where(n_duplicates > 0)[0]

    # Step 5: Set density.grid values to -100 where nearest_dist <= near_clip
    # Broadcasting nearest_dist to match density_grid shape
    density_grid[nearest_dist[None, None] <= near_clip] = -100.0

    # Step 6: Calculate z-distance from voxel centers to camera position along the lookat vector
    zdist = ((vox_centers[vis_idx] - cam_position) * cam_lookat).sum(-1)

    # Step 7: Mark voxels as near if zdist <= near_plane + vox_lengths
    is_near[vis_idx] |= (zdist <= near_plane + vox_lengths.squeeze(1)[vis_idx])

    return is_near
```

**Parameters:**
- `near_plane`: Default value 0.2, used as the threshold for near-plane culling [S2, unofficial].
- `near_clip`: Distance threshold for masking voxels near the camera [S1, unofficial].

**Edge Cases and Pitfalls:**
- Precision issues may arise when `zdist` is very close to `near_plane + vox_lengths` [S2, S1, unofficial].
- Boundary conditions for `n_duplicates` must be handled to ensure `vis_idx` is valid [S2, S1, unofficial].
- Not given in the sources.

## Operating characteristics
- **Time Complexity:** Not given in the sources.
- **Memory Complexity:** Not given in the sources.
- **Measured Performance:** Not given in the sources.
- **Scaling:** Not given in the sources.
- **Strengths:** Effectively prevents rendering artifacts from voxels too close to the camera [S2, S1, unofficial].
- **Limitations:** Requires accurate camera parameters and voxel centers [S2, S1, unofficial].
- **When to use:** When rendering volumes with a camera that may intersect or be very close to the voxel grid [S2, S1, unofficial].
- **When not to use:** When the camera is always far from the voxel grid [S2, S1, unofficial].

## Background
Near Plane Visibility Culling is used in 3D segmentation and rendering pipelines, such as SA3D, to handle near-plane clipping [S1, S2, unofficial].
