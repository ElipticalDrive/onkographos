# Near Plane Visibility Culling

Also called: Maskout Near Camera Voxels, Near Plane Visibility Check (mark_near)

## Overview
Near Plane Visibility Culling determines if voxels are too close to the camera for visibility, returning a boolean mask to exclude them from rendering [S2, S1, unofficial]. It sets apart from siblings by explicitly handling the near-plane clipping threshold to prevent artifacts from voxels intersecting the camera frustum's near plane, whereas Visible Bounds Calculation focuses on spatial extent and Obstacle-Flag handles occlusion [S2, S1, unofficial].

## How it works
**Inputs:**
- `cam_o`: Camera origin coordinates (tensor).
- `vox_centers`: Center coordinates of active voxels (tensor).
- `vox_lengths`: Lengths of voxels (tensor).
- `near_plane`: Threshold for near-plane culling (float, default 0.2) [S2, S1, unofficial].
- `near_clip`: Distance threshold for masking voxels near the camera (float) [S1, unofficial].
- `cam.lookat`: Camera look-at vector (tensor).
- `n_duplicates`: Count of duplicates per voxel (tensor, used to identify visible voxels) [S2, S1, unofficial].

**Outputs:**
- `is_near`: Boolean tensor of size `len(octree_paths)` indicating if each voxel is too near [S2, S1, unofficial].
- `density.grid`: Updated density values with near voxels masked to -100 [S1, unofficial].

**Data Structures:**
- `self_grid_xyz`: Tensor generated via `torch.meshgrid` of `linspace` from `xyz_min` to `xyz_max` for each dimension, stacked at the last axis [S1, unofficial].
- `is_near`: Boolean tensor initialized to `False` on CUDA [S2, S1, unofficial].

**Steps:**
1. Generate `self_grid_xyz` using `torch.meshgrid` of `linspace` from `xyz_min` to `xyz_max` for each dimension, stacked at -1 [S1, unofficial].
2. Initialize `is_near` tensor of size `len(octree_paths)` with `False` on CUDA [S2, S1, unofficial].
3. Calculate nearest distance from each grid point to each camera origin: `nearest_dist = amin(0) of amin(-1) of sqrt(sum((self_grid_xyz.unsqueeze(-2) - co)^2))` for `co` in `cam_o.split(100)` [S1, unofficial].
4. Identify visible voxels where `n_duplicates > 0`: `vis_idx = torch.where(n_duplicates > 0)[0]` [S2, S1, unofficial].
5. Set `density.grid` values to -100 where `nearest_dist[None,None] <= near_clip` [S1, unofficial].
6. Calculate z-distance from voxel centers to camera position along the lookat vector: `zdist = ((vox_centers[vis_idx] - cam.position) * cam.lookat).sum(-1)` [S2, S1, unofficial].
7. Mark voxels as near if `zdist <= near_plane + vox_lengths.squeeze(1)[vis_idx]`: `is_near[vis_idx] |= (zdist <= near_plane + vox_lengths.squeeze(1)[vis_idx])` [S2, S1, unofficial].

**Parameters:**
- `near_plane`: Default value 0.2, used as the threshold for near-plane culling [S2, S1, unofficial].
- `near_clip`: Distance threshold for masking voxels near the camera [S1, unofficial].

**Edge Cases and Pitfalls:**
- Precision issues may arise when `zdist` is very close to `near_plane + vox_lengths` [S2, S1, unofficial].
- Boundary conditions for `n_duplicates` must be handled to ensure `vis_idx` is valid [S2, S1, unofficial].
- Degenerate input where `vox_lengths` is zero or negative should be avoided [S2, S1, unofficial].

## Operating characteristics
- **Time Complexity:** Depends on the number of voxels and cameras. The distance calculation is $O(N \cdot M)$ where $N$ is the number of voxels and $M$ is the number of cameras [S1, S2, unofficial].
- **Memory Complexity:** $O(N)$ for storing `is_near` and `nearest_dist` [S1, S2, unofficial].
- **Measured Performance:** Not given in the sources.
- **Scaling:** Scales linearly with the number of voxels and cameras [S1, S2, unofficial].
- **Strengths:** Effectively prevents rendering artifacts from voxels too close to the camera [S2, S1, unofficial].
- **Limitations:** Requires accurate camera parameters and voxel centers [S2, S1, unofficial].
- **When to use:** When rendering volumes with a camera that may intersect or be very close to the voxel grid [S2, S1, unofficial].
- **When not to use:** When the camera is always far from the voxel grid [S2, S1, unofficial].

## Background
Near Plane Visibility Culling is used in 3D segmentation and rendering pipelines, such as SA3D and SVRaster, to handle near-plane clipping [S1, S2, unofficial]. It was developed as part of these projects to improve rendering quality and stability [S1, S2, unofficial].
