# Voxel Visibility Propagation
Also called: Cascade Visibility Inheritance

## Overview
Voxel Visibility Propagation determines voxel visibility within a multi-resolution cascade by inheriting occlusion data from coarser levels [S1, unofficial]. It efficiently culls visibility contributions in high-resolution grids by leveraging spatial coherence across cascade boundaries [S1, unofficial].

## How it works
**Inputs:** `voxel_targets` (opacity data), `visibility_targets` (visibility state), `target_cascade` (cascade index), and `first_entry` (boolean flag indicating the start of a cascade iteration) [S1, unofficial].
**Outputs:** Updated `visibility_targets` array containing propagated visibility values [S1, unofficial].
**Data Structures:** `visibility_targets` stores visibility as `unorm4x8` (4 channels, 8-bit unsigned normalized) with the visibility component in one channel and zeros in the others [S1, unofficial]. `voxel_targets` stores opacity values indexed by voxel position [S1, unofficial].
**Algorithm:**
1. Iterate through voxels in the `target_cascade` [S1, unofficial].
2. **Boundary Check:** Skip processing if any coordinate of `voxel_pos` is $\le 0$ or $\ge 32$ [S1, unofficial].
3. **Cascade Inheritance:** If `first_entry` is true, calculate `outer_voxel_pos = voxel_pos / 2` using integer division [S1, unofficial]. Compute the coarser index via `indexFromCascadePos(target_cascade + 1, outer_voxel_pos)` and set `visibility` to the value at that index in `visibility_targets` [S1, unofficial]. Set `first_entry` to false [S1, unofficial].
4. **Opacity Sampling:** Compute `ix_voxel = indexFromCascadePos(target_cascade, voxel_pos)` and unpack the opacity from `voxel_targets[ix_voxel]` [S1, unofficial].
5. **Visibility Update:** Store the current `visibility` into `visibility_targets[ix_voxel]` as a `unorm4x8` value with zeros in other channels [S1, unofficial]. Update `visibility` by multiplying it by $(1 - opacity)$ [S1, unofficial].

**Pseudocode:**
```python
def propagate_visibility(voxel_targets, visibility_targets, target_cascade, first_entry):
    # voxel_positions is the set of 3D coordinates for the cascade [G]
    is_first = first_entry
    visibility = 1.0  # Default; overwritten on first_entry

    for voxel_pos in voxel_positions:
        # Step 1: Boundary check
        if any(c <= 0 or c >= 32 for c in voxel_pos):
            continue

        # Step 2: Cascade inheritance
        if is_first:
            outer_voxel_pos = tuple(p // 2 for p in voxel_pos)
            coarser_index = indexFromCascadePos(target_cascade + 1, outer_voxel_pos)
            visibility = unpack_visibility(visibility_targets[coarser_index])
            is_first = False

        # Step 3: Opacity sampling
        ix_voxel = indexFromCascadePos(target_cascade, voxel_pos)
        opacity = unpack_opacity(voxel_targets[ix_voxel])

        # Step 4: Visibility update
        visibility_targets[ix_voxel] = pack_unorm4x8(visibility, 0, 0, 0)
        visibility = visibility * (1.0 - opacity)

# Helper definitions [G]
def indexFromCascadePos(cascade, pos):
    size = 32
    return pos[0] + pos[1] * size + pos[2] * size * size

def unpack_opacity(data):
    return data[0]

def unpack_visibility(data):
    return data[0]

def pack_unorm4x8(v, r, g, b):
    return [v, r, g, b]
```

**Parameters:**
- `cascade_size`: 32 voxels per dimension per cascade level, derived from the boundary check [S1, unofficial].
- `unorm4x8`: 8-bit unsigned normalized integer per channel, mapping values to $[0, 1]$ [S1, unofficial].

**Edge Cases:**
- **Precision:** Multiplicative accumulation of $(1 - opacity)$ can cause precision loss or underflow for deep occlusion chains [S1, unofficial].
- **Boundary Conditions:** Voxels at the edge of the cascade may lack valid coarser neighbors if the cascade hierarchy is not aligned [S1, unofficial].
- **Degenerate Input:** If `voxel_targets` contains no opacity data, visibility retains the inherited value [S1, unofficial].

## Operating characteristics
- **Time Complexity:** Not given in the sources.
- **Memory Complexity:** Not given in the sources.
- **Strengths:** Leverages spatial coherence; simple to implement; low computational overhead [S1, unofficial].
- **Limitations:** Accuracy depends on cascade alignment; multiplicative opacity can suffer from precision loss [S1, unofficial].
- **When to Use:** Skylight culling and ambient occlusion in voxel-based rendering pipelines [S1, unofficial].
- **When Not to Use:** Complex global illumination or dynamic scenes requiring high-precision visibility tracking [S1, unofficial].

## Background
Originated in the context of voxel cone tracing and voxel-based rendering pipelines, specifically in implementations like Sandalmoth's voxel-cone-tracing project [S1, unofficial]. It addresses the need for efficient visibility culling in multi-resolution voxel grids [S1, unofficial].
