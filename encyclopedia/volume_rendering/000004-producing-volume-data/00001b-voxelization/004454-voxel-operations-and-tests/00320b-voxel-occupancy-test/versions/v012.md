# Voxel Occupancy Test

Also called: Inclusion Test, Shared Voxels Mask, Sphere Filling, Void Check, Voxel Mask, Voxel Mask Output, Voxel Occlusion Query

## Overview
The Voxel Occupancy Test determines whether discrete points or geometric primitives lie within occupied voxels of a 3D grid, returning a binary mask of inclusion [S1][S4, unofficial]. It solves the problem of mapping continuous spatial queries (point clouds, bounding volumes) to a discrete voxel representation for culling, subdivision, or collision detection. It differs from [Voxel Filled Check](1705-voxel-filled-check.md) by actively computing occupancy from input geometry rather than querying a pre-existing static mask, and from [Sparse AABB Collision Test](3047-sparse-aabb-collision-test.md) by returning a per-point or per-voxel binary result rather than a material-classified collision status [S1][S4, unofficial].

## How it works
**Inputs:**
1.  **Voxel Grid**: A structured 3D grid defining the spatial domain. Defined by origin $(O_x, O_y, O_z)$, spacing $(S_x, S_y, S_z)$, and dimensions $(D_x, D_y, D_z)$ [S4, unofficial].
2.  **Query Points**: An array of $N$ points, each with continuous coordinates $(p_x, p_y, p_z)$ [S1].
3.  **Geometry (Optional)**: For geometry-based tests, scene primitives or depth buffers [S5, unofficial].

**Outputs:**
1.  **Binary Mask**: A boolean or UInt8 array of size $N$ (per point) or $D_x \times D_y \times D_z$ (per voxel), where $1$ indicates occupancy/inclusion and $0$ indicates void [S1][S4, unofficial].

**Data Structures:**
*   **Grid Layout**: Linearized array of size $D_x D_y D_z$. Index $I(i, j, k) = i + D_x(j + D_y k)$ for XYZ indexing [G].
*   **Point Array**: $N \times 3$ float matrix.

**Steps:**

1.  **Coordinate Transformation**: For each query point $P_n = (p_x, p_y, p_z)$, compute grid indices $(i, j, k)$:
    $$
    i = \lfloor \frac{p_x - O_x}{S_x} \rfloor, \quad j = \lfloor \frac{p_y - O_y}{S_y} \rfloor, \quad k = \lfloor \frac{p_z - O_z}{S_z} \rfloor
    $$
    [G]

2.  **Boundary Check**: If any index is outside $[0, D_x-1]$, $[0, D_y-1]$, or $[0, D_z-1]$, the point is outside the grid.
    *   *Pitfall*: Points outside are silently dropped with no warning, resulting in an all-zero mask if origin/spacing is mismatched [S4, unofficial].
    *   *Pitfall*: Non-finite coordinates (NaN/Inf) are skipped [S4, unofficial].

3.  **Occupancy Determination**:
    *   **Point-to-Voxel**: If the grid stores occupancy flags, read the value at $(i, j, k)$. If the grid is empty, mark as 0. If the grid is populated, mark as 1 [S1].
    *   **Sphere Filling (Kernel Generation)**: To fill a voxel with a sphere of radius $r = CS/2$ (where $CS$ is cell size), iterate over a 3D grid centered at the origin with radius $r$. For each voxel $(x, y, z)$, if $\sqrt{x^2 + y^2 + z^2} < r$, set the voxel at $(x+r, y+r, z+r)$ to 1 [S3, unofficial].
    *   **Geometry Intersection**: Sample scene depth at voxel corners or use occlusion queries to determine if scene geometry exists inside the voxel [S5, unofficial].

4.  **Output Assembly**: Write the result to the output array. For point clouds, the mask is written in point order. A spatially unsorted cloud produces scattered writes, which is I/O-bound with out-of-core storage. Pre-sorting the point cloud spatially helps [S4, unofficial].

**Pseudocode:**
```python
def voxel_occupancy_test(points, grid_origin, grid_spacing, grid_dims):
    """
    Test if points are within occupied voxels.
    points: list of (x, y, z) tuples
    grid_origin: (ox, oy, oz)
    grid_spacing: (sx, sy, sz)
    grid_dims: (dx, dy, dz)
    Returns: list of bools
    """
    results = []
    for p in points:
        px, py, pz = p
        
        # Check for non-finite coordinates
        if not (isfinite(px) and isfinite(py) and isfinite(pz)):
            results.append(False)
            continue
            
        # Compute grid indices
        ix = floor((px - grid_origin[0]) / grid_spacing[0])
        iy = floor((py - grid_origin[1]) / grid_spacing[1])
        iz = floor((pz - grid_origin[2]) / grid_spacing[2])
        
        # Boundary check
        if (ix < 0 or ix >= grid_dims[0] or
            iy < 0 or iy >= grid_dims[1] or
            iz < 0 or iz >= grid_dims[2]):
            # Silently drop out-of-bounds points
            continue
            
        # Check occupancy in grid
        # Assuming grid is a 3D array or hash map of occupancy flags
        if grid[ix, iy, iz] == 1:
            results.append(True)
        else:
            results.append(False)
            
    return results
```

## Subtopics

### Voxel Contains Scene Geometry Test
A method to determine if any scene geometry exists inside a voxel, used to flag voxels for subdivision [S5, unofficial]. It differs from simple point inclusion by using rendering techniques (depth sampling or occlusion queries) to detect geometry intersection [S5, unofficial]. Steps include: 1) Sample scene depth at voxel corners; 2) Alternatively, place the camera at the voxel center, render quads for the voxel faces, then render the scene, and check if any draw calls pass the occlusion query [S5, unofficial].

## Operating characteristics
*   **Time Complexity**: $O(N)$ for point clouds, where $N$ is the number of query points [S1]. For sphere filling, $O(r^3)$ where $r$ is the radius in voxels [S3, unofficial].
*   **Memory Complexity**: $O(D_x D_y D_z)$ for the grid storage [S4, unofficial].
*   **Performance**: I/O-bound if point clouds are unsorted and written to out-of-core storage [S4, unofficial].
*   **Strengths**: Simple, fast for dense grids; effective for culling and subdivision [S1][S5, unofficial].
*   **Limitations**: Sensitive to coordinate system mismatches; silent failures for out-of-bounds points [S4, unofficial].

## Background
The Voxel Occupancy Test is a fundamental operation in voxel-based rendering and simulation, originating from early voxelization techniques in computer graphics [S1]. It is widely used in point cloud processing, irradiance volume generation, and voxel-based physics engines [S1][S4, S5, unofficial].
