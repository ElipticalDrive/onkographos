# Sparse AABB Collision Test

Also called: TestAabb

## Overview
The Sparse AABB Collision Test determines whether an axis-aligned bounding box (AABB) intersects any occupied voxels within a sparse volume representation [S1, unofficial]. It solves the problem of discrete collision detection for entities or objects moving through a voxel world by sampling the volume defined by the AABB [S1, unofficial]. It differs from its sibling [Point-in-Box Inclusion Test](1400-point-in-box-inclusion-test.md) by classifying samples into specific material types (solid, liquid, unknown) rather than a simple binary occupancy, and from its parent [Voxel Occupancy Test](1281-voxel-occupancy-test.md) by supporting configurable blocking rules for liquids and tracking the first blocking sample [S1, unofficial].

## How it works
**Inputs:**
- `aabb`: A `SparseCollisionAabb` structure defining the test volume with `min` and `max` float coordinates.
- `liquidsBlock`: A boolean flag indicating if liquid voxels count as blocking collisions.

**Outputs:**
- A result structure containing:
  - `blocked`: Boolean indicating if any blocking voxel was found.
  - `solidVoxels`, `liquidVoxels`, `unknownVoxels`, `sampledVoxels`: Integer counters for each sample type.
  - `hasLiquid`, `hasUnknown`: Boolean flags indicating presence of these types.
  - `firstBlockingSample`: The `CollisionSample` data of the first blocking voxel encountered.
  - `firstBlockingX`, `firstBlockingY`, `firstBlockingZ`: Integer voxel coordinates of the first blocking voxel.

**Data Structures:**
- `SparseCollisionAabb`: Contains `min` and `max` vectors.
- `CollisionSample`: Contains `status` (enum: `KnownAir`, `KnownSolid`, `KnownLiquid`, `UnknownBlocked`) and potentially other metadata.
- `colHeight`, `colRelief`: Precomputed arrays indexed by XZ footprint column, storing terrain height and relief values to cache noise evaluation.

**Steps:**
1. **Validate Bounds:** Check if `aabb.min` or `aabb.max` contains non-finite values (NaN or Infinity). If so, return immediately with `UnknownBlockedVolume` status [S1, unofficial].
2. **Voxel Range Conversion:** Convert the AABB's float coordinates to integer voxel indices using `TryBuildVoxelRange`. This function handles float precision at boundaries using `nextafter` for the max-exclusive limit [S1, unofficial]. Let the resulting range be `[minX, maxX]`, `[minY, maxY]`, `[minZ, maxZ]`.
3. **Sample Limit Check:** Calculate the total voxel count: $(maxX - minX + 1) \times (maxY - minY + 1) \times (maxZ - minZ + 1)$. If this count exceeds `kMaxCollisionVolumeSamples` (32768), return immediately with `UnknownBlockedVolume` status [S1, unofficial].
4. **Precompute Column Data:** Iterate over the XZ footprint of the AABB. For each column $(x, z)$, compute the terrain height and relief using the volume's noise function. Store these in `colHeight` and `colRelief` arrays indexed by the column offset. This collapses the noise evaluation cost from $O(voxels)$ to $O(columns)$ [S1, unofficial].
5. **Iterate Voxels:** Loop through the voxel grid in order: $Z$ from `minZ` to `maxZ`, $Y$ from `minY` to `maxY`, $X$ from `minX` to `maxZ` [S1, unofficial].
6. **Sample Voxel:** For each voxel $(x, y, z)$, calculate the column index and call `SampleWithColumn(x, y, z, colHeight[idx], colRelief[idx])` to get the `CollisionSample` [S1, unofficial].
7. **Classify and Count:** Increment `sampledVoxels`. Based on `sample.status`:
   - `KnownAir`: Do nothing.
   - `KnownSolid`: Increment `solidVoxels`. Set `sampleBlocks = true`.
   - `KnownLiquid`: Increment `liquidVoxels`. Set `hasLiquid = true`. Set `sampleBlocks = liquidsBlock`.
   - `UnknownBlocked` (or default): Increment `unknownVoxels`. Set `hasUnknown = true`. Set `sampleBlocks = true`.
8. **Track First Block:** If `sampleBlocks` is true and `result.blocked` is false, set `result.blocked = true`, record `result.firstBlockingSample`, and store $(x, y, z)$ in `result.firstBlockingX/Y/Z` [S1, unofficial].
9. **Return:** Return the populated result structure.

**Pseudocode:**
```python
def sparse_aabb_collision_test(aabb: SparseCollisionAabb, liquidsBlock: bool) -> CollisionResult:
    # Step 1: Validate bounds
    if not is_finite(aabb.min) or not is_finite(aabb.max):
        return CollisionResult(status=UnknownBlockedVolume)

    # Step 2: Convert to voxel indices
    minX, maxX, minY, maxY, minZ, maxZ = try_build_voxel_range(aabb)

    # Step 3: Check sample limit
    spanX = maxX - minX + 1
    spanY = maxY - minY + 1
    spanZ = maxZ - minZ + 1
    total_voxels = spanX * spanY * spanZ
    
    if total_voxels > 32768:
        return CollisionResult(status=UnknownBlockedVolume)

    # Step 4: Precompute column data
    colHeight = array(size=spanX * spanZ)
    colRelief = array(size=spanX * spanZ)
    for z in range(minZ, maxZ + 1):
        for x in range(minX, maxX + 1):
            idx = (x - minX) + (z - minZ) * spanX
            colHeight[idx], colRelief[idx] = compute_terrain_noise(x, z)

    # Initialize result
    result = CollisionResult()
    result.blocked = False

    # Step 5-8: Iterate and sample
    for z in range(minZ, maxZ + 1):
        for y in range(minY, maxY + 1):
            for x in range(minX, maxX + 1):
                idx = (x - minX) + (z - minZ) * spanX
                sample = sample_with_column(x, y, z, colHeight[idx], colRelief[idx])
                result.sampledVoxels += 1
                
                sampleBlocks = False
                if sample.status == KnownAir:
                    pass
                elif sample.status == KnownSolid:
                    result.solidVoxels += 1
                    sampleBlocks = True
                elif sample.status == KnownLiquid:
                    result.liquidVoxels += 1
                    result.hasLiquid = True
                    sampleBlocks = liquidsBlock
                else: # UnknownBlocked or default
                    result.unknownVoxels += 1
                    result.hasUnknown = True
                    sampleBlocks = True

                if sampleBlocks and not result.blocked:
                    result.blocked = True
                    result.firstBlockingSample = sample
                    result.firstBlockingX = x
                    result.firstBlockingY = y
                    result.firstBlockingZ = z

    return result
```

**Parameters:**
- `kMaxCollisionVolumeSamples`: Constant `uint64_t` value of 32768. Maximum allowed voxel count before early exit [S1, unofficial].

**Edge Cases and Pitfalls:**
- Non-finite AABB bounds trigger an immediate return with `UnknownBlockedVolume` [S1, unofficial].
- Exceeding the sample limit (32768 voxels) triggers an immediate return with `UnknownBlockedVolume` [S1, unofficial].
- `TryBuildVoxelRange` uses `nextafter` for the max-exclusive boundary to handle floating-point precision errors at voxel edges [S1, unofficial].

## Subtopics

### [Sparse AABB Sweep Test](5413-sparse-aabb-sweep-test.md)
The Sparse AABB Sweep Test is a voxel occupancy test that determines whether an axis-aligned bounding box (AABB) moving along a displacement vector intersects any occupied voxels in a sparse volume. It approximates continuous collision detection by sampling the displacement path at discrete intervals. It differs from its sibling [Support Below Search](5414-support-below-search.md) by testing the entire swept volume rather than just the base support, and from its parent [Sparse AABB Collision Test](3047-sparse-aabb-collision-test.md) by handling non-zero displacement vectors through temporal sampling.

### [Support Below Search](5414-support-below-search.md)
Support Below Search determines if a voxel position has structural support directly beneath it within a specified vertical drop distance. It solves the problem of identifying valid standing positions for entities or objects in a voxel world by finding the first non-empty voxel (solid, liquid, or blocked unknown) below a given footprint. It differs from [Sparse AABB Sweep Test](5413-sparse-aabb-sweep-test.md) by iterating through a defined volume to find the *first* support rather than sweeping for *any* collision along a path, and builds on [Sparse AABB Collision Test](3047-sparse-aabb-collision-test.md) by utilizing its collision sample semantics [G].

### Voxel-Primitive Intersection Culling
A technique to cull unwanted voxels generated by conservative rasterization edge expansion. It checks for intersections between the primitive's plane and the voxels in the depth direction within a single pixel [S2, unofficial]. The method splits workload between the Geometry Shader (GS) and Pixel Shader (PS). In the GS, the primitive's AABB is calculated from vertex min/max coordinates. In the PS, the voxel's AABB is defined by the grid. An AABB test discards voxels that do not intersect the primitive's AABB. If they intersect, an Edge-Voxel Condition Test is performed in each of the three axis-aligned planes (XY, YZ, ZX). For each edge, the signed distance from the edge to the voxel's vertices is calculated. The maximum signed distance across all voxel vertices is used. If all calculated signed distances are positive, the test passes, and the voxel is covered [S2, unofficial]. The intersection target is the entire box of the voxel [S2, unofficial].

### VoxelBoxMover Collision System
A Minecraft-like collision system provided by the `VoxelBoxMover` class, used as an alternative to mesh-based collisions (Trimesh) which are slow to build and process. It is faster, not affected by tunnelling, but more limited [S3]. The system initializes with a character bounding box (AABB) and terrain node. In the physics process, it calculates a motion vector from velocity and delta time, then calls `box_mover.get_motion()` with the current translation, motion vector, character box, and terrain to apply collision. The global translation and velocity are updated based on the returned motion. If using `VoxelMesherBlocky`, collision is determined by a list of AABBs in `VoxelBlockyModel` resources. If the list is empty, the voxel has no collisions. Collisions can be filtered using `VoxelBoxMover.collision_mask` matched against `VoxelBlockyModel.collision_mask` [S3]. This technique mainly works with `VoxelMesherBlocky`, which gets collidable block info from `VoxelBlockyLibrary`. It may have limited support in other meshers [S3].

## Operating characteristics
- **Time Complexity:** $O(columns)$ for cache initialization + $O(voxels)$ for sampling. The method collapses terrain-noise evaluation cost from $O(voxels)$ to $O(columns)$ by caching per-column height/relief [S1, unofficial].
- **Memory Complexity:** Proportional to the XZ footprint size ($spanX \times spanZ$) for the `colHeight` and `colRelief` caches.
- **Performance:** The sample limit of 32768 voxels ensures bounded execution time, preventing performance spikes from large AABBs [S1, unofficial].
- **Strengths:** Efficient noise caching; configurable blocking rules for liquids; handles sparse volumes effectively.
- **Limitations:** Limited to AABB shapes; discrete sampling may miss thin features if not carefully tuned (though this specific test is discrete, not swept); limited support for non-blocky meshers in related systems [S3].
- **When to use:** Discrete collision detection in voxel-based games or simulations where performance is critical and AABBs are sufficient.
- **When not to use:** Continuous collision detection requiring swept volumes (use [Sparse AABB Sweep Test](5413-sparse-aabb-sweep-test.md)); complex mesh collisions (use Trimesh).

## Background
The Sparse AABB Collision Test is part of the VENPOD voxel physics engine implementation [S1, unofficial]. It is designed for high-performance voxel simulation, targeting 100M+ active voxels at 60 FPS [S1, unofficial]. The method leverages precomputed column data to optimize noise evaluation, a common technique in procedural voxel terrain generation.
