# Entity Collision & Movement

Also called: Entity Physics, Grid-Based Movement, Player Movement & Collision, Voxel Entity Physics

## Overview
Entity Collision & Movement handles the physics simulation and positional updates of an entity within a voxel grid, ensuring it moves correctly without intersecting solid blocks [S2, unofficial]. It distinguishes itself from simple raycasting by integrating gravity, ground detection, and axis-aligned sliding against voxel walls [S1, S2, unofficial].

## How it works
**Inputs:** Entity state (position, velocity, yaw), input direction vector, time step ($dt$), and the voxel world data (chunks/blocks).
**Outputs:** Updated entity position and velocity.

**Data Structures:**
*   **Entity:** Contains `position` (vec3), `velocity` (vec3), and `onGround` (bool) [S2, unofficial].
*   **World:** A collection of `Chunk` objects. Each chunk has a fixed size (`CHUNK_SIZE`) and height (`CHUNK_HEIGHT`) [S2, unofficial]. Blocks are stored in a 3D array `blocks[localX][localY][localZ]` [S2, unofficial].
*   **Block ID:** Solid blocks are represented by any integer other than 255 (air) [S2, unofficial].

**Parameters:**
*   `MOVE_SPEED`: 10 [S2, unofficial].
*   `JUMP_POWER`: 10 [S2, unofficial].
*   `GRAVITY`: 30 [S2, unofficial].
*   `ENTITY_HEIGHT`: 2 blocks [S2, unofficial].

**Steps:**
1.  **Gravity Application:** Apply gravitational acceleration to the vertical velocity: $velocity.y \leftarrow velocity.y - GRAVITY \times dt$ [S2, unofficial].
2.  **Ground Detection:** Check the block at the entity's feet position. The check location is `position - (0, ENTITY_HEIGHT, 0)` [S2, unofficial].
    *   If the block is not air (255), set `onGround = true`.
    *   If `onGround` is true and `velocity.y < 0`, set `velocity.y = 0` [S2, unofficial].
    *   Snap `position.y` to `ceil(position.y)` to align with the block surface [S2, unofficial].
    *   If not on ground, update vertical position: $position.y \leftarrow position.y + velocity.y \times dt$ [S2, unofficial].
3.  **Fall-off Reset:** If `position.y < 0`, teleport the entity to `y = 100` and reset `velocity.y` to 0 [S2, unofficial].
4.  **Horizontal Movement Calculation:**
    *   Normalize the input direction vector to the horizontal plane (ignore Y) [S2, unofficial].
    *   Calculate the `front` vector based on yaw: $front = (\cos(yaw), 0, \sin(yaw))$ [S2, unofficial].
    *   Calculate the `right` vector: $right = normalize(cross(front, up))$, where $up = (0, 1, 0)$ [S2, unofficial].
    *   Calculate the movement `change` vector:
        $$change = front \times (-input.z \times MOVE\_SPEED \times dt) + right \times (input.x \times MOVE\_SPEED \times dt)$$
        Note: The source code uses `dir.z` for forward/backward and `dir.x` for strafe, with a negative sign on the front component [S2, unofficial].
5.  **Collision Resolution (Axis-Aligned Sliding):**
    *   Define `goal` as `position - (0, ENTITY_HEIGHT - 0.5, 0)` [S2, unofficial].
    *   Check if `blockAt(goal + change)` is air (255).
        *   If yes, update position to `goal + change + (0, ENTITY_HEIGHT - 0.5, 0)` [S2, unofficial].
        *   If no, attempt to slide along X: Set `change.x = 0`. Check `blockAt(goal + change)`.
            *   If air, update position [S2, unofficial].
            *   If not, attempt to slide along Z: Set `change.z = 0` (resetting X to 0 as well). Check `blockAt(goal + change)`.
            *   If air, update position [S2, unofficial].
6.  **Jumping:** If `onGround` is true and jump is triggered, set `velocity.y = JUMP_POWER` [S2, unofficial].

**Pseudocode:**
```python
def update_entity(entity, input_dir, yaw, chunks, dt):
    # 1. Gravity
    entity.velocity.y -= GRAVITY * dt

    # 2. Ground Detection
    # Check block at feet: position - (0, ENTITY_HEIGHT, 0)
    feet_pos = entity.position - vec3(0, ENTITY_HEIGHT, 0)
    block = block_at(feet_pos, chunks)

    if block != 255:
        entity.on_ground = True
        if entity.velocity.y < 0:
            entity.velocity.y = 0
        entity.position.y = ceil(entity.position.y)
    else:
        entity.on_ground = False
        entity.position.y += entity.velocity.y * dt

    # 3. Fall-off Reset
    if entity.position.y < 0:
        entity.position.y = 100
        entity.velocity.y = 0

    # 4. Horizontal Movement
    # Normalize input to horizontal plane
    move_dir = normalize(vec3(input_dir.x, 0, input_dir.z))
    
    # Calculate vectors
    front = vec3(cos(yaw), 0, sin(yaw))
    up = vec3(0, 1, 0)
    right = normalize(cross(front, up))
    
    # Calculate change vector
    # Source: change += front * dir.z * (float) -MOVE_SPEED * (float)dt;
    # Source: change += right * dir.x * (float) MOVE_SPEED * (float)dt;
    change = front * (-move_dir.z * MOVE_SPEED * dt) + right * (move_dir.x * MOVE_SPEED * dt)

    # 5. Collision Resolution
    # Goal is position adjusted for entity height offset used in block check
    goal = entity.position - vec3(0, ENTITY_HEIGHT - 0.5, 0)
    
    if block_at(goal + change, chunks) == 255:
        entity.position = goal + change + vec3(0, ENTITY_HEIGHT - 0.5, 0)
    else:
        # Try sliding X
        new_change = change
        new_change.x = 0
        if block_at(goal + new_change, chunks) == 255:
            entity.position = goal + new_change + vec3(0, ENTITY_HEIGHT - 0.5, 0)
        else:
            # Try sliding Z
            new_change = change
            new_change.z = 0
            if block_at(goal + new_change, chunks) == 255:
                entity.position = goal + new_change + vec3(0, ENTITY_HEIGHT - 0.5, 0)

def jump(entity):
    if entity.on_ground:
        entity.velocity.y = JUMP_POWER

def block_at(goal, chunks):
    # Round to nearest integer block coordinate
    x = round(goal.x - 0.5)
    y = goal.y
    z = round(goal.z - 0.5)
    
    # Calculate chunk indices
    x_chunk_idx = floor(x / CHUNK_SIZE)
    z_chunk_idx = floor(z / CHUNK_SIZE)
    
    # Find the correct chunk
    for chunk in chunks:
        if y >= chunk.CHUNK_HEIGHT:
            break
        if chunk.position.x == x_chunk_idx and chunk.position.y == z_chunk_idx:
            local_x = x - chunk.position.x * CHUNK_SIZE
            local_y = y
            local_z = z - chunk.position.y * CHUNK_SIZE
            return chunk.blocks[local_x][local_y][local_z]
            
    return 255 # Air if chunk not found or out of bounds
```

## Operating characteristics
*   **Time Complexity:** $O(1)$ per frame for a single entity, assuming chunk lookup is $O(1)$ or $O(\log N)$ depending on chunk storage structure. The collision resolution involves at most 3 block lookups [S2, unofficial].
*   **Memory Complexity:** $O(1)$ additional memory per entity [S2, unofficial].
*   **Strengths:** Simple to implement; provides basic "slide" behavior against walls; handles gravity and ground detection [S2, unofficial].
*   **Limitations:** Only supports axis-aligned sliding; does not handle diagonal sliding or complex collisions (e.g., head-bumping ceilings during movement) [S2, unofficial]. The teleport-on-fall is a simple safeguard rather than a physics solution [S2, unofficial].
*   **When to use:** Simple voxel games where high-fidelity physics is not required [S2, unofficial].

## Background
This method is derived from implementations found in voxel engine tutorials and prototypes, specifically those involving grid-based movement and collision detection [S1, S2, unofficial]. It is commonly used in early-stage voxel game development to provide basic player interaction with the world [S1, S2, unofficial].
