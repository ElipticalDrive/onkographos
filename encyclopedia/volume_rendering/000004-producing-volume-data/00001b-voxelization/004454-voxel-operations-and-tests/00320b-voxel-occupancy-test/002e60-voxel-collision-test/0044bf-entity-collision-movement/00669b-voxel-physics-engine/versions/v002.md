# Voxel Physics Engine

Also called: Abstracted terrain physics engine for voxel games

## Overview
The Voxel Physics Engine is a rigid-body simulation system designed for voxel-based game environments, handling collisions between entities and solid or liquid voxel terrain [S1, unofficial]. It distinguishes itself from general-purpose physics engines by relying on abstracted boolean test functions for voxel properties rather than a pre-computed spatial structure, making it lightweight and engine-agnostic [S1, unofficial]. Unlike its predecessor `voxel-physical`, it implements more physically accurate behaviors including semi-implicit Euler integration, axis-dependent friction, and buoyancy [S1, unofficial].

## How it works
### Inputs and Outputs
**Inputs:**
*   `testSolid(x, y, z)`: A function returning `true` if the voxel at integer coordinates is solid [S1, unofficial].
*   `testFluid(x, y, z)`: A function returning `true` if the voxel at integer coordinates is fluid [S1, unofficial].
*   `options`: Configuration object merging with `DefaultOptions` [S1, unofficial].
*   `dt`: Time step in milliseconds [S1, unofficial].

**Outputs:**
*   Updated rigid body states (position, velocity, resting flags) [S1, unofficial].
*   Collision impact vectors passed to `onCollide` callbacks [S1, unofficial].

### Data Structures
**RigidBody:**
*   `aabb`: Axis-Aligned Bounding Box defined by `base` (min corner) and `vec` (dimensions) [S1, unofficial].
*   `mass`: Scalar. Bodies with `mass <= 0` are static [S1, unofficial].
*   `velocity`: Vector `[vx, vy, vz]` [S1, unofficial].
*   `resting`: Vector `[rx, ry, rz]` where each component is `-1`, `0`, or `1` indicating contact direction (-1 for negative axis, 1 for positive, 0 for none) [S1, unofficial].
*   `friction`: Scalar coefficient [S1, unofficial].
*   `restitution`: Scalar coefficient (0 to 1) [S1, unofficial].
*   `gravityMultiplier`: Scalar multiplier for global gravity [S1, unofficial].
*   `airDrag`: Scalar. If `>= 0`, overrides global air drag [S1, unofficial].
*   `fluidDrag`: Scalar. If `>= 0`, overrides global fluid drag [S1, unofficial].
*   `inFluid`: Boolean flag [S1, unofficial].
*   `ratioInFluid`: Scalar fraction of volume submerged [S1, unofficial].
*   `autoStep`: Boolean flag enabling automatic stepping onto 1-unit obstructions [S1, unofficial].
*   `onCollide(impacts)`: Callback function receiving impact vector [S1, unofficial].

**Physics Engine:**
*   `bodies`: List of `RigidBody` instances [S1, unofficial].
*   `gravity`: Vector `[gx, gy, gz]` [S1, unofficial].
*   `airDrag`: Global default air drag coefficient [S1, unofficial].
*   `fluidDrag`: Global default fluid drag coefficient [S1, unofficial].
*   `fluidDensity`: Scalar density for buoyancy calculations [S1, unofficial].
*   `minBounceImpulse`: Scalar threshold for bounce activation [S1, unofficial].

### Parameters
*   `DefaultOptions.airDrag`: 0.1 [S1, unofficial].
*   `DefaultOptions.fluidDrag`: 0.4 [S1, unofficial].
*   `DefaultOptions.fluidDensity`: 2.0 [S1, unofficial].
*   `DefaultOptions.gravity`: `[0, -10, 0]` [S1, unofficial].
*   `DefaultOptions.minBounceImpulse`: 0.5 [S1, unofficial].

### Algorithm Steps
1.  **Initialization**: Create `Physics` instance with `testSolid`, `testFluid`, and optional `options` [S1, unofficial]. Merge options with `DefaultOptions` [S1, unofficial].
2.  **Body Addition**: Add bodies via `addBody(aabb, mass, friction, restitution, gravMult, onCollide)` [S1, unofficial]. Defaults: AABB `[0,0,0]` to `[1,1,1]`, mass 1, friction 1, restitution 0, gravMult 1 [S1, unofficial].
3.  **Simulation Tick (`tick(dt)`)**:
    1.  Convert `dt` to seconds: `dt_sec = dt / 1000` [S1, unofficial].
    2.  For each body `b`:
        1.  **Static Check**: If `b.mass <= 0`, set `velocity`, `_forces`, and `_impulses` to zero [S1, unofficial]. Return [S1, unofficial].
        2.  **Sleep Check**: If `bodyAsleep(b)` returns true, skip processing [S1, unofficial]. Decrement `_sleepFrameCount` [S1, unofficial].
        3.  **Fluid Forces**: Call `applyFluidForces(self, b)` [S1, unofficial].
            *   Check if corner `(b.aabb.base[0], b.aabb.base[1], b.aabb.base[2])` is fluid [S1, unofficial]. If not, `b.inFluid = false` [S1, unofficial].
            *   If fluid, count submerged voxels from `y0 = b.aabb.base[1]` up to `y1 = b.aabb.base[1] + b.aabb.vec[1]` [S1, unofficial].
            *   Calculate `fluidLevel = y0 + submerged_count` [S1, unofficial].
            *   Calculate `heightInFluid = fluidLevel - b.aabb.base[1]` [S1, unofficial].
            *   Calculate `ratioInFluid = min(heightInFluid / b.aabb.vec[1], 1.0)` [S1, unofficial].
            *   Calculate displaced volume `vol = b.aabb.vec[0] * b.aabb.vec[1] * b.aabb.vec[2]` [S1, unofficial].
            *   Calculate buoyant force `f = -gravity * fluidDensity * (vol * ratioInFluid)` [S1, unofficial].
            *   Apply force `f` to body [S1, unofficial]. Set `b.inFluid = true`, `b.ratioInFluid = ratioInFluid` [S1, unofficial].
        4.  **Integration (Semi-implicit Euler)**:
            *   Acceleration: `a = (_forces / mass) + (gravity * gravityMultiplier)` [S1, unofficial].
            *   Velocity Change: `dv = (_impulses / mass) + (a * dt_sec)` [S1, unofficial].
            *   Update Velocity: `velocity = velocity + dv` [S1, unofficial].
        5.  **Friction Application**: If `b.friction` is set, call `applyFrictionByAxis` for axes 0, 1, and 2 [S1, unofficial].
            *   For axis `i`:
                *   Let `restDir = resting[i]`, `vNormal = dv[i]` [S1, unofficial].
                *   If `restDir == 0` or `restDir * vNormal <= 0`, return [S1, unofficial].
                *   Calculate lateral velocity magnitude `vCurr` from `velocity` excluding axis `i` [S1, unofficial].
                *   If `vCurr == 0`, return [S1, unofficial].
                *   Calculate `dvMax = abs(friction * vNormal)` [S1, unofficial].
                *   Calculate scaler `s = max(0, (vCurr - dvMax) / vCurr)` [S1, unofficial].
                *   Scale lateral velocity components by `s` [S1, unofficial].
        6.  **Linear Drag**:
            *   Determine `drag`: If `b.airDrag >= 0` use it, else use global `airDrag` [S1, unofficial].
            *   If `b.inFluid`: If `b.fluidDrag >= 0` use it, else use global `fluidDrag` [S1, unofficial]. Multiply by `(1 - ratioInFluid)^2` [S1, unofficial].
            *   Calculate multiplier `mult = max(1 - (drag * dt_sec / mass), 0)` [S1, unofficial].
            *   Scale `velocity` by `mult` [S1, unofficial].
        7.  **Position Update**: `dx = velocity * dt_sec` [S1, unofficial].
        8.  **Reset Forces**: Set `_forces` and `_impulses` to zero [S1, unofficial].
        9.  **Collision Sweep**:
            *   If `b.autoStep`, cache current AABB in `tmpBox` [S1, unofficial].
            *   Call `sweep(testSolid, b.aabb, dx, callback)` [S1, unofficial].
            *   Callback: If collision detected on axis `i` with direction `dir`, set `resting[i] = dir` and zero the position component along `i` in `dx` (effectively stopping movement along that axis) [S1, unofficial].
        10. **Auto-Stepping**: If `b.autoStep` and `resting[1] >= 0` (on ground) or `b.inFluid`, return [S1, unofficial].
            *   Check if X or Z movement is blocked [S1, unofficial].
            *   Check movement ratio `abs(dx[0]/dx[2])` against cutoff 4 [S1, unofficial].
            *   Move towards target until first X/Z collision (ignoring Y) [S1, unofficial].
            *   Calculate Y step distance `ydist = floor(b.aabb.base[1] + 1.001) - b.aabb.base[1]` [S1, unofficial].
            *   Sweep up by `upvec = [0, ydist, 0]` [S1, unofficial]. If collision, return [S1, unofficial].
            *   Sweep leftover X/Z movement [S1, unofficial]. If no movement in blocked direction, return [S1, unofficial].
            *   Update AABB and `resting` [S1, unofficial].
        11. **Impact Calculation**:
            *   Initialize `impacts` to zero [S1, unofficial].
            *   For each axis `i`: If `resting[i] != 0` and `oldResting[i] == 0`, set `impacts[i] = -velocity[i]` [S1, unofficial].
            *   Set `velocity[i] = 0` for all collided axes [S1, unofficial].
        12. **Bounce Resolution**:
            *   Calculate impact magnitude `mag = length(impacts)` [S1, unofficial].
            *   If `mag > 0.001` (epsilon) and `b.restitution > 0` and `mag > minBounceImpulse`:
                *   Scale `impacts` by `b.restitution` [S1, unofficial].
                *   Apply impulse `impacts` to body [S1, unofficial].
        13. **Sleep Check**: If `squared_length(velocity) > 1e-5`, mark body as active [S1, unofficial].

import math
from typing import Callable, List, Tuple, Optional

def vec_add(v1, v2): return [v1[0]+v2[0], v1[1]+v2[1], v1[2]+v2[2]]
def vec_sub(v1, v2): return [v1[0]-v2[0], v1[1]-v2[1], v1[2]-v2[2]]
def vec_scale(v, s): return [v[0]*s, v[1]*s, v[2]*s]
def vec_length(v): return math.sqrt(v[0]**2 + v[1]**2 + v[2]**2)
def vec_squared_length(v): return v[0]**2 + v[1]**2 + v[2]**2
def vec_copy(v1, v2): v1[0]=v2[0]; v1[1]=v2[1]; v1[2]=v2[2]
def vec_set(v, x, y, z): v[0]=x; v[1]=y; v[2]=z
def vec_scale_and_add(v1, v2, v3, s):
    v1[0] = v2[0] + v3[0]*s
    v1[1] = v2[1] + v3[1]*s
    v1[2] = v2[2] + v3[2]*s

class AABB:
    def __init__(self, base, vec):
        self.base = list(base)
        self.vec = list(vec)

class RigidBody:
    def __init__(self, aabb, mass, friction, restitution, grav_mult, on_collide):
        self.aabb = aabb
        self.mass = mass
        self.friction = friction
        self.restitution = restitution
        self.gravity_multiplier = grav_mult
        self.on_collide = on_collide
        self.velocity = [0.0, 0.0, 0.0]
        self.resting = [0, 0, 0]
        self._forces = [0.0, 0.0, 0.0]
        self._impulses = [0.0, 0.0, 0.0]
        self.air_drag = -1.0
        self.fluid_drag = -1.0
        self.in_fluid = False
        self.ratio_in_fluid = 0.0
        self.auto_step = False
        self._sleep_frame_count = 0

    def apply_force(self, f):
        self._forces[0] += f[0]
        self._forces[1] += f[1]
        self._forces[2] += f[2]

    def apply_impulse(self, i):
        self._impulses[0] += i[0]
        self._impulses[1] += i[1]
        self._impulses[2] += i[2]

class Physics:
    def __init__(self, test_solid: Callable[[int, int, int], bool], 
                 test_fluid: Callable[[int, int, int], bool], 
                 options: dict = None):
        defaults = {
            'airDrag': 0.1,
            'fluidDrag': 0.4,
            'fluidDensity': 2.0,
            'gravity': [0, -10, 0],
            'minBounceImpulse': 0.5
        }
        if options:
            defaults.update(options)
        self.gravity = defaults['gravity']
        self.air_drag = defaults['airDrag']
        self.fluid_drag = defaults['fluidDrag']
        self.fluid_density = defaults['fluidDensity']
        self.min_bounce_impulse = defaults['minBounceImpulse']
        self.bodies: List[RigidBody] = []
        self.test_solid = test_solid
        self.test_fluid = test_fluid

    def add_body(self, aabb, mass=1, friction=1, restitution=0, grav_mult=1, on_collide=None):
        b = RigidBody(aabb, mass, friction, restitution, grav_mult, on_collide)
        self.bodies.append(b)
        return b

    def tick(self, dt_ms):
        dt = dt_ms / 1000.0
        no_gravity = (vec_squared_length(self.gravity) == 0)
        for b in self.bodies:
            self._iterate_body(b, dt, no_gravity)

    def _iterate_body(self, b, dt, no_gravity):
        old_resting = list(b.resting)
        if b.mass <= 0:
            vec_set(b.velocity, 0, 0, 0)
            vec_set(b._forces, 0, 0, 0)
            vec_set(b._impulses, 0, 0, 0)
            return
        if self._body_asleep(b, dt, no_gravity):
            return
        b._sleep_frame_count -= 1
        self._apply_fluid_forces(b)
        a = vec_scale(b._forces, 1.0 / b.mass)
        vec_scale_and_add(a, a, self.gravity, b.gravity_multiplier)
        dv = vec_scale(b._impulses, 1.0 / b.mass)
        vec_scale_and_add(dv, dv, a, dt)
        b.velocity = vec_add(b.velocity, dv)
        if b.friction:
            self._apply_friction_by_axis(0, b, dv)
            self._apply_friction_by_axis(1, b, dv)
            self._apply_friction_by_axis(2, b, dv)
        drag = b.air_drag if b.air_drag >= 0 else self.air_drag
        if b.in_fluid:
            drag = b.fluid_drag if b.fluid_drag >= 0 else self.fluid_drag
            drag *= (1 - b.ratio_in_fluid) ** 2
        mult = max(1 - (drag * dt / b.mass), 0)
        b.velocity = vec_scale(b.velocity, mult)
        dx = vec_scale(b.velocity, dt)
        vec_set(b._forces, 0, 0, 0)
        vec_set(b._impulses, 0, 0, 0)
        tmp_box = None
        if b.auto_step:
            tmp_box = AABB(list(b.aabb.base), list(b.aabb.vec))
        self._process_collisions(b, dx)
        if b.auto_step:
            self._try_auto_stepping(b, tmp_box, dx)
        impacts = [0.0, 0.0, 0.0]
        for i in range(3):
            if b.resting[i] != 0:
                if old_resting[i] == 0:
                    impacts[i] = -b.velocity[i]
                b.velocity[i] = 0.0
        mag = vec_length(impacts)
        if mag > 0.001:
            if b.restitution > 0 and mag > self.min_bounce_impulse:
                bounce_impulse = vec_scale(impacts, b.restitution)
                b.apply_impulse(bounce_impulse)
            if b.on_collide:
                b.on_collide(impacts)
        if vec_squared_length(b.velocity) > 1e-5:
            b._sleep_frame_count = 0

    def _body_asleep(self, b, dt, no_gravity):
        if vec_squared_length(b.velocity) <= 1e-5 and b._sleep_frame_count <= 0:
            return True
        return False

    def _apply_fluid_forces(self, b):
        x0, y0, z0 = b.aabb.base
        if not self.test_fluid(x0, y0, z0):
            b.in_fluid = False
            return
        submerged = 0
        y1 = y0 + b.aabb.vec[1]
        for y in range(int(y0), int(y1)):
            if self.test_fluid(x0, y, z0):
                submerged += 1
        fluid_level = y0 + submerged
        height_in_fluid = fluid_level - b.aabb.base[1]
        ratio_in_fluid = height_in_fluid / b.aabb.vec[1]
        if ratio_in_fluid > 1.0:
            ratio_in_fluid = 1.0
        vol = b.aabb.vec[0] * b.aabb.vec[1] * b.aabb.vec[2]
        displaced = vol * ratio_in_fluid
        f = vec_scale(self.gravity, -self.fluid_density * displaced)
        b.apply_force(f)
        b.in_fluid = True
        b.ratio_in_fluid = ratio_in_fluid

    def _apply_friction_by_axis(self, axis, b, dvel):
        rest_dir = b.resting[axis]
        v_normal = dvel[axis]
        if rest_dir == 0:
            return
        if rest_dir * v_normal <= 0:
            return
        lateral_vel = list(b.velocity)
        lateral_vel[axis] = 0
        v_curr = vec_length(lateral_vel)
        if v_curr == 0:
            return
        dv_max = abs(b.friction * v_normal)
        scaler = (v_curr - dv_max) / v_curr if v_curr > dv_max else 0
        b.velocity[(axis + 1) % 3] *= scaler
        b.velocity[(axis + 2) % 3] *= scaler

    def _process_collisions(self, b, dx):
        # Implements sweep(testSolid, box, velocity, callback) behavior from evidence
        # Callback sets resting[axis] = dir and zeros dx[axis]
        step = 0.05
        remaining = vec_length(dx)
        direction = vec_scale(dx, 1.0 / remaining) if remaining > 0 else [0,0,0]
        current_pos = list(b.aabb.base)
        while remaining > 0.001:
            test_pos = [current_pos[i] + direction[i] * step for i in range(3)]
            if self.test_solid(int(test_pos[0]), int(test_pos[1]), int(test_pos[2])):
                for i in range(3):
                    if abs(direction[i]) > 0.1:
                        b.resting[i] = 1 if direction[i] > 0 else -1
                        dx[i] = 0
                return
            current_pos = test_pos
            remaining -= step

## Operating characteristics
*   **Time Complexity**: $O(N \cdot K)$ per tick, where $N$ is the number of bodies and $K$ is the number of voxels checked during collision sweeps and fluid queries [S1, unofficial]. Fluid queries require scanning the height of the body, so $K$ scales with body size [S1, unofficial].
*   **Memory Complexity**: $O(N)$ for body data structures [S1, unofficial]. No spatial acceleration structure is maintained by the engine itself; it relies on the caller's voxel storage [S1, unofficial].
*   **Strengths**: Lightweight, no pre-processing required, handles fluid dynamics (buoyancy/drag) natively, supports auto-stepping for platformer mechanics [S1, unofficial].
*   **Limitations**: Does not handle rigid body-to-rigid body collisions [S1, unofficial]. Does not support non-cubic voxels [S1, unofficial]. Performance degrades with large bodies due to voxel counting for buoyancy [S1, unofficial].
*   **When to Use**: Voxel-based games (Minecraft-like) where terrain is the primary collision surface and rigid body interactions are minimal [S1, unofficial].
*   **When Not to Use**: Games requiring complex rigid body collisions (e.g., ragdolls hitting each other), non-cubic terrain, or high-precision continuous collision detection beyond AABB sweeps [S1, unofficial].

## Background
The Voxel Physics Engine was developed as a replacement for `voxel-physical` to provide more physically accurate behavior for voxel games [S1, unofficial]. It was designed to work with the `noa` engine and `voxel.js`, but is abstracted to work with any engine providing boolean voxel test functions [S1, unofficial]. The library has undergone several versions, with significant changes in version 0.8.0 (friction scaling) and 0.9.0 (drag renaming and per-body overrides) [S1, unofficial].
