# Sphere-Voxel Collision Detection via Displacement Averaging

Also called: sphereIntersect

## Overview
A collision detection method for a sphere moving through a voxel grid that calculates a displacement vector representing the push-out needed to resolve penetration by averaging displacements from all intersected voxel faces [S1, unofficial]. It differs from simple boolean occupancy tests by providing a continuous resolution vector, allowing the sphere to be pushed out of the voxel structure rather than merely detecting overlap [S1, unofficial].

## How it works
**Inputs:**
- `sphere`: A sphere defined by a center point (`Vector3`) and a radius (`float`) [S1, unofficial].
- `voxelmapCollider`: An object providing access to voxel data, specifically `getVoxel(voxel)` which returns an `EVoxelStatus` enum (e.g., `EMPTY`, `FULL`) [S1, unofficial].

**Outputs:**
- `null` if no collision is detected [S1, unofficial].
- An object `{ normal: Vector3, depth: float }` where `normal` is the unit vector of the average displacement and `depth` is the magnitude of that average displacement [S1, unofficial].

**Data Structures:**
- `displacements`: An array of `Vector3` objects storing individual face push-out vectors [S1, unofficial].
- `voxel`: A `Vector3` representing integer voxel coordinates `(x, y, z)` [S1, unofficial].
- `sphereCenterProjection2dX/Y/Z`: Objects with `x` and `y` fields representing 2D projections of the sphere center onto specific voxel faces [S1, unofficial].

**Algorithm Steps:**

1. Initialize an empty list `displacements` [S1, unofficial].
2. Define a helper function `addDisplacementIfNeeded(sphereCenterProjection)`:
   a. Calculate `projectionToCenter = sphere.center - sphereCenterProjection` [S1, unofficial].
   b. Calculate `distanceFromCenter = projectionToCenter.length()` [S1, unofficial].
   c. If `distanceFromCenter < sphere.radius`:
      i. Calculate `pushVector = projectionToCenter.normalize() * (sphere.radius - distanceFromCenter)` [S1, unofficial].
      ii. Push `pushVector` to `displacements` [S1, unofficial].
3. Calculate the bounding voxel coordinates containing the sphere:
   a. `voxelFrom = floor(sphere.center - sphere.radius)` [S1, unofficial].
   b. `voxelTo = floor(sphere.center + sphere.radius)` [S1, unofficial].
4. Iterate through all voxels in the bounding box:
   a. For `voxel.z` from `voxelFrom.z` to `voxelTo.z`:
   b.   For `voxel.y` from `voxelFrom.y` to `voxelTo.y`:
   c.     For `voxel.x` from `voxelFrom.x` to `voxelTo.x`:
      i. Calculate local sphere center relative to voxel: `localSphereCenter = sphere.center - voxel` [S1, unofficial].
      ii. Calculate 2D projections of the local sphere center onto the voxel faces:
          - `sphereCenterLocalProjection2dX` (using z, y components) [S1, unofficial].
          - `sphereCenterLocalProjection2dY` (using x, z components) [S1, unofficial].
          - `sphereCenterLocalProjection2dZ` (using x, y components) [S1, unofficial].
      iii. Calculate global 2D projection coordinates for each face by adding voxel indices:
          - `sphereCenterProjection2dX = { x: sphereCenterLocalProjection2dX.x + voxel.z, y: sphereCenterLocalProjection2dX.y + voxel.y }` [S1, unofficial].
          - `sphereCenterProjection2dY = { x: sphereCenterLocalProjection2dY.x + voxel.x, y: sphereCenterLocalProjection2dY.y + voxel.z }` [S1, unofficial].
          - `sphereCenterProjection2dZ = { x: sphereCenterLocalProjection2dZ.x + voxel.x, y: sphereCenterLocalProjection2dZ.y + voxel.y }` [S1, unofficial].
      iv. Check if current voxel is full: `voxelIsFull = (voxelmapCollider.getVoxel(voxel) != EVoxelStatus.EMPTY)` [S1, unofficial].
      v. Check neighbors for fullness:
          - `voxelBelowIsFull`: status of `(voxel.x, voxel.y - 1, voxel.z)` [S1, unofficial].
          - `voxelAboveIsFull`: status of `(voxel.x, voxel.y + 1, voxel.z)` [S1, unofficial].
          - `voxelLeftIsFull`: status of `(voxel.x - 1, voxel.y, voxel.z)` [S1, unofficial].
          - `voxelRightIsFull`: status of `(voxel.x + 1, voxel.y, voxel.z)` [S1, unofficial].
          - `voxelBackIsFull`: status of `(voxel.x, voxel.y, voxel.z - 1)` [S1, unofficial].
          - `voxelFrontIsFull`: status of `(voxel.x, voxel.y, voxel.z + 1)` [S1, unofficial].
      vi. If `voxelIsFull != voxelBelowIsFull`, call `addDisplacementIfNeeded({ x: sphereCenterProjection2dY.x, y: voxel.y, z: sphereCenterProjection2dY.y })` [S1, unofficial].
      vii. If `voxelIsFull != voxelAboveIsFull`, call `addDisplacementIfNeeded({ x: sphereCenterProjection2dY.x, y: voxel.y + 1, z: sphereCenterProjection2dY.y })` [S1, unofficial].
      viii. If `voxelIsFull != voxelLeftIsFull`, call `addDisplacementIfNeeded({ x: voxel.x, y: sphereCenterProjection2dX.y, z: sphereCenterProjection2dX.x })` [S1, unofficial].
      ix. If `voxelIsFull != voxelRightIsFull`, call `addDisplacementIfNeeded({ x: voxel.x + 1, y: sphereCenterProjection2dX.y, z: sphereCenterProjection2dX.x })` [S1, unofficial].
      x. If `voxelIsFull != voxelBackIsFull`, call `addDisplacementIfNeeded({ x: sphereCenterProjection2dZ.x, y: sphereCenterProjection2dZ.y, z: voxel.z })` [S1, unofficial].
      xi. If `voxelIsFull != voxelFrontIsFull`, call `addDisplacementIfNeeded({ x: sphereCenterProjection2dZ.x, y: sphereCenterProjection2dZ.y, z: voxel.z + 1 })` [S1, unofficial].
5. After loops, if `displacements.length > 0`:
   a. Sum all displacements into `totalDisplacement` [S1, unofficial].
   b. Calculate `averageDisplacement = totalDisplacement / displacements.length` [S1, unofficial].
   c. Calculate `totalDepth = averageDisplacement.length()` [S1, unofficial].
   d. Return `{ normal: averageDisplacement.normalize(), depth: totalDepth }` [S1, unofficial].
6. If `displacements.length` is 0, return `null` [S1, unofficial].

**Pseudocode:**

```python
def sphere_voxel_collision(sphere, voxelmap_collider):
    """
    sphere: dict with 'center' (Vec3) and 'radius' (float)
    voxelmap_collider: object with get_voxel(voxel: Vec3) -> EVoxelStatus
    Returns: dict with 'normal' (Vec3) and 'depth' (float), or None
    """
    displacements = []

    def add_displacement_if_needed(sphere_center_projection):
        projection_to_center = sphere['center'] - sphere_center_projection
        distance_from_center = projection_to_center.length()
        if distance_from_center < sphere['radius']:
            push_vector = projection_to_center.normalize() * (sphere['radius'] - distance_from_center)
            displacements.append(push_vector)

    voxel_from = floor_vec3(sphere['center'] - sphere['radius'])
    voxel_to = floor_vec3(sphere['center'] + sphere['radius'])

    for z in range(voxel_from.z, voxel_to.z + 1):
        for y in range(voxel_from.y, voxel_to.y + 1):
            for x in range(voxel_from.x, voxel_to.x + 1):
                voxel = Vec3(x, y, z)
                local_sphere_center = sphere['center'] - voxel

                # 2D projections of local sphere center onto voxel faces
                proj_x = Vec3(local_sphere_center.z, local_sphere_center.y, 0)
                proj_y = Vec3(local_sphere_center.x, 0, local_sphere_center.z)
                proj_z = Vec3(local_sphere_center.x, local_sphere_center.y, 0)

                # Global 2D projection coordinates for each face
                sphere_center_proj_2d_x = Vec3(proj_x.x + z, proj_x.y + y, 0)
                sphere_center_proj_2d_y = Vec3(proj_y.x + x, 0, proj_y.y + z)
                sphere_center_proj_2d_z = Vec3(proj_z.x + x, proj_z.y + y, 0)

                voxel_is_full = voxelmap_collider.get_voxel(voxel) != EVoxelStatus.EMPTY
                voxel_below_is_full = voxelmap_collider.get_voxel(Vec3(x, y - 1, z)) != EVoxelStatus.EMPTY
                voxel_above_is_full = voxelmap_collider.get_voxel(Vec3(x, y + 1, z)) != EVoxelStatus.EMPTY
                voxel_left_is_full = voxelmap_collider.get_voxel(Vec3(x - 1, y, z)) != EVoxelStatus.EMPTY
                voxel_right_is_full = voxelmap_collider.get_voxel(Vec3(x + 1, y, z)) != EVoxelStatus.EMPTY
                voxel_back_is_full = voxelmap_collider.get_voxel(Vec3(x, y, z - 1)) != EVoxelStatus.EMPTY
                voxel_front_is_full = voxelmap_collider.get_voxel(Vec3(x, y, z + 1)) != EVoxelStatus.EMPTY

                if voxel_is_full != voxel_below_is_full:
                    add_displacement_if_needed(Vec3(sphere_center_proj_2d_y.x, y, sphere_center_proj_2d_y.y))
                if voxel_is_full != voxel_above_is_full:
                    add_displacement_if_needed(Vec3(sphere_center_proj_2d_y.x, y + 1, sphere_center_proj_2d_y.y))
                if voxel_is_full != voxel_left_is_full:
                    add_displacement_if_needed(Vec3(x, sphere_center_proj_2d_x.y, sphere_center_proj_2d_x.x))
                if voxel_is_full != voxel_right_is_full:
                    add_displacement_if_needed(Vec3(x + 1, sphere_center_proj_2d_x.y, sphere_center_proj_2d_x.x))
                if voxel_is_full != voxel_back_is_full:
                    add_displacement_if_needed(Vec3(sphere_center_proj_2d_z.x, sphere_center_proj_2d_z.y, z))
                if voxel_is_full != voxel_front_is_full:
                    add_displacement_if_needed(Vec3(sphere_center_proj_2d_z.x, sphere_center_proj_2d_z.y, z + 1))

    if len(displacements) > 0:
        total_displacement = sum(displacements)
        average_displacement = total_displacement / len(displacements)
        total_depth = average_displacement.length()
        return {'normal': average_displacement.normalize(), 'depth': total_depth}
    return None
```

**Parameters:**
- `sphere.radius`: The radius of the sphere. Typical values depend on the scene scale.
- `voxelmapCollider.chunkSize`: Dimensions of the voxel chunks. Not given in the sources.
- `voxelmapCollider.voxelsChunkOrdering`: String defining the memory layout of voxels within a chunk. Not given in the sources.

**Edge Cases and Pitfalls:**
- If `displacements` is empty, the function returns `null`, indicating no collision [S1, unofficial].
- Precision issues may arise if `distanceFromCenter` is very close to `sphere.radius` [G].
- The algorithm assumes `floor` is applied to the bounding box calculation [G].
- The algorithm assumes `normalize` handles zero-length vectors gracefully or that they do not occur [G].

## Operating characteristics
- **Time Complexity:** Proportional to the number of voxels in the sphere's bounding box, which is $O(r^3)$ where $r$ is the sphere radius in voxel units [G].
- **Memory Complexity:** Proportional to the number of intersected faces, which is $O(r^2)$ [G].
- **Measured Performance:** Not given in the sources.
- **Scaling:** Performance scales with the cube of the sphere radius [G].
- **Strengths:** Provides a continuous displacement vector for collision resolution, allowing for smooth movement and penetration recovery [S1, unofficial].
- **Limitations:** Requires checking multiple neighbors for each voxel in the bounding box, which can be computationally expensive for large spheres or dense voxel grids [G].
- **When to use:** When continuous collision resolution is needed for spheres in a voxel environment [S1, unofficial].
- **When not to use:** When only boolean collision detection is required, or when performance is critical and the sphere is very large [G].
