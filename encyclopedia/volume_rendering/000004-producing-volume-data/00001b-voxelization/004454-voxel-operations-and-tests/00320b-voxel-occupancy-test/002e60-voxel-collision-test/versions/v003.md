# Voxel Collision Test

Also called: Grid Check, Voxel Column Collision, vertical column check

## Overview
A method to determine if a vertical column of voxels at a specific world XZ position contains any solid geometry between two world Y heights ($slab_{lo}$ and $slab_{hi}$) [S2, unofficial]. It solves the problem of collision detection in voxel-based environments, specifically allowing entities to walk through carved-out holes or gaps in terrain [S2, unofficial]. Unlike general point-in-voxel tests which check a single coordinate, this method iterates along the Y-axis to detect occupancy within a vertical slab [S2, unofficial].

## How it works
**Inputs:**
- World XZ position ($P_{xz}$): A 2D vector $(x, z)$ representing the horizontal location of the query [S2, unofficial].
- Slab bounds ($slab_{lo}, slab_{hi}$): World Y coordinates defining the vertical range to check [S2, unofficial].
- Grid parameters:
  - $origin$: World position of the voxel grid origin $(o_x, o_y, o_z)$ [S2, unofficial].
  - $vox\_size$: Side length of a single voxel [S2, unofficial].
  - $grid\_dim$: Dimension of the cubic grid (assumed uniform in X, Y, Z) [S2, unofficial].
  - $half\_grid$: Offset constant used in coordinate conversion [S2, unofficial].
  - $rotation\_inv$: Inverse rotation matrix transforming world space to local grid space [S2, unofficial].
- Voxel data: A 3D array or hash map indicating solid/empty status [G].

**Outputs:**
- Boolean: `true` if any voxel in the column is solid; `false` otherwise [S2, unofficial].

**Steps:**
1. **Coordinate Transformation:** Convert the world XZ position to local grid coordinates [S2, unofficial].
   - Construct a temporary 3D vector $p = (P_{xz}.x, 0.0, P_{xz}.y)$.
   - Apply inverse rotation and translation to get local position $local$:
     $$ local = R^{-1} \cdot (p - origin) $$
     Where $R^{-1}$ is the inverse rotation matrix [S2, unofficial].
2. **Calculate Local X and Z:**
   - Compute floating-point local coordinates:
     $$ lx\_f = \frac{local.x + half\_grid}{vox\_size} $$
     $$ lz\_f = \frac{local.z + half\_grid}{vox\_size} $$
   - Convert to integer grid indices:
     $$ lx = \lfloor lx\_f \rfloor $$
     $$ lz = \lfloor lz\_f \rfloor $$
3. **Boundary Check (XZ):**
   - If $lx < 0$ or $lx \ge grid\_dim$ or $lz < 0$ or $lz \ge grid\_dim$, return `false` [S2, unofficial].
4. **Calculate Local Y Bounds:**
   - Convert world slab bounds to local floating-point Y indices:
     $$ ly\_lo\_f = \frac{slab\_lo - origin.y + half\_grid}{vox\_size} $$
     $$ ly\_hi\_f = \frac{slab\_hi - origin.y + half\_grid}{vox\_size} $$
5. **Clamp and Convert Y Indices:**
   - Determine the range of integer Y indices to check:
     $$ ly\_lo = \max(0, \lfloor ly\_lo\_f \rfloor) $$
     $$ ly\_hi = \min(grid\_dim - 1, \lceil ly\_hi\_f \rceil) $$
     The source implementation uses `.floor().max(0.0)` for the lower bound and `.ceil().min(...)` for the upper bound, casting to unsigned integers [S2, unofficial].
6. **Iterate and Test:**
   - For $y$ from $ly\_lo$ to $ly\_hi$ inclusive:
     - If the voxel at $(lx, y, lz)$ is solid, return `true` [S2, unofficial].
   - If the loop completes without finding a solid voxel, return `false` [S2, unofficial].

**Pseudocode:**
```python
import math

def voxel_collision_test(world_x, world_z, slab_lo, slab_hi, grid, origin, vox_size, grid_dim, half_grid, rotation_inv):
    # 1. Transform world XZ to local
    p_x, p_z = world_x, world_z
    dx, dz = p_x - origin.x, p_z - origin.z
    # Apply inverse rotation and translation [S2, unofficial]
    local_x = rotation_inv[0][0] * dx + rotation_inv[0][2] * dz
    local_z = rotation_inv[2][0] * dx + rotation_inv[2][2] * dz

    # 2. Calculate local X and Z grid coordinates
    lx_f = (local_x + half_grid) / vox_size
    lz_f = (local_z + half_grid) / vox_size
    lx = math.floor(lx_f)
    lz = math.floor(lz_f)

    # 3. Boundary check
    if lx < 0 or lx >= grid_dim or lz < 0 or lz >= grid_dim:
        return False

    # 4. Convert slab Y range to local grid Y indices
    ly_lo_f = (slab_lo - origin.y + half_grid) / vox_size
    ly_hi_f = (slab_hi - origin.y + half_grid) / vox_size

    # 5. Clamp Y indices
    ly_lo = max(0, math.floor(ly_lo_f))
    ly_hi = min(grid_dim - 1, math.ceil(ly_hi_f))

    # 6. Iterate
    for y in range(ly_lo, ly_hi + 1):
        if grid[lx][y][lz]:
            return True

    return False
```

**Edge Cases and Pitfalls:**
- **Out of Bounds:** If the query XZ is outside the grid, the method must return `false` rather than crashing [S2, unofficial].
- **Degenerate Slab:** If $slab_{lo} > slab_{hi}$, the loop range is empty, correctly returning `false` [G].
- **Precision:** Floating-point errors in coordinate transformation may cause off-by-one errors at boundaries; using epsilon for comparisons or robust floor/ceil logic is recommended [G].

## Subtopics

### Solid Voxel Particle Physics
A variant used for GPU particle systems where collisions are detected against a solid voxelization that includes normal vectors [S3, unofficial].
- **Definition:** Detects collisions and makes particles bounce based on solid voxelization with normals, treating concave regions and dynamic deformation [S3, unofficial].
- **Method:** Recomputes density and normals at every frame to allow dynamic deformation. Normals are evaluated only when a particle enters in contact with a surface [S3, unofficial].
- **Comparison:** Provides uniform quality in all directions compared to depth peeling (which has resolution/hole issues) or clipping planes (restricted z-axis info). Allows consistent back integration and can be combined with movement extraction steps [S3, unofficial].

## Operating characteristics
- **Time Complexity:** $O(N_y)$, where $N_y = ly\_hi - ly\_lo + 1$ is the number of voxels in the vertical column between $slab_{lo}$ and $slab_{hi}$ [S2, unofficial]. In the worst case, this is $O(grid\_dim)$ [S2, unofficial].
- **Memory Complexity:** $O(1)$ auxiliary space, assuming the grid is accessed directly [G].
- **Performance:** Extremely fast for sparse checks or small slabs. The bottleneck in particle systems is often the rendering (billboards) rather than the simulation query [S3, unofficial].
- **Strengths:** Simple to implement; handles concave geometry and holes naturally; supports dynamic deformation if normals are recomputed [S2, unofficial][S3, unofficial].
- **Limitations:** Only checks vertical columns; does not handle diagonal collisions or general AABB/SSA collisions without extension [S2, unofficial].

## Background
Collision detection in voxel games often extends naturally from 2D cases [S1, unofficial]. The "simple grid check" is a foundational technique in voxel engines like noa, where it is used alongside custom physics implementations [S1, unofficial]. More advanced applications, such as GPU particle physics, utilize solid voxelization with normals to handle complex concave shapes and dynamic deformation, offering advantages over traditional depth-peeling or clipping-plane methods [S3, unofficial].
