### Background Thresholding via K-Means
Fits two intensity populations on a bounded, seeded sample of nonzero data to determine a background threshold [S2, unofficial]. The algorithm extracts nonzero values (`values = volume[volume > 0]`) and returns 0.0 if empty [S2, unofficial]. It creates a seeded random number generator (`rng = np.random.default_rng(seed)`) and samples up to 10,000 values without replacement (`sample = values[rng.choice(values.size, min(10000, values.size), replace=False)]`) [S2, unofficial]. If the unique sample size is less than 2, it returns 0.0 to preserve constant-valued foreground [S2, unofficial]. It fits a K-Means model with 2 clusters, 3 initializations, and the given seed (`model = KMeans(n_clusters=2, n_init=3, random_state=seed).fit(sample[:, None])`) [S2, unofficial]. Finally, it returns the minimum cluster center rounded to 6 decimal places (`round(float(model.cluster_centers_.min()), 6)`) [S2, unofficial].
