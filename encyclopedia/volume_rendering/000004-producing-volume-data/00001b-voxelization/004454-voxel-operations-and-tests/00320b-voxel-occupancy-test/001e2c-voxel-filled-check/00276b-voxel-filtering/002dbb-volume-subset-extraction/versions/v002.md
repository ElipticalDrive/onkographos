# Volume Subset Extraction
## Overview
Volume Subset Extraction selects voxels from a 3D volume dataset that satisfy a user-defined threshold applied to a transfer function evaluated on the voxel's gradient and density [S1, unofficial]. It stores the selected voxels in a 2D array of splat rows to enable traversal in back-to-front or front-to-back order without storing empty voxels [S1, unofficial].
## How it works
**Inputs:**
*   3D volume dataset with voxel density $p$ and gradient $V$ [S1, unofficial].
*   Transfer function $F(V, p)$ [S1, unofficial].
*   Threshold $\tau$ [S1, unofficial].

**Outputs:**
*   A 2D array of splat rows, where each row contains extracted voxels [S1, unofficial].

**Data Structures:**
*   **Voxel:** Stores location (3D coordinates) and normal vector (3D components) [S1, unofficial].
*   **Splat Row:** An array of voxels, where rows may contain different numbers of voxels [S1, unofficial].

**Steps:**
1.  Traverse the data structure in back-to-front or front-to-back order [S1, unofficial].
2.  For each voxel, evaluate the transfer function $t = F(V, p)$, where $V$ is the gradient and $p$ is the density [S1, unofficial].
3.  If $t$ exceeds $\tau$, include the voxel in the subset [S1, unofficial].
4.  Store the voxel's location and normal vector in the current splat row [S1, unofficial].

**Pseudocode:**
```python
def extract_volume_subset(volume, transfer_function, threshold):
    """
    Extracts a subset of voxels based on a transfer function threshold.
    
    Args:
        volume: 3D array of voxels, each having 'density', 'gradient', and 'normal' attributes.
        transfer_function: Function F(V, p) returning a scalar value.
        threshold: Float threshold tau.
        
    Returns:
        list of lists: 2D array of splat rows, where each row is a list of voxel dicts.
    """
    splat_rows = []
    
    # Traverse in back-to-front or front-to-back order [S1, unofficial]
    for z in reversed(range(volume.depth)):
        for y in reversed(range(volume.height)):
            for x in reversed(range(volume.width)):
                voxel = volume[z][y][x]
                
                # Evaluate transfer function
                t = transfer_function(voxel.gradient, voxel.density)
                
                # Check threshold
                if t > threshold:
                    # Create voxel record with location and normal
                    voxel_record = {
                        'location': (x, y, z),
                        'normal': voxel.normal
                    }
                    
                    # Row assignment scheme is not specified in the sources [G]
                    row_index = z
                    if row_index >= len(splat_rows):
                        splat_rows.append([])
                    splat_rows[row_index].append(voxel_record)
                    
    return splat_rows
```

**Parameters:**
*   $\tau$: User-defined threshold [S1, unofficial].

**Edge Cases:**
*   **Empty Voxels:** Not stored, reducing memory usage [S1, unofficial].
*   **Variable Row Lengths:** Rows may contain different numbers of voxels [S1, unofficial].
*   **Traversal Order:** The data structure supports traversal in either back-to-front or front-to-back order [S1, unofficial].

*   **Strengths:** Reduces data size by not storing empty voxels [S1, unofficial].
*   **Limitations:** Requires storing location and normal vector for each extracted voxel [S1, unofficial].
