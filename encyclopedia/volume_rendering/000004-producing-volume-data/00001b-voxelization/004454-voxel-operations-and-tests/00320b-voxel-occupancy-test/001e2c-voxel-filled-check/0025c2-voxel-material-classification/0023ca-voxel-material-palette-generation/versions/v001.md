# Voxel Material Palette Generation


## Overview
This method generates a compact lookup table (palette) that maps discrete voxel values (1–255) to physically-based rendering (PBR) material definitions for each of the six voxel faces. It solves the problem of efficiently storing and accessing per-face material properties (opacity, color, emission, normal, and RSMA maps) by packing material layer indices and flags into a single 2D texture atlas and a corresponding 3D palette array. It differs from per-voxel material instances by batching materials into atlases, thereby reducing memory overhead and draw calls [S1, unofficial].

## How it works
**Inputs:**
- `materials`: A dictionary mapping string voxel values ("1" to "255") to a list of 6 material names (one per face: +X, -X, +Y, -Y, +Z, -Z).
- `material_definitions`: A source (e.g., JSON) providing PBR texture paths and boolean flags (`is_opaque`, `has_color`, etc.) for each material name.
- `atlas_width`, `atlas_height`: Dimensions of the output texture atlas in pixels.
- `res`: Resolution of each material tile in the atlas. Typical value: 512 [S1, unofficial].

**Outputs:**
- `palette`: A 3D NumPy array of shape `(256, 6, 3)` with type `np.uint8`.
- `color_atlas`, `emission_atlas`, `normal_atlas`, `rsma_atlas`: 2D texture arrays containing the packed material channels.

**Data Structures:**
1.  **Palette Texture**: Shape `(256, 6, 3)`. Each entry `[voxel, face]` contains:
    -   Index 0: `layer & 255` (lower 8 bits of the material index).
    -   Index 1: `layer >> 8` (upper 8 bits of the material index).
    -   Index 2: `flag` (bitmask of material properties).
2.  **Material Flags Bitmask**:
    -   Bit 0: `IS_OPAQUE`
    -   Bit 1: `HAS_COLOR`
    -   Bit 2: `HAS_EMISSION`
    -   Bit 3: `HAS_NORMAL`
    -   Bit 4: `HAS_RSMA`
3.  **Material Channels**:
    -   `color`: RGBA texture.
    -   `emission`: RGB texture.
    -   `normal`: RGB texture (derived from RG source).
    -   `rsma`: RGBA texture (R=roughness, G=specular, B=metallic, A=ambient occlusion).

**Algorithm Steps:**

1.  **Load and Sort Materials**:
    -   Parse material definitions to extract unique material names.
    -   Sort unique names alphabetically to create a deterministic index `i` for each name.
    -   Calculate atlas grid dimensions:
        $$ cols = \lfloor atlas\_width / res \rfloor $$
        $$ rows = \lfloor atlas\_height / res \rfloor $$

2.  **Build Atlas and Lookup Tables**:
    -   Initialize empty atlas textures for `color`, `emission`, `normal`, and `rsma` with dimensions `(rows * res, cols * res)`.
    -   For each unique material name `name` at index `i`:
        -   Calculate grid position:
            $$ col = i \pmod{cols} $$
            $$ row = \lfloor i / cols \rfloor $$
        -   Calculate pixel coordinates:
            $$ x = col \times res $$
            $$ y = row \times res $$
        -   Extract sub-region `[y:y+res, x:x+res]` from each atlas.
        -   Load the material's PBR channels. If a channel is missing, fill it with a default value (e.g., `self.red_x` for color) [S1, unofficial].
        -   Store the loaded textures in lists `self.color_textures`, etc.
        -   Record the layer index: `layers[name] = i`.
        -   Compute the flag bitmask:
            $$ flag = (IS\_OPAQUE \text{ if } is\_opaque \text{ else } 0) \ | \ (HAS\_COLOR \text{ if } has\_color \text{ else } 0) \ | \ (HAS\_EMISSION \text{ if } has\_emission \text{ else } 0) \ | \ (HAS\_NORMAL \text{ if } has\_normal \text{ else } 0) \ | \ (HAS\_RSMA \text{ if } has\_rsma \text{ else } 0) $$
        -   Record flags: `flags[name] = flag`.

3.  **Fill Palette**:
    -   Initialize `palette` array of shape `(256, 6, 3)` with zeros.
    -   For each voxel value `v` (1 to 255):
        -   Get the list of 6 material names for the faces.
        -   If the list length is 1, replicate it to 6 faces: `names *= 6`.
        -   If the list length is not 6, raise an error.
        -   For each face `f` (0 to 5):
            -   Get `name = names[f]`.
            -   Lookup `layer = layers[name]` and `flag = flags[name]`.
            -   Set `palette[v, f] = [layer & 255, layer >> 8, flag]`.

4.  **Verify Palette**:
    -   Check for mixed opaque/transparent sides on a single voxel.
    -   Count opaque flags per voxel: `opaque_counts = sum(flag & 1 for face in palette[v])`.
    -   If `0 < opaque_counts < 6` for any voxel, raise an error. Mixed opacity on a single voxel is invalid [S1, unofficial].

5.  **Write Outputs**:
    -   Save `palette` as a PNG texture.
    -   Save `color_atlas`, `emission_atlas`, `normal_atlas`, and `rsma_atlas` as PNG textures.

**Pseudocode:**

```python
import numpy as np

def generate_voxel_palette(materials, material_defs, atlas_width, atlas_height, res=512):
    # 1. Load and Sort Materials
    all_names = set()
    for face_names in materials.values():
        all_names.update(face_names)
    names = sorted(list(all_names))
    name_to_index = {name: i for i, name in enumerate(names)}
    
    count = len(names)
    cols = atlas_width // res
    rows = atlas_height // res
    
    # Initialize atlases
    color_atlas = np.zeros((rows * res, cols * res, 4), dtype=np.uint8)
    emission_atlas = np.zeros((rows * res, cols * res, 3), dtype=np.uint8)
    normal_atlas = np.zeros((rows * res, cols * res, 3), dtype=np.uint8)
    rsma_atlas = np.zeros((rows * res, cols * res, 4), dtype=np.uint8)
    
    layers = {}
    flags = {}
    
    # 2. Build Atlas and Lookup Tables
    for i, name in enumerate(names):
        col = i % cols
        row = i // cols
        x = col * res
        y = row * res
        
        # Load material properties
        mat = material_defs[name]
        is_opaque = mat.get('is_opaque', True)
        has_color = mat.get('has_color', True)
        has_emission = mat.get('has_emission', False)
        has_normal = mat.get('has_normal', False)
        has_rsma = mat.get('has_rsma', False)
        
        # Load textures (placeholder for actual image loading logic)
        color = load_texture(mat['color_path'], res, default=255) # RGBA
        emission = load_texture(mat['emission_path'], res, default=0) # RGB
        normal = load_texture(mat['normal_path'], res, default=128) # RGB from RG
        rsma = load_texture(mat['rsma_path'], res, default=0) # RGBA
        
        # Store in atlas
        color_atlas[y:y+res, x:x+res] = color
        emission_atlas[y:y+res, x:x+res] = emission
        normal_atlas[y:y+res, x:x+res] = normal
        rsma_atlas[y:y+res, x:x+res] = rsma
        
        # Compute flags
        flag = 0
        if is_opaque: flag |= 1 # IS_OPAQUE
        if has_color: flag |= 2 # HAS_COLOR
        if has_emission: flag |= 4 # HAS_EMISSION
        if has_normal: flag |= 8 # HAS_NORMAL
        if has_rsma: flag |= 16 # HAS_RSMA
        
        layers[name] = i
        flags[name] = flag
        
    # 3. Fill Palette
    palette = np.zeros((256, 6, 3), dtype=np.uint8)
    
    for voxel_str, face_names in materials.items():
        voxel = int(voxel_str)
        if voxel < 1 or voxel > 255:
            raise ValueError(f"Invalid voxel value: {voxel}")
            
        if len(face_names) == 1:
            face_names = face_names * 6
        if len(face_names) != 6:
            raise ValueError(f"Invalid material names at voxel {voxel}: {face_names}")
            
        for f, name in enumerate(face_names):
            layer = layers[name]
            flag = flags[name]
            palette[voxel, f] = [layer & 255, layer >> 8, flag]
            
    # 4. Verify Palette
    opaque_counts = np.sum((palette[:, :, 2] & 1) > 0, axis=1, dtype=np.uint8)
    mixed = np.logical_and(opaque_counts > 0, opaque_counts < 6)
    if np.any(mixed):
        raise ValueError("ERROR: Palette contains voxels with mixed opaque/transparent sides.")
        
    return palette, color_atlas, emission_atlas, normal_atlas, rsma_atlas
```

**Edge Cases and Pitfalls:**
-   **Mixed Opacity**: A voxel cannot have both opaque and transparent faces. The system validates this and exits with an error if detected [S1, unofficial].
-   **Missing Channels**: If a material lacks a specific channel (e.g., no emission), it must be filled with a default value (e.g., black for emission, white for normal) to prevent atlas corruption [S1, unofficial].
-   **Voxel Value Range**: Only voxel values 1–255 are supported. Value 0 is typically reserved for air/empty space and is not processed in the palette generation loop [S1, unofficial].

## Operating characteristics
-   **Time Complexity**: $O(N \cdot R^2 + V \cdot F)$, where $N$ is the number of unique materials, $R$ is the resolution of each tile, $V$ is the number of voxel types (255), and $F$ is the number of faces (6). The dominant cost is loading and packing textures for $N$ materials.
-   **Memory Complexity**: $O(N \cdot R^2 + V \cdot F)$. The atlas size is $N \cdot R^2$ pixels per channel. The palette size is fixed at $256 \times 6 \times 3$ bytes.
-   **Performance**: Reduces memory overhead and draw calls by batching materials into atlases instead of using per-voxel material instances [S1, unofficial].
-   **Strengths**: Efficient storage for voxel worlds with many distinct materials; fast lookup during rendering.
-   **Limitations**: Fixed voxel value range (1–255); mixed opacity per voxel is not supported; atlas size grows linearly with the number of unique materials.

## Background
This method is part of the voxel material classification and storage system in the Godot Voxel plugin. It enables efficient PBR rendering for voxel-based games by mapping discrete voxel IDs to a shared set of material atlases.
