# Surrounding Voxel Neighbor Traversal

Also called: Multi-Grid Neighbor Check, SurroundingVoxelVisitor

## Overview
Surrounding Voxel Neighbor Traversal is a method for iterating over the 6 immediate spatial neighbors (West, East, Bottom, Top, North, South) of a specific voxel within a `VoxelGrid`. It solves the problem of boundary crossing in multi-grid volume representations by detecting when a neighbor lies outside the current grid's dimensions and redirecting the traversal to an adjacent `VoxelGrid` if one exists [S1, unofficial]. It is distinguished from simple intra-grid neighbor checks by its explicit handling of inter-grid connectivity via a visitor pattern, ensuring that surface detection or occupancy tests remain continuous across chunk boundaries [S1, unofficial].

## How it works
The method operates as a generic visitor that processes a single voxel identified by a flat index. It calculates the 3D coordinates of the voxel, determines the strides for movement in each axis, and then checks each of the 6 neighbors. If a neighbor is within the current grid, it is processed directly; if it is outside, the method checks for an adjacent grid in that direction and processes the corresponding boundary voxel in that neighbor grid.

### Inputs and Outputs
*   **Input**:
    *   `flatIndex`: The integer index of the current voxel in the current `VoxelGrid`.
    *   `voxels`: The `VoxelGrid` instance containing the current voxel.
    *   `checker`: An object implementing the `ISurroundingVoxelVisitor` interface.
    *   `NeighborGrids`: A map or array associating directions (West, East, Bottom, Top, North, South) with optional adjacent `VoxelGrid` instances.
*   **Output**:
    *   Side effects via `checker.Check()` and `checker.CheckBelow()` calls for each valid neighbor.

### Data Structures
*   **VoxelGrid**:
    *   `GridSize`: Integer representing the dimension size (assumed cubic, $N \times N \times N$).
    *   `AsCoordinate(int flatIndex)`: Converts a flat index to a 3D coordinate $(x, y, z)$.
    *   `AsFlatIndex(int x, int y, int z)`: Converts a 3D coordinate to a flat index.
*   **ISurroundingVoxelVisitor**:
    *   `Check(int flatIndex, VoxelGrid grid)`: Called for neighbors in positive X, positive Z, and positive Y directions (relative to the traversal logic, though Y is split).
    *   `CheckBelow(int flatIndex, VoxelGrid grid)`: Called specifically for the neighbor in the negative Y direction (Bottom).

### Strides and Coordinates
Let $N$ be `voxels.GridSize`. The strides for moving to adjacent voxels in the flat array are:
$$ xInc = 1 $$
$$ yInc = N $$
$$ zInc = N \times N $$

The current voxel's coordinates $(x, y, z)$ are derived from `flatIndex` using `voxels.AsCoordinate(flatIndex)`.

### Algorithm Steps
1.  **Initialize Strides**: Calculate $xInc=1$, $yInc=N$, $zInc=N^2$.
2.  **Convert Index**: Get $(x, y, z) = \text{voxels.AsCoordinate}(\text{flatIndex})$.
3.  **Check West Neighbor (X-1)**:
    *   If $x > 0$: Call `checker.Check(flatIndex - xInc, voxels)`.
    *   Else if `NeighborGrids[WEST]` exists: Let $otherGrid = \text{NeighborGrids[WEST]}$. Calculate the boundary index in the neighbor grid as $(N-1, y, z)$. Call `checker.Check(otherGrid.AsFlatIndex(N-1, y, z), otherGrid)`.
4.  **Check East Neighbor (X+1)**:
    *   If $x < N - 1$: Call `checker.Check(flatIndex + xInc, voxels)`.
    *   Else if `NeighborGrids[EAST]` exists: Let $otherGrid = \text{NeighborGrids[EAST]}$. Calculate the boundary index as $(0, y, z)$. Call `checker.Check(otherGrid.AsFlatIndex(0, y, z), otherGrid)`.
5.  **Check Bottom Neighbor (Y-1)**:
    *   If $y > 0$: Call `checker.CheckBelow(flatIndex - yInc, voxels)`.
    *   Else if `NeighborGrids[BOTTOM]` exists: Let $otherGrid = \text{NeighborGrids[BOTTOM]}$. Calculate the boundary index as $(x, N-1, z)$. Call `checker.CheckBelow(otherGrid.AsFlatIndex(x, N-1, z), otherGrid)`.
6.  **Check Top Neighbor (Y+1)**:
    *   If $y < N - 1$: Call `checker.Check(flatIndex + yInc, voxels)`.
    *   Else if `NeighborGrids[TOP]` exists: Let $otherGrid = \text{NeighborGrids[TOP]}$. Calculate the boundary index as $(x, 0, z)$. Call `checker.Check(otherGrid.AsFlatIndex(x, 0, z), otherGrid)`.
7.  **Check North Neighbor (Z-1)**:
    *   If $z > 0$: Call `checker.Check(flatIndex - zInc, voxels)`.
    *   Else if `NeighborGrids[NORTH]` exists: Let $otherGrid = \text{NeighborGrids[NORTH]}$. Calculate the boundary index as $(x, y, N-1)$. Call `checker.Check(otherGrid.AsFlatIndex(x, y, N-1), otherGrid)`.
8.  **Check South Neighbor (Z+1)**:
    *   If $z < N - 1$: Call `checker.Check(flatIndex + zInc, voxels)`.
    *   Else if `NeighborGrids[SOUTH]` exists: Let $otherGrid = \text{NeighborGrids[SOUTH]}$. Calculate the boundary index as $(x, y, 0)$. Call `checker.Check(otherGrid.AsFlatIndex(x, y, 0), otherGrid)`.

### Pseudocode
```python
def SurroundingVoxelNeighborTraversal(flatIndex, voxels, checker, NeighborGrids):
    """
    Iterates over the 6 neighbors of a voxel.
    :param flatIndex: int, flat index of the current voxel
    :param voxels: VoxelGrid, the current grid
    :param checker: ISurroundingVoxelVisitor, the visitor object
    :param NeighborGrids: dict, mapping Direction to optional VoxelGrid
    """
    N = voxels.GridSize
    
    # Calculate strides
    xInc = 1
    yInc = N
    zInc = N * N
    
    # Convert flat index to coordinates
    x, y, z = voxels.AsCoordinate(flatIndex)
    
    # 1. West Neighbor (X-1)
    if x > 0:
        checker.Check(flatIndex - xInc, voxels)
    elif NeighborGrids.get(Direction.WEST) is not None:
        otherGrid = NeighborGrids[Direction.WEST]
        # Boundary voxel in neighbor grid: x = N-1
        neighborFlatIndex = otherGrid.AsFlatIndex(N - 1, y, z)
        checker.Check(neighborFlatIndex, otherGrid)
        
    # 2. East Neighbor (X+1)
    if x < N - 1:
        checker.Check(flatIndex + xInc, voxels)
    elif NeighborGrids.get(Direction.EAST) is not None:
        otherGrid = NeighborGrids[Direction.EAST]
        # Boundary voxel in neighbor grid: x = 0
        neighborFlatIndex = otherGrid.AsFlatIndex(0, y, z)
        checker.Check(neighborFlatIndex, otherGrid)
        
    # 3. Bottom Neighbor (Y-1)
    if y > 0:
        checker.CheckBelow(flatIndex - yInc, voxels)
    elif NeighborGrids.get(Direction.BOTTOM) is not None:
        otherGrid = NeighborGrids[Direction.BOTTOM]
        # Boundary voxel in neighbor grid: y = N-1
        neighborFlatIndex = otherGrid.AsFlatIndex(x, N - 1, z)
        checker.CheckBelow(neighborFlatIndex, otherGrid)
        
    # 4. Top Neighbor (Y+1)
    if y < N - 1:
        checker.Check(flatIndex + yInc, voxels)
    elif NeighborGrids.get(Direction.TOP) is not None:
        otherGrid = NeighborGrids[Direction.TOP]
        # Boundary voxel in neighbor grid: y = 0
        neighborFlatIndex = otherGrid.AsFlatIndex(x, 0, z)
        checker.Check(neighborFlatIndex, otherGrid)
        
    # 5. North Neighbor (Z-1)
    if z > 0:
        checker.Check(flatIndex - zInc, voxels)
    elif NeighborGrids.get(Direction.NORTH) is not None:
        otherGrid = NeighborGrids[Direction.NORTH]
        # Boundary voxel in neighbor grid: z = N-1
        neighborFlatIndex = otherGrid.AsFlatIndex(x, y, N - 1)
        checker.Check(neighborFlatIndex, otherGrid)
        
    # 6. South Neighbor (Z+1)
    if z < N - 1:
        checker.Check(flatIndex + zInc, voxels)
    elif NeighborGrids.get(Direction.SOUTH) is not None:
        otherGrid = NeighborGrids[Direction.SOUTH]
        # Boundary voxel in neighbor grid: z = 0
        neighborFlatIndex = otherGrid.AsFlatIndex(x, y, 0)
        checker.Check(neighborFlatIndex, otherGrid)
```

### Parameters and Edge Cases
*   **Grid Size ($N$)**: The method assumes a cubic grid where all dimensions are equal to `GridSize`. If the grid is not cubic, the stride calculations and boundary indices must be adjusted to use separate dimensions $W, H, D$ [S1, unofficial].
*   **Missing Neighbor Grids**: If a neighbor is out of bounds and no `NeighborGrid` exists for that direction, the neighbor is simply skipped. This effectively treats the volume boundary as a hard stop for neighbor traversal [S1, unofficial].
*   **Flat Index Conversion**: The correctness of the method relies on `AsCoordinate` and `AsFlatIndex` being consistent with the stride calculations ($xInc=1, yInc=N, zInc=N^2$). Any mismatch in memory layout (e.g., row-major vs column-major) will cause incorrect neighbor identification [S1, unofficial].

## Operating characteristics
*   **Time Complexity**: $O(1)$ per voxel, as it performs a fixed number of checks (6) and coordinate conversions.
*   **Memory Complexity**: $O(1)$ auxiliary space, excluding the storage of the `NeighborGrids` map.
*   **Performance**: The method is efficient for sparse traversal or surface detection where only active voxels are processed. The overhead of checking `NeighborGrids` existence is minimal compared to the cost of the volume rendering or occupancy tests themselves [S1, unofficial].
*   **Strengths**: Seamless integration across chunked volume data; avoids complex boundary logic within the visitor itself.
*   **Limitations**: Requires the `VoxelGrid` structure to support efficient flat index conversion. Does not handle diagonal neighbors or higher-order neighborhoods [S1, unofficial].

## Background
The method originates from the `Wrecker` project, an unofficial generative graphics tool [S1, unofficial]. It was implemented to support voxel-based operations in a multi-grid environment, allowing for continuous surface detection and occupancy testing across chunk boundaries without requiring global coordinate mapping [S1, unofficial]. It is part of a broader set of voxel operations designed for real-time or near-real-time volume visualization.
