# Voxel Neighbor Activation Check

Also called: GetActiveNeighbors

## Overview
Voxel Neighbor Activation Check determines which of the six immediate spatial neighbors (±X, ±Y, ±Z) of a given voxel are active (solid) or empty. It solves the problem of boundary detection in chunk-based voxel grids where external neighbors may lie outside the current chunk's local array bounds, requiring a lookup against an external heightmap or adjacent grid. It is distinguished from simple intra-grid neighbor checks by its explicit handling of inter-grid connectivity via heightmap queries when a neighbor crosses a chunk boundary [S1, unofficial].

## How it works
**Inputs:**
- `pos`: The global 3D integer coordinates $(x, y, z)$ of the query voxel.
- `width`, `height`, `depth`: The dimensions of the current voxel chunk.
- `voxels`: A 3D array or flat buffer representing the chunk's internal data.
- `getHeightAt(cx, cz)`: A function returning the surface height (Y-coordinate) at global chunk-local coordinates $(cx, cz)$.
- `cubic_size`: The physical size of a voxel (used for scaling if necessary, though indices are typically integer-based in this context).

**Outputs:**
- A `std::array<bool, 6>` where each element corresponds to the activation status of a neighbor.
- Index 0: +X neighbor.
- Index 1: -X neighbor.
- Index 2: +Y neighbor.
- Index 3: -Y neighbor.
- Index 4: +Z neighbor.
- Index 5: -Z neighbor.

**Data Structures:**
- The `voxels` array is assumed to be indexed as `voxels(x, y, z)` or flattened with a standard stride.
- The return type is a fixed-size array of 6 booleans.

**Algorithm:**
For each of the 6 directions, the method checks if the neighbor is within the current chunk's bounds. If it is, it checks the `voxels` array for non-empty status. If the neighbor is outside the chunk's bounds, it queries the external heightmap to determine if the neighbor's Y-coordinate is below the surface height (implying solid ground/voxel exists there).

1.  **Check +X Neighbor (Index 0):**
    -   If $x < \text{width} - 1$: Check if `voxels(x+1, y, z)` is not Empty.
    -   Else ($x = \text{width} - 1$): Check if $y < \text{getHeightAt}(\text{cubic\_size}, \text{pos}.x + x + 1, \text{pos}.z + z)$.

2.  **Check -X Neighbor (Index 1):**
    -   If $x > 0$: Check if `voxels(x-1, y, z)` is not Empty.
    -   Else ($x = 0$): Check if $y < \text{getHeightAt}(\text{cubic\_size}, \text{pos}.x + x - 1, \text{pos}.z + z)$.

3.  **Check +Y Neighbor (Index 2):**
    -   If $y < \text{height} - 1$: Check if `voxels(x, y+1, z)` is not Empty.
    -   Else ($y = \text{height} - 1$): Check if $y + 1 < \text{getHeightAt}(\text{cubic\_size}, \text{pos}.x + x, \text{pos}.z + z)$.

4.  **Check -Y Neighbor (Index 3):**
    -   If $y > 0$: Check if `voxels(x, y-1, z)` is not Empty.
    -   Else ($y = 0$): Check if $y - 1 < \text{getHeightAt}(\text{cubic\_size}, \text{pos}.x + x, \text{pos}.z + z)$.

5.  **Check +Z Neighbor (Index 4):**
    -   If $z < \text{depth} - 1$: Check if `voxels(x, y, z+1)` is not Empty.
    -   Else ($z = \text{depth} - 1$): Check if $y < \text{getHeightAt}(\text{cubic\_size}, \text{pos}.x + x, \text{pos}.z + z + 1)$.

6.  **Check -Z Neighbor (Index 5):**
    -   If $z > 0$: Check if `voxels(x, y, z-1)` is not Empty.
    -   Else ($z = 0$): Check if $y < \text{getHeightAt}(\text{cubic\_size}, \text{pos}.x + x, \text{pos}.z + z - 1)$.

**Pseudocode:**
```python
def get_active_neighbors(pos_x, pos_y, pos_z, width, height, depth, voxels, get_height_at, cubic_size):
    """
    Returns a list of 6 booleans indicating if neighbors in +X, -X, +Y, -Y, +Z, -Z are active.
    """
    neighbors = [False] * 6
    
    # +X Neighbor (Index 0)
    if pos_x < width - 1:
        neighbors[0] = not is_empty(voxels, pos_x + 1, pos_y, pos_z)
    else:
        # Boundary check against heightmap
        # Note: pos.x + x + 1 implies global chunk offset + local index + 1
        # Assuming get_height_at takes global chunk coordinates
        neighbors[0] = pos_y < get_height_at(cubic_size, pos_x + 1, pos_z)

    # -X Neighbor (Index 1)
    if pos_x > 0:
        neighbors[1] = not is_empty(voxels, pos_x - 1, pos_y, pos_z)
    else:
        neighbors[1] = pos_y < get_height_at(cubic_size, pos_x - 1, pos_z)

    # +Y Neighbor (Index 2)
    if pos_y < height - 1:
        neighbors[2] = not is_empty(voxels, pos_x, pos_y + 1, pos_z)
    else:
        neighbors[2] = (pos_y + 1) < get_height_at(cubic_size, pos_x, pos_z)

    # -Y Neighbor (Index 3)
    if pos_y > 0:
        neighbors[3] = not is_empty(voxels, pos_x, pos_y - 1, pos_z)
    else:
        neighbors[3] = (pos_y - 1) < get_height_at(cubic_size, pos_x, pos_z)

    # +Z Neighbor (Index 4)
    if pos_z < depth - 1:
        neighbors[4] = not is_empty(voxels, pos_x, pos_y, pos_z + 1)
    else:
        neighbors[4] = pos_y < get_height_at(cubic_size, pos_x, pos_z + 1)

    # -Z Neighbor (Index 5)
    if pos_z > 0:
        neighbors[5] = not is_empty(voxels, pos_x, pos_y, pos_z - 1)
    else:
        neighbors[5] = pos_y < get_height_at(cubic_size, pos_x, pos_z - 1)

    return neighbors

def is_empty(voxels, x, y, z):
    # Implementation detail: Check if voxel data at x,y,z represents empty space
    # [G] Assuming a standard boolean or enum check; specific implementation depends on voxels layout
    return voxels[x, y, z] == EMPTY_VALUE
```

**Parameters:**
- `cubic_size`: Not explicitly defined in value, but passed to `getHeightAt`. Likely the voxel dimension in world units [S1, unofficial].
- `EMPTY_VALUE`: The value representing an empty voxel. Not given in the sources. [G]

**Edge Cases:**
- **Boundary Crossing:** When a neighbor is outside the chunk, the method relies on `getHeightAt`. If the heightmap is not consistent with the voxel grid's coordinate system, incorrect activation states may result.
- **Precision:** The comparison `y < getHeightAt(...)` uses floating-point height values against integer Y coordinates. Care must be taken with floating-point precision errors at exact boundaries.

## Subtopics

### [Surrounding Voxel Neighbor Traversal](21927-surrounding-voxel-neighbor-traversal.md)
Surrounding Voxel Neighbor Traversal is a method for iterating over the 6 immediate spatial neighbors (West, East, Bottom, Top, North, South) of a specific voxel within a `VoxelGrid`. It solves the problem of boundary crossing in multi-grid volume representations by detecting when a neighbor lies outside the current grid's dimensions and redirecting the traversal to an adjacent `VoxelGrid` if one exists. It is distinguished from simple intra-grid neighbor checks by its explicit handling of inter-grid connectivity via a visitor pattern, ensuring that surface detection or occupancy tests remain continuous across chunk boundaries.

## Operating characteristics
- **Time Complexity:** $O(1)$ per voxel, as it performs a fixed number of checks (6) and array lookups or heightmap queries.
- **Memory Complexity:** $O(1)$ auxiliary space, returning a fixed-size array of 6 booleans.
- **Strengths:** Efficiently handles chunk boundaries without requiring global grid access for every neighbor check, leveraging heightmaps for external context.
- **Limitations:** Relies on the correctness and availability of the `getHeightAt` function for boundary cases. If the heightmap is not synchronized with the voxel data, surface detection may be inaccurate at chunk edges.
- **When to use:** When performing surface detection or occupancy tests in chunk-based voxel engines where external neighbors are defined by a heightmap rather than a full voxel grid.

## Background
The method originates from the Lensimax/VoxelEngine project, an unofficial voxel engine implementation. It is used to determine voxel solidity in the context of surface detection, specifically handling the transition between internal chunk data and external heightmap-defined terrain.
