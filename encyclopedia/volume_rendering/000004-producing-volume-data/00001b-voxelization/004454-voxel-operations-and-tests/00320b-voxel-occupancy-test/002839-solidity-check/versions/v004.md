# Solidity Check

Also called: Void Check with Boundary Handling

## Overview
Solidity Check determines whether a specific voxel coordinate in a 3D world is occupied by solid geometry or is empty space (void) [S2, unofficial]. It differs from general occupancy tests by explicitly handling boundary conditions, coordinate wrapping, and chunk-based data structures to prevent rendering artifacts at world edges [S1, unofficial][S2, unofficial].

## How it works
**Inputs:**
- `x, y, z`: Integer world voxel coordinates.
- `map`: Reference to the voxel map structure containing dimensions and chunk data.

**Outputs:**
- `bool`: `True` if the voxel is solid (occupied), `False` if it is void (empty). Note: [S1, unofficial] inverts this convention, returning `False` for solid and `True` for void.

**Data Structures:**
- `libvxl_map`: Contains `width`, `height`, `depth` (dimensions), `chunks` (array of chunk pointers), `geometry` (lookup table), and `streamed` (streaming state) [S2, unofficial].
- `libvxl_chunk`: Contains `blocks` (pointer to block data), `length`, and `index` [S2, unofficial].
- `libvxl_span`: Packed struct with `length`, `color_start`, `color_end`, `air_start` (uint8_t each) [S2, unofficial].
- Coordinate key packing (libvxl): `pos_key(x,y,z) = ((y)<<20) | ((x)<<8) | (z)`, using 12 bits for X, 12 bits for Y, and 8 bits for Z [S2, unofficial].

**Algorithm Steps:**
1. **Z-axis boundary check:** If `z < 0`, return void. If `map` is null or `z >= map->depth`, return solid. This treats out-of-bounds Z as solid to prevent holes [S2, unofficial].
2. **Coordinate wrapping:** X and Y coordinates wrap around the map dimensions using modulo: `x_wrapped = x % map->width`, `y_wrapped = y % map->height`. Z does not wrap and is passed unchanged [S2, unofficial].
3. **Chunk lookup:** Calculate the chunk index for the world position. If `chunk_index == -1` (out of bounds in X/Y), return solid (non-void) to prevent rendering holes at world edges [S1, unofficial].
4. **Local voxel index:** Calculate the local index within the chunk using modulo arithmetic: `local_index = (x_wrapped % CHUNK_SIZE) + (z % CHUNK_SIZE) * CHUNK_SIZE + (y_wrapped % CHUNK_SIZE) * (CHUNK_SIZE * CHUNK_SIZE)` [S1, unofficial].
5. **Occupancy test:** Access the voxel data at `local_index`. If `chunk_voxels[local_index]` is non-zero, return solid. Otherwise, return void [S1, unofficial].

**Pseudocode:**
```python
def solidity_check(x, y, z, map, CHUNK_SIZE=16):
    # Step 1: Z-axis boundary check
    if z < 0:
        return False  # Void
    if map is None or z >= map.depth:
        return True   # Solid (boundary)

    # Step 2: Coordinate wrapping
    x_wrapped = x % map.width
    y_wrapped = y % map.height
    # Z does not wrap, already validated against depth

    # Step 3: Chunk lookup
    chunk_index = get_chunk_index(x, y, z, map.width, map.height, CHUNK_SIZE)
    if chunk_index == -1:
        return True   # Solid (non-void) to prevent holes [S1, unofficial]

    # Step 4: Local voxel index calculation
    CHUNK_AREA = CHUNK_SIZE * CHUNK_SIZE
    local_x = x_wrapped % CHUNK_SIZE
    local_z = z % CHUNK_SIZE
    local_y = y_wrapped % CHUNK_SIZE
    voxel_index = local_x + (local_z * CHUNK_SIZE) + (local_y * CHUNK_AREA)

    # Step 5: Occupancy test
    # Note: [S1, unofficial] returns False for solid and True for void.
    # This implementation standardizes on True=solid, False=void.
    if map.chunks[chunk_index].voxels[voxel_index] != 0:
        return True   # Solid
    else:
        return False  # Void

def get_chunk_index(x, y, z, map_width, map_height, CHUNK_SIZE):
    # Standard 3D chunk grid mapping. Formula not given in sources. [G]
    chunk_cols = map_width // CHUNK_SIZE
    chunk_rows = map_height // CHUNK_SIZE
    cx = x // CHUNK_SIZE
    cy = y // CHUNK_SIZE
    cz = z // CHUNK_SIZE
    if cx < 0 or cx >= chunk_cols or cy < 0 or cy >= chunk_rows or cz < 0:
        return -1
    return cz * chunk_cols * chunk_rows + cy * chunk_cols + cx
```

**Parameters:**
- `CHUNK_SIZE`: Not given in the sources. [G] Typical value is 16.

**Edge Cases:**
- `z < 0`: Always void.
- `z >= depth`: Always solid.
- `chunk_index == -1`: Solid (non-void) to prevent rendering holes.
- Coordinate wrapping: X and Y wrap, Z does not.

## Subtopics

### [Surface Detection](5803-surface-detection.md)
Surface detection determines whether a voxel or particle lies on the boundary of a solid or fluid volume. In voxel-based representations, it identifies voxels that have at least one non-solid neighbor in the 6-connected neighborhood. In particle-based fluid simulations, it identifies boundary particles by estimating occlusion on a spherical screen cover, distinguishing interior particles (shadowed by neighbors) from boundary particles (with unshadowed screen areas). It differs from general solidity checks by specifically evaluating the *neighborhood* state rather than the local occupancy, serving as a prerequisite for surface tension, boundary rendering, or collision detection.

## Operating characteristics
- **Time Complexity:** O(1) for chunk lookup and local index calculation, assuming constant-time array access.
- **Memory Complexity:** O(1) additional memory.
- **Strengths:** Efficient boundary handling prevents rendering holes, and the chunk-based structure allows for sparse world representation.
- **Limitations:** Coordinate wrapping for X/Y may cause unexpected behavior at world edges if not intended, and Z-axis is not wrapped, requiring explicit depth management.
- **When to use:** When determining if a specific voxel is occupied for rendering or collision.
- **When not to use:** When surface properties or neighborhood information is required (use Surface Detection).

## Background
The method originates from voxel-based rendering systems, specifically those used in Minecraft-like games and the libvxl library. It is used to efficiently determine voxel occupancy in large, chunked 3D worlds.
