# Searchsorted
## Overview
Searchsorted finds the indices where query points `v` should be inserted into a sorted reference array `a` to maintain order [S1, unofficial]. It serves as the core lookup mechanism for the parent method, enabling range queries on pre-sorted coordinate arrays [S1, unofficial]. Unlike standard binary search which returns a single insertion point, this vectorized implementation explicitly computes both lower (`idx_lo`) and upper (`idx_hi`) bounds to handle edge cases and range queries robustly [S1, unofficial].
## How it works
**Inputs:**
- `a`: Sorted reference points (keys) [S2, unofficial].
- `v`: Query points [S1, unofficial].
**Outputs:**
- `idx_lo`: Indices of the maximum position in `a` where `v >= a` holds [S1, unofficial].
- `idx_hi`: Indices of the minimum position in `a` where `v < a` holds [S1, unofficial].
**Data Structures:**
- `a`: Array of floats or integers, sorted in ascending order.
- `v`: Array of floats or integers, same type as `a`.
- `i`: Index tensor for the last dimension of `a` [S1, unofficial].
- `v_ge_a`: Boolean mask where `v >= a` [S1, unofficial].
**Steps:**
1. Create an index tensor `i` corresponding to the last dimension of `a` [S1, unofficial].
2. Compute a boolean mask `v_ge_a` where each element is true if the corresponding query point `v` is greater than or equal to the reference point `a` [S1, unofficial].
3. Compute `idx_lo` as the maximum index `i` where `v_ge_a` is true, handling out-of-range values [S1, unofficial].
4. Compute `idx_hi` as the minimum index `i` where `v < a`, handling out-of-range values [S1, unofficial].
**Pseudocode:**
```python
import numpy as np

def searchsorted(key, query):
    a = np.asarray(key)
    v = np.asarray(query)
    # Step 1: Create index tensor i for the last dimension of a
    i = np.arange(a.shape[-1])
    # Step 2: Compute boolean mask v_ge_a where v >= a
    v_ge_a = v[..., np.newaxis] >= a
    # Step 3: Compute idx_lo as max of indices where v >= a
    idx_lo = np.zeros(v.shape, dtype=np.int64)
    for idx in np.ndindex(v.shape):
        valid = np.where(v_ge_a[idx])[0]
        idx_lo[idx] = valid[-1] if len(valid) > 0 else 0
    # Step 4: Compute idx_hi as min of indices where v < a
    idx_hi = np.full(v.shape, len(a), dtype=np.int64)
    for idx in np.ndindex(v.shape):
        valid = np.where(~v_ge_a[idx])[0]
        idx_hi[idx] = valid[0] if len(valid) > 0 else len(a)
    return idx_lo, idx_hi
```
**Parameters:**
- `query`: Query values `v` [S2, unofficial].
- `key`: Key values to search within [S2, unofficial].
**Edge Cases and Pitfalls:**
- If `v` is out of the range `[a[0], a[-1]]`, `idx_lo` and `idx_hi` are clamped to the first or last index of `a` respectively [S1, unofficial]. Specifically, if `v < a[0]`, both are set to 0; if `v > a[-1]`, both are set to `len(a)` [S1, unofficial].
