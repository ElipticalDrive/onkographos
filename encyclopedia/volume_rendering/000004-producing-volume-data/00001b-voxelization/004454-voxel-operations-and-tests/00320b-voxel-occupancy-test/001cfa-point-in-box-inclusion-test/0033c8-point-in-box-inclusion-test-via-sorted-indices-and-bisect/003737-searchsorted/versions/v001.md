# Searchsorted


## Overview
Searchsorted finds the indices where query points `v` should be inserted into a sorted reference array `a` to maintain order [S1, S2, unofficial]. It serves as the core lookup mechanism for the parent method, enabling O(log N) point-in-box inclusion tests by determining the range of indices in pre-sorted coordinate arrays that correspond to a query point's coordinate [S1, S2, unofficial]. Unlike standard binary search which returns a single insertion point, this implementation explicitly computes both lower (`idx_lo`) and upper (`idx_hi`) bounds to handle edge cases and range queries robustly [S1, unofficial].

## How it works
**Inputs:**
- `a`: A 1D sorted array of reference points (keys) [S1, S2, unofficial].
- `v`: A 1D array of query points [S1, S2, unofficial].

**Outputs:**
- `idx_lo`: Indices of the first element in `a` that is greater than or equal to each element in `v` [S1, unofficial].
- `idx_hi`: Indices of the first element in `a` that is strictly greater than each element in `v` [S1, unofficial].

**Data Structures:**
- `a`: Array of floats or integers, sorted in ascending order.
- `v`: Array of floats or integers, same type as `a`.
- `i`: Index tensor for the last dimension of `a`, typically `range(len(a))` [S1, unofficial].
- `v_ge_a`: Boolean mask where `v >= a` [S1, unofficial].

**Steps:**
1. Create an index tensor `i` corresponding to the indices of `a` [S1, unofficial].
2. Compute a boolean mask `v_ge_a` where each element is true if the corresponding query point `v` is greater than or equal to the reference point `a` [S1, unofficial].
3. Compute `idx_lo` as the maximum index `i` where `v_ge_a` is true. If `v` is less than all elements in `a`, `idx_lo` is set to 0 [S1, unofficial].
4. Compute `idx_hi` as the minimum index `i` where `v < a` (i.e., `~v_ge_a`). If `v` is greater than all elements in `a`, `idx_hi` is set to `len(a)` [S1, unofficial].

**Pseudocode:**
```python
import numpy as np

def searchsorted(a, v):
    """
    Finds indices where v should be inserted into sorted array a.
    Returns idx_lo and idx_hi.
    """
    # Ensure inputs are numpy arrays for vectorized operations
    a = np.asarray(a)
    v = np.asarray(v)
    
    # Step 1: Create index tensor for the last dimension of a
    # Assuming 1D arrays as per source context
    i = np.arange(len(a))
    
    # Step 2: Compute boolean mask v >= a
    # Broadcasting v over a to compare each query point with each reference point
    # Shape of v_ge_a: (len(v), len(a))
    v_ge_a = v[:, np.newaxis] >= a[np.newaxis, :]
    
    # Step 3: Compute idx_lo as max of indices where v >= a
    # If no element in a is >= v, the mask is all False, max index is undefined.
    # We handle this by setting idx_lo to 0 in such cases.
    # np.argmax returns the first occurrence of the maximum value (True).
    # If all are False, argmax returns 0, which is correct for lower bound 0.
    # However, we need to be careful: if v < a[0], v_ge_a is all False.
    # We want idx_lo = 0.
    # If v >= a[0], we want the last index where v >= a[k].
    # Actually, the source says "max of indices where v >= a".
    # Let's use np.where to get indices, then max.
    
    # For each query point v[j], find indices k where v[j] >= a[k]
    # Then take the max of those indices.
    
    idx_lo = np.zeros(len(v), dtype=np.int64)
    idx_hi = np.zeros(len(v), dtype=np.int64)
    
    for j in range(len(v)):
        # Get indices where v[j] >= a[k]
        valid_indices = np.where(v_ge_a[j])[0]
        
        if len(valid_indices) > 0:
            idx_lo[j] = valid_indices[-1] # Max index
        else:
            idx_lo[j] = 0 # Out of range, set to first index
            
        # Step 4: Compute idx_hi as min of indices where v < a
        # Indices where v[j] < a[k]
        invalid_indices = np.where(~v_ge_a[j])[0]
        
        if len(invalid_indices) > 0:
            idx_hi[j] = invalid_indices[0] # Min index
        else:
            idx_hi[j] = len(a) # Out of range, set to last index + 1
            
    return idx_lo, idx_hi
```

**Parameters:**
- `query`: Query values `v` [S2, unofficial].
- `key`: Key values `a` [S2, unofficial].

**Edge Cases and Pitfalls:**
- If `v` is out of the range `[a[0], a[-1]]`, `idx_lo` and `idx_hi` are clamped to the first or last index of `a` respectively [S1, unofficial]. Specifically, if `v < a[0]`, `idx_lo` and `idx_hi` are 0. If `v > a[-1]`, `idx_lo` and `idx_hi` are `len(a)` [S1, unofficial].

## Subtopics

## Operating characteristics
**Time Complexity:** O(N * M) for the naive implementation described in [S1, unofficial], where N is the number of query points and M is the number of reference points. This is because the source describes a vectorized comparison followed by reduction operations. For large datasets, a binary search approach would be O(N log M), but the provided source implementation uses a full comparison mask [S1, unofficial].
**Memory Complexity:** O(N * M) to store the boolean mask `v_ge_a` [S1, unofficial].
**Strengths:** Simple to implement using vectorized operations; handles edge cases explicitly [S1, unofficial].
**Limitations:** Memory intensive for large arrays due to the creation of the comparison mask [S1, unofficial]. Not suitable for very large N and M.
**When to use:** Small to medium-sized datasets where simplicity and vectorization are preferred over optimal time complexity [S1, unofficial].

## Background
The method is used in the context of 3D Gaussian Splatting and related rendering techniques, specifically within the InstantSplat and CNC projects [S1, S2, unofficial]. It is employed for efficient point-in-box inclusion tests by leveraging pre-sorted indices [S1, S2, unofficial]. The implementation is based on CUDA kernels for performance [S2, unofficial].
