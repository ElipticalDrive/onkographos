# Sphere-Clamped Voxel Neighbor Search


## Overview
Sphere-Clamped Voxel Neighbor Search finds the closest voxel cell to a query point within a specified radius, constrained to the grid boundaries [S1, unofficial]. It solves the problem of locating the nearest valid material cell in a voxelized environment for operations like neighbor lookups [S1, unofficial]. It differs from [Point-in-Box Inclusion Test](1400-point-in-box-inclusion-test.md) by using a spherical distance metric and from [Voxel Filled Check](1705-voxel-filled-check.md) by returning the specific closest cell rather than a boolean occupancy status [G].

## How it works
**Inputs:** `from` (query point in world coordinates), `radius` (search radius in world units), `p` (configuration struct containing `voxel_size_m`, `height_step_m`, `base_depth_m`, `extent`, `height_cells`), `grid` (provides coordinate mapping functions), `mats` (array of material data), `pred` (predicate function `bool(VoxMat)`) [S1, unofficial].

**Outputs:** `best` (world coordinates of the center of the closest valid cell, or `std::nullopt` if no valid cell is found within the sphere) [S1, unofficial].

**Data Structures:** The grid uses a linear indexing scheme via `grid.cell_index(ix, iy, iz)` to map 3D coordinates to a 1D array index for `mats` [S1, unofficial]. Coordinate accessors include `grid.column_center_x(ix)`, `grid.column_center_z(iz)`, and `grid.cell_bottom_y(iy)` [S1, unofficial].

**Pseudocode:**
```python
def sphere_clamped_voxel_neighbor_search(from, radius, p, grid, mats, pred):
    half = 0.5 * p.voxel_size_m  # [G]
    r2 = radius * radius
    found = False
    best2 = float('inf')
    best = None

    ix0 = clamp(floor((from.x - radius + half) / p.voxel_size_m), 0, p.extent - 1)
    ix1 = clamp(floor((from.x + radius + half) / p.voxel_size_m), 0, p.extent - 1)
    iz0 = clamp(floor((from.z - radius + half) / p.voxel_size_m), 0, p.extent - 1)
    iz1 = clamp(floor((from.z + radius + half) / p.voxel_size_m), 0, p.extent - 1)
    iy0 = clamp(floor((from.y - radius + p.base_depth_m) / p.height_step_m), 0, p.height_cells - 1)
    iy1 = clamp(floor((from.y + radius + p.base_depth_m) / p.height_step_m), 0, p.height_cells - 1)

    for iy in range(iy0, iy1 + 1):
        for ix in range(ix0, ix1 + 1):
            for iz in range(iz0, iz1 + 1):
                idx = grid.cell_index(ix, iy, iz)
                if not pred(mats[idx]):
                    continue
                cx = grid.column_center_x(ix)
                cz = grid.column_center_z(iz)
                cy = grid.cell_bottom_y(iy) + 0.5 * p.height_step_m
                dx = cx - from.x
                dy = cy - from.y
                dz = cz - from.z
                d2 = dx * dx + dy * dy + dz * dz
                if d2 <= r2 and (not found or d2 < best2):
                    best2 = d2
                    best = (cx, cy, cz)
                    found = True
    return best if found else None
```

**Parameters:** `radius` (search radius in world units) and `from` (query point) [S1, unofficial].

**Edge Cases and Pitfalls:** The clamping ensures no out-of-bounds access [S1, unofficial]. The implementation uses strict inequality for distance updates, ensuring that ties resolve to the cell with the lowest index due to the ascending iteration order of the loops [S1, unofficial]. If no cells satisfy the predicate, the function returns `std::nullopt` [S1, unofficial].
