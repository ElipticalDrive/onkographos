# Voxel Build Process
Also called: BuildNodeVoxels

## Overview
The Voxel Build Process is a procedural method for constructing a voxel representation of a specific `SceneNode` into a persistent "built voxels" container, managing state transitions for undo/redo operations [S1, unofficial]. It distinguishes itself from static voxelization methods by maintaining a history of voxel states, allowing the system to detach old representations and atomically swap in newly computed voxel data while preserving spatial origin consistency [S1, unofficial].

## How it works
**Inputs and Outputs**
- **Input**: A `SceneNode` to be voxelized, a `buildContext` containing build parameters, and a reference to the global `generatedVoxels` collection.
- **Output**: A new voxel group labeled `BUILT_VOXELS_GROUP_NAME` attached to the `voxelRoot`, replacing any previous built voxels for this node.

**Data Structures**
- `BlockStorageDelegate`: Wraps a `ChunkedStorage3D` structure for efficient voxel storage [S1, unofficial].
- `RootBuilder`: The core algorithmic engine that processes the `SceneNode` into voxel data [S1, unofficial].
- `Vec3`: A 3D vector type used for coordinate transformations [S1, unofficial].
- `generatedVoxels`: A collection storing the active voxel groups [S1, unofficial].

**Steps**
1. **Initialization Check**: Determine if this is the first invocation (`firstTime=true`).
2. **Locate Existing State**: Search `generatedVoxels` for an existing group with the label `BUILT_VOXELS_GROUP_NAME`. Let this be `oldBuiltVoxels`.
3. **Prepare New Storage**:
   - Create a new `BlockStorageDelegate` initialized with `ChunkedStorage3D()`.
   - Create a new voxel group with label `BUILT_VOXELS_GROUP_NAME`, the new storage, the current `renderMode`, and a visibility flag set to `true`. Let this be `newBuiltVoxels`.
4. **Origin Handling**:
   - If `oldBuiltVoxels` exists:
     - Copy its voxel data into the new storage using `copyTo()`.
     - Set `newBuiltVoxels.origin` to `oldBuiltVoxels.origin`.
   - If `oldBuiltVoxels` does not exist:
     - Set `newBuiltVoxels.origin` to the rounded global position of the `SceneNode`.
5. **Coordinate Transformation**:
   - Create a translation transform $T$ that shifts coordinates by $-newBuiltVoxels.origin$.
   - Apply $T$ to the world coordinates, converting them to local space relative to the voxel group's origin.
6. **Voxel Generation**:
   - Instantiate a `RootBuilder`.
   - If `verboseBuild` is enabled, attach a `VerboseLogger` listener to the builder.
   - Invoke the builder to generate voxels for the `SceneNode`, passing the transformed world coordinates, the `offsetWorld`, and the `buildContext`.
7. **State Swap**:
   - Add `newBuiltVoxels` to `voxelRoot`.
   - Detach `newBuiltVoxels` from the root temporarily and store it in a variable `newVoxels`.
   - Detach `oldBuiltVoxels` (if it exists) from `generatedVoxels`.
   - Reattach `newVoxels` to `generatedVoxels`.
8. **Finalization**: Trigger a redraw of the voxel display.

**Revert Operation**
- Detach `newVoxels`.
- If `oldVoxels` (the state before the current build) exists, reattach it to `generatedVoxels`.
- Trigger a redraw.

**Pseudocode**
```python
def build_node_voxels(scene_node, build_context, generated_voxels, voxel_root, first_time, verbose_build):
    # Step 1: Locate existing built voxels
    old_built_voxels = None
    for group in generated_voxels:
        if group.label == "BUILT_VOXELS_GROUP_NAME":
            old_built_voxels = group
            break

    # Step 2: Create new storage and group
    new_storage = BlockStorageDelegate(ChunkedStorage3D())
    new_built_voxels = VoxelGroup(
        label="BUILT_VOXELS_GROUP_NAME",
        storage=new_storage,
        render_mode=current_render_mode,
        visible=True
    )

    # Step 3: Handle origin and data copy
    if old_built_voxels is not None:
        old_built_voxels.storage.copy_to(new_built_voxels.storage)
        new_built_voxels.origin = old_built_voxels.origin
    else:
        # Round global position to integer grid coordinates
        new_built_voxels.origin = round(scene_node.global_position)

    # Step 4: Transform world to local coordinates
    # Translation vector is negative of the origin
    translation_vector = Vec3(-new_built_voxels.origin.x, -new_built_voxels.origin.y, -new_built_voxels.origin.z)
    local_world = transform_world_coordinates(translation_vector)

    # Step 5: Build voxels
    builder = RootBuilder()
    if verbose_build:
        builder.add_listener(VerboseLogger())
    
    # The builder processes the scene node into the new storage
    # Implementation detail: builder.build(scene_node, local_world, build_context, new_built_voxels.storage)
    # Note: Exact signature of builder.build is not fully specified in source, assumed to take node, world, context, storage
    builder.build(scene_node, local_world, build_context, new_built_voxels.storage)

    # Step 6: Swap state
    voxel_root.add(new_built_voxels)
    
    # Detach new voxels to store in temporary variable
    new_voxels = voxel_root.detach(new_built_voxels)
    
    # Detach old voxels if they exist
    if old_built_voxels is not None:
        generated_voxels.detach(old_built_voxels)
        
    # Reattach new voxels to generated_voxels
    generated_voxels.add(new_voxels)
    
    # Trigger redraw
    trigger_redraw()

def revert_build(generated_voxels, old_voxels, new_voxels):
    # Detach the newly built voxels
    generated_voxels.detach(new_voxels)
    
    # Reattach the old voxels if they exist
    if old_voxels is not None:
        generated_voxels.add(old_voxels)
        
    # Trigger redraw
    trigger_redraw()
```

## Operating characteristics
- **Time Complexity**: Not given in the sources. Depends on the complexity of the `RootBuilder` and the size of the `SceneNode`.
- **Memory Complexity**: Not given in the sources. Depends on the `ChunkedStorage3D` implementation and the density of the voxelized node.
- **Strengths**: Supports undo/redo functionality by maintaining state history; handles origin consistency across rebuilds.
- **Limitations**: The source code is specific to the `VoxelArchitecture` library and may not be directly portable without adapting the `BlockStorageDelegate` and `RootBuilder` interfaces.

## Background
The Voxel Build Process is part of the `VoxelArchitecture` library by Hunternif, a Minecraft modding library for voxel generation [S1, unofficial]. It is designed to handle incremental and reversible voxel building for procedural generation, such as the `FlatDungeon` generator which creates rooms and corridors [S1, unofficial].
