# Image-to-Voxel Heightmap Generation

Also called: Excavate mode height clipping, Grayscale heightmap extrusion, Heightmap-to-Voxel Conversion, Heightmap-to-Voxlap Conversion

## Overview
This method converts a 2D image into a 3D voxel structure where pixel intensity determines voxel height along the Y-axis [S1, S3, unofficial]. It differs from standard rasterization by treating the image as a heightfield rather than a surface mesh, supporting both simple vertical extrusion and an 'excavate' mode that clips voxel columns to the minimum height of their 4-connected neighbors to prevent overhangs [S1, S3, unofficial]. It builds on [Image-based Voxelization](12822-image-based-voxelization.md) by mapping image pixels to X and Z axes while using intensity for Y [S1, S3, unofficial].

## How it works
**Inputs:**
- A 2D heightmap image (grayscale or RGB) [S1, S3, unofficial].
- An optional scale/color map image for color lookup [S1, unofficial].
- `heightFactor` (float): Multiplier applied to normalized pixel intensity to determine voxel height. Typical value: 1 [S3, unofficial].
- `Excavate` (bool): Flag to enable neighbor-aware height clipping [S3, unofficial].

**Outputs:**
- A 3D voxel volume (voxlap) with a binary column layout [S1, unofficial].

**Data Structures:**
- Implicit voxel grid where each column corresponds to an image pixel $(x, z)$ [S1, S3, unofficial].
- [S1, unofficial] uses a fixed 512×512 grid; [S3, unofficial] supports arbitrary dimensions [S3, unofficial].
- Each column header is 4 bytes written as `[0, currHeight, currHeight + gap, 0]` [S1, unofficial].

**Steps:**
1. **Read Heightmap:** Load the heightmap image [S1, unofficial].
2. **Compute Target Height:** Calculate $H_{target}$ for each pixel $(x, z)$ [S3, unofficial].
   - Formula [S3, unofficial]: $H_{target} = \left\lfloor \frac{\sum_{c=0}^{2} I_c}{\min(N_c, 3) \times 65535} \times H_{max} \right\rfloor$, where $I_c$ are channel values, $N_c$ is channel count, and $H_{max} = \text{heightFactor}$ [S3, unofficial].
   - Alternative [S1, unofficial]: $H_{target} = \lfloor (255 - R) / 4 \rfloor$ for 8-bit grayscale, which reduces precision to 0–63 [S1, unofficial].
3. **Determine Clipping Height (if `Excavate` is true):**
   - Identify 4-connected neighbors: $(x-1, z), (x+1, z), (x, z-1), (x, z+1)$ [S1, S3, unofficial].
   - Boundary handling: [S1, unofficial] wraps coordinates modulo grid width. [S3, unofficial] checks bounds explicitly; out-of-bounds neighbors are ignored, defaulting to no clipping [S3, unofficial].
   - Compute $H_{min\_neighbor} = \min(\{H_{neighbor} \mid \text{valid}\} \cup \{0\})$ [S3, unofficial].
   - Calculate gap: initialize `gap = 0`. Iterate neighbors; if $H_{neighbor} > H_{target} + \text{gap} + 1$, set $\text{gap} = H_{neighbor} - H_{target} - 1$ [S1, unofficial].
   - Set shadow flag: 1 if left neighbor height < $H_{target}$, else 0 [S1, unofficial].
   - Effective height: $H_{eff} = \min(H_{target}, H_{min\_neighbor})$ [S3, unofficial].
   - Pitfall: If excavating and $H_{target} \le H_{min\_neighbor}$, place a single voxel at $y = \max(0, H_{target} - 1)$ instead of an empty column [S1, S3, unofficial].
4. **Generate Voxels:**
   - If `Excavate` is false, $H_{eff} = H_{target}$ [S1, S3, unofficial].
   - Write the 4-byte column header [S1, unofficial].
   - Iterate $k$ from 0 to `gap` (if excavating) or $H_{eff}-1$ (if not) [S1, unofficial].
   - Lookup color from scale map at $(0, H_{target})$ [S1, unofficial].
   - Apply noise and shadow: $R, G, B = \text{hmColor} + \text{random}(-2, 2) - 16 \times \text{shadow}$ [S1, unofficial]. Set alpha to 128 [S1, unofficial].
   - Write RGBA voxel data [S1, unofficial].

**Parameters:**
- `heightFactor`: 1 [S3, unofficial].
- Grid dimensions: 512×512 [S1, unofficial].

**Edge Cases and Pitfalls:**
- Height calculation uses integer division by 4 in [S1, unofficial], reducing 8-bit precision to 6-bit (0–63) [S1, unofficial].
- Boundary pixels lack neighbors; [S3, unofficial] defaults to no clipping for out-of-bounds checks [S3, unofficial].
- Shadowing is determined solely by the left neighbor in [S1, unofficial], ignoring other neighbors [S1, unofficial].
- Color noise is added uniformly to all channels with the same random offset, potentially desaturating colors [S1, unofficial].
- When excavating, if computed height $\le$ neighbor minimum, the algorithm places a single voxel at `max(0, height - 1)` instead of an empty column [S1, S3, unofficial].

**Pseudocode:**
```python
def generate_voxels(heightmap, scale_map, height_factor, excavate, wrap_bounds=True):
    voxels = []
    W, H = heightmap.width, heightmap.height
    heights = [[0] * H for _ in range(W)]

    for x in range(W):
        for z in range(H):
            r, g, b = heightmap.get_pixel(x, z)
            # [S3, unofficial] formula for normalized/16-bit input
            h_target = int((r + g + b) / (3 * 65535.0) * height_factor)
            heights[x][z] = h_target

    for x in range(W):
        for z in range(H):
            curr_height = heights[x][z]
            gap = 0
            shadow = 0

            if excavate:
                neighbors = []
                offsets = [(-1, 0), (1, 0), (0, -1), (0, 1)]
                for dx, dz in offsets:
                    nx, nz = x + dx, z + dz
                    if wrap_bounds:
                        nx, nz = nx % W, nz % H
                    elif not (0 <= nx < W and 0 <= nz < H):
                        continue
                    neighbors.append(heights[nx][nz])

                if neighbors:
                    h_min_neighbor = min(neighbors)
                    for adj_h in neighbors:
                        if adj_h > curr_height + gap + 1:
                            gap = adj_h - curr_height - 1
                    if neighbors[0] < curr_height:
                        shadow = 1
                    if curr_height <= h_min_neighbor:
                        y_pos = max(0, curr_height - 1)
                        voxels.append((x, y_pos, z))
                        continue
                    h_eff = min(curr_height, h_min_neighbor)
                else:
                    h_eff = curr_height
            else:
                h_eff = curr_height

            if scale_map:
                color = scale_map.get_pixel(0, curr_height)
            else:
                color = (128, 128, 128)

            limit = gap + 1 if excavate else h_eff
            for k in range(limit):
                r_c = color[0] + random(-2, 2) - 16 * shadow
                g_c = color[1] + random(-2, 2) - 16 * shadow
                b_c = color[2] + random(-2, 2) - 16 * shadow
                a_c = 128
                voxels.append((x, k, z, r_c, g_c, b_c, a_c))
    return voxels
```

## Subtopics

### [Height Curve Activation & Voxel Column Generation](17940-height-curve-activation-voxel-column-generation.md)
This method transforms a normalized 2D noise heightmap into a 3D voxel column structure by applying a hyperbolic tangent activation function, scaling the result to world units, and stacking voxels from a defined ground offset to the calculated height. It differs from linear extrusion by compressing extreme noise values through a non-linear curve and explicitly mapping discrete terrain bands to color indices.

## Operating characteristics
- **Time Complexity:** $O(W \times H \times H_{max})$ where $W, H$ are image dimensions and $H_{max}$ is max height (63), due to nested loops and per-voxel writes [S1, unofficial].
- **Memory Complexity:** $O(W \times H)$ for the intermediate height map, plus $O(V)$ for the output voxel list where $V$ is total voxels [G].
- **Strengths:** Simple to implement; efficient for generating terrain-like structures from heightmaps; excavate mode prevents floating islands [G].
- **Limitations:** Resolution is limited by image resolution; no sub-voxel precision; excavate mode can flatten steep features [G].
- **When to use:** Converting 2D heightmaps into 3D voxel data for games or simulations [G].
- **When not to use:** When high-resolution smooth surfaces are required or complex 3D geometry beyond heightfields is needed [G].

## Background
This method originates from voxel terrain generation pipelines and procedural generation workflows [S2, unofficial]. It is implemented in tools like FileToVox for converting image formats into voxel schematics [S3, unofficial]. The 'excavate' mode serves as a heuristic to maintain structural integrity in voxel art by preventing overhangs [S3, unofficial].
