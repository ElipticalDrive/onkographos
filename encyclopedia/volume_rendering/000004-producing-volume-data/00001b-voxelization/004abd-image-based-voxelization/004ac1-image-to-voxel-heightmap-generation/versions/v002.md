# Image-to-Voxel Heightmap Generation

Also called: Excavate mode height clipping, Grayscale heightmap extrusion

## Overview
This method converts a 2D image into a 3D voxel structure where pixel intensity determines voxel height along the Y-axis [S1, unofficial]. It is distinguished from standard vertical extrusion by supporting an 'excavate' mode that clips voxel columns to the minimum height of their 4-connected neighbors [S1, unofficial].

## How it works
**Inputs:** A 2D image (grayscale or RGB), `heightFactor` (float, typical value 1), and `Excavate` (bool) [S1, unofficial].
**Outputs:** A list of 3D voxel coordinates $(x, y, z)$ [S1, unofficial].
**Data Structures:** The image is treated as a 2D grid where the X-axis corresponds to image width and the Z-axis corresponds to image height [S1, unofficial]. The Y-axis represents vertical height in voxel space [S1, unofficial]. Pixel values are accessed by channel; for RGB images, intensity is derived from the sum of Red, Green, and Blue channels [S1, unofficial].

**Steps:**
1. Initialize an empty list for voxels.
2. Iterate through each pixel at image coordinates $(u, v)$ where $0 \le u < \text{Width}$ and $0 \le v < \text{Height}$ [S1, unofficial].
3. Calculate base height $h$ using the formula:
   $$ h = \left\lfloor \frac{\sum_{c=0}^{2} I_c}{\min(N_c, 3) \times 65535} \times H_{max} \right\rfloor $$
   where $I_c$ are the channel values, $N_c$ is the number of channels, and $H_{max}$ is `heightFactor` [S1, unofficial].
4. Determine final height $h_{final}$:
   - If `Excavate` is false, $h_{final} = h$ [S1, unofficial].
   - If `Excavate` is true, find the minimum height $h_{min\_neighbor}$ among the 4-connected neighbors (up, down, left, right) within bounds [S1, unofficial]. If a neighbor is out of bounds, it is ignored [S1, unofficial]. If no neighbors exist, $h_{min\_neighbor} = 0$ [S1, unofficial]. Then $h_{final} = \min(h, h_{min\_neighbor})$ [S1, unofficial].
5. Generate voxels:
   - If $h_{final} \le 0$ and $h > 0$, place a single voxel at $y = \max(0, h - 1)$ [S1, unofficial].
   - Otherwise, place voxels at $y = 0$ to $h_{final} - 1$ [S1, unofficial].

**Pseudocode:**
```python
def generate_heightmap_voxels(image, height_factor=1.0, excavate=False):
    width = image.width
    height = image.height
    voxels = []
    raw_heights = [[0] * width for _ in range(height)]
    for y in range(height):
        for x in range(width):
            pixel = image[y][x]
            channels = pixel
            n_c = len(channels)
            sum_channels = sum(channels)
            denominator = min(n_c, 3) * 65535
            if denominator == 0:
                h = 0
            else:
                h = int((sum_channels / denominator) * height_factor)
            raw_heights[y][x] = h
    for y in range(height):
        for x in range(width):
            h = raw_heights[y][x]
            if not excavate:
                h_final = h
            else:
                min_neighbor_h = float('inf')
                has_neighbor = False
                for dx, dy in [(-1, 0), (1, 0), (0, -1), (0, 1)]:
                    nx, ny = x + dx, y + dy
                    if 0 <= nx < width and 0 <= ny < height:
                        has_neighbor = True
                        if raw_heights[ny][nx] < min_neighbor_h:
                            min_neighbor_h = raw_heights[ny][nx]
                if not has_neighbor:
                    min_neighbor_h = 0
                h_final = min(h, min_neighbor_h)
            if h_final <= 0:
                if h > 0:
                    vy = max(0, h - 1)
                    voxels.append((x, vy, y))
                continue
            for vy in range(h_final):
                voxels.append((x, vy, y))
    return voxels
```

**Parameters:** `heightFactor` (float, typical value 1) and `Excavate` (bool) [S1, unofficial].
**Edge Cases and Pitfalls:** Boundary pixels lack neighbors on one or more sides; the implementation checks bounds explicitly: `if (param.X - 1 >= 0 && param.X + 1 < param.GrayscaleImage.Width && param.Y - 1 >= 0 && param.Y + 1 < param.GrayscaleImage.Height)` [S1, unofficial]. If out of bounds, it defaults to adding voxels from 0 to the computed height [S1, unofficial]. When excavating, if the computed height is less than or equal to the neighbor minimum, the algorithm places a single voxel at `max(0, height - 1)` instead of an empty column or negative height [S1, unofficial].

## Operating characteristics
- **Time Complexity:** $O(W \times H)$, where $W$ and $H$ are image dimensions [G].
- **Memory Complexity:** $O(W \times H \times H_{max})$ for the output voxel list [G].
- **Strengths:** Simple to implement; generates terrain-like structures efficiently; "Excavate" mode reduces vertical artifacts [S1, unofficial].
- **Limitations:** Resolution is limited by the input image resolution; height resolution is limited by `heightFactor` and pixel precision [S1, unofficial].
- **When to use:** Converting 2D heightmaps or grayscale images into 3D voxel data for games or simulations [G].
- **When not to use:** When high-resolution surface geometry is required [G].

## Background
This method is implemented in the FileToVox tool for converting various file formats into Minecraft-style `.vox` files [S1, unofficial]. The specific "Excavate" mode and heightmap generation logic are part of its image processing pipeline [S1, unofficial].
