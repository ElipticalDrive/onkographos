# Image-to-Voxel Heightmap Generation

Also called: Excavate mode height clipping, Grayscale heightmap extrusion

## Overview
This method converts a 2D image into a 3D voxel structure where pixel intensity determines voxel height along the Y-axis [S1, unofficial]. It supports standard vertical extrusion and an 'excavate' mode that clips voxel columns to the minimum height of their 4-connected neighbors [S1, unofficial]. It operates as a specific rasterization step within [Image-based Voxelization](12822-image-based-voxelization.md) [G].

## How it works
**Inputs:**
- A 2D image (grayscale or RGB) [S1, unofficial].
- `heightFactor` (float): Multiplier applied to normalized pixel intensity to determine voxel height. Typical value: 1 [S1, unofficial].
- `Excavate` (bool): Boolean flag. When true, enables neighbor-aware height clipping; when false, extrudes columns from the base plane (Y=0) [S1, unofficial].

**Outputs:**
- A list of 3D voxel coordinates $(x, y, z)$ representing the generated structure [S1, unofficial].

**Data Structures:**
- The image is treated as a 2D grid where image width maps to the X-axis and image height maps to the Z-axis [G].
- Pixel intensity determines the vertical Y-axis height [S1, unofficial].
- Channel values $I_c$ are accessed per pixel; $N_c$ tracks the number of channels present [S1, unofficial].

**Steps:**
1. **Initialize Output:** Create an empty list for voxels [S1, unofficial].
2. **Precompute Raw Heights:** Iterate through every pixel $(u, v)$ across image width $W$ and height $H$ [G]. Compute the raw height $h$ for each pixel using the intensity formula [S1, unofficial].
3. **Apply Excavation (if enabled):** For each pixel, check if all 4-connected neighbors exist within image bounds [S1, unofficial]. If any neighbor is out of bounds, skip clipping and use the raw height [S1, unofficial]. If all neighbors exist, find the minimum height $h_{min\_neighbor}$ among them and set $h_{final} = \min(h, h_{min\_neighbor})$ [S1, unofficial].
4. **Handle Edge Cases:** If $h_{final} \le 0$, place a single voxel at $y = \max(0, h - 1)$ instead of an empty column or negative height [S1, unofficial].
5. **Extrude Voxels:** For each $y$ from $0$ to $h_{final} - 1$, add a voxel at $(x=u, y=y, z=v)$ to the output list [S1, unofficial].

**Formula:**
$$ h = \left\lfloor \frac{\sum_{c=0}^{2} I_c}{\min(N_c, 3) \times 65535} \times H_{max} \right\rfloor $$
Where:
- $I_c$ is the value of channel $c$ (Red, Green, Blue) [S1, unofficial].
- $N_c$ is the number of channels (1 for grayscale, 3 for RGB) [S1, unofficial].
- $H_{max}$ is the `heightFactor` parameter [S1, unofficial].
- The denominator normalizes the channel sum against the maximum possible sum, using the constant 65535 [S1, unofficial].

**Pseudocode:**
```python
import math

def generate_heightmap_voxels(image, height_factor=1.0, excavate=False):
    """
    image: 2D array of pixels, shape (height, width).
           Each pixel is a list/tuple of channel values.
    height_factor: float, H_max
    excavate: bool
    """
    height, width = image.shape
    voxels = []
    raw_heights = [[0] * width for _ in range(height)]
    
    for v in range(height):
        for u in range(width):
            channels = image[v][u]
            n_c = len(channels)
            channel_sum = sum(channels)
            denominator = min(n_c, 3) * 65535
            if denominator == 0:
                h = 0
            else:
                h = math.floor((channel_sum / denominator) * height_factor)
            raw_heights[v][u] = h

    for v in range(height):
        for u in range(width):
            h = raw_heights[v][u]
            h_final = h

            if excavate:
                if (u - 1 >= 0 and u + 1 < width and
                    v - 1 >= 0 and v + 1 < height):
                    min_neighbor_h = float('inf')
                    for dv, du in [(-1, 0), (1, 0), (0, -1), (0, 1)]:
                        min_neighbor_h = min(min_neighbor_h, raw_heights[v + dv][u + du])
                    if h <= min_neighbor_h:
                        voxels.append((u, max(0, h - 1), v))
                        continue
                    h_final = min(h, min_neighbor_h)
                # If out of bounds, defaults to adding voxels from 0 to computed height [S1, unofficial]

            if h_final <= 0:
                if h > 0:
                    vy = max(0, h - 1)
                    voxels.append((u, vy, v))
                continue

            for vy in range(h_final):
                voxels.append((u, vy, v))

    return voxels
```

**Parameters:**
- `heightFactor`: Controls the vertical scale. Default 1 [S1, unofficial].
- `Excavate`: Boolean. Enables clipping to neighbor minimums [S1, unofficial].

**Edge Cases and Pitfalls:**
- **Boundary Pixels:** Pixels on the edge lack neighbors on one or more sides [S1, unofficial]. The implementation checks bounds explicitly (`if (param.X - 1 >= 0 && param.X + 1 < param.GrayscaleImage.Width && param.Y - 1 >= 0 && param.Y + 1 < param.GrayscaleImage.Height)`) [S1, unofficial]. If out of bounds, it defaults to adding voxels from 0 to the computed height [S1, unofficial].
- **Negative/Zero Height:** When excavating, if the computed height is less than or equal to the neighbor minimum, the algorithm places a single voxel at `max(0, height - 1)` instead of an empty column or negative height [S1, unofficial].
- **Precision:** The formula uses the constant 65535 for normalization [S1, unofficial]. Implementers must verify the input image's bit-depth matches this scaling factor, as 8-bit images (0-255) will yield near-zero heights unless `heightFactor` is adjusted or the denominator is modified [S1, unofficial].

## Operating characteristics
- **Time Complexity:** $O(W \times H)$, where $W$ and $H$ are image dimensions [G]. Neighbor lookups are constant-time (4 neighbors), preserving linear scaling [G].
- **Memory Complexity:** $O(W \times H)$ for the output voxel list [G]. Maximum voxel count scales with $W \times H \times H_{max}$ [G].
- **Strengths:** Simple to implement; generates terrain-like structures efficiently; "Excavate" mode reduces vertical artifacts and creates smoother transitions [S1, unofficial].
- **Limitations:** Resolution is strictly bound to the input image dimensions; height resolution depends on `heightFactor` and channel precision; boundary pixels may exhibit uneven edges due to missing neighbor data [S1, unofficial].
- **When to use:** Converting 2D heightmaps or grayscale images into 3D voxel data for games or simulations where performance is critical and high-fidelity surface detail is not required [S1, unofficial].
- **When not to use:** When high-resolution surface geometry is needed (use mesh extraction instead); when the input image is not a heightmap (e.g., color textures should be mapped differently) [S1, unofficial].
