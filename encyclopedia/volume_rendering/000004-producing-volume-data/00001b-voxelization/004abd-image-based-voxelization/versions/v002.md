# Image-based Voxelization

Also called: Custom Maps Generation, Multiple Image to Schematic Conversion, Picture-to-Voxel Forge

## Overview
Image-based Voxelization converts a sequence of 2D images into a 3D volumetric schematic where the image index maps to the depth axis (Y), and pixel coordinates map to the spatial axes (X and Z) [S2, unofficial]. It is distinguished from standard volume extrusion by its specific handling of surface boundaries via an "excavate" mode, which clips voxel columns based on neighbor transparency to create terraced structures rather than solid vertical walls [S2, unofficial].

## How it works
**Inputs and Outputs**
*   **Input**: A list of 2D images (PNG/JPG/JPEG), an optional 256x1 pixel color gradient file (`mInputColorFile`), a boolean `mExcavate` flag, and an integer `mColorLimit` [S2, unofficial].
*   **Output**: A `.npz` voxel volume containing a `Schematic` object with a list of voxels [S1, S2, unofficial].

**Data Structures**
*   **Voxel**: Defined by integer coordinates $(x, y, z)$ and a `Color` object. $x$ is the image pixel column index, $y$ is the image index in the input list (depth), and $z$ is the image pixel row index [S2, unofficial].
*   **Schematic**: Contains a list of voxels. Maximum world width and length are constrained by `Schematic.MAX_WORLD_WIDTH` and `Schematic.MAX_WORLD_LENGTH` [S2, unofficial].

**Parameters**
*   `mExcavate` (boolean): If `true`, only adds voxels at surface boundaries where neighbors are not all present; if `false`, adds all non-transparent/non-black pixels [S2, unofficial].
*   `mInputColorFile` (string path): Optional path to a 256x1 pixel color gradient file; if present, overrides pixel colors based on distance from the image center [S2, unofficial].
*   `mColorLimit` (integer): Limit for color quantization applied to the final voxel list [S2, unofficial].
*   `loadImageParam.Height`: Determines the vertical extent of voxels when not in single-voxel mode [S2, unofficial].

**Steps**
1.  **Validation**: If `mInputColorFile` is provided, verify its dimensions are exactly 256x1 pixels; otherwise, throw an `ArgumentException` [S2, unofficial]. Verify input image width $\le 256$ and height $\le 256$ (or `Schematic.MAX_WORLD_LENGTH`) [S2, unofficial].
2.  **Color Quantization**: If `mInputColorFile` is present and the image has more than 256 unique colors, or if `loadImageParam.EnableColor` is true, quantize the image colors to `mColorLimit` [S2, unofficial].
3.  **Iteration**: For each image index $i$ (representing the Y-axis):
    a. Load the image.
    b. Iterate through each pixel $(x, z)$ where $x \in [0, \text{width}-1]$ and $z \in [0, \text{height}-1]$.
    c. Retrieve pixel color channels (RGB and Alpha).
    d. **Skip Condition**: If the pixel is Empty, Transparent, Black, or has all RGB channels equal to zero, skip this pixel [S2, unofficial].
    e. **Color Override**: If `mInputColorFile` is present: calculate distance $d$ from the image center $(\text{height}/2, \text{height}/2)$ to pixel $(x, z)$; normalize $d$ to range $[0, 1]$; sample color from `mInputColorFile` at index $\lfloor \text{normalized\_d} \times (\text{colorWidth}-1) \rfloor$ [S2, unofficial].
    f. **Voxel Placement**: If `mExcavate` is `true`: call `CheckNeighbor(x, z)`. If any of the four 4-connected neighbors (left, top, right, bottom) is empty/transparent/black or has zero RGB, add a voxel at $(x, i, z)$ with the determined color [S2, unofficial]. If `mExcavate` is `false`: add a voxel at $(x, i, z)$ with the determined color [S2, unofficial].
4.  **Quantization**: Apply quantization to the blocks list using `mColorLimit` [S2, unofficial].
5.  **Finalization**: Create and return the `Schematic` from the quantized list [S2, unofficial].

**Pseudocode**
```python
import math

def image_based_voxelization(images, input_color_file=None, excavate=False, color_limit=256):
    """
    Convert a list of 2D images into a 3D schematic.
    
    Args:
        images: List of 2D image arrays (height, width, channels).
        input_color_file: Optional 256x1 color gradient array.
        excavate: Boolean flag for surface-only voxelization.
        color_limit: Integer for color quantization.
        
    Returns:
        List of tuples: (x, y, z, color)
    """
    voxels = []
    color_width = 256

    if input_color_file is not None:
        if len(input_color_file) != 1 or len(input_color_file[0]) != color_width:
            raise ValueError("Input color file must be exactly 256x1 pixels")

    for i, image in enumerate(images):
        height, width = image.shape[:2]
        if width > 256 or height > 256:
            raise ValueError("Image dimensions exceed maximum limits")

        for x in range(width):
            for z in range(height):
                pixel = image[z, x]
                r, g, b, a = pixel[:4]

                if a == 0 or (r == 0 and g == 0 and b == 0):
                    continue

                final_color = pixel[:3].copy()

                if input_color_file is not None:
                    center_x = height / 2
                    center_z = height / 2
                    dist = math.sqrt((x - center_x)**2 + (z - center_z)**2)
                    max_dist = math.sqrt((center_x)**2 + (center_z)**2)
                    normalized_dist = dist / max_dist if max_dist > 0 else 0.0
                    normalized_dist = max(0.0, min(1.0, normalized_dist))
                    color_idx = int(normalized_dist * (color_width - 1))
                    final_color = input_color_file[0, color_idx].copy()

                if excavate:
                    if is_surface_voxel(images, i, x, z, width, height):
                        voxels.append((x, i, z, tuple(final_color)))
                else:
                    voxels.append((x, i, z, tuple(final_color)))

    voxels = quantize_colors(voxels, color_limit)
    return voxels

def is_surface_voxel(images, y_idx, x, z, width, height):
    """Check if any 4-connected neighbor is empty/transparent/black."""
    neighbors = [(x - 1, z), (x + 1, z), (x, z - 1), (x, z + 1)]
    for nx, nz in neighbors:
        if nx < 0 or nx >= width or nz < 0 or nz >= height:
            return True
        neighbor_pixel = images[y_idx][nz, nx]
        r, g, b, a = neighbor_pixel[:4]
        if a == 0 or (r == 0 and g == 0 and b == 0):
            return True
    return False
```

## Subtopics

### [Image-to-Voxel Heightmap Generation](12828-image-to-voxel-heightmap-generation.md)
Converts a single 2D image into a 3D voxel structure by extruding voxel columns along the Y-axis, where pixel intensity determines the height. It is distinguished from standard volume extrusion by supporting an "excavate" mode that clips voxel columns to the minimum height of their 4-connected neighbors, creating terraced or smoothed terrain-like structures rather than vertical walls. It serves as a specific implementation within Image-based Voxelization for generating heightmaps from single images.

A specific chunk layout for the Picture-to-Voxel feature where Chunk row 0 contains a solid 16x16 launchpad runway at Z=0, Chunk row 1 is empty air, and Chunk row 2 contains the forged picture starting at Z=0 [S1, unofficial].

## Background
Originating from the FileToVox tool, this method is designed to convert 2D images into 3D Minecraft-style schematics [S2, unofficial]. It is part of a pipeline for generating voxel assets from image data, specifically targeting users who want to create 3D structures from 2D art or heightmaps [S1, unofficial]. It is used in conjunction with the Porter Pipeline & Space Flight Game and the Picture-to-Voxel Forge custom map generation workflow [S1, unofficial].
