# Voxelization of Lines and Planes

Also called: Slab-based Voxelization, N-separating Voxelization, 6-separating voxelization, 26-separating voxelization, 26-Separating Plane Voxelization

## Overview
This method generates a discrete volumetric representation of 2D lines or 3D planes that is both **N-separating** (topologically robust against N-connected ray penetration) and **N-minimal** (containing no redundant voxels) [S2]. It solves the problem of topological holes in voxelized surfaces by defining a "slab" of thickness $t$ around the geometric primitive, including only voxels whose centers fall within this slab [S2]. Unlike general rasterization-based voxelization [908-rasterization-based-voxelization], this analytic approach guarantees specific connectivity properties (4/8 for 2D, 6/26 for 3D) based on the surface normal and grid resolution, ensuring that 26-connected paths cannot pass through the discretized surface without intersecting a voxel [S1, unofficial].

## How it works
**Inputs:**
*   Geometric primitive: A 2D line defined by $A_p x + B_p y + D_p = 0$ or a 3D plane defined by $A_p X + B_p Y + C_p Z + D_p = 0$.
*   Normal vector $(A_p, B_p, C_p)$: Must be normalized such that $\sqrt{A_p^2 + B_p^2 + C_p^2} = 1$ [S2].
*   Grid parameters: Voxel width $L$ (typically 1.0 in normalized space), grid resolution $(N_x, N_y, N_z)$, and bounding box.
*   Separability type $N$: Either 6 or 26 for 3D planes; 4 or 8 for 2D lines [S2].

**Outputs:**
*   A set of voxel coordinates $\tilde{S}$ representing the voxelized primitive.

**Data Structures:**
*   A 3D boolean array or sparse set of coordinates $(x, y, z)$ where $x \in [0, N_x-1]$, etc.
*   Each voxel is classified as "black" (1, included) or "white" (0, excluded) [S2].

**Parameters:**
*   $t$: The half-thickness of the slab. The value depends on $N$, $L$, and the angle between the grid diagonal and the surface normal.
    *   For 26-separability (3D): $t_{26} = \frac{L}{2 \sqrt{3} \cos \alpha}$, where $\alpha$ is the angle between the voxel diagonal $K$ and the plane normal $N$ [S2].
    *   For 6-separability (3D): $t_6 = \frac{L}{2 \cos \beta}$, where $\beta$ is the angle between the normal to the voxel face and the plane normal [S2].
    *   For 8-separability (2D): $t_8 = \frac{L}{2 \cos \alpha}$, where $\alpha$ is the angle between the pixel diagonal and the line normal [S2].
    *   For 4-separability (2D): $t_4 = \frac{L}{2 \cos \beta}$, where $\beta$ is the angle between the normal to the pixel edge and the line normal [S2].
*   Note: The source text contains a garbled normalization formula $\frac{A_p^2 + B_p^2 + C_p^2}{2} = 1$, but explicitly states the standard normalization $\sqrt{A_p^2 + B_p^2 + C_p^2} = 1$ in Equation (3) [S2]. The standard interpretation is used.

**Steps:**
1.  **Define Slab Boundaries:** Construct two parallel planes (or lines in 2D) offset from the original surface by distance $t$.
    *   Original Plane: $A_p X + B_p Y + C_p Z + D_p = 0$ [S2].
    *   Slab Boundaries: $A_p X + B_p Y + C_p Z + D_p \pm t = 0$ [S2].
2.  **Iterate Voxels:** For each voxel center $(x, y, z)$ within the grid bounds:
3.  **Evaluate Distance:** Calculate the signed distance value $val$ from the voxel center to the original plane:
    $$val = A_p x + B_p y + C_p z + D_p$$
4.  **Classify:** If $-t \leq val \leq t$, mark the voxel as included (black/1). Otherwise, mark as excluded (white/0) [S2].
5.  **Handle Degeneracies:** If the surface passes exactly through a voxel corner, edge, or face, apply infinitesimal perturbation to the surface position or normal to ensure the intersection occurs strictly inside a voxel, avoiding ambiguous boundary cases [S1, unofficial].

**Pseudocode:**
```python
def voxelize_plane(Ap, Bp, Cp, Dp, L, Nx, Ny, Nz, separability_type):
    """
    Voxelize a 3D plane with guaranteed N-separability and N-minimality.
    
    Args:
        Ap, Bp, Cp: Normalized plane normal coefficients (sqrt(Ap^2+Bp^2+Cp^2) == 1).
        Dp: Plane constant.
        L: Voxel width (grid unit size).
        Nx, Ny, Nz: Grid dimensions.
        separability_type: '6' or '26'.
        
    Returns:
        A 3D list/array of booleans indicating voxel occupancy.
    """
    # 1. Calculate thickness t based on separability
    # Normalize normal if not already done (though input spec says it is normalized)
    norm = (Ap**2 + Bp**2 + Cp**2)**0.5
    if norm != 1.0:
        Ap, Bp, Cp = Ap/norm, Bp/norm, Cp/norm
        
    # Calculate angle alpha between voxel diagonal and plane normal
    # Voxel diagonal vector K = (1, 1, 1) in local grid coords (length sqrt(3))
    # Normal N = (Ap, Bp, Cp)
    # cos(alpha) = |N . K| / (|N| * |K|)
    # Since |N|=1 and |K|=sqrt(3):
    dot_product = abs(Ap + Bp + Cp)
    cos_alpha = dot_product / (1.0 * (3**0.5))
    
    # Avoid division by zero if normal is perpendicular to diagonal (rare in general position)
    if cos_alpha < 1e-9:
        cos_alpha = 1e-9

    if separability_type == '26':
        t = L / (2 * (3**0.5) * cos_alpha)
    elif separability_type == '6':
        # For 6-separability, t is derived from the face normal angle beta.
        # The source defines t_6 = L / (2 * cos(beta)).
        # In the context of the slab method for 6-separation, the critical distance 
        # is often simplified to L/2 for axis-aligned faces, but the general formula 
        # relies on the specific orientation. 
        # Note: Source [S2] Theorem 4 uses t_6. The derivation for t_6 involves 
        # the angle between the plane normal and the voxel face normal.
        # For a general plane, the tightest 6-separating slab thickness is L/2.
        # However, to maintain consistency with the "slab" definition using normal angles:
        # We use the maximum projection of the voxel half-width onto the normal.
        # The source implies t_6 is distinct from t_26. 
        # Standard 6-separation requires covering the voxel face. 
        # We use L/2 as the robust thickness for 6-separation in the absence of 
        # specific beta calculation in the provided text snippet for 3D planes.
        t = L / 2.0 
    else:
        raise ValueError("Separability type must be '6' or '26'")

    # 2. Initialize voxel grid
    voxels = [[[False for _ in range(Nz)] for _ in range(Ny)] for _ in range(Nx)]

    # 3. Iterate and classify
    for x in range(Nx):
        for y in range(Ny):
            for z in range(Nz):
                # Evaluate signed distance
                val = Ap * x + Bp * y + Cp * z + Dp
                
                # Check if inside slab [-t, t]
                if -t <= val <= t:
                    voxels[x][y][z] = True
                else:
                    voxels[x][y][z] = False
                    
    return voxels
```

**Edge Cases and Pitfalls:**
*   **Degeneracies:** If the plane passes exactly through a voxel corner, standard intersection tests may fail or produce ambiguous results. The method requires infinitesimal perturbation to ensure the intersection target lies strictly inside a voxel [S1, unofficial].
*   **Precision:** Floating-point errors in the distance calculation $A_p x + B_p y + C_p z + D_p$ can lead to incorrect inclusion/exclusion near the boundary $t$. High-precision arithmetic or careful epsilon handling is recommended [S2].
*   **Minimality vs. Separability:** Using a thickness $t$ smaller than the derived $t_{26}$ or $t_6$ will result in "holes" (N-holes) where N-connected paths can penetrate the surface. Using a larger $t$ violates minimality by including unnecessary voxels [S2].

## Subtopics

### [4-Separating Line Voxelization](2502-4-separating-line-voxelization.md)
A method to generate a discrete representation of a 2D line that is 4-separating (no 4-holes) and 4-minimal. It uses the same slab-based principle but in 2D with thickness $t_4 = \frac{L}{2 \cos \beta}$.

### [4-Separating Line Voxelization](2502-4-separating-line-voxelization.md)
(Implicit sibling) A 2D line voxelization method ensuring 8-separability with thickness $t_8 = \frac{L}{2 \cos \alpha}$.

## Operating characteristics
*   **Time Complexity:** $O(N_x N_y N_z)$ for a full grid scan. The method requires iterating over all voxels in the bounding volume to evaluate the distance function. An incremental algorithm could optimize this, but the source notes that the provided implementation is a non-optimized scan conversion [S2].
*   **Memory Complexity:** $O(N_x N_y N_z)$ for the voxel grid. Sparse representations can reduce this if the grid is large and the primitive is small.
*   **Performance:** Measured in VPM (Voxels Per Millisecond). Performance decreases as the number of voxels increases due to linked list maintenance costs in the implementation [S2]. For a $256^3$ grid, the method is computationally feasible but slower than 6-separating variants due to the higher voxel count [S2].
*   **Strengths:** Guarantees topological correctness (separability and minimality) for planes and polygons. Eliminates artifacts at edges and vertices common in other methods [S2]. Visually indistinguishable from 6-separating models in rendering [S2].
*   **Limitations:** 26-separating voxelization produces significantly more Vertex and Edge voxels than 6-separating voxelization, increasing memory and processing time [S2]. Not inherently optimized for sparse grids without additional data structures.
*   **When to use:** When topological robustness is critical (e.g., ray casting, collision detection) and the input is a planar surface or polygon mesh.
*   **When not to use:** When performance is paramount and topological holes are acceptable (use 6-separating or rasterization-based methods).

## Background
The method originates from the need to create discrete surfaces that preserve the topological properties of continuous surfaces, specifically regarding connectivity and separation [S1, unofficial][S2]. Early work focused on 2D polygon scan-conversion [S2]. The specific slab-based approach for 3D planes was introduced to guarantee both N-separability and N-minimality, addressing deficiencies in existing algorithms that failed to handle edges and vertices correctly [S2]. The 26-separating property was analyzed by Cohen-Or and Kaufman [COK97, COK95], who showed that a full 3D voxel cover is 26-separating, but this method provides a minimal cover [S1, unofficial]. The technique is applicable to polygon meshes by combining vertex, edge, and body voxel sets [S2].
