# Curve Voxelization

Also called: 1D Input Voxelization (Curves), 1D inputs, 2D targets, Line Segment Voxelization, voxelizeCurve

## Overview
Curve Voxelization maps 1D geometric inputs (curves, polylines, or line segments) into a 3D voxel grid while guaranteeing specific topological connectivity (6-connected or 26-connected) in the output. It solves the problem of preserving the continuity of thin features in discrete volumetric representations, ensuring that adjacent voxels in the result are connected via faces (6-connectivity) or faces and edges/corners (26-connectivity) without gaps. It sets itself apart from standard rasterization methods by using **Intersection Targets**—geometric primitives dual to the input dimension—to determine voxel occupancy, rather than simple distance thresholds or ray-casting against voxel boundaries [S1, S2].

## How it works
The method relies on the principle of **Topological Voxelization**, which uses Poincaré Duality to define "Intersection Targets" inside each candidate voxel. For 1D inputs, the target is a 2D feature (faces or planes) within the 3D voxel space [S1, S2].

### Inputs and Outputs
*   **Input**:
    *   `curves`: A list of 1D geometric objects (curves, polylines, or line segments).
    *   `connectivity`: An integer specifying the desired adjacency level: `6` or `26`.
    *   `vSize`: A 3D vector `[sx, sy, sz]` defining the dimensions of a single voxel.
*   **Output**:
    *   `voxels`: A list of 3D points representing the centers of occupied voxels.

### Data Structures
*   **Voxel Point**: A 3D coordinate $(x, y, z)$ representing the center of a voxel.
*   **Bounding Box (BBox)**: Defined by minimum and maximum coordinates $(x_{min}, y_{min}, z_{min})$ and $(x_{max}, y_{max}, z_{max})$.
*   **Intersection Target**: A geometric mesh (list of triangles) defined relative to a voxel center and size.

### Algorithm Steps

1.  **Initialization**:
    For each curve in `curves`:
    a. Compute the axis-aligned bounding box ($RBBox$) of the curve in $\mathbb{R}^3$.
    b. Define the voxel size vector $vSize = [sx, sy, sz]$.
    c. Convert the real-world bounding box to a zero-based integer grid bounding box ($ZBBox$) aligned with the voxel grid. This is done by scaling the $RBBox$ by $vSize$ and rounding appropriately to ensure coverage [S1, S2].
    d. Generate a list of all voxel center points (`VoxelPoints`) within $ZBBox$ using a grid generation function `BBoxToVoxels(ZBBox, vSize)`.

2.  **Filtering (Candidate Selection)**:
    Filter `VoxelPoints` to keep only those "near" the curve. A voxel point $P$ is considered near if its Euclidean distance to the curve is less than half the length of the voxel diagonal:
    $$ |P - \text{Curve}| < \frac{|vSize|}{2} $$
    where $|vSize| = \sqrt{sx^2 + sy^2 + sz^2}$. Let the resulting list be `near_voxel_points` [S1, S2].

3.  **Intersection Testing**:
    Initialize an empty list `voxels`.
    For each `voxel_point` in `near_voxel_points`:
    a. **Construct Intersection Target**:
       Based on the `connectivity` parameter, construct a specific geometric target inside the voxel centered at `voxel_point`:
       *   If `connectivity == 6`: Create the **1D_6_intersectionTarget**. This consists of the **6 faces** of the voxel cube.
       *   If `connectivity == 26`: Create the **1D_26_intersectionTarget**. This consists of **3 plane faces** cutting the voxel in half along the X, Y, and Z axes, meeting at the voxel center (forming a 3D crosshair structure).
       *   If `connectivity` is neither 6 nor 26, throw an exception [S1, S2].
    b. **Check Intersection**:
       Test if the input `curve` intersects the constructed `intersectionTarget`.
       *   Note: The curve may be approximated as a polyline of line segments for this test. The intersection test `TriangleIntersectLine` checks if the line segment intersects any triangle in the target mesh using barycentric coordinates [S1, S2].
    c. **Add to Output**:
       If an intersection is detected, add `voxel_point` to `voxels`.

4.  **Return**:
    Return the `voxels` list.

### Pseudocode

```python
def voxelizeCurve(curves, connectivity, sx, sy, sz):
    """
    Voxelize 1D curves into a 3D grid with guaranteed connectivity.
    
    Args:
        curves: List of curve objects (supporting bounding box and intersection tests).
        connectivity: Integer, 6 or 26.
        sx, sy, sz: Floats, voxel dimensions.
        
    Returns:
        List of 3D points (centers of occupied voxels).
    """
    voxels = []
    vSize = [sx, sy, sz]
    vSize_norm = sqrt(sx**2 + sy**2 + sz**2)
    half_diag = vSize_norm / 2.0

    for curve in curves:
        # 1. Bounding Box Setup
        rbbox = curve.get_bounding_box() # Returns (min_x, min_y, min_z, max_x, max_y, max_z)
        
        # Convert Real BBox to Zero-based Grid BBox
        # Assuming voxel grid starts at (0,0,0) and aligns with axes
        # This step scales the real coordinates to grid indices
        zbbox = rbbox_to_zbbox(rbbox, vSize)
        
        # 2. Generate Candidate Voxels
        voxel_points = bbox_to_voxels(zbbox, vSize)
        
        # 3. Filter by Distance
        near_voxel_points = []
        for p in voxel_points:
            # Distance from point p to curve
            dist = point_to_curve_distance(p, curve)
            if dist < half_diag:
                near_voxel_points.append(p)
        
        # 4. Intersection Testing
        for p in near_voxel_points:
            # Construct Intersection Target
            if connectivity == 6:
                target = create_1d_6_intersection_target(p, vSize)
            elif connectivity == 26:
                target = create_1d_26_intersection_target(p, vSize)
            else:
                raise ValueError("Connectivity must be 6 or 26")
            
            # Check Intersection
            # Note: curve might need to be decomposed into line segments for TriangleIntersectLine
            if triangle_intersect_line(target, curve):
                voxels.append(p)
                
    return voxels

def create_1d_6_intersection_target(center, vSize):
    """
    Returns a mesh of 6 triangles representing the 6 faces of the voxel cube.
    """
    sx, sy, sz = vSize
    cx, cy, cz = center
    
    # Define the 8 corners of the voxel
    corners = [
        [cx - sx/2, cy - sy/2, cz - sz/2],
        [cx + sx/2, cy - sy/2, cz - sz/2],
        [cx + sx/2, cy + sy/2, cz - sz/2],
        [cx - sx/2, cy + sy/2, cz - sz/2],
        [cx - sx/2, cy - sy/2, cz + sz/2],
        [cx + sx/2, cy - sy/2, cz + sz/2],
        [cx + sx/2, cy + sy/2, cz + sz/2],
        [cx - sx/2, cy + sy/2, cz + sz/2]
    ]
    
    # Define 6 faces as pairs of triangles
    # Face -X, +X, -Y, +Y, -Z, +Z
    triangles = [
        # -X face
        [corners[0], corners[3], corners[4]], [corners[3], corners[7], corners[4]],
        # +X face
        [corners[1], corners[2], corners[5]], [corners[2], corners[6], corners[5]],
        # -Y face
        [corners[0], corners[1], corners[4]], [corners[1], corners[5], corners[4]],
        # +Y face
        [corners[3], corners[2], corners[7]], [corners[2], corners[6], corners[7]],
        # -Z face
        [corners[0], corners[1], corners[3]], [corners[1], corners[2], corners[3]],
        # +Z face
        [corners[4], corners[5], corners[7]], [corners[5], corners[6], corners[7]]
    ]
    return triangles

def create_1d_26_intersection_target(center, vSize):
    """
    Returns a mesh representing 3 plane faces cutting the voxel in halves along X, Y, Z axes.
    This forms a 3D crosshair structure.
    """
    sx, sy, sz = vSize
    cx, cy, cz = center
    
    # The target consists of 3 rectangles intersecting at the center.
    # Each rectangle is split into 2 triangles.
    
    # Plane X (cutting along Y-Z plane at center X)
    # Vertices: (cx, cy-sy/2, cz-sz/2), (cx, cy+sy/2, cz-sz/2), (cx, cy+sy/2, cz+sz/2), (cx, cy-sy/2, cz+sz/2)
    tri_x1 = [[cx, cy - sy/2, cz - sz/2], [cx, cy + sy/2, cz - sz/2], [cx, cy + sy/2, cz + sz/2]]
    tri_x2 = [[cx, cy - sy/2, cz - sz/2], [cx, cy + sy/2, cz + sz/2], [cx, cy - sy/2, cz + sz/2]]
    
    # Plane Y (cutting along X-Z plane at center Y)
    tri_y1 = [[cx - sx/2, cy, cz - sz/2], [cx + sx/2, cy, cz - sz/2], [cx + sx/2, cy, cz + sz/2]]
    tri_y2 = [[cx - sx/2, cy, cz - sz/2], [cx + sx/2, cy, cz + sz/2], [cx - sx/2, cy, cz + sz/2]]
    
    # Plane Z (cutting along X-Y plane at center Z)
    tri_z1 = [[cx - sx/2, cy - sy/2, cz], [cx + sx/2, cy - sy/2, cz], [cx + sx/2, cy + sy/2, cz]]
    tri_z2 = [[cx - sx/2, cy - sy/2, cz], [cx + sx/2, cy + sy/2, cz], [cx - sx/2, cy + sy/2, cz]]
    
    return tri_x1 + tri_x2 + tri_y1 + tri_y2 + tri_z1 + tri_z2
```

### Parameters and Typical Values
*   **connectivity**: `6` (face-adjacent) or `26` (face/edge/corner-adjacent). No other values are supported [S1, S2].
*   **vSize**: Determines resolution. Smaller values increase accuracy but also computational cost.
*   **Distance Threshold**: Half the voxel diagonal ($|vSize|/2$) is used as the initial filter [S1, S2].

### Edge Cases and Pitfalls
*   **Invalid Connectivity**: If `connectivity` is not 6 or 26, the algorithm throws an exception [S1, S2].
*   **Curve Approximation**: The intersection test `TriangleIntersectLine` requires the curve to be decomposed into line segments (polylines). High-curvature curves must be sufficiently tessellated to avoid missing intersections with the thin intersection targets [S1, S2].
*   **Precision**: Floating-point precision in distance calculations and intersection tests can lead to gaps or spurious voxels. Robust geometric predicates are recommended for the intersection test [S1, S2].

## Operating characteristics
*   **Time Complexity**: $O(N \cdot M)$, where $N$ is the number of voxels in the bounding box and $M$ is the number of line segments in the curve approximation. The distance filter reduces $N$ to "near" voxels.
*   **Memory Complexity**: $O(N)$ to store the voxel points and intersection targets.
*   **Performance**: Efficient for sparse curves as it iterates over objects (curves) rather than the entire space. However, for large meshes (e.g., TINs), decomposition into primitives is necessary [S1, S2].
*   **Strengths**: Guarantees topological connectivity (6 or 26). Mathematically proven to be "minimally thin" (no unnecessary voxels) [S1, S2].
*   **Limitations**: Requires curve tessellation. Not suitable for 0D (points) or 2D (surfaces) without different targets [S1, S2].

## Background
The method is based on **Topological Voxelization**, introduced by Laine [1], which uses Poincaré Duality to define intersection targets. The specific implementation for 1D inputs (curves) was detailed in geospatial applications by [S1, S2]. The approach ensures that the raster output preserves the topological properties of the vector input.
