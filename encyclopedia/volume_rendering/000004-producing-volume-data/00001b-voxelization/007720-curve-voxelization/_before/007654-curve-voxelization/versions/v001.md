# Curve Voxelization

Also called: 1D Input Voxelization (Curves), 1D inputs, 2D targets, voxelizeCurve

## Overview
Curve Voxelization maps 1D geometric inputs (lines, polylines, or curves) into a 3D voxel grid while guaranteeing specific topological connectivity levels (6-connected or 26-connected) in the output [S1]. Unlike standard rasterization which may produce fragmented or disconnected voxel chains for thin features, this method uses "intersection targets" derived from Poincaré Duality to ensure that every voxel containing part of the curve is topologically linked to its neighbors [S1]. It sets itself apart from sibling methods like [VoxelGrid from Mesh (Fill Method)](1013-voxelgrid-from-mesh-fill-method.md) by focusing on minimal, connectivity-preserving digitization of 1D primitives rather than filling solid volumes or processing surface meshes [S1].

## How it works
**Inputs:**
*   `curves`: A list of 1D geometric objects (lines, polylines, or curves).
*   `connectivity`: An integer specifying the desired adjacency level (6 or 26).
*   `vSize`: A vector $[s_x, s_y, s_z]$ defining the voxel dimensions.
*   `bounding_box`: The spatial domain for the output.

**Outputs:**
*   `voxels`: A list of 3D points representing the centers of the voxels that intersect the curve.

**Data Structures:**
*   **Voxel Point**: A 3D coordinate $(x, y, z)$ representing the center of a voxel.
*   **Intersection Target**: A geometric primitive (triangle mesh for 6/26 connectivity of 1D inputs, or line arrays for 2D inputs) defined relative to a voxel center.
*   **Line Segment**: Defined by two endpoints $P_1, P_2$.

**Algorithm Steps:**

1.  **Initialization**:
    *   Initialize an empty list `voxels`.
    *   Define voxel size $vSize = [s_x, s_y, s_z]$.

2.  **Iterate over Curves**:
    *   For each `curve` in `curves`:
        *   Compute the axis-aligned bounding box (AABB) of the curve in $\mathbb{R}^3$.
        *   Convert the curve's bounding box to a voxel-aligned bounding box ($ZBBox$) using `RBBox_to_ZBBox`. This ensures the voxel grid covers the curve completely [S1].
        *   Generate all potential voxel center points within $ZBBox$ using `BBoxToVoxels(ZBBox, vSize)`. Let this set be $V_{all}$ [S1].

3.  **Filter Candidate Voxels**:
    *   Filter $V_{all}$ to keep only voxel centers `v_point` that are closer to the `curve` than half the diagonal length of the voxel.
    *   Condition: $|v\_point - C| < \frac{|vSize|}{2}$, where $C$ is the closest point on the curve to `v_point` and $|vSize| = \sqrt{s_x^2 + s_y^2 + s_z^2}$ [S1].
    *   Let the filtered set be $V_{near}$ [G]. *Note: The source uses `lambda | lambda.DistanceTo(Curve) < |vSize|/2`.*

4.  **Connectivity Check**:
    *   For each `v_point` in $V_{near}$:
        *   If `connectivity` == 26:
            *   Generate the 26-connected intersection target $T_{26}$ using `1D_26_intersectionTarget(v_point, vSize)` [S1].
        *   Else if `connectivity` == 6:
            *   Generate the 6-connected intersection target $T_{6}$ using `1D_6_intersectionTarget(v_point, vSize)` [S1].
        *   Else:
            *   Throw an exception ("other connectivity levels undefined") [S1].

5.  **Intersection Test**:
    *   Check if the curve intersects the intersection target $T$.
    *   The source notes that the implementation may use `Rhinocommon`'s Curve-Mesh intersection or a line-triangle intersection algorithm if the curve is approximated as a polyline [S1].
    *   If `TriangleIntersectLine(T, curve)` returns true:
        *   Add `v_point` to `voxels` [S1].

6.  **Return**:
    *   Return `voxels` [S1].

**Intersection Target Definitions:**

*   **1D_6_intersectionTarget**: Represents the 6 faces of the voxel cube. Intersecting the curve with any of these faces ensures the voxel is part of a 6-connected chain (face-adjacent) [S1].
*   **1D_26_intersectionTarget**: Represents a 3D crosshair centered at the voxel cube, consisting of 3 plane faces cutting the voxel in halves along the X, Y, and Z axes, meeting at the center. Intersecting the curve with this target ensures 26-connectivity (corner/edge/face adjacent) [S1].

**Pseudocode:**

```python
def voxelizeCurve(curves, connectivity, vSize):
    """
    Voxelize 1D curves with guaranteed connectivity.
    
    Args:
        curves: List of curve objects (supporting bounding box and intersection tests).
        connectivity: Integer, 6 or 26.
        vSize: Tuple (sx, sy, sz) of voxel dimensions.
        
    Returns:
        List of 3D points (voxel centers).
    """
    voxels = []
    diag_len = (vSize[0]**2 + vSize[1]**2 + vSize[2]**2)**0.5
    threshold = diag_len / 2.0
    
    for curve in curves:
        # 1. Get bounding box of the curve
        rbbox = curve.get_bounding_box()
        
        # 2. Convert to voxel-aligned bounding box
        zbbox = rbbox_to_zbbox(rbbox, vSize)
        
        # 3. Generate all voxel centers in the bounding box
        # Assuming BBoxToVoxels returns a list of (x, y, z) tuples
        voxel_points = bbox_to_voxels(zbbox, vSize)
        
        # 4. Filter points close to the curve
        near_voxel_points = []
        for v_point in voxel_points:
            # Calculate distance from voxel center to the curve
            dist = curve.distance_to_point(v_point)
            if dist < threshold:
                near_voxel_points.append(v_point)
        
        # 5. Check intersection with connectivity target
        for v_point in near_voxel_points:
            if connectivity == 26:
                target = create_1d_26_intersection_target(v_point, vSize)
            elif connectivity == 6:
                target = create_1d_6_intersection_target(v_point, vSize)
            else:
                raise ValueError("Connectivity must be 6 or 26")
            
            # Check if curve intersects the target
            # Note: If curve is a polyline, approximate with line segments
            if curve_intersects_target(curve, target):
                voxels.append(v_point)
                
    return voxels

def create_1d_6_intersection_target(v_point, vSize):
    """
    Creates a triangle mesh representing the 6 faces of a voxel.
    Returns a list of triangles (each triangle is 3 points).
    """
    sx, sy, sz = vSize
    cx, cy, cz = v_point
    
    # Define the 8 corners of the voxel relative to center
    # Corners: (+/-sx/2, +/-sy/2, +/-sz/2)
    corners = []
    for dx in [-sx/2, sx/2]:
        for dy in [-sy/2, sy/2]:
            for dz in [-sz/2, sz/2]:
                corners.append((cx + dx, cy + dy, cz + dz))
    
    # Define the 6 faces as triangles
    # Face 1: +X (corners 4,5,6,7 -> split into 2 triangles)
    # Face 2: -X
    # Face 3: +Y
    # Face 4: -Y
    # Face 5: +Z
    # Face 6: -Z
    # Standard ordering for a cube centered at origin with corners indexed:
    # 0:(-,-,-), 1:(+,-,-), 2:(-,+,-), 3:(+,+,-), 4:(-,-,+), 5:(+,-,+), 6:(-,+,+), 7:(+,+,+)
    # Re-indexing based on generation order above:
    # 0:(-,-,-), 1:(+,-,-), 2:(-,-,+), 3:(+,-,+), 4:(-,+,-), 5:(+,+,-), 6:(-+,+), 7:(+,+,+)
    
    # Simplified: Return a mesh object or list of triangles
    # For the purpose of intersection, we can return a list of triangles
    triangles = []
    
    # Helper to add two triangles for a quad defined by 4 points
    def add_quad(p0, p1, p2, p3):
        triangles.append((p0, p1, p2))
        triangles.append((p0, p2, p3))

    # +X face (x = cx + sx/2)
    p0 = (cx + sx/2, cy - sy/2, cz - sz/2)
    p1 = (cx + sx/2, cy + sy/2, cz - sz/2)
    p2 = (cx + sx/2, cy + sy/2, cz + sz/2)
    p3 = (cx + sx/2, cy - sy/2, cz + sz/2)
    add_quad(p0, p1, p2, p3)
    
    # -X face
    p0 = (cx - sx/2, cy - sy/2, cz - sz/2)
    p1 = (cx - sx/2, cy - sy/2, cz + sz/2)
    p2 = (cx - sx/2, cy + sy/2, cz + sz/2)
    p3 = (cx - sx/2, cy + sy/2, cz - sz/2)
    add_quad(p0, p1, p2, p3)
    
    # +Y face
    p0 = (cx - sx/2, cy + sy/2, cz - sz/2)
    p1 = (cx + sx/2, cy + sy/2, cz - sz/2)
    p2 = (cx + sx/2, cy + sy/2, cz + sz/2)
    p3 = (cx - sx/2, cy + sy/2, cz + sz/2)
    add_quad(p0, p1, p2, p3)
    
    # -Y face
    p0 = (cx - sx/2, cy - sy/2, cz - sz/2)
    p1 = (cx - sx/2, cy - sy/2, cz + sz/2)
    p2 = (cx + sx/2, cy - sy/2, cz + sz/2)
    p3 = (cx + sx/2, cy - sy/2, cz - sz/2)
    add_quad(p0, p1, p2, p3)
    
    # +Z face
    p0 = (cx - sx/2, cy - sy/2, cz + sz/2)
    p1 = (cx + sx/2, cy - sy/2, cz + sz/2)
    p2 = (cx + sx/2, cy + sy/2, cz + sz/2)
    p3 = (cx - sx/2, cy + sy/2, cz + sz/2)
    add_quad(p0, p1, p2, p3)
    
    # -Z face
    p0 = (cx - sx/2, cy - sy/2, cz - sz/2)
    p1 = (cx - sx/2, cy + sy/2, cz - sz/2)
    p2 = (cx + sx/2, cy + sy/2, cz - sz/2)
    p3 = (cx + sx/2, cy - sy/2, cz - sz/2)
    add_quad(p0, p1, p2, p3)
    
    return triangles

def create_1d_26_intersection_target(v_point, vSize):
    """
    Creates a 3D crosshair (3 plane faces) centered at the voxel.
    Returns a list of triangles representing the 3 intersecting planes.
    """
    sx, sy, sz = vSize
    cx, cy, cz = v_point
    
    triangles = []
    
    # Plane X (cutting along YZ plane at center)
    # Vertices: (cx, cy-sy/2, cz-sz/2), (cx, cy+sy/2, cz-sz/2), (cx, cy+sy/2, cz+sz/2), (cx, cy-sy/2, cz+sz/2)
    p0 = (cx, cy - sy/2, cz - sz/2)
    p1 = (cx, cy + sy/2, cz - sz/2)
    p2 = (cx, cy + sy/2, cz + sz/2)
    p3 = (cx, cy - sy/2, cz + sz/2)
    triangles.append((p0, p1, p2))
    triangles.append((p0, p2, p3))
    
    # Plane Y (cutting along XZ plane at center)
    p0 = (cx - sx/2, cy, cz - sz/2)
    p1 = (cx + sx/2, cy, cz - sz/2)
    p2 = (cx + sx/2, cy, cz + sz/2)
    p3 = (cx - sx/2, cy, cz + sz/2)
    triangles.append((p0, p1, p2))
    triangles.append((p0, p2, p3))
    
    # Plane Z (cutting along XY plane at center)
    p0 = (cx - sx/2, cy - sy/2, cz)
    p1 = (cx + sx/2, cy - sy/2, cz)
    p2 = (cx + sx/2, cy + sy/2, cz)
    p3 = (cx - sx/2, cy + sy/2, cz)
    triangles.append((p0, p1, p2))
    triangles.append((p0, p2, p3))
    
    return triangles

def curve_intersects_target(curve, target_triangles):
    """
    Checks if the curve intersects any triangle in the target.
    If curve is a polyline, iterate over segments.
    """
    # If curve is a complex NURBS/Bezier, use library intersection or approximate as polyline
    # Here we assume curve can be approximated or has a direct intersection method
    if hasattr(curve, 'get_segments'):
        segments = curve.get_segments()
        for seg in segments:
            if line_intersects_triangles(seg, target_triangles):
                return True
    else:
        # Fallback: if direct intersection method exists
        if hasattr(curve, 'intersects_mesh'):
            return curve.intersects_mesh(target_triangles)
        # Approximate as single segment if no segments available
        if hasattr(curve, 'get_start') and hasattr(curve, 'get_end'):
            seg = (curve.get_start(), curve.get_end())
            if line_intersects_triangles(seg, target_triangles):
                return True
    return False

def line_intersects_triangles(line_seg, triangles):
    """
    Checks if a line segment intersects any triangle in the list.
    Uses Möller–Trumbore intersection algorithm.
    """
    p1, p2 = line_seg
    for t in triangles:
        v0, v1, v2 = t
        if triangle_intersects_line(v0, v1, v2, p1, p2):
            return True
    return False

def triangle_intersects_line(v0, v1, v2, p1, p2):
    """
    Möller–Trumbore intersection algorithm.
    Returns True if line segment p1-p2 intersects triangle v0-v1-v2.
    """
    epsilon = 1e-8
    edge1 = (v1[0]-v0[0], v1[1]-v0[1], v1[2]-v0[2])
    edge2 = (v2[0]-v0[0], v2[1]-v0[1], v2[2]-v0[2])
    direction = (p2[0]-p1[0], p2[1]-p1[1], p2[2]-p1[2])
    
    # Calculate determinant
    det = edge1[0]*(edge2[1]*direction[2] - edge2[2]*direction[1]) - \
          edge1[1]*(edge2[0]*direction[2] - edge2[2]*direction[0]) + \
          edge1[2]*(edge2[0]*direction[1] - edge2[1]*direction[0])
    
    if det > -epsilon and det < epsilon:
        return False # Parallel
    
    inv_det = 1.0 / det
    
    # Calculate u, v, t
    diff = (p1[0]-v0[0], p1[1]-v0[1], p1[2]-v0[2])
    u = (diff[0]*(edge2[1]*direction[2] - edge2[2]*direction[1]) - \
         diff[1]*(edge2[0]*direction[2] - edge2[2]*direction[0]) + \
         diff[2]*(edge2[0]*direction[1] - edge2[1]*direction[0])) * inv_det
    
    if u < 0.0 or u > 1.0:
        return False
        
    v = (diff[0]*(edge1[2]*direction[1] - edge1[1]*direction[2]) - \
         diff[1]*(edge1[0]*direction[2] - edge1[2]*direction[0]) + \
         diff[2]*(edge1[0]*direction[1] - edge1[1]*direction[0])) * inv_det
        
    if v < 0.0 or u + v > 1.0:
        return False
        
    t = (diff[0]*(edge1[1]*edge2[2] - edge1[2]*edge2[1]) - \
         diff[1]*(edge1[0]*edge2[2] - edge1[2]*edge2[0]) + \
         diff[2]*(edge1[0]*edge2[1] - edge1[1]*edge2[0])) * inv_det
         
    if t < 0.0 or t > 1.0:
        return False
        
    return True
```

## Subtopics

### [1D_6_intersectionTarget](23476-1d-6-intersectiontarget.md)
The `1D_6_intersectionTarget` method generates a specific 3D mesh geometry used as an "intersection target" within each candidate voxel during the voxelization of 1D inputs (lines, polylines, or curves). Its primary purpose is to guarantee 6-connectivity (face-adjacency) in the resulting voxel set by ensuring that any curve passing through a voxel intersects this internal mesh. Unlike the cube outline target, which traces the voxel edges, this method uses a diagonal mesh structure composed of triangles to determine intersection. It is a core component of the Curve Voxelization pipeline, specifically designed to resolve the topological connectivity of the output volume data.

## Operating characteristics
*   **Time Complexity**: The algorithm iterates over all voxels in the bounding box of the curve. The number of candidate voxels is proportional to the surface area of the curve's bounding box divided by the voxel volume, filtered by proximity. For each candidate, a line-triangle intersection test is performed. The complexity is $O(N_v \cdot N_t)$, where $N_v$ is the number of candidate voxels and $N_t$ is the number of triangles in the intersection target (constant, 12 for 6-connected, 6 for 26-connected).
*   **Memory Complexity**: $O(N_v)$ to store the list of voxel centers.
*   **Performance**: The method is efficient for sparse curves because it only processes voxels near the curve [S1]. However, for large meshes (e.g., TIN terrain models), decomposing into primitives and iterating can be inefficient if not optimized [S1].
*   **Strengths**: Guarantees topological connectivity (6 or 26) which is critical for applications like skeletonization or graph-based analysis of voxelized data [S1]. It produces "minimally thin" results, avoiding over-segmentation [S1].
*   **Limitations**: Requires the curve to be decomposable into line segments or support intersection tests. Precision issues may arise with floating-point arithmetic in intersection tests [G].
*   **When to use**: When topological connectivity of 1D features is required in the voxel output.
*   **When not to use**: When solid volume filling is required, or when the input is a surface mesh (use [Textured Mesh to Volumetric Attribute Voxelization](2760-textured-mesh-to-volumetric-attribute-voxelization.md) or surface variants).

## Background
The method is based on the topological voxelization approach introduced by Laine [1], which uses Poincaré Duality to define "intersection targets" that guarantee connectivity levels [S1]. The specific implementation for 1D inputs (curves) was detailed in "Voxelization algorithms for geospatial applications" [S1], which presented algorithms for point, curve, and surface objects. The work builds on earlier mathematical proofs by Laine regarding the duality between input features and intersection targets [S1]. The implementation described in the source uses Rhinocommon for curve-mesh intersection but can be adapted to standard line-triangle intersection algorithms [S1].
