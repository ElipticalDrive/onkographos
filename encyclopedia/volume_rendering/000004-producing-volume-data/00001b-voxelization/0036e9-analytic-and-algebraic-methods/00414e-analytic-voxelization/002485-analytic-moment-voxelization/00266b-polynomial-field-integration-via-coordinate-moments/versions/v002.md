# Polynomial Field Integration via Coordinate Moments

Also called: Coordinate Moment Integration, Polynomial Coefficient Integration

## Overview
This method computes the integral of arbitrary scalar fields (or component-wise vector fields) over a voxel by evaluating coordinate moments and combining them via polynomial coefficients [S1, unofficial]. It allows the simultaneous integration of multiple fields without re-clipping voxels [S1, unofficial]. It builds on [Analytic Moment Voxelization](3307-analytic-moment-voxelization.md) [G].

## How it works
**Inputs:**
- A voxel volume $V$ [G].
- A scalar field $f(x,y,z)$ represented as a polynomial of order $N$ [G].
- The polynomial coefficients of $f$ [S1, unofficial].

**Outputs:**
- The integral $\int_V f(x,y,z) \, dV$ [S1, unofficial].

**Data Structures:**
- **Coordinate Moments:** A list or array storing values of $\int_V x^i y^j z^k \, dV$ for all monomials up to order $N$ [S1, unofficial]. For a second-order polynomial, this includes $\int_V 1 \, dV, \int_V x \, dV, \int_V y \, dV, \int_V z \, dV, \int_V x^2 \, dV, \int_V y^2 \, dV, \int_V z^2 \, dV, \int_V xy \, dV, \int_V xz \, dV, \int_V yz \, dV$ [S1, unofficial].
- **Polynomial Coefficients:** A vector or array containing the weights $A, B, C, \dots, J$ for the polynomial terms [S1, unofficial].

**Steps:**
1. Find the integral over each coordinate moment ($\int_V x^2 dV, \dots, \int_V xy dV, \dots, \int_V x dV, V$) for the desired polynomial order [S1, unofficial].
2. Perform further manipulation (gradient estimation, field normalization, etc.) as a linear algebra problem in the space of polynomial coefficients [S1, unofficial].

**Formula:**
For a second-order polynomial field $f(x,y,z) = Ax^2 + By^2 + Cz^2 + Dxy + Exz + Fyz + Gx + Hy + Iz + J$, the integral is:
$$ \int_V f(x,y,z) \, dV = A \int_V x^2 \, dV + B \int_V y^2 \, dV + C \int_V z^2 \, dV + D \int_V xy \, dV + E \int_V xz \, dV + F \int_V yz \, dV + G \int_V x \, dV + H \int_V y \, dV + I \int_V z \, dV + J \int_V 1 \, dV $$ [S1, unofficial].

**Parameters:**
- Polynomial order: Determines the number of moments required. Second-order is common for smooth fields [S1, unofficial].

**Edge Cases and Pitfalls:**
- **Precision:** High-order moments can suffer from numerical instability if the voxel is far from the origin. Use local coordinates if available (see [Cancellation Error Reduction via Local Coordinates](5926-cancellation-error-reduction-via-local-coordinates.md)) [G].
- **Degenerate Volumes:** If $V$ is zero (voxel outside the polyhedron), all moments are zero [G].

**Pseudocode:**
```python
def integrate_polynomial_field(moments, polynomial_coeffs):
    """
    Integrate a polynomial field over a voxel volume using precomputed coordinate moments.
    
    Args:
        moments: Dictionary or list of precomputed coordinate moments for the voxel volume.
        polynomial_coeffs: List of coefficients [A, B, C, D, E, F, G, H, I, J] for 2nd order.
        
    Returns:
        Float: The integral of the field over the volume.
    """
    # Step 1: Compute coordinate moments for the voxel volume.
    # The sources do not provide the geometric integration algorithm for this step.
    # moments = compute_coordinate_moments(voxel_volume, moment_order)
    
    # Step 2 & 3: Linear combination and summation of moments weighted by coefficients
    integral = (polynomial_coeffs[0] * moments['x^2'] +
                polynomial_coeffs[1] * moments['y^2'] +
                polynomial_coeffs[2] * moments['z^2'] +
                polynomial_coeffs[3] * moments['xy'] +
                polynomial_coeffs[4] * moments['xz'] +
                polynomial_coeffs[5] * moments['yz'] +
                polynomial_coeffs[6] * moments['x'] +
                polynomial_coeffs[7] * moments['y'] +
                polynomial_coeffs[8] * moments['z'] +
                polynomial_coeffs[9] * moments['1'])
    return integral
```

## Subtopics

### [Cancellation Error Reduction via Local Coordinates](5926-cancellation-error-reduction-via-local-coordinates.md)
Mitigates catastrophic cancellation errors in volume and moment calculations for simplicial decomposition by shifting the integration domain into a local coordinate system near the origin before calculation. It sets itself apart from naive global-coordinate integration by changing the error scaling from cubic to linear with respect to the ratio of the integration domain size to its absolute coordinate position.

## Operating characteristics
- **Time Complexity:** Dominated by the computation of coordinate moments, which depends on the complexity of the voxel-polyhedron intersection and the polynomial order [G]. Once moments are computed, integration is $O(1)$ with respect to the number of fields [G].
- **Memory Complexity:** Proportional to the number of moments, which grows as $O(N^3)$ for order $N$ in 3D [G].
- **Strengths:** Efficient for integrating many different fields over the same geometry, as moments are computed once [S1, unofficial]. Avoids redundant geometric clipping [S1, unofficial].
- **Limitations:** Requires pre-computation of moments [G]. High-order polynomials may require significant memory and precision [G].
- **When to use:** When integrating multiple scalar fields or performing operations like gradient estimation on the same voxelized geometry [S1, unofficial].
- **When not to use:** For single-field integration where geometric clipping is cheap, or for non-polynomial fields that cannot be easily approximated by polynomials [G].

## Background
Described in the context of exact general remeshing schemes for conservative voxelization [S1, unofficial]. The method leverages the linearity of integration to separate geometric computation (moments) from field-specific computation (coefficients) [G].
