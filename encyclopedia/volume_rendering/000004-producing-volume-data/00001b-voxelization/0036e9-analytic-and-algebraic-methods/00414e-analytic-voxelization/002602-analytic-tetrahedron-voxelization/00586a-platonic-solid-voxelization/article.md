# Platonic Solid Voxelization

Also called: Analytic Platonic Solid Voxelization, Inside-Outside Test for Regular Polyhedra, Polyhedron Voxelization

## Overview
Platonic Solid Voxelization generates a 3D binary voxel array representing the interior of regular platonic solids (tetrahedron, cube, octahedron, dodecahedron, and icosahedron) [S1, unofficial]. It outputs a 3D array where the voxel value is 1 if inside the polyhedron and 0 otherwise [S1, unofficial]. Unlike [Analytic Tetrahedron Voxelization](3724-analytic-tetrahedron-voxelization.md), which computes conservative moments for arbitrary tetrahedra, this method outputs a simple binary mask for specific regular polyhedra [S1, unofficial]. It differs from [Exact General Remeshing Scheme for Conservative Voxelization](3774-exact-general-remeshing-scheme-for-conservative-voxelization.md) by using a direct half-space intersection test rather than remeshing [S1, unofficial].

## How it works
**Inputs:**
- `poly`: Symbol or integer identifying the solid (`:tetra`, `:cubic`, `:octa`, `:dodeca`, `:icosa` or 4, 6, 8, 12, 20) [S1, unofficial].
- `voxel`: A 3D array of size $N \times N \times N$. Must be cubic [S1, unofficial].
- `radius`: Float in $[0, 1]$. The radius of the circumscribed sphere relative to the array size $N$ [S1, unofficial].
- `translation`: 3D vector in $[-0.5, 0.5]^3$ [S1, unofficial].
- `axis`: Collection of 3D vectors defining rotation axes [S1, unofficial].
- `angle`: Vector of rotation angles in radians [S1, unofficial].

**Outputs:**
- `voxel`: 3D array where `voxel[x,y,z] = 1` if the voxel center is inside the polyhedron, `0` otherwise [S1, unofficial].

**Data Structures:**
- **Vertices**: Matrix of size $3 \times V$. Columns are vertices $(x,y,z)$. $V$ is 4, 8, 6, 20, or 12 [S1, unofficial].
- **Faces**: Matrix of size $F \times FV$. Columns are faces. Rows are 1-based vertex indices. $FV$ is 3, 4, or 5 [S1, unofficial].

**Steps:**
1.  **Initialize Rotation Matrix**: Set `rmtx` to the $3 \times 3$ identity matrix [S1, unofficial]. For each index `idx` in `angle`, multiply `rmtx` by the rotation matrix for `axis[idx]` and `angle[idx]` [S1, unofficial].
2.  **Assert Constraints**: Verify `radius` $\in [0, 1]$, `translation` $\in [-0.5, 0.5]^3$, and `voxel` dimensions are equal ($N \times N \times N$) [S1, unofficial].
3.  **Scale Parameters**: Calculate `radius_N = radius * N` and `translation_N = translation * N` [S1, unofficial].
4.  **Retrieve Geometry**: Call the shape function for `poly` with `radius_N` [S1, unofficial]. This returns `vertices` ($3 \times V$) and `faces` ($F \times FV$) [S1, unofficial].
    -   *Tetrahedron*: Vertices generated via spherical coordinates with specific $\theta, \phi$ [S1, unofficial].
    -   *Cube*: Vertices at $(\pm r/\sqrt{3}, \pm r/\sqrt{3}, \pm r/\sqrt{3})$ [S1, unofficial].
    -   *Octahedron*: Vertices at $(\pm r, 0, 0), (0, \pm r, 0), (0, 0, \pm r)$ [G].
    -   *Dodecahedron/Icosahedron*: Vertices derived from golden ratio or spherical coordinates [S1, unofficial].
5.  **Rotate Vertices**: Compute `vertices_rot = rmtx * vertices` [S1, unofficial].
6.  **Initialize Voxel Array**: Fill `voxel` with `1` [S1, unofficial].
7.  **Voxel Loop**: Iterate $x_1, x_2, x_3$ from $0$ to $N-1$ [S1, unofficial].
    -   Calculate real-world coordinates:
        $$x_{1r} = x_1 - \lfloor N/2 \rfloor + translation_{N,1}$$
        $$x_{2r} = x_2 - \lfloor N/2 \rfloor + translation_{N,2}$$
        $$x_{3r} = x_3 - \lfloor N/2 \rfloor + translation_{N,3}$$
    -   Let $P = [x_{1r}, x_{2r}, x_{3r}]^T$.
8.  **Inside Test**: For each face $f$ in `faces`:
    -   Get the vertices of the face from `vertices_rot`.
    -   Compute normal $n = (v_1 - v_2) \times (v_1 - v_3)$ using the first three vertices [S1, unofficial].
    -   Compute $D = n \cdot v_1$ [S1, unofficial].
    -   Check condition: $(-D) \cdot (n \cdot P - D) \ge 0$ [S1, unofficial].
    -   If false for any face, set `voxel[x1,x2,x3] = 0` and break [S1, unofficial].
