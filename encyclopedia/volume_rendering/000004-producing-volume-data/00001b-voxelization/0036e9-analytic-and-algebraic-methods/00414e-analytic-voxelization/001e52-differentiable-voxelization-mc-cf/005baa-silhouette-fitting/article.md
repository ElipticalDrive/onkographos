# Silhouette Fitting
Also called: Silhouette-fitted voxelization

## Overview
Silhouette fitting is a post-processing voxelization technique that refines an initial coarse voxel model by aligning its boundary with the silhouette of the input 3D mesh, thereby preserving shape accuracy [S1]. Unlike standard rasterization-based voxelization which produces blocky artifacts, this method minimizes an energy function based on distance, tangent, and gradient differences to carve or adjust the voxel boundary [S1]. It is distinct from [Differentiable Voxelization (MC/CF)](1742-differentiable-voxelization-mc-cf.md) because it operates on a discrete voxel set using heuristic search rather than continuous gradient descent, and from [Differentiable Voxelization via Smoothed Winding Numbers](2325-differentiable-voxelization-via-smoothed-winding-numbers.md) by focusing specifically on silhouette curve matching rather than volumetric field smoothing.

## How it works
**Inputs:** A user-specified 3D triangle mesh $S$ and a target voxel resolution.
**Outputs:** A refined voxel model $V$ where the silhouette matches the mesh $S$.

**Data Structures:**
1.  **Initial Voxel Model ($V_{init}$):** A 3D grid of boolean values or occupancy flags, generated by slicing the mesh.
2.  **Silhouette Curve ($C$):** A 2D chain code representing the boundary pixels of a rendered silhouette.
3.  **Signed Distance Map:** A 2D grid aligned with the silhouette pixels, storing the signed distance $d$ from each pixel to the closest point on the silhouette curve.
4.  **Priority Queue:** Stores silhouette voxels sorted by descending distance $d(v)$.

**Steps:**

1.  **Initial Voxelization:** Render the input 3D mesh $S$ using an OpenGL pipeline. Control a clipping plane to extract a series of slice images. Stack these layers to form the initial voxel model $V_{init}$ [S1].

2.  **Silhouette Extraction:** Render both the initial voxel model $V_{init}$ and the input mesh $S$ using a background color distinguishable from the object color. This produces bi-colored framebuffer images where the boundary between inside and outside colors defines the silhouette [S1].

3.  **Chain Code Construction:** Visit the boundary of the rendered silhouette using a chain code algorithm to build a discrete silhouette curve $C$ for both the voxel model and the mesh [S1].

4.  **Signed Distance Map Construction:** Build a signed distance map on the silhouette voxels. The distance $d$ is estimated as the closest Euclidean distance between the center of a silhouette voxel (or pixel) and the closest point on the silhouette curve $C$. Accelerate this nearest-point search using the Jump Flooding Algorithm [S1].

5.  **Distance Value Assignment:** For each voxel $v$ on the silhouette, assign a signed distance value $d(v)$ based on its position relative to the curve $C$:
    $$
    d(v) = \begin{cases} 
    -d & \text{if } C(v) < 0 \\
    d & \text{if } C(v) > 0 \\
    0 & \text{if } C(v) = 0 
    \end{cases}
    $$
    where $C(v) < 0$ indicates the voxel is outside the mesh silhouette, $C(v) > 0$ indicates inside, and $d$ is the unsigned closest distance [S1].

6.  **Voxel-Pixel Matching:** Match each silhouette voxel $v$ of the initial model to its closest silhouette pixel $S_v$ on the input 3D mesh $S$ [S1].

7.  **Differentiation Estimation:** Estimate the first-order differentiation (tangent) $t(v)$ and second-order differentiation (gradient/curvature) $g(v)$ at the matching voxel $v$ using central difference approximations. To reduce anomalies from discrete sampling, sample three candidate values from one-ring ($v_{i-1}, v_{i+1}$), two-ring ($v_{i-2}, v_{i+2}$), and three-ring ($v_{i-3}, v_{i+3}$) neighborhoods. Determine $t(v)$ and $g(v)$ by averaging these three candidate values [S1].

8.  **Energy Minimization (Heuristic Search):**
    *   Sort all silhouette voxels $v$ in descending order of their distance value $d(v)$ and insert them into a priority queue [S1].
    *   While the priority queue is not empty:
        1.  Select voxel $w$ from the top of the queue [S1].
        2.  Calculate the energy of the current model $E(V, S)$ and the energy if $w$ were removed $E(V - \{w\}, S)$ [S1].
        3.  The energy function is defined as:
            $$
            E(V, S) = \sum_{v \in V} \left( d(v, S_v) + (1 - t(v) \cdot t(S_v)) + (1 - g(v) \cdot g(S_v)) \right)
            $$
            where:
            *   $d(v, S_v) = \max(0, d(v))$ is the distance term, zero if the voxel is not outside the silhouette [S1].
            *   $t(v) \cdot t(S_v)$ is the inner product of the tangent vectors.
            *   $g(v) \cdot g(S_v)$ is the inner product of the gradient vectors [S1].
        4.  If $E(V - \{w\}, S) < E(V, S)$:
            *   Remove $w$ from $V$ and the priority queue.
            *   Update $V$ by inserting new silhouette voxels resulting from the removal (neighbors that become exposed) [S1].
        5.  Else:
            *   Remove $w$ from the priority queue only (preserve the voxel) [S1].

**Edge Cases and Pitfalls:**
*   **Precision:** The chain code and distance estimation rely on discrete pixel/voxel centers. Small misalignments can cause significant energy fluctuations.
*   **Degenerate Input:** If the mesh has holes or non-manifold geometry, the silhouette extraction may be ambiguous.
*   **Shrinking:** The distance term $d(v, S_v)$ is zero if the voxel is inside. Without the tangent and gradient terms, the energy minimization might shrink the model excessively. The inclusion of $1 - t(v) \cdot t(S_v)$ and $1 - g(v) \cdot g(S_v)$ prevents this by penalizing orientation mismatches [S1].

## Operating characteristics
*   **Time Complexity:** Dominated by the rendering steps and the iterative energy minimization. The Jump Flooding Algorithm accelerates distance estimation to $O(\log N)$ per pixel. The heuristic search processes each boundary voxel once, but neighbor updates may cause re-evaluation.
*   **Memory Complexity:** Requires storage for the voxel grid, silhouette curves, and distance maps.
*   **Strengths:** Preserves the shape of the input mesh more accurately than simple rasterization. Efficient for generating models for physical fabrication (e.g., LEGO) where structural stability and aesthetics are balanced [S1].
*   **Limitations:** The heuristic search is not guaranteed to find the global minimum. It is specific to silhouette fitting and does not handle volumetric interior properties.
*   **When to use:** When the primary goal is shape fidelity of the surface boundary for fabrication or visualization, and the input is a closed manifold mesh.
*   **When not to use:** For volumetric data where interior density matters, or when differentiable gradients are required for end-to-end neural network training (use [Differentiable Voxelization (MC/CF)](1742-differentiable-voxelization-mc-cf.md) instead).

## Background
Silhouette fitting voxelization was introduced by Kyungha Min et al. in the paper "Legorization from silhouette-fitted voxelization" published in the KSII Transactions on Internet and Information Systems in June 2018 [S1]. The method was developed to address the challenges of converting 3D meshes into LEGO models, where shape preservation, structural stability, and aesthetic balance are critical. It builds upon standard OpenGL rendering pipelines and incorporates techniques from computer graphics such as chain codes and jump flooding for efficient distance computation [S1].
