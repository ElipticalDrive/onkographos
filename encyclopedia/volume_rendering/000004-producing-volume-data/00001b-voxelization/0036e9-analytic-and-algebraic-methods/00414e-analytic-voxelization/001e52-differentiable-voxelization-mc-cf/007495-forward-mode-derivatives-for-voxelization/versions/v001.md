# Forward-Mode Derivatives for Voxelization
Also called: Forward-Mode Automatic Differentiation for Voxelization

## Overview
This method computes the tangent (derivative) of the occupancy grid with respect to mesh vertex positions, given vertex tangents, by propagating derivatives through the voxelization process using forward-mode automatic differentiation [S1]. It differs from backward-mode approaches by computing the gradient of the output with respect to the input directly during the forward pass, making it suitable for scenarios where the number of inputs (vertices) is smaller than the number of outputs (voxels) or when specific directional derivatives are required [S1].

## How it works
**Inputs and Outputs**
- **Input**: Mesh vertices $V \in \mathbb{R}^{n \times d}$, simplices $S$, grid resolution $\mathbf{r} = (r_1, \dots, r_d)$, vertex tangents $\hat{V} \in \mathbb{R}^{n \times d}$ [S1].
- **Output**: Occupancy tangent $\hat{O} \in \mathbb{R}^{r_1 \times \dots \times r_d}$ [S1].

**Data Structures**
- **Voxel Grid**: A dense array of size $r_1 \times \dots \times r_d$ storing the tangent values $\hat{O}[\mathbf{i}]$.
- **Barycentric Polytope**: Represented by a matrix $\mathbf{P}$ where rows correspond to vertices of the clipped simplex in barycentric coordinates relative to the original simplex $\sigma$.
- **Vertex Matrix**: $\mathbf{V}_\sigma \in \mathbb{R}^{d \times d}$ containing the Cartesian coordinates of the simplex vertices.

**Algorithm Steps**
1. **Initialization**: Compute voxel size $\mathbf{h} \leftarrow (2/r_1, \dots, 2/r_d)$ assuming the grid spans $[-1, 1]^d$. Compute voxel volume $m \leftarrow \prod_{\ell=1}^d h_\ell$ [S1]. Initialize the output tangent grid $\hat{O}$ to zeros.

2. **Simplex Processing**: For each simplex $\sigma \in S$:
   a. Extract vertices $\mathbf{v}_0, \dots, \mathbf{v}_{d-1}$ and compute the unit outward normal $\hat{\mathbf{n}} \leftarrow \text{unit\_normal}(\sigma)$ [S1].
   b. Project vertex tangents onto the normal direction: for $i \leftarrow 0$ to $d-1$, compute $\hat{v}_i^n \leftarrow \hat{\mathbf{v}}_i \cdot \hat{\mathbf{n}}$ [S1].
   c. Compute the bounding box $(b_{\min}^1, \dots, b_{\max}^d)$ using $\text{BOUNDINGBOX}(V, h)$ [S1].
   d. Initialize barycentric polytope $\mathbf{P}^{(0)} \leftarrow \sigma$ and vertex matrix $\mathbf{V}_\sigma \leftarrow (\mathbf{v}_0, \dots, \mathbf{v}_{d-1})^\top$ [S1].

3. **Clipping and Integration**: Iterate dimensions $\ell \leftarrow 1$ to $d$ and voxel indices $i_\ell \leftarrow b_{\min}^\ell$ to $b_{\max}^\ell$:
   a. Compute threshold $t_{hi}^\ell \leftarrow -1 + (i_\ell + 1) \cdot h_\ell$ [S1].
   b. Split polytope: $(\mathbf{P}^{(\ell)}, \mathbf{P}_{\text{above}}^{(\ell)}) \leftarrow \text{SPLITPOLYTOPE}(\mathbf{P}^{(\ell-1)}, \mathbf{V}_\sigma, t_{hi}^\ell, \ell, d)$ [S1].
   c. Update $\mathbf{P}^{(\ell-1)} \leftarrow \mathbf{P}_{\text{above}}^{(\ell)}$ [S1].
   d. If $\ell = d$:
      i. Set index $\mathbf{i} \leftarrow (i_1, \dots, i_d)$ [S1].
      ii. Compute Cartesian coordinates of the clipped polytope $\mathbf{V}^{(d)} \leftarrow \mathbf{P}^{(d)} \mathbf{V}_\sigma$ [S1].
      iii. Integrate normal velocity: $\hat{O}[\mathbf{i}] \leftarrow \hat{O}[\mathbf{i}] + \text{INTEGRATELINEAR}(\mathbf{P}^{(d)}, \mathbf{V}^{(d)}, \hat{\mathbf{v}}^n)/m$ [S1].

**Pseudocode**
```python
def forward_mode_voxelization(V, S, r, V_tangent):
    """
    V: (n, d) array of mesh vertices
    S: list of simplices, each simplex is a list of vertex indices
    r: tuple of grid resolutions (r_1, ..., r_d)
    V_tangent: (n, d) array of vertex tangents
    Returns: (r_1, ..., r_d) array of occupancy tangents
    """
    d = V.shape[1]
    h = tuple(2.0 / ri for ri in r)
    m = 1.0
    for hi in h:
        m *= hi
    
    # Initialize output tangent grid
    O_tangent = np.zeros(r)
    
    for simplex_indices in S:
        # Extract vertices
        v = V[simplex_indices] # (d, d)
        v_tan = V_tangent[simplex_indices] # (d, d)
        
        # Compute unit outward normal
        # For a triangle (d=3), normal is cross(v1-v0, v2-v0) normalized
        # For general d, use generalized cross product or normal estimation
        n_hat = unit_normal(v)
        
        # Project vertex tangents onto normal direction
        v_tan_normal = np.zeros(d)
        for i in range(d):
            v_tan_normal[i] = np.dot(v_tan[i], n_hat)
        
        # Compute bounding box
        b_min, b_max = bounding_box(v, h)
        
        # Initialize barycentric polytope
        # P is a matrix where rows are barycentric coordinates of vertices
        # For a simplex, initial P is identity matrix (or standard basis)
        P = np.eye(d)
        V_sigma = v
        
        # Clip and integrate
        for l in range(1, d + 1):
            for i_l in range(b_min[l-1], b_max[l-1] + 1):
                t_hi = -1.0 + (i_l + 1) * h[l-1]
                
                # Split polytope
                P_curr, P_above = split_polytope(P, V_sigma, t_hi, l, d)
                
                # Update P for next dimension
                P = P_above
                
                if l == d:
                    i = tuple(i_l for i_l in range(b_min[0], b_max[0] + 1)) # Note: this loop structure in source is nested
                    # Correctly, i is the full index tuple
                    i = (b_min[0], ..., b_max[0]) # Placeholder for actual nested loop index
                    # In the source, i is constructed from the loop indices
                    # Let's assume i is correctly formed from the nested loops
                    i = tuple(i_l_val for i_l_val in [i_1, i_2, ..., i_d]) # Conceptual
                    
                    # Compute Cartesian coords of clipped polytope
                    V_clipped = P_curr @ V_sigma
                    
                    # Integrate normal velocity
                    # INTEGRATELINEAR computes the integral of the linear function defined by v_tan_normal
                    # over the polytope P_curr with vertices V_clipped
                    integral_val = integrate_linear(P_curr, V_clipped, v_tan_normal)
                    
                    O_tangent[i] += integral_val / m

    return O_tangent
```
*Note: The pseudocode above simplifies the nested loop structure for indices. The actual implementation requires $d$ nested loops to iterate over all voxel indices within the bounding box.*

**Parameters**
- Grid resolution $\mathbf{r}$: Determines the granularity of the output grid.
- Vertex tangents $\hat{V}$: The directional derivatives of the vertex positions.

**Edge Cases and Pitfalls**
- **Degenerate Simplices**: If a simplex has zero volume or area, the normal is undefined. Guard against this by checking the magnitude of the normal vector.
- **Precision**: Floating-point errors in clipping and integration can accumulate. Use stable numerical methods for splitting polytopes.
- **Boundary Conditions**: The grid spans $[-1, 1]^d$. Ensure that voxel indices and thresholds are correctly mapped to this range.

## Operating characteristics
- **Time Complexity**: Proportional to the number of simplices times the number of voxels they intersect. Each voxel intersection involves clipping and integration.
- **Memory Complexity**: $O(r_1 \times \dots \times r_d)$ for the output grid. Intermediate polytope representations are small (constant size relative to grid resolution).
- **Strengths**: Efficient for computing directional derivatives. No need for a separate backward pass.
- **Limitations**: Less efficient than backward-mode when the number of outputs is much larger than the number of inputs, as it computes the derivative for each output voxel individually.

## Background
This method is part of the differentiable voxelization framework, enabling gradient-based optimization of mesh parameters through the voxelization process. It builds on analytic voxelization techniques that provide closed-form solutions for occupancy and its derivatives.
