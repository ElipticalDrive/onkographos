# Monte Carlo 2D Voxelization

Also called: Differentiable 2D Voxelization (Forward/Backward Mode), Monte Carlo 3D Voxelization, Monte Carlo Voxelization

## Overview
Monte Carlo 2D Voxelization is a differentiable method for converting a 2D triangle mesh (defined by vertices and edges) into a volumetric occupancy grid using Monte Carlo integration of the generalized winding number [S1, unofficial]. It computes voxel occupancy by sampling points within the voxel grid and evaluating the generalized winding number against the mesh, using a box filter to accumulate contributions [S1, unofficial]. Unlike [Analytic Voxelization](10493-analytic-voxelization.md) which computes exact integrals, this method approximates the winding number field via stochastic sampling, enabling gradient-based optimization of mesh geometry through [Forward-Mode Derivative of Monte Carlo 2D Voxelization](1876-forward-mode-derivative-of-monte-carlo-2d-voxelization.md) or [Backward Differentiable Monte Carlo Voxelization](#backward-differentiable-monte-carlo-voxelization) [S1, unofficial].

## How it works
**Inputs and Outputs:**
*   `vertices`: Array of shape $(n, 2)$ containing 2D vertex coordinates, type `Float` [S1, unofficial].
*   `edges`: Array of shape $(m, 2)$ containing edge vertex indices, type `uint32_t` [S1, unofficial].
*   `grid`: Voxel grid dimensions $(h, w)$ [S1, unofficial].
*   `num_samples_per_voxel`: Number of Monte Carlo samples per voxel [S1, unofficial].
*   `sampling_flags`: Bitmask controlling strategy. Default `Adaptive | Stratified` [S1, unofficial].
*   `filter_radius`: Radius for the box filter [S1, unofficial].
*   **Output:** `occupancy`: Array of shape $(h, w)$ containing smoothed winding numbers [S1, unofficial].

**Data Structures:**
*   `Bitset`: Used in Adaptive mode to mark boundary voxels. Stores bits for each voxel index [S1, unofficial].
*   `Filter`: Box filter with radius `filter_radius` and evaluation method `eval(distance)` [S1, unofficial].

**Parameters:**
*   `num_samples_per_voxel`: Typical value determined by user; default logic adjusts for stratified sampling [S1, unofficial].
*   `sampling_flags`: `Adaptive` (1<<0), `Stratified` (1<<1) [S1, unofficial].

**Steps:**
1.  **Initialization:**
    *   Validate inputs: `vertices` shape $(n, 2)$, `edges` shape $(m, 2)$, grid dimensions $>0$ [S1, unofficial].
    *   Compute `voxel_size`: The volume is $[-1, 1]^2$. `voxel_size = 2.0 / grid.width` for x and `2.0 / grid.height` for y [S1, unofficial].
    *   Compute `voxel_volume`: `voxel_size[0] * voxel_size[1]` [S1, unofficial].
    *   Initialize random engine and uniform distribution `distribution` over $[0, 1)$ [S1, unofficial].
    *   If `Adaptive` flag is set, call `mark_boundary_voxels` to create a `Bitset` mask identifying voxels near the mesh surface [S1, unofficial].

2.  **Sampling Loop:**
    *   Total samples: `num_samples_total = num_samples_per_voxel * grid.num_elements()` [S1, unofficial].
    *   For each `sample_index` from $0$ to `num_samples_total - 1`:
        *   Determine `voxel_index = sample_index / num_samples_per_voxel` [S1, unofficial].
        *   Determine `sample_lane = sample_index % num_samples_per_voxel` [S1, unofficial].
        *   **Adaptive Check:** If `Adaptive` is set and the voxel at `voxel_index` is not marked in the mask (constant voxel):
            *   Set `num_samples_this_voxel = 1` [S1, unofficial].
            *   If `sample_lane > 0`, skip to next sample [S1, unofficial].
        *   Else:
            *   Set `num_samples_this_voxel = num_samples_per_voxel` [S1, unofficial].

3.  **Sample Generation:**
    *   Compute `voxel` coordinates from `voxel_index` using `linear_index_to_coords` [S1, unofficial].
    *   Compute `voxel_origin`:
        $$ \text{voxel\_origin} = [\text{voxel}.x() \cdot \text{voxel\_size}[0] - 1, \text{voxel}.y() \cdot \text{voxel\_size}[1] - 1] $$
        [S1, unofficial]
    *   Generate local sample `sample_local` using uniform random numbers in $[0, 1)$ for each dimension [S1, unofficial].
    *   **Stratified Sampling:** If `Stratified` is set and `num_samples_this_voxel > 1`:
        *   Compute `num_samples_sqrt = \sqrt{num_samples_this_voxel}` [S1, unofficial].
        *   Compute `stratum = {sample_lane % num_samples_sqrt, sample_lane / num_samples_sqrt}` [S1, unofficial].
        *   Compute `stratum_size = voxel_size / num_samples_sqrt` [S1, unofficial].
        *   Sample position:
            $$ \text{sample} = \text{voxel\_origin} + (\text{stratum} + \text{sample\_local}) \cdot \text{stratum\_size} $$
            [S1, unofficial]
    *   **Non-Stratified:**
        $$ \text{sample} = \text{voxel\_origin} + \text{voxel\_size} \cdot \text{sample\_local} $$
        [S1, unofficial]

4.  **Winding Number Computation:**
    *   Compute generalized winding number at `sample`:
        $$ \text{sample\_occupancy} = \text{generalized\_winding\_number}(\text{vertices}, \text{edges}, \text{sample}) $$
        [S1, unofficial]
    *   Compute sample weight:
        $$ \text{sample\_weight} = \frac{\text{voxel\_volume}}{\text{num\_samples\_this\_voxel}} $$
        [S1, unofficial]

5.  **Filtering and Accumulation:**
    *   Compute sample grid coordinate:
        $$ \text{sample\_grid\_coord} = \text{voxel} + \text{sample\_local} $$
        [S1, unofficial]
    *   Determine filter support range using `get_grid_support` with radius `filter_radius / voxel_size` [S1, unofficial].
    *   Iterate over neighbor voxels $(nx, ny)$ in the support range, clamped to grid bounds $[0, w)$ and $[0, h)$ [S1, unofficial].
    *   Compute neighbor center in world space:
        $$ \text{n\_center} = [\text{nx} \cdot \text{voxel\_size}[0] + \text{half\_voxel\_size}[0] - 1, \text{ny} \cdot \text{voxel\_size}[1] + \text{half\_voxel\_size}[1] - 1] $$
        where `half_voxel_size = 0.5 * voxel_size` [S1, unofficial].
    *   Compute filter weight:
        $$ \text{filter\_weight} = \text{filter.eval}(\text{n\_center} - \text{sample}) $$
        [S1, unofficial]
    *   If `filter_weight > 0`:
        $$ \text{occupancy}[nx, ny] += \text{filter\_weight} \cdot \text{sample\_occupancy} \cdot \text{sample\_weight} $$
        [S1, unofficial]

**Pseudocode:**
```python
import math
import random

def voxelize_mc_2d(vertices, edges, grid, num_samples_per_voxel, sampling_flags, filter_radius):
    ADAPTIVE = 1 << 0
    STRATIFIED = 1 << 1
    
    h, w = grid
    voxel_size_x = 2.0 / w
    voxel_size_y = 2.0 / h
    voxel_volume = voxel_size_x * voxel_size_y
    half_voxel_size_x = 0.5 * voxel_size_x
    half_voxel_size_y = 0.5 * voxel_size_y
    
    # Adaptive mask initialization
    mask = None
    if sampling_flags & ADAPTIVE:
        mask = [False] * (h * w)
        # mark_boundary_voxels: identifies voxels near the surface (implementation not provided in sources)
        
    num_samples_total = num_samples_per_voxel * h * w
    occupancy = [0.0] * (h * w)
    
    for sample_index in range(num_samples_total):
        voxel_index = sample_index // num_samples_per_voxel
        sample_lane = sample_index % num_samples_per_voxel
        
        # Adaptive logic
        if mask is not None and not mask[voxel_index]:
            num_samples_this_voxel = 1
            if sample_lane > 0:
                continue
        else:
            num_samples_this_voxel = num_samples_per_voxel
            
        # Voxel coordinates
        vy, vx = divmod(voxel_index, w)
        voxel_origin_x = vx * voxel_size_x - 1.0
        voxel_origin_y = vy * voxel_size_y - 1.0
        
        # Sample generation
        s_x = random.random()
        s_y = random.random()
        
        if (sampling_flags & STRATIFIED) and num_samples_this_voxel > 1:
            sqrt_samples = int(math.sqrt(num_samples_this_voxel))
            stratum_x = sample_lane % sqrt_samples
            stratum_y = sample_lane // sqrt_samples
            stratum_size_x = voxel_size_x / sqrt_samples
            stratum_size_y = voxel_size_y / sqrt_samples
            sample_x = voxel_origin_x + (stratum_x + s_x) * stratum_size_x
            sample_y = voxel_origin_y + (stratum_y + s_y) * stratum_size_y
        else:
            sample_x = voxel_origin_x + voxel_size_x * s_x
            sample_y = voxel_origin_y + voxel_size_y * s_y
            
        # Winding number computation
        # generalized_winding_number_2d: computes winding number against mesh (implementation not provided in sources)
        sample_occupancy = 0.0 
        
        # Weight
        sample_weight = voxel_volume / num_samples_this_voxel
        
        # Grid support
        sample_grid_x = vx + s_x
        sample_grid_y = vy + s_y
        # get_grid_support: computes bounding box of affected voxels (implementation not provided in sources)
        min_x, max_x, min_y, max_y = 0, w-1, 0, h-1
        
        # Accumulation
        for ny in range(max(0, min_y), min(h, max_y + 1)):
            for nx in range(max(0, min_x), min(w, max_x + 1)):
                n_center_x = nx * voxel_size_x + half_voxel_size_x - 1.0
                n_center_y = ny * voxel_size_y + half_voxel_size_y - 1.0
                dist_x = n_center_x - sample_x
                dist_y = n_center_y - sample_y
                
                # Box filter evaluation
                filter_weight = 1.0 if abs(dist_x) <= filter_radius and abs(dist_y) <= filter_radius else 0.0
                
                if filter_weight > 0:
                    occupancy[ny * w + nx] += filter_weight * sample_occupancy * sample_weight
                    
    return occupancy
```

## Subtopics

### [Forward-Mode Derivative of Monte Carlo 2D Voxelization](1876-forward-mode-derivative-of-monte-carlo-2d-voxelization.md)
Computes the forward-mode derivatives of the voxel occupancy grid with respect to the input mesh vertex positions. It extends [Monte Carlo 2D Voxelization](1734-monte-carlo-2d-voxelization.md) by propagating gradients through the Monte Carlo integration of the generalized winding number boundary term. Unlike the forward pass which only computes occupancy, this method computes $\frac{\partial \text{occupancy}}{\partial \text{vertices}}$ using the same sampling strategy, enabling gradient-based optimization of mesh geometry.

### Backward Differentiable Monte Carlo Voxelization
Computes backward-mode gradients of voxel occupancy with respect to vertex positions using Monte Carlo sampling [S1, unofficial]. It validates inputs and dispatches to the 2D or 3D backward-mode implementation with `DifferentiationMode::Backward` [S1, unofficial]. Inputs include `d_occupancy` (gradients of occupancy) and outputs `d_vertices` (gradients of vertices) [S1, unofficial].

## Operating characteristics
*   **Time Complexity:** Proportional to `num_samples_per_voxel * grid.num_elements() * filter_support_size` [S1, unofficial].
*   **Memory Complexity:** $O(N_g)$ for the occupancy grid and $O(N_g)$ for the adaptive mask if used, where $N_g$ is the number of voxels [S1, unofficial].
*   **Strengths:** Differentiable, supports adaptive sampling for efficiency, handles complex meshes [S1, unofficial].
*   **Limitations:** Stochastic noise requires many samples for smooth gradients; input mesh must be within $[-1, 1]^d$ [S1, unofficial].

## Background
Originated in the paper "Differentiable Voxelization of Surface Representations" by Djuren, Finnendahl, Worchel, Meyer, and Alexa (2026) [S1, unofficial]. The method is implemented in C++ in the `dvx` package, targeting CPU with CUDA GPU support in progress [S1, unofficial]. It is used for shape optimization, intersection avoidance, and volumetric objectives driven by surface representations [S1, unofficial].
