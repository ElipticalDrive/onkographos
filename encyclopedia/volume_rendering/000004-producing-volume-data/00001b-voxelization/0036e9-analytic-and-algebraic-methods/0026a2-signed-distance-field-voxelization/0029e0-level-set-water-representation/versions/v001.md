# Level Set Water Representation

Also called: Level Set Method for Liquid Surface

## Overview
The Level Set Water Representation is a method for tracking the interface between liquid and air in fluid simulations by storing the shortest signed distance from each grid cell to the water surface [S1, unofficial]. It solves the problem of maintaining a topologically flexible surface representation that can be advected by fluid velocity and used to define the simulation domain (liquid vs. air) [S1, unofficial]. It differs from binary voxelization by storing continuous distance values rather than discrete occupancy, allowing for smoother surface reconstruction and more accurate normal estimation for rendering and physics [S1, unofficial].

## How it works
**Inputs:**
- A 3D grid of resolution $N \times N \times N$ (or $N_x \times N_y \times N_z$).
- A scalar field $\phi$ (the level set) initialized with signed distances to the initial water surface.
- A fluid velocity field $\mathbf{u}$.
- An equilibrium level set $\phi^\infty$ (optional, for damping).

**Outputs:**
- Updated level set field $\phi^{n+1}$ representing the advected water surface.
- Classification of cells as liquid ($\phi < 0$) or air ($\phi \geq 0$).

**Data Structures:**
- **Level Set Texture/Grid:** A 3D array or texture where each cell $(i, j, k)$ stores a single floating-point value $\phi_{i,j,k}$.
- **Velocity Field:** A 3D vector field $\mathbf{u}_{i,j,k}$ associated with the grid cells.

**Steps:**

1.  **Initialization:**
    Compute the initial signed distance field $\phi^0$ for the water surface. For each cell center $x$, $\phi^0(x)$ is the shortest signed distance to the initial water boundary. Convention: $\phi < 0$ indicates water (interior), $\phi \geq 0$ indicates air (exterior) [S1, unofficial].

2.  **Domain Definition:**
    Identify liquid cells where $\phi_{i,j,k} < 0$. The simulation dynamics (pressure solve, external forces like gravity) are applied only to these cells. Air cells ($\phi \geq 0$) are typically set to zero pressure and no external forces [S1, unofficial].

3.  **Advection:**
    Advect the level set field $\phi$ by the fluid velocity $\mathbf{u}$. This moves the surface according to the flow. Standard semi-Lagrangian or upwind schemes are used. Note that advection alone does not preserve the signed distance property [S1, unofficial].

    Pseudocode for advection step (conceptual):
    ```python
    # phi_n is the level set at time n
    # u is the velocity field
    # dt is the time step
    phi_advected = advect(phi_n, u, dt)
    ```

4.  **Equilibrium Damping (Optional):**
    If an equilibrium level set $\phi^\infty$ is defined (e.g., $\phi^\infty(x,y,z) = y - h$ for water height $h$), apply damping to prevent sinking when pressure solve is under-converged. This blends the advected level set with the equilibrium state [S1, unofficial].

    Formula:
    $$
    \phi_{i,j,k}^{n+1} = \begin{cases} 
    A(\phi^n)_{i,j,k} & \text{if } \phi_{i,j,k}^{\infty} \geq 0 \\
    (1-\beta)A(\phi^n)_{i,j,k} + \beta\phi_{i,j,k}^{\infty} & \text{if } \phi_{i,j,k}^{\infty} < 0 
    \end{cases}
    $$
    Where:
    - $A(\phi^n)$ is the result of advection.
    - $\beta \in [0, 1]$ is the damping parameter.
    - $\phi^\infty$ is the equilibrium level set [S1, unofficial].

5.  **Reinitialization (Optional):**
    Periodically reinitialize $\phi$ to restore the signed distance property (shortest distance to the zero set). This is not strictly required for defining the surface or real-time animation but improves accuracy for rendering and physics [S1, unofficial].

**Parameters:**
- $\beta$: Damping parameter. Range: $[0, 1]$. Larger values allow fewer pressure solver iterations but reduce fluid liveliness [S1, unofficial].

**Edge Cases and Pitfalls:**
- **Reinitialization Cost:** Reinitialization is computationally expensive and often skipped in real-time applications [S1, unofficial].
- **Damping Limitations:** Damping is a nonphysical hack. It fails if the equilibrium state is unknown (e.g., water in a bowl at an arbitrary location) [S1, unofficial].
- **Volume Gain:** Damping can cause temporary volume gain in splashes outside the equilibrium domain [S1, unofficial].
- **Precision:** Floating-point precision issues may arise in narrow channels or thin films [G].

## Subtopics

### Equilibrium Level Set Damping
A technique to force liquid toward static equilibrium when the pressure solve is under-converged, preventing the liquid from sinking through tank floors [S1, unofficial]. It blends the advected level set with a known equilibrium level set $\phi^\infty$ (e.g., $y-h$) using a damping parameter $\beta$ [S1, unofficial]. It is chosen when the equilibrium state is known and static, and computational resources for pressure solving are limited [S1, unofficial]. It is not suitable for arbitrary environments where the equilibrium is unknown [S1, unofficial].

## Operating characteristics
- **Time Complexity:** Advection is $O(N^3)$ per frame. Reinitialization is also $O(N^3)$ but less frequent. Damping is $O(N^3)$ if applied every frame.
- **Memory Complexity:** $O(N^3)$ for the level set field and velocity field.
- **Performance:** Suitable for real-time simulation on GPU due to scalar field operations and parallelizability [S1, unofficial].
- **Strengths:** Topological flexibility, easy surface extraction, efficient GPU implementation [S1, unofficial].
- **Limitations:** Advection does not preserve distance field; requires reinitialization for accuracy; damping is nonphysical [S1, unofficial].
- **When to Use:** Real-time fluid simulation where performance is critical and topological changes are expected [S1, unofficial].
- **When Not to Use:** When exact volume conservation is critical without hacks, or when equilibrium state is unknown [S1, unofficial].

## Background
The level set method was popularized by Sethian (1999) for tracking interfaces [S1, unofficial]. It is widely used in real-time fluid simulation for games and interactive applications due to its efficiency on GPUs [S1, unofficial]. The specific application to water representation in 3D fluids is detailed in "Real-Time Simulation and Rendering of 3D Fluids" [S1, unofficial].
