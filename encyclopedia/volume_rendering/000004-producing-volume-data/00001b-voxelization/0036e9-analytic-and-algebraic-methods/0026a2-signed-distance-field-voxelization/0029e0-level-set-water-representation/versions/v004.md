# Level Set Water Representation

Also called: Level Set Method for Liquid Surface

## Overview
The Level Set Water Representation is a method for tracking the interface between liquid and air in fluid simulations by encoding the surface as a signed distance field (SDF) [S1, unofficial]. It solves the problem of maintaining a sharp, topologically flexible boundary between two phases (water and air) during advection, distinguishing itself from Eulerian grid methods that track volume fractions by storing only the scalar distance value at each grid cell [S1, unofficial]. Unlike sibling methods that may rely on scanned surfaces or binary voxelization, this approach explicitly defines the fluid domain via the zero set of the level set function, allowing for efficient culling of air cells during pressure solves [S1, unofficial].

## How it works
**Inputs and Outputs**
*   **Input**: A 3D grid of scalar values representing the level set function $\phi$, a fluid velocity field $\mathbf{u}$, and optionally an equilibrium level set $\phi^\infty$ for damping.
*   **Output**: An updated 3D grid of signed distances $\phi^{n+1}$ representing the advected liquid surface.

**Data Structures**
*   **Level Set Field ($\phi$)**: A 3D texture or array where each cell $(i, j, k)$ stores a single floating-point value.
    *   $\phi < 0$: Cell contains water.
    *   $\phi \geq 0$: Cell contains air.
    *   $\phi = 0$: The water surface (zero set).
    *   Value magnitude: The shortest Euclidean signed distance from the cell center to the surface.

**Steps**
1.  **Initialization**: Initialize $\phi$ such that it represents the shortest signed distance to the initial water surface. Cells inside the water have negative values; cells outside have positive values [S1, unofficial].
2.  **Advection**: Advect the level set field using the fluid velocity field. This moves the surface according to the flow [S1, unofficial].
    *   The advection operator $A$ updates the field: $\phi^{temp} = A(\phi^n)$.
    *   Note: Standard advection does not preserve the signed distance property [S1, unofficial].
3.  **Domain Definition (Pressure Solve Context)**: Use $\phi$ to define the simulation domain.
    *   Set pressure to zero in cells where $\phi \geq 0$ (air) [S1, unofficial].
    *   Apply external forces (e.g., gravity) only in cells where $\phi < 0$ (water) [S1, unofficial].
4.  **Reinitialization (Optional)**: Periodically reinitialize $\phi$ to restore the signed distance property (ensuring $|\nabla \phi| = 1$) [S1, unofficial].
    *   *Note*: For real-time animation, reinitialization is optional and may be skipped to save performance, accepting that the distance property degrades over time [S1, unofficial].
5.  **Equilibrium Damping (Conditional)**: If a static equilibrium is known and pressure convergence is insufficient, apply damping blending [S1, unofficial].

**Formulas**
*   **Classification**:
    $$ \text{Cell State} = \begin{cases} \text{Water} & \text{if } \phi < 0 \\ \text{Air} & \text{if } \phi \geq 0 \end{cases} $$
*   **Equilibrium Level Set Damping**:
    When applying damping to prevent sinking through tank floors due to under-converged pressure solves:
    $$ \phi_{i,j,k}^{n+1} = \begin{cases} A(\phi^n)_{i,j,k} & \text{if } \phi_{i,j,k}^{\infty} \geq 0 \\ (1-\beta)A(\phi^n)_{i,j,k} + \beta\phi_{i,j,k}^{\infty} & \text{if } \phi_{i,j,k}^{\infty} < 0 \end{cases} $$
    Where:
    *   $A(\phi^n)_{i,j,k}$ is the advected level set value.
    *   $\phi_{i,j,k}^{\infty}$ is the equilibrium level set value (e.g., $y - h$ for water height $h$).
    *   $\beta \in [0, 1]$ is the damping parameter [S1, unofficial].

**Parameters**
*   **$\beta$ (Damping Parameter)**: Controls the blend between the advected solution and the equilibrium solution.
    *   Range: $[0, 1]$ [S1, unofficial].
    *   Typical Values: Not given in the sources.
    *   Effect: Larger $\beta$ permits fewer pressure solver iterations but decreases the "liveliness" of the fluid [S1, unofficial].

**Edge Cases and Pitfalls**
*   **Distance Property Loss**: Advection distorts the level set, causing values to no longer represent shortest distances. Reinitialization is required for accurate physics but is computationally expensive [S1, unofficial].
*   **Damping Artifacts**: Damping is only applied where $\phi^\infty < 0$. This keeps splashes outside the equilibrium domain lively but can result in temporary volume gain (water appearing to spawn) [S1, unofficial].
*   **Unknown Equilibrium**: The damping hack fails in environments where the equilibrium state is not known a priori (e.g., water in a bowl placed at an arbitrary location), as $\phi^\infty$ cannot be defined [S1, unofficial].
*   **Nonphysical Behavior**: Damping is a nonphysical hack; it should be used judiciously [S1, unofficial].

**Pseudocode**
```python
def advect_level_set(phi, velocity_field, beta=None, phi_equilibrium=None):
    """
    Advects the level set field phi using the velocity field.
    Optionally applies equilibrium damping.
    """
    # Step 1: Advect the level set
    # A(phi) represents the advection of phi by velocity_field
    phi_advected = advect(phi, velocity_field)
    
    # Step 2: Apply Equilibrium Damping if parameters are provided
    if beta is not None and phi_equilibrium is not None:
        phi_new = zeros_like(phi)
        for i, j, k in grid_indices():
            eq_val = phi_equilibrium[i, j, k]
            adv_val = phi_advected[i, j, k]
            
            if eq_val >= 0:
                # Outside equilibrium domain: keep advected value
                phi_new[i, j, k] = adv_val
            else:
                # Inside equilibrium domain: blend
                phi_new[i, j, k] = (1 - beta) * adv_val + beta * eq_val
        phi = phi_new
    else:
        phi = phi_advected
        
    return phi

def classify_cells(phi):
    """
    Classifies grid cells based on the level set value.
    Returns a boolean mask where True indicates water.
    """
    return phi < 0
```

## Subtopics

### Equilibrium Level Set Damping
A technique to force liquid toward static equilibrium when the pressure solve is under-converged, preventing the liquid from sinking through tank floors [S1, unofficial]. It blends the advected level set values with a known equilibrium level set $\phi^\infty$ (e.g., $y - h$) [S1, unofficial]. It is chosen when computational constraints limit the number of pressure solver iterations, but static stability is required [S1, unofficial]. It is not suitable for arbitrary environments where the equilibrium state is unknown [S1, unofficial].

## Operating characteristics
*   **Time Complexity**: Advection is $O(N)$ where $N$ is the number of grid cells. Reinitialization is typically $O(N)$ but with a higher constant factor. Damping is $O(N)$.
*   **Memory Complexity**: $O(N)$ for storing the scalar level set field.
*   **Measured Performance**: Not given in the sources.
*   **Scaling**: Scales linearly with grid resolution. Well-suited for GPU implementation because it requires only a scalar value per cell [S1, unofficial].
*   **Strengths**: Simple data structure (scalar field); efficient culling of air cells; handles topological changes naturally; good for real-time animation if reinitialization is skipped [S1, unofficial].
*   **Limitations**: Advection destroys the signed distance property; reinitialization is expensive; damping is nonphysical and limited to known equilibrium scenarios [S1, unofficial].
*   **When to use**: Real-time fluid simulation where performance is critical and exact distance preservation is not strictly required for every frame [S1, unofficial].
*   **When not to use**: When the equilibrium state is unknown or dynamic (e.g., water in a moving container) [S1, unofficial].

## Background
The level set method for liquid surface representation was popularized by Sethian (1999) and is widely used in real-time fluid simulation [S1, unofficial]. It is particularly well-suited for GPU implementation due to its scalar nature [S1, unofficial]. The specific application to water simulation with equilibrium damping is described in *Real-Time Simulation and Rendering of 3D Fluids* [S1, unofficial].
