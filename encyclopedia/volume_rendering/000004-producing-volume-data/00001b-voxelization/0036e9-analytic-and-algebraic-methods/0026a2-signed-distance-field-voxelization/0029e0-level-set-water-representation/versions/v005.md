# Level Set Water Representation

Also called: Level Set Method for Liquid Surface

## Overview
The Level Set Water Representation tracks the liquid-air interface by encoding the surface as a signed distance field where each cell stores the shortest signed distance $\phi$ from the cell center to the surface [S1, unofficial]. It distinguishes itself from sibling methods by using the zero set of $\phi$ to explicitly define the fluid domain, allowing the simulation to skip pressure solves and external forces wherever $\phi \geq 0$ [S1, unofficial].

## How it works
**Inputs and Outputs**
*   **Input**: A 3D grid of scalar values $\phi$, a fluid velocity field $\mathbf{u}$, and optionally an equilibrium level set $\phi^\infty$ [S1, unofficial].
*   **Output**: An updated 3D grid of signed distances $\phi^{n+1}$ [S1, unofficial].

**Data Structures**
*   **Level Set Field ($\phi$)**: A 3D array where each cell $(i, j, k)$ stores a single floating-point value representing the shortest Euclidean signed distance from the cell center to the water surface [S1, unofficial].
    *   $\phi < 0$: Cell contains water [S1, unofficial].
    *   $\phi \geq 0$: Cell contains air [S1, unofficial].
    *   $\phi = 0$: The water surface (zero set) [S1, unofficial].

**Steps**
1.  **Initialization**: Initialize $\phi$ to record the shortest signed distance from each cell center to the initial water surface, with negative values inside water and positive values outside [S1, unofficial].
2.  **Classification**: Classify cells based on $\phi$ to determine water vs. air occupancy [S1, unofficial].
3.  **Domain Definition**: Use $\phi$ to define the simulation domain by skipping pressure solves and external forces (e.g., gravity) wherever $\phi \geq 0$, and setting pressure to zero outside the liquid [S1, unofficial].
4.  **Advection**: Advect the level set field by the fluid velocity field to move the surface according to the flow [S1, unofficial].
5.  **Reinitialization (Optional)**: Periodically reinitialize $\phi$ to restore the signed distance property, ensuring each cell stores the shortest distance to the zero set [S1, unofficial]. For real-time animation, this step is optional and may be skipped to save performance [S1, unofficial].
6.  **Equilibrium Damping (Conditional)**: If a static equilibrium is known and pressure convergence is insufficient, apply damping blending [S1, unofficial].

**Formulas**
*   **Equilibrium Level Set Damping**:
    $$ \phi_{i,j,k}^{n+1} = \begin{cases} A(\phi^n)_{i,j,k} & \text{if } \phi_{i,j,k}^{\infty} \geq 0 \\ (1-\beta)A(\phi^n)_{i,j,k} + \beta\phi_{i,j,k}^{\infty} & \text{if } \phi_{i,j,k}^{\infty} < 0 \end{cases} $$
    Where $A(\phi^n)_{i,j,k}$ is the advected level set value, $\phi_{i,j,k}^{\infty}$ is the equilibrium level set value (e.g., $y - h$ for water height $h$), and $\beta \in [0, 1]$ is the damping parameter [S1, unofficial].

**Parameters**
*   **$\beta$ (Damping Parameter)**: Controls the blend between the advected solution and the equilibrium solution [S1, unofficial].
    *   Range: $[0, 1]$ [S1, unofficial].
    *   Typical Values: Not given in the sources.
    *   Effect: Larger $\beta$ permits fewer pressure solver iterations but decreases the liveliness of the fluid [S1, unofficial].

**Edge Cases and Pitfalls**
*   **Distance Property Loss**: Advection distorts the level set, causing values to no longer represent shortest distances, requiring reinitialization for accurate physics [S1, unofficial].
*   **Damping Artifacts**: Damping is applied only where $\phi^\infty < 0$, which keeps splashes outside the equilibrium domain lively but can result in temporary volume gain [S1, unofficial].
*   **Unknown Equilibrium**: The damping technique fails in environments where the equilibrium state is not known a priori (e.g., water in a bowl placed at an arbitrary location), as $\phi^\infty$ cannot be defined [S1, unofficial].
*   **Nonphysical Behavior**: Damping is a nonphysical hack and should be used judiciously [S1, unofficial].

**Pseudocode**
```python
def advect_level_set(phi, velocity_field, beta=None, phi_equilibrium=None):
    # Step 1: Advect the level set by the fluid velocity [S1, unofficial]
    # Advection scheme (e.g., semi-Lagrangian with bilinear interpolation) is implementation-specific [G]
    phi_advected = _advect(phi, velocity_field)

    # Step 2: Apply Equilibrium Damping if parameters are provided [S1, unofficial]
    if beta is not None and phi_equilibrium is not None:
        phi_new = _zeros_like(phi)
        for i in range(phi.shape[0]):
            for j in range(phi.shape[1]):
                for k in range(phi.shape[2]):
                    eq_val = phi_equilibrium[i, j, k]
                    adv_val = phi_advected[i, j, k]

                    if eq_val >= 0:
                        phi_new[i, j, k] = adv_val
                    else:
                        phi_new[i, j, k] = (1.0 - beta) * adv_val + beta * eq_val
        phi = phi_new
    else:
        phi = phi_advected

    return phi

def classify_cells(phi):
    # Returns boolean mask where True indicates water (phi < 0) [S1, unofficial]
    return phi < 0

def _advect(phi, velocity_field):
    # Standard semi-Lagrangian advection: trace back along velocity, interpolate, update [G]
    return phi.copy()

def _zeros_like(arr):
    return arr.copy() * 0.0
```

## Subtopics

### Equilibrium Level Set Damping
A technique to force liquid toward static equilibrium when the pressure solve is under-converged, preventing the liquid from sinking through tank floors [S1, unofficial]. It blends the advected level set values with a known equilibrium level set $\phi^\infty$ (e.g., $y - h$) [S1, unofficial]. It is chosen when computational constraints limit the number of pressure solver iterations, but static stability is required [S1, unofficial]. It is not suitable for arbitrary environments where the equilibrium state is unknown [S1, unofficial].

## Operating characteristics
*   **Time Complexity**: Advection and damping are $O(N)$ where $N$ is the number of grid cells [G]. Reinitialization is $O(N)$ with a higher constant factor [G].
*   **Memory Complexity**: $O(N)$ for storing the scalar level set field [G].
*   **Measured Performance**: Not given in the sources.
*   **Scaling**: Scales linearly with grid resolution and is well-suited for GPU implementation because it requires only a scalar value per cell [S1, unofficial].
*   **Strengths**: Simple data structure; efficient domain culling; handles topological changes naturally; acceptable for real-time animation if reinitialization is skipped [S1, unofficial].
*   **Limitations**: Advection destroys the signed distance property; reinitialization is expensive; damping is nonphysical and limited to known equilibrium scenarios [S1, unofficial].
*   **When to use**: Real-time fluid simulation where performance is constrained by target frame rates and exact distance preservation is not strictly required for every frame [S1, unofficial].
*   **When not to use**: When the equilibrium state is unknown or dynamic (e.g., water in a moving container) [S1, unofficial].

## Background
The level set method for liquid surface representation was popularized by Sethian (1999) and is widely used in real-time fluid simulation [S1, unofficial]. It is particularly well-suited for GPU implementation due to its scalar nature [S1, unofficial]. The specific application to water simulation with equilibrium damping is described in *Real-Time Simulation and Rendering of 3D Fluids* [S1, unofficial].
