# MeshIntegrator Integration

Also called: Mesh Voxelization via Truncated Distance Field, TSDF Voxelization

## Overview
MeshIntegrator Integration computes a Truncated Signed Distance Field (TSDF) for a triangle mesh by writing directly into a `VoxelBlockGrid`'s `tsdf` and `weight` attributes [S1, unofficial]. It solves the problem of efficiently rasterizing arbitrary triangle meshes into a volumetric representation suitable for downstream encoding or rendering. Unlike methods that blend or accumulate values, this method overwrites every voxel within the mesh's truncation band, leaving voxels outside the band untouched [S1, unofficial].

## How it works
**Inputs and Outputs:**
*   **Input:** A triangle mesh (vertices and indices), a target `VoxelBlockGrid` with `tsdf` and `weight` attributes, and configuration parameters (`trunc_dist`, `kMaxBinTriangles`, `kMaxVoxelsPerBlock`, `kMaxDispatchBinEntries`) [S1, unofficial].
*   **Output:** The `VoxelBlockGrid` is modified in place. Voxels within the truncation band of any triangle are overwritten with clamped distance and weight=1. Voxels in the same block but outside the band are set to `tsdf=0, weight=0`. Blocks not reached by any triangle remain unchanged [S1, unofficial].

**Data Structures:**
*   **VoxelBlockGrid:** A hierarchical grid where each block holds a fixed number of voxels (`kMaxVoxelsPerBlock` = $2^{12}$ = 4096) [S1, unofficial].
*   **Bin:** A temporary structure storing pairs of (triangle index, block index) for triangles intersecting a block's truncation band. Maximum capacity is `kMaxBinTriangles` ($2^{16}$ = 65536) [S1, unofficial].
*   **Scratch Memory:** ~16 bytes per grid block slot, plus storage for the largest mesh's inputs and bins. Counts, prefix sums, fill cursors, and occupied bins reside on the device [S1, unofficial].

**Algorithm Steps:**
1.  **Binning (Two Dispatches):**
    *   **Count Pass:** For each triangle, determine which grid blocks its truncation band intersects. Increment a counter for each intersected block.
    *   **Prefix Sum:** Compute exclusive prefix sums of the counters to determine start offsets for each block's bin.
    *   **Fill Pass:** For each triangle, write its index and the corresponding block index into the bin at the calculated offset.
    *   *Constraint:* If a block's bin exceeds `kMaxBinTriangles`, the operation is refused [S1, unofficial].

2.  **Integration (Per Block):**
    *   One workgroup processes one block. If the bin entries for a block exceed `kMaxDispatchBinEntries` ($2^{20}$ = 1,048,576), the work is split into multiple submissions [S1, unofficial].
    *   The bin entries for the block are sorted by distance to the block center (nearest first) [S1, unofficial].
    *   **Voxel Processing:** For each voxel in the block:
        *   Initialize `min_dist` = $\infty$, `best_tri_idx` = -1.
        *   Iterate through the sorted triangles.
        *   **Culling:** If the lower bound of the triangle's distance to the voxel is $\ge$ `min_dist` or $\ge$ `trunc_dist`, skip the triangle.
        *   **Distance Calculation:** Compute exact distance $d$ from voxel center $x$ to triangle $T$ [S2, unofficial][S4, unofficial].
        *   **Update:** If $d < min\_dist$, set `min_dist` = $d$ and `best_tri_idx` = $T$.
        *   **Termination:** Stop iterating if all remaining triangles are ruled out by the lower bound check.
        *   **Clamping:** If `best_tri_idx` != -1, $D(x) = \text{clamp}(d, -\text{trunc\_dist}, \text{trunc\_dist})$. Else $D(x) = 0$.
        *   **Weight:** If $|D(x)| \le \text{trunc\_dist}$, `weight` = 1. Else `weight` = 0.
        *   **Sign:** The sign of $D(x)$ is determined by the normal of the closest triangle. If the vector from the closest point on the triangle to $x$ opposes the triangle normal, $D(x)$ is negative (inside); otherwise positive (outside) [S4, unofficial].

**Pseudocode:**
```python
def mesh_integrator_integration(mesh, voxel_grid, trunc_dist):
    # 1. Binning
    # Determine blocks intersected by each triangle's truncation band
    block_counts = {} # block_id -> count
    for tri in mesh.triangles:
        blocks = get_intersected_blocks(tri, voxel_grid, trunc_dist)
        for block_id in blocks:
            block_counts[block_id] = block_counts.get(block_id, 0) + 1
            
    # Check capacity
    for block_id, count in block_counts.items():
        if count > 65536: # kMaxBinTriangles
            raise ValueError("Bin overflow: mesh too fine for voxel size")

    # Prefix sum to get offsets
    offsets = {}
    current_offset = 0
    for block_id in sorted(block_counts.keys()):
        offsets[block_id] = current_offset
        current_offset += block_counts[block_id]

    # Fill bins
    bins = {block_id: [] for block_id in block_counts}
    for tri in mesh.triangles:
        blocks = get_intersected_blocks(tri, voxel_grid, trunc_dist)
        for block_id in blocks:
            bins[block_id].append((tri, offsets[block_id]))
            offsets[block_id] += 1

    # 2. Integration per block
    for block_id, tri_list in bins.items():
        # Sort by distance to block center
        block_center = get_block_center(block_id, voxel_grid)
        tri_list.sort(key=lambda t: distance(t[0].center, block_center))
        
        # Split if too large
        if len(tri_list) > 1048576: # kMaxDispatchBinEntries
            process_large_bin(tri_list, block_id, voxel_grid, trunc_dist)
            continue
            
        process_block_voxels(tri_list, block_id, voxel_grid, trunc_dist)

def process_block_voxels(tri_list, block_id, voxel_grid, trunc_dist):
    block = voxel_grid.get_block(block_id)
    for voxel in block.voxels:
        min_dist = float('inf')
        best_tri = None
        
        for tri, _ in tri_list:
            # Lower bound culling
            if tri.lower_bound_distance(voxel.center) >= min_dist:
                break
            if tri.lower_bound_distance(voxel.center) >= trunc_dist:
                break
                
            d, closest_point = point_to_triangle_distance(voxel.center, tri)
            
            if d < min_dist:
                min_dist = d
                best_tri = tri
                
        if best_tri is not None:
            # Determine sign
            normal = best_tri.normal_at(closest_point)
            vec = voxel.center - closest_point
            if dot(vec, normal) < 0:
                sign = -1
            else:
                sign = 1
            
            # Clamp and write
            tsdf = sign * min(min_dist, trunc_dist)
            voxel.tsdf = tsdf
            voxel.weight = 1 if min_dist <= trunc_dist else 0
        else:
            voxel.tsdf = 0
            voxel.weight = 0
```

**Parameters:**
*   `trunc_dist`: Truncation distance. Voxels farther than this get weight 0 [S1, unofficial].
*   `kMaxBinTriangles`: 65536. Max triangles per block bin [S1, unofficial].
*   `kMaxVoxelsPerBlock`: 4096. Max voxels per block [S1, unofficial].
*   `kMaxDispatchBinEntries`: 1,048,576. Max bin entries per dispatch [S1, unofficial].

**Edge Cases and Pitfalls:**
*   **Bin Overflow:** If the mesh is too fine relative to the voxel size, a block's bin may exceed `kMaxBinTriangles`. The method refuses to measure and requires mesh decimation [S1, unofficial].
*   **Grid State:** The grid must be quiescent (no concurrent writes) because the binning kernel probes a hash table without locking [S1, unofficial].
*   **Overwriting:** Voxels in the truncation band are overwritten, not blended. To integrate a single mesh cleanly, the grid must be cleared beforehand [S1, unofficial].
*   **Non-Watertight Meshes:** The sign determination relies on triangle normals. For non-watertight meshes, the winding number method is more robust than normal alignment, but this implementation uses normal alignment [S1, unofficial][S4, unofficial].

## Operating characteristics
*   **Time Complexity:** $O(N \cdot M \cdot B)$ in the worst case, where $N$ is the number of triangles, $M$ is the number of blocks, and $B$ is the number of voxels per block. In practice, spatial culling and sorting reduce this significantly. The binning step is $O(N \cdot K)$ where $K$ is the average number of blocks a triangle intersects.
*   **Memory Complexity:** $O(B_{grid} + N \cdot K)$ for scratch memory, where $B_{grid}$ is the number of blocks and $K$ is the average number of blocks per triangle. Scratch memory is ~16 bytes per block slot [S1, unofficial].
*   **Performance:** Efficient for large meshes due to parallel binning and block-wise processing. Performance degrades if meshes are excessively fine, causing bin overflows or excessive culling checks [S1, unofficial].
*   **Strengths:** Fast, parallelizable, handles arbitrary meshes, direct TSDF output.
*   **Limitations:** Requires quiescent grid, sensitive to mesh resolution vs. voxel size, overwrites existing data.

## Background
MeshIntegrator Integration is part of the `volumetric_kit` library, specifically the `vgrid` module. It is designed for high-performance GPU-based voxelization of triangle meshes into TSDF representations for subsequent encoding or rendering [S1, unofficial].
