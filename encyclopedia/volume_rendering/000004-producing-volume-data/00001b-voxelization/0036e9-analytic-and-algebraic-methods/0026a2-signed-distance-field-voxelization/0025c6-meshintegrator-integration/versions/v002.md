# MeshIntegrator Integration

Also called: Mesh Voxelization via Truncated Distance Field, TSDF Voxelization

## Overview
MeshIntegrator Integration computes a Truncated Signed Distance Function (TSDF) volume from a triangle mesh by writing distance and weight values into a `VoxelBlockGrid`. It solves the problem of converting explicit surface geometry into a bounded volumetric representation suitable for downstream rendering or reconstruction. It differs from unbounded SDF generation by operating within a fixed truncation band and overwriting voxel values rather than blending them, making it suitable for scenes where memory is constrained by the `depth_trunc` parameter [S1, unofficial].

## How it works
**Inputs and Outputs:**
*   **Input:** A triangle mesh (vertices and indices) and a target `VoxelBlockGrid` with `tsdf` and `weight` attributes.
*   **Output:** The `VoxelBlockGrid` is updated. Voxels within the mesh's truncation band are overwritten; voxels outside are untouched.

**Data Structures:**
*   **VoxelBlockGrid:** A sparse grid composed of blocks. Each block contains `tsdf` (float) and `weight` (float) arrays.
*   **Bin:** A temporary structure storing pairs of (triangle index, block index) for triangles intersecting a block's truncation band.
*   **Scratch Memory:** ~16 bytes per grid block slot, plus storage for the largest mesh's inputs and bins. Counts, prefix sums, fill cursors, and occupied bins reside on the device [S1, unofficial].

**Parameters:**
*   `trunc_dist`: The truncation radius. Voxels within this distance of the mesh surface are updated.
*   `kMaxBinTriangles`: Maximum triangles one block's bin may hold. Value: $2^{16}$ (65536) [S1, unofficial].
*   `kMaxVoxelsPerBlock`: Maximum voxels a block may hold. Value: $2^{12}$ (4096) [S1, unofficial].
*   `kMaxDispatchBinEntries`: Maximum bin entries one integrate dispatch measures. Value: $2^{20}$ (1048576) [S1, unofficial].

**Algorithm Steps:**
1.  **Binning (Count Pass):** Dispatch a kernel to count how many triangles fall within the truncation band of each block. This requires one work item per (triangle, candidate block) pair.
2.  **Binning (Fill Pass):** Using the counts from step 1, perform a prefix sum to determine write offsets. Dispatch a kernel to fill the bins with (triangle index, block index) pairs. The bin is sorted nearest to the block center first [S1, unofficial].
3.  **Integration (Voxel Update):** For each block, dispatch a workgroup to write its voxels. If the bin exceeds `kMaxDispatchBinEntries`, split the submission into multiple submissions [S1, unofficial].
    *   For each voxel in the block, iterate through the sorted triangles in its bin.
    *   Calculate the distance $d$ from the voxel center to the triangle.
    *   If $d > \text{trunc\_dist}$ or $d$ is strictly greater than the current best distance, rule out the triangle.
    *   Stop when all later triangles are ruled out.
    *   Take the minimum distance. Use triangle index as a tie-breaker.
    *   If the minimum distance $d_{min} \le \text{trunc\_dist}$:
        *   Clamp the TSDF value: $D(x) = \text{clamp}(d_{min}, -\text{trunc\_dist}, \text{trunc\_dist})$.
        *   Set weight: $W(x) = 1$.
    *   Else:
        *   Set TSDF: $D(x) = 0$.
        *   Set weight: $W(x) = 0$.
4.  **Completion:** Only validation totals and bounded dispatch ranges are read back from the device [S1, unofficial].

```python
    # Sort bins by distance to block center
    fill_bins(mesh, voxel_block_grid, trunc_dist, offsets, bins)

    for block in voxel_block_grid.blocks:
        bin_entries = bins[block.id]
        
        # Handle large bins by splitting dispatches
        if len(bin_entries) > kMaxDispatchBinEntries:
            split_and_dispatch(bin_entries, block, mesh, trunc_dist)
        else:
            process_block(block, bin_entries, mesh, trunc_dist)

def process_block(block, bin_entries, mesh, trunc_dist):
    """
    Processes a single block's voxels against its bin of triangles.
    """
    for voxel in block.voxels:
        best_dist = infinity
        best_tri_idx = -1
        
        for tri_idx, _ in bin_entries:
            triangle = mesh.get_triangle(tri_idx)
            
            # Rule out if strictly farther than current best or trunc_dist
            if tri_idx > best_tri_idx: # Tie-break logic implied by sort order
                # Check if triangle is strictly farther than best_dist
                # Note: Source says "ruled out only if strictly farther... or trunc_dist"
                # This implies we stop early if the sorted order guarantees no better distance
                pass 
            
            # Calculate distance from voxel center to triangle
            d = point_to_triangle_distance(voxel.center, triangle)
            
            if d < best_dist:
                best_dist = d
                best_tri_idx = tri_idx
        
        # Update voxel based on best distance
        if best_dist <= trunc_dist:
            block.tsdf[voxel.id] = clamp(best_dist, -trunc_dist, trunc_dist)
            block.weight[voxel.id] = 1.0
        else:
            block.tsdf[voxel.id] = 0.0
            block.weight[voxel.id] = 0.0

def point_to_triangle_distance(point, triangle):
    """
    Standard point-to-triangle distance calculation.
    """
    a, b, c = triangle.vertices
    # Compute closest point on triangle to point
    closest = closest_point_on_triangle(point, a, b, c)
    return length(point - closest)
```

**Edge Cases and Pitfalls:**
*   **Bin Overflow:** If a bin exceeds `kMaxBinTriangles` (65536), the mesh is refused rather than measured. Meshes far finer than voxels cause bin growth; decimate the mesh toward voxel size first [S1, unofficial].
*   **Grid State:** The grid must be quiescent across the call. The binning kernel probes the hash table without a lock [S1, unofficial].
*   **Overwriting:** Every voxel in the mesh's truncation band is overwritten, not blended. To convert one mesh on its own, the grid must be cleared first [S1, unofficial].

## Operating characteristics
*   **Time Complexity:** Proportional to the number of (triangle, block) pairs within the truncation band. Sorting bins adds a logarithmic factor relative to bin size.
*   **Memory Complexity:** ~16 bytes per grid block slot plus scratch memory for bins. Scratch memory scales with the largest mesh's inputs and bins [S1, unofficial].
*   **Strengths:** Efficient for dense meshes via spatial binning; handles truncation naturally; overwriting simplifies fusion logic.
*   **Limitations:** Requires mesh decimation for very fine meshes to avoid bin overflow; not suitable for blending multiple meshes without clearing the grid first.
