# MeshIntegrator Integration

Also called: Mesh Voxelization via Truncated Distance Field, TSDF Voxelization

## Overview
MeshIntegrator Integration maps a triangle mesh into a `VoxelBlockGrid` by writing a Truncated Signed Distance Function (TSDF) and associated confidence weights. It solves the problem of converting continuous parametric geometry into a discrete volumetric representation suitable for downstream volume rendering or fusion. Unlike sibling methods that may blend or accumulate data, this method overwrites voxels within the mesh's truncation band, making it an atomic replacement operation rather than a cumulative fusion step [S1, unofficial].

## How it works
**Inputs and Outputs**
*   **Input**: A triangle mesh (vertices and indices) and a target `VoxelBlockGrid`. The grid must be quiescent (no concurrent writes) [S1, unofficial].
*   **Output**: The grid's `tsdf` and `weight` attributes are updated. Voxels within the truncation band are overwritten; voxels outside are untouched [S1, unofficial].

**Data Structures**
The method operates on a `VoxelBlockGrid` composed of blocks. Each block contains a fixed number of voxels.
*   **Block Layout**: Defined by `kMaxVoxelsPerBlock` (4096) [S1, unofficial].
*   **Bin Layout**: A hash table maps candidate blocks to lists of triangles. Each bin entry stores triangle indices. The maximum capacity per bin is `kMaxBinTriangles` (65,536) [S1, unofficial].
*   **Scratch Memory**: ~16 bytes per grid block slot, plus storage for the largest mesh's inputs and bins. Counts, prefix sums, fill cursors, and occupied bins remain on the device [S1, unofficial].

**Parameters**
*   `trunc_dist`: The truncation distance. Voxels within this distance of the surface are processed [S1, unofficial].
*   `kMaxBinTriangles`: 65,536. Maximum triangles per block bin [S1, unofficial].
*   `kMaxVoxelsPerBlock`: 4,096. Maximum voxels per block [S1, unofficial].
*   `kMaxDispatchBinEntries`: 1,048,576. Maximum bin entries processed per dispatch [S1, unofficial].

**Algorithm Steps**
1.  **Binning (Count Pass)**: Dispatch a kernel where each work item processes one (triangle, candidate block) pair. A candidate block is one whose spatial extent intersects the triangle's truncation band. Increment a counter for each valid pair.
2.  **Binning (Fill Pass)**: Perform a prefix sum on the counters to determine write offsets. Dispatch a second kernel to populate the bin structures with triangle indices. Sort the bin entries by distance to the block center (nearest first) [S1, unofficial].
3.  **Voxel Integration**: For each block, dispatch a workgroup. If the bin size exceeds `kMaxDispatchBinEntries`, split the work into multiple submissions [S1, unofficial].
    *   For each voxel in the block:
        *   Initialize `min_dist` to `trunc_dist` and `best_triangle` to -1.
        *   Iterate through triangles in the bin (sorted nearest first).
        *   Compute the exact Euclidean distance $d$ from the voxel center to the triangle.
        *   If $d < min\_dist$:
            *   Update `min_dist = d`.
            *   Update `best_triangle = triangle_index`.
        *   **Optimization**: A triangle is ruled out if its lower bound distance to the voxel is strictly greater than `min_dist` or `trunc_dist`. Stop iterating when all remaining triangles are ruled out.
        *   If `best_triangle` != -1:
            *   Set `tsdf = clamp(min_dist, -trunc_dist, trunc_dist)`.
            *   Set `weight = 1`.
        *   Else:
            *   Set `tsdf = 0`.
            *   Set `weight = 0`.
    *   Write `tsdf` and `weight` to the grid. Note: This is an overwrite, not a blend [S1, unofficial].

**Pseudocode**
```python
def mesh_integrator_integration(mesh, grid, trunc_dist):
    # 1. Binning: Identify candidate blocks for each triangle
    # A block is a candidate if its AABB intersects the triangle's expanded AABB (trunc_dist buffer)
    bin_entries = [] # List of (block_id, triangle_index)
    
    for tri in mesh.triangles:
        tri_aabb = tri.compute_aabb()
        expanded_aabb = tri_aabb.expand(trunc_dist)
        
        for block in grid.blocks:
            if block.aabb.intersects(expanded_aabb):
                bin_entries.append((block.id, tri.index))
    
    # 2. Sort bins by distance to block center
    # Group by block_id, then sort each group by distance(block.center, tri)
    sorted_bins = {}
    for block_id, tri_idx in bin_entries:
        if block_id not in sorted_bins:
            sorted_bins[block_id] = []
        sorted_bins[block_id].append(tri_idx)
        
    for block_id in sorted_bins:
        sorted_bins[block_id].sort(key=lambda t: distance(grid.block_center(block_id), mesh.triangle(t).center))
        
    # 3. Integration
    for block_id, tri_indices in sorted_bins.items():
        block = grid.get_block(block_id)
        
        # Handle large bins by splitting if necessary
        if len(tri_indices) > kMaxDispatchBinEntries:
            process_large_bin(block, tri_indices, trunc_dist)
            continue
            
        for voxel in block.voxels:
            min_dist = trunc_dist
            best_tri_idx = -1
            
            for tri_idx in tri_indices:
                tri = mesh.triangle(tri_idx)
                
                # Lower bound check: if triangle is strictly farther than current best or trunc_dist, skip
                # This requires a conservative lower bound distance from voxel to triangle
                lower_bound = voxel.lower_bound_distance_to_triangle(tri)
                if lower_bound >= min_dist or lower_bound >= trunc_dist:
                    continue
                
                # Exact distance
                d = voxel.center.distance_to_triangle(tri)
                
                if d < min_dist:
                    min_dist = d
                    best_tri_idx = tri_idx
            
            if best_tri_idx != -1:
                # Clamp distance to truncation range
                tsdf_val = clamp(min_dist, -trunc_dist, trunc_dist)
                grid.write_tsdf(block_id, voxel.index, tsdf_val)
                grid.write_weight(block_id, voxel.index, 1.0)
            else:
                grid.write_tsdf(block_id, voxel.index, 0.0)
                grid.write_weight(block_id, voxel.index, 0.0)

def process_large_bin(block, tri_indices, trunc_dist):
    # Split tri_indices into chunks of kMaxDispatchBinEntries
    chunk_size = kMaxDispatchBinEntries
    for i in range(0, len(tri_indices), chunk_size):
        chunk = tri_indices[i : i + chunk_size]
        # Process chunk as above, merging results if necessary (though overwrite semantics simplify this)
        for voxel in block.voxels:
            min_dist = trunc_dist
            best_tri_idx = -1
            
            for tri_idx in chunk:
                tri = mesh.triangle(tri_idx)
                lower_bound = voxel.lower_bound_distance_to_triangle(tri)
                if lower_bound >= min_dist or lower_bound >= trunc_dist:
                    continue
                d = voxel.center.distance_to_triangle(tri)
                if d < min_dist:
                    min_dist = d
                    best_tri_idx = tri_idx
            
            if best_tri_idx != -1:
                tsdf_val = clamp(min_dist, -trunc_dist, trunc_dist)
                grid.write_tsdf(block.id, voxel.index, tsdf_val)
                grid.write_weight(block.id, voxel.index, 1.0)
            else:
                grid.write_tsdf(block.id, voxel.index, 0.0)
                grid.write_weight(block.id, voxel.index, 0.0)
```

**Edge Cases and Pitfalls**
*   **Bin Overflow**: If a bin exceeds `kMaxBinTriangles` (65,536), the mesh is refused. This occurs when the mesh is significantly finer than the voxel resolution. Decimate the mesh to match voxel size before integration [S1, unofficial].
*   **Concurrency**: The grid must be quiescent. The binning kernel probes the hash table without locks [S1, unofficial].
*   **Overwrite Semantics**: Voxels outside the truncation band retain their previous values. To replace an entire mesh's contribution, the grid must be cleared beforehand [S1, unofficial].

## Subtopics

### [TSDF Fusion Mesh Extraction](6831-tsdf-fusion-mesh-extraction.md)
Extracts a triangle mesh from a TSDF volume by integrating depth and color maps from multiple viewpoints into a scalable voxel grid and then performing a direct mesh extraction. It differs from differentiable surface optimization methods by relying on explicit geometric fusion of rendered depth maps, making it suitable for reconstructing geometry from 2D Gaussian Splatting or similar primitive-based renderers. The method is typically used as the final step in a reconstruction pipeline, converting per-surfel depth outputs into a unified 3D mesh.

## Operating characteristics
*   **Time Complexity**: Dominated by the binning and voxel-triangle intersection tests. Binning is $O(N_t \cdot N_b)$ where $N_t$ is triangles and $N_b$ is candidate blocks, but optimized via spatial hashing. Integration is $O(N_v \cdot N_{tri\_per\_voxel})$, where $N_{tri\_per\_voxel}$ is small due to culling.
*   **Memory Complexity**: $O(N_b)$ for the bin hash table and scratch memory (~16 bytes per block slot). Scratch memory stays on-device [S1, unofficial].
*   **Performance**: Efficient for moderate-resolution meshes. Performance degrades if mesh density vastly exceeds voxel density due to bin overflow risks [S1, unofficial].
*   **Strengths**: Exact analytic evaluation; fast culling; atomic overwrite semantics simplify pipeline logic [S1, unofficial].
*   **Limitations**: No blending; requires grid clearance for full replacement; sensitive to mesh/voxel resolution mismatch [S1, unofficial].

Originating from the `volumetric_kit` project by Tao Jin, this method provides a GPU-accelerated approach to TSDF voxelization [S1, unofficial].
