# Progressive TSDF Fusion & Mesh Extraction

Also called: Multi-resolution TSDF Fusion, Progressive TSDF

## Overview
Progressive TSDF Fusion & Mesh Extraction is a multi-resolution surface reconstruction method that fuses rendered depth and alpha maps into a Truncated Signed Distance Field (TSDF) grid, progressively refines the voxel resolution while pruning empty space, and finally extracts a mesh via Marching Cubes [S1, unofficial]. It differs from single-resolution TSDF fusion by reducing memory usage and computational cost through early pruning of empty voxels and subdividing only where necessary [S1, unofficial].

## How it works
**Inputs:**
- `cam_lst`: List of camera parameters for all training views [S1, unofficial].
- `voxel_model`: A neural voxel model capable of rendering depth and transmittance [S1, unofficial].
- `args`: Configuration object containing `use_mean` (bool), `bandwidth_vox` (float), `alpha_thres` (float), `crop_border` (int/bool), `bbox_scale` (float), `init_lv` (int), `final_lv` (int), and `crop_bbox` (optional bounding box) [S1, unofficial].
- `data_pack`: Object providing `get_train_cameras()` [S1, unofficial].

**Outputs:**
- `mesh`: A mesh object containing vertices and faces [S1, unofficial].

**Data Structures:**
- `grid_pts_xyz`: Tensor of shape `[N, 3]` containing the 3D coordinates of all grid points (voxel corners) [S1, unofficial].
- `grid_pts_val`: Tensor of shape `[N]` containing the TSDF values at each grid point [S1, unofficial].
- `vox_key`: Tensor of shape `[M, 8]` mapping each voxel `i` to its 8 corner indices in `grid_pts_xyz` [S1, unofficial].
- `vol`: Volume object managing voxel grid state, with attributes `num_voxels`, `vox_size`, `grid_pts_xyz`, `vox_key`, and methods `pruning()`, `subdividing()`, `model_init()` [S1, unofficial].

**Pseudocode:**
```python
def extract_mesh_progressive(args, data_pack, voxel_model, init_lv, final_lv, crop_bbox):
    # 1. Render depth and alpha for all training views
    cam_lst = data_pack.get_train_cameras()
    depth_lst, alpha_lst = [], []
    for cam in cam_lst:
        render_pkg = voxel_model.render(cam, output_depth=True, output_T=True)
        frame_depth = render_pkg['raw_depth'][[0]] if args.use_mean else render_pkg['raw_depth'][[2]]
        frame_alpha = 1.0 - render_pkg['raw_T']
        if args.save_gpu:
            frame_depth, frame_alpha = frame_depth.cpu(), frame_alpha.cpu()
        depth_lst.append(frame_depth)
        alpha_lst.append(frame_alpha)

    # 2. Determine bounding volume
    if crop_bbox is None:
        inside_min = voxel_model.scene_center - 0.5 * voxel_model.inside_extent * args.bbox_scale
        inside_max = voxel_model.scene_center + 0.5 * voxel_model.inside_extent * args.bbox_scale
    else:
        inside_min, inside_max = crop_bbox[:3], crop_bbox[3:]

    # 3. Initialize dense grid at initial level
    vol = VoxelGrid()
    vol.model_init(bounding=torch.stack([inside_min, inside_max]), outside_level=0, init_n_level=init_lv)

    # 4. Progressive TSDF Fusion Loop
    for lv in range(init_lv, final_lv + 1):
        now_voxel_size = vol.vox_size[0].item()
        bandwidth = args.bandwidth_vox * now_voxel_size
        grid_tsdf = tsdf_fusion(cam_lst, depth_lst, alpha_lst, vol.grid_pts_xyz, bandwidth, args.crop_border, args.alpha_thres)

        if lv < final_lv:
            vox_tsdf = grid_tsdf[vol.vox_key]
            thickness = 2.0 / args.bandwidth_vox
            thickness = min(thickness, 0.99)
            prune_mask = vox_tsdf.isnan().any(-1) | (vox_tsdf.amax(1) < -thickness) | (vox_tsdf.amin(1) > thickness)
            vol.pruning(prune_mask)
            vol.subdividing(torch.ones([vol.num_voxels], dtype=torch.bool))

    # 5. Extract mesh via Marching Cubes
    verts, faces = torch_marching_cubes_grid(grid_pts_val=grid_tsdf, grid_pts_xyz=vol.grid_pts_xyz, vox_key=vol.vox_key, iso=0)
    mesh = trimesh.Trimesh(verts.cpu().numpy(), faces.cpu().numpy())
    return mesh

def tsdf_fusion(cam_lst, depth_lst, alpha_lst, grid_pts_xyz, trunc_dist, crop_border, alpha_thres):
    fuser = Fuser(xyz=grid_pts_xyz, bandwidth=trunc_dist, use_trunc=True, fuse_tsdf=True, feat_dim=0, alpha_thres=alpha_thres, crop_border=crop_border, normal_weight=False, depth_weight=False, border_weight=False, use_half=False)
    for cam, frame_depth, frame_alpha in zip(cam_lst, depth_lst, alpha_lst):
        fuser.integrate(cam, frame_depth.cuda(), alpha=frame_alpha.cuda())
    return fuser.tsdf.squeeze(1).contiguous()

# [G] VoxelGrid, Fuser, torch_marching_cubes_grid, and trimesh are external dependencies.
# VoxelGrid manages grid state and provides model_init, pruning, subdividing.
# Fuser projects depth/alpha onto grid_pts_xyz, computes weighted TSDF updates, and clamps to [-bandwidth, bandwidth].
# torch_marching_cubes_grid extracts the iso-surface at value iso from the grid.
```

**Parameters:**
- `bandwidth_vox`: Multiplier for voxel size to determine truncation distance [S1, unofficial]. Typical value: Not given in the sources.
- `alpha_thres`: Alpha threshold for fusion [S1, unofficial]. Typical value: Not given in the sources.
- `bbox_scale`: Scale factor for bounding box extent [S1, unofficial]. Typical value: Not given in the sources.
- `init_lv`: Initial resolution level [S1, unofficial]. Typical value: Not given in the sources.
- `final_lv`: Final resolution level [S1, unofficial]. Typical value: Not given in the sources.
- `use_mean`: Boolean flag to select mean depth (`raw_depth[0]`) over median depth (`raw_depth[2]`) [S1, unofficial]. Default: False.

**Edge Cases and Pitfalls:**
- **NaN Values:** The pruning mask explicitly handles NaN values in TSDF corners, treating any voxel with a NaN corner as empty/prunable [S1, unofficial].
- **Boundary Conditions:** The bounding volume is determined either by a provided `crop_bbox` or by scaling the scene center and extent by `bbox_scale` [S1, unofficial].
- **Precision:** The method uses floating-point operations, and the `use_half` flag in the Fuser is set to False, suggesting full precision is used [S1, unofficial].

## Subtopics

### Adaptive TSDF Fusion & Mesh Extraction
Adaptive TSDF Fusion & Mesh Extraction operates on an adaptive sparse voxel octree instead of a dense grid, rendering depth/alpha, initializing from clamped octree levels, pruning outside voxels, fusing TSDF, and extracting a mesh [S1, unofficial]. It is chosen when memory efficiency is critical for large scenes, as it only allocates voxels where needed [S1, unofficial]. The key difference is the use of `octpath_init` and `clamp_level` to manage octree structure, and pruning based on corner positions relative to the bounding box rather than TSDF values [S1, unofficial]. The pruning mask is computed as `corners_outside.all(-1)` where `corners_outside` is true if any corner is outside the bounding box [S1, unofficial]. The bandwidth is computed using `vol.vox_size.min().item()` to handle varying voxel sizes in the octree [S1, unofficial].

## Background
Progressive TSDF Fusion & Mesh Extraction is part of the SVRaster pipeline, developed by NVIDIA Corporation [S1, unofficial]. It builds on the TSDF Reconstruction from Depth Maps method, which converts per-surfel depth outputs into a unified 3D mesh [Parent]. The method was introduced in the context of neural voxel rendering, where depth and alpha are rendered from training views and fused into a TSDF grid [S1, unofficial].
