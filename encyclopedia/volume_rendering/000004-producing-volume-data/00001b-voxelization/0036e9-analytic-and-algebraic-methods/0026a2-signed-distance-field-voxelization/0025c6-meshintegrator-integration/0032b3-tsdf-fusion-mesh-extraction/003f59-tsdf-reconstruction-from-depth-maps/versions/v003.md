# TSDF Reconstruction from Depth Maps

Also called: Depth Map Fusion, TSDF Reconstruction

## Overview
This method converts per-surfel depth outputs from a primitive-based renderer into a unified 3D mesh by computing a robust depth value per pixel and fusing the resulting depth maps via Truncated Signed Distance Function (TSDF) fusion [S1]. It differs from direct neural rendering mesh extraction by relying on explicit geometric fusion of rendered depth maps rather than differentiable surface optimization [S1]. It serves as the final step in the pipeline, taking the depth and color maps produced by [TSDF Fusion Mesh Extraction](6831-tsdf-fusion-mesh-extraction.md) and providing the specific algorithmic details for generating the input depth maps and configuring the fusion parameters [S1].

## How it works
**Inputs:**
- Rendered depth maps: For each pixel $p$ in each view, a list of splats $i$ contributing to that pixel, along with their depth $t_i$ and transmittance $T_i$ [S1].
- Camera intrinsics and extrinsics for each view [S1].
- TSDF grid configuration parameters [S1].

**Outputs:**
- A fused TSDF volume [S1].
- A mesh extracted from the TSDF volume (typically via Marching Cubes, as handled by the parent method) [S1].

**Data Structures:**
- **TSDF Volume:** A 3D grid of voxels. Each voxel stores a weighted average distance value and a weight accumulator [G].
- **Voxel Layout:** Standard TSDF implementations store a float for the distance value and a float for the weight [G].
- **Parameters:**
  - Voxel size: $0.004$ [S1].
  - Truncation threshold: $0.02$ [S1].
  - Gradient threshold: $0.3$ [S1].
  - Percent dense value: $0.001$ [S1].

**Algorithm Steps:**

1. **Compute Median Depth per Pixel:**
   For each pixel $p$ in a rendered depth map, identify all splats $i$ that contribute to that pixel [S1]. Calculate the transmittance $T_i$ for each splat [S1]. Select the maximum depth $t_i$ among all splats where the transmittance $T_i$ exceeds $0.5$ [S1]. This value is the median depth $t_{median}$ for the pixel [S1].
   
   Formula:
   $$ t_{median} = \max \{ t_i \mid T_i > 0.5 \} $$

2. **TSDF Fusion:**
   Fuse the computed $t_{median}$ depth maps from all views into a single 3D representation using Truncated Signed Distance Fusion (TSDF) via Open3D [S1].
   - For each view, project the depth map into the 3D TSDF volume [S1].
   - For each voxel intersected by a ray from the camera through a pixel with valid depth:
     - Compute the signed distance from the voxel center to the depth surface [G].
     - If the absolute distance is less than the truncation threshold ($0.02$), update the voxel's TSDF value using a weighted average based on the new observation and previous observations [G].
     - Accumulate weights to handle multi-view consistency [G].

3. **Mesh Extraction:**
   The resulting TSDF volume is passed to the mesh extraction stage (handled by [TSDF Fusion Mesh Extraction](6831-tsdf-fusion-mesh-extraction.md)), which uses Open3D's `TruncatedSDFVolume` to extract the mesh [S1].

**Pseudocode:**

```python
import numpy as np

def compute_median_depth(depth_maps, splat_transmittances):
    """
    Computes the median depth for each pixel based on splat contributions.
    Args:
        depth_maps: List of 2D arrays, each shape (H, W), containing depth t_i per splat per pixel.
        splat_transmittances: List of 2D arrays, same shape, containing T_i.
    Returns:
        median_depth_map: 2D array of median depths per pixel.
    """
    median_depth_map = np.full_like(depth_maps[0], np.nan)
    H, W = depth_maps[0].shape
    for h in range(H):
        for w in range(W):
            valid_depths = []
            for i in range(len(depth_maps)):
                if splat_transmittances[i][h, w] > 0.5:
                    valid_depths.append(depth_maps[i][h, w])
            if valid_depths:
                median_depth_map[h, w] = max(valid_depths)
    return median_depth_map

def tsdf_fusion(median_depth_maps, camera_poses, intrinsics, voxel_size=0.004, truncation_threshold=0.02):
    """
    Fuses median depth maps into a TSDF volume using a standard weighted integration scheme.
    Args:
        median_depth_maps: List of 2D arrays containing median depths.
        camera_poses: List of 4x4 numpy arrays for camera-to-world transforms.
        intrinsics: 3x3 numpy array for camera intrinsic matrix.
        voxel_size: Size of each voxel in meters.
        truncation_threshold: Maximum distance to consider for TSDF update.
    Returns:
        tsdf_volume: 3D numpy array of TSDF values.
    """
    # Initialize TSDF volume dimensions based on scene bounds [G]
    # Not given in the sources. Standard practice allocates a 3D grid covering the camera frustums.
    D, H_v, W_v = 64, 256, 256 # Placeholder dimensions for implementation [G]
    tsdf_volume = np.zeros((D, H_v, W_v))
    weight_volume = np.zeros((D, H_v, W_v))
    
    for depth_map, pose in zip(median_depth_maps, camera_poses):
        H, W = depth_map.shape
        for h in range(H):
            for w in range(W):
                depth_val = depth_map[h, w]
                if np.isnan(depth_val):
                    continue
                
                # Compute ray direction in world space
                cam_center = np.linalg.inv(pose)[:3, 3]
                pixel_uv = np.array([w, h, 1.0])
                ray_dir_cam = np.linalg.inv(intrinsics) @ pixel_uv
                ray_dir_world = (pose[:3, :3] @ ray_dir_cam)
                ray_dir_world /= np.linalg.norm(ray_dir_world)
                
                # Traverse voxels along the ray within the truncation range
                # Standard voxel traversal algorithm [G]
                step_size = voxel_size
                t = 0.0
                while t < truncation_threshold * 2.0:
                    voxel_center_world = cam_center + ray_dir_world * (depth_val + t)
                    # Convert world coordinates to voxel indices
                    scene_origin = np.array([-1.0, -1.0, -1.0]) # Placeholder [G]
                    voxel_idx = (
                        int((voxel_center_world[0] - scene_origin[0]) / voxel_size),
                        int((voxel_center_world[1] - scene_origin[1]) / voxel_size),
                        int((voxel_center_world[2] - scene_origin[2]) / voxel_size)
                    )
                    
                    if 0 <= voxel_idx[0] < D and 0 <= voxel_idx[1] < H_v and 0 <= voxel_idx[2] < W_v:
                        # Compute signed distance from voxel center to depth surface
                        signed_dist = -t
                        
                        # Update TSDF value using weighted average
                        current_val = tsdf_volume[voxel_idx]
                        current_weight = weight_volume[voxel_idx]
                        new_weight = 1.0
                        
                        if abs(signed_dist) < truncation_threshold:
                            tsdf_volume[voxel_idx] = (current_val * current_weight + signed_dist * new_weight) / (current_weight + new_weight)
                        weight_volume[voxel_idx] += new_weight
                    
                    t += step_size
    return tsdf_volume
```

## Subtopics

### [Progressive TSDF Fusion & Mesh Extraction](10786-progressive-tsdf-fusion-mesh-extraction.md)
Progressive TSDF Fusion & Mesh Extraction is a multi-resolution surface reconstruction method that fuses rendered depth and alpha maps into a Truncated Signed Distance Field (TSDF) grid, progressively refining the voxel resolution while pruning empty space, and finally extracts a mesh via Marching Cubes. It differs from single-resolution TSDF fusion by reducing memory usage and computational cost through early pruning of empty voxels and subdividing only where necessary, and it differs from direct neural rendering mesh extraction by relying on explicit geometric fusion rather than differentiable surface optimization.

## Operating characteristics
- **Time Complexity:** Not explicitly given in the sources. However, the method is noted to require half the computation time of GOF on the TNT dataset [S1].
- **Memory Complexity:** Not explicitly given in the sources.
- **Measured Performance:**
  - On the TNT dataset, full QGS achieves a mean F1-Score of 0.50 with a training time of 75 minutes [S1].
  - On Mip-NeRF 360 indoor scenes, full QGS achieves PSNR 30.45, SSIM 0.919, and LPIPS 0.184 [S1].
  - On Mip-NeRF 360 outdoor scenes, full QGS achieves PSNR 24.32, SSIM 0.706, and LPIPS 0.242 [S1].
  - On the DTU dataset, evaluations are performed at half the original image resolution [S1].
- **Strengths:** Superior geometric fitting capability of quadrics enables finer detail preservation [S1]. Outperforms both implicit and explicit approaches on the DTU dataset [S1].
- **Limitations:** High geometric fitting capability can cause overfitting in regions with sparse views or low texture, resulting in surface artifacts like dents [S1].
- **When to use:** When high-quality surface reconstruction is needed from 2D Gaussian Splatting outputs, and computational efficiency is a concern compared to other explicit methods like GOF [S1].
- **When not to use:** In scenes with sparse views or low texture, where overfitting may occur [S1].

## Background
The method originates from the Quadratic Gaussian Splatting (QGS) paper, which introduces high-quality surface reconstruction using second-order geometric primitives [S1]. It builds on the TSDF fusion approach used in 2DGS [16] and adapts it for quadric surfels [S1]. The adaptive control strategy is adopted from 3DGS [21] [S1].
