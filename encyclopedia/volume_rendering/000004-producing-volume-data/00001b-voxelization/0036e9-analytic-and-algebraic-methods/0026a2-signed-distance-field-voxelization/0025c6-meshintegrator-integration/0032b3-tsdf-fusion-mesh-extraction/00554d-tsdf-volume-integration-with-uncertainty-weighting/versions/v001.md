# TSDF Volume Integration with Uncertainty Weighting

Also called: NeRF-SLAM Fusion, Sigma-Fusion

## Overview
TSDF Volume Integration with Uncertainty Weighting is a volumetric fusion method that integrates depth maps into a Truncated Signed Distance Function (TSDF) volume using per-pixel weights derived from depth uncertainty (inverse standard deviation) [S1, unofficial]. It solves the problem of noisy depth measurements in SLAM pipelines by down-weighting unreliable observations, distinguishing it from standard TSDF fusion which applies uniform weights [S1, unofficial]. This method is specifically designed for integration with 2D Gaussian Splatting or NeRF-based depth outputs where uncertainty estimates are available [S1, unofficial].

## How it works
**Inputs and Outputs:**
- **Inputs:** A SLAM packet containing camera poses (extrinsics), depth maps (stored as inverse depth), depth covariance (uncertainty), and RGB images. Camera intrinsics and a down-scaling factor are also required.
- **Outputs:** A TSDF volume (either legacy `ScalableTSDFVolume` or new `VoxelBlockGrid`) containing fused geometry and color.

**Data Structures:**
The method primarily utilizes Open3D's `VoxelBlockGrid` for the volume representation [S1, unofficial]. The grid stores attributes per voxel block:
- `tsdf`: float32, 1 channel.
- `weight`: float32, 1 channel.
- `color`: float32, 3 channels.

**Parameters:**
- `voxel_size`: Physical size of a voxel in meters. Typical value: $6.0 / 512$ meters (for a $3m \times 3m \times 3m$ room with a $512^3$ grid) [S1, unofficial].
- `sdf_trunc`: Truncation distance for the TSDF in meters. Typical value: $0.10$ [S1, unofficial].
- `max_depth`: Maximum depth in meters for integration. Depths beyond this are ignored. Typical value: $6.0$ [S1, unofficial].
- `max_weight`: Maximum weight value allowed in the volume. Units: $1/m^2$ (inverse variance). Typical value: $20.0$ [S1, unofficial].
- `block_resolution`: Resolution of each voxel block in the `VoxelBlockGrid`. Typical value: $16$ [S1, unofficial].
- `block_count`: Maximum number of voxel blocks allowed in the grid. Typical value: $5000$ [S1, unofficial].
- `depth_scale`: Scale factor applied to depth values. Typical value: $1.0$ [S1, unofficial].
- `min_depth`: Minimum valid depth in meters. Typical value: $0.01$ [S1, unofficial].
- `dsf`: Down-scaling factor for camera intrinsics. Hardcoded value: $8.0$ [S1, unofficial].
- `max_depth_sigma_thresh`: Threshold for depth sigma (uncertainty). Depths with sigma higher than this are considered invalid/out-of-reconstruction. Value not explicitly given in sources [S1, unofficial].
- `min_weight_for_render`: Minimum weight required for a pixel to be included in volume rendering. Typical value: $0.01$ [S1, unofficial].

**Steps:**
1. **Initialize Volume:** Create the TSDF volume using Open3D's `ScalableTSDFVolume` (legacy) or `VoxelBlockGrid` (new) with the parameters defined above [S1, unofficial].
2. **Receive Packet:** Obtain a SLAM packet containing `cam0_idepths_up` (inverse depth), `cam0_depths_cov_up` (depth covariance), RGB images, camera intrinsics, and extrinsics [S1, unofficial].
3. **Determine Fusion Mode:** Check if the fusion mode is 'sigma' (uncertainty-based) or standard (uniform) [S1, unofficial].
4. **Compute Masks:**
   - If 'sigma': Create a mask based on `max_depth_sigma_thresh`. Pixels with uncertainty (sigma) above this threshold are masked out [S1, unofficial].
   - If standard: Set all depth weights to 1.0 [S1, unofficial].
5. **Convert Depth:** Convert inverse depth values to linear depth by taking the reciprocal:
   $$ \text{depths} = \text{packet}['\text{cam0\_idepths\_up}']^{-1} $$
   [S1, unofficial].
6. **Compute Weights:** Calculate integration weights from the depth covariance. The weight is the inverse square root of the covariance (inverse standard deviation):
   $$ \text{weights} = \text{packet}['\text{cam0\_depths\_cov\_up}']^{-0.5} $$
   Higher standard deviation results in lower weight [S1, unofficial].
7. **Convert Data Types:** Convert PyTorch tensors to Open3D tensors using DLpack to avoid memory copies:
   ```python
   o3d_depth = o3d.t.geometry.Image(o3d.core.Tensor.from_dlpack(torch.utils.dlpack.to_dlpack(depth)))
   ```
   [S1, unofficial].
8. **Identify Blocks:** Compute the unique voxel block coordinates intersected by the camera frustum using the depth image, intrinsics, extrinsics, depth scale, and `max_depth` [S1, unofficial].
9. **Activate Blocks:** Activate the identified blocks in the volume's hash map [S1, unofficial].
10. **Find Indices:** Find the indices and masks for the activated blocks to prepare for integration [S1, unofficial].
11. **Synchronize:** Synchronize the CUDA stream to ensure completion of volume operations [S1, unofficial].
12. **Integrate:**
    - If using legacy volume (`use_old_volume` is True): Create an Open3D RGBD image from color and depth, then integrate it into the volume using the intrinsic and extrinsic matrices [S1, unofficial].
    - If using new volume (`use_old_volume` is False): Call `custom_volume_integrate`, which handles block activation and index finding, implying further integration steps are handled by the Open3D backend [S1, unofficial].

**Pseudocode:**
```python
import torch
import open3d as o3d

def integrate_frame_sigma(packet, volume, params):
    """
    Integrate a single frame into the TSDF volume using uncertainty weighting.
    """
    # 1. Extract data from packet
    # packet contains: cam0_idepths_up, cam0_depths_cov_up, cam0_colors_up, 
    #                   cam0_intrinsics, cam0_extrinsics
    
    # 2. Convert inverse depth to linear depth
    # Note: packet['cam0_idepths_up'] is a PyTorch tensor
    idepths = packet['cam0_idepths_up']
    depths = idepths.pow(-1)
    
    # 3. Compute weights from covariance (uncertainty)
    # Covariance is variance. Weight is 1/sqrt(variance) = 1/sigma
    covariances = packet['cam0_depths_cov_up']
    weights = covariances.pow(-0.5)
    
    # 4. Apply uncertainty mask
    # Assume max_depth_sigma_thresh is defined in params
    sigma = covariances.sqrt()
    valid_mask = sigma < params['max_depth_sigma_thresh']
    
    # Also mask by min/max depth
    min_depth = params['min_depth']
    max_depth = params['max_depth']
    depth_valid = (depths > min_depth) & (depths < max_depth)
    
    # Combine masks
    final_mask = valid_mask & depth_valid
    
    # 5. Prepare Open3D tensors
    # Convert to Open3D format using DLpack
    o3d_depth = o3d.t.geometry.Image(o3d.core.Tensor.from_dlpack(torch.utils.dlpack.to_dlpack(depths)))
    o3d_color = o3d.t.geometry.Image(o3d.core.Tensor.from_dlpack(torch.utils.dlpack.to_dlpack(packet['cam0_colors_up'])))
    
    # 6. Compute unique block coordinates
    # This function may raise an exception if parameters are invalid
    try:
        block_coords = compute_unique_block_coordinates(
            o3d_depth, 
            packet['cam0_intrinsics'], 
            packet['cam0_extrinsics'], 
            params['voxel_size'], 
            params['max_depth'],
            params['dsf'] # Down-scaling factor
        )
    except Exception as e:
        print(f"Integration skipped due to error: {e}")
        return False

    # 7. Activate blocks in volume
    volume.activate_blocks(block_coords)
    
    # 8. Find indices for activated blocks
    indices, masks = volume.find_block_indices(block_coords)
    
    # 9. Synchronize CUDA stream
    torch.cuda.synchronize()
    
    # 10. Integrate
    # If using legacy volume:
    if params['use_old_volume']:
        # Create RGBD image
        rgbd = o3d.t.geometry.RGBDImage(o3d_depth, o3d_color)
        # Integrate using Open3D's standard method
        volume.integrate(rgbd, packet['cam0_intrinsics'], packet['cam0_extrinsics'])
    else:
        # If using new VoxelBlockGrid
        # Call custom integration function which handles the backend logic
        custom_volume_integrate(volume, o3d_depth, o3d_color, weights, final_mask, indices, masks, packet['cam0_intrinsics'], packet['cam0_extrinsics'])
        
    return True
```

**Edge Cases and Pitfalls:**
- The `compute_unique_block_coordinates` function may raise an exception if parameters are invalid (e.g., `max_depth` issues). The implementation should catch this exception, print it, and skip integration for that frame [S1, unofficial].
- Depth values are stored as inverse depth (`idepths`) in the packet. They must be converted to linear depth before integration [S1, unofficial].
- GPU memory usage is intensive. Out-of-memory errors may require parameter adjustment or better hardware [S1, unofficial].

## Operating characteristics
- **Time Complexity:** Not given in the sources.
- **Memory Complexity:** GPU memory intensive due to frame-to-frame correlation volumes and volumetric rendering [S1, unofficial].
- **Measured Performance:** Not given in the sources.
- **Scaling:** Not given in the sources.
- **Strengths:** Reduces noise in reconstructed geometry by down-weighting uncertain depth measurements [S1, unofficial].
- **Limitations:** High GPU memory consumption [S1, unofficial].
- **When to use:** When integrating depth maps from SLAM systems (like NeRF-SLAM) that provide uncertainty estimates, and when noise reduction is critical [S1, unofficial].
- **When not to use:** When GPU memory is constrained and uncertainty data is not available [S1, unofficial].

## Background
The method was introduced in the NeRF-SLAM project by Antoni Rosinol, John J. Leonard, and Luca Carlone in 2022 [S1, unofficial]. It is an implementation of Sigma-Fusion, which was originally proposed in the paper "Sigma-Fusion: Uncertainty-Aware Dense Visual Mapping" [S1, unofficial]. The code is part of the NeRF-SLAM repository, which also implements parts of Droid-SLAM and Instant-NGP [S1, unofficial].
