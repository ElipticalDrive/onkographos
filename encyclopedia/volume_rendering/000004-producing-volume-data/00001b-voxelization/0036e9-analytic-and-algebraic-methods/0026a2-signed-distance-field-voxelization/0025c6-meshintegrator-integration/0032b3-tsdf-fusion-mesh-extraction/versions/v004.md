# TSDF Fusion Mesh Extraction

Also called: Bounded TSDF Mesh Extraction, Direct extraction, Progressive extraction, ScalableTSDFVolume Mesh Extraction, Sparse Voxel Mesh Extraction, TSDF Volume Integration

## Overview
This method extracts a triangle mesh from a Truncated Signed Distance Function (TSDF) volume by integrating depth and color maps from multiple viewpoints into a scalable voxel grid and then performing a direct mesh extraction [S1, S3, unofficial]. It differs from differentiable surface optimization methods by relying on explicit geometric fusion of rendered depth maps, making it suitable for reconstructing geometry from 2D Gaussian Splatting or similar primitive-based renderers [S1, unofficial]. The method is typically used as the final step in a reconstruction pipeline, converting per-surfel depth outputs into a unified 3D mesh [S1, unofficial].

## How it works
**Inputs:**
- A set of viewpoints (cameras) with associated RGB and depth maps.
- Camera intrinsic and extrinsic matrices for each viewpoint.
- Optional ground truth alpha masks for background masking.
- Parameters: `voxel_size`, `sdf_trunc`, `depth_trunc`, `color_type`, and optional progressive extraction settings (`init_lv`, `final_lv`, `bandwidth_vox`).

**Outputs:**
- A triangle mesh (e.g., in PLY format) representing the reconstructed surface.

**Data Structures:**
- `ScalableTSDFVolume`: An octree-based data structure that stores TSDF values and color information. It dynamically adjusts resolution based on the `voxel_size` and octree levels.
- `RGBDImage`: A container holding synchronized RGB and depth data for a single viewpoint.

**Steps:**

1. **Initialize the TSDF Volume:**
   Create a `ScalableTSDFVolume` instance with the specified `voxel_size`, `sdf_trunc`, and `color_type` (typically `RGB8` for color meshes) [S1, S3, unofficial].
   $$ \text{volume} = \text{ScalableTSDFVolume}(\text{voxel\_length}=\text{voxel\_size}, \text{sdf\_trunc}=\text{sdf\_trunc}, \text{color\_type}=\text{RGB8}) $$

2. **Prepare Viewpoints:**
   Iterate through the list of viewpoints. For each viewpoint:
   a. Convert the camera parameters to Open3D format [S3, unofficial].
   b. If background masking is enabled and a ground truth alpha mask is available, set depth values to 0 where the alpha mask is less than 0.5 [S1, S3, unofficial].
   c. Create an `RGBDImage` from the RGB and depth maps. Clip RGB values to $[0, 1]$, multiply by 255, and cast to `uint8`. Set `depth_scale` to 1.0 and `depth_trunc` to the maximum depth range [S1, S3, unofficial].

3. **Integrate into Volume:**
   Integrate the `RGBDImage` into the `ScalableTSDFVolume` using the camera's intrinsic and extrinsic matrices [S1, S3, unofficial].
   $$ \text{volume.integrate}(\text{rgbd}, \text{intrinsic}=\text{cam\_intrinsic}, \text{extrinsic}=\text{cam\_extrinsic}) $$

4. **Extract Mesh:**
   Extract the triangle mesh from the integrated volume [S1, S3, unofficial].
   $$ \text{mesh} = \text{volume.extract\_triangle\_mesh}() $$

**Parameters:**
- `voxel_size`: Resolution of the TSDF volume. Default: 0.004 [S1, S3, unofficial].
- `sdf_trunc`: Truncation distance for the SDF. Default: 0.02 [S1, S3, unofficial].
- `depth_trunc`: Maximum depth range for integration. Default: 3.0 [S1, S3, unofficial].
- `init_lv`: Starting octree level for progressive extraction. Default: 8 [S2, unofficial].
- `final_lv`: Target octree level for extraction. Default: 10 [S2, unofficial].
- `bandwidth_vox`: Truncation bandwidth measured in voxel size units. Default: 5.0 [S2, unofficial].
- `alpha_thres`: Alpha threshold applied during TSDF fusion. Default: 0.5 [S2, unofficial].

**Pitfalls:**
- In non-progressive mode, octree levels strictly greater than `outside_level + final_lv` are clamped [S2, unofficial].
- In progressive mode, the initial extraction level is marked with `>>> Init level <<<` when `lv == outside_level + args.init_lv` [S2, unofficial].
- Ensure `depth_trunc` is set appropriately based on the scene's scale to avoid clipping distant geometry [S1, S3, unofficial].

**Pseudocode:**

```python
import open3d as o3d
import numpy as np

def extract_mesh_bounded(viewpoint_stack, voxel_size=0.004, sdf_trunc=0.02, depth_trunc=3.0, mask_background=True):
    """
    Extract a mesh from TSDF volume using Open3D's ScalableTSDFVolume.
    
    Args:
        viewpoint_stack: List of dictionaries containing 'rgb', 'depth', 'intrinsic', 'extrinsic', and optionally 'gt_alpha_mask'.
        voxel_size: Resolution of the TSDF volume.
        sdf_trunc: Truncation distance for the SDF.
        depth_trunc: Maximum depth range for integration.
        mask_background: Whether to mask background using alpha mask.
        
    Returns:
        o3d.geometry.TriangleMesh: Extracted mesh.
    """
    # Initialize TSDF Volume
    volume = o3d.pipelines.integration.ScalableTSDFVolume(
        voxel_length=voxel_size,
        sdf_trunc=sdf_trunc,
        color_type=o3d.pipelines.integration.TSDFVolumeColorType.RGB8
    )
    
    for i, viewpoint in enumerate(viewpoint_stack):
        # Convert camera to Open3D format
        cam_o3d = to_cam_open3d(viewpoint)
        
        # Prepare depth map
        depth = viewpoint['depth'].copy()
        
        # Background masking
        if mask_background and 'gt_alpha_mask' in viewpoint and viewpoint['gt_alpha_mask'] is not None:
            alpha_mask = viewpoint['gt_alpha_mask']
            # Set depth to 0 where alpha < 0.5
            depth[alpha_mask < 0.5] = 0.0
            
        # Prepare RGB map
        rgb = viewpoint['rgb'].copy()
        # Clip RGB to [0, 1]
        rgb = np.clip(rgb, 0.0, 1.0)
        # Scale to uint8
        rgb_uint8 = (rgb * 255).astype(np.uint8)
        
        # Create RGBD Image
        rgbd = o3d.geometry.RGBDImage.create_from_color_and_depth(
            o3d.geometry.Image(rgb_uint8),
            o3d.geometry.Image(depth.astype(np.float32)),
            depth_scale=1.0,
            depth_trunc=depth_trunc,
            convert_rgb_to_intensity=False
        )
        
        # Integrate into volume
        volume.integrate(rgbd, intrinsic=cam_o3d.intrinsic, extrinsic=cam_o3d.extrinsic)
        
    # Extract mesh
    mesh = volume.extract_triangle_mesh()
    return mesh

def to_cam_open3d(viewpoint):
    """
    Convert viewpoint dictionary to Open3D CameraIntrinsics and Extrinsic.
    This is a placeholder for actual conversion logic.
    """
    # Placeholder for camera conversion
    cam = o3d.camera.PinholeCameraIntrinsic()
    # Assume intrinsic matrix is available in viewpoint
    # cam.intrinsic_matrix = viewpoint['intrinsic']
    cam.extrinsic = viewpoint['extrinsic']
    return cam
```

## Subtopics

### [TSDF Reconstruction from Depth Maps](9982-tsdf-reconstruction-from-depth-maps.md)
This method converts per-surfel depth outputs from a 2D Gaussian Splatting (or similar primitive-based) renderer into a unified 3D mesh by computing a robust depth value per pixel and fusing the resulting depth maps via Truncated Signed Distance Function (TSDF) fusion. It differs from direct neural rendering mesh extraction by relying on explicit geometric fusion of rendered depth maps rather than differentiable surface optimization. It serves as the final step in the pipeline, taking the depth and color maps produced by [TSDF Fusion Mesh Extraction](6831-tsdf-fusion-mesh-extraction.md) (which uses Open3D's ScalableTSDFVolume) and providing the specific algorithmic details for generating the input depth maps and configuring the fusion parameters.

### SDF and RGB Fusion (Fuser)
A variant that fuses SDF and RGB information using specific parameters. It takes input coordinates `xyz` set to `voxel_model.grid_pts_xyz` and sets `bandwidth` to 20 times the minimum voxel size (`voxel_model.vox_size.min().item() * 20`) [S2, unofficial]. It uses `use_trunc=True` for truncation and `fuse_tsdf=True` to fuse the Truncated SDF [S2, unofficial]. An alternative bandwidth calculation is commented out, which would use the maximum voxel size repeated 8 times per voxel key, multiplied by 3 [S2, unofficial].

## Operating characteristics
- **Time Complexity:** Depends on the number of viewpoints and the resolution of the TSDF volume. Integration is linear with respect to the number of voxels in the truncation band for each viewpoint.
- **Memory Complexity:** Proportional to the number of voxels in the `ScalableTSDFVolume`. The octree structure allows for efficient memory usage by only storing detailed information where needed.
- **Strengths:** Robust to noise and outliers due to the truncation of the SDF. Efficient integration using Open3D's optimized C++ backend.
- **Limitations:** Requires careful tuning of `voxel_size`, `sdf_trunc`, and `depth_trunc` for different scenes. Progressive extraction can be complex to configure.
- **When to use:** Suitable for reconstructing detailed geometry from multi-view depth maps, especially in the context of 2D Gaussian Splatting.
- **When not to use:** Not ideal for real-time applications due to the offline nature of the integration and extraction process.

## Background
The method originates from the integration of depth maps into a TSDF volume, a technique widely used in 3D reconstruction [S1, S3, unofficial]. It has been adapted for use with 2D Gaussian Splatting to extract high-quality meshes from the rendered depth and color maps [S1, unofficial]. The use of Open3D's `ScalableTSDFVolume` allows for efficient handling of large scenes and varying levels of detail [S1, S3, unofficial].
