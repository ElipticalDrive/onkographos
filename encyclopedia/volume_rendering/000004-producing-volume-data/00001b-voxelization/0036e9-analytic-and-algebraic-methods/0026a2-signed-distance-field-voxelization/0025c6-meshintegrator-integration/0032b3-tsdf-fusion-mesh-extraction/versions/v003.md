# TSDF Fusion Mesh Extraction

Also called: Bounded TSDF Mesh Extraction, Direct extraction, Progressive extraction, ScalableTSDFVolume Mesh Extraction, Sparse Voxel Mesh Extraction, TSDF Volume Integration

## Overview
This method extracts a triangle mesh from a Truncated Signed Distance Function (TSDF) volume by integrating depth and color observations from multiple viewpoints. It solves the problem of converting sparse, noisy depth estimates (such as those from 2D Gaussian Splatting) into a watertight, textured 3D surface. It differs from implicit surface extraction methods by relying on explicit depth estimation followed by volumetric integration, offering a balance between geometric fidelity and computational efficiency [S1, S1, unofficial]. It builds on [MeshIntegrator Integration](3630-meshintegrator-integration.md) by consuming the integrated TSDF data to produce the final geometry.

## How it works
**Inputs:**
- A stack of RGB and depth maps from multiple viewpoints.
- Camera intrinsic and extrinsic matrices for each viewpoint.
- Optional binary masks for background removal.
- Parameters: `voxel_size`, `sdf_trunc`, `depth_trunc`, `alpha_thres`, `mask_background`.

**Outputs:**
- A triangle mesh (vertices and faces) with associated vertex colors.

**Data Structures:**
- **ScalableTSDFVolume**: An octree-based structure storing TSDF values and weights.
  - Fields: `voxel_length` (float), `sdf_trunc` (float), `color_type` (enum, e.g., RGB8).
  - Layout: Hierarchical octree nodes. Each leaf node contains a voxel grid. The sources do not specify the exact bit-packing of the TSDF value and weight within the node, but standard Open3D implementations typically use 16-bit or 32-bit floats for distance and weight. [G] Default precision is usually 16-bit for memory efficiency in scalable volumes.

**Steps:**

1. **Initialize Volume:**
   Create a `ScalableTSDFVolume` with the specified `voxel_size`, `sdf_trunc`, and `color_type=RGB8`.
   $$ \text{voxel\_length} = \text{voxel\_size} $$
   $$ \text{sdf\_trunc} = \text{sdf\_trunc} $$

2. **Prepare RGBD Images:**
   For each viewpoint in the stack:
   a. If `mask_background` is True and a ground truth alpha mask exists, set depth values where alpha $< 0.5$ to 0 (invalid).
   b. Clip RGB values to $[0, 1]$.
   c. Multiply RGB by 255 and cast to `uint8`.
   d. Create an `RGBDImage` from the RGB and depth maps.
   e. Set `depth_scale = 1.0` and `depth_trunc` for the image creation.

3. **Integrate:**
   For each `RGBDImage`:
   a. Call `integrate(rgbd_image, intrinsic, extrinsic)` on the volume.
   b. The integration updates the TSDF value and weight for all voxels intersected by the camera frustum within `depth_trunc`.

4. **Extract Mesh:**
   Depending on the mode:
   - **Non-progressive:** Call `extract_mesh()` using `final_lv`.
   - **Progressive:** Call `extract_mesh_progressive()` starting from `init_lv` up to `final_lv`.

**Parameters:**
- `voxel_size`: Resolution of the TSDF volume. Default: 0.004 [S1, unofficial].
- `sdf_trunc`: Truncation distance for the SDF. Default: 0.02 [S1, unofficial].
- `depth_trunc`: Maximum depth range for integration. Default: 3.0 [S1, unofficial].
- `alpha_thres`: Alpha threshold applied during TSDF fusion. Default: 0.5 [S2, unofficial].
- `mask_background`: Whether to mask background. Default: True [S1, unofficial].
- `init_lv`: Starting octree level for progressive extraction. Default: 8 [S2, unofficial].
- `final_lv`: Target octree level for extraction. Default: 10 [S2, unofficial].
- `bandwidth_vox`: Truncation bandwidth measured in voxel size units. Default: 5.0 [S2, unofficial].

**Pseudocode:**

```python
import open3d as o3d
import numpy as np

def extract_mesh_bounded(viewpoint_stack, voxel_size=0.004, sdf_trunc=0.02, 
                         depth_trunc=3.0, alpha_thres=0.5, mask_background=True):
    """
    Extract mesh from TSDF volume using Open3D's ScalableTSDFVolume.
    """
    # 1. Initialize ScalableTSDFVolume
    # voxel_length: size of one voxel in world units
    # sdf_trunc: truncation distance
    # color_type: o3d.pipelines.integration.TSDFVolumeColorType.RGB8
    voxel_length = voxel_size
    tsdf_vol = o3d.pipelines.integration.ScalableTSDFVolume(
        voxel_length=voxel_length,
        sdf_trunc=sdf_trunc,
        color_type=o3d.pipelines.integration.TSDFVolumeColorType.RGB8
    )

    # 2. Iterate through viewpoints
    for cam in viewpoint_stack:
        # Get RGB and Depth maps
        rgb_map = cam.rgb_map
        depth_map = cam.depth_map
        intrinsic = cam.intrinsic
        extrinsic = cam.extrinsic

        # 2a. Background masking
        if mask_background and cam.has_alpha_mask:
            alpha_mask = cam.alpha_mask
            # Set depth to 0 where alpha < threshold
            depth_map[alpha_mask < alpha_thres] = 0.0

        # 2b. Prepare RGBDImage
        # Clip RGB to [0, 1]
        rgb_clipped = np.clip(rgb_map, 0.0, 1.0)
        # Convert to uint8 [0, 255]
        rgb_uint8 = (rgb_clipped * 255).astype(np.uint8)
        
        # Create RGBDImage
        # depth_scale is 1.0 as per source
        rgbd = o3d.geometry.RGBDImage.create_from_color_and_depth(
            o3d.geometry.Image(rgb_uint8),
            o3d.geometry.Image(depth_map.astype(np.float32)),
            depth_scale=1.0,
            depth_trunc=depth_trunc,
            convert_rgb_to_intensity=False
        )

        # 2c. Integrate into volume
        tsdf_vol.integrate(rgbd, intrinsic, extrinsic)

    # 3. Extract Mesh
    # Default to non-progressive extraction if not specified
    mesh = tsdf_vol.extract_triangle_mesh()
    
    return mesh
```

**Edge Cases and Pitfalls:**
- **Depth Truncation:** If `depth_trunc` is too small, distant geometry is missed. If too large, noise from far-away background is integrated. It should depend on the scene's scales [S1, unofficial].
- **Alpha Threshold:** Incorrect `alpha_thres` can lead to noisy boundaries or missing geometry if the alpha mask is not reliable [S2, unofficial].
- **Level Clamping:** In non-progressive mode, octree levels strictly greater than `outside_level + final_lv` are clamped, indicated by the suffix `>>> Level clamped <<<` in logs [S2, unofficial].
- **Progressive Initialization:** In progressive mode, the initial extraction level is marked with `>>> Init level <<<` when `lv == outside_level + args.init_lv` [S2, unofficial].

### [TSDF Reconstruction from Depth Maps](9982-tsdf-reconstruction-from-depth-maps.md)
Converts per-surfel depth outputs from a 2D Gaussian Splatting variant into a unified 3D mesh by computing a robust depth value per pixel and fusing the resulting depth maps via TSDF fusion. It differs from implicit surface extraction methods by relying on explicit depth estimation followed by volumetric integration, offering a balance between geometric fidelity and computational efficiency.

## Operating characteristics
- **Time Complexity:** Linear with respect to the number of voxels integrated and the number of viewpoints. The octree structure allows adaptive resolution, but integration still requires visiting all active voxels in the frustum.
- **Memory Complexity:** Proportional to the number of active voxels in the `ScalableTSDFVolume`. The octree structure reduces memory usage compared to a dense grid, especially for sparse scenes.
- **Performance:** Depends heavily on `voxel_size` and `depth_trunc`. Smaller voxel sizes increase memory and computation time significantly.
- **Strengths:** Robust to noise; handles multi-view consistency well; produces watertight meshes.
- **Limitations:** Requires accurate depth maps; sensitive to `sdf_trunc` and `voxel_size` selection; may introduce artifacts if depth maps are noisy or incomplete.
- **When to use:** When high-quality mesh extraction from multi-view depth data is required, and computational resources allow for volumetric integration.
- **When not to use:** For real-time applications where memory is constrained, or when depth maps are extremely noisy or sparse.

## Background
The method originates from the integration of Truncated Signed Distance Functions (TSDF) for 3D reconstruction, popularized by algorithms like KinectFusion [G]. In the context of 2D Gaussian Splatting, it was adapted to extract meshes from the depth and color outputs of the splats, as seen in the `2d-gaussian-splatting` repository [S1, unofficial]. The use of `ScalableTSDFVolume` allows for efficient handling of large scenes by using an octree structure.
