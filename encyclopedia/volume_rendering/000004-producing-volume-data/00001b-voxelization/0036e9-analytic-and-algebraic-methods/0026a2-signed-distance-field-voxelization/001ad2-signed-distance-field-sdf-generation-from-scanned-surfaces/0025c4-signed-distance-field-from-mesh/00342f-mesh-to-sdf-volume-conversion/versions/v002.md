# Mesh to SDF Volume Conversion

Also called: Mesh SDF Volume Generation, Mesh to Atlas SDF

## Overview
This method converts a watertight 3D mesh into a voxelized Signed Distance Field (SDF) volume [S1, unofficial][S2, unofficial]. It solves the problem of creating a continuous implicit representation from discrete triangle data for use in volume rendering or differentiable rendering pipelines [S1, unofficial]. It is distinguished from naive CPU-based generation by its use of GPU-accelerated ray tracing for initial occupancy and fast sweeping for redistancing, often followed by a surface refinement pass to reduce discretization error [S1, unofficial]. It differs from TSDF fusion methods by relying on a single static mesh instance rather than multi-view sensor fusion [S2, unofficial].

## How it works
**Inputs:**
- A watertight manifold 3D mesh (e.g., STL, OBJ) [S1, unofficial][S2, unofficial].
- Grid resolution `res` (integer, e.g., 64, 128) [S1, unofficial].
- Grid bounds normalized to $[-0.5, 0.5]$ in each dimension [S1, unofficial].
- Boolean flag `refine_surface` (default `true`) [S1, unofficial].
- Angular resolution `angular_res` for refinement (default 16) [S1, unofficial].

**Outputs:**
- A 3D tensor/grid of floats representing the SDF values at voxel centers [S1, unofficial].
- Alternatively, an atlas texture containing the SDF values [S2, unofficial].

**Data Structures:**
- `mi.TensorXf`: A multi-dimensional tensor structure holding the grid values with layout `(res, res, res)` [S1, unofficial].
- `mi.Ray3f`: Ray structure containing origin `o` and direction `d` [S1, unofficial].
- `si` (Surface Interaction): Intersection result containing validity flag, hit distance `t`, and surface normal `n` [S1, unofficial].

**Steps:**

1. **Grid Initialization:**
   Create a 3D grid of ray origins covering the volume bounds using `dr.meshgrid` and `dr.linspace` over the range $[-0.5, 0.5]$ with resolution `res` [S1, unofficial]. Rays are cast in the $+Y$ direction ($\vec{d} = (0, 1, 0)$) [S1, unofficial].

2. **Ray-Mesh Intersection & Occupancy:**
   For each voxel center, cast a ray in the $+Y$ direction and intersect with the mesh [S1, unofficial]. Compute binary occupancy value $v$:
   $$
   v = \begin{cases} 
   1.0 & \text{if intersection is valid AND } \vec{n} \cdot \vec{d} > 0 \\
   0.0 & \text{otherwise}
   \end{cases}
   $$
   where $\vec{n}$ is the surface normal at the hit point and $\vec{d}$ is the ray direction [S1, unofficial]. The condition $\vec{n} \cdot \vec{d} > 0$ ensures front-face culling [S1, unofficial].

3. **Initial SDF Estimation:**
   Invert the occupancy to get an initial signed distance approximation using $\text{initial\_values} = 0.5 - v$ [S1, unofficial]. This results in values of $0.5$ (outside, if $v=0$) and $-0.5$ (inside, if $v=1$) [S1, unofficial].

4. **Fast Sweeping Redistancing:**
   Apply a fast sweeping algorithm to propagate the signed distance from the initial binary grid to a true Euclidean distance field [S1, unofficial].
   $$
   \text{grid} = \text{redistance}(\text{initial\_values})
   $$
   This step ensures the grid values represent the true distance to the nearest surface, preserving the sign [S1, unofficial].

5. **Surface Refinement (Optional):**
   If `refine_surface` is true:
   a. Identify voxels close to the surface where $|\text{grid}[i]| < 1.0 / \text{res}$ [S1, unofficial].
   b. For each such voxel center $\vec{o}$, generate `angular_res^2` rays uniformly distributed over the sphere using `square_to_uniform_sphere` [S1, unofficial].
   c. Trace these rays against the mesh and find the minimum hit distance $d_{min}$ for each voxel center across all angular samples [S1, unofficial].
   d. Preserve the sign of the existing SDF value:
      $$
      d_{final} = d_{min} \times \text{sign}(\text{grid}[i])
      $$
   e. Update the grid values with $d_{final}$ for the near-surface voxels [S1, unofficial].
   f. Re-apply redistancing to smooth the updated values [S1, unofficial].

6. **Atlas Texture Update (Alternative Output):**
   If using an atlas texture approach, initialize the texture with resolution, origin, and voxel size using `volumeRenderer.createAtlasTexture` [S2, unofficial]. Update the texture by invoking a mesh sampler function with world coordinates for each voxel [S2, unofficial].

**Pseudocode:**

```python
import numpy as np

def mesh_to_sdf(mesh, res, refine_surface=True, angular_res=16):
    # Step 1: Grid Initialization
    coords = np.linspace(-0.5, 0.5, res)
    x, y, z = np.meshgrid(coords, coords, coords, indexing='ij')
    origins = np.stack([x.ravel(), y.ravel(), z.ravel()], axis=-1)
    ray_directions = np.array([0.0, 1.0, 0.0])
    rays = list(zip(origins, [ray_directions] * len(origins)))

    # Step 2: Ray-Mesh Intersection & Occupancy
    intersections = mesh.ray_intersect_batch(rays)
    values = np.zeros(len(intersections))
    for i, si in enumerate(intersections):
        if si.is_valid and np.dot(si.n, ray_directions) > 0:
            values[i] = 1.0
        else:
            values[i] = 0.0

    # Step 3: Initial SDF Estimation
    initial_values = 0.5 - values

    # Step 4: Fast Sweeping Redistancing
    grid = initial_values.reshape(res, res, res)
    grid = fast_sweep_redistance(grid)  # [G] Standard fast sweeping algorithm

    # Step 5: Surface Refinement
    if refine_surface:
        indices = np.arange(res ** 3)
        near_surface_mask = np.abs(grid.ravel()) < 1.0 / res
        near_surface_indices = indices[near_surface_mask]

        if len(near_surface_indices) > 0:
            # Reconstruct origins for near-surface voxels
            x_idx = near_surface_indices % res
            y_idx = (near_surface_indices // res) % res
            z_idx = near_surface_indices // (res * res)
            step = 1.0 / (res - 1)  # Spacing from linspace
            ray_o_near = np.stack([
                -0.5 + (x_idx + 0.5) * step,
                -0.5 + (y_idx + 0.5) * step,
                -0.5 + (z_idx + 0.5) * step
            ], axis=-1)

            n_angle_samples = angular_res ** 2
            r = np.arange(angular_res)
            u, v = np.meshgrid((r + 0.5) / angular_res, (r + 0.5) / angular_res)
            uv = np.stack([u.ravel(), v.ravel()], axis=-1)
            uv = np.tile(uv, (len(ray_o_near), 1))

            # Generate refined rays
            refined_origins = np.repeat(ray_o_near, n_angle_samples, axis=0)
            refined_dirs = uniform_sphere_samples(uv)  # [G] Maps UV to sphere directions
            refined_rays = list(zip(refined_origins, refined_dirs))

            # Trace refined rays
            si_refined = mesh.ray_intersect_batch(refined_rays)
            t_values = np.array([si.t if si.is_valid else 100.0 for si in si_refined])

            # Find minimum distance per voxel
            min_dist = np.full(len(near_surface_indices), 100.0)
            for i in range(n_angle_samples):
                col = t_values[i::n_angle_samples]
                min_dist = np.minimum(min_dist, col)

            # Preserve sign
            existing_vals = grid.ravel()[near_surface_indices]
            signs = np.sign(existing_vals)
            min_dist = min_dist * signs

            # Scatter back
            grid.ravel()[near_surface_indices] = min_dist
            grid = fast_sweep_redistance(grid)  # [G] Re-redistance

    return grid
```

**Edge Cases and Pitfalls:**
- **Non-watertight meshes:** The method assumes a watertight mesh [S1, unofficial].

## Background
The method is derived from differentiable SDF rendering techniques, specifically those implemented in the Mitsuba 3 renderer [S1, unofficial]. It leverages the differentiable nature of ray tracing and redistancing to create SDFs that can be optimized or used in gradient-based pipelines [S1, unofficial]. The atlas texture approach is associated with volume rendering in web-based contexts using Three.js [S2, unofficial].
