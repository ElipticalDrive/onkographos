# SDF Training Data Resampling

Also called: Point cloud sampling for SDF, volume/surface resampling

## Overview
Generates a balanced set of training points (surface, uniform, volume) with ground-truth Signed Distance Field (SDF) values for neural network training [S1, unofficial]. It differs from [SDF Grid Resampling from File](4878-sdf-grid-resampling-from-file.md) by constructing the point cloud directly from a mesh via raycasting/BVH queries rather than interpolating from an existing voxel grid, and from [Mesh Normalization](3796-mesh-normalization.md) by adding the sampling and distance query logic on top of coordinate normalization.

## How it works
**Inputs:** A triangular mesh (vertices $\mathbf{V}$, faces $\mathbf{F}$), total sample count $N$, surface ratio $r_s$, uniform ratio $r_u$, perturbation range $d$, target radius $R_{target}$.
**Outputs:** Tensor of points $\mathbf{P} \in \mathbb{R}^{N \times 3}$, Tensor of SDF values $\mathbf{D} \in \mathbb{R}^{N}$.

**Data Structures:**
*   `cuBVH`: A CUDA-accelerated bounding volume hierarchy storing mesh vertices and faces, supporting nearest-point and distance queries.
*   `points_list`, `distances_list`: Lists of tensors to be concatenated.

**Parameters:**
*   $r_s$: Surface ratio. Default $0.0$ [S1, unofficial].
*   $r_u$: Uniform ratio. Default $0.05$ [S1, unofficial].
*   $d$: Perturbation range for volume points. Fixed at $0.2$ [S1, unofficial].
*   $R_{target}$: Normalization radius. Fixed at $1.0 / 1.03 \approx 0.9709$ [S1, unofficial].
*   $\sigma$: Perturbation standard deviation. $\sigma = d / 6.0$ [S1, unofficial].

**Steps:**
1.  **Normalize Mesh:**
    *   Compute vertex center $\mathbf{C} = \frac{1}{M}\sum \mathbf{V}_i$.
    *   Center vertices: $\mathbf{V}'_i = \mathbf{V}_i - \mathbf{C}$.
    *   Compute max norm $r_{max} = \max_i \|\mathbf{V}'_i\|$. Clamp $r_{max}$ to $\epsilon$ if zero.
    *   Scale vertices: $\mathbf{V}''_i = \mathbf{V}'_i \times \frac{R_{target}}{r_{max}}$.
2.  **Build BVH:** Construct `cuBVH` from $\mathbf{V}''$ and $\mathbf{F}$.
3.  **Calculate Counts:**
    *   $N_s = \lfloor N \times r_s \rfloor$
    *   $N_u = \lfloor N \times r_u \rfloor$
    *   $N_v = N - N_s - N_u$
4.  **Surface Points:**
    *   If $N_s > 0$: Repeat vertices cyclically to get $N_s$ points. Shuffle. Query BVH for SDF (should be $\approx 0$).
5.  **Uniform Points:**
    *   If $N_u > 0$: Sample $N_u$ points uniformly from $[-1, 1]^3$. Query BVH for SDF.
6.  **Volume Points:**
    *   If $N_v > 0$:
        *   Select $N_v$ anchor points from mesh vertices (with replacement if necessary).
        *   Generate Gaussian noise $\mathbf{\Delta} \sim \mathcal{N}(0, \sigma^2 I)$.
        *   Clip perturbation magnitude: if $\|\mathbf{\Delta}\| > d$, scale $\mathbf{\Delta} \leftarrow \mathbf{\Delta} \times \frac{d}{\|\mathbf{\Delta}\|}$.
        *   Perturbed points $\mathbf{P}_v = \text{Anchors} + \mathbf{\Delta}$.
        *   Query BVH for SDF values.
7.  **Concatenate:** Combine surface, uniform, and volume points and their distances. Shuffle the final dataset.

**Pseudocode:**

```python
import torch
import numpy as np

def resample_sdf(mesh_vertices, mesh_faces, total_samples, surface_ratio=0.0, uniform_ratio=0.05, d=0.2):
    """
    Resample training data for SDF.
    mesh_vertices: np.array (N, 3)
    mesh_faces: np.array (M, 3)
    total_samples: int
    """
    # 1. Normalize Mesh
    center = mesh_vertices.mean(axis=0)
    centered_verts = mesh_vertices - center
    r_max = np.linalg.norm(centered_verts, axis=1).max()
    if r_max < 1e-8:
        r_max = 1e-8
    target_radius = 1.0 / 1.03
    scale = target_radius / r_max
    normalized_verts = centered_verts * scale
    
    # 2. Build BVH (Pseudocode assumes a hypothetical cuBVH interface)
    # In practice, this calls the CUDA library. Here we assume a query function.
    bvh = build_cubvh(normalized_verts, mesh_faces)
    
    # 3. Calculate Counts
    num_surface = int(total_samples * surface_ratio)
    num_uniform = int(total_samples * uniform_ratio)
    num_volume = total_samples - num_surface - num_uniform
    
    points_list = []
    dists_list = []
    
    # 4. Surface Points
    if num_surface > 0:
        n_verts = normalized_verts.shape[0]
        repeat_factor = (num_surface + n_verts - 1) // n_verts
        # Repeat vertices to fill count
        surf_pts = np.tile(normalized_verts, (repeat_factor, 1))[:num_surface]
        # Shuffle
        idx = np.random.permutation(num_surface)
        surf_pts = surf_pts[idx]
        
        # Query SDF (should be ~0)
        surf_dists = query_bvh_sdf(bvh, surf_pts)
        points_list.append(surf_pts)
        dists_list.append(surf_dists)
        
    # 5. Uniform Points
    if num_uniform > 0:
        # Sample from [-1, 1]^3
        unif_pts = np.random.uniform(-1, 1, size=(num_uniform, 3))
        unif_dists = query_bvh_sdf(bvh, unif_pts)
        points_list.append(unif_pts)
        dists_list.append(unif_dists)
        
    # 6. Volume Points
    if num_volume > 0:
        # Select anchors from vertices
        anchor_indices = np.random.choice(normalized_verts.shape[0], num_volume, replace=True)
        anchors = normalized_verts[anchor_indices]
        
        # Generate Gaussian noise
        sigma = d / 6.0
        delta = np.random.normal(0, sigma, size=(num_volume, 3))
        
        # Clip perturbation magnitude to d
        norms = np.linalg.norm(delta, axis=1, keepdims=True)
        mask = norms > d
        if mask.any():
            delta[mask] = delta[mask] * (d / norms[mask])
            
        vol_pts = anchors + delta
        vol_dists = query_bvh_sdf(bvh, vol_pts)
        points_list.append(vol_pts)
        dists_list.append(vol_dists)
        
    # 7. Concatenate and Shuffle
    all_points = np.concatenate(points_list, axis=0)
    all_dists = np.concatenate(dists_list, axis=0)
    
    shuffle_idx = np.random.permutation(len(all_points))
    return all_points[shuffle_idx], all_dists[shuffle_idx]
```

**Edge Cases:**
*   $r_{max} = 0$: Clamped to $\epsilon$ to avoid division by zero [S1, unofficial].
*   $N_v < 0$: If $r_s + r_u > 1$, $N_v$ becomes negative. The code assumes $r_s + r_u \le 1$. If $N_v < 0$, the logic fails. [G] Guard: ensure $r_s + r_u \le 1$.
*   Mesh with no vertices: Handled by $r_{max}$ clamp.

## Operating characteristics
*   **Time Complexity:** Dominated by BVH construction $O(M \log M)$ and $N$ queries $O(N \log M)$, where $M$ is face count.
*   **Memory Complexity:** $O(N + M)$ for storing points and BVH.
*   **Strengths:** Provides explicit control over surface vs. volume point distribution, crucial for training SDF networks to converge correctly.
*   **Limitations:** Requires a watertight or nearly watertight mesh for accurate SDF queries via BVH. Noise clipping is heuristic.
*   **When to use:** When training neural SDFs from mesh data and a balanced point cloud is required.
*   **When not to use:** When a pre-computed voxel grid is available (use [SDF Grid Resampling from File](4878-sdf-grid-resampling-from-file.md)).

## Background
Originated in the TetraSDF project by Naver AI [S1, unofficial]. The method uses `cubvh` for fast CUDA-based SDF queries and `trimesh` for mesh loading. The perturbation strategy ($d=0.2, \sigma=d/6$) ensures volume points are close to the surface but not exactly on it, helping the network learn the transition zone.
