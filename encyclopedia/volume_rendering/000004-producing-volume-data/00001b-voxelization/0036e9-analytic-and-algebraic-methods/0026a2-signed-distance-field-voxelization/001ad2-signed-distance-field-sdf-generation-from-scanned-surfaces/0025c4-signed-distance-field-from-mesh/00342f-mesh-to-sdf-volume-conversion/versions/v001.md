# Mesh to SDF Volume Conversion

Also called: Mesh SDF Volume Generation, Mesh to Atlas SDF

## Overview
This method converts a watertight 3D mesh into a voxelized Signed Distance Field (SDF) volume. It solves the problem of creating a continuous implicit representation from discrete triangle data for use in volume rendering or differentiable rendering pipelines. It is distinguished from naive CPU-based generation by its use of GPU-accelerated ray tracing for initial occupancy and fast sweeping for redistancing, often followed by a surface refinement pass to reduce discretization error [S1, unofficial]. It differs from TSDF fusion methods by relying on a single static mesh instance rather than multi-view sensor fusion [S2, unofficial].

## How it works
**Inputs:**
- A watertight manifold 3D mesh (e.g., STL, OBJ) [S1, unofficial][S2, unofficial].
- Grid resolution `res` (integer, e.g., 64, 128) [S1, unofficial].
- Grid bounds: typically normalized to $[-0.5, 0.5]$ in each dimension, or defined by mesh bounding box [S1, unofficial].
- Boolean flag `refine_surface` (default `true`) [S1, unofficial].
- Angular resolution `angular_res` for refinement (default 16) [S1, unofficial].

**Outputs:**
- A 3D tensor/grid of floats representing the SDF values at voxel centers [S1, unofficial].
- Alternatively, an atlas texture containing the SDF values [S2, unofficial].

**Data Structures:**
- `mi.TensorXf`: A multi-dimensional tensor structure holding the grid values. Layout is `(res, res, res)` [S1, unofficial].
- `mi.Ray3f`: Ray structure containing origin `o` and direction `d` [S1, unofficial].
- `si` (Surface Interaction): Intersection result containing validity flag, hit distance `t`, and surface normal `n` [S1, unofficial].

**Steps:**

1. **Grid Initialization:**
   Create a 3D grid of ray origins covering the volume bounds. For a resolution `res` and bounds $[-0.5, 0.5]$, origins are spaced by $1/res$. Rays are cast in the $+Y$ direction ($\vec{d} = (0, 1, 0)$) [S1, unofficial].

2. **Ray-Mesh Intersection & Occupancy:**
   For each voxel center, cast a ray in the $+Y$ direction. Intersect with the mesh.
   Compute binary occupancy value $v$:
   $$
   v = \begin{cases} 
   1.0 & \text{if intersection is valid AND } \vec{n} \cdot \vec{d} > 0 \\
   0.0 & \text{otherwise}
   \end{cases}
   $$
   where $\vec{n}$ is the surface normal at the hit point and $\vec{d}$ is the ray direction. The condition $\vec{n} \cdot \vec{d} > 0$ ensures front-face culling, assuming the mesh normals point outward [S1, unofficial].

3. **Initial SDF Estimation:**
   Invert the occupancy to get an initial signed distance approximation. The value $0.5$ represents the surface (halfway between inside 0 and outside 1).
   $$
   \text{initial\_values} = 0.5 - v
   $$
   This results in values of $0.5$ (surface), $0.5$ (outside, if $v=0$), and $-0.5$ (inside, if $v=1$). Note: The source code uses `0.5 - values`, implying $v=1$ (inside) yields $-0.5$ and $v=0$ (outside) yields $0.5$. This assumes the ray hits the *first* surface from $-Y$ or that the geometry is convex/simple enough that a single ray determines inside/outside correctly relative to the camera/view direction. *Correction*: Standard ray casting for SDF usually requires checking if the ray origin is inside or outside. The provided code snippet implies a specific convention where $v=1$ means "hit front face", which might imply the ray originated from outside and hit the front face, or it's a specific differentiable rendering setup. We follow the source exactly: `values = 0.5 - values` [S1, unofficial].

4. **Fast Sweeping Redistancing:**
   Apply a fast sweeping algorithm to propagate the signed distance from the initial binary grid to a true Euclidean distance field.
   $$
   \text{grid} = \text{redistance}(\text{initial\_values})
   $$
   This step ensures the grid values represent the true distance to the nearest surface, preserving the sign [S1, unofficial].

5. **Surface Refinement (Optional):**
   If `refine_surface` is true:
   a. Identify voxels close to the surface where $|\text{grid}[i]| < 1.0 / \text{res}$ [S1, unofficial].
   b. For each such voxel center $\vec{o}$, generate `angular_res^2` rays uniformly distributed over the sphere. Directions are computed using `square_to_uniform_sphere` mapping from a 2D grid of UV coordinates [S1, unofficial].
   c. Trace these rays against the mesh. Find the minimum hit distance $d_{min}$ for each voxel center across all angular samples [S1, unofficial].
   d. Preserve the sign of the existing SDF value:
      $$
      d_{final} = d_{min} \times \text{sign}(\text{grid}[i])
      $$
   e. Update the grid values with $d_{final}$ for the near-surface voxels [S1, unofficial].
   f. Re-apply redistancing to smooth the updated values [S1, unofficial].

6. **Atlas Texture Update (Alternative Output):**
   If using an atlas texture approach, initialize the texture with resolution, origin, and voxel size. Update the texture by invoking a mesh sampler function with world coordinates for each voxel [S2, unofficial].

**Pseudocode:**

```python
import mitsuba as mi
import drjit as dr
import numpy as np

def mesh_to_sdf(mesh, res, refine_surface=True, angular_res=16):
    """
    Convert a mesh to an SDF volume using ray tracing and fast sweeping.
    
    Args:
        mesh: Mitsuba mesh object.
        res: Grid resolution (integer).
        refine_surface: Boolean, whether to refine near-surface voxels.
        angular_res: Resolution for angular sampling during refinement.
        
    Returns:
        mi.TensorXf: The SDF grid.
    """
    # Step 1: Create grid of ray origins
    # Bounds [-0.5, 0.5]
    coords = dr.linspace(mi.Float, -0.5, 0.5, res)
    x, y, z = dr.meshgrid(coords, coords, coords)
    
    # Flatten to 1D array of origins
    origins = dr.flatten(mi.Point3f(x, y, z))
    
    # Step 2: Cast rays in +Y direction
    ray_d = mi.Vector3f(0, 1, 0)
    rays = mi.Ray3f(origins, ray_d)
    
    # Intersect with mesh
    si = mesh.ray_intersect(rays)
    
    # Compute occupancy: 1.0 if hit front-face, 0.0 otherwise
    # Front-face: normal dot direction > 0
    is_valid = si.is_valid()
    front_face = dr.dot(si.n, ray_d) > 0
    values = dr.select(is_valid & front_face, 1.0, 0.0)
    
    # Step 3: Initial SDF estimation
    # Invert occupancy: 0.5 - value
    # Inside (hit front face) -> 0.5 - 1.0 = -0.5
    # Outside (no hit or back face) -> 0.5 - 0.0 = 0.5
    initial_values = 0.5 - values
    
    # Reshape to 3D tensor (res, res, res)
    grid_tensor = mi.TensorXf(initial_values, (res, res, res))
    
    # Step 4: Fast sweeping redistancing
    grid = mi.TensorXf(mi.redistancing.redistance(grid_tensor))
    
    # Step 5: Surface refinement
    if refine_surface:
        # Identify voxels close to surface
        indices = dr.arange(mi.UInt32, res ** 3)
        # Gather current grid values
        current_vals = dr.gather(mi.Float, grid.array, indices)
        near_surface_mask = dr.abs(current_vals) < 1.0 / res
        near_surface_indices = indices[near_surface_mask]
        
        if dr.size(near_surface_indices) > 0:
            # Get world space origins for near-surface voxels
            ray_o_near = dr.gather(mi.Point3f, grid.o, near_surface_indices) # Assuming grid.o stores origins? 
            # Note: In the source, ray.o is used. We need to reconstruct origins or store them.
            # Reconstructing origins for simplicity in this pseudocode:
            # Map index back to 3D coordinates
            idx = near_surface_indices
            x_idx = idx % res
            y_idx = (idx // res) % res
            z_idx = idx // (res * res)
            
            # Convert indices to world coordinates [-0.5, 0.5]
            # Assuming uniform grid from -0.5 to 0.5
            step = 1.0 / res
            ox = -0.5 + (x_idx + 0.5) * step
            oy = -0.5 + (y_idx + 0.5) * step
            oz = -0.5 + (z_idx + 0.5) * step
            
            ray_o_near = mi.Point3f(ox, oy, oz)
            
            # Generate angular samples
            n_angle_samples = angular_res ** 2
            r = dr.arange(mi.Float, angular_res)
            u, v = dr.meshgrid((r + 0.5) / angular_res, (r + 0.5) / angular_res)
            uv = dr.tile(mi.Vector2f(u, v), dr.size(ray_o_near))
            
            # Create refined rays
            rays_refined = mi.Ray3f(dr.repeat(ray_o_near, n_angle_samples), 
                                    mi.warp.square_to_uniform_sphere(uv))
            
            # Intersect refined rays
            si_refined = mesh.ray_intersect(rays_refined)
            
            # Find minimum distance for each voxel
            # si_refined.t contains distances for all angular samples
            # We need to gather min distance per voxel
            min_dist = dr.full(mi.Float, 100.0, dr.size(near_surface_indices))
            
            # Loop over angular samples to find min
            # This is a simplified loop; in practice, use dr.minimum over the flattened array
            # Reshape si_refined.t to (n_near, n_angles)
            t_flat = si_refined.t
            # Reshape to (n_near_surface_indices, n_angle_samples)
            t_reshaped = dr.reshape(t_flat, (dr.size(near_surface_indices), n_angle_samples))
            
            # Find min along the angular dimension
            # Note: dr.minimum.reduce might be needed depending on drjit version
            # Assuming dr.minimum.reduce exists or using a loop for clarity
            min_dists = dr.full(mi.Float, 100.0, dr.size(near_surface_indices))
            for i in range(n_angle_samples):
                col = dr.gather(mi.Float, t_reshaped, i) # This syntax is illustrative
                # Correct drjit way:
                col = t_reshaped[:, i]
                min_dists = dr.minimum(min_dists, col)
            
            # Modulate by sign of existing SDF
            existing_vals = dr.gather(mi.Float, grid.array, near_surface_indices)
            signs = dr.sign(existing_vals)
            min_dist = min_dists * signs
            
            # Scatter back to grid
            dr.scatter(grid.array, min_dist, near_surface_indices)
            
            # Re-redistance
            grid = mi.TensorXf(mi.redistancing.redistance(grid))
            
    return grid
```

**Edge Cases and Pitfalls:**
- **Non-watertight meshes:** The method assumes a watertight mesh. Non-watertight meshes may result in incorrect inside/outside classification [S1, unofficial].
- **Precision:** Floating-point precision issues may arise in the redistancing step for very large grids or complex geometries [S1, unofficial].
- **Boundary Conditions:** The grid bounds must encompass the entire mesh. Voxels outside the mesh bounds will have incorrect distances if not handled [S1, unofficial].
- **Angular Sampling:** The number of angular samples (`angular_res^2`) affects the accuracy of the surface refinement. Too few samples may miss the closest surface point [S1, unofficial].

## Operating characteristics
- **Time Complexity:** $O(N \cdot A)$, where $N$ is the number of voxels and $A$ is the number of angular samples per voxel during refinement. The redistancing step is typically $O(N)$ with a small constant factor [S1, unofficial].
- **Memory Complexity:** $O(N)$ for storing the grid and intermediate ray intersection data [S1, unofficial].
- **Performance:** GPU-accelerated ray tracing allows for fast generation of large grids (e.g., 128^3) in seconds [S1, unofficial].
- **Strengths:** High accuracy with surface refinement; differentiable (if using differentiable rendering framework) [S1, unofficial].
- **Limitations:** Requires a watertight mesh; refinement step can be computationally expensive for high resolutions [S1, unofficial].

## Background
The method is derived from differentiable SDF rendering techniques, specifically those implemented in the Mitsuba 3 renderer [S1, unofficial]. It leverages the differentiable nature of ray tracing and redistancing to create SDFs that can be optimized or used in gradient-based pipelines. The atlas texture approach is associated with volume rendering in web-based contexts using Three.js [S2, unofficial].
