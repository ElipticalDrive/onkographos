# Sampling SDF Near Surface

Also called: DeepSDF Sampling

## Overview
This method generates a set of query points for training or evaluating Signed Distance Fields (SDFs) by concentrating samples near the mesh surface while maintaining a sparse background of uniform samples. It addresses the problem of insufficient surface detail in SDF training data by oversampling the region immediately surrounding the geometry. It differs from pure uniform sampling by prioritizing surface proximity, following the strategy proposed in the DeepSDF paper [S1, unofficial].

## How it works
**Inputs:**
- `mesh`: The input triangular mesh.
- `number_of_points`: Total number of query points to generate. Default: 500,000 [S1, unofficial].
- `surface_point_method`: Method to generate surface points (e.g., 'scan', 'sample') [S1, unofficial].
- `sign_method`: Method to determine SDF sign (e.g., 'normal', 'depth') [S1, unofficial].
- `scan_count`: Number of virtual camera scans if using scan-based surface sampling [S1, unofficial].
- `scan_resolution`: Resolution of each scan buffer [S1, unofficial].
- `sample_point_count`: Number of points to sample per scan or surface method iteration [S1, unofficial].
- `normal_sample_count`: Number of samples for normal-based sign determination [S1, unofficial].
- `min_size`: Optional minimum volume ratio check [S1, unofficial].
- `return_gradients`: Boolean flag to compute gradients [S1, unofficial].

**Outputs:**
- A list or array of query points $(x, y, z)$ and their corresponding SDF values and signs.

**Data Structures:**
- `surface_point_cloud`: A collection of 3D points derived from the mesh, optionally with normals.
- `query_points`: The final set of $N$ points sampled near the surface and in the volume.

**Steps:**
1. **Scale Mesh**: Transform the input mesh to fit within a unit sphere. This is achieved by scaling the mesh such that its bounding sphere has a radius of 1 [S1, unofficial].
   $$ \text{mesh}_{scaled} = \text{scale\_to\_unit\_sphere}(\text{mesh}) $$
2. **Generate Surface Point Cloud**: Create a dense point cloud representing the mesh surface.
   - Call `get_surface_point_cloud` with the scaled mesh, `surface_point_method`, bounding radius 1, `scan_count`, `scan_resolution`, `sample_point_count`, and `calculate_normals` set to `True` if `sign_method` is 'normal' or `return_gradients` is `True` [S1, unofficial].
3. **Sample Query Points**: Generate the final query points using the following distribution [S1, unofficial]:
   - **Surface Proximity Samples (47/50 of total)**:
     - Sample 47/50 of the total points in two stages:
       1. Sample half of the required surface points (i.e., $47/100$ of total) from the surface point cloud. Add Gaussian noise with scale $\sigma_1 = 0.0025$ to these points.
       2. Sample the other half of the required surface points ($47/100$ of total) from the surface point cloud. Add Gaussian noise with scale $\sigma_2 = 0.00025$ to these points.
   - **Uniform Background Samples (3/50 of total)**:
     - Sample the remaining $3/50$ of the total points uniformly within the unit sphere.
4. **Compute SDF Values**: For each query point, compute the signed distance to the mesh.
   - Use `get_sdf_in_batches` or equivalent logic with the specified `sign_method` [S1, unofficial].
   - If `sign_method` is 'normal', determine the sign using the dot product of the vector from the query point to the closest surface point and the surface normal at that point [S1, unofficial].
5. **Size Check (Optional)**: If `min_size > 0`:
   - Calculate the ratio of query points with negative SDF values (inside the mesh) among the uniform sphere samples.
   - If this ratio is less than `min_size`, raise a `BadMeshException` [S1, unofficial].

**Pseudocode:**
```python
def sample_sdf_near_surface(mesh, number_of_points=500000, surface_point_method='scan', sign_method='normal', scan_count=100, scan_resolution=400, sample_point_count=10000000, normal_sample_count=11, min_size=0, return_gradients=False):
    # Step 1: Scale mesh to unit sphere
    mesh = scale_to_unit_sphere(mesh)
    
    # Handle incompatible method combinations
    if surface_point_method == 'sample' and sign_method == 'depth':
        sign_method = 'normal'
        
    # Step 2: Generate surface point cloud
    calculate_normals = (sign_method == 'normal') or return_gradients
    surface_point_cloud = get_surface_point_cloud(
        mesh, surface_point_method, bounding_radius=1, 
        scan_count=scan_count, scan_resolution=scan_resolution, 
        sample_point_count=sample_point_count, 
        calculate_normals=calculate_normals
    )
    
    # Step 3 & 4: Sample and compute SDF
    # The actual sampling logic is encapsulated in the point cloud object
    # according to the DeepSDF strategy: 47/50 surface (with noise), 3/50 uniform
    query_points = surface_point_cloud.sample_sdf_near_surface(
        number_of_points=number_of_points,
        is_scan=(surface_point_method == 'scan'),
        sign_method=sign_method,
        normal_sample_count=normal_sample_count,
        min_size=min_size,
        return_gradients=return_gradients
    )
    
    return query_points
```

**Parameters:**
- `number_of_points`: Default 500,000 [S1, unofficial].
- `scan_count`: Default 100 [S1, unofficial].
- `scan_resolution`: Default 400 [S1, unofficial].
- `sample_point_count`: Default 10,000,000 [S1, unofficial].
- `normal_sample_count`: Default 11 [S1, unofficial].
- Noise scales: 0.0025 and 0.00025 [S1, unofficial].

**Edge Cases:**
- If `surface_point_method` is 'sample' and `sign_method` is 'depth', the method automatically falls back to `sign_method='normal'` [S1, unofficial].
- Precision issues may arise if the mesh is not properly scaled to the unit sphere before sampling.

## Subtopics

### [Normal-Based Sign Determination](16359-normal-based-sign-determination.md)
Determines the sign of the SDF using the normal of the closest surface point via a dot product.

## Operating characteristics
- **Time Complexity**: Dominated by the generation of the surface point cloud and the computation of distances for all query points. The number of surface points generated is proportional to `scan_count * scan_resolution^2` or `sample_point_count` depending on the method [S1, unofficial].
- **Memory Complexity**: Proportional to the number of surface points and query points.
- **Strengths**: Provides high-density samples near the surface, which is critical for learning fine geometric details in neural SDFs [S1, unofficial].
- **Limitations**: Requires a robust surface point cloud generation step. The fixed ratio (47/50 vs 3/50) may not be optimal for all mesh types or resolutions.

## Background
This sampling strategy is proposed in the DeepSDF paper [S1, unofficial]. It is implemented in the `mesh_to_sdf` library [S1, unofficial]. The method is designed to improve the quality of SDF representations for neural networks by ensuring sufficient coverage of the surface region.
