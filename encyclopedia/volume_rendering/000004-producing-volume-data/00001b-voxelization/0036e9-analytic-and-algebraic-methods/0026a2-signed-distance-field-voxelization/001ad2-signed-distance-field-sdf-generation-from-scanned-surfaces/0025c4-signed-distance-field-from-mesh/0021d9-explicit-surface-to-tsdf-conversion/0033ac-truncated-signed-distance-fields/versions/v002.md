# Truncated Signed Distance Fields

Also called: Truncated SDF

## Overview
Truncated Signed Distance Fields (TSDF) represent a 3D implicit surface as the zero crossing of a function interpolating truncated signed distances on a uniform grid [S1, S2]. Unlike full Signed Distance Fields (SDFs), TSDFs limit distance magnitudes to a specific interval to handle incomplete information and reduce memory usage for robotics and reconstruction applications [S2]. It differs from Projective TSDF Fusion by focusing on the static representation definition rather than the multi-view integration process, and from Mesh-to-TSDF Sequence Encoding by addressing the fundamental voxel value definition rather than temporal compression [G].

## How it works
**Inputs:** A closed surface $Q$ (mesh or point cloud), truncation limits $d_{min}$ and $d_{max}$, and a uniform 3D grid resolution $W \times H \times D$ [S1, S2].
**Outputs:** A 3D grid where each voxel stores a scalar TSDF value [S1, S2].

**Data Structures:**
The output is a uniform $W \times H \times D$ 3D grid [S1]. Each voxel stores a single floating-point value representing the truncated signed distance [S2]. The grid coordinates correspond to spatial positions in the world frame [G].

**Steps:**
1. For each voxel center $p$ in the $W \times H \times D$ grid, find the closest point $q$ on the surface $Q$ [S2].
2. Compute the Euclidean distance $\|p - q\|_2$ [S2].
3. Determine the sign using the surface normal $n(q)$ at $q$: $I_{\pm}(p) = \text{sign}(n(q)^T \cdot (p - q))$ [S2]. [G] If normals are unavailable, estimate $n(q)$ from local surface geometry or default to positive for outside points.
4. Compute the signed distance $d_{signed}(p) = I_{\pm}(p) \cdot \|p - q\|_2$ [S2].
5. Truncate the value to $[d_{min}, d_{max}]$ to produce $d(p)$ [S1, S2].

**Formulas:**
The TSDF value $d(p)$ for a point $p$ is defined as [S2]:
$$ d(p) = \min(d_{max}, \max(d_{min}, I_{\pm}(p) \min_{q \in Q} \|p - q\|_2)) $$
where:
- $d_{min}$ and $d_{max}$ are the lower and upper truncation limits [S2].
- $Q$ is the surface [S2].
- $I_{\pm}(p)$ assigns the sign based on the surface normal $n(q)$ at the closest point $q$ via $I_{\pm}(p) = \text{sign}(n(q)^T \cdot (p - q))$ [S2].
- $\| \cdot \|_2$ denotes the Euclidean distance [S2].

**Parameters:**
- Truncation limits: Typical values are $d_{min} = -0.04$ and $d_{max} = 0.1$ (in meters, assuming 2cm voxel size context) [S2].
- Sign convention: Distances outside the surface are positive; distances inside are negative [S1, S2].
- $\tau$: A general truncation threshold value that limits the magnitude of signed distances stored in the grid [S1].

**Edge Cases:**
- If $p$ is exactly on the surface, $d(p) = 0$ [G].
- If the closest point $q$ is ambiguous (e.g., equidistant to multiple surface parts), the sign may be unstable [G].
- Precision issues may arise when $p$ is very close to $q$; use epsilon guards for zero-crossing detection [G].

**Pseudocode:**
```python
def compute_tsdf(p, surface_points, surface_normals, d_min, d_max):
    """
    Compute TSDF value for a single point p.
    p: tuple/list of 3 floats (x, y, z)
    surface_points: list of tuples/lists of 3 floats representing Q
    surface_normals: list of tuples/lists of 3 floats representing n(q)
    d_min: float, lower truncation limit
    d_max: float, upper truncation limit
    Returns: float, truncated signed distance d(p)
    """
    def dot(v1, v2):
        return v1[0]*v2[0] + v1[1]*v2[1] + v1[2]*v2[2]

    def normalize(v):
        mag = (v[0]**2 + v[1]**2 + v[2]**2)**0.5
        if mag == 0:
            return (0.0, 0.0, 0.0)
        return (v[0]/mag, v[1]/mag, v[2]/mag)

    min_dist_sq = float('inf')
    closest_q = None
    normal_at_q = None

    for i, q in enumerate(surface_points):
        dist_sq = (p[0]-q[0])**2 + (p[1]-q[1])**2 + (p[2]-q[2])**2
        if dist_sq < min_dist_sq:
            min_dist_sq = dist_sq
            closest_q = q
            normal_at_q = surface_normals[i]

    min_dist = min_dist_sq**0.5

    if normal_at_q is None:
        vec = (p[0]-closest_q[0], p[1]-closest_q[1], p[2]-closest_q[2])
        normal_at_q = normalize(vec)

    vec = (p[0]-closest_q[0], p[1]-closest_q[1], p[2]-closest_q[2])
    dot_product = dot(normal_at_q, vec)

    if dot_product > 0:
        sign = 1.0
    elif dot_product < 0:
        sign = -1.0
    else:
        sign = 0.0

    signed_dist = sign * min_dist
    truncated = max(d_min, min(d_max, signed_dist))
    return truncated
```

## Operating characteristics
- **Time Complexity:** $O(N \cdot M)$ where $N$ is the number of voxels and $M$ is the number of surface points/vertices, unless accelerated with spatial indexing (e.g., KD-tree, BVH) [G].
- **Memory Complexity:** $O(W \times H \times D)$ for the grid [S1]. Truncation reduces the effective dynamic range but not the storage size per voxel [G].
- **Strengths:** Robust to noise and incomplete data; compatible with standard image processing filters [S2].
- **Limitations:** Memory intensive for high-resolution volumes [S2].
- **Use Cases:** Robotics scene reconstruction, pose estimation, collision detection [S2].

## Background
TSDFs were introduced to address difficulties in computing and updating distance fields based on incomplete information, proving useful in robotics research for accurate scene reconstruction and rigid-body pose estimation [S2]. They are applied to speeding up image-alignment, raycasting, collision detection, and motion planning [S2]. The concept is often used in conjunction with marching cubes for surface extraction [S1].
