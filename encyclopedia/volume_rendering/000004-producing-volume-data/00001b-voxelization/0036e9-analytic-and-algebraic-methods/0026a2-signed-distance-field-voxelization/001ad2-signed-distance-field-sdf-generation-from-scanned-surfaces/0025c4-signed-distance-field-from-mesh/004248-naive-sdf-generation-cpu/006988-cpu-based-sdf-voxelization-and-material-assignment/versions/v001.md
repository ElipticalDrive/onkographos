# CPU-based SDF Voxelization and Material Assignment

Also called: Asynchronous SDF Voxelization, Time-bounded SDF Sampling

## Overview
This method populates 3D textures with Signed Distance Field (SDF) data and material properties by sampling an SDF surface on the CPU, handling time constraints via a loop, and committing the data to the GPU [S1, unofficial]. It differs from synchronous approaches by allowing partial updates within a frame budget, and from GPU-based methods by performing the sampling logic on the host CPU [S1, unofficial]. It builds on [Naive SDF Generation (CPU)](10688-naive-sdf-generation-cpu.md) by adding material assignment and time-bounded iteration.

## How it works
**Inputs:**
- `sdf`: An SDF surface object providing a `sample(pos, false)` method returning a struct with `distance` (f32) and `color` (RGB).
- `loading_mgr`: A loading manager providing `next()` (returns optional voxel index) and `passes_left()` (returns u8).
- `tex0_data_ref`, `tex1_data_ref`: Mutable references to flat arrays representing two 3D textures.
- `tex0.width`, `tex0.height`: Dimensions of the SDF texture.
- `sdf_bb`: A bounding box defined by `sdf_bb[0]` (min corner) and `sdf_bb_size` (size vector).
- `changed_box`: Optional bounding box restricting updates to a specific region.
- `max_delta_time`: Maximum allowed processing time per frame.
- `AIR_DIST`: A constant representing the "air" or empty distance value.

**Outputs:**
- `tex0`: 3D Texture storing distance (Channel 0) and linear sRGB color (Channels 1-3).
- `tex1`: 3D Texture storing material properties: metallic (Channel 0), roughness (Channel 1), and occlusion (Channel 2).

**Data Structures:**
- `tex0_data_ref`: Array of size `width * height * depth`. Each element is a 4-component vector `[distance, r, g, b]`.
- `tex1_data_ref`: Array of size `width * height * depth`. Each element is a 3-component vector `[metallic, roughness, occlusion]`.
- Voxel indices are 3D coordinates `(x, y, z)`.

**Steps:**
1. Initialize a loop that continues if it is the first iteration or if the elapsed time is less than `max_delta_time`: `while first || start_time.elapsed() < max_delta_time`.
2. Retrieve the next voxel index from the loading manager: `if let Some(index) = self.loading_mgr.next()`.
3. Compute the flat index for the 3D texture assuming row-major order: `let flat_index = (index.z * self.tex0.height as usize + index.y) * self.tex0.width as usize + index.x;`.
4. Convert the voxel index to world space position: create Vector3 from index, normalize to [0, 1] by dividing by texture_size_minus_1, scale by sdf_bb_size, and add sdf_bb[0].
5. Determine if an update is required: check if the existing value in tex0_data_ref[flat_index][0] equals AIR_DIST, or if the position falls within changed_box (if present).
6. Sample the SDF at the computed position: `let mut sample = sdf.sample(pos, false);`.
7. Store the distance in tex0_data_ref[flat_index][0] by adding 1e-1, clamping the result to [0.0, 1.0]: `tex0_data_ref[flat_index][0] = (1e-1 + sample.distance).clamp(0.0, 1.0);`.
8. Handle default black color: if sample.color is (0,0,0), set it to (0.5, 0.5, 0.5) to avoid invisible objects in dark environments.
9. Convert sample.color to linear sRGB and store in tex0_data_ref channels 1, 2, and 3: `let color_raw = Srgba::from(sample.color).to_linear_srgb(); tex0_data_ref[flat_index][1] = color_raw.x; tex0_data_ref[flat_index][2] = color_raw.y; tex0_data_ref[flat_index][3] = color_raw.z;`.
10. Store material properties in tex1_data_ref: metallic to channel 0, roughness to channel 1, and occlusion to channel 2 (defaulting to 1.0 if sample.occlusion <= 0.0).
11. Break the loop if no more work is available: `else { break; }`.
12. Commit data to GPU by filling tex0 and tex1 textures with their respective data slices.
13. Set lod_dist_between_samples to 2 raised to the power of passes_left: `vol_mut.material.lod_dist_between_samples = 2f32.pow(self.loading_mgr.passes_left() as u8);`.

**Pseudocode:**
```python
def cpu_sdf_voxelization(sdf, loading_mgr, tex0_data_ref, tex1_data_ref, 
                         width, height, depth, sdf_bb, sdf_bb_size, 
                         changed_box, max_delta_time, air_dist):
    """
    Voxelize SDF and materials on CPU with time bounds.
    """
    import time
    import math
    
    # Helper to convert voxel index to world position
    def voxel_to_world(index_x, index_y, index_z):
        # Normalize to [0, 1]
        # Note: texture_size_minus_1 is typically (width-1, height-1, depth-1)
        # If dimensions are 1, avoid division by zero
        tx = width - 1 if width > 1 else 1
        ty = height - 1 if height > 1 else 1
        tz = depth - 1 if depth > 1 else 1
        
        nx = index_x / tx
        ny = index_y / ty
        nz = index_z / tz
        
        # Scale and translate
        wx = sdf_bb[0].x + nx * sdf_bb_size.x
        wy = sdf_bb[0].y + ny * sdf_bb_size.y
        wz = sdf_bb[0].z + nz * sdf_bb_size.z
        return (wx, wy, wz)

    # Helper to compute flat index (row-major: z, y, x)
    def get_flat_index(x, y, z):
        return (z * height + y) * width + x

    # Helper to convert sRGB to linear
    def srgb_to_linear(c):
        # Standard sRGB linearization
        if c <= 0.04045:
            return c / 12.92
        else:
            return math.pow((c + 0.055) / 1.055, 2.4)

    start_time = time.time()
    first_iteration = True
    
    while first_iteration or (time.time() - start_time) < max_delta_time:
        first_iteration = False
        
        # Get next voxel index from manager
        index = loading_mgr.next()
        if index is None:
            break
            
        x, y, z = index
        
        flat_idx = get_flat_index(x, y, z)
        pos = voxel_to_world(x, y, z)
        
        # Check if update is needed
        current_dist = tex0_data_ref[flat_idx][0]
        needs_update = False
        
        if current_dist == air_dist:
            needs_update = True
        elif changed_box is not None:
            # Check if pos is within changed_box
            if (changed_box.min.x <= pos.x <= changed_box.max.x and
                changed_box.min.y <= pos.y <= changed_box.max.y and
                changed_box.min.z <= pos.z <= changed_box.max.z):
                needs_update = True
        
        if not needs_update:
            continue
            
        # Sample SDF
        sample = sdf.sample(pos, False)
        
        # Store distance
        # Add 1e-1 offset, clamp to [0.0, 1.0]
        dist_val = sample.distance + 1e-1
        dist_val = max(0.0, min(1.0, dist_val))
        tex0_data_ref[flat_idx][0] = dist_val
        
        # Handle color
        r, g, b = sample.color
        if r == 0 and g == 0 and b == 0:
            r, g, b = 0.5, 0.5, 0.5
            
        # Convert to linear sRGB
        r_lin = srgb_to_linear(r)
        g_lin = srgb_to_linear(g)
        b_lin = srgb_to_linear(b)
        
        tex0_data_ref[flat_idx][1] = r_lin
        tex0_data_ref[flat_idx][2] = g_lin
        tex0_data_ref[flat_idx][3] = b_lin
        
        # Store material properties
        metallic = sample.metallic
        roughness = sample.roughness
        occlusion = sample.occlusion
        
        # Default occlusion to 1.0 if <= 0.0
        if occlusion <= 0.0:
            occlusion = 1.0
            
        tex1_data_ref[flat_idx][0] = metallic
        tex1_data_ref[flat_idx][1] = roughness
        tex1_data_ref[flat_idx][2] = occlusion
        
    # Commit to GPU (implementation detail, assumed handled by caller or framework)
    # Commit data to GPU by filling tex0 and tex1 textures with their respective data slices.
    
    # Set LOD distance
    passes_left = loading_mgr.passes_left()
    lod_dist = math.pow(2, passes_left)
    return lod_dist
```

**Parameters:**
- `lod_dist_between_samples`: Determines how many voxels are skipped in each dimension between reads. Default value is 1f32 [S1, unofficial].

**Edge Cases and Pitfalls:**
- Default black color (0,0,0) makes objects invisible in dark environments; handled by forcing color to (0.5, 0.5, 0.5) [S1, unofficial].
- Occlusion values <= 0.0 are clamped to 1.0 to use ambient light by default [S1, unofficial].
- Division by zero in normalization if texture dimensions are 1.
- Precision issues with `AIR_DIST` comparison; ensure exact match or use epsilon if floating point.

## Operating characteristics
- **Time Complexity:** O(N) where N is the number of voxels processed per frame. Bounded by `max_delta_time`.
- **Memory Complexity:** O(W * H * D) for two 3D textures (tex0 and tex1).
- **Measured Performance:** Not given in the sources.
- **Scaling:** Scales with CPU core count if parallelized, but the described method is single-threaded per frame.
- **Strengths:** Time-bounded execution prevents frame drops; allows incremental updates.
- **Limitations:** CPU-bound; slower than GPU for large volumes; requires careful time management.
- **When to use:** When incremental updates are needed, or when GPU is busy with rendering.
- **When not to use:** For large volumes requiring full recomputation every frame.
