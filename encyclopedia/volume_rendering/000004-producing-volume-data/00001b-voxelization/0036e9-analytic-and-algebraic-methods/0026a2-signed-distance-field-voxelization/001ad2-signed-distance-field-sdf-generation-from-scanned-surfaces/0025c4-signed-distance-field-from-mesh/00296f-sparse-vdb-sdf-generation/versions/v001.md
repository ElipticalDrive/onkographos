# Sparse VDB SDF Generation

Also called: OpenVDB SDF, meshToDistanceVdbVolume

## Overview
A method that converts a triangle mesh into a sparse, tree-structured signed or unsigned distance grid using OpenVDB, storing only active voxels near the surface for memory efficiency [S1]. It differs from dense voxelization by dynamically allocating memory only for the narrow band around the mesh, making it suitable for large or complex models where ray-marched rendering or fast implicit queries are required [S1].

## How it works
**Inputs and Outputs:**
- Input: A triangle mesh (e.g., STL format) [S1].
- Output: A `VdbVolume` object containing the sparse distance field [S1]. Optionally, a reconstructed mesh can be extracted from the volume [S1].

**Data Structures:**
- `MeshToVolumeParams`: Configuration structure containing:
  - `surfaceOffset`: Integer specifying the number of voxel layers around the surface to mark as active [S1].
  - `type`: Enum (`Signed` or `Unsigned`) determining distance sign logic [S1].
  - `voxelSize`: `Vector3f` defining the physical size of each voxel [S1].
  - `outXf`: `AffineXf3f` transformation matrix applied to shift output voxels relative to the original mesh [S1].
- `GridToMeshSettings`: Configuration for reconstruction containing:
  - `voxelSize`: `Vector3f` matching the generation voxel size [S1].
  - `isoValue`: Float representing the isosurface threshold in voxel units [S1].

**Steps:**
1. Load the input mesh from file [S1].
2. Initialize `MeshToVolumeParams` [S1].
3. Set `surfaceOffset` to 3 [S1].
4. Determine `type`: If `mesh.topology.isClosed()` is true, set to `Signed`; otherwise, set to `Unsigned` [S1].
5. Calculate `voxelSize`: Use `suggestVoxelSize(mesh, 1e7)` to determine a dimension that targets approximately 10 million voxels, then create a diagonal vector from this result [S1].
6. Initialize `voxelsShift` as an identity `AffineXf3f` and assign it to `params.outXf` [S1].
7. Call `meshToDistanceVdbVolume(mesh, params)` to generate the `VdbVolume` [S1].
8. (Optional Reconstruction) Initialize `GridToMeshSettings` with `voxelSize` and `isoValue` of 0.5 [S1].
9. Call `gridToMesh(vdbVolume.data, gSettings)` to extract a mesh from the volume [S1].
10. Apply the inverse shift to the output mesh using `offMesh.transform(voxelsShift)` to restore the original mesh position [S1].

**Pseudocode:**
```python
from meshlib import mrmeshpy as mm

# 1. Load mesh
mesh = mm.loadMesh("mesh.stl")

# 2. Initialize parameters
params = mm.MeshToVolumeParams()

# 3. Set surface offset (3 voxel layers)
params.surfaceOffset = 3

# 4. Determine distance type based on topology
if mesh.topology.isClosed():
    params.type = mm.MeshToVolumeParams.Type.Signed
else:
    params.type = mm.MeshToVolumeParams.Type.Unsigned

# 5. Calculate voxel size targeting ~10 million voxels
# suggestVoxelSize returns a scalar; diagonal creates a Vector3f
params.voxelSize = mm.Vector3f.diagonal(mm.suggestVoxelSize(mesh, 1e7))

# 6. Initialize shift transformation
voxelsShift = mm.AffineXf3f()
params.outXf = voxelsShift

# 7. Generate sparse VDB volume
vdbVolume = mm.meshToDistanceVdbVolume(mesh, params)

# --- Optional: Reconstruct Mesh from VDB ---

# 8. Initialize grid-to-mesh settings
gSettings = mm.GridToMeshSettings()
gSettings.voxelSize = params.voxelSize
gSettings.isoValue = 0.5  # Isosurface value in voxel units

# 9. Extract mesh from volume data
offMesh = mm.gridToMesh(vdbVolume.data, gSettings)

# 10. Transform output mesh back to original position
offMesh.transform(voxelsShift)

# 11. Save result
mm.saveMesh(offMesh, "out_mesh.stl")
```

**Parameters:**
- `surfaceOffset`: Integer. Typical value: 3 [S1].
- `type`: Enum. `Signed` for closed meshes, `Unsigned` for open meshes [S1].
- `voxelSize`: `Vector3f`. Calculated to target approximately 10 million voxels for the input mesh [S1].
- `outXf`: `AffineXf3f`. Transformation matrix for shifting voxels relative to the original mesh [S1].

**Edge Cases and Pitfalls:**
- The mesh must be closed for `Signed` distance calculation; otherwise, `Unsigned` must be used [S1].
- The `isoValue` for reconstruction is specified in voxel units (0.5), not world units [S1].
- Precision issues may arise if the voxel size is too small relative to mesh features, though `suggestVoxelSize` helps mitigate this by targeting a specific voxel count [S1].

## Operating characteristics
- **Memory Efficiency:** High. Stores only active voxels near the surface, making it suitable for large or complex models [S1].
- **Performance:** Fast queries due to sparse tree structure. Generation time depends on mesh complexity and target voxel count [S1].
- **Use Cases:** Ray-marched rendering, workflows requiring fast implicit queries without storing every voxel [S1].
- **Limitations:** Not suitable for dense volume rendering where every voxel is needed. Requires closed mesh for signed distances [S1].

## Background
Originated in the MeshLib library, which provides Python and C++ bindings for mesh processing and voxelization [S1]. Developed to address the need for scalable, production-grade SDF generation for large models [S1].
