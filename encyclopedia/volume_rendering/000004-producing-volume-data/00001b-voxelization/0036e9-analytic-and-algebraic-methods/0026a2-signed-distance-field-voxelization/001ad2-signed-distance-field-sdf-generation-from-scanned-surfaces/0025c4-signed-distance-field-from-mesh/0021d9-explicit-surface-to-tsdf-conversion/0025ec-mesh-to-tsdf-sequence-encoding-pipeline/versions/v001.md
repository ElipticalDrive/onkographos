# Mesh-to-TSDF Sequence Encoding Pipeline

Also called: codec_mesh workflow

## Overview
This method automates the conversion of a sequence of triangle meshes into a compressed TSDF (Truncated Signed Distance Field) voxel grid, encoding the result into a codec stream for efficient storage or transmission. It solves the problem of managing large volumetric datasets derived from animated geometry by providing a complete pipeline from raw mesh files to decoded surface verification. It differs from single-frame conversion by handling temporal sequences, applying a unified similarity transform to all frames, and performing codec-specific compression rather than just voxelization.

## How it works
**Inputs and Outputs:**
- **Input:** A sequence of triangle mesh files (e.g., PLY) matching a printf-style path pattern.
- **Output:** A codec stream containing the TSDF data, plus optional output meshes for verification (input, uncompressed TSDF surface, decoded surface).

**Data Structures:**
- `Pattern`: A struct defining the file path template.
  - `head`: String prefix before the number.
  - `tail`: String suffix after the number.
  - `width`: Integer width for zero-padding (e.g., 3 for `%03d`). Set to -1 if no number placeholder exists.
- `MeshSequence`: Represents the open sequence of meshes, including metadata like frame count and global transform.
- `EncoderConfig`: Configuration for the TSDF codec, including `true_sdf` flag (set to true for this pipeline) and band constraints.
- `MeshSdfParams`: Parameters for SDF generation, including voxel size, truncation distance, and topology handling flags.

**Parameters:**
- `source.path`: Printf-style pattern for frame files (e.g., `%03d.ply`). Must contain at most one number placeholder.
- `source.height_m`: Target height in meters used to compute the similarity transform fitting the union of all mesh bounds.
- `source.metres_per_unit`: Alternative scale factor for the similarity transform if `height_m` is not used.
- `source.allow_holes`: Boolean flag. If true, allows signed mode to process meshes with topology defects (holes). If false, signed mode rejects such meshes.
- `codec.inspect_only`: Boolean flag. If true, skips GPU encoding/decoding and runs a host-only audit of frames.
- `fusion.voxel_size_m`: Resolution of the voxel grid.
- `trunc`: Truncation distance for the TSDF.

**Steps:**
1. **Parse Path Pattern:**
   - Parse `source.path` to extract `head`, `tail`, and `width`.
   - Validate that the pattern contains exactly one number placeholder in the format `%d` or `%0Nd` (where N is 1-9).
   - Reject patterns like `%5d` because printf pads with spaces while other tools (e.g., ffmpeg) pad with zeros, causing path mismatches.
   - Handle escaped `%%` by converting to a single `%`.

2. **Open Mesh Sequence:**
   - Load the sequence of meshes defined by the parsed pattern.
   - Compute the union of bounding boxes of all meshes.
   - Fit a single similarity transform to this union. Use `source.height_m` to scale the transform, or `source.metres_per_unit` as an alternative.
   - Store the transform for application to all frames.

3. **Configure Encoder and SDF Params:**
   - Create `EncoderConfig` and `MeshSdfParams`.
   - Set `config.true_sdf = true` because the mesh field represents a true distance, coding without an observed mask in a band that observes every voxel it codes.
   - Validate the true SDF band constraints against the grid resolution and truncation.

4. **Initialize GPU (if not inspect-only):**
   - Create Vulkan instance, select physical device, create device, and allocator.
   - Prepare volume data structures for TSDF storage.

5. **Process Frames (Core Loop):**
   - For each frame in the sequence:
     a. Load the mesh file using the pattern and current frame index.
     b. Apply the pre-computed similarity transform to the mesh vertices.
     c. **Topology Check:**
        - If `source.allow_holes` is false and the mesh has topology defects (holes), reject the frame in signed mode.
        - In shell mode, accept any topology.
     d. **Voxelization:** Convert the transformed mesh to a TSDF voxel grid.
        - Compute signed distances using closest-face sign (signed mode) or treat as closed surface (shell mode).
        - Truncate distances at `trunc`.
     e. **Encoding:** Encode the TSDF grid into the codec stream.
     f. Track statistics (e.g., triangle counts, conversion errors).

6. **Decode and Verify (if not inspect-only):**
   - Decode the codec stream back to a TSDF grid.
   - Extract surfaces from the original input mesh, the uncompressed TSDF, and the decoded TSDF.
   - Write output meshes (`_input.ply`, `_source.ply`, `_decoded.ply`) if `opt.output.prefix` is set.
   - Compare surfaces using `eval::CompareOptions` based on `voxel_size_m` and `trunc`.
   - Calculate and report:
     - Conversion error: Uncompressed TSDF surface vs. normalized input.
     - Codec error: Decoded surface vs. uncompressed TSDF surface.
     - Total error: Decoded surface vs. normalized input.

7. **Inspect Mode (if `codec.inspect_only` is true):**
   - Skip GPU work.
   - Run a host-only second pass to audit frames.
   - Print details of the last frame.
   - Write input mesh if output prefix is set.

**Pseudocode:**
```python
def run_mesh_to_tsdf_pipeline(opt):
    # 1. Parse Path Pattern
    pattern = parse_pattern(opt.source.path)
    if pattern.width == -1:
        raise ValueError("No number placeholder in path")
    if pattern.width > 0 and pattern.width != 1:
        # Reject %5d style because printf pads with spaces, not zeros
        raise ValueError("Only %0Nd with N=1 is supported due to padding mismatch")

    # 2. Open Mesh Sequence
    sequence = MeshSequence.open(opt.source.path, pattern)
    transform = fit_similarity_transform(sequence.bounding_boxes, opt.source.height_m)

    # 3. Configure Encoder and SDF Params
    config = EncoderConfig()
    config.true_sdf = True
    sdf_params = MeshSdfParams(
        voxel_size=opt.fusion.voxel_size_m,
        trunc=opt.trunc,
        allow_holes=opt.source.allow_holes,
        transform=transform
    )
    check_true_sdf_band(sdf_params, sequence.grid_resolution)

    # 4. Initialize GPU (if not inspect-only)
    if not opt.codec.inspect_only:
        instance = vkc.Instance.create({})
        gpu = instance.select_physical_device(device_requirements())
        device = vkc.Device.create(instance, gpu, device_requirements())
        allocator = vkc.Allocator.create(instance.handle(), device)
    else:
        device = None
        allocator = None

    # 5. Process Frames
    for frame_idx in range(sequence.count()):
        mesh = sequence.load_frame(frame_idx)
        mesh.apply_transform(transform)

        # Topology check
        if not opt.source.allow_holes and has_topology_defects(mesh):
            if mode == SIGNED_MODE:
                raise TopologyError(f"Frame {frame_idx} has holes")
            # Shell mode accepts any topology

        # Voxelization
        tsdf_grid = voxelize_mesh(mesh, sdf_params)

        # Encoding
        if device is not None:
            encode_to_codec_stream(tsdf_grid, config, device, allocator)

    # 6. Decode and Verify
    if not opt.codec.inspect_only:
        decoded_tsdf = decode_codec_stream()
        input_mesh = sequence.load_last_frame()
        input_mesh.apply_transform(transform)
        
        source_mesh = extract_surface(tsdf_grid)
        decoded_mesh = extract_surface(decoded_tsdf)

        if opt.output.prefix:
            write_ply(f"{opt.output.prefix}_input.ply", input_mesh)
            write_ply(f"{opt.output.prefix}_source.ply", source_mesh)
            write_ply(f"{opt.output.prefix}_decoded.ply", decoded_mesh)

        compare_options = CompareOptions(voxel_size=opt.fusion.voxel_size_m, trunc=opt.trunc)
        input_ref = ReferenceMesh.create(input_mesh, compare_options)
        source_ref = ReferenceMesh.create(source_mesh, compare_options)
        decoded_ref = ReferenceMesh.create(decoded_mesh, compare_options)

        conversion_error = input_ref.compare(source_ref)
        codec_error = source_ref.compare(decoded_ref)
        total_error = input_ref.compare(decoded_ref)

        print_comparison(conversion_error)
        print_comparison(codec_error)
        print_comparison(total_error)

    # 7. Inspect Mode
    if opt.codec.inspect_only:
        inspected = inspect_frames(sequence)
        print_frame(inspected.last)
        if opt.output.prefix:
            write_ply(f"{opt.output.prefix}_input.ply", inspected.last.mesh)

    return {}
```

**Edge Cases and Pitfalls:**
- **Path Pattern Mismatch:** Using `%5d` causes issues because printf pads with spaces while other tools pad with zeros. Only `%0Nd` with N=1 is supported.
- **Topology Defects:** Signed mode requires valid topology (no holes) unless `source.allow_holes` is true. Shell mode accepts any topology.
- **True SDF Band:** The pipeline uses `true_sdf = true`, meaning it codes without an observed mask. Ensure the grid resolution and truncation are compatible with this constraint.

## Operating characteristics
- **Time Complexity:** Linear with respect to the number of frames and the number of voxels per frame. Voxelization is $O(N \cdot V)$ where $N$ is the number of triangles and $V$ is the number of voxels. Encoding/decoding depends on the codec algorithm.
- **Memory Complexity:** $O(V)$ per frame for the TSDF grid. Codec memory depends on compression ratio.
- **Performance:** Measured performance depends on GPU hardware, resolution, and scene complexity. The pipeline is designed for efficient processing of sequences.
- **Strengths:** Automated handling of sequences, unified transform, codec compression, verification pipeline.
- **Limitations:** Requires valid topology for signed mode (unless `allow_holes` is set). Path pattern restrictions.
- **When to Use:** When processing animated geometry sequences into compressed TSDF volumes.
- **When Not to Use:** For single-frame conversion (use [Explicit Surface to TSDF Conversion](2615-explicit-surface-to-tsdf-conversion.md) directly). For point clouds (use point cloud voxelization methods).

## Background
This pipeline is part of the volumetric kit grid project, providing a complete workflow for mesh sequence to TSDF conversion. It integrates mesh I/O, SDF generation, and codec compression into a single tool.
