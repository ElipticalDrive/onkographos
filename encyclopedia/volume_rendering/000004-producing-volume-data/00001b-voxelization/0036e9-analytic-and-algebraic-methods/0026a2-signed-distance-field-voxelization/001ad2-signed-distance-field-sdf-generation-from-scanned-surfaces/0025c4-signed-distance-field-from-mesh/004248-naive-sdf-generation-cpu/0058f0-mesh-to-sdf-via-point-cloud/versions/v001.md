# Mesh to SDF via Point Cloud

Also called: Mesh to Signed Distance Field (SDF) via Point Cloud, SurfacePointCloud SDF computation

## Overview
This method generates a Signed Distance Field (SDF) for a query set of points by first converting a triangular mesh into a discrete point cloud and then computing distances to that cloud. It solves the problem of creating volumetric distance data from polygonal surfaces without requiring complex analytic integration or GPU-based ray marching. It differs from analytic voxelization by relying on nearest-neighbor search in a point cloud, and from GPU-based generation by performing the heavy lifting on the CPU using KD-trees and batched processing.

## How it works
The method proceeds in three phases: surface point cloud generation, SDF computation via nearest-neighbor search, and sign determination.

### Inputs and Outputs
- **Input**: A triangular mesh (typically `trimesh` object), a set of query points (numpy array of shape $(N, 3)$), and configuration parameters.
- **Output**: An array of signed distances of shape $(N)$, and optionally gradients.

### Data Structures
The core data structure is `SurfacePointCloud` [S1, unofficial]:
- `mesh`: The original triangular mesh.
- `points`: A float array of shape $(M, 3)$ containing the sampled surface points.
- `normals`: A float array of shape $(M, 3)$ containing surface normals (optional, required if `sign_method='normal'`).
- `kd_tree`: A `sklearn.neighbors.KDTree` built on `points`.
- `scans`: A list of `Scan` objects (used for depth-based sign determination).

### Parameters
- `surface_point_method`: `'scan'` or `'sample'`. Default: `'scan'` [S1, unofficial].
- `sign_method`: `'normal'` or `'depth'`. Default: `'normal'` [S1, unofficial].
- `scan_count`: Number of camera scans for `'scan'` method. Default: 100 [S1, unofficial].
- `scan_resolution`: Resolution of each scan. Default: 400 [S1, unofficial].
- `sample_point_count`: Number of points to sample for `'sample'` method. Default: 10,000,000 [S1, unofficial].
- `normal_sample_count` ($k$): Number of nearest neighbors for KD-tree query in normal sign method. Default: 11 [S1, unofficial].
- `batch_size`: Max query points per batch. Default: 1,000,000 [S1, unofficial].

### Algorithm Steps

1. **Input Validation**: Ensure `query_points` is a numpy array of shape $(N, 3)$. If `surface_point_method` is `'sample'` and `sign_method` is `'depth'`, override `sign_method` to `'normal'` due to incompatibility [S1, unofficial].

2. **Generate Surface Point Cloud**:
   - If `surface_point_method` is `'scan'`: Render the mesh from multiple viewpoints using `pyrender` to generate depth and normal buffers. Extract surface points from these scans. This requires disabling antialiasing to avoid blurred edges in normal buffers [S1, unofficial].
   - If `surface_point_method` is `'sample'`: Uniformly sample `sample_point_count` points from the mesh surface. Calculate normals if `sign_method` is `'normal'` [S1, unofficial].
   - Build a KD-tree on the resulting points [S1, unofficial].

3. **Compute SDF in Batches**:
   - Split `query_points` into batches of size `batch_size`.
   - For each batch, compute distances and signs based on `sign_method`.

4. **Sign Determination (Normal Method)**:
   - Query the KD-tree for $k = \text{normal\_sample\_count}$ nearest neighbors. Let the closest point be $p_{closest}$ and its normal be $n_{closest}$.
   - Compute direction vector: $d = q - p_{closest}$, where $q$ is the query point [S1, unofficial].
   - Determine if inside: Calculate the sum of dot products between $d$ and the normals of the $k$ neighbors. If $\sum_{i=1}^{k} (d \cdot n_i) < k \times 0.5$, the point is considered inside [S1, unofficial].
   - If inside, negate the distance.

5. **Sign Determination (Depth Method)**:
   - Query the KD-tree for 1 nearest neighbor.
   - Use ray casting via the stored scans (`is_outside()` method) to determine if the point is outside the mesh. Points not outside are considered inside [S1, unofficial].
   - Negate distance for inside points.

6. **Gradient Calculation (Normal Method)**:
   - Compute raw gradient as the direction vector $d$ normalized.
   - If inside, negate the gradient.
   - **Near-Surface Correction**: For points where $|dist| < \sqrt{0.0025^2 \times 3} \times 3$, replace the gradient with the pre-computed surface normal $n_{closest}$ to avoid noise [S1, unofficial].
   - Normalize the final gradient.

### Pseudocode

```python
import numpy as np
from sklearn.neighbors import KDTree

def mesh_to_sdf_via_point_cloud(mesh, query_points, 
                                surface_point_method='scan', 
                                sign_method='normal',
                                scan_count=100, 
                                scan_resolution=400, 
                                sample_point_count=10000000, 
                                normal_sample_count=11, 
                                batch_size=1000000):
    # 1. Input Validation
    if not isinstance(query_points, np.ndarray):
        raise TypeError('query_points must be a numpy array.')
    if len(query_points.shape) != 2 or query_points.shape[1] != 3:
        raise ValueError('query_points must be of shape N x 3.')
    
    # Incompatible method override
    if surface_point_method == 'sample' and sign_method == 'depth':
        sign_method = 'normal'

    # 2. Generate Point Cloud
    # This step involves rendering (for 'scan') or sampling (for 'sample')
    # and building a KDTree. Implementation details depend on the specific library.
    point_cloud = get_surface_point_cloud(
        mesh, surface_point_method, scan_count, scan_resolution, 
        sample_point_count, calculate_normals=(sign_method == 'normal')
    )
    
    kd_tree = point_cloud.kd_tree
    points = point_cloud.points
    normals = point_cloud.normals
    
    # 3. Process in Batches
    all_distances = []
    all_gradients = []
    
    num_batches = (len(query_points) + batch_size - 1) // batch_size
    
    for i in range(num_batches):
        start_idx = i * batch_size
        end_idx = min((i + 1) * batch_size, len(query_points))
        batch_queries = query_points[start_idx:end_idx]
        
        distances, gradients = compute_sdf_batch(
            batch_queries, kd_tree, points, normals, 
            sign_method, normal_sample_count
        )
        
        all_distances.append(distances)
        all_gradients.append(gradients)
        
    return np.concatenate(all_distances), np.concatenate(all_gradients)

def compute_sdf_batch(queries, kd_tree, points, normals, sign_method, k):
    distances = np.zeros(len(queries))
    gradients = np.zeros((len(queries), 3))
    
    # Query KDTree for k nearest neighbors
    # distances_k: shape (N, k)
    # indices_k: shape (N, k)
    distances_k, indices_k = kd_tree.query(queries, k=k)
    
    # Get normals for the k neighbors
    # normals_k: shape (N, k, 3)
    normals_k = normals[indices_k]
    
    # Closest point and normal
    closest_points = points[indices_k[:, 0]]
    closest_normals = normals[indices_k[:, 0]]
    
    if sign_method == 'normal':
        # Direction from closest surface point to query point
        direction = queries[:, np.newaxis, :] - closest_points[:, np.newaxis, :]
        
        # Sum of dot products for inside check
        # direction * normals_k: shape (N, k, 3)
        dot_products = np.sum(direction * normals_k, axis=2)
        inside = np.sum(dot_products, axis=1) < (k * 0.5)
        
        # Distances are the distance to the closest point
        distances = distances_k[:, 0]
        
        # Negate distance for inside points
        distances[inside] = -distances[inside]
        
        # Gradient calculation
        raw_gradients = direction[:, 0] # Direction to closest point
        raw_gradients[inside] = -raw_gradients[inside]
        
        # Normalize
        norms = np.linalg.norm(raw_gradients, axis=1, keepdims=True)
        # Avoid division by zero
        norms[norms == 0] = 1.0
        gradients = raw_gradients / norms
        
        # Near-surface gradient correction
        # Threshold: sqrt(0.0025^2 * 3) * 3
        threshold = np.sqrt(0.0025**2 * 3) * 3
        near_surface = np.abs(distances) < threshold
        gradients[near_surface] = closest_normals[near_surface]
        
    elif sign_method == 'depth':
        # Depth method uses ray casting via scans
        # This requires access to the 'scans' object in point_cloud
        # For simplicity, we assume a helper function exists
        is_outside = check_outside_via_scans(queries, point_cloud.scans)
        
        distances = distances_k[:, 0]
        inside = ~is_outside
        distances[inside] = -distances[inside]
        
        # Gradients for depth method are not detailed in the primary notes
        # [G] Typically computed via finite differences or normal approximation
        gradients = np.zeros_like(queries)
        
    return distances, gradients
```

## Operating characteristics
- **Time Complexity**: Dominated by KD-tree construction $O(M \log M)$ and $N$ queries $O(N \log M)$, where $M$ is the number of surface points and $N$ is the number of query points.
- **Memory Complexity**: $O(M + N)$ to store the point cloud and query results.
- **Performance**: CPU-bound. Batching allows processing large query sets without excessive memory allocation. The `scan` method is slower to generate the point cloud but provides robust normals. The `sample` method is faster for cloud generation but may have less uniform distribution.
- **Strengths**: Simple implementation, no GPU required, robust sign determination via normals.
- **Limitations**: Resolution is limited by the density of the point cloud. Very thin features may be missed if not sampled. The `depth` method requires storing scan data, increasing memory usage.

## Background
This method is part of the `mesh_to_sdf` library, an unofficial Python package for converting meshes to SDFs [S1, unofficial]. It leverages `pyrender` for rendering and `scikit-learn` for KD-tree operations. It is designed as a CPU-based alternative to GPU-based SDF generation methods, suitable for preprocessing or environments without GPU support.
