# Signed Distance Field from Mesh

Also called: Signed Mesh SDF, Triangle Mesh SDF, Mesh SDF Rendering

## Overview
This method converts a triangulated surface mesh into a 3D Signed Distance Field (SDF) texture or an implicit function, where the scalar value at any point represents the signed Euclidean distance to the nearest surface triangle [S1, S2, unofficial][S4]. The sign is negative inside the mesh and positive outside, determined by the closest triangle's face normal or a topological side-of-mesh test [S3, unofficial][S4]. It differs from [Slice-based SDF Voxelization](1736-slice-based-sdf-voxelization.md) by evaluating the distance field directly from the explicit mesh geometry via per-voxel raycasting or spatial acceleration structures, allowing for exact analytical distances without rasterization artifacts [S2, unofficial][S4].

## How it works
**Inputs and Outputs:**
*   **Input:** A triangulated mesh (e.g., STL format) with consistent winding [S1, S3, unofficial].
*   **Output:** An implicit function $f(\mathbf{p})$ returning the signed distance, or a 3D texture where each voxel stores the distance value [S1, S2, unofficial].

**Data Structures:**
1.  **Mesh Storage:** Vertices and triangle indices [S1, unofficial][S4]. In GPU implementations, vertices may be stored in a texture (`meshtex`) with 3 floats (RGB) per texel and a stride of 16384 texels per row [S2, unofficial].
2.  **Spatial Acceleration:** An Axis-Aligned Bounding Box (AABB) tree built from the mesh faces to accelerate closest-point queries [S4].
3.  **Side-of-Mesh Functor:** A structure (e.g., `Side_of_triangle_mesh`) that determines if a query point is on the bounded (inside) or unbounded (outside) side of the mesh [S4].

**Algorithm Steps:**
The method follows two primary implementation patterns depending on the target hardware and output format.

### Approach A: GPU Raycasting (Per-Voxel Texture)
1.  **Initialize Grid:** For each voxel in the output grid (resolution `res` x `res` x `res`), calculate the voxel center $\mathbf{pos}$ in world space, typically mapped to $[-1, 1]^3$ via $\mathbf{pos} = (\mathbf{uv} / \text{res}) \times 2.0 - 1.0$ [S2, unofficial].
2.  **Distance Search:** Initialize `dist` to a large value (e.g., 10000.0) [S2, unofficial].
3.  **Triangle Iteration:** Loop through all triangles in the mesh [S2, unofficial]. For each triangle with vertices $\mathbf{a}, \mathbf{b}, \mathbf{c}$:
    *   Compute the Euclidean distance $d$ from $\mathbf{pos}$ to the triangle using a closest-point function `udTriangle` [S2, unofficial].
    *   Update `dist = min(dist, d)` [S2, unofficial].
4.  **Sign Determination:** In some implementations, the sign is ignored or handled by taking the absolute value `abs(dist)` if the winding/sign logic is not fully integrated into the distance kernel [S2, unofficial]. In robust implementations, the sign is determined by the closest triangle's normal [S3, unofficial].
5.  **Output:** Store the final distance in the output texture (e.g., `fragColor.r`) [S2, unofficial].

### Approach B: Spatial Query (CPU/Implicit Function)
1.  **Build Tree:** Construct an `AABB_tree` from the mesh faces [S4].
2.  **Initialize Oracle:** Create an `Offset_oracle` struct containing the `is_closed` flag, the `AABB_tree`, and the `Side_of_triangle_mesh` functor [S4].
3.  **Query Point:** For a query point $\mathbf{p}$:
    *   Find the closest point $\mathbf{cp}$ on the mesh surface using `tree.closest_point(p)` [S4].
    *   Compute the unsigned distance $d = \sqrt{(\mathbf{p} - \mathbf{cp})^2}$ [S4].
    *   Determine the sign: If `is_closed` is true and `sotm(p)` returns `ON_BOUNDED_SIDE`, negate the distance: $d = -d$ [S4].
4.  **Return:** Return $d$ [S4].

**Formulas:**

*   **Triangle Distance (`udTriangle`):**
    Let $\mathbf{pa} = \mathbf{p} - \mathbf{a}$ and $\mathbf{ba} = \mathbf{b} - \mathbf{a}$ [S2, unofficial].
    The projection of $\mathbf{pa}$ onto $\mathbf{ba}$ is clamped:
    $$ \mathbf{proj} = \mathbf{ba} \cdot \text{clamp}\left(\frac{\mathbf{ba} \cdot \mathbf{pa}}{\mathbf{ba} \cdot \mathbf{ba}}, 0, 1\right) - \mathbf{pa} $$
    The distance is the minimum of the distance to the triangle plane (if outside) or the edge/vertex distances [S2, unofficial].
    If outside: $d = \sqrt{\min(\dots)}$ [S2, unofficial].
    If inside: $d = \frac{(\mathbf{n} \cdot \mathbf{pa})^2}{\mathbf{n} \cdot \mathbf{n}}$ where $\mathbf{n}$ is the triangle normal [S2, unofficial].
    Inside check for winding: $\sum \text{sign}(\mathbf{ba} \times \mathbf{n} \cdot \mathbf{pa}) < 2$ [S2, unofficial].

*   **Ray-Triangle Intersection (Möller-Trumbore):**
    Used to determine if a ray from the voxel center intersects the triangle [S2, unofficial].
    $$ \mathbf{e1} = \mathbf{v1} - \mathbf{v0}, \quad \mathbf{e2} = \mathbf{v2} - \mathbf{v0} $$
    $$ \mathbf{pvec} = \mathbf{dir} \times \mathbf{e2}, \quad det = \mathbf{e1} \cdot \mathbf{pvec} $$
    If $|det| < 10^{-8}$, the ray is parallel [S2, unofficial].
    $$ u = \frac{\mathbf{tvec} \cdot \mathbf{pvec}}{det}, \quad v = \frac{\mathbf{dir} \cdot \mathbf{qvec}}{det} $$
    Hit if $0 \le u, v$ and $u + v \le 1$ [S2, unofficial].
    Note: The implementation calculates `hits` (ray intersection count) but does not use it for inside/outside determination in the final output [S2, unofficial].

**Parameters:**
*   `res`: Texture resolution (default 50) [S2, unofficial].
*   `is_closed`: Boolean flag indicating if the mesh is closed, required for correct sign determination in Approach B [S4].
*   `trunc_dist`: Maximum distance for skirt generation in open meshes [S3, unofficial].

**Pseudocode (Approach B - CPU/Implicit):**

```python
import math

def dot(a, b):
    return a[0]*b[0] + a[1]*b[1] + a[2]*b[2]

def cross(a, b):
    return (a[1]*b[2] - a[2]*b[1], a[2]*b[0] - a[0]*b[2], a[0]*b[1] - a[1]*b[0])

def sub(a, b):
    return (a[0]-b[0], a[1]-b[1], a[2]-b[2])

def add(a, b):
    return (a[0]+b[0], a[1]+b[1], a[2]+b[2])

def scale(v, s):
    return (v[0]*s, v[1]*s, v[2]*s)

def squared_length(v):
    return dot(v, v)

def closest_point_on_triangle(p, tri):
    a, b, c = tri
    ab = sub(b, a)
    ac = sub(c, a)
    ap = sub(p, a)
    
    d1 = dot(ab, ap)
    d2 = dot(ac, ap)
    if d1 <= 0.0 and d2 <= 0.0:
        return a
    
    bp = sub(p, b)
    d3 = dot(ab, bp)
    d4 = dot(ab, ab)
    if d3 >= 0.0 and d3 >= d4:
        return b
    
    vc = d1 * d4 - d3 * d2
    if vc >= 0.0 and d2 <= 0.0:
        t = d1 / d4
        return add(a, scale(ab, t))
    
    cp = sub(p, c)
    d5 = dot(ac, cp)
    d6 = dot(ac, ac)
    if d5 >= 0.0 and d5 >= d6:
        return c
    
    vb = d5 * d4 - d3 * d6
    if vb >= 0.0 and d1 <= 0.0 and d5 <= d6:
        t = vb / (d1 * d4 - d3 * d2)
        return add(a, scale(add(ab, scale(ac, t)), t))
    
    denom = 1.0 / (d1 * d4 - d3 * d2)
    t = (d2 * d4 - d3 * d6) * denom
    return add(a, scale(add(ab, scale(ac, t)), t))

def side_of_triangle_mesh(p, mesh):
    """Standard ray-casting test to determine bounded/unbounded side [G]."""
    ray_dir = (1.0, 0.0, 0.0)
    intersections = 0
    for tri in mesh.triangles:
        v0, v1, v2 = tri
        e1 = sub(v1, v0)
        e2 = sub(v2, v0)
        pvec = cross(ray_dir, e2)
        det = dot(e1, pvec)
        if abs(det) < 1e-8:
            continue
        tvec = sub(p, v0)
        u = dot(tvec, pvec) / det
        if u < 0.0 or u > 1.0:
            continue
        qvec = cross(tvec, e1)
        v = dot(ray_dir, qvec) / det
        if v < 0.0 or u + v > 1.0:
            continue
        t = dot(e2, qvec) / det
        if t > 0.0:
            intersections += 1
    return "ON_BOUNDED_SIDE" if intersections % 2 == 1 else "ON_UNBOUNDED_SIDE"

class AABBTree:
    def __init__(self, triangles):
        self.triangles = triangles

    def closest_point(self, p):
        min_dist_sq = float('inf')
        closest_pt = None
        for tri in self.triangles:
            pt = closest_point_on_triangle(p, tri)
            d_sq = squared_length(sub(p, pt))
            if d_sq < min_dist_sq:
                min_dist_sq = d_sq
                closest_pt = pt
        return closest_pt

def compute_sdf(p, mesh, is_closed):
    tree = AABBTree(mesh.triangles)
    cp = tree.closest_point(p)
    d = math.sqrt(squared_length(sub(p, cp)))
    
    if is_closed:
        side = side_of_triangle_mesh(p, mesh)
        if side == "ON_BOUNDED_SIDE":
            d = -d
    return d
```

## Operating characteristics
*   **Strengths:** Exact analytical distances; robust rendering with interval arithmetic bisection tracers [S1, unofficial]; supports CSG operations [S1, unofficial].
*   **Limitations:** Open meshes generate skirts up to `trunc_dist` past the rim [S3, unofficial]; inside-out meshes remain inside-out [S3, unofficial]; edges/corners with angles under 90 degrees may have incorrect signs due to nearest-face tie-breaking by lowest index [S3, unofficial].
*   **When to use:** Rendering CAD meshes (e.g., brake calipers, brackets) as implicit surfaces [S1, unofficial]; generating offset meshes for isosurfacing [S4].
*   **When not to use:** Open meshes requiring precise boundary handling without skirts (use Shell mode) [S3, unofficial].

## Background
The method originates from the need to render complex CAD meshes as implicit surfaces using robust interval-arithmetic bisection tracers [S1, unofficial]. It was implemented in libraries like `isoray` to support STL files and in CGAL's `Isosurfacing_3` module for contouring mesh offsets [S4][S1, unofficial]. The technique leverages spatial acceleration structures (AABB trees) and side-of-mesh functors to efficiently compute signed distances, enabling applications like dual contouring and marching cubes on mesh-derived fields [S4].
