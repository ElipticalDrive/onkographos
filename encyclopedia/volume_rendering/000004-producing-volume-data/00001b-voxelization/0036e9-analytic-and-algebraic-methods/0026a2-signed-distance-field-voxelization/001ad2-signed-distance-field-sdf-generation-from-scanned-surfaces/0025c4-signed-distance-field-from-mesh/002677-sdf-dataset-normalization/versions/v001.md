# SDF Dataset Normalization
Also called: SDF Mesh Loading
## Overview
SDF Dataset Normalization prepares a triangle mesh for Signed Distance Field (SDF) generation by centering the geometry at the origin and scaling its vertices to fit within a unit cube $[-1, 1]^3$ [S1, unofficial]. This standardization ensures that the resulting implicit function operates in a consistent coordinate space, which is critical for stable voxelization and neural network training in NeRF-based pipelines. It differs from its siblings by focusing specifically on the input mesh preprocessing stage rather than the grid resampling or sparse data structure generation [S1, unofficial].
## How it works
**Inputs and Outputs:**
- Input: A path to a mesh file (typically STL or OBJ).
- Output: A normalized mesh object with vertices scaled and translated.

**Data Structures:**
- `mesh`: A mesh object containing a vertex array `vs` of shape $(N, 3)$, where $N$ is the number of vertices.
- `vmin`: A 3D vector representing the component-wise minimum of the vertices.
- `vmax`: A 3D vector representing the component-wise maximum of the vertices.
- `v_center`: A 3D vector representing the centroid of the bounding box.

**Steps:**
1. Load the mesh from the specified file path using a library such as `trimesh`, forcing the load as a mesh object [S1, unofficial].
2. Extract the vertex coordinates $v_s$ from the loaded mesh [S1, unofficial].
3. Compute the minimum bounds $v_{min}$ by finding the minimum value along each axis (x, y, z) of $v_s$ [S1, unofficial].
4. Compute the maximum bounds $v_{max}$ by finding the maximum value along each axis of $v_s$ [S1, unofficial].
5. Calculate the center $v_{center}$ of the bounding box using the formula:
   $$ v_{center} = \frac{v_{min} + v_{max}}{2} $$
   [S1, unofficial].
6. Translate the vertices by subtracting $v_{center}$ to center the mesh at the origin.
7. Scale the vertices to fit within the range $[-1, 1]$. The scale factor is typically determined by the maximum extent of the bounding box. If the bounding box extent is $E = v_{max} - v_{min}$, the scale factor $s$ is often $2 / \max(E)$ to ensure the largest dimension fits exactly within $[-1, 1]$ [G].
8. Apply the translation and scaling to the vertex array.

**Pseudocode:**
```python
import trimesh
import numpy as np

def normalize_sdf_mesh(mesh_path):
    # Load mesh, forcing mesh type
    mesh = trimesh.load(mesh_path, force='mesh')
    
    # Extract vertices
    vs = mesh.vertices
    
    # Calculate bounds
    vmin = np.min(vs, axis=0)
    vmax = np.max(vs, axis=0)
    
    # Calculate center
    v_center = (vmin + vmax) / 2.0
    
    # Center the mesh
    centered_vs = vs - v_center
    
    # Calculate scale to fit in [-1, 1]
    # Extent of the bounding box
    extent = vmax - vmin
    # Max dimension of the extent
    max_extent = np.max(extent)
    
    # Avoid division by zero for degenerate meshes
    if max_extent == 0:
        scale = 1.0
    else:
        # Scale factor to map max_extent to 2 (from -1 to 1)
        scale = 2.0 / max_extent
        
    # Scale vertices
    normalized_vs = centered_vs * scale
    
    # Update mesh vertices
    mesh.vertices = normalized_vs
    
    return mesh
```

**Edge Cases and Pitfalls:**
- **Degenerate Meshes:** If the mesh has zero volume or identical vertices, `max_extent` will be zero, leading to division by zero. A guard is required [G].
- **Non-Watertight Meshes:** The normalization does not check for watertightness; it only transforms coordinates. Invalid geometry may still cause issues in subsequent SDF generation steps.
- **Coordinate System:** The method assumes a standard Cartesian coordinate system. If the source mesh uses a different convention (e.g., Y-up vs Z-up), additional rotation may be needed before normalization [G].

## Operating characteristics
- **Time Complexity:** $O(N)$, where $N$ is the number of vertices, as it requires a single pass to find min/max values.
- **Memory Complexity:** $O(N)$ to store the vertex array.
- **Strengths:** Simple, fast, and ensures consistent input scale for downstream SDF generation and neural networks.
- **Limitations:** Does not handle mesh quality issues (e.g., non-manifold edges). The choice of scaling factor (axis-aligned vs. spherical) can affect the final SDF quality if the mesh is highly anisotropic.

## Background
This method originates from the NeRF-Factory/IDDR-NGP project, which uses it as a preprocessing step for generating Signed Distance Fields from mesh data [S1, unofficial]. It is commonly used in neural rendering pipelines where consistent input scaling is crucial for model convergence.
