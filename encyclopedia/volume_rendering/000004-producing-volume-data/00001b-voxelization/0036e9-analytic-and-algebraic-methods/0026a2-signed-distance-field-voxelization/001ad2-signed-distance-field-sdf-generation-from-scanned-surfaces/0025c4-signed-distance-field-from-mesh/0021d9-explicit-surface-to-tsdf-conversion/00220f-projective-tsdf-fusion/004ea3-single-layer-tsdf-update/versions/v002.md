# Single Layer TSDF Update

Also called: Incremental map update, TSDF integration

## Overview
Single Layer TSDF Update is the core integration step in Projective TSDF Fusion that computes a signed distance field (SDF) sample for a specific voxel from a new depth measurement and merges it into the global map using a weighted average [S1]. It differs from static TSDF integration by supporting dynamic scale allocation within a multi-resolution octree, ensuring that distant voxels are not allocated as contiguous blocks and that the voxel size remains proportional to the camera distance [S1].

## How it works
**Inputs:**
*   $D_k$: Depth map at frame $k$ [S1].
*   $T_{cw}$: Euclidean transformation from camera frame $\{c\}$ to world frame $\{w\}$ [S1].
*   $p^l_w$: Position of the voxel in world frame at scale $l$ [S1].
*   $F^l_{k-1}$: Global map function value at scale $l$ and previous time step (or down-propagated value) [S1].
*   $y^l_{k-1}$: Accumulated weight at scale $l$ and previous time step [S1].
*   $\mu$: Truncation region parameter for TSDF [S1].
*   $y_{max}$: Maximum weight clamping value (typical: 100) [S1].
*   $\lambda$: Factor transforming z-axis distance to range distance [S1].
*   $\Delta y^l_{k-1}$: Previous weight increment for down-propagation [S1].

**Outputs:**
*   $F^l_k$: Updated global map function value at scale $l$ and time $k$ [S1].
*   $y^l_k$: Updated accumulated weight at scale $l$ and time $k$ [S1].
*   $\Delta y^l_k$: Increment of weight for down-propagation [S1].

**Data Structures:**
The method operates on voxels indexed by integer coordinates $x^l_w$ at the finest resolution possible [S1]. A scale parameter $l$ determines the factor $s = 2^{d-l}$ applied to retrieve entries in coarser grids, where $d$ is the maximum depth of the tree and $d - \log_2(8) \le l \le d$ [S1]. Voxels are cell-centred, meaning the sampling location is at the centre of its enclosing octant, allowing parent voxels to be exact linear combinations of their children [S1].

**Steps:**
1.  **Projection:** Transform the voxel world position $p^l_w$ to the camera frame using $T_{cw}$ [S1]. Project the 3D camera coordinates to 2D pixel coordinates using $\pi(\cdot)$ [S1].
2.  **Depth Sampling:** Retrieve the depth value $D_k$ at the projected pixel location [S1].
3.  **Distance Calculation:** Compute the signed distance $d$ along the z-axis in the camera frame, then transform to range distance using $\lambda$ [S1].
4.  **TSDF Sample:** Compute the local TSDF sample $f^l_k$ by clamping the normalized distance to $[-1, 1]$ [S1].
5.  **Integration:** Update the global map value $F^l_k$ and accumulated weight $y^l_k$ using the weighted average formula [S1].
6.  **Weight Tracking:** Update the weight increment $\Delta y^l_k$ for subsequent down-propagation [S1].

**Formulas:**
The signed distance $d$ is computed as:
$$ d = \lambda(D_k[\pi(T_{cw} p^l_w)] - p^l_{cz}) $$
where $p^l_{cz}$ is the z-component of the voxel position expressed in the camera coordinate frame [S1].

The TSDF sample $f^l_k$ is:
$$ f^l_k = \min\left(1, \frac{d}{\mu}\right) $$
The source omits the lower bound explicitly but the integration step enforces clamping to $[-1, 1]$ [S1].

The global map function value $F^l_k$ is updated as:
$$ F^l_k = \max\left(-1, \min\left(1, \frac{F^l_{k-1} + w f^l_k}{y^l_{k-1} + w}\right)\right) $$
where $w$ is the weight of the new sample, which the source formula structure implies as $w=1$ [S1].

The accumulated weight $y^l_k$ is:
$$ y^l_k = \min(y_{max}, y^l_{k-1} + 1) $$
where $y_{max}$ is the maximum weight (typically 100) [S1].

The weight increment $\Delta y^l_k$ is:
$$ \Delta y^l_k = \Delta y^l_{k-1} + 1 $$
This value is tracked for down-propagation [S1].

**Pseudocode:**
```python
def single_layer_tsdf_update(
    depth_map: Array2D,
    T_cw: Matrix4x4,
    voxel_pos_w: Vector3,
    current_map_value: float,
    current_weight: float,
    prev_delta_weight: int,
    max_weight: float = 100.0,
    truncation_mu: float = 0.05,
    lambda_factor: float = 1.0
) -> Tuple[float, float, int]:
    # 1. Transform voxel to camera frame and project to pixels
    # T_cw here represents the world-to-camera transformation matrix as used in the source formula [S1]
    voxel_pos_c = T_cw @ voxel_pos_w
    pixel_u = int(round(voxel_pos_c.x / voxel_pos_c.z))
    pixel_v = int(round(voxel_pos_c.y / voxel_pos_c.z))

    # 2. Retrieve depth
    depth_z = depth_map[pixel_v, pixel_u]

    # 3. Compute signed distance d
    p_cz = voxel_pos_c.z
    d = lambda_factor * (depth_z - p_cz)

    # 4. Compute TSDF sample f^l_k
    f_k = d / truncation_mu

    # 5. Integrate
    w = 1.0  # Sample weight implied by the source formula structure [S1]
    numerator = current_map_value + w * f_k
    denominator = current_weight + w
    new_map_value = numerator / denominator

    # 6. Update weight
    new_weight = current_weight + w
    if new_weight > max_weight:
        new_weight = max_weight

    # 7. Track weight increment for down-propagation
    new_delta_weight = prev_delta_weight + 1

    # 8. Clamp final map value to [-1, 1]
    if new_map_value > 1.0:
        new_map_value = 1.0
    elif new_map_value < -1.0:
        new_map_value = -1.0

    return new_map_value, new_weight, new_delta_weight
```

**Edge Cases and Pitfalls:**
*   **Precision:** The method relies on accurate projection and depth retrieval, requiring invalid depth values (e.g., infinity or zero) to be handled before calculation [S1].
*   **Boundaries:** The TSDF sample is clamped to $[-1, 1]$ and the integrated value is explicitly clamped to $[-1, 1]$ [S1].
*   **Scale Selection:** Each block is assigned a uniform scale to simplify iteration and up-propagation, avoiding the overhead of per-voxel scale selection [S1].
*   **Dynamic Allocation:** Voxels are allocated via ray-casting around the truncation region $\pm \mu$ [S1]. Distant voxels are not allocated as contiguous blocks to save memory [S1].

### Subtopics
**Multi-resolution Octree Structure:** Hierarchical storage where voxels at any scale are accessed via integer coordinates and a scaling factor $s=2^{d-l}$ [S1]. Cell-centred voxels enable exact linear combinations of children for parent voxels, distinguishing it from standard octrees [S1]. Choose when adaptive resolution and efficient multi-resolution traversal are required [S1]. [Multi-resolution Octree](multi-resolution-octree.md)

**Down-propagation:** Propagates information from finer to coarser scales using tracked weight increments $\Delta y^l_k$ [S1]. Distinguished by its reliance on the weight increment history rather than raw values [S1]. Choose when maintaining consistency across the octree hierarchy is necessary [S1]. [Down-propagation](down-propagation.md)

**Up-propagation:** Propagates information from coarser to finer scales, leveraging the cell-centred property [S1]. Distinguished by its use of linear combinations of children to update parents [S1]. Choose when refining coarse estimates with finer data is required [S1]. [Up-propagation](up-propagation.md)

## Operating characteristics
*   **Time Complexity:** The update is $O(1)$ per voxel per frame, assuming constant-time depth map access and projection [S1].
*   **Memory Complexity:** Memory usage is dynamic [S1]. Voxels are allocated only within the truncation region $\pm \mu$ of observed depth [S1]. The multi-resolution structure avoids allocating contiguous blocks for distant voxels, reducing memory footprint compared to uniform grids [S1].
*   **Measured Performance:** Not given in the sources.
*   **Scaling:** Not given in the sources.
*   **Strengths:** Efficient integration of new depth frames; dynamic scale selection keeps voxel size proportional to camera distance, maintaining resolution relevance; cell-centred voxels enable efficient multi-resolution operations [S1].
*   **Limitations:** Requires careful handling of depth map indexing and coordinate transformations; dynamic allocation adds complexity to memory management [S1].
*   **When to use:** Suitable for real-time SLAM and mapping systems where memory efficiency and adaptive resolution are critical [S1].

## Background
The method is part of the Adaptive-resolution octree-based volumetric SLAM system presented by Luiten et al. in 2019 [S1]. It builds upon previous work [21] by introducing dynamic scale allocation and cell-centred voxels for improved local consistency and efficient multi-resolution handling [S1].
