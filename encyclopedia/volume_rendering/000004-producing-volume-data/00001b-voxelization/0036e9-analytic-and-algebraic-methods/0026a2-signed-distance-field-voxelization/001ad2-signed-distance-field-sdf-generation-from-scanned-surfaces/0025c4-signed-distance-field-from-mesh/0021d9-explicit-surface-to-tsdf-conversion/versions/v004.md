# Explicit Surface to TSDF Conversion

Also called: Explicit Geometry to TSDF, Mesh to TSDF

## Overview
This method converts explicit geometry, such as triangle meshes or oriented point clouds, into a Truncated Signed Distance Field (TSDF) voxel grid by computing the closest-surface distance for each voxel center and assigning a sign based on surface orientation [S1]. It differs from [Projective TSDF Fusion](2658-projective-tsdf-fusion.md) by operating directly on explicit geometric primitives rather than raw depth buffers, and from [Sparse VDB SDF Generation](4498-sparse-vdb-sdf-generation.md) by focusing on the initial conversion of a single explicit surface representation into a dense or sparse voxel volume [S1].

## How it works
**Inputs:**
*   A set of triangles $\mathcal{T}$ (for meshes) or a set of oriented points (for point clouds).
*   A global voxel grid definition (origin, resolution, truncation band $\epsilon$).

**Outputs:**
*   A TSDF voxel grid where each valid voxel contains a truncated signed distance value.

**Data Structures:**
*   **Triangle:** Defined by vertices $a, b, c \in \mathbb{R}^3$.
*   **Voxel Center:** $\mathbf{p} \in \mathbb{R}^3$.
*   **TSDF Value:** Scalar $s(\mathbf{p}) \in [-1, 1]$.

**Algorithm:**

1.  **Closest Point Projection:** For each voxel center $\mathbf{p}$, find the closest point on the surface.
    *   For a mesh, iterate over all triangles $\tau \in \mathcal{T}$.
    *   For a triangle with vertices $a, b, c$, the closest point $\Pi_\tau(\mathbf{p})$ is found by projecting $\mathbf{p}$ onto the triangle plane. If the projection lies within the triangle, it is the closest point. Otherwise, project $\mathbf{p}$ onto the three edge segments and select the nearest point [S1].
    *   The barycentric coordinate $q(v, w)$ on the triangle is defined as:
        $$q(v, w) = a + v(b-a) + w(c-a)$$
        subject to $v \geq 0, w \geq 0, v + w \leq 1$ [S1].
    *   Compute the unsigned distance:
        $$d(\mathbf{p}) = \min_{\tau \in \mathcal{T}} \|\mathbf{p} - \Pi_\tau(\mathbf{p})\|_2 \quad (7)$$
    *   For point clouds, $d(\mathbf{p})$ is the distance to the nearest point in the cloud.

2.  **Sign Assignment:** Determine the sign of the distance.
    *   **Watertight Meshes:** If the mesh is watertight with consistent orientation, let $\tau^\star$ be the triangle containing the closest point $\Pi_{\tau^\star}(\mathbf{p})$ and $\mathbf{n}_{\tau^\star}$ be its unit normal. The signed distance is:
        $$s(\mathbf{p}) = \text{sign}((\mathbf{p} - \Pi_{\tau^\star}(\mathbf{p}))^\top \mathbf{n}_{\tau^\star}) d(\mathbf{p}) \quad (8)$$
        This local point-to-plane side test assumes a coherent inside/outside convention [S1].
    *   **Oriented Point Clouds:** Use the normal of the closest point to determine the sign analogously to the mesh case.
    *   **Non-Watertight/Unreliable Normals:** If the surface is non-watertight, contains thin sheets, or normals are unreliable, a global inside/outside sign is ill-defined. Use the unsigned-distance offset fallback:
        $$s(\mathbf{p}) = d(\mathbf{p}) - \delta \quad (9)$$
        where $\delta \approx 1\text{--}2$ voxel sizes. This creates a stable zero level set around the geometry without requiring watertightness [S1].

3.  **Truncation and Marking:**
    *   Truncate the signed distance $s(\mathbf{p})$ to the band $[-\epsilon, \epsilon]$.
    *   Mark voxels within this band as valid.

**Pseudocode:**

```python
def compute_tsdf_from_mesh(triangles, voxel_centers, epsilon, delta):
    """
    Converts a mesh to a TSDF grid.
    
    Args:
        triangles: List of triangles, each defined by 3 vertices (a, b, c).
        voxel_centers: List of 3D points representing voxel centers.
        epsilon: Truncation band width.
        delta: Offset for non-watertight fallback (approx 1-2 voxel sizes).
        
    Returns:
        tsdf_values: List of truncated signed distances for each voxel center.
        valid_mask: Boolean mask indicating which voxels are within the truncation band.
    """
    tsdf_values = []
    valid_mask = []
    
    for p in voxel_centers:
        # 1. Find closest triangle and point
        min_dist = infinity
        closest_point = None
        closest_normal = None
        is_watertight_sign = False
        
        for tri in triangles:
            a, b, c = tri.vertices
            n = tri.normal # Precomputed unit normal
            
            # Project p onto triangle plane
            # Plane equation: n . (x - a) = 0
            # Distance to plane: d_plane = n . (p - a)
            # Projection point: proj = p - d_plane * n
            
            d_plane = dot(n, sub(p, a))
            proj = sub(p, mul(d_plane, n))
            
            # Check if proj is inside triangle using barycentric coords
            # v, w such that proj = a + v(b-a) + w(c-a)
            # Solve for v, w. If v >= 0, w >= 0, v+w <= 1, proj is inside.
            # Otherwise, find closest point on edges.
            
            closest_tri_point = project_point_to_triangle(p, a, b, c)
            dist = length(sub(p, closest_tri_point))
            
            if dist < min_dist:
                min_dist = dist
                closest_point = closest_tri_point
                closest_normal = n
                # Assume watertight if we found a valid triangle projection
                # Note: In practice, watertightness is a property of the mesh,
                # not per-voxel. This flag indicates if we *can* use normal sign.
                is_watertight_sign = True 

        # 2. Compute Signed Distance
        if is_watertight_sign:
            # s(p) = sign((p - closest_point)^T * normal) * d(p)
            diff = sub(p, closest_point)
            side = dot(diff, closest_normal)
            sign_val = 1.0 if side >= 0 else -1.0
            s = sign_val * min_dist
        else:
            # Fallback for non-watertight or unreliable normals
            s = min_dist - delta
            
        # 3. Truncate
        if abs(s) <= epsilon:
            tsdf_values.append(s / epsilon) # Normalize to [-1, 1]
            valid_mask.append(True)
        else:
            tsdf_values.append(0.0) # Or undefined, depending on implementation
            valid_mask.append(False)
            
    return tsdf_values, valid_mask

def project_point_to_triangle(p, a, b, c):
    """
    Finds the closest point on triangle abc to point p.
    Returns the closest point on the triangle surface.
    """
    # Vector from a to b, a to c, a to p
    ab = sub(b, a)
    ac = sub(c, a)
    ap = sub(p, a)
    
    # Dot products
    d1 = dot(ab, ap)
    d2 = dot(ac, ap)
    d3 = dot(ab, ac)
    d4 = dot(ab, ab)
    d5 = dot(ac, ac)
    
    # Barycentric coordinates
    denom = d4 * d5 - d3 * d3
    if denom == 0:
        # Degenerate triangle, return a
        return a
        
    v = (d4 * d2 - d3 * d1) / denom
    w = (d5 * d3 - d3 * d2) / denom
    
    if v >= 0 and w >= 0 and (v + w) <= 1:
        # Projection is inside the triangle
        return add(a, add(mul(v, ab), mul(w, ac)))
    
    # Projection is outside, find closest point on edges
    # Edge AB
    if v < 0:
        # Closest point is on edge AB or AC or vertex A
        # Check edge AB
        t = max(0, min(1, d1 / d4))
        pt_ab = add(a, mul(t, ab))
        dist_ab = length(sub(p, pt_ab))
        
        # Check edge AC
        t_ac = max(0, min(1, d2 / d5))
        pt_ac = add(a, mul(t_ac, ac))
        dist_ac = length(sub(p, pt_ac))
        
        # Check vertex A (already covered by t=0 in edges, but for completeness)
        dist_a = length(sub(p, a))
        
        if dist_ab <= dist_ac and dist_ab <= dist_a:
            return pt_ab
        elif dist_ac <= dist_ab and dist_ac <= dist_a:
            return pt_ac
        else:
            return a
            
    # Edge BC
    if w < 0:
        # Closest point is on edge BC or vertex B or C
        # Check edge BC
        bc = sub(c, b)
        bp = sub(p, b)
        t_bc = max(0, min(1, dot(bc, bp) / dot(bc, bc)))
        pt_bc = add(b, mul(t_bc, bc))
        dist_bc = length(sub(p, pt_bc))
        
        # Check vertex B
        dist_b = length(sub(p, b))
        # Check vertex C
        dist_c = length(sub(p, c))
        
        if dist_bc <= dist_b and dist_bc <= dist_c:
            return pt_bc
        elif dist_b <= dist_bc and dist_b <= dist_c:
            return b
        else:
            return c
            
    # Edge AC (v > 1, w < 0 case handled above? No, v>1 implies outside AB extended)
    # Actually, if v > 1, we are past B. If w < 0, we are "below" AC.
    # The logic above for v<0 and w<0 covers the corners.
    # If v > 1 and w > 0 and v+w > 1, we are past edge BC.
    # Let's simplify: just check all 3 edges and 3 vertices.
    
    # Edge AB
    t_ab = max(0, min(1, dot(ab, ap) / dot(ab, ab)))
    pt_ab = add(a, mul(t_ab, ab))
    
    # Edge BC
    bc = sub(c, b)
    bp = sub(p, b)
    t_bc = max(0, min(1, dot(bc, bp) / dot(bc, bc)))
    pt_bc = add(b, mul(t_bc, bc))
    
    # Edge CA
    ca = sub(a, c)
    cp = sub(p, c)
    t_ca = max(0, min(1, dot(ca, cp) / dot(ca, ca)))
    pt_ca = add(c, mul(t_ca, ca))
    
    # Vertices
    dist_a = length(sub(p, a))
    dist_b = length(sub(p, b))
    dist_c = length(sub(p, c))
    
    dist_ab = length(sub(p, pt_ab))
    dist_bc = length(sub(p, pt_bc))
    dist_ca = length(sub(p, pt_ca))
    
    min_d = min(dist_a, dist_b, dist_c, dist_ab, dist_bc, dist_ca)
    
    if min_d == dist_a: return a
    if min_d == dist_b: return b
    if min_d == dist_c: return c
    if min_d == dist_ab: return pt_ab
    if min_d == dist_bc: return pt_bc
    if min_d == dist_ca: return pt_ca
    
    return a # Fallback
```

## Operating characteristics
*   **Time Complexity:** $O(N \cdot M)$ where $N$ is the number of voxels and $M$ is the number of triangles/points. This is computationally expensive for high-resolution grids and complex meshes.
*   **Memory Complexity:** $O(N)$ for the voxel grid.
*   **Strengths:** Direct conversion from explicit geometry; handles both meshes and point clouds; robust to non-watertight surfaces via offset fallback.
*   **Limitations:** Slow for large scenes without spatial acceleration structures (e.g., BVH, Octree); not given in the sources whether acceleration structures are used in the basic method.
*   **When to use:** When explicit mesh or point cloud data is available and a TSDF representation is needed for downstream tasks like rendering or compression.
*   **When not to use:** When real-time performance is critical and depth images are available (use Projective TSDF Fusion); when memory is extremely constrained and sparse representations are preferred (use Sparse VDB SDF Generation).

## Background
The method is described in the context of implicit surface compression using Discrete Cosine Transform and Motion Compensation [S1]. It addresses the problem of converting explicit geometry (meshes or point clouds) into a format suitable for volumetric compression pipelines. The approach handles non-watertight surfaces by using an unsigned-distance offset fallback, a technique inspired by Xu and Barbič [2020] for polygonsoup meshes [S1].
