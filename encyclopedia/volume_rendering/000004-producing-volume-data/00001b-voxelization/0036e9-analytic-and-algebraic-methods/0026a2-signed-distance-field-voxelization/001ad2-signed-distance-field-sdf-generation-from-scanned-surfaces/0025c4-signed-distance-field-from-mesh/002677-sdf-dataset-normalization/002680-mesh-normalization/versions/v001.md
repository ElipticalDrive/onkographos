# Mesh Normalization


## Overview
Mesh normalization is a preprocessing method that transforms a 3D mesh's vertex coordinates so that the geometry is centered at the origin and scaled to fit within a unit cube $[-1, 1]^3$ [S1, unofficial]. This standardization ensures consistent scale and position for downstream tasks such as Signed Distance Field (SDF) generation, neural network training, or voxelization, where input invariance to translation and rotation (if combined with rotation normalization) is critical [S1, unofficial]. It differs from Variance Normalization, which scales based on the distribution of points rather than bounding extent [S2, unofficial].

## How it works
**Inputs:** A mesh object containing a list of vertices $V = \{v_1, v_2, \dots, v_N\}$ where each $v_i \in \mathbb{R}^3$.
**Outputs:** The same mesh object with updated vertex coordinates.

**Data Structures:**
- `vertices`: A numpy-like array or list of 3D vectors.
- `bounds`: A pair of 3D vectors representing the minimum and maximum coordinates of the mesh.

**Steps:**
1. **Compute Bounds:** Determine the axis-aligned bounding box (AABB) of the mesh. Let $min$ and $max$ be the minimum and maximum coordinates across all vertices.
   $$ min = \min_{v \in V} v, \quad max = \max_{v \in V} v $$
2. **Compute Center:** Calculate the centroid of the bounding box.
   $$ center = \frac{min + max}{2} $$
3. **Compute Extents:** Calculate the size of the bounding box along each axis.
   $$ extents = max - min $$
4. **Compute Max Extent:** Find the largest dimension of the bounding box.
   $$ max\_extent = \max(extents) $$
5. **Compute Scale Factor:** Determine the uniform scale factor required to fit the mesh into a unit cube.
   $$ scale\_factor = \frac{1.0}{max\_extent} $$
6. **Translate:** Subtract the center from each vertex to move the mesh to the origin.
   $$ v'_i = v_i - center $$
7. **Scale:** Multiply each translated vertex by the scale factor.
   $$ v''_i = v'_i \times scale\_factor $$

**Pseudocode:**
```python
def normalize_mesh(mesh):
    # 1. Compute bounds
    vertices = mesh.vertices
    min_coord = vertices.min(axis=0)
    max_coord = vertices.max(axis=0)
    
    # 2. Compute center
    center = (min_coord + max_coord) / 2.0
    
    # 3. Compute extents
    extents = max_coord - min_coord
    
    # 4. Compute max extent
    max_extent = extents.max()
    
    # Guard against degenerate mesh with zero volume
    if max_extent == 0:
        return mesh
        
    # 5. Compute scale factor
    scale_factor = 1.0 / max_extent
    
    # 6. Translate and 7. Scale
    mesh.vertices = (vertices - center) * scale_factor
    
    return mesh
```

**Parameters:**
- None. The method is deterministic based on the input geometry.

**Edge Cases and Pitfalls:**
- **Zero Extent:** If the mesh consists of a single point or all vertices are identical, `max_extent` is 0, leading to division by zero. A guard clause is required [G].
- **Precision:** Floating-point precision errors in `min`/`max` calculations can cause slight misalignments in high-precision applications, though typically negligible for normalization [G].

## Subtopics

### Variance Normalization
Variance normalization scales a mesh so that the mean squared distance from its center of mass is 1 [S2, unofficial]. Unlike Mesh Normalization which uses the bounding box extent, this method uses the covariance of the vertex positions [S2, unofficial].
**Steps:**
1. Compute the center of mass (COM) of the vertices [S2, unofficial].
2. Translate the mesh to the origin: $v'_i = v_i - COM$ [S2, unofficial].
3. Compute the covariance matrix $C$ of the translated vertices [S2, unofficial].
4. Compute the scale factor $s$ using the trace of the covariance matrix: $s = \frac{1}{\sqrt{\text{tr}(C)}}$ [S2, unofficial].
5. Apply the scale: $v''_i = v'_i \times s$ [S2, unofficial].
6. Translate back to the original center of mass: $v'''_i = v''_i + COM$ [S2, unofficial].
**Formula:**
$$ s = \frac{1}{\sqrt{C_{00} + C_{11} + C_{22}}} $$
where $C_{ij}$ are the diagonal elements of the covariance matrix [S2, unofficial].
**When to choose:** Use when the distribution of points (variance) is more important than the bounding extent, such as in some statistical shape analyses or specific neural network architectures that assume unit variance [S2, unofficial].

## Operating characteristics
- **Time Complexity:** $O(N)$, where $N$ is the number of vertices. Requires a single pass to find min/max and another for translation/scaling.
- **Memory Complexity:** $O(1)$ auxiliary space if performed in-place, or $O(N)$ if creating a new mesh.
- **Strengths:** Simple, fast, and ensures the model fits within a known canonical space $[-1, 1]^3$, which is standard for many SDF and neural rendering pipelines [S1, unofficial].
- **Limitations:** Does not account for the internal distribution of the mesh, only its outer bounds. Thin structures or outliers can dominate the scale factor, potentially shrinking important features [G].
- **When to use:** Standard preprocessing for SDF generation and voxelization where a canonical bounding box is required [S1, unofficial].

## Background
Mesh normalization is a fundamental preprocessing step in computer graphics and geometric deep learning. It is widely used in pipelines involving Signed Distance Fields (SDFs) to ensure that the spatial sampling grid covers the object uniformly [S1, unofficial]. The specific implementation described here, centering at the bounding box center and scaling by the max extent, is common in modern neural reconstruction frameworks [S1, unofficial].
