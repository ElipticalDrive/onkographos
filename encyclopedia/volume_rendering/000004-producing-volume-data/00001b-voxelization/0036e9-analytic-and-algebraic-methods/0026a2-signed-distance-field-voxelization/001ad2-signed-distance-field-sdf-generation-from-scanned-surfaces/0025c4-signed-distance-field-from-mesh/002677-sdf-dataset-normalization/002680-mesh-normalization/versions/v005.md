# Mesh Normalization
## Overview
Mesh Normalization transforms a 3D mesh's vertex coordinates to fit within a standardized canonical space, typically a unit cube or unit sphere centered at the origin [S1, S3, unofficial]. This process solves the problem of inconsistent scale and position in input meshes [S1, S3, unofficial]. It differs from [SDF Grid Resampling from File](4878-sdf-grid-resampling-from-file.md) by operating on the source mesh geometry directly rather than on an existing voxel grid [S1, S3, unofficial].

## How it works
The method consists of three primary variants: Axis-Aligned Bounding Box (AABB) Normalization, Variance Normalization, and Mesh Loading with Normalization [S1, S2, S3, unofficial]. All variants assume the input is a mesh defined by a set of 3D vertices $V = \{v_1, v_2, \dots, v_n\}$ where $v_i \in \mathbb{R}^3$ [G].

### AABB Normalization (Standard)
This variant centers the mesh and scales it to fit within a unit cube $[-1, 1]^3$ [S1, unofficial].
**Inputs:** `vertices`: Array of $n$ 3D vectors [S1, unofficial].
**Outputs:** `vertices`: Transformed array of $n$ 3D vectors [S1, unofficial].
**Steps:**
1. Compute bounds and center of the mesh [S1, unofficial].
2. Compute max extent [S1, unofficial].
3. Compute scale factor as $1.0 / \text{max\_extent}$ [S1, unofficial].
4. Subtract center from vertices [S1, unofficial].
5. Multiply vertices by scale factor [S1, unofficial].
**Formulas:**
Let $v_i = (x_i, y_i, z_i)$.
1. Bounds:
   $$ x_{min} = \min_i(x_i), \quad x_{max} = \max_i(x_i) $$
   $$ y_{min} = \min_i(y_i), \quad y_{max} = \max_i(y_i) $$
   $$ z_{min} = \min_i(z_i), \quad z_{max} = \max_i(z_i) $$
2. Center:
   $$ c = \left( \frac{x_{min} + x_{max}}{2}, \frac{y_{min} + y_{max}}{2}, \frac{z_{min} + z_{max}}{2} \right) $$
3. Extents:
   $$ e_x = x_{max} - x_{min}, \quad e_y = y_{max} - y_{min}, \quad e_z = z_{max} - z_{min} $$
4. Max Extent:
   $$ e_{max} = \max(e_x, e_y, e_z) $$
5. Scale Factor:
   $$ s = \frac{1.0}{e_{max}} $$
6. Translation:
   $$ v'_i = v_i - c $$
7. Scaling:
   $$ v''_i = v'_i \cdot s $$
**Pseudocode:**
```python
def normalize_mesh_aabb(vertices):
    """
    Normalizes mesh vertices to fit in a unit cube [-1, 1]^3.
    vertices: list of [x, y, z] floats.
    Returns: list of normalized [x, y, z] floats.
    """
    if not vertices:
        return []

    # 1. Compute bounds
    xs = [v[0] for v in vertices]
    ys = [v[1] for v in vertices]
    zs = [v[2] for v in vertices]

    x_min = min(xs)
    x_max = max(xs)
    y_min = min(ys)
    y_max = max(ys)
    z_min = min(zs)
    z_max = max(zs)

    # 2. Compute center
    center_x = (x_min + x_max) / 2.0
    center_y = (y_min + y_max) / 2.0
    center_z = (z_min + z_max) / 2.0
    center = (center_x, center_y, center_z)

    # 3. Compute extents
    extent_x = x_max - x_min
    extent_y = y_max - y_min
    extent_z = z_max - z_min

    # 4. Compute max extent
    max_extent = max(extent_x, extent_y, extent_z)

    # Handle degenerate case where max_extent is 0
    if max_extent == 0:
        return vertices

    # 5. Compute scale factor
    scale_factor = 1.0 / max_extent

    # 6 & 7. Translate and Scale
    normalized_vertices = []
    for v in vertices:
        tx = (v[0] - center_x) * scale_factor
        ty = (v[1] - center_y) * scale_factor
        tz = (v[2] - center_z) * scale_factor
        normalized_vertices.append([tx, ty, tz])

    return normalized_vertices
```

### Variance Normalization
This variant scales a mesh so that the mean squared distance from its center of mass is 1 [S2, unofficial].
**Inputs:** `vertices`: Array of $n$ 3D vectors [S2, unofficial].
**Outputs:** `vertices`: Transformed array [S2, unofficial].
**Steps:**
1. Compute center of mass `com` [S2, unofficial].
2. Translate mesh to origin: `trans(mesh, -com)` [S2, unofficial].
3. Compute covariance matrix `C` [S2, unofficial].
4. Compute scale factor: $s = 1.0 / \sqrt{C_{00} + C_{11} + C_{22}}$ [S2, unofficial].
5. Apply scale: `scale(mesh, s)` [S2, unofficial].
6. Translate back: `trans(mesh, com)` [S2, unofficial].
**Formulas:**
1. Center of Mass:
   $$ \text{com} = \frac{1}{n} \sum_{i=1}^{n} v_i $$
2. Translation to Origin:
   $$ v'_i = v_i - \text{com} $$
3. Covariance Matrix $C$:
   $$ C = \frac{1}{n} \sum_{i=1}^{n} v'_i (v'_i)^T $$
   Where $C$ is a $3 \times 3$ matrix.
4. Scale Factor:
   $$ s = \frac{1}{\sqrt{\text{tr}(C)}} = \frac{1}{\sqrt{C_{00} + C_{11} + C_{22}}} $$
5. Scaling:
   $$ v''_i = v'_i \cdot s $$
6. Translation Back:
   $$ v'''_i = v''_i + \text{com} $$
**Pseudocode:**
```python
def normalize_mesh_variance(vertices):
    """
    Normalizes mesh vertices so mean squared distance from center of mass is 1.
    vertices: list of [x, y, z] floats.
    Returns: list of normalized [x, y, z] floats.
    """
    if not vertices:
        return []

    n = len(vertices)
    
    # 1. Compute Center of Mass
    com_x = sum(v[0] for v in vertices) / n
    com_y = sum(v[1] for v in vertices) / n
    com_z = sum(v[2] for v in vertices) / n
    com = (com_x, com_y, com_z)

    # 2. Translate to origin
    translated = []
    for v in vertices:
        translated.append([v[0] - com_x, v[1] - com_y, v[2] - com_z])

    # 3. Compute Covariance Matrix C
    # C is 3x3. We only need the diagonal for the trace, but we compute full matrix for clarity.
    # C_ij = (1/n) * sum(v'_i * v'_j)
    c00 = sum(t[0]**2 for t in translated) / n
    c11 = sum(t[1]**2 for t in translated) / n
    c22 = sum(t[2]**2 for t in translated) / n
    
    # 4. Compute scale factor s = 1 / sqrt(tr(C))
    trace_c = c00 + c11 + c22
    if trace_c == 0:
        return vertices # Degenerate case
    
    s = 1.0 / (trace_c ** 0.5)

    # 5. Scale vertices
    scaled = []
    for t in translated:
        scaled.append([t[0] * s, t[1] * s, t[2] * s])

    # 6. Translate back
    final_vertices = []
    for t in scaled:
        final_vertices.append([t[0] + com_x, t[1] + com_y, t[2] + com_z])

    return final_vertices
```

### Mesh Loading and Normalization
This variant loads a 3D model from a file, extracts vertices and indices, normalizes the mesh to a unit sphere centered at the origin, and builds an acceleration structure [S3, unofficial].
**Inputs:** File path to a 3D model [S3, unofficial].
**Outputs:** Normalized mesh data (vertices, indices) ready for acceleration structure construction [S3, unofficial].
**Steps:**
1. Load model using Assimp::Importer with specific flags: `Triangulate`, `JoinIdenticalVertices`, `RemoveComponent`, `ImproveCacheLocality`, `OptimizeMeshes`, `OptimizeGraph`, `DropNormals` [S3, unofficial].
2. Extract vertices from the first mesh [S3, unofficial].
3. Calculate bounding box centroid and radius (max distance from centroid to any vertex) [S3, unofficial].
4. Scale vertices so that the radius is 1.0 (centered at centroid) [S3, unofficial].
5. Extract indices from faces and convert to 3-component indices [S3, unofficial].
6. Build acceleration structure with vertices and indices [S3, unofficial].

## Subtopics

### Variance Normalization
Scales a mesh so that the mean squared distance from its center of mass is 1 [S2, unofficial]. It differs from AABB normalization by using statistical variance rather than geometric bounds, making it sensitive to the distribution of vertices rather than just the extremities [G]. Choose this when the mesh has outliers that distort the bounding box but the core geometry is what matters for SDF generation [G]. Link: [S2, unofficial].

### Mesh Loading and Normalization
Integrates normalization into the file loading pipeline, specifically targeting unit sphere normalization (radius 1.0) for use with acceleration structures [S3, unofficial]. It differs from standalone normalization by including the loading step and specific Assimp processing flags [S3, unofficial]. Choose this when building a renderer that requires immediate acceleration structure construction upon loading [G]. Link: [S3, unofficial].

## Operating characteristics
- **Time Complexity:** $O(n)$ for all variants, where $n$ is the number of vertices [G].
- **Memory Complexity:** $O(n)$ to store the transformed vertices [G].
- **Measured Performance:** Not given in the sources.
- **Scaling:** Linear with respect to vertex count [G].
- **Strengths:** Ensures consistent input scale for SDF grids [G].
- **Limitations:** AABB normalization can be skewed by outliers [G]. Variance normalization can be skewed by sparse regions [G]. Mesh Loading variant depends on the correctness of the Assimp parsing flags [S3, unofficial].
- **When to use:** Always before SDF generation or voxelization if the input mesh scale is unknown or variable [G].
- **When not:** If the mesh is already normalized or if the absolute scale is physically meaningful and must be preserved [G].

## Background
Mesh normalization is a standard preprocessing step in computer graphics, particularly in pipelines involving Signed Distance Fields (SDFs) and voxelization [G]. The AABB method is used to standardize input shapes by centering at the origin and scaling to a unit cube [S1, unofficial]. The Variance Normalization method is used in research on high-resolution sparse voxel DAGs [S2, unofficial]. The Mesh Loading variant is used in implementations that integrate normalization with ray tracing acceleration structure construction [S3, unofficial].
