# SDF Grid Resampling from File

## Overview
Reads a raw Signed Distance Field (SDF) text file, parses its grid resolution, bounding box, and voxel size, then resamples it to a target cubic grid resolution using coordinate mapping and clamping [S1, unofficial]. It differs from sibling methods by handling non-cubic source grids and normalizing the spatial extent to a centered bounding box before interpolation [S1, unofficial].

## How it works
**Inputs:**
- `file_path`: Path to the raw SDF text file [S1, unofficial].
- `target_grid_res`: Integer target cubic resolution for the output SDF grid [S1, unofficial].
- `target_bounding_box_min`: 3D vector defining the minimum corner of the target bounding box in physical space [S1, unofficial].
- `target_bounding_box_max`: 3D vector defining the maximum corner of the target bounding box in physical space [S1, unofficial].
- `target_voxel_size`: Physical voxel size for the target grid [S1, unofficial].

**Outputs:**
- `target_grid`: A 3D tensor of shape `(target_grid_res, target_grid_res, target_grid_res)` containing the resampled SDF values [S1, unofficial].

**Data Structures:**
- Source Grid: A 3D array of size `grid_res_x x grid_res_y x grid_res_z` [S1, unofficial].
- Target Grid: A 3D array of size `target_grid_res x target_grid_res x target_grid_res` [S1, unofficial].
- Points Tensor: A 2D tensor of shape `(N, 3)` where `N = target_grid_res^3`, representing physical coordinates [S1, unofficial].

**Steps:**
1. **Parse Header:** Read the first line to extract `grid_res_x`, `grid_res_y`, `grid_res_z` [S1, unofficial]. Read the second line to extract `bounding_box_min_x`, `bounding_box_min_y`, `bounding_box_min_z` [S1, unofficial]. Read the third line to extract `voxel_size` [S1, unofficial].
2. **Compute Source Bounds:** Calculate `bounding_box_max_x = bounding_box_min_x + voxel_size * (grid_res_x - 1)` [S1, unofficial]. Similarly compute Y and Z bounds [S1, unofficial].
3. **Normalize Extent:** Compute `min_bounding_box_min = min(bounding_box_min_x, bounding_box_min_y, bounding_box_min_z)` and `max_bounding_box_max = max(bounding_box_max_x, bounding_box_max_y, bounding_box_max_z)` [S1, unofficial]. Compute `max_dist = max(bounding_box_max_x - bounding_box_min_x, bounding_box_max_y - bounding_box_min_y, bounding_box_max_z - bounding_box_min_z)` [S1, unofficial].
4. **Initialize Source Grid:** Create a 3D array of size `grid_res_x x grid_res_y x grid_res_z` initialized to `2.0` [S1, unofficial].
5. **Read Data:** Read SDF values from the file in Z, Y, X order (outer loop Z, middle loop Y, inner loop X) and assign to `grid[k][j][i]` [S1, unofficial].
6. **Generate Target Coordinates:** Create linear spaces `linear_space_x`, `linear_space_y`, `linear_space_z` from `0` to `target_grid_res - 1` [S1, unofficial]. Generate all combinations to form a 2D tensor of shape `(N, 3)` [S1, unofficial].
7. **Map to Physical Space:** Construct `bounding_min_matrix` by repeating `bounding_box_min` N times [S1, unofficial]. Construct `move_to_center_matrix` with offsets `move_x = (max_dist - (bounding_box_max_x - bounding_box_min_x)) / 2`, similarly for Y and Z [S1, unofficial]. Calculate physical points using `points = bounding_min_matrix + (target_voxel_size * max_dist / (target_bounding_box_max - target_bounding_box_min)) * points_indices - move_to_center_matrix` [S1, unofficial].
8. **Clamp Points:** Clamp out-of-bounds points to the nearest face of the source bounding box to prevent memory access errors [S1, unofficial].
9. **Compute Indices:** Calculate `voxel_min_point_index = floor((points - min) / voxel_size).clamp(max=grid_res-2)` [S1, unofficial].
10. **Interpolate:** Call `calculate_sdf_value` with points and indices to perform trilinear interpolation [S1, unofficial].
11. **Reshape:** Reshape the result to `(target_grid_res, target_grid_res, target_grid_res)` [S1, unofficial].

**Parameters:**
- `target_grid_res`: Typical value 64 or higher [S1, unofficial].
- `target_voxel_size`: Typical value 0.002 [S1, unofficial].

**Pitfalls:**
- Points falling outside the source bounding box must be clamped to the nearest face to prevent out-of-bounds memory access during interpolation [S1, unofficial].
- Round errors in bounding box calculation can be mitigated by adding a small epsilon (e.g., 0.0001) to `bounding_box_max` [S1, unofficial].

```python
import torch

def read_sdf(file_path, target_grid_res, target_bounding_box_min, target_bounding_box_max, target_voxel_size):
    with open(file_path) as file:
        # 1. Parse Header
        line = file.readline()
        grid_res = line.split()
        grid_res_x, grid_res_y, grid_res_z = int(grid_res[0]), int(grid_res[1]), int(grid_res[2])

        line = file.readline()
        bounding_box_min = line.split()
        bounding_box_min_x, bounding_box_min_y, bounding_box_min_z = float(bounding_box_min[0]), float(bounding_box_min[1]), float(bounding_box_min[2])

        line = file.readline()
        voxel_size = float(line)

        # 2. Compute Source Bounds
        bounding_box_max_x = bounding_box_min_x + voxel_size * (grid_res_x - 1)
        bounding_box_max_y = bounding_box_min_y + voxel_size * (grid_res_y - 1)
        bounding_box_max_z = bounding_box_min_z + voxel_size * (grid_res_z - 1)

        # 3. Normalize Extent
        min_bounding_box_min = min(bounding_box_min_x, bounding_box_min_y, bounding_box_min_z)
        max_bounding_box_max = max(bounding_box_max_x, bounding_box_max_y, bounding_box_max_z)
        max_dist = max(bounding_box_max_x - bounding_box_min_x, 
                       bounding_box_max_y - bounding_box_min_y, 
                       bounding_box_max_z - bounding_box_min_z)

        # 4. Initialize Source Grid
        grid = torch.full((grid_res_x, grid_res_y, grid_res_z), 2.0)
        
        # 5. Read Data (Z, Y, X order)
        for i in range(grid_res_z):
            for j in range(grid_res_y):
                for k in range(grid_res_x):
                    val = file.readline()
                    if val:
                        grid[k, j, i] = float(val)

        # 6. Generate Target Coordinates
        N = target_grid_res ** 3
        linear_space = torch.linspace(0, target_grid_res - 1, target_grid_res)
        xx, yy, zz = torch.meshgrid(linear_space, linear_space, linear_space, indexing='ij')
        points_indices = torch.stack((xx, yy, zz), dim=-1).reshape(-1, 3)

        # 7. Map to Physical Space
        min_x = torch.full((N, 1), bounding_box_min_x)
        min_y = torch.full((N, 1), bounding_box_min_y)
        min_z = torch.full((N, 1), bounding_box_min_z)
        bounding_min_matrix = torch.cat((min_x, min_y, min_z), 1)

        move_to_center_x = torch.full((N, 1), (max_dist - (bounding_box_max_x - bounding_box_min_x)) / 2)
        move_to_center_y = torch.full((N, 1), (max_dist - (bounding_box_max_y - bounding_box_min_y)) / 2)
        move_to_center_z = torch.full((N, 1), (max_dist - (bounding_box_max_z - bounding_box_min_z)) / 2)
        move_to_center_matrix = torch.cat((move_to_center_x, move_to_center_y, move_to_center_z), 1)

        scale = (target_voxel_size * max_dist) / (target_bounding_box_max - target_bounding_box_min)
        points = bounding_min_matrix + scale * points_indices - move_to_center_matrix

        # 8. Clamp Points
        points[:, 0] = torch.clamp(points[:, 0], bounding_box_min_x, bounding_box_max_x)
        points[:, 1] = torch.clamp(points[:, 1], bounding_box_min_y, bounding_box_max_y)
        points[:, 2] = torch.clamp(points[:, 2], bounding_box_min_z, bounding_box_max_z)

        # 9. Compute Indices
        min_tensor = torch.tensor([bounding_box_min_x, bounding_box_min_y, bounding_box_min_z])
        voxel_min_point_index = torch.floor((points - min_tensor) / voxel_size).clamp(max=grid_res_x-2)
        voxel_min_point_index[:, 1] = voxel_min_point_index[:, 1].clamp(max=grid_res_y-2)
        voxel_min_point_index[:, 2] = voxel_min_point_index[:, 2].clamp(max=grid_res_z-2)

        # 10. Interpolate (Trilinear)
        def trilinear_interpolate(grid, points, indices):
            i0, j0, k0 = indices[:, 0].long(), indices[:, 1].long(), indices[:, 2].long()
            i1, j1, k1 = i0 + 1, j0 + 1, k0 + 1
            x = (points[:, 0] - (min_tensor[0] + i0 * voxel_size)) / voxel_size
            y = (points[:, 1] - (min_tensor[1] + j0 * voxel_size)) / voxel_size
            z = (points[:, 2] - (min_tensor[2] + k0 * voxel_size)) / voxel_size
            
            c00 = grid[i0, j0, k0] * (1-x) + grid[i1, j0, k0] * x
            c01 = grid[i0, j0, k1] * (1-x) + grid[i1, j0, k1] * x
            c10 = grid[i0, j1, k0] * (1-x) + grid[i1, j1, k0] * x
            c11 = grid[i0, j1, k1] * (1-x) + grid[i1, j1, k1] * x
            
            r0 = c00 * (1-y) + c10 * y
            r1 = c01 * (1-y) + c11 * y
            return r0 * (1-z) + r1 * z

        target_values = trilinear_interpolate(grid, points, voxel_min_point_index)

        # 11. Reshape
        target_grid = target_values.reshape(target_grid_res, target_grid_res, target_grid_res)
        return target_grid
```

## Operating characteristics
- **Time Complexity:** O(N) where N is the number of voxels in the target grid, dominated by coordinate mapping and interpolation [S1, unofficial].
- **Memory Complexity:** O(N) for the target grid and intermediate tensors [S1, unofficial].
- **Strengths:** Handles non-cubic source grids; normalizes spatial extent; robust against out-of-bounds access [S1, unofficial].
- **Limitations:** Dependent on the specific file format (Z, Y, X order); requires explicit bounding box parsing [S1, unofficial].
- **When to use:** When converting pre-computed SDF files to a uniform resolution for training or rendering [S1, unofficial].
- **When not to use:** When real-time generation from meshes is required [S1, unofficial].

## Background
Originated in the SDFDiff project (Yue Jiang et al., CVPR 2020) for differentiable rendering of SDFs [S1, unofficial]. It is used to load pre-computed SDF datasets into a uniform format for neural network training [S1, unofficial].
