# Mesh to SDF via Point Cloud

Also called: Mesh to Signed Distance Field (SDF) via Point Cloud, SDF Voxelization, SurfacePointCloud SDF computation, Voxelization of SDF

## Overview
This method generates a Signed Distance Field (SDF) for a triangular mesh by first constructing a surface point cloud and then querying that cloud to determine distances and signs for arbitrary query points or a voxel grid. It solves the problem of converting explicit mesh geometry into a continuous volumetric representation suitable for neural rendering or implicit surface reconstruction. It differs from direct rasterization-based SDF generation by relying on nearest-neighbor searches in a point cloud, which allows for flexible sign determination via surface normals or depth buffers. It builds on [Naive SDF Generation (CPU)](10688-naive-sdf-generation-cpu.md) by introducing structured point cloud sampling and batched KD-tree queries.

## How it works
The method consists of three phases: mesh normalization and point cloud generation, sign determination, and SDF computation (either for arbitrary points or a voxel grid).

### Inputs and Outputs
**Inputs:**
- `mesh`: A triangular mesh object (e.g., `trimesh.Trimesh`).
- `query_points`: An $(N, 3)$ numpy array of points at which to evaluate the SDF. For voxelization, these are derived from the voxel grid.
- `surface_point_method`: String, either `'scan'` or `'sample'`. Determines how the surface point cloud is generated.
- `sign_method`: String, either `'normal'` or `'depth'`. Determines how the inside/outside status is calculated.
- `bounding_radius`: Float. Radius of the sphere around the mesh center for sampling. Default: $\sqrt{3}$ (for unit cube).
- `scan_count`: Integer. Number of camera viewpoints for `'scan'` method. Default: 100.
- `scan_resolution`: Integer. Resolution of each scan image. Default: 400.
- `sample_point_count`: Integer. Number of points to sample uniformly from the mesh surface for `'sample'` method. Default: 10,000,000.
- `normal_sample_count`: Integer. Number of nearest neighbors ($k$) for KD-tree query when `sign_method='normal'`. Default: 11.
- `voxel_resolution`: Integer. Resolution $V$ of the output voxel grid ($V \times V \times V$). Default: 64.
- `batch_size`: Integer. Maximum number of query points processed in one batch to manage memory. Default: 1,000,000.
- `pad`: Boolean. If true, pad the resulting voxel grid by 1 voxel with constant value 1 (SDF) or edge mode (gradients).
- `check_result`: Boolean. If true, validate voxel smoothness.

**Outputs:**
- For `mesh_to_sdf`: A numpy array of SDF values (and optionally gradients) corresponding to `query_points`.
- For `mesh_to_voxels`: A 3D numpy array of shape $(V, V, V)$ containing SDF values.

### Data Structures
**SurfacePointCloud:**
- `mesh`: The original mesh.
- `points`: $(M, 3)$ float array of surface points.
- `normals`: $(M, 3)$ float array of surface normals (optional, computed if `sign_method='normal'`).
- `scans`: List of `Scan` objects (used for depth-based sign).
- `kd_tree`: A `sklearn.neighbors.KDTree` built on `points`.

**Scan:**
- `depth_buffer`: 2D array of depth values from rendering.
- `normal_buffer`: 2D array of normal vectors from rendering (optional).
- `camera_transform`: $4 \times 4$ transformation matrix.
- `resolution`: Integer, width/height of the buffer.

### Steps

1.  **Input Validation:**
    - Ensure `query_points` is a numpy array of shape $(N, 3)$.
    - If `surface_point_method == 'sample'` and `sign_method == 'depth'`, override `sign_method` to `'normal'` because depth-based sign requires scan data which is not generated by uniform sampling [S1, unofficial].

2.  **Mesh Normalization:**
    - Scale the mesh to fit within a unit cube centered at the origin. This is done by `scale_to_unit_cube(mesh)` [S1, unofficial].

3.  **Generate Surface Point Cloud:**
    - If `surface_point_method == 'scan'`:
        - Generate `scan_count` camera poses distributed around the mesh.
        - For each pose, render the mesh to obtain depth and normal buffers using a custom OpenGL/pyrender wrapper that disables antialiasing [S1, unofficial].
        - Extract 3D points from the depth buffer and their corresponding normals.
    - If `surface_point_method == 'sample'`:
        - Sample `sample_point_count` points uniformly from the mesh surface.
        - If `sign_method == 'normal'`, compute vertex/face normals for these points.
    - Construct a KD-tree from the resulting points.

4.  **Compute SDF for Query Points:**
    - Split `query_points` into batches of size `batch_size`.
    - For each batch:
        - **If `sign_method == 'normal'`:**
            - Query the KD-tree for `normal_sample_count` ($k=11$) nearest neighbors.
            - Compute direction vectors: $\vec{d}_i = \mathbf{q}_i - \mathbf{p}_{\text{nearest}, i}$, where $\mathbf{q}_i$ is the query point and $\mathbf{p}_{\text{nearest}, i}$ is the nearest surface point.
            - Determine "inside" status: Calculate the dot product of $\vec{d}_i$ with the normal $\mathbf{n}_{\text{nearest}, i}$ of the nearest point. If the sum of dot products for the $k$ neighbors is less than $k \times 0.5$, the point is considered inside [S1, unofficial].
            - Compute distance: Euclidean distance to the nearest neighbor.
            - If inside, negate the distance.
            - **Gradient Calculation:**
                - Raw gradient is $\vec{d}_i$. If inside, negate gradient.
                - For points very close to the surface ($|\text{distance}| < \sqrt{0.0025^2 \times 3} \times 3$), replace the gradient with the pre-computed surface normal $\mathbf{n}_{\text{nearest}, i}$ to avoid noise [S1, unofficial].
                - Normalize the gradient.
        - **If `sign_method == 'depth'`:**
            - Query the KD-tree for 1 nearest neighbor.
            - Determine "inside" status using ray casting via the stored scans (`is_outside()` method). A point is outside if it is visible in any scan and the ray from the camera to the point intersects the surface before the point itself.
            - Compute distance to nearest neighbor.
            - If not outside (i.e., inside), negate the distance.

5.  **Voxelization (Optional):**
    - Generate grid points for a $V \times V \times V$ grid spanning $[-1, 1]$ in each dimension.
    - Compute SDF values for these grid points using the steps above.
    - Reshape results to $(V, V, V)$.
    - If `pad=True`, pad the array by 1 voxel.
    - If `check_result=True`, verify smoothness: max difference between adjacent voxels must be $< \frac{2.0}{V} \sqrt{3} \times 1.1$ [S1, unofficial].

    # Replace gradient with normal for points very close to surface
    threshold = np.sqrt(0.0025**2 * 3) * 3

    gradients[near_surface] = normals[near_surface, 0]
    
    # Normalize gradients
    norms = np.linalg.norm(gradients, axis=1, keepdims=True)

    inside = ~point_cloud.is_outside(query_points)

### Edge Cases and Pitfalls
- **Incompatible Methods:** Using `surface_point_method='sample'` with `sign_method='depth'` is invalid because the depth buffer is not generated for sampled points. The code automatically falls back to `sign_method='normal'` [S1, unofficial].
- **Near-Surface Gradient Noise:** Distances very close to zero may have noisy gradients from the KD-tree direction. These are replaced by the pre-computed surface normals [S1, unofficial].
- **Precision:** The mesh is scaled to a unit cube. Ensure the mesh is watertight for accurate sign determination, especially with the depth method.

## Operating characteristics
- **Time Complexity:** $O(N \log M)$ for $N$ query points and $M$ surface points, due to KD-tree queries.
- **Memory Complexity:** $O(M + N)$ for storing the point cloud and query results.
- **Performance:** Depends heavily on `scan_count` and `sample_point_count`. Rendering scans is GPU-accelerated but can be slow for high resolutions. KD-tree queries are CPU-bound.
- **Strengths:** Flexible sign determination; handles non-watertight meshes better than pure rasterization if normals are used; easy to implement on CPU.
- **Limitations:** Slower than GPU-based rasterization for high-resolution voxel grids; memory intensive for large point clouds; noisy gradients near surface without correction.
- **When to use:** When CPU-only implementation is required; when normal-based sign is preferred; for generating training data for neural SDFs.
- **When not to use:** For real-time rendering; for very high-resolution voxel grids where GPU rasterization is significantly faster.

## Background
The method is based on the `mesh_to_sdf` library by marian42 [S1, unofficial]. It draws inspiration from the DeepSDF paper [S1, unofficial] for sampling strategies. The approach of using point clouds and KD-trees for SDF computation is a common technique in implicit surface reconstruction and neural rendering pipelines.
