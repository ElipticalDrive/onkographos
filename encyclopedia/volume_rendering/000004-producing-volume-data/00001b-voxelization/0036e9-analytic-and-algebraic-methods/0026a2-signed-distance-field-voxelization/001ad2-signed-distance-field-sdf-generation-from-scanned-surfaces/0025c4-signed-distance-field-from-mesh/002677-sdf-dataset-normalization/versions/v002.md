# SDF Dataset Normalization
Also called: SDF Mesh Loading
## Overview
SDF Dataset Normalization prepares a triangle mesh for Signed Distance Field (SDF) generation by loading the mesh and normalizing its vertex coordinates to the range $[-1, 1]$ [S1, unofficial].
## How it works
**Inputs and Outputs:**
- Input: A path to a mesh file [S1, unofficial].
- Output: A normalized mesh object with vertices scaled and translated to $[-1, 1]$ [S1, unofficial].

**Data Structures:**
- `mesh`: A mesh object containing a vertex array `vs` of shape $(N, 3)$, where $N$ is the number of vertices [G].
- `vmin`: A 3D vector representing the component-wise minimum of the vertices along axis 0 [S1, unofficial].
- `vmax`: A 3D vector representing the component-wise maximum of the vertices along axis 0 [S1, unofficial].
- `v_center`: A 3D vector representing the centroid of the bounding box [S1, unofficial].

**Steps:**
1. Load the mesh from the specified file path using `trimesh.load` with `force='mesh'` [S1, unofficial].
2. Extract the vertex coordinates $v_s$ from `mesh.vertices` [S1, unofficial].
3. Calculate $v_{min}$ as the minimum of $v_s$ along axis 0 [S1, unofficial].
4. Calculate $v_{max}$ as the maximum of $v_s$ along axis 0 [S1, unofficial].
5. Calculate the center $v_{center}$ of the bounding box using the formula:
   $$ v_{center} = \frac{v_{min} + v_{max}}{2} $$
   [S1, unofficial].
6. Translate the vertices by subtracting $v_{center}$ to center the mesh at the origin [G].
7. Compute the bounding box extent $E = v_{max} - v_{min}$ and the maximum dimension $E_{max} = \max(E)$ [G].
8. Scale the vertices by $2 / E_{max}$ to fit within the range $[-1, 1]$ [G].

**Pseudocode:**
```python
import trimesh
import numpy as np

def normalize_sdf_mesh(mesh_path):
    # Load mesh, forcing mesh type
    mesh = trimesh.load(mesh_path, force='mesh')
    
    # Extract vertices
    vs = mesh.vertices
    
    # Calculate bounds
    vmin = np.min(vs, axis=0)
    vmax = np.max(vs, axis=0)
    
    # Calculate center
    v_center = (vmin + vmax) / 2.0
    
    # Center the mesh
    centered_vs = vs - v_center
    
    # Calculate scale to fit in [-1, 1]
    # Extent of the bounding box
    extent = vmax - vmin
    # Max dimension of the extent
    max_extent = np.max(extent)
    
    # Avoid division by zero for degenerate meshes
    if max_extent == 0:
        scale = 1.0
    else:
        # Scale factor to map max_extent to 2 (from -1 to 1)
        scale = 2.0 / max_extent
        
    # Scale vertices
    normalized_vs = centered_vs * scale
    
    # Update mesh vertices
    mesh.vertices = normalized_vs
    
    return mesh
```

**Edge Cases and Pitfalls:**
- **Degenerate Meshes:** If all vertices are identical, `max_extent` becomes zero, causing division by zero during scaling. A guard is required [G].
## Subtopics

### [Mesh Normalization](3796-mesh-normalization.md)
Mesh normalization transforms a 3D mesh's vertex coordinates so that the geometry is centered at the origin and scaled to fit within a unit cube $[-1, 1]^3$. It differs from Variance Normalization, which scales based on the distribution of points rather than bounding extent [G].

### [SDF Grid Resampling from File](4878-sdf-grid-resampling-from-file.md)
SDF Grid Resampling from File reads a raw Signed Distance Field (SDF) text file, parses its grid resolution, bounding box, and voxel size, then resamples it to a target cubic grid resolution using coordinate mapping and clamping [G]. It differs from sibling methods by handling non-cubic source grids and normalizing the spatial extent to a centered bounding box before interpolation [G].

## Operating characteristics
- **Time Complexity:** $O(N)$, where $N$ is the number of vertices, due to a single pass for min/max computation [G].
- **Memory Complexity:** $O(N)$ to store the vertex array [G].
- **Strengths:** Computationally inexpensive and standardizes input scale for downstream SDF generation [G].
- **Limitations:** Does not validate mesh topology or watertightness; highly anisotropic meshes may require axis-specific scaling adjustments [G].
## Background
The method is implemented in the NeRF-Factory/IDDR-NGP project as a dataset class for loading and normalizing mesh vertices [S1, unofficial].
