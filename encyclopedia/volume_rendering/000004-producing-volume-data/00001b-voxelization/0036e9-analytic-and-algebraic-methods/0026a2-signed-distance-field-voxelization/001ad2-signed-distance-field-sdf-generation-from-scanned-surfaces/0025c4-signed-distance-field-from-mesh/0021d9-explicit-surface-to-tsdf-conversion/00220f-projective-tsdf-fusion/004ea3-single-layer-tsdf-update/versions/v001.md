# Single Layer TSDF Update

Also called: Incremental map update, TSDF integration

## Overview
Single Layer TSDF Update is the core integration step in Projective TSDF Fusion that computes a signed distance field (SDF) sample for a specific voxel from a new depth measurement and merges it into the global map using a weighted average [S1]. It differs from static TSDF integration by supporting dynamic scale allocation within a multi-resolution octree, ensuring that distant voxels are not allocated as contiguous blocks and that the voxel size remains proportional to the camera distance [S1].

## How it works
**Inputs:**
*   $D_k$: Depth map at frame $k$ [S1].
*   $T_{cw}$: Euclidean transformation from camera frame $\{c\}$ to world frame $\{w\}$ [S1].
*   $p^l_w$: Position of the voxel in world frame at scale $l$ [S1].
*   $F^l_{k-1}$: Global map function value at scale $l$ and previous time step (or down-propagated value) [S1].
*   $y^l_{k-1}$: Accumulated weight at scale $l$ and previous time step [S1].
*   $\mu$: Truncation region parameter for TSDF [S1].
*   $y_{max}$: Maximum weight clamping value (typical: 100) [S1].
*   $\lambda$: Factor transforming z-axis distance to range distance [S1].

**Outputs:**
*   $F^l_k$: Updated global map function value at scale $l$ and time $k$ [S1].
*   $y^l_k$: Updated accumulated weight at scale $l$ and time $k$ [S1].
*   $\Delta y^l_k$: Increment of weight for down-propagation [S1].

**Data Structures:**
The method operates on voxels indexed by integer coordinates $x^l_w$ at the finest resolution possible. A scale parameter $l$ determines the factor $s = 2^{d-l}$ applied to retrieve entries in coarser grids, where $d$ is the maximum depth of the tree and $d - \log_2(8) \le l \le d$ [S1]. Voxels are cell-centred, meaning the sampling location is at the centre of its enclosing octant, allowing parent voxels to be exact linear combinations of their children [S1].

**Steps:**
1.  **Projection:** Transform the voxel world position $p^l_w$ to the camera frame using $T_{cw}$. Project the 3D camera coordinates to 2D pixel coordinates using $\pi(\cdot)$ [S1].
2.  **Depth Sampling:** Retrieve the depth value $D_k$ at the projected pixel location [S1].
3.  **Distance Calculation:** Compute the signed distance $d$ along the z-axis in the camera frame, then transform to range distance using $\lambda$ [S1].
4.  **TSDF Sample:** Compute the local TSDF sample $f^l_k$ by clamping the normalized distance to $[-1, 1]$ [S1].
5.  **Integration:** Update the global map value $F^l_k$ and accumulated weight $y^l_k$ using the weighted average formula [S1].
6.  **Weight Tracking:** Update the weight increment $\Delta y^l_k$ for subsequent down-propagation [S1].

**Formulas:**
The signed distance $d$ is computed as:
$$ d = \lambda(D_k[\pi(T_{cw} p^l_w)] - p^l_{cz}) $$
where $p^l_{cz}$ is the z-component of the voxel position expressed in the camera coordinate frame [S1].

The TSDF sample $f^l_k$ is:
$$ f^l_k = \min\left(1, \max\left(-1, \frac{d}{\mu}\right)\right) $$
Note: The source text presents this as $\min(1, \frac{d}{\mu})$ but implies standard TSDF clamping to $[-1, 1]$ via the integration step's explicit bounds [S1].

The global map function value $F^l_k$ is updated as:
$$ F^l_k = \max\left(-1, \min\left(1, \frac{F^l_{k-1} + w f^l_k}{y^l_{k-1} + w}\right)\right) $$
where $w$ is the weight of the new sample. The source formula shows $w f^l_k$ in the numerator and $+1$ in the denominator relative to the accumulated weight, implying $w=1$ for the sample weight relative to the accumulated weight increment [S1].

The accumulated weight $y^l_k$ is:
$$ y^l_k = \min(y_{max}, y^l_{k-1} + 1) $$
where $y_{max}$ is the maximum weight (typically 100) [S1].

The weight increment $\Delta y^l_k$ is:
$$ \Delta y^l_k = \Delta y^l_{k-1} + 1 $$
This value is tracked for down-propagation [S1].

**Pseudocode:**
```python
def single_layer_tsdf_update(
    depth_map: Array2D,
    T_cw: Matrix4x4,
    voxel_pos_w: Vector3,
    current_map_value: float,
    current_weight: float,
    max_weight: float = 100.0,
    truncation_mu: float = 0.05,
    lambda_factor: float = 1.0
) -> Tuple[float, float, int]:
    """
    Performs a single layer TSDF update for a voxel.
    
    Args:
        depth_map: The depth map D_k.
        T_cw: Transformation from camera to world frame.
        voxel_pos_w: Position of the voxel in world frame p^l_w.
        current_map_value: F^l_{k-1}.
        current_weight: y^l_{k-1}.
        max_weight: y_max.
        truncation_mu: Truncation region parameter mu.
        lambda_factor: Factor lambda transforming z-distance to range distance.
        
    Returns:
        (F^l_k, y^l_k, Delta_y^l_k)
    """
    # 1. Transform voxel to camera frame
    # T_cw transforms world to camera. 
    # Note: Source uses T_cw for Euclidean transformation from camera {c} to world {w} 
    # but the formula uses T_cw to project p_w to camera frame. 
    # Standard convention: if T_cw is c->w, then w->c is T_cw^-1. 
    # However, source notation T_cw is used in pi(T_cw p_w). 
    # We assume T_cw provided is the matrix that converts world coords to camera coords 
    # based on the formula context pi(T_cw p_w). If T_cw is c->w, invert it.
    # For implementation clarity, we assume input T_cw is the matrix to apply to p_w to get camera coords.
    voxel_pos_c = T_cw @ voxel_pos_w
    
    # 2. Project to pixel coordinates
    # pi() projects 3D camera coordinates to 2D pixels.
    # Assuming standard pinhole model:
    u = voxel_pos_c.x / voxel_pos_c.z
    v = voxel_pos_c.y / voxel_pos_c.z
    # Add principal point and focal length if not normalized, 
    # but source implies pi() handles the mapping to D_k indices.
    # We assume D_k is indexed by integer pixels.
    pixel_u = int(round(u))
    pixel_v = int(round(v))
    
    # 3. Retrieve depth
    # D_k[pi(...)]
    depth_z = depth_map[pixel_v, pixel_u]
    
    # 4. Compute signed distance d
    # p^l_cz is the z-component of the voxel in camera frame
    p_cz = voxel_pos_c.z
    d = lambda_factor * (depth_z - p_cz)
    
    # 5. Compute TSDF sample f^l_k
    # Clamp to [-1, 1]
    f_k = d / truncation_mu
    if f_k > 1.0:
        f_k = 1.0
    elif f_k < -1.0:
        f_k = -1.0
        
    # 6. Integrate
    # w is 1 for the new sample
    w = 1.0
    
    numerator = current_map_value + w * f_k
    denominator = current_weight + w
    
    new_map_value = numerator / denominator
    
    # Clamp map value to [-1, 1]
    if new_map_value > 1.0:
        new_map_value = 1.0
    elif new_map_value < -1.0:
        new_map_value = -1.0
        
    # 7. Update weight
    new_weight = current_weight + w
    if new_weight > max_weight:
        new_weight = max_weight
        
    # 8. Track weight increment for down propagation
    # Delta_y^l_k = Delta_y^l_{k-1} + 1
    # This function returns the increment, assuming the caller tracks the previous increment.
    # Here we return the increment value itself.
    weight_increment = 1
    
    return new_map_value, new_weight, weight_increment
```

**Edge Cases and Pitfalls:**
*   **Precision:** The method relies on accurate projection and depth retrieval. Invalid depth values (e.g., infinity or zero) must be handled before calculation [S1].
*   **Boundaries:** The TSDF sample is clamped to $[-1, 1]$ and the integrated value is clamped to $[-1, 1]$ [S1].
*   **Scale Selection:** Each block is assigned a uniform scale to simplify iteration and up-propagation, avoiding the overhead of per-voxel scale selection [S1].
*   **Dynamic Allocation:** Voxels are allocated via ray-casting around the truncation region $\pm \mu$. Distant voxels are not allocated as contiguous blocks to save memory [S1].

## Subtopics

### Multi-resolution Octree Structure
Defines the hierarchical storage where voxels at any scale are accessed via integer coordinates and a scaling factor $s=2^{d-l}$. It supports cell-centred voxels for local consistency [S1]. [Multi-resolution Octree](link-to-octree-article)

### Down-propagation
Uses the tracked weight increment $\Delta y^l_k$ to propagate information from finer to coarser scales, ensuring data consistency across the hierarchy [S1]. [Down-propagation](link-to-downprop-article)

### Up-propagation
Propagates information from coarser to finer scales, leveraging the cell-centred property where parent voxels are linear combinations of children [S1]. [Up-propagation](link-to-upprop-article)

## Operating characteristics
*   **Time Complexity:** The update is $O(1)$ per voxel per frame, assuming constant-time depth map access and projection [S1].
*   **Memory Complexity:** Memory usage is dynamic. Voxels are allocated only within the truncation region $\pm \mu$ of observed depth. The multi-resolution structure avoids allocating contiguous blocks for distant voxels, reducing memory footprint compared to uniform grids [S1].
*   **Strengths:** Efficient integration of new depth frames; dynamic scale selection keeps voxel size proportional to camera distance, maintaining resolution relevance; cell-centred voxels enable efficient multi-resolution operations [S1].
*   **Limitations:** Requires careful handling of depth map indexing and coordinate transformations; dynamic allocation adds complexity to memory management [S1].
*   **When to use:** Suitable for real-time SLAM and mapping systems where memory efficiency and adaptive resolution are critical [S1].
*   **When not to use:** Not suitable for static scenes where a fixed-resolution grid is sufficient and simpler to implement [S1].

## Background
The method is part of the Adaptive-resolution octree-based volumetric SLAM system presented by Luiten et al. in 2019 [S1]. It builds upon previous work [21] (likely referring to earlier octree-based TSDF fusion methods) by introducing dynamic scale allocation and cell-centred voxels for improved local consistency and efficient multi-resolution handling [S1].
