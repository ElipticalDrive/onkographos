# Projective TSDF Fusion

Also called: Depth-based TSDF Integration, Incremental TSDF Update, KinectFusion SDF Fusion, TSDF Fusion from Depth Images, TSDF Volumetric Fusion, Truncated Signed Distance Function (TSDF) Fusion, Truncated Signed Distance Function (TSDF) Volumetric Integration

## Overview
Projective TSDF Fusion is a method for incrementally updating the geometric representation of a scene by fusing new sensor measurements (depth images) into a voxel grid using a weighted average of truncated signed distance values and cumulative weights [S1][S2, unofficial]. It solves the problem of integrating noisy, sparse depth data from multiple viewpoints into a coherent, watertight 3D model by projecting voxel centers into the camera frame to compute signed distances [S3]. It differs from static TSDF integration by supporting dynamic scale allocation within a multi-resolution octree, ensuring that distant voxels are not allocated as contiguous blocks and that the voxel size remains proportional to the camera distance [S1]. It builds on [Explicit Surface to TSDF Conversion](2615-explicit-surface-to-tsdf-conversion.md) by deriving SDF values directly from depth projections rather than closest-surface queries on explicit meshes.

## How it works
**Inputs:**
- A global TSDF volume `vol` storing `SDF_t` structs.
- A depth image `depth` (float) and optionally a normal image `normals` (float4) or a vertex buffer from which normals are computed [S2, unofficial].
- Camera intrinsics `K` (focal lengths $f_x, f_y$, principal points $c_x, c_y$) [S3].
- Camera extrinsics `T_cw` (rotation $R$, translation $t$) transforming world coordinates to camera coordinates [S3].
- Parameters: `trunc_dist` (truncation threshold), `max_w` (maximum accumulated weight), `mincostheta` (minimum cosine of angle between normal and view direction) [S2, unofficial].

**Outputs:**
- Updated global TSDF volume `vol` where each voxel contains a fused signed distance and an accumulated weight [S2, unofficial].

**Data Structures:**
- `SDF_t`: A struct containing two fields:
  - `dist`: A signed distance value, clamped to $[-\text{trunc\_dist}, \text{trunc\_dist}]$.
  - `weight`: An accumulated weight.
  - Supports addition (`+=`) and a `LimitWeight(max_w)` method that caps the weight at `max_w` [S2, unofficial].

**Steps:**
1. **Preprocessing:** Copy raw depth to `d_tsdf_depth`. Apply a bilateral filter if `BILATERAL` flag is set, otherwise apply a medium filter if `MEDIUM` flag is set, otherwise use raw depth [S2, unofficial]. If normals are not provided, convert the filtered depth to a vertex buffer (VBO) and compute normals from it [S2, unofficial].
2. **Voxel Iteration:** For each voxel at grid coordinates $(x, y, z)$ in the volume:
   a. Compute the voxel's world position $\mathbf{P}_w$ using `vol.VoxelPositionInUnits(x, y, z)` [S2, unofficial].
   b. Transform $\mathbf{P}_w$ to the camera frame $\mathbf{P}_c = (x, y, z)^\top$ using the extrinsics: $\mathbf{P}_c = R^\top (\mathbf{P}_w - \mathbf{t})$. Note that in the implementation, the z-component is negated ($P_c.z *= -1$) to align with the depth camera convention where positive Z is into the scene [S2, unofficial][S3].
   c. Project $\mathbf{P}_c$ to 2D image coordinates $(u, v)$ using the pinhole model:
      $$u = f_x \frac{x}{z} + c_x, \quad v = f_y \frac{y}{z} + c_y$$
      where $x, y, z$ are the components of $\mathbf{P}_c$ [S3].
   d. Check if $(u, v)$ lies within the depth image bounds (with a margin of 2 pixels). If not, skip the voxel [S2, unofficial].
   e. Retrieve the observed depth $\hat{z}$ (denoted `md`) at $(u, v)$ using bilinear interpolation from the depth image [S2, unofficial][S3].
   f. Retrieve the surface normal $\mathbf{n}$ (denoted `mdn`) at $(u, v)$ using bilinear interpolation from the normal image [S2, unofficial].
   g. Calculate the cosine of the angle between the surface normal and the viewing direction:
      $$\text{costheta} = \frac{\mathbf{n} \cdot \mathbf{P}_c}{-\|\mathbf{P}_c\|}$$
      where $\|\mathbf{P}_c\|$ is the length of $\mathbf{P}_c$ [S2, unofficial].
   h. Calculate the signed distance $s(\mathbf{P}_w)$ (denoted `sd`) from the voxel to the measured surface:
      $$s(\mathbf{P}_w) = \hat{z} - z$$
      where $z$ is the depth of the voxel center in the camera frame (`vd` = $P_c.z$) [S2, unofficial][S3].
      *Note: The implementation uses a modified formula `sd = costheta * (md - vd)` to account for surface orientation [S2, unofficial].*
   i. Calculate the integration weight $w$:
      $$w = \text{costheta} \cdot \frac{1.0}{vd}$$
      where $vd = P_c.z$ [S2, unofficial].
   j. **Update Logic:**
      - If $sd \le -\text{trunc\_dist}$, the voxel is too far behind the surface; do nothing [S2, unofficial].
      - If $sd > -\text{trunc\_dist}$, check if `md` and `w` are finite and if $\text{costheta} > \text{mincostheta}$.
      - If valid, create a new SDF value:
        $$\text{sdf}_{\text{new}} = \text{SDF\_t}(\text{clamp}(sd, -\text{trunc\_dist}, \text{trunc\_dist}), w)$$
      - Add the new SDF value to the existing voxel value:
        $$\text{sdf}_{\text{new}} += \text{vol}(x, y, z)$$
      - Limit the accumulated weight:
        $$\text{sdf}_{\text{new}}.\text{LimitWeight}(\text{max\_w})$$
      - Update the voxel:
        $$\text{vol}(x, y, z) = \text{sdf}_{\text{new}}$$

**Pseudocode:**
```python
def projective_tsdf_fusion(vol, depth_img, normal_img, T_cw, K, trunc_dist, max_w, mincostheta):
    """
    vol: BoundedVolume<SDF_t>
    depth_img: Image<float>
    normal_img: Image<float4>
    T_cw: Mat<float, 3, 4> (World to Camera transform)
    K: ImageIntrinsics (fx, fy, cx, cy)
    """
    # Thread indices for 3D grid
    x, y, z = get_thread_indices()
    
    # 1. Get world position
    P_w = vol.VoxelPositionInUnits(x, y, z)
    
    # 2. Transform to camera frame
    # T_cw is 3x4 matrix [R|t]. P_c = R^T * (P_w - t)
    # In implementation: P_c = T_cw * P_w, then P_c.z *= -1
    P_c = T_cw * P_w
    P_c.z = -P_c.z
    
    # 3. Project to 2D
    u = K.fx * (P_c.x / P_c.z) + K.cx
    v = K.fy * (P_c.y / P_c.z) + K.cy
    
    # 4. Check bounds (with margin of 2 pixels)
    if not depth_img.InBounds(u, v, margin=2):
        return

    # 5. Retrieve depth and normal
    vd = P_c.z
    md = depth_img.GetBilinear(u, v)
    mdn = normal_img.GetBilinear(u, v) # Returns float4, convert to float3
    
    # 6. Calculate costheta
    # dot(mdn, P_c) / -length(P_c)
    costheta = dot(mdn, P_c) / -length(P_c)
    
    # 7. Calculate signed distance
    # Implementation uses: sd = costheta * (md - vd)
    # Standard formula: sd = md - vd
    sd = costheta * (md - vd)
    
    # 8. Calculate weight
    w = costheta * (1.0 / vd)
    
    # 9. Update voxel
    if sd <= -trunc_dist:
        return # Too far behind surface
    
    if isfinite(md) and isfinite(w) and costheta > mincostheta:
        # Clamp distance
        clamped_sd = clamp(sd, -trunc_dist, trunc_dist)
        
        # Create new SDF struct
        sdf_new = SDF_t(clamped_sd, w)
        
        # Add to existing
        sdf_new += vol(x, y, z)
        
        # Limit weight
        sdf_new.LimitWeight(max_w)
        
        # Update volume
        vol(x, y, z) = sdf_new
```

**Parameters:**
- `trunc_dist`: The distance threshold for truncating the SDF. Values beyond this distance are ignored [S2, unofficial][S4].
- `max_w`: The maximum accumulated weight for a voxel [S2, unofficial].
- `mincostheta`: The minimum cosine of the angle between the normal and view direction. Used to filter out side-facing surfaces [S2, unofficial].
- `w~(x*)`: A scalar weight assigned to the new measurement. A common choice is $w~(x*) = 1$ [S1].

**Edge Cases and Pitfalls:**
- **Precision:** Bilinear interpolation is used for depth and normal retrieval, which may introduce smoothing artifacts at boundaries [S2, unofficial].
- **Boundaries:** Voxels projected outside the image bounds (with a 2-pixel margin) are skipped, potentially leaving holes near image edges [S2, unofficial].
- **Degenerate Input:** If `vd` (depth of voxel) is zero or negative, the weight calculation involves division by zero or negative depth, which should be handled by the `isfinite` check or by ensuring valid camera poses [S2, unofficial].

## Subtopics

### [Single Layer TSDF Update](13744-single-layer-tsdf-update.md)
Single Layer TSDF Update is the core integration step in Projective TSDF Fusion that computes a signed distance field (SDF) sample for a specific voxel from a new depth measurement and merges it into the global map using a weighted average. It differs from static TSDF integration by supporting dynamic scale allocation within a multi-resolution octree, ensuring that distant voxels are not allocated as contiguous blocks and that the voxel size remains proportional to the camera distance.

### [Color Truncated SDF Fusion](20867-color-truncated-sdf-fusion.md)
Color Truncated SDF Fusion extends Projective TSDF Fusion by integrating color information into the volume alongside the signed distance field (SDF). It solves the problem of producing photorealistic, textured 3D models from RGB-D data by maintaining a separate color volume that is updated via weighted averaging based on the SDF integration weights. It differs from its parent method by adding a parallel color accumulation step and from [Single Layer TSDF Update](13744-single-layer-tsdf-update.md) by operating on the full 3D voxel grid rather than a single slice.

### [TSDF Integration with Online Variance](23473-tsdf-integration-with-online-variance.md)
This method integrates depth observations into a Truncated Signed Distance Field (TSDF) grid while maintaining a running mean distance and sample variance per voxel to guide adaptive resolution. It differs from standard TSDF fusion by explicitly tracking the variance of signed distance observations to identify geometric complexity, allowing for memory-efficient voxel merging in smooth regions and higher resolution near boundaries. It builds on [Projective TSDF Fusion](2658-projective-tsdf-fusion.md) by adding statistical tracking to the integration process.

### TSDF Sub-volume Sampling and Preprocessing
This variant involves fusing sequences of depth images into a TSDF using truncation limits $d_{min} = -0.04$ and $d_{max} = 0.1$ [S5]. Sub-volumes of size $16 \times 16 \times 16$ voxels are sampled from the TSDF at every eight voxels along each spatial dimension [S5]. The indexing order along each axis is permuted for every sample to generate five additional reflections at each location [S5]. Distance values are mapped from $[d_{min}, d_{max}]$ to $[0, 1]$ and saved [S5]. Sub-volumes where the mean sum of normalized distances is below 0.85 are discarded to avoid disproportionate empty space samples, and a small proportion of empty samples is explicitly included to balance the dataset [S5]. The input data structure is $X \in \{ \mathbb{R}^{m \times n} \mid 0 \le x_{i,j} \le 1 \}$, where $m$ is the number of samples (e.g., 200,000) and $n$ is the dimensionality of each sub-volume (4096) [S5].

## Operating characteristics
- **Time Complexity:** $O(N)$ where $N$ is the number of voxels in the volume, as each voxel is processed once per frame [S2, unofficial].
- **Memory Complexity:** Proportional to the number of voxels in the volume, with each voxel storing a signed distance and a weight [S2, unofficial].
- **Measured Performance:** The kernel uses a 3D grid of $8 \times 8 \times 8$ threads for parallel execution on GPU [S2, unofficial].
- **Strengths:** Efficiently integrates multiple views into a coherent model; handles noise through weighted averaging; supports real-time processing on GPU [S2, unofficial][S3].
- **Limitations:** Requires accurate camera poses and intrinsics; sensitive to depth noise and outliers; truncation distance must be chosen carefully to balance detail and robustness [S2, unofficial][S3].
- **When to Use:** Real-time dense reconstruction from RGB-D sensors (e.g., Kinect, RealSense) [S2, unofficial][S4].
- **When Not to Use:** When high-precision static reconstruction from explicit meshes is required without temporal integration [S2, unofficial].

## Background
Projective TSDF Fusion was introduced in the context of KinectFusion by Newcombe et al. in 2011 [S2, unofficial][S4]. It builds on the volumetric fusion approach proposed by Curless and Levoy in 1996, which iteratively fused range images into an SDF voxel volume [S4]. The method utilizes camera extrinsics and intrinsics to project depth measurements into a global voxel grid, enabling real-time dense surface mapping and tracking [S2, unofficial][S4]. It has been widely adopted in robotics and computer vision for 3D reconstruction from RGB-D data [S1, S3, S5].
