# Cube SDF Grid Construction
## Overview
Constructs a discrete Signed Distance Field (SDF) grid for a cube centered in the grid using analytical distance formulas for interior and exterior voxels [S1, unofficial]. It differs from its sibling [Sphere SDF Grid Construction](4895-sphere-sdf-grid-construction.md) by using box-based min/max operations rather than spherical symmetry and Euclidean distance from the center [G].
## How it works
**Inputs:**
- `grid_res`: Integer, the resolution of the cubic grid ($N \times N \times N$) [S1, unofficial].
- `bounding_box_min`: 3D vector, the minimum coordinates of the bounding box [S1, unofficial].
- `bounding_box_max`: 3D vector, the maximum coordinates of the bounding box [S1, unofficial].

**Outputs:**
- `grid`: 3D tensor of shape `(grid_res, grid_res, grid_res)` containing the SDF values [S1, unofficial].

**Data Structures:**
- The grid is a dense 3D array where each element corresponds to a voxel index $(i, j, k)$ [G].
- Indices are integer ranges $[0, \text{grid\_res}-1]$ [G].

**Parameters:**
- `voxel_size`: Calculated as $(\text{bounding\_box\_max} - \text{bounding\_box\_min}) / (\text{grid\_res} - 1)$ [S1, unofficial].
- `cube_center`: Index coordinate of the grid center, calculated as $(\text{grid\_res} - 1) / 2$ [S1, unofficial].
- `cube_left_bound_index`: Index coordinate of the left boundary of the cube, calculated as $(\text{grid\_res} - 1) / 4$ [S1, unofficial].
- `cube_right_bound_index`: Index coordinate of the right boundary of the cube, calculated as $3 \times (\text{grid\_res} - 1) / 4$ [S1, unofficial].

**Steps:**
1. Calculate `voxel_size`, `cube_left_bound_index`, `cube_right_bound_index`, and `cube_center` using the formulas above [S1, unofficial].
2. Initialize a 3D grid of size `grid_res` $\times$ `grid_res` $\times$ `grid_res` [G].
3. Iterate over all voxel indices $i, j, k$ from $0$ to $\text{grid\_res}-1$ [S1, unofficial].
4. Determine if the voxel $(i, j, k)$ is inside the cube. A voxel is inside if $\text{cube\_left\_bound\_index} \le i \le \text{cube\_right\_bound\_index}$, $\text{cube\_left\_bound\_index} \le j \le \text{cube\_right\_bound\_index}$, and $\text{cube\_left\_bound\_index} \le k \le \text{cube\_right\_bound\_index}$ [S1, unofficial].
5. If inside, compute the interior SDF: $\text{grid}[i,j,k] = \text{voxel\_size} \times \max(|i - \text{cube\_center}|, |j - \text{cube\_center}|, |k - \text{cube\_center}|) - 1$ [S1, unofficial].
6. If outside, compute the exterior SDF by projecting to the nearest face. Calculate the clamped distances to the cube boundaries: $\Delta x = \max(i - \text{cube\_right\_bound\_index}, \text{cube\_left\_bound\_index} - i, 0)$, $\Delta y = \max(j - \text{cube\_right\_bound\_index}, \text{cube\_left\_bound\_index} - j, 0)$, $\Delta z = \max(k - \text{cube\_right\_bound\_index}, \text{cube\_left\_bound\_index} - k, 0)$ [S1, unofficial]. Then compute $\text{grid}[i,j,k] = \sqrt{(\text{voxel\_size} \cdot \Delta x)^2 + (\text{voxel\_size} \cdot \Delta y)^2 + (\text{voxel\_size} \cdot \Delta z)^2}$ [S1, unofficial].

**Formula:**
The SDF value for a voxel at indices $(i,j,k)$ is given by:
$$ SDF(i,j,k) = \begin{cases} v \cdot \max(|i-c|, |j-c|, |k-c|) - 1 & \text{if inside} \\ \sqrt{(v \cdot \Delta x)^2 + (v \cdot \Delta y)^2 + (v \cdot \Delta z)^2} & \text{if outside} \end{cases} $$
where $v$ is `voxel_size`, $c$ is `cube_center`, and $\Delta$ terms are clamped to 0 [S1, unofficial].

**Pseudocode:**
```python
import math

def grid_construction_cube(grid_res, bounding_box_min, bounding_box_max):
    # Calculate geometric parameters
    voxel_size = (bounding_box_max - bounding_box_min) / (grid_res - 1)
    cube_left_bound_index = float(grid_res - 1) / 4.0
    cube_right_bound_index = float(grid_res - 1) / 4.0 * 3.0
    cube_center = float(grid_res - 1) / 2.0
    
    # Initialize grid
    grid = [[[0.0 for _ in range(grid_res)] for _ in range(grid_res)] for _ in range(grid_res)]
    
    for i in range(grid_res):
        for j in range(grid_res):
            for k in range(grid_res):
                # Check if inside the cube bounds
                if (i >= cube_left_bound_index and i <= cube_right_bound_index and
                    j >= cube_left_bound_index and j <= cube_right_bound_index and
                    k >= cube_left_bound_index and k <= cube_right_bound_index):
                    # Interior SDF
                    dist = max(abs(i - cube_center), abs(j - cube_center), abs(k - cube_center))
                    grid[i][j][k] = voxel_size * dist - 1.0
                else:
                    # Exterior SDF
                    dx = max(i - cube_right_bound_index, cube_left_bound_index - i, 0)
                    dy = max(j - cube_right_bound_index, cube_left_bound_index - j, 0)
                    dz = max(k - cube_right_bound_index, cube_left_bound_index - k, 0)
                    grid[i][j][k] = math.sqrt((voxel_size * dx)**2 + (voxel_size * dy)**2 + (voxel_size * dz)**2)
                    
    return grid
```

### [Sphere SDF Grid Construction](4895-sphere-sdf-grid-construction.md)
Constructs a discrete SDF grid for a sphere using analytical implicit surface equations. Choose this for spherical primitives or tori; it uses spherical symmetry rather than box-based min/max operations [G].

## Operating characteristics
- **Time Complexity:** $O(N^3)$ where $N$ is `grid_res`, as every voxel is visited once [G].
- **Memory Complexity:** $O(N^3)$ to store the dense grid [G].
- **Strengths:** Simple analytical implementation; no ray casting or point cloud processing required; deterministic results [G].
- **Limitations:** Only applicable to axis-aligned cubes centered in the grid; resolution-dependent accuracy for the distance field [G].
- **When to use:** When a simple, analytically defined cube SDF is needed for testing or as a base volume [G].
- **When not to use:** For arbitrary shapes, non-cube primitives, or when memory efficiency is critical (consider sparse representations) [G].
