# Dense Volume SDF Generation
Also called: Dense Grid SDF, meshToDistanceVolume

## Overview
Dense Volume SDF Generation constructs a dense 3D grid where every voxel contains a signed distance value, providing full data access for simulation, remeshing, or machine learning applications [S1]. It is distinguished from sparse methods by its uniform memory layout and from binary voxelization by its continuous distance field, making it the cleanest path for exact voxel-by-voxel control or direct marching cubes extraction on small to medium-sized meshes [S1].

## How it works
**Inputs and Outputs:**
- Input: A triangular mesh (vertices and faces).
- Output: A `simpleVolume` (dense 3D grid) containing signed distance values at every voxel center, and optionally a reconstructed mesh via marching cubes.

**Data Structures:**
The core data structure is `MeshToDistanceVolumeParams`, which configures the grid and distance calculation:
- `vol.voxelSize`: `Vector3f` representing the diagonal size of a voxel.
- `vol.origin`: `Vector3f` defining the grid's origin point.
- `vol.dimensions`: `Vector3i` defining the number of voxels along each axis.
- `dist.maxDistSq`: `float` squared maximum distance to calculate.
- `dist.nullOutsideMinMax`: `bool` flag to skip calculation for voxels too far from the mesh.
- `dist.signMode`: Enum for sign detection logic.
- `fwn`: Optional `FastWindingNumber` object for GPU-accelerated sign calculation.

**Steps:**
1.  **Load Mesh:** Load the input triangular mesh.
2.  **Determine Voxel Size:** Calculate a target one-dimensional voxel size using a heuristic based on mesh complexity (e.g., target 10 million voxels) [S1].
    $$ \text{oneDimVoxelSize} = \text{suggestVoxelSize}(\text{mesh}, 10^7) $$
3.  **Calculate Grid Bounds:** Compute the grid origin and dimensions based on the mesh bounding box and the calculated voxel size [S1].
    $$ (\text{origin}, \text{dimensions}) = \text{calcOriginAndDimensions}(\text{mesh.computeBoundingBox()}, \text{oneDimVoxelSize}) $$
4.  **Configure Parameters:** Initialize `MeshToDistanceVolumeParams`:
    - Set `voxelSize` to a diagonal vector of `oneDimVoxelSize`.
    - Set `origin` and `dimensions` from step 3.
    - Set `maxDistSq` to $(3 \times \text{oneDimVoxelSize})^2$ to cover 3 voxel layers of valid distance [S1].
    - Set `nullOutsideMinMax` to `True` to ignore voxels outside the max distance [S1].
    - Set `signMode` to `HoleWindingRule` for robustness against holes and self-intersections [S1].
5.  **Optional GPU Acceleration:** If CUDA is available, create a `FastWindingNumber` object from the mesh and assign it to `params.fwn` [S1].
6.  **Generate Volume:** Call `meshToDistanceVolume(mesh, params)` to produce the `simpleVolume` [S1].
7.  **Optional Reconstruction:** To extract a mesh, configure `MarchingCubesParams` with `lessInside=True` (for SDF), `origin` from step 3, and `iso` set to $0.5 \times \text{oneDimVoxelSize}$ [S1]. Call `marchingCubes(simpleVolume, mcParams)` [S1].

**Pseudocode:**
```python
import meshlib.mrmeshpy as mm
import meshlib.mrcudapy as mc

def dense_volume_sdf_generation(mesh_path, output_mesh_path):
    # 1. Load Mesh
    mesh = mm.loadMesh(mesh_path)

    # 2. Determine Voxel Size (target ~10 million voxels)
    oneDimVoxelSize = mm.suggestVoxelSize(mesh, 1e7)

    # 3. Calculate Grid Bounds
    originAndDims = mm.calcOriginAndDimensions(mesh.computeBoundingBox(), oneDimVoxelSize)

    # 4. Configure Parameters
    params = mm.MeshToDistanceVolumeParams()
    params.vol.voxelSize = mm.Vector3f.diagonal(oneDimVoxelSize)
    params.vol.origin = originAndDims.origin
    params.vol.dimensions = originAndDims.dimensions

    # 3 voxel layers with valid distance
    params.dist.maxDistSq = (3 * oneDimVoxelSize) ** 2
    params.dist.nullOutsideMinMax = True
    # Robust sign detection for holes and self-intersections
    params.dist.signMode = mm.SignDetectionMode.HoleWindingRule

    # 5. Optional GPU Acceleration
    if mc.isCudaAvailable():
        params.fwn = mc.FastWindingNumber(mesh)

    # 6. Generate Volume
    simpleVolume = mm.meshToDistanceVolume(mesh, params)

    # 7. Optional Reconstruction via Marching Cubes
    mcParams = mm.MarchingCubesParams()
    mcParams.lessInside = True  # True for SDF, False for Density
    mcParams.origin = params.vol.origin
    mcParams.iso = oneDimVoxelSize * 0.5  # Half of voxel offset

    offMesh = mm.marchingCubes(simpleVolume, mcParams)

    # Save result
    mm.saveMesh(offMesh, output_mesh_path)
```

**Edge Cases and Pitfalls:**
- **Sign Ambiguity:** For non-watertight meshes or those with self-intersections, standard parity tests fail. `HoleWindingRule` is required for robustness [S1].
- **Memory Usage:** This method is dense; memory scales with $N^3$. It is suitable only for small to medium meshes where performance and memory are not bottlenecks [S1].
- **Distance Cutoff:** `nullOutsideMinMax` prevents calculating distances for voxels far from the mesh, saving time but leaving those voxels null/undefined [S1].

## Operating characteristics
- **Time Complexity:** $O(V \cdot P)$ where $V$ is the number of voxels and $P$ is the number of primitives, unless spatial acceleration is used. The use of `FastWindingNumber` on GPU can accelerate sign calculation [S1].
- **Memory Complexity:** $O(N^3)$ for the dense grid, where $N$ is the resolution per dimension.
- **Performance:** Suitable for small to medium-sized meshes. Performance and memory use are bottlenecks for large meshes [S1].
- **Strengths:** Provides exact voxel-by-voxel control; ideal for simulation, remeshing, and exporting to ML models or image slices [S1].
- **Limitations:** High memory consumption; not suitable for very large scenes or meshes requiring sparse representation.

## Background
This method is part of the MeshLib library, providing a Python and C++ interface for mesh processing [S1]. It leverages the `meshToDistanceVolume` function to bridge triangular meshes and dense volumetric representations.
