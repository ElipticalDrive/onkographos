# Breadth-First Distance Field Expansion
Also called: BFS SDF Expansion, Voxel-based Surface Expansion

## Overview
Breadth-First Distance Field Expansion computes the Signed Distance Field (SDF) for a voxel grid by propagating distance values from known surface voxels to empty space using a queue-based breadth-first search [S1, unofficial]. It differs from [Naive Jumping Farthest Away (JFA)](7621-naive-jumping-farthest-away-jfa.md) by processing neighbors in strict distance order (Manhattan distance) rather than using a halving radius strategy, and from [Sequential Jumping Farthest Away (JFA)](7637-sequential-jumping-farthest-away-jfa.md) by utilizing a global queue rather than sequential passes [S1, unofficial].

## How it works
**Inputs:** A voxel grid containing initial distance values for surface voxels (marked as "completed") and empty voxels (marked as "uncompleted").
**Outputs:** A voxel grid where all voxels contain the correct signed distance to the nearest surface.

**Data Structures:**
1.  **Grid:** A 3D array of voxels. Each voxel stores:
    *   `distance`: float, the current SDF value.
    *   `completed`: boolean, true if the final distance is computed.
2.  **Queue:** A FIFO list of voxel coordinates `(x, y, z)` representing "completed" points whose neighbors need to be processed.

**Definitions:**
*   **Direct Neighbor:** A voxel that is axis-aligned with a completed point. The distance between a completed point and its direct neighbor is exactly the voxel edge size, denoted as $v$ [S1, unofficial].
*   **Normal:** For a neighbor point $np$ and a completed point $cp$, the normal direction is $n = |np - cp|$ [S1, unofficial].
*   **Voxel Face:** One of the four faces of a voxel connected to the completed point, defined by the two orthogonal grid directions perpendicular to the normal [S1, unofficial].

**Algorithm Steps:**

1.  **Initialization:**
    *   Iterate through the grid.
    *   For every voxel with an initial distance value, mark it as `completed` and add its coordinates to the `Queue` [S1, unofficial].

2.  **Expansion Loop:**
    *   While `Queue` is not empty:
        1.  Dequeue a completed point $cp$ [S1, unofficial].
        2.  Identify all uncompleted direct neighbors of $cp$. A direct neighbor is any voxel sharing a face with $cp$ along the X, Y, or Z axis [S1, unofficial].
        3.  For each uncompleted neighbor $np$:
            a.  Calculate the normal vector $n = |np - cp|$ [S1, unofficial].
            b.  Identify the four voxel faces connected to $cp$ that are relevant for determining the distance to the surface relative to $np$. These faces are aligned with the grid and orthogonal to the axes not aligned with $n$ [S1, unofficial].
            c.  For each of the four faces, calculate the smallest distance to the surface. This distance is composed of:
                *   $d_1$: The geometric distance to the voxel face itself. This is calculated using trigonometry. The distance to a point on the face is either the voxel edge size $v$, the face diagonal $v\sqrt{2}$, or the cube diagonal $v\sqrt{3}$, depending on the specific point on the face being considered [S1, unofficial].
                *   $d_2$: The signed distance field value inside the voxel (the distance from the point to the surface within the completed voxel's context) [S1, unofficial].
            d.  To find the minimum distance over the face:
                i.  Calculate the distance $d$ to the surface over the axis-aligned edge [S1, unofficial].
                ii. Calculate the difference in distance for both $d_1$ and $d_2$ for all four corners of the voxel face by subtracting $d$ from every value [S1, unofficial].
                iii. Assume the smallest distance is over the axis-aligned edge to the completed point. Calculate the smallest distance by computing $d_2 - d_1$ for all four corners [S1, unofficial].
                iv. Select the corner with the smallest distance that is also $\le 0$ [S1, unofficial].
            e.  Assign the calculated minimum distance to $np$ and mark $np$ as `completed`.
            f.  Enqueue $np$ into the `Queue` [S1, unofficial].

3.  **Termination:**
    *   The algorithm terminates when the `Queue` is empty, meaning all reachable voxels have been completed [S1, unofficial].

**Parameters:**
*   $x$: The edge length of a square area in terms of voxel edges. For example, $x=2$ implies a $2 \times 2$ voxel area. This parameter is used to define the sampling neighborhood for correctness checks [S1, unofficial].

**Pitfalls and Edge Cases:**
*   **Voxel Size Consistency:** Expanded values are correct only if the distance to the surface inside a completed voxel matches the voxel size. If the voxel size does not match the distance values, comparisons are invalid [S1, unofficial].
*   **Global Correctness:** To guarantee global correctness, for any expanded point, there must be no other surface closer to this point than the one found via the BFS path [S1, unofficial].
*   **Sampling Neighborhood:** To ensure neighboring distances are calculated correctly, the algorithm must sample at least $x$ neighboring voxels in every axis around the area of interest [S1, unofficial].

## Operating characteristics
*   **Time Complexity:** The maximum number of iterations is no longer than the Manhattan distance in terms of $x$ [S1, unofficial]. In the worst case, this is proportional to the grid dimensions.
*   **Memory Complexity:** Requires storage for the grid and a queue. The queue size can grow up to the surface area of the expanding front.
*   **Strengths:** Guarantees that neighbors are processed in order of increasing Manhattan distance from the source, which can simplify correctness proofs for local distance calculations [S1, unofficial].
*   **Limitations:** Requires careful handling of the geometric distance calculations ($d_1, d_2$) for each face. The requirement to sample $x$ neighboring voxels for correctness can increase computational overhead if $x$ is large [S1, unofficial].
*   **When to use:** When a strict breadth-first propagation order is desired for local distance accuracy, and the grid size is manageable.
*   **When not to use:** For very large grids where the queue memory overhead becomes prohibitive, or when approximate distances are acceptable and faster methods like [Naive Jumping Farthest Away (JFA)](7621-naive-jumping-farthest-away-jfa.md) are preferred.
