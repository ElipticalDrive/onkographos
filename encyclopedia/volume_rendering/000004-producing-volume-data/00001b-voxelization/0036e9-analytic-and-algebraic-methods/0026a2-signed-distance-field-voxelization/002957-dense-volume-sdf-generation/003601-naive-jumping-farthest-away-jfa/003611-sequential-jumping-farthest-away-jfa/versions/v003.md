# Sequential Jumping Farthest Away (JFA)

Also called: Sequential JFA (Jumping Farthest Away), SequentialJFA

## Overview
Sequential Jumping Farthest Away (JFA) is a CPU-based algorithm for computing the Signed Distance Field (SDF) and the 3D position of the closest surface point for a voxel grid. It solves the problem of propagating distance information from known surface voxels into empty space by using a multi-scale search strategy. It differs from its parent [Naive Jumping Farthest Away (JFA)](7621-naive-jumping-farthest-away-jfa.md) by explicitly defining the sequential execution order and data layout for CPU implementation, and from [Breadth-First Distance Field Expansion](9703-breadth-first-distance-field-expansion.md) by using a geometric stride-based search rather than a queue-based expansion.

## How it works
The algorithm initializes boundary voxels with zero distance and infinite distance for interior voxels, then iteratively refines the SDF by searching neighbors at decreasing strides $k$.

**Inputs and Outputs:**
- Input: A voxel grid `gridV` containing boolean occupancy (`Voxel`) and origin/size metadata.
- Output: Two grids of the same dimensions as `gridV`:
  - `sdf`: Float grid storing the signed distance value.
  - `positions`: 3D vector grid storing the world position of the closest surface point.

**Data Structures:**
- `gridV`: Contains `VoxelsPerSide()` (assumed cubic grid side length $N$), `VoxelSize()`, and origin offsets `OriginX()`, `OriginY()`, `OriginZ()`.
- `sdf`: 3D array `float[N][N][N]`.
- `positions`: 3D array of 3D vectors `vec3[N][N][N]`.
- `sdfApp`, `positionsApp`: Temporary buffers of the same layout, used to store updates for the current stride $k$ to avoid race conditions in sequential updates (though strictly sequential, the source uses a double-buffering pattern per stride).

**Parameters:**
- $k$: The search stride. Starts at $N/2$ and halves until $k=1$.

**Steps:**

1. **Initialization**:
   Iterate over all voxel coordinates $(voxelZ, voxelY, voxelX)$ from $0$ to $N-1$.
   - Let $gridV$ be the input grid.
   - If `!gridV.Voxel(voxelX, voxelY, voxelZ)` (voxel is empty), skip.
   - Calculate world position:
     $$ pos = \begin{bmatrix} gridV.OriginX() + voxelX \cdot gridV.VoxelSize() \\ gridV.OriginY() + voxelY \cdot gridV.VoxelSize() \\ gridV.OriginZ() + voxelZ \cdot gridV.VoxelSize() \end{bmatrix} $$
   - Check all 26 neighbors $(nx, ny, nz)$ where $nx, ny, nz \in \{-1, 0, 1\}$ excluding $(0,0,0)$.
   - If any neighbor is out of bounds or `!gridV.Voxel(nx, ny, nz)`, the voxel is a boundary.
     - Set `sdf(voxelX, voxelY, voxelZ) = 0.0f`.
     - Set `positions(voxelX, voxelY, voxelZ) = pos`.
   - Else (voxel is interior, all neighbors occupied):
     - Set `sdf(voxelX, voxelY, voxelZ) = INFINITY`.

2. **Processing Loop**:
   - Initialize `sdfApp` and `positionsApp` as copies of `sdf` and `positions`.
   - Let $N = gridV.VoxelsPerSide()$.
   - Iterate $k$ from $N/2$ down to $1$, halving $k$ each iteration ($k = \lfloor k/2 \rfloor$).

3. **Inner Loop (for each $k$)**:
   - For each voxel $(voxelZ, voxelY, voxelX)$:
     - Calculate `voxelPos` using the same formula as in Initialization.
     - Initialize `bestDistance = sdf(voxelX, voxelY, voxelZ)`.
     - Initialize `findNewBest = false`.
     - Iterate neighbor directions $(x, y, z)$ where $x, y, z \in \{-1, 0, 1\}$ excluding $(0,0,0)$.
     - Calculate neighbor indices:
       $$ nx = voxelX + (x \cdot k) $$
       $$ ny = voxelY + (y \cdot k) $$
       $$ nz = voxelZ + (z \cdot k) $$
     - If $(nx, ny, nz)$ is out of bounds, continue.
     - Get `seed = sdf(nx, ny, nz)`.
     - If `fabs(seed) < INFINITY`:
       - Get `seedPos = positions(nx, ny, nz)`.
       - Calculate `distance = CalculateDistance(voxelPos, seedPos)`.
       - If `distance < fabs(bestDistance)`:
         - Set `findNewBest = true`.
         - Set `bestDistance = copysignf(distance, bestDistance)`.
         - Set `bestPosition = seedPos`.
     - If `findNewBest` is true:
       - Set `sdfApp(voxelX, voxelY, voxelZ) = bestDistance`.
       - Set `positionsApp(voxelX, voxelY, voxelZ) = bestPosition`.

4. **Update**:
   - After processing all voxels for the current $k$, update:
     - `sdf = sdfApp`
     - `positions = positionsApp`

**Pseudocode:**

```python
import math

def sequential_jfa(grid_v):
    N = grid_v.voxels_per_side()
    voxel_size = grid_v.voxel_size()
    origin_x = grid_v.origin_x()
    origin_y = grid_v.origin_y()
    origin_z = grid_v.origin_z()
    
    # Initialize output grids
    sdf = [[[[float('inf')] for _ in range(N)] for _ in range(N)] for _ in range(N)]
    positions = [[[[None] for _ in range(N)] for _ in range(N)] for _ in range(N)]
    
    # Step 1: Initialization
    for z in range(N):
        for y in range(N):
            for x in range(N):
                if not grid_v.voxel(x, y, z):
                    continue
                
                pos = [
                    origin_x + x * voxel_size,
                    origin_y + y * voxel_size,
                    origin_z + z * voxel_size
                ]
                
                is_boundary = False
                for dx in [-1, 0, 1]:
                    for dy in [-1, 0, 1]:
                        for dz in [-1, 0, 1]:
                            if dx == 0 and dy == 0 and dz == 0:
                                continue
                            nx, ny, nz = x + dx, y + dy, z + dz
                            if not (0 <= nx < N and 0 <= ny < N and 0 <= nz < N):
                                is_boundary = True
                                break
                            if not grid_v.voxel(nx, ny, nz):
                                is_boundary = True
                                break
                        if is_boundary: break
                    if is_boundary: break
                
                if is_boundary:
                    sdf[z][y][x] = 0.0
                    positions[z][y][x] = pos
                else:
                    sdf[z][y][x] = float('inf')
    
    # Step 2: Processing Loop
    k = N // 2
    while k >= 1:
        sdf_app = [[row[:] for row in grid] for grid in sdf]
        positions_app = [[row[:] for row in grid] for grid in positions]
        
        # Step 3: Inner Loop
        for z in range(N):
            for y in range(N):
                for x in range(N):
                    voxel_pos = [
                        origin_x + x * voxel_size,
                        origin_y + y * voxel_size,
                        origin_z + z * voxel_size
                    ]
                    
                    best_distance = sdf[z][y][x]
                    find_new_best = False
                    best_position = positions[z][y][x]
                    
                    for dx in [-1, 0, 1]:
                        for dy in [-1, 0, 1]:
                            for dz in [-1, 0, 1]:
                                if dx == 0 and dy == 0 and dz == 0:
                                    continue
                                
                                nx = x + dx * k
                                ny = y + dy * k
                                nz = z + dz * k
                                
                                if not (0 <= nx < N and 0 <= ny < N and 0 <= nz < N):
                                    continue
                                
                                seed = sdf[nz][ny][nx]
                                if abs(seed) < float('inf'):
                                    seed_pos = positions[nz][ny][nx]
                                    distance = math.sqrt(
                                        (voxel_pos[0] - seed_pos[0])**2 +
                                        (voxel_pos[1] - seed_pos[1])**2 +
                                        (voxel_pos[2] - seed_pos[2])**2
                                    )
                                    
                                    if distance < abs(best_distance):
                                        find_new_best = True
                                        best_distance = math.copysign(distance, best_distance)
                                        best_position = seed_pos
                    
                    if find_new_best:
                        sdf_app[z][y][x] = best_distance
                        positions_app[z][y][x] = best_position
        
        # Step 4: Update
        sdf = sdf_app
        positions = positions_app
        
        k = k // 2
    
    return sdf, positions
```

**Edge Cases and Pitfalls:**
- **Interior Voxels**: Voxels with no empty neighbors are initialized to `INFINITY`. If the grid is fully occupied, no distance propagation occurs.
- **Boundary Conditions**: Neighbors outside the grid bounds are treated as empty, correctly identifying surface voxels.
- **Precision**: `copysignf` is used to preserve the sign of the distance while updating the magnitude. Floating-point precision may affect the exact distance value for large grids.

## Subtopics

### [Parallel Jumping Farthest Away (JFA)](7860-parallel-jumping-farthest-away-jfa.md)
Parallel Jumping Farthest Away (JFA) is an OpenMP-based parallelization of the Sequential JFA algorithm for computing Signed Distance Fields (SDFs) on voxel grids. It accelerates the distance propagation phase by parallelizing the inner triple loop over voxel coordinates, while keeping the outer iteration over the jump distance scale $k$ sequential. It differs from the Compute Shader variant by running on CPU multi-core architectures rather than GPU, and from the Sequential JFA by utilizing thread-level parallelism for the spatial updates.

## Operating characteristics
- **Time Complexity**: The algorithm runs in $O(N^3 \log N)$ time, where $N$ is the grid side length. The outer loop runs $\log N$ times (halving $k$), and the inner loops iterate over all $N^3$ voxels and 26 neighbors.
- **Memory Complexity**: $O(N^3)$ for storing the SDF and position grids, plus temporary buffers for each stride iteration.
- **Performance**: As a sequential CPU algorithm, it is slower than GPU-based variants like [Naive Jumping Farthest Away (JFA)](7621-naive-jumping-farthest-away-jfa.md) for large grids. It is suitable for small to medium-sized grids or CPU-only environments.
- **Strengths**: Simple implementation, no parallel synchronization overhead, deterministic results.
- **Limitations**: Slow for large grids due to sequential execution.
- **When to use**: When GPU resources are unavailable or for small-scale voxelization tasks.
- **When not to use**: For large-scale volume rendering or real-time applications requiring fast SDF generation.

## Background
Sequential Jumping Farthest Away (JFA) is derived from the broader class of Jumping Farthest Away algorithms for SDF generation. It is implemented in the `bigmat18/cuda-mesh-voxelization` repository [S1, unofficial], which provides a reference implementation for CPU-based voxelization operations. The algorithm is part of a family of methods that include Naive JFA, Parallel JFA, and Tiled JFA, each optimizing the core propagation logic for different hardware architectures.
