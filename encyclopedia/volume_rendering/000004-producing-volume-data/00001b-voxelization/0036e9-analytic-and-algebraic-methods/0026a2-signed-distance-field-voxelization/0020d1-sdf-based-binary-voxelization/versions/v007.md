# SDF-based Binary Voxelization

Also called: Binary Voxelization, Level Set Voxelization, SDF Voxelization

## Overview
SDF-based Binary Voxelization converts a continuous parametric object or a pre-computed Signed Distance Field (SDF) into a discrete 3D grid where each voxel is classified strictly as inside or outside the object [S2, unofficial]. It solves the problem of creating a topological binary representation from a continuous scalar field, serving as a foundational step for binary volume rendering and mesh extraction [G]. Unlike [Dense Volume SDF Generation](4499-dense-volume-sdf-generation.md) which preserves distance magnitudes, this method discards geometric precision in favor of binary membership, and unlike [Signed Distance Field (SDF) Generation from Scanned Surfaces](854-signed-distance-field-sdf-generation.md) which generates the SDF from raw data, this method assumes the SDF or implicit definition is already available [G].

## How it works
**Inputs and Outputs:**
*   **Input:** A continuous parametric object $Q_c$ defined by an implicit function $f(\mathbf{x})$, or a pre-existing dense Signed Distance Field grid (e.g., `MeshSignedDistanceGrid`) [S2, unofficial].
*   **Output:** A binary voxel grid (Bitmap) $D_p$ where each cell $v_{ijk}$ is a boolean value (true/inside or false/outside) [S2, unofficial].

**Data Structures:**
*   **Binary Grid:** A 3D array of boolean values. Dimensions match the input SDF grid [S2, unofficial].
*   **SDF Grid:** A 3D array of floating-point values representing signed Euclidean distance [S2, unofficial].

**Steps:**
1.  **Initialize Grid:** Create a binary voxel grid with dimensions identical to the input SDF grid [S2, unofficial].
2.  **Iterate:** Loop through every index $(i, j, k)$ in the grid [S2, unofficial].
3.  **Evaluate:** Retrieve the signed distance value $d$ at the current index from the SDF [S2, unofficial]. If the input is a parametric object, compute $d = f(\mathbf{x}_{center})$ where $\mathbf{x}_{center}$ is the center of the voxel [G].
4.  **Classify:** Apply the thresholding rule:
    $$
    v_{ijk} = \begin{cases} 
    \text{true} & \text{if } d < 0 \\
    \text{false} & \text{if } d \ge 0 
    \end{cases}
    $$
    *   $d < 0$ indicates the point is inside the object [S2, unofficial].
    *   $d \ge 0$ indicates the point is outside or on the surface [S2, unofficial].
5.  **Store:** Set the voxel value in the binary grid [S2, unofficial].

**Pseudocode:**
```python
def sdf_to_binary_voxelization(sdf_grid, dimensions):
    """
    Converts a dense Signed Distance Field grid into a binary voxel grid.
    
    Args:
        sdf_grid: 3D array of floats, shape (D, H, W).
        dimensions: Tuple (D, H, W) defining the output grid size.
        
    Returns:
        binary_grid: 3D array of booleans, shape (D, H, W).
    """
    D, H, W = dimensions
    # Initialize output grid with False
    binary_grid = [[[False for _ in range(W)] for _ in range(H)] for _ in range(D)]

    # Iterate over all indices
    for i in range(D):
        for j in range(H):
            for k in range(W):
                # Retrieve signed distance value
                distance = sdf_grid[i][j][k]
                
                # Classify based on sign
                if distance < 0:
                    binary_grid[i][j][k] = True
                else:
                    binary_grid[i][j][k] = False
                    
    return binary_grid
```

**Parameters:**
*   **Threshold:** 0.0 (standard for signed distance fields) [S2, unofficial].
*   **Inequality:** Strictly less than ($<$) for inside [S2, unofficial].

**Edge Cases and Pitfalls:**
*   **Surface Precision:** Voxels intersected by the surface are classified based on the sample point (typically the center) [G]. This can lead to "stair-stepping" artifacts or topological inconsistencies if the surface passes through the center of a voxel but the geometry is complex [G].
*   **Subdivision Cost:** Early techniques used recursive subdivision for spatial enumeration, but these are computationally expensive and inappropriate for medium or high-resolution grids [S1, unofficial]. Direct evaluation is preferred [S1, unofficial].
*   **Topological Requirements:** The goal is to generate an N-separating, N-minimal, and covering set, where N is application-dependent [S1, unofficial].

## Background
Binary voxelization is one of the earliest techniques for the digitization of solids, employing spatial enumeration via point or cell classification [S1, unofficial]. The paradigm follows 2D scan-conversion algorithms, emphasizing incremental, accurate, and integer-based arithmetic where possible [S1, unofficial]. Pioneering work included algorithms for 3D lines, circles, and quadric objects using techniques like forward differencing and weaving [S1, unofficial]. Modern implementations often leverage pre-computed SDFs to simplify the classification step to a simple sign check [S2, unofficial].
