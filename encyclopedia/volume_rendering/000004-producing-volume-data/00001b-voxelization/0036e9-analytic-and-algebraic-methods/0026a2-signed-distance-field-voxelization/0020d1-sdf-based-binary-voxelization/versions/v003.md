# SDF-based Binary Voxelization

Also called: Level Set Voxelization, SDF Voxelization

## Overview
SDF-based Binary Voxelization converts a continuous signed distance field into a discrete binary volume by thresholding at zero [S1, unofficial]. It differs from sibling methods that generate SDFs from geometry or scanned data by operating strictly as a post-processing discretization step on an existing distance field [S1, unofficial].

## How it works
**Inputs:** A 3D grid of signed distance values (e.g., `MeshSignedDistanceGrid`) [S1, unofficial].
**Outputs:** A 3D boolean bitmap (`Bitmap3`) where each voxel indicates occupancy [S1, unofficial].

**Data Structures:**
*   `MeshSignedDistanceGrid`: A 3D array storing `float` values representing the signed distance to the surface at each grid point [S1, unofficial].
*   `Bitmap3`: A 3D array of `bool` values with dimensions identical to the input SDF grid [S1, unofficial].

**Steps:**
1. Initialize a `Bitmap3` object with dimensions identical to the input `MeshSignedDistanceGrid` [S1, unofficial].
2. Iterate through every index $(i, j, k)$ in the `Bitmap3` grid [S1, unofficial].
3. Retrieve the signed distance value $d$ from the SDF at the corresponding index: $d = \text{SDF}[i, j, k]$ [S1, unofficial].
4. Evaluate the occupancy condition: if $d < 0$, set `Bitmap3[i, j, k] = true`; otherwise ($d \ge 0$), set `Bitmap3[i, j, k] = false` [S1, unofficial].

**Pseudocode:**
```python
class Grid:
    def __init__(self, width, height, depth, default_value=None):
        self.width = width
        self.height = height
        self.depth = depth
        self.data = [[[default_value for _ in range(depth)] for _ in range(height)] for _ in range(width)]
    def get(self, x, y, z):
        return self.data[x][y][z]
    def set(self, x, y, z, value):
        self.data[x][y][z] = value

def sdf_to_binary_voxelization(sdf_grid: Grid) -> Grid:
    binary_grid = Grid(sdf_grid.width, sdf_grid.height, sdf_grid.depth, default_value=False)
    for x in range(sdf_grid.width):
        for y in range(sdf_grid.height):
            for z in range(sdf_grid.depth):
                distance = sdf_grid.get(x, y, z)
                binary_grid.set(x, y, z, distance < 0)
    return binary_grid
```

**Parameters:** Not given in the sources [S1, unofficial].

**Edge Cases and Pitfalls:**
*   **Zero Distance:** Points exactly on the surface ($d=0$) are classified as outside (`false`) [S1, unofficial].
*   **Boundary Conditions:** The iteration is strictly bounded by the input grid dimensions, so no extrapolation or boundary checks are required [S1, unofficial].

## Operating characteristics
*   **Time Complexity:** $O(N)$, where $N$ is the total voxel count, due to a single pass over the grid [S1, unofficial].
*   **Memory Complexity:** $O(N)$ for the input SDF and $O(N)$ for the output bitmap [S1, unofficial].
*   **Performance:** Near-instantaneous for typical resolutions, limited only by memory bandwidth for array traversal [S1, unofficial].
*   **Strengths:** Deterministic, trivial to implement, and preserves the exact input resolution [S1, unofficial].

## Background
This method serves as a standard discretization step in pipelines that generate voxel meshes from implicit fields [S1, unofficial]. It is explicitly demonstrated in the context of generating "Minecraft-style" surface meshes from signed distance fields [S1, unofficial]. The technique is documented by gradientspace in their tutorial on 3D bitmaps and mesh winding numbers [S1, unofficial].
