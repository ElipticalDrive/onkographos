# Surface-Aware Discretization

Also called: Mesh-intersection voxelization, Surface-aware voxelization

## Overview
Surface-Aware Discretization is a voxelization method that computes the effective volume of each voxel by estimating the intersection between the voxel grid and a target mesh, rather than assuming binary occupancy. It solves the problem of resolution-related artifacts in additive manufacturing by providing a more accurate representation of the object's geometry within the discrete volume. It differs from [Signed Distance Field Voxelization](3849-signed-distance-field-voxelization.md) and [Analytic Voxelization](10493-analytic-voxelization.md) by using Monte Carlo ray tracing to estimate the fractional volume occupied by the mesh, making it suitable for differentiable rendering pipelines where gradient-based optimization of printing patterns is required.

## How it works
This method uses a Monte Carlo integration approach to estimate the volume of a voxel occupied by a 3D mesh. It treats the voxel as a sampling domain and shoots rays to determine the probability of intersection with the target surface.

**Inputs:**
- A target triangular mesh (implicitly defined by a scene graph).
- A 3D grid resolution $(R_x, R_y, R_z)$.
- The voxel size (derived from the grid and the bounding box of the mesh).
- A sample count $N$ (default $2^{14}$).

**Outputs:**
- A scalar field (tensor) of shape $(R_x, R_y, R_z)$ where each element represents the estimated volume of the voxel occupied by the mesh.

**Data Structures:**
- `voxel`: A 3D tensor of `Point3f` coordinates representing the center of each voxel.
- `count_in`, `count_out`: Integer tensors of size $R_x R_y R_z$ storing the number of rays hitting the mesh and missing it, respectively.
- `self.volumes`: A tensor of shape $(R_x, R_y, R_z)$ storing the final computed volumes.

**Steps:**
1.  **Initialization**:
    -   Check if the discretization is surface-aware. If not, return the full voxel volume for all cells.
    -   If volumes are already computed, return them.
    -   Identify the target shape in the scene by ID (e.g., 'target'). Raise an error if not found.
    -   Create a `target_scene` containing only the target shape to optimize intersection queries.
    -   Initialize `self.volumes` as a tensor of ones with shape `self.m_film.data.shape`.
    -   Generate voxel coordinates using a meshgrid:
        $$ \text{voxel}_i = (x_i, y_i, z_i) $$
        where $x_i, y_i, z_i$ are indices along each axis.
    -   Initialize counters `count_in` and `count_out` to zeros with size $R_x R_y R_z$.
    -   Initialize a random sampler with a fixed seed (e.g., 0) and total samples $N \times R_x R_y R_z$.

2.  **Monte Carlo Sampling Loop**:
    -   For each sample $k$ from $0$ to $N-1$:
        -   Generate a random offset $(u, v, w)$ uniformly in $[0, 1]^3$.
        -   Compute the ray origin $P$ inside the voxel:
            $$ P = B_{min} + \text{voxel\_size} \cdot (\text{voxel} + (u, v, w)) $$
            where $B_{min}$ is the minimum corner of the mesh bounding box.
        -   Generate a random direction $D$ uniformly distributed over the sphere:
            $$ D = \text{warp\_square\_to\_uniform\_sphere}(s_1, s_2) $$
        -   Construct a ray $R = (P, D)$.
        -   Check if $P$ is inside the mesh bounding box. If not, skip intersection test.
        -   Perform ray-mesh intersection using the `target_scene`.
        -   Determine if the ray hits the target mesh:
            $$ \text{hit} = (\text{si.is\_valid}()) \land (\text{si.shape} == \text{target\_shape}) \land (\text{dot}(D, \text{si.normal}) > 0) $$
            The normal check ensures the ray enters the mesh (or hits the front face, depending on convention; here it checks for positive dot product with normal, implying specific orientation handling).
        -   If `hit` is true, increment `count_in` for the corresponding voxel index.
        -   If `hit` is false (and ray was within bbox), increment `count_out`.

3.  **Volume Calculation**:
    -   After all samples are processed, compute the volume for each voxel $i$:
        $$ V_i = \frac{\text{count\_in}_i}{N} \cdot V_{voxel} $$
        where $V_{voxel} = \text{voxel\_size}_x \cdot \text{voxel\_size}_y \cdot \text{voxel\_size}_z$.
    -   Store $V_i$ in `self.volumes`.

**Pseudocode:**
```python
import drjit as dr
import mitsuba as mi

def surface_aware_discretization(target_scene, target_shape_id, resolution, sample_count=2**14):
    # 1. Initialization
    if not is_surface_aware():
        return dr.prod(voxel_size) * dr.ones(resolution)
    
    if volumes_computed:
        return self.volumes

    target_shape = target_scene.shape(target_shape_id)
    if target_shape is None:
        raise ValueError("Target shape not found")

    # Initialize volumes tensor
    self.volumes = dr.ones(mi.Float, resolution)
    
    # Generate voxel centers
    xx = dr.arange(mi.Float, resolution.x)
    yy = dr.arange(mi.Float, resolution.y)
    zz = dr.arange(mi.Float, resolution.z)
    z_idx, y_idx, x_idx = dr.meshgrid(zz, yy, xx, indexing='ij')
    voxel_centers = mi.Point3f(x_idx, y_idx, z_idx)
    
    # Initialize counters
    count_in = dr.zeros(mi.UInt32, dr.prod(resolution))
    count_out = dr.zeros(mi.UInt32, dr.prod(resolution))
    
    # Setup sampler
    sampler = mi.load_array_sampler() # Assuming a sampler creation utility
    sampler.seed(0, dr.prod(resolution) * sample_count)
    
    bbox = target_scene.bounding_box()
    voxel_vol = dr.prod(voxel_size)
    
    active = dr.ones(mi.Bool, dr.prod(resolution))
    
    # 2. Sampling Loop
    for d in range(sample_count):
        # Generate random offset within voxel
        u = sampler.next_1d()
        v = sampler.next_1d()
        w = sampler.next_1d()
        offset = mi.Point3f(u, v, w)
        
        # Compute ray origin
        pos = bbox.min + voxel_size * (voxel_centers + offset)
        
        # Generate random direction
        s1 = sampler.next_2d()
        ray_dir = mi.warp.square_to_uniform_sphere(s1)
        
        ray = mi.Ray3f(pos, ray_dir)
        
        # Check if inside bounding box
        in_bbox = dr.all((ray.o > bbox.min) & (ray.o < bbox.max))
        
        # Perform intersection
        si = target_scene.ray_intersect(ray, active=active & in_bbox)
        
        # Determine hit
        is_valid = si.is_valid()
        is_target = si.shape == target_shape
        front_face = dr.dot(ray.d, si.n) > 0
        
        hit = is_valid & is_target & front_face
        
        # Update counters
        # Note: In a real implementation, scatter_add is used for parallel updates
        # Here we simulate the logic for clarity
        idx = dr.flatten_index(...) # Get linear index of voxel
        count_in = dr.scatter_add(count_in, idx, hit.astype(mi.UInt32))
        count_out = dr.scatter_add(count_out, idx, (~hit).astype(mi.UInt32))
        
        active &= (d < sample_count)
        
    # 3. Final Volume Calculation
    # V_i = (count_in / sample_count) * voxel_vol
    # Using drjit scatter/gather for final assignment
    for i in range(dr.prod(resolution)):
        if count_in[i] > 0:
            self.volumes.flat()[i] = (count_in[i] / sample_count) * voxel_vol
        else:
            self.volumes.flat()[i] = 0.0
            
    return self.volumes
```

**Parameters:**
- `sample_count`: Number of Monte Carlo samples per voxel. Default is $2^{14}$ (16384) [S1, unofficial].

**Edge Cases and Pitfalls:**
-   **Precision**: Monte Carlo estimation introduces noise. Higher sample counts reduce variance but increase computation time.
-   **Boundaries**: Rays originating outside the mesh bounding box are skipped to save computation.
-   **Orientation**: The hit condition checks `dot(ray.d, si.n) > 0`. This assumes a specific mesh orientation convention. If the mesh normals are inconsistent, the volume estimation may be incorrect [S1, unofficial].
-   **Degenerate Input**: If the target shape is not found, the method raises a `ValueError` [S1, unofficial].

## Subtopics

### Signed Distance Field Voxelization
Computes the exact signed distance from each voxel center to the mesh surface. Choose when smooth gradients and exact distance metrics are needed, rather than volume fractions. [Link](3849-signed-distance-field-voxelization.md)

### Analytic Voxelization
Uses exact geometric formulas to compute the intersection volume for simple primitives (e.g., spheres, boxes). Choose when the geometry is composed of simple primitives and exact analytical results are preferred over Monte Carlo estimates. [Link](10493-analytic-voxelization.md)

## Operating characteristics
-   **Time Complexity**: $O(N \cdot R_x R_y R_z)$, where $N$ is the sample count and $R_x R_y R_z$ is the number of voxels. Each voxel requires $N$ ray-mesh intersection tests.
-   **Memory Complexity**: $O(R_x R_y R_z)$ to store the volume tensor and counters.
-   **Performance**: The method is computationally expensive due to the large number of ray intersections. However, it is parallelizable across voxels and samples. In the Dr. TVAM implementation, it is optimized using differentiable rendering backends (Mitsuba) [S1, unofficial].
-   **Strengths**: Accurately models the fractional volume of complex meshes, reducing artifacts in additive manufacturing. Integrates seamlessly with differentiable rendering pipelines.
-   **Limitations**: Noisy output due to Monte Carlo sampling. Slow convergence for high-precision requirements. Dependent on the efficiency of the underlying ray-tracer.
-   **When to use**: When using differentiable rendering for inverse problems in volumetric additive manufacturing, where accurate volume representation is critical for print fidelity.
-   **When not to use**: When real-time performance is required, or when the geometry is simple enough for analytic solutions.

## Background
Surface-Aware Discretization was introduced in the context of Tomographic Volumetric Additive Manufacturing (TVAM) by Nicolet et al. in 2024. It is part of the Dr. TVAM framework, which uses physically-based differentiable rendering to optimize printing patterns. The method addresses limitations of prior discretization schemes by accurately modeling the intersection of voxels with complex mesh geometries, thereby mitigating resolution-related artifacts in printed parts [S1, unofficial].
