# Discretized Gaussian Representation (DGR)
## Overview
Discretized Gaussian Representation (DGR) is a framework for direct 3D tomographic volume reconstruction that models the volume as a sum of isotropic Gaussian functions, discretized onto a 3D grid to enable end-to-end differentiable optimization [S1]. It addresses the integration bias and density inconsistency inherent in standard 3D Gaussian Splatting (3DGS) when applied to CT by ensuring gradient flow through the discretization process, unlike naive rounding methods [S1]. It builds on [Fast Volume Reconstruction from Gaussians](2575-fast-volume-reconstruction-from-gaussians.md) by introducing a "Discretize and Align" mechanism that preserves differentiability while allowing parallel aggregation of Gaussian contributions into a voxel grid [S1].

## How it works
**Inputs and Outputs:**
*   **Inputs:** A set of $n$ Gaussians, each defined by a continuous mean $\mu_i \in \mathbb{R}^3$, a covariance matrix $\Sigma_i$ (isotropic, diagonal), and a scalar intensity $I_i \in \mathbb{R}^+$ [S1]. Target volume dimensions $w \times h \times c$ [S1]. Local region size parameters $w_0, h_0, c_0$ (odd integers) [S1].
*   **Outputs:** Reconstructed voxel grid $V \in \mathbb{R}^{w \times h \times c}$ [S1].

**Data Structures:**
*   **Gaussian Parameters:** Stored as tensors of shape $(n, 3)$ for $\mu$, $(n, 3, 3)$ for $\Sigma$ (or $(n, 3)$ for isotropic $\sigma$), and $(n,)$ for $I$ [S1].
*   **Volume Grid:** $V$ initialized to zeros [S1].
*   **Local Box Coordinates:** A tensor $B_0$ of shape $(w_0, h_0, c_0, 3)$ containing the 3D coordinates of the cuboid centered at the origin [S1]. This is constant for all Gaussians due to translation invariance [S1].

**Numbered Steps:**
1.  **Gaussian Effect Confinement:** Restrict each Gaussian's influence to a localized cuboid $B_0$ of size $w_0 \times h_0 \times c_0$ centered on the voxel [S1]. The set of 3D coordinates within this cuboid is $B_0 \subset \mathbb{R}^3$ [S1].
2.  **Discretize and Align:** Calculate contribution at discretized grid positions aligned with floored integer coordinates $\lfloor \mu \rfloor$ [S1]. Define residual $\Delta\mu = \mu - \lfloor \mu \rfloor$ [S1]. Transform coordinates from $B$ to $\lfloor B \rfloor$ using $[B]_{n,w_0,h_0,c_0,d} = B_{w_0,h_0,c_0,d} - \Delta \mu_{n,1,1,d}$, where $\Delta\mu$ is broadcast across spatial dimensions [S1].
3.  **Fast Volume Reconstruction:** Compute $D^2$ in parallel for each local region using the discretized box $\lfloor B \rfloor$ [S1]. Decompose $D^2$ into four Einstein sums: $D^2 = (B^\top C^{-1} B) - (B^\top C^{-1} \Delta \mu) - (\Delta \mu^\top C^{-1} B) + (\Delta \mu^\top C^{-1} \Delta \mu)$ [S1].
4.  **Compute Contribution:** Calculate the contribution tensor $\Gamma$ for the local region as $\Gamma = e^{-\frac{1}{2}D_n^2} \cdot I_n$, where $\Gamma \in \mathbb{R}^{n \times w_0 \times h_0 \times c_0}$ [S1].
5.  **Aggregation:** Update volume voxel $V_{x,y,z}$ by adding contribution $\Gamma_{i,x,y,z}$ from the $i$-th Gaussian: $V_{x,y,z} \leftarrow V_{x,y,z} + \Gamma_{i,x,y,z}$ [S1]. This is performed in a highly parallelized manner for all Gaussians [S1].
6.  **Optimization:** Project the reconstructed volume into the measurement domain for optimization, allowing for joint optimization of all Gaussians [S1].

**Formulas:**
*   Continuous Gaussian: $G(p, \mu, \Sigma) = e^{-\frac{1}{2}(p-\mu)^T\Sigma^{-1}(p-\mu)}$, where $p \in \mathbb{R}^3$ is the 3D point, $\mu$ is the mean, and $\Sigma$ is the covariance matrix [S1].
*   Voxel intensity: $V(p) = \sum_{i=1}^n G(p, \mu_i, \Sigma_i) \cdot I_i$, where $I_i \in \mathbb{R}^+$ is the scalar intensity/weight [S1].
*   Relative coordinates: $B = B_0 - \mu$, where $B_0$ is the set of 3D coordinates within the cuboid [S1].
*   Squared Mahalanobis distance: $D^2 = B^\top C^{-1} B$, where $C$ is the covariance matrix [S1].
*   Contribution: $e^{-\frac{1}{2}D^2} \cdot I_i$ [S1].
*   Discretization alignment: $[B]_{n,w_0,h_0,c_0,d} = B_{w_0,h_0,c_0,d} - \Delta \mu_{n,1,1,d}$ [S1].
*   Decomposed $D^2$: $D^2 = (B^\top C^{-1} B) - (B^\top C^{-1} \Delta \mu) - (\Delta \mu^\top C^{-1} B) + (\Delta \mu^\top C^{-1} \Delta \mu)$ [S1].
*   Final contribution tensor: $\Gamma = e^{-\frac{1}{2}D_n^2}$, where $\Gamma \in \mathbb{R}^{n \times w_0 \times h_0 \times c_0}$ [S1].
*   Aggregation: $V_{x,y,z} \leftarrow V_{x,y,z} + \Gamma_{i,x,y,z}$ [S1].

**Parameters:**
*   $w_0, h_0, c_0$: Dimensions of the effective proximity cuboid. Must be odd integers. Not given in the sources. [S1]
*   Isotropic Covariance: $\Sigma_i = \sigma_i^2 I$, where $I$ is the identity matrix. This is chosen because CT tissues, particularly soft tissues, exhibit isotropic attenuation properties [S1].

**Edge Cases and Pitfalls:**
*   **Non-differentiability:** Directly discretizing $\mu$ by rounding to the nearest integer makes the process non-differentiable, hindering optimization [S1]. The "Discretize and Align" method avoids this by using the residual $\Delta \mu$ [S1].
*   **Boundary Conditions:** Gaussians near the volume boundary may have contributions that fall outside the grid. These must be clipped or masked to avoid out-of-bounds errors [G].
*   **Cuboid Size:** The sources do not specify optimal cuboid dimensions beyond requiring odd integers [S1].

**Pseudocode:**
```python
import torch

def discretized_gaussian_representation(gaussians, volume_shape, box_size):
    """
    Reconstructs a 3D volume from a set of Gaussians using DGR.
    Args:
        gaussians: Dict with keys 'mu' (n, 3), 'sigma' (n,), 'I' (n,)
        volume_shape: Tuple (w, h, c)
        box_size: Tuple (w0, h0, c0) - odd integers
    Returns:
        V: Reconstructed volume tensor (w, h, c)
    """
    n = gaussians['mu'].shape[0]
    w0, h0, c0 = box_size
    d = 3
    
    # Step 1 & 2: Create constant local box coordinates B0 centered at origin
    coords = torch.meshgrid(
        torch.arange(w0, dtype=torch.float32) - w0 // 2,
        torch.arange(h0, dtype=torch.float32) - h0 // 2,
        torch.arange(c0, dtype=torch.float32) - c0 // 2,
        indexing='ij'
    )
    B0 = torch.stack(coords, dim=-1)  # (w0, h0, c0, 3)
    
    # Extract Gaussian parameters
    mu = gaussians['mu']              # (n, 3)
    sigma = gaussians['sigma']        # (n,)
    I = gaussians['I']                # (n,)
    
    # Covariance inverse for isotropic Gaussians: C_inv = 1/sigma^2
    C_inv = 1.0 / (sigma ** 2)        # (n,)
    
    # Step 2: Discretize and Align
    mu_floor = torch.floor(mu)        # (n, 3)
    delta_mu = mu - mu_floor          # (n, 3)
    
    # Relative coordinates B = B0 - mu
    B = B0.unsqueeze(0) - mu.unsqueeze(1).unsqueeze(1)  # (n, w0, h0, c0, 3)
    
    # Transform to discretized box aligned with floored mean: [B] = B - delta_mu
    B_disc = B - delta_mu.unsqueeze(1).unsqueeze(1)      # (n, w0, h0, c0, 3)
    
    # Step 3: Fast Volume Reconstruction (Compute D^2 via decomposition)
    # Term 1: B^T C^-1 B
    term1 = torch.sum(B_disc ** 2 * C_inv.unsqueeze(1).unsqueeze(1).unsqueeze(1), dim=-1)  # (n, w0, h0, c0)
    
    # Term 2: B^T C^-1 delta_mu
    term2 = torch.sum(B_disc * delta_mu.unsqueeze(1).unsqueeze(1).unsqueeze(1) * C_inv.unsqueeze(1).unsqueeze(1).unsqueeze(1), dim=-1)  # (n, w0, h0, c0)
    
    # Term 3: delta_mu^T C^-1 B (identical to term2 for scalar product)
    term3 = term2
    
    # Term 4: delta_mu^T C^-1 delta_mu
    term4 = torch.sum(delta_mu ** 2 * C_inv, dim=-1)  # (n,)
    
    D2 = term1 - term2 - term3 + term4.unsqueeze(1).unsqueeze(1).unsqueeze(1)  # (n, w0, h0, c0)
    
    # Step 4: Compute Contribution Gamma
    Gamma = torch.exp(-0.5 * D2) * I.unsqueeze(1).unsqueeze(1).unsqueeze(1)  # (n, w0, h0, c0)
    
    # Step 5: Aggregation
    V = torch.zeros(volume_shape, dtype=torch.float32)
    
    for i in range(n):
        base_idx = mu_floor[i].long()  # (3,)
        
        local_indices = torch.meshgrid(
            torch.arange(w0),
            torch.arange(h0),
            torch.arange(c0),
            indexing='ij'
        )
        local_indices = torch.stack(local_indices, dim=-1)  # (w0, h0, c0, 3)
        
        global_indices = base_idx.unsqueeze(0).unsqueeze(0).unsqueeze(0) + local_indices  # (w0, h0, c0, 3)
        
        x = torch.clamp(global_indices[:, :, :, 0], 0, volume_shape[0] - 1)
        y = torch.clamp(global_indices[:, :, :, 1], 0, volume_shape[1] - 1)
        z = torch.clamp(global_indices[:, :, :, 2], 0, volume_shape[2] - 1)
        
        V[x, y, z] += Gamma[i, :, :, :]
        
    return V
```

## Operating characteristics
*   **Time Complexity:** The Fast Volume Reconstruction technique reduces time complexity by decomposing the Mahalanobis distance calculation and reusing the spatial grid $B$ [S1]. The exact complexity is not given in the sources. [S1]
*   **Memory Complexity:** S1 states the decomposition reduces time complexity without increasing space complexity [S1].
*   **Performance:** DGR achieves superior reconstruction quality and runtime performance across various CT reconstruction scenarios compared to traditional DLR and 3DGS [S1].
*   **Strengths:** End-to-end differentiable optimization, efficient parallel aggregation, handles isotropic tissues well [S1].
*   **Limitations:** Relies on the assumption of isotropic attenuation, which may not hold for all tissue types or anisotropic structures. The cuboid confinement may lose information from distant Gaussians, though this is mitigated by trainable Gaussians [S1].

## Background
DGR was proposed in 2025 by W. King et al. in the paper "Discretized Gaussian Representation for Tomographic Reconstruction" [S1]. It addresses limitations in existing differentiable volumetric reconstruction methods, particularly the integration bias and density inconsistency of 3D Gaussian Splatting when applied to CT [S1]. The method is designed to be a plug-and-play module that can be integrated into existing 3D Gaussian-based pipelines [S1].
