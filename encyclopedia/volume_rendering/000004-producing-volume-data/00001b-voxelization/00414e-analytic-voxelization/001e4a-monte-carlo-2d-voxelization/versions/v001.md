# Monte Carlo 2D Voxelization

Also called: Differentiable 2D Voxelization (Forward/Backward Mode), Monte Carlo 3D Voxelization, Monte Carlo Voxelization

## Overview
Monte Carlo 2D Voxelization is a differentiable method for converting a 2D triangle mesh (defined by vertices and edges) into a volumetric occupancy grid using Monte Carlo integration of the generalized winding number [S1, unofficial]. It sets itself apart from [Analytic Voxelization](4969-analytic-voxelization.md) by using stochastic sampling rather than exact geometric intersection, allowing for adaptive sampling strategies and gradient propagation through the sampling process [S1, unofficial]. It differs from [Differentiable Voxelization (MC/CF)](1742-differentiable-voxelization-mc-cf.md) by specifically implementing the 2D case with a focus on the generalized winding number boundary term [S1, unofficial].

## How it works
**Inputs and Outputs:**
- `vertices`: Array of shape $(n, 2)$ containing vertex coordinates in $\mathbb{R}^2$, type `Float` [S1, unofficial].
- `edges`: Array of shape $(m, 2)$ containing vertex indices for each edge, type `uint32_t` [S1, unofficial].
- `grid`: Voxel grid dimensions $(h, w)$ [S1, unofficial].
- `num_samples_per_voxel`: Number of Monte Carlo samples per voxel [S1, unofficial].
- `sampling_flags`: Bitmask controlling strategy (Adaptive, Stratified) [S1, unofficial].
- `filter_radius`: Radius for the box filter [S1, unofficial].
- Output: `occupancy` array of shape $(h, w)$ containing smoothed winding numbers [S1, unofficial].

**Data Structures:**
- `Bitset`: Used in adaptive mode to mark boundary voxels. Stores bits for each voxel index [S1, unofficial].
- `Filter`: Box filter with radius `filter_radius` and evaluation method `eval(distance)` [S1, unofficial].

**Parameters:**
- `num_samples_per_voxel`: Typical value determined by user; default logic adjusts for stratified sampling [S1, unofficial].
- `sampling_flags`: Default is `Adaptive | Stratified`. Flags: `Adaptive` (1<<0), `Stratified` (1<<1) [S1, unofficial].
- Coordinate system: Volume is $[-1, 1]^2$. Grid covers this volume exactly [S1, unofficial].

**Steps:**
1. **Initialization**:
   - Compute `voxel_size` from grid dimensions and volume $[-1, 1]^2$. Specifically, `voxel_size = 2.0 / grid_dim` for each dimension [S1, unofficial].
   - Compute `voxel_volume = voxel_size[0] * voxel_size[1]` [S1, unofficial].
   - Initialize random engine and uniform distribution `std::uniform_real_distribution<Float>` [S1, unofficial].
   - If `Adaptive` flag is set, create a bitset mask and call `mark_boundary_voxels` to identify voxels near the surface [S1, unofficial].

2. **Sampling Loop**:
   - Total samples: `num_samples_total = num_samples_per_voxel * grid.num_elements()` [S1, unofficial].
   - Iterate `sample_index` from 0 to `num_samples_total - 1` [S1, unofficial].
   - Determine `voxel_index = sample_index / num_samples_per_voxel` [S1, unofficial].
   - Determine `sample_lane = sample_index % num_samples_per_voxel` [S1, unofficial].
   - **Adaptive Check**: If `Adaptive` is set and the voxel at `voxel_index` is not marked in the mask (constant voxel), set `num_samples_this_voxel = 1`. If `sample_lane > 0`, skip this sample [S1, unofficial]. Otherwise, `num_samples_this_voxel = num_samples_per_voxel` [S1, unofficial].

3. **Sample Generation**:
   - Generate local sample position in $[0, 1]^2$: `sample_local = {distribution(engine), distribution(engine)}` [S1, unofficial].
   - Convert `voxel_index` to coordinates `(vx, vy)` [S1, unofficial].
   - Compute voxel origin in global space: `voxel_origin = {vx * voxel_size[0] - 1, vy * voxel_size[1] - 1}` [S1, unofficial].
   - **Stratified Sampling**: If `Stratified` flag is set and `num_samples_this_voxel > 1`:
     - Compute `num_samples_sqrt = ceil(sqrt(num_samples_this_voxel))` [G].
     - Compute stratum index: `stratum = {sample_lane % num_samples_sqrt, sample_lane / num_samples_sqrt}` [S1, unofficial].
     - Compute `stratum_size = voxel_size / num_samples_sqrt` [G].
     - Sample position: `sample = voxel_origin + (stratum + sample_local) * stratum_size` [S1, unofficial].
   - **Non-Stratified**: `sample = voxel_origin + voxel_size * sample_local` [S1, unofficial].

4. **Generalized Winding Number (GWN)**:
   - Compute GWN for the sample point against the mesh: `sample_occupancy = generalized_winding_number(vertices, edges, sample)` [S1, unofficial].
   - The GWN is computed by summing contributions from all edges. For each edge $(v_0, v_1)$, the contribution is based on the angle subtended by the edge at the sample point [G].

5. **Filtering and Accumulation**:
   - Compute sample grid coordinate: `sample_grid_coord = Point2<Float>(voxel) + sample_local` [S1, unofficial].
   - Determine filter support range using `get_grid_support(sample_grid_coord, filter.radius / voxel_size, min_coord, max_coord)` [S1, unofficial].
   - Iterate over neighbor voxels `(nx, ny)` in the support box, clamped to grid dimensions $[0, width)$ and $[0, height)$ [S1, unofficial].
   - Compute neighbor voxel center in world space: `n_center = {nx * voxel_size[0] + half_voxel_size[0] - 1, ny * voxel_size[1] + half_voxel_size[1] - 1}` [S1, unofficial].
   - Compute filter weight: `filter_weight = filter.eval(n_center - sample)` [S1, unofficial].
   - If `filter_weight > 0`:
     - Compute sample weight: `sample_weight = voxel_volume / num_samples_this_voxel` [S1, unofficial].
     - Update occupancy: `occupancy[coords_to_linear_index(nx, ny, grid)] += filter_weight * sample_occupancy * sample_weight` [S1, unofficial].

**Pseudocode:**

```python
import random
import math

def monte_carlo_2d_voxelization(vertices, edges, grid, num_samples_per_voxel, sampling_flags, filter_radius):
    """
    vertices: list of [x, y] coordinates
    edges: list of [v0_idx, v1_idx]
    grid: (height, width)
    num_samples_per_voxel: int
    sampling_flags: dict with 'adaptive' and 'stratified' booleans
    filter_radius: float
    """
    h, w = grid
    voxel_size_x = 2.0 / w
    voxel_size_y = 2.0 / h
    voxel_size = (voxel_size_x, voxel_size_y)
    voxel_volume = voxel_size_x * voxel_size_y
    half_voxel_size = (voxel_size_x / 2.0, voxel_size_y / 2.0)
    
    # Initialize occupancy grid
    occupancy = [0.0] * (h * w)
    
    # Adaptive mask
    mask = [False] * (h * w)
    if sampling_flags.get('adaptive', False):
        # mark_boundary_voxels is a helper to identify voxels near edges
        mask = mark_boundary_voxels(vertices, edges, grid, filter_radius)
        
    num_samples_total = num_samples_per_voxel * h * w
    engine = random.Random()
    
    for sample_index in range(num_samples_total):
        voxel_index = sample_index // num_samples_per_voxel
        sample_lane = sample_index % num_samples_per_voxel
        
        # Adaptive logic
        if sampling_flags.get('adaptive', False):
            if not mask[voxel_index]:
                num_samples_this_voxel = 1
                if sample_lane > 0:
                    continue
            else:
                num_samples_this_voxel = num_samples_per_voxel
        else:
            num_samples_this_voxel = num_samples_per_voxel
            
        # Sample generation
        sample_local_x = engine.random()
        sample_local_y = engine.random()
        
        vx = voxel_index // h
        vy = voxel_index % h
        
        voxel_origin_x = vx * voxel_size_x - 1.0
        voxel_origin_y = vy * voxel_size_y - 1.0
        
        if sampling_flags.get('stratified', False) and num_samples_this_voxel > 1:
            num_samples_sqrt = math.ceil(math.sqrt(num_samples_this_voxel))
            stratum_x = sample_lane % num_samples_sqrt
            stratum_y = sample_lane // num_samples_sqrt
            stratum_size_x = voxel_size_x / num_samples_sqrt
            stratum_size_y = voxel_size_y / num_samples_sqrt
            sample_x = voxel_origin_x + (stratum_x + sample_local_x) * stratum_size_x
            sample_y = voxel_origin_y + (stratum_y + sample_local_y) * stratum_size_y
        else:
            sample_x = voxel_origin_x + sample_local_x * voxel_size_x
            sample_y = voxel_origin_y + sample_local_y * voxel_size_y
            
        # Generalized Winding Number
        sample_occupancy = generalized_winding_number_2d(vertices, edges, (sample_x, sample_y))
        
        # Filter support
        sample_grid_x = vx + sample_local_x
        sample_grid_y = vy + sample_local_y
        
        min_nx = max(0, int(sample_grid_x - filter_radius / voxel_size_x))
        max_nx = min(w - 1, int(sample_grid_x + filter_radius / voxel_size_x))
        min_ny = max(0, int(sample_grid_y - filter_radius / voxel_size_y))
        max_ny = min(h - 1, int(sample_grid_y + filter_radius / voxel_size_y))
        
        sample_weight = voxel_volume / num_samples_this_voxel
        
        for ny in range(min_ny, max_ny + 1):
            for nx in range(min_nx, max_nx + 1):
                n_center_x = nx * voxel_size_x + half_voxel_size_x - 1.0
                n_center_y = ny * voxel_size_y + half_voxel_size_y - 1.0
                
                dist_x = n_center_x - sample_x
                dist_y = n_center_y - sample_y
                
                # Box filter evaluation
                filter_weight = 1.0 if abs(dist_x) <= filter_radius and abs(dist_y) <= filter_radius else 0.0
                
                if filter_weight > 0:
                    n_voxel_index = ny * w + nx
                    occupancy[n_voxel_index] += filter_weight * sample_occupancy * sample_weight
                    
    return occupancy

def generalized_winding_number_2d(vertices, edges, point):
    """
    Computes the 2D generalized winding number for a point against a set of edges.
    """
    gwn = 0.0
    for v0_idx, v1_idx in edges:
        v0 = vertices[v0_idx]
        v1 = vertices[v1_idx]
        
        # Vector from point to vertices
        p0 = (v0[0] - point[0], v0[1] - point[1])
        p1 = (v1[0] - point[0], v1[1] - point[1])
        
        # Angle subtended by the edge at the point
        # Using atan2 to compute the angle
        angle0 = math.atan2(p0[1], p0[0])
        angle1 = math.atan2(p1[1], p1[0])
        
        # Difference in angles, normalized to [-pi, pi]
        diff = angle1 - angle0
        while diff <= -math.pi:
            diff += 2 * math.pi
        while diff > math.pi:
            diff -= 2 * math.pi
            
        gwn += diff
    return gwn / (2 * math.pi)
```

## Subtopics

### Backward Differentiable Monte Carlo Voxelization
Computes backward-mode gradients of voxel occupancy with respect to vertex positions using Monte Carlo sampling [S1, unofficial]. It validates inputs and dispatches to the 2D or 3D backward-mode implementation with `DifferentiationMode::Backward` [S1, unofficial]. Inputs include `d_occupancy` (gradients of occupancy) and outputs `d_vertices` (gradients of vertices) [S1, unofficial].

## Operating characteristics
- **Time Complexity**: $O(N_s \cdot N_v \cdot R^2)$, where $N_s$ is the number of samples, $N_v$ is the number of voxels, and $R$ is the filter radius in voxels. The GWN computation is $O(N_e)$ per sample, where $N_e$ is the number of edges [S1, unofficial].
- **Memory Complexity**: $O(N_v)$ for the occupancy grid and mask [S1, unofficial].
- **Performance**: Depends on the number of samples and the adaptive mask efficiency. Adaptive mode reduces samples for constant voxels [S1, unofficial].
- **Strengths**: Differentiable, supports adaptive sampling, handles complex meshes via GWN [S1, unofficial].
- **Limitations**: Stochastic noise, requires many samples for smooth gradients, restricted to $[-1, 1]^2$ volume [S1, unofficial].

## Background
Originated from the paper "Differentiable Voxelization of Surface Representations" by Djuren, Finnendahl, Worchel, Meyer, and Alexa (2026) [S1, unofficial]. The method is implemented in C++ and exposed to Python via PyTorch [S1, unofficial]. It is used for shape optimization, intersection avoidance, and differentiable rendering [S1, unofficial].
