# Mesh to Voxel Generation via AABB-Triangle Intersection

Also called: MeshToVoxel, Voxelizer

## Overview
This method generates a 3D voxel grid from a triangle mesh by explicitly testing every voxel in the mesh's bounding volume against every triangle to determine occupancy [S1, unofficial]. It differs from rasterization-based methods [908-rasterization-based-voxelization.md] by avoiding GPU projection and instead using a CPU-based Separating Axis Theorem (SAT) intersection test, which guarantees conservative overlap detection without relying on sampling density [S1, unofficial]. It serves as the foundational broad-phase culling step for hierarchical voxelization, such as in Level 1 Triangle-Voxel Classification [4872-level-1-triangle-voxel-classification.md].

## How it works
**Inputs and Outputs**
*   **Input**: A triangle mesh defined by vertices and indices, a voxel side length `_unitSize` (default 0.05f [S1, unofficial]), and a world-space transformation matrix.
*   **Output**: A 3D integer array `_voxels` of dimensions $[Y, Z, X]$, where values are `0` (empty), `1` (intersected), or `2` (occupied/final) [S1, unofficial].

**Data Structures**
*   `Triangle`: A struct containing three `Vector3` fields (`p1`, `p2`, `p3`) representing the world-space vertices of a triangle [S1, unofficial].
*   `_voxels`: A 3D array `int[Y, Z, X]` [S1, unofficial].
*   `_bounds`: A bounding box defined by `min` and `max` vectors in world space [S1, unofficial].

**Algorithm Steps**

1.  **Vertex Transformation**: Transform all mesh vertices from local space to world space using the object's transform matrix [S1, unofficial].
2.  **Bounding Box Calculation**: Compute the world-space axis-aligned bounding box (AABB) of the mesh by finding the minimum and maximum coordinates across all transformed vertices [S1, unofficial].
3.  **Grid Alignment**:
    *   Round the bounding box `min` down to the nearest multiple of `_unitSize` using `RoundDown` [S1, unofficial].
    *   Round the bounding box `max` up to the nearest multiple of `_unitSize` using `RoundUp` [S1, unofficial].
    *   **Edge Case**: If any dimension of `max` equals `min` after rounding, add `_unitSize` to that dimension of `max` to ensure non-zero grid size [S1, unofficial].
4.  **Grid Allocation**: Calculate grid dimensions $N_x, N_y, N_z$ as $\lfloor \frac{max - min}{\_unitSize} \rfloor$. Allocate `_voxels` with these dimensions [S1, unofficial]. Note: `Mathf.RoundToInt` is used, which may introduce slight inaccuracies in grid coverage relative to the exact bounding box [S1, unofficial].
5.  **Voxel Iteration**: Iterate through all voxels in the grid, typically in Y, Z, X order [S1, unofficial].
6.  **Voxel Center Calculation**: For each voxel at indices $(i_x, i_y, i_z)$, compute its world-space center:
    $$
    \text{center} = (i_x \cdot \text{_unitSize} + \frac{\text{_unitSize}}{2}, i_y \cdot \text{_unitSize} + \frac{\text{_unitSize}}{2}, i_z \cdot \text{_unitSize} + \frac{\text{_unitSize}}{2}) + \text{min}
    $$
    [S1, unofficial]
7.  **Intersection Test**: For each triangle in the mesh, perform an AABB-Triangle intersection test using the voxel center and `_unitSize` [S1, unofficial].
8.  **Occupancy Update**: If the test returns true, set `_voxels[i_y, i_z, i_x] = 1` and break the triangle loop for that voxel [S1, unofficial].
9.  **Finalization**: (Post-processing) Convert `1` to `2` for occupied voxels if required by downstream systems [S1, unofficial].

**AABB-Triangle Intersection Test (SAT)**
The function `AABBTriangleOverlaped(voxelCenter, voxelSize, triangle)` determines if the triangle intersects the voxel cube [S1, unofficial].

1.  **Relative Coordinates**: Translate triangle vertices $v_1, v_2, v_3$ relative to the voxel center: $v_i' = v_i - \text{voxelCenter}$ [S1, unofficial].
2.  **Edge Vectors**: Compute edges:
    $$
    e_1 = v_2' - v_1', \quad e_2 = v_3' - v_2', \quad e_3 = v_1' - v_3'
    $$
    [S1, unofficial]
3.  **Separation Axes**: Test for separation along the following axes. If separation is found on any axis, the shapes do not intersect [S1, unofficial]:
    *   **X, Y, Z Axes**: Project triangle vertices onto axes $(1,0,0), (0,1,0), (0,0,1)$. The projection interval for an axis test (e.g., X-axis with edge $e_1$) is calculated as:
        $$
        \text{min} = \min(a \cdot v_{1,y} - b \cdot v_{1,z}, a \cdot v_{3,y} - b \cdot v_{3,z})
        $$
        $$
        \text{max} = \max(a \cdot v_{1,y} - b \cdot v_{1,z}, a \cdot v_{3,y} - b \cdot v_{3,z})
        $$
        $$
        \text{rad} = |e_{1,z}| \cdot \text{halfboxsize}_y + |e_{1,y}| \cdot \text{halfboxsize}_z
        $$
        Separation occurs if $\text{min} > \text{rad}$ or $\text{max} < -\text{rad}$ [S1, unofficial].
    *   **Edge Cross Axes**: Test axes $e_i \times \hat{x}, e_i \times \hat{y}, e_i \times \hat{z}$ for $i \in \{1,2,3\}$ [S1, unofficial].
    *   **Triangle Normal**: Test the axis $\hat{n} = e_1 \times e_2$ [S1, unofficial].
        *   Compute plane constant $d = -\text{Dot}(\hat{n}, v_1')$ [S1, unofficial].
        *   Find extremal points of the box along $\hat{n}$: $v_{\text{min}}$ and $v_{\text{max}}$ [S1, unofficial].
        *   Separation if $\text{Dot}(\hat{n}, v_{\text{min}}) + d > 0$ [S1, unofficial].
        *   Intersection if $\text{Dot}(\hat{n}, v_{\text{max}}) + d \ge 0$ [S1, unofficial].

**Pseudocode**

```python
import math
from typing import List, Tuple

class Vector3:
    def __init__(self, x: float, y: float, z: float):
        self.x = x
        self.y = y
        self.z = z

    def __sub__(self, other):
        return Vector3(self.x - other.x, self.y - other.y, self.z - other.z)

    def __add__(self, other):
        return Vector3(self.x + other.x, self.y + other.y, self.z + other.z)

    def __mul__(self, scalar):
        return Vector3(self.x * scalar, self.y * scalar, self.z * scalar)

    def dot(self, other):
        return self.x * other.x + self.y * other.y + self.z * other.z

    def cross(self, other):
        return Vector3(
            self.y * other.z - self.z * other.y,
            self.z * other.x - self.x * other.z,
            self.x * other.y - self.y * other.x
        )

class Triangle:
    def __init__(self, p1: Vector3, p2: Vector3, p3: Vector3):
        self.p1 = p1
        self.p2 = p2
        self.p3 = p3

def round_down(value: float, length: float) -> float:
    return value - (value % length) if value >= 0 else value - (length - (value % length)) % length

def round_up(value: float, length: float) -> float:
    return value + (length - (value % length)) % length

def aabb_triangle_overlap(voxel_center: Vector3, voxel_size: float, triangle: Triangle) -> bool:
    half_size = voxel_size * 0.5
    half_box = Vector3(half_size, half_size, half_size)
    
    # Translate vertices relative to box center
    v1 = triangle.p1 - voxel_center
    v2 = triangle.p2 - voxel_center
    v3 = triangle.p3 - voxel_center
    
    # Edge vectors
    e1 = v2 - v1
    e2 = v3 - v2
    e3 = v1 - v3
    
    # Test axes: X, Y, Z
    # X-axis test
    # Projection of triangle onto X-axis is just min/max of x components
    # Separation axis test for X-axis involves projecting edges onto YZ plane?
    # The source formula: min = min(a*v1.y - b*v1.z, ...), rad = |e1.z|*half.y + |e1.y|*half.z
    # This corresponds to the cross product of Edge and X-axis (0,1,0) x (1,0,0) = (0,0,-1)? 
    # Actually, SAT for AABB vs Triangle tests 13 axes.
    # 1. X, Y, Z axes of the box.
    # 2. Normal of the triangle.
    # 3. Cross products of each triangle edge with each of the box axes (3 edges * 3 axes = 9 axes).
    
    # Helper for separating axis test
    def test_axis(axis: Vector3, verts: List[Vector3], half_box: Vector3) -> bool:
        # Project vertices onto axis
        projections = [v.dot(axis) for v in verts]
        min_p = min(projections)
        max_p = max(projections)
        
        # Project half-box onto axis
        # The radius of the box projection is sum of abs(axis component) * half_size
        rad = (abs(axis.x) * half_box.x + 
               abs(axis.y) * half_box.y + 
               abs(axis.z) * half_box.z)
        
        if min_p > rad or max_p < -rad:
            return False # Separated
        return True # Not separated on this axis

    # 1. Box Axes
    if not test_axis(Vector3(1, 0, 0), [v1, v2, v3], half_box): return False
    if not test_axis(Vector3(0, 1, 0), [v1, v2, v3], half_box): return False
    if not test_axis(Vector3(0, 0, 1), [v1, v2, v3], half_box): return False

    # 2. Triangle Normal
    normal = e1.cross(e2)
    if normal.x == 0 and normal.y == 0 and normal.z == 0:
        return False # Degenerate triangle
    if not test_axis(normal, [v1, v2, v3], half_box): return False

    # 3. Edge Cross Axes
    edges = [e1, e2, e3]
    box_axes = [Vector3(1, 0, 0), Vector3(0, 1, 0), Vector3(0, 0, 1)]
    
    for edge in edges:
        for box_axis in box_axes:
            axis = edge.cross(box_axis)
            if axis.x == 0 and axis.y == 0 and axis.z == 0:
                continue
            if not test_axis(axis, [v1, v2, v3], half_box): return False

    return True

def mesh_to_voxel(mesh_vertices: List[Vector3], mesh_indices: List[int], 
                  transform_matrix, unit_size: float = 0.05) -> List[List[List[int]]]:
    
    # 1. Transform vertices
    # Assuming transform_matrix is a 4x4 matrix or similar; simplified here to identity for logic
    # In practice: world_v = transform.TransformPoint(local_v)
    world_vertices = [v for v in mesh_vertices] # Placeholder for transform
    
    # 2. Compute Bounding Box
    min_v = Vector3(float('inf'), float('inf'), float('inf'))
    max_v = Vector3(float('-inf'), float('-inf'), float('-inf'))
    
    for v in world_vertices:
        min_v.x = min(min_v.x, v.x)
        min_v.y = min(min_v.y, v.y)
        min_v.z = min(min_v.z, v.z)
        max_v.x = max(max_v.x, v.x)
        max_v.y = max(max_v.y, v.y)
        max_v.z = max(max_v.z, v.z)
        
    # 3. Round Bounds
    min_v = Vector3(round_down(min_v.x, unit_size), round_down(min_v.y, unit_size), round_down(min_v.z, unit_size))
    max_v = Vector3(round_up(max_v.x, unit_size), round_up(max_v.y, unit_size), round_up(max_v.z, unit_size))
    
    # Handle zero-size dimensions
    if max_v.x == min_v.x: max_v.x += unit_size
    if max_v.y == min_v.y: max_v.y += unit_size
    if max_v.z == min_v.z: max_v.z += unit_size
    
    bounds_min = min_v
    bounds_max = max_v
    
    # 4. Allocate Grid
    dim_x = int(math.floor((bounds_max.x - bounds_min.x) / unit_size))
    dim_y = int(math.floor((bounds_max.y - bounds_min.y) / unit_size))
    dim_z = int(math.floor((bounds_max.z - bounds_min.z) / unit_size))
    
    # Initialize voxels with 0
    voxels = [[[0 for _ in range(dim_x)] for _ in range(dim_z)] for _ in range(dim_y)]
    
    # 5. Create Triangles
    triangles = []
    for i in range(0, len(mesh_indices), 3):
        p1 = world_vertices[mesh_indices[i]]
        p2 = world_vertices[mesh_indices[i+1]]
        p3 = world_vertices[mesh_indices[i+2]]
        triangles.append(Triangle(p1, p2, p3))
        
    unit_size_half = unit_size * 0.5
    
    # 6. Iterate Voxels
    for iy in range(dim_y):
        for iz in range(dim_z):
            for ix in range(dim_x):
                # Calculate voxel center
                center = Vector3(
                    ix * unit_size + unit_size_half,
                    iy * unit_size + unit_size_half,
                    iz * unit_size + unit_size_half
                )
                center = center + bounds_min
                
                # Test against triangles
                for tri in triangles:
                    if aabb_triangle_overlap(center, unit_size, tri):
                        voxels[iy][iz][ix] = 1
                        break
                        
    return voxels
```

## Subtopics

### [Level 1 Triangle-Voxel Classification](4872-level-1-triangle-voxel-classification.md)
Classifies input triangles into a coarse 3D voxel grid by mapping vertices to voxel indices and testing overlap with all candidate voxels the triangle spans. It serves as the initial broad-phase culling step in hierarchical voxelization, building on [Mesh to Voxel Generation via AABB-Triangle Intersection](3775-mesh-to-voxel-generation-via-aabb-triangle-intersection.md) by applying the AABB-Triangle intersection test to a grid structure. It differs from [Tessellation-based Voxelization](5430-tessellation-based-voxelization.md) by using a fixed-resolution grid and explicit triangle-voxel overlap tests rather than GPU tessellation hardware.

### [Tessellation-based Voxelization](5430-tessellation-based-voxelization.md)
Tessellation-based Voxelization is a GPU-accelerated method for generating 3D voxel grids from triangle meshes by leveraging the hardware tessellation pipeline to subdivide geometry before rasterization. It differs from fixed-function or CPU-based voxelizers by enabling adaptive triangle density and displacement mapping during the generation phase, allowing for higher fidelity in complex regions.

## Operating characteristics
*   **Time Complexity**: $O(N_v \cdot N_t)$, where $N_v$ is the number of voxels and $N_t$ is the number of triangles. This is a brute-force approach and becomes expensive for high-resolution grids or complex meshes [S1, unofficial].
*   **Memory Complexity**: $O(N_v)$ for the voxel grid storage [S1, unofficial].
*   **Performance**: The method is typically implemented on the CPU (e.g., using C# Tasks in Unity [S1, unofficial]). It is conservative, ensuring no intersections are missed due to sampling, but lacks the parallelism of GPU rasterization methods [S1, unofficial].
*   **Strengths**: Simple to implement; guarantees geometric accuracy via SAT; no aliasing artifacts from rasterization.
*   **Limitations**: Slow for large grids; does not scale well to high resolutions; requires explicit bounding box management [S1, unofficial].
*   **When to use**: Small to medium meshes where exact geometric intersection is required and performance is not critical; as a broad-phase step in hierarchical voxelization [4872-level-1-triangle-voxel-classification.md].
*   **When not to use**: Large-scale scenes requiring real-time performance; high-resolution grids where $O(N_v \cdot N_t)$ is prohibitive.

## Background
This method originates from a Unity-specific implementation for generating voxel grids from triangle meshes using the Separating Axis Theorem for intersection testing [S1, unofficial]. It was published as an unofficial guide on Qiita by @fukaken5050 in 2017, demonstrating a CPU-based approach using asynchronous tasks [S1, unofficial]. It is often used as a baseline or broad-phase step in more complex voxelization pipelines.
