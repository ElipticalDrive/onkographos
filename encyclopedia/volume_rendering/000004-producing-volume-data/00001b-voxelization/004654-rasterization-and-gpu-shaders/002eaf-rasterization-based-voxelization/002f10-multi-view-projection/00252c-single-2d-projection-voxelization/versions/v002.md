# Single 2D Projection Voxelization

Also called: Dominant axis voxelization, Thin voxelization via single projection

## Overview
This method produces 6-separating (tunnel-free) voxelization using only a single 2D projection along the dominant axis of a triangle's normal vector, leveraging the thinness property to avoid redundant calculations. Unlike [Orthographic Multi-View Voxelization](3892-orthographic-multi-view-voxelization.md) which requires projections along all three axes, this approach reduces computational cost by determining occupancy based on the triangle's orientation relative to the voxel grid, ensuring topological correctness with minimal rasterization passes.

## How it works
**Inputs:** A planar triangle mesh, a target voxel grid resolution, and the scene bounding box.
**Outputs:** A 3D voxel grid where occupied voxels form a 6-separating representation of the input geometry.

**Data Structures:**
*   **Voxel Grid:** A 3D array or sparse structure indexed by $(i, j, k)$.
*   **Triangle:** Defined by vertices $\mathbf{v}_0, \mathbf{v}_1, \mathbf{v}_2$ and geometric normal $\mathbf{n}$.
*   **Pixel Buffer:** A 2D buffer storing depth values or occupancy flags for the projected triangle.

**Algorithm Steps:**

1.  **Identify Dominant Axis:**
    Compute the geometric normal $\mathbf{n} = (n_x, n_y, n_z)$ of the triangle. Determine the dominant axis $A$ corresponding to the component of $\mathbf{n}$ with the largest absolute magnitude. Let the other two axes be $B$ and $C$. The projection direction is along axis $A$.

2.  **2D Rasterization:**
    Project the triangle onto the 2D plane defined by axes $B$ and $C$. Rasterize this projection into a 2D buffer. For each pixel $(u, v)$ in the buffer, determine if the triangle covers the pixel center.

3.  **Center Test (Primary Occupancy):**
    For pixels where the projected triangle contains the pixel center:
    *   Evaluate the depth $d_{tri}$ of the triangle at the pixel center coordinates in the 3D space.
    *   Find the voxel in the column corresponding to $(u, v)$ whose center depth $d_{vox}$ is closest to $d_{tri}$.
    *   Mark this voxel as occupied.
    *   *Note:* Due to the thinness property, no other projection direction can produce additional voxels in this column that are not already covered by this test [S1, unofficial].

4.  **Edge Test (Boundary Handling):**
    For pixels where the triangle covers part of the pixel but *not* the center (i.e., the triangle intersects the pixel boundary):
    *   **Horizontal Test:**
        *   Find the intersection points of the triangle edges with the horizontal line bisecting the pixel (line $v = v_{center}$).
        *   Let these intersection points be $p_{left}$ and $p_{right}$.
        *   Clamp these points to the horizontal extents of the pixel (i.e., ensure they lie within the pixel's $u$-range).
        *   Evaluate the depth of the triangle at these two clamped points, yielding $d_{left}$ and $d_{right}$.
        *   Let $d_{vox}$ be the center depth of the voxel in the column corresponding to this pixel.
        *   If $d_{left}$ and $d_{right}$ are on different sides of $d_{vox}$ (i.e., $(d_{left} - d_{vox}) \times (d_{right} - d_{vox}) < 0$), mark the voxel as occupied.
    *   **Vertical Test:**
        *   If the horizontal test fails (values are not on different sides), repeat the process using the vertical line bisecting the pixel (line $u = u_{center}$).
        *   Find intersections with triangle edges, clamp to vertical pixel extents, evaluate depths $d_{top}$ and $d_{bottom}$.
        *   If $d_{top}$ and $d_{bottom}$ are on different sides of $d_{vox}$, mark the voxel as occupied.

**Pseudocode:**

```python
def single_2d_projection_voxelization(triangles, grid_resolution, bbox):
    # Initialize empty voxel grid
    voxel_grid = create_empty_3d_grid(grid_resolution)
    
    for triangle in triangles:
        # 1. Identify dominant axis
        normal = compute_normal(triangle)
        abs_normal = abs(normal)
        dominant_axis = argmax(abs_normal)
        
        # Map axis indices: 0->X, 1->Y, 2->Z
        proj_axis = dominant_axis
        if proj_axis == 0:
            axis_b, axis_c = 1, 2
        elif proj_axis == 1:
            axis_b, axis_c = 0, 2
        else:
            axis_b, axis_c = 0, 1
            
        # 2. Project and Rasterize
        # Project triangle vertices onto the plane perpendicular to proj_axis
        projected_vertices = project_triangle(triangle, proj_axis)
        
        # Rasterize projected triangle to 2D buffer
        # Buffer stores coverage info and potentially depth
        pixel_buffer = rasterize_2d(projected_vertices, grid_resolution)
        
        for u, v in pixel_buffer.active_pixels:
            # Get 3D coordinates of pixel center
            center_3d = pixel_to_3d(u, v, grid_resolution, bbox, proj_axis)
            
            # 3. Center Test
            if triangle_contains_pixel_center(projected_vertices, u, v):
                depth_at_center = evaluate_triangle_depth(triangle, center_3d)
                voxel_index = get_voxel_index_for_depth(depth_at_center, grid_resolution, bbox, proj_axis)
                voxel_grid[voxel_index] = OCCUPIED
            else:
                # 4. Edge Test
                # Horizontal Test
                h_intersections = get_edge_intersections_with_line(triangle, line='horizontal', pixel_u=u, pixel_v=v)
                if h_intersections:
                    p1, p2 = clamp_to_pixel(h_intersections, u, v, axis_b, axis_c)
                    d1 = evaluate_triangle_depth(triangle, p1)
                    d2 = evaluate_triangle_depth(triangle, p2)
                    voxel_center_depth = get_voxel_center_depth(u, v, grid_resolution, bbox, proj_axis)
                    
                    if is_on_different_sides(d1, d2, voxel_center_depth):
                        voxel_index = get_voxel_index_for_depth(voxel_center_depth, grid_resolution, bbox, proj_axis)
                        voxel_grid[voxel_index] = OCCUPIED
                    else:
                        # Vertical Test
                        v_intersections = get_edge_intersections_with_line(triangle, line='vertical', pixel_u=u, pixel_v=v)
                        if v_intersections:
                            p3, p4 = clamp_to_pixel(v_intersections, u, v, axis_b, axis_c)
                            d3 = evaluate_triangle_depth(triangle, p3)
                            d4 = evaluate_triangle_depth(triangle, p4)
                            
                            if is_on_different_sides(d3, d4, voxel_center_depth):
                                voxel_index = get_voxel_index_for_depth(voxel_center_depth, grid_resolution, bbox, proj_axis)
                                voxel_grid[voxel_index] = OCCUPIED

    return voxel_grid
```

**Parameters:**
*   **Grid Resolution:** Determines the size of the voxel grid. Higher resolution increases accuracy but also memory and compute cost.
*   **Bounding Box:** Defines the spatial extent of the voxel grid.

**Edge Cases and Pitfalls:**
*   **Degenerate Triangles:** Triangles with zero area or collinear vertices should be skipped or handled as degenerate cases to avoid division by zero during normal calculation.
*   **Precision:** Floating-point precision issues may arise when evaluating depths near voxel boundaries. Using robust geometric predicates or epsilon comparisons is recommended.
*   **Dominant Axis Selection:** If two components of the normal are equal in magnitude, the choice of dominant axis is arbitrary but must be consistent.

## Operating characteristics
*   **Time Complexity:** $O(N \cdot R^2)$, where $N$ is the number of triangles and $R$ is the grid resolution (assuming uniform distribution). The rasterization step dominates.
*   **Memory Complexity:** $O(R^3)$ for the voxel grid.
*   **Strengths:** Significantly faster than multi-view methods as it requires only one rasterization pass per triangle. Maintains topological correctness (6-separating).
*   **Limitations:** Performance can degrade if triangles are nearly parallel to the projection plane (though the dominant axis selection mitigates this). Not suitable for non-planar surfaces without tessellation.
*   **When to Use:** When computational resources are limited and a topologically correct, tunnel-free voxelization is required. Ideal for real-time applications or large-scale scenes where multi-view projection is too expensive.

## Background
This method is derived from the topological approach to voxelization, specifically leveraging the "thinness" property of voxelizations. It was presented by Laine et al. in "A Topological Approach to Voxelization" [S1, unofficial]. The method builds on the equivalence between 3-axis rasterization and the crosshairs target, showing that a single projection along the dominant normal axis is sufficient to achieve 6-separating voxelization.
