# Huang et al. Voxelization Method
Also called: Huang voxelization

## Overview
This method voxelizes a triangle mesh into a Sparse Voxel DAG by rasterizing triangles into a Morton-coded voxel subgrid using a three-stage overlap test consisting of vertex spheres, edge cylinders, and a plane-barycentric check [S1, unofficial]. It differs from its parent method by operating on a pre-partitioned Morton subgrid range rather than iterating a 2D grid with projection containment tests, allowing for out-of-core processing of large meshes [S1, unofficial].

## How it works
**Inputs and Outputs:**
*   **Input:** A triangle mesh (streamed via `.tri` format), a 64-bit Morton code range `[morton_start, morton_end)` defining the target subgrid, and a voxel side length `unitlength` [S1, unofficial].
*   **Output:** A sparse voxel structure (SVO/DAG) where filled voxels store boolean flags or indices into a data array containing normals and averaged vertex colors [S1, unofficial].

**Data Structures:**
*   **Voxels Array:** An array of size `morton_end - morton_start`.
    *   If `BINARY_VOXELIZATION` is defined: stores `bool` or `char` [S1, unofficial].
    *   Otherwise: stores `size_t`, representing an index into `voxel_data` or a sentinel `EMPTY_VOXEL` value [S1, unofficial].
*   **Voxel Data:** A vector of `VoxelData` structs. Each struct contains:
    *   `morton_index`: The 64-bit Morton code of the voxel [S1, unofficial].
    *   `normal`: The averaged triangle normal [S1, unofficial].
    *   `color`: The averaged vertex colors [S1, unofficial].

**Parameters:**
*   `unitlength`: Voxel side length in world units [S1, unofficial].
*   `morton_start`, `morton_end`: 64-bit Morton codes defining the subgrid range [S1, unofficial].
*   `BINARY_VOXELIZATION`: Compile-time flag [S1, unofficial].

**Algorithm Steps:**
1.  Initialize the voxels array for the range `[morton_start, morton_end)` to `EMPTY_VOXEL` [S1, unofficial].
2.  Decode `morton_start` and `morton_end - 1` to compute the partition bounding box `p_bbox_grid.min` and `p_bbox_grid.max` in grid coordinates [S1, unofficial].
3.  Compute `unit_div = 1.0f / unitlength` and `radius = unitlength / 2.0f` [S1, unofficial].
4.  For each triangle:
    a. Compute its world bounding box.
    b. Convert to grid coordinates by multiplying by `unit_div`.
    c. Clamp the triangle's grid bounding box `t_bbox_grid` to the partition bounding box `p_bbox_grid` [S1, unofficial].
    d. Construct test primitives:
        i. Sphere at each vertex with radius `radius`.
        ii. Cylinder on each edge with radius `radius`.
        iii. Plane `S` defined by the triangle vertices [S1, unofficial].
    e. Iterate `x`, `y`, `z` within `t_bbox_grid`.
    f. Compute index `idx = morton3D_64_encode(z, y, x)`.
    g. Skip if `voxels[idx]` is already filled [S1, unofficial].
    h. **TEST 1 (Vertex Spheres):** Compute `middle_point = vec3((x + 0.5f)*unitlength, (y + 0.5f)*unitlength, (z + 0.5f)*unitlength)`. If `middle_point` is inside any vertex sphere, mark voxel filled, add data if non-binary, increment `nfilled`, and continue [S1, unofficial].
    i. **TEST 2 (Edge Cylinders):** If `middle_point` is inside any edge cylinder, mark voxel filled, add data, increment `nfilled`, and continue [S1, unofficial].
    j. **TEST 3 (Plane-Barycentric):**
        i. Compute `halfunit = unitlength / 2.0f`.
        ii. Calculate `b0, b1, b2` as `abs(dot(halfunit_axis, S.normal))`.
        iii. Compute `cosbeta = max(b0, b1, b2) / (length(halfunit_axis) * length(S.normal))`.
        iv. Compute `tc = (unitlength / 2.0f) * cosbeta`.
        v. Check if `middle_point` is between parallel planes defined by `S.normal` and `S.D + tc` and `S.normal` and `S.D - tc` [S1, unofficial].
        vi. If the plane test passes, compute barycentric-like values:
            $$s_1 = (\mathbf{n} \times \mathbf{e}_1) \cdot (\mathbf{p} - \mathbf{v}_0)$$
            $$s_2 = (\mathbf{n} \times \mathbf{e}_2) \cdot (\mathbf{p} - \mathbf{v}_1)$$
            $$s_3 = (\mathbf{n} \times \mathbf{e}_3) \cdot (\mathbf{p} - \mathbf{v}_2)$$
            where $\mathbf{n}$ is the triangle normal, $\mathbf{e}_i$ are edge vectors ($\mathbf{v}_1-\mathbf{v}_0$, etc.), $\mathbf{p}$ is the voxel center, and $\mathbf{v}_i$ are vertices [S1, unofficial].
        vii. If signs are consistent ($(s_1 \le 0) == (s_2 \le 0) \land (s_2 \le 0) == (s_3 \le 0)$), mark voxel filled, add data, increment `nfilled`, and continue [S1, unofficial].

**Pseudocode:**
```python
def voxelize_triangles(triangles, morton_start, morton_end, unitlength, binary_mode):
    # 1. Initialize voxels array
    num_voxels = morton_end - morton_start
    voxels = [EMPTY_VOXEL] * num_voxels
    voxel_data = []
    nfilled = 0

    # 2. Decode range to get partition bounding box
    p_min = decode_morton(morton_start)
    p_max = decode_morton(morton_end - 1)
    p_bbox_grid = (p_min, p_max)

    unit_div = 1.0 / unitlength
    radius = unitlength / 2.0

    for tri in triangles:
        # 4a. Compute world bounding box and convert to grid
        t_bbox_world = compute_world_bbox(tri)
        t_bbox_grid_min = clamp(t_bbox_world.min * unit_div, p_bbox_grid.min, p_bbox_grid.max)
        t_bbox_grid_max = clamp(t_bbox_world.max * unit_div, p_bbox_grid.min, p_bbox_grid.max)
        
        # 4d. Construct test primitives
        spheres = [Sphere(tri.v0, radius), Sphere(tri.v1, radius), Sphere(tri.v2, radius)]
        cylinders = [Cylinder(tri.v0, tri.v1, radius), Cylinder(tri.v1, tri.v2, radius), Cylinder(tri.v2, tri.v0, radius)]
        plane_S = Plane.from_vertices(tri.v0, tri.v1, tri.v2)

        # 4e. Iterate grid coordinates
        for x in range(t_bbox_grid_min.x, t_bbox_grid_max.x + 1):
            for y in range(t_bbox_grid_min.y, t_bbox_grid_max.y + 1):
                for z in range(t_bbox_grid_min.z, t_bbox_grid_max.z + 1):
                    # 4f. Compute Morton index
                    idx = morton3D_64_encode(z, y, x)
                    
                    # 4g. Skip if filled
                    if voxels[idx] != EMPTY_VOXEL:
                        continue

                    # 4h. Middle point of voxel
                    middle_point = vec3((x + 0.5) * unitlength, (y + 0.5) * unitlength, (z + 0.5) * unitlength)

                    # TEST 1: Vertex Spheres
                    if is_inside_any_sphere(middle_point, spheres):
                        voxels[idx] = FILL
                        if not binary_mode:
                            voxel_data.append(VoxelData(idx, plane_S.normal, average_colors(tri)))
                        nfilled += 1
                        continue

                    # TEST 2: Edge Cylinders
                    if is_inside_any_cylinder(middle_point, cylinders):
                        voxels[idx] = FILL
                        if not binary_mode:
                            voxel_data.append(VoxelData(idx, plane_S.normal, average_colors(tri)))
                        nfilled += 1
                        continue

                    # TEST 3: Plane-Barycentric
                    halfunit = unitlength / 2.0
                    halfunit_axis = vec3(halfunit, halfunit, halfunit)
                    
                    b0 = abs(dot(halfunit_axis, plane_S.normal))
                    b1 = abs(dot(halfunit_axis, plane_S.normal)) # Note: Source implies checking axes, simplified here
                    b2 = abs(dot(halfunit_axis, plane_S.normal))
                    
                    # Correct interpretation of source logic for cosbeta:
                    # The source calculates max(b0, b1, b2) where b_i are projections of halfunit_axis onto normal
                    # Since halfunit_axis is uniform, b0=b1=b2.
                    cosbeta = max(b0, b1, b2) / (length(halfunit_axis) * length(plane_S.normal))
                    tc = (unitlength / 2.0) * cosbeta

                    # Check if middle_point is between parallel planes
                    # Plane equation: n . x + D = 0. D is derived from plane_S.
                    # Source checks if middle_point is within distance tc from the triangle plane
                    dist = abs(dot(plane_S.normal, middle_point) + plane_S.D)
                    if dist > tc:
                        continue

                    # Barycentric check
                    n = plane_S.normal
                    e1 = tri.v1 - tri.v0
                    e2 = tri.v2 - tri.v1
                    e3 = tri.v0 - tri.v2
                    
                    s1 = dot(cross(n, e1), middle_point - tri.v0)
                    s2 = dot(cross(n, e2), middle_point - tri.v1)
                    s3 = dot(cross(n, e3), middle_point - tri.v2)

                    if (s1 <= 0) == (s2 <= 0) and (s2 <= 0) == (s3 <= 0):
                        voxels[idx] = FILL
                        if not binary_mode:
                            voxel_data.append(VoxelData(idx, plane_S.normal, average_colors(tri)))
                        nfilled += 1

    return voxels, voxel_data
```

## Operating characteristics
*   **Time Complexity:** Proportional to the number of triangles times the number of voxels in their projected bounding boxes, with a constant-time overlap test per voxel.
*   **Memory Complexity:** Linear with respect to the number of voxels in the Morton range `[morton_start, morton_end)` for the voxels array, plus linear with respect to the number of filled voxels for `voxel_data` [S1, unofficial].
*   **Strengths:** Allows out-of-core processing by partitioning the scene into Morton subgrids, reducing memory pressure for large models [S1, unofficial].
*   **Limitations:** Requires pre-partitioning and Morton encoding/decoding. The three-stage test, while robust, involves multiple geometric checks per voxel [S1, unofficial].

## Background
This method is part of the implementation for "High Resolution Sparse Voxel DAGs" by Zheng et al., specifically the voxelization stage used to build the Sparse Voxel Octree (SVO) before DAG reduction [S1, unofficial]. It was developed for reconstructing models from the Stanford 3D Scanning library [S1, unofficial].
