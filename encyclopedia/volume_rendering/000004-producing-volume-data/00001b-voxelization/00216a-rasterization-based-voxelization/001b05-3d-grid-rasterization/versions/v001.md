# 3D Grid Rasterization

Also called: Grid-Snapped Voxelization, Mesh Vox, Mesh Vox Voxelization, Mesh Voxelizer, Surface Voxelize, Voxelization via Triangle-AABB Sampling

## Overview
3D Grid Rasterization converts a triangular mesh into a discrete 3D occupancy grid (voxel array) by mapping mesh geometry to a fixed-resolution integer lattice. It solves the problem of representing continuous surface geometry as a volume suitable for ray marching or other volume rendering techniques. Unlike [Voxelization](12-voxelization.md) methods that may use ray casting or signed distance fields, this approach explicitly rasterizes triangles into grid cells, often snapping voxel centers to the grid. It differs from [3D Voxel Grid Smoothing](833-3d-voxel-grid-smoothing.md) by producing raw occupancy without post-processing, and from [Signed Distance Field (SDF) Generation from Scanned Surfaces](854-signed-distance-field-sdf-generation-from-scanned-surfaces.md) by outputting binary or colored occupancy rather than distance values.

## How it works
The method typically follows one of two primary implementations: a **Triangle-AABB Sampling** approach (common in C++ libraries like `voxelizer`) or a **Slice-and-Rasterize** approach (common in Python libraries like `mesh_vox`). Both produce a 3D grid where each cell indicates occupancy and optionally color.

### Inputs and Outputs
**Inputs:**
- A triangular mesh defined by vertices $V$ and indices $I$.
- Target grid dimensions: width $W$, height $H$, depth $D$ (or a single resolution $R$ for the largest dimension).
- Optional: Vertex colors (RGB or RGBA).
- Optional: STL file path (for direct reading).

**Outputs:**
- A 3D array `voxels` of shape $(D, W, H)$ or $(Z, X, Y)$.
- Data type: Boolean (occupancy) or 32-bit integer (packed ABGR color).

### Data Structures

Used to cull triangles.

### Algorithm: Triangle-AABB Sampling (C++ Style)
This method iterates over triangles, computes their bounding box in voxel space, and tests each voxel in that box for intersection.

**Steps:**

1.  **Initialize Grid:** Allocate a flat array `data` of size $W \times H \times D$, initialized to 0.
2.  **Compute Mesh AABB:** Iterate over all triangles to compute the global bounding box `meshaabb` of the mesh.
3.  **Compute Resolution per Axis:**
    $$
    res_x = \frac{meshaabb.max.x - meshaabb.min.x}{W}
    $$
    $$
    res_y = \frac{meshaabb.max.y - meshaabb.min.y}{H}
    $$
    $$
    res_z = \frac{meshaabb.max.z - meshaabb.min.z}{D}
    $$
4.  **Voxelize Points (Optional Pre-step):** Some implementations first convert the mesh to a point cloud using `vx_voxelize_pc` with the computed resolutions, then map points to the grid. However, the core rasterization works directly on triangles.
5.  **Iterate Triangles:** For each triangle $T$ with vertices $v_1, v_2, v_3$:
    a. Compute $T$'s AABB in world space.
    b. Map the AABB min/max to voxel grid indices.
       - Min index: $\lfloor \frac{min - aabb.min}{res} \rfloor$ (rounded down).
       - Max index: $\lceil \frac{max - aabb.min}{res} \rceil - 1$ (rounded up, then adjusted).
       *Note: Implementation details vary on boundary handling. The source uses `vx__map_to_voxel` with specific rounding rules.*
    c. Iterate over voxel indices $(x, y, z)$ within the mapped AABB range.
    d. **Intersection Test:** For each voxel, construct its AABB (centered at grid point, size $res_x, res_y, res_z$). Test for intersection with triangle $T$ using `vx__triangle_box_overlap`.
    e. **Color Interpolation (if colors present):**
       If intersecting, compute the color at the voxel center $C_{voxel}$ using barycentric interpolation.
       - Create sub-triangles $t_1(v_1, v_2, C_{voxel})$, $t_2(v_2, v_3, C_{voxel})$, $t_3(v_3, v_1, C_{voxel})$.
       - Compute areas $A_1, A_2, A_3$.
       - Total Area $A = A_1 + A_2 + A_3$.
       - Weighted Color $C = \frac{C_1 A_2 + C_2 A_3 + C_3 A_1}{A}$.
    f. **Insertion:**
       - Compute flat index $idx = x + y \cdot W + z \cdot (W \cdot H)$.
       - If `data[idx]` is 0, set `data[idx] = Color`.
       - If `data[idx]` is non-zero, blend: `data[idx] = mix(data[idx], Color)` (average of existing and new color).

**Pseudocode (Triangle-AABB Sampling):**

```python
import numpy as np

def triangle_box_overlap(tri, box_min, box_max):
    """
    Simplified check: returns True if triangle intersects box.
    In practice, use a robust SAT or separating axis test.
    Here we assume a helper exists or implement a basic overlap.
    """
    # Placeholder for robust intersection test
    # The source uses vx__triangle_box_overlap
    # We implement a basic bounding sphere check for completeness
    tri_center = (tri.p1 + tri.p2 + tri.p3) / 3.0
    tri_radius = max(
        np.linalg.norm(tri.p1 - tri_center),
        np.linalg.norm(tri.p2 - tri_center),
        np.linalg.norm(tri.p3 - tri_center)
    )
    box_center = (box_min + box_max) / 2.0
    box_radius = np.linalg.norm(box_max - box_min) / 2.0
    
    dist = np.linalg.norm(tri_center - box_center)
    return dist <= (tri_radius + box_radius)

def voxelize_snap_3dgrid(vertices, indices, width, height, depth, colors=None):
    """
    Voxelize a mesh into a 3D grid using AABB sampling.
    """
    # 1. Initialize Grid
    grid = np.zeros((width, height, depth), dtype=np.uint32) # ABGR packed
    
    # 2. Compute Mesh AABB
    min_v = np.min(vertices, axis=0)
    max_v = np.max(vertices, axis=0)
    
    # 3. Compute Resolution per Axis
    res_x = (max_v[0] - min_v[0]) / width
    res_y = (max_v[1] - min_v[1]) / height
    res_z = (max_v[2] - min_v[2]) / depth
    
    # Handle zero dimensions to avoid division by zero
    if res_x == 0: res_x = 1e-9
    if res_y == 0: res_y = 1e-9
    if res_z == 0: res_z = 1e-9

    # 4. Iterate Triangles
    for i in range(0, len(indices), 3):
        i1, i2, i3 = indices[i], indices[i+1], indices[i+2]
        p1, p2, p3 = vertices[i1], vertices[i2], vertices[i3]
        tri = {'p1': p1, 'p2': p2, 'p3': p3}
        
        # Compute Triangle AABB
        tri_min = np.minimum(np.minimum(p1, p2), p3)
        tri_max = np.maximum(np.maximum(p1, p2), p3)
        
        # Map to Voxel Indices
        # Min index: floor((min - mesh_min) / res)
        x_min = int(np.floor((tri_min[0] - min_v[0]) / res_x))
        y_min = int(np.floor((tri_min[1] - min_v[1]) / res_y))
        z_min = int(np.floor((tri_min[2] - min_v[2]) / res_z))
        
        # Max index: ceil((max - mesh_min) / res) - 1
        x_max = int(np.ceil((tri_max[0] - min_v[0]) / res_x)) - 1
        y_max = int(np.ceil((tri_max[1] - min_v[1]) / res_y)) - 1
        z_max = int(np.ceil((tri_max[2] - min_v[2]) / res_z)) - 1
        
        # Clamp to grid bounds
        x_min = max(0, min(x_min, width - 1))
        x_max = max(0, min(x_max, width - 1))
        y_min = max(0, min(y_min, height - 1))
        y_max = max(0, min(y_max, height - 1))
        z_min = max(0, min(z_min, depth - 1))
        z_max = max(0, min(z_max, depth - 1))
        
        # 5. Iterate Voxels in AABB
        for z in range(z_min, z_max + 1):
            for y in range(y_min, y_max + 1):
                for x in range(x_min, x_max + 1):
                    # Construct Voxel AABB
                    box_min = np.array([
                        min_v[0] + x * res_x,
                        min_v[1] + y * res_y,
                        min_v[2] + z * res_z
                    ])
                    box_max = box_min + np.array([res_x, res_y, res_z])
                    
                    # Intersection Test
                    if triangle_box_overlap(tri, box_min, box_max):
                        # Color Interpolation
                        if colors is not None:
                            c1, c2, c3 = colors[i1], colors[i2], colors[i3]
                            # Barycentric weights based on sub-triangle areas
                            # Area of triangle (a,b,c)
                            def tri_area(a, b, c):
                                return 0.5 * np.linalg.norm(np.cross(b-a, c-a))
                            
                            center = (box_min + box_max) / 2.0
                            a1 = tri_area(p1, p2, center)
                            a2 = tri_area(p2, p3, center)
                            a3 = tri_area(p3, p1, center)
                            total_area = a1 + a2 + a3
                            
                            if total_area > 0:
                                r = (c1[0]*a2 + c2[0]*a3 + c3[0]*a1) / total_area
                                g = (c1[1]*a2 + c2[1]*a3 + c3[1]*a1) / total_area
                                b_val = (c1[2]*a2 + c2[2]*a3 + c3[2]*a1) / total_area
                                a_alpha = 1.0 # Assuming opaque
                            else:
                                r, g, b_val, a_alpha = 0, 0, 0, 0
                        else:
                            r, g, b_val, a_alpha = 1, 1, 1, 1
                            
                        # Pack ABGR
                        color_int = (
                            ((int(a_alpha * 255) & 0xff) << 24) |
                            ((int(b_val * 255) & 0xff) << 16) |
                            ((int(g * 255) & 0xff) << 8) |
                            ((int(r * 255) & 0xff) << 0)
                        )
                        
                        # Insert or Blend
                        idx = x + y * width + z * (width * height)
                        if grid[idx] == 0:
                            grid[idx] = color_int
                        else:
                            # Blend: average of current and new
                            # Unpack
                            old_r = (grid[idx] >> 0) & 0xff
                            old_g = (grid[idx] >> 8) & 0xff
                            old_b = (grid[idx] >> 16) & 0xff
                            old_a = (grid[idx] >> 24) & 0xff
                            
                            new_r = (old_r + int(r * 255)) // 2
                            new_g = (old_g + int(g * 255)) // 2
                            new_b = (old_b + int(b_val * 255)) // 2
                            new_a = (old_a + int(a_alpha * 255)) // 2
                            
                            grid[idx] = (
                                (new_a << 24) |
                                (new_b << 16) |
                                (new_g << 8) |
                                (new_r << 0)
                            )
    return grid
```

### Algorithm: Slice-and-Rasterize (Python Style)
This method slices the mesh at each height $z$, computes 2D intersection lines, and rasterizes them into a 2D grid.

**Steps:**

1.  **Read Mesh:** Load STL file (binary or ASCII).
2.  **Scale and Shift:**
    - Find min/max coordinates of all vertices.
    - Compute `xyscale = (resolution - 1) / max(width, depth)`.
    - `shift = -min`.
    - `scale = [xyscale, xyscale, xyscale]`.
    - Transform vertices: $v' = (v + shift) \times scale$.
    - Filter degenerate triangles (fewer than 3 unique points after transformation).
3.  **Initialize Voxel Array:** Boolean array `voxels` of shape `(bounding_box[2], bounding_box[0], bounding_box[1])`.
4.  **Iterate Height $z$:**
    a. **Find Intersecting Triangles:** Filter triangles that cross the plane $z$.
       - A triangle crosses if:
         - It has vertices both above ($z_v > z$) and below ($z_v < z$).
         - OR it has 2 or 3 vertices exactly on the plane ($z_v == z$).
       - Exclude triangles lying entirely on the plane (handled by the "above/below" logic or specific exclusion).
    b. **Compute Intersection Lines:**
       - For each valid triangle, compute the intersection line segment with the plane $z$.
       - Cases:
         - 2 vertices on plane: Return those 2 vertices.
         - 1 vertex on plane: Compute intersection point on the edge between the above/below vertex and the on-plane vertex. Return (intersection, on-plane vertex).
         - 0 vertices on plane: Compute intersection points on the two edges crossing the plane. Return those 2 points.
       - Intersection point calculation:
         - Ensure $p_1.z < p_2.z$.
         - If $p_1.z == p_2.z$, distance = 0.
         - Else, $t = \frac{z - p_1.z}{p_2.z - p_1.z}$.
         - $point = p_1 + t \times (p_2 - p_1)$.
    c. **Rasterize Lines to 2D Grid:**
       - Initialize `prepixel` grid of size `(bounding_box[0], bounding_box[1])` to False.
       - For each $x$ column:
         - Find relevant lines crossing this $x$. A line is relevant if it spans across $x$ (vertices on both sides) or one vertex is on $x$ and another is above.
         - Compute target $y$ coordinates for each line at this $x$:
           - If vertical ($x_0 == x_1$), return -1 (skip).
           - Else, $ratio = \frac{x - x_0}{x_1 - x_0}$.
           - $y_{new} = y_0 + ratio \times (y_1 - y_0)$.
         - For each $y$ row:
           - If `isBlack` is True, set `prepixel[x][y] = True`.
           - If $y$ matches a target $y$ coordinate AND the point lies on the line segment (checked by integer comparison and range checks), toggle `isBlack` and set `prepixel[x][y] = True`.
       - Assign `prepixel` to `voxels[z]`.
5.  **Padding (Optional):** If padding is enabled, expand dimensions by 2 in each axis and shift data by 1.

```python
import numpy as np

def read_stl(filepath):

def calculate_scale_and_shift(mesh, resolution):
    all_points = [pt for tri in mesh for pt in tri]
    mins = np.min(all_points, axis=0)
    maxs = np.max(all_points, axis=0)
    width = maxs[0] - mins[0]
    depth = maxs[1] - mins[1] # Assuming X is width, Y is depth? Source uses X,Y for 2D grid
    # Source: xyscale = (resolution - 1) / max(width, depth)
    # Note: Source uses 'width' and 'depth' for X and Y dimensions of the model
    max_dim = max(width, depth)
    if max_dim == 0: max_dim = 1e-9
    xyscale = (resolution - 1) / max_dim
    shift = -mins
    scale = np.array([xyscale, xyscale, xyscale])
    # Bounding box in voxel space
    # Z dimension is scaled by xyscale as well
    z_range = (maxs[2] - mins[2]) * xyscale
    bounding_box = [resolution, resolution, int(np.ceil(z_range))]
    return scale, shift, bounding_box

def scale_and_shift_mesh(mesh, scale, shift):
    new_mesh = []
    for tri in mesh:
        new_tri = []
        for pt in tri:
            new_pt = (np.array(pt) + shift) * scale
            new_tri.append(tuple(new_pt))
        # Check for degeneracy
        if len(set(new_tri)) == 3:
            new_mesh.append(new_tri)
    return new_mesh

def is_above_and_below(tri, height):
    zs = [pt[2] for pt in tri]
    has_above = any(z > height for z in zs)
    has_below = any(z < height for z in zs)
    return has_above and has_below

def is_intersecting_triangle(tri, height):
    # Exclude triangles lying entirely on the plane
    zs = [pt[2] for pt in tri]
    on_plane = sum(1 for z in zs if abs(z - height) < 1e-9)
    return on_plane == 3

def triangle_to_intersecting_lines(tri, height):
    p1, p2, p3 = tri
    pts = [p1, p2, p3]
    above = [p for p in pts if p[2] > height]
    below = [p for p in pts if p[2] < height]
    same = [p for p in pts if abs(p[2] - height) < 1e-9]
    
    if len(same) == 2:
        return [same]
    elif len(same) == 1:
        # One vertex on plane, one above, one below
        # Find the edge crossing
        # The vertex on plane is one endpoint. The other is the intersection.
        # Find the vertex that is not 'same'
        others = [p for p in pts if p not in same]
        # One of others is above, one is below
        # Compute intersection on the edge between above and below? 
        # No, the line is from 'same' to the intersection on the edge between above/below?
        # Source: side1 = whereLineCrossesZ(above[0], below[0], height)
        # return side1, same[0]
        if above and below:
            side1 = where_line_crosses_z(above[0], below[0], height)
            return [[side1, same[0]]]
        else:
            return []
    else:
        # No vertices on plane
        # Compute intersections on two edges
        # Edges are (p1,p2), (p2,p3), (p3,p1)
        # Find edges that cross
        lines = []
        for i in range(3):
            p_a = pts[i]
            p_b = pts[(i+1)%3]
            if (p_a[2] > height) != (p_b[2] > height):
                inter = where_line_crosses_z(p_a, p_b, height)
                lines.append(inter)
        if len(lines) == 2:
            return [lines]
        return []

def where_line_crosses_z(p1, p2, z):
    # Ensure p1 is below p2
    if p1[2] > p2[2]:
        p1, p2 = p2, p1
    if abs(p2[2] - p1[2]) < 1e-9:
        distance = 0
    else:
        distance = (z - p1[2]) / (p2[2] - p1[2])
    # Linear interpolation
    x = p1[0] - distance * (p1[0] - p2[0])
    y = p1[1] - distance * (p1[1] - p2[1])
    return (x, y)

def find_relevant_lines(line_list, x):
    relevant = []
    for line in line_list:
        p1, p2 = line
        # Check if line spans across x
        # Vertices on both sides, or one on x and one above
        x1, y1 = p1
        x2, y2 = p2
        
        above = False
        below = False
        same = False
        
        if x1 > x: above = True
        elif x1 < x: below = True
        else: same = True
        
        if x2 > x: above = True
        elif x2 < x: below = True
        else: same = True
        
        if above and below:
            relevant.append(line)
        elif same and above:
            relevant.append(line)
    return relevant

def generate_y(line, x):
    p1, p2 = line
    x1, y1 = p1
    x2, y2 = p2
    if x1 == x2:
        return -1
    ratio = (x - x1) / (x2 - x1)
    newy = y1 + ratio * (y2 - y1)
    return newy

def on_line(line, x, y):
    p1, p2 = line
    x1, y1 = p1
    x2, y2 = p2
    
    newy = generate_y(line, x)
    if int(newy) != y:
        return False
    
    # Check if x is within line's X range
    if not (min(x1, x2) <= x <= max(x1, x2)):
        return False
        
    # Check if y is within line's Y range
    if not (min(y1, y2) <= y <= max(y1, y2)):
        return False
        
    return True

def voxelize_slice(mesh, resolution):
    scale, shift, bounding_box = calculate_scale_and_shift(mesh, resolution)
    mesh = scale_and_shift_mesh(mesh, scale, shift)
    
    z_max, x_max, y_max = bounding_box
    voxels = np.zeros((z_max, x_max, y_max), dtype=bool)
    
    for z in range(z_max):
        # Find intersecting triangles
        relevant_tris = [tri for tri in mesh if is_above_and_below(tri, z)]
        # Exclude triangles entirely on plane
        valid_tris = [tri for tri in relevant_tris if not is_intersecting_triangle(tri, z)]
        
        # Compute lines
        lines = []
        for tri in valid_tris:
            tri_lines = triangle_to_intersecting_lines(tri, z)
            lines.extend(tri_lines)
            
        # Rasterize
        prepixel = np.zeros((x_max, y_max), dtype=bool)
        for x in range(x_max):
            is_black = False
            rel_lines = find_relevant_lines(lines, x)
            target_ys = [generate_y(line, x) for line in rel_lines]
            
            for y in range(y_max):
                if is_black:
                    prepixel[x, y] = True
                if y in target_ys:
                    for line in rel_lines:
                        if on_line(line, x, y):
                            is_black = not is_black
                            prepixel[x, y] = True
            if is_black:
                # Error: unbalanced edge crossings
                pass
        voxels[z] = prepixel
    return voxels
```

### Parameters
- **Resolution:** Number of voxels for the largest dimension. Typical value: 100 [S3].
- **Width, Height, Depth:** Explicit grid dimensions [S2].
- **Padding:** Boolean flag (default True). Adds a 1-voxel border of empty space by expanding dimensions by 2 in each axis [S3].

### Edge Cases and Pitfalls
- **Degenerate Triangles:** Triangles with collinear or duplicate vertices are filtered out during scaling [S3].
- **Division by Zero:** Grid dimensions of zero are handled by ternary checks (e.g., `ax == 0.0 ? 0 : ...`) [S2].
- **Vertical Lines:** In slice rasterization, vertical lines ($x_0 == x_1$) return $Y=-1$, which skips them in scanline fill [S3].
- **Unbalanced Edges:** If `isBlack` is still True after processing all $y$ rows, an error is printed, indicating unbalanced edge crossings [S3].
- **Precision:** Floating-point comparisons for "on plane" or "on line" should use a small epsilon to avoid missing intersections due to precision errors [G].

## Subtopics

### [A-Buffer Solid Voxelization](1189-a-buffer-solid-voxelization.md)
A GPU-based solid voxelization technique that outputs a linked list of starting and ending voxels for each row and column in the voxel grid. It uses an A-buffer approach to handle multiple fragments per pixel by building and sorting linked lists of fragment data. Choose this when you need depth-sorted solid voxels for accurate interior rendering.

## Operating characteristics
- **Time Complexity:** $O(T \cdot V)$ for Triangle-AABB, where $T$ is the number of triangles and $V$ is the number of voxels in the triangle's AABB. For Slice-and-Rasterize, $O(Z \cdot T + Z \cdot X \cdot Y)$, where $Z$ is depth, $X, Y$ are width/height.
- **Memory Complexity:** $O(W \cdot H \cdot D)$ for the voxel grid.
- **Performance:** Depends heavily on mesh complexity and grid resolution. Triangle-AABB can be slow for high-resolution grids due to per-voxel intersection tests. Slice-and-Rasterize is generally faster for sparse grids but requires careful handling of 2D rasterization.
- **Strengths:** Simple to implement, produces exact occupancy for convex shapes, supports color interpolation.
- **Limitations:** Aliasing artifacts at low resolutions, slow for high-resolution grids with Triangle-AABB, requires robust intersection tests.

## Background
3D Grid Rasterization is a fundamental technique in voxelization, originating from early computer graphics research on converting polygonal models to volume data. It is widely used in volume rendering pipelines, particularly in differentiable rendering and medical imaging. The specific implementations cited here are from open-source libraries: `differentiable_volumetric_rendering` [S1], `voxelizer` [S2], and `mesh_vox` [S3].
