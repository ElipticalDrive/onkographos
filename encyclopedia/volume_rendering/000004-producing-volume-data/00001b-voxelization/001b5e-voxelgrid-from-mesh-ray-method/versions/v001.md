# VoxelGrid from Mesh (Ray Method)
Also called: CUDA Mesh Voxelizer, Mesh to Particle Cloud Conversion, Raycasting-based Voxelization, X-ray Voxelization

## Overview
This method converts a 3D triangle mesh into a discrete voxel grid by casting rays from voxel centers to determine occupancy. It distinguishes itself from rasterization-based siblings by relying on geometric intersection tests rather than screen-space projection, allowing it to robustly handle arbitrary mesh orientations and generate solid volumes or signed distance fields (SDFs) [S2, S3, unofficial]. It solves the problem of converting continuous surface representations into discrete volumetric data suitable for volume rendering or 3D printing [S1, unofficial].

## How it works
**Inputs:** A triangle mesh (OBJ or STL format) and a resolution parameter (voxel spacing or grid dimension).
**Outputs:** A voxel grid (binary occupancy, SDF values, or particle cloud) in formats such as OBJ, BINVOX, PLY, or custom binary.

**Data Structures:**
*   **Mesh:** List of triangles, each defined by three 3D vertices ($V_1, V_2, V_3$).
*   **Voxel Grid:** 3D array or sparse structure indexed by $(i, j, k)$.
*   **Ray:** Defined by origin $O$ and direction $D$.
*   **Intersection Data:** List of hit distances or coordinates.

**Parameters:**
*   `resolution`: Voxel grid spacing (e.g., 0.5 units). Must be finite and $> 10^{-6}$ [S3, unofficial].
*   `samples`: Number of random ray directions per voxel for open meshes. Default 1 (single direction) [S2, unofficial].
*   `double_thick`: Boolean flag. If true, handles double-sided geometry by checking `(intersections / 2) % 2 == 1` [S2, unofficial].
*   `narrow_band`: Optional distance threshold. Expands evaluation bounds and filters voxels where $|SDF| \le band$ [S3, unofficial].
*   `surface_only`: Boolean. If true, retains only voxels intersecting the surface, ignoring interior filling [S3, unofficial].

**Steps:**

1.  **Preprocessing:**
    *   Load mesh vertices and indices. Validate that position and index array lengths are multiples of 3 [S3, unofficial].
    *   Compute the Axis-Aligned Bounding Box (AABB) of the mesh: $bb_{min}, bb_{max}$ [S2, unofficial].
    *   Apply optional transforms: scale, center, translate, rotate, or crop [S3, unofficial].
    *   If `narrow_band` is provided, expand bounds: $bb_{min} -= band$, $bb_{max} += band$ [S3, unofficial].
    *   Calculate grid dimensions: $N_x = \lceil (bb_{max}.x - bb_{min}.x) / resolution \rceil$, similarly for $y, z$ [S3, unofficial].
    *   Calculate spacing: $spacing = \max(bb_{max} - bb_{min}) / (dim - 2)$ if using fixed dimension $dim$ [S2, unofficial].

2.  **Voxel Center Calculation:**
    *   For each voxel index $(i, j, k)$, compute the center coordinate:
        $$x = bb_{min}.x + (i + 0.5) \times resolution$$
        $$y = bb_{min}.y + (j + 0.5) \times resolution$$
        $$z = bb_{min}.z + (k + 0.5) \times resolution$$
    *   [G] Ensure coordinates are within the expanded bounds if `narrow_band` is active.

3.  **Ray Casting and Intersection:**
    *   **Single Ray (Closed Mesh):** Cast a ray from the voxel center along a fixed axis (typically +X) or multiple fixed axes.
        *   Origin: $O = (bb_{min}.x - 1.0, y, z)$ [S3, unofficial].
        *   Direction: $D = (1, 0, 0)$ [S3, unofficial].
        *   Max Distance: $max\_dist = (bb_{max}.x - O.x) + 1.0$ [S3, unofficial].
    *   **Multiple Rays (Open/Incomplete Mesh):** If `samples > 1`, generate random directions on a unit sphere for each sample.
        *   Generate uniform random $\theta \in [0, 2\pi)$ and $z \in [-1, 1]$.
        *   Compute direction components:
            $$D_x = \sqrt{1 - z^2} \cos(\theta)$$
            $$D_y = \sqrt{1 - z^2} \sin(\theta)$$
            $$D_z = \sqrt{1 - z^2} \cos(\theta)$$
        *   Note: Some implementations use $\cos(\theta)$ for both $x$ and $z$ components [S2, unofficial].
    *   **Intersection Test:** For each ray, iterate over all mesh triangles and perform the Möller–Trumbore intersection test [S2, unofficial].
        *   Let triangle edges be $E_1 = V_2 - V_1$, $E_2 = V_3 - V_1$.
        *   Compute determinant: $det = \text{dot}(E_1, \text{cross}(D, E_2))$.
        *   If $|det| < \epsilon$, no intersection.
        *   Compute inverse: $inv\_det = 1 / det$.
        *   Compute barycentric coordinates:
            $$u = \text{dot}(O - V_1, \text{cross}(D, E_2)) \times inv\_det$$
            $$v = \text{dot}(D, \text{cross}(O - V_1, E_1)) \times inv\_det$$
            $$t = \text{dot}(E_2, \text{cross}(O - V_1, E_1)) \times inv\_det$$
        *   Intersection if $0 \le u \le 1$, $0 \le v \le 1$, $u + v \le 1$, and $t > \epsilon$ [S2, unofficial].
    *   **Precision Handling:**
        *   Collect all intersection distances $t$ (or hit coordinates).
        *   Sort intersections to correct floating-point ordering errors [S3, unofficial].
        *   Advance ray origin by a small epsilon (e.g., $10^{-4}$) after each hit to prevent re-hitting the same face [S3, unofficial].
        *   Limit hits to a maximum count (e.g., 100,000) to prevent infinite loops on degenerate geometry [S3, unofficial].

4.  **Occupancy Determination:**
    *   **Parity Rule:** Count the number of intersections $N_{int}$ to the right of the voxel center (or along the ray).
        *   If `double_thick` is false: $is\_inside = (N_{int} \pmod 2) \neq 0$ [S3, unofficial].
        *   If `double_thick` is true: $is\_inside = ((N_{int} / 2) \pmod 2) \neq 0$ [S2, unofficial].
    *   **Voting (Multiple Samples):** If `samples > 1`, vote on the majority result of all sampled rays. If the majority indicates "inside", mark as inside [S2, unofficial].

5.  **SDF and Filtering (Optional):**
    *   Compute the distance from the voxel center to the mesh surface: $d = \text{mesh.distance}(center)$ [S3, unofficial].
    *   Assign SDF value: $SDF = -d$ if inside, $SDF = d$ if outside [S3, unofficial].
    *   Apply `narrow_band` filter: Keep voxel only if $|SDF| \le band$ [S3, unofficial].
    *   Apply `surface_only` filter: Keep voxel only if it intersects the surface (often determined by proximity or direct intersection) [S3, unofficial].

6.  **Output Generation:**
    *   Save the resulting voxel data to the specified format (OBJ, BINVOX, PLY, etc.) [S2, S3, unofficial].

**Pseudocode:**

```python
def voxelize_mesh(mesh, resolution, samples=1, double_thick=False, narrow_band=None, surface_only=False):
    # 1. Preprocessing
    bb_min, bb_max = compute_aabb(mesh.vertices)
    
    if narrow_band is not None:
        bb_min -= narrow_band
        bb_max += narrow_band
        
    # Calculate grid dimensions
    dim_x = ceil((bb_max.x - bb_min.x) / resolution)
    dim_y = ceil((bb_max.y - bb_min.y) / resolution)
    dim_z = ceil((bb_max.z - bb_min.z) / resolution)
    
    grid = empty_3d_array(dim_x, dim_y, dim_z)
    
    # 2. Iterate over voxels
    for i in range(dim_x):
        for j in range(dim_y):
            for k in range(dim_z):
                # Compute voxel center
                cx = bb_min.x + (i + 0.5) * resolution
                cy = bb_min.y + (j + 0.5) * resolution
                cz = bb_min.z + (k + 0.5) * resolution
                
                inside_votes = 0
                total_samples = samples if samples > 1 else 1
                
                for s in range(total_samples):
                    # Determine ray direction
                    if total_samples == 1:
                        # Single ray along +X
                        ray_origin = Vec3(bb_min.x - 1.0, cy, cz)
                        ray_dir = Vec3(1.0, 0.0, 0.0)
                    else:
                        # Random direction on sphere
                        theta = random_uniform(0, 2 * PI)
                        z = random_uniform(-1, 1)
                        r_xy = sqrt(1 - z*z)
                        ray_dir = Vec3(r_xy * cos(theta), r_xy * sin(theta), r_xy * cos(theta))
                        ray_origin = Vec3(cx, cy, cz)
                    
                    # Cast ray
                    intersections = []
                    current_origin = ray_origin
                    max_dist = (bb_max.x - current_origin.x) + 1.0
                    
                    # Limit iterations to prevent infinite loops
                    for _ in range(100000):
                        hit_t = infinity
                        hit_tri = None
                        
                        # Möller-Trumbore intersection for all triangles
                        for tri in mesh.triangles:
                            t, u, v = moller_trumbore(current_origin, ray_dir, tri)
                            if t is not None and t > EPSILON and t < max_dist:
                                if t < hit_t:
                                    hit_t = t
                                    hit_tri = tri
                        
                        if hit_t == infinity:
                            break
                            
                        intersections.append(hit_t)
                        
                        # Advance origin to prevent re-hitting
                        current_origin = ray_origin + ray_dir * (hit_t + 1e-4)
                        max_dist -= (hit_t + 1e-4)
                        if max_dist <= 0:
                            break
                    
                    # Sort intersections for parity check
                    intersections.sort()
                    
                    # Determine inside status
                    n_intersections = len(intersections)
                    is_inside = False
                    if double_thick:
                        is_inside = (n_intersections // 2) % 2 != 0
                    else:
                        is_inside = n_intersections % 2 != 0
                        
                    if is_inside:
                        inside_votes += 1
                
                # Voting for open meshes
                if total_samples > 1:
                    is_inside = inside_votes > total_samples / 2
                
                # 3. SDF and Filtering
                if surface_only:
                    # Check if voxel intersects surface (simplified: check distance)
                    dist = mesh.distance_to_point(Vec3(cx, cy, cz))
                    if dist > resolution * 0.5: # Heuristic
                        continue
                    grid[i, j, k] = 1
                else:
                    # Compute SDF
                    dist = mesh.distance_to_point(Vec3(cx, cy, cz))
                    sdf_val = -dist if is_inside else dist
                    
                    if narrow_band is not None:
                        if abs(sdf_val) <= narrow_band:
                            grid[i, j, k] = sdf_val
                        else:
                            grid[i, j, k] = 0 # Or empty
                    else:
                        grid[i, j, k] = 1 if is_inside else 0
                        
    return grid
```

**Edge Cases and Pitfalls:**
*   **Double-thick meshes:** Standard parity fails for double-sided surfaces. Use `(intersections / 2) % 2` logic [S2, unofficial].
*   **Open meshes:** Single-ray parity is unreliable. Use multiple random samples and voting [S2, unofficial].
*   **Precision errors:** Ray re-hitting the same face causes infinite loops or incorrect counts. Advance origin by $10^{-4}$ [S3, unofficial]. Sort intersection points to handle precision-induced ordering errors [S3, unofficial].
*   **Malformed input:** OBJ/STL files with non-multiple-of-3 vertex/index arrays must be rejected or handled with explicit checks [S3, unofficial].
*   **Memory:** High resolutions (e.g., 256^3) can generate multi-gigabyte files. Use binary formats (BINVOX) instead of ASCII OBJ for large grids [S2, unofficial].

## Operating characteristics
*   **Time Complexity:** $O(N_v \cdot N_t)$, where $N_v$ is the number of voxels and $N_t$ is the number of triangles. With spatial acceleration structures (not detailed in sources), this can be reduced, but the sources describe brute-force triangle iteration [S2, S3, unofficial].
*   **Memory Complexity:** $O(N_v)$ for the output grid. Input mesh storage is $O(N_t)$.
*   **Performance:** GPU acceleration (CUDA) provides significant speedups (400x–2750x) over CPU [S2, unofficial].
    *   Example: Teapot (2464 triangles) at 512^3 resolution with 3 samples took 15.64 seconds on an NVIDIA GTX 970 [S2, unofficial].
    *   Example: Bunny (69664 triangles) at 512^3 took 417.62 seconds [S2, unofficial].
*   **Strengths:** Robust for closed meshes; generates solid volumes; supports SDF output; parallelizable [S2, S3, unofficial].
*   **Limitations:** Slow for high resolutions and complex meshes without acceleration structures; sensitive to floating-point precision; large file sizes for ASCII output [S2, unofficial].
*   **When to use:** When solid voxelization or SDF generation is required from a mesh, and performance is not the primary constraint or GPU acceleration is available.
*   **When not to use:** For real-time applications with very high-resolution grids without GPU support; for open meshes without sufficient sampling.

## Background
The method originates from computational fabrication and voxelization research. The CUDA implementation was developed for MIT's 6.807 Computational Fabrication course, leveraging the Möller–Trumbore intersection algorithm for GPU acceleration [S2, unofficial]. The Rust implementation (`voxelizer-rs`) extends this with multi-threading (Rayon), SDF support, and various export formats, addressing robustness issues like precision errors and open mesh handling [S3, unofficial]. It is used in 3D printing pipelines, volume rendering preprocessing, and geometric modeling [S2, S3, unofficial].
