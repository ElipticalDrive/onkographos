# VoxelGrid from Mesh (Ray Method)
Also called: CUDA Mesh Voxelizer, Mesh to Particle Cloud Conversion, Raycasting-based Voxelization, X-ray Voxelization

## Overview
This method converts a 3D triangle mesh into a discrete voxel grid by casting rays from voxel centers to determine occupancy [S2, S3]. It distinguishes itself from rasterization-based siblings by relying on geometric intersection tests rather than screen-space projection, allowing it to robustly handle arbitrary mesh orientations and generate solid volumes or signed distance fields (SDFs) [S2, S3]. It solves the problem of converting continuous surface representations into discrete volumetric data suitable for volume rendering or 3D printing [S1].

## How it works
**Inputs:** A triangle mesh (OBJ or STL format) and a resolution parameter (voxel spacing or grid dimension) [S2, S3].
**Outputs:** A voxel grid (binary occupancy, SDF values, or particle cloud) in formats such as OBJ, BINVOX, PLY, or custom binary [S2, S3].

**Data Structures:**
*   **Mesh:** List of triangles, each defined by three 3D vertices ($V_1, V_2, V_3$) [S2, S3].
*   **Voxel Grid:** 3D array indexed by $(i, j, k)$ [S3].
*   **Ray:** Defined by origin $O$ and direction $D$ [S2, S3].
*   **Intersection Data:** List of hit coordinates or distances [S3].

**Parameters:**
*   `resolution`: Voxel grid spacing (e.g., 0.5 units). Must be finite and $> 10^{-6}$ [S3].
*   `samples`: Number of random ray directions per voxel for open meshes. Default -1 implies 1 sample/direction [S2].
*   `double_thick`: Boolean flag. If true, handles double-sided geometry by checking `(intersections / 2) % 2 == 1` [S2].
*   `narrow_band`: Optional distance threshold. Expands evaluation bounds and filters voxels where $|SDF| \le band$ [S3].
*   `surface_only`: Boolean. If true, retains only voxels intersecting the surface, ignoring interior filling [S3].

**Steps:**

1.  **Preprocessing:**
    *   Load mesh vertices and indices. Validate that position and index array lengths are multiples of 3 [S3].
    *   Compute the Axis-Aligned Bounding Box (AABB) of the mesh: $bb_{min}, bb_{max}$ [S2, S3].
    *   Apply optional transforms: scale, center, translate, rotate, or crop [S3].
    *   If `narrow_band` is provided, expand bounds: $bb_{min} -= band$, $bb_{max} += band$ [S3].
    *   Calculate grid dimensions: $N_x = \lceil (bb_{max}.x - bb_{min}.x) / resolution \rceil$, similarly for $y, z$ [S3].
    *   Calculate spacing if using fixed dimension $dim$: $spacing = \max(bb_{max} - bb_{min}) / (dim - 2)$ [S2].

2.  **Voxel Center Calculation:**
    *   For each voxel index $(i, j, k)$, compute the center coordinate:
        $$x = bb_{min}.x + (i + 0.5) \times resolution$$
        $$y = bb_{min}.y + (j + 0.5) \times resolution$$
        $$z = bb_{min}.z + (k + 0.5) \times resolution$$
    *   [G] Ensure coordinates are within the expanded bounds if `narrow_band` is active.

3.  **Ray Casting and Intersection:**
    *   **Single Ray (Closed Mesh):** Cast a ray from the voxel center along a fixed axis (typically +X).
        *   Origin: $O = (bb_{min}.x - 1.0, y, z)$ [S3].
        *   Direction: $D = (1, 0, 0)$ [S3].
        *   Max Distance: $max\_dist = (bb_{max}.x - O.x) + 1.0$ [S3].
    *   **Multiple Rays (Open/Incomplete Mesh):** If `samples > 1`, generate random directions on a unit sphere for each sample.
        *   Generate uniform random $\theta \in [0, 2\pi)$ and $z \in [-1, 1]$.
        *   Compute direction components:
            $$D_x = \sqrt{1 - z^2} \cos(\theta)$$
            $$D_y = \sqrt{1 - z^2} \sin(\theta)$$
            $$D_z = \sqrt{1 - z^2} \cos(\theta)$$
        *   Note: Some implementations use $\cos(\theta)$ for both $x$ and $z$ components [S2].
    *   **Intersection Test:** For each ray, iterate over all mesh triangles and perform the Möller–Trumbore intersection test [S2].
        *   Let triangle edges be $E_1 = V_2 - V_1$, $E_2 = V_3 - V_1$.
        *   Compute determinant: $det = \text{dot}(E_1, \text{cross}(D, E_2))$.
        *   If $|det| < \epsilon$, no intersection.
        *   Compute inverse: $inv\_det = 1 / det$.
        *   Compute barycentric coordinates:
            $$u = \text{dot}(O - V_1, \text{cross}(D, E_2)) \times inv\_det$$
            $$v = \text{dot}(D, \text{cross}(O - V_1, E_1)) \times inv\_det$$
            $$t = \text{dot}(E_2, \text{cross}(O - V_1, E_1)) \times inv\_det$$
        *   Intersection if $0 \le u \le 1$, $0 \le v \le 1$, $u + v \le 1$, and $t > \epsilon$ [S2].
    *   **Precision Handling:**
        *   Collect all intersection distances $t$ (or hit coordinates).
        *   Sort intersections to correct floating-point ordering errors [S3].
        *   Advance ray origin by a small epsilon (e.g., $10^{-4}$) after each hit to prevent re-hitting the same face [S3].
        *   Limit hits to a maximum count (e.g., 100,000) to prevent infinite loops on degenerate geometry [S3].

4.  **Occupancy Determination:**
    *   **Parity Rule:** Count the number of intersections $N_{int}$ to the right of the voxel center (or along the ray).
        *   If `double_thick` is false: $is\_inside = (N_{int} \pmod 2) \neq 0$ [S3].
        *   If `double_thick` is true: $is\_inside = ((N_{int} / 2) \pmod 2) \neq 0$ [S2].
    *   **Voting (Multiple Samples):** If `samples > 1`, vote on the majority result of all sampled rays. If the majority indicates "inside", mark as inside [S2].

5.  **SDF and Filtering (Optional):**
    *   Compute the distance from the voxel center to the mesh surface: $d = \text{mesh.distance}(center)$ [S3].
    *   Assign SDF value: $SDF = -d$ if inside, $SDF = d$ if outside [S3].
    *   Apply `narrow_band` filter: Keep voxel only if $|SDF| \le band$ [S3].
    *   Apply `surface_only` filter: Keep voxel only if it intersects the surface (often determined by proximity or direct intersection) [S3].

6.  **Output Generation:**
    *   Save the resulting voxel data to the specified format (OBJ, BINVOX, PLY, etc.) [S2, S3].

**Pseudocode:**

```python
import math
import random

def voxelize_mesh(mesh_vertices, mesh_indices, resolution, samples=1, double_thick=False, narrow_band=None, surface_only=False):
    # 1. Preprocessing
    bb_min = [min(v[i] for v in mesh_vertices) for i in range(3)]
    bb_max = [max(v[i] for v in mesh_vertices) for i in range(3)]

    if narrow_band is not None:
        bb_min = [bb_min[i] - narrow_band for i in range(3)]
        bb_max = [bb_max[i] + narrow_band for i in range(3)]

    dim_x = math.ceil((bb_max[0] - bb_min[0]) / resolution)
    dim_y = math.ceil((bb_max[1] - bb_min[1]) / resolution)
    dim_z = math.ceil((bb_max[2] - bb_min[2]) / resolution)

    grid = {}

    for j in range(dim_y):
        for k in range(dim_z):
            cy = bb_min[1] + (j + 0.5) * resolution
            cz = bb_min[2] + (k + 0.5) * resolution

            for i in range(dim_x):
                cx = bb_min[0] + (i + 0.5) * resolution
                inside_votes = 0
                total_samples = samples if samples > 1 else 1

                for s in range(total_samples):
                    if total_samples == 1:
                        ray_origin = [bb_min[0] - 1.0, cy, cz]
                        ray_dir = [1.0, 0.0, 0.0]
                    else:
                        theta = random.uniform(0, 2 * math.pi)
                        z = random.uniform(-1, 1)
                        r_xy = math.sqrt(1 - z*z)
                        ray_dir = [r_xy * math.cos(theta), r_xy * math.sin(theta), r_xy * math.cos(theta)]
                        ray_origin = [cx, cy, cz]

                    intersections = []
                    current_origin = ray_origin[:]
                    max_dist = (bb_max[0] - current_origin[0]) + 1.0

                    for _ in range(100000):
                        hit_t = float('inf')
                        hit_found = False

                        for tri_idx in range(0, len(mesh_indices), 3):
                            v1 = mesh_vertices[mesh_indices[tri_idx]]
                            v2 = mesh_vertices[mesh_indices[tri_idx+1]]
                            v3 = mesh_vertices[mesh_indices[tri_idx+2]]

                            e1 = [v2[0]-v1[0], v2[1]-v1[1], v2[2]-v1[2]]
                            e2 = [v3[0]-v1[0], v3[1]-v1[1], v3[2]-v1[2]]
                            p = cross(ray_dir, e2)
                            det = dot(e1, p)
                            if abs(det) < 1e-6:
                                continue
                            inv_det = 1.0 / det
                            T = [current_origin[0]-v1[0], current_origin[1]-v1[1], current_origin[2]-v1[2]]
                            u = dot(T, cross(ray_dir, e2)) * inv_det
                            v = dot(ray_dir, cross(T, e1)) * inv_det
                            t = dot(e2, cross(T, e1)) * inv_det

                            if 0 <= u <= 1 and 0 <= v <= 1 and u + v <= 1 and t > 1e-6 and t < max_dist:
                                if t < hit_t:
                                    hit_t = t
                                    hit_found = True

                        if not hit_found:
                            break

                        intersections.append(hit_t)
                        current_origin = [ray_origin[0] + ray_dir[0]*(hit_t + 1e-4),
                                          ray_origin[1] + ray_dir[1]*(hit_t + 1e-4),
                                          ray_origin[2] + ray_dir[2]*(hit_t + 1e-4)]
                        max_dist -= (hit_t + 1e-4)
                        if max_dist <= 0:
                            break

                    intersections.sort()
                    n_intersections = len(intersections)

                    if double_thick:
                        is_inside = (n_intersections // 2) % 2 != 0
                    else:
                        is_inside = n_intersections % 2 != 0

                    if is_inside:
                        inside_votes += 1

                if total_samples > 1:
                    is_inside = inside_votes > total_samples / 2

                if surface_only:
                    dist = point_to_mesh_distance(mesh_vertices, mesh_indices, [cx, cy, cz])
                    if dist > resolution * 0.5:
                        continue
                    grid[(i, j, k)] = 1.0
                else:
                    dist = point_to_mesh_distance(mesh_vertices, mesh_indices, [cx, cy, cz])
                    sdf_val = -dist if is_inside else dist
                    if narrow_band is not None:
                        if abs(sdf_val) <= narrow_band:
                            grid[(i, j, k)] = sdf_val
                        else:
                            grid[(i, j, k)] = 0.0
                    else:
                        grid[(i, j, k)] = 1.0 if is_inside else 0.0

    return grid

def dot(a, b):
    return a[0]*b[0] + a[1]*b[1] + a[2]*b[2]

def cross(a, b):
    return [a[1]*b[2]-a[2]*b[1], a[2]*b[0]-a[0]*b[2], a[0]*b[1]-a[1]*b[0]]

def point_to_mesh_distance(vertices, indices, point):
    min_dist = float('inf')
    for tri_idx in range(0, len(indices), 3):
        v1 = vertices[indices[tri_idx]]
        v2 = vertices[indices[tri_idx+1]]
        v3 = vertices[indices[tri_idx+2]]
        e1 = [v2[0]-v1[0], v2[1]-v1[1], v2[2]-v1[2]]
        e2 = [v3[0]-v1[0], v3[1]-v1[1], v3[2]-v1[2]]
        p = [point[0]-v1[0], point[1]-v1[1], point[2]-v1[2]]
        a = dot(e1, e1); b = dot(e1, e2); c = dot(e2, e2)
        d = dot(e1, p); e = dot(e2, p)
        denom = a*c - b*b
        u = (b*c - e*b) / denom if denom != 0 else 0.0
        v = (a*e - d*b) / denom if denom != 0 else 0.0
        u = max(0.0, min(1.0, u))
        v = max(0.0, min(1.0, v))
        closest = [v1[0] + u*e1[0] + v*e2[0], v1[1] + u*e1[1] + v*e2[1], v1[2] + u*e1[2] + v*e2[2]]
        dist_sq = (point[0]-closest[0])**2 + (point[1]-closest[1])**2 + (point[2]-closest[2])**2
        if dist_sq < min_dist:
            min_dist = dist_sq
    return math.sqrt(min_dist)
```

**Edge Cases and Pitfalls:**
*   **Double-thick meshes:** Standard parity fails for double-sided surfaces. Use `(intersections / 2) % 2` logic [S2].
*   **Open meshes:** Single-ray parity is unreliable. Use multiple random samples and voting [S2].
*   **Precision errors:** Ray re-hitting the same face causes infinite loops or incorrect counts. Advance origin by $10^{-4}$ [S3]. Sort intersection points to handle precision-induced ordering errors [S3].
*   **Malformed input:** OBJ/STL files with non-multiple-of-3 vertex/index arrays must be rejected or handled with explicit checks [S3].
*   **Memory:** High resolutions (e.g., 256^3) can generate multi-gigabyte files. Use binary formats (BINVOX) instead of ASCII OBJ for large grids [S2].

## Operating characteristics
*   **Time Complexity:** Not given in the sources.
*   **Memory Complexity:** $O(N_v)$ for the output grid. Input mesh storage is $O(N_t)$.
*   **Performance:** GPU acceleration (CUDA) provides significant speedups (400x–2750x) over CPU [S2].
    *   Example: Teapot (2464 triangles) at 512^3 resolution with 3 samples took 15.64 seconds on an NVIDIA GTX 970 [S2].
    *   Example: Bunny (69664 triangles) at 512^3 took 417.62 seconds [S2].
*   **Strengths:** Robust for closed meshes; generates solid volumes; supports SDF output; parallelizable [S2, S3].
*   **Limitations:** Slow for high resolutions and complex meshes without acceleration structures; sensitive to floating-point precision; large file sizes for ASCII output [S2, S3].
*   **When to use:** When solid voxelization or SDF generation is required from a mesh, and performance is not the primary constraint or GPU acceleration is available [S2, S3].
*   **When not to use:** For real-time applications with very high-resolution grids without GPU support; for open meshes without sufficient sampling [S2].

## Background
The method originates from computational fabrication and voxelization research. The CUDA implementation was developed for MIT's 6.807 Computational Fabrication course, leveraging the Möller–Trumbore intersection algorithm for GPU acceleration [S2]. The Rust implementation (`voxelizer-rs`) extends this with multi-threading (Rayon), SDF support, and various export formats, addressing robustness issues like precision errors and open mesh handling [S3]. It is used in 3D printing pipelines, volume rendering preprocessing, and geometric modeling [S2, S3].
