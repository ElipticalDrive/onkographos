# NxNxN Cube Filter for Gradient Smoothing

Also called: 3D Box Filter for Gradients, Cubic Gradient Smoothing, N x N x N Gradient Filtering

## Overview
This method smooths gradient vectors in a 3D voxel grid by averaging the gradients of neighboring voxels within a cubic neighborhood. It solves the problem of high-frequency irregularities and noise in gradient fields, which can cause artifacts during isosurface extraction or volume rendering. It differs from its sibling [3D Box Filter for Voxel Averaging](1513-3d-box-filter-for-voxel-averaging.md) by operating on vector-valued gradient data rather than scalar voxel intensities, and from [Iterative Convolution and Thresholding for Noise Removal](1516-iterative-convolution-and-thresholding-for-noise-removal.md) by using a single-pass box filter without iterative refinement or thresholding.

## How it works
**Inputs:**
- A 3D grid of gradient vectors, typically stored as an array of `Vector3` (or equivalent) structures. Let the grid dimensions be $W \times H \times D$ (width, height, depth).
- An integer filter size $n$, which must be an odd number.

**Outputs:**
- A smoothed 3D grid of gradient vectors, same dimensions as input.

**Data Structures:**
- `gradients`: A 1D array or 3D array of size $W \times H \times D$, where each element is a 3-component floating-point vector $(g_x, g_y, g_z)$.
- `temp_average`: A temporary 3-component floating-point vector used for accumulation.
- `count`: An integer accumulator for the number of valid neighbors.

**Parameters:**
- $n$: The dimension of the cubic filter. Must be an odd number. Default value is 3 [S2, unofficial].

**Steps:**
1. For each voxel at coordinates $(x, y, z)$ where $0 \le x < W$, $0 \le y < H$, $0 \le z < D$:
   a. Calculate the radius $r = (n - 1) / 2$.
   b. Initialize `temp_average` to $(0, 0, 0)$ and `count` to 0.
   c. Iterate over $k$ from $z - r$ to $z + r$ (inclusive).
   d. Iterate over $j$ from $y - r$ to $y + r$ (inclusive).
   e. Iterate over $i$ from $x - r$ to $x + r$ (inclusive).
   f. If the coordinates $(i, j, k)$ are within the grid bounds ($0 \le i < W$, $0 \le j < H$, $0 \le k < D$):
      i. Add `gradients[i][j][k]` to `temp_average`.
      ii. Increment `count`.
   g. If `count` > 0:
      i. Divide each component of `temp_average` by `count` to get the averaged vector.
      ii. Normalize the averaged vector to unit length. [S2, unofficial]
   h. Store the resulting normalized vector in the output grid at $(x, y, z)$.

**Pseudocode:**
```python
def filter_nxnxn_gradients(gradients: List[List[List[Vector3]]], width: int, height: int, depth: int, n: int) -> List[List[List[Vector3]]]:
    """
    Applies an NxNxN cube filter to gradient vectors.
    
    Args:
        gradients: 3D array of Vector3 gradients.
        width, height, depth: Dimensions of the grid.
        n: Filter size (must be odd).
        
    Returns:
        Smoothed gradient grid.
    """
    if n % 2 == 0:
        raise ValueError("Filter size n must be an odd number.")
        
    radius = (n - 1) // 2
    smoothed_gradients = [[Vector3(0, 0, 0) for _ in range(depth)] for _ in range(height)]
    for z in range(depth):
        smoothed_gradients[z] = [[Vector3(0, 0, 0) for _ in range(width)] for _ in range(height)]

    for z in range(depth):
        for y in range(height):
            for x in range(width):
                average = Vector3(0, 0, 0)
                count = 0
                
                # Iterate over the NxNxN cube
                for k in range(z - radius, z + radius + 1):
                    for j in range(y - radius, y + radius + 1):
                        for i in range(x - radius, x + radius + 1):
                            # Check bounds
                            if 0 <= i < width and 0 <= j < height and 0 <= k < depth:
                                average += gradients[k][j][i]
                                count += 1
                
                if count > 0:
                    # Average
                    average.x /= count
                    average.y /= count
                    average.z /= count
                    
                    # Normalize
                    length = average.magnitude()
                    if length > 0:
                        average /= length
                    else:
                        average = Vector3(0, 0, 0)
                        
                smoothed_gradients[z][y][x] = average
                
    return smoothed_gradients
```

**Edge Cases and Pitfalls:**
- **Boundary Conditions:** Voxels near the grid boundaries have fewer neighbors. The method handles this by only summing valid neighbors and dividing by the actual count, effectively using a smaller averaging kernel at boundaries [S1, unofficial][S2, unofficial].
- **Zero Vector:** If the averaged gradient vector is zero (e.g., all neighbors are zero or cancel out), normalization is undefined. The pseudocode handles this by setting the result to a zero vector [S2, unofficial].
- **Return Value Bug:** In the original source code, the `sampleNxNxN` function returns a reference to a local variable `average`, which is undefined behavior and likely causes garbage values [S1, unofficial]. The pseudocode above avoids this by returning the value directly or storing it in the output array.
- **Filter Size:** The filter size $n$ must be odd to ensure a well-defined center voxel [S2, unofficial].

## Operating characteristics
- **Time Complexity:** $O(W \cdot H \cdot D \cdot n^3)$, where $W, H, D$ are grid dimensions and $n$ is the filter size. Each voxel requires $n^3$ vector additions and one normalization.
- **Memory Complexity:** $O(W \cdot H \cdot D)$ for the input and output gradient grids. Additional $O(1)$ space per voxel for temporary accumulation.
- **Strengths:** Simple to implement; effectively reduces high-frequency noise in gradients; preserves the general direction of gradients.
- **Limitations:** Blurs gradient details; computational cost increases cubically with $n$; boundary effects may cause slight inaccuracies near edges.
- **When to use:** When gradient noise causes artifacts in isosurface extraction or volume rendering, and computational resources allow for $O(n^3)$ per voxel.
- **When not to use:** When preserving fine gradient details is critical, or when performance is a major constraint with large $n$.
