# Incremental Voxel Training


## Overview
Incremental Voxel Training is a regularization strategy for sparse input scenarios that prevents the radiance field from overfitting to input views by suppressing the optimization of peripheral voxels in early training stages [S1]. It solves the problem where outer voxels acquire high density values near camera planes, hindering the convergence of inner geometry and causing degenerate solutions like holes or floaters [S1]. It sets itself apart from standard voxel optimization by dynamically restricting the active optimization domain to an expanding bounding box, whereas siblings like [3D Voxel Grid Smoothing](833-3d-voxel-grid-smoothing.md) focus on post-hoc regularization of geometry shape [S1].

## How it works
**Inputs and Outputs:**
*   **Input:** Voxel grid $V \in \mathbb{R}^{C \times N_x \times N_y \times N_z}$ representing the radiance field, where $C$ is the modality dimension and $N_x, N_y, N_z$ are grid dimensions [S1]. Current training iteration $i$ [S1].
*   **Output:** A set of optimized voxel features restricted to an expanding bounding box $B$ [S1].

**Data Structures:**
*   **Bounding Box $B$:** Defined by corner points $P_{min}, P_{max} \in \mathbb{R}^3$ [S1].
*   **Iteration Counter:** Integer $i$ [S1].
*   **Max Iteration:** Pre-defined integer $M$ [S1].

**Parameters:**
*   $M$: Maximum iteration steps for the increment process. Default: 256 [S1].
*   $P_{min\_init}$: Initial ratio for $P_{min}$.
    *   Bounded inward-facing scenes: $(0.2, 0.2, 0.2)$ [S1].
    *   Forward-facing scenes: $(0, 0, 0.995)$ [S1].
*   $P_{max\_init}$: Initial ratio for $P_{max}$.
    *   Bounded inward-facing scenes: $(0.8, 0.8, 0.8)$ [S1].
    *   Forward-facing scenes: $(1, 1, 1)$ [S1].

**Formulas:**
The expansion factor $r(i)$ is calculated as:
$$ r(i) = \min\left(\frac{i}{M}, 1\right) $$
[S1]

The bounding box corners $P_{min}$ and $P_{max}$ are computed using element-wise multiplication ($\odot$):
$$ P_{min} = (P_{min\_init} \times (1 - r(i))) \odot (N_x, N_y, N_z) $$
$$ P_{max} = (P_{max\_init} \times (1 - r(i)) + r(i)) \odot (N_x, N_y, N_z) $$
[S1]

**Steps:**
1.  Initialize the voxel grid $V$ and set iteration counter $i = 0$ [S1].
2.  Calculate $r(i)$ using the current iteration $i$ and max iterations $M$ [S1].
3.  Compute the bounding box corners $P_{min}$ and $P_{max}$ using the formulas above [S1].
4.  During the optimization step (e.g., gradient descent), only update the features of voxels whose coordinates fall within the bounding box defined by $P_{min}$ and $P_{max}$ [S1].
5.  Increment $i$ and repeat until convergence or $i \ge M$, at which point the bounding box covers the full grid [S1].

**Pseudocode:**
```python
def compute_voxel_mask(iteration, max_iterations, p_min_init, p_max_init, grid_dims):
    """
    Computes the active voxel indices for the current training step.
    
    Args:
        iteration: Current training iteration index i.
        max_iterations: Pre-defined max iteration steps M.
        p_min_init: Initial ratio tuple (px, py, pz) for P_min.
        p_max_init: Initial ratio tuple (px, py, pz) for P_max.
        grid_dims: Tuple (Nx, Ny, Nz) of grid dimensions.
        
    Returns:
        A list of (x, y, z) indices for voxels inside the bounding box.
    """
    # 1. Calculate expansion factor r(i)
    r_i = min(iteration / max_iterations, 1.0)
    
    # 2. Calculate bounding box corners in absolute voxel coordinates
    # P_min = (P_min_init * (1 - r(i))) * (Nx, Ny, Nz)
    # P_max = (P_max_init * (1 - r(i)) + r(i)) * (Nx, Ny, Nz)
    p_min = [p_min_init[j] * (1 - r_i) * grid_dims[j] for j in range(3)]
    p_max = [(p_max_init[j] * (1 - r_i) + r_i) * grid_dims[j] for j in range(3)]
    
    # 3. Generate mask indices for voxels inside the bounding box
    mask = []
    for x in range(int(p_min[0]), int(p_max[0]) + 1):
        for y in range(int(p_min[1]), int(p_max[1]) + 1):
            for z in range(int(p_min[2]), int(p_max[2]) + 1):
                mask.append((x, y, z))
    return mask
```

**Edge Cases and Pitfalls:**
*   **Sparse Inputs:** In sparse input scenarios, peripheral voxels close to the camera near planes may acquire high density values at the initial stage, hindering the optimization of inner voxels [S1]. This strategy specifically addresses this by freezing those peripheral voxels initially [S1].
*   **Boundary Precision:** The bounding box coordinates are continuous ratios scaled to integer grid dimensions [S1]. Implementation must handle the conversion from float ratios to integer indices carefully to ensure voxels on the boundary are included or excluded consistently [S1].

## Subtopics

### [Hybrid Regularization and Training Strategy](17808-hybrid-regularization-and-training-strategy.md)
A two-stage optimization method for voxel-based neural radiance fields that mitigates overfitting in explicit feature grids by leveraging an implicit neural network for initialization. It solves the problem of deterministic integration prone to overfitting at specific voxels when features are directly optimized, which leads to degenerate solutions like floaters or holes in sparse input scenarios. It sets itself apart from pure explicit regularization by using an intermediate implicit phase to provide a powerful initialization, and from pure implicit methods by discarding the network to allow direct grid optimization for higher final quality. Choose it when sparse inputs cause overfitting in explicit grids but pure implicit methods lack final quality. *   **Strengths:** Simple to implement; effectively mitigates overfitting in sparse scenarios without complex architectural changes [S1].
*   **Limitations:** Requires tuning of $M$, $P_{min\_init}$, and $P_{max\_init}$ based on scene type (inward-facing vs. forward-facing) [S1].

*   **When not to use:** Dense input scenarios where peripheral voxels do not cause early overfitting, making the expanding box constraint unnecessary overhead [S1].

## Background
Incremental Voxel Training was introduced in the paper "VGOS: Voxel Grid Optimization for View Synthesis from Sparse Inputs" [S1]. It was developed to address limitations in existing voxel-based NeRF methods (like DVGO) when dealing with sparse input views, where standard optimization leads to overfitting and degenerate geometry [S1]. The method builds on the principles of Voxel Grid Optimization [4131-voxel-grid-optimization.md] by adding a dynamic constraint on the optimization domain [S1].
