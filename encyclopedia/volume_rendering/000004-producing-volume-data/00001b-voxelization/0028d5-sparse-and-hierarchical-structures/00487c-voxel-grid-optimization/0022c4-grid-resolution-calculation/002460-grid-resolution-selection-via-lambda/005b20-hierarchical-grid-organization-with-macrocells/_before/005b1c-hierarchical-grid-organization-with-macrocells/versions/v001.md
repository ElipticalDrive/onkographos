# Hierarchical Grid Organization with Macrocells

Also called: Cazals, Drettakis, and Puech approach, Hierarchy of Uniform Grids (HUG)

## Overview
Hierarchical Grid Organization with Macrocells (HUG) is a sparse acceleration structure for volume rendering that partitions objects into a global uniform grid and recursively inserts smaller uniform grids into voxels containing dense clusters of objects [S1, unofficial]. It solves the problem of inefficient ray traversal in scenes with varying object densities by adapting grid resolution locally, unlike the single-resolution [Uniform Grid Construction](4876-uniform-grid-construction.md). It differs from [Sort-last Grid Construction](12788-sort-last-grid-construction.md) by maintaining a strict hierarchical grid topology rather than a flat sorted list [S1, unofficial].

## How it works
**Inputs:** A set of 3D objects with bounding boxes; parameters for group count ($N_g$) and delta-connectivity ($\Delta$).
**Outputs:** A hierarchical structure consisting of a global uniform grid containing references to sub-grids (macrocells) and leaf objects.

**Data Structures:**
1.  **Object Group:** A list of objects sharing a size category.
2.  **Cluster:** A subset of objects within a group, grouped by spatial proximity.
3.  **Uniform Grid:** A 3D array of cells. Each cell contains a list of objects or a reference to a sub-grid.
4.  **Sub-grid:** A Uniform Grid instance stored within a parent grid cell.

**Steps:**
1.  **Histogram Computation:** Compute a histogram of object sizes (e.g., bounding box volume or diagonal length) for all input objects [S1, unofficial].
2.  **Grouping:** Split objects into $N_g$ groups based on the histogram. Typically, $N_g=3$, creating groups for large, middle-size, and small objects [S1, unofficial].
3.  **Clustering:** For the middle-size and small-size groups, perform clustering based on the distance between objects. Objects are grouped into clusters if their separation is within the delta-connectivity threshold $\Delta$ [S1, unofficial].
4.  **Global Grid Construction:** Construct an initial global uniform grid for the large-size group objects. Objects are assigned to all voxels their bounding boxes overlap [S1, unofficial].
5.  **Sub-grid Construction:** For each cluster in the middle and small groups, if the cluster contains a sufficient number of objects (threshold not specified in sources), construct a local uniform grid [S1, unofficial].
6.  **Recursive Insertion:** Insert these local sub-grids into the global grid. A sub-grid is placed in the global grid cell that best contains the cluster. Smaller grids are contained within the cells of larger grids [S1, unofficial].
7.  **Traversal:** Ray traversal uses "mail boxes" where sub-grids are treated as objects. The ray intersects the global grid, and if a cell contains a sub-grid, the ray traversal continues into that sub-grid [S1, unofficial].

**Parameters:**
*   $N_g$: Number of size groups. Typical value: 3 [S1, unofficial].
*   $\Delta$: Delta-connectivity threshold for clustering. Value must be set experimentally [S1, unofficial].
*   Cluster Size Threshold: Minimum number of objects to justify creating a sub-grid. Not given in the sources.

**Pitfalls:**
*   The method is not fully automatic; it requires manual tuning of $N_g$ and $\Delta$ [S1, unofficial].
*   Precision issues may arise if $\Delta$ is not scaled to the scene bounding box [S1, unofficial].
*   Ray traversal complexity increases due to the need to handle sub-grids as nested objects (mail boxes) [S1, unofficial].

## Subtopics

### Adaptive Grid
A variant that clusters objects based on distance and surface area, builds a BVH over clusters, and constructs grids for cluster leaves [S1, unofficial]. It differs from HUG by using a BVH for cluster management and constructing sub-voxel grids for dense voxels [S1, unofficial]. Choose it when scene complexity varies significantly in surface area density. Parameters include two merging criteria and a sub-voxel threshold [S1, unofficial].

## Operating characteristics
*   **Time Complexity:** Construction is $O(N \log N)$ or worse depending on clustering, due to histogramming and distance-based clustering [S1, unofficial].
*   **Memory Complexity:** Proportional to the number of objects plus the overhead of grid cells and sub-grid structures [S1, unofficial].
*   **Performance:** More efficient than uniform grids for sparse scenes but requires parameter tuning [S1, unofficial].
*   **Strengths:** Adapts to local object density; handles large and small objects separately [S1, unofficial].
*   **Limitations:** Requires manual parameter settings; traversal is complex due to nested grids [S1, unofficial].

## Background
The method was introduced by Cazals, Drettakis, and Puech in EG'95 and SCG'97 [S1, unofficial]. It is also known as the "hierarchy of uniform grids" (HUG) [S1, unofficial]. It was developed to address the limitations of recursive grids and uniform grids in handling scenes with varying object sizes and densities [S1, unofficial].
