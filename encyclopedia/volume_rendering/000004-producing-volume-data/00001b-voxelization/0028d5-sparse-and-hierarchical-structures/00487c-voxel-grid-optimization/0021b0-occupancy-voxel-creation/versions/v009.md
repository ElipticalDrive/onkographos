# Occupancy Voxel Creation

## Overview
Occupancy Voxel Creation converts a continuous density matrix into a boolean occupancy mask by applying a $2 \times 2 \times 2$ convolution to identify fully occupied blocks [S1, unofficial]. It returns a mask indicating which $2 \times 2 \times 2$ blocks are completely filled [S1, unofficial]. Not given in the sources.

## How it works
**Inputs:**
- `density_mat`: A 3D array containing continuous density values [S1, unofficial].

**Outputs:**
- `mask`: A boolean 3D array where `True` indicates a voxel is the minimum-coordinate corner of a fully occupied $2 \times 2 \times 2$ block [S1, unofficial].

**Data Structures:**
- `density_mat`: Input density field [S1, unofficial].
- `occupancy_mat`: Binary occupancy array, same shape as `density_mat` [S1, unofficial].
- `kernel`: 5D array for JAX convolution with shape $(2, 2, 2, 1, 1)$ [S1, unofficial].

**Steps:**
1. **Binary Conversion:** Convert the density matrix to a binary occupancy mask by setting values greater than zero to one [S1, unofficial].
   $$ \text{occupancy\_mat}[i, j, k] = \begin{cases} 1 & \text{if } \text{density\_mat}[i, j, k] > 0 \\ 0 & \text{otherwise} \end{cases} $$
2. **Reshape for Convolution:** Prepare the data for JAX's `conv_general_dilated` by adding batch and channel dimensions [S1, unofficial].
   $$ \text{data} = \text{occupancy\_mat}[\text{None}, :, :, :, \text{None}] $$
3. **Define Kernel:** Create a $2 \times 2 \times 2$ kernel of ones and expand it for JAX's convolution API [S1, unofficial].
   $$ \text{kernel} = \mathbf{1}_{2 \times 2 \times 2}[:, :, :, \text{None}, \text{None}] $$
4. **Convolution:** Perform a 3D convolution with stride 1 and 'SAME' padding [S1, unofficial].
   $$ \text{out} = \text{lax.conv\_general\_dilated}(\text{data}, \text{kernel}, (1, 1, 1), \text{'SAME'}, (1, 1, 1), (1, 1, 1), dn) $$
5. **Mask Extraction:** Identify blocks where all 8 voxels are occupied by checking if the convolution output equals 8 [S1, unofficial].
   $$ \text{mask} = \text{np.array}(\text{out} == 8) $$

**Pseudocode:**
```python
import numpy as np
import jax.numpy as jnp
from jax import lax

def create_occupancy_voxels(density_mat):
    """
    Converts a density matrix into a boolean occupancy mask of 2x2x2 blocks.
    
    Args:
        density_mat: 3D array of shape (H, W, D) with density values.
        
    Returns:
        mask: Boolean numpy array of shape (H, W, D).
    """
    # Step 1: Convert density to binary occupancy
    occupancy_mat = (density_mat > 0).astype(np.float32)
    
    # Step 2: Reshape for JAX convolution
    # Adds batch dimension (1) and channel dimension (1)
    data = occupancy_mat[None, :, :, :, None]
    
    # Step 3: Define 2x2x2 kernel of ones
    kernel = jnp.ones([2, 2, 2])[:, :, :, jnp.newaxis, jnp.newaxis]
    
    # Step 4: Perform convolution
    # dimension_numbers tuple for NWHC format [G]
    dn = lax.ConvDimensionNumbers(lhs_spec=('NWHC',), rhs_spec=('HWIO',), out_spec=('NWHC',))
    out = lax.conv_general_dilated(
        data, 
        kernel, 
        window_strides=(1, 1, 1), 
        padding='SAME',
        lhs_dilation=(1, 1, 1),
        rhs_dilation=(1, 1, 1),
        dimension_numbers=dn
    )
    
    # Step 5: Extract mask where sum is 8 (all 8 voxels occupied)
    mask = np.array(out.squeeze() == 8)
    
    return mask
```

**Parameters:**
- `density_mat`: Input density field [S1, unofficial].

## Subtopics

### [Mark Invisible Cells](4648-mark-invisible-cells.md)
Marks voxels not covered by any training camera with a density of -1, executed once before training. It differs from sibling methods by performing visibility culling rather than density-based block detection.

### [Occupancy Grid Filling](6913-occupancy-grid-filling.md)
Fills interior regions of an occupancy grid by identifying the "outside" label and setting all other background labels to occupied (1). It ensures that enclosed voids are treated as solid while preserving original non-zero data attached to occupied voxels.
