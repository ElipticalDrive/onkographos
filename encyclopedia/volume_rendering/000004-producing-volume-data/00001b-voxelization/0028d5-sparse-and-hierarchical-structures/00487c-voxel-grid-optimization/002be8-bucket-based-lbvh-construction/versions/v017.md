# Bucket-based LBVH construction

Also called: BVH Building, Bvh constructor, Fernandes and Walter LBVH construction

## Overview
Bucket-based LBVH construction builds a Bounding Volume Hierarchy (BVH) from voxel data by grouping voxels into dynamic buckets rather than a uniform grid with fixed brick sizes [S2, unofficial]. This approach addresses the inefficiency of fixed-grid methods in sparse volumes by adapting the spatial partitioning to the actual distribution of active voxels [S2, unofficial]. It sets itself apart from sibling methods like [Bounding Volume Optimization](3583-bounding-volume-optimization.md) by utilizing compute shaders for neighbor finding, cluster merging, and prefix scans to construct the hierarchy [S1, unofficial].

## How it works
**Inputs and Outputs:**
*   **Input:** A set of active voxels representing the volume geometry.
*   **Output:** A BVH structure enabling efficient ray traversal and empty-space skipping.

**Data Structures:**
*   **Voxel Data:** A collection of voxel positions and properties.
*   **Clusters:** Groups of voxels merged during construction.
*   **Bucket Texture:** Stores the index of the last voxel of each bucket (the bucket boundary voxel) [S1, unofficial][S2, unofficial].

**Parameters:**
*   `BVH_BUILDING_RADIUS`: A static constant defining the search radius for neighbors. Typical value: 100 [S1, unofficial].

**Formulas:**
Not given in the sources.

**Steps:**
1.  **Aggregate Data:** Call `aggregateSSBOData(volatileGPUData)` to prepare voxel data for processing [S1, unofficial].
2.  **Bucket Grouping:** Group voxels into buckets. Unlike uniform grids, bucket sizes are determined dynamically based on voxel density [S2, unofficial].
3.  **Neighbor Finding:** Use the `FIND_BEST_NEIGHBOR` compute shader to identify neighboring voxels within `BVH_BUILDING_RADIUS` [S1, unofficial].
4.  **Cluster Merging:** Use the `CLUSTER_MERGING` compute shader to merge neighboring voxels into clusters [S1, unofficial].
5.  **Reallocation:** Use the `REALLOCATE_CLUSTERS` compute shader to adjust cluster assignments [S1, unofficial].
6.  **Prefix Scan:** Perform a parallel prefix scan using `REDUCE_PREFIX_SCAN` and `DOWN_SWEEP_PREFIX_SCAN` to compute bucket boundaries and offsets [S1, unofficial].
7.  **Boundary Reset:** Use `RESET_LAST_POSITION_PREFIX_SCAN` to finalize boundary positions [S1, unofficial].
8.  **End Loop:** Use `END_LOOP_COMPUTATIONS` to finalize the BVH structure [S1, unofficial].

**Pseudocode:**
```python
def build_bucket_lbvhi(voxels, radius=100):
    # Step 1: Aggregate data
    gpu_data = aggregateSSBOData(voxels)
    # Step 2: Find neighbors within radius
    neighbors = find_best_neighbor(gpu_data, radius)
    # Step 3: Merge clusters based on neighbors
    clusters = cluster_merging(gpu_data, neighbors)
    # Step 4: Reallocate clusters if necessary
    clusters = reallocate_clusters(clusters)
    # Step 5: Compute prefix sums for bucket boundaries
    prefix_sum = reduce_prefix_scan(clusters)
    prefix_sum = down_sweep_prefix_scan(prefix_sum)
    # Step 6: Reset last positions
    last_positions = reset_last_position_prefix_scan(prefix_sum)
    # Step 7: Finalize BVH
    bvh = end_loop_computations(clusters, last_positions)
    return bvh

def aggregateSSBOData(voxels):
    # Packs voxel positions and properties into a contiguous buffer
    return [v.position for v in voxels]

def find_best_neighbor(data, radius):
    # Identifies neighboring voxels within BVH_BUILDING_RADIUS
    neighbors = {}
    for i, pos in enumerate(data):
        neighbors[i] = [j for j, p in enumerate(data) if sum((a-b)**2 for a,b in zip(pos, p)) <= radius**2]
    return neighbors

def cluster_merging(data, neighbors):
    # Merges neighboring voxels into clusters
    clusters = []
    visited = set()
    for i in range(len(data)):
        if i not in visited:
            cluster = [i]
            queue = [i]
            visited.add(i)
            while queue:
                curr = queue.pop(0)
                for nb in neighbors.get(curr, []):
                    if nb not in visited:
                        visited.add(nb)
                        cluster.append(nb)
                        queue.append(nb)
            clusters.append(cluster)
    return clusters

def reallocate_clusters(clusters):
    # Adjusts cluster assignments to balance load
    return [c for c in clusters if len(c) > 0]

def reduce_prefix_scan(clusters):
    # Computes prefix sums of cluster sizes
    sizes = [len(c) for c in clusters]
    prefix = [0]
    for s in sizes:
        prefix.append(prefix[-1] + s)
    return prefix

def down_sweep_prefix_scan(prefix):
    # Parallel down-sweep variant of prefix sum
    return prefix

def reset_last_position_prefix_scan(prefix):
    # Finalizes boundary positions using prefix sums
    return [prefix[i] - 1 for i in range(1, len(prefix))]

def end_loop_computations(clusters, last_positions):
    # Finalizes the BVH structure
    return {"clusters": clusters, "boundaries": last_positions}
```

**Edge Cases and Pitfalls:**
*   **Precision:** Floating-point precision in neighbor finding may cause missed connections in sparse regions [G].
*   **Boundaries:** Bucket boundaries must be correctly computed to avoid overlapping or empty buckets [S1, unofficial].
*   **Degenerate Input:** Empty volumes or single-voxel inputs require special handling to avoid division by zero or invalid memory access [G].

## Operating characteristics
*   **Performance:** Enables 2-3x higher frame rates than ray marching without empty-space skipping [S2, unofficial].
*   **Strengths:** Adapts to sparse data; efficient GPU parallelization [S2, unofficial].
*   **When to Use:** Sparse volumetric data where uniform grids waste memory [S2, unofficial].

## Background
Originated from Fernandes and Walter [FW20], who proposed grouping voxels into buckets for LBVH construction [S2, unofficial]. Zellmann et al. [ZHL19] used fixed brick sizes, while Fernandes and Walter improved upon this for sparse volumes [S2, unofficial].
