# Point Cloud Reconstruction from 2D Slices

Also called: 2D Slice to 3D Point Cloud, Shell Reconstruction from Slices

## Overview
This method reconstructs a 3D point cloud (representing a surface shell) from a series of aligned 2D image slices, typically binary masks derived from medical or microscopic imaging. It extracts boundary and interior points from each slice, assigns them depth coordinates based on slice spacing, and merges them into a single 3D structure. It differs from volumetric voxelization (e.g., [CT Slice Voxel Construction](8351-ct-slice-voxel-construction.md)) by producing a sparse set of surface points rather than a dense grid of voxels, making it suitable for mesh generation or surface visualization where memory efficiency is prioritized over volume density.

## How it works
**Inputs:**
- A directory of 2D image files (e.g., `.tif`).
- `slice_thickness`: Distance between slices in the z-axis.
- `xy_scale`: Scaling factor for x and y coordinates.
- `target_resolution`: Target width and height for resizing images.
- `threshold_min`, `threshold_max`: Range for binary mask creation.

**Outputs:**
- A numpy array of shape $(-1, 3)$ containing unique 3D points $[x, y, z]$ as `float32`.

**Data Structures:**
- `points`: A list of lists, where each inner list is $[x, y, z]$.
- `masks`: A list of 2D numpy arrays (uint8), padded with blank masks at the start and end.

**Parameters:**
- `slice_thickness`: Typical value 0.2 [S1, unofficial].
- `xy_scale`: Typical value 1.0 [S1, unofficial].
- `target_resolution`: Typical value $(100, 100)$ [S1, unofficial].
- `threshold`: Typical range $[0, 100]$ for binary mask generation [S1, unofficial].

**Steps:**
1. **Load and Preprocess:** Iterate through the input directory. Filter for image files (e.g., ending in `.tif`). Read each image in grayscale. Resize each image to `target_resolution` using bilinear or nearest-neighbor interpolation.
2. **Mask Generation:** For each resized image, create a binary mask. Pixels with values in $[threshold\_min, threshold\_max]$ are set to 255 (white); others are set to 0 (black).
3. **Padding:** Append a blank mask (all zeros) to the beginning and end of the mask list to handle boundary conditions for the first and last slices.
4. **Point Extraction Loop:** Initialize `depth` to 0. Iterate through the masks from index $1$ to $N-2$ (where $N$ is the total number of masks including padding). Let $M_{prev}$, $M_{curr}$, and $M_{next}$ be the masks at indices $i-1$, $i$, and $i+1$ respectively.
    a. **Previous Boundary Points:** Create a temporary mask $M_{prev\_slice}$ where pixels are taken from $M_{curr}$ only if the corresponding pixel in $M_{prev}$ is 0. Add all non-zero points from $M_{prev\_slice}$ to `points` at `depth`.
    b. **Next Boundary Points:** Create a temporary mask $M_{next\_slice}$ where pixels are taken from $M_{curr}$ only if the corresponding pixel in $M_{next}$ is 0. Add all non-zero points from $M_{next\_slice}$ to `points` at `depth`.
    c. **Contour Points:** Extract contours from $M_{curr}$ using a hierarchy retrieval mode (e.g., `RETR_TREE`) and approximation method (e.g., `CHAIN_APPROX_NONE`). Add all contour points to `points` at `depth`.
    d. **Depth Increment:** Increase `depth` by `slice_thickness`.
5. **Rescaling:** For each point $[x, y, z]$ in `points`, update $x \leftarrow x \times xy\_scale$ and $y \leftarrow y \times xy\_scale$.
6. **Deduplication:** Convert `points` to a numpy array of `float32`. Reshape to $(-1, 3)$. Remove duplicate points using a unique row operation.

**Pseudocode:**
```python
import cv2
import numpy as np
import os

def add_points(mask, points_list, depth):
    """Extracts coordinates from a binary mask and appends them to points_list."""
    # Get indices where mask value is 255
    mask_points = np.where(mask == 255)
    for ind in range(len(mask_points[0])):
        y = mask_points[0][ind]
        x = mask_points[1][ind]
        points_list.append([x, y, depth])

def reconstruct_point_cloud(image_folder, slice_thickness=0.2, xy_scale=1.0, 
                            target_res=(100, 100), threshold=(0, 100)):
    # 1. Load and resize images
    files = [f for f in os.listdir(image_folder) if f.endswith('.tif')]
    images = []
    for f in files:
        img = cv2.imread(os.path.join(image_folder, f), cv2.IMREAD_GRAYSCALE)
        img = cv2.resize(img, target_res)
        images.append(img)
    
    if not images:
        return np.empty((0, 3), dtype=np.float32)

    # 2. Create masks
    masks = []
    # Pad with blank mask at start
    masks.append(np.zeros_like(images[0], dtype=np.uint8))
    
    for img in images:
        mask = cv2.inRange(img, threshold[0], threshold[1])
        masks.append(mask)
        
    # Pad with blank mask at end
    masks.append(np.zeros_like(images[-1], dtype=np.uint8))
    
    # 3. Extract points
    points = []
    depth = 0.0
    
    # Iterate from index 1 to len(masks)-2
    for i in range(1, len(masks) - 1):
        prev_mask = masks[i-1]
        curr_mask = masks[i]
        next_mask = masks[i+1]
        
        # Points from previous slice boundary
        # Logic: Take curr_mask pixels where prev_mask is 0
        prev_slice = np.zeros_like(curr_mask)
        prev_slice[prev_mask == 0] = curr_mask[prev_mask == 0]
        add_points(prev_slice, points, depth)
        
        # Points from next slice boundary
        # Logic: Take curr_mask pixels where next_mask is 0
        next_slice = np.zeros_like(curr_mask)
        next_slice[next_mask == 0] = curr_mask[next_mask == 0]
        add_points(next_slice, points, depth)
        
        # Contour points from current slice
        # Note: cv2.findContours modifies the source image, so pass a copy if needed
        # RETR_TREE retrieves all contours; CHAIN_APPROX_NONE stores all points
        contours, _ = cv2.findContours(curr_mask, cv2.RETR_TREE, cv2.CHAIN_APPROX_NONE)
        for contour in contours:
            for point in contour:
                # point is [[x, y]]
                points.append([point[0][0], point[0][1], depth])
                
        depth += slice_thickness
        
    # 4. Rescale X and Y
    for i in range(len(points)):
        points[i][0] *= xy_scale
        points[i][1] *= xy_scale
        
    # 5. Convert to numpy and remove duplicates
    if not points:
        return np.empty((0, 3), dtype=np.float32)
        
    points_arr = np.array(points, dtype=np.float32)
    # Unique rows based on all 3 coordinates
    unique_points = np.unique(points_arr, axis=0)
    
    return unique_points
```

**Edge Cases and Pitfalls:**
- **Empty Slices:** If a slice contains no foreground pixels, the mask is all zeros. The logic still holds, but no points are added for that depth.
- **Boundary Conditions:** Padding with blank masks ensures that the first and last actual slices are processed correctly against a "null" neighbor, preventing edge artifacts where the object might abruptly start or end.
- **Duplicate Points:** Points may be added multiple times if they appear in both contour extraction and boundary slice logic, or if adjacent slices share boundary pixels. `np.unique` handles this.
- **Coordinate System:** The code assumes standard image coordinates (x horizontal, y vertical). The z-axis is discrete and determined by the loop index.
- **OpenCV Version:** `cv2.findContours` return value order changed between OpenCV 2.x and 3/4.x. The pseudocode uses the modern return format `(contours, hierarchy)`. [S1, unofficial]

## Operating characteristics
- **Time Complexity:** $O(N \cdot W \cdot H)$, where $N$ is the number of slices, and $W, H$ are the image dimensions. Contour extraction is linear in the number of pixels/boundaries.
- **Memory Complexity:** $O(P)$, where $P$ is the total number of extracted points before deduplication. The final output is $O(P_{unique})$.
- **Strengths:** Produces a lightweight representation suitable for rendering shells or generating meshes. Simple to implement.
- **Limitations:** Does not capture internal volume information. Resolution is limited by the input slice spacing and image resolution. Artifacts may occur if slices are not perfectly aligned or if the thresholding is inconsistent.
- **When to use:** When only the surface geometry is needed for visualization or meshing, and memory is constrained.
- **When not to use:** When volumetric analysis (e.g., density, internal structure) is required. Use [CT Slice Voxel Construction](8351-ct-slice-voxel-construction.md) or direct voxelization instead.

## Background
This method is a practical approach for converting 2D image stacks (such as TIFF sequences from microscopes or CT scanners) into 3D point clouds for visualization or further processing (e.g., mesh generation). It relies on basic image processing techniques (thresholding, contour detection) and geometric assembly. It is often used in bio-imaging and medical visualization pipelines where a quick 3D representation of a structure (like a tumor or cell) is needed without the computational cost of full volumetric rendering. The specific implementation described is derived from community solutions for creating PLY files from 2D image series.
