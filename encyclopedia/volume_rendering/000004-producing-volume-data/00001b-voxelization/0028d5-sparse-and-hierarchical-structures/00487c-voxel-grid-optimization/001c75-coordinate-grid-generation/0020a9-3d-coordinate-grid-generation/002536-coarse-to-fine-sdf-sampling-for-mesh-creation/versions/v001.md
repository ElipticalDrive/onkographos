# Coarse-to-Fine SDF Sampling for Mesh Creation

Also called: Speedup Mesh Creation via Coarse-to-Fine SDF Sampling

## Overview
This method accelerates the generation of 3D meshes from implicit surface representations by reducing the number of expensive neural network inference calls required to evaluate Signed Distance Functions (SDFs). It achieves this by first computing SDF values on a coarse grid, classifying regions as clearly inside or outside the surface, and only evaluating the neural network for points near the zero-crossing boundary at full resolution. This approach builds on [3D Coordinate Grid Generation](2333-3d-coordinate-grid-generation.md) to provide the necessary sample coordinates.

## How it works
The method assumes a trained decoder network capable of predicting SDF values given a latent vector and 3D coordinates. The input is the latent vector representing the shape, the target resolution $N$, and the voxel space bounds. The output is a PLY mesh file representing the isosurface.

### Data Structures
- **Voxel Grid**: A 3D array of size $N \times N \times N$.
- **Samples Array**: A 2D array of shape $(M, 4)$, where $M$ is the number of samples. Columns 0-2 are $(x, y, z)$ coordinates, and column 3 is the SDF value.
- **Classification Masks**: Boolean arrays or index lists for `pos_samples` (positive SDF), `neg_samples` (negative SDF), and `valid_samples` (near-zero SDF).

### Parameters
- $N$: Target resolution (e.g., 1024) [S1, unofficial].
- $N_{half}$: Coarse resolution, typically $N/2$ [S1, unofficial].
- `voxel_origin`: The minimum corner of the voxel space, typically $[-1, -1, -1]$ [S1, unofficial].
- `max_batch`: Maximum number of points to process in a single neural network inference pass [S1, unofficial].
- `threshold`: The tolerance for classifying a point as "valid" (near the surface). Not explicitly defined in sources, but implied by `check_valid` [S1, unofficial].

### Steps
1.  **Initialize Coarse Grid Parameters**:
    Calculate the voxel size for the coarse grid:
    $$ \text{voxel\_size}_{half} = \frac{2.0}{N_{half} - 1} $$
    where $N_{half} = N/2$ [S1, unofficial].

2.  **Generate Coarse Samples**:
    Generate sample coordinates for the half-resolution grid using `get_samples(N_{half}, voxel\_origin, voxel\_size_{half})` [S1, unofficial].

3.  **Infer Coarse SDF Values**:
    Evaluate the decoder network on the coarse samples:
    $$ \text{sdf\_values}_{half} = \text{infer\_samples}(\text{decoder}, \text{latent\_vec}, \text{samples}_{half}, \text{max\_batch}) $$
    This returns SDF values for all points in the $N_{half} \times N_{half} \times N_{half}$ grid [S1, unofficial].

4.  **Upsample to Full Resolution**:
    Use cubic upsampling to interpolate the coarse SDF values to the full resolution $N$:
    $$ \text{sdf\_values}_{upsampled} = \text{upsample\_cubic}(\text{sdf\_values}_{half}, N_{half}, N) $$
    The result is a 3D tensor of size $N \times N \times N$ [S1, unofficial].

5.  **Classify Regions**:
    Determine which full-resolution points are near the surface. Points with SDF values close to zero (within a small threshold relative to `voxel_size_half` or absolute) are marked as `valid_samples`. Points with positive SDF are `pos_samples`, and negative SDF are `neg_samples` [S1, unofficial].

6.  **Generate Full Resolution Coordinates**:
    Calculate the voxel size for the full grid:
    $$ \text{voxel\_size} = \frac{2.0}{N - 1} $$
    Generate sample coordinates for the full resolution grid using `get_samples(N, voxel\_origin, voxel\_size)` [S1, unofficial].

7.  **Assign Pre-computed SDF Values**:
    Initialize the SDF column (column 3) of the full-resolution samples array:
    - For `pos_samples`: Set SDF to a fixed positive value (e.g., 0.1) [S1, unofficial].
    - For `neg_samples`: Set SDF to a fixed negative value (e.g., -0.1) [S1, unofficial].
    - For `valid_samples`: Leave SDF as 0.0 or undefined, to be computed by the network [S1, unofficial].

8.  **Infer Fine SDF Values**:
    Evaluate the decoder network *only* on the `valid_samples` points to get precise SDF values near the surface. Assign these values to the corresponding entries in the samples array [S1, unofficial].

9.  **Extract and Reshape**:
    Extract the SDF values from the third column of the samples array and reshape them into an $N \times N \times N$ tensor [S1, unofficial].

10. **Mesh Generation**:
    Convert the SDF grid to a PLY mesh using `convert_sdf_samples_to_ply(SDF\_tensor, voxel\_origin, voxel\_size, output\_filename)` [S1, unofficial].

### Pseudocode
```python
def create_mesh_speedup(decoder, latent_vec, N, max_batch, output_filename):
    # Step 1: Initialize coarse parameters
    N_half = N // 2
    voxel_origin = [-1, -1, -1]
    voxel_size_half = 2.0 / (N_half - 1)
    
    # Step 2: Generate coarse samples
    samples_half = get_samples(N_half, voxel_origin, voxel_size_half)
    
    # Step 3: Infer coarse SDF values
    sdf_values_half = infer_samples(decoder, latent_vec, samples_half, max_batch)
    
    # Step 4: Upsample to full resolution
    sdf_values_upsampled = upsample_cubic(sdf_values_half, N_half, N)
    
    # Step 5: Classify regions
    # check_valid returns indices for pos, neg, and valid (near-zero) samples
    pos_samples, neg_samples, valid_samples = check_valid(sdf_values_upsampled, voxel_size_half)
    
    # Step 6: Generate full resolution coordinates
    voxel_size = 2.0 / (N - 1)
    samples_full = get_samples(N, voxel_origin, voxel_size)
    
    # Step 7: Assign pre-computed values
    # Initialize SDF column (index 3)
    samples_full[:, 3] = 0.0
    
    # Assign fixed values for non-valid regions
    if pos_samples is not empty:
        samples_full[pos_samples, 3] = 0.1
    if neg_samples is not empty:
        samples_full[neg_samples, 3] = -0.1
        
    # Step 8: Infer fine SDF values for valid samples only
    if valid_samples is not empty:
        valid_coords = samples_full[valid_samples, :3]
        sdf_values_valid = infer_samples(decoder, latent_vec, valid_coords, max_batch)
        samples_full[valid_samples, 3] = sdf_values_valid
        
    # Step 9: Extract and reshape
    sdf_tensor = samples_full[:, 3].reshape(N, N, N)
    
    # Step 10: Convert to mesh
    convert_sdf_samples_to_ply(sdf_tensor, voxel_origin, voxel_size, output_filename)
```

## Operating characteristics
- **Time Complexity**: Significantly faster than full-resolution sampling. The number of neural network inferences is reduced from $N^3$ to approximately $(N/2)^3 + N_{valid}$, where $N_{valid}$ is the number of points near the surface (typically much smaller than $N^3$).
- **Memory Complexity**: Requires storing the coarse SDF grid ($N_{half}^3$) and the full-resolution coordinate grid ($N^3$). The SDF tensor is $N^3$.
- **Strengths**: Reduces computational cost of SDF evaluation, which is often the bottleneck in implicit surface reconstruction.
- **Limitations**: Accuracy depends on the quality of the upsampling and the threshold for classifying "valid" points. If the threshold is too large, too many points are evaluated; if too small, the surface may be aliased or incomplete.
- **When to use**: When generating high-resolution meshes from neural implicit representations where inference is expensive.
- **When not to use**: When the surface is extremely complex or thin, requiring dense sampling everywhere.

## Background
This method is described in the unofficial repository [B1ueber2y/DIST-Renderer](https://github.com/B1ueber2y/DIST-Renderer) [S1, unofficial]. It is part of a pipeline for color training and mesh creation from 3D shapes. The specific function `create_mesh_speedup` is designed to optimize the mesh generation step.
