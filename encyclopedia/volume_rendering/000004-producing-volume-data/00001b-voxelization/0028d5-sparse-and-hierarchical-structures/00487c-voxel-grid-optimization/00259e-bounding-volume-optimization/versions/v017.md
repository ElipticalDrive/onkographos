# Bounding Volume Optimization

Also called: Adaptive Voxel-Array-Größe, BV Optimisation, Bounding Volume Optimisation, Bounding-Volume-Optimierung, SDF Bounding Volume Culling, Volumen-Größenanpassung

## Overview
Bounding Volume Optimization reduces the computational cost of voxel-based rendering by restricting ray traversal and Signed Distance Field (SDF) evaluation to the spatial extents of active geometry [S1, unofficial][S2]. It solves the problem of uniform computation waste in sparse scenes by eliminating false positives from empty regions and skipping expensive primitive evaluations for objects that do not contribute to the minimal distance field [S1, unofficial][S2]. Unlike [Grid Resolution Calculation](2908-grid-resolution-calculation.md), which adjusts the density of the grid, this method adjusts the spatial bounds of the data structure itself [S1, unofficial].

## How it works
**Inputs and Outputs:**
*   **Input:** A set of scene primitives (e.g., SDF primitives), their individual bounding volumes (typically Axis-Aligned Bounding Boxes, AABBs), and the global scene bounds.
*   **Output:** A trimmed 3D voxel array with dimensions matching the union of active object bounds, and a traversal logic that culls rays outside these bounds or skips primitives outside the current ray's bounding volume.

**Data Structures:**
1.  **Global Bounding Box:** A single AABB defining the active region of the voxel grid.
    *   Fields: `min` (vec3), `max` (vec3).
    *   Layout: Stored as two 3D vectors.
2.  **Primitive Bounding Boxes:** An AABB for each primitive used for early-out culling.
    *   Fields: `min` (vec3), `max` (vec3).
    *   Layout: Stored in a flat array or structure-of-arrays for cache efficiency.

**Steps:**
1.  **Compute Active Bounds:** Determine the union of all primitive bounding volumes to define the global active region. Let $B_{global} = [min_{global}, max_{global}]$.
2.  **Trim Voxel Array:** Resize the 3D voxel texture/array from a fixed power-of-two size (e.g., $512^3$) to the integer dimensions corresponding to $B_{global}$ at the target resolution [S1, unofficial].
    *   Formula: $D_x = \lceil \frac{max_{global,x} - min_{global,x}}{voxel\_size} \rceil$.
3.  **Traverse with Culling:** During raymarching, for each step:
    *   Check if the current ray origin is within $B_{global}$. If not, terminate or skip [S1, unofficial].
    *   For each primitive $i$, check if the ray intersects the primitive's bounding box $B_i$.
    *   If the ray does not intersect $B_i$, skip the evaluation of the primitive's SDF function $S_i(x)$ [S2].
    *   If the ray intersects $B_i$, evaluate $d_i = S_i(x)$ and update the minimum distance $d_{min} = \min(d_{min}, d_i)$ [S2].
4.  **Handle Shadows:** Apply similar bounding volume checks to shadow rays to skip SDF evaluations for objects occluded by the primary surface [S2].

**Pseudocode:**
```python
def raymarch_with_bv_optimization(ray_origin, ray_direction, primitives, global_bounds, voxel_size):
    """
    ray_origin: vec3
    ray_direction: vec3 (normalized)
    primitives: list of dict with keys 'sdf_func', 'bbox_min', 'bbox_max'
    global_bounds: dict with keys 'min', 'max'
    voxel_size: float
    """
    # Step 1: Check global bounds
    if not ray_intersects_aabb(ray_origin, ray_direction, global_bounds['min'], global_bounds['max']):
        return None  # Ray misses entire active volume

    t_min = 0.0
    t_max = 1000.0  # Max ray length
    
    # Calculate intersection with global bounds to limit traversal
    t_hit_global = ray_aabb_intersection(ray_origin, ray_direction, global_bounds['min'], global_bounds['max'])
    if t_hit_global is None:
        return None
    t_max = min(t_max, t_hit_global[1])
    t_min = max(t_min, t_hit_global[0])

    current_dist = t_max
    hit_primitive = None
    hit_normal = None

    # Step 2: Traverse within global bounds
    while t_min < current_dist:
        current_pos = ray_origin + ray_direction * t_min
        
        # Step 3: Evaluate primitives with BV culling
        min_sdf = current_dist
        for prim in primitives:
            # Check if ray intersects primitive's bounding box
            if not ray_intersects_aabb(ray_origin, ray_direction, prim['bbox_min'], prim['bbox_max']):
                continue  # Skip expensive SDF evaluation
            
            # Evaluate SDF
            d = prim['sdf_func'](current_pos)
            
            if d < min_sdf:
                min_sdf = d
                hit_primitive = prim

        # Step 4: Advance ray
        if min_sdf < 0.001:  # Hit threshold
            hit_normal = compute_normal(current_pos, primitives)
            break
        
        t_min += min_sdf
        current_dist = t_min

    return hit_primitive, hit_normal

def ray_intersects_aabb(origin, direction, min_b, max_b):
    """
    Returns (t_min, t_max) of intersection or None.
    Standard slab method.
    """
    t_min = (min_b.x - origin.x) / direction.x if direction.x != 0 else -float('inf')
    t_max = (max_b.x - origin.x) / direction.x if direction.x != 0 else float('inf')
    
    if t_min > t_max: t_min, t_max = t_max, t_min

    ty_min = (min_b.y - origin.y) / direction.y if direction.y != 0 else -float('inf')
    ty_max = (max_b.y - origin.y) / direction.y if direction.y != 0 else float('inf')
    
    if ty_min > ty_max: ty_min, ty_max = ty_max, ty_min

    if t_min > ty_max or ty_min > t_max:
        return None
    
    if ty_min > t_min: t_min = ty_min
    if ty_max < t_max: t_max = ty_max

    tz_min = (min_b.z - origin.z) / direction.z if direction.z != 0 else -float('inf')
    tz_max = (max_b.z - origin.z) / direction.z if direction.z != 0 else float('inf')
    
    if tz_min > tz_max: tz_min, tz_max = tz_max, tz_min

    if t_min > tz_max or tz_min > t_max:
        return None
    
    if tz_min > t_min: t_min = tz_min
    if tz_max < t_max: t_max = tz_max

    if t_min > t_max:
        return None
        
    return (t_min, t_max)
```

**Parameters:**
*   **Voxel Size:** Determined by the target resolution and scene scale. Not given in the sources.
*   **Threshold:** Distance threshold for termination (e.g., 0.001). Not given in the sources.

**Edge Cases and Pitfalls:**
*   **Precision:** Floating-point errors in ray-AABB intersection tests can cause rays to miss valid primitives or enter empty space. [G] Use epsilon comparisons in intersection tests.
*   **Degenerate Input:** If the scene has no geometry, global bounds are undefined. [G] Handle empty scenes by returning immediately.
*   **Sparse Regions:** If geometry is sparse within the global bounds, false positives may still occur. [S1, unofficial]

## Operating characteristics
*   **Time Complexity:** $O(N \cdot M)$ where $N$ is the number of voxels traversed and $M$ is the number of primitives. With BV optimization, $M$ is effectively reduced to the number of primitives intersecting the ray's bounding volume at each step.
*   **Memory Complexity:** $O(D_x \cdot D_y \cdot D_z)$ where $D$ are the trimmed dimensions. This is significantly less than a fixed power-of-two grid for sparse scenes [S1, unofficial].
*   **Measured Performance:** In a scene with 20 expensive primitives at 720p, enabling BV optimization reduced average frame duration from 41 ms (24 fps) to 21 ms (48 fps) [S2].
*   **Strengths:** Reduces memory bandwidth by loading only necessary voxels; reduces computation by skipping SDF evaluations for non-contributing primitives [S1, unofficial][S2].
*   **Limitations:** Requires pre-computation of bounding volumes; overhead of BV checks may outweigh benefits for very simple scenes or very few primitives [S2].
*   **When to Use:** Sparse scenes with expensive SDF primitives; scenes with large empty spaces [S1, unofficial][S2].
*   **When Not to Use:** Dense, uniformly filled volumes; scenes with very simple primitives where SDF evaluation is cheap [S2].

## Background
*   **Origin:** The concept is discussed in the context of raycasting-based voxel rendering to eliminate false positives and reduce memory usage [S1, unofficial]. It is also explored in CUDA-based raymarching of distance fields to minimize map function cost [S2].
*   **History:** The technique is part of the broader family of voxel grid optimization methods, sharing principles with spatial culling and data compression [S1, unofficial][S2].
*   **Usage:** Used in voxel-based physics simulations where dense voxel models serve as bounding boxes for rigid bodies [S1, unofficial].

## Background
Bounding Volume Optimization is a technique used in voxel-based rendering to improve performance by reducing the computational load associated with ray traversal and SDF evaluation. It is particularly useful in scenes with sparse geometry or expensive primitive evaluations. The method is discussed in the context of raycasting-based voxel rendering [S1, unofficial] and CUDA-based raymarching [S2].
