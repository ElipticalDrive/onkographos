# Iterative Convolution and Thresholding for Noise Removal
Also called: Noise Removal via Iterative Convolution and Thresholding, Stray Voxel Removal

## Overview
This method removes scattered noise voxels from a 3D voxel grid by iteratively applying a convolution with a filled circle kernel and zeroing out voxels below a threshold [S1, unofficial]. It is designed to clean up stray artifacts that persist after initial voxelization or smoothing, distinct from the broader smoothing operations of [3D Voxel Grid Smoothing](833-3d-voxel-grid-smoothing.md) which primarily address aliasing [S1, unofficial]. Unlike [NxNxN Cube Filter for Gradient Smoothing](864-nxnxn-cube-filter-for-gradient-smoothing.md) which preserves gradients, or [3D Box Filter for Voxel Averaging](1513-3d-box-filter-for-voxel-averaging.md) which averages values, this method acts as a binary cleaner, aggressively removing low-intensity noise while preserving significant signal [S1, unofficial].

## How it works
**Inputs and Outputs:**
- Input: A 3D voxel grid tensor `grid_cells` of shape $(D, H, W, C)$, where the last channel $C$ contains the alpha (opacity) values to be cleaned.
- Output: The modified `grid_cells` tensor with noise voxels set to zero.

**Data Structures:**
- `grid_cells`: A dense 3D tensor. No specific bit-packing is mentioned; standard floating-point representation is assumed for the alpha channel [S1, unofficial].
- `weights`: A 3D convolution kernel tensor of shape $(1, 1, K, K, K)$, where $K$ is `kernel_size`.

**Parameters:**
- `kernel_size`: Size of the convolution kernel. Default is 3 [S1, unofficial].
- `radius`: Radius for the filled circle kernel. Default is 1.0 [S1, unofficial].
- `threshold`: Minimum value for keeping a voxel after convolution. Default is 2 [S1, unofficial].
- `repeats`: Number of iterations. Default is 20 [S1, unofficial].

**Steps:**
1. **Kernel Generation:** Generate a 3D filled circle kernel of size `kernel_size` with the specified `radius`. The kernel represents a spherical or circular mask within the cubic bounds.
2. **Normalization:** Normalize the kernel by dividing all elements by the maximum value in the kernel. This ensures the peak response is 1.0 [S1, unofficial].
3. **Iteration:** For each repeat from 1 to `repeats`:
    a. **Convolution:** Apply 3D convolution to the alpha channel (`grid_cells[..., -1]`) using the normalized kernel. Use 'same' padding to preserve spatial dimensions [S1, unofficial].
    b. **Thresholding:** Identify voxels where the convolved output is strictly less than `threshold`. Set these voxels in the original `grid_cells` to 0 [S1, unofficial].

**Pseudocode:**
```python
import torch
import torch.nn.functional as F
import numpy as np

def filled_circle_kernel_3d(kernel_size, radius):
    """
    Generates a 3D filled circle (sphere) kernel.
    Assumes kernel_size is odd.
    """
    center = kernel_size // 2
    kernel = np.zeros((kernel_size, kernel_size, kernel_size), dtype=np.float32)
    for x in range(kernel_size):
        for y in range(kernel_size):
            for z in range(kernel_size):
                dist_sq = (x - center)**2 + (y - center)**2 + (z - center)**2
                if dist_sq <= radius**2:
                    kernel[x, y, z] = 1.0
    return torch.tensor(kernel)

def iterative_convolution_thresholding(grid_cells, kernel_size=3, radius=1.0, threshold=2.0, repeats=20):
    """
    Removes scattered noise voxels from the grid by iteratively applying a convolution 
    with a filled circle kernel and zeroing out voxels below a threshold.
    
    Args:
        grid_cells (torch.Tensor): Input voxel grid of shape (D, H, W, C).
        kernel_size (int): Size of the convolution kernel.
        radius (float): Radius for the filled circle kernel.
        threshold (float): Minimum value for keeping a voxel.
        repeats (int): Number of iterations.
        
    Returns:
        torch.Tensor: Cleaned grid_cells.
    """
    # Step 1 & 2: Generate and normalize kernel
    weights = filled_circle_kernel_3d(kernel_size, radius)
    # Add batch and channel dimensions for conv3d: (1, 1, K, K, K)
    weights = weights.unsqueeze(0).unsqueeze(0)
    weights /= weights.max()
    
    # Extract alpha channel for processing
    # grid_cells shape: (D, H, W, C)
    # conv3d expects (N, C, D, H, W)
    alpha_channel = grid_cells[..., -1] # Shape: (D, H, W)
    
    for _ in range(repeats):
        # Step 3a: Convolution
        # Unsqueeze for batch (N=1) and channel (C=1) dimensions
        input_tensor = alpha_channel.unsqueeze(0).unsqueeze(0) # Shape: (1, 1, D, H, W)
        output = F.conv3d(input_tensor, weights, padding='same') # Shape: (1, 1, D, H, W)
        output = output[0] # Remove batch and channel dims: (D, H, W)
        
        # Step 3b: Thresholding
        # Zero out grid cells where the convolved output is less than the threshold
        # Note: The source code applies this to the entire grid_cells tensor, 
        # but logically only the alpha channel or relevant channels should be zeroed 
        # if other channels contain valid data. The source code implies zeroing 
        # the whole cell if the alpha condition fails.
        mask = output < threshold
        grid_cells[mask] = 0
        
    return grid_cells
```

**Edge Cases and Pitfalls:**
- **Precision:** The threshold value (default 2.0) is unusually high for normalized alpha values (typically 0-1). This suggests the kernel normalization or input data scale might differ from standard assumptions, or the threshold is applied to a sum of weights rather than a mean [S1, unofficial]. Implementers should verify the scale of `grid_cells` values.
- **Boundaries:** 'Same' padding is used, which typically implies zero-padding. This can cause edge effects where boundary voxels are incorrectly zeroed out if they have no neighbors.
- **Degenerate Input:** If `grid_cells` is all zeros, the method remains stable but performs no work. If `kernel_size` is even, the center calculation in `filled_circle_kernel_3d` may need adjustment (integer division is used in the pseudocode) [G].

## Subtopics

### [Foreground Selection with Cleanup](11591-foreground-selection-with-cleanup.md)
Applies intensity thresholding and optional morphological cleanup (connected component filtering, opening, or legacy border removal) to select foreground voxels. This variant focuses on selecting the primary object rather than just removing scattered noise, often used in conjunction with or as a follow-up to iterative convolution [11591-foreground-selection-with-cleanup.md].

### Variance-based artifact removal
Removes false skin voxels caused by metallic streaking artifacts by selecting voxels with high local variance, as real skin exhibits higher variance than the slowly varying surroundings of metal artifacts. It computes local variance for each voxel using a spherical neighborhood (radius 2.0 voxels) and selects voxels exceeding a high-variance threshold to filter out artifacts and false skin [S2, unofficial].

## Operating characteristics
- **Time Complexity:** $O(R \cdot D \cdot H \cdot W \cdot K^2)$, where $R$ is repeats, $D,H,W$ are grid dimensions, and $K$ is kernel size. Each iteration involves a full 3D convolution.
- **Memory Complexity:** $O(D \cdot H \cdot W \cdot C)$ for the grid, plus $O(K^3)$ for the kernel.
- **Performance:** The method is computationally intensive due to the high number of default iterations (20) and the 3D convolution. However, it is effective at removing scattered noise that simpler filters might miss [S1, unofficial].
- **Strengths:** Effective at removing isolated noise voxels and stray artifacts. Simple to implement using standard convolution libraries.
- **Limitations:** Can erode thin structures if the threshold is too high or iterations too many. The default threshold of 2.0 is non-standard and requires careful tuning based on data scale. Not suitable for preserving fine details that have low local intensity.
- **When to use:** When scattered noise voxels are present after initial voxelization and other smoothing methods have failed to remove them without blurring the main structure.
- **When not to use:** When preserving thin structures or when the noise is correlated with the signal (e.g., metallic streaks in medical imaging, which require variance-based removal instead) [S2, unofficial].

## Background
The method originates from the Plenoxels project, an unofficial implementation for neural radiance fields, where it is used to clean up scattered voxels in the 3D grid representation [S1, unofficial]. The concept of iterative convolution and thresholding for noise removal is a general image processing technique adapted for 3D voxel grids. The variance-based variant is described in the context of multi-dimensional transfer function design for volume rendering, specifically for handling metallic streaking artifacts in medical imaging [S2, unofficial].
