# Iterative Convolution and Thresholding for Noise Removal
Also called: Noise Removal via Iterative Convolution and Thresholding, Stray Voxel Removal

## Overview
This method removes scattered noise voxels from a 3D voxel grid by iteratively applying a convolution with a filled circle kernel and zeroing out voxels whose convolved output falls below a specified threshold [S1, unofficial].

## How it works
**Inputs and Outputs:**
- Input: A 3D voxel grid `grid_cells` of shape $(D, H, W, C)$, where the last channel represents the alpha channel or occupancy probability [S1, unofficial].
- Output: The same grid `grid_cells` with noise voxels set to zero [S1, unofficial].

**Data Structures:**
- `grid_cells`: Tensor of shape $(D, H, W, C)$ storing voxel attributes [S1, unofficial].
- `kernel`: 3D tensor of shape $(K, K, K)$ storing convolution weights [S1, unofficial].

**Steps:**
1. Generate a 3D filled circle kernel of size $K \times K \times K$ with radius $R$ [S1, unofficial].
2. Normalize the kernel by dividing all values by its maximum value [S1, unofficial].
3. For each repeat iteration:
   a. Apply 3D convolution to the alpha channel (last channel) of `grid_cells` using the kernel with 'same' padding [S1, unofficial].
   b. Zero out `grid_cells` where the convolved output is less than the threshold [S1, unofficial].

**Formulas:**
The convolution operation computes the weighted sum of the alpha channel $A$ over the kernel $W$:
$$A'_{i,j,k} = \sum_{u=-\lfloor K/2 \rfloor}^{\lfloor K/2 \rfloor} \sum_{v=-\lfloor K/2 \rfloor}^{\lfloor K/2 \rfloor} \sum_{w=-\lfloor K/2 \rfloor}^{\lfloor K/2 \rfloor} A_{i+u, j+v, k+w} \cdot W_{u+\lfloor K/2 \rfloor, v+\lfloor K/2 \rfloor, w+\lfloor K/2 \rfloor}$$
where $A'_{i,j,k}$ is the convolved output at voxel $(i,j,k)$, $A$ is the extracted alpha channel, and $W$ is the normalized kernel [S1, unofficial]. The thresholding step then applies:
$$\text{grid\_cells}_{i,j,k,c} = \begin{cases} 0 & \text{if } A'_{i,j,k} < \text{threshold} \\ \text{grid\_cells}_{i,j,k,c} & \text{otherwise} \end{cases}$$
for all channels $c$ [S1, unofficial].

**Parameters:**
- `kernel_size`: Size of the convolution kernel. Default is 3 [S1, unofficial].
- `radius`: Radius for the filled circle kernel. Default is 1.0 [S1, unofficial].
- `threshold`: Minimum value for keeping a voxel. Default is 2 [S1, unofficial].
- `repeats`: Number of iterations. Default is 20 [S1, unofficial].

**Pseudocode:**
```python
import torch
import torch.nn.functional as F

def filled_circle_kernel_3d(size, radius):
    center = size // 2
    kernel = torch.zeros(size, size, size, dtype=torch.float32)
    for x in range(size):
        for y in range(size):
            for z in range(size):
                dist = ((x - center)**2 + (y - center)**2 + (z - center)**2)**0.5
                if dist <= radius:
                    kernel[x, y, z] = 1.0
    return kernel

def iterative_convolution_thresholding(grid_cells, kernel_size=3, radius=1.0, threshold=2, repeats=20):
    weights = filled_circle_kernel_3d(kernel_size, radius).unsqueeze(0).unsqueeze(0)
    weights /= weights.max()
    alpha = grid_cells[..., -1].unsqueeze(0).unsqueeze(0)
    for _ in range(repeats):
        output = F.conv3d(alpha, weights, padding='same')[0]
        mask = output < threshold
        grid_cells[mask] = 0
        alpha = grid_cells[..., -1].unsqueeze(0).unsqueeze(0)
    return grid_cells
```

## Subtopics

### [Foreground Selection with Cleanup](11591-foreground-selection-with-cleanup.md)
Foreground Selection with Cleanup isolates the relevant volumetric data (foreground) from the surrounding empty space (background) and removes small, scattered noise artifacts. It serves as a preprocessing step for volume rendering pipelines, particularly those utilizing parallel coordinates for transfer function design. Unlike its parent method, which handles scattered noise via iterative convolution, this method focuses on removing the large background volume to reduce computational complexity and applying morphological operations to clean up the remaining foreground structure.

### Variance-based artifact removal
Variance-based artifact removal removes false skin voxels caused by metallic streaking artifacts by selecting voxels with high local variance, as real skin exhibits higher variance than the slowly varying surroundings of metal artifacts [S2, unofficial]. It computes local variance for each voxel using a spherical neighborhood, then selects voxels exceeding a high-variance threshold to filter out artifacts and false skin [S2, unofficial]. The spherical neighborhood radius for variance calculation is 2.0 voxels [S2, unofficial].
