# Color Quantization via Histogram & Manhattan Distance Mapping

Also called: Frequency-based color mapping, Palette reduction

## Overview
This method reduces the number of unique colors in a voxel list to a specified limit by selecting the most frequent colors as a palette and mapping all other colors to the nearest palette entry using Manhattan distance [S1, unofficial].

## How it works
**Inputs:**
- A list of voxels, each containing an RGB color value [S1, unofficial].
- An integer `colorLimit` specifying the maximum number of colors in the output palette [S1, unofficial].

**Outputs:**
- A modified list of voxels where each voxel's color is snapped to one of the `colorLimit` most frequent original colors [S1, unofficial].

**Data Structures:**
- `Histogram`: A dictionary mapping `Color` (RGB tuple) to `int` (frequency count) [S1, unofficial].
- `Palette`: A list of `Color` objects, size at most `colorLimit` [S1, unofficial].
- `ColorMap`: A dictionary mapping original `Color` to mapped `Color` (palette entry) [S1, unofficial].

**Steps:**
1. **Handle Edge Cases:** If the voxel list is empty or quantization is disabled, return the original voxel list unchanged [S1, unofficial].
2. **Build Histogram:** Iterate through all voxels and increment the count for each color in the `Histogram` dictionary [S1, unofficial].
3. **Sort and Select Palette:** Sort the `Histogram` entries by frequency in descending order. Select the top `colorLimit` colors to form the `Palette` [S1, unofficial].
4. **Enforce Hard Cap:** The implementation enforces a hard cap of 256 on `colorLimit` via `colorLimit = Math.Min(colorLimit, 256)` [S1, unofficial].
5. **Build Color Map:** For each unique color $c_{orig}$ in the `Histogram`:
   - Compute the Manhattan distance to every color $c_{pal}$ in the `Palette`.
   - The Manhattan distance is defined as:
     $$d(c_1, c_2) = |R_1 - R_2| + |G_1 - G_2| + |B_1 - B_2|$$
     where $R, G, B$ are the red, green, and blue channel values of colors $c_1$ and $c_2$ [S1, unofficial].
   - Find the palette color $c_{best}$ that minimizes this distance.
   - Store the mapping $c_{orig} \rightarrow c_{best}$ in the `ColorMap` dictionary [S1, unofficial].
6. **Map Voxels:** Iterate through the original voxel list and replace each voxel's color with its mapped palette color from the `ColorMap` dictionary [S1, unofficial].

**Pseudocode:**
```python
def color_quantize_histogram_manhattan(voxels, color_limit):
    # Edge case: empty list or disabled quantization
    if not voxels or color_limit <= 0:
        return voxels

    # Enforce hard cap of 256
    color_limit = min(color_limit, 256)

    # Step 1: Build frequency histogram
    histogram = {}
    for voxel in voxels:
        color = voxel.color
        if color in histogram:
            histogram[color] += 1
        else:
            histogram[color] = 1

    # Step 2: Sort by frequency descending
    sorted_colors = sorted(histogram.keys(), key=lambda c: histogram[c], reverse=True)

    # Step 3: Select top colors as palette
    palette = sorted_colors[:color_limit]

    # Step 4: Build color map
    color_map = {}
    for orig_color in histogram.keys():
        best_pal_color = None
        min_dist = float('inf')
        
        for pal_color in palette:
            # Manhattan distance
            dist = abs(orig_color.r - pal_color.r) + \
                   abs(orig_color.g - pal_color.g) + \
                   abs(orig_color.b - pal_color.b)
            
            if dist < min_dist:
                min_dist = dist
                best_pal_color = pal_color
        
        color_map[orig_color] = best_pal_color

    # Step 5: Map voxels
    quantized_voxels = []
    for voxel in voxels:
        new_voxel = voxel.copy()
        new_voxel.color = color_map[voxel.color]
        quantized_voxels.append(new_voxel)

    return quantized_voxels
```

**Parameters:**
- `colorLimit`: Maximum number of colors allowed in the output palette. The implementation enforces a hard cap of 256 [S1, unofficial].

**Pitfalls:**
- Empty voxel lists or disabled quantization bypass the algorithm entirely and return the original list unchanged [S1, unofficial].
- Boundary checks are implicit since the algorithm only processes existing voxels [S1, unofficial].

## Subtopics

### Voxel Color Palette Mapping
A method to map 2D image pixels to solid block colors using high-precision Euclidean distance matching in RGB space against a central engine block database [S2, unofficial]. It calculates the Euclidean distance between the image pixel color and each color in the voxel registry, then selects the closest solid block color as the mapped voxel color [S2, unofficial]. Compiled 3D voxel textures may experience subtle color adjustments to align with the active voxel registry [S2, unofficial].

## Operating characteristics
**Time Complexity:** $O(N + C \log C + N \cdot M)$, where $N$ is the number of voxels, $C$ is the number of unique colors, and $M$ is `colorLimit` [S1, unofficial].

**Strengths:**
- Preserves the most common colors exactly [S1, unofficial].

**Limitations:**
- $O(N \cdot M)$ mapping can be slow for large $N$ and large $M$ [S1, unofficial].

**When to use:**
- When the most frequent colors are the most important [S1, unofficial].
