# Voxelization Optimization

## Overview
Voxelization Optimization refers to techniques that reduce the computational cost of generating voxel data from 3D geometry in real-time applications [S1, unofficial][S2, unofficial]. It addresses the bottleneck of high draw call counts and redundant geometric transformations during rasterization [S1, unofficial]. It is distinguished from its siblings by focusing on the generation pipeline efficiency (e.g., stream output, instancing, LOD selection) rather than post-generation data compression or structural simplification [S1, unofficial][S2, unofficial].

## How it works
The method optimizes the GPU-based rasterization process used to convert triangle meshes into voxel occupancy or density fields [S1, unofficial].

### Inputs and Outputs
- **Input:** 3D mesh geometry (vertices, indices), voxel grid parameters (resolution, bounds), and transformation matrices [S1, unofficial].
- **Output:** A voxel grid containing occupancy values or density data [S1, unofficial].

### Data Structures
- **Voxel Grid:** A 3D array or texture where each cell represents a voxel [S1, unofficial].
- **Stream Output Buffer:** A GPU buffer used to cache transformed vertex data [S1, unofficial].
- **Instance Data:** Per-slice transformation matrices or offsets used in instanced rendering [S1, unofficial].
- **Heightmap Arrays:** `minAltitude` and `maxAltitude` byte arrays of size $ChunkSize^2$ (e.g., 1024 bytes for $32 \times 32$ chunks), storing the lowest and highest occupied Y index per XZ column [S3, unofficial].

### Steps
1. **Mesh Simplification (LOD Selection):** For obstacles or static geometry, use a low-level-of-detail (LOD) mesh for voxelization to speed up the process [S1, unofficial].
2. **Stream Output for Deforming Meshes:** When voxelizing deforming meshes (e.g., skinned characters), use GPU stream output to cache the transformed vertices, avoiding recomputation for each slice [S1, unofficial].
3. **Instanced Slicing:** Instead of issuing a separate draw call for each voxel slice (plane), use instanced rendering to draw all slices in a single draw call, using instance IDs to specify the target slice [S1, unofficial].
4. **Static Object Caching:** Do not re-voxelize static objects unless necessary [S2, unofficial]. If an obstacle undergoes a simple analytic transformation (e.g., rigid translation/rotation), precompute the voxelization and apply the inverse transformation when accessing the 3D textures [S1, unofficial]. Note that dynamic lights intersecting static objects may force re-voxelization [S2, unofficial].
5. **Heightmap Optimization (Min/Max Altitude):** For voxel grids with vertical structure, maintain per-column minimum and maximum occupied voxel heights to skip empty or fully occupied columns during meshing [S3, unofficial]. Initialize `minAltitude` to $ChunkSize$ (32) for all columns, indicating initially empty columns [S3, unofficial]. On voxel addition at $(i, j, k)$, update the heightmaps to reflect the new occupied column [S3, unofficial]. On voxel removal at $(i, j, k)$, update the heightmaps to reflect the cleared column [S3, unofficial].

### Pseudocode
```python
def optimize_voxelization(mesh, voxel_grid, is_deforming=False, is_static=False):
    if is_static:
        if not voxel_grid.has_data():
            voxel_grid = standard_voxelization(mesh)
            voxel_grid.cache()
        return voxel_grid
    if is_deforming:
        transformed_vertices = apply_skinning_and_transform(mesh)
        voxel_grid = render_slices_instanced(transformed_vertices, voxel_grid)
        return voxel_grid
    lod_mesh = simplify_mesh(mesh)
    voxel_grid = standard_voxelization(lod_mesh)
    return voxel_grid

def update_heightmaps(min_altitude, max_altitude, chunk_size, x, z, y, operation):
    if min_altitude[x][z] == chunk_size:
        min_altitude[x][z] = y
        max_altitude[x][z] = y
        return
    if operation == 'add':
        min_altitude[x][z] = min(min_altitude[x][z], y)
        max_altitude[x][z] = max(max_altitude[x][z], y)
    elif operation == 'remove':
        min_altitude[x][z] = scan_column_for_min_y(x, z, voxel_grid)
        max_altitude[x][z] = scan_column_for_max_y(x, z, voxel_grid)

def standard_voxelization(mesh):
    # [G] Rasterize mesh triangles into a 3D occupancy grid
    return VoxelGrid()

def apply_skinning_and_transform(mesh):
    # [G] Apply model, view, projection, and skinning matrices to vertices
    return [vertex.transform() for vertex in mesh.vertices]

def render_slices_instanced(transformed_vertices, voxel_grid):
    # [G] Issue a single draw call using instance IDs to specify target slices
    for slice_id in range(voxel_grid.depth):
        voxel_grid.render_slice(slice_id, transformed_vertices)
    return voxel_grid

def simplify_mesh(mesh):
    # [G] Generate a low-polygon version of the mesh
    return Mesh(low_poly=True)

def scan_column_for_min_y(x, z, voxel_grid):
    # [G] Iterate over Y indices in the column to find the lowest occupied voxel
    for y in range(voxel_grid.height):
        if voxel_grid.is_occupied(x, y, z):
            return y
    return voxel_grid.height

def scan_column_for_max_y(x, z, voxel_grid):
    # [G] Iterate over Y indices in the column to find the highest occupied voxel
    for y in range(voxel_grid.height - 1, -1, -1):
        if voxel_grid.is_occupied(x, y, z):
            return y
    return -1
```

### Parameters
- **LOD Level:** The level of detail for obstacle meshes. Lower LOD reduces performance cost [S1, unofficial].
- **Chunk Size:** For heightmap optimization, typically 32x32, resulting in 1024-byte arrays for min/max altitude [S3, unofficial].

### Edge Cases and Pitfalls
- **Dynamic Lights:** Dynamic lights intersecting static objects may force re-voxelization, negating the benefits of static caching [S2, unofficial].
- **Empty Columns:** Heightmap optimization assumes vertical continuity; gaps in columns must be handled correctly during removal updates [S3, unofficial].

## Subtopics

### [32nd Bit Avoidance Modification](3351-32nd-bit-avoidance-modification.md)
The 32nd Bit Avoidance Modification is a set of adjustments to GPU-based solid voxelization and density computation pipelines to prevent conflicts with the reserved 32nd bit of standard 32-bit integer or floating-point formats. It ensures that the highest bit (bit 31) remains available for other purposes, such as flags or sign bits, by restricting voxel data to lower bits. This method is distinct from general sparse voxelization techniques by focusing specifically on bit-packing constraints within dense or semi-dense voxel grids.

### [Sparse Voxelization with Oracle and Parallel Scan](3687-sparse-voxelization-with-oracle-and-parallel-scan.md)
Sparse Voxelization with Oracle and Parallel Scan is a real-time, high-resolution technique for reconstructing 3D surface models from image-based inputs (calibrated RGB camera streams) using a coarse-to-fine voxel hierarchy. It solves the problem of on-the-fly surface reconstruction by iteratively refining a sparse list of voxels, using an oracle kernel to cull empty space and a parallel prefix sum scan to compact the list, ensuring that only relevant voxels are subdivided. Unlike bottom-up approaches or methods designed for static models, this method is top-down and optimized for interactive rates (e.g., >30 fps at 1024^3 resolution) by leveraging GPU parallelism for both computation and rendering.

### [Greedy Voxel Mesh Optimization](3979-greedy-voxel-mesh-optimization.md)
Greedy Voxel Mesh Optimization is a greedy algorithm that optimizes voxel mesh generation for 2D tile grids (e.g., Minecraft-like games) by merging adjacent identical tiles into larger rectangular quads to reduce draw calls. It differs from its siblings, [32nd Bit Avoidance Modification](3351-32nd-bit-avoidance-modification.md) and [Sparse Voxelization with Oracle and Parallel Scan](3687-sparse-voxelization-with-oracle-and-parallel-scan.md), by explicitly constructing maximal rectangular regions of uniform tile properties through iterative expansion, rather than relying on bit-packing tricks or parallel scan-based sparse structures.

### Stream Output for Voxelization
A technique to optimize voxelization of deforming meshes by caching transformed vertices, avoiding recomputation for each slice [S1, unofficial]. It uses GPU stream output to cache an entire buffer of transformed vertices during the voxelization of deforming meshes (e.g., skinned characters) [S1, unofficial].

### Min/Max Altitude Heightmap Optimization
Stores per-column minimum and maximum occupied voxel heights to skip empty or fully occupied columns during meshing [S3, unofficial]. On voxel addition (index > 0), `OnVoxelAdded(i, j, k)` updates the heightmaps to reflect the new occupied column. On voxel removal (index == 0), `OnVoxelRemoved(i, j, k)` updates the heightmaps to reflect the cleared column. The `minAltitude` array is a byte array of size $ChunkSize^2$ (1024 bytes for $ChunkSize=32$), storing the lowest occupied Y index per XZ column. The `maxAltitude` array is similarly sized, storing the highest occupied Y index. Initialization sets `minAltitude` to $ChunkSize$ for all columns, indicating initially empty columns [S3, unofficial].
