# Qubicle File Parsing
Also called: QBToSchematic, Qubicle QB to Schematic Conversion

## Overview
This method parses the binary `.qb` file format used by the Qubicle voxel editor to reconstruct a 3D voxel grid [S1, unofficial]. It handles both uncompressed and run-length encoded compressed data streams, applying axis orientation and color format transformations to produce a standardized list of voxel data [S1, unofficial].

## How it works
**Inputs:** A path to a `.qb` file.
**Outputs:** A list of `VoxelDTO` objects, each containing world coordinates $(X, Y, Z)$ and color $(R, G, B)$ [S1, unofficial].

### Data Structures
The file begins with a global header, followed by a sequence of matrix blocks [S1, unofficial].

**QB Header (uint32 fields):**
1. `version`: File format version.
2. `colorFormat`: Integer indicating color channel order (0 or 1).
3. `zAxisOrientation`: Integer indicating axis mapping (0 or 1).
4. `compressed`: Boolean flag (0 for uncompressed, non-zero for compressed).
5. `visibilityMaskEncoded`: Boolean flag.
6. `numMatrices`: Number of matrix blocks following the header.

**Matrix Header (variable size):**
1. `nameLength` (byte): Length of the matrix name string.
2. `name` (UTF8 string): Matrix identifier, length `nameLength`.
3. `sizeX` (uint): Width of the voxel grid.
4. `sizeY` (uint): Height of the voxel grid.
5. `sizeZ` (uint): Depth of the voxel grid.
6. `posX` (int): World X offset.
7. `posY` (int): World Y offset.
8. `posZ` (int): World Z offset.

**Compressed Stream Constants:**
- `CODE_FLAG`: Constant value `2`. Indicates a compressed run of voxels in the bitstream [S1, unofficial].
- `NEXT_SLICE_FLAG`: Constant value `6`. Indicates the end of the current Z-slice in the compressed stream [S1, unofficial].

### Algorithm Steps
1. **Parse Header:** Read the 6 uint32 values from the start of the file [S1, unofficial].
2. **Iterate Matrices:** Loop `numMatrices` times [S1, unofficial].
3. **Parse Matrix Header:** Read `nameLength`, then the UTF8 string, then the size and position fields [S1, unofficial].
4. **Parse Voxel Data:** Depending on the `compressed` flag in the global header, execute either the Uncompressed or Compressed parsing routine [S1, unofficial].
5. **Transform and Emit:** For each voxel identified, calculate world coordinates and transform color channels, then add to the output list [S1, unofficial].

#### Uncompressed Mode (`compressed == 0`)
Iterate through the voxel grid in Z-Y-X order (outer to inner loop: $z \in [0, sizeZ-1]$, $y \in [0, sizeY-1]$, $x \in [0, sizeX-1]$) [S1, unofficial].
1. Read 4 bytes as a raw `Color` integer [S1, unofficial].
2. Extract Alpha channel $A$ [S1, unofficial].
3. If $A \neq 0$, the voxel is present [S1, unofficial].
4. Calculate local coordinates $(x, y, z)$ [S1, unofficial].
5. Transform coordinates to world space $(X, Y, Z)$ using the `zAxisOrientation` rule [S1, unofficial].
6. Transform color channels $(R, G, B)$ using the `colorFormat` rule [S1, unofficial].
7. Emit voxel [S1, unofficial].

#### Compressed Mode (`compressed != 0`)
Initialize $z = 0$ and a linear index counter $index = -1$ [S1, unofficial].
1. Read 4-byte chunks (uint32) from the stream sequentially [S1, unofficial].
2. Let the raw 4-byte read be `data` (or `color` in compressed mode) [S1, unofficial].
3. If $data == CODE\_FLAG$:
    a. Read the next uint32 as `count` [S1, unofficial].
    b. Read the next uint32 as `color` [S1, unofficial].
    c. Loop `count` times:
        i. Increment $index$ [S1, unofficial].
        ii. Calculate local coordinates $(x, y)$ from $index$:
            $$x = (index + 1) \pmod{sizeX}$$
            $$y = \lfloor (index + 1) / sizeX \rfloor$$
        iii. Transform coordinates to world space $(X, Y, Z)$ using the `zAxisOrientation` rule [S1, unofficial].
        iv. Transform color channels using the `colorFormat` rule [S1, unofficial].
        v. Emit voxel [S1, unofficial].
4. If $data == NEXT\_SLICE\_FLAG$:
    a. Increment $z$ [S1, unofficial].
    b. Reset $index = -1$ [S1, unofficial].
    c. Continue reading the next chunk [S1, unofficial].
5. Repeat until the matrix data is exhausted [S1, unofficial].

### Coordinate Transformation Formulas
The transformation depends on the global `zAxisOrientation` flag [S1, unofficial].

**Uncompressed Mode:**
- If `zAxisOrientation == 1`:
  $$X = z + posX$$
  $$Z = x + posX$$
  $$Y = y + posY$$
- Else (`zAxisOrientation == 0`):
  $$X = x + posX$$
  $$Z = z + posZ$$
  $$Y = y + posY$$

**Compressed Mode:**
- If `zAxisOrientation == 1`:
  $$X = z + posZ$$
  $$Z = x + posX$$
  $$Y = y$$
- Else (`zAxisOrientation == 0`):
  $$X = x + posX$$
  $$Z = z + posZ$$
  $$Y = y$$

### Color Transformation Formulas
The transformation depends on the global `colorFormat` flag [S1, unofficial].

- If `colorFormat == 0`:
  $$R = data.B$$
  $$G = data.G$$
  $$B = data.R$$
- Else (`colorFormat == 1`):
  $$R = data.R$$
  $$G = data.G$$
  $$B = data.B$$

### Pseudocode
```python
import struct

class VoxelDTO:
    def __init__(self, x, y, z, r, g, b):
        self.x, self.y, self.z = x, y, z
        self.r, self.g, self.b = r, g, b

def _read_uint32(f):
    return struct.unpack('<I', f.read(4))[0]

def _read_byte(f):
    return struct.unpack('<B', f.read(1))[0]

def _read_int32(f):
    return struct.unpack('<i', f.read(4))[0]

def _read_utf8_string(f, length):
    return f.read(length).decode('utf-8')

def _transform_color(color_data, color_format):
    b_val = color_data & 0xFF
    g_val = (color_data >> 8) & 0xFF
    r_val = (color_data >> 16) & 0xFF
    if color_format == 0:
        return b_val, g_val, r_val
    else:
        return r_val, g_val, b_val

def _transform_coords(x, y, z, pos_x, pos_y, pos_z, z_axis_orientation):
    if z_axis_orientation == 1:
        return z + pos_x, y + pos_y, x + pos_x
    else:
        return x + pos_x, y + pos_y, z + pos_z

def parse_qb_file(file_path):
    with open(file_path, 'rb') as f:
        version = _read_uint32(f)
        color_format = _read_uint32(f)
        z_axis_orientation = _read_uint32(f)
        compressed = _read_uint32(f)
        visibility_mask_encoded = _read_uint32(f)
        num_matrices = _read_uint32(f)

        voxels = []

        for _ in range(num_matrices):
            name_length = _read_byte(f)
            name = _read_utf8_string(f, name_length)
            size_x = _read_uint32(f)
            size_y = _read_uint32(f)
            size_z = _read_uint32(f)
            pos_x = _read_int32(f)
            pos_y = _read_int32(f)
            pos_z = _read_int32(f)

            if compressed == 0:
                voxels.extend(_parse_uncompressed(f, size_x, size_y, size_z,
                                                 pos_x, pos_y, pos_z,
                                                 z_axis_orientation, color_format))
            else:
                voxels.extend(_parse_compressed(f, size_x, size_y, size_z,
                                                pos_x, pos_y, pos_z,
                                                z_axis_orientation, color_format))

        return voxels

def _parse_uncompressed(f, size_x, size_y, size_z, pos_x, pos_y, pos_z, z_axis_orientation, color_format):
    voxels = []
    for z in range(size_z):
        for y in range(size_y):
            for x in range(size_x):
                color_data = _read_uint32(f)
                alpha = (color_data >> 24) & 0xFF
                if alpha != 0:
                    r, g, b = _transform_color(color_data, color_format)
                    wx, wy, wz = _transform_coords(x, y, z, pos_x, pos_y, pos_z, z_axis_orientation)
                    voxels.append(VoxelDTO(wx, wy, wz, r, g, b))
    return voxels

def _parse_compressed(f, size_x, size_y, size_z, pos_x, pos_y, pos_z, z_axis_orientation, color_format):
    voxels = []
    z = 0
    index = -1
    while True:
        data_bytes = f.read(4)
        if not data_bytes:
            break
        data = struct.unpack('<I', data_bytes)[0]
        if data == 2:
            count = _read_uint32(f)
            color_data = _read_uint32(f)
            r, g, b = _transform_color(color_data, color_format)
            for _ in range(count):
                index += 1
                x = (index + 1) % size_x
                y = (index + 1) // size_x
                if z_axis_orientation == 1:
                    wx, wy, wz = z + pos_z, y, x + pos_x
                else:
                    wx, wy, wz = x + pos_x, y, z + pos_z
                voxels.append(VoxelDTO(wx, wy, wz, r, g, b))
        elif data == 6:
            z += 1
            index = -1
    return voxels
```

### Edge Cases and Pitfalls
- **Precision:** Coordinate calculations use integer arithmetic. Ensure no overflow if `pos` values are large [G].
- **Boundaries:** The compressed mode resets `index` at each slice. Ensure `sizeX` is not zero to avoid division by zero [G].
- **Degenerate Input:** If `numMatrices` is 0, return an empty list [S1, unofficial]. If a matrix has 0 volume, skip parsing [G].
- **Color Format Ambiguity:** The source notes define `colorFormat` 0 as swapping R and B. The exact byte extraction depends on the endianness of the `uint32` read [G].

## Operating characteristics
- **Time Complexity:** $O(N)$ where $N$ is the total number of voxels in the uncompressed case [G]. For compressed mode, it is $O(M)$ where $M$ is the number of 4-byte chunks in the stream, which is typically much smaller than $N$ if compression is effective [G].
- **Memory Complexity:** $O(N)$ to store the output voxel list [G]. The parser itself uses $O(1)$ auxiliary space [G].
- **Strengths:** Handles both compressed and uncompressed data; supports multiple matrices; explicit axis/color transformations [S1, unofficial].
- **Limitations:** Limited to the specific Qubicle `.qb` format; compression scheme is simple RLE with specific flags, not a general-purpose codec [G].

## Background
The Qubicle File Parsing method originates from the `FileToVox` project, an unofficial tool for converting various 3D formats into the Vox format used by MagicaVoxel [S1, unofficial]. The specific implementation for `.qb` files is found in the `QBToSchematic` class within the `FileToVox` repository [S1, unofficial]. Qubicle is a voxel art editor, and its `.qb` format stores scenes with multiple matrices [S1, unofficial].
