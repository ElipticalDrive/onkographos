# Voxel Interchange Format Serialization

Also called: voxel interchange format, voxel serialization

## Overview
Serializes a 3D voxel region into a flat 1D array accompanied by metadata for transport or storage [S1, unofficial].

## How it works
**Inputs:** A voxel grid access function `getVoxelDataFor(x, y, z)` returning voxel data, and region parameters: `length`, `width`, `depth` (integers), and `start` (array `[startX, startY, startZ]`) [S1, unofficial].
**Outputs:** A JSON object containing a packed 1D array of voxels, dimensions, and position [S1, unofficial].

**Data Structures:**
- `voxels`: A 1D array of size `length * width * depth` [S1, unofficial].
- `dimensions`: Array `[length, width, height]` [S1, unofficial].
- `position`: Array `[startX, startY, startZ]` [S1, unofficial].

**Steps:**
1. Initialize `length`, `width`, `depth`, and `start` coordinates [S1, unofficial].
2. Create a 1D array `voxels` of size `length * width * depth` [S1, unofficial].
3. Initialize index `idx = 0` [S1, unofficial].
4. Iterate `z` from `0` to `depth - 1`, `y` from `0` to `width - 1`, and `x` from `0` to `length - 1` [G]. (Corrected from source bounds that mixed absolute coordinates with relative dimensions)
5. Compute absolute coordinates `ax = start[0] + x`, `ay = start[1] + y`, `az = start[2] + z` [G].
6. Call `getVoxelDataFor(ax, ay, az)` and assign the result to `voxels[idx]` [S1, unofficial].
7. Increment `idx` [S1, unofficial].
8. Return the structure `{ "voxels": voxels, "dimensions": [length, width, height], "position": [start[0], start[1], start[2]] }` [S1, unofficial].

**Pseudocode:**
```python
def serialize_voxel_region(getVoxelDataFor, length, width, depth, start):
    # start is [startX, startY, startZ]
    height = width  # Source output uses 'height'; assumed equivalent to width [G]
    num_voxels = length * width * depth
    voxels = [0] * num_voxels
    idx = 0
    for z in range(depth):
        for y in range(width):
            for x in range(length):
                ax = start[0] + x
                ay = start[1] + y
                az = start[2] + z
                voxels[idx] = getVoxelDataFor(ax, ay, az)
                idx += 1
    return {
        "voxels": voxels,
        "dimensions": [length, width, height],
        "position": [start[0], start[1], start[2]]
    }
```

**Edge Cases and Pitfalls:**
- The reference implementation's loop bounds mix absolute world coordinates with relative dimensions, which may cause out-of-bounds access or incorrect indexing if not adapted to local chunk coordinates [S1, unofficial].
- The original loop variable `x` starting at `start[0]` combined with an additional `+ start[0]` offset causes double-offsetting for absolute coordinate lookups; using relative loop indices resolves this [G].
