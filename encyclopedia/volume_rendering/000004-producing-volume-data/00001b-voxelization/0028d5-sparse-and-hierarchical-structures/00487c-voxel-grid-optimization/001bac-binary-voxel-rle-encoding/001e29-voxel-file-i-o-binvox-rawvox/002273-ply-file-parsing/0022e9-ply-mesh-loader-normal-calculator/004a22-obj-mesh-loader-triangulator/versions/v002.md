# OBJ Mesh Loader & Triangulator
Also called: OBJ Mesh Loading and Triangulation, tinyobj OBJ Loader
## Overview
Reads an OBJ file, extracts vertex coordinates and face indices, and ensures all polygons are triangulated [S1, unofficial]. It differs from its parent [PLY Mesh Loader & Normal Calculator](2859-ply-mesh-loader-normal-calculator.md) by parsing a different file format and explicitly handling polygon-to-triangle conversion [S1, unofficial].
## How it works
**Inputs and Outputs:**
- Input: Path to an `.obj` file.
- Output: A list of 3D vertex coordinates and a list of triangle faces.
**Data Structures:**
- `vertices`: List of `(x, y, z)` coordinates.
- `faces`: List of `(i, j, k)` triangle indices.
**Steps:**
1. Initialize a reader configuration object and set `triangulate` to `true` [S1, unofficial].
2. Instantiate the OBJ reader.
3. Call the parse method with the file path and configuration [S1, unofficial].
4. Extract the vertex positions from the reader's internal storage.
5. Extract the face indices from the reader's internal storage.
**Pseudocode:**
```python
def load_obj(filepath):
    config = {"triangulate": True}
    reader = ObjReader()
    # Internal tokenization, vertex extraction, and triangulation logic [G]
    reader.ParseFromFile(filepath, config)
    vertices = reader.GetVertices()
    faces = reader.GetFaces()
    return vertices, faces
```
**Parameters:**
- `triangulate`: Boolean. If `true`, polygons are split into triangles [S1, unofficial].

## Subtopics

### OBJ Mesh Export
Writes a 3D mesh to an OBJ file, supporting optional per-vertex RGB colors [S2, unofficial].
**Steps:**
1. Open file for writing [S2, unofficial].
2. If `vert_rgb` is `None`, write vertex positions: `v x y z\n` [S2, unofficial].
3. If `vert_rgb` is provided, write vertex positions and colors: `v x y z r g b\n` [S2, unofficial].
4. For each triangle face, write `f i+1 j+1 k+1\n` (1-indexed) [S2, unofficial].
5. Close file [S2, unofficial].
**Layout:**
Each vertex line starts with `v` followed by 3 floats (position) and optionally 3 floats (RGB color) [S2, unofficial]. Each face line starts with `f` followed by 3 integers (1-indexed vertex indices) [S2, unofficial].
**Pseudocode:**
```python
def export_obj(filepath, vertices, triangles, vert_rgb=None):
    with open(filepath, 'w') as file:
        for i, v in enumerate(vertices):
            if vert_rgb is None:
                file.write("v %.4f %.4f %.4f\n" % (v[0], v[1], v[2]))
            else:
                file.write("v %.4f %.4f %.4f %.4f %.4f %.4f\n" % (v[0], v[1], v[2], vert_rgb[i][0], vert_rgb[i][1], vert_rgb[i][2]))
        for f in triangles:
            f_plus = [idx + 1 for idx in f]
            file.write("f %d %d %d\n" % (f_plus[0], f_plus[1], f_plus[2]))
```
