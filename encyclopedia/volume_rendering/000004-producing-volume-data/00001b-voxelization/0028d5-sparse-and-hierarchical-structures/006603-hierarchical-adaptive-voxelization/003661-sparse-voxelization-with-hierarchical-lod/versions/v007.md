# Sparse Voxelization with Hierarchical LoD

Also called: Fabre et al. voxelization, Fast Voxelization and Level of Detail for Microgeometry Rendering

## Overview
This method is a voxelization pipeline designed for high-frequency sparse geometric objects (fibers, hair, thin planes) that processes volumetric data into multiple Levels of Detail (LoD), preserving appearance information by separating geometric/directional data from material properties [S1]. It differs from general-purpose voxelizers by explicitly handling microgeometry via deterministic subsampling and encoding directional distributions into SGGX functions, rather than relying on simple occupancy or fixed-resolution grids [S1].

## How it works
**Inputs and Outputs:**
*   **Input:** A triangle mesh or a collection of splines (e.g., Catmull-Rom) [S1].
*   **Output:** A hierarchical sparse voxel structure with multiple LoD levels, where leaf nodes contain aggregated directional data (SGGX) and material properties [S1].

**Data Structures:**
1.  **Node Structure (Initial):** Each node stores:
    *   Translation $p=(x,y,z) \in \mathbb{R}^3$ [S1].
    *   Normal $n=(n_x,n_y,n_z) \in \mathbb{R}^3$ with $\|n\|=1$ [S1].
    *   Tangent $t=(t_x,t_y,t_z) \in \mathbb{R}^3$ with $\|t\|=1$ [S1].
    *   Properties ID: A 32-bit integer $id \in \mathbb{Z}^{32}$ [S1].
2.  **Per-Sample Data Structure:** Used during generation [S1]:
    *   2nd level index: integer, 4 bytes.
    *   3rd level index: integer, 4 bytes.
    *   Tangent data: u-integer, 3x1 bytes.
    *   Normal data: u-integer, 3x1 bytes.
    *   Material ID: u-integer, 4 bytes.

**Parameters:**
*   $Resolution$: The target resolution for the first two levels. The third level uses a fixed resolution of 8 voxels per axis in the examples [S1].
*   $\delta$: Maximum generation radius (e.g., max yarn radius or triangle edge length) [S1].
*   $S_{block}$: Block size [S1].

**Steps:**

1.  **Global Setup:** Compute a global bounding box $B(b_{min}, b_{max})$ and the maximum generation radius $\delta$ for the input model [S1].
2.  **Coordinate Transformation:** Transform samples from global space to normalized coordinates in range $[0, Resolution)$ using:
    $$ P_{normalized} = \frac{P - b_{min}}{b_{max} - b_{min}} $$
    $$ P_{volume} = P_{normalized} * Resolution $$
    [S1]
3.  **Block Filtering (GPU Kernel 1):** Generate maximum nodes for first-level blocks [S1]. Identify and discard empty blocks by checking control nodes using a distance function [S1]. For a block with position $P_{block}$ and 3D index $I_{block}$, compute the node position relative to the block $P_{relative}$:
    $$ P_{block} = S_{block} * I_{block} $$
    $$ P_{relative} = P_{volume} - P_{block} $$
    $$ Q = P_{relative} - \frac{S_{block}}{2} $$
    $$ D = \| \max(Q, 0) \| + \min(\max(Q_x, Q_y, Q_z), 0) $$
    Discard nodes where $D \ge \delta^2$ [S1].
4.  **Mask Generation:** Initialize a CPU flat array with space for the number of nodes per block and an extra counter [S1]. Use a kernel to write the number of valid nodes and their IDs for each block [S1]. Copy the mask to CPU to identify empty first-level blocks and generate an axis-aligned stencil for volumetric path tracing [S1].
5.  **Sparse Data Sampling (Kernels 2-4, for non-empty blocks only):**
    *   **Prepare Initial Nodes:** Reorder, duplicate, or generate additional data to ensure consecutive samples are accessible [S1].
    *   **Subsample:**
        *   *For Splines (Catmull-Rom):* Define the spline from 4 points and generate additional samples using linear spline interpolation [S1].
        *   *For Triangles:* Generate additional points on the surface using barycentric coordinates [S1].
        *   *Distribution:* Distribute samples equally based on kernel indices (not random) [S1]. For triangles, weight sample count by relative area to the largest triangle in the model [S1].
    *   **Generate Voxel Nodes:** Create voxel nodes from the new samples [S1].
6.  **Sample Gathering:** Move samples to a grid-like structure [S1]. Save only the last sample generated at each voxel asynchronously to avoid implicit ordering of draw calls [S1].
7.  **Block Aggregation:** Order samples by second-level block ID [S1]. Use a kernel to detect vector positions where the ID changes to determine block start positions and sample counts [S1].
8.  **Directional Data Encoding:** Compute a distribution histogram for directional data (normals/tangents) at every voxel with density $> 0$ [S1]. Fit each computed histogram to an SGGX function [18] to encode the distribution using 6 values [S1].

**Pseudocode:**

```python
import math

def sparse_voxelization_hierarchical_lod(nodes, resolution, delta, S_block, max_triangle_area):
    # 1. Global Setup
    b_min = [min(n.position[i] for n in nodes) for i in range(3)]
    b_max = [max(n.position[i] for n in nodes) for i in range(3)]

    # 2. Coordinate Transformation
    def transform_to_volume(P):
        P_norm = [(P[i] - b_min[i]) / (b_max[i] - b_min[i]) for i in range(3)]
        return [p * resolution for p in P_norm]

    # 3. Block Filtering & Distance Check
    # Initialize CPU flat array for node counts per block and an extra counter
    block_data = {}
    for node in nodes:
        P_vol = transform_to_volume(node.position)
        I_block = [int(math.floor(P_vol[i] / S_block)) for i in range(3)]
        block_id = tuple(I_block)
        P_block = [I_block[i] * S_block for i in range(3)]
        P_rel = [P_vol[i] - P_block[i] for i in range(3)]
        Q = [P_rel[i] - S_block / 2.0 for i in range(3)]
        Q_pos = [max(q, 0.0) for q in Q]
        D = math.sqrt(sum(q**2 for q in Q_pos)) + min(max(Q[0], Q[1], Q[2]), 0.0)
        if D < delta**2:
            if block_id not in block_data:
                block_data[block_id] = []
            block_data[block_id].append(node.id)

    # 4. Mask Generation
    # Copy mask to CPU to identify empty first-level blocks and generate axis-aligned stencil
    empty_blocks = [bid for bid in block_data if len(block_data[bid]) == 0]
    stencil = set(block_data.keys())

    # 5. Sparse Data Sampling (for non-empty blocks)
    voxel_samples = []
    for block_id, node_ids in block_data.items():
        # 5.1 Prepare Initial Nodes
        prepared_nodes = [n for n in nodes if n.id in node_ids]
        subsampled_points = []

        # 5.2 Subsample
        for idx, node in enumerate(prepared_nodes):
            if node.is_spline:
                pts = node.spline_points
                for i in range(len(pts) - 1):
                    # Linear spline interpolation between consecutive points
                    subsampled_points.append(pts[i])
                    subsampled_points.append(pts[i+1])
            elif node.is_triangle:
                # Distribute samples equally based on kernel indices (not random)
                # Weight sample count by relative area to the largest triangle
                area_weight = node.area / max_triangle_area if max_triangle_area > 0 else 1.0
                num_samples = int(10 * area_weight)
                for k in range(num_samples):
                    # Deterministic barycentric sampling based on kernel index k
                    r1 = math.sqrt(k / num_samples)
                    r2 = (k / num_samples) % 1.0
                    u = 1.0 - r1
                    v = r2 * r1
                    w = 1.0 - u - v
                    v0, v1, v2 = node.vertices
                    subsampled_points.append([v0[i]*u + v1[i]*v + v2[i]*w for i in range(3)])

        # 5.3 Generate Voxel Nodes
        for pt in subsampled_points:
            P_vol = transform_to_volume(pt)
            voxel_samples.append({
                'position': P_vol,
                'normal': node.normal,
                'tangent': node.tangent,
                'material_id': node.material_id,
                'block_id': block_id
            })

    # 6. Sample Gathering
    voxel_grid = {}
    for sample in voxel_samples:
        voxel_key = tuple(int(math.floor(sample['position'][i])) for i in range(3))
        # Save only the last sample generated at each voxel asynchronously
        voxel_grid[voxel_key] = sample

    # 7. Block Aggregation
    # Order samples by second-level block ID
    samples_by_block = {}
    for sample in voxel_grid.values():
        bid = sample['block_id']
        if bid not in samples_by_block:
            samples_by_block[bid] = []
        samples_by_block[bid].append(sample)

    # Use kernel to detect vector positions where ID changes to determine block start positions and sample counts
    sorted_blocks = sorted(samples_by_block.keys())
    block_boundaries = []
    current_start = 0
    for bid in sorted_blocks:
        count = len(samples_by_block[bid])
        block_boundaries.append((bid, current_start, count))
        current_start += count

    # 8. Directional Data Encoding
    final_voxels = {}
    for bid, samples in samples_by_block.items():
        if len(samples) > 0:
            # Compute distribution histogram for directional data (normals/tangents)
            hist = [0.0] * 36
            for s in samples:
                # Bin normal/tangent into histogram
                pass
            # Fit each computed histogram to an SGGX function [18] to encode the distribution using just 6 values
            # Sources do not provide the SGGX fitting algorithm details [G]
            sggx_params = [0.0] * 6
            final_voxels[bid] = {
                'sggx': sggx_params,
                'density': len(samples),
                'material_id': samples[0]['material_id']
            }

    return final_voxels, stencil
```

## Operating characteristics
*   **Time Complexity:** Dominated by GPU kernels for sampling and aggregation [S1].
*   **Memory Complexity:** Memory usage scales with the number of generated samples, not the voxel resolution [S1].
*   **Strengths:** Efficiently handles high-frequency sparse details (fibers, hair) without rasterization artifacts or fixed-size memory overhead [S1].
*   **Limitations:** Requires careful subsampling to avoid discontinuities [S1].

## Background
The method was introduced by Javier Fabre et al. in "Fast Voxelization and Level of Detail for Microgeometry Rendering" [S1]. It addresses the complexity of aggregating fine sparse details into coarser blocks, which usually implies rasterization and fixed-size memory allocation for sub-block grids [S1].
