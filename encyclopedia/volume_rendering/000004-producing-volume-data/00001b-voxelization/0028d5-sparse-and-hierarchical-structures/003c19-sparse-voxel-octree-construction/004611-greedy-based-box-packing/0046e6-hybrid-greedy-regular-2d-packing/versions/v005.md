# Hybrid Greedy/Regular 2D Packing

Also called: Greedy-based approach, Hybrid Greedy/Regular 2D Packing for Volume Rendering, Regular 2D packing approach

## Overview
Hybrid Greedy/Regular 2D Packing is a volume rendering pre-processing method that partitions a 3D volume into non-empty bounding boxes and packs them into 2D texture slices to bypass 3D texture padding waste [S1]. It distinguishes itself from sibling methods by dynamically selecting between a recursive greedy packing strategy and a regular 2D packing strategy based on dataset sparsity, followed by post-packing rotation optimization to minimize memory overhead [S1]. Unlike [Li03a], which partitions based on density and gradient magnitude, this method applies only to alpha values as density magnitude for a streamlined process [S1].

## How it works
**Inputs:** 3D volume dataset (voxel grid with alpha values), density threshold ($\tau_{density}$), sparsity threshold ($\tau_{sparsity}$), aspect ratio threshold ($\tau_{ratio}$) [S1].
**Outputs:** Packed 2D texture atlas, lookup tables mapping slice coordinates to packed texture coordinates, final texture dimensions $(W, H)$ [S1].

**Data Structures:**
1. **Seed Map:** Binary 3D array $M$ of size $D_x \times D_y \times D_z$. $M_{i,j,k} = 1$ if voxel alpha $\ge \tau_{density}$, else $0$ [S1].
2. **Rectangles:** List of 2D bounding boxes for each slice, defined by $(x, y, w, h)$ [S1].
3. **Slice Classification:** List of slices labeled as "square-like", "tall", or "wide" [S1].

**Steps:**

1. **Seed Map Creation:** Iterate over all voxels. If voxel alpha value $\alpha \ge \tau_{density}$, mark as seed (important voxel). Otherwise, mark as unimportant [S1].
2. **Sparse Check:** Calculate dataset sparsity $S$ (ratio of unimportant voxels to total voxels) [S1]. If $S < \tau_{sparsity}$, proceed to **2D Greedy Packing** [S1]. If $S \ge \tau_{sparsity}$, proceed to **Regular 2D Packing** [S1].
3. **2D Greedy Packing:** For each 2D slice, intersect 3D density boxes to obtain 2D rectangles [S1]. Sort rectangles by area descending [S1]. Place the largest rectangle to define the initial packed area [S1]. For each subsequent rectangle, evaluate four placement scenarios in empty regions adjacent to the current packed area: (a) place right, (b) place top, (c) place right-transposed, (d) place top-transposed [S1]. Select the placement that minimizes the growth of the slice's total bounding area [S1].
4. **Regular 2D Packing:** The sources do not specify the algorithmic steps for Regular 2D Packing distinct from Greedy packing [S1].
5. **Post-packing Optimisation:** Pre-classify slices based on aspect ratio threshold $\tau_{ratio}$ [S1]. Evaluate two strategies: Strategy A (Uniformly Vertical) and Strategy B (Uniformly Horizontal) [S1]. Select the strategy with the smallest overall texture area [S1]. Rotate minority slices (wide in A, tall in B) by 90 degrees and repack them [S1].
6. **Rendering:** Upload final 3D texture atlas and lookup tables to GPU [S1]. Apply mipmapping [S1]. Render slice-by-slice using a proxy polygon and fragment shader sampling from the packed texture using lookup tables [S1].

**Pseudocode:**

```python
def hybrid_packing(volume_data, tau_density, tau_sparsity, tau_ratio):
    # Step 1: Seed Map Creation
    seed_map = [[[False] * volume_data.shape[2] for _ in range(volume_data.shape[1])] for _ in range(volume_data.shape[0])]
    for i in range(volume_data.shape[0]):
        for j in range(volume_data.shape[1]):
            for k in range(volume_data.shape[2]):
                if volume_data[i][j][k] >= tau_density:
                    seed_map[i][j][k] = True

    # Step 2: Sparse Check
    total_voxels = volume_data.shape[0] * volume_data.shape[1] * volume_data.shape[2]
    unimportant_voxels = sum(1 for i in range(volume_data.shape[0]) for j in range(volume_data.shape[1]) for k in range(volume_data.shape[2]) if not seed_map[i][j][k])
    sparsity = unimportant_voxels / total_voxels

    if sparsity < tau_sparsity:
        packing_method = "greedy"
    else:
        packing_method = "regular"

    slices = []
    for z in range(volume_data.shape[2]):
        slice_seed_map = [[seed_map[i][j][z] for j in range(volume_data.shape[1])] for i in range(volume_data.shape[0])]
        rectangles = extract_2d_rectangles(slice_seed_map)
        rectangles.sort(key=lambda r: r['w'] * r['h'], reverse=True)

        if packing_method == "greedy":
            packed_rects = greedy_pack(rectangles)
        else:
            # Regular 2D packing algorithm details not given in the sources.
            packed_rects = regular_pack(rectangles)

        slices.append({'z': z, 'rects': packed_rects})

    # Step 5: Post-packing Optimisation
    optimized_slices = post_packing_optimization(slices, tau_ratio)

    # Step 6: Rendering Setup
    texture_atlas = create_texture_atlas(optimized_slices)
    lookup_tables = generate_lookup_tables(optimized_slices)
    return texture_atlas, lookup_tables

def extract_2d_rectangles(slice_seed_map):
    rects = []
    visited = [[False] * len(slice_seed_map[0]) for _ in range(len(slice_seed_map))]
    for i in range(len(slice_seed_map)):
        for j in range(len(slice_seed_map[0])):
            if slice_seed_map[i][j] and not visited[i][j]:
                min_i, max_i, min_j, max_j = i, i, j, j
                stack = [(i, j)]
                while stack:
                    ci, cj = stack.pop()
                    if not visited[ci][cj]:
                        visited[ci][cj] = True
                        min_i = min(min_i, ci); max_i = max(max_i, ci)
                        min_j = min(min_j, cj); max_j = max(max_j, cj)
                        for di, dj in [(-1,0),(1,0),(0,-1),(0,1)]:
                            ni, nj = ci+di, cj+dj
                            if 0 <= ni < len(slice_seed_map) and 0 <= nj < len(slice_seed_map[0]) and slice_seed_map[ni][nj] and not visited[ni][nj]:
                                stack.append((ni, nj))
                rects.append({'x': min_j, 'y': min_i, 'w': max_j - min_j + 1, 'h': max_i - min_i + 1})
    return rects

def greedy_pack(rectangles):
    if not rectangles: return []
    packed_area = {'x': rectangles[0]['x'], 'y': rectangles[0]['y'], 'w': rectangles[0]['w'], 'h': rectangles[0]['h']}
    placed = [rectangles[0]]
    remaining = rectangles[1:]

    for rect in remaining:
        best_scenario = None
        min_growth = float('inf')

        scenarios = []
        scenarios.append(calculate_union(packed_area, rect))
        scenarios.append(calculate_union(packed_area, rect))
        rect_t = {'x': rect['x'], 'y': rect['y'], 'w': rect['h'], 'h': rect['w']}
        scenarios.append(calculate_union(packed_area, rect_t))
        scenarios.append(calculate_union(packed_area, rect_t))

        for scenario in scenarios:
            growth = scenario['w'] * scenario['h'] - packed_area['w'] * packed_area['h']
            if growth < min_growth:
                min_growth = growth
                best_scenario = scenario
        packed_area = best_scenario
        placed.append(rect)
    return placed

def calculate_union(area1, area2):
    min_x = min(area1['x'], area2['x'])
    min_y = min(area1['y'], area2['y'])
    max_x = max(area1['x'] + area1['w'], area2['x'] + area2['w'])
    max_y = max(area1['y'] + area1['h'], area2['y'] + area2['h'])
    return {'x': min_x, 'y': min_y, 'w': max_x - min_x, 'h': max_y - min_y}

def post_packing_optimization(slices, tau_ratio):
    tall_slices = []
    wide_slices = []
    square_like_slices = []

    for s in slices:
        if not s['rects']: continue
        max_w = max(r['w'] for r in s['rects'])
        max_h = max(r['h'] for r in s['rects'])
        aspect = max(max_w / max_h, max_h / max_w)
        if aspect > tau_ratio:
            if max_h > max_w:
                tall_slices.append(s)
            else:
                wide_slices.append(s)
        else:
            square_like_slices.append(s)

    area_A = compute_texture_area(slices, tall_slices, wide_slices, orientation='tall')
    area_B = compute_texture_area(slices, tall_slices, wide_slices, orientation='wide')

    if area_A < area_B:
        for s in wide_slices:
            rotate_and_repack(s)
    else:
        for s in tall_slices:
            rotate_and_repack(s)

    return slices

def compute_texture_area(slices, tall_slices, wide_slices, orientation):
    temp_slices = [s.copy() for s in slices]
    for s in temp_slices:
        if orientation == 'tall' and s in wide_slices:
            rotate_and_repack(s)
        elif orientation == 'wide' and s in tall_slices:
            rotate_and_repack(s)
    if not temp_slices: return 0
    min_x = min(r['x'] for s in temp_slices for r in s['rects'])
    min_y = min(r['y'] for s in temp_slices for r in s['rects'])
    max_x = max(r['x'] + r['w'] for s in temp_slices for r in s['rects'])
    max_y = max(r['y'] + r['h'] for s in temp_slices for r in s['rects'])
    return (max_x - min_x) * (max_y - min_y)

def rotate_and_repack(slice_data):
    for r in slice_data['rects']:
        r['w'], r['h'] = r['h'], r['w']
        r['x'], r['y'] = r['y'], r['x']
    slice_data['rects'].sort(key=lambda r: r['w'] * r['h'], reverse=True)
    slice_data['rects'] = greedy_pack(slice_data['rects'])
```

**Parameters:**
*   **density threshold ($\tau_{density}$):** User-defined alpha value threshold to distinguish important (seed) voxels from empty voxels. Typical values tested: 0.05, 0.5 [S1].
*   **sparsity threshold ($\tau_{sparsity}$):** User-defined threshold for dataset sparsity to decide between Greedy-based and Regular 2D packing approaches [S1].
*   **aspect ratio threshold ($\tau_{ratio}$):** Aspect ratio threshold used to classify slices as square-like or imbalanced during post-packing optimisation [S1].

**Edge Cases and Pitfalls:**
*   **Precision:** Increasing the density threshold leads to a significant FPS decrease due to increased box count, particularly on discrete GPUs like Nvidia 1050M [S1].
*   **Boundaries:** The method explicitly bypasses 3D texture padding waste, but performance is sensitive to hardware architecture [S1].

## Subtopics

### Greedy-based Box Packing
*   **What it is:** A volume rendering pre-processing method that partitions a volume into variably-sized bounding boxes based on alpha values and packs these boxes into 2D texture slices.
*   **What sets it apart:** It uses a recursive greedy algorithm to minimize bounding area growth during packing.
*   **When to choose:** When dataset sparsity is low (below the sparsity threshold).
*   **Link:** [Greedy-based Box Packing](11669-greedy-based-box-packing.md)

## Operating characteristics
*   **Time Complexity:** Not given in the sources. [S1]
*   **Memory Complexity:** Reduces memory overhead by compacting isolated non-empty voxels into 2D texture slices, bypassing 3D texture padding waste [S1].
*   **Measured Performance:** On a Head768x768x273 dataset with Nvidia 1050M, increasing the density threshold leads to a significant FPS decrease due to increased box count [S1]. Performance is not primarily limited by fragment processing and is less sensitive to geometric complexity [S1].
*   **Scaling:** Results reveal a strong dependency on hardware architecture, with varying levels of efficiency observed across the proposed greedy-based pipeline [S1].
*   **Strengths:** Streamlined process using only alpha values; reduces texture size; enables empty-space skipping; mipmapping improves rendering performance [S1].
*   **Limitations:** Volatile performance on discrete GPUs; strong dependency on hardware architecture; increasing box count degrades FPS [S1].
*   **When to use:** For memory-efficient volume rendering of medical image data where 3D texture padding waste is a concern [S1].
*   **When not:** When hardware architecture is unknown or highly variable, or when gradient magnitude information is critical for partitioning (use [Li03a] instead) [S1].

## Background
*   **Origin:** Proposed in "A Hybrid CPU-GPU Approach for Memory-Efficient Volume Rendering of Medical Image Data" (WSCG 2026) [S1].
*   **History and Development:** Bridges the gap between AMR structures and out-of-core streaming by applying fast 2D packing strategies directly to non-empty voxels [S1]. It adapts the box-growing algorithm and 2D greedy-packing proposed by [Li03a] but simplifies the partitioning criteria to alpha values only [S1].
*   **Where it is used:** Practical 3D volume rendering pipelines, specifically for medical image data [S1].
