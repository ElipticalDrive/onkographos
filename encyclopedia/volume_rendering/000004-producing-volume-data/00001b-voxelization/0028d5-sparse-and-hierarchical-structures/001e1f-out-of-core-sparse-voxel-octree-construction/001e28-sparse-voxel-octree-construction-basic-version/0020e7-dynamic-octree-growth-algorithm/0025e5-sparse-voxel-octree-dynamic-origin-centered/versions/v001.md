# Sparse Voxel Octree (Dynamic, Origin-Centered)

Also called: bit-svo

## Overview
A sparse voxel octree implementation where voxel widths are powers of 2, positions are integer multiples of their widths (ensuring alignment to widths), the tree is always centered at (0,0,0), and the tree expands dynamically on insert [S1, unofficial]. It differs from static SVOs by growing its depth and spatial extent only when necessary, and from general dynamic octrees by enforcing a strict origin-centered coordinate system and power-of-two voxel dimensions [S1, unofficial].

## How it works
**Inputs:** A voxel defined by integer coordinates $(x, y, z)$ and a logarithmic size $lg\_size$ (where width $w = 2^{lg\_size}$). The tree stores values of type $T$.
**Outputs:** A reference to the `TreeBody` node corresponding to the voxel, or `None` if the voxel is outside the current bounds.

**Data Structures:**
*   `VoxelTree<T>`:
    *   `lg_size: u8`: The log_2 of the total tree size (width). The tree spans $[-2^{lg\_size}, 2^{lg\_size})$ in each dimension.
    *   `contents: Branches<T>`: The root node, always a `Branches` struct.
*   `Branches<T>`:
    *   A struct with 8 fields of type `TreeBody<T>`, named `lll`, `llh`, `lhl`, `lhh`, `hll`, `hlh`, `hhl`, `hhh`.
    *   Memory layout is `#[repr(C)]`, allowing direct indexing via coordinate bits.
*   `TreeBody<T>`:
    *   `Empty`: No data.
    *   `Leaf(T)`: Contains the value $T$.
    *   `Branch(Box<Branches<T>>)`: Points to a child `Branches` node.
*   `VoxelBounds`:
    *   `x: i32`, `y: i32`, `z: i32`: Integer coordinates.
    *   `lg_size: i32`: Logarithmic size. Negative values indicate sub-unit or special voxels.

**Algorithm Steps:**

1.  **Bounds Check (`contains_bounds`)**:
    Determine if a voxel fits within the current tree bounds.
    *   If `voxel.lg_size < 0`, return `true` [S1, unofficial].
    *   Calculate `high = (1 << self.lg_size) >> voxel.lg_size`.
    *   Calculate `low = -high`.
    *   If `voxel.x < low` or `voxel.y < low` or `voxel.z < low`, return `false`.
    *   If `(voxel.x + 1) <= high` and `(voxel.y + 1) <= high` and `(voxel.z + 1) <= high`, return `true`.
    *   Otherwise, return `false`.

2.  **Mask Calculation (`find_mask`)**:
    Determine the traversal mask for the voxel's size relative to the tree.
    *   Initialize `mask = (1 << self.lg_size) >> 1`.
    *   If `voxel.lg_size >= 0`, shift `mask` right by `voxel.lg_size`: `mask = mask >> voxel.lg_size`.
    *   If `voxel.lg_size < 0`, shift `mask` left by `-voxel.lg_size`: `mask = mask << (-voxel.lg_size)`.

3.  **Traversal (`mut_find`)**:
    Traverse or create nodes to reach the target voxel.
    *   Initialize `mask` using `find_mask`.
    *   Initialize `branches` pointer to `&self.contents`.
    *   **First Iteration**: Use condition `x >= 0` to select the branch. This determines the most significant bit (sign) of the coordinates.
        *   If `mask == 0`, return the current branch.
        *   Otherwise, step into the child branch.
    *   **Subsequent Iterations**: Loop while `mask > 0`.
        *   Use condition `(x & mask) != 0` to select the branch. This determines the remaining bits of the coordinates.
        *   Update `mask = mask >> 1`.
        *   Step into the child branch.
    *   *Step Logic*: If the current node is `Empty`, replace it with a `Branch` of 8 empty children. If it is a `Leaf`, replace it with a `Branch` of 8 empty children (erasing the leaf) [S1, unofficial].

4.  **Branch Selection (`get_branch`)**:
    Map coordinates $(x, y, z)$ to one of the 8 children.
    *   Define `choose_branch(val, mask)` as `(val & mask) != 0`.
    *   The bits determine the index:
        *   $x$ bit selects `l` (low) or `h` (high).
        *   $y$ bit selects `l` or `h`.
        *   $z$ bit selects `l` or `h`.
    *   Example: `lll` corresponds to `(false, false, false)`, `hhh` to `(true, true, true)`.

5.  **Retrieval (`get`)**:
    *   If `!contains_bounds(voxel)`, return `None`.
    *   Call `mut_find` with a step function that returns `Ok(branches)` if the node is a `Branch`, else `Err`.
    *   If the result is `Ok(&TreeBody::Leaf(t))`, return `Some(t)`. Else, return `None`.

6.  **Ray Casting (`cast_ray`)**:
    *   Calculate `coords` array: `coords[i] = 1` if `origin[i] >= 0.0`, else `0`.
    *   Set `child_lg_size = self.lg_size as i16`.
    *   Define `make_bounds` closure: returns `VoxelBounds` with `x = coords[0] - 1`, `y = coords[1] - 1`, `z = coords[2] - 1`, `lg_size = child_lg_size`.
    *   Call `raycast::cast_ray_branches` with `&self.contents`, `origin`, `direction`, `None`, `coords`, `&mut make_bounds`, and the action function `act`.

## Operating characteristics
*   **Time Complexity**: Insertion is $O(D)$ where $D$ is the depth of the tree. Benchmarks show approximately 1 microsecond per insert through 30 levels of depth (world width of $2^{30}$ voxels) [S1, unofficial].
*   **Memory Complexity**: Proportional to the number of non-empty nodes. Each branch node consumes memory for 8 child pointers.
*   **Strengths**: Dynamic growth avoids pre-allocating memory for empty space. Origin-centered design simplifies coordinate arithmetic for symmetric scenes.
*   **Limitations**: The strict power-of-two width and alignment requirements limit flexibility. Leaf replacement on insertion may cause unnecessary memory churn if leaves are frequently replaced by branches [S1, unofficial].

## Background
This implementation is part of the `bit-svo` project by `bfops` [S1, unofficial]. It is designed for efficient sparse voxel storage with a focus on performance and simplicity, leveraging bit manipulation for branch selection.
