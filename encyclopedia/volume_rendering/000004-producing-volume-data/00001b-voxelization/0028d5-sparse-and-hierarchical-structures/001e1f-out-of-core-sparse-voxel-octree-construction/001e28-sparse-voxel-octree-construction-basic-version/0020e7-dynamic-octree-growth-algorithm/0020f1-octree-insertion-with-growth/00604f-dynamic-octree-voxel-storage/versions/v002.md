# Dynamic Octree Voxel Storage


## Overview
Dynamic Octree Voxel Storage is a spatial partitioning structure for storing 3D voxels that supports automatic subdivision based on voxel density and bounds size [S1, unofficial]. It solves the problem of efficiently managing sparse 3D data by dynamically growing the tree during insertion and using dictionary-based leaf storage rather than fixed arrays [S1, unofficial].

## How it works
**Inputs and Outputs:**
- Input: A 3D voxel position (`Vector3`) and voxel data (`Voxel`) [S1, unofficial].
- Output: The updated octree structure with the voxel inserted [S1, unofficial].

**Data Structures:**
The core structure is `OctreeNode` [S1, unofficial]. It contains the following fields:
- `depth`: `int` [S1, unofficial].
- `bounds`: `Bounds` object defining the spatial extent of the node [S1, unofficial].
- `IsLeaf`: `bool` flag indicating if the node is a leaf [S1, unofficial].
- `voxels`: `Dictionary<Vector3, Voxel>` storing voxels at this node if it is a leaf [S1, unofficial].
- `Children`: `OctreeNode[8]` array of 8 child nodes, null if leaf [S1, unofficial].
- `capacity`: `int` maximum number of voxels allowed in this leaf [S1, unofficial].
- `mesh`: `OctreeMesh` reference to associated mesh data [S1, unofficial].
- `tree`: `Octree` reference to the parent octree instance [S1, unofficial].

**Formulas:**
The capacity of a leaf node is calculated based on its bounds size [S1, unofficial]:
$$ capacity = \text{clamp}\left(\frac{size^3}{3}, minBoundsSize, maxCapacity\right) $$
Where:
- $size$ is the extent of the bounds (specifically the x-dimension) [S1, unofficial].
- $minBoundsSize$ is the minimum bounds extent required to allow subdivision [S1, unofficial].
- $maxCapacity$ is the maximum number of voxels a leaf can hold [S1, unofficial].

**Parameters:**
- `maxCapacity`: 5000 [S1, unofficial].
- `minBoundsSize`: 7.0f [S1, unofficial].

**Steps:**
1. **Check Bounds:** Determine if the voxel position is within the current node's bounds [S1, unofficial].
   - If outside, trigger the `Grow()` routine [S1, unofficial].
   - If inside, proceed to insertion logic [S1, unofficial].
2. **Leaf Check:** If the current node is a leaf:
   - Add the voxel to the `voxels` dictionary [S1, unofficial].
   - Check if the number of voxels exceeds `capacity` [S1, unofficial].
   - If capacity is exceeded AND the bounds size is greater than or equal to `minBoundsSize`:
     - Subdivide the node [S1, unofficial].
     - Redistribute existing voxels from the dictionary to the 8 child nodes [S1, unofficial].
     - Re-insert the new voxel into the appropriate child node [S1, unofficial].
3. **Non-Leaf Check:** If the current node is not a leaf:
   - Determine the octant index for the voxel position relative to the node's center [S1, unofficial].
   - Recursively insert the voxel into the corresponding child node [S1, unofficial].

**Octant Index Calculation:**
The octant index is determined by comparing the voxel's coordinates to the node's center [S1, unofficial]:
- Bit 4 (value 16): Set if $x > center.x$ [S1, unofficial].
- Bit 2 (value 4): Set if $y > center.y$ [S1, unofficial].
- Bit 1 (value 2): Set if $z > center.z$ [S1, unofficial].
The octant index is the sum of the set bits [S1, unofficial].

**Subdivision:**
Child node centers are calculated by adding or subtracting half the parent's half-size (quarterSize) based on the octant index bits [S1, unofficial].

**Pseudocode:**
```python
def clamp(val, low, high):
    return max(low, min(val, high))

class OctreeNode:
    def __init__(self, bounds, depth, tree_ref):
        self.depth = depth
        self.bounds = bounds
        self.IsLeaf = True
        self.voxels = {}
        self.Children = [None] * 8
        self.capacity = self.calculate_capacity(bounds.size)
        self.mesh = None
        self.tree = tree_ref

    def calculate_capacity(self, size):
        # Source formula clamps capacity between minBoundsSize and maxCapacity.
        # minBoundsSize is a length (7.0f), capacity is an int count.
        # We cast minBoundsSize to int to fix the unit mismatch for capacity.
        return clamp(int((size ** 3) / 3), 7, 5000)

    def insert(self, position, voxel):
        if not self.bounds.contains(position):
            self.grow()
            return

        if self.IsLeaf:
            self.voxels[position] = voxel
            if len(self.voxels) > self.capacity and self.bounds.size >= 7.0:
                self.subdivide()
                for pos, vox in list(self.voxels.items()):
                    self.voxels.pop(pos)
                    self.insert_into_children(pos, vox)
                self.insert_into_children(position, voxel)
        else:
            self.insert_into_children(position, voxel)

    def insert_into_children(self, position, voxel):
        octant = self.get_octant(position)
        if self.Children[octant] is None:
            child_bounds = self.get_child_bounds(octant)
            self.Children[octant] = OctreeNode(child_bounds, self.depth + 1, self.tree)
        self.Children[octant].insert(position, voxel)

    def get_octant(self, position):
        center = self.bounds.center
        octant = 0
        if position.x > center.x:
            octant |= 16
        if position.y > center.y:
            octant |= 4
        if position.z > center.z:
            octant |= 2
        return octant

    def subdivide(self):
        self.IsLeaf = False
        for i in range(8):
            child_bounds = self.get_child_bounds(i)
            self.Children[i] = OctreeNode(child_bounds, self.depth + 1, self.tree)

    def get_child_bounds(self, octant):
        # Standard octree child bounds calculation [G]
        half = self.bounds.half_size
        quarter = half / 2.0
        center = self.bounds.center
        offset_x = quarter if (octant & 16) else -quarter
        offset_y = quarter if (octant & 4) else -quarter
        offset_z = quarter if (octant & 2) else -quarter
        child_center = center + Vector3(offset_x, offset_y, offset_z)
        return Bounds(child_center, half)

    def grow(self):
```

## Operating characteristics
- **Time Complexity:** Not given in the sources.
- **Memory Complexity:** Not given in the sources.
- **Strengths:** Dynamic growth allows handling of sparse data efficiently [S1, unofficial]. Dictionary storage allows easy lookup by position [S1, unofficial].
- **Limitations:** Dictionary-based storage may have higher memory overhead and slower iteration compared to array-based or Morton-code-based structures [S1, unofficial]. The `Grow()` method is not implemented, leading to silent data loss for out-of-bounds voxels [S1, unofficial].
- **When to use:** Suitable for applications where voxel density is highly variable and out-of-bounds growth is not critical or is handled externally [S1, unofficial].
- **When not to use:** When strict memory efficiency is required or when out-of-bounds growth is essential [S1, unofficial].
