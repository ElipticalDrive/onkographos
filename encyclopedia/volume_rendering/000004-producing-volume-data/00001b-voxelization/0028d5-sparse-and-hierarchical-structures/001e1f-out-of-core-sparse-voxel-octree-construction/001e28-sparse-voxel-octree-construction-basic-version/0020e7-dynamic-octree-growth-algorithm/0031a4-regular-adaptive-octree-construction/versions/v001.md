# Regular-Adaptive Octree Construction

Also called: Build Octree algorithm, Local refinement algorithm

## Overview
Regular-Adaptive Octree Construction is an iterative algorithm for building a Sparse Voxel Octree (SVO) that maintains a regular (uniform) structure up to a specified minimal level (`minLevel`) and switches to adaptive subdivision between `minLevel` and a maximal level (`maxLevel`) [S1, unofficial]. It solves the problem of efficiently representing implicit surfaces while ensuring topological correctness (manifoldness) by detecting and resolving non-manifold configurations caused by collapsed cells adjacent to higher-resolution neighbors [S1, unofficial]. It builds on [Dynamic Octree Growth Algorithm](2375-dynamic-octree-growth-algorithm.md) by introducing a fixed-depth regular base and explicit topological validation.

## How it works
The method consists of two phases: the primary octree construction and a subsequent local refinement pass to fix topological artifacts.

### Inputs and Outputs
*   **Input:** Root cell $c$ of the octree; minimal level `minLevel`; maximal subdivision level `maxLevel`; implicit function $F(x)$ used to evaluate cell complexity.
*   **Output:** An octree that is regular until level `minLevel` and adaptive between `minLevel` and `maxLevel`, with topological issues resolved [S1, unofficial].

### Data Structures
*   **Cell:** Represents a voxel or octree node. Contains level information and status flags (e.g., `collapsed`, `leaf`).
*   **toProcess List:** A queue or stack of cells pending processing.
*   **Affected Set $A$:** A set of cells identified as having topological issues (complex faces) requiring refinement.

### Algorithm 1: Build Octree
This phase constructs the tree structure.

1.  Initialize `toProcess` list by adding the root cell $c$.
2.  While `toProcess` is not empty:
    a.  Retrieve the first element as `currentCell`.
    b.  Check if `currentCell` requires subdivision:
        i.  If `GetLevel(currentCell)` < `maxLevel`:

                *   Proceed to **Subdivide**.
            *   Else:
                *   Mark `currentCell` as a leaf and as `collapsed`.
        ii. Else (level >= `maxLevel`):
            *   Mark `currentCell` as a leaf and as `collapsed`.
    c.  **Subdivide** block:
        i.  Divide `currentCell` into 8 child cells $S = \{q_1, ..., q_8\}$.

            *   Add $q_i$ to `toProcess`.

### Algorithm 2: Local Refinement
This phase fixes topological errors.

1.  Initialize affected set $A$ with the set $T$ of collapsed cells from Algorithm 1.
2.  For each cell $c$ in $A$:
    a.  Apply **Build Octree** method to $c$ up to refinement level $l$.
3.  For each cell $c$ in $A$:
    a.  Iterate through all 6 faces of $c$.
    b.  If a face is detected as **complex**:
        i.  Identify the adjacent cell sharing that face.
        ii. Add the adjacent cell to $A$.
4.  Repeat steps 2-3 recursively until no cell in $A$ presents complex faces.

**Complexity:** Linear with respect to the number of cells affected by the induced subdivision [S1, unofficial].

### Parameters
*   `minLevel`: The octree level up which the structure remains regular (uniform subdivision). [S1, unofficial]
*   `maxLevel`: The maximum depth for adaptive subdivision. [S1, unofficial]
*   `l`: The level of refinement applied during the local refinement process. [S1, unofficial]

### Pseudocode

```python
def build_octree(root_cell, min_level, max_level, implicit_func):
    """
    Constructs the regular-adaptive octree.
    """
    to_process = [root_cell]
    
    while to_process:
        current_cell = to_process.pop(0) # Retrieve first element
        level = current_cell.level
        
        # Regularity: Force subdivision up to min_level
        # Adaptivity: Subdivide if complex/planar or at max_level
        should_subdivide = False
        
        if level < min_level:
            should_subdivide = True
        elif level < max_level:
            # Check complexity and planarity
            is_complex = not is_not_complex(current_cell, implicit_func)
            is_planar = not is_not_planar(current_cell, implicit_func)
            
            if is_complex or is_planar:
                should_subdivide = True
            else:
                # Simple and non-planar: Mark as leaf/collapsed
                current_cell.mark_leaf()
                current_cell.mark_collapsed()
        else:
            # Level >= max_level: Subdivide to capture topology
            should_subdivide = True
            
        if should_subdivide:
            children = divide(current_cell) # Returns 8 child cells
            for child in children:
                to_process.append(child)

def local_refinement(collapsed_cells, refinement_level):
    """
    Fixes topological problems caused by collapsed cells.
    """
    affected_set = set(collapsed_cells)
    
    while True:
        changed = False
        new_affected = set()
        
        for cell in affected_set:
            # Apply build octree up to refinement level l
            # Note: This re-evaluates/subdivides the cell's neighborhood
            build_octree(cell, cell.level, refinement_level, implicit_func)
            
            # Check 6 faces
            for face in cell.faces:
                if is_face_complex(face):
                    adjacent = get_adjacent_cell(cell, face)
                    if adjacent not in affected_set:
                        new_affected.add(adjacent)
                        changed = True
        
        if not new_affected:
            break
            
        affected_set.update(new_affected)
        
    return affected_set
```

## Subtopics

### Local refinement algorithm
A recursive algorithm to fix topological problems (non-manifold configurations) caused by collapsed cells adjacent to higher-resolution cells [S1, unofficial]. It works by identifying collapsed cells, checking their faces for complexity, and recursively subdividing affected neighbors until no complex faces remain [S1, unofficial]. It is chosen when the primary construction phase produces non-manifold surfaces due to resolution mismatches [S1, unofficial]. Complexity is linear over the number of affected cells [S1, unofficial].

## Operating characteristics
*   **Time Complexity:** The primary construction is proportional to the number of cells created. The local refinement is linear with respect to the number of cells affected by induced subdivision [S1, unofficial]. Execution time depends on the topological complexity of $F(x)$ [S1, unofficial].
*   **Memory Complexity:** Proportional to the number of nodes in the octree. Collapsed cells are stored as leaves, saving memory compared to full subdivision [S1, unofficial].
*   **Strengths:** Ensures manifold surface generation by explicitly handling topological artifacts at resolution boundaries [S1, unofficial]. Efficient by keeping the base regular and only adapting where necessary [S1, unofficial].
*   **Limitations:** Requires a post-processing pass (local refinement) which adds overhead. Performance depends on the complexity of the implicit function [S1, unofficial].
*   **When to use:** When generating SVOs for implicit surface rendering where manifold topology is critical, and the implicit function has complex features that might cause non-manifold edges at lower resolutions [S1, unofficial].

## Background
The method was proposed in 2012 by SCITEPRESS publications [S1, unofficial]. It addresses issues in SVO construction where collapsed cells (leaves at max depth or simple cells) create non-manifold configurations when adjacent to deeper, adaptive cells [S1, unofficial]. The approach builds on dynamic growth algorithms but adds a regular base and explicit topological validation [S1, unofficial].
