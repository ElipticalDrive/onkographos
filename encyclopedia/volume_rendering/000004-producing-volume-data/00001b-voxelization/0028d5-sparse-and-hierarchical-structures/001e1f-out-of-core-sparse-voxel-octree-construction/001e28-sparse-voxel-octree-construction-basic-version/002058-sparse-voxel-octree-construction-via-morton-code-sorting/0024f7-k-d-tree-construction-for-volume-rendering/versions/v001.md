# K-D Tree Construction for Volume Rendering

Also called: Kdtree::buildFromOctree, KdtreeISO build

## Overview
This method constructs a K-D tree from a Sparse Voxel Octree (SVO) to optimize volume rendering and mesh extraction by partitioning space based on Quadratic Error Function (QEF) variance [S1, unofficial]. It differs from sibling methods like [Octree Volume Construction](3332-octree-volume-construction.md) by explicitly balancing the split plane to minimize the error difference between child nodes, rather than simply splitting at geometric centers or based on occupancy alone. This approach facilitates efficient contouring and mesh extraction by ensuring that each node's QEF solution is representative of its contained geometry [S1, unofficial].

## How it works
The algorithm recursively partitions the octree nodes into a K-D tree structure. It uses the aggregate QEF statistics of the nodes within a bounding box to determine the optimal splitting axis and plane.

### Inputs and Outputs
- **Input**: An `Octree` structure, and two `PositionCode` values (`minCode`, `maxCode`) defining the range of octree nodes to process.
- **Output**: A pointer to a `Kdtree` node (or `nullptr` if the range is empty/invalid).

### Data Structures
The implementation relies on the following structures (derived from [S1, unofficial]):

**QefSolver**: Aggregates statistics for solving a QEF.
- `ATA`: `glm::mat4` (4x4 matrix), initialized to zero.
- `ATb`: `glm::fvec3` (3D vector), initialized to zero.
- `diag_ATc`: `float`, initialized to zero.
- `btb`: `float`, initialized to zero.
- `diag_ctc`: `glm::fvec3`, initialized to zero.
- `massPointSum`: `glm::fvec3`, initialized to zero.
- `averageNormalSum`: `glm::fvec3`, initialized to zero.
- `roughness`: `float`, initialized to zero.
- `pointCount`: `int`, initialized to zero.

**RectilinearGrid** (Node Content):
- `minCode`, `maxCode`: `PositionCode` (defines spatial bounds).
- `allQef`: `QefSolver` (aggregate statistics for the node).
- `components`: `std::vector<QefSolver>` (QEFs for sub-components).
- `vertices`: `std::vector<Vertex>` (extracted mesh vertices).
- `approximate`: `Vertex` (approximate solution to the QEF).
- `cornerSigns`: `uint8_t[8]` (signs of the 8 corners).
- `componentIndices`: `int8_t[8]` (indices of components for corners).
- `isSigned`: `bool`.
- `faceVertices`: `std::map<RectilinearGrid*, Vertex*>`.

**Kdtree Node**:
- Contains `minCode`, `maxCode`, `dir` (split axis), `depth`, and pointers to left/right children.
- If leaf: stores `sign` and sample QEF from scalar field.
- If internal: stores `clusterability` and combined QEFs.

### Steps

1. **Termination Check**:
   If `minCode >= maxCode` (component-wise comparison using `glm::any(glm::greaterThanEqual(minCode, maxCode))`), return `nullptr` [S1, unofficial].

2. **Aggregate QEF Calculation**:
   Call `Octree::getSum(octree, minCode, maxCode, sum)` to compute the aggregate `QefSolver` (`sum`) for all octree nodes in the range [S1, unofficial].

3. **Empty Check**:
   If `sum.pointCount == 0`, return `nullptr` [S1, unofficial].

4. **Select Splitting Axis**:
   Call `chooseAxisDir(sum, minCode, maxCode)` [S1, unofficial]:
   - Calculate the bounding box size: `size = maxCode - minCode`.
   - Compute variance for each axis `i`: `variance[i] = sum.getVariance(axis[i]) * size[i]` [S1, unofficial].
   - Identify `maxVarDir` (axis with maximum variance) and `minVarDir` (axis with minimum variance) [S1, unofficial].
   - If `size[maxVarDir] < 2`, fallback to `3 - maxVarDir - minVarDir`.
   - If the fallback size is also `< 2`, use `minVarDir` [S1, unofficial].
   - Let `dir` be the selected axis [S1, unofficial].

5. **Determine Split Plane**:
   Use a binary search to find the split that minimizes the error difference between left and right children [S1, unofficial]:
   - Initialize `minError = infinity`, `bestLeftMaxCode`, `bestRightMinCode`.
   - Set `minAxis = minCode[dir]`, `maxAxis = maxCode[dir]` [S1, unofficial].
   - Loop while `maxAxis - minAxis > 1`:
     - `mid = (maxAxis + minAxis) / 2` [S1, unofficial].
     - Define split bounds: `rightMinCode[dir] = mid`, `leftMaxCode[dir] = mid` [S1, unofficial].
     - Recursively compute sums for left (`minCode` to `leftMaxCode`) and right (`rightMinCode` to `maxCode`) halves. Note: This requires a helper function to get sums without building the tree, or reusing `Octree::getSum` with adjusted codes [S1, unofficial].
     - Solve QEF for left and right to get `leftError` and `rightError` [S1, unofficial].
     - If `abs(leftError - rightError) < minError`:
       - `minError = abs(leftError - rightError)`
       - `bestLeftMaxCode = leftMaxCode`
       - `bestRightMinCode = rightMinCode` [S1, unofficial].
     - If `leftError > rightError`, `minAxis = mid`; else `maxAxis = mid` [S1, unofficial].
     - If `leftError == rightError`, break [S1, unofficial].

6. **Create Node**:
   Create a new `Kdtree` node with `sum`, `minCode`, `maxCode`, `dir`, and `depth` [S1, unofficial].

7. **Recursive Build**:
   - Recursively build left child: `buildFromOctree(octree, minCode, bestLeftMaxCode)` [S1, unofficial].
   - Recursively build right child: `buildFromOctree(octree, bestRightMinCode, maxCode)` [S1, unofficial].
   - Assign children to the current node [S1, unofficial].

8. **Leaf Processing**:
   If the node is a leaf (`kd->isLeaf()`):
   - Assign `sign` and sample QEF from the scalar field `t` [S1, unofficial].

9. **Internal Node Processing**:
   If not a leaf:
   - Assign `sign` [S1, unofficial].
   - Calculate `clusterability` using `calClusterability(left, right, dir)` [S1, unofficial].
   - Combine QEFs from children into the node's `allQef` [S1, unofficial].
   - If `clusterable` is true:
     - Solve QEF for each component in `kd->grid.components` [S1, unofficial].

### Pseudocode

```python
def build_kd_tree(octree, min_code, max_code):
    # Step 1: Termination Check
    if any(min_code[i] >= max_code[i] for i in range(3)):
        return None

    # Step 2: Aggregate QEF
    sum_qef = octree.get_sum(min_code, max_code)

    # Step 3: Empty Check
    if sum_qef.point_count == 0:
        return None

    # Step 4: Select Splitting Axis
    size = max_code - min_code
    variance = [sum_qef.get_variance(i) * size[i] for i in range(3)]
    max_var_dir = argmax(variance)
    min_var_dir = argmin(variance)

    if size[max_var_dir] < 2:
        dir = 3 - max_var_dir - min_var_dir
        if size[dir] < 2:
            dir = min_var_dir
    else:
        dir = max_var_dir

    # Step 5: Determine Split Plane
    min_axis = min_code[dir]
    max_axis = max_code[dir]
    min_error = float('inf')
    best_left_max = None
    best_right_min = None

    while max_axis - min_axis > 1:
        mid = (max_axis + min_axis) // 2
        
        # Define split codes
        left_max = max_code.copy()
        left_max[dir] = mid
        right_min = min_code.copy()
        right_min[dir] = mid

        # Get sums for halves
        left_qef = octree.get_sum(min_code, left_max)
        right_qef = octree.get_sum(right_min, max_code)

        # Solve QEF for errors
        left_error = solve_qef_error(left_qef)
        right_error = solve_qef_error(right_qef)

        error_diff = abs(left_error - right_error)
        if error_diff < min_error:
            min_error = error_diff
            best_left_max = left_max
            best_right_min = right_min

        if left_error > right_error:
            min_axis = mid
        elif right_error > left_error:
            max_axis = mid
        else:
            break

    # Step 6: Create Node
    node = KdtreeNode(sum_qef, min_code, max_code, dir, depth=0)

    # Step 7: Recursive Build
    node.left = build_kd_tree(octree, min_code, best_left_max)
    node.right = build_kd_tree(octree, best_right_min, max_code)

    # Step 8 & 9: Leaf/Internal Processing
    if node.is_leaf():
        node.sign = sample_sign(node, octree.scalar_field)
        node.qef = sample_qef(node, octree.scalar_field)
    else:
        node.sign = combine_signs(node.left.sign, node.right.sign)
        node.clusterability = cal_clusterability(node.left, node.right, dir)
        node.all_qef = combine_qefs(node.left.all_qef, node.right.all_qef)
        
        if node.clusterability:
            for i in range(len(node.grid.components)):
                solve_qef_component(node.grid.components[i])

    return node
```

### Parameters and Edge Cases
- **Parameters**: The binary search in Step 5 continues until `max_axis - min_axis > 1`. The fallback logic in Step 4 handles degenerate boxes where one dimension has size < 2 [S1, unofficial].
- **Edge Cases**: If `sum.pointCount == 0`, the node is skipped [S1, unofficial]. Precision issues in QEF solving may affect `minError` comparisons; using `abs(leftError - rightError)` helps balance the tree [S1, unofficial].

## Operating characteristics
- **Time Complexity**: The construction is recursive. At each level, it computes QEF sums and performs a binary search over the split axis. The binary search depth is logarithmic with respect to the number of voxels in the dimension. Overall complexity depends on the octree depth and the number of nodes [S1, unofficial].
- **Memory Complexity**: Stores QEF statistics (`QefSolver`) for each node. The `RectilinearGrid` structure adds overhead for vertices and components [S1, unofficial].
- **Strengths**: Optimizes for mesh extraction quality by balancing QEF error. Efficient for contouring [S1, unofficial].
- **Limitations**: More complex than simple geometric splitting. Requires efficient QEF summation [S1, unofficial].

## Background
This method originates from the KdtreeISO project by Danielmelody, designed for efficient volume rendering and mesh extraction from sparse voxel data [S1, unofficial]. It builds upon the Sparse Voxel Octree Construction via Morton Code Sorting [2227-sparse-voxel-octree-construction-via-morton-code-sorting.md] to provide a spatial partitioning structure optimized for QEF-based surface reconstruction [S1, unofficial].
