# Octree Volume Construction

Also called: Sparse Voxel Octree Construction (Leaf Masking Variant)

## Overview
Constructs a hierarchical octree data structure from a 3D volume grid to accelerate ray marching, where leaf nodes store a bitmask representing the presence of density values in their spatial extent [S1, unofficial]. It differs from sibling methods by explicitly quantizing volume samples into discrete brackets to form compact leaf masks, rather than storing raw density values or using uniform voxel grids.

## How it works
**Inputs:**
*   `volume`: A 3D scalar field (density grid).
*   `settings.brackets`: An array of threshold coefficients used to quantize volume samples into discrete bracket indices.
*   `levels`: The maximum depth of the octree recursion.

**Outputs:**
*   `octree`: The root node of the constructed octree.

**Data Structures:**
*   `OctreeNode`:
    *   `mask`: A bitmask (integer) representing the status of children or leaf samples.
    *   `children`: An array of 8 `OctreeNode` pointers (for non-leaf nodes).
    *   `boundingBox`: The spatial extent of the node.

**Algorithm:**
The construction is recursive. For a node at a given `levels`:

1.  **Base Case (Leaf):** If `levels == 0`, the node is a leaf.
    *   Iterate over the bounding box coordinates expanded by 1 unit in all directions:
        $$ x \in [\lfloor \text{bb.min}_x - 1 \rfloor, \lceil \text{bb.max}_x + 1 \rceil] $$
        $$ y \in [\lfloor \text{bb.min}_y - 1 \rfloor, \lceil \text{bb.max}_y + 1 \rceil] $$
        $$ z \in [\lfloor \text{bb.min}_z - 1 \rfloor, \lceil \text{bb.max}_z + 1 \rceil] $$
    *   For each integer coordinate $(x, y, z)$:
        *   Sample the volume to get `coef`.
        *   Determine the bracket index by incrementing `bracket` while `settings.brackets[bracket + 1] <= coef`.
        *   Set the bit corresponding to the bracket index in the leaf node's mask:
            $$ \text{octree.mask} \ |= \ (1 \ll \text{bracket}) $$
2.  **Recursive Case (Non-Leaf):** If `levels > 0`:
    *   Split the current bounding box at its midpoint (`bb.mid`) to define 8 child octants.
    *   Children are indexed 0-7 corresponding to binary coordinates $(x, y, z)$ relative to the midpoint.
    *   Recursively construct each child with `levels - 1`.
    *   After building children, aggregate their masks:
        *   `octree.mask` is the bitwise OR of all children's masks.
        *   `maskAll` is the bitwise AND of all children's masks.
3.  **Compression:**
    *   If `octree.mask == maskAll`, the current node is converted to a leaf node to compress the tree.
    *   Note: Memory for children is not freed in this implementation [S1, unofficial].

**Pseudocode:**
```python
def build_octree(volume, settings, levels, bounding_box):
    node = OctreeNode()
    node.bounding_box = bounding_box
    
    if levels == 0:
        # Leaf node construction
        node.mask = 0
        min_x = floor(bounding_box.min.x - 1)
        max_x = ceil(bounding_box.max.x + 1)
        min_y = floor(bounding_box.min.y - 1)
        max_y = ceil(bounding_box.max.y + 1)
        min_z = floor(bounding_box.min.z - 1)
        max_z = ceil(bounding_box.max.z + 1)
        
        for x in range(min_x, max_x + 1):
            for y in range(min_y, max_y + 1):
                for z in range(min_z, max_z + 1):
                    coef = volume.sample(x, y, z)
                    bracket = 0
                    # Find bracket index
                    while bracket < len(settings.brackets) - 1 and settings.brackets[bracket + 1] <= coef:
                        bracket += 1
                    node.mask |= (1 << bracket)
        return node

    else:
        # Non-leaf node construction
        mid = bounding_box.midpoint()
        children = []
        
        # Define 8 octants based on binary coordinates relative to midpoint
        # Index i corresponds to bits (x_bit, y_bit, z_bit)
        for i in range(8):
            x_bit = (i >> 2) & 1
            y_bit = (i >> 1) & 1
            z_bit = i & 1
            
            # Construct child bounding box
            child_min = bounding_box.min
            child_max = bounding_box.max
            
            if x_bit: child_min.x = mid.x
            else: child_max.x = mid.x
            
            if y_bit: child_min.y = mid.y
            else: child_max.y = mid.y
            
            if z_bit: child_min.z = mid.z
            else: child_max.z = mid.z
            
            child_box = BoundingBox(child_min, child_max)
            child_node = build_octree(volume, settings, levels - 1, child_box)
            children.append(child_node)
        
        node.children = children
        
        # Aggregate masks
        combined_mask = 0
        all_mask = -1 # All bits set
        
        for child in children:
            combined_mask |= child.mask
            all_mask &= child.mask
            
        node.mask = combined_mask
        
        # Compression: if all children have identical masks, convert to leaf
        if combined_mask == all_mask:
            # TODO: Free memory for children
            node.children = None
            # The mask remains the same, representing the uniform state
            pass
            
        return node
```

**Parameters:**
*   `levels`: Maximum recursion depth. When `levels == 0`, the node is a leaf [S1, unofficial].
*   `settings.brackets`: Array of threshold coefficients for quantization [S1, unofficial].

**Edge Cases and Pitfalls:**
*   **Compression Memory Leak:** If all children have identical masks, the node is converted to a leaf, but memory for the children is not freed [S1, unofficial].
*   **Bracket Indexing:** The bracket index determination relies on the sorted order of `settings.brackets`. If `coef` exceeds all brackets, the index must be handled (implementation details vary, but typically clamped or handled as a special case) [S1, unofficial].

## Operating characteristics
*   **Time Complexity:** $O(N \cdot L)$ where $N$ is the number of voxels in the expanded bounding box and $L$ is the depth. The expansion by 1 unit increases the leaf sampling volume.
*   **Memory Complexity:** Depends on the sparsity of the volume and the effectiveness of the mask compression. In the worst case (no compression), it stores $8^L$ nodes.
*   **Strengths:** Compact representation for sparse volumes; fast traversal using bitmasks.
*   **Limitations:** Quantization loss due to bracketing; potential memory leak in compression step; fixed expansion of leaf bounding boxes may include empty space.

## Background
This method is derived from implementations in path tracing and volume rendering contexts, specifically focusing on sparse voxel octrees with leaf-level bitmasking for acceleration [S1, unofficial].
