# Sparse Voxel Octree Construction (Optimized Version)
Also called: SVO construction, optimized version

## Overview
This method constructs a Sparse Voxel Octree (SVO) from a stream of non-empty voxel Morton codes by optimizing the handling of empty space. Unlike the basic version, which inserts empty child nodes individually, this approach calculates the number of empty nodes between consecutive input leaves and directly inserts empty parent nodes into higher-level queues. This reduces the number of queue operations significantly, as pushing back $2^d$ empty nodes is equivalent to pushing back a single node at the level above. It builds on [Sparse Voxel Octree Construction (Basic Version)](1694-sparse-voxel-octree-construction-basic-version.md).

## How it works
**Inputs:** A sorted stream of non-empty leaf nodes, each containing a 64-bit Morton code.
**Outputs:** An out-of-core SVO stored on disk, with internal structure maintained in memory queues.
**Data Structures:**
- `queues`: An array of queues, one for each depth level $d \in [0, \text{depth}]$. Each queue holds nodes (empty or internal) waiting to be merged.
- `current_morton`: An integer tracking the Morton code of the previously processed leaf.
- `depth`: The maximum depth of the octree (typically 10–14 for high-resolution grids).

**Algorithm Steps:**
1. Initialize `current_morton` to 0.
2. While input exists:
   a. Consume the next leaf node $l$ from the input stream.
   b. Calculate the number of empty nodes between the current and previous Morton code:
      $$ \text{nb\_empty\_nodes} = l.\text{morton} - \text{current\_morton} $$
   c. While $\text{nb\_empty\_nodes} > 0$:
      i. Determine the insertion depth for empty nodes. Calculate $a$ as the largest integer such that $8^a < \text{nb\_empty\_nodes}$. Calculate $b$ as the largest index such that `queues[b]` is not empty. Set the insertion depth $d_i = \max(\text{depth} - a, b)$.
      ii. Push an empty node onto `queues[d_i]`.
      iii. While $d_i > 0$ and `queues[d_i]` is full:
           1. Create an internal node $p$.
           2. Set $p.\text{children}$ to the contents of `queues[d_i]`.
           3. Write non-empty elements of `queues[d_i]` to disk.
           4. Clear `queues[d_i]`.
           5. Push $p$ onto `queues[d_i - 1]`.
           6. Decrement $d_i$.
           7. Subtract $8^{\text{depth} - d_i}$ from $\text{nb\_empty\_nodes}$.
   d. Process the non-empty leaf node $l$ using the basic version logic: push $l$ to the appropriate queue, and if the queue is full, merge nodes up the tree as described in the basic version.
   e. Update `current_morton` to $l.\text{morton}$.

**Pseudocode:**
```python
def optimized_svo_construction(input_stream, depth):
    queues = [Queue() for _ in range(depth + 1)]
    current_morton = 0
    
    for leaf in input_stream:
        nb_empty_nodes = leaf.morton - current_morton
        
        # Handle empty space
        while nb_empty_nodes > 0:
            # Find largest a such that 8^a < nb_empty_nodes
            a = 0
            while (8 ** (a + 1)) < nb_empty_nodes:
                a += 1
            
            # Find largest b such that queues[b] is not empty
            b = -1
            for i in range(depth, -1, -1):
                if not queues[i].is_empty():
                    b = i
                    break
            if b == -1:
                b = 0 # Fallback if all queues empty, though logic implies b>=0 if queues exist
            
            di = max(depth - a, b)
            
            queues[di].push_back(EmptyNode())
            
            # Merge if queue is full
            while di > 0 and queues[di].is_full():
                p = InternalNode()
                p.children = queues[di].get_all_elements()
                
                # Write non-empty elements to disk
                for child in p.children:
                    if not child.is_empty():
                        write_to_disk(child)
                
                queues[di].clear()
                queues[di - 1].push_back(p)
                di -= 1
                nb_empty_nodes -= 8 ** (depth - di)
        
        # Process non-empty leaf using basic version logic
        # (Simplified: push to queue, merge if full)
        # Assuming basic version logic is encapsulated or inline:
        # For a leaf, it goes to queue[depth]
        queues[depth].push_back(leaf)
        
        d = depth
        while d > 0 and queues[d].is_full():
            p = InternalNode()
            p.children = queues[d].get_all_elements()
            
            for child in p.children:
                if not child.is_empty():
                    write_to_disk(child)
            
            queues[d].clear()
            queues[d - 1].push_back(p)
            d -= 1
            
        current_morton = leaf.morton
```

**Parameters:**
- `depth`: The maximum depth of the octree. Typical values depend on the voxel grid resolution.
- Queue size: Typically 8 for internal nodes (since it's an octree), but the implementation may use a larger buffer for efficiency.

**Edge Cases and Pitfalls:**
- Precision: Morton codes are 64-bit integers. Ensure no overflow when calculating differences.
- Boundary: If `nb_empty_nodes` is exactly a power of 8, the logic for $a$ must handle the strict inequality $8^a < \text{nb\_empty\_nodes}$ correctly.
- Empty Input: If the input stream is empty, the algorithm terminates immediately.

## Operating characteristics
- **Time Complexity:** The optimized version is over two orders of magnitude faster than the non-optimized version [S1].
- **Memory Complexity:** The process consumes only roughly 1.6 MB of memory [S1].
- **Scaling:** Efficient for large voxel grids where the majority of cells are empty.
- **Strengths:** Significantly reduced queue operations by inserting empty parent nodes directly.
- **Limitations:** Requires sorted input of Morton codes.

## Background
The optimized version was introduced by Lagae and Dutre in 2008 [S1]. It addresses the inefficiency of the basic version, which spends considerable time processing empty nodes. The key insight is that pushing back $2^d$ empty nodes is equivalent to pushing back a single node at the level above. This method is part of the out-of-core construction of sparse voxel octrees, allowing for the handling of very large voxel grids that do not fit in main memory.
