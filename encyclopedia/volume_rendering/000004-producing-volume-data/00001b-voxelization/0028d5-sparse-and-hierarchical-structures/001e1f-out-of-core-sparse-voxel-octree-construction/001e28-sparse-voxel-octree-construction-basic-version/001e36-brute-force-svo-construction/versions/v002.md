# Brute Force SVO Construction

Also called: In-Memory SVO Construction, Sparse Voxel Octree (SVO) Construction, Top-down Octree Construction with Pruning

## Overview
Brute Force SVO Construction is a top-down algorithm that builds a complete octree in memory and subsequently prunes empty branches to form a Sparse Voxel Octree (SVO) [S2, unofficial]. It differs from its siblings, such as [Sparse Voxel Octree Construction via Morton Code Sorting](2227-sparse-voxel-octree-construction-via-morton-code-sorting.md), by avoiding complex sorting or streaming logic in favor of a simple recursive subdivision and depth-first search [S2, unofficial]. This method is chosen when implementation simplicity is prioritized over memory efficiency and construction speed [S2, unofficial].

## How it works
**Inputs:**
- `worldSize`: The side length of the root bounding box in world units [S1, unofficial].
- `maxDepth`: The maximum recursion depth, determining the finest voxel resolution [S1, unofficial].
- `geometries`: Scene geometry objects to intersect against [S1, unofficial].

**Outputs:**
- An SVO structure consisting of pruned `IndirectionGrid` nodes and `Data` nodes [S1, unofficial].

**Data Structures:**
1.  **IndirectionGrid**: An array of 8 `Cell` objects representing the 8 children of an octree node [S1, unofficial].
2.  **Cell**: A structure containing:
    -   `node_type`: Enum value `DATA` or `INDEX` [S1, unofficial].
    -   If `DATA`:
        -   `color`: `Vector3f` storing the geometry's color, normalized by dividing by `worldSize` [S1, unofficial].
        -   `real_location`: `Vector3f` storing the geometry's real-world location, normalized by `worldSize` [S1, unofficial].
    -   If `INDEX`:
        -   `texture_index`: `Vector3f` storing the 3D texture coordinate pointing to the child `IndirectionGrid` [S1, unofficial].
3.  **IndirectionPool**: A pool with capacity $8 \times \text{maxDepth}^2$ used to manage `IndirectionGrid` allocations [S1, unofficial].

**Algorithm Steps:**

1.  **Initialization**: Create an empty list for `geometries` and initialize the `indirectionPool` with capacity $8 \times \text{maxDepth}^2$ [S1, unofficial].
2.  **Root Creation**: Call `createNode(0, Vector3f(0, 0, 0))` to start generation at depth 0 with the origin [S1, unofficial].
3.  **Recursive Subdivision (`createNode`)**:
    For a call `createNode(depth, boxStart)`:
    a.  Calculate child box size:
        $$ \text{childBoxSize} = \frac{\text{worldSize}}{2^{\text{depth}+1}} $$
        [S1, unofficial]
    b.  Define child box offsets for the 8 sub-cubes relative to the parent's minimum corner [G].
    c.  Iterate $i$ from 0 to 7 for the 8 sub-nodes:
        i.  Calculate `childBoxStart` using `childBoxOffsets[i] * childBoxSize + boxStart`, and `childBoxEnd = childBoxStart + childBoxSize` [S1, unofficial].
        ii. Check for intersection between the child box and any geometry in the scene using `Geometry.intersects(childBoxStart, childBoxEnd)` [S1, unofficial].
    d.  **Branching Logic**:
        -   If $\text{depth} + 1 \neq \text{maxDepth}$ (not leaf level):
            -   If intersection is not null:
                1.  Recursively call `createNode(depth + 1, childBoxStart)` to create a child indirection grid [S1, unofficial].
                2.  Create an `INDEX` cell pointing to the new grid's texture index [S1, unofficial].
                3.  Assign this cell to the corresponding child slot of the current node [S1, unofficial].
        -   If $\text{depth} + 1 == \text{maxDepth}$ (leaf level):
            -   If intersection is not null:
                1.  Create a `DATA` cell [S1, unofficial].
                2.  Set `color` by normalizing the geometry's color by dividing by `worldSize` [S1, unofficial].
                3.  Set `real_location` by normalizing the geometry's real location by `worldSize` [S1, unofficial].
                4.  Assign this cell to the corresponding child slot of the current node [S1, unofficial].
    e.  If no intersection is found for a child, the child slot remains empty [S1, unofficial].
4.  **Pruning**: Perform a depth-first search and grid lookup to prune empty branches [S2, unofficial].
5.  **Gathering**: After pruning, octree nodes are spread all over memory; an extra pass is required to gather them into a sequential structure (array) for cache coherence [S2, unofficial].

**Pseudocode:**

```python
class Vector3f:
    def __init__(self, x=0.0, y=0.0, z=0.0):
        self.x, self.y, self.z = x, y, z
    def __add__(self, other):
        return Vector3f(self.x + other.x, self.y + other.y, self.z + other.z)
    def __mul__(self, scalar):
        return Vector3f(self.x * scalar, self.y * scalar, self.z * scalar)
    def __truediv__(self, scalar):
        return Vector3f(self.x / scalar, self.y / scalar, self.z / scalar)

class Cell:
    INDEX = 0
    DATA = 1
    def __init__(self, node_type, color=None, real_location=None, texture_index=None):
        self.node_type = node_type
        self.color = color
        self.real_location = real_location
        self.texture_index = texture_index

class IndirectionGrid:
    def __init__(self, children=None):
        self.children = children if children else [None] * 8

class IndirectionPool:
    def __init__(self, capacity):
        self.capacity = capacity
        self.grids = [None] * capacity
        self.used = 0
    def allocate(self):
        if self.used < self.capacity:
            grid = IndirectionGrid()
            self.grids[self.used] = grid
            self.used += 1
            return grid
        return None

# Standard octree offsets: 0 or 1 for each axis relative to parent min corner
child_box_offsets = [
    Vector3f(0,0,0), Vector3f(1,0,0), Vector3f(0,1,0), Vector3f(1,1,0),
    Vector3f(0,0,1), Vector3f(1,0,1), Vector3f(0,1,1), Vector3f(1,1,1)
]

def build_svo(world_size, max_depth, geometries):
    indirection_pool = IndirectionPool(capacity=8 * max_depth * max_depth)
    root = create_node(0, Vector3f(0, 0, 0), world_size, max_depth, geometries, indirection_pool)
    prune_tree(root)
    gathered_nodes = gather_nodes(root)
    return gathered_nodes

def create_node(depth, box_start, world_size, max_depth, geometries, indirection_pool):
    child_box_size = world_size / (2 ** (depth + 1))
    children = [None] * 8
    
    for i in range(8):
        child_box_start = box_start + (child_box_offsets[i] * child_box_size)
        child_box_end = child_box_start + Vector3f(child_box_size, child_box_size, child_box_size)
        
        intersection = check_intersection(child_box_start, child_box_end, geometries)
        
        if intersection is not None:
            if depth + 1 != max_depth:
                child_grid = create_node(depth + 1, child_box_start, world_size, max_depth, geometries, indirection_pool)
                cell = Cell(node_type=Cell.INDEX, texture_index=Vector3f(0, 0, 0))
            else:
                normalized_color = intersection.color / world_size
                normalized_location = intersection.location / world_size
                cell = Cell(node_type=Cell.DATA, color=normalized_color, real_location=normalized_location)
            
            children[i] = cell
        else:
            children[i] = None
            
    return IndirectionGrid(children=children)

def check_intersection(box_start, box_end, geometries):
    for geom in geometries:
        if geom.intersects(box_start, box_end):
            return geom
    return None

def prune_tree(node):
    if node is None:
        return
    for i in range(8):
        if node.children[i] is not None:
            if node.children[i].node_type == Cell.INDEX:
                prune_tree(node.children[i].grid)
                if node.children[i].grid.children == [None] * 8:
                    node.children[i] = None

def gather_nodes(node):
    result = []
    collect_recursive(node, result)
    return result

def collect_recursive(node, result):
    if node is None:
        return
    result.append(node)
    for child in node.children:
        if child is not None:
            if child.node_type == Cell.INDEX:
                collect_recursive(child.grid, result)
```

**Edge Cases and Pitfalls:**
-   **Memory Usage**: The entire octree structure must be held in memory at runtime, leading to high memory usage [S2, unofficial].
-   **Dense Scenes**: The texture size calculation assumes 1/2 of the space is empty, which may break if the scene is dense [S1, unofficial].
-   **Index Limitation**: Index nodes can only point to $2^8=255$ values along each axis, limiting the max texture size to 256 [S1, unofficial].
-   **Cache Coherence**: After pruning, octree nodes are spread all over memory; an extra pass is required to gather them into a sequential structure for cache coherence [S2, unofficial].

## Operating characteristics
-   **Time Complexity**: $O(N)$ where $N$ is the number of nodes visited during construction and pruning [S2, unofficial].
-   **Memory Complexity**: $O(N)$, requiring the entire octree to be stored in memory simultaneously [S2, unofficial].
-   **Performance**: Simple to implement but suffers from high memory consumption and poor cache coherence due to scattered nodes [S2, unofficial].
-   **Strengths**: Simple recursive implementation; easy to write and debug [S2, unofficial].
-   **Limitations**: High memory usage; not suitable for very large scenes or out-of-core construction; requires post-processing for cache coherence [S2, unofficial].
-   **When to use**: Not given in the sources.
-   **When not to use**: Large-scale scenes, out-of-core processing, or when memory efficiency is critical [S2, unofficial].

## Background
The brute force approach was one of the first methods proposed for constructing Sparse Voxel Octrees [S2, unofficial]. It was introduced as a simple baseline to demonstrate the concept of sparsifying an octree by pruning empty branches [S2, unofficial]. The method is described in Jeroen Baert's blog post on out-of-core construction of SVOs [S2, unofficial].
