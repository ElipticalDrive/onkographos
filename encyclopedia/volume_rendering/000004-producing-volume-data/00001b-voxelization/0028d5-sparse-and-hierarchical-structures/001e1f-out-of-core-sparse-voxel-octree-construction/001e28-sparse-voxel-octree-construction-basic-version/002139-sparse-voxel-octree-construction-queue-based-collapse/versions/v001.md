# Sparse Voxel Octree Construction (Queue-Based Collapse)

Also called: Builder collapse, NodeQueue processing, Queue-based SVO construction, Queue-based hierarchical tree construction, Sparse Voxel Octree (SVO) Builder with Queue-Based Collapse, Zazen Builder

## Overview
This method constructs a Sparse Voxel Octree (SVO) from a stream of indexed leaves by maintaining a fixed-size array of queues, one per tree depth level, and collapsing homogeneous subtrees into single leaf or invalid nodes to compress the structure [S1, unofficial]. It differs from the Basic Version by explicitly handling the "collapse" of identical children into a single leaf node during the push operation, and from the Optimized Version by using a simpler, non-optimized queue management strategy without advanced memory pooling or sorting pre-processing [S1, unofficial].

## How it works
**Inputs and Outputs:**
- **Input:** A stream of indexed leaves, where each leaf has an `index` (Morton code or similar linearized coordinate) and a `leaf` data structure (e.g., RGBA color). The stream is assumed to be sorted by index.
- **Output:** A serialized SVO written to disk via a `BlockWriter`, consisting of Voxel and Leaf nodes.

**Data Structures:**
The core data structures are defined as follows [S1, unofficial]:

1.  **`Node`**: A union-based structure representing either a Voxel or a Leaf.
    ```cpp
    struct Node {
        union {
            Voxel voxel;
            Leaf leaf;
        };
        bool is_leaf;
        bool is_valid;

        // Constructors
        Node() : is_leaf(false), is_valid(false) {}
        Node(const Leaf& leaf) : leaf(leaf), is_leaf(true), is_valid(true) {}
        Node(const Voxel& voxel) : voxel(voxel), is_leaf(false), is_valid(true) {}
    };
    ```

2.  **`Voxel`**: A non-leaf node structure.
    ```cpp
    struct Voxel {
        uint32_t child; // Offset to children in block
        uint8_t valid;  // 8-bit mask for visible children
        uint8_t leaf;   // 8-bit mask for leaf children
    };
    ```

3.  **`Leaf`**: A leaf node structure.
    ```cpp
    struct Leaf {
        uint8_t rgba[4]; // Validity determined by rgba[3] != 0x00
    };
    ```

4.  **`NodeQueue`**: A fixed-size queue for nodes at a specific depth level.
    ```cpp
    class NodeQueue {
        Node data[8];
        uint8_t size = 0;

    public:
        void push(const Node& node) { data[size] = node; size++; }
        bool full() const { return size == 8; }
        bool empty() const { return !size; }
        void clear() { size = 0; }
        Node& operator[](uint8_t index) { return data[index]; }
    };
    ```

5.  **`Builder`**: The main builder class.
    ```cpp
    class Builder {
        NodeQueue* queues;
        const unsigned int queue_count;
        unsigned long long int stream_index = 0;
        BlockWriter& writer;

    public:
        Builder(unsigned int q_count, BlockWriter& w)
            : queue_count(q_count), writer(w) {
            queues = new NodeQueue[queue_count];
        }
        ~Builder() { delete[] queues; }
        // ... methods ...
    };
    ```

**Parameters:**
- `queue_count`: The number of queues used. Typically 8 for an octree, corresponding to the maximum depth of the tree or a specific design choice [S1, unofficial].

**Algorithm Steps:**

1.  **Initialization:**
    - Initialize `stream_index` to 0.
    - Initialize all `queues` to empty.

2.  **Processing a Leaf (`add_leaf`):**
    - Let `ileaf` be the incoming leaf with `ileaf.index` and `ileaf.leaf`.
    - Calculate `leaf_count = ileaf.index - stream_index`.
    - Loop while `leaf_count > 0`:
        1.  Calculate `power`:
            - If `leaf_count >= 8`, `power = floor(log(leaf_count) / log(8))`.
            - Else, `power = 0`.
        2.  Find `non_empty_i`: The index of the first non-empty queue in `queues[0..queue_count-1]`. If all are empty, `non_empty_i = queue_count`.
        3.  Calculate `insert_i = min(power, non_empty_i)`.
        4.  If `insert_i >= queue_count`, throw error "Homogenous model" and write the leaf directly to the output (bypassing the tree structure for this segment) [S1, unofficial].
        5.  Create `to_push` Node:
            - If `ileaf.leaf.valid()` is true (e.g., `rgba[3] != 0x00`), `to_push = Node(ileaf.leaf)`.
            - Else, `to_push = Node()` (invalid node).
        6.  Call `push_at(to_push, insert_i)`.
        7.  Subtract `pow(8, insert_i)` from `leaf_count`.
    - Set `stream_index = ileaf.index`.

3.  **Pushing to Queue (`push_at`):**
    - Input: `node` (Node), `index` (uint8_t).
    - Push `node` to `queues[index]`.
    - Call `collapse(index)`.

4.  **Collapse Logic (`collapse`):**
    - Input: `index` (uint8_t).
    - If `queues[index]` is not full, return immediately [S1, unofficial].
    - Initialize `parent_is_leaf = true`.
    - Initialize `parent` Voxel: `parent.valid = 0`, `parent.leaf = 0`, `parent.child = writer.pos()`.
    - Loop `j` from 0 to 7 over `queues[index]` (which is now full):
        1.  Determine `to_push` for the parent level:
            - If `parent_is_leaf` is true:
                - `to_push = Node(queues[index][0].leaf)`. (Assumes all children are identical leaves).
            - Else if `!parent.valid` (i.e., parent is currently invalid):
                - `to_push = Node()` (invalid node).
            - Else:
                - Write the 8 children from `queues[index]` to `writer`. For each child, if it is a leaf, write the Leaf; if it is a valid voxel, write the Voxel.
                - `to_push = Node(parent)`.
        2.  Update `parent_is_leaf`:
            - If `queues[index][j].is_leaf` is false, set `parent_is_leaf = false`.
            - If `queues[index][j].is_valid` is false, update `parent.valid` mask accordingly.
            - If `queues[index][j].is_leaf` is true, update `parent.leaf` mask accordingly.
        3.  **Note:** The source notes indicate the implementation is truncated, so the exact logic for updating the `parent.valid` and `parent.leaf` masks based on the 8 children is not fully detailed [S1, unofficial]. However, standard SVO construction implies these masks track which children are valid and which are leaves.
    - After processing all 8 children, if `parent_is_leaf` is true, the entire subtree is collapsed into a single leaf node. This leaf node is then pushed to the parent queue (`queues[index-1]` or higher) via `push_at`. If `parent_is_leaf` is false, the `parent` Voxel is pushed to the parent queue.
    - Clear `queues[index]`.

**Edge Cases and Pitfalls:**
- **Homogenous Model:** If `insert_i >= queue_count`, the algorithm cannot represent the gap in the current tree structure and writes the leaf directly. This is a fallback for very large gaps or specific data distributions [S1, unofficial].
- **Truncated Logic:** The exact mask calculation for `parent.valid` and `parent.leaf` is not fully specified in the source. Implementers must infer standard bitmask operations based on the 8 children's validity and leaf status [S1, unofficial].
- **Precision:** `log` and `floor` operations for `power` calculation should use floating-point arithmetic with care for large `leaf_count` values.

## Operating characteristics
- **Time Complexity:** Not explicitly given in the sources. The algorithm processes each leaf once, with queue operations being O(1) per push/collapse. The collapse step is O(1) since queues are fixed size (8).
- **Memory Complexity:** O(queue_count * 8) for the queues, plus O(1) for other variables. This is very memory efficient compared to building the entire tree in memory.
- **Measured Performance:** Not given in the sources.
- **Strengths:** Low memory footprint, suitable for out-of-core construction, simple implementation.
- **Limitations:** Truncated logic in source makes full implementation difficult without inference. May not be optimal for all data distributions due to fixed queue size.

## Background
This method is associated with the "Zazen" project by Gabriel Muller, an unofficial implementation of a volume renderer using Sparse Voxel Octrees [S1, unofficial]. It is part of a series of SVO construction methods, evolving from the Basic Version to include queue-based collapse for better compression.
