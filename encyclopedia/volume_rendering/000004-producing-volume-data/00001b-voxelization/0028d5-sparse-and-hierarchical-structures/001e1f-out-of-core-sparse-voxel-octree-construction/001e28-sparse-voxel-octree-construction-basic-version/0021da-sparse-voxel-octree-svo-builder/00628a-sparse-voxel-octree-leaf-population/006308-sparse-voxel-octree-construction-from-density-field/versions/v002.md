# Sparse Voxel Octree Construction from Density Field

Also called: ConstructOctreeFromField pipeline, OpenCL Octree Construction from Density Field

## Overview
This method converts a 3D density field into a compact sparse voxel octree (SVO) structure using an OpenCL-based pipeline [S1, unofficial]. It identifies active voxels, compacts them into a contiguous node list, and computes leaf node data including quadratic error function (QEF) fits, normals, and materials [S1, unofficial]. It builds on [Sparse Voxel Octree Leaf Population](18654-sparse-voxel-octree-leaf-population.md) and is distinguished by its explicit handling of OpenCL/OpenGL interop limitations, opting for a download-reupload strategy to avoid rendering thread blocking [S1, unofficial].

## How it works
**Inputs:**
- `field`: A structure containing the 3D density field data, including `field.numEdges`, `field.materials`, `field.edgeIndices`, `field.normals`, and `field.size` [S1, unofficial].
- `meshGen`: A configuration structure containing `voxelsPerChunk` [S1, unofficial].
- `octree`: The target octree structure with buffers `octree->d_nodeCodes`, `octree->d_nodeMaterials`, `octree->d_vertexPositions`, and `octree->d_vertexNormals` [S1, unofficial].

**Outputs:**
- `octree`: Populated with compacted node codes, materials, vertex positions, and normals for active chunks [S1, unofficial].

**Data Structures:**
- `chunkBufferSize`: Integer, size `meshGen->voxelsPerChunk * meshGen->voxelsPerChunk * meshGen->voxelsPerChunk` [S1, unofficial].
- `d_leafOccupancy`, `d_leafEdgeInfo`, `d_leafCodes`, `d_leafMaterials`, `d_voxelScan`: `cl::Buffer` of type `CL_MEM_READ_WRITE`, size `chunkBufferSize * sizeof(int)` [S1, unofficial].
- `d_compactLeafEdgeInfo`, `octree->d_nodeCodes`, `octree->d_nodeMaterials`: `CL_MEM_READ_WRITE` buffers, size `octree->numNodes * sizeof(int)` [S1, unofficial].
- `octree->d_vertexPositions`, `octree->d_vertexNormals`: `CL_MEM_READ_WRITE` buffers, size `octree->numNodes * sizeof(cl_float4)` [S1, unofficial].
- `d_qefs`: `CL_MEM_READ_WRITE` buffer, size `octree->numNodes * sizeof(QEFData)` [S1, unofficial].
- `edgeHashTable`: Cuckoo hash table initialized with `field.numEdges` [S1, unofficial].

**Parameters:**
- `sampleScale`: Scaling factor for leaf creation, calculated as `field.size / (meshGen->voxelsPerChunk * LEAF_SIZE_SCALE)` [S1, unofficial]. `LEAF_SIZE_SCALE` is not defined in the sources [G].

**Steps:**
1. Check if `field.numEdges == 0` [S1, unofficial]. If true, return `CL_SUCCESS` immediately to skip processing [S1, unofficial].
2. Launch `FindActiveVoxels` kernel with NDRange `(meshGen->voxelsPerChunk, meshGen->voxelsPerChunk, meshGen->voxelsPerChunk)` [S1, unofficial]. Bind `field.materials`, `d_leafOccupancy`, `d_leafEdgeInfo`, `d_leafCodes`, and `d_leafMaterials` [S1, unofficial].
3. Compute `octree->numNodes` using an exclusive scan on `d_leafOccupancy` into `d_voxelScan` with size `chunkBufferSize` [S1, unofficial].
4. If `octree->numNodes <= 0`, set `octree->numNodes = 0` and return the error code instead of proceeding [S1, unofficial].
5. Launch `CompactVoxels` kernel with NDRange `chunkBufferSize` [S1, unofficial]. Bind `d_leafOccupancy`, `d_leafEdgeInfo`, `d_leafCodes`, `d_leafMaterials`, `d_voxelScan`, `octree->d_nodeCodes`, `d_compactLeafEdgeInfo`, and `octree->d_nodeMaterials` [S1, unofficial].
6. Initialize Cuckoo hash table for edge lookups: `Cuckoo_InitialiseTable(&edgeHashTable, field.numEdges)` [S1, unofficial].
7. Insert keys: `Cuckoo_InsertKeys(&edgeHashTable, field.edgeIndices, field.numEdges)` [S1, unofficial].
8. Launch `CreateLeafNodes` kernel with NDRange `octree->numNodes` [S1, unofficial]. Bind `sampleScale`, `octree->d_nodeCodes`, `d_compactLeafEdgeInfo`, `field.normals`, `octree->d_vertexNormals`, `d_qefs`, and cuckoo table components (`table`, `stash`, `prime`, `hashParams`, `stashUsed`) [S1, unofficial].

**Pseudocode:**
```python
CL_SUCCESS = 0
ERROR_CODE_NO_SURFACE = -1

def exclusive_scan(input_array, output_array, size):
    """Computes prefix sum of input_array into output_array."""
    acc = 0
    for i in range(size):
        output_array[i] = acc
        acc += input_array[i]

def execute_kernel_FindActiveVoxels(ndrange, materials, leaf_occupancy, leaf_edge_info, leaf_codes, leaf_materials):
    """Launches OpenCL kernel FindActiveVoxels over ndrange."""
    pass

def execute_kernel_CompactVoxels(ndrange, leaf_occupancy, leaf_edge_info, leaf_codes, leaf_materials, voxel_scan, node_codes, compact_leaf_edge_info, node_materials):
    """Launches OpenCL kernel CompactVoxels over ndrange."""
    pass

def execute_kernel_CreateLeafNodes(ndrange, sample_scale, node_codes, compact_leaf_edge_info, normals, vertex_normals, qefs, table, stash, prime, hash_params, stash_used):
    """Launches OpenCL kernel CreateLeafNodes over ndrange."""
    pass

def Cuckoo_InitialiseTable(hash_table, num_edges):
    """Initializes cuckoo hash table for num_edges entries."""
    pass

def Cuckoo_InsertKeys(hash_table, edge_indices, num_edges):
    """Inserts edge_indices into hash_table."""
    pass

def ConstructOctreeFromDensityField(field, meshGen, octree):
    # Step 1: Early exit check
    if field.numEdges == 0:
        return CL_SUCCESS

    # Calculate buffer sizes
    voxelsPerChunk = meshGen.voxelsPerChunk
    chunkBufferSize = voxelsPerChunk * voxelsPerChunk * voxelsPerChunk

    # Allocate leaf buffers
    d_leafOccupancy = [0] * chunkBufferSize
    d_leafEdgeInfo = [0] * chunkBufferSize
    d_leafCodes = [0] * chunkBufferSize
    d_leafMaterials = [0] * chunkBufferSize
    d_voxelScan = [0] * chunkBufferSize

    # Step 2: Find Active Voxels
    execute_kernel_FindActiveVoxels(
        ndrange=(voxelsPerChunk, voxelsPerChunk, voxelsPerChunk),
        materials=field.materials,
        leaf_occupancy=d_leafOccupancy,
        leaf_edge_info=d_leafEdgeInfo,
        leaf_codes=d_leafCodes,
        leaf_materials=d_leafMaterials
    )

    # Step 3: Compute Node Count via Exclusive Scan
    exclusive_scan(d_leafOccupancy, d_voxelScan, chunkBufferSize)
    octree.numNodes = d_voxelScan[-1] if chunkBufferSize > 0 else 0

    # Step 4: Edge Case Handling
    if octree.numNodes <= 0:
        octree.numNodes = 0
        return ERROR_CODE_NO_SURFACE

    # Allocate compact buffers
    octree.d_nodeCodes = [0] * octree.numNodes
    octree.d_nodeMaterials = [0] * octree.numNodes
    d_compactLeafEdgeInfo = [0] * octree.numNodes
    octree.d_vertexPositions = [0.0] * (octree.numNodes * 4)
    octree.d_vertexNormals = [0.0] * (octree.numNodes * 4)
    d_qefs = [None] * octree.numNodes

    # Step 5: Compact Voxels
    execute_kernel_CompactVoxels(
        ndrange=chunkBufferSize,
        leaf_occupancy=d_leafOccupancy,
        leaf_edge_info=d_leafEdgeInfo,
        leaf_codes=d_leafCodes,
        leaf_materials=d_leafMaterials,
        voxel_scan=d_voxelScan,
        node_codes=octree.d_nodeCodes,
        compact_leaf_edge_info=d_compactLeafEdgeInfo,
        node_materials=octree.d_nodeMaterials
    )

    # Step 6: Initialize Cuckoo Hash Table
    edgeHashTable = {}
    Cuckoo_InitialiseTable(edgeHashTable, field.numEdges)

    # Step 7: Insert Edge Indices
    Cuckoo_InsertKeys(edgeHashTable, field.edgeIndices, field.numEdges)

    # Step 8: Create Leaf Nodes
    # LEAF_SIZE_SCALE is not given in the sources [G]
    LEAF_SIZE_SCALE = 1.0
    sampleScale = field.size / (voxelsPerChunk * LEAF_SIZE_SCALE)

    # Launch OpenCL kernel: CreateLeafNodes
    execute_kernel_CreateLeafNodes(
        ndrange=octree.numNodes,
        sample_scale=sampleScale,
        node_codes=octree.d_nodeCodes,
        compact_leaf_edge_info=d_compactLeafEdgeInfo,
        normals=field.normals,
        vertex_normals=octree.d_vertexNormals,
        qefs=d_qefs,
        table=edgeHashTable.get('table'),
        stash=edgeHashTable.get('stash'),
        prime=edgeHashTable.get('prime'),
        hash_params=edgeHashTable.get('hashParams'),
        stash_used=edgeHashTable.get('stashUsed')
    )
```

## Operating characteristics
- Time complexity is not given in the sources. [S1, unofficial]
- Memory complexity is not given in the sources. [S1, unofficial]
- The pipeline downloads generated mesh data to main memory before reuploading to OpenGL, which is less than optimal. [S1, unofficial]
- The method avoids rendering thread blocking associated with OpenCL/OpenGL interop. [S1, unofficial]
- Data transfer overhead between APIs and potential resource starvation causing hitches in OpenGL operations are limitations. [S1, unofficial]
- It should be used when using OpenCL for voxel generation and OpenGL for rendering, and Vulkan is not available. [S1, unofficial]
- It should not be used when low-latency interop is required, as Vulkan is suggested as a solution. [S1, unofficial]

## Background
This method originates from the "leven" project by Nick Gildea, an unofficial personal project using OpenCL for GPGPU voxel component generation and OpenGL for rendering. [S1, unofficial] The author noted that while OpenCL and OpenGL might seem compatible, their interop causes the rendering thread to block during GPU data transfer, leading to unworkable performance. [S1, unofficial] The pipeline was designed as a workaround to these interop issues. [S1, unofficial]
