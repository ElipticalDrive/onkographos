# Neural Sparse Voxel Fields (NSVF)

Also called: Sparse Voxel Fields

## Overview

Neural Sparse Voxel Fields (NSVF) is a hybrid neural scene representation that accelerates free-viewpoint rendering by combining the spatial efficiency of sparse voxel grids with the implicit modeling power of neural networks [S3, S4, unofficial]. It solves the problem of inefficient sampling in empty space inherent in monolithic neural radiance fields (NeRF) by restricting ray-marching to non-empty voxels, thereby reducing the number of required neural network evaluations [S5, unofficial]. Unlike NeRF, which uses a single global MLP, NSVF uses local voxel embeddings, allowing parameter growth to be additive rather than multiplicative, which enables scalability to larger scenes [S4, unofficial].

## How it works

**Inputs and Outputs:**
*   **Inputs:** A set of posed 2D images (camera poses and RGB values); optional coarse geometry for initialization.
*   **Outputs:** Rendered RGB images and depth maps for novel viewpoints.

**Data Structures:**
*   **Sparse Voxel Grid:** A hierarchical structure (typically an octree or hash table) storing only non-empty voxels.
*   **Voxel Features:** Each non-empty voxel stores a learnable feature vector (embedding) of dimension $D$ (default 32) [S1, unofficial].
*   **Bounding Box:** An initial axis-aligned bounding box (AABB) enclosing the scene, subdivided into an initial grid of ~1000 voxels [S3, unofficial].

**Algorithm Steps:**

1.  **Voxel Initialization:**
    *   Define an initial bounding box with sufficient margin around the scene.
    *   Subdivide the box into a coarse grid (e.g., ~1000 voxels) [S3, unofficial].
    *   If coarse geometry is available, initialize voxels by voxelizing the geometry; otherwise, initialize uniformly [S1, S3, unofficial].

2.  **Ray-Voxel Intersection:**
    *   For each ray, perform an Axis-Aligned Bounding Box (AABB) intersection test to determine entry into the voxel grid [S1, S3, unofficial].
    *   Identify the sequence of non-empty voxels intersected by the ray [S3, unofficial].

3.  **Ray Marching and Sampling:**
    *   **Coarse Sampling:** Uniformly sample $N_{samples}$ points along the ray within the intersected voxels. If `use_disp` is true, sample in disparity space (inverse depth) [S2, unofficial].
    *   **Perturbation:** Perturb the sampling positions for the coarse model using a random factor to reduce banding artifacts [S2, unofficial].
    *   **Importance Sampling (Optional):** If $N_{importance} > 0$, perform importance sampling based on coarse weights to generate $N_{importance}$ fine samples [S2, unofficial].

4.  **Feature Embedding and Neural Query:**
    *   For each sampled point $p$, retrieve the 8 corner features of the containing voxel [S1, unofficial].
    *   Perform trilinear interpolation of these corner features to obtain the voxel embedding $E_v$ for point $p$ [S3, unofficial].
    *   Apply post-processing (e.g., Fourier features) to the interpolated embedding [S3, unofficial].
    *   Concatenate the embedded position with the embedded ray direction $d$ (repeated for each sample) [S2, unofficial].
    *   Pass the concatenated vector through a query MLP to predict raw density $\sigma$ and RGB color $c$ [S1, S3, unofficial].
    *   *Note:* The model outputs shape $(N_{rays}, N_{samples}, 4)$ for RGB+Sigma or $(N_{rays}, N_{samples})$ for Sigma only [S2, unofficial].

5.  **Volume Rendering Integration:**
    *   Compute deltas $\delta_i$ (distances between samples). Convert to real-world distances by multiplying by the norm of the ray direction [S2, unofficial].
    *   Add noise to predicted sigmas: $\sigma' = \sigma + \mathcal{N}(0, \text{noise\_std}^2)$ [S2, unofficial].
    *   Compute alpha values using the volume rendering formula:
        $$ \alpha_i = 1 - \exp(-\delta_i \cdot \max(0, \sigma'_i)) $$
    *   Compute transmittance $T_i = \prod_{j < i} (1 - \alpha_j)$ [S2, unofficial].
    *   Accumulate color and depth:
        $$ C = \sum_i T_i \alpha_i c_i, \quad D = \sum_i T_i \alpha_i z_i $$
    *   Handle background: Define a learnable background RGB if the ray misses the object within the voxel bounds [S1, unofficial].

6.  **Early Termination:**
    *   Terminate volume accumulation when the accumulated transparency (transmittance) $A$ drops below a threshold $\varepsilon$ (default 0.01) to skip empty space behind surfaces [S1, S3, unofficial].

7.  **Progressive Training and Pruning:**
    *   **Self-Pruning:** Every 2.5K iterations, check the maximum predicted density in each voxel. If all sampled points have very low density, prune the voxel [S1, S3, unofficial].
    *   **Progressive Refinement:** At specific iteration milestones (e.g., 5K, 25K, 75K), halve the voxel size and ray-marching step size [S3, unofficial].
    *   Subdivide each voxel into 8 sub-voxels. Initialize the feature representations of the new vertices via trilinear interpolation of the original eight voxel vertices [S1, S3, unofficial].

## Subtopics

### SuRFNet
SuRFNet is a variant that distills multiple image views into partial 3D Sparse Radiance Fields (SRFs) and learns in the 3D sparse voxel space to generate full SRFs [S6]. It uses MinkowskiNet as a 3D sparse convolution network to convert partial SRFs to whole SRFs, ensuring multi-view consistency [S6]. A key challenge is that input/output topologies may differ due to sparse convolutional strides and pruning, requiring specific sampling (e.g., Quantized Gaussian sampling) for loss calculation [S6].

## Operating characteristics

*   **Time Complexity:** Rendering is faster than NeRF because it skips empty space sampling. The complexity depends on the number of non-empty voxels intersected by rays rather than the total volume [S5, unofficial]. However, the use of 32-dim embeddings with sinusoidal positional encoding leads to relatively large GPU time compared to lighter embeddings [S1, unofficial].
*   **Memory Complexity:** Memory usage is proportional to the number of non-empty voxels and their feature dimensions. It scales additively with scene size, unlike NeRF's multiplicative parameter growth [S4, unofficial].
*   **Performance:** On synthetic datasets, NSVF achieves high PSNR and SSIM with faster rendering speeds (e.g., 2.62 s/frame on certain hardware) compared to NeRF [S3, unofficial].
*   **Strengths:** Efficient sampling in empty space; scalable to large scenes; allows spatial editing due to explicit geometry representation [S4, unofficial].
*   **Limitations:** Cannot handle complex backgrounds well in its basic form; requires careful initialization and progressive training to converge; embedding size can be a bottleneck [S3, S1, unofficial].
*   **When to use:** When rendering large scenes with significant empty space, or when scalability and spatial editing are required.
*   **When not to use:** When memory is extremely constrained and a simpler, denser representation is preferred, or when complex background handling is critical without modification.

## Background

NSVF was introduced by Liu et al. in 2020 as a method for fast and high-quality free-viewpoint rendering [S3, unofficial]. It extends NeRF ideas by incorporating a multi-resolution coarse-to-fine approach and using a sparse voxel grid for spatial embedding [S2, unofficial]. The method was designed to address the inefficiency of NeRF's uniform sampling and its difficulty in scaling to large scenes [S4, unofficial]. It has been used in various datasets including Synthetic-NeRF, BlendedMVS, Tanks & Temple, and ScanNet [S3, unofficial].
