# Neural Sparse Voxel Fields (NSVF)

Also called: Sparse Voxel Fields

## Overview
Neural Sparse Voxel Fields (NSVF) is a hybrid neural scene representation that accelerates free-viewpoint rendering by combining the quality of implicit neural fields with the efficiency of explicit sparse voxel structures [S3, unofficial]. Unlike standard Neural Radiance Fields (NeRF) which samples uniformly across the entire bounding volume, NSVF restricts sampling to a sparse set of active voxels, thereby skipping empty space and significantly reducing computational cost [S1, unofficial][S4, unofficial]. It sets itself apart from its siblings by providing a coarse-to-fine multi-resolution framework that supports progressive training, self-pruning of empty voxels, and the modeling of dynamic scenes via a time dimension [S2, unofficial].

## How it works

### Inputs and Outputs
**Inputs:**
*   A set of posed 2D images (camera poses and RGB values) [S3, unofficial].
*   Optional coarse geometry for initialization [S3, unofficial].
*   Ray parameters: origin, direction, and near/far depth bounds [S2, unofficial].

**Outputs:**
*   Rendered RGB color and depth for each ray [S2, unofficial].
*   A sparse voxel grid containing learned feature embeddings [S3, unofficial].

### Data Structures

**Voxel Grid:**
*   **Layout:** A sparse hash map or list of active voxels. Each active voxel stores a learnable feature vector.
*   **Feature Vector:** A 32-dimensional vector per voxel vertex [S1, unofficial].
*   **Hierarchy:** Supports progressive subdivision. A voxel can be split into 8 sub-voxels. The features of the new sub-voxel vertices are initialized via trilinear interpolation of the parent voxel's 8 corner features [S3, unofficial].

**Ray Structure:**
*   **Fields:** `origin` (3 floats), `direction` (3 floats), `near` (float), `far` (float) [S2, unofficial].

**Sampling State:**
*   **Coarse Samples:** Array of $N_{samples}$ depth values along the ray [S2, unofficial].
*   **Fine Samples:** Array of $N_{importance}$ depth values generated via importance sampling [S2, unofficial].

### Numbered Steps

1.  **Voxel Initialization:**
    *   Define a bounding box enclosing the scene with sufficient margin [S3, unofficial].
    *   Subdivide the bounding box into approximately 1000 initial voxels [S3, unofficial].
    *   If coarse geometry is available, initialize voxels by voxelizing the geometry; otherwise, initialize uniformly [S1, unofficial][S3, unofficial].

2.  **Self-Pruning (Periodic):**
    *   Every 2,500 iterations, evaluate the maximum predicted density from uniformly sampled points inside each active voxel [S3, unofficial].
    *   If all sampled points within a voxel have very low volume density, prune (remove) the voxel from the active set [S1, unofficial].

3.  **Progressive Training (Periodic):**
    *   At iterations 5K, 25K, and 75K (or every 2,500 steps in some configurations), halve the voxel size and ray-marching step size [S3, unofficial][S1, unofficial].
    *   Split each existing voxel into 8 sub-voxels [S3, unofficial].
    *   Initialize the feature representations of the new sub-voxel vertices by trilinearly interpolating the feature representations of the original 8 voxel vertices [S3, unofficial].

4.  **Ray-Voxel Intersection:**
    *   For each ray, perform an Axis-Aligned Bounding Box (AABB) intersection test against the active voxels [S1, unofficial][S3, unofficial].
    *   Identify the set of intersected voxels along the ray [S3, unofficial].

5.  **Coarse Sampling:**
    *   Sample $N_{samples}$ (default 64) points along the ray within the intersected voxels [S2, unofficial].
    *   If `use_disp` is true, sample in disparity space (inverse depth) [S2, unofficial].
    *   Perturb the sampling positions using a `perturb` factor to avoid regular aliasing artifacts [S2, unofficial].

6.  **Voxel Embedding and Feature Extraction:**
    *   For each sampled point $p$, identify the containing voxel $V_i$ [S3, unofficial].
    *   Retrieve the 8 corner feature embeddings of $V_i$ [S1, unofficial].
    *   Perform trilinear interpolation of these 8 features to get the voxel feature $f_v$ for point $p$ [S3, unofficial].
    *   Apply post-processing to $f_v$. NSVF uses Fourier features with maximum frequency $L=6$ [S3, unofficial].
    *   Encode the spatial position $p$ using sinusoidal positional encoding (embedding dimension 32) [S1, unofficial].
    *   Encode the ray direction $d$ using the same positional encoding [S2, unofficial].
    *   Concatenate the embedded position, embedded direction, and voxel feature $f_v$ [S2, unofficial].

7.  **Neural Network Inference:**
    *   Pass the concatenated embedding through a query MLP (Multi-Layer Perceptron) [S1, unofficial].
    *   The MLP outputs raw volume density $\sigma$ and optionally RGB color [S2, unofficial].
    *   Add noise to $\sigma$: $\sigma_{noisy} = \sigma + \text{noise}$, where $\text{noise} \sim \mathcal{N}(0, \text{noise\_std}^2)$ [S2, unofficial].

8.  **Alpha and Transmittance Calculation:**
    *   Compute the distance between adjacent samples $\Delta z$. For the last sample, set $\Delta z = \infty$ (e.g., $10^{10}$) [S2, unofficial].
    *   Convert $\Delta z$ to real-world distance $\Delta d$ by multiplying by the norm of the ray direction $\|d\|$ [S2, unofficial].
    *   Compute alpha (opacity) for each sample:
        $$ \alpha = 1 - \exp(-\Delta d \cdot \max(0, \sigma_{noisy})) $$
        [S2, unofficial]

9.  **Volume Rendering Integration:**
    *   Compute transmittance $T_i$ for each sample:
        $$ T_i = \exp\left(-\sum_{j=1}^{i-1} \Delta d_j \cdot \sigma_j\right) $$
        [S2, unofficial]
    *   Compute final RGB color $C$ and Depth $D$ using standard volume rendering accumulation:
        $$ C = \sum_{i=1}^{N} T_i \alpha_i c_i $$
        $$ D = \sum_{i=1}^{N} T_i \alpha_i z_i $$
        where $c_i$ is the RGB color and $z_i$ is the depth of the $i$-th sample [S2, unofficial].

10. **Importance Sampling (Fine Model):**
    *   If $N_{importance} > 0$, use the coarse weights ($T_i \alpha_i$) to perform importance sampling [S2, unofficial].
    *   Generate $N_{importance}$ fine samples using `sample_pdf` on the coarse bins [S2, unofficial].
    *   Handle division by zero in `sample_pdf` by adding epsilon ($10^{-5}$) to weights and setting denominator to 1 if zero [S2, unofficial].
    *   Repeat steps 6-9 for the fine samples to refine the result [S2, unofficial].

11. **Early Termination:**
    *   During accumulation, if the accumulated transmittance $A$ (or transparency) drops below a threshold $\varepsilon = 0.01$, terminate the ray marching early to skip empty space behind the surface [S1, unofficial][S3, unofficial].

12. **Background Handling:**
    *   If a ray misses all active voxels or terminates early, blend the accumulated color with a learnable background RGB or a white background (if `white_back` is true) [S1, unofficial][S2, unofficial].

def nsvf_render(rays, voxel_grid, coarse_model, fine_model, 
                N_samples=64, N_importance=0, 
                early_termination_thresh=0.01, 
                noise_std=0.0, chunk_size=32768):
    """
    Renders rays using Neural Sparse Voxel Fields.
    
    Args:
        rays: Tensor of shape (N_rays, 8) containing [origin_x, origin_y, origin_z, 
              dir_x, dir_y, dir_z, near, far].
        voxel_grid: Sparse structure mapping voxel indices to 32-dim feature vectors.
        coarse_model: MLP for coarse density/color prediction.
        fine_model: MLP for fine density/color prediction.
        N_samples: Number of coarse samples per ray.
        N_importance: Number of fine samples per ray.
        early_termination_thresh: Transparency threshold for early termination.
        noise_std: Standard deviation for noise added to sigma.
        chunk_size: Batch size for inference to limit memory.
        
    Returns:
        rgbs: Tensor of shape (N_rays, 3)
        depths: Tensor of shape (N_rays, 1)
    """
    N_rays = rays.shape[0]
    device = rays.device
    
    # Initialize outputs
    rgbs = torch.zeros(N_rays, 3, device=device)
    depths = torch.zeros(N_rays, 1, device=device)
    
    # Process rays in chunks to manage memory
    for start_idx in range(0, N_rays, chunk_size):
        end_idx = min(start_idx + chunk_size, N_rays)
        chunk_rays = rays[start_idx:end_idx]
        
        # 1. Ray-Voxel Intersection
        # Find intersected voxels for each ray in the chunk
        # Returns list of lists: intersected_voxels[r] contains indices of voxels intersected by ray r
        intersected_voxels = ray_voxel_intersection(chunk_rays, voxel_grid)
        
        # 2. Coarse Sampling
        # Sample points along the ray within intersected voxels
        # z_vals: (N_rays, N_samples)
        z_vals, deltas = sample_coarse(chunk_rays, intersected_voxels, N_samples)
        
        # 3. Feature Extraction and Coarse Inference
        # Embed positions and directions
        # xyz_embed: (N_rays, N_samples, embed_dim)
        # dir_embed: (N_rays, N_samples, embed_dim)
        xyz_embed = positional_encoding(chunk_rays[:, :3].unsqueeze(1).expand(-1, N_samples, -1))
        dir_embed = positional_encoding(chunk_rays[:, 3:6].unsqueeze(1).expand(-1, N_samples, -1))
        
        # Get voxel features for each sample point
        # voxel_feats: (N_rays, N_samples, 32)
        voxel_feats = get_voxel_features(chunk_rays[:, :3], intersected_voxels, voxel_grid)
        
        # Concatenate and pass through coarse model
        # Input: xyz_embed + dir_embed + voxel_feats
        coarse_input = torch.cat([xyz_embed, dir_embed, voxel_feats], dim=-1)
        
        # Split into chunks if necessary for the MLP
        coarse_sigma, coarse_rgb = infer_chunked(coarse_model, coarse_input, chunk_size)
        
        # Add noise to sigma
        noise = torch.randn_like(coarse_sigma) * noise_std
        coarse_sigma_noisy = coarse_sigma + noise
        
        # Compute alphas
        # deltas need to be scaled by ray direction norm
        ray_dirs_norm = torch.norm(chunk_rays[:, 3:6], dim=1, keepdim=True)
        deltas_scaled = deltas * ray_dirs_norm
        
        # Alpha = 1 - exp(-delta * sigma)
        # Use relu on sigma to ensure non-negative density
        alphas = 1.0 - torch.exp(-deltas_scaled * torch.relu(coarse_sigma_noisy))
        
        # 4. Volume Rendering (Coarse)
        # Compute transmittance
        # T_i = exp(-sum_{j<i} delta_j * sigma_j)
        # Accumulate alpha * sigma for transmittance calculation
        alpha_sigma = alphas * torch.relu(coarse_sigma_noisy)
        transmittance = torch.cumprod(1.0 - alpha_sigma, dim=1)
        # Prepend 1.0 for the first sample
        transmittance = torch.cat([torch.ones_like(transmittance[:, :1]), transmittance[:, :-1]], dim=1)
        
        # Weighted accumulation
        weights = transmittance * alphas
        coarse_rgb_acc = torch.sum(weights.unsqueeze(-1) * coarse_rgb, dim=1)
        coarse_depth_acc = torch.sum(weights * z_vals, dim=1, keepdim=True)
        
        # 5. Early Termination Check
        # If accumulated transparency (1 - transmittance) is high enough, we can stop?
        # Actually, early termination usually means stopping if transmittance is low (surface found)
        # But NSVF uses it to skip empty space behind the surface.
        # We continue to accumulate, but can mask out samples behind the surface if needed.
        # For simplicity, we proceed to importance sampling if requested.
        
        # 6. Importance Sampling (Fine Model)
        if N_importance > 0:
            # Sample PDF from coarse weights
            # Handle division by zero
            eps = 1e-5
            weights_safe = weights + eps
            pdf = weights_safe / torch.sum(weights_safe, dim=1, keepdim=True)
            
            # Generate fine samples using inverse CDF sampling
            z_fine = sample_pdf(z_vals, weights_safe, N_importance)
            
            # Re-compute deltas for fine samples
            # Combine coarse and fine z_vals, sort them
            z_combined = torch.cat([z_vals, z_fine], dim=1)
            z_combined, _ = torch.sort(z_combined, dim=1)
            
            # Compute new deltas
            z_shifted = torch.cat([z_combined[:, 1:], torch.ones_like(z_combined[:, :1]) * 1e10], dim=1)
            deltas_fine = z_shifted - z_combined
            
            # Re-extract features and infer for fine samples
            xyz_embed_fine = positional_encoding(chunk_rays[:, :3].unsqueeze(1).expand(-1, z_combined.shape[1], -1))
            dir_embed_fine = positional_encoding(chunk_rays[:, 3:6].unsqueeze(1).expand(-1, z_combined.shape[1], -1))
            voxel_feats_fine = get_voxel_features(chunk_rays[:, :3], intersected_voxels, voxel_grid)
            
            fine_input = torch.cat([xyz_embed_fine, dir_embed_fine, voxel_feats_fine], dim=-1)
            fine_sigma, fine_rgb = infer_chunked(fine_model, fine_input, chunk_size)
            
            fine_sigma_noisy = fine_sigma + torch.randn_like(fine_sigma) * noise_std
            alphas_fine = 1.0 - torch.exp(-deltas_fine * torch.relu(fine_sigma_noisy))
            
            # Re-compute transmittance for combined samples
            alpha_sigma_fine = alphas_fine * torch.relu(fine_sigma_noisy)
            transmittance_fine = torch.cumprod(1.0 - alpha_sigma_fine, dim=1)
            transmittance_fine = torch.cat([torch.ones_like(transmittance_fine[:, :1]), transmittance_fine[:, :-1]], dim=1)
            
            weights_fine = transmittance_fine * alphas_fine
            
            # Final Accumulation
            final_rgb = torch.sum(weights_fine.unsqueeze(-1) * fine_rgb, dim=1)
            final_depth = torch.sum(weights_fine * z_combined, dim=1, keepdim=True)
            
            rgbs[start_idx:end_idx] = final_rgb
            depths[start_idx:end_idx] = final_depth
        else:
            rgbs[start_idx:end_idx] = coarse_rgb_acc
            depths[start_idx:end_idx] = coarse_depth_acc
            
    return rgbs, depths

def aabb_intersect(origin, inv_dir, min_pt, max_pt):
    """
    Standard AABB intersection test.
    """
    t_min = (min_pt - origin) * inv_dir
    t_max = (max_pt - origin) * inv_dir
    t1 = torch.min(t_min, t_max)
    t2 = torch.max(t_min, t_max)
    t_near = torch.max(torch.max(t1[:, 0], t1[:, 1]), t1[:, 2])
    t_far = torch.min(torch.min(t2[:, 0], t2[:, 1]), t2[:, 2])
    return t_near <= t_far

def positional_encoding(x, N_freqs=6, logscale=True):
    """
    Sinusoidal positional encoding.
    """
    if logscale:
        freq_bands = 2**torch.linspace(0, N_freqs-1, N_freqs)
    else:
        freq_bands = torch.linspace(1, 2**(N_freqs-1), N_freqs)
    
    out = [x]
    for freq in freq_bands:
        out += [torch.sin(freq * x), torch.cos(freq * x)]
    return torch.cat(out, dim=-1)

### Parameters
*   **$N_{samples}$**: Number of coarse samples per ray. Default: 64 [S2, unofficial].
*   **$N_{importance}$**: Number of fine samples per ray. Default: 0 (no fine model) [S2, unofficial].
*   **$\varepsilon$**: Early termination threshold for transparency. Default: 0.01 [S3, unofficial].
*   **Embedding Dimension**: 32 [S1, unofficial].
*   **Fourier Frequency $L$**: Maximum frequency for Fourier post-processing. Default: 6 [S3, unofficial].
*   **Chunk Size**: Batch size for inference. Default: 32,768 (1024 * 32) [S2, unofficial].
*   **Halving Interval**: Progressive training steps. Default: 5K, 25K, 75K iterations [S3, unofficial].
*   **Pruning Interval**: Self-pruning frequency. Default: Every 2,500 iterations [S3, unofficial].
*   **Batch Size**: 32 images per batch, 2,048 rays per image [S3, unofficial].

### Edge Cases and Pitfalls
*   **Division by Zero in Importance Sampling**: When computing PDF for `sample_pdf`, if a bin has zero weight, the denominator becomes zero. Handle by adding a small epsilon ($10^{-5}$) to weights and setting the denominator to 1 if it is zero [S2, unofficial].
*   **Precision**: The method uses a 32-dim embedding with sinusoidal positional encoding, which can lead to relatively large GPU memory and time consumption compared to lighter embeddings [S1, unofficial].
*   **Empty Space**: If the bounding box is not tight, large amounts of empty space may be sampled, reducing efficiency. Self-pruning helps mitigate this but requires sufficient training [S3, unofficial].
*   **Boundary Conditions**: The last delta in ray marching is set to infinity ($10^{10}$) to account for the ray extending to the far plane, ensuring the last sample contributes correctly to the transmittance [S2, unofficial].

## Operating characteristics

**Time and Memory Complexity:**
*   **Time:** Significantly faster than NeRF for scenes with large empty spaces because it avoids sampling in empty voxels [S1, unofficial][S4, unofficial]. The complexity depends on the number of active voxels intersected by rays.
*   **Memory:** Requires storing voxel features. The memory usage scales with the number of active voxels and the embedding dimension (32) [S1, unofficial].

**Measured Performance:**
*   On a single V100 GPU, NSVF achieves real-time rendering speeds (e.g., 2.62 s/frame for high-resolution scenes, though this varies by scene complexity) [S3, unofficial].
*   PSNR on Synthetic-NeRF dataset is competitive with NeRF [S3, unofficial].

**Strengths:**
*   **Efficiency:** Skips empty space sampling, leading to faster rendering [S1, unofficial].
*   **Quality:** High-quality free-viewpoint rendering comparable to NeRF [S3, unofficial].
*   **Flexibility:** Supports multi-resolution, dynamic scenes (via time dimension), and single-image initialization [S2, unofficial].

**Limitations:**
*   **Complex Backgrounds:** Struggles with complex backgrounds if not explicitly modeled [S3, unofficial].
*   **Training Time:** Requires progressive training and self-pruning, which can increase training time compared to simpler methods [S3, unofficial].
*   **Embedding Size:** The 32-dim embedding with Fourier features is computationally expensive [S1, unofficial].

**When to Use:**
*   When rendering speed is critical and the scene has significant empty space.
*   When high-quality novel view synthesis is required.
*   When dynamic scenes or single-image initialization is needed.

**When Not to Use:**
*   For very small scenes where the overhead of voxel management outweighs the benefits.
*   When memory is extremely constrained and the 32-dim embedding per voxel is too large.

## Background

**Origin:**
Neural Sparse Voxel Fields (NSVF) was introduced by Lingjie Liu et al. in 2020 [S3, unofficial]. It extends the ideas of Neural Radiance Fields (NeRF) by Mildenhall et al. (2020) and Neural Volumes by Lombardi et al. (2019) [S2, unofficial].

**History and Development:**
*   NSVF was presented at NeurIPS 2020 [S4, unofficial].
*   It was designed to address the computational inefficiency of NeRF by introducing a sparse voxel structure [S4, unofficial].
*   The method supports progressive training, allowing the model to learn from coarse to fine resolutions [S3, unofficial].

**Applications:**
*   Free-viewpoint rendering [S3, unofficial].
*   Dynamic scene rendering (e.g., human body animation) [S3, unofficial].
*   Large-scale indoor scene reconstruction [S3, unofficial].
