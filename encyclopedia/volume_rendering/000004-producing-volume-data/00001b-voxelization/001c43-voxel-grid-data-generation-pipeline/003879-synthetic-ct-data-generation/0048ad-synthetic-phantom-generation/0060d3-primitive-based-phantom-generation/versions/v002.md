# Primitive-based Phantom Generation
Also called: CT Phantom Generation, Geometrical Phantom Generation, Primitive-based Volume Synthesis

## Overview
Primitive-based Phantom Generation creates 3D CT phantoms by combining mathematical primitives (spheres, spheroids, cuboids, cylinders, checkers) within a specified volume geometry using voxel coordinates in millimeters [S1, unofficial]. It differs from grid-based voxelization by evaluating implicit equations directly on the coordinate grid, allowing for exact geometric boundaries without discretization artifacts [S1, unofficial].

## How it works
**Inputs:**
- `shape`: Tuple of integers $(N_x, N_y, N_z)$ defining the volume dimensions in voxels [S1, unofficial].
- `geometry`: Object providing voxel size (`geometry.voxel`) and coordinate generation (`geometry.volume_xyz`) [S1, unofficial].
- `primitives`: List of primitive definitions containing type, size parameters, and optional rotation flags [S1, unofficial].
- `overlap`: String defining combination logic ('or', 'and', 'xor') [S1, unofficial].
- `rotation`: Boolean controlling spheroid rotation [S1, unofficial].
- `area_shrink`: Float scalar to constrain random placement within bounds [S1, unofficial].

**Outputs:**
- `volume`: 3D NumPy array of shape `shape` containing float values representing the phantom density or mask [S1, unofficial].

**Data Structures:**
- The volume array is initialized as zeros [S1, unofficial].
- Primitive parameters are stored as dictionaries or objects containing type, dimensions, and offset [S1, unofficial].

**Steps:**
1. Initialize `volume` array of zeros with shape `shape` [S1, unofficial].
2. For each primitive in the list:
   a. Generate a random offset. The range for each axis $i$ is calculated as $\text{range}_i = (\text{shape}_i - 1) \times \text{geometry.voxel} \times \text{area\_shrink}$ [S1, unofficial]. The offset vector is $\text{offset} = \text{range} \times (\text{np.random.rand}(3) - 0.5)$ [S1, unofficial].
   b. Compute voxel coordinates in millimeters using `geometry.volume_xyz(shape, offset)` [S1, unofficial].
   c. If `rotation` is True and the primitive is a spheroid, apply a random rotation matrix to the coordinates around axes (1,2) by a random angle in $[0, 360)$ degrees [S1, unofficial].
   d. Evaluate the primitive's implicit equation over the coordinate grid to produce a mask [S1, unofficial].
   e. Convert the result to a boolean or float mask [S1, unofficial].
   f. Combine the primitive's mask with `volume` using the `overlap` rule [S1, unofficial].

**Parameters:**
- `overlap`: String, defines how primitives combine. 'or' uses logical OR, 'and' uses arithmetic addition, 'xor' uses arithmetic addition with values > 1 clipped to 0. Default: 'xor' [S1, unofficial].
- `rotation`: Boolean, rotates spheroids around axes (1,2) by a random angle in $[0, 360)$ degrees. Default: True [S1, unofficial].

**Formulas:**
The implicit equations are evaluated element-wise on the grid. A point is inside the primitive if the inequality holds [S1, unofficial].
- **Spheroid**: $((xx \cdot r_2 r_3)^2 + (yy \cdot r_1 r_3)^2 + (zz \cdot r_1 r_2)^2) < (r_1 r_2 r_3)^2$, where $xx, yy, zz$ are voxel coordinates in mm, and $r_1, r_2, r_3$ are radii in geometry units [S1, unofficial].
- **Cuboid**: $|xx| < a/2 \land |yy| < b/2 \land |zz| < c/2$, where $a, b, c$ are dimensions in geometry units [S1, unofficial].
- **Cylinder**: $(zz^2 + yy^2) < r^2 \land |xx| < h/2$, where $r$ is radius and $h$ is height in geometry units, aligned along the x-axis [S1, unofficial].

**Overlap Rules:**
- **'or'**: Logical OR [S1, unofficial].
- **'and'**: Arithmetic addition [S1, unofficial].
- **'xor'**: Arithmetic addition with values > 1 clipped to 0 [S1, unofficial].

**Pseudocode:**
```python
import numpy as np

def generate_primitive_phantom(shape, geometry, primitives, overlap='xor', rotation=True, area_shrink=1.0):
    """
    Generate a synthetic CT phantom from geometric primitives.
    
    Args:
        shape: Tuple (Nx, Ny, Nz)
        geometry: Object with .voxel and .volume_xyz(shape, offset)
        primitives: List of dicts with 'type' and 'params'
        overlap: 'or', 'and', 'xor'
        rotation: Boolean
        area_shrink: Float for placement constraint
        
    Returns:
        volume: 3D numpy array
    """
    volume = np.zeros(shape, dtype=np.float32)
    
    for prim in primitives:
        p_type = prim['type']
        params = prim['params']
        
        # 1. Generate random offset
        ranges = (np.array(shape) - 1) * geometry.voxel * area_shrink
        offset = ranges * (np.random.rand(3) - 0.5)
        
        # 2. Compute voxel coordinates in mm
        xx, yy, zz = geometry.volume_xyz(shape, offset)
        
        # 3. Handle Rotation for Spheroids
        if rotation and p_type == 'spheroid':
            angle = np.random.uniform(0, 360) * np.pi / 180
            cos_a = np.cos(angle)
            sin_a = np.sin(angle)
            # Rotate around axes (1,2) i.e., Y and Z
            new_yy = yy * cos_a - zz * sin_a
            new_zz = yy * sin_a + zz * cos_a
            yy, zz = new_yy, new_zz
            
        # 4. Evaluate Implicit Equation
        mask = np.zeros(shape, dtype=np.float32)
        
        if p_type == 'spheroid':
            r1, r2, r3 = params['r1'], params['r2'], params['r3']
            lhs = (xx * r2 * r3)**2 + (yy * r1 * r3)**2 + (zz * r1 * r2)**2
            rhs = (r1 * r2 * r3)**2
            mask = (lhs < rhs).astype(np.float32)
            
        elif p_type == 'cuboid':
            a, b, c = params['a'], params['b'], params['c']
            mask = ((np.abs(xx) < a/2) & (np.abs(yy) < b/2) & (np.abs(zz) < c/2)).astype(np.float32)
            
        elif p_type == 'cylinder':
            r, h = params['r'], params['h']
            mask = ((zz**2 + yy**2) < r**2) & (np.abs(xx) < h/2)
            mask = mask.astype(np.float32)
            
        elif p_type == 'sphere':
            # Sources do not give the explicit formula for sphere.
            pass
            
        elif p_type == 'checker':
            # Sources do not give the explicit formula for checker.
            pass
            
        else:
            raise ValueError(f"Unknown primitive type: {p_type}")

        # 5. Combine with Volume
        if overlap == 'or':
            volume = np.maximum(volume, mask)
        elif overlap == 'and':
            volume = volume + mask
        elif overlap == 'xor':
            volume = volume + mask
            volume[volume > 1] = 0
        else:
            raise ValueError(f"Unknown overlap mode: {overlap}")
            
    return volume
```
