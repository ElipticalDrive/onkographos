# DCX Mesh Extraction

Also called: DCX Pipeline Mesh Extraction

## Overview
DCX Mesh Extraction is a method to extract a mesh from a point cloud using the DCX pipeline, with optional thinning and supplementary sampling to fill holes [S1, unofficial]. It operates on a discrete voxel grid, allowing explicit control over topology via cube types and enabling supplementary sampling for geometric hole filling [S1, unofficial].

## How it works
The method takes a point cloud as input and produces mesh vertices and faces as output [S1, unofficial].

### Data Structures
The pipeline maintains arrays for `voxel_ids` and `voxel_points`, along with `cube_ids` and `cube_types` for voxel classification [S1, unofficial].

### Parameters
- `enable_thinning` (boolean): enables the thinning step [S1, unofficial].
- `enable_supplementary_sampling` (boolean): enables the hole-filling step [S1, unofficial].
- `hole_query_fn` (function): required if `enable_supplementary_sampling` is true; takes `query_points` and returns `selected_candidate_indexes` and `selected_points` [S1, unofficial].

### Steps
1. Convert points to voxels using `dcx_pkg.points_to_voxels` to obtain `voxel_ids` and `voxel_points` [S1, unofficial].
2. Compute cube types using `dcx_pkg.get_cube_types` to obtain `cube_ids` and `cube_types` [S1, unofficial].
3. If `enable_supplementary_sampling` is true:
    a. If `enable_thinning` is true, run thinning [S1, unofficial].
    b. Run reconstruction with `pattern=1` and `enable_postprocessing=False` to get `margin_voxel_ids` [S1, unofficial].
    c. Call `filling_holes_prepare` to get `candidate_voxel_ids` and `query_points` [S1, unofficial].
    d. Call `hole_query_fn` to select candidate indexes and points [S1, unofficial].
    e. Call `filling_holes_apply` to add selected voxels [S1, unofficial].
    f. Recompute cube types using `dcx_pkg.get_cube_types` [S1, unofficial].
4. If `enable_thinning` is true, run thinning [S1, unofficial].
5. Run reconstruction with `pattern=0` to get vertices and faces [S1, unofficial].

### Pseudocode
```python
# DCX package operations [S1, unofficial]
def dcx_points_to_voxels(points):
    # Converts input points to voxel IDs and coordinates
    return points, points

def dcx_get_cube_types(voxel_ids, voxel_points):
    # Classifies each voxel's local geometry
    return voxel_ids, voxel_ids

def dcx_thinning(voxel_ids, voxel_points, cube_ids, cube_types):
    # Reduces voxel density
    return voxel_ids, voxel_points, cube_ids, cube_types

def dcx_reconstruction(voxel_ids, voxel_points, cube_ids, cube_types, pattern=0, enable_postprocessing=True):
    # pattern=1 returns margin voxels; pattern=0 returns mesh vertices and faces
    if pattern == 1:
        return voxel_ids, None, None
    return voxel_ids, voxel_points

def dcx_filling_holes_prepare(margin_voxel_ids):
    # Generates candidate voxels and query points for hole filling
    return margin_voxel_ids, margin_voxel_ids

def dcx_filling_holes_apply(voxel_ids, voxel_points, candidate_voxel_ids, selected_candidate_indexes, selected_points):
    # Adds selected voxels to the grid
    return voxel_ids, voxel_points, selected_candidate_indexes, selected_points

def dcx_mesh_extraction(points, enable_thinning=False, enable_supplementary_sampling=False, hole_query_fn=None):
    # Step 1
    voxel_ids, voxel_points = dcx_points_to_voxels(points)
    # Step 2
    cube_ids, cube_types = dcx_get_cube_types(voxel_ids, voxel_points)
    # Step 3
    if enable_supplementary_sampling:
        if hole_query_fn is None:
            raise ValueError("hole_query_fn is required when enable_supplementary_sampling is true")
        # Step 3a
        if enable_thinning:
            voxel_ids, voxel_points, cube_ids, cube_types = dcx_thinning(voxel_ids, voxel_points, cube_ids, cube_types)
        # Step 3b
        margin_voxel_ids, _, _ = dcx_reconstruction(voxel_ids, voxel_points, cube_ids, cube_types, pattern=1, enable_postprocessing=False)
        # Step 3c
        candidate_voxel_ids, query_points = dcx_filling_holes_prepare(margin_voxel_ids)
        # Step 3d
        selected_candidate_indexes, selected_points = hole_query_fn(query_points)
        # Step 3e
        voxel_ids, voxel_points, add_voxel_ids, add_voxel_points = dcx_filling_holes_apply(voxel_ids, voxel_points, candidate_voxel_ids, selected_candidate_indexes, selected_points)
        # Step 3f
        cube_ids, cube_types = dcx_get_cube_types(voxel_ids, voxel_points)
    # Step 4
    if enable_thinning:
        voxel_ids, voxel_points, cube_ids, cube_types = dcx_thinning(voxel_ids, voxel_points, cube_ids, cube_types)
    # Step 5
    vertices, faces = dcx_reconstruction(voxel_ids, voxel_points, cube_ids, cube_types, pattern=0)
    return vertices, faces
```

### Edge Cases and Pitfalls
- If `enable_supplementary_sampling` is true and `hole_query_fn` is `None`, a `ValueError` is raised [S1, unofficial].
- The order of operations requires thinning to run before hole filling preparation if both are enabled, and cube types must be recomputed after hole filling [S1, unofficial].

## Background
The method is part of the DCX Pipeline, which converts point clouds to meshes using voxelization, cube type classification, thinning, and reconstruction [S1, unofficial]. It is exposed via a Python binding module [S1, unofficial].
