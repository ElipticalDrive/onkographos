# COLMAP Camera Loading

Also called: COLMAP Camera Info Extraction, COLMAP Camera Reader

## Overview
This method loads camera extrinsics and intrinsics from COLMAP reconstruction files (binary or text) to create `CameraInfo` objects for volume rendering pipelines [S1, S2, unofficial]. It handles multiple camera models, specifically supporting undistorted datasets using `PINHOLE` or `SIMPLE_PINHOLE`/`SIMPLE_RADIAL` models [S1, S2, unofficial]. It sets apart from general reconstruction loaders by strictly enforcing undistortion requirements and mapping COLMAP's quaternion-based extrinsics and focal-length-based intrinsics into a unified `CameraInfo` structure with computed Field of View (FoV) values [S1, S2, unofficial].

## How it works
**Inputs:** COLMAP reconstruction data (binary or text format) containing camera definitions with `qvec`, `tvec`, and `params` arrays [S1, S2, unofficial].
**Outputs:** A list of `CameraInfo` objects [S2, unofficial].

**Data Structures:**
The `CameraInfo` object contains the following fields:
- `uid`: int, unique identifier for the camera.
- `R`: np.array, 3x3 rotation matrix.
- `T`: np.array, 3x1 translation vector.
- `FovY`: np.array, vertical field of view in radians.
- `FovX`: np.array, horizontal field of view in radians.
- `image`: np.array, the loaded image data.
- `intrinsics`: np.array, intrinsic parameters.
- `image_path`: str, path to the image file.
- `image_name`: str, name of the image file.
- `width`: int, image width in pixels.
- `height`: int, image height in pixels.
- `mask`: np.array, optional mask for the image [S2, unofficial].

**Steps:**
1. Iterate through each camera in the COLMAP reconstruction [S1, S2, unofficial].
2. Extract the quaternion `qvec` and translation vector `tvec` from the camera's extrinsic data [S1, S2, unofficial].
3. Convert the quaternion to a rotation matrix $R$. The rotation matrix is computed as the transpose of the rotation matrix derived from the quaternion:
   $$ R = \text{transpose}(\text{qvec2rotmat}(qvec)) $$
   where `qvec2rotmat` converts the 4-element quaternion vector to a 3x3 rotation matrix [S1, S2, unofficial].
4. Set the translation vector $T$ directly from `tvec`:
   $$ T = \text{array}(tvec) $$ [S1, S2, unofficial].
5. Extract intrinsic parameters from the camera's `params` array based on the camera model [S1, S2, unofficial]:
   - **SIMPLE_PINHOLE** or **SIMPLE_RADIAL**: Use `params[0]` as the focal length $f$. Assume square pixels. Compute FoV using $f$ and image dimensions.
   - **PINHOLE**: Use `params[0]` as $f_x$ and `params[1]` as $f_y$. Compute respective FoVs for rectangular pixels.
   - Other models trigger an assertion error [S1, S2, unofficial].
6. Compute Field of View (FoV) values. The FoV is calculated using the focal length and image dimensions. For a focal length $f$ and image dimension $D$ (width or height), the FoV is:
   $$ \text{FoV} = 2 \cdot \arctan\left(\frac{D}{2f}\right) $$ [S1, S2, unofficial].
7. Construct the `CameraInfo` object with the computed $R$, $T$, FoV values, image data, and metadata [S2, unofficial].

**Pseudocode:**
```python
import numpy as np
import os
from PIL import Image

def qvec2rotmat(qvec):
    """Convert quaternion to rotation matrix."""
    return np.array([
        [1 - 2 * qvec[2]**2 - 2 * qvec[3]**2,
         2 * qvec[1] * qvec[2] - 2 * qvec[0] * qvec[3],
         2 * qvec[3] * qvec[1] + 2 * qvec[0] * qvec[2]],
        [2 * qvec[1] * qvec[2] + 2 * qvec[0] * qvec[3],
         1 - 2 * qvec[1]**2 - 2 * qvec[3]**2,
         2 * qvec[2] * qvec[3] - 2 * qvec[0] * qvec[1]],
        [2 * qvec[3] * qvec[1] - 2 * qvec[0] * qvec[2],
         2 * qvec[2] * qvec[3] + 2 * qvec[0] * qvec[1],
         1 - 2 * qvec[1]**2 - 2 * qvec[2]**2]
    ])

def focal2fov(focal_length, size):
    """Compute field of view from focal length and image size."""
    return 2 * np.arctan(size / (2 * focal_length))

def load_image(path):
    """Load an image file into a numpy array."""
    return np.array(Image.open(path).convert("RGB"))

class CameraInfo:
    def __init__(self, uid, R, T, FovY, FovX, image, intrinsics, image_path, image_name, width, height, mask=None):
        self.uid = uid
        self.R = R
        self.T = T
        self.FovY = FovY
        self.FovX = FovX
        self.image = image
        self.intrinsics = intrinsics
        self.image_path = image_path
        self.image_name = image_name
        self.width = width
        self.height = height
        self.mask = mask

def load_colmap_cameras(colmap_data, image_dir):
    """
    Load camera info from COLMAP reconstruction data.
    
    Args:
        colmap_data: Dictionary or object containing camera info from COLMAP.
                     Expected to have 'cameras' key with camera IDs mapping to camera objects.
                     Each camera object has 'model', 'width', 'height', 'params', 'qvec', 'tvec'.
        image_dir: Path to the directory containing images.
    
    Returns:
        List of CameraInfo objects.
    """
    cameras = colmap_data['cameras']
    camera_infos = []
    
    for cam_id, cam in cameras.items():
        # Extract extrinsics
        qvec = cam['qvec']
        tvec = cam['tvec']
        
        # Convert quaternion to rotation matrix
        R = np.transpose(qvec2rotmat(qvec))
        T = np.array(tvec)
        
        # Extract intrinsics based on model
        model = cam['model']
        params = cam['params']
        width = cam['width']
        height = cam['height']
        
        FovY = None
        FovX = None
        intrinsics = None
        
        if model == 'SIMPLE_PINHOLE' or model == 'SIMPLE_RADIAL':
            focal_length = params[0]
            FovY = focal2fov(focal_length, height)
            FovX = focal2fov(focal_length, width)
            intrinsics = np.array([focal_length, focal_length, width/2, height/2])
        elif model == 'PINHOLE':
            fx = params[0]
            fy = params[1]
            FovY = focal2fov(fy, height)
            FovX = focal2fov(fx, width)
            intrinsics = np.array([fx, fy, width/2, height/2])
        else:
            raise AssertionError(f"Unsupported camera model: {model}. Only PINHOLE, SIMPLE_PINHOLE, and SIMPLE_RADIAL are supported.")
        
        # Load image
        image_name = f"{cam_id}.jpg"
        image_path = os.path.join(image_dir, image_name)
        image = load_image(image_path)
        
        # Create CameraInfo object
        camera_info = CameraInfo(
            uid=cam_id,
            R=R,
            T=T,
            FovY=FovY,
            FovX=FovX,
            image=image,
            intrinsics=intrinsics,
            image_path=image_path,
            image_name=image_name,
            width=width,
            height=height,
            mask=None
        )
        camera_infos.append(camera_info)
        
    return camera_infos
```

**Parameters:**
- `colmap_data`: The parsed COLMAP reconstruction data. Not given in the sources.
- `image_dir`: Directory containing the source images.
- `model`: Camera model identifier. Supported: `SIMPLE_PINHOLE`, `SIMPLE_RADIAL`, `PINHOLE` [S1, S2, unofficial].

**Edge Cases and Pitfalls:**
- **Unsupported Models:** Only undistorted datasets with `PINHOLE` or `SIMPLE_PINHOLE`/`SIMPLE_RADIAL` cameras are supported. Other models trigger an assertion error [S1, S2, unofficial].

## Operating characteristics
- **Time Complexity:** Linear with respect to the number of cameras $N$ [G]. Parsing extrinsics and intrinsics is $O(1)$ per camera [S2, unofficial]. Image loading is $O(W \cdot H)$ per image [G].
- **Memory Complexity:** $O(N \cdot W \cdot H)$ for storing images and camera data [G].
- **Measured Performance:** Not given in the sources.
- **Scaling:** Scales linearly with the number of cameras and image resolution [G].
- **Strengths:** Handles multiple common camera models and computes FoV directly [S1, S2, unofficial].
- **Limitations:** Does not support distorted camera models [S1, S2, unofficial].
- **When to use:** When using COLMAP with undistorted images and standard pinhole camera models [S1, S2, unofficial].
- **When not to use:** When using distorted camera models [S1, S2, unofficial].
