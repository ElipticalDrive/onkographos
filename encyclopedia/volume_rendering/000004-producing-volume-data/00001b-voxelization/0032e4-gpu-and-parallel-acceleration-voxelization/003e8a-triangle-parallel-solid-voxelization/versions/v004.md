# Triangle-Parallel Solid Voxelization

Also called: Facet-based Voxelization, Triangle-based parallelization

## Overview
Triangle-Parallel Solid Voxelization is a data-parallel algorithm that maps a triangular mesh to a discrete 3D voxel grid by dedicating one processing thread (or work-item) to each triangle [S1, S2]. It solves the problem of efficiently determining which voxels are enclosed by a surface without iterating over the entire voxel grid [S2]. Unlike sibling methods that parallelize over voxels (e.g., [Per-Pixel Linked List Voxelization](1187-per-pixel-linked-list-voxelization.md) or [Parallel CPU Voxelization](7135-parallel-cpu-voxelization.md)), this method skips voxels outside the triangle's Axis-Aligned Bounding Box (AABB), reducing intersection tests by orders of magnitude [S2]. It differs from [Compute Shader Triangle Voxelization](12867-compute-shader-triangle-voxelization.md) by explicitly utilizing atomic operations to flip voxel states in a global grid, whereas the compute shader variant iterates over a 2D footprint to solve plane equations for precise solid filling without necessarily relying on global atomic flips in the same manner [S1, S1].

## How it works
**Inputs:** A triangular mesh defined by vertices $\mathbf{v}_0, \mathbf{v}_1, \mathbf{v}_2$ and a 3D voxel grid of resolution $(N_x, N_y, N_z)$ with voxel size 1 in voxel space.
**Outputs:** A 3D boolean grid (or bit-field) where each voxel $(i, j, k)$ indicates whether it is inside the mesh.

**Data Structures:**
*   **Voxel Grid:** A 3D array or flattened buffer of bits/booleans. Access is via atomic XOR operations.
*   **Triangle Data:** Local storage for vertex coordinates $\mathbf{v}_i = (x_i, y_i, z_i)$ and derived normal $\mathbf{n}$.

**Algorithm Steps:**
1.  **Thread Assignment:** Assign one thread/work-item to each triangle in the mesh [S1, S2].
2.  **AABB Calculation:** Compute the Axis-Aligned Bounding Box (AABB) of the triangle in the voxel grid space. Determine the range of voxel indices $(j, k)$ in the $yz$-plane that overlap with the triangle's projection [S1, S2].
3.  **Voxel Column Iteration:** Loop over all voxel columns $(j, k)$ within the AABB range [S1].
4.  **Early Exit / Validity Check:** For each voxel column, perform a fast rejection test to determine if the triangle intersects the voxel slab.
    *   Calculate the facet normal $\mathbf{n}$ and the critical point $\mathbf{c}$ [S2].
    *   The critical point $\mathbf{c}$ is defined component-wise based on the normal $\mathbf{n} = (n_x, n_y, n_z)$ and the extreme corner of the voxel $\mathbf{p}$ (where $\mathbf{p} + \Delta\mathbf{p}$ is the opposite corner) [S2]:
        $$
        c_x = \begin{cases} p_x & \text{if } n_x > 0 \\ 0 & \text{if } n_x \le 0 \end{cases}, \quad
        c_y = \begin{cases} p_y & \text{if } n_y > 0 \\ 0 & \text{if } n_y \le 0 \end{cases}, \quad
        c_z = \begin{cases} p_z & \text{if } n_z > 0 \\ 0 & \text{if } n_z \le 0 \end{cases}
        $$
    *   Compute $a_1 = \langle \mathbf{n}, \mathbf{c} - \mathbf{v}_0 \rangle$ and $a_2 = \langle \mathbf{n}, \Delta\mathbf{p} - \mathbf{c} - \mathbf{v}_0 \rangle$ [S2].
    *   If $(\langle \mathbf{n}, \mathbf{p} \rangle + a_1)(\langle \mathbf{n}, \mathbf{p} \rangle + a_2) > 0$, the triangle and voxel are separated; skip this voxel [S2].
5.  **Projection Tests:** If the validity check passes, test for intersection on the principal planes (e.g., $yz$, $xy$, $xz$) [S2].
    *   **YZ Plane Test:** Test the voxel center against the triangle's $yz$ projection using edge functions [S1].
        *   Calculate edge vectors $\mathbf{e}_i = \mathbf{v}_{i+1 \pmod 3} - \mathbf{v}_i$.
        *   Calculate edge normals $\mathbf{n}_{yz}^{e_i}$ [S1].
        *   Calculate $d_{yz}^{e_i} = -\langle \mathbf{n}_{yz}^{e_i}, \mathbf{v}_{i,yzi} \rangle$ [S1].
        *   Apply the **Top-Left Fill Rule** to handle shared edges/vertices consistently [S1]. Define a correction term $f_{yz}^{e_i}$:
            $$
            f_{yz}^{e_i} = \begin{cases} \epsilon & \text{if } (n_{yz}^{e_i, y} > 0) \lor (n_{yz}^{e_i, y} = 0 \land n_{yz}^{e_i, z} < 0) \\ 0 & \text{otherwise} \end{cases}
            $$
            where $\epsilon$ is the smallest positive floating-point number [S1].
        *   The test passes if:
            $$
            \bigwedge_{i=0}^2 \left( (\langle \mathbf{n}_{\mathbf{e}_i}^{\text{YZ}}, \mathbf{p}_{\text{YZ}} \rangle + d_{\mathbf{e}_i}^{\text{YZ}}) + f_{\mathbf{e}_i}^{\text{YZ}} > 0 \right)
            $$
            where $\mathbf{p}_{\text{YZ}}$ is the voxel center projected onto the $yz$ plane [S1].
    *   **Other Planes:** Similar projection tests are performed for $xy$ and $xz$ planes to ensure 3D intersection [S2]. For the $xy$ plane, the edge normal $\mathbf{n}_{e_i}^{xy}$ is determined by:
        $$
        \mathbf{n}_{e_i}^{xy} = \begin{cases} (-e_{i,y}, e_{i,x}) & \text{if } n_z \ge 0 \\ (e_{i,y}, -e_{i,x}) & \text{if } n_z < 0 \end{cases}
        $$
        And the test is:
        $$
        \langle \mathbf{n}_{e_i}^{xy}, \mathbf{p}_{xy} \rangle + a_{e_i} \ge 0, \quad \forall i \in \{0, 1, 2\}
        $$
        where $a_{e_i} = -\langle \mathbf{n}_{e_i}^{xy}, \mathbf{v}_{i,xy} \rangle + \max\{0, \Delta p_x n_{e_i,x}^{xy}\} + \max\{0, \Delta p_y n_{e_i,y}^{xy}\}$ [S2].
6.  **X-Range Calculation:** If the voxel column intersects the triangle, project the voxel center along the $x$-axis onto the triangle's plane to find the intersection $x$-coordinate $q$ [S1].
7.  **Atomic Flip:** Determine the range of voxel indices in the $x$-direction that are inside the triangle. Flip the bits for these voxels using an atomic XOR operation [S1].
    *   The range is typically derived from $q$. If the triangle spans multiple voxels in $x$, all voxels from the entry point to the exit point are flipped [S1].

**Pseudocode:**

def triangle_parallel_voxelization(triangles, grid_width, grid_height, grid_depth):
    # grid is a 1D array representing 3D voxel space, accessed via atomic operations
    grid = [0] * (grid_width * grid_height * grid_depth)
    
    # Parallel loop over triangles
    for triangle in triangles:
        v0, v1, v2 = triangle.vertices
        e0 = v1 - v0
        e1 = v2 - v1
        e2 = v0 - v2
        
        # Calculate normal
        n = cross(e0, e2) # or e0 x e1 depending on winding
        n = normalize(n)
        
        # Determine AABB in YZ plane
        min_y, max_y = min(v0.y, v1.y, v2.y), max(v0.y, v1.y, v2.y)
        min_z, max_z = min(v0.z, v1.z, v2.z), max(v0.z, v1.z, v2.z)
        
        # Convert to voxel indices
        start_j = floor(min_y)
        end_j = floor(max_y)
        start_k = floor(min_z)
        end_k = floor(max_z)
        
        for j in range(start_j, end_j + 1):
            for k in range(start_k, end_k + 1):
                # Voxel center in world space (assuming voxel size 1 and origin alignment)
                # p_yz is the center of the voxel column at (j, k)
                p_yz = (j + 0.5, k + 0.5)
                
                # 1. YZ Projection Test with Top-Left Fill Rule
                yz_inside = True
                for i, edge in enumerate([e0, e1, e2]):
                    # Edge normal in YZ plane
                    # Assuming standard 2D edge normal calculation
                    if i == 0: # e0 = v1 - v0
                        ex, ey = e0.y, e0.z
                    elif i == 1: # e1 = v2 - v1
                        ex, ey = e1.y, e1.z
                    else: # e2 = v0 - v2
                        ex, ey = e2.y, e2.z
                        
                    # Normal perpendicular to edge in YZ
                    # n_yz = (-ey, ex) or (ey, -ex) depending on winding
                    # Standard counter-clockwise winding: n = (-ey, ex)
                    ny, nz = -ey, ex
                    
                    # Vertex for this edge
                    if i == 0:
                        vx, vy = v0.y, v0.z
                    elif i == 1:
                        vx, vy = v1.y, v1.z
                    else:
                        vx, vy = v2.y, v2.z
                        
                    d_yz = -(ny * vy + nz * vz) # <n, v>
                    
                    # Top-Left Fill Rule correction
                    f_yz = 0.0
                    if (nz > 0) or (nz == 0 and ny < 0): # Left or Top edge
                        f_yz = -1e-9 # Smallest float epsilon
                    
                    val = (ny * p_yz[0] + nz * p_yz[1]) + d_yz + f_yz
                    if val <= 0:
                        yz_inside = False
                        break
                
                if not yz_inside:
                    continue
                
                # 2. X-Range Calculation
                # Project voxel center (j+0.5, k+0.5) along X onto triangle plane
                # Plane equation: n . (x - v0) = 0 => n.x * x + n.y * (j+0.5) + n.z * (k+0.5) - n.v0 = 0
                # x = (n.v0 - n.y*(j+0.5) - n.z*(k+0.5)) / n.x
                
                if abs(n.x) < 1e-9:
                    continue # Triangle parallel to X axis, handle degenerate case or skip
                
                q = (dot(n, v0) - n.y * (j + 0.5) - n.z * (k + 0.5)) / n.x
                
                # Determine voxel range in X
                # The triangle intersects the voxel column. 
                # We need to find which voxels in X are "inside".

                # Let's implement a standard slab intersection for the column
                # Ray from (0, j+0.5, k+0.5) to (inf, j+0.5, k+0.5)
                # Intersect with triangle.
                
                # T0 = v0 - (0, j+0.5, k+0.5)
                # Ray dir D = (1, 0, 0)
                # Plane normal N = n
                # t = dot(N, T0) / dot(N, D) = dot(N, T0) / n.x

## Subtopics

### [Compute Shader Triangle Voxelization](12867-compute-shader-triangle-voxelization.md)
A compute shader technique for voxelizing large triangles by iterating over a 2D bounding box in the plane of the triangle and testing for collisions, designed to handle triangles that span many voxels more efficiently than per-voxel rasterization. It differs from standard rasterization-based voxelization by explicitly solving the plane equation for every candidate voxel within the triangle's 2D footprint, allowing for precise solid voxelization and texture coordinate interpolation without relying on hardware rasterization pipelines.

## Operating characteristics
**Time Complexity:** $O(T \cdot C)$, where $T$ is the number of triangles and $C$ is the average number of voxel columns intersected by a triangle [S1].
**Memory Complexity:** $O(N_x N_y N_z)$ for the voxel grid [S1]. Local memory usage per work-item is minimal, storing only vertex coordinates [S2].
**Performance:**
*   Reduces intersection tests by more than four orders of magnitude compared to Voxel-Based (VB) parallelization [S2].
*   On the Stanford Bunny model at 3mm voxel size, FB reduces tests from 1,767,431 (VB) to 93 (FB) [S2]. At 0.5mm, from 368,832,950 to 5,874 [S2].
*   **Weaknesses:**
    *   **Warp Divergence:** The number of relevant voxel columns varies significantly among triangles in a warp, leading to underutilization [S1].
    *   **Memory Bandwidth:** Flipping voxels in large grids requires high memory bandwidth. Atomic XOR operations may be sequentialized, negatively affecting performance [S1].
*   **Strengths:** Efficient for sparse meshes or when the voxel grid is much larger than the mesh extent, as it skips empty space [S2].

## Background
The method was introduced as a data-parallel approach for solid voxelization on GPUs [S1]. It was developed to address the inefficiencies of voxel-based parallelization, where every voxel must be tested against the mesh [S2]. The facet-based (FB) approach was shown to be significantly faster than voxel-based (VB) methods due to reduced intersection tests and better memory locality [S2]. It is part of the broader family of GPU and Parallel Acceleration Voxelization techniques [Parent].
