# Vessel Voxelizer
Also called: GPU accelerated (fuzzy) voxelization of vascular structures, Vessel Voxelization

## Overview
The Vessel Voxelizer converts vascular structures, defined as line segments with associated radii, into a fuzzy 3D voxel volume where each voxel's value represents the fraction of its volume occupied by the vessels [S1, unofficial]. It uses supersampling to estimate the continuous volume intersection, calculating the ratio of sample points within the vessel radius to the total number of points per voxel [S1, unofficial].

## How it works
**Inputs and Outputs:**
*   **Inputs:**
    *   `vessel_positions`: Array of shape $(N, 2, 3)$ containing the start and end points $(p_0^i, p_1^i)$ for $N$ vessel segments [S1, unofficial].
    *   `vessel_radii`: Array of shape $(N,)$ containing the radius $r^i$ for each segment [S1, unofficial].
    *   `volume_shape`: Array of integers $(N_x, N_y, N_z)$ defining the output grid dimensions [S1, unofficial].
    *   `volume_origin`: Array of floats $(x_0, y_0, z_0)$ defining the world coordinates of the voxel at index $(0,0,0)$ [S1, unofficial].
    *   `volume_spacing`: Scalar or array of floats $(d_x, d_y, d_z)$ defining the side length of each voxel [S1, unofficial].
*   **Output:**
    *   `volume`: 3D array of shape $(N_x, N_y, N_z)$ with `float32` values in the range $[0.0, 1.0]$ [S1, unofficial].

**Data Structures:**
*   **Vessel Bounding Boxes (`vessel_bbox`):** Precomputed axis-aligned bounding boxes for each vessel segment [S1, unofficial]. For segment $i$, the box is defined by min/max coordinates along each axis, expanded by the segment's radius [S1, unofficial]. The layout is a flat array of shape $(N, 2, 3)$, where `vessel_bbox[i, 0, :]` is the minimum corner and `vessel_bbox[i, 1, :]` is the maximum corner [S1, unofficial].
*   **Voxel Grid:** A 3D array indexed by $(x, y, z)$ [S1, unofficial].

**Parameters:**
*   $K$: The supersampling resolution per voxel dimension [S1, unofficial]. The total number of sample points per voxel is $K^3$ [S1, unofficial]. The source code hardcodes $K=10$, resulting in 1000 points per voxel [S1, unofficial].
*   Thread Block Dimensions: Fixed at $8 \times 8 \times 8$ threads per block in the CUDA implementation [S1, unofficial].

**Algorithm Steps:**
1.  **Preprocessing (CPU):** Compute the bounding boxes for all vessel segments [S1, unofficial]. Sort the vessel positions along axis 1 (to ensure start < end) and expand the bounds by the radius:
    ```python
    vessel_bounds = np.sort(vessel_positions, axis=1)
    vessel_bounds = vessel_bounds + np.hstack((-vessel_radii.reshape(-1, 1, 1), vessel_radii.reshape(-1, 1, 1)))
    ```
    Transfer `vessel_positions`, `vessel_bounds`, `vessel_radii`, `volume_origin`, `volume_spacing`, and `volume_shape` to GPU memory [S1, unofficial].
2.  **Kernel Launch:** Launch a CUDA kernel where each thread corresponds to a single voxel $(x, y, z)$ in the output volume [S1, unofficial].
3.  **Voxel Boundary Calculation:** Each thread computes the world coordinates of its voxel's minimum and maximum corners:
    $$
    \begin{aligned}
    \text{voxel\_min}[d] &= \text{volume\_origin}[d] + x \cdot \text{volume\_spacing}[d] \\
    \text{voxel\_max}[d] &= \text{voxel\_min}[d] + \text{volume\_spacing}[d]
    \end{aligned}
    $$
    for $d \in \{0, 1, 2\}$ [S1, unofficial].
4.  **Bounding Box Culling:** Iterate through all $N$ vessel segments [S1, unofficial]. For each segment $i$, check if the voxel's bounding box intersects the segment's precomputed bounding box [S1, unofficial]. The check for axis $d$ is:
    $$
    \text{voxel\_max}[d] \ge \text{vessel\_bbox}[i, 0, d] \quad \land \quad \text{voxel\_min}[d] \le \text{vessel\_bbox}[i, 1, d]
    $$
    If the voxel does not intersect the bounding box for any axis, skip this vessel segment [S1, unofficial].
5.  **Internal Sampling:** Initialize an array `internal_point` of size $K \times K \times K$ to zero [S1, unofficial]. Define a local grid of $K \times K \times K$ sample points within the voxel [S1, unofficial]. For each sample point indexed by $(i_x, i_y, i_z)$ where $i_x, i_y, i_z \in \{0, \dots, K-1\}$:
    Calculate the world coordinates of the sample point:
    $$
    \text{check\_point}[d] = \text{voxel\_min}[d] + \left( \frac{1}{2K} + \frac{i_x}{K} \right) \cdot \text{volume\_spacing}[d]
    $$
    This places the points in the center of $K$ sub-cells along each axis [S1, unofficial].
6.  **Distance Calculation:** For the current vessel segment $i$ (with start $p_0^i$, end $p_1^i$, and radius $r^i$), calculate the squared distance from `check_point` to the line segment [S1, unofficial].
    Compute the direction vector $v = p_1^i - p_0^i$ [S1, unofficial].
    Compute the vector from the segment start to the point $w = \text{check\_point} - p_0^i$ [S1, unofficial].
    Calculate the projection parameter $t$:
    $$
    t = \text{clamp}\left( \frac{w \cdot v}{v \cdot v}, 0.0, 1.0 \right)
    $$
    Compute the closest point on the segment $p_{proj} = p_0^i + t \cdot v$ [S1, unofficial].
    The squared distance is $d^2 = \| \text{check\_point} - p_{proj} \|^2$ [S1, unofficial].
7.  **Inside Test:** If $d^2 \le (r^i)^2$, set `internal_point[(i_z * K * K) + (i_y * K) + i_x] = 1` [S1, unofficial].
8.  **Volume Update:** Sum the `internal_point` array to get `intersections` [S1, unofficial]. Compute the voxel value:
    $$
    \text{volume}[x, y, z] = \frac{\text{intersections}}{K^3}
    $$
    Map 0 intersections to 0.0 and $K^3$ intersections to 1.0 [S1, unofficial].

**Edge Cases and Pitfalls:**
*   The sampling resolution $K$ is hardcoded in the source code, limiting adaptability to different resolution requirements or performance constraints [S1, unofficial].
*   The method assumes vessel segments are straight lines; curved vessels are approximated by their linear segments, which may introduce errors if the segments are long relative to the voxel size [S1, unofficial].
*   The method does not handle vessel branching topology explicitly, treating each segment independently [S1, unofficial].

**Pseudocode:**
```python
import numpy as np

def vessel_voxelizer_kernel(x, y, z, volume, volume_origin, volume_spacing, volume_shape, vessel_positions, vessel_bbox, vessel_radii, K=10):
    """
    Simulates the CUDA kernel logic for a single voxel (x, y, z).
    In the actual implementation, this runs in parallel for all voxels.
    """
    spacing = volume_spacing if isinstance(volume_spacing, np.ndarray) else np.full(3, volume_spacing, dtype=np.float32)
    origin = volume_origin.astype(np.float32)
    
    voxel_min = origin + np.array([x, y, z], dtype=np.float32) * spacing
    voxel_max = voxel_min + spacing
    
    internal_point = np.zeros(K * K * K, dtype=np.float32)
    
    for i in range(len(vessel_radii)):
        # Bounding Box Culling
        bbox_min = vessel_bbox[i, 0]
        bbox_max = vessel_bbox[i, 1]
        if not (voxel_max[0] >= bbox_min[0] and voxel_min[0] <= bbox_max[0] and
                voxel_max[1] >= bbox_min[1] and voxel_min[1] <= bbox_max[1] and
                voxel_max[2] >= bbox_min[2] and voxel_min[2] <= bbox_max[2]):
            continue
            
        p0 = vessel_positions[i, 0]
        p1 = vessel_positions[i, 1]
        r = vessel_radii[i]
        
        for ix in range(K):
            for iy in range(K):
                for iz in range(K):
                    check_point = voxel_min + spacing * (1.0 / (2 * K) + np.array([ix, iy, iz], dtype=np.float32) / K)
                    
                    v = p1 - p0
                    w = check_point - p0
                    v_dot_v = np.dot(v, v)
                    
                    if v_dot_v == 0:
                        dist_sq = np.dot(w, w)
                    else:
                        t = np.dot(w, v) / v_dot_v
                        t = max(0.0, min(1.0, t))
                        p_proj = p0 + t * v
                        dist_sq = np.sum((check_point - p_proj) ** 2)
                    
                    if dist_sq <= r * r:
                        internal_point[(iz * K * K) + (iy * K) + ix] = 1
                        
    intersections = np.sum(internal_point)
    volume[x, y, z] = intersections / (K * K * K)
```

## Operating characteristics
*   **Time Complexity**: $O(V \cdot N_{voxels} \cdot K^3)$ in the worst case, where $V$ is the number of vessels, $N_{voxels}$ is the total number of voxels, and $K$ is the sampling resolution [S1, unofficial]. The bounding box check provides an early exit optimization, reducing the constant factor for sparse scenes [S1, unofficial].
*   **Memory Complexity**: $O(N_{voxels} + V)$ [S1, unofficial]. The output volume requires $N_x N_y N_z$ floats [S1, unofficial]. The input data requires $O(V)$ space for positions, radii, and bounding boxes [S1, unofficial].
*   **Performance**: The method is implemented in CUDA and uses a fixed thread block size of $8 \times 8 \times 8$ [S1, unofficial]. The supersampling factor $K=10$ results in 1000 distance calculations per voxel per intersecting vessel [S1, unofficial]. Performance scales linearly with the number of vessels and voxels [S1, unofficial]. The source code includes timing measurements for kernel execution and data transfers [S1, unofficial].
*   **Strengths**: Produces smooth, anti-aliased representations of vascular structures [S1, unofficial]. The bounding box culling efficiently skips non-intersecting vessels [S1, unofficial].
*   **Limitations**: The sampling resolution $K$ is hardcoded in the source code, limiting adaptability to different resolution requirements or performance constraints [S1, unofficial]. The method assumes vessel segments are straight lines; curved vessels are approximated by their linear segments, which may introduce errors if the segments are long relative to the voxel size [S1, unofficial]. The method does not handle vessel branching topology explicitly, treating each segment independently [S1, unofficial].
*   **When to use**: When rendering vascular networks where the internal structure (density) matters more than the exact surface boundary, and when GPU acceleration is available [S1, unofficial].
*   **When not to use**: When exact surface boundaries are required (use [Implicit Surface Voxelization](2379-implicit-surface-voxelization.md) or [Mesh Voxelization](6514-mesh-voxelization.md)), or when the vessel segments are highly curved and cannot be adequately approximated by straight lines [S1, unofficial].

## Background
The Vessel Voxelizer is an open-source project hosted on GitHub by faberno [S1, unofficial]. It is implemented using CUDA and Python bindings via `nanobind` [S1, unofficial]. The method is designed for the voxelization of vascular structures, which are typically represented as tree-like graphs of line segments with associated radii [S1, unofficial]. The project includes a demo notebook and a CSV-based input format for vessel data [S1, unofficial].
