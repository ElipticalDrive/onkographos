# Soft Voronoi Decomposition

Also called: Differentiable Voronoi Diagram, SoftVoronoi

## Overview
Soft Voronoi Decomposition is a differentiable spatial partitioning method that decomposes a scene into $N$ regions (Voronoi cells) defined by a set of $N$ sites $\phi \in \mathbb{R}^{N \times 3}$ [S1]. It solves the problem of creating a smooth, differentiable approximation of a hard Voronoi diagram, allowing gradients to flow to the site positions $\phi$ during training [S1]. Unlike MLP-based decomposition methods which rely on softmax activations and suffer from random memory access patterns during integration, Soft Voronoi provides spatial coherence and cache-friendly memory access, enabling efficient acceleration as the number of decomposition heads increases [S1].

## How it works
**Inputs:**
*   A set of $N$ Voronoi sites $\phi = [\phi_1, \dots, \phi_N]$, where each $\phi_n \in \mathbb{R}^3$ [S1].
*   A query point $x \in \mathbb{R}^3$ [S1].
*   A temperature parameter $\beta \in \mathbb{R}^+$ [S1].

**Outputs:**
*   A weight vector $w_\phi(x) \in \mathbb{R}^N$, where each component $w_{\phi_n}(x)$ represents the soft assignment of point $x$ to site $\phi_n$ [S1].

**Data Structures:**
*   $\phi$: A matrix of shape $(N, 3)$ containing the coordinates of the Voronoi sites [S1].
*   $w_\phi(x)$: A vector of shape $(N)$ containing the computed weights [S1].

**Parameters:**
*   $\beta$: Temperature parameter controlling the softness of the Voronoi approximation [S1]. Typical value: $10^9$ [S1].

**Steps:**
1.  **Initialize Sites:** Scale the scene coordinate system such that $\phi \in [-1, 1]^{N \times 3}$ to ensure training invariance with respect to variable magnitude when using optimizers like ADAM [S1].
2.  **Schedule $\beta$:** Begin training with a sufficiently low $\beta$ such that $w_i(x) \approx w_j(x)$ for all $i, j$ [S1]. Exponentially increase $\beta$ during training until it reaches a high value (e.g., $10^9$) [S1]. This ensures that at convergence, $w_i(x) \approx 1$ or $w_i(x) \approx 0$ for all $i$, making the decomposition indistinguishable from a hard Voronoi diagram [S1].
3.  **Compute Weights:** For each query point $x$ and each site $\phi_n$, compute the weight using the following formula [S1]:

    $$
    w_{\phi_n}(x) = \frac{\exp(-\beta \|x - \phi_n\|^2)}{\sum_{j=1}^{N} \exp(-\beta \|x - \phi_j\|^2)}
    $$

    Where:
    *   $\| \cdot \|$ denotes the Euclidean norm [S1].
    *   $\beta$ is the current temperature parameter [S1].

**Pitfalls and Edge Cases:**
*   If $\beta$ is too low, the decomposition is not spatially distinct, resulting in overlapping regions with similar weights [S1].
*   If $\beta$ is too high too early in training, gradients may become zero or unstable, preventing effective learning of site positions [S1]. The exponential scheduling strategy resolves this by starting low and increasing gradually [S1].
*   Without scaling $\phi$ to $[-1, 1]$, training with common optimizers may fail due to magnitude invariance issues [S1].

**Pseudocode:**

```python
import numpy as np

def soft_voronoi_weights(phi, x, beta):
    """
    Compute soft Voronoi weights for a set of sites phi at query point x.
    
    Args:
        phi: numpy array of shape (N, 3), Voronoi sites.
        x: numpy array of shape (3,), query point.
        beta: float, temperature parameter.
        
    Returns:
        weights: numpy array of shape (N,), soft assignment weights.
    """
    # Compute squared Euclidean distances from x to each site
    # phi shape: (N, 3), x shape: (3,)
    # diff shape: (N, 3)
    diff = phi - x
    
    # Squared L2 norm for each site
    # dist_sq shape: (N,)
    dist_sq = np.sum(diff ** 2, axis=1)
    
    # Compute unnormalized weights
    # exp_term shape: (N,)
    exp_term = np.exp(-beta * dist_sq)
    
    # Normalize weights
    # sum_exp is a scalar
    sum_exp = np.sum(exp_term)
    
    # Avoid division by zero if sum_exp is 0 (e.g., if beta is very large and exp underflows)
    if sum_exp == 0:
        # Fallback to uniform distribution if all weights underflow
        return np.ones(len(phi)) / len(phi)
        
    weights = exp_term / sum_exp
    
    return weights

def schedule_beta(step, start_beta=1e-3, end_beta=1e9, total_steps=10000):
    """
    Exponentially schedule beta from start_beta to end_beta.
    
    Args:
        step: current training step.
        start_beta: initial beta value.
        end_beta: final beta value.
        total_steps: total number of training steps.
        
    Returns:
        beta: current beta value.
    """
    # Linear interpolation in log space for exponential growth
    log_start = np.log(start_beta)
    log_end = np.log(end_beta)
    
    # Clamp step to [0, total_steps]
    t = min(max(step, 0), total_steps)
    progress = t / total_steps
    
    current_log_beta = log_start + progress * (log_end - log_start)
    beta = np.exp(current_log_beta)
    
    return beta
```

## Operating characteristics
*   **Time Complexity:** The computation of weights for a single point $x$ requires $O(N)$ operations to compute distances and the softmax normalization [S1].
*   **Memory Complexity:** Requires storing $N$ sites $\phi \in \mathbb{R}^{N \times 3}$ [S1].
*   **Measured Performance:** DeRF models using Soft Voronoi decomposition exhibit significantly better runtime scaling compared to MLP-based decomposition methods as the number of heads increases [S1]. This is because Soft Voronoi enables cache-friendly memory access patterns, whereas MLP methods suffer from random memory access during integration [S1].
*   **Strengths:** Differentiable with respect to site positions $\phi$; provides smooth gradients; spatially coherent; compatible with the Painter’s Algorithm for efficient compositing [S1].
*   **Limitations:** Requires careful scheduling of $\beta$ to balance differentiability and spatial distinctness; sensitive to the magnitude of $\phi$ without proper scaling [S1].
*   **When to use:** When training neural radiance fields or similar models that require decomposing the scene into multiple heads with differentiable spatial partitioning [S1].
*   **When not to use:** When a hard, non-differentiable partition is sufficient and training overhead is a concern; when memory access patterns are not a bottleneck and simplicity is preferred [S1].

## Background
Soft Voronoi Decomposition was introduced in the context of Decomposed Radiance Fields (DeRF) [S1]. The method builds on the solution proposed in [22] (cited in [S1]) to define a differentiable Voronoi diagram. It addresses the limitations of naive decomposition strategies, such as regular grids and MLP-based softmax decompositions, by providing a spatially coherent and computationally efficient alternative [S1]. The approach enables efficient compositing of rendering heads using the Painter’s Algorithm [S1].
