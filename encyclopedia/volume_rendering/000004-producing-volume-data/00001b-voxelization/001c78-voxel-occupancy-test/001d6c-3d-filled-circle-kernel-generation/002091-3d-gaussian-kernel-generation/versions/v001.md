# 3D Gaussian Kernel Generation
Also called: 3D Gaussian Smoothing Kernel, Zero-Centered Gaussian Kernel

## Overview
Generates a 3D Gaussian kernel for smoothing operations, with the center element set to zero [S1, unofficial]. It differs from its parent [3D Filled Circle Kernel Generation](1520-3d-filled-circle-kernel-generation.md) by using continuous weighted values based on a Gaussian probability density function rather than a binary occupancy mask. It is distinct from [Sphere Carving](2377-sphere-carving.md) and [3D Binary Sphere Kernel Generation](4654-3d-binary-sphere-kernel-generation.md) which produce hard-edged spherical masks.

## How it works
**Inputs:**
- `size`: Integer kernel dimension (assumed cubic). Default: 3 [S1, unofficial].
- `sigma`: Float standard deviation. Default: 1.0 [S1, unofficial].

**Outputs:**
- A 3D tensor of shape `(size, size, size)` containing normalized Gaussian weights with the center element explicitly set to 0.

**Data Structures:**
- 3D array/tensor of floating-point numbers.

**Steps:**
1. Define a linear coordinate space ranging from $-\lfloor \text{size}/2 \rfloor$ to $\lfloor \text{size}/2 \rfloor$.
2. Generate a 3D meshgrid of coordinates $(x, y, z)$ from this space.
3. Compute the radial distance $d$ from the center for each element: $d = \sqrt{x^2 + y^2 + z^2}$.
4. Compute raw Gaussian values: $w = \exp\left(-\frac{d^2}{2\sigma^2}\right)$.
5. Set the center element (where $x=y=z=0$) to 0.
6. Normalize the kernel by dividing all elements by the sum of all elements.

**Pseudocode:**
```python
import math

def generate_3d_gaussian_kernel(size: int = 3, sigma: float = 1.0) -> list:
    """
    Generates a 3D Gaussian kernel with the center element set to 0.
    """
    half_size = size // 2
    # Step 1: Create linear space from -(size//2) to size//2
    coords = list(range(-half_size, half_size + 1))
    
    # Step 2: Generate 3D meshgrid
    kernel = []
    for x in coords:
        row = []
        for y in coords:
            col = []
            for z in coords:
                # Step 3: Compute radial distance d from center
                d_sq = x*x + y*y + z*z
                # Step 4: Compute Gaussian values
                if d_sq == 0:
                    # Step 5: Set center element to 0
                    val = 0.0
                else:
                    val = math.exp(-d_sq / (2 * sigma * sigma))
                col.append(val)
            row.append(col)
        kernel.append(row)
    
    # Step 6: Normalize by sum of all elements
    total_sum = sum(sum(sum(row) for row in kernel_slice) for kernel_slice in kernel)
    
    if total_sum == 0:
        # Edge case: if sigma is extremely small or size is 1, sum might be 0
        # Return zeros to avoid division by zero
        return [[[0.0 for _ in range(size)] for _ in range(size)] for _ in range(size)]
        
    for x_idx in range(size):
        for y_idx in range(size):
            for z_idx in range(size):
                kernel[x_idx][y_idx][z_idx] /= total_sum
                
    return kernel
```

**Parameters:**
- `size`: Kernel dimension. Default is 3 [S1, unofficial].
- `sigma`: Standard deviation of Gaussian. Default is 1.0 [S1, unofficial].

**Edge Cases:**
- If `size` is 1, the center is the only element, set to 0, sum is 0, resulting in a zero kernel [G].
- Precision issues may arise if `sigma` is very small relative to `size`, causing underflow in `exp` for non-center elements [G].

## Subtopics

## Operating characteristics
- **Time Complexity:** $O(\text{size}^3)$ to compute all elements.
- **Memory Complexity:** $O(\text{size}^3)$ to store the kernel.
- **Strengths:** Simple to implement; provides smooth weighting.
- **Limitations:** The explicit zeroing of the center element is non-standard for Gaussian kernels and may introduce bias in smoothing operations [S1, unofficial].
- **When to use:** When a specific implementation requires a zero-centered Gaussian weight distribution as defined in the source [S1, unofficial].
