# 3D Discrete Topology Fundamentals

Also called: Discrete Adjacency Definitions, Voxel Connectivity Types

## Overview
3D Discrete Topology provides the theoretical framework for defining topological properties, such as surface separation and connectivity, within a 3D discrete voxel grid [S1, book]. It solves the problem of "discrete disagreement," where standard continuous topology concepts fail in discrete space (e.g., 8-connected black curves can be penetrated by 8-connected white pixels without intersection) [S1, book]. It sets itself apart from general graph theory by specifically addressing the geometric adjacency constraints of cubic voxels in 3D Euclidean space to ensure robust surface representation for volume rendering and ray tracing [S1, book].

## How it works
**Inputs and Outputs:**
*   **Input:** A 3D discrete space $\Sigma$, defined as a set of integral grid points in 3D Euclidean space with Cartesian coordinates $(x, y, z)$. A subset of voxels $S \subset \Sigma$ (typically "black" or opaque) and the background voxels $W = \Sigma \setminus S$ ("white" or transparent).
*   **Output:** Classification of connectivity (N-connected components), separation status (N-separating), and minimality of surfaces (N-minimal covers).

**Data Structures:**
*   **Voxel Grid:** A 3D array where each cell corresponds to a unit cubic volume centered at an integral grid point.
*   **Voxel Values:** Mapped to a binary set $\{0, 1\}$ where $1$ represents "black" (opaque) and $0$ represents "white" (transparent) [S1, book]. Non-binary mappings to $[0, 1]$ are supported for partial coverage or variable densities, enabling 3D antialiasing [S1, book].

**Adjacency Definitions:**
Two voxels are defined as N-adjacent based on their geometric intersection:
1.  **6-adjacent:** Voxels share a face. Each voxel has 6 face-sharing neighbors.
2.  **18-adjacent:** Voxels share an edge or a face. Each voxel has 12 edge-sharing and 6 face-sharing neighbors.
3.  **26-adjacent:** Voxels share a vertex, an edge, or a face. Each voxel has 8 vertex-sharing, 12 edge-sharing, and 6 face-sharing neighbors [S1, book].

**Connectivity and Paths:**
*   An **N-path** is a sequence of voxels with the same value where all consecutive pairs are N-adjacent.
*   A set $W$ is **N-connected** if there exists an N-path between every pair of voxels in $W$.
*   An **N-connected component** is a maximal N-connected set [S1, book].

**Separation and Minimality:**
*   **N-Separating:** A subset $S$ is N-separating in $\Sigma$ if $\Sigma - S$ is not N-connected (i.e., $\Sigma - S$ consists of at least two white N-connected components) [S1, book].
*   **N-Simple Voxel:** For an N-separating surface $W$, a voxel $p \in W$ is N-simple if $W - p$ is still N-separating [S1, book].
*   **N-Minimal Surface:** An N-separating surface is N-minimal if it contains no N-simple voxels [S1, book].
*   **Cover:** A set of voxels such that every point of the continuous surface lies in a voxel of the cover. A **minimal cover** has no subset that is also a cover. Note that a cover is not necessarily separating, and a minimal cover is not necessarily N-minimal for any N [S1, book].

**Avoiding Discrete Disagreement:**
To prevent the penetration of a closed surface by the background without intersection (discrete disagreement), "opposite" connectivity types must be used for the object and the background. In 3D space, 6 is "opposite" to 26 or to 18 [S1, book].

**Pseudocode:**
The following logic determines if a voxel is N-simple within an N-separating surface.

```python
def is_n_simple(surface_voxels, n_adjacency_type, voxel_space_shape):
    """
    Determines if a voxel p in surface_voxels is N-simple.
    A voxel is N-simple if removing it from the surface leaves the surface
    still N-separating (i.e., the background remains disconnected).
    
    Args:
        surface_voxels: Set of voxel coordinates (x,y,z) forming the surface W.
        n_adjacency_type: Integer, 6, 18, or 26.
        voxel_space_shape: Tuple (Dx, Dy, Dz) defining the bounds of Sigma.
    
    Returns:
        True if p is N-simple, False otherwise.
    """
    # 1. Identify the background voxels (Sigma - Surface)
    # In a full grid implementation, this would be all voxels not in surface_voxels.
    # For efficiency, we assume a function to get background components.
    background = get_background_voxels(surface_voxels, voxel_space_shape)
    
    # 2. Check if the original surface is N-separating
    # This implies the background has >= 2 N-connected components.
    if not is_n_separating(surface_voxels, n_adjacency_type, voxel_space_shape):
        return False # Surface must be separating to have simple voxels

    # 3. Iterate through each voxel p in the surface
    for p in surface_voxels:
        # 4. Create a temporary surface W' = W - {p}
        temp_surface = surface_voxels - {p}
        
        # 5. Check if W' is still N-separating
        # This requires recomputing background connectivity for W'
        if not is_n_separating(temp_surface, n_adjacency_type, voxel_space_shape):
            # If removing p disconnects the background further or merges components
            # such that it is no longer separating (or changes separation status),
            # p is critical. If it remains separating, p is simple.
            # Note: The definition states p is simple if W-p is STILL N-separating.
            # So if is_n_separating returns True for W-p, p is simple.
            pass 
        else:
            # If W-p is still N-separating, then p is N-simple.
            return True
            
    return False

def is_n_separating(surface_voxels, n_adjacency_type, voxel_space_shape):
    """
    Checks if the surface voxels separate the background into >= 2 N-connected components.
    """
    background = get_background_voxels(surface_voxels, voxel_space_shape)
    if not background:
        return False
    
    # Find connected components in the background using N-adjacency
    components = find_n_connected_components(background, n_adjacency_type)
    
    # Separating means the background is NOT N-connected (i.e., > 1 component)
    return len(components) >= 2

def find_n_connected_components(voxel_set, n_adjacency_type):
    """
    Standard BFS/DFS to find connected components in a voxel set.
    """
    visited = set()
    components = []
    
    for voxel in voxel_set:
        if voxel not in visited:
            component = set()
            queue = [voxel]
            visited.add(voxel)
            
            while queue:
                current = queue.pop(0)
                component.add(current)
                
                # Get N-neighbors
                neighbors = get_n_neighbors(current, n_adjacency_type, voxel_space_shape)
                
                for neighbor in neighbors:
                    if neighbor in voxel_set and neighbor not in visited:
                        visited.add(neighbor)
                        queue.append(neighbor)
            
            components.append(component)
            
    return components

def get_n_neighbors(voxel, n_adjacency_type, voxel_space_shape):
    """
    Returns all voxels adjacent to 'voxel' based on N-adjacency rules.
    """
    x, y, z = voxel
    neighbors = []
    
    # Offsets for 26-adjacency
    offsets = []
    for dx in [-1, 0, 1]:
        for dy in [-1, 0, 1]:
            for dz in [-1, 0, 1]:
                if dx == 0 and dy == 0 and dz == 0:
                    continue
                offsets.append((dx, dy, dz))
    
    for dx, dy, dz in offsets:
        nx, ny, nz = x + dx, y + dy, z + dz
        
        # Filter by adjacency type
        if n_adjacency_type == 6:
            # Face sharing: exactly one coordinate differs by 1
            if abs(dx) + abs(dy) + abs(dz) == 1:
                neighbors.append((nx, ny, nz))
        elif n_adjacency_type == 18:
            # Edge or face sharing: max(|dx|,|dy|,|dz|) <= 1 and not vertex-only (sum of abs > 1? No)
            # Vertex sharing: all 3 differ by 1. Edge sharing: 2 differ by 1. Face: 1 differs by 1.
            # 18-adjacent includes face (1 diff) and edge (2 diffs). Excludes vertex (3 diffs).
            if max(abs(dx), abs(dy), abs(dz)) <= 1 and not (abs(dx)==1 and abs(dy)==1 and abs(dz)==1):
                neighbors.append((nx, ny, nz))
        elif n_adjacency_type == 26:
            # All 26 neighbors
            neighbors.append((nx, ny, nz))
            
        # Boundary check
        if 0 <= nx < voxel_space_shape[0] and \
           0 <= ny < voxel_space_shape[1] and \
           0 <= nz < voxel_space_shape[2]:
            pass
        else:
            neighbors.remove((nx, ny, nz))
            
    return neighbors
```

## Operating characteristics
*   **Time Complexity:** Determining N-connectivity and separation requires graph traversal (BFS/DFS) on the voxel grid. Complexity is $O(V + E)$ where $V$ is the number of voxels and $E$ is the number of adjacencies. For 26-adjacency, $E \approx 26V$. Checking N-minimality requires iterating over all surface voxels and recomputing connectivity, leading to $O(S \cdot (V + E))$ where $S$ is the surface size.
*   **Memory Complexity:** $O(V)$ to store the voxel grid and visited sets for connectivity analysis.
*   **Strengths:** Provides rigorous guarantees for topological correctness in discrete space, preventing artifacts like tunneling in ray tracing or incorrect surface extraction.
*   **Limitations:** Computationally expensive for large volumes if minimality checks are performed frequently. The choice of N (6, 18, 26) significantly impacts performance and topological properties.
*   **When to use:** When topological correctness is critical, such as in space subdivision for ray tracing or robust surface extraction.
*   **When not to use:** For real-time rendering where performance is paramount and approximate topology is acceptable.

## Background
The concept of 3D discrete topology was formalized to address the limitations of 2D discrete topology in three dimensions. The specific definitions of N-adjacency (6, 18, 26) and the concept of "opposite" connectivity to avoid discrete disagreement are detailed in foundational works on volume visualization. The text cites [94] and [43] for further details on covers and minimality, indicating a lineage of research in computational geometry and computer graphics.
