# Labeled Volume Creation via MultiBlock Iteration

Also called: Labeled Volume Creation via Sample and Split

## Overview
This method produces a single `RectilinearGrid` volume from a `MultiBlock` mesh input, where each voxel is labeled with the integer ID of the specific sub-mesh block it intersects, rather than a binary inside/outside flag [S1, unofficial]. It differs from sibling methods like [Relaxed Connectivity Voxelization](2481-relaxed-connectivity-voxelization.md) by providing explicit block attribution per voxel through iterative enclosed-point testing or data sampling, ensuring that the resulting volume preserves the topological identity of each mesh component [S1, unofficial].

## How it works
The method supports two distinct implementation strategies: an iterative geometric approach using `select_enclosed_points` and a data-driven approach using `voxelize` combined with `sample` and `split_values`. Both produce a labeled volume but differ in computational strategy and data handling.

### Inputs and Outputs
- **Input**: A `pyvista.MultiBlock` mesh containing multiple sub-meshes. Each sub-mesh should ideally be watertight or manifold for robust enclosed-point testing [S1, unofficial].
- **Output**: A `pyvista.RectilinearGrid` where the `cell_data` array `InsideMesh` (or equivalent label array) contains integer IDs corresponding to the sub-mesh index (1-based) of the voxel's containing block [S1, unofficial].

### Data Structures
- **`RectilinearGrid`**: Defined by coordinate arrays `x`, `y`, `z`.
- **`InsideMesh`**: A 1D integer array of size `voi.n_cells`, initialized to zeros.
- **`mask_vol`**: A boolean array of size `voi.n_points`, indicating which grid points are enclosed by the current sub-mesh surface.

### Parameters
- **`mesh`**: The input `pyvista.DataSet` (specifically a `MultiBlock`) [S1, unofficial].
- **`density`**: Float or array-like of floats. Defines voxel size. If `None`, defaults to `mesh.length / 100` [S1, unofficial].
- **`check_surface`**: Boolean, default `True`. If `True`, raises a `RuntimeError` if the surface is not closed and manifold [S1, unofficial].

### Algorithm: Iterative Enclosed-Point Method
This method iterates over each sub-mesh, determines which voxels are enclosed by its surface, and assigns a unique label.

1.  **Wrap and Validate**: Wrap the input mesh using `pyvista.wrap(mesh)`. If `density` is `None`, set `density = mesh.length / 100`. Parse `density` into `density_x`, `density_y`, `density_z` (uniform if scalar, separate if sequence) [S1, unofficial].
2.  **Grid Initialization**: Extract mesh bounds `(x_min, x_max, y_min, y_max, z_min, z_max)`. Create coordinate arrays:
    $$ x = \text{np.arange}(x_{min}, x_{max}, density_x) $$
    $$ y = \text{np.arange}(y_{min}, y_{max}, density_y) $$
    $$ z = \text{np.arange}(z_{min}, z_{max}, density_z) $$
    Initialize `voi` as `pyvista.RectilinearGrid(x, y, z)`. Initialize `voi['InsideMesh']` with zeros of size `voi.n_cells` [S1, unofficial].
3.  **Iteration**: For each `sub_mesh` in `mesh` with index `i`:
    a. Set `sub_mesh_number = i + 1`.
    b. Extract geometry: `surface = sub_mesh.extract_geometry()`.
    c. **Pre-processing**: If `surface.faces.size` is 0, raise `ValueError` ("Input mesh must have faces for voxelization."). If `not surface.is_all_triangles`, call `surface.triangulate(inplace=True)` to reduce artifacts [S1, unofficial].
    d. **Enclosure Test**: Call `selection = voi.select_enclosed_points(surface, tolerance=0.0, check_surface=check_surface)`.
    e. **Mask Extraction**: Get boolean mask from `selection.point_data['SelectedPoints']` viewed as `np.bool_`: `mask_vol = selection.point_data['SelectedPoints'].view(np.bool_)`.
    f. **Cell ID Mapping**: Identify voxels (cells) corresponding to selected points. Extract points where `mask_vol` is true, retrieve their `vtkOriginalCellIds`, and take unique values:
       $$ \text{cell\_ids} = \text{np.unique}(\text{voi.extract\_points}(\text{np.argwhere}(mask\_vol))['\text{vtkOriginalCellIds}']) $$
    g. **Label Assignment**: Assign the label to the volume: `voi['InsideMesh'][cell_ids] = sub_mesh_number` [S1, unofficial].
4.  **Return**: Return `voi` [S1, unofficial].

### Algorithm: Sample and Split Method
This method voxelize the entire mesh first, then samples cell data from the original mesh onto the voxel grid, and splits the result into a multi-block structure based on label values.

1.  **Label Assignment**: Assign integer labels to the original mesh cells. For example, `labels = np.zeros((mesh.n_cells,))`; `labels[:700] = 1`; `mesh['labels'] = labels` [S1, unofficial].
2.  **Voxelization**: Voxelize the mesh: `vox = pv.voxelize(mesh, density=0.01)` [S1, unofficial].
3.  **Sampling**: Sample the voxelized mesh against the original mesh to transfer labels: `sampled = vox.sample(target=mesh, tolerance=1)`. Note: `tolerance` must be sufficiently large (e.g., 1 or `inf`) to ensure coverage [S1, unofficial].
4.  **Data Conversion**: Set active scalars to `'labels'`: `sampled.set_active_scalars('labels')`. Convert point data to cell data: `sampled = sampled.ptc()`. Round labels to integers: `sampled['labels'] = np.round(sampled['labels'])` [S1, unofficial].
5.  **Splitting**: Split the sampled data into a `MultiBlock` based on unique label values: `multiblock = sampled.split_values()`. Note: `split_values` is available in `pyvista>=0.44.0` [S1, unofficial].

### Pseudocode: Iterative Enclosed-Point Method
```python
import numpy as np
import pyvista as pv
import collections

def voxelize_volume_multiblock_label(mesh, density=None, check_surface=True):
    """
    Voxelize a MultiBlock mesh into a single RectilinearGrid volume.
    Each voxel is labeled with the integer ID of the sub-mesh block it intersects.
    """
    # 1. Wrap and prepare density
    mesh = pv.wrap(mesh)
    if density is None:
        density = mesh.length / 100
    
    if isinstance(density, (int, float, np.number)):
        density_x, density_y, density_z = [density] * 3
    elif isinstance(density, (collections.abc.Sequence, np.ndarray)):
        density_x, density_y, density_z = density
    else:
        raise TypeError(f"Invalid density {density!r}, expected number or array-like.")

    # 2. Initialize Grid
    x_min, x_max, y_min, y_max, z_min, z_max = mesh.bounds
    x = np.arange(x_min, x_max, density_x)
    y = np.arange(y_min, y_max, density_y)
    z = np.arange(z_min, z_max, density_z)
    
    voi = pv.RectilinearGrid(x, y, z)
    voi['InsideMesh'] = np.zeros(voi.n_cells, dtype=int)

    # 3. Iterate over sub-meshes
    for i, sub_mesh in enumerate(mesh):
        sub_mesh_number = i + 1
        
        # Extract geometry
        surface = sub_mesh.extract_geometry()
        
        # Pre-processing: Check for empty mesh
        if not surface.faces.size:
            raise ValueError("Input mesh must have faces for voxelization.")
        
        # Pre-processing: Triangulate if necessary
        if not surface.is_all_triangles:
            surface.triangulate(inplace=True)
        
        # Enclosed points test
        selection = voi.select_enclosed_points(
            surface, tolerance=0.0, check_surface=check_surface
        )
        
        # Get boolean mask of selected points
        mask_vol = selection.point_data['SelectedPoints'].view(np.bool_)
        
        # Map selected points to cell IDs
        # Extract points where mask is true, get their original cell IDs, and unique them
        selected_indices = np.argwhere(mask_vol)
        # Handle case where no points are selected
        if selected_indices.size == 0:
            continue
            
        extracted_points = voi.extract_points(selected_indices)
        cell_ids = np.unique(extracted_points['vtkOriginalCellIds'])
        
        # Assign label
        voi['InsideMesh'][cell_ids] = sub_mesh_number

    return voi
```

### Edge Cases and Pitfalls
- **Non-Triangular Faces**: If the surface contains non-triangular faces, artifacts may occur. Triangulate in-place before enclosed-point testing [S1, unofficial].
- **Empty Mesh**: If `surface.faces.size` is 0 (point cloud), raise `ValueError` [S1, unofficial].
- **Tolerance in Sample Method**: The `sample` filter only operates on point data. The `tolerance` parameter must be sufficiently large (e.g., 1 or `inf`) to ensure that voxel points are correctly associated with mesh cells [S1, unofficial].
- **Point vs Cell Data**: The `sample` filter interpolates data as point data. If cell data is required, a `ptc` (point-to-cell) conversion is necessary, which involves double interpolation and may be considered "hacky" [S1, unofficial].
- **Surface Closure**: If `check_surface=True` and the surface is not closed and manifold, a `RuntimeError` is raised [S1, unofficial].

## Operating characteristics
- **Time Complexity**: The iterative method is $O(N \cdot M)$, where $N$ is the number of sub-meshes and $M$ is the number of voxels, due to the enclosed-point test per sub-mesh. The sample method is dominated by the voxelization and sampling steps, which are generally efficient but depend on mesh complexity and voxel resolution.
- **Memory Complexity**: $O(V)$, where $V$ is the number of voxels, for storing the `RectilinearGrid` and label arrays.
- **Strengths**: Provides explicit block attribution. The iterative method is robust for watertight meshes. The sample method is concise for transferring existing cell data.
- **Limitations**: The iterative method requires each sub-mesh to be individually processed. The sample method relies on `split_values` which may not be available in older PyVista versions and involves interpolation artifacts [S1, unofficial].
- **When to Use**: Use when the goal is to preserve the identity of each mesh component in the voxelized volume. Use the iterative method for watertight meshes and the sample method when cell data is already available and needs to be transferred.

## Background
This method originates from discussions in the PyVista GitHub repository regarding the creation of labeled volumes for `MultiBlock` meshes [S1, unofficial]. It was proposed as a solution to extend the standard `voxelize` functionality to handle multiple mesh blocks with distinct labels, leveraging existing filters like `select_enclosed_points`, `sample`, and `split_values` [S1, unofficial].
