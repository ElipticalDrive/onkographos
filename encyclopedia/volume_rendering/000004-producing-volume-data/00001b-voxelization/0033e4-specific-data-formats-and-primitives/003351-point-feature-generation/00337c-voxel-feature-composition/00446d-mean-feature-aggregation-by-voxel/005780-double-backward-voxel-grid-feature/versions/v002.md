# Double Backward Voxel Grid Feature

Also called: Custom CUDA Double Backward, Voxel Grid Gradient of Gradient

## Overview
The Double Backward Voxel Grid Feature is a custom CUDA implementation that computes second-order gradients (gradients of gradients) for voxel grid features [S1, unofficial]. It solves the problem of excessive memory overhead and computational slowness associated with naive automatic differentiation frameworks, which construct long and complex computation graphs that cannot be optimized automatically [S1, unofficial].

## How it works
**Inputs:**
- Query points $\mathbf{x}_b = (x_b, y_b, z_b)$ for batch index $b$ [S1, unofficial].
- Voxel grid feature tensor $\mathbf{F}_V$ with grid size $G$ and bounds $m$ (min) and $M$ (max) [S1, unofficial].
- First-order gradient of the output feature w.r.t. the interpolated value, denoted $g^{(1)}\bar{\mathbf{f}}(\bar{\mathbf{x}}_b)$ [S1, unofficial].
- Second-order gradient of the loss w.r.t. the first-order gradient of the query point, denoted $g^{(2)}g^{(1)}\mathbf{x}_b = (g^{(2)}g^{(1)}x_b, g^{(2)}g^{(1)}y_b, g^{(2)}g^{(1)}z_b)$ [S1, unofficial].

**Outputs:**
- Second-order gradient of the loss w.r.t. the interpolated feature value, $g^{(2)}g^{(1)}\bar{\mathbf{f}}(\bar{\mathbf{x}}_b)$ [S1, unofficial].
- Accumulated second-order gradient w.r.t. the voxel grid features, $g^{(2)}\mathbf{f}_{i,j,k}$ [S1, unofficial].

**Data Structures:**
- The voxel grid feature is stored with dimensions $G \times G \times G$ and feature dimension $D$ [S1, unofficial].
- Gradients are stored in tensors matching their corresponding inputs [S1, unofficial].
- The CUDA implementation uses atomic add operations for gradient accumulation over the $i,j,k$ and $d$ dimensions [S1, unofficial].

**Steps:**

1. **Coordinate Transformation:** Transform the continuous query point $\mathbf{x}_b$ to the discrete coordinate system $\bar{\mathbf{x}}_b$ [S1, unofficial]. For the $x$ component: $\bar{x}_b = \frac{x_b - m}{M - m} G = s_x(x_b - m)$, where $s_x = \frac{G}{M - m}$ is the scaling factor [S1, unofficial]. Compute $\bar{y}_b$ and $\bar{z}_b$ analogously with scaling factors $s_y$ and $s_z$ [S1, unofficial].

2. **Forward Interpolation:** Compute the interpolated feature $\bar{\mathbf{f}}(\bar{\mathbf{x}}_b) = \sum_{i,j,k} w_{i,j,k}(\bar{\mathbf{x}}_b) \mathbf{f}_{i,j,k}(\bar{\mathbf{x}}_b)$, where $w_{i,j,k}(\bar{\mathbf{x}}_b)$ are the interpolation coefficients and $\mathbf{f}_{i,j,k}(\bar{\mathbf{x}}_b)$ are the voxel grid features queried at the $i,j,k$-th location of the discrete coordinate system [S1, unofficial].

3. **First-Order Gradients:** Compute the gradient w.r.t. the query point: $g^{(1)}x_b = \sum_d g^{(1)}\bar{f}^d(\bar{\mathbf{x}}_b) \sum_{i,j,k} s_x \frac{\partial w_{i,j,k}(\bar{\mathbf{x}}_b)}{\partial \bar{x}_b} f_{i,j,k}^d(\bar{\mathbf{x}}_b)$, with identical forms for $y$ and $z$ components [S1, unofficial]. Compute the gradient w.r.t. the voxel grid feature: $g^{(1)} \mathbf{f}_{i,j,k}(\bar{\mathbf{x}}_b) += g^{(1)} \bar{\mathbf{f}}(\bar{\mathbf{x}}_b) w_{i,j,k}(\bar{\mathbf{x}}_b)$ [S1, unofficial].

4. **Second-Order Gradient w.r.t. Interpolated Feature:** Compute the gradient flowing back to the output of the interpolation function: $g^{(2)} g^{(1)} \bar{f}^d(\bar{\mathbf{x}}_b) = g^{(2)} g^{(1)} x_b \sum_{i,j,k} s_x \frac{\partial w_{i,j,k}(\bar{\mathbf{x}}_b)}{\partial \bar{x}_b} f_{i,j,k}^d(\bar{\mathbf{x}}_b) + g^{(2)} g^{(1)} y_b \sum_{i,j,k} s_y \frac{\partial w_{i,j,k}(\bar{\mathbf{x}}_b)}{\partial \bar{y}_b} f_{i,j,k}^d(\bar{\mathbf{x}}_b) + g^{(2)} g^{(1)} z_b \sum_{i,j,k} s_z \frac{\partial w_{i,j,k}(\bar{\mathbf{x}}_b)}{\partial \bar{z}_b} f_{i,j,k}^d(\bar{\mathbf{x}}_b)$ [S1, unofficial].

5. **Second-Order Gradient w.r.t. Voxel Grid Feature:** Accumulate the gradient into the voxel grid feature tensor: $g^{(2)} f_{i,j,k}^d(\bar{\mathbf{x}}_b) += g^{(2)} g^{(1)} x_b g^{(1)} \bar{f}^d(\bar{\mathbf{x}}_b) s_x \frac{\partial w_{i,j,k}(\bar{\mathbf{x}}_b)}{\partial \bar{x}_b} + g^{(2)} g^{(1)} y_b g^{(1)} \bar{f}^d(\bar{\mathbf{x}}_b) s_y \frac{\partial w_{i,j,k}(\bar{\mathbf{x}}_b)}{\partial \bar{y}_b} + g^{(2)} g^{(1)} z_b g^{(1)} \bar{f}^d(\bar{\mathbf{x}}_b) s_z \frac{\partial w_{i,j,k}(\bar{\mathbf{x}}_b)}{\partial \bar{z}_b}$ [S1, unofficial].

**Pitfalls and Edge Cases:**
- **STE Limitation:** If the Straight Through Estimator is used for the forward pass, the derivative of the weights $\frac{\partial w_{i,j,k}}{\partial \bar{\mathbf{x}}}$ is zero, meaning the normals of the voxel grid feature are ignored and gradients w.r.t. the query point vanish [S1, unofficial].
- **Lookup Result:** The feature values $\mathbf{f}_{i,j,k}$ are results of lookups, and gradients are not backpropagated w.r.t. the lookup result itself in the second-order gradient step because it is treated as a constant source for the interpolation derivative calculation [S1, unofficial].

**Pseudocode:**
```python
def compute_trilinear_weights_and_derivatives(x_bar, y_bar, z_bar, grid_size):
    """Computes weights and derivatives for the 8 surrounding voxels."""
    # Floor coordinates
    ix, iy, iz = int(x_bar), int(y_bar), int(z_bar)
    # Fractional distances
    fx, fy, fz = x_bar - ix, y_bar - iy, z_bar - iz
    neighbors = []
    for dx in (0, 1):
        for dy in (0, 1):
            for dz in (0, 1):
                # Wrap coordinates if necessary (standard trilinear assumes clamping or wrapping)
                nx, ny, nz = (ix + dx) % grid_size, (iy + dy) % grid_size, (iz + dz) % grid_size
                # Trilinear weight
                w = (1 if dx == 0 else fx) * (1 if dy == 0 else fy) * (1 if dz == 0 else fz)
                # Derivatives w.r.t discrete coordinates
                dw_dx = (1 if dx == 1 else -1) * (1 if dx == 0 else fx) * (1 if dy == 0 else fy) * (1 if dz == 0 else fz)
                dw_dy = (1 if dx == 0 else fx) * (1 if dy == 1 else -1) * (1 if dy == 0 else fy) * (1 if dz == 0 else fz)
                dw_dz = (1 if dx == 0 else fx) * (1 if dy == 0 else fy) * (1 if dz == 1 else -1) * (1 if dz == 0 else fz)
                neighbors.append({
                    'coords': (nx, ny, nz),
                    'w': w,
                    'dw_dx': dw_dx,
                    'dw_dy': dw_dy,
                    'dw_dz': dw_dz
                })
    return neighbors

def double_backward_voxel_grid(query_points, voxel_features, bounds_min, bounds_max, grid_size,
                               grad_output_first_order, grad_query_point_second_order):
    """
    query_points: list of (x, y, z) tuples, length B
    voxel_features: 4D list/tensor of shape (G, G, G, D)
    bounds_min: (min_x, min_y, min_z)
    bounds_max: (max_x, max_y, max_z)
    grid_size: int G
    grad_output_first_order: list of (D,) vectors, length B
    grad_query_point_second_order: list of (gx, gy, gz) tuples, length B
    Returns: grad_voxel_features, grad_interpolated_feature_second_order
    """
    B = len(query_points)
    D = len(voxel_features[0][0][0])
    G = grid_size
    
    # Initialize gradient accumulator for voxel features
    grad_voxel_features = [[[ [0.0] * D for _ in range(G) ] for _ in range(G) ] for _ in range(G)]
    grad_interpolated_feature_second_order = [ [0.0] * D for _ in range(B) ]
    
    # Scaling factors
    scale_x = G / (bounds_max[0] - bounds_min[0])
    scale_y = G / (bounds_max[1] - bounds_min[1])
    scale_z = G / (bounds_max[2] - bounds_min[2])
    
    for b in range(B):
        x_b, y_b, z_b = query_points[b]
        g2g1_x, g2g1_y, g2g1_z = grad_query_point_second_order[b]
        g1_f_bar = grad_output_first_order[b]  # Shape (D,)
        
        # 1. Transform to discrete coordinates
        x_bar = scale_x * (x_b - bounds_min[0])
        y_bar = scale_y * (y_b - bounds_min[1])
        z_bar = scale_z * (z_b - bounds_min[2])
        
        # 2. Identify surrounding voxels and compute weights/derivatives
        neighbors = compute_trilinear_weights_and_derivatives(x_bar, y_bar, z_bar, G)
        
        # Accumulators for the gradient w.r.t interpolated feature (sum over i,j,k)
        sum_term_x = [0.0] * D
        sum_term_y = [0.0] * D
        sum_term_z = [0.0] * D
        
        for n in neighbors:
            i, j, k = n['coords']
            w = n['w']
            dw_dx, dw_dy, dw_dz = n['dw_dx'], n['dw_dy'], n['dw_dz']
            
            # Fetch feature vector at voxel (i,j,k)
            f_val = voxel_features[i][j][k]  # Shape (D,)
            
            # 3. Accumulate for g^(2)g^(1) f_bar^d
            for d in range(D):
                sum_term_x[d] += scale_x * dw_dx * f_val[d]
                sum_term_y[d] += scale_y * dw_dy * f_val[d]
                sum_term_z[d] += scale_z * dw_dz * f_val[d]
            
            # 4. Accumulate for g^(2) f_{i,j,k}^d
            # g^(2)g^(1) x_b * g^(1) f_bar^d * s_x * dw/dx + ...
            for d in range(D):
                term = (g2g1_x * g1_f_bar[d] * scale_x * dw_dx +
                        g2g1_y * g1_f_bar[d] * scale_y * dw_dy +
                        g2g1_z * g1_f_bar[d] * scale_z * dw_dz)
                grad_voxel_features[i][j][k][d] += term  # In CUDA, this is an atomic add
        
        # 5. Compute final g^(2)g^(1) f_bar^d
        for d in range(D):
            grad_interpolated_feature_second_order[b][d] = (
                g2g1_x * sum_term_x[d] +
                g2g1_y * sum_term_y[d] +
                g2g1_z * sum_term_z[d]
            )
            
    return grad_voxel_features, grad_interpolated_feature_second_order
```

## Operating characteristics
- **Time Complexity:** Not given in the sources.
- **Memory Complexity:** Not given in the sources, though the method avoids storing the large computation graph of naive automatic differentiation frameworks [S1, unofficial].
- **Performance:** Not given in the sources.
- **Strengths:** Efficient computation of second-order gradients required for Eikonal regularization without the memory overhead of standard auto-diff frameworks [S1, unofficial].
- **Limitations:** Requires custom CUDA implementation; not applicable if the Straight Through Estimator is used, as gradients vanish [S1, unofficial].

## Background
The method was developed to address the computational inefficiencies of using standard automatic differentiation libraries for voxel grid features in neural rendering [S1, unofficial]. Naive composition of functions creates a long computation graph that is difficult to optimize, leading to slow execution and high memory usage [S1, unofficial]. By implementing specific CUDA kernels for double-backward propagation, the authors achieved a more efficient solution for optimizing voxel-based representations with second-order constraints [S1, unofficial].
