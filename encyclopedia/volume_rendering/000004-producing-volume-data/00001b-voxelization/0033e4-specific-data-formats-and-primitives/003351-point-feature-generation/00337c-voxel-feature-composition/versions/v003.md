# Voxel Feature Composition

Also called: Gaussian Voxel Feature Generation, compose-voxel-features

## Overview
Voxel Feature Composition generates per-voxel feature vectors by sampling points within each Gaussian's volume and weighting them by Gaussian attenuation [S1, unofficial]. It aggregates voxel-level geometric and appearance data into a single feature vector per voxel for storage or further processing [S1, unofficial]. Unlike its sibling [Mean Feature Aggregation by Voxel](11242-mean-feature-aggregation-by-voxel.md), which relies on direct spatial averaging of raw points, this method computes features by sampling Gaussian volumes and weighting by attenuation [S1, unofficial].

## How it works
**Inputs:**
- `gaussians`: List of dictionaries. Each contains `mean` (3D vector $\mu$), `inverse_3d_covariance_matrix` ($3 \times 3$ matrix $\Sigma^{-1}$), `opacity` (scalar $\alpha$), and `rgb` (3D vector) [S1, unofficial].
- `num_voxels_per_g`: List or tensor of integers specifying the number of voxels per Gaussian [S1, unofficial].
- `grid_size`: Float, the voxel cell size [S1, unofficial].

**Outputs:**
- `voxel_xyzs`: List of 3D coordinate tensors for all generated voxels [S1, unofficial].
- `voxel_features`: List of feature tensors. Each is a 7-element vector per voxel: 3 for position ($xyz$), 3 for color ($rgb$), and 1 for opacity [S1, unofficial].

**Data Structures:**
- The feature vector concatenates position, color, and opacity along the feature dimension: `[voxel_xyz, color_rgb, voxel_opacity]` [S1, unofficial].

**Steps:**
1. Initialize empty lists `voxel_xyzs` and `voxel_features` [S1, unofficial].
2. Iterate over each Gaussian $g$ in `gaussians` and its corresponding voxel count $N$ from `num_voxels_per_g` [S1, unofficial].
3. Extract parameters: $\mu = g[\text{"mean"}]$, $\Sigma^{-1} = g[\text{"inverse_3d_covariance_matrix"}]$, $\alpha = g[\text{"opacity"}]$, $c = g[\text{"rgb"}]$ [S1, unofficial].
4. For each voxel index $i$ from $0$ to $N-1$:
   a. Compute the 3D coordinate $v$ using `get_voxel_location(i, g, grid_size)` [S1, unofficial].
   b. Compute Mahalanobis distance:
      $$dist = (v - \mu)^T \Sigma^{-1} (v - \mu)$$
      where $v$ is the voxel coordinate, $\mu$ is the Gaussian mean, and $\Sigma^{-1}$ is the inverse covariance matrix [S1, unofficial].
   c. Compute voxel opacity:
      $$opacity = \alpha \cdot \exp(-0.5 \cdot dist)$$
      where $\alpha$ is the Gaussian opacity factor and $dist$ is the Mahalanobis distance [S1, unofficial].
   d. Concatenate features: $feature\_vec = [v, c, opacity]$ [S1, unofficial].
   e. Append $v$ to `voxel_xyzs` and $feature\_vec$ to `voxel_features` [S1, unofficial].
5. Return `voxel_xyzs` and `voxel_features` [S1, unofficial].

**Pseudocode:**
```python
import torch
from typing import List, Dict, Tuple

def compose_voxel_features(
    gaussians: List[Dict], 
    num_voxels_per_g: List[int], 
    grid_size: float
) -> Tuple[List[torch.Tensor], List[torch.Tensor]]:
    """
    Generate per-voxel feature vectors for a set of 3D Gaussians.
    """
    voxel_xyzs = []
    voxel_features = []
    
    for gaussian, num_voxels in zip(gaussians, num_voxels_per_g):
        mu = gaussian["mean"]
        inv_cov = gaussian["inverse_3d_covariance_matrix"]
        opacity_factor = gaussian["opacity"]
        color_rgb = gaussian["rgb"]
        
        for voxel_idx in range(num_voxels):
            # 1. Get the 3D coordinate for the current voxel
            # [G] Sources do not specify implementation; typically computes world coordinates 
            # from voxel index and grid size relative to the Gaussian's bounding volume.
            voxel_xyz = get_voxel_location(voxel_idx, gaussian, grid_size)
            voxel_xyzs.append(voxel_xyz)
            
            # 2. Compute the Mahalanobis distance
            diff = voxel_xyz - mu
            dist = diff @ inv_cov @ diff
            
            # 3. Compute voxel opacity using a Gaussian attenuation factor
            voxel_opacity = opacity_factor * torch.exp(-0.5 * dist)
            
            # 4. Concatenate features: [xyz, rgb, opacity]
            # Source uses dim=1; for standard 1D tensors, dim=0 is used.
            feature_vec = torch.cat([voxel_xyz, color_rgb, voxel_opacity], dim=0)
            voxel_features.append(feature_vec)
            
    return voxel_xyzs, voxel_features
```

**Parameters and Edge Cases:**
- `grid_size`: Determines the spatial resolution. Not given in the sources.
- `num_voxels_per_g`: Precomputed count. If zero, the Gaussian contributes no voxels.
- Precision: The Mahalanobis distance calculation involves matrix-vector multiplication. The source does not specify handling for non-positive definite covariance matrices [S1, unofficial].

## Subtopics

### [Mean Feature Aggregation by Voxel](11242-mean-feature-aggregation-by-voxel.md)
Computes mean features for each voxel by aggregating point features based on voxel indices. It serves as a geometric feature extraction step that converts sparse, noisy LiDAR point clouds into dense, structured neural volumetric features. Unlike Voxel Feature Composition, it relies on direct spatial averaging of raw LiDAR points followed by a 3D sparse convolutional network to encode global context.

### Volume Elements Construction
Constructs volume elements by concatenating sampled colors, features, and features' cosine similarities [S2]. For large baselines, features are more important than cosine similarities because feature matching is less reliable due to insufficient scene overlap; for small baselines, cosine similarities become more important. Sampled colors contribute to performance in both settings [S2].

## Operating characteristics
- **Time Complexity:** Linear with respect to the total number of voxels generated across all Gaussians. Each voxel requires a Mahalanobis distance calculation and concatenation [G].
- **Memory Complexity:** Proportional to the total number of voxels. Each voxel stores a 7-element feature vector [G].
- **Strengths:** Provides a structured, dense representation of Gaussian splats suitable for downstream neural networks (e.g., sparse convolutions) [S1, unofficial].
- **Limitations:** Requires precomputing the number of voxels per Gaussian and a helper function to map voxel indices to 3D coordinates, which is not detailed in the source [S1, unofficial].

## Background
Voxel Feature Composition was introduced in the context of "Quantile Rendering: Efficiently Embedding High-dimensional Feature on 3D Gaussian Splatting" [S1, unofficial]. It is used to embed high-dimensional features into 3D Gaussian Splatting for quantile rendering and semantic segmentation tasks [S1, unofficial].
