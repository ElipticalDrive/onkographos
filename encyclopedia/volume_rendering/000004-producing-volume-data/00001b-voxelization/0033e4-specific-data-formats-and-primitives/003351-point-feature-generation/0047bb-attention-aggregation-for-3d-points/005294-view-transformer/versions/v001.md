# View Transformer

Also called: Linear Attention View Transformer

## Overview
The View Transformer aggregates multi-view features into a single projection feature to handle occlusions and view consistency without assuming an order of source views. It sets itself apart from sibling methods by using a self-attention mechanism with linear attention complexity, avoiding positional encodings to maintain permutation invariance across the input views.

## How it works
**Inputs and Outputs:**
*   **Inputs:** A set of $N$ source views. For a specific query point $p$ (e.g., a point on a ray from a reference pixel), the inputs are the extracted color features $\{c_i\}_{i=1}^N$ and feature vectors $\{f_i\}_{i=1}^N$ from each source view $i$. A learnable aggregation token $f_0$ is also required.
*   **Outputs:** A single projection feature $f_p$ and updated multi-view features $\{f'_i\}_{i=1}^N$.

**Data Structures:**
*   $f_i \in \mathbb{R}^d$: Feature vector for view $i$.
*   $c_i \in \mathbb{R}^3$: Color vector for view $i$.
*   $f_0 \in \mathbb{R}^d$: Learnable aggregation token.
*   $f_p \in \mathbb{R}^d$: Output projection feature.

**Steps:**
1.  **Feature Extraction:** For each source view $i$, project the query point $p$ onto the feature map of that view. Extract the color $c_i$ and feature vector $f_i$ using bilinear interpolation [S1].
2.  **Token Initialization:** Initialize the aggregation token $f_0$. This token is learnable and serves as the query for the attention mechanism [S1].
3.  **Attention Aggregation:** Apply a self-attention transformer with linear attention to the sequence of inputs $(f_0, \{f_i\}_{i=1}^N)$.
    *   The attention mechanism computes the projection feature $f_p$ and updated features $\{f'_i\}_{i=1}^N$.
    *   The operation is defined as:
        $$ f_p, \{f'_i\}_{i=1}^N = \text{ViewTrans}(f_0, \{f_i\}_{i=1}^N) $$
    *   Linear attention is used to reduce computational complexity compared to standard quadratic self-attention [S1].
4.  **Color Weighting (Post-Processing):** Although the transformer outputs features, the final color contribution often involves weighting the extracted colors $c_i$ by attention weights $\eta_i$. The accumulated color $\hat{C}$ is computed as:
    $$ \hat{C} = \sum_{i=1}^N \eta_i \cdot c_i $$
    Note: The specific formula for $\eta_i$ is not detailed in the provided text, but it is implied to be derived from the attention mechanism [S1].

**Parameters:**
*   **Positional Encoding:** Not used. The method assumes no order of source views, so positional encodings are omitted to preserve permutation invariance [S1].
*   **Learnable Token:** $f_0$ is a learnable parameter vector [S1].

**Pseudocode:**
```python

    """
    Aggregates multi-view features for a query point using linear attention.
    
    Args:
        query_point: 3D point p to be projected.
        source_views: List of N source view feature maps and camera parameters.
        learnable_token_f0: Learnable aggregation token f0.
        
    Returns:
        projection_feature: f_p
        updated_features: List of f'_i
    """
    N = len(source_views)
    features = []
    colors = []
    
    # Step 1: Extract features and colors via bilinear interpolation
    for i in range(N):
        view = source_views[i]
        # Project query_point onto view's feature map
        # Extract f_i and c_i using bilinear interpolation
        f_i, c_i = extract_feature_and_color(query_point, view)
        features.append(f_i)
        colors.append(c_i)
        
    # Step 2: Prepare input sequence for transformer
    # Input sequence: [f0, f1, f2, ..., fN]
    input_sequence = [learnable_token_f0] + features
    
    # Step 3: Apply self-attention with linear attention
    # Note: Linear attention implementation details (e.g., kernel functions) 
    # are not specified in the source. [G]
    # Standard self-attention would be:
    # attention_weights = softmax(Q @ K^T / sqrt(d))
    # Linear attention approximates this for efficiency.
    
    # The transformer computes f_p and updated f'_i
    # f_p is typically the output corresponding to the first token (f0)
    # f'_i are the outputs corresponding to the other tokens
    
    projection_feature, updated_features = linear_self_attention(input_sequence)
    
    return projection_feature, updated_features
```

**Edge Cases and Pitfalls:**
*   **Occlusion:** The transformer handles occlusions by aggregating features from multiple views. However, if all views are occluded, the result may be unreliable.
*   **Permutation Invariance:** Do not add positional encodings, as the order of views is arbitrary [S1].

## Operating characteristics
*   **Time Complexity:** Linear attention reduces the complexity from $O(N^2)$ to $O(N)$ with respect to the number of views $N$, making it efficient for large numbers of source views [S1].
*   **Memory Complexity:** Linear in the number of views $N$ and the feature dimension $d$.
*   **Strengths:** Handles arbitrary input counts of views; permutation invariant; efficient due to linear attention.
*   **Limitations:** Relies on the quality of extracted features; no positional encoding means it cannot leverage spatial ordering if it were beneficial.

## Background
The View Transformer is introduced in the context of generalizable multi-view reconstruction, specifically in the VolRecon method. It builds on previous work using self-attention for feature aggregation [S1]. The method is part of a pipeline that includes volume rendering of Signed Ray Distance Functions (SRDF) [S1].
