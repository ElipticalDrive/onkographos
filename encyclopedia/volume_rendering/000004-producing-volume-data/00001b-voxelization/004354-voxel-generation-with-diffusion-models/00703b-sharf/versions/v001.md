# Sharf

Also called: ShaRF, Shape-aware Radiance Fields

## Overview
Sharf (Shape-aware Radiance Fields) generates novel 3D shapes and high-fidelity novel views by combining a generative model of voxelized shapes with a conditional neural radiance field (NeRF) [S1, unofficial][S2]. It addresses the limitation of standard NeRFs, which represent a single static scene, by enabling the synthesis of diverse object instances within a category [S1, unofficial][S2]. Unlike sibling methods that may use continuous latent deformations or template-based approaches, Sharf explicitly discretizes shape generation into a voxel grid, which then conditions the radiance field for rendering [S2].

## How it works
**Inputs and Outputs:**
*   **Input:** A shape latent code $z_s$ and an appearance latent code $z_a$.
*   **Output:** A rendered image of a novel view of a generated 3D object.

**Data Structures:**
1.  **Shape Latent Code ($z_s$):** A vector sampled from a learned distribution representing the geometric structure.
2.  **Appearance Latent Code ($z_a$):** A vector representing visual properties (color, texture) independent of shape.
3.  **Voxel Grid:** A 3D grid representing the occupancy of the object. The resolution is determined by the shape network's output.
4.  **NeRF Network:** A multi-layer perceptron (MLP) that outputs color and density.

**Steps:**
1.  **Shape Generation:** A shape network (encoder/decoder or generator) maps the shape latent code $z_s$ into a 3D voxel grid $V$. This grid represents the occupancy of the object in the category [S2].
2.  **Conditioning:** The NeRF network is conditioned on two factors:
    *   The occupancy value $o(x)$ estimated from the voxel grid $V$ at the query point $x$ [S2].
    *   The appearance latent code $z_a$ [S2].
3.  **Rendering:** The conditioned NeRF is rendered using standard volume rendering techniques to produce the final image [S1, unofficial][S2].

**Formulas:**
The occupancy $o(x)$ is derived from the voxel grid $V$. The NeRF function $F_\theta$ takes position $x$, viewing direction $d$, occupancy $o(x)$, and appearance code $z_a$:
$$ (c, \sigma) = F_\theta(x, d, o(x), z_a) $$
where $c$ is color and $\sigma$ is density [S2].

**Parameters:**
*   Resolution of the voxel grid: Not given in the sources.
*   Dimension of latent codes: Not given in the sources.

**Edge Cases and Pitfalls:**
*   **Discretization Artifacts:** The voxel grid introduces discretization errors, potentially leading to jagged surfaces if the resolution is insufficient [S2].
*   **Conditioning Consistency:** The occupancy value must be accurately estimated from the voxel grid to ensure the NeRF renders the correct shape [S2].

**Pseudocode:**
```python
def shaRF_render(shape_latent_code, appearance_latent_code, camera_params):
    # Step 1: Generate voxel grid from shape latent code
    # Shape network maps z_s to a 3D voxel grid V
    voxel_grid = shape_network(shape_latent_code)
    
    # Step 2: Define the conditioned NeRF
    # The NeRF takes position, direction, occupancy, and appearance code
    def neRF(position, direction):
        # Get occupancy from voxel grid at position
        occupancy = get_occupancy_from_voxel_grid(voxel_grid, position)
        
        # NeRF predicts color and density conditioned on occupancy and appearance
        color, density = neRF_network(position, direction, occupancy, appearance_latent_code)
        return color, density
    
    # Step 3: Render using volume rendering
    # Cast rays through camera_params and integrate along rays
    image = volume_render(neRF, camera_params)
    return image
```

## Subtopics

### DDPM Sampling at Inference
Uses a Denoising Diffusion Probabilistic Model (DDPM) to generate voxelized shapes. The goal is to learn a parameterized Markov chain that generates novel samples after finite time steps. [18300-ddpm-sampling-at-inference.md]

## Operating characteristics
*   **Time Complexity:** Not given in the sources.
*   **Memory Complexity:** Not given in the sources.
*   **Strengths:** Enables high-fidelity novel view synthesis by leveraging the explicit shape representation of the voxel grid [S1, unofficial][S2].
*   **Limitations:** The reliance on voxel grids may limit resolution and introduce discretization artifacts [S2].
*   **When to use:** When generating diverse 3D shapes within a category and requiring high-quality novel views [S1, unofficial][S2].
*   **When not to use:** When continuous, high-resolution shape representation is required without discretization artifacts [S2].

## Background
Sharf was introduced by [RMBF21] as a method to generate voxelized shapes of objects in a category, which condition a higher resolution neural radiance field for novel view synthesis [S1, unofficial][S2]. It builds on the idea of using latent codes to represent 3D structures, extending it to include explicit voxel-based shape generation [S2].
