# Voxel Generation with Diffusion Models
Also called: DDPM-based Voxel Generation

## Overview
This method generates discrete 3D volumetric shapes by training a Denoising Diffusion Probabilistic Model (DDPM) to learn the distribution of voxelized objects [S1, unofficial]. It learns a parameterized Markov chain that generates novel samples after a finite number of steps [S1, unofficial]. The generated voxel grids serve as an initial coarse representation for downstream volumetric mesh extraction [S1, unofficial].

## How it works
**Inputs and Outputs**
*   **Input:** A training dataset of voxelized shapes, where each shape is a binary tensor $V \in \{0, 1\}^{r \times r \times r}$ representing a mesh discretized into a grid [S1, unofficial]. Shapes are normalized to fit within a unit cube [S1, unofficial].
*   **Output:** A generated binary tensor $\hat{x}_0 \in \{0, 1\}^{r \times r \times r}$ representing a novel 3D shape [S1, unofficial].

**Data Structures**
*   **Voxel Tensor:** A 3D array of size $r \times r \times r$ with values $0$ (unfilled) or $1$ (filled) [S1, unofficial].
*   **Noise Schedule:** A sequence of variance parameters $\beta_t$ for $t \in [1, T]$, where $\beta_t$ gradually decreases to $0$ as $t \to 0$ [S1, unofficial].

**Parameters**
*   $r$: Voxel resolution. Not given in the sources.
*   $T$: Total number of diffusion steps. Not given in the sources.
*   $\beta_t$: Noise schedule parameter. Not given in the sources.

**Algorithm Steps**

1.  **Forward Process (Diffusion):**
    The forward Markov chain gradually diffuses a real data sample $x_0$ to standard Gaussian noise $x_T$ over $T$ steps [S1, unofficial]. The joint distribution is $q(x_{0:T}) = q(x_0) \prod_{t=1}^T q(x_t | x_{t-1})$ [S1, unofficial]. Each transition adds Gaussian noise: $q(x_t | x_{t-1}) = \mathcal{N}(x_t ; \sqrt{1 - \beta_t} x_{t-1}, \beta_t I)$ [S1, unofficial]. Using the reparameterization trick, any step $t$ can be sampled directly from $x_0$: $x_t = \sqrt{\bar{\alpha}_t} x_0 + \sqrt{1 - \bar{\alpha}_t} \epsilon$, where $\epsilon \sim \mathcal{N}(0, I)$, $\alpha_t = 1 - \beta_t$, and $\bar{\alpha}_t = \prod_{i=1}^t \alpha_i$ [S1, unofficial].

2.  **Model Parameterization:**
    A 3D convolutional neural network $\epsilon_\phi$ predicts the noise $\epsilon$ added to $x_t$ at step $t$ [S1, unofficial]. The architecture follows standard 3D CNN designs with modifications for voxel generation tasks [S1, unofficial].

3.  **Training Objective:**
    The model maximizes the evidence lower bound (ELBO), which simplifies to a mean squared error loss between the predicted noise and the actual noise [S1, unofficial]. The loss is $L_{ddpm} = \mathbb{E}_{x_0, t, \epsilon} [ || \epsilon - \epsilon_\phi(\sqrt{\bar{\alpha}_t} x_0 + \sqrt{1 - \bar{\alpha}_t} \epsilon, t) ||^2 ]$ [S1, unofficial]. Training samples $x_0$ from the dataset, $t$ uniformly from $[1, T]$, and $\epsilon$ from $\mathcal{N}(0, I)$ [S1, unofficial].

4.  **Sampling (Reverse Process):**
    To generate a shape, start with $\hat{x}_T \sim \mathcal{N}(0, I)$ and iteratively denoise from $t=T$ down to $t=0$ [S1, unofficial]. The reverse chain is $p_\phi(x_{0:T}) = p(x_T) \prod_{t=1}^T p_\phi(x_{t-1} | x_t)$ [S1, unofficial]. Each step samples from $p_\phi(x_{t-1} | x_t) = \mathcal{N}(x_{t-1} ; \mu_\phi(x_t, t), \beta_t I)$ [S1, unofficial]. The mean is computed as $\mu_\phi(x_t, t) = \frac{1}{\sqrt{\alpha_t}} (x_t - \sqrt{1 - \bar{\alpha}_t} \epsilon_\phi(x_t, t))$ [S1, unofficial].

**Pseudocode**

```python
import torch
import torch.nn as nn
import torch.nn.functional as F

def train_step(model, x_0, alpha_t, alpha_bar_t, beta_t, device):
    """
    Computes the training loss for one batch.
    x_0: Ground truth voxel tensor [B, 1, r, r, r]
    alpha_t: Tensor of alpha values [T]
    alpha_bar_t: Tensor of alpha_bar values [T]
    beta_t: Tensor of beta values [T]
    """
    B, C, H, W, D = x_0.shape
    # Sample time step t uniformly from [0, T-1]
    t = torch.randint(0, len(alpha_t), (B,), device=device).long()
    
    # Sample noise epsilon ~ N(0, I)
    epsilon = torch.randn_like(x_0)
    
    # Create noisy sample x_t using reparameterization trick
    # x_t = sqrt(alpha_bar_t) * x_0 + sqrt(1 - alpha_bar_t) * epsilon
    sqrt_alpha_bar = torch.sqrt(alpha_bar_t[t]).view(B, 1, 1, 1, 1)
    sqrt_one_minus_alpha_bar = torch.sqrt(1 - alpha_bar_t[t]).view(B, 1, 1, 1, 1)
    x_t = sqrt_alpha_bar * x_0 + sqrt_one_minus_alpha_bar * epsilon
    
    # Predict noise with 3D CNN
    predicted_epsilon = model(x_t, t)
    
    # Loss: MSE between predicted and actual noise
    loss = F.mse_loss(predicted_epsilon, epsilon)
    return loss

def generate_sample(model, alpha_t, alpha_bar_t, beta_t, device, resolution=32):
    """
    Generates a voxel grid from noise.
    """
    # Start with pure Gaussian noise x_T ~ N(0, I)
    x_t = torch.randn(1, 1, resolution, resolution, resolution, device=device)
    
    # Iteratively denoise from t = T-1 down to 0
    for t in reversed(range(len(alpha_t))):
        # Predict noise
        predicted_epsilon = model(x_t, torch.tensor([t], device=device))
        
        # Compute mean for reverse process
        # mu = 1/sqrt(alpha_t) * (x_t - sqrt(1 - alpha_bar_t) * epsilon_pred)
        alpha = alpha_t[t]
        alpha_bar = alpha_bar_t[t]
        
        sqrt_alpha = torch.sqrt(alpha)
        sqrt_one_minus_alpha_bar = torch.sqrt(1 - alpha_bar)
        
        mu = (1.0 / sqrt_alpha) * (x_t - sqrt_one_minus_alpha_bar * predicted_epsilon)
        
        # Add noise if t > 0, otherwise use deterministic mean
        if t > 0:
            beta = beta_t[t]
            z = torch.randn_like(x_t)
            x_t = mu + torch.sqrt(beta) * z
        else:
            x_t = mu
            
    # Threshold continuous output to binary voxel grid {0, 1} [G]
    voxel_grid = (x_t > 0.5).float()
    return voxel_grid
```

**Edge Cases and Pitfalls**
*   **Binary Constraint:** The diffusion process operates on continuous space, but the target representation is binary $\{0, 1\}$ [S1, unofficial]. Thresholding the final output is required to enforce the binary constraint [G].
*   **Resolution:** The method assumes a fixed resolution $r \times r \times r$ [S1, unofficial]. Changing resolution requires retraining or interpolation, which is not detailed in the source [S1, unofficial].
*   **Normalization:** Shapes must be normalized to a unit cube before voxelization for training [S1, unofficial].

## Operating characteristics
Training requires iterative 3D convolutional network forward passes over $T$ steps per sample [S1, unofficial]. Sampling time scales linearly with $T$ [S1, unofficial]. Memory usage scales with the voxel grid volume $r^3$ and the 3D CNN parameters [S1, unofficial]. The method generates novel shapes with good generalization but is constrained by fixed resolution and the computational cost of 3D convolutions [S1, unofficial].

## Background
This method was proposed by Yan Zheng, Lemeng Wu, Xingchao Liu, Zhen Chen, Qiang Liu, and Qixing Huang from the University of Texas at Austin in the paper "Neural Volumetric Mesh Generator" (2022) [S1, unofficial]. It builds on the Denoising Diffusion Probabilistic Model (DDPM) framework introduced by Ho et al. (2020) [S1, unofficial]. It serves as the first module in the NVMG pipeline to produce coarse voxel representations for subsequent tetrahedral mesh generation [S1, unofficial].
