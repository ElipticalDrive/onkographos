# Local Density Bounds via Sliding Window

Also called: 3-pass axis-aligned min/max filter, Deque-based Window Min/Max, Local density bound estimation, Monotonic Queue Sweep, Sliding Window Minimum/Maximum for Volume Bounds, Volume density bound computation (sliding window min/max filter)

## Overview
This method computes the minimum and maximum volume density values within a neighborhood defined by a `search_radius` around each voxel, establishing local density bounds for volume rendering preprocessing [S1, unofficial]. It differs from global scalar range calculation by providing spatially varying bounds, and from naive box filtering by achieving linear time complexity $O(N)$ using monotonic queues instead of $O(N \cdot R^3)$ [S1, unofficial].

## How it works
**Inputs:**
- `volume`: 1D array of scalar density values, size $N = \text{width} \times \text{height} \times \text{depth}$ [S1, unofficial].
- `width`, `height`, `depth`: Integer dimensions of the volume grid [S1, unofficial].
- `search_radius`: Float, radius of the neighborhood to search around each voxel [S1, unofficial].
- `extent_width`: Float, used to compute the cell size [S1, unofficial].

**Outputs:**
- `bound_volume_2`: 1D array of `Data2` structs, size $N$ [S1, unofficial].

**Data Structures:**
- `Data2`: Struct with two fields: `x` (max density) and `y` (min density) [S1, unofficial].
- `bound_volume` and `bound_volume_2`: 1D arrays of `Data2`, indexed as `k * nxy + i + j * nx` where `nxy = width * height` and `nx = width` [S1, unofficial].
- `CircularBuffer<int, buffer_size>`: Fixed-size buffer used to implement monotonic queues, with `buffer_size` hardcoded to 256 [S1, unofficial].

**Parameters:**
- `search_radius`: Float [S1, unofficial].
- `buffer_size`: Integer, hardcoded to 256 [S1, unofficial].
- `cell_size`: Float, calculated as $2.0 / \text{extent\_width}$ [S1, unofficial].
- `diffusion_iters`: Integer, calculated as $\lceil \text{search\_radius} / \text{cell\_size} \rceil$ [S1, unofficial].
- `window_size`: Integer, calculated as $\text{diffusion\_iters} \times 2 + 1$ [S1, unofficial].

**Steps:**
1. Allocate `bound_volume` and `bound_volume_2` of size $N$. Initialize `bound_volume[i] = make<Data, Data2>(volume[i], volume[i])` for all $i$ [S1, unofficial].
2. Calculate `cell_size`, `diffusion_iters`, and `window_size` [S1, unofficial].
3. Loop `sweep_dir` from $0$ to $2$ (x, y, z axes). Parallelize over the two orthogonal dimensions for each axis [S1, unofficial].
4. For each line along the sweep axis:
   a. Initialize empty `max_window` and `min_window` buffers [S1, unofficial].
   b. Iterate index $k$ from $0$ to $\text{line\_len} + \text{diffusion\_iters} + 1$ [S1, unofficial].
   c. If $k < \text{line\_len}$: read density $d$, pop back from `max_window` if $d.x > \text{bound\_volume}[\text{back}].x$, pop back from `min_window` if $d.y < \text{bound\_volume}[\text{back}].y$, then push $k$ to both [S1, unofficial].
   d. Pop front from `max_window` if $\text{front} \le k - \text{window\_size}$, and similarly for `min_window` [S1, unofficial].
   e. If $k > \text{diffusion\_iters}$: write `bound_volume_2[(k - \text{diffusion\_iters} - 1) \times \text{stride} + \text{offset}] = make<Data, Data2>(\text{max\_window.front().x}, \text{min\_window.front().y})` [S1, unofficial].

**Pseudocode:**
```python
import math

def local_density_bounds(volume, width, height, depth, search_radius, extent_width):
    N = width * height * depth
    nxy = width * height
    nx = width
    ny = height
    nz = depth

    class Data2:
        def __init__(self, x, y):
            self.x = x
            self.y = y

    # Step 1: Initialize bound_volume
    bound_volume = [Data2(v, v) for v in volume]
    bound_volume_2 = [Data2(0.0, 0.0) for _ in range(N)]

    # Step 2: Calculate parameters
    cell_size = 2.0 / extent_width
    diffusion_iters = math.ceil(search_radius / cell_size)
    window_size = diffusion_iters * 2 + 1
    buffer_size = 256
    assert buffer_size > window_size, "buffer_size must be strictly greater than window_size"

    # Step 3: Sweep along all three axes
    # Z-axis sweep
    for j in range(ny):
        for i in range(nx):
            offset = i + j * nx
            max_window = []
            min_window = []
            for k in range(nz + diffusion_iters + 1):
                if k < nz:
                    d = bound_volume[k * nxy + offset]
                    while max_window and d.x > bound_volume[max_window[-1] * nxy + offset].x:
                        max_window.pop()
                    while min_window and d.y < bound_volume[min_window[-1] * nxy + offset].y:
                        min_window.pop()
                    max_window.append(k)
                    min_window.append(k)

                if max_window and max_window[0] <= k - window_size:
                    max_window.pop(0)
                if min_window and min_window[0] <= k - window_size:
                    min_window.pop(0)

                if k > diffusion_iters:
                    d_max = bound_volume[max_window[0] * nxy + offset].x
                    d_min = bound_volume[min_window[0] * nxy + offset].y
                    out_idx = (k - diffusion_iters - 1) * nxy + offset
                    bound_volume_2[out_idx] = Data2(d_max, d_min)

    # Y-axis sweep
    for i in range(nx):
        for k in range(nz):
            offset = i + k * nxy
            max_window = []
            min_window = []
            for j in range(ny + diffusion_iters + 1):
                if j < ny:
                    d = bound_volume[j * nx + offset]
                    while max_window and d.x > bound_volume[max_window[-1] * nx + offset].x:
                        max_window.pop()
                    while min_window and d.y < bound_volume[min_window[-1] * nx + offset].y:
                        min_window.pop()
                    max_window.append(j)
                    min_window.append(j)

                if max_window and max_window[0] <= j - window_size:
                    max_window.pop(0)
                if min_window and min_window[0] <= j - window_size:
                    min_window.pop(0)

                if j > diffusion_iters:
                    d_max = bound_volume[max_window[0] * nx + offset].x
                    d_min = bound_volume[min_window[0] * nx + offset].y
                    out_idx = (j - diffusion_iters - 1) * nx + offset
                    bound_volume_2[out_idx] = Data2(d_max, d_min)

    # X-axis sweep
    for j in range(ny):
        for k in range(nz):
            offset = j * nx + k * nxy
            max_window = []
            min_window = []
            for i in range(nx + diffusion_iters + 1):
                if i < nx:
                    d = bound_volume[i + offset]
                    while max_window and d.x > bound_volume[max_window[-1] + offset].x:
                        max_window.pop()
                    while min_window and d.y < bound_volume[min_window[-1] + offset].y:
                        min_window.pop()
                    max_window.append(i)
                    min_window.append(i)

                if max_window and max_window[0] <= i - window_size:
                    max_window.pop(0)
                if min_window and min_window[0] <= i - window_size:
                    min_window.pop(0)

                if i > diffusion_iters:
                    d_max = bound_volume[max_window[0] + offset].x
                    d_min = bound_volume[min_window[0] + offset].y
                    out_idx = (i - diffusion_iters - 1) + offset
                    bound_volume_2[out_idx] = Data2(d_max, d_min)

    return bound_volume_2
```

**Pitfalls:**
- `buffer_size` must exceed `window_size` to prevent the circular buffer from overwriting valid indices before eviction [S1, unofficial].
- The output index $(k - \text{diffusion\_iters} - 1)$ is guarded by $k > \text{diffusion\_iters}$ to avoid negative indices [S1, unofficial].
- Window eviction uses $\le$ to ensure the window strictly contains `window_size` elements when $k \ge \text{window\_size}$ [S1, unofficial].

## Operating characteristics
- **Time Complexity:** $O(N)$ per axis pass, where $N = \text{width} \times \text{height} \times \text{depth}$, totaling $O(3N) = O(N)$ [S1, unofficial].
- **Space Complexity:** $O(N)$ for `bound_volume` and `bound_volume_2`, plus $O(\text{window\_size})$ per thread for the circular buffers [S1, unofficial].
- **Measured Performance:** Not given in the sources.
- **Strengths:** Linear time complexity, efficient line-based memory access, and straightforward parallelization [S1, unofficial].
- **Limitations:** Approximates a spherical neighborhood with axis-aligned passes, which may introduce anisotropy, and requires strict buffer sizing [S1, unofficial].
