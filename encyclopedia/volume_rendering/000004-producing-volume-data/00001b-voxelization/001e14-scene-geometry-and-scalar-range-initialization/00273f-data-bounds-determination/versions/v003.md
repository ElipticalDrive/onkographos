# Data Bounds Determination

Also called: Bounds Computation, Scalar Range Initialization

## Overview
Data Bounds Determination is a preprocessing procedure that establishes the minimum and maximum scalar values ($v_{min}, v_{max}$) for a volume dataset to enable consistent color mapping [S1, unofficial]. It solves the problem of outlier sensitivity and cross-file consistency in volume rendering by selecting a scalar range from three available strategies: manual user specification, percentile-based filtering, or global extremum selection [S1, unofficial]. It is distinguished from [Scalar Range Calculation](11487-scalar-range-calculation.md) by its specific implementation of histogram-based percentile selection and manual overrides, and from [Local Density Bounds via Sliding Window](12750-local-density-bounds-via-sliding-window.md) by computing a single global static range rather than spatially adaptive local bounds.

## How it works
**Inputs and Outputs:**
- Input: A scalar field dataset $V$ containing $N$ values; a configuration specifying the chosen method (Manual, Percentile, or Global).
- Output: A pair of scalar bounds $(v_{min}, v_{max})$ used for normalization.

**Data Structures:**
- Histogram $H$: An array of bin counts used for percentile calculation. The bin width and count are implementation-specific details not provided in the source [G].

**Steps:**
1. **Select Method:** Determine which of the three methods applies based on user configuration or data characteristics.
2. **Manual Method:** If selected, assign $v_{min}$ and $v_{max}$ to user-defined constants. This ensures consistent coloring across multiple file types displayed simultaneously [S1, unofficial].
3. **Percentile Method:** If selected (default 1st and 99th percentiles):
   a. Scan the entire dataset $V$ to compute a histogram $H$.
   b. Calculate the cumulative distribution from $H$.
   c. Identify the scalar values corresponding to the specified lower and upper percentile levels (default 1% and 99%) [S1, unofficial].
   d. Set $v_{min}$ and $v_{max}$ to these values. This handles data outliers effectively [S1, unofficial].
4. **Global Method:** If selected, scan $V$ to find the absolute minimum and maximum values.
   a. $v_{min} = \min(V)$
   b. $v_{max} = \max(V)$
5. **Edge Cases:** If $v_{min} = v_{max}$, the denominator in color indexing becomes zero. The source does not specify a guard for this division-by-zero case [G].

**Pseudocode:**
```python
def determine_data_bounds(data, method="percentile", user_min=None, user_max=None, lower_pct=1, upper_pct=99):
    """
    Determines scalar bounds for volume rendering.
    
    Args:
        data: Array of scalar values.
        method: 'manual', 'percentile', or 'global'.
        user_min, user_max: Required if method is 'manual'.
        lower_pct, upper_pct: Percentiles for 'percentile' method.
        
    Returns:
        (v_min, v_max)
    """
    if method == "manual":
        if user_min is None or user_max is None:
            raise ValueError("User bounds required for manual method")
        return user_min, user_max
        
    elif method == "percentile":
        # Compute histogram from data
        histogram = compute_histogram(data)
        
        # Find values at specified percentiles
        # Note: Exact histogram binning and interpolation logic is not provided in source [G]
        v_min = get_percentile_value(histogram, lower_pct)
        v_max = get_percentile_value(histogram, upper_pct)
        
        return v_min, v_max
        
    elif method == "global":
        v_min = min(data)
        v_max = max(data)
        return v_min, v_max
        
    else:
        raise ValueError(f"Unknown method: {method}")
```

**Color Indexing Formula:**
The determined bounds are used to map scalar values $v$ to color indices $i$ in a 256-entry table:
$$
i = \begin{cases} 
0 & v < v_{min} \\
1 + 253 \frac{v - v_{min}}{v_{max} - v_{min}} & v_{min} \leq v \leq v_{max} \\
255 & v > v_{max}
\end{cases}
$$

## Operating characteristics
- **Time Complexity:** $O(N)$ for both Percentile (histogram scan) and Global (min/max scan) methods, where $N$ is the number of data points. Manual is $O(1)$.
- **Memory Complexity:** $O(N)$ to store the data; $O(B)$ for the histogram where $B$ is the number of bins.
- **Strengths:** Percentile method effectively mitigates the impact of outliers on color mapping. Manual method ensures visual consistency across heterogeneous datasets.
- **Limitations:** Global method is sensitive to outliers. The source does not specify performance on parallel/distributed AMR data, though the parent article mentions MPI aggregation [S1, unofficial].
- **When to use:** Use Percentile for general visualization with potential outliers. Use Manual for comparative analysis across multiple file types. Use Global for complete data representation.

## Background
This method is implemented in Smokeview, a tool for visualizing Fire Dynamics Simulation (FDS) data [S1, unofficial]. It was documented in the Smokeview Version 6 Technical Reference Guide [S1, unofficial]. The use of 1D texture maps in subsequent visualization steps allows for detailed color interpolation between grid points [S1, unofficial].
