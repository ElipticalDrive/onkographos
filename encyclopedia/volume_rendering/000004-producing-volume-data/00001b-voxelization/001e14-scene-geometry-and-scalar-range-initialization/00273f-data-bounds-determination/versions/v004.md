# Data Bounds Determination

Also called: Bounds Computation, Scalar Range Initialization

## Overview
Data Bounds Determination is a preprocessing procedure that establishes the minimum and maximum scalar values ($v_{min}, v_{max}$) for a volume dataset to enable consistent color mapping [S1, unofficial]. It solves the problem of outlier sensitivity and cross-file consistency in volume rendering by selecting a scalar range from three available strategies: manual user specification, percentile-based filtering, or global extremum selection [S1, unofficial].

## How it works
**Inputs and Outputs:**
- Input: A scalar field dataset $V$ containing $N$ values; a configuration specifying the chosen method (Manual, Percentile, or Global) [S1, unofficial].
- Output: A pair of scalar bounds $(v_{min}, v_{max})$ used for normalization [S1, unofficial].

**Data Structures:**
- Histogram $H$: An array of bin counts used for percentile calculation. The bin width, count, and interpolation logic are implementation-specific details not provided in the source [G].

**Steps:**
1. **Select Method:** Determine which of the three methods applies based on user configuration [S1, unofficial].
2. **Manual Method:** Assign $v_{min}$ and $v_{max}$ to user-defined constants to ensure consistent coloring when several file types are displayed simultaneously [S1, unofficial].
3. **Percentile Method:** Use percentile bounds (default 1st and 99th) to handle data outliers [S1, unofficial].
   a. Scan the entire dataset $V$ to compute a histogram $H$ [S1, unofficial].
   b. Pick data bounds at the specified percentile levels from $H$ [S1, unofficial].
   c. Set $v_{min}$ and $v_{max}$ to these values [S1, unofficial].
4. **Global Method:** Select the global bounds for the entire dataset by finding the absolute minimum and maximum values [S1, unofficial].
5. **Edge Cases:** If $v_{min} = v_{max}$, the denominator in the color indexing formula becomes zero. The source does not specify a guard for this division-by-zero case [G].

**Pseudocode:**
```python
def determine_data_bounds(data, method="percentile", user_min=None, user_max=None, lower_pct=1, upper_pct=99):
    """
    Determines scalar bounds for volume rendering.
    
    Args:
        data: Array of scalar values.
        method: 'manual', 'percentile', or 'global'.
        user_min, user_max: Required if method is 'manual'.
        lower_pct, upper_pct: Percentiles for 'percentile' method.
        
    Returns:
        (v_min, v_max)
    """
    if method == "manual":
        if user_min is None or user_max is None:
            raise ValueError("User bounds required for manual method")
        return user_min, user_max
        
    elif method == "percentile":
        # Source does not specify histogram binning or interpolation logic [G]
        def compute_histogram(arr, bins=256):
            mn, mx = min(arr), max(arr)
            if mn == mx: return [len(arr)] * bins, mn, mx
            step = (mx - mn) / bins
            hist = [0] * bins
            for v in arr:
                idx = int((v - mn) / step)
                if idx == bins: idx -= 1
                hist[idx] += 1
            return hist, mn, mx
            
        def get_percentile_value(hist, mn, mx, pct):
            total = sum(hist)
            target = total * pct / 100.0
            cum = 0
            step = (mx - mn) / len(hist)
            for i, count in enumerate(hist):
                cum += count
                if cum >= target:
                    return mn + i * step
            return mx
            
        hist, mn, mx = compute_histogram(data)
        v_min = get_percentile_value(hist, mn, mx, lower_pct)
        v_max = get_percentile_value(hist, mn, mx, upper_pct)
        return v_min, v_max
        
    elif method == "global":
        v_min = min(data)
        v_max = max(data)
        return v_min, v_max
        
    else:
        raise ValueError(f"Unknown method: {method}")
```

**Color Indexing Formula:**
The determined bounds are used to map scalar values $v$ to color indices $i$ in a 256-entry table:
$$
i = \begin{cases} 
0 & v < v_{min} \\
1 + 253 \frac{v - v_{min}}{v_{max} - v_{min}} & v_{min} \leq v \leq v_{max} \\
255 & v > v_{max}
\end{cases}
$$

## Subtopics

### [Scalar Range Calculation](11487-scalar-range-calculation.md)
Computes global min/max for normalization. It differs from [Local Density Bounds via Sliding Window](12750-local-density-bounds-via-sliding-window.md) by computing a static global range rather than local adaptive bounds. Choose when a simple extremum is sufficient.

### [Local Density Bounds via Sliding Window](12750-local-density-bounds-via-sliding-window.md)
Computes local density bounds. It differs from [Scalar Range Calculation](11487-scalar-range-calculation.md) by providing spatially varying bounds. Choose when spatially varying contrast is needed.

### Global Min-Max Computation
Computes the minimum and maximum values in a volume dataset by iterating through all data elements [S2, unofficial]. Initialize min to Infinity and max to -Infinity, then iterate through all data elements; if a value is not NaN, update min and max with Math.min and Math.max respectively [S2, unofficial]. Store the results and return them [S2, unofficial]. Pitfall: NaN values in the data are skipped during computation [S2, unofficial].

## Operating characteristics
- **Time Complexity:** $O(N)$ for Percentile and Global methods, where $N$ is the number of data points [S1, unofficial]. Manual is $O(1)$ [G].
- **Memory Complexity:** $O(N)$ to store the data; $O(B)$ for the histogram where $B$ is the number of bins [G].
- **Strengths:** Percentile method effectively mitigates the impact of outliers on color mapping [S1, unofficial]. Manual method ensures visual consistency across heterogeneous datasets [S1, unofficial].
- **Limitations:** Global method is sensitive to outliers [S1, unofficial].
- **When to use:** Use Percentile for general visualization with potential outliers, Manual for comparative analysis across multiple file types, and Global for complete data representation [S1, unofficial].

## Background
This method is implemented in Smokeview, a tool for visualizing Fire Dynamics Simulation (FDS) data [S1, unofficial]. It was documented in the Smokeview Version 6 Technical Reference Guide [S1, unofficial]. The use of 1D texture maps in subsequent visualization steps allows for detailed color interpolation between grid points [S1, unofficial].
