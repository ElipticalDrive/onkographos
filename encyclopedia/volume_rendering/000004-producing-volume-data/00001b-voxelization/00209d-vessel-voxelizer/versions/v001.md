# Vessel Voxelizer
Also called: GPU accelerated (fuzzy) voxelization of vascular structures, Vessel Voxelization

## Overview
Vessel Voxelizer is a CUDA-accelerated method that converts vascular structures, defined as line segments with associated radii, into a 3D "fuzzy" voxel volume where each voxel's value represents the fraction of its volume occupied by the vessels [S1, unofficial]. It differs from binary voxelization methods by outputting continuous occupancy values via supersampling, and from general mesh voxelization by operating directly on parametric tube primitives (line segments) rather than polygonal surfaces [S1, unofficial].

## How it works
**Inputs:**
*   `vessel_positions`: Array of shape $(N, 2, 3)$ containing the start and end 3D coordinates for $N$ vessel segments.
*   `vessel_radii`: Array of shape $(N,)$ containing the radius $r^i$ for each vessel segment $i$.
*   `volume_shape`: Array of integers defining the dimensions $(n_x, n_y, n_z)$ of the output voxel grid.
*   `volume_origin`: Array of floats $(x_0, y_0, z_0)$ defining the world coordinates of the voxel at index $(0,0,0)$.
*   `volume_spacing`: Float or array of size 3 defining the side length of each voxel.

**Outputs:**
*   `volume`: A 3D array of shape `volume_shape` with `float32` values in the range $[0.0, 1.0]$, representing the fractional occupancy of each voxel by the vessels.

**Data Structures:**
*   `vessel_bbox`: Precomputed bounding boxes for each vessel. For vessel $i$, this is an array of shape $(N, 2, 3)$ where `vessel_bbox[i, 0, :]` is the minimum corner and `vessel_bbox[i, 1, :]` is the maximum corner of the bounding box enclosing the cylinder segment $i$ expanded by its radius.
*   `internal_point`: A temporary array of size $K^3$ used within the CUDA kernel to count supersampled points inside the vessel radius for the current voxel.

**Parameters:**
*   $K$: The supersampling resolution per voxel dimension. The total number of sample points per voxel is $K^3$. The source implementation hardcodes $K=10$, resulting in 1000 points per voxel [S1, unofficial].
*   Thread Block Dimensions: Fixed at $8 \times 8 \times 8$ threads per block in the reference implementation [S1, unofficial].

**Algorithm Steps:**

1.  **Preprocessing (CPU):**
    Compute the bounding box for each vessel segment. Sort the start and end positions along each axis and expand by the radius:
    ```python
    # vessel_positions shape: (N, 2, 3)
    # vessel_radii shape: (N,)
    sorted_pos = np.sort(vessel_positions, axis=1) # Sorts start/end points per vessel
    vessel_bbox = sorted_pos + np.hstack((
        -vessel_radii.reshape(-1, 1, 1),
        vessel_radii.reshape(-1, 1, 1)
    ))
    ```
    The resulting `vessel_bbox` has shape $(N, 2, 3)$.

2.  **Kernel Launch:**
    Launch a CUDA kernel where each thread corresponds to a single voxel $(x, y, z)$ in the output volume.

3.  **Voxel Boundary Calculation:**
    Each thread computes the world coordinates of its voxel's minimum and maximum corners:
    $$
    \text{voxel\_min}[d] = \text{volume\_origin}[d] + x_d \cdot \text{volume\_spacing}[d]
    $$
    $$
    \text{voxel\_max}[d] = \text{voxel\_min}[d] + \text{volume\_spacing}[d]
    $$
    where $d \in \{0, 1, 2\}$ corresponds to axes $x, y, z$.

4.  **Bounding Box Culling:**
    Iterate over all $N$ vessels. For each vessel $i$, check if the voxel's bounding box intersects the vessel's precomputed bounding box. The vessel bounding box is stored in a flattened array with stride $2 \times 3$. The intersection check for axis $d$ is:
    $$
    (\text{voxel\_max}[d] \ge \text{vessel\_bbox}[i, 0, d]) \land (\text{voxel\_min}[d] \le \text{vessel\_bbox}[i, 1, d])
    $$
    If the voxel does not intersect the bounding box for any axis, skip vessel $i$ and continue to the next vessel. This optimization avoids expensive distance calculations for voxels far from the vessel [S1, unofficial].

5.  **Internal Sampling:**
    Initialize `internal_point` array of size $K^3$ to zeros. Iterate through indices $i_x, i_y, i_z$ from $0$ to $K-1$. Calculate the 3D coordinates of the supersampled point within the voxel:
    $$
    \text{check\_point}[d] = \text{voxel\_min}[d] + \left( \frac{1}{2K} + \frac{i_d}{K} \right) \cdot \text{volume\_spacing}[d]
    $$
    This places points in the center of $K$ sub-cells along each axis, effectively creating a uniform grid of $K^3$ points inside the voxel [S1, unofficial].

6.  **Distance Calculation:**
    For each vessel $i$ that passed the bounding box test, compute the squared Euclidean distance from `check_point` to the vessel line segment. The segment is defined by start point $p_0^i$ and end point $p_1^i$.
    
    Calculate the direction vector $v = p_1^i - p_0^i$.
    Calculate the vector from the segment start to the point $w = \text{check\_point} - p_0^i$.
    Compute the projection parameter $t$:
    $$
    t = \text{clamp}\left( \frac{w \cdot v}{v \cdot v}, 0.0, 1.0 \right)
    $$
    Calculate the closest point on the segment $p_{proj} = p_0^i + t \cdot v$.
    The squared distance is:
    $$
    \text{dist\_squared} = \| \text{check\_point} - p_{proj} \|^2
    $$

7.  **Inside Test:**
    If $\text{dist\_squared} \le (r^i)^2$, set the corresponding entry in `internal_point` to 1. Otherwise, it remains 0. Note: The source implementation sums intersections across all vessels. If multiple vessels overlap within the same sample point, the point is counted multiple times, potentially resulting in voxel values $> 1.0$ if not clamped, though the description implies mapping 0 points to 0.0 and all points to 1.0. The code sums `internal_point` values. If a point is inside multiple vessels, it increments the count. The final value is `intersections / (K*K*K)`.

8.  **Volume Update:**
    Sum all values in `internal_point` to get `intersections`. Set the voxel value:
    $$
    \text{volume}[x, y, z] = \frac{\text{intersections}}{K^3}
    $$
    This represents the fraction of supersampled points that fell within at least one vessel's radius.

**Pseudocode:**

```python
import numpy as np

def vessel_voxelizer(vessel_positions, vessel_radii, volume_shape, volume_origin, volume_spacing, K=10):
    """
    CPU-side preparation and simulation of the Vessel Voxelizer logic.
    Note: The actual method is GPU-accelerated. This pseudocode outlines the logic
    for a single voxel to demonstrate the algorithm.
    """
    # 1. Preprocessing: Compute Bounding Boxes
    # Sort start/end points for each vessel
    sorted_pos = np.sort(vessel_positions, axis=1) # Shape (N, 2, 3)
    # Expand by radius
    # vessel_radii shape (N,) -> reshape to (N, 1, 1)
    neg_r = -vessel_radii.reshape(-1, 1, 1)
    pos_r = vessel_radii.reshape(-1, 1, 1)
    vessel_bbox = sorted_pos + np.hstack((neg_r, pos_r)) # Shape (N, 2, 3)
    
    # 2. Initialize Output Volume
    volume = np.zeros(volume_shape, dtype=np.float32)
    
    # 3. Iterate Voxels (Simulated for one voxel (x,y,z))
    # In reality, this loop is parallelized across CUDA threads
    for x in range(volume_shape[0]):
        for y in range(volume_shape[1]):
            for z in range(volume_shape[2]):
                
                # Calculate voxel boundaries
                spacing = np.array(volume_spacing) if isinstance(volume_spacing, (int, float)) else volume_spacing
                voxel_min = volume_origin + np.array([x, y, z]) * spacing
                voxel_max = voxel_min + spacing
                
                # Initialize sample counter
                intersections = 0
                total_samples = K * K * K
                
                # 4. Supersampling Grid
                # Generate K^3 points
                # Using meshgrid for clarity, though kernel uses linear indices
                ix, iy, iz = np.meshgrid(np.arange(K), np.arange(K), np.arange(K), indexing='ij')
                
                # Calculate check points
                # check_point[d] = voxel_min[d] + (1/(2K) + i_d/K) * spacing[d]
                check_points = np.zeros((K, K, K, 3))
                for d in range(3):
                    check_points[:, :, :, d] = voxel_min[d] + (1.0/(2*K) + ix/d if d==0 else iy/d if d==1 else iz/d) * spacing[d] # Simplified logic for pseudocode
                    
                # Correct calculation for check_points:
                # ix, iy, iz are indices 0..K-1
                # offset = (1/(2K) + index/K) * spacing
                offsets = (1.0/(2*K) + np.arange(K)/K) * spacing # Shape (3, K) if transposed correctly
                # Let's do it explicitly per axis
                x_offsets = (1.0/(2*K) + ix.flatten()/K) * spacing[0]
                y_offsets = (1.0/(2*K) + iy.flatten()/K) * spacing[1]
                z_offsets = (1.0/(2*K) + iz.flatten()/K) * spacing[2]
                
                # Flatten indices for iteration
                n_samples = K**3
                sample_points = np.zeros((n_samples, 3))
                for s in range(n_samples):
                    sample_points[s, 0] = voxel_min[0] + x_offsets[s]
                    sample_points[s, 1] = voxel_min[1] + y_offsets[s]
                    sample_points[s, 2] = voxel_min[2] + z_offsets[s]

                # 5. Check against Vessels
                for i in range(len(vessel_positions)):
                    # Bounding Box Culling
                    v_min = vessel_bbox[i, 0]
                    v_max = vessel_bbox[i, 1]
                    
                    if not (voxel_max[0] >= v_min[0] and voxel_min[0] <= v_max[0] and
                            voxel_max[1] >= v_min[1] and voxel_min[1] <= v_max[1] and
                            voxel_max[2] >= v_min[2] and voxel_min[2] <= v_max[2]):
                        continue
                    
                    # Distance Calculation
                    p0 = vessel_positions[i, 0]
                    p1 = vessel_positions[i, 1]
                    r = vessel_radii[i]
                    
                    v = p1 - p0
                    v_dot_v = np.dot(v, v)
                    
                    # Avoid division by zero for degenerate segments
                    if v_dot_v == 0:
                        continue
                        
                    # Vector from p0 to sample point
                    # Vectorized over all sample points
                    p_to_p0 = sample_points - p0 # Shape (n_samples, 3)
                    
                    # Projection parameter t
                    t = np.dot(p_to_p0, v) / v_dot_v
                    t = np.clip(t, 0.0, 1.0)
                    
                    # Closest point on segment
                    # p_proj = p0 + t * v
                    # Since t is scalar per point, we broadcast
                    p_proj = p0 + t[:, np.newaxis] * v # Shape (n_samples, 3)
                    
                    # Squared distance
                    diff = sample_points - p_proj
                    dist_sq = np.sum(diff**2, axis=1)
                    
                    # Inside test
                    inside = dist_sq <= (r * r)
                    intersections += np.sum(inside)
                
                # 6. Volume Update
                volume[x, y, z] = intersections / total_samples
                
    return volume
```

**Edge Cases and Pitfalls:**
*   **Hardcoded K:** The number of sample points $K$ is hardcoded to 10 in the source code. The TODO list indicates a need to make this adaptable [S1, unofficial].
*   **Degenerate Segments:** If a vessel segment has zero length ($p_0 = p_1$), the dot product $v \cdot v$ is zero. The source code does not explicitly show a guard for this in the kernel, which could lead to division by zero. [G] A robust implementation should check `v_dot_v > epsilon` before computing $t$.
*   **Overlap:** If vessels overlap, a single sample point may be counted multiple times. The final value is the sum of intersections divided by $K^3$. If the sum exceeds $K^3$, the value exceeds 1.0. The source description says "Map 0 points to 0.0 and all points to 1.0", but the code simply divides by $K^3$. [S1, unofficial]

## Operating characteristics
*   **Time Complexity:** $O(V \cdot N_{voxels} \cdot K^3)$ in the worst case where all vessels intersect all voxels, where $V$ is the number of vessels and $K$ is the sampling resolution (10) [S1, unofficial]. The bounding box check provides an early exit optimization, reducing the constant factor significantly for sparse scenes.
*   **Memory Complexity:** $O(N_{voxels} + N_{vessels})$. The output volume dominates memory usage. The GPU kernel uses minimal shared/local memory per thread ($K^3$ is computed locally or via registers).
*   **Performance:** The method is GPU-accelerated using CUDA. The reference implementation uses `nanobind` for Python bindings. Performance scales with the number of voxels and vessels. The fixed thread block size of $8 \times 8 \times 8$ is used [S1, unofficial].
*   **Strengths:** Fast conversion of tubular structures; handles fuzzy/continuous occupancy; GPU parallelization.
*   **Limitations:** Fixed sampling resolution ($K=10$); potential for values $>1.0$ if vessels overlap heavily; requires precomputed bounding boxes.

## Background
The Vessel Voxelizer is an open-source project hosted on GitHub by faberno [S1, unofficial]. It is designed for the voxelization of vascular structures, commonly used in medical imaging and visualization.
