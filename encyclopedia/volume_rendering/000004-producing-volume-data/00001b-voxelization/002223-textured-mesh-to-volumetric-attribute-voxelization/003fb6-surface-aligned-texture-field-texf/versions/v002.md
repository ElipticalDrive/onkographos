# Surface-aligned Texture Field (TexF)


## Overview
Surface-aligned Texture Field (TexF) is a UV-free volumetric representation that associates texture attributes with voxels derived from a mesh surface, preserving spatial locality without UV parameterization [S1, unofficial]. It solves the problem of transferring and storing 2D texture maps on 3D geometry by embedding attributes directly in a 3D field, allowing direct queries at mesh surface positions during rendering [S1, unofficial]. Unlike UV-based pipelines that rely on chart-based unfolding and UV coordinates, TexF operates in a shared 3D coordinate system, enabling direct spatial queries and facilitating compression via 3D attribute codecs [S1, unofficial].

## How it works
**Inputs:** A textured mesh $M$ (geometry and source UV texture maps); a grid resolution parameter $K$.
**Outputs:** A sparse set of active voxels $Q$ with associated texture attributes $t(q)$; a differentiable renderer for refinement.

**Data Structures:**
*   **Grid:** A canonical axis-aligned bounding box (AABB) of the mesh discretized into a $K \times K \times K$ grid.
*   **Active Voxels ($Q$):** A sparse set of voxel indices intersecting the mesh surface. The dense $K^3$ grid is not allocated; only active voxels are stored.
*   **Attributes ($t(q)$):** For each voxel $q \in Q$, a vector of attributes (default: RGB base color; extensible to PBR attributes like roughness/metallicity).

**Construction Steps:**
1.  **Grid Discretization:** Compute the canonical AABB of mesh $M$. Define a grid resolution $K$. The TexF and mesh geometry share this common coordinate system [S1, unofficial].
2.  **Surface Sampling:** Sample points on the mesh surface. For each sample, compute its 3D position $\mathbf{p}$ and barycentric coordinates [S1, unofficial].
3.  **UV Coordinate Mapping:** Use the barycentric coordinates to determine the corresponding UV coordinate $\mathbf{u}$ on the source texture maps [S1, unofficial].
4.  **Attribute Retrieval:** Sample the source material maps at $\mathbf{u}$ to retrieve the texture attribute vector $\mathbf{t}_{src}$ [S1, unofficial].
5.  **Voxel Assignment:** Map the 3D position $\mathbf{p}$ to the corresponding voxel index $q$ in the $K \times K \times K$ grid.
6.  **Attribute Aggregation:** If multiple surface samples map to the same voxel $q$, average their retrieved attributes $\mathbf{t}_{src}$ to determine the final attribute $t(q)$ for that voxel [S1, unofficial].
7.  **Sparse Support Formation:** The set of voxels $Q$ containing assigned attributes forms the sparse support. Voxels not intersecting the surface or receiving no samples are excluded [S1, unofficial].

**Refinement (Inverse Rendering):**
Voxel discretization and interpolation during UV transfer introduce errors [S1, unofficial]. These are reduced using a differentiable renderer:
1.  **Rasterization:** Rasterize the mesh to determine visible surface positions for each camera view [S1, unofficial].
2.  **TexF Query:** For each visible surface position, query the TexF $T$ using trilinear interpolation to obtain the texture attribute $\hat{t}(\mathbf{q})$ [S1, unofficial].
3.  **Rendering:** Render the image using the queried attributes [S1, unofficial].
4.  **Optimization:** Use multi-view image-space supervision to refine the voxel attributes $t(q)$ (and potentially compressed neural fields) via inverse rendering (IR) [S1, unofficial].

**Pseudocode:**

def construct_texf(mesh, texture_maps, K):
    """
    Construct a Surface-aligned Texture Field from a textured mesh.
    
    Args:
        mesh: Object with geometry (vertices, faces) and UV coordinates.
        texture_maps: Dictionary of source texture maps (e.g., 'diffuse', 'roughness').
        K: Resolution of the canonical AABB grid.
        
    Returns:
        active_voxels: List of active voxel indices.
        attributes: Dictionary mapping voxel index to attribute vector.
    """
    # 1. Compute canonical AABB and grid parameters
    bbox_min, bbox_max = mesh.compute_aabb()
    grid_size = K
    voxel_size = (bbox_max - bbox_min) / grid_size
    
    # Dictionary to accumulate attributes for each voxel
    # Key: (x, y, z) voxel index, Value: list of attribute vectors
    voxel_accumulators = {}
    
    # 2. Sample mesh surface
    # Note: Implementation of surface sampling is not specified in sources [G]
    # Typically involves stratified sampling or uniform sampling on faces
    surface_samples = mesh.sample_surface(num_samples=10000) 
    
    for sample in surface_samples:
        # sample.position: 3D point on mesh
        # sample.barycentric: (u, v, w) barycentric coordinates
        # sample.face_id: index of the triangle
        
        # 3. Determine UV coordinate from barycentric coordinates
        # Assuming mesh stores UVs per vertex
        v0, v1, v2 = mesh.get_face_vertices(sample.face_id)
        uv0, uv1, uv2 = mesh.get_face_uvs(sample.face_id)
        
        u_coord = sample.barycentric[0] * uv0[0] + sample.barycentric[1] * uv1[0] + sample.barycentric[2] * uv2[0]
        v_coord = sample.barycentric[0] * uv0[1] + sample.barycentric[1] * uv1[1] + sample.barycentric[2] * uv2[1]
        
        # 4. Sample texture maps
        # Note: texture_maps is assumed to be a function or object supporting sampling
        # Default attribute is RGB base color
        attr = texture_maps.sample(u_coord, v_coord)
        
        # 5. Map 3D position to voxel index
        # Clamp position to bbox to handle boundary cases
        pos = sample.position
        pos_clamped = clamp(pos, bbox_min, bbox_max)
        
        # Calculate voxel index
        x = int((pos_clamped[0] - bbox_min[0]) / voxel_size[0])
        y = int((pos_clamped[1] - bbox_min[1]) / voxel_size[1])
        z = int((pos_clamped[2] - bbox_min[2]) / voxel_size[2])
        
        voxel_idx = (x, y, z)
        
        # 6. Accumulate attributes
        if voxel_idx not in voxel_accumulators:
            voxel_accumulators[voxel_idx] = []
        voxel_accumulators[voxel_idx].append(attr)
        
    # 7. Average attributes and form sparse support
    active_voxels = []
    attributes = {}
    
    for voxel_idx, attr_list in voxel_accumulators.items():
        # Average attributes assigned to the same voxel
        avg_attr = sum(attr_list) / len(attr_list)
        active_voxels.append(voxel_idx)
        attributes[voxel_idx] = avg_attr
        
    return active_voxels, attributes

    """

    # 3. Get voxel indices for trilinear interpolation
    x0 = floor(frac_pos[0])
    y0 = floor(frac_pos[1])
    z0 = floor(frac_pos[2])
    
    x1 = x0 + 1
    y1 = y0 + 1

## Subtopics

### [Bitstream-oriented TexF Compression](10086-bitstream-oriented-texf-compression.md)
Compresses TexF attributes using 3D point cloud attribute codecs (Unicorn, G-PCC), treating attributes as a point cloud dataset without transmitting voxel coordinates.

### [Differentiable TexF Rendering](10095-differentiable-texf-rendering.md)
Renders TexF by querying the 3D field at rasterized surface positions using trilinear interpolation, enabling inverse-rendering refinement.

## Operating characteristics
*   **Time Complexity:** Construction is linear in the number of surface samples. Querying is $O(1)$ with a hash map or $O(\log N)$ with a tree structure for sparse voxels. Refinement requires iterative optimization.
*   **Memory Complexity:** Proportional to the number of active voxels $|Q|$, which is typically much less than $K^3$.
*   **Performance:** Experiments on MPEG and AOM benchmarks show improved average rate-distortion performance over UV-based methods for both bitstream and GPU-resident compression [S1, unofficial]. 3DNTC supports real-time rendering [S1, unofficial].
*   **Strengths:** No UV parameterization overhead; direct 3D queries; compatible with 3D attribute codecs; supports inverse rendering.
*   **Limitations:** Voxel discretization and interpolation introduce transfer errors, requiring refinement [S1, unofficial]. Resolution $K$ must be chosen carefully to balance detail and memory.
*   **When to use:** When UV mapping is difficult or undesirable; when 3D spatial correlations are beneficial for compression; when inverse rendering is needed.
*   **When not to use:** When UV-based pipelines are strictly required for compatibility; when memory is extremely constrained and $K$ must be very small.

## Background
TexF was introduced in "Beyond UV Mapping: Mesh Texture Compression via Surface-Aligned Texture Fields" [S1, unofficial]. It addresses the limitations of UV-based texture representations, which require chart-based unfolding and UV coordinates. By embedding texture attributes in a surface-aligned 3D field, TexF enables direct queries and leverages 3D spatial correlations for compression. The method supports both bitstream compression using established 3D attribute codecs and GPU-resident compression using a neural codec (3DNTC) [S1, unofficial].
