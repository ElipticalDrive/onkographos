# Surface-aligned Texture Field (TexF)
Also called: TexF (Surface-Aligned Texture Field)
## Overview
Surface-aligned Texture Field (TexF) associates texture attributes with voxels derived from a mesh surface, preserving spatial locality without UV parameterization [S1, unofficial]. It forms a sparse voxel support where surface positions can directly query the 3D field [S1, unofficial]. Unlike UV-based pipelines that use chart-based unfolding and require UV coordinates/indices, TexF embeds texture attributes directly in a surface-aligned 3D field, allowing direct queries at mesh surface positions without intermediate parameterization [S1, unofficial].
## How it works
**Inputs:** A textured mesh $M$ (geometry and source UV texture maps) [S1, unofficial].
**Outputs:** A sparse voxel set $Q$ and a texture field $T$ mapping each active voxel $q \in Q$ to an attribute vector $t(q)$ [S1, unofficial].

**Data Structures:**
1. **Grid:** A canonical axis-aligned bounding box (AABB) of the mesh discretized into a $K \times K \times K$ grid [S1, unofficial].
2. **Active Voxel Set $Q$:** A sparse set of voxels intersecting the mesh surface, constructed without allocating the dense $K^3$ grid [S1, unofficial].
3. **Texture Field $T$:** A map from voxel index $q$ to attribute vector $t(q)$, defaulting to base color (RGB) but extensible to PBR attributes like roughness and metallicity [S1, unofficial].

**Parameters:**
* $K$: Resolution of the canonical AABB grid. Typical values are not specified in the sources [S1, unofficial].

**Construction Steps:**
1. **Grid Discretization:** Compute the canonical AABB of mesh $M$ and discretize it into a $K \times K \times K$ grid [S1, unofficial].
2. **Surface Sampling:** Sample points on the mesh surface. For each sample, determine its 3D position $\mathbf{p}$ and UV coordinate $\mathbf{u}$ via barycentric coordinates [S1, unofficial].
3. **Voxel Identification:** Map the 3D position $\mathbf{p}$ to a voxel index $q$ in the grid. Add $q$ to the active set $Q$ [S1, unofficial].
4. **Attribute Transfer:** Sample the source texture maps at UV coordinate $\mathbf{u}$ to retrieve an attribute vector $\mathbf{a}$ [S1, unofficial]. Assign $\mathbf{a}$ to voxel $q$ [S1, unofficial]. If multiple samples map to the same voxel, average their retrieved attributes to determine $t(q)$ [S1, unofficial].
5. **Refinement:** Use a differentiable renderer with multi-view image-space supervision to refine $T$, reducing transfer and discretization errors introduced by voxelization and interpolation [S1, unofficial].

**Pseudocode:**
```python
def construct_texf(mesh_vertices, mesh_faces, mesh_uvs, texture_maps, K):
    # 1. Compute canonical AABB
    bbox_min = min(mesh_vertices, key=lambda v: v[0]) # Simplified min
    bbox_max = max(mesh_vertices, key=lambda v: v[0]) # Simplified max
    # In practice, compute component-wise min/max across all vertices
    bbox_min = [min(v[i] for v in mesh_vertices) for i in range(3)]
    bbox_max = [max(v[i] for v in mesh_vertices) for i in range(3)]
    bbox_size = [bbox_max[i] - bbox_min[i] for i in range(3)]

    # 2. Initialize sparse structures
    Q = set()
    T_accum = {}  # voxel_index -> list of attribute vectors

    # 3. Surface sampling and attribute transfer
    for i in range(len(mesh_faces)):
        v0, v1, v2 = mesh_faces[i]
        u0, u1, u2 = mesh_uvs[i]
        # Sample a point on the triangle (centroid)
        p_3d = [(mesh_vertices[v0][j] + mesh_vertices[v1][j] + mesh_vertices[v2][j]) / 3.0 for j in range(3)]
        u_uv = [(u0[j] + u1[j] + u2[j]) / 3.0 for j in range(2)]

        # Map 3D position to voxel index
        p_norm = [(p_3d[j] - bbox_min[j]) / bbox_size[j] for j in range(3)]
        # Clamp to [0, 1] to handle boundary cases [G]
        p_norm = [max(0.0, min(1.0, p_norm[j])) for j in range(3)]
        q_idx = tuple(int(p_norm[j] * K) for j in range(3))

        # Sample texture
        attr = texture_maps['baseColor'].sample(u_uv[0], u_uv[1])

        # Accumulate
        if q_idx not in T_accum:
            T_accum[q_idx] = []
        T_accum[q_idx].append(attr)
        Q.add(q_idx)

    # 4. Average attributes
    T = {}
    for q_idx, attrs in T_accum.items():
        T[q_idx] = [sum(a[j] for a in attrs) / len(attrs) for j in range(len(attrs[0]))]

    # 5. Refinement step: Use differentiable renderer with multi-view image-space supervision to optimize T [S1, unofficial].
    return Q, T
```

**Edge Cases and Pitfalls:**
* **Transfer Errors:** Voxel discretization and interpolation introduce transfer errors during UV texture transfer [S1, unofficial]. These are reduced through rendering-driven refinement [S1, unofficial].
* **Boundary Conditions:** Points on the mesh surface must be correctly mapped to voxels. Clamping normalized coordinates to $[0, 1]$ is necessary to avoid out-of-bounds voxel indices [G].
* **Attribute Averaging:** If multiple samples map to the same voxel, averaging is used. This may blur high-frequency details if the voxel size $K$ is too small relative to texture features [G].
## Subtopics

### [Bitstream-oriented TexF Compression](10086-bitstream-oriented-texf-compression.md)
Compresses TexF attributes using 3D attribute codecs (Unicorn, G-PCC) by treating them as a point cloud, relying on known mesh geometry for voxel reconstruction.

### [Differentiable TexF Rendering](10095-differentiable-texf-rendering.md)
The rendering and refinement stage that queries the 3D field directly at rasterized surface positions using trilinear interpolation, enabling inverse-rendering optimization.

## Operating characteristics
* **Time Complexity:** Construction scales linearly with the number of surface samples and active voxels [S1, unofficial]. Refinement is iterative and uses differentiable rendering with multi-view image-space supervision [S1, unofficial].
* **Memory Complexity:** Sparse storage of active voxels $Q$ and attributes $T$, avoiding allocation of the dense $K^3$ grid [S1, unofficial].
* **Performance:** Experiments on MPEG and AOM mesh compression benchmarks demonstrate improved average rate–distortion performance over representative UV-based methods for both bitstream and GPU-resident compression [S1, unofficial]. GPU-resident compression (3DNTC) supports real-time rendering [S1, unofficial].
* **Strengths:** Eliminates UV parameterization overhead; enables direct 3D surface queries; supports both bitstream and GPU-resident compression; preserves spatial locality [S1, unofficial].
* **Limitations:** Requires refinement to mitigate discretization errors; resolution $K$ must be chosen to balance detail and memory [S1, unofficial].
## Background
TexF was introduced in "Beyond UV Mapping: Mesh Texture Compression via Surface-Aligned Texture Fields" [S1, unofficial]. It addresses the limitations of UV-based texture representations by embedding texture attributes directly in a surface-aligned 3D field, enabling efficient compression and rendering without UV maps [S1, unofficial].
