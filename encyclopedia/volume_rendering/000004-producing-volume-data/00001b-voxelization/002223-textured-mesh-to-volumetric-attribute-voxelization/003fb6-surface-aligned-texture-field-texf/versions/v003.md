# Surface-aligned Texture Field (TexF)


## Overview
Surface-aligned Texture Field (TexF) is a UV-free volumetric representation that associates texture attributes with voxels derived from a mesh surface, preserving spatial locality without UV parameterization [S1, unofficial]. It solves the problem of transferring 2D texture data to 3D geometry by embedding attributes directly in a surface-aligned 3D field, allowing direct queries at mesh surface positions during rendering [S1, unofficial]. Unlike UV-based pipelines that use chart-based unfolding and require UV coordinates/indices, TexF eliminates intermediate parameterization overhead [S1, unofficial]. It builds on [Textured Mesh to Volumetric Attribute Voxelization](2760-textured-mesh-to-volumetric-attribute-voxelization.md) by specifically targeting surface-aligned sparse voxelization for texture storage and compression.

## How it works
**Inputs:** A textured mesh $M$ (geometry and source UV texture maps).
**Outputs:** A sparse voxel set $Q$ and a texture field $T$ mapping each active voxel $q \in Q$ to an attribute vector $t(q)$.

**Data Structures:**
1.  **Grid:** A canonical axis-aligned bounding box (AABB) of the mesh discretized into a $K \times K \times K$ grid. The TexF and mesh geometry share this common coordinate system [S1, unofficial].
2.  **Active Voxel Set $Q$:** A sparse set of voxels intersecting the mesh surface. The dense $K^3$ grid is not allocated; only active voxels are stored [S1, unofficial].
3.  **Texture Field $T$:** A map from voxel index $q$ to attribute vector $t(q)$. By default, $t(q)$ encodes base color (RGB), but can be extended to PBR attributes (roughness, metallicity) channel-wise [S1, unofficial].

**Parameters:**
*   $K$: Resolution of the canonical AABB grid. Typical values are not specified in the sources [S1, unofficial].

**Construction Steps:**
1.  **Grid Discretization:** Compute the canonical AABB of mesh $M$. Discretize this volume into a $K \times K \times K$ grid [S1, unofficial].
2.  **Surface Sampling:** Sample points on the mesh surface. For each sample, compute its 3D position $\mathbf{p}$ and UV coordinate $\mathbf{u}$ using barycentric coordinates [S1, unofficial].
3.  **Voxel Identification:** Map the 3D position $\mathbf{p}$ to a voxel index $q$ in the $K \times K \times K$ grid. Add $q$ to the active set $Q$ if it intersects the surface [S1, unofficial].
4.  **Attribute Transfer:**
    *   Sample the source texture maps at UV coordinate $\mathbf{u}$ to retrieve an attribute vector $\mathbf{a}$ [S1, unofficial].
    *   Assign $\mathbf{a}$ to voxel $q$.
    *   If multiple surface samples map to the same voxel $q$, average their retrieved attributes $\mathbf{a}$ to determine $t(q)$ [S1, unofficial].
5.  **Refinement (Optional but Recommended):** Use differentiable rendering to refine $T$. Render the mesh using the current TexF, compare against reference multi-view images, and optimize voxel attributes to reduce transfer and discretization errors introduced by voxelization and interpolation [S1, unofficial].

**Pseudocode:**
```python
def construct_texf(mesh, texture_maps, K):
    """
    Construct a Surface-aligned Texture Field from a textured mesh.
    
    Args:
        mesh: Object containing geometry (vertices, faces) and UV coordinates.
        texture_maps: Dictionary of source texture images (e.g., 'baseColor').
        K: Integer resolution of the canonical AABB grid.
        
    Returns:
        Q: Set of active voxel indices.
        T: Dictionary mapping voxel index q to attribute vector t(q).
    """
    # 1. Compute Canonical AABB
    bbox_min, bbox_max = compute_aabb(mesh.vertices)
    
    # 2. Initialize structures
    Q = set()
    T = {} # Map: voxel_index -> list of attributes (for averaging)
    
    # Helper: Map 3D point to voxel index
    def point_to_voxel(p):
        # Normalize p to [0, 1] range relative to bbox
        p_norm = (p - bbox_min) / (bbox_max - bbox_min)
        # Clamp to [0, 1] to handle boundary cases
        p_norm = clamp(p_norm, 0.0, 1.0)
        # Convert to integer grid coordinates
        q = floor(p_norm * K)
        return tuple(q)

    # 3. Surface Sampling and Attribute Transfer
    # Iterate over mesh faces or pre-defined surface samples
    for sample in mesh.surface_samples:
        # Get 3D position and UV from barycentric interpolation
        p_3d = sample.position_3d
        u_uv = sample.uv_coordinate
        
        # Identify voxel
        q_idx = point_to_voxel(p_3d)
        
        # Sample texture
        # Assuming texture_maps['baseColor'] is a function sample(u, v)
        attr = texture_maps['baseColor'].sample(u_uv.u, u_uv.v)
        
        # Accumulate attributes for averaging
        if q_idx not in T:
            T[q_idx] = []
        T[q_idx].append(attr)
        
        # Add to active set
        Q.add(q_idx)
        
    # 4. Average Attributes
    T_final = {}
    for q_idx, attrs in T.items():
        # Average all attributes assigned to this voxel
        avg_attr = sum(attrs) / len(attrs)
        T_final[q_idx] = avg_attr
        
    return Q, T_final

def refine_texf(mesh, T, Q, reference_images, learning_rate=0.01, steps=1000):
    """
    Refine TexF attributes using differentiable rendering.
    
    Args:
        mesh: Mesh geometry.
        T: Current texture field (mutable).
        Q: Active voxels.
        reference_images: Ground truth multi-view images.
        learning_rate: Step size for optimization.
        steps: Number of optimization iterations.
        
    Returns:
        Refined T.
    """
    # Note: This requires a differentiable renderer that supports
    # trilinear interpolation of T at surface positions.
    # The gradient flows from image loss to voxel attributes.
    
    for step in range(steps):
        # Render current TexF
        rendered_images = render_texf(mesh, T, Q)
        
        # Compute loss against reference images
        loss = compute_loss(rendered_images, reference_images)
        
        # Backpropagate to update T
        # In a real implementation, T would be a differentiable tensor
        # or optimized via an optimizer step.
        # Here we assume a generic update mechanism.
        gradients = compute_gradients(loss, T)
        update_T(T, gradients, learning_rate)
        
    return T
```

**Edge Cases and Pitfalls:**
*   **Transfer Errors:** Voxel discretization and interpolation during UV texture transfer introduce errors [S1, unofficial]. These are reduced through rendering-driven refinement [S1, unofficial].
*   **Boundary Conditions:** Points on the mesh surface must be correctly mapped to voxels. Clamping normalized coordinates to $[0, 1]$ is necessary to avoid out-of-bounds voxel indices [G].
*   **Attribute Averaging:** If multiple samples map to the same voxel, averaging is used. This may blur high-frequency details if the voxel size $K$ is too small relative to texture features [G].

## Subtopics

### [Bitstream-oriented TexF Compression](10086-bitstream-oriented-texf-compression.md)
Compresses TexF attributes using 3D attribute codecs (Unicorn, G-PCC) by treating them as a point cloud, relying on known mesh geometry for voxel reconstruction.

### [Differentiable TexF Rendering](10095-differentiable-texf-rendering.md)
The rendering and refinement stage that queries the 3D field directly at rasterized surface positions using trilinear interpolation, enabling inverse-rendering optimization.

## Operating characteristics
*   **Time Complexity:** Construction is dominated by surface sampling and voxelization, which is linear in the number of samples. Refinement is iterative and depends on the number of optimization steps and rendering cost per step [S1, unofficial].
*   **Memory Complexity:** Sparse storage of active voxels $Q$ and attributes $T$. Memory usage is proportional to the number of surface-intersecting voxels, not the full $K^3$ grid [S1, unofficial].
*   **Performance:** Experiments on MPEG and AOM benchmarks show improved average rate-distortion performance over UV-based methods for both bitstream and GPU-resident compression [S1, unofficial]. GPU-resident compression (3DNTC) supports real-time rendering [S1, unofficial].
*   **Strengths:** No UV parameterization overhead; direct 3D queries; supports both bitstream and GPU-resident compression; preserves spatial locality [S1, unofficial].
*   **Limitations:** Requires refinement to mitigate discretization errors; resolution $K$ must be chosen carefully to balance detail and memory [S1, unofficial].

## Background
TexF was introduced in "Beyond UV Mapping: Mesh Texture Compression via Surface-Aligned Texture Fields" [S1, unofficial]. It addresses the limitations of UV-based texture representations, which require complex charting and parameterization. The method leverages surface-aligned voxelization to embed texture attributes directly in 3D space, enabling efficient compression and rendering without UV maps [S1, unofficial].
