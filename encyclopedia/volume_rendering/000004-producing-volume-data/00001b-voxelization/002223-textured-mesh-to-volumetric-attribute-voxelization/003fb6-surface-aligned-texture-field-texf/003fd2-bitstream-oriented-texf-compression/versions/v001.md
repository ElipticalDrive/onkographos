# Bitstream-oriented TexF Compression

Also called: TexF Compression using 3D Attribute Codecs

## Overview
Bitstream-oriented TexF Compression reduces the storage size of Surface-aligned Texture Fields (TexF) by leveraging established 3D attribute codecs to compress texture data without transmitting voxel coordinates. It solves the redundancy problem inherent in sparse voxel grids where spatial positions are either implicit or derived from geometry. Unlike [Differentiable TexF Rendering](10095-differentiable-texf-rendering.md), which focuses on gradient-based optimization, this method is strictly a data compression technique for efficient storage and transmission of TexF assets.

## How it works
The method relies on the shared voxel set $Q$ between the geometry and the attributes. The encoder and decoder independently derive the same voxel set $Q$ from the reconstructed mesh geometry, ensuring that no coordinate data needs to be included in the bitstream.

**Inputs and Outputs:**
*   **Input:** Reconstructed mesh geometry, TexF attributes $t(q)$ for each voxel $q \in Q$.
*   **Output:** Compressed bitstream containing only the encoded attributes.

**Data Structures:**
*   **TexF Definition:** $T = \{(q, t(q)) \mid q \in Q\}$, where $Q$ is the shared voxel set and $t(q)$ represents the texture attributes at voxel $q$ [S1, unofficial].
*   **Voxel Set $Q$:** Implicitly defined by the geometry reconstruction process. No explicit coordinate list is stored in the attribute bitstream.

**Steps:**
1.  **Geometry Reconstruction:** Both encoder and decoder reconstruct the mesh geometry to derive the identical voxel set $Q$. This step ensures spatial alignment without transmitting coordinates [S1, unofficial].
2.  **Attribute Extraction:** Extract the texture attributes $t(q)$ for all voxels $q \in Q$ from the TexF.
3.  **Compression:** Pass the attributes $t(q)$ to an established 3D attribute codec backend (e.g., Unicorn or G-PCC). The codec performs:
    *   Analysis transform.
    *   Entropy coding.
    *   Generation of the compressed bitstream.
    *   Crucially, the codec does not receive or encode voxel coordinates [S1, unofficial].
4.  **Decoding:** The decoder receives the bitstream and uses the same 3D attribute codec backend to perform entropy decoding and reconstruct the attributes $\hat{t}(q)$ for the voxel set $Q$ derived from the decoded geometry [S1, unofficial].

**Parameters:**
*   **Backend Codec:** Established 3D attribute codecs such as Unicorn or G-PCC are used [S1, unofficial].
*   **Typical Values:** Not given in the sources.

**Edge Cases and Pitfalls:**
*   **Geometry Mismatch:** If the encoder and decoder derive different voxel sets $Q$ due to geometry reconstruction errors or different parameters, the attribute decoding will fail or produce misaligned data.
*   **Precision:** The quality of the reconstructed attributes $\hat{t}(q)$ depends on the fidelity of the 3D attribute codec.

**Pseudocode:**
```python
# Encoder
def encode_texf(mesh_geometry, texf_attributes):
    # Derive voxel set Q from geometry (shared logic)
    Q = derive_voxel_set(mesh_geometry)
    
    # Extract attributes for voxels in Q
    # t(q) is the attribute vector for voxel q
    attributes = [texf_attributes[q] for q in Q]
    
    # Compress attributes using 3D attribute codec (e.g., Unicorn/G-PCC)
    # The codec handles analysis transform and entropy coding
    # Coordinates are NOT transmitted
    bitstream = compress_attributes(attributes)
    
    return bitstream

# Decoder
def decode_texf(bitstream, mesh_geometry):
    # Derive voxel set Q from geometry (must match encoder)
    Q = derive_voxel_set(mesh_geometry)
    
    # Decode attributes using 3D attribute codec
    # Reconstructs t_hat(q) for voxels in Q
    reconstructed_attributes = decompress_attributes(bitstream)
    
    # Reconstruct TexF T = {(q, t_hat(q)) | q in Q}
    texf = {q: reconstructed_attributes[i] for i, q in enumerate(Q)}
    
    return texf
```

## Operating characteristics
*   **Time Complexity:** Depends on the complexity of the underlying 3D attribute codec (Unicorn/G-PCC).
*   **Memory Complexity:** Depends on the codec's internal buffers and the size of the compressed bitstream.
*   **Strengths:** Significant reduction in bitstream size by eliminating coordinate transmission; leverages mature, optimized 3D attribute codecs.
*   **Limitations:** Requires identical geometry reconstruction on both ends; compression ratio depends on the attribute codec's performance.
*   **When to use:** When storage or bandwidth for TexF assets is a constraint and geometry is already available or cheap to transmit.
*   **When not to use:** When random access to specific voxels without geometry context is required, or when geometry reconstruction is unreliable.

## Background
This method was introduced in the paper "Beyond UV Mapping: Mesh Texture Compression via Surface-Aligned Texture Fields" [S1, unofficial]. It addresses the need for efficient compression of texture data associated with surface-aligned voxel structures, moving beyond traditional UV-based compression methods.
