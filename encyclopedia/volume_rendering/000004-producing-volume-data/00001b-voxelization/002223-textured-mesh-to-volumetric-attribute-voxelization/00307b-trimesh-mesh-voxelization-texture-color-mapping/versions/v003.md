# Trimesh Mesh Voxelization & Texture Color Mapping

Also called: Proximity-based Texture Mapping to Voxels, Schwarz and Seidel Voxelization, Voxel Density Field Generation from Mesh, Voxelization and Attribute Creation

## Overview
This method converts a polygonal triangle mesh into a 3D volumetric density field by marking voxels whose centers are in close proximity to the mesh surface, while simultaneously mapping vertex texture colors to those voxels [S2, S3, unofficial]. It differs from standard binary voxelization by integrating attribute creation directly during the voxelization process using barycentric projection or proximity queries, avoiding the need for post-hoc interpolation [S1]. Unlike [Surface-aligned Texture Field (TexF)](10067-surface-aligned-texture-field-texf.md) which aligns texture fields to surface normals, this method relies on geometric proximity and barycentric coordinate projection to assign attributes [S1][S3, unofficial].

## How it works
**Inputs:**
- A triangle mesh $M$ with vertices $V = \{v_0, v_1, \dots, v_n\}$ and faces $F$ [S1][S2, S3, unofficial].
- Vertex colors or texture coordinates associated with $V$ [S1][S3, unofficial].
- A target voxel size $s$ (or resolution) [S2, unofficial].

**Outputs:**
- A 3D voxel grid (density field) where occupied voxels have a density value (typically 1.0) and an associated RGBA color attribute [S2, S3, unofficial].

**Data Structures:**
1. **Voxel Grid:** A 3D array of dimensions $(N_x, N_y, N_z)$ with shape $(X, Y, Z, 4)$ storing RGBA values [S3, unofficial].
2. **Morton Queue:** A list of valid voxel-attribute pairs (Morton indices and attributes) used for efficient hierarchical tree construction [S1].
3. **Proximity Query Structure:** A spatial index built on mesh vertices to find the closest vertex to a given point [S3, unofficial].

**Parameters:**
- $s$: Voxel side length. Determines grid resolution [S2, unofficial].
- $\epsilon$: Distance threshold for voxel inclusion. Typically $\epsilon = s \cdot 0.87 \approx s \cdot \frac{\sqrt{3}}{2}$ [S2, unofficial].
- Relaxation factor for barycentric bounds: $0.5$ (i.e., bounds are $[-0.5, 1.5]$) [S2, unofficial].

**Steps:**

1. **Bounding Box and Grid Initialization:**
   Compute the axis-aligned bounding box (AABB) of the mesh [G]. Determine grid dimensions:
   $$ N_x = \lfloor \frac{bbox_{max,x} - bbox_{min,x}}{s} \rfloor + 1 $$
   $$ N_y = \lfloor \frac{bbox_{max,y} - bbox_{min,y}}{s} \rfloor + 1 $$
   $$ N_z = \lfloor \frac{bbox_{max,z} - bbox_{min,z}}{s} \rfloor + 1 $$
   Initialize a hollow voxel grid of size $(N_x, N_y, N_z)$ [S2, S3, unofficial].

2. **Voxelization (Density Field Generation):**
   For each triangle $T \in F$ with vertices $v_0, v_1, v_2$:
   a. Compute the triangle normal:
      $$ \mathbf{n} = \frac{(v_1 - v_0) \times (v_2 - v_0)}{\|(v_1 - v_0) \times (v_2 - v_0)\|} $$
   b. Determine the range of grid cells overlapping the triangle's bounding box ($minCell$ to $maxCell$) [S1][S2, unofficial].
   c. For each voxel index $(i, j, k)$ in the overlapping range:
      i. Compute the voxel center position:
         $$ \mathbf{c}_{voxel}[axis] = bbox_{min}[axis] + (index + 0.5) \cdot s $$
      ii. Calculate the distance from the voxel center to the triangle plane:
          $$ d_{plane} = | \mathbf{n} \cdot (\mathbf{c}_{voxel} - v_0) | $$
      iii. If $d_{plane} < s \cdot 0.87$ (approximating $\frac{\sqrt{3}}{2}s$):
           - Project the voxel center onto the triangle plane:
             $$ \mathbf{p} = \mathbf{c}_{voxel} - \mathbf{n} (\mathbf{n} \cdot (\mathbf{c}_{voxel} - v_0)) $$
           - Compute barycentric coordinates $(u, v)$ of $\mathbf{p}$ relative to $v_0, v_1, v_2$ using the standard dot-product method [S2, unofficial].
           - Check if the point is inside or near the triangle using relaxed bounds:
             $$ u \ge -0.5, \quad v \ge -0.5, \quad u + v \le 1.5 $$
           - If true, set the voxel density to 1.0 [S2, unofficial].

3. **Attribute Mapping (Color):**
   Two approaches are cited in the sources:

   *Approach A: Barycentric Projection (Schwarz and Seidel [2010])*
   - During Step 2, if the voxel center projects onto the triangle, use the computed barycentric coordinates $(u, v)$ to sample the triangle's texture or vertex colors [S1].
   - If the projection falls outside the triangle, clamp $(u, v)$ to the nearest edge before lookup [S1].

   *Approach B: Proximity Query (Trimesh/PyVista)*
   - Create a proximity query object on the mesh vertices: $Q = \text{ProximityQuery}(M)$ [S3, unofficial].
   - For each voxel center $\mathbf{c}_{voxel}$ in the grid:
     - Find the closest mesh vertex $v_{closest}$ using $Q$ [S3, unofficial].
     - Extract the color of $v_{closest}$.
     - Map this color to the voxel at $(i, j, k)$ in the $(X, Y, Z, 4)$ array [S3, unofficial].

4. **Parallel Implementation (GPU/Stream Compaction):**
   - Process triangles in batches [S1].
   - Use parallel stream compaction to remove empty slots from per-triangle voxel memory [S1].
   - Copy valid voxel-attribute pairs (Morton indices and attributes) into a Morton queue [S1].
   - This avoids atomic operations required in grid-based parallel voxelization [S1].

**Pseudocode:**

```python
import math

def voxelize_mesh_proximity(mesh, voxel_size):
    """
    Voxelizes a mesh and maps vertex colors to voxels using proximity.
    """
    # 1. Setup Grid
    bbox_min = mesh.bounds_min
    bbox_max = mesh.bounds_max
    dims = [int(math.ceil((bbox_max[i] - bbox_min[i]) / voxel_size)) + 1 for i in range(3)]
    # Shape (X, Y, Z, 4) for RGBA
    voxel_colors = [[[[(0.0, 0.0, 0.0, 0.0) for _ in range(dims[2])] for _ in range(dims[1])] for _ in range(dims[0])]]
    
    # 2. Extract Vertex Data
    vertices = mesh.vertices
    vertex_colors = mesh.vertex_colors # Assume normalized RGB tuples
    
    # 3. Proximity Query (Standard nearest-neighbor search) [G]
    def find_closest_vertex(point, verts):
        min_dist = float('inf')
        closest_idx = -1
        for i, v in enumerate(verts):
            d = math.sqrt(sum((p - c)**2 for p, c in zip(point, v)))
            if d < min_dist:
                min_dist = d
                closest_idx = i
        return closest_idx
    
    # 4. Iterate Voxels
    for x in range(dims[0]):
        for y in range(dims[1]):
            for z in range(dims[2]):
                # Voxel center
                cx = bbox_min[0] + (x + 0.5) * voxel_size
                cy = bbox_min[1] + (y + 0.5) * voxel_size
                cz = bbox_min[2] + (z + 0.5) * voxel_size
                voxel_center = (cx, cy, cz)
                
                # Find closest vertex
                closest_v = find_closest_vertex(voxel_center, vertices)
                if closest_v != -1:
                    voxel_colors[x][y][z] = vertex_colors[closest_v]
    
    return voxel_colors

def voxelize_mesh_barycentric(mesh, voxel_size):
    """
    Voxelizes a mesh using barycentric projection for attribute mapping.
    """
    bbox_min = mesh.bounds_min
    bbox_max = mesh.bounds_max
    dims = [int(math.ceil((bbox_max[i] - bbox_min[i]) / voxel_size)) + 1 for i in range(3)]
    
    # Initialize grid
    voxel_data = [[[[(0.0, 0.0, 0.0, 0.0) for _ in range(dims[2])] for _ in range(dims[1])] for _ in range(dims[0])]]
    voxel_density = [[[0.0 for _ in range(dims[2])] for _ in range(dims[1])] for _ in range(dims[0])]
    
    triangles = mesh.faces
    vertices = mesh.vertices
    vertex_colors = mesh.vertex_colors
    
    # Precompute triangle normals
    normals = []
    for tri in triangles:
        v0, v1, v2 = vertices[tri[0]], vertices[tri[1]], vertices[tri[2]]
        cross = tuple(v1[j] - v0[j] for j in range(3))
        cross2 = tuple(v2[j] - v0[j] for j in range(3))
        n = (cross[1]*cross2[2] - cross[2]*cross2[1],
             cross[2]*cross2[0] - cross[0]*cross2[2],
             cross[0]*cross2[1] - cross[1]*cross2[0])
        length = math.sqrt(sum(c*c for c in n))
        normals.append(tuple(c/length for c in n))
    
    # Iterate triangles
    for i, tri in enumerate(triangles):
        v0 = vertices[tri[0]]
        v1 = vertices[tri[1]]
        v2 = vertices[tri[2]]
        n = normals[i]
        
        # Bounding box of triangle
        t_min = tuple(min(v0[j], v1[j], v2[j]) for j in range(3))
        t_max = tuple(max(v0[j], v1[j], v2[j]) for j in range(3))
        
        # Grid indices overlapping triangle bbox
        min_idx = tuple(max(0, int(math.floor((t_min[j] - bbox_min[j]) / voxel_size))) for j in range(3))
        max_idx = tuple(min(dims[j]-1, int(math.floor((t_max[j] - bbox_min[j]) / voxel_size))) for j in range(3))
        
        # Iterate overlapping voxels
        for ix in range(min_idx[0], max_idx[0] + 1):
            for iy in range(min_idx[1], max_idx[1] + 1):
                for iz in range(min_idx[2], max_idx[2] + 1):
                    # Voxel center
                    vc = (bbox_min[0] + (ix + 0.5) * voxel_size,
                          bbox_min[1] + (iy + 0.5) * voxel_size,
                          bbox_min[2] + (iz + 0.5) * voxel_size)
                    
                    # Distance to plane
                    dot_val = sum(n[j] * (vc[j] - v0[j]) for j in range(3))
                    dist_plane = abs(dot_val)
                    
                    if dist_plane < voxel_size * 0.87:
                        # Project onto plane
                        proj = tuple(vc[j] - n[j] * dot_val for j in range(3))
                        
                        # Barycentric coordinates (standard dot-product method)
                        v0v1 = tuple(v1[j] - v0[j] for j in range(3))
                        v0v2 = tuple(v2[j] - v0[j] for j in range(3))
                        v0p = tuple(proj[j] - v0[j] for j in range(3))
                        
                        d00 = sum(v0v1[j]*v0v1[j] for j in range(3))
                        d01 = sum(v0v1[j]*v0v2[j] for j in range(3))
                        d11 = sum(v0v2[j]*v0v2[j] for j in range(3))
                        d20 = sum(v0p[j]*v0v1[j] for j in range(3))
                        d21 = sum(v0p[j]*v0v2[j] for j in range(3))
                        
                        denom = d00 * d11 - d01 * d01
                        if denom == 0: continue
                        
                        v = (d11 * d20 - d01 * d21) / denom
                        w = (d00 * d21 - d01 * d20) / denom
                        u = 1.0 - v - w
                        
                        # Relaxed bounds check
                        if u >= -0.5 and v >= -0.5 and (u + v) <= 1.5:
                            voxel_density[ix][iy][iz] = 1.0
                            
                            # Color mapping (clamp to nearest edge if outside [0,1])
                            u_c = max(0.0, min(1.0, u))
                            v_c = max(0.0, min(1.0, v))
                            
                            # Interpolate color
                            c0 = vertex_colors[tri[0]]
                            c1 = vertex_colors[tri[1]]
                            c2 = vertex_colors[tri[2]]
                            color = tuple((1 - u_c - v_c)*c0[j] + u_c*c1[j] + v_c*c2[j] for j in range(3))
                            
                            voxel_data[ix][iy][iz] = color + (1.0,)
    
    return voxel_data, voxel_density
```

## Operating characteristics
- **Time Complexity:** $O(N \cdot M)$ where $N$ is the number of triangles and $M$ is the average number of voxels overlapping each triangle's bounding box [G]. With spatial hashing or Morton sorting, construction can be optimized to near-linear time relative to the output voxel count [S1].
- **Memory Complexity:** Proportional to the volume of the bounding box in voxels [G]. The use of Morton queues and stream compaction allows for sparse storage, reducing memory usage for hollow or thin structures [S1].
- **Strengths:**
  - Handles arbitrary topology and non-watertight meshes (though holes may appear) [S3, unofficial].
  - Integrates attribute mapping (color/normal) directly, avoiding separate interpolation steps [S1].
  - Efficient on GPU via parallel stream compaction, avoiding atomic conflicts [S1].
- **Limitations:**
  - Resolution is limited by voxel size; small features may be lost if $s$ is too large [S2, unofficial].
  - Proximity-based mapping (Approach B) can produce artifacts if the mesh is not watertight or has self-intersections, as it relies on vertex proximity rather than surface projection [S3, unofficial].
- **When to use:** Ideal for converting textured polygonal models into volumetric representations for ray marching or SDF-based rendering where vertex colors are important [S2, S3, unofficial].
- **When not to use:** Not given in the sources.

## Background
The method originates from the work of Schwarz and Seidel [2010], who proposed a grid-free, out-of-core voxelization technique for sparse voxel octrees (SVO) on the GPU [S1]. Their approach emphasized attribute creation (normals, colors) during voxelization using barycentric coordinates and texture lookups, avoiding atomic operations through parallel stream compaction and Morton sorting [S1]. Later implementations, such as those using the `trimesh` library in Python, adapted these concepts for easier mesh analysis and visualization, often using proximity queries for color mapping when barycentric projection is not directly supported [S3, unofficial]. The technique is widely used in procedural generation, game development, and preprocessing for volume rendering [S2, S3, unofficial].
