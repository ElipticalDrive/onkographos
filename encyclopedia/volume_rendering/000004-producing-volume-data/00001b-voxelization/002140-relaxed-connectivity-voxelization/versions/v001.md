# Relaxed Connectivity Voxelization

Also called: 26-connected voxelization of 1D input

## Overview
Relaxed Connectivity Voxelization is a method for voxelizing effectively one-dimensional input (primitives that are 1D, 2D, or 3D but lack volume separation in 3D space) such that the resulting voxels form a connected path. It solves the problem of ensuring topological continuity for flow simulation or fill operations without the excessive voxel count of strict 6-connected methods. It sets itself apart from standard voxelization by using specific 2D intersection targets within voxels to guarantee connectivity, and from [Conservative Voxelization](3247-conservative-voxelization.md) by prioritizing topological correctness of thin structures over volumetric inclusion.

## How it works
**Inputs:** A set of geometric primitives (lines, curves, surfaces, or volumes) that are "effectively one-dimensional" in 3D space.
**Outputs:** A set of voxel indices representing the input, guaranteed to be 6-connected or 26-connected.

### Data Structures
*   **Voxel Grid:** A 3D array or sparse structure mapping integer coordinates $(x, y, z)$ to occupancy status.
*   **Intersection Target:** A set of 2D geometric primitives (quadrilaterals or surfaces) defined within the local coordinate system of a single voxel.

### Method: 26-Connected Voxelization
This is the primary "relaxed" variant described in the sources.

1.  **Define the Intersection Target:** For a voxel $V$ with side length $s$, define the target as three quadrilaterals that bisect the voxel along the X, Y, and Z axes.
    *   Let the voxel center be $(0,0,0)$ and side length be $2$. The voxel spans $[-1, 1]^3$.
    *   Target 1 (XY plane): Quadrilateral with vertices $(\pm 1, \pm 1, 0)$.
    *   Target 2 (XZ plane): Quadrilateral with vertices $(\pm 1, 0, \pm 1)$.
    *   Target 3 (YZ plane): Quadrilateral with vertices $(0, \pm 1, \pm 1)$.
    *   This target subdivides space into 8 cubes centered at the voxel corners.

2.  **Intersect Input with Target:** For each voxel $V$ in the grid:
    *   Check if the input geometry intersects any part of the intersection target defined in Step 1.
    *   If an intersection exists, mark voxel $V$ as occupied.

3.  **Connectivity Guarantee:**
    *   If input intersects the target in voxel $V$, any continuous path from $V$ to a voxel outside the immediate 26-neighbors $N_{26}(V)$ must cross a boundary.
    *   The parts of the intersection targets of the 26-neighbors of $V$ form a closed box with side length $2s$ centered at $V$'s center.
    *   Therefore, the path must intersect the target in at least one neighbor in $N_{26}(V)$, ensuring 26-connectivity.

### Method: 6-Connected Voxelization
A stricter variant for cases where 6-connectivity is required.

1.  **Define the Intersection Target:** Construct a continuous surface for each of the 6 faces of the voxel. The surface must prevent curves from entering through one face and exiting through another without intersecting the surface.
    *   **Octahedral Tessellation Realization:** Close each face with a pyramid meeting at the voxel center. The centers of these octahedra are at voxel face centers.
    *   **Cubical Tessellation Realization:** Push the surfaces to the boundaries of the voxels. The target consists of the surface of the cube (2D sheets).

2.  **Intersect Input with Target:** For each voxel $V$:
    *   Check if the input geometry intersects the constructed surfaces.
    *   If an intersection exists, mark voxel $V$ as occupied.

3.  **Connectivity Guarantee:** A continuous 1D object cannot extend between two voxels without forming a 6-connected path of voxels in between, as it must intersect the face surfaces.

### Pseudocode
```python
def voxelize_relaxed_connectivity(primitives, grid_bounds, voxel_size, connectivity='26'):
    """
    Voxelizes effectively 1D input using relaxed connectivity.
    
    Args:
        primitives: List of geometric primitives (lines, surfaces, etc.)
        grid_bounds: Tuple (min_x, min_y, min_z, max_x, max_y, max_z)
        voxel_size: Float, side length of a voxel
        connectivity: String, '6' or '26'
        
    Returns:
        Set of voxel coordinates (x, y, z) that are occupied.
    """
    occupied_voxels = set()
    
    # Determine voxel grid dimensions
    num_x = int((grid_bounds[3] - grid_bounds[0]) / voxel_size)
    num_y = int((grid_bounds[4] - grid_bounds[1]) / voxel_size)
    num_z = int((grid_bounds[5] - grid_bounds[2]) / voxel_size)
    
    for x in range(num_x):
        for y in range(num_y):
            for z in range(num_z):
                # Calculate voxel center and bounds
                center_x = grid_bounds[0] + (x + 0.5) * voxel_size
                center_y = grid_bounds[1] + (y + 0.5) * voxel_size
                center_z = grid_bounds[2] + (z + 0.5) * voxel_size
                
                voxel_occupied = False
                
                if connectivity == '26':
                    # Define 26-connected target: 3 bisecting quadrilaterals
                    # In local coordinates relative to center, voxel is [-0.5, 0.5]^3
                    half = voxel_size / 2.0
                    
                    # Target 1: XY plane at z=0
                    # Vertices: (±half, ±half, 0)
                    quad_xy = Polygon([(center_x - half, center_y - half, center_z),
                                       (center_x + half, center_y - half, center_z),
                                       (center_x + half, center_y + half, center_z),
                                       (center_x - half, center_y + half, center_z)])
                    
                    # Target 2: XZ plane at y=0
                    # Vertices: (±half, 0, ±half)
                    quad_xz = Polygon([(center_x - half, center_y, center_z - half),
                                       (center_x + half, center_y, center_z - half),
                                       (center_x + half, center_y, center_z + half),
                                       (center_x - half, center_y, center_z + half)])
                    
                    # Target 3: YZ plane at x=0
                    # Vertices: (0, ±half, ±half)
                    quad_yz = Polygon([(center_x, center_y - half, center_z - half),
                                       (center_x, center_x + half, center_z - half), # Note: typo in logic, should be center_y + half
                                       (center_x, center_y + half, center_z + half),
                                       (center_x, center_y - half, center_z + half)])
                    
                    # Corrected Quad YZ vertices
                    quad_yz = Polygon([(center_x, center_y - half, center_z - half),
                                       (center_x, center_y + half, center_z - half),
                                       (center_x, center_y + half, center_z + half),
                                       (center_x, center_y - half, center_z + half)])
                    
                    targets = [quad_xy, quad_xz, quad_yz]
                    
                    for target in targets:
                        if intersects_any(primitives, target):
                            voxel_occupied = True
                            break
                            
                elif connectivity == '6':
                    # Define 6-connected target: Surfaces on voxel faces
                    # Using Cubical Tessellation realization (surface of the cube)
                    # Check intersection with the 6 faces of the voxel
                    faces = [
                        # Front, Back, Left, Right, Top, Bottom
                        Plane(center_x, center_y, center_z + half, normal=(0,0,1)),
                        Plane(center_x, center_y, center_z - half, normal=(0,0,-1)),
                        Plane(center_x - half, center_y, center_z, normal=(-1,0,0)),
                        Plane(center_x + half, center_y, center_z, normal=(1,0,0)),
                        Plane(center_x, center_y + half, center_z, normal=(0,1,0)),
                        Plane(center_x, center_y - half, center_z, normal=(0,-1,0))
                    ]
                    
                    for face in faces:
                        if intersects_any(primitives, face):
                            voxel_occupied = True
                            break
                            
                if voxel_occupied:
                    occupied_voxels.add((x, y, z))
                    
    return occupied_voxels

def intersects_any(primitives, target):
    """
    Checks if any primitive in the list intersects the target geometry.
    Implementation depends on primitive type (line, triangle, etc.).
    """
    for prim in primitives:
        if intersects_geometry(prim, target):
            return True
    return False
```

### Parameters
*   **Connectivity:** '6' or '26'. Default is '26' for relaxed connectivity.
*   **Voxel Size:** Determines resolution. Smaller sizes increase accuracy but also voxel count.

### Edge Cases and Pitfalls
*   **Inefficiency:** The resulting voxelization may contain almost as many voxels as a cover produced by intersecting the input against the entire 3D voxel volume, making it potentially inefficient for dense scenes [S1, unofficial].
*   **Not "Thin":** The result is not thin in the same sense as the 2D crosshairs target. Stepping along a curve in the dominant direction may produce fewer voxels than this method [S1, unofficial].
*   **Input Type:** The method is designed for "effectively one-dimensional" input. It works for 2D or 3D primitives that are effectively 1D, unlike existing algorithms restricted to 1D primitives like line segments [S1, unofficial].

## Operating characteristics
*   **Time Complexity:** $O(N \cdot M)$, where $N$ is the number of voxels and $M$ is the number of primitives. Each voxel requires intersection tests against the target geometry.
*   **Memory Complexity:** $O(N)$ to store the voxel grid.
*   **Strengths:** Guarantees topological connectivity (6 or 26) for thin structures; handles 2D/3D primitives that are effectively 1D.
*   **Limitations:** Can produce a high voxel count (similar to full volume intersection); not optimal for "thin" representations compared to directional stepping algorithms.
*   **When to use:** When topological continuity is critical for flow simulation or fill operations, and the input consists of thin structures (curves, surfaces) rather than solid volumes.
*   **When not to use:** When memory efficiency is paramount and the input is solid volumetric data; when a "thin" representation is preferred over topological guarantees.

## Background
The method was introduced by S. M. Laine in the paper "A Topological Approach to Voxelization" (2013) [S1, unofficial]. It addresses the limitations of previous voxelization techniques that were restricted to 1D primitives (e.g., line segments) and did not guarantee connectivity for effectively 1D 2D/3D primitives. The work builds on earlier 2D topological voxelization concepts [S1, unofficial].
