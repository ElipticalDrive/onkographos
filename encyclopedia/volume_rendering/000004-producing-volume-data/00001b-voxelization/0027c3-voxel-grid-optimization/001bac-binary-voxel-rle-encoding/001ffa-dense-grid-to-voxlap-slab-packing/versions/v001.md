# Dense-grid to Voxlap-slab packing

## Overview
Converts a dense 3D voxel mask and color grid into the Voxlap slab-RLE column format, seeding an all-solid VXL and carving air voxels using a column function to preserve buried-voxel-aware encoding. It differs from [Binary Voxel RLE Encoding](1071-binary-voxel-rle-encoding.md) by maintaining explicit column offsets and supporting direct color attachment per column, and from [Run-length encoded voxel runs](1209-run-length-encoded-voxel-runs.md) by using a slab-based internal structure rather than simple run lists.

## How it works
**Inputs:**
- `grid`: A slice of `u8` bytes sized `VSID × VSID × MAXZDIM` in `(y, x, z)` order. A non-zero byte marks a voxel as solid.
- `color`: A slice of `u32` bytes sized `VSID × VSID × MAXZDIM`. The corresponding `u32` is the BGRA color stored when a voxel becomes exposed.
- `vsid`: The voxel side dimension (width/depth).

**Outputs:**
- A `VXL` struct containing the packed voxel data, column offsets, and metadata.

**Data Structures:**
- `VXL`: Contains `vsid`, `ipo` (origin), `ist` (x-axis), `ihe` (z-axis), `ifo` (y-axis), `data` (boxed slice of bytes), `column_offset` (boxed slice of `u32`), `mip_base_offsets`, `vbit`, and `vbiti`.
- `column_offset`: A vector of `u32` with capacity `n_cols + 1`, where `n_cols = vsid²`. Stores the byte offset into `data` for the start of each column.
- `data`: A vector of bytes storing the slab-RLE encoded columns.
- `Vspan`: Struct with fields `x` (`u32`), `y` (`u32`), `z0` (`u8`), `z1` (`u8`). `z1` is inclusive.

**Parameters:**
- `MAXZDIM`: The maximum height of the voxel grid, defined as 256 (one byte per z value) [S1, unofficial].

**Steps:**
1. **Validate Input Sizes:** Assert that `grid.len()` and `color.len()` equal `vsid² × MAXZDIM`. Panic if they do not [S1, unofficial].
2. **Seed VXL Data Structures:** Initialize `data` Vec and `column_offset` Vec with capacity `n_cols * 8` and `n_cols + 1` respectively, where `n_cols = vsid²` [S1, unofficial].
3. **Iterate Columns:** Iterate `y` from 0 to `vsid_u` and `x` from 0 to `vsid_u`:
   - Push current `data.len()` to `column_offset`.
   - Write header `[nextptr=0, z1=0, z1c=0, z0=0]` (4 bytes) to `data`.
   - Calculate base index in `grid`/`color`.
   - If `grid[base]` is 0, set base color to 0; else set to `color[base]`.
   - Write base color as 4 little-endian bytes to `data` [S1, unofficial].
4. **Finalize Column Offsets:** Push final `data.len()` to `column_offset` [S1, unofficial].
5. **Construct VXL Struct:** Set `vsid`, `ipo=[0.0,0.0,0.0]`, `ist=[1.0,0.0,0.0]`, `ihe=[0.0,0.0,1.0]`, `ifo=[0.0,1.0,0.0]`. Set `data` to `data.into_boxed_slice()` and `column_offset` to `column_offset.into_boxed_slice()`. Set `mip_base_offsets` to `Box::new([0, n_cols + 1])`, `vbit` to `Box::new([])`, and `vbiti` to 0 [S1, unofficial].
6. **Reserve Edit Capacity:** Call `vxl.reserve_edit_capacity(n_cols * 512)` [S1, unofficial].
7. **Build Sorted Air-Span List:** Initialize empty `air_spans` Vec. Iterate `y` from 0 to `vsid_u` and `x` from 0 to `vsid_u`. Calculate base index. Initialize `z=0`. While `z < maxzdim_u`:
   - If `grid[base+z] == 0`, set `zs=z`.
   - Inner while loop: While `z < maxzdim_u` and `grid[base+z] == 0`, increment `z`.
   - Push `Vspan { x: x as u32, y: y as u32, z0: zs as u8, z1: (z - 1) as u8 }` to `air_spans`.
   - Else increment `z` [S1, unofficial].
8. **Carve Air Spans:** If `air_spans` is not empty, call `set_spans_with_colfunc(&mut vxl, &air_spans, SpanOp::Carve, closure)`. The closure takes `x`, `y`, `z`, calculates `idx = (y * vsid_u + x) * maxzdim_u + z`, and returns `roxlap_formats::VoxColor(color[idx])` [S1, unofficial].

**Pseudocode:**
```python
def pack_dense_grid_to_vxl(grid: List[u8], color: List[u32], vsid: u32) -> VXL:
    MAXZDIM = 256
    n_cols = vsid * vsid
    
    # Step 1: Validate
    assert len(grid) == vsid * vsid * MAXZDIM
    assert len(color) == vsid * vsid * MAXZDIM
    
    # Step 2: Seed structures
    data = []
    column_offset = []
    data.reserve(n_cols * 8)
    column_offset.reserve(n_cols + 1)
    
    # Step 3: Iterate columns
    for y in range(vsid):
        for x in range(vsid):
            column_offset.append(len(data))
            # Write header: nextptr=0, z1=0, z1c=0, z0=0
            data.extend([0, 0, 0, 0])
            
            base_idx = (y * vsid + x) * MAXZDIM
            if grid[base_idx] != 0:
                col_val = color[base_idx]
            else:
                col_val = 0
            # Write base color as 4 little-endian bytes
            data.extend(col_val.to_bytes(4, byteorder='little'))
            
    # Step 4: Finalize offsets
    column_offset.append(len(data))
    
    # Step 5: Construct VXL
    vxl = VXL(
        vsid=vsid,
        ipo=[0.0, 0.0, 0.0],
        ist=[1.0, 0.0, 0.0],
        ihe=[0.0, 0.0, 1.0],
        ifo=[0.0, 1.0, 0.0],
        data=data.to_boxed_slice(),
        column_offset=column_offset.to_boxed_slice(),
        mip_base_offsets=Box([0, n_cols + 1]),
        vbit=Box([]),
        vbiti=0
    )
    
    # Step 6: Reserve capacity
    vxl.reserve_edit_capacity(n_cols * 512)
    
    # Step 7: Build air spans
    air_spans = []
    for y in range(vsid):
        for x in range(vsid):
            base_idx = (y * vsid + x) * MAXZDIM
            z = 0
            while z < MAXZDIM:
                if grid[base_idx + z] == 0:
                    zs = z
                    while z < MAXZDIM and grid[base_idx + z] == 0:
                        z += 1
                    air_spans.append(Vspan(x=x, y=y, z0=zs, z1=z-1))
                else:
                    z += 1
                    
    # Step 8: Carve air spans
    if air_spans:
        def closure(x, y, z):
            idx = (y * vsid + x) * MAXZDIM + z
            return VoxColor(color[idx])
        set_spans_with_colfunc(vxl, air_spans, SpanOp::Carve, closure)
        
    return vxl
```

## Operating characteristics
- **Time Complexity:** Linear in the number of voxels for the initial seeding and air-span detection. Carving is proportional to the number of air spans.
- **Memory Complexity:** Proportional to `VSID² * MAXZDIM` for input, plus `VSID² * 8` for initial output structure, plus overhead for air spans.
- **Strengths:** Efficiently handles dense grids with large solid regions by seeding all-solid columns and only carving air. Preserves color information for exposed voxels.
- **Limitations:** Requires `MAXZDIM` to be 256. Panics if grid size mismatch or slab pool overflow occurs during carving [S1, unofficial].
- **When to Use:** When converting dense voxel data to a format suitable for acoustic or rendering simulations that require buried-voxel awareness.
- **When Not to Use:** For sparse data where other RLE methods might be more efficient, or when `MAXZDIM` exceeds 256.

## Background
Originated in the Roxlap project, a portable reimplementation of Ken Perlin's work, specifically for acoustic simulation and cavity estimation [S1, unofficial].
