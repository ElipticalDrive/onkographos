# Occupancy Voxel Creation
## Overview
Occupancy Voxel Creation converts a continuous density representation into a sparse boolean occupancy mask by identifying fully occupied 2x2x2 blocks. It solves the problem of reducing memory footprint and computational cost in volume rendering by discarding empty space and merging small occupied regions into larger coherent blocks. It differs from [3D Voxel Grid Smoothing](833-3d-voxel-grid-smoothing.md) by using hard thresholding rather than interpolation, and from [Binary Voxel RLE Encoding](1071-binary-voxel-rle-encoding.md) by producing a structural mask rather than a compressed bitstream.
## How it works
**Inputs:** A 3D density matrix `density` of shape `(side, side, side)` containing non-negative float values.
**Outputs:** A boolean mask `mask` of shape `(side-1, side-1, side-1)` indicating which 2x2x2 blocks are fully occupied.

**Data Structures:**
- `density`: 3D array, dtype float32.
- `occupancy_mat`: 3D array, dtype int32 or bool.
- `kernel`: 5D array for JAX convolution, shape `(2, 2, 2, 1, 1)`.
- `out`: 5D array, result of convolution.

**Steps:**
1. **Thresholding:** Convert the density matrix to a binary occupancy mask. A voxel is considered occupied if its density value is strictly greater than 0.
   $$ occupancy\_mat[i, j, k] = \begin{cases} 1 & \text{if } density[i, j, k] > 0 \\ 0 & \text{otherwise} \end{cases} $$
2. **Reshape for Convolution:** Prepare the data for JAX's `conv_general_dilated` function. The input tensor must be 5-dimensional. Add a batch dimension and a channel dimension.
   $$ data = occupancy\_mat[None, :, :, :, None] $$
   Shape becomes `(1, side, side, side, 1)`.
3. **Define Kernel:** Create a 2x2x2 kernel of ones. The kernel must match the 5D structure.
   $$ kernel = \mathbf{1}_{2 \times 2 \times 2} $$
   In code: `kernel = jnp.ones([2, 2, 2])[:, :, :, jnp.newaxis, jnp.newaxis]`. Shape `(2, 2, 2, 1, 1)`.
4. **Convolution:** Perform a 3D convolution with stride 1 and 'SAME' padding. The kernel slides over the `occupancy_mat`. For each position $(i, j, k)$, the output is the sum of the 8 neighboring voxels in the 2x2x2 block starting at $(i, j, k)$.
   $$ out[i, j, k, :, :] = \sum_{dx=0}^{1} \sum_{dy=0}^{1} \sum_{dz=0}^{1} data[i, j+dx, k+dy, l+dz, :] $$
   Using JAX: `out = lax.conv_general_dilated(data, kernel, (1, 1, 1), 'SAME', (1, 1, 1), (1, 1, 1))`.
   Note: The source code uses `dn` (dimension numbers) which typically maps input spatial dimensions to the kernel spatial dimensions. Standard mapping is `('NCHW', 'OIHW', 'NCHW')` or similar, but for 3D spatial data in JAX, it is often `('NHWC', 'HWIO', 'NHWC')` or explicit dimension numbers. The source snippet implies a standard spatial convolution.
5. **Mask Extraction:** Create the final boolean mask. A 2x2x2 block is fully occupied if the convolution sum equals 8 (since all 8 voxels are 1).
   $$ mask[i, j, k] = (out[i, j, k, 0, 0] == 8) $$
   The output shape is `(side-1, side-1, side-1)` because the 2x2x2 kernel can only start at indices $0$ to $side-2$.

**Pseudocode:**
```python
import jax.numpy as jnp
from jax.lax import conv_general_dilated

def create_occupancy_voxels(density: jnp.ndarray) -> jnp.ndarray:
    """
    Converts a density matrix into a boolean occupancy mask of fully occupied 2x2x2 blocks.
    
    Args:
        density: 3D array of shape (side, side, side) with float values.
        
    Returns:
        mask: 3D boolean array of shape (side-1, side-1, side-1).
    """
    # Step 1: Threshold density to binary occupancy
    # Voxels with density > 0 are occupied (1), others are empty (0)
    occupancy_mat = (density > 0).astype(jnp.int32)
    
    # Step 2: Reshape for JAX convolution
    # Add batch dimension (1) and channel dimension (1)
    # Input shape: (1, side, side, side, 1)
    data = occupancy_mat[jnp.newaxis, :, :, :, jnp.newaxis]
    
    # Step 3: Define 2x2x2 kernel of ones
    # Kernel shape: (2, 2, 2, 1, 1)
    kernel = jnp.ones([2, 2, 2])[:, :, :, jnp.newaxis, jnp.newaxis]
    
    # Step 4: Perform convolution
    # Strides: (1, 1, 1)
    # Padding: 'SAME'
    # Input dimension numbers: ('NCHW', 'OIHW', 'NCHW') is not standard for 3D spatial.
    # JAX conv_general_dilated expects dimension numbers like ('NHWC', 'HWIO', 'NHWC') for 2D spatial.
    # For 3D spatial data (batch, x, y, z, channel), the dims are ('NCDHW', 'OIDHW', 'NCDHW')
    # However, the source uses lax.conv_general_dilated with default dn or implicit.
    # Assuming standard 3D convolution on spatial dimensions.
    # The source code snippet: lax.conv_general_dilated(data, kernel, (1, 1, 1), 'SAME', (1, 1, 1), (1, 1, 1), dn)
    # dn is not defined in the snippet, but typically for (N, D, H, W, C) it is ('NCDHW', 'OIDHW', 'NCDHW')
    # Let's assume the source implies a valid dimension mapping for the specific JAX version.
    # We will write the call with explicit dimension numbers for clarity and correctness.
    # Input: (N, D, H, W, C) -> (1, side, side, side, 1)
    # Kernel: (O, D, H, W, I) -> (1, 2, 2, 2, 1)
    # Output: (N, D', H', W', C')
    
    # Note: The source code uses `dn` which is likely a tuple of strings.
    # For 3D spatial convolution in JAX with shape (N, D, H, W, C):
    dn = ('NCDHW', 'OIDHW', 'NCDHW')
    
    out = conv_general_dilated(
        data, 
        kernel, 
        window_strides=(1, 1, 1), 
        padding='SAME',
        lhs_dilation=(1, 1, 1), 
        rhs_dilation=(1, 1, 1), 
        dimension_numbers=dn
    )
    
    # Step 5: Extract mask where sum equals 8
    # out shape: (1, side-1, side-1, side-1, 1)
    # We check if the value is exactly 8.0
    mask = out[0, :, :, :, 0] == 8.0
    
    return mask
```

**Parameters:**
- Threshold: 0. [S1, unofficial]
- Kernel size: 2x2x2. [S1, unofficial]
- Convolution padding: SAME. [S1, unofficial]

**Edge Cases:**
- If `side` is less than 2, the output mask is empty.
- If all densities are 0, the mask is all False.
- Precision: The comparison `== 8` relies on integer arithmetic if `occupancy_mat` is int32. If float, use `jnp.isclose(out, 8.0)`. The source uses `out == 8` after casting to int32 implicitly or explicitly. [S1, unofficial]

## Operating characteristics
**Time Complexity:** $O(N)$ where $N$ is the number of voxels, dominated by the convolution operation. The convolution is highly parallelizable on GPU.
**Memory Complexity:** $O(N)$ for the input density and intermediate convolution output. The output mask is smaller by a factor of 8 in volume, but stored as a dense boolean array of size $(side-1)^3$.
**Performance:** Fast on GPU due to JAX's optimized convolution primitives. [S1, unofficial]
**Strengths:** Simple to implement; effectively reduces memory usage for sparse scenes; compatible with differentiable rendering pipelines if gradients are needed (though the thresholding step is non-differentiable, the convolution is).
**Limitations:** Loses fine-grained detail within 2x2x2 blocks; assumes a uniform grid; the threshold of 0 may be too sensitive for noisy density fields.
**When to use:** When memory is constrained and the scene has large empty regions. When using a differentiable renderer that benefits from sparse occupancy masks.
**When not to use:** When high-frequency details are critical and cannot be captured by 2x2x2 blocks. When the density field is very noisy and requires smoothing before thresholding.

## Background
The method originates from the Jax-Volumetric-Renderer project, which implements a differentiable volumetric renderer in JAX. The specific technique of using 2x2x2 convolution to identify fully occupied blocks is a heuristic for sparse voxel optimization. [S1, unofficial]
