# Occupancy Voxel Creation
## Overview
Occupancy Voxel Creation converts a continuous density matrix into a discrete boolean occupancy mask and identifies fully occupied 2x2x2 blocks for efficient rendering or storage [S1, unofficial]. It differs from sibling methods like [3D Voxel Grid Smoothing](833-3d-voxel-grid-smoothing.md) by focusing on block-level density aggregation rather than spatial averaging, and from [Binary Voxel RLE Encoding](1071-binary-voxel-rle-encoding.md) by producing a structural mask rather than a compressed bitstream.
## How it works
**Inputs:** A 3D density matrix $D$ of shape $(H, W, D)$ containing non-negative float values.
**Outputs:** A boolean mask $M$ of shape $(H-1, W-1, D-1)$ indicating which 2x2x2 blocks are fully occupied.

**Data Structures:**
- `density_mat`: 3D array of floats.
- `occupancy_mat`: 3D array of integers (0 or 1).
- `kernel`: 5D array for JAX convolution, shape $(2, 2, 2, 1, 1)$.
- `out`: 5D array result of convolution.

**Steps:**
1.  **Binary Conversion:** Convert the density matrix to a binary occupancy grid. For every voxel $v$, if $D[v] > 0$, set $O[v] = 1$, else $O[v] = 0$ [S1, unofficial].
2.  **Reshape for Convolution:** Prepare the binary grid for JAX's `conv_general_dilated`. Add batch and channel dimensions: $data = O[None, :, :, :, None]$ [S1, unofficial].
3.  **Define Kernel:** Create a 2x2x2 kernel of ones. Shape: $(2, 2, 2, 1, 1)$ [S1, unofficial].
4.  **Convolution:** Perform a 3D convolution with stride 1 and 'SAME' padding. The kernel slides over the grid, summing the values of the 8 voxels in each 2x2x2 block [S1, unofficial].
    $$ out = \text{conv\_general\_dilated}(data, kernel, strides=(1,1,1), padding='SAME', dilations=(1,1,1)) $$
5.  **Mask Extraction:** The output value for a block is the sum of its 8 constituent voxels. A value of 8 indicates all 8 voxels are occupied (value 1). Create a boolean mask where $out == 8$ [S1, unofficial].

**Pseudocode:**
```python
import jax.numpy as jnp
from jax.lax import conv_general_dilated

def create_occupancy_voxels(density_mat):
    # Step 1: Convert density to binary occupancy
    # [G] Assuming density_mat is a JAX array. 
    # If using NumPy, use np.where or boolean indexing.
    occupancy_mat = (density_mat > 0).astype(jnp.int32)
    
    # Step 2: Reshape for JAX convolution
    # Add batch dimension (1) and channel dimension (1)
    # Shape becomes (1, H, W, D, 1)
    data = occupancy_mat[jnp.newaxis, :, :, :, jnp.newaxis]
    
    # Step 3: Define 2x2x2 kernel of ones
    # Shape (2, 2, 2, 1, 1)
    kernel = jnp.ones([2, 2, 2, 1, 1])
    
    # Step 4: Perform convolution
    # Strides: (1, 1, 1)
    # Padding: 'SAME'
    # Dilations: (1, 1, 1)
    out = conv_general_dilated(
        data, 
        kernel, 
        window_strides=(1, 1, 1), 
        padding='SAME', 
        dimension_numbers=('NHWC', 'OIHW', 'NHWC'), # Note: JAX default dims may vary; source implies standard 3D conv
        feature_group_count=1
    )
    
    # Step 5: Extract mask where sum is 8
    # The output shape will be (1, H, W, D, 1) due to SAME padding and 1x1x1 stride on 2x2x2 kernel?
    # Actually, SAME padding with stride 1 and kernel 2x2x2 on input H,W,D results in output H,W,D.
    # We need to check if the source implies a specific output shape reduction.
    # Standard conv with SAME padding preserves spatial dimensions.
    # However, the mask is typically for the *blocks*, which are (H-1)x(W-1)x(D-1).
    # The source code snippet `mask = np.array(out == 8)` suggests direct comparison.
    # If out is (1, H, W, D, 1), the last element might be invalid or the source handles it.
    # Let's assume the source returns a mask of the same spatial size, where valid blocks are marked.
    
    mask = (out == 8)
    
    # [G] The source snippet does not explicitly crop the mask to (H-1, W-1, D-1).
    # However, logically, the last row/col/depth of a 2x2x2 block sum does not represent a full block 
    # if the grid is not padded. The source uses 'SAME' padding, which pads the input.
    # The resulting mask includes the padded regions. 
    # For implementation, one might need to crop or ignore the padded boundary if strict block indexing is required.
    # But based strictly on the source, we return the result of the comparison.
    
    return mask
```

**Parameters:**
- Threshold: $0$ (implicit in `> 0`) [S1, unofficial].
- Kernel Size: $2 \times 2 \times 2$ [S1, unofficial].

**Edge Cases:**
- Empty density matrix: Returns empty mask.
- All zeros: Returns all False mask.
- Precision: Density values must be strictly positive to be considered occupied. Floating point noise near zero should be handled by the threshold [S1, unofficial].

## Operating characteristics
**Time Complexity:** $O(N)$ where $N$ is the number of voxels, dominated by the convolution operation.
**Memory Complexity:** $O(N)$ for storing the density, occupancy, and output convolution results.
**Performance:** Efficient on GPU via JAX convolution primitives. The 2x2x2 block detection is a single pass convolution.
**Strengths:** Simple, differentiable (if using float approximations, though this method uses hard threshold), and efficient for identifying dense regions.
**Limitations:** Only identifies *fully* occupied blocks. Partially occupied blocks are ignored, which may lead to loss of detail in sparse regions.

## Background
Originated in the context of JAX-based volumetric rendering pipelines, specifically for optimizing voxel grid processing by reducing the number of active voxels to render [S1, unofficial].
