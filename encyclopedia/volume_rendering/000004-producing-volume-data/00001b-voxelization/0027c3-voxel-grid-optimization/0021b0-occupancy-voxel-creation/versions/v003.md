# Occupancy Voxel Creation
## Overview
Occupancy Voxel Creation converts a continuous density matrix into a discrete boolean occupancy mask and simplifies the geometry by identifying fully occupied 2x2x2 blocks. It differs from [3D Voxel Grid Smoothing](833-3d-voxel-grid-smoothing.md) by using hard thresholding and structural convolution rather than continuous filtering, and from [Binary Voxel RLE Encoding](1071-binary-voxel-rle-encoding.md) by producing a structural mask rather than a compressed bitstream. It serves as a preprocessing step to reduce voxel grid complexity for rendering or training.
## How it works
**Inputs:** A 3D density matrix $D$ of shape $(S, S, S)$ where $S$ is the side length.
**Outputs:** A boolean mask $M$ of shape $(S-1, S-1, S-1)$ indicating the top-left corner of each fully occupied 2x2x2 block.

**Data Structures:**
- `density_mat`: 3D array of floats.
- `occupancy_mat`: 3D array of integers (0 or 1).
- `kernel`: 5D array for JAX convolution, shape $(2, 2, 2, 1, 1)$.
- `out`: 5D array result of convolution.
- `mask`: 3D boolean array.

**Steps:**
1. **Thresholding:** Convert density to binary occupancy. For every voxel $v$ in $D$:
   $$
   O[v] = \begin{cases} 
   1 & \text{if } D[v] > 0 \\
   0 & \text{otherwise}
   \end{cases}
   $$
2. **Reshape for Convolution:** Prepare the occupancy data for JAX's `conv_general_dilated`. Add batch and channel dimensions:
   $$
   \text{data} = O[\text{None}, :, :, :, \text{None}]
   $$
   Shape becomes $(1, S, S, S, 1)$.
3. **Define Kernel:** Create a 2x2x2 kernel of ones.
   $$
   K = \mathbf{1}_{2 \times 2 \times 2}
   $$
   Reshape to $(2, 2, 2, 1, 1)$ to match JAX's expected input format for spatial convolution with batch/channel dims.
4. **Convolution:** Perform a 3D convolution with stride 1 and 'SAME' padding.
   $$
   \text{out} = \text{conv\_general\_dilated}(\text{data}, K, \text{strides}=(1,1,1), \text{padding}='SAME', \text{dilation}=(1,1,1))
   $$
   The output shape is $(1, S, S, S, 1)$. Each element represents the sum of the 8 voxels in the 2x2x2 block anchored at that position.
5. **Mask Extraction:** Identify blocks where all 8 voxels are occupied.
   $$
   M = (\text{out} == 8)
   $$
   The resulting mask $M$ has shape $(S-1, S-1, S-1)$ if cropped, or $(S, S, S)$ if padded. Typically, only valid top-left corners are kept, implying the output is effectively $(S-1, S-1, S-1)$.

**Pseudocode:**
```python
import jax.numpy as jnp
from jax.lax import conv_general_dilated

def create_occupancy_voxels(density_mat):
    """
    Converts a density matrix to an occupancy mask of 2x2x2 blocks.
    
    Args:
        density_mat: jnp.ndarray of shape (S, S, S)
        
    Returns:
        mask: jnp.ndarray of shape (S-1, S-1, S-1) boolean
    """
    # Step 1: Threshold density to binary occupancy
    # [G] Assuming density values are non-negative. 
    # If negative densities are possible, threshold at 0.
    occupancy = jnp.where(density_mat > 0, 1, 0)
    
    # Step 2: Reshape for JAX convolution
    # Add batch dimension (1) and channel dimension (1)
    # Shape: (1, S, S, S, 1)
    data = occupancy[jnp.newaxis, :, :, :, jnp.newaxis]
    
    # Step 3: Define 2x2x2 kernel of ones
    # Shape: (2, 2, 2, 1, 1)
    kernel = jnp.ones([2, 2, 2, 1, 1])
    
    # Step 4: Perform convolution
    # Strides: (1, 1, 1)
    # Padding: 'SAME'
    # Input/Output dilations: (1, 1, 1)
    out = conv_general_dilated(
        data, 
        kernel, 
        window_strides=(1, 1, 1), 
        padding='SAME', 
        lhs_dilation=(1, 1, 1), 
        rhs_dilation=(1, 1, 1)
    )
    
    # Step 5: Extract mask where sum equals 8 (all 8 voxels occupied)
    # out shape is (1, S, S, S, 1)
    # We remove batch and channel dims to get (S, S, S)
    # Then we typically crop to (S-1, S-1, S-1) as the last row/col/depth 
    # cannot form a 2x2x2 block top-left corner in a strict grid sense, 
    # though 'SAME' padding keeps size S.
    # The source code implies checking == 8 on the full output.
    # To match the logical "block" definition, we usually consider valid top-lefts.
    # However, the source simply does `out == 8`.
    
    # Remove batch and channel dims
    out_squeezed = jnp.squeeze(out, axis=(0, 4))
    
    # Create boolean mask
    mask = out_squeezed == 8
    
    # [G] The source code snippet `mask = np.array(out == 8)` suggests 
    # the output might be kept at size S or cropped later. 
    # Standard 2x2x2 block detection on an SxSxS grid yields (S-1)x(S-1)x(S-1) blocks.
    # If the implementation requires strict block indices, we crop.
    # If it's a dense mask for visualization, we keep S.
    # Given the sibling "Bounding Volume Optimization" handles trimming, 
    # we return the full SxSxS mask or crop if specified. 
    # The source does not explicitly crop, so we return SxSxS.
    
    return mask
```

**Parameters:**
- Threshold: 0. Voxel is occupied if density > 0.
- Block Size: 2x2x2.
- Kernel: All ones.

**Edge Cases:**
- **Empty Density:** If all densities are $\le 0$, the mask is all False.
- **Single Voxel:** If $S=1$, no 2x2x2 blocks exist. The convolution output will be 0 or 1, never 8. Mask is all False.
- **Precision:** Floating point comparisons `== 8` are safe here because the kernel is integer ones and input is integer 0/1. Sum is exact.

## Operating characteristics
**Time Complexity:** $O(S^3)$ for thresholding and $O(S^3)$ for convolution. Total $O(S^3)$.
**Memory Complexity:** $O(S^3)$ for input, output, and kernel.
**Performance:** Highly parallelizable on GPU via JAX. Convolution is efficient.
**Strengths:** Simple, fast, reduces data size by factor of 8 (if all blocks are full) or more.
**Limitations:** Loses internal structure of 2x2x2 blocks. Only detects "solid" blocks.

## Background
Originated in the context of JAX-based volumetric rendering pipelines. Used to simplify voxel data for efficient rendering or neural network training by reducing the number of active voxels.
