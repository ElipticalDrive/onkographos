# Occupancy Voxel Creation
## Overview
Occupancy Voxel Creation converts a continuous density matrix into a discrete boolean occupancy mask and identifies fully occupied 2x2x2 blocks via convolution. It differs from [3D Voxel Grid Smoothing](833-3d-voxel-grid-smoothing.md) by using hard thresholding rather than smoothing filters, and from [Binary Voxel RLE Encoding](1071-binary-voxel-rle-encoding.md) by producing a structural mask of coherent blocks rather than a compressed bitstream. It serves as a preprocessing step for [Mark Invisible Cells](4648-mark-invisible-cells.md) by establishing the initial occupancy state.
## How it works
**Inputs:** A 3D density matrix $D$ of shape $(S, S, S)$, where $S$ is the side length.
**Outputs:** A boolean mask $M$ of shape $(S-1, S-1, S-1)$ indicating the top-left corner of each fully occupied 2x2x2 block.

**Data Structures:**
- `occupancy_mat`: Binary matrix of shape $(S, S, S)$, values $\{0, 1\}$.
- `kernel`: 3D tensor of shape $(2, 2, 2)$, all elements $1$.
- `out`: Convolution result of shape $(S, S, S)$, values $\in [0, 8]$.
- `mask`: Boolean matrix of shape $(S-1, S-1, S-1)$.

**Steps:**
1. **Thresholding:** Convert density to binary occupancy. For each voxel $v$ in $D$:
   $$
   \text{occupancy\_mat}[v] = \begin{cases} 1 & \text{if } D[v] > 0 \\ 0 & \text{otherwise} \end{cases}
   $$
   [S1, unofficial]

2. **Reshape for Convolution:** Prepare data for JAX convolution by adding batch and channel dimensions. Let $data = \text{occupancy\_mat}$.
   $$
   data_{\text{jax}} = data[\text{None}, :, :, :, \text{None}]
   $$
   Shape becomes $(1, S, S, S, 1)$. [S1, unofficial]

3. **Define Kernel:** Create a 2x2x2 kernel of ones.
   $$
   \text{kernel} = \mathbf{1}_{2 \times 2 \times 2}
   $$
   Reshaped to $(2, 2, 2, 1, 1)$ for JAX `conv_general_dilated`. [S1, unofficial]

4. **Convolution:** Perform 3D convolution with stride 1 and 'SAME' padding.
   $$
   out = \text{conv\_general\_dilated}(data_{\text{jax}}, \text{kernel}, \text{strides}=(1,1,1), \text{padding}='SAME', \text{dilation}=(1,1,1))
   $$
   The output $out$ has shape $(1, S, S, S, 1)$. Each element represents the sum of the 8 voxels in the 2x2x2 block starting at that coordinate. [S1, unofficial]

5. **Mask Extraction:** Identify blocks where all 8 voxels are occupied.
   $$
   mask = (out == 8)
   $$
   The result is a boolean mask of shape $(S-1, S-1, S-1)$ (excluding boundary effects if 'SAME' padding is used strictly, or $(S, S, S)$ if padded; typically cropped to valid 2x2x2 blocks). [S1, unofficial]

**Pseudocode:**
```python
import jax.numpy as jnp
from jax.lax import conv_general_dilated

def create_occupancy_voxels(density_matrix: jnp.ndarray) -> jnp.ndarray:
    """
    Converts a density matrix to a boolean occupancy mask of fully occupied 2x2x2 blocks.
    
    Args:
        density_matrix: 3D array of shape (S, S, S) with density values.
        
    Returns:
        mask: 3D boolean array of shape (S-1, S-1, S-1) indicating top-left corners 
              of fully occupied 2x2x2 blocks.
    """
    # Step 1: Threshold density to binary occupancy
    # Values > 0 become 1, others 0
    occupancy_mat = (density_matrix > 0).astype(jnp.float32)
    
    # Step 2: Reshape for JAX convolution (add batch and channel dims)
    # Shape: (1, S, S, S, 1)
    data = occupancy_mat[None, :, :, :, None]
    
    # Step 3: Define 2x2x2 kernel of ones
    # Shape: (2, 2, 2, 1, 1)
    kernel = jnp.ones([2, 2, 2])[:, :, :, jnp.newaxis, jnp.newaxis]
    
    # Step 4: Perform convolution
    # Strides: (1, 1, 1), Padding: SAME, Dilation: (1, 1, 1)
    # Output shape: (1, S, S, S, 1)
    out = conv_general_dilated(
        data, 
        kernel, 
        window_strides=(1, 1, 1), 
        padding='SAME', 
        lhs_dilation=(1, 1, 1), 
        rhs_dilation=(1, 1, 1)
    )
    
    # Step 5: Extract mask where sum equals 8 (all 8 voxels occupied)
    # out is (1, S, S, S, 1), squeeze to (S, S, S)
    # The valid 2x2x2 blocks are typically those where the top-left corner 
    # allows a full 2x2x2 block within bounds. With 'SAME' padding, 
    # boundary blocks include padded zeros, so out==8 only happens for 
    # fully occupied internal blocks.
    mask = (out.squeeze() == 8)
    
    # Crop to (S-1, S-1, S-1) to represent valid 2x2x2 block origins
    # Note: The exact crop depends on implementation details of 'SAME' padding 
    # and whether boundary voxels are considered. 
    # If out is (S, S, S), the valid origins for 2x2x2 blocks are (0..S-2, 0..S-2, 0..S-2).
    return mask[:-1, :-1, :-1]
```
[G] The final cropping to $(S-1, S-1, S-1)$ assumes that the convolution output includes boundary voxels that cannot form a complete 2x2x2 block with valid neighbors. The source code snippet implies using the result directly, but logically, a 2x2x2 block starting at index $S-1$ would extend to $S+1$, which is out of bounds. Thus, the mask is typically valid for indices $0$ to $S-2$.

## Subtopics

### [Mark Invisible Cells](4648-mark-invisible-cells.md)
Marks voxels not visible to any training camera as -1. Chosen when visibility culling is required before training. Differs by focusing on visibility rather than density-based block detection.

## Operating characteristics
**Time Complexity:** $O(S^3)$ for thresholding and $O(S^3)$ for convolution, where $S$ is the side length. The convolution is the dominant operation.
**Memory Complexity:** $O(S^3)$ for storing the density matrix, occupancy matrix, and convolution output.
**Performance:** Efficient on GPU due to JAX convolution optimization. [S1, unofficial]
**Strengths:** Simple, differentiable (if using soft thresholding, though this method uses hard thresholding), and effectively reduces noise by requiring full 2x2x2 occupancy.
**Limitations:** Hard thresholding is non-differentiable. Boundary effects may require careful handling. [S1, unofficial]
**When to use:** When a sparse representation of fully occupied blocks is needed for efficient rendering or training.
**When not to use:** When partial occupancy or smooth density gradients are required.
