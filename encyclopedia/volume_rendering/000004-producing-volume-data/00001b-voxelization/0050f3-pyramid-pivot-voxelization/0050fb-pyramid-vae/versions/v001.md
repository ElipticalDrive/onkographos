# Pyramid VAE

Also called: Pyramid VAE decoder, Pyramid VAE encoder

## Overview
The Pyramid VAE is a Variational Autoencoder that learns compact, multi-resolution latent codes over locally reconstructable pivot blocks, avoiding the memory cost of modeling an entire high-resolution voxelized shape as a dense global field [S1, unofficial]. It differs from uniform voxelization methods by exploiting spatial non-uniformity: it allocates high-resolution tokens to geometrically complex regions (silhouettes, sharp boundaries) while keeping smooth regions coarse and compact [S1, unofficial]. It builds on [Pyramid Pivot Voxelization](14366-pyramid-pivot-voxelization.md), which provides the adaptive sampling map $M$ and pivot tokens $T_{pyr}$ that the VAE encodes.

## How it works
The method processes pyramid pivot tokens extracted from watertight meshes voxelized at a global resolution of $512^3$. It organizes these tokens into multi-resolution block tensors according to the sampling map $M$, where each level corresponds to a sampling resolution within macro-blocks of size $B$. The model uses hierarchical 3D convolutional stages to aggregate features and reconstruct pivot tokens, enabling efficient mesh reconstruction for downstream 3D tasks [S1, unofficial].

### Inputs and Outputs
*   **Input:** Pyramid pivot tokens $T_{pyr}$ organized by the sampling map $M$. Each input token contains 4 channels: a relative 3D pivot coordinate $(p_x, p_y, p_z)$ and a discrete sign value $s \in \{-1, 0, +1\}$ [S1, unofficial].
*   **Output:** Reconstructed pivot-token grids at multiple resolutions. The decoder predicts 6 channels per token: three relative coordinate channels and three sign logits for classes $\{-1, 0, +1\}$ [S1, unofficial].

### Data Structures
*   **Sampling Map $M$:** Defines the spatial allocation of sampling resolutions. It guides each active macro-block to reconstruct at its assigned resolution. The resolutions used are $R \in \{32, 16, 8\}$ [S1, unofficial].
*   **Latent Code $z$:** A shared pyramid latent representation $z = \{z_n\}_{n=1}^N$ with $C_z = 16$ channels. The encoder predicts both the posterior mean and log-variance for this latent space [S1, unofficial].
*   **Block Structure:** Each local block has a maximum resolution of $R_{max} = 32$. The model is trained over three pyramid stages corresponding to these resolutions [S1, unofficial].

### Architecture
The architecture consists of an Encoder and a Decoder, both using hierarchical 3D convolutional stages with Layer Normalization and SiLU activations [S1, unofficial].

**Encoder:**
*   Uses hierarchical 3D CNN branches to aggregate block-wise geometric features from coarse to fine levels.
*   Channel widths: $[32, 64, 128, 256]$.
*   Each stage contains two residual blocks.
*   The bottleneck contains two residual blocks.
*   Outputs the latent code $z \sim q_\phi(z | T_{pyr}, M)$ [S1, unofficial].

**Decoder:**
*   Mirrors the encoder hierarchy to reconstruct pivot-token grids at multiple resolutions.
*   Channel widths: $[512, 256, 128, 64]$.
*   Each stage contains two residual blocks.
*   The bottleneck contains two residual blocks.
*   Maps the latent grid ($C_z=16$) to multi-resolution token predictions. Each output head predicts 6 channels (3 coordinates, 3 sign logits) [S1, unofficial].

### Training Procedure
The model is trained end-to-end with a multi-stage strategy.

1.  **Stage Sampling:** At each iteration, one pyramid stage is randomly sampled according to weights $w_{32} : w_{16} : w_8 = 5 : 3 : 2$ (probabilities $0.5, 0.3, 0.2$). This emphasizes the finest stage while exposing the model to coarser levels. In distributed training, the selected stage is synchronized across processes [S1, unofficial].
2.  **Optimization:** AdamW optimizer with an initial learning rate of $5 \times 10^{-6}$ and cosine annealing over 500 epochs. Precision is FP32. Gradient clipping is applied at norm 1.0. Block batch size is 64, mini-batch size is 2. Random seed is 1234 [S1, unofficial].
3.  **Loss Function:** The objective is a weighted sum of four terms:
    $$ L = \lambda_{xyz} L_{xyz} + \lambda_{empty} L_{empty} + \lambda_{sign} L_{sign} + \lambda_{KL} L_{KL} $$
    Where:
    *   $\lambda_{xyz} = 1.0$
    *   $\lambda_{empty} = 0.01$
    *   $\lambda_{sign} = 0.5$
    *   $\lambda_{KL} = 10^{-4}$
    *   $L_{xyz}$: $\ell_1$ coordinate reconstruction loss applied only to occupied voxels [S1, unofficial].
    *   $L_{empty}$: Penalizes non-zero coordinate predictions in empty voxels to prevent spurious surface evidence [S1, unofficial].
    *   $L_{sign}$: Weighted three-class cross-entropy loss for sign labels $\{-1, 0, +1\}$ with class weights $(1.0, 0.25, 1.0)$ to balance occupied and empty states [S1, unofficial].
    *   $L_{KL}$: Regularizes the latent posterior toward a standard Gaussian prior [S1, unofficial].

### Pseudocode

```python
import torch
import torch.nn as nn
import torch.nn.functional as F

class ResBlock3D(nn.Module):
    """Standard 3D Residual Block with LayerNorm and SiLU."""
    def __init__(self, in_channels, out_channels, kernel_size=3):
        super().__init__()
        self.conv1 = nn.Conv3d(in_channels, out_channels, kernel_size, padding=1)
        self.norm1 = nn.LayerNorm(out_channels)
        self.conv2 = nn.Conv3d(out_channels, out_channels, kernel_size, padding=1)
        self.norm2 = nn.LayerNorm(out_channels)
        self.skip = nn.Conv3d(in_channels, out_channels, 1) if in_channels != out_channels else nn.Identity()
        
    def forward(self, x):
        residual = self.skip(x)
        out = self.conv1(x)
        out = self.norm1(out.permute(0, 2, 3, 4, 1)).permute(0, 4, 1, 2, 3) # LayerNorm on channel dim
        out = F.silu(out)
        out = self.conv2(out)
        out = self.norm2(out.permute(0, 2, 3, 4, 1)).permute(0, 4, 1, 2, 3)
        out = F.silu(out + residual)
        return out

class PyramidVAEEncoder(nn.Module):
    """
    Encoder for Pyramid VAE.
    Channels: [32, 64, 128, 256]
    Input: Tokens with 4 channels (3 coord, 1 sign)
    Output: Latent z with 16 channels (mean and log_var)
    """
    def __init__(self, C_z=16):
        super().__init__()
        # Stage 1
        self.enc1 = nn.Sequential(
            nn.Conv3d(4, 32, 3, padding=1),
            ResBlock3D(32, 32),
            ResBlock3D(32, 32)
        )
        # Stage 2
        self.down2 = nn.Conv3d(32, 64, 2, stride=2)
        self.enc2 = nn.Sequential(
            nn.Conv3d(64, 64, 3, padding=1),
            ResBlock3D(64, 64),
            ResBlock3D(64, 64)
        )
        # Stage 3
        self.down3 = nn.Conv3d(64, 128, 2, stride=2)
        self.enc3 = nn.Sequential(
            nn.Conv3d(128, 128, 3, padding=1),
            ResBlock3D(128, 128),
            ResBlock3D(128, 128)
        )
        # Stage 4 (Bottleneck)
        self.down4 = nn.Conv3d(128, 256, 2, stride=2)
        self.bottleneck = nn.Sequential(
            nn.Conv3d(256, 256, 3, padding=1),
            ResBlock3D(256, 256),
            ResBlock3D(256, 256)
        )
        # Latent projection
        self.latent_proj = nn.Conv3d(256, 2 * C_z, 3, padding=1)

    def forward(self, x):
        # x shape: (B, 4, D, H, W)
        h = self.enc1(x)
        h = self.down2(h)
        h = self.enc2(h)
        h = self.down3(h)
        h = self.enc3(h)
        h = self.down4(h)
        h = self.bottleneck(h)
        stats = self.latent_proj(h) # (B, 2*C_z, D, H, W)
        
        mean, log_var = torch.chunk(stats, 2, dim=1)
        return mean, log_var

class PyramidVAEDecoder(nn.Module):
    """
    Decoder for Pyramid VAE.
    Channels: [512, 256, 128, 64]
    Input: Latent z with 16 channels
    Output: Tokens with 6 channels (3 coord, 3 sign logits)
    """
    def __init__(self, C_z=16):
        super().__init__()
        # Bottleneck
        self.bottleneck = nn.Sequential(
            nn.Conv3d(C_z, 256, 3, padding=1),
            ResBlock3D(256, 256),
            ResBlock3D(256, 256)
        )
        # Stage 4
        self.up4 = nn.ConvTranspose3d(256, 128, 2, stride=2)
        self.dec4 = nn.Sequential(
            nn.Conv3d(128, 128, 3, padding=1),
            ResBlock3D(128, 128),
            ResBlock3D(128, 128)
        )
        # Stage 3
        self.up3 = nn.ConvTranspose3d(128, 64, 2, stride=2)
        self.dec3 = nn.Sequential(
            nn.Conv3d(64, 64, 3, padding=1),
            ResBlock3D(64, 64),
            ResBlock3D(64, 64)
        )
        # Stage 2
        self.up2 = nn.ConvTranspose3d(64, 32, 2, stride=2)
        self.dec2 = nn.Sequential(
            nn.Conv3d(32, 32, 3, padding=1),
            ResBlock3D(32, 32),
            ResBlock3D(32, 32)
        )
        # Stage 1
        self.up1 = nn.ConvTranspose3d(32, 16, 2, stride=2)
        self.dec1 = nn.Sequential(
            nn.Conv3d(16, 16, 3, padding=1),
            ResBlock3D(16, 16),
            ResBlock3D(16, 16)
        )
        # Output head: 3 coord channels + 3 sign logits
        self.output_head = nn.Conv3d(16, 6, 3, padding=1)

    def forward(self, z):
        # z shape: (B, C_z, D, H, W)
        h = self.bottleneck(z)
        h = self.up4(h)
        h = self.dec4(h)
        h = self.up3(h)
        h = self.dec3(h)
        h = self.up2(h)
        h = self.dec2(h)
        h = self.up1(h)
        h = self.dec1(h)
        out = self.output_head(h) # (B, 6, D, H, W)
        return out

def sample_z(mean, log_var):
    """Reparameterization trick."""
    std = torch.exp(0.5 * log_var)
    eps = torch.randn_like(std)
    return mean + eps * eps

def compute_loss(pred_coords, pred_sign_logits, target_coords, target_signs, occupied_mask):
    """
    Computes the total loss L.
    pred_coords: (B, 3, D, H, W)
    pred_sign_logits: (B, 3, D, H, W)
    target_coords: (B, 3, D, H, W)
    target_signs: (B, 1, D, H, W) integer labels {-1, 0, 1}
    occupied_mask: (B, 1, D, H, W) boolean mask for occupied voxels
    """
    # L_xyz: L1 loss on occupied voxels
    # Note: Source says "applied only to occupied voxels". 
    # We mask the coordinates. Empty voxels in target might be arbitrary, 
    # but L_empty handles the prediction penalty.
    if occupied_mask.sum() > 0:
        l_xyz = F.l1_loss(pred_coords[occupied_mask], target_coords[occupied_mask])
    else:
        l_xyz = torch.tensor(0.0, device=pred_coords.device)
        
    # L_empty: Penalize non-zero coords in empty voxels
    # Source: "Penalizes non-zero coordinate predictions in empty voxels"
    empty_mask = ~occupied_mask
    if empty_mask.sum() > 0:
        # Penalize magnitude of predicted coords where empty
        l_empty = F.l1_loss(pred_coords[empty_mask], torch.zeros_like(pred_coords[empty_mask]))
    else:
        l_empty = torch.tensor(0.0, device=pred_coords.device)
        
    # L_sign: Weighted cross-entropy
    # Classes: {-1, 0, 1}. Map to indices 0, 1, 2.
    # Weights: (1.0, 0.25, 1.0)
    # pred_sign_logits shape (B, 3, D, H, W). Target signs need to be long tensor.
    # Reshape for CrossEntropyLoss: (N, C, ...) -> (N, C, H, W, D) or similar.
    # Standard CrossEntropy expects (N, C, ...) where N is batch*H*W*D
    b, c, d, h, w = pred_sign_logits.shape
    pred_logits_flat = pred_sign_logits.permute(0, 2, 3, 4, 1).contiguous().view(-1, 3)
    target_signs_flat = target_signs.squeeze(1).long().view(-1)
    
    # Map -1 -> 0, 0 -> 1, 1 -> 2
    target_indices = target_signs_flat + 1
    
    weights = torch.tensor([1.0, 0.25, 1.0], device=pred_sign_logits.device)
    l_sign = F.cross_entropy(pred_logits_flat, target_indices, weight=weights)
    
    # L_KL: Standard KL divergence to N(0,1)
    # mean, log_var are from encoder
    # This function is called after sampling, but we need mean/log_var for KL
    # Assuming mean/log_var are passed or computed externally. 
    # For this pseudocode, we assume they are available in the scope or passed.
    # Here we just define the term.
    return l_xyz, l_empty, l_sign

def pyramid_vae_forward(encoder, decoder, tokens, sampling_map, stage_resolution):
    """
    Single forward pass for a specific stage.
    tokens: Input tokens organized by sampling_map for the given stage_resolution.
    """
    # 1. Encode
    mean, log_var = encoder(tokens)
    z = sample_z(mean, log_var)
    
    # 2. Decode
    pred_tokens = decoder(z)
    
    # 3. Post-processing (Conceptual)
    # Filter predicted blocks, lift to max grid, stitch through shared corner-value consistency
    # for Sparse-MC reconstruction.
    # This step is external to the VAE loss calculation but part of the pipeline.
    
    return pred_tokens, mean, log_var

def train_step(encoder, decoder, optimizer, tokens, sampling_map, stage_resolution):
    """
    One training iteration.
    """
    optimizer.zero_grad()
    
    pred_tokens, mean, log_var = pyramid_vae_forward(encoder, decoder, tokens, sampling_map, stage_resolution)
    
    # Extract predictions
    pred_coords = pred_tokens[:, :3, :, :, :]
    pred_sign_logits = pred_tokens[:, 3:, :, :, :]
    
    # Ground truth is in 'tokens'
    target_coords = tokens[:, :3, :, :, :]
    target_signs = tokens[:, 3:, :, :, :] # Assuming one-hot or similar, need to convert to class indices
    
    # Determine occupied mask based on target signs or geometry
    # Source implies occupied voxels are those with valid surface evidence.
    # For simplicity, assume a mask is provided or derived from target_signs != 0 (if 0 is empty)
    # Source says sign labels are {-1, 0, 1}. 0 is likely empty or ambiguous.
    # Let's assume occupied if sign != 0.
    occupied_mask = (target_signs.abs() > 0.5) 
    
    l_xyz, l_empty, l_sign = compute_loss(pred_coords, pred_sign_logits, target_coords, target_signs, occupied_mask)
    
    # KL Loss
    l_kl = -0.5 * torch.sum(1 + log_var - mean.pow(2) - log_var.exp())
    l_kl = l_kl / mean.numel() # Normalize
    
    # Total Loss
    lambda_xyz = 1.0
    lambda_empty = 0.01
    lambda_sign = 0.5
    lambda_kl = 1e-4
    
    loss = (lambda_xyz * l_xyz + 
            lambda_empty * l_empty + 
            lambda_sign * l_sign + 
            lambda_kl * l_kl)
            
    loss.backward()
    
    # Gradient clipping
    torch.nn.utils.clip_grad_norm_(encoder.parameters(), 1.0)
    torch.nn.utils.clip_grad_norm_(decoder.parameters(), 1.0)
    
    optimizer.step()
    
    return loss.item()
```

### Edge Cases and Pitfalls
*   **Empty Voxels:** The $L_{empty}$ term is critical to prevent the model from predicting spurious surface evidence in inactive regions. Without it, the model might generate noise in empty space [S1, unofficial].
*   **Sign Balance:** The sign loss uses class weights $(1.0, 0.25, 1.0)$ to balance occupied states ($\pm 1$) against empty states ($0$). Imbalance here can lead to biased surface orientation [S1, unofficial].
*   **Distributed Training:** When using distributed training, the randomly sampled stage must be synchronized across all processes to ensure consistent batch composition [S1, unofficial].
*   **Memory:** Validation reconstruction is disabled in the reported configuration for memory efficiency, as full reconstruction validation is optional [S1, unofficial].

## Operating characteristics
*   **Time Complexity:** Training is multi-stage, sampling one of three resolutions ($R \in \{32, 16, 8\}$) per iteration. The finest stage ($R=32$) is sampled with probability 0.5, making it the dominant computational cost.
*   **Memory Complexity:** By avoiding dense global voxel fields and using local block tensors, the method significantly reduces memory usage compared to monolithic voxel representations. The latent code is compact ($C_z=16$) [S1, unofficial].
*   **Performance:** On the ABO dataset, Pivot512 (using this method) reaches reconstruction quality comparable to FaithC with fewer active voxels. It demonstrates effective multi-scale budget allocation, with higher-resolution tokens concentrating around silhouettes and sharp boundaries [S1, unofficial].
*   **Strengths:** Compact representation, efficient memory usage, adaptive resolution allocation.
*   **Limitations:** Requires watertight meshes for voxelization. Multi-stage training adds complexity to the training loop.

## Background
The Pyramid VAE was introduced in the paper "P2Voxel: Pyramid Pivot Voxelization for 3D Mesh Tokenization" [S1, unofficial]. It addresses the memory inefficiency of learning global high-resolution voxel fields, which is difficult even with sparse convolutional techniques. By leveraging the "Block Reconstructability" assumption, it allows for local surface evidence sampling, converting meshes into compact, structured, and learnable pyramid pivot tokens for scalable 3D mesh reconstruction. The method is part of the P2Voxel framework, which also includes Pyramid Pivot Voxelization [S1, unofficial].
