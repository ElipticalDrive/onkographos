# Direct Illumination with Shadow Rays

Also called: Direct Lighting with Shadows, Direct Lighting with Volume Transmittance, Direct Radiance with Volumetric Transmittance, Shadow Ray Illumination, Shadow Ray Lighting

## Overview
Direct Illumination with Shadow Rays computes the direct lighting contribution at a surface point within or on the boundary of a volume, accounting for attenuation by heterogeneous participating media between the surface and the light source [S1, S2, unofficial]. It builds on [Local illumination, shadows and ambient occlusion](34-local-illumination-shadows-and-ambient-occlusion.md) by explicitly evaluating directional light sources through volumetric transmittance rather than approximating indirect hemispherical illumination.

## How it works
**Inputs:**
*   Surface point $\mathbf{p}$ and surface normal $\mathbf{n}$ [S2, S3, unofficial].
*   List of light sources, each defined by position $\mathbf{l}_i$, color $C_{light, i}$, enabled flag, and optionally area $A_i$ [S1, S2, unofficial].
*   Volume extinction coefficient $\sigma_t$ accessible via a volume integrator or sampler [S1, S4, unofficial].
*   Surface material properties (diffuse color, specular parameters, roughness) [S2, S4, unofficial].

**Outputs:**
*   Direct radiance contribution $L_{direct}$ at $\mathbf{p}$ [S1, S2, unofficial].

**Data Structures:**
*   **Light:** Struct containing `position` (vec3), `color` (vec3), `enabled` (bool/uint), and `area` (float, for PDF calculation) [S1, S2, unofficial].
*   **HitSurface:** Struct containing `hit_point` (vec3), `normal` (vec3), and `material` properties [S3, unofficial].
*   **Ray:** Struct containing `origin` (vec3) and `direction` (vec3) [S3, S4, unofficial].
*   **IntersectionResult:** Struct containing `t` (distance to hit, -1 if none) and `d` (distance to light source for comparison) [S3, unofficial].

**Steps:**
1.  **Initialize Accumulator:** Set direct lighting accumulator $L_{direct} = \mathbf{0}$ [S2, unofficial].
2.  **Iterate Lights:** For each light source $i$ in the light list:
    a.  **Skip Disabled:** If light $i$ is disabled, skip to next light [S2, unofficial].
    b.  **Compute Light Vector:** Calculate vector $\mathbf{L} = \mathbf{l}_i - \mathbf{p}$ and distance $d_{light} = \|\mathbf{L}\|$ [S2, S3, unofficial].
    c.  **Normalize Direction:** $\mathbf{w}_i = \mathbf{L} / d_{light}$ [S1, unofficial].
    d.  **Cast Shadow Ray:** Create a shadow ray originating at $\mathbf{p}_{shadow} = \mathbf{p} + \epsilon \mathbf{n}$ (where $\epsilon$ is a small offset, e.g., $0.01 \times \|\mathbf{n}\|$) in direction $\mathbf{w}_i$ [S3, unofficial].
    e.  **March Shadow Ray:** Evaluate transmittance or occlusion along the shadow ray up to distance $d_{light}$ [S1, S3, S4, unofficial].
        *   **Binary Occlusion:** If an opaque object intersects the ray at distance $t < d_{light}$, visibility $V = 0$, else $V = 1$ [S1, S3, unofficial].
        *   **Volumetric Transmittance:** Integrate extinction coefficient $\sigma_t$ along the ray using fixed steps (e.g., 16 steps) to compute $T_{light} = \exp(-\int \sigma_t ds)$ [S1, S4, unofficial].
    f.  **Compute Geometric Term:** $G = \max(0, \mathbf{n} \cdot \mathbf{w}_i) \cdot |\mathbf{w}_i \cdot \mathbf{l}_n| / d_{light}^2$, where $\mathbf{l}_n$ is the light normal (or $1$ for point lights) [S1, S2, unofficial].
    g.  **Compute BRDF Contribution:**
        *   **Diffuse:** $L_{diff} = C_{light, i} \cdot C_{diffuse} \cdot G \cdot V \cdot T_{light} / p_y$, where $p_y = 1/A_i$ is the probability density for area lights [S1, unofficial].
        *   **Specular:** If enabled, compute $L_{spec} = C_{light, i} \cdot C_{specular} \cdot T_{light} \cdot \max(0, \mathbf{H} \cdot \mathbf{n})^{\alpha}$, with half-vector $\mathbf{H} = \text{normalize}(\mathbf{w}_i + \mathbf{V})$ and shininess $\alpha = 1/\text{roughness}$ [S4, unofficial].
    h.  **Accumulate:** $L_{direct} += L_{diff} + L_{spec}$ [S2, S4, unofficial].
3.  **Return:** Return $L_{direct}$ [S2, unofficial].

**Pseudocode:**
```python
import math

class Vec3:
    def __init__(self, x, y, z):
        self.x, self.y, self.z = x, y, z
    def __add__(self, other): return Vec3(self.x+other.x, self.y+other.y, self.z+other.z)
    def __sub__(self, other): return Vec3(self.x-other.x, self.y-other.y, self.z-other.z)
    def __mul__(self, s): return Vec3(self.x*s, self.y*s, self.z*s)
    def __rmul__(self, s): return self.__mul__(s)
    def dot(self, other): return self.x*other.x + self.y*other.y + self.z*other.z
    def length(self): return math.sqrt(self.x**2 + self.y**2 + self.z**2)
    def normalized(self): l = self.length(); return Vec3(self.x/l, self.y/l, self.z/l) if l > 1e-6 else Vec3(0,0,0)

class Ray:
    def __init__(self, origin, direction):
        self.origin = origin
        self.direction = direction

def direct_illumination_with_shadow_rays(p, normal, lights, volume_sampler, view_dir):
    """
    Computes direct lighting at point p considering volume shadows.
    Args:
        p: Vec3, surface position
        normal: Vec3, surface normal
        lights: list of Light objects
        volume_sampler: object with method extinction_at(pos) returning sigma_t
        view_dir: Vec3, view direction (for specular)
    Returns:
        Vec3, direct lighting contribution
    """
    direct_light = Vec3(0.0, 0.0, 0.0)
    
    for light in lights:
        if not light.enabled:
            continue
            
        # 1. Compute light vector and distance
        delta = light.position - p
        l_dist = delta.length()
        if l_dist < 1e-6:
            continue
            
        w_i = delta.normalized()
        
        # 2. Cast shadow ray
        epsilon = 0.01 * normal.length()
        shadow_origin = p + epsilon * normal
        shadow_ray = Ray(shadow_origin, w_i)
        
        # 3. Evaluate transmittance via discrete integration (16 steps)
        num_samples = 16
        delta_s = l_dist / num_samples
        optical_depth = 0.0
        
        for i in range(num_samples):
            pos = shadow_ray.origin + shadow_ray.direction * (i * delta_s)
            sigma_t = volume_sampler.extinction_at(pos)
            optical_depth += sigma_t * delta_s
            
        T_light = math.exp(-optical_depth)
        
        # 4. Compute geometric term
        n_dot_l = max(0.0, normal.dot(w_i))
        
        # 5. Compute BRDF contribution (diffuse + specular)
        p_y = 1.0 / light.area if light.area > 0 else 1.0
        diffuse_term = light.color * n_dot_l * T_light / (l_dist * l_dist * p_y)
        
        h = (w_i + view_dir.normalized()).normalized()
        n_dot_h = max(0.0, normal.dot(h))
        shininess = 32.0
        specular_term = light.color * T_light * (n_dot_h ** shininess)
        
        # Accumulate
        direct_light = direct_light + diffuse_term + specular_term
        
    return direct_light
```

**Parameters:**
*   `num_samples`: Number of steps for shadow ray integration. Typical value: 16 [S1, unofficial].
*   `epsilon`: Offset for shadow ray origin. Typical value: $0.01 \times \|\mathbf{n}\|$ [S3, unofficial].
*   `MAX_LIGHTS`: Maximum number of lights to process. Value: 8 [S2, unofficial].

**Edge Cases and Pitfalls:**
*   **Self-Shadowing:** Failing to offset the shadow ray origin causes self-intersection artifacts. An offset $\epsilon$ is required [S3, unofficial].
*   **Precision:** In highly heterogeneous volumes, large step sizes $\Delta s$ may miss thin high-density regions, leading to inaccurate transmittance [G].
*   **Boundary Conditions:** If the light source is inside the volume, the shadow ray integration must handle the exit from the volume boundary correctly [G].
*   **Degenerate Input:** If $\mathbf{n}$ is zero or $\mathbf{L}$ is zero, the method is undefined. Guard against division by zero in distance and normalization [G].

## Subtopics

### [Shadow Ray Transmittance Estimation](5248-shadow-ray-transmittance-estimation.md)
Estimates transmittance from a surface point to a distant light source through participating media using majorant sampling. It differs from the base method by using stochastic sampling for transmittance estimation rather than deterministic integration. Choose this when performance is critical and the volume is large.

### [Voxel Direct Lighting and Shadowing](6610-voxel-direct-lighting-and-shadowing.md)
Computes local illumination and shadows in voxel-based scenes by casting shadow rays from surface positions toward light sources. It differs from [Shadow Ray Transmittance Estimation](5248-shadow-ray-transmittance-estimation.md) by using binary hit/miss results for shadowing rather than estimating transmittance through participating media. It builds on [Direct Illumination with Shadow Rays](2011-direct-illumination-with-shadow-rays.md). Choose this for voxel-based rendering where binary occlusion is sufficient.

### Transparent Shadows
A shadowing technique where shadow rays cross smooth glass in a straight line, and paths refracted to a light already reached that way do not count as reaching the light [S5, unofficial]. This is a variant of shadow ray casting used in stylized voxel rendering to handle transparent materials without complex refraction tracing. Choose this for stylized rendering with transparent objects.

## Operating characteristics
*   **Time and Memory Complexity:** Not given in the sources.
*   **Scaling:** Performance scales linearly with the number of lights and shadow ray samples [S1, S2, unofficial].
*   **Strengths:** Simple to implement; provides accurate volumetric shadows for direct lighting; works with any volume representation accessible via sampling [S1, S4, unofficial].
*   **Limitations:** Does not account for multiple scattering or indirect illumination; noisy if sample count is low in heterogeneous media; expensive for many lights [S1, S2, unofficial].
*   **When to Use:** Real-time or offline rendering where direct lighting shadows are required in participating media [G].
*   **When Not to Use:** When full global illumination (multiple bounces) is needed; when the volume is extremely large and sparse (use [Shadow Ray Transmittance Estimation](5248-shadow-ray-transmittance-estimation.md) instead) [G].

## Background
The method is a fundamental component of local illumination models in volume rendering, extending surface-based shadow ray casting to account for volumetric extinction [S1, S4, unofficial]. It is widely used in real-time voxel-based renderers (e.g., MagicaVoxel) and offline path tracers for accurate shadowing in fog, smoke, and clouds [S1, S3, S5, unofficial].
