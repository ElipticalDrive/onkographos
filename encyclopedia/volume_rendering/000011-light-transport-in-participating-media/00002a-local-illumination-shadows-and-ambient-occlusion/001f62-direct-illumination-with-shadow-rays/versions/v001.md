# Direct Illumination with Shadow Rays

Also called: Direct Lighting with Shadows, Direct Lighting with Volume Transmittance, Direct Radiance with Volumetric Transmittance, Shadow Ray Illumination, Shadow Ray Lighting

## Overview
Computes the direct lighting contribution at a surface point (or volume sample) by casting shadow rays toward light sources, accounting for attenuation by heterogeneous participating media between the point and the light [S1, S2, unofficial]. It differs from pure surface shadowing by integrating volumetric transmittance along the ray path, and from full path tracing by only evaluating direct illumination from explicit light sources rather than indirect bounces [S1, S2, unofficial].

## How it works
**Inputs:**
- Hit point position $\mathbf{p}$ and surface normal $\mathbf{n}$ [S2, S3, unofficial].
- List of light sources, each with position $\mathbf{l}_i$, color/intensity $\mathbf{C}_i$, and optionally area/normal [S1, S2, unofficial].
- Volume density/extinction coefficient field $\sigma_t(\mathbf{x})$ [S1, S6, unofficial].
- Surface material properties (diffuse color, specular, roughness, metallic) [S2, S3, unofficial].
- Camera/view direction $\mathbf{V}$ for specular calculations [S3, unofficial].

**Outputs:**
- Direct illumination radiance $\mathbf{L}_{direct}$ at $\mathbf{p}$ [S1, S2, unofficial].

**Data Structures:**
- Light structure: `struct Light { vec3 position; vec3 color; bool enabled; float area; }` [S2, unofficial].
- Shadow ray result: `struct Intersection { float t; vec3 hit_point; bool hit; }` [S3, unofficial].
- Volume integrator interface: `Transmittance(Ray)` returns scalar transmittance [S4, unofficial].

**Steps:**
1. Initialize accumulated light color $\mathbf{L}_{direct} = \mathbf{0}$ [S2, unofficial].
2. For each light $i$ in the light list:
   a. If light $i$ is disabled, skip [S2, unofficial].
   b. Compute light direction $\mathbf{L} = \mathbf{l}_i - \mathbf{p}$ and distance $d = \|\mathbf{L}\|$ [S2, S4, unofficial].
   c. Normalize direction: $\mathbf{w}_i = \mathbf{L} / d$ [S1, unofficial].
   d. Create a shadow ray starting from $\mathbf{p} + \epsilon \mathbf{n}$ (where $\epsilon \approx 0.01$) in direction $\mathbf{w}_i$ [S3, unofficial].
   e. Compute volumetric transmittance $T_{light}$ from $\mathbf{p}$ to $\mathbf{l}_i$:
      - Option A (Discrete steps): Integrate extinction over 16 uniform steps from $\mathbf{p}$ to $\mathbf{l}_i$ [S1, unofficial].
      - Option B (Majorant sampling): Use a majorant-based sampler to estimate transmittance through the volume grid, handling participating media with null-event rejection and Russian Roulette if transmittance drops below 0.05 [S6, unofficial].
      - Option C (Geometry-only): If no volume is present, intersect the shadow ray with scene geometry. If an intersection occurs at distance $t < d$, set $T_{light} = 0.0$; otherwise $T_{light} = 1.0$ [S4, unofficial].
   f. Compute visibility $V$:
      - If using geometry-only shadowing: $V = 1$ if no intersection or intersection distance $\ge d$, else $V = 0$ [S1, unofficial].
      - If using volumetric transmittance: $V$ is implicitly handled by $T_{light}$ [S1, unofficial].
   g. Compute geometric term:
      $$ G = \frac{\max(0, \mathbf{n} \cdot \mathbf{w}_i) \cdot |\mathbf{w}_i \cdot \mathbf{n}_{light}|}{d^2} $$
      where $\mathbf{n}_{light}$ is the light surface normal (for area lights) [S1, unofficial].
   h. Compute probability density $p_y = 1.0 / \text{light\_area}$ for importance sampling [S1, unofficial].
   i. Compute BRDF contribution:
      - Diffuse: $\mathbf{C}_i \cdot T_{light} \cdot V \cdot \frac{\rho_d}{\pi} \cdot G / p_y$ [S1, unofficial].
      - Specular (if enabled): $\mathbf{C}_i \cdot T_{light} \cdot \text{specular} \cdot \max(0, \mathbf{H} \cdot \mathbf{n})^{\text{shininess}}$, where $\mathbf{H} = \text{normalize}(\mathbf{V} + \mathbf{w}_i)$ and $\text{shininess} = 1/\text{roughness}$ [S3, S4, unofficial].
   j. Add contribution to $\mathbf{L}_{direct}$ [S2, unofficial].
3. Return $\mathbf{L}_{direct}$ [S2, unofficial].

**Pseudocode:**
```python
def direct_illumination_with_shadow_rays(hit_point, normal, view_dir, lights, volume_integrator, geometry_tracer):
    """
    Computes direct lighting with volumetric shadow rays.
    
    Args:
        hit_point: vec3, surface position
        normal: vec3, surface normal
        view_dir: vec3, view direction
        lights: list of Light objects
        volume_integrator: object with Transmittance(ray) method
        geometry_tracer: object with intersect(ray) method
        
    Returns:
        vec3, direct illumination radiance
    """
    L_direct = vec3(0.0)
    
    for light in lights:
        if not light.enabled:
            continue
            
        # Light direction and distance
        delta = light.position - hit_point
        d = length(delta)
        if d < 1e-6:
            continue
        w_i = normalize(delta)
        
        # Shadow ray setup
        epsilon = 0.01 * length(normal)
        shadow_ray_origin = hit_point + epsilon * normal
        shadow_ray = Ray(shadow_ray_origin, w_i)
        
        # Compute transmittance through volume
        T_light = volume_integrator.Transmittance(shadow_ray)
        
        # Check for geometric occlusion (optional, depends on implementation)
        # If geometry_tracer is used for hard shadows in addition to volume:
        intersection = geometry_tracer.intersect(shadow_ray)
        if intersection.hit and intersection.t < d:
            T_light = 0.0
            
        # Visibility factor (if not fully covered by T_light)
        V = 1.0 if (not intersection.hit or intersection.t >= d) else 0.0
        
        # Geometric term
        cos_theta = max(0.0, dot(normal, w_i))
        # For point lights, light normal term is 1.0; for area lights, use light.normal
        cos_light = 1.0 if light.is_point else max(0.0, dot(-w_i, light.normal))
        geometric_term = (cos_theta * cos_light) / (d * d)
        
        # Probability density for light sampling
        p_y = 1.0 / light.area if light.area > 0 else 1.0
        
        # BRDF calculation
        # Diffuse component
        diffuse_reflectance = light.color * T_light * V * geometric_term / p_y
        L_direct += diffuse_reflectance * hit_material.diffuse_color
        
        # Specular component (if enabled)
        if hit_material.specular_enabled:
            H = normalize(view_dir + w_i)
            cos_Hn = max(0.0, dot(H, normal))
            shininess = 1.0 / hit_material.roughness
            specular_term = light.color * T_light * hit_material.specular * pow(cos_Hn, shininess)
            L_direct += specular_term
            
    return L_direct
```

**Parameters:**
- $\epsilon$: Shadow ray offset, typically $0.01 \times \|\mathbf{n}\|$ [S3, unofficial].
- Number of integration steps: 16 for discrete integration [S1, unofficial].
- MAX_LIGHTS: Maximum number of lights, typically 8 [S2, unofficial].
- Russian Roulette threshold: 0.05 for transmittance [S6, unofficial].

**Edge Cases and Pitfalls:**
- Precision: Shadow ray origin must be offset to avoid self-intersection [S3, unofficial].
- Boundaries: Handle light distance $d=0$ to avoid division by zero [S2, unofficial].
- Degenerate input: Disabled lights should be skipped early [S2, unofficial].
- Volumetric density: If density is zero, transmittance is 1.0 [S6, unofficial].

## Subtopics

### Transparent Shadows
A shadowing technique where shadow rays cross smooth glass in a straight line, and paths refracted to a light already reached that way do not count as reaching the light [S5, unofficial]. This allows for realistic glass shadows without complex refraction path tracing [S5, unofficial].

### Shadow Ray Transmittance Estimation
Estimates transmittance from a point to a distant light source using majorant sampling to handle participating media [S6, unofficial]. It initializes transmittance to 1.0, creates a shadow ray, intersects with the volume grid to get a majorant iterator, and loops through sampled points with null event probabilities and Russian Roulette if transmittance drops below 0.05 [S6, unofficial]. The phase function (Henyey-Greenstein) is multiplied by the estimated transmittance and light intensity [S6, unofficial].

## Operating characteristics
- **Time Complexity:** $O(N \cdot S)$, where $N$ is the number of lights and $S$ is the number of sampling steps per shadow ray [S1, S6, unofficial].
- **Memory Complexity:** $O(1)$ per light, plus volume grid storage [S6, unofficial].
- **Measured Performance:** Depends heavily on volume density and number of lights. Majorant sampling can be faster for sparse volumes but requires RNG state [S6, unofficial].
- **Scaling:** Linear with number of lights and volume samples [S1, unofficial].
- **Strengths:** Handles heterogeneous volumes, supports multiple lights, integrates with PBR [S1, S2, unofficial].
- **Limitations:** Noisy for sparse sampling, expensive for many lights or dense volumes [S6, unofficial].
- **When to use:** When volumetric shadows are required and direct illumination is sufficient [S1, unofficial].
- **When not to use:** For real-time applications with many lights and complex volumes, consider precomputed shadows or variance shadow mapping [S2, S4, unofficial].

## Background
Originated in volumetric path tracing implementations to handle direct lighting in participating media [S1, unofficial]. Developed alongside ray marching techniques for voxel-based scenes [S3, S4, unofficial]. Used in real-time ray marchers and offline path tracers for volumetric effects [S2, S6, unofficial].
