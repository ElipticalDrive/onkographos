# Voxel Outgoing Radiance


## Overview
Voxel Outgoing Radiance is a primary shading method that evaluates the diffuse outgoing radiance of a voxel based on cached irradiance and material properties [S1, unofficial]. It solves the problem of efficiently computing direct and indirect lighting for voxel-based participating media by decoupling the irradiance calculation from the shading step, allowing for fast, face-dependent radiance evaluation [S1, unofficial]. It differs from [Ray Casting and Fragment Shading](12415-ray-casting-and-fragment-shading.md) by relying on pre-computed irradiance caches rather than real-time ray integration, and from [Basic Gas Rendering Algorithm](12423-basic-gas-rendering-algorithm.md) by explicitly handling directional irradiance for diffuse surfaces within the voxel grid [S1, unofficial].

## How it works
**Inputs and Outputs:**
*   **Input:** A voxel `v` at grid coordinates; a face normal `n` indicating the viewing direction relative to the voxel (one of the six axis-aligned faces); a material `m` associated with the voxel.
*   **Output:** The outgoing radiance `L_out` for the specified direction.

**Data Structures:**
*   **Material `m`:** Contains fields `emission` (scalar or vector) and `albedo` (vector, typically RGB).
*   **Irradiance Texture `u_gi`:** A 3D texture or grid storing cached irradiance values. The access is determined by the face of the normal.
*   **Atlas Coordinate Function `atlas_coord(v, face)`:** Maps the voxel index `v` and face index (0-5) to a texture coordinate or grid index in `u_gi`.

**Steps:**
1.  Fetch the material `m` for voxel `v`.
2.  Determine the face index corresponding to the normal `n`.
3.  Fetch the cached irradiance value `I` from `u_gi` using the atlas coordinate derived from `v` and the face of `n`.
4.  Compute the diffuse component: `L_diffuse = m.albedo * I`.
5.  Add the emission component: `L_out = L_diffuse + m.emission`.

**Formula:**
$$ L_{out} = m.albedo \cdot I + m.emission $$

Where:
*   $L_{out}$ is the outgoing radiance.
*   $m.albedo$ is the diffuse reflectivity of the voxel.
*   $I$ is the cached irradiance fetched from the GI texture.
*   $m.emission$ is the self-emitted radiance.

**Parameters:**
*   **Irradiance Cache Resolution:** Not given in the sources.
*   **Face Normal Mapping:** The method assumes a fixed set of six directions corresponding to the voxel faces [S1, unofficial].

**Edge Cases and Pitfalls:**
*   **Boundary Conditions:** The `atlas_coord` function must handle voxels on the grid boundary, potentially returning zero irradiance or clamping to edge values [G].
*   **Precision:** Irradiance values should be stored in a format sufficient to prevent banding, though specific bit depths are not given [G].
*   **Emission Directionality:** Emission is added omnidirectionally, meaning it does not depend on the face normal `n` [S1, unofficial].

**Pseudocode:**
```python

    """
    Calculate outgoing radiance for a voxel given a face normal.
    
    Args:
        v: The 3D index of the voxel.
        n: The face normal (one of the 6 axis-aligned directions).
        m: The material properties of the voxel.
        u_gi: The irradiance cache texture.
        
    Returns:
        The outgoing radiance.
    """
    # 1. Fetch material (already provided as argument m)
    
    # 2. Determine face index from normal
    # Assuming n is normalized and axis-aligned
    face_index = get_face_index(n)
    
    # 3. Fetch irradiance from cache
    # atlas_coord maps voxel v and face_index to a texture coordinate
    coord = atlas_coord(v, face_index)
    irradiance = u_gi.sample(coord)
    
    # 4. Compute diffuse radiance
    diffuse_radiance = m.albedo * irradiance
    
    # 5. Add emission (omnidirectional)
    outgoing_radiance = diffuse_radiance + m.emission
    
    return outgoing_radiance
```

## Subtopics

### [Irradiance Vector Grid](21996-irradiance-vector-grid.md)
The Irradiance Vector Grid (IVG) is a volumetric data structure for caching low-frequency indirect illumination in participating media or diffuse scenes, designed for efficient storage and GPU rendering. It stores a fixed set of irradiance vectors in a 3D grid to capture geometric and photometric robustness against local variations of geometry and reflectance. Unlike scalar irradiance caching or Christensen’s cache, which suffer from Voronoi-like artifacts or geometric dependency, IVG uses directional interpolation on a fixed axis-aligned grid to provide smooth, normal-aware indirect lighting.

### HDR Emissive Material (Legacy)
A legacy variant of the emission calculation in MagicaVoxel where the emission intensity is computed using a power function [S2]. The formula is $Emit \times (10 ^ {Power})$, where `Emit` is the base emission value and `Power` is a slider-controlled exponent [S2]. This formula was introduced to enhance Bloom and Bokeh effects, replacing a prior calculation method [S2].

### Volumetric Radiosity
A calculation method where voxels are regarded as discrete elements in radiosity calculations on pairs of elements, computed on a voxel-by-voxel basis [S3, unofficial]. This approach treats the volume as a set of discrete surfaces, applying traditional radiosity principles to compute inter-voxel light transport [S3, unofficial].

## Operating characteristics
*   **Time Complexity:** $O(1)$ per voxel per face, as it involves a texture lookup and simple arithmetic operations [S1, unofficial].
*   **Memory Complexity:** Depends on the size of the irradiance cache `u_gi` and the material library. The cache size is proportional to the volume resolution and the number of faces stored [S1, unofficial].
*   **Measured Performance:** Not given in the sources.
*   **Strengths:** Fast shading evaluation; decouples irradiance computation from shading; supports directional lighting via face-dependent caching [S1, unofficial].
*   **Limitations:** Requires pre-computation of irradiance; limited to low-frequency indirect illumination; may suffer from artifacts if the cache resolution is insufficient [S1, unofficial].
*   **When to Use:** Suitable for real-time rendering of voxel-based scenes with diffuse materials where indirect lighting is important but full ray tracing is too expensive [S1, unofficial].
*   **When Not to Use:** Not suitable for high-frequency lighting effects, specular reflections, or complex participating media with high scattering albedo without additional techniques [S1, unofficial].

## Background
The method is implemented in Voxmat, an unofficial voxel material renderer [S1, unofficial]. The concept of treating voxels as discrete elements for radiosity calculations has roots in early volume rendering research, where voxels were used to compute light transport in participating media [S3, unofficial]. The specific implementation in Voxmat leverages this approach for efficient primary shading [S1, unofficial]. The HDR emissive material formula is documented in MagicaVoxel changelogs [S2].
