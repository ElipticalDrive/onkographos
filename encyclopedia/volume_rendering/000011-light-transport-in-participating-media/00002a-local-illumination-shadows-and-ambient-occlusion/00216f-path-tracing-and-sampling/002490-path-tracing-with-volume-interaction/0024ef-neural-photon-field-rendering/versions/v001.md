# Neural Photon Field Rendering

Also called: Neural Path Tracer, Neural Photon Field Rendering Pipeline, PFF, Photon Field Network, Wavefront Path Tracing with Neural Fields

## Overview
Neural Photon Field Rendering is a GPU-based path tracing method that estimates direct illumination via standard ray-marching techniques and approximates indirect global illumination by querying a pre-trained neural field [S1]. Unlike traditional path tracers that recursively trace secondary rays for global illumination, this method computes only the first volume interaction and uses the neural network to predict the incoming radiance $L_i$ from the rest of the scene [S1]. It is distinguished from its sibling [Emissive Volume Rendering](3398-emissive-volume-rendering.md) by its explicit handling of indirect scattering via a learned photon field, whereas emissive rendering typically focuses on self-emission without complex global illumination approximation [S1].

## How it works
The method operates as a wavefront path tracer [S1]. It replaces the expensive secondary ray tracing required for global illumination with a neural network inference step, significantly reducing stochastic noise and computational cost at low sample counts [S1].

### Inputs and Outputs
*   **Inputs:** Camera parameters, volume density field, phase function coefficients ($g$), pre-trained neural photon field network, number of samples per pixel ($SPP$).
*   **Outputs:** Final radiance $L$ per pixel.

### Data Structures
1.  **Rays Buffer:** Stores ray origins, directions, and intersection status for rays that hit the volume bounding box.
2.  **Samples Buffer:** A fixed-size buffer of size $|samples|_{max} = SPP \times |rays|$ [S1]. Each entry stores the 3D position, the phase coefficient $g$ used for that sample, and validity flags. Invalid interactions (where delta tracking failed or the ray escaped) are left blank [S1].
3.  **Neural Network Input:** A 6-dimensional vector consisting of the 3D position $(x, y, z)$ and the phase coefficient $g$ [S1]. The position is encoded using hashgrid encoding [S1].

### Parameters
*   **SPP:** Samples per pixel. Typically 1 for performance measurement, but supports accumulation [S1].
*   **Maximum Path Length:** Set to 16 for all rendering evaluations [S1].
*   **Phase Coefficients ($G$):** The network is trained on a discrete subset $G \subset [-1, 1]$ [S1]. It generalizes to unseen $g \notin G$ [S1].
*   **Photon Map Size:** The underlying data is generated from photon maps consisting of 12M total photons, distributed as 4M photons per phase [S1].

### Steps
1.  **Ray Generation:** Spawn view rays based on camera parameters. Perform basic intersection testing against the volume bounding box. Store intersecting rays in the Rays Buffer [S1].
2.  **Volume Sampling:** For each ray in the buffer, use delta tracking [S1] to estimate the depth of the first interaction with the volume. Generate $SPP$ samples per ray. Store the interaction positions and the corresponding phase coefficient $g$ in the Samples Buffer. Invalid interactions are marked as blank [S1].
3.  **Photon Field Prediction:** Batch all valid samples from the Samples Buffer into a single neural network inference step. The network takes the 6D input (position + $g$) and outputs the predicted incoming radiance $L_i^{pred}$ [S1]. This is decoded using the network's output layer (Equation 7 in [S1]) to obtain the final radiance value [S1].
4.  **Compaction:** Compact the Samples Buffer by discarding samples where delta tracking did not generate a valid interaction, removing 'holes' to optimize subsequent memory access [S1].
5.  **Direct Illumination:** Use Next-Event Estimation (NEE) and delta tracking [S1] to sample light sources directly from the generated sample points. This computes the direct illumination term $L_d$ [S1].
6.  **Composition:** Compute the scattering probability $\sigma_s$ at each sample point. Determine Multiple Importance Sampling (MIS) weights $w_d$ (for NEE) and $w_i$ (for the neural network prediction) [S1]. Compose the total illumination using the formula below [S1].

### Pseudocode
```python
def neural_photon_field_rendering(camera, neural_field, spp):
    # 1. Ray Generation
    rays = ray_generation(camera)
    
    # 2. Volume Sampling
    # Generate spp interactions per ray using delta tracking
    samples = volume_sampling(rays, spp)
    
    # 3. Photon Field Prediction
    # Batch all samples for single inference step
    # Input: 6D vector (position, phase_coefficient)
    # Output: Predicted incoming radiance Li_pred
    li_pred = neural_field.decode(samples)
    
    # 4. Compaction (Implicit in efficient implementation, 
    # but logically removes invalid samples before composition)
    valid_samples = compact(samples)
    valid_li_pred = li_pred[valid_samples]
    
    # 5. Direct Illumination
    # Use NEE and delta tracking from sample points
    ld = direct_illumination(valid_samples)
    
    # 6. Composition
    # Compute scattering probability and MIS weights
    sigma_s = scattering_probability(valid_samples)
    w_d, w_i = compute_mis_weights(valid_samples)
    
    # Final Radiance Formula
    # L = (1/SPP) * sum(w_d * Ld + wi * sigma_s * Li_pred)
    # Note: The sum is over the SPP samples per pixel
    l = (1.0 / spp) * sum(
        w_d * ld + w_i * sigma_s * valid_li_pred
    )
    
    return l
```

### Edge Cases and Pitfalls
*   **High Transparency/Gradients:** Highly transparent volumes and regions with high density gradients (e.g., air-surface boundaries) suffer from insufficient photon density in the training data, causing the averaged radiance to underestimate true illumination [S1].
*   **Unseen Phase Coefficients:** Evaluating the network on phase coefficients $g \notin G$ introduces error compounded by both prediction bias and the inherent stochasticity of the photon tracing used to train the field [S1].
*   **Delta Tracking Failure:** If delta tracking fails to find a valid interaction within the volume bounds, the sample is marked invalid and discarded during compaction [S1].

## Subtopics

### Photon Field Training
The process of generating the baseline photon maps and training the neural network to approximate the radiance field. This is a pre-computation step not covered in the rendering algorithm itself [S1].

### Delta Tracking
The volume sampling technique used to find the first interaction point. It is a standard method in volume rendering [S1].

## Operating characteristics
*   **Time Complexity:** The rendering time is dominated by the neural network inference and direct illumination sampling. It avoids the exponential cost of secondary ray tracing for global illumination [S1].
*   **Memory Complexity:** Requires storing the neural network weights and the samples buffer ($SPP \times |rays|$) [S1]. The pre-computed photon maps are not stored during rendering but are used for training [S1].
*   **Performance:** Achieves an average speedup of 4–5× over a conventional path tracer [S1]. The speedup for generating the indirect illumination term ($L_i$) reaches up to 13× [S1]. Frame time speedup strongly correlates with the screen fill ratio of the rendered volume [S1].
*   **Image Quality:** Exhibits significantly less stochastic noise than path tracers at low SPP (e.g., 1–4 SPP) [S1]. Noise profiles improve faster as SPP increases [S1]. The method is suitable for real-time applications or denoising pipelines [S1].
*   **Limitations:** Quality is limited by the quality of the underlying photon maps (e.g., 12M photons) [S1]. Low opacity volumes and boundary gradients may suffer from underestimation [S1].

## Background
The method was introduced in "Photon Field Networks for Dynamic Real-Time Volumetric Global Illumination" [S1]. It builds on the concept of photon mapping [S1] and neural radiance fields [S1]. The authors propose using a neural network to approximate the radiance field learned from photon maps, enabling real-time rendering of global illumination in participating media [S1]. The approach is designed to be implemented as a GPU path tracer, leveraging wavefront parallelism [S1].
