# Path Tracing with Volume Interaction

Also called: Path Tracing for Volume Lighting

## Overview
Path Tracing with Volume Interaction is a global illumination algorithm that handles light transport through participating media by treating volume intersections as potential scattering events within the path generation loop [S1, unofficial]. It distinguishes itself from pure surface path tracers by integrating volume sampling directly into the ray intersection logic, allowing for multiple scattering in heterogeneous media, and from pure ray marching methods by using stochastic path sampling rather than deterministic integration for indirect light [S2, unofficial].

## How it works
**Inputs:**
*   Scene geometry and volume data (density fields, transfer functions) [S1, unofficial].
*   Camera ray $(o, d)$ [G].
*   Sampler instance for random number generation [G].
*   Settings: `minBounces`, `maxBounces`, `gradientFactor`, `stepSize`, `backgroundLight` [S1, unofficial].

**Outputs:**
*   Radiance color $C$ for the pixel [G].

**Data Structures:**
*   `ScatterEvent`: Stores intersection position, normal, material ID, and index of refraction ($iorI$, $iorO$) [S1, unofficial].
*   `LightHit`: Stores light color, direction, distance, and PDF [S1, unofficial].
*   `Material`: Defines BRDF/BSDF properties, emission status, sampled lobe type, and transfer function RGBA output [S1, unofficial].

**Algorithm Steps:**

1.  **Initialization:** Set throughput $T = (1.0, 1.0, 1.0)$ and accumulated color $C = (0, 0, 0)$ [S1, unofficial]. Set initial index of refraction $interaction.iorI = 1.0$ (air) [S1, unofficial]. Loop $bounces$ from $0$ to $maxBounces - 1$ [S1, unofficial].
2.  **Intersection:** Intersect the current ray with the scene [S1, unofficial]. If no intersection is found, add $T \times backgroundLight$ to $C$ and break the loop [S1, unofficial].
3.  **Volume vs. Surface Decision:** If the intersection is a volume, compute the local position relative to the volume origin, get the gradient magnitude, and sample the volume intensity [S1, unofficial]. Calculate the probability of treating the interaction as a surface (BRDF) using [S1, unofficial]:
    $$probBRDF = 1.0 - \exp\left(-settings.gradientFactor \times \frac{magnitude}{intensity}\right)$$
    If $sampler.nextFloat() < probBRDF$, treat as surface: shift position along the normal by $settings.stepSize$, multiply $T$ by the transfer function's RGBA output, and retrieve the material from the transfer function [S1, unofficial]. Otherwise, treat as isotropic volume: multiply $T$ by $2.0$ and create an isotropic material using the transfer function's color [S1, unofficial]. If the intersection is a surface, retrieve the material from $scene.materials$ using $intersection.materialID$ [S1, unofficial].
4.  **Emission:** If the material has a light source and ($bounces == 0$ or the sampled lobe is Specular), add $T \times hitLight.getEmittance(interaction)$ to $C$ [S1, unofficial].
5.  **Direct Lighting:** Add direct lighting contribution: $C \leftarrow C + T \times SampleOneLight(interaction, scene, material, hitLight, settings, sampler)$ [S1, unofficial].
6.  **Next Direction Sampling:** Sample the next direction from the material [S1, unofficial]. If the PDF is not a finite number (e.g., parallel direction), resample until a valid PDF is obtained [S1, unofficial]. Update throughput: $T \leftarrow T \times \frac{material.evaluate(interaction)}{pdf}$ [S1, unofficial]. If the sampled lobe is SpecularTransmission, update the index of refraction: $interaction.iorI \leftarrow interaction.iorO$ [S1, unofficial].
7.  **Ray Update:** Create the new ray: origin $= interaction.position$, direction $= interaction.inputDir$ (the sampled direction), $minT = RAY\_EPS$ [S1, unofficial].
8.  **Russian Roulette:** If $bounces \ge minBounces - 1$, calculate $p$ as the maximum component of $T$ [S1, unofficial]. If $sampler.nextFloat() > p$, break the loop. Otherwise, divide $T$ by $p$ [S1, unofficial].
9.  **Final Output:** Return the final color divided by $(1 + bounces)$ [S1, unofficial].

**Pseudocode:**

```python
import math
from typing import Tuple, List, Optional

Vector3 = Tuple[float, float, float]
RAY_EPS = 1e-4
LOBE_SPECULAR = 0
LOBE_SPECULAR_TRANSMISSION = 1
INTERSECTION_VOLUME = 0
INTERSECTION_SURFACE = 1

class Material:
    def __init__(self, is_light: bool, sampled_lobe: int, color: Vector3, transfer_rgba: Vector3 = (1.0, 1.0, 1.0), ior_o: float = 1.0):
        self.is_light = is_light
        self.sampled_lobe = sampled_lobe
        self.color = color
        self.transfer_rgba = transfer_rgba
        self.ior_o = ior_o

    def evaluate(self, new_dir: Vector3) -> Vector3:
        return self.color

    def sample(self, sampler) -> Tuple[Vector3, float]:
        return (0.0, 0.0, 1.0), 1.0

    def get_emittance(self, hit) -> Vector3:
        return self.color

class Light:
    def illuminate(self, interaction, sampler) -> Tuple[Vector3, float]:
        return (1.0, 1.0, 1.0), 1.0

def sample_one_light(hit, scene, material, settings, sampler) -> Vector3:
    # Selects a random light from scene.lights and calls light.illuminate(hit, sampler)
    # Handles point, directional, and object lights per [S1, unofficial]
    light = scene.lights[0]
    color, _ = light.illuminate(hit, sampler)
    return color

def path_trace_volume(ray_o: Vector3, ray_d: Vector3, scene, sampler, settings) -> Vector3:
    throughput = (1.0, 1.0, 1.0)
    color = (0.0, 0.0, 0.0)
    ior_i = 1.0

    for bounces in range(settings.max_bounces):
        hit = scene.intersect(ray_o, ray_d)

        if hit is None:
            color = (color[0] + throughput[0] * settings.background_light[0],
                     color[1] + throughput[1] * settings.background_light[1],
                     color[2] + throughput[2] * settings.background_light[2])
            break

        if hit.type == INTERSECTION_VOLUME:
            local_pos = (hit.position[0] - hit.volume_origin[0],
                         hit.position[1] - hit.volume_origin[1],
                         hit.position[2] - hit.volume_origin[2])
            magnitude = math.sqrt(sum(x**2 for x in hit.volume_gradient(local_pos)))
            intensity = hit.volume_intensity(local_pos)

            prob_brdf = 1.0 - math.exp(-settings.gradient_factor * (magnitude / intensity))

            if sampler.next_float() < prob_brdf:
                hit.position = (hit.position[0] + hit.normal[0] * settings.step_size,
                                hit.position[1] + hit.normal[1] * settings.step_size,
                                hit.position[2] + hit.normal[2] * settings.step_size)
                throughput = (throughput[0] * hit.transfer_function_rgba[0],
                              throughput[1] * hit.transfer_function_rgba[1],
                              throughput[2] * hit.transfer_function_rgba[2])
                material = Material(is_light=False, sampled_lobe=LOBE_SPECULAR, color=hit.transfer_function_rgba)
            else:
                throughput = (throughput[0] * 2.0, throughput[1] * 2.0, throughput[2] * 2.0)
                material = Material(is_light=False, sampled_lobe=LOBE_SPECULAR, color=hit.transfer_function_color)
        else:
            material = scene.materials[hit.material_id]

        if material.is_light and (bounces == 0 or material.sampled_lobe == LOBE_SPECULAR):
            light_color = material.get_emittance(hit)
            color = (color[0] + throughput[0] * light_color[0],
                     color[1] + throughput[1] * light_color[1],
                     color[2] + throughput[2] * light_color[2])

        direct_color = sample_one_light(hit, scene, material, settings, sampler)
        color = (color[0] + throughput[0] * direct_color[0],
                 color[1] + throughput[1] * direct_color[1],
                 color[2] + throughput[2] * direct_color[2])

        pdf = 0.0
        while not math.isfinite(pdf):
            new_dir, pdf = material.sample(sampler)

        eval_color = material.evaluate(new_dir)
        throughput = (throughput[0] * eval_color[0] / pdf,
                      throughput[1] * eval_color[1] / pdf,
                      throughput[2] * eval_color[2] / pdf)

        if material.sampled_lobe == LOBE_SPECULAR_TRANSMISSION:
            ior_i = material.ior_o

        ray_o = hit.position
        ray_d = new_dir
        ray_o = (ray_o[0] + ray_d[0] * RAY_EPS,
                 ray_o[1] + ray_d[1] * RAY_EPS,
                 ray_o[2] + ray_d[2] * RAY_EPS)

        if bounces >= settings.min_bounces - 1:
            p = max(throughput)
            if sampler.next_float() > p:
                break
            throughput = (throughput[0] / p, throughput[1] / p, throughput[2] / p)

    return (color[0] / (1.0 + bounces),
            color[1] / (1.0 + bounces),
            color[2] / (1.0 + bounces))
```

**Parameters:**
*   `settings.minBounces`: The minimum number of bounces before Russian Roulette can terminate the path [S1, unofficial].
*   `settings.maxBounces`: The maximum number of bounces allowed for the path [S1, unofficial].
*   `settings.gradientFactor`: Controls the probability of treating a volume interaction as a surface [S1, unofficial].
*   `settings.stepSize`: Offset distance for surface shift in volume [S1, unofficial].

**Edge Cases:**
*   **NaN PDF:** If the sampled direction is parallel to the normal or otherwise invalid, the PDF may be NaN. The algorithm must resample until a valid PDF is obtained [S1, unofficial].
*   **Heterogeneous Media:** Standard homogeneous assumptions fail; Woodcock tracking is required for unbiased results in heterogeneous media [S2, unofficial].

## Subtopics

### [Emissive Volume Rendering](3398-emissive-volume-rendering.md)
Emissive Volume Rendering extends path tracing to support participating media that emit light, integrating volume emission sampling directly into medium interaction routines. It avoids the performance penalties of direct solid-angle-to-volume PDF conversion for Multiple Importance Sampling (MIS).

### [Neural Photon Field Rendering](3427-neural-photon-field-rendering.md)
Neural Photon Field Rendering is a GPU-based method that estimates direct illumination via ray marching and approximates indirect global illumination by querying a pre-trained neural field. It decouples direct and indirect terms, computing only the first volume interaction and using the network to predict incoming radiance, differing from Emissive Volume Rendering by its reliance on learned fields.

### Woodcock Tracking
Woodcock Tracking is a technique used during integration over the sphere for each step along the ray to obtain unbiased results for heterogeneous media [S2, unofficial].

## Operating characteristics
*   **Complexity:** Path tracing for volumes is expensive because light can take random paths in the media until it reaches the point, analogous to indirect illumination in surface rendering [S2, unofficial].
*   **Performance:** Multiple scattering increases computational cost significantly compared to single scattering methods [S2, unofficial].
*   **Strengths:** Handles multiple scattering and complex light transport in participating media [S1, unofficial].
*   **Limitations:** High computational cost for multiple scattering; requires careful handling of heterogeneous media [S2, unofficial].

## Background
Originating from general path tracing principles applied to participating media, this method addresses the need for physically based light transport in volumes [S1, S2, unofficial]. It builds on the foundation of [Path Tracing and Sampling](2526-path-tracing-and-sampling.md) and is discussed in contexts such as the SIGGRAPH 2015 presentation "Physically-based & Unified Volumetric Rendering in Frostbite" for proper integration [S2, unofficial].
