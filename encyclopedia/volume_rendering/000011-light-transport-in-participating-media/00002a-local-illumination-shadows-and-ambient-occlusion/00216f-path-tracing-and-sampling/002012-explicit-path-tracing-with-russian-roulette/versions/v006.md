# Explicit Path Tracing with Russian Roulette

Also called: Implicit Path Tracing, Monte Carlo Path Tracing, Path Tracing with Russian Roulette and Material Sampling

## Overview
Explicit Path Tracing with Russian Roulette is a backward ray tracing algorithm that simulates light transport by recursively tracing rays from the camera, accumulating color contributions from surface interactions until a maximum bounce count is reached or a probabilistic termination condition is met [S2, unofficial]. It is distinguished from its siblings by its explicit management of recursion depth combined with Russian Roulette termination based on the maximum component of the surface albedo, contrasting with methods that rely solely on fixed depth limits or discrete event sampling for sparse media [S1, unofficial][S2, unofficial].

## How it works
**Inputs and Outputs:**
*   **Inputs:** A `Scene` struct containing a `Camera`, a signed distance field (SDF) map (`SdfMap`), and a background color function [S2, unofficial].
*   **Outputs:** A `Vec3` representing the accumulated color for a pixel.

**Data Structures:**
*   `Scene`:
    *   `camera`: `Camera` struct.
    *   `map`: `Box<dyn SdfMap>` interface providing ray intersection and normal queries [S2, unofficial].
    *   `background_color`: `Box<dyn Fn(Vec3) -> Vec3 + Sync>` function evaluating environment color [S2, unofficial].
*   `Camera`:
    *   `position`: `Vec3` eye position.
    *   `left`, `forward`, `up`: `Vec3` basis vectors [S2, unofficial].
    *   `focal_length`: `f32` derived from angle of view.
    *   `aspect_ratio`: `f32` width/height ratio.
    *   `focus_dist`: `f32` distance to focal plane.
    *   `aperture`: `f32` for depth of field [S2, unofficial].
*   `HitInfo` (returned by `ray_intersection`):
    *   `position`: `Vec3` intersection point.
    *   `material`: Enum `Material` (Lambertian, Emissive, Specular).
    *   `id`: `usize` object index (light sources are `objects.size() - 1`) [S1, unofficial].

**Parameters:**
*   `MAX_BOUNCES`: `i32 = 4`. Maximum recursion depth [S2, unofficial].
*   `SURFACE_DIST`: `f32 = 0.001`. Epsilon to prevent self-intersection [S2, unofficial].
*   `WIDTH`: `i32 = 800`. Render width [S2, unofficial].
*   `HEIGHT`: `i32 = 600`. Render height [S2, unofficial].
*   `SAMPLE_COUNT`: `i32 = 100`. Samples per pixel [S2, unofficial].

**Steps:**
1.  **Pixel Sampling:** For each pixel $(i, j)$, generate `SAMPLE_COUNT` samples [S2, unofficial]. Compute pixel coordinates $x, y$ with jitter:
    $$ x = -0.5 + \frac{j + \text{jitter}_x}{\text{width} - 1.0} $$
    $$ y = 0.5 - \frac{i + \text{jitter}_y}{\text{height} - 1.0} $$
    where $\text{jitter} \in [-0.5, 0.5]$ is a uniform random float [S2, unofficial].
2.  **Ray Generation:** Use `Camera::get_ray(x, y)` to generate the primary ray [S2, unofficial]. This accounts for depth of field using `uniform_disk()` for aperture sampling [S2, unofficial].
3.  **Path Tracing Loop:** Call `cast_ray` with the ray origin and direction [S2, unofficial]. Initialize `acc = Vec3::ONE` and `bounces = 0` [S2, unofficial].
4.  **Intersection:** Query `scene.map.ray_intersection(origin, direction)` [S2, unofficial].
    *   If `None` (miss), multiply `acc` by `scene.background_color(direction)` and terminate the path [S2, unofficial].
    *   If `Some(hit_info)`, proceed to shading [S2, unofficial].
5.  **Shading and Termination:**
    *   **Lambertian:** Multiply `acc` by `hit_info.material.color`. Compute normal `n = scene.map.normal(hit_info.position)` [S2, unofficial]. Offset origin: `origin = hit_info.position + 2.0 * SURFACE_DIST * n` [S2, unofficial]. Sample new direction `w` using `cos_weighted_hemisphere(n)` [S2, unofficial].
    *   **Emissive:** Multiply `acc` by `hit_info.material.color` and terminate the path (absorbing/emitting surface) [S2, unofficial].
    *   **Specular:** Compute reflection. If `rand < specularity`, reflect direction with fuzziness [S2, unofficial]. If reflected direction points below surface (`dot < 0`), zero `acc` and terminate [S2, unofficial]. Else, multiply `acc` by color and sample `cos_weighted_hemisphere` for next bounce [S2, unofficial].
6.  **Russian Roulette:** Calculate $Q = \max(\text{acc}.x, \text{acc}.y, \text{acc}.z)$ [S1, unofficial]. Generate random float $r \in [0, 1]$. If $r > Q$, terminate path (set `acc = Vec3::ZERO`) [S1, unofficial]. Otherwise, scale `acc` by $1/Q$ to maintain unbiased expectation [S1, unofficial].
7.  **Bounce Limit:** If `bounces > MAX_BOUNCES`, set `acc = Vec3::ZERO` and terminate [S2, unofficial].
8.  **Accumulation:** Sum all pixel samples and divide by `SAMPLE_COUNT` [S2, unofficial].

**Pseudocode:**
```python
import math
import random

class Vec3:
    def __init__(self, x, y, z):
        self.x, self.y, self.z = x, y, z
    def add(self, v): return Vec3(self.x + v.x, self.y + v.y, self.z + v.z)
    def sub(self, v): return Vec3(self.x - v.x, self.y - v.y, self.z - v.z)
    def scale(self, s): return Vec3(self.x * s, self.y * s, self.z * s)
    def dot(self, v): return self.x * v.x + self.y * v.y + self.z * v.z
    def cross(self, v): return Vec3(self.y * v.z - self.z * v.y, self.z * v.x - self.x * v.z, self.x * v.y - self.y * v.x)
    def length(self): return math.sqrt(self.x**2 + self.y**2 + self.z**2)
    def normalize(self):
        l = self.length()
        return Vec3(self.x/l, self.y/l, self.z/l) if l > 1e-8 else Vec3(0,0,0)

class Material:
    Lambertian = "Lambertian"
    Emissive = "Emissive"
    Specular = "Specular"

class HitInfo:
    def __init__(self, position, material, id):
        self.position = position
        self.material = material
        self.id = id

class SdfMap:
    def ray_intersection(self, origin, direction):
        # Standard SDF raymarching loop
        t = 0.0
        for _ in range(64):
            p = origin.add(direction.scale(t))
            d = self.sdf(p)
            if d < 1e-4:
                return HitInfo(p, self.material_at(p), self.id_at(p))
            t += d
        return None
    def sdf(self, p): return 1.0 # Placeholder for actual SDF function
    def material_at(self, p): return Material.Lambertian
    def id_at(self, p): return 0
    def normal(self, position):
        # Central difference gradient
        eps = 1e-4
        return Vec3(
            self.sdf(position.add(Vec3(eps,0,0))) - self.sdf(position.add(Vec3(-eps,0,0))),
            self.sdf(position.add(Vec3(0,eps,0))) - self.sdf(position.add(Vec3(0,-eps,0))),
            self.sdf(position.add(Vec3(0,0,eps))) - self.sdf(position.add(Vec3(0,0,-eps)))
        ).normalize()

class Camera:
    def __init__(self, position, left, forward, up, focal_length, aspect_ratio, focus_dist, aperture):
        self.position = position
        self.left = left
        self.forward = forward
        self.up = up
        self.focal_length = focal_length
        self.aspect_ratio = aspect_ratio
        self.focus_dist = focus_dist
        self.aperture = aperture

    def get_ray(self, x, y):
        dx, dy = uniform_disk()
        offset = Vec3(0.5 * self.aperture * (dx * self.left.x + dy * self.up.x),
                      0.5 * self.aperture * (dx * self.left.y + dy * self.up.y),
                      0.5 * self.aperture * (dx * self.left.z + dy * self.up.z))
        origin = self.position.add(offset)
        dir_x = x / self.focal_length * self.left.x + y / (self.focal_length * self.aspect_ratio) * self.up.x + self.forward.x
        dir_y = x / self.focal_length * self.left.y + y / (self.focal_length * self.aspect_ratio) * self.up.y + self.forward.y
        dir_z = x / self.focal_length * self.left.z + y / (self.focal_length * self.aspect_ratio) * self.up.z + self.forward.z
        direction = Vec3(self.focus_dist * dir_x - offset.x, self.focus_dist * dir_y - offset.y, self.focus_dist * dir_z - offset.z).normalize()
        return {"origin": origin, "direction": direction}

def uniform_disk():
    while True:
        x = 2.0 * random.random() - 1.0
        y = 2.0 * random.random() - 1.0
        if x*x + y*y <= 1.0:
            return x, y

def uniform_ball():
    while True:
        x = 2.0 * random.random() - 1.0
        y = 2.0 * random.random() - 1.0
        z = 2.0 * random.random() - 1.0
        if x*x + y*y + z*z <= 1.0:
            return Vec3(x, y, z).normalize()

def cos_weighted_hemisphere(normal):
    u1 = random.random()
    u2 = random.random()
    r = math.sqrt(u1)
    theta = 2.0 * math.pi * u2
    x = r * math.cos(theta)
    y = r * math.sin(theta)
    z = math.sqrt(max(0.0, 1.0 - u1))
    if abs(normal.x) > 0.999:
        tangent = Vec3(1, 0, 0)
    else:
        tangent = Vec3(0, 1, 0).cross(normal).normalize()
    bitangent = normal.cross(tangent)
    return (tangent.scale(x) + bitangent.scale(y) + normal.scale(z)).normalize()

SURFACE_DIST = 0.001
MAX_BOUNCES = 4

def cast_ray(scene, origin, direction):
    acc = Vec3(1.0, 1.0, 1.0)
    bounces = 0
    while True:
        if bounces > MAX_BOUNCES:
            return Vec3(0.0, 0.0, 0.0)
        
        hit_info = scene.map.ray_intersection(origin, direction)
        if hit_info is None:
            acc = acc.scale(scene.background_color(direction))
            break
        
        # Skip light source to avoid double counting emission [S1, unofficial]
        if hit_info.id == scene.objects.size() - 1:
            origin = hit_info.position.add(scene.map.normal(hit_info.position).scale(2.0 * SURFACE_DIST))
            direction = cos_weighted_hemisphere(scene.map.normal(hit_info.position))
            bounces += 1
            continue
            
        material = hit_info.material
        position = hit_info.position
        normal = scene.map.normal(position)
        
        if material == Material.Lambertian:
            color = material.color
            acc = acc.scale(color)
            
            Q = max(color.x, color.y, color.z)
            if Q < 1e-4:
                return Vec3(0.0, 0.0, 0.0)
            r = random.random()
            if r > Q:
                return Vec3(0.0, 0.0, 0.0)
            acc = acc.scale(1.0 / Q)
            
            origin = position.add(normal.scale(2.0 * SURFACE_DIST))
            direction = cos_weighted_hemisphere(normal)
            bounces += 1
            
        elif material == Material.Emissive:
            color = material.color
            acc = acc.scale(color)
            break
            
        elif material == Material.Specular:
            color = material.color
            specularity = material.specularity
            fuzziness = material.fuzziness
            
            origin = position.add(normal.scale(2.0 * SURFACE_DIST))
            r = random.random()
            if r < specularity:
                specular = direction.sub(normal.scale(2.0 * direction.dot(normal)))
                direction = (specular.add(uniform_ball().scale(fuzziness))).normalize()
                if direction.dot(normal) < 0.0:
                    acc = Vec3(0.0, 0.0, 0.0)
                    break
            else:
                acc = acc.scale(color)
                direction = cos_weighted_hemisphere(normal)
            
            Q = max(color.x, color.y, color.z)
            if Q < 1e-4:
                return Vec3(0.0, 0.0, 0.0)
            r = random.random()
            if r > Q:
                return Vec3(0.0, 0.0, 0.0)
            acc = acc.scale(1.0 / Q)
            bounces += 1
        else:
            break
    return acc

def render(scene, width, height, sample_count):
    pixels = [[Vec3(0.0, 0.0, 0.0) for _ in range(width)] for _ in range(height)]
    for i in range(height):
        for j in range(width):
            pixel_color = Vec3(0.0, 0.0, 0.0)
            for _ in range(sample_count):
                jitter_x = random.random() - 0.5
                jitter_y = random.random() - 0.5
                x = -0.5 + (j + jitter_x) / (width - 1.0)
                y = 0.5 - (i + jitter_y) / (height - 1.0)
                ray = scene.camera.get_ray(x, y)
                pixel_color = pixel_color.add(cast_ray(scene, ray["origin"], ray["direction"]))
            pixels[i][j] = pixel_color.scale(1.0 / sample_count)
    return pixels
```

**Edge Cases and Pitfalls:**
*   **Light Source Index:** Light sources are represented as the last object in the vector (`objects.size() - 1`). The loop for sampling indirect bounces must skip hits on the light source to prevent double counting its emission [S1, unofficial].
*   **Self-Intersection:** A small epsilon `SURFACE_DIST = 0.001` is added to the hit position along the surface normal to prevent self-intersection (shadow acne) when spawning the next ray [S2, unofficial].
*   **Russian Roulette Scaling:** Russian Roulette introduces variance if not scaled correctly; the throughput must be divided by the survival probability $Q$ to maintain an unbiased estimator [G].

## Subtopics

### [Path Tracing with Discrete Event Sampling](5168-path-tracing-with-discrete-event-sampling.md)
Replaces continuous Russian Roulette with discrete probabilistic decisions (absorption, scattering, null events) to improve efficiency in sparse media by skipping non-interacting steps. Unlike Explicit Path Tracing with Russian Roulette, which uses continuous probability based on albedo/extinction ratios, this method explicitly handles null events to improve efficiency in sparse media. Supports temperature-dependent emission and Henyey-Greenstein phase function scattering.

### [Recursive Trace Function](9277-recursive-trace-function.md)
The core recursive routine for backward path tracing with Directed Distance Fields (DDF), handling intersection, shading, and recursion logic for single light path segments [G]. Distinguished from non-recursive or iterative path tracers by its explicit handling of DDF queries (forward and backward passes) and its direct integration of Russian Roulette termination logic via the parent algorithm's bounce limit [G].

### Russian Roulette for Scattering Albedo
A variance reduction technique using the scattering albedo to decide whether to continue tracing a scattered ray or terminate it [S3, unofficial]. The scattering albedo is defined as $\alpha = \sigma_s / \sigma_t$ [S3, unofficial]. If a random number $\xi < \alpha$, the diffusion contribution is computed as $L_{diffusion,N} = \frac{1}{N} \sum J(s_j')$; otherwise, the contribution is 0 [S3, unofficial].

## Operating characteristics
*   **Time Complexity:** $O(N \cdot S \cdot B)$, where $N$ is the number of pixels, $S$ is samples per pixel, and $B$ is the average path length (bounded by `MAX_BOUNCES`) [G].
*   **Memory Complexity:** $O(1)$ auxiliary space per ray (excluding scene storage), as the algorithm is iterative or shallowly recursive [G].
*   **Performance:** Depends heavily on scene complexity and `MAX_BOUNCES`. In the reference implementation, 800x600 resolution with 100 samples and 4 bounces renders in seconds on modern CPUs [S2, unofficial].
*   **Strengths:** Simple to implement, unbiased, handles complex lighting via recursion [G].
*   **Limitations:** High variance in dark areas (noise), slow convergence for indirect lighting. Russian Roulette introduces variance if not scaled correctly [G].
*   **When to use:** General-purpose offline rendering, educational purposes, scenes with moderate indirect lighting [G].
*   **When not to use:** Real-time rendering, scenes requiring high precision in very dark areas without sufficient samples, or highly participating media (requires volume-specific extensions) [G].

## Background
Originating from standard Monte Carlo path tracing techniques, this specific implementation is found in unofficial repositories such as `ollituohenmaa/raymarching-pathtracer` [S2, unofficial] and `wangyuehi/VolumeSingleScattering` [S1, unofficial]. It builds on the principles of backward ray tracing and Russian Roulette termination introduced by Kajiya (1986) and Whitted (1980), adapted for SDF-based rendering [G].
