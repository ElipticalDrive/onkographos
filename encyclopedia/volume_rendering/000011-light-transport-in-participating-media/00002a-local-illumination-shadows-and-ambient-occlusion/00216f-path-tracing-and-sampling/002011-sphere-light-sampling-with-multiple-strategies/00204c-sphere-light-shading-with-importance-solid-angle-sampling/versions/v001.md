# Sphere Light Shading with Importance Solid Angle Sampling

Also called: Importance Solid Angle Sampling for Sphere Lights

## Overview
This method estimates direct illumination from a spherical light source using Monte Carlo integration over the solid angle subtended by the light [S1, unofficial]. It sets itself apart from surface-area sampling by sampling directions uniformly within the cone defined by the light's extent, which naturally handles the geometric relationship between the shading point and the light without requiring explicit area calculations [S1, unofficial]. It is a specific strategy within the broader [Sphere Light Sampling with Multiple Strategies](2207-sphere-light-sampling-with-multiple-strategies.md) framework.

## How it works
**Inputs:**
- Shading point position $X$.
- Light center $C$ and radius $R_{light}$.
- Surface normal $N$ (required for coordinate system construction if using helper functions, though strictly the direction sampling depends on $X$ and $C$).
- Bidirectional Reflectance Distribution Function (BRDF) $f_r$.
- Incident radiance $L_i$ from the light.
- Shadow status $inShadow$ (boolean or visibility term).

**Outputs:**
- Estimated reflected radiance contribution $L_r$.

**Data Structures:**
- Standard 3D vector types for positions, directions, and normals.
- Random number generator for uniform samples $\eta_1, \eta_2 \in [0, 1)$.

**Steps:**
1. **Compute Geometry:** Calculate the vector from the shading point to the light center: $\vec{d} = C - X$. Compute the distance $D = |\vec{d}|$.
2. **Determine Cone Parameters:** Calculate the sine and cosine of the maximum half-angle $\theta_{max}$ subtended by the light sphere:
   $$ \sin\theta_{max} = \frac{R_{light}}{D} $$
   $$ \cos\theta_{max} = \sqrt{1 - \sin^2\theta_{max}} $$
   *Note:* If $D < R_{light}$, the point is inside the light; handle as a special case or clamp to avoid NaNs [G].
3. **Sample Direction:** Sample a direction $\omega_i$ uniformly within the solid angle of the cone. This typically involves generating a random direction in a local coordinate system aligned with $\vec{d}$ and mapping it to the cone defined by $\theta_{max}$ and $\phi \in [0, 2\pi)$ [S1, unofficial].
4. **Shadow Test:** Trace a ray from $X$ in direction $\omega_i$ with length $D$. If the ray hits the light sphere (and no other geometry), set $inShadow = 0$; otherwise $inShadow = 1$.
5. **Calculate PDF:** The probability density function for uniform sampling over the solid angle of the cone is constant:
   $$ p(\omega_i) = \frac{1}{2\pi(1 - \cos\theta_{max})} $$
   Therefore, the importance sampling weight (inverse PDF) is:
   $$ \frac{1}{p(\omega_i)} = 2\pi(1 - \cos\theta_{max}) $$
6. **Update Estimator:** Accumulate the radiance contribution:
   $$ L_r \leftarrow L_r + f_r(\omega_i, \omega_o) \cdot L_i \cdot \cos\theta_i \cdot (1 - inShadow) \cdot 2\pi(1 - \cos\theta_{max}) $$
   where $\theta_i$ is the angle between $\omega_i$ and the surface normal $N$.
7. **Average:** Repeat for $N$ samples and divide by $N$.

**Pseudocode:**
```python
def shade_sphere_light_importance_solid_angle(X, C, R_light, N, fr, L_i, num_samples):
    """
    Estimates direct lighting from a sphere using importance solid angle sampling.
    """
    total_radiance = 0.0
    
    # Vector from shading point to light center
    d = C - X
    dist = length(d)
    
    # Handle degenerate case where point is inside the light
    if dist <= R_light:
        # Point is inside; simple approximation or handle as emissive
        # For standard shading, this might be clamped or treated as full visibility
        cos_theta_max = 1.0 
    else:
        sin_theta_max = R_light / dist
        cos_theta_max = sqrt(1.0 - sin_theta_max * sin_theta_max)
    
    # PDF constant (inverse of solid angle)
    pdf_constant = 2.0 * PI * (1.0 - cos_theta_max)
    
    for _ in range(num_samples):
        # 1. Sample direction uniformly within the cone subtended by the light
        # This requires generating a random direction in the cone defined by
        # axis=d and half-angle=theta_max.
        # Implementation detail: Generate random u, v in [0,1], convert to
        # spherical coordinates within the cone, then rotate to align with d.
        omega_i = sample_cone_uniform(d, cos_theta_max)
        
        # 2. Shadow test
        # Trace ray from X + epsilon * omega_i with length dist
        hit_light = trace_ray(X, omega_i, dist)
        in_shadow = 1.0 if not hit_light else 0.0
        
        # 3. Calculate cosine term
        cos_theta_i = max(0.0, dot(omega_i, N))
        
        # 4. Update estimator
        # L_r += fr * L_i * cos_theta_i * (1 - in_shadow) * pdf_constant
        radiance_contribution = fr * L_i * cos_theta_i * (1.0 - in_shadow) * pdf_constant
        total_radiance += radiance_contribution
        
    return total_radiance / num_samples

def sample_cone_uniform(axis, cos_theta_max):
    """
    Samples a direction uniformly within a cone defined by axis and cos_theta_max.
    """
    # Generate random phi in [0, 2pi)
    phi = 2.0 * PI * randf()
    
    # Generate random cos_theta in [cos_theta_max, 1]
    # Uniform in solid angle means uniform in cos_theta
    cos_theta = randf() * (1.0 - cos_theta_max) + cos_theta_max
    sin_theta = sqrt(1.0 - cos_theta * cos_theta)
    
    # Construct local basis aligned with axis
    # Create two orthogonal vectors to axis
    if abs(axis.x) < 0.9:
        up = Vector3(1, 0, 0)
    else:
        up = Vector3(0, 1, 0)
    
    tangent = normalize(cross(axis, up))
    bitangent = cross(axis, tangent)
    
    # Combine
    direction = sin_theta * (cos(phi) * tangent + sin(phi) * bitangent) + cos_theta * axis
    return normalize(direction)
```

**Edge Cases and Pitfalls:**
- **Inside Light:** If the shading point is inside the light sphere ($D < R_{light}$), $\sin\theta_{max} > 1$, leading to NaNs in $\cos\theta_{max}$. Clamp or handle separately [G].
- **Precision:** For very distant lights, $\theta_{max}$ is small, and $1 - \cos\theta_{max}$ may suffer from catastrophic cancellation. Use `1 - cos(theta)` approximation or higher precision if necessary [G].
- **Shadow Ray Accuracy:** Ensure shadow rays are cast with a small epsilon to avoid self-intersection artifacts.

## Subtopics

### Sphere Light Shading with Cosine-Weighted Sampling
Estimates direct illumination by sampling directions from a cosine-weighted hemisphere distribution aligned with the surface normal [S1, unofficial]. Unlike importance solid angle sampling, this method does not explicitly account for the light's solid angle in the PDF calculation but relies on the cosine term to weight the contribution [S1, unofficial]. The PDF is $p(\omega_i) = \frac{\cos\theta}{\pi}$, and the estimator update is $L_r += f_r \cdot L_i \cdot (1 - inShadow) \cdot \pi$ [S1, unofficial]. This is simpler to implement but may be less efficient for small, distant lights compared to solid angle sampling [S1, unofficial].

## Operating characteristics
- **Time Complexity:** $O(N)$ per shading point, where $N$ is the number of samples. Each sample requires a ray trace (shadow test).
- **Memory Complexity:** $O(1)$ auxiliary memory.
- **Performance:** Efficient for large, nearby lights where the solid angle is significant. For small, distant lights, the variance can be high if the sampling does not align well with the light's extent, though importance sampling mitigates this compared to uniform hemisphere sampling [S1, unofficial].
- **Strengths:** Unbiased estimator; handles arbitrary light positions and sizes; no need for explicit area calculations.
- **Limitations:** Requires a shadow ray for each sample; variance can be high in complex scenes with many occlusions.

This method is derived from standard Monte Carlo integration techniques for light transport in participating media and surface rendering [S1, unofficial].
