# Importance Sampling

## Overview
Importance sampling is a variance reduction technique for Monte Carlo integration that accelerates convergence by selecting samples from a probability density function (PDF) $p(x)$ that mimics the shape of the integrand $f(x)$ [S1, unofficial]. Unlike uniform sampling, which treats all regions equally, this method concentrates computational effort on directions or values that contribute significantly to the final integral, such as light directions in rendering [S1, unofficial]. It sets itself apart from its parent [Importance Sampling for Sphere Surface Area](2223-importance-sampling-for-sphere-surface-area.md) by providing the general theoretical framework, while its sibling [Occlusion-Aware vMF Importance Sampler](9557-occlusion-aware-vmf-importance-sampler.md) applies specific geometric constraints to that framework.
## How it works
**Inputs and Outputs:**
- Input: An integrand function $f(x)$ to be integrated over a domain $\Omega$, and a target PDF $p(x)$ chosen to approximate $f(x)$.
- Output: An unbiased estimator of the integral $\int_{\Omega} f(x) dx$.

**Data Structures:**
- No specific complex data structures are required for the core definition. The method relies on a random number generator capable of sampling from the distribution defined by $p(x)$.

**Steps:**
1.  **Select PDF:** Choose a probability density function $p(x)$ such that $p(x) \approx c \cdot f(x)$ for some constant $c$, where $p(x) > 0$ whenever $f(x) > 0$.
2.  **Sample:** Draw $N$ independent samples $X_1, \dots, X_N$ from the distribution $p(x)$.
3.  **Estimate:** Compute the Monte Carlo estimator $F_N$ using the formula:
    $$ F_N = \frac{1}{N} \sum_{i=1}^N \frac{f(X_i)}{p(X_i)} $$
    [S1, unofficial]

**Formulas:**
- The estimator is defined as $F_N = \frac{1}{N} \sum_{i=1}^n \frac{f(X_i)}{p(X_i)}$ [S1, unofficial].
- In the ideal case where $p(x) = c f(x)$, the ratio $\frac{f(X_i)}{p(X_i)}$ becomes constant $\frac{1}{c}$, resulting in zero variance [S1, unofficial].

**Parameters:**
- $N$: The number of samples. The convergence rate is $O(1/\sqrt{N})$ [S1, unofficial].

**Edge Cases and Pitfalls:**
- If $p(x) = 0$ where $f(x) > 0$, the estimator is undefined or biased.
- If $p(x)$ poorly approximates $f(x)$, variance reduction is minimal compared to uniform sampling.
- Precision issues may arise if $p(X_i)$ is extremely small, leading to large weights.

**Pseudocode:**
```python
def importance_sampling_estimator(f, p_pdf, p_sample, N):
    """
    Estimate the integral of f using importance sampling.
    
    Args:
        f: The integrand function f(x).
        p_pdf: The PDF function p(x).
        p_sample: A function that samples x from distribution p.
        N: Number of samples.
        
    Returns:
        The estimated integral value.
    """
    total = 0.0
    for i in range(N):
        # Sample x from p(x)
        x = p_sample()
        
        # Evaluate integrand and PDF at sample point
        f_val = f(x)
        p_val = p_pdf(x)
        
        # Avoid division by zero
        if p_val == 0:
            continue
            
        # Accumulate weighted contribution
        total += f_val / p_val
        
    return total / N
```
[G] The pseudocode assumes `p_sample` returns a valid sample and `p_pdf` returns the density at that sample. In practice, `p_sample` often uses inverse transform sampling or rejection sampling based on the analytical form of $p(x)$.

## Operating characteristics
- **Time Complexity:** $O(N)$, where $N$ is the number of samples. Each sample requires evaluating $f(x)$ and $p(x)$.
- **Memory Complexity:** $O(1)$ auxiliary space per sample if processed sequentially.
- **Performance:** Convergence rate is $O(1/\sqrt{N})$, independent of dimensionality [S1, unofficial]. Variance is significantly lower than uniform sampling when $p(x)$ closely matches $f(x)$.
- **Strengths:** Accelerates computation for integrals with sharp peaks or localized contributions.
- **Limitations:** Requires finding a suitable $p(x)$ that is both easy to sample from and close to $f(x)$. If $p(x)$ is difficult to sample or evaluate, overhead may negate benefits.
- **When to use:** When the integrand has known high-contribution regions (e.g., light sources in rendering).
- **When not to use:** When no good approximation of $f(x)$ is available, or when $f(x)$ is smooth and uniform sampling is sufficient.

## Background
Originating from Monte Carlo methods in statistics, importance sampling is widely used in computer graphics to accelerate light transport simulation. It is discussed in the context of null-scattering path integral formulations [S1, unofficial]. The technique leverages the fact that sampling from a distribution similar to the integrand reduces the variance of the estimator, leading to faster convergence.
