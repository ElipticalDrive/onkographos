# Importance Sampling for Specular Term

Also called: Inverse Transform Sampling for GGX-like Distribution, NDJIR Specular Term Sampling

## Overview
This method computes the specular term in the Neural Direct and Joint Inverse Rendering (NDJIR) forward model using Monte Carlo integration with importance sampling [S1, unofficial]. It accelerates convergence by sampling light directions according to a probability density function (PDF) derived from the GGX microfacet distribution $D$ and geometric factors, rather than uniform hemisphere sampling [S1, unofficial].

## How it works
**Inputs:**
- $\zeta_\phi, \zeta_\theta$: Uniform random numbers in $[0, 1)$.
- $\hat{\alpha}_r$: Roughness parameter (scalar).
- $\hat{n}$: Surface normal vector (world coordinates).
- $\mathbf{v}$: Viewing direction vector (world coordinates).
- $\mathbf{f}_0$: Fresnel coefficient at normal incidence.
- $L_V(\hat{\mathbf{x}}, \mathbf{l})$: Volume radiance at position $\hat{\mathbf{x}}$ in direction $\mathbf{l}$.
- $L_E(\mathbf{l})$: Emissive radiance of the light source in direction $\mathbf{l}$.
- $V(\mathbf{v}, \mathbf{l}, \hat{n}, \hat{\alpha}_r)$: Visibility term.
- $I(\mathbf{v}, \mathbf{l}, \hat{n})$: Interaction term.
- $\widehat{L}_p$: Pre-computed or estimated constant factor.
- $N_L$: Number of light samples per pixel.

**Outputs:**
- $\mathbf{l}_i$: Sampled light direction vectors in the local coordinate system (where $\hat{n}$ is the up-vector).
- $\widehat{L}_p$: The estimated specular radiance contribution.

**Steps:**

1.  **Sample Azimuthal Angle:**
    Compute the azimuthal angle $\phi$ using the first random number:
    $$ \phi = 2\pi \zeta_\phi $$

2.  **Sample Polar Angle:**
    Compute the polar angle $\theta$ using the second random number $\zeta_\theta$ and the roughness $\hat{\alpha}_r$:
    $$ \theta = \cos^{-1} \sqrt{\frac{1 - \zeta_\theta}{(\hat{\alpha}_r^2 - 1) \zeta_\theta + 1}} $$
    The PDF used for this inverse transform is derived from the GGX D term in solid angle representation:
    $$ p(\theta, \phi) = \frac{\hat{\alpha}_r^2}{\pi(\cos^2 \theta (\hat{\alpha}_r^2 - 1) + 1)^2} \cos \theta \sin \theta $$

3.  **Construct World Direction:**
    Construct the light direction vector $\mathbf{l}_{world}$ in the world coordinate system (upper-hemisphere):
    $$ \mathbf{l}_{world} = (\cos \phi \sin \theta, \sin \phi \sin \theta, \cos \theta) $$

4.  **Transform to Local Coordinates:**
    Transform the light direction from the world coordinate system to the local coordinate system where the normal $\hat{n}$ is the up-vector:
    $$ \mathbf{l} \leftarrow T(\hat{n}) \mathbf{l}_{world} $$
    where $T(\hat{n})$ is the rotation matrix that maps the world basis to the local basis aligned with $\hat{n}$ [G].

5.  **Compute Half Vector:**
    Calculate the half vector $\mathbf{h}$ between the viewing direction $\mathbf{v}$ and the sampled light direction $\mathbf{l}$:
    $$ \mathbf{h} = \frac{\mathbf{v} + \mathbf{l}}{\|\mathbf{v} + \mathbf{l}\|} $$

6.  **Evaluate Specular Term:**
    For each sample $i$, compute the contribution using the discretized specular term formula:
    $$ \widehat{L}_p = \frac{\widehat{L}_p}{N_L} \sum_{i=1}^{N_L} V(\mathbf{v}, \mathbf{l}_i, \hat{n}, \hat{\alpha}_r) F(\mathbf{v}, \mathbf{l}_i, \mathbf{f}_0) \frac{4(\mathbf{v} \cdot \mathbf{h}_i)}{(\hat{n} \cdot \mathbf{h}_i)} L_V(\hat{\mathbf{x}}, \mathbf{l}_i) L_E(\mathbf{l}_i) (\hat{n} \cdot \mathbf{l}_i) I(\mathbf{v}, \mathbf{l}_i, \hat{n}) $$
    The factor $\frac{4(\mathbf{v} \cdot \mathbf{h})}{(\hat{n} \cdot \mathbf{h})}$ arises from the ratio of the GGX D term (used in the PDF) and the geometric term in the BSDF, effectively canceling the PDF denominator [S1, unofficial].

7.  **Gradient Handling:**
    Do not backpropagate gradients through the sampling process (steps 1-4) to avoid non-differentiable operations [S1, unofficial].

**Pseudocode:**

```python
import math
import numpy as np

def sample_specular_direction(zeta_phi, zeta_theta, alpha_r):
    """
    Samples a light direction in the world upper-hemisphere.
    
    Args:
        zeta_phi: Uniform random float in [0, 1).
        zeta_theta: Uniform random float in [0, 1).
        alpha_r: Roughness parameter.
        
    Returns:
        l_world: numpy array [3] representing the direction in world coords.
    """
    # Step 1: Sample Azimuthal Angle
    phi = 2.0 * math.pi * zeta_phi
    
    # Step 2: Sample Polar Angle
    numerator = 1.0 - zeta_theta
    denominator = (alpha_r**2 - 1.0) * zeta_theta + 1.0
    
    # Guard against division by zero or negative sqrt
    if denominator <= 0:
        denominator = 1e-8
        
    cos_theta = math.sqrt(numerator / denominator)
    theta = math.acos(cos_theta)
    
    # Step 3: Construct World Direction
    sin_theta = math.sin(theta)
    cos_phi = math.cos(phi)
    sin_phi = math.sin(phi)
    
    l_world = np.array([
        cos_phi * sin_theta,
        sin_phi * sin_theta,
        cos_theta
    ])
    
    return l_world

def transform_to_local(l_world, normal):
    """
    Transforms a world direction vector to the local coordinate system 
    where the normal is the up-vector (Z-axis).
    
    Args:
        l_world: numpy array [3] in world coords.
        normal: numpy array [3] world normal (assumed normalized).
        
    Returns:
        l_local: numpy array [3] in local coords.
    """
    # Construct orthonormal basis for local space
    # Choose an arbitrary vector not parallel to normal
    if abs(normal[0]) > 0.9:
        aux = np.array([1.0, 0.0, 0.0])
    else:
        aux = np.array([0.0, 1.0, 0.0])
        
    t1 = np.cross(aux, normal)
    t1 = t1 / np.linalg.norm(t1)
    t2 = np.cross(normal, t1)
    
    # T(n) maps world to local: dot product with basis vectors
    l_local = np.array([
        np.dot(l_world, t1),
        np.dot(l_world, t2),
        np.dot(l_world, normal)
    ])
    
    return l_local

def compute_specular_term(v, normal, alpha_r, f0, N_L, L_V_func, L_E_func, V_func, I_func, L_p_const):
    """
    Computes the specular term using importance sampling.
    
    Args:
        v: numpy array [3] viewing direction (world).
        normal: numpy array [3] surface normal (world).
        alpha_r: float roughness.
        f0: float or array Fresnel at normal incidence.
        N_L: int number of samples.
        L_V_func: function returning volume radiance for a direction.
        L_E_func: function returning light emissive radiance for a direction.
        V_func: function returning visibility term.
        I_func: function returning interaction term.
        L_p_const: float pre-computed constant factor.
        
    Returns:
        L_p: float estimated specular radiance.
    """
    L_p_sum = 0.0
    
    for _ in range(N_L):
        # Generate random numbers
        zeta_phi = np.random.uniform(0, 1)
        zeta_theta = np.random.uniform(0, 1)
        
        # Sample direction in world, then transform to local
        l_world = sample_specular_direction(zeta_phi, zeta_theta, alpha_r)
        l = transform_to_local(l_world, normal)
        
        # Compute half vector
        h = v + l
        h_norm = np.linalg.norm(h)
        if h_norm < 1e-8:
            continue # Degenerate case
        h = h / h_norm
        
        # Dot products
        v_dot_h = np.dot(v, h)
        n_dot_h = np.dot(normal, h)
        n_dot_l = np.dot(normal, l)
        
        # Guard against division by zero
        if n_dot_h < 1e-8:
            continue
            
        # Evaluate terms
        V_term = V_func(v, l, normal, alpha_r)
        # Schlick's Fresnel approximation [G]
        cos_theta_i = max(0.0, np.dot(v, h))
        F_term = f0 + (1.0 - f0) * (1.0 - cos_theta_i)**5
        Lv_term = L_V_func(l)
        Le_term = L_E_func(l)
        I_term = I_func(v, l, normal)
        
        # Specular contribution
        contribution = V_term * F_term * (4.0 * v_dot_h / n_dot_h) * Lv_term * Le_term * n_dot_l * I_term
        
        L_p_sum += contribution
        
    # Average with pre-factor
    L_p = (L_p_const / N_L) * L_p_sum
    
    return L_p
```

**Parameters:**
- $N_L$: Number of light samples per pixel. Typical value: 128 (composed of 8 polar samples $\times$ 16 azimuthal samples) [S1, unofficial].
- $\hat{\alpha}_r$: Roughness parameter. Range typically $[0, 1]$.

**Edge Cases and Pitfalls:**
- **Gradients:** Gradients are not backpropagated through the sampling process to avoid non-differentiable operations [S1, unofficial].
- **Degenerate Half Vector:** If $\mathbf{v} \approx -\mathbf{l}$, the half vector $\mathbf{h}$ is undefined or unstable. A guard is required [G].
- **Uniform Sampling for Diffuse:** The diffuse term uses uniform sampling instead, where $\theta = \cos^{-1}(1 - \zeta_\theta)$ [S1, unofficial].

## Subtopics

### Uniform Sampling for Diffuse Term
Uses $\theta = \cos^{-1}(1 - \zeta_\theta)$ for the diffuse component, contrasting with the GGX-based importance sampling for specular [S1, unofficial].

## Background
This method is part of the Neural Direct and Joint Inverse Rendering (NDJIR) framework [S1, unofficial]. It applies importance sampling to the specular term of the forward rendering model, deriving the PDF from the GGX microfacet distribution $D$ and geometric factors [S1, unofficial]. The approach avoids backpropagation through the sampler, following suggestions in reference [62] of the original paper [S1, unofficial].
