# Importance Sampling

## Overview
Importance sampling is a Monte Carlo integration technique that accelerates convergence by selecting samples from a probability density function (PDF) $p(x)$ that mimics the shape of the integrand $f(x)$ [S1, unofficial]. Unlike uniform sampling, which treats all regions equally, this method concentrates computational effort on areas where $f(x)$ contributes significantly to the integral, thereby reducing variance [S1, unofficial]. It sets itself apart from its parent [Importance Sampling for Sphere Surface Area](2223-importance-sampling-for-sphere-surface-area.md) by providing the general theoretical framework, while its sibling [Occlusion-Aware vMF Importance Sampler](9557-occlusion-aware-vmf-importance-sampler.md) applies specific directional distributions for participating media.
## How it works
**Inputs:**
- Integrand function $f(x)$ to be integrated over domain $\Omega$.
- Number of samples $N$.

**Outputs:**
- Estimated integral value $F_N$.

**Data Structures:**
- Random number generator producing uniform variates $u \in [0, 1]$.
- Sampler object capable of generating $X_i \sim p(x)$ and evaluating $p(X_i)$.

**Steps:**
1. Generate $N$ independent samples $X_1, \dots, X_N$ from the importance PDF $p(x)$.
2. For each sample $X_i$, evaluate the integrand $f(X_i)$ and the PDF $p(X_i)$.
3. Compute the weighted contribution for each sample: $w_i = \frac{f(X_i)}{p(X_i)}$.
4. Average the contributions to estimate the integral:
   $$ F_N = \frac{1}{N} \sum_{i=1}^{N} \frac{f(X_i)}{p(X_i)} \quad (2.7) $$

**Formulas:**
- The estimator is unbiased if $p(x) > 0$ whenever $f(x) \neq 0$.
- In the ideal case where $p(x) = c f(x)$ for some constant $c$, the term $\frac{f(X_i)}{p(X_i)}$ becomes constant $\frac{1}{c}$, resulting in zero variance [S1, unofficial].

**Parameters:**
- $N$: Number of samples. Larger $N$ reduces variance by $O(1/\sqrt{N})$ [S1, unofficial].

**Edge Cases and Pitfalls:**
- If $p(x) = 0$ where $f(x) \neq 0$, the estimator becomes undefined or biased.
- If $p(x)$ is poorly matched to $f(x)$, variance may exceed that of uniform sampling.
- Numerical underflow/overflow in $f(X_i)/p(X_i)$ if values span many orders of magnitude.

**Pseudocode:**
```python
def importance_sampling(f, sampler, N):
    """
    Estimate integral of f using importance sampling.
    
    Args:
        f: callable, integrand function f(x)
        sampler: object with method sample() returning (x, pdf_value)
                 where x is a sample from p(x) and pdf_value is p(x)
        N: int, number of samples
        
    Returns:
        float: estimated integral value
    """
    total = 0.0
    for i in range(N):
        x, p_x = sampler.sample()
        # Guard against division by zero
        if p_x == 0:
            continue
        f_x = f(x)
        total += f_x / p_x
    return total / N
```

## Operating characteristics
- **Time Complexity:** $O(N)$, where $N$ is the number of samples. Each sample requires one evaluation of $f(x)$ and one evaluation of $p(x)$.
- **Memory Complexity:** $O(1)$ auxiliary space, excluding storage for samples if batched.
- **Performance:** Convergence rate is $O(1/\sqrt{N})$ regardless of dimensionality, but the constant factor is significantly improved when $p(x) \approx f(x)$ [S1, unofficial].
- **Strengths:** Reduces variance compared to uniform sampling; effective for high-dimensional integrals; simple to implement if a good PDF is available.
- **Limitations:** Requires knowledge of a PDF $p(x)$ that approximates $f(x)$; poor choice of $p(x)$ can increase variance; difficult to construct for complex, multi-modal integrands.
- **When to use:** When the integrand has known peaks or regions of high contribution; when uniform sampling is too slow to converge.
- **When not to use:** When no suitable PDF is available; when the cost of sampling from $p(x)$ or evaluating $p(x)$ is prohibitively high.
## Background
The concept of importance sampling is a fundamental technique in Monte Carlo integration, widely used in computer graphics for rendering [S1, unofficial]. It was formalized in the context of light transport simulation to efficiently sample light paths and directions. The method is discussed in "A null-scattering path integral formulation of light transport" by Steven Schürstedt [S1, unofficial].
