# Multiple Importance Sampling

Also called: Multi-sample estimator

## Overview
Multiple Importance Sampling (MIS) is a Monte Carlo integration technique that combines estimates from multiple sampling strategies to reduce variance when no single probability density function (PDF) adequately matches the integrand [S1, unofficial]. Unlike standard importance sampling which relies on one optimal PDF, MIS allows the use of several specialized PDFs, weighting each sample by a factor that ensures the combined estimator remains unbiased [S1, unofficial]. It is particularly useful in rendering when different lighting components (e.g., direct light, indirect bounces) require different sampling distributions [S1, unofficial].

## How it works
**Inputs:**
- $n$: The number of distinct sampling strategies (PDFs) $p_i(x)$ being combined [S1, unofficial].
- $n_i$: The number of samples generated by the $i$-th strategy [S1, unofficial].
- $f(x)$: The integrand function (excluding the PDF) [S1, unofficial].
- $p_i(x)$: The PDF of the $i$-th sampling strategy [S1, unofficial].
- $x_{i,j}$: The $j$-th sample generated by the $i$-th strategy [S1, unofficial].

**Outputs:**
- $I_{MIS}$: The unbiased estimate of the integral $\int_{\Omega} f(x)g(x)dx$ [S1, unofficial].

**Data Structures:**
- A list of $n$ sampling strategies.
- For each strategy $i$, a list of $n_i$ samples $x_{i,j}$ and their corresponding PDF values $p_i(x_{i,j})$.

**Steps:**
1. For each strategy $i$ from $1$ to $n$:
    a. Generate $n_i$ samples $x_{i,1}, \dots, x_{i,n_i}$ using the sampling distribution $p_i(x)$ [S1, unofficial].
    b. For each sample $x_{i,j}$, calculate the weight $w_i(x_{i,j})$ using the balance heuristic [S1, unofficial]:
       $$w_i(x_{i,j}) = \frac{n_i p_i(x_{i,j})}{\sum_{k=1}^n n_k p_k(x_{i,j})}$$
       [S1, unofficial]
    c. Compute the contribution of the sample to the estimator:
       $$\text{contribution}_{i,j} = w_i(x_{i,j}) \frac{f(x_{i,j})}{p_i(x_{i,j})}$$
       [S1, unofficial]
2. Sum the contributions across all strategies and samples to get the final estimate:
   $$I_{MIS} = \sum_{i=1}^n \frac{1}{n_i} \sum_{j=1}^{n_i} w_i(x_{i,j}) \frac{f(x_{i,j})}{p_i(x_{i,j})}$$
   [S1, unofficial]

**Constraints on Weights:**
The weights $w_i(x)$ must satisfy two conditions to ensure an unbiased result [S1, unofficial]:
1. $\sum_{i=1}^n w_i(x) = 1$ for all $x$ where $f(x) \neq 0$ [S1, unofficial].
2. $w_i(x) = 0$ if $p_i(x) = 0$ [S1, unofficial].

This implies that for any point $x$ where the integrand is non-zero, at least one sampling strategy must have a non-zero probability of generating that sample [S1, unofficial].

```python
def multiple_importance_sampling(strategies, integrand):
    """
    strategies: list of tuples (n_i, sample_func, pdf_func)
        n_i: number of samples for this strategy
        sample_func: function that returns a sample x given random numbers
        pdf_func: function that returns p(x) for a given sample x
    integrand: function that returns f(x) for a given sample x
    """
    total_estimate = 0.0
    
    # Pre-calculate PDFs for all samples to compute weights
    # We need to evaluate all PDFs at all sample points to compute the balance heuristic denominator
    all_samples = [] # List of (strategy_index, sample_index, x, pdf_values)
    
    for i, (n_i, sample_func, pdf_func) in enumerate(strategies):
        for j in range(n_i):
            x = sample_func()
            # Evaluate all PDFs at this sample x
            pdf_values = [pdf_k(x) for k, (_, _, pdf_k) in enumerate(strategies)]
            all_samples.append((i, j, x, pdf_values))
            
    # Compute estimates
    for i, (n_i, sample_func, pdf_func) in enumerate(strategies):
        strategy_sum = 0.0
        for j in range(n_i):
            # Find the sample entry for this strategy and index
            # Note: In a real implementation, we would store x and pdf_values directly
            # Here we assume we can retrieve them or re-evaluate. 
            # To be precise and self-contained, we assume we have access to x and pdf_values
            # from the all_samples list.
            
            # Find the specific sample
            sample_entry = None
            for entry in all_samples:
                if entry[0] == i and entry[1] == j:
                    sample_entry = entry
                    break
            
            if sample_entry is None:
                continue
                
            _, _, x, pdf_values = sample_entry
            f_x = integrand(x)
            p_i_x = pdf_values[i]
            
            # Calculate weight using balance heuristic
            # w_i(x) = (n_i * p_i(x)) / sum_k(n_k * p_k(x))
            denominator = sum(n_k * p_k for (n_k, _, _) in strategies for p_k in pdf_values)
            
            # Guard against division by zero if all PDFs are zero
            if denominator == 0:
                weight = 0.0
            else:
                weight = (n_i * p_i_x) / denominator
            
            # Guard against division by zero in the estimator term
            if p_i_x == 0:
                contribution = 0.0
            else:
                contribution = weight * (f_x / p_i_x)
                
            strategy_sum += contribution
            
        total_estimate += strategy_sum / n_i
        
    return total_estimate
```

**Parameters:**
- $n$: Number of sampling techniques [S1, unofficial].
- $n_i$: Number of samples per technique [S1, unofficial].
- Typical values: Not given in the sources.

**Edge Cases and Pitfalls:**
- If $p_i(x) = 0$ for all $i$ at a point where $f(x) \neq 0$, the estimator is undefined or zero depending on implementation, but the condition $\sum w_i(x)=1$ requires at least one $p_i(x) > 0$ [S1, unofficial].
- Precision issues may arise if the denominator in the balance heuristic is very small [G].

## Subtopics

### Tailored MIS Sampling
A variant of MIS that combines exponential and equiangular sampling strategies for photon beam diffusion in participating media [S2, unofficial]. It dedicates samples entirely to the superior PDF except in a small transition zone where it smoothly weights the two strategies, avoiding the wasteful standard balance heuristic [S2, unofficial]. The weights are defined as $w_{exp}(t_i, x) = \text{clamp}((x-a)/(b-a), 0, 1)$ and $w_{eq}(t_i, x) = 1 - w_{exp}(t_i, x)$ [S2, unofficial]. The transition zone boundaries are $a = 0.9/t_0$ and $b = 1.1/t_0$, centered around one diffuse mean free path [S2, unofficial]. With just 3 samples, this combined MIS strategy matches the entire profile, including the peak and asymptotic tail behavior, outperforming either strategy alone [S2, unofficial].

### Multiple Importance Sampling for Guided Sampling
A method to combine multiple guided sampling processes using MIS to improve estimation quality for boundary path integrals in differentiable rendering [S3]. It is used in primary-sample-space guiding techniques to efficiently estimate gradients [S3].

## Operating characteristics
- **Time Complexity:** Proportional to the total number of samples $\sum n_i$ plus the cost of evaluating all PDFs for all samples to compute weights [S1, unofficial].
- **Memory Complexity:** Proportional to the total number of samples to store samples and PDF values for weight calculation [S1, unofficial].
- **Strengths:** Reduces variance by combining the strengths of different sampling strategies; unbiased [S1, unofficial].
- **Limitations:** Requires evaluating multiple PDFs for each sample, increasing computational cost per sample compared to single importance sampling [S1, unofficial].
- **When to use:** When no single PDF closely matches the integrand, or when different parts of the domain are better sampled by different strategies [S1, unofficial].
- **When not to use:** When a single PDF is known to be optimal, or when computational resources are extremely limited and the overhead of multiple PDF evaluations is prohibitive [G].

## Background
Multiple Importance Sampling was introduced by Veach and Guibas in 1995 [S1, S2, unofficial]. It is widely used in computer graphics for rendering, particularly in path tracing and photon mapping, to handle complex lighting scenarios involving multiple light sources and materials [S1, S2, unofficial]. The balance heuristic for weights was also introduced by Veach and Guibas [S1, unofficial].
