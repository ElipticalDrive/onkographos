# Multiple Importance Sampling

Also called: Multi-sample estimator

## Overview
Multiple Importance Sampling (MIS) is a Monte Carlo integration technique that combines estimates from multiple sampling strategies to reduce variance when no single probability density function (PDF) adequately matches the integrand [S1, unofficial]. Unlike standard importance sampling [9521-importance-sampling.md], MIS allows several specialized PDFs to be used simultaneously, weighting each sample to keep the combined estimator unbiased [S1, unofficial].

## How it works
**Inputs:**
- $n$: The number of distinct sampling strategies (PDFs) $p_i(x)$ being combined [S1, unofficial].
- $n_i$: The number of samples generated by the $i$-th strategy [S1, unofficial].
- $f(x)$: The integrand function (excluding the PDF) [S1, unofficial].
- $p_i(x)$: The PDF of the $i$-th sampling strategy [S1, unofficial].
- $x_{i,j}$: The $j$-th sample generated by the $i$-th strategy [S1, unofficial].

**Outputs:**
- $I_{MIS}$: The unbiased estimate of the integral $\int_{\Omega} f(x)g(x)dx$ [S1, unofficial].

**Data Structures:**
- A list of $n$ strategies, each storing its sample count $n_i$, a sample generator, and a PDF evaluator [G].
- For each strategy $i$, an array of size $n_i$ storing tuples of $(x_{i,j}, \text{pdf\_values})$, where $\text{pdf\_values}$ is a list of length $n$ containing $p_k(x_{i,j})$ for all $k \in \{1, \dots, n\}$ [G].

**Steps:**
1. For each strategy $i$ from $1$ to $n$, generate $n_i$ samples $x_{i,1}, \dots, x_{i,n_i}$ using the sampling distribution $p_i(x)$ [S1, unofficial].
2. For each sample $x_{i,j}$, evaluate all PDFs $p_k(x_{i,j})$ for $k \in \{1, \dots, n\}$ [S1, unofficial].
3. Compute the balance heuristic weight for each sample:
   $$w_i(x_{i,j}) = \frac{n_i p_i(x_{i,j})}{\sum_{k=1}^n n_k p_k(x_{i,j})}$$
   [S1, unofficial]
4. Accumulate the estimator:
   $$I_{MIS} = \sum_{i=1}^n \frac{1}{n_i} \sum_{j=1}^{n_i} w_i(x_{i,j}) \frac{f(x_{i,j})}{p_i(x_{i,j})}$$
   [S1, unofficial]

**Constraints on Weights:**
The weights $w_i(x)$ must satisfy two conditions to ensure an unbiased result [S1, unofficial]:
1. $\sum_{i=1}^n w_i(x) = 1$ for all $x$ where $f(x) \neq 0$ [S1, unofficial].
2. $w_i(x) = 0$ if $p_i(x) = 0$ [S1, unofficial].
This implies that for any point $x$ where the integrand is non-zero, at least one sampling strategy must have a non-zero probability of generating that sample [S1, unofficial].

**Pseudocode:**
> **Unverified code.** The code below did not pass a test run against a reference implementation, or no test fits it, so it may contain errors.

```python
def multiple_importance_sampling(strategies, integrand):
    """
    strategies: list of tuples (n_i, sample_func, pdf_func)
        n_i: number of samples for this strategy
        sample_func: function that returns a sample x given random numbers
        pdf_func: function that returns p(x) for a given sample x
    integrand: function that returns f(x) for a given sample x
    """
    total_estimate = 0.0
    # Store samples and evaluate all PDFs at each sample point
    samples = [] # List of lists: samples[i][j] = (x, pdf_values_list)
    
    for i, (n_i, sample_func, pdf_func) in enumerate(strategies):
        samples.append([])
        for j in range(n_i):
            x = sample_func()
            pdf_values = [pdf_k(x) for k, (_, _, pdf_k) in enumerate(strategies)]
            samples[i].append((x, pdf_values))

    for i, (n_i, sample_func, pdf_func) in enumerate(strategies):
        strategy_sum = 0.0
        for j, (x, pdf_values) in enumerate(samples[i]):
            f_x = integrand(x)
            p_i_x = pdf_values[i]

            # Balance heuristic denominator: sum_k(n_k * p_k(x))
            denominator = sum(n_k * pdf_values[k] for k, (n_k, _, _) in enumerate(strategies))

            if denominator == 0:
                weight = 0.0
            else:
                weight = (n_i * p_i_x) / denominator

            if p_i_x == 0:
                contribution = 0.0
            else:
                contribution = weight * (f_x / p_i_x)

            strategy_sum += contribution
        total_estimate += strategy_sum / n_i

    return total_estimate
```

**Parameters:**
- $n$: Number of sampling techniques [S1, unofficial].
- $n_i$: Number of samples per technique [S1, unofficial].
- Typical values: Not given in the sources. [G]

**Edge Cases and Pitfalls:**
- If $p_i(x) = 0$ for all $i$ at a point where $f(x) \neq 0$, the estimator is undefined; the weight constraint requires at least one $p_i(x) > 0$ [S1, unofficial].
- Precision issues may arise if the denominator in the balance heuristic is very small [G].

## Subtopics

### Tailored MIS Sampling
A variant that combines exponential and equiangular sampling for photon beam diffusion in participating media [S2, unofficial]. It dedicates samples entirely to the superior PDF except in a small transition zone where it smoothly weights the two strategies, avoiding the wasteful standard balance heuristic [S2, unofficial]. The weights are defined as $w_{exp}(t_i, x) = \text{clamp}((x-a)/(b-a), 0, 1)$ and $w_{eq}(t_i, x) = 1 - w_{exp}(t_i, x)$ [S2, unofficial]. The transition zone boundaries are $a = 0.9/t_0$ and $b = 1.1/t_0$, centered around one diffuse mean free path [S2, unofficial]. With just 3 samples, this combined strategy matches the entire profile, including the peak and asymptotic tail behavior, making it preferable when standard MIS fails to capture both near-source and far-field contributions [S2, unofficial].

### Multiple Importance Sampling for Guided Sampling
A method to combine multiple guided sampling processes using MIS to improve estimation quality for boundary path integrals in differentiable rendering [S3]. It is used in primary-sample-space guiding techniques to efficiently estimate gradients, and is chosen when gradient estimation requires combining multiple importance sampling paths [S3].

### Feature Density Importance Sampling
A strategy that combines area-based and vertex-based probabilities to sample triangles during training, addressing inefficient convergence caused by non-uniform feature distribution [S4, unofficial]. The sampling probability is $p(i) = \eta \frac{A(i)}{A_{total}} + (1 - \eta) \frac{N(i)}{N_{total}}$, where $\eta$ controls the weighting factor [S4, unofficial]. It is chosen when training convergence is bottlenecked by uneven feature density across mesh faces [S4, unofficial].

## Operating characteristics
- **Time Complexity:** Proportional to $\sum n_i$ plus the cost of evaluating all PDFs for all samples to compute weights [G].
- **Memory Complexity:** Not given in the sources. [G]
- **Measured Performance:** Not given in the sources. [G]
- **Scaling:** Scales linearly with the number of strategies and samples, but PDF evaluation overhead grows with $n$ [G].
- **Strengths:** Reduces variance by combining the strengths of different sampling strategies; remains unbiased [S1, unofficial].
- **Limitations:** Requires evaluating multiple PDFs for each sample, increasing computational cost per sample compared to single importance sampling [S1, unofficial].
- **When to use:** When no single PDF closely matches the integrand, or when different parts of the domain are better sampled by different strategies [S1, unofficial].
- **When not to use:** When a single PDF is known to be optimal, or when computational resources are extremely limited and the overhead of multiple PDF evaluations is prohibitive [G].

## Background
Multiple Importance Sampling was introduced by Veach in 1997 [S1, unofficial]. It is widely used in computer graphics for rendering, particularly in path tracing and photon mapping, to handle complex lighting scenarios involving multiple light sources and materials [S1, unofficial]. The balance heuristic for weights was also introduced by Veach [S1, unofficial].
