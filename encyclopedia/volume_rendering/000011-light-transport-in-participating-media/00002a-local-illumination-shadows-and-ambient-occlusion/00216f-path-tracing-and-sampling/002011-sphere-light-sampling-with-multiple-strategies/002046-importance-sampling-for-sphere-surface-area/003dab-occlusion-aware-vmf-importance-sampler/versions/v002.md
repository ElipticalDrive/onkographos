# Occlusion-Aware vMF Importance Sampler

Also called: Spatially-varying vMF distribution, vMF mixture sampler

## Overview
This method provides a lightweight importance sampler for incoming radiance in participating media and surface rendering, using a Neural Graphics Primitive (NGP) to predict a mixture of von Mises-Fisher (vMF) distributions [S1]. It solves the problem of approximating the true distribution of incoming light, including occlusions, by allowing the model to "turn off" lobes for light sources that are occluded from a specific point in space [S1].

## How it works
**Inputs:**
- A 3D point $\mathbf{x}$ in the scene [S1].
- A trained NGP mapping $\mathbf{x}$ to scalar parameters [S1].
- A set of $M$ sample directions $\{\boldsymbol{\omega}^j_{in}\}_{j=1}^M$ generated by a proposal distribution $p$ [S1].
- Incident radiance estimates $\hat{L}_{NeRF}(\mathbf{x}, \boldsymbol{\omega}^j_{in})$ from a NeRF cache or similar estimator [S1].

**Outputs:**
- A mixture of $L$ vMF distributions parameterized by $\{\lambda_\ell(\mathbf{x}), \boldsymbol{\mu}_\ell(\mathbf{x}), \kappa_\ell(\mathbf{x})\}_{\ell=1}^L$ [S1].
- The probability density value $\text{mixture}(\mathbf{d}; \mathbf{x})$ for any direction $\mathbf{d}$ [S1].

**Data Structures:**
The NGP consists of:
1. **Hash Grid:** Maximum resolution $2048$ [S1].
2. **Hash Map:** Fixed size $2^{19}$ [S1].
3. **MLP:** 2-layer network with 64 hidden units [S1].
4. **Output:** The MLP predicts $5L$ scalars for each point $\mathbf{x}$, interpreted as $L$ sets of parameters $\{\boldsymbol{\mu}'_\ell(\mathbf{x}), \kappa_\ell(\mathbf{x}), \lambda_\ell(\mathbf{x})\}$ [S1].

**Parameters:**
- $L = 128$: Number of vMF lobes [S1].
- NGP Resolution: $2048$ [S1].
- MLP: 2 layers, 64 hidden units [S1].

**Formulas:**
The mixture distribution is defined as [S1]:
$$
\text{mixture}(\mathbf{d}; \mathbf{x}) = \frac{1}{Z} \sum_{\ell=1}^{L} \lambda_\ell(\mathbf{x}) \text{vMF}(\mathbf{d}; \boldsymbol{\mu}_\ell(\mathbf{x}), \kappa_\ell(\mathbf{x}))
$$
where $Z = \sum_{\ell=1}^{L} \lambda_\ell(\mathbf{x})$ is the partition function [S1].

The mean direction $\boldsymbol{\mu}_\ell(\mathbf{x})$ is derived from the raw NGP output $\boldsymbol{\mu}'_\ell(\mathbf{x})$ by normalizing the vector from the point $\mathbf{x}$ to the predicted source location [S1]:
$$
\boldsymbol{\mu}_\ell(\mathbf{x}) = \frac{\boldsymbol{\mu}'_\ell(\mathbf{x}) - \mathbf{x}}{\| \boldsymbol{\mu}'_\ell(\mathbf{x}) - \mathbf{x} \|}
$$
This ensures the lobe points towards the light source [S1]. The parameters $\lambda_\ell$ (mixture weights) and $\kappa_\ell$ (concentration) are non-negative scalars predicted directly by the NGP [S1].

**Training Objective:**
The parameters are optimized to match the true incoming radiance distribution, accounting for occlusions [S1]. The loss function is [S1]:
$$
\mathcal{L}_{vMF} = \frac{1}{M} \sum_{j=1}^{M} \frac{\| Z \cdot \text{mixture}(\boldsymbol{\omega}^j_{in}; \mathbf{x}) - \bar{L}(\mathbf{x}, \boldsymbol{\omega}^j_{in}) \|^2}{p(\boldsymbol{\omega}^j_{in})}
$$
where $\bar{L}(\mathbf{x}, \boldsymbol{\omega}^j_{in}) = \| \hat{L}_{NeRF}(\mathbf{x}, \boldsymbol{\omega}^j_{in}) \|^2$ is the L2 norm of incident radiance across channels [S1]. $p$ is the sampling distribution used to generate the samples, which combines the mixture distribution $q$ and a standard material-based importance sampling distribution [S1].

**Pseudocode:**
```python
import math
import numpy as np

def vmf_pdf(d, mu, kappa):
    """Computes the PDF of a 3D von Mises-Fisher distribution [G]."""
    d = d / np.linalg.norm(d)
    mu = mu / np.linalg.norm(mu)
    cos_theta = np.clip(np.dot(d, mu), -1.0, 1.0)
    if kappa == 0:
        return 1.0 / (4.0 * math.pi)
    sinh_kappa = np.sinh(kappa)
    if sinh_kappa == 0:
        return 1.0 / (4.0 * math.pi)
    c_d = kappa / (4.0 * math.pi * sinh_kappa)
    return c_d * np.exp(kappa * cos_theta)

def sample_vmf(mu, kappa):
    """Samples from a 3D vMF distribution using standard rejection sampling [G]."""
    if kappa == 0:
        u1 = np.random.uniform(0, 1)
        u2 = np.random.uniform(0, 1)
        theta = 2 * np.pi * u1
        phi = np.arccos(2 * u2 - 1)
        return np.array([np.sin(phi)*np.cos(theta), np.sin(phi)*np.sin(theta), np.cos(phi)])
    while True:
        u1 = np.random.uniform(0, 1)
        u2 = np.random.uniform(0, 1)
        u3 = np.random.uniform(0, 1)
        z = (1 - (1 + kappa) * u1) / (1 + kappa * u1)
        if z < -1 or z > 1:
            continue
        if u2 * (1 - z**2) <= (kappa * z / (1 + kappa))**2:
            break
    theta = 2 * np.pi * u3
    cos_theta = z
    sin_theta = np.sqrt(1 - z**2)
    # Construct vector in local frame aligned with mu
    # Find orthogonal basis
    if abs(mu[2]) < 0.9:
        v1 = np.cross(mu, [0, 0, 1])
    else:
        v1 = np.cross(mu, [1, 0, 0])
    v1 = v1 / np.linalg.norm(v1)
    v2 = np.cross(mu, v1)
    return mu * cos_theta + v1 * sin_theta * np.cos(theta) + v2 * sin_theta * np.sin(theta)

def get_ngp_params(x, ngp_model, L):
    """Retrieves the 5L parameters from the NGP for point x [S1]."""
    raw_output = ngp_model.forward(x)
    mu_prime = raw_output[:3*L].reshape(L, 3)
    kappa = raw_output[3*L:4*L]
    lambda_weights = raw_output[4*L:]
    return mu_prime, kappa, lambda_weights

def compute_mixture_pdf(d, x, ngp_model, L):
    """Computes the mixture PDF for direction d at point x [S1]."""
    mu_prime, kappa, lambda_weights = get_ngp_params(x, ngp_model, L)
    Z = np.sum(lambda_weights)
    if Z == 0:
        return 0.0
    total_pdf = 0.0
    for l in range(L):
        diff = mu_prime[l] - x
        norm_diff = np.linalg.norm(diff)
        if norm_diff < 1e-8:
            mu_l = np.array([1.0, 0.0, 0.0])
        else:
            mu_l = diff / norm_diff
        pdf_l = vmf_pdf(d, mu_l, kappa[l])
        total_pdf += lambda_weights[l] * pdf_l
    return total_pdf / Z

def compute_loss(x, samples, radiance_cache, ngp_model, proposal_dist, L):
    """Computes the L_vMF loss [S1]."""
    M = len(samples)
    mu_prime, kappa, lambda_weights = get_ngp_params(x, ngp_model, L)
    Z = np.sum(lambda_weights)
    L_sum = 0.0
    for j in range(M):
        omega = samples[j]
        mixture_pdf = compute_mixture_pdf(omega, x, ngp_model, L)
        L_neurf = radiance_cache(x, omega)
        L_bar = np.linalg.norm(L_neurf) ** 2
        p_omega = proposal_dist(omega)
        if p_omega == 0:
            continue
        term = (Z * mixture_pdf - L_bar) ** 2 / p_omega
        L_sum += term
    return L_sum / M
```

**Edge Cases and Pitfalls:**
- If the predicted source location $\boldsymbol{\mu}'_\ell(\mathbf{x})$ coincides with $\mathbf{x}$, the mean direction $\boldsymbol{\mu}_\ell$ is undefined [G] A fallback to a uniform direction or a small epsilon perturbation is required.
- The parameters $\lambda_\ell$ and $\kappa_\ell$ must be non-negative [G] The NGP output should be passed through a ReLU or softplus activation to enforce non-negativity, though the source states they are "nonnegative numbers" without specifying the activation.

## Operating characteristics
- **Time Complexity:** Scales linearly with the number of lobes $L$ and the NGP lookup cost [S1].
- **Memory Complexity:** Determined by the NGP grid and hash map size $2^{19}$ [S1].
- **Performance:** Described as lightweight [S1].
- **Strengths:** Capable of modeling occlusions by turning off lobes and provides spatially varying distributions [S1].
- **Limitations:** Requires training the NGP and depends on the quality of the NeRF cache for radiance estimation [S1].

## Background
The method originates from "Flash Cache: Reducing Bias in Radiance Cache Based Inverse Rendering" by Attal et al. [S1]. It is used within the Flash Cache framework for inverse rendering to approximate incoming radiance distributions [S1]. The use of vMF mixtures for directional distributions is adapted here for spatial variation and occlusion awareness [S1].
