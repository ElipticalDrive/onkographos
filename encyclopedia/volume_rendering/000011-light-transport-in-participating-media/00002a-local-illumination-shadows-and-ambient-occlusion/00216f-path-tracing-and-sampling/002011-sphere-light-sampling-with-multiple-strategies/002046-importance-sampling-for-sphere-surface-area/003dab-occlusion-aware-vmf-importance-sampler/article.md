# Occlusion-Aware vMF Importance Sampler

Also called: Spatially-varying vMF distribution, vMF mixture sampler

## Overview
This method provides a lightweight importance sampler for incoming radiance in participating media and surface rendering, using a Neural Graphics Primitive (NGP) to predict a mixture of von Mises-Fisher (vMF) distributions [S1]. It solves the problem of approximating the true distribution of incoming light, including occlusions, by allowing the model to "turn off" lobes for light sources that are occluded from a specific point in space [S1]. It builds on [Importance Sampling for Sphere Surface Area](2223-importance-sampling-for-sphere-surface-area.md) by adding spatial variation and occlusion awareness via the NGP, distinguishing it from static [Importance Sampling](9521-importance-sampling.md) strategies.

## How it works
**Inputs:**
- A 3D point $\mathbf{x}$ in the scene.
- A pre-trained NGP mapping $\mathbf{x}$ to scalar parameters.
- A set of $M$ sample directions $\{\boldsymbol{\omega}^j_{in}\}_{j=1}^M$ generated by a proposal distribution $p$.
- Incident radiance estimates $\hat{L}_{NeRF}(\mathbf{x}, \boldsymbol{\omega}^j_{in})$ from a NeRF cache or similar estimator.

**Outputs:**
- A mixture of $L$ vMF distributions parameterized by $\{\lambda_\ell(\mathbf{x}), \boldsymbol{\mu}_\ell(\mathbf{x}), \kappa_\ell(\mathbf{x})\}_{\ell=1}^L$.
- The probability density value $\text{mixture}(\mathbf{d}; \mathbf{x})$ for any direction $\mathbf{d}$.

**Data Structures:**
The NGP consists of:
1.  **Hash Grid:** Maximum resolution $2048 \times 2048 \times 2048$. Hash map size $2^{19}$ [S1].
2.  **MLP:** 2-layer network with 64 hidden units [S1].
3.  **Output:** The MLP predicts $5L$ scalars for each point $\mathbf{x}$. These scalars are interpreted as $L$ sets of parameters $\{\boldsymbol{\mu}'_\ell(\mathbf{x}), \kappa_\ell(\mathbf{x}), \lambda_\ell(\mathbf{x})\}$ [S1].

**Parameters:**
- $L = 128$: Number of vMF lobes [S1].
- NGP Resolution: $2048$ [S1].
- MLP: 2 layers, 64 hidden units [S1].

**Formulas:**
The mixture distribution is defined as [S1]:
$$
\text{mixture}(\mathbf{d}; \mathbf{x}) = \frac{1}{Z} \sum_{\ell=1}^{L} \lambda_\ell(\mathbf{x}) \text{vMF}(\mathbf{d}; \boldsymbol{\mu}_\ell(\mathbf{x}), \kappa_\ell(\mathbf{x}))
$$
where $Z = \sum_{\ell=1}^{L} \lambda_\ell(\mathbf{x})$ is the partition function [S1].

The mean direction $\boldsymbol{\mu}_\ell(\mathbf{x})$ is derived from the raw NGP output $\boldsymbol{\mu}'_\ell(\mathbf{x})$ by normalizing the vector from the point $\mathbf{x}$ to the predicted source location [S1]:
$$
\boldsymbol{\mu}_\ell(\mathbf{x}) = \frac{\boldsymbol{\mu}'_\ell(\mathbf{x}) - \mathbf{x}}{\| \boldsymbol{\mu}'_\ell(\mathbf{x}) - \mathbf{x} \|}
$$
This ensures the lobe points towards the light source [S1]. The parameters $\lambda_\ell$ (mixture weights) and $\kappa_\ell$ (concentration) are non-negative scalars predicted directly by the NGP [S1].

**Training Objective:**
The parameters are optimized to match the true incoming radiance distribution, accounting for occlusions [S1]. The loss function is [S1]:
$$
\mathcal{L}_{vMF} = \frac{1}{M} \sum_{j=1}^{M} \frac{\| Z \cdot \text{mixture}(\boldsymbol{\omega}^j_{in}; \mathbf{x}) - \bar{L}(\mathbf{x}, \boldsymbol{\omega}^j_{in}) \|^2}{p(\boldsymbol{\omega}^j_{in})}
$$
where $\bar{L}(\mathbf{x}, \boldsymbol{\omega}^j_{in}) = \| \hat{L}_{NeRF}(\mathbf{x}, \boldsymbol{\omega}^j_{in}) \|^2$ is the L2 norm of incident radiance across channels [S1]. $p$ is the sampling distribution used to generate the samples, which combines the mixture distribution $q$ and a standard material-based importance sampling distribution [S1].

import math
import numpy as np

def vmf_pdf(d, mu, kappa):
    """
    Computes the PDF of a von Mises-Fisher distribution.
    d: direction vector (3,)
    mu: mean direction vector (3,)
    kappa: concentration parameter (scalar)
    """
    # Ensure inputs are normalized
    d = d / np.linalg.norm(d)
    mu = mu / np.linalg.norm(mu)
    
    cos_theta = np.dot(d, mu)
    # Clamp to [-1, 1] for numerical stability
    cos_theta = np.clip(cos_theta, -1.0, 1.0)
    
    # vMF PDF: C_d(kappa) * exp(kappa * cos_theta)
    # C_d(kappa) = kappa^(d-1) / ((2*pi)^(d/2) * I_{d/2-1}(kappa))
    # For 3D (d=3): C_3(kappa) = kappa / (4*pi * sinh(kappa))
    if kappa == 0:
        return 1.0 / (4.0 * math.pi)
    
    sinh_kappa = np.sinh(kappa)
    if sinh_kappa == 0:
        return 1.0 / (4.0 * math.pi)
        
    c_d = kappa / (4.0 * math.pi * sinh_kappa)
    return c_d * np.exp(kappa * cos_theta)

    return mu_prime, kappa, lambda_weights

def compute_mixture_pdf(d, x, ngp_model):
    """
    Computes the mixture PDF for direction d at point x.
    """
    mu_prime, kappa, lambda_weights = get_ngp_params(x, ngp_model)
    
    L = 128
    Z = np.sum(lambda_weights)
    
    if Z == 0:
        return 0.0
        
    total_pdf = 0.0
    for l in range(L):
        # Compute mean direction mu_l
        diff = mu_prime[l] - x
        norm_diff = np.linalg.norm(diff)
        if norm_diff < 1e-8:
            # Degenerate case: point coincides with predicted source
            # Direction is undefined. Return uniform or handle as error.
            # [G] Default to uniform distribution for this lobe if direction is undefined.
            mu_l = np.array([1.0, 0.0, 0.0]) 
        else:
            mu_l = diff / norm_diff
            
        # Compute vMF PDF
        pdf_l = vmf_pdf(d, mu_l, kappa[l])
        
        # Add weighted contribution
        total_pdf += lambda_weights[l] * pdf_l
        
    return total_pdf / Z

def compute_loss(x, samples, radiance_cache, ngp_model, proposal_dist):
    """
    Computes the L_vMF loss.
    samples: array of shape (M, 3) of directions omega_in
    radiance_cache: function returning L_NeRF(x, omega)
    proposal_dist: function returning p(omega)
    """
    M = len(samples)
    L_sum = 0.0
    
    for j in range(M):
        omega = samples[j]
        
        # Get mixture PDF
        mixture_pdf = compute_mixture_pdf(omega, x, ngp_model)
        
        # Get radiance
        L_neurf = radiance_cache(x, omega)
        L_bar = np.linalg.norm(L_neurf) ** 2 # L2 norm squared
        
        # Get proposal probability
        p_omega = proposal_dist(omega)

        Z = np.sum(lambda_weights)
        
        term = (Z * mixture_pdf - L_bar) ** 2 / p_omega
        L_sum += term
        
    return L_sum / M

**Edge Cases and Pitfalls:**
- If the predicted source location $\boldsymbol{\mu}'_\ell(\mathbf{x})$ coincides with $\mathbf{x}$, the mean direction $\boldsymbol{\mu}_\ell$ is undefined. [G] A fallback to a uniform direction or a small epsilon perturbation is required.
- The NGP hash map size is fixed at $2^{19}$ [S1].
- The parameters $\lambda_\ell$ and $\kappa_\ell$ must be non-negative. [G] The NGP output should be passed through a ReLU or softplus activation to enforce non-negativity, though the source states they are "nonnegative numbers" without specifying the activation.

## Operating characteristics
- **Time Complexity:** Depends on the number of lobes $L$ and the NGP lookup cost. For $L=128$, the mixture evaluation involves 128 vMF PDF computations and a sum. NGP lookup is $O(1)$ with hash collisions.
- **Memory Complexity:** The NGP grid size is $2048^3$ with hash map size $2^{19}$ [S1]. The MLP has $2 \times 64$ hidden units.
- **Performance:** The method is described as "lightweight" [S1]. It is used in inverse rendering contexts to reduce bias in radiance cache based methods [S1].
- **Strengths:** Capable of modeling occlusions by turning off lobes [S1]. Spatially varying.
- **Limitations:** Requires training the NGP. Performance depends on the quality of the NeRF cache for radiance estimation.

## Background
The method originates from "Flash Cache: Reducing Bias in Radiance Cache Based Inverse Rendering" by Attal et al. [S1]. It is part of a broader approach to inverse rendering that uses neural representations (NGPs) to accelerate radiance cache computations and importance sampling. The use of vMF mixtures for directional distributions is a common technique in physically-based rendering, adapted here for spatial variation and occlusion awareness.
