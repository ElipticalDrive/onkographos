# Volumetric Scattering via Ray Marching (Single Light)

Also called: Exponential Fog Light Shafts, Ray Marching Light Volume Integration, Ray Marching with Spot Factor, Tomas Ohlsson's volumetric shader, Volumetric.frag method

## Overview
This method simulates volumetric light shafts (God rays) for spot lights by ray marching from the camera through a participating medium, integrating scattering contributions along the view ray. It differs from full path tracing by approximating single scattering only and typically operates as a post-processing compute shader pass. It sets itself apart from simple blur-based light shafts by explicitly calculating light attenuation, spot cone factors, and phase function scattering at each sample point along the view ray.

## How it works
The method reconstructs world-space positions from depth, then marches along the view vector. At each sample, it calculates the contribution of a spot light based on distance, spot cone attenuation, and exponential fog, modulated by a phase function.

### Inputs and Outputs
*   **Inputs**:
    *   `inputTexture`: Color buffer (SRGB or linear depending on pipeline).
    *   `depthTexture`: Depth buffer (linear or non-linear depending on pipeline).
    *   `gInvProj`: Inverse projection matrix.
    *   `gInvView`: Inverse view matrix.
    *   `gCameraPos`: Camera position in world space.
    *   `gLights`: Array of light structures containing `Position`, `Direction`, `Range`, `Color`, `VolumetricStrength`, `outerCosine`, `innerCosine`, `SpotPower`, `Type`.
    *   Constants: `absorptionTau`, `absorptionColor`, `scatteringSamples`, `scatteringTau`, `scatteringZFar`, `scatteringColor`.
*   **Outputs**:
    *   `outputTexture`: Accumulated volumetric scattering color.

### Data Structures
**Constant Buffer 'VolumetricCB' Layout** [S1, unofficial]:
*   `c0.x`: `absorptionTau` (float)
*   `c0.y`: `absorptionColor` (float3)
*   `c1.x`: `scatteringSamples` (int)
*   `c1.y`: `scatteringTau` (float)
*   `c1.z`: `scatteringZFar` (float)
*   `c2`: `scatteringColor` (float3)
*   `c3-c6`: `gInvProj` (matrix)
*   `c7-c10`: `gInvView` (matrix)
*   `c11`: `gCameraPos` (float3)
*   `c12+`: `gLights` (array of Light structs)

**Light Struct Fields** [S1, unofficial]:
*   `Position`: float3
*   `Direction`: float3
*   `Range`: float
*   `Color`: float3
*   `VolumetricStrength`: float
*   `outerCosine`: float
*   `innerCosine`: float
*   `SpotPower`: float
*   `Type`: int (enum, e.g., `SPOT_LIGHT`)

### Numbered Steps

1.  **Reconstruct World Position**:
    *   Get pixel coordinates $(u, v)$ and depth $d$.
    *   Convert to NDC: $x = \frac{u}{W} \cdot 2 - 1$, $y = \frac{v}{H} \cdot (-2) + 1$, $z = d$.
    *   Form NDC vector $\mathbf{p}_{ndc} = [x, y, z, 1]^T$.
    *   Transform to view space: $\mathbf{p}_{view} = \mathbf{p}_{ndc} \cdot \mathbf{M}_{invProj}$.
    *   Divide by $w$: $\mathbf{p}_{view} /= \mathbf{p}_{view}.w$.
    *   Transform to world space: $\mathbf{p}_{world} = \mathbf{p}_{view} \cdot \mathbf{M}_{invView}$.
    *   Result: $\mathbf{W} = \mathbf{p}_{world}.xyz$ [S1, unofficial].

2.  **Initialize Ray March**:
    *   Calculate vector from camera to fragment: $\mathbf{V}_{cf} = \mathbf{W} - \mathbf{C}$, where $\mathbf{C}$ is `gCameraPos`.
    *   If $|\mathbf{V}_{cf}| > \text{scatteringZFar}$, clamp: $\mathbf{V}_{cf} = \text{normalize}(\mathbf{V}_{cf}) \cdot \text{scatteringZFar}$.
    *   Calculate step vector: $\mathbf{\Delta} = \mathbf{V}_{cf} / (\text{scatteringSamples} + 1)$.
    *   Calculate random offset: $r = \text{random}(\mathbf{W}.xy + \mathbf{W}.z)$.
    *   Set start position: $\mathbf{X}_0 = \mathbf{C} + \mathbf{\Delta} \cdot r$.
    *   Calculate normalized view direction: $\mathbf{V}_{dir} = \text{normalize}(\mathbf{C} - \mathbf{W})$. [S1, unofficial]

3.  **Scattering Loop**:
    *   Initialize result $\mathbf{R} = [0, 0, 0]$.
    *   For $i$ from $0$ to $\text{scatteringSamples} - 1$:
        *   Current sample position: $\mathbf{X} = \mathbf{X}_0 + \mathbf{\Delta} \cdot i$.
        *   Calculate light vector: $\mathbf{L}_{vec} = \mathbf{X} - \mathbf{L}_{pos}$, where $\mathbf{L}_{pos}$ is light position.
        *   Calculate light distance: $d_L = |\mathbf{L}_{vec}|$.
        *   Calculate solid angle factor: $\Omega = 4\pi d_L^2$.
        *   Calculate absorption transmittance from light to sample: $T_{abs}(d_L) = \mathbf{C}_{abs} \cdot e^{-d_L (\tau_{abs} + \tau_{scat})}$.
        *   Calculate visibility: $V_{is} = 1.0$ [G] (Note: Sources indicate constant 1.0 is a simplification that may cause artifacts; shadow maps should ideally be used [S1, unofficial]).
        *   Calculate incoming radiance: $L_{in} = \frac{T_{abs}(d_L) \cdot V_{is} \cdot \mathbf{L}_{diff} \cdot \mathbf{L}_{spotPower}}{\Omega}$.
        *   Calculate phase function: $P(\theta) = \frac{0.5 + 16.5 x^{32}}{4\pi}$, where $x = \frac{1 + \cos\theta}{2}$ and $\cos\theta = \frac{\mathbf{L}_{vec} \cdot \mathbf{V}_{dir}}{|\mathbf{L}_{vec}| |\mathbf{V}_{dir}|}$.
        *   Calculate scattered radiance: $L_{scat} = L_{in} \cdot \tau_{scat} \cdot \mathbf{C}_{scat} \cdot P(\theta)$.
        *   Calculate transmittance from sample to camera: $T_{cam} = T_{abs}(|\mathbf{X} - \mathbf{C}|)$.
        *   Accumulate: $\mathbf{R} += L_{scat} \cdot T_{cam} \cdot |\mathbf{\Delta}|$.
        *   Advance: $\mathbf{X}_0 += \mathbf{\Delta}$ (or use loop index for position). [S1, unofficial]

4.  **Main Dispatch**:
    *   For each pixel, reconstruct world position.
    *   For each light in `gLights`:
        *   If `Type == SPOT_LIGHT` and distance to light $< \text{FalloffEnd}$:
            *   Add volumetric scattering result to output. [S1, unofficial]

### Formulas

**Absorption Transmittance** [S1, unofficial]:
$$ T_{abs}(dist) = \mathbf{C}_{abs} \times e^{-dist \times (\tau_{abs} + \tau_{scat})} $$
Where:
*   $\mathbf{C}_{abs}$: `absorptionColor`
*   $\tau_{abs}$: `absorptionTau`
*   $\tau_{scat}$: `scatteringTau`

**Phase Function** [S1, unofficial]:
$$ P(\theta) = \frac{0.5 + 16.5 \times x^{32}}{4\pi} $$
Where:
*   $x = \frac{1 + \cos\theta}{2}$
*   $\cos\theta = \frac{\mathbf{inDir} \cdot \mathbf{outDir}}{|\mathbf{inDir}| |\mathbf{outDir}|}$

**Spot Factor Calculation** [S1, unofficial]:
$$ \text{SpotFactor} = \max(\mathbf{L}_{vec} \cdot \mathbf{L}_{dir}, 0.0)^{\mathbf{L}_{spotPower}} $$
*Note: In the alternative implementation, a linear falloff between inner and outer cosine is squared.*

### Parameters
*   `absorptionTau`: float, typical value $-0.061$ [S1, unofficial]. Controls absorption coefficient.
*   `scatteringTau`: float, typical value $0.059$ [S1, unofficial]. Controls scattering coefficient.
*   `scatteringSamples`: int, typical value $16$ [S1, unofficial]. Number of samples per view ray.
*   `scatteringZFar`: float. Maximum distance for ray marching.

### Pseudocode

```python
import math

def random(co):
    return math.frac(math.sin(math.dot(co.xy, [12.9898, 78.233])) * 43758.5453123)

def absorption_transmittance(dist, absorption_color, absorption_tau, scattering_tau):
    return absorption_color * math.exp(-dist * (absorption_tau + scattering_tau))

def phase_function(in_dir, out_dir):
    cos_angle = math.dot(in_dir, out_dir) / (math.length(in_dir) * math.length(out_dir))
    x = (1.0 + cos_angle) / 2.0
    x32 = x ** 32
    return (0.5 + 16.5 * x32) / (4.0 * math.pi)

def volumetric_scattering(world_position, camera_pos, light, inv_proj, inv_view, 
                          absorption_tau, absorption_color, scattering_samples, 
                          scattering_tau, scattering_zfar, scattering_color):
    # Reconstruct view vector
    cam_to_frag = world_position - camera_pos
    dist_cf = math.length(cam_to_frag)
    
    if dist_cf > scattering_zfar:
        cam_to_frag = math.normalize(cam_to_frag) * scattering_zfar
        
    delta_step = cam_to_frag / (scattering_samples + 1)
    frag_to_cam_norm = math.normalize(camera_pos - world_position)
    
    # Random offset
    rand_val = random([world_position.x, world_position.y + world_position.z])
    x = camera_pos + delta_step * rand_val
    
    result = [0.0, 0.0, 0.0]
    
    for i in range(scattering_samples):
        # Light vector
        light_to_x = x - light.position
        light_dist = math.length(light_to_x)
        
        # Solid angle
        omega = 4.0 * math.pi * light_dist * light_dist
        
        # Transmittance from light
        t_abs_light = absorption_transmittance(light_dist, absorption_color, absorption_tau, scattering_tau)
        
        # Visibility (Simplified to 1.0 per source, but note pitfall)
        visibility = 1.0 
        
        # Incoming radiance
        # Note: light.diffuse and light.spot_power are assumed to be pre-calculated or part of light struct
        # In source: light.Diffuse * light.SpotPower / omega
        # Assuming light.diffuse is color and spot_power is intensity factor or similar
        lin = t_abs_light * visibility * light.diffuse * light.spot_power / omega
        
        # Phase function
        p_func = phase_function(math.normalize(light_to_x), frag_to_cam_norm)
        
        # Scattered radiance
        li = lin * scattering_tau * scattering_color * p_func
        
        # Transmittance to camera
        dist_x_cam = math.length(x - camera_pos)
        t_abs_cam = absorption_transmittance(dist_x_cam, absorption_color, absorption_tau, scattering_tau)
        
        # Accumulate
        result += li * t_abs_cam * math.length(delta_step)
        
        # Advance
        x += delta_step
        
    return result

def compute_shader(pixel, depth, input_texture, output_texture, inv_proj, inv_view, camera_pos, 
                   lights, absorption_tau, absorption_color, scattering_samples, scattering_tau, 
                   scattering_zfar, scattering_color):
    # Reconstruct world position
    width, height = input_texture.dimensions()
    u, v = pixel
    x_ndc = (u / width) * 2 - 1
    y_ndc = (v / height) * -2 + 1
    z_ndc = depth
    
    ndc = [x_ndc, y_ndc, z_ndc, 1.0]
    p_view = math.mul(ndc, inv_proj)
    p_view = [p_view[0]/p_view[3], p_view[1]/p_view[3], p_view[2]/p_view[3]]
    world_pos = math.mul(p_view, inv_view)
    world_pos = [world_pos[0], world_pos[1], world_pos[2]]
    
    volumetric_color = [0.0, 0.0, 0.0]
    
    for light in lights:
        if light.type == SPOT_LIGHT:
            dist_light = math.length(light.position - world_pos)
            if dist_light < light.falloff_end:
                vol = volumetric_scattering(world_pos, camera_pos, light, inv_proj, inv_view,
                                            absorption_tau, absorption_color, scattering_samples,
                                            scattering_tau, scattering_zfar, scattering_color)
                volumetric_color += vol
                
    output_texture[pixel] = volumetric_color + input_texture[pixel]
```

### Edge Cases and Pitfalls
*   **Visibility**: Setting visibility to a constant $1.0$ ignores shadow maps and results in undesired output (light shafts appearing through occluders) [S1, unofficial]. Correct visibility calculation is critical.
*   **Light Direction Transformation**: Incorrect transformation of light direction vectors causes volume direction errors. Multiplying light direction by the view matrix may fix vehicle headlights but break street lamps, and vice versa. The correct transformation depends on whether the light direction is stored in world or view space [S1, unofficial].
*   **Precision**: Using `float` for depth reconstruction can lead to precision issues at large distances.
*   **Boundary**: Ray marching is clamped to `scatteringZFar`. Samples beyond this distance are ignored.

## Operating characteristics
*   **Time Complexity**: $O(N \cdot S)$, where $N$ is the number of pixels and $S$ is the number of scattering samples per pixel. For multiple lights, it is $O(N \cdot S \cdot L)$, where $L$ is the number of lights.
*   **Memory Complexity**: $O(1)$ per pixel for the compute shader, plus storage for textures and constant buffers.
*   **Performance**: High performance on GPU due to parallel pixel processing. However, high sample counts (`scatteringSamples`) and many lights can cause frame drops. The source notes excessive frame drops with 32 lights and shadow map visibility calculations [S1, unofficial].
*   **Strengths**: Realistic volumetric light shafts, supports multiple spot lights, post-processing friendly.
*   **Limitations**: Approximates single scattering only. Visibility calculation is expensive if shadow maps are used. Direction artifacts if light vectors are not transformed correctly.

## Background
This method is derived from post-processing techniques for simulating volumetric scattering in real-time graphics. It references Tomas Ohlsson's volumetric shader (`volumetric.frag`) and concepts from GPU Gems 3, Chapter 13 [S1, unofficial]. The specific implementation details, including the phase function and attenuation formulas, are based on a Stack Overflow discussion regarding DX12 implementation [S1, unofficial].
