# Volumetric Lighting with Phase Functions

Also called: Secondary Raymarching for Volumetric Lighting, Volumetric Lighting and Phase Functions

## Overview
This method illuminates participating media by marching a short secondary ray toward a distant light source when volume density is non-zero, integrating optical thickness to compute solar attenuation [S1, unofficial]. It applies the Henyey-Greenstein phase function to scatter light toward the camera, producing edge highlights and silver linings in single-scattering approximations [S1, unofficial].

## How it works
**Inputs:**
- 3D density field (e.g., Perlin-Worley noise texture) [S1, unofficial].
- Camera position and view direction.
- Light source direction (assumed distant, e.g., the sun) [G].
- Asymmetry parameter $g$ for the phase function [S1, unofficial].

**Outputs:**
- Illuminated color contribution for the current volume sample [G].

**Data Structures:**
- Density sample: A scalar value representing optical depth or particle density at a 3D coordinate. If the density is zero, no lighting calculation is performed [S1, unofficial].

**Steps:**
1. **Density Check:** Sample the primary 3D density field at the current view ray intersection point. If the density is zero, the contribution is zero [S1, unofficial].
2. **Secondary Raymarching:** Cast a short ray from the current volume sample toward the light source. This ray typically consists of 4 to 6 steps [S1, unofficial].
3. **Optical Thickness Integration:** Along the secondary ray, sample the density field and integrate the optical thickness $d$. The optical thickness is the integral of density along the light path [S1, unofficial].
4. **Solar Attenuation:** Calculate the transmittance $T$ of light reaching the current point from the source using Beer's Law:
   $$ T = \exp(-d) $$
   where $d$ is the integrated light-path density [S1, unofficial].
5. **Phase Function Evaluation:** Calculate the scattering probability based on the angle $\theta$ between the view ray (from camera to sample) and the sun ray (from sample to light). Use the Henyey-Greenstein phase function:
   $$ P(\theta) = \frac{1 - g^2}{4\pi (1 + g^2 - 2g\cos\theta)^{1.5}} $$
   where $g$ is the asymmetry parameter and $\theta$ is the scattering angle [S1, unofficial].
6. **Combine:** Multiply the solar attenuation $T$ by the phase function $P(\theta)$ and the incident light intensity to get the final illumination contribution [S1, unofficial].

**Parameters:**
- $g$ (asymmetry parameter): Controls the directionality of scattering.
  - Forward-scattering lobe: $g \approx 0.8$ [S1, unofficial].
  - Mild backward-scattering lobe: $g \approx -0.2$ [S1, unofficial].
  - Combining these lobes creates edge highlights and silver linings [S1, unofficial].

**Pseudocode:**
```python
import math

def compute_volumetric_lighting(sample_pos, view_dir, sun_dir, density_field, g_forward=0.8, g_backward=-0.2, num_steps=5, step_size=1.0, light_intensity=1.0):
    density = density_field.sample(sample_pos)
    if density <= 0:
        return 0.0

    optical_thickness = 0.0
    for i in range(num_steps):
        march_pos = sample_pos + sun_dir * (i * step_size)
        optical_thickness += density_field.sample(march_pos) * step_size

    transmittance = math.exp(-optical_thickness)

    cos_theta = math.dot(view_dir, sun_dir)
    p_forward = (1 - g_forward**2) / (4 * math.pi * (1 + g_forward**2 - 2 * g_forward * cos_theta)**1.5)
    p_backward = (1 - g_backward**2) / (4 * math.pi * (1 + g_backward**2 - 2 * g_backward * cos_theta)**1.5)

    # Source does not specify blending weights for the two lobes [G]
    phase = (p_forward + p_backward) / 2.0

    return transmittance * phase * light_intensity
```

### [Volumetric Scattering via Ray Marching (Single Light)](11370-volumetric-scattering-via-ray-marching-single-light.md)
Simulates volumetric light shafts for multiple spot lights by ray marching from the camera through the scene volume, integrating scattering contributions along the view ray. It operates as a post-processing compute shader pass that explicitly calculates light attenuation, spot cone factors, and phase function scattering at each sample point. Choose this when rendering multiple localized light sources in a post-process pipeline [G].

## Operating characteristics
- **Time Complexity:** $O(N \cdot M)$, where $N$ is the number of volume samples requiring lighting and $M$ is the number of secondary ray steps (typically 4-6) [G].
- **Memory Complexity:** Low, as it only requires temporary storage for the optical thickness integral [G].
- **Performance:** Computationally intensive due to the secondary raymarching. Optimizations such as quarter-resolution raymarching, bilateral upsampling, and temporal reprojection are recommended to maintain frame rates [S1, unofficial].
- **Strengths:** Produces realistic edge highlights and silver linings in single-scattering approximations [S1, unofficial].
- **Limitations:** Only accounts for single scattering. Multi-scattering effects are not captured [G]. Performance degrades with higher resolution or more secondary steps [G].

## Background
This technique is part of the broader field of real-time volumetric rendering, specifically for simulating clouds and atmospheric effects [S1, unofficial]. The use of Perlin-Worley noise for density generation and secondary raymarching for lighting is described in the context of OpenGL implementations [S1, unofficial]. The Henyey-Greenstein phase function is a standard model in radiative transfer for anisotropic scattering [G].
