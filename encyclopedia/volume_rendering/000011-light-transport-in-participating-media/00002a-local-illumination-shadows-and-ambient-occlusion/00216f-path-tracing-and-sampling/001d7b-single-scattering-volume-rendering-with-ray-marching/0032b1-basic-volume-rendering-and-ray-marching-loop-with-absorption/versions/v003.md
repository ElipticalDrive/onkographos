# Basic Volume Rendering and Ray Marching Loop with Absorption & Scattering

Also called: Single Scattering Ray Marching, Single-Scattering Volume Rendering with Fixed-Length Ray Marching, Volumetric Ray Marching

## Overview
This method traces rays through participating media by sampling free paths, evaluating transmittance, and updating ray direction and throughput in a loop until a surface is hit or termination conditions are met [S1, unofficial]. It builds on [Single Scattering Volume Rendering with Ray Marching](1532-single-scattering-volume-rendering-with-ray-marching.md) by detailing the explicit ray marching loop structure, distance sampling, and throughput accumulation for homogeneous media [S1, unofficial].

## How it works
**Data Structures:**
*   `Ray`: struct containing `origin` (vec3), `direction` (vec3), and `t_max` (float) [G].
*   `MediumInteraction`: struct containing `position` (vec3), `distance` (float), `transmittance` (float), and `scattering_event` (bool) [G].

**Parameters:**
*   $\sigma_a$: Absorption coefficient [S1, unofficial].
*   $\sigma_s$: Scattering coefficient [S1, unofficial].
*   $\sigma_t$: Extinction coefficient, composed of $\sigma_a$ and $\sigma_s$ [S1, unofficial].

**Steps:**
1.  **Ray Intersection:** Calculate the maximum extent for the ray before hitting a surface [S1, unofficial]. If the ray does not hit a surface, check if the world contains a scatter medium; if not, return [S1, unofficial].
2.  **Distance Sampling (Free-path Sampling):** For a homogeneous scattering medium, sample a distance $d$ traveled before a scattering event and evaluate transmittance [S1, unofficial].
3.  **Phase Function Sampling:** If a medium event occurs (the sampled distance is less than the distance to the closest surface), update the ray direction using the phase function [S1, unofficial]. The distance sampling already updates the ray origin [S1, unofficial].
4.  **Throughput Update:** Update the path throughput by multiplying it by the transmittance value [S1, unofficial].
5.  **Loop:** Update the ray for the next intersection and scattering event [S1, unofficial].

**Formulas:**
*   Transmittance of a distance $d$ is calculated as:
    $$ T(d) = \exp(-\sigma_t d) $$
    where $d$ is the distance [S1, unofficial].
*   The estimator for a homogeneous example is:
    $$ \text{estimator} = \sigma_s \frac{f(x)}{p(x)} = \sigma_s \frac{\exp(-\sigma_t d)}{\sigma_t \exp(-\sigma_t d)} = \frac{\sigma_s}{\sigma_s + \sigma_a} \approx 1 $$
    [S1, unofficial]

**Pseudocode:**
```python
def render_volume_ray(scene, ray, sigma_a, sigma_s, max_depth):
    sigma_t = sigma_a + sigma_s
    throughput = vec3(1.0, 1.0, 1.0)
    
    for _ in range(max_depth):
        # Step 1: Ray intersection
        t_hit = scene.query_intersection(ray)
        if t_hit == float('inf'):
            if not scene.has_medium():
                return vec3(0.0, 0.0, 0.0)
        
        # Step 2: Distance sampling (free-path sampling)
        u = random_float()
        d = -log(1.0 - u) / sigma_t if sigma_t > 0 else float('inf')
        tr = exp(-sigma_t * d)
        
        # Step 3: Phase function sampling & medium event check
        if d < t_hit:
            # Medium event occurs before surface hit
            ray.origin = ray.origin + ray.direction * d
            ray.direction = sample_phase_function(ray.direction)
            # Step 4: Throughput update
            throughput = throughput * tr
        else:
            # Ray hits surface before scattering event
            throughput = throughput * exp(-sigma_t * t_hit)
            break
            
        # Step 5: Loop continues by updating the ray for the next intersection and scattering event
    return throughput
```

**Edge Cases and Pitfalls:**
*   **Non-uniform transmittance:** For heterogeneous media, transmittance must be evaluated via ray marching (subdividing space and multiplying parts together) rather than analytically [S1, unofficial].
*   **Highly scattering media:** In highly scattering media (high $\sigma_s$, low $\sigma_a$), path tracing converges poorly because the estimator value is approximately 1, requiring a huge amount of scattering events and resulting in high variance [S1, unofficial].
