# Optimization Strategies for Volumetric Lighting

Also called: God Rays Optimization Techniques, Real-time Volumetric Lighting Optimizations

## Overview
This article details performance optimization strategies for real-time volumetric lighting, specifically addressing the high computational cost of ray marching in participating media. It solves the problem of excessive sample counts and memory bandwidth usage required to render soft, low-frequency light shafts (god rays) without sacrificing visual fidelity. Unlike [Single Scattering Volume Rendering with Ray Marching](1532-single-scattering-volume-rendering-with-ray-marching.md), which focuses on the physical accuracy of light transport, these strategies prioritize rendering efficiency through resolution reduction, temporal accumulation, and noise management.

## How it works
The optimization pipeline modifies the standard ray marching loop to reduce per-frame computational load while maintaining visual continuity across frames.

**Inputs and Outputs**
- **Input:** Full-resolution scene color buffer, depth buffer, light source position (screen-space or world-space), previous frame's volumetric lighting buffer, current frame index.
- **Output:** Optimized volumetric lighting buffer at reduced resolution, composited onto the final scene.

**Data Structures**
- **Reduced Resolution Buffer:** A texture with dimensions $W/2 \times H/2$ or $W/4 \times H/4$ relative to the screen.
- **Previous Frame Buffer:** A texture storing the volumetric contribution from the prior frame, used for temporal blending.
- **Blue Noise Texture:** A 2D texture containing pre-generated blue noise values for dithering.

**Numbered Steps**

1.  **Resolution Reduction:**
    Initialize the ray marching loop to compute volumetric lighting at half or quarter screen resolution. The effect is inherently soft and low-frequency, allowing this reduction with minimal quality loss while achieving a 4x or greater performance gain [S1, unofficial].

2.  **Blue Noise Dithering:**
    To mitigate banding artifacts caused by fewer samples, offset the ray march starting positions or sample intervals using blue noise. This converts structured aliasing into imperceptible high-frequency noise [S1, unofficial].
    $$
    \text{start\_offset} = \text{blue\_noise}(uv \times \text{scale}) \times \text{step\_size}
    $$
    Where $uv$ is the texture coordinate, $\text{scale}$ adjusts noise frequency, and $\text{step\_size}$ is the ray march step length [G].

3.  **Temporal Reprojection:**
    For each pixel, retrieve the volumetric contribution from the previous frame's buffer. Reproject this contribution to the current frame's coordinates using motion vectors or depth-based reprojection. Blend the current frame's computed result with the reprojected previous frame result. This effectively multiplies the sample count across frames while computing only a fraction per frame [S1, unofficial].
    $$
    C_{final} = \alpha C_{current} + (1 - \alpha) C_{previous\_reprojected}
    $$
    Where $\alpha$ is the blending factor, typically determined by temporal stability or convergence rate [G].

4.  **Early Termination:**
    During the ray marching loop, calculate the accumulated transmittance $T$. If $T$ drops below a threshold (e.g., 0.01), terminate the march early. Samples beyond this point contribute negligibly to the final color, especially in dense media [S1, unofficial].
    $$
    \text{if } T < 0.01: \text{break}
    $$

5.  **Bilateral Upsampling:**
    When compositing the reduced-resolution result onto the full-resolution scene, apply a depth-aware bilateral filter. This prevents halos and artifacts at depth discontinuities (object edges) by weighting samples based on both spatial proximity and depth similarity [S1, unofficial].

**Pseudocode**

```python
def optimize_volumetric_lighting(scene_color, depth_buffer, light_pos, prev_volumetric_buffer, frame_idx):
    # 1. Render at reduced resolution
    res_w = scene_color.width // 2
    res_h = scene_color.height // 2
    reduced_volumetric = empty_texture(res_w, res_h)
    
    for y in range(res_h):
        for x in range(res_w):
            uv = vec2(x / res_w, y / res_h)
            
            # 2. Blue noise dithering for starting position
            noise_val = blue_noise_texture.sample(uv * 10.0)
            start_offset = noise_val * ray_step_size
            
            # Initialize ray
            ray = create_ray_from_screen(uv, light_pos, start_offset)
            transmittance = 1.0
            accumulated_light = vec3(0.0)
            
            # 3. Ray marching with early termination
            for step in range(max_steps):
                pos = ray.origin + ray.direction * step * ray_step_size
                density = get_density_at(pos, depth_buffer)
                
                # Early termination check
                if transmittance < 0.01:
                    break
                
                # Compute scattering contribution
                scatter = compute_scattering(pos, density, light_pos)
                accumulated_light += scatter * transmittance * ray_step_size
                transmittance *= exp(-density * ray_step_size * extinction_coeff)
            
            reduced_volumetric.set_pixel(x, y, accumulated_light)
    
    # 4. Temporal reprojection
    # Reproject previous frame's volumetric buffer to current coordinates
    prev_reprojected = reproject_buffer(prev_volumetric_buffer, motion_vectors)
    
    # Blend current reduced result with reprojected previous result
    blended_volumetric = empty_texture(res_w, res_h)
    for y in range(res_h):
        for x in range(res_w):
            curr = reduced_volumetric.get_pixel(x, y)
            prev = prev_reprojected.get_pixel(x, y)
            # Alpha blending factor [G]
            alpha = 0.5 
            blended_volumetric.set_pixel(x, y, curr * alpha + prev * (1.0 - alpha))
    
    # 5. Bilateral upsampling to full resolution
    full_volumetric = empty_texture(scene_color.width, scene_color.height)
    for y in range(scene_color.height):
        for x in range(scene_color.width):
            uv = vec2(x / scene_color.width, y / scene_color.height)
            # Sample from blended reduced buffer with depth-aware weighting
            full_volumetric.set_pixel(x, y, bilateral_upsample(blended_volumetric, uv, depth_buffer))
            
    return full_volumetric
```

## Subtopics

## Operating characteristics
- **Time Complexity:** Reduced by a factor of 4x to 16x due to half/quarter resolution rendering. Temporal reprojection further reduces per-frame cost by allowing fewer spatial samples.
- **Memory Complexity:** Requires storage for the reduced-resolution buffer, the previous frame's buffer, and blue noise texture. Bilateral upsampling may require additional temporary buffers for depth-aware filtering.
- **Performance:** Significant performance gain on GPU-bound scenarios. The trade-off is potential temporal instability if reprojection fails (e.g., at camera motion boundaries) and slight blurring due to resolution reduction.
- **Strengths:** Effective for soft, low-frequency effects like god rays. Minimal quality loss for the performance gain.
- **Limitations:** Not suitable for high-frequency volumetric details. Requires stable depth and motion vectors for effective temporal reprojection.

## Background
These optimization strategies are standard practices in real-time graphics, particularly in high-end PC games and engines like Unreal Engine 5, which uses froxel grids with temporal reprojection for volumetric fog by default [S1, unofficial]. The techniques address the inherent expense of volumetric lighting as a post-processing effect.
