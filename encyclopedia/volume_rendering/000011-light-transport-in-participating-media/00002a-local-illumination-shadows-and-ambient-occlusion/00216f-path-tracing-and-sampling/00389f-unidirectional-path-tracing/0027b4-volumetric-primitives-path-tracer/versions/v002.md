# Volumetric-Primitives Path Tracer

Also called: Volumetric-Primitives Radiance Field (VPRF)

## Overview
Volumetric-Primitives Path Tracer (VPPT) is a forward rendering method for scattering and emissive media that models the scene as a collection of 3D kernel-based volumetric primitives and uses ray tracing to compute light transport, supporting multiple scattering via Next-Event Estimation [S1, unofficial]. Unlike 3D Gaussian Splatting (3DGS), which approximates density as a sum of delta functions leading to view-dependent ordering artifacts, VPPT maintains 3D volumetric density and integrates physically, preserving reciprocity and avoiding popping artifacts [S1, unofficial]. It builds on [Unidirectional Path Tracing](8283-unidirectional-path-tracing.md) by replacing voxel grids with analytically tractable kernel primitives, enabling closed-form transmittance and noise-free sampling [S1, unofficial].

## How it works
**Inputs:**
*   A set of $N$ volumetric primitives $P_i$.
*   Camera ray origin $\mathbf{x}_0$ and direction $\boldsymbol{\omega}$.
*   Scene bounding volume hierarchy (BVH) containing primitive bounding boxes/shells.

**Outputs:**
*   Radiance $L(\mathbf{x}_0, \boldsymbol{\omega})$ for the camera ray.

**Data Structures:**
*   **Primitive $P_i$:**
    *   `kernel_type`: Enum (Gaussian, Epanechnikov).
    *   `sigma`: Optical cross-section $\sigma_i$ ($m^{-1}$).
    *   `center`: Position $\mathbf{c}_i$ ($m$).
    *   `covariance`: Matrix defining shape/orientation (for Gaussian) or support radius (for Epanechnikov).
    *   `emission`: Emissive term $Q_i(\boldsymbol{\omega})$ ($W \cdot sr^{-1} \cdot m^{-3}$).
    *   `phase_function`: Phase function $f_{p,i}(\boldsymbol{\omega}' \to \boldsymbol{\omega})$.
*   **Segment $S_k$:**
    *   `t_start`: Entry parameter $b_{t_{k,0}}$.
    *   `t_end`: Exit parameter $b_{t_{k,1}}$.
    *   `primitives`: List of primitive indices overlapping this segment.

**Algorithm:**

1.  **Scene Representation:**
    Define the extinction coefficient $\mu_t(\mathbf{x})$ as the sum of products of cross-sections and kernel functions:
    $$ \mu_t(\mathbf{x}) = \sum_{i=1}^{N} \sigma_i K_i(\mathbf{x}) $$
    where $K_i(\mathbf{x})$ is the kernel function for primitive $i$ [S1, unofficial].

2.  **Ray-Primitive Intersection:**
    Use hardware-accelerated ray tracing (e.g., BVH on OptiX) to find all intersecting volumetric primitive bounding boxes/shells for the camera ray [S1, unofficial].

3.  **Segmentation:**
    Segment the ray into an ordered sequence of segments $S_k = [b_{t_{k,0}}, b_{t_{k,1}}]$ based on the entry and exit points of the primitives. Each segment may contain 0, 1, or multiple overlapping primitives [S1, unofficial].

4.  **Transmittance Calculation:**
    For each segment $S_k$, calculate transmittance $T(\mathbf{x}_{b_{t_{k,0}}}, \mathbf{x}_t)$ analytically by accumulating optical depths $\tau_i$ of all overlapping primitives:
    $$ T(\mathbf{x}_{b_{t_{k,0}}}, \mathbf{x}_t) = \exp \left( -\sum_{i \in S_k} \tau_i(\mathbf{x}_{b_{t_{k,0}}}, \mathbf{x}_{\min(t, b_{t_{k,1}})}) \right) $$
    The optical depth $\tau_i(\mathbf{x}_a, \mathbf{x}_b)$ for a primitive is defined as the integral of the kernel along the ray segment:
    $$ \tau_i(\mathbf{x}_a, \mathbf{x}_b) = \sigma_i \int_{\max(a, t_{i,0})}^{\min(b, t_{i,1})} K_i(\mathbf{x}_{t'}) dt' $$
    where $t_{i,0}$ and $t_{i,1}$ are the entry and exit parameters of primitive $i$ along the ray [S1, unofficial].

5.  **Free-Flight Sampling:**
    Sample free-flight distance $t$ along the ray proportional to the PDF $p(t) = \mu_t(\mathbf{x}_t)T(\mathbf{x}_0, \mathbf{x}_t)$.
    *   For a single primitive, use analytical inversion.
    *   For multiple overlapping primitives, use numerical root-finding (Newton-Raphson or bisection) or uniform sampling approximation [S1, unofficial].

6.  **Radiance Integration:**
    Integrate radiance $L(\mathbf{x}_0, \boldsymbol{\omega})$ front-to-back over segments:
    $$ L(\mathbf{x}_0, \boldsymbol{\omega}) = \sum_{k=1}^{M} T^{k-1}(\mathbf{x}_0, \mathbf{x}_t) L_k(\mathbf{x}_{b_{t_{k,0}}}, \boldsymbol{\omega}) $$
    where $L_k$ is the radiance from segment $S_k$, including emission and in-scattering contributions [S1, unofficial].

7.  **Next-Event Estimation (NEE):**
    Use NEE to sample scattering events within segments for multiple scattering and recursively trace paths [S1, unofficial].

**Parameters:**
*   **Kernel Types:** Gaussian Kernel and Epanechnikov Kernel. Gaussian uses error function (erf) for closed-form transmittance. Epanechnikov has finite support [S1, unofficial].
*   **Max Depth:** Typical value 5-10 for multiple scattering [G].

**Edge Cases and Pitfalls:**
*   **Infinite Support:** Gaussian kernels have infinite support, requiring clipping to avoid evaluating all primitives. Epanechnikov kernel has finite support, enabling more efficient acceleration structures [S1, unofficial].
*   **Precision:** Numerical root-finding for multiple overlapping primitives can suffer from precision issues. Use robust methods like bisection if Newton-Raphson fails [S1, unofficial].
*   **Degenerate Input:** Primitives with zero cross-section or zero emission should be skipped to avoid division by zero or unnecessary computation [G].

## Subtopics

### Volumetric Path Tracing
A general method for rendering participating media using path tracing. VPPT is a specific implementation using kernel primitives instead of voxel grids. [Volumetric Path Tracing](1863-volumetric-path-tracing.md)

### 3D Gaussian Splatting
A method for rendering 3D Gaussians as splats. VPPT differs by maintaining 3D volumetric density and integrating physically, avoiding view-dependent ordering artifacts. [3D Gaussian Splatting](52-3d-gaussian-splatting.md)

## Operating characteristics
*   **Time Complexity:** $O(N \log N)$ for BVH traversal, where $N$ is the number of primitives. Transmittance and optical depth calculations are $O(1)$ per primitive due to closed-form solutions.
*   **Memory Complexity:** $O(N)$, significantly lower than voxel grids which require $O(V)$ where $V$ is the number of voxels [S1, unofficial].
*   **Measured Performance:** Significant speedup compared to traditional grid-based methods due to analytical transmittance and efficient sampling. Epanechnikov kernels offer faster rendering and sharper details than Gaussian kernels [S1, unofficial].
*   **Scaling:** Scales well with the number of primitives. Level-of-Detail (LoD) can be applied by adjusting the number of primitives [S1, unofficial].
*   **Strengths:** Noise-free rendering, memory efficiency, physical accuracy, support for multiple scattering via NEE.
*   **Limitations:** Requires analytical integration for each kernel type. Infinite support of Gaussian kernels requires clipping.

## Background
VPPT was proposed by Meta in 2025 in the paper "Don’t Splat your Gaussians: Volumetric Ray-Traced Primitives for Modeling and Rendering Scattering and Emissive Media" [S1, unofficial]. It addresses the limitations of voxel grids (high memory, noise) and 3DGS (lack of physical light transport) by using 3D kernel-based volumetric primitives. The method leverages hardware-accelerated ray tracing and closed-form solutions for transmittance and free-flight sampling, enabling efficient forward and inverse rendering [S1, unofficial].
