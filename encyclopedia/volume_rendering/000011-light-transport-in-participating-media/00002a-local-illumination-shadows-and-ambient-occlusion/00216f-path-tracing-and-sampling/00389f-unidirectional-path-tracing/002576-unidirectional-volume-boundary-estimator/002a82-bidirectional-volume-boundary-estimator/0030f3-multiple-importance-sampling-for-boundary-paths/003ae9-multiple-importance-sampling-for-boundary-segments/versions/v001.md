# Multiple Importance Sampling for Boundary Segments

Also called: MIS with Primary-Sample-Space Guiding

## Overview
This method combines Multiple Importance Sampling (MIS) with primary-sample-space guiding to estimate the boundary segment contribution in differentiable volume rendering, specifically addressing the issue where light-source sampling yields invalid directions due to occlusion [S1]. It differs from a full 5D MIS sampler by applying guiding separately to two lower-dimensional mappings (light-source and direct direction), thereby avoiding the computational expense of guiding a higher-dimensional space while maintaining unbiased estimation [S1].

## How it works
**Inputs and Outputs:**
*   **Input:** The boundary segment function components $\hat{f}_B$, $\tilde{h}_S$, $\tilde{h}_D$; the geometry of the scene (to resolve occlusion); the error threshold $\epsilon$ for tree construction.
*   **Output:** An unbiased estimator for the boundary integral term.

**Data Structures:**
Two K-d trees are built during preprocessing, one for each sampling strategy. Each node in the tree stores:
*   An axis-aligned bounding box (`aabb`) defining the region in the primary sample space $[0, 1)^2$.
*   A first-order linear fit approximation of the target function within that box.
*   A global list of leaf nodes is maintained to allow discrete sampling proportional to the fit error or function value.

**Numbered Steps:**

1.  **Preprocessing (Guiding):**
    Construct two K-d trees to approximate the target functions $ \tilde{F}_{light} $ and $ \tilde{F}_{dir} $ in a piecewise linear fashion.
    *   For each function, recursively split the domain $[0, 1)^2$.
    *   At each node, compute a first-order fit of the function within the current `aabb`.
    *   If the fitting error exceeds $\epsilon$, split the box along the axis with the maximum error.
    *   If the error is below $\epsilon$, make the node a leaf and add it to a global list.
    *   From the leaf nodes, create a discrete distribution where the probability mass of each node is proportional to the integral of the fit (or error metric) within that node's `aabb` [S1].

2.  **Render Time (Sampling):**
    Draw two independent sets of primary samples from the precomputed distributions:
    *   Sample $(u_{1\_light}, u_{2\_light})$ from the distribution derived from $\tilde{F}_{light}$ with density $p_{light}$.
    *   Sample $(u_{1\_dir}, u_{2\_dir})$ from the distribution derived from $\tilde{F}_{dir}$ with density $p_{dir}$.

3.  **Evaluation:**
    Compute the two unbiased estimators and combine them. The total estimator is the sum of the contributions from both sampling strategies:
    $$
    \text{Estimator} = \left\langle \frac{\tilde{F}_{light}(u_{1\_light}, u_{2\_light})}{p_{light}(u_{1\_light}, u_{2\_light})} \right\rangle + \left\langle \frac{\tilde{F}_{dir}(u_{1\_dir}, u_{2\_dir})}{p_{dir}(u_{1\_dir}, u_{2\_dir})} \right\rangle
    $$
    [S1]

**Formulas:**
The target functions for the two sampling strategies are defined as [S1]:

$$
\tilde{F}_{light}(u_1, u_2) = \hat{f}_B(\mathbf{p}_{0S}, \mathbf{p}_{0D}) J^{light}_B(u_1, u_2) \tilde{h}_S(\mathbf{p}_{0S}, \mathbf{p}_{0D}) \tilde{h}_D(\mathbf{p}_{0S}, \mathbf{p}_{0D})
$$

$$
\tilde{F}_{dir}(u_1, u_2) = \hat{f}_B(\mathbf{p}_{0S}, \mathbf{p}_{0D}) J^{dir}_B(u_1, u_2) \tilde{h}_S(\mathbf{p}_{0S}, \mathbf{p}_{0D}) \tilde{h}_D(\mathbf{p}_{0S}, \mathbf{p}_{0D})
$$

Where:
*   $\hat{f}_B(\mathbf{p}_{0S}, \mathbf{p}_{0D})$ is the boundary scattering function.
*   $J^{light}_B$ is the Jacobian for light-source sampling of the boundary segment direction $\omega_B$.
*   $J^{dir}_B$ is the Jacobian for direct direction sampling of $\omega_B$.
*   $\tilde{h}_S$ and $\tilde{h}_D$ are the shadow and detector terms.
*   $\mathbf{p}_{0S}$ and $\mathbf{p}_{0D}$ are determined by $\omega_B$ via the specific sampling mappings (Eqs. 8 and 9 in [S1]). Note that $\mathbf{p}_{0S}$ and $\mathbf{p}_{0D}$ take different values for the same primary sample index if the sampling strategies differ, but within each estimator, they are consistent with the sampled $\omega_B$ [S1].

**Pseudocode:**

```python
def build_kd_tree(target_function, aabb, epsilon):
    """
    Recursively builds a K-d tree to approximate target_function over aabb.
    Returns a list of leaf nodes with their associated probability mass.
    """
    # Compute first-order linear fit of target_function within aabb
    fit, error = compute_first_order_fit(target_function, aabb)
    
    if error > epsilon:
        # Find axis with maximum error
        axes = ['x', 'y', 'z']
        errors = [compute_fit_error_along_axis(target_function, aabb, ax) for ax in axes]
        best_axis = argmax(errors)
        
        # Split aabb along best_axis
        aabb1, aabb2 = split_aabb(aabb, best_axis)
        
        # Recurse
        leaves1 = build_kd_tree(target_function, aabb1, epsilon)
        leaves2 = build_kd_tree(target_function, aabb2, epsilon)
        
        return leaves1 + leaves2
    else:
        # Leaf node: store fit and calculate mass
        mass = integrate_fit(fit, aabb)
        return [LeafNode(aabb=aabb, fit=fit, mass=mass)]

def sample_boundary_segment():
    """
    Draws samples and returns the MIS estimator value.
    """
    # 1. Preprocessing (Assume trees are already built and stored)
    # p_light_tree and p_dir_tree are the discrete distributions from leaves
    
    # 2. Draw primary samples
    u_light = sample_from_distribution(p_light_tree) # Returns (u1_light, u2_light)
    u_dir = sample_from_distribution(p_dir_tree)     # Returns (u1_dir, u2_dir)
    
    # 3. Evaluate Estimators
    # Note: p_light and p_dir here refer to the PDF values at the sampled points
    # in the primary sample space, derived from the tree structure.
    
    val_light = evaluate_F_light(u_light)
    pdf_light = get_pdf_at_point(u_light, p_light_tree)
    
    val_dir = evaluate_F_dir(u_dir)
    pdf_dir = get_pdf_at_point(u_dir, p_dir_tree)
    
    estimator = (val_light / pdf_light) + (val_dir / pdf_dir)
    
    return estimator

def evaluate_F_light(u1, u2):
    """
    Computes F_tilde_light(u1, u2).
    """
    # Map u1, u2 to direction omega_B using light-source sampling
    # This involves drawing a point x_0S on the light source
    x_0S = sample_light_source(u1) # Implementation detail of light sampling
    omega_B = normalize(x_0S - x_B)
    
    # Check for occlusion/invalidity
    if is_occluded(x_B, omega_B):
        # If invalid, this specific sample might be rejected or handled
        # The source implies the MIS handles the *validity* issue by
        # combining with dir sampling, but the Jacobian and geometry
        # must still be computed for the valid case.
        # [G]: If the direction is invalid, the contribution is 0.
        return 0.0
        
    # Compute paths p_0S and p_0D from omega_B
    p_0S, p_0D = compute_paths(omega_B)
    
    # Calculate Jacobian for light sampling
    J_light = compute_jacobian_light_sampling(u1, u2)
    
    # Calculate terms
    f_hat_B = evaluate_boundary_scattering(p_0S, p_0D)
    h_tilde_S = evaluate_shadow_term(p_0S, p_0D)
    h_tilde_D = evaluate_detector_term(p_0S, p_0D)
    
    return f_hat_B * J_light * h_tilde_S * h_tilde_D

def evaluate_F_dir(u1, u2):
    """
    Computes F_tilde_dir(u1, u2).
    """
    # Map u1, u2 to direction omega_B using direct direction sampling
    omega_B = sample_direction_direct(u1, u2)
    
    # Compute paths p_0S and p_0D from omega_B
    p_0S, p_0D = compute_paths(omega_B)
    
    # Calculate Jacobian for direct sampling
    J_dir = compute_jacobian_direct_sampling(u1, u2)
    
    # Calculate terms
    f_hat_B = evaluate_boundary_scattering(p_0S, p_0D)
    h_tilde_S = evaluate_shadow_term(p_0S, p_0D)
    h_tilde_D = evaluate_detector_term(p_0S, p_0D)
    
    return f_hat_B * J_dir * h_tilde_S * h_tilde_D
```

**Edge Cases and Pitfalls:**
*   **Occlusion:** When sampling $\omega_B$ by drawing a point $x_{0S}$ on a light source and setting $\omega_B = \text{normalize}(x_{0S} - x_B)$, the resulting direction may be invalid because the boundary segment would penetrate the object due to occlusion [S1]. The direct direction sampling strategy is used to mitigate this, as it can often produce valid directions where light-source sampling fails [S1].
*   **Parameter Dependence:** The domain of the boundary integral $\partial \hat{\Omega}$ generally depends on the scene parameter $\theta$, unlike the interior term [S1].

## Operating characteristics
*   **Complexity:** The preprocessing step involves building K-d trees. The cost depends on the complexity of the functions $\tilde{F}_{light}$ and $\tilde{F}_{dir}$ and the error threshold $\epsilon$. The render-time cost is dominated by the sampling and evaluation of the two estimators, which is constant per sample but requires two sets of primary samples.
*   **Comparison:** Unlike a full MIS sampler which guides a 5D primary sample space $(u_1, u_2, u_{2dir})$, this method applies primary-sample-space guiding separately to two 3D mappings (light and direction) to avoid the expense of guiding the higher-dimensional space [S1].
*   **Strengths:** It effectively handles occlusion issues in complex lighting by combining light-source and direct direction sampling [S1]. It is more efficient than full 5D guiding [S1].
*   **Limitations:** It requires preprocessing to build the guiding trees. The validity of the light-source sampled direction must be checked [S1].

## Background
This method is part of the framework for efficient estimation of boundary integrals in path-space differentiable rendering. It builds on the decomposition of the boundary integral into direct and indirect terms using next-event estimation [S1]. The specific technique of combining MIS with primary-sample-space guiding for boundary segments was introduced by Zhang et al. in 2020 [S1].
