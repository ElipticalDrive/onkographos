# Multiple Importance Sampling for Boundary Segments

Also called: MIS with Primary-Sample-Space Guiding

## Overview
This method combines Multiple Importance Sampling (MIS) with primary-sample-space guiding to estimate the boundary segment contribution in differentiable volume rendering, specifically addressing the issue where light-source sampling yields invalid directions due to occlusion [S1]. It differs from a full 5D MIS sampler by applying guiding separately to two lower-dimensional mappings (light-source and direct direction), thereby avoiding the computational expense of guiding a higher-dimensional space while maintaining unbiased estimation [S1].

## How it works
**Inputs and Outputs:**
*   **Input:** The boundary segment function components $\hat{f}_B$, $\tilde{h}_S$, $\tilde{h}_D$; the error threshold $\epsilon$ for tree construction [S1].
*   **Output:** An unbiased estimator for the boundary integral term [S1].

**Data Structures:**
Two K-d trees are built during preprocessing, one for each sampling strategy [S1]. Each node in the tree stores:
*   An axis-aligned bounding box (`aabb`) defining the region in the primary sample space $[0, 1)^2$ [S1].
*   A first-order linear fit approximation of the target function within that box [S1].
*   A global list of leaf nodes is maintained to allow discrete sampling [S1].

**Numbered Steps:**

1.  **Preprocessing (Guiding):**
    Construct two K-d trees to approximate the target functions $\tilde{F}_{light}$ and $\tilde{F}_{dir}$ in a piecewise linear fashion [S1].
    *   For each function, recursively split the domain $[0, 1)^2$ [S1].
    *   At each node, compute a first-order fit of the function within the current `aabb` [S1].
    *   If the fitting error exceeds $\epsilon$, split the box along the axis with the maximum error [S1].
    *   If the error is below $\epsilon$, make the node a leaf and add it to a global list [S1].
    *   During preprocessing, apply primary-sample-space guiding to both $\tilde{F}_{light}$ and $\tilde{F}_{dir}$ to obtain two probability densities $p_{light}$ and $p_{dir}$ approximately proportional to them [S1].

2.  **Render Time (Sampling):**
    Draw two independent sets of primary samples from the precomputed distributions [S1].
    *   Sample $(u_{1\_light}, u_{2\_light})$ with density $p_{light}$ [S1].
    *   Sample $(u_{1\_dir}, u_{2\_dir})$ with density $p_{dir}$ [S1].

3.  **Evaluation:**
    Compute the two unbiased estimators and combine them [S1]. The total estimator is the sum of the contributions from both sampling strategies:
    $$
    \text{Estimator} = \left\langle \frac{\tilde{F}_{light}(u_{1\_light}, u_{2\_light})}{p_{light}(u_{1\_light}, u_{2\_light})} \right\rangle + \left\langle \frac{\tilde{F}_{dir}(u_{1\_dir}, u_{2\_dir})}{p_{dir}(u_{1\_dir}, u_{2\_dir})} \right\rangle
    $$
    [S1]

**Formulas:**
The target functions for the two sampling strategies are defined as [S1]:

$$
\tilde{F}_{light}(u_1, u_2) = \hat{f}_B(\mathbf{p}_{0S}, \mathbf{p}_{0D}) J^{light}_B(u_1, u_2) \tilde{h}_S(\mathbf{p}_{0S}, \mathbf{p}_{0D}) \tilde{h}_D(\mathbf{p}_{0S}, \mathbf{p}_{0D})
$$

$$
\tilde{F}_{dir}(u_1, u_2) = \hat{f}_B(\mathbf{p}_{0S}, \mathbf{p}_{0D}) J^{dir}_B(u_1, u_2) \tilde{h}_S(\mathbf{p}_{0S}, \mathbf{p}_{0D}) \tilde{h}_D(\mathbf{p}_{0S}, \mathbf{p}_{0D})
$$

Where:
*   $\hat{f}_B(\mathbf{p}_{0S}, \mathbf{p}_{0D})$ is the boundary scattering function [S1].
*   $J^{light}_B$ is the Jacobian for light-source sampling of the boundary segment direction $\omega_B$ [S1].
*   $J^{dir}_B$ is the Jacobian for direct direction sampling of $\omega_B$ [S1].
*   $\tilde{h}_S$ and $\tilde{h}_D$ are the shadow and detector terms [S1].
*   $\mathbf{p}_{0S}$ and $\mathbf{p}_{0D}$ are determined by $\omega_B$ via the specific sampling mappings [S1]. Note that $\mathbf{p}_{0S}$ and $\mathbf{p}_{0D}$ take different values in the two equations for the same primary sample, but within each estimator, they are consistent with the sampled $\omega_B$ [S1].

**Pseudocode:**

```python
class LeafNode:
    def __init__(self, aabb, fit, mass):
        self.aabb = aabb
        self.fit = fit
        self.mass = mass

def compute_first_order_fit(func, aabb):
    # Standard linear regression over the domain aabb
    return linear_regression(func, aabb), compute_residual(func, aabb)

def compute_fit_error_along_axis(func, aabb, axis):
    # Compute fitting error if split along axis
    return compute_residual(func, aabb)

def split_aabb(aabb, axis):
    mid = (aabb[axis*2] + aabb[axis*2+1]) / 2
    aabb1 = aabb.copy()
    aabb1[axis*2+1] = mid
    aabb2 = aabb.copy()
    aabb2[axis*2] = mid
    return aabb1, aabb2

def integrate_fit(fit, aabb):
    return sum(fit) * volume(aabb)

def build_kd_tree(target_function, aabb, epsilon):
    fit, error = compute_first_order_fit(target_function, aabb)
    if error > epsilon:
        axes = ['x', 'y', 'z']
        errors = [compute_fit_error_along_axis(target_function, aabb, ax) for ax in axes]
        best_axis = axes[max(range(len(axes)), key=lambda i: errors[i])]
        aabb1, aabb2 = split_aabb(aabb, best_axis)
        return build_kd_tree(target_function, aabb1, epsilon) + build_kd_tree(target_function, aabb2, epsilon)
    else:
        mass = integrate_fit(fit, aabb)
        return [LeafNode(aabb=aabb, fit=fit, mass=mass)]

def sample_from_distribution(leaves):
    total_mass = sum(leaf.mass for leaf in leaves)
    r = random.uniform(0, total_mass)
    cumulative = 0.0
    for leaf in leaves:
        cumulative += leaf.mass
        if r <= cumulative:
            return uniform_sample_in_aabb(leaf.aabb)
    return uniform_sample_in_aabb(leaves[-1].aabb)

def evaluate_F_light(u1, u2):
    x_0S = sample_light_source(u1)
    omega_B = normalize(x_0S - x_B)
    if is_occluded(x_B, omega_B):
        return 0.0
    p_0S, p_0D = compute_paths(omega_B)
    J_light = compute_jacobian_light_sampling(u1, u2)
    return f_hat_B(p_0S, p_0D) * J_light * h_tilde_S(p_0S, p_0D) * h_tilde_D(p_0S, p_0D)

def evaluate_F_dir(u1, u2):
    omega_B = sample_direction_direct(u1, u2)
    p_0S, p_0D = compute_paths(omega_B)
    J_dir = compute_jacobian_direct_sampling(u1, u2)
    return f_hat_B(p_0S, p_0D) * J_dir * h_tilde_S(p_0S, p_0D) * h_tilde_D(p_0S, p_0D)

def main_estimator():
    p_light_tree = build_kd_tree(F_tilde_light, [0, 1, 0, 1], epsilon)
    p_dir_tree = build_kd_tree(F_tilde_dir, [0, 1, 0, 1], epsilon)
    u_light = sample_from_distribution(p_light_tree)
    u_dir = sample_from_distribution(p_dir_tree)
    val_light = evaluate_F_light(u_light[0], u_light[1])
    pdf_light = get_pdf_at_point(u_light, p_light_tree)
    val_dir = evaluate_F_dir(u_dir[0], u_dir[1])
    pdf_dir = get_pdf_at_point(u_dir, p_dir_tree)
    return (val_light / pdf_light) + (val_dir / pdf_dir)
```

**Edge Cases and Pitfalls:**
*   **Occlusion:** When sampling $\omega_B$ by drawing a point $x_{0S}$ on a light source and setting $\omega_B = \text{normalize}(x_{0S} - x_B)$, the resulting direction may be invalid because the boundary segment would penetrate the object due to occlusion [S1]. The direct direction sampling strategy is used to mitigate this, as it can often produce valid directions where light-source sampling fails [S1].
*   **Parameter Dependence:** The domain of the boundary integral $\partial \hat{\Omega}$ generally depends on the scene parameter $\theta$, unlike the interior term [S1].

## Operating characteristics
*   **Complexity:** The preprocessing step involves building K-d trees to approximate the target functions [S1]. The render-time cost is dominated by the sampling and evaluation of the two estimators, which requires two sets of primary samples [S1].
*   **Comparison:** Unlike a full MIS sampler which guides a 5D primary sample space $(u_1, u_2, u_{2dir})$, this method applies primary-sample-space guiding separately to two mappings from a 2D primary sample space to avoid the expense of guiding the higher-dimensional space [S1].
*   **Strengths:** It effectively handles occlusion issues in complex lighting by combining light-source and direct direction sampling [S1]. It is more efficient than full 5D guiding [S1].
*   **Limitations:** It requires preprocessing to build the guiding trees. The validity of the light-source sampled direction must be checked [S1].

## Background
This method is part of the framework for efficient estimation of boundary integrals in path-space differentiable rendering [S1]. The specific technique of combining MIS with primary-sample-space guiding for boundary segments was introduced by Zhang et al. in 2020 [S1].
