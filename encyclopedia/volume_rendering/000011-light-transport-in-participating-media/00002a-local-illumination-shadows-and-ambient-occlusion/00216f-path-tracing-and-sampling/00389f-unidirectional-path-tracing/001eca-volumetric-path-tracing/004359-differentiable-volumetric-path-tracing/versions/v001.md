# Differentiable Volumetric Path Tracing

Also called: Differential Theory of Radiative Transfer, Differentiable Volumetric Path Tracing for Albedo Gradient, unbiased Monte Carlo method for scene derivatives

## Overview
Differentiable Volumetric Path Tracing is an unbiased Monte Carlo method used to numerically estimate derivatives of the radiative transfer equation (RTE) with respect to arbitrary scene parameterizations, specifically albedo [S1, unofficial][S2]. It solves the problem of computing gradients for inverse rendering in participating media, enabling the optimization of scene parameters such as material properties [S1, unofficial][S2]. Unlike standard volumetric path tracing which only estimates radiance, this method simultaneously computes radiance and its gradient with respect to a chosen parameter (e.g., albedo $\alpha$) along sampled paths [S2]. It sets itself apart from siblings like [Multiple Scattering Volume Path Tracing with Phase Function Sampling](1043-multiple-scattering-volume-path-tracing-with-phase-function-.md) by explicitly differentiating the path contribution weights to provide gradient information for regularization or optimization, rather than just reducing noise in the radiance estimate [S2].

## How it works
**Inputs and Outputs:**
*   **Inputs:** Scene geometry, participating media properties (extinction coefficient $\sigma_t$, albedo $\alpha$, phase function $p$), light source definitions, camera parameters, and the specific scene parameter to differentiate with respect to (typically albedo $\alpha$) [S1, unofficial][S2].
*   **Outputs:** Estimated radiance $L(x, \omega)$ and its gradient $\frac{\partial L}{\partial \alpha}$ for each pixel [S2].

**Data Structures:**
*   **Path State:** A sequence of bounce points $x_0, x_1, \dots, x_K$, where $x_0$ is the camera position and $x_K$ is the endpoint (light source or termination) [S2].
*   **Path Contribution:** A scalar value $f(\tilde{p})$ representing the unnormalized contribution of a path $\tilde{p}$ [S2].
*   **Accumulators:** Per-pixel accumulators for radiance sum and gradient sum, initialized to zero [S2].

**Formulas:**
The radiance $L(x, \omega)$ is expressed as a path integral over a path space $S_p$ containing all paths starting from $x$ with direction $\omega$ and ending at the light source [S2]:
$$ L(x, \omega) = \int_{S_p} f(\tilde{p}) d\tilde{p} $$
Using Monte Carlo sampling with $M$ samples, the estimator is:
$$ L(x, \omega) = \frac{1}{M} \sum_{i=1}^{M} \frac{f(\tilde{p}_i)}{\text{pdf}(\tilde{p}_i)} $$
where $\text{pdf}(\tilde{p}_i)$ is the probability density function of sampling path $\tilde{p}_i$ [S2].

The contribution $f(\tilde{p}_i)$ for a path with $K$ bounces is defined as:
$$ f(\tilde{p}_i) = \prod_{k=1}^{K} w_k g(\omega_{k-1}, \omega_k) $$
where $w_k$ is the weight at bounce $k$ and $g(\omega_{k-1}, \omega_k)$ is the scattering term [S2].

The weight $w_k$ depends on whether the bounce point $x_k$ is in a medium or on a surface [S2]:
$$ w_k = \begin{cases} \alpha \sigma_t \text{Tr}(x_{k-1} \leftrightarrow x_k) & \text{if } x_k \in \text{medium} \\ \text{Tr}(x_{k-1} \leftrightarrow x_k) & \text{if } x_k \in \text{surface} \end{cases} $$
where $\text{Tr}(x_{k-1} \leftrightarrow x_k)$ is the transmittance between $x_{k-1}$ and $x_k$, $\sigma_t$ is the extinction coefficient, and $\alpha$ is the albedo [S2].

The scattering term $g(\omega_{k-1}, \omega_k)$ is defined as [S2]:
$$ g(\omega_{k-1}, \omega_k) = \begin{cases} p(\omega_{k-1}, \omega_k) & \text{if } x_k \in \text{medium} \\ \frac{\rho(\omega_{k-1}, \omega_k) \cos(\theta_k)}{4\pi} & \text{if } x_k \in \text{surface} \end{cases} $$
where $p$ is the phase function, $\rho$ is the bidirectional scattering distribution function (BSDF), and $\theta_k$ is the angle between the surface normal at $x_k$ and the direction $\omega_k$ [S2].

**Parameters:**
*   $M$: Number of samples per pixel. Typical values depend on noise tolerance; low sample counts are used for iterative optimization [S1, unofficial][S2].
*   $K$: Maximum number of bounces. Not given in the sources.
*   $\alpha$: Albedo parameter. Not given in the sources.

**Numbered Steps:**
1.  Initialize per-pixel accumulators for radiance $L_{sum}$ and gradient $G_{sum}$ to zero [S2].
2.  For each sample $i$ from $1$ to $M$:
    a. Sample a path $\tilde{p}_i$ from the camera through the scene to a light source, recording bounce points $x_0, \dots, x_K$ and directions $\omega_0, \dots, \omega_K$ [S2].
    b. Compute the path contribution $f(\tilde{p}_i)$ using the product of weights $w_k$ and scattering terms $g(\omega_{k-1}, \omega_k)$ as defined above [S2].
    c. Compute the gradient of the contribution with respect to albedo $\alpha$, $\frac{\partial f(\tilde{p}_i)}{\partial \alpha}$. This is done using automatic differentiation (autodiff) tools (e.g., Eigen C++ library) to compute both radiance and gradient simultaneously along the sampled path [S2].
    d. Compute the importance sampling weight $1/\text{pdf}(\tilde{p}_i)$ [S2].
    e. Update the pixel accumulators:
       $$ L_{sum} \leftarrow L_{sum} + \frac{f(\tilde{p}_i)}{\text{pdf}(\tilde{p}_i)} $$
       $$ G_{sum} \leftarrow G_{sum} + \frac{\frac{\partial f(\tilde{p}_i)}{\partial \alpha}}{\text{pdf}(\tilde{p}_i)} $$
3.  After all $M$ samples, compute the final radiance and gradient for the pixel:
    $$ L = \frac{L_{sum}}{M} $$
    $$ G = \frac{G_{sum}}{M} $$
4.  Return $L$ and $G$ [S2].

**Pseudocode:**
```python
def differentiable_volumetric_path_tracing(camera, scene, num_samples):
    # Initialize accumulators for the pixel
    radiance_sum = 0.0
    gradient_sum = 0.0
    
    for i in range(num_samples):
        # Sample a path from camera to light
        # Returns sequence of points x[0..K] and directions omega[0..K]
        path = sample_path(camera, scene)
        K = len(path.points) - 1
        
        # Compute path contribution and its gradient w.r.t. albedo alpha
        # Using automatic differentiation to compute both simultaneously
        # f is the unnormalized contribution
        # df_dalpha is the derivative of f w.r.t. alpha
        f, df_dalpha = compute_path_contribution_and_gradient(path, scene)
        
        # Compute PDF of the sampled path
        pdf = compute_path_pdf(path, scene)
        
        # Avoid division by zero
        if pdf == 0:
            continue
            
        # Weighted contribution
        weight = 1.0 / pdf
        
        # Accumulate
        radiance_sum += f * weight
        gradient_sum += df_dalpha * weight
        
    # Average over samples
    radiance = radiance_sum / num_samples
    gradient = gradient_sum / num_samples
    
    return radiance, gradient

def compute_path_contribution_and_gradient(path, scene):
    # Initialize contribution and its gradient
    # Using autodiff, we track operations on alpha
    alpha = scene.albedo
    f = 1.0
    df_dalpha = 0.0
    
    for k in range(1, len(path.points)):
        x_prev = path.points[k-1]
        x_curr = path.points[k]
        omega_prev = path.directions[k-1]
        omega_curr = path.directions[k]
        
        # Compute transmittance
        tr = compute_transmittance(x_prev, x_curr, scene)
        
        # Determine weight w_k based on whether x_curr is in medium or surface
        if is_in_medium(x_curr, scene):
            # w_k = alpha * sigma_t * Tr
            sigma_t = scene.extinction_coefficient(x_curr)
            w_k = alpha * sigma_t * tr
            # dw_k/dalpha = sigma_t * Tr
            dw_k_dalpha = sigma_t * tr
        else:
            # w_k = Tr
            w_k = tr
            dw_k_dalpha = 0.0
            
        # Compute scattering term g
        if is_in_medium(x_curr, scene):
            # g = p(omega_prev, omega_curr)
            g = scene.phase_function(omega_prev, omega_curr)
            dg_dalpha = 0.0
        else:
            # g = rho(omega_prev, omega_curr) * cos(theta) / 4pi
            bsdf = scene.bsdf(x_curr, omega_prev, omega_curr)
            normal = scene.surface_normal(x_curr)
            cos_theta = max(0.0, dot(normal, omega_curr))
            g = bsdf * cos_theta / (4.0 * PI)
            dg_dalpha = 0.0
            
        # Update contribution f = f * w_k * g
        # df_dalpha = df_dalpha * w_k * g + f * dw_k_dalpha * g
        # Note: g is independent of alpha, so dg_dalpha is 0
        
        f = f * w_k * g
        df_dalpha = df_dalpha * w_k * g + f * dw_k_dalpha * g # Wait, f is updated after?
        # Correct update:
        # Let f_old = f, df_old = df_dalpha
        # f_new = f_old * w_k * g
        # df_new = df_old * w_k * g + f_old * dw_k_dalpha * g
        
        # Re-calculate to avoid using updated f in derivative term
        f_new = f * w_k * g
        df_dalpha_new = df_dalpha * w_k * g + f * dw_k_dalpha * g
        
        f = f_new
        df_dalpha = df_dalpha_new
        
    return f, df_dalpha
```
*Note: The pseudocode above uses a simplified autodiff logic. In practice, automatic differentiation libraries handle the chain rule automatically if the operations are recorded in a computational graph [S2]. The explicit derivative calculation shown is for illustration of the mathematical dependency.*

**Edge Cases and Pitfalls:**
*   **Ideal Specular Surfaces:** Discontinuities of radiance $L(x, \omega)$ in $\omega$ must include mirror images of geometric edges, which can be nontrivial to identify [S1, unofficial].
*   **Non-Exponential Transmittance:** The derivations assume exponential transmittance. Supporting media with non-exponential transmittance requires adjustment of the derivations [S1, unofficial].
*   **Noise:** Gradient images suffer from large amounts of noise, especially in media with high albedo where light paths are long and attenuation is slow [S2]. Temporal denoising or other regularization techniques may be required [S2].

## Subtopics

### Differential Theory of Radiative Transfer
The theoretical framework underlying the method, showing how the RTE can be differentiated with respect to arbitrary scene parameterizations [S1, unofficial]. It handles volumetric absorption, single and multiple scattering, anisotropic phase functions, and heterogeneity [S1, unofficial].

### Temporal Gradient Denoising
A post-processing technique used to reduce noise in gradient images by reprojection and blending with neighboring frames using motion vectors [S2].

## Operating characteristics
*   **Time Complexity:** Proportional to the number of samples $M$ and the path length $K$. Similar to standard volumetric path tracing, but with additional overhead for computing gradients via automatic differentiation [S2].
*   **Memory Complexity:** Proportional to the number of pixels and the path length $K$ for storing path states during computation [S2].
*   **Measured Performance:** The method produces better results than standard volumetric path tracing in terms of gradient accuracy for the same computational time, particularly in media with varying extinction coefficients [S2]. However, gradient images are noisy, requiring denoising or low sample counts for iterative optimization [S1, unofficial][S2].
*   **Strengths:** Unbiased estimation of radiance derivatives; handles complex volumetric phenomena; enables inverse rendering in participating media [S1, unofficial][S2].
*   **Limitations:** High variance in gradient estimates, especially for high albedo media; assumptions of exponential transmittance; difficulty with ideal specular surfaces [S1, unofficial][S2].
*   **When to use:** When gradients of radiance with respect to scene parameters (like albedo) are needed for inverse rendering or optimization in scenes with participating media [S1, unofficial][S2].
*   **When not to use:** When only radiance estimation is needed (use standard VPT); when non-exponential transmittance is present without modification; when real-time performance is critical and noise cannot be tolerated [S1, unofficial][S2].

## Background
The method is based on the "Differential Theory of Radiative Transfer," introduced in a paper by [S1, unofficial]. It was developed to enable inverse rendering in participating media by providing unbiased Monte Carlo estimators for scene derivatives. The technique has been applied to imaging-inspired and design-inspired inverse rendering examples, optimizing scene parameters such as material properties [S1, unofficial]. Another related work by [S2] focuses on efficient participating media rendering by using differentiable volumetric path tracing to compute gradients with respect to albedo for temporal denoising in video rendering.
