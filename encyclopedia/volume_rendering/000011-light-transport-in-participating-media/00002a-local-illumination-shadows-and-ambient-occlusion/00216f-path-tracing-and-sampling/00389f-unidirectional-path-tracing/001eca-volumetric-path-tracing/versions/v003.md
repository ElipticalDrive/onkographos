# Volumetric Path Tracing

Also called: Simple Volumetric Path Tracing, SimpleVolPathIntegrator, VolpathSimpleIntegrator, volpathsimple-basic, volpathsimple-drt

## Overview
Volumetric Path Tracing is a Monte Carlo method for simulating light transport in participating media by extending classical path tracing to allow rays to enter volumetric regions, sample scattering events, and continue random walks [S1, unofficial][S4, unofficial]. It solves the problem of computing radiance in scenes with fog, smoke, or clouds by modeling absorption, emission, and scattering within the medium [S1, unofficial]. It differs from [Multiple Scattering Volume Path Tracing with Phase Function Sampling](1043-multiple-scattering-volume-path-tracing-with-phase-function-.md) by lacking explicit light sampling (Next-Event Estimation) and surface scattering support, relying instead on delta tracking for distance selection and phase function sampling for direction [S4, unofficial]. It is used for computing ground-truth results when debugging more sophisticated algorithms [S4, unofficial].

## How it works
**Inputs and Outputs**
*   **Input:** A camera ray $\mathbf{r}$ (origin $\mathbf{o}$, direction $\mathbf{d}$), a scene containing participating media (defined by extinction $\sigma_t$, scattering $\sigma_s$, absorption $\sigma_a$, and phase function $p$), and optional infinite light sources [S1, unofficial][S3, unofficial][S5].
*   **Output:** The estimated radiance $L$ along the ray [S1, unofficial][S5].

**Data Structures**
*   **Medium Properties:** Contains coefficients $\sigma_a, \sigma_s, \sigma_t$ (vectors for spectral or RGB), emission $\sigma_e$, and a phase function object [S1, unofficial][S5].
*   **Majorant:** A constant vector $\sigma_{maj}$ such that $\sigma_{maj} \ge \sigma_t(\mathbf{x})$ for all $\mathbf{x}$ in the medium [S4, unofficial].
*   **Path State:**
    *   $L$: Accumulated radiance (Spectrum/Vector) [S5].
    *   $\beta$: Path throughput (Scalar or Vector) [S5].
    *   $\mathbf{r}$: Current ray (Origin $\mathbf{o}$, Direction $\mathbf{d}$) [S5].
    *   $depth$: Current path depth [S5].

**Numbered Steps**
1.  **Initialization:** Initialize $L = 0$, $\beta = 1.0$, $depth = 0$ [S5]. Terminate secondary wavelengths if spectral rendering is supported [S4, unofficial].
2.  **Loop:** While true:
    3.  **Surface Intersection:** Compute the closest surface intersection $\mathbf{si}$ along $\mathbf{r}$ with distance $t_{max}$ [S5]. If no surface exists, $t_{max} = \infty$ [S5].
    4.  **Medium Sampling (Delta Tracking):** If the ray is in a medium:
        *   Initialize a local RNG seeded by two hashed samples from the main sampler [S5].
        *   Sample the distance to the next interaction using delta tracking with the majorant $\sigma_{maj}$ [S5]. This involves sampling a uniform random number $u$ and computing the geometric distance [S1, unofficial].
        *   The delta tracking lambda function determines the event type:
            *   Compute probabilities: $p_{absorb} = \sigma_a / \sigma_{maj}$, $p_{scatter} = \sigma_s / \sigma_{maj}$, $p_{null} = \max(0, 1 - p_{absorb} - p_{scatter})$ [S5].
            *   Sample event mode using $u_{mode}$:
                *   **Absorb (mode 0):** Add emission to $L$: $L += \beta \cdot \sigma_e$. Terminate path [S5].
                *   **Scatter (mode 1):**
                    *   If $depth \ge maxDepth$, terminate [S5].
                    *   Increment $depth$.
                    *   Sample scattering direction $\mathbf{d}'$ from the phase function $p(\mathbf{d}, \mathbf{d}')$ using two uniform samples [S5].
                    *   Update throughput: $\beta = \beta \cdot \frac{p_{scatter}}{pdf}$ [S5].
                    *   Update ray: $\mathbf{o} = \mathbf{o} + \mathbf{d} \cdot t$, $\mathbf{d} = \mathbf{d}'$. Set $scattered = true$.
                *   **Null (mode 2):** Continue delta tracking loop with a new $u_{mode}$ [S5].
    5.  **Termination Check:** If path terminated, return $L$ [S5].
    6.  **Scatter Continue:** If $scattered$, continue loop to process new ray [S5].
    7.  **Surface Handling:** If $\mathbf{si}$ exists:
        *   Get BSDF. If BSDF supports sampling (non-delta), the integrator errors out as it does not support surface scattering [S3, unofficial][S5].
        *   If BSDF is null or non-sampling, skip intersection and continue ray [S5].
    8.  **Emission:** If no surface intersection (ray escapes to infinity):
        *   Add emission from all infinite lights: $L += \beta \cdot \sum \mathbf{L}_{light}$ [S5].
        *   Return $L$ [S5].

**Formulas**
*   **Transmittance:** $T(\mathbf{x}_1, \mathbf{x}_2) = \exp\left(-\int_{\mathbf{x}_1}^{\mathbf{x}_2} \sigma_t(\mathbf{x}) d\mathbf{x}\right)$ [S1, unofficial].
*   **Delta Tracking Distance:** Sample $u \sim U[0,1]$. Compute distance $t = -\ln(1 - u) / \sigma_{maj}$ [S1, unofficial][S5].
*   **Throughput Update:** $\beta_{new} = \beta_{old} \cdot \frac{p_{scatter}}{pdf(\omega_o)}$ [S5].

**Parameters**
*   `maxDepth`: Maximum path length (e.g., 10, 64) [S1, unofficial][S3, unofficial][S5].
*   `sigma_t`: Total extinction coefficient [S1, unofficial].
*   `sigma_s`: Scattering coefficient [S1, unofficial].
*   `sigma_a`: Absorption coefficient [S1, unofficial].
*   `phase`: Phase function (e.g., Henyey-Greenstein) [S2, unofficial][S4, unofficial].

**Pseudocode**
```python
import math
import random

class Spectrum:
    def __init__(self, r=0.0, g=0.0, b=0.0):
        self.r, self.g, self.b = r, g, b
    def __add__(self, other): return Spectrum(self.r + other.r, self.g + other.g, self.b + other.b)
    def __mul__(self, s): return Spectrum(self.r * s, self.g * s, self.b * s)
    def __rmul__(self, s): return self.__mul__(s)

class PhaseSample:
    def __init__(self, wi, pdf):
        self.wi = wi
        self.pdf = pdf

def simple_vol_path_trace(ray_o, ray_d, sigma_a, sigma_s, sigma_maj, sigma_e, phase_fn, max_depth, t_max_surface):
    L = Spectrum()
    beta = 1.0
    depth = 0
    scattered = False
    terminated = False

    while True:
        # Delta tracking loop
        while True:
            u = random.random()
            # Sample distance from majorant exponential distribution
            t = -math.log(1.0 - u) / sigma_maj

            if t > t_max_surface:
                break # No interaction before surface

            # Compute probabilities
            p_absorb = sigma_a / sigma_maj
            p_scatter = sigma_s / sigma_maj
            p_null = max(0.0, 1.0 - p_absorb - p_scatter)

            u_mode = random.random()
            if u_mode < p_absorb:
                # Absorb
                L = L + beta * Spectrum(*sigma_e)
                terminated = True
                break
            elif u_mode < p_absorb + p_scatter:
                # Scatter
                if depth >= max_depth:
                    terminated = True
                    break
                depth += 1
                # Sample phase function
                u_phase = (random.random(), random.random())
                ps = phase_fn.sample(-ray_d, u_phase)
                if ps is None:
                    terminated = True
                    break
                # Update throughput
                beta = beta * (p_scatter / ps.pdf)
                # Update ray
                ray_o = ray_o + ray_d * t
                ray_d = ps.wi
                scattered = True
                break
            else:
                # Null scattering: continue loop with new u
                continue

        if terminated:
            return L

        if scattered:
            # Ray continues, update t_max for next iteration
            t_max_surface = t_max_surface - t
            continue

        # No surface intersection before interaction
        # Add emission from infinite lights if ray escapes
        # L = L + beta * scene.infinite_light.eval(ray_o, ray_d)
        break

    return L
```

## Operating characteristics
*   **Time Complexity:** $O(N \cdot D \cdot S)$, where $N$ is samples per pixel, $D$ is max depth, and $S$ is the number of scattering events per path (dependent on optical thickness) [S1, unofficial][S4, unofficial].
*   **Memory Complexity:** $O(1)$ for iterative path traversal, as the integrator uses a `while` loop structure rather than recursion [S5].
*   **Performance:** High variance for small light sources due to lack of explicit light sampling (Next-Event Estimation) [S4, unofficial]. Significantly higher MSE than [VolPathIntegrator](35-single-and-multiple-scattering.md) which uses MIS and light sampling [S4, unofficial].
*   **Strengths:** Simple implementation, robust for homogeneous media, good ground-truth baseline [S4, unofficial].
*   **Limitations:** No surface scattering support, no explicit light sampling, high variance in scenes with small lights [S4, unofficial]. Assumes convex bounding volume for medium [S3, unofficial].

## Background
The method originates from basic volumetric path tracing implementations in educational and research contexts. The `SimpleVolPathIntegrator` is described in the PBRT book (Chapter 14) as a basic integrator that does not handle surface scattering or explicit light sampling [S4, unofficial]. It is used for debugging and as a baseline for more advanced methods like [Differential Ratio Tracking](3853-radiative-transfer-and-integral-equation-solvers.md) [S3, unofficial]. The approach extends classical path tracing by allowing rays to interact with participating media [S1, unofficial].
