# Volumetric Path Tracing

Also called: Simple Volumetric Path Tracing, SimpleVolPathIntegrator, VolpathSimpleIntegrator, volpathsimple-basic, volpathsimple-drt

## Overview

Volumetric Path Tracing simulates light transport in participating media by extending classical path tracing to allow rays to enter volumetric regions, sample scattering events within the medium, and continue random walks after each scattering interaction to support multiple scattering [S1, unofficial][S4]. Unlike classical path tracing which assumes a vacuum, this method models absorption and scattering to create effects like colored shadows and fog [S1, unofficial]. It is distinguished from its siblings by its simplicity: it typically uses basic delta tracking for distance sampling and lacks explicit light sampling (Next-Event Estimation), relying instead on the recursive phase function sampling to capture indirect lighting [S4][S1, unofficial]. This makes it robust for debugging and computing ground-truth results for pure volume scattering, but inefficient for scenes with small light sources due to high variance [S4][S1, unofficial].

## How it works

**Inputs:**
*   Camera ray origin $o$ and direction $d$ (normalized).
*   Scene geometry (surfaces) and participating media (volumes).
*   Light sources (typically infinite/emissive backgrounds for the simplest variant).
*   Medium properties: absorption coefficient $\sigma_a$, scattering coefficient $\sigma_s$, total extinction $\sigma_t = \sigma_a + \sigma_s$, and phase function $p(\omega_i, \omega_o)$.
*   Parameters: `maxDepth` (integer, max path length), `sigma_maj` (majorant extinction for delta tracking).

**Outputs:**
*   Estimated radiance $L$ at the camera pixel.

**Data Structures:**
*   `Ray`: Struct with `o` (Vec3 origin) and `d` (Vec3 direction, normalized).
*   `MediumProperties`: Struct containing $\sigma_a$, $\sigma_s$, $\sigma_t$, and a reference to the phase function.
*   `RNG`: Random number generator initialized with hashed samples from the main sampler to ensure uncorrelated samples per path vertex.

**Steps:**

1.  **Initialization:**
    *   Initialize path throughput $\beta = 1.0$.
    *   Initialize accumulated radiance $L = 0$.
    *   Initialize depth $depth = 0$.
    *   Terminate secondary wavelength samples if spectral rendering is used (estimate at a single wavelength for simplicity) [S4].

2.  **Ray Marching Loop:**
    While `depth < maxDepth`:
    
    a. **Surface Intersection:**
    *   Cast ray to find closest surface intersection $si$ at distance $t_{max}$.
    *   If no intersection, $t_{max} = \infty$.

    b. **Medium Sampling (Delta Tracking):**
    *   If the ray passes through a medium:
        *   Initialize a local RNG using two hashed samples from the main sampler: `hash0 = Hash(sampler.Get1D())`, `hash1 = Hash(sampler.Get1D())`, `RNG rng(hash0, hash1)` [S4].
        *   Sample the medium using delta tracking with majorant $\sigma_{maj}$ (typically $\max(\sigma_t)$ in the volume) [S4].
        *   Pass $t_{max}$, a uniform sample $u$, and a mode sample $u_{mode}$ to the delta tracking routine.
        *   **Delta Tracking Logic:**
            *   Compute probabilities: $p_{absorb} = \sigma_a / \sigma_{maj}$, $p_{scatter} = \sigma_s / \sigma_{maj}$, $p_{null} = \max(0, 1 - p_{absorb} - p_{scatter})$ [S4].
            *   Select event mode using discrete sampling with probabilities $\{p_{absorb}, p_{scatter}, p_{null}\}$ based on $u_{mode}$ [S4].
            *   **If Absorb (mode 0):**
                *   Add emission from the medium at the hit point: $L += \beta \cdot \sigma_a \cdot L_e$ (where $L_e$ is medium emission) [S4, G].
                *   Set `terminated = true` and break loop.
            *   **If Scatter (mode 1):**
                *   If `depth >= maxDepth`, set `terminated = true` and break loop [S4].
                *   Increment `depth`.
                *   Sample the phase function for the scattering event using two uniform samples $u = \{rng.Uniform(), rng.Uniform()\}$ [S4].
                *   If phase function sampling fails, set `terminated = true` and break loop [S4].
                *   Update throughput: $\beta = \beta \cdot \frac{p(\omega_i, \omega_o)}{pdf}$ [S4].
                *   Update ray origin to intersection point $p$ and direction to scattered direction $d = \omega_o$.
                *   Set `scattered = true` and continue loop.
            *   **If Null (mode 2):**
                *   Generate a new $u_{mode}$ from the RNG and continue delta tracking (loop back to step b) [S4].

    c. **Handle Termination/No Scatter:**
    *   If `terminated` is true, return $L$ [S4].
    *   If `scattered` is false (ray hit surface or left medium):
        *   If surface intersection $si$ exists:
            *   Get BSDF. If BSDF exists and returns a valid sample (non-delta), the simple integrator errors out as it does not support surface scattering [S4].
            *   If BSDF is null or delta, skip intersection and continue loop with updated ray origin/direction if applicable, or terminate.
        *   If no surface intersection (ray escaped medium):
            *   Add emission from infinite lights/background: $L += \beta \cdot L_{env}(ray.d)$ [S4].
            *   Return $L$.

3.  **Final Output:**
    *   Return accumulated radiance $L$.

**Formulas:**

*   **Total Extinction:** $\sigma_t = \sigma_a + \sigma_s$ [S1, unofficial].
*   **Single Scattering Albedo:** $\omega = \sigma_s / \sigma_t$ [S1, unofficial].
*   **Transmittance:** $T(d) = \exp(-\sigma_t \cdot d)$ [S1, unofficial].
*   **Phase Function (Isotropic):** $p(\omega_i, \omega_o) = \frac{1}{4\pi}$ [S1, unofficial].
*   **Phase Function (Henyey-Greenstein):** $p(\cos \theta) = \frac{1}{4\pi} \frac{1-g^2}{(1+g^2-2g\cos\theta)^{1.5}}$, where $g$ is the asymmetry parameter [S2, unofficial].
*   **Throughput Update:** $\beta_{new} = \beta_{old} \cdot \frac{p(\omega_i, \omega_o)}{pdf}$ [S4].

**Pseudocode:**

```python
def volumetric_path_tracing(ray, scene, max_depth, sigma_maj):
    """
    Simulates light transport in participating media using simple delta tracking.
    
    Args:
        ray: Ray object with origin 'o' and normalized direction 'd'.
        scene: Scene object providing 'intersect(ray)' and 'get_medium(ray)'.
        max_depth: Integer maximum path length.
        sigma_maj: Vector3 majorant extinction coefficient for delta tracking.
        
    Returns:
        SampledSpectrum: Estimated radiance.
    """
    L = Spectrum(0.0)
    beta = 1.0
    depth = 0
    
    # Terminate secondary wavelengths for single-wavelength estimation [S4]
    # lambda.TerminateSecondary() 
    
    while depth < max_depth:
        # 1. Find surface intersection
        si = scene.intersect(ray)
        t_max = si.t_hit if si else float('inf')
        
        scattered = False
        terminated = False
        
        # 2. Sample medium if ray is in a medium
        medium = scene.get_medium(ray)
        if medium:
            # Initialize local RNG from main sampler [S4]
            hash0 = hash(scene.sampler.get_1d())
            hash1 = hash(scene.sampler.get_1d())
            rng = RNG(hash0, hash1)
            
            u = scene.sampler.get_1d()
            u_mode = scene.sampler.get_1d()
            
            # Delta Tracking Loop
            while True:
                # Sample distance using majorant
                # xi = uniform(0, 1)
                # t = -log(1 - xi) / sigma_maj
                # Note: Standard delta tracking implementation details omitted for brevity,
                # assuming SampleT_maj handles the loop and returns (p, mp, sigma_maj, T_maj)
                result = sample_t_maj(ray, t_max, u, rng, medium, sigma_maj)
                
                if result is None:
                    # Ray escaped medium without interaction
                    break
                
                p, mp, sigma_maj_val, T_maj = result
                sigma_a = mp.sigma_a
                sigma_s = mp.sigma_s
                
                # Compute probabilities [S4]
                p_absorb = sigma_a / sigma_maj_val
                p_scatter = sigma_s / sigma_maj_val
                p_null = max(0.0, 1.0 - p_absorb - p_scatter)
                
                # Select mode [S4]
                mode = sample_discrete([p_absorb, p_scatter, p_null], u_mode)
                
                if mode == 0: # Absorb
                    L += beta * mp.L_e # Add medium emission [S4, G]
                    terminated = True
                    break
                elif mode == 1: # Scatter
                    if depth >= max_depth:
                        terminated = True
                        break
                    
                    depth += 1
                    
                    # Sample phase function [S4]
                    u_phase = (rng.uniform(), rng.uniform())
                    ps = mp.phase.sample_p(-ray.d, u_phase)
                    
                    if not ps:
                        terminated = True
                        break
                    
                    # Update throughput [S4]
                    beta *= ps.p / ps.pdf
                    
                    # Update ray state [S4]
                    ray.o = p
                    ray.d = ps.wi
                    scattered = True
                    break
                else: # Null
                    u_mode = rng.uniform()
                    # Continue delta tracking loop
                    continue
        
        # 3. Handle termination or surface interaction
        if terminated:
            return L
            
        if not scattered:
            # Ray hit surface or escaped medium
            if si:
                bsdf = si.get_bsdf(ray)
                if bsdf and bsdf.has_non_delta_sample():
                    # SimpleVolPathIntegrator does not support surface scattering [S4]
                    raise Error("SimpleVolPathIntegrator doesn't support surface scattering.")
                else:
                    # Skip intersection, continue with ray
                    si.skip_intersection(ray, si.t_hit)
                    continue
            else:
                # Escaped medium, add background/emission [S4]
                for light in scene.infinite_lights:
                    L += beta * light.L_e(ray)
                return L
        
        # If scattered, loop continues with new ray direction

    return L
```

**Parameters:**
*   `maxDepth`: Integer, typically 5-10 for basic implementations [S1, unofficial][S4].
*   `sigma_maj`: Vector3, majorant extinction. Must be $\ge \sigma_t$ everywhere in the volume [S4].
*   `sigma_a`, `sigma_s`: Vector3 absorption and scattering coefficients. Typical values for fog: $\sigma_a = (0.003, 0.025, 0.030)$, $\sigma_s = (0.15, 0.03, 0.02)$ [S1, unofficial].

**Edge Cases and Pitfalls:**
*   **Surface Scattering:** The simple integrator errors out if it encounters a surface with a non-delta BSDF, as it does not handle surface scattering [S4].
*   **Light Sampling:** It does not perform explicit light sampling (NEE). It relies on random walks to intersect lights, leading to high variance for small light sources [S4][S1, unofficial].
*   **Delta Tracking Efficiency:** If $\sigma_{maj}$ is much larger than the actual $\sigma_t$, the null scattering rate increases, reducing efficiency [S4].
*   **Zero Vector Normalization:** Ensure ray directions are normalized before phase function evaluation to avoid NaNs [S2, unofficial].

## Operating characteristics

*   **Time Complexity:** $O(N \cdot D \cdot K)$, where $N$ is samples per pixel, $D$ is max depth, and $K$ is the average number of delta tracking steps per scattering event (dependent on $\sigma_{maj}/\sigma_t$) [S4].
*   **Memory Complexity:** $O(1)$ per path, as it does not store path history for MIS or advanced techniques [S4].
*   **Performance:** High variance for scenes with small light sources due to lack of explicit light sampling [S4]. Lower MSE than naive random walk but higher than VolPathIntegrator (which uses NEE and surface scattering) [S4].
*   **Strengths:** Simple implementation, robust for pure volume scattering, good for debugging and ground-truth generation [S4].
*   **Limitations:** No surface scattering support, no explicit light sampling, high variance for small lights, assumes convex medium boundaries [S3, unofficial][S4].
*   **When to use:** Debugging volumetric effects, scenes with large area lights or infinite backgrounds, educational purposes [S4].
*   **When not to use:** Scenes with small discrete light sources, scenes requiring surface-volumetric interaction, production rendering requiring low noise [S4].

## Background

Volumetric Path Tracing originated as a method to simulate light transport in participating media by extending classical path tracing [S1, unofficial]. The "Simple" variant, often referred to as `SimpleVolPathIntegrator`, was introduced in the context of educational tools and basic rendering engines to demonstrate delta tracking and basic volume scattering without the complexity of surface interactions or explicit light sampling [S4]. It is commonly used in academic settings and as a baseline for more advanced integrators like `VolPathIntegrator` [S4]. The method is implemented in various open-source projects and research codebases, including Mitsuba 3 plugins for differential ratio tracking [S3, unofficial].
