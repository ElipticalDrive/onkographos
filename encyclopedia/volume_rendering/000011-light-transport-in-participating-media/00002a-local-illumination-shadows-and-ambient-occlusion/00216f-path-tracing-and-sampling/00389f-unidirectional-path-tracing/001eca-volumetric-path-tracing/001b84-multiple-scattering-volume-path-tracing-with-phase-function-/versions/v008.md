# Multiple Scattering Volume Path Tracing with Phase Function Sampling

Also called: VolPathIntegrator, Volumetric Path Integrator

## Overview
A path tracing technique for simulating light transport in participating media where a ray enters a material, applies a BTDF, travels a distance determined by an exponential distribution, scatters according to a phase function, and repeats until exiting the material with another BTDF [S1, unofficial][S2, S3]. It solves the problem of rendering multiple scattering events in homogeneous volumes by importance-sampling the distance to the next interaction and the scattering direction, supporting index-matched surfaces and Russian roulette termination [S2]. Unlike its parent [Volumetric Path Tracing](1863-volumetric-path-tracing.md), which uses simple delta tracking, this method explicitly samples the phase function to handle multiple bounces efficiently [S2]. It differs from [Volumetric Path Tracing with Transmittance Sampling](6593-volumetric-path-tracing-with-transmittance-sampling.md) by using majorant-based transmittance sampling to handle inhomogeneous or complex media boundaries robustly [S3].

## How it works
**Inputs:** Camera ray, scene geometry, participating media definitions (scattering coefficient $\sigma_s$, absorption coefficient $\sigma_a$, phase function), light sources, maximum depth `maxDepth`, Russian roulette depth `rr_depth`, and a sampler for random numbers [S2, S3].
**Outputs:** Radiance $L$ for the pixel [S3].

**Data Structures:**
*   `Ray`: Origin `o`, direction `d`, time `time`, medium pointer [S3].
*   `MediumProperties`: $\sigma_a$ (absorption), $\sigma_s$ (scattering), $\sigma_t = \sigma_a + \sigma_s$ (extinction), phase function, emission $L_e$ [S1, unofficial][S3].
*   `SampledSpectrum`: Represents spectral data (e.g., RGB or sampled wavelengths) [S3].
*   `PhaseFunctionSample`: Contains direction `wi`, PDF `pdf`, and phase function value `p` [S3].
*   `BSDFSample`: Contains direction `wi`, PDF `pdf`, BSDF value `f`, and flags (specular, transmission) [S3].

**Parameters:**
*   `maxDepth`: Integer limiting the maximum number of bounces/scattering events. If -1, infinite bounces are allowed (though Russian roulette terminates them) [S2, S3]. `maxDepth=2` corresponds to single scattering [S2].
*   `rr_depth`: Controls when Russian roulette begins. RR starts when a light path has `rr_depth + 1` vertices [S2].
*   `regularize`: Boolean flag; if true, BSDFs are regularized after non-specular bounces to prevent numerical instability [S3].
*   `lightSampleStrategy`: String specifying the light sampling strategy (default "bvh") [S3].

**Steps:**
1.  Initialize path state variables: radiance $L=0$, throughput $\beta=1$, rescaled unidirectional probability $r_u=1$, rescaled light-sampling probability $r_l=1$, `specularBounce=false`, `anyNonSpecularBounces=false`, `depth=0`, `etaScale=1`, and `prevIntrContext` [S3].
2.  Intersect the current ray with the scene geometry to obtain intersection `si` and maximum traversal distance $t_{max}$ [S3].
3.  If the ray is inside a medium, initialize a local RNG from the sampler, sample majorant transmittance $T_{maj}$, and handle medium emission if applicable [S3].
4.  Compute interaction probabilities for absorption, scattering, and null scattering based on the majorant cross-section [S3].
5.  Sample the interaction type using a discrete distribution [S3]. Handle absorption by terminating the path, scattering by updating throughput and sampling the phase function, or null scattering by updating throughput with the null coefficient [S3].
6.  If the path terminated or throughput became invalid, return $L$ [S3]. If a real scattering event occurred, continue to the next loop iteration [S3]. If the ray passed through the medium unscattered, scale throughput by the transmittance ratio [S3].
7.  Handle surface intersections: retrieve the BSDF, initialize visible surface albedo at depth 0, check depth limits, regularize the BSDF if needed, sample direct lighting for non-specular BSDFs, and sample the BSDF for the next direction [S3].
8.  Update throughput $\beta$ and rescaled probability $r_l$ using the BSDF sample and the absolute dot product of the normal and outgoing direction [S3].
9.  Update path state flags, refractive index scale for transmission, and spawn the new ray [S3]. Handle BSSRDF subsurface scattering if present and transmission occurs [S3].
10. Apply Russian roulette termination based on the scaled throughput and depth [S3]. If terminated, break; otherwise, scale $\beta$ and continue [S3].
11. Return the accumulated radiance $L$ [S3].

**Pseudocode:**
```python
def Li(ray, lambda, sampler, scratchBuffer, visibleSurf, maxDepth, regularize, camera, lights, lightSampler):
    L = SampledSpectrum(0.0)
    beta = SampledSpectrum(1.0)
    r_u = SampledSpectrum(1.0)
    r_l = SampledSpectrum(1.0)
    specularBounce = False
    anyNonSpecularBounces = False
    depth = 0
    etaScale = 1.0
    prevIntrContext = LightSampleContext()

    while True:
        si = Intersect(ray)
        t_max = si.tHit if si else Infinity

        if ray.medium:
            hash0 = Hash(sampler.Get1D())
            hash1 = Hash(sampler.Get1D())
            rng = RNG(hash0, hash1)
            scattered = False
            terminated = False

            def medium_callback(p, mp, sigma_maj, T_maj):
                nonlocal scattered, terminated, beta, r_u, r_l, L, prevIntrContext, depth
                if depth < maxDepth and mp.Le:
                    pdf = sigma_maj[0] * T_maj[0]
                    betap = beta * T_maj / pdf
                    r_e = r_u * sigma_maj * T_maj / pdf
                    if r_e:
                        L += betap * mp.sigma_a * mp.Le / r_e.Average()

                pAbsorb = mp.sigma_a[0] / sigma_maj[0]
                pScatter = mp.sigma_s[0] / sigma_maj[0]
                pNull = max(0.0, 1.0 - pAbsorb - pScatter)

                um = rng.Uniform()
                mode = SampleDiscrete([pAbsorb, pScatter, pNull], um)

                if mode == 0:
                    terminated = True
                    return False
                elif mode == 1:
                    if depth >= maxDepth:
                        terminated = True
                        return False
                    depth += 1
                    pdf = T_maj[0] * mp.sigma_s[0]
                    beta *= T_maj * mp.sigma_s / pdf
                    r_u *= T_maj * mp.sigma_s / pdf
                    if beta and r_u:
                        intr = MediumInteraction(p, -ray.d, ray.time, ray.medium, mp.phase)
                        L += SampleLd(intr, None, lambda, sampler, beta, r_u)
                        u = sampler.Get2D()
                        ps = intr.phase.Sample_p(-ray.d, u)
                        if not ps or ps.pdf == 0:
                            terminated = True
                        else:
                            beta *= ps.p / ps.pdf
                            r_l = r_u / ps.pdf
                            prevIntrContext = LightSampleContext(intr)
                            scattered = True
                            ray.o = p
                            ray.d = ps.wi
                            specularBounce = False
                            anyNonSpecularBounces = True
                    return False
                else:
                    sigma_n = ClampZero(sigma_maj - mp.sigma_a - mp.sigma_s)
                    pdf = T_maj[0] * sigma_n[0]
                    beta *= T_maj * sigma_n / pdf
                    if pdf == 0: beta = SampledSpectrum(0.0)
                    r_u *= T_maj * sigma_n / pdf
                    r_l *= T_maj * sigma_maj / pdf
                    return bool(beta and r_u)

            T_maj = SampleT_maj(ray, t_max, sampler.Get1D(), rng, lambda, medium_callback)

            if terminated or not beta or not r_u:
                return L
            if scattered:
                continue
            beta *= T_maj / T_maj[0]
            r_u *= T_maj / T_maj[0]
            r_l *= T_maj / T_maj[0]

        if not si:
            for light in infiniteLights:
                Le = light.Le(ray, lambda)
                if Le:
                    if depth == 0 or specularBounce:
                        L += beta * Le / r_u.Average()
                    else:
                        lightPDF = lightSampler.PMF(prevIntrContext, light) * light.PDF_Li(prevIntrContext, ray.d, True)
                        r_l *= lightPDF
                        L += beta * Le / (r_u + r_l).Average()
            continue

        isect = si
        bsdf = isect.GetBSDF(ray, lambda, camera, scratchBuffer, sampler)
        if not bsdf:
            isect.SkipIntersection(&ray, si.tHit)
            continue

        if depth == 0 and visibleSurf:
            albedo = bsdf.rho(isect.wo, ucRho, uRho)
            visibleSurf = VisibleSurface(isect, albedo, lambda)

        if depth >= maxDepth:
            return L

        if regularize and anyNonSpecularBounces:
            bsdf.Regularize()

        if IsNonSpecular(bsdf.Flags()):
            L += SampleLd(isect, bsdf, lambda, sampler, beta, r_u)
            prevIntrContext = LightSampleContext(isect)

        wo = isect.wo
        u = sampler.Get1D()
        bs = bsdf.Sample_f(wo, u, sampler.Get2D())
        if not bs:
            break

        beta *= bs.f * abs(dot(bs.wi, isect.shading.n)) / bs.pdf
        if bs.pdfIsProportional:
            r_l = r_u / bsdf.PDF(wo, bs.wi)
        else:
            r_l = r_u / bs.pdf

        specularBounce = bs.IsSpecular()
        anyNonSpecularBounces |= not bs.IsSpecular()
        if bs.IsTransmission():
            etaScale *= bs.eta ** 2
        ray = isect.SpawnRay(ray, bsdf, bs.wi, bs.flags, bs.eta)

        bssrdf = isect.GetBSSRDF(ray, lambda, camera, scratchBuffer)
        if bssrdf and bs.IsTransmission():
            uc = sampler.Get1D()
            up = sampler.Get2D()
            probeSeg = bssrdf.SampleSp(uc, up)
            if not probeSeg:
                break
            seed = MixBits(FloatToBits(sampler.Get1D()))
            interactionSampler = WeightedReservoirSampler(seed)
            base = Interaction(probeSeg.p0, ray.time, Medium())
            while True:
                r = base.SpawnRayTo(probeSeg.p1)
                si_sub = Intersect(r, 1)
                if not si_sub:
                    break
                base = si_sub.intr
                if si_sub.intr.material == isect.material:
                    interactionSampler.Add(SubsurfaceInteraction(si_sub.intr), 1.0)
            if not interactionSampler.HasSample():
                break
            ssi = interactionSampler.GetSample()
            bssrdfSample = bssrdf.ProbeIntersectionToSample(ssi, scratchBuffer)
            if not bssrdfSample.Sp or not bssrdfSample.pdf:
                break
            pdf = interactionSampler.SampleProbability() * bssrdfSample.pdf[0]
            beta *= bssrdfSample.Sp / pdf
            r_u *= bssrdfSample.Sp / pdf
            anyNonSpecularBounces = True
            Sw = bssrdfSample.Sw
            if regularize:
                Sw.Regularize()
            pi = bssrdfSample.pi
            L += SampleLd(pi, Sw, lambda, sampler, beta, r_u)
            u = sampler.Get1D()
            bs = Sw.Sample_f(pi.wo, u, sampler.Get2D())
            if not bs:
                break
            beta *= bs.f * abs(dot(bs.wi, pi.shading.n)) / bs.pdf
            r_l = r_u / bs.pdf
            specularBounce = bs.IsSpecular()
            ray = RayDifferential(pi.SpawnRay(bs.wi))

        rrBeta = beta * etaScale / r_u.Average()
        uRR = sampler.Get1D()
        if rrBeta.MaxComponentValue() < 1 and depth > 1:
            q = max(0.0, 1.0 - rrBeta.MaxComponentValue())
            if uRR < q:
                break
            beta /= 1.0 - q

    return L
```

**Formulas:**
*   **Extinction:** $\sigma_t = \sigma_s + \sigma_a$ [S1, unofficial].
*   **Rescaled Probabilities:**
    $$r_{u, \lambda, i}(\bar{p}_n) = \frac{p_{u, \lambda, i}(\bar{p}_n)}{p_{path}(\bar{p}_n)}$$
    $$r_{l, \lambda, i}(\bar{p}_n) = \frac{p_{l, \lambda, i}(\bar{p}_n)}{p_{path}(\bar{p}_n)}$$ [S3]
*   **MIS Weight (Unidirectional):**
    $$w_u(\bar{p}_n) = \frac{1}{\frac{1}{m} \sum_{i=1}^m r_{u, \lambda, i}(\bar{p}_n) + \sum_{i=1}^m r_{l, \lambda, i}(\bar{p}_n)}$$ [S3]
*   **Russian Roulette Probability:**
    $$P_{rr} = \min \left( \frac{\text{contrib}(\text{path})}{p(\text{path})}, 0.95 \right)$$ [S2]

**Edge Cases and Pitfalls:**
*   **Double Counting:** Do not apply Beer-Lambert attenuation $e^{-\sigma x}$ explicitly to path weights if the distance was importance-sampled from the exponential distribution, as it is implicitly incorporated in the sampling probability [S1, unofficial][S3].
*   **Zero PDF:** If phase function sampling fails or returns zero PDF, terminate the path [S3]. If null scattering PDF is zero, explicitly set $\beta=0$ to prevent division by zero [S3].
*   **Chromatic Media:** For non-monochromatic coefficients, simulating all channels simultaneously is inefficient. Assign each ray a single wavelength or color channel and calculate scattering separately [S1, unofficial].
*   **Index-Matched Surfaces:** Surfaces with `material_id == -1` are index-matched. Pass through them, update the medium using `update_medium`, and increment bounces [S2].

## Operating characteristics
*   **Complexity:** Time complexity depends on the number of scattering events, which is driven by the optical thickness of the medium [G]. Memory complexity is linear in path depth [G].
*   **Performance:** Robust for multiple scattering in homogeneous and inhomogeneous media. Majorant sampling handles complex boundaries but may be less efficient if the majorant is much larger than the actual extinction coefficient [S3].
*   **Strengths:** Handles multiple scattering, index-matched surfaces, and chromatic media. Rescaled probabilities prevent floating-point overflow/underflow [S3].
*   **Limitations:** Can be slow for very dense media due to many scattering events. Russian roulette introduces variance [S2].
*   **When to use:** Ground truth rendering, scenes with complex volumetric interactions, translucent materials [S3].
*   **When not to use:** Real-time rendering requiring approximations, very sparse media where simpler methods suffice [G].

## Background
Originated from the need to simulate light transport in participating media accurately [G]. The VolPathIntegrator is a key component of modern path tracers like PBRT, handling both surface and volume transport robustly [S3]. It builds on earlier work in Monte Carlo volumetric scattering [S1, unofficial] and extends basic volumetric path tracing [S2] by incorporating rescaled probabilities and MIS for unidirectional and light sampling strategies [S3].
