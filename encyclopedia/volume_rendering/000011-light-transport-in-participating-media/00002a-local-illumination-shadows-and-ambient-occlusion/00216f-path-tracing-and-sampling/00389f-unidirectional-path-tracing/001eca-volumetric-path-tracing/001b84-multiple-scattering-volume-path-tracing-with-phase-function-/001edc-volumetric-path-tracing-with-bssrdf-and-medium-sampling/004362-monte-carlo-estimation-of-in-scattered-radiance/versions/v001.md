# Monte Carlo estimation of in-scattered radiance

Also called: Monte Carlo In-scattering, Source Function Estimation

## Overview
This method estimates the in-scattered radiance $L_{\text{ins}}(x, \boldsymbol{\omega})$ at a specific point $x$ and direction $\boldsymbol{\omega}$, accounting for light scattered into $\boldsymbol{\omega}$ from all other directions. It solves the integral term of the Radiative Transfer Equation (RTE) by sampling directions according to the phase function. It differs from direct transmission estimation by focusing on the volumetric scattering contribution, and from reference path tracing by providing a specific estimator for the in-scattering term rather than a full path weight.

## How it works
**Inputs:**
- Point $x$ (position in 3D space).
- Direction $\boldsymbol{\omega}$ (view direction or outgoing direction).
- Phase function $f_p(x, \boldsymbol{\omega}', \boldsymbol{\omega})$ or $p(x, \boldsymbol{\omega}', \boldsymbol{\omega})$.
- Surface normal $\mathbf{n}(x)$ (if $x$ is on the boundary).
- Radiance evaluation function $L(x, \boldsymbol{\omega}')$ (returns radiance at $x$ in direction $\boldsymbol{\omega}'$).
- Boundary radiance function $L_s(x, \boldsymbol{\omega}')$ (returns radiance refracted into the medium at boundary $x$).
- Epsilon $\epsilon$ (small scalar, $\epsilon \to 0^+$).

**Outputs:**
- Estimated in-scattered radiance $L_{\text{ins}}$.

**Data Structures:**
- No persistent data structures required. The method is a point-wise estimator.

**Steps:**
1. Determine if $x$ is in the interior or on the boundary.
2. If $x$ is in the interior ($x \in \Omega \setminus \partial \Omega$):
   a. Draw a direction $\boldsymbol{\omega}'$ from the phase function distribution $f_p(x, -\boldsymbol{\omega}', \boldsymbol{\omega})$.
   b. Evaluate the radiance $L(x, \boldsymbol{\omega}')$ at $x$ in direction $\boldsymbol{\omega}'$.
   c. Set $L_{\text{ins}} \leftarrow L(x, \boldsymbol{\omega}')$.
3. If $x$ is on the boundary ($x \in \partial \Omega$):
   a. Define a point slightly inside the medium: $x_{\text{in}} = x + \epsilon \boldsymbol{\omega}$.
   b. Draw a direction $\boldsymbol{\omega}'$ from the phase function distribution $f_p(x_{\text{in}}, -\boldsymbol{\omega}', \boldsymbol{\omega})$.
   c. Check the dot product of the surface normal $\mathbf{n}(x)$ and the drawn direction $\boldsymbol{\omega}'$.
   d. If $\langle \mathbf{n}(x), \boldsymbol{\omega}' \rangle > 0$:
      i. Set $L_{\text{ins}} \leftarrow L(x, \boldsymbol{\omega}')$.
   e. Else:
      i. Set $L_{\text{ins}} \leftarrow L_s(x, \boldsymbol{\omega}')$.
4. Return $L_{\text{ins}}$.

**Formulas:**
The in-scattered radiance is estimated by sampling the phase function. For the source function $J(s')$ (in-scattering from all directions at $s'$), the Monte Carlo estimator with $M$ samples is:
$$ J_N = \frac{1}{M} \sum_{k=1}^M \frac{p(s', \boldsymbol{\omega}_k', \boldsymbol{\omega}) L(s', \boldsymbol{\omega}_k')}{\text{pdf}(\boldsymbol{\omega}_k')} $$
where $p$ is the phase function, $L$ is the radiance, and $\text{pdf}$ is the probability density function of the sampled direction.

For isotropic media, $p = \frac{1}{4\pi}$. Directions are sampled uniformly on the unit sphere.

**Parameters:**
- $\epsilon$: A small positive scalar to offset boundary points into the interior. Value not given in the sources [G: typically $10^{-6}$ to $10^{-4}$ world units].
- $M$: Number of samples for the source function estimator. Value not given in the sources.

**Pitfalls:**
- **Boundary Precision:** When $x$ is on the boundary, sampling directly at $x$ can cause self-intersection or incorrect normal evaluation. Offsetting by $\epsilon$ along $\boldsymbol{\omega}$ is required [S1, unofficial].
- **Direction Validity:** On the boundary, if the sampled direction $\boldsymbol{\omega}'$ points out of the medium ($\langle \mathbf{n}(x), \boldsymbol{\omega}' \rangle \le 0$), the radiance must come from the surface source $L_s$ (refracted light), not the interior volume $L$ [S1, unofficial].
- **Distance to Next Scatter:** When estimating diffusion terms involving distance sampling, if the sampled distance to the next scattering event $d_j$ is greater than the distance to the surface $s$, the event is a refraction (direct transmission), not an internal scatter [S2, unofficial]. This method handles the angular part; the distance part is handled by the parent method's distance sampling.

## Operating characteristics
- **Time Complexity:** $O(M)$ where $M$ is the number of samples for the source function estimator [S2, unofficial]. Each sample requires one phase function evaluation and one radiance evaluation.
- **Memory Complexity:** $O(1)$ auxiliary memory.
- **Strengths:** Unbiased estimator for the in-scattering term. Can be combined with importance sampling using the phase function to reduce variance [S2, unofficial].
- **Limitations:** High variance if the phase function is highly anisotropic and not sampled correctly. Requires accurate evaluation of $L(x, \boldsymbol{\omega}')$ which may itself be expensive. Boundary handling requires careful offsetting to avoid self-intersection [S1, unofficial].
- **When to use:** When accurate volumetric lighting is required and the in-scattering term is significant.
- **When not to use:** When performance is critical and approximate lighting (e.g., single scattering) is sufficient.

## Background
The method is based on the Monte Carlo estimation of the source function $J(s')$ in the Radiative Transfer Equation (RTE) [S2, unofficial]. The RTE was formalized by Chandrasekhar [1950] [S2, unofficial]. The specific algorithm for estimating $L_{\text{ins}}$ at interior and boundary points, including the handling of discontinuities and side paths, is described in "A Differential Theory of Radiative Transfer" [S1, unofficial]. The phase function sampling techniques, such as for the Henyey-Greenstein phase function, are based on work by Henyey and Greenstein [1940] [S2, unofficial].
