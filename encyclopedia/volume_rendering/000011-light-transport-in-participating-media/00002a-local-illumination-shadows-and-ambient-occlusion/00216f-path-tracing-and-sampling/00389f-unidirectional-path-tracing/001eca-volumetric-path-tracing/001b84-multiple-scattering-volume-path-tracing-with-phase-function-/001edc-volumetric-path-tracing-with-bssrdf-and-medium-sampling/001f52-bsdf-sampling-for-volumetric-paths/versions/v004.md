# BSDF Sampling for Volumetric Paths

Also called: GoTracer, Implicit Path Tracing with Volume Interaction, Ray Tracing in One Weekend Go Implementation, Surface scattering in volumetric path tracing

## Overview
BSDF Sampling for Volumetric Paths handles the surface interaction component of path tracing, calculating indirect lighting contributions based on surface BRDFs and sampling strategies [S1, unofficial][S3]. It determines the new direction of a volumetric path upon hitting a surface, updating throughput and rescaled probabilities to account for the surface scattering event [S3]. It builds on [Volumetric Path Tracing with BSSRDF and Medium Sampling](1867-volumetric-path-tracing-with-bssrdf-and-medium-sampling.md) and differs from [Reference Path Tracing](3170-reference-path-tracing.md) by explicitly managing volumetric path state and BSDF probability rescaling during surface bounces [S3].

## How it works

### Inputs and Outputs
**Inputs:**
- Incoming ray $r$ (origin, direction) [S2, unofficial].
- Scene geometry and materials, including participating media definitions [S2, unofficial].
- Current path throughput $\beta$ [S3].
- Random number generator state for sampling directions and distances [S3].
- Maximum recursion depth [S2, unofficial].

**Outputs:**
- Scattered ray direction and origin [S3].
- Updated throughput $\beta'$ [S3].
- Boolean flag indicating if the path terminates or continues [S2, unofficial].

### Data Structures
**HitRecord** [S2, unofficial]:
- `P`: Vector, intersection point.
- `Normal`: Vector, surface normal at intersection.
- `T`: float64, distance along ray to intersection.
- `FrontFace`: bool, true if normal points against ray direction.
- `Mat`: Material, material properties at intersection.

**Material** [S2, unofficial]:
- `Scatter`: Function pointer, scattering function (e.g., Lambertian, Metal, Dielectric).
- `Colour`: Vector (RGB), albedo or emission color.
- `Fuzz`: float64, roughness factor for metallic reflections.
- `Light`: bool, true if the material is an emissive light source.

**ConstantMedium** [S2, unofficial]:
- `Obj`: Object, the enclosed geometry.
- `Density`: float64, density of the participating medium.
- `Colour`: Vector (RGB), color of the medium.

**Ray** [S2, unofficial]:
- `Origin`: Vector.
- `Direction`: Vector.

### Steps
1. **Ray-Scene Intersection**: Cast the incoming ray against the scene. If the ray hits an object, retrieve the `HitRecord` containing the intersection point, normal, and material [S2, unofficial]. If the ray hits a `ConstantMedium`, perform a two-step hit test against the inner object to determine entry and exit points, then sample the distance to the first scattering event within the medium using the density [S2, unofficial].
2. **Surface Interaction Check**: If a surface intersection occurs:
   - If the material is emissive (`Mat.Light` is true), return the material's color as the direct lighting contribution and terminate the path [S2, unofficial].
   - If the material is not emissive, proceed to BSDF sampling [S2, unofficial].
3. **BSDF Sampling**: Sample the Bidirectional Scattering Distribution Function (BSDF) to determine the outgoing direction $w_o$ [S3].
   - Generate random numbers $u_1, u_2$ from a uniform distribution $[0, 1)$ [S3].
   - Call the material's specific scatter function (e.g., `LambertianScatter`, `MetalScatter`, `DielectricScatter`) using the incoming direction $w_i$, the surface normal, and the random numbers [S2, unofficial][S3].
   - The scatter function returns the scattered ray direction and the attenuation color [S2, unofficial].
4. **Throughput Update**: Update the path throughput $\beta$ to account for the surface scattering [S3].
   $$ \beta' = \beta \cdot \frac{f_r(w_i, w_o) \cdot |\cos \theta_i|}{p(w_o)} $$
   Where:
   - $f_r(w_i, w_o)$ is the BSDF value (often hardcoded or derived from the material color, e.g., $1/\pi$ for Lambertian) [S1, unofficial][S3].
   - $\theta_i$ is the angle between the surface normal and the outgoing direction [S1, unofficial][S3].
   - $p(w_o)$ is the probability density function (PDF) of the sampled direction [S3].
   - For Uniform Hemisphere sampling: $p(w_o) = \frac{1}{2\pi}$ [S1, unofficial].
   - For Cosine-Weighted Hemisphere sampling: $p(w_o) = \frac{1}{\pi}$ [S1, unofficial].
5. **Rescaled Probabilities**: If `bs->pdfIsProportional` is true: $r_l = r_u / \text{bsdf.PDF}(w_o, w_i)$ [S3]. Else: $r_l = r_u / \text{bs->pdf}$ [S3].
6. **State Update**: Update `specularBounce` flag based on whether the BSDF sample is specular [S3]. Update `anyNonSpecularBounces` flag [S3]. If the interaction is a transmission (refraction), update the eta scale factor: $\eta_{scale} *= \eta^2$ [S3]. Spawn the new ray with the updated direction and origin [S3].
7. **Recursive Path Tracing**: Recursively call the path tracer with the new scattered ray, decrementing the depth counter [S2, unofficial]. Accumulate the indirect radiance into the pixel color [S1, unofficial].
8. **Termination**: If depth reaches 0, return black (0,0,0) [S2, unofficial]. If the BSDF sample fails (e.g., metal reflection dot product is negative), terminate the path [S2, unofficial].

### Pseudocode
```python
import math
import random

def random_float():
    """Returns a uniform random float in [0.0, 1.0)."""
    return random.uniform(0.0, 1.0)

def dot(v1, v2):
    return v1[0]*v2[0] + v1[1]*v2[1] + v1[2]*v2[2]

def reflect(v, n):
    return [v[i] - 2*dot(v, n)*n[i] for i in range(3)]

def refract(v, n, eta_ratio):
    cos_theta = min(-dot(v, n), 1.0)
    r_out_perp = [v[i] + cos_theta * n[i] for i in range(3)]
    r_out_parallel = [-math.sqrt(max(0.0, 1.0 - sum(x*x for x in r_out_perp))) * n[i] for i in range(3)]
    return [r_out_perp[i] + r_out_parallel[i] for i in range(3)]

def reflectance(cosine, ref_idx):
    r0 = ((1.0 - ref_idx) / (1.0 + ref_idx)) ** 2
    return r0 + (1.0 - r0) * (1.0 - cosine) ** 5

class HitRecord:
    def __init__(self):
        self.P = [0.0, 0.0, 0.0]
        self.Normal = [0.0, 0.0, 0.0]
        self.T = 0.0
        self.FrontFace = False
        self.Mat = None

class Ray:
    def __init__(self, origin, direction):
        self.origin = origin
        self.direction = direction
    def at(self, t):
        return [self.origin[i] + self.direction[i]*t for i in range(3)]

class Colour:
    def __init__(self, r, g, b):
        self.r, self.g, self.b = r, g, b
    def add(self, other): return Colour(self.r+other.r, self.g+other.g, self.b+other.b)
    def mul(self, s): return Colour(self.r*s, self.g*s, self.b*s)

def lambertian_scatter(ray_dir, normal, mat):
    scatter_dir = [normal[i] + random_float()*2 - 1 for i in range(3)]
    length = math.sqrt(sum(x*x for x in scatter_dir))
    if length < 1e-6: scatter_dir = normal
    scatter_dir = [x/length for x in scatter_dir]
    return scatter_dir, mat.Colour

def metal_scatter(ray_dir, normal, mat):
    reflected = reflect(ray_dir, normal)
    fuzzed = [reflected[i] + (random_float()*2 - 1)*mat.Fuzz for i in range(3)]
    return fuzzed, mat.Colour

def dielectric_scatter(ray_dir, normal, front_face, mat):
    attenuation = Colour(1.0, 1.0, 1.0)
    ref_idx = 1.5
    ref_ratio = 1.0/ref_idx if front_face else ref_idx
    unit_dir = [x/math.sqrt(sum(y*y for y in ray_dir)) for x in ray_dir]
    cos_theta = min(-dot(unit_dir, normal), 1.0)
    sin_theta = math.sqrt(1.0 - cos_theta**2)
    cannot_refract = ref_ratio * sin_theta > 1.0
    if cannot_refract or reflectance(cos_theta, ref_ratio) > random_float():
        direction = reflect(unit_dir, normal)
    else:
        direction = refract(unit_dir, normal, ref_ratio)
    return direction, attenuation

def ray_colour(ray_origin, ray_direction, scene, depth, beta):
    if depth <= 0:
        return Colour(0.0, 0.0, 0.0)
    
    rec = HitRecord()
    if scene.hit(ray_origin, ray_direction, 0.001, float('inf'), rec):
        scattered_dir = None
        attenuation = Colour(0.0, 0.0, 0.0)
        
        if rec.Mat.Light:
            return rec.Mat.Colour
            
        if rec.Mat.Scatter == "Lambertian":
            scattered_dir, attenuation = lambertian_scatter(ray_direction, rec.Normal, rec.Mat)
        elif rec.Mat.Scatter == "Metal":
            scattered_dir, attenuation = metal_scatter(ray_direction, rec.Normal, rec.Mat)
        elif rec.Mat.Scatter == "Dielectric":
            scattered_dir, attenuation = dielectric_scatter(ray_direction, rec.Normal, rec.FrontFace, rec.Mat)
            
        if scattered_dir is not None:
            cos_theta = abs(dot(rec.Normal, scattered_dir))
            pdf = 1.0 / (2.0 * math.pi) # Uniform hemisphere assumption
            brdf = rec.Mat.Colour.r / math.pi # Lambertian approximation
            beta_new = beta * (brdf * cos_theta) / pdf
            scattered_origin = rec.P
            return attenuation.mul(ray_colour(scattered_origin, scattered_dir, scene, depth - 1, beta_new))
            
    return Colour(0.0, 0.0, 0.0)
```

### Parameters
- `samplesPerPixel`: Number of samples per pixel for anti-aliasing. Default: 300 [S2, unofficial].
- `maxDepth`: Maximum recursion depth for path tracing. Default: 50 [S2, unofficial].
- `aperture`: Depth of field aperture size. Default: 0.0 [S2, unofficial].
- `vfov`: Vertical field of view in degrees. Default: 40.0 [S2, unofficial].
- `refractionIndex`: Index of refraction for dielectric materials. Default: 1.5 [S2, unofficial].

### Edge Cases and Pitfalls
- **Metal Scatter Direction**: The reflected ray direction must have a positive dot product with the surface normal. If `dot(normal, scattered_direction) <= 0`, the ray is absorbed, and the path terminates [S2, unofficial].
- **Dielectric Total Internal Reflection**: If `refractionRatio * sinTheta > 1.0`, total internal reflection occurs, and the ray is reflected instead of refracted [S2, unofficial].
- **Constant Medium Hit Test**: A small epsilon (0.0001) is added to the inner object's hit distance to avoid self-intersection when finding the second hit point [S2, unofficial].
- **Lambertian Degeneracy**: If the random unit vector added to the normal results in a near-zero vector, the scatter direction is clamped to the normal to avoid degenerate rays [S2, unofficial].
- **Gamma Correction**: Output values are gamma-corrected using `sqrt(pixel_value / samplesPerPixel)` before display [S2, unofficial].

## Operating characteristics

### Time and Memory Complexity
Not given in the sources.

### Measured Performance
Performance depends heavily on scene complexity and the number of samples [S2, unofficial]. GoTracer uses parallelism via goroutines to process image rows in parallel, leveraging multi-core CPUs [S2, unofficial]. Default settings (800x533 resolution, 300 samples, depth 50) provide high-quality images but require significant computation time [S2, unofficial].

### Strengths and Limitations
- **Strengths**: Simple implementation, supports multiple surface types (Lambertian, Metal, Dielectric, Isotropic), handles participating media (Constant Medium), supports depth of field and anti-aliasing [S2, unofficial].
- **Limitations**: Limited to simple geometries (Spheres, Boxes, Rectangles), no advanced material models, no global illumination beyond path tracing, limited to constant density media [S2, unofficial].

### When to Use
- Suitable for educational purposes and simple volumetric rendering demonstrations [S2, unofficial].
- Not suitable for production-quality rendering due to limited material models and lack of advanced optimization techniques [S2, unofficial].

## Background

### Origin
The method is based on the "Ray Tracing in One Weekend" series by Peter Shirley, implemented in Go as "GoTracer" by hexhowells [S2, unofficial]. It also draws concepts from the "Volume Single Scattering" project by wangyuehi [S1, unofficial] and the theoretical framework of volume scattering integrators from the "Physically Based Rendering" (pbr-book) 4th edition [S3].

### History and Development
- **Ray Tracing in One Weekend**: Popularized simple path tracing techniques for educational purposes [S2, unofficial].
- **GoTracer**: Extended the original C++ implementation to Go, adding parallelism and supporting participating media [S2, unofficial].
- **Volume Single Scattering**: Handles the surface interaction part of path tracing, calculating indirect lighting contribution based on the surface BRDF and sampling strategy [S1, unofficial].
- **pbr-book**: Provided the theoretical basis for volume scattering integrators, including BSDF sampling and throughput updates [S3].

### Applications
- Educational ray tracers [S2, unofficial].
- Simple volumetric rendering demonstrations [S1, unofficial].
- Research prototyping for volume rendering algorithms [S3].
