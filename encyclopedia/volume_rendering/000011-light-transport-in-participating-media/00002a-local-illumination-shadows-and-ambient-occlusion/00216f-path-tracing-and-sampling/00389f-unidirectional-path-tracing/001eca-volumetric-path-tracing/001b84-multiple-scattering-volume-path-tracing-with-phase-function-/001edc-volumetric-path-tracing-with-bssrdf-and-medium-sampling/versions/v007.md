# Volumetric Path Tracing with BSSRDF and Medium Sampling

Also called: BSSRDF integration, Path Tracing with Subsurface Scattering and Participating Media, Subsurface Scattering Integration in Volumetric Path Tracing, Subsurface scattering in VolPathIntegrator, VolPathIntegrator with BSSRDF

## Overview
This method extends volumetric path tracing to handle subsurface scattering by integrating BSSRDF (Bidirectional Surface Scattering Reflectance Distribution Function) probes directly into the path traversal loop, allowing light to enter a material, scatter internally, and exit at a different surface point before continuing as a standard surface interaction [S1]. It bridges surface geometry and participating media by treating the subsurface exit as a surface scattering event with direct and indirect illumination, distinct from [Multiple Scattering Volume Path Tracing with Phase Function Sampling](1043-multiple-scattering-volume-path-tracing-with-phase-function-.md) which focuses on homogeneous volume multiple scattering without explicit surface BSSRDF probes [S1].

## How it works
**Inputs and Outputs:**
*   **Input:** Current path state (`beta`, `r_u`, `ray`, `depth`), surface intersection `isect` with an attached `BSSRDF`, scene geometry for intersection tests, sampler for random numbers, and `MediumProperties` for the current volume [S1].
*   **Output:** Updated path contribution `L`, updated path state (`beta`, `r_u`, `ray`), and termination flags [S1].

**Data Structures:**
*   `BSSRDFProbeSegment`: Contains entry point `p0` and exit point `p1` on the surface [S1].
*   `WeightedReservoirSampler<T>`: A reservoir sampling structure to select a random intersection from a stream of candidates with equal weight [S1].
*   `BSSRDFSample`: Contains the exit point interaction `ssi`, the scattering probability `Sp`, the PDF `pdf`, the outgoing direction `wo`, and the BSDF `Sw` at the exit point [S1].
*   `MediumInteraction`: Contains position `p`, incoming direction, time, medium reference, and phase function [S1].

**Parameters:**
*   `maxDepth`: Maximum path depth [S1].
*   `regularize`: Boolean flag to regularize specular BSDFs to prevent infinite throughput spikes [S1].
*   `lambda`: Wavelength or spectral sample index [S1].

**Formulas:**
The emission estimator for a medium scattering event at $p'$ is $\beta(\overline{p_n} + p') \sigma_a(p') L_e(p' \to p_n)$ [S1]. The incremental beta is computed as $\beta(\overline{p_n} + p') = \frac{\beta(\overline{p_n}) T_{maj}(p_n \to p')}{p_e(p') p_{maj}(p' | p_n, \omega)}$, where $p_e=1$ because absorption is sampled for emission [S1]. The MIS balance heuristic weight is $w_e(\overline{p_n} + p') = \frac{1}{\frac{1}{m} \sum_{i=1}^m r_{e, \lambda_i}(\overline{p_n} + p')}$, where the denominator is computed using `SampledSpectrum::Average()` [S1].

**Algorithm Steps:**

1.  **Retrieve BSSRDF:** Get the BSSRDF from the current intersection `isect` [S1]. If BSSRDF exists and is transmission, sample a probe segment: `Float uc = sampler.Get1D(); Point2f up = sampler.Get2D(); pstd::optional<BSSRDFProbeSegment> probeSeg = bssrdf.SampleSp(uc, up);` If no probe segment, break [S1].
2.  **Reservoir Sampling for Exit Point:** Initialize `WeightedReservoirSampler<SubsurfaceInteraction>` with seed `MixBits(FloatToBits(sampler.Get1D()))` [S1]. Create base interaction at `probeSeg->p0` [S1]. Loop: spawn ray from `base` to `probeSeg->p1`, intersect against scene geometry. If intersection `si` exists and `si->intr.material == isect.material`, add `SubsurfaceInteraction(si->intr)` to reservoir with weight 1.0 [S1]. Update `base = si->intr`. If no intersection, break. If reservoir has no samples, break [S1].
3.  **Convert to BSSRDFSample:** Get sampled `SubsurfaceInteraction` (`ssi`) from reservoir [S1]. Call `bssrdf.ProbeIntersectionToSample(ssi, scratchBuffer)` to get `bssrdfSample` [S1]. If `!bssrdfSample.Sp` or `!bssrdfSample.pdf`, break [S1].
4.  **Update Path State:** Calculate PDF: `pdf = interactionSampler.SampleProbability() * bssrdfSample.pdf[0]` [S1]. Update throughput: `beta *= bssrdfSample.Sp / pdf` [S1]. Update rescaled probability: `r_u *= bssrdfSample.pdf / bssrdfSample.pdf[0]` [S1]. Set surface interaction `pi = ssi` [S1]. Set outgoing direction `pi.wo = bssrdfSample.wo` [S1]. Set `prevIntrContext = LightSampleContext(pi)` [S1].
5.  **Regularize BSDF (Optional):** If `regularize` is true, call `Sw.Regularize()` on BSDF from `bssrdfSample` [S1]. Set `anyNonSpecularBounces = true` [S1].
6.  **Sample Direct Illumination:** Call `SampleLd(pi, &Sw, lambda, sampler, beta, r_u)` to add attenuated direct illumination to `L` [S1].
7.  **Sample Indirect Subsurface Scattering:** Generate `u` (1D) and `v` (2D) [S1]. Call `Sw.Sample_f(pi.wo, u, v)` to get `bs` [S1]. If no sample, break. Update throughput: `beta *= bs->f * AbsDot(bs->wi, pi.shading.n) / bs->pdf` [S1]. Update rescaled probability: `r_l = r_u / bs->pdf` [S1]. Set `specularBounce = bs->IsSpecular()` [S1]. Spawn new ray: `ray = RayDifferential(pi.SpawnRay(bs->wi))` [S1].
8.  **Russian Roulette:** If `depth > 1`, calculate `rrBeta = beta * etaScale / r_u.Average()` [S1]. If `rrBeta.MaxComponentValue() < 1`, generate `uRR` [S1]. If `uRR < 1 - rrBeta.MaxComponentValue()`, terminate [S1]. Else, `beta /= 1 - q` [S1].
9.  **Sample Participating Medium:** Determine `tMax` from next surface intersection or infinity [S1]. Initialize RNG with two 1D samples. Call `SampleT_maj` with lambda function [S1].
10. **Compute Medium Event Probabilities:** `Float pAbsorb = mp.sigma_a[0] / sigma_maj[0]; Float pScatter = mp.sigma_s[0] / sigma_maj[0]; Float pNull = std::max<Float>(0, 1 - pAbsorb - pScatter);` Sample mode `m` using `um` [S1].
11. **Handle Absorption (Mode 0):** Set `terminated = true`, return false [S1].
12. **Handle Scattering (Mode 1):** If `depth >= maxDepth`, set `terminated = true`, return false [S1]. Update `beta` and `r_u` with transmittance and scattering PDF. If valid, add emission: `L += betap * sigma_a * Le / r_e.Average()` where `betap = beta * T_maj / pdf` and `r_e = r_u * sigma_maj * T_maj / pdf`. Note: Do not cancel `T_maj` factors before MIS weighting [S1]. Sample direct lighting: `L += SampleLd(intr, nullptr, lambda, sampler, beta, r_u)` [S1].
13. **Sample Phase Function:** `ps = intr.phase.Sample_p(-ray.d, u)`. If valid, update `beta`, `r_l`, `ray`, and set `scattered = true` [S1].
14. **Handle Null Scattering (Mode 2):** Compute `sigma_n = ClampZero(sigma_maj - sigma_a - sigma_s)`. Update `beta` and `r_u` with null scattering PDF. If `pdf == 0`, set `beta = 0`. Return `beta && r_u` [S1].
15. **Handle Terminated/Scattered/Unscattered Rays:** If `terminated` or invalid `beta`/`r_u`, return `L`. If `scattered`, continue to next path vertex. Else, update `beta`, `r_u`, `r_l` by `T_maj / T_maj[0]` [S1].

**Pitfalls:** Do not cancel out $T_{maj}$ factors between betap and re before MIS weighting, because the final estimator divides by the average of rescaled probabilities, not component-wise. Cancelling leads to incorrect results [S1].

**Pseudocode:**

```python
def sample_t_maj(ray, t_max, rng, event_lambda):
    sigma_maj = ray.medium.sigma_maj
    t = 0.0
    while t < t_max:
        t += -log(1.0 - rng.uniform()) / sigma_maj[0]
        if t >= t_max:
            return
        T_maj_val = exp(-sigma_maj[0] * t)
        p = ray.o + t * ray.d
        mp = ray.medium.get_properties(p)
        if not event_lambda(p, mp, sigma_maj, T_maj_val):
            return

def volumetric_path_tracing_with_bssrdf(isect, beta, r_u, ray, depth, max_depth, sampler, scene, lambda_idx, regularize, eta_scale=1.0, scratch_buffer=None):
    L = Spectrum(0.0)
    specular_bounce = False
    any_non_specular_bounces = False
    terminated = False
    scattered = False

    # Retrieve BSSRDF
    bssrdf = isect.get_bssrdf(ray, lambda_idx)
    if bssrdf and bssrdf.is_transmission():
        uc = sampler.get_1d()
        up = sampler.get_2d()
        probe_seg = bssrdf.sample_sp(uc, up)
        if not probe_seg:
            return L, beta, r_u, ray, terminated, scattered

        seed = hash(sampler.get_1d())
        interaction_sampler = WeightedReservoirSampler[SubsurfaceInteraction](seed)
        base = Interaction(probe_seg.p0, ray.time, Medium())

        while True:
            r = base.spawn_ray_to(probe_seg.p1)
            si = scene.intersect(r, 1.0)
            if not si:
                break
            base = si.intr
            if si.intr.material == isect.material:
                interaction_sampler.add(SubsurfaceInteraction(si.intr), 1.0)

        if not interaction_sampler.has_sample():
            return L, beta, r_u, ray, terminated, scattered

        ssi = interaction_sampler.get_sample()
        bssrdf_sample = bssrdf.probe_intersection_to_sample(ssi, scratch_buffer)
        if not bssrdf_sample.Sp or not bssrdf_sample.pdf:
            return L, beta, r_u, ray, terminated, scattered

        pdf = interaction_sampler.sample_probability() * bssrdf_sample.pdf[0]
        beta *= bssrdf_sample.Sp / pdf
        r_u *= bssrdf_sample.pdf / bssrdf_sample.pdf[0]

        pi = ssi
        pi.wo = bssrdf_sample.wo
        prev_intr_context = LightSampleContext(pi)

        Sw = bssrdf_sample.Sw
        any_non_specular_bounces = True
        if regularize:
            Sw.regularize()

        L += sample_ld(pi, Sw, lambda_idx, sampler, beta, r_u)

        u = sampler.get_1d()
        bs = Sw.sample_f(pi.wo, u, sampler.get_2d())
        if not bs:
            return L, beta, r_u, ray, terminated, scattered

        beta *= bs.f * abs_dot(bs.wi, pi.shading.n) / bs.pdf
        r_l = r_u / bs.pdf
        specular_bounce = bs.is_specular()
        ray = RayDifferential(pi.spawn_ray(bs.wi))

    rr_beta = beta * eta_scale / r_u.average()
    u_rr = sampler.get_1d()
    if rr_beta.max_component_value() < 1 and depth > 1:
        q = max(0.0, 1.0 - rr_beta.max_component_value())
        if u_rr < q:
            terminated = True
            return L, beta, r_u, ray, terminated, scattered
        beta /= 1.0 - q

    t_max = scene.intersect(ray, 1.0).t_hit if scene.intersect(ray, 1.0) else float('inf')
    hash0 = hash(sampler.get_1d())
    hash1 = hash(sampler.get_1d())
    rng = RNG(hash0, hash1)

    def medium_event_lambda(p, mp, sigma_maj, T_maj_val):
        nonlocal scattered, terminated, beta, r_u, r_l, L, ray, specular_bounce, any_non_specular_bounces, prev_intr_context

        if depth < max_depth and mp.Le:
            pdf_em = sigma_maj[0] * T_maj_val[0]
            betap = beta * T_maj_val / pdf_em
            r_e = r_u * sigma_maj * T_maj_val / pdf_em
            if r_e:
                L += betap * mp.sigma_a * mp.Le / r_e.average()

        p_absorb = mp.sigma_a[0] / sigma_maj[0]
        p_scatter = mp.sigma_s[0] / sigma_maj[0]
        p_null = max(0.0, 1.0 - p_absorb - p_scatter)
        um = rng.uniform()
        mode = sample_discrete([p_absorb, p_scatter, p_null], um)

        if mode == 0:
            terminated = True
            return False
        elif mode == 1:
            if depth >= max_depth:
                terminated = True
                return False
            pdf_sc = T_maj_val[0] * mp.sigma_s[0]
            beta *= T_maj_val * mp.sigma_s / pdf_sc
            r_u *= T_maj_val * mp.sigma_s / pdf_sc

            if beta and r_u:
                intr = MediumInteraction(p, -ray.d, ray.time, ray.medium, mp.phase)
                L += sample_ld(intr, None, lambda_idx, sampler, beta, r_u)

                u_phase = sampler.get_2d()
                ps = intr.phase.sample_p(-ray.d, u_phase)
                if not ps or ps.pdf == 0:
                    terminated = True
                else:
                    beta *= ps.p / ps.pdf
                    r_l = r_u / ps.pdf
                    prev_intr_context = LightSampleContext(intr)
                    scattered = True
                    ray.o = p
                    ray.d = ps.wi
                    specular_bounce = False
                    any_non_specular_bounces = True
            return False
        else:
            sigma_n = clamp_zero(sigma_maj - mp.sigma_a - mp.sigma_s)
            pdf_null = T_maj_val[0] * sigma_n[0]
            beta *= T_maj_val * sigma_n / pdf_null
            if pdf_null == 0:
                beta = Spectrum(0.0)
            r_u *= T_maj_val * sigma_n / pdf_null
            r_l *= T_maj_val * sigma_maj / pdf_null
            return beta and r_u

    sample_t_maj(ray, t_max, rng, medium_event_lambda)

    if terminated or not beta or not r_u:
        return L, beta, r_u, ray, terminated, False
    if scattered:
        return L, beta, r_u, ray, False, False
    else:
        beta *= T_maj / T_maj[0]
        r_u *= T_maj / T_maj[0]
        r_l *= T_maj / T_maj[0]
        return L, beta, r_u, ray, False, False
```

## Subtopics

### [BSDF Sampling for Volumetric Paths](1995-bsdf-sampling-for-volumetric-paths.md)
BSDF Sampling for Volumetric Paths handles the surface interaction component of path tracing within participating media, calculating indirect lighting contributions based on surface BRDFs and sampling strategies. It determines the new direction of a volumetric path upon hitting a surface, updating throughput and rescaled probabilities to account for the surface scattering event. Unlike pure volume integrators, this method bridges surface geometry and participating media by treating surface interactions as scattering events that redirect rays back into the medium or to other surfaces.

### [Reference Path Tracing](3170-reference-path-tracing.md)
Reference Path Tracing is an unbiased volumetric path tracer used as a ground-truth reference renderer for subsurface scattering and participating media. It solves the problem of accurate light transport in high-curvature surfaces and complex media by treating the subsurface layer as a volume, performing full random walks from entry to exit points. It sets itself apart from diffusion-based models by explicitly tracking geometric features for accurate shadowing and handling zero- and single-scatter events, while differing from sibling methods like BSDF Sampling for Volumetric Paths by relying on a pure random walk with Next-Event Estimation (NEE) rather than specialized BSDF sampling strategies.

### [Monte Carlo estimation of in-scattered radiance](10983-monte-carlo-estimation-of-in-scattered-radiance.md)
This method estimates the in-scattered radiance $L_{\text{ins}}(x, \boldsymbol{\omega})$ for interior points $x \in \Omega \setminus \partial \Omega$ and boundary points $x \in \partial \Omega$. It computes the angular integral of the source function by sampling directions according to the phase function.

### Chromatic Effects with MIS
A technique to handle non-monochromatic media efficiently by using Multiple Importance Sampling (MIS) between RGB channels during distance sampling, avoiding the inefficiency of picking a single wavelength [S2, unofficial]. The probability of picking channel $\lambda$ is $P(\lambda)$, and the probability density for distance $s$ given channel $\lambda$ is $P_\lambda(s) = \sigma_\lambda e^{-s\sigma_\lambda}$, where $\sigma_\lambda$ is the extinction coefficient for channel $\lambda$ [S2, unofficial]. The total probability density is $P(s) = P(\lambda) P_\lambda(s)$ [S2, unofficial]. The MIS weight using the balance heuristic for standard RGB renders is $W_\lambda(s) = \frac{P(\lambda)}{P(\lambda_R) + P(\lambda_G) + P(\lambda_B)}$ [S2, unofficial]. To prevent fireflies from throughput spiking in deep paths with highly tinted extinction, $P(\lambda)$ should be chosen using the current throughput instead of single scatter albedo [S2, unofficial].

## Operating characteristics
*   **Time Complexity:** $O(N)$ per path vertex, where $N$ is the number of intersections along the BSSRDF probe segment [S1].
*   **Memory Complexity:** $O(1)$ additional memory for the reservoir sampler state, assuming the scene intersection structure is pre-built [S1].
*   **Strengths:** Accurately handles subsurface scattering in complex scenes with participating media [S1]. Integrates seamlessly with existing path tracing infrastructure [S1]. Handles chromatic effects via MIS [S2, unofficial].
*   **Limitations:** Performance depends heavily on the density of geometry along the BSSRDF probe segment [S1]. Reservoir sampling can be inefficient if few valid intersections are found [S1].
*   **When to use:** When rendering translucent materials (skin, wax, marble) in scenes with fog, smoke, or other participating media [S1].
*   **When not to use:** For purely opaque materials or purely volumetric effects without surface subsurface scattering [S1].

## Background
