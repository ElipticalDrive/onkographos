# Wavefront Path Tracer with Spatial Hashing

Also called: Spatial Hash Path Tracing

## Overview
A path tracing method that uses spatial hashing to accumulate radiance, allowing for denoising via spatial filtering [S1, unofficial]. It differs from standard path tracing by decoupling the accumulation buffer from the pixel grid, enabling spatial averaging of radiance estimates before final display [S1, unofficial].

## How it works
The method consists of four distinct phases: Generate, Extend, Accumulate, and Display. It relies on Multiple Importance Sampling (MIS) to combine light source and BRDF samples [S1, unofficial].

**Inputs and Outputs:**
*   **Inputs:** G-buffer raster (containing position, normal, albedo), voxel grid (sparse representation of participating media/surfaces), sun disk direction, camera parameters.
*   **Outputs:** Final image with surface details retained.

**Data Structures:**
*   **Ray Queue:** A dynamic list of rays to be processed in the Extend phase.
*   **Spatial Hash Map:** A hash table mapping 3D spatial coordinates (bucket indices) to accumulated radiance values. The hash function maps a 3D position to a bucket index. The size of the hash buckets determines the spatial resolution of the denoising.

**MIS Weight Formula:**
The importance sampling weight $F$ for a direction sample $X$ is calculated as [S1, unofficial]:

$$
F = \frac{f(X)}{(1/2)p_1(X) + (1/2)p_2(X)}
$$

Where:
*   $F$ is the MIS weight.
*   $f(X)$ is the PDF of the combined distribution.
*   $p_1(X)$ is the probability density of sampling from the cosine-weighted normal distribution.
*   $p_2(X)$ is the probability density of sampling from the sun disk distribution.
*   Both distributions are sampled with equal probability $1/2$.

**Steps:**

1.  **Generate:**
    For each pixel in the G-buffer raster:
    a. Generate a primary ray based on the pixel's position and the camera's projection.
    b. Scatter rays using MIS. The direction sample $X$ is chosen from either the cosine-weighted normal distribution or the sun disk distribution with probability $1/2$ each [S1, unofficial].
    c. Calculate the MIS weight $F$ for the chosen direction.
    d. Place the generated ray into the ray queue.

2.  **Extend:**
    Process each ray in the ray queue:
    a. Intersect the ray with the voxel grid using sparse ray marching.
    b. At each intersection, shade the point by updating the path's throughput. The throughput is multiplied by the albedo and the MIS weight $F$ of the scattering event.
    c. If a scattering event occurs (e.g., at a surface intersection or within participating media), generate a new scattered ray direction using MIS.
    d. Place the scattered ray into the output ray queue for the next iteration or frame.

3.  **Accumulate:**
    For each completed path (or after a fixed number of bounces):
    a. Calculate the radiance $L$ of the path.
    b. Demodulate the radiance by dividing by the path's albedo (or the albedo at the final intersection point) to isolate the shading component. This is referred to as "albedo-demodulated radiance" [S1, unofficial].
    c. Map the path's final position to a spatial hash bucket.
    d. Accumulate the albedo-demodulated radiance into the spatial hash bucket. This step averages radiance estimates across nearby pixels, providing denoising.

4.  **Display:**
    a. For each pixel, retrieve the accumulated albedo-demodulated radiance from the corresponding spatial hash bucket.
    b. Multiply this value by the pixel's albedo to remodulate the radiance. This step retains surface details (such as color and texture) that were lost during the spatial averaging in the hash buckets [S1, unofficial].
    c. Output the final image.

**Pseudocode:**

```python
def wavefront_path_tracer_with_spatial_hashing(gbuffer, voxel_grid, sun_direction, num_samples):
    # Initialize spatial hash map
    # Key: (bucket_x, bucket_y, bucket_z)
    # Value: (accumulated_radiance, count)
    spatial_hash = {}

    # Initialize ray queue
    ray_queue = []

    # Generate Phase
    for pixel in gbuffer:
        for _ in range(num_samples):
            # Generate primary ray from pixel
            ray = generate_ray_from_pixel(pixel)
            
            # Scatter using MIS
            # Choose distribution with probability 0.5
            if random() < 0.5:
                direction = sample_cosine_weighted_normal(pixel.normal)
                pdf = cosine_weighted_pdf(direction, pixel.normal)
            else:
                direction = sample_sun_disk(sun_direction)
                pdf = sun_disk_pdf(direction, sun_direction)
            
            # Calculate MIS weight
            # f(X) is the PDF of the chosen distribution
            # p1(X) is cosine-weighted PDF, p2(X) is sun disk PDF
            f_x = pdf
            p1_x = cosine_weighted_pdf(direction, pixel.normal)
            p2_x = sun_disk_pdf(direction, sun_direction)
            
            mis_weight = f_x / (0.5 * p1_x + 0.5 * p2_x)
            
            # Create ray with throughput
            new_ray = Ray(ray.origin, direction, throughput=pixel.albedo * mis_weight)
            ray_queue.append(new_ray)

    # Extend Phase
    while ray_queue:
        current_ray = ray_queue.pop(0)
        
        # Sparse ray marching through voxel grid
        intersection = sparse_ray_march(current_ray, voxel_grid)
        
        if intersection:
            # Shade intersection
            albedo = intersection.albedo
            normal = intersection.normal
            
            # Update throughput
            current_ray.throughput *= albedo
            
            # Scatter if needed (e.g., for participating media or surface scattering)
            # For simplicity, assume surface scattering generates new rays
            # Re-sample direction using MIS
            if random() < 0.5:
                new_direction = sample_cosine_weighted_normal(normal)
                pdf = cosine_weighted_pdf(new_direction, normal)
            else:
                new_direction = sample_sun_disk(sun_direction)
                pdf = sun_disk_pdf(new_direction, sun_direction)
            
            f_x = pdf
            p1_x = cosine_weighted_pdf(new_direction, normal)
            p2_x = sun_disk_pdf(new_direction, sun_direction)
            
            mis_weight = f_x / (0.5 * p1_x + 0.5 * p2_x)
            
            # Create new scattered ray
            scattered_ray = Ray(intersection.point, new_direction, throughput=current_ray.throughput * mis_weight)
            ray_queue.append(scattered_ray)
            
            # Accumulate radiance for the path ending here (or after fixed bounces)
            # For this example, we assume accumulation happens at the end of a path
            # In a real implementation, this might be done after a fixed number of bounces
            # or when throughput drops below a threshold.
            # Here, we accumulate the current radiance estimate
            radiance = current_ray.throughput * intersection.emission # Assuming emission is 0 for surfaces
            
            # Demodulate radiance
            # Avoid division by zero
            if albedo > 1e-6:
                demodulated_radiance = radiance / albedo
            else:
                demodulated_radiance = 0.0
            
            # Map to spatial hash
            bucket = get_spatial_hash_bucket(intersection.point)
            
            # Accumulate into hash
            if bucket not in spatial_hash:
                spatial_hash[bucket] = [0.0, 0]
            
            spatial_hash[bucket][0] += demodulated_radiance
            spatial_hash[bucket][1] += 1

    # Display Phase
    final_image = {}
    for pixel in gbuffer:
        bucket = get_spatial_hash_bucket(pixel.position)
        if bucket in spatial_hash:
            avg_demodulated_radiance = spatial_hash[bucket][0] / spatial_hash[bucket][1]
            # Remodulate by albedo
            final_radiance = avg_demodulated_radiance * pixel.albedo
        else:
            final_radiance = 0.0
        
        final_image[pixel.id] = final_radiance
    
    return final_image
```

**Parameters:**
*   **Spatial Hash Cell Size:** Determines the size of the spatial buckets. Large cell sizes result in a blocky appearance [S1, unofficial].
*   **MIS Probabilities:** Both cosine-weighted normal and sun disk distributions are sampled with probability $1/2$ [S1, unofficial].

**Edge Cases and Pitfalls:**
*   **Large Cell Sizes:** Using large cell sizes in the spatial hash results in a blocky appearance [S1, unofficial].
*   **No Spatial Filtering:** The implementation does not perform spatial filtering on the hash map itself, which may lead to artifacts if the hash buckets are too large or too small [S1, unofficial].
*   **Division by Zero:** When demodulating radiance, ensure albedo is not zero to avoid division by zero errors.

## Operating characteristics
*   **Time Complexity:** Depends on the number of rays, the depth of the voxel grid, and the number of bounces. The spatial hash lookup is $O(1)$ on average.
*   **Memory Complexity:** Proportional to the number of spatial hash buckets and the number of rays in the queue.
*   **Strengths:** Allows for denoising via spatial averaging. Retains surface details by remodulating with albedo.
*   **Limitations:** Large cell sizes cause blocky artifacts. No spatial filtering is applied to the hash map.
*   **When to use:** When denoising is desired and surface details need to be preserved. Suitable for scenes with sparse voxels.
*   **When not to use:** When high-frequency spatial details are critical and cannot be approximated by spatial averaging.

## Background
The method is loosely based on Jacco Bikker’s blog entry [S1, unofficial]. It was implemented as part of a voxel raytracer development log [S1, unofficial]. The use of MIS for combining light source and BRDF samples is a common technique in path tracing, but the specific application of spatial hashing for radiance accumulation in this context is notable [S1, unofficial].
