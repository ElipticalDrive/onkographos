# Differentiable Shadow Kernel Sampling via Normal Distribution

Also called: ICDF sampling for differentable shadows, Normal distribution kernel for shadow offset

## Overview
This method enables differentiable path tracing by importance sampling shadow offsets using a Normal distribution kernel in parameter space [S1]. It allows for the computation of gradients with respect to scene parameters by treating shadowing as a convolution with a smooth kernel, rather than a hard binary visibility test [S1]. Unlike standard binary shadow mapping or hard-edged shadow volumes, this approach provides continuous visibility derivatives, which is essential for optimization tasks such as material parameter recovery or geometry refinement [S1].

## How it works
**Inputs and Outputs:**
*   **Input:** A uniform random variable $\uniformRandom \in (0, 1)$, a bandwidth parameter $\bandwidth > 0$, and the current parameter vector $\theta$ [S1].
*   **Output:** A sampled offset $\offset$ and the updated parameter vector $\theta' = \theta - \offset$ [S1].

**Data Structures:**
No specific complex data structures are required beyond standard scalar variables for the random number, bandwidth, and parameters [G]. The method operates on scalar offsets applied to parameter vectors [G].

**Steps:**
1.  **Define the Kernel:** The shadow offset is modeled as a Normal distribution $\mathcal{N}(0, \bandwidth)$ centered at 0 [S1]. The Probability Density Function (PDF) is defined as:
    $$ \kernel (\offset ) = \frac {1}{\bandwidth \sqrt {2\pi }} \exp \left (-\frac {\offset ^2}{2\bandwidth ^2}\right ) $$
    where $\kernel$ is the kernel density, $\offset$ is the offset value, and $\bandwidth$ controls the spread of the shadow blur [S1].

2.  **Normalize for Halfspaces:** To handle the domain constraints and ensure the CDF is well-defined, the PDF is treated separately for positive and negative halfspaces [S1]. The PDF on the positive halfspace is normalized to integrate to 0.5 [S1]. The normalized PDF for the positive halfspace is given by:
    $$ \text{PDF}_+(\offset) = \frac {\offset }{2\bandwidth ^2} \exp \left (\frac {-\offset ^2}{2\bandwidth ^2}\right ) $$
    [S1].

3.  **Determine Integration Constants:** The Cumulative Distribution Function (CDF) is derived by integrating the PDF [S1]. To ensure the CDF is continuous, monotonically increasing, and defined in $(0, 1)$, specific integration constants are chosen [S1]:
    *   For the positive halfspace ($\offset > 0$), the integration constant is $C_+ = 1$ [S1].
    *   For the negative halfspace ($\offset < 0$), the integration constant is $C_- = 0$ [S1].
    
    The resulting CDF expression involves the term:
    $$ \text{CDF}(\offset) = -0.5 \exp \left (\frac {-\offset ^2}{2\bandwidth ^2}\right ) + C_+ \quad (\text{or } C_-) $$
    [S1].

4.  **Invert the CDF (ICDF):** To enable importance sampling, the CDF is inverted to obtain the Inverse CDF (ICDF) [S1]. The general form of the ICDF is:
    $$ \cdf ^{-1}(\uniformRandom ) = \begin {cases} \sqrt {2\bandwidth ^2\log (2(1-\uniformRandom ))} & \uniformRandom \in [0.5, 1) \\ \sqrt {2\bandwidth ^2\log (2\uniformRandom )} & \uniformRandom \in (0, 0.5] \end {cases} $$
    [S1].

5.  **Simplify Domain Constraints:** By analyzing the domain constraints for the square root and logarithm functions, the piecewise definition can be simplified [S1]. The source states that for $\uniformRandom \in (0, 1)$, the final simplified equation for the ICDF is:
    $$ \cdf ^{-1}(\uniformRandom )= \sqrt {-2\bandwidth ^2\log (\uniformRandom )}\,. $$
    [S1]. This formula generates the offset $\offset$ directly from a single uniform random sample $\uniformRandom$ [S1].

6.  **Apply Offset:** The sampled offset $\offset$ is subtracted from the current parameters $\theta$ to obtain the new parameters $\theta'$ for the differentiable path tracing step [S1]:
    $$ \theta' = \theta - \offset $$
    [S1].

**Pseudocode:**
```python
import math

def sample_shadow_offset(uniform_random: float, bandwidth: float) -> float:
    """
    Samples an offset from the differentiable shadow kernel using the simplified ICDF.
    
    Args:
        uniform_random: A uniform random variable in (0, 1).
        bandwidth: The bandwidth parameter sigma for the Normal distribution.
        
    Returns:
        The sampled offset value.
    """
    # Guard against log(0) to avoid numerical errors [G]
    if uniform_random <= 0.0:
        uniform_random = 1e-9
    if uniform_random >= 1.0:
        uniform_random = 1.0 - 1e-9
        
    # Final simplified ICDF equation from source [S1]
    # cdf^-1(uniform_random) = sqrt(-2 * bandwidth^2 * log(uniform_random))
    argument = -2.0 * (bandwidth ** 2) * math.log(uniform_random)
    
    # Ensure argument is non-negative for sqrt [G]
    if argument < 0:
        argument = 0.0
        
    offset = math.sqrt(argument)
    return offset

def update_parameters(theta, uniform_random, bandwidth):
    """
    Updates parameters using the sampled shadow offset.
    
    Args:
        theta: Current parameter vector.
        uniform_random: Uniform random variable.
        bandwidth: Bandwidth parameter.
        
    Returns:
        Updated parameter vector theta'.
    """
    offset = sample_shadow_offset(uniform_random, bandwidth)
    theta_prime = theta - offset
    return theta_prime
```

**Parameters:**
*   $\uniformRandom$: A uniform random variable, typically in $(0, 1)$ [S1].
*   $\bandwidth$: The bandwidth parameter of the Normal distribution, controlling the scale of the shadow blur [S1].

**Edge Cases and Pitfalls:**
*   **Logarithm Domain:** The ICDF involves $\log(\uniformRandom)$. If $\uniformRandom = 0$, the logarithm is undefined. In practice, $\uniformRandom$ must be clamped away from 0 (e.g., $\uniformRandom \ge \epsilon$) to avoid numerical errors [G].
*   **Square Root Domain:** The argument to the square root is $-2\bandwidth^2 \log(\uniformRandom)$. Since $\uniformRandom \in (0, 1)$, $\log(\uniformRandom)$ is negative, making the argument positive [G].
*   **Continuity:** The source emphasizes that the CDF must be continuous and monotonically increasing. The choice of $C_+=1$ and $C_-=0$ ensures this behavior across the halfspace boundary [S1].

## Operating characteristics
**Time and Memory Complexity:**
The method involves a constant number of arithmetic operations (logarithm, multiplication, square root) per sample [G]. Time complexity is $O(1)$ per shadow offset sample [G]. Memory complexity is $O(1)$ as no large data structures are required [G].

**Strengths and Limitations:**
*   **Strengths:** Enables differentiable path tracing by providing smooth gradients for shadow visibility [S1]. Allows for optimization of scene parameters [S1].
*   **Limitations:** The method relies on a specific kernel shape (Normal distribution) which may not be optimal for all shadow geometries [S1]. The simplification of the ICDF assumes specific domain constraints that must be carefully handled [S1].

**When to use it and when not:**
Use this method when differentiable gradients with respect to shadowing are required, such as in inverse rendering or optimization tasks [S1]. Do not use it if non-differentiable, hard shadows are desired, or if computational efficiency is the primary concern without the need for gradients [G].

## Background
**Origin:**
The method originates from the paper "Plateau-Reduced Differentiable Path Tracing" [S1].

**History and Development:**
The technique was developed to address the issue of plateaus in differentiable rendering, where hard visibility transitions cause zero gradients [S1]. By convolving the visibility with a Normal distribution kernel, the method provides non-zero gradients over a wider range of parameter changes [S1].

**Where it is used:**
It is used in differentiable path tracing renderers for tasks such as material parameter estimation, geometry optimization, and lighting estimation [S1].
