# Anisotropic Ambient Volume Shading

Also called: Anisotropic Volume Shading, Scale-aware Anisotropic Shading

## Overview
Anisotropic Ambient Volume Shading is a method for direct volume rendering that improves the perception of the orientation and shape of surface-like structures by computing anisotropic specular highlights [S1]. It solves the problem where isotropic models (e.g., Blinn-Phong) fail to convey the elliptic or linear nature of volumetric features [S2, unofficial]. Unlike isotropic shading or standard ambient occlusion, this method derives local tangent frames from the scalar field's ambient region to drive anisotropic BRDFs (Ward, Lafortune), aligning highlights with principal anisotropy directions [S1].

## How it works
**Inputs:** Scalar volume data $s(\mathbf{x})$, transfer function parameters (extinction coefficient $\sigma_t$), light direction $\mathbf{l}$, view direction $\mathbf{v}$, and user-defined parameters: ambient radius $r$, sample count $n$, interval size $\varepsilon$, global anisotropy scaling $\gamma$, and glossiness $\kappa$.
**Outputs:** Shaded radiance image.
**Data Structures:**
*   **Normals:** $\mathbf{N}(\mathbf{x})$ stored per voxel, same resolution as data.
*   **Covariance Matrices:** Symmetric $2 \times 2$ matrix $\mathbf{C}(\mathbf{x})$ stored per voxel.
*   **Tangent Vectors:** $\mathbf{U}(\mathbf{x}), \mathbf{V}(\mathbf{x})$ computed per voxel during rendering or precomputed.

**Algorithm Steps:**

1.  **Normal Estimation:** Compute the normal $\mathbf{N}(\mathbf{x})$ from the gradient of the unclassified scalar field $s$ using the Sobel operator [S1]:
    $$ \mathbf{N}(\mathbf{x}) = -\frac{\nabla s(\mathbf{x})}{\|\nabla s(\mathbf{x})\|} $$
    If $\|\nabla s(\mathbf{x})\| = 0$, skip shading (specular coefficient becomes 0) [S1].

2.  **Explorative Sampling:** Define a sphere of radius $r$ centered at shading point $\mathbf{x}$. Draw $n$ samples $\mathbf{x}_i$ uniformly inside the sphere using random numbers $\xi_0, \xi_1, \xi_2 \in [0,1]$ [S1]:
    $$ d = r \sqrt[3]{\xi_0} $$
    $$ \mathbf{x}_i = \mathbf{x} + \begin{pmatrix} 2d \cos(2\pi\xi_1)\sqrt{\xi_2(1-\xi_2)} \\ 2d \sin(2\pi\xi_1)\sqrt{\xi_2(1-\xi_2)} \\ d(1-2\xi_2) \end{pmatrix} $$
    Filter samples to keep only those where $s(\mathbf{x}_i) \in [s(\mathbf{x}) - \varepsilon, s(\mathbf{x}) + \varepsilon]$. Let the accepted set be $X_a(\mathbf{x})$ with size $m$ [S1].

3.  **Projection:** Project samples $X_a(\mathbf{x})$ onto the tangent plane defined by $\mathbf{N}(\mathbf{x})$:
    $$ \mathbf{x}_i^p = \mathbf{x}_i - (\mathbf{N}(\mathbf{x}) \cdot (\mathbf{x}_i - \mathbf{x}))\mathbf{N}(\mathbf{x}) $$
    Compute orthonormal basis vectors $\boldsymbol{\eta}_1, \boldsymbol{\eta}_2$ in the tangent plane to avoid discontinuities [S1]:
    $$ \phi = \text{atan2}(N_y, N_x) $$
    $$ \boldsymbol{\eta}_1 = (-\sin\phi, \cos\phi, 0)^T $$
    $$ \boldsymbol{\eta}_2 = \boldsymbol{\eta}_1 \times \mathbf{N} $$
    Transform projected samples to 2D coordinates $X_2(\mathbf{x})$:
    $$ \mathbf{x}_i^2 = (\mathbf{x}_i^p \cdot \boldsymbol{\eta}_1, \mathbf{x}_i^p \cdot \boldsymbol{\eta}_2)^T $$

4.  **Covariance Matrix Construction:** Compute the centroid $\bar{\mathbf{x}}$ of $X_2(\mathbf{x})$ and the weighted covariance matrix $\mathbf{C}$ [S1]:
    $$ \bar{\mathbf{x}} = \frac{1}{m} \sum_{i=1}^m \mathbf{x}_i^2 $$
    $$ \mathbf{C} = \sum_{i=1}^m (\mathbf{x}_i^2 - \bar{\mathbf{x}})(\mathbf{x}_i^2 - \bar{\mathbf{x}})^T w(d_i) $$
    where $w(d) = 1-d^2$ if $d \le 1$, else $0$, and $d_i = \|\mathbf{x}_i^2 - \bar{\mathbf{x}}\|/r$.
    *Pitfall:* For small $r$ or noisy data, apply a discrete Gaussian filter to elements $C_{11}, C_{12}, C_{22}$ before eigenanalysis [S1].

5.  **Eigenanalysis:** Compute eigenvalues $\lambda_1, \lambda_2$ and eigenvectors $\boldsymbol{\Lambda}_1, \boldsymbol{\Lambda}_2$ of $\mathbf{C}$ [S1]:
    $$ \lambda_{1,2} = \frac{\text{tr}(\mathbf{C})}{2} \pm \sqrt{\left(\frac{\text{tr}(\mathbf{C})}{2}\right)^2 - \det(\mathbf{C})} $$
    Sort such that $\lambda_1 \le \lambda_2$. Compute eigenvectors in 2D:
    If $C_{12} \neq 0$:
    $$ \boldsymbol{\Lambda}_1 = (C_{12}, \lambda_1 - C_{11})^T, \quad \boldsymbol{\Lambda}_2 = (C_{12}, \lambda_2 - C_{11})^T $$
    Else:
    $$ \boldsymbol{\Lambda}_1 = (1, 0)^T, \quad \boldsymbol{\Lambda}_2 = (0, 1)^T $$
    Transform back to 3D:
    $$ \bar{\mathbf{U}} = \Lambda_{1,x}\boldsymbol{\eta}_1 + \Lambda_{1,y}\boldsymbol{\eta}_2, \quad \bar{\mathbf{V}} = \Lambda_{2,x}\boldsymbol{\eta}_1 + \Lambda_{2,y}\boldsymbol{\eta}_2 $$
    Normalize: $\mathbf{U} = \bar{\mathbf{U}}/\|\bar{\mathbf{U}}\|$, $\mathbf{V} = \bar{\mathbf{V}}/\|\bar{\mathbf{V}}\|$. $\mathbf{V}$ is the major anisotropy direction [S1].

6.  **BRDF Parameter Mapping:** Map eigenvalue ratio to BRDF parameters using global scaling $\gamma$ [S1].
    *   **Ward:** Parameters $u_w, v_w$ control anisotropy magnitude.
    *   **Lafortune:** Parameters $u_l, v_l$ control anisotropy. Set $n_l = 1$.
    *   **Glossiness:** $\kappa$ controls specular lobe width.

7.  **Rendering:** Compute radiance using the scattering function [S1]:
    $$ L(\mathbf{x}, \mathbf{v}) = T(\mathbf{x}_b, \mathbf{x})L_b + \int T(\mathbf{x}_0, \mathbf{x})\sigma_s(\mathbf{x}_0)L_i(\mathbf{x}_0, \mathbf{v}) d\mathbf{x}_0 $$
    Scattering function:
    $$ f(\mathbf{x}, \mathbf{v}', \mathbf{v}) = k_d f_d + k_s f_s(\mathbf{x}, \mathbf{v}', \mathbf{v}) (\mathbf{v}' \cdot \mathbf{N}_{\sigma_t})_+ $$
    where $\mathbf{N}_{\sigma_t} = -\nabla \sigma_t / \|\nabla \sigma_t\|$, $k_s = \|\nabla \sigma_t\|$, $k_d = 1$. $f_s$ is the chosen anisotropic BRDF (Ward/Lafortune) using $\mathbf{U}, \mathbf{V}$ [S1].

**Pseudocode:**
```python
def compute_anisotropic_shading(x, s, sigma_t, l, v, r, n, eps, gamma, kappa):
    # 1. Normal Estimation
    grad_s = sobel_gradient(s, x)
    norm_s = length(grad_s)
    if norm_s == 0:
        return diffuse_shading(x, s, l, v) # Specular coeff ks=0
    
    N = -normalize(grad_s)
    
    # 2. Explorative Sampling
    samples_2d = []
    for i in range(n):
        xi0, xi1, xi2 = random_uniform(), random_uniform(), random_uniform()
        d = r * cbrt(xi0)
        # Sample point in sphere
        px = x.x + 2*d*cos(2*pi*xi1)*sqrt(xi2*(1-xi2))
        py = x.y + 2*d*sin(2*pi*xi1)*sqrt(xi2*(1-xi2))
        pz = x.z + d*(1-2*xi2)
        xi = Vector(px, py, pz)
        
        # Filter by scalar value
        si = sample_scalar(s, xi)
        if abs(si - s(x)) <= eps:
            # 3. Projection
            proj = xi - dot(N, xi - x) * N
            phi = atan2(N.y, N.x)
            eta1 = Vector(-sin(phi), cos(phi), 0)
            eta2 = cross(eta1, N)
            
            x2 = Vector(dot(proj, eta1), dot(proj, eta2))
            samples_2d.append((x2, xi)) # Keep 3D for distance weighting
            
    m = len(samples_2d)
    if m == 0:
        return diffuse_shading(x, s, l, v)
        
    # 4. Covariance Matrix
    centroid = Vector(0,0,0)
    for x2, _ in samples_2d:
        centroid += x2
    centroid /= m
    
    C = Matrix2x2(0,0,0,0)
    for x2, xi in samples_2d:
        diff = x2 - centroid
        dist = length(diff) / r
        w = max(0, 1 - dist*dist)
        C += outer_product(diff, diff) * w
        
    # Optional: Filter C elements here if needed
        
    # 5. Eigenanalysis
    tr = C[0][0] + C[1][1]
    det = C[0][0]*C[1][1] - C[0][1]*C[1][0]
    
    lambda1 = tr/2 - sqrt(tr*tr/4 - det)
    lambda2 = tr/2 + sqrt(tr*tr/4 - det)
    
    # Eigenvectors
    if abs(C[0][1]) > 1e-6:
        lam1_vec = Vector(C[0][1], lambda1 - C[0][0])
        lam2_vec = Vector(C[0][1], lambda2 - C[0][0])
    else:
        lam1_vec = Vector(1, 0)
        lam2_vec = Vector(0, 1)
        
    # Transform to 3D
    U_bar = lam1_vec.x * eta1 + lam1_vec.y * eta2
    V_bar = lam2_vec.x * eta1 + lam2_vec.y * eta2
    
    U = normalize(U_bar)
    V = normalize(V_bar)
    
    # 6. BRDF Parameters
    # Map eigenvalue ratio to anisotropy parameters using gamma
    # Example for Ward: u_w, v_w derived from lambda1, lambda2, gamma
    # Example for Lafortune: u_l, v_l derived similarly
    
    # 7. Rendering
    N_sigma_t = -normalize(gradient_sigma_t(sigma_t, x))
    ks = length(gradient_sigma_t(sigma_t, x))
    if ks == 0:
        return diffuse_shading(x, s, l, v)
        
    H = normalize(l + v)
    # Compute specular term using anisotropic BRDF (e.g., Lafortune)
    # fs = f_anisotropic(N_sigma_t, H, U, V, u_l, v_l, kappa)
    # L = ks * fs * max(0, dot(l, N_sigma_t)) + diffuse_term
    return compute_radiance(N_sigma_t, H, U, V, ks, kappa, gamma)
```

## Operating characteristics
*   **Complexity:** Precomputation of normals is $O(N)$. Per-voxel anisotropy estimation is $O(n)$ where $n$ is sample count. Rendering is $O(N \cdot n)$ if computed per pixel/voxel, or $O(N)$ if precomputed.
*   **Performance:** Precomputation takes ~985 ms (vs 465 ms for curvature-based). Memory usage is ~44.9 MB (vs 67.4 MB for curvature-based) due to storing $2 \times 2$ vs $3 \times 3$ matrices. Rendering speed is ~81 fps (vs 69 fps) [S1].
*   **Strengths:** Data-driven, independent of transfer function (can be precomputed). Enhances perception of tubular/linear structures. Reduces aliasing with large radius [S1].
*   **Limitations:** Sensitive to parameter choice ($r, \varepsilon, n$). Small $r$ or low $n$ causes noise/artifacts. Large $\varepsilon$ includes irrelevant features [S1].
*   **When to use:** When visualizing anisotropic structures (vortices, fibers, edges) in scalar volumes.
*   **When not to use:** For isotropic features or when performance is critical and precomputation is not feasible.

## Background
*   **Origin:** Proposed by Marco Ament and Carsten Dachsbacher [S1].
*   **Publication:** IEEE Transactions on Visualization and Computer Graphics, 2015 [S1]. Also presented in IEEE SciVis 2015 [S2, unofficial].
*   **Context:** Extends local illumination models for volume rendering by incorporating anisotropic BRDFs derived from scalar field geometry, addressing limitations of isotropic Blinn-Phong shading [S1].
