# Simplified Phong Lighting Model

Also called: Phong Illumination, Phong Illumination Model, Phong Lighting Model, Phong Reflection Model, Simplified Phong Shading

## Overview
The Simplified Phong Lighting Model is a local illumination technique used in volume rendering to calculate diffuse and specular contributions based on data values and estimated surface normals [S2, S3, S4, S5, S6, S7, S8, S9, S11, unofficial]. It solves the problem of adding visual depth and material appearance to volume data by modulating the existing pixel color or raymarched geometry with ambient, diffuse, and specular terms [S2, S3, S4, S11, S12, unofficial]. Unlike physically based global illumination methods, it is an empirical approximation that ignores occlusion, interreflection, and complex light transport, relying solely on local surface properties and light source parameters [S2, S7, S8, S11, unofficial]. It is distinguished from its sibling [Blinn-Phong Shading Model](2239-blinn-phong-shading-model.md) by using the explicit reflection vector $R$ rather than the halfway vector $H$ for the specular calculation [S7, S11, unofficial].

## How it works
**Inputs and Outputs:**
*   **Inputs:**
    *   Volume data or Signed Distance Function (SDF) defining the geometry [S2, S11, unofficial].
    *   Camera position (eye) and view direction [S7, S11, unofficial].
    *   Light position(s) and light intensity/color [S7, S11, unofficial].
    *   Material coefficients: ambient ($k_a$), diffuse ($k_d$), specular ($k_s$), and shininess ($n$ or $\alpha$) [S5, S11, unofficial].
    *   Ambient light color/intensity [S7, S11, unofficial].
*   **Outputs:**
    *   Final pixel color (RGB) [S3, S11, unofficial].

**Data Structures:**
*   **Volume/SDF:** A 3D grid of values or a function $f(x,y,z)$ returning distance to surface [S2, S11, unofficial].
*   **Normal Vector ($N$):** A 3D vector estimated from the gradient of the volume data or SDF [S2, S7, S11, unofficial].
*   **Light Vector ($L$):** Direction from surface point to light source [S7, S11, unofficial].
*   **View Vector ($V$):** Direction from surface point to eye [S7, S11, unofficial].
*   **Reflection Vector ($R$):** Direction of perfect reflection of light about the normal [S5, S7, S11, unofficial].

**Numbered Steps:**

1.  **Ray Marching / Sampling:** Iterate along the view ray to find a surface point $p$ or sample the volume [S2, S4, S11, unofficial]. If using a volume gradient, compute the gradient $\Delta f$ at the current voxel coordinates [S2, unofficial]. If using an SDF, estimate the normal $N$ at point $p$ using finite differences [S7, S11, unofficial]:
    $$ N = \text{normalize} \left( \begin{bmatrix} f(p + \epsilon_x) - f(p - \epsilon_x) \\ f(p + \epsilon_y) - f(p - \epsilon_y) \\ f(p + \epsilon_z) - f(p - \epsilon_z) \end{bmatrix} \right) $$
    where $\epsilon$ is a small epsilon value (e.g., 0.0001 or 0.0005) [S7, S8, S11, unofficial]. If using a volume gradient, normalize the gradient vector to get $N$ [S2, unofficial].

2.  **Compute Vectors:**
    *   Calculate the light direction vector $L$:
        $$ L = \text{normalize}(lightPos - p) $$ [S7, S11, unofficial].
    *   Calculate the view direction vector $V$:
        $$ V = \text{normalize}(eye - p) $$ [S7, S11, unofficial].
    *   Calculate the reflection vector $R$ by reflecting $-L$ about $N$:
        $$ R = \text{normalize}(reflect(-L, N)) $$ [S5, S7, S11, unofficial].
        *Note: Some implementations use the half-vector $H = \text{normalize}(V + L)$ for specular, which is Blinn-Phong, but the standard Simplified Phong model uses $R$ [S7, S11, unofficial].*

3.  **Calculate Dot Products:**
    *   Compute $dotLN = \text{dot}(L, N)$ [S9, S11, unofficial].
    *   Compute $dotRV = \text{dot}(R, V)$ [S9, S11, unofficial].

4.  **Apply Lighting Components:**
    *   **Ambient:** Initialize color with ambient term:
        $$ C_{ambient} = k_a \times ambientLight $$ [S3, S11, unofficial].
        *Typical values:* $ambientLight$ is often a constant gray, e.g., $0.5 \times (1,1,1)$ or $0.025 \times (0.8, 0.8, 0.8)$ [S7, S11, unofficial].
    *   **Diffuse:** If $dotLN > 0$, add diffuse contribution:
        $$ C_{diffuse} = k_d \times \max(dotLN, 0.0) \times lightIntensity $$ [S11, unofficial].
        *Note:* Some implementations clamp $dotLN$ to $[0, 1]$ explicitly [S5, S8, unofficial]. If $dotLN < 0$, the point is facing away from the light, and diffuse contribution is 0 [S9, S11, unofficial].
    *   **Specular:** If $dotRV > 0$, add specular contribution:
        $$ C_{specular} = k_s \times \max(dotRV, 0.0)^n \times lightIntensity $$ [S11, unofficial].
        *Note:* If $dotRV < 0$, the reflection vector is pointing away from the viewer. Some implementations return only the diffuse component in this case, while others set specular to 0 [S7, S11, unofficial].
        *Typical values:* Shininess $n$ (or $\alpha$) controls highlight sharpness, e.g., 10.0 to 60.0 [S8, S11, unofficial].

5.  **Combine and Output:**
    *   Sum the components:
        $$ C_{final} = C_{ambient} + C_{diffuse} + C_{specular} $$ [S10, S11, unofficial].
    *   Apply gamma correction if required:
        $$ C_{out} = C_{final}^{(1/2.2)} $$ [S8, S11, unofficial].

**Pseudocode:**

```python
def simplified_phong_lighting(p, eye, light_pos, light_intensity, k_a, k_d, k_s, shininess, ambient_light_color, estimate_normal_func):
    """
    Calculates the simplified Phong lighting contribution for a single point.
    
    Args:
        p (vec3): Position of the point on the surface.
        eye (vec3): Position of the camera.
        light_pos (vec3): Position of the light source.
        light_intensity (vec3): Color/intensity of the light.
        k_a (vec3): Ambient reflection coefficient.
        k_d (vec3): Diffuse reflection coefficient.
        k_s (vec3): Specular reflection coefficient.
        shininess (float): Shininess exponent (n).
        ambient_light_color (vec3): Color of the ambient light.
        estimate_normal_func (function): Function to estimate normal at point p.
        
    Returns:
        vec3: Final color contribution.
    """
    # Step 1: Estimate Normal
    N = estimate_normal_func(p)
    
    # Step 2: Compute Vectors
    L = normalize(light_pos - p)
    V = normalize(eye - p)
    R = normalize(reflect(-L, N))
    
    # Step 3: Calculate Dot Products
    dotLN = dot(L, N)
    dotRV = dot(R, V)
    
    # Step 4: Apply Lighting Components
    
    # Ambient
    color = k_a * ambient_light_color
    
    # Diffuse
    if dotLN > 0.0:
        diffuse_factor = max(dotLN, 0.0)
        color += k_d * diffuse_factor * light_intensity
    else:
        # Light is behind the surface
        return color # Return only ambient if no diffuse/specular
    
    # Specular
    if dotRV > 0.0:
        specular_factor = pow(max(dotRV, 0.0), shininess)
        color += k_s * specular_factor * light_intensity
    else:
        # Reflection vector points away from viewer
        # Some implementations return only diffuse here, but standard is to add 0 specular
        pass
        
    return color

def estimate_normal_sdf(p, sdf_func, epsilon=0.0001):
    """
    Estimates the normal at point p using finite differences of an SDF.
    """
    grad_x = sdf_func(p + vec3(epsilon, 0.0, 0.0)) - sdf_func(p - vec3(epsilon, 0.0, 0.0))
    grad_y = sdf_func(p + vec3(0.0, epsilon, 0.0)) - sdf_func(p - vec3(0.0, epsilon, 0.0))
    grad_z = sdf_func(p + vec3(0.0, 0.0, epsilon)) - sdf_func(p - vec3(0.0, 0.0, epsilon))
    return normalize(vec3(grad_x, grad_y, grad_z))
```

**Parameters with Typical Values:**
*   $k_a$: Ambient coefficient, e.g., $(0.2, 0.2, 0.2)$ [S11, unofficial].
*   $k_d$: Diffuse coefficient, e.g., $(0.7, 0.2, 0.2)$ [S11, unofficial].
*   $k_s$: Specular coefficient, e.g., $(1.0, 1.0, 1.0)$ [S11, unofficial].
*   $n$ (shininess): e.g., 10.0 to 60.0 [S8, S11, unofficial].
*   $ambientLight$: e.g., $0.5 \times (1,1,1)$ or $0.025 \times (0.8, 0.8, 0.8)$ [S7, S11, unofficial].
*   $lightIntensity$: e.g., $(0.2, 0.4, 0.4)$ or $(0.8, 0.8, 0.8)$ [S7, S11, unofficial].

**Edge Cases and Pitfalls:**
*   **Back-facing surfaces:** If $dotLN < 0$, the light is behind the surface relative to the normal. The diffuse and specular contributions should be zero [S9, S11, unofficial].
*   **Reflection vector direction:** If $dotRV < 0$, the reflection vector points away from the viewer. Specular contribution should be zero [S7, S11, unofficial].
*   **Gradient estimation:** Using finite differences for normal estimation can be noisy if the volume data or SDF is not smooth. Small epsilon values are required [S7, S8, S11, unofficial].
*   **Occlusion:** The simplified model does not account for shadows or occlusion. Self-shadowing is expensive and rarely crucial for volume visualization, so it is often ignored [S1, unofficial].
*   **Ambient term deviation:** Some implementations use a normalized color difference for the ambient term instead of a constant scalar, which deviates from the standard Phong model [S5, unofficial].

## Subtopics

### [Specular Reflections via Polynomial Expansion](1172-specular-reflections-via-polynomial-expansion.md)
Extends the Fourier Projection-Slice volume rendering framework to handle specular highlights by analytically expanding the Phong specular term into a polynomial. Solves the problem of rendering shiny surfaces in participating media without recursive overhead. Uses precomputed spectra and linear combination of Fourier projections.

### [Phong Shading Model for Volume Data](1353-phong-shading-model-for-volume-data.md)
Renders 3D volume data by mapping it to textures and projecting polygonal planes, computing Phong illumination in a fragment shader. Trades physical accuracy for interactive performance on older hardware using hardware-accelerated texture lookups.

### [Phong Shading](1853-phong-shading.md)
The standard local illumination model summing ambient, diffuse, and specular components. Distinguished from Blinn-Phong by using the explicit reflection vector $R$.

### [Blinn-Phong Shading Model](2239-blinn-phong-shading-model.md)
Approximates reflected light using a cosine-power lobe based on the half-vector between light and view directions. Ignores indirect light and shadows.

### [Blinn-Phong Lighting with Depth Cueing](2448-blinn-phong-lighting-with-depth-cueing.md)
Computes per-voxel illumination using Blinn-Phong and applies depth cueing to enhance perception of volume density and depth.

### [Non-Lambertian Rendering of Spherical Harmonics](4373-non-lambertian-rendering-of-spherical-harmonics.md)
Renders non-Lambertian surfaces by approximating the Phong shading model using Spherical Harmonic (SH) lighting representations. Replaces explicit light source summation with SH domain operations.

### Final Illumination and Texture Mapping
*   Utilizes built-in trilinear texture interpolation to smoothly reconstruct normal vectors from attribute maps [S13, unofficial].
*   Uses reconstructed normals for Phong shading [S13, unofficial].
*   Implements reflection and refraction using cube mapping with continuous per-fragment correct normals [S13, unofficial].
*   Sums contributions from lighting, texture mapping, reflectance mapping, and refraction mapping to set the final fragment color [S13, unofficial].

## Operating characteristics
*   **Time Complexity:** $O(1)$ per surface point per light source, assuming normal estimation is $O(1)$ (e.g., via SDF gradient or precomputed texture lookup) [S11, S13, unofficial]. For volume ray marching, the cost is proportional to the number of samples along the ray [S2, S11, unofficial].
*   **Memory Complexity:** $O(1)$ additional memory per point for vectors and scalars, plus storage for the volume data or SDF [S2, S11, unofficial].
*   **Measured Performance:** Interactive performance is achievable on older hardware when using texture-based normal lookups [S3, S13, unofficial]. Ray marching with SDFs can be slower depending on the complexity of the SDF and the number of steps required [S11, unofficial].
*   **Scaling:** Scales linearly with the number of light sources [S11, unofficial].
*   **Strengths:** Simple to implement, computationally efficient, provides good visual cues for shape and material [S2, S3, S11, unofficial].
*   **Limitations:** Does not account for shadows, occlusion, or global illumination effects [S1, S2, S7, S8, S11, unofficial]. Can appear unrealistic for complex lighting scenarios.
*   **When to use:** When visual clarity and performance are prioritized over physical accuracy, especially in real-time volume visualization or non-photorealistic rendering [S1, S3, S11, unofficial].
*   **When not to use:** When physically accurate lighting, shadows, or complex light transport effects are required [S1, S7, S11, unofficial].

## Background
The Phong reflection model was introduced by Bui Tuong Phong in 1975 [S1, S2, S7, S11, unofficial]. It is an empirical model widely used in computer graphics for shading surfaces [S1, S2, S7, S11, unofficial]. In the context of volume rendering, it has been adapted to work with volume data by estimating normals from gradients or SDFs [S2, S7, S11, unofficial]. It is commonly used in non-photorealistic rendering (NPR) techniques to enhance visual appearance [S1, unofficial].
