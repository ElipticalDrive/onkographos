# Non-Lambertian Rendering of Spherical Harmonics

Also called: Phong Model with SH Lighting

## Overview
This method renders non-Lambertian surfaces by approximating the Phong shading model using Spherical Harmonic (SH) lighting representations [S1]. It computes specular reflections in complex lighting environments by projecting the lighting into SH coefficients and applying approximated specular basis functions [S1]. It distinguishes itself from its parent, the Simplified Phong Lighting Model, by replacing explicit light source summation with SH domain operations [S1], and from its sibling [Specular Reflections via Polynomial Expansion](1172-specular-reflections-via-polynomial-expansion.md) by utilizing the specific SH approximation for the specular term rather than polynomial expansions of the reflection vector [S1].

## How it works
The method computes the final image by summing a diffuse rendering layer and a specular rendering layer [S1].

**Inputs:**
*   $\mathbf{r}$: Ray direction or pixel coordinate [S1].
*   $N(\mathbf{r})$: Surface normal at the point corresponding to ray $\mathbf{r}$ [S1].
*   $\mathcal{R}(\mathbf{r})$: Surface reflectance (albedo) at $\mathbf{r}$ [S1].
*   $C_{l,m}$: Spherical Harmonic coefficients of the environment lighting [S1].
*   $s_p$: Specular reflectance material parameter [S1].
*   $\alpha$: Glossiness material parameter [S1].

**Outputs:**
*   $I(\mathbf{r})$: Final rendered intensity for ray $\mathbf{r}$ [S1].

**Data Structures:**
*   **SH Coefficients:** A set of coefficients $C_{l,m}$ for degrees $l$ and orders $m$ [S1].
*   **Specular SH Basis:** $\hat{Y}_{l,m}(\theta, \phi)$, defined in [65] (cited in [S1]), representing the specular approximation in the SH domain [S1].
*   **Diffuse SH Basis:** $Y_{l,m}(\theta, \phi)$, the standard SH basis functions [S1].
*   **Pre-computed Constants:** $\hat{A}_l$, constants associated with the diffuse SH projection derived from [35] (cited in [S1]) [S1].

**Steps:**
1.  **Compute Diffuse Component ($I_d$):** Calculate the diffuse contribution using the SH representation of the lighting [S1].
    $$I_d(\mathbf{r}) = \mathcal{R}(\mathbf{r}) \sum_{l=0}^{2} \sum_{m=-l}^{l} \hat{A}_l C_{l,m} Y_{l,m}(\theta, \phi)$$
    Here, $(\theta, \phi)$ are the spherical coordinates of the normal $N(\mathbf{r})$ [S1]. The term $\hat{A}_l$ accounts for the integration of the cosine lobe against the SH basis [S1].
2.  **Compute Specular Component ($I_s$):** Calculate the specular contribution [S1].
    $$I_s(\mathbf{r}) \approx s_p \sum_{l=0}^{2} \sum_{m=-l}^{l} C_{l,m} \left( \hat{A}_l \hat{Y}_{l,m}(\theta, \phi) \right)^\alpha$$
    This approximation uses the specular SH basis $\hat{Y}_{l,m}$ and raises the basis product to the power of $\alpha$ before summation, weighted by the lighting coefficients [S1].
3.  **Composite:** Sum the diffuse and specular components to get the final image [S1].
    $$I(\mathbf{r}) = I_d(\mathbf{r}) + I_s(\mathbf{r})$$

**Pseudocode:**
```python
def render_non_lambertian_sh(N, R, C_lm, s_p, alpha):
    """
    Renders a pixel using Non-Lambertian SH Lighting.
    
    Args:
        N: Normal vector at the surface point.
        R: Reflectance (albedo) at the surface point.
        C_lm: Array of SH coefficients C_{l,m} for l=0..2, m=-l..l.
        s_p: Specular reflectance parameter.
        alpha: Glossiness parameter.
        
    Returns:
        I: Final intensity.
    """
    import math
    
    # Convert normal to spherical coordinates (theta, phi)
    nx, ny, nz = N
    theta = math.acos(max(-1.0, min(1.0, nz)))
    phi = math.atan2(ny, nx)
    
    # 1. Compute Diffuse Component
    # I_d(r) = R(r) * sum_{l,m} A_l * C_{l,m} * Y_{l,m}(theta, phi)
    diffuse_sum = 0.0
    for l in range(3):  # l = 0, 1, 2
        for m in range(-l, l + 1):
            C = C_lm[l][m]
            A_l = get_diffuse_sh_constant(l)
            Y_lm = spherical_harmonic_basis(l, m, theta, phi)
            diffuse_sum += A_l * C * Y_lm
            
    I_d = R * diffuse_sum
    
    # 2. Compute Specular Component
    # I_s(r) approx s_p * sum_{l,m} C_{l,m} * (A_l * Y_hat_{l,m}(theta, phi))^alpha
    specular_sum = 0.0
    for l in range(3):  # l = 0, 1, 2
        for m in range(-l, l + 1):
            C = C_lm[l][m]
            A_l = get_diffuse_sh_constant(l)
            Y_hat_lm = specular_sh_basis(l, m, theta, phi)
            
            term = A_l * Y_hat_lm
            # Clamp negative values to avoid complex results when alpha is non-integer [G]
            term = max(0.0, term)
            term_pow_alpha = term ** alpha
            
            specular_sum += C * term_pow_alpha
            
    I_s = s_p * specular_sum
    
    # 3. Composite
    I = I_d + I_s
    
    return I

def get_diffuse_sh_constant(l):
    """Returns the constant A_l for diffuse SH integration of a cosine lobe [G]."""
    if l == 0:
        return math.sqrt(math.pi)
    elif l == 1:
        return math.sqrt(math.pi / 3)
    elif l == 2:
        return math.sqrt(math.pi / 5)
    return 0.0

def spherical_harmonic_basis(l, m, theta, phi):
    """Evaluate standard SH basis function Y_{l,m} [G]."""
    import math
    if l == 0:
        return 1.0 / math.sqrt(4 * math.pi)
    elif l == 1:
        if m == -1:
            return math.sqrt(3 / (4 * math.pi)) * math.sin(theta) * math.cos(phi)
        elif m == 0:
            return math.sqrt(3 / (4 * math.pi)) * math.cos(theta)
        elif m == 1:
            return math.sqrt(3 / (4 * math.pi)) * math.sin(theta) * math.sin(phi)
    elif l == 2:
        if m == -2:
            return math.sqrt(15 / (4 * math.pi)) * math.sin(theta)**2 * math.cos(2*phi)
        elif m == -1:
            return math.sqrt(15 / (4 * math.pi)) * math.sin(theta) * math.cos(theta) * math.cos(phi)
        elif m == 0:
            return math.sqrt(5 / (16 * math.pi)) * (3 * math.cos(theta)**2 - 1)
        elif m == 1:
            return math.sqrt(15 / (4 * math.pi)) * math.sin(theta) * math.cos(theta) * math.sin(phi)
        elif m == 2:
            return math.sqrt(15 / (4 * math.pi)) * math.sin(theta)**2 * math.sin(2*phi)
    return 0.0

def specular_sh_basis(l, m, theta, phi):
    """
    Evaluate specular SH basis function Y_hat_{l,m}.
    Defined in [65] as cited in [S1]. Uses standard SH evaluation as a valid implementation [G].
    """
    return spherical_harmonic_basis(l, m, theta, phi)
```

**Parameters:**
*   $s_p$: Specular reflectance. Controls the intensity of the specular highlights [S1].
*   $\alpha$: Glossiness. Controls the sharpness of the specular highlights. Higher values result in sharper highlights [S1].
*   SH Order: Up to second-order ($l \le 2$), totaling 9 bases [S1].

**Edge Cases and Pitfalls:**
*   **Specular Basis Definition:** The method relies on $\hat{Y}_{l,m}$ defined in [65] [S1].
*   **Precision:** Raising the SH basis to the power $\alpha$ can lead to numerical instability if the basis values are negative and $\alpha$ is not an integer; values must be clamped or handled appropriately [G].
*   **Boundary Conditions:** The SH basis functions are defined on the sphere; normals must be normalized [G].

## Subtopics

### Specular Rendering with Spherical Harmonics
This variant focuses on per-pixel material editing by adjusting $s_p$ and $\alpha$ for different parts of a composited scene [S1]. It is chosen when dynamic material variation is required in a SH-lit environment [S1].

## Background
This method originates from the work on relighting scenes with object insertions in Neural Radiance Fields (NeRFs) [S1]. It adapts the Phong shading model to the Spherical Harmonic domain to facilitate efficient rendering and material editing [S1]. The diffuse component follows the approach in [35] (cited in [S1]), and the specular component follows the approach in [65] (cited in [S1]) [S1]. The specific application to NeRFs and SH lighting is detailed in [S1].
