# Two-sided Lighting
Also called: Two-sided Directional Lighting
## Overview
Two-sided lighting is a shading mode for surface displays that illuminates both the front and back faces of a surface geometry, rather than restricting illumination to the exterior [S1, S2]. It differs from standard one-sided lighting by treating the specified light direction $\mathbf{l}$ and its opposite $-\mathbf{l}$ as active sources, allowing the interior or back-facing surfaces of a volume boundary to receive direct illumination [S2]. The method builds on [Lighting Models](2056-lighting-models.md).
## How it works
**Inputs and Outputs:**
*   **Input:** Surface geometry defined by a volume threshold or mesh; light direction vector $\mathbf{l}$; light color $\mathbf{c}_{light}$; material properties (ambient $\mathbf{c}_{amb}$, diffuse $\mathbf{c}_{diff}$); viewing direction $\mathbf{v}$ (implicit in brightness calculation) [S1, S2].
*   **Output:** Final pixel color for surface points, combining ambient and diffuse contributions from both light directions [S1, S2].

**Data Structures:**
The implementation relies on a rendering context storing light states [S2]. Key constants include `VP_LIGHT0` through `VP_LIGHT5` for light identifiers, and `VP_LIGHT_BOTH_SIDES` as a flag for the enable state [S2]. Material properties are stored per material index (`VP_MATERIAL0`–`VP_MATERIAL5`) with separate coefficients for ambient and diffuse reflection [S2].

**Steps:**
1.  **Configure Light Color:** Set the RGB components of the light color $\mathbf{c}_{light}$ using `vpSetLight` with property `VP_COLOR`. Values must be in the range $[0.0, 1.0]$ [S2].
2.  **Configure Light Direction:** Set the direction vector $\mathbf{l} = (l_x, l_y, l_z)$ using `vpSetLight` with property `VP_DIRECTION`. This vector is transformed by the current modeling matrix before storage [S2].
3.  **Enable Light:** Call `vpEnable` with the light identifier (e.g., `VP_LIGHT1`) and a value of 1 to activate it. Light 0 is enabled by default; others are disabled [S2].
4.  **Enable Two-Sided Mode:** Call `vpEnable` with the light identifier and the `VP_LIGHT_BOTH_SIDES` option. This instructs the renderer to treat the light as bidirectional [S2].
5.  **Evaluate Illumination:** For each surface point $\mathbf{p}$ with normal $\mathbf{n}$:
    *   Calculate the angle between the normal $\mathbf{n}$ and the line of sight. Brightness is maximal when $\mathbf{n}$ is parallel to the line of sight [S1].
    *   Compute diffuse contribution from both $\mathbf{l}$ and $-\mathbf{l}$ [S2].
    *   Combine with ambient term defined by material parameters [G].

**Pseudocode:**
```python
def setup_two_sided_lighting(context, light_id, color_rgb, direction_xyz):
    # Set light color in range [0.0, 1.0] [S2]
    vpSetLight(context, light_id, VP_COLOR, color_rgb[0], color_rgb[1], color_rgb[2])
    # Set light direction; transformed by current modeling matrix before storage [S2]
    vpSetLight(context, light_id, VP_DIRECTION, direction_xyz[0], direction_xyz[1], direction_xyz[2])
    # Enable the light; light 0 is enabled by default, others disabled [S2]
    vpEnable(context, light_id, 1)
    # Enable two-sided mode so light shines in both specified and opposite directions [S2]
    vpEnable(context, light_id, VP_LIGHT_BOTH_SIDES)
    # Evaluation loop over surface points is not given in the sources.
```

**Formulas:**
The brightness varies according to the angle between the surface point normal and the line of sight [S1]. The exact shading equation is not given in the sources.

**Parameters:**
*   **Light Direction:** Transformed by the modeling matrix [S2].
*   **Color Range:** $[0.0, 1.0]$ for RGB components [S2].
*   **Light Count:** Supports up to 6 lights (`VP_LIGHT0`–`VP_LIGHT5`) [S2].

**Edge Cases and Pitfalls:**
*   **Normal Definition:** The definition of "outside" depends on the `flipNormals` setting [S1]. If `twoSidedLighting` is false, `flipNormals` determines which side is lit [S1]. When `twoSidedLighting` is true, both sides are lit regardless, but the normal orientation affects the dot product calculation [S1].
*   **Threshold Sign:** For volume data, the side treated as "outside" for negative thresholds is toward larger/more positive values, and for positive thresholds toward smaller/more negative values, if `flipNormals` is true [S1].
