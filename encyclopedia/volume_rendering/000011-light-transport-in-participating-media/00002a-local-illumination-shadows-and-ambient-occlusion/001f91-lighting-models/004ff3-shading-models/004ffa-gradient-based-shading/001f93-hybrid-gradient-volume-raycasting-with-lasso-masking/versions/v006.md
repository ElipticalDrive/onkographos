# Hybrid Gradient Volume Raycasting with Lasso Masking

Also called: Colored Raycast Volume Render, HU Direction + Opacity Threshold Lighting

## Overview
This method performs direct volume raycasting using pre-computed Hounsfield Unit (HU) gradients for lighting direction, applying Phong shading only when a significant opacity change is detected along the gradient vector [S1, unofficial]. It combines this hybrid lighting model with lasso-based voxel masking to selectively render regions of interest and cutting cube bounds to clip the volume [S1, unofficial]. It differs from standard Phong shading by decoupling the lighting direction from the local sample gradient, relying instead on global HU gradients, and by gating the lighting contribution based on opacity thresholds to prevent shading artifacts on smooth structures like vessels [S1, unofficial].

## How it works
**Inputs and Outputs**
*   **Inputs:** A 3D volume texture array of scalar density values (HU), a 1D Color Transfer Function (CTF) texture, a 3D lasso mask texture, and camera/model matrices [S1, unofficial].
*   **Outputs:** A final RGBA color for each pixel [S1, unofficial].

**Data Structures**
The method uses a `Uniforms` struct passed to the shader [S1, unofficial]. The layout is fixed as follows [S1, unofficial]:
*   `modelMatrix`: `mat4x4<f32>`
*   `viewMatrix`: `mat4x4<f32>`
*   `projectionMatrix`: `mat4x4<f32>`
*   `cameraPosition`: `vec3<f32>`
*   `_padding0`: `f32`
*   `numSlices`: `f32`
*   `stepSize`: `f32`
*   `densityScale`: `f32`
*   `_padding1`: `f32`
*   `inverseModelMatrix`: `mat4x4<f32>`
*   `_padding2` to `_padding5`: `f32` (padding) [S1, unofficial]
*   `voxelSpacing`: `vec3<f32>`
*   `_padding6`: `f32`
*   `toggleGradient`: `u32` (0 or non-zero)
*   `volumeWidth`, `volumeHeight`, `volumeDepth`: `u32` (Dimensions of the volume texture) [S1, unofficial]
*   `xmin`, `xmax`, `ymin`, `ymax`, `zmin`, `zmax`: `f32` (Cutting cube bounds) [S1, unofficial]

Texture bindings [S1, unofficial]:
*   `@binding(0)`: `uniforms` (`Uniforms`)
*   `@binding(1)`: `volumeTexture` (`texture_2d_array<f32>`)
*   `@binding(2)`: `volumeSampler` (`sampler`)
*   `@binding(3)`: `gradientTexture` (`texture_2d_array<f32>`)
*   `@binding(4)`: `ctfTexture` (`texture_1d<f32>`)
*   `@binding(5)`: `lassoMask` (`texture_3d<u32>`)

**Numbered Steps**

1.  **Vertex Shader:** Transform the input quad position to clip space using `projectionMatrix * viewMatrix * modelMatrix` [S1, unofficial]. Pass the world position and a zero ray direction to the fragment shader [S1, unofficial].
2.  **Fragment Shader Initialization:** Compute the camera position in cube space using the `inverseModelMatrix` [S1, unofficial]. Set the ray origin to the camera position [S1, unofficial]. Compute the ray direction by normalizing `(worldPosition - cameraPosition)` and scaling by `voxelSpacing` [S1, unofficial].
3.  **Ray-Box Intersection:** Define the box bounds: `boxMin = vec3(-1.0/voxelSpacing.x, -1.0/voxelSpacing.y, -1.0/voxelSpacing.z)` and `boxMax = vec3(1.0/voxelSpacing.x, 1.0/voxelSpacing.y, 1.0/voxelSpacing.z)` [S1, unofficial]. Intersect the ray with this box to find `tNear` and `tFar` [S1, unofficial]. Discard the pixel if `tNear >= tFar` or `tFar <= 0` [S1, unofficial].
4.  **Jitter:** Compute a jitter value to reduce banding:
    $$ \text{jitter} = \text{fract}(\sin(\text{dot}(\text{clipPosition.xy}, \text{vec2}(12.9898, 78.233))) \times 43758.5453) \times \text{stepSize} $$ [S1, unofficial].
5.  **Ray Marching Loop:**
    a. Initialize `accumulatedColor = vec3(0.0)`, `accumulatedAlpha = 0.0`, `t = tNear + jitter`, and `stepCount = 0` [S1, unofficial].
    b. While `accumulatedAlpha < 0.95` and `t < tFar`:
        i. **Position Conversion:**
           $$ \text{scaledPos} = \text{rayOrigin} + \text{rayDir} \times t $$
           $$ \text{pos} = \text{scaledPos} \times \text{voxelSpacing} \times 0.5 + \text{vec3}(0.5) $$
           This converts from cube space `[-1, 1]` to texture space `[0, 1]` [S1, unofficial].
        ii. **Texture Bounds Check:** If `pos.x`, `pos.y`, or `pos.z` is outside `[0, 1]`, break the loop [S1, unofficial].
        iii. **Lasso Mask Check:** Compute voxel coordinates:
             $$ \text{voxelCoord} = (\lfloor \text{pos.x} \times (\text{volumeWidth}-1) \rfloor, \lfloor \text{pos.y} \times (\text{volumeHeight}-1) \rfloor, \lfloor \text{pos.z} \times (\text{volumeDepth}-1) \rfloor) $$
             Load `maskValue` from `lassoMask` at `voxelCoord` [S1, unofficial]. If `maskValue == 0`, increment `t` by `stepSize` and `stepCount`, then `continue` to the next iteration [S1, unofficial].
        iv. **Volume Sampling:** Sample the density using `sampleVolumeFast(pos)` [S1, unofficial]. This function performs trilinear interpolation across the 2D texture array slices [S1, unofficial].
        v. **CTF Evaluation:** Normalize the density to the HU range `[-1024.0, 3071.0]`:
             $$ \text{normalized} = \text{clamp}\left(\frac{\text{density} - (-1024.0)}{3071.0 - (-1024.0)}, 0.0, 1.0\right) $$
             Map to texture index:
             $$ \text{texelIndex} = \lfloor \text{normalized} \times 255.0 \rfloor $$
             Load `ctfColor` and `sampleAlpha` from `ctfTexture` at `texelIndex` [S1, unofficial].
        vi. **Alpha Threshold:** If `sampleAlpha <= 0.001`, skip lighting and accumulation. Increment `t` by `stepSize` and `stepCount`, then `continue` [S1, unofficial].
        vii. **Alpha Normalization:**
             $$ \alpha = \text{sampleAlpha} \times \frac{\text{stepSize}}{0.006} $$
             $$ \alpha = \text{clamp}(\alpha, 0.0, 1.0) $$ [S1, unofficial].
        viii. **Lighting Calculation (Hybrid Gradient):** If `toggleGradient` is non-zero: Sample the pre-computed gradient from `gradientTexture` at `pos` [S1, unofficial]. Normalize the gradient to get the normal $\mathbf{n}$ [G]. Compute the Phong lighting term $L(\mathbf{p})$ using the standard model (ambient, diffuse, specular) with the view vector $\mathbf{v}$ and light vector $\mathbf{l}$ [G]. **Opacity Threshold Check:** Calculate the opacity change along the gradient direction. If the opacity change is $\le 0.15$, set $L(\mathbf{p}) = 1.0$ (no shading). Otherwise, use the computed Phong lighting. This prevents shading on smooth vessels [S1, unofficial]. If `toggleGradient` is zero, set $L(\mathbf{p}) = 1.0$ [S1, unofficial].
        ix. **Accumulation:**
             $$ \text{weight} = \alpha \times (1.0 - \text{accumulatedAlpha}) $$
             $$ \text{accumulatedColor} += \text{ctfColor.rgb} \times L(\mathbf{p}) \times \text{weight} $$
             $$ \text{accumulatedAlpha} += \text{weight} $$
             If `accumulatedAlpha >= 0.95`, break loop [S1, unofficial].
        x. **Increment:** $t += \text{stepSize}$, $\text{stepCount} += 1$ [S1, unofficial].
6.  **Post-Processing:** If `accumulatedAlpha < 0.1`, add a subtle ambient gray color to mask numerical errors:
    $$ \text{accumulatedColor} += \text{vec3}(0.02) \times (0.1 - \text{accumulatedAlpha}) $$ [S1, unofficial].
7.  **Return:** Return `vec4(accumulatedColor, accumulatedAlpha)` [S1, unofficial].

**Pseudocode**

```python
def sample_volume_fast(pos, volume_texture, volume_sampler, num_slices):
    coords = clamp(pos, vec3(0.0), vec3(1.0))
    z = coords.z * (num_slices - 1.0)
    z0 = floor(z)
    z1 = min(z0 + 1.0, num_slices - 1.0)
    z_frac = z - z0
    sample0 = texture_sample_level(volume_texture, volume_sampler, coords.xy, int(z0), 0.0)
    sample1 = texture_sample_level(volume_texture, volume_sampler, coords.xy, int(z1), 0.0)
    return mix(sample0.r, sample1.r, z_frac)

def evaluate_ctf(density, ctf_texture):
    min_hu = -1024.0
    max_hu = 3071.0
    normalized = clamp((density - min_hu) / (max_hu - min_hu), 0.0, 1.0)
    texel_index = int(normalized * 255.0)
    return texture_load(ctf_texture, texel_index, 0)

def intersect_ray_box(origin, direction, box_min, box_max):
    t_min = (box_min - origin) / direction
    t_max = (box_max - origin) / direction
    t1 = min(t_min, t_max)
    t2 = max(t_min, t_max)
    t_near = max(max(t1.x, t1.y), t1.z)
    t_far = min(min(t2.x, t2.y), t2.z)
    return t_near, t_far

def compute_phong_lighting(normal, light_dir, view_dir):
    ambient = vec3(0.1)
    diffuse = vec3(0.8) * max(dot(normal, light_dir), 0.0)
    reflect_dir = reflect(-light_dir, normal)
    spec = vec3(0.1) * pow(max(dot(view_dir, reflect_dir), 0.0), 32.0)
    return ambient + diffuse + spec

def fragment_main(world_pos, light_dir, view_dir):
    camera_pos = inverse_model_matrix * vec4(uniforms.cameraPosition, 1.0).xyz
    ray_dir = normalize(world_pos - camera_pos) * uniforms.voxel_spacing
    ray_origin = camera_pos

    box_min = vec3(-1.0 / uniforms.voxel_spacing.x, -1.0 / uniforms.voxel_spacing.y, -1.0 / uniforms.voxel_spacing.z)
    box_max = vec3(1.0 / uniforms.voxel_spacing.x, 1.0 / uniforms.voxel_spacing.y, 1.0 / uniforms.voxel_spacing.z)
    t_near, t_far = intersect_ray_box(ray_origin, ray_dir, box_min, box_max)

    if t_near >= t_far or t_far <= 0.0:
        return vec4(0.0, 0.0, 0.0, 0.0)

    jitter = fract(sin(dot(input.clip_position.xy, vec2(12.9898, 78.233))) * 43758.5453) * uniforms.step_size

    accumulated_color = vec3(0.0)
    accumulated_alpha = 0.0
    t = t_near + jitter
    step_count = 0

    while accumulated_alpha < 0.95 and t < t_far:
        scaled_pos = ray_origin + ray_dir * t
        pos = scaled_pos * uniforms.voxel_spacing * 0.5 + vec3(0.5)

        if pos.x < 0.0 or pos.x > 1.0 or pos.y < 0.0 or pos.y > 1.0 or pos.z < 0.0 or pos.z > 1.0:
            break

        voxel_coord = vec3(
            int(pos.x * (uniforms.volume_width - 1)),
            int(pos.y * (uniforms.volume_height - 1)),
            int(pos.z * (uniforms.volume_depth - 1))
        )
        mask_value = texture_load(lasso_mask, voxel_coord, 0)
        if mask_value == 0:
            t += uniforms.step_size
            step_count += 1
            continue

        density = sample_volume_fast(pos, volume_texture, volume_sampler, uniforms.num_slices)
        ctf_result = evaluate_ctf(density, ctf_texture)
        ctf_color = ctf_result.rgb
        sample_alpha = ctf_result.a

        if sample_alpha <= 0.001:
            t += uniforms.step_size
            step_count += 1
            continue

        alpha = sample_alpha * (uniforms.step_size / 0.006)
        alpha = clamp(alpha, 0.0, 1.0)

        lighting = 1.0
        if uniforms.toggle_gradient != 0:
            grad = texture_sample_level(gradient_texture, gradient_sampler, pos, 0, 0.0)
            normal = normalize(grad)
            lighting = compute_phong_lighting(normal, light_dir, view_dir)
            # Opacity change computation not provided in sources [G]
            opacity_change = 0.0
            if opacity_change <= 0.15:
                lighting = 1.0

        weight = alpha * (1.0 - accumulated_alpha)
        accumulated_color += ctf_color * lighting * weight
        accumulated_alpha += weight

        t += uniforms.step_size
        step_count += 1

    if accumulated_alpha < 0.1:
        accumulated_color += vec3(0.02) * (0.1 - accumulated_alpha)

    return vec4(accumulated_color, accumulated_alpha)
```

**Parameters**
*   `stepSize`: `f32` - Distance between samples along the ray [S1, unofficial].
*   `densityScale`: `f32` - Scaling factor for density values [S1, unofficial].
*   `voxelSpacing`: `vec3<f32>` - Physical spacing between voxels in world units [S1, unofficial].
*   `toggleGradient`: `u32` - Boolean flag (0 or non-zero) to enable/disable gradient-based lighting [S1, unofficial].
*   `volumeWidth`, `volumeHeight`, `volumeDepth`: `u32` - Dimensions of the volume texture [S1, unofficial].
*   `numSlices`: `f32` - Number of slices in the volume texture array [S1, unofficial].

**Edge Cases and Pitfalls**
*   **Numerical Errors:** Very transparent regions (`accumulatedAlpha < 0.1`) may show black dots due to `f16` numerical errors. This is mitigated by adding a subtle gray ambient color [S1, unofficial].
*   **Lasso Masking:** Voxels inside the lasso contour (`maskValue == 0`) are skipped, allowing selective rendering [S1, unofficial].
*   **Gradient Threshold:** Lighting is only applied if opacity change > 0.15. This prevents shading on smooth vessels but may reduce detail in low-contrast regions [S1, unofficial].

## Background
This method is designed for medical volume rendering, specifically leveraging Hounsfield Unit (HU) gradients for lighting [S1, unofficial]. The technique combines elements of direct volume raycasting, Phong shading, and lasso-based masking to provide an interactive and visually informative rendering experience [S1, unofficial].
