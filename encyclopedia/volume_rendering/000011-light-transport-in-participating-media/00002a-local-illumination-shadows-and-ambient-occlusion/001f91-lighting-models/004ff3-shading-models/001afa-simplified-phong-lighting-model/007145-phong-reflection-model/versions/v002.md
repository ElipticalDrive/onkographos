# Phong Reflection Model

Also called: Blinn-Phong shading, Phong Shading Model, Phong-like Shading Model, Shade Module Lighting

## Overview
The Phong Reflection Model describes how light is reflected from objects, defining the color of each pixel as the sum of ambient, diffuse, and specular components [S1, unofficial]. It calculates the amount and direction of light falling on an object's surface using normals, light sources, and the viewer's eye point [S2]. It builds on [Simplified Phong Lighting Model](885-simplified-phong-lighting-model.md) by explicitly separating the specular calculation into a Blinn-Phong half-vector formulation [S1, unofficial].

## How it works
**Inputs and Outputs**
*   **Inputs**: Surface normal $\mathbf{N}$ at the hit point; light direction vector $\mathbf{L}$ (from surface to light); view direction vector $\mathbf{V}$ (from surface to camera); light color/intensity $I_{light}$; ambient light color/intensity $I_{ambient}$; object diffuse color coefficient $k_d$; object specular color coefficient $k_s$; specular power/shininess $k$.
*   **Outputs**: Final ray color $C_{ray}$.

**Data Structures**
Not given in the sources.

**Numbered Steps**
1. Initialize the ray color with the ambient component: $C_{ray} = I_{ambient}$ [S1, unofficial].
2. Add the diffuse component using Lambert shading: multiply the object's diffuse color coefficient $k_d$, the light color $I_{light}$, the maximum of the dot product of the normal and light direction clamped to 0, and the diffuse coefficient [S1, unofficial].
3. Add the specular component using Blinn-Phong shading: multiply the specular coefficient $k_s$, the light color $I_{light}$, the maximum of the dot product of the normal and the normalized half-vector $\mathbf{H}$ raised to the specular power $k$, and the specular color coefficient [S1, unofficial].

**Formulas**
The total color is the sum of three components [S1, unofficial]:
$$ C_{ray} = C_{ambient} + C_{diffuse} + C_{specular} $$

Where:
1.  **Ambient Component**: $C_{ambient} = I_{ambient}$ [S1, unofficial].
2.  **Diffuse Component** (Lambertian reflection): $C_{diffuse} = k_d \cdot I_{light} \cdot \max(\mathbf{N} \cdot \mathbf{L}, 0)$ [S1, unofficial]. This represents light emanating from a direct source bouncing off the surface [S2].
3.  **Specular Component** (Blinn-Phong model): $C_{specular} = k_s \cdot I_{light} \cdot \max(\mathbf{N} \cdot \mathbf{H}, 0)^k$ [S1, unofficial]. Where $\mathbf{H}$ is the normalized half-vector: $\mathbf{H} = \text{normalize}(\mathbf{L} + \mathbf{V})$ [S1, unofficial]. This approximates the specular highlight [S2].

**Parameters**
*   $k_d$: Diffuse color coefficient. Represents the object's diffuse color [S1, unofficial].
*   $k_s$: Specular color coefficient. Represents the object's specular color coefficient [S1, unofficial].
*   $k$: Specular power (shininess). Controls the spread of the specular reflection; higher values produce sharper highlights, making surfaces appear more metallic or plastic [S2].
*   $I_{ambient}$: Ambient light intensity. Applied uniformly to all visible voxels [S1, unofficial]. It represents indirect light, a "glow" emanating from a non-point source that illuminates parts of objects facing away from point light sources [S2].
*   $I_{light}$: Light source color/intensity [S1, unofficial].

**Edge Cases and Pitfalls**
*   **Specular Highlights and Data Interpretation**: Specular highlights appear as bright white areas (assuming white incident light) [S2]. In volume rendering or scientific visualization where color maps represent data values, these bright spots can confuse viewers interpreting the color-mapped data [S2].
*   **Zero Specular**: Setting the specular coefficient to 0.0 eliminates specular reflection, resulting in a purely diffuse and ambient surface [S2].
*   **Vector Normalization**: The half-vector $\mathbf{H}$ must be normalized before the dot product with $\mathbf{N}$ to ensure correct intensity scaling [S1, unofficial].

**Pseudocode**
```python
def phong_reflection_model(N, L, V, I_ambient, I_light, k_d, k_s, k):
    """
    Calculate the reflected color using the Phong Reflection Model (Blinn-Phong specular).
    
    Args:
        N (vec3): Surface normal at the hit point.
        L (vec3): Direction from surface to light source.
        V (vec3): Direction from surface to viewer/camera.
        I_ambient (vec3): Ambient light color/intensity.
        I_light (vec3): Light source color/intensity.
        k_d (vec3): Diffuse color coefficient.
        k_s (vec3): Specular color coefficient.
        k (float): Specular power (shininess).
        
    Returns:
        vec3: Final color of the ray.
    """
    # 1. Initialize with ambient component
    # Ambient light is applied uniformly to all visible voxels [S1, unofficial]
    col_ray = I_ambient
    
    # 2. Add diffuse component (Lambert shading)
    # max(dot(N, L), 0) ensures no negative lighting (back-facing surfaces receive no direct diffuse light)
    dot_nl = max(dot(N, L), 0.0)
    col_ray += k_d * I_light * dot_nl
    
    # 3. Add specular component (Blinn-Phong shading)
    # Calculate half-vector H = normalize(L + V)
    H = normalize(L + V)
    
    # Calculate dot product of normal and half-vector
    dot_nh = max(dot(N, H), 0.0)
    
    # Raise to specular power k
    specular_term = dot_nh ** k
    
    # Add specular contribution
    col_ray += k_s * I_light * specular_term
    
    return col_ray
```

## Background
The specific implementation described in the sources uses the Blinn-Phong variation for the specular term, which uses the half-vector instead of the reflection vector, offering computational efficiency and smoother results [S1, unofficial]. It is widely used in visualization tools like Data Explorer, where it is implemented in the "Shade" module to control the appearance of volume data [S2].
