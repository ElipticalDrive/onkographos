# Phong Shading with Exponential Fog

Also called: Fragment Shader Lighting, Levoy - Shading, Phong Shading with Depth Cueing, Standard Lighting

## Overview
Phong Shading with Exponential Fog is a local illumination model that combines standard Phong lighting components with exponential depth cueing to simulate distance-based fading in volume rendering [S1, unofficial]. It extends [Phong Shading](1853-phong-shading.md) by integrating a distance-dependent attenuation factor into the final color calculation [S1, unofficial]. It differs from [Reflectance Map Shading](3606-reflectance-map-shading.md) by computing lighting dynamically per fragment rather than via precomputed textures [S2, unofficial].

## How it works
**Inputs:**
*   Surface normal vector $N$ (normalized) [S1, unofficial].
*   Fragment position in view space $P_{view}$ (or distance $d(x)$ to the picture plane) [S1, unofficial].
*   Light direction vector $L$ (normalized) [S1, unofficial].
*   Eye/View direction vector $V$ (normalized, pointing from fragment to eye) [G].
*   Material coefficients: ambient $k_a$, diffuse $k_d$, specular $k_s$, shininess $p$ [S1, unofficial].
*   Light color $C_p$ (parallel light source color) [S1, unofficial].
*   Fog parameters: fog density $k_1$ (or `FogDensity`), fog color $C_f$ [S2, unofficial].

**Outputs:**
*   Final fragment color $C(x)$ [S1, unofficial].

**Data Structures:**
The method operates on per-fragment data [S2, unofficial]. In a typical GPU implementation, the vertex shader outputs the following to the fragment shader [S2, unofficial]:
*   `Normal`: `vec3` (normalized surface normal in view space) [S2, unofficial].
*   `Position`: `vec4` (fragment position in view space) [S2, unofficial].
*   `viewSpace`: `vec4` (fragment position in view space, used for distance calculation) [S2, unofficial].

**Parameters:**
*   $k_a, k_d, k_s$: Ambient, diffuse, and specular light coefficients [S1, unofficial].
*   $p$: Shininess exponent for specular highlights [S1, unofficial].
*   $k_1$: Exponential fog density constant. Typical value: `0.01f` [S2, unofficial].
*   $C_f$: Fog color. Typical value: `vec3(0.0f, 0.3f, 0.6f)` [S2, unofficial].
*   $C_p$: Color of the parallel light source [S1, unofficial].
*   $k_2$: Quadratic fall-off constant for depth cueing [S1, unofficial].

**Steps:**
1.  **Calculate Ambient Component:** Compute the ambient contribution based on the light's ambient intensity and color [S2, unofficial].
    $$ C_{ambient} = C_p \cdot k_a $$
    [S2, unofficial] specifies `ambientColor = vec4(light.color, 1.0f) * light.ambientIntensity`.
2.  **Calculate Diffuse Component:** Compute the dot product between the normal $N$ and light direction $L$ [S1, unofficial].
    $$ N_{dot\_L} = \max(N \cdot L, 0.0) $$
    $$ C_{diffuse} = C_p \cdot k_d \cdot N_{dot\_L} $$
    [S2, unofficial] specifies `diffuseFactor = max(dot(normalize(Normal), normalize(direction)), 0.0f)` and `diffuseColor = vec4(light.color * light.diffuseIntensity * diffuseFactor, 1.0f)`.
3.  **Calculate Specular Component:** If $N_{dot\_L} > 0.0$, compute the specular highlight [S2, unofficial].
    a. Calculate the half-vector $H$ or the reflection vector [S1, unofficial]. The formula in [S1, unofficial] uses $H$ (normalized vector for maximum highlight direction). The pseudocode in [S2, unofficial] uses the reflection vector $R$ [S2, unofficial]. Both are valid approximations; the standard Phong model uses $H$ [G].
    $$ H = \text{normalize}(L + V) $$
    $$ H_{dot\_N} = \max(H \cdot N, 0.0) $$
    $$ C_{specular} = C_p \cdot k_s \cdot (H_{dot\_N})^p $$
    [S2, unofficial] uses the reflection vector approach: `reflectedVertex = normalize(reflect(direction, normalize(Normal)))`, `specularFactor = dot(fragToEye, reflectedVertex)`, and `specularFactor = pow(specularFactor, material.shininess)` if positive [S2, unofficial].
4.  **Combine Lighting:** Sum the components [S1, unofficial].
    $$ C_{lit} = C_{ambient} + C_{diffuse} + C_{specular} $$
    [S1, unofficial] formula: $C_p (k_a + k_d (N \cdot L) + k_s (N \cdot H)^p)$ [S1, unofficial].
5.  **Calculate Fog Factor:** Compute the distance $d(x)$ from the fragment to the picture plane (or camera) [S1, unofficial].
    $$ d(x) = \| P_{view} \| $$
    [S2, unofficial] specifies `dist = length(viewSpace)` [S2, unofficial].
    Compute the exponential fog factor [S1, unofficial]. The sources disagree on the fog function [S1, S2, unofficial]. [S1, unofficial] defines a double exponential $e^{-k_1 d(x)} e^{-k_2 d(x)^2}$, while [S2, unofficial] uses a single exponential $1.0 / \exp(dist \cdot \text{FogDensity})$ [S1, S2, unofficial].
    General form [S1, unofficial]:
    $$ F = e^{-k_1 d(x)} \cdot e^{-k_2 d(x)^2} $$
    Implementation form [S2, unofficial]:
    $$ F = \frac{1}{\exp(d(x) \cdot \text{FogDensity})} $$
    Clamp $F$ to $[0.0, 1.0]$ [S2, unofficial].
6.  **Apply Fog:** Mix the lit color with the fog color [S2, unofficial].
    $$ C(x) = C_{lit} \cdot F + C_f \cdot (1 - F) $$
    [S2, unofficial] specifies `color = mix(color*1.5f, vec4(fogColor, 1.0f), (1.0f - fogFactor))` [S2, unofficial]. Note the `color*1.5f` multiplier, which is a specific implementation detail in [S2, unofficial] not present in the general formula [S1, unofficial] [S2, unofficial].

**Pseudocode:**
```python
def phong_shading_with_exponential_fog(N, L, V, P_view, k_a, k_d, k_s, p, C_p, k_1, k_2, C_f):
    # 1. Ambient
    ambient = C_p * k_a
    
    # 2. Diffuse
    N_dot_L = max(dot(N, L), 0.0)
    diffuse = C_p * k_d * N_dot_L
    
    # 3. Specular
    # Using Half-Vector H as per standard Phong formula [S1, unofficial]
    H = normalize(L + V)
    H_dot_N = max(dot(H, N), 0.0)
    specular = C_p * k_s * pow(H_dot_N, p)
    
    # Combine lighting
    C_lit = ambient + diffuse + specular
    
    # 4. Fog Distance
    dist = length(P_view)
    
    # 5. Fog Factor
    # Sources disagree on quadratic term. [S1, unofficial] includes k_2, [S2, unofficial] does not.
    # If k_2 is 0 or not provided, use exponential only.
    if k_2 > 0:
        fog_factor = exp(-k_1 * dist) * exp(-k_2 * dist * dist)
    else:
        fog_factor = exp(-k_1 * dist)
        
    # Clamp fog factor
    fog_factor = clamp(fog_factor, 0.0, 1.0)
    
    # 6. Apply Fog
    # [S2, unofficial] applies a 1.5x multiplier to the lit color before mixing.
    # [S1, unofficial] does not specify this multiplier.
    # We follow [S1, unofficial] for the general formula, but note [S2, unofficial]'s variation.
    final_color = mix(C_lit * 1.5, C_f, 1.0 - fog_factor)
    
    return final_color
```

**Edge Cases and Pitfalls:**
*   **Precision:** At large distances, $e^{-k_1 d(x)}$ approaches zero, potentially causing underflow if not handled carefully in fixed-point arithmetic [S1, S2, unofficial].
*   **Boundary Conditions:** If $d(x) = 0$, fog factor is 1.0, and no fog is applied [S2, unofficial].
*   **Disagreement:** The sources disagree on the fog function. [S1, unofficial] uses a double exponential $e^{-k_1 d} e^{-k_2 d^2}$, while [S2, unofficial] uses a single exponential $e^{-k_1 d}$ [S1, S2, unofficial].
*   **Lighting Multiplier:** [S2, unofficial] multiplies the lit color by 1.5 before fog mixing, which is not part of the standard model described in [S1, unofficial] [S2, unofficial].

## Background
The method is attributed to Marc Levoy, who described "Levoy - Shading" as Phong Shading combined with Depth Cueing in the context of Direct Volume Rendering (DVR) [S1, unofficial]. It was presented in lecture materials for a course on DVR Ray-casting (Fall 2007) by Mengxia Zhu [S1, unofficial]. The implementation details in [S2, unofficial] reflect a modern GPU fragment shader interpretation of this concept, using exponential fog for depth cueing [S2, unofficial].
