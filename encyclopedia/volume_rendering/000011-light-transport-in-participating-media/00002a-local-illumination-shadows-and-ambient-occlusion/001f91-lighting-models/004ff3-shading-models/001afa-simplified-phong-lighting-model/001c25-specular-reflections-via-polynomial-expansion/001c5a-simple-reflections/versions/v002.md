# Simple Reflections


## Overview
Simple Reflections is a local illumination technique that calculates a reflected ray direction off a surface normal and raymarches along it, blending the result with the surface color [S1, unofficial].

## How it works
**Inputs:**
*   Surface position $\mathbf{p}$ [G]
*   Surface normal $\mathbf{n}$ (normalized) [G]
*   View direction $\mathbf{v}$ (normalized, pointing from surface to camera) [G]
*   Distance field function $SDF(\mathbf{x})$ [G]
*   Reflection blend factor $\alpha \in [0, 1]$ [G]

**Outputs:**
*   Reflected color $C_{refl}$ [G]

**Data Structures:**
*   Ray structure: $\{ \mathbf{origin}: \mathbb{R}^3, \mathbf{direction}: \mathbb{R}^3, \mathbf{color}: \mathbb{R}^3, \mathbf{t}: \mathbb{R} \}$ [G]

**Steps:**
1.  **Calculate Reflected Direction:** Compute the direction of the reflected ray $\mathbf{r}$ using the surface normal $\mathbf{n}$ and the view direction $\mathbf{v}$: $\mathbf{r} = 2(\mathbf{n} \cdot \mathbf{v})\mathbf{n} - \mathbf{v}$ [S1, unofficial].
2.  **Raymarch:** Cast a ray starting at $\mathbf{p}$ with direction $\mathbf{r}$ into the scene [S1, unofficial]. Initialize ray origin $\mathbf{o} = \mathbf{p} + \epsilon \mathbf{r}$ [G]. Iterate to find the closest surface intersection distance $d = SDF(\mathbf{o})$ [G]. Advance the ray: $\mathbf{o} \leftarrow \mathbf{o} + d \mathbf{r}$ [G]. Repeat until $d$ is below a threshold (hit) or a maximum distance is exceeded (miss) [G]. If a hit occurs, sample the color $C_{env}$ at the hit point [G]. If no hit, use a background color $C_{bg}$ [G].
3.  **Blend:** Combine the reflected color $C_{env}$ with the original surface color $C_{surf}$ using the blend factor $\alpha$: $C_{refl} = \alpha C_{env} + (1 - \alpha) C_{surf}$ [S1, unofficial].

**Parameters:**
*   $\alpha$: Reflection blend factor [G].
*   $\epsilon$: Offset for self-intersection prevention [G].

**Edge Cases and Pitfalls:**
*   **Self-Intersection:** Without the offset $\epsilon$, the reflected ray may immediately intersect the surface it originated from, causing artifacts [G].
*   **Precision:** Floating-point precision errors in raymarching can cause jittering in reflections, especially at grazing angles [G].

**Pseudocode:**
```python
def simple_reflections(p, n, v, sdf, alpha, C_surf, max_steps=10, max_dist=100.0, epsilon=1e-4):
    # 1. Calculate reflected direction based on surface normal [S1, unofficial]
    r = 2.0 * dot(n, v) * n - v
    r = normalize(r)

    # 2. Raymarch along the reflected direction [S1, unofficial]
    ray_origin = p + epsilon * r
    ray_color = vec3(0.0)
    hit = False

    for _ in range(max_steps):
        dist = sdf(ray_origin)
        if dist < 1e-4:
            hit = True
            # Sample color at hit point [G] step not given in sources
            ray_color = vec3(1.0, 1.0, 1.0)
            break
        if dist > max_dist:
            ray_color = vec3(0.0, 0.0, 0.0)
            break
        ray_origin += dist * r

    if not hit:
        ray_color = vec3(0.0, 0.0, 0.0)

    # 3. Blend the resulting color with the original surface color [S1, unofficial]
    return alpha * ray_color + (1.0 - alpha) * C_surf
```

## Subtopics

### Cube Map Mapping
A variant that replaces raymarching with a cube map lookup for reflections [S2, unofficial]. It maps the reflected direction to cube map texture coordinates following OpenGL specifications [S2, unofficial].
**Steps:**
1.  Compute reflected directions: `reflected_directions = 2 * surface_normals * torch.sum(view_directions * surface_normals, dim=-1, keepdim=True) - view_directions` [S2, unofficial].
2.  Find the max absolute component index and value: `max_indices = torch.argmax(torch.abs(reflected_directions), dim=-1, keepdim=True)`; `max_values = torch.gather(reflected_directions, -1, max_indices)` [S2, unofficial].
3.  Compute texture coordinates: `texcoords_x, texcoords_y, texcoords_z = torch.unbind(reflected_directions / torch.abs(max_values), dim=-1)` [S2, unofficial].
4.  Map coordinates to cube faces using linear mapping for the third coordinate: `linear_mapping(inputs, in_min, in_max, out_min, out_max) = (inputs - in_min) / (in_max - in_min) * (out_max - out_min) + out_min` [S2, unofficial].
5.  Construct grid coordinates for each face based on `max_indices` and `max_values` sign, stacking `(u, v, face_index)` where `face_index` is mapped from 0-5 to -1 to 1 [S2, unofficial].
6.  Sample cube map: `images = nn.functional.grid_sample(images, grids.unsqueeze(-4)).squeeze(-3)` [S2, unofficial].
7.  Permute output: `images = images.permute(0, 2, 3, 1)` [S2, unofficial].
