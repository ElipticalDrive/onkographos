# Volume Shading Modes
## Overview
Volume Shading Modes are a set of three shading strategies applied during volume ray marching to compute lighting and shadows for each sample along a ray [S1, unofficial].
## How it works
**Inputs and Outputs**
*   **Input**: Ray origin and direction in world space, volume data, transformation matrices (`wto`, `otw`), shading mode (`FULL_SHADOW`, `GRADIENT_SHADING`, `SINGLE_SHADE_HEURISTIC`), `shadingScale`, `gradientStep`, and light parameters (ambient color, directional light color and direction) [S1, unofficial].
*   **Output**: Shaded color and accumulated alpha for the ray segment [S1, unofficial].

**Data Structures**
*   `RadiancePayload`: Contains `rng` (pointer to RandomTEA), `alpha` (float), and `color` (vec3f). Packaged via `packPointer(&payload, u0, u1)` for OptiX trace [S1, unofficial].

**Pseudocode**
```python
def volume_shading_modes(ray_origin_world, ray_dir_world, volume, wto, otw, mode, shading_scale, gradient_step, light_ambient, light_dir_rgb, light_dir_dir):
    org = xfm_point(wto, ray_origin_world)
    dir = xfm_vector(wto, ray_dir_world)
    
    payload_alpha = 0.0
    payload_color = vec3f(0.0)
    
    if mode == SINGLE_SHADE_HEURISTIC:
        highest_contribution_org = vec3f(0.0)
        highest_contribution_color = vec3f(0.0)
        highest_contribution_alpha = 0.0
        
    for t in raymarching_iterator(org, dir, t_min, t_max, step):
        # Compute sample position with jitter
        p = org + lerp(jitter, t.x, t.y) * dir
        
        # Sample volume data and compute alpha/color [G]
        sample_value = sample_volume(volume, p)
        sample_alpha = compute_alpha(sample_value)
        sample_color = compute_color(sample_value)
        
        # Compute gradient in object space and negate it
        no = -sample_gradient(volume, p, sample_value, gradient_step)
        nw = xfm_normal(otw, no)
        
        if mode == GRADIENT_SHADING:
            shading_color = shade_scivis_light(dir, nw, sample_color, mat_gradient_shading, light_ambient, light_dir_rgb, light_dir_dir)
            sample_color = lerp(shading_scale, sample_color, shading_color)
            
        elif mode == SINGLE_SHADE_HEURISTIC:
            contribution_alpha = (1.0 - payload_alpha) * sample_alpha
            if highest_contribution_alpha < contribution_alpha:
                highest_contribution_org = p
                highest_contribution_color = sample_color
                highest_contribution_alpha = contribution_alpha
                
        # Update payload alpha and color [G]
        payload_alpha = 1.0 - (1.0 - payload_alpha) * (1.0 - sample_alpha)
        payload_color = payload_color * (1.0 - sample_alpha) + sample_color * sample_alpha
        
        if payload_alpha >= nearly_one:
            break
            
    return payload_alpha, payload_color
```

**Parameters**
*   `shadingScale`: Controls the interpolation weight between base color and shaded color in `lerp(shadingScale, base, shaded)` [S1, unofficial].
*   `gradientStep`: Step size used for finite-difference gradient estimation in `sampleGradient` [S1, unofficial].

**Pitfalls**
*   **Gradient Direction**: The gradient direction must be negated (`-sampleGradient`) because the implementation assumes opacity directly correlates to the volume scalar field, meaning the gradient naturally points toward higher values (outside), requiring a flip for correct lighting [S1, unofficial].
