# Blinn-Phong Lighting with Depth Cueing

Also called: Volume Rendering with Depth Cueing and Blinn-Phong Lighting

## Overview
This method computes per-voxel illumination using the Blinn-Phong shading model and applies depth cueing to enhance the perception of volume density and depth [S1, unofficial]. It differs from pure [Blinn-Phong Shading Model](2239-blinn-phong-shading-model.md) by integrating lighting directly into the volume compositing loop with depth-based color modulation [S1, unofficial].

## How it works

### Inputs and Outputs
**Inputs:** `rgba` (current voxel color and opacity), `convolution.gradient` (spatial gradient), `camera` (parameters including `near_clip_view`, `far_clip_view`, `n`, and projection type), `pos_world_init` (ray origin), `pos_world` (current voxel position), `pos_view` (view-space position), `context` (lighting and transfer function parameters), and `light` (light source data with `num`, `rgb`, and `xyz`) [S1, unofficial].
**Outputs:** `self.result` (accumulated RGB color and opacity), `keepgoing` (boolean for early termination) [S1, unofficial].

### Data Structures
`self.result`: A 4-component vector storing the accumulated result [S1, unofficial].
`self.result_curr`: A 4-component vector storing the lit and depth-cued color for the current voxel [S1, unofficial].
`self.transparency`: A scalar storing the accumulated transparency [S1, unofficial].
`self.result_cache`: A 4-component vector storing the previous step's `self.result` [S1, unofficial].

### Numbered Steps
1. **Determine Viewer Direction and Lit Color:** If `rgba[3]` is 0, set `rgb_lit` to `rgba[:3]` without applying lighting [S1, unofficial]. Otherwise, if the camera is orthographic, set `viewer_dir` to `camera.n`; if perspective, compute `pos_world_dir = self.pos_world_init - pos_world`, normalize it, and use it as `viewer_dir` [S1, unofficial]. Compute `rgb_lit` by calling `blinn_phong(rgba[:3], convolution.gradient, viewer_dir, context)` [S1, unofficial].
2. **Compute Depth Cueing Factor:** Calculate $\gamma$ using clamped linear interpolation between `camera.near_clip_view` and `camera.far_clip_view` with `-pos_view[2, 0]` [S1, unofficial].
3. **Apply Depth Cueing:** Retrieve `dcn` and `dcf` from `context.params_light.depth_color_near` and `context.params_light.depth_color_far` [S1, unofficial]. Compute `color_lerped` by interpolating `dcn` and `dcf` with $\gamma$ [S1, unofficial]. Set `self.result_curr[:3]` to the component-wise product of `rgb_lit` and `color_lerped`, and set `self.result_curr[3]` to `rgba[3]` [S1, unofficial].
4. **Composite:** Call `blend(context)` to composite the current result with the accumulated result, and return `keepgoing` [S1, unofficial].

### Pseudocode
```python
def step(rgba, gradient, camera, pos_world_init, pos_world, pos_view, context, light, self):
    # 1. Determine viewer direction and lit color
    if rgba[3] == 0:
        rgb_lit = rgba[:3]
    else:
        if camera.is_orthographic:
            viewer_dir = camera.n
        else:
            pos_world_dir = self.pos_world_init - pos_world
            norm_val = sum(x**2 for x in pos_world_dir) ** 0.5
            viewer_dir = [x / norm_val for x in pos_world_dir]
        rgb_lit = blinn_phong(rgba[:3], gradient, viewer_dir, context, light)

    # 2. Depth cueing factor (clamped lerp)
    near = camera.near_clip_view
    far = camera.far_clip_view
    depth_val = -pos_view[2, 0]
    if far == near:
        gamma = 0.0
    else:
        gamma = max(0.0, min(1.0, (depth_val - near) / (far - near)))
    
    # 3. Apply depth cueing
    dcn = context.params_light.depth_color_near
    dcf = context.params_light.depth_color_far
    color_lerped = [dcn[i] + gamma * (dcf[i] - dcn[i]) for i in range(3)]
    
    self.result_curr = [rgb_lit[i] * color_lerped[i] for i in range(3)] + [rgba[3]]
    
    # 4. Composite
    keepgoing = blend(self, context)
    return keepgoing

def blinn_phong(rgb_in, gradient, viewer_dir, context, light):
    k_ambient = context.params_light.k_ambient
    k_diffuse = context.params_light.k_diffuse
    k_specular = context.params_light.k_specular
    p_shininess = context.params_light.p_shininess
    
    rgb_out = [k_ambient * c for c in rgb_in]
    
    if light.num == 0 or (k_ambient == 0 and k_specular == 0):
        return rgb_out
        
    gradient_len = sum(g**2 for g in gradient) ** 0.5
    if gradient_len == 0:
        return rgb_out
        
    normal = [-g / gradient_len for g in gradient]
    
    for i in range(light.num):
        light_col = light.rgb[i]
        light_dir = light.xyz[i]
        
        prod = [rgb_in[j] * light_col[j] for j in range(3)]
        scale_diffuse = max(0.0, sum(n * d for n, d in zip(normal, light_dir)))
        diffuse = [k_diffuse * scale_diffuse * p for p in prod]
        
        halfway = [viewer_dir[j] + light_dir[j] for j in range(3)]
        halfway_len = sum(h**2 for h in halfway) ** 0.5
        if halfway_len == 0:
            scale_specular = 0.0
        else:
            halfway_norm = [h / halfway_len for h in halfway]
            scale_specular = max(0.0, sum(n * h for n, h in zip(normal, halfway_norm)))
            scale_specular = scale_specular ** p_shininess
            
        specular = [k_specular * scale_specular * c for c in light_col]
        rgb_out = [rgb_out[j] + diffuse[j] + specular[j] for j in range(3)]
        
    return rgb_out

def blend(self, context):
    keepgoing = True
    transparency_curr = 1.0 - self.result_curr[3]
    
    if self.result_cache is None:
        self.result = self.result_curr[:]
        self.transparency = transparency_curr
    else:
        rgb_premultiplied = [self.result_cache[3] * c for c in self.result_cache[:3]]
        rgb_curr = [self.transparency * self.result_curr[3] * c for c in self.result_curr[:3]]
        rgb_composite = [rgb_premultiplied[j] + rgb_curr[j] for j in range(3)]
        
        self.transparency *= transparency_curr
        opacity = 1.0 - self.transparency
        
        if opacity == 0:
            self.result = [0.0, 0.0, 0.0, 0.0]
        else:
            inv_opacity = 1.0 / opacity
            self.result[:3] = [inv_opacity * c for c in rgb_composite]
            self.result[3] = opacity
            
        if opacity > context.transfer_func.alpha_near_one:
            self.transparency = 0
            keepgoing = False
            
    self.result_cache = self.result[:]
    return keepgoing
```

### Parameters
- `context.params_light.k_ambient`: Ambient lighting coefficient [S1, unofficial].
- `context.params_light.k_diffuse`: Diffuse lighting coefficient [S1, unofficial].
- `context.params_light.k_specular`: Specular lighting coefficient [S1, unofficial].
- `context.params_light.p_shininess`: Shininess exponent for specular highlight [S1, unofficial].
- `context.params_light.depth_color_near`: Depth cueing color at near clip plane [S1, unofficial].
- `context.params_light.depth_color_far`: Depth cueing color at far clip plane [S1, unofficial].
- `context.transfer_func.alpha_near_one`: Opacity threshold for early ray termination [S1, unofficial].
- `camera.near_clip_view`: Near clip plane distance in view space [S1, unofficial].
- `camera.far_clip_view`: Far clip plane distance in view space [S1, unofficial].

### Edge Cases and Pitfalls
- **Division by Zero (Opacity):** If the accumulated opacity is 0 during compositing, the division $1/\text{opacity}$ is avoided by setting `self.result` to `[0.0, 0.0, 0.0, 0.0]` [S1, unofficial].
- **Zero Gradient:** If the gradient length is 0, the `blinn_phong` function returns immediately to avoid division by zero in normal computation [S1, unofficial].
- **Zero Opacity Voxel:** If the current voxel's opacity `rgba[3]` is 0, lighting is skipped, and the lit RGB color is set to the input RGB [S1, unofficial].

## Operating characteristics

### Time and Memory Complexity
- **Time Complexity:** $O(L)$ per voxel, where $L$ is the number of lights, due to the loop over lights with constant-time vector operations per light [S1, unofficial].
- **Memory Complexity:** $O(1)$ auxiliary memory per voxel, storing the current result, transparency, and cache [S1, unofficial].
