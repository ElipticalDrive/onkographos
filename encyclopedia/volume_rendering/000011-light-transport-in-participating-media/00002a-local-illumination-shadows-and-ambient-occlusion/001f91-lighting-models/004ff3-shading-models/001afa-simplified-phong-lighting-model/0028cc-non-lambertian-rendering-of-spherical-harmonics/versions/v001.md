# Non-Lambertian Rendering of Spherical Harmonics

Also called: Phong Model with SH Lighting

## Overview
This method renders non-Lambertian (specular) surfaces by approximating the Phong shading model using Spherical Harmonic (SH) lighting representations. It solves the problem of efficiently computing specular reflections in environments with complex, high-dynamic-range lighting by projecting the lighting into SH coefficients and applying pre-computed or approximated specular basis functions. It distinguishes itself from its parent, the Simplified Phong Lighting Model, by replacing explicit light source summation with SH domain operations, and from its sibling [Specular Reflections via Polynomial Expansion](1172-specular-reflections-via-polynomial-expansion.md) by utilizing the specific SH approximation for the specular term rather than polynomial expansions of the reflection vector.

## How it works
The method computes the final image by summing a diffuse rendering layer and a specular rendering layer.

**Inputs:**
*   $\mathbf{r}$: Ray direction or pixel coordinate.
*   $N(\mathbf{r})$: Surface normal at the point corresponding to ray $\mathbf{r}$.
*   $\mathcal{R}(\mathbf{r})$: Surface reflectance (albedo) at $\mathbf{r}$.
*   $C_{l,m}$: Spherical Harmonic coefficients of the environment lighting.
*   $s_p$: Specular reflectance material parameter.
*   $\alpha$: Glossiness (shininess) material parameter.

**Outputs:**
*   $I(\mathbf{r})$: Final rendered intensity for ray $\mathbf{r}$.

**Data Structures:**
*   **SH Coefficients:** A set of coefficients $C_{l,m}$ for degrees $l$ and orders $m$. The implementation uses up to second-order SH bases ($l \le 2$), resulting in 9 coefficients total ($l=0,1,2$; $m \in [-l, l]$).
*   **Specular SH Basis:** $\hat{Y}_{l,m}(\theta, \phi)$, defined in [65] (cited in [S1]), representing the specular approximation in the SH domain.
*   **Diffuse SH Basis:** $Y_{l,m}(\theta, \phi)$, the standard SH basis functions.
*   **Pre-computed Constants:** $\hat{A}_l$, constants associated with the diffuse SH projection (derived from [35] as cited in [S1]).

**Steps:**

1.  **Compute Diffuse Component ($I_d$):**
    Calculate the diffuse contribution using the SH representation of the lighting. The standard Phong diffuse term $\sum l_\omega (L_\omega \cdot N)$ is replaced by the SH convolution.
    $$I_d(\mathbf{r}) = \mathcal{R}(\mathbf{r}) \sum_{l=0}^{2} \sum_{m=-l}^{l} \hat{A}_l C_{l,m} Y_{l,m}(\theta, \phi)$$
    Here, $(\theta, \phi)$ are the spherical coordinates of the normal $N(\mathbf{r})$. The term $\hat{A}_l$ accounts for the integration of the cosine lobe against the SH basis.

2.  **Compute Specular Component ($I_s$):**
    Calculate the specular contribution. The exact Phong specular term involves the reflection vector $R = 2(N \cdot V)N - V$ (or similar half-vector approximations). This is approximated using the specular SH basis $\hat{Y}_{l,m}$.
    $$I_s(\mathbf{r}) \approx s_p \sum_{l=0}^{2} \sum_{m=-l}^{l} C_{l,m} \left( \hat{A}_l \hat{Y}_{l,m}(\theta, \phi) \right)^\alpha$$
    Note: The source [S1] presents the approximation as $s_p \sum_{l,m} C_{l,m} (\hat{A}_l \hat{Y}_{l,m}(\theta, \phi))^\alpha$. This implies the specular basis is raised to the power of $\alpha$ before summation, weighted by the lighting coefficients.

3.  **Composite:**
    Sum the diffuse and specular components to get the final image.
    $$I(\mathbf{r}) = I_d(\mathbf{r}) + I_s(\mathbf{r})$$

**Pseudocode:**

```python
def render_non_lambertian_sh(r, N, R, C_lm, s_p, alpha):
    """
    Renders a pixel using Non-Lambertian SH Lighting.
    
    Args:
        r: Ray/pixel identifier (used to lookup N and R if not passed directly).
        N: Normal vector at the surface point.
        R: Reflectance (albedo) at the surface point.
        C_lm: Dictionary or array of SH coefficients C_{l,m} for l=0..2.
        s_p: Specular reflectance parameter.
        alpha: Glossiness parameter.
        
    Returns:
        I: Final intensity.
    """
    # Convert normal to spherical coordinates (theta, phi)
    theta, phi = normal_to_spherical(N)
    
    # 1. Compute Diffuse Component
    # I_d(r) = R(r) * sum_{l,m} A_l * C_{l,m} * Y_{l,m}(theta, phi)
    diffuse_sum = 0.0
    for l in range(3): # l = 0, 1, 2
        for m in range(-l, l + 1):
            # Get coefficient C_{l,m}
            C = C_lm[l][m]
            # Get pre-computed constant A_l (from source [35]/[S1])
            A_l = get_diffuse_sh_constant(l)
            # Evaluate standard SH basis Y_{l,m} at (theta, phi)
            Y_lm = spherical_harmonic_basis(l, m, theta, phi)
            diffuse_sum += A_l * C * Y_lm
            
    I_d = R * diffuse_sum
    
    # 2. Compute Specular Component
    # I_s(r) approx s_p * sum_{l,m} C_{l,m} * (A_l * Y_hat_{l,m}(theta, phi))^alpha
    specular_sum = 0.0
    for l in range(3): # l = 0, 1, 2
        for m in range(-l, l + 1):
            # Get coefficient C_{l,m}
            C = C_lm[l][m]
            # Get pre-computed constant A_l
            A_l = get_diffuse_sh_constant(l) # Note: Source uses A_l for specular basis scaling too
            # Evaluate SPECULAR SH basis Y_hat_{l,m} at (theta, phi)
            # Defined in [65] as cited in [S1]
            Y_hat_lm = specular_sh_basis(l, m, theta, phi)
            
            # Apply glossiness alpha
            term = A_l * Y_hat_lm
            term_pow_alpha = term ** alpha
            
            specular_sum += C * term_pow_alpha
            
    I_s = s_p * specular_sum
    
    # 3. Composite
    I = I_d + I_s
    
    return I

def normal_to_spherical(N):
    """Convert 3D normal vector to spherical coordinates."""
    # N = (nx, ny, nz)
    # theta = arccos(nz)
    # phi = arctan2(ny, nx)
    import math
    nx, ny, nz = N
    theta = math.acos(max(-1.0, min(1.0, nz)))
    phi = math.atan2(ny, nx)
    return theta, phi
```

**Parameters:**
*   $s_p$: Specular reflectance. Controls the intensity of the specular highlights.
*   $\alpha$: Glossiness. Controls the sharpness of the specular highlights. Higher values result in sharper highlights.
*   SH Order: Up to second-order ($l \le 2$), totaling 9 bases.

**Edge Cases and Pitfalls:**
*   **Specular Basis Definition:** The method relies on $\hat{Y}_{l,m}$ defined in [65]. If [65] is not available, the specular term cannot be implemented.
*   **Precision:** Raising the SH basis to the power $\alpha$ can lead to numerical instability if the basis values are negative and $\alpha$ is not an integer. The source does not specify how negative values in $\hat{Y}_{l,m}$ are handled before exponentiation.
*   **Boundary Conditions:** The SH basis functions are defined on the sphere. Normals must be normalized.

## Subtopics

### Specular Rendering with Spherical Harmonics
This variant focuses specifically on the material editing aspect of the specular term. It allows per-pixel editing of material properties $s_p$ and $\alpha$ to achieve different material appearances across a composited scene. The core algorithm is the same as the main method, but the emphasis is on the ability to vary these parameters spatially. It is chosen when dynamic material editing is required in a SH-lit environment.is a sibling method using polynomial expansion.

## Operating characteristics
*   **Time Complexity:** $O(L^2)$ per pixel, where $L$ is the SH order. With $L=2$, this is a constant 9 terms for diffuse and 9 terms for specular. This is significantly faster than explicit light summation for high-resolution HDR environments.
*   **Memory Complexity:** $O(L^2)$ to store the SH coefficients $C_{l,m}$. For $L=2$, this is 9 coefficients (typically 3 floats per coefficient for RGB, so 27 floats).
*   **Performance:** Efficient for real-time rendering or post-processing of NeRFs. The cost is dominated by the evaluation of SH basis functions and the exponentiation for the specular term.
*   **Strengths:** Efficient handling of complex lighting; enables material editing; smooth lighting transitions.
*   **Limitations:** Approximation error in the specular term due to SH truncation and the specific approximation formula; requires pre-computation of SH coefficients from the environment map; reliance on external definitions for specular SH basis.
*   **When to use:** When rendering non-Lambertian surfaces in complex, pre-computed lighting environments, especially in the context of NeRF relighting.
*   **When not to use:** When exact specular reflections are required and SH approximation is insufficient; when the lighting environment is simple and explicit light summation is cheaper.

## Background
This method originates from the work on relighting scenes with object insertions in Neural Radiance Fields (NeRFs). It adapts the Phong shading model to the Spherical Harmonic domain to facilitate efficient rendering and material editing. The diffuse component follows the approach in [35] (cited in [S1]), and the specular component follows the approach in [65] (cited in [S1]). The specific application to NeRFs and SH lighting is detailed in [S1].
