# Lambert Shading with Shadow Rays

Also called: Diffuse Surface Illumination with Shadows

## Overview
Lambert Shading with Shadow Rays is a local illumination technique for isosurface rendering that computes diffuse lighting using the Lambertian reflectance model and enhances depth perception by casting shadow rays to detect occlusion [S1, unofficial]. It distinguishes itself from sibling models like [Simplified Phong Lighting Model](885-simplified-phong-lighting-model.md) by focusing exclusively on diffuse reflection without specular highlights, and from [Gradient-based Shading with Phase Functions](1020-gradient-based-shading-with-phase-functions.md) by treating the volume as an opaque isosurface rather than a participating medium for light transport [S1, unofficial].

## How it works
**Inputs and Outputs:**
*   **Input:** A scalar field defined on a regular grid, the isovalue threshold, the domain bounds ($uDomainMin, uDomainMax$), the sampling step size ($uStepSize$), the light direction vector ($lightDir$), and a boolean flag for shadow enablement ($uEnableShadows$) [S1, unofficial].
*   **Output:** A final color value for a surface intersection point, combining ambient, diffuse, and shadow contributions [S1, unofficial].

**Data Structures:**
The scalar field is accessed via a function `sampleDensityWorld(p)` which returns the density value at world coordinate $p$ [S1, unofficial]. The domain is bounded by $uDomainMin$ and $uDomainMax$ [S1, unofficial].

**Steps:**

1.  **Compute Surface Normal:**
    Calculate the surface normal at the hit point $p$ using central differences with step size $h = uStepSize$ [S1, unofficial]. The gradient components are computed as:
    $$
    \begin{aligned}
    dx &= \text{sampleDensityWorld}(p + (h, 0, 0)) - \text{sampleDensityWorld}(p - (h, 0, 0)) \\
    dy &= \text{sampleDensityWorld}(p + (0, h, 0)) - \text{sampleDensityWorld}(p - (0, h, 0)) \\
    dz &= \text{sampleDensityWorld}(p + (0, 0, h)) - \text{sampleDensityWorld}(p - (0, 0, h))
    \end{aligned}
    $$
    The normal $n$ is the normalized negative gradient:
    $$ n = \frac{(-dx, -dy, -dz)}{\|(-dx, -dy, -dz)\|} $$
    [S1, unofficial]

2.  **Compute Diffuse Term:**
    Calculate the Lambertian diffuse factor using the dot product of the normal $n$ and the normalized light direction $L$:
    $$ diffuse = \max(\text{dot}(n, L), 0.0) $$
    [S1, unofficial]

3.  **Shadow Ray Traversal (if $uEnableShadows == 1$):**
    Cast a shadow ray from the hit point $p$ towards the light source along direction $L$ [S1, unofficial].
    *   Initialize distance $t = 2.0 \times uStepSize$ [S1, unofficial].
    *   Iterate while the point $p_{test} = p + t \cdot L$ is within the domain bounds ($uDomainMin \le p_{test} \le uDomainMax$) [S1, unofficial]:
        *   Sample the density at $p_{test}$ [S1, unofficial].
        *   If $\text{sampleDensityWorld}(p_{test}) \ge uIsovalue$, the ray has hit the isosurface before reaching the light [S1, unofficial].
        *   Increment $t$ by $uStepSize$ [S1, unofficial].
    *   If the loop completes without hitting the isosurface, return shadow factor $shadow = 1.0$ [S1, unofficial].
    *   If shadows are disabled, $shadow = 1.0$ [S1, unofficial].

4.  **Final Color Computation:**
    Combine the diffuse term with the shadow factor and ambient lighting (if applicable) and the material color $C_{mat}$ [S1, unofficial]:
    $$ C_{final} = C_{ambient} + (C_{mat} \times diffuse \times shadow) $$
    [S1, unofficial]

**Parameters:**
*   $uLightAngle$: Controls the direction of the light source. In the reference implementation, this is set to $0.1f$ [S1, unofficial].
*   $uEnableShadows$: Integer flag (0 or 1) to enable or disable shadow ray casting [S1, unofficial].
*   $uIsovalue$: The threshold value for isosurface extraction [S1, unofficial].
*   $uStepSize$: The step size used for normal computation and shadow ray traversal [S1, unofficial].

**Edge Cases and Pitfalls:**
*   **Boundary Conditions:** The shadow ray traversal must check domain boundaries to prevent out-of-bounds memory access [S1, unofficial].
*   **Initial Offset:** The shadow ray origin is exactly at the surface, but the reference implementation uses a fixed initial offset of $2.0 \times uStepSize$ before the first sample to step away from the surface [S1, unofficial].

**Pseudocode:**

```python
import math

class Vector3:
    def __init__(self, x, y, z):
        self.x, self.y, self.z = x, y, z
    def __add__(self, other): return Vector3(self.x + other.x, self.y + other.y, self.z + other.z)
    def __sub__(self, other): return Vector3(self.x - other.x, self.y - other.y, self.z - other.z)
    def __mul__(self, s): return Vector3(self.x * s, self.y * s, self.z * s)
    def dot(self, other): return self.x * other.x + self.y * other.y + self.z * other.z
    def length(self): return math.sqrt(self.x**2 + self.y**2 + self.z**2)
    def normalized(self):
        l = self.length()
        return Vector3(self.x / l, self.y / l, self.z / l) if l > 0 else Vector3(0, 0, 0)

def compute_normal(p, step_size, sample_density_world):
    h = step_size
    dx = sample_density_world(p + Vector3(h, 0.0, 0.0)) - sample_density_world(p - Vector3(h, 0.0, 0.0))
    dy = sample_density_world(p + Vector3(0.0, h, 0.0)) - sample_density_world(p - Vector3(0.0, h, 0.0))
    dz = sample_density_world(p + Vector3(0.0, 0.0, h)) - sample_density_world(p - Vector3(0.0, 0.0, h))
    grad = Vector3(dx, dy, dz)
    return grad.normalized()

def trace_shadow_ray(origin, dir, step_size, isovalue, domain_min, domain_max, sample_density_world):
    t = 2.0 * step_size
    while True:
        p_test = origin + dir * t
        if p_test.x < domain_min.x or p_test.y < domain_min.y or p_test.z < domain_min.z:
            break
        if p_test.x > domain_max.x or p_test.y > domain_max.y or p_test.z > domain_max.z:
            break
        if sample_density_world(p_test) >= isovalue:
            return 0.0
        t += step_size
    return 1.0

def shade_isopoint(p_hit, light_dir, step_size, isovalue, domain_min, domain_max, 
                   sample_density_world, enable_shadows, ambient_color, material_color):
    # Light direction derivation from uLightAngle not provided in sources [G]
    normal = compute_normal(p_hit, step_size, sample_density_world)
    diffuse = max(normal.dot(light_dir), 0.0)
    
    shadow = 1.0
    if enable_shadows:
        shadow = trace_shadow_ray(p_hit, light_dir, step_size, isovalue, 
                                  domain_min, domain_max, sample_density_world)
        
    final_color = ambient_color + (material_color * diffuse * shadow)
    return final_color
```

## Subtopics

### [Point Light Shading with Shadow Offset](2225-point-light-shading-with-shadow-offset.md)
This method computes direct diffuse illumination from a point light at a surface intersection point while mitigating self-shadowing artifacts (shadow acne) through geometric biasing of the shadow ray origin. It differs from standard shadow ray casting by explicitly offsetting the ray origin along the surface normal based on the dot product of the incoming ray and the normal, ensuring the ray starts slightly above the surface rather than exactly on it.

### Point Light Shading
A shading model using a single point light source to determine illumination strength at a surface intersection point using the dot product of the normalized light direction and the surface normal (gradient) [S2, unofficial].

## Background
The method is demonstrated in the `isosurface-ray-casting` project [S1, unofficial]. It is based on the standard Lambertian reflectance model, which assumes that light is scattered equally in all directions from a surface [S1, unofficial]. The concept of using a single point light source for shading is also discussed in the context of OpenCL volume raycasting [S2, unofficial].
