# Volume Shading Model

Also called: directLight, indirectDiffuseLight, indirectSpecularLight

## Overview
The Volume Shading Model is a local illumination technique implemented within ray casting volume renderers that calculates diffuse and specular contributions based on scalar data values and their gradients [S1, unofficial]. It computes the final fragment color by combining indirect diffuse, indirect specular, emissivity, transparency/refraction, and direct light contributions, applying shadow blending and gamma correction [S1, unofficial]. It differs from its siblings by explicitly managing the interplay between material opacity and light transport modes (indirect vs. direct) within a single shading pass, whereas [Simplified Phong Lighting Model](885-simplified-phong-lighting-model.md) focuses on surface-like reflection approximations and [Gradient-based Shading with Phase Functions](1020-gradient-based-shading-with-phase-functions.md) emphasizes angular scattering properties [S1, S2, unofficial].

## How it works
**Inputs and Outputs:**
*   **Inputs:** Material properties (`diffuseColor`, `specularColor`, `specularReflectivity`, `diffuseReflectivity`, `emissivity`, `specularDiffusion`, `transparency`, `refractiveIndex`), lighting settings (`indirectSpecularLight`, `indirectDiffuseLight`, `directLight`, `shadows`), light sources (`PointLight` array with position, color, intensity), camera parameters (`V`, `P`, `cameraPosition`), and voxel data (`voxelTextureSize`, `state`) [S1, unofficial].
*   **Output:** A `vec4` color value representing the final fragment color with alpha [S1, unofficial].

**Data Structures:**
The material properties are packed into a `Material` struct:
*   `diffuseColor`: `packed_float3`
*   `specularColor`: `packed_float3`
*   `specularReflectivity`: `float`
*   `diffuseReflectivity`: `float`
*   `emissivity`: `float`
*   `specularDiffusion`: `float`
*   `transparency`: `float`
*   `refractiveIndex`: `float`

The application state includes a `Settings` struct with boolean flags: `indirectSpecularLight`, `indirectDiffuseLight`, `directLight`, `shadows` [S1, unofficial]. It also holds an array of `PointLight` objects (`MAX_LIGHTS`), the number of active lights, view/projection matrices (`V`, `P`), camera position, voxel texture size, and current state [S1, unofficial].

**Algorithm Steps:**
1.  Initialize the output color `color` to `vec4(0, 0, 0, 1)` [S1, unofficial].
2.  Compute the `viewDirection` vector from the camera to the current fragment [S1, unofficial].
3.  **Indirect Diffuse:** If `settings.indirectDiffuseLight` is enabled AND the material is sufficiently opaque (`material.diffuseReflectivity * (1.0 - material.transparency) > 0.01f`), add the result of `indirectDiffuseLight()` to `color.rgb` [S1, unofficial].
4.  **Indirect Specular:** If `settings.indirectSpecularLight` is enabled AND the material is sufficiently opaque (same threshold as above), add the result of `indirectSpecularLight(viewDirection)` to `color.rgb` [S1, unofficial].
5.  **Emissivity:** Add the material's self-illumination: `color.rgb += material.emissivity * material.diffuseColor` [S1, unofficial].
6.  **Refraction:** If `material.transparency > 0.01f`, mix the current color with refractive light: `color.rgb = mix(color.rgb, indirectRefractiveLight(viewDirection), material.transparency)` [S1, unofficial].
7.  **Direct Light:** If `settings.directLight` is enabled, add the contribution from `directLight(viewDirection)` to `color.rgb` [S1, unofficial].
8.  **Gamma Correction:** If `GAMMA_CORRECTION == 1`, apply gamma correction to the final color [S1, unofficial].

**Formulas:**
The specular component uses a modified Phong-like exponent:
$$specular = SPECULAR\_FACTOR \times specularAngle^{df \times SPECULAR\_POWER}$$
where:
*   $SPECULAR\_FACTOR$ and $SPECULAR\_POWER$ are constants controlling intensity and sharpness [S1, unofficial].
*   $specularAngle$ is the angle between the view direction and the perfect reflection vector [S1, unofficial].
*   $df = 1.0 / (1.0 + 0.25 \times material.specularDiffusion)$ is a diffusion factor derived from the material's specular diffusion property [S1, unofficial].

The diffuse component accounts for opacity:
$$diffuse = diffuseAngle \times (1.0 - material.transparency)$$
where $diffuseAngle$ is the angle between the surface normal (or gradient) and the light direction [S1, unofficial].

The total light contribution from a source is:
$$total = light.color \times (diff + spec)$$
scaled by `DIRECT_LIGHT_INTENSITY` [S1, unofficial].

**Parameters:**
*   `DIRECT_LIGHT_INTENSITY`: Multiplier for the sum of direct light contributions [S1, unofficial].
*   `SPECULAR_FACTOR`: Constant for specular intensity [S1, unofficial].
*   `SPECULAR_POWER`: Constant for the specular exponent [S1, unofficial].

**Pitfalls and Edge Cases:**
*   **Shadow Blending:** Shadow blending clamps both diffuse and specular angles to prevent light leaking through semi-transparent regions. Specifically: $diffuseAngle = \min(shadowBlend, diffuseAngle)$ and $specularAngle = \min(shadowBlend, \max(specularAngle, refractiveAngle))$ [S1, unofficial].
*   **Opacity Thresholds:** The check `> 0.01f` prevents noise and incorrect shading on nearly transparent voxels where indirect lighting calculations might be unstable or visually irrelevant [S1, unofficial].
*   **Precision:** Floating point precision in angle calculations can affect specular highlights; ensure consistent vector normalization [G].

**Pseudocode:**
```python
def volume_shading(material, settings, view_direction, lights, state):
    # Step 1: Initialize color to vec4(0,0,0,1)
    color = [0.0, 0.0, 0.0, 1.0]
    
    # Threshold for opacity check
    opacity_threshold = 0.01
    
    # Check if material is opaque enough
    is_opaque = material.diffuseReflectivity * (1.0 - material.transparency) > opacity_threshold
    
    # Step 3: Indirect Diffuse
    if settings.indirectDiffuseLight and is_opaque:
        # Source does not specify internal calculation for indirectDiffuseLight() [Comment]
        pass
        
    # Step 4: Indirect Specular
    if settings.indirectSpecularLight and is_opaque:
        # Source does not specify internal calculation for indirectSpecularLight() [Comment]
        pass
        
    # Step 5: Emissivity
    color[:3] = [color[i] + material.emissivity * material.diffuseColor[i] for i in range(3)]
    
    # Step 6: Refraction
    if material.transparency > opacity_threshold:
        # Source does not specify internal calculation for indirectRefractiveLight() [Comment]
        refractive = [0.0, 0.0, 0.0]
        color[:3] = [color[i] * (1.0 - material.transparency) + refractive[i] * material.transparency for i in range(3)]
        
    # Step 7: Direct Light
    if settings.directLight:
        direct_sum = [0.0, 0.0, 0.0]
        for i in range(state.numberOfLights):
            light = lights[i]
            
            # Compute angles (assumed normalized)
            diffuse_angle = compute_diffuse_angle(material, light)
            specular_angle = compute_specular_angle(material, light, view_direction)
            refractive_angle = compute_refractive_angle(material, light, view_direction)
            
            # Shadow blending clamp
            shadow_blend = compute_shadow_blend(light, view_direction) # [G] standard shadow ray/texture lookup
            
            diffuse_angle = min(shadow_blend, diffuse_angle)
            specular_angle = min(shadow_blend, max(specular_angle, refractive_angle))
            
            # Diffuse formula
            diffuse = diffuse_angle * (1.0 - material.transparency)
            
            # Specular formula
            df = 1.0 / (1.0 + 0.25 * material.specularDiffusion)
            specular = SPECULAR_FACTOR * (specular_angle ** (df * SPECULAR_POWER))
            
            # Total light contribution
            direct_sum = [direct_sum[j] + light.color[j] * (diffuse + specular) for j in range(3)]
            
        color[:3] = [color[i] + DIRECT_LIGHT_INTENSITY * direct_sum[i] for i in range(3)]
        
    # Step 8: Gamma Correction
    if state.GAMMA_CORRECTION == 1:
        color[:3] = [c ** (1.0 / 2.2) for c in color[:3]]
        
    return color
```

## Subtopics

### Luminous Gas Shading Model
A shading component based on the traditional 'luminous gas' model used in direct volume rendering, applied to both ambient and reflecting materials [S2, unofficial]. It interprets each rendered plane as the center of a slab of thickness $A$ [S2, unofficial]. The color per primary $p$ is calculated as $C(p) = E(p) \frac{1 - e^{-\bar{\rho} A}}{\bar{\rho}}$, where $E(p)$ is color emission per unit distance and $\bar{\rho}$ is opacity per unit distance [S2, unofficial]. The opacity is $A = 1 - e^{-\bar{\rho} A}$ [S2, unofficial]. This model is well-defined as opacity per unit distance approaches 0 via power series expansion [S2, unofficial]. It is chosen when a volumetric, non-surface-based ambient lighting approximation is required [S2, unofficial].

## Background
The Volume Shading Model is implemented in the VoxelConeTracingMetal project [S1, unofficial]. The underlying concepts of combining direct and indirect lighting with transparency in volume rendering have roots in earlier direct volume rendering techniques, such as the "luminous gas" model described in NASA Technical Reports from 1997 [S2, unofficial]. The specific implementation details (struct layouts, thresholds) are derived from the primary source code repository [S1, unofficial].
