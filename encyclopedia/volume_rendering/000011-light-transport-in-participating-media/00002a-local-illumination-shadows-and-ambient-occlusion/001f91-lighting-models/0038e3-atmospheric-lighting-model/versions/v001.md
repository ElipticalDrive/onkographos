# Atmospheric Lighting Model

Also called: Multi-field Gradient Lighting, Multi-gradient Lighting

## Overview
The Atmospheric Lighting Model is a volume shading technique designed for multi-field data visualization that avoids the ambiguity and instability of surface normals derived from multi-variate gradients [S1][S2, unofficial]. Unlike traditional lighting models that approximate a surface normal via the eigenvector of the largest eigenvalue of a metric tensor, this method attenuates light through the volume and modulates the voxel's initial color by the summed attenuation [S1]. It provides simple, robust lighting cues for shape and curvature without relying on directional surface approximations that may flip or be undefined when eigenvalues are similar [S1][S2, unofficial].

## How it works
The method operates during the volume rendering compositing pass. It replaces the standard normal-based illumination calculation with a density-dependent attenuation factor.

### Inputs and Outputs
*   **Input:** A volume dataset where each sample contains $m$ scalar fields (e.g., temperature, humidity, pressure). For each sample point $\mathbf{x}$ along a ray, the method requires the multi-field gradient information and the initial color $C_{init}$ assigned by the transfer function.
*   **Output:** The final composited color $C_{final}$ for the pixel.

### Data Structures
The core data structure is the **Metric Tensor** $[g_{ij}]$, a symmetric matrix describing the rate of change of the multi-field data in all directions at a sample point [S1].
*   **Fields:** The tensor is $m \times m$ for $m$ fields.
*   **Computation:** The elements $g_{ij}$ are derived from the partial derivatives of the fields. The differential change $d\Phi$ is calculated as:
    $$ d\Phi = \sum_{i=1}^{3} w_i \frac{\partial \Phi}{\partial u_i} du_i $$
    where $W$ is a diagonal weight matrix with weights $w_1, w_2, ..., w_m$ [S1]. Note: The source notation $\sum_{i=1}^{3}$ implies spatial dimensions, but the weight matrix $W$ has size $m$ (number of fields). The metric tensor $[g_{ij}]$ is constructed from these derivatives to capture multi-variate structure [S1].

### Steps
1.  **Compute Multi-Gradient Magnitude:** For each sample along the ray, compute the metric tensor $[g_{ij}]$ [S1]. Extract a scalar magnitude representing the total change at that location. The sources specify three equivalent metrics for this magnitude:
    *   The L2 norm of the matrix $[g_{ij}]$ [S1].
    *   The magnitude of the largest eigenvalue of $[g_{ij}]$ [S1].
    *   The trace of $[g_{ij}]$ (sum of eigenvalues) [S1].
    This scalar value is used as an additional axis in the transfer function to determine opacity and initial color [S1].

2.  **Handle High-Dimensional Fields:** If the number of fields $m$ is three or more, apply the gradient portion of the transfer function separably to accommodate hardware limitations [S1].

3.  **Atmospheric Attenuation:** During compositing, accumulate the attenuation through the volume. The light is attenuated based on the density/gradient magnitude of the samples traversed [S1][S2, unofficial].

4.  **Color Modulation:** Modulate the voxel's initial color $C_{init}$ (determined by the transfer function) by the summed attenuation factor $A$ [S1]. The attenuated color is then composited to form the final volume rendering [S1].

### Pseudocode
```python
def atmospheric_lighting_model(ray_samples, transfer_function):
    """
    ray_samples: list of Sample objects along the ray.
                 Each Sample has:
                 - fields: array of m scalar values
                 - partial_derivs: gradient information for the fields
                 - color: initial color from transfer function
                 - opacity: initial opacity from transfer function
    transfer_function: function that maps fields and gradient magnitude to color/opacity
    """
    accumulated_transmittance = 1.0
    accumulated_color = (0.0, 0.0, 0.0)
    
    for sample in ray_samples:
        # Step 1: Compute metric tensor magnitude
        # Construct metric tensor [g_ij] from partial derivatives
        # Note: Implementation details of [g_ij] construction from partial_derivs
        # are not fully specified beyond the differential change formula [S1].
        # We assume a helper computes the tensor from the multi-field gradients.
        metric_tensor = compute_metric_tensor(sample.partial_derivs)
        
        # Extract scalar magnitude using one of the specified metrics [S1]
        # Option A: L2 norm
        magnitude = l2_norm(metric_tensor)
        # Option B: Largest eigenvalue magnitude
        # magnitude = abs(largest_eigenvalue(metric_tensor))
        # Option C: Trace
        # magnitude = trace(metric_tensor)
        
        # Step 2: Apply transfer function
        # If m >= 3, apply gradient portion separably [S1]
        color, opacity = transfer_function(sample.fields, magnitude)
        
        # Step 3 & 4: Attenuate and Modulate
        # The model attenuates light through the volume.
        # The "summed attenuation" implies an exponential decay based on density/gradient.
        # Standard volume rendering compositing:
        # C_out = C_in * T + C_sample * alpha * T
        # Here, the "lighting" aspect is the attenuation of the background/ambient light
        # or the modulation of the voxel color by the path's density.
        
        # The source states: "modulate the voxel's initial color by the summed attenuation"
        # This suggests the final color contribution is the initial color scaled by the 
        # transmittance of the path up to this point, or the local attenuation.
        # Given "attenuates light through the volume", we treat the gradient magnitude 
        # as contributing to extinction.
        
        # Calculate local extinction coefficient from magnitude [G]
        # Not explicitly defined in sources, but required for attenuation.
        # We assume magnitude maps to extinction sigma_t.
        sigma_t = magnitude 
        
        # Calculate transmittance for this segment [G]
        # Assuming unit step size or delta_s from ray marching
        delta_s = 1.0 
        segment_transmittance = exp(-sigma_t * delta_s)
        
        # Update accumulated transmittance
        accumulated_transmittance *= segment_transmittance
        
        # Modulate initial color by the accumulated attenuation (transmittance)
        # The source says "modulate the voxel's initial color by the summed attenuation"
        # This can be interpreted as the color contribution being:
        # C_contrib = color * accumulated_transmittance
        # However, standard compositing blends. The "atmospheric" nature suggests
        # the color is visible through the volume, scaled by how much light gets through.
        
        # Standard front-to-back compositing with the modulated color
        alpha = opacity
        if alpha > 0:
            # The "lighting" effect is the attenuation of the background light
            # or the modulation of the voxel's own emission/color.
            # We modulate the voxel color by the transmittance of the path *before* this voxel?
            # Or the path *through* the volume?
            # "Attenuates light through the volume" -> The light source is behind or ambient.
            # Let's assume the color is modulated by the accumulated transmittance from the viewer
            # to the point, or from the light to the point.
            # Given "atmospheric", it often implies light scattering/absorption.
            # We use the accumulated transmittance as the modulation factor for the color.
            modulated_color = color * accumulated_transmittance
            
            # Blend into result
            # C_final = C_prev * (1 - alpha) + modulated_color * alpha
            # But the source emphasizes "summed attenuation" modulating the color.
            # Let's stick to the core definition: Color is modulated by attenuation.
            accumulated_color = accumulated_color * (1 - alpha) + modulated_color * alpha
            
            accumulated_transmittance *= (1 - alpha)
        else:
            # No opacity, just pass through transmittance
            pass
            
    return accumulated_color
```

### Parameters
*   **Metric Tensor Norm:** The choice of L2 norm, largest eigenvalue, or trace [S1].
*   **Weights:** The diagonal weights $w_i$ in the weight matrix $W$ [S1].
*   **Separable Application:** For $m \ge 3$, the gradient transfer function is applied separably [S1].

### Edge Cases and Pitfalls
*   **Gradient Flip:** Using the eigenvector of the largest eigenvalue as a normal is problematic because the gradient can flip direction in local neighborhoods [S1][S2, unofficial]. The Atmospheric Lighting Model avoids this by not using a normal [S1][S2, unofficial].
*   **Ambiguous Eigenvalues:** The choice of eigenvector is unclear when two or more eigenvalues have the same or similar values [S1][S2, unofficial]. The Atmospheric Lighting Model avoids this ambiguity [S1][S2, unofficial].
*   **Orientation Mismatch:** The orientation of the multi-field gradient may not correspond to the surface of the classified region [S1][S2, unofficial]. The Atmospheric Lighting Model does not rely on surface orientation [S1][S2, unofficial].

## Operating characteristics
*   **Strengths:** Robustness in multi-field data visualization; avoids normal estimation artifacts (flipping, ambiguity); simple to implement; provides shape and curvature cues via attenuation [S1][S2, unofficial].
*   **Limitations:** Does not provide explicit surface normal-based shading (e.g., specular highlights); relies on attenuation which may be less intuitive for some features than normal-based lighting; requires computation of multi-field gradients and metric tensors [S1].
*   **Performance:** Computationally more expensive than scalar gradient lighting due to the need to compute the metric tensor and its eigenvalues/norm for multi-field data [S1].

## Background
The Atmospheric Lighting Model was introduced by Kniss, Hansen, Grenier, and Robinson in the context of visualizing multivariate meteorological simulations [S1]. It was developed to address the limitations of traditional lighting models when applied to multi-field data, where surface normals derived from gradients are unstable or misleading [S1][S2, unofficial]. The method was demonstrated on datasets involving temperature, humidity, and pressure fields [S1][S2, unofficial].
