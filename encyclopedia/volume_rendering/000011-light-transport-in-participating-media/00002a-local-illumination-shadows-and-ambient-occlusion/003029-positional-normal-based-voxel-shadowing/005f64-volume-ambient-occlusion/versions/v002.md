# Volume Ambient Occlusion

Also called: AO Field, Occlusion Field

## Overview
Volume Ambient Occlusion computes a scalar occlusion field from a density field, quantifying how much of the surrounding environment each voxel sees [S1]. It is primarily used to accelerate cloud rendering by approximating multiple scattering effects through a remapped occlusion field, offering a balance between efficiency and visual quality despite not being physically accurate [S1]. Unlike [Positional & Normal-Based Voxel Shadowing](6206-positional-normal-based-voxel-shadowing.md), which calculates directional shading based on face normals and block types, this method computes a per-voxel occlusion value by sampling the density field [S1].

## How it works
**Inputs and Outputs**
*   **Input:** A volume or VDB density field [S1].
*   **Output:** The input density field with an additional scalar field named `occlusion` [S1]. The `occlusion` field stores values where 0 indicates no occlusion and 1 indicates full occlusion [S1].

**Data Structures**
*   **Density Field:** The source field containing density values [S1].
*   **Occlusion Field:** A scalar field stored alongside the density field, with resolution defined by the `Resolution Ratio` parameter [S1].
*   **VDB Structure:** If the input is a VDB, the occlusion field is stored within the VDB structure, and the `Expand Voxels` parameter pads the active area to prevent out-of-bounds sampling during interpolation [S1].

**Numbered Steps**
1.  **Grid Setup:** Create the target occlusion grid at a resolution determined by `Resolution Ratio` relative to the input density field [S1].
2.  **VDB Padding:** If the input is a VDB, expand the active voxel area by `Expand Voxels` to ensure interpolation at render time does not sample outside the computed region [S1].
3.  **Ray Marching:** For each voxel in the target grid, march rays in multiple directions through the density field to compute transmittance [S1].
4.  **Accumulation:** Average the occlusion contributions from all sampled directions to produce the final scalar value [G].

**Formulas**
*   Transmittance update per step: $T_{new} = T_{old} \cdot e^{-\rho \cdot d_{scale} \cdot \Delta s}$ [G]
*   Occlusion contribution per direction: $O_{dir} = 1 - T_{final}$ [G]
*   Final voxel occlusion: $\text{occlusion}(v) = \frac{1}{|\mathcal{D}|} \sum_{\vec{d} \in \mathcal{D}} O_{dir}$ [G]
*   Where $\rho$ is the sampled density, $d_{scale}$ is `Density Scale`, $\Delta s$ is the step size, and $\mathcal{D}$ is the set of ray directions [G].

**Parameters**
*   **Resolution Ratio:** Defines the occlusion field resolution as a ratio of the density field resolution. A value of 0.5 yields half resolution. Smaller values are more efficient but less accurate [S1].
*   **Expand Voxels:** Expands the active area of the occlusion field by a specified number of voxels to prevent sampling outside the computed area during interpolation at render time. This parameter is only considered for VDBs; dense volumes are not affected [S1].
*   **Density Scale:** A multiplier applied to the density field for the occlusion computation only. The original density field remains untouched. A value of 0.1 makes the density appear ten times more transparent to the computation [S1].
*   **Transmission Cutoff:** The transmittance threshold below which a ray is considered fully occluded, terminating the marching process. A value of 0.005 means an occlusion value of 0.995 is treated as fully occluded. Larger values improve efficiency but reduce accuracy [S1].

**Pseudocode**
```python
def compute_volume_ambient_occlusion(density_field, resolution_ratio, expand_voxels, density_scale, transmission_cutoff):
    # 1. Setup target grid based on resolution_ratio [S1]
    target_grid = downsample_grid(density_field, resolution_ratio)
    
    # 2. Pad active area for VDBs if expand_voxels > 0 [S1]
    if is_vdb(density_field):
        target_grid = pad_active_area(target_grid, expand_voxels)
        
    occlusion_field = create_scalar_field(target_grid)
    directions = get_uniform_sphere_directions()  # Standard distribution [G]
    step_size = get_voxel_size(target_grid)
    
    for voxel in target_grid:
        total_occlusion = 0.0
        for d in directions:
            transmittance = 1.0
            pos = voxel.position + d * step_size
            # 3. March rays until fully occluded [S1]
            while transmittance > transmission_cutoff:
                density = density_field.sample(pos)
                # Apply density scale and exponential attenuation [G]
                transmittance *= exp(-density * density_scale * step_size)
                pos += d * step_size
            # 4. Accumulate contribution [G]
            total_occlusion += (1.0 - transmittance)
        # Average over directions and clamp to [0, 1] [G]
        occlusion_field[voxel] = clamp(total_occlusion / len(directions), 0.0, 1.0)
    return occlusion_field
```

**Edge Cases and Pitfalls**
*   **VDB Padding:** When using VDBs, failing to set `Expand Voxels` may cause the renderer to sample undefined values at the boundaries during interpolation, leading to artifacts [S1].
*   **Density Scale Interaction:** A high `Density Scale` will cause rays to terminate quickly, potentially underestimating occlusion in sparse regions if `Transmission Cutoff` is not adjusted accordingly [S1].
*   **Resolution Trade-off:** Lower `Resolution Ratio` speeds up computation but reduces the accuracy of the occlusion field [S1].

## Operating characteristics
*   **Time Complexity:** Not given in the sources.
*   **Memory Complexity:** Not given in the sources.
*   **Performance:** Smaller `Resolution Ratio` and larger `Transmission Cutoff` values improve efficiency but reduce accuracy [S1].
*   **Strengths:** Significantly accelerates cloud rendering by approximating multiple scattering effects [S1].
*   **Limitations:** Not physically accurate; relies on post-processing remapping for visual effect [S1].

## Background
Volume Ambient Occlusion was initially created to accelerate cloud rendering [S1]. It allows for the approximation of multiple scattering by remapping the occlusion field at render time, mapping dark values to cloud edges and bright values to the cloud interior [S1]. This technique was introduced in Houdini version 20.0 [S1].
