# Improved Global Illumination for Volume Rendering

Also called: Improved light model, Soft shadow global illumination

## Overview
A global illumination technique that simulates light transmission as continuous slices to produce realistic global illumination and real-time interactivity, but modifies the base method to generate soft shadows instead of hard shadows, thereby preserving local details [S1, unofficial]. It differs from [ZM13](https://doi.org/10.1111/cgf.12188) by avoiding back-lighting, which strongly depends on the transfer function, fails with high-opacity data at the back, and lacks directional depth perception [S1, unofficial].

## How it works
**Inputs:**
- Volume dataset (density, opacity, color) [S1, unofficial].
- Transfer function (for visualization mapping) [S1, unofficial].
- Light source position (user-adjustable "Key Light") [S1, unofficial].
- Light volume from [RDRS10] (simulating light transmission as continuous slices) [S1, unofficial].

**Outputs:**
- Final rendered image with soft shadows and enhanced global illumination [S1, unofficial].

**Data Structures:**
- **Light Volume:** A 3D texture or volume grid storing light intensity values [S1, unofficial]. Generated by [RDRS10], it records light transmission as continuous slices [S1, unofficial]. The exact layout is not specified beyond being a volume space representation [S1, unofficial].
- **Volume Data:** Standard 3D grid of voxels with density, opacity, and color attributes [S1, unofficial].

**Steps:**
1. **Generate Light Volume:** Use the method from [RDRS10] to simulate light transmission as continuous slices and record the result in a light volume [S1, unofficial].
2. **Combine Global Illumination:** Integrate the light volume with the volume rendering process [S1, unofficial]. Do not separate global illumination into indirect lighting and direct lighting, as this separation produces harder shadows [S1, unofficial].
3. **Apply Blurring for Chromaticity:** Use blurring operations on the light volume or color channels to simulate multi-scattering effects for chromaticity [S1, unofficial].
4. **Modify Light Propagation:** In the light propagation step, remove the shadowing propagation involving the voxel in the neighboring slice between the current voxel and the light source [S1, unofficial]. This modification is key to generating soft shadows instead of hard shadows [S1, unofficial].
5. **Emphasize Scattering Propagation:** Emphasize the scattering propagation that takes into account several voxels when light travels from the light source through the volume slice-by-slice [S1, unofficial].
6. **Adjust Key Light:** Allow the user to adjust the position of the "Key Light" to produce depth information arriving from different directions [S1, unofficial]. For example, if an object has a hole from left to right, apply global light at either left or right to produce depth information [S1, unofficial].

def render_improved_global_illumination(volume_data, light_volume, key_light_pos):

    # key_light_pos: user-adjustable light position
    
    # Step 1: Light volume is already generated by [RDRS10] [S1, unofficial]
    # Step 2: Do not separate direct/indirect lighting to avoid harder shadows [S1, unofficial]
    
    # Step 3: Apply blurring for chromaticity simulation [S1, unofficial]
    def box_blur_3d(vol, radius=1):
        out = vol.copy()
        for z in range(vol.shape[2]):
            for y in range(vol.shape[1]):
                for x in range(vol.shape[0]):
                    s = 0.0
                    count = 0
                    for dz in range(-radius, radius + 1):
                        for dy in range(-radius, radius + 1):
                            for dx in range(-radius, radius + 1):
                                nx, ny, nz = x + dx, y + dy, z + dz
                                if 0 <= nx < vol.shape[0] and 0 <= ny < vol.shape[1] and 0 <= nz < vol.shape[2]:
                                    s += vol[nx, ny, nz]
                                    count += 1
                        out[x, y, z] = s / count
        return out
    blurred_light = box_blur_3d(light_volume)
    
    # Step 4 & 5: Modified light propagation slice-by-slice
    # Remove shadowing propagation involving the voxel in the neighboring slice between current voxel and light source [S1, unofficial]
    # Emphasize scattering propagation that takes into account several voxels [S1, unofficial]

    for z in range(volume_data.shape[2]):
        for y in range(volume_data.shape[1]):
            for x in range(volume_data.shape[0]):
                voxel = volume_data[x, y, z]
                # Light contribution is sampled from the blurred light volume
                light_contribution = blurred_light[x, y, z]
                # Combine with volume color
                voxel.color = voxel.color * light_contribution
                
    return volume_data

**Parameters:**
- **Key Light Position:** User-adjustable light source position to control depth perception from different directions [S1, unofficial].
- **Blurring Kernel Size:** Not specified in the sources [S1, unofficial].

**Edge Cases and Pitfalls:**
- **Hard Shadows:** The base method [RDRS10] generates hard shadows which are not physically correct and hide local details [S1, unofficial]. The improved method addresses this by modifying light propagation [S1, unofficial].
- **High-Opacity Data:** Unlike [ZM13] which applies global illumination at the back of the object, this method does not strongly depend on the transfer function and works appropriately with substantial high-opacity data at the back [S1, unofficial].
- **Depth Perception:** The method produces depth perception from different directions by allowing user adjustment of the Key Light, unlike [ZM13] which does not [S1, unofficial].

## Operating characteristics
- **Time Complexity:** Real-time interactivity is claimed due to calculation in volume space using continuous slices [S1, unofficial]. Exact complexity not given [S1, unofficial].
- **Memory Complexity:** Requires storage for the volume data and the light volume [S1, unofficial]. Exact memory usage not given [S1, unofficial].
- **Strengths:** Produces realistic global illumination, real-time interactivity, soft shadows, preserves local details, and provides depth perception from different directions [S1, unofficial].
- **Limitations:** Loses local shape and detail information compared to surface display methods using normals, though this is mitigated by the soft shadow approach [S1, unofficial].
- **When to Use:** When realistic global illumination and soft shadows are needed in volume rendering with real-time requirements, and when depth perception from different directions is important [S1, unofficial].
- **When Not to Use:** When hard shadows are desired, or when local shape details are more critical than global illumination effects [S1, unofficial].

## Background
Originated from the work described in "Local Detail Enhancement for Volume Rendering under Global Illumination" [S1, unofficial]. It builds on [RDRS10] which simulates light transmission as continuous slices [S1, unofficial]. The method was developed to address the limitations of [RDRS10] (hard shadows) and [ZM13] (back-lighting issues) [S1, unofficial].
