# Approximate Image-Space Multidirectional Occlusion Shading (ISMOS)
Also called: Approximate Image-Space Multidirectional Occlusion Shading (ISMOS) model, ISMOS model

## Overview
ISMOS is a screen-space shading technique that computes multidirectional occlusion at the end of a direct volume rendering pipeline using rendered depth and normal buffers, simulating global illumination effects such as shadows and ambient occlusion without preprocessing [S1]. It differs from previous image-space models by sampling along the pixel-to-light ray instead of a hemisphere, enabling multiple directional lights with minor overhead [S1].

## How it works
**Inputs and Outputs:**
*   **Inputs:** Rendered frame buffers containing color, depth, and normal information for the volume [S1]. Light source parameters including position, type, area light radius $d$, and hemisphere radius $R$ [S1].
*   **Outputs:** Final shaded image with computed occlusion effects [S1].

**Data Structures:**
1.  **Depth Buffer:** Stores four front-most depth layers in the RGBA components of a single buffer [S1]. This allows layer differentiation according to transfer function settings [S1].
2.  **Transmittance Parameter Buffer:** Stores a single parameter $\beta$ per pixel in the Alpha (A) component of the color buffer [S1]. This parameter describes the functional form of opacity values over depth, approximating the volume transmittance [S1].

**Method Steps:**

1.  **Volume Rendering with Transmittance Approximation:**
    During the initial ray-casting pass, compute the discrete transmittance $T_n$ for samples along the ray [S1]. The continuous transmittance is defined as:
    $$ T(z) = \exp\left(-\int_0^z \alpha(z') \, dz'\right) $$
    In discrete form:
    $$ T_n \approx \prod_{j=1}^{n} \exp(-\alpha(z_j)\Delta z) $$
    where $n$ is the number of samples to reach depth $z$, $\Delta z$ is the distance between samples, and $\alpha$ is the opacity [S1].
    
    To avoid storing a list of transmittances, approximate the continuous transmittance $T(z)$ using a Gaussian function:
    $$ f(z) = \exp(-\beta z^2) $$
    where $\beta$ is a parameter to be approximated [S1]. Compute $\beta$ for each pixel using linear least-squares fitting to minimize the residual:
    $$ \text{Residual} = \sum_{i} \left(\beta z_i^2 - \log\left(\frac{1}{T_i}\right)\right)^2 $$
    The solution is:
    $$ \beta = (X^T X)^{-1} X^T y $$
    where $X = [z_1^2, \dots, z_n^2]$ and $y = [\log(1/T_1), \dots, \log(1/T_n)]$ [S1]. Store $\beta$ in the Alpha channel of the color buffer [S1].

2.  **Opacity Reconstruction:**
    Calculate approximate opacity $\alpha_{app}(z)$ at any depth $z$ using the fitted $\beta$:
    $$ \frac{f(z)}{f(z - \Delta z)} = \frac{T_n}{T_{n-1}} = \exp(-\alpha(z)\Delta z) $$
    $$ \alpha_{app}(z) = \frac{1}{\Delta z} \cdot \log\left(\frac{f(z - \Delta z)}{f(z)}\right) $$
    This allows on-the-fly calculation of opacity values for any depth layer [S1].

3.  **Occlusion Shading Pass:**
    Retrieve the four front-most depth layers from the depth buffer and the $\beta$ parameter from the Alpha channel of the color buffer [S1].
    
    *   **Light Sampling:** Place light sources on a hemisphere of radius $R$ centered at the image-space center [S1].
        *   **Point Light (Hard Shadow):** Use $N=1$ sample. $Occ_i$ is binary (0 or 1) [S1].
        *   **Area Light (Soft Shadow):** Use multiple samples [S1]. The light source is a disk with radius $d$ [S1]. Smaller $d$ generates harder shadows [S1].
        *   **Ambient Occlusion:** Use large $d$, small $R$, and place light at $\phi = \pi/2$ [S1].
    
    *   **Ray Marching for Occlusion:**
        Sample test points along a ray between the pixel and the light source [S1].
        Termination conditions for ray marching:
        1.  Ray position $r(t)$ is not between $(0,0,0)$ and $(1,1,1)$ [S1].
        2.  $Occ_i$ is one (fully occluded) [S1].
        3.  $t$ is one (reached light) [S1].
        
        Compute binary occlusion $Occ_i$ for each sample $i$:
        $$ Occ_i = \begin{cases} 1 & \text{if ray is blocked by volume} \\ 0 & \text{otherwise} \end{cases} $$
        
        Compute total occlusion $Occ$ for $N$ light samples:
        $$ Occ = \frac{\sum_{i=1}^{N} Occ_i}{N} $$
        For multiple light sources $j$, with $N_j$ samples and $No_j$ occluded samples:
        $$ Occ = \frac{\sum_{j} No_j}{\sum_{j} N_j} $$
        For partial occlusion (blending):
        $$ Occ = \frac{\sum_{j} \left(\sum_{i} Occ_i\right)}{\sum_{j} N_j} $$
        [S1]

    *   **Layer Application:**
        Differentiate layers according to transfer function settings [S1].
        *   **Opaque Layers:** Apply ISMOS occlusion if opacity $\alpha > \alpha_{th}$ [S1].
        *   **Transparent Layers:** Use local illumination (e.g., Phong shading) only, or blend ISMOS results across all layers [S1].

4.  **Final Color Computation:**
    Combine the base color with the occlusion factor [S1].

**Pseudocode:**

```python
import math

def compute_ismos(depth_buffer, color_buffer, light_sources, alpha_threshold, dz):
    """
    depth_buffer: (H, W, 4) float32, stores 4 depth layers in RGBA.
    color_buffer: (H, W, 4) float32, stores RGB color and beta in A.
    light_sources: List of dicts with keys: 'type', 'position', 'center', 'radius_d', 'radius_R', 'samples'.
    alpha_threshold: Float, threshold for opaque vs transparent layers.
    dz: Float, distance between samples during the initial ray-casting pass.
    """
    H, W, _ = depth_buffer.shape
    shaded_image = [[0.0, 0.0, 0.0, 1.0] for _ in range(H * W)]

    for y in range(H):
        for x in range(W):
            # 1. Retrieve layer depths and beta
            depths = depth_buffer[y][x]  # 4 depth values
            beta = color_buffer[y][x][3] # Beta parameter
            base_color = color_buffer[y][x][:3]

            # 2. Reconstruct opacity for each depth layer
            layer_opacities = []
            for i, z in enumerate(depths):
                if z <= 0.0:
                    layer_opacities.append(0.0)
                    continue
                # f(z) = exp(-beta * z^2)
                f_z = math.exp(-beta * z**2)
                f_z_minus_dz = math.exp(-beta * (z - dz)**2)
                # alpha_app(z) = (1/dz) * log(f(z-dz)/f(z))
                alpha_app = (1.0 / dz) * math.log(f_z_minus_dz / f_z)
                layer_opacities.append(alpha_app)

            # 3. Compute Occlusion
            total_occlusion = 0.0
            total_samples = 0

            for light in light_sources:
                if light['type'] == 'point':
                    N = 1
                elif light['type'] == 'area':
                    N = light.get('samples', 16)
                else: # ambient
                    N = light.get('samples', 16)

                occluded_count = 0
                for k in range(N):
                    # Sample light position
                    if light['type'] == 'point':
                        sample_pos = list(light['position'])
                    elif light['type'] == 'area':
                        # Sample on disk radius d around center
                        r = math.sqrt(math.random()) * light['radius_d']
                        theta = math.random() * 2 * math.pi
                        sample_pos = [
                            light['center'][0] + r * math.cos(theta),
                            light['center'][1] + r * math.sin(theta),
                            light['center'][2]
                        ]
                    else: # ambient
                        # phi = pi/2, small R
                        sample_pos = [0.0, light['radius_R'], 0.0]

                    # Ray from pixel to light sample (in NDC/camera space)
                    ray_origin = [x / (W-1), y / (H-1), depths[0]]
                    ray_direction = [sample_pos[i] - ray_origin[i] for i in range(3)]
                    norm = math.sqrt(sum(v**2 for v in ray_direction))
                    ray_direction = [v / norm for v in ray_direction]

                    # Ray march
                    is_occluded = False
                    t = 0.0
                    step = 0.01 # Step size not specified in sources; typical value used in practice [G]
                    while t < 1.0:
                        current_pos = [ray_origin[i] + ray_direction[i] * t for i in range(3)]
                        # Termination: bounds check (0,0,0) to (1,1,1)
                        if not (0.0 <= current_pos[0] <= 1.0 and 0.0 <= current_pos[1] <= 1.0 and 0.0 <= current_pos[2] <= 1.0):
                            break
                        # Project to screen (identity in NDC)
                        sx = int(current_pos[0] * (W-1))
                        sy = int(current_pos[1] * (H-1))
                        if 0 <= sx < W and 0 <= sy < H:
                            # Get depth at screen position (front-most layer)
                            depth_at_ray_point = depth_buffer[sy][sx][0]
                            # Shadow ray logic: if buffer depth < ray depth, geometry blocks light
                            if depth_at_ray_point < current_pos[2]:
                                is_occluded = True
                                break
                        t += step

                    if is_occluded:
                        occluded_count += 1

                total_occlusion += occluded_count
                total_samples += N

            occ_factor = total_occlusion / total_samples if total_samples > 0 else 0.0

            # 4. Apply Shading
            front_alpha = layer_opacities[0]
            if front_alpha > alpha_threshold:
                shaded_color = [base_color[i] * (1.0 - occ_factor) for i in range(3)]
            else:
                shaded_color = base_color # Local illumination fallback

            idx = y * W + x
            shaded_image[idx] = shaded_color + [1.0]

    return shaded_image
```

**Edge Cases and Pitfalls:**
*   **Precision:** The least-squares fitting for $\beta$ assumes the transmittance follows a Gaussian-like decay. If the volume has complex internal structures, the approximation may be inaccurate [S1].
*   **Boundaries:** Ray marching termination must handle cases where the ray exits the volume bounds $(0,0,0)$ to $(1,1,1)$ [S1].
*   **Degenerate Input:** If $\beta$ is zero or very small, the opacity approximation may fail. Guard against division by zero in log operations [G].
*   **Layer Differentiation:** Storing only 4 layers limits the complexity of transparent scenes. More layers require more buffers [S1].

## Operating characteristics
*   **Time Complexity:** Computation scales with screen size (resolution) rather than volume data size [S1]. It is computationally less expensive than global illumination models [S1].
*   **Memory Complexity:** Requires no extra GPU memory for the entire volume data. Only standard frame buffers (color, depth, normals) and one additional parameter ($\beta$) per pixel are needed [S1].
*   **Strengths:** Interactive transfer function manipulations and light position changes are achievable without preprocessing [S1]. Simulates hard shadows, soft shadows, and ambient occlusion in a unified model [S1].
*   **Limitations:** Approximation of transmittance may not capture fine details. Limited to 4 depth layers by default [S1].

## Background
ISMOS was proposed in 2021 by authors published in *Applied Sciences* (MDPI) [S1]. It addresses the lack of interactivity in previous global illumination models for volume rendering, which required preprocessing and extra GPU memory [S1]. It builds on image-space techniques but extends them to multidirectional lighting by sampling along pixel-to-light rays [S1].
