# Approximate Image-Space Multidirectional Occlusion Shading (ISMOS)
Also called: Approximate Image-Space Multidirectional Occlusion Shading (ISMOS) model, ISMOS model

## Overview
ISMOS is a screen-space shading technique that computes multidirectional occlusion at the end of a direct volume rendering pipeline using rendered depth and normal buffers, simulating global illumination effects such as shadows and ambient occlusion without preprocessing [S1]. It differs from previous image-space models by sampling along the pixel-to-light ray instead of a hemisphere, enabling multiple directional lights with minor overhead [S1].

## How it works
**Inputs and Outputs:**
*   **Inputs:** Rendered frame buffers containing color, depth, and normal information for the volume [S1]. Light source parameters (position, type, radius $d$, hemisphere radius $R$) [S1].
*   **Outputs:** Final shaded image with occlusion effects [S1].

**Data Structures:**
1.  **Depth Buffer:** Stores four front-most depth layers in the RGBA components of a single buffer [S1]. This allows differentiation of layers based on transfer function settings [S1].
2.  **Transmittance Parameter Buffer:** Stores a single parameter $\beta$ per pixel in the Alpha (A) component of the color buffer [S1]. This parameter describes the functional form of opacity values over depth, approximating the volume transmittance [S1].

**Method Steps:**

1.  **Volume Rendering with Transmittance Approximation:**
    During the initial ray-casting pass, compute the discrete transmittance $T_n$ for samples along the ray [S1]. The transmittance is defined as:
    $$ T(z) = \exp\left(-\int_0^z \alpha(z') \, dz'\right) $$
    In discrete form:
    $$ T_n \approx \prod_{j=1}^{n} \exp(-\alpha(z_j)\Delta z) $$
    where $n$ is the number of samples to reach depth $z$, $\Delta z$ is the distance between samples, and $\alpha$ is the opacity [S1].
    
    To avoid storing a list of transmittances, approximate the continuous transmittance $T(z)$ using a Gaussian function:
    $$ f(z) = \exp(-\beta z^2) $$
    where $\beta$ is a parameter to be approximated [S1]. Compute $\beta$ for each pixel using linear least-squares fitting to minimize the residual:
    $$ \text{Residual} = \sum_{i} \left(\beta z_i^2 - \log\left(\frac{1}{T_i}\right)\right)^2 $$
    The solution is:
    $$ \beta = (X^T X)^{-1} X^T y $$
    where $X = [z_1^2, \dots, z_n^2]$ and $y = [\log(1/T_1), \dots, \log(1/T_n)]$ [S1]. Store $\beta$ in the Alpha channel of the color buffer [S1].

2.  **Opacity Reconstruction:**
    Calculate approximate opacity $\alpha_{app}(z)$ at any depth $z$ using the fitted $\beta$:
    $$ \frac{f(z)}{f(z - \Delta z)} = \frac{T_n}{T_{n-1}} = \exp(-\alpha(z)\Delta z) $$
    $$ \alpha_{app}(z) = \frac{1}{\Delta z} \cdot \log\left(\frac{f(z - \Delta z)}{f(z)}\right) $$
    This allows on-the-fly calculation of opacity values for any depth layer [S1].

3.  **Occlusion Shading Pass:**
    For each pixel, retrieve the depth layers and the $\beta$ parameter [S1].
    
    *   **Light Sampling:** Place light sources on a hemisphere of radius $R$ centered at the image-space center [S1].
        *   **Point Light (Hard Shadow):** Use $N=1$ sample. $Occ_i$ is binary (0 or 1) [S1].
        *   **Area Light (Soft Shadow):** Use multiple samples. The light source is a disk with radius $d$. Smaller $d$ generates harder shadows [S1].
        *   **Ambient Occlusion:** Use large $d$, small $R$, and place light at $\phi = \pi/2$ [S1].
    
    *   **Ray Marching for Occlusion:**
        Sample test points along a ray between the pixel and the light source [S1].
        Termination conditions for ray marching:
        1.  Ray position $r(t)$ is not between $(0,0,0)$ and $(1,1,1)$ [S1].
        2.  $Occ_i$ is one (fully occluded) [S1].
        3.  $t$ is one (reached light) [S1].
        
        Compute binary occlusion $Occ_i$ for each sample $i$:
        $$ Occ_i = \begin{cases} 1 & \text{if ray is blocked by volume} \\ 0 & \text{otherwise} \end{cases} $$
        
        Compute total occlusion $Occ$ for $N$ light samples:
        $$ Occ = \frac{\sum_{i=1}^{N} Occ_i}{N} $$
        For multiple light sources $j$, with $N_j$ samples and $No_j$ occluded samples:
        $$ Occ = \frac{\sum_{j} No_j}{\sum_{j} N_j} $$
        For partial occlusion (blending):
        $$ Occ = \frac{\sum_{j} \left(\sum_{i} Occ_i\right)}{\sum_{j} N_j} $$
        [S1]

    *   **Layer Application:**
        Differentiate layers according to transfer function settings [S1].
        *   **Opaque Layers:** Apply ISMOS occlusion if opacity $\alpha > \alpha_{th}$ [S1].
        *   **Transparent Layers:** Use local illumination (e.g., Phong shading) only, or blend ISMOS results across all layers [S1].

4.  **Final Color Computation:**
    Combine the base color with the occlusion factor [S1].

**Pseudocode:**

```python
def compute_ismos(depth_buffer_rgba, color_buffer_rgba, light_sources, alpha_threshold):
    """
    depth_buffer_rgba: Array of shape (H, W, 4), storing 4 depth layers in RGBA.
    color_buffer_rgba: Array of shape (H, W, 4), storing RGB color and Beta in A.
    light_sources: List of light source objects with position, type, radius d, radius R.
    alpha_threshold: Float, threshold for opaque vs transparent layers.
    """
    shaded_image = np.zeros_like(color_buffer_rgba)
    
    for y in range(H):
        for x in range(W):
            # 1. Retrieve layer depths and beta
            depths = depth_buffer_rgba[y, x]  # 4 depth values
            beta = color_buffer_rgba[y, x, 3] # Beta parameter
            
            # 2. Determine which layers to shade
            # Reconstruct opacity for each depth layer using beta
            layer_opacities = []
            for i, z in enumerate(depths):
                if z == 0: # Empty space
                    layer_opacities.append(0.0)
                    continue
                # f(z) = exp(-beta * z^2)
                f_z = np.exp(-beta * z**2)
                # Approximate delta_z from previous layer or use fixed step
                # Assuming uniform sampling step dz for simplicity in reconstruction
                # In practice, dz might be derived from ray marching step
                dz = 0.01 # Placeholder for actual step size from rendering pass
                f_z_minus_dz = np.exp(-beta * (z - dz)**2)
                
                # alpha_app(z) = (1/dz) * log(f(z-dz)/f(z))
                alpha_app = (1.0 / dz) * np.log(f_z_minus_dz / f_z)
                layer_opacities.append(alpha_app)
            
            # 3. Compute Occlusion for relevant layers
            total_occlusion = 0.0
            num_light_samples_total = 0
            
            for light in light_sources:
                # Determine number of samples N based on light type
                if light.type == 'point':
                    N = 1
                elif light.type == 'area':
                    N = light.samples # e.g., 16
                else: # ambient
                    N = light.samples
                
                occluded_count = 0
                
                for k in range(N):
                    # Generate sample point on light source
                    # For point: light.position
                    # For area: random point on disk radius d
                    # For ambient: fixed position based on phi=pi/2
                    sample_pos = light.get_sample_point(k)
                    
                    # Ray from pixel to light sample
                    ray_origin = get_pixel_world_pos(x, y, depths[0]) # Front-most layer
                    ray_direction = normalize(sample_pos - ray_origin)
                    
                    # Ray march to check occlusion
                    is_occluded = False
                    t = 0.0
                    step_size = 0.01
                    
                    while t < 1.0: # t is normalized distance to light
                        # Check if ray is within volume bounds (0,0,0) to (1,1,1)
                        current_pos = ray_origin + ray_direction * t
                        if not is_inside_volume(current_pos):
                            break
                            
                        # Check if current position is inside volume
                        # Use depth buffer to find if there is geometry closer than the light path
                        # Or use the reconstructed opacity from beta
                        # Simplified: Check if depth at current screen pos is closer than light
                        # But ISMOS samples along the ray in world space or screen space?
                        # Source says "sample test points along a ray between the pixel and the light source"
                        # and "uses rendered depth and normal buffers"
                        
                        # Project current_pos to screen space to check depth
                        screen_pos = project_to_screen(current_pos)
                        if screen_pos is valid:
                            # Get depth at this screen position
                            depth_at_ray_point = get_depth_from_buffer(screen_pos)
                            
                            # If the volume surface at this screen position is closer to camera
                            # than the current ray point, it's occluded.
                            # However, we are marching from pixel TO light.
                            # If we hit a surface that is "in front" of the light path relative to camera?
                            # Actually, standard shadow ray: if any geometry blocks the path.
                            # In image space, we check if the depth buffer value at the projected
                            # ray point is less than the depth of the ray point itself?
                            # No, the ray point IS the point in space.
                            # We need to know if there is volume between ray_origin and current_pos.
                            
                            # Alternative interpretation from source:
                            # "sample test points along a ray... to calculate light transfer"
                            # "Occ_i is one" if occluded.
                            
                            # Let's assume we march and check density/opacity.
                            # Since we have beta, we can estimate opacity at current_pos depth?
                            # But current_pos is in world space.
                            
                            # Simpler approach for Image Space:
                            # The ray is defined in screen space coordinates?
                            # No, light is in world space.
                            
                            # Let's use the depth buffer to check occlusion.
                            # If we are at 't' along the ray to light, we project this point.
                            # If the depth buffer at that projection shows a surface CLOSER to the camera
                            # than the point 't' on the ray, then that surface blocks the light.
                            
                            # Wait, the ray starts at the pixel (closest) and goes to light (farthest).
                            # So if we find ANY surface in the depth buffer that is closer to the camera
                            # than the current ray point 't', it blocks the light.
                            
                            # But the depth buffer stores the front-most surface.
                            # If the front-most surface is closer than 't', it blocks.
                            
                            # However, we are marching FROM the pixel.
                            # The pixel itself is at depth d0.
                            # The light is at depth d_light.
                            # We march t from 0 to 1.
                            # At t, we are at depth d(t).
                            # If depth_buffer[screen_pos] < d(t), then there is something closer.
                            # But depth_buffer[screen_pos] IS d(t) if we are on the surface.
                            # If we are in empty space, depth_buffer[screen_pos] is the surface behind.
                            
                            # Correct logic for shadow ray in image space:
                            # Project the test point P(t) to screen.
                            # Get depth D_screen from buffer.
                            # Get depth D_ray of P(t) in camera space.
                            # If D_screen < D_ray, then the surface in the buffer is closer to camera
                            # than P(t), meaning it blocks the light from reaching P(t).
                            
                            if depth_at_ray_point < current_pos.z: # Assuming z is depth
                                is_occluded = True
                                break
                                
                        t += step_size
                        
                    if is_occluded:
                        occluded_count += 1
                
                num_light_samples_total += N
                total_occlusion += occluded_count
            
            # Compute final occlusion factor
            if num_light_samples_total > 0:
                occ_factor = total_occlusion / num_light_samples_total
            else:
                occ_factor = 0.0
            
            # 4. Apply Shading
            # Base color from volume rendering
            base_color = color_buffer_rgba[y, x, :3]
            
            # Check if layer is opaque enough to apply ISMOS
            # Use the front-most layer's opacity
            front_alpha = layer_opacities[0]
            
            if front_alpha > alpha_threshold:
                # Apply occlusion
                shaded_color = base_color * (1.0 - occ_factor) # Simplified shading
                # Or: shaded_color = base_color * (1.0 - occ_factor * intensity)
            else:
                # Transparent: Use local illumination (Phong)
                # This part is not fully detailed in sources, so we use base color
                shaded_color = base_color
                
            shaded_image[y, x, :3] = shaded_color
            shaded_image[y, x, 3] = 1.0 # Opaque output
            
    return shaded_image
```

**Edge Cases and Pitfalls:**
*   **Precision:** The least-squares fitting for $\beta$ assumes the transmittance follows a Gaussian-like decay. If the volume has complex internal structures, the approximation may be inaccurate [S1].
*   **Boundaries:** Ray marching termination must handle cases where the ray exits the volume bounds $(0,0,0)$ to $(1,1,1)$ [S1].
*   **Degenerate Input:** If $\beta$ is zero or very small, the opacity approximation may fail. Guard against division by zero in log operations [G].
*   **Layer Differentiation:** Storing only 4 layers limits the complexity of transparent scenes. More layers require more buffers [S1].

## Operating characteristics
*   **Time Complexity:** Computation scales with screen size (resolution) rather than volume data size [S1]. It is computationally less expensive than global illumination models [S1].
*   **Memory Complexity:** Requires no extra GPU memory for the entire volume data. Only standard frame buffers (color, depth, normals) and one additional parameter ($\beta$) per pixel are needed [S1].
*   **Strengths:** Interactive transfer function manipulations and light position changes are achievable without preprocessing [S1]. Simulates hard shadows, soft shadows, and ambient occlusion in a unified model [S1].
*   **Limitations:** Approximation of transmittance may not capture fine details. Limited to 4 depth layers by default [S1].

## Background
ISMOS was proposed in 2021 by authors published in *Applied Sciences* (MDPI) [S1]. It addresses the lack of interactivity in previous global illumination models for volume rendering, which required preprocessing and extra GPU memory [S1]. It builds on image-space techniques but extends them to multidirectional lighting by sampling along pixel-to-light rays [S1].
