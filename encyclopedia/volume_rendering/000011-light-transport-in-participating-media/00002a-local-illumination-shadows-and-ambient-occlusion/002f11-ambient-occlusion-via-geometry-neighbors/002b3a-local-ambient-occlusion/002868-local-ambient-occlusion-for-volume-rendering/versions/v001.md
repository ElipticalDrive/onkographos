# Local Ambient Occlusion for Volume Rendering

Also called: Ambient Occlusion Volume Rendering with Local Vicinity Statistics, High-Speed Ambient Occlusion Volume Rendering, Probabilistic Ambient Occlusion for Volume Rendering

## Overview
This method calculates ambient occlusion (AO) for volume rendering by estimating the probability of occlusion based on the statistical distribution of CT values in the local vicinity of each sample [S1]. It assumes these values follow a normal distribution, allowing the integration of opacity over this distribution to be solved analytically rather than numerically [S1]. This approach provides superior spatial and depth cues compared to local illumination alone, such as clearer definition of the human ear depth or vertebrae spaces [S1]. It sets itself apart from basic numerical integration by reducing the computational complexity from being proportional to the CT value range (e.g., 4096 iterations for 12-bit data) to being proportional only to the number of linear segments in the Transfer Function (TF) [S1].

## How it works
### Inputs and Outputs
**Inputs:**
1.  Volume dataset (CT values).
2.  Transfer Function (TF): Defined as a piecewise linear function with $k$ segments.
3.  Window size ($w$): The dimension of the local vicinity cube (e.g., $w \times w \times w$) used to calculate statistics.
4.  Ray parameters: Origin and direction for volume traversal.

**Outputs:**
1.  Final color for each pixel, incorporating the ambient occlusion factor.

### Data Structures
1.  **Lookup Table for Cumulative Normal Distribution**: An array storing values of $N(x)$, the cumulative standard normal distribution, for $O(1)$ access. The range and resolution depend on implementation needs, but standard floating-point precision is implied [S1].
2.  **Precomputed Local Statistics**: For each voxel (or sample position), the mean ($m$) and standard deviation ($\sigma$) of the CT values in the local vicinity. These are calculated in a preprocessing step [S1].
3.  **TF Segment Representation**: A list of $k$ segments, where each segment $i$ is defined by coefficients $a_i, b_i$ and bounds $n_i, n_{i+1}$ [S1].

### Numbered Steps

1.  **Preprocessing: Calculate Local Statistics**
    For each voxel in the volume, calculate the mean ($m$) and standard deviation ($\sigma$) of the CT values within a cubic window of size $w \times w \times w$ centered on that voxel. This is done in constant time using precomputed sums [S1].
    *   Let $Avg3D(s, t, u)$ be the average CT value in the window.
    *   Let $SquaredAvg3D(s, t, u)$ be the average of the squared CT values in the window.
    *   $\sigma^2 = SquaredAvg3D(s, t, u) - Avg3D(s, t, u)^2$ [S1].

2.  **TF Simplification (Optional but Recommended for Speed)**
    If the TF is hand-drawn or complex, simplify it to reduce the number of line segments $k$. This is done using an error-tolerance method (e.g., Hadwiger et al.) where simplified segments must pass through windows defined for each vertex [S1]. Increasing the window size for simplification reduces $k$, increasing speed but degrading image quality. Quality stabilizes at a simplification window size of 10 [S1].

3.  **Rendering: Ray Marching and AO Calculation**
    For each sample point along the ray:
    a. Retrieve the precomputed mean $m$ and standard deviation $\sigma$ for the sample's location [S1].
    b. The ambient occlusion factor is calculated by integrating the product of the TF opacity $\alpha(x)$ and the probability density $\rho(x)$ of the local CT values [S1]:
       $$ AO = \int_{-\infty}^{\infty} \alpha(x)\rho(x)dx $$
    c. Since $\alpha(x)$ is piecewise linear and $\rho(x)$ is assumed to be a normal distribution $N(m, \sigma^2)$, the integral is computed segment by segment [S1].

4.  **Analytical Integration per Segment**
    For each segment $i$ of the TF, defined by $\alpha(x) = a_i x + b_i$ for $n_i \le x < n_{i+1}$:
    a. Transform the segment coefficients and bounds to the standard normal space $N(0,1)$ using the normalized variable $z = \frac{x-m}{\sigma}$:
       $$ a'_i = \sigma a_i $$
       $$ b'_i = b_i + a_i m $$
       $$ n'_i = \frac{n_i - m}{\sigma} $$
       $$ n'_{i+1} = \frac{n_{i+1} - m}{\sigma} $$
    b. Calculate the contribution $Seg_i$ of this segment using the lookup table for $N(x)$:
       $$ Seg_i = \frac{a'_i}{\sqrt{2\pi}} \left( e^{-n_i'^2/2} - e^{-n_{i+1}'^2/2} \right) + b'_i \left( N(n'_{i+1}) - N(n'_i) \right) $$
       Note: The source formula in [S1] uses $a_i$ in the final expression but defines the transformation for $N(0,1)$ integration. The term $\frac{1}{\sqrt{2\pi}}$ comes from the standard normal PDF. The source explicitly writes:
       $$ Seg_i = \frac{a_i}{\sqrt{2\pi}} (e^{-n_i^2/2} - e^{-n_{i+1}^2/2}) + b_i (N(n_{i+1}) - N(n_i)) $$
       for standard normal, and applies the transformation to $a, b, n$ before using this formula. We will use the transformed variables $a', b', n', n'_{next}$ in the implementation logic below for clarity.
    c. Sum the contributions:
       $$ AO = \sum_{i=1}^{k} Seg_i $$
    d. The AO value ranges from 0 to 1. A value closer to 1.0 indicates darker shading (more occlusion) [S1].

5.  **Lighting Application**
    Use the calculated AO factor to modulate the ambient or diffuse lighting component of the sample's color [S1].

### Pseudocode

```python
import math

# Precomputed Lookup Table for Cumulative Standard Normal Distribution N(x)
# In practice, this is an array indexed by x * scale_factor
def get_N(x):
    # Placeholder for actual LUT access. 
    # For implementation, use a standard approximation or precomputed array.
    # [G] Using a standard approximation for N(x) if LUT is not provided.
    return 0.5 * (1 + math.erf(x / math.sqrt(2)))

def calculate_segment_contribution(a_prime, b_prime, n_start, n_end):
    """
    Calculates Seg_i for a segment transformed to standard normal space.
    Formula: Seg_i = (a' / sqrt(2pi)) * (exp(-n_start^2/2) - exp(-n_end^2/2)) 
                 + b' * (N(n_end) - N(n_start))
    """
    sqrt_2_pi = math.sqrt(2 * math.pi)
    
    term1 = (a_prime / sqrt_2_pi) * (math.exp(-0.5 * n_start**2) - math.exp(-0.5 * n_end**2))
    term2 = b_prime * (get_N(n_end) - get_N(n_start))
    
    return term1 + term2

def compute_ao(m, sigma, tf_segments):
    """
    Computes Ambient Occlusion for a sample with local statistics m, sigma
    and a piecewise linear TF defined by segments.
    
    Args:
        m: Mean of local CT values.
        sigma: Standard deviation of local CT values.
        tf_segments: List of dicts, each with keys 'a', 'b', 'n_start', 'n_end'.
                     Represents alpha(x) = a*x + b for n_start <= x < n_end.
    
    Returns:
        AO value between 0 and 1.
    """
    ao_sum = 0.0
    
    for seg in tf_segments:
        a = seg['a']
        b = seg['b']
        n_start = seg['n_start']
        n_end = seg['n_end']
        
        # Transform to standard normal space N(0,1)
        # x = sigma * z + m  =>  z = (x - m) / sigma
        # a*x + b = a*(sigma*z + m) + b = (a*sigma)*z + (b + a*m)
        
        a_prime = sigma * a
        b_prime = b + a * m
        
        n_start_prime = (n_start - m) / sigma
        n_end_prime = (n_end - m) / sigma
        
        # Calculate contribution
        seg_val = calculate_segment_contribution(a_prime, b_prime, n_start_prime, n_end_prime)
        ao_sum += seg_val
        
    return ao_sum

# Example Usage in Ray Marching Loop
# For each sample along ray:
#   m, sigma = get_local_stats(sample_position)
#   ao = compute_ao(m, sigma, tf_segments)
#   color = apply_lighting(color, ao)
```

### Parameters
*   **Window Size ($w$)**: The dimension of the local vicinity cube. A window size of 8 provides a 40x performance improvement with ~40 dB SNR. Quality stabilizes at a simplification window size of 10 [S1].
*   **$k$**: The number of line segments in the piecewise linear TF. Performance is $O(k)$ [S1].

### Edge Cases and Pitfalls
*   **Non-Normal Distributions**: The method assumes CT values follow a normal distribution. If the actual distribution is binary or bimodal with the same mean and standard deviation as a normal distribution, the lighting will be inaccurate. For example, two regions with identical mean (30) and std (20) but different transparent voxel counts will receive the same AO, even if one should be brighter [S1].
*   **Precision**: The method replaces 4096 iterations (for 12-bit CT) with $k$ iterations. If $k$ is too small due to aggressive simplification, visual artifacts may occur [S1].

## Operating characteristics
*   **Time Complexity**: $O(k)$ per sample, where $k$ is the number of TF segments. This is a significant reduction from $O(R)$ where $R$ is the CT value range (e.g., 4096 for 12-bit) [S1].
*   **Memory Complexity**: Requires storage for local statistics ($m, \sigma$) for each voxel, and a lookup table for $N(x)$ [S1].
*   **Performance**: Achieves approximately 40x faster rendering compared to unaccelerated numerical integration. With a window size of 8, SNR is ~40 dB, making the image visually indistinguishable from the original [S1].
*   **Strengths**: Enables real-time rendering with complex, hand-drawn TFs. Provides better depth cues than local illumination alone.
*   **Limitations**: Accuracy degrades if the local CT distribution is not normal. Simplification of TF can introduce artifacts if the window size is too large [S1].

## Background
This method was proposed in 2019 by researchers publishing in *Human-Intelligent Systems* (Hir). It builds upon previous work [14] that calculated local vicinity statistics for AO in volumes. The key innovation was deriving a general equation for piecewise linear TFs to allow real-time rendering with hand-drawn curves, and applying TF simplification to further reduce computational cost [S1].
