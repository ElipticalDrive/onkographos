# Local Ambient Occlusion (LAO)

Also called: LAO Renderer, Local Ambient Occlusion (LAO) in DVR, Volumetric Ambient Occlusion

## Overview
Local Ambient Occlusion (LAO) is a local shading technique that estimates light contributions from neighboring voxels rather than the entire volume, creating softer shadows and avoiding the complete occlusion of volume parts often seen in global lighting methods [S1][S3, unofficial]. It stands mid-way between local and global shading by sampling an arbitrary number of neighboring voxels in arbitrary directions to simulate ambient occlusion effects [S1][S2, unofficial].

## How it works
LAO evaluates visibility or illumination at a specific point $\mathbf{p}$ within the volume by branching rays towards random directions within a hemisphere and tracing voxels to average accumulated translucency [S3, unofficial]. The method can be implemented via a two-pass pipeline or an incremental per-frame update, depending on the hardware and accuracy requirements [S4, unofficial].

### Inputs and Outputs
*   **Inputs:** Volume data (scalar field), Transfer Functions for Color ($TF_c$) and Emission ($TF_E$), light direction $\mathbf{l}$, and LAO parameters (kernel size, radius, step size).
*   **Outputs:** A Local Ambient Occlusion (LAO) map stored in a Frame Buffer Object (FBO) or integrated directly into the final ray-casting color buffer [S4, unofficial].

### Data Structures
1.  **LAO Map:** Stored in a Frame Buffer Object (FBO). The FBO planes correspond to screen coordinates $(x, y)$ and store intensity/light computation results [S4, unofficial].
2.  **Multiresolution Volume (Optional):** For optimized performance, volumes are organized into a multiresolution representation (e.g., packed textures with high, middle, and low resolution blocks) to allow empty space skipping [S4, unofficial][S5].
3.  **Indices:** Mapping indices $V \to P$ (Volume to Pixel) and $P \to V$ (Pixel to Volume) are used to map packed coordinates to volume coordinates [S4, unofficial].

### Parameters
*   `uNumLAOSamples` (LAOKernelSize): Number of ray directions to branch. Default: 1 [S2, S3, unofficial].
*   `uLAOStepSize`: Step size for LAO ray marching. Default: 0.05 [S2, unofficial].
*   `uLightRadious`: Radius of the light source used for LAO sampling. Default: 0.19 [S2, unofficial].
*   `uLightCoeficient`: Coefficient used to normalize LAO accumulation. Default: 1.0 [S2, unofficial].
*   `uLAOWeight`: Weight applied to the LAO contribution when mixing into the final color. Default: 0.69 [S2, unofficial].
*   `uLocalAmbientOcclusion`: Boolean flag to enable/disable LAO. Default: true [S2, unofficial].
*   `LAOKernelRadius`: Number of voxels traced in each direction [S3, unofficial].
*   `K`: Number of directions sampled (e.g., 1 or 8) [S4, unofficial].

### Algorithm Steps
The implementation varies slightly between the incremental GPU-based approach [S4, unofficial] and the discrete sampling approach [S2, S3, unofficial]. The following pseudocode combines the core logic: generating random directions, marching rays, accumulating translucency, and integrating emission.

```python
def compute_lao(position, light_direction, volume_data, params):
    """
    Computes Local Ambient Occlusion contribution for a given position.
    
    Args:
        position: vec3, current sample position in volume.
        light_direction: vec3, direction to the light source.
        volume_data: function, samples volume at (x,y,z) returning opacity/density.
        params: dict containing uNumLAOSamples, uLAOStepSize, uLightRadious, etc.
        
    Returns:
        float, LAO contribution factor (0.0 to 1.0).
    """
    # 1. Initialize accumulator
    accumu_lao = 0.0
    num_samples = params.get('uNumLAOSamples', 1)
    
    # 2. Loop over number of LAO samples (directions)
    for i in range(num_samples):
        # Generate random direction within hemisphere around light vector
        # Note: Specific random generation varies by implementation [S2, S4, unofficial]
        # S2 suggests: normalize(-1.0 + 2.0 * vec3(rand())) * rand()
        # S4 suggests dynamically configured directions (tetrahedron/icosahedron subdivision)
        random_dir = generate_random_direction_in_hemisphere(light_direction)
        
        # 3. March along the ray
        ray_accum = 0.0
        t = 0.001
        step = params.get('uLAOStepSize', 0.05)
        
        # Inner loop: trace voxels in this direction
        while t <= 1.0:
            # Compute LAO half vector or sample position
            # S2 formula: laoHalfVector = normalize(vLight + randomDirection * mix(0.0, uLightRadious, t) - position)
            # Simplified for general implementation:
            sample_pos = position + random_dir * t
            
            # Sample volume at current position
            # Returns opacity/translucency value
            lao_sample = volume_data(sample_pos)
            
            # Weight by distance squared (inverse square falloff approximation)
            # S2: weight = (1.0 - t)^2
            weight = pow(1.0 - t, 2.0)
            
            # Add to accumulator
            ray_accum += lao_sample * weight
            
            # Increment step
            t += step
            
        # Normalize ray accumulation by light coefficient
        # S2: divide by uLightCoeficient
        normalized_ray = ray_accum / params.get('uLightCoeficient', 1.0)
        
        # Add to total LAO accumulator
        accumu_lao += normalized_ray

    # 4. Final normalization and clamping
    # S2: divide by uNumLAOSamples
    if num_samples > 0:
        lao_contribution = accumu_lao / num_samples
    else:
        lao_contribution = 0.0
        
    # Clamp to [0, 1]
    lao_contribution = clamp(lao_contribution, 0.0, 1.0)
    
    return lao_contribution
```

### Emissive Tissue Illumination Variant
To simulate single light scattering of luminous objects, the incident light equation is modified to include colored light emission $c_E(s)$ from sample points along the ray [S5].

**Formula:**
$$ I_k(x) = \int_{a}^{R_\Omega} \frac{(1 + c_E(s)) \exp\left(-\int_{a}^{s} \tau(u)du\right) ds}{R_\Omega - a} $$

Where:
*   $c_E(s)$: Colored light emission parameter at sample point $s$, controlled by the emissive component in the transfer function [S5].
*   $\tau(u)$: Extinction coefficient (opacity/density) at $u$.
*   $R_\Omega$: Integration limit (ray length) [S5].

### Edge Cases and Pitfalls
*   **Single Ray Equivalence:** When the number of rays equals 1, LAO is almost equivalent to volumetric shading with a short ray length [S3, unofficial].
*   **Precision:** Incremental updates (one ray per frame) require careful handling of frame-to-frame consistency to avoid flickering [S4, unofficial].
*   **Empty Space:** In multiresolution volumes, empty space skipping (Volume block < $4^3$) must be implemented to avoid unnecessary computation [S4, unofficial].

## Subtopics

### [In-scattering / Emittance Integral](11184-in-scattering-emittance-integral.md)
The In-scattering / Emittance Integral method estimates the light scattered into a volume sample from local light sources by discretizing the emittance integral into a compositing scheme. It sets itself apart from its parent, Local Ambient Occlusion (LAO), by applying similar local sampling principles to compute in-scattered and emissive light contributions rather than just shadowing. It builds on [Local Ambient Occlusion (LAO)](4502-local-ambient-occlusion-lao.md).

## Operating characteristics
*   **Time Complexity:** Performance varies significantly depending on parameters; LAO could be either slower or faster than standard volumetric shading [S3, unofficial].
*   **Memory Complexity:** Requires an additional FBO for the LAO map [S4, unofficial]. Multiresolution approaches reduce memory bandwidth by skipping empty blocks [S4, unofficial].
*   **Measured Performance:** On an NVIDIA GF8800 Ultra with 768 MB graphics texture memory, updating one ray in the LAO map took 51 ms/frame, resulting in 27 FPS [S4, unofficial].
*   **Strengths:** Creates soft ambient shadows and avoids fully shadowed regions, which is often desired for medical visualization [S3, unofficial]. It stands mid-way between local and global shading, offering softer shadows than pure local methods without the cost of global illumination [S1].
*   **Limitations:** Can be computationally expensive if many directions or steps are used. The quality depends heavily on the kernel radius and size parameters [S1][S3, unofficial].

## Background
Local Ambient Occlusion (LAO) was developed as a technique to improve the visual quality of volume rendering by providing more natural lighting. It was introduced in preliminary versions around 2010 (Hernell et al.) and further detailed in research on advanced illumination techniques for GPU-based volume raycasting (Ljung et al., 2008) [S1][S4, unofficial]. It is used in medical visualization and cinematic volume rendering to enhance depth perception and tissue clarity [S3, unofficial][S5].
