# Local Ambient Occlusion (LAO)

Also called: LAO Renderer, Volumetric Ambient Occlusion

## Overview
Local Ambient Occlusion (LAO) is a technique to estimate local occlusion by sampling the volume along random directions around the light vector, weighted by distance, to simulate ambient occlusion effects in volume rendering [S1, unofficial]. It differs from global ambient occlusion by focusing on local density variations near the light source to enhance depth perception in participating media [S1, unofficial].

## How it works
**Inputs:**
- `position`: Current 3D position in the volume.
- `vLight`: Normalized light direction vector.
- `uNumLAOSamples`: Number of LAO samples per pixel (default 1) [S1, unofficial].
- `uLAOStepSize`: Step size for LAO ray marching (default 0.05) [S1, unofficial].
- `uLightRadious`: Radius of the light source used for LAO sampling (default 0.19) [S1, unofficial].
- `uLightCoeficient`: Coefficient used to normalize LAO accumulation (default 1.0) [S1, unofficial].
- `uLocalAmbientOcclusion`: Boolean flag to enable/disable LAO calculation (default true) [S1, unofficial].
- `uLAOWeight`: Weight applied to the LAO contribution when mixing into the final color (default 0.69) [S1, unofficial].
- `sampleVolume(pos)`: Function returning the density or color at `pos`.

**Outputs:**
- `LAOContribution`: A scalar value in [0, 1] representing the occlusion factor.

**Data Structures:**
- `accumuLAOContribution`: A `vec4` accumulator initialized to `(0.0, 0.0, 0.0, 0.0)` [S1, unofficial].

**Steps:**
1. Initialize `accumuLAOContribution` to `vec4(0.0)` [S1, unofficial].
2. Loop `uNumLAOSamples` times:
   a. Initialize `innerAccum = 0.0` [G].
   b. Loop `t` from `0.001` to `1.0` with step `uLAOStepSize`:
      i. Generate a random direction:
         ```python
         rand_vec = vec3(rand(), rand(), rand())
         random_direction = normalize(-1.0 + 2.0 * rand_vec) * rand()
         ```
         [S1, unofficial]
      ii. Compute the LAO half vector:
          ```python
          lao_half_vector = normalize(vLight + random_direction * mix(0.0, uLightRadious, t) - position)
          ```
          [S1, unofficial]
      iii. Sample the volume at `position + lao_half_vector * t`:
          ```python
          lao_sample = sampleVolume(position + lao_half_vector * t)
          ```
          [S1, unofficial]
      iv. Add to accumulator weighted by `(1.0 - t)^2`:
          ```python
          innerAccum += lao_sample * pow(1.0 - t, 2.0)
          ```
          [S1, unofficial]
   c. Divide `innerAccum` by `uLightCoeficient`, clamp to `[0, 1]`, and add to `accumuLAOContribution` [S1, unofficial].
3. Divide `accumuLAOContribution` by `uNumLAOSamples` [S1, unofficial].
4. The final `LAOContribution` is derived from `accumuLAOContribution` [S1, unofficial].

**Pseudocode:**
```python
def compute_lao(position, vLight, uNumLAOSamples, uLAOStepSize, uLightRadious, uLightCoeficient, sampleVolume):
    if not uLocalAmbientOcclusion:
        return 1.0  # No occlusion

    accumuLAOContribution = vec4(0.0)

    for _ in range(uNumLAOSamples):
        innerAccum = 0.0
        t = 0.001
        while t <= 1.0:
            # Generate random direction
            rand_vec = vec3(rand(), rand(), rand())
            random_direction = normalize(-1.0 + 2.0 * rand_vec) * rand()
            
            # Compute LAO half vector
            lao_half_vector = normalize(vLight + random_direction * mix(0.0, uLightRadious, t) - position)
            
            # Sample volume
            lao_sample = sampleVolume(position + lao_half_vector * t)
            
            # Accumulate with distance weight
            innerAccum += lao_sample * pow(1.0 - t, 2.0)
            
            t += uLAOStepSize
        
        # Normalize and clamp
        contribution = innerAccum / uLightCoeficient
        contribution = clamp(contribution, 0.0, 1.0)
        accumuLAOContribution += contribution

    # Average over samples
    LAOContribution = accumuLAOContribution / uNumLAOSamples
    return LAOContribution
```

## Background
Local Ambient Occlusion is implemented in the `terier/vpt` project, an unofficial volume rendering tool [S1, unofficial]. It is used to enhance the visual quality of volumetric scenes by simulating how light is occluded by nearby volume density [S1, unofficial].
