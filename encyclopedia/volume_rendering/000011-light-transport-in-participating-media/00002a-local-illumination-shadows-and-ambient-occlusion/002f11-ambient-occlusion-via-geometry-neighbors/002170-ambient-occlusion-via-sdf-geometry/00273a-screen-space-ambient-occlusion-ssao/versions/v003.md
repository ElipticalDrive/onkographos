# Screen-Space Ambient Occlusion (SSAO)
Also called: Crytek's Screen-Space AO, SSAO (Original), Screen-Space Ambient Occlusion (SSAO) Pass

## Overview
Screen-Space Ambient Occlusion (SSAO) is a post-processing technique that estimates ambient occlusion by sampling points in a hemisphere around each pixel's surface position and checking if those points are occluded by geometry in the depth buffer [S1, unofficial]. It was the first screen-space method for ambient occlusion, using only the Z-Buffer to compute AO at full resolution [S2, unofficial]. Unlike sibling methods that rely on explicit geometry or SDFs, SSAO operates entirely on screen-space data, meaning its performance cost is independent of scene complexity and depends only on output resolution [S2, unofficial].

## How it works
**Inputs and Outputs:**
The method requires three input textures sampled at the current fragment coordinate:
1.  `hitPosTex`: World or view space position of the surface point $\mathbf{p}$.
2.  `hitNormTex`: Surface normal $\mathbf{n}$ at $\mathbf{p}$.
3.  `depthTex`: Depth buffer containing the depth value $z_{buffer}$ and potentially cell size information.

The output is a single float `outVisibility` representing the occlusion factor (1.0 = fully lit, 0.0 = fully occluded).

**Data Structures:**
*   **Sample Buffer:** An array of `NUM_SAMPLES` random 3D vectors, typically pre-computed on the CPU or stored in a texture (`noiseTex`), representing directions in a hemisphere or sphere.
*   **TBN Matrix:** A $3 \times 3$ matrix constructed from the tangent, bitangent, and normal vectors to rotate sample vectors from local tangent space to world/view space.

**Parameters:**
*   `NUM_SAMPLES`: Integer, number of random samples per pixel.
*   `radius`: Float, the radius of the hemisphere/sphere used for sampling. Determines the scale of occlusion.
*   `hitDepth_cellSize`: Derived from the depth buffer or geometry, used to offset the position slightly to avoid self-intersection.

**Steps:**
1.  **Fetch Data:** Retrieve the hit position $\mathbf{p}$, normal $\mathbf{n}$, and depth $z_{buffer}$ from the input textures using the current screen coordinate.
2.  **Discard Background:** If the hit position is zero (background), discard the fragment.
3.  **Offset Position:** Offset the hit position slightly along the normal to prevent self-occlusion artifacts (z-fighting):
    $$ \mathbf{p}' = \mathbf{p} + \mathbf{n} \cdot \frac{\text{hitDepth\_cellSize}_y}{5.0} $$
4.  **Construct TBN Matrix:**
    *   Generate a random tangent vector $\mathbf{t}_{rand}$ (e.g., from `noiseTex`).
    *   Compute tangent $\mathbf{t}$ by orthogonalizing $\mathbf{t}_{rand}$ against $\mathbf{n}$:
        $$ \mathbf{t} = \text{normalize}(\mathbf{t}_{rand} - \mathbf{n} \cdot (\mathbf{t}_{rand} \cdot \mathbf{n})) $$
    *   Compute bitangent $\mathbf{b} = \mathbf{n} \times \mathbf{t}$.
    *   Construct matrix $M_{TBN} = [\mathbf{t}, \mathbf{b}, \mathbf{n}]$.
5.  **Sample Loop:** For each sample $i$ from $0$ to `NUM_SAMPLES` - 1:
    *   Retrieve random direction $\mathbf{v}_{local}$ from the sample buffer.
    *   Transform to world/view space: $\mathbf{v}_{world} = M_{TBN} \cdot \mathbf{v}_{local}$.
    *   Calculate sample position: $\mathbf{s} = \mathbf{p}' + \mathbf{v}_{world} \cdot \text{radius}$.
    *   Project $\mathbf{s}$ into screen space:
        $$ \mathbf{s}_{clip} = M_{proj} \cdot M_{view} \cdot [\mathbf{s}, 1]^T $$
        $$ \mathbf{s}_{ndc} = \mathbf{s}_{clip}.xyz / \mathbf{s}_{clip}.w $$
        $$ \mathbf{s}_{screen} = \mathbf{s}_{ndc}.xyz \cdot 0.5 + 0.5 $$
    *   **Range Check:** Verify if the sample is within the screen bounds ($0 \le \mathbf{s}_{screen}.xy \le 1$).
    *   **Occlusion Test:**
        *   Fetch the depth $z_{sample}$ from the depth buffer at $\mathbf{s}_{screen}.xy$.
        *   Calculate distance from camera to sample: $d_{cam} = \| \mathbf{p}_{camera} - \mathbf{s} \|$.
        *   Check if the sample is closer to the camera than the buffer depth (occluded) and within the radius range:
            $$ \text{occluded} = (z_{sample} < d_{cam}) \land (|z_{buffer} - z_{sample}| < \text{radius}) $$
        *   Accumulate occlusion: $O_{acc} += \text{occluded}$.
6.  **Final Visibility:**
    $$ \text{outVisibility} = 1.0 - \frac{O_{acc}}{\text{count}} $$
    where `count` is the number of valid samples.

**Pseudocode:**
```python
def compute_ssao(coord, hitPosTex, hitNormTex, depthTex, noiseTex, projMat, viewMat, radius, num_samples):
    # 1. Fetch data
    hitPos = hitPosTex.fetch(coord).xyz
    hitNorm = hitNormTex.fetch(coord).xyz
    depthData = depthTex.fetch(coord)
    z_buffer = depthData.z
    cellSizeY = depthData.w # Assuming cell size is stored in w component or derived
    
    # 2. Discard background
    if all(hitPos == 0.0):
        return 1.0 # Fully visible if no geometry

    # 3. Offset position
    offset = hitNorm * (cellSizeY / 5.0)
    p_prime = hitPos + offset

    # 4. Construct TBN
    # Get random vector for tangent space orientation
    randVec = noiseTex.fetch(coord).xyz
    tangent = normalize(randVec - hitNorm * dot(randVec, hitNorm))
    bitangent = cross(hitNorm, tangent)
    tbn = mat3(tangent, bitangent, hitNorm)

    occlusion = 0.0
    count = 0

    # 5. Sample loop
    for i in range(num_samples):
        # Get sample direction in tangent space
        sampleLocal = samples[i] # Pre-computed random vector
        
        # Transform to world/view space
        sampleWorld = tbn * sampleLocal
        
        # Calculate sample position
        samp = p_prime + sampleWorld * radius
        
        # Project to screen space
        offsetVec = vec4(samp, 1.0)
        clipSpace = projMat * viewMat * offsetVec
        ndc = clipSpace.xyz / clipSpace.w
        screenPos = ndc * 0.5 + 0.5
        
        # Check bounds
        if all(screenPos.xy >= 0.0) and all(screenPos.xy <= 1.0):
            # Fetch depth at sample position
            sampleDepth = depthTex.fetch(screenPos.xy).z
            
            # Range check and occlusion
            # Note: 'hitDepth_cellSize.x' in source likely refers to a radius check or depth difference threshold
            # Here we use the radius parameter for range check as per standard SSAO logic
            rangeCheck = 1.0 if abs(z_buffer - sampleDepth) < radius else 0.0
            
            # Distance from camera to sample (approximated using depth if view space pos not available)
            # In the source, 'camPos' is used. Assuming view space, camPos is (0,0,0)
            # length(camPos - samp) is simply the length of the view-space sample position
            dist = length(samp) 
            
            isOccluded = 1.0 if sampleDepth < dist else 0.0
            
            occlusion += isOccluded * rangeCheck
            count += 1

    # 6. Final visibility
    if count > 0:
        return 1.0 - (occlusion / count)
    else:
        return 1.0
```

**Edge Cases and Pitfalls:**
*   **Halo Effect:** Because the method is not cosine-weighted, it accounts for occlusion that should not be accounted for, leading to blackened edges around objects [S2, unofficial].
*   **Self-Intersection:** Without the normal offset, samples may intersect the surface they are sampling from, causing incorrect occlusion.
*   **Depth Precision:** Z-fighting or low-depth buffer precision can cause artifacts, especially at large radii.

## Operating characteristics
*   **Time Complexity:** $O(N \cdot S)$, where $N$ is the number of pixels and $S$ is `NUM_SAMPLES`. Performance is independent of scene geometry complexity.
*   **Memory Complexity:** $O(N)$ for the output texture and input buffers.
*   **Strengths:** Resolution-independent of scene complexity; fast on modern GPUs; works on any rendered scene without explicit geometry access.
*   **Limitations:** Cannot occlude objects not currently visible on screen (no occlusion for off-screen geometry); suffers from the "halo effect" due to lack of cosine weighting; sensitive to depth buffer precision.
*   **When to use:** Real-time rendering where performance is critical and scene complexity is high.
*   **When not to use:** When accurate occlusion involving off-screen geometry is required, or when high-quality, artifact-free results are needed without post-processing fixes.

## Background
SSAO was introduced by Crytek as the first screen-space method for ambient occlusion [S2, unofficial]. It utilizes the Z-Buffer as its only input and computes ambient occlusion at full resolution. The method was later expanded upon by Loos and Sloan, who formulated it as a Monte Carlo integration and named it "Volumetric Obscurance" [S2, unofficial]. They defined the occlusion as:
$$ v_A(p) = \int_{x \in X} \rho(d(p, x)) O(x) dx $$
where $X$ is a 3D spherical neighborhood around the point, $\rho(d(p, x))$ is a distance mapping function, and $O(x)$ is the occupancy function [S2, unofficial].
