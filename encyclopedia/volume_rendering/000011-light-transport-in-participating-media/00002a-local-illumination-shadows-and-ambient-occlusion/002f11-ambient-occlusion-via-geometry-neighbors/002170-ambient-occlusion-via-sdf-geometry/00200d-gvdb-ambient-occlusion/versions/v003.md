# GVDB Ambient Occlusion

Also called: GVDB AO, computeAmbientOcclusion

## Overview
GVDB Ambient Occlusion computes local occlusion at a surface point by sampling a hemisphere of directions against a volume density field, using either point sampling or ray casting with distance-based falloff [S1, unofficial]. It operates in world-space volume coordinates using a device function for GPU execution [S1, unofficial].

## How it works
**Inputs:**
- Surface position `pos` (world space) [S1, unofficial].
- Surface normal `normal` (world space, normalized) [S1, unofficial].
- `aoSamples`: Number of hemisphere samples (integer, max 512) [S1, unofficial].
- `aoRadius`: World-space radius for AO sampling (float) [S1, unofficial].
- `aoBias`: Backtrack distance to reduce acne artifacts (float, typically $10^{-3}$) [S1, unofficial].
- `AMBIENT_OCCLUSION_MODE`: Integer switch (0 for point sampling, 1 for ray sampling) [S1, unofficial].
- `noise`: A precomputed random rotation vector (float3) [S1, unofficial].

**Outputs:**
- Occlusion factor (float, range [0, 1]) [S1, unofficial].

**Data Structures:**
- The volume is accessed via a query function returning a scalar density value [S1, unofficial].
- Vectors are 3D floats (`float3`) [S1, unofficial].

**Steps:**
1. If `aoSamples == 0`, return 1.0 [S1, unofficial].
2. Compute tangent and bitangent vectors to form a local basis aligned with the surface normal [S1, unofficial]:
   $$ \text{tangent} = \frac{\text{noise} - \text{normal} \cdot \text{noise}}{\|\text{noise} - \text{normal} \cdot \text{noise}\|} $$
   $$ \text{bitangent} = \text{normal} \times \text{tangent} $$
3. Backtrack the query position along the normal by `aoBias` to mitigate acne artifacts [S1, unofficial].
4. Initialize `occlusion = 0.0` [S1, unofficial].
5. For each of `aoSamples` hemisphere directions:
   a. Generate a sample direction in the hemisphere defined by the tangent-bitangent-normal basis [G].
   b. Transform the sample to world space using the basis [S1, unofficial].
   c. In mode 0 (point sampling), query the volume at `pos + aoRadius * sampleWorld`; if the value is less than or equal to `aoBias`, add 1.0 to `occlusion` [S1, unofficial].
   d. In mode 1 (ray sampling), shoot a ray; if a hit is found, compute the distance `dist`, apply `smoothstep(1, 0, aoRadius / dist)` to get the value, and add it to `occlusion` [S1, unofficial].
6. Divide `occlusion` by `aoSamples` and return the result [S1, unofficial].

**Pseudocode:**
```python
def computeGVDBAO(pos, normal, aoSamples, aoRadius, aoBias, mode, noise, queryVolume):
    if aoSamples == 0:
        return 1.0

    # Compute tangent and bitangent from random rotation vector and normal
    proj = noise - normal * dot(noise, normal)
    tangent = normalize(proj)
    bitangent = cross(normal, tangent)

    # Backtrack position to reduce acne artifacts
    queryPos = pos - normal * aoBias

    occlusion = 0.0

    for i in range(aoSamples):
        # Generate hemisphere sample in local tangent-bitangent-normal space
        sampleLocal = hemisphere_sample(i, aoSamples)

        # Transform to world space
        sampleWorld = tangent * sampleLocal.x + bitangent * sampleLocal.y + normal * sampleLocal.z

        if mode == 0:
            # Point sampling
            samplePoint = queryPos + sampleWorld * aoRadius
            density = queryVolume(samplePoint)
            if density <= aoBias:
                occlusion += 1.0
        elif mode == 1:
            # Ray sampling
            # Sources do not specify the exact ray march implementation [Comment]
            hitDist = ray_march(queryPos, sampleWorld, aoRadius, queryVolume)
            if hitDist < aoRadius:
                t = aoRadius / hitDist
                # smoothstep(1, 0, t)
                t_clamped = max(0.0, min(1.0, t))
                weight = t_clamped * t_clamped * (3.0 - 2.0 * t_clamped)
                occlusion += weight

    return occlusion / aoSamples

def hemisphere_sample(index, total):
    # Standard uniform hemisphere sampling [G]
    phi = 2.0 * 3.14159265358979 * (index / total)
    cos_theta = 1.0 - 2.0 * (index / total)
    sin_theta = sqrt(1.0 - cos_theta * cos_theta)
    return float3(sin_theta * cos(phi), sin_theta * sin(phi), cos_theta)

def ray_march(origin, direction, max_dist, queryVolume):
    # Standard volume ray march [G]
    step = 0.01
    dist = 0.0
    while dist < max_dist:
        if queryVolume(origin + direction * dist) > 0.0:
            return dist
        dist += step
    return max_dist
```

**Parameters:**
- `aoSamples`: Max 512 [S1, unofficial].
- `aoBias`: Typically $10^{-3}$ [S1, unofficial].

**Edge Cases and Pitfalls:**
- Acne artifacts from sampling at the surface are mitigated by backtracking position by `aoBias` before querying the volume [S1, unofficial].
- If `aoSamples` is 0, the function returns 1.0 [S1, unofficial].
