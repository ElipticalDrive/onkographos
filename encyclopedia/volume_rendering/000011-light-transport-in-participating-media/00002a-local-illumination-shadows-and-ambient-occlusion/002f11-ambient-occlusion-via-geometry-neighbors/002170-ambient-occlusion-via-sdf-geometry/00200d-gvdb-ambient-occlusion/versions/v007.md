# GVDB Ambient Occlusion

Also called: GVDB AO, computeAmbientOcclusion

## Overview
GVDB Ambient Occlusion is a device-side function that computes ambient occlusion at a surface point by sampling a hemisphere of directions against a voxel volume, using either point sampling or ray casting to determine occlusion weights [S1, unofficial]. It distinguishes itself from sibling methods by using a precomputed random rotation vector to generate a tangent-space basis, avoiding per-sample random number generation overhead [S1, unofficial].

## How it works
**Inputs and Outputs:**
*   **Input:** Surface position $\mathbf{p}$, surface normal $\mathbf{n}$, a precomputed random rotation vector $\mathbf{r}$, the volume data structure, and parameters: `aoSamples` (number of hemisphere samples, max 512), `aoRadius` (world-space radius for AO sampling), `aoBias` (distance in world space to backtrack position, typically $10^{-3}$), and `mode` (0 for point sampling, 1 for ray sampling) [S1, unofficial].
*   **Output:** A float value in $[0, 1]$ representing the ambient occlusion factor, where 1 is fully illuminated and 0 is fully occluded [S1, unofficial].

**Data Structures:**
The volume is queried directly via its device API [S1, unofficial].

**Steps:**
1.  **Early Exit:** If `aoSamples == 0`, return $1.0$ [S1, unofficial].
2.  **Tangent Space Basis Construction:**
    *   Compute the tangent vector $\mathbf{t}$ by subtracting the projection of $\mathbf{r}$ onto $\mathbf{n}$ from $\mathbf{r}$, then normalizing:
        $$ \mathbf{t} = \frac{\mathbf{r} - \mathbf{n} (\mathbf{r} \cdot \mathbf{n})}{\| \mathbf{r} - \mathbf{n} (\mathbf{r} \cdot \mathbf{n}) \|} $$
    *   Compute the bitangent vector $\mathbf{b}$ using the cross product:
        $$ \mathbf{b} = \mathbf{n} \times \mathbf{t} $$
    *   [G] Handle the degenerate case where $\mathbf{r}$ is parallel to $\mathbf{n}$ by using an arbitrary orthogonal vector for $\mathbf{t}$ [G].
3.  **Bias Retrieval and Position Offset:**
    *   Retrieve the bias threshold $B_{val}$ from the volume at position $\mathbf{p}$ [S1, unofficial].
    *   Offset the starting position along the normal to prevent self-intersection: $\mathbf{p}_{start} = \mathbf{p} + \text{aoBias} \cdot \mathbf{n}$ [S1, unofficial].
4.  **Hemisphere Sampling Loop:**
    *   Initialize `occlusion = 0.0`.
    *   For $i$ from $0$ to `aoSamples` - 1:
        *   Generate a sample direction $\mathbf{d}_{local}$ in the upper hemisphere (relative to the $\mathbf{z}$-axis). The exact distribution is not specified in the sources [S1, unofficial].
        *   Transform $\mathbf{d}_{local}$ to world space $\mathbf{d}_{world}$ using the basis $(\mathbf{t}, \mathbf{b}, \mathbf{n})$:
            $$ \mathbf{d}_{world} = \mathbf{t} \cdot d_{local,x} + \mathbf{b} \cdot d_{local,y} + \mathbf{n} \cdot d_{local,z} $$
        *   **Mode 0 (Point Sampling):**
            *   Query the volume at position $\mathbf{p}_{query} = \mathbf{p}_{start} + \text{aoRadius} \cdot \mathbf{d}_{world}$.
            *   Let $V$ be the returned value.
            *   If $V \le B_{val}$, add $1.0$ to `occlusion` [S1, unofficial].
        *   **Mode 1 (Ray Sampling):**
            *   Cast a ray from $\mathbf{p}_{start}$ in direction $\mathbf{d}_{world}$ with maximum length `aoRadius`.
            *   If a hit is found at distance $D_{hit}$:
                *   Compute the occlusion weight:
                    $$ w = \text{smoothstep}(1, 0, \frac{\text{aoRadius}}{D_{hit}}) $$
                *   Add $w$ to `occlusion` [S1, unofficial].
            *   If no hit is found, add $0.0$ to `occlusion` [S1, unofficial].
5.  **Normalization:**
    *   Return $\frac{\text{occlusion}}{\text{aoSamples}}$ [S1, unofficial].

**Pseudocode:**
```python
class Vec3:
    def __init__(self, x, y, z): self.x, self.y, self.z = x, y, z
    def __mul__(self, s): return Vec3(self.x*s, self.y*s, self.z*s)
    def __add__(self, o): return Vec3(self.x+o.x, self.y+o.y, self.z+o.z)
    def __sub__(self, o): return Vec3(self.x-o.x, self.y-o.y, self.z-o.z)
    def dot(self, o): return self.x*o.x + self.y*o.y + self.z*o.z
    def cross(self, o): return Vec3(self.y*o.z-self.z*o.y, self.z*o.x-self.x*o.z, self.x*o.y-self.y*o.x)
    def length(self): return (self.x**2 + self.y**2 + self.z**2)**0.5
    def normalize(self):
        l = self.length()
        return Vec3(self.x/l, self.y/l, self.z/l) if l > 1e-8 else self

def smoothstep(edge0, edge1, x):
    t = max(0.0, min(1.0, (x - edge0) / (edge1 - edge0)))
    return t * t * (3.0 - 2.0 * t)

def sample_hemisphere(index, total):
    # Deterministic uniform hemisphere sampling; exact distribution not specified [S1, unofficial]
    phi = 2.0 * 3.14159265358979 * index / total
    cos_theta = 1.0
    sin_theta = (1.0 - cos_theta**2)**0.5
    return Vec3(sin_theta * (cos(phi) if total > 1 else 0.0), sin_theta * (sin(phi) if total > 1 else 0.0), cos_theta)

def compute_ambient_occlusion(p, n, r, volume, ao_samples, ao_radius, ao_bias, mode):
    if ao_samples == 0:
        return 1.0

    # Construct tangent space basis
    proj = n * r.dot(n)
    tangent = (r - proj).normalize()
    bitangent = n.cross(tangent)

    # Get bias value from volume at pos [S1, unofficial]
    bias_val = volume.query(p)
    # Backtrack position by aoBias [S1, unofficial]
    p_start = p + n * ao_bias

    occlusion = 0.0
    for i in range(ao_samples):
        d_local = sample_hemisphere(i, ao_samples)
        d_world = tangent * d_local.x + bitangent * d_local.y + n * d_local.z

        if mode == 0:
            # Point sampling mode
            query_pos = p_start + d_world * ao_radius
            val = volume.query(query_pos)
            if val <= bias_val:
                occlusion += 1.0
        elif mode == 1:
            # Ray sampling mode
            hit_dist = volume.raycast(p_start, d_world, ao_radius)
            if hit_dist < ao_radius:
                weight = smoothstep(1.0, 0.0, ao_radius / hit_dist)
                occlusion += weight
            else:
                occlusion += 0.0

    return occlusion / ao_samples
```

**Parameters:**
*   `aoSamples`: Number of hemisphere samples. Max 512 [S1, unofficial].
*   `aoRadius`: World-space radius for AO sampling, controls falloff distance [S1, unofficial].
*   `aoBias`: Distance in world space to backtrack position, typically $10^{-3}$, used to reduce acne artifacts [S1, unofficial].
*   `AMBIENT_OCCLUSION_MODE`: Switch between 0 (point sampling) and 1 (ray sampling) [S1, unofficial].

**Edge Cases and Pitfalls:**
*   **Acne Artifacts:** Sampling at the surface can cause self-intersection due to floating-point precision. Mitigated by backtracking position by `aoBias` along the normal [S1, unofficial].
*   **Degenerate Normal:** If the random vector $\mathbf{r}$ is parallel to $\mathbf{n}$, the tangent calculation fails. A guard is required [G].
*   **Mode 0 Threshold:** The source states "if value <= bias, add 1.0". The bias threshold is retrieved from the volume at the surface position, distinct from the `aoBias` backtrack distance [S1, unofficial].

**Strengths and Limitations:**
*   **Strengths:** Unified interface for point and ray sampling; efficient tangent space generation using precomputed random vectors; biasing reduces self-intersection artifacts [S1, unofficial].
*   **Limitations:** Point sampling mode (Mode 0) may be less accurate than ray casting (Mode 1) for complex geometry; accuracy depends on the resolution and representation of the queried volume [S1, unofficial].

## Background
GVDB Ambient Occlusion is implemented as a device function within the adaptive sampling and reconstruction pipeline for volume visualization [S1, unofficial]. It builds on the general principles of SDF/Geometry-based ambient occlusion by leveraging the volume data structure as the geometric query primitive [Parent].
