# Gradient-based Occlusion Information Computation

Also called: Boundary-preserving occlusion, Perona-Malik inspired occlusion metric

## Overview
This method computes a view-independent occlusion metric for volume data that preserves structural boundaries, addressing the isotropic blurring inherent in simple spherical mean ambient occlusion [S1, unofficial]. It modulates a spherical neighborhood mean with a gradient-based weight derived from Perona-Malik diffusion principles to prevent boundary loss during filtering [S1, unofficial].

## How it works
**Inputs and Outputs**
*   **Input:** A 3D volume dataset $I$ (voxel values), a neighborhood radius $R$, and a boundary-preservation parameter $\eta$ [S1, unofficial].
*   **Output:** An occlusion volume $m$ where each voxel $m_x$ represents the boundary-preserving occlusion information for voxel $x$ [S1, unofficial].

**Data Structures**
*   **Volume $I$:** A 3D array of floating-point values representing the scalar field [G].
*   **Gradient Field $\|\nabla I\|$:** A 3D array of scalar values representing the spatial gradient magnitude at each voxel [G].
*   **Weight Field $g$:** A 3D array of floating-point values storing the gradient-based modulation weights [G].
*   **Occlusion Volume $m$:** A 3D array of floating-point values, same dimensions as $I$ [G].

**Parameters**
*   $R$: Radius of the spherical neighborhood. Typical value: $R=40$ [S1, unofficial].
*   $\eta$: Dataset-dependent parameter handling gradients of zero magnitude.
    *   $\eta \in [0.001, 0.01]$ for preserving boundaries in CT/MRI data [S1, unofficial].
    *   $\eta = 1.0$ for noisy synthetic data [S1, unofficial].
    *   If $\eta \ge 1$, the filter behaves like a standard box filter [S1, unofficial].

**Algorithm Steps**
1.  **Compute Gradient Magnitude:** Calculate the gradient magnitude $\|\nabla I_x\|$ for every voxel $x$ in the volume using central differences [G].
2.  **Compute Gradient Weight:** Calculate the weight $g_x$ for each voxel using the formula:
    $$g_x = \frac{\eta^2}{\|\nabla I_x\|^2 + \eta^2}$$
    This weight approaches 1 in smooth regions (low gradient) and approaches 0 near sharp boundaries (high gradient) [S1, unofficial].
3.  **Approximate Spherical Filter:** Replace the computationally expensive spherical convolution $B_R$ with a separable box filter of width $2R+1$ to exploit GPU performance and separability [S1, unofficial].
4.  **Apply Separable Convolution:** Compute the neighborhood mean approximation by applying three consecutive 1D box filter convolutions of width $2R+1$ along the X, Y, and Z axes. The convolution is:
    $$M_x = b_{2R+1} * [b_{2R+1} * (b_{2R+1} * I_x)]$$
    where $b_{2R+1}$ denotes the 1D box filter kernel of width $2R+1$ with uniform weights [S1, unofficial].
5.  **Modulate by Gradient Weight:** Multiply the convolved result by the gradient weight to obtain the final occlusion information:
    $$m_x = g_x \cdot M_x$$
    This is equivalent to convolving the volume with a spherical filter $B_R$ and modulating it with $g_x$ [S1, unofficial].

**Pseudocode**
```python
def compute_gradient_based_occlusion(volume: list[list[list[float]]], R: float, eta: float) -> list[list[list[float]]]:
    """
    Computes gradient-based occlusion information for a volume.
    
    Args:
        volume: 3D array of voxel values I.
        R: Radius of the neighborhood.
        eta: Boundary preservation parameter.
        
    Returns:
        3D array m of occlusion information.
    """
    H, W, D = len(volume), len(volume[0]), len(volume[0][0])
    
    # Step 1: Compute gradient magnitude using central differences
    grad_mag_sq = [[[0.0 for _ in range(D)] for _ in range(W)] for _ in range(H)]
    for h in range(H):
        for w in range(W):
            for d in range(D):
                gx = (volume[h][w+1][d] if w+1 < W else volume[h][w][d]) - (volume[h][w-1][d] if w-1 >= 0 else volume[h][w][d])
                gy = (volume[h+1][w][d] if h+1 < H else volume[h][w][d]) - (volume[h-1][w][d] if h-1 >= 0 else volume[h][w][d])
                gz = (volume[h][w][d+1] if d+1 < D else volume[h][w][d]) - (volume[h][w][d-1] if d-1 >= 0 else volume[h][w][d])
                grad_mag_sq[h][w][d] = gx**2 + gy**2 + gz**2
    
    # Step 2: Compute gradient weight g_x
    weight = [[[eta**2 / (grad_mag_sq[h][w][d] + eta**2) for d in range(D)] for w in range(W)] for h in range(H)]
    
    # Step 3 & 4: Apply separable box filter approximation of spherical mean
    kernel_width = int(2 * R + 1)
    
    # Apply 1D box filter along X axis (axis 1)
    conv_x = [[[0.0 for _ in range(D)] for _ in range(W)] for _ in range(H)]
    for h in range(H):
        for d in range(D):
            for w in range(W):
                acc = 0.0
                for k in range(kernel_width):
                    idx = w - kernel_width // 2 + k
                    idx = max(0, min(W - 1, idx)) # Boundary clamp [G]
                    acc += volume[h][idx][d]
                conv_x[h][w][d] = acc / kernel_width
    
    # Apply 1D box filter along Y axis (axis 0)
    conv_y = [[[0.0 for _ in range(D)] for _ in range(W)] for _ in range(H)]
    for w in range(W):
        for d in range(D):
            for h in range(H):
                acc = 0.0
                for k in range(kernel_width):
                    idx = h - kernel_width // 2 + k
                    idx = max(0, min(H - 1, idx)) # Boundary clamp [G]
                    acc += conv_x[idx][w][d]
                conv_y[h][w][d] = acc / kernel_width
    
    # Apply 1D box filter along Z axis (axis 2)
    conv_z = [[[0.0 for _ in range(D)] for _ in range(W)] for _ in range(H)]
    for h in range(H):
        for w in range(W):
            for d in range(D):
                acc = 0.0
                for k in range(kernel_width):
                    idx = d - kernel_width // 2 + k
                    idx = max(0, min(D - 1, idx)) # Boundary clamp [G]
                    acc += conv_y[h][w][idx]
                conv_z[h][w][d] = acc / kernel_width
    
    # Step 5: Modulate by gradient weight
    occlusion = [[[weight[h][w][d] * conv_z[h][w][d] for d in range(D)] for w in range(W)] for h in range(H)]
    
    return occlusion
```

**Edge Cases and Pitfalls**
*   **Isotropic Blurring:** Simple ambient occlusion (weighted sample mean without gradient modulation) results in isotropic blurring that destroys boundary information [S1, unofficial].
*   **High $\eta$:** If $\eta \ge 1$, the gradient weight $g_x$ becomes approximately 1 everywhere, causing the filter to behave like a standard box filter, losing boundary preservation [S1, unofficial].
*   **Noisy Data:** Noisy volumes may require higher $\eta$ (e.g., 1.0) to prevent gradient noise from incorrectly suppressing occlusion [S1, unofficial].
*   **Complexity:** The naive spherical convolution has complexity $O(mn)$ where $m = \frac{4}{3}\pi R^3 + 1$, which is infeasible for large $R$ [S1, unofficial]. The separable box filter approximation considerably reduces computation time [S1, unofficial].

## Operating characteristics
*   **Time Complexity:** The naive spherical convolution is $O(mn)$ where $m = \frac{4}{3}\pi R^3 + 1$ and $n$ is the number of voxels, described as very costly [S1, unofficial]. The separable box filter approximation considerably reduces computation time, allowing computation within seconds on modern GPUs [S1, unofficial].
*   **Memory Complexity:** Requires storage for the input volume, gradient field, weight field, and output occlusion volume. $O(n)$ space [G].
*   **Performance:** The method is view-independent, allowing precomputation and storage without affecting visualization speed [S1, unofficial].
*   **Strengths:** Preserves boundaries of structures better than simple spherical mean occlusion; computationally efficient via separable filtering [S1, unofficial].
*   **Limitations:** The box filter approximation is an approximation of the spherical filter; may introduce slight anisotropy compared to a true spherical convolution [G].
*   **When to Use:** When boundary preservation is critical for volume visualization or transfer function design, and computational efficiency is required [S1, unofficial].
*   **When Not to Use:** When exact spherical averaging is required and performance is not a constraint, or when the data is extremely noisy and requires different smoothing strategies [G].

## Background
The method is inspired by the Perona-Malik anisotropic diffusion equation [S1, unofficial]. It was proposed in the context of multivariate transfer function design for volume visualization, specifically to create statistical feature spaces that include occlusion information while preserving structural boundaries [S1, unofficial]. The approach was applied to CT, MRI, and synthetic datasets, with typical parameters $R=40$ and $\eta$ varying based on data noise and boundary preservation needs [S1, unofficial].
