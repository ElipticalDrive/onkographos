# Gradient-based Occlusion Information Computation

Also called: Boundary-preserving occlusion, Perona-Malik inspired occlusion metric

## Overview
This method computes a view-independent occlusion metric for volume data that preserves sharp boundaries between structures, addressing the isotropic blurring inherent in simple spherical mean ambient occlusion [S1, unofficial]. It modulates the neighborhood mean with a gradient-based weight derived from Perona-Malik diffusion principles, ensuring that edges are not smoothed out during the occlusion calculation [S1, unofficial].

## How it works
**Inputs:**
- Volume data $I$, a 3D grid of voxel intensities [S1, unofficial].
- Radius $R$, defining the neighborhood size [S1, unofficial].
- Parameter $\eta$, controlling boundary preservation strength [S1, unofficial].

**Outputs:**
- Occlusion volume $m$, where each voxel $m_x$ contains the computed occlusion information [S1, unofficial].

**Data Structures:**
- The input volume $I$ is stored as a 3D array [G].
- The gradient $\nabla I_x$ is computed per voxel [G].
- The output $m$ is stored in a 3D array of the same dimensions as $I$ [G].

**Steps:**
1. **Compute Gradient Magnitude:** For each voxel $x$, calculate the gradient magnitude $\|\nabla I_x\|$ [G].
2. **Compute Gradient Weight:** Calculate the weight $g_x$ for each voxel using the formula:
   $$ g_x = \frac{\eta^2}{\|\nabla I_x\|^2 + \eta^2} $$
   Here, $\eta$ is a dataset-dependent parameter [S1, unofficial]. Small $\eta$ (e.g., $0.001$ to $0.01$) preserves boundaries by reducing the weight in high-gradient regions [S1, unofficial]. Large $\eta$ (e.g., $\ge 1$) acts as a box filter, suitable for noisy data [S1, unofficial].
3. **Approximate Spherical Convolution:** The exact occlusion metric is defined as a spherical mean modulated by $g_x$:
   $$ m_x = g_x \cdot (B_R * I_x) $$
   where $B_R$ is a spherical filter of radius $R$ and $*$ denotes convolution [S1, unofficial]. To avoid the high complexity $O(mn)$ where $m = \frac{4}{3}\pi R^3 + 1$, the spherical filter $B_R$ is approximated by a box filter of width $2R$ [S1, unofficial].
4. **Separable Convolution:** The 3D convolution with the box filter is separated into three consecutive 1D box filter convolutions of width $2R+1$:
   $$ m_x = g_x \cdot [b_{2R+1} * [b_{2R+1} * (b_{2R+1} * I_x)]] $$
   This separability allows for efficient GPU implementation [S1, unofficial].
5. **Modulation:** Multiply the result of the separable convolution by the precomputed gradient weight $g_x$ to obtain the final occlusion value $m_x$ [S1, unofficial].

**Pseudocode:**
```python
def compute_gradient_based_occlusion(volume: list, R: float, eta: float) -> list:
    """
    Computes gradient-based occlusion information for a volume.
    
    Args:
        volume: 3D list of voxel intensities.
        R: Radius of the neighborhood.
        eta: Boundary preservation parameter.
        
    Returns:
        3D list of occlusion values.
    """
    H, W, D = len(volume), len(volume[0]), len(volume[0][0])
    eta_sq = eta * eta
    filter_width = int(2 * R) + 1
    half_w = filter_width // 2
    box_kernel = [1.0 / filter_width] * filter_width

    # Step 1: Gradient magnitude squared (central differences, edge clamping)
    grad_sq = [[[0.0]*D for _ in range(W)] for _ in range(H)]
    for h in range(H):
        for w in range(W):
            for d in range(D):
                gx = volume[min(h+1, H-1)][w][d] - volume[max(h-1, 0)][w][d]
                gy = volume[h][min(w+1, W-1)][d] - volume[h][max(w-1, 0)][d]
                gz = volume[h][w][min(d+1, D-1)] - volume[h][w][max(d-1, 0)]
                grad_sq[h][w][d] = gx*gx + gy*gy + gz*gz

    # Step 2: Gradient weight
    g = [[[eta_sq / (grad_sq[h][w][d] + eta_sq) for d in range(D)] for w in range(W)] for h in range(H)]

    # Helper for 1D convolution along an axis with edge padding
    def convolve_axis(data, axis, width, half):
        result = [[[0.0]*D for _ in range(W)] for _ in range(H)]
        for h in range(H):
            for w in range(W):
                for d in range(D):
                    val = 0.0
                    for k in range(width):
                        idx = h if axis == 0 else (w if axis == 1 else d)
                        neighbor = idx + half - k
                        if neighbor < 0: neighbor = 0
                        if neighbor >= (H if axis == 0 else (W if axis == 1 else D)): neighbor = (H if axis == 0 else (W if axis == 1 else D)) - 1
                        if axis == 0: val += box_kernel[k] * data[neighbor][w][d]
                        elif axis == 1: val += box_kernel[k] * data[h][neighbor][d]
                        else: val += box_kernel[k] * data[h][w][neighbor]
                    result[h][w][d] = val
        return result

    # Step 3 & 4: Separable convolution along X, Y, Z
    temp_x = convolve_axis(volume, 0, filter_width, half_w)
    temp_y = convolve_axis(temp_x, 1, filter_width, half_w)
    temp_z = convolve_axis(temp_y, 2, filter_width, half_w)

    # Step 5: Modulation
    return [[[g[h][w][d] * temp_z[h][w][d] for d in range(D)] for w in range(W)] for h in range(H)]
```

**Parameters:**
- $\eta$: Dataset-dependent parameter. Typical values: $\eta \in [0.001, 0.01]$ for preserving boundaries in CT/MRI data; $\eta = 1.0$ for noisy synthetic data [S1, unofficial]. If $\eta \ge 1$, the filter behaves like a box filter [S1, unofficial].
- $R$: Radius of the spherical neighborhood. Typical value: $R=40$ for all datasets in the source results [S1, unofficial].

**Edge Cases and Pitfalls:**
- **Isotropic Blurring:** Simple ambient occlusion (weighted sample mean of spherical neighborhood) results in isotropic blurring that does not preserve boundaries [S1, unofficial]. This method mitigates that by using $g_x$ [S1, unofficial].
- **Complexity:** The naive spherical convolution has complexity $O(mn)$ where $m = \frac{4}{3}\pi R^3 + 1$, which is infeasible for large $R$ [S1, unofficial]. The separable box filter approximation is necessary for performance [S1, unofficial].
- **Boundary Conditions:** Gradient computation at volume boundaries requires careful handling (e.g., edge clamping or replication) to avoid artifacts [G].

## Operating characteristics
- **Time Complexity:** The naive spherical convolution is $O(mn)$ where $m = \frac{4}{3}\pi R^3 + 1$, which is very costly [S1, unofficial]. The separable box filter approximation reduces this significantly, allowing computation within seconds on modern GPUs [S1, unofficial].
- **Memory Complexity:** Requires storage for the input volume, gradient volume, weight volume, and intermediate convolution results. Typically $O(N)$ where $N$ is the number of voxels [G].
- **Performance:** The method is view-independent and can be precomputed and stored, not affecting visualization speed [S1, unofficial].
- **Strengths:** Preserves boundaries between structures, avoiding the isotropic blurring of simple ambient occlusion [S1, unofficial]. Efficient via separable convolution [S1, unofficial].
- **Limitations:** Requires tuning of $\eta$ and $R$. The box filter approximation may introduce slight artifacts compared to a true spherical filter, but this is negligible for large $R$ [G].

## Background
This method was introduced in the context of multivariate transfer function design for volume visualization, specifically to improve the statistical feature space construction by providing a boundary-preserving occlusion metric [S1, unofficial]. It is inspired by the Perona-Malik anisotropic diffusion equation, which is known for edge-preserving smoothing [S1, unofficial]. The method is used in conjunction with statistical transfer function spaces to classify volume data, such as tumors in MRI datasets [S1, unofficial].
