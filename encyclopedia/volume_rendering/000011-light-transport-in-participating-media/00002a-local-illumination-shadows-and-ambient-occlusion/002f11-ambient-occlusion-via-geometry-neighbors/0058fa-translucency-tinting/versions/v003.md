# Translucency Tinting

Also called: Colored Light Through Glass

## Overview
Translucency Tinting tints volumetric light beams with the color of light passing through transparent objects (such as glass or curtains) by capturing a color map during the shadow capture pass [S1, unofficial]. It extends standard shadow occlusion by capturing color information from occluders into the light transport calculation, rather than merely attenuating intensity [S1, unofficial]. It builds on [Ambient Occlusion via Geometry/Neighbors](5936-ambient-occlusion-via-geometry-neighbors.md).

## How it works
**Inputs and Outputs:**
*   **Inputs:** Volumetric light parameters, transparent renderer materials, and light volume bounds.
*   **Outputs:** An HDR translucency map (color + depth) cached alongside the shadow map [S1, unofficial].

**Data Structures:**
*   **Translucency Map:** An HDR texture with the same resolution as the associated shadow map, storing RGB color data and depth information [S1, unofficial]. Bit packing and exact channel layout are Not given in the sources [S1, unofficial].
*   **Light Volume Bounds:** Axis-aligned bounding volumes used to cull objects; only objects whose bounds intersect the light's volume are processed [S1, unofficial].

**Steps:**
1.  **Enable Translucency:** Activate the Translucency option on the light source and attach the `Volumetric Lights Translucency` component to transparent renderers (e.g., stained glass, curtains) [S1, unofficial].
2.  **Culling:** Identify transparent renderers whose bounding volumes intersect the light's volume [S1, unofficial]. Distant objects outside this volume are excluded to save cost [S1, unofficial].
3.  **Render Pass:** During the OcclusionCam render pass (shared with shadow map capture), the selected transparent renderers draw their color into the HDR translucency map [S1, unofficial].
4.  **Depth Storage:** The pass simultaneously stores depth values in the translucency map [S1, unofficial].
5.  **Caching:** The translucency map is cached together with the shadow map [S1, unofficial].
6.  **Application:** During volume rendering, the beam color is tinted using the translucency map [S1, unofficial].

**Parameters:**
*   **Intensity (Light):** Scales the overall translucency effect on the light [S1, unofficial].
*   **Blending (Light):** Sets the amount of colorization applied to the light [S1, unofficial].
*   **Intensity Multiplier (Object):** Adjusts the tinting amount for a specific object [S1, unofficial].
*   **Base Texture Property Name:** Material property holding the texture (default `_BaseMap`, fallback `_MainTex`) [S1, unofficial].
*   **Base Color Property Name:** Material property holding the tint (default `_BaseColor`, fallback `_Color`) [S1, unofficial].
*   **Preserve Original Shader:** If enabled, renders the object with its own shader instead of the internal fast shader [S1, unofficial].

**Edge Cases and Pitfalls:**
*   **Platform Limitation:** Translucent shadow maps are not available on DirectX 12 with Forward+ or Deferred+ rendering paths [S1, unofficial]. Users must use DirectX 11 or another rendering path [S1, unofficial].
*   **Front/Back Ambiguity:** Without depth storage, the tint might incorrectly apply to the volume in front of the glass [S1, unofficial]. The translucency map's depth channel resolves this by ensuring only the color behind the glass is applied [S1, unofficial].

## Operating characteristics
*   **Performance:** Cost is proportional to the number of transparent objects intersecting the light volume [S1, unofficial]. Distant windows outside the volume incur no cost [S1, unofficial].
*   **Memory:** Requires an additional HDR texture with the same resolution as the shadow map [S1, unofficial].
*   **Strengths:** Provides realistic colored light patches on surfaces and within the beam volume [S1, unofficial].
*   **Limitations:** Restricted to specific rendering paths (DX11 preferred) and requires specific component setup [S1, unofficial].

## Background
Documented in a Kronnect guide for Unity URP volumetric lighting [S1, unofficial]. It extends standard shadow occlusion to include color information from translucent occluders [S1, unofficial].
