# Histogram-based Voxel Ambient Occlusion

Also called: Dynamic Ambient Occlusion, Histogram-based AO, Precomputed local histograms for ambient occlusion, Ropinski et al

## Overview
Histogram-based Voxel Ambient Occlusion is a local illumination technique for volume rendering that approximates ambient occlusion, color bleeding, and basic scattering effects by modulating precomputed intensity distributions (local histograms) with the transfer function during rendering [S1]. Unlike ray-based approaches such as Local AO, it uses vector quantization clustering to store these distributions in a 2D texture table, allowing real-time updates via GPU texture blending with only two additional texture lookups compared to standard gradient-based shading [S1].

## How it works
**Inputs and Outputs**
*   **Input:** Scalar volume data set, transfer function (mapping intensity to transparency $\tau_\alpha$ and emissive color $\tau_{rgb}$), and precomputed clustering data [S1].
*   **Output:** Final pixel color incorporating ambient occlusion, environmental color (color bleeding), and glow effects [S1].

**Data Structures**
1.  **Cluster ID Volume:** A scalar volume data set where each voxel stores an integer ID [S1]. This ID associates the voxel with a specific row in the 2D texture table [S1].
2.  **2D Texture Table:** Stores representative local histograms for clusters of similar voxels [S1]. The texture is indexed by the cluster ID [S1]. Each entry represents a normalized local histogram $LH$ [S1].

**Parameters**
*   $\Omega_R$: Radius of the region for which local histograms $LH$ have been precomputed [S1].
*   $b$: Data bit depth. The number of bins in the local histogram is $2^b$ [S1].
*   $\tau_\alpha(j)$: Transparency assigned to intensity bin $j$ [S1].
*   $\tau_{rgb}(j)$: Emissive color of voxels having intensity $j$ [S1].

**Algorithm Steps**
1.  **Precomputation (Offline):**
    1.  For each voxel in the volume, compute a local histogram of intensities within the neighborhood defined by radius $\Omega_R$ [S1].
    2.  Normalize these histograms [S1].
    3.  Perform similarity-based clustering (vector quantization) on the histograms to group similar neighborhoods [S1].
    4.  Store the representative histogram for each cluster in a 2D texture table [S1].
    5.  Generate the Cluster ID Volume, assigning each voxel the ID of its corresponding cluster [S1].
    *   *Note:* This stage is computationally expensive [S1]. Interactive clipping is not supported because changing the clipping plane would alter the density distribution in the voxel neighborhoods, invalidating the precomputed histograms [S1].

2.  **Rendering (Per Voxel/Sample):**
    1.  Retrieve the cluster ID for the current voxel $\tilde{x}$ from the Cluster ID Volume [S1].
    2.  Look up the representative local histogram $LH_{\tilde{x}}$ from the 2D Texture Table using the cluster ID [S1].
    3.  Modulate the histogram bins based on the transfer function transparency $\tau_\alpha(j)$ for each bin $j$ [S1].
    4.  Compute the local occlusion factor $O_{env}$ using the modulated histogram:
        $$ O_{env}(\tilde{x}, \nabla\tau(f(\tilde{x}))) = \frac{2}{3} \cdot \frac{1}{\pi \Omega_R} \sum_{0 \le j < 2^b} \tau_\alpha(j) \cdot LH_j(\tilde{x}) $$
        where $LH_j(\tilde{x})$ is the value of the histogram bin $j$ for the voxel's cluster [S1].
    5.  Compute the environmental color $E_{env}$ (for color bleeding) by modulating the histogram with the transfer function color $\tau_{rgb}(j)$:
        $$ E_{env}(\tilde{x}, \nabla\tau(f(\tilde{x}))) = \frac{2}{3} \cdot \frac{1}{\pi \Omega_R} \sum_{0 \le j < 2^b} \tau_\alpha(j) \cdot \tau_{rgb}(j) \cdot LH_j(\tilde{x}) $$
        [S1].
    6.  **For Isosurface Rendering:** Compute the ambient intensity $L_{amb}$ using the ambient light coefficient $k_a$:
        $$ L_{amb}(\tilde{x}) = 1.0 - O_{env}(\tilde{x}, \nabla\tau(f(\tilde{x}))) \cdot k_a $$
        [S1].
    7.  **For Direct Volume Rendering:** Compute the diffuse color coefficient $k_d$ by blending the transfer function color $\tau_{rgb}$ and the environmental color $E_{env}$ using $O_{env}$ as the blend factor [S1]. This simulates color bleeding, where the voxel's color is affected by its environment [S1].
    8.  **Glow Effect:** An additional mapping function can be used to modulate the local histograms to produce a simple glow effect, highlighting specific regions [S1].

**Pseudocode**
```python
import math

def precompute(volume_data, radius_Omega_R, bit_depth_b):
    raw_histograms = []
    num_bins = 2 ** bit_depth_b
    for voxel in volume_data:
        # [G] Standard 3D grid iteration to collect intensities within radius Ω_R
        neighborhood_intensities = get_voxel_neighbors(voxel, radius_Omega_R)
        hist = [0.0] * num_bins
        for intensity in neighborhood_intensities:
            bin_idx = int(intensity) % num_bins
            hist[bin_idx] += 1.0
        # Normalize histogram [S1]
        total = sum(hist)
        if total > 0:
            hist = [h / total for h in hist]
        raw_histograms.append(hist)

    # [G] Apply vector quantization (e.g., k-means) to group similar histograms
    clusters = perform_vector_quantization(raw_histograms)
    cluster_ids = [c.id for c in clusters]

    # Build 2D texture table and cluster ID volume [S1]
    texture_table = [c.representative for c in clusters]
    cluster_id_volume = [c.id for c in clusters.assignments]

    return texture_table, cluster_id_volume

def render_voxel(voxel_pos, texture_table, cluster_id_volume, tf_alpha, tf_rgb, Omega_R, bit_depth_b):
    cluster_id = cluster_id_volume[voxel_pos]
    histogram = texture_table[cluster_id]

    num_bins = 2 ** bit_depth_b
    normalization_factor = (2.0 / 3.0) / (math.pi * Omega_R)

    sum_occlusion = 0.0
    sum_env_color = [0.0, 0.0, 0.0]

    for j in range(num_bins):
        h_j = histogram[j]
        t_a = tf_alpha[j]
        t_c = tf_rgb[j]
        modulated_h = t_a * h_j
        sum_occlusion += modulated_h
        sum_env_color[0] += modulated_h * t_c[0]
        sum_env_color[1] += modulated_h * t_c[1]
        sum_env_color[2] += modulated_h * t_c[2]

    O_env = normalization_factor * sum_occlusion
    E_env = normalization_factor * sum_env_color

    # [G] Standard 3D grid lookup to retrieve intensity at voxel_pos
    current_voxel_color = tf_rgb[get_voxel_intensity(voxel_pos)]
    k_d = [
        current_voxel_color[0] * (1.0 - O_env) + E_env[0] * O_env,
        current_voxel_color[1] * (1.0 - O_env) + E_env[1] * O_env,
        current_voxel_color[2] * (1.0 - O_env) + E_env[2] * O_env
    ]

    return k_d
```

## Operating characteristics
*   **Performance:** Interactive rendering performance is achieved [S1]. It requires only two additional texture lookups compared to standard gradient-based shading [S1].
*   **Update Speed:** Illumination update time is very low because histogram modulation is performed through GPU texture blending [S1].
*   **Precomputation Cost:** The precomputation stage (computing local histograms and performing clustering) is expensive [S1]. However, CUDA-based optimizations can reduce precomputation times by a factor of up to 10 [S1].
*   **Limitations:** Interactive clipping is not supported because it would affect the density distribution in the voxel neighborhoods used for histogram precomputation [S1]. Only local shadows with a soft appearance are supported [S1]. The set of precomputed local histograms may become too large for large datasets, increasing memory requirements [S2, unofficial].
*   **Strengths:** Allows real-time updates of occlusion information and supports ambient occlusion, color bleeding, basic scattering, and glow effects in a unified framework [S1].

## Background
The method was introduced by Ropinski et al. in 2008 as "Dynamic Ambient Occlusion" [S1]. It was originally presented in the context of volume ray-casting [S1]. The approach was later discussed in the context of interactive volume rendering with volumetric illumination [S1]. A follow-up CUDA-based approach by Mess and Ropinski (2010) improved precomputation performance [S1].
