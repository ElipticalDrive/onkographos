# Physically-Based Rendering (PBR) Lighting
Also called: Disney PBR, Metallic-Roughness PBR

## Overview
Calculates direct lighting contributions for surface points using a physically-based shading model that separates diffuse and specular components, driven by metallic-roughness material inputs [S1, unofficial]. It differs from its parent [Direct Lighting and Shading](3953-direct-lighting-and-shading.md) by replacing the non-standard GGX-like specular term and Lambertian diffuse with the Burley diffuse model and a microfacet specular model, providing energy-conserving, view-dependent shading [S1, unofficial].

## How it works
**Inputs and Outputs**
- **Inputs**: `baseColor` (vec3, RGB), `mrSample` (vec4, RGBA), surface normal `n` (vec3), view direction `v` (vec3), light direction `l` (vec3).
- **Output**: `PBRInfo` struct containing precomputed dot products and material parameters for the shading evaluation.

**Data Structures**
The `PBRInfo` struct holds the following fields:
- `NdotL`: float
- `NdotV`: float
- `NdotH`: float
- `LdotH`: float
- `VdotH`: float
- `perceptualRoughness`: float
- `reflectance0`: vec3
- `reflectance90`: vec3
- `alphaRoughness`: float
- `diffuseColor`: vec3
- `specularColor`: vec3
- `n`: vec3
- `v`: vec3

**Steps**
1.  **Extract Material Properties**:
    -   Extract `perceptualRoughness` from `mrSample.g` (green channel).
    -   Extract `metallic` from `mrSample.b` (blue channel).
    -   Clamp `perceptualRoughness` to `[c_MinRoughness, 1.0]`, where `c_MinRoughness = 0.04` [S1, unofficial].
    -   Clamp `metallic` to `[0.0, 1.0]` [S1, unofficial].

2.  **Calculate Alpha Roughness**:
    -   Compute `alphaRoughness = perceptualRoughness * perceptualRoughness` [S1, unofficial].

3.  **Calculate Diffuse Color**:
    -   Define `f0 = vec3(0.04)` [S1, unofficial].
    -   Compute `diffuseColor = baseColor.rgb * (vec3(1.0) - f0)` [S1, unofficial].
    -   Apply metallic factor: `diffuseColor *= 1.0 - metallic` [S1, unofficial].

4.  **Calculate Specular Color**:
    -   Compute `specularColor = mix(f0, baseColor.rgb, metallic)` [S1, unofficial].

5.  **Calculate Grazing Reflectance**:
    -   Determine `reflectance` as the maximum component of `specularColor` [S1, unofficial].
    -   Compute `reflectance90 = clamp(reflectance * 25.0, 0.0, 1.0)` [S1, unofficial].
    -   Set `reflectance0 = specularColor` [S1, unofficial].

6.  **Compute Dot Products**:
    -   Compute `NdotL = dot(n, l)`.
    -   Compute `NdotV = clamp(abs(dot(n, v)), 0.001, 1.0)` [S1, unofficial].
    -   Compute half-vector `h = normalize(l + v)`.
    -   Compute `NdotH = dot(n, h)`.
    -   Compute `LdotH = dot(l, h)`.
    -   Compute `VdotH = dot(v, h)`.

7.  **Populate PBRInfo**:
    -   Fill the `PBRInfo` struct with the calculated values: `NdotL`, `NdotV`, `NdotH`, `LdotH`, `VdotH`, `perceptualRoughness`, `reflectance0`, `reflectance90`, `alphaRoughness`, `diffuseColor`, `specularColor`, `n`, `v` [S1, unofficial].

**Shading Evaluation**
Once `PBRInfo` is populated, the shading contributions are calculated as follows:

1.  **Diffuse Contribution (Burley Model)**:
    -   Compute `f90 = 2.0 * LdotH * LdotH * alphaRoughness - 0.5` [S1, unofficial].
    -   Compute diffuse term:
        $$
        \text{diffuse} = \frac{\text{diffuseColor}}{\pi} \times (1.0 + f90 \times (1.0 - \text{NdotL})^5) \times (1.0 + f90 \times (1.0 - \text{NdotV})^5)
        $$
        [S1, unofficial]

2.  **Specular Fresnel Term**:
    -   Compute:
        $$
        F = \text{reflectance0} + (\text{reflectance90} - \text{reflectance0}) \times \text{clamp}(1.0 - \text{VdotH}, 0.0, 1.0)^5
        $$
        [S1, unofficial]

3.  **Geometric Attenuation (Schlick-GGX)**:
    -   Compute `rSqr = alphaRoughness * alphaRoughness` [S1, unofficial].
    -   Compute attenuation for light:
        $$
        \text{attenuationL} = \frac{2.0 \times \text{NdotL}}{\text{NdotL} + \sqrt{\text{rSqr} + (1.0 - \text{rSqr}) \times \text{NdotL}^2}}
        $$
        [S1, unofficial]
    -   Compute attenuation for view:
        $$
        \text{attenuationV} = \frac{2.0 \times \text{NdotV}}{\text{NdotV} + \sqrt{\text{rSqr} + (1.0 - \text{rSqr}) \times \text{NdotV}^2}}
        $$
        [S1, unofficial]
    -   Return `attenuationL * attenuationV` [S1, unofficial].

4.  **Microfacet Distribution (Trowbridge-Reitz)**:
    -   Compute `roughnessSq = alphaRoughness * alphaRoughness` [S1, unofficial].
    -   Compute denominator factor:
        $$
        f = (\text{NdotH} \times \text{roughnessSq} - \text{NdotH}) \times \text{NdotH} + 1.0
        $$
        [S1, unofficial]
    -   Return distribution:
        $$
        D = \frac{\text{roughnessSq}}{\pi \times f^2}
        $$
        [S1, unofficial]

**Parameters**
-   `M_PI`: 3.141592653589793 [S1, unofficial].
-   `c_MinRoughness`: 0.04 [S1, unofficial].

**Pseudocode**
```python
import math

def calculate_pbr_info(base_color, mr_sample, n, v, l):
    # 1. Extract and clamp material properties
    perceptual_roughness = mr_sample.g
    metallic = mr_sample.b
    
    c_min_roughness = 0.04
    perceptual_roughness = max(c_min_roughness, min(1.0, perceptual_roughness))
    metallic = max(0.0, min(1.0, metallic))
    
    # 2. Calculate alpha roughness
    alpha_roughness = perceptual_roughness * perceptual_roughness
    
    # 3. Calculate diffuse color
    f0 = vec3(0.04, 0.04, 0.04)
    diffuse_color = base_color.rgb * (vec3(1.0) - f0)
    diffuse_color = diffuse_color * (1.0 - metallic)
    
    # 4. Calculate specular color
    specular_color = mix(f0, base_color.rgb, metallic)
    
    # 5. Calculate grazing reflectance
    reflectance = max(specular_color.r, max(specular_color.g, specular_color.b))
    reflectance90 = clamp(reflectance * 25.0, 0.0, 1.0)
    reflectance0 = specular_color
    
    # 6. Compute dot products
    n_dot_l = dot(n, l)
    n_dot_v = clamp(abs(dot(n, v)), 0.001, 1.0)
    
    h = normalize(l + v)
    n_dot_h = dot(n, h)
    l_dot_h = dot(l, h)
    v_dot_h = dot(v, h)
    
    # 7. Populate PBRInfo struct
    pbr_info = {
        'NdotL': n_dot_l,
        'NdotV': n_dot_v,
        'NdotH': n_dot_h,
        'LdotH': l_dot_h,
        'VdotH': v_dot_h,
        'perceptualRoughness': perceptual_roughness,
        'reflectance0': reflectance0,
        'reflectance90': reflectance90,
        'alphaRoughness': alpha_roughness,
        'diffuseColor': diffuse_color,
        'specularColor': specular_color,
        'n': n,
        'v': v
    }
    
    return pbr_info

def evaluate_diffuse(pbr_info):
    l_dot_h = pbr_info['LdotH']
    alpha_roughness = pbr_info['alphaRoughness']
    n_dot_l = pbr_info['NdotL']
    n_dot_v = pbr_info['NdotV']
    diffuse_color = pbr_info['diffuseColor']
    
    f90 = 2.0 * l_dot_h * l_dot_h * alpha_roughness - 0.5
    
    term1 = 1.0 + f90 * math.pow(1.0 - n_dot_l, 5.0)
    term2 = 1.0 + f90 * math.pow(1.0 - n_dot_v, 5.0)
    
    return (diffuse_color / math.pi) * term1 * term2

def evaluate_fresnel(pbr_info):
    reflectance0 = pbr_info['reflectance0']
    reflectance90 = pbr_info['reflectance90']
    v_dot_h = pbr_info['VdotH']
    
    f = reflectance0 + (reflectance90 - reflectance0) * math.pow(clamp(1.0 - v_dot_h, 0.0, 1.0), 5.0)
    return f

def evaluate_geometry(pbr_info):
    alpha_roughness = pbr_info['alphaRoughness']
    n_dot_l = pbr_info['NdotL']
    n_dot_v = pbr_info['NdotV']
    
    r_sqr = alpha_roughness * alpha_roughness
    
    denom_l = n_dot_l + math.sqrt(r_sqr + (1.0 - r_sqr) * n_dot_l * n_dot_l)
    attenuation_l = (2.0 * n_dot_l) / denom_l if denom_l != 0 else 0.0
    
    denom_v = n_dot_v + math.sqrt(r_sqr + (1.0 - r_sqr) * n_dot_v * n_dot_v)
    attenuation_v = (2.0 * n_dot_v) / denom_v if denom_v != 0 else 0.0
    
    return attenuation_l * attenuation_v

def evaluate_distribution(pbr_info):
    alpha_roughness = pbr_info['alphaRoughness']
    n_dot_h = pbr_info['NdotH']
    
    roughness_sq = alpha_roughness * alpha_roughness
    f = (n_dot_h * roughness_sq - n_dot_h) * n_dot_h + 1.0
    
    return roughness_sq / (math.pi * f * f)
```

**Edge Cases and Pitfalls**
-   **Precision**: `NdotV` is clamped to a minimum of 0.001 to avoid division by zero or instability in the geometric term when the view vector is nearly perpendicular to the normal [S1, unofficial].
-   **Boundaries**: Roughness is clamped to a minimum of 0.04 (`c_MinRoughness`) to prevent numerical issues associated with perfectly smooth surfaces in this specific approximation [S1, unofficial].
-   **Degenerate Input**: If `l + v` is zero (light and view directions are opposite), the half-vector `h` is undefined. The pseudocode assumes `l + v` is non-zero; in practice, this case implies the light is behind the viewer, which may result in zero lighting contribution anyway.

## Background
This method is derived from the Disney PBR shading model, specifically the implementation found in the "cgue22-greed" project repository [S1, unofficial]. It is used in the context of direct volume rendering to calculate lighting at surface intersections determined by ray marching and iso-surface extraction [S1, unofficial].
