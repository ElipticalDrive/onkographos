# PCF Shadow Lookup with Slope Scaling and Edge Fade

Also called: PCF with Slope Scaling and Edge Fade

## Overview
Computes sun shadow occlusion at a world position using a comparison sampler and a dynamic Percentage-Closer Filtering (PCF) kernel, with slope-scaled depth bias and distance-based edge fading to prevent peter-panning and hard shadow edges [S1, unofficial]. It differs from standard shadow mapping by offsetting the sample position along the surface normal rather than the light direction to maintain contact stability, and by fading occlusion at the periphery of the shadow map to avoid black artifacts at volume boundaries [S1, unofficial].

## How it works
**Inputs:**
- `world_pos`: The 3D world position of the point being shaded.
- `normal`: The surface normal at `world_pos`, normalized.
- `scene.shadow_params`: A uniform vector containing:
  - `.x`: Texel size in UV space.
  - `.y`: Base normal offset magnitude.
  - `.z`: Shadow strength multiplier (0 disables shadows).
  - `.w`: Kernel radius in texels (dynamically adjusted).
- `scene.light_view_proj`: The 4x4 view-projection matrix for the directional light.
- `shadow_map`: A `sampler2DShadow` comparison sampler [S1, unofficial].

**Outputs:**
- `float`: The final shadow occlusion value in the range $[0.0, 1.0]$, where 0.0 is fully lit and 1.0 is fully shadowed.

**Data Structures:**
- `shadow_map`: Declared as `layout(set = 0, binding = 2) uniform sampler2DShadow shadow_map;` [S1, unofficial]. This sampler performs the depth comparison internally.

**Constants:**
- `SHADOW_PCF_MAX_RADIUS = 4`: Limits the kernel half-width to a maximum of 9x9 samples [S1, unofficial].
- `SHADOW_SLOPE_OFFSET = 2.0`: Constant float for slope scaling bias [S1, unofficial].
- `SHADOW_FADE_START = 0.85`: Constant float, fraction of map half-width where fade begins [S1, unofficial].

**Steps:**
1.  **Normal-Light Alignment:** Calculate the dot product of the surface normal and the light direction, clamped to $[0.0, 1.0]$.
    $$ n\_dot\_l = \text{clamp}(\text{dot}(\text{normal}, \text{light\_dir}), 0.0, 1.0) $$
2.  **Slope-Scaled Offset:** Compute the normal offset magnitude. The offset increases as the surface becomes more perpendicular to the light (lower $n\_dot\_l$), mitigating peter-panning on steep angles.
    $$ \text{offset} = \text{scene.shadow\_params.y} \times (1.0 + \text{SHADOW\_SLOPE\_OFFSET} \times (1.0 - n\_dot\_l)) $$
3.  **Light Space Transformation:** Transform the world position, adjusted by the normal offset, into the light's clip space.
    $$ \text{light\_clip} = \text{scene.light\_view\_proj} \times \text{vec4}(\text{world\_pos} + \text{normal} \times \text{offset}, 1.0) $$
4.  **NDC Conversion:** Convert to Normalized Device Coordinates (NDC). If the point is outside the light's view frustum in depth ($z \le 0.0$ or $z \ge 1.0$), return 0.0 (fully lit) [S1, unofficial].
    $$ \text{ndc} = \text{light\_clip.xyz} / \text{light\_clip.w} $$
    If $\text{ndc.z} \le 0.0$ or $\text{ndc.z} \ge 1.0$, return $0.0$.
5.  **UV Mapping:** Convert NDC to texture coordinates. If outside $[0, 1]$, return 0.0 [S1, unofficial].
    $$ \text{uv} = \text{ndc.xy} \times 0.5 + 0.5 $$
    If $\text{uv.x} < 0.0$ or $\text{uv.x} > 1.0$ or $\text{uv.y} < 0.0$ or $\text{uv.y} > 1.0$, return $0.0$.
6.  **Kernel Setup:** Determine the texel size and clamp the kernel radius to the maximum allowed.
    $$ \text{texel} = \text{scene.shadow\_params.x} $$
    $$ \text{radius} = \text{clamp}(\text{int}(\text{scene.shadow\_params.w} + 0.5), 0, \text{SHADOW\_PCF\_MAX\_RADIUS}) $$
7.  **PCF Sampling:** Loop over the square kernel centered at `uv`. Accumulate the inverse of the shadow comparison result. **Pseudocode:**
```python
def pcf_shadow_lookup(world_pos, normal, light_dir, scene):
    # 1. Normal-Light Alignment
    n_dot_l = clamp(dot(normal, light_dir), 0.0, 1.0)
    
    # 2. Slope-Scaled Offset
    offset = scene.shadow_params.y * (1.0 + SHADOW_SLOPE_OFFSET * (1.0 - n_dot_l))
    
    # 3. Light Space Transformation
    light_clip = scene.light_view_proj * vec4(world_pos + normal * offset, 1.0)
    
    # 4. NDC Conversion
    ndc = light_clip.xyz / light_clip.w
    if ndc.z <= 0.0 or ndc.z >= 1.0:
        return 0.0 # Fully lit (outside frustum)
        
    # 5. UV Mapping
    uv = ndc.xy * 0.5 + 0.5
    if uv.x < 0.0 or uv.x > 1.0 or uv.y < 0.0 or uv.y > 1.0:
        return 0.0 # Fully lit (outside map)
        
    # 6. Kernel Setup
    texel = scene.shadow_params.x
    radius = clamp(int(scene.shadow_params.w + 0.5), 0, SHADOW_PCF_MAX_RADIUS)
    
    # 7. PCF Sampling
    occlusion_sum = 0.0
    kernel_size = (2 * radius + 1) * (2 * radius + 1)
    
    for y in range(-radius, radius + 1):
        for x in range(-radius, radius + 1):
            tap = uv + vec2(x, y) * texel
            # texture2DShadow returns 1.0 if depth <= stored, 0.0 otherwise
            shadow_sample = texture(shadow_map, vec3(tap, ndc.z))
            # Accumulate "lit" contribution (1 - shadow)
            occlusion_sum += 1.0 - shadow_sample
            
    # 8. Averaging
    occlusion = occlusion_sum / float(kernel_size)
    
    # 9. Edge Fade
    edge = max(abs(uv.x - 0.5), abs(uv.y - 0.5)) * 2.0
    fade = 1.0 - smoothstep(SHADOW_FADE_START, 1.0, edge)
    
    # 10. Final Result
    return occlusion * fade * scene.shadow_params.z
```

**Edge Cases and Pitfalls:**
- **Peter-Panning:** Pure depth bias can cause shadows to detach from geometry. Offsetting along the normal instead of the light direction keeps contact points fixed relative to the surface geometry [S1, unofficial].
- **Volume Edges:** If the point is outside the shadow map slab (NDC z out of bounds or UV out of bounds), the method returns 0.0 (fully lit) rather than 1.0 (fully shadowed). This prevents black walls at volume edges where the shadow map does not cover the entire scene [S1, unofficial].
- **Degenerate Normals:** If the model matrix is degenerate (e.g., fully flattened scale), the normal might be invalid. The source notes a check `length(result) > 1e-4` to fallback to a world normal, though this is part of the grain perturbation logic, not the shadow lookup itself. The shadow lookup assumes a valid `normal` input.

## Operating characteristics
- **Time Complexity:** $O(R^2)$ where $R$ is the kernel radius. With `SHADOW_PCF_MAX_RADIUS = 4`, the maximum number of texture lookups is $9 \times 9 = 81$ per sample. This is constant and small, making it suitable for real-time rendering.
- **Memory Complexity:** $O(1)$ additional memory beyond the shadow map texture.
- **Strengths:**
  - Prevents peter-panning via slope-scaled normal offset.
  - Softens shadow edges via PCF.
  - Avoids harsh artifacts at the boundaries of the shadow map via edge fading.
  - Simple to implement using standard hardware comparison samplers.
- **Limitations:**
  - Performance scales with kernel size; larger radii increase fill rate usage.
  - The edge fade is a heuristic and may not perfectly match the physical falloff of participating media shadows.
  - Relies on a pre-computed shadow map; does not handle dynamic shadow casting from participating media directly (requires volume shadow map generation).
- **When to use:** Suitable for real-time rendering of directional light shadows on surfaces or volume boundaries where soft shadows and stability are prioritized over exact physical accuracy.
- **When not to use:** Not suitable for high-precision offline rendering or when the shadow map resolution is insufficient to capture fine details, as PCF can blur these further.

## Background
This method is derived from the lighting implementation in the VoxelPhase project, which focuses on real-time volumetric rendering. It combines standard shadow mapping techniques with specific adjustments for volume rendering contexts, such as edge fading to handle the finite extent of shadow maps in large scenes. The slope-scaled offset is a common technique in shadow mapping (often attributed to Williams' "Casting Casting Shadows at a Distance" or similar bias techniques), adapted here for normal-based offsetting.
