# PCF Shadow Lookup with Slope Scaling and Edge Fade

Also called: PCF with Slope Scaling and Edge Fade

## Overview
This method computes sun shadow occlusion at a world position using Percentage-Closer Filtering (PCF) with a dynamic kernel, slope-scaled depth bias, and distance-based edge fading [S1, unofficial]. It prevents peter-panning by offsetting geometry along the surface normal rather than the light direction, and avoids hard shadow cutoffs at the shadow map boundaries by fading occlusion based on UV distance from the map center [S1, unofficial]. It differs from standard PCF Shadow Mapping by dynamically scaling the depth bias with surface orientation and applying a distance-based fade instead of a fixed bias and uniform kernel [S1, unofficial].

## How it works
**Inputs and Outputs:**
- `world_pos`: The 3D world-space position of the fragment being shaded [S1, unofficial].
- `normal`: The surface normal at `world_pos`, normalized [S1, unofficial].
- `light_dir`: The direction from the surface towards the light, normalized [S1, unofficial].
- `scene.light_view_proj`: The 4x4 view-projection matrix transforming world space to light clip space [S1, unofficial].
- `scene.shadow_params`: A uniform vector containing texel size (`x`), base normal offset magnitude (`y`), shadow strength multiplier (`z`), and kernel radius in texels (`w`) [S1, unofficial].
- `shadow_map`: A 2D depth texture bound as a comparison sampler [S1, unofficial].
- Output: `occlusion`, a float in `[0.0, 1.0]` representing final shadow intensity (0.0 = fully lit, 1.0 = fully shadowed) [S1, unofficial].

**Data Structures:**
- `shadow_map`: Declared as `layout(set = 0, binding = 2) uniform sampler2DShadow shadow_map;` [S1, unofficial]. The comparison sampler returns `1.0` if the stored depth is greater than the provided depth, and `0.0` otherwise [S1, unofficial].

**Parameters:**
- `SHADOW_PCF_MAX_RADIUS = 4`: Integer constant limiting the kernel half-width to a 9x9 grid [S1, unofficial].
- `SHADOW_SLOPE_OFFSET = 2.0`: Float constant for the slope-scaled bias multiplier [S1, unofficial].
- `SHADOW_FADE_START = 0.85`: Float constant representing the fraction of the map half-width where edge fading begins [S1, unofficial].

**Numbered Steps and Formulas:**
1. Calculate the dot product between the surface normal and the light direction: `n_dot_l = clamp(dot(normal, light_dir), 0.0, 1.0)` [S1, unofficial].
2. Compute the slope-scaled normal offset: `offset = scene.shadow_params.y * (1.0 + SHADOW_SLOPE_OFFSET * (1.0 - n_dot_l))` [S1, unofficial].
3. Transform the offset world position to light clip space: `light_clip = scene.light_view_proj * vec4(world_pos + normal * offset, 1.0)` [S1, unofficial].
4. Perform perspective division to obtain Normalized Device Coordinates: `ndc = light_clip.xyz / light_clip.w` [S1, unofficial].
5. Map NDC to texture UV space: `uv = ndc.xy * 0.5 + 0.5` [S1, unofficial].
6. Retrieve texel size and clamp the kernel radius: `texel = scene.shadow_params.x` and `radius = clamp(int(scene.shadow_params.w + 0.5), 0, SHADOW_PCF_MAX_RADIUS)` [S1, unofficial].
7. Initialize `occlusion = 0.0` and loop `y` from `-radius` to `radius`, `x` from `-radius` to `radius` [S1, unofficial]. Compute `tap = uv + vec2(x, y) * texel` and accumulate `occlusion += 1.0 - texture(shadow_map, vec3(tap, ndc.z))` [S1, unofficial].
8. Average the accumulated occlusion: `occlusion /= float((2 * radius + 1) * (2 * radius + 1))` [S1, unofficial].
9. Compute the edge distance from the UV center: `edge = max(abs(uv.x - 0.5), abs(uv.y - 0.5)) * 2.0` [S1, unofficial].
10. Compute the fade factor: `fade = 1.0 - smoothstep(SHADOW_FADE_START, 1.0, edge)` [S1, unofficial].
11. Return the final result: `occlusion * fade * scene.shadow_params.z` [S1, unofficial].

**Edge Cases and Pitfalls:**
- If `ndc.z <= 0.0 || ndc.z >= 1.0`, the point is outside the light's view frustum; return `0.0` [S1, unofficial].
- If `uv` falls outside `[0, 1]`, the point is outside the shadow map bounds; return `0.0` to avoid black walls at volume edges [S1, unofficial].
- Offsetting along the surface normal instead of the light direction keeps contact points fixed and prevents peter-panning [S1, unofficial].

**Pseudocode:**
```python
def pcf_shadow_lookup_with_slope_scaling_and_edge_fade(
    world_pos: vec3,
    normal: vec3,
    light_dir: vec3,
    light_view_proj: mat4,
    shadow_params: vec4,
    shadow_map: sampler2DShadow,
    SHADOW_PCF_MAX_RADIUS: int = 4,
    SHADOW_SLOPE_OFFSET: float = 2.0,
    SHADOW_FADE_START: float = 0.85
) -> float:
    # 1. Light Direction Dot Product
    n_dot_l = clamp(dot(normal, light_dir), 0.0, 1.0)

    # 2. Slope-Scaled Normal Offset
    offset = shadow_params.y * (1.0 + SHADOW_SLOPE_OFFSET * (1.0 - n_dot_l))

    # 3. Transform to Light Clip Space
    light_clip = light_view_proj * vec4(world_pos + normal * offset, 1.0)

    # 4. Convert to NDC
    ndc = vec3(light_clip.x / light_clip.w, light_clip.y / light_clip.w, light_clip.z / light_clip.w)

    # Edge case: Outside light frustum
    if ndc.z <= 0.0 or ndc.z >= 1.0:
        return 0.0

    # 5. Compute UV Coordinates
    uv = vec2(ndc.x * 0.5 + 0.5, ndc.y * 0.5 + 0.5)

    # Edge case: Outside shadow map bounds
    if uv.x < 0.0 or uv.x > 1.0 or uv.y < 0.0 or uv.y > 1.0:
        return 0.0

    # 6. Initialize PCF Kernel
    texel = shadow_params.x
    radius = clamp(int(shadow_params.w + 0.5), 0, SHADOW_PCF_MAX_RADIUS)

    # 7. Accumulate Occlusion
    occlusion = 0.0
    kernel_size = 2 * radius + 1
    for y in range(-radius, radius + 1):
        for x in range(-radius, radius + 1):
            tap = uv + vec2(x, y) * texel
            # Comparison sampler: 1.0 if stored_depth > provided_depth, else 0.0
            sample_val = texture(shadow_map, vec3(tap, ndc.z))
            occlusion += 1.0 - sample_val

    # 8. Average Occlusion
    occlusion = occlusion / float(kernel_size * kernel_size)

    # 9. Edge Fade
    edge = max(abs(uv.x - 0.5), abs(uv.y - 0.5)) * 2.0
    fade = 1.0 - smoothstep(SHADOW_FADE_START, 1.0, edge)

    # 10. Final Result
    return occlusion * fade * shadow_params.z
```

## Subtopics

### [PCF Shadow Mapping](11337-pcf-shadow-mapping.md)
Applies a fixed bias and a uniform 3x3 kernel without dynamic slope scaling or edge fading, trading geometric precision for simplicity.

## Operating characteristics
- **Time Complexity:** $O(R^2)$ per fragment, where $R$ is the PCF radius [S1, unofficial]. With $R=4$, this requires 81 texture samples per fragment [S1, unofficial].
- **Memory Complexity:** $O(1)$ additional memory per fragment, plus the shadow map texture size [S1, unofficial].
- **Strengths:** Reduces peter-panning and shadow acne by scaling bias with surface slope [S1, unofficial]. Fades occlusion at the shadow map periphery to prevent hard cutoff artifacts [S1, unofficial].
- **Limitations:** Performance cost increases quadratically with kernel radius [S1, unofficial]. Relies on a single shadow map [S1, unofficial]. The edge fade is a heuristic [S1, unofficial].
- **When to Use:** Static or semi-static scenes with a dominant directional light [S1, unofficial]. When visual continuity at shadow map boundaries is required for volumes or terrain [S1, unofficial].
- **When Not to Use:** Scenes with many dynamic shadow-casting objects where performance is critical [S1, unofficial]. When physically accurate soft shadows are required [S1, unofficial].

## Background
Implemented in the VoxelPhase engine [S1, unofficial]. It addresses peter-panning via normal-offset bias and hard shadow edges via distance-based fading [S1, unofficial]. The slope-scaled bias technique is a standard shadow mapping optimization, while the edge fade adapts it for volume rendering to prevent black artifacts at map boundaries [S1, unofficial].
