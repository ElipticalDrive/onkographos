# PCF Shadow Mapping

Also called: Percentage-Closer Filtering Shadows, Soft Shadow Mapping

## Overview
PCF Shadow Mapping renders soft shadows by comparing a fragment's light-space depth against a pre-rendered depth texture using a 3×3 sampling grid with Percentage-Closer Filtering (PCF) to produce soft shadow edges [S1, unofficial]. It builds on [PCF Shadow Lookup with Slope Scaling and Edge Fade](10994-pcf-shadow-lookup-with-slope-scaling-and-edge-fade.md) by applying a fixed bias and a uniform 3×3 kernel without dynamic slope scaling or edge fading, trading geometric precision for simplicity [S1, unofficial].

## How it works
**Inputs and Outputs**
*   **Input:** Fragment world position ($FragPos$), light-space transformation matrix ($lightSpaceMatrix$), shadow map texture ($shadowMap$), bias value ($bias$) [S1, unofficial].
*   **Output:** Shadow factor ($shadow$) in range $[0, 1]$, where 0 is fully lit and 1 is fully shadowed [S1, unofficial].

**Data Structures**
*   **Shadow Map:** A 2D depth texture of resolution $4096 \times 4096$ [S1, unofficial].
*   **Bias:** A scalar float, typically $0.001$ [S1, unofficial].

**Steps**
1.  Transform the fragment's world position to light space:
    $$ fragPosLightSpace = lightSpaceMatrix \times vec4(FragPos, 1.0) $$ [S1, unofficial].
2.  Perform perspective divide to obtain normalized device coordinates (NDC):
    $$ projCoords = \frac{fragPosLightSpace.xyz}{fragPosLightSpace.w} $$ [S1, unofficial].
3.  Map coordinates from the $[-1, 1]$ range to the $[0, 1]$ texture coordinate range:
    $$ projCoords = projCoords \times 0.5 + 0.5 $$ [S1, unofficial].
4.  Fetch the closest depth from the shadow map at the projected 2D coordinates:
    $$ closestDepth = texture(shadowMap, projCoords.xy).r $$ [S1, unofficial].
5.  Extract the current fragment's depth from light space:
    $$ currentDepth = projCoords.z $$ [S1, unofficial].
6.  Compute the texel size for filtering:
    $$ texelSize = \frac{1.0}{4096.0} $$ [S1, unofficial].
7.  Initialize the shadow accumulator to $0.0$ [S1, unofficial].
8.  Loop $x$ from $-1$ to $1$ and $y$ from $-1$ to $1$:
    *   Sample the shadow map at offset $(x, y) \times texelSize$ [S1, unofficial].
    *   Compare $currentDepth - bias$ against the sampled depth [S1, unofficial].
    *   Add $1.0$ if the fragment is in shadow (i.e., $currentDepth - bias > pcfDepth$), else add $0.0$ [S1, unofficial].
9.  Average the 9 samples:
    $$ shadow = \frac{accumulator}{15.0} $$ [S1, unofficial].
    *Note: The divisor 15.0 is used in the source implementation despite a 3×3 grid having 9 samples [S1, unofficial].*
10. If the fragment depth exceeds $1.0$ (outside the light frustum), force shadow to $0.0$ (fully lit) [S1, unofficial].

**Formula**
The shadow factor is computed as:
$$ shadow = \frac{1}{15} \sum_{x=-1}^{1} \sum_{y=-1}^{1} \text{step}(pcfDepth, currentDepth - bias) $$ [S1, unofficial].
Where:
*   $pcfDepth$ is the sampled shadow map depth [S1, unofficial].
*   $currentDepth$ is the fragment's light-space depth [S1, unofficial].
*   $bias$ prevents self-shadowing artifacts [S1, unofficial].

**Parameters**
*   **bias:** $0.001$ (hardcoded offset to prevent shadow acne/peter-panning) [S1, unofficial].
*   **shadowMap resolution:** $4096 \times 4096$ [S1, unofficial].

**Edge Cases and Pitfalls**
*   **Shadow Acne vs. Peter-Panning:** A fixed bias mitigates shadow acne but may cause peter-panning if too large or fail if too small [S1, unofficial].
*   **Out-of-Frustum Sampling:** Fragments with depth $z > 1.0$ are explicitly clamped to $0$ shadow to avoid sampling undefined depth values [S1, unofficial].

**Pseudocode**
```python
def pcf_shadow_mapping(frag_pos, light_space_matrix, shadow_map, bias=0.001):
    # 1. Transform to light space
    frag_pos_light_space = light_space_matrix * vec4(frag_pos, 1.0)
    
    # 2. Perspective divide
    proj_coords = frag_pos_light_space.xyz / frag_pos_light_space.w
    
    # 3. Map to [0, 1]
    proj_coords = proj_coords * 0.5 + 0.5
    
    # 10. Check if outside light frustum
    if proj_coords.z > 1.0:
        return 0.0
        
    # 4. Fetch closest depth
    closest_depth = texture(shadow_map, proj_coords.xy).r
    
    # 5. Current fragment depth
    current_depth = proj_coords.z
    
    # 6. Compute texel size
    texel_size = 1.0 / 4096.0
    
    # 7. Initialize accumulator
    shadow_accumulator = 0.0
    
    # 8. PCF Sampling
    for x in range(-1, 2):
        for y in range(-1, 2):
            pcf_depth = texture(shadow_map, proj_coords.xy + vec2(x, y) * texel_size).r
            if current_depth - bias > pcf_depth:
                shadow_accumulator += 1.0
                
    # 9. Average (using source-specific divisor)
    shadow = shadow_accumulator / 15.0
    
    return shadow
```

## Operating characteristics
*   **Time Complexity:** $O(1)$ per fragment, specifically 9 texture lookups and comparisons [S1, unofficial].
*   **Memory Complexity:** $O(W \times H)$ for the shadow map, where $W=4096, H=4096$ [S1, unofficial].
*   **Strengths:** Simple to implement; produces soft shadows without complex kernel calculations [S1, unofficial].
*   **Limitations:** Fixed bias can lead to artifacts (acne or peter-panning); no slope scaling or edge fading; uniform kernel size regardless of distance [S1, unofficial].
*   **When to use:** When simplicity is prioritized over artifact-free soft shadows; suitable for static or simple scenes [S1, unofficial].
*   **When not to use:** When high-quality soft shadows are required without bias artifacts; when dynamic bias or edge fading is needed [S1, unofficial].

## Background
PCF Shadow Mapping is a technique used in real-time rendering to soften shadow edges [S1, unofficial]. It is implemented in the VoxelEngine project, which uses a 3×3 grid and a fixed bias of 0.001 [S1, unofficial].
