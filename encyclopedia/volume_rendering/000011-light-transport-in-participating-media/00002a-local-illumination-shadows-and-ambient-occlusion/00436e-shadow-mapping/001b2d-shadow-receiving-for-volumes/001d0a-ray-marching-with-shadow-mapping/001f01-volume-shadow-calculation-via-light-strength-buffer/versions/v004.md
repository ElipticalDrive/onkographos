# Volume Shadow Calculation via Light Strength Buffer

Also called: 2D Shadow Buffer for Volumetric Shadows, 3D Light Strength Buffer Shadow Casting, 3D Shadow Casting, Light Strength Buffer Method, Williams 1978 two-pass approach (3D variant)

## Overview
Volume Shadow Calculation via Light Strength Buffer is a shadow casting method that stores shadow information in a 3D light strength buffer instead of a 2D shadow depth buffer, allowing correct rendering of penumbras, semi-transparent object shadows, and self-shadows for volumetric objects [S2, unofficial]. It differs from its parent method, [Ray Marching with Shadow Mapping](1415-ray-marching-with-shadow-mapping.md), by decoupling the shadow computation from the view ray and storing pre-computed attenuation in a 3D volume, and from [Shadow Volume Rendering](1556-shadow-volume-rendering.md) by using continuous light strength values rather than binary depth comparisons [S2, unofficial].

## How it works
**Inputs:**
- Volumetric data (voxel grid with opacity and color properties) [S3, unofficial].
- Polygonal geometry (optional, for hybrid scenes) [S3, unofficial].
- Light source definitions (position, initial strength) [S3, unofficial].

**Outputs:**
- A 3D light strength buffer storing attenuation values [S3, unofficial].
- Composite color and opacity volumes for final rendering [S3, unofficial].

**Data Structures:**
1. **Volumetric Data:** A 3D grid of voxels. Each voxel stores material properties (opacity $\alpha$, color $C$) [S3, unofficial].
2. **3D Light Strength Buffer:** A 3D grid aligned with the volumetric data. Each cell stores a scalar value $P$ representing the fractional light strength at that location [S3, unofficial].
3. **Composite Color/Opacity Arrays:** 3D grids storing $c_t$ (total color) and $o_c$ (composite opacity) for each voxel [S3, unofficial].

**Steps:**

1. **Shade and Classify:** Shade and classify the volumetric data. If polygons are present, shade and scan-convert them. Use volume matting operators to yield composite colors $C_i$ and opacity $O_c$ for each voxel for each light source $i$ [S3, unofficial].

2. **Cast Illumination Rays:** For each light source $i$, cast parallel illumination rays into the data volume [S3, unofficial].

3. **Compute Opacity and Attenuate:** For each sample position along the ray:
   - Compute the opacity $\alpha$ at the location by tri-linearly interpolating from the nearest eight voxels of the volumetric data [S3, unofficial].
   - Attenuate the ray strength using the formula:
     $$ P_{i,j+k} = P_{i,j} \left(1 - \frac{k_{i,j}}{d^2}\right) $$
     where:
     - $P_{i,j}$ is the light strength approaching the sample.
     - $P_{i,j+k}$ is the light strength leaving the sample.
     - $k_{i,j}$ is a constant for linear approximation of square-law attenuation.
     - $d$ is the distance from the light source to the sample location [S3, unofficial].

4. **Store Light Strengths:** Store the set of light strengths $P_{i,j}$ computed at each sample position along each ray in the 3D light strength buffer [S3, unofficial].

5. **Compute Total Color:** Compute the total color $c_t$ for each voxel as the weighted sum of light strengths mapped from voxel indices into the coordinate system of each light source $i$. This involves tri-linearly interpolating from the nearest eight light strength values in the buffer for each light source [S3, unofficial].

6. **Final Rendering:** Ray trace, resample, and composite the arrays of total color $c_t$ and composite opacity $o_c$ [S3, unofficial].

```python
def compute_light_strength_buffer(volumetric_data, light_sources, grid_shape):
    # Initialize 3D light strength buffer with zeros
    # Dimensions match volumetric_data: [light_count][Z][Y][X]
    light_strength_buffer = [[[0.0] * grid_shape[2] for _ in range(grid_shape[1])] for _ in range(grid_shape[0])]
    
    for light_idx, light in enumerate(light_sources):
        buffer = light_strength_buffer[light_idx]
        # Cast parallel rays from light source across the grid
        for x in range(grid_shape[0]):
            for y in range(grid_shape[1]):
                for z in range(grid_shape[2]):
                    sample_pos = (x, y, z)
                    # Distance from light source to sample
                    dx, dy, dz = sample_pos[0] - light.position[0], sample_pos[1] - light.position[1], sample_pos[2] - light.position[2]
                    distance = (dx**2 + dy**2 + dz**2)**0.5
                    
                    current_strength = light.initial_strength
                    
                    # Compute opacity by tri-linear interpolation from nearest 8 voxels
                    opacity = trilinear_interpolate(volumetric_data, sample_pos)
                    
                    # Constant for linear approximation of square-law attenuation
                    k = 1.0 
                    
                    # Attenuate strength: P_{i,j+k} = P_{i,j} * (1 - k / d^2)
                    if distance > 0:
                        attenuation_factor = 1.0 - (k / (distance ** 2))
                        attenuation_factor = max(0.0, attenuation_factor)
                        current_strength = current_strength * attenuation_factor
                    
                    # Store in buffer
                    buffer[x][y][z] = current_strength
    return light_strength_buffer

def compute_total_color(volumetric_data, light_strength_buffers, light_sources, grid_shape):
    total_color_volume = [[[0.0] * grid_shape[2] for _ in range(grid_shape[1])] for _ in range(grid_shape[0])]
    composite_opacity_volume = [[[0.0] * grid_shape[2] for _ in range(grid_shape[1])] for _ in range(grid_shape[0])]
    
    for x in range(grid_shape[0]):
        for y in range(grid_shape[1]):
            for z in range(grid_shape[2]):
                total_color = 0.0
                composite_opacity = 0.0
                
                for light_idx, light in enumerate(light_sources):
                    # Map voxel index into coordinate system of light source i
                    # and tri-linearly interpolate from nearest 8 light strength values
                    light_strength = trilinear_interpolate(light_strength_buffers[light_idx], (x, y, z))
                    
                    # Get voxel material properties
                    voxel_color = volumetric_data.color(x, y, z)
                    voxel_opacity = volumetric_data.opacity(x, y, z)
                    
                    # Weighted sum of light strengths
                    contribution = light_strength * voxel_color
                    total_color += contribution
                    composite_opacity += voxel_opacity
                    
                total_color_volume[x][y][z] = total_color
                composite_opacity_volume[x][y][z] = composite_opacity
    return total_color_volume, composite_opacity_volume
```

**Edge Cases and Pitfalls:**
- **Self-Shadowing Aliasing:** Surfaces in volumetric data (thickness of several voxels) tend to partially shadow themselves. Solution: Translate the 3-D light strength volume a few voxels away from the light source before computing $c_t$. This reduces accuracy within small objects but avoids distracting aliasing artifacts [S3, unofficial].
- **Memory Usage:** The 3D buffer requires significantly more memory than 2D shadow maps [S2, unofficial].

## Subtopics

### [Half-Angle Slicing for Incremental Lighting](3446-half-angle-slicing-for-incremental-lighting.md)
Half-Angle Slicing for Incremental Lighting is a multipass technique that computes volumetric shadows by accumulating light attenuation in an off-screen pixel buffer, thereby avoiding the memory overhead and leakage artifacts associated with volumetric shadow maps. It differs from its parent method, [Volume Shadow Calculation via Light Strength Buffer](1914-volume-shadow-calculation-via-light-strength-buffer.md), by decoupling the light transport sampling from the data volume resolution and using a single 2D buffer instead of a 3D volume.

### [Shadow Mapping for Volumes](11153-shadow-mapping-for-volumes.md)
Shadow Mapping for Volumes adapts the standard image-based shadow mapping technique to participate in light transport within volumetric data. It solves the problem of determining whether a sample point along a view ray is occluded by the volume itself when viewed from a light source. Unlike methods that compute exact volumetric occlusion integrals, this approach provides a binary shadow decision based on depth comparisons, offering a performance trade-off where speed is prioritized over physically accurate attenuation.

## Operating characteristics
- **Memory Complexity:** High. The 3D light strength buffer requires memory proportional to the volume of the scene, which is significantly greater than 2D shadow depth buffers [S2, unofficial].
- **Time Complexity:** Proportional to the number of light sources and the number of samples per ray. Each light source requires a separate pass to cast rays and populate the buffer.
- **Strengths:** Correctly renders penumbras, semi-transparent shadows, and self-shadows for volumetric objects. Avoids shadow aliasing problems associated with 2D shadow maps [S2, unofficial]. Handles shadows cast by polygons on volumetric objects and vice versa [S3, unofficial].
- **Limitations:** High memory consumption. Reduced accuracy within small objects due to the self-shadowing mitigation technique (translating the buffer) [S3, unofficial].
- **When to Use:** When physically accurate volumetric shadows, including penumbras and semi-transparency, are required and memory is not a constraint.
- **When Not to Use:** When memory is limited or real-time performance is critical and approximate binary shadows are acceptable.

## Background
The method employs a two-pass approach originally proposed by Williams (1978) but stores shadow information in a 3D light strength buffer instead of a 2D shadow depth buffer [S3, unofficial]. It was designed to handle mixtures of geometric and volumetric data, addressing the limitations of 2D shadow maps in rendering volumetric shadows [S3, unofficial]. The technique is cited in surveys of shadow casting algorithms by Nelson Max [S3, unofficial].
