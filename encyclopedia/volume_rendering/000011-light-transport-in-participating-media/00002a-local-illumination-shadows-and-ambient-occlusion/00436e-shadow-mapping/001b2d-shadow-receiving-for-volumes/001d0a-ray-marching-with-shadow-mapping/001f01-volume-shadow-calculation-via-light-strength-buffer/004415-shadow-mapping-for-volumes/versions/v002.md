# Shadow Mapping for Volumes

Also called: Image-based shadow algorithms

## Overview
Shadow Mapping for Volumes is an image-based shadow algorithm that determines occlusion for volumetric samples by comparing their depth against a precomputed depth buffer from the light's perspective [S1, unofficial]. It provides a fast binary shadow decision instead of computing exact volumetric attenuation integrals [S1, unofficial].

## How it works
**Inputs and Outputs:**
*   **Input:** Volumetric dataset, light source position and direction (for directional lights) or position (for point lights), and transfer function (required for alpha shadow maps) [S1, unofficial].
*   **Output:** A shadow map texture and the final rendered volume with shadowed regions [S1, unofficial].

**Data Structures:**
1.  **Standard Shadow Map:** A 2D texture storing depth values [S1, unofficial]. Each texel stores the distance from the light source to the first hit point along the light ray [S1, unofficial].
2.  **Alpha Shadow Map:** A 2D texture storing multiple layers per pixel [S1, unofficial]. Each layer consists of a pair $(d_i, \alpha_i)$ representing depth and transparency [S1, unofficial]. Control points for piecewise linear functions are saved to reconstruct the attenuation profile [S1, unofficial].

**Steps:**
1.  **Shadow Map Construction (Preprocessing):** Render the volume from the light source's perspective [S1, unofficial]. For each pixel in the light-space image, trace a ray through the volume [S1, unofficial]. Identify the first hit point (entry point) of the ray into the volume [S1, unofficial]. For standard maps, store the depth value $d$ of this first hit point in the shadow map [S1, unofficial]. For alpha shadow maps, save the first key value at the first hit point [S1, unofficial]. Evaluate an error function to determine if further sampling is needed [S1, unofficial]. If the error exceeds a threshold, save further key values to approximate the piecewise linear function of the volume's opacity profile [S1, unofficial].
2.  **Shadow Lookup (Rendering):** For each sample point $P$ along the view ray during volume raycasting, project $P$ into light space to obtain coordinates $(u, v)$ [S1, unofficial]. Retrieve the depth value $d_{\text{shadow}}$ from the shadow map at $(u, v)$ [S1, unofficial]. Compute the distance $d_{\text{sample}}$ from the light source to $P$ [S1, unofficial]. Compare $d_{\text{sample}}$ with $d_{\text{shadow}}$ to make a binary decision [S1, unofficial]. Apply a shadow threshold to mark the intensity limit [S1, unofficial]. Filter the shadow map to reduce artifacts [S1, unofficial].

**Formulas:**
*   Depth comparison: $d_{\text{sample}} > d_{\text{shadow}}$ indicates the sample is in shadow [S1, unofficial].
*   Depth comparison: $d_{\text{sample}} \le d_{\text{shadow}}$ indicates the sample is lit [S1, unofficial].

**Parameters:**
*   Error thresholds for alpha shadow map construction: $0.01$ and $0.00005$ [S1, unofficial].

**Pitfalls:**
*   Standard shadow maps only support opaque occluders [S1, unofficial].
*   The shadow map must be recomputed if the light source position changes or if the transfer function changes [S1, unofficial].
*   Depth precision limits can cause shadow acne or peter-panning artifacts [S1, unofficial].

**Pseudocode:**
```python
def construct_shadow_map(volume, light_view_matrix, is_alpha=False, error_threshold=0.01):
    shadow_map = create_texture(volume.resolution)
    for y, x in pixels:
        ray = trace_ray_through_volume(volume, light_view_matrix, x, y)
        hit_point = find_first_hit(ray)
        if hit_point is not None:
            depth = distance(light_origin, hit_point)
            if is_alpha:
                save_alpha_key(shadow_map, x, y, depth, transparency, error_threshold)
            else:
                shadow_map[x, y] = depth
    return shadow_map

def render_with_shadows(volume, view_matrix, shadow_map, light_view_matrix, shadow_threshold):
    image = create_image(volume.resolution)
    for y, x in pixels:
        ray = trace_ray_through_volume(volume, view_matrix, x, y)
        for sample in ray.samples:
            light_coords = project_to_light_space(light_view_matrix, sample.position)
            d_shadow = shadow_map[light_coords]
            d_sample = distance(light_origin, sample.position)
            if d_sample > d_shadow:
                sample.intensity *= shadow_threshold
            else:
                sample.intensity = full_light
        image[y, x] = accumulate_samples(ray.samples)
    apply_filtering(shadow_map)
    return image
```

## Subtopics

### Alpha Shadow Maps
A variant of shadow mapping that supports semi-transparent occluders by incorporating multiple layers of depth and transparency [S1, unofficial]. It differs from standard shadow mapping by saving control points of piecewise linear functions for each pixel instead of a single depth value [S1, unofficial]. Choose this when visual fidelity of shadows in semi-transparent media is required, accepting higher memory and preprocessing costs [S1, unofficial]. Error values of $0.01$ and $0.00005$ are cited as typical thresholds for determining the granularity of these control points [S1, unofficial].

## Operating characteristics
*   **Time Complexity:** Not given in the sources.

*   **Performance:** Not given in the sources.
*   **Strengths:** Fast, simple to implement, decouples shadow calculation from the main raycasting loop [S1, unofficial].
*   **Limitations:** Binary shadowing, opaque occluders only, requires recomputation on light or transfer function changes [S1, unofficial].

## Background
The technique was developed by Timo Ropinski, Markus Hadwiger, Patric Ljung, and Christof Rezk Salama as part of advanced illumination techniques for GPU-based volume raycasting [S1, unofficial]. It was presented in the 2008 thesis "Advanced Illumination Techniques for GPU-Based Volume Raycasting" [S1, unofficial].
