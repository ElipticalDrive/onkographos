# Volumetric Soft Shadowing

Also called: Soft Shadows (Volumetric), Volumetric Shadowing

## Overview
Volumetric Soft Shadowing estimates soft shadows in participating media by sampling random directions towards the light source, weighting samples by local density and distance [S1, unofficial]. It approximates the penumbra through stochastic sampling rather than geometric hard edges [S1, unofficial].

## How it works
**Inputs:**
- Volume density field $V(\mathbf{x})$ [S1, unofficial].
- Light direction vector $\mathbf{l}$ (from `vLight`) [S1, unofficial].
- Light radius parameter $R$ (`uLightRadious`) [S1, unofficial].
- Shading position $\mathbf{p}$ [S1, unofficial].
- Sample count $N$ (`uNumShadowSamples`) [S1, unofficial].
- Random seed `s` [S1, unofficial].

**Outputs:**
- Shadow contribution $S \in [0, 1]$ [S1, unofficial].

**Data Structures:**
- Accumulator `acc` initialized to $0.0$ [S1, unofficial].
- Persistent shadow state `shadow_contribution` (typically carries over from previous frames or accumulation passes) [S1, unofficial].

**Parameters:**
- `uNumShadowSamples`: Number of shadow samples per pixel. Default value: 10 [S1, unofficial].
- `uLightRadious`: Radius parameter for sampling distance [S1, unofficial].
- `uShadowsWeight`: Weight applied when mixing shadow contribution into final color. Default value: 0.54 [S1, unofficial].

**Steps:**
1. Initialize `acc = 0.0` [S1, unofficial].
2. Loop $i = 0$ to $N-1$:
   a. Generate random direction $\mathbf{d}$: $\mathbf{d} = \text{normalize}(\text{vec3}(-1.0 + l_x r_1, l_y + r_2 l_z, -1.0 + 2.0 r_3)) \cdot r_4$, where $r_k \sim \mathcal{U}[0,1]$ [S1, unofficial].
   b. Sample density $v = V(\mathbf{p} + \mathbf{d} R)$ [S1, unofficial].
   c. Compute intermediate weight $w = v \cdot 0.2$ [S1, unofficial].
   d. Update accumulator: `acc += v * w * length(d)` [S1, unofficial].
3. Post-process accumulator: `acc = pow(acc, 1.0) / N * 20.0`, then clamp to $[0, 1]$ [S1, unofficial].
4. Update shadow state: `S = mix(1.0 - S, acc, 1.2)`, where `mix(a, b, t) = a(1-t) + bt` [S1, unofficial]. The factor $1.2$ extrapolates beyond the standard $[0,1]$ range [G].
5. Normalize and clamp: `S /= 1.3`, then clamp to $[0, 1]$ [S1, unofficial].

**Pseudocode:**
```python
import math
import random

def vec3(x, y, z):
    return (x, y, z)

def length(v):
    return math.sqrt(v[0]**2 + v[1]**2 + v[2]**2)

def normalize(v):
    l = length(v)
    return vec3(v[0]/l, v[1]/l, v[2]/l) if l > 0 else vec3(0, 0, 0)

def mix(a, b, t):
    return a * (1.0 - t) + b * t

def clamp(x, lo, hi):
    return max(lo, min(hi, x))

def volumetric_soft_shadowing(position, light_dir, light_radius, num_samples, seed, sample_volume_func):
    acc = 0.0
    shadow_contribution = 0.0
    random.seed(seed)
    for _ in range(num_samples):
        r1 = random.random()
        r2 = random.random()
        r3 = random.random()
        r4 = random.random()
        dx = -1.0 + light_dir[0] * r1
        dy = light_dir[1] + r2 * light_dir[2]
        dz = -1.0 + 2.0 * r3
        direction = normalize(vec3(dx, dy, dz))
        direction = vec3(direction[0] * r4, direction[1] * r4, direction[2] * r4)
        sample_pos = vec3(position[0] + direction[0] * light_radius,
                          position[1] + direction[1] * light_radius,
                          position[2] + direction[2] * light_radius)
        v_sample = sample_volume_func(sample_pos)
        volume_shadow_sample = v_sample * 0.2
        acc += v_sample * volume_shadow_sample * length(direction)
    acc = pow(acc, 1.0) / num_samples * 20.0
    acc = clamp(acc, 0.0, 1.0)
    shadow_contribution = mix(1.0 - shadow_contribution, acc, 1.2)
    shadow_contribution /= 1.3
    shadow_contribution = clamp(shadow_contribution, 0.0, 1.0)
    return shadow_contribution
```

## Subtopics

### [Improved Global Illumination for Volume Rendering](8468-improved-global-illumination-for-volume-rendering.md)
A global illumination technique that simulates light transmission as continuous slices to produce realistic global illumination and real-time interactivity, but modifies the base method to generate soft shadows instead of hard shadows, thereby preserving local details. It differs from [Volumetric Soft Shadowing](4507-volumetric-soft-shadowing.md) by operating in volume space using a light volume generated slice-by-slice, and from [ZM13](https://doi.org/10.1111/cgf.12188) by avoiding back-lighting which fails with high-opacity data and lacks directional depth perception.

## Operating characteristics
- **Time Complexity:** $O(N)$ per pixel, where $N$ is the number of shadow samples [S1, unofficial].
- **Memory Complexity:** $O(1)$ auxiliary memory per pixel, plus the volume data structure [S1, unofficial].
- **Performance:** Depends heavily on the cost of volume sampling; stochastic sampling introduces noise if $N$ is low [S1, unofficial].
- **Strengths:** Produces soft shadows suitable for volumetric media with a relatively simple implementation [S1, unofficial].
- **Limitations:** Stochastic noise and empirical mixing parameters ($1.2$, $1.3$) that may not generalize across scenes [S1, unofficial].

## Background
The method is described in the context of the `terier/vpt` project, an unofficial implementation [S1, unofficial]. The specific parameters and mixing logic appear to be tuned for real-time or specific visual effects rather than physically based rendering [S1, unofficial].
