# Bounded Directional Shadow Ray Generation

Also called: Bounded Directional Shadow Rays, Hard/Soft/Hybrid Shadow Ray Dispatch

## Overview
Bounded Directional Shadow Ray Generation is a method for dispatching a batch of shadow rays from primary ray hit points to evaluate visibility against a directional light source (typically the sun) in voxel-based volume rendering [S1, S2, unofficial]. It solves the problem of efficiently computing hard, soft, contact, and hybrid shadows for participating media by converting world-space parameters into voxel-index units and batching ray generation to minimize overhead [S1, unofficial]. It differs from standard shadow ray casting by explicitly bounding the ray length and supporting multiple shadow modes (hard, soft, contact) within a single dispatch loop, optimizing for GPU or parallel CPU execution [S1, unofficial].

## How it works
**Inputs and Outputs:**
*   **Inputs:** Primary ray hit results (position, normal, hit status), global light direction ($gSunDirection$), shadow mode ($gShadowMode$), softness angle ($gShadowSoftnessRadians$), bias distance ($gShadowBiasMeters$), max contact shadow distance ($gContactShadowDistanceMeters$), max shadow distance ($gShadowMaxDistanceMeters$), maximum samples per ray ($kMaximumShadowSamples = 16$), and a random number generator state (e.g., Hammersley sequence) [S1, unofficial].
*   **Outputs:** A structured buffer of shadow rays ($gShadowRays$), where each ray contains origin, direction, maxDistance, and rayId [S1, unofficial].

**Data Structures:**
*   **Shadow Ray Structure:** Contains fields for `origin` (float3), `direction` (float3), `maxDistance` (float), and `rayId` (uint) [S1, unofficial].
*   **Dispatch Indexing:** Global index is decomposed into `pixelIndex` (primary ray ID) and `sampleIndex` (shadow sample ID) [S1, unofficial].

**Steps:**
1.  **Calculate Active Sample Count:** Determine the number of shadow samples to generate per primary hit based on $gShadowMode$ [S1, unofficial]:
    *   If $gShadowMode == kShadowOff$: $activeSamples = 0$.
    *   If $gShadowMode == kShadowHard$ or $kShadowContact$: $activeSamples = 1$.
    *   If $gShadowMode == kShadowHybrid$: $activeSamples = \min(\max(samples, 1) + 1, 16)$.
    *   If $gShadowMode == kShadowSoft$: $activeSamples = \min(\max(samples, 1), 16)$.
2.  **Dispatch Loop:** Iterate over global indices. For each `globalIndex`:
    *   Compute `pixelIndex = globalIndex / 16` and `sampleIndex = globalIndex % 16` [S1, unofficial].
    *   If `globalIndex >= totalCapacity` (where `totalCapacity = primaryRayCount * 16`), return [S1, unofficial].
    *   Fetch the primary ray result for `pixelIndex`. If `primary.hit == 0` or `sampleIndex >= activeSamples`, write a zero ray (or skip) and return [S1, unofficial].
3.  **Compute Ray Origin:**
    *   Start with `TraceHitPosition` from the primary ray result [S1, unofficial].
    *   Offset the origin along the surface normal to prevent self-shadowing:
        $$ \mathbf{p}_{shadow} = \mathbf{p}_{hit} + \mathbf{n} \cdot \max(10^{-3}, \text{MetersToVoxelUnits}(gShadowBiasMeters)) $$
    *   `MetersToVoxelUnits` converts world meters to voxel grid indices [S1, unofficial].
4.  **Determine Ray Direction:**
    *   If $gShadowMode$ is $kShadowContact$ or $kShadowHard$:
        $$ \mathbf{d} = \text{normalize}(gSunDirection) $$
    *   Otherwise (Soft or Hybrid):
        *   Generate a random pair from `RotatedHammersley2D` using `pixelIndex` and `diskIndex` (where `diskIndex = sampleIndex - 1` for Hybrid, `sampleIndex` for Soft) [S1, unofficial].
        *   Map to sun disk using Concentric Square Mapping:
            $$ \text{disk} = \text{ConcentricSquareToDisk}(\text{randomPair}) \times \tan(gShadowSoftnessRadians) $$
        *   Construct an orthonormal basis $(\mathbf{t}, \mathbf{b})$ from $gSunDirection$ using `BuildOrthonormalBasis` [S1, unofficial].
        *   Compute direction:
            $$ \mathbf{d} = \text{normalize}(gSunDirection + \mathbf{t} \cdot \text{disk}.x + \mathbf{b} \cdot \text{disk}.y) $$
5.  **Set Ray Bounds:**
    *   If $gShadowMode == kShadowContact$:
        $$ \text{maxDistance} = \text{MetersToVoxelUnits}(gContactShadowDistanceMeters) $$
    *   Otherwise:
        $$ \text{maxDistance} = \text{MetersToVoxelUnits}(gShadowMaxDistanceMeters) $$
6.  **Write Output:** Set `rayId = pixelIndex` and write the shadow ray (origin, direction, maxDistance, rayId) to $gShadowRays$ at index `globalIndex` [S1, unofficial].

**Pseudocode:**
```python
import math

def MetersToVoxelUnits(meters, voxel_size):
    """Converts world meters to voxel grid indices."""
    return meters / voxel_size

def ConcentricSquareToDisk(uv):
    """Maps a point in the unit square to the unit disk using concentric mapping."""
    u = 2.0 * uv.x - 1.0
    v = 2.0 * uv.y - 1.0
    r = math.sqrt(max(0.0, min(1.0, u*u + v*v))) # Clamp to avoid NaN if u^2+v^2 > 1 due to precision
    theta = 2.0 * math.pi * (u / (r + 1e-6)) # Avoid division by zero
    # Standard concentric mapping implementation
    r_disk = math.sqrt(max(0.0, u*u + v*v))
    if r_disk == 0:
        return (0.0, 0.0)
    theta = math.atan2(v, u)
    return (r_disk * math.cos(theta), r_disk * math.sin(theta))

def BuildOrthonormalBasis(normal):
    """Constructs tangent and bitangent vectors for a given normal."""
    # Simple method: pick an arbitrary vector not parallel to normal
    if abs(normal.x) < 0.9:
        tangent = normalize(cross(normal, (1.0, 0.0, 0.0)))
    else:
        tangent = normalize(cross(normal, (0.0, 1.0, 0.0)))
    bitangent = cross(normal, tangent)
    return tangent, bitangent

def normalize(v):
    length = math.sqrt(v[0]**2 + v[1]**2 + v[2]**2)
    if length == 0: return (0.0, 0.0, 0.0)
    return (v[0]/length, v[1]/length, v[2]/length)

def cross(a, b):
    return (a[1]*b[2] - a[2]*b[1],
            a[2]*b[0] - a[0]*b[2],
            a[0]*b[1] - a[1]*b[0])

def generate_shadow_rays(primary_hits, gSunDirection, gShadowMode, gShadowSoftnessRadians, 
                         gShadowBiasMeters, gContactShadowDistanceMeters, gShadowMaxDistanceMeters,
                         voxel_size, samples, total_primary_rays, hammersley_generator):
    """
    Generates bounded directional shadow rays.
    """
    kMaximumShadowSamples = 16
    shadow_rays = []
    
    # Precompute voxel unit conversions
    bias_voxels = MetersToVoxelUnits(gShadowBiasMeters, voxel_size)
    contact_dist_voxels = MetersToVoxelUnits(gContactShadowDistanceMeters, voxel_size)
    max_dist_voxels = MetersToVoxelUnits(gShadowMaxDistanceMeters, voxel_size)
    
    # Determine active samples based on mode
    if gShadowMode == "kShadowOff":
        active_samples = 0
    elif gShadowMode in ["kShadowHard", "kShadowContact"]:
        active_samples = 1
    elif gShadowMode == "kShadowHybrid":
        active_samples = min(max(samples, 1) + 1, kMaximumShadowSamples)
    elif gShadowMode == "kShadowSoft":
        active_samples = min(max(samples, 1), kMaximumShadowSamples)
    else:
        active_samples = 0 # Default off

    total_capacity = total_primary_rays * 16
    
    for global_index in range(total_capacity):
        if global_index >= total_capacity:
            break
            
        pixel_index = global_index // 16
        sample_index = global_index % 16
        
        # Fetch primary result
        if pixel_index >= len(primary_hits):
            # Write zero ray or skip depending on buffer size constraints
            shadow_rays.append({"origin": (0,0,0), "direction": (0,0,0), "maxDistance": 0, "rayId": pixel_index})
            continue
            
        primary = primary_hits[pixel_index]
        
        if primary.hit == 0 or sample_index >= active_samples:
            shadow_rays.append({"origin": (0,0,0), "direction": (0,0,0), "maxDistance": 0, "rayId": pixel_index})
            continue
            
        # Compute Ray Origin
        hit_pos = primary.position
        normal = primary.normal
        offset = max(1e-3, bias_voxels)
        origin = (hit_pos[0] + normal[0] * offset,
                  hit_pos[1] + normal[1] * offset,
                  hit_pos[2] + normal[2] * offset)
        
        # Determine Ray Direction
        if gShadowMode in ["kShadowContact", "kShadowHard"]:
            direction = normalize(gSunDirection)
        else:
            # Soft/Hybrid sampling
            disk_index = sample_index - 1 if gShadowMode == "kShadowHybrid" else sample_index
            # Get random pair from Hammersley sequence
            random_pair = hammersley_generator.get(pixel_index, disk_index)
            
            # Sun disk sampling
            tan_softness = math.tan(gShadowSoftnessRadians)
            disk = ConcentricSquareToDisk(random_pair)
            disk = (disk[0] * tan_softness, disk[1] * tan_softness)
            
            # Build basis
            tangent, bitangent = BuildOrthonormalBasis(gSunDirection)
            
            # Direction calculation
            dir_x = gSunDirection[0] + tangent[0] * disk[0] + bitangent[0] * disk[1]
            dir_y = gSunDirection[1] + tangent[1] * disk[0] + bitangent[1] * disk[1]
            dir_z = gSunDirection[2] + tangent[2] * disk[0] + bitangent[2] * disk[1]
            direction = normalize((dir_x, dir_y, dir_z))
            
        # Set Ray Max Distance
        if gShadowMode == "kShadowContact":
            max_distance = contact_dist_voxels
        else:
            max_distance = max_dist_voxels
            
        shadow_rays.append({
            "origin": origin,
            "direction": direction,
            "maxDistance": max_distance,
            "rayId": pixel_index
        })
        
    return shadow_rays
```

**Parameters:**
*   $kMaximumShadowSamples$: 16 [S1, unofficial].
*   $gShadowMode$: Enum ($kShadowOff, kShadowHard, kShadowContact, kShadowHybrid$) [S1, unofficial].
*   $gShadowSoftnessRadians$: Angular radius of the sun disk [S1, unofficial].
*   $gShadowBiasMeters$: Bias in meters [S1, unofficial].
*   $gContactShadowDistanceMeters$: Max distance for contact shadows [S1, unofficial].

**Edge Cases and Pitfalls:**
*   **Precision:** When computing `ConcentricSquareToDisk`, ensure inputs are normalized to $[-1, 1]$ and handle $r=0$ to avoid NaNs [S1, unofficial].
*   **Boundaries:** If `pixelIndex` exceeds the number of primary rays, the loop must terminate or write dummy rays to maintain buffer integrity [S1, unofficial].
*   **Self-Shadowing:** The bias offset must be sufficient to prevent artifacts but small enough not to create gaps; `max(1e-3, ...)` ensures a minimum voxel-unit offset [S1, unofficial].

## Subtopics

### Camera-Following Sky Dome & Sun Shadow Frustum
A variant where the shadow generation is tied to a camera-following sky dome and directional key light [S2, unofficial]. The sky dome mirrors the biome gradient and sun disc, following the camera to prevent streamed chunks from reaching the dome edge [S2, unofficial]. The directional key light matches the biome sun and follows the camera, ensuring the shadow frustum tracks the player [S2, unofficial]. Voxel shadows are cast by this light, gated by a quality preset (mapSize/enabled) [S2, unofficial]. This approach replaces static placeholder lights and ensures consistent shadow quality relative to the viewer [S2, unofficial].

## Operating characteristics
*   **Time Complexity:** $O(N \cdot S)$, where $N$ is the number of primary ray hits and $S$ is the number of shadow samples per hit (up to 16) [S1, unofficial]. The dispatch is parallelizable across pixels and samples.
*   **Memory Complexity:** $O(N \cdot 16)$ for the shadow ray buffer, assuming a fixed maximum of 16 samples per primary ray [S1, unofficial].
*   **Performance:** Efficient for GPU dispatch due to batched generation. The use of Hammersley sequences provides low-discrepancy sampling for soft shadows without requiring complex jittering [S1, unofficial].
*   **Strengths:** Supports multiple shadow modes (hard, soft, contact, hybrid) in a single pass; bounded rays reduce unnecessary volume traversal; bias handling prevents self-shadowing artifacts [S1, unofficial].
*   **Limitations:** Fixed maximum of 16 samples may limit soft shadow quality for very large light sources; contact shadows are limited by a fixed distance parameter [S1, unofficial].
*   **When to Use:** Real-time voxel rendering where shadow performance is critical and multiple shadow types are needed [S1, unofficial].
*   **When Not to Use:** Offline rendering requiring high-quality soft shadows with many samples, or scenes where shadow distance varies dynamically beyond the fixed bounds [S1, unofficial].

## Background
This method originates from the implementation details of the `destructible-voxel-engine` by HiroSakuraba, specifically in the shadow ray generation pipeline [S1, unofficial]. It is designed to integrate with a voxel-based lighting system that supports hard, soft, and contact shadows for directional lights (sun) [S1, unofficial]. The approach is also referenced in the context of Phase 9 voxel surface exploration, where camera-following shadow frustums are used to maintain shadow consistency in streamed worlds [S2, unofficial].
