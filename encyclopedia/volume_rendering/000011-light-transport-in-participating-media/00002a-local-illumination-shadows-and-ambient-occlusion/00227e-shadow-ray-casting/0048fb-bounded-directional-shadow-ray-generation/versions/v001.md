# Bounded Directional Shadow Ray Generation

Also called: Bounded Directional Shadow Rays, Bounded Shadow Ray Dispatch

## Overview
This method generates a bounded set of directional shadow rays for hard, soft-area, contact, and hybrid shadow modes, converting authored metric distances into the tracer's voxel-index units [S1, unofficial]. It differs from [Direct Illumination with Shadow Rays](2011-direct-illumination-with-shadow-rays.md) by decoupling ray generation from the primary shading pass into a dedicated dispatch loop that handles multiple samples per primary hit, and from [Soft Shadows via Ray Tracing](5136-soft-shadows-via-ray-tracing.md) by using a fixed maximum sample count and explicit bounding distances rather than adaptive depth or recursive tracing.

## How it works
**Inputs and Outputs:**
*   **Inputs:** Primary ray hit results (position, normal, hit flag), global shadow configuration parameters (mode, softness, bias, max distances), and a random number generator state.
*   **Outputs:** A buffer of shadow rays (`gShadowRays`), where each ray contains origin, direction, and maximum distance.

**Data Structures:**
*   `ShadowRay`: A structure containing `origin` (float3), `direction` (float3), `maxDistance` (float), and `rayId` (uint32).
*   `TraceHitResult`: Contains `hit` (bool/uint32), `position` (float3), and `normal` (float3).
*   The dispatch uses a global index space where each primary ray can generate up to 16 shadow rays.

**Parameters:**
*   `kMaximumShadowSamples`: 16 [S1, unofficial].
*   `gShadowMode`: Enum (`kShadowOff`, `kShadowHard`, `kShadowContact`, `kShadowHybrid`) [S1, unofficial].
*   `gShadowSoftnessRadians`: Angular radius of the sun disk [S1, unofficial].
*   `gShadowBiasMeters`: Bias to prevent self-shadowing, converted to voxel units [S1, unofficial].
*   `gContactShadowDistanceMeters`: Max distance for contact shadows, converted to voxel units [S1, unofficial].
*   `gShadowMaxDistanceMeters`: Max distance for standard shadows, converted to voxel units [S1, unofficial].

**Steps:**
1.  **Calculate Active Sample Count:**
    *   If `gShadowMode` is `kShadowOff`, count is 0.
    *   If `gShadowMode` is `kShadowHard` or `kShadowContact`, count is 1.
    *   If `gShadowMode` is `kShadowHybrid`, count is `min(max(samples, 1) + 1, 16)` [S1, unofficial].
    *   If `gShadowMode` is `kShadowSoft`, count is `min(max(samples, 1), 16)` [S1, unofficial].

2.  **Dispatch Loop:**
    *   Iterate `globalIndex` from 0 to `totalCapacity - 1`, where `totalCapacity = primaryRayCount * 16`.
    *   Compute `pixelIndex = globalIndex / 16` and `sampleIndex = globalIndex % 16`.
    *   If `globalIndex >= totalCapacity`, return.

3.  **Fetch Primary Result:**
    *   Retrieve the `TraceHitResult` for `pixelIndex`.
    *   If `primary.hit == 0` or `sampleIndex >= activeSamples`, write a zero-initialized ray to `gShadowRays[globalIndex]` and return.

4.  **Compute Ray Origin:**
    *   Let `p` be `primary.position` and `n` be `primary.normal`.
    *   Calculate bias: `bias = max(1e-3, MetersToVoxelUnits(gShadowBiasMeters))`.
    *   Set `ray.origin = p + n * bias`.

5.  **Determine Ray Direction:**
    *   If `gShadowMode` is `kShadowContact` or `kShadowHard`:
        *   `ray.direction = normalize(gSunDirection)`.
    *   Otherwise (Soft or Hybrid):
        *   Determine `diskIndex`: `sampleIndex - 1` if Hybrid, `sampleIndex` if Soft.
        *   Generate `randomPair` using `RotatedHammersley2D(pixelIndex, diskIndex)`.
        *   Calculate `disk = ConcentricSquareToDisk(randomPair) * tan(gShadowSoftnessRadians)`.
        *   Construct orthonormal basis (`tangent`, `bitangent`) from `gSunDirection` using `BuildOrthonormalBasis`.
        *   `ray.direction = normalize(gSunDirection + tangent * disk.x + bitangent * disk.y)`.

6.  **Set Ray Max Distance:**
    *   If `gShadowMode` is `kShadowContact`:
        *   `ray.maxDistance = MetersToVoxelUnits(gContactShadowDistanceMeters)`.
    *   Otherwise:
        *   `ray.maxDistance = MetersToVoxelUnits(gShadowMaxDistanceMeters)`.

7.  **Write Ray:**
    *   Set `ray.rayId = pixelIndex`.
    *   Write `ray` to `gShadowRays[globalIndex]`.

**Pseudocode:**
```python
def generate_shadow_rays(primary_hits, global_shadow_config, random_state):
    """
    primary_hits: List of TraceHitResult for each primary ray.
    global_shadow_config: Object containing gShadowMode, gShadowSoftnessRadians, etc.
    random_state: State for RotatedHammersley2D.
    Returns: List of ShadowRay.
    """
    k_max_samples = 16
    shadow_mode = global_shadow_config.gShadowMode
    softness_rad = global_shadow_config.gShadowSoftnessRadians
    bias_meters = global_shadow_config.gShadowBiasMeters
    contact_dist_meters = global_shadow_config.gContactShadowDistanceMeters
    max_dist_meters = global_shadow_config.gShadowMaxDistanceMeters
    sun_direction = global_shadow_config.gSunDirection
    
    # Convert metric units to voxel units
    bias_voxels = max(1e-3, meters_to_voxel_units(bias_meters))
    contact_dist_voxels = meters_to_voxel_units(contact_dist_meters)
    max_dist_voxels = meters_to_voxel_units(max_dist_meters)
    
    primary_ray_count = len(primary_hits)
    total_capacity = primary_ray_count * k_max_samples
    shadow_rays = [None] * total_capacity
    
    # Determine active samples based on mode
    if shadow_mode == 'kShadowOff':
        active_samples = 0
    elif shadow_mode in ['kShadowHard', 'kShadowContact']:
        active_samples = 1
    elif shadow_mode == 'kShadowHybrid':
        # Assuming 'samples' is a parameter, defaulting to 1 if not specified in notes
        # Note: The source says min(max(samples, 1)+1, 16). We assume samples=1 for hard-like behavior in hybrid base
        # or it's a configurable parameter. For implementation, we treat 'samples' as a variable.
        # Since the note doesn't specify where 'samples' comes from, we assume it's a fixed config value.
        # Let's assume a default of 1 for the base calculation if not provided, 
        # but strictly following the note: min(max(samples, 1)+1, 16).
        # We will use a placeholder 'base_samples' which is likely 1 or a config param.
        # To be safe and generic, we'll assume base_samples is 1 for the 'hard' component of hybrid.
        base_samples = 1 
        active_samples = min(max(base_samples, 1) + 1, k_max_samples)
    elif shadow_mode == 'kShadowSoft':
        base_samples = 1
        active_samples = min(max(base_samples, 1), k_max_samples)
    else:
        active_samples = 0

    for global_index in range(total_capacity):
        pixel_index = global_index // k_max_samples
        sample_index = global_index % k_max_samples
        
        if global_index >= total_capacity:
            break
            
        # Fetch primary result
        if pixel_index >= len(primary_hits):
            shadow_rays[global_index] = create_zero_ray()
            continue
            
        hit_result = primary_hits[pixel_index]
        
        if hit_result.hit == 0 or sample_index >= active_samples:
            shadow_rays[global_index] = create_zero_ray()
            continue
            
        # Compute Ray Origin
        p = hit_result.position
        n = hit_result.normal
        ray_origin = p + n * bias_voxels
        
        # Determine Ray Direction
        if shadow_mode in ['kShadowContact', 'kShadowHard']:
            ray_direction = normalize(sun_direction)
        else:
            # Soft or Hybrid
            disk_index = sample_index - 1 if shadow_mode == 'kShadowHybrid' else sample_index
            random_pair = rotated_hammersley_2d(pixel_index, disk_index, random_state)
            disk = concentric_square_to_disk(random_pair) * tan(softness_rad)
            
            tangent, bitangent = build_orthonormal_basis(sun_direction)
            ray_direction = normalize(sun_direction + tangent * disk.x + bitangent * disk.y)
            
        # Set Ray Max Distance
        if shadow_mode == 'kShadowContact':
            ray_max_distance = contact_dist_voxels
        else:
            ray_max_distance = max_dist_voxels
            
        # Write Ray
        shadow_ray = ShadowRay()
        shadow_ray.origin = ray_origin
        shadow_ray.direction = ray_direction
        shadow_ray.max_distance = ray_max_distance
        shadow_ray.ray_id = pixel_index
        shadow_rays[global_index] = shadow_ray
        
    return shadow_rays

def create_zero_ray():
    return ShadowRay(origin=[0,0,0], direction=[0,0,0], max_distance=0, ray_id=0)

def meters_to_voxel_units(meters):
    # Implementation depends on voxel size, assumed known in context
    return meters / voxel_size

def normalize(v):
    length = sqrt(v.x**2 + v.y**2 + v.z**2)
    if length == 0: return [0,0,0]
    return [v.x/length, v.y/length, v.z/length]

def tan(x):
    return sin(x) / cos(x)

def build_orthonormal_basis(v):
    # Standard basis construction
    if abs(v.x) > abs(v.y):
        inv_len = 1.0 / sqrt(v.x**2 + v.z**2)
        tangent = [v.z * inv_len, 0, -v.x * inv_len]
    else:
        inv_len = 1.0 / sqrt(v.y**2 + v.z**2)
        tangent = [0, v.z * inv_len, -v.y * inv_len]
    bitangent = cross(v, tangent)
    return tangent, bitangent

def cross(a, b):
    return [a.y*b.z - a.z*b.y, a.z*b.x - a.x*b.z, a.x*b.y - a.y*b.x]

def concentric_square_to_disk(uv):
    # Map unit square to unit disk
    u = 2 * uv[0] - 1
    v = 2 * uv[1] - 1
    r = sqrt(u**2 + v**2)
    theta = atan2(v, u)
    if r <= 1:
        return [r * cos(theta), r * sin(theta)]
    else:
        # Fallback or normalization if outside, though concentric mapping usually stays within
        return [u/sqrt(u**2+v**2), v/sqrt(u**2+v**2)]
```

**Edge Cases and Pitfalls:**
*   **Precision:** Converting meters to voxel units can introduce precision errors if the voxel size is very small or very large. Ensure consistent unit handling [S1, unofficial].
*   **Bias Artifacts:** If `gShadowBiasMeters` is too small, self-shadowing artifacts (acne) may occur. If too large, shadows may appear detached from the object [S1, unofficial].
*   **Boundary Conditions:** If `primary.hit == 0`, the ray generation must gracefully handle the absence of a hit position and normal, writing a zero ray to avoid invalid memory access or NaN propagation [S1, unofficial].
*   **Sample Count Limits:** The hard limit of 16 samples per primary ray means that for very soft shadows, the angular resolution is capped. Increasing `kMaximumShadowSamples` requires modifying the dispatch loop capacity [S1, unofficial].

## Operating characteristics
*   **Time Complexity:** $O(N \cdot S)$, where $N$ is the number of primary rays and $S$ is the active sample count (up to 16). The generation is parallelizable across primary rays and samples.
*   **Memory Complexity:** $O(N \cdot 16)$ for the shadow ray buffer.
*   **Performance:** The method is efficient for hard and contact shadows (1 sample). For soft shadows, performance scales linearly with the number of samples, up to the limit of 16. The fixed dispatch size allows for efficient GPU kernel launches or thread block configurations.
*   **Strengths:** Simple to implement, deterministic sample placement via Hammersley sequence, bounded memory usage.
*   **Limitations:** Fixed maximum sample count limits soft shadow quality. Contact shadows are limited by a fixed distance parameter. Not suitable for dynamic light sources that change position frequently without regenerating the sun direction basis.

## Background
This method is part of the destructible voxel engine's lighting system, specifically designed for real-time shadowing in voxel-based environments. It is documented in the context of the `adversarial_bench.cpp` application and the broader engine architecture [S1, unofficial]. The approach leverages the structured nature of voxel data to optimize shadow ray generation, converting metric world units to voxel indices for efficient traversal.
