# Direct Illumination with Shadow Rays

Also called: Direct Lighting with Shadows, Direct Lighting with Volume Transmittance, Direct Radiance with Volumetric Transmittance, Shadow Ray Illumination, Shadow Ray Lighting

## Overview
Direct Illumination with Shadow Rays computes the direct lighting contribution at a surface point $\mathbf{p}$ by evaluating visibility and volumetric attenuation along the direction to each light source [S1, S2, unofficial]. It differs from [Ambient Occlusion via Shadow Rays](878-ambient-occlusion-via-shadow-rays.md) by calculating full directional light contributions (including BRDF terms) rather than just occlusion factors, and from [Lookup Table Shadow Rendering](3588-lookup-table-shadow-rendering.md) by performing real-time ray marching for transmittance rather than precomputing or querying static tables. It builds on [Shadow Ray Casting](2796-shadow-ray-casting.md) by explicitly integrating extinction coefficients along the shadow ray to handle participating media [S1, S4, unofficial].

## How it works
**Inputs:**
*   Surface point $\mathbf{p}$ and surface normal $\mathbf{n}$ [S2, S3, unofficial].
*   List of light sources, each defined by position $\mathbf{l}_i$, color $C_{light, i}$, and optionally area $A_i$ [S1, S2, unofficial].
*   Volume data structure providing extinction coefficient $\sigma_t(\mathbf{x})$ at any position $\mathbf{x}$ [S1, S4, unofficial].
*   Surface material properties (diffuse color, specular parameters, metallic, roughness) [S2, S3, unofficial].

**Outputs:**
*   Direct radiance $L_{direct}$ at $\mathbf{p}$ [S1, S2, unofficial].

**Data Structures:**
*   **Light List:** Array of light structs. Each contains `position` (vec3), `color` (vec3), `enabled` (bool/uint), and `area` (float, for sampling PDF) [S1, S2, unofficial].
*   **Volume Integrator:** Interface or function `Transmittance(ray)` that returns the transmittance $T$ from the ray origin to the end point, integrating $\sigma_t$ along the path [S4, unofficial].
*   **Ray Marcher:** Function `rayMarch(ray)` returning intersection distance $t$ and hit object info, used for hard shadow testing in non-participating or hybrid scenes [S3, unofficial].

**Parameters:**
*   $N_{steps}$: Number of integration steps for volumetric transmittance. Typical value: 16 [S1, unofficial].
*   $MAX\_LIGHTS$: Maximum number of lights to process. Typical value: 8 [S2, unofficial].
*   $\epsilon$: Offset distance to prevent self-intersection. Typical value: $0.01 \times \|\mathbf{n}\|$ or a small fixed epsilon [S3, unofficial].

**Steps:**
1.  **Initialize Accumulator:** Set $L_{direct} = \mathbf{0}$ [S2, unofficial].
2.  **Loop Lights:** For each light $i$ from $0$ to $MAX\_LIGHTS - 1$:
    a.  **Check Enable:** If light $i$ is disabled, skip to next light [S2, unofficial].
    b.  **Compute Direction:** Calculate vector $\mathbf{d} = \mathbf{l}_i - \mathbf{p}$, distance $d_{light} = \|\mathbf{d}\|$, and normalized direction $\mathbf{l} = \mathbf{d} / d_{light}$ [S2, S4, unofficial].
    c.  **Cast Shadow Ray:** Create a shadow ray originating at $\mathbf{p}_{start} = \mathbf{p} + \epsilon \mathbf{n}$ with direction $\mathbf{l}$ [S3, S4, unofficial].
    d.  **Evaluate Transmittance/Visibility:**
        *   **Volumetric Approach (Participating Media):** Integrate $\sigma_t$ along the shadow ray from $\mathbf{p}_{start}$ to $\mathbf{l}_i$ using $N_{steps}$ samples. Compute transmittance $T_{light} = \exp\left(-\sum_{j=1}^{N_{steps}} \sigma_t(\mathbf{x}_j) \Delta s_j\right)$ [S1, S4, unofficial].
        *   **Hard Shadow Approach (Non-participating/Surface):** Use `rayMarch` to find the closest intersection distance $t_{hit}$. If $t_{hit} < 0$ (no hit) or $t_{hit} \ge d_{light}$ (hit is behind light), set $T_{light} = 1.0$. Otherwise, set $T_{light} = 0.0$ [S3, unofficial].
    e.  **Compute Illumination:**
        *   **Geometric Term:** Calculate $G = \frac{\max(0, \mathbf{n} \cdot \mathbf{l})}{d_{light}^2}$ [S1, unofficial]. If light area $A_i$ is used for importance sampling, $G = \frac{\max(0, \mathbf{n} \cdot \mathbf{l}) \cdot \max(0, -\mathbf{l} \cdot \mathbf{n}_{light})}{d_{light}^2 \cdot A_i}$ [S1, unofficial].
        *   **BRDF Contribution:** Compute the reflected radiance based on material model.
            *   *Diffuse:* $L_{diff} = C_{light, i} \cdot T_{light} \cdot C_{diff} \cdot \max(0, \mathbf{n} \cdot \mathbf{l})$ [S4, unofficial].
            *   *Specular (Phong):* $L_{spec} = C_{light, i} \cdot T_{light} \cdot C_{spec} \cdot \max(0, \mathbf{h} \cdot \mathbf{n})^{shininess}$, where $\mathbf{h} = \text{normalize}(\mathbf{l} + \mathbf{v})$ and $\mathbf{v}$ is view direction [S4, unofficial].
            *   *PBR:* Use standard PBR formulation with $T_{light}$ modulating the incoming light [S2, S3, unofficial].
        *   **Accumulate:** $L_{direct} \leftarrow L_{direct} + L_{diff} + L_{spec}$ [S2, S4, unofficial].
    f.  **Fallback/AO:** If the shadow ray hits an occluder before the light (in hard shadow mode), add a small ambient term (e.g., $0.03 \cdot C_{diff} \cdot AO$) to prevent black shadows [S3, unofficial].

**Pseudocode:**
```python
def direct_illumination_with_shadow_rays(p, n, v, lights, volume_integrator, material, max_steps=16):
    """
    Computes direct lighting at point p with shadow rays.
    
    Args:
        p: Surface position (vec3)
        n: Surface normal (vec3)
        v: View direction (vec3)
        lights: List of light objects with .position, .color, .enabled, .area
        volume_integrator: Object with .transmittance(ray) method
        material: Object with .diffuse, .specular, .shininess, .metallic
        max_steps: Number of steps for volumetric integration
        
    Returns:
        vec3: Direct illumination color
    """
    epsilon = 0.01  # [G] Small offset to prevent self-intersection
    l_direct = vec3(0.0)
    
    for light in lights:
        if not light.enabled:
            continue
            
        # 1. Compute light direction and distance
        delta = light.position - p
        d_light = length(delta)
        l_dir = normalize(delta)
        
        # 2. Cast shadow ray
        # Offset origin to avoid self-intersection
        ray_origin = p + n * epsilon
        shadow_ray = Ray(ray_origin, l_dir)
        
        # 3. Evaluate Transmittance
        # Method A: Volumetric Transmittance (for participating media)
        # [S1, S4, unofficial]
        transmittance = volume_integrator.transmittance(shadow_ray, max_steps)
        
        # Method B: Hard Shadow (if volume_integrator is not available or for surfaces)
        # [S3, unofficial]
        # hit = ray_march(shadow_ray)
        # if hit.t < 0 or hit.t >= d_light:
        #     transmittance = 1.0
        # else:
        #     transmittance = 0.0
        
        # 4. Compute Illumination
        # Geometric term
        n_dot_l = max(0.0, dot(n, l_dir))
        
        # Light area PDF factor (if using area lights)
        # [S1, unofficial]
        pdf = 1.0 / light.area if light.area > 0 else 1.0
        
        # Diffuse contribution
        # [S1, S4, unofficial]
        diffuse_term = light.color * transmittance * material.diffuse * n_dot_l
        
        # Specular contribution (Phong approximation)
        # [S4, unofficial]
        h = normalize(l_dir + normalize(v))
        n_dot_h = max(0.0, dot(n, h))
        specular_term = light.color * transmittance * material.specular * pow(n_dot_h, material.shininess)
        
        # Accumulate
        l_direct += diffuse_term + specular_term
        
        # Fallback ambient if occluded (Hard Shadow mode only)
        # [S3, unofficial]
        # if transmittance == 0.0:
        #     l_direct += vec3(0.03) * material.diffuse * material.ao
        
    return l_direct
```

**Edge Cases and Pitfalls:**
*   **Self-Intersection:** Failing to offset the shadow ray origin causes false occlusion. Use $\epsilon \mathbf{n}$ [S3, unofficial].
*   **Precision:** In high-extinction volumes, $T_{light}$ may underflow to 0. Clamp or handle very small values appropriately [S1, unofficial].
*   **Boundary Conditions:** Ensure the volume integrator correctly handles rays starting inside the volume or ending outside [S4, unofficial].
*   **Light Distance:** If $d_{light}$ is very small, $1/d_{light}^2$ can cause overflow. Clamp minimum distance [G].

## Subtopics

### [Shadow Ray Transmittance Estimation](5248-shadow-ray-transmittance-estimation.md)
Estimates transmittance from a surface point to a distant light source through participating media using majorant sampling. It differs from the base method by using stochastic sampling (Russian Roulette) for the integration path rather than fixed-step deterministic marching, which is more efficient for sparse or highly heterogeneous volumes. Choose this when the volume is sparse or when variance reduction techniques are needed. See [Shadow Ray Transmittance Estimation](5248-shadow-ray-transmittance-estimation.md).

### [Voxel Direct Lighting and Shadowing](6610-voxel-direct-lighting-and-shadowing.md)
Computes local illumination and shadows in voxel-based scenes by casting shadow rays from surface positions toward light sources. It differs from [Shadow Ray Transmittance Estimation](5248-shadow-ray-transmittance-estimation.md) by using binary hit/miss results for shadowing rather than estimating transmittance through participating media. It builds on [Direct Illumination with Shadow Rays](2011-direct-illumination-with-shadow-rays.md) by applying these concepts specifically to voxel geometry. Choose this for voxel art styles or grid-based volumes where binary occlusion is sufficient. See [Voxel Direct Lighting and Shadowing](6610-voxel-direct-lighting-and-shadowing.md).

### Transparent Shadows
A shadowing technique where shadow rays cross smooth glass in a straight line, and paths refracted to a light already reached that way do not count as reaching the light [S5, unofficial]. It differs from standard shadow rays by allowing partial transmission through transparent surfaces without full path tracing. Choose this for stylized rendering or when performance precludes full refraction path tracing.

## Operating characteristics
*   **Time Complexity:** $O(N_L \cdot N_s)$, where $N_L$ is the number of lights and $N_s$ is the number of samples/steps per shadow ray [S1, S3, unofficial].
*   **Memory Complexity:** $O(1)$ auxiliary memory per pixel, excluding the volume data structure [S4, unofficial].
*   **Performance:** Fast for a small number of lights and low-resolution volumes. Performance degrades linearly with the number of lights and volume resolution [S2, S4, unofficial].
*   **Strengths:** Simple to implement; handles participating media correctly; provides sharp shadows [S1, S4, unofficial].
*   **Limitations:** No soft shadows (unless extended); noisy if using stochastic sampling; expensive for many lights or high-resolution volumes [S3, S5, unofficial].
*   **When to Use:** Real-time rendering with few lights; offline rendering where accuracy is prioritized over speed for direct lighting [S1, S4, unofficial].
*   **When Not to Use:** Scenes with many dynamic lights; scenes requiring soft shadows from area lights without additional techniques [S3, unofficial].

## Background
Direct illumination with shadow rays is a fundamental technique in ray tracing and ray marching, originating from the basic principles of light transport simulation [S1, S3, unofficial]. It was popularized in early ray tracers and is a standard component in modern real-time renderers and offline path tracers [S2, S4, unofficial]. The method is widely used in voxel-based editors like MagicaVoxel for its simplicity and visual quality [S5, unofficial].
