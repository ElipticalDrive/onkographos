# Voxel Direct Lighting and Shadowing


## Overview
Voxel Direct Lighting and Shadowing is a method for computing local illumination and shadows in voxel-based scenes by casting shadow rays from surface positions toward light sources. It differs from [Shadow Ray Transmittance Estimation](5248-shadow-ray-transmittance-estimation.md) by using binary hit/miss results for shadowing rather than estimating transmittance through participating media. It builds on [Direct Illumination with Shadow Rays](2011-direct-illumination-with-shadow-rays.md) by applying these concepts specifically to voxel geometry.

## How it works
**Inputs:**
- `pos`: The 3D position of the surface point being shaded.
- `normal`: The surface normal at `pos`.
- `material`: A struct containing `rgb` (color) and `a` (emissive intensity).
- `SUN_DIR`: The normalized direction vector to the light source (e.g., the sun).
- `trace_uniforms.shadows`: A boolean or integer flag indicating whether shadow casting is enabled.

**Outputs:**
- `color`: The final RGB color of the surface point.
- `shadow`: A float value (0.0 or 1.0) representing the shadow factor.

**Data Structures:**
- `DirectLightningInfo`: A struct containing `color` (vec3) and `shadow` (f32).
- `shadow_ray`: A ray structure initialized with origin `pos` and direction `-normalize(SUN_DIR)`.

**Steps:**
1. **Calculate Diffuse Lighting:** Compute the diffuse lighting factor using the dot product of the surface normal and the normalized negative light direction.
   $$ \text{diffuse} = \max(\text{dot}(\text{normal}, -\text{normalize}(\text{SUN\_DIR})), 0.0) $$
2. **Initialize Shadow Factor:** Set the shadow factor to 1.0 (fully lit).
3. **Cast Shadow Ray (if enabled):** If `trace_uniforms.shadows` is non-zero:
   - Cast a shadow ray from `pos` in the direction `-normalize(SUN_DIR)` using the function `shoot_ray(shadow_ray, 0.0, 0u)`.
   - Determine the shadow factor: If the ray hits an object (`shadow_hit.hit` is true), the shadow factor is 0.0; otherwise, it is 1.0.
     $$ \text{shadow} = \text{f32}(!\text{shadow\_hit.hit}) $$
   - If shadows are disabled, `shadow` remains 1.0.
4. **Calculate Emissive:** If the material's emissive intensity `a` is non-zero, set the emissive color to the material's RGB color; otherwise, set it to black.
   $$ \text{emissive} = \begin{cases} \text{vec3}(\text{material.rgb}) & \text{if } \text{material.a} \neq 0.0 \\ \text{vec3}(0.0) & \text{otherwise} \end{cases} $$
5. **Combine Results:** Compute the final color by multiplying the diffuse lighting by the shadow factor and adding the emissive component.
   $$ \text{color} = \text{diffuse} \times \text{shadow} + \text{emissive} $$
6. **Return:** Return a `DirectLightningInfo` struct containing the computed `color` and `shadow`.

**Pseudocode:**
```python
def voxel_direct_lighting_and_shadowing(pos, normal, material, SUN_DIR, trace_uniforms):
    # Step 1: Calculate diffuse lighting
    light_dir = -normalize(SUN_DIR)
    diffuse = max(dot(normal, light_dir), 0.0)
    
    # Step 2: Initialize shadow factor
    shadow = 1.0
    
    # Step 3: Cast shadow ray if enabled
    if trace_uniforms.shadows != 0:
        shadow_ray = Ray(origin=pos, direction=light_dir)
        shadow_hit = shoot_ray(shadow_ray, 0.0, 0u)
        shadow = f32(not shadow_hit.hit)
    
    # Step 4: Calculate emissive
    if material.a != 0.0:
        emissive = vec3(material.rgb)
    else:
        emissive = vec3(0.0)
    
    # Step 5: Combine results
    color = diffuse * shadow + emissive
    
    # Step 6: Return
    return DirectLightningInfo(color=color, shadow=shadow)
```

**Parameters:**
- `trace_uniforms.shadows`: Typically 1 (enabled) or 0 (disabled).

**Edge Cases:**
- If `SUN_DIR` is not normalized, the dot product will be incorrect.
- If `pos` is inside a voxel, the shadow ray might immediately hit the same voxel, causing incorrect shadowing. This requires a small epsilon offset or specific ray casting logic to avoid self-intersection.
