# Chromatic Null-Scattering Transmittance Estimation for Next Event Estimation

Also called: NEE Transmittance with Null Scattering, Shadow Ray Transmittance in Chromatic Media

## Overview
This method estimates the transmittance from a surface point to a light source in participating media with wavelength-dependent scattering properties using null-scattering (delta-tracking) [S1]. It differs from standard majorant sampling by selecting a specific RGB channel for the majorant at each step, allowing for tighter bounds per channel and reducing the variance caused by the global majorant in chromatic media [S1]. It is designed for Next Event Estimation (NEE) within volumetric path tracing [S1].

## How it works
**Inputs:** Current path point $p$, light sample point $p'$, random number generator `rng`, and scene medium properties [S1].
**Outputs:** Transmittance spectrum $T_{light}$, null-scattering path PDF $p_{trans\_nee}$, and direct direction PDF $p_{trans\_dir}$ [S1].
**Data Structures:** Medium properties include scattering coefficient $\sigma_s$, absorption coefficient $\sigma_a$, total coefficient $\sigma_t = \sigma_s + \sigma_a$, null-scattering coefficient $\sigma_n$, and majorant $\sigma_m$, all stored as 3-component vectors for RGB channels [S1]. `accum_t` tracks the accumulated distance along the shadow ray as a scalar [S1]. `channel` is an integer index 0, 1, or 2 [S1]. Bit packing details are not given in the sources.
**Numbered Steps & Formulas:**
1. Initialize $T_{light} = [1, 1, 1]$, $p_{trans\_nee} = [1, 1, 1]$, $p_{trans\_dir} = [1, 1, 1]$ [S1].
2. Set `accum_t` = 0 [S1].
3. Create a shadow ray from $p$ to $p'$ [S1].
4. Intersect the scene to find the nearest intersection `isect` [S1].
5. Compute `next_t` = distance($p, p'$) [S1]. If `isect` exists, `next_t` = distance($p, \text{isect.position}$) [S1].
6. If the medium exists along the path:
   a. Sample $u \sim U[0,1]$ from `rng` [S1].
   b. Determine `channel` = $\lfloor u \times 3 \rfloor$, clamped to $[0, 2]$ [S1].
   c. Initialize `iteration` = 0 [S1].
   d. Loop while True:
      i. If `majorant[channel]` $\le 0$, break [S1].
      ii. If `iteration` $\ge$ `max_null_collisions`, break [S1].
      iii. Sample $t = -\ln(1 - \text{next(rng)}) / \text{majorant[channel]}$ [S1].
      iv. Compute $dt = \text{next\_t} - \text{accum\_t}$ [S1].
      v. Update $\text{accum\_t} = \min(\text{accum\_t} + t, \text{next\_t})$ [S1].
      vi. If $t < dt$ (null-scattering event):
          1. Update $T_{light} \ *= \exp(-\text{majorant} \times t) \times \frac{\sigma_n}{\max(\text{majorant})}$ [S1].
          2. Update $p_{trans\_nee} \ *= \exp(-\text{majorant} \times t) \times \frac{\text{majorant}}{\max(\text{majorant})}$ [S1].
          3. Calculate $\text{real\_prob} = \frac{\sigma_t}{\text{majorant}}$ [S1].
          4. Update $p_{trans\_dir} \ *= \exp(-\text{majorant} \times t) \times \text{majorant} \times (1 - \text{real\_prob}) / \max(\text{majorant})$ [S1].
          5. If $\max(T_{light}) \le 0$, break [S1].
      vii. Else (hit surface):
          1. Update $T_{light} \ *= \exp(-\text{majorant} \times dt)$ [S1].
          2. Update $p_{trans\_nee} \ *= \exp(-\text{majorant} \times dt)$ [S1].
          3. Update $p_{trans\_dir} \ *= \exp(-\text{majorant} \times dt)$ [S1].
          4. Break loop [S1].
      viii. Increment `iteration` [S1].
7. Return $T_{light}$, $p_{trans\_nee}$, $p_{trans\_dir}$ [S1].

**Parameters:** `max_null_collisions` limits the iteration count to prevent unbounded loops from numerical errors, with a default of 1000 [S1].
**Edge Cases and Pitfalls:** Numerical instability can cause unbounded loops without the iteration limit [S1]. Dividing by $\max(\text{majorant})$ improves numerical robustness when $\sigma_n$ is large relative to the majorant [S1]. If $\sigma_n = 0$, $T_{light}$ becomes zero and the loop breaks early to save computation [S1].
**Usage in Path Throughput:** When updating the path throughput, the Monte Carlo estimate of transmittance is divided by the average PDF over the RGB channels: `current_path_throughput *= (T_light / avg(p_trans_dir))` [S1]. This normalization is required because the PDFs are scaled by $\max(\text{majorant})$ for numerical robustness [S1].

**Pseudocode:**
```python
def chromatic_null_scattering_nee(p, p_prime, rng, max_null_collisions, get_majorant, intersect, distance, clamp, exp, log, min, max):
    T_light = [1.0, 1.0, 1.0]
    p_trans_nee = [1.0, 1.0, 1.0]
    p_trans_dir = [1.0, 1.0, 1.0]
    accum_t = 0.0
    shadow_ray = Ray(p, p_prime - p)
    isect = intersect(scene, shadow_ray)
    next_t = distance(p, p_prime)
    if isect is not None:
        next_t = distance(p, isect.position)
    if shadow_medium_exists:
        u = rng.next()
        channel = clamp(int(u * 3), 0, 2)
        iteration = 0
        while True:
            if majorant[channel] <= 0:
                break
            if iteration >= max_null_collisions:
                break
            t = -log(1.0 - rng.next()) / majorant[channel]
            dt = next_t - accum_t
            accum_t = min(accum_t + t, next_t)
            if t < dt:
                T_light *= exp(-majorant * t) * sigma_n / max(majorant)
                p_trans_nee *= exp(-majorant * t) * majorant / max(majorant)
                real_prob = sigma_t / majorant
                p_trans_dir *= exp(-majorant * t) * majorant * (1.0 - real_prob) / max(majorant)
                if max(T_light) <= 0:
                    break
            else:
                T_light *= exp(-majorant * dt)
                p_trans_nee *= exp(-majorant * dt)
                p_trans_dir *= exp(-majorant * dt)
                break
            iteration += 1
    return T_light, p_trans_nee, p_trans_dir
```

## Operating characteristics
- **Time Complexity:** Proportional to the number of null-scattering events, bounded by `max_null_collisions` [S1].
- **Memory Complexity:** Constant, per-ray [S1].
- **Strengths:** Handles chromatic media efficiently by using channel-specific majorants, reducing the overestimation of the global majorant [S1].
- **Limitations:** Requires precomputed channel-specific majorants and null-scattering coefficients. The hard iteration limit is an approximation [S1].
