# Deep Shadow Maps

Also called: DOM, Deep Opacity Maps

## Overview
Deep Shadow Maps are a shadow mapping technique for volume rendering where each pixel stores a curve representing volume density as a function of distance, rather than just the depth to the nearest opaque object [S1, unofficial]. Unlike standard shadow maps, which only capture the nearest surface, deep shadow maps capture the entire volumetric structure along the light ray [S1, unofficial].

## How it works
**Inputs:** Light positions and directions. Volume density fields. [S1, unofficial]
**Outputs:** A set of shadow maps, one per light source. Each shadow map pixel contains a data structure representing the volume density profile along the ray from the light to the far plane. [S1, unofficial]
**Data Structures:** Each pixel in the deep shadow map stores a curve. While the exact bit-packing is not specified in the primary sources, the conceptual structure is a function $D(d)$ where $d$ is the distance from the light source and $D$ is the density or transmission factor [S1, unofficial]. In practice, this is often implemented as a 1D texture or a series of samples along the ray [S1, unofficial].
**Steps:**
1. Compute a shadow map per light in the scene [S1, unofficial].
2. Store a curve in each pixel representing how transmission through the volume changes as one moves through it (density as a function of distance) [S1, unofficial].
**Formulas:** Not given in the sources.
**Parameters:** Shadow map resolution: Not given in the sources. Number of samples per ray for curve approximation: Not given in the sources.
**Edge Cases and Pitfalls:** Not given in the sources.

## Subtopics

### Cascaded Deep Opacity Maps
A variant of deep opacity maps using a series of cuboids covering different splits of the view frustum, similar to cascaded shadow maps, to handle varying distances [S2, unofficial].

## Background
Deep Shadow Maps were developed in 2000 by Tom Lokovic and Eric Veach from Pixar [S1, unofficial]. The technique is mentioned for completeness and historical reasons, with similarities to baking lighting into voxels [S1, unofficial].
