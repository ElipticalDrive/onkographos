# Extended Triangle Shadow Testing with Barycentric Coordinates

Also called: Barycentric extension, Parker's method

## Overview
This method computes soft shadows (penumbra) by extending shadow-casting triangles and testing rays against the extended area using barycentric coordinates to determine attenuation [S1, unofficial]. Unlike classic shadow testing which returns a binary hit/miss, this method returns a percentage (attenuation) [S1, unofficial]. It is more expensive than classic shadow testing but not significantly so [S1, unofficial].

## How it works
**Inputs:** Ray origin $\mathbf{o}$, ray direction $\mathbf{d}$, triangle vertices $\mathbf{v}_0, \mathbf{v}_1, \mathbf{v}_2$, extension distance $D$ (proportional to the distance from the test location to the intersected plane) [S1, unofficial].
**Outputs:** Attenuation factor $\alpha \in [0, 1]$, where 1 is full illumination and 0 is full occlusion [S1, unofficial].

**Data Structures:**
*   Triangle vertices: $\mathbf{v}_i \in \mathbb{R}^3$ for $i \in \{0, 1, 2\}$.
*   Barycentric coordinates: $\lambda_0, \lambda_1, \lambda_2$ such that $\mathbf{p} = \lambda_0 \mathbf{v}_0 + \lambda_1 \mathbf{v}_1 + \lambda_2 \mathbf{v}_2$ and $\sum \lambda_i = 1$.

**Steps:**
1.  Perform standard ray-triangle intersection test. If the ray misses the triangle, return $\alpha = 1.0$ [S1, unofficial].
2.  If the ray hits the triangle, calculate the barycentric coordinates $\lambda_0, \lambda_1, \lambda_2$ of the intersection point [S1, unofficial].
3.  For each vertex $i$, determine the extended range $[min_i, max_i]$ based on the geometry. Let $L_i$ be the length of the edge opposite to vertex $i$. The range is $[-D/L_i, 1 + D/L_i]$ [S1, unofficial].
4.  For each coordinate $\lambda_i$, calculate the attenuation contribution $a_i$:
    *   If $\lambda_i \in [0, 1]$, $a_i = 1.0$ (umbra region) [S1, unofficial].
    *   If $\lambda_i < min_i$ or $\lambda_i > max_i$, $a_i = 0.0$ (fully outside extended area) [S1, unofficial].
    *   If $\lambda_i \in [min_i, 0)$ or $\lambda_i \in (1, max_i]$, calculate the normalized distance $a$ from the umbra edge:
        *   If $\lambda_i < 0$, $a = \frac{\lambda_i - min_i}{0 - min_i}$ [S1, unofficial].
        *   If $\lambda_i > 1$, $a = \frac{\lambda_i - 1}{max_i - 1}$ [S1, unofficial].
    *   Apply the S-curve falloff (Bernstein polynomial) to avoid discontinuities: $f = 3a^2 - 2a^3$ [S1, unofficial].
    *   Set $a_i = f$ [S1, unofficial].
5.  The final attenuation is the maximum of the individual contributions: $\alpha = \max(a_0, a_1, a_2)$ [S1, unofficial]. This ensures that the light is dimmed by the least restrictive edge, effectively modeling the penumbra [S1, unofficial].

**Parameters:**
*   Extension distance $D$: Proportional to the distance the ray travels from the test location to the intersected plane [S1, unofficial].

**Pitfalls:**
*   Using only barycentric coordinates results in a somewhat chopped-off extended triangle with sharp corners, which can cause the penumbra to extend too far at sharp tips [S1, unofficial].
*   The efficiency scheme holding the shadowing objects must take into account the maximum increased size of the triangles [S1, unofficial].

**Pseudocode:**
```python
def extended_triangle_shadow_test(ray_origin, ray_direction, v0, v1, v2, extension_distance):
    """
    Computes soft shadow attenuation for a ray against an extended triangle.
    
    Args:
        ray_origin: (x, y, z)
        ray_direction: (x, y, z)
        v0, v1, v2: Triangle vertices (x, y, z)
        extension_distance: D, proportional to distance from test location to plane
        
    Returns:
        alpha: Attenuation factor in [0, 1]
    """
    # Standard ray-triangle intersection
    # Compute edge vectors
    e1 = v1 - v0
    e2 = v2 - v0
    h = cross(ray_direction, e2)
    a = dot(e1, h)
    
    # If a is close to zero, ray is parallel to triangle
    if abs(a) < 1e-8:
        return 1.0
    
    f = 1.0 / a
    s = ray_origin - v0
    u = f * dot(s, h)
    
    # If u is out of range, ray misses triangle
    if u < 0.0 or u > 1.0:
        return 1.0
    
    q = cross(s, e1)
    v = f * dot(ray_direction, q)
    
    # If v is out of range, ray misses triangle
    if v < 0.0 or u + v > 1.0:
        return 1.0
    
    # Ray hits triangle, calculate barycentric coordinates
    # lambda0 = 1 - u - v, lambda1 = u, lambda2 = v
    lambda0 = 1.0 - u - v
    lambda1 = u
    lambda2 = v
    
    # Calculate edge lengths opposite to each vertex
    # L0 is length of edge v1-v2
    L0 = length(v2 - v1)
    # L1 is length of edge v0-v2
    L1 = length(v2 - v0)
    # L2 is length of edge v0-v1
    L2 = length(v1 - v0)
    
    # Calculate extended ranges for each barycentric coordinate
    # Range for lambda_i is [-D/L_i, 1 + D/L_i]
    ranges = []
    for L in [L0, L1, L2]:
        if L < 1e-8:
            # Degenerate triangle edge, use a small epsilon to avoid division by zero
            L = 1e-8
        min_val = -extension_distance / L
        max_val = 1.0 + extension_distance / L
        ranges.append((min_val, max_val))
    
    lambdas = [lambda0, lambda1, lambda2]
    attenuations = []
    
    for i in range(3):
        lam = lambdas[i]
        min_val, max_val = ranges[i]
        
        if lam < min_val or lam > max_val:
            att = 0.0
        elif lam < 0.0:
            # In penumbra below umbra
            a_norm = (lam - min_val) / (0.0 - min_val)
            att = 3 * a_norm**2 - 2 * a_norm**3
        elif lam > 1.0:
            # In penumbra above umbra
            a_norm = (lam - 1.0) / (max_val - 1.0)
            att = 3 * a_norm**2 - 2 * a_norm**3
        else:
            # In umbra
            att = 1.0
        
        attenuations.append(att)
    
    # Final attenuation is the maximum of the individual contributions
    alpha = max(attenuations)
    
    return alpha
```

## Operating characteristics
*   **Time Complexity:** More expensive than classic shadow testing due to the additional barycentric coordinate calculations and attenuation logic, but not significantly more [S1, unofficial].
*   **Memory Complexity:** No additional memory required beyond standard triangle data [S1, unofficial].
*   **Strengths:** Produces soft shadows (penumbra) without requiring multiple ray samples or complex geometry [S1, unofficial].
*   **Limitations:** The extended triangle shape is not perfectly rounded, leading to sharp corners that may extend the penumbra too far [S1, unofficial]. The efficiency scheme for shadowing objects must account for the increased triangle size [S1, unofficial].

## Background
This method was first implemented by Steve Parker [S1, unofficial]. It is described in the Real-Time Rendering News, Volume 12, Number 1 [S1, unofficial]. The technique is based on extending triangle edges and using barycentric coordinates to determine attenuation, avoiding the need for rounding corners explicitly, which was found to be less efficient [S1, unofficial].
