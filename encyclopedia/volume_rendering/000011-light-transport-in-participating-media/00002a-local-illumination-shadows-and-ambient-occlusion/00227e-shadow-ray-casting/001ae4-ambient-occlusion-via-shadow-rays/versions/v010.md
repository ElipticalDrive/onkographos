# Ambient Occlusion via Shadow Rays

Also called: Ray-traced AO, Shadow Ray Ambient Occlusion

## Overview
Ambient Occlusion via Shadow Rays approximates the lack of secondary (reflected) light rays by casting shadow rays into the hemisphere above a surface point to determine geometric obscurance [S1, unofficial][S2, unofficial]. It differs from direct illumination methods by integrating over the hemisphere rather than a single light direction, and from screen-space approximations (SSAO) by using explicit ray tracing against the scene geometry or volume [S3, unofficial]. This method provides view-independent occlusion values that can be combined with arbitrary direct illumination [S1, unofficial].

## How it works
**Inputs:** Surface point $\mathbf{p}$, surface normal $\mathbf{n}$, scene geometry or volume density field, number of rays $N_R$, number of samples per ray $N_S$, and optional falloff parameters [S1, unofficial][S4, unofficial][S6, unofficial].
**Outputs:** Ambient occlusion factor $A \in [0, 1]$ or radiance contribution $L_r$ [S1, unofficial][S6, unofficial].

**Data Structures:**
*   **Hemisphere Sampling:** A set of $N_R$ directions $\omega_i$ distributed over the hemisphere oriented by $\mathbf{n}$ using Uniform Solid Angle or Cosine-Weighted distributions [S2, unofficial][S6, unofficial].
*   **Visibility Function:** $V(\mathbf{p}, \omega)$ is binary: 1 if the path from $\mathbf{p}$ in direction $\omega$ is clear, 0 if occluded [S1, unofficial].
*   **Distance Function (Obscurance):** $\rho(d)$ maps the distance to the first intersection to an attenuation value [S1, unofficial]. In simplified Ambient Occlusion, this is replaced by the binary visibility function [S1, unofficial].

**Steps:**
1.  **Coordinate Frame Construction:** Construct a local tangent space at $\mathbf{p}$ using the normal $\mathbf{n}$. Compute tangent $\mathbf{t}_0$ and bitangent $\mathbf{t}_1$ [S6, unofficial]. If $|n_z| > 0.5$, set $\mathbf{t}_0 = (-n_y, n_x, 0)$, else $\mathbf{t}_0 = (1, 0, 0)$ [S6, unofficial]. Normalize $\mathbf{t}_0$ and compute $\mathbf{t}_1 = \mathbf{n} \times \mathbf{t}_0$ [S6, unofficial].
2.  **Direction Sampling:** For each ray $i \in [0, N_R-1]$, sample a direction $\omega_i$ in the hemisphere using the chosen distribution [S2, unofficial][S6, unofficial]. Transform $\omega_i$ from local tangent space to world space: $\mathbf{d}_i = \mathbf{t}_0 \omega_{i,x} + \mathbf{t}_1 \omega_{i,y} + \mathbf{n} \omega_{i,z}$ [S6, unofficial].
3.  **Ray Casting:** For each direction $\mathbf{d}_i$, cast a shadow ray from $\mathbf{p}$ (offset slightly along $\mathbf{n}$ to avoid self-intersection) [S2, unofficial]. Check for intersection with scene geometry or volume density [S2, unofficial][S3, unofficial]. Determine visibility $V_i$: 1 if no intersection within the maximum distance bound $d_{max}$, 0 otherwise [S1, unofficial]. In sparse voxel structures, traversal may terminate early if a node subtends a solid angle below a threshold [S5].
4.  **Integration:** Compute the ambient occlusion factor by averaging over $N$ samples [S2, unofficial].
    *   **Binary Visibility (Standard AO):**
        $$ A(\mathbf{p}) = \frac{1}{\pi} \int_{\Omega} V(\mathbf{p}, \omega) \cos \theta \, d\omega \approx \frac{1}{N} \sum_{i=1}^{N} V_i \cos \theta_i $$
        where $\theta_i$ is the angle between $\mathbf{n}$ and $\mathbf{d}_i$ [S1, unofficial][S2, unofficial].
    *   **Distance-Based (Obscurance):**
        $$ O(\mathbf{p}) = \frac{1}{\pi} \int_{\Omega} \rho(d(\mathbf{p}, \omega)) \cos \theta \, d\omega $$
        where $\rho$ is a falloff function of the distance to the first hit [S1, unofficial].
    *   **Volume Density Implementation:** For volumetric data, sample density along the ray. Accumulate attenuation based on density thresholds [S4, unofficial].
        $$ \text{AO} = \text{clamp}\left(2 \cdot \exp\left(\frac{-7.0}{N_R N_S} \sum_{i=0}^{N_R-1} \sum_{j=0}^{N_S-1} I_{ij} \cdot \mathbb{I}(T_{min} \le I_{ij} \le T_{max})\right), 0, 1\right) $$
        where $I_{ij}$ is the density at sample $j$ of ray $i$ [S4, unofficial].
5.  **Final Color:** Combine the occlusion factor with ambient lighting [S6, unofficial].
    $$ L_{ambient} = L_{sky} \cdot A(\mathbf{p}) $$
    Or in the specific implementation from [S6, unofficial]:
    $$ \text{outputColor} = \frac{1}{2} \left( \text{ambientColor} \cdot t^{\text{ambientExponent}} + \text{constantColor} \cdot \max(1.0, \text{hitDist} \cdot 0.25) \right) $$
    where $t = \frac{\text{hitDist}}{24.0}$ [S6, unofficial].

**Pseudocode:**
```python
import math
import random

def compute_ambient_occlusion(p, normal, volume_sampler, num_rays=10, samples_per_ray=5, max_dist=1.0):
    # 1. Construct tangent frame [S6, unofficial]
    if abs(normal.z) > 0.5:
        t0 = vec3(-normal.y, normal.x, 0.0)
    else:
        t0 = vec3(1.0, 0.0, 0.0)
    t0 = normalize(t0)
    t1 = cross(normal, t0)

    occlusion_sum = 0.0
    for i in range(num_rays):
        # 2. Sample direction in hemisphere (Uniform Solid Angle) [S2, unofficial]
        theta = math.sqrt(random.random()) * math.pi
        phi = random.random() * 2 * math.pi
        local_dir = vec3(math.sin(theta)*math.cos(phi), math.sin(theta)*math.sin(phi), math.cos(theta))
        dir_world = t0 * local_dir.x + t1 * local_dir.y + normal * local_dir.z

        # 3. Cast ray / sample volume [S4, unofficial]
        ray_origin = p + normal * 0.01
        ray_accum = 0.0
        for j in range(samples_per_ray):
            sample_pos = ray_origin + dir_world * (j * max_dist / samples_per_ray)
            # Check bounds [S4, unofficial]
            if any(sample_pos < min_slices) or any(sample_pos > max_slices):
                break
            # Sample density [S4, unofficial]
            density = volume_sampler.extinction_at(sample_pos)
            # Accumulate attenuation if in threshold range [S4, unofficial]
            if min_density_threshold <= density <= max_density_threshold:
                ray_accum += -7.0 * density / (num_rays * samples_per_ray)
            # Early exit if geometry/volume blocks ray [S1, unofficial]
            if density > 0.0:
                break

        occlusion_sum += ray_accum

    # 4. Final AO factor [S4, unofficial]
    ao_factor = clamp(2.0 * math.exp(occlusion_sum), 0.0, 1.0)
    return ao_factor
```

**Parameters:**
*   $N_R$: Number of shadow rays per pixel. Typical values: 10 [S4, unofficial], 64 [S5], or 1-2 samples per surface for real-time hardware ray tracing [S3, unofficial].
*   $N_S$: Samples per ray. Typical value: 5 [S4, unofficial].
*   $d_{max}$: Maximum distance for occlusion calculation [S1, unofficial].
*   $\text{ambientExponent}$: Exponent for falloff. Typical value: 1.3 [S6, unofficial].
*   $\text{ambientColor}$: Color of ambient light. Typical value: `vec3(1.0)` [S6, unofficial].
*   $\text{constantColor}$: Constant ambient to prevent total darkness. Typical value: `vec3(0.003)` [S6, unofficial].

**Pitfalls:**
*   **Noise:** Low sample counts (e.g., 1-2 samples) lead to very noisy images [S3, unofficial]. Denoising algorithms (spatial/temporal convolutional or deep learning) are required [S3, unofficial].
*   **Precision:** Small gradients in volume data can lead to incorrect normals if not clamped [S4, unofficial].
*   **Performance:** Computational complexity scales with scene complexity [S3, unofficial].

## Subtopics

### [Evans Ambient Occlusion](1083-evans-ambient-occlusion.md)
Evans Ambient Occlusion approximates ambient occlusion by sampling a Signed Distance Field (SDF) along the surface normal to estimate sky visibility. It measures occlusion by comparing the distance field value at sampled points against the actual distance traveled from the surface.

### [Incremental Local Ambient Occlusion](1089-incremental-local-ambient-occlusion.md)
Incremental Local Ambient Occlusion (LAO) is a shading model for direct volume rendering that computes ambient lighting effects by integrating attenuated transfer function density over a local spherical neighborhood around each voxel, rather than using a constant ambient factor or global shadowing. It solves the problem of missing local shadowing and context in direct volume rendering while avoiding global shadows that might hide relevant information. Unlike its siblings, which may compute occlusion in a single pass or use different sampling strategies, LAO-I updates the occlusion result incrementally, processing one ray direction per frame and storing the accumulated result in an ambient light texture using OpenGL blend operations, allowing for user interaction during computation.

### [Solid Angle Early Termination for Ambient Occlusion](1146-solid-angle-early-termination-for-ambient-occlusion.md)
Solid Angle Early Termination for Ambient Occlusion accelerates shadow ray traversal in sparse voxel structures by stopping traversal when a node subtends a solid angle below a specified threshold, effectively using a lower level-of-detail representation for distant points.

### [Zhukov Ambient Occlusion](2245-zhukov-ambient-occlusion.md)
Zhukov Ambient Occlusion is an empirical local illumination model that simulates indirect lighting by computing the geometric obscurance of a surface point, representing how open the point is to the environment. It differs from radiosity by measuring the degree of occlusion (lack of secondary light) rather than the intensity of secondary reflections, making it computationally cheaper and aesthetically driven rather than physically correct. It builds on [Ambient Occlusion via Shadow Rays](878-ambient-occlusion-via-shadow-rays.md) by approximating the hemisphere integral of visibility weighted by the cosine of the incident angle.

### [Spatially Cached Raytraced Ambient Occlusion](4106-spatially-cached-raytraced-ambient-occlusion.md)
Spatially Cached Raytraced Ambient Occlusion (SC-RTAO) is an optimization for raytraced ambient occlusion that stores accumulated occlusion values in spatial cells within a hashmap. Since ambient occlusion is view-independent, these values can be accumulated into a cell without reprojection when the camera moves, reducing redundant ray tracing for static geometry across frames. It distinguishes itself from naive RTAO by caching results to avoid redundant ray tracing, and from sibling methods like Evans AO or Zhukov AO by relying on spatial hashing and atomic accumulation rather than different sampling or approximation strategies.

### Ambient Occlusion Field
Ambient Occlusion Field is a storage and reconstruction method where the reciprocal of a quadratic polynomial encodes how ambient occlusion changes with distance [S3, unofficial]. Coefficients are stored in a cube map [S3, unofficial]. A pitfall is that it requires reconstructing the ambient occlusion factor at runtime, which incurs a performance penalty [S3, unofficial].

## Background
Ambient Occlusion was introduced by Zhukov et al. [Zhukov 1998] and Iones [2003] as an efficient technique for perceptually similar results to global illumination with lower cost [S1, unofficial]. The term "obscurances" was used to describe the measure of the part of the hemisphere obscured by neighboring surfaces [S1, unofficial]. Landis [2002] detailed its use for adding realism to models, and Méndez et al. [2003b] extended it to ray tracing [S1, unofficial]. The method is a property of geometry, independent of lighting conditions and viewpoint [S1, unofficial].
