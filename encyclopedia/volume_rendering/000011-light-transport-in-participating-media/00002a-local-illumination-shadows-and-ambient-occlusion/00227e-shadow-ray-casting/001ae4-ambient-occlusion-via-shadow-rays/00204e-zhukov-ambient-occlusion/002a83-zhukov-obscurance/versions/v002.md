# Zhukov Obscurance

Also called: Ambient Occlusion (Zhukov et al.), Ambient Occlusion Approximation (Zhukov et al.), Distance Ambient Effect, Geometric Obscurance, Obscurance, Obscurance Illumination Model

## Overview
Zhukov Obscurance is a local illumination approximation that attenuates ambient light based on the distance to the nearest occluding geometry [S2, unofficial]. It generalizes standard binary ambient occlusion by replacing the visibility function with a distance suitability function [S2, unofficial]. Unlike standard ambient occlusion which yields a binary 0 or 1, this method provides a smooth gradient of darkening based on proximity [S2, unofficial]. It is distinct from global illumination techniques as it ignores indirect bounces and considers only local geometry [S1, unofficial].

## How it works
**Inputs:** Surface point position $x$, surface normal $n$, decay parameter $\tau > 0$, ambient light intensity $I_a$, and diffuse reflectance $k_a(x)$ [S2, unofficial].

**Outputs:** Obscurance value $W(x) \in [0, 1]$ and final ambient intensity $I(x)$ [S2, unofficial].

**Data Structures:** Not given in the sources. Implementation requires a ray-casting routine to determine $d(x, \omega)$ [S2, unofficial].

**Steps:**
1. Sample directions $\omega$ uniformly over the hemisphere $\Omega$ above $n$ [S2, unofficial].
2. For each $\omega$, compute $d(x, \omega)$ via ray casting to the first intersection [S2, unofficial].
3. Evaluate the distance suitability $\rho(d(x, \omega)) = 1 - e^{-\tau d(x, \omega)}$ [S2, unofficial].
4. Accumulate the product $\rho(d(x, \omega)) |\omega \cdot n|$ over all samples [S2, unofficial].
5. Scale the sum by $2/N$ to approximate the normalized hemisphere integral [S2, unofficial].

**Formulas:**
The obscurance value $W(x, n)$ is defined as [S2, unofficial]:
$$
W(x, n) = \frac{1}{\pi} \int_{\Omega} \rho(d(x, \omega)) |\omega \cdot n| d\omega
$$
where $W(x, n)$ ranges from 0 (fully occluded) to 1 (fully open) [S2, unofficial]. The hemisphere $\Omega$ contains all directions above the surface normal $n$ [S2, unofficial]. The distance suitability function $\rho(d)$ maps intersection distance to ambient light magnitude [S2, unofficial]. The distance $d(x, \omega)$ is the distance to the first intersection in direction $\omega$ [S2, unofficial].

The distance suitability function $\rho(d)$ is modeled as [S2, unofficial]:
$$
\rho(d) = 1 - e^{-\tau d}
$$
where $\tau$ is a positive parameter defining the decay rate [S2, unofficial]. The function satisfies $\rho(0) = 0$ (fully occluded), $\rho(+\infty) = 1$ (fully open), $\rho'(d) > 0$ (monotonically increasing), and $\rho''(d) < 0$ (monotonically decreasing derivative/smoothness) [S2, unofficial].

The final reflected intensity $I(x)$ is calculated as [S2, unofficial]:
$$
I(x) = I_a k_a(x) W(x)
$$
where $I_a$ is the ambient light intensity and $k_a(x)$ is the diffuse reflectance for ambient light [S2, unofficial].

**Pseudocode:**
```python
import math
import random

def sample_hemisphere_uniform(n):
    """Generates a uniformly distributed direction in the hemisphere above normal n."""
    u = random.random()
    v = random.random()
    phi = 2.0 * math.pi * u
    cos_theta = v
    sin_theta = math.sqrt(1.0 - cos_theta * cos_theta)
    # Construct orthonormal basis
    if abs(n[0]) < 0.999:
        up = (1.0, 0.0, 0.0)
    else:
        up = (0.0, 1.0, 0.0)
    tangent = (n[1]*up[2] - n[2]*up[1], n[2]*up[0] - n[0]*up[2], n[0]*up[1] - n[1]*up[0])
    t_len = math.sqrt(tangent[0]**2 + tangent[1]**2 + tangent[2]**2)
    tangent = (tangent[0]/t_len, tangent[1]/t_len, tangent[2]/t_len)
    bitangent = (n[1]*tangent[2] - n[2]*tangent[1], n[2]*tangent[0] - n[0]*tangent[2], n[0]*tangent[1] - n[1]*tangent[0])
    return (sin_theta*math.cos(phi)*tangent[0] + sin_theta*math.sin(phi)*bitangent[0] + cos_theta*n[0],
            sin_theta*math.cos(phi)*tangent[1] + sin_theta*math.sin(phi)*bitangent[1] + cos_theta*n[1],
            sin_theta*math.cos(phi)*tangent[2] + sin_theta*math.sin(phi)*bitangent[2] + cos_theta*n[2])

def zhukov_obscurance(x, n, raycaster, tau, num_samples=100):
    """
    Computes Zhukov Obscurance for a surface point.
    Args:
        x: Point position (vec3).
        n: Surface normal (vec3).
        raycaster: Function returning distance to first intersection for ray origin/direction.
        tau: Positive decay rate parameter.
        num_samples: Number of Monte Carlo samples.
    Returns:
        W: Obscurance value in [0, 1].
    """
    integral_sum = 0.0
    for _ in range(num_samples):
        omega = sample_hemisphere_uniform(n)
        d = raycaster(x, omega)
        if d == float('inf'):
            rho = 1.0
        else:
            rho = 1.0 - math.exp(-tau * d)
        cos_theta = abs(omega[0]*n[0] + omega[1]*n[1] + omega[2]*n[2])
        integral_sum += rho * cos_theta
    W = (2.0 / num_samples) * integral_sum
    return max(0.0, min(1.0, W))

def compute_ambient_intensity(x, n, raycaster, tau, I_a, k_a):
    W = zhukov_obscurance(x, n, raycaster, tau)
    return I_a * k_a * W
```

**Parameters:** $\tau$ is a positive parameter defining the decay rate [S2, unofficial]. Typical values are not given in the sources [S2, unofficial].

**Edge Cases and Pitfalls:** If $d=0$, $\rho(0)=0$ correctly indicates full occlusion [S2, unofficial]. The method does not account for indirect illumination and only considers local geometry, making it not physically accurate [S1, unofficial].

## Subtopics

### Zhukov Ambient Occlusion
Zhukov Ambient Occlusion is the broader category of techniques that use Zhukov's obscurance model to approximate indirect illumination. Zhukov Obscurance is the specific illumination model within this family that replaces binary visibility with distance suitability. Choose the broader category when implementing a family of distance-based occlusion techniques, and choose Zhukov Obscurance when a specific exponential decay model is required. [Zhukov Ambient Occlusion](2245-zhukov-ambient-occlusion.md)

## Operating characteristics
Time complexity depends on the number of samples $N$ used to approximate the hemisphere integral and the cost of each ray intersection test [G]. Memory complexity is low, as it computes values per point and can store results in texture maps or vertex attributes for static scenes [S2, unofficial]. Strengths include providing smooth, distance-based occlusion gradients and operating independently of light sources [S2, unofficial]. Limitations are that it ignores indirect illumination and only considers local geometry, making it not physically accurate [S1, unofficial]. Use it when a smooth, distance-based ambient darkening is desired for static geometry and performance is critical [S2, unofficial]. Do not use it when physically accurate global illumination is required [S1, unofficial].

## Background
Zhukov Obscurance was introduced by Zhukov, Iones, and Kronin in 1998 as an approximation for global illumination through occlusions [S1, unofficial]. It was developed to determine the occlusion of ambient light at interpolated points [S1, unofficial]. The technique was later elaborated upon by Iones et al. in 2003, who defined the distance suitability function properties and the exponential decay model [S2, unofficial]. It is used in computer graphics for simulating indirect illumination effects in real-time or pre-computed contexts [S2, unofficial].
