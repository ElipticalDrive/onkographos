# Evans Ambient Occlusion

Also called: Ambient Occlusion via Distance Field Sampling, Evans AO, Evans Signed Distance Field Occlusion, Evans method, SDF Sky Visibility

## Overview
Evans Ambient Occlusion is a technique for approximating ambient occlusion by sampling a Signed Distance Field (SDF) along the surface normal to estimate sky visibility [S1, unofficial][S2, unofficial][S3, unofficial]. It differs from its siblings [Incremental Local Ambient Occlusion](1089-incremental-local-ambient-occlusion.md) and [Zhukov Ambient Occlusion](2245-zhukov-ambient-occlusion.md) by relying on a global distance field texture rather than local geometric primitives or hemisphere sampling, making it suitable for dynamic or deforming scenes where explicit geometry is unavailable or expensive to query [S2, unofficial][S3, unofficial].

## How it works
**Inputs and Outputs:**
*   **Input:** A Signed Distance Function (SDF) $f(\mathbf{p})$ representing the scene, a surface point $\mathbf{x}$, the surface normal $\mathbf{n}$ at $\mathbf{x}$, a maximum sample count $i_{max}$, and a contrast parameter $\tau$.
*   **Output:** A scalar occlusion value $C$.

**Data Structures:**
*   **SDF:** A function or volume texture mapping 3D coordinates to a scalar distance value. Evans uses a convention where the distance is **positive** inside the surface and **negative** outside [S2, unofficial][S3, unofficial]. This is the inverse of the standard convention (negative inside, positive outside) often used in modern ray marching [S2, unofficial][S3, unofficial].

**Parameters:**
*   $i_{max}$: The number of samples taken along the normal. Not given in the sources.
*   $\tau$: A parameter defining the overall contrast of the occlusion effect. Not given in the sources.
*   $d_i$: The distance of the $i$-th sample from the surface point $\mathbf{x}$. The distances are strictly increasing ($d_i < d_{i+1}$) with $d_0 = 0$. Not given in the sources.

**Method:**
The method estimates occlusion by comparing the actual distance traveled along the normal against the distance reported by the SDF at each sample point. In an unoccluded region, the SDF value at a point $\mathbf{x} + d_i \mathbf{n}$ should equal the distance $d_i$ from the origin $\mathbf{x}$, because the closest surface is the one at $\mathbf{x}$ itself. If another surface is closer, the SDF value will differ from $d_i$ [S1, unofficial][S2, unofficial].

1.  Initialize an accumulator for the occlusion difference to zero.
2.  Iterate from $i = 0$ to $i_{max}$.
3.  Calculate the sample position: $\mathbf{p}_i = \mathbf{x} + d_i \mathbf{n}$.
4.  Query the SDF at $\mathbf{p}_i$ to get $f(\mathbf{p}_i)$.
5.  Calculate the difference: $\Delta_i = d_i - f(\mathbf{p}_i)$.
    *   Note: Due to Evans' sign convention (positive inside, negative outside), if the ray moves into empty space (outside), $f(\mathbf{p}_i)$ is negative. If it hits another surface, $f(\mathbf{p}_i)$ is the distance to that surface. The difference $d_i - f(\mathbf{p}_i)$ accumulates the "missing" distance caused by occlusion [S2, unofficial][S3, unofficial].
6.  Sum the differences: $S = \sum_{i=0}^{i_{max}} \Delta_i$.
7.  Apply contrast and exponential falloff to compute the final occlusion value $C$:

**Pseudocode:**

```python
def evans_ao(x, n, sdf, i_max, tau, d_distances):
    """
    x: vec3, surface point
    n: vec3, surface normal (normalized)
    sdf: function, returns signed distance (positive inside, negative outside)
    i_max: int, number of samples
    tau: float, contrast parameter
    d_distances: list of floats, distances d_i such that d_0=0 and d_i < d_{i+1}
    """
    occlusion_sum = 0.0
    
    for i in range(i_max + 1):
        d_i = d_distances[i]
        # Sample point along the normal
        p = x + d_i * n
        
        # Query SDF
        # Note: Evans convention: positive inside, negative outside
        f_p = sdf(p)
        
        # Accumulate difference
        # If unoccluded, f(p) should equal d_i (distance from x to closest surface, which is x itself)
        # If occluded, f(p) < d_i (distance to closer surface)
        # Difference is d_i - f(p)
        diff = d_i - f_p
        occlusion_sum += diff
        
    # Apply contrast and exponential factor as per source formula 3.26
    # C = e^tau * sum(...)
    # Note: In practice, tau is often negative to create falloff, or the formula 
    # might be exp(tau * sum). The source explicitly writes e^tau * sum.
    # We follow the source exactly.
    c = exp(tau) * occlusion_sum
    
    return c
```

**Edge Cases and Pitfalls:**
*   **SDF Sign Convention:** The implementation must respect Evans' specific sign convention (positive inside, negative outside). Using the standard convention (negative inside) will invert the difference $d_i - f(\mathbf{p}_i)$, leading to incorrect occlusion values [S2, unofficial][S3, unofficial].
*   **Scene Size:** The method requires the SDF to be computed for the entire scene and stored in a volume texture. This makes it memory-intensive and limited to small scenes [S2, unofficial][S3, unofficial].
*   **Precision:** The difference $d_i - f(\mathbf{p}_i)$ can be small. Floating-point precision errors may affect the accuracy of the occlusion estimate, especially for distant samples [G].

## Subtopics

### [Evans' Normal Modification](1114-evans-normal-modification.md)
A variant that perturbs the surface normal at each sample step to better approximate sky visibility effects. It differs from its sibling [Quilez Ambient Occlusion](1117-quilez-ambient-occlusion.md) by modifying the ray direction per step and changing the accumulation base from 2 to 1.1. It builds on [Evans Ambient Occlusion](1083-evans-ambient-occlusion.md) by tilting the marching direction toward the sky dome.

### [Quilez Ambient Occlusion](1117-quilez-ambient-occlusion.md)
A fast approximation for ambient occlusion in Signed Distance Field (SDF) rendering that estimates surface visibility by ray marching along the surface normal. Unlike Evans Ambient Occlusion, which measures the difference between the sampled distance and the distance field value at a single point, Quilez's method accumulates occlusion contributions from multiple samples along the normal, weighting closer geometry more heavily. It differs from standard ray marching by using no explicit intersection checks and marching along the normal instead of a hemisphere.

## Operating characteristics
*   **Time Complexity:** Linear with respect to the number of samples $i_{max}$. Each sample requires one SDF query.
*   **Memory Complexity:** Dominated by the storage of the global SDF volume texture. This is a significant limitation, as the SDF must cover the entire scene [S2, unofficial][S3, unofficial].
*   **Strengths:** Supports dynamic and deforming scenes without requiring explicit geometry updates or BVH rebuilds, as long as the SDF can be evaluated procedurally or updated [S2, unofficial][S3, unofficial].
*   **Limitations:** Limited to small scenes due to the memory requirements of the global SDF volume texture. The approximation is unphysical and may not accurately represent complex lighting effects in large, detailed scenes [S2, unofficial][S3, unofficial].
*   **When to use:** Small scenes, procedural geometry, or dynamic environments where maintaining a global distance field is feasible.
*   **When not to use:** Large-scale scenes with complex static geometry where explicit ray tracing against meshes is more memory-efficient.

## Background
Evans Ambient Occlusion was introduced by Evans in 2006 [S2, unofficial][S3, unofficial]. The method is based on the idea that the signed distance function can be used to assess the visibility of the sky from any point in the scene. It was presented in the context of rendering implicit surfaces and distance fields. The method relies on the property that in an unoccluded region, the distance field value at a point along the normal equals the distance from the surface point [S2, unofficial][S3, unofficial].
