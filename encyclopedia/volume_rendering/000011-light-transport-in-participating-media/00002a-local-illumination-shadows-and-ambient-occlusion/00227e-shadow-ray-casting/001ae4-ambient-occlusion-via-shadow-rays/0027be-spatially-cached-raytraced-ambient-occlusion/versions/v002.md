# Spatially Cached Raytraced Ambient Occlusion

Also called: Spatial Hashing for Raytraced Ambient Occlusion

## Overview
Spatially Cached Raytraced Ambient Occlusion (SC-RTAO) is an optimization for raytraced ambient occlusion that stores accumulated occlusion values in spatial cells within a hashmap [S1, unofficial]. Since ambient occlusion is view-independent, these values can be accumulated into a cell without reprojection when the camera moves, reducing redundant ray tracing for static geometry across frames [S1, unofficial]. It distinguishes itself from naive RTAO by caching results to avoid redundant ray tracing, and from sibling methods like Evans AO or Zhukov AO by relying on spatial hashing and atomic accumulation rather than different sampling or approximation strategies [S1, unofficial].

## How it works
**Inputs and Outputs:**
*   **Inputs:** Face position (`face_pos`), face normal (`normal`), pixel coordinate (`pixel`), frame index (`uniforms.frame_index`), cell size, hash map parameters [S1, unofficial].
*   **Outputs:** Updated hash map payloads (occlusion count and sample count); final AO value derived from the hash map in a separate shading pass [S1, unofficial].

**Data Structures:**
1.  **`spatial_hash_key`**: A struct containing two 32-bit unsigned integers: `hash` (spatial hash key derived from position and normal) and `checksum` (checksum for collision verification) [S1, unofficial].
2.  **`hash_payloads`**: An array of 32-bit unsigned integers. The layout packs two 16-bit values: upper 16 bits store `occlusion_count` (number of rays that hit geometry), and lower 16 bits store `ray_count` (total number of rays cast for this cell, typically `VX_AO_RAYS_PER_PIXEL`) [S1, unofficial].
3.  **`hash_checksums`**: An array of 32-bit unsigned integers storing the checksum for each hash slot [S1, unofficial].
4.  **`hash_frames`**: An array of 32-bit unsigned integers storing the last frame index in which each hash slot was accessed [S1, unofficial].

**Parameters:**
*   `VX_AO_HASH_MASK`: Mask for the hash map size (e.g., for 16 million elements, this is `0xFFFFFF` if power-of-two, or specific mask for the chosen size) [S1, unofficial].
*   `VX_AO_MAX_CELL_AGE`: Maximum age (in frames) before a cell is considered expired [S1, unofficial].
*   `VX_AO_SAMPLE_LIMIT`: Maximum number of samples allowed per hash cell before stopping accumulation [S1, unofficial].
*   `VX_AO_RAYS_PER_PIXEL`: Number of rays cast per pixel for the AO calculation [S1, unofficial].
*   `cell_size`: Size of the spatial cell for hashing [S1, unofficial].
*   Hash map size: 16 million elements (recommended to prevent running out of space during rapid camera movement at 4k resolutions) [S1, unofficial].

**Steps:**
1.  **Generate Key:** Compute the spatial hash key from the face position and normal: `key = make_spatial_hash_key(face_pos, normal, cell_size)` [S1, unofficial].
2.  **Lookup/Insert:** Call `spatial_hash_find_or_insert(key)` to find the index in the hash map [S1, unofficial].
3.  **Check Validity:** If the returned index is `0xFFFFFFFF` (not found/failed) or the current sample count in the payload exceeds `VX_AO_SAMPLE_LIMIT`, return immediately without casting rays [S1, unofficial].
4.  **Offset Ray Origin:** Calculate the ray origin by offsetting the face position along the normal: `pos = offset_ray(face_pos, normal)` [S1, unofficial].
5.  **Generate Frame Seed:** Create a seed based on the current frame index to vary the sampling pattern across frames:
    $$ \text{frame\_seed} = (\text{frame\_index} \times 0x9E3779B9, \text{pcg}(\text{frame\_index} \oplus 0xA511E9B3)) $$
6.  **Generate Pixel Noise:** Compute a 2D noise vector based on the pixel coordinate and frame seed:
    $$ \text{pixel\_noise} = \text{as\_normalized\_float}(\text{pcg2d}(\text{pixel} \oplus \text{frame\_seed})) $$
7.  **Initialize Count:** Set `occlusion_count = 0` [S1, unofficial].
8.  **Cast Rays:** Loop `i` from `0` to `VX_AO_RAYS_PER_PIXEL - 1`:
    a. Calculate sample direction `u`:
       $$ u = \text{frac}(\text{pixel\_noise} + \text{r2\_sequence}(i)) $$
    b. Sample hemisphere:
       $$ v = \text{sample\_cosine\_weighted\_hemisphere}(u) $$
    c. Orient direction:
       $$ \text{dir} = \text{orient\_sample\_direction}(v, \text{normal}) $$
    d. Perform DDA (Digital Differential Analyzer) ray march against the voxel grid for `uniforms.rtao_radius` [S1, unofficial].
    e. If a hit is detected, increment `occlusion_count` [S1, unofficial].
9.  **Atomic Update:** Atomically add the results to the hash map payload at the found index:
    $$ \text{hash\_payloads}[index] \leftarrow \text{hash\_payloads}[index] + ((\text{occlusion\_count} \ll 16) \mid \text{VX\_AO\_RAYS\_PER\_PIXEL}) $$

**Pseudocode:**
```python
# Helper functions (make_spatial_hash_key, offset_ray, pcg, pcg2d, as_normalized_float,
# frac, r2_sequence, sample_cosine_weighted_hemisphere, orient_sample_direction, dda)
# are assumed to be provided by the shader environment or standard math libraries.

def compute_spatially_cached_rtao(face_pos, normal, pixel, uniforms, hash_payloads, hash_checksums, hash_frames):
    # 1. Generate Key
    key = make_spatial_hash_key(face_pos, normal, uniforms.cell_size)
    
    # 2. Lookup/Insert
    index = spatial_hash_find_or_insert(key, uniforms, hash_checksums, hash_frames, hash_payloads)
    
    # 3. Check Validity
    current_ray_count = hash_payloads[index] & 0xFFFF
    if index == 0xFFFFFFFF or current_ray_count >= VX_AO_SAMPLE_LIMIT:
        return

    # 4. Offset Ray Origin
    pos = offset_ray(face_pos, normal)
    
    # 5. Generate Frame Seed
    frame_seed_x = uniforms.frame_index * 0x9E3779B9
    frame_seed_y = pcg(uniforms.frame_index ^ 0xA511E9B3)
    frame_seed = (frame_seed_x, frame_seed_y)
    
    # 6. Generate Pixel Noise
    pixel_noise = as_normalized_float(pcg2d(pixel ^ frame_seed))
    
    # 7. Initialize Count
    occlusion_count = 0
    
    # 8. Cast Rays
    for i in range(VX_AO_RAYS_PER_PIXEL):
        u = frac(pixel_noise + r2_sequence(float(i)))
        v = sample_cosine_weighted_hemisphere(u)
        dir = orient_sample_direction(v, normal)
        if dda(pos, dir, uniforms.rtao_radius):
            occlusion_count += 1
            
    # 9. Atomic Update
    update_value = (occlusion_count << 16) | VX_AO_RAYS_PER_PIXEL
    hash_payloads[index] += update_value

def spatial_hash_find_or_insert(key, uniforms, hash_checksums, hash_frames, hash_payloads):
    frame = uniforms.frame_index
    index = key.hash & VX_AO_HASH_MASK
    
    for probe in range(VX_AO_HASH_PROBE_COUNT):
        old_checksum = hash_checksums[index]
        if old_checksum == 0:
            hash_checksums[index] = key.checksum
            ex_checksum = 0
        else:
            ex_checksum = old_checksum
            
        if ex_checksum == 0 or ex_checksum == key.checksum:
            hash_frames[index] = frame
            return index
            
        ex_frame = hash_frames[index]
        
        # Check age
        if frame - ex_frame > VX_AO_MAX_CELL_AGE:
            hash_checksums[index] = key.checksum
            hash_payloads[index] = 0
            hash_frames[index] = frame
            return index
            
        # Linear probe
        index = (index + 1) & VX_AO_HASH_MASK
        
    return 0xFFFFFFFF
```

**Edge Cases and Pitfalls:**
*   **Hash Map Saturation:** At 4k resolutions, the algorithm may fail to find a free slot older than 20 frames if the hash map is too small. A size of 16 million elements is recommended to mitigate this [S1, unofficial].
*   **Atomic Overhead:** The hashmap lookup involves multiple atomic operations (`InterlockedCompareExchange`, `InterlockedExchange`, `InterlockedAdd`), which add overhead compared to regular buffer reads [S1, unofficial].
*   **Register Allocation:** Maintaining many `float3` variables during the computation can bloat register allocation, reducing shader occupancy (e.g., from ~40% to ~20% in some implementations) [S1, unofficial].

## Operating characteristics
*   **Time Complexity:** Hash map lookup is $O(1)$ average case but with a high constant factor due to atomic operations and potential linear probing [S1, unofficial]. Ray casting scales linearly with the number of rays per pixel [S1, unofficial].
*   **Memory Complexity:** $O(M)$ where $M$ is the hash map size (16 million elements) [S1, unofficial]. Requires storage for `hash_payloads`, `hash_checksums`, and `hash_frames` [S1, unofficial].
*   **Measured Performance:** On a Macbook Air (M2) with the Sponza scene at 4k resolution:
    *   Baseline RTAO: 39.04 FPS (46.16 ms) [S1, unofficial].
    *   With SC-RTAO (Cell size 5->10): 71.73 FPS (23.50 ms), a ~83.72% improvement [S1, unofficial].
    *   Further optimizations (checkerboard update, rasterized brick coordinates) pushed FPS to ~72.00 (19.33 ms) [S1, unofficial].
*   **Strengths:** Significant performance improvement in static or slowly moving scenes by avoiding redundant ray tracing. View-independent accumulation allows for smooth camera movement without reprojection artifacts [S1, unofficial].
*   **Limitations:** High memory usage for the hash map. Atomic operations can become a bottleneck. Performance degrades if the camera moves rapidly, causing frequent cache misses and overwrites. Precision issues with `float3` can impact shader occupancy [S1, unofficial].
*   **When to Use:** Scenes with significant static geometry where AO is a major performance bottleneck [S1, unofficial].
*   **When Not to Use:** Highly dynamic scenes with rapid camera movement or frequent geometry changes, as the cache invalidation overhead may negate benefits [S1, unofficial].

## Background
Spatially Cached Raytraced Ambient Occlusion was introduced in August 2026 as an optimization for a voxel raytracer, documented in the "Voxel Raytracer Devlog" by the author of the `nelari.us` blog [S1, unofficial]. The method was added in commit `4a6c4b7` to address performance issues in the RTAO hashmap update pass [S1, unofficial]. It builds on the concept of spatial hashing for raytraced ambient occlusion, leveraging the view-independence of AO to cache results across frames [S1, unofficial].
