# Solid Angle Early Termination for Ambient Occlusion

Also called: Solid Angle Culling for AO, Solid Angle Thresholding for AO

## Overview
This method accelerates ambient occlusion (AO) computation by terminating shadow ray traversal when a scene node subtends a solid angle below a specified threshold [S1]. It builds on [Ambient Occlusion via Shadow Rays](878-ambient-occlusion-via-shadow-rays.md) by treating the scene hierarchy as a variable-resolution representation: distant nodes are effectively treated as lower level-of-detail (LOD) primitives [S1]. Unlike [Evans Ambient Occlusion](1083-evans-ambient-occlusion.md) which uses hemisphere sampling, or [Zhukov Ambient Occlusion](2245-zhukov-ambient-occlusion.md) which uses precomputed spherical harmonics, this method operates directly on the spatial hierarchy during ray casting [S1].

## How it works
**Inputs:**
- A hierarchical scene representation (e.g., Sparse Voxel DAG or Octree) [S1].
- A shading point $P$ and its surface normal $n$ [S1].
- A cone angle threshold $\theta_{thresh}$ [S1].

**Outputs:**
- Ambient occlusion factor $A$ for point $P$ [S1].

**Data Structures:**
- The scene is represented as a tree where each node $N$ has a bounding volume (typically an axis-aligned bounding box or sphere) and potentially child nodes [S1].
- No additional per-ray data structures are required beyond the traversal stack [S1].

**Steps:**
1. Initialize the occlusion accumulator $A = 1.0$ and the ray direction distribution (e.g., 64 shadow rays uniformly distributed over the hemisphere defined by $n$) [S1].
2. For each shadow ray direction $d$:
   a. Traverse the hierarchy starting from the root.
   b. For each node $N$ intersected by the ray:
      i. Calculate the solid angle $\Omega_N$ subtended by node $N$ at point $P$.
      ii. If $\Omega_N < \Omega_{thresh}$ (where $\Omega_{thresh}$ corresponds to $\theta_{thresh}$):
          - Terminate traversal for this ray.
          - Do not add the contribution of this node or its descendants to $A$ [S1].
      iii. If the node is a leaf and is occluded (intersects geometry):
          - Update $A$ based on the occlusion contribution (typically reducing $A$ by the solid angle fraction or binary occlusion depending on the specific AO formulation, though the source implies binary termination) [S1].
3. Return the final $A$ [S1].

**Formulas:**
The solid angle $\Omega_N$ of a node $N$ with bounding radius $r$ at distance $d$ from $P$ (approximated as a cone) is:
$$ \Omega_N = 2\pi (1 - \cos \theta_N) $$
where $\theta_N = \arcsin(r/d)$ [S1].

The threshold is defined by a cone angle $\theta_{thresh}$:
$$ \Omega_{thresh} = 2\pi (1 - \cos \theta_{thresh}) $$

**Parameters:**
- Cone angle threshold $\theta_{thresh}$: 9 degrees [S1].
- Corresponding solid angle threshold $\Omega_{thresh}$: 0.07 sr [S1].
- Number of shadow rays per pixel: 64 (used in evaluation) [S1].

**Edge Cases and Pitfalls:**
- **Darkening:** The method results in images that are darker than ground-truth because occluded distant geometry is ignored [S1].
- **Near-contact quality:** Despite the darkening, it maintains high quality for near-contact occlusion [S1].
- **Precision:** The solid angle calculation must handle cases where $P$ is inside the node's bounding volume (division by zero or negative distance), though the source does not specify the guard [G].

**Pseudocode:**
```python
def compute_ao_with_solid_angle_termination(shading_point, normal, scene_root, theta_thresh_deg):
    # Convert threshold to radians and solid angle
    theta_thresh_rad = math.radians(theta_thresh_deg)
    omega_thresh = 2 * math.pi * (1 - math.cos(theta_thresh_rad))
    
    # Initialize 64 shadow rays over the hemisphere
    rays = generate_hemisphere_samples(normal, count=64)
    occlusion_factor = 1.0
    
    for ray_dir in rays:
        current_node = scene_root
        occluded = False
        
        while current_node is not None:
            # Calculate bounding sphere radius and distance for solid angle
            # Note: Source assumes node can be projected to unit hemisphere
            # and solid angle calculated. We approximate node as sphere for calculation.
            center = current_node.bounding_volume.center
            radius = current_node.bounding_volume.radius
            dist = distance(shading_point, center)
            
            # Guard against point inside bounding volume
            if dist <= radius:
                # Point is inside; treat as fully occluded or handle specifically
                # Source does not specify, assuming standard traversal where
                # intersection check happens before solid angle or inside nodes are leaves.
                occluded = True
                break
            
            # Calculate subtended cone angle
            sin_theta = radius / dist
            if sin_theta > 1.0: sin_theta = 1.0 # Clamp for precision
            theta_node = math.asin(sin_theta)
            
            # Calculate solid angle
            omega_node = 2 * math.pi * (1 - math.cos(theta_node))
            
            # Early termination check
            if omega_node < omega_thresh:
                # Stop traversal; node and children are ignored
                break
            
            # Check intersection with node geometry (if leaf) or children
            if current_node.is_leaf:
                if ray_intersects_node(ray_dir, shading_point, current_node):
                    occluded = True
                    break
            else:
                # Traverse to children
                next_node = get_next_child(current_node, ray_dir, shading_point)
                if next_node is None:
                    break
                current_node = next_node
        
        if occluded:
            # In standard AO, occlusion reduces the factor.
            # The source implies binary termination affects the final image brightness.
            # Assuming standard AO accumulation where each ray contributes 1/N if occluded.
            occlusion_factor -= 1.0 / len(rays)
            
    return occlusion_factor
```

## Subtopics

### [Octree Subdivision for Multiple Scattering](3356-octree-subdivision-for-multiple-scattering.md)
This method computes multiple scattering contributions in participating media by traversing an octree of volume samples to identify a "tree cut" of nodes that significantly influence a camera sample point. It addresses the computational cost of evaluating light transport from distant or less relevant volume samples by combining solid angle thresholds with phase function checks. It builds on [Solid Angle Early Termination for Ambient Occlusion](1146-solid-angle-early-termination-for-ambient-occlusion.md) by extending the early termination logic to higher-order scattering events, specifically double and multiple scattering, rather than just direct illumination or ambient occlusion.

## Operating characteristics
- **Time Complexity:** Reduces traversal time by skipping nodes with small solid angles [S1]. The speedup depends on scene density and distance from the shading point.
- **Memory Complexity:** No additional memory overhead beyond the scene hierarchy [S1].
- **Measured Performance:** The method was found to be faster while providing similar quality in evaluations using sparse voxel DAGs [S1].
- **Strengths:** Efficiently handles large scenes (e.g., 28M triangles in Lucy) by reducing node visits [S1].
- **Limitations:** Produces darker images than ground-truth due to ignored distant occlusion [S1].
- **When to use:** When performance is critical and slight darkening in distant areas is acceptable.
- **When not to use:** When physically accurate global illumination brightness is required.

## Background
This technique was presented in the context of high-resolution sparse voxel DAGs [S1]. It leverages the hierarchical nature of sparse voxel structures to optimize shadow ray casting for ambient occlusion [S1]. The approach was evaluated on scenes such as CRYSPONZA, HAIRBALL, LUCY, and SANMIGUEL [S1].
