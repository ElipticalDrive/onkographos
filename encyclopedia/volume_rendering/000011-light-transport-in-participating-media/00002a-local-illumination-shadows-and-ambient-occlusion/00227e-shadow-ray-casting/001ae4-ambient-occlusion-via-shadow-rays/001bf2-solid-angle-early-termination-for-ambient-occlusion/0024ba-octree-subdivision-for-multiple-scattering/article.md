# Octree Subdivision for Multiple Scattering


## Overview
This method computes multiple scattering contributions in participating media by traversing an octree of volume samples to identify a "tree cut" of nodes that significantly influence a camera sample point [S1]. It addresses the computational cost of evaluating light transport from distant or less relevant volume samples by combining solid angle thresholds with phase function checks [S1]. It builds on [Solid Angle Early Termination for Ambient Occlusion](1146-solid-angle-early-termination-for-ambient-occlusion.md) by extending early termination logic to higher-order scattering events [S1].

## How it works
**Inputs:**
- Camera sample position $P_k$ [S1].
- Camera ray direction $\hat{o}$ [S1].
- Octree cell $C$ with center $C.r$ and incoming light direction $C.d$ [S1].
- Volume sample positions $v_i$ associated with nodes in the hierarchy [S1].
- Scattering coefficient $\sigma_s$ [S1].
- Extinction coefficient $\sigma_i$ for each sample $i$ [S1].
- Phase function $p(\cdot, \cdot)$ [S1].
- Precomputed multiple scattering table [S1].
- Thresholds $\epsilon_1$ and $\epsilon_2$ [S1].

**Outputs:**
- Multiple scattering contribution to the radiance at $P_k$ in direction $\hat{o}$ [S1].

**Data Structures:**
- **Octree Cell:** Contains center position $C.r$, incoming light direction $C.d$, references to child cells, and a reference to the volume sample $v_i$ stored at the leaf [S1].
- **Volume Sample:** Contains position $v_i$, intensity $I_{v_i}$, and extinction coefficient $\sigma_i$ [S1].

**Steps:**
1. Initialize traversal at the root of the octree [S1].
2. For the current cell $C$ and sample point $P_k$, compute the vector $\mathbf{u} = P_k - C.r$ and its unit vector $\hat{u}$ [S1].
3. Calculate the solid angle $\Omega(P_k, C)$ subtended by cell $C$ at $P_k$ [S1].
4. Apply subdivision criteria: if $\Omega(P_k, C) > \epsilon_1$, subdivide and process children [S1]. Else if $\Omega(P_k, C) > \epsilon_2$ and ($p(\hat{o}, \hat{u}) > \pi/4$ or $p(\hat{u}, C.d) > \pi/4$), subdivide [S1]. Else, add $C$ to the tree cut [S1].
5. For each node $v_i$ in the tree cut, compute double scattering using the formula [S1]:
   $$\text{double}(P_k) = \sigma_s^2 \sum_{v_i} \frac{e^{-\sigma_i r_i} I_{v_i}}{r_i^2} p(\hat{\alpha}, \hat{r}_i) p(\hat{r}_i, \hat{\alpha}_{v_i})$$
   where $\mathbf{r}_i = P_k - v_i$, $r_i = \|\mathbf{r}_i\|$, $\hat{r}_i = \mathbf{r}_i/r_i$, $\hat{\alpha} = \hat{o}$, and $\hat{\alpha}_{v_i} = C.d$ [S1].
6. Handle weak singularities caused by $1/r_i^2$ by clamping the distance squared [S1].
7. Use the same tree cut to compute higher-order multiple scattering via a precomputed table generated by Monte Carlo simulation of photon propagation in an infinite medium [S1].

**Pseudocode:**

```python
def compute_multiple_scattering(P_k, o_hat, octree_root, epsilon_1, epsilon_2, sigma_s, phase_function, precomputed_table):
    tree_cut = []

    def traverse(node):
        u_vec = P_k - node.center
        u_hat = u_vec / length(u_vec)
        omega = solid_angle(node, P_k)  # [G]

        if omega > epsilon_1:
            for child in node.children:
                traverse(child)
        elif omega > epsilon_2:
            cond1 = phase_function(o_hat, u_hat) > math.pi / 4
            cond2 = phase_function(u_hat, node.incoming_light_dir) > math.pi / 4
            if cond1 or cond2:
                for child in node.children:
                    traverse(child)
            else:
                tree_cut.append(node.sample)
        else:
            tree_cut.append(node.sample)

    traverse(octree_root)

    double_scattering = 0.0
    for sample in tree_cut:
        r_vec = P_k - sample.position
        r_dist = length(r_vec)
        r_hat = r_vec / r_dist
        r_dist_sq = max(r_dist ** 2, 1e-6)  # [S1]

        term = (sigma_s ** 2) * (exp(-sample.extinction * r_dist) * sample.intensity / r_dist_sq)
        term *= phase_function(o_hat, r_hat)
        term *= phase_function(r_hat, sample.incoming_light_dir)
        double_scattering += term

        # [S1] Higher-order scattering uses a precomputed table from Monte Carlo simulation of photon propagation in an infinite medium.

    return double_scattering
```

**Parameters:**
- $\epsilon_1$: Threshold for solid angle to force subdivision [S1].
- $\epsilon_2$: Secondary threshold for solid angle combined with phase function check [S1].
- $\sigma_s$: Scattering coefficient [S1].
- $\sigma_i$: Extinction coefficient for sample $i$ [S1].

**Edge Cases and Pitfalls:**
- **Weak Singularities:** The $1/r_i^2$ term in the double scattering formula can cause numerical instability when $r_i$ is very small. This is handled by clamping the distance squared [S1].
- **Degenerate Input:** If $P_k$ coincides with a sample position, $r_i = 0$. Clamping prevents division by zero [S1].

## Subtopics

### Double Scattering via Tree Cut
This variant focuses specifically on the double scattering component, computing only the first two scattering events (sample to $P_k$ to camera) using the tree cut mechanism [S1]. It explicitly evaluates the $1/r^2$ attenuation and phase functions for each node in the cut [S1]. The stopping criterion uses the solid angle sustained by the node from $P_k$ and the phase function between the outgoing direction $\hat{o}$ and the direction from $P_k$ to the node center $v_i$ [S1]. The double scattering contribution is calculated as $\text{double}(P_k) = \sigma_s^2 \sum_{v_i} \frac{e^{-\sigma_i r_i} I_{v_i}}{r_i^2} p(\hat{\alpha}, \hat{r}_i) p(\hat{r}_i, \hat{\alpha}_{v_i})$ [S1]. Weak singularities from $1/r^2$ are handled by clamping [S1].

## Operating characteristics
- **Time Complexity:** Depends on the depth of the octree and the number of nodes in the tree cut; worst case traverses the entire tree, but solid angle and phase checks prune it significantly [S1].
- **Memory Complexity:** Linear in the number of volume samples stored in the octree [S1].
- **Measured Performance:** Not given in the sources.
- **Strengths:** Efficiently approximates multiple scattering by ignoring distant or poorly oriented samples and reduces the number of expensive phase function and attenuation calculations [S1].
- **Limitations:** Accuracy depends on the thresholds $\epsilon_1$ and $\epsilon_2$; poorly chosen thresholds can lead to over-subdivision or under-subdivision artifacts; assumes homogeneous media or precomputed per-sample properties [S1].
- **When to Use:** When simulating participating media with significant multiple scattering and performance is a concern [S1].
- **When Not to Use:** When high accuracy is required for near-field scattering or when the media is highly heterogeneous and cannot be well-represented by the octree samples [S1].

## Background
The method originates from point-based rendering for homogeneous participating media with refractive boundaries [S1]. It extends the PBGI (Point-Based Global Illumination) approach to multiple scattering events [S1]. The tree cut mechanism is inspired by solid angle-based early termination techniques used in ambient occlusion [S1]. The precomputed table for higher-order scattering is generated via Monte Carlo simulation of photon propagation in an infinite medium [S1].
