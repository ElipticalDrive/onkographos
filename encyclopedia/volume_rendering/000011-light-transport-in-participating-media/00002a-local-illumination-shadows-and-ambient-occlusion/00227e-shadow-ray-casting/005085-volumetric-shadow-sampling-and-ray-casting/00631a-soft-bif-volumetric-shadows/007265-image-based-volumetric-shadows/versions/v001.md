# Image-Based Volumetric Shadows

Also called: Tóth, Wyman

## Overview
Image-Based Volumetric Shadows is a screen-space technique that approximates volumetric shadowing by leveraging geometric depth information and image-based processing, avoiding the computational cost of full ray marching through participating media. Unlike parent method [Soft BiF Volumetric Shadows](18810-soft-bif-volumetric-shadows.md) which relies on spatial interpolation of sampled radiance, this approach uses epipolar geometry, bilateral filtering, and depth discontinuities to determine shadowing along view rays. It is distinct from geometric-based methods [Geometrical-Based Volumetric Shadows](18811-geometrical-based-volumetric-shadows.md) by replacing explicit polygon casting or depth peeling with image-space operations such as downsampling and rectification.

## How it works
The method is not a single algorithm but a family of screen-space techniques that share the goal of computing volumetric shadows using image-based primitives. Implementations vary by author, but all operate in screen space using depth buffers and epipolar lines.

### Inputs and Outputs
- **Inputs**: Depth buffer (Z-buffer), view direction, light direction, image resolution.
- **Outputs**: Shadow factor per pixel, often integrated into a single-scattering radiance term.

### Data Structures
- **Depth Buffer**: Standard screen-space depth values.
- **Downsampled Buffer**: Lower-resolution representation of shadow/scattering state.
- **Epipolar Line Data**: Linear arrays of samples along epipolar lines in screen space.

### Steps
The general workflow involves placing samples along epipolar lines, detecting depth discontinuities, and applying filtering. Specific implementations differ:

1. **Epipolar Line Construction**: Transform eye rays and radiance rays into a coordinate system where epipolar lines are aligned with screen rows or columns (rectification) [S1, unofficial].
2. **Sample Placement**:
   - *Tóth*: Compute downsamples for each pixel; neighboring pixels share results [S1, unofficial].
   - *Engelhardt*: Linearly search epipolar lines for Z-buffer discontinuities; place samples only after and before these positions [S1, unofficial].
   - *Wyman [36]*: Voxelize image-based shadow casters in epipolar geometry instead of ray marching [S1, unofficial].
3. **Visibility Testing**:
   - *Tóth*: Use interleaved sampling to evaluate if a sample position along the view-ray is in scattering or shadow [S1, unofficial].
   - *Wyman [26]*: Add polygons along the view ray; clamp the segment between the front and farthest polygon, then perform visibility testing against image-based shadows [S1, unofficial].
4. **Filtering**:
   - *Engelhardt*: Apply bilateral filtering along and between epipolar lines to preserve downsamples for single scattering [S1, unofficial].
   - *Ali*: Use bilateral filtering to generate soft shadow maps using multiple image-based algorithms [S1, unofficial].
5. **Incremental Evaluation**:
   - *Baran*: Evaluate radiance incrementally along the same epipolar line using rectified shadow maps [S1, unofficial].
   - *Chen*: Accelerate partial sum tree method by replacing one-dimensional min-max mipmap calculation [S1, unofficial].

### Pseudocode
The following pseudocode represents a generalized implementation based on Tóth and Engelhardt, as no single source provides a complete unified algorithm.

```python
def compute_image_based_volumetric_shadows(depth_buffer, light_dir, view_dir, resolution):
    # Step 1: Rectify coordinates to align epipolar lines with screen rows
    # [G] Implementation detail: Transform view and light directions to 
    # a coordinate system where epipolar lines are horizontal.
    rectified_depth = rectify_epipolar_geometry(depth_buffer, light_dir, view_dir)
    
    # Step 2: Detect Z-buffer discontinuities along epipolar lines
    # [G] Linear search for depth jumps
    discontinuities = find_z_discontinuities(rectified_depth)
    
    # Step 3: Place samples around discontinuities
    # [G] Samples are placed only after and before discontinuity positions
    sample_positions = place_samples_around_discontinuities(discontinuities)
    
    # Step 4: Interleaved sampling for shadow/scattering state
    # [G] Evaluate if sample is in shadow or scattering
    shadow_flags = interleaved_shadow_test(sample_positions, rectified_depth)
    
    # Step 5: Bilateral filtering to preserve edges
    # [G] Filter along and between epipolar lines
    filtered_shadows = bilateral_filter(shadow_flags, rectified_depth)
    
    return filtered_shadows
```

### Edge Cases and Pitfalls
- **Depth Discontinuities**: Incorrect detection can lead to artifacts where shadow boundaries are misplaced [S1, unofficial].
- **Epipolar Alignment**: Rectification errors can cause misalignment of samples along view rays [S1, unofficial].
- **Occlusion Clamping**: In Wyman's method, incorrect clamping of the ray segment can result in over- or under-shading [S1, unofficial].

## Subtopics

### Geometrical-Based Volumetric Shadows
Uses depth peeling or sorted shadow polygons instead of image-based filtering. Choose when explicit geometric control is needed. [Geometrical-Based Volumetric Shadows](18811-geometrical-based-volumetric-shadows.md)

### Soft BiF Volumetric Shadows
Uses spatial interpolation of sampled radiance for smooth transitions. Choose when high-quality soft shadows are required without screen-space artifacts. [Soft BiF Volumetric Shadows](18810-soft-bif-volumetric-shadows.md)

## Operating characteristics
- **Time Complexity**: Depends on the number of samples per pixel and filter radius. Generally faster than ray marching due to screen-space operations.
- **Memory Complexity**: Requires depth buffer and intermediate buffers for downsampling and filtering.
- **Strengths**: Real-time performance, avoids volumetric grid storage, leverages existing depth buffers.
- **Limitations**: Screen-space only (no off-screen shadows), artifacts at depth discontinuities, dependent on depth buffer accuracy.
- **When to Use**: Real-time applications where performance is critical and screen-space shadows are sufficient.
- **When Not to Use**: When off-screen shadows are required or when high-quality volumetric scattering is needed.

## Background
The method was proposed by multiple authors independently:
- **Wyman [26, 36]**: Proposed geometric-based shadows with polygon clamping and later voxelize shadow casters in epipolar geometry [S1, unofficial].
- **Tóth [23]**: Introduced downsampling and interleaved sampling in pixel shaders [S1, unofficial].
- **Engelhardt [24]**: Presented epipolar line sampling with bilateral filtering [S1, unofficial].
- **Ali [35]**: Used bilateral filtering for soft shadow maps [S1, unofficial].
- **Baran [25]**: Proposed incremental radiance evaluation along epipolar lines [S1, unofficial].
- **Chen [27]**: Accelerated the method using min-max mipmaps [S1, unofficial].
