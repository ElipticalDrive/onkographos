# Soft Shadows via Ray Packets

Also called: Ray Packet Soft Shadows

## Overview
This method extends ray casting in participating media to support non-local illumination effects, specifically soft shadows, by tracing secondary ray packets from primary rays toward area light sources [S1]. It distinguishes itself from hard shadow techniques by sampling a spatial distribution of directions to approximate the penumbra, leveraging the coherence of these secondary rays to maintain interactive performance [S1].

## How it works
**Inputs and Outputs**
*   **Input:** Primary ray, scene geometry, light source definition [S1].
*   **Output:** Shadow term (transmittance) applied to the primary ray's contribution [G].

**Data Structures**
The method operates on ray packets. A packet is a collection of rays sharing a common origin but diverging in direction to sample the light source area [G].
*   **Packet Size:** Fixed configurations of $2 \times 2$ (4 rays), $4 \times 4$ (16 rays), and $8 \times 8$ (64 rays) [S1].
*   **Ray Layout:** Each ray consists of an origin point $\mathbf{o}$ and a direction vector $\mathbf{d}$ [G]. Shadow rays originate from the shading point on the primary ray, not the primary ray origin [G]. Directions are distributed across the solid angle subtended by the light source [G].

**Parameters**
*   **Light Source Area:** The size of the light source is defined as 5% of the solid angle subtended by the bounding box of the scene [S1].
*   **Packet Dimensions:** $k \times k$, where $k \in \{2, 4, 8\}$ [S1].

**Algorithm Steps**
1.  **Generate Shadow Directions:** For a given primary ray shading point $\mathbf{o}_p$, generate $N$ secondary ray directions $\{\mathbf{d}_i\}_{i=1}^{N}$ toward the light source area [G].
2.  **Construct Packet:** Create a ray packet where each ray $i$ has origin $\mathbf{o}_i = \mathbf{o}_p$ and direction $\mathbf{d}_i$ [G].
3.  **Trace Rays:** Trace each ray in the packet against the scene geometry or particles [S1].
    *   For each ray $i$, compute the transmittance $T_i$ from $\mathbf{o}_p$ to the light source, checking for occlusions along the path [G].
4.  **Aggregate Shadow Term:** Compute the final shadow term $S$ for the primary ray by averaging the transmittances:
    $$ S = \frac{1}{N} \sum_{i=1}^{N} T_i $$
    [G] This assumes equal weighting for all samples in the packet.
5.  **Apply:** Multiply the primary ray's radiance contribution by $S$ [G].

**Pseudocode**
```python
class Ray:
    def __init__(self, origin, direction):
        self.origin = origin
        self.direction = direction

def compute_soft_shadow(primary_ray, light_source, packet_dim):
    """
    Computes soft shadow term for a primary ray using a ray packet.
    Args:
        primary_ray: Ray object with origin and direction.
        light_source: Object defining area and position.
        packet_dim: Integer dimension of the square packet (2, 4, or 8).
    Returns:
        float: Shadow term (0.0 to 1.0).
    """
    n = packet_dim * packet_dim
    total_transmittance = 0.0
    
    # Generate directions sampling the light source solid angle
    # The light source area is 5% of the solid angle of the scene bounding box [S1]
    directions = sample_light_source_directions(primary_ray.origin, light_source, n)
    
    for d in directions:
        shadow_ray = Ray(origin=primary_ray.origin, direction=d)
        # Trace ray against scene geometry/particles [S1]
        # Returns transmittance from origin to light source [G]
        t = trace_ray(shadow_ray)
        total_transmittance += t
        
    return total_transmittance / n

def sample_light_source_directions(origin, light_source, count):
    """
    Generates 'count' directions from 'origin' that sample the light source.
    The light source subtends 5% of the solid angle of the scene bounding box [S1].
    """
    directions = []
    for _ in range(count):
        # Standard stratified or uniform sampling over the light's solid angle [G]
        d = generate_direction(origin, light_source)
        directions.append(d)
    return directions

def generate_direction(origin, light_source):
    """Generates a single ray direction toward the light source area [G]."""
    # Standard vector math to compute direction toward a point/area on the light [G]
    target = light_source.sample_point()
    return normalize(target - origin)

def normalize(v):
    return v / magnitude(v)

def magnitude(v):
    return (v[0]**2 + v[1]**2 + v[2]**2)**0.5
```

**Edge Cases and Pitfalls**
*   **Coherence Dependency:** Interactive performance depends heavily on the coherence exhibited by secondary ray packets [S1].
*   **Performance Degradation:** The performance impact is sublinear in the number of shadow rays traced, but large packets (e.g., $8 \times 8$) can significantly reduce frame rates [S1].
*   **Light Size:** The light source area is fixed at 5% of the solid angle subtended by the scene bounding box for the tested configurations [S1].

## Operating characteristics
**Time and Memory Complexity**
*   **Time Complexity:** The cost is proportional to the number of shadow rays per primary ray and the cost of tracing each ray [S1].
*   **Memory Complexity:** Minimal additional memory is required for storing the packet of rays [G].

**Strengths and Limitations**
*   **Strengths:** Supports soft shadows with minimal code changes to existing ray casting pipelines [S1]. Performance degradation is sublinear, allowing for interactive frame rates with small packets (e.g., $2 \times 2$) [S1].
*   **Limitations:** Performance is highly dependent on ray coherence [S1]. Large packets ($8 \times 8$) can result in significant frame rate drops, with degradation factors ranging from 2.42 (for $2 \times 2$ packets) to 19.35 (for $8 \times 8$ packets) [S1].

**When to Use**
*   Use when soft shadows are required and interactive performance is critical [S1].
*   Use small packet sizes ($2 \times 2$) for high performance, larger sizes ($4 \times 4$ or $8 \times 8$) for higher quality if performance allows [S1].

## Background
This method was introduced in the context of interactive visualization environments to support non-local effects like shadows, which were previously omitted for performance reasons [S1]. It extends basic ray casting by leveraging the coherence of rays to maintain interactivity even when tracing multiple shadow rays per pixel [S1].
