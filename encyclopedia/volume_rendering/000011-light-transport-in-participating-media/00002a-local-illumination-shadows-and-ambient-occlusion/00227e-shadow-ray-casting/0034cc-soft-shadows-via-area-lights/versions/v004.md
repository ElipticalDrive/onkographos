# Soft Shadows via Area Lights

Also called: Area Light Shadow Sampling, Area Light Shadows, Partial Occlusion, Shadow Occlusion

## Overview
This method computes soft shadows by modeling light sources with spatial extent, allowing points in space to be partially occluded rather than fully lit or fully in shade [S2, unofficial]. Unlike point source approximations which cast sharp shadows, this approach samples the light source area to generate natural penumbra effects [S1, unofficial].

## How it works
**Inputs and Outputs:**
*   **Input:** Shading point position $\mathbf{p}$, light source sample points $\{\mathbf{l}_i\}$ over area $A$, and volume extinction coefficient function $\sigma_t(\mathbf{x})$ [G].
*   **Output:** Shadow factor $S \in [0, 1]$ representing the fraction of the light source visible from $\mathbf{p}$ [G].

**Data Structures:**
*   **Light Source:** A list of sample points $\{\mathbf{l}_i\}$ distributed over the light's area $A$ [G].
*   **Volume:** Accessible via a distance field for ray marching [S2, unofficial].

**Steps:**
1.  **Sample the Light Area:** Generate sample points over the light source area to replace a single boolean shadow test [S1, unofficial].
2.  **Cast Shadow Rays:** For each sample point $\mathbf{l}_i$, cast a ray towards $\mathbf{p}$ [G].
3.  **Evaluate Transmittance:** Compute the transmittance $T_i$ from $\mathbf{l}_i$ to $\mathbf{p}$ by integrating the extinction coefficient along the path:
    $$ T_i = \exp\left(-\int_{\mathbf{l}_i}^{\mathbf{p}} \sigma_t(\mathbf{x}) \, d\mathbf{x}\right) $$
    In discrete implementations, this integral is approximated by summing $\sigma_t \cdot \Delta s$ over samples along the ray segment [G].
4.  **Compute Shadow Factor:** Average the transmittance values from all samples to determine the final shadow factor:
    $$ S = \frac{1}{N} \sum_{i=1}^{N} T_i $$
    If $N=1$, the result is a hard shadow [S2, unofficial].

**Pseudocode:**
```python
def compute_area_light_shadow(p, light_samples, volume_sampler, step_size=0.01):
    """
    Computes soft shadow factor for point p given light samples and volume.
    
    Args:
        p: 3D vector, shading point position.
        light_samples: List of 3D vectors, sample points on the light area.
        volume_sampler: Function that returns sigma_t at a 3D position.
        step_size: Distance between volume samples along each shadow ray.
        
    Returns:
        float: Shadow factor S in [0, 1].
    """
    total_transmittance = 0.0
    for l_i in light_samples:
        direction = p - l_i
        distance = length(direction)
        if distance < 1e-6:
            transmittance = 1.0
        else:
            num_steps = max(1, int(distance / step_size))
            transmittance = 1.0
            for k in range(num_steps):
                t = (k + 0.5) / num_steps
                current_pos = l_i + direction * t
                sigma_t = volume_sampler(current_pos)
                transmittance *= exp(-sigma_t * step_size)
        total_transmittance += transmittance
    return total_transmittance / len(light_samples)
```

**Parameters:**
*   $N$: Number of light samples. Not given in the sources.
*   `step_size`: Distance between volume samples along each shadow ray. Typical values depend on volume resolution and required precision [G].

**Edge Cases:**
*   **$N=1$:** Results in a hard shadow, equivalent to a point source [S2, unofficial].
*   **Zero Density:** If $\sigma_t = 0$ along all paths, $S=1$ (fully lit) [G].
*   **High Density:** If $\sigma_t$ is very high, $S \to 0$ (fully shadowed) [G].

## Operating characteristics
*   **Time Complexity:** $O(N \cdot M)$, where $N$ is the number of light samples and $M$ is the number of volume samples per shadow ray. Implementing area light sources and sampling the light source area leads to an exponential growth of rays and reduces rendering performance [S1, unofficial].
*   **Memory Complexity:** $O(1)$ additional memory per shading point, assuming the volume data is accessed on the fly [G].
*   **Strengths:** Produces natural appearing soft shadows with penumbra by approximating partial occlusion [S2, unofficial].
*   **Limitations:** Computationally expensive due to multiple shadow rays per shading point, which reduces rendering performance [S1, unofficial].
*   **When to Use:** When realistic soft shadows are required and performance allows for multiple ray casts per pixel [G].
*   **When Not to Use:** In real-time applications with strict performance constraints where hard shadows or approximate methods are preferred [G].

## Background
The concept of soft shadows via area lights originated from the observation that real-world light sources have spatial extent, leading to partial occlusion and penumbra [S2, unofficial]. In raster graphics, this is often achieved via distance-based filtering of shadow maps [S2, unofficial]. In ray marching and volume rendering, direct sampling of the light area provides a more accurate solution than a single boolean test, though it increases computational cost [S1, unofficial].
