# Recursive Ray Tracing
Also called: Higher-order Rays, Secondary Ray Shooting, Whitted shading, Whitted-style Ray Tracing

## Overview
Recursive Ray Tracing extends basic ray casting by handling diffuse reflection, specular reflection, and transmission (refraction) through the recursive tracing of secondary rays upon intersection with objects [S2, unofficial]. It solves the problem of local illumination effects like shadows, reflections, and refractions that simple shadow ray casting cannot capture in isolation [S1, unofficial]. What sets it apart from its siblings is the explicit recursive generation of new rays based on material properties (specular/transmission) and physical laws (Fresnel, Snell's law), rather than just sampling for shadows or ambient occlusion [S1, unofficial].

## How it works
**Inputs and Outputs:**
*   **Input:** A ray $\mathbf{r}$ (origin $\mathbf{o}$, direction $\mathbf{d}$), a scene description (list of shapes/objects), a maximum recursion depth $D_{max}$, and material properties for each object (diffuse color, specular coefficient, transmission coefficient, refractive index $\eta$).
*   **Output:** A final color value $C$ for the pixel associated with the ray.

**Data Structures:**
*   **Ray:** Defined by origin $\mathbf{o}$ and direction $\mathbf{d}$ (unit vector).
*   **Intersection:** Contains hit point $\mathbf{p}$, surface normal $\mathbf{n}$, distance $t$, and material properties.
*   **Shape:** Geometric primitive capable of returning intersection data.

**Numbered Steps:**
1.  **Intersection Test:** Find the closest intersection between the input ray and the scene geometry. If no intersection is found, return the background color [S2, unofficial].
2.  **Shadow Calculation (Visibility):** For each light source, construct a shadow ray from the intersection point $\mathbf{p}$ towards the light. The maximum distance for this ray is the distance to the light source. If the ray intersects any object before reaching the light, the visibility factor $V$ for that light is 0; otherwise, it is 1 [S1, unofficial].
3.  **Diffuse Shading:** Calculate the diffuse contribution using the surface normal $\mathbf{n}$, view direction, and incident light direction. The contribution is proportional to the dot product of the normal and the light direction, modulated by the visibility factor and light intensity [S2, unofficial].
4.  **Specular Reflection:** If the material has specular properties, compute the ideal reflection direction $\mathbf{r}_{refl}$ using the surface normal $\mathbf{n}$ and the incoming light direction $\mathbf{l}$ (or view direction depending on formulation, typically $\mathbf{r}_{refl} = 2(\mathbf{n} \cdot \mathbf{l})\mathbf{n} - \mathbf{l}$) [S2, unofficial].
5.  **Transmission/Refraction:** If the material has transmission properties, compute the refraction direction $\mathbf{r}_{refr}$ using Snell's law. Determine if the ray is entering or exiting the medium by checking the dot product of the view direction and normal. If exiting ($\mathbf{v} \cdot \mathbf{n} < 0$), flip the normal and invert the refractive index ratio [S2, unofficial].
6.  **Recursive Call:** Shoot new rays in the directions of reflection and/or refraction. The color contribution from these rays is added to the final result, weighted by the material's reflectance/transmittance coefficients.
7.  **Termination:** Recursion stops when the maximum depth $D_{max}$ is reached, or if the contribution of the ray becomes negligible [S1, unofficial].

**Formulas:**
*   **Reflection Direction:**
    $$ \mathbf{r}_{refl} = 2.0 (\mathbf{n} \cdot \mathbf{l}) \mathbf{n} - \mathbf{l} $$
    where $\mathbf{n}$ is the surface normal and $\mathbf{l}$ is the incident light direction (normalized) [S2, unofficial].
*   **Refraction Direction:**
    Let $\mathbf{wi}$ be the incoming direction (normalized) and $\mathbf{n}$ be the surface normal (normalized). Let $\eta$ be the relative refractive index.
    $$ \cos_i = -\mathbf{wi} \cdot \mathbf{n} $$
    If the ray is exiting the medium ($\cos_i > 0$ is entering, so if $\cos_i < 0$ it is exiting? Note: Source [S2, unofficial] defines `entering = cos_i > 0.0` where `cos_i = dot(-wi, n)`. If `!entering`, flip normal and invert eta):
    $$ k = 1.0 - \eta^2 (1.0 - \cos_i^2) $$
    If $k < 0.0$, total internal reflection occurs, and reflection is computed instead [S2, unofficial].
    Otherwise:
    $$ \mathbf{r}_{refr} = \eta \mathbf{wi} + (\eta \cos_i - \sqrt{k}) \mathbf{n} $$
    [S2, unofficial].

**Parameters:**
*   **Recursion Depth ($D_{max}$):** A pre-defined level limiting ray tracing. Typical values are 3-5 for real-time, higher for offline. Contribution diminishes with each level [S1, unofficial].
*   **Refractive Index Ratio:** Default approximation used in source is 0.75 for entering, inverted for exiting [S2, unofficial].

**Pseudocode:**
```python
def recursive_ray_trace(ray, objects, depth, max_depth, background_color):
    """
    Recursively trace a ray through the scene.
    
    Args:
        ray: Ray object with origin o and direction d.
        objects: List of Shape objects.
        depth: Current recursion depth.
        max_depth: Maximum allowed recursion depth.
        background_color: Color to return if no intersection is found.
        
    Returns:
        Vector3D: The final color contribution.
    """
    # Base case: max depth reached
    if depth > max_depth:
        return Vector3D(0, 0, 0) # Or background_color depending on implementation preference

    # Find closest intersection
    intersection = get_closest_intersection(ray, objects)
    
    # Base case: no intersection
    if intersection is None:
        return background_color

    p, n, material = intersection.point, intersection.normal, intersection.material
    light_direction = get_light_direction(p) # Simplified for single light
    view_direction = -ray.d # Assuming camera ray origin is viewer

    # 1. Shadow Calculation
    shadow_ray = Ray(p + epsilon * n, light_direction)
    shadow_hit = get_closest_intersection(shadow_ray, objects)
    visibility = 0.0
    if shadow_hit is None or shadow_hit.distance > distance_to_light:
        visibility = 1.0

    # 2. Diffuse Shading
    # Assuming standard Lambertian diffuse
    diffuse_intensity = max(0.0, dot(n, light_direction))
    diffuse_color = material.diffuse_color * visibility * diffuse_intensity

    # 3. Specular Reflection
    reflected_color = Vector3D(0, 0, 0)
    if material.has_specular:
        # Compute reflection direction
        # r = 2 * (n . l) * n - l
        # Note: Source uses in_light_direction as -(r.d) normalized? 
        # Standard reflection: r = 2(n.l)n - l where l is light direction towards surface.
        # If light_direction is from surface to light, then incident is -light_direction.
        incident = -light_direction
        scale_factor = 2.0 * dot(n, incident)
        reflection_dir = scale_factor * n - incident
        
        # Recursive call for reflection
        reflected_ray = Ray(p + epsilon * n, reflection_dir)
        reflected_color = recursive_ray_trace(reflected_ray, objects, depth + 1, max_depth, background_color)
        reflected_color = reflected_color * material.specular_coefficient

    # 4. Transmission/Refraction
    refracted_color = Vector3D(0, 0, 0)
    if material.has_transmission:
        # Compute refraction direction
        # Determine if entering or exiting
        # Source: cos_i = dot(-wi, n). entering = cos_i > 0.0
        # wi is incoming direction (from light/camera to surface). 
        # Here, ray.d is from camera to surface. So wi = ray.d.
        wi = ray.d
        n_local = n
        eta = material.refractive_index
        
        cos_i = dot(-wi, n_local)
        entering = cos_i > 0.0
        
        if not entering:
            # Inside -> Outside
            n_local = -n_local
            eta = 1.0 / eta
            cos_i = dot(-wi, n_local)
            
        k = 1.0 - eta * eta * (1.0 - cos_i * cos_i)
        
        if k >= 0.0:
            # Refraction
            refract_term = sqrt(k)
            first_term = eta * wi
            second_term = eta * cos_i - refract_term
            refract_dir = -first_term + n_local * second_term
            
            refracted_ray = Ray(p + epsilon * n_local, refract_dir)
            refracted_color = recursive_ray_trace(refracted_ray, objects, depth + 1, max_depth, background_color)
            refracted_color = refracted_color * material.transmission_coefficient
        else:
            # Total Internal Reflection
            # Compute specular reflection instead
            scale_factor = 2.0 * dot(n_local, wi) # Note: source uses view_direction here? 
            # Source: scale_factor = 2.0 * dot(normal, view_direction)
            # If view_direction is -ray.d, and wi is ray.d, then dot(n, view) = -dot(n, wi).
            # Standard reflection uses incident vector. Let's stick to source logic if ambiguous.
            # Source snippet: "scale_factor = 2.0 * dot(normal, view_direction)... transmissive_reflection = reflection - view_direction"
            # This implies view_direction is the vector pointing FROM surface TO camera? 
            # Let's use standard reflection formula for consistency with reflection block.
            incident = -wi # Incident is opposite to ray direction
            scale_factor = 2.0 * dot(n_local, incident)
            reflection_dir = scale_factor * n_local - incident
            refracted_ray = Ray(p + epsilon * n_local, reflection_dir)
            refracted_color = recursive_ray_trace(refracted_ray, objects, depth + 1, max_depth, background_color)
            refracted_color = refracted_color * material.transmission_coefficient

    # Final Color
    final_color = diffuse_color + reflected_color + refracted_color
    return final_color
```

## Subtopics

### Whitted-Style Ray Tracing
The specific implementation of recursive ray tracing that handles perfect specular reflection and refraction, typically without diffuse interreflection (which requires path tracing). Choose when you need sharp reflections and refractions without global illumination. [Link to Whitted-style Ray Tracing article if available, otherwise link to Parent](2796-shadow-ray-casting.md).

### Path Tracing
A stochastic extension of recursive ray tracing that handles diffuse interreflection by sampling the hemisphere. Choose when you need full global illumination, including color bleeding. [Link to Path Tracing article if available](52-name.md).

## Operating characteristics
*   **Time Complexity:** Exponential in the worst case ($O(b^d)$ where $b$ is branching factor and $d$ is depth), but typically linear with respect to the number of primitives per ray for a fixed depth. Performance degrades rapidly with increasing recursion depth and number of reflective/refractive objects.
*   **Memory Complexity:** Linear with respect to the scene graph depth and recursion stack.
*   **Measured Performance:** Depends heavily on scene complexity and recursion depth. For simple scenes with few reflective objects, it is fast. For complex scenes with many bounces, it becomes expensive.
*   **Strengths:** Produces physically plausible reflections and refractions. Simple to implement for basic scenes.
*   **Limitations:** Does not handle diffuse interreflection (global illumination) correctly. Can be slow due to recursive nature. Requires efficient acceleration structures (BVH, KD-tree) for performance.
*   **When to use:** For rendering scenes with transparent or reflective objects where global illumination is not critical.
*   **When not to use:** For scenes requiring soft shadows, diffuse interreflection, or complex lighting interactions (use Path Tracing or Radiosity).

## Background
Recursive Ray Tracing was introduced by Turner Whitted in 1980 in his paper "An Improved Illumination Model for Shaded Display" [S1, unofficial]. It extended the basic ray casting algorithm by adding support for specular reflection and refraction, allowing for more realistic images. The method is named after Whitted, who popularized the technique. It is a foundational algorithm in computer graphics and is often taught as the first step towards full path tracing.
