# Direct Illumination Sampling with Mesh Intersection

Also called: Direct Integrator

## Overview
This method computes direct illumination for a surface point by sampling a light source and verifying visibility against explicit triangle meshes [S1, unofficial]. It serves as the standard direct illumination integrator for polygonal scenes, distinguishing itself from SDF-based approaches by relying on geometric primitives rather than implicit distance fields [S1, unofficial]. It builds on [Direct Light Sampling](3337-direct-light-sampling.md) by handling the specific geometry intersection requirements of mesh-based renderers [S1, unofficial].

## How it works
**Inputs:** Surface point, scene geometry, light source, and BSDF evaluator [G].
**Outputs:** Accumulated direct illumination radiance $L$ at the surface point [G].
**Data Structures:** `SurfaceInteraction3f`: A structure holding intersection details, including position, normal, UV coordinates, and primitive ID [S1, unofficial].
**Steps:**
1. Perform ray intersection against the scene: `itx : SurfaceInteraction3f = scene.ray_intersect(ray)` [S1, unofficial].
2. Sample the emitter direction and evaluate the BSDF to compute incoming radiance `Li` [S1, unofficial].
3. Check visibility using a shadow ray intersected against the scene: `itx_shadow : mi.SurfaceInteraction3f = scene.ray_intersect(rayL)` [S1, unofficial].
4. Accumulate direct illumination if both primary and secondary rays are valid: `L += dr.select(valid_ray, Li, black)` [S1, unofficial].
**Formulas:** Not given in the sources.
**Parameters:** Not given in the sources.
**Edge Cases and Pitfalls:**
- Self-Intersection: The shadow ray origin must be offset from the surface point along the normal to prevent immediate self-intersection [G].
- Precision: Floating-point errors can cause shadow acne or false occlusions; an epsilon offset is required [G].
- Light Hit Detection: Determining if a shadow ray hit the light source requires comparing the intersection's primitive ID or object ID with the light's ID, or verifying that the intersection distance matches the sampled light distance [G].

**Pseudocode:**
```python
def select(cond, a, b):
    return a if cond else b

class Ray:
    def __init__(self, origin, direction, max_t):
        self.origin = origin
        self.direction = direction
        self.max_t = max_t

def direct_illumination_mesh(scene, primary_ray, bsdf, light_sampler):
    # Step 1: Perform ray intersection against the scene
    itx = scene.ray_intersect(primary_ray)
    if not itx.valid:
        return 0.0

    # Step 2: Sample the emitter direction and evaluate the BSDF to compute incoming radiance Li
    l_direction, distance = light_sampler.sample(itx.position)
    ray_L = Ray(origin=itx.position + itx.normal * 1e-4, direction=l_direction, max_t=distance)
    Li = bsdf.evaluate(itx.normal, l_direction)

    # Step 3: Check visibility using a shadow ray intersected against the scene
    itx_shadow = scene.ray_intersect(ray_L)

    # Step 4: Accumulate direct illumination if both primary and secondary rays are valid
    valid_ray = (itx_shadow is None) or itx_shadow.hit_light
    return select(valid_ray, Li, 0.0)
```

## Subtopics

### SDF Direct Integrator
A direct illumination integrator for SDF-based scenes that performs ray intersection against the signed distance field rather than mesh geometry [S1, unofficial]. It differs from the mesh integrator by using `sdf.ray_intersect` instead of `scene.ray_intersect` [S1, unofficial]. The visibility check accumulates illumination if the shadow ray is valid or hits the emitter [S1, unofficial].
