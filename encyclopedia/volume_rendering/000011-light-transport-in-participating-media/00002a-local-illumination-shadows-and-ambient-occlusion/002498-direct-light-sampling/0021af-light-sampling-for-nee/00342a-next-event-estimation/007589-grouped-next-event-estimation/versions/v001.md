# Grouped Next Event Estimation

Also called: Double Summation Sampling, Next Event Selection, Weighted Reservoir Sampling for Next Event

## Overview
Grouped Next Event Estimation is a variance reduction and acceleration technique for Monte Carlo light transport solvers that selects the next interaction kernel $j$ for a current kernel $i$ by grouping kernels and sampling hierarchically. It solves the problem of $O(N^2)$ complexity in constructing the full probability matrix for next event estimation by rewriting the single summation of light transport interactions into a double summation over groups and kernels, enabling importance sampling at the group level. It differs from [Importance-Sampled Next Event Estimation](7684-importance-sampled-next-event-estimation.md) by explicitly clustering kernels to reduce the search space complexity, and from [Random-Walk Subsurface Scattering](9028-random-walk-subsurface-scattering.md) by focusing on direct light sampling selection rather than path traversal.

## How it works
**Inputs:** A set of $N$ kernels, where each kernel $i$ has a position $\mathbf{p}_i$, normal $\mathbf{n}_i$, and current estimated outgoing radiance $\mathbf{B}_i^c$. A preset number of groups $G$.
**Outputs:** An index $j$ representing the selected next event kernel for kernel $i$.

**Data Structures:**
1.  **Kernel List:** Array of size $N$. Each element stores:
    *   $\mathbf{p}_i \in \mathbb{R}^3$: Position.
    *   $\mathbf{n}_i \in \mathbb{R}^3$: Normal direction.
    *   $\mathbf{B}_i^c \in \mathbb{R}^3$: Outgoing radiance (RGB).
2.  **Group Cluster:** Array of size $G$. Each element stores:
    *   $\mathbf{c}_g \in \mathbb{R}^3$: Averaged central point of kernels in group $g$.
    *   $\mathbf{n}_g \in \mathbb{R}^3$: Averaged normal direction of kernels in group $g$.
    *   $R_g \in \mathbb{R}$: Summed current estimation of outgoing radiance (scalar proxy, e.g., sum of norms or mean intensity) for importance weighting.
    *   Indices: List of kernel indices belonging to group $g$.

**Steps:**

1.  **Grouping (Clustering):**
    Group the $N$ kernels into $G$ groups using K-Means clustering. The features used for clustering are the averaged central points ($\mathbf{p}_i$), normal directions ($\mathbf{n}_i$), and the summed current estimation of outgoing radiance ($\sum \|\mathbf{B}_i^c\|$ or similar scalar proxy) for each kernel. This creates a spatial and radiance-based hierarchy.

2.  **Probability Approximation:**
    For a given kernel $i$, the unnormalized probability $p_j$ of selecting kernel $j$ is approximated by:
    $$
    p_j \propto \text{clamp}(\mathbf{B}_j^{c(t)T} Y) \frac{|\mathbf{n}_i \cdot \omega_I| |\mathbf{n}_j \cdot \omega_I|}{\|\mathbf{p}_j - \mathbf{p}_i\|_2^2}
    $$
    Where:
    *   $\text{clamp}(\cdot)$ converts the RGB channel values of the incoming radiance approximation into a single scalar. In the forward pass, this is the converted illumination from the RGB color space. In gradient calculation, the norm of gradients for all three channels is used.
    *   $\mathbf{B}_j^{c(t)}$ is the incoming radiance estimate for kernel $j$ at time/iteration $t$.
    *   $Y$ is the basis function.
    *   $\omega_I$ is the incident direction.
    *   $\mathbf{n}_i, \mathbf{n}_j$ are the normals of kernels $i$ and $j$.
    *   $\mathbf{p}_i, \mathbf{p}_j$ are the positions.
    *   The term $\frac{|\mathbf{n}_i \cdot \omega_I| |\mathbf{n}_j \cdot \omega_I|}{\|\mathbf{p}_j - \mathbf{p}_i\|_2^2}$ serves as a rough estimate of the geometric decay and visibility.

3.  **Hierarchical Sampling:**
    To avoid $O(N^2)$ complexity of calculating $p_j$ for all $j$, the method samples in two stages:
    *   **Stage 1: Group Selection.** Sample a group $g$ from the $G$ groups. The probability of selecting group $g$ is proportional to its aggregated importance (derived from the summed outgoing radiance and spatial proximity factors).
    *   **Stage 2: Kernel Selection.** Within the selected group $g$, sample a specific kernel $j$ based on the unnormalized probability $p_j$ defined in Step 2.

4.  **Online Streaming Weighted Sampling:**
    When sampling $j \sim p_j$ within a group (or if not grouping, across all kernels), the algorithm uses online streaming weighted sampling (specifically weighted reservoir sampling [Chao 1982]). This allows sampling $j$ based on $p_j$ without seeing all probabilities simultaneously or knowing the normalization factor in advance. The algorithm streams each kernel $i$ with its calculated unnormalized $p_j$ for every other kernel only once.

**Pseudocode:**

```python
import math
import random

def clamp_rgb_to_scalar(rgb_vector):
    """Converts RGB vector to a scalar. Forward pass uses converted illumination."""
    # Implementation detail: sum of components or max component, 
    # depending on specific clamp definition in source. 
    # Source implies a scalar conversion. We assume sum for simplicity 
    # or standard luminance if Y is defined. 
    # Note: Source says "converted illumination from RGB color space".
    # We implement a generic scalar reduction.
    return sum(rgb_vector)

def calculate_unnormalized_prob(kernel_i, kernel_j, omega_I):
    """
    Calculates p_j proportional to Eqn 26.
    """
    # Geometric term
    dist_sq = sum((kernel_i.pos[k] - kernel_j.pos[k])**2 for k in range(3))
    if dist_sq == 0:
        return 0.0
    
    # Dot products
    dot_ni = abs(sum(kernel_i.normal[k] * omega_I[k] for k in range(3)))
    dot_nj = abs(sum(kernel_j.normal[k] * omega_I[k] for k in range(3)))
    
    geometric_factor = (dot_ni * dot_nj) / dist_sq
    
    # Radiance term
    # B_j^{c(t)T} Y is approximated by clamping B_j
    radiance_scalar = clamp_rgb_to_scalar(kernel_j.outgoing_radiance)
    
    return radiance_scalar * geometric_factor

def weighted_reservoir_sampling_single_pass(items_with_weights):
    """
    Implements weighted reservoir sampling for a single selection.
    items_with_weights: list of (item, weight)
    Returns the selected item.
    """
    if not items_with_weights:
        return None
    
    # Standard weighted reservoir sampling algorithm (Chao 1982 style)
    # For a single sample, this is equivalent to alias method or cumulative sum 
    # if all weights are known, but "streaming" implies we might not store all.
    # However, for a group of size M, we can just do cumulative sum if M is small.
    # The source emphasizes "streaming... only once".
    
    total_weight = sum(w for _, w in items_with_weights)
    if total_weight == 0:
        return items_with_weights[0][0]
        
    r = random.uniform(0, total_weight)
    current_sum = 0
    for item, weight in items_with_weights:
        current_sum += weight
        if current_sum >= r:
            return item
    return items_with_weights[-1][0]

def grouped_next_event_estimation(kernels, groups, kernel_i, omega_I):
    """
    Selects next event kernel j for kernel i using grouped NEE.
    """
    # 1. Identify which group kernel_i belongs to? 
    # No, we select a group j to sample FROM.
    
    # 2. Sample a group first.
    # Probability of group g is proportional to its importance.
    # Source says: "sample a group and then sample a kernel within that group".
    # Importance proxy for group g: Summed outgoing radiance + spatial factors.
    # Let's assume group weights are precomputed or computed on fly.
    
    group_weights = []
    for g in groups:
        # Proxy: Sum of outgoing radiance norms of members
        w = sum(sum(k.outgoing_radiance) for k in g.members)
        group_weights.append(w)
        
    selected_group = weighted_reservoir_sampling_single_pass(
        [(g, w) for g, w in zip(groups, group_weights)]
    )
    
    # 3. Sample a kernel within the selected group
    candidates = []
    for k in selected_group.members:
        if k == kernel_i:
            continue # Avoid self-interaction if necessary, or handle 0 prob
        prob = calculate_unnormalized_prob(kernel_i, k, omega_I)
        candidates.append((k, prob))
        
    if not candidates:
        return None
        
    return weighted_reservoir_sampling_single_pass(candidates)
```

**Edge Cases and Pitfalls:**
*   **Zero Distance:** If $\|\mathbf{p}_j - \mathbf{p}_i\|_2^2 = 0$, the probability calculation divides by zero. The pseudocode handles this by returning 0.0.
*   **Visibility:** The method uses a rough geometric decay estimate. Actual visibility $V_{ji}$ is not explicitly calculated in the probability selection step to maintain efficiency, which may lead to selecting occluded kernels. The shadow ray test (from parent NEE) handles this later.
*   **Gradient Calculation:** When computing gradients, the `clamp` function must use the norm of gradients for all three channels, not just the forward pass illumination conversion.

## Operating characteristics
**Time Complexity:** The complexity is reduced from $O(N^2)$ to $O(N\sqrt{N})$ (or $O(N \cdot \sqrt{N})$ as stated in source, though logically if groups are size $N/G$, it's $O(N \cdot (N/G))$ if sampling is linear, but source explicitly states $O(N\sqrt{N})$). This is achieved by rewriting the single summation into a double summation (a tree of depth 2).
**Memory Complexity:** Requires storing group structures ($O(N)$ for kernel data + $O(G)$ for group metadata).
**Strengths:** Significantly reduces computational cost for large numbers of kernels ($N$). Enables importance sampling at a coarser group level.
**Limitations:** Approximation of probability ignores explicit visibility and BRDF response in the selection phase. Non-binary visibility means radiance cannot be fully aggregated per group, requiring per-kernel calculation within the group.
**When to use:** When $N$ (number of kernels/surfels) is large, and $O(N^2)$ next event estimation is a bottleneck. Suitable for differentiable rendering where gradients are needed.
**When not to use:** When high accuracy in direct light sampling probability is critical and visibility is complex, as the geometric approximation may be insufficient.

## Background
Originated in the context of differentiable light transport with Gaussian surfels. It draws inspiration from many-lights rendering [Walter et al. 2005; Yuksel 2019] but differs from hierarchical radiosity methods [Aupperle and Hanrahan 1993; Hanrahan et al. 1991] where transmitted radiance is assumed identical for group elements. In this method, transmitted radiance is calculated per kernel due to non-binary visibility. It is used in the solving procedure for efficient relighting and geometry reconstruction, providing an unbiased estimation unlike classical iterative radiosity methods.
