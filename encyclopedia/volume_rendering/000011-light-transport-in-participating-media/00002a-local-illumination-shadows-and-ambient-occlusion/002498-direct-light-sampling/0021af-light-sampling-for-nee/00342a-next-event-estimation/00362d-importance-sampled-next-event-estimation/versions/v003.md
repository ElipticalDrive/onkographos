# Importance-Sampled Next Event Estimation

Also called: NEE with Importance Sampling, Next-Habits-Event Estimation

## Overview
Importance-Sampled Next Event Estimation (NEE) is a Monte Carlo technique that reduces variance in direct illumination estimation by decoupling the sample budget from ray casting and using pre-computed importance structures to guide sampling of light paths [S1, unofficial]. It differs from standard [Next Event Estimation](7209-next-event-estimation.md) by explicitly sampling high-frequency boundary light paths using grid-based or proxy structures rather than uniform emitter sampling, and differs from [Random-Walk Subsurface Scattering](9028-random-walk-subsurface-scattering.md) by focusing on direct boundary interactions rather than volumetric scattering [S2].

## How it works
**Inputs:** Scene geometry (implicit or explicit), light sources, pre-computed importance data (grid cells or proxy surfaces), and a surface point $p$ on the boundary [S1, unofficial][S2][S3, unofficial].
**Outputs:** A sampled point on the light source and the corresponding radiance contribution [S1, unofficial][S2][S3, unofficial].

**Data Structures:**
1. **Grid-based Structure (for explicit/voxelized scenes):** A regular grid where each cell stores an estimated importance value derived from photon mapping (from lights) and importon mapping (from sensor) [S1, unofficial].
2. **Proxy Surface (for implicit surfaces):** A proxy mesh $F$ approximating the implicit surface $\phi$, used to sample points $q$ which are then projected onto $\phi$ [S2].
3. **ABSDF Components:** Factored appearance scattering distribution function components (specular and diffuse) with weights $w_j$ and convolved lobes [S3, unofficial].

**Steps:**
1. **Pre-processing (Grid Method):** Perform a photon mapping pass from light sources and an importon mapping pass from the sensor to assign an estimated importance value to each grid cell [S1, unofficial].
2. **Pre-processing (Implicit Method):** For environment maps, pre-compute plane-sphere intersections with uniformly distributed normals to determine plane orientation and build a 1D distribution conditioned on the normal direction [S2].
3. **Component Selection:** Pick one component between specular and diffuse via uniform sampling [S3, unofficial].
4. **Specular Sampling:** Pick one convolved lobe from the set based on weights $w_j$, then sample the corresponding SGGX distribution [S3, unofficial].
5. **Diffuse Sampling:** Assume a fixed $\kappa$ during importance sampling because $\kappa_{ij}$ cannot be determined without $\omega_i$ [S3, unofficial]. Pick one convolved lobe with the fixed $\kappa$ and sample the corresponding SGGX distribution [S3, unofficial].
6. **Light Path Completion (Grid Method):** Utilize the spatial importance information from the grid to sample the edge and complete the light path [S1, unofficial].
7. **Light Path Completion (Implicit Method):** Intersect the tangent plane $T_p B$ at point $p$ with the light source $L$ [S2]. Sample points from the resulting intersection [S2].
8. **PDF Computation:** Compute the corresponding probability density function (PDF) for the selected sample [S3, unofficial].

**Pseudocode:**
```python
import random

def importance_sample_nee(surface_point_p, light_source, precomputed_data, component_type):
    # Step 3: Component Selection (Uniform)
    if component_type == 'specular':
        # Step 4: Specular Sampling
        total_weight = sum(precomputed_data.lobes_weights)
        r = random.uniform(0.0, total_weight)
        cumulative = 0.0
        for i, w in enumerate(precomputed_data.lobes_weights):
            cumulative += w
            if r <= cumulative:
                lobe_index = i
                break
        else:
            lobe_index = len(precomputed_data.lobes_weights) - 1
        direction = precomputed_data.lobes[lobe_index].sample()
        light_point = intersect_ray_with_light(surface_point_p, direction, light_source)
        pdf = precomputed_data.lobes[lobe_index].pdf(direction)
        
    elif component_type == 'diffuse':
        # Step 5: Diffuse Sampling
        fixed_kappa = 1.0  # [G] Standard default for fixed kappa assumption
        total_weight = sum(precomputed_data.lobes_weights)
        r = random.uniform(0.0, total_weight)
        cumulative = 0.0
        for i, w in enumerate(precomputed_data.lobes_weights):
            cumulative += w
            if r <= cumulative:
                lobe_index = i
                break
        else:
            lobe_index = len(precomputed_data.lobes_weights) - 1
        direction = precomputed_data.lobes[lobe_index].sample()
        light_point = intersect_ray_with_light(surface_point_p, direction, light_source)
        pdf = precomputed_data.lobes[lobe_index].pdf(direction)
        
    else:
        # Step 7: Light Path Completion (Implicit/Tangent Plane)
        tangent_plane_normal = surface_point_p.normal
        tangent_plane_point = surface_point_p.position
        intersection_segment = intersect_plane_with_light(tangent_plane_point, tangent_plane_normal, light_source)
        if light_source.is_environment_map():
            # Use pre-computed 1D distribution conditioned on normal
            direction = sample_from_precomputed_distribution(surface_point_p.normal, precomputed_data.env_map_dist)
        else:
            t = random.uniform(0.0, 1.0)
            direction = intersection_segment.start + t * (intersection_segment.end - intersection_segment.start)
        light_point = intersect_ray_with_light(surface_point_p, direction, light_source)
        pdf = compute_pdf(direction, light_source, surface_point_p)

    return light_point, light_point.radiance, pdf

# Helper definitions (standard operations)
def intersect_ray_with_light(origin, direction, light):
    # Cast ray from origin along direction to find intersection with light geometry
    return light.cast_ray(origin, direction)

def intersect_plane_with_light(point, normal, light):
    # Intersect plane defined by point and normal with light geometry
    return light.intersect_plane(point, normal)

def sample_from_precomputed_distribution(normal, dist):
    # Sample from the pre-computed 1D distribution conditioned on normal
    return dist.sample(normal)

def compute_pdf(direction, light, point):
    # Standard geometric PDF computation
    return light.pdf(direction, point)
```

**Parameters:**
* **Sample Budget:** Decoupled from the ray casting sample budget [S3, unofficial].
* **Grid Resolution:** Must be high for complex scenes, leading to scalability issues [S1, unofficial].
* **Number of Lights:** Experiments assume one light; handling large numbers of polygons is left for future work [S2].

**Edge Cases and Pitfalls:**
* **Complex Scenes:** When the scene becomes more complicated, the resolution of the regular grid has to be impractically high to achieve desirable results, leading to scalability issues [S1, unofficial].
* **Kappa Determination:** For diffuse components, $\kappa_{ij}$ cannot be determined without $\omega_i$, necessitating the assumption of a fixed $\kappa$ [S3, unofficial].
* **Large Polygon Counts:** Efficient plane intersection with a large number of polygons is not handled in the implicit surface variant [S2].

## Subtopics

### Tangent Plane Light Intersection for NEE
An efficient sampling strategy for implicit surfaces that intersects the tangent plane at a sampled surface point with the light source, then samples points from the resulting intersection, rather than uniformly sampling tangent directions [S2]. It pre-computes plane-sphere intersections for environment maps to build a 1D distribution conditioned on the normal direction, avoiding on-the-fly distribution building [S2]. It assumes one light source in experiments [S2].

## Operating characteristics
* **Time Complexity:** Pre-processing requires photon/importon mapping passes [S1, unofficial]. Sampling is efficient if the importance structure is accurate, but grid resolution requirements can make pre-processing costly for complex scenes [S1, unofficial].
* **Memory Complexity:** Grid-based methods require memory proportional to the grid resolution, which can be impractically high for complex scenes [S1, unofficial].
* **Strengths:** Decouples sample budget from ray casting [S3, unofficial]. Reduces variance for high-frequency boundary light paths [S1, unofficial].
* **Limitations:** Scalability issues with regular grids in complex scenes [S1, unofficial]. Limited handling of multiple lights in implicit variants [S2].
* **When to Use:** When direct illumination variance is high due to small or complex light sources, and pre-processing time is acceptable [S1, S3, unofficial].
* **When Not to Use:** For very complex scenes where grid resolution becomes prohibitive [S1, unofficial].

## Background
Originating from techniques like Next-Habits-Event Estimation (NEE) introduced by Zhang et al. [ZMY* 20] for differentiable rendering, this method uses pre-processed grid-based structures to sample high-frequency boundary light paths [S1, unofficial]. It was further developed to address scalability issues with kd-trees [YLB* 22] and adapted for implicit surfaces using tangent plane intersections [S2]. It is used in physics-based differentiable rendering and level-of-detail rendering pipelines [S1, S3, unofficial].
