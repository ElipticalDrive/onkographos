# Direct Light Sampling

Also called: Direct Illumination Sampling, Iluminación directa

## Overview
Direct Light Sampling is a technique for estimating direct illumination in participating media by explicitly shooting a ray from an intersection point (or volume sample) toward a light source to determine visibility and light contribution [S1, unofficial][S2, unofficial]. It solves the problem of noisy or absent direct lighting in volumetric scenes by providing a deterministic or probabilistic check for occlusion between the shading point and the light [S1, unofficial]. It differs from [Shadow Ray Casting](2796-shadow-ray-casting.md) by often employing importance sampling strategies and power heuristics for unbiased estimation in complex scenes, and from [Light Sampling for NEE](2616-light-sampling-for-nee.md) by focusing on the general mechanism of direct light visibility rather than specific Nearest Energy Estimation PDFs for path tracing connections.

## How it works
The method evaluates the direct light contribution at a point $\mathbf{p}$ (either a surface intersection or a volume sample) by testing the line of sight to one or more light sources.

### Inputs and Outputs
*   **Inputs:**
    *   $\mathbf{p}$: The 3D position where illumination is being computed.
    *   $\mathcal{L}$: The set of light sources in the scene.
    *   $\mathcal{O}$: The set of occluding geometry (objects, voxels, or meshes).
    *   $\mathbf{n}$: The normal at $\mathbf{p}$ (if surface shading is applied).
    *   $\sigma_t(\mathbf{x})$: The extinction coefficient field (for volumetric transmittance).
*   **Outputs:**
    *   $L_{direct}(\mathbf{p})$: The radiance contribution from direct light sources.

### Data Structures
*   **Light Source:** Defined by position $\mathbf{p}_L$, direction $\mathbf{d}_L$ (for directional), color/intensity $I_L$, and probability density function (PDF) $pdf_L$ if sampled [S2, unofficial].
*   **Occlusion Test:** Returns the minimum distance $t_{min}$ to the nearest object along a ray. For volumes, this may involve integrating $\sigma_t$ along the ray [S1, unofficial][S6, unofficial].

### Steps
1.  **Select Light:** If multiple lights exist, select a light source $L \in \mathcal{L}$ using a sampler. If only one light exists and it is the "hit light" (the primary light used for shading), it may be skipped or handled specifically to avoid double counting in some path tracing contexts, though direct sampling typically includes all lights [S2, unofficial].
2.  **Compute Direction:** Calculate the direction vector from the shading point $\mathbf{p}$ to the light source position $\mathbf{p}_L$:
    $$ \mathbf{d}_L = \text{normalize}(\mathbf{p}_L - \mathbf{p}) $$
    [S1, unofficial]
3.  **Cast Shadow Ray:** Create a shadow ray $\mathbf{r}$ originating at $\mathbf{p}$ (with a small epsilon offset to avoid self-intersection) in direction $\mathbf{d}_L$.
4.  **Test Visibility:**
    *   **Geometry:** Find the minimum intersection distance $t_{obj}$ among all objects $O \in \mathcal{O}$ along $\mathbf{r}$.
    *   **Light:** Find the distance $t_{light}$ to the light source $L$ along $\mathbf{r}$.
    *   **Volume:** If the medium is participating, integrate the optical depth $\tau$ from $\mathbf{p}$ to the light. The transmittance is $T = \exp(-\tau)$.
5.  **Determine Occlusion:** The light is visible if $t_{light} < t_{obj}$ (for geometric occlusion) and the transmittance $T$ is non-zero.
6.  **Compute Contribution:**
    *   If visible, calculate the direct light contribution. For a point light, this involves the light's color, intensity, and the shading model (e.g., Lambertian).
    *   Apply the **Power Heuristic** if using multiple importance sampling to balance the probability of selecting the light vs. the path direction [S2, unofficial]:
        $$ w = \frac{p_s(x)^2}{p_s(x)^2 + p_l(x)^2} $$
        where $p_s$ is the PDF of the shadow ray direction and $p_l$ is the PDF of the light sampling.
    *   The contribution is added to the total direct light:
        $$ L_{direct} += \text{Material}(\mathbf{p}, \mathbf{n}, \mathbf{d}_L) \cdot L_{incident} \cdot w $$
    *   Scale by the total number of lights if uniform sampling is used [S2, unofficial].

### Pseudocode
```python
def direct_light_sampling(p, normal, lights, objects, volume_field):
    """
    Computes direct illumination at point p.
    """
    direct_light = Vec3(0.0, 0.0, 0.0)
    
    # Select a light (simplified: uniform random selection for demonstration)
    # In practice, use a sampler that respects light power
    light_index = random_integer(0, len(lights) - 1)
    light = lights[light_index]
    
    # Calculate direction to light
    if light.type == DIRECTIONAL:
        direction_to_light = light.direction
        distance = float('inf')
    else:
        direction_to_light = normalize(light.position - p)
        distance = length(light.position - p)
        
    # Create shadow ray
    shadow_ray_origin = p + normal * EPSILON
    shadow_ray = Ray(shadow_ray_origin, direction_to_light)
    
    # Test for occlusion by geometry
    min_t_obj = float('inf')
    for obj in objects:
        t = obj.intersect(shadow_ray)
        if t > EPSILON and t < min_t_obj:
            min_t_obj = t
            
    # Test for light intersection (if point/area light)
    is_light_hit = False
    if light.type != DIRECTIONAL:
        # Check if the light is closer than any occluding object
        if distance < min_t_obj:
            is_light_hit = True
            
    # For directional lights, assume infinite distance, so check only geometry
    if light.type == DIRECTIONAL:
        is_light_hit = (min_t_obj == float('inf'))
        
    # Calculate Transmittance through volume (if applicable)
    # This requires integrating sigma_t along the ray
    transmittance = 1.0
    if volume_field is not None:
        # Simplified: sample at midpoint or use ray marching
        # Real implementation requires numerical integration
        optical_depth = integrate_extinction(shadow_ray, distance if light.type != DIRECTIONAL else MAX_DIST, volume_field)
        transmittance = exp(-optical_depth)
        
    if is_light_hit and transmittance > 0:
        # Get light radiance
        light_radiance = light.get_radiance(p, direction_to_light)
        
        # Evaluate material shading
        # Example: Lambertian diffuse
        cos_theta = max(0.0, dot(normal, -direction_to_light))
        material_reflectance = light.material.get_reflectance(normal, -direction_to_light)
        
        # Contribution
        contribution = light_radiance * cos_theta * material_reflectance * transmittance
        
        # Scale by number of lights if uniform sampling was used
        # (Assuming uniform selection here)
        contribution *= len(lights)
        
        direct_light += contribution
        
    return direct_light
```

### Parameters and Edge Cases
*   **EPSILON:** A small offset added to the shadow ray origin to prevent self-intersection artifacts [S1, unofficial].
*   **Light Types:** Point lights require distance calculation and inverse-square falloff (implicit in radiance). Directional lights have infinite distance and no falloff [S2, unofficial].
*   **Degenerate Input:** If $\mathbf{p}$ is on the boundary of the volume, the shadow ray may immediately intersect the volume boundary. Proper epsilon handling is required.
*   **Precision:** Floating-point precision issues can cause flickering shadows. Using a small bias or normal offset is standard [S1, unofficial].

## Subtopics

### Direct Light Contribution Estimation
This variant specifically addresses the accuracy of direct light in voxel-based rendering by combining local and global opacity data. It calculates the direct light intensity $I_d(s_0)$ at a sample point $s_0$ by using local piecewise integration for the segment near the sample and global volume rendering (SVR) for the rest of the path to the light [S3].
*   **Formula:** $I_d(s_0) = I_0 \cdot (1 - \alpha_g(s_1)) \cdot (1 - \alpha_l(s_0))$, where $I_0$ is source intensity, $\alpha_g(s_1)$ is global opacity from $s_1$ to the light, and $\alpha_l(s_0)$ is local opacity at $s_0$ [S3].
*   **Pitfall:** Using only global opacity $\alpha_g$ for the entire ray reduces quality. Using local $\alpha_l(s_0)$ for the first segment ensures highest resolution for local occlusion [S3].

## Operating characteristics
*   **Time Complexity:** $O(N \cdot L)$, where $N$ is the number of shading points (pixels/voxels) and $L$ is the number of light sources tested per point. If all lights are tested, it is $O(N \cdot L)$. If importance sampling is used, it is $O(N)$.
*   **Memory Complexity:** $O(1)$ additional memory per shading point, assuming the light and geometry data structures are pre-loaded.
*   **Strengths:** Provides sharp, accurate shadows for point and directional lights. Simple to implement for basic scenes.
*   **Limitations:** Noisy with many lights unless multiple importance sampling is used. Does not account for indirect illumination (bounces). Performance degrades with complex geometry or large numbers of lights.
*   **When to use:** Scenes with few dominant light sources where sharp shadows are desired.
*   **When not to use:** Scenes with many lights (use Light Sampling for NEE), or when indirect lighting is required (use Path Tracing).

## Background
Direct Light Sampling is a fundamental technique in computer graphics, originating from the need to render shadows in ray-traced and ray-marched scenes. It is a core component of many global illumination algorithms, including Whitted-style ray tracing and path tracing. The specific application to volume rendering involves adapting the shadow ray to integrate extinction coefficients through participating media [S1, unofficial][S3]. The term "Iluminación directa" appears in Spanish-language theses on sparse voxel octrees and global illumination [S1, unofficial].
