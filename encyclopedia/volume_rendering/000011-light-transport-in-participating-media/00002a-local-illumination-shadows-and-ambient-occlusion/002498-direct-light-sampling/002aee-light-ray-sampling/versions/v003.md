# Light Ray Sampling

Also called: Light Ray Marching

## Overview
Light Ray Sampling computes the direct illumination at a volume sample point by stepping along the direction to a distant light source (typically the sun), accumulating density, and applying a phase function to determine the scattered light color [S1, unofficial]. It differs from mesh-based shadow casting by explicitly integrating density through the participating medium along the light path [S1, unofficial].

## How it works
**Inputs:**
- Sample point $p$ (3D position) [S1, unofficial].
- Light direction $\omega_l$ (unit vector, e.g., sun direction) [S1, unofficial].
- View direction $\omega_v$ (unit vector, for powder effect) [S1, unofficial].
- Extinction coefficient $\sigma_T$ (scalar or field) [S1, unofficial].
- Number of steps $N_{steps}$ (integer, constant `STEPS_LIGHT` in source) [S1, unofficial].
- Light ray distance $D$ (distance from $p$ to sun or AABB boundary) [S1, unofficial].
- Density field: Accessible via `getDensity(pos)`, returning a scalar density value $\rho$ at position `pos` [S1, unofficial].

**Outputs:**
- Inscatter radiance contribution $L_{inscatter}$ (RGB color) [S1, unofficial].

**Data Structures:**
- Accumulator `lightRayDensity` (scalar, initialized to 0.0) [S1, unofficial].

**Steps:**
1. **Calculate Light Ray Distance:** Determine the distance $D$ from point $p$ to the sun using an AABB intersection test [S1, unofficial].
2. **Initialize Accumulators:** Set `lightRayDensity` = 0.0 and `distToStart` = 0.0 [S1, unofficial].
3. **Calculate Step Size:** Compute the step length $h = D / N_{steps}$ [S1, unofficial].
4. **Accumulate Density:** Loop $j$ from 0 to $N_{steps}-1$: `lightRayDensity` += `getDensity`($p + \omega_l \cdot j \cdot h$) [S1, unofficial].
5. **Scale Density:** Multiply the accumulated density by the step size: `lightRayDensity` *= $h$ [S1, unofficial].
6. **Calculate Inscatter Color:** Compute the base inscatter color using the accumulated optical depth and the scattering angle cosine $\cos\Theta = \omega_l \cdot \omega_v$ via `multipleOctaves`(`lightRayDensity`, $\cos\Theta$) [S1, unofficial].
7. **Apply Powder Effect:** Modulate the result using a view-dependent attenuation: return `mix`(`beersLaw` $\cdot 2.0 \cdot (1.0 - \exp(-\text{lightRayDensity} \cdot 2.0 \cdot \sigma_T))$, `beersLaw`, $0.5 + 0.5 \cdot \cos\Theta$) [S1, unofficial]. Here `beersLaw` is the result from step 6, and `mix(a, b, t)` is linear interpolation $a(1-t) + b t$ [S1, unofficial].

**Pseudocode:**
```python
def light_ray_sampling(p, omega_l, omega_v, sigma_T, n_steps, get_density, light_ray_distance):
    # Step 1 & 2: Initialize
    light_ray_density = 0.0
    dist_to_start = 0.0  # Initialized per source [S1, unofficial]
    
    # Step 3: Step size
    step_l = light_ray_distance / n_steps
    
    # Step 4: Accumulate density
    for j in range(n_steps):
        pos = p + omega_l * (j * step_l)
        light_ray_density += get_density(pos)
        
    # Step 5: Scale by step size
    light_ray_density *= step_l
    
    # Step 6: Calculate base inscatter color
    cos_theta = dot(omega_l, omega_v)
    # Source does not specify multipleOctaves implementation [S1, unofficial]
    beers_law = multiple_octaves(light_ray_density, cos_theta)
    
    # Step 7: Apply powder effect
    attenuation = 2.0 * (1.0 - exp(-light_ray_density * 2.0 * sigma_T))
    modified_color = beers_law * attenuation
    blend_factor = 0.5 + 0.5 * cos_theta
    final_color = mix(modified_color, beers_law, blend_factor)
    
    return final_color

def mix(a, b, t):
    return a * (1.0 - t) + b * t
```

**Parameters:**
- $N_{steps}$: Number of samples along the light ray. The source uses a constant `STEPS_LIGHT` [S1, unofficial].
- $\sigma_T$: Extinction coefficient. Not given in the sources.

**Edge Cases:**
- If $D=0$, step size is undefined. Guard against division by zero [G].
- If $\cos\Theta < -1$ or $> 1$ due to floating point error, clamp to $[-1, 1]$ [G].

## Subtopics

### Sun Direction Sampling
A variant for distant light sources with a small angular diameter, modeled by irradiance and sampled uniformly within its cone [S2, unofficial]. Instead of a single fixed direction, the sun direction is sampled uniformly within its defined angular cone [S2, unofficial]. The sun's contribution is added to the camera's escaped radiance in addition to any environment sky contribution [S2, unofficial].
