# Light Ray Sampling

Also called: Light Ray Marching

## Overview
Light Ray Sampling computes the direct illumination at a surface or volume sample point by stepping along the direction to a light source (typically a distant sun) to the light's boundary, accumulating optical density, and applying the phase function [S1, unofficial]. It differs from standard shadow ray tracing by explicitly integrating the participating medium's extinction and scattering properties along the light path, rather than performing a single binary occlusion test [S1, S3, unofficial].

## How it works
**Inputs:**
- Sample point $p$ [S1, unofficial].
- Light direction vector $\hat{\omega}_l$ (normalized) [S1, unofficial].
- Distance to light source boundary $d_{light}$, obtained via AABB intersection [S1, unofficial].
- Number of steps $N_{steps}$ (denoted `STEPS_LIGHT` in sources) [S1, unofficial].
- Volume density function $f_{density}(x)$ [S1, unofficial].
- Phase function $P(\cos \theta)$, implemented as `multipleOctaves` [S1, unofficial].
- Total scattering coefficient $\sigma_T$ [S1, unofficial].
- View direction $\hat{\omega}_v$ for powder effect [S1, unofficial].
- Beer's law attenuation factor `beersLaw` [S1, unofficial].

**Outputs:**
- Inscafter color contribution [S1, unofficial].

**Data Structures:**
- Accumulators: `lightRayDensity` (scalar, initialized to 0.0) [S1, unofficial].
- Loop counter $j$ from $0$ to $N_{steps}-1$ [S1, unofficial].

**Parameters:**
- `STEPS_LIGHT`: Integer number of steps. Typical value not given in sources [S1, unofficial].
- Powder effect blend factor: 0.5 [S1, unofficial].
- Powder effect multiplier: 2.0 [S1, unofficial].

**Steps:**
1. Calculate the distance from point $p$ to the light source boundary using AABB intersection. Let this be $d_{light}$ [S1, unofficial].
2. Initialize `lightRayDensity` = 0.0 [S1, unofficial].
3. Calculate the step size: $stepL = d_{light} / N_{steps}$ [S1, unofficial].
4. Loop $j$ from $0$ to $N_{steps}-1$:
   a. Calculate the sample position: $p_j = p + \hat{\omega}_l \cdot (j \cdot stepL)$ [S1, unofficial].
   b. Retrieve the density at $p_j$: $\rho_j = f_{density}(p_j)$ [S1, unofficial].
   c. Accumulate density: `lightRayDensity` += $\rho_j$ [S1, unofficial].
5. Scale the accumulated density by the step size: `lightRayDensity` *= $stepL$ [S1, unofficial].
6. Calculate the inscafter color using the accumulated density and the cosine of the scattering angle $\theta$ (angle between $\hat{\omega}_l$ and $\hat{\omega}_v$):
   $$ C_{inscatter} = \text{multipleOctaves}(\text{lightRayDensity}, \cos \theta) $$
   [S1, unofficial].
7. Apply the powder effect (view-dependent attenuation):
   $$ C_{final} = \text{mix}\left( \text{beersLaw} \cdot 2.0 \cdot (1.0 - e^{-\text{lightRayDensity} \cdot 2.0 \cdot \sigma_T}), \text{beersLaw}, 0.5 + 0.5 \cdot \cos \theta \right) $$
   [S1, unofficial].
   Where $\text{mix}(a, b, t) = a(1-t) + b t$.

**Pseudocode:**
```python
def light_ray_sampling(p, sun_direction, distance_to_light, steps_light, get_density, multiple_octaves, sigma_T, view_direction, beers_law):
    # Step 1 & 2: Distance is input, density accumulator initialized
    light_ray_density = 0.0
    
    # Step 3: Calculate step size
    step_l = distance_to_light / steps_light
    
    # Step 4: Loop and accumulate density
    for j in range(steps_light):
        # Calculate sample position
        sample_pos = p + sun_direction * (j * step_l)
        
        # Get density and accumulate
        density_at_sample = get_density(sample_pos)
        light_ray_density += density_at_sample
        
    # Step 5: Scale by step size
    light_ray_density *= step_l
    
    # Calculate cosine theta between light direction and view direction
    cos_theta = dot(sun_direction, view_direction)
    
    # Step 6: Calculate inscafter color
    inscafter_color = multiple_octaves(light_ray_density, cos_theta)
    
    # Step 7: Apply powder effect
    # Term 1: Beer's law modified by powder effect
    term1 = beers_law * 2.0 * (1.0 - exp(-light_ray_density * 2.0 * sigma_T))
    # Term 2: Original Beer's law
    term2 = beers_law
    # Blend factor
    t = 0.5 + 0.5 * cos_theta
    
    final_color = mix(term1, term2, t)
    
    return final_color
```

**Edge Cases and Pitfalls:**
- If `distance_to_light` is 0 or negative, the step size becomes undefined or negative. This requires a guard clause [G].
- Precision issues may arise if `light_ray_density` becomes very large, causing $e^{-\dots}$ to underflow to 0 [G].
- The powder effect blend factor $0.5 + 0.5 \cos \theta$ ranges from 0 to 1, ensuring valid interpolation [S1, unofficial].

## Subtopics

### Sun Direction Sampling
A variant for distant light sources with small angular diameter. Instead of a fixed sun direction, the direction is sampled uniformly within the sun's defined angular cone [S2, unofficial]. The sun's contribution is added to the camera's escaped radiance, separate from environment sky contributions [S2, unofficial]. This handles the finite size of the sun for soft shadows or volumetric glow effects [S2, unofficial].

### Light Color Transmission
A modification to the ray march procedure where the material color is multiplied by the light color, and the light color is attenuated by the volume material between the light and the ray march point [S3, unofficial]. This accounts for the spectral interaction between light and volume, treating color as a triplet product where $C_{out} = C_{in} \odot F$ [S3, unofficial].

## Operating characteristics
- **Time Complexity:** $O(N_{steps})$ per sample point, where $N_{steps}$ is the number of light ray steps [S1, unofficial].
- **Memory Complexity:** $O(1)$ auxiliary memory, as density is accumulated in a scalar [S1, unofficial].
- **Strengths:** Accurately models light transport through participating media, including absorption and scattering variations along the light path [S1, unofficial].
- **Limitations:** Computationally expensive due to multiple density queries and phase function evaluations per light sample [S1, unofficial]. Performance scales linearly with `STEPS_LIGHT` [S1, unofficial].
- **When to use:** When accurate volumetric lighting, such as god rays or light shafts through fog/dust, is required [S1, unofficial].
- **When not to use:** For real-time applications with strict performance budgets where approximate shadow rays suffice [G].

## Background
Light Ray Sampling is a technique used in volume rendering to compute direct illumination in participating media. It is often associated with real-time volumetric effects in games and interactive applications, as seen in the `volumetrics` repository [S1, unofficial]. The concept of light color transmission through volumes has been discussed in academic contexts, such as production volume rendering reports [S3, unofficial]. The specific implementation details, including the powder effect and multiple octaves phase function, are documented in unofficial repositories [S1, S2, unofficial].
