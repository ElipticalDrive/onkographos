# Light Ray Sampling

Also called: Light Ray Marching, Ray Marching with Light Sampling

## Overview
Light Ray Sampling computes direct illumination at a sample point by stepping along the direction to a light source (typically a distant sun) to the light's boundary, accumulating optical density, and applying the phase function [S2, unofficial]. It differs from standard shadow ray tracing by explicitly integrating the participating medium's extinction and scattering properties along the light path, rather than performing a single binary occlusion test [S2, unofficial].

## How it works
**Inputs:**
- Sample point $p$ [S2, unofficial].
- Light direction vector $\hat{\omega}_l$ (normalized) [S2, unofficial].
- Distance to light source boundary $d_{light}$, obtained via AABB intersection [S2, unofficial].
- Number of steps $N_{steps}$ (denoted `STEPS_LIGHT` in sources) [S2, unofficial].
- Volume density function $f_{density}(x)$ [S2, unofficial].
- Phase function `multipleOctaves` [S2, unofficial].
- Total scattering coefficient $\sigma_T$ [S2, unofficial].
- View direction $\hat{\omega}_v$ for powder effect [S2, unofficial].
- Beer's law attenuation factor `beersLaw` [S2, unofficial].

**Outputs:**
- Inscafter color contribution [S2, unofficial].

**Data Structures:**
- Accumulator: `lightRayDensity` (scalar, initialized to 0.0) [S2, unofficial].
- Loop counter $j$ from $0$ to $N_{steps}-1$ [S2, unofficial].

**Parameters:**
- `STEPS_LIGHT`: Integer number of steps. Typical value not given in the sources.
- Powder effect blend factor: 0.5 [S2, unofficial].
- Powder effect multiplier: 2.0 [S2, unofficial].

**Steps:**
1. Calculate the distance from point $p$ to the light source boundary using AABB intersection. Let this be $d_{light}$ [S2, unofficial].
2. Initialize `lightRayDensity` = 0.0 [S2, unofficial].
3. Calculate the step size: $stepL = d_{light} / N_{steps}$ [S2, unofficial].
4. Loop $j$ from $0$ to $N_{steps}-1$:
   a. Calculate the sample position: $p_j = p + \hat{\omega}_l \cdot (j \cdot stepL)$ [S2, unofficial].
   b. Retrieve the density at $p_j$: $\rho_j = f_{density}(p_j)$ [S2, unofficial].
   c. Accumulate density: `lightRayDensity` += $\rho_j$ [S2, unofficial].
5. Scale the accumulated density by the step size: `lightRayDensity` *= $stepL$ [S2, unofficial].
6. Calculate the inscafter color using the accumulated density and the cosine of the scattering angle $\theta$ (angle between $\hat{\omega}_l$ and $\hat{\omega}_v$):
   $$ C_{inscatter} = \text{multipleOctaves}(\text{lightRayDensity}, \cos \theta) $$
   [S2, unofficial].
7. Apply the powder effect (view-dependent attenuation):
   $$ C_{final} = \text{mix}\left( \text{beersLaw} \cdot 2.0 \cdot (1.0 - e^{-\text{lightRayDensity} \cdot 2.0 \cdot \sigma_T}), \text{beersLaw}, 0.5 + 0.5 \cdot \cos \theta \right) $$
   [S2, unofficial].

**Pseudocode:**
```python
def light_ray_sampling(p, sun_direction, distance_to_light, steps_light, get_density, multiple_octaves, sigma_T, view_direction, beers_law):
    # Guard for zero or negative distance [G]
    if distance_to_light <= 0.0:
        return beers_law
    
    # Step 2: Initialize accumulator
    light_ray_density = 0.0
    
    # Step 3: Calculate step size
    step_l = distance_to_light / steps_light
    
    # Step 4: Loop and accumulate density
    for j in range(steps_light):
        sample_pos = p + sun_direction * (j * step_l)
        light_ray_density += get_density(sample_pos)
        
    # Step 5: Scale by step size
    light_ray_density *= step_l
    
    # Calculate cosine theta and clamp for precision [G]
    cos_theta = dot(sun_direction, view_direction)
    cos_theta = max(-1.0, min(1.0, cos_theta))
    
    # Step 6: Calculate inscafter color (intermediate step per source)
    inscafter_color = multiple_octaves(light_ray_density, cos_theta)
    
    # Step 7: Apply powder effect
    term1 = beers_law * 2.0 * (1.0 - exp(-light_ray_density * 2.0 * sigma_T))
    term2 = beers_law
    t = 0.5 + 0.5 * cos_theta
    
    # Component-wise mix if beers_law is a vector, else scalar [G]
    final_color = mix(term1, term2, t)
    
    return final_color

def mix(a, b, t):
    # Linear interpolation: a(1-t) + b*t [G]
    return a * (1.0 - t) + b * t
```

**Edge Cases and Pitfalls:**
- If `distance_to_light` is 0 or negative, the step size becomes undefined or negative. A guard clause returns the base Beer's law attenuation [G].
- Precision issues may arise if `light_ray_density` becomes very large, causing $e^{-\dots}$ to underflow to 0 [G].
- The powder effect blend factor $0.5 + 0.5 \cos \theta$ ranges from 0 to 1, ensuring valid interpolation [S2, unofficial].
- Floating-point inaccuracies in `dot` products can push $\cos \theta$ outside $[-1, 1]$, requiring clamping before interpolation [G].

## Subtopics

### Sun Direction Sampling
A variant for distant light sources with small angular diameter. Instead of a fixed sun direction, the direction is sampled uniformly within the sun's defined angular cone [S3, unofficial]. The sun's contribution is added to the camera's escaped radiance, separate from environment sky contributions [S3, unofficial].

### [Light Color Transmission](10965-light-color-transmission.md)
A modification to the ray march procedure where the material color is multiplied by the light color, and the light color is attenuated by the volume material between the light and the ray march point.

## Operating characteristics
- **Time Complexity:** $O(N_{steps})$ per sample point, where $N_{steps}$ is the number of light ray steps [G].
- **Memory Complexity:** $O(1)$ auxiliary memory, as density is accumulated in a scalar [G].
- **Strengths:** Accurately models light transport through participating media, including absorption and scattering variations along the light path [S2, unofficial].
- **Limitations:** Computationally expensive due to multiple density queries and phase function evaluations per light sample [S2, unofficial]. Performance scales linearly with `STEPS_LIGHT` [S2, unofficial].

## Background
Light Ray Sampling is a technique used in volume rendering to compute direct illumination in participating media. The specific implementation details, including the powder effect and multiple octaves phase function, are documented in the `volumetrics` repository [S2, unofficial]. The concept of light color transmission through volumes has been discussed in production volume rendering reports [S1, unofficial].
