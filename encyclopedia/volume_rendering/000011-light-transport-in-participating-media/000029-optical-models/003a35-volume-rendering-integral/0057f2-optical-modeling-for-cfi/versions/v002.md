# Optical Modeling for CFI

Also called: CFI Optical Intensity Calculation, Shadowgraph/Schlieren/Interferometry Formulas

## Overview
Optical Modeling for CFI is a theoretical model calculating optical intensities for shadowgraph, schlieren, and interferometric techniques based on line-of-sight integration through a discrete three-dimensional field [S1, unofficial].

## How it works
**Inputs:**
*   A discrete 3D field of gas density $\rho(x,y,z)$ or refractive index $n(x,y,z)$ [S1, unofficial].
*   Integration limits $z_1, z_2$ representing the length along the optical path where the index of refraction varies [S1, unofficial].
*   Optical parameters: wavelength $\lambda$, reference refractive index $n_0$, and glass plate angle difference $\xi$ (or $\xi_x, \xi_y$) [S1, unofficial].
*   Gladstone-Dale constant $K$ [S1, unofficial].

**Outputs:**
*   Optical intensity $I$ for shadowgraph or schlieren modes [S1, unofficial].
*   Fringe shift $F(x,y)$ and resulting intensity $I \propto \cos^2(\pi F)$ for interferometry [S1, unofficial].

**Data Structures:**
The input is a discrete 3D array [S1, unofficial]. The integration is performed along the $z$-axis (line of sight) for each $(x,y)$ location [S1, unofficial]. The optical path is divided into $n$ segments along the $z$-axis [S1, unofficial].

**Formulas and Definitions:**
*   $\xi$: Difference of the angle of two glass plates $P_1$ and $P_2$ [S1, unofficial].
*   $\lambda$: Wavelength of the light source [S1, unofficial].
*   $n_0$: Refractive index of the reference field [S1, unofficial].
*   $z_1, z_2$: Limits of integration representing the length along the optical path where the index of refraction varies [S1, unofficial].
*   $K$: Gladstone-Dale constant [S1, unofficial]. For gas mixtures, the source provides a garbled formula involving mass fraction $a_i$ and species constant $K_i$ [S1, unofficial].

**Step-by-Step Method:**

1.  **Determine Optical Mode:** Select the appropriate intensity formula based on the imaging technique (Shadowgraph, Schlieren, or Interferometry) [S1, unofficial].

2.  **Shadowgraph Intensity:**
    Calculate the intensity proportional to the second derivative of density $\rho$ integrated along $z$ [S1, unofficial]:
    $$ I \propto \int_{z_1}^{z_2} \left( \frac{\partial^2 \rho}{\partial x^2} + \frac{\partial^2 \rho}{\partial y^2} \right) dz $$
    In discrete form over $n$ segments with step $\Delta z_i$:
    $$ I \propto \sum_{i=1}^{n} \left( \frac{\partial^2 \rho}{\partial x^2} + \frac{\partial^2 \rho}{\partial y^2} \right)_i \Delta z_i $$
    [S1, unofficial]

3.  **Schlieren Intensity:**
    Calculate the intensity proportional to the first derivative of refractive index $n$ integrated along $z$ [S1, unofficial].
    *   Vertical knife-edge/filter:
        $$ I \propto \int_{z_1}^{z_2} \frac{\partial n}{\partial x} dz $$
    *   Horizontal knife-edge/filter:
        $$ I \propto \int_{z_1}^{z_2} \frac{\partial n}{\partial y} dz $$
    Discrete forms are implied by applying the trapezoidal rule to the continuous integrals [S1, unofficial].

4.  **Interferometry Fringe Shift:**
    Calculate the continuous fringe shift $F(x,y)$ [S1, unofficial]:
    $$ F(x,y) = \frac{2\xi_x}{\lambda} \int_{z_1}^{z_2} [n(x,y,z) - n_0] dz $$
    For discrete fields with $n$ segments:
    $$ F(x,y) = \frac{2\xi_x}{\lambda} \sum_{i=1}^{n} [n_i - n_0] \Delta z_i $$
    [S1, unofficial]

    Alternatively, using the Gladstone-Dale equation $n - 1 = K\rho$ [S1, unofficial], the fringe shift can be expressed in terms of density $\rho$ and reference density $\rho_0$ (where $n_0 - 1 = K\rho_0$) [S1, unofficial]:
    $$ F(x,y) = \frac{2\xi_x K}{\lambda \rho_0} \sum_{i=1}^{n} \rho_i \Delta z_i $$
    [S1, unofficial]

5.  **Interferometry Intensity:**
    Compute the final intensity:
    $$ I \propto \cos^2(\pi F) $$
    [S1, unofficial]

**Pseudocode:**

```python
import math

def calculate_cfi_intensity(rho_grid, n_grid, z_limits, dx, dy, dz, lambda_val, xi_x, xi_y, n0, K, mode, use_horizontal=False):
    """
    Calculate optical intensity for CFI modes.
    
    Args:
        rho_grid: 3D list/array indexed as [x][y][z] of density values.
        n_grid: 3D list/array indexed as [x][y][z] of refractive index values.
        z_limits: Tuple (z1, z2) defining integration bounds.
        dx, dy, dz: Grid spacing in x, y, z directions.
        lambda_val: Wavelength lambda.
        xi_x, xi_y: Glass plate angle differences.
        n0: Reference refractive index.
        K: Gladstone-Dale constant.
        mode: String, one of 'shadowgraph', 'schlieren', 'interferometry'.
        use_horizontal: Boolean, True for horizontal knife-edge, False for vertical.
        
    Returns:
        2D list/array [x][y] of optical intensity.
    """
    x_dim = len(rho_grid)
    y_dim = len(rho_grid[0])
    z_dim = len(rho_grid[0][0])
    intensity_map = [[0.0] * y_dim for _ in range(x_dim)]

    for x in range(x_dim):
        for y in range(y_dim):
            # Precompute derivatives along z
            # Not given in the sources how to handle boundaries; using standard finite differences [G]
            d2_rho_dx2 = []
            for z in range(z_dim):
                if x == 0:
                    val = (rho_grid[x+1][y][z] - 2*rho_grid[x][y][z] + rho_grid[x+1][y][z]) / (dx**2)
                elif x == x_dim - 1:
                    val = (rho_grid[x][y][z] - 2*rho_grid[x][y][z] + rho_grid[x-1][y][z]) / (dx**2)
                else:
                    val = (rho_grid[x+1][y][z] - 2*rho_grid[x][y][z] + rho_grid[x-1][y][z]) / (dx**2)
                d2_rho_dx2.append(val)

            d2_rho_dy2 = []
            for z in range(z_dim):
                if y == 0:
                    val = (rho_grid[x][y+1][z] - 2*rho_grid[x][y][z] + rho_grid[x][y+1][z]) / (dy**2)
                elif y == y_dim - 1:
                    val = (rho_grid[x][y][z] - 2*rho_grid[x][y][z] + rho_grid[x][y-1][z]) / (dy**2)
                else:
                    val = (rho_grid[x][y+1][z] - 2*rho_grid[x][y][z] + rho_grid[x][y-1][z]) / (dy**2)
                d2_rho_dy2.append(val)

            dn_dx = []
            for z in range(z_dim):
                if x == 0:
                    val = (n_grid[x+1][y][z] - n_grid[x][y][z]) / dx
                elif x == x_dim - 1:
                    val = (n_grid[x][y][z] - n_grid[x-1][y][z]) / dx
                else:
                    val = (n_grid[x+1][y][z] - n_grid[x-1][y][z]) / (2*dx)
                dn_dx.append(val)

            dn_dy = []
            for z in range(z_dim):
                if y == 0:
                    val = (n_grid[x][y+1][z] - n_grid[x][y][z]) / dy
                elif y == y_dim - 1:
                    val = (n_grid[x][y][z] - n_grid[x][y-1][z]) / dy
                else:
                    val = (n_grid[x][y+1][z] - n_grid[x][y-1][z]) / (2*dy)
                dn_dy.append(val)

            if mode == 'shadowgraph':
                integrand = [d2_rho_dx2[z] + d2_rho_dy2[z] for z in range(z_dim)]
                # Source mentions trapezoidal rule, but discrete formula (Eq 2.1) uses a simple sum.
                # Implementing simple Riemann sum as per Eq 2.1/2.9 [S1, unofficial]
                integral_value = sum(integrand) * dz
                intensity_map[x][y] = integral_value
                
            elif mode == 'schlieren':
                integrand = dn_dy if use_horizontal else dn_dx
                integral_value = sum(integrand) * dz
                intensity_map[x][y] = integral_value
                
            elif mode == 'interferometry':
                rho_sum = sum(rho_grid[x][y][z] for z in range(z_dim)) * dz
                rho0 = (n0 - 1.0) / K
                F = (2.0 * xi_x * K / (lambda_val * rho0)) * rho_sum
                intensity_map[x][y] = math.cos(math.pi * F) ** 2
                
    return intensity_map
```

**Edge Cases and Pitfalls:**
*   **Zero Angle Difference ($\xi = 0$):** If $\xi = 0$, the beams reach the photo plane with the same phase, resulting in no reference fringes (infinite-fringe mode) [S1, unofficial].
*   **Non-Zero Angle Difference ($\xi \neq 0$):** If $\xi > 0$ or $\xi < 0$, recombined beams interfere and produce reference fringes (finite-fringe mode) [S1, unofficial].
*   **Fringe Orientation:** The reference fringes in the standard equations are vertical [S1, unofficial]. To obtain horizontal reference fringes, replace $2\xi_x$ with $2\xi_y$ in the interferometry equations [S1, unofficial].
*   **Mixture Constants:** The Gladstone-Dale constant $K$ for gas mixtures is defined in the source with garbled text (Eq 2.8) [S1, unofficial]. Implementers should verify the exact mixing rule from primary physics literature if high accuracy is required, as the source text "A i P (2.8)" is unclear [S1, unofficial].

## Operating characteristics
*   **Time Complexity:** Not given in the sources.
*   **Memory Complexity:** Not given in the sources.
*   **Strengths:** Provides a direct mapping from CFD density fields to optical diagnostic images [S1, unofficial].
*   **Limitations:** Assumes straight-line light paths and refractive effects only [G]. Accuracy depends on grid resolution and derivative approximation [G].
*   **When to use:** When visualizing flow fields using optical diagnostic techniques where density gradients are the primary observable [G].
*   **When not to use:** For scenes with significant absorption, emission, or scattering [G]. For time-of-flight or phase-based depth sensing [G].
