# Transparency and Opacity

Also called: Opacity Calculation

## Overview
Transparency and Opacity quantify the attenuation of light as it travels through a participating medium, determining how much incident radiance is preserved versus blocked by absorption [S1, unofficial]. This method isolates energy loss from redirection, serving as the foundational attenuation model for volume rendering before compositing with emission or scattering [S1, unofficial].

## How it works
**Inputs and Outputs:**
*   **Input:** Extinction coefficient $\kappa(x, \omega)$ (units: inverse length), ray origin $x$, ray direction $\omega$, and integration distance $s$ [S1, unofficial].
*   **Output:** Transparency $T(s)$ and Opacity $O(s)$ [S1, unofficial].

**Data Structures:**
*   **Extinction Coefficient Field:** A spatial field storing $\kappa$ [G]. In general volume rendering, this is a 3D texture or grid [G].

**Steps:**
1.  Sample the extinction coefficient $\kappa$ along the ray path from $x$ to $x + s\omega$ [S1, unofficial].
2.  Compute the optical depth $\tau(s)$ by integrating $\kappa$ over the path length [S1, unofficial].
3.  Compute transparency $T(s)$ using the exponential decay of $\tau(s)$ [S1, unofficial].
4.  Compute opacity $O(s)$ as the complement of transparency [S1, unofficial].

**Formulas:**
The optical depth $\tau(s)$ is the integral of the extinction coefficient along the ray:
$$ \tau(s) = \int_0^s \kappa(x + t\omega, \omega) dt $$
[S1, unofficial]

If $\kappa$ is constant, $\tau(s) = \kappa s$ [S1, unofficial].

Transparency $T(s)$ is defined as:
$$ T(s) = e^{-\tau(s)} = e^{-\int_0^s \kappa(x + t\omega) dt} $$
[S1, unofficial]

Opacity $O(s)$ is defined as:
$$ O(s) = 1 - T(s) $$
[S1, unofficial]

**Parameters:**
*   **Extinction Coefficient ($\kappa$):** Defines the probability of photon absorption per unit length [S1, unofficial].
*   **Integration Distance ($s$):** The path length along the ray over which attenuation is computed [S1, unofficial].

**Edge Cases and Pitfalls:**
*   **Singularity at Zero Absorption:** Pure transparency $T(s) = e^{-\kappa s}$ remains $1.0$ at $\kappa=0$, which is numerically stable [S1, unofficial].
*   **Precision:** For large optical depths, $T(s)$ underflows to $0$, which is physically correct [G].
*   **Boundary Artifacts:** In fuzzy surface rendering, lack of transparency attenuation can cause visual artifacts at object boundaries [S3].

**Pseudocode:**
The following Python-like pseudocode computes transparency and opacity for a constant extinction coefficient, directly implementing the closed-form solution:

```python
import math

def compute_transparency_opacity(kappa, s):
    """
    Compute transparency and opacity for a constant extinction coefficient.
    
    Args:
        kappa (float): Extinction coefficient (inverse length).
        s (float): Distance along the ray.
        
    Returns:
        tuple: (transparency, opacity)
    """
    tau = kappa * s
    transparency = math.exp(-tau)
    opacity = 1.0 - transparency
    return transparency, opacity
```

## Subtopics

### Transparency Attenuation
A technique introduced to reduce visual artifacts at object boundaries [S3]. Using transparency-decay resulted in a 2.13 dB PSNR gain on the Shelly scene compared to not using it [S3].

### Constant Intensity Model
A specific formulation for intensity $I(s)$ along a ray with constant absorption coefficient $\sigma$ and emission $q$ [S4, unofficial]. If $|\sigma| < 10^{-10}$, $I(s) = I_0 + q \cdot s$ [S4, unofficial]. Otherwise, $I(s) = I_0 \cdot \exp(-\sigma s) + (q / \sigma) \cdot (-\text{expm1}(-\sigma s))$ [S4, unofficial].

### Fire Opacity Texture Mode
A set of modes in Phoenix for Maya determining how fire opacity is calculated [S5].
*   **Use Smoke Opacity:** Fire uses smoke's opacity; invisible where smoke is absent [S5].
*   **Fully Visible:** Fire renders with full opacity but produces no alpha; visible even in cells with no opacity [S5].
*   **Use Own Opacity:** Custom varying opacity via diagram/texture [S5].
    *   **Don't Use Opacity Texture:** Based entirely on Color and Opacity Curve [S5].
    *   **Multiply Opacity By Texture:** Curve multiplied by texture [S5].
    *   **Fire Opacity From Texture:** Based entirely on texture; curve ignored [S5].
*   **Parameter:** `emAlphaTexture` specifies the texture for Multiply or From Texture modes [S5].

### Smoke Opacity Calculation
Scaled opacity $\alpha$ (0 to 255) is calculated as $\alpha = 255 \exp(-K S \Delta x)$, where $K$ is mass extinction coefficient, $S$ is smoke density, and $\Delta x$ is path length [S6, unofficial]. Path length from grey level is $\Delta x = -\frac{\ln(\alpha/255)}{KS}$ [S6, unofficial]. Parameters: soot density $S = 79.67$ mg/m³, $K = 8700$ m² [S6, unofficial]. For $\alpha$ of 192, 128, 64, 32, 16, and 8, $\Delta x$ are 0.41 m, 1.0 m, 2.0 m, 3.0 m, 4.0 m, and 5.0 m respectively [S6, unofficial]. Better results are achieved with a refined grid (0.1 m vs 0.2 m) and all planes (no skipping) [S6, unofficial].

### Image Transparency Calculation
Computes per-pixel transparency for image displays rendered as stacks of planes, based on histogram position and slab thickness [S7]. Histogram transparency is $T_{\text{histogram}} = 1 - \text{vertical position}$ [S7]. Per-pixel transparency for a slab with $p$ planes is $T_{\text{pixel}} = T_{\text{histogram}}(1/p)$ [S7]. Parameter `transparency` sets slab thickness as a fraction of dataset thickness along its shortest dimension, matching $T_{\text{histogram}}$ [S7].

## Operating characteristics
*   **Time Complexity:** Not given in the sources.
*   **Memory Complexity:** Not given in the sources.
*   **Strengths:** Simple, physically grounded model for absorption-only media [S1, unofficial].
*   **Limitations:** Does not account for scattering [G]. In fire rendering, mode selection impacts compositing correctness [S5].
*   **When to use:** When absorption is the dominant light transport mechanism or when modeling non-scattering media like fog, smoke, or X-rays [S1, unofficial].
*   **When not to use:** When scattering is significant and must be modeled explicitly [G].

## Background
The concepts of transparency and opacity are fundamental to the absorption-only model in volume rendering [S1, unofficial]. The differential form of the light transport equation for absorption is $dL/ds = -\kappa L$, leading to the exponential decay solution [S1, unofficial]. Transparency attenuation was introduced for fuzzy geometries to improve boundary rendering [S3]. The Constant Intensity Model formula is documented in HPC demonstration contexts [S4, unofficial]. Fire opacity modes are specific to Phoenix for Maya simulations [S5]. Smoke opacity calculation is verified in Fire Dynamics Simulation visualization tools [S6, unofficial]. Image transparency calculation is implemented in UCSF ChimeraX volume rendering commands [S7].
