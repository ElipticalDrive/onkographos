# Absorption-only model

Also called: Absorption Model, Absorption-only homogeneous volume rendering, Attenuation model, Cold black particle model, Pure absorption, Single monochromatic absorption-only homogeneous volume, X-ray model

## Overview

The absorption-only model is a simplified volumetric light transport method that accounts exclusively for the attenuation of light as it passes through a participating medium, ignoring both emission from the volume and scattering [S1][S2, book][S3, unofficial]. It solves the problem of rendering a scene where the volume acts as a "cold black" occluder, similar to black smoke or X-ray attenuation, by computing the radiance reaching the camera from emissive surfaces after it has been exponentially decayed by the medium's density [S1][S4, unofficial]. Unlike the [Emission-Absorption Model](927-emission-absorption-model.md), which adds light generated within the volume, this model assumes the volume itself contributes no radiance, making it computationally cheaper but visually limited to opacity-based visualization [S2, book][S4, unofficial].

## How it works

### Inputs and Outputs
*   **Inputs**:
    *   Camera geometry and screen position.
    *   Scene definition containing emissive surfaces (with radiance $L_e$) and a single homogeneous volume.
    *   Volume absorption coefficient $\sigma_a$ (constant in space).
    *   Particle density $\rho$ and projected area $A$ (if deriving $\sigma_a$ microscopically).
    *   Random number generator state (for sampling).
*   **Outputs**:
    *   Radiance $L$ for each pixel.

### Data Structures
*   **Ray**: Defined by origin $\mathbf{p}(0)$ and direction $\omega$.
*   **Intersection**: Contains distance $t_{\text{hit}}$ to the surface and surface radiance $L_e$.
*   **Volume Properties**:
    *   $\sigma_a$: Absorption coefficient (units: $1/\text{length}$).
    *   $\tau(s)$: Extinction coefficient at distance $s$. In the homogeneous case, $\tau(s) = \sigma_a$.

### Formulas
The radiative transfer equation simplifies to an ordinary differential equation describing intensity decay:
$$ \frac{d}{dt} L_1(\mathbf{p}(t), \omega) = -\sigma_a L_1(\mathbf{p}(t), \omega) \quad [S1] $$
Alternatively, using particle density $\rho(s)$ and projected area $A$:
$$ \frac{dI}{ds} = -\rho(s) A I(s) = -\tau(s) I(s) \quad [S2, book][S3, S4, unofficial] $$
where $\tau(s) = \rho(s)A$ is the extinction coefficient [S3, unofficial].

The closed-form solution for the radiance $L$ observed at the camera (ray origin) from a surface hit at distance $t_{\text{hit}}$ is:
$$ L = \exp(-\sigma_a t_{\text{hit}}) L_e \quad [S1] $$
Or generally, for intensity $I(s)$ at distance $s$ from an initial intensity $I_0$:
$$ I(s) = I_0 \exp\left(-\int_0^s \tau(t) dt\right) \quad [S2, book][S3, S4, unofficial] $$
The term $T(s) = \exp\left(-\int_0^s \tau(t) dt\right)$ is the transparency of the medium between 0 and $s$ [S3, S4, unofficial].

### Parameters
*   $\sigma_a$: Absorption coefficient. Assumed constant (homogeneous) in the basic implementation [S1].
*   $\sigma_s$: Scattering coefficient. Set to 0 [S1].
*   Ray Differentials: Disabled (set to 0) in standard implementations to avoid complexity [S1].
*   Environment Maps: Assumed absent [S1].

### Pseudocode
The following algorithm computes the radiance for a single pixel. It assumes a scene with emissive surfaces and a single homogeneous absorbing volume.

```python
def render_absorption_only(screen_pos, rng, camera, scene, sigma_a):
    """
    Renders a single pixel using the absorption-only model.
    
    Args:
        screen_pos: 2D coordinates of the pixel.
        rng: Random number generator.
        camera: Camera object with sample_primary method.
        scene: Scene object with intersect method.
        sigma_a: Homogeneous absorption coefficient.
        
    Returns:
        Radiance L at the camera.
    """
    # 1. Sample the primary camera ray
    camera_ray = sample_primary(camera, screen_pos, rng)
    
    # 2. Intersect the ray with the scene geometry
    isect = intersect(scene, camera_ray)
    
    # 3. If an intersection exists, calculate attenuated radiance
    if isect is not None:
        # Distance to the hit point
        t = isect.distance
        
        # Calculate transmittance through the homogeneous volume
        # T = exp(-sigma_a * t)
        transmittance = exp(-sigma_a * t)
        
        # Get surface emission radiance
        Le = 0.0
        if is_light_source(isect):
            Le = isect.emission_radiance
            
        # Return attenuated radiance
        return transmittance * Le
        
    # 4. If no intersection, return black (0 radiance)
    return 0.0
```

### Edge Cases and Pitfalls
*   **Extinction vs. Voxel Opacity**: Do not confuse the extinction coefficient $\tau$ with voxel opacity $\alpha$. $\alpha$ depends on the path length through the voxel, which varies if the voxel is scaled or viewed diagonally. $\tau$ is a local property (differential opacity per unit length) [S3, unofficial].
*   **Homogeneity Assumption**: The simple closed-form solution $L = e^{-\sigma_a t} L_e$ relies on $\sigma_a$ being constant. If $\sigma_a$ varies spatially, the integral $\int_0^s \tau(t) dt$ must be evaluated numerically along the ray [S3, S4, unofficial].
*   **Monochromatic vs. Color**: The model is often described as monochromatic (single $\sigma_a$ for all channels), but $\sigma_a$ can be a vector (RGB) to simulate colored absorption, while the surface $L_e$ provides color [S1].

### Subtopics
*   **X-ray Model**: A specific application where the volume represents dense tissue blocking X-rays. The "light source" is the X-ray source, and the volume attenuates the flux reaching the film [S2, book][S4, unofficial].
*   **Black Smoke Model**: A visual application where the volume is a cloud of non-emitting, non-scattering particles obscuring the background [S2, book][S4, unofficial].

## Operating characteristics

*   **Time Complexity**: $O(1)$ per pixel for homogeneous volumes, as it requires only a single ray intersection and one exponential evaluation. For inhomogeneous volumes, complexity depends on the number of samples required to integrate $\tau(s)$ along the ray.
*   **Memory Complexity**: $O(1)$ auxiliary memory, plus storage for the scene geometry and volume density field (if inhomogeneous).
*   **Strengths**: Extremely fast; simple to implement; effective for visualizing density distributions (e.g., bone in X-rays) or occlusion [S2, book][S4, unofficial].
*   **Limitations**: Cannot render volumetric effects like fog glow, subsurface scattering, or light shafts; surfaces do not reflect light, only emit [S1][S2, book].
*   **When to use**: When performance is critical and only opacity/density visualization is needed; for X-ray simulation; for simple occlusion clouds [S2, book][S4, unofficial].
*   **When not to use**: When realistic lighting, shadows, or volumetric illumination effects are required [S1].

## Background

The absorption-only model is the simplest participating medium model, originating from early work in direct volume rendering and neutron transport [S2, book][S4, unofficial]. It was formalized in the context of optical models for direct volume rendering by Max [S3, unofficial] and Blinn [S2, book], who described the "cold black particle" model. The mathematical formulation is analogous to the Beer-Lambert law in physics and neutron absorption cross-sections in transport theory [S4, unofficial]. It serves as the foundational case for more complex models like the [Emission-Absorption Model](927-emission-absorption-model.md) and scattering models [S1].
