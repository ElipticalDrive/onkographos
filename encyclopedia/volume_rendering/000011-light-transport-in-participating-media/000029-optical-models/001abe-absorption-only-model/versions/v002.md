# Absorption-only model

Also called: Absorption Model, Absorption-only homogeneous volume rendering, Attenuation model, Cold black particle model, Pure absorption, Single monochromatic absorption-only homogeneous volume, X-ray model

## Overview

The absorption-only model is the simplest participating medium model, accounting exclusively for the attenuation of light as it passes through a volume while ignoring emission from the medium and scattering [S2, book][S3, unofficial]. It computes the radiance reaching the camera from emissive surfaces after exponential decay by the medium's density, effectively simulating a cloud of black smoke or X-ray attenuation [S1][S4, unofficial]. Unlike the [Emission-Absorption Model](927-emission-absorption-model.md), which adds light generated within the volume, this model assumes the volume contributes no radiance and surfaces only emit light without reflecting or transmitting it [S1][S2, book].

## How it works

### Inputs and Outputs
*   **Inputs**: Camera geometry and screen position [S1]. Random number generator state for sampling [S1]. Scene definition containing emissive surfaces [S1]. Homogeneous volume absorption coefficient $\sigma_a$ [S1]. Particle density $\rho$ and projected area $A$ for microscopic derivation of $\sigma_a$ [S3, unofficial].
*   **Outputs**: Radiance $L$ for each pixel [S1].

### Data Structures
*   **Ray**: Defined by origin $\mathbf{p}(0)$ and direction $\omega$ [S1].
*   **Intersection**: Contains distance $t_{\text{hit}}$ to the surface and surface emission radiance $L_e$ [S1].
*   **Volume Properties**: $\sigma_a$ (units: $1/\text{length}$) [S1]. $\tau(s)$ extinction coefficient at distance $s$ [S3, unofficial].

### Formulas
The radiative transfer equation simplifies to an ordinary differential equation describing intensity decay:
$$ \frac{d}{dt} L_1(\mathbf{p}(t), \omega) = -\sigma_a L_1(\mathbf{p}(t), \omega) \quad [S1] $$
Alternatively, using particle density $\rho(s)$ and projected area $A$:
$$ \frac{dI}{ds} = -\rho(s) A I(s) = -\tau(s) I(s) \quad [S2, book][S3, S4, unofficial] $$
where $\tau(s) = \rho(s)A$ is the extinction coefficient [S3, unofficial].

The closed-form solution for the radiance $L$ observed at the camera (ray origin) from a surface hit at distance $t_{\text{hit}}$ is:
$$ L = \exp(-\sigma_a t_{\text{hit}}) L_e \quad [S1] $$
Or generally, for intensity $I(s)$ at distance $s$ from an initial intensity $I_0$:
$$ I(s) = I_0 \exp\left(-\int_0^s \tau(t) dt\right) \quad [S2, book][S3, S4, unofficial] $$
The term $T(s) = \exp\left(-\int_0^s \tau(t) dt\right)$ is the transparency of the medium between $0$ and $s$ [S3, S4, unofficial].

### Parameters
*   $\sigma_a$: Absorption coefficient. Assumed constant (homogeneous) in the basic implementation [S1].
*   $\sigma_s$: Scattering coefficient. Set to $0$ [S1].
*   Ray Differentials: Disabled (set to $0$) in standard implementations to avoid complexity [S1].
*   Environment Maps: Assumed absent [S1].

### Pseudocode
The following algorithm computes the radiance for a single pixel. It assumes a scene with emissive surfaces and a single homogeneous absorbing volume.

```python
def render_absorption_only(screen_pos, rng, camera, scene, sigma_a):
    # 1. Sample primary camera ray for the screen position
    camera_ray = sample_primary(camera, screen_pos, rng)
    
    # 2. Intersect the ray with the scene geometry
    isect = intersect(scene, camera_ray)
    
    # 3. If an intersection exists, calculate attenuated radiance
    if isect is not None:
        t = isect.distance  # Distance to the hit point
        transmittance = exp(-sigma_a * t)  # Homogeneous transmittance
        Le = 0.0
        if is_light_source(isect):  # Check if hit surface is emissive
            Le = isect.emission_radiance
        return transmittance * Le
        
    # 4. If no intersection, return zero radiance
    return 0.0

# Helper definitions for self-containment
def sample_primary(camera, screen_pos, rng):
    # [G] Generates a ray from camera origin through screen_pos using rng for jitter
    return Ray(origin=camera.origin, direction=camera.direction(screen_pos, rng))

def intersect(scene, ray):
    # [G] Returns intersection object with .distance and .emission_radiance, or None
    closest = None
    for prim in scene.primitives:
        hit = prim.intersect(ray)
        if hit and (closest is None or hit.distance < closest.distance):
            closest = hit
    return closest

def is_light_source(isect):
    # [G] Returns True if the hit primitive has non-zero emission radiance
    return isect.emission_radiance > 0.0
```

### Edge Cases and Pitfalls
*   **Extinction vs. Voxel Opacity**: Do not confuse the extinction coefficient $\tau$ with voxel opacity $\alpha$. $\alpha$ depends on the path length through the voxel, which varies if the voxel is scaled or viewed diagonally [S3, unofficial].
*   **Homogeneity Assumption**: The simple closed-form solution $L = e^{-\sigma_a t} L_e$ relies on $\sigma_a$ being constant [S1].
*   **Spatial Variation**: For spatially varying density, the integral $\int_0^s \tau(t) dt$ must be evaluated continuously along the viewing ray [S3, unofficial].
*   **Monochromatic Assumption**: The basic model assumes a single $\sigma_a$ for all color channels, though $L_e$ can still be colored [S1].

### Subtopics
*   **X-ray Model**: A specific application where the volume represents dense tissue blocking X-rays. The "light source" is the X-ray source, and the volume attenuates the flux reaching the film [S2, book][S4, unofficial].
*   **Black Smoke Model**: A visual application where the volume is a cloud of non-emitting, non-scattering particles obscuring the background [S2, book][S4, unofficial].

## Operating characteristics
*   **Time Complexity**: Not given in the sources.
*   **Memory Complexity**: Not given in the sources.
*   **Strengths**: Effective for visualizing density distributions (e.g., bone in X-rays) or occlusion [S2, book][S4, unofficial].
*   **Limitations**: Cannot render volumetric effects like fog glow or subsurface scattering; surfaces do not reflect light, only emit [S1][S2, book].
*   **Compositing**: The compositing equation is commutative, allowing regions to be combined in any order [S2, book].
*   **When to use**: X-ray simulation, simple occlusion clouds, density distribution visualization [S2, book][S4, unofficial].
*   **When not to use**: Realistic lighting, shadows, or volumetric illumination effects are required [S1].

## Background
The absorption-only model is the simplest participating medium model, originating from early work in direct volume rendering and neutron transport [S2, book][S4, unofficial]. It was formalized in the context of optical models for direct volume rendering by Max [S3, unofficial] and Blinn [S2, book], who described the "cold black particle" model. The mathematical formulation is analogous to the Beer-Lambert law in physics and neutron absorption cross-sections in transport theory [S4, unofficial]. It serves as the foundational case for more complex models like the [Emission-Absorption Model](927-emission-absorption-model.md) and scattering models [S1].
