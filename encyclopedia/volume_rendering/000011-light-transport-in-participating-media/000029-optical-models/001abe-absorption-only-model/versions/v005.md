# Absorption-only model

Also called: Pure absorption, Absorption Model, Absorption-only Volume Rendering

## Overview
The absorption-only model renders a participating medium composed of cold, perfectly black particles that absorb all intercepted light without scattering or emitting [S1, unofficial][S4, book]. It solves for light intensity attenuation along a ray, producing an X-ray-like projection or a "black smoke" obscuring effect [S4, book][S7, unofficial]. Unlike the emission-absorption model, it ignores in-scattering and self-illumination, making it computationally simpler but physically limited to non-luminous, non-scattering media [S3][S4, book].

## How it works
**Inputs and Outputs**
*   **Input:** A scalar field $f(\mathbf{x})$ representing density or material properties; a transfer function mapping $f$ to the extinction coefficient $\tau$; a background radiance $L_{bg}$ (or source intensity $I_0$); and camera rays.
*   **Output:** The final radiance $L_o$ for each pixel, representing the background light attenuated by the medium.

**Data Structures**
*   **Scalar Field:** A 3D grid of values $f_{ijk}$.
*   **Transfer Function:** A mapping $\tau = T(f)$. Common implementations include:
    *   Thresholded: $\tau = \infty$ if $f > K$, else $\tau = 0$ [S1, unofficial][S6].
    *   Linear: $\tau = c \cdot f$ [S7, unofficial].
    *   Continuous interpolation: Trilinear or tricubic interpolation of $f$ to estimate $\tau$ at arbitrary ray positions [S1, unofficial].

**Mathematical Formulation**
The change in radiance $L$ over a differential path length $dt$ is governed by the absorption coefficient $\sigma_a$ (equivalent to the extinction coefficient $\tau$ in the absence of scattering) [S2, unofficial][S5, unofficial]:
$$ \frac{dL}{dt} = -\sigma_a L $$
where $\sigma_a$ has units of $m^{-1}$ [S2, unofficial].

The solution for radiance at distance $s$ along a ray starting at $s=0$ with initial radiance $L_0$ is:
$$ L(s) = L_0 \exp\left(-\int_0^s \sigma_a(t) \, dt\right) $$
The term $T(s) = \exp\left(-\int_0^s \sigma_a(t) \, dt\right)$ is the **transmittance** (or transparency) of the medium [S1, unofficial][S5, unofficial].

The **opacity** $\alpha$ of a segment of length $l$ is defined as:
$$ \alpha = 1 - T(l) = 1 - \exp\left(-\int_0^l \sigma_a(t) \, dt\right) $$
If $\sigma_a$ is constant, $\alpha = 1 - e^{-\sigma_a l}$ [S1, unofficial][S6].

**Algorithm Steps**
1.  **Ray Generation:** For each pixel, generate a primary camera ray $\mathbf{r}(t) = \mathbf{o} + t\mathbf{d}$.
2.  **Intersection:** Determine the entry and exit points of the ray with the volume bounding box. If the ray misses the volume, return the background color.
3.  **Integration:**
    *   *Discrete (Ray Marching):* Divide the path inside the volume into $N$ steps of size $\Delta t$.
    *   For each step $i$ from $0$ to $N-1$:
        *   Sample the scalar field $f$ at the current ray position $\mathbf{r}(t_i)$.
        *   Compute the extinction coefficient $\sigma_a = T(f)$ using the transfer function.
        *   Compute the step transmittance: $T_{step} = \exp(-\sigma_a \Delta t)$.
        *   Update accumulated transmittance: $T_{acc} = T_{acc} \times T_{step}$.
        *   Advance ray position: $t_{i+1} = t_i + \Delta t$.
    *   *Continuous (Analytical/Fast):* If the volume is homogeneous or simple, compute the integral $\int \sigma_a dt$ analytically. For large datasets, Fourier methods (Projection Slice Theorem) can compute the integral rapidly [S1, unofficial].
4.  **Compositing:**
    *   The final radiance is the background radiance attenuated by the total transmittance:
        $$ L_{final} = L_{bg} \times T_{total} $$
    *   If the volume is treated as a stack of opaque slices (thresholded model), use a back-to-front painter's algorithm or z-buffer to project front faces, shading based on depth [S1, unofficial].

**Pseudocode**
```python
def render_absorption_only(ray_origin, ray_direction, volume_grid, transfer_function, background_radiance):
    """
    Renders a single ray using the absorption-only model.
    
    Args:
        ray_origin: vec3, origin of the camera ray.
        ray_direction: vec3, normalized direction of the camera ray.
        volume_grid: 3D array, scalar field values.
        transfer_function: function, maps scalar value to extinction coefficient sigma_a.
        background_radiance: float or vec3, radiance behind the volume.
        
    Returns:
        float or vec3, final radiance for the pixel.
    """
    # 1. Intersect ray with volume bounding box
    t_min, t_max = intersect_bounding_box(ray_origin, ray_direction, volume_bounds)
    
    # If ray misses volume, return background
    if t_max < t_min:
        return background_radiance

    # 2. Initialize accumulation
    # T_acc stores the total transmittance from the entry point to the current step
    T_acc = 1.0
    
    # Step size for ray marching
    delta_t = 0.1 # Not given in sources; typical value depends on resolution
    
    # 3. March along the ray from entry to exit
    t = t_min
    while t < t_max:
        # Sample scalar field at current position
        # [G] Implementation detail: Interpolate volume_grid at (ray_origin + t * ray_direction)
        scalar_value = sample_scalar_field(volume_grid, ray_origin + t * ray_direction)
        
        # Map scalar to extinction coefficient (sigma_a)
        sigma_a = transfer_function(scalar_value)
        
        # Compute transmittance for this step
        # T_step = exp(-sigma_a * delta_t)
        # [G] Guard against NaN if sigma_a is infinite (opaque threshold)
        if sigma_a == float('inf'):
            return 0.0 # Completely opaque, no light passes
            
        T_step = exp(-sigma_a * delta_t)
        
        # Update accumulated transmittance
        T_acc = T_acc * T_step
        
        # Advance ray
        t += delta_t
        
        # Optimization: If T_acc is very small, break early
        if T_acc < 1e-6:
            break

    # 4. Final Compositing
    # The light reaching the camera is the background light attenuated by the total transmittance
    final_radiance = background_radiance * T_acc
    
    return final_radiance
```

**Parameters**
*   **Extinction Coefficient ($\sigma_a$ or $\tau$):** Defined as $\rho A$, where $\rho$ is particle number density and $A$ is the projected cross-sectional area of a particle ($\pi r^2$ for spheres) [S1, unofficial][S5, unofficial]. Units: $m^{-1}$ [S2, unofficial].
*   **Transfer Function:** Maps scalar density $f$ to $\sigma_a$. Can be a simple threshold ($K$) or a continuous function [S1, unofficial].
*   **Step Size ($\Delta t$):** Determines sampling density. Smaller steps increase accuracy but cost more [S3].

**Edge Cases and Pitfalls**
*   **Opacity vs. Extinction:** Do not confuse the extinction coefficient $\tau$ (per unit length) with voxel opacity $\alpha$ (dimensionless). $\alpha$ depends on the path length through the voxel. If a voxel is viewed diagonally or scaled, the path length changes, making $\alpha = 1 - e^{-\tau l}$ invalid if $\tau$ is treated as constant opacity [S1, unofficial][S6].
*   **Thresholding:** For thresholded opaque volumes, interior voxels hidden by front faces can be skipped using a z-buffer or painter's algorithm [S1, unofficial].
*   **Precision:** The exponential function can be computed once per pixel via a gamma correction table lookup if the integral is precomputed [S1, unofficial].

## Subtopics

### [X-ray simulation via ray integration](1445-x-ray-simulation-via-ray-integration.md)
Generates a simulated radiograph (DR) by integrating attenuation along viewing rays through a volume, using Hounsfield Unit values. Produces a single-energy, projection-style image without scatter.

### [Prism Model](3153-prism-model.md)
A surface-based model that approximates absorption on triangle meshes by assigning depth based on orientation. Solves the problem of rendering volumetric absorption on dynamic meshes without voxelization.

## Operating characteristics
*   **Time Complexity:** $O(N \cdot M)$, where $N$ is the number of pixels and $M$ is the number of samples per ray. Can be reduced to $O(N)$ using Fourier methods (Projection Slice Theorem) for homogeneous or simple volumes [S1, unofficial].
*   **Memory Complexity:** $O(V)$ for storing the volume grid, where $V$ is the number of voxels.
*   **Strengths:** Computationally efficient; simple to implement; effective for visualizing density distributions (e.g., bone in medical imaging, black smoke) [S4, book][S7, unofficial].
*   **Limitations:** Cannot render self-illumination (emission) or scattering effects (glow, shadows cast by the volume); assumes particles are "black" (no color scattering) [S1, unofficial][S4, book].
*   **When to use:** X-ray simulation, visualization of dense structures (bones), simple smoke/fog effects where scattering is negligible [S4, book][S7, unofficial].
*   **When not to use:** Realistic fire, clouds with sunsets, translucent materials, or any scenario requiring in-scattering or emission [S4, book].

## Background
The absorption-only model is the simplest participating medium model, derived from the conservation of energy for a differential cylinder of light [S1, unofficial]. It was formalized in the context of direct volume rendering by Max [S1, unofficial][S5, unofficial] and is analogous to neutron transport absorption models [S7, unofficial]. Early medical visualizations used thresholded absorption to visualize bone [S1, unofficial]. The model assumes cold, perfectly black particles that absorb all intercepted light [S1, unofficial].
