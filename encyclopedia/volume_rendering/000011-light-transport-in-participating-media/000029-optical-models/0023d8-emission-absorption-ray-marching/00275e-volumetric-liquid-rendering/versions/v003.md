# Volumetric Liquid Rendering


## Overview
Volumetric Liquid Rendering is a specific application of emission-absorption ray marching used to render liquid volumes, such as the wax in a lava lamp, illuminated from below [S1, unofficial]. It differs from general volume rendering by masking the liquid visibility with the depth of an occluding surface (wax) and driving emission based on proximity to a light source [S1, unofficial]. It builds on [Emission-Absorption Ray Marching](3171-emission-absorption-ray-marching.md) [G].

## How it works
**Inputs and Outputs:**
- Input: Ray origin and direction, wax depth buffer, liquid volume density field, light position (below), material parameters (absorption coefficient, emission intensity), liquid bounds, pixel UV coordinates, and background color [S1, unofficial][G].
- Output: Color and opacity of the liquid along the ray [G].

**Data Structures:**
- Depth Buffer: 2D texture storing the depth of the wax surface [S1, unofficial][G].
- Liquid Volume: Implicit or explicit density field [G].

**Steps:**
1. **Ray Casting:** Cast a ray from the camera through the pixel [G].
2. **Wax Masking:** Intersect the ray with the wax surface using the depth buffer [S1, unofficial]. If the ray does not intersect the wax, or if the intersection is behind the liquid volume, the liquid is not visible [S1, unofficial].
3. **Liquid Marching:** For the segment of the ray inside the liquid volume: sample the liquid density, accumulate absorption using the Beer-Lambert law, and accumulate emission driven by proximity to the light source below [S1, unofficial][G].
4. **Compositing:** Combine the accumulated transmission and emission with the background color [G].

**Formulas:**
- Transmission: $T = \exp(-\sigma_a \cdot \Delta l)$ [G]
- Emission: $E = \sigma_e \cdot \Delta l \cdot f_{\text{light}}$ [G]
- Final Color: $C_{\text{out}} = C_{\text{in}} \cdot T + E$ [G]

**Parameters:**
- Absorption coefficient: Not given in the sources. [G]
- Emission intensity: Proportional to proximity to the light source [S1, unofficial].
- Ray step size: Not given in the sources. [G]

**Edge Cases:**
- Precision issues may arise if the liquid volume is thin or the step size is too large [G].

**Pseudocode:**
```python
def render_liquid(ray_origin, ray_direction, wax_depth_buffer, liquid_bounds, light_position, sigma_a, sigma_e, step_size, uv, background_color):
    # Step 1: Intersect ray with wax depth buffer
    z_wax = wax_depth_buffer[uv]
    if abs(ray_direction.z) < 1e-6:
        return background_color
    t_wax = (z_wax - ray_origin.z) / ray_direction.z
    if t_wax < 0:
        return background_color

    # Step 2: Clip to liquid volume bounds
    t_start = max(0.0, (liquid_bounds.min_z - ray_origin.z) / ray_direction.z)
    t_end = min(t_wax, (liquid_bounds.max_z - ray_origin.z) / ray_direction.z)
    if t_start >= t_end:
        return background_color

    # Step 3: Ray march through liquid
    accum_transmission = 1.0
    accum_emission = vec3(0.0)
    t = t_start

    while t < t_end:
        pos = ray_origin + ray_direction * t
        density = sample_volume(pos) # [G] standard 3D volume texture lookup
        delta_l = step_size

        trans = exp(-sigma_a * density * delta_l)
        dist_to_light = length(pos - light_position)
        light_factor = 1.0 / (1.0 + dist_to_light)
        emiss = sigma_e * light_factor * delta_l

        accum_emission += accum_transmission * emiss
        accum_transmission *= trans
        t += step_size

    # Step 4: Composite
    return background_color * accum_transmission + accum_emission
```

## Subtopics

### Height Field Ray-Casting
A ray-casting method based on a height field (2D grid containing elevation in each cell) used for real-time rendering of liquid volumes [S2, unofficial]. It allows handling of reflections, refractions, and complex effects like light absorption, refracted shadows, and caustics [S2, unofficial]. It was used by [BD06] [S2, unofficial].
