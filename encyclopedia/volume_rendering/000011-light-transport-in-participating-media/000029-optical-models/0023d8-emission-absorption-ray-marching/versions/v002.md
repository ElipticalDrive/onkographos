# Emission-Absorption Ray Marching

Also called: Absorption plus Emission Volume Rendering, Direct Volume Rendering (Emission plus Absorption), Discrete Direct Volume Rendering, EAM Render, EmissionAbsorption, General optical model, Participating medium rendering, Ray Marching with Blend Function

## Overview
Emission-Absorption Ray Marching is a deterministic integration pass that accumulates color and opacity along a viewing ray using alpha compositing to render a participating medium where particles both occlude incoming light (absorption) and add their own glow (emission) [S1, unofficial][S5]. It solves the volume rendering equation for the general optical model by discretizing the continuous integral into a Riemann sum, distinguishing itself from [Absorption-only model](839-absorption-only-model.md) by including a source term and from [Emission-only Model](1016-emission-only-model.md) by providing an upper bound on intensity via attenuation [S5].

## How it works
**Inputs and Outputs**
*   **Inputs:** Ray origin $\mathbf{o}$, ray direction $\boldsymbol{\omega}$, step size $h$ (or `step_size`), maximum steps `max_steps`, extinction coefficient $\sigma_t$ (or `uExtinction`), and a source function $g(\mathbf{p})$ (or `render_func`) that returns color/emission at position $\mathbf{p}$. Background radiance $I_0$ is also required.
*   **Outputs:** Final accumulated radiance $I(D)$ and opacity $\alpha_{total}$.

**Data Structures**
*   **Accumulator:** A vector `accumulator` of size 4 (RGBA), initialized to $(0, 0, 0, 0)$ [S1, unofficial].
*   **Transmission Array:** An array `acc_transmission` storing the cumulative product of transparencies $(1-\alpha_i)$, used for blend weight calculation [S2, unofficial].

**Formulas**
The continuous differential equation for intensity $I(s)$ along the ray parameter $s$ is [S6]:
$$ \frac{dI}{ds} = g(s) - \tau(s)I(s) $$
where $g(s)$ is the emission source term and $\tau(s)$ is the extinction coefficient (often denoted $\sigma_t$ or $\sigma_a$ in implementation contexts) [S5, S6].

The analytical solution at distance $D$ is [S6]:
$$ I(D) = I_0 e^{-\int_0^D \tau(t) dt} + \int_0^D g(s) e^{-\int_s^D \tau(t) dt} ds $$

Discretizing this into $n$ samples with step size $h$, where $\alpha_i = 1 - e^{-\tau_i h}$ is the opacity of sample $i$, the discrete implementation is [S6]:
$$ I(D) = I_0 \prod_{i=1}^n (1 - \alpha_i) + \sum_{i=1}^n g_i \prod_{j=i+1}^n (1 - \alpha_j) $$
Note: The product $\prod_{j=i+1}^n (1 - \alpha_j)$ represents the transmission of all samples *after* (closer to the viewer than) sample $i$ [S6].

**Parameters**
*   `step_size` (or $h$): The distance between samples. Default value is 0.5 [S3, unofficial].
*   `max_steps`: Maximum number of steps per ray. Default value is 2000 [S3, unofficial].
*   `uExtinction`: Extinction coefficient used in alpha accumulation. In some implementations, this is divided by 100.0 [S1, unofficial].
*   `uStepSize`: Used to calculate `rayStepLength` and initial random offset [S1, unofficial].

**Algorithm Steps**
1.  **Initialization:**
    *   Initialize `accumulator` to $(0, 0, 0, 0)$ [S1, unofficial].
    *   Calculate ray bounds and step length: `rayStepLength = distance(from, to) * uStepSize` [S1, unofficial].
    *   Initialize random start offset: $t = \text{rand}(\mathbf{p} \cdot \text{seed}).r \times \text{uStepSize} \times 1.5$, clamped to $[0, 1]$ [S1, unofficial].
    *   Initialize `acc_transmission` array.

2.  **Ray Marching Loop:**
    *   While $t < 1.0$ and `accumulator.a` < 0.99 (or 0.98/0.9 depending on implementation):
        *   Sample position $\mathbf{p}$ along the ray at offset $t$ [S1, unofficial].
        *   Compute local properties: value, gradient, normal, half vector, LAO, and Shadows [S1, unofficial].
        *   Compute extinction $\tau$ and emission $g$ (or color) at $\mathbf{p}$ [S2, unofficial].
        *   Compute opacity: $\alpha = 1 - e^{-\sigma \times \text{ray\_dist}}$ [S2, unofficial].
        *   **Update Accumulator (Front-to-Back or Back-to-Back equivalent):**
            *   The standard back-to-front compositing formula is preferred for efficiency [S6]. However, many implementations (like [S1, unofficial]) use a front-to-back update for the accumulator:
                *   `accumulator.rgb += (1.0 - accumulator.a) * color.rgb * value` [S1, unofficial].
                *   `accumulator.a += (1.0 - accumulator.a) * value * uExtinction / 100.0` [S1, unofficial].
            *   Alternatively, using blend weights [S2, unofficial]:
                *   Compute cumulative product of $(1 - \alpha_i)$ with epsilon for numerical stability to get `acc_transmission` [S2, unofficial].
                *   Compute blend weights using `blend_func` on opacity and `acc_transmission` [S2, unofficial].
                *   Accumulate ray color: `ray_color += point_color * blend_weight` [S2, unofficial].
        *   Increment $t$ by `uStepSize` [S1, unofficial].
        *   **Early Termination:** If `accumulator.a` > 0.98 (or 0.9), break early [S1, unofficial].

3.  **Finalization:**
    *   If `accumulator.a` > 1.0, divide RGB by Alpha to premultiply/normalize [S1, unofficial].
    *   Add background color scaled by background transmission if provided [S2, unofficial].
    *   Output final color with alpha 1: `oColor = vec4(accumulator.rgb, 1)` [S1, unofficial].

**Pseudocode**
```python
def emission_absorption_ray_march(ray_origin, ray_direction, step_size, max_steps, extinction_coeff, source_func, background_color):
    """
    Renders a volume using emission-absorption ray marching.
    """
    accumulator_color = [0.0, 0.0, 0.0]
    accumulator_alpha = 0.0
    
    # Calculate total ray length and step length
    ray_length = calculate_ray_length(ray_origin, ray_direction) # Placeholder for actual ray-box intersection logic
    step_length = step_size 
    
    # Random offset for jittering
    t = random() * step_length * 1.5
    t = clamp(t, 0.0, 1.0)
    
    # Pre-calculate transmission array for back-to-front if needed, 
    # or use front-to-back accumulation as per [S1, unofficial]
    
    for i in range(max_steps):
        if t >= 1.0:
            break
            
        # Sample position
        position = ray_origin + ray_direction * t
        
        # Get volume properties
        # value represents the density/extinction contribution at this point
        value = source_func(position)
        
        # Compute opacity for this step
        # sigma is often derived from value or a separate density field
        sigma = value 
        opacity = 1.0 - exp(-sigma * step_length)
        
        # Early termination check
        if accumulator_alpha > 0.98:
            break
            
        # Front-to-back accumulation (common in shader implementations [S1, unofficial])
        # Weight of current sample
        weight = (1.0 - accumulator_alpha) * opacity
        
        # Get color/emission from source function
        color = source_func(position) # Assuming source_func returns color if emitting, or use separate emission_func
        
        # Update accumulator
        accumulator_color = accumulator_color + weight * color
        accumulator_alpha = accumulator_alpha + weight * opacity
        
        # Advance ray
        t += step_length
        
    # Normalize if alpha exceeds 1.0 due to precision
    if accumulator_alpha > 1.0:
        accumulator_color = accumulator_color / accumulator_alpha
        
    # Add background
    # Note: In front-to-back, background is implicitly handled by the (1-alpha) term,
    # but explicit background addition might be needed if the ray exits the volume.
    # background_transmission = 1.0 - accumulator_alpha
    # final_color = accumulator_color + background_color * background_transmission
    
    return accumulator_color, 1.0
```

## Subtopics

### [Volumetric Liquid Rendering](4017-volumetric-liquid-rendering.md)
Volumetric Liquid Rendering is a specific application of emission-absorption ray marching used to render liquid volumes, such as the wax in a lava lamp, illuminated from below. It differs from general volume rendering by masking the liquid visibility with the depth of an occluding surface (wax) and driving emission based on proximity to a light source. It builds on [Emission-Absorption Ray Marching](3171-emission-absorption-ray-marching.md).

### Emission-only Volume Rendering
A volume rendering technique where the medium adds light to the ray by emission but neglects absorption (transparent particles that glow) [S5]. It integrates the source term $g(s)$ along the ray, potentially using Fourier projection slice theorem and FFTs for rapid computation [S5]. A key pitfall is that accumulated intensity has no upper bound because there is no attenuation, easily exceeding the representable range of the output device [S5].

### Alpha Ray Marching
Computes opacity, transmission, and blend weights for volume rendering without accumulating final color, used for auxiliary losses or intermediate states [S2, unofficial]. It computes the cumulative product of $(1 - \text{opacity})$ with epsilon for numerical stability, extracts background transmission, and computes blend weights using a provided `blend_func` [S2, unofficial].

## Operating characteristics
*   **Time Complexity:** $O(N)$ per ray, where $N$ is the number of steps (`max_steps`). Early termination reduces average complexity for opaque regions [S6].
*   **Memory Complexity:** $O(1)$ if using front-to-back accumulation with a single accumulator, or $O(N)$ if storing transmission arrays for back-to-front compositing [S2, unofficial].
*   **Performance:** Deterministic and stable. The use of back-to-front compositing is more computationally efficient for early ray termination [S6].
*   **Strengths:** Handles both glowing and occluding media realistically; upper bound on intensity prevents blowout compared to emission-only models [S5].
*   **Limitations:** Requires sampling the volume density field; step size must be small enough to avoid aliasing in high-frequency density variations.

## Background
The method is derived from the volume rendering equation, specifically the case where scattering is neglected (or folded into extinction) and only absorption and emission are considered [S5]. The analytical solution using the integrating factor is described in standard texts on participating media [S5]. The discrete implementation using Riemann sums and alpha compositing is a standard technique in direct volume rendering [S5, S6].
