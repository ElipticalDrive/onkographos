# Emission-Absorption Ray Marching

Also called: Absorption plus Emission Volume Rendering, Direct Volume Rendering (Emission plus Absorption), EAM Render, Emission plus Absorption Volume Rendering, EmissionAbsorption, X-Ray Rendering

## Overview
Emission-Absorption Ray Marching is a deterministic volume rendering technique that computes the final pixel color by integrating the combined effects of light attenuation (extinction) and light generation (emission) along a viewing ray [S1, unofficial][S6, S7]. It solves the problem of rendering participating media where particles both occlude background light and contribute their own luminance, such as clouds, smoke, or medical tissue [S6]. Unlike the [Absorption-only model](839-absorption-only-model.md), which only darkens the background, or the [Emission-only Model](1016-emission-only-model.md), which lacks intensity bounds, this method provides a physically bounded result by balancing source terms against exponential decay [S6]. It builds on the general [Optical models](33-optical-models.md) framework by solving the specific differential equation for media with non-zero extinction and emission coefficients [G].

## How it works
**Inputs:**
*   Ray origin $\mathbf{o}$ and direction $\boldsymbol{\omega}$ (unit vector) [G].
*   Volume bounds (entry and exit distances $t_{min}, t_{max}$ or a bounding box) [G].
*   Step size $h$ (or step count limit) [S2, S4, unofficial].
*   Extinction coefficient $\sigma_t$ (or opacity $\alpha$ per sample) [S3, unofficial][S7].
*   Emission coefficient $g(s)$ (or source term) [S6, S7].
*   Background radiance $L_{bg}$ (or initial intensity $I_0$) [S7].

**Outputs:**
*   Final accumulated radiance $L_{out}$ and opacity $\alpha_{out}$ [G].

**Data Structures:**
*   Accumulator: A vector or struct holding current accumulated color $C_{acc}$ and opacity $\alpha_{acc}$ [G]. Initialized to $(\mathbf{0}, 0)$ [G].
*   Transmission buffer: An array storing cumulative transmission $T_i = \prod_{k=i+1}^{n} (1-\alpha_k)$ for back-to-front compositing [S3, unofficial][S7].

**Numbered Steps:**

1.  **Initialization:**
    *   Calculate ray length: $L = t_{max} - t_{min}$ [G].
    *   Determine step size: $h$ can be fixed or derived from ray length and a step count parameter [S2, S4, unofficial].
    *   Initialize random offset for jittering (optional): $t_{offset} = \text{rand}() \cdot h$ [S2, unofficial].
    *   Initialize accumulator: $C_{acc} = \mathbf{0}$, $\alpha_{acc} = 0$ [G].
    *   Initialize transmission: $T_{curr} = 1.0$ [S7].

2.  **Ray Marching Loop (Back-to-Front):**
    *   Iterate $i$ from $0$ to $N-1$ (where $N = \lfloor L / h \rfloor$):
        *   Advance position: $t = t_{min} + i \cdot h + t_{offset}$ [G].
        *   Sample volume at $\mathbf{p} = \mathbf{o} + t\boldsymbol{\omega}$:
            *   Get extinction $\sigma_t$ or opacity $\alpha_i$. If using density $\sigma$, compute $\alpha_i = 1 - e^{-\sigma_i h}$ [S3, unofficial][S7].
            *   Get emission $g_i$ (radiance added per unit length) [S6, S7].
        *   **Update Transmission:**
            *   $T_{curr} = T_{curr} \cdot (1 - \alpha_i)$ [S7].
            *   Store $T_{curr}$ in a buffer for back-to-front compositing [S3, unofficial].
        *   **Accumulate Color:**
            *   The contribution of the current sample to the final color is its emission weighted by the transmission of all *subsequent* (closer to viewer) samples, plus the attenuation of the background [S7].
            *   Using the discrete form derived from the integrating factor solution [S7]:
                $$ L_{out} = L_{bg} \prod_{k=0}^{N-1} (1-\alpha_k) + \sum_{i=0}^{N-1} g_i \prod_{j=i+1}^{N-1} (1-\alpha_j) $$
            *   In a forward loop with a precomputed transmission array, this is implemented as:
                $$ C_{acc} = C_{acc} + g_i \cdot T_{after\_i} \cdot h $$
                where $T_{after\_i}$ is the transmission from sample $i+1$ to the end [S7].
            *   **Early Termination:**
                *   If $\alpha_{acc} > 0.98$, break loop [S2, unofficial].

3.  **Background Contribution:**
    *   Add background scaled by the final transmission:
        $$ C_{final} = C_{acc} + L_{bg} \cdot T_{curr} $$
        where $T_{curr}$ is the product of all $(1-\alpha_k)$ [S7].

4.  **Normalization:**
    *   If $\alpha_{acc} > 1.0$ (due to precision), clamp or normalize [S2, unofficial].
    *   Output $C_{final}$ with $\alpha_{out} = \min(\alpha_{acc}, 1.0)$ [G].

**Pseudocode (Back-to-Front Compositing):**

```python
import math
import random

def emission_absorption_ray_march(ray_origin, ray_direction, t_min, t_max, volume_sampler, step_size, background_color):
    """
    Renders a volume using emission-absorption ray marching.
    Implements back-to-front compositing as specified by the discrete RTE solution [S7].
    """
    # 1. Initialize
    ray_length = t_max - t_min
    num_steps = int(ray_length / step_size)
    if num_steps == 0:
        return background_color, 0.0

    # Precompute transmission from back to front
    transmission = [0.0] * num_steps
    alphas = [0.0] * num_steps
    current_trans = 1.0

    for i in range(num_steps - 1, -1, -1):
        t = t_min + (i + 0.5) * step_size
        if t > t_max:
            break
        density = volume_sampler.sample_density(t)
        alpha = 1.0 - math.exp(-density * step_size)
        alphas[i] = alpha
        transmission[i] = current_trans
        current_trans *= (1.0 - alpha)

    # 2. Accumulate emission and background
    accumulated_color = [0.0, 0.0, 0.0]
    accumulated_alpha = 0.0

    for i in range(num_steps):
        t = t_min + (i + 0.5) * step_size
        if t > t_max:
            break
        emission = volume_sampler.sample_emission(t)
        alpha = alphas[i]
        T_after = transmission[i]

        # Back-to-front compositing
        weight = T_after * alpha
        accumulated_color = [accumulated_color[k] + weight * emission[k] * step_size for k in range(3)]
        accumulated_alpha += weight

        # Early termination
        if accumulated_alpha > 0.98:
            break

    # 3. Add background
    final_color = [accumulated_color[k] + background_color[k] * current_trans for k in range(3)]
    return final_color, min(accumulated_alpha, 1.0)
```

**Parameters:**
*   `step_size`: Distance between samples. Default value is 0.5 in some implementations [S4, unofficial]. Smaller values increase accuracy but cost more [G].
*   `max_steps`: Maximum iterations per ray. Default value is 2000 [S4, unofficial].
*   `uExtinction`: Extinction coefficient scaling factor [S2, unofficial].
*   `_AbsorptionCoefficient`: Used in Beer-Lambert law for light density [S5, unofficial].

**Edge Cases:**
*   **Precision:** If $\alpha_i$ is very small, $1-\alpha_i$ may suffer from floating-point cancellation. Use `expm1` or higher precision for transmission products [S3, unofficial].
*   **Unbounded Emission:** If absorption is zero, emission accumulates linearly without bound, potentially exceeding display range [S6].
*   **Degenerate Input:** Empty volume (zero density) should return background color immediately [G].

## Subtopics

### [Volumetric Liquid Rendering](4017-volumetric-liquid-rendering.md)
A specific application for liquids like lava lamp wax, masking visibility with surface depth and driving emission by proximity to lights.

### [Energy-based Volume Rendering (Energy Engine)](8218-energy-based-volume-rendering-energy-engine.md)
Decouples absorption and emission into separate ray buffers for precise control over attenuation of emitted light.

### Emission-only Volume Rendering
Renders glowing media by integrating the source term $g(s)$ along the ray, neglecting absorption [S6]. It is computationally simpler but lacks an upper bound on intensity, risking overflow [S6].

### Alpha Ray Marching
Computes opacity, transmission, and blend weights without accumulating final color [S3, unofficial]. Used for auxiliary losses or intermediate states [G]. It calculates cumulative transmission with epsilon for stability and extracts background transmission [S3, unofficial].

## Operating characteristics
*   **Time Complexity:** $O(N)$ per ray, where $N$ is the number of steps. Early termination reduces average cost for opaque regions [S7].
*   **Memory Complexity:** $O(1)$ for front-to-back accumulation. $O(N)$ if storing full transmission history for back-to-front compositing [S3, unofficial].
*   **Performance:** Deterministic and stable. Performance is limited by memory bandwidth when sampling 3D textures [S4, unofficial].
*   **Strengths:** Computationally efficient and supports early termination [S7].
*   **Limitations:** Neglects in-scattering, modeling only extinction (absorption + out-scattering) and emission [S6]. Requires careful tuning of step size to avoid artifacts [S2, unofficial].

## Background
The method is derived from the Radiative Transfer Equation (RTE) for participating media [S5, unofficial][S6]. The specific differential equation for emission and absorption, $\frac{dI}{ds} = g(s) - \tau(s)I(s)$, is solved using an integrating factor [S6, S7]. This approach was formalized in direct volume rendering literature, notably by Levoy [S6], who distinguished it from emission-only and absorption-only models. It is widely used in medical imaging and scientific visualization for segmented data where tissue types have distinct emission and absorption properties [S6].
