# Alpha Ray Marching


## Overview
Alpha Ray Marching computes opacity, transmission, and blend weights for volume rendering without accumulating final color [S1, unofficial]. It solves the problem of generating intermediate states or auxiliary losses by integrating extinction along a ray, effectively attenuating light contributions from different depths . Unlike its parent method, Emission-Absorption Ray Marching, which computes final composited images, Alpha Ray Marching produces the raw transparency metrics required for gradient-based optimization in neural rendering pipelines [S1, unofficial].

## How it works
**Inputs:**
- `ray_features`: Tensor of shape $(N, D)$, where $N$ is the number of rays and $D$ is the feature dimension. The first channel ($[..., 0]$) represents the density $\sigma$.
- `ray_dist`: Tensor of shape $(N, M)$, representing the distance between consecutive samples along each ray.
- `ray_valid`: Boolean or float tensor of shape $(N, M)$, indicating valid samples (1.0 for valid, 0.0 for invalid).
- `blend_func`: A callable function that computes blend weights given opacity and transmission tensors.

**Outputs:**
- `opacity`: Tensor of shape $(N, M)$, the probability of absorption at each sample.
- `acc_transmission`: Tensor of shape $(N, M+1)$, cumulative transmission from the ray origin to each sample.
- `blend_weights`: Tensor of shape $(N, M)$, weights for compositing if needed, derived from opacity and transmission.
- `background_blend_weight`: Scalar or tensor $(N)$, weight for the background color.

**Data Structures:**
- Tensors are typically floating-point (float32).
- `acc_transmission` is padded to align with samples.

**Steps:**
1. **Compute Density:** Calculate the effective density $\sigma$ by masking the first channel of `ray_features` with `ray_valid` [S1, unofficial].
   $$ \sigma = \text{ray\_features}[..., 0] \times \text{ray\_valid}.float() $$
2. **Compute Opacity:** Calculate the opacity for each sample using the exponential attenuation model [S1, unofficial].
   $$ \text{opacity} = 1 - e^{-\sigma \times \text{ray\_dist}} $$
3. **Compute Cumulative Transmission:** Calculate the cumulative product of $(1 - \text{opacity})$ to get transmission. An epsilon value is added for numerical stability to prevent zero transmission [S1, unofficial].
   $$ \text{acc\_transmission}_{raw}[i] = \prod_{j=0}^{i} (1 - \text{opacity}[j] + \epsilon) $$
4. **Extract Background Transmission:** The background transmission is the last element of the raw cumulative transmission array [S1, unofficial].
   $$ \text{background\_transmission} = \text{acc\_transmission}_{raw}[-1] $$
5. **Align Transmission:** Prepend $1.0$ to `acc_transmission` and remove the last element to align the transmission values with the sample indices [S1, unofficial].
   $$ \text{acc\_transmission} = [\text{acc\_transmission}_{raw}[0], \dots, \text{acc\_transmission}_{raw}[-2]] $$
   Note: The prepended $1.0$ represents the transmission at the ray origin (before any samples).
6. **Compute Blend Weights:** Apply `blend_func` to `opacity` and `acc_transmission` to get per-sample blend weights [S1, unofficial].
   $$ \text{blend\_weights} = \text{blend\_func}(\text{opacity}, \text{acc\_transmission}) $$
7. **Compute Background Blend Weight:** Apply `blend_func` to $1$ and `background_transmission` [S1, unofficial].
   $$ \text{background\_blend\_weight} = \text{blend\_func}(1, \text{background\_transmission}) $$

**Pseudocode:**
```python
import torch
import torch.nn.functional as F

def alpha_ray_marching(ray_features, ray_dist, ray_valid, blend_func, epsilon=1e-6):
    """
    Computes opacity, transmission, and blend weights without final color accumulation.
    
    Args:
        ray_features: (N, D) tensor, ray_features[..., 0] is density sigma.
        ray_dist: (N, M) tensor, distances between samples.
        ray_valid: (N, M) tensor, validity mask (1.0 or 0.0).
        blend_func: Callable(opacity, transmission) -> weights.
        epsilon: Float, numerical stability constant.
        
    Returns:
        opacity: (N, M)
        acc_transmission: (N, M+1)
        blend_weights: (N, M)
        background_blend_weight: (N,)
    """
    # Step 1: Compute density sigma
    sigma = ray_features[..., 0] * ray_valid.float()
    
    # Step 2: Compute opacity
    # opacity = 1 - exp(-sigma * ray_dist)
    opacity = 1.0 - torch.exp(-sigma * ray_dist)
    
    # Step 3: Compute cumulative transmission
    # 1 - opacity is the transmission through a single sample
    # Add epsilon for stability
    trans_per_sample = 1.0 - opacity + epsilon
    
    # Cumulative product along the sample dimension (dim=1)
    # acc_transmission_raw[i] = prod(trans_per_sample[0...i])
    acc_transmission_raw = torch.cumprod(trans_per_sample, dim=1)
    
    # Step 4: Extract background transmission
    background_transmission = acc_transmission_raw[:, -1]
    
    # Step 5: Align transmission
    # Prepend 1.0 (transmission at origin)
    # Remove last element to align with M samples
    # acc_transmission shape: (N, M+1)
    ones = torch.ones_like(acc_transmission_raw[:, :1])
    acc_transmission = torch.cat([ones, acc_transmission_raw[:, :-1]], dim=1)
    
    # Step 6: Compute blend weights
    blend_weights = blend_func(opacity, acc_transmission)
    
    # Step 7: Compute background blend weight
    # blend_func expects tensors of compatible shapes
    # background_transmission is (N,), need to broadcast or reshape if blend_func requires (N, 1)
    # Assuming blend_func handles scalar or 1D tensor appropriately
    background_blend_weight = blend_func(torch.ones_like(background_transmission), background_transmission)
    
    return opacity, acc_transmission, blend_weights, background_blend_weight
```

**Parameters:**
- `epsilon`: Small constant for numerical stability in cumulative product. Typical value: $10^{-6}$ [S1, unofficial].

**Edge Cases:**
- **Zero Density:** If $\sigma = 0$, opacity is 0, transmission remains 1.
- **Invalid Samples:** `ray_valid` masks out invalid samples, setting $\sigma$ to 0.
- **Numerical Underflow:** Cumulative product of values close to 0 can underflow. Epsilon addition prevents this [S1, unofficial].

## Subtopics

### [Opacity Accumulation](21799-opacity-accumulation.md)
Opacity Accumulation is a ray traversal scheme that accumulates opacity while compositing colors to make transparent layers visible. It solves the problem of rendering participating media by integrating the extinction along a ray, effectively attenuating light and color contributions from different depths. Unlike its parent method, Alpha Ray Marching, which computes intermediate states without final color accumulation, Opacity Accumulation produces the final composited image by blending contributions based on the accumulated opacity.

## Operating characteristics
- **Time Complexity:** $O(N \times M)$, where $N$ is the number of rays and $M$ is the number of samples per ray. The cumulative product and exponential operations are linear in the number of samples.
- **Memory Complexity:** $O(N \times M)$ for storing intermediate tensors (`opacity`, `acc_transmission`, `blend_weights`).
- **Strengths:** Efficient computation of transparency metrics for neural rendering optimization. Decouples transparency calculation from color compositing, allowing for flexible loss functions.
- **Limitations:** Does not produce final rendered images. Requires a separate compositing step if color is needed. Sensitive to numerical precision in cumulative products.
- **When to Use:** When training neural radiance fields or volume representations where auxiliary losses on opacity/transparency are needed. When intermediate states are required for debugging or analysis.
- **When Not to Use:** When final rendered images are the only output required. When performance is critical and compositing can be fused with marching.

## Background
Alpha Ray Marching is a technique used in neural volume rendering, specifically in the context of point-based neural radiance fields. It originates from the implementation in the `pointnerf` repository by Xharlie [S1, unofficial]. The method is designed to compute transparency metrics efficiently for gradient-based optimization, enabling the training of neural representations using auxiliary losses related to opacity and transmission.
