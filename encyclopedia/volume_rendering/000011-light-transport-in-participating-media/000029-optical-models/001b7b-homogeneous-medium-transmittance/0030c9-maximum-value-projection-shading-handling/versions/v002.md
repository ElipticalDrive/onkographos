# Maximum-Value Projection Shading Handling


## Overview
Maximum-Value Projection Shading Handling renders volumetric data by selecting the highest scalar value along the viewing ray and mapping it to a color via a transfer function [S2]. It differs from sibling methods such as [Exponential Fog (Beer-Lambert)](3968-exponential-fog-beer-lambert.md) and [Absorption Adjustment](4020-absorption-adjustment.md) by discarding intermediate values and focusing solely on the extremum [G].

## How it works
**Inputs and Outputs:**
*   **Input:** A ray cast through a volumetric cell containing scalar data values [S2].
*   **Output:** A single color value derived from the maximum scalar value found along the ray, processed through a transfer function [S2].

**Data Structures:**
*   **Ray:** Defined by origin $O$ and direction $D$ [G].
*   **Cell:** A volumetric element with an associated opacity $O_1$ and scalar data values [S1, unofficial].
*   **Transfer Function:** A mapping $T(v) \rightarrow C$ that converts a scalar value $v$ to a color $C$ [S2].

**Steps:**
1.  Cast a primary ray through the volume [G].
2.  Examine all measured data values from the ray path within the current cell [S2].
3.  Identify the maximum scalar value $v_{\text{max}}$ from the sampled data [S2].
4.  Display the maximum value found by means of the transfer function [S2].
5.  Configure shading for maximum-value projections: turn off all shading effects except transmission [S1, unofficial].
6.  Set the index of refraction to 1 [S1, unofficial].
7.  Calculate the transmission coefficient $T_c$ using the opacity $O_1$ of the maximum value:
    $$ T_c = 1 - O_1 $$
    where $O_1$ is the opacity corresponding to the maximum value [S1, unofficial].
8.  If casting a transmission ray from a maximum-value intersection, turn the cell "off" to prevent the ray from performing intersection calculations with it, avoiding a recursive maximum-value intersection within the same object [S1, unofficial].
9.  Once the transmission ray intersects the polygon, turn the cell "on" again to allow correct shadowing and reflection calculations [S1, unofficial].

**Parameters:**
*   **Index of Refraction:** Set to 1 [S1, unofficial].
*   **Transmission Coefficient:** $1 - O_1$ [S1, unofficial].

**Edge Cases and Pitfalls:**
*   **Recursive Intersection:** Naively casting a transmission ray from a maximum-value intersection without disabling the current cell results in another maximum-value intersection within the same object [S1, unofficial].
*   **Opacity Handling:** The transmission coefficient depends on the opacity of the maximum value; if the maximum value is opaque, no transmission occurs and underlying polygons are hidden [S1, unofficial].

## Subtopics

### Maximum Shader
A shader that examines all measured data values along the ray and displays the maximum found using a transfer function [S2].

## Operating characteristics
Not given in the sources.

## Background
The "Maximum shader" was introduced for overlapping and combining 3D voxel volume data with 3D building models [S2]. The shading handling details, including the transmission coefficient formula and intersection management, were described in the context of volumetric ray tracing within the VolVis volume visualization system [S1, unofficial].
