# Transmittance Calculation via Ratio Tracking

Also called: Ratio Tracking, Ratio Tracking Transmittance

## Overview
Ratio Tracking is an unbiased Monte Carlo estimator for the transmittance function $T(x_i, x_{i+1})$ in heterogeneous media, proposed by Novák et al. [2014] [S1]. It is used within Pseudo-Marginal Metropolis Light Transport (PMLT) to provide a noisy but unbiased estimate of transmission where exact integration is intractable [S1]. Unlike deterministic methods such as [Exponential Fog (Beer-Lambert)](3968-exponential-fog-beer-lambert.md) which assume homogeneous density, Ratio Tracking handles spatially varying extinction coefficients by sampling distances and evaluating the ratio of samples that exceed the target distance [S1].

## How it works
**Inputs:**
- Ray segment endpoints $x_i$ and $x_{i+1}$ [S1].
- Extinction coefficient function $\sigma_t(x)$, defined for all $x$ along the segment [S2, unofficial].
- Bounding density $\sigma_{max} \ge \max(\sigma_t(x))$ along the segment [G].
- Number of samples $N$ (integer $> 0$) [G].
- Transmittance depth parameter $\alpha$ (float, typically $1.0$, range $0.1$ to $10$) [S2, unofficial].

**Outputs:**
- Estimated transmittance $\hat{T}$ (float in $[0, 1]$) [S1].

**Data Structures:**
- No persistent data structures required. The method is stateless per evaluation [G].

**Steps:**
1. Compute the ray direction $\omega = (x_{i+1} - x_i) / \|x_{i+1} - x_i\|$ and the segment length $L = \|x_{i+1} - x_i\|$ [G].
2. Scale the target distance by the transmittance depth parameter: $L_{eff} = L \cdot \alpha$ [S2, unofficial].
3. Initialize a cumulative sum `sum_T = 0.0` [G].
4. For each sample $j$ from $1$ to $N$:
   a. Initialize `pos = x_i`, `accum_dist = 0.0`, and `prod = 1.0` [G].
   b. Loop indefinitely:
      i. Sample a uniform random number $u \in (0, 1]$ [G].
      ii. Compute free-flight distance $d = -\ln(u) / \sigma_{max}$ [G].
      iii. Update position: `pos = pos + d * \omega` [G].
      iv. Update accumulated distance: `accum_dist += d` [G].
      v. Multiply the running product by the ratio of actual to bounding density: `prod *= \sigma_t(pos) / \sigma_{max}` [G].
      vi. Check if `accum_dist >= L_{eff}`. If true, break the loop [G].
      vii. Check if `pos` has exited the volume bounding box. If true, set `prod = 0.0` and break the loop [S2, unofficial].
   c. Add `prod` to `sum_T` [G].
5. Compute the raw estimate: $\hat{T}_{raw} = \text{sum\_T} / N$ [G].
6. Clamp $\hat{T}_{raw}$ to $[0, 1]$ and return as $\hat{T}$ [G].

**Formulas:**
The transmittance $T(x_i, x_{i+1})$ represents the fraction of energy reaching $x_{i+1}$ from $x_i$ [S2, unofficial].
$$ T(x_i, x_{i+1}) = \exp\left(-\int_{x_i}^{x_{i+1}} \sigma_t(s) ds\right) $$
The estimator $\hat{T}$ is derived from $N$ independent samples [G]. Each sample estimates the transmittance by tracking the product of density ratios along a stochastic path until the scaled target distance is reached or the medium boundary is crossed [S1].

**Parameters:**
- $\alpha$ (transmittance depth): Scales the transmittance distance, allowing adjustment of transmittance without changing density or distance estimation [S2, unofficial]. Range observed: $0.1$ to $10$ [S2, unofficial]. Default is typically $1.0$ [S2, unofficial].

**Edge Cases and Pitfalls:**
- Changing $\alpha$ affects the number of steps required to exit the volume bounding box because the code always checks if the ray position is still inside the medium boundaries [S2, unofficial].
- Precision issues may arise if $\sigma_t$ varies rapidly, requiring careful bounding density selection in delta tracking steps [G].
- If $\sigma_t(x) = 0$ anywhere, $\sigma_{max}$ must still be positive to avoid division by zero in the ratio product [G].

**Pseudocode:**
```python
import math
import random

def ratio_tracking_transmittance(x_i, x_i_plus_1, sigma_t, sigma_max, N, alpha=1.0):
    """
    Estimate transmittance using Ratio Tracking.
    
    Args:
        x_i: Start point of the ray segment.
        x_i_plus_1: End point of the ray segment.
        sigma_t: Function returning extinction coefficient at a point.
        sigma_max: Bounding density, >= max(sigma_t) along segment [G].
        N: Number of Monte Carlo samples.
        alpha: Transmittance depth parameter.
        
    Returns:
        Estimated transmittance.
    """
    direction = normalize(x_i_plus_1 - x_i)
    segment_length = length(x_i_plus_1 - x_i)
    target_dist = segment_length * alpha  # Scale distance per [S2, unofficial]
    
    sum_T = 0.0
    
    for _ in range(N):
        current_pos = list(x_i)
        prod = 1.0
        accum_dist = 0.0
        
        while True:
            u = random.random()
            if u == 0.0: u = 1e-9  # Guard against log(0) [G]
            d = -math.log(u) / sigma_max
            accum_dist += d
            
            # Update position
            current_pos = [current_pos[k] + d * direction[k] for k in range(3)]
            
            # Update product with density ratio
            sigma = sigma_t(current_pos)
            prod *= sigma / sigma_max
            
            # Check if target distance is reached
            if accum_dist >= target_dist:
                break
                
            # Check if current_pos is outside the volume bounding box [S2, unofficial]
            if not is_inside_volume(current_pos):
                prod = 0.0
                break
                
        sum_T += prod
        
    raw_estimate = sum_T / N if N > 0 else 0.0
    return max(0.0, min(1.0, raw_estimate))

def normalize(v):
    l = length(v)
    return [c / l for c in v] if l > 0 else [0.0, 0.0, 0.0]

def length(v):
    return math.sqrt(sum(c*c for c in v))

def is_inside_volume(p):

    return True
```

## Background
Ratio Tracking was proposed by Novák et al. in 2014 as part of the Pseudo-Marginal Metropolis Light Transport (PMLT) method [S1]. It was introduced to provide an unbiased estimate of transmittance in heterogeneous media, which is difficult to compute exactly [S1]. The method is based on the principle of ratio tracking, where the transmittance is estimated by the ratio of samples that survive the distance to the total number of samples [S1]. It has been used in research contexts involving complex light transport in participating media [S1].
