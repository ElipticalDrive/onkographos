# Non-Exponential Free Flight Model
Also called: Davis and Xu model, Generalized linear transport model for spatially correlated stochastic media

## Overview
The Non-Exponential Free Flight Model describes light transport in participating media where scattering particles are positively correlated, resulting in free path distributions with longer tails than the standard exponential distribution [S1, unofficial]. It allows for artistic control over the depth of light bleeding into subsurface media by introducing a shape parameter that modifies the probability of interaction based on distance traveled [S1, unofficial]. Unlike the Exponential Fog (Beer-Lambert) model, which assumes uncorrelated particle distribution, this model gives photons "memory," where past non-interactions influence future interaction probabilities [S1, unofficial]. It builds on [Homogeneous Medium Transmittance](1022-homogeneous-medium-transmittance.md) by replacing the exponential transmittance function with a power-law alternative.

## How it works
**Inputs:**
- $\sigma_e$: Extinction coefficient (constant for the homogeneous medium).
- $\sigma_s$: Scattering coefficient (constant for the homogeneous medium).
- $s$: Distance traveled from the current position.
- $b$: User-defined "bleed" parameter controlling the shape of the distribution.

**Outputs:**
- $T_a(s)$: Transmittance at distance $s$.
- $p(s)$: Probability density function (PDF) for sampling distance $s$.
- $c(s)$: Cumulative distribution function (CDF) for sampling distance $s$.
- $s(\xi)$: Sampled distance from a uniform random variable $\xi$.
- $S(s)$: Modified scattering coefficient for Monte Carlo random walk steps.

**Data Structures:**
No complex data structures are required. The model relies on scalar values and standard floating-point arithmetic [G]. The shape parameter $a$ is derived from the user-friendly parameter $b$ as $a = 1/b$ [S1, unofficial].

**Parameters:**
- $b$ (bleed): Controls the tail length of the distribution. The mapping $a=1/b$ is designed to provide a meaningful unit range for artists [S1, unofficial].
- $a$: Shape parameter. $a = 1/b$.

**Formulas:**
The transmittance $T_a$ is defined as [S1, unofficial]:
$$ T_a(s) = \frac{1}{(1 + \frac{\sigma_e s}{a})^a} $$

The probability density function (PDF) for sampling distance $s$ is [S1, unofficial]:
$$ p(s) = \frac{\sigma_e}{(1 + \frac{\sigma_e s}{a})^{a+1}} $$

The cumulative distribution function (CDF) is [S1, unofficial]:
$$ c(s) = \frac{1}{(1 + \frac{\sigma_e s}{a})^a} $$

To sample a distance $s$ from a uniform random variable $\xi \in (0, 1]$, use the inverse CDF [S1, unofficial]:
$$ s(\xi) = \frac{a \cdot (\xi^{-1/a} - 1)}{\sigma_e} $$

In the context of a Monte Carlo random walk, the scattering coefficient $\sigma_s$ is modified to depend on the distance traveled $s$ [S1, unofficial]:
$$ S(s) = \frac{\sigma_s}{1 + \frac{\sigma_e s}{a}} $$

**Steps:**
1. Compute the shape parameter $a = 1/b$.
2. Generate a uniform random number $\xi \in (0, 1]$.
3. Sample the free flight distance using the inverse CDF: $s = \frac{a \cdot (\xi^{-1/a} - 1)}{\sigma_e}$.
4. Compute the transmittance at the sampled distance: $T_a(s) = \frac{1}{(1 + \sigma_e s/a)^a}$.
5. Compute the modified scattering coefficient for the next step: $S(s) = \frac{\sigma_s}{1 + \sigma_e s/a}$.
6. If a scattering event occurs, update the current position by $s$ and repeat from step 2.

**Pseudocode:**
```python
def compute_transmittance(sigma_e, s, a):
    """Computes the non-exponential transmittance Ta(s)."""
    if sigma_e == 0.0:
        return 1.0
    return 1.0 / (1.0 + sigma_e * s / a) ** a

def sample_free_flight(sigma_e, sigma_s, a, xi):
    """Samples a new free flight distance and computes the modified scattering coefficient."""
    if sigma_e == 0.0:
        return float('inf'), sigma_s
    # Inverse CDF sampling: s = a * (xi^(-1/a) - 1) / sigma_e
    new_s = a * (xi ** (-1.0 / a) - 1.0) / sigma_e
    # Modified scattering coefficient at the sampled distance
    modified_sigma_s = sigma_s / (1.0 + sigma_e * new_s / a)
    return new_s, modified_sigma_s
```

**Edge Cases and Pitfalls:**
- **Division by Zero:** If $\sigma_e = 0$, the medium is transparent [G]. The formulas involve division by $\sigma_e$ or terms like $1 + \sigma_e s/a$ [G].
- **Parameter Range:** The parameter $a$ can result in unintuitive ranges for users [S1, unofficial]. The model maps it to 'bleed' ($b$) where $a = 1/b$ to provide a meaningful unit range [S1, unofficial].
- **Random Variable Range:** The inverse CDF formula $s(\xi) = \frac{a \cdot (\xi^{-1/a} - 1)}{\sigma_e}$ requires $\xi \in (0, 1]$ [G]. If $\xi = 0$, the term $\xi^{-1/a}$ becomes infinite [G]. In practice, $\xi$ should be sampled from $(0, 1]$ or clamped to a small positive value [G].
- **Memory Effect:** The probability of scattering depends on both the scattering cross section and the distance traveled [S1, unofficial]. This "memory" effect means that photons that have traveled further without interacting have a lower probability of scattering in the immediate future compared to the exponential case [S1, unofficial].

## Operating characteristics
- **Time Complexity:** The computational cost per step is similar to the exponential model, involving a few floating-point operations (power, division, multiplication) [G]. The inverse CDF sampling requires a power operation, which is slightly more expensive than the logarithm used in exponential sampling, but still constant time $O(1)$ per step [G].
- **Memory Complexity:** $O(1)$ per particle/step [G]. No additional data structures are required [G].
- **Strengths:** Provides artistic control over light bleeding depth [S1, unofficial]. The long-tail distribution allows a small fraction of photons to travel much deeper than an exponential distribution would allow, which can be useful for simulating subsurface scattering in materials like skin [S1, unofficial].
- **Limitations:** The model assumes a homogeneous medium with positively correlated particle distribution [S1, unofficial]. The parameter $a$ (or $b$) requires tuning to achieve desired visual results [G].
- **When to use:** When simulating subsurface scattering in materials where light bleeding depth is a key artistic control, and the medium can be approximated as having positively correlated scattering particles [S1, unofficial].
- **When not to use:** For media with uncorrelated particle distributions (use Exponential Fog) or heterogeneous media (use Heterogeneous Medium Transmittance) [G].

## Background
The Non-Exponential Free Flight Model was developed by Anthony B. Davis and Feng Xu in 2014, published in "A generalized linear transport model for spatially correlated stochastic media" in the Journal of Computational and Theoretical Transport [S1, unofficial]. The model addresses the limitation of Beer's Law, which assumes uncorrelated particle distribution, by introducing a shape parameter that allows for non-exponential free path distributions [S1, unofficial]. This is particularly useful for simulating the visual appearance of subsurface scattering in materials like skin, where light bleeding depth is a critical factor [S1, unofficial].
