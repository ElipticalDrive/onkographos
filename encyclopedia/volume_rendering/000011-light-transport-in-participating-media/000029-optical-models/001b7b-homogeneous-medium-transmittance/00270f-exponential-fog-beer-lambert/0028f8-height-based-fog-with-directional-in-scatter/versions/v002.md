# Height-based Fog with Directional In-scatter

Also called: aerial perspective, atmospheric fog

## Overview
This method simulates aerial perspective by adding a directional in-scatter term to a height-based fog model, making distant objects appear hazy and colored by the sky or sun while maintaining distance perception [S1, unofficial]. It differs from [Linear Distance Fog](4409-linear-distance-fog.md) by using exponential height falloff rather than linear distance blending, and from [Fog Blending with Clouds](4123-fog-blending-with-clouds.md) by focusing on atmospheric haze rather than volumetric cloud structures.

## How it works
**Inputs:** Ray direction $(dx, dy, dz)$, ray origin height $y$, distance to the hit surface, sun direction $(sunX, sunY, sunZ)$, base fog color $fogColor_{base}$, sun fog color $sunFogColor_{rgb}$, atmospheric parameters $fogDensity$, $fogHeight$, $haze$, $sunScatter$, $scattering$, reference height $reference$ (default 200, or water level if enabled), and original pixel color $color_{rgb}$ [S1, unofficial].

**Outputs:** Final fog-modulated pixel color $color_{rgb}$ [S1, unofficial].

**Data Structures:** None; the method operates on scalar values and vectors derived from the ray and scene parameters [G].

**Steps:**

1.  **Early Exit Checks:** If $fogDensity \le 0$, return the original pixel color unchanged [S1, unofficial]. If $fogAmount \le 0$, return the original pixel color unchanged [S1, unofficial].
2.  **Height Falloff:** Compute $midY = y \times 0.5$ [S1, unofficial]. Calculate the height falloff factor:
    $$heightFalloff = \exp\left(-\frac{\max(0, midY - reference)}{\max(1, fogHeight)}\right)$$
    where $fogHeight$ controls the exponential thinning of fog with altitude [S1, unofficial].
3.  **Optical Depth:** Compute the optical depth combining distance, density, height falloff, and haze:
    $$opticalDepth = distance \times fogDensity \times heightFalloff \times haze$$
    where $haze$ acts as a multiplier for the optical depth [S1, unofficial].
4.  **Fog Amount:** Determine the fog coverage amount using the Beer-Lambert law:
    $$fogAmount = \min(1, 1 - \exp(-opticalDepth))$$
    This value represents the fraction of the view ray occupied by fog [S1, unofficial].
5.  **Directional In-scatter:** Compute the dot product between the ray direction and the sun direction:
    $$dot = dx \cdot sunX + dy \cdot sunY + dz \cdot sunZ$$
    Calculate the scatter intensity by raising the positive part of the dot product to the 4th power and scaling by the sun scatter parameter:
    $$towardsSun = \max(0, dot)^4 \times sunScatter$$
    Clamp the scatter value:
    $$scatter = \min(1, towardsSun)$$
    This term simulates the directional in-scatter of sunlight, making fog brighter and warmer when looking towards the sun [S1, unofficial].
6.  **Interpolate Fog Color:** Blend between the base fog color and the sun fog color based on the scatter value:
    $$fogColor_{rgb} = fogColor_{base} + (sunFogColor_{rgb} - fogColor_{base}) \times scatter$$
    This creates the aerial perspective effect where fog takes on the color of the light source [S1, unofficial].
7.  **Apply Fog to Pixel Color:** Let $amount = fogAmount$. Blend the computed fog color with the original pixel color using the scattering multiplier:
    $$color_{rgb} += (fogColor_{rgb} - color_{rgb}) \times amount \times scattering$$
    where $scattering$ controls the overall intensity of the fog application [S1, unofficial].

**Pseudocode:**
```python
import math
from typing import Tuple

def height_based_fog_with_directional_inscatter(
    dx: float, dy: float, dz: float,
    y: float,
    distance: float,
    sunX: float, sunY: float, sunZ: float,
    fogColor_base: Tuple[float, float, float],
    sunFogColor: Tuple[float, float, float],
    fogDensity: float,
    fogHeight: float,
    haze: float,
    sunScatter: float,
    scattering: float,
    reference: float = 200.0,
    original_color: Tuple[float, float, float] = (0.0, 0.0, 0.0)
) -> Tuple[float, float, float]:
    # Early exit checks
    if fogDensity <= 0:
        return original_color

    # 1. Height Falloff
    mid_y = y * 0.5
    height_falloff = math.exp(-max(0.0, mid_y - reference) / max(1.0, fogHeight))

    # 2. Optical Depth
    optical_depth = distance * fogDensity * height_falloff * haze

    # 3. Fog Amount
    fog_amount = min(1.0, 1.0 - math.exp(-optical_depth))

    # Early exit for amount
    if fog_amount <= 0:
        return original_color

    # 4. Directional In-scatter
    dot = dx * sunX + dy * sunY + dz * sunZ
    towards_sun = max(0.0, dot) ** 4 * sunScatter
    scatter = min(1.0, towards_sun)

    # 5. Interpolate Fog Color
    fog_color = (
        fogColor_base[0] + (sunFogColor[0] - fogColor_base[0]) * scatter,
        fogColor_base[1] + (sunFogColor[1] - fogColor_base[1]) * scatter,
        fogColor_base[2] + (sunFogColor[2] - fogColor_base[2]) * scatter
    )

    # 6. Apply Fog
    amount = fog_amount
    final_color = (
        fog_color[0] + (fog_color[0] - original_color[0]) * amount * scattering,
        fog_color[1] + (fog_color[1] - original_color[1]) * amount * scattering,
        fog_color[2] + (fog_color[2] - original_color[2]) * amount * scattering
    )
    return final_color
```

**Parameters:**
- `FOG_BASE`: Constant reference height for fog calculation, default value 200 [S1, unofficial].
- `atmosphere.fogDensity`: Controls overall fog density [S1, unofficial].
- `atmosphere.fogHeight`: Exponential falloff height for fog thinning with altitude [S1, unofficial].
- `atmosphere.haze`: Multiplier for optical depth [S1, unofficial].
- `atmosphere.sunScatter`: Controls strength of sun-directional in-scatter [S1, unofficial].
- `atmosphere.scattering`: Multiplier for fog application intensity [S1, unofficial].

**Edge Cases and Pitfalls:**
- If $fogDensity \le 0$, calculations should be skipped to avoid artifacts [S1, unofficial].
- If $amount \le 0$, color blending should be skipped [S1, unofficial].
- Precision issues may arise if $fogHeight$ is very small; using $\max(1, fogHeight)$ in the denominator prevents division by zero or extreme values [S1, unofficial].

## Subtopics

### Height Fog
A volumetric fog effect where density falls exponentially with height, filling space and sampled in closed form [S2, unofficial]. It fades the horizon and fills valleys [S2, unofficial].
