# Exponential Fog (Beer-Lambert)

Also called: Depth Fog, Distance Fog

## Overview
Exponential fog is a depth-cueing technique that fades scene colors toward a background (sky) color based on the viewer's distance from the camera [S1, S2, S3, unofficial]. It differs from linear distance fog by using an exponential decay function for atmospheric perspective, and from heterogeneous models by assuming a uniform density throughout the medium [S1, S3, unofficial].

## How it works
**Inputs:**
- `viewDist`: The Euclidean distance from the camera origin to the surface hit point; if no surface is hit, this is the ray limit `tLimit` [S1, unofficial].
- `fogColor`: The background or sky color vector (e.g., `vec3(0.03, 0.04, 0.06)` for a dark blue-grey) [S1, S2, unofficial].
- `FOG_DENSITY`: A scalar controlling the rate of exponential decay [S1, S2, S3, unofficial].
- `FOG_START`: (Optional) The distance from the camera at which fog begins to appear; distances below this value are unaffected [S1, unofficial].

**Outputs:**
- `finalColor`: The blended color of the surface and the fog [S1, S2, unofficial].

**Data Structures:**
- Not given in the sources.

**Steps:**
1. Calculate the effective distance `d` contributing to fog: `d = max(0.0, viewDist - FOG_START)` [S1, unofficial].
2. Compute the raw fog factor `fogRaw` using the exponential decay formula [S1, S2, S3, unofficial]. Implementations vary between linear and squared distance in the exponent [S1, S2, S3, unofficial].
   - Linear exponent: `fogRaw = 1.0 - exp(-FOG_DENSITY * d)` [S1, unofficial].
   - Squared exponent: `fogRaw = 1.0 - exp(-FOG_DENSITY * d * d)` [S2, S3, unofficial].
3. Clamp the fog factor to prevent complete obscuration: `fogFact = clamp(fogRaw, 0.0, 0.97)` [S1, unofficial].
4. Blend the object color `C_obj` with the fog color `C_fog` using the fog factor: `finalColor = mix(C_obj, C_fog, fogFact)` [S1, S2, unofficial].

**Pseudocode:**
```python
import math

def compute_exponential_fog(view_dist: float, obj_color: tuple, fog_color: tuple,
                            fog_density: float, fog_start: float = 0.0,
                            use_squared_falloff: bool = True) -> tuple:
    """
    Computes the final color blended with exponential fog.
    
    Args:
        view_dist: Distance from camera to hit point.
        obj_color: Surface color (R, G, B).
        fog_color: Background/sky color (R, G, B).
        fog_density: Coefficient k in the exponential term.
        fog_start: Distance where fog begins.
        use_squared_falloff: If True, uses d^2 in exponent (common in shaders); 
                             if False, uses d (standard Beer-Lambert).
                             
    Returns:
        Final blended color (R, G, B).
    """
    # Step 1: Calculate effective distance
    d = max(0.0, view_dist - fog_start)
    
    # Step 2: Compute raw fog factor
    if use_squared_falloff:
        exponent = -fog_density * (d * d)
    else:
        exponent = -fog_density * d
        
    fog_raw = 1.0 - math.exp(exponent)
    
    # Step 3: Clamp to prevent full obscuration
    fog_fact = max(0.0, min(0.97, fog_raw))
    
    # Step 4: Blend colors
    # mix(a, b, t) = a * (1 - t) + b * t
    final_r = obj_color[0] * (1.0 - fog_fact) + fog_color[0] * fog_fact
    final_g = obj_color[1] * (1.0 - fog_fact) + fog_color[1] * fog_fact
    final_b = obj_color[2] * (1.0 - fog_fact) + fog_color[2] * fog_fact
    
    return (final_r, final_g, final_b)
```

**Parameters:**
- `FOG_DENSITY`: Typical values vary by implementation [S1, S2, S3, S4, unofficial]. [S1, unofficial] uses a generic constant. [S2, unofficial] uses $0.02$. [S3, unofficial] uses $0.00007$ with squared distance. [S4, unofficial] uses $0.000002$ with squared distance for water blending.
- `FOG_START`: Often $0.0$ (fog starts at camera) or a small positive value to avoid fog at the immediate foreground [S1, unofficial].
- `fogColor`: Often the sky color or a dark grey/blue (e.g., `vec3(0.03, 0.04, 0.06)`) [S1, S2, unofficial].

**Edge Cases and Pitfalls:**
- **Clamping:** If the fog factor reaches $1.0$, the scene is completely obscured by the fog color. Sources recommend clamping the factor to a maximum of $0.97$ to retain visibility of distant geometry [S1, unofficial].
- **Precision:** At very large distances, `exp(-large_number)` approaches zero, making `fogRaw` approach $1.0$ [S1, S2, S3, unofficial].
- **Squared vs Linear:** The choice between $e^{-k \cdot d}$ and $e^{-k \cdot d^2}$ significantly changes the falloff curve [S1, S2, S3, unofficial]. The squared variant requires a much smaller density coefficient than the linear variant [S2, S3, S4, unofficial].

## Subtopics

### [Fog Blending with Clouds](4123-fog-blending-with-clouds.md)
This method renders a cloud layer by mixing a fixed cloud color with the background (sky) color using distance-based exponential fog, outputting a semi-transparent result. It sets itself apart from siblings like [Height-based Fog with Directional In-scatter](4400-height-based-fog-with-directional-in-scatter.md) by avoiding per-sample fog calculations; instead, it computes a single weighted average depth for the ray passing through the cloud and applies the fog blend only at that specific depth. Choose it when rendering static cloud layers without per-particle volumetric scattering.

### [Height-based Fog with Directional In-scatter](4400-height-based-fog-with-directional-in-scatter.md)
This method simulates aerial perspective by adding a directional in-scatter term to a height-based fog model, making distant objects appear hazy and colored by the sky or sun while maintaining distance perception. Choose it when simulating realistic atmospheric scattering with directional lighting and vertical density gradients.

### [Linear Distance Fog](4409-linear-distance-fog.md)
Linear distance fog is a depth-cueing technique that attenuates surface brightness linearly with view distance, fading colors toward black with a brightness floor to simulate atmospheric density or limited visibility. Unlike [Exponential Fog (Beer-Lambert)](3968-exponential-fog-beer-lambert.md), which models physical light absorption via exponential decay, linear fog is a geometric approximation implemented with integer or fixed-point arithmetic for performance. Choose it when maximum performance is required and physical accuracy is secondary.

### Exponential Distance Fog
A variant used for rendering water planes with distance-based exponential fog and sRGB gamma correction to blend the water surface into the scene [S4, unofficial]. It calculates alpha using exponential falloff based on clip-space depth.

**Definition:** Renders a water plane with distance-based exponential fog and sRGB gamma correction to blend the water surface into the scene [S4, unofficial].

**Steps:**
1. Sample the texture color `tex_col` [S4, unofficial].
2. Expand gamma (linearize): `tex_col = pow(tex_col, 2.2)` [S4, unofficial].
3. Compute fog distance from clip-space depth: `fog_dist = gl_FragCoord.z / gl_FragCoord.w` [S4, unofficial].
4. Calculate alpha using exponential falloff: `alpha = mix(0.5, 0.0, 1.0 - exp(-0.000002 * fog_dist^2))` [S4, unofficial].
5. Compress gamma (re-apply sRGB): `tex_col = pow(tex_col, 1/2.2)` [S4, unofficial].
6. Output `vec4(tex_col, alpha)` [S4, unofficial].

**Formula:**
$$ \alpha = \text{mix}(0.5, 0.0, 1.0 - e^{-k \cdot d^2}) $$
where $d$ is fog distance and $k = 0.000002$ [S4, unofficial].

**Parameters:**
- `gamma`: `vec3(2.2)`, used for linear-to-sRGB conversion [S4, unofficial].
- `inv_gamma`: `vec3(1/2.2)`, used for sRGB-to-linear conversion [S4, unofficial].

**Pseudocode:**
```python
import math

def exponential_distance_fog_water(tex_color: tuple, fog_dist: float) -> tuple:
    """
    Renders a water plane with distance-based exponential fog and sRGB gamma correction.
    
    Args:
        tex_color: Sampled texture color (R, G, B) in sRGB space.
        fog_dist: Distance from camera (clip-space depth derived).
        
    Returns:
        Final color with alpha (R, G, B, A).
    """
    gamma = 2.2
    inv_gamma = 1.0 / 2.2
    k = 0.000002
    
    # Step 1: Expand gamma (linearize)
    tex_col_linear = [c ** gamma for c in tex_color]
    
    # Step 2: Calculate alpha
    # mix(0.5, 0.0, t) = 0.5 * (1 - t) + 0.0 * t = 0.5 * (1 - t)
    t = 1.0 - math.exp(-k * fog_dist * fog_dist)
    alpha = 0.5 * (1.0 - t)
    
    # Step 3: Compress gamma (re-apply sRGB)
    tex_col_srgb = [c ** inv_gamma for c in tex_col_linear]
    
    return (tex_col_srgb[0], tex_col_srgb[1], tex_col_srgb[2], alpha)
```

## Operating characteristics
- **Time Complexity:** $O(1)$ per pixel [G].
- **Memory Complexity:** $O(1)$ [G].
- **Strengths:** Physically plausible falloff for homogeneous media; simple to implement; effective for hiding far-clip artifacts and tiling [S3, unofficial].
- **Limitations:** Assumes uniform density; does not account for in-scattering or height variations [S1, S3, unofficial].
- **When to use:** Ideal for simple atmospheric haze, depth cueing in raymarched scenes, or blending transparent surfaces (like water) into the background [S1, S3, S4, unofficial].
- **When not to use:** When accurate volumetric scattering (in-scattering) is required, or when fog density varies with height or position [S1, S3, unofficial].

## Background
Exponential fog is based on the Beer-Lambert law for light attenuation in absorbing media [S1, unofficial]. In computer graphics, this is adapted as a depth-cueing technique to simulate atmospheric perspective [G]. The specific implementation using squared distance ($e^{-k \cdot d^2}$) is a common shader-based approximation that provides a sharper falloff than the linear exponent, often used in real-time rendering for aesthetic control [S2, S3, unofficial].
