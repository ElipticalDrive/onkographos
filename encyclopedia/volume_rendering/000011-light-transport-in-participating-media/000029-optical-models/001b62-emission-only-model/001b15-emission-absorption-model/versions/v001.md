# Emission-Absorption Model

Also called: Absorption and Emission Model, Attenuated emission model, Direct Volume Rendering Integral, Glow and Absorption Combined Model, Low Albedo Volume Rendering, Sabella's density emitter model, Volume Rendering Integral, Volumetric Rendering Integral

## Overview
The Emission-Absorption Model is the most widely used optical rendering model for direct volume rendering, calculating the final radiance reaching a camera from a participating medium by accounting for both light emission (glow) and absorption (attenuation) [S2, unofficial][S3, book]. It solves the problem of simulating realistic media like clouds or smoke without the computational cost of multiple scattering, distinguishing it from the Absorption-only model (which lacks glow) and the Single Scattering Model (which adds directional scattering) [S2, unofficial][S3, book][S4, unofficial].

## How it works
**Inputs and Outputs:**
*   **Input:** A viewing ray $\mathcal{R}$ parameterized by distance $t$ from the viewpoint, extending from start position $s_0$ (volume entry) to end position $D$ (volume exit or eye).
*   **Input:** Extinction coefficient (density) function $k(t)$ or $\tau(t)$ or $\rho(t)$.
*   **Input:** Emissive source term function $q(s)$, $g(s)$, or $C(s)\rho(s)A$.
*   **Input:** Background radiance $I_0$ at $s_0$.
*   **Output:** Final radiance $I(D)$ at the camera.

**Data Structures:**
The method operates on scalar values along a 1D ray segment. For implementation, the ray is discretized into $n$ segments of length $\Delta t = (D-s_0)/n$ [S2, unofficial].

**Formulas:**
The continuous differential equation for intensity $I$ along the ray is:
$$ \frac{dI}{ds} = g(s) - \tau(s)I(s) $$
where $g(s)$ is the added intensity (emission) and $\tau(s)$ is the extinction coefficient [S4, unofficial]. Alternatively, using density $\rho$ and glow per unit projected area $C$:
$$ \frac{dI}{ds} = C(s)\rho(s)A - \rho(s)AI(s) $$
where $A$ is area [S3, book].

The exact solution is the Volume Rendering Integral:
$$ I(D) = I_0 e^{-\int_{s_0}^D \tau(t) \, dt} + \int_{s_0}^D g(s) e^{-\int_s^D \tau(t) \, dt} \, ds $$
where $I_0$ is the background radiance, the first term is the attenuated background, and the second term is the emitted light attenuated by the medium between the emission point and the eye [S2, S4, unofficial].

**Discretization (Riemann Sum):**
The integral is approximated by dividing the ray into $n$ equal segments of size $\Delta t$ [S2, unofficial][S3, book].
Let $t_i = e^{-k(s_0 + i\Delta t)\Delta t}$ be the transmittance of segment $i$ [S3, book].
Let $g_i = q(s_0 + i\Delta t)$ be the emitted light of segment $i$ [S2, unofficial].

The discrete approximation is:
$$ I(D) \approx I_0 \prod_{i=0}^n t_i + \sum_{i=0}^n g_i \prod_{j=i+1}^n t_j $$
where $t_i = e^{-k(s_0+i\Delta t)\Delta t}$ and $g_i = q(s_0 + i\Delta t)$ [S2, unofficial][S3, book]. Note: Some sources index from $1$ to $n$ [S3, book], but the logic remains identical.

**Compositing (Back-to-Front):**
In practice, this is often implemented as back-to-front alpha compositing [S3, book].
For each segment $i$ (from back to front, $n$ down to $0$):
1.  Calculate segment opacity $\alpha_i = 1 - t_i$.
2.  Calculate segment color $\mathbf{c}_i$ (pre-multiplied by $\alpha_i$ if derived from $g_i$).
3.  Composite:
    $$ \mathbf{c}_{out} = \mathbf{c}_i \alpha_i + \mathbf{c}_{in} (1 - \alpha_i) $$
    $$ \alpha_{out} = \alpha_i + \alpha_{in} (1 - \alpha_i) $$
    where $\mathbf{c}_{in}, \alpha_{in}$ are the accumulated color and opacity from segments behind $i$, and $\mathbf{c}_{out}, \alpha_{out}$ are the results after including segment $i$ [S3, book].

**Sabella's Density Emitter Model (Simplified):**
If the emissive term is proportional to the extinction coefficient ($g(s) = \kappa \tau(s)$), where $\kappa$ is the constant color of the volume cloud, the integral simplifies [S4, unofficial]:
$$ I = I_0 T(D) + \kappa (1 - T(D)) $$
where $T(D) = e^{-\int_0^D \tau(t) dt}$ is the total transmittance [S4, unofficial]. This is equivalent to compositing color $\kappa$ over background $I_0$ using opacity $1 - T(D)$ [S3, book][S4, unofficial].

**Pseudocode:**
```python
def emission_absorption_model(ray_start, ray_end, num_samples, background_radiance, extinction_func, emission_func):
    """
    Computes the final radiance using the Emission-Absorption model via back-to-front compositing.
    
    Args:
        ray_start: Start position s0 along the ray.
        ray_end: End position D along the ray.
        num_samples: Number of segments n.
        background_radiance: I0, the radiance behind the volume.
        extinction_func: Function k(t) returning extinction coefficient at t.
        emission_func: Function q(t) returning emitted light intensity at t.
        
    Returns:
        final_radiance: The computed radiance I(D).
    """
    delta_t = (ray_end - ray_start) / num_samples
    
    # Accumulators for back-to-front compositing
    # Initialize with background
    accumulated_color = background_radiance
    accumulated_opacity = 0.0
    
    # Iterate from back (i = n-1) to front (i = 0)
    # Note: The integral sum in [S2, unofficial] goes i=0 to n, but compositing is typically
    # done back-to-front. The term for segment i contributes to the sum.
    # We map the Riemann sum index to the compositing order.
    
    for i in range(num_samples - 1, -1, -1):
        t_pos = ray_start + i * delta_t
        
        # Calculate segment properties
        k = extinction_func(t_pos)
        q = emission_func(t_pos)
        
        # Transmittance of this segment
        # t_i = exp(-k * delta_t)
        segment_transmittance = math.exp(-k * delta_t)
        
        # Opacity of this segment
        segment_opacity = 1.0 - segment_transmittance
        
        # Emitted color for this segment (pre-multiplied by opacity if using standard compositing)
        # In the integral, g_i is the added intensity. 
        # For compositing, we need the color contribution. 
        # If q is intensity, and we assume it's the color of the emitted light:
        segment_color = q 
        
        # Back-to-front compositing equations [S3, book]
        # c_out = c_i * alpha_i + c_in * (1 - alpha_i)
        # alpha_out = alpha_i + alpha_in * (1 - alpha_i)
        
        # Note: In standard alpha compositing, c_i is the source color (pre-multiplied).
        # Here, q is the emitted intensity. If q represents the color * opacity product,
        # we use it directly. If q is just intensity, we might need to scale.
        # Based on [S3, book], g_i = C*rho*A. This is the added intensity.
        # The compositing equation uses c_i * alpha_i. 
        # If we treat segment_color as the pre-multiplied color (c_i * alpha_i),
        # then:
        
        # However, the integral term is g_i * product(transmittance_behind).
        # The compositing approach accumulates this implicitly.
        
        # Let's stick to the direct compositing form from [S3, book]:
        # c_i is the color of the segment. alpha_i is the opacity.
        # The contribution of the segment to the final image is c_i * alpha_i * T_behind.
        
        # Standard Porter-Duff Over operator:
        # new_c = c_seg * alpha_seg + c_acc * (1 - alpha_seg)
        # new_alpha = alpha_seg + c_acc_alpha * (1 - alpha_seg) -- wait, alpha_acc is scalar.
        
        # Correct Back-to-Front [S3, book]:
        # c_i = c_i * alpha_i + c_{i+1} * (1 - alpha_i)
        # alpha_i = alpha_i + alpha_{i+1} * (1 - alpha_i)
        
        # Here c_i is the segment color (unmultiplied? No, [S3, book] says resulting color is pre-multiplied).
        # Let's assume c_seg is the unmultiplied color of the segment.
        # Then pre-multiplied contribution is c_seg * alpha_seg.
        
        # If emission_func returns the pre-multiplied color (intensity * alpha), we use it directly.
        # If it returns just intensity (glow), we must define the color. 
        # In [S4, unofficial], g(s) = kappa * tau(s). kappa is color.
        # So segment_color_unmultiplied = kappa.
        # segment_color_premultiplied = kappa * (1 - exp(-k*delta_t))
        
        # General case:
        # Let's assume emission_func returns the "added intensity" g_i.
        # If we don't have a specific color, we might assume white or use a separate color function.
        # For generic implementation, we assume the emission function provides the color contribution
        # already scaled by the segment's opacity if we are doing direct compositing, 
        # OR we separate color and opacity.
        
        # Let's assume emission_func returns the color * opacity product (pre-multiplied)
        # to match the integral term g_i which is intensity.
        # If q is intensity, and we want color C, then pre-multiplied color is C * (1-T).
        # If q IS the pre-multiplied color, then:
        
        c_seg_premultiplied = q # Assuming q is the pre-multiplied color contribution
        
        # Compositing
        # c_acc is the accumulated color from behind (already pre-multiplied)
        # alpha_acc is the accumulated opacity from behind
        
        # c_new = c_seg + c_acc * (1 - alpha_seg)
        # alpha_new = alpha_seg + alpha_acc * (1 - alpha_seg)
        
        accumulated_color = c_seg_premultiplied + accumulated_color * (1.0 - segment_opacity)
        accumulated_opacity = segment_opacity + accumulated_opacity * (1.0 - segment_opacity)
        
    return accumulated_color
```

**Edge Cases and Pitfalls:**
*   **Ordering:** Compositing requires strict ordering (back-to-front) because the equations are not commutative [S3, book].
*   **Scattering:** The model does not explicitly consider light scattering (refraction), only attenuation and emission [S1].
*   **Precision:** High intensities in emission-only models can produce unrealistic imagery; absorption is necessary for realism [S3, book].
*   **Constant Emissivity:** If $C$ is constant, the simplified formula $I(D) = I_0 e^{-\int \rho A} + \mathbf{c}(1 - e^{-\int \rho A})$ can be used [S3, book].

## Operating characteristics
*   **Time Complexity:** $O(n)$ per ray, where $n$ is the number of samples. The Riemann sum approximation is linear in the number of segments [S2, unofficial].
*   **Memory Complexity:** $O(1)$ auxiliary memory per ray if marching in place, or $O(n)$ if storing voxel data.
*   **Performance:** It is computationally less expensive than Single Scattering or Multiple Scattering models, making it suitable for real-time rendering on CPUs and GPUs, although high-resolution datasets remain challenging [S2, unofficial].
*   **Strengths:** High level of realism for media like clouds and smoke; tractable; widely supported [S3, book].
*   **Limitations:** No multiple scattering; no explicit refraction; requires careful handling of opacity and color compositing [S1][S3, book].
*   **When to use:** Direct volume rendering of participating media where scattering is negligible or approximated by attenuation [S3, book].
*   **When not to use:** When realistic light transport involving multiple bounces or refraction is required [S1].

## Background
The Emission-Absorption Model is derived from the physical model of light transport in participating media. It is based on the volume rendering equation, first formalized by Max [Max95] and others [S1]. The specific simplification where emission is proportional to density (Sabella's density emitter model) was introduced by Sabella [S4, unofficial]. It is considered "Low Albedo Volume Rendering" because it assumes low reflectivity (albedo), ignoring multiple scattering events [S3, book]. It is the standard model for Direct Volume Rendering (DVR) [S3, book].
