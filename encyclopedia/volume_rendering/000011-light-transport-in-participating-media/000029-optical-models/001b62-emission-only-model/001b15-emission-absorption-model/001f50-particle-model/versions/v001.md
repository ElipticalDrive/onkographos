# Particle Model

Also called: Simple Compositing Model, Identical Spherical Particle Model

## Overview
The Particle Model is a special case of the Emission-Absorption Model where the source term is defined as $g(s) = C(s) \tau(s)$, based on the assumption of identical spherical particles [S1, unofficial][S2]. It solves the volume rendering integral by simplifying it to a simple compositing equation when the color $C$ is constant along the ray [S1, unofficial][S2]. It sets itself apart from the general Emission-Absorption Model by enforcing a specific physical relationship between emission and absorption, and from the Point-Sampled Spectrum Model by assuming a continuous density field rather than discrete samples [S2].

## How it works
**Inputs and Outputs:**
*   Input: Background radiance $I_0$, total transparency $T(D)$, and constant color $C$.
*   Output: Final radiance $I(D)$.

**Data Structures:**
Not given in the sources. The model operates on scalar values along a ray.

**Formulas:**
The source term is defined as:
$$ g(s) = C(s) \tau(s) $$
where $\tau(s)$ is the extinction coefficient and $C(s)$ is the color [S1, unofficial][S2].

If $C$ is constant along the ray (or segment), the volume rendering integral simplifies to [S1, unofficial][S2]:
$$ I(D) = I_0 T(D) + C(1 - T(D)) $$
where $T(D) = \exp\left(-\int_0^D \tau(t) dt\right)$ is the total transparency [S1, unofficial][S2].

The opacity $\alpha$ is defined as:
$$ \alpha = 1 - T(D) $$
This represents the probability that a ray hits a particle and sees color $C$ [S1, unofficial][S2].

**Steps:**
1.  Calculate total transparency $T(D)$ from the extinction coefficient $\tau(s)$ along the ray [S1, unofficial][S2].
2.  Compute opacity $\alpha = 1 - T(D)$ [S1, unofficial][S2].
3.  Compute final radiance $I(D) = I_0 (1 - \alpha) + C \alpha$ [S1, unofficial][S2].

**Pseudocode:**
```python
def particle_model(I0, T_D, C):
    """
    Computes radiance using the Particle Model.
    
    Args:
        I0: Background radiance (scalar or vector).
        T_D: Total transparency along the ray segment [0, 1].
        C: Constant color of the particles (scalar or vector).
        
    Returns:
        Final radiance I(D).
    """
    # Opacity is the probability of hitting a particle
    alpha = 1.0 - T_D
    
    # Simple compositing: blend background with particle color
    # I(D) = I0 * T(D) + C * (1 - T(D))
    I_D = I0 * T_D + C * alpha
    
    return I_D
```

**Edge Cases and Pitfalls:**
*   If $I_0 = 0$ and $\tau$ is proportional to density $f$, the result resembles an X-ray negative (brightest where density is highest) but saturates at maximum intensity $C$ [S1, unofficial][S2].
*   The model assumes $C$ is constant. If $C$ and $\tau$ vary linearly, $g(s)$ becomes quadratic, requiring more complex analytic integration (Williams and Max) [S2].

## Subtopics

### General Emission-Absorption Model
Defines $g(s)$ independently of $\tau(s)$. Allows $g(s)$ to be non-zero when $\tau(s)$ is zero (transparent glowing gas) and remains linear if interpolated linearly, unlike the particle model where $g(s)$ is quadratic if $C$ and $\tau$ are linear. [General Emission-Absorption Model](927-emission-absorption-model.md)

### Point-Sampled Spectrum Model
Uses discrete samples rather than a continuous density field. [Point-Sampled Spectrum Model](3468-point-sampled-spectrum-model.md)

## Operating characteristics
*   **Time Complexity**: $O(1)$ per ray segment if $T(D)$ is precomputed. The compositing step is a simple blend.
*   **Memory Complexity**: $O(1)$ additional memory per ray.
*   **Strengths**: Computationally efficient; simplifies to standard alpha compositing.
*   **Limitations**: Assumes identical spherical particles; cannot model transparent glowing gas without infinite color intensity; saturation at $C$ limits dynamic range in high-density regions [S1, unofficial][S2].
*   **When to use**: When particles are assumed identical and color is constant; for fast approximations.
*   **When not to use**: When emission and absorption are decoupled or when linear interpolation of source terms is required [S2].

## Background
The Particle Model was introduced by Marc Levoy in "Optical Models for Direct Volume Rendering" (1990) [S1, unofficial][S2]. It is based on the derivation of the source term $g(s)$ for identical spherical particles [S1, unofficial][S2]. The model is widely used in direct volume rendering for its simplicity and connection to standard compositing algorithms [S1, unofficial][S2].
