# Homogeneous Media

Also called: Homogeneous Medium Density Integration, Homogeneous Volume, Homogeneous volume representation, Uniform Participating Medium, Uniform Volume

## Overview
Homogeneous Media is a volumetric representation where the participating medium has constant optical properties (density, absorption, scattering) throughout its entire volume [S3, unofficial]. It solves the problem of analytically integrating the density along a ray segment, allowing for closed-form solutions for transmittance and density accumulation without numerical quadrature [S3, unofficial]. It is distinguished from its siblings by its assumption of spatial uniformity, which enables exact integration of the density term $P(x)$ [S3, unofficial].

## How it works
### Inputs and Outputs
**Inputs:**
- Camera origin $\mathbf{c}$ (3D vector) [S3, unofficial].
- Ray direction $\boldsymbol{\omega}$ (normalized 3D vector) [G].
- Intersection point $\mathbf{x}$ on the scene geometry (3D vector) [G].
- Constant density factor $\varrho'$ (scalar, $\varrho' \ge 0$) [S3, unofficial].
- Extinction coefficient $\sigma_t$ (scalar), where $\sigma_t = \sigma_a + \sigma_s$ [S1, unofficial]. $\sigma_a$ is absorption, $\sigma_s$ is scattering [S1, unofficial].
- Geometric boundary object defining the volume extent [S2, unofficial].

**Outputs:**
- Transmittance $T_r(\mathbf{c}, \mathbf{x})$ from camera to intersection point [S1, unofficial].
- Integrated density $P(\mathbf{x}_{2D})$ along the ray segment [S3, unofficial].

### Data Structures
The volume is represented by a class `HomogeneousVolume` which inherits from `Object` [S2, unofficial].
- **Fields:**
  - `Object *boundary_`: Pointer to the enclosing geometric boundary [S2, unofficial].
  - `double density_`: The constant density value $\varrho'$ used in intersection and scattering calculations [S2, unofficial].
- **Constructor:** `HomogeneousVolume(Object *boundary, double density, Material *material)` [S2, unofficial].

### Formulas
1. **Integrated Density:** For a homogeneous medium, the particle density $\varrho(\mathbf{x}) = \varrho'$ is constant [S3, unofficial]. The integrated density $P$ along a line segment from camera $\mathbf{c}$ to point $\mathbf{x}$ is:
   $$ P(\mathbf{x}_{2D}) = \int_{\mathbf{c}}^{\mathbf{x}} \varrho(\mathbf{x}') \, d\mathbf{x}' = \varrho' \cdot D $$
   where $D = \|\mathbf{x} - \mathbf{c}\|$ is the Euclidean distance between the camera and the intersection point [S3, unofficial].

2. **Transmittance:** The transmittance $T_r$ from point $\mathbf{x}$ to $\mathbf{x}_t$ is:
   $$ T_r(\mathbf{x}, \mathbf{x}_t) = \exp(-\sigma_t t) $$
   where $t$ is the distance between $\mathbf{x}$ and $\mathbf{x}_t$, and $\sigma_t$ is the extinction factor [S1, unofficial].

### Parameters
- $\varrho'$: Constant density factor, $\varrho' \ge 0$ [S3, unofficial].
- $\sigma_a$: Absorption factor [S1, unofficial].
- $\sigma_s$: Scattering factor [S1, unofficial].
- $\sigma_t$: Extinction factor, $\sigma_t = \sigma_a + \sigma_s$ [S1, unofficial].
- `density_`: The value of $\varrho'$ stored in the volume object [S2, unofficial].

### Steps
1. **Ray-Volume Intersection:** Determine if the ray intersects the `boundary_` geometry [S2, unofficial].
2. **Distance Calculation:** Compute the distance $D$ from the camera origin $\mathbf{c}$ to the intersection point $\mathbf{x}$ along the ray direction $\boldsymbol{\omega}$: $D = \|\mathbf{x} - \mathbf{c}\|$ [S3, unofficial].
3. **Density Integration:** Calculate the integrated density $P$ using the constant density factor $\varrho'$: $P = \varrho' \cdot D$ [S3, unofficial].
4. **Transmittance Calculation:** Compute the transmittance from the camera to the intersection point using the extinction coefficient $\sigma_t$: $T_r = \exp(-\sigma_t \cdot D)$ [S1, unofficial].
5. **Scattering/Rendering:** Use the transmittance and density to modulate the radiance contribution from the medium in the emission-absorption model [S1, unofficial].

### Pseudocode
```python
import math

class HomogeneousVolume:
    def __init__(self, boundary, density, material):
        self.boundary = boundary
        self.density = density
        self.material = material

    def compute_transmittance(self, camera_origin, intersection_point):
        dx = intersection_point.x - camera_origin.x
        dy = intersection_point.y - camera_origin.y
        dz = intersection_point.z - camera_origin.z
        D = math.sqrt(dx*dx + dy*dy + dz*dz)
        sigma_t = self.material.sigma_a + self.material.sigma_s
        return math.exp(-sigma_t * D)

    def compute_integrated_density(self, camera_origin, intersection_point):
        dx = intersection_point.x - camera_origin.x
        dy = intersection_point.y - camera_origin.y
        dz = intersection_point.z - camera_origin.z
        D = math.sqrt(dx*dx + dy*dy + dz*dz)
        return self.density * D

    def intersect(self, ray_origin, ray_direction):
        # Sources do not provide the specific intersection algorithm for boundary_ [G]
        # Standard ray-primitive intersection logic applies here.
        return self.boundary.intersect(ray_origin, ray_direction)
```

### Edge Cases and Pitfalls
- **Zero Distance:** If the camera is at the intersection point ($D=0$), transmittance is $1.0$ and integrated density is $0.0$ [G].
- **Boundary Definition:** The volume is bounded by `boundary_`. If the ray does not intersect the boundary, the medium is not sampled [S2, unofficial].
- **Uniformity Assumption:** This method fails if the medium is not homogeneous [S3, unofficial].

### Subtopics
- **Exponential Medium:** A medium where density follows an exponential function, allowing analytical integration for altitude-dependent densities [S3, unofficial]. Choose when density varies exponentially with height.
- **Absorption Term Restriction:** Restricts absorption terms for performance or stability [S1, unofficial]. Choose when absorption is negligible or simplified.
- **Particle Model:** Represents medium as discrete particles [S2, unofficial]. Choose for sparse media or when particle-based scattering is required.
- **Point-Sampled Spectrum Model:** Uses point samples for spectral rendering [S3, unofficial]. Choose for spectral accuracy in participating media.

## Operating characteristics
- **Time Complexity:** $O(1)$ for transmittance and density calculation given the intersection point, as it involves only basic arithmetic and an exponential function [S1, S3, unofficial].
- **Memory Complexity:** $O(1)$ per volume instance, storing only boundary pointer, density, and material [S2, unofficial].
- **Performance:** Very fast due to closed-form solutions [S3, unofficial].
- **Strengths:** Exact integration and simple implementation [S3, unofficial].
- **Limitations:** Only applicable to uniform media [S3, unofficial].
- **When to Use:** Scenes with uniform fog, smoke, or clouds where density is constant [S1, S3, unofficial].
- **When Not to Use:** Scenes with spatially varying density, such as atmospheric gradients or volumetric textures [S3, unofficial].

## Background
The homogeneous medium model is a fundamental concept in volume rendering, often introduced as the simplest case of participating media [S3, unofficial]. It is widely used in educational contexts and real-time rendering for its simplicity and analytical tractability [S1, S3, unofficial]. The model is derived from the radiative transfer equation, assuming constant extinction coefficient [S1, unofficial].
