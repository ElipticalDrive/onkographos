# Objects as Volumes (OaV) Attenuation-Vacancy Relation

Also called: OaV Relation, Stochastic Surface Occupancy Model

## Overview
The Objects as Volumes (OaV) Attenuation-Vacancy Relation provides a theoretical framework interpreting the scene as a stochastic surface where occupancy $O$ is the probability of a point being occupied [S1]. It links the vacancy $v(\mathbf{x}) = 1 - O(\mathbf{x})$ (the probability that $\mathbf{x}$ is unoccupied) to the optical attenuation coefficient $\sigma(\mathbf{x}, \mathbf{w})$ used in standard volumetric rendering [S1]. This relation enables explicit surface extraction from continuous volumetric primitives by establishing a reciprocal exponential transport relationship between geometry and optics [S1].

## How it works
**Inputs:**
- Set of $N$ Gaussian primitives, each defined by opacity $\alpha_i \in [0, 1]$, mean $\mu_i \in \mathbb{R}^3$, and precision matrix $\Sigma_i^{-1} \in \mathbb{S}_{++}^3$ [S1].
- Set of training camera rays $\mathcal{T}_c$, where each ray is defined by origin $\mathbf{o}$ and direction $\mathbf{w} \in \mathcal{S}^2$ [S1].

**Outputs:**
- A vacancy field $v: \mathbb{R}^3 \rightarrow [0, 1]$, representing the probability that a point is outside the opaque volume [S1].
- An occupancy field $O(\mathbf{x}) = 1 - v(\mathbf{x})$ [S1].

**Data Structures:**
- **Gaussian Primitive:** Stores $\alpha_i, \mu_i, \Sigma_i^{-1}$ [S1].
- **Ray:** Stores $\mathbf{o}, \mathbf{w}$ [S1].
- **Vacancy Grid:** A 3D grid storing $v(\mathbf{x})$ values for mesh extraction [S1].

**Core Formula:**
The fundamental relation connects the vacancy $v(\mathbf{x})$ to the attenuation $\sigma(\mathbf{x}, \mathbf{w})$:

$$ \sigma(\mathbf{x}, \mathbf{w}) = |\mathbf{w} \cdot \nabla \log v(\mathbf{x})| $$

This holds under the reciprocity assumption:
$$ \sigma(\mathbf{x}, \mathbf{w}) = \sigma(\mathbf{x}, -\mathbf{w}) $$

**Vacancy Estimation via Transmittance Lower Bound:**
Direct integration of the vector field $\nabla \log v$ is sensitive to noise from non-oriented or hidden Gaussians [S1]. Instead, a robust lower bound is computed using training camera transmittance [S1].

1. For a query point $\mathbf{x} \in \mathbb{R}^3$, iterate over all training camera rays $(\mathbf{o}, \mathbf{w}) \in \mathcal{T}_c$ [S1].
2. For each ray, determine if it passes through $\mathbf{x}$ [S1]. If $\mathbf{x} = \mathbf{o} + t\mathbf{w}$ for some $t > 0$, compute the transmittance $T_{\mathbf{o},\mathbf{w}}(t)$ along the ray segment from $\mathbf{o}$ to $\mathbf{x}$ [S1].
3. The transmittance is calculated using the non-oriented Gaussian formulation for robustness against outlier Gaussians [S1]:
   $$ T_{\mathbf{o},\mathbf{w}}(t) = \prod_{i=1}^{N} (1 - \bar{G}_{\mathbf{o},\mathbf{w}}^{(i)}(t)) $$
   where $\bar{G}_{\mathbf{o},\mathbf{w}}^{(i)}(t)$ is the contribution of the $i$-th Gaussian at the intersection point, clipped to the ray segment [S1].
4. The vacancy estimate $v(\mathbf{x})$ is the maximum transmittance observed across all training rays passing through $\mathbf{x}$:
   $$ v(\mathbf{x}) \geq \max_{(\mathbf{o},\mathbf{w}) \in \mathcal{T}_c} \{ T_{\mathbf{o},\mathbf{w}}(t) : \mathbf{x} = \mathbf{o} + t\mathbf{w}, t > 0 \} $$

**Pseudocode:**

```python
import math

def dot(a, b):
    return sum(x * y for x, y in zip(a, b))

def norm_sq(a):
    return dot(a, a)

def compute_vacancy_lower_bound(x, gaussians, training_cameras):
    """
    Computes the lower bound of vacancy v(x) for a point x.
    
    Args:
        x: Query point in 3D space (list/tuple of 3 floats).
        gaussians: List of Gaussian primitives. Each element is a dict/object 
                   with attributes: alpha, mean, precision_matrix.
        training_cameras: List of training camera rays. Each element is a tuple 
                          (origin, direction).
    
    Returns:
        v_est: Estimated vacancy value in [0, 1].
    """
    max_transmittance = 0.0
    
    for origin, direction in training_cameras:
        # Vector from origin to x
        vec = [x[i] - origin[i] for i in range(3)]
        
        # Project vec onto direction to find t
        # t = (vec . direction) / (direction . direction)
        # Assuming direction is normalized, denominator is 1.
        t = dot(vec, direction)
        
        # Check if t is positive and x is approximately on the ray
        if t <= 0:
            continue
            
        # Check distance from ray to x (should be near zero)
        projection_point = [origin[i] + t * direction[i] for i in range(3)]
        dist_sq = norm_sq([projection_point[i] - x[i] for i in range(3)])
        if dist_sq > 1e-8: # [G] Tolerance for grid-based spatial queries
            continue 
        
        # Compute transmittance from origin to x along this ray
        transmittance = 1.0
        
        for gaussian in gaussians:
            # Calculate contribution of this Gaussian at point p = origin + t * direction
            # Using non-oriented formulation for robustness [S1]
            p = [origin[i] + t * direction[i] for i in range(3)]
            
            # Gaussian value at p
            # G_i(p) = alpha_i * exp(-0.5 * (p - mu_i)^T * Sigma_inv_i * (p - mu_i))
            diff = [p[i] - gaussian.mean[i] for i in range(3)]
            # Compute quadratic form: diff^T * Sigma_inv * diff
            temp = [sum(gaussian.precision_matrix[j][k] * diff[k] for k in range(3)) for j in range(3)]
            exponent = -0.5 * dot(diff, temp)
            g_val = gaussian.alpha * math.exp(exponent)
            
            # Clip g_val to [0, 1] to ensure valid probability
            g_val = max(0.0, min(1.0, g_val))
            
            transmittance *= (1.0 - g_val)
            
            # Early exit if transmittance is negligible
            if transmittance < 1e-6:
                break
        
        # Update maximum transmittance
        if transmittance > max_transmittance:
            max_transmittance = transmittance
            
    return max_transmittance
```

**Edge Cases and Pitfalls:**
- **Non-oriented Gaussians:** Direct integration of $\nabla \log v$ fails if Gaussians do not follow the oriented assumption, leading to noisy results [S1]. The transmittance lower bound is robust to this [S1].
- **Hidden/Floaters:** Gaussians trapped inside the volume or floaters can perturb direct integration [S1]. The lower bound method is robust because transmittance is non-decreasing and depends mainly on visible Gaussians [S1].
- **Holes:** Remaining holes in the Gaussian coverage can affect direct integration but are handled robustly by the max-transmittance approach [S1].

## Subtopics

### Vacancy Estimation via Transmittance Lower Bound
A specific implementation technique for computing the vacancy field $v(\mathbf{x})$ [S1]. Instead of integrating the gradient of the log-vacancy, it computes a lower bound by taking the maximum transmittance over all training camera rays passing through $\mathbf{x}$ [S1]. This method is chosen for its robustness to outlier Gaussians, floaters, and holes in the Gaussian coverage, as it relies on the non-decreasing nature of transmittance and primarily considers visible Gaussians [S1].

## Operating characteristics
- **Time Complexity:** Not given in the sources.
- **Memory Complexity:** Not given in the sources.
- **Strengths:** Provides a principled link between volumetric rendering and surface geometry [S1]. The lower bound estimation is robust to common artifacts in Gaussian Splatting (floaters, unoriented Gaussians) [S1].
- **Limitations:** The method assumes reciprocity of attenuation, which may not hold for all media [S1].

## Background
The Objects as Volumes (OaV) framework was introduced to bridge the gap between volumetric rendering (used in NeRF and 3DGS) and explicit surface representations [S1]. It interprets the scene as a stochastic surface, where occupancy is the probability of a point being occupied [S1]. This framework grounds the theoretical justification of Neural SDFs and links the vacancy to the attenuation of standard volumetric ray-marching [S1]. The specific application to 3D Gaussian Splatting for surface reconstruction was detailed in "From Blobs to Spokes: High-Fidelity Surface Reconstruction via Oriented Gaussians" [S1].
