# Absorption Term Restriction


## Overview
Absorption Term Restriction is an optical model simplification that restricts the volume density model to the absorption term [S1]. It removes absorption collisions from path simulation to reduce variance and the magnitude of outliers when the bounding function $\bar{\mu}$ does not tightly bound the total extinction coefficient $\mu_t(x)$ [S2]. It builds on the [Emission-Absorption Model](927-emission-absorption-model.md) by disabling absorption for non-emissive media.

## How it works
**Inputs and Outputs:**
- Input: Absorption coefficient $\mu_a(x)$, scattering coefficient $\mu_s(x)$, bounding function $\bar{\mu}$, and scene geometry [S2].
- Output: Radiance values for pixels [G].

**Data Structures:**
- **3D Texture Map:** Contains the integral of the absorption coefficient along the viewing ray segment [S1].
- **Probability Tables:** Normalization constants $c$ and probabilities $P_s(x_j)$ (scattering) and $P_n(x_j)$ (null collision) are stored and recomputed without the absorption term [S2].

**Steps:**
1. Initialize the total extinction coefficient $\mu_t(x) = \mu_a(x) + \mu_s(x)$ [S2].
2. Set the absorption probability $P_a(x_j) = 0$ to remove absorption collisions [S2].
3. Remove the absorption term from the normalization constant $c$ and recompute $P_s(x_j)$ and $P_n(x_j)$ [S2].
4. Trace rays through the volume, sampling collision types based on the recomputed $P_s$ and $P_n$ [S2].
5. Update radiance contributions on scattering events and continue on null collisions until termination [G].
6. Accumulate radiance contributions [G].

**Pseudocode:**
```python
def absorption_term_restriction(volume, mu_bar):
    # 1. Initialize total extinction coefficient
    mu_t = volume.mu_a + volume.mu_s
    # 2. Set absorption probability to zero
    P_a = 0.0
    # 3. Remove absorption from normalization constant c
    c = volume.mu_s + (mu_bar - mu_t)
    # 4. Recompute scattering and null-collision probabilities
    P_s = volume.mu_s / c
    P_n = (mu_bar - mu_t) / c
    # 5. Trace paths using recomputed probabilities
    # (Standard delta tracking loop with modified termination)
    # ...
    return radiance
```

**Formulas:**
The probability of a scattering event at position $x_j$ is:
$$ P_s(x_j) = \frac{\mu_s(x_j)}{c'} $$
The probability of a null collision is:
$$ P_n(x_j) = \frac{\bar{\mu} - \mu_t(x_j)}{c'} $$
where $c'$ is the updated normalization constant excluding absorption [S2].

**Parameters:**
- $\bar{\mu}$: The bounding function for the total extinction coefficient. It must bound $\mu_t(x)$ across all wavelengths if spectral tracking is used [S2].

**Edge Cases and Pitfalls:**
- **Increased Computational Cost:** Disabling absorption increases the computational cost because paths must be simulated longer to terminate via scattering or null collisions [S2].
- **Variance Reduction:** This technique reduces variance and the magnitude of outliers only if $\bar{\mu}$ does not tightly bound $\mu_t(x)$ [S2].
- **Non-Emissive Assumption:** The method is invalid for emissive media [S2].

## Subtopics

### Reduced Termination Rates for Non-Emissive Media
This variant targets non-emissive media by setting $P_a(x_j) = 0$ and redistributing the absorption probability among scattering and null-collision types [S2]. It recomputes $P_s(x_j)$ and $P_n(x_j)$ to reduce throughput upon these events, increasing path length but reducing variance and outlier magnitude when $\bar{\mu}$ is loose [S2].

## Operating characteristics
- **Time Complexity:** Increases compared to standard absorption-inclusive models because paths are longer [S2].
- **Memory Complexity:** Requires a 3D texture map containing the integral of the absorption coefficient for hardware implementations [S1].
- **Strengths:** Reduces variance and outlier magnitude when $\bar{\mu}$ is loose [S2].
- **Limitations:** Higher computational cost due to longer paths; invalid for emissive media [S2].
- **When to Use:** Rendering non-emissive volumes with loose bounding functions where variance reduction is critical [S2].
- **When Not to Use:** When the medium emits light or computational cost is the primary constraint [S2].
