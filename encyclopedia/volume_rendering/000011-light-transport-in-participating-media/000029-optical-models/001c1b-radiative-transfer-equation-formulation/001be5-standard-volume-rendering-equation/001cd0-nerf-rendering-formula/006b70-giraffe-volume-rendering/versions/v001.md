# GIRAFFE Volume Rendering

Also called: GIRAFFE composite function, GIRAFFE rendering pipeline

## Overview
GIRAFFE Volume Rendering is a multi-object volume rendering method that renders multiple object bounding boxes and a background plane simultaneously [S1, unofficial]. It solves the problem of compositional scene representation by using a composite function that handles multiple sigma (density) fields before standard alpha compositing [S1, unofficial]. It sets itself apart from standard NeRF rendering by explicitly managing discrete object instances via bounding boxes and supporting both max and weighted composition strategies for merging object features [S1, unofficial].

## How it works
**Inputs:**
- `n_boxes`: Number of object bounding boxes.
- `render_background`: Boolean flag indicating whether to render a background plane.
- `use_max_composition`: Boolean flag (default `False`) to choose between max composition and weighted composition [S1, unofficial].
- `sample_object_existance`: Boolean flag to enable random object existence masking during training [S1, unofficial].
- `last_dist`: Default distance for the last segment in weight calculation (default `1e10`) [S1, unofficial].
- `padd`: Padding value for bounding box boundary checks [S1, unofficial].
- `z_shape_obj`, `z_app_obj`: Latent codes for object shape and appearance [S1, unofficial].
- `background_generator`: Generator network for background features [S1, unofficial].
- `get_evaluation_points`: Function returning points `p_i` and rays `r_i` for object `i` [S1, unofficial].
- `get_evaluation_points_bg`: Function returning points `p_bg` and rays `r_bg` for background [S1, unofficial].
- `get_object_existance`: Function generating object existence masks [S1, unofficial].
- `dists`: Distances between sample points along the ray [S1, unofficial].

**Outputs:**
- `feat_map`: Final rendered feature map [S1, unofficial].

**Data Structures:**
- `sigma`: Tensor of shape `(n_boxes_or_bg, batch_size, n_points, n_steps)` [S1, unofficial].
- `feat`: Tensor of shape `(n_boxes_or_bg, batch_size, n_points, n_steps, feat_dim)` [S1, unofficial].

**Steps:**

1.  **Initialization**: Initialize empty lists `sigma_list` and `feat_list`.
2.  **Iteration Count**: Determine `n_iter = n_boxes` if not rendering background, else `n_boxes + 1` [S1, unofficial].
3.  **Loop**: Iterate `i` from `0` to `n_iter - 1`.
    4.  **Object Processing** (if `i < n_boxes`):
        -   Call `get_evaluation_points` to get `p_i`, `r_i` [S1, unofficial].
        -   Decode `z_shape_obj[:, i]`, `z_app_obj[:, i]` with `p_i`, `r_i` to get `feat_i`, `sigma_i` [S1, unofficial].
        -   **Training Noise**: If in training mode, add noise: `sigma_i += torch.randn_like(sigma_i)` [S1, unofficial].
        -   **Boundary Masking**: Create mask `mask_box = torch.all(p_i <= 1. + padd, dim=-1) & torch.all(p_i >= -1. - padd, dim=-1)` [S1, unofficial]. Set `sigma_i[mask_box == 0] = 0` [S1, unofficial].
    5.  **Background Processing** (if `i == n_boxes`):
        -   Call `get_evaluation_points_bg` to get `p_bg`, `r_bg` [S1, unofficial].
        -   Decode with `background_generator` to get `feat_i`, `sigma_i` [S1, unofficial].
        -   **Training Noise**: If in training mode, add noise [S1, unofficial].
    6.  **Append**: Append `feat_i`, `sigma_i` to `feat_list`, `sigma_list` [S1, unofficial].
7.  **Stacking**: Stack `sigma_list` into `sigma` of shape `(n_boxes_or_bg, batch_size, n_points, n_steps)` and apply ReLU: `sigma = F.relu(sigma)` [S1, unofficial]. Stack `feat_list` into `feat` [S1, unofficial].
8.  **Object Existence Masking** (if `sample_object_existance` is true):
    -   Generate object existence mask using `get_object_existance` [S1, unofficial].
    -   Concatenate ones for background to object existence mask [S1, unofficial].
    -   Reshape `sigma` and object existence mask to 1D [S1, unofficial].
    -   Set `sigma` to 0 where object existence is 0 [S1, unofficial].
    -   Reshape `sigma` back to original shape [S1, unofficial].
9.  **Composition**:
    -   Call `composite_function(sigma, feat)` to get `sigma_sum` and `feat_weighted` [S1, unofficial].
    -   Call `calc_volume_weights(dists, sigma_sum)` to get `weights` [S1, unofficial].
    -   Compute final feature map: `feat_map = torch.sum(weights.unsqueeze(-1) * feat_weighted, dim=-2)` [S1, unofficial].

**Composite Function:**
-   **Max Composition** (if `use_max_composition` is true):
    -   `sigma_sum = max_i(sigma_i)` [S1, unofficial].
    -   `feat_weighted = feat_i` where `i` is the index of the max sigma [S1, unofficial].
-   **Weighted Composition** (default):
    -   `w_sigma = sigma / sum(sigma)` [S1, unofficial].
    -   `sigma_sum = sum(sigma)` [S1, unofficial].
    -   `feat_weighted = sum(feat * w_sigma)` [S1, unofficial].
    -   **Pitfall Handling**: Division by zero in weighted composition denominator is handled by setting `denom_sigma` to `1e-4` if it equals 0 [S1, unofficial].

**Volume Weights Calculation:**
-   Formula: `alpha = 1 - exp(-sigma * dists)` [S1, unofficial].
-   Formula: `weights = alpha * prod_{j=0}^{i-1} (1 - alpha_j)` [S1, unofficial].
-   **Numerical Stability**: Add `1e-10` to `(1 - alpha)` in the cumulative product to prevent numerical instability [S1, unofficial].
-   **Last Segment**: Use `last_dist` (default `1e10`) for the last segment distance [S1, unofficial].

    n_iter = n_boxes if not render_background else n_boxes + 1

            sigma_i[~mask_box] = 0
        else:

            feat_i, sigma_i = background_generator(p_bg, r_bg)

    # Stacking
    sigma = F.relu(torch.stack(sigma_list, dim=0))
    feat = torch.stack(feat_list, dim=0)
    
    # Object existence masking
    if sample_object_existance:
        obj_existence = get_object_existance()
        # Concatenate ones for background
        bg_ones = torch.ones_like(obj_existence[:, :1])
        obj_existence = torch.cat([obj_existence, bg_ones], dim=1)
        
        # Reshape to 1D
        sigma_flat = sigma.reshape(-1)
        obj_existence_flat = obj_existence.reshape(-1)

        sigma_flat[obj_existence_flat == 0] = 0

            torch.ones_like(alpha[:, :, :1]),

## Operating characteristics
-   **Time Complexity**: Linear with respect to the number of boxes, background, points, and steps due to the stacking and composition operations [S1, unofficial].
-   **Memory Complexity**: Proportional to the number of boxes, background, points, steps, and feature dimension due to storing `sigma` and `feat` tensors [S1, unofficial].
-   **Strengths**: Allows for explicit manipulation of object existence and composition strategies (max vs. weighted) [S1, unofficial]. Handles multiple objects and background simultaneously [S1, unofficial].
-   **Limitations**: Requires careful handling of boundary conditions and numerical stability (e.g., adding `1e-10` to transmittance) [S1, unofficial]. The choice of composition strategy can affect the final appearance [S1, unofficial].
-   **When to use**: When rendering scenes with multiple distinct objects that need to be composited in a specific way, or when training with object existence masking [S1, unofficial].
-   **When not to use**: For simple single-object or background-only rendering where standard NeRF rendering is sufficient [S1, unofficial].

## Background
GIRAFFE Volume Rendering is part of the GIRAFFE (Generative Inverse Rendering via Adaptive Feature Fields) framework [S1, unofficial]. It extends the NeRF rendering formula to handle multiple objects and backgrounds [S1, unofficial]. The method was introduced in the GIRAFFE repository by autonomousvision [S1, unofficial].
