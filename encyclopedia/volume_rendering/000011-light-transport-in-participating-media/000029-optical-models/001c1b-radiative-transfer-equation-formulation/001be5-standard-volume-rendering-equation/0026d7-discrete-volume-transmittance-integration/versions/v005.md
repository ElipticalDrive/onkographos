# Discrete Volume Transmittance Integration

Also called: Transmittance Calculation, Transmittance Integration, Visibility function, Volume Rendering Integral (Transmittance), getTransmittance, step-wise optical depth, tau integration

## Overview
Discrete Volume Transmittance Integration computes the fraction of light that travels from a ray origin to a target point through a participating medium without being absorbed or scattered, by numerically integrating the extinction coefficient along the ray path [S1, S3, S4, unofficial]. It solves the problem of determining visibility or attenuation in heterogeneous media where the density varies spatially, which cannot be solved analytically using the simple Beer-Lambert law [S5, unofficial]. It sets itself apart from [Analytic Transmittance Integration](5116-analytic-transmittance-integration.md) by using fixed-step numerical summation rather than closed-form solutions, and from [Unbiased Line Integration](9583-unbiased-line-integration.md) by introducing bias through discretization to gain computational simplicity [S1, S3, S5, unofficial].

## How it works
**Inputs and Outputs:**
*   **Input:** Ray origin $\mathbf{o}$, ray direction $\mathbf{d}$ (normalized), start distance $t_{start}$, end distance $t_{end}$, extinction coefficient field $\sigma_t(\mathbf{x})$ (or density $\rho(\mathbf{x})$ scaled by extinction cross-section), and number of integration steps $N$ [S1, S3, S6, unofficial].
*   **Output:** Transmittance $T$, a scalar value in $[0, 1]$ representing the ratio of transmitted light [S1, S4, unofficial].

**Data Structures:**
*   **Extinction Field:** A 3D grid or texture storing $\sigma_t$ or $\rho$ at voxel centers. Access is typically trilinear or nearest-neighbor interpolated [S2, S3, unofficial].
*   **Accumulator:** A floating-point variable `tau` initialized to 0.0, storing the cumulative optical depth [S1, S3, unofficial].

**Numbered Steps:**
1.  **Ray Validation:** If the ray direction $\mathbf{d}$ has zero length, return $T=0$ or handle as invalid [S3, unofficial].
2.  **Bounds Intersection:** Calculate the intersection interval $[t_0, t_1]$ of the ray with the volume's bounding box (e.g., AABB) [S3, unofficial]. If no intersection, return $T=1$ (fully transparent) or 0 depending on convention (usually 1 for empty space, but some implementations return 0 if the volume is strictly defined within bounds and the ray misses) [S3, unofficial]. *Note: Source [S3, unofficial] states "returns 0 transmittance" if no intersection, implying the volume is opaque or the function assumes the ray must hit the volume to compute valid transmittance within it. However, physically, missing the volume means no attenuation, so $T=1$. We follow the source's explicit pitfall note but note the physical contradiction.* [S3, unofficial].
3.  **Step Size Calculation:** Compute the step size $\Delta t = (t_1 - t_0) / N$ [S1, S3, unofficial]. Some implementations apply an offset to $t_0$ to align samples with the grid [S3, unofficial].
4.  **Initialization:** Set `tau` = 0.0 [S1, S3, unofficial].
5.  **Integration Loop:** For $i$ from 0 to $N-1$:
    a. Calculate sample position: $\mathbf{p}_i = \mathbf{o} + (\mathbf{o} + \mathbf{d} \cdot (t_0 + i \cdot \Delta t)) \cdot \mathbf{d}$? No, simpler: $\mathbf{p}_i = \mathbf{o} + \mathbf{d} \cdot (t_0 + i \cdot \Delta t)$ [S1, S3, unofficial].
    b. Sample the extinction coefficient: $\sigma_i = \sigma_t(\mathbf{p}_i)$ [S1, S3, unofficial].
    c. Update optical depth: `tau` += $\sigma_i \cdot \Delta t$ [S1, S3, unofficial].
6.  **Exponentiation:** Compute transmittance $T = \exp(-\text{tau})$ [S1, S3, S4, unofficial].

**Formulas:**
The optical depth $\tau$ is approximated by the Riemann sum:
$$ \tau \approx \Delta t \sum_{i=0}^{N-1} \sigma_t(\mathbf{p}_i) $$
The transmittance is:
$$ T = e^{-\tau} $$
Where:
*   $\sigma_t(\mathbf{p}_i)$ is the extinction coefficient at sample point $\mathbf{p}_i$ [S3, S4, unofficial].
*   $\Delta t$ is the step length along the ray [S3, unofficial].
*   $N$ is the number of steps [S1, unofficial].

**Parameters:**
*   **StEPS (N):** The number of integration steps. A typical value is 16 [S1, unofficial]. Higher values increase accuracy but cost more [S3, unofficial].
*   **Step Size:** The distance between samples. In some implementations, this is a fixed global `gStepSize` multiplied by a factor (e.g., 2) [S3, unofficial].

**Edge Cases and Pitfalls:**
*   **Zero Ray Direction:** If $\|\mathbf{d}\| = 0$, the function should return immediately to avoid division by zero or invalid sampling [S3, unofficial].
*   **No Intersection:** If the ray does not intersect the volume bounds, behavior varies. Source [S3, unofficial] states it returns 0 transmittance, which physically implies the volume is opaque or the function is strictly for computing attenuation *within* a hit volume. Physically, missing the volume should yield $T=1$ [S3, unofficial].
*   **Precision:** For large optical depths, `tau` can become very large, causing $T$ to underflow to 0. Early termination can be used if `tau` exceeds a threshold (e.g., 10.0) [S2, unofficial].
*   **Heterogeneous vs Homogeneous:** Using the homogeneous Beer-Lambert law $L_y = L_x e^{-\mu |x-y|}$ for heterogeneous media is incorrect because it fails to account for cumulative attenuation variations along the path [S5, unofficial].

**Pseudocode:**
```python
def compute_transmittance(ray_origin, ray_direction, volume_bounds, extinction_field, num_steps):
    """
    Computes transmittance through a heterogeneous volume using discrete integration.
    
    Args:
        ray_origin (Vec3): Origin of the ray.
        ray_direction (Vec3): Normalized direction of the ray.
        volume_bounds (AABB): Axis-aligned bounding box of the volume.
        extinction_field (Function): Function sigma_t(point) returning extinction coefficient.
        num_steps (int): Number of integration steps (e.g., 16).
        
    Returns:
        float: Transmittance T in [0, 1].
    """
    # 1. Ray Validation
    if ray_direction.length() == 0:
        return 0.0  # Or handle error [S3, unofficial]

    # 2. Bounds Intersection
    t_min, t_max = volume_bounds.intersect(ray_origin, ray_direction)
    
    # If no intersection, return 1.0 (fully transparent) physically, 
    # but source [S3, unofficial] says return 0. We follow source [S3, unofficial] for consistency with its implementation note.
    if t_min is None or t_max is None:
        return 0.0  # [S3, unofficial]

    # 3. Step Size Calculation
    # Apply offset if necessary to align with grid [S3, unofficial]
    t_start = t_min
    t_end = t_max
    step_size = (t_end - t_start) / num_steps

    # 4. Initialization
    tau = 0.0

    # 5. Integration Loop
    for i in range(num_steps):
        # Calculate sample position
        # Source [S1, unofficial] uses i * step_size from p1. 
        # Source [S3, unofficial] iterates from t0 to t1.
        # We use the start of the interval for each step.
        t_sample = t_start + i * step_size
        pos = ray_origin + ray_direction * t_sample
        
        # Sample extinction coefficient
        sigma_t = extinction_field.sample(pos)
        
        # Update optical depth
        tau += sigma_t * step_size

    # 6. Exponentiation
    transmittance = exp(-tau)
    
    return transmittance
```

## Subtopics

### [Heterogeneous Medium Transmittance](4909-heterogeneous-medium-transmittance.md)
Computes transmittance between two points through a heterogeneous participating medium. It provides the geometric setup required before applying the discrete extinction summation and exponentiation logic of its parent, [Discrete Volume Transmittance Integration](3905-discrete-volume-transmittance-integration.md).

### [Analytic Transmittance Integration](5116-analytic-transmittance-integration.md)
Analytic Transmittance Integration computes radiance along a ray with floating-point accuracy by integrating the radiative transfer equation analytically over each segment where optical properties (extinction coefficient and emission) are constant. It sets itself apart from discrete summation methods (like Iteration A or standard ray marching) by solving the integral of the transmittance term exactly, which prevents significant accuracy loss when the optical depth $\tau \Delta s$ is large and transmittance varies significantly between samples.

### [Unbiased Line Integration](9583-unbiased-line-integration.md)
Unbiased Line Integration is a method for estimating the transmittance-weighted integral along a light ray in participating media, specifically designed to split primary rays and estimate contributions from both the volume and the surface boundary. It solves the problem of accurately computing the integral $C$ defined in the radiative transfer context without the bias introduced by fixed-step ray marching. Unlike [Analytic Transmittance Integration](5116-analytic-transmittance-integration.md) which relies on closed-form solutions, or [Heterogeneous Medium Transmittance](4909-heterogeneous-medium-transmittance.md) which may use different sampling strategies, this method uses transformed equidistant sampling to achieve smoothness approaching that of ray marching while remaining perfectly unbiased.

### [Discrete Volume Transmittance Integration > Discrete Radiance Step Integration](14606-discrete-volume-transmittance-integration-discrete-radiance-.md)
Discrete Radiance Step Integration computes the outgoing radiance after traversing a small step of length $ds$ through a participating medium with extinction coefficient $\sigma$ and emission coefficient $q$, given incoming radiance $I$. It serves as the core update kernel for the discrete radiative transfer equation, iteratively applying the transport equation along a single ray to compute final intensity from initial intensity, absorption coefficient, and source term. It is distinct from sibling methods like [Heterogeneous Medium Transmittance](4909-heterogeneous-medium-transmittance.md) and [Analytic Transmittance Integration](5116-analytic-transmittance-integration.md) by focusing on the per-step radiance update rather than just transmittance calculation, often employing a linear approximation for small optical depths to maintain precision.

### Heterogeneous Volume Absorption via Ray Marching
A technique for calculating the transmittance of a heterogeneous participating medium between an eye point and a surface intersection by discretely sampling the medium along the ray path, as an alternative to the analytical Beer-Lambert law used for homogeneous media [S5, unofficial]. For homogeneous media, transmittance is calculated analytically using $L_y = L_x e^{-\mu|x-y|}$ [S5, unofficial]. For heterogeneous media, ray marching is required [S5, unofficial]. Using the equation $L(x, \omega) = \tau(x,y)L_e(x,\omega)$ for heterogeneous absorption-only models is incorrect because it fails to account for the cumulative attenuation along the path, leading to incorrect images [S5, unofficial]. Homogeneous media allow analytical calculation, whereas heterogeneous media require discrete ray marching [S5, unofficial].

### Ray-marched Volume Attenuation with Summation
A method to compute light attenuation through a volume using a discrete sum of densities along a ray, replacing the continuous integral to account for line integrals through surfaces going to zero. It models the volume as a 'texel' model where each voxel contributes density [S6, unofficial]. For each voxel, a ray is marched from the center in direction $d$ until it leaves the volume, adding the density of each voxel hit scaled by the length of the ray that passed through it [S6, unofficial]. The formula is $T = e^{-r \sum_{t_{start}}^{t_{end}} \rho (e+td)}$ where $T$ is transparency, $r$ is a constant (implied extinction coefficient), $\rho$ is the 3D density function, $e$ is the ray origin, $d$ is the ray direction, and $t$ is the parameter along the ray [S6, unofficial]. The light is placed at infinity in the direction defined by vector $d$ [S6, unofficial].

## Operating characteristics
*   **Time Complexity:** $O(N)$, where $N$ is the number of integration steps per ray [S1, S3, unofficial].
*   **Memory Complexity:** $O(1)$ auxiliary memory per ray, plus the storage for the extinction field [S1, S3, unofficial].
*   **Measured Performance:** With $N=16$ steps, the method is computationally inexpensive per ray but can be slow if many rays are traced through dense volumes [S1, unofficial]. Performance scales linearly with $N$ [S3, unofficial].
*   **Strengths:** Simple to implement; handles heterogeneous media; robust [S1, S3, unofficial].
*   **Limitations:** Biased due to discretization; accuracy depends on $N$; may suffer from aliasing if $N$ is too low [S1, S3, unofficial].
*   **When to Use:** When high performance is needed and moderate accuracy is acceptable; for heterogeneous media where analytic solutions are not feasible [S1, S5, unofficial].
*   **When Not to Use:** When unbiased results are required (use [Unbiased Line Integration](9583-unbiased-line-integration.md)); when the medium is homogeneous (use [Analytic Transmittance Integration](5116-analytic-transmittance-integration.md) or Beer-Lambert law) [S5, S1, unofficial].

## Background
Discrete Volume Transmittance Integration is a fundamental technique in volume rendering, derived from the numerical integration of the Radiative Transfer Equation (RTE) [S1, S3, S4, unofficial]. It is widely used in computer graphics for rendering fog, smoke, and other participating media [S4, unofficial]. The method is often referred to as "ray marching" in the context of volume rendering [S5, unofficial]. It is a core component of many volume rendering pipelines, including those in neural radiance fields (NeRFs) [S4, unofficial].
