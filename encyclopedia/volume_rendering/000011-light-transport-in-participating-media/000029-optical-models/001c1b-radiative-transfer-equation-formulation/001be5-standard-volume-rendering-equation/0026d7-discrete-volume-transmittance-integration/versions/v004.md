# Discrete Volume Transmittance Integration

Also called: Transmittance Calculation, Transmittance Integration, Visibility function, Volume Rendering Integral (Transmittance), getTransmittance, step-wise optical depth, tau integration

## Overview
Discrete Volume Transmittance Integration computes the fraction of light that travels from a ray origin to a target point through a participating medium without being absorbed or scattered, by numerically integrating the extinction coefficient along the ray path [S1, S3, S4, unofficial]. It solves the problem of determining visibility or attenuation in heterogeneous media where analytical solutions (like the Beer-Lambert law for homogeneous media) are intractable [S5, unofficial]. It sets itself apart from [Analytic Transmittance Integration](5116-analytic-transmittance-integration.md) by using fixed-step numerical summation rather than closed-form integration, and from [Unbiased Line Integration](9583-unbiased-line-integration.md) by introducing bias via fixed discretization to gain computational simplicity [S1, S3, S5, unofficial].

## How it works
**Inputs:**
*   Ray origin $\mathbf{p}_0$ and direction $\mathbf{d}$ (normalized).
*   Integration interval $[t_{start}, t_{end}]$ defining the segment of the ray within the volume bounds [S3, unofficial].
*   Number of integration steps $N$ (typically 16) [S1, unofficial].
*   Extinction coefficient field $\sigma_t(\mathbf{p})$ (or density field $\rho(\mathbf{p})$ combined with mass extinction coefficient) [S1, S3, unofficial].

**Outputs:**
*   Transmittance $T$, a scalar value in $[0, 1]$ representing the ratio of transmitted light [S1, S4, unofficial].

**Data Structures:**
*   Accumulator $\tau$ (optical depth): Floating-point scalar, initialized to 0.
*   Sample position $\mathbf{p}_i$: 3D vector.
*   Step size $\Delta t$: Scalar, calculated as $(t_{end} - t_{start}) / N$ [S3, unofficial].

**Steps:**
1.  **Validate Ray:** If the length of the ray direction $\mathbf{d}$ is zero, return $T=0$ immediately to avoid division by zero or invalid sampling [S3, unofficial].
2.  **Determine Bounds:** Calculate the intersection interval $[t_0, t_1]$ of the ray with the volume bounds (e.g., AABB) [S3, unofficial]. If the ray does not intersect the volume, return $T=0$ (fully transparent/empty) [S3, unofficial].
3.  **Initialize:** Set optical depth accumulator $\tau = 0$ [S1, S3, unofficial].
4.  **Iterate Samples:** Loop for $i$ from $0$ to $N-1$:
    a. Calculate sample position along the ray: $\mathbf{p}_i = \mathbf{p}_0 + \mathbf{d} \cdot (t_0 + i \cdot \Delta t)$ [S1, S3, unofficial]. Note: Some implementations apply an offset to $t_0$ to align samples with the grid [S3, unofficial].
    b. Evaluate extinction coefficient $\sigma_t(\mathbf{p}_i)$ at the current position [S3, unofficial]. If using a density field $\rho$, compute $\sigma_t = \rho \cdot \mu_{ext}$ where $\mu_{ext}$ is the mass extinction coefficient [S1, S2, unofficial].
    c. Update optical depth: $\tau \leftarrow \tau + \sigma_t(\mathbf{p}_i) \cdot \Delta t$ [S1, S3, unofficial].
5.  **Compute Transmittance:** Calculate the final transmittance using the exponential of the negative optical depth:
    $$ T = e^{-\tau} $$
    [S1, S3, S4, unofficial].

**Pseudocode:**
```python
def compute_discrete_transmittance(ray_origin, ray_direction, t_start, t_end, num_steps, get_extinction):
    """
    Computes transmittance through a heterogeneous medium using discrete integration.
    
    Args:
        ray_origin (Vec3): Origin of the ray.
        ray_direction (Vec3): Normalized direction of the ray.
        t_start (float): Start distance of the integration interval.
        t_end (float): End distance of the integration interval.
        num_steps (int): Number of discrete steps (e.g., 16).
        get_extinction (function): Function that returns sigma_t at a given Vec3 position.
        
    Returns:
        float: Transmittance T in [0, 1].
    """
    # Pitfall: Check for zero-length direction
    if ray_direction.length() == 0:
        return 0.0

    # Pitfall: Check for no intersection (handled by caller usually, but if t_start > t_end, return 0)
    if t_start >= t_end:
        return 0.0

    # Step 3: Initialize optical depth
    tau = 0.0
    
    # Calculate step size
    step_size = (t_end - t_start) / num_steps
    
    # Step 4: Iterate
    for i in range(num_steps):
        # Calculate position: p_i = p0 + d * (t_start + i * step_size)
        # Note: Some implementations might use (i + 0.5) * step_size for mid-point sampling,
        # but the source notes specify i * step_size relative to start or similar linear progression.
        # We follow the explicit formula from [S1, unofficial]: pos = p1 + dir * (i * step_size) 
        # assuming p1 is the start of the interval.
        current_t = t_start + i * step_size
        pos = ray_origin + ray_direction * current_t
        
        # Evaluate extinction coefficient
        sigma_t = get_extinction(pos)
        
        # Accumulate optical depth: tau += sigma_t * step_size
        tau += sigma_t * step_size

    # Step 5: Exponentiate
    transmittance = exp(-tau)
    
    return transmittance
```

**Parameters:**
*   `num_steps` (STEPS): The number of integration steps. A typical value is 16 [S1, unofficial].
*   `step_size`: The distance between sample points. In some implementations, this is derived from a global `gStepSize` multiplied by a factor (e.g., 2) [S3, unofficial].

**Edge Cases and Pitfalls:**
*   **Zero Ray Direction:** If the ray direction vector has zero length, the function must return 0 immediately to prevent division by zero or invalid sampling logic [S3, unofficial].
*   **No Intersection:** If the ray does not intersect the volume bounds, the transmittance is 0 (fully transparent) [S3, unofficial].
*   **Precision:** For large optical depths, the transmittance approaches 0. Early-out optimizations (e.g., `if tm < TM_MIN: break`) are often used in shader implementations to save computation, though this introduces bias if not handled carefully [S2, unofficial].
*   **Heterogeneous vs Homogeneous:** Using the homogeneous Beer-Lambert law ($L_y = L_x e^{-\mu|x-y|}$) for heterogeneous media is incorrect because it fails to account for the cumulative, path-dependent attenuation variations [S5, unofficial].

## Subtopics

### [Heterogeneous Medium Transmittance](4909-heterogeneous-medium-transmittance.md)
Computes transmittance between two points through a heterogeneous participating medium. It provides the geometric setup required before applying the discrete extinction summation and exponentiation logic of its parent, [Discrete Volume Transmittance Integration](3905-discrete-volume-transmittance-integration.md).

### [Analytic Transmittance Integration](5116-analytic-transmittance-integration.md)
Analytic Transmittance Integration computes radiance along a ray with floating-point accuracy by integrating the radiative transfer equation analytically over each segment where optical properties (extinction coefficient and emission) are constant. It sets itself apart from discrete summation methods (like Iteration A or standard ray marching) by solving the integral of the transmittance term exactly, which prevents significant accuracy loss when the optical depth $\tau \Delta s$ is large and transmittance varies significantly between samples.

### [Unbiased Line Integration](9583-unbiased-line-integration.md)
Unbiased Line Integration is a method for estimating the transmittance-weighted integral along a light ray in participating media, specifically designed to split primary rays and estimate contributions from both the volume and the surface boundary. It solves the problem of accurately computing the integral $C$ defined in the radiative transfer context without the bias introduced by fixed-step ray marching. Unlike [Analytic Transmittance Integration](5116-analytic-transmittance-integration.md) which relies on closed-form solutions, or [Heterogeneous Medium Transmittance](4909-heterogeneous-medium-transmittance.md) which may use different sampling strategies, this method uses transformed equidistant sampling to achieve smoothness approaching that of ray marching while remaining perfectly unbiased.

#### Heterogeneous Volume Absorption via Ray Marching
A technique for calculating the transmittance of a heterogeneous participating medium between an eye point and a surface intersection by discretely sampling the medium along the ray path, as an alternative to the analytical Beer-Lambert law used for homogeneous media [S5, unofficial]. For homogeneous media, transmittance is calculated analytically using $L_y = L_x e^{-\mu|x-y|}$ [S5, unofficial]. For heterogeneous media, it requires ray marching [S5, unofficial]. A common pitfall is using the equation $L(x, \omega) = \tau(x,y)L_e(x,\omega)$ for heterogeneous absorption-only models, which is incorrect because it fails to account for cumulative attenuation along the path [S5, unofficial]. Homogeneous media allow analytical calculation, whereas heterogeneous media require discrete ray marching [S5, unofficial].

## Operating characteristics
*   **Time Complexity:** $O(N)$, where $N$ is the number of integration steps [S1, S3, unofficial].
*   **Memory Complexity:** $O(1)$ auxiliary space, excluding the storage for the extinction coefficient field [S1, S3, unofficial].
*   **Measured Performance:** Performance depends heavily on the cost of evaluating `get_extinction` (e.g., texture lookup vs. sparse voxel traversal) and the chosen $N$. Typical values for $N$ are around 16 [S1, unofficial].
*   **Scaling:** Linear scaling with the number of steps. Increasing $N$ improves accuracy but increases computational cost linearly.
*   **Strengths:** Simple to implement; works for arbitrary heterogeneous media where analytical integration is impossible; computationally inexpensive per step compared to stochastic methods [S1, S5, unofficial].
*   **Limitations:** Biased estimator due to fixed-step discretization; accuracy degrades if the extinction coefficient varies rapidly between samples (aliasing); requires careful handling of boundaries and zero-length rays [S3, S5, unofficial].
*   **When to use:** Standard volume rendering in neural radiance fields (NeRFs) and traditional ray marching where performance is prioritized over strict unbiasedness [S4, unofficial].
*   **When not to use:** When unbiased results are required (use [Unbiased Line Integration](9583-unbiased-line-integration.md)) or when the medium is homogeneous (use [Analytic Transmittance Integration](5116-analytic-transmittance-integration.md) or Beer-Lambert law) [S1, S5, unofficial].

## Background
The method is rooted in the numerical solution of the Radiative Transfer Equation (RTE) for participating media. The concept of transmittance as the exponential of the negative optical depth is derived from the Beer-Lambert law [S4, S5, unofficial]. The discrete integration approach is a standard technique in computer graphics for rendering fog, smoke, and neural density fields, where the medium properties are sampled at discrete points along a ray [S4, unofficial]. It is widely used in the rendering equation for volume rendering, particularly in the context of the emission-absorption model which neglects in-scattering for tractability [S4, unofficial].
