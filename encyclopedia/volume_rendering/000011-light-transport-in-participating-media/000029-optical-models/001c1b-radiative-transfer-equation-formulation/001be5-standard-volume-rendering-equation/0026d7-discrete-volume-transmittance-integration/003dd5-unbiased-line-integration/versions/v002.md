# Unbiased Line Integration

Also called: Transformed equidistant sampling for line integration, Transmittance-weighted line integral estimation, Unbiased line integration along a ray

## Overview
Unbiased Line Integration is a method for estimating the transmittance-weighted integral along a light ray in participating media, specifically designed to split primary rays and estimate contributions from both the volume and the surface boundary [S1]. It solves the problem of accurately computing the integral $C$ defined in the radiative transfer context without the bias introduced by fixed-step ray marching [S1]. Unlike biased ray marching, this method uses transformed equidistant sampling to achieve smoothness approaching that of ray marching while remaining perfectly unbiased [S1].

## How it works
**Inputs:**
- Ray origin $x$ and direction $\omega$ [S1].
- Maximum volume extinction coefficient $\sigma_t$ (assumed constant or an upper bound for the segment) [S1].
- Number of samples $n$ [S1].
- Surface contribution function $c_{\partial V}$ and volume contribution function $c_V$ [S1].

**Outputs:**
- Estimated integral value $C$ [S1].

**Data Structures:**
- No complex data structures are required. The method operates on scalar values and simple arrays for sample points [S1].

**Steps:**
1. **Determine Geometry:** Compute the surface intersection point $x_{\partial V} = h(x, -\omega)$ and the distance to the boundary $t_{\partial V} = \|x - x_{\partial V}\|$ [S1].
2. **Compute Probabilities:** Calculate the probability of interaction within the volume $p_V$ and the probability of hitting the surface $p_{\partial V}$ using the maximum extinction $\sigma_t$ and distance $t_{\partial V}$ [S1]:
   $$ p_V = 1 - e^{-\sigma_t t_{\partial V}} $$
   $$ p_{\partial V} = 1 - p_V $$
3. **Initialize Accumulator:** Estimate the surface contribution $c_{\partial V} = L(x_{\partial V}, \omega)$ and initialize the accumulator $C$ with the surface term [S1]:
   $$ C = p_{\partial V} \cdot c_{\partial V} $$
4. **Generate Sample Points:** Generate $n$ randomly shifted equidistant sample points $\Delta$ in the interval $[0, p_V)$ using a single uniform random number $\xi \in [0, 1)$ [S1]:
   $$ \Delta = \left\{ \frac{(k + \xi)p_V}{n} : k = 0, \dots, n-1 \right\} $$
5. **Sample Distances:** For each point in $\Delta$, use it as the initial random number for a random walk (Algorithm 1 from [Discrete Volume Transmittance Integration](3905-discrete-volume-transmittance-integration.md)) to obtain distances $t_1, \dots, t_n$ [S1].
6. **Accumulate Contributions:** For each $k = 1, \dots, n$, add the contribution to $C$ based on whether the sampled distance $t_k$ falls within the volume or exceeds the boundary [S1]:
   $$ C = C + \begin{cases} \frac{1}{n} \cdot p_V \cdot \frac{c(x-t_k\omega, \omega)}{\sigma_t(x-t_k\omega)}, & \text{if } t_k < t_{\partial V} \\ \frac{1}{n} \cdot p_V \cdot c_{\partial V}, & \text{else} \end{cases} $$

**Pseudocode:**
```python
import math
import random

def ray_surface_intersection(origin, direction):
    """Simple ray-box intersection returning the closest intersection point."""
    # Assume a unit box centered at origin for simplicity; returns origin + direction * t_min
    t_min = float('inf')
    for i in range(3):
        if abs(direction[i]) > 1e-8:
            t1 = (-0.5 - origin[i]) / direction[i]
            t2 = (0.5 - origin[i]) / direction[i]
            t_min = min(t_min, max(t1, t2))
        else:
            if origin[i] < -0.5 or origin[i] > 0.5:
                return None
    if t_min < 0:
        return None
    return [origin[i] + direction[i] * t_min for i in range(3)]

def unbiased_line_integration(x, omega, sigma_t_max, n, surface_contribution_func, volume_contribution_func):
    """
    Estimates the transmittance-weighted integral C along a ray.
    """
    # Step 1: Determine geometry
    x_partial_V = ray_surface_intersection(x, [-c for c in omega])
    if x_partial_V is None:
        return 0.0
    t_partial_V = math.sqrt(sum((x[i] - x_partial_V[i])**2 for i in range(3)))
    
    # Step 2: Compute probabilities
    p_V = 1.0 - math.exp(-sigma_t_max * t_partial_V)
    p_partial_V = 1.0 - p_V
    
    # Step 3: Initialize accumulator
    c_partial_V = surface_contribution_func(x_partial_V, omega)
    C = p_partial_V * c_partial_V
    
    # Step 4: Generate randomly shifted equidistant sample points
    xi = random.random()
    delta = [((k + xi) * p_V) / n for k in range(n)]
        
    # Step 5 & 6: Sample distances and accumulate contributions
    for prob_val in delta:
        # Standard exponential distance sampling [G]
        t_k = -math.log(1.0 - prob_val) / sigma_t_max
        
        if t_k < t_partial_V:
            # Volume contribution
            sample_pos = [x[i] - t_k * omega[i] for i in range(3)]
            sigma_t_sample = sigma_t_max  # Use max if constant, or evaluate sigma_t_func(sample_pos)
            c_V = volume_contribution_func(sample_pos, omega)
            contribution = (1.0 / n) * p_V * (c_V / sigma_t_sample)
        else:
            # Surface contribution (sampled distance exceeded boundary)
            contribution = (1.0 / n) * p_V * c_partial_V
            
        C += contribution
        
    return C
```

**Parameters:**
- $n$: The number of random walks/samples used to estimate the integral [S1].
- $\sigma_t$: The maximum volume extinction coefficient [S1].
- $t_{\partial V}$: The distance to the volume boundary [S1].

**Pitfalls:**
- Using purely random starting points for the random walks (Algorithm 1) can lead to poor distribution and slower convergence [S1]. The transformed equidistant sampling (Algorithm 2) is specifically designed to mitigate this [S1].

## Operating characteristics
**Time Complexity:** $O(n)$, where $n$ is the number of samples [S1]. Each sample requires one random walk and one evaluation of the contribution functions [S1].
**Memory Complexity:** $O(1)$ auxiliary space, excluding the storage for the input functions and the single random number $\xi$ [S1].
**Measured Performance:** In scenarios with a large set of point light sources, Algorithm 2 approaches the smoothness of ray marching with increasing homogeneity along the ray, while remaining perfectly unbiased [S1]. It performs well at low sampling rates compared to reference images computed with vast amounts of samples using Algorithm 1 [S1].
**Strengths:** Perfectly unbiased; better sample distribution than pure random sampling; smoothness approaches that of biased ray marching in homogeneous media [S1].
**Limitations:** Requires a random walk implementation (Algorithm 1) which may be complex to implement efficiently; performance depends on the efficiency of the underlying random walk algorithm [S1].
**When to use:** When unbiased estimation of transmittance-weighted integrals is required, especially in scenes with participating media where bias from ray marching is unacceptable [S1].

## Background
Unbiased Line Integration was introduced in the context of unbiased global illumination with participating media [S1]. It generalizes the one-dimensional integration along a ray to provide a generic and unbiased solution for splitting primary rays [S1]. The method was developed to address the limitations of biased ray marching and the inefficiency of pure random sampling (Algorithm 1) by introducing transformed equidistant sampling (Algorithm 2) [S1]. It is used in rendering algorithms that require accurate handling of participating media, such as those involving global illumination with point light sources [S1].
