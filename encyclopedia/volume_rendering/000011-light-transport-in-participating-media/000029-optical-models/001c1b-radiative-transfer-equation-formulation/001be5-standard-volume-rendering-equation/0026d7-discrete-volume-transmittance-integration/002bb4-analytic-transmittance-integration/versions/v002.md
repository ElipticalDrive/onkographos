# Analytic Transmittance Integration
Also called: Analytic segment integration, Exact segment integration, Iteration B
## Overview
Analytic Transmittance Integration computes radiance along a ray with floating-point accuracy by integrating the radiative transfer equation analytically over each segment where optical properties (extinction coefficient and emission) are constant [S1, book]. It sets itself apart from discrete summation methods (like Iteration A or standard ray marching) by solving the integral of the transmittance term exactly, which prevents significant accuracy loss when the optical depth $\tau \Delta s$ is large and transmittance varies significantly between samples [S1, book]. It builds on [Discrete Volume Transmittance Integration](3905-discrete-volume-transmittance-integration.md) by replacing the numerical approximation of the transmittance integral with a closed-form solution.
## How it works
**Inputs and Outputs:**
- Input: An array of $n$ segments along a ray. For each segment $i$ ($0 \le i < n$), the inputs are the extinction coefficient $\tau_i$, the emission coefficient $c_i$, and the geometric length $\Delta s_i$. A boundary term $B$ (transmitted radiance from behind the volume) is also required.
- Output: The accumulated radiance $E$ at the near end of the ray.

**Data Structures:**
- Arrays `tau`, `c`, `DeltaS` of size $n$, containing floating-point values for extinction, emission, and segment length respectively.
- Scalar `B` for background radiance.
- Scalars `E` (accumulator) and `T` (current transmittance).

**Steps:**
1. Initialize the accumulated radiance $E = 0$ and the current transmittance $T = 1$.
2. Iterate through each segment $i$ from $0$ to $n-1$:
   a. Compute the transmittance factor for the current segment: $F = \exp(-\tau_i \Delta s_i)$.
   b. Update the accumulated radiance: $E = E + T \cdot c_i \cdot (1 - F)$.
   c. Update the current transmittance: $T = T \cdot F$.
3. After the loop, add the contribution from the background: $E = E + T \cdot B$.

**Derivation:**
The method solves the integral for a single segment $[s_i, s_{i+1}]$ with constant $\tau_i$ and $c_i$. The contribution to radiance is:
$$ \int_{s_i}^{s_{i+1}} T(s_i) \tau_i c_i \exp(-\tau_i(s-s_i)) ds $$
where $T(s_i)$ is the transmittance entering the segment. Evaluating the integral:
$$ T(s_i) \tau_i c_i \left[ \frac{\exp(-\tau_i(s-s_i))}{-\tau_i} \right]_{s_i}^{s_{i+1}} = T(s_i) c_i (1 - \exp(-\tau_i \Delta s_i)) $$
This matches the update step $E = E + T \cdot c_i \cdot (1 - F)$ where $F = \exp(-\tau_i \Delta s_i)$.

**Pseudocode:**
```python
def analytic_transmittance_integration(tau, c, delta_s, B):
    """
    Computes radiance along a ray using analytic integration over segments.
    
    Args:
        tau: List[float], extinction coefficients for each segment.
        c: List[float], emission coefficients for each segment.
        delta_s: List[float], geometric lengths of each segment.
        B: float, background radiance transmitted through the volume.
        
    Returns:
        float, accumulated radiance E.
    """
    n = len(tau)
    E = 0.0
    T = 1.0
    
    for i in range(n):
        # F is the transmittance through the current segment i
        F = math.exp(-tau[i] * delta_s[i])
        
        # Add emitted and scattered light from segment i, attenuated by incoming transmittance T
        # The term (1 - F) represents the fraction of light emitted/scattered within the segment
        # that reaches the end of the segment.
        E = E + T * c[i] * (1.0 - F)
        
        # Update transmittance for the next segment
        T = T * F
        
    # Add the background radiance, attenuated by the total transmittance through all segments
    E = E + T * B
    
    return E
```

**Parameters:**
- $\tau_i$: Extinction coefficient. Must be non-negative.
- $c_i$: Emission coefficient.
- $\Delta s_i$: Geometric length of the segment.
- $B$: Background radiance.

**Edge Cases and Pitfalls:**
- If $\tau_i \Delta s_i$ is large, discrete summation (Iteration A) suffers from precision loss or underestimation because $T$ varies significantly. Analytic integration handles this correctly [S1, book].
- If $\tau_i = 0$, $F = 1$, and the term $(1-F)$ becomes 0, correctly contributing no emission from that segment (assuming no scattering source term is added separately).
- Precision: Using `exp` is standard. For very small $\tau_i \Delta s_i$, standard floating point is sufficient.

## Subtopics

### [Trapezoid-based Radiance Integration in Box Coordinates](9001-trapezoid-based-radiance-integration-in-box-coordinates.md)
Exactly integrates unoccluded single-scattering radiance in rectilinear box-shaped media with homogeneous density. It decomposes the intersection into trapezoid segments for closed-form evaluation.

### [Trapezoid Integration for Transmittance](9006-trapezoid-integration-for-transmittance.md)
Computes transmittance integrals in skewed coordinate systems where geometric path length varies non-linearly, handling box face intersections efficiently.

### [Analytically Integrable Participating Media Rendering](9088-analytically-integrable-participating-media-rendering.md)
Uses analytical integration of density functions (e.g., exponential) for quasi-heterogeneous media, enabling real-time performance by rescaling distances.

## Operating characteristics
- **Accuracy:** Higher than discrete Riemann sum methods (Iteration A) when $\tau \Delta s$ is large, as it avoids the error introduced by assuming constant transmittance over the segment [S1, book].
- **Complexity:** $O(n)$ where $n$ is the number of segments. Each step involves one exponential, one multiplication, and a few additions.
- **Memory:** $O(1)$ auxiliary space if processing segments sequentially, or $O(n)$ if storing segment parameters.
- **Strengths:** Floating-point accuracy for radiance accumulation; handles high optical depth segments without bias.
- **Limitations:** Requires segments to have constant optical properties. If properties vary within a segment, the segment must be subdivided.

## Background
The method is described as "Iteration B" in contrast to "Iteration A" (Riemann sum approximation) in the context of volume rendering integrals [S1, book]. It addresses the inaccuracy of discrete sampling when transmittance varies significantly between samples. The approach is foundational for methods that decompose volumes into constant-property segments, such as those using box coordinates or skewed systems for analytic integration.
