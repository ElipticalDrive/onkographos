# Joseph Discrete Integration Method (DIM)
Also called: dim::joseph
## Overview
The Joseph Discrete Integration Method (DIM) is a discrete integration technique for tomography that computes voxel contributions by stepping along the axis with the largest ray delta component and interpolating values in the orthogonal axes [S1, unofficial]. It avoids "shadowing non-zeros," a phenomenon where distinct rays sharing the same indices along the primary axis incorrectly overwrite or mask each other's contributions [S1, unofficial].
## How it works
### Inputs and outputs
- **Inputs**: A ray defined by a current point and a delta vector (`line`); a 3D volume grid (`volume_`) with known dimensions and margins; a slice volume (`slice_volume`) for interpolation; and a queue (`queue_`) to store intermediate results [S1, unofficial].
- **Outputs**: Updated queue entries containing interpolated voxel contributions extended with row indices [S1, unofficial].

### Data structures
- **Ray**: `line` contains `current_point` (3D vector) and `delta` (3D vector).
- **Volume**: `volume_` contains voxel dimensions (`voxels()`), margins, and accessors for `inside_margin`.
- **Queue**: `queue_` stores elements that are extended with slice indices.

### Steps
1. **Reset and Primary Axis Selection**: Determine the primary axis by finding the index of the maximum absolute component of the ray delta [S1, unofficial]:
   $$ \text{axis} = \operatorname{argmax}_i |\text{delta}[i]| $$
2. **Step Vector Calculation**: Calculate the step vector along the primary axis [S1, unofficial]:
   $$ \text{step} = \frac{\text{delta}}{|\text{delta}[\text{axis}]|} $$
3. **Initial Step to First Voxel Center**: Calculate the target coordinate for the first voxel center along the primary axis [S1, unofficial]:
   $$ \text{nearest\_column} = \operatorname{round}(\text{current\_point}[\text{axis}] - 0.5) + 0.5 $$
   Compute the displacement to this target and update the current point, adjusting direction based on the sign of `step[axis]` [S1, unofficial]:
   $$ \text{initial\_step} = \text{nearest\_column} - \text{current\_point}[\text{axis}] $$
   $$ \text{if } \text{step}[\text{axis}] > 0: \text{current\_point}[\text{axis}] \leftarrow \text{current\_point}[\text{axis}] + \text{initial\_step} $$
   $$ \text{else}: \text{current\_point}[\text{axis}] \leftarrow \text{current\_point}[\text{axis}] - \text{initial\_step} $$
4. **Backward Step to Margin Boundary**: Step backwards until the point is outside the volume margin [S1, unofficial]:
   $$ \text{while } \text{inside\_margin}(\text{current\_point} - \text{step}, \text{volume\_}, 1.0): \text{current\_point} \leftarrow \text{current\_point} - \text{step} $$
5. **Forward Iteration**: Iterate while the point is inside the volume margin [S1, unofficial]:
   a. **Calculate Row Index**: Determine the current row index along the primary axis [S1, unofficial]:
      $$ \text{current\_row} = \operatorname{round}(\text{current\_point}[\text{axis}] - 0.5) $$
   b. **Boundary Check**: Skip if the row index is out of bounds [S1, unofficial]:
      $$ \text{if } \text{current\_row} \ge \text{volume\_}. \text{voxels()}[\text{axis}] \text{ or } \text{current\_row} < 0: \text{current\_point} \leftarrow \text{current\_point} + \text{step}; \text{continue} $$
   c. **Interpolate and Queue**: Interpolate the restricted point into the slice volume, adding results to the queue [S1, unofficial]:
      $$ \text{interpolate}(\text{restrict}(\text{current\_point}, \text{axis}), \text{slice\_volume}, \text{queue\_}) $$
   d. **Extend Indices**: Update the indices of the newly added queue elements by extending the slice index with the current row [S1, unofficial]:
      $$ \text{extended\_slice\_index} = \text{extend}(\text{slice\_index}, \text{axis}, \text{current\_row}) $$
   e. **Advance Point**: Move to the next voxel center along the primary axis [S1, unofficial]:
      $$ \text{current\_point} \leftarrow \text{current\_point} + \text{step} $$

### Formula
The matrix value for a voxel is calculated as the product of the intersection lengths in the non-primary axes [S1, unofficial]:
$$ \text{value} = \prod_{i \neq \text{axis}} \max(0, 1 - |\text{in\_slice}[i] - \text{voxel\_center}[i]|) $$
Where:
- $\text{in\_slice}[i]$ is the coordinate of the ray in the non-primary axis $i$ within the slice [S1, unofficial].
- $\text{voxel\_center}[i]$ is the center coordinate of the voxel in axis $i$ [S1, unofficial].

### Parameters
- **Queue Size**: The queue size is reserved based on the maximum dimension size [S1, unofficial]:
  $$ \text{queue\_}. \text{reserve}(2 \times \text{max\_width}) $$
  Where $\text{max\_width}$ is the maximum element of the volume voxels [S1, unofficial].

### Pseudocode
```python
def joseph_discrete_integration(line, volume_, slice_volume, queue_, slice_index):
    # 1. Determine primary axis
    axis = max(range(len(line.delta)), key=lambda i: abs(line.delta[i]))

    # 2. Calculate step vector
    step = [d / abs(line.delta[axis]) for d in line.delta]

    # 3. Initial step to first voxel center
    nearest_column = round(line.current_point[axis] - 0.5) + 0.5
    initial_step = nearest_column - line.current_point[axis]

    if step[axis] > 0:
        line.current_point[axis] += initial_step
    else:
        line.current_point[axis] -= initial_step

    # 4. Step backwards to margin boundary
    while inside_margin([p - s for p, s in zip(line.current_point, step)], volume_, 1.0):
        line.current_point = [p - s for p, s in zip(line.current_point, step)]

    # 5. Iterate while inside margin
    while inside_margin(line.current_point, volume_, 1.0):
        current_row = round(line.current_point[axis] - 0.5)

        # Boundary check
        if current_row >= volume_.voxels()[axis] or current_row < 0:
            line.current_point = [p + s for p, s in zip(line.current_point, step)]
            continue

        # Interpolate and queue
        restricted_point = [line.current_point[i] for i in range(3) if i != axis]
        interpolate(restricted_point, slice_volume, queue_)

        # Extend indices
        extended_slice_index = slice_index[:axis] + [current_row] + slice_index[axis:]

        # Advance point
        line.current_point = [p + s for p, s in zip(line.current_point, step)]

def inside_margin(point, volume, margin):
    # Standard boundary check [G]
    for i in range(3):
        if point[i] < volume.origin[i] - margin or point[i] > volume.origin[i] + volume.size[i] + margin:
            return False
    return True

def interpolate(point, slice_vol, queue):
    # Bilinear interpolation on 2D slice [G]
    x, y = point[0], point[1]
    ix, iy = int(x), int(y)
    fx, fy = x - ix, y - iy
    v00 = slice_vol[iy][ix]
    v01 = slice_vol[iy][ix + 1]
    v10 = slice_vol[iy + 1][ix]
    v11 = slice_vol[iy + 1][ix + 1]
    val = (1 - fx) * (1 - fy) * v00 + fx * (1 - fy) * v01 + (1 - fx) * fy * v10 + fx * fy * v11
    queue.append(val)
```

### Edge cases and pitfalls
- **Shadowing Non-Zeros**: The method avoids shadowing non-zeros by stepping along the primary axis and interpolating in others, ensuring distinct rays do not incorrectly mask contributions [S1, unofficial].
- **Boundary Conditions**: Explicit checks for out-of-bounds row indices are required to prevent accessing invalid memory [S1, unofficial].
- **Precision**: Rounding operations for voxel centers and row indices are applied consistently in the implementation [S1, unofficial].
