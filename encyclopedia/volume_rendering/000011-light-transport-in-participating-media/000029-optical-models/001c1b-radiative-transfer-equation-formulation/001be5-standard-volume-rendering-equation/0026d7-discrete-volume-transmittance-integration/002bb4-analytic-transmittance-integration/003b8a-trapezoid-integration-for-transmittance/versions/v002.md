# Trapezoid Integration for Transmittance

Also called: Linear Segment Integration

## Overview
Trapezoid Integration for Transmittance computes the integral of transmittance over a linear segment within a skewed coordinate system, accounting for varying distances to the box boundary [S1]. It solves the problem of analytically integrating the radiative transfer equation over segments where optical properties are constant but the geometric path length through the medium varies non-linearly with respect to the camera ray parameter [S1]. It sets itself apart from standard constant-coefficient integration by handling the "skew" introduced by the intersection of a ray with a box face, allowing for efficient, closed-form evaluation without numerical quadrature [S1].

## How it works
**Inputs and Outputs:**
*   **Inputs:**
    *   $t_{C,S}$: Camera ray distance at the start of the segment.
    *   $t_{C,E}$: Camera ray distance at the end of the segment.
    *   $d_{E,S}$: Exit distance (distance to the box boundary along the light direction) at the start.
    *   $d_{E,E}$: Exit distance at the end.
    *   $\sigma_t$: Extinction coefficient (assumed constant over the segment).
    *   $t_{C,Surface}$: Distance to any occluding surface along the camera ray.
*   **Outputs:**
    *   $\mathcal{I}_{\text{trapezoid}}$: The integrated transmittance contribution over the segment.

**Data Structures:**
The method operates on scalar values representing ray parameters and optical properties [S1].

**Steps:**

1.  **Clamp End Distance:**
    Determine the effective end of the segment by clamping the geometric end distance $t_{C,E}$ against the surface occlusion distance $t_{C,Surface}$ and the start distance $t_{C,S}$ [S1].
    $$t_{C,B} = \text{clamp}(t_{C,E}, t_{C,S}, t_{C,Surface})$$
    If $t_{C,B} \le t_{C,S}$, the segment contributes zero transmittance [G].

2.  **Compute Slope $c$:**
    Calculate the slope of the skewed coordinate system, which accounts for the change in exit distance relative to the camera ray distance [S1]:
    $$c = 1 + \frac{d_{E,E} - d_{E,S}}{t_{C,E} - t_{C,S}}$$

3.  **Handle Degenerate Cases:**
    If the slope $c$ approaches zero ($|c| < \epsilon$) or the segment size is negligible ($t_{C,E} - t_{C,S} < \epsilon$), use the linear approximation to avoid numerical instability [S1]:
    $$T = (t_{C,B} - t_{C,S}) E_I$$
    where $E_I = e^{-(t_{C,S} + d_{E,S})\sigma_t}$ [S1]. Return $T$.

4.  **Compute Exponential Terms:**
    Calculate the precomputed exponential terms for efficiency [S1]:
    $$E_I = e^{-(t_{C,S} + d_{E,S})\sigma_t}$$
    $$E_u = e^{-\sigma_t (t_{C,B} - t_{C,S})^c}$$

5.  **Compute Integral:**
    Calculate the trapezoid integral using the derived formula [S1]:
    $$\mathcal{I}_{\text{trapezoid}} = E_I (1 - E_u)$$

**Pseudocode:**

```python
import math

def trapezoid_integration(t_c_s, t_c_e, d_e_s, d_e_e, sigma_t, t_c_surface):
    """
    Computes the transmittance integral over a linear segment in a skewed coordinate system.
    
    Args:
        t_c_s: Camera ray distance at start.
        t_c_e: Camera ray distance at end.
        d_e_s: Exit distance at start.
        d_e_e: Exit distance at end.
        sigma_t: Extinction coefficient.
        t_c_surface: Distance to occluding surface.
        
    Returns:
        Integrated transmittance contribution.
    """
    # Step 1: Clamp end distance
    t_c_b = min(max(t_c_s, t_c_e), t_c_surface)
    
    # If segment is invalid or zero length, return 0
    if t_c_b <= t_c_s:
        return 0.0

    # Step 2: Compute slope
    denom = t_c_e - t_c_s
    if abs(denom) < 1e-9:
        # Avoid division by zero in slope calculation
        c = 1.0 
    else:
        c = 1.0 + (d_e_e - d_e_s) / denom

    # Step 3: Handle degenerate cases (c -> 0 or small segment)
    segment_size = t_c_b - t_c_s
    
    # Precompute common exponential term E_I
    exponent_i = -(t_c_s + d_e_s) * sigma_t
    e_i = math.exp(exponent_i)
    
    # Check for linear approximation condition
    if abs(c) < 1e-9 or segment_size < 1e-9:
        return segment_size * e_i

    # Step 4: Compute E_u
    exponent_u = -sigma_t * (segment_size ** c)
    e_u = math.exp(exponent_u)
    
    # Step 5: Compute Integral
    integral_value = e_i * (1.0 - e_u)
    
    return integral_value
```

**Optimization Note:**
To reduce the number of exponential evaluations in consecutive segment evaluations, the product of the lower and upper bound parts ($E_I \cdot E_u$) can be extracted outside the evaluation loop and assigned as the lower bound part ($E_I$) for the next segment [S1].

## Subtopics

### Box Integration for Parallel/Opposite Vectors
Handles special cases where incident ($\tilde{\omega}_i$) and outgoing ($\tilde{\omega}_o$) light vectors are parallel or opposite, requiring separate solutions without traversing the box outline [S1].
*   **Opposite Vectors:** If $\tilde{\omega}_i \cdot \tilde{\omega}_o < 0$, the end distance is set to zero [S1]. Box transmittance is computed using trapezoid integration with parameters $(0, t_C, d_L, 0)$ [S1].
*   **Same Direction:** If vectors face the same direction, the end distance is the sum of distances to both exit points along the incident ($d_L$) and outgoing ($t_C$) vectors [S1]. Box transmittance is computed with parameters $(0, t_C, d_L, d_L + t_C)$ [S1].

### Gobo-Extended Integration
Extends integration to collimated light sources with a gobo (convex binary map or stencil) [S1].
*   **Method:** Offset the starting point of the integration to lie on the gobo edge and limit the integration to the far end of the gobo [S1]. The result is exponentially attenuated by the distance from the camera origin to the start of the gobo [S1].

## Operating characteristics
*   **Time Complexity:** $O(1)$ per segment, as it involves a constant number of arithmetic operations and exponential evaluations [S1].
*   **Memory Complexity:** $O(1)$, requiring only scalar storage for ray parameters and optical properties [S1].
*   **Strengths:** Provides an exact analytic solution for transmittance over skewed segments, avoiding the noise and convergence issues of Monte Carlo integration [S1]. It is compatible with distance sampling [S1].
*   **Limitations:** Requires careful handling of numerical edge cases (slope near zero, small segments) to maintain stability [S1]. Assumes homogeneous media within the segment [S1].
*   **When to Use:** When rendering participating media with homogeneous properties within bounding volumes (boxes) and high accuracy is required without stochastic noise [S1].

## Background
The method originates from the work on collimated whole volume light scattering in homogeneous finite media [S1]. It was developed to provide an efficient and accurate estimator for light transport in participating media, specifically addressing the challenges of shadowing and attenuation in complex geometries [S1]. The source compares this analytic approach against moment-based estimation, ratio estimation, and Monte Carlo integration [S1].
