# Analytically Integrable Participating Media Rendering

Also called: Quasi-heterogeneous media rendering, Real-Time Light Transport in Analytically Integrable Participating Media

## Overview
A real-time rendering method for participating media that uses analytical integration of density functions to handle quasi-heterogeneous media (e.g., exponential density with altitude), improving upon homogeneous approximations [S1, unofficial]. Unlike Elek et al. [2013] which approximates media as homogeneous, this method handles non-homogeneous media by analytically integrating density and rescaling distances [S1, unofficial]. Unlike Premože et al. [2004] which samples light paths at multiple points (taking minutes), this method uses analytical integration and rescaling for real-time performance [S1, unofficial]. Builds on [Analytic Transmittance Integration](5116-analytic-transmittance-integration.md) and contrasts with [Trapezoid-based Radiance Integration in Box Coordinates](9001-trapezoid-based-radiance-integration-in-box-coordinates.md) and [Trapezoid Integration for Transmittance](9006-trapezoid-integration-for-transmittance.md).

## How it works
**Inputs and Outputs**
*   **Inputs:**
    *   $L: \mathbb{N}^2 \rightarrow \mathbb{R}^3$: Input vacuum rendered image (radiance in a vacuum) [S1, unofficial].
    *   $D: \mathbb{N}^2 \rightarrow \mathbb{R}$: World-space distances from pixels to the camera [S1, unofficial].
    *   $\varrho(\mathbf{x})$: Density function of the medium, assumed to be analytically integrable (quasi-heterogeneous) [S1, unofficial].
    *   $C_a$: Absorption coefficient [S1, unofficial].
    *   $C_s$: Scattering coefficient [S1, unofficial].
    *   $C_t = C_a + C_s$: Total extinction coefficient [S1, unofficial].
*   **Outputs:**
    *   $L': \mathbb{N}^2 \rightarrow \mathbb{R}^3$: Final composited image with participating media effects [S1, unofficial].

**Data Structures**
*   $P: \mathbb{N}^2 \rightarrow \mathbb{R}$: Integrated density image [S1, unofficial].
*   $L_{\text{at}}: \mathbb{N}^2 \rightarrow \mathbb{R}^3$: Attenuated radiance image [S1, unofficial].
*   $L_{\text{sc}}: \mathbb{N}^2 \rightarrow \mathbb{R}^3$: Scattered radiance image [S1, unofficial].
*   $D': \mathbb{N}^2 \rightarrow \mathbb{R}$: Rescaled distance image [S1, unofficial].
*   $W: \mathbb{N}^2 \rightarrow \mathbb{R}$: Spreading width image [S1, unofficial].
*   $L_{\text{ssc}}: \mathbb{N}^2 \rightarrow \mathbb{R}^3$: Separated bright scattered radiance image [S1, unofficial].
*   MIP chains (pyramids) for $L_{\text{sc}}$, $W$, $D'$, and $L_{\text{ssc}}$, denoted as $L^{[0\dots K]}_{\text{sc}}$, $W^{[0\dots K]}$, $D'^{[0\dots K]}$, and $L^{[0\dots K]}_{\text{ssc}}$ [S1, unofficial].

**Steps**

1.  **Preprocessing: Integrated Density**
    Integrate the density $\varrho$ along camera rays to compute the integrated density image $P$ [S1, unofficial]. The integration is performed from the camera position towards the pixel's position in 3D space [S1, unofficial]:
    $$
    P(\mathbf{x}) = \int_{\text{camera}}^{\text{pixel } \mathbf{x}} \varrho(\mathbf{x}') \, d\mathbf{x}'
    $$
    [S1, unofficial]

2.  **Preprocessing: Attenuated and Scattered Radiance**
    Compute the attenuated radiance $L_{\text{at}}$ and scattered radiance $L_{\text{sc}}$ using the Beer-Lambert law and the integrated density $P$ [S1, unofficial]:
    $$
    L_{\text{at}} = \exp(-C_t \cdot P) \cdot L
    $$
    $$
    L_{\text{sc}} = \exp(-C_a \cdot P) \cdot (1 - \exp(-C_s \cdot P)) \cdot L
    $$
    [S1, unofficial]

3.  **Preprocessing: Distance Rescaling**
    Rescale world-space distances $D$ to rescaled distances $D'$ to support non-homogeneous media [S1, unofficial]. The method assumes that the ratio function can be approximated by the density function $\varrho'' \approx \varrho$, assuming a homogeneous medium density $\varrho' = 1$ [S1, unofficial]. This leads to the approximation $D' \approx P$ [S1, unofficial]:
    $$
    D' \approx P
    $$
    [S1, unofficial]

4.  **Preprocessing: Spreading Widths**
    Compute the spreading widths $W$ for the pixels' point spread functions using the rescaled distances $D'$ (or equivalently $P$) [S1, unofficial]. The spreading width function $W(D)$ is derived from the theory of Premože et al. [2004] but adapted for heterogeneous media via rescaling [S1, unofficial]:
    $$
    W(D') = W\left(\int_l \varrho''(\mathbf{x}) \, \mathrm{d}\mathbf{x}\right) \approx W\left(\int_l \varrho(\mathbf{x}) \, \mathrm{d}\mathbf{x}\right)
    $$
    Thus, $W = W(D') \approx W(P)$ [S1, unofficial].

5.  **Filtering: MIP Chain Construction**
    Build Gaussian MIP chains for the following images: $L^{[0\dots K]}_{\text{sc}}$ for scattered radiance, $W^{[0\dots K]}$ for luminance weighting, and $D'^{[0\dots K]}$ for depth blurring [S1, unofficial].

6.  **Filtering: Pixel Separation**
    Separate bright pixels from $L_{\text{sc}}$ to create $L_{\text{ssc}}$ and build a separate MIP chain $L^{[0\dots K]}_{\text{ssc}}$ for them [S1, unofficial]. This step reduces artifacts of the filtering approach [S1, unofficial].

7.  **Composition**
    Compose the final image $L'$ by interpolating pixels from the corresponding levels of the MIP pyramids ($L^{[0\dots K]}_{\text{sc}}$, $W^{[0\dots K]}$, $D'^{[0\dots K]}$, $L^{[0\dots K]}_{\text{ssc}}$) and adding an arbitrary emissive term for enhanced visual results [S1, unofficial].

**Pitfalls**
In heterogeneous media with density variation perpendicular to the light path, multiple-scattered rays may behave differently above and below the segment, violating the 2D Gaussian distribution assumption [S1, unofficial].

**Pseudocode**
```python
import math

def analytically_integrable_media_rendering(L, D, rho_func, C_a, C_s, K):
    """
    L: Input vacuum rendered image (H x W x 3)
    D: World-space distances (H x W)
    rho_func: Function returning density rho(x) for a given 3D point x
    C_a: Absorption coefficient
    C_s: Scattering coefficient
    K: Number of MIP levels
    """
    C_t = C_a + C_s
    H, W_img = len(L), len(L[0])
    
    # 1. Preprocessing: Integrated Density P
    P = [[0.0] * W_img for _ in range(H)]
    for y in range(H):
        for x in range(W_img):
            # Integrate density along camera ray to pixel (x,y) up to distance D[y][x]
            # The exact analytical formula depends on rho_func [G]
            # P[y][x] = integrate_density_along_ray(camera_origin, pixel_direction(x,y), D[y][x], rho_func)
            P[y][x] = 0.0  # Replace with analytical integral of rho along ray
            
    # 2. Preprocessing: Attenuated and Scattered Radiance
    L_at = [[0.0, 0.0, 0.0] for _ in range(H)]
    L_sc = [[0.0, 0.0, 0.0] for _ in range(H)]
    for y in range(H):
        for x in range(W_img):
            p = P[y][x]
            L_at[y][x] = [math.exp(-C_t * p) * c for c in L[y][x]]
            L_sc[y][x] = [math.exp(-C_a * p) * (1.0 - math.exp(-C_s * p)) * c for c in L[y][x]]
            
    # 3. Preprocessing: Distance Rescaling
    D_prime = P
    
    # 4. Preprocessing: Spreading Widths
    W = [[0.0] * W_img for _ in range(H)]
    for y in range(H):
        for x in range(W_img):
            # Spreading width formula from Premoze et al. [2004] adapted for rescaled distance [G]
            W[y][x] = compute_spreading_width(D_prime[y][x], C_s)
            
    # 5. Filtering: Pixel Separation
    L_ssc = [[0.0, 0.0, 0.0] for _ in range(H)]
    for y in range(H):
        for x in range(W_img):
            # Separate bright pixels based on luminance threshold [G]
            lum = 0.299 * L_sc[y][x][0] + 0.587 * L_sc[y][x][1] + 0.114 * L_sc[y][x][2]
            if lum > 0.5:
                L_ssc[y][x] = L_sc[y][x]
                
    # 6. Filtering: MIP Chain Construction
    mip_sc = build_mip_chain(L_sc, K)
    mip_W = build_mip_chain(W, K)
    mip_D = build_mip_chain(D_prime, K)
    mip_ssc = build_mip_chain(L_ssc, K)
    
    # 7. Composition
    L_prime = [[0.0, 0.0, 0.0] for _ in range(H)]
    for y in range(H):
        for x in range(W_img):
            # Interpolation from MIP pyramids based on W and D' [G]
            L_prime[y][x] = compose_from_mips(mip_sc, mip_W, mip_D, mip_ssc, x, y)
            # Add arbitrary emissive term [S1, unofficial]
            L_prime[y][x] = [c + 0.0 for c in L_prime[y][x]]
            
    return L_prime

def build_mip_chain(image, K):
    """Builds a Gaussian MIP chain of K levels for the given image."""
    mip_chain = [image]
    current = image
    for _ in range(K):
        h, w = len(current), len(current[0])
        next_h, next_w = h // 2, w // 2
        if next_h == 0 or next_w == 0:
            break
        next_img = [[0.0] * next_w for _ in range(next_h)]
        for y in range(next_h):
            for x in range(next_w):
                # Average 2x2 block
                val = (current[2*y][2*x] + current[2*y][2*x+1] + 
                       current[2*y+1][2*x] + current[2*y+1][2*x+1]) / 4.0
                next_img[y][x] = val
        mip_chain.append(next_img)
        current = next_img
    return mip_chain

def compute_spreading_width(D_prime, C_s):
    """Computes spreading width W based on rescaled distance D_prime and scattering coefficient C_s."""
    # Exact formula from Premoze et al. [2004] adapted for rescaled distance [G]
    return D_prime * C_s

def compose_from_mips(mip_sc, mip_W, mip_D, mip_ssc, x, y):
    """Composes a single pixel by interpolating from MIP pyramids."""
    # Interpolation logic selects appropriate MIP level based on W and D' [G]
    return mip_sc[0][y][x]
```

## Operating characteristics
*   **Time Complexity:** Real-time performance is claimed, significantly faster than sampling-based methods like Premože et al. [2004] which take minutes [S1, unofficial]. The filtering and composition steps are efficient due to the use of MIP chains and interpolation [S1, unofficial].
*   **Strengths:** Handles quasi-heterogeneous media (e.g., exponential density) in real-time, which is an improvement over homogeneous approximations [S1, unofficial].
*   **Limitations:** The method relies on the assumption that the density function is analytically integrable. It may introduce errors in heterogeneous media where density varies significantly perpendicular to the light path, as the 2D Gaussian distribution assumption may be violated [S1, unofficial].
*   **When to use:** Suitable for real-time rendering of participating media with quasi-heterogeneous density distributions where visual quality is important but full path tracing is too slow [S1, unofficial].
*   **When not to use:** Not suitable for media with arbitrary, non-analytically integrable density functions or where high accuracy in complex heterogeneous media is required [S1, unofficial].

## Background
The approach is based on Elek et al. [2013] with improvements for non-homogeneous media and pixel separation [S1, unofficial]. It extends the theory of Premože et al. [2004] [S1, unofficial]. The method was developed to address the limitations of homogeneous media approximations and the high computational cost of sampling-based methods [S1, unofficial].
