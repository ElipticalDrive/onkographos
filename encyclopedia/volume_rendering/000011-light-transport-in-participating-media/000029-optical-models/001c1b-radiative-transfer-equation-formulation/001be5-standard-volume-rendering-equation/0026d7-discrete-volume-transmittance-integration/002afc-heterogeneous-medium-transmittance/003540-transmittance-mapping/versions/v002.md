# Transmittance Mapping

Also called: Moment-based Transmittance Approximation, Moment-based transmittance mapping, TM-n

## Overview
Transmittance Mapping is a differentiable method for approximating volume transmittance (visibility) using bounds derived from the theory of moments [S1]. It solves the problem of computing visibility in inverse rendering tasks, such as pose recovery and 3D reconstruction, where gradients with respect to scene parameters are required [S1]. Unlike shadow mapping variants, which fail in empty space and suffer from geometric inaccuracies, Transmittance Mapping provides a principled, volume-based approximation that correctly reports constant 1 transmittance in free space while maintaining efficiency comparable to shadow mapping [S1]. It builds on [Heterogeneous Medium Transmittance](4909-heterogeneous-medium-transmittance.md) by providing a differentiable, moment-based approximation of the transmittance integral [S1].

## How it works
**Inputs:**
*   Density field $\sigma(\mathbf{r})$ [S1].
*   Camera ray $\mathbf{r}(t) = \mathbf{o} + t\mathbf{d}$ [S1].
*   Light source position (point light assumed) [S1].

**Outputs:**
*   Approximated visibility $V$ along the ray [S1].
*   Gradient of $V$ with respect to scene parameters (e.g., pose, density) [S1].

**Data Structures:**
*   **Transmittance Map:** A 2D texture storing $2n + 1$ values (moments $m_0, \dots, m_{2n}$) per pixel [S1]. The resolution determines spatial accuracy; coarse resolutions miss small structures [S1].

**Parameters:**
*   **Order $n$:** Integer $\ge 1$ determining the number of moments ($2n + 1$) [S1]. Higher orders increase accuracy but raise computational cost and numerical instability risks [S1]. Typical values range from 1 to 5 [S1].
*   **Density Scaling $s$:** Controls the spread of volume density spikes, typically applied to implicit surfaces via $\sigma(\mathbf{r}(t)) = \phi_s(g(\mathbf{r}(t)))$ [S1]. Optimized from low to high values to balance gradient density and surface localization [S1].
*   **Blending Parameter $\beta$:** Scalar $\in [0, 1]$ blending between lower and upper bounds [S1].

**Steps:**
1.  **Moment Integration:** Compute moments $m_k = \int_0^\infty z^k \sigma(\mathbf{r}(z)) \, dz$ for $k = 0, \dots, 2n$ [S1].
2.  **Bound Construction:** Construct lower bound $L(t)$ and upper bound $U(t)$ for the absorbance $A(t) = -\ln T(t) = \int_0^t \sigma(\mathbf{r}(z)) \, dz$ using moment theory [S1].
3.  **Transmittance Approximation:** Blend the bounds to approximate transmittance: $T(t) \approx \exp\left(-((1-\beta)L(t) + \beta U(t))\right)$ [S1].
4.  **Visibility Integration:** Compute visibility $V = \int_0^\infty \sigma(\mathbf{r}(t)) T(t) \, dt$ [S1]. A direction-dependent normalization factor is omitted for brevity [S1].
5.  **Gradient Propagation:** Compute gradients of $V$ with respect to scene parameters using automatic differentiation, leveraging the continuous differentiability of the moment bounds [S1].

**Pseudocode:**
```python
import math

def transmittance_mapping(ray_origin, ray_direction, density_field, density_scaling, order_n, light_position, beta):
    """
    Approximates volume transmittance and visibility using moment-based bounds.
    
    Args:
        ray_origin: 3D vector, camera ray origin.
        ray_direction: 3D vector, camera ray direction.
        density_field: Callable, returns density sigma at 3D point.
        density_scaling: Float, parameter s controlling density spikes.
        order_n: Int, order of moment approximation (n).
        light_position: 3D vector, position of the point light.
        beta: Float, blending parameter in [0, 1].
        
    Returns:
        visibility: Float, approximated visibility V.
    """
    # 1. Compute moments m_k = integral_0^inf z^k * sigma(r(z)) dz
    # [G] Numerical quadrature along the ray from 0 to max_distance.
    max_distance = 100.0
    num_samples = 256
    dz = max_distance / num_samples
    moments = [0.0] * (2 * order_n + 1)
    
    for k in range(2 * order_n + 1):
        integral = 0.0
        for i in range(num_samples):
            z = (i + 0.5) * dz
            point = ray_origin + ray_direction * z
            sigma = density_field(point, density_scaling)
            integral += (z ** k) * sigma * dz
        moments[k] = integral

    # 2. Construct lower bound L(t) and upper bound U(t) for absorbance A(t).
    # [G] The sources state bounds are derived from moment theory and are continuously differentiable,
    #     but do not specify the exact polynomial root-finding or Hankel matrix solver.
    #     Standard implementations solve the truncated moment problem to find valid bounding functions.
    L_t = construct_lower_bound(moments, order_n)
    U_t = construct_upper_bound(moments, order_n)

    # 3. Evaluate transmittance approximation T(t) = exp(-((1-beta)*L(t) + beta*U(t)))
    # [G] For visibility integration, we evaluate T(t) at quadrature points.
    visibility_integral = 0.0
    for i in range(num_samples):
        z = (i + 0.5) * dz
        point = ray_origin + ray_direction * z
        sigma = density_field(point, density_scaling)
        
        # Evaluate bounds at t = z
        L_val = L_t(z)
        U_val = U_t(z)
        
        # Approximate transmittance
        absorbance_approx = (1.0 - beta) * L_val + beta * U_val
        T_t = math.exp(-absorbance_approx)
        
        visibility_integral += sigma * T_t * dz

    return visibility_integral

def construct_lower_bound(moments, order_n):
    """Returns a callable L(t) for the lower absorbance bound."""
    # [G] Placeholder for the specific moment-problem solver.
    # In practice, this solves a constrained optimization or polynomial root-finding problem
    # to ensure L(t) <= A(t) for all t >= 0.
    def L(t):
        # Simplified linear bound for demonstration; real implementation uses moment matrices.
        return moments[0] * t
    return L

def construct_upper_bound(moments, order_n):
    """Returns a callable U(t) for the upper absorbance bound."""
    # [G] Placeholder for the specific moment-problem solver.
    # Ensures U(t) >= A(t) for all t >= 0.
    def U(t):
        # Simplified linear bound for demonstration; real implementation uses moment matrices.
        return moments[0] * t
    return U
```

**Edge Cases and Pitfalls:**
*   **Empty Space:** Shadow mapping fails in empty space because it is not volume-based; Transmittance Mapping correctly reports constant 1 transmittance [S1].
*   **Numerical Instability:** Higher-order moments lead to ill-conditioned matrices and difficult polynomial root finding; implementations must be designed around these constraints [S1].
*   **Light Source Assumptions:** The approach assumes point lights; area lights or image-based lighting are not supported [S1].
*   **Resolution Dependence:** If the transmittance map is too coarse, small structures are missed; memory requirements increase with resolution [S1].
*   **Singularity Handling:** Automatic differentiation implementations may generate undefined outputs and gradients if the query point is close to a singularity [S1].

## Operating characteristics
*   **Time Complexity:** Equally efficient as shadow mapping, approximately 4× faster than shadow rays [S1].
*   **Memory Complexity:** Reasonable memory consumption; e.g., 10.55 GiB peak for 190x256 pixel views using 128 samples in multi-view 3D reconstruction [S1]. Memory increases with map resolution [S1].
*   **Performance:** In pose recovery tasks, TM-5 achieved a translation error ($\Delta t$) of 0.07 and Hausdorff distance ($D_H$) of 0.09, compared to Tiwary et al.'s 0.50 and 0.33 respectively [S1]. In multi-view 3D reconstruction, TM-3 maintained a performance of one iteration per second [S1].
*   **Strengths:** More accurate than shadow mapping variants (Tiwary et al., VSM); handles free space correctly; differentiable; equally efficient as shadow mapping [S1].
*   **Limitations:** Numerical instability for higher orders; not supported for area lights or image-based lighting; quality depends on spatial discretization [S1].
*   **When to Use:** Differentiable shadow mapping and differentiable volumetric visibility for inverse rendering tasks like pose recovery, shadow art, and 3D reconstruction from low-density volumes [S1].
*   **When Not to Use:** When area lights or image-based lighting are required; when very high-order approximations are needed without careful numerical handling [S1].

## Background
Transmittance Mapping was introduced by Worchel and Alexa in 2025 [S1]. It is based on the theory of moments, citing classical work in real-time graphics and moment shadow mapping [S1]. The method was developed to address the inaccuracies of shadow mapping in inverse rendering, particularly in pose recovery and 3D reconstruction tasks [S1]. It builds on previous work in differentiable volume rendering and shadow mapping [S1].
