# Standard volume rendering equation

Also called: Integral form of VRE, NeRF Rendering Equation, Standard Volume Rendering, VRE derivation, Volume Rendering Equation (VRE), Volume Rendering Equation (VRE) Derivation from Radiance Transfer Equation, Volume Rendering Formula, Volumetric Rendering Equation, Volumetric Rendering Formula, Volumetric Rendering via Numerical Quadrature

## Overview
The standard volume rendering equation (VRE) computes the final pixel color by integrating emitted and scattered radiance along a camera ray, weighted by the transmittance (probability of survival) through the participating medium [S3, unofficial][S18][S23, unofficial]. It differs from its sibling [Volume Rendering Equation](2098-volume-rendering-equation.md) by explicitly defining the discrete numerical quadrature used in modern neural rendering (e.g., NeRF) and standard ray-marching, where opacity is derived from density and step size via Beer's Law, rather than treating opacity as an independent, ray-independent absolute value as in variants like Neural Volumes [S7]. It solves the problem of compositing volumetric data into a 2D image by accounting for absorption, emission, and occlusion in a single differentiable integral [S10, S23, unofficial].

## How it works
**Inputs:**
*   Ray origin $\mathbf{o}$ and direction $\mathbf{d}$ (unit vector).
*   Near and far bounds $t_n, t_f$ defining the integration interval along the ray.
*   A volume representation providing density $\sigma(\mathbf{x})$ and emitted radiance $\mathbf{c}(\mathbf{x}, \mathbf{d})$ at any 3D position $\mathbf{x}$ and viewing direction $\mathbf{d}$. In neural rendering, these are outputs of a neural network or lookup table [S10, S11, unofficial].
*   Background color $\mathbf{C}_{bg}$ (optional, default white or black) [S14, S27, unofficial].

**Outputs:**
*   Final pixel color $\mathbf{C}(\mathbf{r})$ (RGB vector) [S9][S27, unofficial].
*   (Optional) Accumulated depth or weights for auxiliary losses [S14, unofficial].

**Data Structures:**
*   **Samples:** A sequence of $N$ points $\{s_i\}_{i=1}^N$ along the ray, where $s_i = \mathbf{o} + t_i \mathbf{d}$. The depths $t_i$ are typically equidistantly distributed between $t_n$ and $t_f$ [S11, unofficial].
*   **Density Tensor:** $\sigma \in \mathbb{R}^N$, scalar values representing volume density (extinction coefficient) at each sample [S27, unofficial].
*   **Color Tensor:** $\mathbf{c} \in \mathbb{R}^{N \times 3}$, RGB radiance values at each sample [S27, unofficial].

**Formulas:**
1.  **Segment Length:** $\delta_i = t_{i+1} - t_i$ (with $t_{N+1}$ often assumed or $\delta_N$ defined by the last step) [S9][S14, unofficial].
2.  **Sample Opacity:** $\alpha_i = 1 - \exp(-\sigma_i \delta_i)$ [S7][S9][S14, unofficial]. This represents the probability that the ray interacts with the medium at sample $i$ [S23, unofficial].
3.  **Transmittance:** $T_i = \exp\left(-\sum_{j=1}^{i-1} \sigma_j \delta_j\right) = \prod_{j=1}^{i-1} (1 - \alpha_j)$ [S7][S9][S14, unofficial]. $T_i$ is the probability that light survives from the ray origin to the start of sample $i$ [S11, unofficial]. Note: $T_1 = 1$.
4.  **Weight:** $w_i = T_i \alpha_i$ [S9][S14, unofficial].
5.  **Color Accumulation:** $\mathbf{C} = \sum_{i=1}^N w_i \mathbf{c}_i$ [S9][S14, S23, unofficial].
6.  **Background Compositing:** $\mathbf{C}_{final} = \mathbf{C} + (1 - \sum_{i=1}^N w_i) \mathbf{C}_{bg}$ [S27, unofficial]. If $T_{N+1} = 1 - \sum w_i$, this is $\mathbf{C}_{final} = \mathbf{C} + T_{N+1} \mathbf{C}_{bg}$ [S26, S29, unofficial].

**Parameters:**
*   $N$: Number of samples per ray. Typical values range from 64 to 256 for high quality, or fewer (e.g., 32) with importance sampling [S14, S20, S23, unofficial].
*   $\sigma$: Volume density. Units are inverse length (e.g., $m^{-1}$) [S23, unofficial].
*   $\mathbf{c}$: Emitted radiance. Typically RGB [S23, unofficial].

**Pseudocode:**
```python
def standard_volume_rendering(rays_o, rays_d, t_n, t_f, num_samples, query_density, query_color, background_color=WHITE):
    """
    Renders a pixel using the standard volume rendering equation.
    
    Args:
        rays_o: Tensor of ray origins [num_rays, 3]
        rays_d: Tensor of ray directions [num_rays, 3]
        t_n: Near plane distance [num_rays]
        t_f: Far plane distance [num_rays]
        num_samples: Integer, number of samples per ray
        query_density: Function returning density sigma(x) for points x
        query_color: Function returning color c(x, d) for points x and direction d
        background_color: Default background color [3]
        
    Returns:
        colors: Rendered RGB colors [num_rays, 3]
        depths: Accumulated depths [num_rays] (optional)
    """
    # 1. Sample depths equidistantly between t_n and t_f
    # t_i = t_n + (i + 0.5) * (t_f - t_n) / num_samples for i in 0..N-1
    # This centers samples within the intervals for better integration accuracy [S2, unofficial]
    t_vals = torch.linspace(t_n, t_f, num_samples + 1) # [num_rays, num_samples + 1]
    # Use midpoints for sample positions
    t_mid = (t_vals[:, :-1] + t_vals[:, 1:]) / 2.0 # [num_rays, num_samples]
    delta_t = t_vals[:, 1:] - t_vals[:, :-1] # [num_rays, num_samples]
    
    # 2. Compute sample positions
    # s_i = o + t_mid_i * d
    # Expand dims for broadcasting: rays_o [N, 1, 3], rays_d [N, 1, 3], t_mid [N, S, 1]
    samples = rays_o.unsqueeze(1) + t_mid.unsqueeze(2) * rays_d.unsqueeze(1) # [N, S, 3]
    
    # 3. Query density and color
    sigma = query_density(samples) # [N, S, 1]
    color = query_color(samples, rays_d.unsqueeze(1)) # [N, S, 3]
    
    # 4. Compute opacity alpha_i = 1 - exp(-sigma_i * delta_t_i)
    alpha = 1.0 - torch.exp(-sigma * delta_t.unsqueeze(2)) # [N, S, 1]
    
    # 5. Compute transmittance T_i
    # T_i = product of (1 - alpha_j) for j < i
    # Cumulative product of (1 - alpha)
    # (1 - alpha) is the step transmittance
    step_transmittance = 1.0 - alpha # [N, S, 1]
    
    # Cumulative product along the sample dimension (dim=1)
    # We need T_i for each sample i. T_1 = 1.
    # cumprod returns P_i = prod_{j=0}^{i} step_transmittance_j
    # So T_i (transmittance TO sample i) is cumprod_{j=0}^{i-1} step_transmittance_j
    # We can compute cumulative product of step_transmittance, then shift.
    
    # Option A: Manual loop or cumsum of log
    # log_T_i = - sum_{j=0}^{i-1} sigma_j * delta_t_j
    # T_i = exp(log_T_i)
    
    # Compute optical depth tau_i = sum_{j=0}^{i-1} sigma_j * delta_t_j
    # sigma * delta_t is [N, S, 1]
    sigma_delta = sigma * delta_t.unsqueeze(2) # [N, S, 1]
    cumulative_sigma_delta = torch.cumsum(sigma_delta, dim=1) # [N, S, 1]
    
    # T_i corresponds to the sum BEFORE sample i.
    # For sample 0, sum is 0. For sample 1, sum is sigma_0 * delta_0.
    # We prepend zeros to cumulative_sigma_delta to get T for each sample
    # T_i = exp(- cumulative_sigma_delta_{i-1})
    
    # Shift cumulative sum: prepend 0, drop last
    # cumulative_sigma_delta_shifted[i] = sum_{j=0}^{i-1} sigma_j * delta_t_j
    # torch.cat([zeros, cumulative_sigma_delta[:, :-1]], dim=1)
    
    zeros = torch.zeros_like(sigma_delta[:, :1]) # [N, 1, 1]
    shifted_cumsum = torch.cat([zeros, cumulative_sigma_delta[:, :-1]], dim=1) # [N, S, 1]
    
    transmittance = torch.exp(-shifted_cumsum) # [N, S, 1]
    
    # 6. Compute weights w_i = T_i * alpha_i
    weights = transmittance * alpha # [N, S, 1]
    
    # 7. Accumulate color
    # color_acc = sum(w_i * c_i)
    # weights is [N, S, 1], color is [N, S, 3]
    # einsum: sum over S
    color_acc = torch.einsum('...s,...sc->...c', weights, color) # [N, 3]
    
    # 8. Accumulate total alpha (transmittance to background)
    # T_{N+1} = 1 - sum(w_i)
    total_alpha = weights.sum(dim=1, keepdim=True) # [N, 1, 1]
    background_transmittance = 1.0 - total_alpha # [N, 1, 1]
    
    # 9. Composite with background
    # background_color needs to be broadcastable [N, 1, 3]
    bg_color_tensor = torch.tensor(background_color).to(color_acc.device).unsqueeze(0).unsqueeze(0) # [1, 1, 3]
    final_color = color_acc + background_transmittance * bg_color_tensor # [N, 3]
    
    return final_color
```

**Edge Cases and Pitfalls:**
*   **Precision:** Computing $T_i$ via product of $(1-\alpha_j)$ can suffer from underflow for large $N$ or high density. Using the exponential of the negative cumulative sum of $\sigma \delta$ (as in the pseudocode) is numerically more stable [S10, S23, unofficial].
*   **Boundary Conditions:** If the ray does not intersect the volume, $T=1$ and color is background. The bounds $t_n, t_f$ must be correctly computed via volume intersection tests [S16, unofficial].
*   **Density Units:** $\sigma$ and $\delta$ must use consistent units (e.g., both in meters) [S25, unofficial].

## Subtopics

### [NeRF Rendering Formula](1362-nerf-rendering-formula.md)
The NeRF Rendering Formula is the specific instantiation of the standard VRE used in Neural Radiance Fields. It differs from generic volume rendering by explicitly handling the sigmoid activation of density (or softplus) and the specific discrete weighting scheme required for differentiable training of implicit representations. It uses the standard transmittance $T_i = \exp(-\sum \sigma \delta)$ and opacity $\alpha_i = 1 - \exp(-\sigma \delta)$, but often employs stratified sampling and hierarchical importance sampling to reduce variance during training.

### [Discrete Volume Transmittance Integration](3905-discrete-volume-transmittance-integration.md)
Discrete Volume Transmittance Integration computes the transmittance term $T$ required by the standard VRE by numerically integrating the extinction coefficient along the ray. Unlike analytic integration which assumes constant properties, this method handles arbitrary heterogeneity by sampling at fixed intervals. It serves as the core visibility calculation for the standard VRE, providing the $T_i$ values that weight the emitted and scattered light contributions.

### [Sub-interval Radiative Transfer Equation (RTE) Combination](3971-sub-interval-radiative-transfer-equation-rte-combination.md)
Sub-interval RTE Combination is a method for computing full-interval radiance by partitioning the integration path at an intermediate point, allowing solutions from multiple slice planes to be combined. It differs from the standard VRE by processing data in discrete 2D slices rather than a continuous ray integral, and from Discrete Volume Transmittance Integration by relying on hardware compositing of pre-solved slice radiance rather than per-sample accumulation.

### [Distance Sampling](8978-distance-sampling.md)
Distance sampling is a Monte Carlo technique to estimate the VRE by importance sampling the non-recursive terms, specifically the medium extinction transmittance, to determine the free flight distance (distance to next collision). It is an alternative to the deterministic equidistant sampling used in the standard VRE pseudocode, often used in path tracing for participating media.

## Operating characteristics
*   **Time Complexity:** $O(N)$ per ray, where $N$ is the number of samples. The transmittance calculation requires a cumulative sum, which is also $O(N)$ [S10, unofficial].
*   **Memory Complexity:** $O(N)$ per ray to store density, color, and transmittance values. For neural rendering, this is dominated by the network inference cost [S10, unofficial].
*   **Measured Performance:** With $N=64$ stratified samples, standard VRE is efficient enough for real-time rendering on modern GPUs when using efficient data structures (e.g., hash grids) [S14, unofficial]. For high-quality offline rendering, $N=256$ or more may be required [S23, unofficial].
*   **Strengths:** Differentiable, allowing gradient-based optimization of scene representations (e.g., NeRF) [S10, unofficial]. Simple to implement and parallelize [S23, unofficial].
*   **Limitations:** Requires many samples for high accuracy in dense media. Sensitive to sampling strategy (stratified vs. uniform) [S14, unofficial]. Early termination is possible when transmittance drops below a threshold, but this breaks differentiability if not handled carefully [S2, unofficial].

## Background
The Volume Rendering Equation is the integral form of the Radiative Transfer Equation (RTE), derived by integrating the first-order non-homogeneous linear differential equation describing light transport in participating media [S3, unofficial][S18]. It was formalized in computer graphics by Kajiya and Von Herzen (1984) and later popularized by Max (1995) for discrete quadrature [S9][S11, unofficial]. It is the foundational equation for modern neural rendering techniques like NeRF (Mildenhall et al., 2020) [S11, S23, unofficial].
