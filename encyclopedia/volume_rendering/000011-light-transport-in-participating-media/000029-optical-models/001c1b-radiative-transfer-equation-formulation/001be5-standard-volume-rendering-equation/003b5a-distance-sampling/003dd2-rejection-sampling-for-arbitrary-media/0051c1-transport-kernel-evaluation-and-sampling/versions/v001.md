# Transport Kernel Evaluation and Sampling

Also called: Transport kernel sampling

## Overview
Transport Kernel Evaluation and Sampling is an unbiased Monte Carlo procedure for determining the next interaction point in a participating medium, supporting both volume scattering and surface interactions [S1]. It generalizes standard distance sampling by allowing arbitrary non-exponential extinction distributions (e.g., Gamma-distributed media) while maintaining the efficiency of delta tracking [S1]. Unlike Rejection Sampling for Arbitrary Media, which relies on rejection steps to handle heterogeneity, this method uses a pre-computed base medium model to sample optical depth directly, inverting it to find physical distance, and adjusting weights based on surface proximity [S1].

## How it works
The method samples a distance $s$ along a ray direction $\omega$ from a starting position $x_i$, accounting for whether the start and end points lie on a surface boundary $\partial V$ or inside the volume. It relies on a "base medium" formulation where macroscopic extinction is normalized to 1, allowing the use of standard sampling primitives for arbitrary media shapes [S1].

### Inputs and Outputs
*   **Inputs**:
    *   Current position $x_i$ and ray direction $\omega$.
    *   Random number $\xi \in [0, 1]$.
    *   Base medium functions: $f_F(\tau)$ (free-flight), $p_P(\tau)$ (volume PDF), $p_F(\tau)$ (mixed PDF).
    *   Sampling procedures: $sampleF_P(\xi)$ and $sampleP_P(\xi)$, which return samples distributed proportional to $f_P$ and $p_P$ respectively.
    *   CDF/PDF evaluators for the base distributions: $sampleF_PCDF$, $sampleF_PPDF$, $sampleP_PCDF$, $sampleP_PPDF$.
    *   Optical depth inversion function $invertTau(\tau^*)$ and ray-surface intersection function $raytrace(x, \omega)$.
*   **Outputs**:
    *   Next position $x_{i+1}$.
    *   Importance weight $w$ for the transport kernel.

### Data Structures and Parameters
The method assumes the existence of pre-computed statistical models for the medium's heterogeneity.
*   **Base Medium**: Defined with macroscopic extinction $\sigma_t = 1$. The functions $f_F, p_P, p_F$ are derived from the specific non-exponential distribution (e.g., Gamma distribution for pink noise media) [S1].
*   **Optical Depth $\tau^*$**: A sample drawn from the base distribution, representing the optical thickness traversed.
*   **Distance $s$**: The physical distance corresponding to $\tau^*$, found by solving $\tau(x_i, x_i + s \cdot \omega) = \tau^*$ [S1].

### Algorithm Steps
1.  **Determine Surface Context**: Check if the current position $x_i$ lies on a surface boundary $\partial V$. Let $surfaceStart$ be true if $x_i \in \partial V$, false otherwise [S1].
2.  **Sample Optical Depth**:
    *   If $surfaceStart$ is true, draw $\tau^* \leftarrow sampleF_P(\xi)$.
    *   If $surfaceStart$ is false, draw $\tau^* \leftarrow sampleP_P(\xi)$ [S1].
3.  **Invert to Physical Distance**: Solve for the distance $s$ such that the optical depth from $x_i$ to $x_i + s \cdot \omega$ equals $\tau^*$.
    *   For homogeneous media, this is analytical: $s = \tau^* / \sigma_t(x_i)$ [S1].
    *   For heterogeneous media, this requires numerical inversion (e.g., regular tracking or raymarching) [S1].
4.  **Find Surface Intersection**: Trace the ray from $x_i$ in direction $\omega$ to find the distance to the nearest surface intersection $z = raytrace(x_i, \omega)$ [S1].
5.  **Determine Next Position**: Calculate the candidate next position $x_{i+1} = x_i + \min(s, z) \cdot \omega$ [S1].
6.  **Determine Interaction Type**: Let $surfaceEnd$ be true if the interaction ended at a surface ($s < z$), false if it ended in the volume ($s \ge z$) [S1].
7.  **Calculate PDF**:
    *   If $surfaceEnd$ is true (interaction stopped at surface):
        $$pdf = 1 - CDF(\tau^*)$$
        Specifically:
        $$pdf = 1 - (surfaceStart ? sampleF_PCDF(\tau^*) : sampleP_PCDF(\tau^*))$$
        This represents the probability that the free-flight distance exceeded the surface distance [S1].
    *   If $surfaceEnd$ is false (interaction in volume):
        $$pdf = \sigma_t(x_{i+1}) \cdot PDF(\tau^*)$$
        Specifically:
        $$pdf = \sigma_t(x_{i+1}) \cdot (surfaceStart ? sampleF_PPDF(\tau^*) : sampleP_PPDF(\tau^*))$$
        Here $\sigma_t(x_{i+1})$ is the macroscopic extinction coefficient at the new position, converting the optical depth PDF to a spatial PDF [S1].
8.  **Evaluate Transport Kernel**: Compute the base transport kernel $\tilde{T}_{base}$ based on the surface start/end states:
    *   If $surfaceStart \land surfaceEnd$: $\tilde{T}_{base} = f_F(\tau^*)$
    *   If $\neg surfaceStart \land \neg surfaceEnd$: $\tilde{T}_{base} = p_P(\tau^*)$
    *   Otherwise (mixed): $\tilde{T}_{base} = p_F(\tau^*)$ [S1].
9.  **Compute Weight**:
    $$weight = \frac{\tilde{T}_{base}(\tau^*, surfaceStart, surfaceEnd)}{pdf}$$
10. **Return**: Return the pair $\{weight, x_{i+1}\}$ [S1].

### Pseudocode
```python
def T_base(tau, surface_start, surface_end):
    """
    Evaluates the base transport kernel for the given optical depth tau
    and surface boundary conditions.
    """
    if surface_start and surface_end:
        return f_F(tau)
    elif not surface_start and not surface_end:
        return p_P(tau)
    else:
        return p_F(tau)

def sample_transport_kernel(x_i, omega, xi):
    """
    Samples the next interaction point and weight.
    
    Args:
        x_i: Current position vector.
        omega: Ray direction vector.
        xi: Random number in [0, 1].
        
    Returns:
        weight: Importance weight.
        x_next: Next interaction position.
    """
    # 1. Determine if starting on a surface
    surface_start = is_on_boundary(x_i)
    
    # 2. Sample optical depth tau* from base distribution
    if surface_start:
        tau_star = sample_F_P(xi)
    else:
        tau_star = sample_P_P(xi)
        
    # 3. Invert optical depth to physical distance s
    # Note: For heterogeneous media, this requires numerical root finding
    # such that integral(x_i to x_i + s*omega) sigma_t(x) dx = tau_star
    s = invert_tau(tau_star)
    
    # 4. Find distance to nearest surface intersection z
    z = raytrace_surface(x_i, omega)
    
    # 5. Determine next position
    min_dist = min(s, z)
    x_next = x_i + min_dist * omega
    
    # 6. Determine if interaction ended at a surface
    surface_end = (s < z)
    
    # 7. Calculate PDF
    if surface_end:
        # Probability that free-flight distance > surface distance
        if surface_start:
            cdf_val = sample_F_P_CDF(tau_star)
        else:
            cdf_val = sample_P_P_CDF(tau_star)
        pdf = 1.0 - cdf_val
    else:
        # PDF includes extinction coefficient at new position
        sigma_t_next = get_extinction_coefficient(x_next)
        if surface_start:
            pdf_val = sample_F_P_PDF(tau_star)
        else:
            pdf_val = sample_P_P_PDF(tau_star)
        pdf = sigma_t_next * pdf_val
        
    # 8. Evaluate Transport Kernel
    t_base = T_base(tau_star, surface_start, surface_end)
    
    # 9. Compute weight
    weight = t_base / pdf
    
    return weight, x_next
```

### Edge Cases and Pitfalls
*   **Heterogeneous Inversion**: The method requires solving $\tau(x_i, x_i + s \cdot \omega) = \tau^*$ for $s$. In heterogeneous media, this cannot be done analytically and requires numerical regular tracking or raymarching, which can be computationally expensive [S1].
*   **Surface Proximity**: If the ray starts exactly on a surface, the logic switches between free-flight ($f_F$) and volume ($p_P$) distributions. Incorrect boundary detection leads to wrong PDF calculations [S1].
*   **Precision**: When $s \approx z$, numerical precision issues may arise in determining $surfaceEnd$. The condition $s < z$ is used strictly [S1].

## Operating characteristics
*   **Time Complexity**: The sampling step is $O(1)$ for homogeneous media (analytical inversion). For heterogeneous media, it depends on the cost of numerical inversion (raymarching), which can be $O(N)$ where $N$ is the number of steps in the marching grid [S1].
*   **Memory Complexity**: $O(1)$ auxiliary memory, assuming the base medium functions and sampling primitives are pre-computed or efficiently evaluated [S1].
*   **Performance**: In benchmarks with Gamma-distributed pink noise media, this method (using delta tracking) rendered 23$\times$ faster than regular tracking while maintaining unbiased results and comparable noise levels [S1].
*   **Strengths**: Unbiased; supports arbitrary non-exponential media distributions; leverages efficient delta tracking principles; handles surface interactions seamlessly [S1].
*   **Limitations**: Requires pre-computation of base medium statistics ($f_F, p_P, p_F$); numerical inversion for heterogeneous media can be slow compared to homogeneous cases [S1].

## Background
The method was introduced in the context of a radiative transfer framework for non-exponential media, allowing rendering systems to handle media with complex extinction statistics (such as those derived from fractal noise) [S1]. It builds upon the concept of delta tracking (also known as Chernoff sampling) [S1]. The framework was implemented in PBRTv3 and Tungsten rendering systems [S1]. The approach addresses the limitation of standard exponential media models by allowing the extinction coefficient to vary stochastically in a structured way, while maintaining the unbiased nature of Monte Carlo path tracing [S1].
