# Whole Volume Importance Sampling

Also called: Geometry-Dependent Transmittance Sampling, Importance Sampling Scheme

## Overview
Whole Volume Importance Sampling is a Monte Carlo strategy for volume rendering that samples the integration domain according to the geometry-dependent transmittance of the entire participating medium, rather than limiting sampling to the transmittance along a single ray [S1]. It solves high-variance noise by incorporating both camera and light ray geometries into the probability density function, delivering lower variance images and superior convergence compared to independent sampling and distance sampling methods [S1]. It differs from classic techniques by accounting for the global geometry of the medium, not just local transmittance [S1].

## How it works
**Inputs and outputs:** Not given in the sources.

**Data structures:** The medium geometry is decomposed into trapezoid-shaped segments defined by the intersection of camera and light rays with the medium boundaries [S1]. Variables describing each segment are cached to avoid repeated traversal [S1].

**Steps:**
1. **Geometry Traversal:** Traverse the edges of the medium bounding box from corner to corner to connect incident and outgoing exit points from the medium, decomposing it into trapezoid-shaped segments [S1].
2. **Segment Selection:** Select a segment based on a probability distribution proportional to the geometry-dependent transmittance of that segment [S1].
3. **Sample Generation:** Generate a sample position within the selected segment according to the local transmittance distribution [S1].
4. **Weight Calculation:** Compute the importance sampling weight as the ratio of the integrand to the PDF of the selected segment and position [S1].

**Formulas:**
The sampling PDF $p(\mathbf{x})$ is derived to match exactly the distribution of the geometry-dependent transmittance along a camera ray [S1]. The weight for a sample $\mathbf{x}$ in segment $i$ is computed as $w(\mathbf{x}) = \frac{T_{\text{geom}}(\mathbf{x})}{p(\mathbf{x})}$, where $T_{\text{geom}}$ is the geometry-dependent transmittance and $p(\mathbf{x})$ is the sampling PDF [S1]. The exact mathematical formulation of $T_{\text{geom}}$ is not provided in the sources [S1]. Standard transmittance along a ray is $T(\mathbf{x}) = \exp\left(-\int_{\mathbf{o}}^{\mathbf{x}} \sigma_t(\mathbf{u}) d\mathbf{u}\right)$ [G].

**Pseudocode:**
```python
import math
import random

def whole_volume_importance_sampling(cam_origin, cam_dir, light_origin, light_dir, box_min, box_max, sigma_t):
    # Step 1: Geometry Traversal
    # Intersect rays with bounding box to find entry/exit points
    cam_t_min, cam_t_max = ray_box_intersection(cam_origin, cam_dir, box_min, box_max)
    light_t_min, light_t_max = ray_box_intersection(light_origin, light_dir, box_min, box_max)
    
    # Decompose medium into trapezoid-shaped segments by connecting exit points
    # For a single convex volume, this yields one segment spanning the camera ray intersection
    segment_length = max(0.0, cam_t_max - cam_t_min)
    segments = [{"length": segment_length, "t_min": cam_t_min, "t_max": cam_t_max}]
    
    # Cache segment variables to avoid repeated traversal
    cached_segments = segments
    
    # Step 2: Segment Selection
    # Calculate geometry-dependent transmittance for each segment
    segment_contributions = []
    for seg in cached_segments:
        # Transmittance matches the distribution of geometry-dependent transmittance along the camera ray [S1]
        transmittance = math.exp(-sigma_t * seg["length"])
        segment_contributions.append(transmittance)
        
    total_contribution = sum(segment_contributions)
    if total_contribution == 0:
        return None, 0.0
        
    # Normalize to form a PDF
    pdfs = [t / total_contribution for t in segment_contributions]
    
    # Select a segment based on the PDF
    segment_index = random.choices(range(len(pdfs)), weights=pdfs, k=1)[0]
    selected_segment = cached_segments[segment_index]
    
    # Step 3: Sample Generation
    # Sample a position within the selected segment according to local transmittance distribution
    u = random.random()
    sample_t = selected_segment["t_min"] + u * selected_segment["length"]
    sample_position = cam_origin + sample_t * cam_dir
    
    # Step 4: Weight Calculation
    # Weight = Integrand / PDF
    integrand = segment_contributions[segment_index]
    pdf_value = pdfs[segment_index] * (1.0 / selected_segment["length"])
    
    weight = integrand / pdf_value
    return sample_position, weight

def ray_box_intersection(origin, direction, box_min, box_max):
    # Standard slab method for ray-AABB intersection [G]
    t_min = -math.inf
    t_max = math.inf
    for i in range(3):
        if direction[i] == 0:
            if origin[i] < box_min[i] or origin[i] > box_max[i]:
                return 0.0, 0.0
        else:
            t1 = (box_min[i] - origin[i]) / direction[i]
            t2 = (box_max[i] - origin[i]) / direction[i]
            t_min = max(t_min, min(t1, t2))
            t_max = min(t_max, max(t1, t2))
    return t_min, t_max
```

## Subtopics

### [Importance Sampling for Forward Scattering Propagator](10151-importance-sampling-for-forward-scattering-propagator.md)
This method provides a Monte Carlo path tracing strategy to evaluate the rendering equation for the forward scattering propagator $G_f^b$, specifically addressing the transport of light through participating media where forward scattering dominates. It differs from standard local importance sampling (which samples phase functions and exponential depth independently at each vertex) by constructing a 7-dimensional global sampling strategy that incorporates the analytical structure of the propagator, resulting in faster convergence for infinite-dimensional scattering problems.

## Operating characteristics
* **Time Complexity:** Depends on the number of segments and the cost of geometry traversal. Caching segment variables reduces repeated traversal costs [S1].
* **Memory Complexity:** Not given in the sources.
* **Measured Performance:** The method yields visible noise reduction and superior convergence compared to independent sampling with existing algorithms and ray marching/distance sampling methods [S1]. It requires only a single sample in unoccluded areas to compute the whole integral solution [S1].
* **Strengths:** Lower variance images, superior convergence, applicable to multiple light sources, directly applicable to indoor scene rendering in room-scale interactive experiences [S1].
* **Limitations:** Requires decomposition of medium geometry into segments [S1].
* **When to use:** Path tracing frameworks where existing approaches enable combining multiple sampling strategies, especially for finite media [S1].
* **When not to use:** Not given in the sources.

## Background
The method was introduced in the paper "Collimated Whole Volume Light Scattering in Homogeneous Finite Media" [S1]. It is part of a broader effort to optimize Monte Carlo integration for volume rendering, specifically addressing the limitations of classic techniques that limit sampling to transmittance along a single ray [S1]. The technique generalizes to multiple scattering and progressive rendering [S1].
