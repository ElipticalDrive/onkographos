# Regular Tracking

Also called: Semi-Analytic Free-path Sampling, Surface Tracking

## Overview
Regular Tracking is a semi-analytic method for sampling free paths in piecewise-simple (e.g., piecewise-constant) media by replacing integration with summation over a structured grid [S1, unofficial]. It differs from analytic closed-form tracking by handling discontinuous extinction coefficients and from ray marching by exactly resolving boundary crossings rather than approximating them with fixed steps [S1, unofficial].

## How it works
**Inputs:** A ray origin $\mathbf{o}$ and direction $\mathbf{d}$; a piecewise homogeneous medium defined by a hierarchical voxel grid or octree where each cell has a constant extinction coefficient $\mu_t$; a uniform random number $\xi \in (0, 1]$ [S2].
**Outputs:** The distance $t$ to the next collision point [S2].

**Data Structures:**
The medium is represented as a hierarchical grid (e.g., voxel grid or octree) [S1, unofficial][S2]. Each leaf node or cell stores the constant extinction coefficient $\mu_t$ for that region [S2]. The structure allows for efficient traversal to identify boundaries along the ray [S2].

**Steps:**
1. Initialize the accumulated optical thickness $\tau_{acc} = 0$ and the current ray parameter $t_{curr} = 0$ [G].
2. Sample the target transmittance $T_{target} = \xi$ and compute the required optical thickness $\tau_{target} = -\ln(T_{target})$ [S2].
3. Traverse the grid to find the sequence of boundaries the ray crosses along its path [S2].
4. For each segment between consecutive boundaries (or from the origin to the first boundary), calculate the segment length $\Delta t$ and the optical thickness contribution $\Delta \tau = \mu_t \cdot \Delta t$, where $\mu_t$ is the extinction coefficient of the current cell [S2].
5. Update the accumulator: $\tau_{acc} \leftarrow \tau_{acc} + \Delta \tau$ [S2].
6. If $\tau_{acc} \ge \tau_{target}$, the collision occurs within the current segment. Compute the exact distance $t = t_{curr} + (\tau_{target} - (\tau_{acc} - \Delta \tau)) / \mu_t$ and return $t$ [S2].
7. If $\tau_{acc} < \tau_{target}$, update $t_{curr} \leftarrow t_{curr} + \Delta t$ and repeat from step 4 [S2].

**Formulas:**
- Target optical thickness: $\tau_{target} = -\ln(\xi)$ [S2].
- Segment optical thickness: $\Delta \tau = \mu_t \cdot \Delta t$ [S2].
- Collision distance within a cell: $t = t_{boundary\_start} + \frac{\tau_{target} - \tau_{acc\_prev}}{\mu_t}$ [S2].

**Edge Cases and Pitfalls:**
- Zero Extinction: If $\mu_t = 0$ in a cell, $\Delta \tau = 0$ and the accumulator does not increase; the algorithm must skip to the next boundary to avoid infinite loops or division by zero [G].
- Boundary Precision: Numerical errors in boundary intersection calculations can lead to missing or double-counting boundaries; robust geometric predicates are required [G].
- Performance: The method becomes expensive if the ray crosses many boundaries, as each boundary requires a grid traversal step [S2].

**Pseudocode:**
```python
def regular_tracking(ray_origin, ray_direction, grid, xi):
    tau_target = -math.log(xi)
    tau_acc = 0.0
    t_curr = 0.0
    t_next = find_grid_boundary(ray_origin, ray_direction, grid)
    while t_next is not None:
        delta_t = t_next - t_curr
        mu_t = grid.get_extinction(t_curr, ray_direction)
        delta_tau = mu_t * delta_t
        tau_acc += delta_tau
        if tau_acc >= tau_target:
            tau_prev = tau_acc - delta_tau
            mu_t_safe = max(mu_t, 1e-12)
            t_collision = t_curr + (tau_target - tau_prev) / mu_t_safe
            return t_collision
        t_curr = t_next
        t_next = find_grid_boundary(t_next, ray_direction, grid)
    return None
```

## Subtopics

### Ray Marching
An approximate method that ignores boundaries and uses fixed steps [S1, unofficial]. It differs from Regular Tracking by trading exactness for speed and is chosen when performance is critical and thin features are not a concern [S1, unofficial]. See [Ray Marching](ray-marching.md).

### Analytic Tracking
A method that uses closed-form inverse CDFs for simple extinction functions [S1, unofficial]. It differs from Regular Tracking by avoiding boundary traversal but is limited to specific functional forms [S1, unofficial]. See [Analytic Tracking](analytic-tracking.md).

## Operating characteristics
**Time Complexity:** Linear in the number of boundaries crossed by the ray, as each boundary requires traversal and optical thickness integration [S2].
**Memory Complexity:** Depends on the grid resolution and hierarchy depth [S1, unofficial].
**Strengths:** Exact sampling for piecewise-constant media without discretization bias [S1, unofficial].
**Limitations:** Performance degrades significantly when rays cross many boundaries; requires efficient boundary discovery structures [S2].
**When to Use:** When the medium is piecewise-constant and represented in a grid or octree, and exact free-path sampling is required [S1, unofficial][S2].
**When Not to Use:** When the medium lacks a structured grid representation or when approximate results are acceptable and performance is critical [S2].

## Background
Regular Tracking, also known as surface tracking, was introduced by Sutton et al. in 1999 [S2]. It is based on the idea of visiting boundaries in piecewise homogeneous regions to integrate optical thickness [S2]. The method relies on efficient boundary traversal algorithms, such as those by Amanatides and Woo (1987) for grids and Hubert-Tremblay et al. (2006) for octrees [S2].
