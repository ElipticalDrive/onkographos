# Similarity Theory / High-Order Similarity Relations

Also called: Equivalence Classes in RTE, Order-N Similarity, Similarity Relations, Similarity Theory for Radiative Transfer

## Overview
Similarity Theory identifies equivalence classes within the Radiative Transfer Equation (RTE) parameter space, where distinct sets of scattering parameters produce identical or approximately identical solution radiance fields, provided the radiance is band-limited in the spherical harmonics domain [S1]. It enables the replacement of difficult-to-simulate scattering parameters with equivalent parameters that reduce the number of scattering events required, thereby accelerating forward rendering [S1]. Unlike first-order methods like the diffusion approximation, which only preserve the first Legendre moment and assume linear anisotropy, higher-order similarity relations preserve higher angular frequencies of the phase function, offering finer partitions of the parameter space and higher accuracy for complex scattering behaviors [S1].

## How it works
The method transforms original scattering parameters $(\sigma_t, \sigma_s, f)$ into altered parameters $(\sigma_t^*, \sigma_s^*, f^*)$ such that the altered RTE yields the same radiance solution as the original [S1].

### Inputs and Outputs
*   Original extinction coefficient $\sigma_t$ (or $\sigma_a, \sigma_s$) [S1].
*   Original scattering coefficient $\sigma_s$ [S1].
*   Original phase function $f(\boldsymbol{\omega}' \cdot \boldsymbol{\omega})$ [S1].
*   User-defined accuracy/performance trade-off parameter $\alpha \in (0, 1)$ [S1].
*   Order of similarity $N$ (integer $\ge 1$) [S1].
*   Altered extinction coefficient $\sigma_t^*$ [S1].
*   Altered scattering coefficient $\sigma_s^*$ [S1].
*   Altered phase function $f^*(\boldsymbol{\omega}' \cdot \boldsymbol{\omega})$, typically represented as a tabulated function or defined by its Legendre moments [S1].

### Data Structures
*   The phase function $f$ is represented by its Legendre moments $f_n$ [S1].
*   Storage consists of an array or list of moments $[f_0, f_1, \dots, f_N]$ for the original phase function, and $[f_0^*, f_1^*, \dots, f_N^*]$ for the altered phase function [S1].
*   By definition of probability density, $f_0 = 1$ and $f_0^* = 1$ [S1].

### Formulas
The phase function $f$ is expanded in Legendre polynomials:
$$ f(\boldsymbol{\omega}' \cdot \boldsymbol{\omega}) = \sum_{n=0}^{\infty} \frac{2n+1}{4\pi} f_n P_n(\boldsymbol{\omega}' \cdot \boldsymbol{\omega}) $$
where $P_n$ is the $n$-th Legendre polynomial, and the moments are computed as:
$$ f_n = 2\pi \int_{-1}^{1} f(t) P_n(t) dt $$
The altered parameters must satisfy the **Similarity Relations of Order N** [S1]:
1.  **Absorption/Extinction:**
    $$ \sigma_a = \sigma_a^* $$
    Consequently, $\sigma_t^* = \sigma_a^* + \sigma_s^* = \sigma_a + \sigma_s^*$ [S1].
2.  **Scattering and Phase Moments ($1 \le n \le N$):**
    $$ \sigma_s (1 - f_n) = \sigma_s^* (1 - f_n^*) $$

### Parameters
*   **$\alpha \in (0, 1)$:** A user-provided parameter controlling the trade-off between performance and accuracy [S1]. In practice, this parameter is used to select the target $\sigma_s^*$, effectively scaling the scattering coefficient to reduce optical density while maintaining appearance fidelity within the band-limit assumption [S1].
*   **$N$:** The order of the similarity relation, determining how many angular frequencies are preserved [S1].

### Steps
1.  Compute the Legendre moments $f_n$ of the original phase function $f$ for $n = 0, \dots, N$ [S1].
2.  Determine the altered scattering coefficient $\sigma_s^*$ based on the desired performance gain using $\alpha$ [S1].
3.  Compute the altered Legendre moments $f_n^*$ for $1 \le n \le N$ using the similarity relation $\sigma_s(1-f_n) = \sigma_s^*(1-f_n^*)$ [S1].
4.  Numerically solve for the altered phase function $f^*(\cdot)$ as a tabulated function given the desired moments $f_n^*$ [S1].
5.  Replace the original scattering parameters with the altered ones in the base rendering method [S1].

### Pseudocode
```python
def compute_altered_parameters(sigma_s, sigma_a, phase_function_moments, alpha, order_N):
    # Step 1: Determine altered scattering coefficient
    sigma_s_star = alpha * sigma_s
    if sigma_s_star <= 0:
        raise ValueError("Altered scattering coefficient must be positive.")

    # Step 2: Compute altered moments
    moments_star = [1.0]  # f_0* is always 1 by probability density definition
    for n in range(1, order_N + 1):
        f_n = phase_function_moments[n]
        # Similarity relation: sigma_s * (1 - f_n) = sigma_s_star * (1 - f_n_star)
        f_n_star = 1.0 - (sigma_s / sigma_s_star) * (1.0 - f_n)
        moments_star.append(f_n_star)

    # Step 3: Compute altered absorption and extinction
    sigma_a_star = sigma_a
    sigma_t_star = sigma_a_star + sigma_s_star
    return sigma_s_star, sigma_a_star, moments_star

def reconstruct_phase_function(moments_star, resolution=100):
    # Step 4: Numerically solve for f*(t) as a tabulated function
    # Standard truncated Legendre series evaluation [G]
    t_values = [2.0 * i / (resolution - 1) - 1.0 for i in range(resolution)]
    f_star_values = []
    for t in t_values:
        value = 0.0
        for n, f_n in enumerate(moments_star):
            value += (2 * n + 1) / (4.0 * 3.141592653589793) * f_n * legendre(n, t)
        f_star_values.append(value)
    return t_values, f_star_values

def legendre(n, x):
    # Standard recurrence for Legendre polynomials [G]
    if n == 0: return 1.0
    if n == 1: return x
    p_prev, p_curr = 1.0, x
    for k in range(2, n + 1):
        p_next = ((2 * k - 1) * x * p_curr - (k - 1) * p_prev) / k
        p_prev, p_curr = p_curr, p_next
    return p_curr
```

### Edge Cases and Pitfalls
*   **Band-Limit Assumption Violation:** The theory assumes the radiance $L$ is band-limited in the spherical harmonics domain ($a_{mn}=0$ for $n>N$) [S1]. In practice, this assumption may not hold everywhere inside the medium, resulting in an approximated solution radiance rather than an identical one [S1].
*   **No Perfect Relation:** There is no "perfect" similarity relation for all $n, m$ simultaneously unless the parameters are unchanged [S1].
*   **Heterogeneous Materials:** For spatially varying parameters, the similarity relations must be satisfied at every location $x$ [S1].

## Subtopics

### Similarity Theory Equivalence Classes
Defines equivalence classes for scattering parameters based on the assumption that radiance is linearly anisotropic (Order-1 similarity) [S1]. Two parameter points $(g, \sigma_s)$ and $(g', \sigma_s')$ belong to the same class if $\sigma_s(1 - g) = \sigma_s'(1 - g')$, where $g$ is the anisotropy factor (first Legendre moment) [S1]. The error function $d(g, \sigma_s) := \|\mathbf{I}(g, \sigma_s) - \mathbf{I}_0\|_2$ measures the difference between rendered images, with low-error regions matching the predicted equivalence classes [S1]. Error values over equivalence class lines are not exactly zero because the linear anisotropy assumption fails near boundaries [S1]. This is used in forward rendering to map difficult scattering parameters to equivalent, easier-to-simulate parameters with lower optical density [S1].

## Operating characteristics
*   **Time Complexity:** The precomputation of altered parameters is $O(N)$, where $N$ is the order of similarity [S1]. The rendering time is reduced because the altered scattering coefficient $\sigma_s^*$ is typically smaller than $\sigma_s$, leading to fewer scattering events per light path [S1].
*   **Memory Complexity:** Requires storage for the altered phase function, which can be represented as a table of size proportional to the resolution of the angular domain or the number of moments $N$ [S1].
*   **Measured Performance:** The method accelerates rendering of optically dense and highly forward-scattering materials by reducing the number of subsurface scatterings needed [S1].
*   **Strengths:** Provides a rigorous theoretical framework for parameter equivalence, and higher-order relations offer better accuracy than first-order methods by capturing more of the phase function's structure [S1]. It is easy to implement as it only requires replacing parameters in an existing renderer [S1].
*   **Limitations:** Accuracy degrades near boundaries or in optically thin regions where the band-limit assumption fails [S1]. The reconstruction of the altered phase function from moments can be non-trivial and may require numerical optimization [S1].
*   **When to Use:** When rendering optically dense, forward-scattering media where standard path tracing is too slow or noisy [S1].
*   **When Not to Use:** When high accuracy is required near boundaries or in thin regions [S1].

## Background
Similarity Theory was originally introduced to applied physics by Wyman et al. in 1989 [S1]. It studies the equivalence classes of the RTE's parameter space by deriving a hierarchy of equivalence relations called "similarity relations" [S1]. In computer graphics, it was previously only used in the form of the simplest order-1 similarity relation [S1]. The paper by Jakob et al. presented a complete exposition of the theory and practical algorithms for higher-order relations in graphics [S1].
