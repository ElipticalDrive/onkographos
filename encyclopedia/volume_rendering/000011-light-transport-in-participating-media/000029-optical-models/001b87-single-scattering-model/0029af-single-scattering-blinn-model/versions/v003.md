# Single Scattering (Blinn Model)
Also called: Blinn 1982 Cloud Model, Blinn's Cloud Model

## Overview
The Single Scattering (Blinn Model) is a light transport approximation for participating media that accounts for exactly one secondary scattering event between the observer and a light source [S2, unofficial]. It solves the problem of rendering volumetric effects like clouds by assuming low albedo, thereby ignoring multiple scattering interactions [S2, unofficial]. It builds on the general Single Scattering Model by applying Blinn's 1982 approximations for uniform, low-density media [S1, unofficial].

## How it works
**Inputs and Outputs:**
*   **Input:** A viewing ray originating from the camera, a light source position, a volume density field $\rho(\mathbf{x})$, and a phase function $p(\cos \theta)$ [G].
*   **Output:** The radiance contribution $L$ at the pixel corresponding to the viewing ray [G].

**Data Structures:**
*   **Volume Density:** A scalar field $\rho(\mathbf{x})$ representing the scattering coefficient at position $\mathbf{x}$ [G].
*   **Phase Function:** A function $p(\cos \theta)$ mapping the cosine of the scattering angle to a relative intensity weight [G].

**Parameters:**
*   **Albedo:** The proportion of reflected light corresponding to the amount of light hitting the particle; the model assumes low albedo [S1, unofficial].
*   **Phase Function Type:** Based on phase angle, determining the brightness of a particle depending on the viewing angle [S1, unofficial].
*   **Scattering:** A particle is only seen if there are no other particles in the line of sight of either the incoming or outgoing ray of light [S1, unofficial].
*   **Transparency:** The amount of light that penetrates the clouded volume without being reflected off any particles [S1, unofficial].

**Steps:**
1.  **Ray-Box Intersection:** Determine the entry point $t_{in}$ and exit point $t_{out}$ of the viewing ray within the volume bounding box [G].
2.  **Viewing Ray Sampling:** Iterate along the viewing ray from $t_{in}$ to $t_{out}$ with a fixed step size $\Delta t$ [G].
3.  **Light Ray Intersection:** For each sample point $\mathbf{x}$, cast a secondary ray towards the light source and determine its intersection bounds $[t_{light, in}, t_{light, out}]$ with the volume [G].
4.  **Transmittance Calculation:** Compute the optical depth $\tau$ along the secondary ray from $\mathbf{x}$ to the light source (or until it exits the volume) [G].
5.  **Phase Function Evaluation:** Evaluate $p(\cos \theta)$ where $\theta$ is the angle of incidence of the light ray on the particle [S2, unofficial].
6.  **Scattering Integration:** Compute the differential contribution $\Delta L = \rho(\mathbf{x}) \cdot T_{\text{light}} \cdot p(\cos \theta) \cdot \Delta t$ [G].
7.  **Accumulation:** Sum the contributions from all sample points along the viewing ray to obtain $L$ [G].

**Formula:**
The reflected light quantity is described by a phase function providing the proportion of reflected intensity based on the incidence angle of the ray on a particle [S2, unofficial]. The total radiance is computed as:
$$ L = \int_{t_{in}}^{t_{out}} \rho(\mathbf{x}(t)) \cdot \exp\left(-\int_{t}^{t_{\text{light, out}}} \rho(\mathbf{x}(u)) \, du\right) \cdot p(\cos \theta) \, dt $$
where $\rho(\mathbf{x})$ is the volume density, the inner exponential is the transmittance to the light source, and $p(\cos \theta)$ is the phase function [S2, unofficial][S3, unofficial].

**Pseudocode:**
```python
import math

def blinn_single_scattering(view_origin, view_dir, light_pos, bbox_min, bbox_max, density_fn, phase_fn):
    # 1. Ray-box intersection (slab method)
    t_min, t_max = 0.0, 1e9
    for i in range(3):
        if abs(view_dir[i]) < 1e-8:
            if view_origin[i] < bbox_min[i] or view_origin[i] > bbox_max[i]:
                return [0.0, 0.0, 0.0, 1.0]
        else:
            t1 = (bbox_min[i] - view_origin[i]) / view_dir[i]
            t2 = (bbox_max[i] - view_origin[i]) / view_dir[i]
            t_min = max(t_min, min(t1, t2))
            t_max = min(t_max, max(t1, t2))
    if t_min > t_max:
        return [0.0, 0.0, 0.0, 1.0]

    num_samples = 100
    step = (t_max - t_min) / num_samples
    radiance = 0.0

    # 2. Sample along viewing ray
    for i in range(num_samples):
        t = t_min + (i + 0.5) * step
        point = [view_origin[j] + view_dir[j] * t for j in range(3)]
        density = density_fn(point)
        if density <= 0:
            continue

        # 3. Light ray intersection
        light_dir_raw = [light_pos[j] - point[j] for j in range(3)]
        light_len = math.sqrt(sum(d**2 for d in light_dir_raw))
        if light_len < 1e-8:
            continue
        light_dir = [d / light_len for d in light_dir_raw]

        t_light_min, t_light_max = 0.0, 1e9
        for j in range(3):
            if abs(light_dir[j]) < 1e-8:
                if point[j] < bbox_min[j] or point[j] > bbox_max[j]:
                    t_light_min = 1e9; break
            else:
                t1 = (bbox_min[j] - point[j]) / light_dir[j]
                t2 = (bbox_max[j] - point[j]) / light_dir[j]
                t_light_min = max(t_light_min, min(t1, t2))
                t_light_max = min(t_light_max, max(t1, t2))
        if t_light_min > t_light_max:
            continue

        # 4. Optical depth to light
        num_light_samples = 50
        light_step = (t_light_max - t_light_min) / num_light_samples
        optical_depth = 0.0
        for k in range(num_light_samples):
            t_l = t_light_min + (k + 0.5) * light_step
            light_point = [point[j] + light_dir[j] * t_l for j in range(3)]
            optical_depth += density_fn(light_point) * light_step
        transmittance = math.exp(-optical_depth)

        # 5. Phase function (angle of incidence)
        view_dir_norm = [-view_dir[j] for j in range(3)]
        cos_theta = sum(light_dir[j] * view_dir_norm[j] for j in range(3))
        cos_theta = max(-1.0, min(1.0, cos_theta))
        phase = phase_fn(cos_theta)

        # 6. Scattering integration
        contribution = density * transmittance * phase * step
        radiance += contribution

    return [radiance, radiance, radiance, 1.0]
```

**Edge Cases and Pitfalls:**
*   **High Albedo:** The model fails for media with high albedo as multiple scattering becomes significant [S1, unofficial].
*   **Boundary Conditions:** The path boundaries for the light ray must be correctly clipped to the volume extent to avoid incorrect optical depth calculations [S2, unofficial].
*   **Precision:** Numerical integration errors can accumulate, especially with steep density gradients. Romberg integration is suggested for higher accuracy [S3, unofficial].

## Subtopics

### Kajiya-Von Herren Ray Tracing Algorithm
This variant uses a precomputed brightness contribution $I_i(x, y, z)$ for each light source, calculated via Romberg integration [S3, unofficial]. The precomputed brightness contribution is calculated as: $I_i(x, y, z) = \exp(-\int_{0}^{r} \tau \rho(\xi) d\xi) \int_{0}^{r} \rho(\xi(t), \eta(t), \zeta(t)) dt$, where $\tau = r \rho$ [S3, unofficial]. The path boundaries are defined as $\lambda_1 = \max(0, d_1)$ and $\lambda_2 = \min(d_{global}, d_2)$, where $d_1$ is the distance to the nearest intersection with the bounding extent, $d_{global}$ is the distance to the nearest intersection with the rest of the world database, and $d_2$ is the distance to the farthest intersection with the bounding extent [S3, unofficial]. It is chosen when precomputation is feasible to accelerate per-frame rendering [S3, unofficial].

## Operating characteristics
*   **Time Complexity:** $O(N \cdot M)$ where $N$ is the number of samples along the viewing ray and $M$ is the number of samples along the light ray [G].
*   **Memory Complexity:** $O(V)$ where $V$ is the size of the volume density field [G].
*   **Strengths:** Simple to implement; efficient for low-density media like clouds or Saturn's rings [S1, unofficial].
*   **Limitations:** Inaccurate for high-albedo or thick media; ignores multiple scattering [S1, unofficial].
*   **When to Use:** Real-time or interactive rendering of thin volumetric effects [S1, unofficial].

## Background
The model was published by Blinn in 1982 for cloud simulation [S1, unofficial][S2, unofficial]. It was one of the first works to incorporate reflection and scattering in participating media, specifically targeting the rings of Saturn [S3, unofficial]. It assumes a uniform medium of relatively low albedo [S2, unofficial]. Later, Max extended this model to arbitrary shapes [S2, unofficial], and Bouthor added anisotropic dispersion effects [S2, unofficial].
