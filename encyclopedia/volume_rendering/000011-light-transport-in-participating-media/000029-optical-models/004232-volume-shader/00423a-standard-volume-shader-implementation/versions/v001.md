# Standard Volume Shader Implementation

Also called: Redshift Volume Shader

## Overview
The Standard Volume Shader Implementation is a method for rendering participating media by ray marching through a heterogeneous density grid, where optical properties vary per voxel. It distinguishes itself from uniform volume models by mapping artist-friendly parameters (Scatter Color, Transparency Color, Depth) directly to physical scattering and absorption coefficients, using a mean-free-path encoding for wavelength-dependent extinction. It is built on the same conceptual framework as Random Walk Subsurface Scattering but adapted for spatially varying density [S1].

## How it works
**Inputs and Outputs:**
*   **Input:** A ray origin $\mathbf{o}$ and direction $\mathbf{d}$; a scalar density grid (voxel data); scene scale factor.
*   **Output:** The accumulated color and opacity of the volume along the ray segment.

**Data Structures:**
*   **Density Grid:** A 3D array of scalar values representing particle density at each voxel. Values are independent of color. Empty space is represented by zero or near-zero density.
*   **Parameters:**
    *   `scatter_color`: A 3-component vector (RGB) representing the albedo of suspended particles.
    *   `transparency_color`: A 3-component vector (RGB) where each channel represents the mean free path for that wavelength.
    *   `depth`: A scalar multiplier (in centimeters) that scales `transparency_color` into real-world distances.
    *   `anisotropy`: A scalar controlling the phase function directionality (default: Henyey-Greenstein).

**Formulas:**
1.  **Extinction Coefficient ($\sigma_t$):**
    The extinction coefficient for each wavelength $\lambda$ is derived from the mean free path ($mfp_\lambda$) encoded in `transparency_color` and scaled by `depth`:
    $$ \sigma_t(\lambda) = \frac{1}{\text{depth} \times \text{transparency\_color}(\lambda)} $$
    Where $\text{transparency\_color}(\lambda)$ is the R, G, or B component respectively. [S1]

2.  **Scattering Coefficient ($\sigma_s$):**
    $$ \sigma_s(\lambda) = \sigma_t(\lambda) \times \text{scatter\_color}(\lambda) $$
    [S1]

3.  **Phase Function ($p(\omega_i, \omega_o)$):**
    Uses Henyey-Greenstein by default:
    $$ p(g) = \frac{1-g^2}{4\pi(1+g^2-2g\cos\theta)^{3/2}} $$
    Where $g$ is the anisotropy parameter and $\theta$ is the angle between incoming and outgoing light. For cloud-like water media, Jendersie-d’Eon may be used. [S1]

**Numbered Steps:**
1.  **Initialize:** Set accumulated color $C_{acc} = (0,0,0)$ and accumulated opacity $\alpha_{acc} = 0$.
2.  **Ray Marching:** Step along the ray $\mathbf{r}(t) = \mathbf{o} + t\mathbf{d}$ through the volume bounds.
3.  **Voxel Sampling:** At each step, sample the density grid to get $\rho$.
4.  **Compute Coefficients:** Calculate $\sigma_t$ and $\sigma_s$ using the formulas above, scaled by $\rho$.
5.  **Transmittance:** Calculate the transmittance over the step size $\Delta t$:
    $$ T = e^{-\sigma_t \Delta t} $$
6.  **Accumulate:** Update accumulated color and opacity:
    $$ C_{acc} = C_{acc} + (1 - \alpha_{acc}) \times \sigma_s \times T \times \Delta t $$
    $$ \alpha_{acc} = \alpha_{acc} + (1 - \alpha_{acc}) \times (1 - T) $$
7.  **Termination:** Stop if $\alpha_{acc}$ exceeds a threshold or the ray exits the volume.

**Pseudocode:**
```python
def standard_volume_shader(ray_origin, ray_direction, density_grid, scatter_color, transparency_color, depth, anisotropy):
    # Constants
    step_size = 0.1  # Not given in sources; typical implementation detail
    max_steps = 1000
    alpha_threshold = 0.99
    
    acc_color = [0.0, 0.0, 0.0]
    acc_alpha = 0.0
    
    # Precompute extinction coefficients from transparency color and depth
    # transparency_color is in [0, 1], depth is in cm
    # sigma_t = 1 / (depth * transparency_color)
    sigma_t = [0.0, 0.0, 0.0]
    for c in range(3):
        if transparency_color[c] > 0:
            sigma_t[c] = 1.0 / (depth * transparency_color[c])
        else:
            sigma_t[c] = 1e9  # Avoid division by zero; effectively opaque or infinite extinction
            
    # Precompute scattering coefficients
    sigma_s = [sigma_t[c] * scatter_color[c] for c in range(3)]
    
    # Ray marching
    t = 0.0
    for i in range(max_steps):
        # Sample density at current position
        # density_grid.sample(ray_origin + ray_direction * t) returns scalar density
        density = density_grid.sample(ray_origin + ray_direction * t)
        
        # Scale coefficients by density
        current_sigma_t = [sigma_t[c] * density for c in range(3)]
        current_sigma_s = [sigma_s[c] * density for c in range(3)]
        
        # Calculate transmittance for this step
        # T = exp(-sigma_t * step_size)
        transmittance = [0.0, 0.0, 0.0]
        for c in range(3):
            transmittance[c] = math.exp(-current_sigma_t[c] * step_size)
            
        # Accumulate color and opacity
        # Contribution = (1 - acc_alpha) * sigma_s * T * step_size
        contribution = [0.0, 0.0, 0.0]
        for c in range(3):
            contribution[c] = (1.0 - acc_alpha) * current_sigma_s[c] * transmittance[c] * step_size
            
        acc_color = [acc_color[c] + contribution[c] for c in range(3)]
        acc_alpha = acc_alpha + (1.0 - acc_alpha) * (1.0 - transmittance[0]) # Approximation using R channel for alpha
        
        # Check termination
        if acc_alpha > alpha_threshold:
            break
            
        t += step_size
        
    return acc_color, acc_alpha
```

**Edge Cases and Pitfalls:**
*   **Wavelength Tinting:** Because different wavelengths are absorbed at different rates (via `transparency_color`), light traveling far through the medium becomes tinted with the opposite of the transparency color as other wavelengths are exhausted. This creates natural depth effects (e.g., deep water appearing blue) [S1].
*   **Precision:** Division by zero in `sigma_t` calculation if `transparency_color` is zero. Handled by setting a large extinction value [G].
*   **Density Boundaries:** Sharp transitions in density grid can cause artifacts if step size is too large. Adaptive stepping may be required [G].

## Operating characteristics
*   **Time Complexity:** Linear with respect to the number of steps taken along the ray, which depends on volume density and step size. Heterogeneous media require per-voxel sampling, increasing cost compared to uniform volumes.
*   **Memory Complexity:** Proportional to the size of the density grid.
*   **Strengths:** Artist-friendly parameters; physically plausible wavelength-dependent absorption; handles heterogeneous media.
*   **Limitations:** Computationally expensive due to ray marching and multiple scattering simulation (if implemented). Single scattering approximation may look thin in dense media.
*   **When to Use:** Clouds, fog, smoke, subsurface-like volumes where density varies spatially.
*   **When Not to Use:** Uniform, thin media where single scattering is sufficient and performance is critical.

## Background
The Standard Volume Shader Implementation is internally related to Random Walk Subsurface Scattering used in Redshift’s OpenPBR and Standard Surface materials. It adapts the subsurface scattering concept (light wandering through a finite, uniform medium like skin or wax) to heterogeneous media where density varies at every voxel [S1]. The parameter mapping is: Subsurface Color $\rightarrow$ Scatter Color, Subsurface Radius $\rightarrow$ Transparency Color, Subsurface Scale $\rightarrow$ Depth [S1].
