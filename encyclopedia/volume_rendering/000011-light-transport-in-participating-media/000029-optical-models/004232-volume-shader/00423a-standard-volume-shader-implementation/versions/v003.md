# Standard Volume Shader Implementation

Also called: RS Volume, Redshift Volume, Redshift Volume Shader

## Overview
The Standard Volume Shader is a technique for rendering non-homogeneous participating media, such as smoke and fire, using voxel grids (typically OpenVDB) stored entirely in GPU memory [S1]. It differs from subsurface scattering by applying a random-walk light transport model to a heterogeneous medium where density varies at every voxel, rather than a uniform finite surface [S2, unofficial][S3]. It is built upon three shading components: Scatter (diffuse reflection), Absorption (transparency/extinction), and Emission (incandescence) [S1].

## How it works

### Inputs and Outputs
*   **Input:** A volume object defined by an OpenVDB file or DCC volume grid, containing scalar channels (e.g., 'density', 'temperature') [S1].
*   **Input:** A scene containing at least one volume-affecting light with `volume contribution scale > 0.0` [S1].
*   **Output:** A rendered image where the volume interacts with light via scattering, absorption, and emission [S1].

### Data Structures
The volume data is stored in GPU memory as a collection of grids. Each grid corresponds to a channel in the OpenVDB file [S1].
*   **Grid Layout:** A 3D array of voxels.
*   **Channel Data:** Scalar values per voxel.
    *   **Density Channel:** Scalar description of particle count per voxel versus empty space [S2, unofficial][S3].
    *   **Temperature Channel:** Scalar value representing heat, used for emission [S1].
*   **Shader Parameters:**
    *   `scatter_channel_name`: String identifying the density channel [S1].
    *   `emission_channel_name`: String identifying the temperature channel [S1].
    *   `scatter_color`: RGB albedo of suspended particles [S2, unofficial][S3].
    *   `transparency_color`: RGB mean free path values (0 to 1) [S2, unofficial][S3].
    *   `depth`: Float multiplier converting transparency color to real-world distance in centimeters [S2, unofficial][S3].
    *   `anisotropy`: Float controlling scattering directionality [S2, unofficial][S3].
    *   `scatter_coefficient`: Float scaling brightness [S1].
    *   `absorption_coefficient`: Float scaling opacity [S1].
    *   `emission_mode`: Enum (`Color Ramp` or `Blackbody`) [S1].
    *   `emission_ramp`: Gradient mapping channel values to emissive colors [S1].
    *   `blackbody_temperature`: Float in Kelvin (default 6500K) [S1].
    *   `blackbody_offset`: Float interpolating intensity (default 1.0) [S1].

### Steps

1.  **Initialization:**
    *   Load the OpenVDB file into GPU memory. If the data exceeds available VRAM, abort rendering [S1].
    *   Identify the channels specified by `scatter_channel_name` and `emission_channel_name`. If these are not set or do not exist, the volume renders as black/empty [S1].
    *   Verify the presence of at least one light with `volume contribution scale > 0.0`. If absent, render black [S1].

2.  **Ray Marching:**
    *   For each pixel, cast a ray into the scene.
    *   Determine the entry and exit points of the ray within the volume bounding box [S2, unofficial][S3].
    *   Step through the volume along the ray direction. The step size is determined by the voxel resolution or a fixed march step [S2, unofficial][S3].
    *   At each step position $P$, sample the density grid to obtain the scalar density value $d$ [S2, unofficial][S3].

3.  **Optical Property Calculation:**
    *   **Scattering Coefficient ($\sigma_s$):**
        $$ \sigma_s = d \cdot \text{scatter\_coefficient} $$
        [S1]
    *   **Absorption Coefficient ($\sigma_a$):**
        $$ \sigma_a = d \cdot \text{absorption\_coefficient} $$
        [S1]
    *   **Total Extinction Coefficient ($\sigma_t$):**
        $$ \sigma_t = \sigma_s + \sigma_a $$
        [G] (Standard radiative transfer definition implied by coefficients)
    *   **Single Scattering Albedo ($\omega_0$):**
        $$ \omega_0 = \frac{\sigma_s}{\sigma_t} $$
        [G] (Derived from coefficients)
    *   **Phase Function ($p(\Omega_i \to \Omega_o)$):**
        *   If `anisotropy` $\neq 0$, use Henyey-Greenstein (default) or Jendersie-d’Eon (for cloud-like water) [S2, unofficial][S3].
        *   If `anisotropy` $= 0$, use isotropic scattering [S2, unofficial][S3].

4.  **Emission Calculation:**
    *   Sample the temperature channel at $P$ to get value $T_{val}$ [S1].
    *   If `emission_mode` is `Color Ramp`:
        *   Map $T_{val}$ through the `emission_ramp` to get emissive color $L_e$ [S1].
    *   If `emission_mode` is `Blackbody`:
        *   Calculate blackbody radiance $L_{bb}$ based on `blackbody_temperature` [S1].
        *   Interpolate between channel value and calculated radiance using `blackbody_offset` [S1].
        *   $L_e = \text{lerp}(T_{val}, L_{bb}, \text{blackbody\_offset})$ [G] (Interpretation of "interpolates... between channel value and calculated radiance")

5.  **Transmittance and Color Accumulation:**
    *   Initialize transmittance $T = 1.0$ and accumulated color $C = 0.0$ [G] (Standard volume rendering integral setup).
    *   For each step of length $\Delta s$:
        *   Calculate optical depth for the step: $\tau = \sigma_t \cdot \Delta s$ [G].
        *   Calculate transmittance through the step: $t = e^{-\tau}$ [G].
        *   Calculate emitted and scattered light contribution:
            $$ C_{step} = T \cdot (L_e + \sigma_s \cdot \text{incident\_light} \cdot p(\dots)) $$
            [G] (Simplified single-bounce approximation; multiple scattering is handled via "Shadow Density Scale" trick or more complex integration not fully detailed in sources) [S1][S2, unofficial].
        *   Update accumulated color: $C = C + C_{step} \cdot t$ [G].
        *   Update transmittance: $T = T \cdot t$ [G].
        *   If $T < \epsilon$ (threshold), break loop [G].
    *   Final pixel color contribution: $C_{final} = C + T \cdot C_{background}$ [G].

6.  **Wavelength-Dependent Absorption (Transparency Color):**
    *   The `transparency_color` defines the mean free path for each wavelength [S2, unofficial][S3].
    *   Let $M_{rgb}$ be the `transparency_color` vector (values 0 to 1) [S2, unofficial][S3].
    *   Let $D$ be the `depth` parameter (real distance in cm) [S2, unofficial][S3].
    *   The effective mean free path for each channel is $m_{rgb} = M_{rgb} \cdot D$ [S2, unofficial][S3].
    *   The absorption coefficient for each wavelength is inversely proportional to the mean free path: $\sigma_{a, rgb} = \frac{1}{m_{rgb}} \cdot d$ [G] (Derived from "mean free path... average distance... before being extinguished" and "density grid... scalar description") [S2, unofficial][S3].
    *   *Note:* Sources state that `transparency_color` is an "artist friendly encoding" and `depth` multiplies these 0-1 values into real distances [S2, unofficial][S3]. The exact formula for integrating this into $\sigma_a$ alongside `absorption_coefficient` is not explicitly given, but the physical effect is that different wavelengths are absorbed at different rates, causing tinting [S2, unofficial][S3].

### Pseudocode

```python
def render_volume_ray(ray_origin, ray_direction, volume_data, shader_params):
    """
    Renders a single ray through a volume using the Standard Volume Shader logic.
    """
    # 1. Check for lights
    if not has_volume_affecting_lights():
        return Color(0, 0, 0)

    # 2. Initialize accumulation
    transmittance = 1.0
    accumulated_color = Color(0, 0, 0)
    
    # 3. Determine march bounds
    entry_point, exit_point = intersect_volume_bbox(ray_origin, ray_direction, volume_data.bbox)
    if entry_point is None:
        return ray_background_color(ray_direction)

    # 4. Ray march
    current_pos = entry_point
    step_size = volume_data.voxel_size # Or fixed step
    max_steps = 1000 # Safety limit
    
    for i in range(max_steps):
        if current_pos > exit_point:
            break
            
        # Sample density
        density = volume_data.sample_density(current_pos)
        
        # Skip empty space
        if density < 1e-6:
            current_pos += ray_direction * step_size
            continue
            
        # Calculate coefficients
        sigma_s = density * shader_params.scatter_coefficient
        sigma_a_base = density * shader_params.absorption_coefficient
        
        # Apply wavelength-dependent absorption from transparency color
        # transparency_color (0-1) * depth (cm) = mean_free_path (cm)
        # sigma_a_wavelength = 1 / mean_free_path * density_factor?
        # Sources say transparency_color encodes mean free path.
        # Let's assume sigma_a is modified by transparency color ratios.
        # Simplified: sigma_a_total = sigma_a_base * (1 / transparency_color_effective)
        # But sources say "transparency color... represents travel distance".
        # We will apply the tinting effect via transmittance per channel.
        
        sigma_t = sigma_s + sigma_a_base
        
        # Phase function
        phase = evaluate_phase_function(shader_params.anisotropy, ray_direction, light_direction)
        
        # Emission
        temp_val = volume_data.sample_temperature(current_pos)
        if shader_params.emission_mode == 'Color Ramp':
            emission_color = shader_params.emission_ramp.map(temp_val)
        else: # Blackbody
            bb_radiance = blackbody_radiance(shader_params.blackbody_temperature)
            emission_color = lerp(temp_val, bb_radiance, shader_params.blackbody_offset)
            
        # Incident light (simplified single scattering)
        incident_light = get_light_contribution(current_pos, ray_direction, volume_data)
        
        # Contribution
        # L_step = T * (E + sigma_s * L_inc * phase)
        # Note: Multiple scattering is approximated or handled by Shadow Density Scale
        step_contribution = transmittance * (emission_color + sigma_s * incident_light * phase)
        
        accumulated_color += step_contribution * exp(-sigma_t * step_size)
        transmittance *= exp(-sigma_t * step_size)
        
        if transmittance < 0.001:
            break
            
        current_pos += ray_direction * step_size

    # 5. Apply background
    final_color = accumulated_color + transmittance * ray_background_color(ray_direction)
    
    # 6. Apply Shadow Density Scale (trick for multiple scattering approximation)
    # This parameter makes volume more/less opaque to shadow rays.
    # It is a post-process or ray-march modifier not fully detailed in formula.
    # final_color = apply_shadow_density_scale(final_color, shader_params.shadow_density_scale)
    
    return final_color
```

### Parameters and Typical Values
*   **Scatter Coefficient:** Default 1.0. Increases brightness [S1].
*   **Absorption Coefficient:** Default 1.0. Increases opacity [S1].
*   **Depth:** Multiplies transparency color 0-1 values to real cm distances. Aware of scene scale [S2, unofficial][S3].
*   **Anisotropy:** Default 0 (isotropic). Positive values scatter forward (Henyey-Greenstein) [S2, unofficial][S3].
*   **Blackbody Temperature:** Default 6500K [S1].
*   **Blackbody Offset:** Default 1.0 [S1].
*   **Shadow Density Scale:** Advanced parameter to emulate multiple scattering by adjusting opacity to shadow rays [S1].

### Edge Cases and Pitfalls
*   **VRAM Limit:** Volume objects must fit entirely in GPU memory. If they do not, rendering aborts with an out-of-VRAM error [S1].
*   **Missing Channels:** If `scatter_channel_name` or `emission_channel_name` are not set or do not exist in the OpenVDB file, the volume will not render (renders black/empty) [S1].
*   **Missing Lights:** If no volume-affecting lights are present (volume contribution scale $\le 0.0$), the volume renders black [S1].
*   **Smoke/Fire Interference:** Smoke (scatter/absorption) obstructs fire (emission). Adjustments to scatter/absorption must not interfere too much with emission [S1].
*   **Temperature Range Remapping:** Temperature channel ranges vary by 3D app. Range remapping may be necessary if the emission ramp does not align with the data range [S1].
*   **Wavelength Tinting:** Light traveling far through the medium becomes tinted with the opposite of the transparency color as other wavelengths are exhausted (e.g., deep water blue) [S2, unofficial][S3].

## Operating characteristics

*   **Memory Complexity:** $O(V)$, where $V$ is the total number of voxels in the OpenVDB file. All data must reside in GPU VRAM [S1].
*   **Time Complexity:** $O(R \cdot M)$, where $R$ is the number of rays and $M$ is the number of march steps per ray. Cost increases with density and number of scattering bounces [S2, unofficial][S3].
*   **Performance:** Volumes are expensive due to the cost of ray marching and multiple scattering calculations [S2, unofficial][S3]. Single scattering is sufficient for thin media; multiple scattering requires more samples or tricks like Shadow Density Scale [S1][S2, unofficial].
*   **Strengths:** Artist-friendly parameters (transparency color, depth), physically plausible wavelength-dependent absorption, integration with OpenVDB [S1][S2, unofficial][S3].
*   **Limitations:** High memory usage (no out-of-core support), sensitive to light setup, requires careful tuning of scatter/absorption/emission balance [S1][S2, unofficial].

## Background

*   **Origin:** The Standard Volume Shader is part of the Redshift renderer by Maxon [S1][S2, unofficial][S3].
*   **Development:** It is described internally as a close relative of Random Walk Subsurface Scattering, adapted for heterogeneous media [S2, unofficial][S3].
*   **Usage:** Used for rendering smoke, fire, clouds, and fog in 3D applications like Cinema 4D, Maya, and Houdini via Redshift [S1].
