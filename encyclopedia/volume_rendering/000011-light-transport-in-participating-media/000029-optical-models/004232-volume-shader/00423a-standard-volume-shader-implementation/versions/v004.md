# Standard Volume Shader Implementation

Also called: RS Volume, Redshift Standard Volume, Redshift Volume, Redshift Volume Shader, Standard Volume, Standard Volume Shader

## Overview
The Standard Volume Shader is a technique for rendering non-homogeneous participating media, such as smoke and fire, using voxel grids (typically OpenVDB) stored entirely in GPU memory [S1]. It differs from subsurface scattering by applying a random-walk light transport model to a heterogeneous medium where density varies at every voxel, rather than a uniform finite surface [S2, unofficial][S3]. It is built upon three shading components: Scatter (diffuse reflection), Absorption (transparency/extinction), and Emission (incandescence) [S1].

## How it works

### Inputs and Outputs
*   **Input:** A volume object defined by an OpenVDB file or DCC volume grid, containing scalar channels (e.g., 'density', 'temperature') [S1].
*   **Input:** A scene containing at least one volume-affecting light with `volume contribution scale > 0.0` [S1].
*   **Output:** A rendered image where the volume interacts with light via scattering, absorption, and emission [S1].

### Data Structures
Volume data is stored entirely in GPU memory as OpenVDB grids [S1]. OpenVDB files store voxels (3D pixels) organized in named channels [S1]. The density channel provides a scalar description of particle count per voxel versus empty space [S2, unofficial][S3]. The temperature channel provides a scalar value representing heat for emission [S1]. Shader parameters include `scatter_channel_name` and `emission_channel_name` strings to map OpenVDB channels [S1], `scatter_color` (RGB albedo) [S2, unofficial][S3], `transparency_color` (RGB mean free path, 0 to 1) [S2, unofficial][S3], `depth` (float multiplier converting transparency color to real distances in centimeters) [S2, unofficial][S3], `anisotropy` (float controlling scattering directionality) [S2, unofficial][S3], `scatter_coefficient` (float scaling brightness) [S1], `absorption_coefficient` (float scaling opacity) [S1], `emission_mode` (enum: `Color Ramp` or `Blackbody`) [S1], `emission_ramp` (gradient mapping channel values to emissive colors) [S1], `blackbody_temperature` (float in Kelvin, default 6500K) [S1], and `blackbody_offset` (float interpolating intensity, default 1.0) [S1].

### Steps

1.  **Initialization:**
    *   Load the OpenVDB file into GPU memory; abort rendering if VRAM is exceeded [S1].
    *   Identify channels via `scatter_channel_name` and `emission_channel_name`; volume renders black if unset or missing [S1].
    *   Verify at least one light with `volume contribution scale > 0.0`; volume renders black if absent [S1].

2.  **Ray Marching:**
    *   For each pixel, cast a ray into the scene [G].
    *   Compute entry and exit points within the volume bounding box [G].
    *   Step through the volume along the ray direction, sampling the density grid at each position to obtain scalar density $d$ [S2, unofficial][S3].

3.  **Optical Properties:**
    *   Compute scattering coefficient: $\sigma_s = d \cdot \text{scatter\_coefficient}$ [S1].
    *   Compute absorption coefficient: $\sigma_a = d \cdot \text{absorption\_coefficient}$ [S1].
    *   Compute total extinction: $\sigma_t = \sigma_s + \sigma_a$ [G].
    *   Compute single scattering albedo: $\omega_0 = \sigma_s / \sigma_t$ [G].
    *   Evaluate phase function using Henyey-Greenstein (default) or Jendersie-d’Eon for cloud-like water media based on `anisotropy` [S2, unofficial][S3].

4.  **Emission Calculation:**
    *   Sample temperature channel at current position to get $T_{val}$ [S1].
    *   If `emission_mode` is `Color Ramp`, map $T_{val}$ through `emission_ramp` to get $L_e$ [S1].
    *   If `emission_mode` is `Blackbody`, calculate blackbody radiance $L_{bb}$ from `blackbody_temperature` [S1].
    *   Interpolate between channel value and radiance using `blackbody_offset`: $L_e = \text{lerp}(T_{val}, L_{bb}, \text{blackbody\_offset})$ [G].

5.  **Transmittance and Color Accumulation:**
    *   Initialize transmittance $T = 1.0$ and accumulated color $C = 0.0$ [G].
    *   For each step of length $\Delta s$:
        *   Compute optical depth: $\tau = \sigma_t \cdot \Delta s$ [G].
        *   Compute transmittance through step: $t = e^{-\tau}$ [G].
        *   Compute step contribution: $C_{step} = T \cdot (L_e + \sigma_s \cdot L_{incident} \cdot p(\Omega_i \to \Omega_o))$ [G].
        *   Update accumulated color: $C = C + C_{step} \cdot t$ [G].
        *   Update transmittance: $T = T \cdot t$ [G].
        *   Break if $T < \epsilon$ [G].
    *   Final pixel color: $C_{final} = C + T \cdot C_{background}$ [G].

6.  **Wavelength-Dependent Absorption:**
    *   The `transparency_color` defines the mean free path for each wavelength [S2, unofficial][S3].
    *   The `depth` parameter multiplies these 0 to 1 values into real distances in centimeters [S2, unofficial][S3].
    *   Different wavelengths are absorbed at different rates, causing light traveling far through the medium to be tinted with the opposite of the transparency color once other wavelengths are exhausted [S2, unofficial][S3].

### Pseudocode

```python
import math

def intersect_aabb(origin, direction, bbox_min, bbox_max):
    """Returns (t_min, t_max) for ray-AABB intersection."""
    t_min, t_max = 0.0, float('inf')
    for i in range(3):
        inv_d = 1.0 / direction[i] if direction[i] != 0 else float('inf')
        t1 = (bbox_min[i] - origin[i]) * inv_d
        t2 = (bbox_max[i] - origin[i]) * inv_d
        t_near = t1 if t1 < t2 else t2
        t_far = t2 if t1 < t2 else t1
        if t_near > t_min: t_min = t_near
        if t_far < t_max: t_max = t_far
    return t_min, t_max

def render_volume_shader(ray_origin, ray_direction, volume_bbox, density_grid, temp_grid, voxel_size, params):
    # 1. Light requirement check
    if not params.get('has_volume_light', False):
        return (0.0, 0.0, 0.0)

    # 2. Ray-AABB intersection
    t_min, t_max = intersect_aabb(ray_origin, ray_direction, volume_bbox[0], volume_bbox[1])
    if t_min > t_max or t_max < 0.0:
        return params.get('background_color', (0.0, 0.0, 0.0))

    # 3. Initialization
    transmittance = 1.0
    accumulated_color = [0.0, 0.0, 0.0]
    current_t = t_min
    step_size = params.get('step_size', voxel_size)
    max_steps = params.get('max_steps', 1000)

    # 4. Ray Marching Loop
    for _ in range(max_steps):
        if current_t > t_max:
            break

        # Sample grids at current position [G]
        pos = (ray_origin[0] + ray_direction[0] * current_t,
               ray_origin[1] + ray_direction[1] * current_t,
               ray_origin[2] + ray_direction[2] * current_t)
        density = density_grid.sample(pos)
        temp_val = temp_grid.sample(pos)

        if density < 1e-6:
            current_t += step_size
            continue

        # 5. Optical Properties
        sigma_s = density * params['scatter_coefficient']
        sigma_a = density * params['absorption_coefficient']
        sigma_t = sigma_s + sigma_a
        omega_0 = sigma_s / sigma_t if sigma_t > 0 else 0.0

        # Phase function
        anisotropy = params.get('anisotropy', 0.0)
        if anisotropy == 0.0:
            phase = 1.0 / (4.0 * math.pi)
        else:
            # Henyey-Greenstein or Jendersie-d’Eon based on anisotropy [S2, unofficial][S3]
            cos_theta = 0.5 # Placeholder for actual scattering angle
            g = anisotropy
            phase = (1.0 - g**2) / (4.0 * math.pi * (1.0 + g**2 - 2.0 * g * cos_theta)**1.5)

        # 6. Emission
        if params['emission_mode'] == 'Color Ramp':
            emission_color = params['emission_ramp'].map(temp_val)
        else: # Blackbody
            bb_radiance = params['blackbody_temperature']
            emission_color = (temp_val + bb_radiance * params['blackbody_offset']) / 2.0

        # 7. Accumulation
        incident_light = params.get('incident_light', (1.0, 1.0, 1.0))
        step_contrib = transmittance * (emission_color + sigma_s * incident_light * phase)
        transmittance_step = math.exp(-sigma_t * step_size)
        accumulated_color = [accumulated_color[i] + step_contrib[i] * transmittance_step for i in range(3)]
        transmittance *= transmittance_step

        if transmittance < 0.001:
            break

        current_t += step_size

    # 8. Final color
    background = params.get('background_color', (0.0, 0.0, 0.0))
    final_color = [accumulated_color[i] + transmittance * background[i] for i in range(3)]
    return tuple(final_color)
```

### Parameters and Typical Values
*   **Scatter Coefficient:** Default 1.0. Increases brightness [S1].
*   **Absorption Coefficient:** Default 1.0. Increases opacity [S1].
*   **Depth:** Multiplies transparency color 0-1 values to real cm distances. Aware of scene scale [S2, unofficial][S3].
*   **Anisotropy:** Default 0 (isotropic). Positive values scatter forward (Henyey-Greenstein) [S2, unofficial][S3].
*   **Blackbody Temperature:** Default 6500K [S1].
*   **Blackbody Offset:** Default 1.0 [S1].
*   **Shadow Density Scale:** Advanced parameter to emulate multiple scattering by adjusting opacity to shadow rays [S1].

### Edge Cases and Pitfalls
*   **VRAM Limit:** Volume objects must fit entirely in GPU memory. If they do not, rendering aborts with an out-of-VRAM error [S1].
*   **Missing Channels:** If `scatter_channel_name` or `emission_channel_name` are not set or do not exist in the OpenVDB file, the volume will not render (renders black/empty) [S1].
*   **Missing Lights:** If no volume-affecting lights are present (volume contribution scale $\le 0.0$), the volume renders black [S1].
*   **Smoke/Fire Interference:** Smoke (scatter/absorption) obstructs fire (emission). Adjustments to scatter/absorption must not interfere too much with emission [S1].
*   **Temperature Range Remapping:** Temperature channel ranges vary by 3D app. Range remapping may be necessary if the emission ramp does not align with the data range [S1].
*   **Wavelength Tinting:** Light traveling far through the medium becomes tinted with the opposite of the transparency color as other wavelengths are exhausted (e.g., deep water blue) [S2, unofficial][S3].

## Operating characteristics

*   **Memory Complexity:** $O(V)$, where $V$ is the total number of voxels in the OpenVDB file. All data must reside in GPU VRAM [S1].
*   **Time Complexity:** $O(R \cdot M)$, where $R$ is the number of rays and $M$ is the number of march steps per ray [G]. Cost increases with density and the number of scattering bounces simulated via Volume Trace Depth [S2, unofficial][S3][S4].
*   **Performance:** Volumes are expensive due to the cost of ray marching and multiple scattering calculations [S2, unofficial][S3]. Single scattering is sufficient for thin media; multiple scattering requires higher Volume Trace Depth or tricks like Shadow Density Scale [S1][S2, unofficial][S4].
*   **Strengths:** Artist-friendly parameters (transparency color, depth), physically plausible wavelength-dependent absorption, integration with OpenVDB [S1][S2, unofficial][S3].
*   **Limitations:** High memory usage (no out-of-core support), sensitive to light setup, requires careful tuning of scatter/absorption/emission balance [S1][S2, unofficial].

## Background

*   **Origin:** The Standard Volume Shader is part of the Redshift renderer by Maxon [S1][S2, unofficial][S3].
*   **Development:** It is described internally as a close relative of Random Walk Subsurface Scattering, adapted for heterogeneous media [S2, unofficial][S3].
*   **Usage:** Used for rendering smoke, fire, clouds, and fog in 3D applications like Cinema 4D, Maya, and Houdini via Redshift [S1].
