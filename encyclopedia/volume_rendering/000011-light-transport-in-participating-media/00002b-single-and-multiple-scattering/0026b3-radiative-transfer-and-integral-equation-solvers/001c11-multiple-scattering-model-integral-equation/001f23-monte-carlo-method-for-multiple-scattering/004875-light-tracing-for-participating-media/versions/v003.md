# Light Tracing for Participating Media

Also called: Monte Carlo light tracing with random distance, Pattanaik and Mudur, Pattanaik and Mudur light tracing, Pattanaik et al. method, Random distance sampling (Light Tracing)

## Overview
Light tracing for participating media is a Monte Carlo method that traces bundles of light from the source through the volume to find interaction points (absorption or scattering) [S1][S2, book]. Unlike constant distance sampling, it is unbiased because it samples the distance to the next interaction continuously rather than restricting it to multiples of a discrete step size [S2, book].

## How it works
### Inputs and Outputs
**Inputs:**
*   Volume geometry and bounds [G].
*   Extinction coefficient field $\sigma_t(\mathbf{x})$ (or optical thickness $\kappa_t$) [S1][S2, book].
*   Scattering coefficient $\sigma_s(\mathbf{x})$ and absorption coefficient $\sigma_a(\mathbf{x})$, where $\sigma_t = \sigma_s + \sigma_a$ [S1][S2, book].
*   Phase function $p(\omega_i, \omega_o)$ [S1][S2, book].
*   Light source emission distribution [G].
*   Rendering algorithm parameters (number of bundles, variance reduction flags) [S1][S2, book].

**Outputs:**
*   Radiance values at image plane pixels or voxel storage buffers [S1][S2, book].

### Data Structures
The method typically uses a storage scheme suited for isotropic scattering, which can be modified to handle anisotropic scattering [S1][S2, book]. For image-based implementations, a pixel buffer accumulates contributions when bundles hit the image plane [S1][S2, book].

### Numbered Steps

1.  **Initialize Bundle:** Shoot a light bundle from the light source with initial direction $\omega_0$ and weight $W_0 = 1.0$ (or scaled by source intensity) [G].

2.  **Sample Distance to Interaction:** Sample the distance $s$ to the next interaction point using the cumulative distribution function (CDF) derived from the extinction coefficient [S1][S2, book]. For homogeneous media, $F(s) = 1 - e^{-\sigma_t s}$ [S2, book]. For inhomogeneous media, $F(s) = 1 - \exp(-\int_0^s \sigma_t(u) du)$ [S1]. The inverse CDF yields $s = -\ln(1 - \xi)/\sigma_t$ where $\xi \in [0, 1)$ [S2, book].

3.  **Move Bundle:** Update the bundle position: $\mathbf{x}_{new} = \mathbf{x}_{old} + s \cdot \omega$ [G]. Check for boundary intersection. If the bundle exits the volume, terminate the path [G].

4.  **Determine Interaction Type:** At $\mathbf{x}_{new}$, decide if the event is absorption or scattering [S1][S2, book]. Two methods are described:
    *   **Method A: Simple Absorption:** Perform a sampling process to decide the event type based on the ratio of scattering to extinction $\Omega = \frac{\sigma_s}{\sigma_t}$ [S1][S2, book]. Generate $\xi \in [0, 1)$. If $\xi < \Omega$, scattering occurs and the weight updates to $W \cdot \frac{\sigma_s}{\sigma_t}$ [S1][S2, book]. If $\xi \ge \Omega$, absorption occurs and the path terminates [S1][S2, book].
    *   **Method B: Absorption Suppression:** The bundle always scatters [S1][S2, book]. The flux reduces by multiplying the weight by $\Omega = \frac{\sigma_s}{\sigma_t}$ [S1][S2, book]. This avoids path termination due to absorption but reduces the weight, increasing variance [S1][S2, book].

5.  **Scattering Event:** If scattering occurs, sample the new direction $\omega_{new}$ from the phase function $p(\omega_{old}, \omega_{new})$ [G]. Update direction: $\omega = \omega_{new}$ [G]. Repeat from Step 2.

6.  **Termination:** If the bundle hits the image plane, add $W$ to the corresponding pixel [S1][S2, book]. If the bundle exits the volume or absorption occurs in Simple Absorption, terminate [G].

### Variance Reduction Techniques
The sources propose three specific techniques [S1][S2, book]:
1.  **Forced Interaction:** Force a bundle to interact with each voxel it passes through [S1][S2, book].
2.  **Absorption Suppression:** As described in Step 4, always scatter and reduce weight by $\frac{\sigma_s}{\sigma_t}$ [S1][S2, book].
3.  **Particle Divergence:** At scattering points, split the outgoing bundle into many smaller bundles [S1][S2, book]. This increases the number of rays traveling through the volume, improving the sampling of energy leaving the volume [S1][S2, book].

### Pseudocode

```python
import math

def random():
    """Returns a uniform random number in [0, 1)."""
    return 0.0  # Standard uniform RNG implementation [G]

def light_trace_participating_media(volume, light_source, camera, num_bundles):
    """
    Monte Carlo light tracing for participating media.
    Uses random distance sampling (Pattanaik et al. method).
    """
    pixel_buffer = [0.0] * (camera.width * camera.height)

    for _ in range(num_bundles):
        # 1. Initialize bundle from light source
        origin, direction, weight = light_source.sample()
        pos = origin
        dir = direction
        w = weight

        while w > 1e-6:
            # 2. Sample distance to next interaction
            xi_dist = random()
            sigma_t = volume.get_extinction(pos)

            if sigma_t == 0:
                # Handle vacuum: move to next boundary
                dist = volume.distance_to_boundary(pos, dir)
                if dist is None:
                    break
                pos = pos + dir * dist
                continue

            # Inverse CDF for homogeneous media: s = -ln(1-xi)/sigma_t
            s = -math.log(1.0 - xi_dist) / sigma_t
            next_pos = pos + dir * s

            # 3. Check boundary intersection
            if not volume.contains(next_pos):
                break

            # 4. Determine interaction type (Absorption Suppression)
            sigma_s = volume.get_scattering(next_pos)
            albedo = sigma_s / sigma_t

            # Always scatter, reduce weight by albedo
            w *= albedo
            if w < 1e-6:
                break

            # 5. Scattering event
            new_dir = volume.phase_function.sample(dir)
            dir = new_dir
            pos = next_pos

            # 6. Check image plane intersection
            hit, pixel_idx = camera.intersect(pos, dir)
            if hit:
                pixel_buffer[pixel_idx] += w

    return pixel_buffer
```

### Edge Cases and Pitfalls
*   **Anisotropic Scattering:** The basic storage scheme is suited for isotropic scattering. For anisotropic scattering, the storage scheme must be modified to account for directionality [S1][S2, book].
*   **Precision:** Sampling distance continuously avoids the bias of constant distance sampling. Using constant distance sampling leads to biased results because bundles can only be scattered at distances which are multiples of a step size $\Delta$, and the expected length before scattering won't be equal to the mean free path without absorption [S2, book].
*   **Performance:** To get accurate sampling of energy leaving the volume, the number of rays must be higher than in per-voxel storage methods [S1][S2, book].

## Operating characteristics
*   **Time Complexity:** $O(N \cdot M)$, where $N$ is the number of bundles and $M$ is the average number of scattering events per bundle [G].
*   **Memory Complexity:** $O(P)$ for pixel buffer or $O(V)$ for voxel storage, where $P$ is pixel count and $V$ is voxel count [G].
*   **Strengths:** Unbiased result (unlike constant distance sampling); effective for complex lighting; no need for eye-point sampling [S2, book].
*   **Limitations:** Requires many bundles for accurate sampling of energy leaving the volume; variance can be high in sparse media without variance reduction techniques [S1][S2, book].
*   **When to use:** Scenes with complex light sources or when light tracing is more efficient than path tracing (e.g., caustics in participating media) [G].
*   **When not to use:** Simple homogeneous media where analytical solutions or simpler methods suffice; scenes where eye-tracing is more efficient (e.g., small light sources) [G].

## Background
The method was introduced by Pattanaik and Mudur [66] and Pattanaik et al. [14] as a Monte Carlo light tracing technique for participating media [S1][S2, book]. It uses a sampling process to find points of interaction within the volume [S1][S2, book]. The method is part of the broader family of Monte Carlo methods for solving the radiative transfer equation, specifically addressing multiple scattering [S2, book]. It is often compared to bidirectional path tracing for non-emitting participating media, which combines light shooting and light gathering [S2, book].
