# Flux-Limited Diffusion

Also called: Flux-Limited Diffusion (FLD) Solver, Flux-Limited Radiative Diffusion, Numerical FLD solver

## Overview
Flux-Limited Diffusion (FLD) is a numerical method for solving the radiative transfer equation in participating media by modifying the classical diffusion approximation (CDA) to handle heterogeneous media, vacuum regions, and transitions to the transport regime [S1]. It improves upon CDA by replacing the constant diffusion coefficient with a flux-limited, fluence-dependent expression that enforces the physical constraint that flux magnitude does not exceed fluence, ensuring accuracy where opacity is low [S1].

## How it works
**Inputs and Outputs**
*   **Inputs:** Voxel grids for emission field $j_p$ (power per unit volume), extinction field $\sigma_{tp}$ (inverse length), and albedo field $\alpha_p$ (dimensionless). Grid coordinates $p=(i,j,k)$ with voxel edge length $\Delta l$.
*   **Outputs:** Fluence grid $\phi_p$ and diffusion coefficient grid $D_p$.

**Data Structures**
*   **Grids:** 3D arrays for $\phi$, $D$, $j$, $\sigma_t$, $\alpha$.
*   **Stencil:** 6-point stencil $s(p)$ surrounding point $p$, consisting of neighbors $(i\pm1, j, k), (i, j\pm1, k), (i, j, k\pm1)$.

**Parameters**
*   **Flux Limiter:** Levermore–Pomraning limiter is used in practical examples [S1].
*   **SOR Factor $\omega$:** Relaxation factor, $0 < \omega < 2$.
*   **Extinction Tolerance $\sigma_\varepsilon$:** Empirical tolerance for vacuum regions, $\sigma_\varepsilon = 10^{-3}/L$ where $L$ is grid extent [S1].
*   **Epsilon $\varepsilon$:** Small constant for numerical stability, $\varepsilon = 10^{-20}$ [S1].
*   **Convergence Tolerance:** $\bar{R}/\bar{j} < 10^{-6}$ (double precision) or $10^{-4}$ (single precision) [S1].
*   **Grid Resolution:** Fluence solve often performed at 1/4 of the original dataset resolution to exploit low spatial frequency of multiply-scattered light [S1].

**Formulas**
*   **Knudsen Number:** $\mathcal{R}_p = \frac{\max(|\nabla \phi_p|, \varepsilon \bar{j})}{\max(\sigma_p \phi_p, \varepsilon \bar{j})}$ [S1].
*   **Flux Limiter Function $\mathcal{F}(\mathcal{R})$:** Must satisfy $\lim_{\mathcal{R} \to 0} \mathcal{F}(\mathcal{R}) = 1/3$ and $\lim_{\mathcal{R} \to \infty} \mathcal{R} \mathcal{F}(\mathcal{R}) = 1$ [S1]. The Levermore–Pomraning limiter is $\mathcal{F}(\mathcal{R}) = \coth(\mathcal{R}) - 1/\mathcal{R}$ [S1].
*   **Diffusion Coefficient:** $D_p = \frac{\mathcal{F}(\mathcal{R}_p)}{\max(\sigma_p, \sigma_\varepsilon)}$ [S1].
*   **Gradient Discretization:** $\nabla \phi_P = \frac{1}{2\Delta l} \begin{pmatrix} \phi_{i+1,j,k} - \phi_{i-1,j,k} \\ \phi_{i,j+1,k} - \phi_{i,j-1,k} \\ \phi_{i,j,k+1} - \phi_{i,j,k-1} \end{pmatrix}$ [S1].
*   **Discretized Equation:** $\frac{\sum_s D_{ps} \phi_s - \phi_p \sum_s D_{ps}}{\Delta l^2} = (1 - \alpha_p) \sigma_p \phi_p - j_p$, where $D_{ps} := (D_p + D_s)/2$ [S1].
*   **Local Update Rule:** $\phi_p^0 = \frac{j_p \Delta l^2 + \sum_s D_{ps} \phi_s}{(1 - \alpha_p) \sigma_p \Delta l^2 + \sum_s D_{ps}}$ [S1].
*   **SOR Update:** $\phi_p \leftarrow \omega \phi_p^0 + (1-\omega)\phi_p$ [S1].
*   **Residual:** $R_p = (\text{numerator} - \phi_p \cdot \text{denominator}) / \Delta l^2$ [S1].

**Steps**
1.  **Preprocessing:** Impose extinction tolerance $\sigma_p \leftarrow \max(\sigma_p, \sigma_\varepsilon)$. Compute RMS emission field $\bar{j}$.
2.  **Initialization:** Initialize $\phi_p = \varepsilon \bar{j} \Delta l$ and $D_p = \varepsilon \Delta l$ for all $p$.
3.  **Iteration Loop:** Repeat until convergence:
    a.  **Red Pass:** For all non-boundary red points (checkerboard coloring):
        i.   Compute $\nabla \phi_p$ using central differences.
        ii.  Compute $\mathcal{R}_p$.
        iii. Update $D_p$ using $\mathcal{F}(\mathcal{R}_p)$.
        iv.  Compute $D_{ps}$ for all 6 neighbors $s$.
        v.   Compute $\phi_p^0$ using the local update rule.
        vi.  Apply SOR: $\phi_p \leftarrow \omega \phi_p^0 + (1-\omega)\phi_p$.
        vii. Compute residual $R_p$.
    b.  **Black Pass:** For all non-boundary black points, perform steps a.i–a.vii.
    c.  **Convergence Check:** Compute RMS residual $\bar{R}$ (ignoring boundary voxels). If $\bar{R}/\bar{j} < \text{tolerance}$, stop.
4.  **Boundary Conditions:** Dirichlet conditions are applied by ignoring voxels abutting the six grid faces during updates, setting $\phi = \varepsilon \bar{j} \Delta l$ at boundaries [S1].

**Pseudocode**
```python
def solve_fld(j, sigma_t, alpha, L, delta_l, omega, tol, epsilon=1e-20):
    # Preprocessing
    sigma_eps = 1e-3 / L
    sigma_t = max(sigma_t, sigma_eps)
    j_rms = rms(j)
    
    # Initialization
    phi = epsilon * j_rms * delta_l
    D = epsilon * delta_l
    R = zeros_like(phi)
    
    # Checkerboard masks
    is_red = ((i + j + k) % 2 == 0)
    is_black = ((i + j + k) % 2 == 1)
    is_boundary = (i==0 or i==L-1 or j==0 or j==L-1 or k==0 or k==L-1)
    
    while True:
        # Red Pass
        for p in points(is_red and not is_boundary):
            grad_phi = compute_gradient(phi, p, delta_l)
            R_val = max(norm(grad_phi), epsilon * j_rms) / max(sigma_t[p] * phi[p], epsilon * j_rms)
            F_val = levermore_pomraning(R_val)
            D[p] = F_val / sigma_t[p]
            
            sum_D_phi = 0
            sum_D = 0
            for s in stencil(p):
                D_ps = (D[p] + D[s]) / 2
                sum_D_phi += D_ps * phi[s]
                sum_D += D_ps
            
            numerator = j[p] * delta_l**2 + sum_D_phi
            denominator = (1 - alpha[p]) * sigma_t[p] * delta_l**2 + sum_D
            phi_new = numerator / denominator
            phi[p] = omega * phi_new + (1 - omega) * phi[p]
            
            # Residual calculation for monitoring
            R[p] = (numerator - phi[p] * denominator) / delta_l**2
            
        # Black Pass
        for p in points(is_black and not is_boundary):
            # Same logic as Red Pass
            grad_phi = compute_gradient(phi, p, delta_l)
            R_val = max(norm(grad_phi), epsilon * j_rms) / max(sigma_t[p] * phi[p], epsilon * j_rms)
            F_val = levermore_pomraning(R_val)
            D[p] = F_val / sigma_t[p]
            
            sum_D_phi = 0
            sum_D = 0
            for s in stencil(p):
                D_ps = (D[p] + D[s]) / 2
                sum_D_phi += D_ps * phi[s]
                sum_D += D_ps
            
            numerator = j[p] * delta_l**2 + sum_D_phi
            denominator = (1 - alpha[p]) * sigma_t[p] * delta_l**2 + sum_D
            phi_new = numerator / denominator
            phi[p] = omega * phi_new + (1 - omega) * phi[p]
            
            R[p] = (numerator - phi[p] * denominator) / delta_l**2
            
        # Boundary Conditions
        phi[is_boundary] = epsilon * j_rms * delta_l
        
        # Convergence Check
        R_rms = rms(R[not is_boundary])
        if R_rms / j_rms < tol:
            break
            
    return phi, D

def levermore_pomraning(R):
    if R == 0: return 1/3
    return 1/tanh(R) - 1/R

def compute_gradient(phi, p, delta_l):
    i, j, k = p
    return (1/(2*delta_l)) * np.array([
        phi[i+1, j, k] - phi[i-1, j, k],
        phi[i, j+1, k] - phi[i, j-1, k],
        phi[i, j, k+1] - phi[i, j, k-1]
    ])
```

## Operating characteristics
*   **Complexity:** Time complexity is dominated by the iterative Gauss-Seidel solver. Memory complexity is linear with grid size, requiring storage for $\phi$, $D$, and input fields.
*   **Performance:** FLD is roughly twice as computationally expensive as CDA due to additional memory access per voxel to compute the Knudsen number [S1]. It is still much faster than path tracing [S1].
*   **Accuracy:** FLD produces results closer to path-traced ground truth than CDA, especially in shadowed regions, indirect lighting, and transitions to vacuum [S1].
*   **Limitations:** Dirichlet boundary conditions introduce unphysical effects near boundaries, though they do not significantly corrupt the bulk solution [S1]. In vacuum regions, convergence is negatively affected without the extinction tolerance $\sigma_\varepsilon$ [S1].

## Background
FLD was developed originally for radiative transfer applications in astrophysics [LP81, TS01] and nuclear physics [LK74] [S1]. It was introduced to computer graphics to improve the accuracy of multiple scattering simulations in heterogeneous media [S1].
