# Neural Network RTE Simplification via Albedo Series

Also called: Albedo power series for neural prediction, Radiation Transfer Equation Simplification for Neural Network, Scattering term approximation

## Overview
This method simplifies the classical Radiative Transfer Equation (RTE) by expressing the co-scattering term as an infinite power series of the single-scattering albedo ($\eta$), enabling the prediction of multiple scattering effects using a neural network [S1, unofficial]. It differs from [Full Propagator Approximation for Multiply-Scattered Radiance](1298-full-propagator-approximation-for-multiply-scattered-radianc.md) by explicitly decoupling the albedo dependency into a series expansion, and from [Monte Carlo Method for Multiple Scattering](1940-monte-carlo-method-for-multiple-scattering.md) by replacing stochastic sampling with deterministic neural inference [S1, unofficial].

## How it works
**Inputs and Outputs:**
*   **Inputs:** Position $p$, direction $\omega$, density features, transmittance features, and phase features. These are pre-calculated and stored in a lookup table based on particle coordinates and sampling templates [S1, unofficial].
*   **Outputs:** Output radiance $L_o(p, \omega)$ [S1, unofficial].

**Data Structures:**
*   **Pre-calculation Table:** Stores sampling features (density, transmittance, phase) for discrete particle positions and template points [S1, unofficial].
*   **Neural Network:** A backbone network with three identical sub-networks (for density, transmittance, and phase features) that takes the pre-calculated features as input and outputs the scattering term coefficients or the final radiance [S1, unofficial].

**Definitions:**
*   $L_o(p, \omega)$: Output radiance at position $p$ in direction $\omega$.
*   $L_i(p, \omega)$: Incident radiance.
*   $L_e(p, \omega)$: Self-illumination term (ignored in simplified form) [S1, unofficial].
*   $\mu_a(p)$: Absorption coefficient.
*   $\mu_s(p)$: Scattering coefficient.
*   $\mu_t(p) = \mu_a(p) + \mu_s(p)$: Decay coefficient.
*   $\eta = \mu_s / \mu_t$: Single-scattering albedo [S1, unofficial].
*   $f_p(\omega_i \to \omega)$: Phase function.
*   $T(p, y) = e^{-\int_p^y \mu_t(x) dx}$: Transmittance from $p$ to $y$ [S1, unofficial].
*   $F(p, \omega)$: Co-scattering term (scattering in the current direction) [S1, unofficial].
*   $F_i(p, \omega)$: The $i$-th order scattering term.
*   $\Pi F(p, \omega)$: Integral operator defined as $\int_\Omega \int_p^z f_p T \mu_t F(p, \omega) dx d\omega_i$ [S1, unofficial].

**Steps:**
1.  **Simplify the RTE:** Assume no self-illumination ($L_e = 0$) and constant albedo. The RTE is simplified to:
    $$ \frac{\partial L_o(p, \omega)}{\partial \omega} = -\mu_t(p)L_i(p, \omega) + \mu_s(p)F(p, \omega) $$
    [S1, unofficial]

2.  **Integral Form:** Integrate the simplified RTE along the ray to obtain:
    $$ L_o(p, \omega) = T(p, z)L_i(z, \omega) + \int_p^z T(p, x)\mu_s(x)F(x, \omega) dx $$
    [S1, unofficial]

3.  **Albedo Series Expansion:** Express the co-scattering term $F(p, \omega)$ as an infinite series of albedo powers:
    $$ F(p, \omega) = \sum_{i=0}^{\infty} \eta^i F_i(p, \omega) $$
    [S1, unofficial]

4.  **Define Scattering Terms:**
    *   Zeroth order: $F_0(p, \omega) = f_p T I$ (or $T \cdot I$ for isotropic case where $f_p$ is constant) [S1, unofficial].
    *   Recursive step: $F_{i+1}(p, \omega) = \Pi F_i(p, \omega)$, where $\Pi F_i(p, \omega) = \int_\Omega \int_p^z f_p T \mu_t F_i(p, \omega) dx d\omega_i$ [S1, unofficial].

5.  **Neural Prediction:** Use the backbone neural network to predict the necessary components of the series or the final radiance directly, bypassing the explicit calculation of high-order terms. The network inputs are pre-calculated sampling features (density, transmittance, phase) [S1, unofficial].

**Pseudocode:**
```python
def compute_radiance_neural(p, omega, pre_calc_table):
    """
    Compute radiance using neural network prediction of albedo series.
    
    Args:
        p: Position vector.
        omega: Direction vector.
        pre_calc_table: Lookup table containing pre-calculated sampling features.
        
    Returns:
        L_o: Output radiance.
    """
    # 1. Retrieve pre-calculated features from table
    # Features include density, transmittance, and phase information
    # based on particle coordinates and template points.
    density_feat = pre_calc_table.get_density_features(p)
    transmittance_feat = pre_calc_table.get_transmittance_features(p, omega)
    phase_feat = pre_calc_table.get_phase_features(p, omega)
    
    # 2. Input features to the backbone neural network
    # The network consists of three identical sub-networks for each feature type.
    # This step replaces the explicit summation of the infinite series.
    # The network outputs the predicted radiance or scattering term components.
    L_o = neural_network.predict(
        density_feat, 
        transmittance_feat, 
        phase_feat
    )
    
    return L_o
```

**Edge Cases and Pitfalls:**
*   **Precision:** The series convergence depends on $\eta < 1$. If $\eta \approx 1$, convergence is slow, and the neural network must be trained to handle high-albedo scenarios [S1, unofficial].
*   **Boundary Conditions:** The transmittance $T(p, y)$ requires accurate integration of $\mu_t$. Errors in $\mu_t$ estimation propagate through the series [S1, unofficial].
*   **Phase Function:** The simplification assumes the phase function $f_p$ is constant for isotropic scattering in the basic form, but anisotropic materials require the full phase function in the operator $\Pi$ [S1, unofficial].

A prediction function that extrapolates radiance from a source albedo ($\alpha_s$) to a target albedo ($\alpha_t$) using the rendered source radiance ($R_s$) and gradient ($G_s$), designed to handle complex non-linear albedo behavior better than linear or log-linear models.

## Operating characteristics
*   **Time Complexity:** $O(1)$ per pixel after pre-calculation and network inference, as it avoids iterative scattering calculations [S1, unofficial].
*   **Memory Complexity:** $O(N)$ for the pre-calculation table, where $N$ is the number of sampling points [S1, unofficial].
*   **Performance:** Enables real-time rendering for high albedo anisotropic materials [S1, unofficial].
*   **Strengths:** Real-time capability, handles multiple scattering without stochastic noise [S1, unofficial].
*   **Limitations:** Requires pre-calculation and training; accuracy depends on the neural network's ability to generalize to unseen albedo values [S1, unofficial].

## Background
The method originates from research on real-time rendering of high albedo anisotropic materials with multiple scattering [S1, unofficial]. It addresses the computational cost of solving the full RTE for participating media by leveraging neural networks to approximate the infinite albedo series [S1, unofficial].
