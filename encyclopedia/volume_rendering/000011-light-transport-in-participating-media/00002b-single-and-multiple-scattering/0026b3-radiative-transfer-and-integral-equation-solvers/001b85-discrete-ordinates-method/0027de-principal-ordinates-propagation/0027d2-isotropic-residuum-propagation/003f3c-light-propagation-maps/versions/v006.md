# Light Propagation Maps

Also called: Fattal's LPM, Fattal's Original LPM Algorithm, Fattal's method, Original LPM iteration

## Overview
Light Propagation Maps (LPM) is a Discrete Ordinate Method (DOM) technique for computing multiple scattering in participating media [S1]. It approximates the radiative transfer equation by decoupling spatial and directional sampling: it uses high-resolution 2D ray maps for iterative light propagation to reduce artifacts like false scattering and ray effects, while using a coarse 3D grid for storing accumulated radiance to minimize memory usage [S1].

## How it works
**Inputs and Outputs:**
*   **Input:** A 3D voxel grid representing the medium with absorption coefficient $K_a$, scattering coefficient $K_s$, and phase function $p(\omega, \omega')$ [S1]. Boundary conditions (incoming radiance) and self-emission radiance [S1].
*   **Output:** Average scattered radiance $I_{xyz}^d$ for each voxel $xyz$ and storage direction $d$ [S1].

**Data Structures:**
1.  **3D Grid:** Stores medium properties ($K_a, K_s$) and radiance buffers [S1].
    *   $I_{xyz}^d$: Average radiance in voxel $xyz$ along direction $d$ [S1].
    *   $U_{xyz}^{d,p}$: Unscattered radiance for storage direction $d$ at iteration $p$ [S1].
    *   *Note:* In practice, only two $U$ buffers are kept (for $p-1$ and $p$) using a swap mechanism to reuse memory [S1].
2.  **Light Propagation Maps (LPMs):** A set of 2D arrays of high spatial resolution [S1]. Each LPM corresponds to a face of the coarse 3D grid [S1].
    *   Each element $(r,s)$ in an LPM stores a set of rays originating at $(r,s)$ with directions sampled from the unit sphere $S^2$ [S1].

**Parameters:**
*   $\varepsilon$: Termination threshold. Iteration stops when $\max_{xyz} |U_{d,pprev,xyz}| < \varepsilon$ [S1].
*   $p$: Iteration number (scattering order) [S1].

**Formulas:**
1.  **Average Radiance Definition:**
    $$I_{xyz}^d \approx (V_{xyz}^d)^{-1} \int_{C_{xyz}} \int_{\Omega^d} \frac{K_{S_{xyz}}}{4\pi} \int_{\omega' \in S^2} L(p, \omega') p(\omega, \omega') d\omega' d\omega dp \quad (2)$$
    Where $V_{xyz}^d = \Delta V |\Omega^d|$ is the product of voxel volume and solid angle [S1].

2.  **Ray Radiance Update (Transport):**
    $$L_{r,s}^i = L_{r,s}^{i,t-1} e^{-\Delta l_q(K_a + K_s)/\omega_z^i} + U_{xyz}^{d,p} \times \frac{1 - e^{-\Delta l_q(K_a + K_s)/\omega_z^i}}{K_a + K_s} \quad (3)$$
    Where:
    *   $L_{r,s}^i$: Radiance leaving the $t$-th voxel for ray $i$ at element $(r,s)$ [S1].
    *   $\Delta l_q$: Distance traversed in the voxel [S1].
    *   $\omega_z^i$: Z-component of direction $i$ [S1].
    *   $U_{xyz}^{d,p}$: Stored unscattered radiance for direction $d$ (closest to $i$) at iteration $p$ [S1].

3.  **Scattering Contribution (Storage):**
    $$R = (V_{xyz}^d)^{-1} A_{r,s} F^{i,d} L_{r,s}^{i,t} \frac{1 - e^{-\Delta l_q K_s}}{\omega_s^i} \quad (4)$$
    Where:
    *   $A_{r,s}$: Area of the LPM sample $(r,s)$ [S1].
    *   $F^{i,d}$: Precomputed phase function integral for propagation direction $i$ and storage direction $d$ [S1].
    *   $\omega_s^i$: Component of direction $i$ relevant to the storage geometry [S1].

4.  **Phase Function Integral:**
    $$F^{i,d} = \frac{1}{4\pi} \int_{\Omega^i} \int_{\Omega^d} p(\omega, \omega') d\omega d\omega' \quad (5)$$
    Where $d$ is the storage direction closest to propagation direction $i$ [S1].

**Algorithm Steps:**
1.  **Initialization:** Set $p_{prev} = 0$ [S1]. Initialize $U_{d,pprev,xyz}$ and $I_{d,xyz}$ with medium self-emission radiance (if any) [S1]. Create LPMs for each face of the 3D grid [S1].
2.  **Iteration Loop:** While $\max_{xyz} |U_{d,pprev,xyz}| \ge \varepsilon$ and $p > 0$: [S1]
    a. Set $p_{cur} = (p_{prev} + 1) \% 2$ [S1].
    b. Initialize $U_{d,pcur,xyz}$ to 0 [S1].
    c. For each LPM: [S1]
        i. For each propagation direction $i$: [S1]
            1. For each element $(r,s)$ of the current map: [S1]
                * If $p == 0$: Initialize $L_{r,s}^{i,0}$ with boundary conditions [S1].
                * Else: Set $L_{r,s}^{i,0}$ to 0 [S1].
            2. March rays through the volume: [S1]
                * For each intersected voxel $t$: [S1]
                    * Update ray radiance $L_{r,s}^{i,t}$ using Eq. (3) and $U_{d,pprev,xyz}$ [S1].
                    * Calculate scattering contribution $R$ using Eq. (4) [S1].
                    * Update $U_{d,pcur,xyz}$ and $I_{d,xyz}$ with $R$ [S1].
                    * *Boundary Handling:* When a ray leaves the medium at boundary point A, generate a new ray of the same direction with zero radiance from the opposite point B to maintain a constant number of rays [S1].
    d. Set $p_{prev} = p_{cur}$ [S1].

**Pseudocode:**
```python
def light_propagation_maps(volume, boundary_conditions, epsilon, directions):
    """
    volume: 3D list of dicts with keys 'Ka', 'Ks', 'self_emission', 'volume'
    boundary_conditions: function returning radiance at boundary
    epsilon: termination threshold
    directions: list of direction vectors (omega)
    """
    X, Y, Z = len(volume), len(volume[0]), len(volume[0][0])
    
    # Initialize buffers: Ud stores unscattered radiance, I stores average radiance
    Ud_prev = [[[0.0 for _ in range(Z)] for _ in range(Y)] for _ in range(X)]
    Ud_cur = [[[0.0 for _ in range(Z)] for _ in range(Y)] for _ in range(X)]
    I = [[[0.0 for _ in range(Z)] for _ in range(Y)] for _ in range(X)]
    
    # Initialize with self-emission
    for x in range(X):
        for y in range(Y):
            for z in range(Z):
                Ud_prev[x][y][z] = volume[x][y][z]['self_emission']
                I[x][y][z] = volume[x][y][z]['self_emission']
                
    p_prev = 0
    p = 1
    
    # Precompute F^{i,d} for all direction pairs using Eq. (5)
    F = {}
    for i in directions:
        F[i] = {}
        for d in directions:
            # Approximate integral over solid angles for directions i and d
            F[i][d] = 0.25 / 3.14159 * sum(1.0 for _ in range(100)) # Placeholder for standard quadrature [G]
            
    # Create LPMs for each face of the grid
    lpm_faces = []
    for face in ['x_min', 'x_max', 'y_min', 'y_max', 'z_min', 'z_max']:
        lpm_faces.append({'face': face, 'directions': directions})
        
    while True:
        max_val = 0.0
        for x in range(X):
            for y in range(Y):
                for z in range(Z):
                    val = abs(Ud_prev[x][y][z])
                    if val > max_val:
                        max_val = val
        if max_val < epsilon or p == 0:
            break
            
        p_cur = (p_prev + 1) % 2
        
        # Reset current buffer
        for x in range(X):
            for y in range(Y):
                for z in range(Z):
                    Ud_cur[x][y][z] = 0.0
                    
        for lpm in lpm_faces:
            for dir_i in lpm['directions']:
                for r in range(X): # Iterate over LPM dimensions
                    for s in range(Y):
                        # Initialize ray radiance
                        if p == 0:
                            L_ray = boundary_conditions(lpm['face'], r, s, dir_i)
                        else:
                            L_ray = 0.0
                            
                        # Ray marching setup
                        origin = get_lpm_origin(lpm, r, s)
                        ray_pos = list(origin)
                        ray_dir = dir_i
                        
                        while True:
                            voxel = volume[ray_pos[0]][ray_pos[1]][ray_pos[2]]
                            delta_l = compute_distance_to_voxel_face(ray_pos, ray_dir)
                            
                            # Guard against division by zero [G]
                            omega_z = abs(ray_dir[2]) if abs(ray_dir[2]) > 1e-6 else 1e-6
                            omega_s = abs(ray_dir[0]) if abs(ray_dir[0]) > 1e-6 else 1e-6 # Example storage axis
                            
                            exp_term = math.exp(-delta_l * (voxel['Ka'] + voxel['Ks']) / omega_z)
                            
                            # Find closest storage direction d to i
                            dir_d = min(directions, key=lambda d: dot_product(d, dir_i))
                            U_prev = Ud_prev[ray_pos[0]][ray_pos[1]][ray_pos[2]]
                            
                            # Update ray radiance (Eq. 3)
                            L_ray = L_ray * exp_term + U_prev * (1.0 - exp_term) / (voxel['Ka'] + voxel['Ks'])
                            
                            # Calculate scattering contribution (Eq. 4)
                            A_rs = 1.0 # LPM sample area
                            V_d = voxel['volume'] * 1.0 # Solid angle placeholder
                            F_id = F[dir_i][dir_d]
                            
                            R = (1.0 / V_d) * A_rs * F_id * L_ray * (1.0 - math.exp(-delta_l * voxel['Ks'])) / omega_s
                            
                            # Update buffers
                            Ud_cur[ray_pos[0]][ray_pos[1]][ray_pos[2]] += R
                            I[ray_pos[0]][ray_pos[1]][ray_pos[2]] += R
                            
                            # Advance ray
                            ray_pos[0] += ray_dir[0] * delta_l
                            ray_pos[1] += ray_dir[1] * delta_l
                            ray_pos[2] += ray_dir[2] * delta_l
                            
                            # Boundary handling: if ray leaves, spawn new ray from opposite side
                            if not is_inside_volume(ray_pos):
                                opposite_point = get_opposite_boundary_point(ray_pos, ray_dir)
                                L_ray = 0.0
                                ray_pos = list(opposite_point)
                                
        p_prev = p_cur
        p += 1
        
    return I

def dot_product(a, b):
    return a[0]*b[0] + a[1]*b[1] + a[2]*b[2]

def get_lpm_origin(lpm, r, s):
    # Returns 3D coordinates based on LPM face
    return [r, s, 0] # Simplified for z_min face

def compute_distance_to_voxel_face(pos, dir):
    return 1.0 # Simplified grid step

def is_inside_volume(pos):
    return 0 <= pos[0] < X and 0 <= pos[1] < Y and 0 <= pos[2] < Z

def get_opposite_boundary_point(pos, dir):
    # Returns opposite boundary coordinate
    return [0, 0, 0] # Simplified
```

**Edge Cases and Pitfalls:**
*   **Ray Effects and False Scattering:** Standard DOM suffers from these; LPM mitigates them via fine spatial sampling in LPMs [S1].
*   **Boundary Conditions:** Rays leaving the volume must be handled by spawning new rays from the opposite boundary to maintain ray density [S1].
*   **Precision:** Division by $\omega_z^i$ and $\omega_s^i$ requires guards against zero values [G].
*   **Memory:** Storing all LPMs and radiance buffers for high-resolution volumes can exceed GPU memory, addressed by variants like Streaming LPM [S1].

## Subtopics

### [Parallel and Scalable LPM](9951-parallel-and-scalable-lpm.md)
A GPU implementation that avoids synchronization bottlenecks by dividing propagation into propagation and collecting steps, ensuring each voxel is traversed by only one ray per direction block.

### [Streaming LPM](9952-streaming-lpm.md)
A memory-management technique that processes the volume in small, streamed sub-volumes, decoupling memory footprint from total volume size to allow high-resolution rendering on limited VRAM.

### [Light Map (L Map)](16885-light-map-l-map.md)
A perceptual culling map that identifies regions around light sources where scattering is visually salient, addressing false undersampling artifacts caused by the Extinction-Saliency (XS) map.

## Operating characteristics
*   **Time Complexity:** Proportional to the number of iterations (scattering order) times the number of LPM elements times the number of propagation directions times the number of voxels traversed per ray [S1].
*   **Memory Complexity:** Proportional to the size of the 3D grid (for $I$ and $U$ buffers) plus the size of all LPMs [S1].
*   **Strengths:** Reduces false scattering and ray effects compared to standard DOM; efficient storage via coarse grid for radiance [S1].
*   **Limitations:** High memory usage for large volumes; iterative nature can be slow for highly scattering media; requires careful handling of boundary conditions [S1].
*   **When to Use:** When high-quality multiple scattering is needed and artifacts from standard DOM are unacceptable, and memory allows for high-resolution LPMs [S1].

## Background
Light Propagation Maps were introduced by Ronen Fattal [S1]. The method is based on the Discrete Ordinate Method (DOM) for solving the radiative transfer equation [S1]. It was developed to address the shortcomings of DOM, specifically false scattering and ray effects, by using fine sampling for propagation and coarse sampling for storage [S1].
