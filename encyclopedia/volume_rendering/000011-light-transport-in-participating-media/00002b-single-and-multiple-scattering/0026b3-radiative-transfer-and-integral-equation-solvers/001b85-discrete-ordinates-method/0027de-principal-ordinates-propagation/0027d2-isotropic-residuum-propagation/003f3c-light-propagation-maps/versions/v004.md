# Light Propagation Maps

Also called: Fattal's LPM, Fattal's Original LPM Algorithm, Fattal's method, Original LPM iteration

## Overview
Light Propagation Maps (LPM) is a Discrete Ordinate Method (DOM) technique that approximates the radiative transfer equation by using fine spatial and directional sampling for iterative light propagation while employing coarse sampling for storage to reduce memory usage and artifacts like false scattering and ray effects [S1]. It solves the problem of efficiently computing multiple scattering in participating media by decoupling the high-resolution propagation steps from the lower-resolution storage of scattered radiance [S1]. Unlike standard DOM which suffers from grid-aligned artifacts, LPM uses 2D ray maps to propagate light through the volume, building on the isotropic residuum propagation concept by handling the anisotropic propagation phase before switching to cheaper isotropic methods [4122-isotropic-residuum-propagation.md].

## How it works
**Inputs and Outputs:**
*   **Inputs:** A 3D voxel grid representing the participating medium with absorption coefficient $K_a$, scattering coefficient $K_s$, and phase function $p(\omega, \omega')$. Boundary conditions (incoming radiance) and self-emission radiance.
*   **Outputs:** Average scattered radiance $I_{xyz}^d$ for each voxel $xyz$ and direction $d$.

**Data Structures:**
*   **Light Propagation Maps (LPMs):** A set of 2D arrays. Each LPM corresponds to a face of the coarse 3D grid and represents a subset of finely sampled propagation directions. Each element $(r,s)$ in an LPM stores a set of rays originating at $(r,s)$ with directions sampled from the unit sphere $S^2$.
*   **Radiance Buffers:**
    *   $I_{xyz}^d$: Stores the average radiance in voxel $xyz$ along direction $\Omega_d$.
    *   $U_{xyz}^{i,p}$: Stores the unscattered radiance contribution for direction $d$ (closest to propagation direction $i$) at iteration $p$.
    *   Memory Optimization: Only two $U$ buffers are kept in practice: $U_{d,pprev}$ (previous iteration) and $U_{d,pcur}$ (current iteration), using a swap mechanism to reuse memory [S1].

**Formulas:**
*   **Average Radiance Approximation:**
    $$I_{xyz}^d \approx (V_{xyz}^d)^{-1} \int_{C_{xyz}} \int_{\Omega^d} \frac{K_{S_{xyz}}}{4\pi} \int_{\omega' \in S^2} L(p, \omega') p(\omega, \omega') d\omega' d\omega dp \quad (2)$$
    Where $V_{xyz}^d = \Delta V |\Omega^d|$ is the product of the voxel volume and the solid angle of direction $d$. $K_S$ is the scattering coefficient.

*   **Ray Radiance Update (Propagation):**
    $$L_{r,s}^i = L_{r,s}^{i,t-1} e^{-\Delta l_q(K_a + K_s)/\omega_z^i} + U_{xyz}^{i,p} \times \frac{1 - e^{-\Delta l_q(K_a + K_s)/\omega_z^i}}{K_a + K_s} \quad (3)$$
    Where:
    *   $L_{r,s}^i$: Radiance leaving the $t$-th voxel for ray $i$ at element $(r,s)$.
    *   $\Delta l_q$: Distance traversed by the ray in the voxel.
    *   $\omega_z^i$: The $z$-component of direction $i$ (assuming propagation along z-axis for the current LPM plane).
    *   $U_{xyz}^{i,p}$: Stored unscattered radiance from the previous iteration $p$.

*   **Scattering Contribution (Storage):**
    $$R = (V_{xyz}^d)^{-1} A_{r,s} F_d^i L_{r,s}^{i,t} \frac{1 - e^{-\Delta l_q K_s}}{\omega_s^i} \quad (4)$$
    Where:
    *   $R$: The scattering contribution added to $U$ and $I$.
    *   $A_{r,s}$: Area of the LPM sample $(r,s)$.
    *   $F_d^i$: Precomputed phase function integral for propagation direction $i$ and storage direction $d$.
    *   $\omega_s^i$: The component of direction $i$ along the storage axis.

*   **Phase Function Integral:**
    $$F_d^i = \frac{1}{4\pi} \int_{\Omega^i} \int_{\Omega^d} p(\omega, \omega') d\omega d\omega' \quad (5)$$
    Where $d$ is the storage direction closest to the propagation direction $i$.

**Parameters:**
*   $\epsilon$: Termination threshold. Iterations stop when $\max_{xyz} |U_{d,pprev}| < \epsilon$.
*   $p$: Iteration number (scattering order).

**Algorithm Steps:**
1.  **Initialize:** Set $pprev = 0$. Initialize $U_{d,pprev}$ and $I_d$ with medium self-emission radiance (if any).
2.  **Iterate:** While $\max_{xyz} |U_{d,pprev}| < \epsilon$ and $p > 0$:
    a.  Set $pcur = (pprev + 1) \% 2$.
    b.  Initialize $U_{d,pcur}$ to 0.
    c.  **For each LPM:**
        i.  **For each propagation direction $i$:**
            1.  **For each element $(r,s)$ of the current map:**
                *   If $p == 0$, initialize $L_{r,s}^{i,0}$ with boundary conditions (incoming radiance).
                *   Else, set $L_{r,s}^{i,0}$ to 0.
            2.  **For each intersected voxel $t$ along the ray path:**
                *   Update ray radiance $L_{r,s}^{i,t}$ using Equation (3) and $U_{d,pprev}$.
                *   Calculate scattering contribution $R$ using Equation (4).
                *   Update $U_{d,pcur}$ and $I_d$ with $R$.
    d.  Set $pprev = pcur$.

**Pseudocode:**

```python
    """
    volume: Object containing K_a, K_s, phase_function, and grid dimensions.
    boundary_conditions: Function or data structure providing incoming radiance at boundaries.
    epsilon: Termination threshold.
    """
    # Initialize buffers
    # U_prev and U_curr store unscattered radiance for direction d
    U_prev = zeros_like(volume.grid)
    U_curr = zeros_like(volume.grid)

    I = zeros_like(volume.grid)

    for voxel in volume.grid:
        I[voxel] = volume.self_emission[voxel]
        U_prev[voxel] = volume.self_emission[voxel]

    p = 1

    lpm_faces = create_lpm_faces(volume.grid)

        p_curr = (p_prev + 1) % 2
        
        # Reset current U buffer
        U_curr[:] = 0

            for direction_i in lpm.propagation_directions:

                    for voxel_t in lpm.march_rays(r, s, direction_i):

                        Ka = volume.K_a[voxel_t]
                        Ks = volume.K_s[voxel_t]
                        dz = volume.dz # or component of direction

                        # L_new = L_old * exp(-...) + U_prev * (1 - exp(-...)) / (Ka + Ks)

        # End LPM loop
        
        # Swap buffers
        U_prev = U_curr
        p_prev = p_curr
        p += 1
        
    return I
```

**Edge Cases and Pitfalls:**
*   **Boundary Conditions:** Rays leaving the medium must be replaced by new rays with zero radiance from the opposite side to maintain a constant number of rays [S1].
*   **Precision:** The exponential terms in the radiance update can suffer from precision issues if optical depth is very high or very low.
*   **Degenerate Input:** If $K_a + K_s = 0$, the division in Equation (3) and (4) is undefined. This should be handled as a special case (no interaction).

## Subtopics

### [Parallel and Scalable LPM](9951-parallel-and-scalable-lpm.md)
Parallel and Scalable LPM is a GPU implementation of Light Propagation Maps that avoids synchronization bottlenecks by dividing the propagation step into a propagation step and a collecting step. This guarantees that each voxel is traversed by only one ray at a time within a specific direction block.

### [Streaming LPM](9952-streaming-lpm.md)
Streaming LPM is a memory-management technique for Light Propagation Maps (LPM) that overcomes GPU memory limitations by processing the volume in small, streamed sub-volumes rather than the entire grid at once. It sets itself apart from standard LPM by decoupling the memory footprint from the total volume size, allowing high-resolution volumes (e.g., $256^3$) to be rendered on hardware with limited VRAM, whereas standard LPM requires storing all radiance buffers for the entire volume simultaneously.

## Operating characteristics
*   **Time Complexity:** The method is iterative, with complexity proportional to the number of scattering orders required for convergence. Each iteration involves marching rays through the volume for each LPM and direction.
*   **Memory Complexity:** LPMs require high-resolution 2D arrays for propagation, but the storage of radiance ($I$ and $U$) is coarse. Only two $U$ buffers are needed, reducing memory usage significantly compared to full DOM [S1].
*   **Performance:** LPM reduces false scattering and ray effects compared to standard DOM by using fine sampling for propagation and coarse sampling for storage [S1].
*   **Strengths:** Efficient handling of multiple scattering; reduced artifacts; lower memory footprint than full DOM.
*   **Limitations:** Iterative convergence can be slow for highly scattering media; requires careful tuning of the termination threshold $\epsilon$ [S1].

## Background
Light Propagation Maps were introduced by Fattal as a method for computing multiple scattering in participating media [S1]. The technique is based on the Discrete Ordinate Method (DOM) but modifies it to mitigate common DOM artifacts like false scattering and ray effects by using different sampling frequencies for propagation and storage [S1]. It is widely used in computer graphics for realistic rendering of participating media such as fog, smoke, and clouds.
