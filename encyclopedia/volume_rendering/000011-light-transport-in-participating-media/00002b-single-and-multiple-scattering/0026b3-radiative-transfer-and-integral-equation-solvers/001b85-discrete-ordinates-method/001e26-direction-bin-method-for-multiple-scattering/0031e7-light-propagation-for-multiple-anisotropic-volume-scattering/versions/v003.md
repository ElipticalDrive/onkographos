# Light Propagation for Multiple Anisotropic Volume Scattering

Also called: Discrete Ordinates with Direction Bins, Shooting Method with Direction Bins

## Overview
This method is a propagation approximation for computing multiple anisotropic light scattering in participating media, designed to reduce the "ray effect" artifacts inherent in traditional discrete ordinates methods [S1, book]. It achieves this by shooting radiosity into the entire solid angle of a direction bin rather than a single discrete representative direction [S1, book]. It builds on the [Direction Bin Method for Multiple Scattering](1690-direction-bin-method-for-multiple-scattering.md) by introducing a shooting algorithm that accumulates opacity on the fly, avoiding the precomputation of complex form factors required by Galerkin finite element schemes [S1, book].

## How it works
The method operates on a regular cubical grid of voxels and discretizes the unit sphere of directions into $M$ bins [S1, book]. It solves the radiative transfer equation by iteratively propagating radiosity through these bins, using a precomputed scattering matrix for intermediate bounces and exact directions only for the source and viewer interactions [S1, book].

### Inputs and Outputs
**Inputs:**
*   **Grid:** A regular cubic volume of $n \times n \times n$ elements (voxels) with total elements $N = n^3$ [S1, book].
*   **Opacity:** An array $k_t[k]$ of size $N$, storing the total opacity (absorption plus scattering) per unit length for each voxel $V_k$, assumed constant within each element [S1, book].
*   **Albedo:** A scalar $a$, representing the fraction of removed intensity scattered in other directions, assumed constant everywhere [S1, book].
*   **Phase Function:** Defined by the Henyey-Greenstein parameter $g \in [-1, 1]$, where positive $g$ indicates forward scattering, negative backward, and $0$ isotropic [S1, book].
*   **Direction Bins:** The unit sphere is divided into $M$ bins; typical values use powers of 2 subdivisions on cube faces [S1, book].
*   **Light Source:** Incoming illumination defined by exact directions and intensity for the first bounce [S1, book].
*   **Viewpoint:** The camera position for the final bounce [S1, book].

**Outputs:**
*   **Radiosity:** The final intensity distribution, stored in the matrix $l[k][l]$ [S1, book].

### Data Structures
1.  **$k_t[k]$**: Array of size $N$. Stores total opacity per unit length for voxel $k$ [S1, book].
2.  **$l[k][l]$**: Matrix of size $M \times N$. Stores radiosity (intensity multiplied by the solid angle of bin $B_l$) for voxel $k$ and direction bin $l$ [S1, book].
3.  **$unshot[k][l]$**: Auxiliary array of size $M \times N$. Stores radiosity waiting to be propagated from voxel $k$ into bin $l$ [S1, book].
4.  **$bintobin[l][m]$**: Matrix of size $M \times M$. Precomputed fraction of flux from bin $l$ directions that scatters into bin $m$ [S1, book].

### Formulas
The Henyey-Greenstein phase function $f(\omega, \omega')$ is defined as [S1, book]:

$$
f(\omega, \omega') = \frac{1 - g^2}{4\pi (1 + g^2 - 2gx)^{3/2}}
$$

where $x$ is the dot product of the unit direction vectors $\omega$ and $\omega'$, and $g$ is the anisotropy parameter [S1, book].

The bintobin matrix is precomputed via Simpson's rule integration over the direction bins [S1, book]:

$$
bintobin[l][m] = \int_{B_l} \int_{B_m} f(\omega, \omega') \, d\omega \, d\omega'
$$

normalized by the solid angles of the bins to yield the fraction of flux [S1, book].

### Parameters
*   **$M$**: Number of direction bins. Typical values are powers of 2 subdivisions on cube faces [S1, book].
*   **$n$**: Number of voxels along one dimension [S1, book].
*   **$a$**: Albedo (constant) [S1, book].
*   **$g$**: Henyey-Greenstein parameter, $[-1, 1]$ [S1, book].

### Steps
1.  **Precalculate Scattering Matrix:** Compute the $M \times M$ matrix $bintobin[l][m]$ using Simpson's rule integration of the Henyey-Greenstein phase function over the direction bins $B_l$ and $B_m$ [S1, book].
2.  **Initialize Unshot Radiosity:** Initialize the $unshot[k][l]$ array with the incoming illumination from the light source, using exact directions for the first bounce [S1, book].
3.  **Iterate Shooting Directions:** Loop through $M$ shooting directions (bins). For each bin $l$, shoot radiosity from source elements into the whole solid angle of bin $l$ [S1, book].
4.  **Accumulate Opacity:** Accumulate opacity on the fly as radiosity propagates through the voxels [S1, book].
5.  **Handle Multiple Scattering:** Within the receiving element, account for multiple scattering events before proceeding to the next shooting step by redistributing the scattered energy into the appropriate bins using the $bintobin$ matrix [S1, book].
6.  **Final Bounce:** After all intermediate bounces are processed, compute the final intensity at the viewpoint using exact directions from the voxels to the camera [S1, book].

### Pseudocode

```python
import math

def light_propagation(n, M, a, g, k_t, light_source_data, viewpoint_data):
    """
    n: int, number of voxels per dimension
    M: int, number of direction bins
    a: float, albedo (constant)
    g: float, Henyey-Greenstein parameter
    k_t: list of float, opacity per unit length for N=n^3 voxels
    light_source_data: list of (dir_vec, intensity) tuples for first bounce
    viewpoint_data: list of dir_vec tuples for final bounce
    """
    N = n ** 3
    radiosity = [[0.0] * M for _ in range(N)]
    unshot = [[0.0] * M for _ in range(N)]
    bintobin = [[0.0] * M for _ in range(M)]

    # Step 1: Precalculate scattering matrix via Simpson's rule integration over direction bins [S1, book]
    for l_idx in range(M):
        for m_idx in range(M):
            # [G] Integrate f(omega, omega') over solid angles of bins B_l and B_m using Simpson's rule
            bintobin[l_idx][m_idx] = 0.0

    # Step 2: Initialize unshot array with incoming illumination from light source [S1, book]
    for dir_vec, intensity in light_source_data:
        # [G] Map direction vector to bin index based on unit cube face subdivision
        bin_idx = 0
        for k in range(N):
            unshot[k][bin_idx] += intensity

    # Step 3: Iterate through M shooting directions [S1, book]
    for l_idx in range(M):
        for k in range(N):
            if unshot[k][l_idx] > 0:
                radiosity_val = unshot[k][l_idx]
                unshot[k][l_idx] = 0.0

                # Handle multiple scattering within the single receiving element before next step [S1, book]
                scattered = radiosity_val * a
                for m_idx in range(M):
                    unshot[k][m_idx] += scattered * bintobin[l_idx][m_idx]

                # Propagate radiosity to other voxels, accumulating opacity on the fly [S1, book]
                current_pos = (0.0, 0.0, 0.0)
                current_dir = (1.0, 0.0, 0.0)
                remaining_radiosity = radiosity_val
                for step in range(n):
                    next_voxel = (step + 1) % N
                    opacity_factor = math.exp(-k_t[next_voxel] * 1.0)
                    remaining_radiosity *= opacity_factor
                    if remaining_radiosity < 1e-6: break
                    # Deposit scattered energy into unshot for next_voxel
                    # (Implementation details for ray traversal and deposit omitted as sources do not specify grid traversal routine) [S1, book]
                    current_pos = (current_pos[0] + current_dir[0], current_pos[1] + current_dir[1], current_pos[2] + current_dir[2])

    # Step 4: Final bounce to viewpoint using exact directions [S1, book]
    final_image = 0.0
    for dir_vec in viewpoint_data:
        # [G] Map direction vector to bin index
        bin_idx = 0
        for k in range(N):
            final_image += radiosity[k][bin_idx]
    return final_image
```

### Edge Cases and Pitfalls
*   **Grid Homogeneity:** The method requires a regular cubical grid and relies on grid homogeneity, and does not work on general finite element meshes [S1, book].
*   **Ray Effects:** While reduced compared to traditional discrete ordinates, artifacts may persist if the number of bins $M$ is too low [S1, book].
*   **Precision:** Accumulating opacity on the fly may introduce numerical errors if not handled carefully, though the text does not specify mitigation strategies [S1, book].

## Operating characteristics
*   **Time Complexity:** $O(M n^3 \log n + M^2 n^3)$ per pass through $M$ shooting directions, with total time $O(M N \log N + M^2 N)$ where $N=n^3$ [S1, book]. This is a significant speedup compared to Tan's point collocation method which has $O(n^7 + M^2 n^6)$ cost [S1, book].
*   **Space Complexity:** $O(M n^3)$ for storing radiosity and unshot radiosity, plus $O(M^2)$ for the bintobin matrix [S1, book]. This avoids the $O(M^2 N^2)$ storage required by Galerkin finite element schemes [S1, book].
*   **Strengths:** Reduces ray effects compared to traditional discrete ordinates; efficient for regular grids; avoids precomputing complex form factors [S1, book].
*   **Limitations:** Restricted to regular cubical grids; requires sufficient $M$ to minimize artifacts; assumes constant albedo [S1, book].
*   **When to Use:** Suitable for rendering participating media like clouds on regular grids where multiple anisotropic scattering is important and ray effects are a concern [S1, book].
*   **When Not to Use:** Not suitable for general finite element meshes or irregular grids [S1, book].

## Background
The method was presented in 1993 as an efficient propagation approximation for multiple anisotropic volume scattering [S1, book]. It builds on the discrete ordinates method from radiation transfer [Sic92, Chan50] and the progressive radiosity method for surface illumination [Coh87] [S1, book]. It was inspired by Patmore's work on discrete ordinates shooting for cloud rendering [Patm93] [S1, book]. The Henyey-Greenstein phase function used is based on Mie scattering theory [Heny40, Mie09] [S1, book].
