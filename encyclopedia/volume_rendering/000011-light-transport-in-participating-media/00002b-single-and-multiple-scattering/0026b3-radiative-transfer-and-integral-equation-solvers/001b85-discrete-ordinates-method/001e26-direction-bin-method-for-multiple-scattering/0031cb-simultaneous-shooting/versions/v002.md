# Simultaneous Shooting

Also called: 2-D flux propagation, binomial flux spreading

## Overview
Simultaneous Shooting is a method for efficiently spreading flux from a shooting voxel to receiving voxels in a volume by assuming flux is proportional to surface area on a unit direction cube, allowing simultaneous propagation for all pixels in a horizontal row [S1, book]. It builds on [Direction Bin Method for Multiple Scattering](1690-direction-bin-method-for-multiple-scattering.md) by optimizing the transfer step between direction bins [G]. It differs from [Light Propagation for Multiple Anisotropic Volume Scattering](6627-light-propagation-for-multiple-scattering.md) by using a discrete bin-based flux spreading model rather than continuous light transport volumes [G].

## How it works
**Inputs and Outputs:** The method takes unshot radiosity values for a shooting row or plane, attenuation data for the volume, and direction bin parameters as input, and outputs updated radiosity values in receiving voxels [S1, book].

**Data Structures:** `work[j]` stores current flux for the shooting row. `tempwork[j]` stores intermediate flux values. `corner[0][j]` and `corner[1][j]` store corner flux contributions for the two diagonal directions. `receive[i]` accumulates flux for the receiving row [S1, book].

**Parameters:** $m$ is the resolution parameter for direction bins, where a unit cube face is divided into $2^m \times 2^m$ equal bins, yielding $M = 2^{4m^2}$ total direction bins [S1, book]. $n$ denotes the number of columns/pixels in the horizontal dimension. $rows$ denotes the number of rows below the shooting plane to propagate to [S1, book].

**Steps:**
1. **Initialization:** For a shooting row at index $i_0$, initialize `work[j]`, `corner[0][j]`, and `corner[1][j]` with the unshot radiosity values for that row for all $j$ from $0$ to $columns-1$ [S1, book].
2. **Propagation Loop:** Iterate over rows $i$ from $i_0$ to $i_0 + rows - 1$. Let $s = i - i_0$ be the vertical distance [S1, book].
3. **Copy Work:** Set `tempwork[j] = work[j]` for all $j$ [S1, book].
4. **Corner Adjustment:** If $j > 0$, update `corner[0][j] += 0.5 * corner[0][j-1]` and `corner[1][j] += 0.5 * corner[1][j-1]` [S1, book]. Add corner contributions to `tempwork`: `tempwork[j] += 0.5 * corner[0][j]` and `tempwork[j] += 0.5 * corner[1][j]` [S1, book].
5. **Receive Accumulation:** Add the attenuated `tempwork` values to the `receive` array for row $i$, scaled by the appropriate geometric factor (e.g., $1/s^2$ in 3-D, implicit in 2-D weights) [S1, book].

**Pseudocode:**
```python
def simultaneous_shooting_2d(unshot_radiosity, columns, rows):
    """
    Simulates 2-D simultaneous shooting for a single direction bin row.
    unshot_radiosity: array of size columns
    columns: int
    rows: int
    """
    work = list(unshot_radiosity)
    corner_0 = list(unshot_radiosity)
    corner_1 = list(unshot_radiosity)
    receive = [0.0] * rows
    
    for i in range(rows):
        s = i  # Vertical distance from shooting plane
        tempwork = list(work)
        
        # Adjust corners for diagonal propagation paths
        for j in range(1, columns):
            corner_0[j] += 0.5 * corner_0[j-1]
            corner_1[j] += 0.5 * corner_1[j-1]
            
        # Add corner contributions to the working flux
        for j in range(columns):
            tempwork[j] += 0.5 * corner_0[j]
            tempwork[j] += 0.5 * corner_1[j]
            
        # Accumulate flux into receiving row
        # Attenuation is applied per-voxel or via precomputed path transmittance
        for j in range(columns):
            receive[i] += tempwork[j]
            
    return receive
```

**Edge Cases and Pitfalls:** Attenuation is accumulated along many propagation paths (downward and diagonal steps) forming a parallelogram, not just the straight path, causing shadow blurring [S1, book]. The number of paths through a voxel is determined by binomial coefficients, where paths using the (1/2, 1/2) scheme are weighted by $\binom{i}{k}$, while corner paths have different weights [S1, book].

## Subtopics

### 3-D Flux Propagation
An extension of 2-D propagation to 3-D where flux spreads across faces of a cubical shell [S1, book]. Voxels shared between two adjacent bins receive a weight of 1/2, voxels shared by four adjacent bins receive 1/4, and corners shared by three adjacent bins receive 1/3 [S1, book]. The weight pattern is reconstructed by dividing values in the inner shell pattern by 4 and adding them to four direct or diagonal neighbors to produce a 1, 1/2, 1/4 pattern [S1, book]. Edge arrays are maintained using the 2-D procedure to add weight 1/2 edges, and four corner arrays adjust corner values to exactly 1 [S1, book]. Flux is added to the receive array by dividing weighted attenuated work values $s$ layers beyond the shooting plane by $s^2$ [S1, book]. An optimization reduces the $O(n)$ factor to $O(\log n)$ by maintaining temporary arrays from all shooting layers and recursively consolidating them when the resulting error is small [S1, book]. The effective inverse square factor after consolidation is $1/(2(s-1)^2 + 2(s+1)^2) = 1/(2s^2 + 2) \approx 1/s^2 + 1/s^4 + O(1/s^6)$ [S1, book].

## Operating characteristics
**Time and Memory Complexity:** The method computes $O(n^3)$ interactions of a shooting row with pixels below it in time $O(n^2)$, compared to $O(n^4)$ for naive accumulation [S1, book]. In 3-D, it propagates flux from $n$ shooting planes to $O(n^3)$ receiving elements in $O(n^3)$ time per bin, producing $O(n^5)$ interactions, with a total cost for a single bin direction across $n$ planes of $O(n^4)$ [S1, book]. The optimization can reduce the last factor of $n$ to $O(\log n)$ [S1, book].

**Strengths and Limitations:** The method provides a significant speedup over naive ray marching for multiple scattering by efficiently handling the spreading of flux across a volume [S1, book]. Its primary limitation is shadow blurring due to the accumulation of attenuation along multiple paths forming a parallelogram shape rather than straight lines [S1, book]. Discontinuous illumination errors (ray effects) are replaced by continuously varying shadow errors, which are considered less severe but still present [S1, book].

## Background
The method originated in the context of efficient light propagation for multiple anisotropic volume scattering [S1, book]. It was developed to address the high computational cost of accumulating opacity for each interaction along a straight path in volume rendering [S1, book]. It is part of the broader family of Discrete Ordinates Methods for solving the Radiative Transfer Equation [S1, book].
