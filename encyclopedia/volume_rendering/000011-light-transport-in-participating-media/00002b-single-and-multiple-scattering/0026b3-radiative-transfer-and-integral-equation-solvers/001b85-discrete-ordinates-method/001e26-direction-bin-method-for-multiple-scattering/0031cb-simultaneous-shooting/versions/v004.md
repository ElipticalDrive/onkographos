# Simultaneous Shooting

Also called: 2-D flux propagation, binomial flux spreading

## Overview
Simultaneous Shooting is a method for efficiently spreading flux from a shooting voxel to receiving voxels in a volume by assuming flux is proportional to surface area on a unit direction cube, allowing simultaneous propagation for all pixels in a horizontal row [S1, book]. It distinguishes itself from its sibling [Light Propagation for Multiple Anisotropic Volume Scattering](6627-light-propagation-for-multiple-anisotropic-volume-scattering.md) by distributing flux to neighbor voxels simultaneously for all voxels in a layer and accumulating attenuation along a set of possible propagation paths rather than a single straight line, which reduces the "ray effect" [S1, book].

## How it works
**Inputs and Outputs:**
- Input: Unshot radiosity/work values for a shooting plane (row in 2-D), resolution parameter $m$, grid dimensions $n \times n$ [S1, book].
- Output: Attenuated flux received by voxels in subsequent layers/rows [S1, book].

**Data Structures:**
- `work[j]`: Array of size `columns` (or $n$) storing current flux values for the shooting row [S1, book].
- `corner[0][j]`, `corner[1][j]`: Arrays of size `columns` storing corner flux contributions for the two diagonal directions [S1, book].
- `tempwork[j]`: Temporary array of size `columns` for intermediate calculations [S1, book].
- `receive[i][j]`: Accumulator for received flux at row $i$, column $j$ [S1, book].

**Parameters:**
- $m$: Resolution parameter for direction bins. A unit cube face is divided into $2^m \times 2^m$ equal bins. Total direction bins $M = 2^{4m^2}$ [S1, book].
- $n$: Grid dimension (rows/columns) [S1, book].
- `rows`: Number of rows to propagate [S1, book].
- `columns`: Number of columns (pixels) in a row [S1, book].

**Steps:**
1. **Initialization:** Let $i_0$ be the starting row index [S1, book]. For $j$ from $0$ to `columns` - 1: set `work[j]` = `unshot[i0][j]`, `corner[0][j]` = `unshot[i0][j]`, and `corner[1][j]` = `unshot[i0][j]` [S1, book].
2. **Propagation Loop:** For $i$ from $i_0$ to $i_0 + \text{rows} - 1$: let $s = i - i_0$ (distance from shooting plane) [S1, book]. For $j$ from $0$ to `columns` - 1: set `tempwork[j]` = `work[j]` [S1, book]. Adjust for corner flux: if $j > 0$, update `corner[0][j]` += $0.5 \times \text{corner}[0][j-1]$ and `corner[1][j]` += $0.5 \times \text{corner}[1][j-1]$ [S1, book]. Add corner contributions to `tempwork`: `tempwork[j]` += $0.5 \times \text{corner}[0][j]$ and `tempwork[j]` += $0.5 \times \text{corner}[1][j]$ [S1, book]. Accumulate to receive: if $s > 0$, `receive[i][j]` += `tempwork[j]` / $s^2$ [S1, book]. Update `work[j]` = `unshot[i][j]` for the next iteration [S1, book].

**Formulas:**
- Flux spreading weights in 2-D: The flux from a pixel is distributed to the pixel directly below and the pixel diagonally below-right with weight $1/2$ each [S1, book].
- Binomial path weighting: The opacity contribution from a pixel $(j, k)$ is weighted by the number of propagation paths passing through it, involving binomial coefficients [S1, book].

**Edge Cases and Pitfalls:**
- Attenuation is accumulated along many propagation paths (downward and diagonal steps) forming a parallelogram, not just the straight path, causing shadow blurring [S1, book].
- The method assumes flux is proportional to surface area on the unit direction cube [S1, book].
- Division by zero occurs if $s = 0$; the receiving step must be skipped or handled separately for the shooting plane itself [G].

**Pseudocode:**
```python
def simultaneous_shooting_2d(unshot, rows, columns, i0=0):
    """
    unshot: 2D array [rows+1][columns] of initial flux values for the shooting plane(s)
    rows: number of rows to propagate downwards
    columns: number of columns in the grid
    i0: starting row index for the shooting plane
    """
    work = [0.0] * columns
    corner0 = [0.0] * columns
    corner1 = [0.0] * columns
    tempwork = [0.0] * columns
    receive = [[0.0] * columns for _ in range(rows + 1)]

    # Initialize with the shooting row
    for j in range(columns):
        work[j] = unshot[i0][j]
        corner0[j] = unshot[i0][j]
        corner1[j] = unshot[i0][j]

    # Propagate flux
    for i in range(i0, i0 + rows):
        s = i - i0
        for j in range(columns):
            tempwork[j] = work[j]
            
            # Adjust for corner flux
            if j > 0:
                corner0[j] += 0.5 * corner0[j - 1]
                corner1[j] += 0.5 * corner1[j - 1]
            
            tempwork[j] += 0.5 * corner0[j]
            tempwork[j] += 0.5 * corner1[j]
            
            # Accumulate to receive array, applying inverse square attenuation
            if s > 0:
                receive[i][j] += tempwork[j] / (s * s)
        
        # Update work array for the next shooting row
        if i + 1 < len(unshot):
            for j in range(columns):
                work[j] = unshot[i + 1][j]
```

## Subtopics

### [Max's Method](13129-max-s-method.md)
Max's Method is a volume rendering technique for participating media that approximates radiative transfer by propagating energy across a grid, thereby avoiding the explicit computation of $M^2 v^2$ form factors required by finite element formulations. It distinguishes itself from sibling methods by distributing flux to neighbor voxels simultaneously for all voxels in a layer and accumulating attenuation along a set of possible propagation paths rather than a single straight line, which reduces the "ray effect".

### 3-D Flux Propagation
3-D Flux Propagation is an extension of 2-D propagation to 3-D where flux spreads across faces of a cubical shell [S1, book]. Voxels shared between two adjacent bins receive weight $1/2$, voxels shared between four adjacent bins receive weight $1/4$, and voxels at the eight cube corners shared between three adjacent bins receive weight $1/3$ [S1, book]. The weight pattern ($1$, $1/2$, $1/4$) is reconstructed by dividing values in the inner shell pattern by $4$ and adding them to four direct or diagonal neighbors [S1, book]. Edge arrays are maintained using the 2-D procedure to add weight $1/2$ edges, and four corner arrays adjust corner values to exactly $1$ [S1, book]. Weighted attenuated work values $s$ layers beyond the shooting plane are divided by $s^2$ and added to the receive array [S1, book]. The $O(n)$ factor can be reduced to $O(\log n)$ by maintaining temporary arrays from all shooting layers and recursively consolidating them when the resulting error is small [S1, book]. The effective inverse square factor after consolidation is $1/(2(s-1)^2 + 2(s+1)^2) = 1/(2s^2 + 2) \approx 1/s^2 + 1/s^4 + O(1/s^6)$ [S1, book].

## Operating characteristics
- **Time Complexity:** Computes $O(n^3)$ interactions of a shooting row with pixels below it in time $O(n^2)$, compared to $O(n^4)$ for naive accumulation [S1, book]. For 3-D, propagating flux from $n$ shooting planes to $O(n^3)$ receiving elements takes $O(n^3)$ time per bin, producing $O(n^5)$ interactions [S1, book]. Total cost for a single bin direction for $n$ planes is $O(n^4)$ [S1, book].
- **Memory Complexity:** Not given in the sources [S1, book].
- **Strengths:** Efficiently spreads flux, reducing computational cost from $O(n^4)$ to $O(n^3)$ for 2-D interactions [S1, book]. Reduces the "ray effect" by accumulating attenuation along multiple paths [S1, book].
- **Limitations:** Shadow blurring occurs due to accumulation along many propagation paths [S1, book]. Complexity increases significantly in 3-D [S1, book].
