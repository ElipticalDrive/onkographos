# Cloud Radiative Transfer Forward Model Setup

Also called: RTE Solver Configuration, Radiative Transfer Grid and Medium Setup

## Overview
This method configures the geometric grid, optical property tables, and solver parameters required to solve the Radiative Transfer Equation (RTE) for cloudy atmospheres [S1, unofficial]. It establishes the spatial discretization and the microphysical scattering models that feed into the numerical solver [S1, unofficial]. It differs from sibling methods by focusing on the setup of the medium and boundary conditions rather than the iterative solution of the transport equation itself [G]. It serves as the prerequisite configuration for [Discrete Ordinates Method](1046-discrete-ordinates-method.md) and other solvers in the family.

## How it works
**Inputs and Outputs:**
*   **Inputs:** Cloud scatterer data containing 3D coordinate arrays $x, y, z$ [S1, unofficial]. Mie lookup tables for mono-disperse clouds `mie_mono_tables` [S1, unofficial]. Size distribution function `size_distribution_function` [S1, unofficial]. Microphysical ranges for effective radius $r_{eff}$ and effective variance $v_{eff}$ [S1, unofficial]. Solver configuration dictionary `numerical_params` [S1, unofficial].
*   **Outputs:** `rte_grid` defining the spatial domain [S1, unofficial]. `medium` containing optical properties [S1, unofficial]. `solver` initialized for propagation [S1, unofficial].

**Data Structures:**
1.  **RTE Grid (`rte_grid`)**: Constructed from x/y spacing, dimensions, and z coordinates [S1, unofficial]. Fields: `dx` (x-spacing), `nx` (x-dim), `dy` (y-spacing), `ny` (y-dim), `z_coords` (z-coordinates with a zero offset prepended) [S1, unofficial].
2.  **Optical Property Generator (`optical_property_generator`)**: Configured with cloud type `'cloud'`, Mie tables, size distribution, and parameter ranges [S1, unofficial].
3.  **Solver Configuration**: Configured with numerical parameters, a Lambertian surface with albedo $0.0$, a solar source defined by wavelength and angles, the medium, and Stokes count $1$ [S1, unofficial].

**Numbered Steps:**
1.  **Construct the Radiative Transfer Grid**: Calculate grid spacing from coordinate differentials $dx = \text{cloud\_scatterer}.x.\text{diff}('x')[0]$ and $dy = \text{cloud\_scatterer}.y.\text{diff}('y')[0]$ [S1, unofficial]. Get dimensions $nx = \text{cloud\_scatterer}.x.\text{data}.\text{size}$ and $ny = \text{cloud\_scatterer}.y.\text{data}.\text{size}$ [S1, unofficial]. Prepend zero to z-coordinates: $z_{grid} = [0] \cup z_{data}$ [S1, unofficial]. Initialize `rte_grid` with $(dx, nx, dy, ny, z_{grid})$ [S1, unofficial].
2.  **Generate Optical Properties**: Define microphysical ranges $r_{eff} \in \text{linspace}(5.0, 30.0, 30)$ and $v_{eff} \in \text{linspace}(0.03, 0.2, 9)$ [S1, unofficial]. Instantiate `optical_property_generator` with cloud type `'cloud'`, `mie_mono_tables`, `size_distribution_function`, and the ranges [S1, unofficial]. Apply the generator to `rte_grid` to produce the `medium` object [S1, unofficial].
3.  **Configure the RTE Solver**: Define the solar source with wavelength $\lambda$, solar zenith cosine $\mu_0$, and solar azimuth $\phi_0 = 140^\circ$ [S1, unofficial]. Define the surface as Lambertian with albedo $\alpha = 0.0$ [S1, unofficial]. Initialize the solver with `numerical_params`, surface, source, medium, and `num_stokes = 1` [S1, unofficial]. Add the solver to the solver dictionary for the given wavelength [S1, unofficial].

**Formulas:**
*   Grid spacing: $dx = \text{cloud\_scatterer}.x.\text{diff}('x')[0]$, $dy = \text{cloud\_scatterer}.y.\text{diff}('y')[0]$ [S1, unofficial].
*   Z-coordinates: $z_{grid} = [0] \cup z_{data}$ [S1, unofficial].
*   Microphysical ranges: $r_{eff} = \text{linspace}(5.0, 30.0, 30)$, $v_{eff} = \text{linspace}(0.03, 0.2, 9)$ [S1, unofficial].
*   Surface albedo: $\alpha = 0.0$ [S1, unofficial].
*   Solar azimuth: $\phi_0 = 140^\circ$ [S1, unofficial].
*   Stokes count: $N_S = 1$ [S1, unofficial].

**Parameters:**
*   `numerical_params`: Solver configuration dictionary [S1, unofficial].
*   `wavelength`: Solar wavelength (float) [S1, unofficial].
*   `solar_mu`: Cosine of solar zenith angle (float) [S1, unofficial].
*   `solar_az`: Solar azimuth angle in degrees, set to $140$ [S1, unofficial].
*   `num_stokes`: Number of Stokes parameters, set to $1$ [S1, unofficial].
*   `reff`: Effective radius range, `linspace(5.0, 30.0, 30)` [S1, unofficial].
*   `veff`: Effective variance range, `linspace(0.03, 0.2, 9)` [S1, unofficial].

**Edge Cases and Pitfalls:**
*   **Precision**: The effective radius and variance ranges are discretized into 30 and 9 points respectively [S1, unofficial]. Coarse discretization may miss microphysical variations [G].
*   **Boundary Conditions**: The surface albedo is fixed at $0.0$ [S1, unofficial]. If a reflective surface is required, this must be changed, affecting the boundary term in the RTE [G].
*   **Polarization**: `num_stokes=1` assumes unpolarized light [S1, unofficial]. For polarized radiative transfer, `num_stokes` must be set to $4$, requiring full Mueller matrix Mie tables [G].

**Pseudocode:**
```python
import numpy as np

def setup_cloud_rte(cloud_scatterer, mie_mono_tables, size_distribution_function, 
                    wavelength, solar_mu, solar_az, numerical_params):
    """
    Sets up the Cloud Radiative Transfer Forward Model.
    
    Args:
        cloud_scatterer: Object containing x, y, z data arrays.
        mie_mono_tables: Pre-computed Mie scattering tables.
        size_distribution_function: Gamma distribution function object.
        wavelength: Solar wavelength (float).
        solar_mu: Cosine of solar zenith angle (float).
        solar_az: Solar azimuth angle in degrees (float).
        numerical_params: Configuration dict for the RTE solver.
        
    Returns:
        solver: Initialized RTE solver instance.
    """
    # Step 1: Construct the radiative transfer grid
    dx = cloud_scatterer.x.diff('x')[0]
    dy = cloud_scatterer.y.diff('y')[0]
    nx = cloud_scatterer.x.data.size
    ny = cloud_scatterer.y.data.size
    z_coords = np.append(0, cloud_scatterer.z.data)
    
    rte_grid = {
        'dx': dx, 'nx': nx, 'dy': dy, 'ny': ny, 'z_coords': z_coords
    }
    
    # Step 2: Generate optical properties
    reff_range = np.linspace(5.0, 30.0, 30)
    veff_range = np.linspace(0.03, 0.2, 9)
    
    optical_property_generator = {
        'cloud_type': 'cloud',
        'mie_tables': mie_mono_tables,
        'size_dist_func': size_distribution_function,
        'reff': reff_range,
        'veff': veff_range
    }
    
    # Apply generator to grid to create medium
    medium = {
        'grid': rte_grid,
        'generator_params': optical_property_generator
    }
    
    # Step 3: Configure and add solver
    surface = {'type': 'lambertian', 'albedo': 0.0}
    source = {'wavelength': wavelength, 'mu0': solar_mu, 'phi0': solar_az}
    
    solver = {
        'numerical_params': numerical_params,
        'surface': surface,
        'source': source,
        'medium': medium,
        'num_stokes': 1
    }
    
    solvers_dict = {}
    solvers_dict[wavelength] = solver
    
    return solver
```

## Subtopics

### Discrete Ordinates Method
Solves the RTE by discretizing the angular domain into a finite set of directions. Choose when high angular accuracy is needed for moderate optical depths. [Link](1046-discrete-ordinates-method.md)

### Multiple Scattering Model (Integral Equation)
Solves the integral form of the RTE. Choose when multiple scattering dominates and angular discretization is too expensive. [Link](1177-multiple-scattering-model-integral-equation.md)

### Jacobi Iterative Method for Diffusion
Iteratively solves diffusion equations for optically thick media. Choose when scattering is highly dominant and angular resolution is less critical. [Link](4382-jacobi-iterative-method-for-diffusion.md)

### Sparse Linear System Solver for Wave Propagation
Solves sparse linear systems for wave-based transport approximations. Choose for high-frequency wave propagation in participating media. [Link](4718-sparse-linear-system-solver-for-wave-propagation.md)

### Differential Form of RTE
Solves the differential form of the RTE directly. Choose when local gradient information is required or for hybrid deterministic-stochastic approaches. [Link](4803-differential-form-of-rte.md)

### Spherical Harmonics and Spherical Gaussians for Radiance Transfer
Approximates angular radiance using basis functions. Choose for efficient multi-directional scattering in complex scenes. [Link](5599-spherical-harmonics-and-spherical-gaussians-for-radiance-tra.md)

### Differential Radiative Transfer
Computes gradients of radiative transfer for optimization or inverse problems. Choose when differentiating through the transport equation is required. [Link](7879-differential-radiative-transfer.md)

### Ratio Estimator for Volume Scattering
Estimates scattering contributions using ratio-based sampling. Choose for variance reduction in Monte Carlo volume rendering. [Link](9012-ratio-estimator-for-volume-scattering.md)

### Real Time Single Scattering Effects
Approximates single scattering for interactive rendering. Choose when performance constraints prohibit full multiple scattering solutions. [Link](20433-real-time-single-scattering-effects.md)

*   **Limitations**: Dependent on pre-computed Mie tables and discretized microphysical ranges [G].
*   **When to use**: When setting up a forward model for cloud radiative transfer in atmospheric remote sensing or climate modeling [S1, unofficial].

## Background
This method is derived from the `hybridCT` framework, which combines hybrid neural network approaches with traditional cloud radiative transfer solvers [S1, unofficial]. It was developed to efficiently generate training data for machine learning models predicting cloud optical depths [S1, unofficial]. The setup follows standard atmospheric radiative transfer principles, using Mie theory for spherical cloud droplets [S1, unofficial].
