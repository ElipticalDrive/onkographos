# Differential Ray Marching

Also called: Differential Form RTE Solver, ODE-based Volume Rendering

## Overview
Differential Ray Marching solves the Radiative Transfer Equation (RTE) in its differential form as an initial value problem, rather than approximating its integral form [S1]. Unlike traditional ray marching, which approximates integrals using the rectangle method (equivalent to Euler's method) and requires computing the double integral for inner transmittance, this method applies numerical ODE solvers directly to the differential equation [S1]. This approach allows for higher-order accuracy and smarter sample selection, reducing the sample count or increasing image quality compared to standard techniques [S1].

## How it works
**Inputs and Outputs:**
*   Ray origin $x_0$ and direction $\omega$ [S1].
*   Medium coefficients at position $x$: absorption $\sigma_a(x)$, scattering $\sigma_s(x)$, extinction $\sigma_t(x) = \sigma_a(x) + \sigma_s(x)$, emission $L_e(x, \omega)$, and phase function $p(x, \omega_0, \omega)$ [S1].
*   Integration distance $t_{end}$ and initial radiance $y_0 = L(x_0, \omega)$ derived from surface material properties and light distribution [S1].
*   Output: Final radiance $y(t_{end})$ at the ray exit [S1].

**Data Structures:**
*   State vector $y$ storing current radiance $L(x, \omega)$ [S1].
*   Independent variable $t$ storing distance traveled along the ray [S1].
*   Derivative function $f(y, t)$ computing the rate of change of radiance [S1].

**Numbered Steps:**
1. Initialize $t = 0$ and $y = y_0$ [S1].
2. Compute current position $x = x_0 + t\omega$ [G].
3. Evaluate the derivative $f(y, t) = \sigma_a(x)L_e(x, \omega) - \sigma_t(x)y + \sigma_s(x)L_{in}(x, \omega)$, where $L_{in}$ is the angular in-scattering integral [S1].
4. Update $y$ and $t$ using a chosen numerical method (e.g., Euler: $y \leftarrow y + \Delta t \cdot f(y,t)$, $t \leftarrow t + \Delta t$) [S1].
5. Repeat steps 2–4 until $t \ge t_{end}$, then return $y$ [S1].

**Formulas:**
The Radiative Transfer Equation is defined as [S1]:
$$
\frac{\partial L(x, \omega)}{\partial t} = \sigma_a (x)L_e (x, \omega) - \sigma_t (x)L(x, \omega) + \sigma_s (x) \int_{\Omega} p(x, \omega_0 , \omega)L(x, \omega_0 ) d\omega_0
$$
This is formulated as an initial value problem [S1]:
$$
y'(t) = f(y, t)
$$
Where:
*   $y(t) = L(x(t), \omega)$ is the radiance [S1].
*   $t$ is the distance along the path of light [S1].
*   $f(y, t)$ is the right-hand side of the RTE [S1].
*   $y_0 = L(x_0, \omega)$ is the known initial value [S1].
*   $\sigma_a$ is the absorption coefficient, $\sigma_s$ is the scattering coefficient, $\sigma_t$ is the extinction coefficient, $L_e$ is emission, and $p$ is the phase function [S1].

**Parameters:**
*   Step size $\Delta t$: Can be fixed or adaptive [S1].
*   Numerical method order: Determines accuracy and computational cost per step [S1].

**Edge Cases and Pitfalls:**
*   The in-scattering integral $\int_{\Omega} p(x, \omega_0, \omega)L(x, \omega_0) d\omega_0$ must be evaluated at each step, which remains computationally expensive [S1]. The method avoids the transmittance double integral but does not eliminate angular integration [S1].
*   Standard floating-point precision requires clamping $\sigma_t$ to a minimum non-zero value to prevent division by zero or numerical instability in adaptive step size controllers [G].
*   The initial value $y_0$ must correctly match the surface exit radiance; if the ray starts inside the medium, $y_0$ is typically zero or the background radiance [S1].

**Pseudocode:**
```python
import math

def differential_ray_marching(ray_origin, ray_direction, medium, t_end, initial_radiance):
    t = 0.0
    y = initial_radiance
    delta_t = medium.get_step_size()
    while t < t_end:
        x = ray_origin + t * ray_direction
        sigma_a = medium.get_sigma_a(x)
        sigma_s = medium.get_sigma_s(x)
        sigma_t = sigma_a + sigma_s
        L_e = medium.get_emission(x, ray_direction)
        # In-scattering integral requires angular quadrature [G]
        L_in = compute_in_scattering_quadrature(x, ray_direction, medium)
        derivative = sigma_a * L_e - sigma_t * y + sigma_s * L_in
        y = y + delta_t * derivative
        t = t + delta_t
    return y

def compute_in_scattering_quadrature(x, view_dir, medium):
    # Standard uniform sampling over the unit sphere [G]
    samples = [(0.0, 0.0), (0.0, math.pi/2), (math.pi/2, 0.0), (math.pi/2, math.pi/2)]
    integral = 0.0
    for theta, phi in samples:
        omega_0 = (math.cos(phi)*math.sin(theta), math.sin(phi)*math.sin(theta), math.cos(theta))
        integral += medium.get_phase(x, omega_0, view_dir) * medium.get_external_radiance(omega_0)
    return integral * (4.0 * math.pi) / len(samples)
```

## Subtopics

### Forward Scattering Dipole Model
A specific scattering model that approximates the in-scattering term efficiently using a dipole approximation for the Green's function of the diffusion equation [G]. It differs from general phase function integration by modeling light transport as a diffusion process near boundaries. Choose this when single scattering is insufficient but full multiple scattering is too expensive. [Link](10173-forward-scattering-dipole-model.md)

## Operating characteristics
*   **Time Complexity:** Depends on the number of steps $n$ and the cost of evaluating the derivative $f(y, t)$ at each step; higher-order ODE methods require more function evaluations per step but may allow larger step sizes, potentially reducing $n$ [S1].
*   **Memory Complexity:** $O(1)$, as it only stores the current state $y$ and $t$ [S1].
*   **Measured Performance:** Not given in the sources.
*   **Scaling:** Scales linearly with the number of steps; adaptive step sizing improves efficiency in media with varying optical thickness [S1].
*   **Strengths:** Avoids the double integral of transmittance required in integral form methods. Allows the use of advanced ODE solvers for better accuracy and adaptive step sizing [S1].
*   **Limitations:** Still requires computation of the in-scattering integral at each step, which can be expensive. The benefit is most pronounced when the in-scattering term is approximated or precomputed [S1].
*   **When to use:** When high accuracy is needed with fewer samples, or when adaptive step sizing is beneficial [S1].
*   **When not to use:** When the in-scattering term is extremely expensive to compute and cannot be approximated, the overhead of the ODE solver may not justify the benefits over simpler methods [S1].

## Background
Differential Ray Marching was introduced in the paper "Differential Ray Marching" (2012) [S1]. It revisits the concept of ray marching not as an integration technique, but as the application of numerical methods to solve an initial value differential equation [S1]. The work analyzes a wide range of numerical methods and their applicability to participating media rendering, showing improvements over traditional ray marching in terms of sample count and accuracy [S1].
