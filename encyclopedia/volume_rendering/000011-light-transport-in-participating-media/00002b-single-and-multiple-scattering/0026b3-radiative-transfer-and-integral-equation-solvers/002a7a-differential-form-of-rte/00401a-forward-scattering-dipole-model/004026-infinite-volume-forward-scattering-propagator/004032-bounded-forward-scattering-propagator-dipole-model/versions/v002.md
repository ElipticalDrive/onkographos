# Bounded Forward Scattering Propagator (Dipole Model)

Also called: Boundary-Aware Propagator G_f^b, Boundary-aware propagator, Gbf, bounded propagator, final boundary-aware propagator

## Overview
The Bounded Forward Scattering Propagator ($G_f^b$) extends the Infinite Volume Forward Scattering Propagator [10181-infinite-volume-forward-scattering-propagator.md] to handle participating media within finite, bounded volumes by approximately satisfying absorbing boundary conditions [S1]. It employs a dipole method using a virtual source to enforce these boundaries, distinguishing itself from empirical corrections (such as those in [Frisvad et al. 2014]) by relying on the well-behaved nature of the underlying infinite volume propagator $G_f$ for regularization [S1].

## How it works
**Inputs:**
*   $\vec{x}_0, \hat{\omega}_0$: Outgoing position and direction.
*   $\vec{x}_1, \hat{\omega}_1$: Incoming position and direction.
*   $s$: Path length.
*   $\hat{n}_1$: Surface normal at $\vec{x}_1$.
*   $\sigma_s', \sigma_a$: Reduced scattering coefficient and absorption coefficient.

**Outputs:**
*   $G_f^b(s, \vec{x}_0, \hat{\omega}_0, \vec{x}_1, \hat{\omega}_1)$: The bounded propagator value [S1].

**Data Structures:**
The method requires standard 3D vectors and scalars for positions, directions, normals, and optical coefficients [S1].

**Steps:**

1.  **Calculate Modified Normal ($\hat{n}_1^*$):**
    Determine the effective normal for the boundary plane at the incoming point $\vec{x}_1$ [S1]. Let $\vec{R} = \vec{x}_0 - \vec{x}_1$.
    *   If $\vec{x}_0 = \vec{x}_1$, set $\hat{n}_1^* = \hat{n}_1$ [S1].
    *   Otherwise, calculate:
        $$ \hat{n}_1^* = \frac{\vec{R}}{|\vec{R}|} \times \frac{\hat{n}_1 \times \vec{R}}{|\hat{n}_1 \times \vec{R}|} $$
    *   **Pitfall:** If $\hat{n}_1$ is parallel to $\vec{R}$, the denominator $|\hat{n}_1 \times \vec{R}|$ is zero. In this case, set the propagator to 0 [S1].

2.  **Calculate Extrapolation Distance ($d_e$):**
    *   Compute reduced transmission coefficient: $\sigma_t' = \sigma_s' + \sigma_a$ [S1].
    *   Compute reduced scattering albedo: $\alpha_0 = \sigma_s' / \sigma_t'$ [S1].
    *   Compute diffusion constant: $D = 1/(3\sigma_t')$ [S1].
    *   Compute extrapolation distance: $d_e = 2.131 D / \sqrt{\alpha_0}$ [S1].

3.  **Define Virtual Source ($\vec{x}_v, \hat{\omega}_v$):**
    *   Set index-matching factor $A = 1$ (assuming no internal Fresnel reflection) [S1].
    *   Calculate virtual position: $\vec{x}_v = \vec{x}_1 + 2 A d_e \hat{n}_1^*$ [S1].
    *   Calculate virtual direction: $\hat{\omega}_v = \hat{\omega}_1^e - 2(\hat{\omega}_1^e \cdot \hat{n}_1^*)\hat{n}_1^*$, where $\hat{\omega}_1^e$ is the effective incoming direction at $\vec{x}_1$ [S1].

4.  **Evaluate Bounded Propagator:**
    The final value is determined by the relationship between the directions and the modified normal $\hat{n}_1^*$ [S1]:
    $$ G_f^b(s, \vec{x}_0, \hat{\omega}_0, \vec{x}_1, \hat{\omega}_1) = \begin{cases} 0 & \text{if } \hat{\omega}_1 \cdot \hat{n}_1^* \geq 0, \\ 0 & \text{if } \hat{\omega}_1^e \cdot \hat{n}_1^* \geq 0, \\ G_f(s, \vec{x}_0, \hat{\omega}_0, \vec{x}_1, \hat{\omega}_1) - G_f(s, \vec{x}_0, \hat{\omega}_0, \vec{x}_v, \hat{\omega}_v) & \text{otherwise.} \end{cases} $$
    *   **Condition 1:** If the outgoing direction points into the effective half-space defined by $\hat{n}_1^*$ ($\hat{\omega}_1 \cdot \hat{n}_1^* \geq 0$), the propagator is 0 [S1].
    *   **Condition 2:** If the incoming direction appears to point out of the medium ($\hat{\omega}_1^e \cdot \hat{n}_1^* \geq 0$), the virtual source would not illuminate the medium in the planar approximation. Set the propagator to 0 [S1].
    *   **Condition 3:** Otherwise, the propagator is the dipole difference between the infinite volume propagator from the real source and the virtual source [S1].

**Pseudocode:**

```python
import math

def dot(v1, v2):
    return v1[0]*v2[0] + v1[1]*v2[1] + v1[2]*v2[2]

def cross(v1, v2):
    return (v1[1]*v2[2] - v1[2]*v2[1],
            v1[2]*v2[0] - v1[0]*v2[2],
            v1[0]*v2[1] - v1[1]*v2[0])

def norm(v):
    return math.sqrt(v[0]**2 + v[1]**2 + v[2]**2)

def bounded_forward_scattering_propagator(s, x0, w0, x1, w1, n1, sigma_s_prime, sigma_a):
    # 1. Calculate Modified Normal n1_star
    R = (x0[0]-x1[0], x0[1]-x1[1], x0[2]-x1[2])
    r_norm = norm(R)
    if r_norm < 1e-9:
        n1_star = n1
    else:
        R_norm = (R[0]/r_norm, R[1]/r_norm, R[2]/r_norm)
        cross_prod = cross(n1, R)
        cross_norm = norm(cross_prod)
        if cross_norm < 1e-9:
            # Ill-defined normal: n1 parallel to R
            return 0.0
        n1_star = cross(R_norm, (cross_prod[0]/cross_norm, cross_prod[1]/cross_norm, cross_prod[2]/cross_norm))

    # 2. Calculate Extrapolation Distance de
    sigma_t_prime = sigma_s_prime + sigma_a
    if sigma_t_prime == 0:
        return 0.0
    alpha_0 = sigma_s_prime / sigma_t_prime
    D = 1.0 / (3.0 * sigma_t_prime)
    if alpha_0 <= 0:
        return 0.0
    d_e = 2.131 * D / math.sqrt(alpha_0)

    # 3. Define Virtual Source
    A = 1.0 # Index-matched boundary
    x_v = (x1[0] + 2.0 * A * d_e * n1_star[0],
           x1[1] + 2.0 * A * d_e * n1_star[1],
           x1[2] + 2.0 * A * d_e * n1_star[2])
    
    # Effective incoming direction at x1 (w1)
    w_v = (w1[0] - 2.0 * dot(w1, n1_star) * n1_star[0],
           w1[1] - 2.0 * dot(w1, n1_star) * n1_star[1],
           w1[2] - 2.0 * dot(w1, n1_star) * n1_star[2])

    # 4. Evaluate Propagator
    # Condition 1: Outgoing direction points into effective half-space
    if dot(w1, n1_star) >= 0:
        return 0.0
    
    # Condition 2: Incoming direction points out of medium
    if dot(w1, n1_star) >= 0:
        return 0.0
    
    # Condition 3: Dipole subtraction
    # Evaluate infinite volume propagator G_f (see Infinite Volume Forward Scattering Propagator)
    g_real = infinite_volume_forward_scattering_propagator(s, x0, w0, x1, w1)
    g_virtual = infinite_volume_forward_scattering_propagator(s, x0, w0, x_v, w_v)
    
    return g_real - g_virtual
```

## Subtopics

### Reciprocal Bounded Propagator
A symmetrical combination of the bounded propagator and its reverse to enforce reciprocity, which is broken by the virtual source dependency on the incoming normal [S1]. The formula is $\frac{1}{2} \left[ G_f^b(s, \vec{x}_0, \hat{\omega}_0, \vec{x}_i, \hat{\omega}_i) + G_f^b(s, \vec{x}_i, -\hat{\omega}_i, \vec{x}_0, -\hat{\omega}_0) \right]$ [S1]. Reciprocity holds only if $\hat{n}_i = \hat{n}_o$ (planar boundaries) or if $\hat{n}_i, \hat{n}_o$ and $\vec{x}_o - \vec{x}_i$ are coplanar [S1]. In practice, the simple $G_f^b$ is used because the difference is negligible and unidirectional path tracing does not strictly require reciprocity [S1].

## Operating characteristics
*   **Complexity:** The method requires evaluating the infinite volume propagator $G_f$ twice (once for the real source, once for the virtual source) plus geometric calculations for the modified normal and virtual source [S1]. The complexity is dominated by $G_f$ [S1].
*   **Performance:** Not given in the sources.
*   **Strengths:** Handles bounded volumes with absorbing boundary conditions without empirical distance corrections, leveraging the well-behaved nature of $G_f$ [S1].
*   **Limitations:** Breaks reciprocity unless the symmetrical combination is used. Ill-defined normals occur when the surface normal is parallel to the displacement vector [S1].
*   **When to use:** When rendering bounded participating media with forward scattering dipole models and index-matched boundaries [S1].

## Background
The method is based on the dipole model for diffusion approximation, originally studied in physics [Bell and Glasstone 1970; Lamarsh 1975] and computer graphics [d'Eon 2014; Habel et al. 2013; Jensen et al. 2001] [S1]. It was introduced in the context of a forward scattering dipole model derived from a functional integral approximation [S1]. It differs from Frisvad et al. [2014] by not requiring an empirical distance correction to offset the real source, as $G_f$ is well-behaved except for the designed delta distribution at short lengths [S1].
