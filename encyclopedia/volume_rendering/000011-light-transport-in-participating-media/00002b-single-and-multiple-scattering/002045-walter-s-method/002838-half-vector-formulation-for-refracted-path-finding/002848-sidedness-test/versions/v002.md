# Sidedness Test


## Overview
The Sidedness Test is a geometric pruning test used to determine if a position bounding box and a normal bounding cone can possibly satisfy the refraction conditions for a light transport path [S1]. It ensures that the view vector $V$ lies on the negative side of the shading normal and within the critical angle cone defined by $\arcsin(1/\eta)$ [S1]. It differs from the smooth normal pruning test only in that positions are bounded by a 3D box rather than a 2D triangle; the test logic is otherwise identical [S1].

## How it works
**Inputs:**
*   Position bounding box $B$ (axis-aligned, defined by min/max extents) [G].
*   Normal bounding cone $C$ (defined by axis $A$ and semi-angle $\alpha$) [S1].
*   Light direction vector $L$ (pointing from surface to light) [G].
*   View direction vector $V$ (pointing from surface to viewer) [G].
*   Refraction index ratio $\eta$ (relative to the medium) [S1].

**Outputs:**
*   Boolean: `True` if the box/cone pair *might* contain a valid refraction point; `False` if it can be safely pruned [S1].

**Method:**
The test verifies three conditions for any potential point $P$ in $B$ with a shading normal $N$ in $C$: $L \cdot N > 0$ (light on the positive side), $V \cdot N < 0$ (viewer on the negative side), and the angle between $V$ and $N$ is less than the critical angle $\theta_c = \arcsin(1/\eta)$ [S1]. To perform this efficiently without sampling, the algorithm computes bounds on the angles between the cone axis $A$ and the vectors $L$ and $V$ as seen from any point in the position bounding box [S1]. These bounds are offset by the semi-angle of the normal bounding cone to check if it is possible for the respective angles to lie within the required ranges [S1].

1.  **Compute angular bounds for $L$:** Calculate the angle $\psi_L$ between the cone axis $A$ and the light direction $L$. Determine the maximum angular deviation $\delta_L$ caused by position variation within $B$ by evaluating the extreme angles subtended by the box corners relative to $L$. The bounds are $[\psi_L - \delta_L, \psi_L + \delta_L]$ clamped to $[0, \pi]$ [G].
2.  **Compute angular bounds for $V$:** Similarly, calculate the angle $\psi_V$ between $A$ and $V$, and the maximum deviation $\delta_V$ from the box corners. The bounds are $[\psi_V - \delta_V, \psi_V + \delta_V]$ clamped to $[0, \pi]$ [G].
3.  **Offset by normal cone semi-angle:** The actual shading normal $N$ can deviate from the cone axis $A$ by at most $\alpha$ [S1]. Adjust the ranges: $[\theta_{L,min}, \theta_{L,max}] = [\max(0, \psi_L - \delta_L - \alpha), \min(\pi, \psi_L + \delta_L + \alpha)]$ and $[\theta_{V,min}, \theta_{V,max}] = [\max(0, \psi_V - \delta_V - \alpha), \min(\pi, \psi_V + \delta_V + \alpha)]$ [S1].
4.  **Check validity ranges:** 
    *   **Light Condition:** The light is on the positive side if the angle is $< \pi/2$. The test passes if the minimum possible angle satisfies $\theta_{L,min} < \pi/2$ [S1].
    *   **Viewer Condition:** The viewer is on the negative side if the angle is $> \pi/2$. The test passes if the maximum possible angle satisfies $\theta_{V,max} > \pi/2$ [S1].
    *   **Critical Angle Condition:** The viewer must be within the critical angle cone. The test passes if the minimum possible angle satisfies $\theta_{V,min} < \arcsin(1/\eta)$ [S1].
5.  **Result:** Return `True` if all three checks pass. Otherwise, return `False` [S1].

**Pseudocode:**
```python
import math

def dot(a, b):
    return a[0]*b[0] + a[1]*b[1] + a[2]*b[2]

def normalize(v):
    inv_len = 1.0 / math.sqrt(dot(v, v))
    return (v[0]*inv_len, v[1]*inv_len, v[2]*inv_len)

def angle_between(a, b):
    cos_theta = max(-1.0, min(1.0, dot(a, b)))
    return math.acos(cos_theta)

def max_angle_deviation_from_box(box_min, box_max, direction):
    # [G] Computes the maximum angle between `direction` and the vectors
    # from any point in the axis-aligned box to the source.
    # The extreme angles occur at the box corners.
    corners = [
        (box_min[0], box_min[1], box_min[2]),
        (box_max[0], box_min[1], box_min[2]),
        (box_min[0], box_max[1], box_min[2]),
        (box_max[0], box_max[1], box_min[2]),
        (box_min[0], box_min[1], box_max[2]),
        (box_max[0], box_min[1], box_max[2]),
        (box_min[0], box_max[1], box_max[2]),
        (box_max[0], box_max[1], box_max[2])
    ]
    dir_norm = normalize(direction)
    max_ang = 0.0
    for c in corners:
        max_ang = max(max_ang, angle_between(dir_norm, c))
    return max_ang

def sidedness_test(box_min, box_max, cone_axis, cone_semi_angle, L, V, eta):
    alpha = cone_semi_angle
    theta_c = math.asin(1.0 / eta)
    
    axis_norm = normalize(cone_axis)
    psi_L = angle_between(axis_norm, L)
    psi_V = angle_between(axis_norm, V)
    
    delta_L = max_angle_deviation_from_box(box_min, box_max, L)
    delta_V = max_angle_deviation_from_box(box_min, box_max, V)
    
    min_angle_L_N = max(0.0, psi_L - delta_L - alpha)
    max_angle_L_N = min(math.pi, psi_L + delta_L + alpha)
    
    min_angle_V_N = max(0.0, psi_V - delta_V - alpha)
    max_angle_V_N = min(math.pi, psi_V + delta_V + alpha)
    
    light_positive = min_angle_L_N < (math.pi / 2.0)
    viewer_negative = max_angle_V_N > (math.pi / 2.0)
    within_critical = min_angle_V_N < theta_c
    
    return light_positive and viewer_negative and within_critical
```

**Edge Cases and Pitfalls:**
*   **Precision:** When angles are close to $\pi/2$ or $\theta_c$, floating-point errors may lead to incorrect pruning. Use epsilon comparisons [G].
*   **Degenerate Box:** If the position box is a point, $\delta_L$ and $\delta_V$ are zero [G].
*   **Large Normal Variation:** If $\alpha$ is large, the bounds become loose and the test may fail to prune, but the test remains cheap to compute [S1].
*   **Total Internal Reflection:** If $\eta < 1$, $\theta_c$ is valid. If $\eta \ge 1$, $\theta_c$ is $\pi/2$ or undefined. The formula $\arcsin(1/\eta)$ handles $\eta > 1$ [G].

## Subtopics

### [Cone Overlap Test for Refractive Boundaries](4948-cone-overlap-test-for-refractive-boundaries.md)
The Cone Overlap Test is a pruning test that determines if a position bounding box and a normal bounding cone can satisfy refraction conditions. It differs from the smooth normal pruning test only by bounding positions with a 3D box instead of a 2D triangle, while keeping identical test logic. Choose it when traversing acceleration structures for refractive media to quickly discard subtrees with large normal variation.

## Operating characteristics
*   **Time Complexity:** $O(1)$ per node in the acceleration structure. The computation involves basic trigonometric functions and comparisons [G].
*   **Memory Complexity:** $O(1)$ auxiliary space [G].
*   **Performance:** The test is cheap to compute and does not depend on the shading normals, allowing it to prune many subtrees even if they have large normal bounding cones [S1].
*   **Strengths:** It is independent of the specific shading normals, relying only on the bounding cone axis and semi-angle. It handles 3D position boxes effectively [S1].
*   **Limitations:** It is a necessary condition, not sufficient. It may return `True` for boxes that do not contain valid points, requiring further refinement [G].
*   **When to use:** Use during the traversal of the acceleration structure (e.g., BVH or KD-tree) for refractive media to quickly discard regions that cannot contribute to the light path [S1].

## Background
The Sidedness Test is part of the method for single scattering in refractive media with triangle mesh boundaries, introduced by Walter et al. [S1]. It builds on techniques from [Walter et al. 2005] for pruning sub-triangles in the smooth normal case, extending them to 3D position bounding boxes for refractive boundaries [S1].
