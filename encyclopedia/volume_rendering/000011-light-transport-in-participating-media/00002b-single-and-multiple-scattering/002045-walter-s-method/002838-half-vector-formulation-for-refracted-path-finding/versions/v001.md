# Half-vector formulation for refracted path finding

Also called: Half-vector based formulation

## Overview
This method finds points $P$ on a boundary surface that refract light from a source $L$ to a scatter point $V$, specifically handling cases where the shading normal $\hat{\mathbf{N}}_s$ differs from the geometric normal $\hat{\mathbf{N}}_g$ [S1]. It sets it apart from Fermat’s principle-based approaches by using a refractive half-vector $\hat{\mathbf{H}}$ that remains collinear with the shading normal at valid solutions, allowing Snell’s law to be satisfied even with interpolated normals or normal maps [S1].

## How it works
**Inputs:**
*   Source position $\mathbf{L}$ (3D vector).
*   Scatter/view position $\mathbf{V}$ (3D vector).
*   Relative index of refraction $\eta = \eta_{in}/\eta_{out}$ (scalar).
*   Shading normal field $\hat{\mathbf{N}}_s(\mathbf{P})$ (unit vector field defined on the boundary).

**Outputs:**
*   Set of valid boundary points $P$ satisfying the refraction conditions.

**Data Structures:**
*   Vectors are 3D Cartesian coordinates.
*   Normals are unit vectors.

**Steps:**
1.  **Define Direction Vectors:** For a candidate point $P$ on the boundary, compute the unit direction vectors from $P$ to the source and from $P$ to the scatter point. Note that the source text contains a typo in Equation (1) using dot product notation $\mathbf{V} \cdot \mathbf{P}$; context and Equation (2) imply vector subtraction is required [S1].
    $$ \hat{\omega}_V = \frac{\mathbf{V} - \mathbf{P}}{\|\mathbf{V} - \mathbf{P}\|} $$
    $$ \hat{\omega}_L = \frac{\mathbf{L} - \mathbf{P}}{\|\mathbf{L} - \mathbf{P}\|} $$
    Here, $\hat{\omega}_V$ points from $P$ to $V$, and $\hat{\omega}_L$ points from $P$ to $L$ [S1].

2.  **Compute Half-Vector:** Calculate the unnormalized refractive half-vector using the relative index of refraction $\eta$. The source text uses $\hat{\omega}_{\text{A}}$ in Equation (3), which contextually refers to $\hat{\omega}_{\text{V}}$ (the internal direction) [S1].
    $$ \hat{\mathbf{H}} = \frac{\eta \hat{\omega}_V + \hat{\omega}_L}{\|\eta \hat{\omega}_V + \hat{\omega}_L\|} $$
    This vector $\hat{\mathbf{H}}$ is collinear with the surface normal at all valid refraction points $P$ because requiring its components perpendicular to the normal to vanish is equivalent to Snell’s law [S1].

3.  **Validate Solution:** A point $P$ is a valid solution if and only if two conditions are met [S1]:
    *   **Normal Alignment:** The half-vector is anti-parallel to the shading normal:
        $$ \hat{\mathbf{H}} = -\hat{\mathbf{N}}_s $$
    *   **Side Constraints:** The source $L$ and viewer $V$ lie on opposite sides of the local tangent plane defined by $\hat{\mathbf{N}}_s$. This is tested by comparing the dot products of the positions with the normal:
        $$ (\mathbf{V} \cdot \hat{\mathbf{N}}_s) \leq (\mathbf{P} \cdot \hat{\mathbf{N}}_s) \leq (\mathbf{L} \cdot \hat{\mathbf{N}}_s) $$
        (Assuming $\eta > 1$ and appropriate orientation conventions; the inequality ensures $P$ lies between the projections of $V$ and $L$ along the normal direction) [S1].

**Pseudocode:**
```python
def is_valid_refraction_point(P, L, V, eta, get_shading_normal):
    """
    Checks if point P is a valid refraction point from L to V.
    """
    # 1. Compute direction vectors
    # Note: Source text Eq (1) has typo V.P; corrected to V - P
    dir_to_V = V - P
    dir_to_L = L - P
    
    # Handle degenerate cases where P coincides with L or V
    if norm(dir_to_V) < 1e-9 or norm(dir_to_L) < 1e-9:
        return False
        
    omega_V = dir_to_V / norm(dir_to_V)
    omega_L = dir_to_L / norm(dir_to_L)
    
    # 2. Compute half-vector H
    # Source text Eq (3) uses omega_A; context implies omega_V
    H_unnorm = eta * omega_V + omega_L
    H = H_unnorm / norm(H_unnorm)
    
    # 3. Get shading normal at P
    N_s = get_shading_normal(P)
    
    # 4. Check Normal Alignment: H = -N_s
    # Use a small epsilon for floating point comparison
    if dot(H, -N_s) < 1.0 - 1e-6:
        return False
        
    # 5. Check Side Constraints: (V . N_s) <= (P . N_s) <= (L . N_s)
    # This assumes specific orientation; generally checks if P is between V and L
    # relative to the normal plane.
    v_proj = dot(V, N_s)
    p_proj = dot(P, N_s)
    l_proj = dot(L, N_s)
    
    if not (v_proj <= p_proj <= l_proj or l_proj <= p_proj <= v_proj):
        return False
        
    return True
```

**Parameters:**
*   $\eta$: Relative index of refraction. Typical values depend on the media (e.g., air to glass $\approx 1.5$).

**Edge Cases and Pitfalls:**
*   **Typo Correction:** The source text defines $\hat{\omega}_V$ using a dot product $\mathbf{V} \cdot \mathbf{P}$ in Equation (1), which is dimensionally incorrect for a direction vector. It must be interpreted as vector subtraction $\mathbf{V} - \mathbf{P}$ [S1].
*   **Variable Naming:** The source text uses $\hat{\omega}_{\text{A}}$ in Equation (3) instead of $\hat{\omega}_{\text{V}}$. This is a contextual error; $\hat{\omega}_{\text{V}}$ is the correct term [S1].
*   **Shading vs Geometric Normal:** This method is specifically designed for cases where $\hat{\mathbf{N}}_g \neq \hat{\mathbf{N}}_s$. If $\hat{\mathbf{N}}_g = \hat{\mathbf{N}}_s$, Fermat’s principle may be used, but this formulation remains valid [S1].

## Background
This formulation was introduced by Walter et al. in 2007 to address the limitations of Fermat’s principle in participating media with triangle mesh boundaries where shading normals vary (e.g., due to normal mapping or interpolation) [S1]. It generalizes the refraction path finding problem to handle these varying normals by leveraging the properties of the refractive half-vector.
