# Delta Tracking with Volume State Changes

Also called: Delta tracking with density updates, Sample reuse in volumes

## Overview
This method adapts delta tracking to handle volumes that change state between optimization iterations, such as in inverse rendering or dynamic simulations. It solves the problem of efficiently reusing sampled path vertices from previous iterations by ensuring the majorant extinction coefficient bounds the density of both the old and new volume states simultaneously [S1]. Unlike standard delta tracking which assumes a static density field, this approach treats the transition between states as a correlated sampling problem, analogous to rendering spectrally varying volumes [S1].

## How it works
**Inputs and Outputs:**
- Input: A sequence of volume density fields $\rho_t(\mathbf{x})$ for iteration $t$ and $t+1$.
- Input: A set of previously sampled path vertices $\{\mathbf{x}_i\}$ from iteration $t$.
- Output: Updated path vertices and weights for iteration $t+1$ that maintain statistical consistency.

**Data Structures:**
- `Majorant`: A scalar value $M$ representing the upper bound on extinction.
- `Vertices`: A list of 3D points $\mathbf{x}$ and associated weights $w$.

**Method Steps:**
1. **Determine the Combined Majorant:** For each sampled vertex $\mathbf{x}_i$ from the previous iteration, calculate the maximum density between the old state $\rho_t(\mathbf{x}_i)$ and the new state $\rho_{t+1}(\mathbf{x}_i)$. The majorant $M$ must satisfy:
   $$ M \geq \max(\sigma_t(\mathbf{x}_i), \sigma_{t+1}(\mathbf{x}_i)) $$
   where $\sigma$ is the extinction coefficient derived from density [S1]. In practice, $M$ is often set to the global maximum of the union of densities or a conservative bound covering both fields [S1].

2. **Sample Free Path:** Using the majorant $M$, sample the distance to the next collision using the standard delta tracking free path distribution:
   $$ d = -\frac{\ln(r)}{M} $$
   where $r$ is a uniform random number in $(0, 1)$ [S1].

3. **Evaluate State:** At the new position $\mathbf{x}' = \mathbf{x} + d \cdot \omega$, evaluate the density for the current target state (e.g., $\rho_{t+1}$).

4. **Accept/Reject:** Perform the standard delta tracking acceptance test. If the sampled density is less than the majorant, accept the collision with probability $\frac{\sigma_{t+1}(\mathbf{x}')}{M}$. If rejected, treat it as a null collision and repeat from step 2 [S1].

5. **Weight Adjustment:** If the vertex is reused from a previous iteration, adjust the weight to account for the change in density and the increased probability of null collisions due to the larger majorant [S1].

**Parameters:**
- $M$: Majorant extinction. Must be $\geq \max(\sigma_{old}, \sigma_{new})$ at all sampled points [S1].

**Edge Cases and Pitfalls:**
- **Increased Null Collisions:** Bounding the majorant for both states increases the number of null collisions because $M$ is larger than the density of either individual state [S1].
- **Small Density Changes:** The overhead is typically limited because density changes between optimization iterations are small [S1].
- **Precision:** Ensure $M$ is computed with sufficient precision to avoid underestimating the bound, which would bias the results [G].

A rendering technique for participating media (clouds, fog, godrays) that uses delta tracking and ratio tracking on density fields instead of sphere tracing on distance, allowing for heterogeneous (non-uniform) density distributions.

## Operating characteristics
- **Time Complexity:** Increases with the ratio of the combined majorant to the actual density. Since $M$ bounds both old and new densities, the expected number of null collisions is proportional to $M / \sigma_{avg}$ [S1].
- **Memory Complexity:** Low, as it reuses existing vertex data structures [S1].
- **Strengths:** Enables efficient optimization by reusing path samples, reducing the cost of recomputing paths from scratch [S1].
- **Limitations:** The increase in null collisions can degrade performance if density changes are large between iterations [S1].
- **When to Use:** Inverse rendering or optimization tasks where volume parameters are updated iteratively and path reuse is beneficial [S1].
- **When Not to Use:** Static rendering where densities do not change, or where density changes are so large that the majorant becomes inefficient [S1].

## Background
The concept of sample reuse in volumes was introduced in the context of recursive control variates for inverse rendering [S1]. The authors observed that rendering a volume with two states (old and new) is mathematically analogous to rendering a volume with spectrally varying extinction and albedo [S1]. This insight allows techniques developed for spectrally varying volumes to be applied to temporal state changes in optimization [S1]. The method builds on the foundational delta tracking algorithm by Woodcock et al. [S1].
