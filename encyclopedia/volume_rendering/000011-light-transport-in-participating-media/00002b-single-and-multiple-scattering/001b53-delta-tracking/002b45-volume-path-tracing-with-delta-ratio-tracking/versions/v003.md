# Volume Path Tracing with Delta/Ratio Tracking

Also called: WebGPU Volume Pathtracer, Woodcock Tracking in WGSL

## Overview
A path tracing method for volumetric rendering implemented in WGSL that uses delta tracking (Woodcock tracking) to sample scattering events and ratio tracking for transmittance estimation [S1, unofficial]. It renders a 3D volume texture using ray-box intersection and Monte Carlo integration [S1, unofficial]. It differs from standard path tracing by explicitly separating the sampling of scattering events (via rejection sampling in delta tracking) from the estimation of transmittance (via ratio tracking), allowing for distinct handling of emission and absorption in heterogeneous media [S1, unofficial].

## How it works
**Inputs and Outputs:**
*   **Inputs:**
    *   `ViewParams`: Uniform buffer containing projection/view matrix (`proj_view`), eye position (`eye_pos`), volume scale (`volume_scale`), light direction (`light_dir`), frame ID (`frame_id`), and scaling factors (`sigma_t_scale`, `sigma_s_scale`) [S1, unofficial].
    *   `volumeTexture`: 3D texture (`rgba32float`) storing volume density data [S1, unofficial].
    *   `colormapTexture`: 2D texture storing color mapping for scattering events [S1, unofficial].
    *   Pixel coordinates and frame ID for RNG seeding [S1, unofficial].
*   **Outputs:**
    *   Accumulation buffer (`rgba32float`) storing the final image color [S1, unofficial].

**Data Structures:**
*   `ViewParams`:
    *   `proj_view`: `mat4x4<f32>` (16 floats) [S1, unofficial].
    *   `eye_pos`: `float4` (4 floats) [S1, unofficial].
    *   `volume_scale`: `float4` (4 floats) [S1, unofficial].
    *   `light_dir`: `float4` (4 floats) [S1, unofficial].
    *   `frame_id`: `u32` (1 uint) [S1, unofficial].
    *   `sigma_t_scale`: `f32` (1 float) [S1, unofficial].
    *   `sigma_s_scale`: `f32` (1 float) [S1, unofficial].
    *   *Note:* WGSL padding is assumed to align to `vec4` boundaries [S1, unofficial].
*   `LCGRand`:
    *   `state`: `u32` [S1, unofficial].
*   `SamplingResult`:
    *   `scattering_event`: `bool` [S1, unofficial].
    *   `color`: `float3` [S1, unofficial].
    *   `transmittance`: `f32` [S1, unofficial].

**Parameters:**
*   `sigma_t_scale`: Scaling factor for extinction coefficient in step size calculation. Default: 100.0 [S1, unofficial].
*   `sigma_s_scale`: Scaling factor for scattering coefficient. Default: 1.0 [S1, unofficial]. *Note: Not explicitly used in the provided tracking function snippets, only `sigma_t_scale` is used in the log calculation* [S1, unofficial].
*   `volume_emission`: Constant ambient emission strength. Default: 0.5 [S1, unofficial].
*   `ambient_strength`: Constant environment light contribution. Default: 0.0 [S1, unofficial].
*   Hash dimensions: Fixed at 1280x720 for RNG seeding [S1, unofficial].

**Steps:**

1.  **RNG Initialization:**
    For each pixel, initialize a Linear Congruential Generator (LCG) state using a hash of the pixel coordinates and frame ID. The hash function is MurmurHash3 mix/finalize [S1, unofficial].

2.  **Ray-Box Intersection:**
    Compute the intersection interval $[t_0, t_1]$ of the view ray with the unit cube $[0,1]^3$. If no intersection ($t_0 > t_1$), discard the pixel. Clamp $t_0$ to $\max(t_0, 0.0)$ [S1, unofficial].

3.  **Path Tracing Loop:**
    Iterate 4 times (hardcoded loop limit) [S1, unofficial].
    *   Initialize `illum = (0.0, 0.0, 0.0)`, `throughput = 1.0`, `had_any_event = false`, `pos = transformed_eye` [S1, unofficial].
    *   For each iteration:
        *   Call `sample_woodcock` to get a `SamplingResult` [S1, unofficial].
        *   If **no scattering event**:
            *   If `had_any_event` is true, add `throughput * ambient_strength` to `illum` [S1, unofficial].
            *   Else (first miss), add `throughput * volume_emission` to `illum` [S1, unofficial].
        *   If **scattering event**:
            *   Add `throughput * event.color` to `illum` [S1, unofficial].
            *   Update `throughput *= event.transmittance` [S1, unofficial].
            *   Set `had_any_event = true` [S1, unofficial].
        *   Update `pos += t * ray_dir` [S1, unofficial].

4.  **Woodcock Tracking (`sample_woodcock`):**
    *   Initialize `transmittance = 0` [S1, unofficial].
    *   Loop:
        *   Generate two random numbers `samples.x`, `samples.y` [S1, unofficial].
        *   Update distance $t$: $t \leftarrow t - \frac{\log(1.0 - \text{samples}.x)}{\text{params}.\sigma_t\_scale}$ [S1, unofficial].
        *   If $t \ge \text{interval}.y$, break (no event in volume) [S1, unofficial].
        *   Sample volume density at $p = \text{orig} + t \times \text{dir}$, let value be `val` [S1, unofficial].
        *   If `val > samples.y`:
            *   Set `scattering_event = true` [S1, unofficial].
            *   Set `color = colormap(val)` [S1, unofficial].
            *   Set `transmittance = 1.0 - val` [S1, unofficial].
            *   Break [S1, unofficial].
        *   Else continue loop [S1, unofficial].

5.  **Delta Tracking Transmittance (`delta_tracking_transmittance`):**
    *   Initialize `transmittance = 1.0`, $t = \text{interval}.x$ [S1, unofficial].
    *   Loop:
        *   Generate two random numbers [S1, unofficial].
        *   Update $t$: $t \leftarrow t - \frac{\log(1.0 - \text{samples}.x)}{\text{params}.\sigma_t\_scale}$ [S1, unofficial].
        *   If $t \ge \text{interval}.y$, break [S1, unofficial].
        *   Sample density `val` [S1, unofficial].
        *   If `val > samples.y`, return `0.0` (absorption) [S1, unofficial].
        *   Else continue [S1, unofficial].
    *   Return `1.0` if loop completes [S1, unofficial].

6.  **Ratio Tracking Transmittance (`ratio_tracking_transmittance`):**
    *   Initialize `transmittance = 1.0`, $t = \text{interval}.x$ [S1, unofficial].
    *   Loop:
        *   Generate one random number [S1, unofficial].
        *   Update $t$: $t \leftarrow t - \frac{\log(1.0 - \text{random})}{\text{params}.\sigma_t\_scale}$ [S1, unofficial].
        *   If $t \ge \text{interval}.y$, break [S1, unofficial].
        *   Sample density `val` [S1, unofficial].
        *   Update `transmittance *= (1.0 - val)` [S1, unofficial].
    *   Return `transmittance` [S1, unofficial].

**Pseudocode:**

```python
import math

HASH_DIMS = (1280, 720)
MAX_ITERATIONS = 4
VOLUME_EMISSION = 0.5
AMBIENT_STRENGTH = 0.0

def murmur_hash_3_mix(x):
    x = ((x >> 16) ^ x) * 0x85ebca6b
    x = ((x >> 13) ^ x) * 0xc2b2ae35
    x = x ^ (x >> 16)
    return x

def murmur_hash_3_finalize(x):
    h = x ^ (x >> 16)
    h = (h * 0x85ebca6b) & 0xFFFFFFFF
    h = h ^ (h >> 13)
    h = (h * 0xc2b2ae35) & 0xFFFFFFFF
    h = h ^ (h >> 16)
    return h

def murmur_hash_3(pixel_x, pixel_y, frame_id):
    h = pixel_x + (pixel_y * HASH_DIMS[0]) + (frame_id * 1000000)
    h = murmur_hash_3_mix(h)
    return murmur_hash_3_finalize(h)

class LCG:
    def __init__(self, seed):
        self.state = seed & 0xFFFFFFFF
        self.a = 1664525
        self.c = 1013904223
        self.m = 0x100000000

    def next(self):
        self.state = (self.a * self.state + self.c) % self.m
        return self.state / self.m

def ray_box_intersection(ray_origin, ray_direction):
    t_min = -float('inf')
    t_max = float('inf')
    for i in range(3):
        if ray_direction[i] == 0:
            if ray_origin[i] < 0 or ray_origin[i] > 1:
                return None
        else:
            t1 = (0 - ray_origin[i]) / ray_direction[i]
            t2 = (1 - ray_origin[i]) / ray_direction[i]
            t_min = max(t_min, min(t1, t2))
            t_max = min(t_max, max(t1, t2))
    if t_min > t_max:
        return None
    t0 = max(t_min, 0.0)
    t1 = t_max
    return (t0, t1)

def sample_volume_density(pos, volume_texture):
    return volume_texture.sample(pos)

def sample_colormap(val, colormap_texture):
    return colormap_texture.sample(val)

def compute_ray_direction(pixel_x, pixel_y, proj_view):
    return (0.0, 0.0, 1.0)

def sample_woodcock(orig, dir, interval, params, rng, volume_texture, colormap_texture):
    transmittance = 0.0
    scattering_event = False
    color = (0.0, 0.0, 0.0)
    t = 0.0
    while True:
        r1 = rng.next()
        r2 = rng.next()
        if r1 == 0.0: r1 = 1e-9
        t -= math.log(1.0 - r1) / params.sigma_t_scale
        if t >= interval[1]:
            break
        pos = (orig[0] + t * dir[0], orig[1] + t * dir[1], orig[2] + t * dir[2])
        val = sample_volume_density(pos, volume_texture)
        if val > r2:
            scattering_event = True
            color = sample_colormap(val, colormap_texture)
            transmittance = 1.0 - val
            break
    return {"scattering_event": scattering_event, "color": color, "transmittance": transmittance, "t": t}

def delta_tracking_transmittance(orig, dir, interval, params, rng, volume_texture):
    transmittance = 1.0
    t = interval[0]
    while True:
        r1 = rng.next()
        r2 = rng.next()
        if r1 == 0.0: r1 = 1e-9
        t -= math.log(1.0 - r1) / params.sigma_t_scale
        if t >= interval[1]:
            break
        pos = (orig[0] + t * dir[0], orig[1] + t * dir[1], orig[2] + t * dir[2])
        val = sample_volume_density(pos, volume_texture)
        if val > r2:
            return 0.0
    return 1.0

def ratio_tracking_transmittance(orig, dir, interval, params, rng, volume_texture):
    transmittance = 1.0
    t = interval[0]
    while True:
        r1 = rng.next()
        if r1 == 0.0: r1 = 1e-9
        t -= math.log(1.0 - r1) / params.sigma_t_scale
        if t >= interval[1]:
            break
        pos = (orig[0] + t * dir[0], orig[1] + t * dir[1], orig[2] + t * dir[2])
        val = sample_volume_density(pos, volume_texture)
        transmittance *= (1.0 - val)
    return transmittance

def fragment_main(pixel_x, pixel_y, frame_id, view_params, volume_texture, colormap_texture):
    seed = murmur_hash_3(pixel_x, pixel_y, frame_id)
    rng = LCG(seed)
    ray_origin = view_params.eye_pos
    ray_direction = compute_ray_direction(pixel_x, pixel_y, view_params.proj_view)
    interval = ray_box_intersection(ray_origin, ray_direction)
    if interval is None:
        return (0.0, 0.0, 0.0, 1.0)
    illum = (0.0, 0.0, 0.0)
    throughput = 1.0
    had_any_event = False
    pos = ray_origin
    for _ in range(MAX_ITERATIONS):
        result = sample_woodcock(pos, ray_direction, interval, view_params, rng, volume_texture, colormap_texture)
        if not result["scattering_event"]:
            if had_any_event:
                illum = (illum[0] + throughput * AMBIENT_STRENGTH, illum[1] + throughput * AMBIENT_STRENGTH, illum[2] + throughput * AMBIENT_STRENGTH)
            else:
                illum = (illum[0] + throughput * VOLUME_EMISSION, illum[1] + throughput * VOLUME_EMISSION, illum[2] + throughput * VOLUME_EMISSION)
        else:
            illum = (illum[0] + throughput * result["color"][0], illum[1] + throughput * result["color"][1], illum[2] + throughput * result["color"][2])
        throughput *= result["transmittance"]
        had_any_event = True
        pos = (pos[0] + result["t"] * ray_direction[0], pos[1] + result["t"] * ray_direction[1], pos[2] + result["t"] * ray_direction[2])
    return illum
```

## Subtopics

### [Differentiable Volume Path Tracing with Delta Tracking](7377-differentiable-volume-path-tracing-with-delta-tracking.md)
A differentiable path tracer for participating media that uses delta tracking (Woodcock tracking) to sample volumetric scattering events and handles surface interactions via BSDF sampling, accumulating separate gradients for emission, scattering, and extinction coefficients to enable inverse rendering optimization of volume parameters. It differs from standard path tracing by maintaining distinct gradient accumulators for volume coefficients, allowing the optimization of material properties directly from image gradients.

## Operating characteristics
*   **Time Complexity:** Linear with respect to the number of scattering events sampled per ray. The number of iterations in Woodcock tracking depends on the ratio of the sampled density to the majorant ($\sigma_t\_scale$). Higher majorants lead to more rejections and more iterations [S1, unofficial].
*   **Memory Complexity:** Low. Requires storage for the 3D volume texture, colormap texture, and uniform parameters. The accumulation buffer is double-buffered [S1, unofficial].
*   **Measured Performance:** Implemented in WebGPU/WGSL. Performance depends on GPU hardware and volume resolution. Volumes with width not divisible by 256 require padding, increasing memory usage [S1, unofficial].
*   **Scaling:** Scales with resolution and number of samples (iterations). The hardcoded loop limit of 4 iterations limits accuracy in highly scattering media [S1, unofficial].
*   **Strengths:** Handles heterogeneous volumes efficiently via delta tracking. Simple implementation in WGSL. Deterministic RNG ensures reproducibility [S1, unofficial].
*   **Limitations:** Hardcoded loop limit may cause bias. Ratio tracking can require more samples for convergence in highly absorbing media [S1, unofficial]. Volume padding may waste memory [S1, unofficial].
*   **When to use:** Real-time volumetric rendering on WebGPU-capable hardware [S1, unofficial].
*   **When not to use:** High-accuracy offline rendering requiring many scattering events [S1, unofficial].
