# Delta tracking

Also called: Homogenization, Homogenized Free-Flight Sampling, Null-Scattering, Woodcock Tracking

## Overview
Delta tracking is a Monte Carlo method for sampling free path lengths in heterogeneous participating media by converting the medium into a homogeneous one via "fake" particles (null-scattering) [S1, S2, S4]. It solves the problem of computing transmittance and scattering events in volumes where the extinction coefficient varies spatially, avoiding the implicit bias of equidistant ray marching [S3, S4]. It sets itself apart from [Homogeneous Medium Sampling](980-homogeneous-medium-sampling.md) by handling spatially varying density without subdivision, and from [Ray Marching](1135-single-scattering-homogeneous-volume-rendering.md) by providing an unbiased estimator at the cost of potentially high variance in sparse regions [S3, S4].

## How it works
**Inputs and Outputs:**
*   **Input:** A ray defined by origin $\mathbf{o}$ and direction $\mathbf{d}$; a volume dataset providing density $\rho(\mathbf{x})$ or extinction $\sigma_t(\mathbf{x})$ at any point; the majorant extinction coefficient $\sigma_t^{\max}$ (the global maximum of $\sigma_t$ in the volume) [S2, S4].
*   **Output:** A sequence of interaction points and types (real collision, null collision, or surface hit) allowing the accumulation of radiance [S1, S4].

**Data Structures:**
*   **Volume:** A sparse or dense grid (e.g., VDB) supporting point queries for density/extinction [S2].
*   **Majorant:** A single scalar value $\sigma_t^{\max}$, computed by iterating through all voxels to find the maximum density and converting it to extinction using the medium's scattering and absorption coefficients [S2].

**Steps:**
1.  **Initialize:** Set current position $\mathbf{p} = \mathbf{o}$ and distance traveled $t = 0$ [S4].
2.  **Sample Free Path:** Generate a uniform random number $\xi \in [0, 1]$. Sample the distance to the next candidate collision $d$ using the majorant extinction:
    $$ d = -\frac{\ln(\xi)}{\sigma_{t}^{\max}} $$
    [S2]
3.  **Advance:** Update position $\mathbf{p} \leftarrow \mathbf{p} + \mathbf{d} \cdot \mathbf{d}$ and $t \leftarrow t + d$ [S4].
4.  **Check Boundary:** If $\mathbf{p}$ is outside the volume or has hit a surface ($t \ge t_{\text{hit}}$), terminate the ray. If it hit a surface, compute surface lighting $L_{\text{surface}}$ [S1, S4].
5.  **Evaluate Density:** Sample the actual extinction coefficient $\sigma_t(\mathbf{p})$ at the new position $\mathbf{p}$ from the volume data [S2, S4].
6.  **Accept/Reject:** Generate a second uniform random number $\xi' \in [0, 1]$. Calculate the acceptance probability:
    $$ p_{\text{accept}} = \frac{\sigma_{t}(\mathbf{p})}{\sigma_{t}^{\max}} $$
    [S2]
    *   If $\xi' < p_{\text{accept}}$, the collision is **real**. Proceed with scattering/absorption decisions (e.g., sample phase function, compute scattering integral) [S1, S2].
    *   If $\xi' \ge p_{\text{accept}}$, the collision is a **null collision** (hit a fake particle). The ray continues in a straight line with no change in radiance. Return to Step 2 from the current position $\mathbf{p}$ [S1, S2, S4].

**Formulas:**
*   **Radiative Transfer Equation (RTE) for heterogeneous media (no emission):**
    $$ \frac{d}{dt} L(\mathbf{p}(t), \omega) = -\sigma_t(\mathbf{p}(t)) L(\mathbf{p}(t), \omega) + \sigma_s(\mathbf{p}(t)) \int_{S^2} \rho(\omega, \omega') L(\mathbf{p}(t), \omega') d\omega' $$
    [S1]
*   **Modified RTE with null-scattering density $\sigma_n$:**
    $$ \frac{d}{dt} L(\mathbf{p}(t), \omega) = - (\sigma_t(\mathbf{p}(t)) + \sigma_n(\mathbf{p}(t))) L(\mathbf{p}(t), \omega) + \sigma_n(\mathbf{p}(t)) L(\mathbf{p}(t), \omega) + \sigma_s(\mathbf{p}(t)) \int_{S^2} \rho(\omega, \omega') L(\mathbf{p}(t), \omega') d\omega' $$
    [S1]
    Here, $\sigma_n(\mathbf{p}) = \sigma_t^{\max} - \sigma_t(\mathbf{p})$ ensures the total extinction is constant $\sigma_t^{\max}$ [S1].
*   **Homogenized Transmittance:**
    $$ T_m(\mathbf{p}(0), \mathbf{p}(t')) = \exp(-\sigma_m t') $$
    where $\sigma_m = \sigma_t^{\max}$ [S1].

**Pseudocode:**
```python
def delta_track(ray, volume, sigma_t_max, max_depth):
    """
    ray: object with origin, direction, and t_hit (distance to surface)
    volume: object with method sample_density(point)
    sigma_t_max: scalar, the majorant extinction coefficient
    max_depth: integer, maximum scattering bounces
    """
    t = 0.0
    current_radiance = Color(0, 0, 0)
    
    for _ in range(max_depth):
        # 1. Sample free path length using majorant
        xi = random_uniform(0, 1)
        d = -log(xi) / sigma_t_max
        
        # 2. Advance ray
        t += d
        p = ray.origin + ray.direction * t
        
        # 3. Check if ray exited volume or hit surface
        if t >= ray.t_hit or not volume.contains(p):
            # Hit surface or exit
            if t < ray.t_hit and volume.contains(p):
                # Should not happen if logic is correct, but handle boundary
                pass
            return current_radiance + volume.get_background_color() * exp(-sigma_t_max * t) # Note: Transmittance estimation is complex in pure delta tracking without ratio tracking
            
        # 4. Evaluate actual extinction at new position
        sigma_t_actual = volume.sample_extinction(p)
        
        # 5. Accept/Reject collision
        xi_accept = random_uniform(0, 1)
        p_accept = sigma_t_actual / sigma_t_max
        
        if xi_accept < p_accept:
            # Real collision
            # Compute scattering contribution
            # Sample phase function, etc.
            # Add to radiance
            # Break or continue for multiple scattering
            break 
        else:
            # Null collision: continue ray
            continue
            
    return current_radiance
```
*[G] The pseudocode above simplifies the radiance accumulation. In a full path tracer, real collisions contribute to the radiance integral via the scattering term. For pure transmittance estimation (as in [S3]), the result is binary (0 if absorbed/scattered, 1 if exited), which has high variance. Ratio tracking [1044-ratio-tracking-with-null-scattering.md] is often used to mitigate this.*

**Parameters:**
*   $\sigma_t^{\max}$: The majorant extinction coefficient. Must be $\ge \sigma_t(\mathbf{x})$ for all $\mathbf{x}$ in the volume [S2]. Tighter majorants reduce null collisions [S4].

**Edge Cases and Pitfalls:**
*   **Empty Space:** Volumes with large low-density regions cause many null collisions because $\sigma_t^{\max}$ remains high while $\sigma_t(\mathbf{p})$ is low, leading to $p_{\text{accept}} \approx 0$ [S2, S4].
*   **Variance:** Binary transmittance estimation (accept/reject) introduces high variance. Ratio tracking is recommended for better convergence [S2, S3].
*   **Majorant Computation:** Finding $\sigma_t^{\max}$ requires a full scan of the volume data structure, which can be expensive for large sparse volumes [S2].

## Subtopics

### [Ratio Tracking with Null Scattering](1044-ratio-tracking-with-null-scattering.md)
Uses ratio tracking to sample distances proportional to homogenized transmittance, distinguishing real and fake interactions to reduce variance compared to standard delta tracking.

### [Woodcock Tracking with Variable Majorants](1084-woodcock-tracking-with-variable-majorants.md)
Uses spatially varying majorants (e.g., via macrocells) to provide tighter bounds in different regions, reducing the number of null collisions compared to a single global majorant.

## Operating characteristics
*   **Time Complexity:** Depends on the number of null collisions. In dense regions, it approaches the cost of homogeneous sampling. In sparse regions, it degrades linearly with the ratio $\sigma_t^{\max} / \sigma_t(\mathbf{x})$ [S4].
*   **Memory Complexity:** Requires storage for the volume data and the majorant value. No additional subdivision structures are strictly required, though hierarchical majorants may add overhead [S2, S4].
*   **Measured Performance:** Rendering a cloud with delta tracking and Next Event Estimation (10 samples per pixel) took 248 seconds on the tested hardware [S2].
*   **Strengths:** Unbiased; handles arbitrary heterogeneous media without subdivision; simple implementation [S2, S4].
*   **Limitations:** High variance in sparse volumes; inefficient for large empty spaces; requires global majorant computation [S2, S4].
*   **When to Use:** Highly detailed heterogeneous volumes where ray marching bias is unacceptable and subdivision is too costly [S2].
*   **When Not to Use:** Volumes with significant empty space or large dynamic range in density without optimization (e.g., variable majorants) [S2, S4].

## Background
Delta tracking, also known as Woodcock tracking, was introduced as a Monte Carlo method to simulate photon movement in heterogeneous media by sampling free path lengths instead of directly sampling data [S4]. It relies on the concept of fictitious particles to homogenize the density to an upper bound (majorant extinction) [S4]. The method avoids the implicit bias of ray marching by providing an unbiased estimate that converges with many rays [S3, S4]. It is widely used in volumetric path tracing for participating media like clouds and smoke [S2, S3].
