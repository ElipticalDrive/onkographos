# Real-scattering vertex connection with ratio tracking

Also called: Delta Tracking for Transmittance Estimation, Real-scattering vertex connection

## Overview
Estimates the transmittance between two points $p_1$ and $p_2$ in a participating medium using ratio tracking, which accumulates a product of null-scattering ratios rather than terminating on collision [S1, unofficial]. Unlike delta tracking for sampling which terminates on collision, ratio tracking continues until the endpoint is reached, accumulating a product of ratios to estimate the total transmittance [S1, unofficial]. It serves as the transmittance estimation component within the real-scattering vertex connection framework, which uses delta-tracking for path sampling [S2, unofficial].

## How it works
**Inputs and Outputs:**
*   **Input:** Start point $p_1$, end point $p_2$, majorant density $\mu_t$ (or $\sigma_t$), absorption density $\mu_a$ (or $\sigma_a$), scattering density $\mu_s$ (or $\sigma_s$), sampler state [S1, unofficial].
*   **Output:** Estimated transmittance $T(p_1, p_2)$ as a vector (typically RGB) [S1, unofficial].

**Data Structures:**
*   `transmittance`: Vector of size 3 (RGB), initialized to $(1, 1, 1)$ [S1, unofficial].
*   `t`: Scalar float, current distance along the ray, initialized to $0$ [S1, unofficial].
*   `distToEnd`: Scalar float, length of the segment $\|p_2 - p_1\|$ [S1, unofficial].
*   `invMajorant`: Scalar or vector float, $1/\mu_t$ [S1, unofficial].

**Steps:**
1.  Calculate `distToEnd` = length($p_2 - p_1$) [S1, unofficial].
2.  Initialize `t` = $0$, `transmittance` = $(1, 1, 1)$ [S1, unofficial].
3.  Create a ray from $p_1$ to $p_2$ [S1, unofficial].
4.  Sample collision-free distance $s = -\log(\max(1.0 - \text{sampler.getNext1D()}, 0.0)) \times \text{invMajorant}$ [S1, unofficial].
5.  Update `t` += $s$ [S1, unofficial].
6.  If `t` > `distToEnd`, break the loop and return `transmittance` [S1, unofficial].
7.  Get local density at ray($t$). Compute $\sigma_n = \text{majorant} - \sigma_a - \sigma_s$ [S1, unofficial].
8.  Update `transmittance` *= $(\sigma_n \times \text{invMajorant})$ [S1, unofficial].
9.  Repeat from step 4 [S1, unofficial].

**Pseudocode:**
```python
import math

class Vec3:
    def __init__(self, x, y, z): self.x, self.y, self.z = x, y, z
    def __sub__(self, o): return Vec3(self.x-o.x, self.y-o.y, self.z-o.z)
    def __add__(self, o): return Vec3(self.x+o.x, self.y+o.y, self.z+o.z)
    def __mul__(self, o):
        if isinstance(o, (int, float)): return Vec3(self.x*o, self.y*o, self.z*o)
        return Vec3(self.x*o.x, self.y*o.y, self.z*o.z)
    def __rmul__(self, o): return self.__mul__(o)
    def __truediv__(self, o):
        if isinstance(o, (int, float)): return Vec3(self.x/o, self.y/o, self.z/o)
        return Vec3(self.x/o.x, self.y/o.y, self.z/o.z)
    def length(self): return math.sqrt(self.x**2 + self.y**2 + self.z**2)

def ratio_tracking_transmittance(p1, p2, majorant, sigma_a, sigma_s, sampler):
    """
    Estimates transmittance from p1 to p2 using ratio tracking.
    Args:
        p1, p2: Vec3 start and end points
        majorant: Vec3 or scalar homogenized extinction coefficient
        sigma_a, sigma_s: Functions returning Vec3 or scalar density at a point
        sampler: Object with getNext1D() returning float in [0, 1)
    Returns:
        transmittance: Vec3, estimated transmittance
    """
    dist_to_end = (p2 - p1).length()
    t = 0.0
    transmittance = Vec3(1.0, 1.0, 1.0)
    
    if isinstance(majorant, (int, float)):
        inv_majorant = 1.0 / majorant
    else:
        inv_majorant = Vec3(1.0/majorant.x, 1.0/majorant.y, 1.0/majorant.z)
        
    while True:
        u = sampler.getNext1D()
        s = -math.log(max(1.0 - u, 0.0)) * inv_majorant
        t += s
        
        if t > dist_to_end:
            break
            
        pos = p1 + (p2 - p1) * (t / dist_to_end)
        
        current_sigma_a = sigma_a(pos)
        current_sigma_s = sigma_s(pos)
        
        sigma_n = majorant - current_sigma_a - current_sigma_s
        transmittance = transmittance * (sigma_n * inv_majorant)
        
    return transmittance
```

**Parameters:**
*   `s`: Number of vertices on the camera subpath (real-scattering) [S2, unofficial].
*   `t`: Number of vertices on the light subpath (real-scattering) [S2, unofficial].
*   $e_x \in \{a, s, n\}$: Event type at vertex $x$ (absorption, scattering, or null-scattering) [S2, unofficial].
*(Note: `s`, `t`, and $e_x$ are parameters of the parent real-scattering vertex connection technique, not the transmittance estimator itself.)* [G]

**Edge Cases and Pitfalls:**
*   **Precision:** If `sampler.getNext1D()` returns exactly $1.0$, `log(0)` results in infinity. A guard such as `max(1.0 - sampler.getNext1D(), epsilon)` or `min(u, 1.0 - epsilon)` is required [G].
*   **Boundary Conditions:** The loop terminates when `t > distToEnd` [S1, unofficial].
*   **Degenerate Input:** If `majorant` is zero, division by zero occurs. The majorant must be strictly positive [G].

## Background
Originated in the context of null-scattering path integral formulations for light transport in participating media [S2, unofficial]. It addresses the need for unbiased transmittance estimation in complex media where analytical solutions are intractable [S1, unofficial].
