# Homogeneous Emission + Absorption (Importance Sampling)
Also called: Homogeneous Medium Sampling with Emission, Infinite/Finite Homogeneous Medium Estimator

## Overview
Estimates the radiance contribution from a participating medium that emits light and absorbs it, but does not scatter ($\sigma_s = 0$). It solves the line integral of the emission coefficient weighted by transmittance. It sets itself apart from [Free-path sampling](1844-free-path-sampling.md) by assuming no scattering events (single interaction only) and from [Constant Distance Sampling](12250-constant-distance-sampling.md) by using importance sampling with respect to the transmittance function to reduce variance in dense media.

## How it works
**Inputs:**
- Ray origin $\mathbf{x}$ and direction $\omega$.
- Total extinction coefficient $\sigma_t$ (here $\sigma_t = \sigma_a$ since $\sigma_s=0$).
- Emission coefficient function $\varepsilon(\mathbf{x}', \omega)$.
- For finite media: maximum distance $s_{\max}$ and background radiance $L_0$ (radiance from behind the medium).

**Outputs:**
- Estimated radiance $L$.

**Data Structures:**
- No complex structures required. A single scalar random number $\xi \in [0, 1]$.

**Steps:**
1. Generate a uniform random number $\xi \in [0, 1]$.
2. Sample the distance $s$ along the ray using the inverse cumulative distribution function (CDF) of the transmittance. The probability density function (PDF) is chosen to match the transmittance decay:
   $$ p(s) = \sigma_t e^{-\sigma_t s} $$
   The inverse transform yields:
   $$ s = -\frac{\ln \xi}{\sigma_t} $$
   Note: Since $1-\xi$ has the same distribution as $\xi$, $s = -\ln(1-\xi)/\sigma_t$ is equivalent.
3. Calculate the sample position $\mathbf{x}' = \mathbf{x} - s\omega$ (assuming $\omega$ points into the medium or defining $s$ as distance from $\mathbf{x}$ in the direction of propagation).
4. Evaluate the estimator. The integrand is $f(\mathbf{x}') = \tau(\mathbf{x}, \mathbf{x}') \varepsilon(\mathbf{x}')$. The estimator is $g(\mathbf{x}') = f(\mathbf{x}') / p(\mathbf{x}')$.
   $$ g(\mathbf{x}') = \frac{e^{-\sigma_t s} \varepsilon(\mathbf{x}')}{\sigma_t e^{-\sigma_t s}} = \frac{\varepsilon(\mathbf{x}')}{\sigma_t} $$
5. Handle boundaries:
   - If the medium is infinite, return $g(\mathbf{x}')$.
   - If the medium is finite with boundary $s_{\max}$:
     - If $s < s_{\max}$, return $g(\mathbf{x}')$.
     - If $s \ge s_{\max}$, return $L_0$. The probability of this event is $e^{-\sigma_t s_{\max}}$, which correctly weights the background radiance contribution [S1, unofficial].

**Pseudocode:**
```python
def homogeneous_emission_absorption_estimator(x, omega, sigma_t, epsilon_func, s_max=None, L_0=0.0):
    """
    Estimates radiance for a homogeneous medium with emission and absorption.
    
    Args:
        x: Ray origin (vec3).
        omega: Ray direction (vec3).
        sigma_t: Total extinction coefficient (scalar, sigma_a).
        epsilon_func: Function returning emission coefficient at a point (vec3 -> vec3).
        s_max: Optional maximum distance for finite medium.
        L_0: Background radiance for finite medium.
        
    Returns:
        Estimated radiance (vec3).
    """
    # 1. Generate random number
    xi = random_uniform()
    
    # 2. Sample distance using inverse CDF of transmittance
    # s = -ln(xi) / sigma_t
    if sigma_t == 0:
        # Degenerate case: no absorption. Uniform sampling or handle separately.
        # Not given in sources for this specific estimator, but typically 
        # implies infinite variance or requires uniform sampling over segment.
        # [G] Assuming uniform sampling over a default segment if sigma_t is 0.
        return epsilon_func(x) * 1.0 # Placeholder for degenerate case
        
    s = -math.log(xi) / sigma_t
    
    # 3. Determine sample position
    # Note: Direction convention. If omega points from x into the medium,
    # sample point is x + s * omega. The source uses x - s*omega implying
    # omega points towards the viewer or x is the far end. 
    # Standard path tracing: ray travels x -> x + s*omega.
    # Source code snippet: epsilon(x - s*omega). This implies the ray 
    # is defined from the eye looking out, or x is the far boundary.
    # We will follow the source's geometric convention: sample at x - s*omega.
    x_prime = x - s * omega
    
    # 4. Evaluate estimator
    epsilon_val = epsilon_func(x_prime)
    estimator_val = epsilon_val / sigma_t
    
    # 5. Handle finite boundary
    if s_max is not None:
        if s < s_max:
            return estimator_val
        else:
            # Sample fell outside the medium boundary
            return L_0
            
    return estimator_val
```

**Parameters:**
- $\sigma_t$: Must be $> 0$. If $\sigma_t = 0$, the method is undefined in this form [G].
- $\xi$: Uniform random in $(0, 1]$. If $\xi=0$, $s \to \infty$. In practice, clamp $\xi$ to $[\epsilon, 1]$.

**Edge Cases:**
- **$\sigma_t = 0$**: The PDF is undefined. The integral becomes $\int \varepsilon dx$. Uniform sampling is required [G].
- **$\xi = 0$**: Results in infinite distance. Clamp $\xi$ to a small positive value like $10^{-7}$ [G].
- **Finite Boundary**: The probability of sampling beyond $s_{\max}$ is $e^{-\sigma_t s_{\max}}$. Returning $L_0$ in this case is mathematically correct because the expected value of the background contribution is $L_0 \cdot e^{-\sigma_t s_{\max}}$ [S1, unofficial].

## Operating characteristics
- **Time Complexity**: $O(1)$ per sample. One log, one division, one function evaluation.
- **Memory Complexity**: $O(1)$.
- **Variance**: Significantly lower than uniform sampling in dense media. Uniform sampling variance grows with optical depth; this estimator's variance depends only on the variance of $\varepsilon(\mathbf{x}')$ [S1, unofficial].
- **Strengths**: Simple implementation, low variance for dense homogeneous media, elegant cancellation of transmittance terms.
- **Limitations**: Only applicable to homogeneous media with no scattering. Requires $\sigma_t > 0$.
- **When to use**: When rendering fog, smoke, or clouds that are homogeneous and emit light, where scattering is negligible or handled separately.

## Background
Originated in the context of volumetric path tracing and Monte Carlo integration for participating media. The specific importance sampling strategy for emission + absorption is detailed in Cornell CS6630 lecture notes on volumetric path tracing [S1, unofficial]. It is a standard technique in offline renderers for handling emissive volumes.
