# Homogeneous Emission Estimator
Also called: Uniform Emission Estimator, Homogeneous Medium Emission Sampling
## Overview
The Homogeneous Emission Estimator computes the radiance contribution from a participating medium that emits light but has no absorption or scattering ($\sigma_a = \sigma_s = 0$). It solves the line integral of the emission coefficient along a ray segment. It is distinguished from its parent, [Homogeneous Emission + Absorption (Importance Sampling)](23693-homogeneous-emission-absorption-importance-sampling.md), by assuming zero optical depth ($\tau=1$), which allows for a simplified uniform sampling estimator that achieves zero variance when the emission is spatially constant.
## How it works
### Inputs and outputs
- **Inputs**:
  - Ray segment endpoints $\mathbf{x}$ and $\mathbf{y}$.
  - Emission coefficient function $\epsilon(\mathbf{x}', \omega)$, which may be constant or spatially varying.
  - Direction $\omega$ (implicit in the ray).
- **Outputs**:
  - Estimated radiance $L(\mathbf{x}, \omega)$ contributed by the medium along the segment.

### Data structures
- No complex data structures are required. The method operates on scalar values (distance, emission intensity) and vector positions.

### Steps
1. Calculate the Euclidean distance of the ray segment: $d = \|\mathbf{x} - \mathbf{y}\|$.
2. Sample a point $\mathbf{x}'$ uniformly along the segment between $\mathbf{x}$ and $\mathbf{y}$. This is done by sampling a scalar $t \sim U[0, 1]$ and computing $\mathbf{x}' = \mathbf{x} + t(\mathbf{y} - \mathbf{x})$.
3. Evaluate the emission coefficient at the sampled point: $e = \epsilon(\mathbf{x}', \omega)$.
4. Compute the estimator value: $g = e \cdot d$.

### Formula
The radiance in a medium with emission only is given by the integral [S1, unofficial]:
$$ L(\mathbf{x}, \omega) = \int_{\mathbf{x}}^{\mathbf{y}} \epsilon(\mathbf{x}', \omega) \, d\mathbf{x}' $$
Using uniform sampling with respect to distance along the ray, the probability density function (pdf) is $p(\mathbf{x}') = \frac{1}{\|\mathbf{x} - \mathbf{y}\|}$. The Monte Carlo estimator is [S1, unofficial]:
$$ g = \frac{\epsilon(\mathbf{x}', \omega)}{p(\mathbf{x}')} = \epsilon(\mathbf{x}', \omega) \|\mathbf{x} - \mathbf{y}\| $$

### Parameters
- **Sampling strategy**: Uniform distance sampling.
- **Number of samples**: 1 sample provides an unbiased estimate. For spatially varying emission, multiple samples reduce variance.

### Edge cases and pitfalls
- **Homogeneous Emission**: If $\epsilon$ is constant, the estimator yields $g = \epsilon \|\mathbf{x} - \mathbf{y}\|$ with zero variance. This is because the pdf is proportional to the integrand, representing perfect importance sampling [S1, unofficial].
- **Dense Media**: This estimator is only applicable when $\sigma_a = 0$. If absorption is present, this estimator is inefficient compared to importance sampling techniques that account for the exponential decay term [S1, unofficial].
- **Boundary Conditions**: The ray segment must be fully contained within the medium or the emission function must be defined as zero outside the medium boundaries.

### Pseudocode
```python
def homogeneous_emission_estimator(x, y, epsilon_func):
    """
    Estimates radiance from a homogeneous medium with emission only.
    
    Args:
        x: Start point of the ray segment (vec3).
        y: End point of the ray segment (vec3).
        epsilon_func: Function returning emission coefficient at a point and direction.
                      Signature: epsilon_func(point, direction) -> float.
    
    Returns:
        Estimated radiance contribution.
    """
    # 1. Calculate segment length
    direction = y - x
    distance = length(direction)
    
    # Handle degenerate case where start and end are the same
    if distance == 0:
        return 0.0
    
    # 2. Sample a point uniformly along the segment
    # t is uniformly distributed in [0, 1]
    t = random_uniform_float()
    x_prime = x + direction * t
    
    # 3. Evaluate emission at the sampled point
    # Note: direction is normalized for the emission function if required by definition
    # However, epsilon is typically per unit distance, so direction magnitude is handled by the distance term
    epsilon = epsilon_func(x_prime, normalize(direction))
    
    # 4. Compute estimator: g = epsilon * distance
    # This is equivalent to epsilon / pdf, where pdf = 1/distance
    radiance = epsilon * distance
    
    return radiance
```
## Subtopics

### Homogeneous Absorption Estimator
This is not a Monte Carlo estimator but a direct analytical solution for a medium with absorption only ($\epsilon = \sigma_s = 0$). The radiance is computed directly as $L(\mathbf{x}, \omega) = \tau(\mathbf{x}, \mathbf{y}) L_e(\mathbf{y}, \omega)$, where $\tau(\mathbf{x}, \mathbf{y}) = \exp(-\sigma_a \|\mathbf{x} - \mathbf{y}\|)$ is the transmittance and $L_e(\mathbf{y}, \omega)$ is the background radiance at the end of the ray [S1, unofficial]. Since there is no integral, no sampling is required.

## Operating characteristics
- **Time Complexity**: $O(1)$ per sample.
- **Memory Complexity**: $O(1)$.
- **Performance**: Extremely fast for homogeneous emission. If emission is spatially varying, variance may be high with a single sample, requiring multiple samples for convergence.
- **Strengths**: Simple to implement; zero variance for constant emission.
- **Limitations**: Inefficient or incorrect if absorption is present; high variance for highly spatially varying emission with few samples.
- **When to use**: When $\sigma_a = \sigma_s = 0$ and emission is the only source of radiance.
- **When not to use**: When absorption or scattering is significant; use [Homogeneous Emission + Absorption (Importance Sampling)](23693-homogeneous-emission-absorption-importance-sampling.md) instead.
## Background
This estimator is derived from the general line integral solution for radiative transfer in participating media. It is discussed in the context of volumetric path tracing as a special case where the medium is purely emissive. The analysis of its zero-variance property for homogeneous emission highlights the concept of importance sampling in rendering [S1, unofficial].
