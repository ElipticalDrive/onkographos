# Multiple Importance Sampling without Selection (mismvpt)
Also called: MIS multi-view path tracing, Multi-view Path Tracing with Classical MIS, mismvpt

## Overview
Multiple Importance Sampling without Selection (mismvpt) is a multi-view rendering estimator that combines base paths and shifted paths (reused from other cameras) using standard MIS weights [S1]. It solves the problem of integrating light transport contributions across multiple viewpoints by reusing geometric prefixes, avoiding the bias and complexity of prefix selection mechanisms [S1]. Unlike its sibling [Multi-View Path Tracing with MWIS](1834-multi-view-path-tracing-with-mwis.md), which uses a self-normalized estimator to reweight samples toward a target pdf, mismvpt uses a standard unbiased MIS estimator, resulting in higher variance when the distribution of shifted prefixes does not follow ideal importance sampling [S1].

## How it works
**Inputs and Outputs:**
- Input: A set of $N$ cameras, each with a pixel grid. For each pixel $i$ in each camera, a base prefix $\bar{x}_i$ is sampled [S1].
- Output: Pixel intensities $I_j$ for all pixels $j$ in all cameras.

**Data Structures:**
- `Sr`: A scalar accumulator for the sum of ratios of ideal to shifted PDFs for a given base prefix.
- `I_j`: The accumulated intensity for pixel $j$.
- `w_i`: The MIS weight for a prefix.

**Parameters:**
- $c_i, c_j$: Normalization constants for the pixel areas or solid angles (implied by the PDF definitions) [S1].
- $S^0_{i \to j}$: The Jacobian determinant of the shift transformation from camera $i$'s pixel to camera $j$'s pixel [S1].

**Steps:**
1. For each pixel $i$ in all cameras:
    a. Sample the base prefix $\bar{x}_i$ [S1].
    b. Initialize the sum of ratios $S_r \leftarrow 0$ [S1].
    c. For each camera $k$ (including $i$ itself):
        i. Shift the base path $\bar{x}_i$ to camera $k$ through pixel $j$ to get the shifted prefix $\bar{x}_j$ [S1].
        ii. Evaluate the shifted PDF $p_{i \to j}(\bar{x}_j)$ using the formula:
        $$ p_{i \to j}(\bar{x}_j) = \frac{c_i \cdot p_i(\bar{x}_i)}{|S^0_{i \to j}|} $$
        where $p_i(\bar{x}_i)$ is the PDF of the base prefix at camera $i$ [S1].
        iii. Evaluate the ideal PDF $p_{j \to j}(\bar{x}_j)$ using the formula:
        $$ p_{j \to j}(\bar{x}_j) = c_j \cdot p_j(\bar{x}_j) $$
        where $p_j(\bar{x}_j)$ is the PDF of the prefix if it were sampled directly at camera $j$ [S1].
        iv. Accumulate the ratio into $S_r$:
        $$ S_r \leftarrow S_r + \frac{p_{j \to j}(\bar{x}_j)}{p_{i \to j}(\bar{x}_j)} $$
    d. Sample light sources to compute direct illumination and sample a path suffix to compute indirect illumination for the base prefix $\bar{x}_i$ [S1].
    e. For each prefix $\bar{x}_j$ associated with pixel $j$ (generated from all base prefixes $\bar{x}_i$ that could shift to $j$):
        i. Evaluate the MIS weight $w_i(\bar{x}_j)$ as:
        $$ w_i(\bar{x}_j) = \frac{1}{S_r} $$
        Note: $S_r$ is specific to the base prefix $\bar{x}_i$ that generated this shifted prefix [S1].
        ii. Accumulate the contribution to pixel intensity $I_j$:
        $$ I_j \leftarrow I_j + w_i(\bar{x}_j) \cdot \frac{f_j(\bar{x}_j)}{p_{i \to j}(\bar{x}_j)} $$
        where $f_j(\bar{x}_j)$ is the radiance contribution of the shifted path [S1].

**Pseudocode:**
```python
# Initialize all pixel intensities I_j to 0 [G]
for each pixel i in all_cameras:
    # 1. Sample base prefix
    x_bar_i = sample_base_prefix(i)
    
    # 2. Initialize sum of ratios
    Sr = 0.0
    shifted_data = []  # Store (pixel_j, shifted_prefix, shifted_pdf)
    
    # 3. Loop over all cameras to shift and evaluate PDFs
    for each camera k in all_cameras:
        j = get_pixel_index(k, x_bar_i)
        x_bar_j = shift_path(x_bar_i, k)
        
        # Evaluate shifted PDF: p_{i->j}(x̄_j) = c_i * p_i(x̄_i) / |S^0_{i->j}|
        p_shifted = (c_i * p_i(x_bar_i)) / abs(Jacobian_shift(i, k, x_bar_i))
        
        # Evaluate ideal PDF: p_{j->j}(x̄_j) = c_j * p_j(x̄_j)
        p_ideal = c_j * p_j(x_bar_j)
        
        # Accumulate ratio into Sr
        # Guard against division by zero [G]
        if p_shifted > 0:
            Sr += p_ideal / p_shifted
        shifted_data.append((j, x_bar_j, p_shifted))
        
    # 4. Sample light sources and path suffix for direct/indirect illumination
    # 5. Accumulate contributions to pixels using MIS weights
    for j, x_bar_j, p_shifted in shifted_data:
        # Evaluate full path contribution f_j(x̄_j) [G]
        f_j = evaluate_path_contribution(x_bar_j)
        
        # MIS weight w_i(x̄_j) = 1 / Sr
        w = 1.0 / Sr
        
        # Accumulate to pixel intensity I_j
        I[j] += w * (f_j / p_shifted)
```

**Edge Cases and Pitfalls:**
- The estimator is not progressive. A full pass over all pixels of all cameras is required to compute $S_r$ for each base prefix before contributions can be fully accumulated [S1].
- If $p_{i \to j}(\bar{x}_j)$ is zero or very small, numerical instability may occur [G].
- Reusing all prefixes disregarding scattering components can result in noisier estimates than the baseline (vpt) in anisotropic volumes [S1].

## Subtopics

### Full MIS in Bidirectional Path Tracing
A method for Bidirectional Path Tracing (BPT) that uses full path PDFs incorporating medium sampling to weight MIS combinations, improving quality over directional MIS which only uses directional real-scattering PDFs [S2, unofficial]. In a BPT scene, Full MIS achieved an RMSE of 0.049 and LTUV of 57.2M lookups, outperforming Directional MIS (RMSE: 0.043, LTUV: 44.9M) and Uni.+NEE MIS (RMSE: 0.731, LTUV: 12.7B) [S2, unofficial]. Full MIS prioritizes vertex connections through the dense medium (e.g., $s=1$), whereas directional MIS is oblivious to media presence and is dominated by camera-connection techniques ($t=1$) [S2, unofficial].

## Operating characteristics
- **Time Complexity:** Requires a full pass over all pixels of all cameras for each base prefix to compute $S_r$, making it non-progressive and potentially slower per sample than progressive methods [S1].
- **Memory Complexity:** Requires storing intermediate shifted prefixes and their contributions for accumulation [S1].
- **Variance:** Exhibits higher variance than MWIS because the mixture density resulting from standard MIS is not optimal when the distribution of shifted prefixes does not follow ideal importance sampling [S1].
- **Noise:** Can exhibit more noise than the baseline (vpt) in anisotropic volumes when reusing all prefixes disregarding scattering components [S1].
- **Strengths:** Unbiased [S1].
- **Limitations:** Non-progressive; higher variance in scenarios with high re-use between cameras where the shifted distribution is suboptimal [S1].

## Background
The method is described in "Volumetric Multi-View Rendering" [S1]. It is presented as a baseline comparison to the proposed MWIS estimator, highlighting the limitations of standard MIS in multi-view volumetric rendering [S1]. The concept of Full MIS in BPT is discussed in "A Null-Scattering Path Integral Formulation of Light Transport" [S2, unofficial], which provides context for the importance of full path PDFs in medium sampling.
