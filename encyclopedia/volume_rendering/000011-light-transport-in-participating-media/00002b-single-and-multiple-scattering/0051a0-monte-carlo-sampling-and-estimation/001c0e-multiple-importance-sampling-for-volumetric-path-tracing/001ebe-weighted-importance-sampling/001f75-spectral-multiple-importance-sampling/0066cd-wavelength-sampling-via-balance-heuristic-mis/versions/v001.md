# Wavelength Sampling via Balance Heuristic MIS

Also called: channel sampling for subsurface scattering

## Overview
This method selects a single wavelength channel (e.g., R, G, B) for volumetric path tracing steps proportional to the product of the ray's spectral throughput and the medium's single scattering albedo. It addresses the variance caused by spectrally varying medium properties, where a single sampling PDF based on one wavelength may be a poor match or invalid for others. It sets itself apart from [Spectral Multiple Importance Sampling](2014-spectral-multiple-importance-sampling.md) by reducing the problem to a discrete categorical selection of channels rather than continuous spectral integration, and from [Chromatic Null-Scattering Free-Flight Sampling](6634-chromatic-null-scattering-free-flight-sampling.md) by using a balance heuristic on the albedo/throughput product rather than null-scattering coefficients.

## How it works
**Inputs:**
- `albedo`: Single scattering albedo as a 3-component vector ($\alpha \in \mathbb{R}^3$), representing weights for the three wavelength channels.
- `throughput`: Ray throughput as a 3-component vector ($T \in \mathbb{R}^3$), representing the accumulated spectral weight of the path up to the current step.
- `rand`: A uniform random number in $[0, 1)$.

**Outputs:**
- `channel_index`: An integer in $\{0, 1, 2\}$ indicating the selected wavelength channel.
- `pdf`: A 3-component vector containing the probability density for each channel.

**Data Structures:**
- `weights`: A 3-component vector storing the unnormalized sampling probabilities.
- `sum_weights`: A scalar storing the sum of the weights.

**Steps:**
1. Calculate the unnormalized weights for each channel by taking the absolute value of the element-wise product of throughput and albedo:
   $$ w_i = |T_i \cdot \alpha_i| \quad \text{for } i \in \{x, y, z\} $$
2. Compute the sum of the weights:
   $$ S = \sum_{i \in \{x, y, z\}} w_i $$
3. Determine the PDF for each channel:
   - If $S > 0$:
     $$ p_i = \frac{w_i}{S} $$
   - If $S = 0$ (degenerate case where all weights are zero):
     $$ p_i = \frac{1}{3} \quad \text{for all } i $$
4. Select the channel index using cumulative distribution sampling with `rand`:
   - If $\text{rand} < p_x$, return $0$.
   - Else if $\text{rand} < p_x + p_y$, return $1$.
   - Else, return $2$.

**Pseudocode:**
```python
def sample_wavelength_channel(albedo: Vector3, throughput: Vector3, rand: float) -> Tuple[int, Vector3]:
    """
    Sample a wavelength channel proportional to throughput and single scattering albedo.
    
    Args:
        albedo: Single scattering albedo (float3).
        throughput: Ray throughput (float3).
        rand: Uniform random number in [0, 1).
        
    Returns:
        channel_index: Selected channel index (0, 1, or 2).
        pdf: Probability density for each channel.
    """
    # Calculate weights: absolute value of throughput * albedo
    weights = Vector3(
        abs(throughput.x * albedo.x),
        abs(throughput.y * albedo.y),
        abs(throughput.z * albedo.z)
    )
    
    # Sum the weights
    sum_weights = weights.x + weights.y + weights.z
    
    # Determine PDF
    if sum_weights > 0.0:
        pdf = Vector3(
            weights.x / sum_weights,
            weights.y / sum_weights,
            weights.z / sum_weights
        )
    else:
        # Fallback to uniform sampling if all weights are zero
        pdf = Vector3(1.0 / 3.0, 1.0 / 3.0, 1.0 / 3.0)
        
    # Select channel based on cumulative PDF
    if rand < pdf.x:
        return 0, pdf
    elif rand < pdf.x + pdf.y:
        return 1, pdf
    else:
        return 2, pdf
```

**Parameters:**
- `albedo`: Input single scattering albedo. Typical values depend on the material, ranging from 0 to 1 per channel.
- `throughput`: Input ray throughput. Values are typically between 0 and 1, decreasing with distance and absorption.
- `rand`: Uniform random number.

**Edge Cases and Pitfalls:**
- **Zero Throughput/Albedo:** If all components of `throughput * albedo` are zero, the sum of weights is zero. The method falls back to uniform sampling ($1/3$ per channel) to avoid division by zero [S1, unofficial].
- **Precision:** Using `fabs` ensures non-negative weights, handling potential negative values from numerical errors or specific throughput representations [S1, unofficial].
- **Discrete vs Continuous:** This method samples a discrete channel, not a continuous wavelength. It is intended for RGB path tracing where spectral variation is approximated by channel-wise weights.

## Operating characteristics
- **Time Complexity:** $O(1)$ per sample. The calculation involves a fixed number of arithmetic operations.
- **Memory Complexity:** $O(1)$. Only a few temporary vectors and scalars are required.
- **Performance:** Significantly reduces noise in volumetric path tracing, especially with many bounces, by prioritizing channels with higher throughput and albedo [S1, unofficial].
- **Strengths:** Simple to implement, computationally inexpensive, effective for reducing variance in RGB-based volumetric rendering.
- **Limitations:** Only applicable to discrete channel-based rendering (e.g., RGB). Does not handle continuous spectral rendering directly. The balance heuristic assumes that the importance of a channel is well-approximated by the product of throughput and albedo.
- **When to use:** Volumetric path tracing with RGB wavelengths where spectral variation is significant and noise reduction is desired.
- **When not to use:** Continuous spectral rendering, or when the medium properties do not vary significantly across channels.

## Background
The method is derived from the technique described in "Practical and Controllable Subsurface Scattering for Production Path Tracing" by Matt Jen-Yuan Chiang, Peter Kutz, and Brent Burley (SIGGRAPH 2016) [S1, unofficial]. It is implemented in production renderers such as Blender Cycles to handle subsurface scattering and volumetric effects efficiently. The approach uses a balance heuristic to sample color channels proportional to throughput and single scattering albedo, which helps in managing the variance introduced by spectrally varying medium properties.
