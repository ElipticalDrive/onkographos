# Wavelength Sampling via Balance Heuristic MIS

Also called: channel sampling for subsurface scattering

## Overview
This method samples a single color channel (wavelength) for volumetric path tracing steps proportional to the product of the ray's spectral throughput and the medium's single scattering albedo [S1, unofficial]. It addresses the variance caused by spectrally varying medium properties, where a single sampling PDF based on one wavelength may be a poor match or invalid for others [S1, unofficial]. It sets itself apart from [Spectral Multiple Importance Sampling](2014-spectral-multiple-importance-sampling.md) by reducing the problem to a discrete categorical selection of channels rather than continuous spectral integration, and from [Chromatic Null-Scattering Free-Flight Sampling](6634-chromatic-null-scattering-free-flight-sampling.md) by using a balance heuristic on the albedo/throughput product rather than null-scattering coefficients [G].

## How it works
**Inputs:**
- `albedo`: Single scattering albedo as a 3-component vector ($\alpha \in \mathbb{R}^3$) [S1, unofficial].
- `throughput`: Ray throughput as a 3-component vector ($T \in \mathbb{R}^3$) [S1, unofficial].
- `rand`: A uniform random number in $[0, 1)$ [S1, unofficial].

**Outputs:**
- `channel_index`: An integer in $\{0, 1, 2\}$ indicating the selected wavelength channel [S1, unofficial].
- `pdf`: A 3-component vector containing the probability density for each channel [S1, unofficial].

**Data Structures:**
- `weights`: A 3-component vector storing the unnormalized sampling probabilities [S1, unofficial].
- `sum_weights`: A scalar storing the sum of the weights [S1, unofficial].

**Steps:**
1. Calculate the unnormalized weights for each channel by taking the absolute value of the element-wise product of throughput and albedo:
   $$ w_i = |T_i \cdot \alpha_i| \quad \text{for } i \in \{x, y, z\} $$
2. Compute the sum of the weights:
   $$ S = \sum_{i \in \{x, y, z\}} w_i $$
3. Determine the PDF for each channel:
   - If $S > 0$:
     $$ p_i = \frac{w_i}{S} $$
   - If $S = 0$ (degenerate case where all weights are zero):
     $$ p_i = \frac{1}{3} \quad \text{for all } i $$
4. Select the channel index using cumulative distribution sampling with `rand`:
   - If $\text{rand} < p_x$, return $0$.
   - Else if $\text{rand} < p_x + p_y$, return $1$.
   - Else, return $2$.

**Pseudocode:**
```python
class Float3:
    def __init__(self, x: float, y: float, z: float):
        self.x = x
        self.y = y
        self.z = z

def sample_wavelength_channel(albedo: Float3, throughput: Float3, rand: float):
    # Calculate weights: absolute value of throughput * albedo
    weights = Float3(
        abs(throughput.x * albedo.x),
        abs(throughput.y * albedo.y),
        abs(throughput.z * albedo.z)
    )
    
    # Sum the weights
    sum_weights = weights.x + weights.y + weights.z
    
    # Determine PDF
    if sum_weights > 0.0:
        pdf = Float3(
            weights.x / sum_weights,
            weights.y / sum_weights,
            weights.z / sum_weights
        )
    else:
        # Fallback to uniform sampling if all weights are zero
        pdf = Float3(1.0 / 3.0, 1.0 / 3.0, 1.0 / 3.0)
        
    # Select channel based on cumulative PDF
    if rand < pdf.x:
        return 0, pdf
    elif rand < pdf.x + pdf.y:
        return 1, pdf
    else:
        return 2, pdf
```

**Parameters:**
- `albedo`: Input single scattering albedo. Typical values: Not given in the sources.
- `throughput`: Input ray throughput. Typical values: Not given in the sources.
- `rand`: Uniform random number. Typical values: Not given in the sources.

**Edge Cases and Pitfalls:**
- **Zero Throughput/Albedo:** If all components of `throughput * albedo` are zero, the sum of weights is zero. The method falls back to uniform sampling ($1/3$ per channel) to avoid division by zero [S1, unofficial].
- **Precision:** Using `fabs` ensures non-negative weights, handling potential negative values from numerical errors or specific throughput representations [S1, unofficial].
- **Discrete vs Continuous:** This method samples a discrete channel, not a continuous wavelength [G].

## Operating characteristics
- **Time Complexity:** $O(1)$ per sample [G].
- **Memory Complexity:** $O(1)$ auxiliary space [G].
- **Performance:** Significantly reduces noise during volumetric path tracing, especially with many bounces [S1, unofficial].
- **Strengths:** Simple to implement, computationally inexpensive [G].
- **Limitations:** Not given in the sources.
- **When to use:** Volumetric path tracing where spectral variation is significant and noise reduction is desired [S1, unofficial].
- **When not to use:** Not given in the sources.

## Background
The method is derived from the technique described in "Practical and Controllable Subsurface Scattering for Production Path Tracing" by Matt Jen-Yuan Chiang, Peter Kutz, and Brent Burley (SIGGRAPH 2016) [S1, unofficial]. It is implemented in production renderers such as Blender Cycles to handle subsurface scattering and volumetric effects efficiently [S1, unofficial]. The approach uses a balance heuristic to sample color channels proportional to throughput and single scattering albedo, which helps in managing the variance introduced by spectrally varying medium properties [S1, unofficial].
