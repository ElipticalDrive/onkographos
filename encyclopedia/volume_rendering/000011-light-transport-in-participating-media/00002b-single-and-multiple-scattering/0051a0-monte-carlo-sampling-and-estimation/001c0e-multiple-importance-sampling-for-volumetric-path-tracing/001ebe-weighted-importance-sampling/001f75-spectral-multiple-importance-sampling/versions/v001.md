# Spectral Multiple Importance Sampling

Also called: Chromatic Media Sampling with MIS, Single-sample MIS for Spectra, Spectral Multiple Importance Sampling (MIS) for Wavelengths, Spectral Volume Sampling

## Overview
Spectral Multiple Importance Sampling (MIS) is a technique to sample wavelengths based on the product of throughput and single scattering albedo, using an empirical discrete distribution to balance contributions across RGB channels [S1, unofficial]. It solves the problem where spectrally varying medium properties cause high variance when a single sampling PDF (based on one wavelength) is used to evaluate a function at multiple wavelengths, as the PDF may be a poor match or invalid (zero-valued) for other wavelengths [S2]. It sets itself apart from standard delta tracking by explicitly weighting spectral samples to handle the mismatch between the sampling distribution (often derived from a majorant at a single wavelength) and the evaluation at other wavelengths [S2].

## How it works
**Inputs:**
*   Throughput vector $\beta$ (typically 3-channel RGB).
*   Single scattering albedo vector $\omega$ (typically 3-channel RGB).
*   Number of spectral samples $n$ (typically 3 for RGB).
*   Random number generator state.

**Outputs:**
*   Sampled channel index $k \in \{0, 1, \dots, n-1\}$.
*   MIS weights $w_{\lambda_i}$ for each wavelength $\lambda_i$.

**Data Structures:**
*   `DiscreteEmpiricalDistribution1D`: A discrete probability distribution constructed from a vector of non-negative weights. It stores the cumulative distribution function (CDF) or normalized weights to allow efficient sampling.

**Steps:**
1.  Compute the spectral weight vector $w$ where each component is the product of the throughput and the single scattering albedo for that channel:
    $$ w_i = \beta_i \cdot \omega_i \quad \text{for } i = 0, \dots, n-1 $$
2.  Construct a `DiscreteEmpiricalDistribution1D` from the vector $w$. This normalizes $w$ to form a probability mass function (PMF) $p_{\lambda_i}$ such that $\sum_{i=0}^{n-1} p_{\lambda_i} = 1$ [S1, unofficial].
3.  Sample a channel index $k$ from this distribution using the random number generator [S1, unofficial].
4.  Calculate the MIS weight for the sampled wavelength $\lambda_k$ and all other wavelengths $\lambda_i$ using the balance heuristic. The balance heuristic is optimal for single-sample MIS [S2].

**Formulas:**
The probability of sampling wavelength $\lambda_i$ is $p_{\lambda_i}$, derived from the normalized throughput-albedo product [S1, unofficial].
The discrete probability of sampling using a specific wavelength $\lambda_1$ (or any specific $\lambda_k$) in the context of the estimator's denominator is $q$, which is uniform at $1/n$ where $n$ is the number of spectral samples [S2].

The MIS weight for wavelength $\lambda_i$ given that $\lambda_k$ was sampled is:
$$ w_{\lambda_i}(x) = \frac{p_{\lambda_i}(x)}{\sum_{j=0}^{n-1} p_{\lambda_j}(x)} $$
Note: Since $p$ is already normalized, the denominator is 1. However, in the context of the single-sample MIS estimator described in [S2], the weight is applied to correct for the fact that the sample was drawn from a distribution $p$ but the estimator considers the uniform probability $q$ of having drawn any specific wavelength. The text in [S2] presents the balance heuristic weight as:
$$ w_{\lambda_1}(x) = \frac{p_{\lambda_1}(x)}{\sum_{i=1}^{n} p_{\lambda_i}(x)} $$
And the full estimator term involves dividing by $q = 1/n$.

**Pseudocode:**
```python
def spectral_mis_sample(throughput, albedo, rng):
    """
    Samples a wavelength channel based on throughput * albedo using Spectral MIS.
    
    Args:
        throughput: List[float] of length n (e.g., 3 for RGB)
        albedo: List[float] of length n (e.g., 3 for RGB)
        rng: Random number generator with method getNext1D() returning float in [0, 1)
        
    Returns:
        sampled_index: int, the index of the sampled channel
        weights: List[float], the MIS weights for each channel
    """
    n = len(throughput)
    
    # Step 1: Compute throughput_albedo
    # Guard against negative values due to precision errors
    weights = []
    for i in range(n):
        w = max(0.0, throughput[i] * albedo[i])
        weights.append(w)
        
    # Step 2: Normalize to form PMF p_lambda
    total = sum(weights)
    if total == 0:
        # Degenerate case: all weights are zero.
        # Return uniform sampling and weights [G]
        sampled_index = int(rng.getNext1D() * n)
        weights_uniform = [1.0 / n] * n
        return sampled_index, weights_uniform
        
    pmf = [w / total for w in weights]
    
    # Step 3: Sample channel index using DiscreteEmpiricalDistribution1D logic
    # This is equivalent to sampling from the CDF of pmf
    u = rng.getNext1D()
    cumulative = 0.0
    sampled_index = n - 1  # Default to last index
    for i in range(n):
        cumulative += pmf[i]
        if u < cumulative:
            sampled_index = i
            break
            
    # Step 4: Calculate MIS weights
    # The balance heuristic weight w_lambda_i(x) = p_lambda_i(x) / sum(p_lambda_j(x))
    # Since pmf is normalized, sum(p) = 1. Thus w_lambda_i = pmf[i].
    # However, the estimator uses these weights to scale the contribution.
    # The sources define the weight as the balance heuristic itself.
    mis_weights = pmf[:]
    
    return sampled_index, mis_weights
```

**Parameters:**
*   $n$: Number of spectral samples. Typical value is 3 for RGB rendering [S2].
*   $q$: Discrete probability of sampling a specific wavelength. Value is $1/n$ [S2].

**Edge Cases and Pitfalls:**
*   **Zero Throughput/Albedo:** If all components of the throughput-albedo product are zero, the distribution is undefined. A uniform distribution should be used as a fallback [G].
*   **Precision:** Floating-point round-off errors can result in negative weights or sums slightly outside [0,1]. Values should be clamped to zero where necessary [S2].
*   **Spectral Mismatch:** If the medium properties vary drastically between channels, a single sample may have very low probability for other channels, leading to high variance if not properly weighted by MIS [S2].

## Operating characteristics
*   **Time Complexity:** $O(n)$ to compute weights and sample, where $n$ is the number of spectral samples (typically 3). This is negligible compared to the cost of ray marching or delta tracking.
*   **Memory Complexity:** $O(n)$ to store the PMF and weights.
*   **Strengths:** Reduces variance in spectrally varying media by ensuring that wavelengths with higher absorption/scattering potential are sampled more frequently, while still allowing unbiased evaluation at all wavelengths via MIS weighting [S1, unofficial][S2].
*   **Limitations:** Requires computing the throughput-albedo product for all spectral channels before sampling. It does not solve variance issues arising from the spatial variation of the medium, only the spectral mismatch [S2].
*   **When to use:** When rendering participating media with spectrally varying properties (e.g., colored smoke, milk, skin) and using a path tracer that evaluates spectral contributions [S1, unofficial][S2].
*   **When not to use:** For monochromatic rendering or when medium properties are spectrally constant (gray media), standard single-wavelength sampling is sufficient and simpler [S2].

## Background
The technique is described in the context of volume scattering integrators in the Physically Based Rendering (pbr-book) [S2]. It addresses the limitations of delta tracking, which samples based on a majorant derived from a single wavelength, causing poor sampling efficiency for other wavelengths. The method leverages the balance heuristic from Multiple Importance Sampling to optimally combine the spectral samples [S2]. An implementation is also found in the unofficial volumetric path tracer `volpt` [S1, unofficial].
