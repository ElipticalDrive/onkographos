# Spectral MIS with Unidirectional Path Tracing

Also called: Spectral MIS, Unidirectional Spectral MIS

## Overview
Spectral MIS with Unidirectional Path Tracing is a volumetric path tracing method that reduces computational time by sampling a single random color channel (e.g., RGB) of the scatter coefficient at each step instead of using the majorant of the entire spectrum [S1, S2, unofficial]. This approach combines unidirectional path sampling and light path sampling using Multiple Importance Sampling (MIS) to estimate direct illumination in participating media [S1, unofficial]. Unlike spectral tracking or delta tracking which use the majorant of the spectrum, this method uses a random channel, resulting in larger sampled distances when the selected channel value is small, leading to fewer steps inside the volume and faster convergence [S1, unofficial].

## How it works
The method estimates the radiance contribution for each color component $c \in \{c_1, \dots, c_N\}$ (typically $N=3$ for RGB) by maintaining per-component path contributions and probability density functions (PDFs) [S2, unofficial]. It avoids computing a conservative majorant for all channels simultaneously by selecting one channel $\tilde{c}$ per interaction and weighting the results via MIS [S2, unofficial].

### Inputs and Outputs
*   **Inputs**:
    *   Current position $x$ and direction $\omega$ [S2, unofficial].
    *   Spectral extinction $\mu_t(x)$, scatter $\mu_s(x)$, absorption $\mu_a(x)$, and null $\mu_n(x)$ coefficients for each color component [S1, unofficial].
    *   Maximum density of the volume `max_density` [S1, unofficial].
    *   Inverse maximum density `imax_density` [S1, unofficial].
    *   Emission coefficient $L_e(x, \omega)$ [S2, unofficial].
    *   Phase function $\rho_m(\omega)$ [S2, unofficial].
*   **Outputs**:
    *   Estimated radiance contribution for the path segment [S2, unofficial].

### Data Structures
*   **Path Contribution Vector $f$**: A vector of size $N$ storing the accumulated transmittance and event weights for each color component. Initialized to $\langle 1, \dots, 1 \rangle_N$ [S2, unofficial].
*   **Path PDF Vector $p$**: A vector of size $N$ storing the accumulated PDFs for each color component. Initialized to $\langle 1, \dots, 1 \rangle_N$ [S2, unofficial].
*   **Selected Channel $\tilde{c}$**: An index or identifier for the randomly chosen color component for the current step [S2, unofficial].

### Parameters
*   `max_density`: The maximum density value in the volume, computed as `density_vol->max_voxel * object->density_mult` [S1, unofficial].
*   `imax_density`: The inverse of the maximum density, computed as `1.0f / max_density` [S1, unofficial].
*   $N$: Number of color components (typically 3) [S2, unofficial].

### Algorithm Steps
1.  **Initialize**: Set path contributions $f \leftarrow \langle 1, \dots, 1 \rangle_N$ and path PDFs $p \leftarrow \langle 1, \dots, 1 \rangle_N$ [S2, unofficial].
2.  **Select Channel**: Select a random color component $\tilde{c}$ from $\{c_1, \dots, c_N\}$ [S2, unofficial].
3.  **Sample Distance**: Sample the medium interaction distance $t$ using the extinction coefficient of the selected component $\tilde{c}$:
    $$ t = -\frac{\ln(1-\xi)}{\mu_t^{\tilde{c}}(x)} $$
    where $\xi \in [0, 1)$ is a uniform random number [S2, unofficial].
4.  **Check Boundary**: If $t$ is greater than the maximum distance to the volume edge, exit the loop [S1, unofficial].
5.  **Update Position**: Move to the new position $x \leftarrow x + t\omega$ [S2, unofficial].
6.  **Sample Event**: Sample the event type $e \in \{a, s, n\}$ (absorption, scattering, null) using `SampleEvent` with probabilities normalized by the max density. The probabilities are computed using the sampled channel of $\mu_a, \mu_s, \mu_n$ [S1, unofficial]. Specifically, the probability of event $e$ is proportional to $\mu_e^{\tilde{c}}(x)$ [S2, unofficial].
7.  **Update Contributions**: Update path contributions $f$ component-wise with transmittance and event coefficient:
    $$ f \leftarrow f \circ \langle T(t)\mu_e^{c_1}(x), \dots, T(t)\mu_e^{c_N}(x) \rangle $$
    where $T(t)$ is the transmittance over distance $t$ [S2, unofficial].
8.  **Update PDFs**: Update path PDFs $p$ by multiplying with the ratio of the true PDF to the sampled PDF for each component [S2, unofficial]. For component $c_i$, this ratio is $\frac{\mu_t^{c_i}(x)}{\mu_t^{\tilde{c}}(x)}T(t)$ [S2, unofficial].
9.  **Handle Event**:
    *   If $e = a$ (absorption): Update $f$ with emission $L_e(x, -\omega)$ and return the average of $f$ across all $N$ components using the balance heuristic [S2, unofficial].
    *   If $e = s$ (scattering): Sample incoming direction $\omega'$ from the phase function $\rho_m(\omega)$ and continue the path walk [S2, unofficial].
    *   If $e = n$ (null): Continue the path walk [S2, unofficial].
10. **Return**: Return the average of the path contributions $f$ across all $N$ components using the balance heuristic [S2, unofficial].

### Pseudocode
```python
def spectral_mis_unidirectional(x, omega, max_density, imax_density, N, mu_t, mu_a, mu_s, mu_n, L_e, rho_m, max_distance_to_edge):
    # Initialize per-component path contributions and PDFs
    f = [1.0] * N
    p = [1.0] * N
    
    # Select a random color component index
    c_tilde = random.randint(0, N - 1)
    
    while True:
        # Sample medium interaction distance using the selected channel's extinction
        xi = random.random()
        t = -math.log(1 - xi) / mu_t[c_tilde](x)
        
        # Check if distance exceeds volume boundary
        if t > max_distance_to_edge(x, omega):
            break
            
        # Update position
        x = x + t * omega
        
        # Sample event type (absorption, scattering, null)
        # Probabilities proportional to the sampled channel's coefficients
        probs = [mu_a[c_tilde](x), mu_s[c_tilde](x), mu_n[c_tilde](x)]
        e = sample_event(probs)
        
        # Compute transmittance over distance t
        T_t = math.exp(-mu_t[c_tilde](x) * t)
        
        # Update path contributions component-wise
        for i in range(N):
            coeff = mu_a[i](x) if e == EVENT_ABSORB else (mu_s[i](x) if e == EVENT_SCATTER else mu_n[i](x))
            f[i] *= T_t * coeff
            
        # Update path PDFs by ratio of true PDF to sampled PDF
        for i in range(N):
            p[i] *= (mu_t[i](x) / mu_t[c_tilde](x)) * T_t
        
        # Handle event
        if e == EVENT_ABSORB:
            # Add emission contribution
            for i in range(N):
                f[i] *= L_e(x, -omega)
            # Return average using balance heuristic
            return sum(f) / N
        elif e == EVENT_SCATTER:
            # Sample phase function
            omega = sample_phase_function(rho_m, omega)
            # Continue path walk
            continue
        elif e == EVENT_NULL:
            # Continue path walk
            continue
            
    # If loop exits without absorption/scattering, return accumulated contribution
    return sum(f) / N
```

### Edge Cases and Pitfalls
*   **Convergence/Accuracy**: The method has problems with convergence or accuracy in certain scenarios, leading the authors to decide to use the mean of the spectrum values instead of the random channel selection, although the random channel method remains faster than precedent algorithms [S1, unofficial].
*   **Precision**: The use of a random channel can lead to higher variance if the selected channel has a very low coefficient, resulting in large steps and potentially missing important interactions [S1, unofficial].
*   **Boundaries**: The method must correctly handle volume boundaries to avoid sampling distances that exceed the volume extent [S1, unofficial].

## Operating characteristics
*   **Time Complexity**: The method reduces computational time compared to spectral tracking and delta tracking by sampling a single random channel, leading to larger sampled distances and fewer steps inside the volume [S1, unofficial].
*   **Memory Complexity**: Requires storing per-component path contributions and PDFs, which is $O(N)$ where $N$ is the number of color components [S2, unofficial].
*   **Measured Performance**:
    *   In a 1D medium experiment, Spectral MIS achieved a reduction of color noise comparable to spectral tracking but at a lower cost (fewer medium lookups) [S2, unofficial].
    *   In the left plume of Fig. 9 (high density, low albedo green channel), Spectral MIS achieved RMSE: 0.047 and LTUV: 4.12M lookups, outperforming Spectral tracking (RMSE: 0.055, LTUV: 5.82M) and Independent tracking (RMSE: 0.077, LTUV: 11.5M) [S2, unofficial].
    *   In the right plume of Fig. 9 (similar spectral variation), Spectral MIS achieved RMSE: 0.029 and LTUV: 1.09M lookups, outperforming Spectral tracking (RMSE: 0.035, LTUV: 1.51M) [S2, unofficial].
    *   In the malachite material (Fig. 10), Spectral MIS achieved RMSE: 0.032 and LTUV: 0.56M lookups, outperforming Spectral tracking (RMSE: 0.042, LTUV: 2.85M) [S2, unofficial].
*   **Strengths**: Faster convergence than spectral tracking and delta tracking in heterogeneous volumes with spectrally varying coefficients [S1, unofficial].
*   **Limitations**: Potential convergence issues in certain scenarios, requiring the use of mean spectrum values for stability [S1, unofficial].

## Background
*   **Origin**: The method was proposed by Miller et al. [S1, unofficial].
*   **History**: It is an improvement over spectral tracking and delta tracking, which use the majorant of the spectrum [S1, unofficial].
*   **Usage**: Used in volumetric path tracing for rendering participating media with spectrally varying coefficients [S1, unofficial].
