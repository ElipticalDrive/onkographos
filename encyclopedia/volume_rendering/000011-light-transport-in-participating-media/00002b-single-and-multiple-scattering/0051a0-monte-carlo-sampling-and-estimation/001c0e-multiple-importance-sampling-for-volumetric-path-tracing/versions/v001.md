# Multiple Importance Sampling for Volumetric Path Tracing

Also called: Direct Lighting Estimation with MIS, Light sampling with Multiple Importance Sampling, MIS weight calculation, Power heuristic for volume rendering, SampleLd, Volume Path Tracing Direct Lighting Estimation with MIS

## Overview
Multiple Importance Sampling (MIS) for volumetric path tracing reduces variance in direct lighting estimation by combining contributions from phase function sampling (unidirectional path tracing) and light source sampling (next event estimation) [S1, S2]. It solves the problem of high variance when sampling strategies are mismatched, particularly in heterogeneous media or when paths skip index-matching surfaces, by weighting each estimator using the power heuristic [S1, S2]. Unlike standard path tracing which may rely on a single sampling strategy, this method dynamically balances the probability densities of finding a light source via scattering versus sampling it directly, ensuring consistent convergence even when one strategy is significantly more efficient than the other [S1, S2].

## How it works
The method estimates the direct lighting contribution at a scattering vertex (surface or volume) by combining two primary sampling strategies: unidirectional sampling (following the phase function) and light sampling (connecting directly to a light source) [S2].

### Inputs and Outputs
**Inputs:**
- `beta`: Path throughput factor, representing the product of BSDF/phase function evaluations and transmittance from the camera to the current vertex [S2].
- `r_p`: Rescaled path probability for unidirectional sampling of the path up to the current vertex [S2].
- `intr`: Interaction point (surface or medium) where direct lighting is estimated [S2].
- `scene`: Scene data containing lights and geometry [S1, S2].
- `sampler`: Random number generator state [S2].
- `depth`: Current path depth [S2].
- `specularBounce`: Boolean indicating if the previous bounce was a delta distribution (specular) [S2].
- `prevIntrContext`: Context for previous interaction, used for light sampling PDFs [S2].

**Outputs:**
- `SampledSpectrum`: The estimated radiance contribution from direct lighting at the vertex [S2].

### Data Structures and Caching
To handle paths that skip index-matching surfaces, quantities required for MIS must be cached during the main path traversal loop [S1]:
- `dir_pdf`: The PDF of the latest phase function sampling in solid angle measure [S1].
- `nee_p_cache`: The position $p$ of the last vertex that can issue Next Event Estimation (NEE). If the current vertex is on an index-matching surface, this is `None` [S1].
- `multi_trans_pdf`: The product PDF of transmittance sampling through index-matching surfaces from the last phase function sampling [S1].

### Algorithm Steps

1. **Initialize Light Sampling:**
   Sample a light source using `lightSampler.Sample(ctx, u)`. If no valid sample is returned, return 0 [S2].
   Sample a point on the light source using `light.SampleLi(ctx, uLight, lambda, true)`. The `true` flag enables incomplete PDFs for MIS [S2].
   If the sample is invalid, has zero radiance, or zero PDF, return 0 [S2].

2. **Compute Light Sampling PDF:**
   Calculate the light PDF as the product of the light selection probability and the point sampling PDF:
   $$ lightPDF = sampledLight.p \times ls.pdf $$
   where $sampledLight.p$ is the probability of selecting the light, and $ls.pdf$ is the PDF of the sampled point on the light [S2].

3. **Evaluate Scattering Function:**
   Evaluate the BSDF or phase function $\hat{f}$ and its corresponding PDF $scatterPDF$ for the direction to the light source [S2].
   - For surfaces: $\hat{f}$ includes the cosine factor ($\hat{f} = f(\omega_o, \omega_i) |\cos \theta_i|$) [S2].
   - For volumes: $\hat{f}$ is the phase function value $p(\omega_o, \omega_i)$ [S2].
   - Note: $\hat{f}$ does **not** include the scattering coefficient $\sigma_s$ for volumes, as this is already accounted for in `beta` [S2].
   If $\hat{f}$ is zero, return 0 [S2].

4. **Compute Unidirectional Sampling PDF (if applicable):**
   If the path has not just started and the previous bounce was not a delta distribution, compute the PDF for the unidirectional strategy [S2].
   - For surface intersections: Use the BSDF PDF [S2].
   - For volume intersections: Use the phase function PDF [S2].
   - If the previous bounce was a delta distribution, the unidirectional strategy is invalid; set $scatterPDF = 0$ [S2].

5. **Handle Infinite Lights and Emissive Surfaces:**
   If the ray escapes the scene or hits an emissive surface:
   - Get emitted radiance $L_e$ [S2].
   - If `depth == 0` or `specularBounce`, accumulate using only unidirectional weight:
     $$ L += \beta \cdot L_e / r_u.Average() $$
   - Otherwise, compute $lightPDF$ using `lightSampler.PMF` and `light.PDF_Li` [S2].
   - Update $r_l$ and accumulate using MIS:
     $$ L += \beta \cdot L_e / (r_u + r_l).Average() $$
   [S2]

6. **Compute MIS Weights for Direct Lighting:**
   Update the rescaled path probabilities [S2]:
   $$ r_l = r_l \times r_p \times lightPDF $$
   $$ r_u = r_u \times r_p \times scatterPDF $$
   [S2]

7. **Return Estimate:**
   - If the light is a delta distribution (e.g., point light), only light sampling is valid. Return:
     $$ \text{Estimate} = \frac{\beta \cdot \hat{f} \cdot T_{ray} \cdot L_s}{r_l.Average()} $$
     [S2]
   - If the light is non-delta (e.g., area light), use both strategies. Return:
     $$ \text{Estimate} = \frac{\beta \cdot \hat{f} \cdot T_{ray} \cdot L_s}{(r_l + r_u).Average()} $$
     [S2]
   where $T_{ray}$ is the transmittance along the shadow ray, and $L_s$ is the light radiance [S2].

### Pseudocode

```python
def sample_ld(beta, r_p, intr, scene, sampler, depth, specular_bounce, prev_intr_context):
    """
    Estimates direct lighting at a scattering vertex using MIS.
    
    Args:
        beta: Path throughput.
        r_p: Rescaled unidirectional path probability.
        intr: Interaction (SurfaceInteraction or MediumInteraction).
        scene: Scene object.
        sampler: Sampler object.
        depth: Current path depth.
        specular_bounce: True if previous bounce was delta.
        prev_intr_context: Context for previous interaction.
        
    Returns:
        SampledSpectrum: Direct lighting estimate.
    """
    # 1. Sample Light Source
    u = sampler.get_1d()
    sampled_light = scene.light_sampler.sample(intr.get_light_sample_context(), u)
    if not sampled_light:
        return SampledSpectrum(0.0)
    
    light = sampled_light.light
    u_light = sampler.get_2d()
    ls = light.sample_li(intr.get_light_sample_context(), u_light, lambda=0, allow_incomplete_pdf=True)
    
    if not ls or ls.L == 0 or ls.pdf == 0:
        return SampledSpectrum(0.0)
        
    # 2. Compute Light PDF
    light_pdf = sampled_light.p * ls.pdf
    
    # 3. Evaluate Scattering Function
    wo = intr.wo
    wi = ls.wi
    
    if intr.is_surface():
        bsdf = intr.as_surface().bsdf
        f_hat = bsdf.f(wo, wi) * abs(dot(wi, intr.as_surface().shading_normal))
        scatter_pdf = bsdf.pdf(wo, wi)
    else:
        phase = intr.as_medium().phase
        f_hat = phase.p(wo, wi)
        scatter_pdf = phase.pdf(wo, wi)
        
    if f_hat == 0:
        return SampledSpectrum(0.0)
        
    # 4. Handle Delta Bounces
    # If previous bounce was delta, unidirectional sampling is invalid
    if specular_bounce:
        scatter_pdf = 0.0
        
    # 5. Compute Rescaled Probabilities
    # r_l and r_u are updated by multiplying with r_p and respective PDFs
    r_l = r_p * light_pdf
    r_u = r_p * scatter_pdf
    
    # 6. Determine Transmittance and Return Estimate
    # T_ray is transmittance from vertex to light
    T_ray = scene.transmittance(intr.p, ls.p_light)
    
    # If delta light, only light sampling is valid
    if light.is_delta():
        # Use only r_l for weight
        # Note: r_l.Average() handles per-wavelength averaging if spectral
        weight = 1.0 / r_l.average()
        return beta * f_hat * T_ray * ls.L * weight
    else:
        # Use both r_l and r_u
        weight = 1.0 / (r_l + r_u).average()
        return beta * f_hat * T_ray * ls.L * weight
```

### Parameters and Edge Cases
- **Delta Lights:** If the light is a delta distribution, the unidirectional strategy cannot intersect it. MIS weights are based solely on the light sampling PDF (or unidirectional PDFs if rescaling is needed for chromatic variance reduction) [S2].
- **Specular Bounces:** If the previous scattering event was a delta distribution, light sampling is not a useful strategy for the current vertex. The MIS weight relies only on the unidirectional PDFs [S2].
- **Index-Matching Surfaces:** PDFs required for MIS may be several bounces old. The `dir_pdf`, `nee_p_cache`, and `multi_trans_pdf` must be cached and updated during the main loop to ensure correct weight calculation [S1].
- **$\hat{f}$ Definition:** For surfaces, $\hat{f}$ includes the cosine term. For volumes, it does not include $\sigma_s$ [S2].

## Subtopics

### [Extended Multiple Importance Sampling](1569-extended-multiple-importance-sampling.md)
Extended Multiple Importance Sampling (Extended MIS) is a framework for combining estimators of integrals defined on spaces of different dimensions, such as standard path sampling and extended-space density estimators (e.g., photon mapping or beam tracing). It solves the problem of variance reduction in volumetric path tracing when mixing unbiased path contributions with biased density estimates that operate on higher-dimensional spaces. Unlike standard MIS, which requires all strategies to sample from the same domain, Extended MIS derives a balance heuristic that accounts for the additional integration over the kernel support inherent in extended-space techniques.

### [Multi-View Path Tracing with MWIS](1834-multi-view-path-tracing-with-mwis.md)
Multi-View Path Tracing with MWIS (MVPT) accelerates the rendering of heterogeneous participating media by exploiting redundancy across multiple camera views, such as in animated sequences or light fields. It jointly renders a sequence by reusing computation during simulation, specifically by transforming light paths from a base view to other views and generating a shared path suffix. Unlike standard multi-view methods that use unbiased Multiple Importance Sampling (MIS) or discard shifted paths based on strict selection criteria, MVPT uses a self-normalized Multiple Weighted Importance Sampling (MWIS) estimator. This approach reweights samples to match a target probability density function (PDF), reducing variance caused by non-contributing strategies and large Jacobian variations, while remaining consistent with a rapidly vanishing bias.

### [Weighted Importance Sampling](1849-weighted-importance-sampling.md)
Weighted Importance Sampling (WIS) is a biased but consistent technique used to simulate the use of a known target probability density function (PDF) $p$ with samples drawn from an arbitrary source PDF $q$. It solves the problem where the ideal PDF for an integrand (the target) is unknown or difficult to sample from directly, but a suboptimal source PDF is available. It sets itself apart from standard Importance Sampling by using self-normalizing weights that prevent poor samples (low $q$ but high $p$) from inflating variance, thereby escaping Veach's theoretical bounds for optimal weights when $p$ is well-chosen.

### [Direct Lighting with MIS in VolPathIntegrator](1877-direct-lighting-with-mis-in-volpathintegrator.md)
Direct Lighting with MIS in VolPathIntegrator is a method to sample direct illumination in volumetric media by combining unidirectional path sampling and light path sampling using Multiple Importance Sampling (MIS). It solves the high variance problem in spectral volumetric path tracing by allowing the estimator to choose between sampling the phase function to find the next vertex or sampling the light source to connect directly, weighting the contributions via the power heuristic. Unlike standard spectral MIS which may suffer from high variance in heterogeneous media, this method specifically handles the transmittance estimation via ratio tracking for the light connection segment, reducing Mean Squared Error (MSE) significantly compared to non-MIS approaches.

### Power Heuristic for Light Sampling
A heuristic used to balance the contribution of different sampling strategies (e.g., light sampling vs. BRDF sampling) in path tracing to reduce variance [S3, unofficial]. The weight for a strategy is calculated as:
$$ w = \frac{(n_f f_{pdf})^2}{(n_f f_{pdf})^2 + (n_g g_{pdf})^2} $$
where $n_f$ and $n_g$ are the number of samples for each strategy, and $f_{pdf}$ and $g_{pdf}$ are the respective probability density functions [S3, unofficial].

## Operating characteristics
- **Time Complexity:** The method adds the cost of sampling a light source and computing its PDF to the standard path tracing loop. The MIS weight calculation is $O(1)$ per vertex [S2].
- **Memory Complexity:** Requires caching `dir_pdf`, `nee_p_cache`, and `multi_trans_pdf` per path, which is $O(1)$ additional memory per path [S1].
- **Performance:** Significantly reduces variance in scenes with small or complex light sources compared to pure phase function sampling [S1]. It is particularly effective in heterogeneous media where transmittance estimation is difficult [S1].
- **Strengths:** Handles index-matching surfaces correctly by caching PDFs; reduces variance for both delta and non-delta lights; consistent estimator [S1, S2].
- **Limitations:** Requires careful implementation of PDF caching to avoid errors when skipping surfaces; may increase variance if one sampling strategy is significantly worse than the other and the power heuristic does not suppress it sufficiently (though the power heuristic is generally robust) [S1][S3, unofficial].

## Background
Multiple Importance Sampling for volumetric path tracing was developed to address the high variance in direct lighting estimation in participating media. The specific caching mechanism for index-matching surfaces was introduced in the context of volumetric path tracing homework assignments at UC San Diego [S1]. The general framework for volume scattering integrators, including the `SampleLd` function and MIS weight calculation, is detailed in the "Physically Based Rendering" (PBRT) book, specifically in Chapter 14 on Volume Scattering Integrators [S2]. The power heuristic is a standard technique in path tracing, often attributed to Veach, and is implemented in various open-source path tracers [S3, unofficial].
