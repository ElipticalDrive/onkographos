# Unknown Distance PDF and MIS

Also called: Distance PDF Cancellation for MIS

## Overview
A technique to enable Multiple Importance Sampling (MIS) for path-construction strategies, such as Next Event Estimation (NEE) or bidirectional methods, in rejection-based volumetric trackers where the free-path sample probability density function (PDF) cannot be evaluated exactly [S1]. It solves the problem of combining strategies by ensuring the unknown distance PDFs cancel out in the MIS weight calculation, allowing the weight to be computed based solely on directional PDFs [S1]. This sets it apart from general MIS applications by relying on the structural identity of the sampling tracker rather than explicit PDF evaluation.

## How it works
**Inputs and Outputs:**
- Input: Two path-construction strategies (e.g., free-path sampling and transmittance sampling/NEE) using the same unbiased rejection-based tracker.
- Output: MIS balance-heuristic weight for combining the strategies.

**Data Structures:**
- Tracker state: Contains the current position, direction, and accumulated weight. The tracker must be identical for both sampling passes.
- Directional PDFs: $p_\Omega(\omega)$ for the sampled directions.

**Steps:**
1. **Ensure Tracker Identity:** Use the exact same unbiased rejection-based tracker implementation for both the free-path sampling (generating the path segment) and the transmittance sampling (evaluating the contribution, e.g., in NEE) [S1]. This ensures the distance PDFs are identical [S1].
2. **Compute Directional PDFs:** Evaluate the directional PDFs, $p_{\Omega,1}(\omega_1)$ and $p_{\Omega,2}(\omega_2)$, for the directions sampled by each strategy [S1].
3. **Calculate MIS Weight:** Compute the balance-heuristic weight using only the directional PDFs. The distance PDFs cancel out because they are identical for both strategies [S1].
   $$ w_1 = \frac{p_{\Omega,1}(\omega_1)^2}{p_{\Omega,1}(\omega_1)^2 + p_{\Omega,2}(\omega_2)^2} $$
   (Using the power heuristic with $\beta=2$ is common, but the balance heuristic is also valid as long as the distance PDFs cancel [S1]).
4. **Apply Weight:** Multiply the contribution of the path segment by the computed weight $w_1$ (or $w_2 = 1 - w_1$) [S1].

**Pseudocode:**
```python
def compute_unknown_distance_mis_weight(strategy1_tracker, strategy2_tracker):
    """
    Computes MIS weight when distance PDFs are unknown but identical.
    Assumes strategy1_tracker and strategy2_tracker are instances of the 
    same unbiased rejection-based tracker class, initialized identically 
    for the current path segment.
    """
    # Get directional PDFs from the trackers
    # The tracker must expose the directional PDF value for the sampled direction
    p_dir_1 = strategy1_tracker.get_directional_pdf()
    p_dir_2 = strategy2_tracker.get_directional_pdf()
    
    # Check for zero PDFs to avoid division by zero
    if p_dir_1 == 0 and p_dir_2 == 0:
        return 0.5
    
    # Power heuristic (beta=2) is standard for stability
    # Balance heuristic would use p_dir_1 / (p_dir_1 + p_dir_2)
    # The source mentions balance-heuristic weight is effectively based on directional PDFs
    # We use power heuristic as it is robust and commonly cited with this technique
    numerator = p_dir_1 * p_dir_1
    denominator = numerator + (p_dir_2 * p_dir_2)
    
    if denominator == 0:
        return 0.5
        
    return numerator / denominator
```

**Parameters:**
- Tracker Consistency: The same tracker must be used. Not given in the sources if partial consistency is allowed.
- Heuristic Type: Balance or Power heuristic. The source specifies balance-heuristic weight is effectively based on directional PDFs [S1].

**Edge Cases and Pitfalls:**
- **Different Trackers:** If different trackers are used for free-path and transmittance sampling, the distance PDFs will not cancel, and this method fails [S1].
- **Other Heuristics:** The cancellation property holds for balance and power heuristics but does not generalize to other MIS heuristics [S1].
- **Spectral Tracking:** The distance PDFs are not wavelength-dependent in the spectral tracker, so the cancellation holds even for spectral tracking [S1].
- **Approximation:** If cancellation conditions are not met, a near-optimal weight can be computed using a deterministic approximation of the PDF, e.g., via an extra ray-marching pass [S1].

## Operating characteristics
- **Time Complexity:** $O(1)$ for weight calculation if directional PDFs are available. An extra ray-marching pass for approximation adds $O(N)$ where $N$ is the number of steps [S1].
- **Memory Complexity:** $O(1)$ additional memory for storing directional PDFs.
- **Measured Performance:** Not given in the sources.
- **Scaling:** Scales with the number of strategies combined. The cancellation property is independent of scene complexity.
- **Strengths:** Enables MIS in rejection-based trackers where distance PDFs are unknown. Works for spectral tracking. Simple to implement if tracker identity is maintained.
- **Limitations:** Requires identical trackers for all strategies. Only works for balance/power heuristics. Does not generalize to other heuristics or different trackers [S1].
- **When to Use:** When using rejection-based trackers and combining strategies like NEE where distance PDFs are unknown but can be made identical.
- **When Not to Use:** When different trackers are necessary for different strategies, or when using MIS heuristics other than balance/power.

## Background
Originated in the context of spectral and decomposition tracking for rendering heterogeneous volumes [S1]. The technique addresses a common drawback of rejection-based trackers where the free-path sample PDF cannot be evaluated exactly [S1]. It allows for the combination of multiple path-construction strategies using MIS, such as in next-event estimation (NEE) or bidirectional techniques [S1]. The method is particularly useful for spectral tracking because the distance PDFs are not wavelength-dependent [S1].
