# Unknown Distance PDF and MIS

Also called: Distance PDF Cancellation for MIS

## Overview
A technique to enable Multiple Importance Sampling (MIS) for path-construction strategies, such as Next Event Estimation (NEE) or bidirectional methods, in rejection-based volumetric trackers where the free-path sample probability density function (PDF) cannot be evaluated exactly [S1]. It solves the problem of combining strategies by ensuring the unknown distance PDFs cancel out in the MIS weight calculation, allowing the weight to be computed based solely on directional PDFs [S1]. This sets it apart from general MIS applications by relying on the structural identity of the sampling tracker rather than explicit PDF evaluation [S1].

## How it works
**Inputs and Outputs:**
- Input: Two path-construction strategies (e.g., free-path sampling and transmittance sampling/NEE) using the same unbiased rejection-based tracker [S1].
- Output: MIS balance-heuristic weight for combining the strategies [S1].

**Data Structures:**
- Directional PDFs: $p_\Omega(\omega)$ for the sampled directions [S1].

**Steps:**
1. **Ensure Tracker Identity:** Use the exact same unbiased rejection-based tracker implementation for both the free-path sampling (generating the path segment) and the transmittance sampling (evaluating the contribution, e.g., in NEE) [S1]. This ensures the distance PDFs are identical [S1].
2. **Compute Directional PDFs:** Evaluate the directional PDFs, $p_{\Omega,1}(\omega_1)$ and $p_{\Omega,2}(\omega_2)$, for the directions sampled by each strategy [S1].
3. **Calculate MIS Weight:** Compute the balance-heuristic weight using only the directional PDFs, as the distance PDFs have cancelled out [S1].
   $$ w_1 = \frac{p_{\Omega,1}(\omega_1)}{p_{\Omega,1}(\omega_1) + p_{\Omega,2}(\omega_2)} $$
   The power heuristic is also valid under these conditions [S1].
4. **Apply Weight:** Multiply the contribution of the path segment by the computed weight $w_1$ (or $w_2 = 1 - w_1$) [S1].

**Pseudocode:**
```python
def compute_unknown_distance_mis_weight(p_dir_1, p_dir_2):
    """
    Computes MIS weight when distance PDFs are unknown but identical.
    Uses the balance heuristic based on directional PDFs.
    """
    total = p_dir_1 + p_dir_2
    if total == 0.0:
        return 0.5
    return p_dir_1 / total
```

**Parameters:**
- Tracker Consistency: The same tracker must be used for both sampling passes [S1]. Not given in the sources if partial consistency is allowed.
- Heuristic Type: Balance or Power heuristic [S1].

**Edge Cases and Pitfalls:**
- **Different Trackers:** If different trackers are used for free-path and transmittance sampling, the distance PDFs will not cancel, and this method fails [S1].
- **Other Heuristics:** The cancellation property holds for balance and power heuristics but does not generalize to other MIS heuristics [S1].
- **Spectral Tracking:** The distance PDFs are not wavelength-dependent in the spectral tracker, so the cancellation holds even for spectral tracking [S1].
- **Approximation:** If cancellation conditions are not met, a near-optimal weight can be computed using a deterministic approximation of the PDF, e.g., via an extra ray-marching pass [S1].

## Operating characteristics
- **Time Complexity:** Not given in the sources.
- **Memory Complexity:** Not given in the sources.
- **Measured Performance:** Not given in the sources.
- **Scaling:** Not given in the sources.
- **Strengths:** Enables MIS in rejection-based trackers where distance PDFs are unknown. Works for spectral tracking.
- **Limitations:** Requires identical trackers for all strategies. Only works for balance/power heuristics. Does not generalize to other heuristics or different trackers [S1].
- **When to Use:** When using rejection-based trackers and combining strategies like NEE where distance PDFs are unknown but can be made identical [S1].
- **When Not to Use:** When different trackers are necessary for different strategies, or when using MIS heuristics other than balance/power [S1].

## Background
Developed for use in rejection-based trackers where the free-path sample PDF cannot be evaluated exactly [S1]. It allows for the combination of multiple path-construction strategies using MIS, such as in next-event estimation (NEE) or bidirectional techniques [S1]. The method is particularly useful for spectral tracking because the distance PDFs are not wavelength-dependent [S1].
