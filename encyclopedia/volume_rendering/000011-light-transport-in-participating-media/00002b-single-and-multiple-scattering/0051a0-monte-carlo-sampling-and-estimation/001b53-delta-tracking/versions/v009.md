# Delta tracking

Also called: Delta Tracking with Null Collisions, Null Collision Method, Null-scattering sampling, Woodcock Tracking

## Overview

Delta tracking is a Monte Carlo free-path sampling method that finds the first real collision point (scattering or absorption) in a heterogeneous participating medium by sampling tentative collisions from a fictitious homogeneous medium with a constant maximum extinction coefficient (majorant) [S4][S18, unofficial]. It solves the problem of efficiently sampling interaction distances in spatially varying media without requiring a structured grid or expensive memory accesses at every step [S4][S11]. Unlike ray marching, which introduces systemic statistical bias by using fixed steps, delta tracking provides an unbiased estimator by probabilistically accepting or rejecting tentative collisions based on the ratio of local to maximum extinction [S14, unofficial][S12, unofficial]. It sets itself apart from siblings like [Dwivedi Sampling](5537-dwivedi-sampling.md) by strictly maintaining unbiasedness through rejection sampling, whereas Dwivedi Sampling introduces bias to reduce variance [G].

## How it works

**Inputs and Outputs**
*   **Input:** Ray origin $\mathbf{o}$, ray direction $\mathbf{w}$ (normalized), maximum distance $t_{max}$ (or volume bounds), majorant extinction coefficient $\bar{\mu}$ (or $\sigma_t^{max}$), and a function to evaluate local extinction coefficient $\sigma_t(\mathbf{x})$ [S4][S11][S14, unofficial].
*   **Output:** Distance to the first real collision $t$, or $t_{max}$ if no collision occurs within the volume [S5][S14, unofficial].

**Data Structures**
*   **Majorant ($\bar{\mu}$):** A scalar value representing the upper bound of the total extinction coefficient over the entire volume or a specific region. It must satisfy $\bar{\mu} \ge \sigma_t(\mathbf{x})$ for all $\mathbf{x}$ along the ray [S18, unofficial][S5].
*   **Local Extinction Function:** A query function that returns $\sigma_t(\mathbf{x}) = \sigma_a(\mathbf{x}) + \sigma_s(\mathbf{x})$ at any position $\mathbf{x}$ [S4][S14, unofficial].

**Numbered Steps**

1.  **Initialization:** Set current distance $t = 0$ (or $t_{min}$) [S14, unofficial]. Compute the inverse majorant $invMajorant = 1 / \bar{\mu}$ [S10][S14, unofficial].
2.  **Sample Tentative Distance:** Generate a uniform random number $\xi \sim U[0, 1)$ [S11]. Sample the distance to the next tentative collision from the exponential distribution defined by the majorant:
    $$ t \leftarrow t - \frac{\ln(1 - \xi)}{\bar{\mu}} $$
3.  **Boundary Check:** If $t > t_{max}$, the ray exits the volume without a collision. Return $t_{max}$ (or the remaining distance) [S5][S14, unofficial].
4.  **Evaluate Local Extinction:** Compute the position $\mathbf{x} = \mathbf{o} + t \mathbf{w}$ [S11]. Evaluate the local total extinction coefficient $\sigma_t(\mathbf{x})$ [S11][S14, unofficial].
    *   *Pitfall:* If the evaluation returns NaN (e.g., out-of-bounds access), skip the rejection test and continue to the next step to avoid incorrect shading [S2, book].
5.  **Acceptance/Rejection Test:** Generate a new uniform random number $\xi' \sim U[0, 1)$ [S11]. Calculate the acceptance probability:
    $$ p_{accept} = \frac{\sigma_t(\mathbf{x})}{\bar{\mu}} $$
    If $\xi' < p_{accept}$, the collision is **real**. Return $t$ as the distance to the first real collision [S5, S11].
    *   *Pitfall:* If $\sigma_t(\mathbf{x}) > \bar{\mu}$ due to numerical error or incorrect majorant, $p_{accept} > 1$, breaking the logic. Ensure $\bar{\mu}$ is a strict upper bound [S5].
6.  **Null Collision:** If $\xi' \ge p_{accept}$, the collision is a **null collision** (fictitious). The ray passes through without interaction. Continue from Step 2 with the current $t$ [S5, S11][S8, unofficial].

**Pseudocode**

```python
import math
import random

def random_uniform():
    return random.random()

def delta_tracking(ray_origin, ray_direction, t_max, majorant, get_local_extinction):
    """
    Finds the first real collision distance in a heterogeneous volume.
    
    Args:
        ray_origin: list of 3 floats, origin of the ray.
        ray_direction: list of 3 floats, normalized direction of the ray.
        t_max: float, maximum distance to search for a collision.
        majorant: float, upper bound on extinction coefficient (sigma_t_max).
        get_local_extinction: function, returns sigma_t(x) at position x.
        
    Returns:
        float: Distance to the first real collision, or t_max if none found.
    """
    if majorant <= 0:
        return t_max
        
    inv_majorant = 1.0 / majorant
    t = 0.0
    
    while True:
        # Step 2: Sample tentative distance
        xi = random_uniform()
        t += -math.log(1.0 - xi) * inv_majorant
        
        # Step 3: Boundary check
        if t >= t_max:
            return t_max
            
        # Step 4: Evaluate local extinction
        position = [ray_origin[i] + ray_direction[i] * t for i in range(3)]
        local_extinction = get_local_extinction(position)
        
        # Pitfall: Handle NaN from invalid positions
        if math.isnan(local_extinction):
            continue
            
        # Step 5: Acceptance/Rejection test
        xi_prime = random_uniform()
        acceptance_prob = local_extinction / majorant
        
        # Clamp probability to [0, 1] to handle floating point errors
        acceptance_prob = max(0.0, min(1.0, acceptance_prob))
        
        if xi_prime < acceptance_prob:
            # Real collision found
            return t
        else:
            # Null collision, continue loop
            pass
```

**Parameters**
*   **Majorant ($\bar{\mu}$):** The tighter the majorant is to the actual extinction, the fewer null collisions occur. A global maximum is simple but inefficient for sparse volumes; local majorants (e.g., per voxel or brick) reduce null collisions but add overhead [S1, book][S13, unofficial]. Typical values depend on the volume's density scale [S6, S10].
*   **Random Numbers:** Two independent uniform random numbers per step are required: one for distance sampling, one for acceptance [S11][S14, unofficial].

**Edge Cases and Pitfalls**
*   **Large Empty Spaces:** If the volume has large regions of zero density but a high global majorant, the algorithm wastes samples on null collisions [S11][S13, unofficial].
*   **Incorrect Majorant:** If $\bar{\mu}$ is not a true upper bound, the estimator becomes biased [S5][S18, unofficial].
*   **NaN Values:** Accessing invalid memory or out-of-bounds coordinates can produce NaN, which must be handled to prevent propagation [S2, book][S10].

## Subtopics

### [Ratio Tracking with Null Scattering](1044-ratio-tracking-with-null-scattering.md)
Accumulates a continuous product of null-scattering ratios for transmittance estimation, avoiding binary visibility tests. Choose when low-variance transmittance is needed in heterogeneous media.

### [Woodcock Tracking with Variable Majorants](1084-woodcock-tracking-with-variable-majorants.md)
Uses spatially varying upper bounds (local majorants) to reduce null collisions in sparse areas. Choose when the volume has significant density variation and global majorant is too loose.

### [Delta Tracking (Uniform Majorant)](1539-delta-tracking-uniform-majorant.md)
Simplified version using a single global majorant. Choose for homogeneous media or when implementation simplicity outweighs performance in sparse volumes.

### [Null Interactions Shift](1836-null-interactions-shift.md)
Maps medium interaction depths between camera viewpoints using majorant optical depth. Choose for multi-view rendering and sample reuse.

### [Volume Path Tracing with Delta/Ratio Tracking](4982-volume-path-tracing-with-delta-ratio-tracking.md)
Separates scattering event sampling (delta tracking) from transmittance estimation (ratio tracking). Choose for GPU implementations requiring distinct handling of emission/absorption.

### [Weighted Delta Tracking](9238-weighted-delta-tracking.md)
Relaxes the majorant constraint, allowing $\bar{\mu} < \mu_t$ by using statistical weights. Choose when a tight majorant is hard to compute but variance from weights is acceptable.

### [Delta Tracking with Volume State Changes](11135-delta-tracking-with-volume-state-changes.md)
Manages majorants for volumes changing over time or optimization steps. Choose for inverse rendering or animation.

## Operating characteristics

*   **Time Complexity:** Expected number of steps is proportional to the ratio of the majorant to the average extinction coefficient. In sparse volumes with a loose majorant, this can be very high [S11][S13, unofficial].
*   **Memory Complexity:** Minimal additional memory beyond the volume data structure and the majorant. No need for structured grids or precomputed transmittance tables [S1, book][S14, unofficial].
*   **Measured Performance:** On the HACC dataset (51 million particles), delta tracking path tracing achieved 1.44 MR/s, compared to 6.0 MR/s for ray casting, but with higher quality and unbiasedness [S2, book]. Rendering a cloud with delta tracking and Next Event Estimation took 248s for 10 samples per pixel [S11].
*   **Strengths:** Unbiased, handles arbitrary heterogeneous media (including particle volumes and unstructured grids), no need for voxelization [S2, book][S14, unofficial].
*   **Limitations:** High variance in sparse volumes with loose majorants; many null collisions waste computation [S11][S13, unofficial].
*   **When to Use:** When unbiased rendering of complex, unstructured, or highly heterogeneous media is required, and performance constraints allow for higher sample counts [S2, book][S14, unofficial].
*   **When Not to Use:** For homogeneous media (use analytical transmittance) or when real-time performance is critical and bias is acceptable (use ray marching) [S14, unofficial][S17].

## Background

Delta tracking, also known as Woodcock tracking, was initially developed in the 1950s and 1960s by Butcher and Messel (1958, 1960), Zerby et al. (1961), Bertini (1963), Woodcock et al. (1965), Miller (1967), and Coleman (1968) [S18, unofficial]. In computer graphics, it has been adopted for unbiased volumetric path tracing to handle complex participating media without the bias of ray marching [S14, unofficial][S12, unofficial]. It is implemented in systems like OSPRay using ISPC and exposed via the Open VKL API for volume rendering of RBF particle data [S2, book].
