# Majorant optical depth shift

Also called: majorant optical depth shift derivation, shift mapping of medium interaction depths

## Overview
The majorant optical depth shift maps a medium interaction depth $t$ sampled on a base viewing segment to a corresponding depth $t'$ on a target viewing segment [S1]. This enables path reuse in multi-view rendering by accounting for differences in volume geometry and extinction coefficients between views [S1]. It builds on [Null Interactions Shift](1836-null-interactions-shift.md) by providing the specific mapping function required when the medium's majorant extinction coefficients differ between the base and target segments [G].

## How it works
The method relies on the piecewise constant approximation of the majorant optical depth along a ray [S1]. It assumes that the ray passes through a sequence of volume sections, each with a constant majorant extinction coefficient [S1]. The mapping is derived by equating the scaled majorant optical depth on the base segment to the majorant optical depth on the target segment [S1].

### Inputs and Outputs
- **Inputs**:
  - $t$: The interaction depth on the base segment [S1].
  - Base segment data: A list of $N$ volume sections [S1]. Each section $j$ has entry depth $t_{\min, j}$, exit depth $t_{\max, j}$, and constant majorant extinction coefficient $\bar{\mu}_j$ [S1].
  - Target segment data: A list of $M$ volume sections [S1]. Each section $i$ has entry depth $t'_{\min, i}$, exit depth $t'_{\max, i}$, and constant majorant extinction coefficient $\bar{\mu}'_i$ [S1].
  - $\bar{\tau}_{\max}$: The total majorant optical depth of the base segment (sum of $\bar{\mu}_j (t_{\max, j} - t_{\min, j})$ for all $j$) [S1].
  - $\bar{\tau}_{0,\max}$: The total majorant optical depth of the target segment (sum of $\bar{\mu}'_i (t'_{\max, i} - t'_{\min, i})$ for all $i$) [S1].
- **Output**:
  - $t'$: The mapped interaction depth on the target segment [S1].

### Parameters
- $C = \bar{\tau}_{0,\max} / \bar{\tau}_{\max}$: The scaling constant relating the total majorant optical depths of the target and base segments [S1].

### Steps
1. **Calculate the scaling constant**: Compute $C = \bar{\tau}_{0,\max} / \bar{\tau}_{\max}$ [S1].
2. **Identify the containing sections**: Find the index $n_l$ such that $t_{\min, n_l} \le t < t_{\max, n_l}$ in the base segment [S1]. Find the index $n_{l'}$ such that $t'_{\min, n_{l'}} \le t' < t'_{\max, n_{l'}}$ in the target segment [S1]. *Note: $t'$ is initially unknown. The algorithm typically involves solving for $t'$ or iterating [G]. In practice, one must determine which target section $t'$ falls into [G]. A common approach is to iterate through target sections or use binary search if sections are sorted, checking if the computed $t'$ from the formula falls within the current target section's bounds [G].*
3. **Compute the offset terms $a_1$ and $a_2$**: Compute $a_2$ for the base segment: $a_2 = \sum_{j=1}^{n_l-1} \bar{\mu}_j (t_{\max, j} - t_{\min, j}) - \bar{\mu}_{n_l} t_{\min, n_l}$ [S1]. Compute $a_1$ for the target segment: $a_1 = \sum_{i=1}^{n_{l'}-1} \bar{\mu}'_i (t'_{\max, i} - t'_{\min, i}) - \bar{\mu}'_{n_{l'}} t'_{\min, n_{l'}}$ [S1]. *Note: The sums are over all sections preceding the containing section. If $n_l=1$ or $n_{l'}=1$, the sum is empty (0) [G].*
4. **Calculate the offset $R$**: $R = \frac{C \cdot a_2 - a_1}{\bar{\mu}'_{n_{l'}}}$ [S1].
5. **Compute the mapped depth $t'$**: $t' = C \cdot \frac{\bar{\mu}_{n_l}}{\bar{\mu}'_{n_{l'}}} \cdot t + R$ [S1].

### Formulas
The core relationship is derived from equating the majorant optical depths [S1]:
$$ \bar{\tau}'(t') = C \cdot \bar{\tau}(t) $$

Expanding the piecewise constant majorant optical depth functions [S1]:
$$ \sum_{i=1}^{M} \bar{\mu}'_i (\min(t', t'_{\max, i}) - t'_{\min, i}) = C \cdot \sum_{j=1}^{N} \bar{\mu}_j (\min(t, t_{\max, j}) - t_{\min, j}) $$

For a specific section $n_{l'}$ containing $t'$ and $n_l$ containing $t$, this simplifies to [S1]:
$$ \bar{\mu}'_{n_{l'}} \cdot t' + a_1 = C \cdot [\bar{\mu}_{n_l} \cdot t + a_2] $$

Solving for $t'$ [S1]:
$$ t' = C \cdot \frac{\bar{\mu}_{n_l}}{\bar{\mu}'_{n_{l'}}} \cdot t + R $$

Where [S1]:
- $a_1 = \sum_{i=1}^{n_{l'}-1} \bar{\mu}'_i (t'_{\max, i} - t'_{\min, i}) - \bar{\mu}'_{n_{l'}} t'_{\min, n_{l'}}$
- $a_2 = \sum_{j=1}^{n_l-1} \bar{\mu}_j (t_{\max, j} - t_{\min, j}) - \bar{\mu}_{n_l} t_{\min, n_l}$
- $R = \frac{C \cdot a_2 - a_1}{\bar{\mu}'_{n_{l'}}}$

### Pseudocode
```python
def majorant_optical_depth_shift(t, base_sections, target_sections, tau_max_base, tau_max_target):
    """
    Maps interaction depth t from base segment to target segment.
    
    Args:
        t: float, interaction depth on base segment.
        base_sections: list of dicts/objects with keys 't_min', 't_max', 'mu_bar'.
        target_sections: list of dicts/objects with keys 't_min', 't_max', 'mu_bar'.
        tau_max_base: float, total majorant optical depth of base segment.
        tau_max_target: float, total majorant optical depth of target segment.
        
    Returns:
        t_prime: float, mapped interaction depth on target segment.
    """
    if tau_max_base == 0:
        return 0.0  # Guard against division by zero; no scattering occurs [G].
        
    C = tau_max_target / tau_max_base
    
    # Find base section index n_l containing t (0-based indexing)
    n_l = -1
    for j, section in enumerate(base_sections):
        if section['t_min'] <= t < section['t_max']:
            n_l = j
            break
    if n_l == -1:
        # Clamp t to the last section if it falls exactly on the boundary or outside [G].
        n_l = len(base_sections) - 1
        if t >= base_sections[-1]['t_max']:
            t = base_sections[-1]['t_max'] - 1e-9
            
    # Compute a2 for the base segment
    a2 = 0.0
    for j in range(n_l):
        section = base_sections[j]
        a2 += section['mu_bar'] * (section['t_max'] - section['t_min'])
    a2 -= base_sections[n_l]['mu_bar'] * base_sections[n_l]['t_min']
    
    # Iterate through target sections to find n_l' and the valid t'
    t_prime = None
    n_l_prime = -1
    
    for i, target_section in enumerate(target_sections):
        # Compute a1 for this candidate target section
        a1 = 0.0
        for k in range(i):
            sec = target_sections[k]
            a1 += sec['mu_bar'] * (sec['t_max'] - sec['t_min'])
        a1 -= target_section['mu_bar'] * target_section['t_min']
        
        # Calculate offset R
        R = (C * a2 - a1) / target_section['mu_bar']
        
        # Compute candidate t'
        t_candidate = C * (base_sections[n_l]['mu_bar'] / target_section['mu_bar']) * t + R
        
        # Verify if candidate falls within this target section's bounds
        if target_section['t_min'] <= t_candidate < target_section['t_max']:
            t_prime = t_candidate
            n_l_prime = i
            break
            
    if t_prime is None:
        # Fallback for numerical precision or ray exit cases [G].
        t_prime = target_sections[-1]['t_max'] - 1e-9
        
    return t_prime
```

### Edge Cases and Pitfalls
- **Zero Total Optical Depth**: If $\bar{\tau}_{\max} = 0$, the scaling constant $C$ is undefined [S1]. This implies no scattering occurs, and the shift is trivial or irrelevant [G].
- **Section Boundary Precision**: Floating-point errors may cause $t'$ to fall slightly outside the computed section bounds [G]. Clamping or re-evaluating the section index may be necessary [G].
- **Ray Exit**: If the mapped depth $t'$ falls outside the target segment's volume bounds, the interaction is invalid for the target view [G].
- **Non-Matching Sections**: The number of sections $N$ and $M$ may differ [S1]. The algorithm handles this by iterating through target sections to find the correct one [G].

## Operating characteristics
- **Time Complexity**: $O(N + M)$ per shift, where $N$ and $M$ are the number of volume sections in the base and target segments, respectively [G]. This is because we iterate through sections to find the containing ones and compute the sums $a_1$ and $a_2$ [G].
- **Memory Complexity**: $O(1)$ additional memory if the section data is accessed sequentially, or $O(N + M)$ to store the section data [G].
- **Strengths**: Provides an exact analytical mapping for piecewise constant majorant extinction coefficients [G]. Efficient for multi-view rendering where many paths are reused [G].
- **Limitations**: Requires pre-computation of section boundaries and majorant coefficients [G]. Assumes piecewise constant extinction, which may not hold for highly heterogeneous media without sufficient subdivision [G].
- **When to Use**: When reusing paths between multiple views with different camera positions or different volume geometries/extinction coefficients [G].
- **When Not to Use**: For single-view rendering where no shift is needed, or for media where the majorant extinction coefficient varies continuously and cannot be well-approximated by piecewise constants [G].

## Background
The majorant optical depth shift is derived in the context of volumetric multi-view rendering, specifically for reusing light transport paths between different views [S1]. It was introduced in the paper "Volumetric Multi-View Rendering" [S1]. The method allows for efficient rendering by avoiding redundant sampling of the medium when the view changes, provided the medium's properties can be described by piecewise constant majorant extinction coefficients [S1].
