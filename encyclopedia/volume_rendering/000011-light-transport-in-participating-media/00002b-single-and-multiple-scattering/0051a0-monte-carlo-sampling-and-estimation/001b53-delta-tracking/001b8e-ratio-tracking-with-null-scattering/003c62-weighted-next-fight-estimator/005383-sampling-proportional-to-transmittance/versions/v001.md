# Sampling Proportional to Transmittance

Also called: Transmittance-weighted sampling using Delta/Ratio trackers

## Overview
Sampling Proportional to Transmittance is a technique for generating free-flight distances distributed according to the transmittance function $T(t)$, rather than the standard extinction-weighted distribution. It solves the problem of needing to sample from $T(t)$ for unbiased inverse volume rendering estimators without requiring explicit evaluation of the normalization constant $C = \int_0^{t_s} T(t') dt'$, which is generally intractable. It sets itself apart from standard delta tracking by producing samples proportional to $T(t)$ directly, whereas standard delta tracking produces samples proportional to $\sigma_t(t)T(t)$ (the probability of the *first* interaction). It builds on [Weighted Next-Fight Estimator](9226-weighted-next-fight-estimator.md) by providing the specific sampling distribution required for the uncollided radiance term.

## How it works
The method generates weighted samples $(t, w)$ such that the weighted density matches the transmittance $T(0, t)$. It relies on the fact that while $T(t)$ is not a probability density function (PDF), it can be sampled using a weighted approach derived from delta tracking.

**Inputs:**
- $\bar{\sigma}$: Majorant density, satisfying $\bar{\sigma} \geq \sigma_t(t)$ for all $t \in [0, t_s]$.
- $t_s$: Upper bound of the ray segment (location of closest surface or medium bounding box).
- $\sigma_t(t)$: Extinction coefficient function.

**Outputs:**
- $t$: A sampled distance in $[0, t_s)$.
- $w$: A sampling weight.

**Data Structures:**
- No persistent data structures are required. The method is stateless per sample generation, relying on random number generation for the tracker steps.

**Steps:**
1. **Delta Tracking Phase:** Perform delta tracking to find the first interaction distance $t_1$ in the homogenized medium.
   - Initialize current position $t_{curr} = 0$.
   - Loop:
     - Sample step size $\Delta t$ from exponential distribution with rate $\bar{\sigma}$: $\Delta t = -\ln(u_1) / \bar{\sigma}$, where $u_1 \sim \mathcal{U}(0, 1)$.
     - Update position: $t_{curr} \leftarrow t_{curr} + \Delta t$.
     - If $t_{curr} \geq t_s$, the ray exits the segment without interaction. Return a special "no interaction" state or handle as boundary case.
     - Sample acceptance probability $u_2 \sim \mathcal{U}(0, 1)$.
     - If $u_2 < \sigma_t(t_{curr}) / \bar{\sigma}$, a real interaction occurs. Set $t_1 = t_{curr}$ and break.
     - Otherwise, it is a null collision; continue loop.

2. **Scaling Phase:**
   - Sample a scaling factor $s$ uniformly from $[0, 1)$: $s = u_3$, where $u_3 \sim \mathcal{U}(0, 1)$.
   - Compute the final sampled distance: $t = t_1 \cdot s$.

3. **Weight Calculation:**
   - Compute the weight: $w = t_1$.
   - Note: $w$ can also be computed as $t / s$ if $s > 0$. If $s=0$, $t=0$ and the weight is still $t_1$.

**Formulas:**
The target PDF is:
$$ p_T(t) = \frac{T(t)}{C}, \quad C = \int_0^{t_s} T(t') dt' $$

The PDF of the first interaction distance in delta tracking is:
$$ p_1(t) = \sigma_t(t) T(0, t) $$

The resulting weighted PDF for the scaled distance $t$ is:
$$ p_2(t) = T(0, t) $$

The weight $w$ serves two purposes:
1. It corrects the PDF from $p_1(t/s)/s$ to $T(0, t)$.
2. It provides an unbiased estimate of the normalization constant $C$. Specifically, the expected value of the weight $w$ over many samples equals $C$.

**Parameters:**
- $t_s$: The maximum distance along the ray. Typically determined by the nearest surface intersection or the end of the medium bounding box.
- $\bar{\sigma}$: The majorant. Must be tight enough for efficiency but valid everywhere in $[0, t_s]$.

**Edge Cases and Pitfalls:**
- **$s=0$**: If $s=0$, $t=0$. The weight $w=t_1$ remains valid. In practice, floating-point precision may result in $s$ being extremely small but non-zero.
- **No Interaction in Delta Tracking**: If delta tracking fails to find an interaction within $t_s$ (i.e., the ray passes through the medium without scattering/absorbing), this corresponds to the transmittance $T(0, t_s)$. The method as described samples $t \in [0, t_s)$. If the goal is to sample from the entire distribution including the "exit" event, additional handling is required. However, for the purpose of estimating the integral $C$, the samples generated within $[0, t_s)$ are sufficient, and the weight $w$ estimates the area under $T$.
- **Precision**: Computing $\sigma_t(t_{curr}) / \bar{\sigma}$ requires accurate evaluation of $\sigma_t$. If $\sigma_t$ is discontinuous, care must be taken at boundaries.

**Pseudocode:**

```python
import random
import math

def sample_proportional_to_transmittance(sigma_t_func, sigma_bar, t_s):
    """
    Samples a distance t proportional to transmittance T(0, t) with weight w.
    
    Args:
        sigma_t_func: Function sigma_t(t) returning extinction at distance t.
        sigma_bar: Majorant density, sigma_bar >= sigma_t(t) for all t in [0, t_s].
        t_s: Upper bound of the ray segment.
        
    Returns:
        t: Sampled distance in [0, t_s).
        w: Sampling weight.
        success: Boolean indicating if a valid sample was generated within [0, t_s).
                 If False, the ray exited the medium without interaction.
    """
    # Step 1: Delta Tracking to find first interaction t1
    t_curr = 0.0
    while True:
        # Sample step from exponential distribution with rate sigma_bar
        u1 = random.random()
        # Avoid log(0)
        if u1 == 0.0:
            u1 = 1e-10
        delta_t = -math.log(u1) / sigma_bar
        t_curr += delta_t
        
        if t_curr >= t_s:
            # Ray exits the segment without interaction
            return None, None, False
        
        # Evaluate extinction at current position
        sigma_t = sigma_t_func(t_curr)
        
        # Acceptance test
        u2 = random.random()
        if u2 < sigma_t / sigma_bar:
            t1 = t_curr
            break
        # Else: null collision, continue
    
    # Step 2: Scaling
    u3 = random.random()
    s = u3
    
    # Step 3: Compute t and w
    t = t1 * s
    w = t1
    
    return t, w, True
```

## Subtopics

### Differential Delta Tracking
Differential Delta Tracking is the specific variant described in the core method. It uses the binary tracking function $f_{DT}$ from delta tracking and samples a point proportional to the area under this function. It is chosen when one needs to sample from the transmittance distribution $T(t)$ for inverse rendering or when estimating the normalization constant $C$ is required. It differs from standard delta tracking in that it produces samples distributed as $T(t)$ rather than $\sigma_t(t)T(t)$. It is preferred over ratio tracking in this context because it directly yields the weight $w=t_1$ which estimates $C$, whereas ratio tracking requires more complex bookkeeping for the null scattering correction.

## Operating characteristics
- **Time Complexity**: The expected number of steps in delta tracking is proportional to $\bar{\sigma} \cdot t_s / \bar{\sigma}_{avg}$? No, the expected number of steps is proportional to the ratio of the majorant to the average extinction. Specifically, the expected number of null collisions is $\int_0^{t_s} (\bar{\sigma} - \sigma_t(t)) dt$. The total expected steps is $1 + \int_0^{t_s} (\bar{\sigma} - \sigma_t(t)) dt$. This is efficient if $\bar{\sigma}$ is tight.
- **Memory Complexity**: $O(1)$. No data structures are stored.
- **Measured Performance**: Not given in the sources.
- **Strengths**: Unbiased estimation of transmittance-weighted samples without explicit integration. The weight $w$ provides an unbiased estimate of $C$. Simple to implement.
- **Limitations**: Requires a valid majorant $\bar{\sigma}$. If $\bar{\sigma}$ is loose, performance degrades due to many null collisions. The method samples from $[0, t_s)$; handling the boundary $t_s$ requires care if the full distribution is needed.
- **When to use**: When implementing inverse volume rendering or any estimator that requires sampling proportional to $T(t)$.
- **When not to use**: When standard forward rendering is used, where sampling proportional to $\sigma_t(t)T(t)$ is standard.

## Background
The method originates from the work on unbiased inverse volume rendering. It is based on the observation that transmittance can be sampled using weighted samples derived from delta tracking. The technique was formalized in the context of differential trackers, which build piecewise approximations of the transmittance function. The key insight is that the weight $w=t_1$ from delta tracking corresponds to the area under the binary tracking function, which estimates the normalization constant $C$. This allows for unbiased estimation without explicit integration.
