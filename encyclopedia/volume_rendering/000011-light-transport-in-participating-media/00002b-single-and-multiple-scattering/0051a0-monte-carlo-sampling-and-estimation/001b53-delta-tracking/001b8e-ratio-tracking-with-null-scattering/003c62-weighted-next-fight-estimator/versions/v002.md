# Weighted Next-Fight Estimator

Also called: Integral Formulation of Transmittance Estimators, Next-flight estimator

## Overview
The Weighted Next-Fight Estimator is a Monte Carlo method for estimating transmittance (uncollided radiance) in participating media using null scattering [S1]. It modifies the Radiative Transfer Equation (RTE) to account for losses and a point source of unit radiance, combining an underestimated uncollided contribution with null collision sampling to correct for the initial underestimation [S1]. It is distinguished from its sibling, Real-scattering vertex connection with ratio tracking, by explicitly adding the transmittance through the rest of the combined medium at each step rather than relying solely on the product of relative concentrations [S1].

## How it works
**Inputs and Outputs**
- **Input**: Starting position $\mathbf{x}_0$, direction $\omega$, remaining distance to the point source $d_i$, combined extinction coefficient function $\bar{\mu}(\mathbf{x})$, null collision coefficient function $\mu_n(\mathbf{x})$, and PDF of sampled free paths $p(t)$ [S1].
- **Output**: The estimated transmittance $L(\mathbf{x}_0, \omega)$ or the Monte Carlo score $w(\mathbf{X})$ [S1].

**Data Structures**
- **Collision Points**: A sequence of positions $\mathbf{x}_j$ generated by sampling free paths [S1].
- **Weights**: Accumulated product of relative concentrations $\frac{\mu_n(\mathbf{x}_j)}{\bar{\mu}(\mathbf{x}_j)}$ [S1].

**Numbered Steps**
1. Define the position of the point source of unit radiance as $\mathbf{x}_d = \mathbf{x}_0 - d_i \omega$ [S1].
2. Initialize the Monte Carlo score $w = 0$, the weight product $W = 1$, and the current position $\mathbf{x}_{curr} = \mathbf{x}_0$ [G].
3. Sample a free path distance $t$ from the PDF $p(t)$ [G].
4. Update the position: $\mathbf{x}_{next} = \mathbf{x}_{curr} + t \omega$ [G].
5. If the distance from $\mathbf{x}_0$ to $\mathbf{x}_{next}$ along $\omega$ exceeds $d_i$, terminate the loop [G].
6. Calculate the transmittance from $\mathbf{x}_{curr}$ to $\mathbf{x}_{next}$ through the combined medium: $T = \exp\left(-\int_0^{t} \bar{\mu}(\mathbf{x}_s) \, ds\right)$ [S1].
7. Add the underestimated uncollided contribution to the score: $w \leftarrow w + T \times W$ [S1].
8. Update the weight product: $W \leftarrow W \times \frac{\mu_n(\mathbf{x}_{next})}{\bar{\mu}(\mathbf{x}_{next})}$ [S1].
9. Update $\mathbf{x}_{curr} = \mathbf{x}_{next}$ and repeat from step 3 [G].

**Formulas**
The radiance $L(\mathbf{x}, \omega)$ is given by:
$$L(\mathbf{x}, \omega) = \exp\left(-\int_0^{d_i} \bar{\mu}(\mathbf{x}_s) \, ds\right) + \int_0^{d_i} p(t) \frac{\mu_n(\mathbf{x}_t)}{\bar{\mu}(\mathbf{x}_t)} L(\mathbf{x}_t, \omega) \, dt$$
where:
- $\bar{\mu}$ is the combined extinction coefficient [S1].
- $d_i$ is the remaining distance to the point source [S1].
- $p(t)$ is the PDF of sampled free paths [S1].
- $\mu_n$ is the null collision coefficient [S1].
- $\mathbf{x}_t$ is the position at distance $t$ [S1].

The Monte Carlo score $w(\mathbf{X})$ is:
$$w(\mathbf{X}) = \sum_{i=0}^{k-1} \exp\left(-\int_0^{d_i} \bar{\mu}(\mathbf{x}_s) \, ds\right) \prod_{j=1}^i \frac{\mu_n(\mathbf{x}_j)}{\bar{\mu}(\mathbf{x}_j)}$$
where:
- $k$ is the index of the first collision after exceeding distance $d$ from $\mathbf{x}_0$ [S1].
- $\mathbf{x}_j$ are the collision points [S1].

**Parameters**
- Typical values for $\bar{\mu}$ and $\mu_n$ are not given in the sources.

**Edge Cases and Pitfalls**
- The PDF $p(t)$ is fully determined by the homogenized extinction coefficient but can differ drastically from the true free-path distribution, frequently resulting in extreme weights [S1].

**Pseudocode**
```python
import random
import math

def weighted_next_flight_estimator(x0, omega, d_i, mu_bar_func, mu_n_func, p_t_sampler):
    """
    Estimates transmittance using the Weighted Next-Fight Estimator.
    
    Args:
        x0: Starting position (vector).
        omega: Direction (vector).
        d_i: Remaining distance to the point source (float).
        mu_bar_func: Function returning combined extinction coefficient at position.
        mu_n_func: Function returning null collision coefficient at position.
        p_t_sampler: Callable that returns a sampled free path distance t.
        
    Returns:
        Estimated transmittance (float).
    """
    x_curr = x0
    score = 0.0
    weight_product = 1.0
    
    while True:
        # Sample free path distance from p(t)
        t = p_t_sampler()
        
        # Update position
        x_next = x_curr + t * omega
        
        # Check if we have exceeded the distance to the point source
        dist_from_origin = dot(x_next - x0, omega)
        
        if dist_from_origin > d_i:
            break
            
        # Calculate transmittance from x_curr to x_next through combined medium
        # Sources do not specify the quadrature method for the integral.
        # In practice, this is computed analytically for constant coefficients
        # or via numerical integration (e.g., midpoint rule).
        integral_val = integrate_mu_bar(x_curr, x_next, mu_bar_func, t)
        transmittance = math.exp(-integral_val)
        
        # Add underestimated uncollided contribution
        score += transmittance * weight_product
        
        # Update weight product with relative concentration of null particles
        mu_bar_val = mu_bar_func(x_next)
        if mu_bar_val == 0:
            relative_concentration = 1.0
        else:
            relative_concentration = mu_n_func(x_next) / mu_bar_val
            
        weight_product *= relative_concentration
        
        # Update current position
        x_curr = x_next
        
    return score

def integrate_mu_bar(x_start, x_end, mu_bar_func, t):
    """
    Computes the integral of mu_bar along the path from x_start to x_end.
    Uses midpoint rule as a standard numerical approximation.
    """
    x_mid = (x_start + x_end) / 2.0
    return mu_bar_func(x_mid) * t
```

## Subtopics

### Real-scattering vertex connection with ratio tracking
A sibling method that uses ratio tracking to sample distances proportional to the homogenized transmittance and distinguishes between real and fake particle interactions. It is chosen when real scattering events are of interest, whereas the Weighted Next-Fight Estimator is chosen for estimating uncollided radiance [1766-real-scattering-vertex-connection-with-ratio-tracking.md].

## Operating characteristics
- **Time Complexity**: Not given in the sources.
- **Memory Complexity**: Not given in the sources.
- **Measured Performance**: Not given in the sources.
- **Scaling**: Performance degrades if the PDF $p(t)$ differs drastically from the true free-path distribution, leading to extreme weights [S1].
- **Strengths**: Provides an unbiased estimate of transmittance by correcting the initial underestimation with null collisions [S1].
- **Limitations**: Can suffer from high variance due to extreme weights if the sampling distribution is poor [S1].

## Background
The Weighted Next-Fight Estimator was presented by Cramer in 1978 [S1]. This document claims it is the first derivation of the next-flight estimator directly from a modified version of the RTE and its first description in computer graphics literature [S1]. It is used in volume rendering for estimating transmittance in participating media [S1].
