# Real-scattering vertex connection with ratio tracking

Also called: Delta Tracking for Transmittance Estimation, Real-scattering vertex connection

## Overview
Estimates the transmittance between two points $p_1$ and $p_2$ in a participating medium using ratio tracking, which accumulates a product of null-scattering ratios rather than terminating on collision [S1, S2, unofficial]. Unlike delta tracking for sampling which terminates on collision, ratio tracking continues until the endpoint is reached, accumulating a product of ratios to estimate the total transmittance [S1, unofficial]. This method serves as the transmittance estimation component within the broader real-scattering vertex connection framework, where it connects real-scattering vertices from camera and light subpaths [S2, unofficial].

## How it works
**Inputs and Outputs:**
*   **Input:** Start point $p_1$, end point $p_2$, majorant density $\mu_t$ (or $\sigma_t$), absorption density $\mu_a$ (or $\sigma_a$), scattering density $\mu_s$ (or $\sigma_s$), sampler state.
*   **Output:** Estimated transmittance $T(p_1, p_2)$ as a vector (typically RGB).

**Data Structures:**
*   `transmittance`: Vector of size 3 (RGB), initialized to $(1, 1, 1)$.
*   `t`: Scalar float, current distance along the ray, initialized to $0$.
*   `distToEnd`: Scalar float, length of the segment $\|p_2 - p_1\|$.
*   `invMajorant`: Scalar float, $1/\mu_t$.

**Steps:**
1.  Calculate `distToEnd` = length($p_2 - p_1$).
2.  Initialize `t` = $0$, `transmittance` = $(1, 1, 1)$.
3.  Create a ray from $p_1$ to $p_2$.
4.  Sample collision-free distance $s = -\log(\max(1.0 - \text{sampler.getNext1D()}, 0.0)) \times \text{invMajorant}$.
5.  Update `t` += $s$.
6.  If `t` > `distToEnd`, break the loop and return `transmittance`.
7.  Get local density at ray($t$). Compute $\sigma_n = \text{majorant} - \sigma_a - \sigma_s$.
8.  Update `transmittance` *= $(\sigma_n \times \text{invMajorant})$.
9.  Repeat from step 4.

**Pseudocode:**
```python
def ratio_tracking_transmittance(p1, p2, majorant, sigma_a, sigma_s, sampler):
    """
    Estimates transmittance from p1 to p2 using ratio tracking.
    
    Args:
        p1: Start point (Vec3)
        p2: End point (Vec3)
        majorant: Homogenized extinction coefficient (scalar or Vec3)
        sigma_a: Absorption coefficient function (returns scalar or Vec3 at point)
        sigma_s: Scattering coefficient function (returns scalar or Vec3 at point)
        sampler: Sampler object with getNext1D() method
        
    Returns:
        transmittance: Vec3, estimated transmittance
    """
    dist_to_end = length(p2 - p1)
    t = 0.0
    transmittance = Vec3(1.0, 1.0, 1.0)
    
    # Precompute inverse majorant
    inv_majorant = 1.0 / majorant
    
    while True:
        # Sample distance from exponential distribution with rate majorant
        u = sampler.getNext1D()
        # Guard against u=1.0 which causes log(0)
        u = max(u, 0.0)
        u = min(u, 1.0 - 1e-12) # Avoid exact 1.0 if possible, or handle log(0)
        
        s = -log(1.0 - u) * inv_majorant
        t += s
        
        # Check if we have reached or passed the endpoint
        if t > dist_to_end:
            break
            
        # Evaluate densities at current position
        # Note: The source notes imply sigma_n = majorant - sigma_a - sigma_s
        # This corresponds to the null-scattering probability weight.
        # In standard ratio tracking, the weight is (mu_t - mu_a - mu_s) / mu_t
        # which is the probability of a null event.
        
        current_sigma_a = sigma_a(p1 + (t / dist_to_end) * (p2 - p1))
        current_sigma_s = sigma_s(p1 + (t / dist_to_end) * (p2 - p1))
        
        # Compute null-scattering ratio
        # sigma_n represents the "null" part of the majorant
        sigma_n = majorant - current_sigma_a - current_sigma_s
        
        # Update transmittance by multiplying with the null-scattering ratio
        # This accumulates the probability that no real interaction occurred
        transmittance = transmittance * (sigma_n * inv_majorant)
        
    return transmittance
```

**Parameters:**
*   `s`: Number of vertices on the camera subpath (real-scattering) [S2, unofficial].
*   `t`: Number of vertices on the light subpath (real-scattering) [S2, unofficial].
*   $e_x \in \{a, s, n\}$: Event type at vertex $x$ (absorption, scattering, or null-scattering) [S2, unofficial].

**Edge Cases and Pitfalls:**
*   **Precision:** If `sampler.getNext1D()` returns exactly $1.0$, `log(0)` results in infinity. A guard such as `max(1.0 - sampler.getNext1D(), epsilon)` or `min(u, 1.0 - epsilon)` is required [G].
*   **Boundary Conditions:** The loop terminates when `t > distToEnd`. If the majorant is not a true upper bound on the extinction coefficient, the sampling distribution is invalid, leading to biased results [G].
*   **Degenerate Input:** If `majorant` is zero, division by zero occurs. The majorant must be strictly positive [G].

## Operating characteristics
*   **Time Complexity:** Proportional to the expected number of steps, which is $\mu_t \times \text{distance}$. High majorants lead to more steps and higher variance.
*   **Memory Complexity:** $O(1)$ auxiliary memory.
*   **Strengths:** Unbiased estimation of transmittance without early termination. Handles spectrally varying media by tracking ratios per color component [S2, unofficial].
*   **Limitations:** Variance increases with optical thickness and majorant magnitude. Not suitable for very thin media where delta tracking sampling (with termination) might be more efficient.
*   **When to use:** When estimating transmittance for vertex connections in null-scattering path integral formulations, especially in spectrally varying media.
*   **When not to use:** For simple homogeneous media where analytical transmittance is available, or when computational budget is extremely tight and variance can be tolerated.

## Background
Originated in the context of null-scattering path integral formulations for light transport in participating media [S2, unofficial]. The method is part of a framework that connects real-scattering vertices from camera and light subpaths using ratio tracking for transmittance estimation [S2, unofficial]. It addresses the need for unbiased transmittance estimation in complex media where analytical solutions are intractable.
