# Real-scattering vertex connection with ratio tracking

Also called: Delta Tracking for Transmittance Estimation, Ratio Tracking Volumetric Sensor, Real-scattering vertex connection

## Overview
This method estimates the transmittance between two points $p_1$ and $p_2$ in a participating medium using ratio tracking, which accumulates a product of null-scattering ratios rather than terminating on collision [S2, unofficial]. It is used to connect real-scattering vertices on camera and light subpaths within a null-scattering path integral framework [S3, unofficial]. Unlike standard delta tracking which terminates on collision, ratio tracking continues until the endpoint is reached, accumulating a product of ratios to estimate the total transmittance [S2, unofficial].

## How it works
### Inputs and Outputs
**Inputs:**
*   $p_1, p_2$: Start and end points of the connection segment.
*   `sampler`: A random number generator providing uniform samples in $[0, 1)$.
*   `majorant`: The homogenized extinction coefficient $\hat{\mu}_t$ used for ratio tracking sampling [S1, unofficial].
*   `throughput`: The current path throughput, initialized by undoing transmittance from previous interactions [S1, unofficial].
*   `t_prev`: The distance traveled in the previous segment [S1, unofficial].
*   `n_scat`: The number of scattering events in the history, used for throughput weighting [S1, unofficial].
*   `sigma_s`, `sigma_a`, `sigma_t`: The scattering, absorption, and total extinction coefficients at the current position [S1, unofficial].
*   `em`: The emission coefficient at the connection point [S1, unofficial].
*   `bbox`, `voxel_size`, `res`: The bounding box, voxel dimensions, and grid resolution for spatial discretization [S1, unofficial].
*   `film`: The volumetric film buffer for writing contributions [S1, unofficial].
*   `grad_array`: The differentiable array for gradient storage [S1, unofficial].

**Outputs:**
*   `transmittance`: The estimated transmittance product along the segment [S1, unofficial].
*   `contrib`: The volumetric contribution written to the film [S1, unofficial].

### Data Structures
*   **VolumetricFilm**: A tensor of shape `(resz, resy, resx, channels)` where `channels` equals 2 if surface-aware discretization is enabled, else 1 [S1, unofficial].
*   **Container**: Stores medium properties including `sigma_t`, `albedo`, and `medium_phase` [S1, unofficial].

### Steps
1.  **Initialize Throughput and Scattering History**:
    Undo transmittance from previous interactions and adjust for scattering history [S1, unofficial]:
    ```python
    throughput = throughput * exp(sigma_t * t_prev)
    if sigma_s != 0:
        throughput *= rcp(sigma_s ** n_scat)
    ```

2.  **Setup Segment**:
    Calculate the distance to the endpoint: `dist_to_end = length(p2 - p1)` [S1, S2, unofficial].
    Initialize `t = 0.0`, `transmittance = 1.0`, and `n_interactions = 0` [S1, S2, unofficial].

3.  **Ratio Tracking Loop**:
    While the ray is active:
    a.  **Sample Distance**:
        Sample a collision-free distance $s$ using the majorant [S1, S2, unofficial]:
        ```python
        u = clamp(sampler.next_1d(), 0.0, 0.9999999)
        sampled_t = -log(1.0 - u) / majorant
        ```
    b.  **Update Position**:
        Update the accumulated distance $t$ [S1, S2, unofficial]:
        ```python
        t += sampled_t
        ```
    c.  **Check Bounds**:
        Check if the ray has reached the endpoint [S2, unofficial]:
        ```python
        if t >= dist_to_end:
            break
        ```
    d.  **Voxel Lookup**:
        Determine the current voxel index [S1, unofficial]:
        ```python
        pos = p1 + (t / dist_to_end) * (p2 - p1)
        voxel = floor((pos - bbox.min) / voxel_size)
        is_inside = all(voxel >= 0) and all(voxel < res)
        if is_inside:
            idx = voxel[0] * res[1] * res[2] + voxel[1] * res[2] + voxel[2]
            if surface_aware:
                idx *= 2
        ```
    e.  **Update Transmittance**:
        Compute the null-scattering ratio and update the transmittance product [S2, unofficial]:
        ```python
        sigma_n = majorant - sigma_a - sigma_s
        transmittance *= sigma_n / majorant
        n_interactions += 1
        ```
    f.  **Compute Contribution**:
        Calculate the sensor contribution for the connection step [S1, unofficial]:
        ```python
        weight = throughput * exp(-sigma_t * t_prev)
        sa = sigma_t - sigma_s
        st = sigma_t
        contrib = weight * em * (sa / st) * ((1.0 - st / majorant) ** n_interactions) * (st / majorant)
        if is_inside:
            film.write(contrib, idx, True)
        ```
    g.  **Write to Film**:
        In primal mode, write the contribution to the film [S1, unofficial]:
        ```python
        film.write(contrib, idx, is_inside)
        ```

4.  **Automatic Differentiation**:
    *   **Forward Mode**: Scatter the gradient [S1, unofficial]:
        ```python
        grad_array.scatter_reduce(Add, forward_to(contrib), idx, is_inside)
        ```
    *   **Reverse Mode**: Gather the gradient and backpropagate [S1, unofficial]:
        ```python
        grad = grad_array.gather(Spectrum, idx, is_inside)
        backward_from(contrib * grad)
        ```

### Formulas
The path PDF for connecting real-scattering vertices on camera and light subpaths with $s$ and $t$ vertices respectively is [S3, unofficial]:
$$
p_{s,t} (x) = p_{dt} (x_{r_0} ...x_{r_{t-1}}) p_{rt}(x_{r_{t-1}}, x_{r_{r-s+1}}) p_{dt}(x_{r_r} ...x_{r_{r-s+1}})
$$
where $p_{dt}(x)$ is the delta-tracking path PDF [S3, unofficial]:
$$
p_{dt}(x) = p(x_0) \prod_{i=1}^{k} p(\omega_i |x_{i-1}, \omega_{i-1}) p(x_i |x_{i-1}, \omega_i) P(e_{x_i}) \prod_{i=1}^{k-1} G(x_{r_i}, x_{r_i+1})
$$
The transition probabilities are [S3, unofficial]:
$$
p(\omega' |x, \omega) \propto \rho(\omega, x, \omega'), \quad p(y|x, \omega) = T(x, y)\mu_t(y), \quad P(e_x) = \frac{\mu_{e_x}(x)}{\mu_t(x)}
$$
where $e_x \in \{a, s, n\}$ denotes the event type (absorption, scattering, or null-scattering) [S3, unofficial].

For the full path PDF including the connection segment [S3, unofficial]:
$$
p(x) = p_{dt}(x_0 ...x_{r_{r-1}}) p(\omega_r |x_{r_{r-1}}, \omega_{r_{r-1}}) p(x_k) p_{ea}(x_{r_{r-1}}|x_{r_{r-2}}, \omega_{r_{r-1}}, x_k) \cdot p_{rt}(x_{r_{r-2}}, x_{r_{r-1}}) p_{rt}(x_{r_{r-1}}, x_k) G(x_{r_{r-2}}, x_{r_{r-1}})
$$
The equiangular sampling PDF for the connection is [S3, unofficial]:
$$
p_{ea}(x_{r_{r-1}}|x_{r_{r-2}}, \omega_{r_{r-1}}, x_k) \propto G(x_{r_{r-1}}, x_k) = \frac{1}{\|x_{r_{r-1}} - x_k\|^2}
$$

### Parameters
*   `majorant`: The majorant density $\hat{\mu}_t$ used for ratio tracking sampling [S1, S3, unofficial].
*   `s`: Number of vertices on the camera subpath (real-scattering) [S3, unofficial].
*   `t`: Number of vertices on the light subpath (real-scattering) [S3, unofficial].

### Edge Cases and Pitfalls
*   **Precision**: Logarithms of values close to 1 or 0 can cause precision issues, so sampler outputs must be clamped away from 1.0 [S2, unofficial].
*   **Boundaries**: Voxel indices must be validated against grid bounds before accessing data to prevent out-of-bounds memory access [S1, unofficial].
*   **Degenerate Input**: If `sigma_s` is 0, division by zero must be avoided during throughput initialization [S1, unofficial].
*   **Termination**: Ratio tracking must continue until the endpoint is reached, unlike standard delta tracking which stops at the first collision [S2, unofficial].

## Operating characteristics
*   **Time Complexity**: Proportional to the number of ratio tracking steps, which scales with the ratio of the majorant to the local extinction coefficient [S2, unofficial].
*   **Memory Complexity**: Depends on the grid resolution for storing medium properties and the film buffer [S1, unofficial].
*   **Strengths**: Provides unbiased estimation of transmittance in heterogeneous media without requiring spatial coherence or bounding volume hierarchies for acceleration structures [S2, S3, unofficial].
*   **Limitations**: Performance degrades when the majorant is much larger than the local extinction coefficient, causing excessive null-scattering events [S2, unofficial].
*   **When to use**: Use when estimating transmittance between two points in a participating medium within a null-scattering path integral framework, particularly for connecting real-scattering vertices [S3, unofficial].

## Background
This method originates from the null-scattering path integral formulation of light transport [S3, unofficial]. It builds on the concept of ratio tracking introduced for transmittance estimation [S2, unofficial]. The implementation details are documented in the Dr. TVAM project for inverse rendering in volumetric additive manufacturing [S1, unofficial].
