# Ratio Tracking with Null Scattering

Also called: Novák et al. Transmittance Estimation, Ratio Tracking, Ratio-Tracking Transmittance Estimation

## Overview
Ratio tracking is a Monte Carlo variance reduction technique for estimating transmittance in participating media, used primarily within null-scattering frameworks to handle heterogeneous volumes [S1, S3]. Unlike standard delta tracking, which terminates a path with a binary outcome upon collision, ratio tracking continues sampling until the endpoint is reached, accumulating a product of ratios to estimate the total transmittance [S1][S2, unofficial]. This approach avoids the high variance associated with binary visibility tests while maintaining unbiasedness [S3]. It builds on [Delta tracking](985-delta-tracking.md) by replacing the binary Russian roulette termination with a continuous weight update [S3].

## How it works
**Inputs and Outputs:**
*   **Input:** Ray origin $o$, direction $\omega$, maximum distance $t_{max}$ (determined by scene intersection or light source), medium properties (extinction $\sigma_t$, absorption $\sigma_a$, scattering $\sigma_s$, or albedo $a$), and a majorant extinction coefficient $\sigma_m \ge \sigma_t(x)$ for all $x$ in the medium [S1, S4].
*   **Output:** Estimated transmittance $T$ (a Spectrum), and PDFs for Multiple Importance Sampling (MIS) if required [S1, S4].

**Data Structures:**
*   **Spectrum:** A vector of 3 floats (R, G, B) used to store transmittance and PDFs to support chromatic media handling [S1].
*   **Majorant ($\sigma_m$):** A constant or spatially varying upper bound on the extinction coefficient. For chromatic media, $\sigma_m$ is typically a Spectrum where each component is the maximum extinction in that channel [S1].
*   **Null-scattering coefficient ($\sigma_n$):** Defined as $\sigma_n(x) = \max(0, \sigma_m - \sigma_t(x))$ [S4].

**Parameters:**
*   `max_null_collisions`: Maximum iterations to prevent infinite loops due to numerical error. Default: 1000 [S1].
*   `termination_threshold`: Threshold for Russian roulette. Default: 0.05 [S4].
*   `q`: Russian roulette termination probability. Default: 0.75 [S4].
*   `ShadowEpsilon`: Small epsilon subtracted from 1.0 to define max distance, preventing self-intersection [S4].

**Steps:**
1.  **Initialize:** Set transmittance accumulator $T_{ray} = 1.0$, rescaled path probabilities $r_l = 1.0$ (for unidirectional sampling) and $r_u = 1.0$ (for light sampling), and PDFs `trans_dir_pdf` and `trans_nee_pdf` to 1.0 [S1, S4]. Initialize RNG with hash of ray origin and direction [S4].
2.  **Determine Bounds:** Compute $t_{min}$ and $t_{max}$ for the ray segment within the medium. If no surface intersection is found, $t_{max}$ is determined by the light source distance minus `ShadowEpsilon` [S4].
3.  **Sample Channel:** For chromatic media, sample a single color channel (R, G, or B) using a uniform random number $u \in [0,1]$ to select the channel [S1].
4.  **Sample Distance:** Sample a distance $t$ from the majorant distribution for the selected channel: $t = -\log(1-u)/\sigma_m[\text{channel}]$ [S1].
5.  **Check Endpoint:** If $t \ge t_{max}$ (or accumulated distance reaches $t_{max}$), update transmittance for the final segment and break the loop [S1, S4].
6.  **Evaluate Null Scattering:** At the sampled point, compute the null-scattering coefficient $\sigma_n = \max(0, \sigma_m - \sigma_a - \sigma_s)$ [S4].
7.  **Update Accumulators:**
    *   Compute the PDF of the majorant sampling at the point: $pdf = T_{maj}[0] \times \sigma_{maj}[0]$ [S4].
    *   Update transmittance: $T_{ray} *= T_{maj} \times \frac{\sigma_n}{pdf}$ [S4].
    *   Update rescaled probabilities: $r_l *= T_{maj} \times \frac{\sigma_{maj}}{pdf}$ and $r_u *= T_{maj} \times \frac{\sigma_n}{pdf}$ [S4].
    *   Update PDFs for MIS: `trans_dir_pdf` and `trans_nee_pdf` are updated similarly to account for the decision to continue (null scattering) vs. terminate (real scattering) [S1, S4].
    *   **Normalization:** Divide $T_{ray}$ and PDFs by $\max(\sigma_m)$ if a null scattering event occurs to prevent numerical blow-up [S1].
8.  **Russian Roulette:** Compute test value $Tr = T_{ray} / (r_l + r_u).Average()$. If $Tr.MaxComponentValue() < 0.05$, terminate with probability $q=0.75$ (setting $T_{ray}=0$) or survive with probability $1-q$ (dividing $T_{ray}$ by $1-q$) [S4].
9.  **Finalize:** After the loop, update accumulators for the final segment from the last sampled point to $t_{max}$ by multiplying by $\frac{T_{maj}}{T_{maj}[0]}$ [S4]. Return $T_{ray}$ [S3].

**Pseudocode:**
```python
import math

class Spectrum:
    def __init__(self, r, g, b):
        self.v = [r, g, b]
    def __mul__(self, other):
        if isinstance(other, Spectrum):
            return Spectrum(self.v[0]*other.v[0], self.v[1]*other.v[1], self.v[2]*other.v[2])
        return Spectrum(self.v[0]*other, self.v[1]*other, self.v[2]*other)
    def __truediv__(self, other):
        if isinstance(other, Spectrum):
            return Spectrum(self.v[0]/other.v[0], self.v[1]/other.v[1], self.v[2]/other.v[2])
        return Spectrum(self.v[0]/other, self.v[1]/other, self.v[2]/other)
    def max_component_value(self):
        return max(self.v)
    def average(self):
        return sum(self.v) / 3.0

def ratio_tracking(ray_origin, ray_direction, t_max, medium, rng):
    # 1. Initialize
    T_ray = Spectrum(1.0, 1.0, 1.0)
    r_l = Spectrum(1.0, 1.0, 1.0)
    r_u = Spectrum(1.0, 1.0, 1.0)
    trans_dir_pdf = Spectrum(1.0, 1.0, 1.0)
    trans_nee_pdf = Spectrum(1.0, 1.0, 1.0)
    t = 0.0
    iteration = 0
    max_null_collisions = 1000
    termination_threshold = 0.05
    q = 0.75
    ShadowEpsilon = 1e-4

    # 2. Determine Bounds
    surface_hit = medium.get_surface_intersection(ray_origin, ray_direction)
    t_max = min(surface_hit, 1.0 - ShadowEpsilon) if surface_hit else 1.0 - ShadowEpsilon
    if t_max <= t:
        return Spectrum(1.0, 1.0, 1.0)

    while True:
        # 3. Sample Channel
        u = rng.uniform()
        channel = int(u * 3) % 3

        sigma_m = medium.get_majorant()
        if sigma_m.v[channel] <= 0 or iteration >= max_null_collisions:
            break

        # 4. Sample Distance
        t_step = -math.log(1.0 - rng.uniform()) / sigma_m.v[channel]
        dt = t_max - t

        if t_step < dt:
            # 5 & 6. Null scattering event
            sigma_t = medium.get_extinction(ray_origin + ray_direction * (t + t_step))
            sigma_a = medium.get_absorption(ray_origin + ray_direction * (t + t_step))
            sigma_s = medium.get_scattering(ray_origin + ray_direction * (t + t_step))
            sigma_n = Spectrum(max(0.0, sigma_m.v[0] - sigma_t.v[0] - sigma_s.v[0]),
                               max(0.0, sigma_m.v[1] - sigma_t.v[1] - sigma_s.v[1]),
                               max(0.0, sigma_m.v[2] - sigma_t.v[2] - sigma_s.v[2]))

            T_maj = Spectrum(math.exp(-sigma_m.v[0] * t_step),
                             math.exp(-sigma_m.v[1] * t_step),
                             math.exp(-sigma_m.v[2] * t_step))
            pdf = T_maj.v[0] * sigma_m.v[0]  # Scalar PDF for sampled channel

            # 7. Update Accumulators
            T_ray = T_ray * T_maj * sigma_n / pdf
            r_l = r_l * T_maj * sigma_m / pdf
            r_u = r_u * T_maj * sigma_n / pdf
            trans_dir_pdf = trans_dir_pdf * T_maj * sigma_m * (1.0 - sigma_t / sigma_m) / Spectrum(max(sigma_m.v), max(sigma_m.v), max(sigma_m.v))
            trans_nee_pdf = trans_nee_pdf * T_maj * sigma_m / Spectrum(max(sigma_m.v), max(sigma_m.v), max(sigma_m.v))

            if T_ray.max_component_value() <= 0.0:
                break
        else:
            # Reached endpoint
            T_maj = Spectrum(math.exp(-sigma_m.v[0] * dt),
                             math.exp(-sigma_m.v[1] * dt),
                             math.exp(-sigma_m.v[2] * dt))
            T_ray = T_ray * T_maj
            trans_dir_pdf = trans_dir_pdf * T_maj
            trans_nee_pdf = trans_nee_pdf * T_maj
            break

        t += t_step
        iteration += 1

        # 8. Russian Roulette
        Tr = T_ray / (r_l + r_u).average()
        if Tr.max_component_value() < termination_threshold:
            if rng.uniform() < q:
                T_ray = Spectrum(0.0, 0.0, 0.0)
                break
            else:
                T_ray = T_ray / (1.0 - q)

    # 9. Finalize
    final_dt = t_max - t
    T_final_maj = Spectrum(math.exp(-sigma_m.v[0] * final_dt),
                           math.exp(-sigma_m.v[1] * final_dt),
                           math.exp(-sigma_m.v[2] * final_dt))
    T_ray = T_ray * T_final_maj / Spectrum(T_final_maj.v[0], T_final_maj.v[0], T_final_maj.v[0])
    r_l = r_l * T_final_maj / Spectrum(T_final_maj.v[0], T_final_maj.v[0], T_final_maj.v[0])
    r_u = r_u * T_final_maj / Spectrum(T_final_maj.v[0], T_final_maj.v[0], T_final_maj.v[0])

    return T_ray
```

**Edge Cases and Pitfalls:**
*   **Determine Bounds:** Compute $t_{min}$ and $t_{max}$ for the ray segment within the medium. If no surface intersection is found, $t_{max}$ is determined by the light source distance minus `ShadowEpsilon` [S4].
*   **Russian Roulette:** Compute test value $Tr = T_{ray} / (r_l + r_u).Average()$. If $Tr.MaxComponentValue() < 0.05$, terminate with probability $q=0.75$ (setting $T_{ray}=0$) or survive with probability $1-q$ (dividing $T_{ray}$ by $1-q$) [S4].
*   **Numerical Instability:** Without normalization, transmittance and PDF values can blow up because $\sigma_n$ can be large. Solution: Divide both transmittance and PDF by $\max(\sigma_m)$ whenever a fake particle is hit [S1].
*   **Chromatic Media:** PDFs must be stored as `Spectrum` types to track individual channel probabilities for MIS. The final PDF used for estimation is the average of the channel PDFs [S1].
*   **Infinite Loops:** Numerical errors can lead to unbounded loops. A maximum iteration count (`max_null_collisions`) is required [S1].

## Subtopics

### [Real-scattering vertex connection with ratio tracking](1766-real-scattering-vertex-connection-with-ratio-tracking.md)
Estimates the transmittance between two points $p_1$ and $p_2$ in a participating medium using ratio tracking, which accumulates a product of null-scattering ratios rather than terminating on collision. Unlike delta tracking for sampling which terminates on collision, ratio tracking continues until the endpoint is reached, accumulating a product of ratios to estimate the total transmittance. This method serves as the transmittance estimation component within the broader real-scattering vertex connection framework, where it connects real-scattering vertices from camera and light subpaths.

### [Homogenized Next Event Estimation (Exponential Integrator)](1136-homogenized-next-event-estimation-exponential-integrator.md)
A method to estimate transmittance for next event estimation in heterogeneous volumes by applying a change of variable to the transmittance integral, avoiding the slow convergence of direct Monte Carlo integration of the exponential. It transforms the transmittance ODE $\frac{dT}{dt'} = -\sigma_t T$ into $\frac{d}{dt'} \tilde{T} = \sigma_n \tilde{T}$ via change of variable $\tilde{T} = e^{\sigma_m t} T$, allowing Monte Carlo estimation of the integral without direct exponentiation. Unbiased estimation of $\exp(X)$ is invalid because $E[\exp(X)] \neq \exp(E[X])$, necessitating this homogenization approach. Integrating both sides of the original ODE yields a slow-converging integral, making the homogenized version preferred.

## Operating characteristics
*   **Time Complexity:** Proportional to the number of null scattering events sampled along the ray segment [S4].
*   **Memory Complexity:** Low. Requires storing only the current transmittance, PDFs, and medium properties at sampled points [S1, S4].
*   **Measured Performance:** Reduces variance compared to standard delta tracking, as shown in comparative images with 25 samples per pixel [S2, unofficial]. However, it increases the number of scattering events per path because paths are not terminated on absorption, leading to slower rendering times in some scenarios [S2, unofficial].
*   **Strengths:** Unbiased, low-variance estimator for transmittance in heterogeneous media [S3]. Handles spectral variations and MIS weights efficiently [S4]. Avoids binary visibility issues [S1].
*   **Limitations:** Slower than delta tracking in terms of raw throughput due to increased path lengths [S2, unofficial]. Requires careful handling of numerical stability [S1].
*   **When to Use:** When low variance is critical and the medium is heterogeneous [S3, S4]. When using null-scattering path tracing frameworks [S5, unofficial].
*   **When Not to Use:** When performance is paramount and high variance is acceptable (use standard delta tracking) [S2, unofficial][S4]. When the medium is homogeneous (analytical transmittance is available) [S5, unofficial].

## Background
Ratio tracking was introduced by Novák et al. in 2014 as a method to solve the recursive integral equation for transmittance in participating media [S3]. It was developed to address the high variance of binary Russian roulette estimators used in standard delta tracking [S3]. The method is a key component of null-scattering formulations, which augment the medium with fictitious scattering matter to enable analytic sampling of transmittance in heterogeneous volumes [S5, unofficial]. It is widely used in modern volumetric path tracers, such as those described in the PBRT books and various academic implementations [S1, S4].
