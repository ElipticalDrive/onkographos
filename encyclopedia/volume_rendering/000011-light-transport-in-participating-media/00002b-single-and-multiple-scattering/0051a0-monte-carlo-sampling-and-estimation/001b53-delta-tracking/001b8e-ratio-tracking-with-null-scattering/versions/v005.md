# Ratio Tracking with Null Scattering

Also called: Novák et al. Transmittance Estimation, Ratio Tracking, Ratio-Tracking Transmittance Estimation

## Overview
Ratio tracking with null scattering is a Monte Carlo method for estimating transmittance in participating media that avoids the high variance of binary visibility tests by accumulating a continuous product of null-scattering ratios [S2, unofficial][S3]. Unlike standard delta tracking, which terminates paths upon real scattering or absorption events, ratio tracking continues sampling along the ray, multiplying the estimate by the ratio of actual to majorant extinction at each step, thereby providing an unbiased, low-variance estimator for heterogeneous media [S3, S4].

## How it works
**Inputs and Outputs:**
- **Input:** Ray origin $o$, direction $\omega$, parametric bounds $[t_{min}, t_{max}]$, medium properties (extinction $\sigma_t$, absorption $\sigma_a$, scattering $\sigma_s$, or albedo $a$), and a majorant extinction coefficient $\sigma_m \ge \sigma_t(x)$ for all $x$ in the medium [S1, S4].
- **Output:** Estimated transmittance $T$ (Spectrum), and optionally PDFs for Multiple Importance Sampling (MIS) [S1, S4].

**Data Structures:**
- **Spectrum:** A vector of 3 floats (R, G, B) used to track transmittance and PDFs independently per channel [S1, S4].
- **Majorant ($\sigma_m$):** A constant Spectrum representing the upper bound of the extinction coefficient [S1, S4].
- **Null Scattering Coefficient ($\sigma_n$):** Computed as $\sigma_n = \max(0, \sigma_m - \sigma_t)$ [S4].

**Parameters:**
- **max_null_collisions:** Integer limit to prevent infinite loops from numerical errors. Default: 1000 [S1].
- **RR Threshold:** Float threshold for Russian roulette. Default: 0.05 [S4].
- **RR Survival Probability:** Float $1-q$. Default: 0.25 (termination probability $q=0.75$) [S4].
- **ShadowEpsilon:** Small float subtracted from 1.0 to define max ray distance, preventing self-intersection [S4].

**Steps:**
1. **Initialize:** Set transmittance accumulator $T_{ray} = 1.0$, rescaled path probabilities $r_l = 1.0$ (for unidirectional/delta tracking PDF) and $r_u = 1.0$ (for null scattering/NEE PDF). Initialize RNG with hash of ray origin and direction [S4].
2. **Sample Channel:** Generate uniform random $u \in [0,1]$. Select channel $c = \text{clamp}(\lfloor u \times 3 \rfloor, 0, 2)$ for distance sampling [S1].
3. **Loop:** While iteration count $< \text{max\_null\_collisions}$:
    a. **Sample Distance:** Sample free path distance $t$ using the majorant for the selected channel: $t = -\ln(1 - \text{rng}()) / \sigma_m[c]$ [S1, S4].
    b. **Check Bounds:** Calculate remaining distance $dt = t_{max} - t_{current}$. If $t \ge dt$, the ray reaches the endpoint/surface. Update $T_{ray} *= \exp(-\sigma_m \cdot dt)$, update PDFs, and break loop [S1, S4].
    c. **Compute Null Coefficient:** At position $x_t$, compute $\sigma_n = \max(0, \sigma_m - \sigma_a - \sigma_s)$ [S4].
    d. **Update Estimators:**
       - Compute PDF of majorant sampling: $pdf = T_{maj}[0] \times \sigma_m[0]$ (where $T_{maj}$ is the majorant transmittance $\exp(-\sigma_m t)$) [S4].
       - Update transmittance: $T_{ray} *= T_{maj} \times \frac{\sigma_n}{pdf}$ [S4].
       - Update rescaled probabilities: $r_l *= T_{maj} \times \frac{\sigma_m}{pdf}$ and $r_u *= T_{maj} \times \frac{\sigma_n}{pdf}$ [S4].
    e. **Russian Roulette:** Compute test value $Tr = T_{ray} / (r_l + r_u).\text{Average()}$. If $\max(Tr) < 0.05$, terminate with probability $q=0.75$ (set $T_{ray}=0$) or survive with probability $1-q$ (divide $T_{ray}$ by $1-q$) [S4].
    f. **Advance:** Update $t_{current} += t$ [S4].
4. **Final Segment:** After the loop, update accumulators for the final segment from the last sampled point to $t_{max}$ by multiplying by $\frac{T_{maj}}{T_{maj}[0]}$ [S4].
5. **Return:** Return $T_{ray}$ normalized by the average PDFs if used for MIS [S1, S4].

**Pseudocode:**
```python
def ratio_tracking(ray_origin, ray_direction, t_min, t_max, medium, sigma_maj, rng):
    """
    Estimates transmittance using ratio tracking with null scattering.
    """
    # Initialize accumulators
    T_ray = Spectrum(1.0)
    r_l = Spectrum(1.0)  # PDF for unidirectional sampling
    r_u = Spectrum(1.0)  # PDF for null scattering/NEE
    
    # Initialize RNG with ray hash
    rng.seed(hash(ray_origin) + hash(ray_direction))
    
    t_current = t_min
    iteration = 0
    max_null_collisions = 1000
    
    while iteration < max_null_collisions:
        # 1. Sample a color channel for distance sampling
        u = rng.uniform(0.0, 1.0)
        channel = clamp(int(u * 3), 0, 2)
        
        # 2. Sample distance using majorant
        if sigma_maj[channel] <= 0:
            break
            
        t = -log(1.0 - rng.uniform(0.0, 1.0)) / sigma_maj[channel]
        
        # 3. Check if we reached the end of the segment
        dt = t_max - t_current
        if t >= dt:
            # Reached surface/endpoint
            T_maj = exp(-sigma_maj * dt)
            T_ray *= T_maj
            r_l *= T_maj
            r_u *= T_maj
            break
            
        # 4. Update accumulated distance
        t_current += t
        
        # 5. Compute null scattering coefficient at current position
        # sigma_n = max(0, sigma_maj - sigma_a - sigma_s)
        sigma_n = clamp_zero(sigma_maj - medium.get_sigma_a() - medium.get_sigma_s())
        
        # 6. Compute PDF of the majorant sampling
        # T_maj is the transmittance over the sampled distance t
        T_maj = exp(-sigma_maj * t)
        pdf = T_maj[0] * sigma_maj[0]
        
        # 7. Update transmittance and rescaled probabilities
        # Note: Division by pdf normalizes the ratio tracking estimator
        T_ray *= T_maj * (sigma_n / pdf)
        r_l *= T_maj * (sigma_maj / pdf)
        r_u *= T_maj * (sigma_n / pdf)
        
        # 8. Russian Roulette for low transmittance
        # Compute test value using MIS weights
        avg_pdf = (r_l + r_u).average()
        if avg_pdf[0] > 0:
            Tr = T_ray / avg_pdf
        else:
            Tr = Spectrum(0.0)
            
        if Tr.max_component_value() < 0.05:
            q = 0.75
            if rng.uniform(0.0, 1.0) < q:
                T_ray = Spectrum(0.0)
                break
            else:
                T_ray /= (1.0 - q)
                
        iteration += 1
        
    # 9. Update for final segment (if loop broke early or for last segment logic)
    # In some implementations, this handles the segment from last sample to t_max
    # if the loop didn't break on 't >= dt' but on max iterations.
    # However, standard ratio tracking usually breaks on endpoint.
    # If using the callback structure from [S4], this update happens inside SampleT_maj.
    
    return T_ray
```

**Edge Cases and Pitfalls:**
- **Numerical Instability:** Without normalization, transmittance and PDF values can explode because $\sigma_n$ can be large. The method divides by $\max(\sigma_m)$ (implicitly via the PDF ratio) to maintain robustness [S1].
- **Chromatic Media:** Distance sampling uses a single channel, but PDFs are tracked for all channels to enable MIS. The final estimate uses the average of channel PDFs [S1].
- **Russian Roulette:** Setting survival probability equal to transmittance transforms the method into delta tracking (binary 0/1 outcome), losing variance reduction benefits. A fixed, less aggressive probability ($q=0.75$) is used [S4].
- **Infinite Loops:** Numerical errors can cause unbounded loops. A maximum iteration count (1000) is enforced [S1].

## Subtopics

### [Real-scattering vertex connection with ratio tracking](1766-real-scattering-vertex-connection-with-ratio-tracking.md)
This method estimates transmittance between two points in a participating medium using ratio tracking to connect real-scattering vertices in a path integral framework. Unlike delta tracking which terminates on collision, ratio tracking continues until the endpoint is reached, accumulating a product of ratios to estimate total transmittance. It is chosen when connecting vertices in null-scattering path tracing to avoid binary visibility variance.

### [Weighted Next-Fight Estimator](9226-weighted-next-fight-estimator.md)
The Weighted Next-Fight Estimator is a Monte Carlo method for estimating transmittance using null scattering that explicitly adds the transmittance through the rest of the combined medium at each step. It is distinguished from Real-scattering vertex connection by correcting for initial underestimation of uncollided radiance via a modified RTE.

### Homogenized Next Event Estimation (Exponential Integrator)
A method to estimate transmittance for next event estimation by solving an ODE derived from the transmittance definition, avoiding unbiased estimation of exponentials [S1]. It transforms the transmittance ODE $\frac{dT}{dt'} = -\sigma_t T$ into $\frac{d}{dt'} \tilde{T} = \sigma_n \tilde{T}$ to enable Monte Carlo sampling [S1]. It is used when unbiased estimation of $\exp(X)$ is invalid due to Jensen's inequality [S1].

## Operating characteristics
- **Time Complexity:** Proportional to the number of null scattering events, which depends on the ratio $\sigma_n / \sigma_m$. In highly heterogeneous media with tight majorants, performance approaches that of delta tracking [S4].
- **Memory Complexity:** Low, requiring only storage for the transmittance accumulator, PDFs, and current position [S1, S4].
- **Variance:** Significantly lower than binary delta tracking for transmittance estimation, as it avoids the high variance of Russian roulette termination on absorption [S2, unofficial][S3].
- **Strengths:** Unbiased, handles heterogeneous media efficiently, reduces noise in transmittance estimation [S3, S4].
- **Limitations:** Can be slower than delta tracking if the number of scattering events increases significantly due to non-termination on absorption [S2, unofficial]. Requires careful tuning of Russian roulette parameters to avoid bias [S4].
- **When to Use:** When accurate, low-variance transmittance estimation is required in heterogeneous media, especially for next-event estimation or vertex connection in path tracing [S1, S3].
- **When Not to Use:** When computational speed is prioritized over variance reduction and the medium is homogeneous or has a very loose majorant [S2, unofficial].

## Background
Ratio tracking was originally analyzed by Cramer in 1978 [S6]. It was reinvented and studied by Novák et al. in 2014 in the context of rendering, where it was applied to transmittance estimation in participating media [S6]. The method is a key component of null-scattering path integral formulations, enabling unbiased light transport in heterogeneous volumes [S5, unofficial].
