# Path Integral Framework

Also called: PI approach, Path Integral, Path Integral Formulation, Path Space Formulation

## Overview
The Path Integral Framework formulates light transport simulation as a Monte Carlo integration problem over the space of light transport paths, serving as the basis for combining photon density estimation and Monte Carlo path integration [S1]. It expresses the image pixel intensity as an integral over the space of all possible paths connecting light sources to the eye sensor, where each path's contribution is weighted by its transmittance and scattering properties [S1][S2]. It differs from standard path tracing by treating the transport process as a sum over transfer events along many different paths subject to boundary conditions, allowing for analytical approximations like the Most Probable Path (MPP) and WKB expansions in participating media [S2].

## How it works
**Inputs:**
*   Light source distribution (emitted radiance $L_e$).
*   Scene geometry and participating media properties (extinction, scattering, phase functions).
*   Sensor properties (sensitivity $W_e$).
*   Path length constraints (maximum number of vertices $k$).

**Outputs:**
*   Estimated pixel intensity $I$.

**Data Structures:**
*   **Path $\mathbf{x}$**: A sequence of vertices $\mathbf{x}_0, \dots, \mathbf{x}_k$.
    *   $\mathbf{x}_0$: Vertex on a light source.
    *   $\mathbf{x}_k$: Vertex on the eye sensor.
    *   $\mathbf{x}_1 \dots \mathbf{x}_{k-1}$: Intermediate vertices on surfaces and/or in media.
    *   $k \ge 1$: Number of segments.
*   **Differential Path Measure $d\mu(\mathbf{x})$**: A product measure corresponding to area integration for surface vertices and volume integration for medium vertices [S1].

**Formulas:**
The pixel intensity $I$ is the integral of the measurement contribution function $f(\bar{\mathbf{x}})$ over the path space $\Omega$:
$$ I = \int_{\Omega} f(\bar{\mathbf{x}}) d\mu(\bar{\mathbf{x}}) $$

The measurement contribution function is defined as [S1]:
$$ f(\bar{\mathbf{x}}) = L_e(\mathbf{x}_0) T(\bar{\mathbf{x}}) W_e(\mathbf{x}_k) $$

The path throughput $T(\bar{\mathbf{x}})$ is the product of geometry and transmittance terms for path segments, and scattering functions for inner path vertices [S1]:
$$ T(\bar{\mathbf{x}}) = \left[ \prod_{i=0}^{l-1} G(\mathbf{x}_i, \mathbf{x}_{i+1}) T_{\mathbf{r}}(\mathbf{x}_i, \mathbf{x}_{i+1}) \right] \left[ \prod_{i=1}^{l-1} \rho(\mathbf{x}_i) \right] $$

Where:
*   $G(\mathbf{x}_i, \mathbf{x}_{i+1})$ is the geometry term for a path segment.
*   $T_{\mathbf{r}}(\mathbf{x}_i, \mathbf{x}_{i+1})$ is the transmittance between vertices.
*   $\rho(\mathbf{x}_i)$ is the scattering function at vertex $\mathbf{x}_i$.
*   $l$ is the number of segments in the path.

In the context of the Path Integral approach for participating media, the propagator $G$ is expressed as an integral over path space using an effective attenuation $\tau$ [S2]:
$$ G \sim \int \exp(-\tau(path)) \mathcal{D}x $$

The attenuation $\tau$ is analogous to the classical action $A$, such that $\exp(-\tau(path)) \sim \exp(-A(path))$ [S2]. For multiple scattering, a portion of the path weight/action is proportional to [S2]:
$$ \exp\left(-\int_0^s \left[a(\vec{\gamma}_P(s')) + \frac{\alpha}{b(\vec{\gamma}_P(s'))} \left|\frac{d\theta}{ds'}\right|^2\right] ds'\right) $$

Where:
*   $\vec{\gamma}(s)$ is a path length parameterized path.
*   $d\theta/ds$ is the curvature of the path.
*   $\alpha = 1/(4(1-g)) = 1/(2\langle h\theta^2 \rangle)$, where $\langle h\theta^2 \rangle$ is the mean square scattering angle.

**Steps:**
1.  **Define Path Space**: Identify the space $\Omega$ of all light transport paths connecting light sources to the sensor. A path $\mathbf{x}$ consists of $k+1$ vertices $\mathbf{x}_0 \dots \mathbf{x}_k$ with $k \ge 1$ segments [S1].
2.  **Construct Path Measure**: Define the differential path measure $d\mu(\mathbf{x})$ as a product of area and volume integration measures for surface and medium vertices, respectively [S1].
3.  **Calculate Path Contribution**: For a given path, compute the measurement contribution function $f(\bar{\mathbf{x}})$ by multiplying the emitted radiance $L_e(\mathbf{x}_0)$, the path throughput $T(\bar{\mathbf{x}})$, and the detector sensitivity $W_e(\mathbf{x}_k)$ [S1].
4.  **Integrate**: Compute the integral of $f(\bar{\mathbf{x}})$ over the path space to obtain the pixel intensity [S1]. Alternatively, in the PI formulation for propagators, integrate $\exp(-\tau(path))$ over the path space measure $\mathcal{D}x$ [S2].
5.  **Approximation (Optional)**: If using the MPP/WKB approach, find the Most Probable Path (MPP) that minimizes attenuation/action. Restrict the integral to paths "around" the MPP, expanding the integrand from square terms to yield a Gaussian form [S2].

**Parameters:**
*   $\tau$: Effective attenuation along the path. Analogous to classical action [S2].
*   $\alpha$: Scattering parameter, $\alpha = 1/(4(1-g))$ [S2].
*   $g$: Asymmetry factor of the phase function (implied by $\alpha$ definition) [S2].

**Edge Cases and Pitfalls:**
*   The integration is performed over an infinite-dimensional path space using a highly non-intuitive differential measure $\mathcal{D}x$, making the mathematics exceptionally complex [S2].
*   The assumption that only a small fraction of paths "around" the MPP contribute significantly may not hold for all media or boundary conditions [S2].
*   Exact backscattering, which can return photons to the same path, is generally ignored in the simple PI formulation [S2].

## Subtopics

### [Surrounding Path Contribution (WKB Expansion)](1300-surrounding-path-contribution-wkb-expansion.md)
Approximates the path integral by considering only paths surrounding the Most Probable Path (MPP), exploiting the global minimum of the action function to yield a Gaussian weighting. Choose when analytical approximation of the path integral is feasible and the MPP dominates the contribution.

### [Null-Scattering Path Integral Framework](3070-null-scattering-path-integral-framework.md)
Formulates light transport as a Monte Carlo integration over a generalized path space including null-scattering vertices, enabling rigorous measure definition in heterogeneous media. Choose when applying variance reduction techniques like MIS or bidirectional integrators in heterogeneous media where standard delta tracking does not fit naturally.

## Operating characteristics
*   **Complexity**: The mathematical complexity is high due to integration over infinite-dimensional path space with non-intuitive measures [S2].
*   **Performance**: Not given in the sources.
*   **Strengths**: Provides a unified framework for combining photon density estimation and Monte Carlo path integration [S1]. Allows for analytical approximations (MPP, WKB) that can account for blurring characteristics of participating media [S2].
*   **Limitations**: The infinite-dimensional nature of the path space and complex measure make direct implementation difficult without approximations [S2]. The MPP approximation relies on the assumption that surrounding paths dominate, which may not always be valid.
*   **When to use**: When a unified theoretical framework is needed or when analytical approximations like MPP are applicable.
*   **When not to use**: When high accuracy is required in complex heterogeneous media without the ability to approximate using MPP, or when computational resources are limited and simpler estimators are sufficient.

## Background
The Path Integral Framework was introduced by Veach [1997] and Pauly et al. [2000] as a way to express image pixel intensity as an integral over the space of light transport paths [S1]. The approach is based on the observation that energy transfer can be viewed as a sum over transfer events along many different paths connecting start and end points, subject to boundary conditions [S2]. Tessendorf [Tes89] derived a path integral expression for the propagator in homogeneous materials, with further work by [Tes91, Tes92] [S2]. The MPP and WKB expansion concepts are discussed in [S2], referencing classical path integral theory [LRT82] and Euler-Lagrange minimization [Fox87].
