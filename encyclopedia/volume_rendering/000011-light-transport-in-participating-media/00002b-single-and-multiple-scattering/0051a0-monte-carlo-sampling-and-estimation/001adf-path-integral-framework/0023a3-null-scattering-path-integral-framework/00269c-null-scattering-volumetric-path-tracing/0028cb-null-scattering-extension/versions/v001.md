# Null-Scattering Extension

Also called: Homogenized density sampling, Null-scattering integral equation of transfer

## Overview
The Null-Scattering Extension generalizes the equation of transfer to enable unbiased sampling from a modified transmittance equation using a constant majorant extinction coefficient [S1]. It solves the problem of efficiently sampling interaction points in sparse or heterogeneous media by homogenizing the density to a fixed majorant $\sigma_{maj}$, allowing algorithms like delta tracking to function correctly [S1]. It differs from standard delta tracking by explicitly maintaining a majorant transmittance factor $T_{maj}$ and applying Russian Roulette based on the ratio of null density to the majorant, ensuring unbiased estimates even when the majorant significantly overestimates the physical extinction [S1].

## How it works
**Inputs:**
- Position $p$ and direction $\omega$ at which radiance $L_i(p, \omega)$ is evaluated.
- Start point $p_s$ and outgoing radiance $L_o(p_s, -\omega)$.
- Distance $t$ along the ray.
- Extinction coefficient $\sigma_t(p)$, absorption coefficient $\sigma_a(p)$, and scattering coefficient $\sigma_s(p)$ at any point $p$.
- Majorant extinction coefficient $\sigma_{maj}$, a constant value such that $\sigma_{maj} \ge \sigma_t(p)$ for all $p$ in the medium.

**Outputs:**
- Incident radiance $L_i(p, \omega)$.

**Data Structures:**
- No specific complex data structures are required beyond standard scalar fields for $\sigma_t, \sigma_a, \sigma_s$. The method relies on the constant $\sigma_{maj}$.

**Steps:**
1. **Assumptions:** Assume scattering coefficients $\sigma$ do not vary as a function of direction [S1]. Assume the null-scattering coefficient $\sigma_n$ is nonnegative and set to homogenize the medium's density to a fixed majorant $\sigma_{maj} = \sigma_n + \sigma_t$ [S1].
2. **Calculate Majorant Transmittance:** Compute the transmittance from a point $p'$ to $p$ using the majorant coefficient. Let $d$ be the distance between $p'$ and $p$. The majorant transmittance is:
   $$ T_{maj}(p' \to p) = e^{-\sigma_{maj} d} $$
   This accounts for both regular attenuation and null scattering [S1].
3. **Calculate Null-Scattering Source Function:** Compute the null-scattering source function $L_n(p, \omega)$. This is defined as the standard source function $L_s^*(p, \omega)$ plus a new third term [S1]:
   $$ L_n(p, \omega) = \frac{\sigma_a(p)}{\sigma_{maj}} L_e(p, \omega) + \frac{\sigma_s(p)}{\sigma_{maj}} \int_{4\pi} f_s(p, \omega', \omega) L_i(p, \omega') d\omega' + \frac{\sigma_n(p)}{\sigma_{maj}} L_i(p, \omega) $$
   Where:
   - $L_e(p, \omega)$ is the emitted radiance.
   - $f_s(p, \omega', \omega)$ is the scattering phase function.
   - $\sigma_n(p) = \sigma_{maj} - \sigma_t(p)$ is the null-scattering coefficient [S1].
4. **Evaluate Integral Equation:** Compute the incident radiance using the null-scattering integral equation of transfer:
   $$ L_i(p, \omega) = T_{maj}(p_s \to p) L_o(p_s, -\omega) + \sigma_{maj} \int_0^t T_{maj}(p' \to p) L_n(p', -\omega) dt' $$
   Here, $p'$ is a point along the ray segment from $p_s$ to $p$ [S1].

    Computes incident radiance L_i(p, omega) using the null-scattering extension.
    
    Args:
        p_s: Start point of the ray segment.
        omega: Direction of the ray.
        t: Distance along the ray to the evaluation point p.

        get_sigma_a(p): Function returning absorption coefficient at p.

    """
    p = p_s + t * omega
    
    # Step 1: Calculate Majorant Transmittance from p_s to p
    # T_maj(p_s -> p) = exp(-sigma_maj * t)
    T_maj_start = math.exp(-sigma_maj * t)

**Parameters:**
- $\sigma_{maj}$: The majorant coefficient, a constant value used to homogenize the medium density, defined as $\sigma_{maj} = \sigma_n + \sigma_t$ [S1].

**Edge Cases and Pitfalls:**
- $\sigma_{maj}$ must be greater than or equal to $\sigma_t(p)$ for all $p$ in the medium. If not, $\sigma_n$ becomes negative, violating the assumption [S1].
- The scattering term in $L_n$ requires an integral over all directions, which can be computationally expensive if not handled by the sampling strategy [S1].

## Subtopics

## Operating characteristics
- **Time Complexity:** Depends on the integration method for the scattering term. If using delta tracking, the number of steps depends on the ratio $\sigma_t / \sigma_{maj}$.
- **Memory Complexity:** Low, as it only requires storing the majorant coefficient and standard coefficient fields.
- **Strengths:** Allows unbiased estimation in heterogeneous media using simple sampling strategies like delta tracking [S1].
- **Limitations:** Requires finding a valid majorant $\sigma_{maj}$, which can be difficult for highly heterogeneous media. The scattering term still requires angular integration [S1].

## Background
The null-scattering extension was introduced as a generalization of the equation of transfer to allow sampling from a modified transmittance equation [S1]. It enables unbiased estimates of transmittance between two points using algorithms like delta tracking and ratio tracking [S1]. The method was developed to simplify notation and derivation in volume rendering, assuming scattering coefficients do not vary with direction [S1].
