# Null-Scattering Transmittance Sampling

Also called: Majorant Sampling, Majorant Transmittance Sampling, MajorantTransmittanceSampler, Null-Event Method

## Overview
Null-Scattering Transmittance Sampling is a technique for unbiased volumetric path tracing that handles participating media with arbitrary density distributions, including empty space, by using a constant majorant extinction coefficient $\sigma_{maj}$ [S1, unofficial]. It solves the problem of efficiently sampling interaction points in sparse or heterogeneous media by converting the physical transmittance integral into a modified integral over a homogeneous medium, where "null events" (rejections) account for the difference between the majorant and the actual density [S1, unofficial]. It differs from standard delta tracking by explicitly maintaining a majorant transmittance factor $T_{maj}$ and applying Russian Roulette based on the ratio of null density to the majorant, ensuring unbiased estimates even when the majorant significantly overestimates the physical extinction [S1, unofficial].

## How it works

### Inputs and Outputs
**Inputs:**
*   A ray segment defined by origin, direction, and interval $[t_0, t_1]$ [S1, unofficial].
*   A density grid (e.g., NanoVDB) providing access to physical density $\rho(\mathbf{x})$ and a precomputed majorant density $d_{maj}$ per tile/leaf [S1, unofficial].
*   The base majorant extinction coefficient $\sigma_{t, base}$ (typically $\sigma_a + \sigma_s$ at maximum density) [S1, unofficial].
*   A random number generator (RNG) [S1, unofficial].

**Outputs:**
*   A sequence of `MediumProperties` structs, each containing:
    *   `point`: World position $\mathbf{x}$ of the sampled interaction [S1, unofficial].
    *   `sigma_maj`: The majorant extinction coefficient at the current location, $\sigma_{maj} = d_{maj} \cdot \sigma_{t, base}$ [S1, unofficial].
    *   `density`: The actual physical density $\rho(\mathbf{x})$ at the point [S1, unofficial].
*   The loop terminates when the ray exits the medium or transmittance drops below a threshold.

### Algorithm Steps

1.  **Initialization**:
    *   Initialize `m_T_maj = 1.0f` [S1, unofficial].
    *   Initialize `m_sigma_t` with the provided base majorant extinction coefficient [S1, unofficial].
    *   Initialize the `m_iterator` with the ray and density grid [S1, unofficial].
    *   Get the first segment from `m_iterator.next()` [S1, unofficial].

2.  **Segment Loop**:
    *   While `m_segment` is valid:
        *   If the segment's majorant density $d_{maj} \le 0$, skip the segment (empty space) and fetch the next segment [S1, unofficial].
        *   Compute the local majorant extinction: $\sigma_{maj} = d_{maj} \cdot m\_sigma\_t$ [S1, unofficial].
        *   Sample a distance $dt_{maj}$ from the exponential distribution with rate $\sigma_{maj}$ using a uniform random number $u \in [0, 1)$:
            $$ dt_{maj} = -\frac{\ln(1 - u)}{\sigma_{maj}} $$
            [G: Standard inverse CDF for exponential distribution. If $u=0$, $dt_{maj} \to \infty$, handled by segment bounds.]
        *   Convert to world space ray parameter $t$:
            $$ t = m\_segment.t_0 + \frac{dt_{maj}}{s} $$
            where $s$ is the iterator's world scale factor (`idx_to_world_scale()`) [S1, unofficial].
        *   If $t < m\_segment.t_1$:
            *   Update segment start: $m\_segment.t_0 = t$ [S1, unofficial].
            *   Update majorant transmittance: $m\_T_{maj} \leftarrow m\_T_{maj} \cdot e^{-dt_{maj} \cdot \sigma_{maj}}$ [S1, unofficial].
            *   Retrieve the physical density $\rho$ at position $\mathbf{x} = \mathbf{o} + t \cdot \mathbf{d}$ using `m_density_sampler` [S1, unofficial].
            *   If $\rho > 0$, return `MediumProperties{point: $\mathbf{x}$, sigma_maj: $\sigma_{maj}$, density: $\rho$}` [S1, unofficial].
            *   If $\rho = 0$, continue to the next iteration of the sampler loop (treat as null event) [S1, unofficial].
        *   If $t \ge m\_segment.t_1$, fetch the next segment and repeat.

3.  **Event Sampling (within the path tracer loop)**:
    *   For each returned `MediumProperties` (with density $\rho$ and majorant $\sigma_{maj}$):
        *   Calculate absorption probability:
            $$ p_a = \frac{\sigma_a \cdot \rho}{\sigma_{maj}} $$
            [S1, unofficial]
        *   Calculate scattering probability:
            $$ p_s = \frac{\sigma_s \cdot \rho}{\sigma_{maj}} $$
            [S1, unofficial]
        *   Calculate null event probability:
            $$ p_n = \max(1.0f - p_a - p_s, 0.0f) $$
            [S1, unofficial]
        *   Sample a discrete event from $\{ \text{Null}, \text{Absorption}, \text{Scatter} \}$ using probabilities $\{ p_n, p_a, p_s \}$ and a uniform random number [S1, unofficial].
        *   If **Null**: Continue to the next iteration of the sampler loop (skip emission/scattering contribution) [S1, unofficial].
        *   If **Absorption**: Terminate the path (or handle absorption contribution if using balance heuristic, but standard null-scattering usually terminates or uses Russian Roulette on the path weight) [G: Standard practice is to terminate or multiply by $\sigma_a/\sigma_t$; here, the null-scattering framework typically treats absorption as a termination event for the path, with the weight adjusted by the transmittance].
        *   If **Scatter**: Proceed with scattering (sample direction, emit new ray) [S1, unofficial].

4.  **Transmittance Update and Russian Roulette**:
    *   After each null event (or effectively, at each step where a point is sampled but not accepted for scattering/absorption), update the ray transmittance $T_{ray}$:
        $$ T_{ray} \leftarrow T_{ray} \cdot \frac{\sigma_n}{\sigma_{maj}} $$
        where $\sigma_n = \max(0.0f, \sigma_{maj} - \sigma_t \cdot \rho)$ is the null density [S1, unofficial].
    *   If $T_{ray} < 0.05f$, apply Russian Roulette:
        *   Let $q = 0.75$ [S1, unofficial].
        *   If $u < q$, set $T_{ray} = 0.0f$ and terminate [S1, unofficial].
        *   Else, set $T_{ray} \leftarrow T_{ray} / (1 - q)$ [S1, unofficial].
    *   If $T_{ray} \le 0.0f$, terminate the shadow ray trace and return zero radiance [S1, unofficial].

### Pseudocode

```python
def null_scattering_transmittance_sampling(ray, density_grid, sigma_t_base, rng):
    """
    Samples interaction points along a ray using null-scattering.
    
    Args:
        ray: Ray with origin, direction, and t_max.
        density_grid: Grid providing density and majorant density per tile.
        sigma_t_base: Base majorant extinction coefficient (sigma_a + sigma_s).
        rng: Random number generator.
        
    Yields:
        MediumProperties: point, sigma_maj, density.
    """
    # Initialize state
    T_maj = 1.0
    sigma_t = sigma_t_base
    iterator = RayMajorantIterator(ray, density_grid)
    segment = iterator.next()
    
    while segment is not None:
        # Skip empty space
        if segment.d_maj <= 0.0:
            segment = iterator.next()
            continue
            
        # Compute majorant extinction for this segment
        sigma_maj = segment.d_maj * sigma_t
        
        # Sample distance from exponential distribution
        u = rng.uniform()
        # Avoid log(0)
        if u == 0.0:
            dt_maj = 1e30
        else:
            dt_maj = -math.log(1.0 - u) / sigma_maj
            
        # Convert to world space t
        t = segment.t0 + dt_maj / iterator.idx_to_world_scale()
        
        # Check if sample is within current segment
        if t < segment.t1:
            # Update segment start
            segment.t0 = t
            
            # Update majorant transmittance
            T_maj *= math.exp(-dt_maj * sigma_maj)
            
            # Get physical density
            point = ray.origin + t * ray.direction
            density = density_grid.sample(point)
            
            # If density is positive, yield properties
            if density > 0.0:
                yield MediumProperties(point, sigma_maj, density)
            else:
                # Null event: density is zero, but we are in a segment with majorant > 0
                # This is handled by the caller's event sampling logic
                # However, the transmittance T_maj has already been updated
                pass
        else:
            # Sample fell outside segment, fetch next
            segment = iterator.next()
            continue

    if event == 'Null':
        T_ray *= sigma_n / sigma_maj
```

### Edge Cases and Pitfalls
*   **Empty Space**: Segments with $d_{maj} \le 0$ must be skipped immediately to avoid sampling in void and ensure efficiency [S1, unofficial].
*   **Precision**: When $\sigma_{maj}$ is very large, $dt_{maj}$ can be very small, leading to precision issues in $t$ calculation. Use double precision for intermediate calculations if necessary [G].
*   **Russian Roulette Threshold**: The threshold $0.05$ and survival probability $0.75$ are specific to the implementation in [S1, unofficial]. Other implementations may use different values.
*   **Majorant Bound**: The majorant must be a true upper bound on the physical extinction. If the majorant is not tight, the number of null events increases, reducing efficiency [G].

## Operating characteristics

*   **Time Complexity**: $O(N)$ where $N$ is the number of samples taken along the ray. The number of samples is proportional to the integral of the majorant density along the ray, which can be significantly larger than the number of physical interactions if the majorant is loose.
*   **Memory Complexity**: $O(1)$ per ray, excluding the storage of the density grid.
*   **Performance**: Efficient for sparse media where the majorant is tight. In dense media, the number of null events may be high, but the algorithm remains unbiased. Performance depends heavily on the quality of the majorant [S1, unofficial].
*   **Strengths**: Handles arbitrary density distributions, including empty space, without complex spatial acceleration structures for the medium itself. Unbiased.
*   **Limitations**: Can be inefficient if the majorant is not tight. Requires precomputed majorant densities for the grid [S1, unofficial].

## Background

Null-scattering was introduced by Laine et al. in "Null-scattering: A new approach to volumetric path tracing" (2018) [G: Common knowledge in graphics, but source [S1, unofficial] implements it]. It allows for unbiased path tracing in participating media by modifying the transmittance equation to include a null-scattering term. The method is implemented in the Shibodd/volume_path_tracer repository [S1, unofficial].
