# Primary Sample Space Metropolis Light Transport (PSSMLT)
Also called: MLT Sample Mutation, mutate

## Overview
Primary Sample Space Metropolis Light Transport (PSSMLT) is a Markov Chain Monte Carlo (MCMC) light transport method that applies mutations to random number vectors in primary sample space rather than sampling directly in path space [S1]. It solves the problem of exploring complex light transport paths in participating media by leveraging traditional path tracing techniques to generate paths from mutated random seeds [S1]. Unlike direct path space mutations, PSSMLT is limited by the expressiveness of the underlying path tracer, restricting the possible exploration of the path space [S1].

## How it works
**Inputs and Outputs:**
*   **Input:** A current path sample configuration (represented by a vector of random numbers) and a proposal distribution for mutating these random numbers.
*   **Output:** A new path sample configuration and its associated radiance estimate.

**Data Structures:**
The method operates on a `PathSample` structure (or equivalent) containing random number generators (RNG) and samples for various path components. Key fields include:
*   `rng`: The random number generator state.
*   `bsdfSample`: Contains `uComponent` (for material selection) and `uDir[0], uDir[1]` (for direction sampling).
*   `lightNum`: Index of the selected light source.
*   `lightSample`: Contains `uComponent` (for light selection) and `uPos[0], uPos[1]` (for position sampling on the light).
*   `rrSample`: Russian Roulette sample.
*   `lightRaySamples`: Array of samples for light ray generation (used in bidirectional methods).

**Numbered Steps:**
1.  **Initialize:** Start with a valid path sample configuration generated by the underlying path tracer.
2.  **Mutation:** Apply a mutation operator to the random number vector in the `PathSample` structure. This involves perturbing specific random numbers used during path generation [S2, unofficial].
3.  **Path Generation:** Use the mutated random numbers to regenerate the light path using the standard path tracing algorithm [S1].
4.  **Acceptance:** Calculate the Metropolis-Hastings acceptance probability based on the ratio of the target density to the proposal density. Accept or reject the new path.
5.  **Iterate:** Repeat steps 2-4 to generate a Markov chain of paths.

**Formulas:**
The acceptance probability $\alpha$ for a move from state $x$ to $x'$ is:
$$ \alpha(x \to x') = \min \left( 1, \frac{\pi(x') q(x | x')}{\pi(x) q(x' | x)} \right) $$
where $\pi(x)$ is the target density (radiance contribution) and $q(x' | x)$ is the proposal density. In PSSMLT, $x$ represents the vector of random numbers [S1].

**Parameters:**
*   **Mutation Scale:** The magnitude of perturbation applied to random numbers. Not given in the sources.
*   **Path Depth:** Maximum number of bounces. Not given in the sources.

**Edge Cases and Pitfalls:**
*   **Biased Estimators:** If a biased estimate of transmission is used instead of the exact quantity, the resulting Markov chain does not necessarily target the desired density $\pi(\bar{x})$ [S1].
*   **Limited Exploration:** PSSMLT is limited to the underlying path tracing techniques, which restricts the possible exploration of the path space compared to direct path space mutations [S1].
*   **Degenerate Input:** If the mutated random numbers lead to invalid path configurations (e.g., invalid directions), the path tracer must handle these gracefully, potentially rejecting the path or restarting.

## Subtopics

### Pseudo-marginal Metropolis Light Transport (PSSMLT)
Uses unbiased estimators of the scalar contribution function to allow for valid MCMC sampling even when the exact contribution is intractable. It extends PSSMLT by employing unbiased estimators, allowing for larger families of path space MLT and ERPT methods. [Pseudo-marginal Metropolis Light Transport (PSSMLT)](12276-pseudo-marginal-metropolis-light-transport-pssmlt.md)

### Metropolis Light Transport
The original MLT method that samples directly in path space. PSSMLT is an alternative that operates in primary sample space, which is easier to implement but may have limited exploration. [Metropolis Light Transport](12286-metropolis-light-transport.md)

## Operating characteristics
*   **Time Complexity:** Depends on the cost of path tracing and the mutation operator. Each step requires a full path trace, which can be expensive.
*   **Memory Complexity:** Depends on the path depth and the size of the `PathSample` structure.
*   **Measured Performance:** Not given in the sources.
*   **Scaling:** Performance scales with the complexity of the scene and the number of bounces.
*   **Strengths:** Easy to implement as it leverages existing path tracing code [S1].
*   **Limitations:** Limited exploration of path space due to reliance on the underlying path tracer [S1]. Susceptible to bias if biased estimators are used [S1].
*   **When to use:** When implementing MLT for participating media and the underlying path tracer is already available and efficient.
*   **When not to use:** When high-quality exploration of complex path space is required, or when unbiased estimators are necessary for correctness.

## Background
PSSMLT was presented by Kelemen et al. in 2002 [S1]. It was introduced as an alternative to sampling directly in path space, applying mutations to random number vectors in primary sample space instead [S1]. Raab et al. [2008] later introduced delta tracking to computer graphics and argued for its use in deriving unbiased path tracing algorithms compatible with PSSMLT [S1].
