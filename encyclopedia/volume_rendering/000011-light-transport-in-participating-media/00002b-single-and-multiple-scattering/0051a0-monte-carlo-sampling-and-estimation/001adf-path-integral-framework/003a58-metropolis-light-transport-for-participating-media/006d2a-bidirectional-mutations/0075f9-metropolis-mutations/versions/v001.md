# Metropolis Mutations

Also called: Caustic Perturbations, Perturbations, Propagation Perturbation, Scattering Perturbations, Sensor Perturbations

## Overview
Metropolis Mutations are local path-space sampling strategies used within Metropolis Light Transport (MLT) to explore neighborhoods of high-contribution paths with high acceptance probabilities [S1]. Specifically designed for participating media, they exploit the fact that small variations to a path's geometry often yield similar image contributions, allowing efficient sampling of bright areas such as caustics [S1]. Unlike global mutation strategies, they alter the image location, leading to a better distribution of paths over the image plane and significantly reduced variance [S1].

## How it works
**Inputs:** A current transport path $\bar{x} = x_0, \dots, x_k$, where $x_0$ is on a light source and $x_k$ is on the sensor (eye) [S1]. The path must contain at least one interaction point in the participating medium [S1].
**Outputs:** A proposed mutated path $\bar{y} = y_0, \dots, y_k$ and an acceptance probability [S1].

**Data Structures:**
*   Path vertices: Points $x_i \in \mathbb{R}^3$ and direction vectors.
*   Medium bounds: Defined by the participating volume geometry [S1].
*   Camera model: Pinhole camera specified by an eye point and an image plane [S1].

**Mutation Types:**
The method distinguishes between two primary types of perturbations, which are complementary:
1.  **Scattering Perturbations:** Displace the direction vector at a certain vertex [S1].
    *   *Sensor Perturbations:* Alter the location on the image plane and retrace the path towards the light source [S1]. This combines lens and multi-chain perturbations [S1].
    *   *Caustic Perturbations:* Retrace the path towards the eye after perturbing the direction vector of the second path edge from the eye [S1].
2.  **Propagation Perturbations:** Displace the interaction point along a certain ray segment [S1]. This is specifically designed for participating media [S1].

**Propagation Perturbation Algorithm:**
This is the primary mutation strategy for participating media described in the sources [S1].

1.  **Select Vertex:** Choose an interaction point $x_{k-1}$ in the medium from the current path $\bar{x}$ [S1].
2.  **Determine Displacement Direction:** Define the vector $\vec{v} = x_{k-1} - x_{k-2}$, where $x_{k-2}$ is the previous vertex on the path [S1].
3.  **Sample Distance $D$:** Sample a distance $D$ from the probability density function (PDF):
    $$ p_D(D) \propto \frac{1}{D} \quad \text{for} \quad D_{min} \le D \le D_{max} $$
    where $D_{min}$ and $D_{max}$ specify the minimal and maximal displacement distances [S1]. The sign of the displacement (direction along the ray) is chosen randomly (either $+D$ or $-D$ along $\vec{v}$) [S1].
4.  **Compute New Vertex:** Calculate the new interaction point $y_{k-1}$:
    $$ y_{k-1} = x_{k-1} \pm D \cdot \frac{\vec{v}}{\|\vec{v}\|} $$
    [S1].
5.  **Check Validity:** If $y_{k-1}$ falls outside the medium, or if the original vertex $x_{k-1}$ is invalid for mutation, reject the mutation (acceptance probability is zero) [S1].
6.  **Connect to Sensor:** Connect the new vertex $y_{k-1}$ with the eyepoint to determine the new sensor location $y_k$ [S1].
7.  **Occlusion Test:** Perform one occlusion test to check if the connection between $y_{k-1}$ and the eyepoint is unobstructed [S1].
8.  **Retrace:** Retrace the original path from the light source to $y_{k-1}$, preserving the path characteristic, to complete the proposed path $\bar{y}$ [S1].

**Pseudocode:**
```python
def propagate_mutation(path, medium_bounds, eye_point, d_min, d_max):
    """
    Performs a propagation mutation on a participating media path.
    
    Args:
        path: List of vertices [x0, x1, ..., xk] where x0 is light, xk is sensor.
        medium_bounds: Geometry defining the participating medium.
        eye_point: 3D vector of the camera eye position.
        d_min: Minimum displacement distance.
        d_max: Maximum displacement distance.
        
    Returns:
        (new_path, acceptance_prob)
    """
    # Identify an interaction point in the medium (e.g., x_{k-1})
    # Note: The source specifies displacing x_{k-1} along x_{k-2} -> x_{k-1}
    # We assume the path has at least 3 vertices (light, medium, sensor)
    if len(path) < 3:
        return None, 0.0
        
    x_prev = path[-2] # x_{k-2}
    x_curr = path[-1] # x_{k-1} (interaction point in medium)
    
    # Vector from previous vertex to current vertex
    direction = x_curr - x_prev
    dist = norm(direction)
    
    if dist == 0:
        return None, 0.0
        
    unit_direction = direction / dist
    
    # Sample D from p(D) proportional to 1/D in [d_min, d_max]
    # PDF: p(D) = C / D. Normalization constant C = 1 / ln(d_max/d_min)
    # CDF: F(D) = ln(D/d_min) / ln(d_max/d_min)
    # Inverse CDF: D = d_min * (d_max/d_min)^u, where u ~ Uniform(0,1)
    u = random_uniform(0, 1)
    D = d_min * (d_max / d_min) ** u
    
    # Randomly choose direction (+ or -)
    sign = 1 if random_bool() else -1
    
    # Calculate new vertex
    y_curr = x_curr + sign * D * unit_direction
    
    # Check if new vertex is inside the medium
    if not is_inside_medium(y_curr, medium_bounds):
        return None, 0.0
        
    # Connect new vertex to eyepoint to determine new sensor location
    # In a pinhole camera model, the sensor location is determined by the ray
    # from the eye through the new vertex.
    # The new path vertex y_k is effectively the intersection of the ray 
    # (eye_point, y_curr) with the image plane, or simply the point on the 
    # sensor corresponding to this direction.
    # For MLT path construction, we usually just need the direction to the eye.
    # The source says "determine the new sensor location y_k".
    # We assume y_k is the point on the image plane hit by the ray from y_curr to eye.
    sensor_direction = eye_point - y_curr
    # Assuming standard pinhole projection, y_k is derived from this direction.
    # For the purpose of the path integral, the vertex y_k is on the sensor.
    y_k = project_to_sensor_plane(y_curr, eye_point, image_plane_params)
    
    # Check occlusion between y_curr and eye_point
    if is_occluded(y_curr, eye_point, scene_geometry):
        return None, 0.0
        
    # Retrace path from light source to y_curr
    # This involves generating a new path segment from x0 to y_curr
    # preserving the path characteristic (e.g., same scattering events if possible,
    # or re-sampling based on the new geometry).
    # The source states: "Retrace the original path while preserving path characteristic"
    # This implies we reuse the previous vertices x0...x_{k-2} if they are valid,
    # or regenerate the path up to y_curr.
    # Given the mutation is local, we assume the path from light to x_{k-2} is reused
    # and we only need to verify visibility or re-sample the segment x_{k-2} -> y_curr.
    
    # Construct new path
    new_path = path[:-1] + [y_curr, y_k]
    
    # Calculate acceptance probability
    # A = min(1, (p_propose(y|x) * p_path(y)) / (p_propose(x|y) * p_path(x)))
    # The source notes that propagation perturbation is computationally cheap.
    # The exact acceptance ratio depends on the specific MLT implementation details
    # not fully provided in the excerpt, but typically involves the ratio of PDFs
    # and the path contributions.
    acceptance_prob = calculate_mlt_acceptance(new_path, path)
    
    return new_path, acceptance_prob
```

**Edge Cases and Pitfalls:**
*   If the displaced vertex $y_{k-1}$ falls outside the medium, the mutation is rejected [S1].
*   If the connection to the eyepoint is obstructed, the mutation is rejected [S1].
*   Precision issues may arise if $D_{min}$ is very small or $D_{max}$ is very large, affecting the sampling of $1/D$ [S1].

## Operating characteristics
*   **Time Complexity:** Computationally very cheap, requiring only one occlusion test to check the connection with the eyepoint [S1].
*   **Memory Complexity:** Low, as it modifies a single vertex and reuses most of the path structure [S1].
*   **Strengths:** Explores path space locally with high acceptance probabilities; beneficial for bright areas like caustics; reduces variance by better distributing paths over the image plane [S1].
*   **Limitations:** Limited to local exploration; may not escape local minima in path space as effectively as global mutations [S1].
*   **When to Use:** When rendering participating media with bright, localized light transport features (caustics) [S1].
*   **When Not to Use:** When global path space exploration is required or when the medium is sparse and local perturbations rarely yield valid paths [S1].

## Background
Metropolis Mutations were adapted from the bidirectional mutation strategy described in [VG97] to the generalized path integral framework for participating media [S1]. The specific propagation perturbation strategy was implemented using the experimental ray tracing kernel McRender [S1]. The phase function of the medium was modeled using a convex combination of Schlick’s base functions [S1].
