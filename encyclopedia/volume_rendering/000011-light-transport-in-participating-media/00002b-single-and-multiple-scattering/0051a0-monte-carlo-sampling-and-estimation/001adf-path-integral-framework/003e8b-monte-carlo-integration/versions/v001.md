# Monte Carlo Integration
Also called: Monte Carlo estimation, crude Monte Carlo integration

## Overview
Monte Carlo integration is a numerical technique for estimating definite integrals by sampling random points from a probability distribution. It solves the problem of computing high-dimensional or analytically intractable integrals common in light transport simulation by approximating the expected value of a function. It is distinguished from deterministic quadrature methods by its dimension-independent convergence rate, making it the foundational estimator for the Path Integral Framework [S1, unofficial].

## How it works
**Inputs and Outputs:**
- Input: A function $f(x)$ to integrate over a domain, a probability density function (pdf) $p(x)$ from which samples are drawn, and an integer $N$ representing the number of samples.
- Output: A scalar estimate $F_N$ of the integral $\int f(x) dx$.

**Data Structures:**
- No specific complex data structures are required for the core estimator. The method relies on a sequence of $N$ independent random variables $X_i$ drawn from $p(x)$.

**Steps:**
1. Generate $N$ independent random samples $X_1, X_2, \dots, X_N$ from the probability density function $p(x)$.
2. Evaluate the function $f(x)$ at each sample point $X_i$.
3. Evaluate the probability density $p(x)$ at each sample point $X_i$.
4. Compute the importance weight for each sample as $w_i = \frac{f(X_i)}{p(X_i)}$.
5. Sum the weighted values and divide by $N$ to obtain the estimator $F_N$.

**Formulas:**
The integral of a function $f(x)$ is estimated as the expected value of the ratio $f(x)/p(x)$:
$$ \int f(x) dx = E \left[ \frac{f(x)}{p(x)} \right] = \int \frac{f(x)}{p(x)} p(x) dx $$

The Monte Carlo estimator $F_N$ is defined as:
$$ F_N = \frac{1}{N} \sum_{i=1}^{N} \frac{f(X_i)}{p(X_i)} $$

Where:
- $N$ is the number of samples.
- $X_i$ is the $i$-th random sample drawn from $p(x)$.
- $f(X_i)$ is the value of the integrand at $X_i$.
- $p(X_i)$ is the probability density of drawing $X_i$.

**Parameters:**
- $N$: The number of samples. The estimator $F_N$ is a random variable whose variance decreases as $N$ increases. Typical values depend on the required noise level and computational budget, often ranging from 1 to 64 per pixel in real-time or higher in offline rendering.

**Edge Cases and Pitfalls:**
- **Zero Density:** If $p(X_i) = 0$ for any sample where $f(X_i) \neq 0$, the weight becomes infinite. The sampling distribution $p(x)$ must have support wherever $f(x)$ is non-zero.
- **Variance:** The convergence rate is $O(1/\sqrt{N})$. High variance leads to noisy results, requiring many samples for smooth images.
- **Bias:** The estimator is unbiased if $p(x)$ is a valid pdf and samples are independent.

**Pseudocode:**
```python
def monte_carlo_integration(f, p, N):
    """
    Estimate the integral of f(x) using Monte Carlo integration.
    
    Args:
        f: Function to integrate.
        p: Probability density function (pdf) for sampling.
        N: Number of samples.
        
    Returns:
        float: The estimated integral value.
    """
    total_weight = 0.0
    
    for i in range(N):
        # Sample X_i from p(x)
        # Implementation of sampling depends on the specific distribution p
        X_i = sample_from_pdf(p)
        
        # Evaluate f(X_i)
        f_val = f(X_i)
        
        # Evaluate p(X_i)
        p_val = p(X_i)
        
        # Guard against division by zero
        if p_val == 0:
            if f_val != 0:
                raise ValueError("Sample drawn from region with zero probability density but non-zero function value.")
            continue
            
        # Compute weight
        weight = f_val / p_val
        total_weight += weight
        
    # Average the weights
    estimate = total_weight / N
    return estimate
```

## Subtopics

### [Monte Carlo Estimator of Edge Integrals](10285-monte-carlo-estimator-of-edge-integrals.md)
This method estimates the edge integrals that arise from discontinuities in radiance across boundary curves in the path integral formulation of light transport. It solves the problem of computing the contribution of radiance differences $\Delta L$ across these boundaries by tracing additional side paths. It is distinguished from the direct term estimators (which use multiple importance sampling) by its reliance on side-path tracing to handle the geometric discontinuities.

## Operating characteristics
- **Time Complexity:** $O(N)$, where $N$ is the number of samples. Each sample requires one evaluation of $f(x)$ and one evaluation of $p(x)$.
- **Memory Complexity:** $O(1)$ auxiliary space, excluding storage for the samples if generated on the fly.
- **Convergence:** The rate of convergence is $O(1/\sqrt{N})$ in any dimension, regardless of the smoothness of the function to be integrated [S1, unofficial]. This makes it superior to deterministic methods for high-dimensional integrals.
- **Strengths:** Simplicity of implementation; dimension independence; unbiased estimation.
- **Limitations:** Slow convergence rate ($1/\sqrt{N}$) compared to deterministic methods for low-dimensional smooth functions; sensitive to variance; requires careful construction of $p(x)$ for efficiency.
- **When to use:** High-dimensional integrals, complex domains, or when the integrand is not analytically tractable.
- **When not to use:** Low-dimensional integrals with smooth functions where deterministic quadrature is faster and more accurate.

## Background
Monte Carlo integration is a fundamental technique in numerical analysis. In computer graphics, it was popularized by Kajiya (1986) in the derivation of the rendering equation, which formulates light transport as an integral equation solvable via Monte Carlo methods [S1, unofficial]. The method is central to modern path tracing and volume rendering algorithms, serving as the basis for combining photon density estimation and Monte Carlo path integration [S1, unofficial].
