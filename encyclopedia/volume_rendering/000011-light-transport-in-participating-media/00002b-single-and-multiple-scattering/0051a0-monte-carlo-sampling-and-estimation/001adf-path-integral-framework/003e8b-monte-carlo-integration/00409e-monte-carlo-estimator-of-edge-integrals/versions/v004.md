# Monte Carlo Estimator of Edge Integrals

Also called: EdgeIntegral

## Overview
This method estimates the edge integrals that arise from discontinuities in radiance across boundary curves in participating media [S1, unofficial]. It requires tracing additional side paths to compute the radiance differences across these boundaries [S1, unofficial].

## How it works
**Inputs:**
- $x$: Current path vertex position.
- $\hat{x}$: Perturbed path vertex position.
- $\omega$: Incoming direction at $x$.
- $f$: Scattering phase function.
- $\hat{\omega}$: Derivative direction vector associated with the path perturbation [G].
- $\partial \Omega(x)$: Boundary curve associated with vertex $x$.
- $p(y)$: Probability density function for sampling a point $y$ on the boundary.

**Outputs:**
- Estimate of the edge integral contribution [S1, unofficial].

**Data Structures:**
- $\partial \Omega(x)$: Boundary curve geometry and sampling interface.
- $p(y)$: PDF value and sampling routine for the boundary.

**Steps:**
1. Draw a point $y$ from the boundary $\partial \Omega(x)$ with probability $p(y)$ [S1, unofficial].
2. Calculate the direction $\omega'$ from $y$ to $x$:
   $$ \omega' = \frac{x - y}{\|x - y\|} $$
   [S1, unofficial]
3. Calculate the normal component $n_\perp$ and the derivative direction $\hat{\omega}'$ using Equations (24) and (25) from the source [S1, unofficial].
4. Compute the radiance difference $\Delta L$ using the `deltaRadiance` function with arguments $x$, $\hat{x}$, $\omega'$, and $\hat{\omega}'$ [S1, unofficial].
5. Return the edge integral estimate:
   $$ \frac{\langle n_\perp, \hat{\omega} \rangle f(x, -\omega', \omega) \Delta L \|y - x\|}{p(y)} $$
   [S1, unofficial]

## Subtopics

### [Monte Carlo Estimator of Radiance Change](10299-monte-carlo-estimator-of-radiance-change.md)
This method estimates the change in radiance $\Delta L$ across geometric discontinuities (boundary, silhouette, and sharp edges) to compute edge integrals in the path integral framework. It distinguishes itself from standard volumetric path tracing by explicitly handling the discontinuities in surface emission and scattering that occur when a ray intersects a boundary curve or sharp edge, ensuring unbiased estimation of the radiance jump [10299-monte-carlo-estimator-of-radiance-change.md].
