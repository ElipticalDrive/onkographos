# Monte Carlo Estimator of Edge Integrals
Also called: EdgeIntegral

## Overview
This method estimates the edge integrals that arise from discontinuities in radiance across boundary curves in the path integral formulation of light transport [S1, unofficial]. It solves the problem of computing the contribution of radiance differences $\Delta L$ across these boundaries by tracing additional side paths. It is distinguished from the direct term estimators (which use multiple importance sampling) by its reliance on side-path tracing to handle the geometric discontinuities [S1, unofficial].

## How it works
**Inputs:**
*   $x$: The current vertex position.
*   $\hat{x}$: The perturbed vertex position (used for derivative estimation).
*   $\omega$: The incoming direction at $x$.
*   $f$: The phase function or scattering term.
*   $p(y)$: The probability density function for sampling points on the edge.

**Outputs:**
*   An unbiased estimate of the edge integral contribution.

**Data Structures:**
*   The edge $\partial \Omega(x)$ is treated as a set of boundary curves.
*   Points $y$ are sampled from this edge.

**Steps:**
1.  **Sample Edge Point:** Draw a point $y$ from the edge $\partial \Omega(x)$ with probability density $p(y)$ [S1, unofficial].
2.  **Compute Direction:** Calculate the direction $\omega'$ from $y$ to $x$:
    $$ \omega' = \frac{x - y}{\|x - y\|} $$
    [S1, unofficial]
3.  **Compute Geometry Terms:** Calculate the normal component $n_\perp$ and the derivative direction $\hat{\omega}'$ using the specific equations defined in the source (Eqs. 24 and 25) [S1, unofficial].
4.  **Compute Radiance Difference:** Compute the radiance difference $\Delta L$ using a `deltaRadiance` function. This function takes arguments $x$, $\hat{x}$, $\omega'$, and $\hat{\omega}'$ and typically involves tracing side paths to estimate the difference in radiance across the discontinuity [S1, unofficial].
5.  **Return Estimate:** Return the weighted estimate:
    $$ \frac{\langle n_\perp, \hat{\omega} \rangle f(x, -\omega', \omega) \Delta L \|y - x\|}{p(y)} $$
    [S1, unofficial]

**Pseudocode:**
```python
def edge_integral(x, x_hat, omega, f, p_y, delta_radiance):
    """
    Estimates the edge integral contribution for a discontinuity.
    
    Args:
        x: Current vertex position.
        x_hat: Perturbed vertex position.
        omega: Incoming direction.
        f: Phase function/scattering term.
        p_y: Probability density function for sampling y on the edge.
        delta_radiance: Function to compute radiance difference.
        
    Returns:
        Estimate of the edge integral.
    """
    # 1. Draw y from the edge boundary with probability p(y)
    # Note: The specific sampling strategy for the edge boundary is not detailed 
    # in the provided notes, but y must be drawn from ∂Ω(x).
    y = sample_edge_boundary(p_y)
    
    # 2. Calculate direction omega' from y to x
    direction_vec = x - y
    norm_dist = vector_norm(direction_vec)
    omega_prime = direction_vec / norm_dist
    
    # 3. Calculate n_perp and omega_hat using source equations (24, 25)
    # These equations define the geometric terms related to the discontinuity.
    n_perp, omega_hat_prime = compute_geometry_terms(x, y, omega_prime)
    
    # 4. Compute radiance difference Delta L
    # This requires tracing side paths to estimate the difference in radiance.
    delta_L = delta_radiance(x, x_hat, omega_prime, omega_hat_prime)
    
    # 5. Return the edge integral estimate
    # Formula: <n_perp, omega_hat> * f(x, -omega', omega) * Delta_L * ||y-x|| / p(y)
    # Note: omega_hat in the formula refers to the derivative direction component 
    # used in the dot product, distinct from omega_hat_prime if not identical.
    # Based on Algorithm 2, the term is <n_perp, omega_hat>. 
    # Assuming omega_hat in the dot product corresponds to the direction 
    # associated with the derivative estimation in the context of the edge integral.
    
    # Re-evaluating the formula from Algorithm 2:
    # return <n_perp, omega_hat> f(x, -omega', omega) Delta_L ||y-x|| / p(y)
    # The variable omega_hat in the dot product is likely the direction 
    # corresponding to the derivative perturbation. In many differential 
    # formulations, this is related to the gradient direction. 
    # However, Algorithm 2 explicitly lists: return <n_perp, omega_hat> ...
    # And step 4 calculates omega_hat_prime. 
    # It is highly probable that omega_hat in the final formula refers to 
    # the direction used for the derivative, which is omega_hat_prime, 
    # or a normalized version thereof. 
    # Let's assume omega_hat in the dot product is the direction vector 
    # associated with the derivative estimation.
    
    # To be precise with Algorithm 2:
    # Step 4 calculates n_perp and omega_hat_prime.
    # Step 6 uses <n_perp, omega_hat>.
    # It is likely omega_hat refers to omega_hat_prime or a related unit vector.
    # We will use omega_hat_prime for the dot product as it is the calculated derivative direction.
    
    dot_product = dot(n_perp, omega_hat_prime)
    
    # Evaluate phase function
    # Note: The phase function f takes arguments (x, -omega', omega)
    phase_val = f(x, -omega_prime, omega)
    
    estimate = (dot_product * phase_val * delta_L * norm_dist) / p_y(y)
    
    return estimate
```

**Parameters:**
*   $p(y)$: The PDF for sampling the edge. Typical values depend on the specific edge geometry and sampling strategy. Not given in the sources.

**Edge Cases and Pitfalls:**
*   **Precision:** The calculation of $\Delta L$ via side paths can be sensitive to numerical precision, especially if the discontinuity is sharp or the paths are short.
*   **Boundaries:** Sampling $y$ must be done carefully to ensure it lies on the actual discontinuity boundary $\partial \Omega(x)$.
*   **Degenerate Input:** If $y = x$, the distance $\|y - x\|$ is zero, leading to division by zero or undefined directions. This should be handled by resampling or clamping.

## Subtopics

### [Monte Carlo Estimator of Radiance Change](10299-monte-carlo-estimator-of-radiance-change.md)
Estimates the change of radiance $\nabla L$ across discontinuity boundaries (boundary, silhouette, and sharp edges) using Monte Carlo integration. It is chosen when the derivative of radiance is required for gradient-based optimization or sensitivity analysis, whereas the Edge Integral estimator is used for the direct contribution of the discontinuity itself.

## Operating characteristics
*   **Time Complexity:** Depends on the cost of sampling $y$ and the cost of the `deltaRadiance` function, which involves tracing side paths. Not given in the sources.
*   **Memory Complexity:** Low, as it primarily requires storing the current vertex and a few vectors. Not given in the sources.
*   **Measured Performance:** Not given in the sources.
*   **Strengths:** Provides an unbiased estimate of the edge contribution, which is crucial for accurate rendering of participating media with sharp discontinuities.
*   **Limitations:** Requires tracing additional side paths, which can be computationally expensive. The accuracy depends on the quality of the `deltaRadiance` estimation.
*   **When to use:** When rendering participating media with sharp boundaries or discontinuities in radiance.
*   **When not to use:** When the scene has no sharp discontinuities or when computational resources are extremely limited and approximate methods are acceptable.

## Background
The method originates from the Differential Theory of Radiative Transfer, which extends the path integral formulation to include derivatives of radiance. It was introduced to handle the complex interactions of light with participating media, particularly at boundaries where radiance changes abruptly. The specific estimator for edge integrals is part of a broader framework for jointly estimating radiance and its derivatives [S1, unofficial].
