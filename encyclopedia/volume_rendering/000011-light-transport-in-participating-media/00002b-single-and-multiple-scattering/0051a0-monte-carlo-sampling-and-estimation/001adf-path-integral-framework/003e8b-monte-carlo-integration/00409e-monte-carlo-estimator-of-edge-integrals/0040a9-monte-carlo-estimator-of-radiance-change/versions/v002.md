# Monte Carlo Estimator of Radiance Change

Also called: Monte Carlo estimation of radiance change ($\Delta L$), deltaRadiance, estimating $\Delta L$

## Overview
This method estimates the change in radiance $\Delta L$ across geometric discontinuities (boundary, silhouette, and sharp edges) to compute edge integrals in the path integral framework [S1, unofficial]. It distinguishes itself from standard volumetric path tracing by explicitly handling the discontinuities in surface emission and scattering that occur when a ray intersects a boundary curve or sharp edge, ensuring unbiased estimation of the radiance jump [S1, unofficial].

## How it works
### Inputs and Outputs
*   **Input**: Current position $x$, direction $\omega$, and geometric context indicating whether $\omega$ corresponds to a boundary/silhouette edge or a sharp edge [S1, unofficial].
*   **Output**: The estimated radiance change $\Delta L$ [S1, unofficial].

### Steps
1. Check if the direction $\omega$ corresponds to a boundary/silhouette edge or a sharp edge [S1, unofficial].
2. For boundary/silhouette edges: Calculate distances $D^-$ and $D^+$ using the geometric definition [S1, unofficial]. Set $D_{\text{near}} = \min(D^-, D^+)$ and $D_{\text{far}} = \max(D^-, D^+)$ [S1, unofficial]. Compute positions $x_{\text{near}} = x - D_{\text{near}}\omega$ and $x_{\text{far}} = x - D_{\text{far}}\omega$ [S1, unofficial]. Initialize $\Delta L$ with the negative surface emission at the near point: $\Delta L \leftarrow -L_s(x_{\text{near}}, \omega)$ [S1, unofficial]. Trace a side path by drawing a free-flight distance $\tau$ from $x_{\text{near}}$ in direction $\omega$ [S1, unofficial]. Update $\tau \leftarrow \tau + D_{\text{near}}$ [S1, unofficial]. If $\tau < D_{\text{far}}$, sample position $x' = x - \tau\omega$ and add the in-scattered radiance contribution: $\Delta L \leftarrow \Delta L + \frac{\sigma_s(x')}{\sigma_t(x')} L_{\text{inScatRadiance}}(x', \omega)$ [S1, unofficial]. Else, add surface emission at the far point: $\Delta L \leftarrow \Delta L + L_s(x_{\text{far}}, \omega)$ [S1, unofficial]. Transmit the accumulated $\Delta L$ from $x_{\text{near}}$ to $x$: $\Delta L \leftarrow T(x_{\text{near}}, x) \Delta L$ [S1, unofficial]. If $D^- < D^+$, negate the result: $\Delta L \leftarrow -\Delta L$ [S1, unofficial].
3. For sharp edges: Calculate normals $n^-$ and $n^+$ [S1, unofficial]. Initialize $\Delta L$ with the difference in surface emission: $\Delta L \leftarrow L_{\text{es}}(x_0, \omega | n^-) - L_{\text{es}}(x_0, \omega | n^+)$ [S1, unofficial]. Draw a scattering direction $\omega'$ with probability $p(\omega')$ [S1, unofficial]. Calculate the BSDF difference: $\Delta f_s = f_s(x_0, -\omega', \omega | n^-) - f_s(x_0, -\omega', \omega | n^+)$ [S1, unofficial]. Add the in-scattering contribution: $\Delta L \leftarrow \Delta L + L_s(x, \omega') \Delta f_s / p(\omega')$ [S1, unofficial].

### Pseudocode
```python
import math
import random

def estimate_delta_L(x, omega, is_boundary_edge, get_distances, get_normals,
                     surface_emission, transmittance, sigma_s, sigma_t,
                     bsdf, surface_emission_sharp, sample_direction, pdf, radiance_func):
    if is_boundary_edge:
        D_minus, D_plus = get_distances(x, omega)
        D_near = min(D_minus, D_plus)
        D_far = max(D_minus, D_plus)

        x_near = x - D_near * omega
        x_far = x - D_far * omega

        delta_L = -surface_emission(x_near, omega)

        tau = -math.log(random.random()) / sigma_t(x_near)
        tau = tau + D_near

        if tau < D_far:
            x_prime = x - tau * omega
            in_scatter = inScatRadiance(x_prime, omega, sigma_t, surface_emission, bsdf, sample_direction, radiance_func)
            delta_L = delta_L + (sigma_s(x_prime) / sigma_t(x_prime)) * in_scatter
        else:
            delta_L = delta_L + surface_emission(x_far, omega)

        delta_L = transmittance(x_near, x) * delta_L

        if D_minus < D_plus:
            delta_L = -delta_L
    else:
        n_minus, n_plus = get_normals(x, omega)
        delta_L = surface_emission_sharp(x, omega, n_minus) - surface_emission_sharp(x, omega, n_plus)

        omega_prime = sample_direction()
        p_omega_prime = pdf(omega_prime)

        delta_f_s = bsdf(x, -omega_prime, omega, n_minus) - bsdf(x, -omega_prime, omega, n_plus)
        delta_L = delta_L + radiance_func(x, omega_prime) * delta_f_s / p_omega_prime

    return delta_L

def inScatRadiance(x, omega, sigma_t, surface_emission, bsdf, sample_direction, radiance_func):
    if not is_on_boundary(x):
        omega_prime = sample_direction()
        return radiance_func(x, omega_prime)
    else:
        epsilon = 1e-6
        omega_prime = sample_direction()
        if dot(normal_at(x), omega_prime) > 0:
            return radiance_func(x, omega_prime)
        else:
            return surface_emission(x, omega_prime)
```

### Parameters
*   $p(\omega')$: Probability density function for sampling the scattering direction $\omega'$ in the sharp edge case [S1, unofficial].
*   $\epsilon$: A small positive offset used in the `inScatRadiance` function when $x$ is on the boundary ($\partial \Omega$) to avoid self-intersection issues [S1, unofficial].

### Edge Cases and Pitfalls
*   **Precision**: When $x$ is on the boundary ($\partial \Omega$), the `inScatRadiance` function uses a small offset $\epsilon$ to sample the direction [S1, unofficial].
*   **Boundary Conditions**: The distinction between $D^-$ and $D^+$ determines the sign of the result [S1, unofficial].
*   **Sharp Edge Normals**: The normals $n^-$ and $n^+$ must be correctly identified for the sharp edge case [S1, unofficial].
