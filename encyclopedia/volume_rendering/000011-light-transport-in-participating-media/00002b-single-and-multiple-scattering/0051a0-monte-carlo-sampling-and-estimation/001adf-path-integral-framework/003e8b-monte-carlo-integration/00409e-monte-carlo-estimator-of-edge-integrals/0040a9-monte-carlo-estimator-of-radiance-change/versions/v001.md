# Monte Carlo Estimator of Radiance Change

Also called: Monte Carlo estimation of radiance change ($\nabla L$), deltaRadiance, estimating $\nabla L$

## Overview
This method estimates the change in radiance $\Delta L$ across geometric discontinuities (boundary, silhouette, and sharp edges) to compute edge integrals in the path integral framework. It distinguishes itself from standard volumetric path tracing by explicitly handling the discontinuities in surface emission and scattering that occur when a ray intersects a boundary curve or sharp edge, ensuring unbiased estimation of the radiance jump.

## How it works
The estimator computes $\Delta L$ by distinguishing between two types of discontinuities: those caused by boundary/silhouette edges and those caused by sharp edges. It relies on the Monte Carlo Estimator of Edge Integrals [10285-monte-carlo-estimator-of-edge-integrals.md] for the broader context of edge integrals.

### Inputs and Outputs
*   **Input**: Current position $x$, direction $\omega$, and geometric context (whether $\omega$ corresponds to a boundary/silhouette edge or a sharp edge).
*   **Output**: The estimated radiance change $\Delta L$.

### Data Structures
No specific complex data structures are required beyond standard geometric queries (distances to boundaries, surface normals, BSDF values).

### Steps
The algorithm proceeds as follows:

1.  **Check Edge Type**: Determine if the direction $\omega$ corresponds to a boundary/silhouette edge or a sharp edge.
2.  **Boundary/Silhouette Edge Handling** (if applicable):
    a.  Calculate distances $D^-$ and $D^+$ to the discontinuity boundaries using the geometric definition [S1, unofficial].
    b.  Set $D_{\text{near}} = \min(D^-, D^+)$ and $D_{\text{far}} = \max(D^-, D^+)$.
    c.  Compute positions $x_{\text{near}} = x - D_{\text{near}}\omega$ and $x_{\text{far}} = x - D_{\text{far}}\omega$.
    d.  Initialize $\Delta L$ with the negative surface emission at the near point: $\Delta L \leftarrow -L_s(x_{\text{near}}, \omega)$.
    e.  **Trace Side Path**:
        i.  Draw a free-flight distance $\tau$ from $x_{\text{near}}$ in direction $\omega$.
        ii. Update $\tau \leftarrow \tau + D_{\text{near}}$.
        iii. If $\tau < D_{\text{far}}$:
            *   Sample position $x' = x - \tau\omega$.
            *   Add in-scattered radiance contribution: $\Delta L \leftarrow \Delta L + \frac{\sigma_s(x')}{\sigma_t(x')} L_{\text{inScatRadiance}}(x', \omega)$, where $L_{\text{inScatRadiance}}$ is estimated via standard volumetric path tracing [S1, unofficial].
        iv. Else (if $\tau \ge D_{\text{far}}$):
            *   Add surface emission at the far point: $\Delta L \leftarrow \Delta L + L_s(x_{\text{far}}, \omega)$.
    f.  Transmit the accumulated $\Delta L$ from $x_{\text{near}}$ to $x$: $\Delta L \leftarrow T(x_{\text{near}}, x) \Delta L$.
    g.  If $D^- < D^+$, negate the result: $\Delta L \leftarrow -\Delta L$.
3.  **Sharp Edge Handling** (if applicable):
    a.  Calculate normals $n^-$ and $n^+$ at the sharp edge location $x_0$.
    b.  Initialize $\Delta L$ with the difference in surface emission: $\Delta L \leftarrow L_{\text{es}}(x_0, \omega | n^-) - L_{\text{es}}(x_0, \omega | n^+)$.
    c.  Draw a scattering direction $\omega'$ with probability $p(\omega')$.
    d.  Calculate the BSDF difference: $\Delta f_s = f_s(x_0, -\omega', \omega | n^-) - f_s(x_0, -\omega', \omega | n^+)$.
    e.  Add the in-scattering contribution: $\Delta L \leftarrow \Delta L + L_s(x, \omega') \Delta f_s / p(\omega')$.

### Pseudocode
```python
def estimate_delta_L(x, omega, is_boundary_edge, get_distances, get_normals, 
                     surface_emission, transmittance, sigma_s, sigma_t, 
                     in_scatter_radiance, bsdf, surface_emission_sharp):
    """
    Estimates the radiance change Delta L across discontinuities.
    
    Args:
        x: Current position.
        omega: Direction of interest.
        is_boundary_edge: Boolean, True if discontinuity is a boundary/silhouette edge.
        get_distances: Function returning (D_minus, D_plus) for boundary edges.
        get_normals: Function returning (n_minus, n_plus) for sharp edges.
        surface_emission: Function L_s(x, omega) for boundary edges.
        transmittance: Function T(x1, x2).
        sigma_s: Function sigma_s(x).
        sigma_t: Function sigma_t(x).
        in_scatter_radiance: Function L_inScatRadiance(x, omega) using standard path tracing.
        bsdf: Function f_s(x, omega_in, omega_out, normal).
        surface_emission_sharp: Function L_es(x, omega, normal) for sharp edges.
        
    Returns:
        Delta L: Estimated radiance change.
    """
    if is_boundary_edge:
        # Boundary/Silhouette Edge Handling
        D_minus, D_plus = get_distances(x, omega)
        D_near = min(D_minus, D_plus)
        D_far = max(D_minus, D_plus)
        
        x_near = x - D_near * omega
        x_far = x - D_far * omega
        
        # Initialize with negative surface emission at near point
        delta_L = -surface_emission(x_near, omega)
        
        # Trace side path
        tau = draw_free_flight_distance(x_near, omega)
        tau = tau + D_near
        
        if tau < D_far:
            x_prime = x - tau * omega
            # Add in-scattered radiance contribution
            # Note: in_scatter_radiance uses standard volumetric path tracing [S1, unofficial]
            in_scatter = in_scatter_radiance(x_prime, omega)
            delta_L = delta_L + (sigma_s(x_prime) / sigma_t(x_prime)) * in_scatter
        else:
            # Add surface emission at far point
            delta_L = delta_L + surface_emission(x_far, omega)
            
        # Transmit accumulated Delta L from x_near to x
        delta_L = transmittance(x_near, x) * delta_L
        
        # Negate if D_minus < D_plus
        if D_minus < D_plus:
            delta_L = -delta_L
            
    else:
        # Sharp Edge Handling
        n_minus, n_plus = get_normals(x, omega)
        
        # Initialize with difference in surface emission
        delta_L = surface_emission_sharp(x, omega, n_minus) - surface_emission_sharp(x, omega, n_plus)
        
        # Draw scattering direction
        omega_prime = draw_direction_with_probability(p_omega_prime)
        
        # Calculate BSDF difference
        delta_f_s = bsdf(x, -omega_prime, omega, n_minus) - bsdf(x, -omega_prime, omega, n_plus)
        
        # Add in-scattering contribution
        # Note: L_s(x, omega') here refers to the radiance coming from direction omega'
        # which is typically estimated via standard path tracing or similar [S1, unofficial]
        L_s_omega_prime = estimate_radiance_at_direction(x, omega_prime) 
        delta_L = delta_L + L_s_omega_prime * delta_f_s / p_omega_prime
        
    return delta_L
```

### Parameters
*   $p(\omega')$: Probability density function for sampling the scattering direction $\omega'$ in the sharp edge case. Not given in the sources.
*   $\epsilon$: A small offset used in the `inScatRadiance` function when $x$ is on the boundary ($\partial \Omega$) to avoid self-intersection issues. Not given in the sources, but implied by $x + \epsilon \omega$ [S1, unofficial].

### Edge Cases and Pitfalls
*   **Precision**: When $x$ is on the boundary ($\partial \Omega$), the `inScatRadiance` function uses a small offset $\epsilon$ to sample the direction [S1, unofficial]. This requires careful implementation to avoid numerical instability.
*   **Boundary Conditions**: The distinction between $D^-$ and $D^+$ determines the sign of the result. Incorrect ordering can lead to sign errors in $\Delta L$.
*   **Sharp Edge Normals**: The normals $n^-$ and $n^+$ must be correctly identified for the sharp edge case. Incorrect normals will lead to incorrect BSDF and emission differences.

## Operating characteristics
*   **Time Complexity**: Depends on the cost of estimating `inScatterRadiance` and `L_s(x, omega')`, which involves standard volumetric path tracing. The boundary case requires tracing a side path, which may involve multiple scattering events. The sharp edge case requires sampling a direction and evaluating BSDFs.
*   **Memory Complexity**: Low, as it primarily involves storing intermediate radiance values and geometric data.
*   **Strengths**: Provides an unbiased estimate of radiance changes across discontinuities, which is crucial for accurate rendering of participating media with complex geometry.
*   **Limitations**: Can be computationally expensive due to the need for side path tracing and multiple radiance estimations. Sensitivity to geometric precision and normal calculation.

## Background
This method is part of the differential theory of radiative transfer, specifically addressing the estimation of edge integrals in the path integral framework. It was introduced in the context of unbiased rendering of participating media with geometric discontinuities.
