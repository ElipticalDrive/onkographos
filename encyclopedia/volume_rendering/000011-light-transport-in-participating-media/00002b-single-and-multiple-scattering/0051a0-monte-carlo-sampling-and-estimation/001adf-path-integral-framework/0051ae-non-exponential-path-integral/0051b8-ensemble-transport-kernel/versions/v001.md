# Ensemble Transport Kernel

Also called: T(x, four transport functions

## Overview
The Ensemble Transport Kernel $T(\mathbf{x}, \mathbf{y})$ is the segment-wise component used to approximate the ensemble average of light throughput in non-exponential participating media. It replaces the classical transmittance term in the path integral to account for spatial correlations between scatterers. Unlike the classical exponential model, which assumes independent random scatterers, this kernel computes the expected transmittance conditioned on the specific configuration of particles at the segment endpoints. It differs from its sibling [Non-exponential transport kernel via macroscopic optical depth](14530-non-exponential-transport-kernel-via-macroscopic-optical-dep.md) by explicitly handling the four discrete boundary cases (particle-to-particle, free-to-particle, etc.) rather than relying on a continuous macroscopic optical depth approximation.

## How it works
The method approximates the ensemble average of the product of segment transmittances by moving the expectation operator inside the product, assuming segment decorrelation [S1]:

$$
\left\langle \prod_{i=0}^{k-1} \text{Tr}_\mu(\mathbf{x}_i, \mathbf{x}_{i+1}) \Sigma_\mu(\mathbf{x}_{i+1}) \right\rangle \approx \prod_{i=0}^{k-1} \langle T_\mu(\mathbf{x}_i, \mathbf{x}_{i+1}) \rangle \Sigma_\mu(\mathbf{x}_{i+1})
$$

The term $\langle T_\mu(\mathbf{x}_i, \mathbf{x}_{i+1}) \rangle$ is the Ensemble Transport Kernel. It is defined based on the four possible configurations of the segment endpoints $\mathbf{x}_i$ and $\mathbf{x}_{i+1}$ relative to the particle distribution. Let $\text{pp}$, $\text{fp}$, $\text{pf}$, and $\text{ff}$ denote the free-flight probability density functions (PDFs) for segments starting/ending on a particle (p) or in free space (f) [S1].

**Inputs:**
- $\mathbf{x}_i, \mathbf{x}_{i+1}$: Endpoints of the segment.
- $\sigma(\mathbf{x})$: Microscopic scattering coefficient at $\mathbf{x}$.
- $\Sigma(\mathbf{x})$: Macroscopic scattering coefficient, defined as:
  $$
  \Sigma(\mathbf{x}) = \begin{cases} \sigma(\mathbf{x}) & \text{if } \mathbf{x} \text{ is in a particle} \\ 0 & \text{if } \mathbf{x} \text{ is in free space} \end{cases}
  $$
  [S1]

**Outputs:**
- $T(\mathbf{x}_i, \mathbf{x}_{i+1})$: The ensemble-averaged transport kernel value.

**Data Structures:**
- The kernel requires access to the free-flight PDFs $\text{pp}(\mathbf{x}, \mathbf{y})$, $\text{fp}(\mathbf{x}, \mathbf{y})$, $\text{pf}(\mathbf{x}, \mathbf{y})$, and $\text{ff}(\mathbf{x}, \mathbf{y})$. These are derived from the underlying stochastic medium model (e.g., Boolean model of grains) [S1].

**Steps:**
1. Determine the configuration of the segment endpoints. Let $C_i$ and $C_{i+1}$ be indicators where $1$ denotes "in a particle" and $0$ denotes "in free space".
2. Select the appropriate free-flight PDF based on the configuration:
   - If $C_i=1, C_{i+1}=1$: Use $\text{pp}(\mathbf{x}_i, \mathbf{x}_{i+1})$.
   - If $C_i=0, C_{i+1}=1$: Use $\text{fp}(\mathbf{x}_i, \mathbf{x}_{i+1})$.
   - If $C_i=1, C_{i+1}=0$: Use $\text{pf}(\mathbf{x}_i, \mathbf{x}_{i+1})$.
   - If $C_i=0, C_{i+1}=0$: Use $\text{ff}(\mathbf{x}_i, \mathbf{x}_{i+1})$.
3. Compute the kernel value. The general form relates the kernel to the selected PDF. For the particle-to-particle case, the kernel evaluates to the particle-to-particle free-flight PDF normalized by the density, effectively representing the average transmittance conditioned on both endpoints lying on a particle [S1].
   $$
   T(\mathbf{x}_i, \mathbf{x}_{i+1}) = \frac{\text{PDF}(\mathbf{x}_i, \mathbf{x}_{i+1})}{\text{Normalization Factor}}
   $$
   *Note: The exact normalization factors for fp, pf, and ff cases are not explicitly detailed in the provided text, but the principle is that $T$ represents the ensemble average of transmittance for the specific boundary condition.* [S1]

**Pitfalls:**
- **Non-reciprocity:** The initial transport kernel $T(\mathbf{x}, \mathbf{y})$ is not reciprocal, i.e., $T(\mathbf{x}, \mathbf{y}) \neq T(\mathbf{y}, \mathbf{x})$ in the general case [S1]. This occurs because:
  1. Free-flight PDFs (such as $\text{pp}$) are not generally reciprocal.
  2. Swapping the endpoints of a surface-to-medium segment causes a different case statement to be evaluated (e.g., $\text{fp}$ vs $\text{pf}$) [S1].
- **Precision:** The distinction between "in a particle" and "in free space" requires robust geometric queries, especially in heterogeneous media where density varies [S1].

**Pseudocode:**
```python
def ensemble_transport_kernel(x_i, x_j, sigma, pdf_pp, pdf_fp, pdf_pf, pdf_ff):
    """
    Computes the non-reciprocal ensemble transport kernel T(x_i, x_j).
    
    Args:
        x_i, x_j: 3D coordinates of segment endpoints.
        sigma: Function returning microscopic scattering coefficient at a point.
        pdf_pp, pdf_fp, pdf_pf, pdf_ff: Functions returning the respective 
                                         free-flight PDF values.
    
    Returns:
        T: The transport kernel value.
    """
    # Determine if points are in a particle (1) or free space (0)
    # [G] Implementation detail: 'in_particle' depends on the specific 
    # stochastic medium definition (e.g., Boolean model).
    in_p_i = is_in_particle(x_i)
    in_p_j = is_in_particle(x_j)
    
    # Select the appropriate free-flight PDF
    if in_p_i and in_p_j:
        pdf_val = pdf_pp(x_i, x_j)
        # For pp, T is related to pp / sigma(y) or similar normalization
        # The text states T_tilde evaluates pp(x,y)/sigma(y) for reciprocity.
        # For the non-reciprocal T, we use the raw PDF structure.
        # Exact normalization for non-reciprocal T is not fully specified 
        # in the snippet, but it resembles Tr * Sigma.
        # We assume the kernel value is the PDF itself or normalized by 
        # the probability of the configuration.
        # [G] Standard interpretation: T(x,y) = PDF(x,y) / Prob(Configuration)
        # However, the text links T to Tr * Sigma. 
        # We return the PDF value as the core component, noting normalization 
        # is required for the final throughput product.
        return pdf_val 
    elif not in_p_i and in_p_j:
        return pdf_fp(x_i, x_j)
    elif in_p_i and not in_p_j:
        return pdf_pf(x_i, x_j)
    else:
        return pdf_ff(x_i, x_j)
```

## Subtopics

### Reciprocal Transport Kernel
The Reciprocal Transport Kernel $\tilde{T}(\mathbf{x}, \mathbf{y})$ is a modified version of the ensemble transport kernel that ensures reciprocity ($\tilde{T}(\mathbf{x}, \mathbf{y}) = \tilde{T}(\mathbf{y}, \mathbf{x})$). It is defined by rearranging the scattering coefficients $\Sigma$ into the vertex terms. The final reciprocal path throughput is given by:
$$
\langle g_\mu(\bar{\mathbf{x}}) \rangle \approx \left[ \prod_{i=1}^{k-1} f(\mathbf{x}_i) \Sigma(\mathbf{x}_i) \right] \left[ \prod_{i=0}^{k-1} \tilde{T}(\mathbf{x}_i, \mathbf{x}_{i+1}) G(\mathbf{x}_i, \mathbf{x}_{i+1}) \right]
$$
[S1]
The kernel $\tilde{T}$ evaluates only averages of transmittance for all four possible configurations of a segment. Specifically, for a segment with both endpoints in the medium, it evaluates $\text{pp}(\mathbf{x}, \mathbf{y})/\sigma(\mathbf{y})$. This formulation is equivalent to averaging the transmittance along a segment conditioned on both endpoints lying on a particle. Since classical transmittance and its averages are reciprocal, $\tilde{T}$ is reciprocal. This formulation differs from the exponential case only by the replacement of transmittance $\text{Tr}$ with $\tilde{T}$, making it straightforward to simulate with existing bidirectional rendering methods [S1].

## Operating characteristics
- **Time Complexity:** Depends on the evaluation of the four free-flight PDFs. For complex media, these PDFs may require expensive geometric queries or integrals.
- **Memory Complexity:** Requires storing or computing the free-flight PDFs for the specific medium model.
- **Strengths:** Accurately models light transport in media with strong spatial correlations (non-exponential statistics) where the classical Beer-Lambert law fails.
- **Limitations:** The non-reciprocal version cannot be directly used in standard bidirectional path tracing without modification. The reciprocal version requires moving $\Sigma$ terms to vertices, which may complicate implementation in some existing renderers.
- **When to use:** When simulating participating media with clustered or correlated scatterers (e.g., clouds, fog with grains) where the exponential assumption is invalid.

## Background
The Ensemble Transport Kernel was introduced in the context of a radiative transfer framework for non-exponential media. It builds upon the general Boltzmann Equation of Larsen and Vasques [S1]. The method was developed to address the limitation of classical path integral formulations that assume independent random scatterers (exponential media). By decorrelating path segments and computing ensemble averages independently for each segment, the framework allows for the simulation of heterogeneous media with arbitrary correlation structures [S1].
