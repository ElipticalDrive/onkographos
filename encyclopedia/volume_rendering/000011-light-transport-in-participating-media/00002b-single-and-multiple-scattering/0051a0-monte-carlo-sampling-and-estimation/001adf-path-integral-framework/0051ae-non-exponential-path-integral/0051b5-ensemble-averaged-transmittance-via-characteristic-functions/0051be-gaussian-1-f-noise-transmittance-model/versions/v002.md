# Gaussian 1/f^β noise transmittance model

Also called: Normal distribution transmittance

## Overview
The Gaussian 1/f^β noise transmittance model computes the ensemble-averaged transmittance for participating media where the line-averaged extinction coefficient follows a Gaussian distribution derived from 1/f^β fractal noise [S1]. It differs from the [Gamma-distributed 1/f^β noise transmittance model](14552-gamma-distributed-1-f-noise-transmittance-model.md) by assuming a symmetric normal distribution for density fluctuations, which yields a closed-form analytic solution but permits nonphysical negative extinction values [S1].

## How it works
**Inputs:**
*   $t$: Ray distance along the path ($t \ge 0$) [S1].
*   $\mu_\sigma$: Mean extinction coefficient of the medium ($\mu_\sigma > 0$) [S1].
*   $C$: Noise amplitude parameter ($C > 0$) [S1].
*   $\beta$: Spectral exponent of the fractal noise [S1].

**Outputs:**
*   $\mathbf{f}_{\mathcal{N}}(t \mid \boldsymbol{\psi})$: Ensemble-averaged transmittance [S1].

**Data Structures:**
The method requires no complex data structures and operates directly on scalar parameters $\boldsymbol{\psi} = \{\mu_\sigma, C, \beta\}$ [S1].

**Numbered Steps:**
1. Compute the mean attenuation term: $A = \mu_\sigma \cdot t$ [S1].
2. Compute the noise scaling base: $B = C \cdot \mu_\sigma \cdot t$ [S1].
3. Compute the variance correction: $E = \frac{1}{2} B^{\beta+1}$ [S1].
4. Compute the total exponent: $X = -A + E$ [S1].
5. Return $\exp(X)$ [S1].

**Formulas:**
The line-averaged extinction coefficient $\overline{\sigma}_\mu$ is modeled as a Gaussian random variable $\mathcal{N}(\mu_\sigma, \nu(t))$ [S1]. The ensemble-averaged transmittance is derived by evaluating the characteristic function of the normal distribution $\varphi(r) = e^{ir\mu_\sigma - r^2\nu/2}$ at $r = ti$ [S1]. This yields the closed-form expression:
$$\mathbf{f}_{\mathcal{N}}(t \mid \boldsymbol{\psi}) = e^{-\mu_{\sigma} t + (C\mu_{\sigma} t)^{\beta+1}/2} \quad (35)$$
where every symbol is defined in the inputs section [S1].

**Parameters:**
Typical values are Not given in the sources. The parameter $\mu_\sigma$ must be sufficiently high and the variance sufficiently low to ensure negative extinction values are statistically unlikely [S1]. The spectral exponent $\beta$ governs the fractal noise properties [S1].

**Edge Cases and Pitfalls:**
The Gaussian distribution is supported on the entire real line, assigning non-zero probability to negative extinction coefficients ($\sigma_\mu < 0$), which are nonphysical [S1]. The model is only reasonable when $\mu_\sigma$ is set sufficiently high and the variance is set sufficiently low so that negative extinction coefficients are unlikely [S1]. For large $t$, the term $(C\mu_\sigma t)^{\beta+1}$ may grow rapidly, potentially causing overflow in the exponent if $\beta+1 > 0$ [G]. Conversely, if $\beta+1 < 0$ and $t$ is small, precision issues may arise [G].

**Pseudocode:**
```python
import math

def gaussian_1f_beta_transmittance(t, mu_sigma, C, beta):
    """Computes the ensemble-averaged transmittance using the Gaussian 1/f^beta model."""
    mean_atten = mu_sigma * t
    noise_base = C * mu_sigma * t
    # Guard against 0^negative exponent which raises ZeroDivisionError in Python
    if noise_base == 0.0:
        exponent_correction = 0.0 if beta + 1 > 0 else float('inf')
    else:
        exponent_correction = 0.5 * (noise_base ** (beta + 1))
    total_exponent = -mean_atten + exponent_correction
    return math.exp(total_exponent)
```

## Operating characteristics
Time complexity is $O(1)$ due to a constant number of arithmetic operations and a single exponential evaluation [G]. Memory complexity is $O(1)$ as no auxiliary storage is required beyond the input parameters [G]. The method provides a closed-form analytic solution that avoids numerical integration or sampling [S1]. Transmittance scales non-linearly with distance $t$ according to the exponent $(C\mu_\sigma t)^{\beta+1}$ [S1]. The primary strength is computational efficiency for media where the Gaussian approximation holds [S1]. The primary limitation is the Gaussian assumption, which permits nonphysical negative extinction values [S1]. It is an approximation of the true transmittance for 1/f^β noise media [S1]. Use the model when computational efficiency is critical and the medium parameters allow for the Gaussian approximation (high mean, low variance relative to mean) [S1]. Use the [Gamma-distributed 1/f^β noise transmittance model](14552-gamma-distributed-1-f-noise-transmittance-model.md) when the mean extinction is low or the variance is high, making the Gaussian approximation inaccurate due to the significant probability of negative extinction [S1].

## Background
The model is based on work by Davis and Mineev-Weinstein [2011], who formally derived the distance-dependent Gaussian distribution for line-averaged density [S1]. The approach operates within a broader framework for non-exponential path integrals in volume rendering [S1]. The underlying 1/f^β noise generates fractional Brownian motion with exponent $\beta+2$ via integration [S1].
