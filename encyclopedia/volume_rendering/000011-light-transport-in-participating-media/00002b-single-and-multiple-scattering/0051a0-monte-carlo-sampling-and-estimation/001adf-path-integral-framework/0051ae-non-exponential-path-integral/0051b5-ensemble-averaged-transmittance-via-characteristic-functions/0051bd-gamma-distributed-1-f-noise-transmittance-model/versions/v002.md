# Gamma-distributed 1/f^β noise transmittance model

Also called: Gamma distribution transmittance

## Overview
This method computes the ensemble-averaged transmittance of participating media by modeling the line-averaged micro-scale density as a Gamma-distributed random variable [S1]. It solves the problem of non-physical negative extinction coefficients inherent in Gaussian approximations [S1]. Unlike the [Gaussian 1/f^β noise transmittance model](14555-gaussian-1-f-noise-transmittance-model.md), which allows negative values, the Gamma model ensures strictly non-negative extinction, making it suitable for heterogeneous media where the mean extinction is low relative to the variance [S1].

## How it works
**Inputs:**
*   $\mu_\sigma$: Mean extinction coefficient.
*   $C$: Amplitude of variation (noise strength).
*   $\beta$: Spectral exponent (color of noise).
*   $t$: Path length.

**Outputs:**
*   $\text{ff}_\Gamma(t \mid \psi)$: Ensemble-averaged transmittance.

**Data Structures:**
Not given in the sources.

**Steps:**
1.  Compute the variance of the line-averaged density, $\nu_{\overline{\sigma}\mu}(t)$, by matching the Gaussian model's characteristic function exponent [S1].
2.  Calculate the shape parameter $\alpha(t)$ using the mean and variance [S1].
3.  Compute the transmittance using the characteristic function of the Gamma distribution [S1].

**Formulas:**
The closed-form transmittance is:
$$ \text{ff}_\Gamma(t \mid \psi) = \left(1 + \frac{\mu_\sigma t}{\alpha(t)}\right)^{-\alpha(t)} \quad (36) $$
The shape parameter is:
$$ \alpha(t) = \frac{\mu_\sigma^2}{\nu_{\overline{\sigma}\mu}(t)} = \frac{\mu_\sigma^{1-\beta} t^{1-\beta}}{C^{\beta+1}} \quad (37) $$
Note: The source text contains a typographical error in Eq 37; the corrected form above matches the variance derivation from the Gaussian model and reduces to the constant $\alpha = C^{-2}$ for pink noise [S1]. The variance scaling is derived from the Gaussian exponent term $\nu_{\overline{\sigma}\mu}(t) t^2 / 2 = (C \mu_\sigma t)^{\beta+1} / 2$, yielding $\nu_{\overline{\sigma}\mu}(t) = C^{\beta+1} \mu_\sigma^{\beta+1} t^{\beta-1}$ [S1].

**Parameters:**
*   $\mu_\sigma > 0$: Mean extinction [S1].
*   $C \ge 0$: Amplitude of variation [S1].
*   $\beta \ge 0$: Spectral exponent [S1].

**Edge Cases:**
*   **Homogeneous/White Noise:** If $C=0$ or $\beta=0$, the variance vanishes, $\alpha \to \infty$, and the model reduces to the standard exponential transmittance $e^{-\mu_\sigma t}$ [S1].
*   **Precision:** For very large $\alpha$, numerical stability of $(1 + x/\alpha)^{-\alpha}$ should be handled using `exp(-x)` or logarithmic evaluation to avoid precision loss [G].

**Pseudocode:**
```python
import math

def gamma_transmittance(mu_sigma, C, beta, t):
    """
    Compute ensemble-averaged transmittance using the Gamma-distributed 1/f^beta noise model.
    
    Args:
        mu_sigma: Mean extinction coefficient.
        C: Amplitude of variation.
        beta: Spectral exponent.
        t: Path length.
        
    Returns:
        Transmittance value.
    """
    if t == 0.0:
        return 1.0
        
    # Variance of line-averaged density derived from Gaussian model exponent matching
    nu = (C ** (beta + 1)) * (mu_sigma ** (beta + 1)) * (t ** (beta - 1))
    
    if nu == 0.0:
        # Variance is zero, alpha is infinite, returns exponential
        return math.exp(-mu_sigma * t)
        
    # Shape parameter
    alpha = (mu_sigma ** 2) / nu
    
    # Transmittance: (1 + mu*t/alpha)^(-alpha)
    term = 1.0 + (mu_sigma * t) / alpha
    
    # Log-exp formulation for numerical stability
    return math.exp(-alpha * math.log(term))
```

## Subtopics

### Pink noise special case
A special case where the spectral exponent $\beta = 1$ (pink noise) [S1]. In this scenario, the distribution of extinction values becomes independent of the path length $t$ [S1]. The variance reduces to $v_{\overline{\sigma}\mu} = C^2 \mu_\sigma^2$, making the shape parameter constant: $\alpha = C^{-2}$ [S1]. The transmittance reduces to the characteristic function of the static probability density function:
$$ \text{ff}_{\text{pink}}(t) = \varphi_{\bar{\sigma}_\mu}(t) = \int_0^\infty e^{-t\bar{\sigma}_\mu} \text{pdf}(\bar{\sigma}_\mu) \, d\bar{\sigma}_\mu \quad (38) $$
This scale-invariant property simplifies the transmittance to a direct integral over the static PDF [S1].

## Operating characteristics
*   **Time Complexity:** Not given in the sources.
*   **Memory Complexity:** Not given in the sources.
*   **Strengths:** Guarantees non-negative extinction coefficients, avoiding the non-physical artifacts of the Gaussian model [S1]. Provides a closed-form solution for non-exponential transmittance [S1].
*   **Limitations:** More complex than the exponential model [S1]. Requires tuning of three parameters ($\mu_\sigma, C, \beta$) [S1].
*   **When to use:** When simulating heterogeneous media with significant density fluctuations where the mean extinction is not sufficiently high to make negative Gaussian samples negligible [S1].

## Background
The Gamma-distributed model was proposed by Davis and Mineev-Weinstein [2011] to address the limitations of the Gaussian approximation in the path integral framework for non-exponential media [S1]. It is part of the broader effort to model light transport in participating media with fractal $1/f^\beta$ noise density distributions [S1].
