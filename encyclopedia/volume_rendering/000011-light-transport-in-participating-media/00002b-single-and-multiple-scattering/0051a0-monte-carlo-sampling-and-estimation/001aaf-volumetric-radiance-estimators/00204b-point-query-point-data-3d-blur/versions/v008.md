# Point Query × Point Data, 3D Blur

Also called: Conventional Radiance Estimation, Standard volumetric radiance estimate, Jensen and Christensen estimate

## Overview
Point Query × Point Data, 3D Blur estimates the in-scattered radiance at a query point by aggregating the energy of discrete photon points stored within a surrounding three-dimensional volume [S2]. It solves the problem of approximating the integral of incoming radiance from all directions by converting a continuous density estimation problem into a discrete summation over a spherical kernel [S2]. It differs from its child, [Beam Query × Beam Data, 2D Blur](4555-beam-query-beam-data-2d-blur.md), by using discrete point data and blurring in three dimensions rather than restricting the spatial blur to a two-dimensional cross-section [S1].

## How it works
**Inputs and Outputs**
*   **Input:** A query position $\mathbf{x}$, a view direction $\vec{\omega}$, a photon map containing discrete photon points, a spherical kernel radius $r$, and the scattering coefficient $\sigma_s$ of the medium [S2].
*   **Output:** The estimated in-scattered radiance $L_i(\mathbf{x} \rightarrow \vec{\omega})$ at the query point [S2].

**Data Structures**
The photon map stores discrete photon points [S2]. Each photon point $p$ contains position $\mathbf{x}_p$, power $\Phi_p$, and direction $\vec{\omega}_p$ [S2].

**Algorithm**
1.  Define a three-dimensional query region $R$ centered at $\mathbf{x}$, typically a sphere of radius $r$ [S2].
2.  Identify all photons $p$ in the photon map such that $\mathbf{x}_p \in R$ [S2].
3.  For each photon $p$, compute the phase function value $f(\theta_p)$, where $\theta_p$ is the scattering angle between the incoming photon direction and the view direction $\vec{\omega}$ [S2].
4.  Sum the product of the phase function and photon power for all photons in $R$ [S2].
5.  Divide the sum by the scattering coefficient $\sigma_s$ and the volume measure $\mu_R(r^3)$ [S2].

**Formula**
The in-scattered radiance $L_i(\mathbf{x} \rightarrow \vec{\omega})$ is estimated as [S2]:

$$
L_i(\mathbf{x} \rightarrow \vec{\omega}) \approx \frac{1}{\sigma_s \mu_R(r^3)} \sum_{p \in R} f(\theta_p) \Phi_p
$$

Where:
*   $\sigma_s$: Scattering coefficient of the medium ($m^{-1}$) [S2].
*   $\mu_R(r^3)$: Volume measure of the query region. For a sphere of radius $r$, $\mu_R(r^3) = \frac{4}{3}\pi r^3$ [S2].
*   $R$: The set of photon indices $p$ such that $\|\mathbf{x}_p - \mathbf{x}\| \le r$ [S2].
*   $f(\theta_p)$: Phase function value for the scattering angle $\theta_p$ [S2].
*   $\Phi_p$: Power of photon $p$ [S2].

```python
def point_query_point_data_3d_blur(query_point, view_direction, photon_map, radius, scattering_coefficient):
    """
    Estimates in-scattered radiance at query_point using Point Query x Point Data, 3D Blur.
    
    Args:
        query_point (Vector3): The position x where radiance is estimated.
        view_direction (Vector3): The view direction omega.
        photon_map (List[Photon]): List of photon points.
        radius (float): The spherical kernel radius r.
        scattering_coefficient (float): The scattering coefficient sigma_s.
        
    Returns:
        float: Estimated in-scattered radiance.
    """
    # 1. Compute volume measure of the spherical kernel
    volume_measure = (4.0 / 3.0) * math.pi * (radius ** 3)
    
    # 2. Initialize summation accumulator
    total_weighted_power = 0.0
    
    # 3. Search for photons within the spherical kernel
    for photon in photon_map:
        # Check if photon is within radius r of query_point
        if vector_length_sq(photon.position - query_point) <= radius * radius:
            # 4. Compute scattering angle cosine
            # Photon direction is the direction it traveled; incoming direction is opposite
            incoming_direction = (-photon.direction.x, -photon.direction.y, -photon.direction.z)
            # Normalize incoming direction
            inv_len_in = 1.0 / math.sqrt(vector_length_sq(incoming_direction))
            incoming_direction = (incoming_direction[0] * inv_len_in, 
                                  incoming_direction[1] * inv_len_in, 
                                  incoming_direction[2] * inv_len_in)
            # Normalize view direction
            inv_len_v = 1.0 / math.sqrt(vector_length_sq(view_direction))
            view_dir_norm = (view_direction.x * inv_len_v, 
                             view_direction.y * inv_len_v, 
                             view_direction.z * inv_len_v)
            # Dot product gives cos(theta_p)
            cos_theta = incoming_direction[0] * view_dir_norm[0] + \
                        incoming_direction[1] * view_dir_norm[1] + \
                        incoming_direction[2] * view_dir_norm[2]
            # Clamp to [-1, 1] to handle floating point errors
            cos_theta = max(-1.0, min(1.0, cos_theta))
            
            # 5. Evaluate phase function and accumulate
            phase_value = phase_function(cos_theta)
            total_weighted_power += phase_value * photon.power
            
    # 6. Normalize by sigma_s and volume measure
    if scattering_coefficient == 0 or volume_measure == 0:
        return 0.0
        
    radiance = total_weighted_power / (scattering_coefficient * volume_measure)
    
    return radiance
```

**Parameters**
*   $r$: The radius of the spherical kernel [S1].
*   $\sigma_s$: The scattering coefficient of the medium [S2].

**Edge Cases and Pitfalls**
*   **Empty Kernel:** If no photons fall within the radius $r$, the summation evaluates to zero [S2].
*   **Division by Zero:** The estimate is undefined if $\sigma_s = 0$ or $r = 0$ [S2].
*   **Adaptive Kernels:** The notation assumes spatially constant query regions for simplicity, though spatially adaptive blurring kernels are possible [S2].

## Subtopics

### [Beam Query × Beam Data, 2D Blur](4555-beam-query-beam-data-2d-blur.md)
Computes accumulated in-scattered radiance along an eye ray by querying photon beams and blurring their energy in two dimensions perpendicular to the beam direction. It differs from this method by using continuous beam data instead of discrete point data and restricting the spatial blur to a 2D cross-section, thereby reducing bias for the same radius. Choose it when high accuracy in anisotropic scattering is required and computational cost allows for beam-based structures.

### [Point Query × Beam Data, 3D Blur](4556-point-query-beam-data-3d-blur.md)
Computes in-scattered radiance at a point using photon beams with a 3D blur. It differs from this method by treating discrete beams as limits of continuous beams and integrating transmittance along the beam within the kernel. Choose it when photon beams are available and a 3D blur is desired for the query point.

### [Beam Query × Point Data, 3D Blur](4557-beam-query-point-data-3d-blur.md)
Computes accumulated in-scattered radiance along a camera ray by querying photon points with a 3D blur. It differs from this method by evaluating transmittance from the photon point towards the eye and integrating it around the photon point, rather than from the query point to the beam start. Choose it when estimating beam radiance for volume rendering along eye rays.

## Background
The method was introduced by Jensen and Christensen in 1998 as the standard volumetric radiance estimate for photon mapping in participating media [S2]. It is based on the principle of density estimation, where radiance is approximated by the average power of photons within a local volume [S2]. It serves as a fundamental component of volumetric photon mapping algorithms [S1].
