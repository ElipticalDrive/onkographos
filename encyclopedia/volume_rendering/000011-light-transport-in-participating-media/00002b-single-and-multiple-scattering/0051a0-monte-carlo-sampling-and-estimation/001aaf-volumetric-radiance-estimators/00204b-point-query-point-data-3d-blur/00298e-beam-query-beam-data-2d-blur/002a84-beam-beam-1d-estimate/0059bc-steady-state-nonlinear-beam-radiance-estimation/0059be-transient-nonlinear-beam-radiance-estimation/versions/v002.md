# Transient Nonlinear Beam Radiance Estimation

Also called: Transient beam estimation

## Overview
Transient Nonlinear Beam Radiance Estimation extends steady-state beam estimation to time-dependent light transport by reconstructing emission signals using time-of-flight (TOF) data stored in the photon map [S1]. It differs from naive 4D photon mapping by assuming quasi-static media and light sources, thereby reusing the spatial photon distribution and using TOF to reconstruct the temporal signal, which avoids the increased photon count required for temporal density estimation [S1].

## How it works
**Inputs and Outputs**
*   **Input:** A photon map containing spatial nodes $\mathbf{u}_j$, each associated with a stored time-of-flight (TOF) value from the emitter to the node, and a light source identifier [S1].
*   **Input:** The absolute observation time $t$ at the query point $\mathbf{x}$ [S1].
*   **Input:** The emission function of the light source, mapping absolute emission time to flux [S1].
*   **Output:** The estimated transient basic radiance $\tilde{L}_b(\mathbf{x}, \boldsymbol{\omega}, t)$ along a curved beam direction $\boldsymbol{\omega}$ [S1].

**Data Structures**
The photon map stores nodes $\mathbf{u}_j$ [S1]. Each node contains:
*   Position $\mathbf{u}_j$ [S1].
*   Time-of-flight (TOF) from the light source to $\mathbf{u}_j$, denoted as $TOF_j$ [S1].
*   Light source identifier [S1].
*   Spatial flux contribution $\Delta \Phi_j$ [S1].

**Numbered Steps**
1.  **Trace and Store TOF:** During the time integration of the curved beam trajectory from the light source to the query point $\mathbf{x}$, compute the TOF for each node $\mathbf{u}_j$ along the path and store these TOF values together with the nodes in a list [S1].
2.  **Determine Node Time:** For each of the $k$ nearest neighbors $\mathbf{u}_j$ to $\mathbf{x}$, determine the time $t'(\mathbf{u}_j)$ at point $\mathbf{u}_j$ as the absolute time $t$ minus the TOF from $\mathbf{x}$ to $\mathbf{u}_j$ [S1].
3.  **Reconstruct Emission Time:** Reconstruct the absolute emission time from the photon map's stored TOF [S1].
4.  **Lookup Time-Dependent Flux:** Using the light source identifier and the reconstructed emission time, perform a lookup in the light source's emission function to determine the time-dependent flux $\Delta \Phi_j(t'(\mathbf{u}_j))$ that each photon contributes with respect to absolute time $t$ [S1].
5.  **Estimate Radiance:** Compute the sum over the $k$ nearest neighbors using the formula below [S1].

**Pseudocode**
```python
def estimate_transient_beam_radiance(x, omega, t, photon_map, emission_function):
    # 1. Trace and Store TOF: During time integration of the curved beam trajectory from the light source to x,
    # compute the TOF for each node uj along the path and store these TOF values together with the nodes in a list [S1].
    nodes, tofs = trace_beam_trajectory(x)

    # 2. Determine Node Time: For each of the k nearest neighbors uj to x,
    # determine the time t'(uj) at point uj as the absolute time t minus the TOF from x to uj [S1].
    k_nearest = find_k_nearest(nodes, x, k)
    t_prime = [t - compute_tof_between_nodes(x, uj, tofs) for uj in k_nearest]

    # 3. Reconstruct Emission Time: Reconstruct the absolute emission time from the photon map's stored TOF [S1].
    emission_times = reconstruct_emission_time(t_prime, tofs)

    # 4. Lookup Time-Dependent Flux: Using the light source identifier and the reconstructed emission time,
    # perform a lookup in the light source's emission function to determine the time-dependent flux Delta_Phi_j(t'(uj)) [S1].
    fluxes = [emission_function(node.light_id, t_emit) for node, t_emit in zip(k_nearest, emission_times)]

    # 5. Estimate Radiance: Compute the sum over the k nearest neighbors using the formula [S1].
    radiance = 0.0
    for j, (uj, t_prime_j, flux_j) in enumerate(zip(k_nearest, t_prime, fluxes)):
        radiance += transmittance(uj, x) * (sigma_t(uj) / n(uj)**2) * K(r_j, d_j) * flux_j * phase_function(uj.omega_in, uj.omega_out)
    return radiance
```

**Formula**
The estimated transient basic radiance is:
$$
\tilde{L}_b(\mathbf{x}, \boldsymbol{\omega}, t) \approx \sum_{j=1}^k \tau(\mathbf{u}_j, \mathbf{x}) \frac{\sigma_t(\mathbf{u}_j)}{n(\mathbf{u}_j)^2} K(r_j, d_j) \Delta \Phi_j(t'(\mathbf{u}_j)) P(\boldsymbol{\omega}_j, \boldsymbol{\omega}'(\mathbf{u}_j))
$$
Where:
*   $\tau(\mathbf{u}_j, \mathbf{x})$ is the transmittance from node $\mathbf{u}_j$ to query point $\mathbf{x}$ [S1].
*   $\sigma_t(\mathbf{u}_j)$ is the extinction coefficient at $\mathbf{u}_j$ [S1].
*   $n(\mathbf{u}_j)$ is the refractive index at $\mathbf{u}_j$ [S1].
*   $K(r_j, d_j)$ is a kernel term used in the estimator [S1].
*   $\Delta \Phi_j(t'(\mathbf{u}_j))$ is the time-dependent flux contribution of the $j$-th photon [S1].
*   $P(\boldsymbol{\omega}_j, \boldsymbol{\omega}'(\mathbf{u}_j))$ is the phase function evaluating scattering from the photon's incoming direction $\boldsymbol{\omega}_j$ to the beam direction $\boldsymbol{\omega}'(\mathbf{u}_j)$ at $\mathbf{u}_j$ [S1].

**Parameters**
*   $k$: Number of nearest neighbors. Not given in the sources.
*   $r_j, d_j$: Kernel parameters. Not given in the sources.

**Edge Cases and Pitfalls**
*   **Quasi-static Assumption:** The method assumes the medium and light sources are quasi-static, allowing reuse of the spatial photon distribution for each point in time [S1].
*   **Refractive Index Cancellation:** The term $n^2(\mathbf{x})$ in the radiance definition does not cancel out with $1/n^2(\mathbf{u}_j)$ in the estimator because these values depend on different positions along the ray [S1].
*   **High-Frequency Emission:** The method avoids increased photon counts even if light source emission functions contain high frequencies, by relying on TOF reconstruction [S1].

## Operating characteristics
*   **Time Complexity:** Dominated by the nearest neighbor search in the photon map and the emission function lookup. Not given in the sources.
*   **Memory Complexity:** Requires storing TOF values for each photon in the map, adding a small overhead to the standard spatial photon map. Not given in the sources.
*   **Strengths:** Avoids the need for a 4D photon map (spatial + time), which would raise the number of photons even further, especially if the emission functions of the light sources contain high frequencies [S1]. Reuses the spatial distribution of the photons for each point in time [S1].
*   **Limitations:** Relies on the quasi-static assumption for media and light sources [S1].

## Background
*   **Origin:** The method is an extension of the nonlinear beam estimation technique for steady-state rendering, adapted for transient rendering by incorporating time-of-flight data [S1].
*   **History:** It builds upon standard photon mapping extensions for transient rendering, such as those by Jarabo [2012] for surface-based transient rendering, but applies them to volumetric participating media with continuous refraction [S1].
*   **Implementation:** Implemented in C++ as a custom integrator plugin in the Mitsuba renderer [S1].
