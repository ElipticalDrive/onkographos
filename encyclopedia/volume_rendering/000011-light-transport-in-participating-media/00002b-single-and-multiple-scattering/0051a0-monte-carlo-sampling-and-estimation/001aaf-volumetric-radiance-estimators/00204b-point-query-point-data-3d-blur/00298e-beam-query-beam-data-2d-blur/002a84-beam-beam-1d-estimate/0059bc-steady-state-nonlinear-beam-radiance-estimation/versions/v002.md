# Steady-State Nonlinear Beam Radiance Estimation
Also called: Beam radiance estimation with curved beams, Nonlinear beam estimation of basic radiance

## Overview
Steady-State Nonlinear Beam Radiance Estimation is a technique for estimating basic radiance along curved beam trajectories in continuously refractive (heterogeneous) participating media [S1]. It solves the problem of accurately computing in-scattering light transport when the medium's refractive index varies spatially, which causes light paths to curve [S1]. Unlike its sibling [Beam × Beam 1D estimate](4776-beam-beam-1d-estimate.md), which assumes straight-line propagation, this method integrates transmittance and scattering along numerically computed curved ray trajectories, accounting for the $n^{-2}$ term in the radiative transfer equation [S1]. It builds on [Beam × Beam 1D estimate](4776-beam-beam-1d-estimate.md) by extending the beam query to handle non-linear paths [S1].

## How it works
The method operates in two main phases: trajectory computation and radiance estimation [S1]. It relies on a pre-computed photon map containing scattered photons with associated flux weights [S1].

**Inputs:**
- A list of curved beam trajectories, where each beam is defined by a sequence of nodes $\mathbf{x}_i$ [S1].
- A photon map containing photons $j=1 \dots N$, each with position $\mathbf{x}_j$, weight $\Delta \Phi_j$, direction $\boldsymbol{\omega}_j$, and radius $r_j$ [S1].
- Medium properties: extinction coefficient $\sigma_t(\mathbf{x})$, refractive index $n(\mathbf{x})$, and phase function $P(\boldsymbol{\omega}_{in}, \boldsymbol{\omega}_{out})$ [S1].
- A smoothing function $K(r, d)$ [S1].

**Outputs:**
- For each point $\mathbf{x}$ along each curved beam and viewing direction $\boldsymbol{\omega}$, the final beam radiance $L_b(\mathbf{x}, \boldsymbol{\omega})$ [S1].

**Data Structures:**
1.  **Beam Node List:** For each curved beam, a list of nodes [S1]. Each node stores:
    -   Position $\mathbf{x}_i$ (3D vector) [S1].
    -   Transmittance $\tau(\mathbf{x}_0, \mathbf{x}_i)$ from the beam origin to the node [S1].
2.  **Photon Map:** Standard photon map structure storing photon attributes [S1].

**Step 1: Compute Beam Trajectories and Transmittance**
For each curved beam:
1.  Compute the trajectory using a 4th-order Runge-Kutta (RK4) solver [S1].
2.  Store the node positions $\mathbf{x}_i$ in a list [S1].
3.  Compute the transmittance $\tau(\mathbf{x}_0, \mathbf{x}_i)$ for each node using the composite Simpson's rule [S1].
4.  Store the transmittance values associated with the nodes in the list [S1].

**Step 2: Estimate Basic Radiance**
For each point $\mathbf{x}$ along the curved beam and viewing direction $\boldsymbol{\omega}$:
1.  Identify the $k$ photons that contribute to the curved beam based on their radius $r_j$ and distance $d_j$ to the beam [S1].
2.  For each contributing photon $j$:
    -   Determine $\mathbf{u}_j$, the projected location of the $j$-th photon onto the closest curve segment of the beam [S1].
    -   Look up and interpolate the transmittance $\tau(\mathbf{u}_j, \mathbf{x})$ from the previously computed list of node transmittances [S1].
    -   Evaluate the medium properties at $\mathbf{u}_j$: $\sigma_t(\mathbf{u}_j)$ and $n(\mathbf{u}_j)$ [S1].
    -   Compute the contribution using the smoothing function $K(r_j, d_j)$ and the phase function $P(\boldsymbol{\omega}_j, \boldsymbol{\omega}'(\mathbf{u}_j))$, where $\boldsymbol{\omega}'(\mathbf{u}_j)$ is the tangent direction of the beam at $\mathbf{u}_j$ [S1].
3.  Sum the contributions to estimate the basic radiance $\tilde{L}_b(\mathbf{x}, \boldsymbol{\omega})$:
    $$ \tilde{L}_b(\mathbf{x}, \boldsymbol{\omega}) \approx \sum_{j=1}^k \tau(\mathbf{u}_j, \mathbf{x}) \frac{\sigma_t(\mathbf{u}_j)}{n(\mathbf{u}_j)^2} K(r_j, d_j) \Delta \Phi_j P(\boldsymbol{\omega}_j, \boldsymbol{\omega}'(\mathbf{u}_j)) $$
    [S1]

**Step 3: Convert to Final Radiance**
Transform the estimated basic radiance to final beam radiance $L_b(\mathbf{x}, \boldsymbol{\omega})$ using the local refractive index at the query point $\mathbf{x}$:
$$ L_b(\mathbf{x}, \boldsymbol{\omega}) = n^2(\mathbf{x}) \tilde{L}_b(\mathbf{x}, \boldsymbol{\omega}) $$
[S1]

**Pitfalls:**
-   The term $n^2(\mathbf{x})$ in the final conversion (Eq. 44) does **not** cancel out with the $1/n^2(\mathbf{u}_j)$ term in the integral (Eq. 43) because they depend on different positions along the ray ($\mathbf{x}$ vs $\mathbf{u}_j$) [S1].

**Pseudocode:**
```python
def compute_beam_trajectory(start_point, end_point, medium, num_nodes):
    nodes = []
    current_pos = start_point
    current_transmittance = 1.0
    direction = normalize(end_point - start_point)
    step_size = distance(start_point, end_point) / num_nodes

    for i in range(num_nodes):
        nodes.append({'pos': current_pos, 'transmittance': current_transmittance})
        # Refractive ray direction update [G]
        grad_n = medium.gradient_refractive_index(current_pos)
        direction = normalize(direction + (step_size / medium.refractive_index(current_pos)) * grad_n)
        # Transmittance segment via composite Simpson's rule [S1]
        mid_pos = current_pos + direction * (step_size / 2)
        end_seg_pos = current_pos + direction * step_size
        t0 = medium.extinction_coefficient(current_pos)
        t1 = medium.extinction_coefficient(mid_pos)
        t2 = medium.extinction_coefficient(end_seg_pos)
        segment_transmittance = exp(-step_size * (t0 + 4*t1 + t2) / 6.0)
        current_transmittance *= segment_transmittance
        current_pos = end_seg_pos
    return nodes

def estimate_basic_radiance(query_point, query_direction, beam_nodes, photon_map, smoothing_kernel):
    basic_radiance = 0.0
    contributing_photons = [p for p in photon_map if distance(p.pos, query_point) <= smoothing_kernel.radius]
    for photon in contributing_photons:
        u_j, distance_to_beam = project_photon_to_beam(photon.pos, beam_nodes)
        if distance_to_beam > smoothing_kernel.radius:
            continue
        tau_u_j_x = interpolate_transmittance(u_j, query_point, beam_nodes)
        sigma_t_u_j = medium.extinction_coefficient(u_j)
        n_u_j = medium.refractive_index(u_j)
        beam_tangent_u_j = get_beam_tangent(u_j, beam_nodes)
        phase = medium.phase_function(photon.direction, beam_tangent_u_j)
        k_value = smoothing_kernel.evaluate(photon.radius, distance_to_beam)
        contribution = (tau_u_j_x * (sigma_t_u_j / (n_u_j ** 2)) * k_value * photon.flux * phase)
        basic_radiance += contribution
    return basic_radiance

def convert_to_final_radiance(basic_radiance, query_point, medium):
    n_x = medium.refractive_index(query_point)
    return (n_x ** 2) * basic_radiance

def project_photon_to_beam(photon_pos, beam_nodes):
    min_dist = float('inf')
    u_j = beam_nodes[0]['pos']
    for i in range(len(beam_nodes) - 1):
        p1 = beam_nodes[i]['pos']
        p2 = beam_nodes[i+1]['pos']
        seg_vec = p2 - p1
        t = dot(photon_pos - p1, seg_vec) / dot(seg_vec, seg_vec)
        t = max(0.0, min(1.0, t))
        closest = p1 + seg_vec * t
        d = distance(photon_pos, closest)
        if d < min_dist:
            min_dist = d
            u_j = closest
    return u_j, min_dist

def interpolate_transmittance(u_j, query_point, beam_nodes):
    for i in range(len(beam_nodes) - 1):
        p1 = beam_nodes[i]['pos']
        p2 = beam_nodes[i+1]['pos']
        if distance(u_j, p1) < distance(u_j, p2):
            total_len = distance(p1, p2)
            if total_len == 0: return beam_nodes[i]['transmittance']
            frac = distance(u_j, p1) / total_len
            return beam_nodes[i]['transmittance'] * (1 - frac) + beam_nodes[i+1]['transmittance'] * frac
    return beam_nodes[-1]['transmittance']

def get_beam_tangent(u_j, beam_nodes):
    for i in range(len(beam_nodes) - 1):
        p1 = beam_nodes[i]['pos']
        p2 = beam_nodes[i+1]['pos']
        if distance(u_j, p1) < distance(u_j, p2):
            return normalize(p2 - p1)
    return normalize(beam_nodes[-1]['pos'] - beam_nodes[-2]['pos'])
```

## Background
The method extends the beam radiance estimation technique by Jarosz et al. [2008] to include basic radiance and curved beams in heterogeneous media [S1]. It addresses the need to integrate the spatially varying nonlinear term $n(\mathbf{u})^{-2}$ along the curved beam, which is not present in standard radiance computation [S1]. The approach builds on the relationship between scattered flux and radiance established by Jensen and Christensen [1998] [S1].
