# Multiple Scattering Approximations

Also called: Multi-bounce scattering, Diffusion approximation (in specific contexts)

## Overview
Multiple scattering approximations address the computational intractability of full volumetric path tracing by estimating the contribution of light undergoing two or more scattering events within participating media. While [Single and multiple scattering](35-single-and-multiple-scattering.md) defines the physical interactions, this family focuses on efficient estimation strategies. Unlike [Single Scattering Approximations](5340-single-scattering-approximations.md), which ignore higher-order bounces, these methods approximate the global illumination component, trading physical rigor for performance or artistic control. They differ from [Radiative Transfer and Integral Equation Solvers](3853-radiative-transfer-and-integral-equation-solvers.md) by often employing stochastic or semi-analytic shortcuts rather than solving the full integro-differential equation deterministically.

## Shared principles
All methods in this family operate on the principle that the total radiance $L$ is the sum of single-scattering ($L_1$) and multiple-scattering ($L_{\ge 2}$) contributions. The core challenge is evaluating the in-scattering integral for higher-order bounces without infinite recursion. Common mechanisms include:
1.  **Isotropic Assumption:** Many methods assume isotropic scattering to simplify the phase function convolution, allowing the source term to depend primarily on position rather than direction [S1, unofficial].
2.  **Source Term Decoupling:** The multiple scattering source is often treated as a diffuse or constant term within local volumes, decoupling it from the view-dependent ray casting [S1, unofficial].
3.  **Variance Reduction:** Analytic methods construct joint PDFs to cancel geometric singularities inherent in multi-segment paths [S1, unofficial].
4.  **Artistic Control:** Some approaches decouple physical diffusion from visual contrast, allowing biased rendering that converges visually without strict physical accuracy [S1, unofficial].

## Subtopics

### [Zonal Method](1891-zonal-method.md)
A deterministic technique for computing multiple scattering in participating media by assuming isotropic scattering, where the source term depends only on position. It extends the diffuse radiosity method for interreflecting surfaces to volumes, solving for the isotropic scattering source term by setting up and solving a system of simultaneous linear equations. Unlike stochastic methods such as [Delta tracking](985-delta-tracking.md) or [Volumetric Radiance Estimators](818-volumetric-radiance-estimators.md), it provides a global solution for multiple bounces but is restricted to isotropic phase functions and suffers from high computational complexity for dense volumes.

### [Unidirectional Importance Sampling for Double-Scattering](2151-unidirectional-importance-sampling-for-double-scattering.md)
A fully analytic method to importance sample the geometry terms along 3-segment paths (double-scattering) in isotropic participating media. It constructs a joint probability density function (PDF) for the intermediate scattering vertices that cancels out the singularities inherent in the path contribution function, thereby reducing variance compared to standard uniform or single-scattering sampling strategies.

### [Art-Directable Multiple Volumetric Scattering](7442-art-directable-multiple-volumetric-scattering.md)
Art-Directable Multiple Volumetric Scattering is a path tracing method that computes efficient, physically accurate multi-bounce diffusion in participating media while allowing independent artistic control over image contrast. It distinguishes itself from standard volumetric path tracers by decoupling the physical diffusion (scale) from the visual contrast, enabling biased but convergent rendering of high-order scattering without pre-computation or caching.

### Multi-Scattering for Ray-Traced Volumes
*   **Definition:** A technique that simulates multiple light interactions within a medium via optimized ray entry/exit searches and phase function evaluations to yield more physically accurate renders of translucent materials [S1, unofficial].
*   **Step:** Perform optimized ray entry/exit searches and evaluate phase functions to simulate multiple light interactions [S1, unofficial].

### Multiple scattering approximation
*   **Definition:** A crude, non-physically based term added to approximate multiple scattering effects [S2, unofficial].
*   **Formula:** The multiple scattering term is computed as:
    $$ C_{mul} = \frac{\sigma_t \left( \frac{z_{min} + z_{max}}{2} \right)}{\sigma} \times \rho R p(L, V) \times 0.001 \times m $$
    where $m$ is an intensity control parameter [S2, unofficial].
*   **Parameter:** $m \in [0, 1]$ controls the intensity of the multiple scattering term, mapped to a 'Multi-Scattering Factor' UI control [S2, unofficial].

## Background
The Zonal Method was introduced by Rushmeier in the early 1990s, extending radiosity to volumes [S1, unofficial]. Unidirectional importance sampling for double-scattering was developed to address variance issues in path tracing for participating media [S1, unofficial]. Art-directable methods emerged more recently to balance physical accuracy with artistic workflow needs [S1, unofficial]. The crude approximation term $C_{mul}$ is often found in real-time rendering contexts or simplified shaders where full path tracing is prohibitive [S2, unofficial].
