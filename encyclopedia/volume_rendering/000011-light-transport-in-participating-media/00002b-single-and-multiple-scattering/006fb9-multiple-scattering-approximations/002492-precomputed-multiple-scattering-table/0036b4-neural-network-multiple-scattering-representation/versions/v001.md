# Neural Network Multiple Scattering Representation

Also called: Compact Representation for Multiple Scattering using Neural Networks, Neural Network Representation of Multiple Scattering

## Overview
This method encodes multiple scattering effects in participating media using a trained neural network, replacing large precomputed lookup tables with a compact model to reduce memory usage from tens of megabytes (or gigabytes for extended parameter spaces) to kilobytes [S1, S2]. It solves the storage bottleneck of precomputed multiple scattering by approximating the complex mapping from spatial/directional coordinates to radiance [S1]. Unlike [Precomputed Multiple Scattering Table](3324-precomputed-multiple-scattering-table.md), which stores discrete samples, this method generalizes the function via regression, allowing for similar visual quality with a fraction of the memory cost [S1].

## How it works
The method consists of two phases: precomputation of reference data and training of the neural network to approximate the multiple scattering function. During rendering, the network is queried to generate the multiple scattering contribution.

### Inputs and Outputs
*   **Precomputation Input:** An infinite participating medium with a Dirac delta light source in position and direction [S1].
*   **Precomputation Output:** Multiple scattering radiance values stored in a table [S1].
*   **Network Input:** Spatial and directional coordinates. In the primary implementation, these are cylindrical coordinates for position $(\rho, z)$ and spherical coordinates for direction $(\theta, \phi)$ [S1]. In extended implementations, the input also includes material properties: anisotropy $g$ and scattering albedo $\alpha$ [S2].
*   **Network Output:** Radiance values in RGB channels [S1, S2].

### Data Structures
**Neural Network Structure (Primary Implementation):**
*   **Type:** Feed-forward fully connected neural network [S1].
*   **Layers:**
    *   Input Layer: 4 dimensions $(\rho, z, \theta, \phi)$ [S1].
    *   Hidden Layer 1: 20 nodes [S1].
    *   Hidden Layer 2: 20 nodes [S1].
    *   Output Layer: 3 dimensions (RGB) [S1].
*   **Activation Function:** Hyperbolic tangent ($\tanh$) for hidden layers [S1].
*   **Parameters:** Weights and biases $w$. Total size: 6490 bytes (1623 floats) [S1].

**Neural Network Structure (Extended Implementation):**
*   **Input:** 7 dimensions: anisotropy $g$, scattering albedo $\alpha$, location $r(\rho, z)$, and direction $(\theta, \phi)$ [S2].
*   **Structure:** Four-layer neural network [S2].
*   **Output:** Radiance [S2].
*   **Storage:** 23.6 kB for double and multiple scattering combined [S2].

### Steps
1.  **Precompute Reference Data:**
    *   Compute multiple scattering effects assuming an infinite participating medium with a Dirac delta light source in position and direction [S1].
    *   Store results using cylindrical coordinates for position $r$ $(\rho, z)$ and spherical coordinates for direction $(\theta, \phi)$ [S1].
    *   This step takes approximately 8 minutes for a given material [S1].

2.  **Normalize Inputs:**
    *   Normalize input parameters $(\rho, z, \theta, \phi)$ to the range $[-1.0, 1.0]^4$ [S1].
    *   Shuffle the data [S1].

3.  **Transform Outputs:**
    *   Switch output parameters (radiance) to the log domain to ensure well-distributed values [S1].

4.  **Split Data:**
    *   Split the precomputed table data into 70% for training and 30% for validation [S1].

5.  **Train Network:**
    *   Define the neural network $\Phi_N$ with weights and biases $w$ [S1].
    *   Minimize the L2 error loss function:
        $$ E = \sum_i \| r_i - \Phi_N(\rho, z, \theta, \phi, w) \|^2 $$
        where $r_i$ is the target radiance and $\Phi_N$ is the predicted radiance [S1].
    *   Use the ADAM optimizer with a learning rate of 0.01 [S1].
    *   Train for 10,000 iterations [S1].
    *   Training time is approximately 25 minutes per material [S1].

6.  **Render:**
    *   During rendering, use the trained neural network to generate multiple scattering radiance [S1].
    *   Alternatively, reproduce the precomputed table for a specific medium from the neural network and use the table for computation [S2].
    *   Integrate with low-order scattering methods (e.g., Virtual Ray Lights) [S1, S2].

*   **Network Size:** 2 hidden layers, 20 nodes each [S1].
*   **Optimizer:** ADAM [S1].
*   **Learning Rate:** 0.01 [S1].
*   **Iterations:** 10,000 [S1].

*   **Output Transformation:** Log domain [S1].

### Edge Cases and Pitfalls
*   **Precision:** The log domain transformation is critical for well-distributed values due to the exponential falloff of radiance [S1].
*   **Boundaries:** The method assumes an infinite medium for precomputation [S1]. Boundary effects in finite media must be handled by the integration with other algorithms (e.g., VRL) [S1].
*   **Material Dependence:** The primary implementation is material-specific (trained per material) [S1]. Extended versions attempt to generalize over albedo and anisotropy [S2].

## Operating characteristics
*   **Memory Usage:** Reduces storage from 40 MB (precomputed table) to 6490 bytes (1623 floats) for a single material [S1]. Extended versions reduce storage from 50 GB to 23.6 kB for double and multiple scattering combined [S2].
*   **Training Time:** Approximately 25 minutes per material on a standard CPU [S1].
*   **Precomputation Time:** Approximately 8 minutes per material to generate the reference data [S1].
*   **Rendering Performance:** Provides similar results to precomputed tables with significantly lower memory footprint, enabling integration with real-time or interactive rendering pipelines (e.g., VRL with GPU implementation) [S1, S2].
*   **Strengths:** Compact representation, fast runtime evaluation (neural network forward pass), compatibility with existing rendering algorithms [S1].
*   **Limitations:** Requires precomputation and training step; bias introduced by the neural network approximation [S2]; primary implementation is material-specific [S1].

## Background
The method was proposed by Ge et al. in 2018 [S1]. It addresses the storage inefficiency of precomputed multiple scattering tables, which were previously used in conjunction with algorithms like Virtual Ray Lights (VRL) [S1]. The approach builds on the symmetry of revolution in infinite media to reduce the dimensionality of the problem [S1]. It is integrated with the Mitsuba Renderer [S1].
