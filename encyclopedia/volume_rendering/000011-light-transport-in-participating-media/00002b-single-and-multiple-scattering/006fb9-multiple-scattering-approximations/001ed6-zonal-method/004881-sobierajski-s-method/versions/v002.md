# Sobierajski’s method

Also called: Hierarchical Zonal Method, Sobierajski's Hierarchical Zonal Method

## Overview
Sobierajski’s method is a hierarchical volumetric radiosity technique for calculating multiple scattering in participating media [S1][S2, book]. It represents volumetric data as voxels modeling Lambertian surfaces, isotropic media, or a combination thereof, extending diffuse radiosity principles to volumetric elements [S1][S2, book]. Unlike classical hierarchical radiosity that relies on pre-computed explicit links between elements, it finds the best highest possible levels of interaction on-the-fly during each shooting iteration, avoiding the quadratic cost of the initial link phase [S1][S2, book].

## How it works
**Inputs:** A scene of participating media represented as a set of global volumes discretized into a 3D grid of voxels [S2, book].
**Outputs:** The diffuse and isotropic radiosity values for all voxels in the hierarchy [S1][S2, book].

**Data Structures:**
*   **Voxel:** Base unit of the hierarchy. Fields: `albedo_diffuse` (ideal diffuse reflection coefficient), `albedo_isotropic` (isotropic scattering coefficient), `radiosity_diffuse`, `radiosity_isotropic`, `children` (array of 8 child voxels), `parent` (pointer to parent voxel) [S1][S2, book].
*   **Hierarchy:** 3D octree structure. Level 0 contains individual voxels. Level $k$ is formed by combining 8 neighboring voxels from level $k-1$ [S1][S2, book]. Built in a preprocessing step [S1][S2, book].

**Formulas:**
*   **Voxel BRDF:** $f_r = f_{\text{diffuse}} + f_{\text{isotropic}}$, where $f_{\text{diffuse}}$ models Lambertian reflection and $f_{\text{isotropic}}$ models uniform scattering in all directions [S1][S2, book].
*   **Radiosity Decomposition:** $B_{\text{voxel}} = B_{\text{diffuse}} + B_{\text{isotropic}}$ [S1][S2, book].
*   **Interaction Criterion:** A test checks if the amount of radiosity shot from an element to another is below a given threshold $\epsilon$; interactions below this threshold are skipped [S2, book].

**Algorithm Steps:**
1.  **Preprocessing:** Discretize media into Level 0 voxels. Recursively combine 8 neighboring voxels to form parent voxels at higher levels. Define a criterion to decide if a parent voxel is a good approximation of its descendents [S1][S2, book].
2.  **Iterative Shooting:**
    a.  Initialize radiosity values based on light sources [S1][S2, book].
    b.  Repeat until convergence or maximum iterations:
        i.  Select a source node with unshot radiosity [S1][S2, book].
        ii. Find interaction levels: Determine the highest hierarchy level where the source and target can interact on-the-fly, without explicit links [S1][S2, book].
        iii. Evaluate interaction: Check if the radiosity shot between nodes is below the threshold $\epsilon$; skip if so [S2, book].
        iv. Shoot energy: Transfer energy based on form factors between diffuse and isotropic components, updating target radiosity [S1][S2, book].
        v.  Push-Pull: After each shooting iteration, perform a Push-Pull procedure to assure the correct representation of energies at all hierarchy levels [S1][S2, book].

**Pitfalls and Edge Cases:**
*   **Self-Refinement:** Participating media are modeled as global volumes. Each global volume is refined against other volumes but not against itself, requiring explicit links between each pair of the smallest volume elements within a given global volume to correctly compute self-illumination [S2, book].
*   **Push-Pull Limitation:** The presented Push-Pull procedure limits the method to media with constant albedo; pushing irradiance instead of radiosity would resolve this drawback [S2, book].
*   **Optically Thick Media:** The standard criterion may cause excessive interactions; using an estimated form factor to check arriving energy against a threshold can dramatically decrease interactions [S2, book].
*   **Non-Convex Objects:** Self-lighting in non-convex solid objects may be missed if self-interaction is not properly handled [S2, book].

## Operating characteristics
*   **Time Complexity:** Avoids the quadratic cost of the initial link phase of classical hierarchical methods by finding interactions on-the-fly [S1][S2, book]. However, performing the Push-Pull procedure after each shooting iteration may imply a high computational cost [S2, book].
*   **Memory Complexity:** Requires storing radiosity values for all nodes at all levels of the hierarchy [S1][S2, book].
*   **Strengths:** Efficiently handles multiple scattering in participating media [S1][S2, book]. Models both Lambertian surfaces and isotropic media within a unified framework [S1][S2, book].
*   **Limitations:** Restricted to constant albedo media due to the Push-Pull procedure [S2, book]. Self-illumination in non-convex volumes requires costly explicit links between smallest elements [S2, book].
*   **When to use:** Scenes with participating media where multiple scattering is significant and media can be approximated as isotropic [S1][S2, book].
*   **When not to use:** Media with highly anisotropic scattering or varying albedo where the Push-Pull limitation applies [S2, book].

## Background
Introduced by Sobierajski [S1][S2, book]. It adapts hierarchical radiosity techniques, such as those by Sillion, to include isotropic volumes [S1]. The technique extends diffuse radiosity principles to volumetric elements represented by voxels [S1][S2, book].
