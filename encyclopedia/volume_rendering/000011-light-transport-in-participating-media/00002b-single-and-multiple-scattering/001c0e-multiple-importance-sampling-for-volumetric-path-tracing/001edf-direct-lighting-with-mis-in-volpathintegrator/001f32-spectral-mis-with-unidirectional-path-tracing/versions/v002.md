# Spectral MIS with Unidirectional Path Tracing

Also called: Spectral MIS

## Overview
Spectral MIS with Unidirectional Path Tracing estimates direct illumination in spectrally varying participating media by combining per-channel sampling techniques via Multiple Importance Sampling (MIS) [S1, unofficial]. It reduces the color noise of independent tracking and the computational cost of spectral tracking, which relies on a conservative majorant for all color components [S1, unofficial]. Unlike [Spectral+NEE MIS (Shadow Connection Routine)](1907-spectral-nee-mis-shadow-connection-routine.md), it omits the shadow connection routine for next-event estimation [S1, unofficial].

## How it works
The method estimates the spectral radiance by computing separate path contributions for each color component $c \in \{c_1, \dots, c_N\}$, but combines them using a balance heuristic to reduce color noise [S1, unofficial].

**Inputs:**
- Current position $x$ and incoming direction $\omega$ [S1, unofficial].
- Spectral extinction $\mu_t^c(x)$, scattering $\mu_s^c(x)$, absorption $\mu_a^c(x)$, and null $\mu_n^c(x)$ coefficients for each component $c$ [S1, unofficial].
- Phase function $\rho_m(\omega)$ and light source radiance $L_e(x, -\omega)$ [S1, unofficial].
- Number of color components $N$ [S1, unofficial].

**Outputs:**
- Estimated spectral radiance contribution [S1, unofficial].

**Data Structures:**
- Vectors $f$ and $p$ of size $N$, initialized to ones, storing per-component path contributions and path PDFs respectively [S1, unofficial].

**Steps:**
1. Initialize $f \leftarrow \langle 1, \dots, 1 \rangle_N$ and $p \leftarrow \langle 1, \dots, 1 \rangle_N$ [S1, unofficial].
2. Select a color component $\tilde{c} \in \{c_1, \dots, c_N\}$ uniformly at random [S1, unofficial].
3. Sample interaction distance $t = -\ln(1-\xi)/\mu_t^{\tilde{c}}(x)$ using a uniform random number $\xi \in [0, 1)$ [S1, unofficial].
4. Update position $x \leftarrow x + t\omega$ [S1, unofficial].
5. Sample event type $e \in \{a, s, n\}$ with probabilities $\mu_e^{\tilde{c}}(x)/\mu_t^{\tilde{c}}(x)$ [S1, unofficial].
6. Update contributions $f \leftarrow f \circ \langle T(t)\mu_e^{c_1}(x), \dots, T(t)\mu_e^{c_N}(x) \rangle$ [S1, unofficial].
7. Update PDFs $p \leftarrow p \circ \langle \mu_t^{c_1}(x)/\mu_t^{\tilde{c}}(x), \dots, \mu_t^{c_N}(x)/\mu_t^{\tilde{c}}(x) \rangle$ [S1, unofficial].
8. If $e=a$, return $\frac{1}{N}\sum_{i=1}^N f_i/p_i$ [S1, unofficial].
9. If $e=s$, sample $\omega \propto \rho_m(\omega)$ and continue the loop [S1, unofficial].
10. If $e=n$, continue the loop [S1, unofficial].

**Pseudocode:**
```python
import math
import random

def spectral_mis_unidirectional(x, omega, mu_t, mu_s, mu_a, mu_n, rho_m, L_e, N, mu_hat):
    f = [1.0] * N
    p = [1.0] * N
    c_tilde = random.randint(0, N - 1)
    while True:
        xi = random.uniform(0, 1)
        t = -math.log(1.0 - xi) / mu_t(x)[c_tilde]
        x = x + t * omega
        mu_t_all = mu_t(x)
        mu_s_all = mu_s(x)
        mu_a_all = mu_a(x)
        mu_n_all = mu_n(x)
        r = random.uniform(0, 1)
        p_a = mu_a_all[c_tilde] / mu_t_all[c_tilde]
        p_s = mu_s_all[c_tilde] / mu_t_all[c_tilde]
        if r < p_a:
            event = 'a'
        elif r < p_a + p_s:
            event = 's'
        else:
            event = 'n'
        T_t = math.exp(-mu_hat * t)
        for i in range(N):
            coeff = mu_a_all[i] if event == 'a' else (mu_s_all[i] if event == 's' else mu_n_all[i])
            f[i] = f[i] * T_t * coeff
        for i in range(N):
            p[i] = p[i] * (mu_t_all[i] / mu_t_all[c_tilde])
        if event == 'a':
            return sum(f[i] / p[i] for i in range(N)) / N
        elif event == 's':
            omega = sample_phase_function(rho_m)
        # event == 'n' continues loop

def sample_phase_function(rho_m):
    # [G] Standard phase function sampling routine (e.g., rejection sampling or analytical inverse)
    return normalize(random_direction())
```

**Parameters:**
- $N$: Number of color components (e.g., 3 for RGB) [S1, unofficial].
- $\xi$: Uniform random number in $[0, 1)$ [S1, unofficial].

**Edge cases and pitfalls:**
- Precision issues may arise if $\mu_t^{\tilde{c}}$ is very small, leading to large $t$ [S1, unofficial].
- Boundary conditions for the medium must be handled when $x$ exits the medium [G].
- The balance heuristic requires that all techniques have non-zero probability of being selected [G].

## Operating characteristics
- **Time Complexity**: $O(N \cdot r)$, where $N$ is the number of color components and $r$ is the path length [S1, unofficial]. Each step involves $N$ operations for updating $f$ and $p$ [S1, unofficial].
- **Memory Complexity**: $O(N)$ for storing $f$ and $p$ vectors [S1, unofficial].
- **Measured Performance**: In a 1D medium experiment, Spectral MIS achieved a reduction of color noise comparable to spectral tracking but at a lower cost (fewer medium lookups) [S1, unofficial]. In the left plume of Fig. 9 (high density, low albedo green channel), Spectral MIS achieved RMSE: 0.047 and LTUV: 4.12M lookups, outperforming Spectral tracking (RMSE: 0.055, LTUV: 5.82M) and Independent tracking (RMSE: 0.077, LTUV: 11.5M) [S1, unofficial]. In the right plume of Fig. 9 (similar spectral variation), Spectral MIS achieved RMSE: 0.029 and LTUV: 1.09M lookups, outperforming Spectral tracking (RMSE: 0.035, LTUV: 1.51M) [S1, unofficial]. In the malachite material (Fig. 10), Spectral MIS achieved RMSE: 0.032 and LTUV: 0.56M lookups, outperforming Spectral tracking (RMSE: 0.042, LTUV: 2.85M) [S1, unofficial].
- **Strengths**: Reduces color noise compared to independent tracking and lowers computational cost compared to spectral tracking by avoiding a common conservative majorant for all color components [S1, unofficial].
- **Limitations**: Still requires sampling per component and may not handle complex light source geometries as effectively as NEE methods [S1, unofficial].
- **When to use**: When simulating spectrally varying media and color noise is a concern, but computational resources are limited compared to full spectral tracking [S1, unofficial].
- **When not to use**: When light sources are inside the medium and next-event estimation is critical; consider [Spectral+NEE MIS (Shadow Connection Routine)](1907-spectral-nee-mis-shadow-connection-routine.md) instead [S1, unofficial].

## Background
The method was introduced by [S1, unofficial] as part of a null-scattering path integral formulation of light transport [S1, unofficial]. It extends the work of Wilkie et al. and Fajardo [2012] by combining per-channel sampling techniques via MIS to reduce color noise while maintaining computational efficiency [S1, unofficial]. The method is used in volumetric path tracing for rendering participating media with spectrally varying properties [S1, unofficial].
