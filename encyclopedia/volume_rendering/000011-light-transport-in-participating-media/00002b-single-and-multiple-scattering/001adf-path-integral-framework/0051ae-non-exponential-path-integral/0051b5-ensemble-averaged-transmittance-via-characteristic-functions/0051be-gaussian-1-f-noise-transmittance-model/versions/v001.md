# Gaussian 1/f^β noise transmittance model

Also called: Normal distribution transmittance

## Overview
The Gaussian 1/f^β noise transmittance model is a closed-form method for computing the ensemble-averaged transmittance in participating media where the line-averaged extinction coefficient follows a Gaussian distribution derived from 1/f^β fractal noise [S1]. It differs from the [Gamma-distributed 1/f^β noise transmittance model](14552-gamma-distributed-1-f-noise-transmittance-model.md) by assuming a symmetric normal distribution for the density fluctuations, which allows for a simpler analytic solution but introduces the physical inconsistency of allowing negative extinction values [S1].

## How it works
**Inputs:**
*   $t$: The distance along the ray (scalar, $t \ge 0$).
*   $\mu_\sigma$: The mean extinction coefficient of the medium (scalar, $\mu_\sigma > 0$).
*   $C$: The noise amplitude parameter (scalar, $C > 0$).
*   $\beta$: The spectral exponent of the fractal noise (scalar, typically $-1 \le \beta \le 3$ for the resulting fBm properties [S1]).

**Outputs:**
*   $\mathbf{f}_{\mathcal{N}}(t \mid \boldsymbol{\psi})$: The ensemble-averaged transmittance (scalar, $0 \le \mathbf{f}_{\mathcal{N}} \le 1$).

**Data Structures:**
No complex data structures are required. The model relies on scalar parameters $\boldsymbol{\psi} = \{\mu_\sigma, C, \beta\}$.

**Mathematical Formulation:**
The model assumes the line-averaged extinction coefficient $\overline{\sigma}_\mu$ is a random variable following a Gaussian distribution $\mathcal{N}(\mu_\sigma, \nu)$, where the variance $\nu$ depends on the distance $t$ [S1].

The probability density function (PDF) is defined as:
$$ \text{pdf}(\overline{\sigma}_\mu \mid t, \boldsymbol{\psi}) = \frac{1}{\sqrt{2\pi \nu(t)}} \exp\left( -\frac{(\overline{\sigma}_\mu - \mu_\sigma)^2}{2\nu(t)} \right) $$

The variance $\nu(t)$ is determined by the parameter $\overline{\sigma}_{\mu}(t)$ defined in Equation 34 of [S1]. While the source notation $\overline{\sigma}_{\mu}(t)$ is ambiguous regarding whether it represents standard deviation or variance, the derivation of the final transmittance formula (Equation 35) implies that the variance term in the characteristic function exponent is $\nu(t) = (C\mu_\sigma)^{\beta+1}t^{\beta+1}$ [S1]. Specifically, the term $(C\mu_\sigma t)^{\beta+1}/2$ in the exponent of the transmittance corresponds to $r^2\nu/2$ with $r=ti$, implying $\nu(t) = (C\mu_\sigma)^{\beta+1}t^{\beta+1}$ [S1].

The ensemble-averaged transmittance is computed using the characteristic function (CF) of the normal distribution. For a normal distribution $\mathcal{N}(\mu, \nu)$, the CF is $\varphi(r) = e^{ir\mu - r^2\nu/2}$ [S1]. Substituting $r = ti$ (where $i$ is the imaginary unit) into the CF yields the transmittance:

$$ \mathbf{f}_{\mathcal{N}}(t \mid \boldsymbol{\psi}) = \varphi(ti) = e^{i(ti)\mu_\sigma - (ti)^2\nu(t)/2} $$
$$ \mathbf{f}_{\mathcal{N}}(t \mid \boldsymbol{\psi}) = e^{-\mu_\sigma t + t^2\nu(t)/2} $$

Substituting $\nu(t) = (C\mu_\sigma)^{\beta+1}t^{\beta+1}$:

$$ \mathbf{f}_{\mathcal{N}}(t \mid \boldsymbol{\psi}) = e^{-\mu_\sigma t + \frac{1}{2}(C\mu_\sigma)^{\beta+1}t^{\beta+2}} $$

Note: The source Equation 35 is written as $e^{-\mu_{\sigma} t + (C\mu_{\sigma} t)^{\beta+1}/2}$. Expanding $(C\mu_{\sigma} t)^{\beta+1}$ gives $(C\mu_\sigma)^{\beta+1}t^{\beta+1}$. This differs from the derived $t^{\beta+2}$ term above. Re-evaluating the source text: "with $\overline{\sigma}_{\mu}(t) = (C\mu_\sigma)^{\beta+1}t^{\beta+1}$" and the transmittance exponent is $(C\mu_\sigma t)^{\beta+1}/2$. The source explicitly states the final formula is $e^{-\mu_{\sigma} t + (C\mu_{\sigma} t)^{\beta+1}/2}$ [S1]. We must adhere to the explicit final formula provided in the source [S1].

**Algorithm:**

1.  Compute the mean attenuation term: $A = \mu_\sigma \cdot t$.
2.  Compute the noise variance term base: $B = C \cdot \mu_\sigma \cdot t$.
3.  Compute the exponent correction: $E = \frac{1}{2} \cdot B^{\beta+1}$.
4.  Compute the total exponent: $X = -A + E$.
5.  Return $\exp(X)$.

**Pseudocode:**

```python
def gaussian_1f_beta_transmittance(t, mu_sigma, C, beta):
    """
    Computes the ensemble-averaged transmittance using the Gaussian 1/f^beta model.
    
    Args:
        t (float): Distance along the ray.
        mu_sigma (float): Mean extinction coefficient.
        C (float): Noise amplitude parameter.
        beta (float): Spectral exponent.
        
    Returns:
        float: Transmittance value.
    """
    # Step 1: Mean attenuation term
    mean_atten = mu_sigma * t
    
    # Step 2: Noise variance term base (C * mu_sigma * t)
    noise_base = C * mu_sigma * t
    
    # Step 3: Exponent correction term: (C * mu_sigma * t)^(beta + 1) / 2
    # Note: If noise_base is 0 and beta+1 < 0, this may result in inf. 
    # Guard against negative base with non-integer exponent if necessary, 
    # though physical parameters C, mu_sigma, t are positive.
    exponent_correction = 0.5 * (noise_base ** (beta + 1))
    
    # Step 4: Total exponent
    total_exponent = -mean_atten + exponent_correction
    
    # Step 5: Transmittance
    return math.exp(total_exponent)
```

**Parameters and Typical Values:**
*   $\mu_\sigma$: Must be sufficiently high to ensure the probability of negative extinction is negligible [S1].
*   $C$: Controls the magnitude of density fluctuations.
*   $\beta$: The spectral exponent. The model is derived from 1/f^β noise which produces fractional Brownian motion (fBm) with $\beta + 2$ [S1].

**Edge Cases and Pitfalls:**
*   **Negative Extinction:** The Gaussian distribution is supported on the entire real line, meaning it assigns non-zero probability to negative extinction coefficients ($\sigma_\mu < 0$), which are nonphysical [S1]. The model is only reasonable when $\mu_\sigma$ is set sufficiently high and the variance (controlled by $C$ and $\beta$) is sufficiently low such that negative values are statistically unlikely [S1].
*   **Precision:** For large $t$, the term $(C\mu_\sigma t)^{\beta+1}$ may grow rapidly, potentially causing overflow in the exponent if $\beta+1 > 0$. Conversely, if $\beta+1 < 0$ and $t$ is small, precision issues may arise.

## Operating characteristics
*   **Time Complexity:** $O(1)$. The model involves a constant number of arithmetic operations and a single exponential evaluation.
*   **Memory Complexity:** $O(1)$. No storage is required beyond the input parameters.
*   **Strengths:** Provides a closed-form analytic solution, avoiding numerical integration or sampling. It is computationally very efficient.
*   **Limitations:** The assumption of a Gaussian distribution allows for negative extinction values, which is physically invalid. This limits the model's applicability to scenarios where the mean extinction is high relative to the variance [S1]. It is an approximation of the true transmittance for 1/f^β noise media.
*   **When to use:** Use when computational efficiency is critical and the medium parameters allow for the Gaussian approximation (high mean, low variance relative to mean).
*   **When not to use:** Use the [Gamma-distributed 1/f^β noise transmittance model](14552-gamma-distributed-1-f-noise-transmittance-model.md) when the mean extinction is low or the variance is high, making the Gaussian approximation inaccurate due to the significant probability of negative extinction.

## Background
The model is based on the work of Davis and Mineev-Weinstein [2011], who formally derived the dependence of the Gaussian distribution of line-averaged density on distance and medium parameters [S1]. The approach is part of a broader framework for non-exponential path integrals in volume rendering, specifically addressing media modeled as fractal noise [S1]. The Gaussian 1/f^β noise is related to fractional Brownian motion (fBm) [Mandelbrot and Ness 1968] [S1].
