# Null-Scattering Transmittance Sampling

Also called: Majorant Sampling, Majorant Transmittance Sampling, MajorantTransmittanceSampler, Null-Event Method

## Overview
Null-Scattering Transmittance Sampling is a technique for unbiased volumetric path tracing that handles participating media with arbitrary density distributions, including empty space, by using a constant majorant extinction coefficient $\sigma_{maj}$ [S1, unofficial]. It solves the problem of efficiently sampling interaction points in sparse or heterogeneous media by converting the physical transmittance integral into a modified integral over a homogeneous medium, where null events account for the difference between the majorant and the actual density [S1, unofficial]. It differs from standard delta tracking by explicitly maintaining a majorant transmittance factor $T_{maj}$ and applying Russian Roulette based on the ratio of null density to the majorant, ensuring unbiased estimates even when the majorant significantly overestimates the physical extinction [S1, unofficial].

## How it works

### Inputs and Outputs
**Inputs:**
*   A ray segment defined by origin, direction, and interval $[t_0, t_1]$ [S1, unofficial].
*   A density grid (e.g., NanoVDB) providing access to physical density $\rho(\mathbf{x})$ and a precomputed majorant density $d_{maj}$ per tile or leaf [S1, unofficial].
*   The base majorant extinction coefficient $\sigma_{t,base} = \sigma_a + \sigma_s$ [S1, unofficial].
*   A random number generator (RNG) [S1, unofficial].

**Outputs:**
*   A sequence of `MediumProperties` structs, each containing:
    *   `point`: World position $\mathbf{x}$ of the sampled interaction [S1, unofficial].
    *   `sigma_maj`: The majorant extinction coefficient at the current location, $\sigma_{maj} = d_{maj} \cdot \sigma_{t,base}$ [S1, unofficial].
    *   `density`: The actual physical density $\rho(\mathbf{x})$ at the point [S1, unofficial].
*   The loop terminates when the ray exits the medium or transmittance drops to zero [S1, unofficial].

### Algorithm Steps

1.  **Initialization**:
    *   Initialize `m_T_maj = 1.0f` [S1, unofficial].
    *   Initialize `m_sigma_t` with the provided base majorant extinction coefficient $\sigma_{t,base}$ [S1, unofficial].
    *   Initialize the `m_iterator` with the ray and density grid [S1, unofficial].
    *   Get the first segment from `m_iterator.next()` [S1, unofficial].

2.  **Segment Loop**:
    *   While `m_segment` is valid:
        *   If the segment's majorant density $d_{maj} \le 0$, skip the segment (empty space) and fetch the next segment [S1, unofficial].
        *   Compute the local majorant extinction: $\sigma_{maj} = d_{maj} \cdot m\_sigma\_t$ [S1, unofficial].
        *   Sample a distance $dt_{maj}$ from the exponential distribution with rate $\sigma_{maj}$ using a uniform random number $u \in [0, 1)$:
            $$ dt_{maj} = -\frac{\ln(1 - u)}{\sigma_{maj}} $$
            [G: Standard inverse CDF for exponential distribution. If $u=0$, $dt_{maj} \to \infty$, handled by segment bounds.]
        *   Convert to world space ray parameter $t$:
            $$ t = m\_segment.t_0 + \frac{dt_{maj}}{s} $$
            where $s$ is the iterator's world scale factor (`idx_to_world_scale()`) [S1, unofficial].
        *   If $t < m\_segment.t_1$:
            *   Update segment start: $m\_segment.t_0 = t$ [S1, unofficial].
            *   Update majorant transmittance: $m\_T_{maj} \leftarrow m\_T_{maj} \cdot e^{-dt_{maj} \cdot \sigma_{maj}}$ [S1, unofficial].
            *   Retrieve the physical density $\rho$ at position $\mathbf{x} = \mathbf{o} + t \cdot \mathbf{d}$ using `m_density_sampler` [S1, unofficial].
            *   If $\rho > 0$, return `MediumProperties{point: $\mathbf{x}$, sigma_maj: $\sigma_{maj}$, density: $\rho$}` [S1, unofficial].
            *   If $\rho = 0$, continue to the next iteration of the sampler loop (treat as null event) [S1, unofficial].
        *   If $t \ge m\_segment.t_1$, fetch the next segment and repeat [G: Standard segment advancement logic].

3.  **Event Sampling (within the path tracer loop)**:
    *   For each returned `MediumProperties` (with density $\rho$ and majorant $\sigma_{maj}$):
        *   Calculate absorption probability:
            $$ p_a = \frac{\sigma_a \cdot \rho}{\sigma_{maj}} $$
            [S1, unofficial]
        *   Calculate scattering probability:
            $$ p_s = \frac{\sigma_s \cdot \rho}{\sigma_{maj}} $$
            [S1, unofficial]
        *   Calculate null event probability:
            $$ p_n = \max(1.0f - p_a - p_s, 0.0f) $$
            [S1, unofficial]
        *   Sample a discrete event from $\{ \text{Null}, \text{Absorption}, \text{Scatter} \}$ using probabilities $\{ p_n, p_a, p_s \}$ and a uniform random number [S1, unofficial].
        *   If **Null**: Continue to the next iteration of the sampler loop (skip emission/scattering contribution) [S1, unofficial].
        *   If **Absorption**: Terminate the path [G: Standard null-scattering framework treats absorption as a termination event].
        *   If **Scatter**: Proceed with scattering (sample direction, emit new ray) [S1, unofficial].

4.  **Transmittance Update and Russian Roulette**:
    *   Calculate the null density component: $\sigma_n = \max(0.0f, \sigma_{maj} - \sigma_t \cdot \rho)$, where $\sigma_t = \sigma_a + \sigma_s$ [S1, unofficial].
    *   Update ray transmittance: $T_{ray} \leftarrow T_{ray} \cdot (\sigma_n / \sigma_{maj})$ [S1, unofficial].
    *   If $T_{ray} < 0.05f$, apply Russian Roulette with survival probability $q=0.75$:
        *   If $u < q$, set $T_{ray} = 0.0f$ [S1, unofficial].
        *   Else, set $T_{ray} \leftarrow T_{ray} / (1 - q)$ [S1, unofficial].
    *   If $T_{ray} \le 0.0f$, terminate the shadow ray trace and return zero radiance [S1, unofficial].

### Pseudocode

```python
from dataclasses import dataclass
import math

@dataclass
class MediumProperties:
    point: tuple  # (x, y, z)
    sigma_maj: float
    density: float

class RayMajorantIterator:
    def __init__(self, ray, density_grid):
        self.ray = ray
        self.grid = density_grid
        self.current_segment = None
        self._advance()

    def _advance(self):
        # Placeholder for grid traversal logic
        # In practice, this iterates over tiles/leaves along the ray
        self.current_segment = self.grid.get_next_segment(self.ray)

    def next(self):
        seg = self.current_segment
        self._advance()
        return seg

    def idx_to_world_scale(self):
        return self.grid.get_scale()

def null_scattering_transmittance_sampling(ray, density_grid, sigma_a, sigma_s, rng):
    sigma_t_base = sigma_a + sigma_s
    T_maj = 1.0
    iterator = RayMajorantIterator(ray, density_grid)
    segment = iterator.next()

    while segment is not None:
        if segment.d_maj <= 0.0:
            segment = iterator.next()
            continue

        sigma_maj = segment.d_maj * sigma_t_base
        u = rng.uniform()
        if u == 0.0:
            dt_maj = float('inf')
        else:
            dt_maj = -math.log(1.0 - u) / sigma_maj

        t = segment.t0 + dt_maj / iterator.idx_to_world_scale()

        if t < segment.t1:
            segment.t0 = t
            T_maj *= math.exp(-dt_maj * sigma_maj)
            point = (ray.origin[0] + t * ray.direction[0],
                     ray.origin[1] + t * ray.direction[1],
                     ray.origin[2] + t * ray.direction[2])
            density = density_grid.sample(point)

            if density > 0.0:
                yield MediumProperties(point, sigma_maj, density)
        else:
            segment = iterator.next()

def process_null_scattering_step(properties, T_ray, sigma_a, sigma_s, rng):
    sigma_maj = properties.sigma_maj
    density = properties.density
    sigma_t_base = sigma_a + sigma_s

    p_a = (sigma_a * density) / sigma_maj
    p_s = (sigma_s * density) / sigma_maj
    p_n = max(1.0 - p_a - p_s, 0.0)

    u = rng.uniform()
    if u < p_n:
        event = 'Null'
    elif u < p_n + p_a:
        event = 'Absorption'
    else:
        event = 'Scatter'

    sigma_n = max(0.0, sigma_maj - sigma_t_base * density)
    T_ray *= sigma_n / sigma_maj

    if T_ray < 0.05:
        q = 0.75
        if rng.uniform() < q:
            T_ray = 0.0
            event = 'Terminate'
        else:
            T_ray /= (1.0 - q)

    if T_ray <= 0.0:
        event = 'Terminate'

    return event, T_ray
```

### Edge Cases and Pitfalls
*   **Empty Space**: Segments with $d_{maj} \le 0$ must be skipped immediately to avoid sampling in void and ensure efficiency [S1, unofficial].
*   **Precision**: When $\sigma_{maj}$ is very large, $dt_{maj}$ can be very small, leading to precision issues in $t$ calculation; double precision for intermediate calculations is recommended [G].
*   **Russian Roulette Threshold**: The threshold $0.05$ and survival probability $0.75$ are specific to the implementation [S1, unofficial].
*   **Majorant Bound**: The majorant must be a true upper bound on the physical extinction to guarantee unbiased results [G].
