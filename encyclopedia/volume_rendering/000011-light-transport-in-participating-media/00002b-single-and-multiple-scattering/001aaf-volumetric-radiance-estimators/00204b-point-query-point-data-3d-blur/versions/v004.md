# Point Query × Point Data, 3D Blur

Also called: Conventional Radiance Estimation, Standard volumetric radiance estimate, Jensen and Christensen estimate

## Overview
This method estimates the in-scattered radiance at a specific query point $\mathbf{x}$ by searching for discrete photon points stored within the medium and averaging their energy over a three-dimensional spherical kernel of radius $r$ [S1, S2]. It differs from its sibling, the [Extended Balance Heuristic](5601-extended-balance-heuristic.md), by using a fixed-density spatial average rather than a balance heuristic that accounts for the relative probabilities of different path connections [S2]. Unlike the [Beam Query × Point Data, 3D Blur](4555-beam-query-beam-data-2d-blur.md) variant, which integrates transmittance along the camera ray to compute beam radiance directly, this method computes the local incident radiance at a point, requiring subsequent ray marching or integration to determine the final pixel color [S2].

## How it works
**Inputs and Outputs**
*   **Input:** A query point $\mathbf{x}$ in the medium, a view direction $\vec{\omega}$, a photon map containing discrete photon points, a spherical kernel radius $r$, and medium properties ($\sigma_t, \sigma_s$).
*   **Output:** The estimated in-scattered radiance $L_i(\mathbf{x} \rightarrow \vec{\omega})$ at the query point.

**Data Structures**
*   **Photon Map:** A spatial index (e.g., k-d tree) storing photon points. Each photon point $p$ contains:
    *   Position $\mathbf{x}_p$ (3D vector).
    *   Power $\Phi_p$ (scalar, radiometric flux).
    *   Direction $\vec{\omega}_p$ (unit vector, incident direction from which the photon arrived).
    *   *Note: The sources do not specify additional fields such as time or wavelength, implying a static, monochromatic, or pre-integrated representation.* [S2]

**Algorithm Steps**
1.  **Query:** Identify all photon points $p$ within the spherical query region $R$ centered at $\mathbf{x}$ with radius $r$. Let this set be $\mathcal{P}_R$.
2.  **Iterate:** For each photon $p \in \mathcal{P}_R$:
    a. Calculate the angle $\theta_p$ between the photon's incident direction $\vec{\omega}_p$ and the view direction $\vec{\omega}$ (or the direction from which radiance is being estimated). Specifically, $f(\theta_p)$ is the phase function evaluated at the scattering angle.
    b. Retrieve the photon power $\Phi_p$.
3.  **Sum:** Compute the weighted sum of photon powers multiplied by the phase function values.
4.  **Normalize:** Divide the sum by the volume measure of the query region, $\mu_R(r^3)$. For a sphere, $\mu_R(r^3) = \frac{4}{3}\pi r^3$.
5.  **Scale:** Multiply by the scattering coefficient $\sigma_s$ if the phase function $f$ is normalized to unity over the sphere, or divide by $\sigma_s$ if the standard definition of radiance density is used as per Equation 7 in [S2]. *Clarification: Equation 7 in [S2] divides by $\sigma_s \mu_R(r^3)$. However, Equation 1 in [S1] divides only by volume. The sources differ on the inclusion of $\sigma_s$ in the denominator. [S2] explicitly includes $\sigma_s$ in the denominator of the standard estimate (Eq 7), while [S1] omits it, attributing the term to the material shading function $s$. We follow [S2]'s explicit formula for the "standard" estimate.*

**Formulas**
The in-scattered radiance $L_i$ at query point $\mathbf{x}$ for direction $\vec{\omega}$ is:

$$ L_i(\mathbf{x} \rightarrow \vec{\omega}) \approx \frac{1}{\sigma_s \mu_R(r^3)} \sum_{p \in R} f(\theta_p) \Phi_p $$

Where:
*   $\sigma_s$: Scattering coefficient ($m^{-1}$).
*   $\mu_R(r^3)$: Volume measure of the query region $R$. For a sphere of radius $r$, $\mu_R(r^3) = \frac{4}{3}\pi r^3$.
*   $f(\theta_p)$: Phase function value for the scattering angle $\theta_p$ between the photon's incoming direction and the view direction.
*   $\Phi_p$: Power (flux) of photon $p$.
*   $R$: The set of photons within distance $r$ of $\mathbf{x}$.

*Alternative Formulation (from [S1]):*
$$ L_{ms}(x,\omega_0) \approx \sum_{i=1}^{n} s(x',\omega_i,\omega_0) \frac{\Delta \Phi(x',\omega_i)}{\frac{4}{3}\pi r^3} $$
Where $s$ is the material shading function (which may include $\sigma_s$ and the phase function) and $n$ is the number of closest photons. [S1]

**Parameters**
*   $r$: Kernel radius. Typical values depend on photon density; not given in sources. [S1, S2]
*   $n$: Number of closest photons. In the standard 3D blur, all photons within radius $r$ are used, so $n$ is variable. [S1]

**Pseudocode**
```python
def estimate_point_query_point_data_3d_blur(query_point, view_direction, photon_map, radius, scattering_coefficient):
    """
    Estimates in-scattered radiance at a point using 3D blur of photon points.
    
    Args:
        query_point: 3D vector, position x
        view_direction: 3D unit vector, omega
        photon_map: Object with method find_photons_in_sphere(center, radius)
        radius: float, r
        scattering_coefficient: float, sigma_s
        
    Returns:
        float, estimated radiance L_i
    """
    # 1. Query photons within spherical kernel
    photons_in_region = photon_map.find_photons_in_sphere(query_point, radius)
    
    sum_weighted_power = 0.0
    
    # 2. Iterate over photons
    for photon in photons_in_region:
        # Calculate scattering angle theta between photon incident direction and view direction
        # Note: Photon direction in map is typically the direction IT traveled.
        # Scattering angle is between incoming light (photon dir) and outgoing view.
        cos_theta = dot(photon.direction, view_direction)
        
        # Evaluate phase function f(theta)
        phase_value = evaluate_phase_function(cos_theta)
        
        # Accumulate weighted power
        sum_weighted_power += phase_value * photon.power
        
    # 3. Normalize by volume measure and scattering coefficient
    # Volume of sphere: 4/3 * pi * r^3
    volume_measure = (4.0 / 3.0) * math.pi * (radius ** 3)
    
    # According to [S2] Eq 7: divide by sigma_s * volume
    # According to [S1]: divide by volume only (shading function includes sigma_s)
    # Using [S2] standard form as primary implementation for "Standard volumetric radiance estimate"
    if scattering_coefficient > 0:
        radiance = sum_weighted_power / (scattering_coefficient * volume_measure)
    else:
        radiance = 0.0
        
    return radiance
```

**Edge Cases and Pitfalls**
*   **Empty Query Region:** If no photons are found within radius $r$, the estimate is zero. This causes dark spots in sparse regions. [S2]
*   **Heterogeneous Media:** The standard point estimate assumes a local density. In heterogeneous media, the transmittance from the photon to the query point is not explicitly handled in the basic point estimate (Eq 7), unlike the beam estimates. This can introduce bias if the medium density varies significantly over the kernel radius. [S2]
*   **Boundary Conditions:** The spherical kernel may extend outside the medium. Photons outside the medium should be excluded or handled via boundary conditions. [G]
*   **Precision:** Division by small volumes (small $r$) can lead to high variance if photon counts are low. [S2]

## Subtopics

### [Beam Query × Beam Data, 2D Blur](4555-beam-query-beam-data-2d-blur.md)
Uses continuous beam data and 2D blur to reduce bias along the beam direction. Choose when high accuracy in participating media with varying beam directions is required and computational cost allows for beam-based integration.

### [Extended Balance Heuristic](5601-extended-balance-heuristic.md)
Uses a balance heuristic to combine multiple estimators. Choose when unbiased results are critical and multiple path connections are available.

## Operating characteristics
*   **Time Complexity:** $O(N \log N)$ for building the photon map (k-d tree), and $O(\log N + k)$ for querying $k$ photons within radius $r$ per sample point. The number of photons $k$ depends on density and radius.
*   **Memory Complexity:** $O(N)$ to store $N$ photons.
*   **Performance:** Fast per-sample evaluation compared to beam methods that require integration. However, it requires a separate ray marching step to accumulate the final radiance along the eye ray, which can be expensive. [S2]
*   **Strengths:** Simple to implement; well-understood; efficient for homogeneous media where the point estimate is sufficient for local incident radiance. [S2]
*   **Limitations:** Biased estimator; requires careful tuning of kernel radius $r$; suffers from noise in sparse regions; does not directly compute beam radiance, requiring additional integration. [S2]
*   **When to use:** Real-time applications or offline rendering where photon mapping is already used for global illumination, and the medium is relatively homogeneous or the kernel radius is small enough to approximate local density. [S1, S2]
*   **When not to use:** Highly heterogeneous media where transmittance varies significantly over the kernel; when unbiased results are required. [S2]

## Background
The method was introduced by Henrik Wann Jensen and Hans H. Christensen in 1998 as the "Conventional Radiance Estimation" for volumetric photon mapping [S1, S2]. It is based on the principle of density estimation using spherical kernels. The method is a direct application of the radiance estimation framework to participating media, extending the point-to-point photon mapping used for surfaces to volumetric interactions. It is widely used in volumetric photon mapping implementations as the standard estimator for in-scattered radiance. [S1, S2]
