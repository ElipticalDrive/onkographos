# Extended Balance Heuristic

Also called: EBH

## Overview
The Extended Balance Heuristic is a variance reduction technique used to weight estimates from a mixture of sampling techniques, combining unbiased path sampling with extended space volumetric estimators [S1]. It generalizes the standard balance heuristic by incorporating kernel density estimation properties into the weighting scheme, allowing for optimal combination of disparate estimators such as photon mapping and path tracing [S1]. It sets itself apart from siblings like Point Query × Point Data by explicitly accounting for the kernel support volume in the probability density function (pdf) calculation for volumetric techniques [S1].

## How it works
The method calculates weights for a mixture of $n$ sampling techniques to estimate radiance at a query point $x$. It relies on the assumption that the underlying radiance function $f(x)$ is approximately constant across the kernel supports of the different techniques [S1].

**Inputs and Outputs**
*   **Input:** A query point $x$ in the medium.
*   **Input:** A set of $n$ sampling techniques. For each technique $i$:
    *   $n_i$: The number of samples generated by technique $i$.
    *   $p_i(x, y_i)$: The standard pdf for technique $i$, defined over the sample space $\mathcal{D}_{y_i}$ [S1].
    *   $K_i(x, y_i)$: The kernel function used by technique $i$ [S1].
    *   $y_i^*$: The specific sample realization used for the weight calculation [S1].
*   **Output:** Normalized weights $\tilde{w}_i'(x, y_i^*)$ for each technique $i$, such that $\sum_{i=1}^n \tilde{w}_i'(x, y_i^*) = 1$ [S1].

**Data Structures**
No complex data structures are required beyond storing the scalar values $n_i$, the pdf values $p_i$, and the kernel integral constants for each technique.

**Formulas**
The weight for technique $i$ is given by [S1]:

$$ \tilde{w}_i'(x, y_i^*) = \frac{n_i p_i'(x, y_i^*)}{\sum_{k=1}^n n_k p_k'(x, y_k^*)} $$

where $p_i'(x, y_i^*)$ is the **extended pdf** [S1]:

$$ p_i'(x, y_i^*) = \frac{p_i(x, y_i^*)}{\int_{\mathcal{D}_{y_i}} K_i^2(x, y_i) \, dy_i} $$

For unbiased path sampling techniques, the extended pdf simplifies to the standard pdf [S1]:

$$ p_i'(x, y_i^*) = p_i(x) $$

**Kernel Support Simplification**
If a constant kernel is used, defined as $K_i(x, y_i) = |S_i(x)|^{-1}$ where $S_i(x)$ is the support of the kernel for query point $x$, the integral term simplifies [S1]:

$$ \int_{\mathcal{D}_{\mathcal{Y}_i}} K_i^2(x, y_i) \, dy_i = |S_i(x)|^{-2} \int_{S_i(x)} dy_i = |S_i(x)|^{-1} $$

Substituting this into the extended pdf formula yields [S1]:

$$ p_i'(x, y_i^*) = p_i(x, y_i^*) |S_i(x)| $$

This formulation corresponds exactly to the vertex merging pdf used in previous work [S1].

**Algorithm Steps**
1.  **Precomputation:** For each volumetric technique $i$, precompute the constant integral $C_i = \int_{\mathcal{D}_{y_i}} K_i^2(x, y_i) \, dy_i$. For constant kernels, $C_i = |S_i(x)|^{-1}$ [S1].
2.  **Sample Selection:** For the current query point $x$, identify the specific sample realization $y_i^*$ for each technique $i$ [S1].
    *   For extended space techniques (e.g., photon mapping), $y_i^*$ is the actual realization of the photon variable (e.g., the photon location) [S1].
    *   For unbiased techniques, $y_i^*$ corresponds to the kernel center (e.g., the query point itself) [S1].
3.  **Extended PDF Calculation:** Calculate $p_i'(x, y_i^*)$ for each technique [S1]:
    *   If technique $i$ is a volumetric estimator: $p_i'(x, y_i^*) = p_i(x, y_i^*) / C_i$ [S1].
    *   If technique $i$ is an unbiased path sampler: $p_i'(x, y_i^*) = p_i(x)$ [S1].
4.  **Weight Calculation:** Compute the unnormalized weight for each technique: $w_i = n_i p_i'(x, y_i^*)$ [S1].
5.  **Normalization:** Compute the sum $W = \sum_{k=1}^n w_k$ and the final weight $\tilde{w}_i' = w_i / W$ [S1].

**Pseudocode**
```python
def extended_balance_heuristic(query_point, techniques):
    """
    Calculate weights for a mixture of volumetric and unbiased techniques.
    
    Args:
        query_point: The spatial location x where radiance is estimated.
        techniques: A list of technique objects. Each object must have:
            - n_samples: int, number of samples n_i
            - is_unbiased: bool, True if path sampling, False if volumetric
            - pdf_func: callable, returns p_i(x, y*) or p_i(x)
            - kernel_support_volume: float, |S_i(x)| for constant kernels
            - kernel_integral: float, precomputed integral of K^2 (C_i)
            - sample_realization: The specific sample y_i* used for this query
            
    Returns:
        list of floats: Normalized weights [w_1, ..., w_n]
    """
    weights = []
    
    for tech in techniques:
        # Step 2: Get the extended PDF
        # Note: The pdf_func should accept the specific sample realization y_i*
        # For unbiased, y_i* is effectively the query point or kernel center.
        # For volumetric, y_i* is the photon location.
        
        if tech.is_unbiased:
            # Unbiased techniques: p_i'(x, y_i*) = p_i(x)
            # The pdf depends only on the query point x
            p_prime = tech.pdf_func(query_point)
        else:
            # Volumetric techniques: p_i'(x, y_i*) = p_i(x, y_i*) / C_i
            # C_i is the precomputed integral of K^2
            p_standard = tech.pdf_func(query_point, tech.sample_realization)
            p_prime = p_standard / tech.kernel_integral
            
        # Step 3: Unnormalized weight w_i = n_i * p_i'
        w_i = tech.n_samples * p_prime
        weights.append(w_i)
        
    # Step 4: Normalize
    total_weight = sum(weights)
    if total_weight == 0:
        # Fallback if all weights are zero (e.g., no samples or zero pdf)
        # Distribute equally or return zeros depending on application needs
        return [0.0] * len(techniques)
        
    normalized_weights = [w / total_weight for w in weights]
    return normalized_weights
```

**Edge Cases and Pitfalls**
*   **Zero Denominator:** If all $p_i'(x, y_i^*)$ are zero, the weights are undefined. A fallback strategy (e.g., uniform weights) is required [G].
*   **Kernel Support Definition:** The support $|S_i(x)|$ must be well-defined and consistent with the kernel function $K_i$. For non-constant kernels, the integral $\int K_i^2$ must be computed accurately [S1].
*   **Approximation Assumption:** The derivation assumes $h_i(x, y_i^*) \approx f(x)$, meaning the radiance is roughly constant within the kernel support. If radiance varies significantly across the support, the heuristic may introduce bias [S1].

## Operating characteristics
*   **Time Complexity:** $O(n)$ per query point, where $n$ is the number of techniques in the mixture. The calculation involves simple arithmetic operations and pdf evaluations [S1].
*   **Memory Complexity:** $O(1)$ additional memory per query, assuming precomputed kernel integrals [S1].
*   **Strengths:** Reduces variance by optimally combining estimators with different sampling strategies. It naturally handles the transition between unbiased and biased (volumetric) estimators [S1].
*   **Limitations:** Relies on the assumption of locally constant radiance. Performance depends on the quality of the individual estimators and the appropriateness of the kernel functions [S1].

## Background
The Extended Balance Heuristic was introduced by Jarosz et al. in the context of unifying points, beams, and paths in volumetric light transport simulation [S1]. It builds upon the balance heuristic from Veach [1997] and extends it to handle the kernel density estimation inherent in volumetric radiance estimators [S1]. The method was developed to provide a unified framework for combining various volumetric sampling techniques, such as photon mapping and path tracing, into a single coherent estimator [S1].
