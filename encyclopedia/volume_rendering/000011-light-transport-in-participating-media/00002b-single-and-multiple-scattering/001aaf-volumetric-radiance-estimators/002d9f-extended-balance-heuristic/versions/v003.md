# Extended Balance Heuristic

Also called: EBH

## Overview
The Extended Balance Heuristic is a variance reduction technique used to combine estimates from a mixture of sampling techniques, specifically unbiased path sampling and extended space volumetric estimators, within the framework of volumetric radiance estimation [S1]. It differs from standard balance heuristics by incorporating an "extended" probability density function (pdf) that accounts for the blurring or kernel operations inherent in volumetric estimators, allowing for optimal weighting of samples that are not point-wise exact [S1]. It is primarily used to merge results from different radiance estimators, such as those derived from photon mapping or vertex merging, to produce a lower-variance final image [S1].

## How it works
The method calculates a weight for each technique $i$ in a mixture of $n$ techniques. The goal is to combine the estimates $\hat{f}_i$ from each technique into a single unbiased estimate $\hat{f}(x) = \sum_{i=1}^n \tilde{w}_i'(x, y_i^*) \hat{f}_i$.

### Inputs and Outputs
*   **Inputs**:
    *   $x$: The query point (e.g., position on a surface or in volume).
    *   $n$: The number of sampling techniques in the mixture.
    *   $n_i$: The number of samples generated by technique $i$.
    *   $p_i(x, y_i)$: The standard pdf for technique $i$.
    *   $K_i(x, y_i)$: The kernel function used by technique $i$ for blurring or reconstruction.
    *   $y_i^*$: A representative sample realization for technique $i$.
*   **Outputs**:
    *   $\tilde{w}_i'(x, y_i^*)$: The computed weight for technique $i$, where $\sum_{i=1}^n \tilde{w}_i' = 1$.

### Data Structures
No specific complex data structures are required beyond standard floating-point variables for pdfs, kernel integrals, and sample counts. The kernel integral $\int K_i^2$ is typically precomputed or cached per technique if the kernel support is static.

### Formulas and Definitions
The weight for technique $i$ is given by the Extended Balance Heuristic formula [S1]:

$$
\tilde{w}_i'(x, y_i^*) = \frac{n_i p_i'(x, y_i^*)}{\sum_{k=1}^n n_k p_k'(x, y_k^*)}
$$

where $p_i'(x, y_i^*)$ is the **extended pdf**. The definition of the extended pdf depends on the type of technique [S1]:

1.  **For unbiased path sampling techniques**:
    $$
    p_i'(x, y_i^*) = p_i(x)
    $$
    Here, the extended pdf is identical to the standard pdf.

2.  **For extended space volumetric estimators** (e.g., photon mapping, vertex merging):
    $$
    p_i'(x, y_i^*) = \frac{p_i(x, y_i^*)}{\int_{\mathcal{D}_{y_i}} K_i^2(x, y_i) \, dy_i}
    $$
    where $p_i(x, y_i^*)$ is the pdf of the sample $y_i^*$, and the denominator is the integral of the squared kernel over the domain $\mathcal{D}_{y_i}$.

### Constant Kernel Simplification
If the kernel $K_i$ is constant over its support $S_i(x)$, such that $K_i(x, y_i) = |S_i(x)|^{-1}$, the integral term simplifies significantly [S1]:

$$
\int_{\mathcal{D}_{y_i}} K_i^2(x, y_i) \, dy_i = \int_{S_i(x)} |S_i(x)|^{-2} \, dy_i = |S_i(x)|^{-2} \cdot |S_i(x)| = |S_i(x)|^{-1}
$$

Consequently, the extended pdf for constant kernels becomes [S1]:

$$
p_i'(x, y_i^*) = p_i(x, y_i^*) \cdot |S_i(x)|
$$

This formulation exactly corresponds to the vertex merging pdf introduced by Georgiev et al. [2012] [S1].

### Implementation Steps
1.  **Precomputation**: For each volumetric technique $i$, compute or cache the integral of the squared kernel:
    $$
    I_i(x) = \int_{\mathcal{D}_{y_i}} K_i^2(x, y_i) \, dy_i
    $$
    If the kernel is constant with support $S_i(x)$, $I_i(x) = |S_i(x)|^{-1}$.

2.  **Sample Selection**: For each technique $i$, identify the representative sample $y_i^*$ [S1]:
    *   For **extended space techniques** (volumetric estimators), use the actual realization of the photon variable (e.g., the specific photon location used in the query) [S1].
    *   For **unbiased path sampling techniques**, use the $y_i^*$ corresponding to the kernel center (e.g., the query point $x$ itself in the context of photon mapping queries) [S1].

3.  **Calculate Extended PDFs**: For each technique $i$, calculate $p_i'(x, y_i^*)$ [S1]:
    *   If technique $i$ is unbiased: $p_i'(x, y_i^*) = p_i(x)$.
    *   If technique $i$ is volumetric: $p_i'(x, y_i^*) = p_i(x, y_i^*) / I_i(x)$.

4.  **Compute Weights**: Calculate the numerator for each technique: $N_i = n_i \cdot p_i'(x, y_i^*)$. Sum all numerators: $D = \sum_{k=1}^n N_k$. The weight for technique $i$ is $\tilde{w}_i' = N_i / D$.

5.  **Combine Estimates**: The final radiance estimate is $\hat{f}(x) = \sum_{i=1}^n \tilde{w}_i' \hat{f}_i$.

### Pseudocode
```python
def extended_balance_heuristic(query_point, techniques):
    """
    Calculate weights for a mixture of volumetric radiance estimators.
    
    Args:
        query_point: The spatial location x.
        techniques: A list of technique objects. Each object must have:
            - type: 'unbiased' or 'volumetric'
            - n_samples: n_i, the number of samples for this technique.
            - pdf(x, y): A function returning p_i(x, y).
            - kernel_integral(x): A function returning int(K_i^2) dy_i.
              For constant kernels, this returns 1.0 / support_volume.
            - sample_y_star: The representative sample y_i*.
              For volumetric, this is the actual photon/sample location.
              For unbiased, this is typically the query point x.
    
    Returns:
        weights: A list of weights w_i' corresponding to each technique.
    """
    numerators = []
    
    for tech in techniques:
        y_star = tech.sample_y_star
        n_i = tech.n_samples
        
        # Step 1: Calculate the extended pdf p_i'(x, y_i*)
        if tech.type == 'unbiased':
            # For unbiased techniques, p_i' = p_i(x)
            # Note: p_i(x) is the pdf evaluated at the query point
            p_i_prime = tech.pdf(query_point, y_star)
        elif tech.type == 'volumetric':
            # For volumetric techniques, p_i' = p_i(x, y_i*) / integral(K_i^2)
            p_i = tech.pdf(query_point, y_star)
            kernel_int = tech.kernel_integral(query_point)
            
            # Guard against division by zero if kernel integral is zero
            if kernel_int == 0:
                p_i_prime = 0.0
            else:
                p_i_prime = p_i / kernel_int
        else:
            raise ValueError("Unknown technique type")
        
        # Step 2: Calculate numerator n_i * p_i'
        numerators.append(n_i * p_i_prime)
    
    # Step 3: Normalize
    total = sum(numerators)
    
    if total == 0:
        # Fallback: equal weights if all pdfs are zero
        weights = [1.0 / len(techniques)] * len(techniques)
    else:
        weights = [num / total for num in numerators]
        
    return weights
```

### Edge Cases and Pitfalls
*   **Zero Denominator**: If the sum of weighted extended pdfs is zero, the heuristic is undefined. This can occur if all techniques have zero probability density at the query point. A fallback to equal weighting or a minimum weight threshold is required [G].
*   **Kernel Support Definition**: The integral $\int K_i^2$ must be computed over the correct domain $\mathcal{D}_{y_i}$. For non-constant kernels, this integral may depend on the query point $x$ if the kernel support varies with position.
*   **Sample Representation**: The choice of $y_i^*$ is critical. Using the wrong sample (e.g., using the query point for a volumetric estimator instead of the actual photon location) breaks the unbiasedness of the estimator [S1].
*   **Precision**: When $n_i$ or $p_i'$ are very small, floating-point underflow may occur. Log-space arithmetic or careful scaling may be needed for robustness in extreme cases [G].

## Operating characteristics
*   **Time Complexity**: The weight calculation is $O(n)$, where $n$ is the number of techniques in the mixture. This is negligible compared to the cost of generating the samples themselves.
*   **Memory Complexity**: $O(1)$ additional memory per query, assuming kernel integrals are precomputed or cheap to evaluate.
*   **Variance Reduction**: The method is designed to reduce variance by optimally weighting samples based on their relative probabilities and the blurring characteristics of the estimators [S1]. It is particularly effective when combining techniques with different sampling densities or kernel sizes.
*   **Unbiasedness**: The resulting estimator is unbiased under the assumptions that $h_i(x, y_i^*) \approx f(x)$ (the function being estimated is roughly constant over the kernel support) and that the extended pdfs are correctly calculated [S1].
*   **Limitations**: The approximation $h_i(x, y_i^*) \approx f(x)$ may break down in regions of high radiance variation, leading to bias. The method assumes that the kernel integrals are known and correctly computed.

## Background
The Extended Balance Heuristic was introduced by Jarosz et al. in 2011 as part of a unified framework for volumetric light transport simulation [S1]. It extends the standard balance heuristic from path tracing to handle the "extended space" techniques used in volumetric rendering, such as photon mapping and vertex merging, where samples are associated with kernel functions rather than point-wise evaluations. The formulation was shown to be consistent with the vertex merging pdf proposed by Georgiev et al. [2012] for constant kernels [S1]. The method is a key component in the family of Volumetric Radiance Estimators, which aim to unify various light transport algorithms under a single theoretical framework [S1].
