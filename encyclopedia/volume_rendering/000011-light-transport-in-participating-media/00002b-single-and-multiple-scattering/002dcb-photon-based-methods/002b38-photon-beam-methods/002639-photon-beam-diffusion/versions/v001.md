# Photon Beam Diffusion

Also called: Photon Beam Diffusion for Rendering

## Overview
Photon Beam Diffusion (PBD) is an efficient numerical method for accurately rendering translucent materials that interprets incident light as a continuous beam of photons inside the material and uses Monte Carlo integration to solve the diffusion equation [S1, unofficial]. It is a hybrid method combining Monte Carlo integration with the diffusion approximation to render subsurface scattering, using improved diffusion profiles and a numerical integration scheme to achieve faster, more accurate, and numerically stable results than quantized diffusion, while being simpler [S1, unofficial]. Unlike Quantized Diffusion (QD), which relies on sum-of-Gaussians approximations, PBD eliminates quantization by treating the beam as an extended source integral [S1, unofficial].

## How it works
**Inputs and Outputs:**
*   **Inputs:** Scattering parameters (scattering coefficient $\sigma_s$, absorption coefficient $\sigma_a$, anisotropy factor $g$), surface geometry, incident light direction, and refractive indices of the medium and surrounding environment.
*   **Outputs:** Radiant exitance (diffuse reflection profile) for a given point on the surface, combining single-scattering and multiple-scattering contributions.

**Data Structures:**
*   **Photon Beam:** A continuous directional ray segment starting at the surface entry point $\mathbf{x}_0$ with direction $\mathbf{d}$ and length determined by the medium's attenuation. Unlike discrete photon points, the beam stores its entry parameters and direction [S1, unofficial].
*   **Sample Points:** A set of distances $t_i$ along the beam where the diffusion profile is evaluated.

**Method Steps:**

1.  **Parameter Conversion:** Convert user-friendly parameters (diffuse albedo $R_d$, diffuse mean free path length $1/\tau_0$) to the internal diffusion model parameters (scattering coefficient $\sigma_s'$, absorption coefficient $\sigma_a$, anisotropy $g$). This involves inverting the relationship between $R_d$ and $\sigma_s'$ using a precomputed table lookup, as the analytical inversion is not available but the function is monotonically increasing [S1, unofficial].

2.  **Beam Sampling:** For a given incident light direction, generate a set of sample distances $t_i$ along the photon beam. The distances are chosen using an exponentially-varying set:
    $$ t_i = t_1 \cdot \alpha^i $$
    where $\alpha = 1.2$ is the step size, and $t_1$ is a minimum distance (e.g., $0.01/\tau_0$) [S1, unofficial]. The number of Monte Carlo samples required is typically 3 to 5 [S1, unofficial].

3.  **Single-Scattering Profile Calculation:** Compute the exact single-scattering profile $S^{(1)}$ using the same sample points or rays as the multi-scattering calculation, adding minimal overhead [S1, unofficial].
    *   If the surface separates volumes with different indices of refraction, use a separate sample sequence for single-scattering starting from the critical angle, as contributions below the critical angle are zero [S1, unofficial]. This guarantees a smooth single-scattering profile regardless of the number of samples [S1, unofficial].
    *   The single-scattering term accounts for the phase function and Fresnel terms explicitly, unlike the approximate similarity theory used in some diffusion models [S1, unofficial].
    *   The single-scattering portion of the BSSRDF is defined in direct analogy to the multi-scattering diffuse profile, but using the single-scattering reflectance $R^{(1)}$ instead of the diffuse reflectance $R_d$ [S1, unofficial].

4.  **Multiple-Scattering Profile Calculation:** Evaluate the multiple-scattering contribution using the improved diffusion model [S1, unofficial].
    *   View each Monte Carlo sample of the beam integral as a weighted photon (monopole) located at $\mathbf{x}_r(t_i)$ inside the medium [S1, unofficial].
    *   Mirror this monopole exactly as in Photon Diffusion (PD) to compute the three boundary conditions (dipole, multipole, and quadrupole) as proposed by Donner and Jensen [DJ07] [S1, unofficial].
    *   For oblique illumination on arbitrary geometries, blend between these boundary conditions [S1, unofficial].
    *   The integral is evaluated numerically using the stored photon beams as extended beam sources [S1, unofficial].

5.  **Combining Profiles:** Add the single-scattering and multiple-scattering profiles to obtain the final radiant exitance profile [S1, unofficial]. The two profiles are computed simultaneously using the same points or rays [S1, unofficial].

6.  **Rendering Integration:**
    *   **Point-Based:** Distribute surface points, construct an octree, and hierarchically traverse it during rendering [S1, unofficial].
    *   **Ray-Traced:** At a shading point, select a point inside the object and shoot rays in all directions, computing the arclength to the surface [S1, unofficial].
    *   **Photon Beam Tracer:** Store continuous, directional photon beams entering the surface instead of discrete photon points. Use equiangular/exponential Monte Carlo Importance Sampling (MIS) for photon beam diffusion to achieve faster multiple scattering convergence than standard Photon Diffusion, especially at oblique light angles [S1, unofficial].

**Pseudocode:**

```python
def compute_photon_beam_diffusion_profile(incident_direction, surface_normal, 
                                          sigma_s, sigma_a, g, n_medium, n_env):
    """
    Computes the combined single and multiple scattering profile for a photon beam.
    """
    # 1. Parameter Conversion
    # Convert sigma_s, sigma_a, g to diffuse albedo Rd and mean free path 1/tau0
    # using table lookup for inversion.
    Rd, tau0 = convert_parameters(sigma_s, sigma_a, g)
    
    # 2. Define Sample Distances
    # Exponentially-varying set with step size 1.2
    alpha = 1.2
    t_min = 0.01 * tau0
    num_samples = 5 # Typical value
    distances = []
    for i in range(num_samples):
        t = t_min * (alpha ** i)
        distances.append(t)
        
    # 3. Single-Scattering Profile
    # Check for refraction index mismatch
    if n_medium != n_env:
        critical_angle = asin(n_env / n_medium)
        # Use separate sample sequence starting from critical angle
        # Contributions below critical angle are zero
        ss_profile = compute_single_scattering_refracted(distances, critical_angle, 
                                                         sigma_s, sigma_a, g, 
                                                         surface_normal, incident_direction)
    else:
        ss_profile = compute_single_scattering(distances, sigma_s, sigma_a, g, 
                                               surface_normal, incident_direction)
        
    # 4. Multiple-Scattering Profile
    # Evaluate diffusion integral for each sample point
    ms_profile = 0.0
    for t in distances:
        # Position of the 'monopole' photon inside the medium
        photon_pos = surface_point + t * incident_direction
        
        # Mirror monopole to compute boundary conditions (dipole, multipole, quadrupole)
        # Blend boundary conditions for oblique illumination [DJ07]
        reflectance_at_t = evaluate_improved_diffusion_reflectance(photon_pos, 
                                                                   sigma_s, sigma_a, g,
                                                                   surface_normal)
        
        # Weight the sample (Monte Carlo estimator)
        # Weight depends on the beam intensity at t and the MIS weights
        weight = compute_beam_weight(t, incident_direction, alpha, num_samples)
        ms_profile += weight * reflectance_at_t
        
    # 5. Combine
    # Reshape exitant radiance by Fresnel term as done with multi-scattering
    final_profile = ss_profile + ms_profile
    return final_profile

def compute_single_scattering(distances, sigma_s, sigma_a, g, normal, direction):
    """
    Computes exact single-scattering profile under planar configuration.
    Accounts for phase function and Fresnel terms explicitly.
    """
    profile = 0.0
    for t in distances:
        # Calculate attenuation along the beam
        attenuation = exp(-(sigma_s + sigma_a) * t)
        
        # Evaluate phase function p(g, theta)
        phase = phase_function(g, angle_between(direction, normal))
        
        # Evaluate Fresnel transmission/reflection
        fresnel = fresnel_term(direction, normal)
        
        # Accumulate contribution
        profile += attenuation * phase * fresnel
    return profile

def evaluate_improved_diffusion_reflectance(photon_pos, sigma_s, sigma_a, g, normal):
    """
    Evaluates the improved diffusion model reflectance.
    Mirrors the monopole source to handle boundary conditions.
    """
    # Determine boundary condition type based on angle and geometry
    # Blend between dipole, multipole, and quadrupole [DJ07]
    bc_type = determine_boundary_condition(photon_pos, normal)
    
    # Calculate reflectance using the specific boundary condition formula
    # from the improved diffusion model [dI11]
    reflectance = diffusion_model_reflectance(photon_pos, sigma_s, sigma_a, g, bc_type)
    return reflectance
```

**Edge Cases and Pitfalls:**
*   **Oblique Illumination:** Requires careful handling of boundary conditions. Blending between dipole, multipole, and quadrupole conditions is necessary [S1, unofficial].
*   **Refractive Index Mismatch:** Single-scattering must start from the critical angle if indices differ, otherwise contributions are zero [S1, unofficial].
*   **Precision:** The numerical integration scheme is designed to be numerically stable, avoiding the instabilities of quantized methods [S1, unofficial].

## Operating characteristics
*   **Time Complexity:** Rendering with PBD and single-scattering typically takes about 15% longer than using the classic dipole model [S1, unofficial].
*   **Speedup:** PBD achieves a speedup factor of 3.1 for a full profile when comparing 5 PBD samples with 44 Gaussians in QD. In cases where only one sample of a profile is needed, the speedup is 21.6 [S1, unofficial].
*   **Memory Complexity:** Stores continuous photon beams instead of discrete points, reducing memory overhead compared to storing large numbers of Gaussians or photons [S1, unofficial].
*   **Quality:** Uses 3–5 Monte Carlo samples to achieve quality equivalent to Quantized Diffusion (QD), which requires 20–60 Gaussians [S1, unofficial].
*   **Strengths:** Increased speed, flexibility, numerical stability, and ease of implementation compared to QD. Supports finite and multi-layer materials and directional incident effects [S1, unofficial].
*   **Limitations:** Assumes the exitant boundary is diffuse (though not Lambertian, reshaped by Fresnel). Less suitable for smooth Fresnel boundaries (marble/milk) compared to Jensen et al.'s approach, which is better for such materials [S1, unofficial].
*   **Performance Example:** Render time for a human head scene was 7 minutes on a multi-core PC [S1, unofficial].

## Background
*   **Origin:** Introduced by Ralf Habel, Per H. Christensen, and Wojciech Jarosz in 2013 at the Eurographics Symposium on Rendering [S1, unofficial].
*   **Development:** The method builds on the improved diffusion model [dI11] and blends boundary conditions proposed by Donner and Jensen [DJ07]. It addresses the computational prohibitions of numerically integrating extended beam sources, which previously led to the use of single-depth dipole approximations and sum-of-Gaussians approaches [S1, unofficial].
*   **Usage:** Implemented in research and production rendering systems, including Mitsuba (point-based subsurface scattering), PRMan (point-based and ray-traced subsurface scattering), and on top of a progressive photon beam tracer [S1, unofficial].
