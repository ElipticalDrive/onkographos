# Grid-based Importance Sampling for Boundary Segments

Also called: Photon/importon map sampling

## Overview
This method provides a precomputed importance sampling distribution for boundary path integrals in differentiable rendering by discretizing the integrand onto a regular 3D grid [S1, unofficial]. It solves the problem of efficiently sampling the low-dimensional boundary space ($\mathbf{x}_B, \boldsymbol{\omega}_B$) where the integrand is complex and potentially discontinuous, making uniform sampling inefficient [S1, unofficial]. Unlike [Instant Radiosity / Virtual Point Lights (VPLs)](9319-instant-radiosity-virtual-point-lights-vpls.md) which uses point sources, this method constructs a continuous density field using bidirectional path tracing data (photons and importons) to guide the sampling of boundary segments [S1, unofficial].

## How it works
**Inputs:**
- Light source radiance distribution.
- Detector importance distribution.
- Scene geometry (e.g., polygonal meshes).

**Outputs:**
- A regular 3D grid storing weights $P_i$ for each cell $C_i$, representing the discretized probability density $P(\mathbf{x}_B, \boldsymbol{\omega}_B)$.

**Data Structures:**
- **Regular 3D Grid:** A fixed-resolution 3D array. Each cell $C_i$ stores a scalar weight $P_i$.
- **Photon Map:** Stores photons traced from the light source, carrying radiance information.
- **Importon Map:** Stores importons traced from the detector, carrying importance information.

**Steps:**
1. **Precomputation:** Before rendering, generate a photon map by tracing photons carrying radiance from the light source [S1, unofficial].
2. **Precomputation:** Generate an importon map by tracing importons carrying importance from the detector [S1, unofficial].
3. **Discretization:** Define a regular 3D grid that covers the domain of the boundary variables. The total dimensionality of the domains for $\mathbf{x}_B$ and $\boldsymbol{\omega}_B$ is 3 (1D for $\mathbf{x}_B$ on mesh edges, 2D for $\boldsymbol{\omega}_B$ on a subset of the sphere of directions) [S1, unofficial].
4. **Weight Calculation:** For each cell $C_i$ in the grid, compute the weight $P_i$ by integrating the boundary integrand $F_B(\mathbf{x}_B, \boldsymbol{\omega}_B)$ over the cell volume using uniform sampling:
   $$ P_i = \int_{C_i} F_B(\mathbf{x}_B, \boldsymbol{\omega}_B) \, d\boldsymbol{\omega}_B \, d\mathbf{x}_B $$
   This provides a piecewise constant representation of the probability density $P(\mathbf{x}_B, \boldsymbol{\omega}_B)$ [S1, unofficial].
5. **Sampling:** During rendering, sample boundary segments $(\mathbf{x}_B, \boldsymbol{\omega}_B)$ by first selecting a cell $C_i$ proportional to $P_i$, then sampling uniformly within that cell [S1, unofficial].

**Pseudocode:**
```python
def precompute_grid(photon_map, importon_map, grid_resolution):
    """
    Precompute the importance sampling grid for boundary segments.
    """
    # Initialize grid with zeros
    grid_weights = zeros(grid_resolution)
    
    # Define the 3D domain covering x_B (1D edge parameter) and omega_B (2D direction)
    domain_bounds = get_domain_bounds() 
    
    # Iterate over all cells in the grid
    for i in range(grid_resolution):
        cell = grid_cells[i]
        
        # Uniformly sample x_B and omega_B within the cell
        # Note: x_B is 1D (edge parameter), omega_B is 2D (direction on sphere subset)
        samples = uniform_sample_cell(cell)
        
        # Compute the integral of F_B over the cell using the samples
        # F_B depends on radiance from photon_map and importance from importon_map
        integral_sum = 0.0
        for sample in samples:
            x_B, omega_B = sample
            radiance = evaluate_radiance(x_B, omega_B, photon_map)
            importance = evaluate_importance(x_B, omega_B, importon_map)
            F_B = radiance * importance # Simplified interaction term
            integral_sum += F_B
            
        # Normalize by number of samples to approximate the integral
        P_i = integral_sum / len(samples)
        grid_weights[i] = P_i
        
    return grid_weights

def sample_boundary_segment(grid_weights, grid_cells):
    """
    Sample a boundary segment using the precomputed grid.
    """
    # Select a cell proportional to its weight
    cell_index = weighted_choice(grid_weights)
    cell = grid_cells[cell_index]
    
    # Sample uniformly within the selected cell
    x_B, omega_B = uniform_sample_cell(cell)
    
    return x_B, omega_B
```

**Parameters:**
- Grid resolution: Not given in the sources.
- Number of uniform samples per cell for integration: Not given in the sources.

**Edge Cases and Pitfalls:**
- The method assumes the total dimensionality of the domain is low (3D) to make the regular grid feasible [S1, unofficial].
- If the AABBs used for spatial partitioning are not small enough, the assumption of at most one intersection per sample point on the proxy curve may be violated, introducing bias [S2].

## Subtopics

### [Primary-Sample-Space Guiding with Kd-Trees](8206-primary-sample-space-guiding-with-kd-trees.md)
This method efficiently estimates boundary path integrals in differentiable rendering by constructing Kd-trees over the 3D primary sample space to importance sample boundary segments. It addresses the challenge that the integrand is complex and potentially discontinuous, making uniform sampling inefficient. Unlike forward rendering path guiding, which accelerates unidirectional path tracing, this technique focuses on the unique boundary integrals required for gradient computation in differentiable rendering. It builds on [Grid-based Importance Sampling for Boundary Segments](7643-grid-based-importance-sampling-for-boundary-segments.md) by replacing the rigid regular grid with an adaptive Kd-tree structure that automatically refines based on the local structure of the approximated integrand.

### [Importance Segment Data Structure and Estimation](15027-importance-segment-data-structure-and-estimation.md)
This method provides a compact, piecewise-constant representation of the importance function $\tilde{k}(t)$ along a ray, enabling efficient importance sampling for Monte Carlo volume rendering. It solves the problem of maintaining an accurate sampling distribution without storing every individual sample, thereby reducing memory usage and accelerating the binary search required for sampling. It differs from naive accumulation by actively discarding redundant samples and splitting segments when importance values change, ensuring the data structure remains a refined approximation of the true importance function.

### Grid-based Guiding for Boundary Path Sampling
A simple regular-grid-based scheme used to guide the sampling of boundary paths for implicit surfaces, helping to find un-occluded regions of light [S2]. Regular-grid-based guiding has difficulties handling reflections off of highly glossy surfaces [S2]. It assumes at most one intersection for each sample point on the proxy curve, which may be violated when AABBs are not small enough, introducing bias [S2].

## Operating characteristics
- **Time Complexity:** Precomputation requires tracing photons and importons and integrating over grid cells. Sampling is $O(1)$ after precomputation.
- **Memory Complexity:** Depends on grid resolution and the size of the photon/importon maps.
- **Strengths:** Exploits the low dimensionality (3D) of the boundary domain [S1, unofficial]. Provides a continuous density field for importance sampling.
- **Limitations:** Struggles with highly glossy surfaces due to the regular grid structure [S2]. Bias can occur if spatial partitioning (AABBs) is too coarse [S2].
- **When to use:** When efficient gradient estimation for boundary integrals in differentiable rendering is required, and the boundary domain is low-dimensional.
- **When not to use:** For scenes with highly glossy reflections where regular grids fail to capture the complex importance distribution [S2].

## Background
Originated in the context of path-space differentiable rendering [S1, unofficial]. The method is inspired by standard path guiding using photon maps [Jensen 1995] [S1, unofficial]. It was developed to address the challenges of sampling boundary paths efficiently in differentiable rendering, particularly for implicit surfaces [S2].
