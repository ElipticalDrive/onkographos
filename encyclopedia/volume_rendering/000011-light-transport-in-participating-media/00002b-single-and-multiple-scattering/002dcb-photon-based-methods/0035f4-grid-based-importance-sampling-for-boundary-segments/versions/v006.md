# Grid-based Importance Sampling for Boundary Segments

Also called: Photon/importon map sampling

## Overview
This method precomputes an importance sampling distribution for boundary path integrals by discretizing the probability density $P(\mathbf{x}_B, \boldsymbol{\omega}_B)$ onto a regular 3D grid [S1, unofficial]. It solves the problem of efficiently sampling the low-dimensional boundary space where the integrand is complex and potentially discontinuous, making uniform sampling inefficient [S1, unofficial]. Unlike [Instant Radiosity / Virtual Point Lights (VPLs)](9319-instant-radiosity-virtual-point-lights-vpls.md) which uses point sources, this method constructs a piecewise constant representation of the importance distribution using photon and importon maps to guide boundary segment sampling [S1, unofficial].

## How it works
**Inputs:**
- Light source radiance distribution.
- Detector importance distribution.
- Scene geometry (e.g., polygonal meshes) [S1, unofficial].

**Outputs:**
- A regular 3D grid storing weights $P_i$ for each cell $C_i$, representing the discretized probability density $P(\mathbf{x}_B, \boldsymbol{\omega}_B)$ [S1, unofficial].

**Data Structures:**
- **Regular 3D Grid:** A fixed-resolution 3D array [S1, unofficial]. Each cell $C_i$ stores a scalar weight $P_i$ [S1, unofficial].
- **Photon Map:** Stores photons traced from the light source, carrying radiance information [S1, unofficial].
- **Importon Map:** Stores importons traced from the detector, carrying importance information [S1, unofficial].

**Steps:**
1. **Precomputation:** Before rendering, generate a photon map by tracing photons carrying radiance from the light source [S1, unofficial].
2. **Precomputation:** Generate an importon map by tracing importons carrying importance from the detector [S1, unofficial].
3. **Discretization:** Define a regular 3D grid that covers the domain of the boundary variables [S1, unofficial]. The total dimensionality of the domains for $\mathbf{x}_B$ and $\boldsymbol{\omega}_B$ is 3 (1D for $\mathbf{x}_B$ on mesh edges, 2D for $\boldsymbol{\omega}_B$ on a subset of the sphere of directions) [S1, unofficial].
4. **Weight Calculation:** For each cell $C_i$ in the grid, compute the weight $P_i$ by integrating the boundary integrand $F_B(\mathbf{x}_B, \boldsymbol{\omega}_B)$ over the cell volume using uniform sampling:
   $$ P_i = \int_{C_i} F_B(\mathbf{x}_B, \boldsymbol{\omega}_B) \, d\boldsymbol{\omega}_B \, d\mathbf{x}_B $$
   This provides a piecewise constant representation of the probability density $P(\mathbf{x}_B, \boldsymbol{\omega}_B)$ [S1, unofficial].
5. **Sampling:** During rendering, sample boundary segments $(\mathbf{x}_B, \boldsymbol{\omega}_B)$ by first selecting a cell $C_i$ proportional to $P_i$, then sampling uniformly within that cell [S1, unofficial].

**Pseudocode:**
```python
import random

def precompute_grid(photon_map, importon_map, grid_res, bounds):
    """
    Precompute importance sampling grid weights for boundary segments.
    photon_map: list of photon objects with .radiance attribute
    importon_map: list of importon objects with .importance attribute
    grid_res: tuple (nx, ny, nz) defining the 3D grid dimensions
    bounds: tuple of ((x_min, x_max), (y_min, y_max), (z_min, z_max))
    """
    nx, ny, nz = grid_res
    grid_weights = [[0.0] * nz for _ in range(ny)]
    cell_volumes = [[0.0] * nz for _ in range(ny)]
    
    dx = (bounds[0][1] - bounds[0][0]) / nx
    dy = (bounds[1][1] - bounds[1][0]) / ny
    dz = (bounds[2][1] - bounds[2][0]) / nz
    
    num_samples = 100  # Not given in the sources [G]
    
    for ix in range(nx):
        for iy in range(ny):
            for iz in range(nz):
                integral_sum = 0.0
                for _ in range(num_samples):
                    # Uniformly sample x_B and omega_B within cell C_i
                    x_B = bounds[0][0] + (ix + random.random()) * dx
                    omega_B = (bounds[1][0] + (iy + random.random()) * dy, 
                               bounds[2][0] + (iz + random.random()) * dz)
                    # Evaluate integrand F_B(x_B, omega_B)
                    F_B = evaluate_F_B(x_B, omega_B, photon_map, importon_map)
                    integral_sum += F_B
                grid_weights[iy][iz] = integral_sum / num_samples
                cell_volumes[iy][iz] = dx * dy * dz
    return grid_weights, cell_volumes, bounds, grid_res

def evaluate_F_B(x_B, omega_B, photon_map, importon_map):
    """Evaluate the boundary integrand F_B using the precomputed maps."""
    radiance = query_radiance(x_B, omega_B, photon_map)
    importance = query_importance(x_B, omega_B, importon_map)
    return radiance * importance

def query_radiance(x_B, omega_B, photon_map):
    """Standard density estimation from photon map [G]."""
    return sum(p.radiance for p in photon_map) / len(photon_map)

def query_importance(x_B, omega_B, importon_map):
    """Standard density estimation from importon map [G]."""
    return sum(i.importance for i in importon_map) / len(importon_map)

def sample_boundary_segment(grid_weights, cell_volumes, bounds, grid_res):
    """Sample a boundary segment using the precomputed grid."""
    nx, ny, nz = grid_res
    # Build cumulative distribution function
    cdf = []
    total = 0.0
    for iy in range(ny):
        for iz in range(nz):
            weight = grid_weights[iy][iz] * cell_volumes[iy][iz]
            total += weight
            cdf.append(total)
    
    # Select cell proportional to weight
    r = random.random() * total
    cell_idx = 0
    for i, val in enumerate(cdf):
        if val >= r:
            cell_idx = i
            break
    
    ix = cell_idx // (ny * nz)
    iy = (cell_idx // nz) % ny
    iz = cell_idx % nz
    
    # Uniform sample within selected cell
    dx = (bounds[0][1] - bounds[0][0]) / nx
    dy = (bounds[1][1] - bounds[1][0]) / ny
    dz = (bounds[2][1] - bounds[2][0]) / nz
    x_B = bounds[0][0] + (ix + random.random()) * dx
    omega_B = (bounds[1][0] + (iy + random.random()) * dy, 
               bounds[2][0] + (iz + random.random()) * dz)
    return x_B, omega_B
```

**Parameters:**
- Grid resolution: Not given in the sources.
- Number of uniform samples per cell for integration: Not given in the sources.

**Edge Cases and Pitfalls:**
- The method assumes the total dimensionality of the domain is low (3D) to make the regular grid feasible [S1, unofficial].
- If the AABBs used for spatial partitioning are not small enough, the assumption of at most one intersection per sample point on the proxy curve may be violated, introducing bias [S2].

## Subtopics

### [Primary-Sample-Space Guiding with Kd-Trees](8206-primary-sample-space-guiding-with-kd-trees.md)
This method efficiently estimates boundary path integrals in differentiable rendering by constructing Kd-trees over the 3D primary sample space to importance sample boundary segments. It addresses the challenge that the integrand is complex and potentially discontinuous, making uniform sampling inefficient. Unlike forward rendering path guiding, which accelerates unidirectional path tracing, this technique focuses on the unique boundary integrals required for gradient computation in differentiable rendering. It builds on [Grid-based Importance Sampling for Boundary Segments](7643-grid-based-importance-sampling-for-boundary-segments.md) by replacing the rigid regular grid with an adaptive Kd-tree structure that automatically refines based on the local structure of the approximated integrand.

### [Importance Segment Data Structure and Estimation](15027-importance-segment-data-structure-and-estimation.md)
This method provides a compact, piecewise-constant representation of the importance function $\tilde{k}(t)$ along a ray, enabling efficient importance sampling for Monte Carlo volume rendering. It solves the problem of maintaining an accurate sampling distribution without storing every individual sample, thereby reducing memory usage and accelerating the binary search required for sampling. It differs from naive accumulation by actively discarding redundant samples and splitting segments when importance values change, ensuring the data structure remains a refined approximation of the true importance function.

### Grid-based Guiding for Boundary Path Sampling
A simple regular-grid-based scheme used to guide the sampling of boundary paths for implicit surfaces, helping to find un-occluded regions of light [S2]. Regular-grid-based guiding has difficulties handling reflections off of highly glossy surfaces [S2]. It assumes at most one intersection for each sample point on the proxy curve, which may be violated when AABBs are not small enough, introducing bias [S2].

## Operating characteristics
- **Time Complexity:** Precomputation requires tracing photons and importons and integrating over grid cells [S1, unofficial]. Sampling is $O(1)$ after precomputation.
- **Memory Complexity:** Depends on grid resolution and the size of the photon/importon maps [S1, unofficial].
- **Strengths:** Exploits the low dimensionality (3D) of the boundary domain [S1, unofficial]. Provides a piecewise constant representation for importance sampling [S1, unofficial].
- **Limitations:** Struggles with highly glossy surfaces due to the regular grid structure [S2]. Bias can occur if spatial partitioning (AABBs) is too coarse [S2].
- **When to use:** When efficient gradient estimation for boundary integrals in differentiable rendering is required, and the boundary domain is low-dimensional [S1, unofficial][S2].
- **When not to use:** For scenes with highly glossy reflections where regular grids fail to capture the complex importance distribution [S2].

## Background
The method is inspired by standard path guiding using photon maps [S1, unofficial]. It was developed to address the challenges of sampling boundary paths efficiently in differentiable rendering, particularly for implicit surfaces [S1, unofficial][S2].
