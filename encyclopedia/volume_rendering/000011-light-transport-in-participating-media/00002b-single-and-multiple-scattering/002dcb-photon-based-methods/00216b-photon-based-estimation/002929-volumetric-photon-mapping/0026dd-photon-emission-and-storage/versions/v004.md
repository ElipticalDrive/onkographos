# Photon Emission and Storage
Also called: Photon Mapping with Volume Storage, emitPhotons

## Overview
Photon Emission and Storage is the first pass of Volumetric Photon Mapping, responsible for generating photons from light sources and recording their positions, directions, and energies into spatial data structures (volume buffers and surface arrays) as they traverse the scene [S1, unofficial]. It solves the problem of pre-computing indirect lighting interactions in participating media by decoupling the light transport simulation from the final image synthesis [S1, unofficial]. Unlike direct integration methods, it stores photon data for later density estimation [S1, unofficial]. It is distinguished from its sibling [Beam Radiance Estimate](1283-beam-radiance-estimate.md) by storing individual photon states rather than beam parameters, and from [Photon Beam Tracing](5401-photon-beam-tracing.md) by using ray marching rather than beam tracing [S1, unofficial].

## How it works
**Inputs and Outputs:**
*   **Inputs:** Light source position (`Light`), light source radius (`light_bulb_r`), maximum bounces (`nrBounces`), reflection limit per bounce (`reflection_limit`), total photon count (`nrPhotons`), scene geometry (`objects`), and a flag for 3D view (`view3D`) [S1, unofficial].
*   **Outputs:** Populated volume photon buffer (`vol_photons`) and surface photon arrays (`numPhotons`) [S1, unofficial].

**Data Structures:**
*   `vol_photons`: Array storing volume photons. Each entry contains position (`vol_photons[i][0]`), direction (`vol_photons[i][1]`), and energy/color (`vol_photons[i][2]`) [S1, unofficial].
*   `objects`: Array of scene objects, each with type (`TYPE_SPHERE`), optics (`OPT_REFLECT`), color, and coordinates [S1, unofficial].
*   `SIntersectionStat`: Structure containing intersection distance (`dist`), intersected object (`obj`), and intersection point (`pnt`) [S1, unofficial].

**Parameters:**
*   `light_bulb_r`: Radius of the light source. Typical value: 0.1 [S1, unofficial].
*   `reflection_limit`: Maximum number of optical interactions (reflections/refractions) per bounce. Typical value: 4 [S1, unofficial].
*   `nrBounces`: Maximum number of bounces for photon tracing. Value not given in the sources [S1, unofficial].
*   `nrPhotons`: Base number of photons to emit. Typical value: 2000 [S1, unofficial].
*   `collect_r`: Radius for photon collection during estimation. Typical value: 0.7 [S1, unofficial].
*   `power`: Photon power scaling factor. Typical value: 500 [S1, unofficial].
*   `exposure`: Exposure scaling factor. Value not given in the sources [S1, unofficial].

**Steps:**
1.  **Initialization:** Reset photon counts for all objects (`numPhotons`) and volume counter (`num_vol`) to 0 [S1, unofficial].
2.  **Determine Total Photons:** If `view3D` is true, set `num_photon = nrPhotons * 3.0`; otherwise, `num_photon = nrPhotons` [S1, unofficial].
3.  **Emit Test Photons (Optional):** Emit 100 photons from a specific object (`objects[5]`) with fixed properties for testing [S1, unofficial].
    *   Generate random direction `ray = randDir(1.0)` [S1, unofficial].
    *   Calculate start position `pnt = Light + stepout(ray, light_bulb_r) + Vector3(0.0001, 0.0001, 0.0001)` [S1, unofficial].
    *   Store photon using `storePhoton(objects[5], pnt, ray, rgb)` where `rgb = Vector3(50,50,50)` [S1, unofficial].
4.  **Main Photon Loop:** Iterate `i` from 0 to `num_photon - 1` [S1, unofficial].
    *   **Initialize Photon:** Set `bounces = 1`, `rgb = white` (1.0, 1.0, 1.0), `ray = randDir(1.0)` [S1, unofficial].
    *   **Generate Start Position:**
        *   Generate `from` such that `from.y() < Light.y()` by sampling `from = randDir(1.0) + Light` until valid [S1, unofficial].
        *   **Boundary Check:** If `fabs(from.x()) > 1.5` or `fabs(from.y()) > 1.2`, mark invalid by setting `bounces = nrBounces + 1` [S1, unofficial].
        *   **Object Intersection Check:** Iterate through all objects. If object is a sphere, calculate `distance(from, center)`. If `distance < radius`, mark invalid by setting `bounces = nrBounces + 1` [S1, unofficial].
    *   **Volume Photon Storage (Alternative Path):** If `bounces == 0` (valid start):
        *   Call `storePhoton_vol(from, ray, rgb)` to store initial state in volume buffer [S1, unofficial].
        *   Call `shadowPhoton(ray, pnt)` to trace shadow ray [S1, unofficial].
        *   Continue to next photon [S1, unofficial].
    *   **Ray Marching Loop:** While `istat.dist < NOT_INTERSECTED` and `bounces <= nrBounces`:
        *   **Trace Ray:** Call `raytrace(ray, from)` to find first intersection `istat` [S1, unofficial].
        *   **Calculate Point:** `pnt = from + ray * istat.dist` [S1, unofficial].
        *   **Handle Optics:** While `istat.obj->getOptics() != OPT_NONE` and `ref < reflection_limit`:
            *   If `OPT_REFLECT`, reflect ray: `ray = reflect(istat.obj, pnt, ray, from)` [S1, unofficial].
            *   Increment `ref` [S1, unofficial].
            *   Update `from = pnt` [S1, unofficial].
            *   Trace next intersection: `istat = raytrace(ray, from)` [S1, unofficial].
            *   If `istat.dist >= NOT_INTERSECTED`, break loop [S1, unofficial].
        *   **Store Photon:** If intersection exists:
            *   Update color: `col = mulColor(rgb, istat.obj)` [S1, unofficial].
            *   Attenuate color: `rgb = col * (1.0 / sqrt(bounces))` [S1, unofficial].
            *   Store photon: `storePhoton(istat.obj, pnt, ray, rgb)` [S1, unofficial].
            *   Draw photon: `drawPhoton(rgb, pnt)` [S1, unofficial].
            *   Trace shadow: `shadowPhoton(ray, pnt)` [S1, unofficial].
            *   Prepare for next bounce: `ray = reflect(istat.obj, pnt, ray, from)` [S1, unofficial].
            *   Trace next intersection: `istat = raytrace(ray, pnt)` [S1, unofficial].
            *   Update `from = pnt` and `bounces++` [S1, unofficial].
            *   If `istat.dist >= NOT_INTERSECTED`, break loop [S1, unofficial].

**Pseudocode:**
```python
def emitPhotons(Light, light_bulb_r, nrBounces, reflection_limit, nrPhotons, objects, view3D):
    # Initialize counters
    numPhotons = [0] * len(objects)
    num_vol = 0
    
    # Determine total photons
    num_photon = nrPhotons * 3.0 if view3D else nrPhotons
    
    # Optional test photons
    for i in range(100):
        ray = randDir(1.0)
        rr = stepout(ray, light_bulb_r)
        pnt = rr + Light + Vector3(0.0001, 0.0001, 0.0001)
        rgb = Vector3(50, 50, 50)
        storePhoton(objects[5], pnt, ray, rgb)
        drawPhoton(rgb, pnt)
        
    white = Vector3(1.0, 1.0, 1.0)
    
    for i in range(num_photon):
        bounces = 1
        rgb = white
        ray = randDir(1.0)
        from_pos = Light
        
        # Generate valid start position
        while from_pos.y() >= Light.y():
            from_pos = randDir(1.0) + Light
            
        # Boundary check
        if abs(from_pos.x()) > 1.5 or abs(from_pos.y()) > 1.2:
            bounces = nrBounces + 1
            
        # Object intersection check
        for dx in range(len(objects)):
            ob = objects[dx]
            if ob.getType() != TYPE_SPHERE:
                continue
            center = Vector3(ob.coords)
            if distance(from_pos, center) < ob.coords[3]:
                bounces = nrBounces + 1
                
        # Volume photon storage if valid
        if bounces == 0:
            storePhoton_vol(from_pos, ray, rgb)
            shadowPhoton(ray, from_pos)
            continue
            
        refractive = 1.0
        istat = raytrace(ray, from_pos)
        
        while istat.dist < NOT_INTERSECTED and bounces <= nrBounces:
            pnt = from_pos + ray * istat.dist
            ref = 0
            
            # Handle optics
            while istat.obj.getOptics() != OPT_NONE and ref < reflection_limit:
                if istat.obj.getOptics() == OPT_REFLECT:
                    ray = reflect(istat.obj, pnt, ray, from_pos)
                ref += 1
                from_pos = pnt
                istat = raytrace(ray, from_pos)
                if istat.dist >= NOT_INTERSECTED:
                    break
                    
            if istat.dist >= NOT_INTERSECTED:
                continue
                
            col = mulColor(rgb, istat.obj)
            rgb = col * (1.0 / sqrt(bounces))
            
            storePhoton(istat.obj, pnt, ray, rgb)
            drawPhoton(rgb, pnt)
            shadowPhoton(ray, pnt)
            
            ray = reflect(istat.obj, pnt, ray, from_pos)
            istat = raytrace(ray, pnt)
            
            if istat.dist >= NOT_INTERSECTED:
                break
                
            from_pos = pnt
            bounces += 1
            
    return numPhotons, num_vol
```

**Edge Cases and Pitfalls:**
*   **Invalid Start Positions:** Photons starting outside the room boundaries or inside objects are marked invalid and skipped [S1, unofficial].
*   **Precision Issues:** Small offsets (0.0001) are added to start positions to avoid self-intersection [S1, unofficial].
*   **Infinite Loops:** The `while` loop for generating valid start positions may not terminate if the light source is completely enclosed [G].
*   **Reflection Limit:** Exceeding `reflection_limit` stops further optical interactions for a bounce [S1, unofficial].

## Subtopics

### [Photon Mapping for Participating Media](5547-photon-mapping-for-participating-media.md)
Extends surface-based photon mapping to handle light transport within volumetric media by decoupling light transport simulation from final image synthesis. It is distinguished by specific handling of volumetric scattering events and a distinct radiance estimate formula for volume photons.

## Operating characteristics
*   **Time Complexity:** Linear with respect to the number of photons emitted and the number of bounces per photon [S1, unofficial].
*   **Memory Complexity:** Linear with respect to the number of photons stored [S1, unofficial].
*   **Measured Performance:** Not given in the sources [S1, unofficial].
*   **Strengths:** Pre-computes indirect lighting, allowing for efficient final image synthesis [S1, unofficial].
*   **Limitations:** High memory usage for large scenes, potential for noise if photon density is low [G].
*   **When to Use:** Scenes with complex indirect lighting effects like caustics and subsurface scattering [S1, unofficial].
*   **When Not to Use:** Real-time applications due to high computational cost [G].

## Background
Photon Emission and Storage is part of the Volumetric Photon Mapping algorithm, which extends the surface-based photon mapping technique to participating media [S1, unofficial]. It was developed to accurately render complex lighting effects in non-homogeneous participating media [S1, unofficial]. The method was introduced in the context of global illumination techniques that store photon energy in spatial data structures [S1, unofficial].
