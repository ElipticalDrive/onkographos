# Adaptive Beam Width

Also called: Adaptive Beam Blur, Photon Beam Rendering with Adaptive Width, Photon Beams, Varying Kernel Beam Estimate, beam tracing for participating media, photon point beams

## Overview
Adaptive Beam Width is a technique for estimating radiance in participating media that uses photon differentials to dynamically adjust the smoothing kernel width of photon beams [S1]. It solves the problem of over-blurring and banding artifacts inherent in fixed-width beam estimates, particularly in regions with sharp lighting features like volume caustics [S1]. Unlike fixed-width methods, it allows for small beam widths in focused regions and larger widths in sparse regions, enabling crisp reconstruction of sharp details with significantly fewer photons [S1].

## How it works
**Inputs and Outputs:**
*   **Input:** Photon beams (generated by the photon tracing stage), including photon differentials (Jacobian matrices of the photon path) at each beam's start point.
*   **Output:** Radiance estimate at a query point or along a camera ray.

**Data Structures:**
*   **Photon Beam:** Extends the standard photon point representation. For heterogeneous media, it stores a 1D transmittance function along the beam's length, analogous to deep shadow maps [S1]. This function can be compressed for efficient storage [S1].
*   **Photon Differentials:** Stored at the start of each beam. These represent the local mapping from the light source parameter space to the beam's spatial position, allowing the calculation of the beam's local cross-section and width [S1].

**Parameters:**
*   **Beam Width:** Determined adaptively by the photon differentials. No fixed scalar width is used [S1].

**Steps:**
1.  **Photon Tracing:** Trace photons through the scene. Store the resulting beams. For each beam, compute and store the photon differentials at the start point [S1].
2.  **Heterogeneous Transmittance (Optional):** If the medium is heterogeneous, compute and store a 1D transmittance function along each beam during the tracing stage. This allows for accurate visibility calculations during rendering without ray marching [S1].
3.  **Radiance Estimation (Beam x Beam Query):** For a query point $x$ (or along a camera ray), identify all photon beams that contribute to the estimate.
4.  **Adaptive Width Calculation:** For each contributing beam, calculate its effective width using the photon differentials. The differentials define the local density and spread of the photon flux [S1].
5.  **Cross-Section Calculation:** For secondary scattering events, compute the cross-section at the start of the child beam using the photon differentials' footprint. This induces a conical frustum shape for the beam [S1].
6.  **Kernel Evaluation:** Use the adaptive width to define the smoothing kernel. The kernel width is small in focused regions (high density) and large in sparse regions [S1].
7.  **Aggregation:** Sum the contributions of all contributing beams, weighted by their respective kernels and the stored transmittance (if applicable) [S1].

**Edge Cases and Pitfalls:**
*   **Division by Zero:** Fixed-width beams or beams with zero cross-section at the start can lead to division by zero. Using photon differentials to induce a conical frustum shape with a non-zero starting cross-section avoids this [S1].
*   **Banding Artifacts:** Fixed-width beams result in over-blurring and banding artifacts, especially in focused regions of volume caustics. Adaptive widths mitigate this [S1].
*   **Multiple Scattering:** While adaptive widths work well for single scattering and caustics, they were not as successful for multiple scattering in the reported implementation [S1].
*   **Heterogeneous Media:** Handling heterogeneous transmittance along photon beams is more costly than homogeneous media. It requires storing and querying 1D transmittance functions [S1].

## Operating characteristics
*   **Time Complexity:** The current implementation uses a BVH over all beams to accelerate Beam x Beam queries. While it performs reasonably well, there is room for improvement via tailored data structures [S1].
*   **Memory Complexity:** Storing photon beams with 1D transmittance functions for heterogeneous media increases memory usage compared to simple photon points. However, these functions can be significantly compressed [S1].
*   **Measured Performance:** In a volume caustic scene, photon beams converged to a crisp solution using 32k beams in 43 seconds. In contrast, 512k photons took almost twice the time and resulted in an over-blurred and noisy caustic [S1]. In the bumpy sphere scene, 90k photon beams reconstructed sharp features in about 100 seconds, whereas the same number of photon points suffered from over-blurring [S1].
*   **Strengths:**
    *   Reduces bias (blur) and variance significantly compared to photon points [S1].
    *   Eliminates the need for shadow rays by reusing visibility information from the photon tracing stage [S1].
    *   Avoids singularities associated with VPL methods by using finite cross-sections [S1].
    *   Can render extremely sharp details (e.g., volume caustics) with tens of thousands of beams, whereas previous methods required millions or billions of photons [S1].
*   **Limitations:**
    *   Adaptive widths were not as successful for multiple scattering [S1].
    *   Current BVH acceleration structure may not be optimal; tailored data structures are needed for better performance [S1].
    *   Handling heterogeneous media adds computational and memory overhead [S1].
*   **When to Use:** Use when rendering scenes with sharp lighting features like volume caustics, especially with area lights or multiple bounces, and when computational resources are limited compared to the requirements of photon point methods.
*   **When Not to Use:** Avoid for multiple scattering if the adaptive width implementation does not perform well, or if heterogeneous media handling is too costly for the application.

## Background
*   **Origin:** Introduced by [S1] as part of a comprehensive theory of volumetric radiance estimation using photon points and beams.
*   **History:** The method generalizes photon points to beams, allowing for area light sources and multiple bounces. It builds on the concept of photon mapping and beam tracing.
*   **Usage:** Used in volumetric photon mapping for rendering participating media, particularly for efficient estimation of in-scattered radiance.
