# Volumetric Photon Mapping with Radiance Transfer

Also called: Volumetric Photon Mapping integrated with Radiance Transfer

## Overview
Volumetric Photon Mapping with Radiance Transfer is a real-time rendering technique for participating media that combines the global illumination capabilities of volumetric photon mapping with the performance benefits of precomputed radiance transfer. It solves the problem of efficiently rendering complex light transport in volumes, such as medical ultrasound data, by separating direct and indirect lighting calculations. Unlike standard volumetric photon mapping which may be computationally expensive for real-time applications, this method incorporates the photon map into a pre-designed radiance transfer procedure to achieve interactive frame rates while maintaining realistic lighting effects [S1].

## How it works
The method operates in two main phases: photon map construction and radiance transfer-based rendering.

**Inputs:**
- 3D volume data (e.g., fetal ultrasound data).
- Transfer function defining opacity and color.
- Light source positions and intensities.
- Camera parameters.

**Outputs:**
- Rendered image with direct and indirect illumination.

**Data Structures:**
- **Photon Map:** Stores photon interactions within the volume. As noted by Daniel et al., a specific data format is used to assess scene areas affected by altering the transfer function, allowing for effective updates [S1].
- **Radiance Transfer Data:** Precomputed coefficients or basis functions that describe how light transfers through the volume.

**Steps:**
1. **Photon Emission and Storage:** Rays are cast from light sources into the volume. Photons are stored upon interaction, building the volumetric photon map. The data structure supports efficient querying and updating based on transfer function changes [S1].
2. **Direct Illumination Calculation:** A raycaster computes direct lighting for each voxel or sample point along the view ray.
3. **Indirect Illumination Calculation:** Indirect lighting is computed using the photon map. The photon map provides estimates of the radiance arriving at a point from indirect bounces.
4. **Radiance Transfer Integration:** The indirect illumination estimates from the photon map are integrated into the pre-designed radiance transfer procedure. This step allows the method to leverage precomputed lighting information for faster evaluation [S1].
5. **Compositing:** Direct and indirect lighting results are combined to produce the final pixel color.

**Formulas:**
The specific mathematical formulation for the radiance transfer integration is not detailed in the provided sources. The method relies on the "customary predesigned radiance transfer procedure" [S1]. The indirect radiance $L_i$ at a point is estimated from the photon map, likely using a density estimation technique (e.g., kernel density estimation), but the exact kernel and bandwidth parameters are not specified in the notes.

**Parameters:**
- Transfer function parameters: Control the mapping of volume data to optical properties.
- Photon map density: Affects the accuracy of indirect lighting estimates.
- Ray marching step size: Balances performance and visual fidelity.

**Edge Cases and Pitfalls:**
- **Transfer Function Changes:** The method is designed to allow effective updates to the photon map when the transfer function is altered, suggesting that standard photon mapping might struggle with dynamic transfer functions without this specific data format [S1].
- **Wide Range of Intensities:** The method addresses the wide range of intensities resulting from varying light conditions, implying that normalization or tone mapping may be necessary [S1].

## Subtopics
## Operating characteristics
- **Performance:** The method is designed for real-time volume rendering, aiming for an "interactive character" [S1].
- **Accuracy:** By incorporating volumetric photon mapping, it captures global illumination effects (indirect lighting) that simpler methods like pure radiance transfer might miss.
- **Flexibility:** The data format allows for updates to the photon map in response to transfer function changes, offering flexibility in visualization [S1].
- **Limitations:** The complexity of maintaining and querying the photon map in 3D volumes can still be significant, although the integration with radiance transfer mitigates this for real-time performance.

## Background
The method was proposed by Zhang et al. in the context of real-time volume rendering for three-dimensional fetal ultrasound [S1]. It builds upon the volumetric photon mapping algorithm and integrates it with existing radiance transfer techniques. The work references Daniel et al. for the data format used to assess scene areas affected by transfer function changes [S1].
