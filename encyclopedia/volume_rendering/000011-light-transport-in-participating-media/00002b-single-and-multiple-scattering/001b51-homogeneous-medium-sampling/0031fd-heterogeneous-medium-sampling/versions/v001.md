# Heterogeneous Medium Sampling


## Overview
Heterogeneous Medium Sampling determines the distance to the next interaction in a participating medium where optical properties vary spatially, such as in a `GridDensityMedium` [S1]. It generalizes homogeneous sampling by integrating the spatially varying extinction coefficient $\sigma_t$ along the ray to compute transmittance and sample an interaction distance [S1]. Unlike regular tracking, which applies homogeneous techniques voxel-by-voxel and is costly with many voxels, this method handles continuous spatial variation and linear interpolation directly [S1].

## How it works
**Inputs and Outputs:**
- Input: Ray origin $o$, direction $d$, medium density grid (providing $\sigma_t(x)$), random number $u \in [0, 1]$.
- Output: Interaction distance $t$ and transmittance $T(o, o+td)$.

**Data Structures:**
- The medium is represented by a density grid where each voxel stores extinction coefficients. Linear interpolation is used to evaluate $\sigma_t(x)$ at arbitrary points [S1].

**Steps:**
1. **Define the PDF:** The probability density function for the interaction distance $t$ is defined as [S1]:
   $$ p_t(t) = \sigma_t(t) e^{-\int_0^t \sigma_t(t') dt'} $$
   where $\sigma_t(t)$ is the extinction coefficient at distance $t$ along the ray [S1].

2. **Invert the CDF:** To sample $t$ given $u$, we solve for $t$ in the cumulative distribution function (CDF):
   $$ u = \int_0^t p_t(t') dt' = 1 - e^{-\int_0^t \sigma_t(t') dt'} $$
   Rearranging gives:
   $$ \int_0^t \sigma_t(t') dt' = -\ln(1 - u) $$
   Let $\tau(t) = \int_0^t \sigma_t(t') dt'$ be the optical depth. We need to find $t$ such that $\tau(t) = -\ln(1 - u)$ [S1].

3. **Numerical Integration:** Since $\sigma_t(t)$ varies spatially, the integral $\tau(t)$ must be computed numerically. The ray is traversed through the density grid. For each segment of the ray within a voxel, $\sigma_t(t')$ is interpolated. The optical depth is accumulated until the target optical depth $\tau_{target} = -\ln(1 - u)$ is reached [S1].

4. **Transmittance Calculation:** The transmittance from the ray origin to the interaction point is:
   $$ T(o, o+td) = e^{-\tau(t)} = 1 - u $$
   If no interaction occurs within the medium bounds, the transmittance is computed over the full path through the medium [S1].

**Pseudocode:**
```python
def sample_heterogeneous_medium(ray, medium, u):
    # Target optical depth
    tau_target = -math.log(1.0 - u)
    
    # Current optical depth
    tau_current = 0.0
    
    # Traverse ray through medium
    t_enter, t_exit = ray.intersect_medium(medium)
    if t_enter is None:
        return None, 1.0
        
    t = t_enter
    while t < t_exit:
        # Get position and direction
        pos = ray.origin + ray.direction * t
        # Interpolate sigma_t at pos from grid
        sigma_t = medium.get_sigma_t(pos)
        
        # Step size to next voxel boundary or until tau_target is reached
        dt = medium.step_size(pos, ray.direction)
        
        # Approximate integral over this segment
        # Using midpoint or trapezoidal rule for better accuracy with linear interpolation
        sigma_t_next = medium.get_sigma_t(pos + ray.direction * dt)
        sigma_t_avg = (sigma_t + sigma_t_next) / 2.0
        
        tau_segment = sigma_t_avg * dt
        tau_current += tau_segment
        
        if tau_current >= tau_target:
            # Interaction occurs in this segment
            # Refine t using bisection or linear approximation
            # Linear approximation:
            t += (tau_target - (tau_current - tau_segment)) / sigma_t_avg
            break
            
        t += dt
        
    if t >= t_exit:
        return None, math.exp(-tau_current)
        
    transmittance = math.exp(-tau_current)
    return t, transmittance
```

**Parameters:**
- `u`: Uniform random number in $[0, 1]$ [S1].

**Edge Cases:**
- If the ray does not intersect the medium, return no interaction [S1].
- Precision issues may arise if $\sigma_t$ is very small or very large; adaptive step sizes may be needed [G].

## Subtopics

### Heterogeneous Medium Sampling with Majorant
A technique for heterogeneous media using a density grid where a precomputed majorant $\sigma_M \ge \sigma_t(x)$ is used for null collision Monte Carlo sampling [S2, unofficial]. This avoids the need for numerical integration of the optical depth by sampling from the majorant and rejecting null collisions [S2, unofficial].

## Operating characteristics
- **Time Complexity:** Depends on the number of voxels intersected and the cost of numerical integration. For dense grids, it can be costly compared to homogeneous sampling [S1].
- **Memory Complexity:** Requires storage of the density grid [S1].
- **Strengths:** Handles continuous spatial variation and linear interpolation, which regular tracking cannot [S1].
- **Limitations:** Numerical integration can be slow and inaccurate if not handled carefully [S1].

## Background
Regular tracking was previously used for piecewise constant media but is inefficient for many voxels [S1]. The heterogeneous sampling method generalizes the homogeneous PDF to spatially varying $\sigma_t$ [S1].
