# Heterogeneous Medium Sampling
## Overview
Heterogeneous Medium Sampling determines the distance to the next interaction in a participating medium where optical properties vary spatially, such as in a `GridDensityMedium` [S1]. It generalizes the homogeneous sampling PDF to account for a spatially varying attenuation coefficient $\sigma_t$ [S1]. Unlike regular tracking, which applies homogeneous techniques voxel-by-voxel and becomes costly with many voxels or incompatible with linear interpolation, this method handles continuous spatial variation directly [S1].
## How it works
**Inputs and Outputs:**
- Input: Ray origin $o$, direction $d$, medium density grid providing $\sigma_t(x)$, random number $u \in [0, 1]$.
- Output: Interaction distance $t$ along the ray and transmittance $T(o, o+td)$.

**Data Structures:**
- The medium is represented by a density grid where $\sigma_t(x)$ is evaluated at arbitrary points using linear interpolation [S1].

**Steps:**
1. **Define the PDF:** The probability density function for the interaction distance $t$ generalizes the homogeneous case to spatially varying attenuation [S1]:
   $$ p_t(t) = \sigma_t(t) e^{-\int_0^t \sigma_t(t') dt'} $$
   where $\sigma_t(t)$ is the extinction coefficient at distance $t$ along the ray [S1].

2. **Invert the CDF:** To sample $t$ given $u$, we solve for $t$ in the cumulative distribution function:
   $$ u = \int_0^t p_t(t') dt' = 1 - e^{-\int_0^t \sigma_t(t') dt'} $$
   Rearranging gives the target optical depth condition:
   $$ \tau(t) = \int_0^t \sigma_t(t') dt' = -\ln(1 - u) $$
   where $\tau(t)$ is the optical depth [G].

3. **Numerical Integration:** Since $\sigma_t(t)$ varies spatially, the integral $\tau(t)$ must be computed numerically by traversing the ray through the density grid [G]. For each segment along the ray, $\sigma_t(t')$ is interpolated from the grid, and the optical depth is accumulated until $\tau(t)$ reaches the target value [G].

4. **Transmittance Calculation:** The transmittance from the ray origin to the interaction point is:
   $$ T(o, o+td) = e^{-\tau(t)} = 1 - u $$
   [G].

**Pseudocode:**
```python
def sample_heterogeneous_medium(ray_origin, ray_direction, density_grid, u):
    tau_target = -math.log(1.0 - u)
    tau_current = 0.0
    t = 0.0
    dt = 0.01  # Integration step size [G]
    
    while tau_current < tau_target:
        pos = ray_origin + ray_direction * t
        sigma_t = density_grid.sample(pos)
        
        t += dt
        pos_next = ray_origin + ray_direction * t
        sigma_t_next = density_grid.sample(pos_next)
        
        sigma_t_avg = (sigma_t + sigma_t_next) / 2.0
        tau_current += sigma_t_avg * dt
        
    # Refine t within the last segment using linear approximation [G]
    t -= dt
    pos = ray_origin + ray_direction * t
    sigma_t = density_grid.sample(pos)
    t += (tau_target - tau_current) / sigma_t
    
    transmittance = math.exp(-tau_current)
    return t, transmittance
```

**Parameters:**
- `u`: Uniform random number in $[0, 1]$ [G].

**Edge Cases:**
- If the ray does not intersect the medium bounds, return no interaction [G].
- Precision issues may arise if $\sigma_t$ is very small or very large; adaptive step sizes or root-finding refinement may be needed [G].

## Subtopics

### Heterogeneous Medium Sampling with Majorant
A technique for heterogeneous media using a density grid where a precomputed majorant $\sigma_M \ge \sigma_t(x)$ is used for null collision Monte Carlo sampling [S2, unofficial]. This avoids the need for numerical integration of the optical depth by sampling from the majorant and rejecting null collisions [S2, unofficial].

## Operating characteristics
- **Time Complexity:** Computational cost depends on the number of grid cells intersected and the cost of numerical integration. Handling continuous spatial variation with linear interpolation is more expensive than piecewise constant voxel tracking [S1].
- **Memory Complexity:** Requires storage of the spatial density grid [G].
- **Strengths:** Handles continuous spatial variation and linear interpolation directly, avoiding the overhead of regular tracking across many voxels [S1].
- **Limitations:** Numerical integration along the ray can be slow if the grid resolution is high or $\sigma_t$ varies rapidly [G].

## Background
The method generalizes the homogeneous medium sampling PDF to spatially varying attenuation coefficients for media like `GridDensityMedium` [S1]. Regular tracking, which applies homogeneous techniques to individual voxels, was previously used but becomes costly with many voxels and cannot utilize linear interpolation [S1].
