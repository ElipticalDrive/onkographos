# Unidirectional transmittance-based path sampling

Also called: Light Tracing

## Overview
Unidirectional transmittance-based path sampling constructs light transport paths by incrementally adding vertices from a single endpoint until a light source or sensor is hit, sampling propagation distances proportional to the medium's transmittance [S1]. It is a stochastic method solving the transport equation by random sampling along interaction points [S2].

## How it works
**Inputs:**
- Current vertex position $\mathbf{c}$ in the medium [S1].
- Incident direction $\omega_{dc}$ at $\mathbf{c}$ [S1].
- Phase function $\rho(\omega_{cb} | \omega_{dc}, \mathbf{c})$ [S1].
- Total extinction coefficient $\kappa_t$ [S2].
- Scene geometry for boundary intersection [G].

**Outputs:**
- Next vertex position $\mathbf{b}$ [S1].
- New direction $\omega_{cb}$ [S1].
- PDF value $p(\mathbf{b}, \omega_{cb} | \mathbf{c}, \omega_{dc})$ [S1].

**Data Structures:**
- $\kappa_t$: Scalar field representing extinction [S2].
- $\rho$: Function mapping directions to scattering probability density [S1].

**Steps:**
1. **Sample Direction:** Sample the outgoing direction $\omega_{cb}$ proportionally to the phase function at $\mathbf{c}$, i.e., $p(\omega_{cb} | \omega_{dc}, \mathbf{c}) \propto \rho(\omega_{cb} | \omega_{dc}, \mathbf{c})$ [S1].
2. **Sample Distance:** Sample the propagation distance $t_{cb}$ along $\omega_{cb}$ proportionally to transmittance with PDF $p(t_{cb} | \mathbf{c}, \omega_{cb})$ [S1].
3. **Compare Distances:** Cast a ray from $\mathbf{c}$ in direction $\omega_{cb}$ to find the nearest geometry intersection at distance $t_{geom}$ [G].
   - If $t_{cb} < t_{geom}$: The next vertex $\mathbf{b}$ is at $\mathbf{c} + t_{cb}\omega_{cb}$, and a medium scattering event occurs [S1].
   - If $t_{cb} \ge t_{geom}$: The ray hits the geometry first, and surface scattering occurs at the intersection point [S1].

**Pseudocode:**
```python
def sample_next_vertex(c, omega_in, kappa_t, phase_func, scene):
    # 1. Sample direction from phase function
    # Standard implementation: sample uniform direction and apply phase function weighting [G]
    omega_out = sample_direction_from_phase(omega_in, phase_func)
    
    # 2. Sample scattering distance proportional to transmittance
    # For homogeneous media: t_scat = -log(u) / kappa_t, where u ~ U[0,1] [G]
    u = random.uniform(0.0, 1.0)
    t_scat = -math.log(u) / kappa_t
    
    # 3. Find geometry intersection
    t_geom = find_nearest_geometry(c, omega_out)
    
    # 4. Determine outcome
    if t_scat < t_geom:
        b = c + t_scat * omega_out
        return b, omega_out, t_scat, "medium"
    else:
        return c + t_geom * omega_out, omega_out, t_geom, "surface"

def sample_direction_from_phase(omega_in, phase_func):
    # Standard spherical sampling weighted by phase function [G]
    theta = math.acos(1.0 - 2.0 * random.uniform(0.0, 1.0))
    phi = 2.0 * math.pi * random.uniform(0.0, 1.0)
    return spherical_to_cartesian(theta, phi)

def find_nearest_geometry(origin, direction):
    # Standard ray-scene intersection routine [G]
    return scene.ray_intersect(origin, direction)
```

## Operating characteristics
- **Complexity:** Depends on the cost of evaluating $\kappa_t$ and the phase function; each step requires a ray intersection test [S1, S2].
- **Strengths:** Categorised alongside bidirectional path tracing and photon maps as methods that sample interaction points using a function of $\kappa_t$ [S2].
- **Limitations:** Performance scales with scene density and the cost of geometry intersection queries [S1, S2].
- **When to use:** Light tracing scenarios where paths are built from a single endpoint and interaction points are sampled via $\kappa_t$ [S2].

## Background
Originated from the concept of light tracing, where paths are built from the light source rather than the eye [S1, S2]. It is a stochastic method for solving the radiative transport equation by random sampling along interaction points [S2]. It is categorised alongside bidirectional path tracing and photon maps as methods that sample interaction points using a function of $\kappa_t$ [S2].
