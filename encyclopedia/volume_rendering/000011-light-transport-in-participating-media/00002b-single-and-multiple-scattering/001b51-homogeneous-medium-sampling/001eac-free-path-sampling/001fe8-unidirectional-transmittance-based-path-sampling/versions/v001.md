# Unidirectional transmittance-based path sampling

Also called: Light Tracing

## Overview
Unidirectional transmittance-based path sampling constructs light transport paths by incrementally adding vertices from a single endpoint (typically the light source) until a sensor or light source is hit, sampling propagation distances proportional to the medium's transmittance [S1]. It differs from eye-based path tracing by decoupling path construction from the camera view, allowing it to naturally sample light sources without explicit visibility tests for the first few bounces [S1].

## How it works
**Inputs:**
- Current vertex position $\mathbf{x}$ in the medium.
- Incident direction $\omega_{in}$ at $\mathbf{x}$.
- Total extinction coefficient function $\kappa_t(\mathbf{x})$.
- Phase function $\rho(\omega_{out} | \omega_{in}, \mathbf{x})$.
- Scene geometry for boundary intersection.

**Outputs:**
- Next vertex position $\mathbf{x}'$.
- New direction $\omega_{out}$.
- PDF value $p(\mathbf{x}', \omega_{out} | \mathbf{x}, \omega_{in})$.

**Data Structures:**
- $\kappa_t$: Scalar field representing extinction.
- $\rho$: Function mapping directions to scattering probability density.

**Steps:**
1. **Sample Direction:** Sample the outgoing direction $\omega_{out}$ from the phase function $\rho(\omega_{out} | \omega_{in}, \mathbf{x})$. The PDF is $p(\omega_{out} | \omega_{in}, \mathbf{x}) = \frac{\rho(\omega_{out} | \omega_{in}, \mathbf{x})}{\int_{S^2} \rho(\omega' | \omega_{in}, \mathbf{x}) d\omega'}$ [S1].
2. **Ray Cast:** Cast a ray from $\mathbf{x}$ in direction $\omega_{out}$ to find the nearest intersection with the scene geometry. Let the distance to this intersection be $t_{geom}$.
3. **Sample Distance:** Sample the propagation distance $t_{scat}$ through the medium using the transmittance-based PDF. The PDF for the distance is $p(t_{scat} | \mathbf{x}, \omega_{out}) = \frac{\kappa_t(\mathbf{x} + t_{scat}\omega_{out}) T(\mathbf{x}, \mathbf{x} + t_{scat}\omega_{out})}{\int_0^{t_{max}} \kappa_t(\mathbf{x} + t\omega_{out}) T(\mathbf{x}, \mathbf{x} + t\omega_{out}) dt}$, where $T(\mathbf{x}_1, \mathbf{x}_2) = \exp\left(-\int_0^{\|\mathbf{x}_2-\mathbf{x}_1\|} \kappa_t(\mathbf{x}_1 + t\frac{\mathbf{x}_2-\mathbf{x}_1}{\|\mathbf{x}_2-\mathbf{x}_1\|}) dt\right)$ is the transmittance [S1].
4. **Compare Distances:**
   - If $t_{scat} < t_{geom}$: The next vertex $\mathbf{x}'$ is at $\mathbf{x} + t_{scat}\omega_{out}$. A scattering event occurs.
   - If $t_{scat} \ge t_{geom}$: The ray hits the geometry first. The next vertex is the intersection point. Surface scattering occurs [S1].

## Operating characteristics
- **Complexity:** Depends on the cost of sampling $\kappa_t$ and phase function. Each step requires a ray intersection test.
- **Strengths:** Naturally handles light source visibility; efficient for scenes with many light sources or complex lighting [S1].
- **Limitations:** Can be inefficient if the light source is small or occluded, as many rays may miss it. Requires careful handling of boundary conditions [S1].
- **When to use:** Light tracing scenarios, especially with multiple light sources or when eye-based path tracing suffers from high variance due to difficult light visibility.

## Background
Originated from the concept of light tracing, where paths are built from the light source rather than the eye [S1, S2]. It is a stochastic method for solving the radiative transport equation by random sampling along interaction points [S2]. It is categorized alongside bidirectional path tracing and photon maps as methods that sample interaction points using a function of $\kappa_t$ [S2].
