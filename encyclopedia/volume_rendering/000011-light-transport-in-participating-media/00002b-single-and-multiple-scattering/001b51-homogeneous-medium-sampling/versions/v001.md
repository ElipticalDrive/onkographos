# Homogeneous Medium Sampling

Also called: Constant-density participating media, Homogeneous Volume Tracking, Tracking in Homogeneous Volumes

## Overview
Homogeneous Medium Sampling is a technique for determining the distance to the first interaction (scattering or absorption) of a ray traveling through a participating medium with uniform optical properties [S1, S3, S4, unofficial]. It solves the problem of efficiently simulating light transport in volumes like fog, smoke, or haze by probabilistically selecting interaction points based on Beer's law, rather than discretizing the volume into a grid [S3, S6, unofficial]. Unlike [Delta tracking](985-delta-tracking.md), which handles heterogeneous media by bounding the extinction coefficient with a majorant, this method uses the exact extinction coefficient to sample the free path length directly, making it optimal for constant-density scenarios [S1, S3, unofficial]. It serves as the foundational sampling step for [Volumetric Path Tracing](1863-volumetric-path-tracing.md) and [Free-path sampling](1844-free-path-sampling.md) [S1, S3, unofficial].

## How it works
**Inputs and Outputs:**
*   **Input:** A ray $r$ defined by origin $o$, direction $\omega$ (normalized), and maximum distance $t_{max}$; the medium's absorption coefficient $\sigma_a$ and scattering coefficient $\sigma_s$ (which may vary by wavelength); a random number generator or sampler.
*   **Output:** A boolean indicating if a medium interaction occurred; if true, a `MediumInteraction` structure containing the position, normal, and phase function; a spectral weighting factor (throughput update) for the path tracer.

**Data Structures:**
*   **Medium Properties:** $\sigma_a$ and $\sigma_s$ are typically stored as `Spectrum` objects (e.g., RGB or spectral samples). The total extinction coefficient is $\sigma_t = \sigma_a + \sigma_s$.
*   **MediumInteraction:** Contains position $p$, normal $n$, time $t$, pointer to the medium, and a pointer to the phase function (e.g., Henyey-Greenstein) [S5]. The `IsValid()` method checks if the phase function pointer is non-null [S5].

**Steps:**
1.  **Select Spectral Channel:** If the medium properties are spectral (varying by wavelength), select a channel $i$ uniformly from the available samples (e.g., RGB channels) [S4, unofficial][S5]. Let $n_{samples}$ be the number of spectral samples.
    $$ i = \lfloor u_1 \cdot n_{samples} \rfloor $$
    where $u_1 \sim U[0, 1]$ [S5].
2.  **Sample Free Path Length:** Generate a uniform random number $u_2 \sim U[0, 1]$ [S1, S3, unofficial]. Compute the distance $d$ to the interaction using the inverse cumulative distribution function (CDF) of the exponential distribution derived from Beer's law [S2][S3, unofficial]:
    $$ d = -\frac{\ln(1 - u_2)}{\sigma_t[i]} $$
    where $\sigma_t[i]$ is the extinction coefficient for the selected channel [S4, unofficial][S5].
3.  **Convert to Ray Parameter:** Convert the physical distance $d$ to the ray parameter $t$:
    $$ t = \min(d, t_{max}) $$
    Note: Some implementations compute $t$ as $d / \|\omega\|$ if the ray direction is not normalized, but standard path tracers use normalized directions, so $t=d$ clipped to $t_{max}$ [S4, unofficial][S5].
4.  **Determine Interaction Type:** Compare $t$ with $t_{max}$ (the distance to the nearest surface intersection or medium boundary) [S2, S5].
    *   If $t < t_{max}$: A medium interaction occurs at $p = o + t\omega$. Initialize the `MediumInteraction` with the position, normal $-\omega$, and the medium's phase function [S5].
    *   If $t \ge t_{max}$: The ray exits the medium or hits a surface before interacting. No medium interaction is recorded; the surface interaction is used instead [S2, S5].
5.  **Compute Weighting Factor:** Calculate the transmittance $T_r$ from the ray origin to the interaction point (or $t_{max}$ if no medium interaction) [S5]:
    $$ T_r = e^{-\sigma_t \cdot t} $$
    Compute the sampling density $p(t)$ [S1, unofficial][S5]:
    *   If medium interaction: $p(t) = \sigma_t[i] e^{-\sigma_t[i] t}$ [S1, S3, unofficial].
    *   If surface interaction: The probability mass is the complement, effectively $e^{-\sigma_t[i] t_{max}}$ [S5].
    
    The returned weighting factor $\beta$ updates the path throughput [S5]:
    *   If medium interaction: $\beta = \frac{T_r \cdot \sigma_s[i]}{p(t)}$ [S5].
    *   If surface interaction: $\beta = \frac{T_r}{p(t)}$ [S5].
    
    For spectral media, the PDF is averaged over all channels:
    $$ p_{avg}(t) = \frac{1}{n_{samples}} \sum_{j=0}^{n_{samples}-1} p_j(t) $$
    where $p_j(t)$ is the density for channel $j$ [S5].

**Pseudocode:**
```python
def sample_homogeneous_medium(ray, sampler, sigma_a, sigma_s, g):
    """
    ray: Ray object with origin, direction (normalized), and tMax
    sampler: Object with Get1D() method returning U[0,1]
    sigma_a, sigma_s: Spectrum objects (e.g., length 3 for RGB)
    g: Henyey-Greenstein asymmetry parameter
    Returns: (is_medium_interaction, medium_interaction_or_none, throughput_weight)
    """
    n_samples = len(sigma_a)  # e.g., 3 for RGB
    channel = min(int(sampler.Get1D() * n_samples), n_samples - 1)
    
    # Sample distance using inverse CDF of exponential distribution
    u = sampler.Get1D()
    sigma_t_channel = sigma_a[channel] + sigma_s[channel]
    dist = -log(1 - u) / sigma_t_channel
    
    # Convert to ray parameter t, clipped to ray max distance
    t = min(dist, ray.tMax)
    
    # Determine if interaction is in the medium
    is_medium = t < ray.tMax
    
    medium_interaction = None
    if is_medium:
        # Initialize MediumInteraction
        # Position: ray.o + t * ray.d
        # Normal: -ray.d
        # Phase function: Henyey-Greenstein with parameter g
        medium_interaction = MediumInteraction(
            position=ray.o + t * ray.d,
            normal=-ray.d,
            time=ray.time,
            medium=self,
            phase_function=HenyeyGreenstein(g)
        )
    
    # Compute transmittance to the interaction point or tMax
    # Use min(t, MaxFloat) to avoid overflow in exp
    t_clamped = min(t, MaxFloat)
    transmittance = exp(-sigma_t * t_clamped * ray.d.Length())
    
    # Compute sampling density
    # If medium interaction, density is sigma_t * exp(-sigma_t * t)
    # If surface interaction, density is exp(-sigma_t * t_max)
    # Note: sigma_t and transmittance are Spectra, so we compute per channel
    
    density = Spectrum()
    for i in range(n_samples):
        sigma_t_i = sigma_a[i] + sigma_s[i]
        t_clamped_i = min(t, MaxFloat)
        tr_i = exp(-sigma_t_i * t_clamped_i * ray.d.Length())
        if is_medium:
            density[i] = sigma_t_i * tr_i
        else:
            density[i] = tr_i
            
    # Average PDF over spectral channels
    pdf = sum(density) / n_samples
    
    # Compute throughput weight
    if is_medium:
        # Weight for medium scattering: (Transmittance * sigma_s) / PDF
        weight = Spectrum()
        for i in range(n_samples):
            sigma_t_i = sigma_a[i] + sigma_s[i]
            sigma_s_i = sigma_s[i]
            t_clamped_i = min(t, MaxFloat)
            tr_i = exp(-sigma_t_i * t_clamped_i * ray.d.Length())
            # Density for this channel
            dens_i = sigma_t_i * tr_i
            weight[i] = (tr_i * sigma_s_i) / dens_i
        # Simplify: tr_i * sigma_s_i / (sigma_t_i * tr_i) = sigma_s_i / sigma_t_i
        # But we must use the averaged PDF for the final weight?
        # According to [S5], the returned weight is Tr * sigma_s / pdf
        # where pdf is the averaged PDF.
        # Let's follow [S5] exactly:
        weight = transmittance * sigma_s / pdf
    else:
        # Weight for surface interaction: Transmittance / PDF
        weight = transmittance / pdf
        
    return is_medium, medium_interaction, weight
```

**Parameters:**
*   $\sigma_a$: Absorption coefficient. Defines light loss due to absorption [S3, unofficial].
*   $\sigma_s$: Scattering coefficient. Defines light loss due to scattering [S3, unofficial].
*   $g$: Henyey-Greenstein asymmetry parameter. Controls forward ($g>0$) or backward ($g<0$) scattering. $g=0$ is isotropic [S6, unofficial].
*   $t_{max}$: Maximum distance along the ray, typically determined by the nearest surface intersection [S2, S5].

**Edge Cases and Pitfalls:**
*   **$t > t_{max}$:** The sampled interaction distance exceeds the distance to the nearest surface. This must be handled by treating it as a surface interaction, accounting for the surface emission and the probability of no medium interaction $P(t \ge t_{hit}) = e^{-\sigma_t t_{hit}}$ [S2].
*   **Spectral Variation:** If $\sigma_t$ varies by wavelength, sampling a single channel and averaging the PDF is required to maintain unbiasedness [S5].
*   **Normalization:** Ray directions must be normalized before computing distances to ensure correct self-hit offsets and transmittance calculations [S6, unofficial].
*   **Zero Extinction:** If $\sigma_t = 0$, the medium is transparent. The sampling formula involves division by zero. In practice, $\sigma_t > 0$ is required [S4, unofficial].

## Subtopics

### [Free-path sampling](1844-free-path-sampling.md)
A general technique for sampling interaction distances in participating media. Homogeneous medium sampling is the specific case where the extinction coefficient is constant, allowing for an analytical inverse CDF solution.

### [Majorant Iterator Ray Sampling](3075-majorant-iterator-ray-sampling.md)
A method for heterogeneous media that iterates through segments defined by a majorant bound. Homogeneous sampling is preferred for constant-density volumes as it avoids the overhead of segment iteration and majorant bounding.

## Operating characteristics
*   **Time Complexity:** $O(1)$ per ray segment, as it involves a constant number of arithmetic operations and a single random number generation (plus spectral averaging if applicable) [S1, unofficial][S5].
*   **Memory Complexity:** $O(1)$, requiring only storage for the medium's coefficients and the current interaction state [S5].
*   **Performance:** Highly efficient for homogeneous volumes. It is significantly faster than delta tracking for constant-density media because it samples the exact distribution without rejection [S1, S3, unofficial].
*   **Strengths:** Unbiased, exact sampling for constant density; simple implementation; efficient spectral handling [S5].
*   **Limitations:** Only applicable to homogeneous media. Cannot handle spatially varying density without approximation or switching to heterogeneous methods like delta tracking [S1, S3, unofficial].
*   **When to use:** When the participating medium has uniform absorption and scattering coefficients throughout the volume [S3, S6, unofficial].
*   **When not to use:** For heterogeneous media (e.g., clouds with varying density) where delta tracking or grid-based methods are more appropriate [S1, S3, unofficial].

## Background
Homogeneous medium sampling is a fundamental technique in volumetric rendering, rooted in the physics of light transport in participating media described by the radiative transfer equation [S3, unofficial][S5]. The method relies on Beer's law, which describes the exponential decay of light intensity as it travels through a medium [S3, unofficial]. The specific implementation using inverse transform sampling for the exponential distribution is standard in path tracing literature, such as the "Physically Based Rendering" (pbr) book [S5]. It is widely used in rendering engines to simulate effects like fog, smoke, and haze [S6, unofficial]. The integration of spectral variation and the specific handling of surface vs. medium interactions as described in [S5] is a key contribution to modern path tracers.
