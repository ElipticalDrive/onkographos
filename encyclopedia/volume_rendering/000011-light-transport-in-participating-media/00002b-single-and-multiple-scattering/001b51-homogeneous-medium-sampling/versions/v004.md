# Homogeneous Medium Sampling

Also called: Homogeneous Volume Tracking, Tracking in Homogeneous Volumes

## Overview
Homogeneous Medium Sampling determines the distance a ray travels through a participating medium with uniform optical properties before interacting, avoiding explicit distance and spherical integrations by letting the ray randomly bounce within the medium before potentially hitting a surface [S1, unofficial]. It differs from [Delta tracking](985-delta-tracking.md) by directly sampling the interaction distance from the extinction coefficient rather than using a majorant bound, and it serves as the foundational step for [Free-path sampling](1844-free-path-sampling.md).

## How it works
**Inputs and Outputs**
*   **Input:** A ray $r$ defined by origin $\mathbf{o}$, direction $\boldsymbol{\omega}$ (unit vector), and maximum distance $t_{\text{max}}$; the medium's absorption coefficient $\sigma_a$, scattering coefficient $\sigma_s$, and extinction coefficient $\sigma_t = \sigma_a + \sigma_s$; a random number generator or sampler.
*   **Output:** A boolean indicating if a medium interaction occurred, and if so, a `MediumInteraction` structure containing the position $\mathbf{p}$, the sampled distance $t$, the phase function, and a throughput weight (Spectrum) to update the path radiance estimator.

**Data Structures**
*   `MediumInteraction`: Contains fields for position $\mathbf{p}$, direction $\boldsymbol{\omega}$, time $t$, a pointer to the medium, and a pointer to the phase function (e.g., Henyey-Greenstein). An `IsValid()` method returns true if the phase function pointer is non-null [S7].
*   `Spectrum`: A vector of values representing spectral channels (e.g., RGB). In spectral MIS implementations, $\sigma_t$ is stored per channel [S7].

**Steps**
1.  **Select Spectral Channel:** If the medium supports spectral variation, uniformly select a channel index $c$ from the available spectral samples (e.g., $c \in \{0, 1, 2\}$ for RGB) [S7][S4, unofficial].
2.  **Sample Free Path:** Generate a uniform random number $u \in [0, 1)$. Compute the collision-free distance $d$ using the inverse CDF of the exponential distribution for the selected channel's extinction coefficient $\sigma_t[c]$:
    $$ d = -\frac{\ln(1 - u)}{\sigma_t[c]} $$
    [S3][S6, unofficial][S7]. Note: To avoid $\ln(0)$, clamp $u$ to $[0, 1-\epsilon)$ or use $1-u$ where $u$ is strictly less than 1 [S4, unofficial].
3.  **Convert to Ray Parameter:** Convert the physical distance $d$ to the ray parameter $t$:
    $$ t = \min\left( \frac{d}{\|\boldsymbol{\omega}\|}, t_{\text{max}} \right) $$
    Since $\boldsymbol{\omega}$ is typically a unit vector, $\|\boldsymbol{\omega}\| = 1$, so $t = \min(d, t_{\text{max}})$ [S7][S6, unofficial].
4.  **Determine Interaction Type:**
    *   If $t < t_{\text{max}}$ (within a small epsilon tolerance, e.g., `RAY_EPS`), a medium interaction occurs [S4, unofficial].
    *   If $t \ge t_{\text{max}}$, the ray exits the volume without scattering; the interaction is treated as a surface hit at $t_{\text{max}}$ [S3, S7].
5.  **Initialize Interaction (if medium hit):**
    *   Set position $\mathbf{p} = \mathbf{o} + t \boldsymbol{\omega}$.
    *   Initialize the phase function (e.g., Henyey-Greenstein with asymmetry parameter $g$) [S7][S8, unofficial].
    *   Compute the transmittance from the ray origin to $\mathbf{p}$:
        $$ T_r = e^{-\sigma_t t} $$
        [S3, S7].
    *   Compute the probability density function (PDF) for the sampled distance. For a single channel, $p(t) = \sigma_t e^{-\sigma_t t}$. For spectral sampling with uniform channel selection probability $p_c = 1/n$, the combined PDF is the average of the channel densities:
        $$ \hat{p}_t(t) = \frac{1}{n} \sum_{i=1}^{n} \sigma_t^i e^{-\sigma_t^i t} $$
        [S7].
6.  **Compute Throughput Weight:**
    *   If a medium interaction occurred:
        $$ \beta = \frac{T_r \cdot \sigma_s}{\hat{p}_t(t)} $$
        [S7][S4, unofficial]. This weight accounts for the scattering coefficient $\sigma_s$ (probability of scattering vs absorption) and the sampling density.
    *   If the ray exited (surface hit):
        $$ \beta = \frac{T_r}{\hat{p}_t(t_{\text{max}})} $$
        [S7]. Here, the "density" is effectively the transmittance itself, representing the probability of *not* interacting in the medium [S7].
7.  **Return:** Return the boolean flag and the weight. If a medium interaction occurred, the caller must also sample a new direction $\boldsymbol{\omega}'$ using the phase function and the incident direction to continue the path [S5, S6, unofficial].

**Pseudocode**
```python
def sample_homogeneous_medium(ray, sigma_a, sigma_s, sampler, spectrum_channels=3):
    """
    Samples a homogeneous medium for a given ray.
    
    Args:
        ray: Object with .origin, .direction (unit vector), .t_max.
        sigma_a: Absorption coefficient (Spectrum or float).
        sigma_s: Scattering coefficient (Spectrum or float).
        sampler: Object with .get_1d() returning uniform [0, 1).
        spectrum_channels: Number of spectral channels (default 3 for RGB).
        
    Returns:
        (hit_medium, interaction, throughput_weight)
        hit_medium: bool
        interaction: dict or None (contains 'pos', 'phase_func')
        throughput_weight: Spectrum or float
    """
    sigma_t = sigma_a + sigma_s
    
    # 1. Select spectral channel
    # Uniformly select channel index c
    u_channel = sampler.get_1d()
    c = int(u_channel * spectrum_channels)
    c = min(c, spectrum_channels - 1)
    
    # 2. Sample free path distance for selected channel
    u_dist = sampler.get_1d()
    # Avoid log(0) by ensuring u_dist < 1
    u_dist = max(0.0, min(u_dist, 1.0 - 1e-7))
    
    sigma_t_c = sigma_t[c] if isinstance(sigma_t, Spectrum) else sigma_t
    d = -log(1.0 - u_dist) / sigma_t_c
    
    # 3. Convert to ray parameter t
    # Assuming ray.direction is unit vector
    t = min(d, ray.t_max)
    
    # 4. Determine if medium interaction occurred
    hit_medium = t < ray.t_max
    
    # 5. Compute Transmittance
    # Use t for transmittance calculation even if hit_medium is false (use t_max)
    t_calc = t if hit_medium else ray.t_max
    sigma_t_vec = sigma_t if isinstance(sigma_t, Spectrum) else Spectrum([sigma_t, sigma_t, sigma_t])
    
    # Transmittance T_r = exp(-sigma_t * t)
    # Note: sigma_t_vec is used element-wise
    tr = exp(-sigma_t_vec * t_calc)
    
    # 6. Compute PDF
    # PDF is the average of the densities over all spectral channels
    # p_i(t) = sigma_t_i * exp(-sigma_t_i * t)
    # If hit_medium is false, the "density" for the surface term is just the transmittance
    # However, the standard MIS formulation for the surface term uses the transmittance as the weight
    # and the PDF for the surface term is effectively 1 (discrete) or handled via the complement.
    # According to [S7], density = sampledMedium ? (sigma_t * Tr) : Tr
    
    if hit_medium:
        # Density for medium interaction: sigma_t * Tr
        # We need the PDF for the specific channel sampled? 
        # No, the return weight uses the *average* PDF over all channels for MIS.
        # But wait, [S7] computes pdf as the average of densities.
        # Let's compute the average PDF for the sampled t.
        pdf_sum = 0.0
        for i in range(spectrum_channels):
            sigma_t_i = sigma_t_vec[i]
            # Density for channel i at distance t
            # Note: if t > t_max, we don't sample a medium interaction, so this branch isn't taken.
            density_i = sigma_t_i * exp(-sigma_t_i * t_calc)
            pdf_sum += density_i
        pdf = pdf_sum / spectrum_channels
    else:
        # Surface interaction: The "density" is the transmittance itself (probability of no interaction)
        # [S7]: density = Tr
        # The PDF for the discrete surface term is not averaged in the same way, 
        # but the weight formula in [S7] is Tr / pdf.
        # Here pdf is the average of the *medium* densities? 
        # Actually, [S7] code:
        # Spectrum density = sampledMedium ? (sigma_t * Tr) : Tr;
        # Float pdf = 0; for ... pdf += density[i]; pdf *= 1/n;
        # This implies if NOT sampled, density[i] = Tr[i].
        # So pdf = mean(Tr).
        pdf_sum = 0.0
        for i in range(spectrum_channels):
            pdf_sum += tr[i]
        pdf = pdf_sum / spectrum_channels

    # 7. Compute Throughput Weight
    sigma_s_vec = sigma_s if isinstance(sigma_s, Spectrum) else Spectrum([sigma_s, sigma_s, sigma_s])
    
    if hit_medium:
        # Weight = (Tr * sigma_s) / pdf
        # Element-wise division
        weight = (tr * sigma_s_vec) / pdf
    else:
        # Weight = Tr / pdf
        weight = tr / pdf
        
    # 8. Initialize Interaction if hit
    interaction = None
    if hit_medium:
        pos = ray.origin + t * ray.direction
        # Phase function initialization (e.g., Henyey-Greenstein)
        # g is a parameter of the medium
        phase_func = HenyeyGreenstein(g=medium.g) 
        interaction = {
            'pos': pos,
            'phase_func': phase_func,
            'valid': True
        }
        
    return hit_medium, interaction, weight
```

**Parameters**
*   $\sigma_a, \sigma_s$: Absorption and scattering coefficients. Typical values depend on the medium (e.g., fog: low $\sigma_t$; smoke: higher $\sigma_t$) [S5, S8, unofficial].
*   $g$: Henyey-Greenstein asymmetry parameter, range $[-1, 1]$. $0$ is isotropic, $1$ is forward scattering, $-1$ is backward scattering [S8, unofficial].

**Edge Cases and Pitfalls**
*   **Precision:** Ensure $u$ is strictly less than 1 to avoid $\ln(0)$ [S4, unofficial].
*   **Boundary Handling:** If the sampled distance $t$ exceeds the ray's maximum extent ($t_{\text{max}}$), the ray is considered to have hit the surface/boundary. The transmittance to the surface must be used, and the surface emission/BSDF is evaluated [S3, S7].
*   **Spectral Variation:** If $\sigma_t$ varies by wavelength, selecting a single channel for distance sampling introduces bias if not handled by MIS. The PDF must be averaged over all channels to ensure unbiasedness [S7].
*   **Anisotropy:** Highly anisotropic media ($g \approx 1$) require careful phase function sampling to avoid noise, as the scattering is concentrated in a narrow cone [S2].

## Subtopics

### [Free-path sampling](1844-free-path-sampling.md)
Determines the distance to the next interaction in a homogeneous medium by sampling the exponential distribution directly. It is the core mechanism used here, differing from [Majorant Iterator Ray Sampling](3075-majorant-iterator-ray-sampling.md) by not iterating through segment boundaries.

### [Majorant Iterator Ray Sampling](3075-majorant-iterator-ray-sampling.md)
Handles heterogeneous media by iterating through segments defined by a majorant bound. It generalizes homogeneous sampling by managing segment boundaries and transmittance accumulation across varying density regions.

### [Heterogeneous Medium Sampling](6654-heterogeneous-medium-sampling.md)
Generalizes homogeneous sampling to spatially varying extinction coefficients $\sigma_t(\mathbf{x})$ by integrating $\sigma_t$ along the ray. It is more costly than homogeneous sampling but handles continuous variation.

### [Constant Distance Sampling](12250-constant-distance-sampling.md)
Advances light in fixed steps $\delta$, decoupling the interaction distance from the exponential distribution. It simplifies multiple scattering handling but is less efficient for low-density media compared to free-path sampling.

## Operating characteristics
*   **Time Complexity:** $O(1)$ per ray segment. The sampling involves a constant number of random number generations, logarithmic, and exponential operations [S7].
*   **Memory Complexity:** $O(1)$ auxiliary memory. No large data structures are required beyond the ray and medium parameters [S7].
*   **Performance:** Highly efficient for homogeneous volumes. Convergence can be slow for high-order scattering media (many interactions) or highly anisotropic media, requiring many samples or variance reduction techniques like Next Event Estimation (NEE) [S2][S5, unofficial].
*   **Strengths:** Unbiased, simple to implement, exact for homogeneous media.
*   **Limitations:** Inefficient for heterogeneous media (requires integration or majorant tracking). Noisy for highly scattering or anisotropic media without additional techniques.
*   **When to use:** Scenes with uniform fog, smoke, or clouds where the medium properties do not vary spatially.
*   **When not to use:** Scenes with complex, spatially varying density distributions (use [Heterogeneous Medium Sampling](6654-heterogeneous-medium-sampling.md)) or when performance is critical and the medium is sparse (consider [Delta tracking](985-delta-tracking.md) if the majorant is tight, though homogeneous sampling is optimal for truly homogeneous media).

## Background
Homogeneous medium sampling is a fundamental technique in volumetric rendering, derived from the Beer-Lambert law and the theory of radiative transfer [S3][S5, unofficial]. It was formalized in the context of Monte Carlo path tracing for participating media, notably in the work of Lafortune and Willems [S2] and later detailed in standard references like *Physically Based Rendering* (PBRT) [S7]. The method relies on the statistical property that the distance to the next interaction in a homogeneous medium follows an exponential distribution [S5, unofficial].
