# Analytical Single Scattering without Boundaries


## Overview
This method provides an analytical solution for single scattering in participating media without boundaries under a point light source [S1]. It solves the radiative transfer equation exactly for this specific configuration, avoiding the noise inherent in Monte Carlo approaches and the discretization errors of ray marching. It is distinguished from general single-scattering approximations by its closed-form nature, which allows for real-time frame rates, though it is strictly limited to point lights and media without boundary interactions [S1].

## How it works
The method computes the radiance arriving at a point within a homogeneous participating medium due to a single point light source, assuming no boundaries (infinite or unbounded medium) and no multiple scattering.

**Inputs:**
*   $x_t$: The 3D position of the scattering point.
*   $x_0$: The 3D position of the light source.
*   $\omega_t$: The extinction coefficient of the medium (assumed constant/homogeneous).
*   $L(\omega_i)$: The radiance of the point light source.
*   $p(\omega_i, \omega)$: The phase function value for the scattering angle between light direction $\omega_i$ and view direction $\omega$.

**Outputs:**
*   $L(x_t, \omega)$: The computed single-scattered radiance at $x_t$ in direction $\omega$.

**Data Structures:**
No complex data structures are required. The method relies on scalar arithmetic and vector distance calculations.

**Steps:**
1.  Calculate the vector from the light source to the scattering point: $\vec{d} = x_t - x_0$.
2.  Calculate the distance $t = \|\vec{d}\|$.
3.  Determine the light direction $\omega_i = \vec{d} / t$.
4.  Evaluate the optical depth $\tau = t \cdot \omega_t$.
5.  Compute the transmittance term: $T = e^{-\tau}$.
6.  Compute the scattering contribution using the analytical formula.

**Formula:**
The radiance $L(x_t, \omega)$ is given by [S2]:

$$
L(x_t, \omega) = e^{-t \omega_t} L(x_0, \omega) + p(\omega_i, \omega) L(\omega_i) \frac{1 - e^{-t \omega_t}}{\omega_t}
$$

Where:
*   $L(x_0, \omega)$ is the background radiance (often 0 in unbounded media contexts or the direct light contribution if boundaries were present, but here typically refers to the light source radiance attenuated by distance if $x_0$ is the source). Note: In the context of [S1] and [S2], the first term often represents the direct light contribution attenuated by the medium if the light is treated as a source at $x_0$, or background. However, [S2] explicitly defines the solution for Equation 1 where $L(x_0, \omega)$ is the incoming radiance at the start of the path. For a point light at $x_0$, the direct term is usually $L(\omega_i) e^{-t \omega_t}$. The second term is the single scattering integral.
*   $t$ is the geometric distance.
*   $\omega_t$ is the extinction coefficient.
*   $p(\omega_i, \omega)$ is the phase function.
*   $L(\omega_i)$ is the light intensity.

**Pseudocode:**
```python
def analytical_single_scattering_point_light(x_t, x_light, omega_t, phase_function, light_radiance):
    """
    Computes analytical single scattering for a point light in a homogeneous medium.
    
    Args:
        x_t: Vector3, position of the scattering point.
        x_light: Vector3, position of the point light source.
        omega_t: float, extinction coefficient of the medium.
        phase_function: function, p(omega_i, omega) returning phase value.
        light_radiance: float, radiance of the point light.
        
    Returns:
        float, the single scattered radiance.
    """
    # 1. Calculate distance and direction
    delta = x_t - x_light
    t = length(delta)
    
    # Handle degenerate case where point is at light source
    if t < 1e-6:
        return light_radiance # Direct contribution, no scattering path length
        
    omega_i = delta / t
    
    # 2. Calculate optical depth
    tau = t * omega_t
    
    # 3. Calculate transmittance
    transmittance = exp(-tau)
    
    # 4. Compute scattering term
    # The term (1 - e^(-t * sigma_t)) / sigma_t is the integral of transmittance over distance
    scattering_integral = (1.0 - transmittance) / omega_t
    
    # 5. Evaluate phase function
    # Note: omega (view direction) is not explicitly passed in this signature 
    # but is required for phase_function. Assuming phase_function takes omega_i and omega.
    # For a complete implementation, omega must be provided.
    # Here we assume phase_function(omega_i, omega) is available.
    # Since omega is not in args, we assume it's a closure or global context.
    # To make it self-contained as per rules, we add omega to args.
    pass

def analytical_single_scattering_point_light_full(x_t, x_light, omega_t, phase_function, light_radiance, omega_view):
    delta = x_t - x_light
    t = length(delta)
    
    if t < 1e-6:
        return light_radiance
        
    omega_i = delta / t
    
    tau = t * omega_t
    transmittance = exp(-tau)
    
    scattering_integral = (1.0 - transmittance) / omega_t
    
    p_val = phase_function(omega_i, omega_view)
    
    # Direct light term (attenuated) + Single scattering term
    # Note: The formula in [S2] includes L(x0, omega). For a point light, 
    # the direct radiance arriving at xt is light_radiance * transmittance.
    # The scattering term is p * L_light * scattering_integral.
    
    direct_term = light_radiance * transmittance
    scatter_term = p_val * light_radiance * scattering_integral
    
    return direct_term + scatter_term
```

**Edge Cases:**
*   **Point at Light Source:** If $t \approx 0$, division by $\omega_t$ in the limit is handled by the Taylor expansion or simply returning the direct radiance. The term $\frac{1 - e^{-t \omega_t}}{\omega_t}$ approaches $t$ as $t \to 0$.
*   **Zero Extinction:** If $\omega_t = 0$, the medium is transparent. The formula involves division by zero. In this case, the scattering term becomes $p \cdot L \cdot t$ and transmittance is 1. [G] Implementation should check for $\omega_t < \epsilon$.

## Subtopics

### Analytical Ground Truth
An analytical solution to the radiative transfer equation used as ground truth for error analysis [S2]. It is applicable only under specific conditions: homogeneous medium (constant absorption and scattering, no emission), uniform lighting without shadows (e.g., infinite directional light, no occluding geometry), and no multiple scattering [S2]. The formula is $L(x_t, \omega) = e^{-t \omega_t} L(x_0, \omega) + p(\omega_i, \omega) L(\omega_i) \frac{1 - e^{-t \omega_t}}{\omega_t}$ [S2]. It serves to validate numerical methods like differential ray marching [S2].

## Operating characteristics
*   **Time Complexity:** $O(1)$ per sample/pixel. The computation involves basic arithmetic and exponential functions.
*   **Memory Complexity:** $O(1)$. No auxiliary data structures or buffers are required.
*   **Performance:** Can achieve real-time frame rates [S1].
*   **Strengths:** Noise-free results; exact solution for the specified conditions; extremely fast.
*   **Limitations:** Limited to point lights [S1]; limited to media without boundaries (or boundaries that do not affect the single scattering integral in a complex way, effectively treating the medium as unbounded or the light as internal) [S1]; cannot handle multiple scattering [S2]; requires homogeneous medium for the specific ground truth variant [S2].
*   **When to use:** Real-time visualization of point lights in homogeneous fog/volume where noise is unacceptable and boundaries are negligible or absent.
*   **When not to use:** Complex lighting (area lights, shadows), heterogeneous media, or when multiple scattering is significant.

## Background
Sun et al. [S1] proposed this analytical solution for single scattering by participating media without boundaries under a point light. It is cited as being significantly faster than previous methods like Walter et al. while providing higher-quality results [S1]. The specific analytical formula used as ground truth is detailed in the context of Differential Ray Marching error analysis [S2].
