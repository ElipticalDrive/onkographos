# Single Scattering

Also called: Direct Lighting in Participating Media

## Overview
Single scattering is an approximation of light transport in participating media where in-scattered radiance is assumed to come from lights directly, similar to direct lighting, requiring integration over the spherical domain [S1, unofficial].

## How it works
**Inputs and Outputs:**
- **Input:** Position $x_t$ in the medium, outgoing direction $\vec{w}$, list of light sources, medium properties (scattering coefficient $\sigma_s$, absorption coefficient $\sigma_a$, phase function $phase$) [S1, unofficial].
- **Output:** In-scattered radiance $L_s(x_t, \vec{w})$ [S1, unofficial].

**Data Structures:**
- **Light List:** A list of light sources, each containing position, intensity, and geometry (e.g., point, directional, area) [S1, unofficial].
- **Medium Properties:** $\sigma_s$ (scattering coefficient), $\sigma_a$ (absorption coefficient), and $phase(\vec{w}', \vec{w})$ (phase function) [S1, unofficial].

**Steps:**
1. Initialize total in-scattered radiance $L_s = 0$.
2. For each light source in the scene:
   a. Determine the direction $\vec{w}'$ from $x_t$ to the light source.
   b. Calculate the incident radiance $L_i(x_t, \vec{w}')$ from the light source at $x_t$, accounting for attenuation through the medium.
   c. Evaluate the phase function $phase(x_t, \vec{w}', \vec{w})$.
   d. Compute the contribution: $phase(x_t, \vec{w}', \vec{w}) \times L_i(x_t, \vec{w}')$.
   e. Add the contribution to $L_s$.
3. Return $L_s$. [S1, unofficial]

**Formula:**
The in-scattered radiance is given by the integral over the unit sphere $S^2$:
$$ L_s(x_t, \vec w) = \int_{S^2} phase(x_t, \vec w', \vec w) L_i(x_t, \vec w') d\vec w' $$
where:
- $L_s(x_t, \vec w)$ is the in-scattered radiance at position $x_t$ in direction $\vec{w}$ [S1, unofficial].
- $phase(x_t, \vec w', \vec w)$ is the phase function [S1, unofficial].
- $L_i(x_t, \vec w')$ is the incident radiance from direction $\vec{w}'$ (from lights) [S1, unofficial].
- $d\vec w'$ is the differential solid angle [G].

**Implementation via Next Event Estimation (NEE):**
In practice, the spherical integral is approximated by Next Event Estimation, directly enumerating all lights [S1, unofficial]. For each light, the contribution is calculated and summed. If a light is occluded by geometry or the medium itself, its contribution is zero [S1, unofficial].

**Pseudocode:**
```python
def single_scattering_radiance(x_t, w_out, lights, sigma_a, sigma_s, phase_func):
    """
    Calculate in-scattered radiance at x_t for direction w_out using single scattering approximation.
    """
    total_radiance = vec3(0.0)
    sigma_t = sigma_a + sigma_s
    for light in lights:
        w_in = normalize(light.position - x_t)
        distance = length(light.position - x_t)
        attenuation = exp(-sigma_t * distance)
        # Geometric occlusion check omitted; sources do not provide intersection logic [G]
        incident_radiance = light.intensity * attenuation
        phase_value = phase_func(w_in, w_out)
        total_radiance += phase_value * incident_radiance
    return total_radiance
```

**Parameters:**
- **Anisotropy ($g$):** Parameter for the Henyey-Greenstein phase function, range -1 to 1 [S1, unofficial].
- **Volume Absorption ($\sigma_a$):** Range 0 to 1 [S1, unofficial].
- **Volume Scattering ($\sigma_s$):** Range 0 to 1 [S1, unofficial].

**Edge Cases and Pitfalls:**
- Degenerate directions (e.g., light directly behind the camera or at the same position as $x_t$) require normalization guards to avoid division by zero [G].
- The sources do not specify precision or boundary handling details [S1, unofficial].

## Subtopics

### Monochromatic Mie Scattering Shading
Monochromatic Mie scattering shading treats the Mie scattering intensity $I_{SM}$ as monochromatic, occupying only one channel in the scattering texture, and shades it during rendering by multiplying by the attenuated direct illumination $I_0^I$ [S2]. Alternatively, the proportionality rule from [Bruneton and Neyret 2008] can be used instead of multiplying by attenuated direct illumination [S2].

### Simple Compositing Illumination Approximation
The simple compositing illumination approximation ignores scattering completely, reducing the illumination equation to a form equivalent to standard volume compositing [S3, book]. The simplified intensity is given by:
$$ I(t_0, \vec{\omega}) = \int_{t_0}^{\infty} E(\tau) e^{(-\int_{t_0}^{t} \sigma_a(\tau) \, d\tau)} \, d\tau $$
In discrete form, this is expressed as:
$$ I(t_{near}, \vec{\omega}) = \sum_{t = t_{near}}^{t \leq t_{far}} \alpha(t) \prod_{t' = t_{near}}^{t' < t_{far}}(1 - a(t')) $$
or recursively:
$$ I(t_n, \vec{\omega}) = \alpha(t_n) + (1 - \alpha(t_n)) I(t_{n+1}, \vec{\omega}) $$
This simplification produces images that do not appear realistic because it reduces the illumination model to simple compositing [S3, book].

## Operating characteristics
- **Time Complexity:** Linear with respect to the number of lights [S1, unofficial].
- **Memory Complexity:** Depends on the acceleration structure used for ray tracing (e.g., Embree) and the storage of medium properties [S1, unofficial].
- **Measured Performance:** With equi-angular sampling, each image is rendered in less than 10 minutes with spp < 100 and spr = 4, using Embree for acceleration [S1, unofficial].
- **Strengths:** Physically plausible for direct illumination in participating media [S1, unofficial].
- **Limitations:** Computationally expensive for scenes with many lights due to per-light enumeration [S1, unofficial].
- **When to Use:** Scenes requiring direct volumetric illumination with a manageable number of lights [S1, unofficial].
- **When Not to Use:** Not given in the sources.

## Background
Not given in the sources. The method is implemented in path tracers using Next Event Estimation for direct lighting and acceleration structures like Embree [S1, unofficial].
