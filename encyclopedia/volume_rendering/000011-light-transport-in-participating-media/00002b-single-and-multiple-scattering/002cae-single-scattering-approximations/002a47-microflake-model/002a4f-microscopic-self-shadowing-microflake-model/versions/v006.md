# Microscopic Self-Shadowing Microflake Model

Also called: Self-shadowing model

## Overview
The Microscopic Self-Shadowing Microflake Model is a physically-based participating medium model that extends the standard Microflake Model by introducing correlations of microflake positions at a microscopic scale [S1]. It accounts for microscopic shadowing and masking effects that the standard model ignores [S1]. Unlike the standard Microflake Model, which assumes microflakes are well-separated and uncorrelated, this model uses a shadowing function $A(\omega)$ to independently control attenuation, single scattering, and multiple scattering based on the probability of a microflake being obscured by its neighbors [S1].

## How it works
**Inputs and Outputs:**
*   **Inputs:** Microflake Normal Distribution Function (NDF) $D(\omega_m)$, shadowing function $A(\omega)$, single scattering albedo $\alpha_{ss}(\lambda)$, multiple scattering albedo $\alpha_{ms}(\lambda)$, density $\rho$, and wavelength $\lambda$ [S1].
*   **Outputs:** Attenuation coefficient $\sigma_t(\omega)$, single scattering coefficient $\sigma_{ss}(\omega)$, multiple scattering coefficient $\sigma_{ms}(\omega)$, single scattering phase function $f_{ss}(\omega \rightarrow \omega')$, and multiple scattering phase function $f_{ms}(\omega \rightarrow \omega')$ [S1].

**Data Structures:**
The model relies on the following mathematical objects:
1.  **NDF $D(\omega_m)$:** A probability density function over the sphere $S^2$ describing microflake orientations [S1].
2.  **Shadowing Function $A(\omega)$:** A scalar field on the sphere $S^2$ where $0 < A(\omega) \leq 1$ [S1]. It represents the probability that a microflake is *not* shadowed or masked in direction $\omega$ [S1].
3.  **Albedos:** $\alpha_{ss}(\lambda)$ and $\alpha_{ms}(\lambda)$ are scalar values per wavelength [S1].

**Formulas and Definitions:**
Let $\omega$ be the incoming direction, $\omega'$ be the outgoing direction, and $\omega_m$ be a microflake normal [G].
The half-vector is defined as $\omega_h = \frac{\omega + \omega'}{\|\omega + \omega'\|}$ [G].

1.  **Shadowing Function Constraints:**
    $$A(\omega) = A(-\omega) \quad \text{and} \quad 0 < A(\omega) \leq 1$$
    $1 - A(\omega)$ is the probability of shadowing/masking by neighboring microflakes in direction $\omega$ [S1]. $A(\omega)=1$ corresponds to the standard microflake model [S1].

2.  **Attenuation Coefficient $\sigma_t(\omega)$:**
    $$\sigma_t(\omega) = A(\omega) \rho \int_{S^2} D(\omega_m) \langle \omega \cdot \omega_m \rangle \, d\omega_m$$
    where $\langle x \rangle$ denotes the positive part $\max(0, x)$ [G]. This is the standard microflake attenuation multiplied by $A(\omega)$ [S1].

3.  **Single Scattering Coefficient $\sigma_{ss}(\omega)$:**
    Single scattering occurs when microflakes are both unmasked (incoming direction $\omega$) and un-shadowed (outgoing direction $\omega'$) [S1]. The coefficient is derived by integrating over outgoing directions using the Jacobian of the transformation from normals to specular reflections [S1]:
    $$\sigma_{ss}(\omega) = \frac{\rho \alpha_{ss}(\lambda) A(\omega)}{4} \int_{S^2} A(\omega') D(\omega_h) \, d\omega'$$
    The integral is over the sphere of outgoing directions $\omega'$, and $\omega_h$ depends on $\omega$ and $\omega'$ [S1].

4.  **Single Scattering Phase Function $f_{ss}(\omega \rightarrow \omega')$:**
    $$f_{ss}(\omega \rightarrow \omega') = \frac{\rho \alpha_{ss}(\lambda) A(\omega) A(\omega') D(\omega_h)}{4 \sigma_{ss}(\omega)}$$
    This function is normalized and satisfies reciprocity [S1].

5.  **Multiple Scattering Coefficient $\sigma_{ms}(\omega)$:**
    Multiple scattering accounts for all scattering orders except single scattering [S1]. It is computed as a linear combination of the total attenuation and single scattering coefficients [S1]:
    $$\sigma_{ms}(\omega) = \alpha_{ms}(\lambda) \left( \sigma_t(\omega) - \frac{\sigma_{ss}(\omega)}{\alpha_{ss}(\lambda)} \right)$$
    Alternatively expressed as:
    $$\sigma_{ms}(\omega) = \alpha_{ms}(\lambda) \rho A(\omega) \int_{S^2} (1 - A(\omega')) D(\omega_m) \langle \omega \cdot \omega_m \rangle \, d\omega_m$$
    [S1].

6.  **Multiple Scattering Phase Function $f_{ms}(\omega \rightarrow \omega')$:**
    The model assumes multiple scattering is roughly diffuse, depending only on the outgoing direction [S1]:
    $$f_{ms}(\omega \rightarrow \omega') = f_{ms}(\omega') = \frac{\sigma_{ms}(\omega')}{\int_{S^2} \sigma_{ms}(\omega'') \, d\omega''}$$
    This satisfies reciprocity because $\sigma_{ms}(\omega) f_{ms}(\omega \rightarrow \omega')$ is symmetric in $\omega$ and $\omega'$ [S1].

**Parameters:**
*   $\alpha_{ss}(\lambda)$: Single scattering albedo [S1].
*   $\alpha_{ms}(\lambda)$: Multiple scattering albedo [S1].
*   Typical values: For energy conservation (White Furnace Test), if $\alpha_{ss} = \alpha_{ms} = 1$, then $\sigma_{ss} + \sigma_{ms} = \sigma_t$ [S1].

**Pseudocode:**
The following Python-like pseudocode computes the coefficients given $D$, $A$, and parameters [S1].

```python
def compute_microflake_self_shadowing(D, A, alpha_ss, alpha_ms, rho, wavelength, sphere_samples, sphere_weights):
    """
    Computes scattering coefficients and phase functions for the 
    Microscopic Self-Shadowing Microflake Model [S1].
    
    Args:
        D: Function D(omega_m) returning NDF value for normal omega_m.
        A: Function A(omega) returning shadowing probability for direction omega.
        alpha_ss: Single scattering albedo scalar.
        alpha_ms: Multiple scattering albedo scalar.
        rho: Density scalar.
        wavelength: Wavelength scalar (used for albedo lookup if needed).
        sphere_samples: List of direction vectors on the unit sphere.
        sphere_weights: List of corresponding quadrature weights.
        
    Returns:
        sigma_t, sigma_ss, sigma_ms, f_ss, f_ms
    """
    
    def integrate_sphere(integrand_func):
        # Standard spherical quadrature [G]
        total = 0.0
        for omega, w in zip(sphere_samples, sphere_weights):
            total += integrand_func(omega) * w
        return total

    def compute_att_integral(omega):
        return integrate_sphere(lambda omega_m: D(omega_m) * max(0.0, dot(omega, omega_m)))

    def compute_ss_integral(omega):
        def integrand(omega_prime):
            omega_h = normalize(omega + omega_prime)
            return A(omega_prime) * D(omega_h)
        return integrate_sphere(integrand)

    def sigma_t(omega):
        return A(omega) * rho * compute_att_integral(omega)

    def sigma_ss(omega):
        return (rho * alpha_ss * A(omega) / 4.0) * compute_ss_integral(omega)

    def sigma_ms(omega):
        return alpha_ms * (sigma_t(omega) - sigma_ss(omega) / alpha_ss)

    def f_ss(omega, omega_prime):
        omega_h = normalize(omega + omega_prime)
        numerator = rho * alpha_ss * A(omega) * A(omega_prime) * D(omega_h)
        denominator = 4.0 * sigma_ss(omega)
        return numerator / denominator if denominator != 0 else 0.0

    ms_norm = integrate_sphere(sigma_ms)
    
    def f_ms(omega, omega_prime):
        return sigma_ms(omega_prime) / ms_norm if ms_norm != 0 else 0.0

    return sigma_t, sigma_ss, sigma_ms, f_ss, f_ms
```

**Edge Cases and Pitfalls:**
*   **Energy Conservation:** The model satisfies reciprocity by construction [S1]. If $\alpha_{ss} = \alpha_{ms} = 1$, the model passes the white furnace test ($\sigma_{ss} + \sigma_{ms} = \sigma_t$) [S1].
*   **Numerical Integration:** The integrals for $\sigma_{ss}$ and $\sigma_t$ involve spherical convolutions [S1]. Standard distributions like SGGX or Gaussian Fibers do not yield closed-form solutions for these integrals with arbitrary $A(\omega)$ [S1]. Implementers should use numerical integration or specific distributions (like Trigonometric Lobes) that allow closed-form solutions [S1].
*   **Shadowing Function Validity:** $A(\omega)$ must be symmetric ($A(\omega) = A(-\omega)$) and bounded $(0, 1]$ [S1]. Violating this breaks the physical interpretation and reciprocity [S1].

## Subtopics

### [Simplified Model with Isotropic Self-Shadowing](4761-simplified-model-with-isotropic-self-shadowing.md)
This method simplifies the Microscopic Self-Shadowing Microflake Model by assuming the shadowing function $A$ is isotropic (constant for all directions). This reduces parameter count and implementation complexity while maintaining sufficient accuracy in practice. It differs from the parent model by decoupling the directional dependence of shadowing, allowing closed-form solutions for spherical integrals that would otherwise require numerical approximation. Choose it when computational efficiency is prioritized and directional shadowing variations are negligible.

### [SGGX Microflake Distribution](6660-sggx-microflake-distribution.md)
The SGGX (Spherical Gaussian Generalized X) microflake distribution is a normal distribution function (NDF) designed for modeling aggregated microflakes in participating media. It solves the problem of efficiently computing attenuation coefficients and sampling specular phase functions for anisotropic microflake ensembles. It is distinguished from its siblings, such as the [Simplified Model with Isotropic Self-Shadowing](4761-simplified-model-with-isotropic-self-shadowing.md), by its ability to represent complex, arbitrarily oriented anisotropic normal distributions using a single lobe, enabling exact and fast evaluation of optical properties. Choose it for highly anisotropic media where exact NDF evaluation is required, though it requires numerical integration for the self-shadowing integrals.

### Trigonometric Lobe Self-Shadowing Model
A volume rendering model using microflake normal distributions based on trigonometric lobes to enable closed-form expressions for self-shadowing integrals, solving the difficulty of finding closed-form solutions for spherical convolutions with distributions like SGGX [S1]. It defines the microflake normal distribution $D$ using trigonometric lobes:
$$D_{\cos}(\boldsymbol{\omega}, \boldsymbol{\xi}, n) = \frac{(\boldsymbol{\omega} \cdot \boldsymbol{\xi})^{2n}}{N_{\cos}(n)}$$
$$D_{\sin}(\boldsymbol{\omega}, \boldsymbol{\xi}, n) = \frac{(1 - (\boldsymbol{\omega} \cdot \boldsymbol{\xi})^2)^n}{N_{\sin}(n)}$$
where $n$ is an integer and $N$ are normalization factors [S1]. This representation is simple, flexible, and can be stored with only 6 parameters [S1]. Choose it when closed-form evaluation of the self-shadowing integrals is required for anisotropic media [S1].

## Operating characteristics
*   **Time Complexity:** The core complexity lies in evaluating the spherical integrals for $\sigma_t$ and $\sigma_{ss}$ [S1]. For general $D$ and $A$, this requires numerical integration, which is expensive [S1]. Using Trigonometric Lobes allows closed-form solutions for the integrals, significantly reducing evaluation cost per direction [S1].
*   **Memory Complexity:** Requires storing $D$ and $A$ [S1]. The self-shadowing function $A$ can be stored with 6 parameters [S1].
*   **Strengths:** Physically accurate for downsampling; handles anisotropic media; preserves energy; satisfies reciprocity [S1].
*   **Limitations:** Requires careful handling of spherical integrals for general distributions; more complex than the standard Microflake Model [S1].
*   **When to use:** When rendering dense participating media (e.g., foliage, fur) at lower resolutions or when downsampling high-resolution data, where microscopic shadowing effects become significant [S1].
*   **When not to use:** For sparse media where microflakes are well-separated (standard Microflake Model suffices); when computational resources are extremely limited and closed-form solutions are not available [S1].

## Background
The Microflake Model was introduced by Jakob et al. [JAM* 10] as a physically-based model for participating media [S1]. The Microscopic Self-Shadowing extension was introduced in [S1] to address inaccuracies in volume downsampling by incorporating microscopic correlations between microflakes. The model builds on the anisotropic radiative transfer equation proposed by Jakob et al. [S1].
