# Microscopic Self-Shadowing Microflake Model

Also called: Self-shadowing model

## Overview
The Microscopic Self-Shadowing Microflake Model extends the standard [Microflake Model](4739-microflake-model.md) by introducing spatial correlations between microflakes at a microscopic scale, resulting in self-shadowing and masking effects [S1]. While the standard model assumes microflakes are uncorrelated and well-separated, this model accounts for the probability that a microflake is occluded by its neighbors, allowing for more accurate representation of dense or clustered particulate media [S1]. It distinguishes itself by independently controlling attenuation, single scattering, and multiple scattering through a directional shadowing function $A(\omega)$, ensuring energy conservation and reciprocity [S1].

## How it works
The model defines the radiative transfer properties of a participating medium composed of microflakes whose orientations are described by a Normal Distribution Function (NDF) $D(\omega_m)$ [S1]. The core innovation is the shadowing function $A(\omega)$, which modulates the standard microflake coefficients to account for microscopic occlusion [S1].

### Inputs and Outputs
**Inputs:**
*   Microflake Normal Distribution Function (NDF): $D(\omega_m)$, defined on the unit sphere.
*   Shadowing function: $A(\omega)$, defined on the unit sphere.
*   Single scattering albedo: $\alpha_{ss}(\lambda)$.
*   Multiple scattering albedo: $\alpha_{ms}(\lambda)$.
*   Density parameter: $\rho$.

**Outputs:**
*   Attenuation coefficient: $\sigma_t(\omega)$.
*   Single scattering coefficient: $\sigma_{ss}(\omega)$.
*   Single scattering phase function: $f_{ss}(\omega \rightarrow \omega')$.
*   Multiple scattering coefficient: $\sigma_{ms}(\omega)$.
*   Multiple scattering phase function: $f_{ms}(\omega \rightarrow \omega')$.

### Data Structures
The implementation requires evaluating integrals over the unit sphere $S^2$.
*   **NDF $D(\omega_m)$**: Evaluated for a given normal direction $\omega_m$. Common choices include SGGX or trigonometric lobes.
*   **Shadowing Function $A(\omega)$**: Evaluated for incoming/outgoing directions $\omega$. Must satisfy $A(\omega) = A(-\omega)$ and $0 < A(\omega) \leq 1$ [S1].
*   **Hemisphere Integral Helper**: A routine to compute integrals of the form $\int_{S^2} f(\omega_m) \langle \omega \cdot \omega_m \rangle d\omega_m$, where $\langle x \rangle = \max(0, x)$.

### Formulas and Definitions
Let $\omega$ be the direction of interest (incoming or outgoing). Let $\omega_h = \frac{\omega + \omega'}{\|\omega + \omega'\|}$ be the half-vector between incoming $\omega$ and outgoing $\omega'$ directions [S1].

1.  **Attenuation Coefficient** $\sigma_t(\omega)$:
    The standard attenuation multiplied by the shadowing function:
    $$ \sigma_t(\omega) = A(\omega) \rho \int_{S^2} D(\omega_m) \langle \omega \cdot \omega_m \rangle \, d\omega_m $$
    [S1]

2.  **Single Scattering Coefficient** $\sigma_{ss}(\omega)$:
    Accounts for microflakes that are both unmasked (incoming) and un-shadowed (outgoing). Using the Jacobian transformation from normals to specular reflections [WMLT07]:
    $$ \sigma_{ss}(\omega) = \frac{\rho \alpha_{ss}(\lambda) A(\omega)}{4} \int_{S^2} A(\omega') D(\omega_h) \, d\omega' $$
    where $\omega'$ is the direction reflected by the microflake normal $\omega_h$ relative to $\omega$. Specifically, the integral is over the sphere of directions $\omega'$ such that $\omega_h$ is the half-vector between $\omega$ and $\omega'$ [S1].

3.  **Single Scattering Phase Function** $f_{ss}(\omega \rightarrow \omega')$:
    Normalized to satisfy reciprocity and energy conservation for single scattering:
    $$ f_{ss}(\omega \rightarrow \omega') = \frac{\rho \alpha_{ss}(\lambda) A(\omega) A(\omega') D(\omega_h)}{4 \sigma_{ss}(\omega)} $$
    [S1]

4.  **Multiple Scattering Coefficient** $\sigma_{ms}(\omega)$:
    Derived from the total attenuation and single scattering components, scaled by the multiple scattering albedo:
    $$ \sigma_{ms}(\omega) = \alpha_{ms}(\lambda) \left( \sigma_t(\omega) - \frac{\sigma_{ss}(\omega)}{\alpha_{ss}(\lambda)} \right) $$
    [S1]

5.  **Multiple Scattering Phase Function** $f_{ms}(\omega \rightarrow \omega')$:
    Assumed to be roughly diffuse, depending only on the outgoing direction $\omega'$:
    $$ f_{ms}(\omega \rightarrow \omega') = f_{ms}(\omega') = \frac{\sigma_{ms}(\omega')}{\int_{S^2} \sigma_{ms}(\omega'') \, d\omega''} $$
    [S1]

### Parameters
*   $\alpha_{ss}(\lambda)$: Single scattering albedo. [S1]
*   $\alpha_{ms}(\lambda)$: Multiple scattering albedo. [S1]
*   $\rho$: Density parameter. [S1]
*   $A(\omega)$: Shadowing function. Typical values are not specified, but $A(\omega)=1$ recovers the standard model. [S1]

### Pseudocode
The following Python-like pseudocode computes the scattering coefficients for a given direction $\omega$. It assumes helper functions for sphere integration are available.

```python
def compute_microflake_self_shadowing_coefficients(
    omega,          # Direction vector (3D)
    D,              # NDF function: D(normal) -> float
    A,              # Shadowing function: A(direction) -> float
    alpha_ss,       # Single scattering albedo
    alpha_ms,       # Multiple scattering albedo
    rho,            # Density
    integrate_sphere # Function: integrate_sphere(func, omega_ref) -> float
):
    """
    Computes sigma_t, sigma_ss, sigma_ms, f_ss, f_ms for direction omega.
    Note: f_ss and f_ms require omega' (outgoing direction) as additional input.
    This function returns the coefficients and helper values needed for phase functions.
    """
    
    # 1. Compute Attenuation Coefficient sigma_t
    # Integral: int D(wm) * max(0, omega . wm) dwm
    def integrand_sigma_t(wm):
        return D(wm) * max(0.0, dot(omega, wm))
    
    integral_sigma_t = integrate_sphere(integrand_sigma_t, omega)
    sigma_t = A(omega) * rho * integral_sigma_t
    
    # 2. Compute Single Scattering Coefficient sigma_ss
    # Integral: int A(omega') * D(omega_h) domega'
    # Note: omega_h is the half-vector between omega and omega'.
    # The integration is over the sphere of outgoing directions omega'.
    # For a fixed omega, as omega' varies over the sphere, omega_h covers the sphere.
    # The Jacobian factor 1/4 is applied outside.
    
    def integrand_sigma_ss(omega_prime):
        # Calculate half vector
        sum_vec = omega + omega_prime
        norm_sum = length(sum_vec)
        if norm_sum < 1e-8:
            return 0.0
        omega_h = sum_vec / norm_sum
        
        return A(omega_prime) * D(omega_h)
        
    integral_sigma_ss = integrate_sphere(integrand_sigma_ss, omega)
    sigma_ss = (rho * alpha_ss * A(omega) / 4.0) * integral_sigma_ss
    
    # 3. Compute Multiple Scattering Coefficient sigma_ms
    # sigma_ms = alpha_ms * (sigma_t - sigma_ss / alpha_ss)
    if alpha_ss > 1e-8:
        sigma_ms = alpha_ms * (sigma_t - sigma_ss / alpha_ss)
    else:
        sigma_ms = 0.0
        
    return sigma_t, sigma_ss, sigma_ms

def compute_single_scattering_phase_function(omega, omega_prime, sigma_ss, alpha_ss, rho, A, D):
    """
    Computes f_ss(omega -> omega_prime).
    """
    sum_vec = omega + omega_prime
    norm_sum = length(sum_vec)
    if norm_sum < 1e-8:
        return 0.0
    omega_h = sum_vec / norm_sum
    
    numerator = rho * alpha_ss * A(omega) * A(omega_prime) * D(omega_h)
    denominator = 4.0 * sigma_ss
    
    if denominator < 1e-8:
        return 0.0
        
    return numerator / denominator

def compute_multiple_scattering_phase_function(omega_prime, sigma_ms_total_integral):
    """
    Computes f_ms(omega -> omega_prime).
    Note: sigma_ms_total_integral is int sigma_ms(w'') dw''.
    """
    if sigma_ms_total_integral < 1e-8:
        return 0.0
    return sigma_ms(omega_prime) / sigma_ms_total_integral
```

### Edge Cases and Pitfalls
*   **Energy Conservation**: The model satisfies the white furnace test (energy conservation) if $\alpha_{ss} = \alpha_{ms} = 1$, ensuring $\sigma_{ss} + \sigma_{ms} = \sigma_t$ [S1].
*   **Reciprocity**: The phase functions are constructed to satisfy reciprocity by design [S1].
*   **Integration Difficulty**: Evaluating the integrals for $\sigma_{ss}$ and $\sigma_t$ can be computationally expensive, especially with complex NDFs like SGGX. Closed-form solutions are difficult to find for general distributions [S1].
*   **Shadowing Function Constraints**: $A(\omega)$ must be symmetric ($A(\omega) = A(-\omega)$) and bounded $(0, 1]$ [S1].

## Subtopics

### [Simplified Model with Isotropic Self-Shadowing](4761-simplified-model-with-isotropic-self-shadowing.md)
A simplification where the shadowing function is isotropic: $A(\omega) = A$ for all $\omega$. This reduces the number of parameters and simplifies implementation while maintaining sufficient accuracy.

### SGGX Microflake Distribution
A microflake normal distribution introduced by Heitz et al. [HDCD15] that supports fast and exact evaluation of attenuation coefficients, as well as efficient evaluation and sampling of specular phase functions. It was used by the authors for implementing their simplified self-shadowing model [S1].

### Trigonometric Lobe Self-Shadowing Model
A variant using microflake normal distributions based on trigonometric lobes to enable closed-form expressions for self-shadowing integrals. The distributions are defined as $D_{\cos}(\omega, \xi, n) = \frac{(\omega \cdot \xi)^{2n}}{N_{\cos}(n)}$ and $D_{\sin}(\omega, \xi, n) = \frac{(1 - (\omega \cdot \xi)^2)^n}{N_{\sin}(n)}$, where $n$ is an integer and $N$ are normalization factors. This approach solves the difficulty of finding closed-form solutions for spherical convolutions with distributions like SGGX [S1].

## Operating characteristics
*   **Complexity**: The computational cost is dominated by the evaluation of spherical integrals for the attenuation and single scattering coefficients. For general NDFs, these integrals may require numerical quadrature, which is expensive.
*   **Performance**: The model is more complex than the standard microflake model due to the additional integrals involving $A(\omega)$. However, using specific distributions like trigonometric lobes allows for closed-form solutions, significantly improving performance [S1].
*   **Strengths**: Physically-based, accounts for microscopic correlations, energy-conserving, reciprocal.
*   **Limitations**: Requires careful handling of integrals; standard NDFs like SGGX do not yield closed-form solutions for the self-shadowing integrals, necessitating numerical methods or alternative distributions like trigonometric lobes [S1].
*   **When to use**: When simulating dense particulate media where microscopic shadowing effects are significant and a physically-based model is required.
*   **When not to use**: When computational resources are limited and the standard microflake model provides sufficient visual fidelity, or when the NDF is complex and closed-form solutions are not available.

## Background
The Microflake Model was originally introduced by Jakob et al. [JAM*10] as a physically-based model for participating media. The Microscopic Self-Shadowing extension was proposed to address the limitations of the standard model in representing dense media with microscopic correlations. The authors utilized the SGGX distribution [HDCD15] for implementation and later introduced trigonometric lobes to enable closed-form solutions for the self-shadowing integrals [S1].
