# Microflake Model

Also called: Jakob et al. model, Physically-based microflake model, Standard Microflake Model, anisotropic microflake model

## Overview
The Microflake Model is a physically-based participating medium model that represents a volume as a homogeneous cloud of microscopic, perfectly specular flakes [S1]. It solves the problem of rendering anisotropic media (such as fur, felt, or certain powders) by deriving direction-dependent attenuation and scattering properties directly from a statistical distribution of microflake orientations [S1]. Unlike isotropic single-scattering approximations, it produces direction-dependent phase functions and attenuation coefficients that satisfy Helmholtz's reciprocity principle by construction [S1].

## How it works
The model assumes the medium consists of microflakes with a normal distribution function $D(\omega_m)$ and a total surface area density $\rho$ [S1]. The microflakes are assumed to be perfectly specular and thin, reflecting light from both sides [S1]. The model requires $D(\omega)$ to be symmetric, i.e., $D(\omega) = D(-\omega)$ [S1].

**Inputs:**
*   $\omega$: Incoming light direction (unit vector).
*   $\omega'$: Outgoing view direction (unit vector).
*   $\lambda$: Wavelength.
*   $D(\omega_m)$: Microflake Normal Distribution Function (NDF), defined over the hemisphere or sphere.
*   $\rho$: Density, total area of microflake surface per unit volume ($m^{-1}$) [S1].
*   $\alpha(\lambda)$: Albedo of the microflakes, wavelength-dependent, unitless [S1].

**Outputs:**
*   $\sigma_t(\omega)$: Attenuation coefficient ($m^{-1}$) [S1].
*   $\sigma_s(\omega)$: Scattering coefficient ($m^{-1}$) [S1].
*   $f(\omega \rightarrow \omega')$: Phase function ($st^{-1}$) [S1].

**Data Structures:**
The implementation requires a function or data structure to evaluate $D(\omega_m)$ for any direction $\omega_m$. Common implementations use analytical distributions (e.g., Gaussian, Power of Sine/Cosine) or precomputed lookup tables [S1].

**Formulas:**
1.  **Clamped Dot Product:**
    $$ \langle a \cdot b \rangle = \max(0, a \cdot b) $$

2.  **Attenuation Coefficient:**
    Derived from the integral of projected areas over all microflake orientations [S1]:
    $$ \sigma_t(\omega) = \rho \int_{S^2} D(\omega_m) \langle \omega \cdot \omega_m \rangle d\omega_m $$

3.  **Scattering Coefficient:**
    Assuming the albedo is not view-dependent [S1]:
    $$ \sigma_s(\omega) = \alpha(\lambda) \sigma_t(\omega) $$

4.  **Phase Function:**
    For perfectly specular microflakes, the phase function depends on the half-vector $\omega_h$ [S1]:
    $$ f(\omega \rightarrow \omega') = \frac{\rho \alpha(\lambda) D(\omega_h)}{4 \sigma_s(\omega)} $$
    where the half-vector is:
    $$ \omega_h = \frac{\omega + \omega'}{\|\omega + \omega'\|} $$

**Pseudocode:**
```python

    """
    Computes attenuation, scattering, and phase function for the Microflake Model.
    
    Args:
        omega_in (Vector3): Incoming light direction.

    # This integral must be computed numerically or via closed-form solution 
    # depending on the specific NDF D.

    sigma_s = albedo * sigma_t

    # omega_h = (omega_in + omega_out) / ||omega_in + omega_out||
    half_vec = (omega_in + omega_out)
    half_vec_norm = length(half_vec)
    
    # Handle degenerate case where omega_in == -omega_out (backscattering)
    if half_vec_norm < 1e-6:
        # Undefined half vector; return 0 or handle as special case
        return sigma_t, sigma_s, 0.0

    # Note: If sigma_s is 0, phase is undefined.
    if sigma_s < 1e-6:
        return sigma_t, sigma_s, 0.0
        
    d_half = ndf_eval(half_vec)
    phase = (density * albedo * d_half) / (4.0 * sigma_s)
    
    return sigma_t, sigma_s, phase
```

**Edge Cases and Pitfalls:**
*   **Reciprocity:** Arbitrary phase functions in anisotropic media often break Helmholtz's reciprocity principle ($\sigma_s(\omega)f(\omega \rightarrow \omega') = \sigma_s(\omega')f(\omega' \rightarrow \omega)$) [S1]. The Microflake Model satisfies reciprocity by construction [S1].
*   **Degenerate Half-Vector:** When $\omega = -\omega'$, the half-vector is undefined. The phase function should handle this case, typically returning 0 or a specific backscattering value if defined by the NDF limit [S1].
*   **Zero Scattering:** If $\sigma_s(\omega) = 0$, the phase function is undefined. Guard against division by zero [S1].

## Subtopics

### [Microscopic Self-Shadowing Microflake Model](4746-microscopic-self-shadowing-microflake-model.md)
Extends the standard model by introducing correlations of microflake positions at a microscopic scale to account for self-shadowing and masking effects.

### [Gaussian Fiber Distribution](6661-gaussian-fiber-distribution.md)
A specific NDF used within the Microflake Model that provides an efficient implementation compared to Power of Sine/Cosine distributions, though it lacks a closed-form attenuation coefficient.

## Operating characteristics
*   **Complexity:** The computational cost is dominated by the evaluation of the integral for $\sigma_t(\omega)$ and the NDF $D(\omega_h)$. If closed-form solutions exist for the specific NDF, evaluation is $O(1)$. Otherwise, numerical integration is required, increasing cost [S1].
*   **Memory:** Requires storage for the NDF parameters and potentially lookup tables if precomputed [S1].
*   **Strengths:** Physically based; satisfies reciprocity; handles anisotropy naturally; accurate for media composed of small, flat particles [S1].
*   **Limitations:** Assumes perfectly specular flakes; assumes no correlation between microflake positions (standard model); requires integration for attenuation [S1].
*   **When to use:** Rendering anisotropic participating media like fur, felt, or powders where microscopic structure matters [S1].
*   **When not to use:** When the medium is isotropic or when multiple scattering effects are significant and not covered by the single-scattering approximation [S1].

## Background
The Microflake Model was introduced by Jakob et al. in 2010 [JAM* 10] as a physically-based model for participating media [S1]. It is based on anisotropic Radiative Transfer Equation (RTE) framework [S1]. The model derives attenuation and phase functions from a microflake normal distribution function $D(\omega)$ [S1]. It has been extended by later work, such as the Microscopic Self-Shadowing Microflake Model, to account for correlations in microflake positions [S1].
