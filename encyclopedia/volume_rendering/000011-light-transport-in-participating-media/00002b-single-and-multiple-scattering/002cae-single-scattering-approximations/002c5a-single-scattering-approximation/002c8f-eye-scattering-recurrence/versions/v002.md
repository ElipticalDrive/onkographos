# Eye Scattering Recurrence

Also called: Single scattering toward viewer recurrence

## Overview
The Eye Scattering Recurrence computes the light exiting each particle in a volume toward the viewer, assuming single scattering events relative to the viewing direction [S1, unofficial]. It solves the problem of determining visible brightness by combining the transmitted light from previous particles with the light scattered by the current particle toward the camera [S1, unofficial]. It differs from its sibling, Multiple Forward Scattering, which computes light incident on particles from the light source; this method uses the precomputed incident light to determine scattering toward the viewer [S1, unofficial].

## How it works
**Inputs and Outputs**
*   **Input:** A sequence of $N$ particles $p_1, \dots, p_N$ along the view ray. For each particle $k$, the albedo $a_k$, extinction $\tau_k$, and the light incident on the particle $I_k$ (computed in a preceding forward scattering pass) are required [S1, unofficial]. The view direction $\omega$ and light direction $l$ are constant for the ray [G].
*   **Output:** The exit radiance $E_k$ for each particle $k$, representing the light leaving particle $k$ toward the viewer [S1, unofficial].

**Data Structures**
The method operates on a linear array of particles. Each particle $k$ stores:
*   $a_k$: Albedo (dimensionless, $0 \le a_k \le 1$) [G].
*   $\tau_k$: Extinction coefficient (inverse length) [G].
*   $I_k$: Incident light intensity (radiance) at particle $k$, computed in the previous pass [S1, unofficial].
*   $T_k$: Transparency of particle $k$, derived from extinction [G].

**Formulas**
The recurrence relation for $1 \le k \le N$ is:

$$ E_k = S_k + T_k \cdot E_{k-1} $$

Where:
*   $E_k$ is the light exiting particle $k$ toward the viewer [S1, unofficial].
*   $S_k$ is the light scattered by particle $k$ toward the viewer [S1, unofficial].
*   $T_k$ is the transparency of particle $k$ [S1, unofficial].
*   $E_{k-1}$ is the light exiting the previous particle $k-1$ [S1, unofficial]. For $k=1$, $E_0 = 0$ [S1, unofficial].

The scattered light $S_k$ is defined as:

$$ S_k = \frac{a_k \cdot \tau_k \cdot p(\omega, -l) \cdot I_k}{4\pi} $$

Where:
*   $a_k$ is the albedo of particle $k$ [S1, unofficial].
*   $\tau_k$ is the extinction of particle $k$ [S1, unofficial].
*   $p(\omega, -l)$ is the phase function evaluated for the view direction $\omega$ and the negative light direction $-l$ (scattering from light direction to view direction) [S1, unofficial].
*   $I_k$ is the light incident on particle $k$ [S1, unofficial].
*   $4\pi$ is the normalization factor for isotropic scattering integration [G].

**Transparency Calculation**
The transparency $T_k$ is calculated as $e^{-\tau_k \Delta d}$, where $\Delta d$ is the distance between particles or the particle thickness [G]. The source notes $T_k$ as "transparency of particle $k$" without an explicit formula [S1, unofficial].

```python
def eye_scattering_recurrence(particles, view_direction, light_direction):
    """
    Computes light exiting each particle toward the viewer.
    
    Args:
        particles: List of particle dicts with fields:
                   - albedo (a_k)
                   - extinction (tau_k)
                   - incident_light (I_k)
                   - thickness (delta_d)
        view_direction: Vector omega
        light_direction: Vector l
        
    Returns:
        List of exit radiances E_k
    """
    N = len(particles)
    E = [0.0] * N
    prev_E = 0.0
    
    # Precompute phase function value: p(omega, -l)
    neg_light = tuple(-v for v in light_direction)
    phase_val = evaluate_phase_function(view_direction, neg_light)
    
    for k in range(N):
        p = particles[k]
        a_k = p['albedo']
        tau_k = p['extinction']
        I_k = p['incident_light']
        delta_d = p['thickness']
        
        # Calculate transparency T_k = exp(-tau_k * delta_d)
        T_k = math.exp(-tau_k * delta_d)
        
        # Calculate scattered light S_k
        S_k = (a_k * tau_k * phase_val * I_k) / (4.0 * math.pi)
        
        # Recurrence: E_k = S_k + T_k * E_{k-1}
        E_k = S_k + T_k * prev_E
        E[k] = E_k
        prev_E = E_k
        
    return E
```

**Edge Cases and Pitfalls**
*   **Double Counting Phase Function:** A common pitfall is assuming the phase function is applied twice to the same light interaction because it appears in both the forward scattering pass (computing $I_k$) and the eye scattering pass (computing $S_k$) [S1, unofficial]. This is incorrect. In the forward pass, the phase function determines scattering from $p_{k-1}$ to $p_k$ in the light direction [S1, unofficial]. In the eye scattering pass, it determines scattering from $p_k$ to the viewer [S1, unofficial]. The incident light $I_k$ is stored and used directly, preventing double counting even if the viewpoint is opposite the light source [S1, unofficial].
*   **Boundary Conditions:** The recurrence starts with $E_0 = 0$ [S1, unofficial]. If there is background light, it should be added to the final $E_N$ or handled as $E_0$ depending on the specific implementation of the volume rendering integral [G]. The source does not specify background handling, so $E_0=0$ is the base case for particle contributions [S1, unofficial].

## Operating characteristics
*   **Time Complexity:** $O(N)$, where $N$ is the number of particles along the ray. Each particle requires a constant number of arithmetic operations [G].
*   **Memory Complexity:** $O(N)$ to store the incident light $I_k$ from the previous pass and the output $E_k$ [G].
*   **Measured Performance and Scaling:** Not given in the sources.
*   **Strengths:** Efficiently computes single scattering toward the viewer. It is simple to implement and integrates well with precomputed incident light [G].
*   **Limitations:** Only accounts for single scattering toward the viewer. It does not account for multiple scattering events in the view direction (glow). It relies on the accuracy of the incident light $I_k$ computed in the previous pass [G].
*   **When to Use:** When single scattering approximation is valid (low albedo/density) and computational efficiency is prioritized over full multiple scattering accuracy [G].

## Background
The Eye Scattering Recurrence is based on the single scattering toward the viewer approximation described by Dobashi et al. [S1, unofficial]. It is part of the Real-Time Cloud Rendering technique, which combines multiple forward scattering (pre-process) with single scattering toward the viewer to achieve realistic cloud shading efficiently [S1, unofficial]. The phase function used is critical for cloud shading, as clouds exhibit anisotropic scattering [S1, unofficial].
