# Most Probable Paths (MPP) Lighting Model

Also called: General Participating Media Lighting Model, MPP model, MPP-based lighting model, Most Probable Path (MPP) Multiple Scattering Model, Multiple Scattering approximation using MPP, Premože et al. 2004 model

## Overview
The Most Probable Paths (MPP) lighting model approximates multiple scattering in general inhomogeneous participating media by summing contributions only from paths close to the "most probable path" (MPP) for a given number of scattering events, assuming strong forward scattering [S1]. It splits radiance into object, single-scattered, and multiple-scattered components, using MPPs to approximate the scattering integral without requiring the diffusion approximation or planar surface assumptions [S1]. Unlike [Kniss et al. 2002], which uses a constant effective scattering angle, this model determines the effective scattering angle locally based on the phase function and the amount of scattering that has occurred [S1].

## How it works
### Inputs and Outputs
**Inputs:**
*   Medium volume: Defined by spatially varying absorption coefficient $a(x)$, scattering coefficient $b(x)$, and extinction coefficient $c(x) = a(x) + b(x)$ [S1].
*   Phase function $P(\theta)$: Assumed strongly forward-scattering with a known mean square scattering angle $\langle \theta^2 \rangle$ [S1].
*   Light source: Directional light source with intensity $L_0$ in direction $\vec{\omega}_0$ [S1].
*   Geometry: Object positions and depths (for shadowing) [S1].
*   Parameters: Mean square scattering angle $\theta^2$ (assumed constant), global average scattering coefficient $\bar{b}$, and rate adjustment parameter $\gamma$ (typically 1.0 for original model, 0.45 for denser media fits) [S1].

**Outputs:**
*   Final radiance $L(x, \vec{\omega})$ at each point $x$ along the viewing ray in direction $\vec{\omega}$ [S1].

### Data Structures
1.  **Light Volume:** A 3D data structure storing $\ell_{light}$ values for every volume cell. The volume is oriented such that the z-axis is aligned with the light direction $\vec{\omega}_0$. This acts as a variation of a deep shadow map [S1].
2.  **Object Image:** The scene rendered without participating media effects (except for shadows cast by the medium onto objects) [S1].

### Numbered Steps

1.  **Preprocessing: Compute Light Volume**
    For every voxel in the volume, compute the number of scattering events $\ell_{light}$ from the voxel to the light source. This is done by integrating the scattering coefficient along the ray from the voxel in direction $\vec{\omega}_0$:
    $$ \ell_{light}(x) = \int_{x}^{\text{light}} b(x') ds' $$
    Store $\ell_{light}(x)$ in the Light Volume [S1].

2.  **Rendering: Volume Sweep**
    For each pixel, cast a ray from the eye into the scene. For each sample point $x$ along the ray (segment $\Delta x$), compute the three components of radiance: Object Weight, Single Scattering, and Multiple Scattering.

3.  **Compute Object Weight ($W$)**
    Calculate the weight for the unfiltered object image $L_{obj}$. First, compute the number of scattering events from the object to the eye, $\ell_{obj}$, by integrating $b(x)$ along the path from the object surface to $x$ [S1].
    Compute the blurring width $w(\ell_{obj}, s_{obj})$ using Equation (4) below.
    The weight $W$ is given by:
    $$ W = \left(1 + \ell_{obj} + \frac{2\bar{b}^2 w(\ell_{obj}, s_{obj})^2 \ell_{obj}}{\langle \theta^2 \rangle}\right) \exp\left(-\frac{c \ell_{obj}}{b}\right) $$
    where $c$ and $b$ are evaluated at $x$ [S1].

4.  **Compute Single Scattering ($L_{SS}$)**
    Calculate the single-scattered radiance arriving at $x$ from the directional light $\vec{\omega}_0$:
    $$ \Delta L_{SS}(x, \vec{\omega}) = L_{unscat}(x, \vec{\omega}_0) P(x, \vec{\omega}, \vec{\omega}_0) \exp\left(-\frac{c}{b} \ell_{eye}\right) b(x) \Delta x $$
    where:
    *   $\ell_{eye}$ is the number of scattering events from $x$ to the eye.
    *   $L_{unscat}(x, \vec{\omega}_0) = L_0 \exp\left(-\frac{c}{b} \ell_{light}(x)\right)$ is the unscattered light available at $x$ [S1].

5.  **Compute Multiple Scattering ($L_{MS}$)**
    The multiple scattering radiance is approximated by integrating over MPPs with different scattering counts $\ell$. The contribution is derived from the blurred incident radiance $L_{blurred}$ [S1].
    
    First, compute the blurred incident radiance $L_{blurred}(x_0, w)$ at the location $x_0$ (projection of $x$ onto the incident plane perpendicular to light) with width $w$:
    $$ L_{blurred}(x_0, w) = \frac{(\bar{b}/\pi\langle \theta^2 \rangle)}{2} \int L_0(x) \exp\left(-\frac{(x-x_0)^2}{2w^2}\right) dA $$
    In practice, this integral is approximated using the object image. The contribution of all paths surrounding the MPP is weighted by a Gaussian. The effective area per path is estimated using global averages, leading to the simplified form for $L_{MS}$ when combined with the object image [S1]:
    $$ L_{MS}(x, \vec{\omega}) = L_{obj}(\vec{\omega}) \exp\left(-\frac{c \ell_{obj}}{b}\right) \ell_{obj} \left(1 + \frac{2\bar{b}^2 w(\ell_{obj}, s_{obj})^2}{\langle \theta^2 \rangle}\right) $$
    *Note: The sources indicate that using the unfiltered object image $L_{obj}$ is acceptable and avoids runtime filtering penalties [S1].*

    Alternatively, the general integral form for $L_{MS}$ at point $x$ for a specific $\ell$ is:
    $$ L_{MS}(x, \vec{\omega}) = \int d\ell \, \exp\left(-\frac{c}{b} \ell(MPP_\ell)\right) \exp(-A_c(MPP_\ell)) \times P_{MS}(\ell, \vec{\omega} - \vec{\omega}_0) \times L_{blurred}(x_0, w(\ell)) $$
    Where $A_c$ is the curvature attenuation term. **Pitfall:** The original model includes a curvature term $A_c$ which penalizes short paths with large angle changes, severely underestimating backscattering. The recommended implementation **drops the curvature term** $A_c$ to correct this behavior [S1].

6.  **Combine Components**
    The total radiance is the sum:
    $$ L(x, \vec{\omega}) = W \cdot L_{obj}(x, \vec{\omega}) + L_{SS}(x, \vec{\omega}) + L_{MS}(x, \vec{\omega}) $$
    [S1]

### Formulas and Definitions

**Number of Scattering Events ($\ell$):**
$$ \ell = \int_{path} b(x) ds $$
where $b(x)$ is the scattering coefficient [S1].

**Blurring Width ($w$):**
The standard deviation of the Gaussian weighting for paths with $\ell$ scattering events and physical length $s$:
$$ w(\ell, s)^2 = \frac{\theta^2 \ell s^2}{24} \left(1 + \frac{\theta^2 (a/b) \ell^2}{12}\right) $$
where $\theta^2$ is the mean square scattering angle, $s$ is the physical length of the path, and $a/b$ is the ratio of absorption to scattering coefficients [S1].

**Multiple Scattering Phase Function ($P_{MS}$):**
$$ P_{MS}(\theta, \ell) = N \cdot P\left(\frac{\theta}{\sqrt{\ell(1 - \exp(-\ell))}}\right) $$
where $N$ is a normalization constant and $P$ is the single scattering phase function [S1].

**Object Image Weight ($W$):**
$$ W = \left(1 + \ell_{obj} + \frac{2\bar{b}^2 w(\ell_{obj}, s_{obj})^2 \ell_{obj}}{\langle \theta^2 \rangle}\right) \exp\left(-\frac{c \ell_{obj}}{b}\right) $$
where $\ell_{obj}$ is the scattering events from the object to the eye, and $\bar{b}$ is the global average scattering coefficient [S1].

**Single Scattering Increment:**
$$ \Delta L_{SS}(x, \vec{\omega}) = L_0 \exp\left(-\frac{c}{b} \ell_{light}\right) P(x, \vec{\omega}, \vec{\omega}_0) \exp\left(-\frac{c}{b} \ell_{eye}\right) b(x) \Delta x $$
[S1]

### Parameters
*   $\ell$: Number of scattering events along the path.
*   $s$: Distance along the path (arclength).
*   $w$: Blurring width (standard deviation of the Gaussian filter).
*   $\langle \theta^2 \rangle$: Mean square scattering angle (characterizes angular distribution).
*   $c(x)$: Extinction coefficient, $c(x) = a(x) + b(x)$.
*   $b(x)$: Scattering coefficient.
*   $a(x)$: Absorption coefficient.
*   $\bar{b}$: Global average scattering coefficient.
*   $\gamma$: Rate adjustment parameter for multiple scattering attenuation. $\gamma=1$ for the original model; $\gamma=0.45$ provides better fits to Monte Carlo simulations for denser media [S1].

### Edge Cases and Pitfalls
1.  **Backscattering Underestimation:** The original MPP model includes a curvature attenuation term $A_c$ that penalizes short paths with large angle changes. This causes severe underestimation of backscattering. **Solution:** Drop the curvature term $A_c$ from the multiple scattering integral [S1].
2.  **Dimensional Inconsistency:** Integrating weighted radiance in the incident plane yields units of radiance $\times$ area, which is incorrect. An effective area per path (or number of contributing paths) must be included. The derivation using global averages $\bar{b}$ and $\langle \theta^2 \rangle$ corrects this [S1].
3.  **Boundary Artifacts:** Unlike diffusion-based methods, MPP handles boundaries and low-density areas correctly because it does not assume optical thickness or uniform media [S1].
4.  **Object Image Filtering:** Using the unfiltered object image $L_{obj}$ instead of a blurred version avoids runtime filtering penalties and does not produce visually objectionable artifacts [S1].

## Operating characteristics
*   **Time Complexity:** The method requires a preprocessing step to build the Light Volume ($O(V)$ where $V$ is volume size) and a single volume sweep for rendering ($O(R \cdot N)$ where $R$ is rays and $N$ is samples per ray). The integration of the blurred radiance is approximated analytically or via simple lookups, avoiding expensive iterative integration.
*   **Memory Complexity:** Requires storage for the medium volume ($b(x)$), the Light Volume ($\ell_{light}$), and the object image. The Light Volume is a 3D structure, increasing memory footprint compared to single scattering methods [S1].
*   **Performance:** The reformulation allows single and multiple scattering to be computed in a single volume sweep, improving performance over the original software implementation which required separate 3D blurring volumes and adaptive step sizes [S1].
*   **Strengths:** Handles general inhomogeneous media; avoids artifacts near boundaries and low-density areas where diffusion approximation fails; incorporates volumetric shadows and object-medium interactions; suitable for hardware implementation (e.g., OpenGL pipeline) [S1].
*   **Limitations:** Assumes strong forward scattering; the approximation of MPPs by straight line segments may introduce errors for highly curved paths; the use of global averages ($\bar{b}$) for area estimation is a crude approximation [S1].
*   **When to Use:** General participating media with strong forward scattering, where inhomogeneity is significant, and interactive or near-real-time performance is desired.
*   **When Not to Use:** Media with isotropic or backward-scattering dominant phase functions (due to backscattering underestimation if curvature term is not handled, though dropping it helps); extremely dense media where diffusion might be more accurate (though MPP can be tuned with $\gamma$) [S1].

## Background
The Most Probable Paths (MPP) lighting model was introduced by Premože et al. in 2004 [S1]. It builds on pioneering work by Tessendorf (1987) and Premože et al. (2003), who introduced the concept of the most probable path for light in strongly forward-scattering inhomogeneous media [S1]. The 2004 paper extended this to a general lighting model for participating media, splitting radiance into object, single-scattered, and multiple-scattered components. It was designed to overcome limitations of previous methods that assumed planar surfaces, uniform media, and optical thickness (leading to diffusion approximation), which produced artifacts near boundaries and low-density areas [S1]. The model was implemented in an OpenGL pipeline using NVIDIA CG, demonstrating its suitability for hardware acceleration [S1].
