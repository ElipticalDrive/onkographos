# Most Probable Paths (MPP) Lighting Model

Also called: General Participating Media Lighting Model, MPP model, MPP-based lighting model, Most Probable Path (MPP) Multiple Scattering Model, Multiple Scattering approximation using MPP, Premože et al. 2004 model

## Overview
The Most Probable Paths (MPP) model is a lighting approximation for general participating media that decomposes radiance into object, single-scattered, and multiple-scattered components [S1]. It approximates the multiple-scattering term ($L_{MS}$) by summing contributions only over paths close to the Most Probable Path (MPP), assuming strong forward scattering [S1]. Unlike diffusion-based methods that fail in low-density regions or near boundaries, this model handles inhomogeneous media and incorporates volumetric shadows and object-media interactions [S1].

## How it works
The model computes the total radiance $L(x, \vec{\omega})$ arriving at the eye from direction $\vec{\omega}$ at position $x$ as the sum of three terms [S1]:
$$ L(x, \vec{\omega}) = W \cdot L_{obj}(x, \vec{\omega}) + L_{SS}(x, \vec{\omega}) + L_{MS}(x, \vec{\omega}) $$
where $L_{obj}$ is the direct object radiance (shadowed by the medium), $L_{SS}$ is single-scattered light, and $L_{MS}$ is the multiple-scattered light approximated via MPPs [S1].

### Inputs and Outputs
*   **Inputs:**
    *   Medium density field $\rho(x)$, from which coefficients are derived: $a(x) = \sigma_a \rho(x)$, $b(x) = \sigma_s \rho(x)$, $c(x) = a(x) + b(x)$ [S1].
    *   Phase function $P(\theta)$, assumed strongly forward-scattering with mean square scattering angle $\langle \theta^2 \rangle$ [S1].
    *   Light source direction $\vec{\omega}_0$ and intensity $L_0$ (directional light assumed for core derivation) [S1].
    *   Object image $L_{obj}$, rendered without participating media effects (except shadows) [S1].
*   **Outputs:**
    *   Final radiance $L(x, \vec{\omega})$ for each pixel/volume sample [S1].

### Data Structures
1.  **Light Volume:** A 3D data structure storing $\ell_{light}$ (scattering events from volume cell to light) for every volume cell. The volume is oriented such that the z-axis aligns with the light direction $\vec{\omega}_0$ [S1]. This acts as a deep shadow map [S1].
2.  **Object Image:** 2D texture containing $L_{obj}$ [S1].

### Parameters
*   $\ell$: Number of scattering events along a path, $\ell = \int_{path} b(x) ds$ [S1].
*   $s$: Physical length (arclength) of the path [S1].
*   $\langle \theta^2 \rangle$: Mean square scattering angle, assumed constant for the medium [S1].
*   $\bar{b}$: Global average of the scattering coefficient, used for area estimation in blurring [S1].
*   $\gamma$: Rate adjustment parameter for multiple scattering attenuation. $\gamma=1$ for the original model; $\gamma=0.45$ provides better fits to Monte Carlo simulations for denser media [S1].

### Formulas and Definitions

**1. Single-Scattered Radiance ($L_{SS}$)**
For a directional light $\vec{\omega}_0$, the contribution from a segment $\Delta x$ at position $x$ along the viewing ray is [S1]:
$$ \Delta L_{SS}(x, \vec{\omega}) = L_{unscat}(x, \vec{\omega}_0) P(x, \vec{\omega}, \vec{\omega}_0) \exp\left(-\frac{c}{b}\ell_{eye}\right) b(x) \Delta x $$
where $L_{unscat}(x, \vec{\omega}_0) = L_0 \exp\left(-\frac{c}{b}\ell_{light}\right)$ is the unscattered light available at $x$ [S1].

**2. Multiple-Scattered Radiance ($L_{MS}$)**
The model approximates $L_{MS}$ by integrating over MPPs characterized by different scattering event counts $\ell$ [S1]:
$$ L_{MS}(x, \vec{\omega}) = \int d\ell \, \exp\left(-\gamma \frac{c}{b}\ell_{MPP(\ell)}\right) \exp(-A_c(MPP_\ell)) \times P_{MS}(\ell, \vec{\omega} - \vec{\omega}_0) \times L_{blurred}(x_0, w(\ell)) $$
*Note: The implementation described in [S1] simplifies this integral into a discrete sum over precomputed $\ell$ values or a specific analytic form derived for the object weight. The core approximation replaces the curved MPP with two straight segments: $\ell_{eye}$ (eye to scattering point) and $\ell_{light}$ (scattering point to light), with total $\ell = \ell_{eye} + \ell_{light}$ [S1].*

**3. Blurred Incident Radiance ($L_{blurred}$)**
This term represents the Gaussian-weighted incident radiance in the plane perpendicular to the light direction at the MPP location [S1]:
$$ L_{blurred}(x_0, w) = \frac{\bar{b}}{\pi \langle \theta^2 \rangle} \int L_0(x) \exp\left(-\frac{(x-x_0)^2}{2w^2}\right) dA $$
where $w$ is the standard deviation of the Gaussian [S1].

**4. Gaussian Width ($w$)**
The width depends on the path's $\ell$, physical length $s$, and media parameters [S1]:
$$ w(\ell, s)^2 = \frac{\langle \theta^2 \rangle \ell s^2}{24} \left(1 + \frac{\langle \theta^2 \rangle (a/b) \ell^2}{12}\right) $$
[G] In implementation, $s$ is approximated by the distance between the eye and the light source intersection with the MPP plane, or derived from $\ell$ and average density if exact path length is unknown.

**5. Multiple Scattering Phase Function ($P_{MS}$)**
Related to the single scattering phase function $P$ by argument substitution and renormalization [S1]:
$$ P_{MS}(\theta, \ell) = N \cdot P\left(\frac{\theta}{\sqrt{\ell(1 - \exp(-\ell))}}\right) $$
where $N$ is a normalization constant [S1].

**6. Object Image Weight ($W$)**
To account for the object's contribution through the medium, a weight $W$ is applied to the unfiltered object image $L_{obj}$ [S1]:
$$ W = \left(1 + \ell_{obj} + \frac{2\bar{b}^2 w^2 \ell_{obj}}{\langle \theta^2 \rangle}\right) \exp\left(-\frac{c}{b}\ell_{obj}\right) $$
where $\ell_{obj}$ is the scattering events from the object to the eye [S1].

### Pseudocode

```python
def compute_mpp_radiance(x, omega, omega_0, L_obj, light_volume, params):
    """
    Computes radiance at point x in direction omega.
    x: 3D position vector
    omega: View direction vector
    omega_0: Light direction vector
    L_obj: Function returning object radiance L_obj(omega)
    light_volume: 3D array storing l_light values
    params: Dictionary containing sigma_a, sigma_s, theta_sq, gamma, b_bar
    """
    
    # 1. Retrieve precomputed l_light from Light Volume
    # The light volume is oriented with z-axis along omega_0.
    # Project x onto the light direction to find the index in light_volume.
    l_light = light_volume.query(x, omega_0)
    
    # 2. Compute l_eye by marching from x towards the eye (or assume ray origin)
    # For a single point evaluation, l_eye is integral of b(x) from x to eye.
    # In a full renderer, this is accumulated during the volume sweep.
    # Here we assume l_eye is provided or computed via a separate pass.
    l_eye = compute_l_eye(x, params) 
    
    # Total scattering events
    l_total = l_light + l_eye
    
    # 3. Compute Single Scattering Contribution (L_SS)
    # L_unscat at x
    c_x = params.sigma_a + params.sigma_s # Extinction at x
    b_x = params.sigma_s                  # Scattering at x
    L_unscat = params.L0 * exp(-gamma * (c_x / b_x) * l_light)
    
    # Phase function P(x, omega, omega_0)
    cos_theta = dot(omega, omega_0)
    P_val = phase_function(cos_theta)
    
    # Delta L_SS for a small segment dx (or normalized per unit length)
    # Note: In a discrete volume renderer, this is integrated over the voxel.
    L_SS = L_unscat * P_val * exp(-gamma * (c_x / b_x) * l_eye) * b_x
    
    # 4. Compute Multiple Scattering Contribution (L_MS)
    # Approximation using the analytic weight derived for the object image
    # and the blurred radiance concept.
    
    # Calculate Gaussian width w
    # s is the physical length of the MPP. Approximated as distance(x, eye) + distance(x, light_plane)
    # Or more accurately, derived from l_total and average density.
    # Using the formula from [S1]:
    # w^2 = (theta_sq * l * s^2 / 24) * (1 + theta_sq * (a/b) * l^2 / 12)
    # We need s. Let's approximate s using l_total and average b_bar.
    # l = integral(b ds) => s approx l / b_bar
    s_approx = l_total / params.b_bar
    
    w_sq = (params.theta_sq * l_total * s_approx**2 / 24) * \
           (1 + params.theta_sq * (params.sigma_a / params.sigma_s) * l_total**2 / 12)
    w = sqrt(w_sq)
    
    # Calculate Blurred Radiance L_blurred
    # L_blurred(x0, w) = (b_bar / (pi * theta_sq)) * integral(L0(x) exp(-(x-x0)^2/2w^2) dA)
    # In implementation, this is often precomputed or approximated by a 2D blur of the light source projection.
    # For this pseudocode, we assume a function that returns the blurred incident radiance
    # at the MPP location (projected x onto plane perpendicular to omega_0).
    L_blurred = compute_blurred_radiance(x, w, params)
    
    # Multiple Scattering Phase Function P_MS
    # P_MS(theta, l) = N * P(theta / sqrt(l * (1 - exp(-l))))
    # Effective angle for phase function
    denom = sqrt(l_total * (1 - exp(-l_total)))
    effective_theta = acos(dot(omega, omega_0)) / denom if denom > 0 else 0
    P_MS_val = N * phase_function(cos(effective_theta)) # N is normalization constant
    
    # Attenuation term for MPP
    # exp(-gamma * (c/b) * l_MPP)
    # Note: The original model uses c/b. The modified model uses gamma.
    # The term exp(-Ac) is dropped to correct backscattering [S1].
    MPP_attenuation = exp(-gamma * (c_x / b_x) * l_total)
    
    L_MS = MPP_attenuation * P_MS_val * L_blurred
    
    # 5. Compute Object Image Weight (W)
    # W = (1 + l_obj + (2 * b_bar^2 * w^2 * l_obj) / theta_sq) * exp(-c * l_obj / b)
    # l_obj is l_eye in the context of light leaving the object to the eye.
    l_obj = l_eye
    
    W = (1 + l_obj + (2 * params.b_bar**2 * w_sq * l_obj) / params.theta_sq) * \
        exp(-gamma * (c_x / b_x) * l_obj)
        
    # 6. Combine
    L_obj_val = L_obj(omega)
    
    return W * L_obj_val + L_SS + L_MS
```

### Edge Cases and Pitfalls
*   **Backscattering Underestimation:** The original model penalizes short paths with large angle changes via the curvature term $A_c$. This causes underestimation of backscattering. The recommended implementation drops the curvature term [S1].
*   **Dimensional Consistency:** Integrating weighted radiance in the incident plane yields units of radiance $\times$ area. An effective area per path (or number of contributing paths) must be included, handled by the factor $\frac{\bar{b}}{\pi \langle \theta^2 \rangle}$ in $L_{blurred}$ [S1].
*   **Object Image Filtering:** Using a blurred version of the object image $L_{obj}$ is more accurate but computationally expensive. The model uses the unfiltered object image with the weight $W$ to avoid runtime filtering penalties, which is visually acceptable [S1].
*   **Attenuation Rate:** The original exponential attenuation rate may not fit dense media well. Using $\gamma = 0.45$ instead of $1$ improves fit to Monte Carlo simulations [S1].

## Operating characteristics
*   **Time Complexity:** The model allows single and multiple scattering to be computed in a single volume sweep, unlike earlier versions requiring separate 3D blurring volumes and adaptive step sizes [S1]. The preprocessing step requires computing the Light Volume ($\ell_{light}$), which is a deep shadow map computation [S1].
*   **Memory Complexity:** Requires storage for the main density volume, the Light Volume ($\ell_{light}$), and the Light Image (preprocessed incident illumination) [S1]. This is more memory-intensive than pure single-scattering models but less than full Monte Carlo or multi-pass diffusion methods.
*   **Strengths:** Handles general inhomogeneous media; avoids artifacts near boundaries and low-density areas where diffusion fails; incorporates volumetric shadows and object-media interactions; efficient single-sweep implementation [S1].
*   **Limitations:** Assumes strong forward scattering; relies on approximations for the MPP and Gaussian width; $\gamma$ parameter requires tuning for different media densities [S1].
*   **When to use:** Real-time or interactive rendering of participating media with significant multiple scattering effects, especially in inhomogeneous environments or near object boundaries.
*   **When not to use:** Media with isotropic or backward-scattering dominant phase functions, or where high physical accuracy of backscattering is critical without parameter tuning.

## Background
The MPP model was introduced by Premože et al. in 2004 [S1]. It builds on pioneering work by Tessendorf (1987) and Premože et al. (2003), who introduced the concept of the Most Probable Path (MPP) for strongly forward-scattering inhomogeneous media [S1]. The 2004 paper extended this to a general lighting model for participating media, addressing limitations of previous methods that assumed planar surfaces, uniform media, and optical thickness (diffusion approximation) [S1]. The method was implemented in OpenGL using NVIDIA CG [S1].
