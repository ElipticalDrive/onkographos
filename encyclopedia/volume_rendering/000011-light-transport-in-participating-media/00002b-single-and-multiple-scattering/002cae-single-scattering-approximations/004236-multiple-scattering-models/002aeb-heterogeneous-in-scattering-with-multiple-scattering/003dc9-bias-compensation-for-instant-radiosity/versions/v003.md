# Bias Compensation for Instant Radiosity

Also called: Singularity handling via geometric term bounding

## Overview
Bias Compensation for Instant Radiosity is an unbiased method to handle weak singularities (infinite variance) in Instant Radiosity when volume points are close to light sources, by bounding the geometric term and recursively compensating for the introduced bias [S1].

## How it works
**Inputs and Outputs:**
The method takes a point $y$, a direction $z$, a bound $b$, and scene data (phase function, transmittance, geometric term) as inputs, and returns the unbiased radiance correction term [S1].

**Data Structures:**
Not given in the sources.

**Definitions:**
* $G(x \leftrightarrow y)$: The standard geometric term between points $x$ and $y$ [S1].
* $b$: An arbitrary positive bound ($b \in \mathbb{R}^+$) used to cap the geometric term [S1].
* $L(x \rightarrow y)$: Radiance arriving at $y$ from $x$ [S1].
* $f(x \rightarrow y \rightarrow z)$: The phase function or BSDF [S1].
* $V(x \leftrightarrow y)$: Visibility term (1 if visible, 0 otherwise) [S1].
* $\tau(y - t\omega \leftrightarrow y)$: Transmittance from $y$ to $y - t\omega$ [S1].
* $d\sigma^*(\omega)$: The modified differential solid angle, defined as:
  $$
  d\sigma^*(\omega) = \begin{cases} |\cos \theta_y| d\sigma(\omega) & \text{if } y \in \partial \mathcal{V} \text{ (surface)} \\ d\sigma(\omega) & \text{if } y \in \mathcal{V} \text{ (volume)} \end{cases}
  $$
  where $\theta_y$ is the angle between the surface normal at $y$ and the direction $\omega$ [S1].

**Numbered Steps:**
1. **Define Modified Geometric Term:** Replace the standard geometric term $G(x \leftrightarrow y)$ with a bounded version $G'(x \leftrightarrow y)$ [S1]:
   $$
   G'(x \leftrightarrow y) := \begin{cases} G(x \leftrightarrow y) & \text{if } G(x \leftrightarrow y) < b \\ b & \text{otherwise} \end{cases} \quad (14)
   $$
2. **Formulate Bias Integral:** The bias introduced by using $G'$ instead of $G$ in the evaluation of $L(y \rightarrow z)$ is given by [S1]:
   $$
   L(y \rightarrow z) - L'(y \rightarrow z) = \int_{\mathbb{R}^3} L(x \rightarrow y) f(x \rightarrow y \rightarrow z) \cdot \frac{\max\{G(x \leftrightarrow y) - b, 0\}}{G(x \leftrightarrow y)} \cdot G(x \leftrightarrow y) V(x \leftrightarrow y) d\lambda(x) \quad (15)
   $$
3. **Reformulate to Spherical Coordinates:** Change the integration domain from $\mathbb{R}^3$ to spherical coordinates centered at $y$ [S1]. The integral becomes [S1]:
   $$
   \int_{S^2} \int_0^{\|h(y, -\omega) - y\|} \tau(y - t\omega \leftrightarrow y) L(y - t\omega \rightarrow y) f(y - t\omega \rightarrow y \rightarrow z) \cdot \frac{\max\{G(y - t\omega \leftrightarrow y) - b, 0\}}{G(y - t\omega \leftrightarrow y)} dt d\sigma^*(\omega)
   $$
4. **Recursive Estimation:** To estimate the bias term [S1]:
   a. Sample a direction $\omega$ from the projected BSDF or phase function [S1].
   b. Sample a distance $t$ from the transmittance $\tau$ [S1].
   c. Compute the next vertex $x = y - t\omega$ [S1].
   d. Recursively estimate $L(x \rightarrow y)$ [S1].
   e. Weight the result by the factor [S1]:
   $$
   w = \frac{\max\{G(x \leftrightarrow y) - b, 0\}}{G(x \leftrightarrow y)}
   $$
5. **Termination:** If $G(x \leftrightarrow y) \le b$, the weight $w$ is 0 [S1]. The path can be terminated at this point because the contribution is nullified [S1].

**Pseudocode:**
```python
def bias_compensation(y, z, b, phase_func, transmittance, geometric_term):
    # [S1] Sample direction omega from projected phase function.
    # Implementation details not given in sources.
    omega = sample_projected_phase_function(y)
    
    # [S1] Sample distance t from transmittance tau along -omega.
    # Implementation details not given in sources.
    t = sample_transmittance_distance(y, -omega)
    
    # [S1] Compute next vertex x = y - t * omega
    x = y - t * omega
    
    # [S1] Compute geometric term G(x <-> y)
    G_xy = geometric_term(x, y)
    
    # [S1] If G_xy <= b, weight is 0; terminate recursion
    if G_xy <= b:
        return 0.0
    
    # [S1] Calculate weight w = max{G(x <-> y) - b, 0} / G(x <-> y)
    weight = (G_xy - b) / G_xy
    
    # [S1] Recursively estimate L(x -> y)
    L_x_to_y = bias_compensation(x, y, b, phase_func, transmittance, geometric_term)
    
    # [S1] Return weighted recursive estimate
    return weight * L_x_to_y
```

**Edge Cases and Pitfalls:**
* **Choice of $b$:** The efficiency depends heavily on the choice of bound $b$ [S1]. Bright spots in weakly illuminated areas can be caused by close-by point lights if $b$ is not chosen carefully [S1].
* **Point Lights:** Special care is needed for point lights [S1]. Options to mitigate this include bounding point light contributions and bias compensation to the same maximum value, or using radiance estimates to bound point light source contributions [S1].
* **Bounding:** The contribution of the bias compensation step is always bounded by the brightness of the scene's light source [S1].

## Background
The method extends the bias compensation technique from [KK04] to participating media [S1]. It is based on the observation that bounding the geometric term $G$ in Instant Radiosity avoids the weak singularity but introduces bias [S1]. By reformulating the bias integral and estimating it recursively, the method achieves unbiased results [S1]. The approach is interpreted as a special case of Bidirectional Path Tracing where weighting functions are constructed with respect to the value of the geometric term [S1].
