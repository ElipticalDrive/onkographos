# Heterogeneous In-scattering with Multiple Scattering


## Overview
This method computes the radiance contribution from light scattering within a heterogeneous participating medium, handling both direct lighting from light sources and recursively computing indirect lighting (multiple scattering) up to a maximum depth [S1, unofficial]. It extends the single-scattering approximation by adding a recursive term for indirect illumination, allowing for more realistic lighting in dense or high-albedo volumes [S1, unofficial]. Unlike its siblings which truncate the scattering series after the first term [S2, unofficial][S3], this approach approximates the second and higher-order scattering events through a limited-depth recursion, addressing the "abnormally dark" shadowing defects seen in single-scattering models for high-albedo media like clouds [S2, unofficial].

## How it works
The method operates in two main phases: computing the total radiance for a ray segment (including surface interactions) and recursively computing the in-scattered radiance for a specific point in the volume.

### Data Structures
*   **Ray**: Origin $\mathbf{o}$, direction $\boldsymbol{\omega}$, length $t_{max}$.
*   **Volume Density Field**: Heterogeneous density $\rho(\mathbf{x})$ or optical coefficients $\sigma_t(\mathbf{x}), \sigma_s(\mathbf{x}), \sigma_a(\mathbf{x})$ sampled at any point $\mathbf{x}$.
*   **Scene Geometry**: A bounding volume hierarchy or similar structure to determine intersections for shadow rays and surface reflections.
*   **Light Sources**: List of lights with position $\mathbf{l}_i$, intensity $I_i$, and area $A_i$.

### Parameters
*   $\mu_a$: Base absorption coefficient. Typical value: $0.05$ [S1, unofficial].
*   $\mu_s$: Base scattering coefficient. Typical value: $0.1$ [S1, unofficial].
*   $MaxDepth$: Maximum recursion depth for multiple scattering. Typical value: $5$ [S1, unofficial].
*   $N_{steps}$: Number of steps for transmittance integration to light. Typical value: $16$ [S1, unofficial].

### Step 1: Compute Total Radiance for a Ray Segment
This function computes the final color for a ray segment from origin $\mathbf{o}$ to intersection $\mathbf{p}_{hit}$ (or far plane if no hit).

1.  **Find Intersection**: Cast a ray from $\mathbf{o}$ in direction $\boldsymbol{\omega}$. Let $\mathbf{p}_{hit}$ be the closest intersection point. If no intersection, return background radiance:
    $$ L_{bg} = L_{ambient} + L_{bgColor} \cdot \exp\left(-(\mu_a + \mu_s) \cdot \bar{\rho} \cdot 10.0\right) $$
    where $\bar{\rho}$ is the average density, clamped to a minimum of $0.2$ [S1, unofficial].
2.  **Compute In-scattering**: Calculate the volumetric in-scattering contribution $L_{inscatter}$ for the segment $[\mathbf{o}, \mathbf{p}_{hit}]$ using the recursive `computeInscattering` function (see Step 2).
3.  **Add Surface Emission**: If $\mathbf{p}_{hit}$ is on a surface, add the surface emission:
    $$ L_{emission} = L_{emissive} \cdot T(\mathbf{o}, \mathbf{p}_{hit}) $$
    where $T(\mathbf{o}, \mathbf{p}_{hit})$ is the transmittance from eye to hit point [S1, unofficial].
4.  **Add Surface Reflection**: If current recursion depth $< MaxDepth$, compute the reflected radiance from the surface at $\mathbf{p}_{hit}$ (including direct and indirect components) and add to the total:
    $$ L_{reflected} = L_{refl} \cdot T(\mathbf{o}, \mathbf{p}_{hit}) $$
5.  **Return**: Sum of $L_{inscatter}$, $L_{emission}$, and $L_{reflected}$ [S1, unofficial].

### Step 2: Compute In-scattering at a Point
This recursive function computes the in-scattered radiance at a point $\mathbf{x}$ in the volume.

1.  **Check Interaction**: Sample the extinction coefficient $\sigma_t(\mathbf{x})$ and scattering coefficient $\sigma_s(\mathbf{x})$ at $\mathbf{x}$. If $\sigma_t(\mathbf{x}) < 0.0001$, return $0$ (no interaction) [S1, unofficial].
2.  **Calculate Single Scattering Albedo**:
    $$ p_{scatter} = \frac{\sigma_s(\mathbf{x})}{\sigma_t(\mathbf{x})} $$
3.  **Initialize Radiance**: $L_{inscatter} = 0$.
4.  **Direct Lighting**: For each light source $i$:
    a.  Sample the light position $\mathbf{l}_i$.
    b.  Cast a shadow ray from $\mathbf{x}$ to $\mathbf{l}_i$. If occluded, skip.
    c.  Compute transmittance $T_{to\_light}$ from $\mathbf{x}$ to $\mathbf{l}_i$ using $N_{steps}$ integration [S1, unofficial].
    d.  Accumulate contribution:
        $$ L_{direct} += I_i \cdot p(\boldsymbol{\omega}_i, \boldsymbol{\omega}_o) \cdot \frac{A_i}{\|\mathbf{l}_i - \mathbf{x}\|^2} \cdot T_{to\_light} $$
        Note: The source code uses a hardcoded isotropic phase function $1/(4\pi)$ for both direct and indirect contributions, ignoring the material's specific phase function [S1, unofficial].
5.  **Indirect Lighting (Multiple Scattering)**: If current depth $< MaxDepth$:
    a.  Sample a hemisphere direction $\boldsymbol{\omega}_s$ using a HemisphericalSampler.
    b.  Cast a ray from $\mathbf{x}$ in direction $\boldsymbol{\omega}_s$.
    c.  If the ray hits an object at $\mathbf{p}_{surf}$:
        i.  Recursively call `computeInscattering` for the segment from $\mathbf{x}$ to $\mathbf{p}_{surf}$ to get $L_{indirect}$.
        ii. Add to $L_{inscatter}$:
            $$ L_{indirect\_contrib} = L_{indirect} \cdot \rho_{albedo} \cdot T(\mathbf{x}, \mathbf{p}_{surf}) \cdot \frac{1}{4\pi} $$
            where $\rho_{albedo}$ is the surface albedo [S1, unofficial].
6.  **Return**: $L_{inscatter}$ [S1, unofficial].

def compute_inscattering_at_point(x, depth):
    """
    Computes in-scattered radiance at a point x.
    """
    # 1. Check interaction
    sigma_t = get_extinction(x)
    sigma_s = get_scattering(x)
    
    if sigma_t < 0.0001:
        return 0.0
    
    # 2. Single scattering albedo
    p_scatter = sigma_s / sigma_t
    
    L_inscatter = 0.0
    
    # 3. Direct Lighting
    for light in lights:
        # Sample light position
        l_pos = light.position
        l_dir = normalize(l_pos - x)
        dist = length(l_pos - x)
        
        # Shadow ray
        if not scene.is_occluded(x, l_pos):
            # Transmittance to light
            T_to_light = integrate_transmittance(x, l_pos, steps=16)
            
            # Phase function (hardcoded isotropic)
            phase = 1.0 / (4.0 * pi)
            
            # Geometric attenuation
            geo_atten = light.area / (dist * dist)
            
            # Accumulate
            L_inscatter += light.intensity * phase * geo_atten * T_to_light
            
    # 4. Indirect Lighting
    if depth < MaxDepth:
        # Sample hemisphere direction
        omega_s = sample_hemisphere()
        
        # Cast ray
        indirect_ray = Ray(x, omega_s)
        indirect_hit = scene.intersect(indirect_ray)
        
        if indirect_hit:
            # Recursively call for segment up to surface
            # Note: The source says "recursively call computeInscattering for the segment"
            # We assume this means computing the in-scattering contribution from that segment
            L_indirect = integrate_inscattering_segment(x, indirect_hit.point, depth + 1)
            
            # Add to L_inscatter
            # T_to_scatter is transmittance from x to indirect_hit.point
            T_to_scatter = integrate_transmittance(x, indirect_hit.point, steps=16)
            
            # Albedo
            albedo = indirect_hit.material.albedo
            
            # Isotropic phase function for indirect
            phase_indirect = 1.0 / (4.0 * pi)
            
            L_inscatter += L_indirect * albedo * T_to_scatter * phase_indirect
            
    return L_inscatter

def integrate_transmittance(o, p, steps=16):
    """
    Computes transmittance from o to p using numerical integration.
    """
    total_extinction = 0.0
    for i in range(steps):
        t = (i + 0.5) / steps
        x = o + t * (p - o)
        sigma_t = get_extinction(x)
        total_extinction += sigma_t * length(p - o) / steps
        
    return exp(-total_extinction)

### Edge Cases and Pitfalls
*   **Hardcoded Phase Function**: The implementation uses a hardcoded isotropic phase function ($1/(4\pi)$) for both direct and indirect scattering, ignoring the material's specific phase function [S1, unofficial]. This is a significant simplification and may lead to inaccurate lighting for anisotropic materials.
*   **Recursion Depth**: The recursion stops if depth $\ge 5$ [S1, unofficial]. This limits the accuracy of multiple scattering in very dense volumes.
*   **Transmittance Integration**: The transmittance to light is computed using a fixed 16-step integration [S1, unofficial]. This may not be sufficient for highly heterogeneous volumes, leading to artifacts.
*   **Density Sampling**: The method assumes access to a density field $\sigma_t(\mathbf{x})$ and $\sigma_s(\mathbf{x})$. If the density is zero or near-zero, the interaction check returns 0 [S1, unofficial].

### [Correction Texture for Surface Albedo](9421-correction-texture-for-surface-albedo.md)
This method corrects the main scattering texture for light reflected off the ground, which is precomputed assuming a homogeneous mean surface albedo $\bar{a}$. It allows the renderer to remove these homogeneous contributions from the main texture and evaluate surface albedos and reflection characteristics separately at runtime for surfaces with varying properties. This is useful for optimizing real-time rendering where surface albedo varies across the scene.

## Operating characteristics
*   **Time Complexity**: The method is computationally expensive due to the recursive nature of multiple scattering. Each in-scattering computation involves shadow rays and recursive calls, leading to $O(N \cdot L \cdot R)$ complexity, where $N$ is the number of samples, $L$ is the number of lights, and $R$ is the recursion depth [S1, unofficial].
*   **Memory Complexity**: Requires storing the volume density field and scene geometry. The recursion depth is limited, so stack memory is bounded [S1, unofficial].
*   **Performance**: The method is suitable for offline rendering or real-time rendering with limited recursion depth and light counts [S1, unofficial]. The hardcoded isotropic phase function and fixed integration steps may allow for some optimization, but the recursive nature remains a bottleneck.
*   **Strengths**: Handles heterogeneous volumes and multiple scattering, providing more realistic lighting than single-scattering approximations [S1, unofficial].
*   **Limitations**: Computationally expensive, sensitive to density field resolution, and uses simplified phase functions [S1, unofficial].
