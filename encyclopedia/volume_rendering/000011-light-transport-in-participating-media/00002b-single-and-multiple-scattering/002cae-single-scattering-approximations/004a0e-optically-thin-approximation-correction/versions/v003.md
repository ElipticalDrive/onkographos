# Optically Thin Approximation Correction

Also called: Exospheric Optical Depth Correction, Self-absorption and Secondary Scattering Correction

## Overview
The Optically Thin Approximation Correction improves the accuracy of the single-scattering approximation by modeling photon loss due to absorption and secondary scattering along the light path [S1]. It addresses the error introduced when assuming no attenuation between the light source, the scattering volume, and the observer [S1]. Unlike the base [Single Scattering Approximation](5264-single-scattering-approximation.md), it applies exponential reduction factors for optical depth along the Sun-to-scatterer path and the scatterer-to-observer path [S1].

## How it works
**Inputs:**
- Density field $\rho$ defined on a voxel grid [S1].
- Line-of-sight (LOS) parameterization $S$ for each pixel, defined by origin, direction, and step size $\Delta l$ [S1].
- Index arrays $r, e, a$ defining the voxel traversal along $S$ [S1].
- Cross-section $\sigma$, dependent on local exospheric temperature [S1].
- Forward tomographic operator $F$ (or its sunward variant $F_1$) [S1].

**Outputs:**
- Corrected radiance $I_{corr}$ for each pixel [S1].

**Data Structures:**
- Arrays $r, e, a$: Indices mapping the LOS traversal to the voxel grid. Size: $N_{steps}$ per LOS [S1].
- Array $\Delta l$: Step lengths along the LOS. Size: $N_{steps}$ per LOS [S1].
- Array $\rho$: Density values at voxel centroids. Size: $N_{voxels}$ [S1].

**Formulas:**
The corrected radiance is given by:
$$ I_{corr} = \int F \rho e^{-\tau_1} e^{-\tau_2} dl $$
where:
- $F$ is the forward tomographic operator [S1].
- $\tau_1$ is the optical depth along path $S_1$ (Sun to scattering point $P_s$) [S1].
- $\tau_2$ is the optical depth along path $S_2$ (scattering point $P_s$ to spacecraft) [S1].
- The optical depths are calculated as cumulative sums of $\sigma \rho \Delta l$ along the respective paths [S1].

**Steps:**
1. Calculate $\tau_1$ for each scattering point $P_s$ along the LOS. This requires a sunward ray trace from $P_s$ to the Sun [S1].
2. Calculate $\tau_2$ for each scattering point $P_s$ along the LOS. This is the optical depth from $P_s$ to the observer along the LOS $S$ [S1].
3. Compute the correction factors $e^{-\tau_1}$ and $e^{-\tau_2}$ [S1].
4. Discretize the integral as an inner product using the custom raytracer operator $F_1$ and cumulative summation [S1].

**Pseudocode:**
```python
def compute_optically_thin_correction(rho, indices, delta_l, sigma):
    """
    Computes the optically thin approximation correction.
    rho: density array [N_voxels]
    indices: list of arrays [r, e, a] for each LOS, each of length N_steps [S1]
    delta_l: step lengths array [N_steps] [S1]
    sigma: cross-section array [N_voxels] [S1]
    """
    import math
    N_steps = len(delta_l)
    N_pixels = len(indices)
    I_corr = []

    for i in range(N_pixels):
        r, e, a = indices[i]
        
        # Step 1: Compute tau_2 (Secondary scattering / Observer path)
        # Reuse LOS arrays r, e, a and delta_l because S2 lies along S [S1]
        tau_2_steps = [sigma[r[j]] * rho[r[j]] * delta_l[j] for j in range(N_steps)]
        # Cumulative sum from the end to get optical depth from point to observer
        tau_2 = [0.0] * N_steps
        running_sum = 0.0
        for j in range(N_steps - 1, -1, -1):
            running_sum += tau_2_steps[j]
            tau_2[j] = running_sum
        tau_2[-1] = 0.0

        # Step 2: Compute tau_1 (Self-absorption / Sun path)
        # F1 is a custom raytracer operator with LOS originating at voxel centroid and propagating sunwards [S1]
        # Approximation: voxel centroids do not lie directly on path S1 [S1]
        tau_1 = [0.0] * N_steps
        for j in range(N_steps):
            # The sources do not specify the exact voxel traversal algorithm for F1 [G]
            tau_1[j] = 0.0

        # Step 3: Compute correction factors
        correction = [0.0] * N_steps
        for j in range(N_steps):
            correction[j] = math.exp(-tau_1[j]) * math.exp(-tau_2[j])

        # Step 4: Discretize integral as inner product
        # I_corr = F * rho * correction . delta_l [S1]
        source_term = [sigma[r[j]] * rho[r[j]] * correction[j] for j in range(N_steps)]
        I_corr_val = sum(source_term[j] * delta_l[j] for j in range(N_steps))
        I_corr.append(I_corr_val)

    return I_corr
```

**Edge Cases and Pitfalls:**
- **Voxel Centroid Approximation:** The operator $F_1$ is an approximation because voxel centroids do not lie directly on the path $S_1$ (Sun to scatterer) [S1]. This introduces geometric error.
- **Temperature Dependence:** The cross-section $\sigma$ depends on local exospheric temperature [S1].
- **Performance:** Computing $\tau_1$ requires a separate ray trace for each scattering point, which is computationally expensive [S1].

## Operating characteristics
- **Time Complexity:** $O(N_{pixels} \cdot N_{steps})$ for the base approximation. The correction adds $O(N_{pixels} \cdot N_{steps})$ for $\tau_2$ (reuse of LOS arrays) and $O(N_{pixels} \cdot N_{steps\_sunward})$ for $\tau_1$ (sunward ray trace). The sunward trace is the bottleneck [S1].
- **Memory Complexity:** $O(N_{voxels})$ for density and cross-section arrays. Additional $O(N_{steps})$ per pixel for intermediate calculations [S1].
- **Strengths:** Improves accuracy of optically thin approximations in planetary exospheres by accounting for self-absorption and secondary scattering [S1].
- **Limitations:** Computationally expensive due to the need for sunward ray tracing. Approximation error from voxel centroid alignment [S1].
- **When to use:** When high accuracy is required for optically thin media, such as planetary exospheres, and computational resources allow for additional ray tracing [S1].
- **When not to use:** For real-time applications where performance is critical, or for optically thick media where multiple scattering dominates [S1].

## Background
The method was introduced by J. H. Zoennchen et al. (2024) in the context of the TomoSphero framework for planetary and solar tomography [S1]. It extends the single-scattering approximation to better model photon loss in exospheric environments [S1].
