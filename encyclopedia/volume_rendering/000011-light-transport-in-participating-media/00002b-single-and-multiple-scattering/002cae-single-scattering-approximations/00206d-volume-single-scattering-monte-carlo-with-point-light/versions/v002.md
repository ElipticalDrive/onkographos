# Volume Single Scattering (Monte Carlo with Point Light)

Also called: GetLightEnergy, Light Energy Calculation, PBRT SingleScatteringIntegrator::Li, Single Scattering Volume Integration (PBRT Implementation)

## Overview
Computes the radiance contribution of a single scattering event in a homogeneous participating medium by integrating in-scattered light from a point light source along a view ray [S1, unofficial]. It differs from uniform ray marching variants by using Monte Carlo distance sampling to select scattering positions [S1, unofficial]. It is a specific instance of single scattering approximations [5340-single-scattering-approximations.md] tailored for point lights and homogeneous media [S1, unofficial].

## How it works
**Inputs:**
- Ray $r$ with origin $o$ and direction $\omega$ [S1, unofficial].
- Homogeneous volume region with total extinction coefficient $\sigma_t$, scattering coefficient $\sigma_s$, and phase function $p(\omega_i, \omega_o)$ [S1, unofficial].
- Point light source at position $L_{pos}$ with intensity $I$ [S1, unofficial].
- Background radiance $L_{bg}$ computed via a point light model [S1, unofficial].
- Number of Monte Carlo samples $N_{samples}$ [S1, unofficial].

**Outputs:**
- Accumulated radiance $L$ at the pixel [S1, unofficial].

**Data Structures:**
- `Volume`: Provides `getSigmaS()`, `getPhaseFunctionValue()`, `getTransmittanceHomogeneous(t1, t2)` [S1, unofficial].
- `Light`: Provides `getLightPosition()` [S1, unofficial].
- `Sampler`: Provides `sample1DDBG` for distance sampling [S1, unofficial].

**Steps:**
1. **Background Transmittance:** Calculate the intersection distance $t_{max}$ to the background surface [S1, unofficial]. Compute the transmittance from the ray origin to $t_{max}$: $T_{bg} = e^{-\sigma_t t_{max}}$ [S1, unofficial]. Compute the background radiance $L_{bg}$ attenuated by this transmittance [S1, unofficial]. Initialize accumulated radiance $L = L_{bg} \cdot T_{bg}$ [S1, unofficial].
2. **Initialize Accumulator:** Initialize the scattered radiance accumulator $L_s = 0$ [S1, unofficial].
3. **Monte Carlo Integration Loop:** For $i = 0$ to $N_{samples} - 1$:
   a. **Sample Distance:** Sample a distance $t_{sample}$ along the ray from the origin using uniform distance sampling weighted by extinction [S1, unofficial]. The PDF for sampling distance $t$ in a homogeneous medium is $p(t) = \sigma_t e^{-\sigma_t t}$ [G].
   b. **Sample Position:** Calculate the 3D position of the scattering event: $x_{sample} = o + t_{sample} \cdot \omega$ [S1, unofficial].
   c. **Eye Transmittance:** Calculate the transmittance from the eye (ray origin) to the sample point: $T_{eye} = e^{-\sigma_t t_{sample}}$ [S1, unofficial].
   d. **Light Radiance:** Calculate the emitted radiance from the point light at $x_{sample}$ using the point light model [S1, unofficial].
   e. **Light Transmittance:** Calculate the transmittance from the sample point to the light source: $T_{light} = e^{-\sigma_t \|x_{sample} - L_{pos}\|}$ [S1, unofficial].
   f. **Phase Function:** Retrieve the phase function value for the scattering direction [S1, unofficial].
   g. **Accumulate:** Add the contribution to $L_s$, divided by the PDF to correct for the sampling distribution: $L_s = L_s + \frac{L_e \cdot T_{eye} \cdot \sigma_s \cdot p \cdot T_{light}}{p(t_{sample})}$ [S1, unofficial].
4. **Average and Finalize:** Average the scattered radiance over the number of samples and add to the background term: $L = L + \frac{L_s}{N_{samples}}$ [S1, unofficial].

**Pseudocode:**
```python
def VolumeSingleScatteringMC(ray, volume, light, objects, MCsamples):
    t_max = ray.getOrigin().distance_to(ray.getOrigin() + ray.getDirection() * ray.getTMax())
    background = getPixelColorPointLight(objects, 0, t_max, ray, light)
    transmittance_bg = volume.getTransmittanceHomogeneous(t_max)
    Li = background * transmittance_bg
    Ls = 0.0
    sigmaS = volume.getSigmaS()
    pf = volume.getPhaseFunctionValue()
    lightPos = light.getLightPosition()
    
    for _ in range(MCsamples):
        t_sample, pdf = sample1DDBG(ray, lightPos, t_max, volume.getSigmaT(), "Distance")
        x_sample = ray.getOrigin() + ray.getDirection() * t_sample
        T_eye = volume.getTransmittanceHomogeneous(t_sample)
        Le = getPixelColorPointLight(objects, -1, t_sample, ray, light)
        T_light = volume.getTransmittanceHomogeneous(x_sample, lightPos)
        Ls += Le * T_eye * sigmaS * pf * T_light / pdf
        
    Li += Ls / MCsamples
    return Li

def sample1DDBG(ray, light_pos, t_max, sigma_t, mode):
    # Standard exponential distance sampling for homogeneous media [G]
    u = random.uniform(0.0, 1.0)
    t_sample = -math.log(1.0 - u * math.exp(-sigma_t * t_max)) / sigma_t
    pdf = sigma_t * math.exp(-sigma_t * t_sample)
    return t_sample, pdf
```

**Parameters:**
- $t_{max}$: Distance to background intersection [S1, unofficial].
- $\sigma_s$: Scattering coefficient [S1, unofficial].
- $N_{samples}$: Number of Monte Carlo samples [S1, unofficial].

**Edge Cases:**
- If $t_{max}$ is infinity (no background intersection), the background term is 0 or handled as environment map [S1, unofficial].
- If $\sigma_s = 0$, no scattering occurs; return only background [S1, unofficial].
- Precision issues may arise if $t_{sample}$ is very large, causing $T_{eye}$ to underflow to 0 [G].

## Subtopics

### [Ray Marching with In/Out-Scattering and Density Scaling](2318-ray-marching-with-in-out-scattering-and-density-scaling.md)
Computes single scattering radiance by ray marching, explicitly accounting for absorption, out-scattering, emission, and in-scattering. It distinguishes homogeneous from heterogeneous media using density scaling. It differs from the parent Monte Carlo method by using deterministic uniform sampling instead of stochastic distance sampling. Choose it for real-time rendering where deterministic performance is preferred over unbiased variance.

### [Single Scattering Approximation with Precomputed Terms](4188-single-scattering-approximation-with-precomputed-terms.md)
Renders single scattering using pre-computed direction-independent radiance components. It differs from Monte Carlo siblings by replacing stochastic sampling with deterministic ray marching and decoupling angular integration, enabling differentiable density optimization. Choose it when gradients are required or for differentiable rendering pipelines.

### [Analytical Approximation of Single Scattering Radiance](4244-analytical-approximation-of-single-scattering-radiance.md)
Computes in-scattered radiance $J_{ss}$ by approximating the phase function and incident radiance with low-order expansions. It differs from Monte Carlo approaches by avoiding repeated ray tracing for incident light estimation, making it significantly more efficient for multi-viewpoint reconstruction. Choose it for differentiable rendering or scenarios requiring fast gradient computation.

### [Volume Single Scattering (Monte Carlo with Sphere Light)](4549-volume-single-scattering-monte-carlo-with-sphere-light.md)
Computes single-scattering radiance using Monte Carlo integration specifically for sphere lights or environment maps. It differs from the point-light variant by using `getPixelColorWithSphereLight` to sample complex lighting via importance sampling of solid angles. Choose it when the scene contains area lights or environment maps instead of point sources.

### [Volume Single Scattering (Uniform Ray Marching with Point Light Background)](4550-volume-single-scattering-uniform-ray-marching-with-point-lig.md)
Computes single scattering radiance using uniform ray marching with a point light background model. It differs from the parent Monte Carlo method by using deterministic uniform sampling along the ray, and from other ray marching siblings by explicitly decoupling background illumination into a point light function. Choose it for deterministic performance with simple point light backgrounds.

### [BSSRDF Approximation with Dipole and Single Scattering](4750-bssrdf-approximation-with-dipole-and-single-scattering.md)
Approximates subsurface light transport by combining a dipole diffusion model for multiple scattering with a single-scattering term. It differs from volumetric siblings by replacing ray-marching with an analytical diffusion solution for bulk transport, explicitly modeling spatial light spread via dipole sources. Choose it for rendering translucent materials like skin or marble.

### [Physical Atmosphere Color Calculation](4820-physical-atmosphere-color-calculation.md)
Calculates physical sky and sun disk color for a given view direction using Rayleigh and Mie scattering. It differs from siblings by providing a closed-form analytical approximation rather than Monte Carlo integration or lookup tables. Choose it for atmospheric rendering and skybox generation.

### Single Scattering with Direction Variance Culling
Traverses a hierarchy of volume samples top-down, discarding nodes not intersected by the camera ray [S4]. At leaf nodes, it tests direction variance and phase function value, gathering from the leaf if both are below a threshold, otherwise from each sample [S4]. The contribution is scaled by density factor $k_v$: $\text{single} = \alpha \sum_v p(\hat{\boldsymbol{h}}, \hat{\boldsymbol{d}}_v) \frac{I_v}{k_v} (e^{-\sigma_T d_{\text{near}}} - e^{-\sigma_T d_{\text{far}}})$ [S4]. Choose it for hierarchical point-based rendering where adaptive sampling reduces noise [S4].

## Operating characteristics
- **Time Complexity:** $O(N_{samples})$ per ray [G]. Each sample requires a light visibility check and transmittance calculation [G].
- **Memory Complexity:** $O(1)$ auxiliary memory per ray [G].
- **Performance:** Convergence is slow due to high variance in dense volumes [G].
- **Strengths:** Unbiased results for homogeneous media with point lights [S1, unofficial].
- **Limitations:** Computationally expensive and cannot handle multiple scattering [S1, unofficial].
- **When to use:** Offline rendering where bias is unacceptable or real-time with low sample counts [G].
- **When not to use:** Heterogeneous media or when performance is critical [G].

## Background
The method computes single scattering radiance using Monte Carlo integration with uniform sampling along the ray distance, using a point light for background and emission [S1, unofficial]. Implementation details derive from educational ray tracing tutorials and PBRT-style integrators [S1, S3, unofficial].
