# Ray Marching with In/Out-Scattering and Density Scaling

Also called: Out-scattering

## Overview
This method computes single scattering radiance in participating media by ray marching, explicitly accounting for absorption, out-scattering (attenuation), and in-scattering (energy gain) [S2, unofficial]. It distinguishes between homogeneous media (uniform coefficients) and heterogeneous media (spatially varying density) by using a density scalar to scale extinction and scattering terms [S2, unofficial]. Unlike the parent method [Volume Single Scattering (Monte Carlo with Point Light)](2293-volume-single-scattering-monte-carlo-with-point-light.md) which uses Monte Carlo integration, this approach uses deterministic uniform sampling along the ray, and unlike [Single Scattering Approximation with Precomputed Terms](4188-single-scattering-approximation-with-precomputed-terms.md) or [Analytical Approximation of Single Scattering Radiance](4244-analytical-approximation-of-single-scattering-radiance.md), it does not rely on precomputed terms or closed-form solutions but iteratively accumulates light contributions per step [S2, unofficial].

## How it works
### Inputs and Outputs
**Inputs:**
- Ray origin $O$ and direction $D$.
- Medium definition: absorption coefficient $\sigma_a$, scattering coefficient $\sigma_s$, and density scalar $\rho$ [S2, unofficial].
- Light position $L_{pos}$ and color $C_{light}$ [S2, unofficial].
- Background color $C_{bg}$ [S2, unofficial].
- Step size $h$ (distance traveled per ray march step) [S2, unofficial].
- Phase function $p(x, \omega, \omega')$ [S2, unofficial].

**Outputs:**
- Final accumulated radiance [S2, unofficial].

### Data Structures
- **Sample Point**: Position $x$ along the ray [S2, unofficial].
- **Intersection Volume**: Structure containing `inside` (boolean) and `t1` (float, distance from sample to light volume boundary along light direction) [S2, unofficial].
- **Accumulators**:
  - `transparency`: Float, initialized to 1.0. Tracks accumulated transmission along the ray [S2, unofficial].
  - `result`: Float (or vector), initialized to 0.0. Accumulates in-scattered radiance [S2, unofficial].

### Formulas
1.  **Extinction Coefficient**:
    $$ \sigma_t = \sigma_a + \sigma_s $$
    Where $\sigma_a$ is the absorption coefficient and $\sigma_s$ is the scattering coefficient [S1, S2, unofficial]. The source text contains a typo $\sigma_t = \sigma_a + \sigma_t$, but the correct physical definition and code usage confirm $\sigma_t = \sigma_a + \sigma_s$ [S2, unofficial].

2.  **Out-Scattering (Attenuation)**:
    The differential change in incident radiance due to out-scattering is:
    $$ \mathrm{d} L_{\mathrm{i}} (x, \omega) := -\sigma_{\mathrm{s}} (x, \omega) L_{\mathrm{i}} (x, \omega) \; \mathrm{d}t $$
    [S1, unofficial]
    The total attenuation over a step $h$ is computed using Beer's Law:
    $$ T_{step} = e^{-\rho \cdot h \cdot (\sigma_a + \sigma_s)} $$
    [S2, unofficial]

3.  **In-Scattering**:
    The in-scattering radiance equation is:
    $$ L_i(x, \omega) = \sigma_s \int_{S^2} p(x, \omega, \omega') L(x, \omega') d\omega' $$
    [S2, unofficial]
    For a single point light, the incident radiance $L(x, \omega')$ is attenuated by the path from the light to the sample. The light attenuation factor is:
    $$ A_{light} = e^{-\rho \cdot t_1 \cdot (\sigma_a + \sigma_s)} $$
    Where $t_1$ is the distance the light travels through the volumetric sphere to the sample [S2, unofficial].

4.  **Phase Function**:
    $p(x, \omega, \omega')$ models the angular distribution of scattered light [S2, unofficial]. It returns a value in $[0, 1]$ and integrates to 1 over the sphere of directions $S^2$ [S2, unofficial].

### Parameters
- $\sigma_a$: Absorption coefficient. Typical value: 0.5 [S2, unofficial].
- $\sigma_s$: Scattering coefficient. Typical value: 0.5 [S2, unofficial].
- $\rho$: Density. Scales $\sigma_a$ and $\sigma_s$ globally. Typical value: 1.0 [S2, unofficial].
- $h$: Step size [S2, unofficial].

### Pseudocode
```python
def ray_march_in_out_scattering(ray_origin, ray_direction, light_pos, light_color, background_color, sigma_a, sigma_s, density, step_size, phase_func, light_radius):
    # Initialize accumulators
    transparency = 1.0
    result = 0.0
    current_pos = ray_origin
    
    # Iterate along the ray until transparency is negligible or max steps reached
    # Not given in the sources.
    max_steps = 100 
    for i in range(max_steps):
        # 1. Compute sample transmission (Out-scattering/Attenuation)
        sigma_t = sigma_a + sigma_s
        sample_attenuation = exp(-density * step_size * sigma_t)
        transparency *= sample_attenuation
        
        # 2. Calculate In-Scattering Contribution
        light_dir = normalize(light_pos - current_pos)
        
        # Check intersection with light volume and compute t1
        # Standard ray-sphere intersection logic [G]
        oc = current_pos - light_pos
        b = dot(oc, light_dir)
        c = dot(oc, oc) - light_radius * light_radius
        disc = b * b - c
        isect_inside = False
        t1 = 0.0
        if disc >= 0:
            t = -b - sqrt(disc)
            if t < 0: t = -b + sqrt(disc)
            if t > 0:
                isect_inside = True
                t1 = t
        
        if isect_inside:
            light_attenuation = exp(-density * t1 * sigma_t)
            p_val = phase_func(ray_direction, light_dir)
            
            # Accumulate in-scattering
            result += transparency * light_color * light_attenuation * sigma_s * density * step_size * p_val
            
        # 3. Advance ray
        current_pos += ray_direction * step_size
        
        # 4. Early exit
        if transparency < 1e-4:
            break
            
    # 5. Composite final color
    final_color = background_color * transparency + result
    return final_color
```

### Edge Cases and Pitfalls
- **Zero Density**: If density $\rho = 0$, the result must be 0. If the density multiplier is omitted in the in-scattering accumulation, non-zero light would be added to empty space, causing visual artifacts [S2, unofficial]. The pseudocode ensures this by multiplying by `density` in the accumulation step.
- **Phase Function Integration**: The phase function must integrate to 1 over the sphere $S^2$ [S2, unofficial].
- **Light Volume Intersection**: The distance $t_1$ must be correctly calculated as the distance from the sample to the boundary of the light volume along the light direction [S2, unofficial].

## Background
The concept of out-scattering and in-scattering is fundamental to volume rendering theory [S1, unofficial]. Out-scattering refers to the reduction in radiance due to light being deflected away from the view direction [S1, unofficial]. The specific ray marching algorithm with density scaling is detailed in Scratchapixel's "Ray Marching: Getting it Right!" lesson [S2, unofficial]. The theoretical background on scattering coefficients and phase functions is attributed to loannis (Yannis) Gkioulekas [S1, unofficial].
