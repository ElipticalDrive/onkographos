# Effective BRDF for Planar Sources

Also called: Effective Forward Scattering BRDF, Forward Scattering BRDF, Planar Propagator

## Overview
The Effective BRDF is a computationally efficient approximation for rendering optically dense, approximately planar media under low-frequency illumination, derived as a limiting case of the subsurface scattering model [S1]. It replaces the expensive integration of the subsurface propagator over a surface area with a single bidirectional reflectance evaluation, enabling its use in level-of-detail hierarchies for participating media [S1].

## How it works
**Inputs and Outputs**
*   **Inputs**: Surface query point $\vec{x}_o$, outgoing direction $\hat{\omega}_e^o$, incoming direction $\hat{\omega}_i^i$, surface normal $\hat{n}$, medium scattering parameters ($N, p, F, C, D, E, \sigma_{a_3}$), effective boundary distance $d_e$ and virtual direction $\hat{\omega}_v$ (if non-index-matched), Fresnel/reflection coefficient $R$, and surface BSDF $f_s$ (if non-index-matched) [S1].
*   **Outputs**: Effective BRDF value $f_r(\hat{\omega}_i^i \leftrightarrow \hat{\omega}_e^o)$ or a sampled direction for recursive evaluation [S1].

**Data Structures**
Standard vector/matrix types for directions and normals are used [G]. The parameters $N, p, F, C, D, E, \sigma_{a_3}$ are constants derived from the medium's optical properties (absorption $\sigma_a$, scattering $\sigma_s$, anisotropy $g$) as defined in the parent [BSSRDF Model](6674-bssrdf-model.md) [S1, G].

**Method Steps**

1.  **Compute the Planar Source Propagator $G_f^{\text{p}}$**:
    Evaluate the Gaussian propagator for a planar tangent source at distance $d$:
    $$
    G_f^{\text{p}}(s, d, \hat{\omega}, \hat{\omega}') = \frac{\pi N}{p^2 F} \exp \left\{ -C - D \hat{\omega} \cdot \hat{\omega}' - E p d (\omega_n + \omega'_n) - F (p d)^2 + \frac{E^2}{4F} [2 + 2 \hat{\omega} \cdot \hat{\omega}' - (\omega_n + \omega'_n)^2] - \sigma_{a_3} \right\}
    $$
    where $\omega_n = \hat{\omega} \cdot \hat{n}$ and $\omega'_n = \hat{\omega}' \cdot \hat{n}$ [S1].

2.  **Compute the Boundary-Aware Planar Propagator $G_f^{\text{pb}}$**:
    Adjust $G_f^{\text{p}}$ based on the outgoing direction relative to the surface normal:
    $$
    G_f^{\text{pb}}(s, \hat{\omega}_0, \hat{\omega}_1) = 
    \begin{cases} 
    G_f^{\text{p}}(s, 0, \hat{\omega}_1, \hat{\omega}_0) & \text{if } \hat{\omega}_1 \cdot \hat{n} \geq 0, \\
    -G_f^{\text{p}}(s, d_e, \hat{\omega}_1, \hat{\omega}_v) & \text{otherwise,}
    \end{cases}
    $$
    where $d_e$ and $\hat{\omega}_v$ are the effective boundary distance and virtual direction from the parent BSSRDF model [S1].

3.  **Evaluate the Effective BRDF ($f_r$)**:
    *   **Index-Matched Medium**: The effective BRDF is the integral of the planar propagator over the scattering length $s$:
        $$
        f_r(\hat{\omega}_i^i \leftrightarrow \hat{\omega}_e^o) = R \int G_f^{\text{pb}}(s, \hat{\omega}_e^o, -\hat{\omega}_i^i) \, ds
        $$
        The integral over $s$ is handled analytically as per the source [S1].
    *   **Non-Index-Matched Medium**: The effective BRDF is evaluated through recursive sampling [S1]. The integral of the subsurface propagator $G_f^b$ over $\vec{x}_i$ is replaced with $f_r(-\hat{\omega}_e^i \leftrightarrow -\hat{\omega}_i^o)$ and $\vec{x}_i$ is set to $\vec{x}_o$ [S1]. The algorithm repeatedly samples $f_r$ and $f_s$ until $f_s$ generates a query direction pointing out of the medium [S1].

**Pseudocode**

```python
import math
import random

def dot(v1, v2):
    return sum(a * b for a, b in zip(v1, v2))

def effective_brdf_planar_source(x_o, omega_e_o, omega_i_i, n, params, fs):
    """
    Computes the effective BRDF contribution for optically dense planar media.
    """
    N, p, F, C, D, E, sigma_a3, d_e, omega_v, R = (
        params['N'], params['p'], params['F'], params['C'],
        params['D'], params['E'], params['sigma_a3'], params['d_e'],
        params['omega_v'], params['R']
    )

    def compute_gf_p(s, d, omega, omega_prime):
        omega_n = dot(omega, n)
        omega_prime_n = dot(omega_prime, n)
        dot_w = dot(omega, omega_prime)
        exponent = (
            -C - D * dot_w
            - E * p * d * (omega_n + omega_prime_n)
            - F * (p * d) ** 2
            + (E ** 2 / (4 * F)) * (2 + 2 * dot_w - (omega_n + omega_prime_n) ** 2)
            - sigma_a3
        )
        return (math.pi * N) / (p ** 2 * F) * math.exp(exponent)

    def compute_gf_pb(s, omega_0, omega_1):
        omega_1n = dot(omega_1, n)
        if omega_1n >= 0:
            return compute_gf_p(s, 0.0, omega_1, omega_0)
        else:
            return -compute_gf_p(s, d_e, omega_1, omega_v)

    # The integral over s is handled analytically as per the source [S1].
    # The sources do not provide the closed-form expression for the integral.
    def integrate_gf_pb(omega_e_o, omega_i_i):
        # Closed-form evaluation of integral(G_pb(s, omega_e_o, -omega_i_i) ds) [S1]
        return 0.0  # Stub for analytical result [S1]

    if params['is_index_matched']:
        integral_val = integrate_gf_pb(omega_e_o, omega_i_i)
        return R * integral_val

    # Non-index-matched: recursive sampling loop [S1]
    current_omega_in = omega_i_i
    current_omega_out = omega_e_o
    max_bounces = 10  # Guard against infinite recursion [G]

    for _ in range(max_bounces):
        # Sample direction from index-matched BRDF f_r(-omega_e^i <-> -omega_i^o)
        # Standard importance sampling for the computed BRDF value [G]
        # Cosine-weighted hemisphere sample as a standard step [G]
        phi = 2.0 * math.pi * random.random()
        cos_theta = math.sqrt(random.random())
        sin_theta = math.sqrt(1.0 - cos_theta**2)
        sample_dir = [sin_theta * math.cos(phi), sin_theta * math.sin(phi), cos_theta]

        # Intersect ray from x_o in sample_dir with scene geometry [G]
        # Standard ray-scene intersection routine [G]
        x_hit = [x_o[i] + sample_dir[i] * 1.0 for i in range(3)]
        t = 1.0

        # Evaluate surface BSDF at intersection point
        fs_result = fs(x_hit, sample_dir)

        if fs_result.direction_out_of_medium:
            return fs_result.radiance

        # Update incoming direction for next subsurface query
        current_omega_in = fs_result.direction
        # current_omega_out remains fixed as the original viewing direction

    return 0.0  # Fallback if max bounces reached [G]
```

**Edge Cases and Pitfalls**
*   **Planarity Assumption**: The method assumes the object is approximately planar on the scale of the reduced scattering length $1/\sigma_s'$ [S1].
*   **Low-Frequency Illumination**: The method assumes low-frequency illumination, where incoming radiance is approximately constant [S1].
*   **Optically Dense Media**: The approximation is valid for optically dense media [S1].
*   **Boundary Handling**: The use of $d_e$ and $\hat{\omega}_v$ requires correct implementation of the effective boundary conditions from the parent BSSRDF model [S1].
*   **Recursion Depth**: The recursive evaluation for non-index-matched media may require a maximum depth limit to prevent infinite loops in pathological cases [G].

## Operating characteristics
*   **Time Complexity**: Not given in the sources.
*   **Memory Complexity**: Not given in the sources.
*   **Strengths**: Computationally efficient approximation for optically dense media; enables level-of-detail rendering; avoids expensive volumetric integration [S1].
*   **Limitations**: Only valid for approximately planar surfaces and low-frequency illumination [S1].
*   **When to Use**: Rendering optically dense, planar translucent materials where performance is critical and lighting is smooth [S1].
*   **When Not to Use**: Transparent materials, high-frequency lighting, highly curved surfaces, or when accurate multiple scattering is required [G].

## Background
The Effective BRDF was introduced by Roald Frederickx and Philip Dutré in 2017 as part of their "Forward Scattering Dipole Model from a Functional Integral Approximation" [S1]. It is derived as a limiting case of their subsurface scattering model, which itself is based on a dipole approximation for forward scattering media [S1]. The method addresses the computational expense of Monte Carlo rendering of strongly forward scattering materials by providing an analytical approximation for optically dense media [S1].
