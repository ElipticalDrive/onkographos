# SubsurfaceMaterial


## Overview
`SubsurfaceMaterial` is a physically based material model that combines a Bidirectional Scattering Distribution Function (BSDF) for surface interactions with a Bidirectional Surface Scattering Reflectance Distribution Function (BSSRDF) for subsurface scattering [S1, unofficial]. It is designed for objects with a defined surface geometry, such as those exhibiting perfect specular transmission or glossy specular transmission, where light enters the surface, scatters internally, and exits at a different location [S1, unofficial]. It differs from `KdSubsurfaceMaterial` by requiring explicit absorption and scattering coefficients rather than deriving them from diffuse reflectance and mean free path [S1, unofficial].

## How it works
The material evaluates scattering properties at a surface interaction point `si` to initialize a `TabulatedBSSRDF` instance. The BSSRDF is precomputed into a `BSSRDFTable` based on optical properties, while the BSDF handles immediate surface reflection and transmission.

**Inputs:**
- Surface interaction `si` (position, normal, tangent frame).
- Memory arena `arena` for allocation.
- Transport mode `mode` (radiance or importance).
- Boolean `allowMultipleLobes`.

**Outputs:**
- Populated `si->bsdf` (handled by parent BSDF logic, not detailed here).
- Populated `si->bssrdf` pointing to a `TabulatedBSSRDF` object.

**Data Structures:**
The `SubsurfaceMaterial` class inherits from `Material` and contains the following private data members [S1, unofficial]:
- `scale`: `const Float`. A scalar multiplier for optical coefficients.
- `Kr`: `std::shared_ptr<Texture<Spectrum>>`. Surface reflection coefficient texture.
- `Kt`: `std::shared_ptr<Texture<Spectrum>>`. Surface transmission coefficient texture.
- `sigma_a`: `std::shared_ptr<Texture<Spectrum>>`. Absorption coefficient texture.
- `sigma_s`: `std::shared_ptr<Texture<Spectrum>>`. Scattering coefficient texture.
- `uRoughness`: `std::shared_ptr<Texture<Float>>`. Microfacet roughness in U direction.
- `vRoughness`: `std::shared_ptr<Texture<Float>>`. Microfacet roughness in V direction.
- `bumpMap`: `std::shared_ptr<Texture<Float>>`. Bump mapping texture.
- `eta`: `const Float`. Index of refraction.
- `remapRoughness`: `const bool`. Flag for roughness remapping.
- `table`: `BSSRDFTable`. Precomputed BSSRDF profile table.

**Parameters:**
- `scale`: A scalar used to scale the absorption cross-section and scattering coefficient. It requires units of $m^{-1}$ [S1, unofficial].

**Algorithm:**
The initialization occurs within the `ComputeScatteringFunctions` method [S1, unofficial]:

1.  **Bump Mapping:** If `bumpMap` is present, perturb the surface normal and tangent frame using `Bump(bumpMap, si)` [S1, unofficial].
2.  **BSDF Initialization:** Initialize the BSDF components using `Kr`, `Kt`, `uRoughness`, `vRoughness`, and `eta` [S1, unofficial]. (Specific BSDF logic is inherited/standard).
3.  **Evaluate Optical Coefficients:**
    -   Evaluate the absorption texture: `Spectrum sigma_a_tex = sigma_a->Evaluate(*si)`.
    -   Evaluate the scattering texture: `Spectrum sigma_s_tex = sigma_s->Evaluate(*si)`.
    -   Apply the scale factor and clamp the results to valid ranges:
        $$ \sigma_a = \text{clamp}(scale \times \sigma_a_{tex}) $$
        $$ \sigma_s = \text{clamp}(scale \times \sigma_s_{tex}) $$
4.  **Allocate BSSRDF:** Allocate a `TabulatedBSSRDF` object in the arena and assign it to `si->bssrdf` [S1, unofficial]:
    ```cpp
    si->bssrdf = ARENA_ALLOC(arena, TabulatedBSSRDF)(*si, this, mode, eta, sig_a, sig_s, table);
    ```

**Pseudocode:**
```python
def ComputeScatteringFunctions(si, arena, mode, allowMultipleLobles):
    # 1. Perform bump mapping if present
    if bumpMap is not None:
        Bump(bumpMap, si)
    
    # 2. Initialize BSDF (Standard BSDF logic using Kr, Kt, eta, roughness)
    # ... (BSDF initialization details are standard and omitted) ...
    
    # 3. Calculate optical coefficients
    # Evaluate textures at the surface interaction point
    sigma_a_tex = sigma_a.Evaluate(si)
    sigma_s_tex = sigma_s.Evaluate(si)
    
    # Scale and clamp
    sig_a = Clamp(scale * sigma_a_tex)
    sig_s = Clamp(scale * sigma_s_tex)
    
    # 4. Allocate and assign BSSRDF
    # TabulatedBSSRDF constructor uses si, material pointer, mode, eta, sig_a, sig_s, and precomputed table
    bssrdf = TabulatedBSSRDF(si, self, mode, eta, sig_a, sig_s, table)
    si.bssrdf = bssrdf
```

**Edge Cases and Pitfalls:**
-   **Units:** The `scale` parameter must be in $m^{-1}$. Incorrect units will result in physically incorrect scattering depths [S1, unofficial].
-   **Clamping:** Optical coefficients are clamped. Negative or excessively large values from texture evaluation or scaling must be handled to prevent numerical instability in the BSSRDF table evaluation [S1, unofficial].
-   **Bump Mapping:** Bump mapping modifies the geometric normal and tangent frame. The BSSRDF sampling and evaluation must be consistent with the perturbed frame if the BSSRDF implementation relies on local geometry [S1, unofficial].

## Operating characteristics
-   **Complexity:** The runtime cost per shading point is dominated by the BSDF evaluation and the BSSRDF table lookup. The BSSRDF table is precomputed, so the online cost is $O(1)$ for the table evaluation, but the table generation itself is expensive and done offline or at material creation.
-   **Memory:** The `BSSRDFTable` stores the precomputed scattering profiles. The size depends on the resolution of the table (radius and albedo bins). The material instance stores textures for `sigma_a`, `sigma_s`, `Kr`, `Kt`, and roughness.
-   **Strengths:** Supports complex surface effects (specular/glossy transmission) combined with subsurface scattering. Allows spatially varying optical properties via textures.
-   **Limitations:** Requires explicit definition of $\sigma_a$ and $\sigma_s$, which can be less intuitive than using diffuse reflectance. The tabulated BSSRDF assumes a homogeneous half-space geometry for the precomputation.
-   **When to use:** For materials like wax, skin, marble, or plastic where surface reflection/transmission and subsurface scattering are both significant and the surface has a defined geometry.
-   **When not to use:** For purely diffuse subsurface scattering where surface reflection is negligible (use `KdSubsurfaceMaterial` instead) or for non-homogeneous media requiring full volume rendering.

## Background
`SubsurfaceMaterial` is implemented in the pbrt rendering system. It is part of the BSSRDF approximation framework, specifically using the dipole model precomputed into a table. It was designed to provide a material model that supports both surface and subsurface effects for objects with defined surfaces, such as those with specular or glossy transmission [S1, unofficial].
