# Analytical Approximation of Single Scattering Radiance

Also called: First-Order Taylor Expansion of Incident Radiance, Legendre Polynomial Expansion Approximation

## Overview
This method computes the in-scattered single scattering radiance $J_{ss}$ by approximating the phase function and incident radiance with low-order expansions, allowing the scattering contribution to be decomposed into direction-independent terms that are pre-computed per voxel [S1]. It differs from Monte Carlo approaches by avoiding repeated ray tracing for incident light estimation during rendering, making it significantly more efficient for differentiable rendering or multi-viewpoint reconstruction where gradients are required [S1].

## How it works

### Inputs and Outputs
**Inputs:**
*   Density field $\rho(x)$ defined on a voxel grid [S1].
*   Extinction cross-section $\sigma_t$ (scalar) [S1].
*   Scattering anisotropy factor $\bar{\mu}$ [S1].
*   Ambient incident radiance field $L_{in}(x, \omega')$ (or a point light source model) [S1].
*   Number of sample directions $N$ for pre-computation [S1].

**Outputs:**
*   Pre-computed voxel grids: $Q_{ri}^0$, $Q_{ri}^1$, $\dot{Q}_{ri}^0$, $\dot{Q}_{ri}^1$ [S1].
*   Final outgoing radiance $L_{out}$ per pixel [S1].

### Data Structures
1.  **Density Grid:** 3D array storing $\rho(x)$ for each voxel [S1].
2.  **Extinction Grid:** 3D array storing $\kappa_t(x) = \sigma_t \rho(x)$ [S1].
3.  **Pre-computed Term Grids:** Four 3D arrays storing the vectors/scalars $Q_{ri}^0(x)$, $Q_{ri}^1(x)$, $\dot{Q}_{ri}^0(x)$, $\dot{Q}_{ri}^1(x)$ for each voxel center [S1].
    *   $Q_{ri}^0(x)$: Scalar [S1].
    *   $Q_{ri}^1(x)$: 3D Vector [S1].
    *   $\dot{Q}_{ri}^0(x)$: Scalar (gradient w.r.t density) [S1].
    *   $\dot{Q}_{ri}^1(x)$: 3D Vector (gradient w.r.t density) [S1].

### Parameters
*   $N$: Number of sample directions over the unit sphere for pre-computation [S1].
*   $\bar{\mu}$: Scattering anisotropy factor, defined as $\bar{\mu} = \frac{3}{2} \int_{-1}^{1} \mu p(\mu) d\mu$ [S1].

### Formulas

**Phase Function Approximation:**
The phase function $p(\omega, \omega')$ is approximated using a truncated Legendre polynomial expansion after the first moment [S1]:
$$ p(\omega, \omega') \approx \frac{1}{4\pi} (1 + \bar{\mu}(\omega \cdot \omega')) \quad (6) $$
where $\omega$ is the view direction and $\omega'$ is the incident direction [S1].

**Incident Radiance Approximation:**
The reduced incident radiance $L_{ri}$ is approximated using a first-order Taylor expansion in direction $\omega'$ [S1]:
$$ L_{ri}(x_u, \omega') \approx L_{ri}^0(x_u) + L_{ri}^1(x_u) \cdot \omega' \quad (7) $$
where $L_{ri}^0$ is the average radiance and $L_{ri}^1$ is the directional gradient vector [S1].

**In-scattered Radiance Decomposition:**
Substituting the approximations into the single scattering integral yields [S1]:
$$ J_{ss}(x_u, \omega) = \Omega (Q_{ri}^0(x_u) + Q_{ri}^1(x_u) \cdot \omega) \quad (8) $$
where $\Omega$ is the solid angle factor [S1]. The direction-independent terms are defined as [S1]:
$$ Q_{ri}^0(x_u) = L_{ri}^0(x_u) \quad (9) $$
$$ Q_{ri}^1(x_u) = \frac{\bar{\mu}}{3} L_{ri}^1(x_u) \quad (10) $$

**Computation of $L_{ri}^0$ and $L_{ri}^1$:**
These are computed via importance sampling over $N$ directions $\omega'_i$ on the unit sphere [S1]:
$$ L_{ri}^0(x_u) = \frac{1}{N} \sum_{i=1}^N L_{ri}(x_u, \omega'_i) \quad (11) $$
$$ L_{ri}^1(x_u) = \frac{3}{N} \sum_{i=1}^N L_{ri}(x_u, \omega'_i) \omega'_i \quad (12) $$
The factor of 3 arises from the spherical integration of direction vectors [S1].

**Gradient Terms (for Differentiable Rendering):**
The derivatives of the pre-computed terms with respect to density are computed similarly [S1]:
$$ \dot{Q}_{ri}^0(x_u) = \frac{1}{N} \sum_{i=1}^N \dot{L}_{ri}(x_u, \omega'_i) \quad (19) $$
$$ \dot{Q}_{ri}^1(x_u) = \frac{3}{N} \sum_{i=1}^N \dot{L}_{ri}(x_u, \omega'_i) \omega'_i \quad (20) $$

### Pseudocode

```python
import numpy as np

def generate_uniform_sphere_samples(N):
    """Generate N directions uniformly distributed over the unit sphere [G]."""
    phi = np.random.uniform(0, 2 * np.pi, N)
    cos_theta = np.random.uniform(-1, 1, N)
    sin_theta = np.sqrt(1 - cos_theta**2)
    x = sin_theta * np.cos(phi)
    y = sin_theta * np.sin(phi)
    z = cos_theta
    return np.stack([x, y, z], axis=1)

def trilinear_interpolate(grid, point):
    """Standard trilinear interpolation for a 3D grid at an arbitrary point [G]."""
    # point is [x, y, z] in grid coordinates
    x, y, z = point
    ix, iy, iz = np.floor([x, y, z]).astype(int)
    fx, fy, fz = [p - i for p, i in zip([x, y, z], [ix, iy, iz])]
    
    # Clamp indices to grid bounds
    D, H, W = grid.shape
    ix = np.clip(ix, 0, D - 2)
    iy = np.clip(iy, 0, H - 2)
    iz = np.clip(iz, 0, W - 2)
    
    v000 = grid[ix, iy, iz]
    v100 = grid[ix + 1, iy, iz]
    v010 = grid[ix, iy + 1, iz]
    v110 = grid[ix + 1, iy + 1, iz]
    v001 = grid[ix, iy, iz + 1]
    v101 = grid[ix + 1, iy, iz + 1]
    v011 = grid[ix, iy + 1, iz + 1]
    v111 = grid[ix + 1, iy + 1, iz + 1]
    
    w000 = (1 - fx) * (1 - fy) * (1 - fz)
    w100 = fx * (1 - fy) * (1 - fz)
    w010 = (1 - fx) * fy * (1 - fz)
    w110 = fx * fy * (1 - fz)
    w001 = (1 - fx) * (1 - fy) * fz
    w101 = fx * (1 - fy) * fz
    w011 = (1 - fx) * fy * fz
    w111 = fx * fy * fz
    
    return (w000 * v000 + w100 * v100 + w010 * v010 + w110 * v110 +
            w001 * v001 + w101 * v101 + w011 * v011 + w111 * v111)

def compute_reduced_incident_radiance(vp, omega_p, sigma_t, density_grid):
    """Trace ray from voxel to light source and compute L_in * transmittance [G]."""
    # Simplified point light model: L_ri = L_light * exp(-sigma_t * optical_dist) / dist^2
    light_pos = np.array([0.0, 10.0, 0.0])
    L_light = 1.0
    direction = light_pos - vp
    dist = np.linalg.norm(direction)
    if dist < 1e-6:
        return L_light
    optical_dist = dist
    transmittance = np.exp(-sigma_t * optical_dist)
    return L_light * transmittance / (dist ** 2)

def compute_gradient_reduced_incident_radiance(vp, omega_p, sigma_t, density_grid):
    """Compute d(L_ri)/d_rho along the light ray [G]."""
    # d/d_rho (L * exp(-sigma_t * int rho ds)) = -L * exp(-sigma_t * int rho ds) * sigma_t * int ds
    light_pos = np.array([0.0, 10.0, 0.0])
    direction = light_pos - vp
    dist = np.linalg.norm(direction)
    if dist < 1e-6:
        return 0.0
    transmittance = np.exp(-sigma_t * dist)
    return -transmittance * sigma_t * dist

def precompute_terms(density_grid, sigma_t, N, anisotropy_mu):
    """Pre-computes direction-independent terms for single scattering [S1]."""
    D, H, W = density_grid.shape
    Q0 = np.zeros((D, H, W))
    dQ0 = np.zeros((D, H, W))
    Q1 = np.zeros((D, H, W, 3))
    dQ1 = np.zeros((D, H, W, 3))
    
    omega_primes = generate_uniform_sphere_samples(N)
    kappa_t = sigma_t * density_grid
    
    for d in range(D):
        for h in range(H):
            for w in range(W):
                vp = np.array([d + 0.5, h + 0.5, w + 0.5])
                
                L_ri_sum = 0.0
                L_ri_vec_sum = np.zeros(3)
                dL_ri_sum = 0.0
                dL_ri_vec_sum = np.zeros(3)
                
                for i in range(N):
                    omega_p = omega_primes[i]
                    L_ri_val = compute_reduced_incident_radiance(vp, omega_p, sigma_t, density_grid)
                    dL_ri_val = compute_gradient_reduced_incident_radiance(vp, omega_p, sigma_t, density_grid)
                    
                    L_ri_sum += L_ri_val
                    L_ri_vec_sum += L_ri_val * omega_p
                    dL_ri_sum += dL_ri_val
                    dL_ri_vec_sum += dL_ri_val * omega_p
                
                L_ri_0 = L_ri_sum / N
                L_ri_1 = (3.0 / N) * L_ri_vec_sum
                dL_ri_0 = dL_ri_sum / N
                dL_ri_1 = (3.0 / N) * dL_ri_vec_sum
                
                Q0[d, h, w] = L_ri_0
                Q1[d, h, w] = (anisotropy_mu / 3.0) * L_ri_1
                dQ0[d, h, w] = dL_ri_0
                dQ1[d, h, w] = (anisotropy_mu / 3.0) * dL_ri_1
                
    return Q0, Q1, dQ0, dQ1

def ray_march_single_scattering(camera_ray_origin, camera_ray_direction, density_grid, sigma_t, Q0, Q1, dQ0, dQ1, t_min, t_max, step_size):
    """Ray marches through the volume to compute single scattering radiance and gradients [S1]."""
    L_ss = 0.0
    dL_ss = 0.0
    tau = 1.0
    current_t = t_max
    
    while current_t > t_min:
        xu = camera_ray_origin + camera_ray_direction * current_t
        current_t -= step_size
        
        rho_xu = trilinear_interpolate(density_grid, xu)
        kappa_t_xu = sigma_t * rho_xu
        
        Q0_xu = trilinear_interpolate(Q0, xu)
        Q1_xu = np.array([trilinear_interpolate(Q1[..., i], xu) for i in range(3)])
        dQ0_xu = trilinear_interpolate(dQ0, xu)
        dQ1_xu = np.array([trilinear_interpolate(dQ1[..., i], xu) for i in range(3)])
        
        omega = camera_ray_direction
        J_ss = Q0_xu + np.dot(Q1_xu, omega)
        dJ_ss = dQ0_xu + np.dot(dQ1_xu, omega)
        
        tau *= np.exp(-kappa_t_xu * step_size)
        
        contribution = J_ss * tau * step_size
        d_contribution = (dJ_ss * tau - J_ss * kappa_t_xu * tau * step_size) * step_size
        
        L_ss += contribution
        dL_ss += d_contribution
        
    return L_ss, dL_ss
```

### Edge Cases and Pitfalls
*   **Interpolation Consistency:** Trilinear interpolation is used for sampling density and pre-computed terms at arbitrary positions [S1]. Gradients are scattered back to the eight nearest voxels using the same interpolation weights to maintain consistency between forward and backward passes [S1].
*   **Anisotropy Factor:** The approximation assumes the phase function can be well-approximated by the first two Legendre moments [S1]. The approximation truncates the Legendre expansion after the first moment, which is sufficient for most common phase functions like Henyey-Greenstein due to rapidly diminishing higher-order contributions [S1].
*   **Light Tracing:** The pre-computation step requires tracing rays from each voxel to the light source to compute $L_{ri}$ [S1]. The method avoids repeated ray tracing during rendering, maintaining efficiency for multi-viewpoint reconstruction [S1].

## Operating characteristics

*   **Time Complexity:** Pre-computation is $O(V \cdot N)$, where $V$ is the number of voxels and $N$ is the number of sample directions [S1]. Ray marching is $O(R \cdot S)$, where $R$ is the number of rays and $S$ is the number of steps per ray [S1].
*   **Memory Complexity:** Requires storing four additional 3D grids ($Q_{ri}^0, Q_{ri}^1, \dot{Q}_{ri}^0, \dot{Q}_{ri}^1$) in addition to the density grid [S1]. Memory usage is $O(V)$ [S1].
*   **Strengths:** Efficient for differentiable rendering as gradients are computed simultaneously with radiance [S1]. Avoids repeated ray tracing for incident light estimation [S1].
*   **Limitations:** Approximation error due to truncation of Legendre series and Taylor expansion [S1].
*   **When to Use:** Suitable for smoke/volumetric rendering where real-time or differentiable rendering is required [S1].
*   **When Not to Use:** For highly anisotropic media where higher-order phase function terms are critical, or for scenes with complex, dynamic lighting where pre-computation is not feasible [S1].

## Background

This method was proposed in "A High-Efficiency Physics-Based Differentiable Renderer for Smoke Reconstruction" [S1]. It addresses the inefficiency of traditional ray tracing-based frameworks for computing single scattering radiance, particularly in the context of differentiable rendering where gradient computation requires tracing additional rays [S1]. By pre-computing direction-independent terms, the method avoids redundant calculations during rendering [S1].
