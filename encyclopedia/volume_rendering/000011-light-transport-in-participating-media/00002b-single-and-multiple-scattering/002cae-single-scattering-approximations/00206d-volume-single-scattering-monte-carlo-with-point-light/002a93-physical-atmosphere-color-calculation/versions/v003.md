# Physical Atmosphere Color Calculation

Also called: Physical Atmosphere Color, getAtmosphereColorPhysical

## Overview
Calculates the physical color of the sky and sun disk for a given view direction, accounting for Rayleigh and Mie scattering, optical depth, and phase functions [S1, unofficial]. It differs from sibling methods by providing a closed-form analytical approximation of the atmospheric radiance rather than using Monte Carlo integration or precomputed lookup tables [S1, unofficial].

## How it works
**Inputs:**
- `dir`: View direction vector (normalized) [S1, unofficial].
- `sunDir`: Sun direction vector (normalized) [S1, unofficial].
- `sunIntensity`: Scalar intensity of the sun [S1, unofficial].
- `turbidity`: Atmospheric turbidity parameter [S1, unofficial].

**Outputs:**
- `localcolor`: The final tone-mapped atmospheric color (RGB) [S1, unofficial].

**Data Structures:**
- Constants are hardcoded vectors/scalars as defined below [S1, unofficial].

**Parameters:**
- `rayleigh_total`: `vec3(5.804542996261093e-6, 1.3562911419845635e-5, 3.0265902468824876e-5)` [S1, unofficial].
- `mie_const`: `vec3(1.839991851443397, 2.779802391966052, 4.079047954386109)` [S1, unofficial].
- `mie`: `0.005` [S1, unofficial].
- `mie_directional`: `0.8` [S1, unofficial].
- `sun_angular_cos`: `0.999956676946448` [S1, unofficial].

**Steps:**

1.  **Calculate Scattering Coefficients:**
    Compute the turbidity factor $c$:
    $$ c = (0.2 \times \text{turbidity}) \times 10^{-17} $$ [S1, unofficial]
    Calculate Mie scattering coefficient $\beta_M$:
    $$ \beta_M = \text{vec3}(0.434 \times c \times \text{mie\_const} \times \text{mie}) $$ [S1, unofficial]
    Calculate sun fade factor:
    $$ \text{sunFade} = 1.0 - \text{clamp}\left(1.0 - \exp\left(\frac{\text{SunLocation.y}}{450000.0}\right), 0.0, 1.0\right) $$ [S1, unofficial]
    Calculate Rayleigh scattering coefficient $\beta_R$:
    $$ \beta_R = \text{vec3}(\text{rayleigh\_total} \times (\text{rayleigh} - 1.0 + \text{sunFade})) $$ [S1, unofficial]
    where $\text{rayleigh} = 2.0$ [S1, unofficial].

2.  **Calculate Optical Path Lengths:**
    Calculate zenith angle $\theta_z$:
    $$ \theta_z = \arccos(\max(0.0, \text{dir}.y)) $$ [S1, unofficial]
    Calculate inverse air mass $m^{-1}$:
    $$ \text{inverse} = \frac{1.0}{\cos(\theta_z) + 0.15 \times \left(93.885 - \frac{\theta_z \times 180.0}{\pi}\right)^{-1.253}} $$ [S1, unofficial]
    Calculate Rayleigh optical path length $s_R$:
    $$ s_R = 8.4 \times 10^3 \times \text{inverse} $$ [S1, unofficial]
    Calculate Mie optical path length $s_M$:
    $$ s_M = 1.25 \times 10^3 \times \text{inverse} $$ [S1, unofficial]

3.  **Calculate Extinction Factor:**
    $$ f_{ex} = \exp\left(-\beta_R \times s_R + \beta_M \times s_M\right) $$ [S1, unofficial]

4.  **Calculate Phase Functions:**
    Calculate cosine of scattering angle:
    $$ \cos\Theta = \text{dot}(\text{sunDir}, \text{dir}) $$ [S1, unofficial]
    Calculate Rayleigh phase term $P_R$:
    $$ P_R = \frac{3 \times (1.0 + \cos\Theta^2)}{16.0 \times \pi} $$ [S1, unofficial]
    Calculate Mie phase term $P_M$ using Henyey-Greenstein:
    $$ P_M = \text{HenyeyGreenstein}(\text{dir}, \text{sunDir}, \text{mie\_directional}) $$ [S1, unofficial]

5.  **Calculate In-Scattered Light:**
    Calculate intermediate scattering terms:
    $$ \beta_R\Theta = \beta_R \times P_R $$ [S1, unofficial]
    $$ \beta_M\Theta = \beta_M \times P_M $$ [S1, unofficial]
    Calculate combined scattering ratio:
    $$ \beta_{sum} = \beta_R + \beta_M $$ [S1, unofficial]
    $$ \beta_{mix} = \frac{\beta_R\Theta + \beta_M\Theta}{\beta_{sum}} $$ [S1, unofficial]
    Calculate sun intensity factor:
    $$ \text{sunE} = \text{sunIntensity} \times \text{calcSunIntensity}() $$ [S1, unofficial]
    Calculate primary in-scattered radiance $L_{in}$:
    $$ L_{in} = \text{pow}\left(\text{sunE} \times \beta_{mix} \times (1.0 - f_{ex}), \text{vec3}(1.5)\right) $$ [S1, unofficial]
    Calculate horizon fade factor $yDot$:
    $$ yDot = 1.0 - \text{sunDir}.y $$ [S1, unofficial]
    $$ yDot = yDot^5 $$ [S1, unofficial]
    Apply horizon blending:
    $$ L_{in} = L_{in} \times \text{mix}\left(\text{vec3}(1), \text{pow}\left(\text{sunE} \times \beta_{mix} \times f_{ex}, \text{vec3}(0.5)\right), \text{clamp}(yDot, 0.0, 1.0)\right) $$ [S1, unofficial]

6.  **Calculate Direct Sun Disk:**
    Initialize direct light $L_0$:
    $$ L_0 = \text{vec3}(0.1 \times f_{ex}) $$ [S1, unofficial]
    Calculate sun disk visibility:
    $$ \text{sunDisk} = \text{smoothstep}(\text{sun\_angular\_cos}, \text{sun\_angular\_cos} + 0.00002, \cos\Theta) $$ [S1, unofficial]
    Add sun disk radiance:
    $$ L_0 = L_0 + (\text{sunE} \times 15000.0 \times f_{ex}) \times \text{sunDisk} $$ [S1, unofficial]

7.  **Combine and Tone-Map:**
    $$ \text{localcolor} = (L_{in} + L_0) \times 0.04 + \text{vec3}(0.0, 0.0003, 0.00075) $$ [S1, unofficial]
    Return `localcolor` [S1, unofficial].

**Pseudocode:**

```python
import math

class Vec3:
    def __init__(self, x, y, z):
        self.x = x
        self.y = y
        self.z = z
    def __mul__(self, s):
        return Vec3(self.x * s, self.y * s, self.z * s)
    def __rmul__(self, s):
        return self.__mul__(s)
    def __add__(self, other):
        return Vec3(self.x + other.x, self.y + other.y, self.z + other.z)
    def __sub__(self, other):
        return Vec3(self.x - other.x, self.y - other.y, self.z - other.z)
    def __truediv__(self, other):
        return Vec3(self.x / other.x, self.y / other.y, self.z / other.z)
    def __pow__(self, p):
        return Vec3(self.x ** p, self.y ** p, self.z ** p)
    def dot(self, other):
        return self.x * other.x + self.y * other.y + self.z * other.z

def clamp(val, min_val, max_val):
    return max(min_val, min(max_val, val))

def mix(a, b, t):
    return a + t * (b - a)

def smoothstep(edge0, edge1, x):
    t = clamp((x - edge0) / (edge1 - edge0), 0.0, 1.0)
    return t * t * (3.0 - 2.0 * t)

def rayleigh_phase(cos_theta):
    return 3.0 * (1.0 + cos_theta * cos_theta) / (16.0 * math.pi)

def henyey_greenstein(dir_vec, sun_dir, g):
    cos_theta = dir_vec.dot(sun_dir)
    numerator = 1.0 - g * g
    denominator = 1.0 + g * g - 2.0 * g * cos_theta
    if denominator < 1e-8:
        denominator = 1e-8
    return numerator / (4.0 * math.pi * (denominator ** 1.5))

def get_atmosphere_color_physical(dir, sun_dir, sun_intensity, turbidity):
    # Constants
    rayleigh_total = Vec3(5.804542996261093e-6, 1.3562911419845635e-5, 3.0265902468824876e-5)
    mie_const = Vec3(1.839991851443397, 2.779802391966052, 4.079047954386109)
    mie = 0.005
    mie_directional = 0.8
    rayleigh = 2.0
    sun_angular_cos = 0.999956676946448
    
    # 1. Scattering Coefficients
    c = (0.2 * turbidity) * 10e-18
    beta_m = Vec3(0.434 * c * mie_const.x * mie, 0.434 * c * mie_const.y * mie, 0.434 * c * mie_const.z * mie)
    
    # [G] SunLocation.y is not defined in the notes; assumed to be sun_dir.y
    sun_location_y = sun_dir.y 
    sun_fade = 1.0 - clamp(1.0 - math.exp(sun_location_y / 450000.0), 0.0, 1.0)
    
    beta_r = rayleigh_total * (rayleigh - 1.0 + sun_fade)
    
    # 2. Optical Path Lengths
    zenith = math.acos(max(0.0, dir.y))
    inverse = 1.0 / (math.cos(zenith) + 0.15 * (93.885 - zenith * 180.0 / math.pi) ** -1.253)
    s_r = 8400.0 * inverse
    s_m = 1250.0 * inverse
    
    # 3. Extinction Factor
    fex = Vec3(math.exp(-beta_r.x * s_r + beta_m.x * s_m),
               math.exp(-beta_r.y * s_r + beta_m.y * s_m),
               math.exp(-beta_r.z * s_r + beta_m.z * s_m))
    
    # 4. Phase Functions
    cos_theta = sun_dir.dot(dir)
    r_phase = rayleigh_phase(cos_theta)
    m_phase = henyey_greenstein(dir, sun_dir, mie_directional)
    
    beta_r_theta = beta_r * r_phase
    beta_m_theta = beta_m * m_phase
    
    beta_sum = beta_r + beta_m
    beta_mix = beta_r_theta / beta_sum + beta_m_theta / beta_sum
    
    # [G] calcSunIntensity() is not defined; assumed to return 1.0
    sun_e = sun_intensity * 1.0
    
    # 5. In-Scattered Light
    lin = Vec3((sun_e * beta_mix.x * (1.0 - fex.x)) ** 1.5,
               (sun_e * beta_mix.y * (1.0 - fex.y)) ** 1.5,
               (sun_e * beta_mix.z * (1.0 - fex.z)) ** 1.5)
    
    y_dot = 1.0 - sun_dir.y
    y_dot = y_dot ** 5
    
    blend_t = clamp(y_dot, 0.0, 1.0)
    lin = Vec3(lin.x * mix(1.0, (sun_e * beta_mix.x * fex.x) ** 0.5, blend_t),
               lin.y * mix(1.0, (sun_e * beta_mix.y * fex.y) ** 0.5, blend_t),
               lin.z * mix(1.0, (sun_e * beta_mix.z * fex.z) ** 0.5, blend_t))
    
    # 6. Direct Sun Disk
    l0 = Vec3(0.1 * fex.x, 0.1 * fex.y, 0.1 * fex.z)
    sun_disk = smoothstep(sun_angular_cos, sun_angular_cos + 0.00002, cos_theta)
    l0 = Vec3(l0.x + (sun_e * 15000.0 * fex.x) * sun_disk,
              l0.y + (sun_e * 15000.0 * fex.y) * sun_disk,
              l0.z + (sun_e * 15000.0 * fex.z) * sun_disk)
    
    # 7. Combine and Tone-Map
    localcolor = Vec3((lin.x + l0.x) * 0.04 + 0.0,
                      (lin.y + l0.y) * 0.04 + 0.0003,
                      (lin.z + l0.z) * 0.04 + 0.00075)
    
    return localcolor
```
