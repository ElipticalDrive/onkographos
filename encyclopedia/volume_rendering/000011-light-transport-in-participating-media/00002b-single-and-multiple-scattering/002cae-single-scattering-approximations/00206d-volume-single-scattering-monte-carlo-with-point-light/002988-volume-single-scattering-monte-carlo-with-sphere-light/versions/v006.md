# Volume Single Scattering (Monte Carlo with Sphere Light)
## Overview
This method computes single scattering radiance in participating media using Monte Carlo integration with a sphere light for background and emission [S1, unofficial]. It differs from its parent method by replacing the point light source with a sphere light and employing equi-angular sampling for distance estimation [S1, unofficial].
## How it works
**Inputs and Outputs:**
- **Inputs:** Ray origin, ray direction, maximum ray distance ($t_{MAX}$), scene objects, volume properties (density, scattering coefficient), sphere light parameters (position, radius, emission color) [S1, unofficial].
- **Outputs:** Radiance value for the pixel [S1, unofficial].

**Data Structures:**
- `Vector3`: 3D vector with components $x, y, z$ [S1, unofficial].
- `Color`: Color representation used in the scene [S1, unofficial].
- `Ray`: Defined by origin and direction [S1, unofficial].
- `Object`: Base class for scene geometry [S1, unofficial].
- `Triangle`: Inherits from `Object`, stores vertices $A, B, C$, normal, distance, and color [S1, unofficial].

**Steps:**
1. **Calculate Background Radiance:** Compute the background radiance using the sphere light [S1, unofficial].
   - Call `getPixelColorWithSphereLight(objects, id, t_MAX, ray, hitPoint, 1, Importance_Solid_Angle)` where `id` is the current pixel index, `t_MAX` is the maximum ray distance, `ray` is the camera ray, `hitPoint` is the intersection point, and `Importance_Solid_Angle` is the sampling mode [S1, unofficial].
2. **Set Sampling Mode:** Set the 1D sampling mode to `EquiAngular` [S1, unofficial].
   - `sampleMode1D sampleMode = EquiAngular` [S1, unofficial].
3. **Monte Carlo Integration Loop:** For each sample:
   a. **Sample Distance:** Sample the distance $t_{sample}$ along the ray using the `EquiAngular` mode [S1, unofficial].
   b. **Calculate Sample Point:** Compute the sample position $x_{sample} = ray.origin + t_{sample} \cdot ray.direction$ [G].
   c. **Calculate Light Radiance ($L_e$):** Compute the radiance arriving at $x_{sample}$ from the sphere light [S1, unofficial].
      - Call `getPixelColorWithSphereLight(objects, -1, t_sample, ray, hitPoint, 1, Importance_Solid_Angle)` where `id` is -1 (indicating a light query), `t_sample` is the sampled distance, and other parameters are as above [S1, unofficial].
   d. **Calculate Transmittance from Light:** Compute the transmittance from the sample point to the light source [S1, unofficial].
      - `transmittanceFromLight = volume->getTransmittanceHomogeneos(x_sample, light.getLightPosition())` [S1, unofficial].
   e. **Accumulate Radiance:** Add the contribution to the total radiance [S1, unofficial].
      - The contribution is the product of the light radiance, the transmittance from the light, and the volume's scattering properties [S1, unofficial].
4. **Average and Return:** Average the accumulated radiance over the number of samples and return the result [S1, unofficial].

**Formulas:**
- Background Radiance: $L_{bg} = \text{getPixelColorWithSphereLight}(\dots)$ [S1, unofficial].
- Sampled Distance: $t_{sample} = \text{sampleEquiAngular}(t_{MAX})$ [S1, unofficial].
- Sample Point: $x_{sample} = o + t_{sample} \cdot d$ [G].
- Light Radiance: $L_e = \text{getPixelColorWithSphereLight}(\dots)$ [S1, unofficial].
- Transmittance from Light: $T(x_{sample}, L) = \text{getTransmittanceHomogeneos}(x_{sample}, L_{pos})$ [S1, unofficial].
- Total Radiance: $L = \frac{1}{N} \sum_{i=1}^{N} L_e(x_i) \cdot T(x_i, L) \cdot \sigma_s \cdot \Delta t$ [G].

**Parameters:**
- `sampleMode1D`: Set to `EquiAngular` [S1, unofficial].
- `Importance_Solid_Angle`: Sampling mode for sphere light [S1, unofficial].

**Edge Cases and Pitfalls:**
- Precision issues with small distances or large scene scales [G].
- Boundary conditions for ray-volume intersections [G].

    import random
    u = random.uniform(0.0, 1.0)
    return t_max * u

## Subtopics

### [Main Ray Marching with Frostbite Integration](4931-main-ray-marching-with-frostbite-integration.md)
Main Ray Marching with Frostbite Integration is a volume rendering technique that marches along the view direction through a participating medium, accumulating radiance using a physically based integration scheme from Frostbite that handles transmittance, inscatter, and early termination. It differs from its parent method by replacing stochastic sphere light sampling with a fixed-step deterministic ray march.

### Spherical Lighting
Spherical Lighting is a technique that mimics blackbody radiation in a unit area, approximating area diffuse lights with a sampling of point lights [S2, unofficial]. It addresses computational challenges in fire and smoke rendering by using selective light sampling based on distance and importance sampling of multiple scattering directions [S2, unofficial].
