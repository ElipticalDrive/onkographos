# Single Scattering

Also called: Direct Lighting in Participating Media

## Overview
Single scattering is an approximation of light transport in participating media where in-scattered radiance is assumed to originate directly from light sources, similar to direct lighting in vacuum [S1, unofficial]. It solves the problem of computing volumetric illumination by integrating over the spherical domain of incident light directions, effectively treating the medium as a collection of points that scatter light from lights once before reaching the camera [S1, unofficial]. This method is distinct from multiple scattering models which account for light bouncing within the medium, and from atmosphere-specific approximations that rely on precomputed textures or simplified phase functions [Siblings].

## How it works
**Inputs and Outputs:**
- **Input:** Position $x_t$ in the medium, outgoing direction $\vec{w}$, list of light sources, medium properties (scattering coefficient $\sigma_s$, absorption coefficient $\sigma_a$, phase function $phase$).
- **Output:** In-scattered radiance $L_s(x_t, \vec{w})$.

**Data Structures:**
- **Light List:** A list of light sources, each containing position, intensity, and geometry (e.g., point, directional, area).
- **Medium Properties:**
  - $\sigma_s$: Scattering coefficient (float).
  - $\sigma_a$: Absorption coefficient (float).
  - $phase(\vec{w}', \vec{w})$: Phase function evaluating the probability of scattering from incoming direction $\vec{w}'$ to outgoing direction $\vec{w}$ [S1, unofficial].

**Steps:**
1. Initialize total in-scattered radiance $L_s = 0$.
2. For each light source $L_i$ in the scene:
   a. Determine the direction $\vec{w}'$ from the current position $x_t$ to the light source.
   b. Calculate the incident radiance $L_i(x_t, \vec{w}')$ from the light source at position $x_t$. This involves tracing a ray from $x_t$ to the light source to compute attenuation through the medium [S1, unofficial].
   c. Evaluate the phase function $phase(x_t, \vec{w}', \vec{w})$ for the scattering event from $\vec{w}'$ to $\vec{w}$ [S1, unofficial].
   d. Compute the contribution: $contribution = phase(x_t, \vec{w}', \vec{w}) \times L_i(x_t, \vec{w}')$.
   e. Add the contribution to $L_s$.
3. Return $L_s$.

**Formula:**
The in-scattered radiance is given by the integral over the unit sphere $S^2$:
$$ L_s(x_t, \vec{w}) = \int_{S^2} phase(x_t, \vec{w}', \vec{w}) L_i(x_t, \vec{w}') d\vec{w}' $$
where:
- $L_s(x_t, \vec{w})$ is the in-scattered radiance at position $x_t$ in direction $\vec{w}$ [S1, unofficial].
- $phase(x_t, \vec{w}', \vec{w})$ is the phase function [S1, unofficial].
- $L_i(x_t, \vec{w}')$ is the incident radiance from direction $\vec{w}'$ (from lights) [S1, unofficial].
- $d\vec{w}'$ is the differential solid angle [S1, unofficial].

**Implementation via Next Event Estimation (NEE):**
In practice, the spherical integral is approximated by Next Event Estimation, directly enumerating all lights [S1, unofficial]. For each light, the contribution is calculated and summed. If a light is occluded by geometry or the medium itself, its contribution is zero.

**Pseudocode:**
```python
def single_scattering_radiance(x_t, w_out, lights, medium):
    """
    Calculate in-scattered radiance at x_t for direction w_out using single scattering approximation.
    
    Args:
        x_t: Position in the medium (vec3)
        w_out: Outgoing direction (vec3, normalized)
        lights: List of light objects, each with position, intensity, and geometry
        medium: Object containing scattering coefficient (sigma_s), absorption coefficient (sigma_a), and phase function
        
    Returns:
        Radiance (vec3)
    """
    total_radiance = vec3(0.0)
    
    for light in lights:
        # Direction from current position to light
        w_in = normalize(light.position - x_t)
        
        # Trace ray from x_t to light to get incident radiance and attenuation
        # This involves integrating the extinction coefficient along the path
        # L_i(x_t, w_in) = L_light * exp(-integral(sigma_t * ds))
        # where sigma_t = sigma_a + sigma_s
        
        incident_radiance = trace_light_attenuation(x_t, w_in, light, medium)
        
        if incident_radiance is None or incident_radiance == 0:
            continue
            
        # Evaluate phase function for scattering from w_in to w_out
        phase_value = medium.phase_function(w_in, w_out)
        
        # Contribution to in-scattered radiance
        contribution = phase_value * incident_radiance
        
        total_radiance += contribution
        
    return total_radiance

def trace_light_attenuation(x_t, w_in, light, medium):
    """
    Trace a ray from x_t towards the light to compute incident radiance and attenuation.
    Returns the attenuated radiance from the light, or None if occluded.
    """
    # Sample points along the ray from x_t to light.position
    # Integrate extinction coefficient sigma_t = sigma_a + sigma_s
    # Check for occlusion by geometry
    
    # Simplified: assume homogeneous medium for demonstration
    # In practice, use a volume traversal or acceleration structure like Embree [S1, unofficial]
    
    distance_to_light = length(light.position - x_t)
    
    # Check for geometric occlusion
    if is_occluded(x_t, light.position):
        return None
        
    # Calculate optical depth
    # sigma_t is assumed constant for simplicity
    sigma_t = medium.sigma_a + medium.sigma_s
    
    # Attenuation factor
    attenuation = exp(-sigma_t * distance_to_light)
    
    # Incident radiance from light
    # For a point light with intensity I
    incident_radiance = light.intensity * attenuation
    
    return incident_radiance

def is_occluded(origin, target):
    """
    Check if the path from origin to target is occluded by geometry.
    Returns True if occluded, False otherwise.
    """
    # Use a ray intersection test against the scene geometry
    # If any intersection is found closer than target, return True
    intersection = ray_intersect(origin, target - origin)
    if intersection is not None and intersection.distance < length(target - origin):
        return True
    return False
```

**Parameters:**
- **Anisotropy ($g$):** Parameter for the Henyey-Greenstein phase function, range -1 to 1 [S1, unofficial].
- **Volume Absorption ($\sigma_a$):** Range 0 to 1 [S1, unofficial].
- **Volume Scattering ($\sigma_s$):** Range 0 to 1 [S1, unofficial].

**Edge Cases and Pitfalls:**
- **Precision:** Numerical precision issues may arise when calculating attenuation over long distances or with high extinction coefficients [S1, unofficial].
- **Boundaries:** Handling the boundaries of the volume and occlusion by geometry is critical for correct attenuation [S1, unofficial].
- **Degenerate Input:** If the light is directly behind the camera or the direction is undefined, special handling is required [G].

## Subtopics

### Monochromatic Mie Scattering Shading
Monochromatic Mie scattering shading treats the Mie scattering intensity $I_{SM}$ as monochromatic, occupying only one channel in the scattering texture, and shades it during rendering by multiplying by the attenuated direct illumination $I_0^I$ [S2]. Alternatively, the proportionality rule from [Bruneton and Neyret 2008] can be used instead of multiplying by attenuated direct illumination [S2].

### Simple Compositing Illumination Approximation
The simple compositing illumination approximation ignores scattering completely, reducing the illumination equation to a form equivalent to standard volume compositing [S3, book]. The simplified intensity is given by:
$$ I(t_0, \vec{\omega}) = \int_{t_0}^{\infty} E(\tau) e^{(-\int_{t_0}^{t} \sigma_a(\tau) \, d\tau)} \, d\tau $$
In discrete form, this is expressed as:
$$ I(t_{near}, \vec{\omega}) = \sum_{t = t_{near}}^{t \leq t_{far}} \alpha(t) \prod_{t' = t_{near}}^{t' < t_{far}}(1 - a(t')) $$
or recursively:
$$ I(t_n, \vec{\omega}) = \alpha(t_n) + (1 - \alpha(t_n)) I(t_{n+1}, \vec{\omega}) $$
This simplification produces images that do not appear realistic because it reduces the illumination model to simple compositing [S3, book].

## Operating characteristics
- **Time Complexity:** Linear with respect to the number of lights and samples per pixel. Each light requires a ray trace to compute attenuation [S1, unofficial].
- **Memory Complexity:** Depends on the acceleration structure used for ray tracing (e.g., Embree) and the storage of medium properties [S1, unofficial].
- **Measured Performance:** With equi-angular sampling, each image can be rendered in less than 10 minutes with spp < 100 and spr = 4, using Embree for acceleration [S1, unofficial].
- **Scaling:** Performance scales with the number of lights and the complexity of the medium.
- **Strengths:** Physically plausible for optically thin media; simpler to implement than multiple scattering.
- **Limitations:** Inaccurate for optically thick media where multiple scattering is significant; computationally expensive for scenes with many lights.
- **When to Use:** Optically thin participating media; real-time applications with limited lighting complexity.
- **When Not to Use:** Optically thick media; scenes with complex lighting requiring accurate indirect illumination.

## Background
Single scattering is a fundamental concept in volume rendering, derived from the radiative transfer equation. It is widely used in computer graphics for rendering participating media such as fog, smoke, and clouds. The method is often implemented using path tracing with Next Event Estimation for direct lighting [S1, unofficial]. Acceleration structures like Embree are commonly used to speed up ray tracing in the medium [S1, unofficial].
