# Single Scattering

Also called: Direct Lighting in Participating Media

## Overview
Single scattering approximates the in-scattered radiance at a point $\mathbf{x}$ by assuming it originates directly from light sources, attenuated by the transmittance from the source to $\mathbf{x}$, and travels directly to the camera, attenuated by the transmittance from $\mathbf{x}$ to the camera [S2][S3]. This method solves the problem of computing volumetric illumination without accounting for light that scatters more than once, effectively treating the volume as a collection of direct-lighting surfaces. It is distinguished from [Single-scattering homogeneous volume rendering](1135-single-scattering-homogeneous-volume-rendering.md) by its general applicability to heterogeneous media and from [Volume Single Scattering (Monte Carlo with Point Light)](2293-volume-single-scattering-monte-carlo-with-point-light.md) by its formulation as a deterministic integral over the spherical domain rather than a stochastic estimator for specific light types.

## How it works
**Inputs and Outputs:**
*   **Inputs:** Camera ray origin $\mathbf{o}$ and direction $\boldsymbol{\omega}$; scene geometry; light sources (positions, intensities, spectra); volume density field $\sigma_t(\mathbf{x})$ and scattering coefficient $\sigma_s(\mathbf{x})$; phase function $p(\boldsymbol{\omega}_i, \boldsymbol{\omega}_o)$.
*   **Outputs:** Radiance $L_o(\mathbf{o}, \boldsymbol{\omega})$ for the ray.

**Data Structures:**
*   **Volume Grid:** A 3D texture or sparse structure storing $\sigma_t(\mathbf{x})$ and $\sigma_s(\mathbf{x})$ at voxel centers. Layout is typically $N_x \times N_y \times N_z$ floats per channel.
*   **Light List:** Array of light objects containing position $\mathbf{l}$, intensity $I$, and type (point, directional, area).

**Numbered Steps:**
1.  **Ray Marching:** Sample points $\mathbf{x}_i$ along the camera ray from $\mathbf{o}$ to $\mathbf{p}_{far}$. For each point, compute the transmittance from the eye $T(\mathbf{o}, \mathbf{x}_i) = \exp\left(-\int_{\mathbf{o}}^{\mathbf{x}_i} \sigma_t(\mathbf{u}) d\mathbf{u}\right)$ [S3].
2.  **Light Sampling (Next Event Estimation):** For each sample point $\mathbf{x}_i$, iterate over all light sources $k$.
3.  **Incident Radiance Calculation:** Compute the incident radiance $L_{in}(\mathbf{x}_i, \boldsymbol{\omega}_{i,k})$ from light $k$. For a point light with intensity $I_k$ at distance $d_k$:
    $$ L_{in}(\mathbf{x}_i, \boldsymbol{\omega}_{i,k}) = \frac{I_k}{d_k^2} T(\mathbf{l}_k, \mathbf{x}_i) p(\boldsymbol{\omega}_{i,k}, \boldsymbol{\omega}_o) $$
    where $T(\mathbf{l}_k, \mathbf{x}_i)$ is the transmittance from the light to the point, and $p$ is the phase function [S1, unofficial].
4.  **Integration:** Accumulate the contribution of each sample point:
    $$ L_{scattered} = \sum_{i} T(\mathbf{o}, \mathbf{x}_i) \sigma_s(\mathbf{x}_i) \sum_{k} L_{in}(\mathbf{x}_i, \boldsymbol{\omega}_{i,k}) \Delta x_i $$
    where $\Delta x_i$ is the step size.
5.  **Background:** Add the background radiance $L_{bg}$ attenuated by the total transmittance: $L_{final} = L_{scattered} + T(\mathbf{o}, \mathbf{p}_{far}) L_{bg}$ [S3].

**Formulas:**
*   **Single Scattering Integral:**
    $$ L_o(\mathbf{o}, \boldsymbol{\omega}) = T(\mathbf{o}, \mathbf{p}_{far}) L_{bg} + \int_{\mathbf{o}}^{\mathbf{p}_{far}} T(\mathbf{o}, \mathbf{x}) \sigma_s(\mathbf{x}) L_{in}(\mathbf{x}, \boldsymbol{\omega}_i) d\mathbf{x} $$
    where $L_s(x_t, \vec w) = \int_{S^2} phase(x_t, \vec w', \vec w) L_i(x_t, \vec w') d\vec w'$ represents the in-scattered radiance component [S1, unofficial].

**Parameters:**
*   **Step Size:** Determined by volume resolution or adaptive sampling. Typical values depend on scene scale; equi-angular sampling may be used for area lights [S1, unofficial].
*   **Phase Function:** Henyey-Greenstein is common, parameterized by anisotropy $g$ (-1 to 1) [S1, unofficial].

**Edge Cases and Pitfalls:**
*   **Precision:** Transmittance can underflow to zero in dense volumes, causing numerical instability. Clamp $\sigma_t$ or use log-space integration [G].
*   **Boundaries:** Ensure ray marching stops at volume boundaries to avoid sampling outside the defined density field.
*   **Degenerate Input:** If $\sigma_s(\mathbf{x}) = 0$, the integral contribution is zero; skip lighting calculations for non-scattering regions.

**Pseudocode:**
```python
def single_scattering(ray_origin, ray_direction, volume, lights, background_radiance):
    # Initialize accumulators
    total_scattered = 0.0
    eye_transmittance = 1.0
    
    # Ray marching parameters
    step_size = volume.resolution_scale # Derived from volume grid size
    max_distance = volume.far_plane
    
    # Sample points along the ray
    for distance in range(0, int(max_distance), step_size):
        point = ray_origin + ray_direction * distance
        
        # Check if point is inside volume
        if not volume.contains(point):
            break
            
        # Get extinction coefficient
        sigma_t = volume.get_sigma_t(point)
        
        # Update eye transmittance
        eye_transmittance *= exp(-sigma_t * step_size)
        
        # Get scattering coefficient
        sigma_s = volume.get_sigma_s(point)
        
        # If no scattering, continue
        if sigma_s == 0:
            continue
            
        # Compute in-scattered radiance from all lights
        incident_radiance = 0.0
        for light in lights:
            # Vector from point to light
            to_light = light.position - point
            dist_to_light = length(to_light)
            
            # Transmittance from light to point
            light_transmittance = exp(-volume.integrate_sigma_t(point, light.position))
            
            # Incident radiance for point light
            # L_in = (I / d^2) * T * phase
            phase_val = phase_function(light.direction, ray_direction, volume.anisotropy)
            incident_radiance += (light.intensity / (dist_to_light ** 2)) * light_transmittance * phase_val
            
        # Accumulate contribution
        total_scattered += eye_transmittance * sigma_s * incident_radiance * step_size
        
    # Final radiance
    final_radiance = total_scattered + eye_transmittance * background_radiance
    return final_radiance
```

## Subtopics

### Monochromatic Mie Scattering Shading
This variant treats Mie scattering intensity $I_{SM}$ as monochromatic, occupying only one channel in the scattering texture, and shades it during rendering by multiplying by the attenuated direct illumination $I_0^I$ [S2]. It is chosen for real-time spectral scattering in large-scale natural participating media where computational efficiency is critical. An alternative is using the proportionality rule from [Bruneton and Neyret 2008] instead of direct multiplication [S2].

## Operating characteristics
*   **Time Complexity:** $O(N \cdot L)$, where $N$ is the number of sample points along the ray and $L$ is the number of light sources.
*   **Memory Complexity:** $O(V)$, where $V$ is the volume of the density grid.
*   **Performance:** With equi-angular sampling, rendering can be achieved in less than 10 minutes per image with <100 spp for complex scenes [S1, unofficial].
*   **Strengths:** Simple to implement; provides physically plausible direct illumination in volumes.
*   **Limitations:** Ignores multiple scattering, leading to dark shadows in dense media; performance degrades linearly with the number of lights.
*   **When to Use:** Real-time applications or offline rendering where multiple scattering is negligible or approximated separately.
*   **When Not to Use:** Highly scattering media (e.g., fog, milk) where multiple scattering dominates.

## Background
The single scattering approximation is a foundational concept in volume rendering, derived from the radiative transfer equation. It is widely used in computer graphics for rendering participating media such as fog, smoke, and clouds. The method is detailed in various academic resources, including CMU lecture notes on volume rendering equation and free-path sampling [S1, unofficial].
