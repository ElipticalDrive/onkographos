# Rayleigh Phase Function

Also called: Rayleigh Scattering Phase Function, RayleighSphere, Simple Rayleigh scattering

## Overview
The Rayleigh Phase Function models the angular distribution of light scattered by particles significantly smaller than the wavelength of light, such as air molecules in the atmosphere [S2, unofficial][S3, unofficial]. It serves as a more physically accurate alternative to the Isotropic Phase Function for media with small particles, capturing the characteristic dipole radiation pattern where scattering is favored in the forward and backward directions and null at 90 degrees [S2, unofficial][S4, unofficial]. Unlike the Henyey-Greenstein Phase Function, which is a parametric approximation often used for larger particles like water droplets, the Rayleigh function is derived from first principles of dipole radiation and provides an exact analytical solution for unpolarized scattering in constant volumes [S1, unofficial][S3, unofficial].

## How it works
**Inputs:**
- Outgoing direction $\omega_o$ (unit vector).
- Incident direction $\omega_i$ (unit vector, direction from which light arrives).
- Uniform random sample $s = (\xi_1, \xi_2)$ where $\xi_1, \xi_2 \in [0, 1]$.

**Outputs:**
- Sampled incoming direction $\omega_i'$ (unit vector).
- Probability density $p(\omega_i' | \omega_o)$.

**Data Structures:**
- `RayleighSphere`: A PDF variant struct containing:
  - `incident`: `Vector3` representing the direction the light came from ($\omega_i$).

**Formulas:**
The normalized phase function for unpolarized Rayleigh scattering is defined as [S3, unofficial]:
$$ p(\cos\theta) = \frac{3}{4} (1 + \cos^2\theta) $$
where $\theta$ is the scattering angle between the incident direction $\omega_i$ and the outgoing direction $\omega_o$, such that $\cos\theta = \omega_i \cdot \omega_o$.

The probability density function (PDF) over the sphere is [S3, unofficial]:
$$ p(\omega) = \frac{3}{16\pi} (1 + (\omega_i \cdot \omega)^2) $$
This is normalized such that $\int_{S^2} p(\omega) d\Omega = 1$ [S3, unofficial].

**Sampling Algorithm:**
To sample a direction $\omega$ from this distribution:
1. Sample the azimuthal angle $\phi$ uniformly from $[0, 2\pi]$ using $\xi_2$:
   $$ \phi = 2\pi \xi_2 $$
2. Sample the cosine of the scattering angle $\cos\theta$ using the inverse CDF method. The CDF for the distribution $p(\cos\theta) \propto (1 + \cos^2\theta)$ leads to the cubic equation [S3, unofficial]:
   $$ \cos^3\theta + 3\cos\theta + 4(1 - 2\xi_1) = 0 $$
   Let $x = \cos\theta$. The equation is $x^3 + 3x + 2B = 0$ where $B = 2\xi_1 - 1$.
   Using Cardano's formula for the real root of $x^3 + 3ax + 2b = 0$ with $a=1$ and $b=B$:
   $$ u = \sqrt[3]{b + \sqrt{b^2 + a^3}} $$
   $$ x = u - \frac{a}{u} = u - \frac{1}{u} $$
   Thus:
   $$ \cos\theta = \sqrt[3]{B + \sqrt{B^2 + 1}} - \frac{1}{\sqrt[3]{B + \sqrt{B^2 + 1}}} $$
   [S2, unofficial][S3, unofficial]
   
   *Alternative:* Rejection sampling can be used with a bounding distribution of $1.5 \times \text{uniform}$, which has a 75% acceptance rate [S3, unofficial].

3. Construct the sampled direction $\omega$ in the local coordinate system defined by $\omega_i$:
   - Let $z = \omega_i$.
   - Construct an orthonormal basis $(x, y, z)$ where $z$ is the incident direction.
   - $\omega = \sin\theta \cos\phi \cdot x + \sin\theta \sin\phi \cdot y + \cos\theta \cdot z$.

**Pseudocode:**
```python
import math

def cardano_formula(a: float, b: float) -> float:
    """
    Computes the real solution for x^3 + 3*a*x + 2*b = 0.
    Uses Cardano's formula.
    """
    # u = cbrt(b + sqrt(b^2 + a^3))
    # x = u - a/u
    # Note: a is typically 1.0 for Rayleigh
    disc = b * b + a * a * a
    sqrt_disc = math.sqrt(disc)
    u = math.pow(b + sqrt_disc, 1.0 / 3.0)
    if u == 0:
        return 0.0 # Guard against division by zero, though unlikely with valid inputs
    return u - a / u

def sample_rayleigh_phase(incident: Vector3, s: Vector2) -> Tuple[Vector3, float]:
    """
    Samples the Rayleigh phase function.
    
    Args:
        incident: The direction the light is coming from (omega_i).
        s: A 2D uniform random sample (xi1, xi2).
        
    Returns:
        sampled_direction: The new direction omega.
        pdf: The probability density of the sampled direction.
    """
    # 1. Sample phi uniformly
    phi = 2.0 * math.pi * s[1]
    
    # 2. Sample cos_theta using inverse CDF (Cardano's formula)
    # Equation: cos^3(theta) + 3*cos(theta) + 4*(1 - 2*xi1) = 0
    # Let x = cos(theta). x^3 + 3x + 2B = 0 where B = 2*xi1 - 1
    B = 2.0 * s[0] - 1.0
    cos_theta = cardano_formula(1.0, B)
    
    # Clamp to valid range [-1, 1] to handle floating point errors
    cos_theta = max(-1.0, min(1.0, cos_theta))
    
    # 3. Construct the direction
    sin_theta = math.sqrt(1.0 - cos_theta * cos_theta)
    
    # Create an orthonormal basis with 'incident' as the Z-axis
    # Helper to create basis from a vector
    x, y, z = create_orthonormal_basis(incident)
    
    # Direction in local space: (sin_theta * cos(phi), sin_theta * sin(phi), cos_theta)
    # Transform to world space
    sampled_direction = (
        x * (sin_theta * math.cos(phi)) +
        y * (sin_theta * math.sin(phi)) +
        z * cos_theta
    )
    
    # 4. Calculate PDF
    # p(omega) = (3 / (16 * pi)) * (1 + (incident . omega)^2)
    cos_scatter = incident.dot(sampled_direction)
    pdf = (3.0 / (16.0 * math.pi)) * (1.0 + cos_scatter * cos_scatter)
    
    return sampled_direction, pdf

def create_orthonormal_basis(v: Vector3) -> Tuple[Vector3, Vector3, Vector3]:
    """
    Creates an orthonormal basis (x, y, z) where z = v.normalized().
    """
    z = v.normalized()
    # Choose an arbitrary vector not parallel to z
    if abs(z.x) < 0.9:
        temp = Vector3(1, 0, 0)
    else:
        temp = Vector3(0, 1, 0)
    
    x = temp.cross(z).normalized()
    y = z.cross(x).normalized()
    return x, y, z
```

**Edge Cases and Pitfalls:**
- **Volume Scattering Integration:** In volume rendering, the in-scattering integral is $\int p(\omega) L(\omega) d\omega$. There is no $\cos\theta$ term in the integration measure for phase functions in volumes, unlike surface BRDFs. The PDF used for importance sampling must reflect the phase function directly without additional geometric cosine factors [S3, unofficial].
- **Precision:** The cubic solution via Cardano's formula is stable for the range of $\xi \in [0,1]$. However, floating-point errors may result in $\cos\theta$ slightly outside $[-1, 1]$, requiring clamping [S2, unofficial].
- **Wavelength Dependence:** While the phase function shape is independent of wavelength, the scattering coefficient $\sigma_s$ scales with $\lambda^{-4}$. For spectrally-varying density, distance sampling should use the maximum $\sigma$ across all wavelengths to avoid bias, followed by per-wavelength transmittance weighting [S3, unofficial].

## Operating characteristics
- **Time Complexity:** Sampling is $O(1)$, involving a few trigonometric operations and a cubic root calculation.
- **Memory Complexity:** $O(1)$, requiring only the storage of the incident direction vector.
- **Strengths:** Physically accurate for small particles; provides the "silver lining" effect in clouds and atmospheric scattering [S4, unofficial]; normalized analytically.
- **Limitations:** Only valid for particles much smaller than the wavelength; does not account for polarization (uses unpolarized average); less flexible than Henyey-Greenstein for large particles [S1, unofficial][S3, unofficial].
- **When to use:** Atmospheric scattering, fog with small particulates, cloud rendering where forward/backward lobes are desired.
- **When not to use:** Large particles (use Mie or Henyey-Greenstein), polarized light simulations.

## Background
The Rayleigh Phase Function is derived from the theory of dipole radiation, describing the scattering of electromagnetic waves by particles much smaller than the wavelength [S3, unofficial]. It was historically used to explain the blue color of the sky and the red color of sunsets. In computer graphics, it has been implemented in various renderers, such as Appleseed [S2, unofficial] and Luxide [S3, unofficial], to provide physically based volume scattering. It is often contrasted with the Henyey-Greenstein Phase Function, which is a parametric model suitable for larger particles like water droplets in clouds [S1, unofficial][S4, unofficial].
