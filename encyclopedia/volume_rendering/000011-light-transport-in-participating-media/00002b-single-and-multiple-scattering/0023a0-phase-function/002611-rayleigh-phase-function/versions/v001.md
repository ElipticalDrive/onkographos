# Rayleigh Phase Function

Also called: Rayleigh Scattering Phase Function, RayleighSphere, Simple Rayleigh scattering

## Overview
The Rayleigh phase function models the angular distribution of light scattered by particles much smaller than the wavelength of light, such as air molecules in the atmosphere [S3, unofficial]. It produces a characteristic two-lobe distribution that favors forward and backward scattering while exhibiting zero intensity at 90-degree angles [S2, S3, unofficial]. Unlike the isotropic phase function, it introduces anisotropy, and unlike the Henyey-Greenstein function, it is derived from physical dipole radiation principles rather than empirical fitting [S2, S3, unofficial].

## How it works
### Inputs and Outputs
*   **Input:** Incident direction $\omega_i$ (direction from which light arrives), scattered direction $\omega_o$ (direction towards the observer), and optionally wavelength $\lambda$ for spectral variations.
*   **Output:** Probability density value $p(\omega_o | \omega_i)$ for importance sampling, or the phase function value for rendering calculations.

### Data Structures
The implementation requires a structure to store the reference axis for sampling.

**`RayleighSphere` (Pdf Variant)**
*   `incident`: `Vector3` — The unit vector representing the direction the light came from ($-\omega_i$). This defines the axis of symmetry for the phase function [S2, unofficial].

**`Rayleigh` (Material/Phase Function Object)**
*   `reflectance_texture`: `Arc<dyn Texture>` — The albedo color of the scattering medium [S2, unofficial].
*   `emittance_texture`: `Arc<dyn Texture>` — Always `SolidColor::BLACK` (non-emissive) [S2, unofficial].

### Formulas
The normalized phase function for unpolarized light is defined as [S1, S2, S3, unofficial]:

$$ p(\cos\theta) = \frac{3}{16\pi} (1 + \cos^2\theta) $$

Where:
*   $\theta$ is the scattering angle between the incident direction $\omega_i$ and the scattered direction $\omega_o$.
*   $\cos\theta = \omega_i \cdot \omega_o$.
*   The normalization constant $\frac{3}{16\pi}$ ensures $\int_{4\pi} p(\omega) d\omega = 1$ [S2, unofficial].

**Wavelength Dependence:**
The scattering coefficient $\sigma_s$ scales with wavelength $\lambda$ as [S2, unofficial]:

$$ \sigma_s(\lambda) = \sigma_s(\lambda_0) \times \left(\frac{\lambda_0}{\lambda}\right)^4 $$

Where $\lambda_0$ is a reference wavelength [S2, unofficial].

### Sampling Algorithm
To sample a direction $\omega_o$ given $\omega_i$:

1.  **Sample Azimuth ($\phi$):** Generate $\phi$ uniformly from $[0, 2\pi]$ [S2, unofficial].
2.  **Sample Cosine of Scattering Angle ($\cos\theta$):**
    *   Generate a uniform random variable $\xi \in [0, 1]$ [S2, unofficial].
    *   Solve the cubic equation for $x = \cos\theta$:
        $$ x^3 + 3x + 4(1 - 2\xi) = 0 $$
    *   The real root of this cubic equation is the sampled $\cos\theta$ [S2, unofficial].
    *   *Alternative:* Rejection sampling can be used with a bounding distribution of $1.5 \times \text{uniform}$, yielding a 75% acceptance rate [S2, unofficial].
3.  **Construct Direction:**
    *   Construct a local coordinate system (ONB) aligned with the incident direction $\omega_i$.
    *   Convert spherical coordinates $(\theta, \phi)$ to Cartesian coordinates in this local frame.
    *   Transform the resulting vector to world space [S2, unofficial].

### Pseudocode

```python
import math

def rayleigh_phase_pdf(incident: Vector3, direction: Vector3) -> float:
    """
    Evaluates the probability density of the Rayleigh phase function.
    incident: The direction the light came from (unit vector).
    direction: The sampled direction (unit vector).
    """
    cos_theta = incident.dot(direction)
    # p(cos_theta) = 3 / (16 * pi) * (1 + cos_theta^2)
    return (3.0 / (16.0 * math.pi)) * (1.0 + cos_theta * cos_theta)

def sample_rayleigh_phase(incident: Vector3) -> Vector3:
    """
    Samples a direction from the Rayleigh phase distribution.
    incident: The direction the light came from (unit vector).
    Returns: A unit vector representing the scattered direction.
    """
    # 1. Sample phi uniformly
    phi = random.uniform(0.0, 2.0 * math.pi)
    
    # 2. Sample cos_theta by solving cubic: x^3 + 3x + 4(1-2xi) = 0
    xi = random.uniform(0.0, 1.0)
    # Coefficients for cubic equation x^3 + px + q = 0
    # Here p = 3, q = 4(1 - 2*xi)
    p = 3.0
    q = 4.0 * (1.0 - 2.0 * xi)
    
    # Solve using Cardano's formula for depressed cubic x^3 + px + q = 0
    # Discriminant D = (q/2)^2 + (p/3)^3
    D = (q / 2.0)**2 + (p / 3.0)**3
    
    # Since p > 0, D > 0, so there is one real root.
    # u = cbrt(-q/2 + sqrt(D))
    # v = cbrt(-q/2 - sqrt(D))
    # x = u + v
    
    sqrt_D = math.sqrt(D)
    u = math.cbrt(-q / 2.0 + sqrt_D)
    v = math.cbrt(-q / 2.0 - sqrt_D)
    cos_theta = u + v
    
    # 3. Construct direction in local space aligned with incident
    # We need an orthonormal basis (ONB) where one axis is incident.
    # Let incident be the Z-axis.
    # Choose an arbitrary vector not parallel to incident for X-axis.
    if abs(incident.z) < 0.999:
        temp = Vector3(0, 0, 1)
    else:
        temp = Vector3(1, 0, 0)
    
    # Gram-Schmidt to get local X
    local_x = (temp - incident.dot(temp) * incident).normalize()
    local_y = incident.cross(local_x).normalize()
    
    # Convert spherical to Cartesian in local space
    # x = sin(theta) * cos(phi)
    # y = sin(theta) * sin(phi)
    # z = cos(theta)
    sin_theta = math.sqrt(max(0.0, 1.0 - cos_theta * cos_theta))
    
    local_dir = Vector3(
        sin_theta * math.cos(phi),
        sin_theta * math.sin(phi),
        cos_theta
    )
    
    # Transform to world space
    # world_dir = local_dir.x * local_x + local_dir.y * local_y + local_dir.z * incident
    return local_dir.x * local_x + local_dir.y * local_y + local_dir.z * incident

def rayleigh_scattering_coefficient(sigma_s_0: float, lambda_0: float, lambda_current: float) -> float:
    """
    Calculates the wavelength-dependent scattering coefficient.
    """
    return sigma_s_0 * (lambda_0 / lambda_current)**4
```

### Edge Cases and Pitfalls
*   **Volume Scattering Integration:** In volume rendering, the scattering integral is $\int phase \times L d\Omega$. There is no $\cos\theta$ term from the surface area projection (as in surface rendering). The PDF used for importance sampling must match the phase function exactly without additional geometric terms [S2, unofficial].
*   **Degenerate Incident Direction:** When constructing the local coordinate system for sampling, ensure the auxiliary vector is not parallel to the incident direction to avoid numerical instability in cross products [S2, G, unofficial].
*   **Spectral Sampling:** If using wavelength-dependent scattering coefficients, distance sampling in the volume should use the maximum $\sigma_s$ across all wavelengths to avoid bias. Per-wavelength transmittance weighting must then be applied [S2, unofficial].

## Subtopics

### [Henyey-Greenstein Phase Function](1010-henyey-greenstein-phase-function.md)
An empirical phase function often used for Mie scattering (larger particles). It is chosen when forward scattering is dominant and asymmetric, unlike the symmetric lobes of Rayleigh.

### [Isotropic Phase Function](5147-isotropic-phase-function.md)
Assumes equal scattering in all directions. Chosen for simplicity or when particle size is comparable to wavelength but polarization effects are ignored and anisotropy is not required.

## Operating characteristics
*   **Time Complexity:** $O(1)$ for evaluation and sampling. Solving the cubic equation involves a constant number of arithmetic operations [S2, unofficial].
*   **Memory Complexity:** $O(1)$ per instance, storing only the incident direction vector [S2, unofficial].
*   **Strengths:** Physically accurate for small particles; produces the "silver lining" effect in clouds and atmospheric haze [S3, unofficial].
*   **Limitations:** Only valid for particles much smaller than the wavelength of light; does not account for polarization (uses unpolarized average) [S2, S3, unofficial].
*   **When to use:** Atmospheres, fog, and clouds where molecular scattering is significant.
*   **When not to use:** Large particles (use Henyey-Greenstein), or when polarization tracking is required [S2, unofficial].

## Background
Rayleigh scattering is derived from classical dipole radiation theory [S2, unofficial]. It was historically used to explain the blue color of the sky and the red color of sunsets. In computer graphics, it is widely used in real-time cloud rendering and atmospheric effects to simulate anisotropic scattering [S3, unofficial]. The specific implementation details for importance sampling in path tracers have been documented in recent graphics development discussions [S2, unofficial].
