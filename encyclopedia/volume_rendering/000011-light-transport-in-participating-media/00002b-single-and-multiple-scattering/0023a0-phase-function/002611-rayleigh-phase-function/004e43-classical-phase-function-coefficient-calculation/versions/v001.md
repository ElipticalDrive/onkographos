# Classical Phase Function Coefficient Calculation

Also called: Classical Phase Function Coefficients, Atmospheric Phase Function Coefficients

## Overview
Computes the polynomial coefficients $c_i$ for classical phase functions (Isotropic, Rayleigh, Hazzy, Murky) used in atmospheric scattering models. It solves the problem of evaluating the single-scattering phase function efficiently by pre-computing the angular-independent polynomial terms that multiply the exponential attenuation factor $e^{-k t h}$. Unlike the Rayleigh Phase Function article which defines the physical model, this method provides the specific algebraic expansion required for real-time implementation of these classical approximations.

## How it works
**Inputs:**
- $k$: Extinction coefficient (or optical depth parameter).
- $t$: Path length or distance variable.
- $h$: Height or vertical coordinate variable.
- $type$: Enum or string specifying the phase function type ('Isotropic', 'Rayleigh', 'Hazzy', 'Murky').

**Outputs:**
- Array of coefficients $[c_0, c_1, c_2, \dots]$ depending on the requested order for the specified phase function.

**Data Structures:**
- Coefficients are stored as floating-point numbers. The number of coefficients varies by type (see formulas below).

**Formulas:**
Let $x = k t h$. The exponential term is $E = e^{-x}$.

1. **Isotropic Phase Function** [S1, unofficial]:
   $$c_0 = E$$
   $$c_1 = -x E$$
   $$c_2 = (x^2 - x) E$$
   $$c_3 = \left(\frac{x^3}{6} - \frac{x^2}{2} + x\right) E$$
   $$c_4 = \left(\frac{x^4}{24} - \frac{x^3}{6} + \frac{11 x^2}{24} - \frac{5 x}{24}\right) E$$

2. **Rayleigh Phase Function** [S1, unofficial]:
   $$c_0 = \frac{3 - x}{4} E$$
   $$c_1 = \left(\frac{3}{4} - \frac{3 x}{4}\right) E$$
   $$c_2 = \left(\frac{3 x^2}{8} - \frac{3 x}{4}\right) E$$

3. **Hazzy Phase Function** [S1, unofficial]:
   $$c_0 = \frac{265 - x}{256} E$$
   $$c_1 = \left(\frac{265 x}{256} - \frac{9}{36}\right) E$$
   $$c_2 = \left(\frac{265 x^2}{512} - \frac{121 x}{64} + \frac{63}{256}\right) E$$

4. **Murky Phase Function** [S1, unofficial]:
   $$c_0 = \frac{2147483673}{2147483648} E$$
   $$c_1 = \left(\frac{2147483673 x}{367108864} - \frac{25}{2147483648}\right) E$$
   $$c_2 = \left(\frac{2147483673 x^2}{4294967296} - \frac{2147482073 x}{134217728} + \frac{775}{4294967296}\right) E$$

**Pseudocode:**
```python
import math

def compute_classical_phase_coefficients(k, t, h, phase_type):
    """
    Computes coefficients for classical phase functions.
    
    Args:
        k (float): Extinction coefficient parameter.
        t (float): Path length.
        h (float): Height/vertical coordinate.
        phase_type (str): 'Isotropic', 'Rayleigh', 'Hazzy', or 'Murky'.
        
    Returns:
        list[float]: Coefficients [c0, c1, ...].
    """
    x = k * t * h
    exp_term = math.exp(-x)
    
    if phase_type == 'Isotropic':
        c0 = exp_term
        c1 = -x * exp_term
        c2 = (x**2 - x) * exp_term
        c3 = (x**3 / 6.0 - x**2 / 2.0 + x) * exp_term
        c4 = (x**4 / 24.0 - x**3 / 6.0 + 11.0 * x**2 / 24.0 - 5.0 * x / 24.0) * exp_term
        return [c0, c1, c2, c3, c4]
        
    elif phase_type == 'Rayleigh':
        c0 = (3.0 - x) / 4.0 * exp_term
        c1 = (3.0 / 4.0 - 3.0 * x / 4.0) * exp_term
        c2 = (3.0 * x**2 / 8.0 - 3.0 * x / 4.0) * exp_term
        return [c0, c1, c2]
        
    elif phase_type == 'Hazzy':
        c0 = (265.0 - x) / 256.0 * exp_term
        c1 = (265.0 * x / 256.0 - 9.0 / 36.0) * exp_term
        c2 = (265.0 * x**2 / 512.0 - 121.0 * x / 64.0 + 63.0 / 256.0) * exp_term
        return [c0, c1, c2]
        
    elif phase_type == 'Murky':
        # Constants for readability
        M0_num = 2147483673.0
        M0_den = 2147483648.0
        M1_num = 2147483673.0
        M1_den = 367108864.0
        M1_const = 25.0 / 2147483648.0
        M2_num = 2147483673.0
        M2_den = 4294967296.0
        M2_mid_num = 2147482073.0
        M2_mid_den = 134217728.0
        M2_const = 775.0 / 4294967296.0
        
        c0 = (M0_num / M0_den) * exp_term
        c1 = (M1_num * x / M1_den - M1_const) * exp_term
        c2 = (M2_num * x**2 / M2_den - M2_mid_num * x / M2_mid_den + M2_const) * exp_term
        return [c0, c1, c2]
        
    else:
        raise ValueError(f"Unknown phase type: {phase_type}")
```

**Edge Cases and Pitfalls:**
- **Precision:** The Murky phase function uses large integers in its coefficients. Using single-precision floats may introduce rounding errors in the constant terms. Double precision is recommended for Murky calculations [S1, unofficial].
- **Boundary Conditions:** If $k=0$ or $t=0$ or $h=0$, then $x=0$ and $E=1$. The formulas should handle this naturally, but implementations should ensure no division by zero occurs if optimized forms are used.
- **Negative Inputs:** $k, t, h$ are typically non-negative physical quantities. Negative values may result in $x < 0$, causing $E > 1$, which might be physically invalid for attenuation but mathematically valid in the formula.

## Subtopics

### Mie Phase Function Calculation
Calculates the phase function for homogeneous spheres larger than the wavelength of light (rain and cloud particles) using Mie theory [S2]. It differs from classical phase functions by accounting for diffraction and interference effects in larger particles. It is chosen when simulating rain or clouds where particle size is significant relative to wavelength. The calculation requires an angular resolution of 0.1 degrees and uses a lognormal particle size distribution with parameters from Pruppacher and Klett [PK00] [S2]. Implementation typically relies on external libraries like Philip Laven’s MiePlot, which implements Bohren and Huffman’s Mie code [S2].

## Operating characteristics
- **Time Complexity:** $O(1)$ per phase function evaluation, as it involves a fixed number of arithmetic operations and one exponential calculation.
- **Memory Complexity:** $O(1)$, storing only a few coefficients.
- **Strengths:** Extremely fast evaluation suitable for real-time rendering. Pre-computing coefficients separates the angular dependence (handled by the phase function model) from the exponential attenuation.
- **Limitations:** Limited to specific classical approximations (Isotropic, Rayleigh, Hazzy, Murky). Does not handle complex particle shapes or size distributions (use Mie Phase Function Calculation for those).
- **When to use:** Real-time atmospheric scattering where performance is critical and the classical approximations are sufficient.
- **When not to use:** When high-fidelity scattering for rain/clouds is required (use Mie Phase Function Calculation) or when polarization effects are critical (Rayleigh is unpolarized average).

## Background
The coefficients for classical phase functions were derived for efficient real-time rendering of atmospheric scattering. The specific algebraic forms for Isotropic, Rayleigh, Hazzy, and Murky functions are presented in [S1, unofficial]. The Hazzy and Murky functions are less standard than Isotropic and Rayleigh, likely serving as empirical or semi-analytical approximations for specific atmospheric conditions (haze and murky water/air) in the context of the source paper. The Rayleigh phase function itself is derived from dipole radiation theory [Parent].
