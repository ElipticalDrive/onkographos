# Classical Phase Function Coefficient Calculation

Also called: Classical Phase Function Coefficients, Atmospheric Phase Function Coefficients

## Overview
This method computes the analytical coefficients ($c_0, c_1, c_2, \dots$) for classical phase functions used in atmospheric scattering models. It solves the problem of evaluating the single-scattering integral for specific phase function types (Isotropic, Rayleigh, Hazzy, Murky) by reducing the angular integration to a closed-form polynomial-exponential expression [S1, unofficial]. It is distinct from numerical quadrature methods by providing exact analytic solutions for these specific approximations, and from Mie calculations by handling particles smaller than or comparable to the wavelength rather than large homogeneous spheres [S1, unofficial][15655-mie-phase-function-calculation.md].

## How it works
**Inputs:**
- $k$: Extinction coefficient (or related optical depth parameter).
- $t$: Optical depth or path length.
- $h$: A geometric or scaling factor (often related to height or phase angle cosine, depending on the specific derivation context in the source).

**Outputs:**
- A set of coefficients $c_i$ for the chosen phase function type. These coefficients are used to construct the phase function value $P(\theta)$ or the scattering integral result.

**Data Structures:**
- No complex data structures. The output is a small array or set of scalar values $[c_0, c_1, c_2, \dots]$.

**Formulas:**
The coefficients are defined by the following closed-form expressions. All formulas include the common term $e^{-k t h}$.

1. **Isotropic Phase Function:**
   $$c_0 = e^{-k t h}$$
   $$c_1 = -k t h e^{-k t h}$$
   $$c_2 = (k t^2 h^2 - k t h) e^{-k t h}$$
   $$c_3 = \left(\frac{(k h)^3}{6} - \frac{k t^2 h^2}{2} + k t h\right) e^{-k t h}$$
   $$c_4 = \left(\frac{(k h)^4}{24} - \frac{(k t h)^3}{6} + \frac{11 k t^2 h^2}{24} - \frac{5 k t h}{24}\right) e^{-k t h}$$

2. **Rayleigh Phase Function:**
   $$c_0 = \frac{3 - k t h}{4} e^{-k t h}$$
   $$c_1 = \left(\frac{3}{4} - \frac{3 k t h}{4}\right) e^{-k t h}$$
   $$c_2 = \left(\frac{3 k^2 h^2}{8} - \frac{3 k t h}{4}\right) e^{-k t h}$$

3. **Hazzy Phase Function:**
   $$c_0 = \frac{265 - k t h}{256} e^{-k t h}$$
   $$c_1 = \left(\frac{265 k t h}{256} - \frac{9}{36}\right) e^{-k t h}$$
   $$c_2 = \left(\frac{265 k t^2 h^2}{512} - \frac{121 k t h}{64} + \frac{63}{256}\right) e^{-k t h}$$

4. **Murky Phase Function:**
   $$c_0 = \frac{2147483673}{2147483648} e^{-k t h}$$
   $$c_1 = \left(\frac{2147483673 k t h}{367108864} - \frac{25}{2147483648}\right) e^{-k t h}$$
   $$c_2 = \left(\frac{2147483673 k t^2 h^2}{4294967296} - \frac{2147482073 k t h}{134217728} + \frac{775}{4294967296}\right) e^{-k t h}$$

**Parameters:**
- Typical values for $k, t, h$ depend on the atmospheric model (e.g., Earth's atmosphere at sea level vs. altitude). Not given in the sources.

**Edge Cases and Pitfalls:**
- **Precision:** The Murky phase function uses large integers (powers of 2) in its coefficients. Implementers should use floating-point arithmetic (float32 or float64) to avoid integer overflow and maintain precision. The denominator $2147483648$ is $2^{31}$.
- **Boundary Conditions:** If $k t h = 0$, the exponential term becomes 1. The formulas simplify accordingly (e.g., $c_1$ becomes 0 for Isotropic).
- **Degenerate Input:** If $h=0$ or $t=0$, the optical depth is zero, and scattering is null. The coefficients should reflect the unscattered or direct transmission state.

**Pseudocode:**
```python
import math

def compute_classical_phase_coefficients(phase_type: str, k: float, t: float, h: float):
    """
    Computes coefficients for classical phase functions.
    
    Args:
        phase_type: One of 'isotropic', 'rayleigh', 'hazzy', 'murky'.
        k: Extinction parameter.
        t: Optical depth/length.
        h: Geometric/scaling factor.
        
    Returns:
        List of coefficients [c0, c1, c2, ...].
    """
    # Common term
    exponent = -k * t * h
    exp_term = math.exp(exponent)
    
    if phase_type == 'isotropic':
        kt_h = k * t * h
        k_h = k * h
        k_t2_h2 = k * (t ** 2) * (h ** 2)
        
        c0 = exp_term
        c1 = -kt_h * exp_term
        c2 = (k_t2_h2 - kt_h) * exp_term
        c3 = ((k_h ** 3) / 6.0 - k_t2_h2 / 2.0 + kt_h) * exp_term
        c4 = ((k_h ** 4) / 24.0 - (kt_h ** 3) / 6.0 + (11.0 * k_t2_h2) / 24.0 - (5.0 * kt_h) / 24.0) * exp_term
        return [c0, c1, c2, c3, c4]
    
    elif phase_type == 'rayleigh':
        kt_h = k * t * h
        k2_h2 = (k ** 2) * (h ** 2)
        
        c0 = ((3.0 - kt_h) / 4.0) * exp_term
        c1 = ((3.0 / 4.0) - (3.0 * kt_h) / 4.0) * exp_term
        c2 = ((3.0 * k2_h2) / 8.0 - (3.0 * kt_h) / 4.0) * exp_term
        return [c0, c1, c2]
    
    elif phase_type == 'hazzy':
        kt_h = k * t * h
        k_t2_h2 = k * (t ** 2) * (h ** 2)
        
        c0 = ((265.0 - kt_h) / 256.0) * exp_term
        c1 = ((265.0 * kt_h) / 256.0 - 9.0 / 36.0) * exp_term
        c2 = ((265.0 * k_t2_h2) / 512.0 - (121.0 * kt_h) / 64.0 + 63.0 / 256.0) * exp_term
        return [c0, c1, c2]
    
    elif phase_type == 'murky':
        kt_h = k * t * h
        k_t2_h2 = k * (t ** 2) * (h ** 2)
        
        # Using floating point division for large integers
        c0 = (2147483673.0 / 2147483648.0) * exp_term
        c1 = ((2147483673.0 * kt_h) / 367108864.0 - 25.0 / 2147483648.0) * exp_term
        c2 = ((2147483673.0 * k_t2_h2) / 4294967296.0 - (2147482073.0 * kt_h) / 134217728.0 + 775.0 / 4294967296.0) * exp_term
        return [c0, c1, c2]
    
    else:
        raise ValueError(f"Unknown phase type: {phase_type}")
```

## Subtopics

### [Mie Phase Function Calculation](15655-mie-phase-function-calculation.md)
Calculates the phase function for homogeneous spheres significantly larger than the wavelength of light, specifically modeling scattering by rain and cloud particles. It distinguishes itself from Rayleigh scattering (which handles particles smaller than the wavelength) by capturing complex interference phenomena such as the strong forward peak, rainbow angles, and the glory effect.

## Operating characteristics
- **Time Complexity:** $O(1)$ per phase function evaluation, as it involves a fixed number of arithmetic operations and one exponential calculation.
- **Memory Complexity:** $O(1)$, storing only a few scalar coefficients.
- **Measured Performance:** Not given in the sources.
- **Strengths:** Extremely fast evaluation; no iterative solvers or numerical integration required; exact analytic form avoids discretization errors.
- **Limitations:** Only applicable to the four specific classical phase functions (Isotropic, Rayleigh, Hazzy, Murky). Not suitable for arbitrary or measured phase functions. The "Hazzy" and "Murky" functions are approximations and may not accurately represent real-world aerosol scattering compared to more complex models.
- **When to use:** Real-time atmospheric rendering where performance is critical and the specific phase function approximations are acceptable.
- **When not to use:** When high-fidelity scattering for large particles (Mie regime) is required, or when using measured phase function data.

## Background
The coefficients for these classical phase functions are derived from analytical solutions to the radiative transfer equation under specific assumptions about particle size and distribution. The specific forms for Hazzy and Murky appear in practical real-time rendering contexts, likely originating from approximations of Henyey-Greenstein or other semi-empirical models adapted for atmospheric scattering [S1, unofficial]. The Rayleigh phase function is a standard result from dipole radiation theory. The source [S1, unofficial] compiles these specific coefficient sets for implementation in real-time rendering engines.
