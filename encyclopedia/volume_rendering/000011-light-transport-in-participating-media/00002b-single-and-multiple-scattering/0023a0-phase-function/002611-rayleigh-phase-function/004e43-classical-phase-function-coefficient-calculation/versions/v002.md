# Classical Phase Function Coefficient Calculation

Also called: Classical phase function coefficients, Atmospheric phase function coefficients, $c_n$ coefficients for phase functions

## Overview
This method computes the analytical coefficients $c_0, c_1, c_2, \dots$ for classical phase functions (Isotropic, Rayleigh, Hazzy, Murky) used in atmospheric scattering models. It solves the problem of evaluating the single-scattering integral terms efficiently by pre-computing the polynomial-exponential structure of the phase function integrals. It is distinct from [Mie Phase Function Calculation](15655-mie-phase-function-calculation.md), which handles larger particles with complex interference, by relying on simplified analytical approximations suitable for real-time rendering of fog and atmosphere.

## How it works
**Inputs:**
- $k$: Extinction coefficient (or optical depth parameter).
- $t$: Path length or distance variable.
- $h$: Height or geometric parameter (context-dependent, often related to atmospheric scale height or ray intersection).
- Phase function type: Isotropic, Rayleigh, Hazzy, or Murky.

**Outputs:**
- A list of coefficients $c_0, c_1, c_2, \dots$ for the selected phase function. These coefficients are used to construct the phase function value or its integral contributions.

**Data Structures:**
- No complex data structures. The output is a set of scalar values.

**Formulas:**
The coefficients are defined as follows. Note that $e^{-kth}$ is a common factor in all terms.

1. **Isotropic Phase Function:**
   $$c_0 = e^{-kth}$$
   $$c_1 = -kth e^{-kth}$$
   $$c_2 = (k^2 t^2 h^2 - kth) e^{-kth}$$
   $$c_3 = \left(\frac{(kh)^3}{6} - \frac{k^2 t^2 h^2}{2} + kth\right) e^{-kth}$$
   $$c_4 = \left(\frac{(kh)^4}{24} - \frac{(kth)^3}{6} + \frac{11 k^2 t^2 h^2}{24} - \frac{5 kth}{24}\right) e^{-kth}$$

2. **Rayleigh Phase Function:**
   $$c_0 = \frac{3 - kth}{4} e^{-kth}$$
   $$c_1 = \left(\frac{3}{4} - \frac{3 kth}{4}\right) e^{-kth}$$
   $$c_2 = \left(\frac{3 k^2 h^2}{8} - \frac{3 kth}{4}\right) e^{-kth}$$

3. **Hazzy Phase Function:**
   $$c_0 = \frac{265 - kth}{256} e^{-kth}$$
   $$c_1 = \left(\frac{265 kth}{256} - \frac{9}{36}\right) e^{-kth}$$
   $$c_2 = \left(\frac{265 k^2 t^2 h^2}{512} - \frac{121 kth}{64} + \frac{63}{256}\right) e^{-kth}$$

4. **Murky Phase Function:**
   $$c_0 = \frac{2147483673}{2147483648} e^{-kth}$$
   $$c_1 = \left(\frac{2147483673 kth}{367108864} - \frac{25}{2147483648}\right) e^{-kth}$$
   $$c_2 = \left(\frac{2147483673 k^2 t^2 h^2}{4294967296} - \frac{2147482073 kth}{134217728} + \frac{775}{4294967296}\right) e^{-kth}$$

**Parameters:**
- Typical values for $k, t, h$ depend on the specific atmospheric model and scene scale. Not given in the sources.

**Edge Cases and Pitfalls:**
- Precision: The Murky phase function uses large integers (powers of 2) in coefficients. Implementation should use floating-point arithmetic to avoid overflow or precision loss, though the denominators are exact powers of 2, allowing for efficient bit-shift operations if implemented in fixed-point or integer arithmetic.
- Boundaries: If $kth$ is very large, $e^{-kth}$ approaches zero, potentially causing underflow. If $kth$ is zero, the exponential is 1.

**Pseudocode:**
```python
import math

def compute_classical_phase_coefficients(phase_type, k, t, h):
    """
    Computes coefficients c0, c1, c2, etc. for classical phase functions.
    
    Args:
        phase_type (str): One of 'isotropic', 'rayleigh', 'hazzy', 'murky'.
        k (float): Extinction coefficient.
        t (float): Path length.
        h (float): Height/Geometric parameter.
        
    Returns:
        dict: Dictionary of coefficients c0, c1, c2, etc.
    """
    kt_h = k * t * h
    exp_term = math.exp(-kt_h)
    
    if phase_type == 'isotropic':
        c0 = exp_term
        c1 = -kt_h * exp_term
        c2 = (k**2 * t**2 * h**2 - kt_h) * exp_term
        c3 = ((k * h)**3 / 6.0 - k**2 * t**2 * h**2 / 2.0 + kt_h) * exp_term
        c4 = ((k * h)**4 / 24.0 - (kt_h)**3 / 6.0 + 11.0 * k**2 * t**2 * h**2 / 24.0 - 5.0 * kt_h / 24.0) * exp_term
        return {'c0': c0, 'c1': c1, 'c2': c2, 'c3': c3, 'c4': c4}
        
    elif phase_type == 'rayleigh':
        c0 = (3.0 - kt_h) / 4.0 * exp_term
        c1 = (3.0 / 4.0 - 3.0 * kt_h / 4.0) * exp_term
        c2 = (3.0 * k**2 * h**2 / 8.0 - 3.0 * kt_h / 4.0) * exp_term
        return {'c0': c0, 'c1': c1, 'c2': c2}
        
    elif phase_type == 'hazzy':
        c0 = (265.0 - kt_h) / 256.0 * exp_term
        c1 = (265.0 * kt_h / 256.0 - 9.0 / 36.0) * exp_term
        c2 = (265.0 * k**2 * t**2 * h**2 / 512.0 - 121.0 * kt_h / 64.0 + 63.0 / 256.0) * exp_term
        return {'c0': c0, 'c1': c1, 'c2': c2}
        
    elif phase_type == 'murky':
        # Using floating point division for clarity, though denominators are powers of 2
        c0 = (2147483673.0 / 2147483648.0) * exp_term
        c1 = (2147483673.0 * kt_h / 367108864.0 - 25.0 / 2147483648.0) * exp_term
        c2 = (2147483673.0 * k**2 * t**2 * h**2 / 4294967296.0 - 2147482073.0 * kt_h / 134217728.0 + 775.0 / 4294967296.0) * exp_term
        return {'c0': c0, 'c1': c1, 'c2': c2}
        
    else:
        raise ValueError("Unknown phase type")
```

## Subtopics

### [Mie Phase Function Calculation](15655-mie-phase-function-calculation.md)
Calculates the phase function for homogeneous spheres significantly larger than the wavelength of light, specifically modeling scattering by rain and cloud particles. It distinguishes itself from Rayleigh scattering (which handles particles smaller than the wavelength) by capturing complex interference phenomena such as the strong forward peak, rainbow angles, and the glory effect.

## Operating characteristics
- **Time Complexity:** $O(1)$ per phase function evaluation, as it involves a fixed number of arithmetic operations and one exponential function.
- **Memory Complexity:** $O(1)$, storing only a few scalar coefficients.
- **Measured Performance:** Not given in the sources.
- **Scaling:** Linear with the number of phase function evaluations.
- **Strengths:** Analytical closed-form solutions allow for very fast evaluation, suitable for real-time rendering.
- **Limitations:** Approximations may not capture the full complexity of scattering for particles in the Mie regime or for polarized light.
- **When to use:** Real-time atmospheric rendering where performance is critical and particle sizes are small (Rayleigh) or approximated (Hazzy/Murky).
- **When not to use:** High-fidelity offline rendering requiring accurate Mie scattering or polarized light simulation.

## Background
The coefficients for classical phase functions are derived from analytical solutions to the radiative transfer equation for specific scattering models. The Isotropic, Rayleigh, Hazzy, and Murky phase functions are approximations used in atmospheric scattering to model different types of particulate matter. The specific coefficients provided in [S1, unofficial] appear to be from a practical implementation for real-time rendering, possibly based on earlier work in thermal radiation or atmospheric physics.
