# Schlick Approximation
Also called: Schlick’s Phase Function

## Overview
The Schlick Approximation is an empirical phase function that provides a faster computational alternative to the Henyey-Greenstein phase function by avoiding the need to compute a square root [S1, S2, unofficial]. It approximates the angular scattering distribution of participating media while maintaining energy conservation [S1, unofficial].

## How it works
**Inputs and Outputs:**
- Input: $\theta$, the scattering angle between the incoming light direction and the outgoing view direction (in radians).
- Input: $k$, the anisotropy parameter.
- Output: $phase_{Schlick}(\theta)$, the probability density value for the given scattering angle.

**Data Structures:**
No complex data structures are required. The function is a direct mathematical evaluation.

**Formula:**
The phase function is defined as [S1, unofficial]:

$$
phase_{Schlick}(\theta) = \frac{1}{4\pi} \cdot \frac{1 - k^2}{(1 - k\cos(\theta))^2}
$$

**Parameters:**
- $k$: Anisotropy parameter analogous to $g$ in the Henyey-Greenstein function.
  - Range: $(-1, 1)$ [S1, unofficial].
  - $k = 0$: Isotropic scattering (uniform in all directions) [S1, unofficial].
  - $k > 0$: Forward-scattering (light continues in the general direction of travel) [S1, unofficial].
  - $k < 0$: Back-scattering (light reflects back towards the source) [S1, unofficial].

**Steps:**
1. Compute $\cos(\theta)$.
2. Compute the denominator term: $d = 1 - k \cdot \cos(\theta)$.
3. Compute the numerator term: $n = 1 - k^2$.
4. Evaluate the function: $phase = \frac{1}{4\pi} \cdot \frac{n}{d^2}$.

**Pseudocode:**
```python
import math

def schlick_phase_function(theta, k):
    """
    Computes the Schlick approximation of the phase function.
    
    Args:
        theta (float): Scattering angle in radians.
        k (float): Anisotropy parameter in (-1, 1).
        
    Returns:
        float: Phase function value.
    """
    cos_theta = math.cos(theta)
    
    # Denominator: (1 - k * cos(theta))^2
    denom = (1.0 - k * cos_theta) ** 2
    
    # Numerator: 1 - k^2
    numer = 1.0 - k * k
    
    # Full formula: (1 / 4pi) * (numer / denom)
    return (1.0 / (4.0 * math.pi)) * (numer / denom)
```

**Edge Cases and Pitfalls:**
- When $k=0$, the function simplifies to $\frac{1}{4\pi}$, representing isotropic scattering [S1, unofficial].
- The denominator $(1 - k\cos(\theta))^2$ is always positive for $k \in (-1, 1)$, avoiding division by zero.
- Energy conservation requires the integral over the sphere to equal 1. The factor $\frac{1}{4\pi}$ ensures this normalization [S1, unofficial].

## Subtopics

### [Cornette and Shanks Phase Function](1710-cornette-and-shanks-phase-function.md)
A phase function that blends isotropic and Henyey-Greenstein scattering, offering a different trade-off between computational cost and physical accuracy compared to Schlick.

### [Multiple Octaves Phase Function](4939-multiple-octaves-phase-function.md)
Uses multiple frequency octaves to create complex scattering patterns, distinct from the single-parameter simplicity of Schlick.

### [HG-Draine Blend Mie Approximation](10011-hg-draine-blend-mie-approximation.md)
Combines Henyey-Greenstein with Draine's Mie theory for more physically accurate scattering based on particle size, whereas Schlick is a purely empirical approximation.

### [Jendersie-d’Eon Phase Function](10716-jendersie-d-eon-phase-function.md)
A more complex phase function derived from Mie theory, providing higher fidelity than Schlick at the cost of performance.

### [Low-Albedo Illumination Model for Gases](12266-low-albedo-illumination-model-for-gases.md)
Focuses on illumination in low-albedo environments, differing from Schlick's general scattering approximation.

### [Exponential Phase Function](18395-exponential-phase-function.md)
Uses an exponential decay model for scattering, offering a different mathematical form than Schlick's rational function.

## Operating characteristics
- **Time Complexity:** $O(1)$ per evaluation. It requires one cosine, one multiplication, one squaring, and a few additions/divisions. It is significantly faster than Henyey-Greenstein because it avoids computing a square root (which is required for the HG denominator's $3/2$ power) [S1, unofficial].
- **Memory Complexity:** $O(1)$. No lookup tables or precomputed data structures are needed.
- **Strengths:** High performance due to the absence of square roots; simple implementation; good visual approximation of HG for many use cases [S2, unofficial].
- **Limitations:** It is an empirical approximation and may not capture the exact scattering behavior of HG as accurately as more complex models like Jendersie-d’Eon or HG-Draine [S2, unofficial].
- **When to use:** When performance is critical and a close approximation of Henyey-Greenstein scattering is sufficient [S2, unofficial].
- **When not to use:** When high physical accuracy is required, or when specific scattering features (like rainbows or complex Mie scattering) need to be modeled [S2, unofficial].

## Background
The Schlick Approximation was introduced as a simpler formula to approximate the Henyey-Greenstein phase function, which is widely used in computer graphics and other fields to model light scattering in participating media [S1, S2, unofficial]. The Henyey-Greenstein function itself was originally introduced for modeling intergalactic dust [S2, unofficial]. Schlick's approximation avoids the computational cost of the square root required in the HG formula, making it a popular choice for real-time rendering [S1, S2, unofficial].
