# Cornette and Shanks Phase Function
Also called: Phase Function Evaluation

## Overview
The Cornette and Shanks phase function is an anisotropic scattering model used to approximate Mie scattering in participating media, specifically designed to produce a realistic forward-scattering halo [S1, unofficial]. It is distinguished from the Henyey-Greenstein phase function by its specific algebraic form which includes a $(1 + \mu^2)$ term, providing a different angular distribution profile for the same asymmetry parameter $g$ [S1, unofficial]. It is commonly used in real-time volumetric rendering of clouds and fog [S1, unofficial].

## How it works
**Inputs:**
- $g$: The anisotropy factor, a scalar in the range $[-1, 1]$. Typical value for Mie scattering approximation is $0.76$ [S1, unofficial].
- $\mu$: The cosine of the scattering angle, computed as the dot product of the incoming light direction ($\mathbf{l}$) and the outgoing view direction ($\mathbf{v}$): $\mu = \mathbf{l} \cdot \mathbf{v}$ [S1, unofficial].

**Outputs:**
- $p(g, \mu)$: The phase function value, representing the probability density of scattering from direction $\mathbf{l}$ to $\mathbf{v}$ [S1, unofficial].

**Data Structures:**
None required; the function operates on scalar inputs [G].

**Formula:**
The phase function is defined as [S1, unofficial]:
$$
p(g, \mu) = \frac{3 (1 - g^2) (1 + \mu^2)}{8 \pi (2 + g^2) (1 + g^2 - 2 g \mu)^{1.5}}
$$

**Parameters:**
- $\pi$: The mathematical constant pi.
- $g$: Anisotropy factor controlling the scattering directionality [S1, unofficial].

**Algorithm:**
1. Compute $\mu = \text{dot}(\mathbf{l}, \mathbf{v})$ [G].
2. Compute the numerator: $N = 3 \cdot (1 - g^2) \cdot (1 + \mu^2)$ [G].
3. Compute the denominator base: $D_{base} = 1 + g^2 - 2 \cdot g \cdot \mu$ [G].
4. Compute the denominator: $D = 8 \cdot \pi \cdot (2 + g^2) \cdot D_{base}^{1.5}$ [G].
5. Return $N / D$ [G].

**Pseudocode:**
```python
import math

def cornette_shanks_phase(g: float, mu: float) -> float:
    """Evaluates the Cornette and Shanks phase function."""
    PI = 3.141592653589793
    numerator = 3.0 * (1.0 - g * g) * (1.0 + mu * mu)
    base_term = 1.0 + g * g - 2.0 * g * mu
    # Guard against division by zero when g=1 and mu=1 [G]
    if base_term <= 0.0:
        base_term = 1e-6
    power_term = math.pow(base_term, 1.5)
    denominator = 8.0 * PI * (2.0 + g * g) * power_term
    if denominator == 0.0:
        return 0.0
    return numerator / denominator

def evaluate_scatter(anisotropic: float, g: float, light_dir: tuple, view_dir: tuple) -> float:
    """Computes the final scattered light contribution by mixing isotropic and anisotropic scattering."""
    mu = light_dir[0]*view_dir[0] + light_dir[1]*view_dir[1] + light_dir[2]*view_dir[2]
    p = cornette_shanks_phase(g, mu)
    # Mix with isotropic scattering per source implementation [S1, unofficial]
    scatter_amount = anisotropic * p + (1.0 - anisotropic)
    return scatter_amount
```

**Edge Cases and Pitfalls:**
- **Singularity:** If $1 + g^2 - 2g\mu = 0$, the denominator becomes zero. This occurs when $\mu = 1$ and $g=1$ (perfect forward scattering with $g=1$) [G]. In practice, $g < 1$ and $\mu \le 1$, so the term is strictly positive unless $g=1, \mu=1$ [G]. Guard against this by clamping the base term [G].
- **Normalization:** The source implementation uses `1 - anisotropic` as the isotropic weight, implying the phase function output is treated as a relative weight or the isotropic term is scaled accordingly in the broader lighting equation [S1, unofficial]. When mixing with isotropic scattering, ensure the isotropic term matches the normalization convention of the renderer [G].
- **Forward Peak:** Like other Mie approximations, the function has a strong forward peak [S2, unofficial]. Importance sampling is recommended for accurate Monte Carlo integration, especially when $g$ is high [S2, unofficial].

## Subtopics

### [Multiple Octaves Phase Function](4939-multiple-octaves-phase-function.md)
A phase function that combines multiple octaves of noise to create complex scattering patterns. Choose when you need spatially varying anisotropy rather than a uniform angular distribution.

### [Henyey-Greenstein Phase Function](1010-henyey-greenstein-phase-function.md)
The standard anisotropic phase function. Choose when you need a simpler, more widely supported model, though it lacks the $(1+\mu^2)$ term of Cornette-Shanks.

## Operating characteristics
- **Time Complexity:** $O(1)$ per evaluation [G]. Requires a few multiplications, additions, and a power function [G].
- **Memory Complexity:** $O(1)$. No auxiliary data structures [G].
- **Strengths:** Simple to implement; produces a realistic forward-scattering halo for clouds [S1, unofficial]; computationally cheap [G].
- **Limitations:** Not a true physical Mie solution but an approximation [S1, unofficial]; requires importance sampling for accurate path tracing due to the forward peak [S2, unofficial]; the mixing formula in [S1, unofficial] is specific to the implementation context and may not directly translate to all radiometric frameworks without adjustment [G].
- **When to use:** Real-time volumetric rendering of clouds, fog, or smoke where a forward-scattering halo is desired and performance is critical [S1, unofficial].

## Background
The Cornette and Shanks phase function was introduced by J.L. Cornette and J.P. Shanks in their 1992 paper "Physical characterization of cloud properties" [S1, unofficial]. It is widely used in computer graphics for approximating Mie scattering in volumetric clouds [S1, unofficial]. The function is cited in Eric Bruneton's work on precomputed radiance transfer for participating media [S1, unofficial].
