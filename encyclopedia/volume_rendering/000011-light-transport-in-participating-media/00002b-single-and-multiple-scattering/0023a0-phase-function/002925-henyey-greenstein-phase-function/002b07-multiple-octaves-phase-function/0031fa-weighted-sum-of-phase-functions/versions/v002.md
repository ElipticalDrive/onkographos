# Weighted Sum of Phase Functions
Also called: Composite Phase Function (Weighted Sum), Weighted Sum Phase Function

## Overview
The Weighted Sum of Phase Functions is a method for modeling complex scattering distributions that cannot be accurately described by a single asymmetry parameter [S1]. It generalizes the Henyey-Greenstein phase function by combining multiple phase function instances with different parameters into a single normalized model [S1].

## How it works
**Inputs and Outputs:**
*   **Inputs:** A set of $n$ base phase functions $p_i$, each defined by its own parameters (e.g., asymmetry parameter $g_i$ for Henyey-Greenstein), and a set of weights $w_i$ for each phase function [S1].
*   **Outputs:** A composite phase function value $p(\omega_o, \omega'_o)$ for given outgoing direction $\omega_o$ and incoming direction $\omega'_o$ [S1].

**Data Structures:**
*   **Phase Function List:** An array or list of $n$ phase function objects. Each object contains the parameters required by its specific type (e.g., $g_i$ for Henyey-Greenstein) [G].
*   **Weights Array:** A vector of $n$ floating-point numbers $w_i$ [G].

**Steps:**
1.  Initialize the total phase value $P_{\text{total}} = 0$ [G].
2.  For each phase function index $i$ from $1$ to $n$:
    a. Evaluate the base phase function $p_i(\omega_o, \omega'_o)$ using its specific parameters [G].
    b. Multiply the result by the corresponding weight $w_i$ [G].
    c. Add the result to $P_{\text{total}}$ [G].
3.  Return $P_{\text{total}}$ [G].

**Formula:**
The composite phase function is defined as:
$$ p(\omega_o, \omega'_o) = \sum_{i=1}^n w_i p_i(\omega_o \rightarrow \omega'_o) $$
where:
*   $p_i(\omega_o \rightarrow \omega'_o)$ is the value of the $i$-th base phase function for directions $\omega_o$ and $\omega'_o$ [S1].
*   $w_i$ is the weight for the $i$-th phase function [S1].
*   The weights must satisfy the normalization constraint:
    $$ \sum_{i=1}^n w_i = 1 $$
    [S1].

**Parameters:**
*   $n$: The number of constituent phase functions. Not given in the sources.
*   $w_i$: Weights for each phase function. Must sum to 1 [S1].

**Edge Cases and Pitfalls:**
*   **Normalization:** The weights $w_i$ must sum to one to maintain normalization of the phase function. If they do not sum to one, the resulting phase function will not be properly normalized, leading to incorrect energy conservation in rendering [S1].
*   **Implementation:** This generalization is not provided in pbrt but is noted as easy to add [S1].

**Pseudocode:**
```python
def weighted_sum_phase_function(outgoing_dir, incoming_dir, phase_functions, weights):
    total_value = 0.0
    for i in range(len(phase_functions)):
        # Evaluate the i-th base phase function using its stored parameters
        p_i = phase_functions[i].evaluate(outgoing_dir, incoming_dir)
        # Multiply by weight and accumulate
        total_value += weights[i] * p_i
    return total_value
```

## Subtopics

### Total Phase Function
The Total Phase Function is a specific application of the weighted sum concept where the weights are determined by the contribution of each particle field to the total scattering coefficient [S2]. It is calculated by weighting each individual particle phase function $P^{(i)}(\Omega)$ by the product of its volume fraction $\alpha^{(i)}$ and its extinction coefficient $\beta_{ex}^{(i)}(\mathbf{s})$ [S2]. The formula is:
$$ P(\Omega, \mathbf{s}) = \frac{\sum_{\text{all fields } i} \alpha^{(i)} \beta_{ex}^{(i)}(\mathbf{s}) P^{(i)}(\Omega)}{\sum_{\text{all fields } i} \alpha^{(i)} \beta_{ex}^{(i)}(\mathbf{s})} $$
[S2]. This method is used in rendering atmospheric data with multiple particle fields to capture realistic illumination effects [S2].

## Background
The concept of modeling complex phase functions as a weighted sum of simpler phase functions (like Henyey-Greenstein) is discussed in the context of volume scattering in computer graphics [S1]. It is noted as a generalization that is not natively provided in the pbrt renderer but is considered easy to implement [S1]. The specific application of weighting phase functions by their contribution to the total scattering coefficient for atmospheric rendering is described in the context of efficient rendering of atmospheric phenomena [S2].
