# Multiple Octaves Phase Function

Also called: Composite Henyey-Greenstein, Multi-Octave Scattering

## Overview
The Multiple Octaves Phase Function is a composite scattering model that combines multiple Henyey-Greenstein lobes with varying asymmetry parameters and weights to create complex scattering patterns, specifically a two-lobed effect [S1, unofficial]. It differs from the parent [Henyey-Greenstein Phase Function](1010-henyey-greenstein-phase-function.md) by allowing independent control over forward and backward scattering peaks through a weighted sum, addressing the limitation of a single asymmetry parameter [S1, unofficial]. It is distinct from the [Cornette and Shanks Phase Function](1710-cornette-and-shanks-phase-function.md) by using a fixed multi-octave loop structure rather than a physically derived single-anisotropy model [S1, unofficial].

## How it works
**Inputs:**
- Incident direction $\omega_i$ (view direction).
- Outgoing direction $\omega_o$ (light direction).
- Optical depth $\sigma_t$ (extinction coefficient).
- Density $\rho$ (medium density).

**Outputs:**
- Accumulated radiance contribution.

**Data Structures:**
No complex data structures are required. The method uses scalar accumulators and loop counters.

**Parameters:**
- Number of octaves: 4.
- Initial attenuation factor $a = 1.0$.
- Initial contribution factor $b = 1.0$.
- Initial phase attenuation factor $c = 1.0$.
- Weights: $w_{forward} = 0.7$, $w_{backward} = 0.3$.
- Asymmetry parameters: $g_{forward} = 0.3 \cdot c$, $g_{backward} = -0.1 \cdot c$.

**Steps:**
1. Initialize `radiance` to 0.0.
2. Initialize $a = 1.0$, $b = 1.0$, $c = 1.0$.
3. Loop $i$ from 0 to 3:
   a. Calculate $g_f = 0.3 \cdot c$ and $g_b = -0.1 \cdot c$.
   b. Evaluate the Henyey-Greenstein phase function $p_{HG}(\omega_i, \omega_o, g)$ for both $g_f$ and $g_b$.
   c. Compute the composite phase: $p = 0.3 \cdot p_{HG}(\omega_i, \omega_o, g_b) + 0.7 \cdot p_{HG}(\omega_i, \omega_o, g_f)$.
   d. Calculate the attenuation term: $att = \exp(-\sigma_t \cdot \rho \cdot a)$.
   e. Add to radiance: `radiance` += $b \cdot p \cdot att$.
   f. Update factors: $a \leftarrow a \cdot 0.2$, $b \leftarrow b \cdot 0.5$, $c \leftarrow c \cdot 0.5$.
4. Return `radiance`.

**Pseudocode:**
```python
def multiple_octaves_phase_function(omega_i, omega_o, sigma_t, density):
    """
    Computes the radiance contribution using the Multiple Octaves Phase Function.
    
    Args:
        omega_i: Incident direction vector (normalized).
        omega_o: Outgoing direction vector (normalized).
        sigma_t: Extinction coefficient (float).
        density: Medium density (float).
        
    Returns:
        Accumulated radiance contribution (float).
    """
    radiance = 0.0
    a = 1.0
    b = 1.0
    c = 1.0
    
    # Precompute cosine of the scattering angle
    cos_theta = dot(omega_i, omega_o)
    
    for i in range(4):
        # Calculate asymmetry parameters for this octave
        g_forward = 0.3 * c
        g_backward = -0.1 * c
        
        # Evaluate Henyey-Greenstein phase function for forward lobe
        # p_HG(cos_theta, g) = (1 - g^2) / (4 * pi * (1 + g^2 - 2*g*cos_theta)^(3/2))
        denom_f = 1.0 + g_forward**2 - 2.0 * g_forward * cos_theta
        if denom_f <= 0:
            denom_f = 1e-8 # Guard against division by zero
        p_forward = (1.0 - g_forward**2) / (4.0 * 3.141592653589793 * (denom_f ** 1.5))
        
        # Evaluate Henyey-Greenstein phase function for backward lobe
        denom_b = 1.0 + g_backward**2 - 2.0 * g_backward * cos_theta
        if denom_b <= 0:
            denom_b = 1e-8 # Guard against division by zero
        p_backward = (1.0 - g_backward**2) / (4.0 * 3.141592653589793 * (denom_b ** 1.5))
        
        # Mix the two lobes
        phase = 0.3 * p_backward + 0.7 * p_forward
        
        # Calculate attenuation
        attenuation = exp(-sigma_t * density * a)
        
        # Add contribution
        radiance += b * phase * attenuation
        
        # Update factors for next octave
        a *= 0.2
        b *= 0.5
        c *= 0.5
        
    return radiance
```

## Subtopics

### [Dual-Lobe Henyey-Greenstein Phase Function](5231-dual-lobe-henyey-greenstein-phase-function.md)
A scattering phase function modeling softer backward back-scattering peaks by blending two Henyey-Greenstein lobes: one for forward scattering and one for backward scattering [5231-dual-lobe-henyey-greenstein-phase-function.md]. It is chosen when a single asymmetry parameter cannot capture both strong forward and significant backward scattering. It is a specific instance of the weighted sum approach but typically uses fixed weights or a simpler blending logic than the multi-octave loop.

### Weighted Sum of Phase Functions
A generalization for complex phase functions not described well by a single asymmetry parameter, modeled as a weighted sum of phase functions (like Henyey-Greenstein) with different parameters [S2]. The formula is $p(\omega_o, \omega'_o) = \sum_{i=1}^n w_i p_i(\omega_o \rightarrow \omega'_o)$, where $\sum w_i = 1$ [S2]. The pitfall is that the weights $w_i$ must sum to one to maintain normalization [S2]. This generalization is not provided in pbrt but is noted as easy to add [S2].

## Operating characteristics
**Time Complexity:** $O(N)$ where $N$ is the number of octaves (fixed at 4 in the source). Each iteration requires two Henyey-Greenstein evaluations and basic arithmetic.
**Memory Complexity:** $O(1)$. Only scalar variables are stored.
**Measured Performance:** Not given in the sources.
**Strengths:** Allows for complex, multi-lobed scattering patterns (e.g., strong forward and soft backward scattering) that a single Henyey-Greenstein function cannot achieve [S1, unofficial].
**Limitations:** The specific weights and asymmetry parameters are hardcoded in the source implementation, limiting flexibility without code modification [S1, unofficial]. The normalization of the composite function is not explicitly guaranteed to be 1.0 unless the weights and individual lobes are carefully balanced, though the source implies it works for the specific case [S1, unofficial].
**When to use:** When simulating media like clouds or smoke that exhibit distinct forward and backward scattering peaks.
**When not to use:** When computational efficiency is critical and a single lobe is sufficient, or when physical accuracy of the scattering distribution is paramount over artistic control.

## Background
The Multiple Octaves Phase Function originates from an unofficial implementation in the `al-ro/volumetrics` repository [S1, unofficial]. It is designed to create complex scattering patterns by combining multiple Henyey-Greenstein lobes. The concept of using a weighted sum of phase functions is discussed in the pbr-book as a generalization for complex scattering distributions [S2].
