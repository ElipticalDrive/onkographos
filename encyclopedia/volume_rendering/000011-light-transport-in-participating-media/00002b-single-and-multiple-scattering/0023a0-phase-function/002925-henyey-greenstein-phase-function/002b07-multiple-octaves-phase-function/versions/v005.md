# Multiple Octaves Phase Function

## Overview
The Multiple Octaves Phase Function is a composite model that combines multiple Henyey-Greenstein lobes with varying asymmetry parameters and weights to create complex, specifically two-lobed, scattering patterns [S1, unofficial]. It differs from its parent [Henyey-Greenstein Phase Function](1010-henyey-greenstein-phase-function.md) by stacking multiple instances with decaying parameters rather than relying on a single asymmetry parameter $g$ [S1, unofficial].

## How it works
**Inputs and Outputs:**
*   Input: scattering direction $\omega_s$, incident direction $\omega_i$, extinction coefficient $\sigma_t$, density $\rho$.
*   Output: accumulated radiance $L$.

**Data Structures:**
The method relies on scalar accumulators and loop counters [G].

**Parameters:**
*   Number of octaves: 4 (fixed) [S1, unofficial].
*   Initial factors: $a=1.0, b=1.0, c=1.0$ [S1, unofficial].
*   Decay factors: $a \leftarrow a \cdot 0.2$, $b \leftarrow b \cdot 0.5$, $c \leftarrow c \cdot 0.5$ [S1, unofficial].
*   Weights: 0.3 for the backward lobe, 0.7 for the forward lobe [S1, unofficial].
*   Asymmetry bases: $-0.1 \cdot c$ and $0.3 \cdot c$ [S1, unofficial].

**Steps:**
1. Initialize radiance $L=0$, attenuation factor $a=1.0$, contribution factor $b=1.0$, and phase attenuation factor $c=1.0$ [S1, unofficial].
2. Loop 4 times ($i=0$ to $3$) [S1, unofficial]:
   a. Calculate phase by mixing two Henyey-Greenstein functions: one with asymmetry $-0.1 \cdot c$ and one with $0.3 \cdot c$, weighted 0.3 and 0.7 respectively [S1, unofficial].
   b. Add to radiance: $L \leftarrow L + b \cdot \text{phase} \cdot \exp(-\sigma_t \cdot \rho \cdot a)$ [S1, unofficial].
   c. Update factors: $a \leftarrow a \cdot 0.2$, $b \leftarrow b \cdot 0.5$, $c \leftarrow c \cdot 0.5$ [S1, unofficial].
3. Return accumulated radiance $L$ [S1, unofficial].

**Pseudocode:**
```python
import math

def multiple_octaves_phase_function(omega_s, omega_i, sigma_t, density):
    """
    Computes radiance contribution using the Multiple Octaves Phase Function.
    """
    # Standard Henyey-Greenstein implementation [G]
    def heney_greenstein(omega_s, omega_i, g):
        cos_theta = dot(omega_s, omega_i)
        g_sq = g * g
        denom = 1.0 + g_sq - 2.0 * g * cos_theta
        if denom < 1e-8:
            denom = 1e-8
        return (1.0 - g_sq) / (4.0 * math.pi * (denom ** 1.5))

    L = 0.0
    a = 1.0
    b = 1.0
    c = 1.0

    for i in range(4):
        g_fwd = 0.3 * c
        g_bwd = -0.1 * c

        p_fwd = heney_greenstein(omega_s, omega_i, g_fwd)
        p_bwd = heney_greenstein(omega_s, omega_i, g_bwd)

        phase = 0.3 * p_bwd + 0.7 * p_fwd

        attenuation = math.exp(-sigma_t * density * a)

        L += b * phase * attenuation

        a *= 0.2
        b *= 0.5
        c *= 0.5

    return L
```
