# Multiple Octaves Phase Function
Also called: Composite Henyey-Greenstein, Multi-Octave Scattering
## Overview
The Multiple Octaves Phase Function is a composite model that generates complex scattering patterns by summing multiple Henyey-Greenstein lobes with varying asymmetry parameters and weights [S1, unofficial]. It solves the limitation of single-parameter phase functions (like the parent [Henyey-Greenstein Phase Function](1010-henyey-greenstein-phase-function.md)) by allowing the creation of multi-lobed distributions, such as those found in clouds, without requiring more expensive physical models [S1, unofficial]. It sets itself apart from the sibling [Cornette and Shanks Phase Function](1710-cornette-and-shanks-phase-function.md) by using a specific iterative octave-based construction rather than a fixed analytical approximation of Mie scattering [S1, unofficial].
## How it works
**Inputs:**
- Incident direction $\omega_i$ and outgoing direction $\omega_o$ (or scattering angle $\cos \theta = \omega_i \cdot \omega_o$).
- Optical depth parameters (density $\rho$, extinction coefficient $\sigma_t$) for attenuation context, though the phase function itself is normalized angular distribution.

**Outputs:**
- Normalized phase value $p(\omega_o, \omega_i)$.
- Accumulated radiance contribution in the context of the specific rendering loop described in [S1, unofficial].

**Data Structures:**
- No persistent data structures. The method is stateless per evaluation but stateful within the specific rendering loop implementation found in [S1, unofficial].

**Algorithm:**
The method is implemented as a fixed 4-octave loop. Each octave mixes two Henyey-Greenstein functions with scaled asymmetry parameters.

1. Initialize accumulators:
   - Radiance $L = 0$.
   - Attenuation factor $a = 1.0$.
   - Contribution weight $b = 1.0$.
   - Phase scale factor $c = 1.0$.

2. Loop $i$ from 0 to 3 (4 iterations):
   a. Calculate asymmetry parameters for two lobes:
      - $g_1 = -0.1 \times c$
      - $g_2 = 0.3 \times c$
   b. Evaluate two Henyey-Greenstein phase functions $p_{HG}(\cos \theta, g)$:
      - $p_1 = p_{HG}(\cos \theta, g_1)$
      - $p_2 = p_{HG}(\cos \theta, g_2)$
   c. Mix the lobes with weights 0.3 and 0.7:
      - $p_{octave} = 0.3 \times p_1 + 0.7 \times p_2$
   d. Calculate attenuation for this step:
      - $attenuation = \exp(-\sigma_t \times \rho \times a)$
   e. Add to radiance:
      - $L += b \times p_{octave} \times attenuation$
   f. Update factors for next octave:
      - $a \leftarrow a \times 0.2$
      - $b \leftarrow b \times 0.5$
      - $c \leftarrow c \times 0.5$

3. Return $L$.

**Pseudocode:**
```python
def heney_greenstein(cos_theta, g):
    """
    Standard Henyey-Greenstein phase function.
    p(cos_theta, g) = (1 - g^2) / (4 * pi * (1 + g^2 - 2*g*cos_theta)^(3/2))
    """
    if abs(g) >= 1.0:
        # Degenerate case: delta function. 
        # In practice, handle as a spike or clamp g slightly below 1.0.
        # For this implementation, we assume valid g inputs from the loop.
        pass 
    
    numerator = 1.0 - g * g
    denominator = 1.0 + g * g - 2.0 * g * cos_theta
    # Avoid division by zero if denominator is very small
    if denominator < 1e-8:
        denominator = 1e-8
        
    return numerator / (4.0 * 3.141592653589793 * (denominator ** 1.5))

def multiple_octaves_phase_function(cos_theta, sigma_t, density):
    """
    Implements the 4-octave composite phase function from [S1, unofficial].
    Note: This function returns the accumulated radiance contribution 
    as defined in the source loop, not just the normalized phase value.
    """
    radiance = 0.0
    a = 1.0
    b = 1.0
    c = 1.0
    
    for i in range(4):
        # Calculate asymmetry parameters
        g1 = -0.1 * c
        g2 = 0.3 * c
        
        # Evaluate Henyey-Greenstein lobes
        p1 = heney_greenstein(cos_theta, g1)
        p2 = heney_greenstein(cos_theta, g2)
        
        # Mix lobes: 0.3 weight for g1, 0.7 weight for g2
        phase_octave = 0.3 * p1 + 0.7 * p2
        
        # Calculate attenuation
        attenuation = math.exp(-sigma_t * density * a)
        
        # Add to radiance
        radiance += b * phase_octave * attenuation
        
        # Update factors
        a *= 0.2
        b *= 0.5
        c *= 0.5
        
    return radiance
```

**Parameters:**
- Number of octaves: 4 (fixed in source [S1, unofficial]).
- Lobe weights: 0.3 (backward/negative g) and 0.7 (forward/positive g).
- Asymmetry scaling: $g_1 = -0.1c$, $g_2 = 0.3c$.
- Attenuation decay: $a$ multiplies by 0.2 per octave.
- Contribution decay: $b$ multiplies by 0.5 per octave.
- Phase scale decay: $c$ multiplies by 0.5 per octave.

**Edge Cases:**
- If $\sigma_t$ or density is 0, attenuation is 1.0.
- If $g$ approaches $\pm 1$, the Henyey-Greenstein function becomes singular; implementation should clamp or handle delta spikes [G].
- The specific implementation in [S1, unofficial] returns a radiance-like value rather than a strictly normalized phase function $p(\omega_o, \omega_i)$ where $\int p d\omega = 1$. This is a pitfall if used in a standard Monte Carlo estimator without proper importance sampling or normalization adjustments [S1, unofficial].

## Subtopics

### [Dual-Lobe Henyey-Greenstein Phase Function](5231-dual-lobe-henyey-greenstein-phase-function.md)
The Dual-Lobe Henyey-Greenstein Phase Function models light scattering in participating media, specifically clouds, by combining a forward-scattering lobe and a backward-scattering lobe to create a more realistic angular distribution than a single lobe. It sets itself apart from the parent [Multiple Octaves Phase Function](4939-multiple-octaves-phase-function.md) by specifically using a two-lobed structure (one forward, one backward) rather than a general composite of multiple octaves, providing a computationally efficient approximation of Mie scattering with significant back-scatter.

### Weighted Sum of Phase Functions
A generalization for complex phase functions not described well by a single asymmetry parameter, modeled as a weighted sum of phase functions (like Henyey-Greenstein) with different parameters [S2]. The formula is $p(\omega_o, \omega'_o) = \sum_{i=1}^n w_i p_i(\omega_o \rightarrow \omega'_o)$, where $\sum w_i = 1$ [S2]. The pitfall is that the weights $w_i$ must sum to one to maintain normalization [S2]. This generalization is not provided in pbrt but is noted as easy to add [S2].

## Operating characteristics
- **Time Complexity:** $O(K)$ where $K$ is the number of octaves (4 in the standard implementation). Each step requires two Henyey-Greenstein evaluations.
- **Memory Complexity:** $O(1)$. No large data structures are required.
- **Performance:** Very fast due to the fixed number of iterations and simple analytical functions.
- **Strengths:** Capable of producing complex, multi-lobed scattering patterns (e.g., forward and backward scattering) with minimal computational overhead compared to tabulated or physical Mie scattering models [S1, unofficial].
- **Limitations:** The specific implementation in [S1, unofficial] does not guarantee a normalized phase function, which can lead to incorrect energy conservation if not handled carefully in the renderer [S1, unofficial]. It is an empirical fit rather than a physically derived model [S1, unofficial].
- **When to use:** When a simple, fast approximation of complex scattering (like cloud scattering) is needed and the overhead of more complex phase functions is unjustified [S1, unofficial].
- **When not to use:** When strict energy conservation and physical accuracy are required, or when the scattering distribution is known to require more than 4 octaves to model accurately.

## Background
The Multiple Octaves Phase Function originates from the `volumetrics` project by al-ro [S1, unofficial]. It is an empirical technique used in real-time or interactive rendering contexts to approximate complex scattering behavior. The approach of summing multiple Henyey-Greenstein functions is a known generalization in volume rendering literature, as noted in the pbr-book [S2], but the specific "4-octave" formulation with the defined decay factors is unique to the source [S1, unofficial].
