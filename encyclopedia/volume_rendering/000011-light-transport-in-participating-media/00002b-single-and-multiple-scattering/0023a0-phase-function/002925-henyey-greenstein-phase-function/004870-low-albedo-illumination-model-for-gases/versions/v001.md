# Low-Albedo Illumination Model for Gases

Also called: Low-albedo illumination model

## Overview
The Low-Albedo Illumination Model for Gases is a rendering technique designed to visualize three-dimensional gaseous volumes with high visual realism, specifically addressing the contrast and shadowing characteristics of low-scattering media. It solves the problem of making subtle density variations visible in gases that do not strongly reflect light. It is distinguished from its parent, the Henyey-Greenstein Phase Function, by its specific application to low-albedo (low single-scattering albedo) scenarios and its integration of a fast, table-based volume shadowing technique to enhance the realism of shadows cast by the gas.

## How it works
The method computes the illumination of a gas element based on incident light and a phase function derived from Henyey-Greenstein functions.

**Inputs and Outputs:**
- Input: Incident light intensity ($I_0$), phase function value ($p(\theta)$).
- Output: Reflected light intensity ($I$).

**Data Structures:**
Not given in the sources.

**Steps:**
1. Determine the angle $\theta$ between the direction to the light source and the direction to the eye (camera).
2. Evaluate the phase function $p(\theta)$. The sources state this is based on the summation of Henyey-Greenstein functions [S1, unofficial].
3. Compute the reflected light intensity using the illumination model formula:
   $$ I = I_0 \cdot p(\theta) $$
   where $I$ is the amount of light reflected from the element, $I_0$ is the incident light, and $p(\theta)$ characterizes the total brightness of a particle as a function of the angle between the light and the eye [S1, unofficial].

**Formulas:**
- Illumination Model: $I = I_0 \cdot p(\theta)$ [S1, unofficial].

**Parameters:**
- $\theta$: Angle between light and eye direction.
- $p(\theta)$: Phase function value. The specific mathematical form of the summation of Henyey-Greenstein functions is not provided in the text, only that it is used [S1, unofficial].

**Edge Cases and Pitfalls:**
- The model relies on a "fast, accurate table-based volume shadowing technique" to increase visual realism [S1, unofficial]. The implementation details of this table-based shadowing are not provided in the source text.
- Precision issues may arise if the phase function summation is not handled carefully, though no specific numerical pitfalls are listed.

**Pseudocode:**
```python
def low_albedo_illumination(I0, phase_function_value):
    """
    Computes the reflected light intensity for a gas element.
    
    Args:
        I0 (float): Incident light intensity.
        phase_function_value (float): The value of the phase function p(theta)
                                      based on the summation of Henyey-Greenstein functions.
    
    Returns:
        float: The amount of light reflected from the element.
    """
    # Formula: I = I0 * p(theta)
    I = I0 * phase_function_value
    return I
```

### Anisotropic Albedo Calculation
A formula to calculate albedo from reflectance ($r$) and anisotropy parameter ($g$), considering anisotropic phase functions [S2, unofficial]. It is used when deriving scattering coefficients from a target reflectance in anisotropic media. To compute it:
1. Compute intermediate variable $s$ using reflectance $r$:
   $$ s = 4.09712 + 4.20863 \cdot r - \sqrt{9.59271 + r \cdot (41.6808 + 17.7126 \cdot r)} $$
2. Compute $s^2$:
   $$ s2 = s \cdot s $$
3. Calculate albedo:
   $$ \text{albedo} = \frac{1.0 - s2}{1.0 - g \cdot s2} $$
Parameters: $r$ is the input reflectance value, $g$ is the input anisotropy parameter [S2, unofficial].
