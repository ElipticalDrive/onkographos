# Jendersie-d’Eon Phase Function
Also called: Jendersie-d'Eon
## Overview
The Jendersie-d’Eon phase function is a model that approximates actual Mie scattering by water droplets, providing a more realistic forward scattering peak than the Henyey-Greenstein phase function [S1][S2, unofficial]. It is specifically used in Redshift for cloud rendering to model the optical properties of water droplets [S2, unofficial].

## How it works
The Jendersie-d’Eon model approximates the true Mie scattering of water droplets, capturing a more realistic forward peak than the Henyey-Greenstein model [S1][S2, unofficial].

**Inputs and Outputs:**
*   **Input:** Incident direction $\omega_i$, outgoing direction $\omega_s$ [G].
*   **Output:** Phase function value $p(\omega_s, \omega_i)$ representing the probability density of scattering into $\omega_s$ [G].

**Steps:**
1. Compute the cosine of the scattering angle $\theta$ between $\omega_i$ and $\omega_s$ using the dot product: $\cos \theta = \omega_i \cdot \omega_s$ [G].
2. Evaluate the phase function $p(\cos \theta)$ using the model's parameters [G]. The exact mathematical formula is not provided in the cited sources [S1][S2, unofficial].
3. Return the resulting phase value [G].

## Operating characteristics
The Jendersie-d’Eon model provides a more realistic forward scattering peak than Henyey-Greenstein, which is critical for accurately rendering the bright edges of clouds illuminated from behind [S1][S2, unofficial]. It is available in Redshift specifically for cloud rendering [S2, unofficial]. Specific time and memory complexity metrics are not given in the sources [S1][S2, unofficial].

## Background
The Henyey-Greenstein phase function is a classic model dating back to a 1941 astrophysics paper [S1][S2, unofficial]. The Jendersie-d’Eon model is a newer alternative introduced to better approximate the true Mie scattering of water droplets, addressing the limitations of the single-anisotropy Henyey-Greenstein model for cloud rendering [S1][S2, unofficial].
