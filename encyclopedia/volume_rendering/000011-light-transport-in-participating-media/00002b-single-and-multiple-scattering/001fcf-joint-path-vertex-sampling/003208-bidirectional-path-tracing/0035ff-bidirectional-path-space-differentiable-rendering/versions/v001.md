# Bidirectional Path-Space Differentiable Rendering
Also called: I.1 (unidirectional variant), I.2 (bidirectional variant), Our deriv

## Overview
Bidirectional Path-Space Differentiable Rendering computes gradients of a rendering equation with respect to scene parameters by constructing a differentiable path space using both light and eye subpaths. It sets itself apart from unidirectional differentiable methods by leveraging the bidirectional structure of [Bidirectional Path Tracing](6666-bidirectional-path-tracing.md) to reduce variance in gradient estimation for complex light transport, specifically addressing the discontinuities inherent in path-space derivatives.

## Shared principles
The method relies on a discretized representation of the joint probability density function (PDF) of the connection segment in path space. Let $\mathbf{x}_B$ be the position and $\boldsymbol{\omega}_B$ be the direction of the connection segment between the light subpath endpoint and the eye subpath endpoint. The joint PDF $P(\mathbf{x}_B, \boldsymbol{\omega}_B)$ is discretized as a regular 3D grid precomputed before rendering [S1, unofficial].

The preprocessing step involves generating two maps:
1.  A **photon map**: Generated by tracing photons carrying radiance information from the light source [S1, unofficial].
2.  An **importon map**: Generated by tracing importons carrying importance information from the detector [S1, unofficial].

For each cell $C_i$ in the grid, the integral of the product of the path contribution $F_B(\mathbf{x}_B, \boldsymbol{\omega}_B)$ and the PDF is computed by uniformly sampling $\mathbf{x}_B$ and $\boldsymbol{\omega}_B$ within the cell:
$$
P_i = \int_{C_i} F_B(\mathbf{x}_B, \boldsymbol{\omega}_B) \, d\boldsymbol{\omega}_B \, d\mathbf{x}_B
$$
This provides a piecewise constant representation of the path-space density [S1, unofficial]. The gradient computation utilizes this precomputed structure to handle the non-differentiable connections in path tracing by smoothing or approximating the derivative within the discretized cells.

## Subtopics

### I.1 (unidirectional variant)
A variant that computes gradients using only the light subpath or eye subpath structure, effectively reducing the bidirectional complexity to a unidirectional path tracing framework while maintaining the path-space differentiation technique. It is chosen when computational resources for bidirectional sampling are limited or when the scene geometry favors one direction of light transport. Validation shows derivatives estimated with this method closely match finite-difference approaches for parameters like rotation angles [S1, unofficial].

### I.2 (bidirectional variant)
The full bidirectional implementation that utilizes both the photon map and importon map to compute gradients across the complete bidirectional path. It is chosen for scenes with complex multiple scattering or when high-fidelity gradient estimation is required for both light and camera parameters. It builds on the shared principles of grid-based path-space discretization [S1, unofficial].

## Background
The method originates from research on path-space differentiable rendering, specifically aiming to extend differentiable rendering techniques to bidirectional path tracing scenarios. The approach was introduced in the paper "Path-Space Differentiable Rendering" [S1, unofficial]. The technique addresses the challenge of computing gradients in path tracing where the connectivity between subpaths is non-differentiable. By discretizing the path space using photon and importon maps, it provides a robust way to estimate derivatives for optimization tasks in computer graphics.
