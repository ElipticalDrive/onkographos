# Primary Sample Space Transformation Layout

Also called: Array of Arrays for Primary Samples, BDPT Primary Sample Layout

## Overview
A data layout for storing the primary sample vector $\bar{u}$ in Bidirectional Path Tracing (BDPT) to ensure that small changes in the sample space $U$ correspond to small changes in the path space $P$ [S1]. It solves the problem of sample correlation in heterogeneous participating media by separating random numbers for eye/light subpaths and between scattering/propagation steps, unlike standard BDPT which uses successive dimensions of $U$ directly [S1].

## How it works
**Inputs:** The primary sample vector $\bar{u}$ [S1].
**Outputs:** A structured array-of-arrays layout mapping indices to specific sampling operations within the BDPT algorithm [S1].

**Data Structure:**
The primary sample $\bar{u}$ is stored as an array of arrays [S1]. The $i$-th row vector provides input to the sampling done at the $|i|$-th vertex of the respective subpath [S1]. Elements within each row are accessed in sequential order [S1]. Indices are assigned as follows: positive indices ($i > 0$) for eye subpath vertices, negative indices ($i < 0$) for light subpath vertices, and index $0$ for transmittance estimation [S1].

**Numbered Steps:**
1. Initialize the primary sample structure as an empty array of arrays [G].
2. For each vertex generation step in the BDPT algorithm, determine the vertex index $i$ based on the subpath type (positive for eye, negative for light) and the vertex order [S1].
3. Retrieve the row vector corresponding to index $i$ [S1].
4. Consume random values from the row vector sequentially for the specific sampling operation (e.g., distance or direction sampling) [S1].
5. If the row is exhausted, append new random values to the row [G].
6. For transmittance estimation between deterministic connections, use the row vector at index $0$ and consume random values sequentially [S1].

**Formulas:**
Let $P$ be the path space and $U$ be the primary sample space. The transformation $s: U \rightarrow P$ must satisfy $\|\Delta U\| \text{ small} \implies \|\Delta P\| \text{ small}$ [S1]. This is achieved by ensuring that random numbers driving distinct parts of path generation are separated [S1].

**Parameters:**
Index mapping: positive for eye, negative for light, $0$ for transmittance [S1]. Access pattern: sequential within each row [S1].

**Edge Cases and Pitfalls:**
Heterogeneous Media: The amount of random input needed for distance sampling in heterogeneous media cannot be determined in advance [S1]. Each deterministic connection between subpaths requires an additional unknown amount of random values for transmittance estimation [S1]. The array-of-arrays layout handles this by allowing variable-length rows [S1]. Transmittance Smoothness: Large variations in random values driving transmittance estimation have little effect on the result because transmittance is fairly smooth in realistic settings [S1]. Therefore, further separation within the transmittance row (index $0$) is not necessary [S1].

**Pseudocode:**
```python
class PrimarySampleSpaceLayout:
    def __init__(self):
        # Array of arrays to store primary samples
        # Index 0: Transmittance
        # Index > 0: Eye subpath vertices
        # Index < 0: Light subpath vertices
        self.samples = {}

    def get_sample(self, index, count):
        """
        Retrieve 'count' random values for the given index.
        Consumes values sequentially from the row.
        """
        if index not in self.samples:
            self.samples[index] = []
        
        row = self.samples[index]
        if len(row) < count:
            # PRNG generation not specified in sources [G]
            new_values = [0.0] * (count - len(row))
            row.extend(new_values)
        
        # Consume values sequentially
        values = row[:count]
        del row[:count]
        return values

    def sample_eye_vertex(self, vertex_index, count):
        """Sample a vertex on the eye subpath."""
        return self.get_sample(vertex_index, count)

    def sample_light_vertex(self, vertex_index, count):
        """Sample a vertex on the light subpath."""
        # Use negative index for light subpath
        return self.get_sample(-vertex_index, count)

    def sample_transmittance(self, count):
        """Sample transmittance between subpath connections."""
        return self.get_sample(0, count)
```

## Subtopics

### [Bidirectional Path Tracing](6666-bidirectional-path-tracing.md)
A method that constructs two independent subpaths and connects their endpoints deterministically. This layout is a specific data organization technique for BDPT's primary samples that ensures path space smoothness. Choose it when using BDPT in participating media to maintain sample continuity.

### [Bidirectional Path-Space Differentiable Rendering](7618-bidirectional-path-space-differentiable-rendering.md)
A sibling method that extends BDPT to differentiable rendering [G]. The primary sample space transformation layout may be relevant for ensuring smooth gradients in differentiable contexts, though specific details are not provided in the sources [G].

## Background
Originated in the paper "Unbiased Global Illumination with Participating Media" [S1]. The method was developed to address the limitations of standard BDPT in participating media, where the fixed mapping of random numbers to path vertices fails to ensure smoothness in path space due to the variable nature of distance sampling in heterogeneous media [S1].
