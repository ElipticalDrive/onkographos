# Bidirectional Path Tracing

Also called: Bidirectional transmittance-based path sampling, Vertex-vertex connection

## Overview
Bidirectional Path Tracing constructs a full light transport path by independently generating a light subpath and an eye subpath, then connecting their endpoints with a deterministic segment [S1]. It addresses the high variance of unidirectional sampling by ensuring both emitted radiance and sensor importance are included in the path probability density function (PDF) [S1]. Unlike its sibling [Bridge Sampling](3881-bridge-sampling.md), which uses probabilistic connections, this method uses a deterministic connection, which introduces specific variance characteristics [S1].

## How it works
**Inputs:** Scene geometry, participating media properties, light source distribution, camera parameters.
**Outputs:** Radiance estimate for the pixel.

**Data Structures:**
*   `LightSubpath`: Array of vertices $v_0, v_1, \dots, v_s$. $v_0$ is on the light.
*   `EyeSubpath`: Array of vertices $u_0, u_1, \dots, u_t$. $u_0$ is on the camera.
*   `ConnectionSegment`: Deterministic segment connecting $v_s$ and $u_t$.

**Steps:**
1.  **Generate Light Subpath:** Sample $s$ vertices starting from a light source. For each vertex $v_i$ ($0 \le i < s$), sample a direction and distance to find $v_{i+1}$ using the medium's scattering properties [S1].
2.  **Generate Eye Subpath:** Sample $t$ vertices starting from the camera. For each vertex $u_i$ ($0 \le i < t$), sample a direction and distance to find $u_{i+1}$ [S1].
3.  **Connect Subpaths:** Deterministically connect the endpoint of the light subpath ($v_s$) to the endpoint of the eye subpath ($u_t$) with a segment [S1]. This segment represents the final path between the two subpaths.
4.  **Estimate Radiance:** Compute the radiance contribution of the full path. The path PDF must account for the independent sampling of both subpaths and the deterministic connection [S1].

**Formulas:**
The path PDF $p(\mathbf{p})$ for a path $\mathbf{p}$ consisting of light subpath $\mathbf{v}$ and eye subpath $\mathbf{u}$ connected deterministically is:
$$ p(\mathbf{p}) = p_L(\mathbf{v}) \cdot p_E(\mathbf{u}) $$
where $p_L(\mathbf{v})$ is the PDF of the light subpath and $p_E(\mathbf{u})$ is the PDF of the eye subpath [S1]. The connection segment has 0 random decisions, so it does not contribute a random variable to the PDF, but its transmittance and geometry are included in the radiance calculation [S1].

**Parameters:**
*   $s$: Number of vertices in the light subpath.
*   $t$: Number of vertices in the eye subpath.
*   Typical values: $s=1, t=1$ corresponds to Next Event Estimation for path tracing; $s=1, t>1$ or $s>1, t=1$ corresponds to light tracing variants [S1].

**Edge Cases and Pitfalls:**
*   **Infinite Variance:** Vertex-vertex connections can lead to infinite variance because none of the terms for the connecting segment are importance sampled, as it is a 0-random-decision subpath [S1].
*   **Boundary Conditions:** Ensure that the deterministic connection is valid within the medium (e.g., no occlusion, valid distance).

## Subtopics

### [Bidirectional Path-Space Differentiable Rendering](7618-bidirectional-path-space-differentiable-rendering.md)
Computes gradients of a rendering equation with respect to scene parameters by constructing a differentiable path space using both light and eye subpaths. It sets itself apart from unidirectional differentiable methods by leveraging the bidirectional structure of [Bidirectional Path Tracing](6666-bidirectional-path-tracing.md) to reduce variance in gradient estimation for complex light transport, specifically addressing the discontinuities inherent in path-space derivatives.

## Operating characteristics
*   **Time Complexity:** Proportional to the sum of the lengths of the light and eye subpaths ($s + t$).
*   **Memory Complexity:** Proportional to the sum of the lengths of the light and eye subpaths ($s + t$).
*   **Measured Performance:** Not given in the sources.
*   **Scaling:** Scales linearly with the number of vertices in the subpaths.
*   **Strengths:** Includes both emitted radiance and sensor importance in the path PDF, reducing variance compared to unidirectional sampling [S1].
*   **Limitations:** Vertex-vertex connections can lead to infinite variance because the connecting segment is not importance sampled [S1].
*   **When to use:** When high variance in unidirectional sampling is a concern and the scene allows for efficient subpath generation.
*   **When not to use:** When the deterministic connection leads to infinite variance or when the scene geometry makes subpath generation inefficient.

## Background
Bidirectional Path Tracing was introduced to address the high variance of unidirectional sampling in light transport simulation [S1]. It is based on the principle of including both emitted radiance and sensor importance in the path PDF [S1]. The method is a form of joint importance sampling of low-order volumetric scattering [S1].
