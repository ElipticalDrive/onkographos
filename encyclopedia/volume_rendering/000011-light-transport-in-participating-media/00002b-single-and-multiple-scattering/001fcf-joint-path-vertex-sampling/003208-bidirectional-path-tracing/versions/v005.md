# Bidirectional Path Tracing

Also called: Bidirectional Path Tracing for Participating Media, Bidirectional transmittance-based path sampling, Vertex-vertex connection

## Overview
Bidirectional Path Tracing (BDPT) constructs a full light transport path by independently generating a light subpath and an eye subpath, then connecting their endpoints with a deterministic segment [S1]. It sets itself apart from unidirectional path tracing by including both emitted radiance and sensor importance in the path PDF, which significantly reduces variance for scenes with refractive boundaries or complex light transport [S1, S2].

## How it works
**Inputs and Outputs:**
*   **Input:** Scene geometry, participating media properties (heterogeneous or homogeneous), camera parameters, light source definitions.
*   **Output:** Radiance estimate for the pixel.

**Data Structures:**
*   **Light Subpath:** A sequence of vertices $l_0, l_1, \dots, l_s$. $l_0$ is on the light source. $l_1 \dots l_s$ are scattering events in the medium or on surfaces.
*   **Eye Subpath:** A sequence of vertices $e_0, e_1, \dots, e_t$. $e_0$ is the camera sensor. $e_1 \dots e_t$ are scattering events or surface interactions.
*   **Connection Segment:** A deterministic link between $l_s$ and $e_t$ (or other combinations depending on the specific BDPT variant).

**Steps:**
1.  **Generate Light Subpath:** Sample $s$ vertices starting from the light source. For each step $i$ from $1$ to $s$:
    *   Sample a direction from the current vertex $l_{i-1}$ using the phase function and medium scattering properties.
    *   Sample a distance to the next scattering event or boundary using the transmittance $\tau$ and extinction coefficient $\sigma_t$.
    *   If a boundary is hit, handle refraction/reflection according to the surface BRDF/BSDF.
    *   Store vertex $l_i$.
2.  **Generate Eye Subpath:** Sample $t$ vertices starting from the camera. For each step $j$ from $1$ to $t$:
    *   Sample a direction into the scene from the current vertex $e_{j-1}$ (often using the camera's lens and pixel sampling).
    *   Sample a distance to the next interaction using the transmittance $\tau$ and extinction coefficient $\sigma_t$.
    *   If a boundary is hit, handle the interaction.
    *   Store vertex $e_j$.
3.  **Connect Subpaths:** Connect the endpoint of the light subpath ($l_s$) to the endpoint of the eye subpath ($e_t$) with a deterministic segment. This segment has zero random decisions, meaning its probability density is determined by the geometry and transmittance between the two points [S1].
4.  **Estimate Radiance:** Calculate the contribution of the full path using the rendering equation, weighted by the probability densities of the subpaths and the connection heuristic [S1].

**Formulas:**
*   **Power Heuristic for MIS:** When combining samples from different subpath lengths or strategies, the weight $w_s(x)$ for a sample generated by strategy $s$ is:
    $$w_s(x) = \frac{p_s^\beta(x)}{\sum_i p_i^\beta(x)} \quad \text{for } \beta \in \mathbb{R}^+ \quad [S3]$$
    *   $\beta = 1$: Balance heuristic.
    *   $\beta \to \infty$: Maximum heuristic [S3].
*   **Multi-sample Estimator:**
    $$F = \sum_{i=1}^n \frac{1}{n_i} \sum_{j=1}^{n_i} w_{ij}(x_{i,j}) \frac{f(x)}{p_i(x_{i,j})} \quad [S3]$$
    *   $n_i$: Number of samples for strategy $i$.
    *   $x_{i,j}$: Sample $j$ from strategy $i$.
    *   $p_i(x_{i,j})$: Probability density of sample $x_{i,j}$ under strategy $i$.
    *   $f(x)$: Integrand (measurement contribution).

**Parameters:**
*   **$\beta$:** Exponent in the power heuristic. Typical value is $1$ (balance heuristic) [S3].

**Edge Cases and Pitfalls:**
*   **Infinite Variance:** Vertex-vertex connections can lead to infinite variance because the connecting segment is a 0-random-decision subpath, meaning none of the terms for the connecting segment are importance sampled [S1].
*   **Heterogeneous Media Density Approximation:** In heterogeneous media, the propagation densities $p_i$ are not analytically computable because they depend on the transmittance $\tau$ [S3].
    *   Using certain approximation algorithms (e.g., Algorithm 2 in [S3]) for density estimation fails condition (17) (weights summing to 1 in expectation) for all but the maximum heuristic, introducing bias [S3].
    *   **Solution:** Approximate $\tau$ by a deterministic quadrature rule. This ensures weights produced by equation (18) sum up to one, preserving the good properties of the heuristics without introducing bias [S3].

## Subtopics

### [Bidirectional Path-Space Differentiable Rendering](7618-bidirectional-path-space-differentiable-rendering.md)
Computes gradients of a rendering equation with respect to scene parameters by constructing a differentiable path space using both light and eye subpaths. It sets itself apart from unidirectional differentiable methods by leveraging the bidirectional structure of [Bidirectional Path Tracing](6666-bidirectional-path-tracing.md) to reduce variance in gradient estimation for complex light transport, specifically addressing the discontinuities inherent in path-space derivatives [7618-bidirectional-path-space-differentiable-rendering].

### [Primary Sample Space Transformation Layout](9592-primary-sample-space-transformation-layout.md)
A data layout for storing the primary sample vector $\bar{u}$ in Bidirectional Path Tracing (BDPT) to ensure that small changes in the sample space $U$ correspond to small changes in the path space $P$. It solves the problem of sample correlation in heterogeneous participating media by separating random numbers for eye/light subpaths and between scattering/propagation steps, unlike standard BDPT which uses successive dimensions of $U$ directly.

### Bidirectional Path Tracing with Approximate Densities
An adaptation of BDPT for participating media where propagation densities $p_i$ are approximated because they are not analytically computable in heterogeneous media [S3]. It approximates $\tau$ by a deterministic quadrature rule to ensure weights produced by the power heuristic sum up to one, preserving the good properties of the heuristics without introducing bias [S3]. Using other approximation methods (like Algorithm 2 in [S3]) fails condition (17) for all but the maximum heuristic, leading to bias [S3].

## Operating characteristics
*   **Time Complexity:** Proportional to the number of subpaths generated and the length of the subpaths ($s$ and $t$). The connection step is $O(1)$ per pair of endpoints.
*   **Memory Complexity:** Proportional to the maximum subpath length stored.
*   **Measured Performance:** Improves convergence rate for light transport with refractive boundaries compared to unidirectional path tracing [S2].
*   **Strengths:** Reduces variance for complex light transport scenarios, especially those involving refractive boundaries or highly anisotropic media [S1, S2].
*   **Limitations:** Can suffer from infinite variance due to the deterministic connection segment [S1]. Requires careful handling of density approximations in heterogeneous media to avoid bias [S3].
*   **When to use:** Scenes with refractive boundaries, complex light transport where unidirectional sampling is inefficient, or when high-order scattering is significant [S2].
*   **When not to use:** Simple scenes where unidirectional path tracing is sufficient, or when computational resources are extremely limited and the overhead of generating two subpaths is prohibitive.

## Background
Bidirectional Path Tracing was expanded from path tracing ideas by Lafortune and Willems to improve convergence rates for light transport with refractive boundaries [S2]. It builds on the foundations of Path Tracing and Light Tracing, combining them using Multiple Importance Sampling (MIS) [S3]. The method is widely used in global illumination rendering, particularly for participating media [S2, S3].
