# Bridge Sampling

Also called: Vertex Bridge Sampling

## Overview
Bridge Sampling is a method for sampling a subpath (bridge) of arbitrary vertex count connecting two vertices in a participating medium, where the probability density is proportional to all inner phase functions and reciprocal squared distance terms [S1]. It sets itself apart from sibling methods like Equiangular Sampling and MVNEE by fixing the endpoint via rotation and uniform scaling of a preliminary path, which preserves angles and handles highly-peaked forward scattering more robustly [S1]. Unlike Path Guiding, it does not use memory to store sampling densities or handle visibility explicitly during construction [S1].

## How it works

### Inputs and Outputs
*   **Inputs:** Start vertex $x_0$, target vertex $x_n$, connection distance $s = \|x_n - x_0\|_2$, medium extinction coefficient $\mu_t$ (assumed homogeneous for sampling, see Heterogeneous Media), phase function parameters (e.g., Henyey-Greenstein mean cosine $g$), and maximum vertex count $n_{max}$ [S1].
*   **Outputs:** A bridge path $\bar{x}_{0,n} = (x_0, x_1, \dots, x_n)$ and its probability density $p(\bar{x}_{0,n})$ [S1].

### Data Structures
*   **Preliminary Path:** A sequence of vertices $\bar{x}'_{0,n}$ and distances $\bar{d}'_{1,n}$ sampled independently before scaling [S1].
*   **SVD Matrices:** For constraint-based sampling, $U \in \mathbb{R}^{3 \times 3}$, $V \in \mathbb{R}^{n \times n}$, and singular values $\Sigma$ from the decomposition of the linear map $O$ [S1].
*   **Precomputed Splines:** Cubic spline approximations of $\beta_n(s\mu_t)$ for $2 \le n \le n_{max}$ and various phase function parameters, used to determine vertex count probabilities [S1].

### Steps

#### 1. Sample Vertex Count $n$
To sample the number of inner vertices $n-1$ (total vertices $n+1$ including endpoints), use the second-moment-based distribution [S1]:
1.  Evaluate the precomputed spline approximation $\beta_n(s\mu_t)$ for each $n \in \{1, \dots, n_{max}\}$ [S1]. Note: $n=1$ corresponds to deterministic connection (Next-Event Estimation) [S1].
2.  Normalize these values to form a probability distribution $P_n$ [S1].
3.  Sample $n$ from this distribution [S1].

#### 2. Sample Preliminary Bridge (Scaling-Based)
This is the recommended instance for arbitrary vertex counts [S1].
1.  **Sample Directions:** From $x_0$, sample the initial direction $\omega'_1$ using the phase function (e.g., importance sampling the phase function $f_s(\omega_0 \to \omega'_1)$) [S1].
2.  **Sample Distances:** For each edge $i \in \{1, \dots, n\}$, sample an independent preliminary distance $d'_i$ from an exponential distribution with scale parameter $\lambda$ [S1]:
    $$ p_{\bar{D}'}(d'_i) = \frac{1}{\lambda} e^{-d'_i/\lambda} $$
    [S1]
3.  **Construct Preliminary Path:** Compute preliminary vertices $\bar{x}'_{0,n}$ using $x'_0 = x_0$ and $x'_i = x'_{i-1} + d'_i \omega'_i$, where $\omega'_i$ is the direction of edge $i$ [S1].

#### 3. Transform to Target
1.  **Rotate:** Compute $R$, the shortest rotation matrix that maps the preliminary final direction $\omega'_{0 \to n}$ (direction from $x'_0$ to $x'_n$) to the target direction $\omega_{0 \to n}$ (direction from $x_0$ to $x_n$) [S1].
2.  **Scale:** Compute the preliminary connection distance $r = \|x'_n - x'_0\|_2$ and the target distance $s = \|x_n - x_0\|_2$ [S1].
3.  **Apply Affine Transformation:** Rotate and uniformly scale the bridge around $x_0$ such that the endpoint matches $x_n$ [S1]:
    $$ \bar{x}_{0,n} = m(\bar{x}'_{0,n}, r, s) = (R \bar{x}'_{0,n}, \frac{s}{r} \bar{x}'_{0,n}) $$
    [S1]
    This transformation preserves angles between edges [S1].

#### 4. Compute PDF
The probability density of the bridge in product vertex area measure is [S1]:
$$ p(\bar{x}_{1,n-1}) = \frac{(n-1)!}{s^{n-1}} \prod_{i=1}^{n} p_{\Omega}(\omega'_i) $$
where $p_{\Omega}(\omega'_i)$ are the phase function sampling densities [S1]. The scale parameter $\lambda$ cancels out, making the result scale-invariant [S1].

#### Alternative: Constraint-Based Sampling (n=2, 3 only)
For $n=2$ or $n=3$, an alternative instance avoids scaling [S1]:
1.  Define linear map $O$ from preliminary distances $\bar{d}'$ to vector $x'_n - x'_0$ using fixed edge directions $\omega'_i$: $x'_n - x'_0 = O \bar{d}'$ [S1].
2.  Compute SVD: $O = U \Sigma V^T$, where $k = \text{rank}(O)$ [S1].
3.  Sample $y' \in \mathbb{R}^k$ uniformly in the feasible region of the image $\text{im}(O)$ defined by $\|O \bar{d}'\|_2 = s$ and $d'_i > 0$ [S1].
4.  Set $\bar{c} = [y', 0, \dots, 0]^T$ (padded with zeros if $k < n$) [S1].
5.  Sample $y_{k+1}, \dots, y_n$ uniformly in the feasible region of the null space $\text{ker}(O)$ [S1].
6.  Set $\bar{c} = [y', y_{k+1}, \dots, y_n]^T$ and compute $\bar{d} = V \bar{c}$ [S1].
7.  The PDF is $p(\bar{x}_{1,n-1}) = \frac{1}{V_{\text{img}} V_{\text{null}}}$, where $V_{\text{img}}$ and $V_{\text{null}}$ are the volumes of the feasible regions [S1].

### Heterogeneous Media Implementation
When integrating into a renderer with heterogeneous media:
1.  Read $\mu_t$ at the endpoint of the current path [S1].
2.  Construct the tentative bridge assuming a homogeneous medium with unit extinction (ignore heterogeneity during construction) [S1].
3.  After construction, evaluate transmittances along the path to compute measurement contribution, testing each edge for visibility [S1].

def sample_bridge(x0, xn, mu_t, phase_func, n_max=10, g=0.95):
    """
    Samples a bridge from x0 to xn in a participating medium.
    Uses scaling-based sampling for arbitrary n.
    """
    s = np.linalg.norm(xn - x0)
    
    # 1. Sample vertex count n
    # Precomputed splines beta_n are assumed available as a function beta(n, s_mu_t)
    s_mu_t = s * mu_t
    probs = np.array([beta(n, s_mu_t) for n in range(1, n_max + 1)])
    probs /= np.sum(probs)
    n = np.random.choice(range(1, n_max + 1), p=probs)
    
    # 2. Sample preliminary bridge
    # Sample initial direction from phase function
    omega_prime_1 = phase_func.sample_direction(x0, xn) # Importance sample phase function
    
    # Sample independent exponential distances
    # Scale lambda cancels out, so we can use lambda=1 for simplicity in sampling
    # The PDF derivation shows lambda independence
    d_primes = np.random.exponential(scale=1.0, size=n)
    
    # Construct preliminary vertices
    x_primes = [x0]
    current_pos = x0
    current_dir = omega_prime_1
    
    # Store directions for SVD if needed, or just accumulate
    for i in range(1, n):
        # Sample next direction from phase function based on previous vertex and direction
        # Note: In the bridge context, we sample phase functions at inner vertices
        # The direction omega'_i+1 is sampled from fs(omega'_i -> omega'_i+1)
        if i < n - 1:
            current_dir = phase_func.sample_direction(current_pos, xn) # Approximation for sampling
            # More precisely: sample from phase function given incoming direction
            # Here we assume a helper that samples the outgoing direction
            current_dir = phase_func.sample_outgoing(current_dir)
        
        next_pos = current_pos + d_primes[i-1] * current_dir
        x_primes.append(next_pos)
        current_pos = next_pos

    # Preliminary final direction
    omega_prime_final = (x_primes[-1] - x0) / np.linalg.norm(x_primes[-1] - x0)

    x_bridge = []
    for x_prime in x_primes:
        # Rotate around x0

        # Scale
        x_scaled = x0 + scale_factor * x_rotated
        x_bridge.append(x_scaled)
        
    return x_bridge, n

def shortest_rotation_matrix(v1, v2):
    """Computes the shortest rotation matrix from v1 to v2."""
    v1 = v1 / np.linalg.norm(v1)
    v2 = v2 / np.linalg.norm(v2)
    
    dot = np.clip(np.dot(v1, v2), -1.0, 1.0)
    
    if dot > 0.999999:

        # Find a vector orthogonal to v1

### Parameters
*   **$n_{max}$:** Maximum number of vertices. Default 10 in tests, up to 14 in complex scenes [S1].
*   **$g$:** Mean cosine of the Henyey-Greenstein phase function. Typical values $0.95$ for forward scattering [S1].
*   **$s\mu_t$:** Product of connection distance and extinction coefficient. Used as index for precomputed functions [S1].
*   **Russian Roulette Survival:** 30% probability for constructing a bridge at an end vertex [S1].

### Edge Cases and Pitfalls
*   **Backward Scattering:** Enabling backward scattering (low $g$) increases variance. In extremely thin media, it can produce paths with large track lengths and low PDF, creating outliers [S1].
*   **Heterogeneity:** Sampling quality deteriorates with increasing medium heterogeneity because the method assumes homogeneity during construction [S1].
*   **Constraint-Based Limit:** Constraint-based sampling is limited to $n=2,3$ because computing the volume of the feasible region in the null space for higher $n$ is NP-hard [S1].
*   **Endpoint Directions:** The method foregoes importance sampling of directions at endpoints $x_0$ and $x_n$. This must be handled by combining with other estimators using Multiple Importance Sampling (MIS) [S1].
*   **Track Length Control:** The method cannot control the total track length and thus transmittance directly, though this typically does not cause significant variance in forward scattering [S1].

## Operating characteristics

### Time and Memory Complexity
*   **Time:** Sampling bridges is approximately 3× as expensive as standard next-event estimation for a maximum path length of 10 [S1]. Overhead arises from testing multiple edges for visibility and computing transmittance in heterogeneous media for longer track lengths [S1].
*   **Memory:** Requires precomputed cubic splines for $\beta_n(s\mu_t)$ for $n \in [2, n_{max}]$ and phase function parameters [S1].

### Measured Performance
*   In parametric unit tests with $g=0.95$ and 16 spp, bridge sampling has an overhead of up to 2× compared to path tracing with equiangular sampling [S1].
*   It scales to long paths up to $k=100$ vertices with $g=0.98$, maintaining moderate variance, whereas equiangular sampling produces few contributing samples [S1].

### Strengths and Limitations
*   **Strengths:** Consistently performs well in strongly forward scattering media ($g=0.95$) compared to Equiangular, MVNEE, and OMNEE. Handles arbitrary vertex counts [S1].
*   **Limitations:** Performance degrades slightly with lower mean cosine $g$. Deteriorates with increasing medium heterogeneity. Cannot control transmittance directly [S1].

### When to Use
*   Use in strongly forward scattering participating media where standard next-event estimation or equiangular sampling fails to find contributing paths [S1].
*   Use when multiple scattering events are expected between connection points [S1].

### When Not to Use
*   Avoid in extremely thin media with backward scattering enabled, due to outlier samples [S1].
*   Avoid if strict control over transmittance/track length is required [S1].

## Background

### Origin
Bridge Sampling was presented in a 2024 paper by Vincent Schüssler, Johannes Hanika, and Carsten Dachsbacher [S1].

### History and Development
The method addresses the limitation of analog path tracing, which terminates at a random point, by fixing the endpoint through rotation and scaling of a preliminary path [S1]. It builds on the observation that phase function sampling is effective and preserves geometric properties under rotation [S1]. The technique was implemented in a spectral renderer supporting heterogeneous media [S1].

### Usage
It is used in spectral renderers for volumetric light transport, particularly for connecting path endpoints in participating media with multiple scattering events [S1].
