# BSDF Sampling for Volumetric Paths

Also called: Implicit Path Tracing with Volume Interaction, Surface scattering in volumetric path tracing

## Overview
This method handles the surface interaction component of volumetric path tracing, calculating indirect lighting contributions based on surface BRDF/BSDF properties and sampling strategies [S1, unofficial]. It determines the new volumetric path direction upon surface intersection, updating throughput and rescaled probabilities to maintain unbiased estimation [S2]. It differs from pure volume scattering integrators by explicitly managing the coupling between surface geometry and participating media, specifically handling the transition from a surface hit back into the medium or to another surface [S2].

## How it works
**Inputs:**
- Intersection data (`isect`): Contains surface normal (`isect.shading.n`), incoming ray direction (`isect.wo`), and optional BSSRDF data.
- BSDF object (`bsdf`): Defines the surface reflectance properties.
- Sampler (`sampler`): Provides random numbers (`Get1D()`, `Get2D()`).
- Current throughput (`beta`): Accumulated path weight.
- Rescaled probabilities (`r_u`, `r_l`): For Russian Roulette or importance rescaling.
- Sample mode (`sampleMode`): Defines the PDF calculation strategy (e.g., Uniform Hemisphere, Cosine Weighted).
- Scene objects and lights: For recursive calls or light sampling.

**Outputs:**
- Updated throughput (`beta`).
- Rescaled probabilities (`r_l`).
- New ray (`ray`) for continuation.
- Indirect radiance contribution (`L_indirect`).
- State flags (`specularBounce`, `anyNonSpecularBounces`, `etaScale`).

**Data Structures:**
- `BSDFSample`: Contains `f` (BSDF value), `wi` (outgoing direction), `pdf` (probability density), `pdfIsProportional` (boolean flag), `IsSpecular()` (boolean), `IsTransmission()` (boolean), `eta` (refraction index), `flags`.
- `Interaction`/`Intersection`: Contains `wo` (incoming direction), `shading.n` (normal), `SpawnRay()` method.

**Steps:**

1.  **Calculate Cosine Factor:**
    Compute the cosine of the angle between the surface normal and the incoming ray direction:
    $$ \cos\theta = \text{clamp}(\mathbf{n} \cdot \mathbf{w}_i) $$
    where $\mathbf{n}$ is the surface normal and $\mathbf{w}_i$ is the incoming direction (often `isect.wo`). [S1, unofficial]

2.  **Sample BSDF:**
    Generate random numbers and sample the BSDF to determine the outgoing direction $\mathbf{w}_o$ (stored as `bs->wi`):
    ```python
    wo = isect.wo
    u = sampler.Get1D()
    bs = bsdf.Sample_f(wo, u, sampler.Get2D())
    if bs is None:
        break # No valid sample
    ```
    [S2]

3.  **Update Throughput:**
    Multiply the current throughput `beta` by the BSDF value, the cosine factor, and divide by the PDF:
    $$ \beta_{new} = \beta_{old} \times \frac{f(\mathbf{w}_i, \mathbf{w}_o) \cdot |\mathbf{n} \cdot \mathbf{w}_o|}{\text{pdf}} $$
    In code:
    ```python
    beta *= bs.f * AbsDot(bs.wi, isect.shading.n) / bs.pdf
    ```
    [S2]

4.  **Update Rescaled Probabilities:**
    Adjust the rescaled path probabilities based on whether the BSDF PDF is proportional to the actual PDF:
    ```python
    if bs.pdfIsProportional:
        r_l = r_u / bsdf.PDF(wo, bs.wi)
    else:
        r_l = r_u / bs.pdf
    ```
    [S2]

5.  **Update Path State:**
    - Determine if the bounce is specular:
      ```python
      specularBounce = bs.IsSpecular()
      anyNonSpecularBounces |= !bs.IsSpecular()
      ```
    - If transmission, update the refraction index scale:
      ```python
      if bs.IsTransmission():
          etaScale *= Sqr(bs.eta)
      ```
    - Spawn the new ray into the volume or scene:
      ```python
      ray = isect.SpawnRay(ray, bsdf, bs.wi, bs.flags, bs.eta)
      ```
    [S2]

6.  **Handle BSSRDF (Optional/Conditional):**
    If the surface supports subsurface scattering and the interaction is transmission, sample the BSSRDF:
    ```python
    bssrdf = isect.GetBSSRDF(ray, lambda, camera, scratchBuffer)
    if bssrdf and bs.IsTransmission():
        uc = sampler.Get1D()
        up = sampler.Get2D()
        probeSeg = bssrdf.SampleSp(uc, up)
        if probeSeg is None:
            break
        # Sample random intersection along BSSRDF probe segment
        seed = MixBits(FloatToBits(sampler.Get1D()))
        interactionSampler = WeightedReservoirSampler<SubsurfaceInteraction>(seed)
        # Intersect BSSRDF sampling ray against scene geometry
        # ... (Implementation details for BSSRDF probe intersection)
    ```
    [S2]

7.  **Calculate Indirect Radiance:**
    Recursively trace the new ray to compute indirect lighting. The specific implementation may vary, but generally:
    $$ L_{indirect} = \text{ObjectColor} \times \text{RecursiveTrace}(\text{ray}, \text{depth}+1) \times \beta_{new} $$
    In the specific source [S1, unofficial]:
    ```python
    L_indirect = hitObj.getObjectColor() * getPixelColor_ImplicitPathTracing(objects, IndexOfClosestObject, hit_t, second_ray, light, ++Depthi, sampleMode) * throughput
    ```
    [S1, unofficial]

8.  **Accumulate Result:**
    Add the indirect radiance to the pixel color:
    $$ C = C + L_{indirect} $$
    [S1, unofficial]

**Parameters:**
- `brdf`: Bidirectional Reflectance Distribution Function value. In some simplified implementations (e.g., [S1, unofficial]), this is hardcoded as $1/\pi$. [S1, unofficial]
- `sampleMode`: Sampling strategy (e.g., `Uniform_Hemisphere_Solid_Angle`, `Cosine_Weighted`). Affects PDF calculation. [S1, unofficial]

**Edge Cases and Pitfalls:**
- **No BSDF Sample:** If `bsdf.Sample_f` returns null, the path terminates. [S2]
- **PDF Proportionality:** Incorrectly handling `pdfIsProportional` leads to biased estimates. [S2]
- **Transmission Refraction:** The `etaScale` must be updated correctly for multiple refractions. [S2]
- **BSSRDF Complexity:** BSSRDF sampling adds significant complexity and requires additional intersection tests. [S2]
- **Undefined Sample Mode:** If `sampleMode` is neither Uniform Hemisphere nor Cosine Weighted, an error should be raised. [S1, unofficial]

## Operating characteristics
- **Time Complexity:** Depends on the BSDF complexity and scene depth. BSSRDF sampling adds overhead due to additional ray intersections. [S2]
- **Memory Complexity:** Low, primarily storing intersection data and BSDF state. [S2]
- **Strengths:** Handles complex surface interactions within volumetric paths, including subsurface scattering. [S2]
- **Limitations:** BSSRDF sampling is computationally expensive. [S2]
- **When to Use:** Scenes with complex surface materials and participating media. [S2]
- **When Not to Use:** Simple scenes where surface scattering is negligible or purely diffuse/specular without subsurface effects. [S2]

## Background
This method is part of the broader field of volumetric path tracing, specifically addressing the coupling between surface and volume interactions. It builds upon the principles of path tracing [S2] and incorporates techniques for handling BSSRDFs in participating media [S2]. The specific implementation details in [S1, unofficial] reflect an early or simplified approach to implicit path tracing with volume interactions.
