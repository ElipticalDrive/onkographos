# Sample Matching for Extinction Gradients

Also called: Sample Matching for Joint Extinction Gradient Estimation

## Overview
Sample Matching for Extinction Gradients is a differentiable volumetric path tracing method that reduces the variance of extinction coefficient gradients by evaluating the positive scattering term and the negative transmittance term at shared spatial locations along each path segment [S1, unofficial][S2, unofficial]. Unlike the base [Volumetric Path Tracing](1863-volumetric-path-tracing.md) method, which estimates these two opposing terms at unrelated points, this technique exploits their negative correlation to cancel variance, while maintaining the same primal rendering output [S1, unofficial][S2, unofficial].

## How it works
### Inputs and Outputs
*   **Inputs:** Scene geometry, participating media (defined by extinction $\sigma_t$, scattering $\sigma_s$, and emission $\sigma_e$), camera parameters, and the primal path records generated in the first pass [S1, unofficial][S2, unofficial].
*   **Outputs:** Radiance image (identical to the base method) and gradients of radiance with respect to the extinction coefficient $\sigma_t$ [S1, unofficial][S2, unofficial].

### Data Structures
The core data structure is the **Segment Record**, written during the primal pass and read during the adjoint pass [S2, unofficial].
*   **Masked Scatter Values:** Fields generated from the variant's spectrum size (RGB or spectral) [S2, unofficial].
*   **Wavelengths:** The path's specific wavelengths, ensuring the second kernel evaluates the medium at the correct spectral channels [S2, unofficial].

### Numbered Steps
1.  **Primal Pass:** Execute path tracing identical to the base [Volumetric Path Tracing](1863-volumetric-path-tracing.md) integrator [S1, unofficial]. Perform no gradient sampling [S2, unofficial].
2.  **Record Writing:** For each path segment, write one small record with masked scatter values to a global buffer; the values die at the end of the iteration [S2, unofficial].
3.  **Reservoir Management:** If `segment_slots` is less than `max_depth + 1`, maintain only the reservoir's running weight in loop state to avoid continuation spills [S2, unofficial].
4.  **Adjoint Kernel 1 (Path Replay):** Replay the primal path for each pixel and write the corresponding Segment Record to the global buffer [S1, unofficial][S2, unofficial].
5.  **Adjoint Kernel 2 (Gradient Sampling):** Read Segment Records from the buffer and trace fresh rays for gradient samples, processing one lane per record [S1, unofficial][S2, unofficial].
6.  **Sample Matching:** Evaluate both the scattering term (positive contribution) and the transmittance term (negative contribution) at the shared segment location [S1, unofficial][S2, unofficial].
7.  **Accumulation:** Combine the matched terms and accumulate the gradient into the output buffer [S2, unofficial].

### Formulas
*   **Transmittance:** $T = e^{-\tau}$, where $\tau = \sigma_t \Delta t$ is the optical depth over path length $\Delta t$ [S3, G].
*   **Gradient Estimation:** $\nabla_{\sigma_t} L \approx \frac{1}{N} \sum_{i=1}^{N} \left( \frac{\partial L_{\text{scat}}}{\partial \sigma_t} - \frac{\partial L_{\text{trans}}}{\partial \sigma_t} \right)$, where both partial derivatives are evaluated at the same spatial point $\mathbf{p}$ on the segment [S1, unofficial][S2, unofficial].

### Parameters
*   **`segment_slots`:** The number of records a path may keep. Any number of slots yields an unbiased result [S1, unofficial].
    *   **Default:** `max_depth + 1` (registered as `prbvolpath_sm_quad`). Every completed segment gets a record slot [S1, unofficial][S2, unofficial].
    *   **Value 1:** One weighted reservoir per lane. The retained segment stands in for the whole path, scaled by the inverse selection probability (registered as `prbvolpath_sm_linear`) [S2, unofficial].
    *   **Value >1:** Linear mapping where segment $j$ goes to slot $\min(j, \text{segment\_slots} - 1)$. The first `segment_slots - 1` segments are kept exactly; everything from there on shares one reserved row per lane and is resolved by a weighted reservoir [S2, unofficial].
*   **`gradient_samples_per_segment`:** Number of gradient samples taken per segment. Typical values are 1 or 4 [S2, unofficial]. Raising from 1 to 4 costs about 35% in time but reduces variance [S2, unofficial].

### Edge Cases and Pitfalls
*   **Continuation Spills:** Keeping a segment's record in loop state (using named variables or `dr.alloc_local`) causes +2.5 KiB/thread of continuation spills and +45% adjoint time on complex scenes (e.g., Bunny cloud), with no benefit under analytic intersection [S2, unofficial]. This is avoided by splitting the pass into two kernels [S2, unofficial].
*   **Reconnection Variance:** Reusing the path's own continuation for gradient samples (reconnection) results in higher variance than tracing fresh sub-paths. The shift mapping weight carries a transmittance ratio ranging from $10^{-9}$ to 356, and only 4.8% of samples could be reused [S2, unofficial].
*   **Unsupported Variants:** Polarized variants and forward mode are not supported, consistent with the base `prbvolpath` method [S1, unofficial].

### Pseudocode
```python
# Standard operations [G]
def sample_distance(pos, dir, medium):
    return medium.sample_distance(pos, dir)

def sample_phase(dir, phase_func):
    return phase_func.sample(dir)

def write_segment_record(record, buffer):
    buffer.append(record)

def trace_sub_path(pos, dir, medium, rng):
    return medium.trace_scattering_gradient(pos, dir, rng)

def trace_sub_path_transmittance(pos, dir, medium, rng):
    return medium.trace_transmittance_gradient(pos, dir, rng)

def accumulate_gradient(grad, output_buffer):
    output_buffer += grad

# Primal Pass
def primal_pass(scene, camera, rng):
    segment_buffer = []
    reservoir_weight = 0.0
    selected_record = None

    for pixel in camera.rays:
        path_radiance = 0.0
        throughput = 1.0
        current_pos = pixel.origin
        current_dir = pixel.direction

        for depth in range(MAX_DEPTH):
            dist = sample_distance(current_pos, current_dir, scene.medium)
            next_pos = current_pos + dist * current_dir

            sigma_t = scene.medium.extinction(next_pos)
            sigma_s = scene.medium.scattering(next_pos)
            sigma_e = scene.medium.emission(next_pos)

            tau = sigma_t * dist
            T = exp(-tau)

            path_radiance += throughput * sigma_e * T * dist

            record = {
                'pos': next_pos,
                'dir': current_dir,
                'throughput': throughput,
                'wavelengths': pixel.wavelengths,
                'depth': depth
            }

            if SEGMENT_SLOTS == 1:
                current_weight = throughput * sigma_s / sigma_t
                reservoir_weight += current_weight
                if rng.uniform() < current_weight / reservoir_weight:
                    selected_record = record
            elif SEGMENT_SLOTS > 1:
                slot_idx = min(depth, SEGMENT_SLOTS - 1)
                if slot_idx < SEGMENT_SLOTS - 1:
                    write_segment_record(record, segment_buffer)
                else:
                    current_weight = throughput * sigma_s / sigma_t
                    reservoir_weight += current_weight
                    if rng.uniform() < current_weight / reservoir_weight:
                        write_segment_record(record, segment_buffer)
                        segment_buffer[-1] = record

            if sigma_s == 0:
                break

            new_dir = sample_phase(current_dir, scene.phase)
            throughput *= (sigma_s / sigma_t) * T * scene.phase(current_dir, new_dir)
            current_pos = next_pos
            current_dir = new_dir

        if SEGMENT_SLOTS == 1 and selected_record is not None:
            write_segment_record(selected_record, segment_buffer)

    return segment_buffer

# Adjoint Pass Kernel 1: Path Replay
def adjoint_kernel_1(scene, camera, rng):
    return primal_pass(scene, camera, rng)

# Adjoint Pass Kernel 2: Gradient Sampling
def adjoint_kernel_2(scene, segment_records, rng):
    output_buffer = 0.0
    for record in segment_records:
        pos = record['pos']
        dir = record['dir']
        throughput = record['throughput']

        scattering_grad = 0.0
        for _ in range(GRADIENT_SAMPLES_PER_SEGMENT):
            scattering_grad += trace_sub_path(pos, dir, scene.medium, rng)
        scattering_grad /= GRADIENT_SAMPLES_PER_SEGMENT

        transmittance_grad = 0.0
        for _ in range(GRADIENT_SAMPLES_PER_SEGMENT):
            transmittance_grad += trace_sub_path_transmittance(pos, dir, scene.medium, rng)
        transmittance_grad /= GRADIENT_SAMPLES_PER_SEGMENT

        gradient = throughput * (scattering_grad - transmittance_grad)
        accumulate_gradient(gradient, output_buffer)

    return output_buffer
```

## Operating characteristics
*   **Time Complexity:** The primal pass is identical to [Volumetric Path Tracing](1863-volumetric-path-tracing.md) [S1, unofficial]. The adjoint pass adds overhead proportional to `gradient_samples_per_segment` and the number of segments [S2, unofficial]. Gradient sampling takes 1.2–1.55× longer in RGB and 0.74–0.82× in spectral variants on a microbenchmark [S2, unofficial].
*   **Memory Complexity:** Depends on `segment_slots` [S2, unofficial]. Value 1 adds ~32 MiB overhead vs base [S2, unofficial]. Default (`max_depth + 1`) adds ~4.6 GB overhead on a typical wavefront [S2, unofficial].
*   **Performance:** Primal speedup: 72.1 s vs 104.5 s at 64 spp because the plugin consumes null collisions in one fused C++ walk instead of paying `optixTrace` for each [S2, unofficial]. Variance reduction: On a Bunny cloud scene (768×576, 8 spp), 4 slots reduced variance from 136.5 (DRT reference) to 46.4 (occupied voxels) and 81.4 (all voxels), a 0.26× factor [S2, unofficial]. Accuracy: Gradients agree with finite differences within 1% in RGB and spectral variants [S1, unofficial].
*   **Strengths:** Significant variance reduction for extinction gradients; supports spectral and RGB variants; efficient primal rendering via fused null-collision walk [S1, unofficial][S2, unofficial].
*   **Limitations:** High memory usage with default `segment_slots`; polarized variants and forward mode are not supported [S1, unofficial][S2, unofficial].

## Background
*   **Origin:** Introduced in 2026 as part of the Mitsuba 3 renderer development [S1, unofficial][S2, unofficial].
*   **Development:** The method was developed to address the high variance of extinction gradients in differentiable volumetric path tracing. Initial attempts using reconnection (reusing path continuations) were abandoned due to instability in transmittance ratios within shift mapping weights [S2, unofficial].
*   **Usage:** Implemented as the `prbvolpath_sm` plugin in Mitsuba 3, supporting both RGB and spectral variants [S2, unofficial].
