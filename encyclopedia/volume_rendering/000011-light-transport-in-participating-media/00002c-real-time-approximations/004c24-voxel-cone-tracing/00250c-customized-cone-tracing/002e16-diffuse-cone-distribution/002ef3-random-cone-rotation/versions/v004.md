# Random Cone Rotation
## Overview
Random Cone Rotation mitigates blocky artifacts in sparse diffuse cone sampling for Voxel Cone Tracing by rotating a fixed set of cones around the surface normal [S1, unofficial]. It breaks up the rigid geometric structure of the sampling pattern without increasing the cone count [S1, unofficial].
## How it works
**Inputs and Outputs:**
- Input: A set of diffuse cone directions in a local coordinate system aligned with the surface normal $\mathbf{n}$, and a random value $\rho \in [0, 1)$ [G].
- Output: Rotated cone directions $\{\mathbf{d}'_i\}$ for tracing [G].
**Data Structures:**
The distribution uses 5 cones: one aligned with $\mathbf{n}$ and four perpendicular to it [S1, unofficial]. All diffuse cones share a fixed aperture angle of $30^\circ$ [S1, unofficial].
**Steps:**
1. Generate a random rotation angle $\theta$ uniformly in $[0, 2\pi)$ from $\rho$ [G].
2. Construct a rotation matrix $R$ around axis $\mathbf{n}$ by $\theta$ [G].
3. Apply $R$ to each base cone direction $\mathbf{d}_i$ to obtain $\mathbf{d}'_i = R\mathbf{d}_i$ [G].
4. Use $\{\mathbf{d}'_i\}$ for cone tracing [G].
**Pseudocode:**
```python
import math
import numpy as np

def random_cone_rotation(normal: np.ndarray, random_value: float) -> list:
    """Rotates a fixed set of 5 diffuse cones around the surface normal [G]."""
    base_cones = [
        np.array([0.0, 0.0, 1.0]),
        np.array([1.0, 0.0, 0.0]),
        np.array([0.0, 1.0, 0.0]),
        np.array([-1.0, 0.0, 0.0]),
        np.array([0.0, -1.0, 0.0])
    ]
    theta = random_value * 2.0 * math.pi
    kx, ky, kz = normal
    s = math.sin(theta)
    c = math.cos(theta)
    one_minus_c = 1.0 - c
    K = np.array([[0.0, -kz, ky], [kz, 0.0, -kx], [-ky, kx, 0.0]])
    I = np.eye(3)
    R = I + s * K + one_minus_c * (K @ K)
    return [R @ base_dir for base_dir in base_cones]
```
**Parameters:**
- Aperture angle: $30^\circ$ [S1, unofficial].
- Number of cones: 5 [S1, unofficial].
**Edge Cases and Pitfalls:**
- Noise: The randomization introduces noise into the lighting result [S1, unofficial].
- Precision: Ensure the normal vector is normalized before constructing the rotation matrix to avoid scaling artifacts [G].
- Degenerate Input: If the normal is zero, the rotation is undefined [G].

### [Noise Kernel Generation](6360-noise-kernel-generation.md)
Constructs a directional basis for cone tracing aligned with the light direction rather than the surface normal. Choose it when aligning the cone distribution with the light vector is preferred over normal-aligned sampling.

## Operating characteristics
- Time Complexity: $O(1)$ per cone, as the number of cones is fixed [G].
- Memory Complexity: $O(1)$, storing only the base cone directions and the rotation matrix [G].
- Strengths: Effectively reduces blocky artifacts caused by sparse sampling without increasing the number of cones [S1, unofficial].
- Limitations: Introduces noise [S1, unofficial].
- When to Use: When using a small number of cones for diffuse indirect lighting in real-time Voxel Cone Tracing and blocky artifacts are visible [S1, unofficial].
- When Not to Use: Not given in the sources.
## Background
Random Cone Rotation was introduced in the context of Voxel Cone Tracing for real-time global illumination [S1, unofficial]. It addresses the blocky artifacts that arise from using only five cones for diffuse lighting [S1, unofficial].
