# Voxel Cone Tracing with Temporal Multi-bounce

Also called: Realtime Global Illumination with Voxel Cone Tracing, Temporal Voxel Cone Tracing

## Overview
Voxel Cone Tracing with Temporal Multi-bounce is a real-time global illumination technique that stores scene radiance in a 3D voxel texture and traces cones through it to approximate indirect lighting, enhanced by temporal propagation to simulate infinite bounces [S1, unofficial]. It builds on [Voxel Cone Tracing](1454-voxel-cone-tracing.md) by adding a temporal feedback loop where light energy is retained and propagated across frames, allowing the approximation of multiple light bounces without the computational cost of spatial multi-bounce tracing [S1, unofficial].

## How it works
The method consists of two main phases: voxelization of the scene into a 3D texture, and cone tracing for shading, with a temporal update step for multi-bounce propagation.

### Inputs and Outputs
**Inputs:**
- Scene geometry (meshes and particles).
- Camera position and projection matrices.
- Light positions and intensities.
- Previous frame's voxel texture state (for temporal propagation).
- Parameters: `voxelCount`, `multibounceRestitution`, `temporalMultibounce`, `anisotropicVoxels`, `hdrVoxels`.

**Outputs:**
- Final shaded pixel color with indirect lighting contributions.
- Updated voxel textures for the next frame.

### Data Structures
The implementation uses the following textures and framebuffers:

1.  **`voxelTexture`**: A 3D texture of size $N \times N \times N$ (where $N = \text{voxelCount}$).
    -   **Storage**: `GL_RGBA16F` if `hdrVoxels` is true, otherwise `GL_RGBA8` [S1, unofficial].
    -   **Content**: Stores isotropic radiance.
    -   **Wrapping**: `GL_CLAMP_TO_BORDER` on all axes [S1, unofficial].
    -   **Filtering**: `GL_LINEAR_MIPMAP_LINEAR` if mipmaps are generated, else `GL_LINEAR` [S1, unofficial].

2.  **`voxelTextureAniso[6]`**: An array of six 3D textures, each of size $(N/2) \times (N/2) \times (N/2)$.
    -   **Storage**: `GL_RGBA16F` [S1, unofficial].
    -   **Content**: Stores anisotropic radiance per direction (positive/negative X, Y, Z).
    -   **Usage**: Only created if `anisotropicVoxels` is true [S1, unofficial].

3.  **`shadowMap`**: A 2D texture of size $2048 \times 2048$.
    -   **Storage**: `GL_DEPTH_COMPONENT` with `GL_FLOAT` type [S1, unofficial].
    -   **Wrapping**: `GL_CLAMP_TO_BORDER` [S1, unofficial].

### Numbered Steps

1.  **Initialize Voxel Textures**:
    -   If `anisotropicVoxels` is true, create `voxelTexture` of size $N^3$ and six `voxelTextureAniso` textures of size $(N/2)^3$.
    -   Otherwise, create only `voxelTexture` of size $N^3$ [S1, unofficial].

2.  **Voxelization Setup**:
    -   Bind the `voxelizeShader`.
    -   Reset the framebuffer.
    -   Set viewport to $N \times N$.
    -   Disable blending, culling, and depth testing.
    -   Set color mask to false (write only to depth/stencil if needed, or use image load/store).
    -   Bind `voxelTexture` to image unit 0 and clear it to $(0, 0, 0, 0)$ [S1, unofficial].

3.  **Bind Image Texture and Set Uniforms**:
    -   Bind `voxelTexture` as a read-write image at unit 0.
    -   Set uniforms: `u_lightProj`, `u_shadowBias`, `u_shadowMap` (unit 1), `u_averageValues`, `u_temporalMultibounce`, `u_voxelCount`, `u_time`, `u_restitution` [S1, unofficial].

4.  **Bind Previous Frame Textures for Temporal Multi-bounce**:
    -   If not `anisotropicVoxels`, bind `voxelTexture` to unit 8 (`u_voxelTexturePrev`) [S1, unofficial].
    -   If `anisotropicVoxels`, bind `voxelTextureAniso[i]` to units 2-7 (`u_voxelTexturePrev` index) [S1, unofficial].

5.  **Fix Opacity**:
    -   Bind `fixopacityShader`.
    -   Bind `voxelTexture` as read-write image at unit 0.
    -   Dispatch compute shader at $N \times N \times N$ threads to convert the opacity counter back to opacity values [S1, unofficial].

6.  **Generate Mipmaps**:
    -   If `anisotropicVoxels` is true, generate mipmaps for all 6 directional textures using `genMipmapLevel` (isotropic to anisotropic) and `genMipmap`.
    -   If `customMipmap` is true, use custom mipmapping.
    -   Otherwise, use hardware `glGenerateMipmap` [S1, unofficial].

7.  **Voxel Cone Tracing Setup**:
    -   Enable back-face culling and depth test (LEQUAL).
    -   Bind `voxelConeShader`.
    -   Set uniforms: `u_project`, `u_cameraPos`, `u_tracedShadows`, `u_shadowAperture`, `u_renderMode`, `u_indirectLight`, `u_voxelCount`, `u_diffuseNoise`, `u_restitution` [S1, unofficial].

8.  **Bind Textures for Cone Tracing**:
    -   Bind `voxelTexture` to unit 1.
    -   If `anisotropicVoxels`, bind `voxelTextureAniso[i]` to units 2-7.
    -   Bind shadow map to unit 0.
    -   Set `u_time`.
    -   Draw scene objects using `voxelConeShader`.
    -   Draw particles using `particleShader` [S1, unofficial].

### Formulas and Parameters

**Temporal Multi-bounce Propagation:**
The core innovation is the temporal propagation of light energy. The energy retention factor `multibounceRestitution` controls how much light is retained from the previous frame's voxel state.

Let $V_t$ be the voxel texture at time $t$ and $V_{t-1}$ be the voxel texture from the previous frame. The update involves blending the newly voxelized radiance with the temporally propagated radiance. The exact blending formula is not explicitly provided in the source code comments, but the parameter `multibounceRestitution` (default 0.3) acts as the retention factor [S1, unofficial].

**Parameters:**
-   `voxelCount`: Resolution of the isotropic voxel texture. Default: 128 [S1, unofficial].
-   `shadowBias`: Depth bias applied to shadow map rendering. Default: 0.0005f [S1, unofficial].
-   `multibounceRestitution`: Energy retention factor for temporal multi-bounce propagation. Default: 0.3f [S1, unofficial].
-   `restitution`: Energy retention factor for standard indirect lighting. Default: 0.3f [S1, unofficial].
-   `shadowAperture`: Controls shadow penumbra/softness in traced shadows. Default: 2 [S1, unofficial].
-   `anisotropicVoxels`: Enables anisotropic voxel storage using 6 directional textures instead of 1 isotropic texture [S1, unofficial].
-   `hdrVoxels`: Determines if voxel textures use HDR RGBA16f storage [S1, unofficial].
-   `averageConflictingValues`: Enables averaging of overlapping fragments during voxelization. Only active when `hdrVoxels` is false [S1, unofficial].
-   `temporalMultibounce`: Enables temporal light propagation across frames [S1, unofficial].
-   `addDiffuseNoise`: Enables diffuse noise injection during cone tracing [S1, unofficial].

### Pseudocode

```python
# Initialization
N = 128  # Default voxelCount
anisotropic = False
hdr = True

if anisotropic:
    voxel_texture = create_3d_texture(N, N, N, GL_RGBA16F)
    voxel_texture_aniso = [create_3d_texture(N//2, N//2, N//2, GL_RGBA16F) for _ in range(6)]
else:
    voxel_texture = create_3d_texture(N, N, N, GL_RGBA16F)
    voxel_texture_aniso = []

shadow_map = create_2d_texture(2048, 2048, GL_DEPTH_COMPONENT)

# Frame Loop
def process_frame(scene, camera, previous_voxel_state):
    # 1. Voxelization Setup
    bind_shader(voxelize_shader)
    reset_framebuffer()
    set_viewport(N, N)
    disable_blend()
    disable_cull()
    disable_depth_test()
    set_color_mask(False)
    
    bind_image(voxel_texture, unit=0)
    clear_image(voxel_texture, (0.0, 0.0, 0.0, 0.0))
    
    # 2. Bind Uniforms
    set_uniform(voxelize_shader, 'u_lightProj', camera.projection)
    set_uniform(voxelize_shader, 'u_shadowBias', 0.0005)
    bind_texture(shadow_map, unit=1)
    set_uniform(voxelize_shader, 'u_shadowMap', 1)
    set_uniform(voxelize_shader, 'u_averageValues', True)
    set_uniform(voxelize_shader, 'u_temporalMultibounce', True)
    set_uniform(voxelize_shader, 'u_voxelCount', N)
    set_uniform(voxelize_shader, 'u_time', current_time)
    set_uniform(voxelize_shader, 'u_restitution', 0.3)
    
    # 3. Bind Previous Frame Textures
    if not anisotropic:
        bind_texture(previous_voxel_state, unit=8)
        set_uniform(voxelize_shader, 'u_voxelTexturePrev', 8)
    else:
        for i in range(6):
            bind_texture(previous_voxel_state_aniso[i], unit=2+i)
            set_uniform(voxelize_shader, f'u_voxelTexturePrev_{i}', 2+i)
            
    # 4. Voxelize Scene
    draw_scene(voxelize_shader)
    
    # 5. Fix Opacity
    bind_shader(fixopacity_shader)
    bind_image(voxel_texture, unit=0)
    dispatch_compute(N, N, N, fixopacity_shader)
    
    # 6. Generate Mipmaps
    if anisotropic:
        for i in range(6):
            gen_mipmap_level(voxel_texture_aniso[i])
            gen_mipmap(voxel_texture_aniso[i])
    else:
        gen_mipmap(voxel_texture)
        
    # 7. Cone Tracing Setup
    enable_backface_cull()
    enable_depth_test(LEQUAL)
    bind_shader(voxel_cone_shader)
    
    set_uniform(voxel_cone_shader, 'u_project', camera.projection)
    set_uniform(voxel_cone_shader, 'u_cameraPos', camera.position)
    set_uniform(voxel_cone_shader, 'u_tracedShadows', True)
    set_uniform(voxel_cone_shader, 'u_shadowAperture', 2.0)
    set_uniform(voxel_cone_shader, 'u_renderMode', 0)
    set_uniform(voxel_cone_shader, 'u_indirectLight', True)
    set_uniform(voxel_cone_shader, 'u_voxelCount', N)
    set_uniform(voxel_cone_shader, 'u_diffuseNoise', False)
    set_uniform(voxel_cone_shader, 'u_restitution', 0.3)
    
    # 8. Bind Textures for Cone Tracing
    bind_texture(voxel_texture, unit=1)
    if anisotropic:
        for i in range(6):
            bind_texture(voxel_texture_aniso[i], unit=2+i)
    bind_texture(shadow_map, unit=0)
    set_uniform(voxel_cone_shader, 'u_time', current_time)
    
    # 9. Draw Scene for Shading
    draw_scene(voxel_cone_shader)
    draw_particles(particle_shader)
    
    # Return updated voxel state for next frame
    return voxel_texture, voxel_texture_aniso if anisotropic else None
```

### Edge Cases and Pitfalls
-   **Anisotropic Mode**: Requires 6 separate directional textures at half resolution ($N/2$) instead of a single isotropic texture, increasing memory usage [S1, unofficial].
-   **Opacity Fix**: The opacity counter must be converted back to opacity values in a separate compute pass to ensure correct voxelization [S1, unofficial].
-   **HDR Storage**: If `hdrVoxels` is false, `averageConflictingValues` is enabled to handle overlapping fragments, which may affect precision [S1, unofficial].

## Operating characteristics
-   **Time Complexity**: The voxelization step is $O(V)$ where $V$ is the number of voxels ($N^3$). The cone tracing step is $O(P \cdot C)$ where $P$ is the number of pixels and $C$ is the cone trace length. Temporal propagation adds minimal overhead per frame.
-   **Memory Complexity**: $O(N^3)$ for the voxel textures. Anisotropic mode increases this by a factor of 6 but reduces resolution to $(N/2)^3$, resulting in a total volume of $6 \times (N/2)^3 = 0.75 N^3$, which is less than the isotropic $N^3$ if mipmaps are not considered. However, the overhead of managing 6 textures is higher [S1, unofficial].
-   **Performance**: The technique is designed for real-time performance on modern GPUs (OpenGL 4.6 required). Performance scales with voxel resolution and cone trace length.
-   **Strengths**: Real-time global illumination with temporal multi-bounce approximation. Supports anisotropic voxels for better directional accuracy.
-   **Limitations**: Requires OpenGL 4.6. Temporal propagation can introduce flickering if not properly stabilized. Anisotropic mode increases memory bandwidth usage.

## Background
Voxel Cone Tracing was introduced in the original paper "Voxel Cone Tracing" (DOI: 10.1111/j.1467-8659.2011.02063.x) [S1, unofficial]. This implementation adds temporal multi-bounce propagation to approximate infinite light bounces [S1, unofficial]. It is used in the `gidemo` OpenGL 4.6 realtime global illumination demo [S1, unofficial].
