# Voxel Cone Tracing for Ambient Occlusion

Also called: VXAO, Voxel AO, Voxel Cone AO, AO via Voxel Cone Tracing, Ambient Occlusion via Voxel Cone Tracing

## Overview
Voxel Cone Tracing for Ambient Occlusion (VXAO) is a real-time technique that approximates ambient occlusion by partitioning the surface hemisphere into a set of cones and tracing them through a voxelized scene representation to accumulate occlusion [S1, S3]. It differs from Signed Distance Field (SDF) based cone tracing [S2, unofficial] by using a voxel grid, which allows for efficient storage of complex geometry and integration into the broader Voxel Cone Tracing global illumination pipeline [S2, unofficial]. Unlike ray casting, it replaces discrete step sampling with continuous integration over conical volumes, reducing aliasing [S1].

## How it works

### Inputs and Outputs
*   **Inputs**:
    *   Surface point position $p$ and surface normal $\mathbf{n}$ [S1, S3].
    *   Voxelized scene representation (extinction coefficients) [S1, S3].
    *   Number of cones $N$ [S1, S3].
    *   Decay parameter $\lambda$ [S1, S3].
    *   Maximum tracing distance $r_{max}$ [S1, S3].
*   **Outputs**:
    *   Ambient occlusion factor $A(p)$ [S1, S3].

### Data Structures
*   **Voxel Grid**: A 3D grid storing extinction coefficients. The specific layout (e.g., sparse vs. dense, bit-packing) is inherited from the parent [Voxel Cone Tracing](1454-voxel-cone-tracing.md).
*   **Cone Parameters**: Each cone $i$ is defined by its axis direction $\mathbf{d}_i$ and opening angle $\theta_i$, derived from the hemisphere partitioning [S1, S3].

### Formulas
The ambient occlusion $A(p)$ at a surface point $p$ is defined as the visibility integral over the hemisphere $\Omega$ (above the surface) with respect to the projected solid angle [S1, S3]:

$$
A(p) = \frac{1}{\pi} \int_{\Omega} V(p,\omega) \cos\theta \, d\omega
$$

where $V(p,\omega)$ is the visibility function:
*   $V(p,\omega) = 0$ if the ray originating at $p$ in direction $\omega$ intersects the scene.
*   $V(p,\omega) = 1$ otherwise [S1, S3].

For practical applications (typically indoor scenes without open sky), visibility is limited to a distance $r_{max}$ because environment walls act as ambient diffusors [S1, S3]. Occlusion is weighted by a distance decay function $f(r)$:

$$
f(r) = \frac{1}{1 + \lambda r}
$$

where $\lambda$ controls the decay rate and $r$ is the distance [S1, S3]. The modified occlusion is defined as:

$$
\alpha' (p+r\omega) = f(r)\alpha(p+r\omega)
$$

To compute the integral efficiently, the hemisphere is partitioned into $N$ integrals, each resembling a cone $\Omega_i$:

$$
A(p) \approx \frac{1}{N} \sum_{i=1}^{N} V^c(p, \Omega_i)
$$

where $V^c(p, \Omega_i)$ is the contribution of cone $i$ [S1, S3]. The cosine term is factored out of the $V^c$ integral as a coarse approximation, which is less accurate for large or grazing cones [S1, S3]. The weighted visibility integral is obtained by accumulating occlusion information weighted by $f(r)$ [S1, S3].

### Parameters
*   **$N$**: Number of cones. Not given in the sources.
*   **$\lambda$**: Decay rate parameter. Not given in the sources.
*   **$r_{max}$**: Maximum tracing distance. Not given in the sources.

### Steps
1.  **Deferred Shading Setup**: Render world position and surface normal pixels to a G-buffer using deferred shading to avoid evaluating computation for hidden geometry [S1, S3].
2.  **Hemisphere Partitioning**: Partition the hemisphere $\Omega$ into $N$ cones $\Omega_i$ [S1, S3].
3.  **Cone Tracing**: For each cone $i$:
    a.  Trace the cone through the voxel grid starting from $p$ along axis $\mathbf{d}_i$ [S1, S3].
    b.  Accumulate occlusion information. For each step or voxel intersection, update the accumulated occlusion $\alpha$ using the decay function $f(r)$ [S1, S3].
    c.  Stop tracing when the maximum distance $r_{max}$ is reached or the cone is fully occluded [S1, S3].
4.  **Cosine Approximation**: Factor the cosine out of the cone integral. This is a coarse approximation, particularly for large or grazing cones [S1, S3].
5.  **Accumulation**: Sum the contributions of all $N$ cones [S1, S3].
6.  **Final AO Calculation**: Compute the final ambient occlusion factor $A(p)$ by averaging the cone contributions [S1, S3].

### Pseudocode

```python
def compute_voxel_cone_ao(p, n, voxel_grid, N, lambda_param, r_max):
    """
    Computes Ambient Occlusion using Voxel Cone Tracing.
    
    Args:
        p: Surface point position (vec3)
        n: Surface normal (vec3)
        voxel_grid: Voxelized scene representation
        N: Number of cones to partition the hemisphere
        lambda_param: Decay rate parameter lambda
        r_max: Maximum tracing distance
        
    Returns:
        A: Ambient occlusion factor (float)
    """
    # Partition hemisphere into N cones
    # Note: Specific partitioning algorithm (e.g., fibonacci sphere) is not detailed in sources [G]
    cones = partition_hemisphere(n, N)
    
    total_occlusion = 0.0
    
    for cone in cones:
        # Cone axis direction
        d = cone.axis
        # Cone opening angle (not used explicitly in accumulation logic in sources, 
        # but defines the cone volume for tracing) [S1]
        theta = cone.angle
        
        # Trace cone through voxel grid
        # Accumulate occlusion weighted by decay function
        accumulated_alpha = 0.0
        r = 0.0
        step_size = get_voxel_step_size(voxel_grid) # [G]
        
        while r < r_max:
            # Get voxel extinction at current position along cone
            # Note: Exact cone-voxel intersection logic is inherited from parent [Voxel Cone Tracing](1454-voxel-cone-tracing.md) [G]
            extinction = trace_cone_step(p, d, r, voxel_grid)
            
            # Apply decay function
            f_r = 1.0 / (1.0 + lambda_param * r)
            
            # Accumulate occlusion
            # Note: Sources state "accumulating the occlusion information only, accounting for the weight f(r)" [S1]
            # Assuming extinction is 0 (transparent) or 1 (opaque) or continuous
            accumulated_alpha += extinction * f_r * step_size
            
            r += step_size
            
        # Factor out cosine (coarse approximation) [S1]
        # Note: The cosine factor is typically cos(theta) for the cone axis, 
        # but sources say "factor the cosine out of the Vc integral" [S1]
        # We assume a simplified contribution based on accumulated alpha
        cone_contribution = accumulated_alpha
        
        total_occlusion += cone_contribution
        
    # Average over N cones
    A = total_occlusion / N
    
    return A
```

### Edge Cases and Pitfalls
*   **Grazing Cones**: The approximation of factoring out the cosine is coarse for large or grazing cones [S1, S3].
*   **Open Sky**: The method assumes indoor scenes or environments where walls act as ambient diffusors. For open sky scenes, the distance limit $r_{max}$ may need adjustment or the method may not be suitable [S1, S3].
*   **Precision**: Floating-point precision during cone tracing and accumulation may affect results, especially for large distances [G].

## Subtopics

### SDF Cone Tracing Ambient Occlusion
An expansion of Evans' approach substituting the ad hoc heuristic with cone tracing against the scene's SDF representation [S2, unofficial]. Cones originate at the surface shading point and are tested for intersection against the scene's SDF representation [S2, unofficial]. It approximates cone tracing by utilizing spheres of increasing radius to check for intersections; if an occluder's distance to the center of the sphere is under its radius, the surface is occluded [S2, unofficial]. Several cones are traced covering the surface hemisphere of incoming light directions to estimate ambient occlusion [S2, unofficial]. The data structure consists of a scene global SDF kept alongside individual objects' SDFs [S2, unofficial]. This method differs from VXAO by using SDFs instead of voxels [S2, unofficial].

## Operating characteristics
*   **Time Complexity**: Linear with respect to the number of cones $N$ and the number of steps per cone [S1, S3].
*   **Memory Complexity**: Depends on the voxel grid size and density [S1, S3].
*   **Performance**: Implemented in Nvidia's VXGI package [S2, unofficial]. Deferred shading is used to avoid computing for hidden geometry [S1, S3].
*   **Strengths**: Real-time performance, integration with global illumination pipeline, reduced aliasing compared to ray casting [S1, S3].
*   **Limitations**: Coarse approximation for grazing cones, limited to indoor scenes or scenes with ambient diffusors [S1, S3].
*   **When to use**: Real-time ambient occlusion in indoor scenes or scenes with complex geometry where SDFs are not available [S1][S2, unofficial][S3].
*   **When not to use**: Open sky scenes, scenes requiring high accuracy for grazing angles [S1, S3].

## Background
The method was presented by Crassin et al. in 2011 [S1, S3]. It is similar to Wright's method but uses a voxel representation instead of signed distance fields [S2, unofficial]. Nvidia implemented this technique into its VXGI (Voxel Accelerated Global Illumination) package, naming the ambient occlusion technique VXAO (Voxel Accelerated Ambient Occlusion) [S2, unofficial]. The technique is based on the concept of cone tracing for ambient occlusion, originally proposed by Evans and expanded by Wright [S2, unofficial].
