# Voxel Number Map with LUT for Translucent Rendering

Also called: VNM method, Voxel Number Map (VNM) with Look-Up-Table (LUT) for Translucent Rendering, Voxel-Number-Map technique

## Overview
This method is a real-time rendering technique for heterogeneous translucent objects containing complex internal structures, such as cavities and multiple distinct media [S1, unofficial]. It solves the problem of accurately computing subsurface scattering in concave or hollow objects, where traditional Translucent Shadow Maps (TSM) fail due to thickness calculation errors [S1, unofficial]. Unlike TSM, it handles concave shapes accurately; unlike Multi-view Depth Maps, it correctly handles objects with internal cavities and supports heterogeneous media [S1, unofficial]. It builds on [Real-time approximations](36-real-time-approximations.md) by precomputing optical thickness in a Look-Up-Table (LUT) and accessing it via a screen-space Voxel-Number-Map (VNM) [S1, unofficial].

## How it works
The method assumes that single-scattering effects are dominant, in-scattering is negligible, and internal reflection and refraction at media interfaces are sufficiently small [S1, unofficial]. It operates in two phases: precomputation and runtime [S1, unofficial].

### Inputs and Outputs
**Inputs:**
- Triangle mesh model of the translucent object [S1, unofficial].
- Surface normals for each vertex [S1, unofficial].
- Extinction coefficients ($\sigma_t$) for each medium layer [S1, unofficial].
- Light direction ($\vec{\omega}_{in}$) and irradiance impulse $I(\vec{\omega}_{in})$ [S1, unofficial].
- Relative index of refraction ($\eta$) [S1, unofficial].
- Camera view (user's view) [S1, unofficial].
- Light view (for generating VNM and Irradiance Map) [S1, unofficial].

**Outputs:**
- Final radiance $L(\vec{x}_{out}, \vec{\omega}_{out})$ for each pixel [S1, unofficial].

### Data Structures
1. **Voxel Grid:** A 3D grid discretizing the object space [S1, unofficial].
2. **Surface Voxel List:** A list of voxels from the grid that lie on the object's surface [S1, unofficial].
3. **Coordinate Mapping:** A mapping from each surface voxel ID to the $(u, v)$ texture coordinates of the original object's vertex [S1, unofficial].
4. **Look-Up-Table (LUT):** A 2D texture storing optical thickness values between surface voxels for each medium [S1, unofficial].
5. **Voxel-Number-Map (VNM):** A screen-space texture generated from the light's view, storing surface voxel numbers to fetch LUT texture coordinates [S1, unofficial].
6. **Irradiance Map:** A screen-space texture storing irradiance results computed from the light's view [S1, unofficial].

### Precomputation Steps
1. **Voxelization:** Voxelize and discretize the object structure by sampling the surface of the object into the 3D voxel grid [S1, unofficial].
2. **Surface Extraction and Numbering:** Extract all voxels that constitute the surface of the object and assign a unique integer ID to each surface voxel [S1, unofficial].
3. **Coordinate Mapping:** Map each surface voxel ID to the $(u, v)$ texture coordinates of the corresponding vertex on the original mesh [S1, unofficial].
4. **Optical Thickness Computation:** For each pair of surface voxels $(\vec{x}_i, \vec{x}_j)$, compute the optical thickness $\tau(\vec{x}_i, \vec{x}_j)$ along the path between them for each distinct medium [S1, unofficial].
5. **LUT Population:** Store the computed optical thickness values into the LUT texture, indexed by the IDs of the surface voxels [S1, unofficial].

### Runtime Steps
**First Pass (Light View):**
1. **Irradiance Computation:** From the light's view, compute the irradiance $E(\vec{x}_{in})$ for each visible surface point and store the result in the Irradiance Map [S1, unofficial].
2. **VNM Generation:** Generate the Voxel-Number-Map (VNM) from the light's view, storing the unique ID of the surface voxel visible at each screen position [S1, unofficial].

**Second Pass (User View):**
1. **Radiance Integral Setup:** For each pixel in the user's view, identify the emission point $\vec{x}_{out}$ and the view direction $\vec{\omega}_{out}$ [S1, unofficial].
2. **Subsurface Reflectance Lookup:** To compute the diffuse subsurface reflectance $R_d(\vec{x}_{in}, \vec{x}_{out})$, the method uses the VNM to fetch the texture coordinates $(u, v)$ associated with the incident surface voxel ID [S1, unofficial].
3. **LUT Sampling:** Use the fetched $(u, v)$ coordinates to sample the LUT and retrieve the optical thickness $\tau(\vec{x}_{in}, \vec{x}_{out})$ [S1, unofficial].
4. **Reflectance Calculation:** Compute $R_d(\vec{x}_{in}, \vec{x}_{out}) = e^{-\tau(\vec{x}_{in}, \vec{x}_{out})}$ [S1, unofficial].
5. **Final Radiance Calculation:** Compute the integral in Equation 1 using a 21-taps sampling filter, identical to the TSM method [S1, unofficial].

### Formulas
- **Final Radiance:** $L(\vec{x}_{out}, \vec{\omega}_{out}) = \frac{1}{\pi} \int_S F_t(\eta, \vec{\omega}_{out}) E(\vec{x}_{in}) R_d(\vec{x}_{in}, \vec{x}_{out}) d\vec{x}_{in}$ [S1, unofficial]
- **Irradiance:** $E(\vec{x}_{in}) = F_t(\eta, \vec{\omega}_{in}) |N(\vec{x}_{in}) \cdot \vec{\omega}_{in}| I(\vec{\omega}_{in})$ [S1, unofficial]
- **Optical Thickness:** $\tau(\vec{x}_{in}, \vec{x}_{out}) = \int_{\vec{x}_{in}}^{\vec{x}_{out}} \sigma_t(\vec{x}') d\vec{x}'$ [S1, unofficial]
- **Diffuse Subsurface Reflectance:** $R_d(\vec{x}_{in}, \vec{x}_{out}) = e^{-\tau(\vec{x}_{in}, \vec{x}_{out})}$ [S1, unofficial]

**Symbol Definitions:**
- $F_t$: Fresnel transmittance at the interface [S1, unofficial].
- $\eta$: Relative index of refraction [S1, unofficial].
- $N(\vec{x}_{in})$: Surface normal at the incident point [S1, unofficial].
- $\vec{\omega}_{in}$: Light direction [S1, unofficial].
- $\vec{\omega}_{out}$: View/emission direction [S1, unofficial].
- $I(\vec{\omega}_{in})$: Irradiance impulse from the light source [S1, unofficial].
- $\sigma_t(\vec{x}')$: Extinction coefficient at position $\vec{x}'$ [S1, unofficial].
- $S$: Surface area over which the integral is computed [S1, unofficial].

### Pseudocode
```python
def precompute(object_mesh, extinction_coefficients):
    # 1. Voxelize object by sampling surface
    voxel_grid = voxelize_surface(object_mesh) # [S1, unofficial]
    # 2. Extract surface voxels and assign unique IDs
    surface_voxels = extract_surface(voxel_grid) # [S1, unofficial]
    for i, voxel in enumerate(surface_voxels):
        voxel.id = i # [S1, unofficial]
    # 3. Map surface voxel IDs to (u, v) texture coordinates
    voxel_to_uv = {}
    for voxel in surface_voxels:
        voxel_to_uv[voxel.id] = get_vertex_uv(voxel.original_vertex) # [S1, unofficial]
    # 4 & 5. Compute optical thickness between pairs and populate LUT
    lut = {}
    for med_id, sigma_t in extinction_coefficients.items():
        for i, vi in enumerate(surface_voxels):
            for j, vj in enumerate(surface_voxels):
                tau = integrate_extinction(vi.pos, vj.pos, sigma_t) # [S1, unofficial]
                lut[(med_id, i, j)] = tau
    return voxel_to_uv, lut

def render_runtime(light_view, user_view, irradiance_map, vnm, lut, voxel_to_uv, extinction_coefficients):
    # First Pass: Light View
    for px in light_view.screen_space:
        if px.hit_surface:
            # Compute irradiance and store in Irradiance Map
            E = fresnel_transmittance(eta, light_view.dir) * abs(dot(px.normal, light_view.dir)) * light_impulse(light_view.dir) # [S1, unofficial]
            irradiance_map[px] = E
            # Generate VNM
            vnm[px] = px.surface_voxel.id # [S1, unofficial]
    # Second Pass: User View
    for px in user_view.screen_space:
        if px.hit_surface:
            radiance = 0.0
            # 21-taps sampling filter identical to TSM [S1, unofficial]
            for sample in sample_21_taps_filter(px):
                incident_voxel_id = sample.voxel_id
                uv = voxel_to_uv[incident_voxel_id] # [S1, unofficial]
                tau = lut[(px.medium_id, px.voxel_id, incident_voxel_id)] # [S1, unofficial]
                Rd = exp(-tau) # [S1, unofficial]
                E = irradiance_map[incident_voxel_id] # [G]
                radiance += (1.0 / pi) * fresnel_transmittance(eta, user_view.dir) * E * Rd # [S1, unofficial]
            px.color = radiance
```

### Parameters
- **Voxel Resolution:** Determines the granularity of the precomputed optical thickness [S1, unofficial].
- **Map Resolution:** Resolution of the VNM, Irradiance Map, and LUT [S1, unofficial].
- **Sampling Filter:** 21-taps filter for the radiance integral [S1, unofficial].

### Edge Cases and Pitfalls
- **Concave Shapes:** TSM fails here due to thickness calculation errors; this method handles them correctly by using precomputed optical thickness [S1, unofficial].
- **Internal Cavities:** Multi-view Depth Maps fail here; this method handles them correctly [S1, unofficial].
- **Heterogeneous Media:** The method supports different extinction coefficients for different media layers, which other methods like Multi-view Depth Maps do not [S1, unofficial].
- **Assumption Violation:** If in-scattering is significant or internal reflections/refractions are strong, the results will be inaccurate as these effects are neglected [S1, unofficial].

## Operating characteristics
- **Time Complexity:** Not given in the sources.
- **Memory Complexity:** Not given in the sources.
- **Measured Performance:**
    - Translucent cube with spherical cavity (2,020 vertices): Voxel division $25 \times 25 \times 25$, FPS 405, map resolution $1024 \times 1024$ [S1, unofficial].
    - Translucent bottle with wine (10,604 vertices): Voxel division $60 \times 60 \times 60$, FPS 238, map resolution $1024 \times 1024$ [S1, unofficial].
- **Strengths:** Real-time performance for complex heterogeneous translucent objects; handles concave shapes and internal cavities accurately; supports multiple media types [S1, unofficial].
- **Limitations:** Assumes single scattering; high memory usage for the LUT for large surface voxel counts; precomputation cost; limited to static or slowly changing geometry (precomputation must be redone if geometry changes) [S1, unofficial].
- **When to use:** Real-time rendering of heterogeneous translucent objects with cavities (e.g., plastic bottles, jellyfish, flowers) where single scattering dominates [S1, unofficial].
- **When not to use:** Objects with significant in-scattering, strong internal reflections/refractions, or dynamic geometry requiring frequent precomputation updates [S1, unofficial].

## Background
The method was introduced by Keisuke Mochida, Midori Okamoto, Hiroyuki Kubo, and Shigeo Morishima in EUROGRAPHICS 2016 [S1, unofficial]. It was implemented in C++ and DirectX11 [S1, unofficial]. It addresses the limitations of Translucent Shadow Maps (TSM) [DS03] and Multi-view Depth Maps [KHKM12] in handling concave shapes and internal cavities [S1, unofficial].
