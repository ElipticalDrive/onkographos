# One-pass Spectral Rendering Integral

Also called: Bergner Spectral Rendering, Spectral Volume Rendering Integral

## Overview
The One-pass Spectral Rendering Integral is a real-time approximation for light transport in participating media that simplifies the multiple scattering model by removing global illumination elements to facilitate ray casting with local illumination [S1, book]. It enables interactive data integration using different light sources during post-illumination by factoring the light source out of the volume rendering integral computation [S1, book]. It is distinguished from its siblings by its specific simplification of assigning a volumetric shadow ratio of 1 and considering only irradiance and radiance aligned with the viewing ray, computed via a local Phong-based model [S1, book].

## How it works
**Inputs and Outputs:**
*   **Inputs:** Light source spectral power distribution $L(\lambda)$, viewing direction $\omega$, sampling position $x$, entry point $d$ (where the light ray first enters the volume), distance $D = |x - d|$, spectral extinction coefficient $\tau(x, \lambda)$, and local material reflectance properties for the Phong model [S1, book].
*   **Outputs:** Irradiance $I_i(x, \omega, \lambda)$ at position $x$ [S1, book].

**Data Structures:**
*   Spectral extinction coefficient $\tau(x, \lambda)$: Defined per voxel and wavelength [S1, book].
*   Local material reflectance: Parameters for the Phong model (ambient, diffuse, specular coefficients) [S1, book].

**Formulas:**
The irradiance $I_i(x, \omega, \lambda)$ is computed as [S1, book]:
$$I_i(x, \omega, \lambda) = L(\lambda) \cdot \tilde{I}_i(x, \omega, \lambda, D)$$
where $\tilde{I}_i$ is the proportion of light arriving at $x$ from the entry point $d$:
$$\tilde{I}_i(x, \boldsymbol{\omega}, \boldsymbol{\lambda}) = \tilde{I}_i(x - D\boldsymbol{\omega}, \boldsymbol{\omega}, \boldsymbol{\lambda}) \cdot T(x, \boldsymbol{\omega}, \boldsymbol{\lambda}, D) + \int_0^D \tilde{I}_r(x - s\boldsymbol{\omega}, \boldsymbol{\omega}, \boldsymbol{\lambda}) \cdot T(x, \boldsymbol{\omega}, \boldsymbol{\lambda}, s) ds$$
The spectral extinction function $T$ is defined as [S1, book]:
$$T(x, \omega, \lambda, s) = \exp\left(-\int_0^s \tau(x-t\omega, \lambda) dt\right)$$
The scattered radiance term $\tilde{I}_r$ is computed using a local illumination model based on the Phong model [S1, book].

**Steps:**
1. Determine the entry point $d$ where the light ray first intersects the volume boundary for the given direction $\omega$ [S1, book].
2. Calculate the distance $D$ from the sampling position $x$ to the entry point $d$ [S1, book].
3. Evaluate the spectral extinction integral $\int_0^s \tau(x-t\omega, \lambda) dt$ for $s$ ranging from $0$ to $D$, discretized along the ray segment from $d$ to $x$ [S1, book].
4. Compute the transmission $T(x, \omega, \lambda, s)$ using the exponential of the negative extinction integral [S1, book].
5. Compute the scattered radiance $\tilde{I}_r$ at each point along the ray using the local Phong illumination model, calculating diffuse and specular contributions based on local material properties and the light direction, ignoring global shadows (shadow ratio = 1) [S1, book].
6. Evaluate the integral $\int_0^D \tilde{I}_r(x - s\omega, \omega, \lambda) \cdot T(x, \omega, \lambda, s) ds$ using numerical quadrature over the sampled points [S1, book].
7. Compute the boundary term $\tilde{I}_i(x - D\omega, \omega, \lambda) \cdot T(x, \omega, \lambda, D)$, where $\tilde{I}_i(x - D\omega, \omega, \lambda)$ represents the irradiance proportion just outside the volume, which is 1 [S1, book].
8. Sum the boundary term and the integral result to get $\tilde{I}_i(x, \omega, \lambda)$ [S1, book].
9. Multiply by the light source spectral power $L(\lambda)$ to obtain the final irradiance $I_i(x, \omega, \lambda)$ [S1, book].

**Pseudocode:**
```python
def one_pass_spectral_rendering_integral(x, omega, L_lambda, tau_function, phong_params, normal_func, num_samples):
    # x: sampling position (list of 3 floats)
    # omega: light ray direction (list of 3 floats, normalized)
    # L_lambda: light source spectral power distribution (list of floats)
    # tau_function(p, wavelengths) -> list of floats: spectral extinction coefficient
    # phong_params: dict with 'k_a', 'k_d', 'k_s', 'shininess'
    # normal_func(p) -> list of 3 floats: surface normal at p
    # num_samples: integer N for discretization
    # Returns: I_i (list of floats)

    D = 1.0 # Distance from x to entry point d, assumed known from ray-volume intersection
    d = [x[i] - D * omega[i] for i in range(3)]

    if D <= 0.0:
        return [0.0] * len(L_lambda)

    ds = D / num_samples
    num_w = len(L_lambda)

    # Precompute cumulative optical depth and transmission T(s)
    tau_optical = [0.0] * num_w
    T_s = [[0.0] * num_w for _ in range(num_samples + 1)]
    for i in range(num_samples + 1):
        s = i * ds
        p_s = [x[j] - s * omega[j] for j in range(3)]
        tau_s = tau_function(p_s, list(range(num_w)))
        if i > 0:
            for k in range(num_w):
                tau_optical[k] += tau_s[k] * ds
        for k in range(num_w):
            T_s[i][k] = exp(-tau_optical[k])

    # Compute scattered radiance I_r at each sample point using local Phong model
    I_r = [[0.0] * num_w for _ in range(num_samples + 1)]
    for i in range(num_samples + 1):
        s = i * ds
        p_s = [x[j] - s * omega[j] for j in range(3)]
        n = normal_func(p_s)
        dot_nl = dot(n, omega)
        # Diffuse term
        diffuse = [phong_params['k_d'] * (dot_nl if dot_nl > 0.0 else 0.0) * L_lambda[k] for k in range(num_w)]
        # Specular term
        reflect_dir = [omega[j] + 2.0 * (-dot_nl) * n[j] for j in range(3)]
        # [G] View direction is assumed to be -omega for local evaluation per simplification (ii)
        view_dir = [-w for w in omega]
        dot_rv = dot(reflect_dir, view_dir)
        specular = [phong_params['k_s'] * pow(dot_rv if dot_rv > 0.0 else 0.0, phong_params['shininess']) * L_lambda[k] for k in range(num_w)]
        # Ambient term
        ambient = [phong_params['k_a'] * L_lambda[k] for k in range(num_w)]
        for k in range(num_w):
            I_r[i][k] = ambient[k] + diffuse[k] + specular[k]

    # Evaluate integral term: int_0^D I_r * T ds using trapezoidal rule
    integral_term = [0.0] * num_w
    for i in range(num_samples):
        I_r_avg = [(I_r[i][k] + I_r[i+1][k]) * 0.5 for k in range(num_w)]
        T_avg = [(T_s[i][k] + T_s[i+1][k]) * 0.5 for k in range(num_w)]
        for k in range(num_w):
            integral_term[k] += I_r_avg[k] * T_avg[k] * ds

    # Boundary term: I_i(d) * T(x, omega, D)
    # I_i(d) is the proportion of light at entry, which is 1.0
    boundary_term = [1.0 * T_s[num_samples][k] for k in range(num_w)]

    # Combine
    I_i = [boundary_term[k] + integral_term[k] for k in range(num_w)]

    # Final irradiance
    return [L_lambda[k] * I_i[k] for k in range(num_w)]

def dot(a, b):
    return sum(a[i] * b[i] for i in range(len(a)))

def exp(x):
    import math
    return math.exp(x)

def pow(base, exp):
    import math
    return math.pow(base, exp)
```

**Parameters:**
*   $N$: Number of samples along the ray segment. Typical value: 64 [G].
*   Phong parameters ($k_a, k_d, k_s, shininess$): Material-specific [S1, book].

**Edge Cases and Pitfalls:**
*   **Precision:** The exponential function in the extinction term can lead to underflow for large optical depths. Use clamping or log-space arithmetic if necessary [G].
*   **Boundaries:** The entry point $d$ must be correctly identified. If the ray does not enter the volume, the result is zero [S1, book].
*   **Degenerate Input:** If $D=0$, the integral is zero [S1, book].

## Subtopics

### Spectral Precomputation
Spectral Precomputation is a variant that uses full spectral computation instead of RGB to simulate light scattering, resulting in smoother, less saturated, and more natural colors [S2]. It uses an array of 4D textures to emulate a spectral texture with $M$ spectral channels, requiring $\lceil (M+1)/4 \rceil$ textures (the +1 is for storing $I_{SM}$) [S2]. Constants must be spectral (sampled at more than three wavelengths), and incident light intensity is calculated as blackbody radiation at 5778K according to Planck's law [S2]. All textures in the array are fetched using exactly the same texture coordinates for both reading and writing [S2]. Spectral color values are converted to CIE XYZ space using standard XYZ primaries, then moved to sRGB gamut and converted to sRGB by multiplication with an XYZ→sRGB conversion matrix [S2]. The final sRGB result is stored in a single 4D texture for use in rendering [S2]. A key pitfall is that RGB precomputation values cannot be used directly as RGB color components; they must be treated as 3-sample spectra and converted via the spectral-to-RGB pipeline [S2].

## Operating characteristics
*   **Time Complexity:** Linear with respect to the number of samples along the ray $N$ and the number of wavelengths $M$ [G]. The precomputation step (if used) is offline [S2].
*   **Memory Complexity:** Depends on the volume resolution and the number of spectral channels. The spectral precomputation variant uses an array of 4D textures, which can be memory-intensive [S2].
*   **Measured Performance:** Not given in the sources.
*   **Scaling:** Scales linearly with resolution and spectral samples [G].
*   **Strengths:** Enables interactive rendering with different light sources via post-illumination; more natural colors than RGB methods [S1, book][S2].
*   **Limitations:** Simplifications (shadow ratio = 1, local illumination only) reduce accuracy for complex lighting scenarios; spectral computation is more expensive than RGB [S1, book].
*   **When to use:** Real-time applications requiring natural-looking spectral effects with local lighting [S1, book].
*   **When not to use:** Applications requiring accurate global illumination or shadowing [S1, book].

## Background
The One-pass Spectral Rendering Integral was developed by Bergner et al. [7, 8] as part of their work on spectral volume rendering [S1, book]. It is based on a simplified multiple scattering model described in Section 4.1 of their work [S1, book]. The method was designed to facilitate ray casting with local illumination and post-illumination with different light sources by removing global illumination elements from the model [S1, book].
