# PSF-based Multiple Scattering Rendering

Also called: Elek et al. (2013) Screen-Space Multiple Scattering, Elek et al. method, PSF convolution method, Path integral and spatial spreading (Elek), Point Spread Function method, Screen-Space Multiple Scattering, Screen-space reference

## Overview
PSF-based Multiple Scattering Rendering approximates volumetric light transport by convolving a vacuum-rendered image with a spatially varying Gaussian Point Spread Function (PSF) derived from the medium's optical properties [S3, unofficial]. It solves the problem of computationally expensive multiple scattering simulation by treating the medium as a blur filter, allowing for real-time performance on homogeneous media while handling directional lighting and visibility effects that simpler diffusion models miss [S3, unofficial]. Unlike diffusion approximations which assume optically dense, homogeneous media with uniform angular distribution, this method uses a path integration framework to describe spatial spreading while avoiding direct numerical simulation, supporting spatially varying materials and anisotropic sources [S2].

## How it works
The method operates in two phases: preprocessing the vacuum-rendered image into attenuated and scattered components, and applying a spatially varying Gaussian blur to the scattered component based on pixel depth [S3, unofficial].

**Inputs:**
*   $L$: Input image rendered in a vacuum (radiance per pixel).
*   $D$: Depth buffer (distance from camera to surface for each pixel).
*   $\sigma_a$: Absorption coefficient.
*   $\sigma_s$: Scattering coefficient.
*   $g$: Anisotropy factor.
*   $\sigma_t = \sigma_a + \sigma_s$: Extinction coefficient.

**Outputs:**
*   $L'$: Final image with multiple scattering effects.

**Data Structures:**
*   $L_{\text{at}}$: Image of attenuated radiance (same dimensions as $L$).
*   $L_{\text{sc}}$: Image of scattered radiance (same dimensions as $L$).
*   $W(s)$: Function returning the standard deviation of the Gaussian kernel for a given depth $s$.
*   MIP map representation for efficient filtering [S3, unofficial].

**Steps:**

1.  **Preprocessing:** Compute the attenuated and scattered radiance images using the Beer-Lambert law [S3, unofficial].
    *   Compute attenuated radiance $L_{\text{at}}$:
        $$L_{\text{at}}(\mathbf{x}) = \exp(-\sigma_t D(\mathbf{x})) \cdot L(\mathbf{x})$$
        where $D(\mathbf{x})$ is the depth at pixel $\mathbf{x}$ [S3, unofficial].
    *   Compute scattered radiance $L_{\text{sc}}$:
        $$L_{\text{sc}}(\mathbf{x}) = \exp(-\sigma_a D(\mathbf{x})) \cdot (1 - \exp(-\sigma_s D(\mathbf{x}))) \cdot L(\mathbf{x})$$
        Note: $L_{\text{at}} + L_{\text{sc}} \neq L$ because absorbed radiance is lost [S3, unofficial].

2.  **PSF Derivation:** Calculate the standard deviation $W(s)$ for the Gaussian kernel based on the distance $s$ between points. For a collimated beam, the width is derived from the path integral framework [S3, unofficial]:
    $$W(s) = \sqrt{\frac{1}{2} \left( \frac{2\sigma_a}{3s} + \frac{4}{s^3\sigma_s(1-g)} \right)^{-1}}$$
    where $s$ is the distance (depth) [S3, unofficial].

3.  **Filtering:** Apply a spatially varying Gaussian blur to $L_{\text{sc}}$ [S3, unofficial]. The final image $L'$ is the sum of the direct attenuated light and the blurred scattered light:
    $$L'(\mathbf{x}) = L_{\text{at}}(\mathbf{x}) + \sum_{\mathbf{x}'} G_{\mathbf{x}'}(\|\mathbf{x}' - \mathbf{x}\|) L_{\text{sc}}(\mathbf{x}')$$
    where $G_{\mathbf{x}'}$ is a 2D Gaussian distribution centered at $\mathbf{x}'$ with standard deviation $W(D(\mathbf{x}'))$ [S3, unofficial].
    *   Implementation Note: To achieve real-time performance, this summation is implemented using MIP map filtering, where the kernel size determines the MIP level, avoiding $O(n^2)$ gathering costs [S3, unofficial].

**Pseudocode:**

```python
import math

def psf_multiple_scattering(L, D, sigma_a, sigma_s, g):
    """
    L: Input vacuum image as list of lists of RGB tuples (H, W, 3)
    D: Depth buffer as list of lists of floats (H, W)
    sigma_a: Absorption coefficient (scalar)
    sigma_s: Scattering coefficient (scalar)
    g: Anisotropy factor (scalar)
    Returns: L_prime (H, W, 3)
    """
    H, W = len(D), len(D[0])
    sigma_t = sigma_a + sigma_s

    # Step 1: Preprocessing
    L_at = [[0.0]*3 for _ in range(H)]
    L_sc = [[0.0]*3 for _ in range(H)]
    for y in range(H):
        for x in range(W):
            d = D[y][x]
            exp_at = math.exp(-sigma_t * d)
            exp_sc = math.exp(-sigma_a * d) * (1.0 - math.exp(-sigma_s * d))
            L_at[y][x] = [c * exp_at for c in L[y][x]]
            L_sc[y][x] = [c * exp_sc for c in L[y][x]]

    # Step 2: PSF width calculation
    W_map = [[0.0]*W for _ in range(H)]
    for y in range(H):
        for x in range(W):
            s = max(D[y][x], 1e-6)  # Guard against division by zero
            inv_var = (2.0 * sigma_a) / (3.0 * s) + 4.0 / (s**3 * sigma_s * (1.0 - g))
            W_map[y][x] = math.sqrt(0.5 / inv_var)

    # Step 3: Filtering & Composition
    # In practice, this uses MIP map filtering for real-time performance [S3, unofficial]
    L_sc_blurred = apply_spatial_gaussian_blur(L_sc, W_map)

    L_prime = [[0.0]*3 for _ in range(H)]
    for y in range(H):
        for x in range(W):
            L_prime[y][x] = [L_at[y][x][i] + L_sc_blurred[y][x][i] for i in range(3)]

    return L_prime

def apply_spatial_gaussian_blur(image, W_map):
    """Applies a spatially varying Gaussian blur. MIP map filtering is used in production to approximate this efficiently [G]."""
    H, W = len(image), len(image[0])
    blurred = [[0.0]*3 for _ in range(H)]
    for y in range(H):
        for x in range(W):
            w = W_map[y][x]
            kernel_radius = max(1, int(math.ceil(3.0 * w)))
            sum_r, sum_g, sum_b, weight_sum = 0.0, 0.0, 0.0, 0.0
            for dy in range(-kernel_radius, kernel_radius + 1):
                for dx in range(-kernel_radius, kernel_radius + 1):
                    ny, nx = y + dy, x + dx
                    if 0 <= ny < H and 0 <= nx < W:
                        dist = math.sqrt(dx*dx + dy*dy)
                        weight = math.exp(-0.5 * (dist / w)**2)
                        sum_r += image[ny][nx][0] * weight
                        sum_g += image[ny][nx][1] * weight
                        sum_b += image[ny][nx][2] * weight
                        weight_sum += weight
            blurred[y][x] = [sum_r/weight_sum, sum_g/weight_sum, sum_b/weight_sum]
    return blurred
```

**Edge Cases and Pitfalls:**
*   **Homogeneous Media Only:** The method assumes homogeneous media [S3, unofficial].
*   **Energy Conservation:** $L_{\text{at}} + L_{\text{sc}} \neq L$ [S3, unofficial].
*   **Depth Accuracy:** The PSF width $W(s)$ depends critically on depth $s$ [S3, unofficial].
*   **When to Use:** Real-time rendering of homogeneous participating media where multiple scattering is desired and performance is critical [S3, unofficial].
*   **When Not to Use:** Heterogeneous media, optically dense media requiring diffusion approximation, or scenes requiring exact energy conservation without post-processing corrections [S3, unofficial].

## Subtopics

### [Narrow beam distribution method](9069-narrow-beam-distribution-method.md)
A screen-space multiple-scattering approximation that filters vacuum-rendered images using a heuristic distribution function derived from the assumption that light remains concentrated in narrow beams. It differs from sibling methods by explicitly modeling the spatial variation of scattering moments for heterogeneous media, though it is generally too slow for real-time performance compared to simpler MIP-map based approaches.

## Operating characteristics
*   **Time Complexity:** Naive gathering is $O(n^2 m^2)$ or $O(n^2 m^4)$ depending on neighborhood size [S3, unofficial]. With MIP map filtering, performance improves significantly, achieving ~2 milliseconds for a sample image compared to 30 seconds for gathering and 15 hours for path-tracing reference [S3, unofficial].
*   **Memory Complexity:** Requires storage for $L_{\text{at}}$, $L_{\text{sc}}$, and MIP map representations for filtering [S3, unofficial].
*   **Strengths:** Handles spatially varying general materials and highly directional effects; accounts for anisotropic sources and visibility effects; much faster than Monte Carlo or finite element techniques [S1].
*   **Limitations:** Restricted to homogeneous media; assumes spatial spreading can be modeled by a Gaussian PSF; not suitable for optically thin or highly heterogeneous media without extension [S1][S3, unofficial].
*   **When to Use:** Real-time rendering of homogeneous participating media where multiple scattering is desired and performance is critical [S3, unofficial].
*   **When Not to Use:** Heterogeneous media, optically dense media requiring diffusion approximation, or scenes requiring exact energy conservation without post-processing corrections [S3, unofficial].

## Background
The method was introduced by Elek et al. in 2013 as a screen-space multiple-scattering approximation [S1][S3, unofficial]. It builds on the mathematical path integration framework introduced by Tesfa [Tes87] and Perez et al. [PAS03] to describe multiple scattering effects in terms of spatial and angular blurring [S2]. The specific formula for the standard deviation of the Gaussian spatial-spreading distribution for a collimated beam was derived by Premože et al. [2004] [S3, unofficial]. The method was developed to address the computational expense of volumetric Monte Carlo and finite element techniques, which can take hours to days to solve [S1].
