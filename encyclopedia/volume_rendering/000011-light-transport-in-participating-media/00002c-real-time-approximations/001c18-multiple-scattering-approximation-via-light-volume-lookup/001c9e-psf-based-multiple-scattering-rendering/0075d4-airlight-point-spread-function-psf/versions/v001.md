# Airlight Point Spread Function (PSF)

Also called: Airlight PSF, PSF for Airlight

## Overview
The Airlight Point Spread Function (PSF) models the angular distribution of light scattered by a participating medium, treating the medium as a blur kernel that modifies incident radiance. It solves the problem of efficiently approximating multiple scattering effects in real-time rendering by decoupling the geometric scattering profile from the medium's attenuation properties. Unlike direct numerical integration of the radiative transfer equation, this method relies on a normalized angular function that can be precomputed or factored, enabling interactive parameter changes without expensive recomputation.

## How it works
**Inputs and Outputs:**
*   **Inputs:** Source intensity $I_0$, source-to-viewer distance $D_{sv}$, viewer-to-point distance $D_{vp}$, scattering coefficient $\beta$, and scattering angle $\gamma$.
*   **Output:** The normalized PSF value $\text{PSF}(\gamma)$, which represents the relative radiance contribution of scattered light at angle $\gamma$.

**Data Structures:**
The PSF is typically stored as a 1D lookup table or analytical function mapping the angle $\gamma \in [0, \pi]$ to a scalar value. The table resolution depends on the desired angular accuracy.

**Method Steps:**
1.  **Calculate Radiance:** Compute the raw radiance $L(\gamma, D_{sv}, D_{vp}, \beta)$ resulting from single scattering events for the given geometry and medium parameters.
2.  **Normalize:** Apply the normalization factor to account for source intensity and distance attenuation. The PSF is defined as:
    $$ \text{PSF}(\gamma)_{D_{sv}, D_{vp}, \beta} = \frac{D_{sv}^2 L(\gamma, D_{sv}, D_{vp}, \beta)}{I_0} \quad [S1] $$
    This normalization removes the dependency on $I_0$ and $D_{sv}^2$, isolating the angular scattering profile.
3.  **Set Integrating Distance:** For surface shading applications, set the viewer-to-point distance $D_{vp}$ to infinity ($\infty$). This assumes the viewer is far enough that the integrating distance does not significantly affect the angular distribution of scattered light reaching the surface. [S1]
4.  **Convolution:** Apply the computed PSF as a convolution kernel to the incident radiance field to approximate the airlight contribution.

**Parameters:**
*   $D_{vp}$: Generally set to $\infty$ for surface shading. [S1]
*   $\beta$: Scattering coefficient. Note that while the PSF definition includes $\beta$, empirical factorization allows $\beta$ to be handled separately (see Subtopics).

**Edge Cases and Pitfalls:**
*   **Precision:** The normalization by $I_0$ requires careful handling of very small or zero source intensities to avoid division by zero.
*   **Boundary Conditions:** The assumption $D_{vp} = \infty$ may introduce errors in close-up views or when the viewer is inside the medium. [S1]

**Pseudocode:**
```python
def compute_airsight_psf(gamma, D_sv, beta, I_0, L_raw):
    """
    Computes the normalized Airlight PSF for a given angle.
    
    Args:
        gamma (float): Scattering angle in radians.
        D_sv (float): Source-to-viewer distance.
        beta (float): Scattering coefficient.
        I_0 (float): Source intensity.
        L_raw (float): Raw radiance computed from single scattering model.
        
    Returns:
        float: Normalized PSF value.
    """
    if I_0 == 0:
        return 0.0
    
    # Normalization factor as defined in [S1]
    # Note: D_vp is assumed to be infinity for surface shading
    psf = (D_sv ** 2 * L_raw) / I_0
    return psf
```

## Subtopics

### [Empirical PSF Factorization](23358-empirical-psf-factorization.md)
Decomposes the PSF into an angular component (NPSF) and an amplitude component dependent on optical thickness. This allows precomputing the angular convolution and changing medium parameters (density, extinction) interactively without recomputing convolutions. Choose this when real-time parameter tweaking is required.

## Operating characteristics
*   **Time Complexity:** $O(1)$ per pixel for PSF evaluation if stored as a lookup table or analytical function. Convolution cost depends on the kernel size.
*   **Memory Complexity:** $O(N)$ where $N$ is the number of angular samples in the PSF lookup table.
*   **Strengths:** Efficient real-time approximation; decouples geometry from medium properties via factorization.
*   **Limitations:** Approximation based on single scattering model; accuracy degrades in highly scattering media or complex geometries where multiple scattering dominates beyond the PSF approximation.
*   **When to Use:** Real-time rendering of volumetric effects like fog, haze, or smoke where performance is critical.
*   **When Not to Use:** Offline rendering requiring high physical accuracy or scenes with extreme density variations where the single-scattering assumption breaks down.

## Background
The Airlight PSF was introduced in the context of real-time single scattering models for participating media. It provides a practical way to approximate the visual impact of light scattering in the atmosphere or volumetric fog without solving the full radiative transfer equation. The method is rooted in the observation that the angular distribution of scattered light can be normalized and reused across different scene configurations.
