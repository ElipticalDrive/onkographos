# Airlight Point Spread Function (PSF)

Also called: Airlight PSF, PSF for Airlight

## Overview
The Airlight Point Spread Function (PSF) models the angular distribution of scattered light in a participating medium, treating the medium as a blur kernel that modifies incident radiance [S1]. It approximates multiple scattering effects in real-time rendering by normalizing radiance into a function of the scattering angle $\gamma$, avoiding costly direct numerical simulation of the radiative transfer equation [S1]. This method builds on [PSF-based Multiple Scattering Rendering](1297-psf-based-multiple-scattering-rendering.md) and differs from [Narrow beam distribution method](9069-narrow-beam-distribution-method.md) and [PSF Modeling](21315-psf-modeling.md) by explicitly normalizing radiance by source intensity and distance to isolate the angular scattering profile [S1].

## How it works
**Inputs and Outputs:**
*   **Inputs:** Source intensity $I_0$, source-to-viewer distance $D_{sv}$, viewer-to-point distance $D_{vp}$, scattering coefficient $\beta$, scattering angle $\gamma$, and raw radiance $L(\gamma, D_{sv}, D_{vp}, \beta)$ [S1].
*   **Output:** Normalized PSF value $\text{PSF}(\gamma)_{D_{sv}, D_{vp}, \beta}$ [S1].

**Data Structures:**
Not given in the sources.

**Method Steps:**
1.  **Calculate Radiance:** Compute the raw radiance $L(\gamma, D_{sv}, D_{vp}, \beta)$ for the given geometry and medium parameters [S1].
2.  **Normalize:** Apply the normalization factor to account for source intensity and distance attenuation, yielding the PSF [S1]:
    $$ \text{PSF}(\gamma)_{D_{sv}, D_{vp}, \beta} = \frac{D_{sv}^2 L(\gamma, D_{sv}, D_{vp}, \beta)}{I_0} $$
3.  **Set Integrating Distance:** For surface shading applications, set the viewer-to-point distance $D_{vp}$ to infinity ($\infty$) [S1].

**Parameters:**
*   $D_{vp}$: Generally set to $\infty$ for surface shading applications [S1].
*   $\beta$: Scattering coefficient of the medium [S1].

**Pseudocode:**
```python
def compute_airlight_psf(gamma, D_sv, D_vp, beta, I_0, L):
    """
    Computes the normalized Airlight PSF for a given angle.
    
    Args:
        gamma (float): Scattering angle in radians.
        D_sv (float): Source-to-viewer distance.
        D_vp (float): Viewer-to-point distance.
        beta (float): Scattering coefficient.
        I_0 (float): Source intensity.
        L (float): Raw radiance L(gamma, D_sv, D_vp, beta).
        
    Returns:
        float: Normalized PSF value.
    """
    if I_0 == 0:
        return 0.0
    # Normalization factor as defined in [S1]
    psf = (D_sv ** 2 * L) / I_0
    return psf
```

## Subtopics

### [Empirical PSF Factorization](23358-empirical-psf-factorization.md)
Decomposes the PSF into a purely angular component (NPSF) and an amplitude component dependent on optical thickness. This separation allows the angular convolution to be precomputed once, enabling interactive changes to medium parameters without recomputing expensive convolutions. Choose this variant when real-time parameter tweaking is required.

## Background
The Airlight PSF was introduced in the context of real-time single scattering models for participating media [S1]. It provides a practical way to approximate the visual impact of light scattering in the atmosphere or volumetric fog without solving the full radiative transfer equation [S1]. The method is rooted in the observation that the angular distribution of scattered light can be normalized and reused across different scene configurations [S1].
