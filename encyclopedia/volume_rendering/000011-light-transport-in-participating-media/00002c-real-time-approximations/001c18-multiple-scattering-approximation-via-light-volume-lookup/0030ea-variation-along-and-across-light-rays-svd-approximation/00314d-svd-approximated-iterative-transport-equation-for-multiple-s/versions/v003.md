# SVD-Approximated Iterative Transport Equation for Multiple Scattering

Also called: Interactive Multiple Scattering with Separable Phase Function, Interactive Rendering of Multiple Scattering in Participating Media Using Separable Phase Function, SVD Factorization for Transport Equation, SVD-based phase function approximation, Separable phase function rendering

## Overview
This method enables interactive rendering of multiple scattering in non-homogeneous participating media by approximating the scattering phase function using Singular Value Decomposition (SVD) [S1, unofficial]. It solves the discrete transport equation iteratively on GPU hardware, replacing expensive angular integrals with efficient texture lookups [S1, unofficial]. Unlike particle-based methods that require path recalculation upon movement, this grid-based approach allows for dynamic scene rendering without recomputing scattering paths [S1, unofficial].

## How it works

### Inputs and Outputs
**Inputs:**
*   **Density Texture:** A 3D texture storing the density values $\rho(x)$ at each point in the volume [S1, unofficial].
*   **Emission Density:** $L_e(x, \omega_0)$, the emitted radiance at position $x$ and direction $\omega_0$ [S1, unofficial].
*   **Phase Function Parameters:** The anisotropy factor $g$ for the Henyey-Greenstein phase function [S1, unofficial].
*   **Precomputed Textures:**
    *   **Incident-Direction Texture:** 2D texture storing $\xi_k u_k(\omega_0)$ [S1, unofficial].
    *   **Outgoing-Direction Texture:** 2D texture storing $\xi_k v_k(\omega_i)$ [S1, unofficial].
*   **Initial Radiance:** $L_0(x, \omega_0)$, typically from single scattering or the previous frame's solution [S1, unofficial].

**Outputs:**
*   **Radiance Texture:** A 3D texture storing the converged radiance $L(x, \omega_0)$ for all positions and directions [S1, unofficial].

### Data Structures
The method relies on specific texture layouts to facilitate GPU-based iteration [S1, unofficial]:

1.  **Incident-Direction Texture:** A 2D texture indexed by column $k \in \{1, \dots, N\}$ (SVD term index) and row $i \in \{1, \dots, D\}$ (direction index) [S1, unofficial]. It stores values $\xi_k u_k(\omega_0)$ [S1, unofficial].
2.  **Outgoing-Direction Texture:** A 2D texture indexed by column $k \in \{1, \dots, N\}$ and row $i \in \{1, \dots, D\}$ [S1, unofficial]. It stores values $\xi_k v_k(\omega_i)$ [S1, unofficial].
3.  **Radiance Texture:** A flat 3D texture storing $L_n(x, \omega_d)$ for the current iteration $n$ [S1, unofficial].
4.  **Temporary Outgoing Texture:** A flat 3D texture used to accumulate $\sum_{d=1}^{D} L_{n+1}(x, \omega_d) \xi_k v_k(\omega_d)$ for each $k$ during the direction loop [S1, unofficial].

### Formulas
The differential transport equation for radiance $L$ is [S1, unofficial]:

$$
\frac{dL(x, \omega_0)}{dx} = \kappa_a(x)L_e(x, \omega_0) - \kappa_a(x)L(x, \omega_0) - \kappa_s(x)L(x, \omega_0) + \frac{\kappa_s(x)}{4\pi} \int_{\Omega} L(x, \omega_i)p(\omega_0, \omega_i)d\sigma_{\omega_i}
$$

Where $\kappa_a(x)$ is the absorption coefficient, $\kappa_s(x)$ is the scattering coefficient, $\kappa_t(x) = \kappa_a(x) + \kappa_s(x)$ is the extinction coefficient, $L_e(x, \omega_0)$ is the emission density, and $p(\omega_0, \omega_i)$ is the phase function [S1, unofficial].

The Henyey-Greenstein (HG) phase function is defined as [S1, unofficial]:

$$
p(\theta) = \frac{1}{4\pi} \frac{1-g^2}{(1+g^2-2g\cos\theta)^{3/2}}
$$

Where $g \in (-1, 1)$ is the asymmetry parameter and $\theta$ is the angle between incident direction $\omega_i$ and outgoing direction $\omega_0$ [S1, unofficial].

The SVD approximation of the phase function is [S1, unofficial]:

$$
p(\omega_0, \omega_i) \approx \sum_{k=1}^{N} \xi_k u_k(\omega_0) v_k(\omega_i)
$$

Where $N$ is the number of retained terms, $\xi_k$ are the singular values, and $u_k, v_k$ are the left and right singular vectors, respectively [S1, unofficial].

The discrete transport equation, solved iteratively, is [S1, unofficial]:

$$
L_{n+1}(x+dx, \omega_0) \approx L_n(x, \omega_0) + \kappa_a(x)L_e(x, \omega_0)dx - \kappa_t(x)L_n(x, \omega_0)dx + \frac{\kappa_s(x)}{4\pi D} \sum_{d=1}^{D} L_n(x, \omega_d) p(\omega_0, \omega_d)dx
$$

Substituting the SVD approximation into the in-scattering term transforms the equation to [S1, unofficial]:

$$
L_{n+1}(x+dx, \omega_0) \approx L_n(x, \omega_0) + \kappa_a(x)L_e(x, \omega_0)dx - \kappa_t(x)L_n(x, \omega_0)dx + \frac{\kappa_s(x)}{4\pi} \sum_{k=1}^{N} \xi_k u_k(\omega_0) \left[ \sum_{d=1}^{D} L_n(x, \omega_d) \xi_k v_k(\omega_d) \right] dx
$$

### Parameters
*   **$N$ (SVD Terms):** Number of terms in the SVD approximation. Typical values are 8 or 24 [S1, unofficial]. For $g=0.5$, 24 terms yield approximately 10% RMSE [S1, unofficial]. Higher $g$ requires more terms [S1, unofficial].
*   **$D$ (Directions):** Number of discrete directions used to discretize the angular domain. Typical values are 128 or 256 [S1, unofficial].
*   **$g$ (Anisotropy):** The asymmetry factor of the HG phase function. Typical value is 0.5 [S1, unofficial].
*   **Albedo:** Single-scattering albedo $\kappa_s / \kappa_t$. Typical value is 0.9 [S1, unofficial].
*   **$dx$:** Step size along the ray [S1, unofficial].

### Pseudocode
The following pseudocode describes the logic within the fragment program for a single direction $d$ and the accumulation logic [S1, unofficial].

```python
# Constants
N = 24  # Number of SVD terms
D = 128 # Number of directions
dx = 1.0 # Step size (normalized)

# Textures (accessed via GPU texture sampling)
# IncidentTexture[k, dir_idx] -> stores xi_k * u_k(w_0)
# OutgoingTexture[k, dir_idx] -> stores xi_k * v_k(w_i)
# DensityTexture[x, y, z] -> stores density rho(x)
# RadianceTexture[x, y, z, dir_idx] -> stores L_n(x, w_d)
# TempOutgoingTexture[x, y, z, k] -> stores sum_d L_{n+1}(x, w_d) * xi_k * v_k(w_d)

def fragment_program(current_direction_index d, current_iteration n):
    w_d = get_direction_from_index(d)
    
    # Retrieve physical coefficients from Density Texture
    rho = sample_3d_texture(DensityTexture, current_position)
    kappa_a = rho * absorption_coefficient_constant # [G]
    kappa_s = rho * scattering_coefficient_constant # [G]
    kappa_t = kappa_a + kappa_s
    
    # Retrieve emission
    L_e = sample_emission(current_position, w_d)
    
    # Retrieve previous radiance L_n(x, w_d)
    L_n_wd = sample_radiance(RadianceTexture, current_position, w_d)
    
    # Calculate in-scattering sum using precomputed Outgoing Texture from iteration n
    in_scattering_sum = 0.0
    for k in range(1, N + 1):
        u_coeff = sample_2d_texture(IncidentTexture, k, get_direction_index(w_d))
        outgoing_sum = sample_3d_texture(OutgoingTexture, current_position, k)
        in_scattering_sum += u_coeff * outgoing_sum
        
    # Update Radiance
    L_n_plus_1_wd = L_n_wd + kappa_a * L_e * dx - kappa_t * L_n_wd * dx + (kappa_s / (4.0 * 3.14159265)) * in_scattering_sum * dx
    
    # Write L_{n+1}(x, w_d) to Radiance Texture
    write_radiance(RadianceTexture, current_position, w_d, L_n_plus_1_wd)
    
    # Accumulate for the NEXT iteration's Outgoing Texture
    for k in range(1, N + 1):
        v_coeff = sample_2d_texture(OutgoingTexture, k, get_direction_index(w_d))
        contribution = L_n_plus_1_wd * v_coeff
        add_to_texture(TempOutgoingTexture, current_position, k, contribution)

def render_iteration(n):
    clear_texture(TempOutgoingTexture)
    for d in range(1, D + 1):
        fragment_program(d, n)
    swap_textures(OutgoingTexture, TempOutgoingTexture)
```

### Edge Cases and Pitfalls
*   **Approximation Error:** The SVD approximation generally yields smaller reconstructed values than the original phase function, leading to darker rendered images, especially in thick parts of the medium [S1, unofficial].
*   **Convergence in Dynamic Scenes:** For highly dynamic scenes, the transport equation may not converge before the scene changes, causing errors to accumulate [S1, unofficial].
*   **Precision:** The method relies on flat 3D textures. Precision issues may arise from texture sampling interpolation if not handled carefully [G].
*   **Boundary Conditions:** The method assumes a volume grid. Boundary conditions for the volume must be defined, typically as zero radiance outside the volume [G].

## Operating characteristics

**Time Complexity:**
*   Per iteration: $O(D \cdot N \cdot V)$, where $V$ is the number of voxels [G].
*   The SVD approximation reduces the complexity of the in-scattering integral from $O(D^2)$ to $O(D \cdot N)$ per voxel per iteration, assuming $N \ll D$ [G].

**Memory Complexity:**
*   $O(V \cdot D)$ for the Radiance Texture [S1, unofficial].
*   $O(V \cdot N)$ for the Outgoing and Temporary Outgoing Textures [S1, unofficial].
*   $O(N \cdot D)$ for the Incident and Outgoing Direction Textures (negligible compared to volume textures) [S1, unofficial].

**Measured Performance:**
*   On an NV7800GT graphics card with 64x64x64 volume resolution and $D=128$, the scene is simulated at 2fps [S1, unofficial].
*   With $D=256$, 1.5fps is achieved [S1, unofficial].
*   Compared to the unfactorized model (no SVD), this method achieves a rendering speed of 1.5fps vs 0.2fps on the same hardware (NV7800GT, 64x64x64 resolution, D=256) [S1, unofficial].

**Strengths and Limitations:**
*   **Strengths:** Interactive rendering rates; handles dynamic scenes; little constraints on lighting conditions compared to other near real-time algorithms like Harris (2001) and Sloan (2002) [S1, unofficial].
*   **Limitations:** Approximation error leads to darker images; convergence issues in highly dynamic scenes; accuracy depends on $N$ and $g$ [S1, unofficial].

**When to Use:**
*   Use for interactive rendering of multiple scattering in participating media where dynamic scenes are required and high accuracy is not critical [S1, unofficial].
*   Avoid for highly dynamic scenes where convergence cannot be achieved, or when precise physical accuracy of the phase function is required [S1, unofficial].

## Background

**Origin:**
The method was proposed by Gong Z., Ren Z., Wang Z., and Peng Q. in 2007 [S1, unofficial]. It is based on the application of Singular Value Decomposition (SVD) to the scattering phase function in the transport equation [S1, unofficial].

**History and Development:**
Separable decomposition techniques were introduced by Kautz (1999) for BRDF rendering [S1, unofficial]. Wang (2004) and Liu (2004) applied SVD to glossy BRDFs in PRT [S1, unofficial]. Wang (2005) introduced SVD to the approximation of BSSRDFs by separating the Henyey-Greenstein phase function [S1, unofficial]. This method extends these ideas to interactive multiple scattering in participating media [S1, unofficial].

**Usage:**
Implemented in a Direct3D/HLSL environment [S1, unofficial].
