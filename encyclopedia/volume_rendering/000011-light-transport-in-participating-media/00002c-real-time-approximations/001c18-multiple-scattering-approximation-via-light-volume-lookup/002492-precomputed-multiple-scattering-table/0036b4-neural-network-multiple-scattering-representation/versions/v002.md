# Neural Network Multiple Scattering Representation

Also called: Neural Network Representation of Multiple Scattering, Multiple Scattering Neural Network Approximation, Neural network model for multiple scattering, Compact Representation for Multiple Scattering using Neural Networks

## Overview
This method encodes multiple scattering effects in participating media using a trained neural network, replacing large precomputed lookup tables with a compact model [S1, S3]. It solves the high storage cost of explicit tables (which can exceed 50 GB) by treating the multiple scattering response as a regression problem to learn the function over the entire parameter space [S3]. It sets itself apart from table-based approaches like [Precomputed Multiple Scattering Table](3324-precomputed-multiple-scattering-table.md) by storing the entire parameter space in kilobytes rather than megabytes, and from diffusion-based methods by handling arbitrary geometry and phase functions without assuming isotropic response or flat surfaces [S1, S3].

## How it works
**Inputs and Outputs:**
*   **Inputs:** Material parameters (scattering albedo $\alpha$, anisotropy $g$), spatial position $r(\rho, z)$, and outgoing direction $(\theta, \phi)$.
*   **Outputs:** Radiance $\Phi$ (RGB channels).

**Data Structures:**
The method uses a feed-forward neural network. Two variants are cited regarding structure:
1.  **Compact Model (S1):** Two fully connected hidden layers with 20 nodes each. Input layer has 4 dimensions $(\rho, z, \theta, \phi)$. Output layer has 3 dimensions (RGB). Activation: $\tanh$. Size: 6490 bytes (1623 floats) [S1].
2.  **General Parameter Space Model (S3):** Two fully connected hidden layers with 50 nodes each. Input layer has 6 dimensions $(\rho, z, \theta, \phi, \alpha, g)$. Output layer has 1 dimension (intensity, later expanded to RGB). Activation: $\tanh$. Size: 11.8 KB for multiple scattering, 11.8 KB for double scattering [S3].

**Precomputation and Training Steps:**
1.  **Precompute Reference Data:** Compute multiple scattering effects assuming a light source with a Dirac delta in position and direction in an infinite homogeneous participating medium [S1, S3].
2.  **Parametrization:** Use cylindrical coordinates for position $r(\rho, z)$ and spherical coordinates for direction $(\theta, \phi)$ [S1, S3]. Normalize all spatial dimensions by the material mean-free path $l$ (where $1/l = \sigma_t = \sigma_s + \sigma_a$) [S3].
3.  **Sampling:** Sample the homogeneous media space with varying anisotropy $g$ and scattering albedo $\alpha$ [S3].
    *   $g \in \{0.0, 0.1, \dots, 0.99\}$
    *   $\alpha \in \{0.01, 0.1, \dots, 0.995\}$
    *   Total 156 materials [S3].
4.  **Data Collection:** Shoot photons (e.g., 500 million per material) and accumulate contributions in a table [S3]. For double scattering, store only the first two scattering events [S3].
5.  **Preprocessing:** Apply logarithm operator to radiance for training: $\Phi' = \log(\Phi + 1)$ [S3].
6.  **Normalization:** Normalize input parameters into $[0, 1]$ (or $[-1.0, 1.0]^4$ for the 4D variant) and shuffle them [S1, S3].
7.  **Training:** Train the neural network $\Phi_N$ to minimize the L2 error:
    $$ E = \sum_i ||r_i - \Phi_N(\rho, z, \theta, \phi, \alpha, g, w)||^2 $$
    where $r_i$ is the target radiance, $\Phi_N$ is the network output, and $w$ are weights and biases [S1, S3].
    *   **Optimizer:** ADAM [S1, S3].
    *   **Learning Rate:** 0.01 (multiple scattering), 0.001 (double scattering) [S1, S3].
    *   **Batch Size:** 30K (multiple scattering), 4K (double scattering) [S3].
    *   **Epochs/Iterations:** 64 epochs (9513 batches) for multiple scattering [S3]; 10,000 iterations for the compact model [S1]; 1024 epochs for double scattering [S3].
8.  **Reconstruction:** At runtime, apply exponential operator to reconstruct radiance: $\hat{\Phi} = \exp(\hat{\Phi}_N) - 1$, where $\hat{\Phi}_N$ is the network output [S3].

**Pseudocode:**

```python
import math
import numpy as np

def preprocess_radiance(radiance):
    """Apply log transform to radiance for training stability."""
    return np.log(radiance + 1.0)

def postprocess_radiance(network_output):
    """Apply exp transform to reconstruct radiance from network output."""
    return np.exp(network_output) - 1.0

def normalize_inputs(inputs, min_val=0.0, max_val=1.0):
    """
    Normalize input parameters to [0, 1].
    Inputs: array of shape (N, 6) for general model or (N, 4) for compact model.
    """
    # Assuming inputs are already scaled by mean-free path for spatial coords
    # and within valid physical ranges for alpha/g
    return (inputs - min_val) / (max_val - min_val)

def neural_network_forward(x, weights, biases):
    """
    Forward pass for a 2-hidden-layer MLP with tanh activation.
    x: input vector
    weights: list of [W1, W2, W3]
    biases: list of [b1, b2, b3]
    """
    # Hidden Layer 1
    h1 = np.tanh(np.dot(x, weights[0]) + biases[0])
    # Hidden Layer 2
    h2 = np.tanh(np.dot(h1, weights[1]) + biases[1])
    # Output Layer
    output = np.dot(h2, weights[2]) + biases[2]
    return output

def train_network(data_X, data_Y, lr=0.01, epochs=64, batch_size=30000):
    """
    Train the neural network using ADAM optimizer and L2 loss.
    data_X: normalized input parameters (N, 6)
    data_Y: preprocessed radiance (N, 1)
    """

        shuffled_X = data_X[indices]
        shuffled_Y = data_Y[indices]

            # Forward pass

                predictions.append(pred)
            predictions = np.array(predictions)
            
            # Compute L2 Loss

def render_multiple_scattering(pos_rho, pos_z, dir_theta, dir_phi, alpha, g, weights, biases):
    """
    Render multiple scattering for a specific point and direction.
    """
    # 1. Normalize inputs [S3]
    inputs = np.array([[pos_rho, pos_z, dir_theta, dir_phi, alpha, g]])
    inputs_norm = normalize_inputs(inputs)
    
    # 2. Forward pass

    radiance = postprocess_radiance(output)
```

**Edge Cases and Pitfalls:**
*   **Bias in Combined Networks:** Representing double and multiple scattering in a single network introduces bias because double scattering has higher frequency content. They must be trained separately [S3].
*   **Infinite Medium Assumption:** The precomputation assumes an infinite participating medium. This avoids handling scene shape but may not account for boundary effects directly in the table [S3].
*   **Precision:** The log/exp transformation is critical for handling the exponential falloff of radiance and ensuring well-distributed values for training [S1, S3].

## Subtopics

### [Neural Network Model for Participating Media Scattering](15850-neural-network-model-for-participating-media-scattering.md)
A method for interactive simulation of scattering effects in participating media that uses a neural network to evaluate multiple and double scattering, combined with a single scattering approximation. It sets itself apart from table-based approaches like [Neural Network Multiple Scattering Representation](7796-neural-network-multiple-scattering-representation.md) by storing the entire parameter space in kilobytes rather than megabytes, and from Virtual Ray Lights by avoiding the artifact-prone need for massive light counts.

### Double Scattering Neural Network
A separate neural network trained to express double scattering response, which has higher frequency than multiple scattering, to avoid bias from representing them together [S3].
*   **Data Collection:** Shoot photons, store only the first two scattering events in the precomputed table [S3].
*   **Structure:** Same as multiple scattering network (two hidden layers, 50 nodes each, tanh activation) [S3].
*   **Training Parameters:** Learning rate 0.001. Mini-batches: 19521 with size 4K. Epochs: 1024 [S3].

## Operating characteristics
*   **Memory Usage:** Reduces storage from 50 GB (explicit tables) to 23.6 KB total (11.8 KB for multiple scattering, 11.8 KB for double scattering) [S3]. The compact 4D model uses only 6490 bytes (1623 floats) [S1].
*   **Rendering Time:** 50 ms per frame in typical scenes [S3].
*   **Training Time:** 45 minutes on a 2.20GHz Intel Xeon E5-2699 (44 cores) with Nvidia TITAN RTX GPU for the 6D model [S3]. 25 minutes for the compact 4D model [S1].
*   **Strengths:** Extremely compact representation; handles arbitrary geometry and phase functions (unlike diffusion methods); integrates with existing algorithms like Virtual Ray Lights (VRL) [S1, S3].
*   **Limitations:** Requires precomputation step; assumes infinite medium for precomputation; separate networks needed for double and multiple scattering [S3].
*   **When to use:** When memory is constrained and interactive rates are required for dense media where multiple scattering dominates [S3].

## Background
The method originates from the need to efficiently store precomputed multiple scattering data, which previously required tens of megabytes to gigabytes [S1, S3]. It builds on [Precomputed Multiple Scattering Table](3324-precomputed-multiple-scattering-table.md) by replacing the table with a neural network [S1]. It was demonstrated integrated with the Mitsuba Renderer and Virtual Ray Lights (VRL) [S1, S3]. The approach treats the scattering response as a regression problem, leveraging neural networks to generalize across the entire parameter space of homogeneous media [S3].
