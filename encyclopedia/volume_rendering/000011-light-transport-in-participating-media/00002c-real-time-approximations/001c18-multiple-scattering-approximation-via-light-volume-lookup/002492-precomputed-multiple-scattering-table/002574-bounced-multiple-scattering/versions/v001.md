# Bounced Multiple Scattering

Also called: Surface bounce correction

## Overview
Bounced Multiple Scattering corrects for light that has bounced off the internal surface of a material, which is missing from the infinite medium precomputed multiple scattering table [S1]. It adds diffuse indirect illumination from inside the material to surface samples, allowing the renderer to account for light that enters the volume, scatters, hits the boundary, reflects back into the volume, and scatters again toward the camera [S1]. It is a correction term applied after the primary multiple scattering lookup, distinct from single and double scattering approximations [S1].

## How it works
**Inputs and Outputs:**
*   **Inputs:** Camera sample position $\mathbf{P}_k$, viewing direction $\hat{\mathbf{o}}$, surface samples $\{s_j\}$ with stored incoming diffuse radiance $I_{s_j}$, surface BRDF $f_r$, scattering coefficient $\sigma_s$, and the precomputed multiple scattering table (used to derive $I_{s_j}$).
*   **Outputs:** The bounced radiance contribution $\text{bounced}(\mathbf{P}_k)$ for the camera sample.

**Data Structures:**
*   **Surface Samples:** A list of points $\mathbf{s}_j$ on the internal boundary. Each sample stores a scalar diffuse incoming radiance value $I_{s_j}$ [S1]. This value is computed by extracting radiance from the precomputed multiple scattering table based on the position of the surface sample relative to volume samples [S1].
*   **Surface BRDF:** A function $f_r(\hat{\mathbf{q}}_j)$ representing the diffuse reflection properties of the internal surface [S1].

**Steps:**
1.  **Compute Surface Illumination:** For each surface sample $s_j$, compute its position relative to the volume samples and extract the incoming radiance from the precomputed multiple scattering table. Store this as the diffuse value $I_{s_j}$ [S1]. This value represents light coming from inside the material and reflected by the surface [S1].
2.  **Tree Cut for Surface Samples:** For the current camera sample $\mathbf{P}_k$, perform a tree cut over the surface samples using the same refinement criterion as the volume sampling (Section 3.5.3 in [S1]). The criterion is: the solid angle sustained by the node multiplied by the phase function from $\mathbf{P}_k$ to the center of the node [S1].
3.  **Accumulate Bounced Contribution:** For each surface sample $s_j$ in the tree cut, compute the vector $\mathbf{q}_j$ from the surface sample to the camera sample:
    $$ \mathbf{q}_j = \mathbf{P}_k - \mathbf{s}_j $$
    Compute the distance $q_j = \|\mathbf{q}_j\|$ and the normalized direction $\hat{\mathbf{q}}_j = \mathbf{q}_j / q_j$ [S1].
4.  **Calculate Radiance:** Accumulate the bounced contribution using the formula:
    $$ \text{bounced}(\mathbf{P}_k) = \sigma_s \sum_{j} \frac{e^{-\sigma_s q_j} I_{s_j}}{q_j^2} f_r(\hat{\mathbf{q}}_j) p(\hat{\mathbf{o}}, \hat{\mathbf{q}}_j) $$
    where:
    *   $\sigma_s$ is the scattering coefficient [S1].
    *   $I_{s_j}$ is the stored incoming diffuse radiance at surface sample $s_j$ [S1].
    *   $f_r(\hat{\mathbf{q}}_j)$ is the surface BRDF evaluated at direction $\hat{\mathbf{q}}_j$ [S1].
    *   $p(\hat{\mathbf{o}}, \hat{\mathbf{q}}_j)$ is the phase function evaluating scattering from direction $\hat{\mathbf{q}}_j$ (incoming from surface) to direction $\hat{\mathbf{o}}$ (outgoing to camera) [S1].
    *   The term $e^{-\sigma_s q_j}$ accounts for attenuation from the surface sample to the camera sample [S1].
    *   The term $1/q_j^2$ accounts for geometric attenuation [S1].

**Pseudocode:**
```python
def compute_bounced_scattering(P_k, o_hat, surface_samples, sigma_s, f_r, phase_function):
    """
    Computes the bounced multiple scattering contribution for a camera sample.
    
    Args:
        P_k: Position of the camera sample (vector).
        o_hat: Viewing direction (normalized vector).
        surface_samples: List of objects, each having:
            - pos: Position of the surface sample (vector).
            - I_s: Stored incoming diffuse radiance (scalar).
        sigma_s: Scattering coefficient (scalar).
        f_r: Surface BRDF function, takes direction vector, returns scalar.
        phase_function: Phase function, takes (outgoing_dir, incoming_dir), returns scalar.
        
    Returns:
        bounced_radiance: Scalar radiance contribution.
    """
    bounced_radiance = 0.0
    
    # Step 2: Tree cut is handled by the caller or a pre-filtered list of relevant surface samples.
    # For implementation completeness, we assume 'relevant_samples' is the result of the tree cut.
    # The tree cut criterion: solid_angle(node) * phase_function(P_k, center_of_node) > threshold.
    # Here we iterate over the filtered samples.
    for sample in surface_samples:
        s_j = sample.pos
        I_s_j = sample.I_s
        
        # Step 3: Compute vector and distance
        q_vec = P_k - s_j
        q_dist = length(q_vec)
        
        # Avoid division by zero
        if q_dist < 1e-6:
            continue
            
        q_hat = normalize(q_vec)
        
        # Step 4: Accumulate contribution
        # Attenuation from surface to camera
        attenuation = exp(-sigma_s * q_dist)
        
        # Geometric attenuation
        geometric = 1.0 / (q_dist * q_dist)
        
        # BRDF evaluation
        brdf_val = f_r(q_hat)
        
        # Phase function evaluation
        # p(o_hat, q_hat): scattering from direction q_hat (incoming from surface) 
        # to direction o_hat (outgoing to camera)
        phase_val = phase_function(o_hat, q_hat)
        
        # Term: (exp(-sigma_s * q) * I_s) / q^2 * f_r * p
        term = (attenuation * I_s_j * geometric * brdf_val * phase_val)
        
        bounced_radiance += term
        
    # Multiply by sigma_s as per formula
    bounced_radiance *= sigma_s
    
    return bounced_radiance
```

**Parameters:**
*   $f_r$: Surface BRDF. Typical value: Diffuse reflection model (e.g., Lambertian) [S1].
*   $\sigma_s$: Scattering coefficient. Value depends on the medium [S1].
*   $I_{s_j}$: Incoming diffuse radiance. Derived from the precomputed multiple scattering table [S1].

**Edge Cases and Pitfalls:**
*   **Precision:** Division by $q_j^2$ can cause instability if $\mathbf{P}_k$ is very close to a surface sample $\mathbf{s}_j$. A small epsilon guard is required [S1, G].
*   **Boundaries:** The method assumes an internal surface. If the volume has no internal boundary (e.g., infinite medium), this term is zero [S1].
*   **Degenerate Input:** If surface samples are not properly stored with $I_{s_j}$, the contribution will be incorrect. The $I_{s_j}$ must be computed using the precomputed table relative to the volume samples [S1].

## Subtopics

### Precomputed Multiple Scattering Table
The source of $I_{s_j}$. It assumes an infinite medium and does not account for surface bounces. [Precomputed Multiple Scattering Table](3324-precomputed-multiple-scattering-table.md)

### Single Scattering
The first-order approximation. Bounced scattering is a higher-order correction. [Single Scattering](3320-single-scattering.md)

### Double Scattering
The second-order approximation. Bounced scattering captures light that has interacted with the boundary, which is not covered by double scattering in an infinite medium. [Double Scattering](3322-double-scattering.md)

## Operating characteristics
*   **Time Complexity:** Linear in the number of surface samples in the tree cut. The tree cut reduces the number of samples considered, making it efficient for large scenes [S1].
*   **Memory Complexity:** Depends on the storage of surface samples and their associated $I_{s_j}$ values. The precomputed table is stored separately [S1].
*   **Measured Performance:** Not given in the sources.
*   **Scaling:** Scales with the number of surface samples. The tree cut helps maintain performance as the number of samples increases [S1].
*   **Strengths:** Corrects for a significant missing component in infinite medium approximations, improving visual accuracy for translucent objects with internal boundaries [S1].
*   **Limitations:** Requires surface samples and a precomputed table. Adds computational cost to the rendering loop [S1].
*   **When to use:** When rendering participating media with internal boundaries (e.g., skin, wax, marble) where surface bounces are visually significant [S1].
*   **When not to use:** For infinite media without boundaries, or when performance is critical and visual accuracy of surface bounces is not required [S1].

## Background
*   **Origin:** The method is described in "Point-Based Rendering for Homogeneous Participating Media with Refractive Boundaries" by Jensen and Buhler (2017) [S1].
*   **History:** It extends the work on point-based rendering for participating media by adding a correction for internal surface reflections, which were previously ignored in infinite medium approximations [S1].
*   **Usage:** Used in real-time rendering of translucent materials, particularly in games and interactive applications where visual accuracy is important [S1].
