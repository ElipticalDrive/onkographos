# Froxel Volumetric Fog with Precomputed Lighting

Also called: Froxel Volumetric Fog, Froxel Fog, Frustum Voxel Fog

## Overview
A per-view volumetric fog rendering technique that stores optical depth and scattered light in a frustum-aligned 3D grid of voxels (froxels) to simulate light scattering in participating media [S1, S2, S3, unofficial]. It solves the problem of rendering fog that reacts to sky, local lights, and transparent materials without using a full-screen blur pass [S3, unofficial]. Unlike its sibling [Froxel Volumetric Fog with Path-Traced Shadows](2314-froxel-volumetric-fog-with-path-traced-shadows.md), which uses path tracing for shadows, this method typically uses shadow maps or atlas-based shadowing for lighting, offering a performance trade-off between shadow accuracy and speed [S2, unofficial].

## How it works
**Inputs and Outputs:**
*   **Inputs:** Camera view frustum parameters (near/far planes), scene depth buffer, light sources (directional, point, spot), shadow maps/atlas, and fog parameters (base density, height falloff, anisotropy).
*   **Outputs:** A final composited image with volumetric fog, and an updated opaque texture for refractive materials.

**Data Structures:**
1.  **Froxel Volume (Scattering):** A 3D texture storing per-voxel scattering radiance and extinction.
    *   **Format:** `RGBA16F` (R16G16B16A16_SFloat) [S2, S4, unofficial].
    *   **Layout:** `RGB` channels store in-scattered radiance; `Alpha` channel stores extinction coefficient [S3, unofficial].
    *   **Dimensions:** Varies by quality preset. Low: $80 \times 45 \times 64$; Medium: $160 \times 90 \times 64$; High: $160 \times 90 \times 128$; Ultra: $240 \times 135 \times 128$ [S3, unofficial].
    *   **Depth Slicing:** Exponential depth distribution to provide higher resolution near the camera:
        $$depth = nearDistance \times \exp\left(\frac{slice}{sliceCount} \times \log\left(\frac{farDistance}{nearDistance}\right)\right)$$
        [S3, unofficial]
2.  **Integrated Volume:** A 3D texture storing accumulated radiance and transmittance.
    *   **Layout:** `RGB` stores accumulated in-scattered radiance; `Alpha` stores remaining transmittance [S3, unofficial].
3.  **History Storage:** Two ping-ponged 3D render textures for temporal reprojection, separate for Game View and Scene View [S3, unofficial].
4.  **Frame Constants:** A constant block (`volumetric_fog_control`) appended to frame data structures (e.g., at offset 528 in `CyFrameData`), total block size 528–544 bytes depending on other controls [S1, unofficial].

**Algorithm Steps:**

1.  **Noise Bake:** Generate or load a prebaked 128×128×128 tileable 3D noise texture to drive animated density variations [S3, unofficial].
2.  **Inject Density:** Compute the base density for each froxel.
    *   Reconstruct jittered world position for each froxel.
    *   Calculate height falloff:
        $$h = worldPos.y - groundHeight$$
        $$density = baseDensity \times \exp\left(-\frac{\max(h, 0.0)}{\max(heightFalloff, 0.01)}\right)$$
        [S3, unofficial]
    *   Apply animated noise:
        $$uvw = \frac{worldPos}{noiseScale} - wind \times \frac{time}{noiseScale}$$
        $$n = \text{noiseTexture}.\text{SampleLevel}(\text{sampler}, \text{frac}(uvw), 0)$$
        [S3, unofficial]
    *   Write to the material volume: `materialVolume.rgb = scattering` (initially 0 or ambient), `materialVolume.a = density` [S3, unofficial].
3.  **Scatter Lighting:** Compute in-scattered light for each froxel.
    *   Sum contributions from: main directional light, main light shadows, point/spot lights, additional light shadows, sky ambient, and atmospheric sun tint [S3, unofficial].
    *   Use Henyey-Greenstein phase function with anisotropy $g$ (default 0.3, validated $|g| < 1$) [S2, unofficial].
    *   Clamp light contributions to prevent temporal instability spikes from nearby point/spot lights [S3, unofficial].
    *   Set froxel normal to `vec3(0.0)` to prevent `normal_bias` displacement [S2, unofficial].
    *   Write to scattering volume: `FogVolume[id] = float4(lighting, density)` [S4, unofficial].
4.  **Temporal Reprojection:** Stabilize the scattering volume.
    *   Jitter each froxel sample using spatio-temporal blue noise or Interleaved Gradient Noise [S3, unofficial].
    *   Reproject current froxel center into the previous frame using the previous view-projection matrix.
    *   If the point lands inside the old volume, trilinearly sample history and blend:
        $$blended = \text{lerp}(history.rgb, current.rgb, temporalBlend)$$
        [S3, unofficial]
5.  **Spatial Filtering:** Apply a 3×3×3 Gaussian-style filter to the scattering volume.
    *   Filter only RGB (scattering); pass extinction (Alpha) unchanged to preserve depth/absorption profiles [S3, unofficial].
    *   Store history *before* filtering to prevent blur stacking [S3, unofficial].
6.  **Integrate:** March through Z for every screen-space XY cell to accumulate radiance.
    *   For each slice:
        $$opticalDepth = extinction \times sliceThickness$$
        $$sliceTransmittance = \exp(-opticalDepth)$$
        $$sliceScatter = scatter \times \frac{1 - sliceTransmittance}{extinction}$$
        [S3, unofficial]
    *   Accumulate `sliceScatter` into RGB and `sliceTransmittance` into Alpha of the integrated volume.
7.  **Composite:** Render the final fog over the scene.
    *   Sample camera depth, convert to froxel Z.
    *   Read integrated volume.
    *   Compute final color:
        $$finalColor = sceneColor \times transmittance + accumulatedScatter$$
        [S3, unofficial]
    *   Near pixels pass through unchanged.
8.  **Far Distance Handling:**
    *   Pixels beyond the froxel far distance use analytical extension.
    *   Terrain pixels estimate extinction rate from integrated transmittance.
    *   Sky pixels integrate exponential height fog toward the horizon [S3, unofficial].
9.  **Update Opaque Texture:** Copy the fogged color back into `_CameraOpaqueTexture` so refractive shaders (glass, windshields) sample the fogged world [S3, unofficial].

**Pseudocode (Compute Shader for Density and Lighting):**

```python
# FogDensity.compute
#pragma kernel CSMain
RWTexture3D<float4> FogVolume;
float fogHeight = 5.0;
float density = 0.04;

[numthreads(8, 8, 4)]
void CSMain(uint3 id : SV_DispatchThreadID)
{
    // Calculate height factor for ground-hugging fog
    float heightFactor = saturate(1.0 - id.y / fogHeight);
    float fog = density * heightFactor;
    
    // Write density to RGB (initially uniform) and alpha as extinction
    FogVolume[id] = float4(fog, fog, fog, 1.0);
}

# FogLighting.compute
#pragma kernel CSMain
RWTexture3D<float4> FogVolume;
float3 lightDirection;
float3 lightColor;

[numthreads(8, 8, 4)]
void CSMain(uint3 id : SV_DispatchThreadID)
{
    // Read density from previous step (stored in R channel in this simplified example)
    float density = FogVolume[id].r;
    
    // Simple phase function approximation (dot product with light direction)
    // In production, use Henyey-Greenstein with anisotropy g
    float scatter = saturate(dot(normalize(float3(0, 1, 0)), -lightDirection));
    
    // Calculate lighting contribution
    float3 lighting = lightColor * density * scatter;
    
    // Write lighting to RGB, keep density in Alpha (or R depending on layout)
    // Based on S4 layout: FogVolume[id] = float4(lighting, density)
    FogVolume[id] = float4(lighting, density);
}

# RaymarchFog (Fragment Shader)
float4 RaymarchFog(float3 rayOrigin, float3 rayDir)
{
    float stepSize = 0.5;
    float3 pos = rayOrigin;
    float3 color = 0.0;
    float transmittance = 1.0;
    
    // March through the volume
    for(int i = 0; i < 64; i++)
    {
        float4 fog = SAMPLE_TEXTURE3D(_FogVolume, sampler_FogVolume, pos);
        
        // Accumulate scattered light
        color += fog.rgb * transmittance;
        
        // Update transmittance based on extinction (alpha)
        transmittance *= exp(-fog.a * stepSize);
        
        // Advance position
        pos += rayDir * stepSize;
    }
    
    return float4(color, 1.0);
}
```

## Subtopics

### [Froxel Fog with Temporal Reprojection and Revealed Froxel Blur](13212-froxel-fog-with-temporal-reprojection-and-revealed-froxel-bl.md)
Improves visual quality by reducing noise in shadow factors when froxels are "revealed" (temporal reprojection fails). It combines increased sampling for revealed froxels with a targeted blur pass that only processes those specific cells, avoiding the cost of blurring converged history. It builds on [Froxel Volumetric Fog with Precomputed Lighting](2647-froxel-volumetric-fog-with-precomputed-lighting.md).

### [Volumetric Particle Injection](13347-volumetric-particle-injection.md)
Injects discrete volumetric particles (smoke, steam) as density into the froxel grid, allowing them to be lit by the same scattering pass as global fog. It solves visible seams and lighting inconsistencies from decoupled particle rendering by unifying particle density with the global fog volume, ensuring consistent light scattering and shadowing.

## Operating characteristics
*   **Time Complexity:** Depends on image resolution and number of light sources, as in-scattering is calculated per light [S5, unofficial]. The froxel approach reduces this by precomputing lighting in a grid.
*   **Memory Complexity:** Proportional to the froxel grid dimensions. For a 2560×1440 view with a 16×16×64 slice volume, memory usage is approximately 7.03 MiB [S2, unofficial].
*   **Measured Performance:** On an NVIDIA GeForce RTX 4090 at 2560×1440, the main view `FOG_SCATTERING` + `FOG_INTEGRATION` takes ~0.043 ms (forward) and ~0.045 ms (deferred) [S2, unofficial]. This is ~10× faster than the 0.5 ms target for 160×90×64 with a four-cascade sun [S2, unofficial].
*   **Strengths:** Reacts to local lights, sky, and transparent materials; avoids full-screen blur artifacts; efficient temporal reprojection.
*   **Limitations:** Limited to single scattering in basic implementations (multiple scattering requires octave approximation) [S5, unofficial]; potential banding at max_distance boundaries [S2, unofficial]; shadow map inside-solid lighting errors if not handled [S1, unofficial].
*   **When to Use:** Real-time applications requiring atmospheric fog with dynamic lighting and shadows.
*   **When Not to Use:** Offline rendering requiring full multiple scattering and global illumination accuracy [S5, unofficial].

## Background
The term "froxel" (frustum voxel) is attributed to Alex Evans and Sony ATG, described in the 'Learning from Failure' SIGGRAPH 2015 talk and noted in Real-Time Rendering blog and Call of Duty: Advanced Warfare post-processing [S3, unofficial]. The Henyey-Greenstein phase function source is L. G. Henyey and J. L. Greenstein, The Astrophysical Journal, 1941 [S3, unofficial]. This specific implementation was introduced by fesoliveira014 in Pull Request #186 for the c3d.c3l project on September 30, 2026 [S2, unofficial]. Another implementation was added to the Cyberdyne Game Engine in Pull Request #39 on September 28, 2026 [S1, unofficial]. The technique is used in commercial games like Assassin's Creed IV (using Wronski's method) [S5, unofficial] and various engine examples (C3D, Cyberdyne) [S1, S2, unofficial].
