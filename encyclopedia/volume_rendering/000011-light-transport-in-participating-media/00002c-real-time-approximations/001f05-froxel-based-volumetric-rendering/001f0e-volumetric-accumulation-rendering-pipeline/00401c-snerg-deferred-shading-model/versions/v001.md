# SNeRG Deferred Shading Model
Also called: Deferred Radiance Field Rendering
## Overview
SNeRG (Sparse Neural Radiance Fields) is a real-time volumetric rendering method that decomposes a radiance field into view-independent density, diffuse color, and view-dependent feature vectors [S1]. It solves the computational bottleneck of traditional NeRFs by reducing MLP evaluations to one per ray, using deferred shading to compute view-dependent appearance from accumulated features [S1]. It sets itself apart from siblings like [Accumulation Buffer Composite](2368-accumulation-buffer-composite.md) by explicitly separating diffuse and specular components via a lightweight decoder MLP, and from [Empirical Volume Shading with Indirect Light Approximation](4092-empirical-volume-shading-with-indirect-light-approximation.md) by using learned feature vectors rather than empirical lighting models.

## How it works
**Inputs:** Camera ray origin $\mathbf{o}$ and direction $\mathbf{d}$; pre-trained block-sparse grid representation of the scene.
**Outputs:** Final pixel color $C$.

**Data Structures:**
The scene is represented as a block-sparse grid. For any 3D location $\mathbf{x}$, the representation queries:
1.  Eight neighbors on a low-resolution 3D grid.
2.  Three projections of $\mathbf{x}$ onto axis-aligned planes, querying four neighbors on each high-resolution 2D grid [S1].
The resulting features are summed into a single feature vector $\mathbf{t}$ [S1]. This vector is split and mapped into three components: density $\sigma$, diffuse RGB color $c_d$, and a feature vector $\mathbf{f}$ [S1].

**Steps:**
1.  **Volumetric Accumulation:** For a ray, sample points $\mathbf{x}_i$ along the path. Query the grid to get $c_{d,i}$ and $\mathbf{f}_i$ for each sample. Compute weights $w_i$ using standard volume rendering alpha compositing (derived from density $\sigma_i$ and step size $\delta_i$) [S1]. Accumulate diffuse color $C_d$ and feature vector $F$:
    $$C_d = \sum_i w_i c_{d,i}$$
    $$F = \sum_i w_i \mathbf{f}_i$$
2.  **View-Dependent Decoding:** Pass the accumulated values $C_d$, $F$, and the viewing direction $\mathbf{d}$ into a small MLP $h$ to compute the view-dependent color offset [S1].
3.  **Final Color:** Sum the accumulated diffuse color and the view-dependent output:
    $$C = C_d + h(C_d, F, \mathbf{d})$$

**Edge Cases:**
-   **Unbounded Scenes:** SNeRG uses a contraction function to warp the unbounded scene domain into a finite sphere to handle nearby and far objects [S1]. The contraction function is:

## Subtopics

### [Neural Deferred Shading](20536-neural-deferred-shading.md)
Neural Deferred Shading is a decoding strategy for radiance fields that models view-dependent appearance using a lightweight shared Multi-Layer Perceptron (MLP) applied per pixel. It separates view-independent opacity from view-dependent color, allowing the network to decode final pixel color from accumulated feature vectors and ray direction without further positional encoding. This approach reduces the computational cost of high-order spherical harmonics while maintaining high-quality novel-view synthesis.

## Operating characteristics
-   **Time Complexity:** Reduces MLP evaluations to one per ray (for the decoder) plus grid queries, compared to one MLP evaluation per sample in original NeRF [S1].
-   **Memory Complexity:** Uses a block-sparse grid for real-time rendering, which is memory-efficient for unbounded scenes [S1].
-   **Performance:** Enables real-time view synthesis in unbounded scenes [S1].
-   **Strengths:** High-quality novel-view synthesis; real-time performance; handles unbounded scenes [S1].
-   **Limitations:** Requires training a large MLP and baking it into a grid [S1].

## Background
SNeRG was introduced by Hedman et al. in 2021 as part of the MERF (Memory-Efficient Radiance Fields) paper [S1]. It builds on the original NeRF work which parameterized radiance fields using an MLP [S1]. It is used for real-time view synthesis in unbounded scenes [S1].
