# Fog Volume Grid Rendering

Also called: FogMaterial volumetric fog integration, FogVolume Volumetric Rendering

## Overview
Fog Volume Grid Rendering is a technique that draws local volumetric fog entities (FogVolume) and their associated material properties (FogMaterial) into a froxel-based volumetric grid by adding their density, albedo, and emission to the froxels geometrically covered by the volume [S1, unofficial][S2]. It solves the problem of creating non-uniform, patchy fog effects (such as fog banks or layered mist) that cannot be achieved with global fog settings alone [S1, unofficial]. It differs from sibling methods like [Froxel TAA Reprojection](1920-froxel-taa-reprojection.md) by focusing on the spatial injection of local volume data rather than temporal stability, and differs from [Fog Volume Entity](16231-fog-volume-entity.md) by providing the low-level implementation details of how that entity's data is processed into the froxel grid [S1, unofficial].

## How it works
**Inputs and Outputs:**
*   **Inputs:** A list of visible, unculled FogVolume entities, each containing a shape (box, ellipsoid, cone, cylinder, or world), a FogMaterial (density, albedo, emission, noise parameters), and spatial transforms.
*   **Outputs:** A 3D froxel grid (texture) where each cell contains accumulated density, albedo, and emission values derived from all overlapping volumes.

**Data Structures:**
1.  **FogVolume Row Texture:** A 1D texture or buffer where each row represents one visible volume. The layout includes shape type, transform matrix, material properties (density, color), and noise parameters.
2.  **Fog Density Atlas:** A single 3D texture formed by stacking individual density textures (from NoiseTexture3D or ImageTexture3D) in depth. This is necessary because WebGL2 shaders cannot index a sampler array in a loop [S1, unofficial]. The atlas holds floats once a density texture does.
3.  **Froxel Grid:** The target 3D texture storing the accumulated volumetric data.

**Numbered Steps:**

1.  **Froxel Range Calculation:**
    For each visible FogVolume, determine the set of froxels it covers. This involves porting the froxel range calculation logic from the reference engine (e.g., Godot's `fog.cpp` lines 551-718) to compute the bounding box of the volume in froxel space and iterating over the intersecting cells [S1, unofficial].

2.  **Density Texture Generation:**
    For each volume, generate its local density texture:
    *   If the density is uniform, create a constant texture.
    *   If noise-based, build a `NoiseTexture3D` as a worker job. Ensure texels and seamless blending match the reference engine byte-for-byte [S1, unofficial].
    *   If image-based, decode `ImageTexture3D` sub-resources in every uncompressed format (8-bit, 16-bit, half, float, RGBA4444, RGB565, RGBE9995) using the reference unpacking logic (e.g., `Image::_get_color_at_ofs`) [S1, unofficial].
    *   For imported 3D textures, cut them into slices matching the reference layered importer (e.g., `resource_importer_layered_texture.cpp:370-386`) [S1, unofficial].
    *   Stack every generated density texture in depth into the `Fog Density Atlas` [S1, unofficial].

3.  **Volume Packing:**
    Pack each visible, unculled volume's parameters into the `FogVolume Row Texture`. This includes the index into the `Fog Density Atlas`, the shape parameters, and material properties [S1, unofficial].

4.  **Froxel Accumulation (Light Pass):**
    Execute a compute shader pass (or fragment shader pass in the light pass) to add the volumes' contributions to the froxel grid:
    *   Iterate over the froxels covered by each volume.
    *   Sample the local density texture (from the atlas) at the relative position within the volume.
    *   Apply noise modulation using parameters:
        *   `DensityNoiseOffset`: Offsets the noise value.
        *   `DensityNoiseScale`: Scales the noise value (controls patch thickness/spacing).
        *   `DensityNoiseFrequency`: Controls spatial frequency (number of patches).
        *   `DensityNoiseTimeFrequency`: Controls temporal morphing of patches.
    *   Calculate the final density contribution:
        $$ \rho_{final} = \rho_{base} \times \rho_{noise} \times GlobalDensity $$
        where $\rho_{base}$ is the global density and $\rho_{noise}$ is the sampled noise value.
    *   Add the density, albedo, and emission to the froxel's accumulated values. Handle packed-color overflow as per the reference engine (e.g., Godot's packed-colour overflow) [S1, unofficial].
    *   Apply shape-specific modifiers:
        *   **Height Falloff:** Modulate density based on vertical position.
        *   **Edge Fade:** Soften edges using `SoftEdges` factor.
        *   **Negative Density:** Carve out fog if density is negative.
        *   **Fall Off Direction:** Use `FallOffDirLati`, `FallOffDirLong`, `FallOffScale`, and `FallOffShift` to control density distribution along a specific direction.
        *   **Ramp:** Apply `RampStart`, `RampEnd`, and `RampInfluence` to fade density based on distance.

**Parameters:**
*   `Active`: On/Off.
*   `AffectsThisAreaOnly`: Boolean. False allows effect across multiple VisAreas/ClipVolumes.
*   `Color`: RGB color of the fog.
*   `DensityNoiseOffset`: Range -2 to +2.
*   `DensityNoiseScale`: Range 0 to 10. Default 1.
*   `DensityNoiseTimeFrequency`: Controls morphing speed. Keep low (e.g., 0.2) to avoid unnatural rapid morphing.
*   `DensityOffset`: Additional density control.
*   `FallOffDirLati`: Latitude direction of fall off. 90 = up.
*   `FallOffDirLong`: Longitude direction of fall off. 0 = East (Positive X).
*   `FallOffScale`: Scales density distribution along fall off direction.
*   `FallOffShift`: Shifts fog density along fall off direction.
*   `GlobalDensity`: Controls base density. Production levels typically 1-3.
*   `IgnoreVisAreas`: Boolean. Controls response to VisAreas/ClipVolumes.
*   `NearCutOff`: Distance in meters to stop rendering.
*   `RampStart`: Start distance of fog density ramp in meters.
*   `RampEnd`: End distance of fog density ramp in meters.
*   `RampInfluence`: Influence of fog density ramp.
*   `SoftEdges`: Factor to soften edges.
*   `UseGlobalFogColor`: Boolean. If true, ignores entity Color and uses global fog color.
*   `VolumeType`: 0 - Ellipsoid, 1 - Cube.
*   `WindInfluence`: Influence of global wind.
*   `DensityNoiseFrequency XYZ`: Spatial frequency of noise. High values create detailed fog.
*   `Size XYZ`: Size limits of the fog volume.

**Pseudocode:**

```python
# Pseudocode for Fog Volume Grid Rendering Accumulation Step

def accumulate_fog_volumes(froxel_grid, volumes, density_atlas):
    """
    Accumulates fog volume contributions into the froxel grid.
    
    Args:
        froxel_grid: 3D texture storing accumulated density, albedo, emission.
        volumes: List of FogVolume objects.
        density_atlas: 3D texture containing stacked density textures.
    """
    for volume in volumes:
        if not volume.active:
            continue
            
        # 1. Determine covered froxels
        covered_froxels = get_froxel_range(volume)
        
        # 2. Get density texture index from atlas
        density_tex_index = volume.density_texture_index
        local_density_texture = density_atlas
        
        # 3. Iterate over covered froxels
        for froxel in covered_froxels:
            # Calculate local position within volume
            local_pos = transform_inverse(volume.transform) * froxel.world_position
            
            # Check if local_pos is inside volume shape
            if not is_inside_volume_shape(local_pos, volume.shape_type, volume.size):
                continue
                
            # Sample base density
            base_density = sample_density_texture(local_density_texture, density_tex_index, local_pos)
            
            # Apply noise modulation
            noise_value = sample_noise(
                local_pos,
                volume.density_noise_frequency,
                volume.density_noise_offset,
                volume.density_noise_scale,
                volume.density_noise_time_frequency
            )
            
            # Calculate final density
            final_density = base_density * noise_value * volume.global_density
            
            # Apply shape-specific modifiers
            final_density = apply_height_falloff(final_density, local_pos, volume)
            final_density = apply_edge_fade(final_density, local_pos, volume.soft_edges)
            final_density = apply_fall_off_direction(final_density, local_pos, volume)
            final_density = apply_density_ramp(final_density, froxel.world_position, volume)
            
            # Handle negative density (carving)
            if final_density < 0:
                final_density = -final_density # Carve out fog
            
            # Accumulate into froxel
            froxel_grid[froxel.index].density += final_density
            froxel_grid[froxel.index].albedo += volume.color * final_density
            froxel_grid[froxel.index].emission += volume.emission * final_density

def sample_noise(pos, frequency, offset, scale, time_freq):
    """
    Samples noise for density modulation.
    """
    # Reconstruct world-space position for noise sampling
    world_pos = pos * frequency + offset
    
    # Sample 3D noise (e.g., Perlin-Worley)
    noise_val = sample_3d_noise(world_pos, time_freq)
    
    # Scale noise
    return noise_val * scale

def is_inside_volume_shape(local_pos, shape_type, size):
    """
    Checks if a point is inside the volume shape.
    """
    if shape_type == 'box':
        return all(abs(local_pos[i]) <= size[i] / 2 for i in range(3))
    elif shape_type == 'ellipsoid':
        return sum((local_pos[i] / (size[i] / 2))**2 for i in range(3)) <= 1.0
    # Add other shape checks (cone, cylinder, world)
    return False
```

**Edge Cases and Pitfalls:**
*   **Float Texel Upload:** Float texels upload raw as half float because the reference engine gives a float format no sRGB view and WebGL2 always filters a half float. An atlas crop of a half-float sheet stays half float, and a canvas read converts it to bytes [S1, unofficial].
*   **ShaderMaterial Limitation:** A fog ShaderMaterial runs no fog shader. This requires a shading-language runtime [S1, unofficial].
*   **Compressed/Integer Formats:** An Image in a block-compressed format draws nothing. An Image in an integer format draws nothing because a float sampler cannot read it [S1, unofficial].
*   **NoiseTexture3D Build Delay:** A NoiseTexture3D shows even density until its build lands [S1, unofficial].
*   **Atlas Limit:** Past 2048 stacked density slices, further textures leave the density even [S1, unofficial].
*   **sRGB Decoding:** A 3D colour slot still decodes every texture as sRGB. Godot reads a format without an sRGB view raw, so a Lum8 or grey-noise albedo draws too dark [S1, unofficial].

## Subtopics

### [Fog Volume Injection Optimization](15036-fog-volume-injection-optimization.md)
Fog Volume Injection Optimization reduces the computational cost of injecting scene fog volumes into a froxel grid by ensuring each volume is processed only by the froxels it geometrically covers, rather than having every froxel test every scene fog volume. It differs from the brute-force approach (where every froxel iterates all volumes) by using precomputed CPU-side bounds to cull irrelevant volume-froxel pairs, and differs from Godot’s per-volume dispatch by using a single GPU kernel with a culled list of ranges, avoiding the overhead of many small kernel launches.

### [Fog Volume Entity](16231-fog-volume-entity.md)
The Fog Volume Entity is a spatial entity used to define local volumetric fog density, color, and noise-based structure within a 3D level. It solves the problem of creating non-uniform, patchy fog effects (such as fog banks or layered mist) that cannot be achieved with global fog settings alone. It differs from sibling methods like [Fog Volume Grid Rendering](4350-fog-volume-grid-rendering.md) by providing a high-level, user-configurable entity interface for shaping fog via noise parameters, rather than directly manipulating the underlying froxel data structures.

### Density and Phase Function Evaluation
Execute a compute shader pass (glDispatchCompute) to evaluate fog density and material properties for every cell in the 3D texture [S3, unofficial]. For dynamic fog, sample an auxiliary 3D noise texture (e.g., Perlin-Worley noise) using the reconstructed world-space position of the froxel [S3, unofficial]. The extinction coefficient is calculated as $\sigma_t = \sigma_s + \sigma_a$, where $\sigma_s$ is scattering and $\sigma_a$ is absorption [S3, unofficial]. The angular distribution of scattered light is modeled using the Henyey-Greenstein phase function: $p(\theta) = \frac{1}{4\pi} \frac{1 - g^2}{(1 + g^2 - 2g \cos\theta)^{3/2}}$, where $g \in (-1, 1)$ is the asymmetry parameter [S3, unofficial].

## Operating characteristics
*   **Time Complexity:** O(V * F), where V is the number of visible volumes and F is the average number of froxels covered by each volume. With optimization, F is reduced to only covered froxels.
*   **Memory Complexity:** O(A + G), where A is the size of the density atlas and G is the size of the froxel grid.
*   **Measured Performance:** Golden test 'fog-volume' (3x3x3 box at 0, 1, -5): Mean error against Godot 4.6.3 drops from 3.476/255 (no volume) to 0.205/255 [S1, unofficial]. Value check mean error over pixels the volume changes in Godot: box 13.05→0.40, ellipsoid 10.66→0.22, cone 8.90→0.40, cylinder 15.67→0.41, world shape 14.07→0.25, negative density 3.65→0.26, height falloff 2 9.58→0.24, edge fade 0 14.21→0.40, edge fade 4 2.55→0.08, no material 13.21→0.35, albedo/emission 32.91→1.13, density 8 23.92→0.45, rotated/scaled 13.73→0.30, spot/sun lights 24.70→0.60 [S1, unofficial]. Value check mean error over whole frame: imported 3D texture 3.554→0.209, ImageTexture3D .tres Lum8 4.459→0.206, NoiseTexture3D .tres 5.418→0.196, ImageTexture3D .tres RHalf 2.227→0.215, RFloat 2.229→0.216, R16 1.153→0.184, RGBE9995 2.229→0.215, NoiseTexture3D warp simplex 0.714→0.194, reduced simplex progressive 0.683→0.199, basic grid independent 0.496→0.196 [S1, unofficial].
*   **Strengths:** Supports complex local fog shapes and variations; integrates with global fog; supports noise-based dynamic fog.
*   **Limitations:** Limited by atlas size (2048 slices); requires careful handling of texture formats; ShaderMaterial integration is non-trivial.
*   **When to use:** When non-uniform, patchy fog effects are needed.
*   **When not to use:** When simple, uniform fog is sufficient; when performance is critical and many volumes are used (due to atlas limits).

## Background
Fog Volume Grid Rendering is a technique used in real-time volumetric rendering to integrate local fog volumes into a global froxel-based fog system. It was implemented in Godot 4.6.3 and ported to other engines like Three.js (via textscene-inspector) [S1, unofficial]. The method draws on principles from volumetric rendering literature, such as the use of 3D textures for density storage and Henyey-Greenstein phase functions for scattering [S3, unofficial]. It is commonly used in game engines to create atmospheric effects like fog banks, mist, and layered clouds.
