# Fog Volume Injection Optimization

Also called: Fog Volume Froxel Culling, Froxel-culled fog injection, Per-volume fog injection, Per-volume froxel bounds culling, SGL3D Fog Volume Injection Optimization, inject scene fog volumes only into the froxels they cover

## Overview
Fog Volume Injection Optimization reduces the computational cost of injecting scene fog volumes into a froxel grid by ensuring each volume is processed only by the froxels it geometrically covers, rather than having every froxel test every scene fog volume [S1, S2, unofficial]. It differs from the brute-force approach (where every froxel iterates all volumes) by using precomputed CPU-side bounds to cull irrelevant volume-froxel pairs, and differs from Godot’s per-volume dispatch by using a single GPU kernel with a culled list of ranges, avoiding the overhead of many small kernel launches [S2, unofficial].

## How it works
**Inputs:**
- List of scene fog volumes, each defined by eight world-space corners and associated density, albedo, and emission parameters.
- Camera parameters: view matrix, projection matrix, near plane distance, and `Fog::length` (far clip).
- Froxel grid parameters: grid dimensions ($N_x, N_y, N_z$) and world-space origin/spacing.

**Outputs:**
- Updated froxel storage buffers: density (fixed-point) and scattering (R11G11B10 packed).

**Data Structures:**
- `fog_volume_froxels`: A storage buffer (group 1, binding 9) containing a list of structures. Each structure represents a volume's froxel range:
  - `first`: `u32`, the first froxel index (linearized) covered by the volume.
  - `last`: `u32`, the last froxel index covered.
  - `volume`: `u32`, the index of the scene fog volume in the scene list.
  - The list is sorted by `volume` index (scene order) [S2, unofficial].

**Parameters:**
- Density scaling factor: $1024$. Density is multiplied by this factor and truncated to integer [S2, unofficial].
- Froxel bound widening: $0.01$. Added to computed bounds to absorb floating-point rounding errors [S2, unofficial].

**Steps:**

1. **Frustum Culling:**
   - For each scene fog volume, determine if it intersects the visible frustum.
   - Drop volumes that lie entirely behind the camera, entirely beyond `Fog::length`, or entirely beside the frame without crossing the camera plane [S2, unofficial].

2. **Bounding Froxel Range Calculation:**
   - Transform the volume's eight world-space corners to view space.
   - Handle volumes crossing the camera's near plane: If any corner is on or behind the camera's plane, expand the froxel range to cover the entire frame (all $x, y$) up to the slice of the farthest corner [S2, unofficial].
   - For other volumes, compute the min and max froxel indices ($i_{min}, i_{max}$) occupied by the corners.
   - Apply widening: $i_{min} \leftarrow \max(0, i_{min} - \lceil 0.01 \times \text{grid\_size} \rceil)$ and $i_{max} \leftarrow \min(\text{grid\_size} - 1, i_{max} + \lceil 0.01 \times \text{grid\_size} \rceil)$ [S2, unofficial].
   - Linearize the 3D froxel indices to a 1D range $[first, last]$ based on the grid dimensions [S2, unofficial].

3. **Upload Range List:**
   - Construct the `fog_volume_froxels` list with entries $(first, last, volume)$ for all surviving volumes.
   - Sort the list by `volume` index.
   - Upload this list to the `fog_volume_froxels` storage buffer every frame [S2, unofficial].

4. **Injection Shader Execution:**
   - The GPU launches a compute shader for the froxel grid.
   - Each workgroup/thread processes a specific froxel (or a tile of froxels).
   - For the current froxel index $F$, iterate through the `fog_volume_froxels` list.
   - For each entry $(first, last, vol\_idx)$, check if $first \le F \le last$.
   - If the condition holds, evaluate the volume's density and scattering at the froxel's position and accumulate into the froxel's storage buffers using atomics [S2, unofficial].

**Pseudocode:**

```python
# CPU-side bounds calculation (simplified)
def compute_froxel_range(volume_corners, camera_view_matrix, froxel_grid):
    # Transform corners to view space
    view_corners = [transform(c, camera_view_matrix) for c in volume_corners]
    
    # Check if any corner is behind or on the near plane
    if any(c.z <= 0.0 for c in view_corners):
        # Expand to whole frame up to farthest corner's slice
        max_z = max(c.z for c in view_corners)
        far_slice = froxel_grid.z_index_at_depth(max_z)
        return (0, froxel_grid.total_xy_froxels() * far_slice, volume.index)
    
    # Compute min/max froxel indices for all corners
    min_x = min(froxel_grid.x_index_at_view(c.x, c.z) for c in view_corners)
    max_x = max(froxel_grid.x_index_at_view(c.x, c.z) for c in view_corners)
    min_y = min(froxel_grid.y_index_at_view(c.y, c.z) for c in view_corners)
    max_y = max(froxel_grid.y_index_at_view(c.y, c.z) for c in view_corners)
    min_z = min(froxel_grid.z_index_at_depth(c.z) for c in view_corners)
    max_z = max(froxel_grid.z_index_at_depth(c.z) for c in view_corners)
    
    # Apply widening
    widen = ceil(0.01 * froxel_grid.resolution)
    min_x = max(0, min_x - widen)
    max_x = min(froxel_grid.width - 1, max_x + widen)
    min_y = max(0, min_y - widen)
    max_y = min(froxel_grid.height - 1, max_y + widen)
    min_z = max(0, min_z - widen)
    max_z = min(froxel_grid.depth - 1, max_z + widen)
    
    # Linearize to 1D range
    first = froxel_grid.linear_index(min_x, min_y, min_z)
    last = froxel_grid.linear_index(max_x, max_y, max_z)
    
    return (first, last, volume.index)

# GPU-side injection shader (WGSL-like pseudocode)
@compute
fn inject_fog(froxel_index: u32, fog_volume_froxels: array<VolumeRange>, fog_volumes: array<FogVolume>, density_buffer: atomic<u32>, scattering_buffer: atomic<u32>) {
    for i in 0..fog_volume_froxels.length {
        let range = fog_volume_froxels[i];
        if froxel_index >= range.first && froxel_index <= range.last {
            let volume = fog_volumes[range.volume];
            
            // Evaluate density at froxel position
            let density = evaluate_density(volume, froxel_position);
            
            // Accumulate density (scaled by 1024, truncated)
            let density_fixed = u32(density * 1024.0);
            atomicAdd(&density_buffer[froxel_index], density_fixed);
            
            // Accumulate scattering (albedo * clamp(density, 0, 1), packed R11G11B10)
            let scattering_weight = clamp(density, 0.0, 1.0);
            let scattering_val = volume.albedo * scattering_weight;
            let scattering_packed = pack_r11g11b10(scattering_val);
            atomicAdd(&scattering_buffer[froxel_index], scattering_packed);
        }
    }
}
```

**Edge Cases and Pitfalls:**
- **Rounding Errors:** Floating-point projection of corners can cause off-by-one froxel errors. The widening factor of $0.01$ froxels absorbs this [S2, unofficial].
- **Camera Plane Crossing:** Volumes holding or crossing the camera plane must be handled carefully. Clamping corners behind the camera (as done in some implementations) can fail to bound boxes crossing the plane. Expanding the bound to the whole frame if any corner is on or behind the plane is safer [S2, unofficial].
- **Determinism:** The order of accumulation must remain consistent with the original brute-force method to ensure identical density and albedo sums where volumes overlap [S1, S2, unofficial].

## Operating characteristics
- **Time Complexity:** Reduces the fog injection loop from $O(F \times V)$ to $O(F \times V_{in\_view}) + O(V \times F_{per\_volume})$, where $F$ is total froxels, $V$ is total volumes, $V_{in\_view}$ is volumes in view, and $F_{per\_volume}$ is froxels per volume [S2, unofficial].
- **Measured Performance:**
  - In Hyperdrive (1920×1080, High, 32 tunnel volumes), brute-force volume loop was ~1.3–1.5 ms of 4.5 ms total fog injection [S1, unofficial].
  - With the optimization (SGL main #42 fix), fog injection dropped from 1.72 ms to 1.25 ms (High/Low night), 4.74 ms to 3.55 ms (High/High night), and 4.96 ms to 3.97 ms (Ultra night) [S1, unofficial].
  - At High/Low day, it dropped from 0.91 ms to 0.31 ms; at Ultra day, from 4.14 ms to 2.15 ms [S1, unofficial].
- **Strengths:** Eliminates redundant volume tests; avoids overhead of many small kernel dispatches (compared to Godot's per-volume dispatch) [S2, unofficial].
- **Limitations:** Requires CPU-side bounds calculation every frame; still iterates all volumes in view for each froxel (though fewer volumes pass the range test) [S2, unofficial].
- **When to Use:** When the number of scene fog volumes is significant and many do not intersect the visible froxel grid.
- **When Not to Use:** When the number of volumes is very small, or when volumes are uniformly distributed across the entire grid, reducing the benefit of culling [S2, unofficial].

## Background
The optimization was developed for the SGL3D rendering engine, following its rendering development rules (RD-1–RD-7) and architecture (AR rules) [S1, unofficial]. It was implemented in pull request #64, addressing issue #42, to improve performance in scenes with many fog volumes, such as the Hyperdrive test environment [S1, S2, unofficial]. It draws inspiration from Godot's per-volume froxel AABB computation and frustum culling [S2, unofficial].
