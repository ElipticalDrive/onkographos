# Fog Volume Injection Optimization

Also called: Froxel-culled fog injection, Per-volume fog injection, SGL3D Fog Volume Injection Optimization, inject scene fog volumes only into the froxels they cover

## Overview
Fog Volume Injection Optimization is a performance enhancement for froxel-based volumetric rendering that restricts the injection of scene fog volumes to only those froxels they geometrically cover, eliminating the naive $O(N_{froxels} \times N_{volumes})$ test where every froxel evaluates every volume [S1, unofficial]. It differs from the baseline SGL3D implementation by replacing the global volume loop with a targeted dispatch mechanism, matching the approach used in Godot's renderer which computes per-volume AABBs and dispatches kernels only for covered regions [S1, unofficial].

## How it works
The optimization replaces the brute-force injection stage with a spatially aware dispatch strategy. The core logic involves determining the intersection between each fog volume's bounding volume and the froxel grid, then processing only the relevant froxels.

### Inputs and Outputs
*   **Inputs**:
    *   List of active scene fog volumes, each defined by a bounding volume (typically AABB) and associated density, albedo, and emission properties [S1, unofficial].
    *   The froxel grid structure (resolution, cell size, origin) [S1, unofficial].
    *   Camera frustum parameters for culling [S1, unofficial].
*   **Outputs**:
    *   Updated froxel buffers containing accumulated density, albedo, and emission values [S1, unofficial].

### Data Structures
*   **Fog Volume List**: An array of volume descriptors. Each descriptor contains the volume's bounding box (min/max coordinates) and material properties (density, albedo, emission) [S1, unofficial].
*   **Froxel Grid**: A 3D texture or buffer representing the volumetric space, divided into cells (froxels) [S1, unofficial].

### Algorithm Steps
1.  **Frustum Culling**: Filter the list of scene fog volumes to retain only those intersecting the camera's view frustum [S1, unofficial].
2.  **Bounding Volume Calculation**: For each remaining volume, compute its Axis-Aligned Bounding Box (AABB) in froxel space [S1, unofficial].
3.  **Range Determination**: Determine the minimum and maximum slice and tile indices (or x, y, z grid indices) that the volume's AABB covers within the froxel grid [S1, unofficial].
4.  **Targeted Dispatch**: Iterate through the frustum-culled volume list. For each volume, dispatch a compute kernel or execute a loop that processes only the froxels within the calculated range [S1, unofficial].
    *   *Note*: The sources describe two potential implementation scopes: full per-volume dispatch (like Godot) or a first step of frustum culling with slice/tile bounding [S1, unofficial]. The core optimization is ensuring the volume loop only touches covered froxels [S1, unofficial].
5.  **Injection**: In the targeted froxels, add the volume's density, albedo, and emission to the existing froxel values [S1, unofficial].
    *   Formula: $F_{new} = F_{old} + V_{contribution}$, where $F$ is the froxel value and $V$ is the volume's contribution [S1, unofficial].
6.  **Verification**: Ensure that where volumes overlap froxels, the final summed density, albedo, and emission remain identical to the unoptimized result [S1, unofficial].

### Pseudocode
```python
# Inputs: volumes (list of Volume), froxel_grid (3D array), camera_frustum (Frustum)
# Output: froxel_grid (modified)

def optimize_fog_injection(volumes, froxel_grid, camera_frustum):
    # Step 1: Frustum culling
    visible_volumes = []
    for vol in volumes:
        if intersects_frustum(vol.bounding_box, camera_frustum):
            visible_volumes.append(vol)
            
    # Step 2 & 3: Determine froxel range for each volume
    for vol in visible_volumes:
        # Convert world-space AABB to froxel grid indices
        min_x, min_y, min_z = world_to_froxel_index(vol.bounding_box.min)
        max_x, max_y, max_z = world_to_froxel_index(vol.bounding_box.max)
        
        # Clamp to grid bounds
        min_x = clamp(min_x, 0, froxel_grid.width - 1)
        max_x = clamp(max_x, 0, froxel_grid.width - 1)
        min_y = clamp(min_y, 0, froxel_grid.height - 1)
        max_y = clamp(max_y, 0, froxel_grid.height - 1)
        min_z = clamp(min_z, 0, froxel_grid.depth - 1)
        max_z = clamp(max_z, 0, froxel_grid.depth - 1)
        
        # Step 4 & 5: Targeted injection
        for z in range(min_z, max_z + 1):
            for y in range(min_y, max_y + 1):
                for x in range(min_x, max_x + 1):
                    # Add volume contribution to the specific froxel
                    froxel_grid[x, y, z].density += vol.density
                    froxel_grid[x, y, z].albedo += vol.albedo
                    froxel_grid[x, y, z].emission += vol.emission
```

### Parameters and Edge Cases
*   **Parameters**: The optimization scope includes whether to implement full per-volume dispatch or just frustum culling with slice/tile bounding [S1, unofficial].
*   **Edge Cases**:
    *   **Overlap**: The result must remain unchanged where volumes overlap froxels, ensuring the same density, albedo, and emission sums are preserved [S1, unofficial].
    *   **Precision**: Standard floating-point accumulation applies; no specific precision issues are noted beyond standard accumulation errors [G].
    *   **Boundaries**: Froxel indices must be clamped to the grid dimensions to prevent out-of-bounds access [G].

## Operating characteristics
*   **Time Complexity**: Reduces the injection phase from $O(N_{froxels} \times N_{volumes})$ to approximately $O(N_{covered\_froxels} \times N_{volumes})$, where $N_{covered\_froxels} \ll N_{froxels}$ in sparse scenes [S1, unofficial].
*   **Measured Performance**:
    *   In the Hyperdrive test (1920×1080, High, 32 tunnel volumes), fog injection was 4.5 ms median, with the volume loop accounting for ~1.3–1.5 ms [S1, unofficial].
    *   With scene lights off, the volume loop dropped from 2.71 ms to 1.15 ms, and total injection from 4.5 ms to 3.22 ms [S1, unofficial].
    *   In RD-6/VR-4 measurements (Meridian, 1920×1080):
        *   High (fog Low) night: Injection dropped from 1.72 ms to 1.25 ms [S1, unofficial].
        *   High (fog High) night: Injection dropped from 4.74 ms to 3.55 ms [S1, unofficial].
        *   Ultra night: Injection dropped from 4.96 ms to 3.97 ms [S1, unofficial].
        *   High (fog Low) day: Injection dropped from 0.91 ms to 0.31 ms [S1, unofficial].
        *   Ultra day: Injection dropped from 4.14 ms to 2.15 ms [S1, unofficial] [S1, unofficial].
*   **Scaling**: The optimization provides significant gains in scenes with many fog volumes, particularly when volumes are sparse relative to the froxel grid [S1, unofficial].
*   **Strengths**: Reduces redundant calculations by avoiding tests for volumes that do not intersect the froxel [S1, unofficial].
*   **Limitations**: Requires additional overhead to compute bounding boxes and ranges per volume [S1, unofficial]. The new filter adds 0.41–0.56 ms at fog Low and 1.1–1.7 ms at fog High, resulting in a net fog sum increase of only +0.3 ms [S1, unofficial].
*   **When to use**: Use in real-time applications with dynamic fog volumes where performance is critical and volumes are not uniformly distributed across the entire froxel grid [S1, unofficial].

## Background
The optimization follows the SGL3D rendering development rules (RD-1–RD-7) and architecture (AR rules) [S1, unofficial]. It was implemented in response to the inefficiency of the original SGL3D implementation, where every froxel tested every scene fog volume in the inject stage (specifically in the volume loop within `crates/sgl-3d/src/stages/fog.wgsl`) [S1, unofficial]. The approach mirrors Godot's method, which computes each volume's froxel AABB and dispatches only that specific kernel per volume over a frustum-culled list [S1, unofficial]. Frostbite also voxelizes participating-media entities in a separate step, as noted in Hillaire 2015 [S1, unofficial]. The issue was opened by stevepryde on Oct 4, 2026, and closed as completed in #64 on the same date [S1, unofficial].
