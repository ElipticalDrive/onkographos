# Random Cone Rotation

Also called: Random Cones

## Overview
Random Cone Rotation is a technique in Voxel Cone Tracing that rotates diffuse cones randomly around the surface normal to reduce blocky artifacts caused by sparse cone distributions [S1, unofficial]. This stochastic variation introduces noise into the lighting result [S1, unofficial].

## How it works
**Inputs and Outputs:**
*   **Input:** Surface normal vector $\mathbf{n}$, a set of base cone directions, and a random value [G].
*   **Output:** Rotated cone directions used for ray marching in the voxel grid [G].

**Data Structures:**
*   **Cone Set:** A small fixed number of cones. The source specifies a distribution of one cone along the normal and four at perpendicular angles, all with an aperture of $30^\circ$ [S1, unofficial].
*   **Rotation Matrix:** A $3 \times 3$ matrix representing the random rotation around the normal [G].

**Steps:**
1.  Generate a random rotation angle $\theta$ around the surface normal $\mathbf{n}$ [G].
2.  Construct a rotation matrix $R$ that rotates vectors by $\theta$ around the axis $\mathbf{n}$ [G].
3.  Apply $R$ to each base cone direction $\mathbf{d}_i$ to obtain the rotated direction $\mathbf{d}'_i = R \mathbf{d}_i$ [G].
4.  Use $\mathbf{d}'_i$ for cone tracing [S1, unofficial].

**Pitfalls:**
*   **Noise:** The primary drawback is the introduction of temporal or spatial noise into the lighting result due to the stochastic nature of the rotation [S1, unofficial].
*   **Blocky Artifacts:** Without this rotation, the sparse cone count (e.g., 5 cones) results in visible blockiness in diffuse shading [S1, unofficial].

**Pseudocode:**
```python
def rotate_cones(normal, base_cones, random_angle):
    """
    Rotates a set of base cone directions around the surface normal.
    
    Args:
        normal (vec3): Surface normal vector.
        base_cones (list of vec3): List of base cone directions.
        random_angle (float): Random rotation angle in radians.
        
    Returns:
        list of vec3: Rotated cone directions.
    """
    c = cos(random_angle)
    s = sin(random_angle)
    
    rotated_cones = []
    for d in base_cones:
        k_cross_d = cross(normal, d)
        k_dot_d = dot(normal, d)
        
        d_rot = (d * c) + (k_cross_d * s) + (normal * k_dot_d * (1 - c))
        rotated_cones.append(d_rot)
        
    return rotated_cones
```

## Subtopics

### Noise Kernel Generation
Generates a 6-tap noise kernel for cone tracing by constructing a rotation matrix aligned with the light direction [S2, unofficial]. It determines the maximum component of the light direction to create a reference vector, computes a local coordinate system, and transforms fixed offsets by this rotation matrix [S2, unofficial].

## Operating characteristics
*   **Strengths:** Effectively reduces blocky artifacts caused by sparse cone distributions [S1, unofficial].
*   **Limitations:** Introduces noise into the lighting result [S1, unofficial].
*   **Performance:** Adds minimal computational overhead for the rotation itself, but the noise may require temporal filtering or additional samples to achieve smooth results, potentially increasing cost [G].

## Background
This method is described in the context of Voxel Cone Tracing implementations, specifically addressing the visual quality issues arising from using a very small number of cones (e.g., 5 cones with $30^\circ$ aperture) for diffuse lighting [S1, unofficial].
