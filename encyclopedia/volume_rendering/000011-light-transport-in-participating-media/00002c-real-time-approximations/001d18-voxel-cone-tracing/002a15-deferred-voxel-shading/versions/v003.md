# Deferred Voxel Shading

Also called: Deferred Voxel Cone Tracing, Villegas Voxel Cone Tracing, Villegas Voxel Shading

## Overview
Deferred Voxel Shading is a four-step real-time global illumination technique that merges voxel cone tracing with deferred shading to compute indirect lighting effects including diffuse/specular reflection, color-blending, emissive materials, indirect shadows, and ambient occlusion [S2, unofficial]. It differs from standard voxel cone tracing by integrating direct lighting calculations into the voxelization stage and utilizing anisotropic directional volumes for more precise cone tracing, while deferring the final lighting composition to the fragment shader to avoid redundant calculations for overlapping geometry [S1, unofficial][S2, unofficial].

## How it works
The method consists of four sequential stages: Voxelization, Voxel Illumination, Anisotropic Voxel Generation, and Voxel Cone Tracing.

### Inputs and Outputs
**Inputs:**
*   Scene geometry (triangles).
*   Material properties: Albedo ($\rho$), Normal ($N$), Emission, Specular exponent (for Blinn-Phong).
*   Light sources: Point, Spot, Directional.
*   Camera parameters: Position, View Direction, Aperture Angle ($\theta$).

**Outputs:**
*   Final fragment color with indirect illumination.

### Data Structures
The technique relies on several 3D textures bound as `uimage3D` (unsigned integer) or standard 3D textures for interpolation.

1.  **Voxelization Storage:** Three 3D textures with `r32ui` format (or equivalent unsigned integer formats for RGBA).
    *   `voxelAlbedo`: Stores averaged albedo.
    *   `voxelNormal`: Stores averaged surface normals.
    *   `voxelEmission`: Stores light emission values.
    *   *Note:* Atomic operations (`imageAtomicRGBA8Avg`) are used to average values per voxel during conservative voxelization [S2, unofficial].
2.  **Radiance Volume:** A 3D texture storing the maximum level of detail (LOD) for the voxelized scene. It holds the computed outgoing radiance per voxel after direct illumination and emission are added.
3.  **Directional Volumes:** Six 3D textures at half the resolution of the Radiance Volume.
    *   One texture per axis direction (positive/negative X, Y, Z).
    *   Mipmap levels store directional values for anisotropic sampling.
4.  **Flag Volume:** A single-value 3D texture used to identify voxels as static. Used to prevent overwriting static voxels during dynamic updates [S2, unofficial].

### Numbered Steps

#### Step 1: Voxelization
Conservative voxelization is performed to generate the initial 3D textures.
1.  For each triangle, determine the bounding box in voxel space.
2.  For each voxel within the bounding box:
    *   Read the current value from `voxelAlbedo`, `voxelNormal`, and `voxelEmission` at the voxel position.
    *   Average the incoming fragment's albedo, normal, and emission with the stored values using atomic operations [S2, unofficial].
    *   If the geometry is static, write a flag to the `Flag Volume` at this position to mark it as static.
3.  **Dynamic Update:** Before writing dynamic voxels, read the `Flag Volume`. If the position is marked static, discard the write. To clear previous dynamic voxels, read the `Flag Volume`; if a voxel exists and is dynamic, clear its data in the three storage textures [S2, unofficial].

#### Step 2: Voxel Illumination
Direct lighting is computed per voxel in a compute shader.
1.  Iterate over all voxels in the Radiance Volume.
2.  Extract the voxel's world-space position and averaged normal ($N$) from the Voxelization Storage.
3.  For each light source (Point, Spot, Directional):
    *   Calculate the light direction ($\Psi$) and intensity ($L_i$).
    *   Compute **Normal Weighted Attenuation** to handle uneven normals within a voxel:
        *   Calculate face attenuation:
            $$D_{x,y,z} = (\hat{i}\cdot\Psi, \hat{j}\cdot\Psi, \hat{k}\cdot\Psi)$$
            where $\hat{i}, \hat{j}, \hat{k}$ are the axis unit vectors and $\Psi$ is the light direction [S2, unofficial].
        *   Select dominant faces based on the sign of the voxel averaged normal vector component ($N_\omega$):
            $$D_{\omega} = \begin{cases} \max\{D_\omega, 0\}, & N_\omega>0 \\ \max\{-D_\omega, 0\}, & \text{otherwise} \end{cases}$$
            where $\omega \in \{x, y, z\}$ [S2, unofficial].
    *   Compute the reflectance model:
        $$W = N^2$$
        $$V_{r} = L_{i}\frac{\rho}{\pi}(W_x D_x + W_y D_y + W_z D_z)$$
        where $\rho$ is the voxel albedo and $N$ is the voxel normal vector [S2, unofficial].
    *   **Voxel Occlusion:** Trace a ray from the voxel position in the direction of the light. Sample the voxelized volume (e.g., `voxelAlbedo`) to determine if a voxel exists at the ray position. If true, the voxel is occluded.
        *   **Soft Voxel Shadows:** Instead of binary occlusion, accumulate soft shadows:
            $$\nu = \nu + (1 - \nu)\kappa\div t$$
            where $\kappa$ is the value accumulated per collision, $t$ is the traced distance, and $1 - \nu$ represents the final occlusion value [S2, unofficial].
    *   Apply occlusion to $V_r$.
4.  Add the emission term from `voxelEmission` to the direct illumination value $V_r$.
5.  Write the resulting radiance to the **Radiance Volume**.

#### Step 3: Generate Anisotropic Voxels
Compute directional values for the Directional Volumes using volumetric integration.
1.  For each mipmap level (from highest resolution down to lowest):
2.  For each voxel in the current level:
    *   Execute a compute shader thread.
    *   Perform volumetric integration in depth using values from the previous (higher resolution) level.
    *   Average the directional values to obtain the resulting value for each of the six axis directions.
    *   Write the results to the corresponding **Directional Volume** [S2, unofficial].

#### Step 4: Voxel Cone Tracing
Performed in the fragment shader as a screenspace effect.
1.  Define the cone by origin $C_o$ (fragment position), direction $C_d$ (view direction), and aperture angle $\theta$.
2.  Initialize accumulated color $c = 0$ and accumulated occlusion $\alpha = 0$.
3.  Loop for cone steps:
    *   Calculate traced distance $t$.
    *   Calculate cone diameter:
        $$d = 2t \times \tan(\theta \div 2)$$
    *   Determine mipmap level:
        $$V_{level} = \log_2(d \div V_{size})$$
        where $V_{size}$ is the size of a voxel at the maximum level of detail [S2, unofficial].
    *   Select the three Directional Volumes corresponding to the cone's direction (based on the signs of $C_d$ components).
    *   Sample the Radiance Volume and the selected Directional Volumes at $V_{level}$ using quadrilinear interpolation for smooth variation [S2, unofficial].
    *   Retrieve outgoing radiance $c_2$ and occlusion $\alpha_2$ from the voxel structure.
    *   Update accumulated values using volumetric front-to-back accumulation:
        $$c = \alpha c + (1-\alpha)\alpha_2c_2$$
        $$\alpha = \alpha + (1-\alpha)\alpha_2$$
    *   Advance the cone. The step distance $d'$ is modified by a factor $\beta$:
        $$d' = \beta \times d$$
        where $\beta = 1$ makes $d'$ equivalent to the current diameter $d$. Values $< 1$ produce higher quality but require more samples [S2, unofficial].
4.  **Indirect Illumination Approximation:**
    *   **Diffuse:** Use a few large cones distributed over the normal-oriented hemisphere.
    *   **Specular:** Use a single cone in the reflected direction, where aperture depends on the specular exponent (Blinn-Phong) [S2, unofficial].
    *   **Ambient Occlusion:** Approximate using the same cones as diffuse reflection. Accumulate only the occlusion value $\alpha_2$, weighted by $f(r) = \frac{1}{1+\lambda r}$, where $r$ is the current radius and $\lambda$ is a parameter [S2, unofficial].

### Pseudocode

```python
# Step 1: Voxelization (Compute Shader)
def voxelize_geometry(triangles, voxel_size):
    for triangle in triangles:
        bbox = get_bounding_box(triangle, voxel_size)
        for voxel_pos in bbox:
            # Atomic average for albedo, normal, emission
            imageAtomicRGBA8Avg(voxelAlbedo, voxel_pos, triangle.albedo)
            imageAtomicRGBA8Avg(voxelNormal, voxel_pos, triangle.normal)
            imageAtomicRGBA8Avg(voxelEmission, voxel_pos, triangle.emission)
            
            if triangle.is_static:
                write_flag(FlagVolume, voxel_pos, STATIC)

# Step 2: Voxel Illumination (Compute Shader)
def compute_voxel_radiance():
    for voxel_pos in all_voxels:
        N = read(voxelNormal, voxel_pos)
        rho = read(voxelAlbedo, voxel_pos)
        E = read(voxelEmission, voxel_pos)
        pos_world = voxel_to_world(voxel_pos)
        
        radiance = 0.0
        
        for light in lights:
            Psi = normalize(light.position - pos_world)
            Li = light.intensity
            
            # Normal Weighted Attenuation
            D_x = dot(vec3(1,0,0), Psi)
            D_y = dot(vec3(0,1,0), Psi)
            D_z = dot(vec3(0,0,1), Psi)
            
            N_x = N.x
            N_y = N.y
            N_z = N.z
            
            if N_x > 0: D_x = max(D_x, 0)
            else: D_x = max(-D_x, 0)
            
            if N_y > 0: D_y = max(D_y, 0)
            else: D_y = max(-D_y, 0)
            
            if N_z > 0: D_z = max(D_z, 0)
            else: D_z = max(-D_z, 0)
            
            W_x = N_x * N_x
            W_y = N_y * N_y
            W_z = N_z * N_z
            
            Vr = Li * (rho / PI) * (W_x * D_x + W_y * D_y + W_z * D_z)
            
            # Soft Voxel Shadows
            nu = 0.0
            t = 0.0
            ray_pos = pos_world
            while t < max_distance:
                ray_pos += Psi * step_size
                if exists_voxel_at(ray_pos):
                    nu = nu + (1 - nu) * kappa / t
                t += step_size
            
            Vr = Vr * (1 - nu)
            radiance += Vr
            
        radiance += E
        write(RadianceVolume, voxel_pos, radiance)

# Step 3: Anisotropic Voxels (Compute Shader)
def generate_anisotropic_voxels():
    for level in mipmap_levels:
        for voxel_pos in level:
            # Volumetric integration from previous level
            dir_values = [0.0] * 6
            for i in range(6):
                dir_values[i] = integrate_directional(voxel_pos, axis[i], prev_level)
            write(DirectionalVolumes[i], voxel_pos, dir_values[i])

# Step 4: Voxel Cone Tracing (Fragment Shader)
def fragment_shader():
    Co = camera_position
    Cd = normalize(view_direction)
    theta = aperture_angle
    beta = 1.0 # Quality factor
    
    c = vec3(0.0)
    alpha = 0.0
    
    t = 0.0
    while t < max_trace_distance:
        d = 2 * t * tan(theta / 2)
        V_level = log2(d / V_size)
        
        # Select 3 directional volumes based on Cd signs
        dirs = get_directions(Cd)
        
        # Sample Radiance and Directional Volumes
        c2 = sample_radiance(RadianceVolume, Co + Cd * t, V_level)
        alpha2 = sample_occlusion(DirectionalVolumes, Co + Cd * t, V_level, dirs)
        
        # Front-to-back accumulation
        c = alpha * c + (1 - alpha) * alpha2 * c2
        alpha = alpha + (1 - alpha) * alpha2
        
        t += beta * d
        
    return c
```

### Parameters
*   **Beta ($\beta$):** Factor modifying the distance $d'$ between cone steps. $\beta = 1$ makes $d'$ equivalent to current diameter $d$. Values $< 1$ produce higher quality but require more samples [S2, unofficial].
*   **Aperture Angle ($\theta$):** Determines the cone's spread.
*   **Voxel Size ($V_{size}$):** Size of a voxel at the maximum level of detail.

### Edge Cases and Pitfalls
*   **Normal Averaging:** Uneven normals within a voxel can cause incorrect lighting. The normal-weighted attenuation method mitigates this [S2, unofficial].
*   **Dynamic Updates:** Static voxels must be protected from being overwritten by dynamic voxelization using the Flag Volume [S2, unofficial].
*   **Precision:** Quadrilinear interpolation is used to ensure smooth variation between samples, avoiding artifacts at mipmap boundaries [S2, unofficial].

## Operating characteristics
*   **Time Complexity:** Dependent on the number of voxels, lights, and cone trace steps. The use of deferred shading avoids redundant lighting calculations for overlapping polygons, enhancing performance in scenes with many light sources [S1, unofficial].
*   **Memory Complexity:** Requires storage for Voxelization Storage (3 textures), Radiance Volume (1 texture), Directional Volumes (6 textures), and Flag Volume (1 texture). Directional volumes are at half resolution [S2, unofficial].
*   **Strengths:** Handles complex lighting effects like emissive materials and multiple light bounces. Compatible with point, spot, and directional lights without shadow maps [S2, unofficial].
*   **Limitations:** Crude Monte Carlo approximation may introduce noise or inaccuracies. High memory usage due to multiple 3D textures. Performance degrades with high resolution or many cone steps [S2, unofficial].

## Background
Deferred Voxel Shading was presented by Jose Villegas [S1, unofficial][S2, unofficial]. It expands upon rudimentary voxel cone tracing by merging it with deferred shading. The approach allows for the computation of lighting effects such as emissive materials, indirect shadows, and multiple light bounces on a voxel cone tracing basis. The generation of mipmaps utilizes anisotropic filtering methods for more precise results [S1, unofficial].
