# Deferred Voxel Shading

Also called: Deferred Voxel Cone Tracing, Villegas Voxel Cone Tracing, Villegas Voxel Shading

## Overview
Deferred Voxel Shading is a real-time global illumination technique that merges voxel cone tracing with deferred shading to compute indirect lighting effects such as diffuse/specular reflection, color-blending, emissive materials, indirect shadows, and ambient occlusion [S2, unofficial]. Unlike forward voxel cone tracing, which computes lighting per fragment during geometry rendering, this method delays all lighting computations until after the geometry pass, avoiding redundant calculations for overlapping polygons and enhancing performance in scenes with many light sources [S1, unofficial]. It builds on [Voxel Cone Tracing](1454-voxel-cone-tracing.md) by introducing a deferred rendering backend and anisotropic voxel structures for higher precision [S2, unofficial].

## How it works
The method consists of four main stages: Voxelization, Voxel Illumination, Anisotropic Voxel Generation, and Voxel Cone Tracing [S2, unofficial].

### Inputs and Outputs
**Inputs:**
*   Scene geometry (triangles).
*   Light sources (point, spot, directional).
*   Camera position and orientation.
*   Material properties (albedo, normal, emission, specular exponent).

**Outputs:**
*   Final screen-space color buffer with global illumination.

### Data Structures
The technique relies on several 3D textures (volumes) stored in GPU memory [S2, unofficial]:

1.  **Voxelization Storage:** Three `uimage3D` textures with `r32ui` format (unsigned integer, 32-bit), bound as `volatile coherent` to allow atomic operations [S2, unofficial]:
    *   `voxelAlbedo`: Stores averaged albedo values.
    *   `voxelNormal`: Stores averaged surface normals.
    *   `voxelEmission`: Stores light emission values.
2.  **Radiance Volume:** A 3D texture storing the maximum level of detail (LOD) for the voxelized scene, containing the computed outgoing radiance per voxel after direct illumination and emission are added [S2, unofficial].
3.  **Directional Volumes:** Six 3D textures at half the resolution of the Radiance Volume. One texture exists for each axis direction (positive and negative X, Y, Z). Mipmap levels within these textures store directional values for anisotropic sampling [S2, unofficial].
4.  **Flag Volume:** A single-value 3D texture used to identify voxels as static. It prevents dynamic geometry from overwriting static voxels during dynamic updates [S2, unofficial].

### Parameters
*   $\beta$ (Beta): A factor modifying the distance $d'$ between cone steps. $\beta = 1$ makes $d'$ equivalent to the current cone diameter $d$. Values $< 1$ produce higher quality but require more samples [S2, unofficial].
*   $\lambda$: A parameter for the ambient occlusion weighting function $f(r) = \frac{1}{1+\lambda r}$, where $r$ is the current radius of the cone [S2, unofficial].

### Steps

#### 1. Voxelization
The scene geometry is voxelized using conservative rasterization. Atomic operations are used to average values per voxel to handle overlapping fragments [S2, unofficial].

1.  For each triangle, determine the voxel coordinates it occupies.
2.  Use atomic operations to update the voxel storage textures [S2, unofficial]:
    *   Average normals: `imageAtomicRGBA8Avg(voxelNormal, position, normal)`
    *   Average albedo: `imageAtomicRGBA8Avg(voxelAlbedo, position, albedo)`
    *   Average emission: `imageAtomicRGBA8Avg(voxelEmission, position, emissive)`
3.  **Dynamic Update Handling:**
    *   Before writing a voxel for dynamic geometry, read the `Flag Volume` at the target position.
    *   If the flag indicates the position is static, discard the write [S2, unofficial].
    *   To clear previous dynamic voxels, use a compute shader to read the `Flag Volume`. If a voxel exists and is dynamic (flag is false), clear its entry in the storage textures [S2, unofficial].

#### 2. Voxel Illumination
Direct lighting is computed per voxel in a compute shader using the stored normal, position, albedo, and emission data. This step is compatible with point, spot, and directional lights and does not require shadow maps, though they can improve precision [S2, unofficial].

1.  Extract the voxel position in world-space from its 3D coordinates.
2.  Calculate direct lighting for each light source.
3.  **Normal-Weighted Attenuation:** To handle uneven normal vectors within a voxel, calculate attenuation per face [S2, unofficial]:
    *   Let $\Psi$ be the light direction.
    *   Calculate face attenuations: $D_{x,y,z} = (\hat{i}\cdot\Psi, \hat{j}\cdot\Psi, \hat{k}\cdot\Psi)$, where $\hat{i}, \hat{j}, \hat{k}$ are the voxel axes.
    *   Let $N$ be the averaged normal vector of the voxel.
    *   Select dominant faces based on the sign of $N$'s components:
        $$
        D_{\omega} =
        \begin{cases}
        \max\{D_\omega, 0\}, & N_\omega > 0 \\
        \max\{-D_\omega, 0\}, & \text{otherwise}
        \end{cases}
        $$
        where $\omega \in \{x, y, z\}$.
4.  **Reflectance Model:** Compute the outgoing radiance $V_r$ [S2, unofficial]:
    *   $W = N^2$ (weight per axis).
    *   $V_{r} = L_{i}\frac{\rho}{\pi}(W_x D_x + W_y D_y + W_z D_z)$
    *   Where $L_i$ is light intensity, $\rho$ is voxel albedo.
5.  **Emission:** Add the emission term from the voxelization process to $V_r$. This allows emissive materials to contribute indirect light even in occluded areas [S2, unofficial].
6.  **Voxel Occlusion (Soft Shadows):** Trace a ray from the voxel position in the direction of the light. Sample the voxelized volume to determine occlusion. Instead of a binary shadow, accumulate soft shadows [S2, unofficial]:
    *   Initialize $\nu = 0$.
    *   For each collision with a voxel along the ray at distance $t$, accumulate: $\nu = \nu + (1 - \nu)\kappa\div t$, where $\kappa$ is the value accumulated per collision.
    *   The final occlusion value is $1 - \nu$.
7.  Store the resulting radiance in the **Radiance Volume**.

#### 3. Generate Anisotropic Voxels
To improve cone tracing precision, anisotropic voxels are generated using volumetric integration in depth [S2, unofficial].

1.  For each mipmap level (from base to higher levels):
2.  Execute a compute shader thread per voxel.
3.  Perform volumetric integration in depth to compute directional values.
4.  Average the values to obtain the resulting directional value for each of the six axis directions (positive/negative X, Y, Z).
5.  Store these values in the corresponding **Directional Volumes**. The mipmap levels store the levels of detail for anisotropic sampling [S2, unofficial].

#### 4. Voxel Cone Tracing
Performed in the fragment shader as a screen-space effect. It requires a deferred rendering backend [S2, unofficial].

1.  **Cone Definition:** Define a cone by origin $C_o$, direction $C_d$, and aperture angle $\theta$.
2.  **Step Size:** Calculate the cone diameter $d$ at traced distance $t$:
    $$d = 2t \times \tan(\theta \div 2)$$
3.  **Mipmap Level Selection:** Determine the LOD to sample:
    $$V_{level} = \log_2(d \div V_{size})$$
    Where $V_{size}$ is the size of a voxel at the maximum level of detail. If $V_{level}$ ranges between the maximum level and the first filtered level, use linear interpolation between samples from the Radiance Volume and Directional Volumes [S2, unofficial].
4.  **Directional Sampling:** The cone direction determines which three Directional Volumes are sampled (e.g., positive X, positive Y, positive Z). Linearly interpolate the three samples to get the directional value [S2, unofficial].
5.  **Accumulation:** Use volumetric front-to-back accumulation to update color $c$ and occlusion $\alpha$ [S2, unofficial]:
    *   Retrieve outgoing radiance $c_2$ and occlusion $\alpha_2$ from the voxel structure.
    *   Update color: $c = \alpha c + (1-\alpha)\alpha_2 c_2$
    *   Update occlusion: $\alpha = \alpha + (1-\alpha)\alpha_2$
    *   Advance the cone by step distance $d' = \beta \times d$.
6.  **Indirect Illumination Approximation:** Use a crude Monte Carlo approximation. Partition the hemisphere integral into a sum of integrals resembling cones [S2, unofficial]:
    *   **Diffuse:** Use a few large cones distributed over the normal-oriented hemisphere.
    *   **Specular:** Use a single cone in the reflected direction, where aperture depends on the specular exponent (Blinn-Phong) [S2, unofficial].
7.  **Ambient Occlusion:** Approximate using the same cones as diffuse reflection. Accumulate only the occlusion value $\alpha_2$ at each step, multiplied by the weighting function $f(r) = \frac{1}{1+\lambda r}$, where $r$ is the current radius of the cone [S2, unofficial].

### Pseudocode

```python
# Step 1: Voxelization (Compute Shader)
def voxelize_geometry(triangles, voxelAlbedo, voxelNormal, voxelEmission, flagVolume):
    for triangle in triangles:
        voxels = conservative_rasterize(triangle)
        for voxel_pos in voxels:
            # Check if static
            is_static = flagVolume.read(voxel_pos)
            if is_static and triangle.is_dynamic:
                continue
            
            # Compute fragment data
            albedo, normal, emission = compute_fragment_data(triangle, voxel_pos)
            
            # Atomic average
            voxelAlbedo.atomic_avg(voxel_pos, albedo)
            voxelNormal.atomic_avg(voxel_pos, normal)
            voxelEmission.atomic_avg(voxel_pos, emission)
            
            # Mark as dynamic if not static
            if not is_static:
                flagVolume.write(voxel_pos, 0) # 0 = dynamic

# Step 2: Voxel Illumination (Compute Shader)
def compute_voxel_radiance(radianceVolume, voxelAlbedo, voxelNormal, voxelEmission, lights):
    for voxel_pos in all_voxels:
        albedo = voxelAlbedo.read(voxel_pos)
        normal = voxelNormal.read(voxel_pos)
        emission = voxelEmission.read(voxel_pos)
        
        radiance = vec3(0.0)
        
        for light in lights:
            # Normal-weighted attenuation
            light_dir = normalize(light.position - voxel_pos)
            D_x = dot(normalize(vec3(1,0,0)), light_dir)
            D_y = dot(normalize(vec3(0,1,0)), light_dir)
            D_z = dot(normalize(vec3(0,0,1)), light_dir)
            
            N_x = sign(normal.x)
            N_y = sign(normal.y)
            N_z = sign(normal.z)
            
            # Select dominant faces
            D_x_dom = max(D_x * N_x, 0.0) if N_x > 0 else max(-D_x * N_x, 0.0) # Simplified logic from source
            # Correct logic from source:
            # D_omega = max{D_omega, 0} if N_omega > 0 else max{-D_omega, 0}
            D_x_dom = max(D_x, 0.0) if N_x > 0 else max(-D_x, 0.0)
            D_y_dom = max(D_y, 0.0) if N_y > 0 else max(-D_y, 0.0)
            D_z_dom = max(D_z, 0.0) if N_z > 0 else max(-D_z, 0.0)
            
            W = normal * normal
            Li = light.intensity
            rho = albedo
            
            # Reflectance model
            V_r = Li * (rho / PI) * (W.x * D_x_dom + W.y * D_y_dom + W.z * D_z_dom)
            
            # Soft Shadow
            nu = 0.0
            ray_pos = voxel_pos
            ray_dir = light_dir
            for step in range(max_steps):
                ray_pos += ray_dir * step_size
                if voxel_exists(ray_pos):
                    kappa = 1.0 # Collision value
                    t = distance(voxel_pos, ray_pos)
                    nu = nu + (1 - nu) * kappa / t
                    if nu > 0.99: break
            
            occlusion = 1 - nu
            radiance += V_r * occlusion
            
        radiance += emission
        radianceVolume.write(voxel_pos, radiance)

# Step 3: Anisotropic Voxels (Compute Shader)
def generate_anisotropic_voxels(directionalVolumes, radianceVolume):
    for level in range(1, max_mipmap_levels):
        for voxel_pos in voxels_at_level(level):
            # Volumetric integration in depth from previous level
            values = []
            for direction in [pos_x, neg_x, pos_y, neg_y, pos_z, neg_z]:
                val = volumetric_integration(radianceVolume, voxel_pos, direction, level-1)
                values.append(val)
            
            # Store in directional volumes
            directionalVolumes[direction].write(voxel_pos, values)

# Step 4: Voxel Cone Tracing (Fragment Shader)
def fragment_shader(camera, radianceVolume, directionalVolumes, material):
    # Cone definition
    Co = camera.position
    Cd = normalize(material.normal) # Or view direction for screen-space
    theta = material.specular_exponent # Or diffuse spread
    
    c = vec3(0.0)
    alpha = 0.0
    
    t = 0.0
    while t < max_distance:
        d = 2 * t * tan(theta / 2)
        V_level = log2(d / V_size)
        
        # Determine which directional volumes to sample
        # Based on Cd signs, select 3 volumes
        selected_volumes = get_directional_volumes(Cd)
        
        # Sample and interpolate
        c2, alpha2 = sample_voxel_structure(selected_volumes, Co, d, V_level)
        
        # Front-to-back accumulation
        c = alpha * c + (1 - alpha) * alpha2 * c2
        alpha = alpha + (1 - alpha) * alpha2
        
        # Step size
        d_prime = beta * d
        t += d_prime
        
        if alpha > 0.99: break
        
    return c
```

## Operating characteristics
*   **Time Complexity:** The voxelization and illumination steps are performed in compute shaders, scaling with the number of voxels and lights. Cone tracing is performed per fragment, scaling with screen resolution and the number of cone steps (determined by $\beta$ and scene depth).
*   **Memory Complexity:** Requires storage for three voxelization textures, one radiance volume, six directional volumes (at half resolution), and a flag volume. The memory footprint is significant due to the 3D textures.
*   **Performance:** Enhanced performance in scenes with many light sources compared to forward rendering, as lighting is computed once per voxel rather than per fragment [S1, unofficial]. However, the deferred backend and multiple texture lookups during cone tracing can be expensive.
*   **Strengths:** Handles complex lighting effects like emissive materials, indirect shadows, and multiple light bounces. Anisotropic filtering provides more precise cone trace results [S1, unofficial]. Compatible with standard light types without shadow maps [S2, unofficial].
*   **Limitations:** Requires a deferred rendering backend. Quality depends on voxel resolution and mipmap levels. High $\beta$ values reduce quality, while low $\beta$ values reduce performance.

## Background
Deferred Voxel Shading was presented by Jose Villegas [S2, unofficial]. It expands upon rudimentary voxel cone tracing by merging it with deferred shading [S1, unofficial]. The approach was inspired by the work of Fredrik Präntare on voxel cone tracing shaders and the use of 3D textures for direct lighting data [S1, unofficial]. The technique aims to provide a real-time approximation of global illumination effects.
