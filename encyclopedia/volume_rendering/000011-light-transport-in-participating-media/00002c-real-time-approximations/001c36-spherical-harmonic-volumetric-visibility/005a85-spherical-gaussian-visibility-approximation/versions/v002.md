# Spherical Gaussian Visibility Approximation

Also called: SG Visibility Approximation, SG-based Visibility Approximation, Visibility Approximation via Spherical Gaussians

## Overview
Spherical Gaussian Visibility Approximation is a real-time technique for approximating the integral of visibility multiplied by a Spherical Gaussian (SG) lobe, yielding another SG [S1]. It sets itself apart from [Spherical Harmonic Volumetric Visibility](1225-spherical-harmonic-volumetric-visibility.md) by using SG basis functions instead of spherical harmonics, which allows for the preservation of the lobe's center and a simple scaling of amplitude to account for occlusion [S1]. It handles narrow specular lobes by sampling the specific specular SG to determine the visibility ratio [S1].

## How it works
**Inputs and Outputs:**
*   **Input:** A 3D location $\mathbf{x}$, a visibility function $V(\mathbf{x}, \boldsymbol{\omega}_i)$, and an incoming SG lobe defined by center $\boldsymbol{\xi}$, sharpness $\lambda$, and amplitude $\boldsymbol{\mu}$ [S1].
*   **Output:** An approximated SG lobe with the same center $\boldsymbol{\xi}$ and sharpness $\lambda$, but with a scaled amplitude $\gamma \boldsymbol{\mu}$ [S1].

**Data Structures:**
*   **SG Lobe:** Defined by parameters $(\boldsymbol{\xi}, \lambda, \boldsymbol{\mu})$ [S1]. The SG function follows the standard exponential form $G(\boldsymbol{\omega}_i; \boldsymbol{\xi}, \lambda, \boldsymbol{\mu}) = \boldsymbol{\mu} e^{\lambda (\boldsymbol{\omega}_i \cdot \boldsymbol{\xi} - 1)}$ [G].
*   **Visibility Query:** A function or data structure that returns $V(\mathbf{x}, \boldsymbol{\omega}_i)$ for a given direction [S1].

**Steps:**
1.  **Sample Directions:** Randomly sample $S$ directions $\boldsymbol{\omega}_k$ within the support of the SG lobe [S1]. The source specifies $S=32$ [S1].
2.  **Query Visibility:** For each sampled direction $\boldsymbol{\omega}_k$, query the visibility $V(\mathbf{x}, \boldsymbol{\omega}_k)$ [S1].
3.  **Compute Weighted Average:** Calculate the visibility ratio $\gamma$ using the weighted average of the queried visibility, weighted by the SG value at each sample direction [S1]:
    $$ \gamma = \frac {\sum ^S_{k=1} G(\boldsymbol{\omega }_k; \boldsymbol{\xi }, \lambda, \boldsymbol{\mu}) V(\mathbf{x}, \boldsymbol{\omega }_k)}{\sum ^S_{k=1} G(\boldsymbol{\omega }_k; \boldsymbol{\xi }, \lambda, \boldsymbol{\mu})} $$
    Since the SG amplitude $\boldsymbol{\mu}$ is common to all terms in the sum, it cancels out [S1, G].
4.  **Construct Output SG:** The approximated SG has center $\boldsymbol{\xi}$, sharpness $\lambda$, and amplitude $\gamma \boldsymbol{\mu}$ [S1].

**Pseudocode:**
```python
import math
import random

def spherical_gaussian_visibility_approximation(x, visibility_func, xi, lambda_val, mu, num_samples=32):
    """
    Approximates the convolution of visibility with an SG lobe.
    
    Args:
        x: 3D location.
        visibility_func: Function V(x, omega) returning visibility in [0, 1].
        xi: SG center direction (unit vector).
        lambda_val: SG sharpness parameter.
        mu: SG amplitude.
        num_samples: Number of random samples S (default 32).
        
    Returns:
        gamma_mu: The scaled amplitude of the output SG.
    """
    numerator = 0.0
    denominator = 0.0
    
    for _ in range(num_samples):
        # Sample a random direction omega_k on the sphere
        # Uniform sampling on the sphere is a standard assumption [G].
        omega_k = random_direction_on_sphere()
        
        # Calculate SG weight for this direction
        # G(omega_k) = exp(lambda * (omega_k . xi - 1))
        # Amplitude mu cancels out in the ratio, so we omit it [G]
        dot_product = dot(omega_k, xi)
        sg_weight = math.exp(lambda_val * (dot_product - 1.0))
        
        # Query visibility
        v = visibility_func(x, omega_k)
        
        numerator += sg_weight * v
        denominator += sg_weight
        
    if denominator == 0:
        return 0.0  # Guard against division by zero [G]
        
    gamma = numerator / denominator
    return gamma * mu

def random_direction_on_sphere():
    """Generates a uniformly random unit vector on the sphere [G]."""
    u = random.uniform(0, 1)
    v = random.uniform(0, 1)
    theta = 2 * math.pi * u
    phi = math.acos(2 * v - 1)
    x = math.sin(phi) * math.cos(theta)
    y = math.sin(phi) * math.sin(theta)
    z = math.cos(phi)
    return (x, y, z)

def dot(a, b):
    """Standard dot product for two 3D vectors [G]."""
    return a[0]*b[0] + a[1]*b[1] + a[2]*b[2]
```

**Parameters:**
*   $S$: Number of random samples. Typical value: 32 [S1].

**Edge Cases and Pitfalls:**
*   **Specular Components:** For narrow specular lobes, the visibility ratio $\gamma$ must be determined by sampling the specular SG specifically to accurately approximate the final integral [S1].
*   **Denominator Zero:** If the denominator in the $\gamma$ calculation is zero (e.g., if all sampled directions have zero SG weight), the result is undefined. The pseudocode handles this by returning 0.0 [G].

## Subtopics

### [Spherical Gaussian Light-Field and Visibility Representation](16742-spherical-gaussian-light-field-and-visibility-representation.md)
A rendering technique that represents light fields and illumination-weighted environment visibility as sets of Spherical Gaussians (SGs), optimized via neural network backpropagation and stored in 2D textures for hardware-accelerated lookups. It sets itself apart from its parent [Spherical Gaussian Visibility Approximation](16679-spherical-gaussian-visibility-approximation.md) by treating SG parameters (axis and sharpness) as learnable degrees of freedom rather than fixed analytical projections, allowing for fewer lobes and higher quality in static scenes.

## Operating characteristics
*   **Time Complexity:** The core approximation step requires $O(S)$ visibility queries, where $S=32$ [S1].
*   **Strengths:** Efficient real-time approximation; preserves lobe center; scales amplitude for occlusion [S1].
*   **Limitations:** Approximation quality depends on the sample count $S$ [S1].

## Background
The method is used in inverse rendering frameworks to efficiently compute visibility integrals for indirect illumination [S1].
