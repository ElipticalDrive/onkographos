# Two-Bounce Indirect Illumination

Also called: Glossy Reflections via Cone Tracing, Real-time Indirect Illumination Algorithm, Voxel Cone Tracing Pipeline

## Overview
A three-step GPU-based algorithm for computing two light bounces of indirect illumination for Lambertian and glossy materials at interactive framerates [S1]. It differs from standard voxel cone tracing by explicitly capturing incoming radiance from dynamic light sources into a sparse voxel octree and filtering it using a view-dependent Gaussian-Lobes representation, enabling efficient approximation of glossy reflections and color bleeding without static caches [S1].

## How it works
The method computes indirect illumination using a two-step approach: capturing incoming radiance from light sources in octree leaves, filtering/distributing it over octree levels, and performing approximate cone tracing for light transport [S1].

**Inputs:**
*   Sparse voxel octree hierarchy [S1].
*   Dynamic light sources (position, color, intensity) [S1].
*   Camera position and view vector [G].
*   Surface material properties (diffuse color, specular exponent) [S1].

**Outputs:**
*   Final color for each visible surface fragment, combining direct and indirect illumination [S1].

**Data Structures:**
*   **Sparse Voxel Octree:** Stores incoming radiance (energy and direction) in leaves, filtered to higher levels using a compact Gaussian-Lobes representation [S1].
*   **Light-View Map:** Rasterization buffer storing world positions and colors for photons emitted by light sources [S1].

**Steps:**

1.  **Capture Incoming Radiance:** Rasterize the scene from each dynamic light source's perspective to generate a light-view map containing world positions and fragment colors [S1]. Each pixel represents a photon bouncing off the visible surface [S1]. Splat these photons into the leaves of the sparse voxel octree, storing their energy and incoming direction [S1].
2.  **Filter and Distribute Radiance:** Filter the incoming radiance values from the octree leaves into higher levels (mipmap) using a compact Gaussian-Lobes representation to store the filtered distribution of incoming light directions [S1]. Perform this filtering in parallel via a screen-space quad-tree analysis [S1]. The filtering scheme treats the Normal Distribution Function (NDF) and the Bidirectional Reflectance Distribution Function (BRDF) in a view-dependent manner [S1].
3.  **Final Gathering:** Render the scene from the camera and use deferred shading to identify surface points requiring indirect illumination [S1]. For each point, perform final gathering by casting several cones over the hemisphere to query the distributed illumination in the octree [S1]. Combine direct and indirect illumination to compute the final color [S1].

**Parameters and Formulas:**
*   **Diffuse Estimation:** Typically five large cones are cast to estimate diffuse energy from the scene [S1].
*   **Specular Estimation:** A tight cone is cast in the direction reflected with respect to the viewpoint to capture the specular component [S1].
*   **Specular Cone Aperture:** The aperture of the specular cone is derived from the material's specular exponent $n$ [S1]. The cone half-angle $\alpha$ is typically computed as $\alpha = \arctan(1/\sqrt{n})$ to align with the glossy lobe width [G].

**Pseudocode:**

```python
def compute_two_bounce_indirect_illumination(scene, lights, camera, octree, materials):
    # Step 1: Capture incoming radiance
    for light in lights:
        light_view_map = scene.rasterize_from_light(light.position, light.direction)
        for pixel in light_view_map:
            photon_energy = pixel.color * light.intensity
            photon_direction = normalize(light.position - pixel.world_position)
            octree.splat_leaf(pixel.world_position, photon_energy, photon_direction)

    # Step 2: Filter radiance into octree levels
    octree.filter_gaussian_lobes()

    # Step 3: Final gathering from camera
    for surface_point in scene.visible_surfaces:
        indirect_color = vec3(0.0)

        # Estimate diffuse energy with 5 large cones
        for i in range(5):
            cone_direction = uniform_hemisphere_sample(surface_point.normal)
            cone_aperture = 0.5  # Large cone angle for diffuse estimation [G]
            radiance = octree.query_cone(cone_direction, cone_aperture)
            indirect_color += radiance * surface_point.diffuse_color

        # Estimate specular energy with tight cone
        view_vector = normalize(camera.position - surface_point.position)
        reflect_direction = reflect(-view_vector, surface_point.normal)
        specular_aperture = arctan(1.0 / sqrt(surface_point.specular_exponent))
        radiance = octree.query_cone(reflect_direction, specular_aperture)
        indirect_color += radiance * surface_point.specular_color

        surface_point.final_color += indirect_color

def uniform_hemisphere_sample(normal):
    # Standard uniform hemisphere sampling [G]
    u = random()
    v = random()
    tangent = normalize(cross(normal, vec3(0.0, 1.0, 0.0)))
    bitangent = cross(normal, tangent)
    x = 2.0 * u - 1.0
    y = 2.0 * v - 1.0
    dir = tangent * x + bitangent * y
    if dot(dir, normal) < 0.0:
        dir = -dir
    return normalize(dir)
```

## Subtopics

### [Online Indirect Illumination via Importance Sampling](15343-online-indirect-illumination-via-importance-sampling.md)
Computes indirect illumination in real-time by importance sampling rays near the reflective direction of the view vector. It differs from standard voxel cone tracing by focusing on specular surfaces where indirect light primarily originates from view-angle reflections, allowing efficient approximation with fewer samples. Choose this method for dynamic scenes with directional lighting where caching-based global illumination fails.

## Operating characteristics
*   **Time Complexity:** Interactive framerates are achieved due to the parallel nature of the octree filtering and the limited number of cones (typically five large cones plus one tight specular cone) per pixel [S1].
*   **Memory Complexity:** Uses a sparse voxel octree, which allows for high precision with lower memory usage compared to dense grids, storing only incoming radiance and occlusion information [S1].
*   **Strengths:** Handles dynamic scenes and dynamic light sources effectively. Supports glossy reflections and color bleeding. View-dependent filtering improves accuracy for anisotropic or glossy materials [S1].
*   **Limitations:** Approximate nature of cone tracing may introduce artifacts. The method is optimized for Phong-like BRDFs, though it supports low-energy/low-frequency and high-energy/high-frequency components of arbitrary material BRDFs [S1].
*   **When to use:** Real-time rendering of scenes with dynamic lighting and glossy materials where global illumination effects like color bleeding are desired [S1].
*   **When not to use:** Scenes requiring exact global illumination or where performance is critical and approximate results are unacceptable [S1].

## Background
The method was introduced in the paper "Interactive Indirect Illumination Using Voxel Cone Tracing" [S1]. It addresses the limitations of caching-based global illumination in dynamic scenes by computing inter-reflections on the fly rather than storing them in static caches [S1]. The approach adapts voxel cone tracing and photon mapping techniques for real-time GPU execution [S1].
