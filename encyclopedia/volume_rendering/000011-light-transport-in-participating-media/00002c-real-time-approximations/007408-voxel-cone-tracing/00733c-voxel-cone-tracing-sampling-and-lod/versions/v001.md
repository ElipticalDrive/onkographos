# Voxel Cone Tracing Sampling and LOD

Also called: VCT LOD Sampling, Voxel Cone Tracing Sampling

## Overview
This method defines the sampling strategy and Level of Detail (LOD) selection for the cone tracing phase of Voxel Cone Tracing. It solves the problem of efficiently accumulating indirect illumination from a sparse voxel octree by adapting the voxel resolution to the cone's geometry. Unlike sibling methods that may use fixed-step ray casting or specialized anisotropic filtering, this approach scales the mipmap level based on the cone's base diameter, using trilinear interpolation to smooth transitions between integer LOD levels [S1, unofficial].

## How it works
**Inputs:**
*   Cone origin (tip) position and direction.
*   Cone base diameter at the current step.
*   Voxel data structure (octree with mipmaps).
*   Maximum stepping distance.
*   Occlusion threshold for early termination.

**Outputs:**
*   Accumulated indirect color $c$.
*   Accumulated occlusion $a$.

**Data Structures:**
*   **Voxel Mipmaps:** A hierarchy of voxel grids where each level $L$ represents a coarser sampling of the scene. Level 0 is the finest resolution. Higher levels contain averaged data from lower levels.
*   **Voxel Value:** A vector $(R, G, B, \alpha)$ or similar. Solid occlusive objects contribute non-zero color values ($R,G,B \ge 0$), while empty space contributes zero color ($R,G,B = 0,0,0$) [S1, unofficial].

**Parameters:**
*   **Max Stepping Distance:** The maximum distance the cone trace will proceed. Not given in the sources.
*   **Occlusion Threshold:** The accumulated occlusion value $a$ at which tracing stops. Not given in the sources.

**Algorithm:**
1.  Initialize accumulated color $c = (0, 0, 0)$ and accumulated occlusion $a = 0$.
2.  Determine the current step position along the cone.
3.  Calculate the cone's base diameter $d$ at the current step.
4.  Compute the LOD index $L$ based on $d$. The sources state that flexible LOD scales with the cone's base diameter, using lower mipmap levels (fewer, bigger, averaged voxels) as the diameter increases [S1, unofficial].
5.  Sample the voxel at the current step position using the computed LOD $L$.
    *   If $L$ is not an integer, use GPU trilinear filtering to interpolate between the two relevant mipmap levels based on the fractional part of $L$ [S1, unofficial].
    *   Let the sampled color be $c_2$ and the sampled occlusion be $a_2$.
6.  Update the accumulated values using front-to-back volumetric compositing:
    $$c += (1 - a) * a_2 * c_2$$
    $$a += (1 - a) * a_2$$
    Here, $c$ is the accumulated color, $a$ is the accumulated occlusion, $a_2$ is the current step's occlusion, and $c_2$ is the current step's color [S1, unofficial].
7.  Check termination criteria:
    *   If the maximum stepping distance is reached, stop.
    *   If the accumulated occlusion $a$ reaches a significant threshold (indicating the cone is blocked by solid objects), stop.
8.  If not terminated, advance to the next step and repeat from step 2.

**Pitfalls:**
*   **Voxel Color Averaging:** Solid occlusive objects contribute non-zero colors, while empty space dilutes with zero color. The product $a_2 * c_2$ correctly handles this averaging, ensuring that empty space does not incorrectly contribute to the indirect light [S1, unofficial].
*   **Precision:** Trilinear filtering requires careful handling of fractional LOD values to avoid artifacts at mipmap boundaries.

**Pseudocode:**
```python
def voxel_cone_tracing_sampling_and_loD(cone_origin, cone_direction, cone_base_diameter_at_tip, voxel_data, max_steps, occlusion_threshold):
    """
    Performs Voxel Cone Tracing with adaptive LOD sampling.
    
    Args:
        cone_origin: Vec3, origin of the cone.
        cone_direction: Vec3, direction of the cone.
        cone_base_diameter_at_tip: float, diameter of the cone at its origin.
        voxel_data: VoxelData, structure containing mipmap levels.
        max_steps: int, maximum number of steps.
        occlusion_threshold: float, threshold to stop tracing.
        
    Returns:
        Vec3, accumulated indirect color.
    """
    accumulated_color = Vec3(0.0, 0.0, 0.0)
    accumulated_occlusion = 0.0
    
    # Step size is not explicitly defined in sources, assumed to be derived from cone geometry or fixed.
    # [G] In typical implementations, step size is proportional to the cone diameter or a fixed fraction.
    step_size = cone_base_diameter_at_tip * 0.5 
    
    current_pos = cone_origin
    current_diameter = cone_base_diameter_at_tip
    
    for step in range(max_steps):
        # Calculate LOD based on current cone diameter
        # [G] The exact formula for LOD from diameter is not provided. 
        # Typically: LOD = log2(diameter / voxel_size_at_level_0)
        lod = calculate_lod_from_diameter(current_diameter, voxel_data)
        
        # Sample voxel at current position with calculated LOD
        # [G] Trilinear filtering is handled by the hardware if using texture lookups.
        # If manual, interpolate between floor(lod) and ceil(lod) levels.
        sampled_color, sampled_occlusion = sample_voxel(voxel_data, current_pos, lod)
        
        # Front-to-back accumulation
        # c += (1 - a) * a2 * c2
        # a += (1 - a) * a2
        accumulated_color += (1.0 - accumulated_occlusion) * sampled_occlusion * sampled_color
        accumulated_occlusion += (1.0 - accumulated_occlusion) * sampled_occlusion
        
        # Check termination
        if accumulated_occlusion >= occlusion_threshold:
            break
            
        # Advance step
        # [G] Cone diameter grows linearly with distance.
        current_pos += cone_direction * step_size
        current_diameter += step_size # Assuming cone expands by step_size per step
        
    return accumulated_color

def calculate_lod_from_diameter(diameter, voxel_data):
    # [G] Placeholder for the specific LOD calculation formula.
    # The sources state LOD scales with cone base diameter.
    # A common approach is: LOD = log2(diameter / base_voxel_size)
    # This is marked as [G] because the exact formula is not in the sources.
    base_voxel_size = voxel_data.get_base_voxel_size()
    if base_voxel_size <= 0:
        return 0.0
    return log2(diameter / base_voxel_size)

def sample_voxel(voxel_data, position, lod):
    # [G] Placeholder for voxel sampling with trilinear filtering.
    # The sources state that GPU trilinear filtering is used for smooth sampling
    # between mipmap levels when LOD is between integer levels.
    lod_floor = floor(lod)
    lod_ceil = ceil(lod)
    frac = lod - lod_floor
    
    color_floor, occ_floor = voxel_data.sample(position, lod_floor)
    color_ceil, occ_ceil = voxel_data.sample(position, lod_ceil)
    
    # Trilinear interpolation
    color = lerp(color_floor, color_ceil, frac)
    occ = lerp(occ_floor, occ_ceil, frac)
    
    return color, occ
```

## Operating characteristics
*   **Time Complexity:** Depends on the number of steps and the cost of voxel sampling. The adaptive LOD reduces the number of samples needed for large cones, improving efficiency [S1, unofficial].
*   **Memory Complexity:** Requires storing multiple mipmap levels of the voxel data. The sources do not specify the exact memory overhead.
*   **Strengths:** Efficient approximation of indirect light from large amounts of geometry by combining smaller voxels into larger, averaged ones through mipmapping [S1, unofficial]. Trilinear filtering provides smooth transitions between LOD levels [S1, unofficial].
*   **Limitations:** Relies on the assumption that voxel color averaging correctly represents the scene's lighting, which may not hold for all materials or lighting conditions. The sources do not provide measured performance metrics.

## Background
This method is part of the Voxel Cone Tracing technique for real-time global illumination. It leverages the flexibility of GPU-based trilinear filtering and mipmap LOD selection to optimize the cone tracing process. The approach is described in the context of evaluating Voxel Cone Tracing for real-time applications [S1, unofficial].
