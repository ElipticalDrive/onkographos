# Cinematic Quality Volumetric Clouds

Also called: High-quality aerial perspective, Per-pixel quality clouds, Ray Marched Clouds, Volumetric Cloud Rendering

## Overview
Cinematic Quality Volumetric Clouds is a high-fidelity rendering technique that generates volumetric clouds by ray marching through a 3D Perlin noise field and applying Beer's law for light absorption [S1, unofficial][S2]. It solves the problem of visual fidelity in cloud rendering by bypassing the resolution and optimization constraints of real-time approximations in favor of per-pixel ray tracing [S2]. Unlike its siblings, which prioritize frame rate through spatial discretization or precomputation, this method achieves cinematic quality by enabling high-quality aerial perspective, per-sample atmospheric transmittance, and multi-scattering approximations, at the cost of significant performance overhead [S2]. It builds on [Real-time approximations](36-real-time-approximations.md) and contrasts with [Multiple Scattering Approximation via Light Volume Lookup](1188-multiple-scattering-approximation-via-light-volume-lookup.md), [Spherical Harmonic Volumetric Visibility](1225-spherical-harmonic-volumetric-visibility.md), [Voxel Cone Tracing](1454-voxel-cone-tracing.md), [Froxel-based Volumetric Rendering](1919-froxel-based-volumetric-rendering.md), [Hardware Ray Tracing Global Illumination](3648-hardware-ray-tracing-global-illumination.md), [Volumetric Light Scattering via Froxel Clustering](4460-volumetric-light-scattering-via-froxel-clustering.md), [Voxel Cone Tracing Global Illumination](6037-voxel-cone-tracing-global-illumination.md), [Light Beam Tracing](10717-light-beam-tracing.md), [Precomputed Radiance Transfer](13182-precomputed-radiance-transfer.md), [Flax Volumetric Fog](13880-flax-volumetric-fog.md), and [Voxel Number Map with LUT for Translucent Rendering](14179-voxel-number-map-with-lut-for-translucent-rendering.md).

## How it works
The method renders volumetric clouds by ray marching through a 3D Perlin noise field to determine density, using Beer's law for light absorption [S1, unofficial]. The implementation relies on specific engine configurations and material expressions to achieve the cinematic quality tier [S2].

### Inputs and Outputs
*   **Inputs:**
    *   Camera position and view direction.
    *   3D Perlin noise field parameters (density, noise scale, opacity) [S1, unofficial].
    *   Directional Light shadow dynamic distance [S2].
    *   Ground albedo color [S2].
    *   Sky Atmosphere parameters (Fast Sky LUT resolution) [S2].
*   **Outputs:**
    *   Final color buffer with volumetric cloud shading, shadows, and aerial perspective [S2].

### Data Structures
The implementation relies on the following engine-specific data structures and console variables:
*   **Volumetric Cloud Component:** Contains properties for `Trace Sample Count Scale`, `Use per Sample Atmospheric Light Transmittance`, and `Ground Albedo` [S2].
*   **Directional Light Component:** Contains `Cloud Shadow Ray Sample Count Scale` and `Shadow Dynamic Distance` [S2].
*   **Volume Cloud Material:** Uses the `Volumetric Advanced Material Output` expression to handle ground contribution and multi-scattering adjustments [S2].
*   **Console Variables:**
    *   `r.VolumetricRenderTarget`: Controls the rendering target quality mode [S2].
    *   `r.VolumetricCloud.HighQualityAerialPerspective`: Enables high-quality ray tracing for aerial perspective [S2].
    *   `r.SkyAtmosphere.FastSkyLUT.Width` and `.Height`: Controls the resolution of the sky atmosphere LUT [S2].
    *   `r.VolumetricCloud.ViewRaySampleMaxCount`, `r.VolumetricCloud.SampleMinCount`, `r.VolumetricCloud.DistanceToSampleMaxCount`: Control ray sampling limits [S2].

### Steps
1.  **Initialize Cinematic Mode:** Set `r.VolumetricRenderTarget` to `0` to enable the quality mode that supports cinematic results [S2].
2.  **Enable High-Quality Aerial Perspective:** Set `r.VolumetricCloud.HighQualityAerialPerspective` to `1` to force the use of high-quality ray tracing for aerial perspective instead of low-resolution Look-Up Tables (LUTs) [S2].
3.  **Configure Sky Atmosphere LUT:** Set `r.SkyAtmosphere.FastSkyLUT.Width` and `r.SkyAtmosphere.FastSkyLUT.Height` to `256` (or higher) to compensate for the low default resolution of cloud shadow quality [S2]. Optionally, set `r.SkyAtmosphere.FastSkyLUT` to `0` to disable the optimization entirely for fewer artifacts, though this is slower [S2].
4.  **Increase Ray Sample Counts:** On the **Volumetric Cloud Component**, increase the `Trace Sample Count Scale` for View, Reflections, and Shadows [S2]. On the **Directional Light Component**, increase the `Cloud Shadow Ray Sample Count Scale` [S2]. Ensure `Shadow Dynamic Distance` on the Directional Light is large enough to effectively shadow large objects onto clouds [S2]. Adjust console variables `r.VolumetricCloud.ViewRaySampleMaxCount`, `r.VolumetricCloud.SampleMinCount`, and `r.VolumetricCloud.DistanceToSampleMaxCount` to increase sample counts further if needed [S2].
5.  **Enable Per-Sample Atmospheric Transmittance:** On the Volumetric Cloud Component, enable `Use per Sample Atmospheric Light Transmittance` to apply atmosphere transmittance per ray sample instead of using the Directional Light's global transmittance [S2].
6.  **Configure Cloud Material:** In the Volume Cloud Material, use the `Volumetric Advanced Material Output` expression [S2]. Enable `Ground Contribution` and specify the `Ground Albedo` on the Volumetric Cloud Component to light the bottom of cloud layers from below with respect to sunlight and atmosphere [S2].
7.  **Simulate Multiple Scattering:** Set the number of `Multi Scattering Approximation Octaves` to simulate light scattering through the cloud volume, up to a maximum value of `2` [S2]. Adjust `Multi Scattering Contribution` and `Multi Scattering Occlusion` values on the `Volumetric Advanced Output` expression to compensate for the increased light scattering introduced by additional octaves [S2].
8.  **Configure Shadows:** On Atmospheric Lights, set `Cast Cloud Shadow` to cast shadows from clouds onto scene elements and into the atmosphere [S2]. Set `Cast Shadows on Clouds` to cast shadows from opaque objects onto cloud layers [S2].

### Pseudocode
The following pseudocode represents the configuration workflow required to enable Cinematic Quality Volumetric Clouds, based on the engine-specific commands and properties described in the sources [S2].

```python
def configure_cinematic_cloud_quality():
    config = {}
    # Step 1: Set base rendering target mode to 0 (Quality/Cinematic start)
    config["r.VolumetricRenderTarget"] = 0

    # Step 2: Enable high-quality aerial perspective (ray tracing instead of LUTs)
    config["r.VolumetricCloud.HighQualityAerialPerspective"] = 1

    # Step 3: Configure Sky Atmosphere LUT resolution for better shadow definition
    # Recommended starting value for both width and height
    config["r.SkyAtmosphere.FastSkyLUT.Width"] = 256
    config["r.SkyAtmosphere.FastSkyLUT.Height"] = 256

    # Optional: Disable FastSkyLUT optimization for fewer artifacts (slower)
    # config["r.SkyAtmosphere.FastSkyLUT"] = 0

    # Step 4: Configure Volumetric Cloud Component
    # Note: Engine-specific component retrieval is required
    cloud_component = {}
    cloud_component["trace_sample_count_scale_view"] = 2.0
    cloud_component["trace_sample_count_scale_reflections"] = 2.0
    cloud_component["trace_sample_count_scale_shadows"] = 2.0
    cloud_component["use_per_sample_atmospheric_light_transmittance"] = True
    cloud_component["ground_albedo"] = (0.2, 0.3, 0.1)
    cloud_component["multi_scattering_approximation_octaves"] = 2
    cloud_component["multi_scattering_contribution"] = 0.5
    cloud_component["multi_scattering_occlusion"] = 0.5

    # Step 5: Configure Directional Light (Atmospheric Light)
    # Note: Engine-specific light retrieval is required
    light_component = {}
    light_component["cloud_shadow_ray_sample_count_scale"] = 2.0
    light_component["shadow_dynamic_distance"] = 10000.0
    light_component["cast_cloud_shadow"] = True
    light_component["cast_shadows_on_clouds"] = True

    # Step 6: Configure Volume Cloud Material
    # Note: Engine-specific material retrieval is required
    material_config = {}
    material_config["enable_ground_contribution"] = True

    # Step 7: Adjust global sample limits via console variables if needed
    config["r.VolumetricCloud.ViewRaySampleMaxCount"] = 100
    config["r.VolumetricCloud.SampleMinCount"] = 10
    config["r.VolumetricCloud.DistanceToSampleMaxCount"] = 50

    # Step 8: Configure Reflection and Shadow Reflection samples if needed
    config["r.VolumetricCloud.ReflectionRaySampleMaxCount"] = 100
    config["r.VolumetricCloud.Shadow.ReflectionRaySampleMaxCount"] = 100

    return config, cloud_component, light_component, material_config
```

### Parameters and Typical Values
*   **`r.VolumetricRenderTarget`**: Set to `0` for cinematic quality [S2].
*   **`r.VolumetricCloud.HighQualityAerialPerspective`**: Set to `1` [S2].
*   **`r.SkyAtmosphere.FastSkyLUT.Width/Height`**: Recommended starting value `256` [S2].
*   **`Multi Scattering Approximation Octaves`**: Maximum value `2` [S2].
*   **`Trace Sample Count Scale`**: Must be increased from default; exact value depends on performance budget [S2].
*   **`Cloud Shadow Ray Sample Count Scale`**: Must be increased from default [S2].
*   **`Shadow Dynamic Distance`**: Must be large enough to cover the scene; exact value depends on scene scale [S2].

### Edge Cases and Pitfalls
*   **Performance Impact:** The cinematic quality workflow bypasses engine optimizations for real-time rendering and can significantly impact performance [S2].
*   **Shadow Definition:** The default resolution of the cloud's shadow quality is low; failing to increase `r.SkyAtmosphere.FastSkyLUT.Width` and `.Height` results in blurry shadows [S2].
*   **Shadow Distance:** If `Shadow Dynamic Distance` on the Directional Light is not large enough, large objects will not cast shadows onto clouds effectively [S2].
*   **Multi-Scattering Compensation:** Increasing multi-scattering octaves increases light scattering through the volume; failing to adjust `Multi Scattering Contribution` and `Multi Scattering Occlusion` will result in incorrect lighting [S2].
*   **Ground Contribution:** Ground lighting is only applied if `Ground Contribution` is enabled in the material and `Ground Albedo` is specified on the component [S2].

## Subtopics

### Volumetric Render Target Quality Modes
Scalable quality modes defined by the console variable `r.VolumetricRenderTarget.Mode` that control the resolution and reactivity of cloud tracing [S2].
*   **Mode 0:** Recommended for quality. Supports fast-paced gameplay and ground-to-space transitions [S2]. Traces at quarter resolution, reconstruction at half, upsample on screen at full [S2]. Supports cloud intersections with opaque surfaces [S2].
*   **Mode 1:** Balances quality and performance for ground views [S2]. More expensive than Mode 0. Traces at half resolution, reconstruction and upsample on screen at full [S2]. Supports cloud intersections with opaque surfaces [S2].
*   **Mode 2:** Less reactive, full resolution look [S2]. Fast to trace, high resolution, but does NOT support cloud intersection with opaque meshes [S2]. For ground views [S2].

### Cinematic Quality Workflow
An advanced workflow that bypasses engine optimizations for real-time rendering to achieve cinematic quality, significantly impacting performance [S2]. It starts with `r.VolumetricRenderTarget` set to `0` and requires increasing sample count scales on the Volumetric Cloud and Directional Light components, as well as adjusting Sky Atmosphere LUT resolutions [S2].

### Dynamic Cloud Rendering with SRT and MLTDB
A simplified method for rendering dynamic clouds using two new data structures: Shadow Relation Table (SRT) and Metaball Lighting Texture Database (MLTDB) [S3]. It uses projected metaball images with various densities and view angles, utilizing a two-pass rendering approach on an octree structure [S3]. The first rendering pass illuminates each voxel in the octree [S3]. The second step performs a back-to-front traversal of the octree, selecting a billboard with the most suited texture from the MLTDB for each node [S3]. The SRT is a 2D grid structure that aids in determining the input illumination for every voxel [S3]. The MLTDB maintains a database of 32 × 32 projected metaball images with various densities and view angles to aid fast computation of scattering parameters [S3].

## Operating characteristics
*   **Performance:** Significantly impacts performance compared to real-time approximations due to high sample counts and bypassed optimizations [S2].
*   **Quality:** Provides "cinematic" or "per-pixel" quality with high-fidelity aerial perspective, accurate shadows, and multi-scattering effects [S2].
*   **Reactivity:** Mode 0 and 1 support cloud intersections with opaque surfaces and are reactive to camera movement (including ground-to-space transitions) [S2]. Mode 2 is less reactive and does not support opaque mesh intersections [S2].
*   **Hardware Requirements:** Requires sufficient GPU power to handle increased ray sample counts and LUT resolutions [S2].
*   **Use Cases:** Best for cinematic sequences, pre-rendered content, or high-end hardware where visual fidelity is prioritized over frame rate [S2]. Not suitable for real-time gameplay on constrained hardware [S2].

## Background
The method is implemented in Unreal Engine 5.8 as part of the Volumetric Cloud Component and Sky Atmosphere systems [S2]. It builds upon the principles of ray marching through noise fields for density generation [S1, unofficial] and Beer's law for absorption [S1, unofficial]. The specific configuration for "Cinematic Quality" is an advanced workflow provided by Epic Games to achieve high-fidelity results by disabling certain real-time optimizations [S2].
