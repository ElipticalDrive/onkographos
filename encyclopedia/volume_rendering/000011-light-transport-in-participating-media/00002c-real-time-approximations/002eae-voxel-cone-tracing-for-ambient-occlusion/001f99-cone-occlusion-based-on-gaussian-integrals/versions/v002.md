# Cone Occlusion based on Gaussian Integrals

Also called: Cone Occlusion, Cone Shadow, RC1PConeTracingDirOcclusionShading

## Overview
Cone Occlusion based on Gaussian Integrals is a volume rendering shading technique that approximates light occlusion and shadowing by tracing cones through a voxel volume and integrating extinction coefficients using Gaussian distributions [S1, unofficial]. It supports two distinct modes: Cone Occlusion for self-shadowing (ambient occlusion) and Cone Shadow for external light source shadows [S1, unofficial].

## How it works
### Inputs and Outputs
*   **Inputs:** Extinction coefficient volume texture (3D texture), camera matrices (Eye, View, Projection), FOV tangent, aspect ratio, occlusion/shadow flags, integration step size, Phong shading flags, Blinn-Phong coefficients ($K_{ambient}, K_{diffuse}, K_{specular}, N_{shininess}$), light source positions, and cone tracing parameters [S1, unofficial].
*   **Outputs:** Output image texture containing the screen-space shading result [S1, unofficial].

### Data Structures
The implementation relies on a `ConeGaussianSampler` structure to manage cone parameters [S1, unofficial]. Key fields include:
*   `cone_half_angle`: Aperture half-angle in degrees.
*   `initial_step`: Initial gap step for cone sampling.
*   `d_sigma`: Cone sample separation multiplier.
*   `r_sigma`: Minimum circular cone section radius.
*   `covered_distance`: Maximum distance the cone covers.
*   `max_gaussian_packing`: Enum indicating the number of Gaussian sections packed into the cone (e.g., `_1`, `_3`) [S1, unofficial].

### Parameters and Initialization
1.  **Step Size Calculation:** The integration step size $m\_u\_step\_size$ is initialized based on the volume scale $sv = (sv.x, sv.y, sv.z)$:
    $$ m\_u\_step\_size = \frac{0.5}{\sqrt{3.0}} \sqrt{sv.x^2 + sv.y^2 + sv.z^2} $$
    [S1, unofficial]
2.  **Cone Occlusion Mode Parameters:**
    *   `cone_half_angle`: Default 20.0 degrees [S1, unofficial].
    *   `initial_step`: Default $3.0 \times \sigma_0$, where $\sigma_0$ is the base level Gaussian sigma from the extinction volume generation [S1, unofficial].
    *   `covered_distance`: Set to $0.50 \times \text{volume diagonal}$ [S1, unofficial].
    *   `max_gaussian_packing`: `_3` [S1, unofficial].
3.  **Cone Shadow Mode Parameters:**
    *   `cone_half_angle`: Default 0.5 degrees [S1, unofficial].
    *   `covered_distance`: Set to $0.75 \times \text{volume diagonal}$ [S1, unofficial].
    *   `max_gaussian_packing`: `_1` [S1, unofficial].
4.  **Light Cache:** A pre-computed light cache texture with resolution $32 \times 32 \times 32$ is used for shading coefficients [S1, unofficial].

### Algorithm Steps
1.  **Initialization:** Generate the extinction coefficient volume and cone samples. Estimate the initial integration step size using the volume diagonal [S1, unofficial].
2.  **Uniform Setup:** Bind camera matrices (Eye, View, Projection), FOV tangent, aspect ratio, occlusion/shadow flags, step size, Phong shading flags, Blinn-Phong coefficients, and light source positions [S1, unofficial].
3.  **Compute Shader Dispatch:** Clear the output texture, bind the rendering shader and output image texture, and dispatch compute shader groups based on screen resolution or multi-scaling mode [S1, unofficial].
4.  **Per-Pixel Shading:** For each pixel, determine the surface point $p$ and normal. Trace a cone from $p$ along the relevant direction (hemisphere normal for occlusion, light direction for shadow). Sample the extinction coefficient volume along the cone's path. Integrate the extinction using Gaussian weights defined by the cone's geometry and `max_gaussian_packing` setting. Compute the final color using the Blinn-Phong model modulated by the calculated visibility/occlusion factor [S1, unofficial].

### Pseudocode
```python
def cone_occlusion_gaussian_integrate(extinction_vol, camera_matrices, light_pos, mode, params):
    # 1. Initialization
    if extinction_vol is None:
        return False
    step_size = 0.5 / sqrt(3.0) * sqrt(params.vol_scale.x**2 + params.vol_scale.y**2 + params.vol_scale.z**2)
    
    # 2. Uniform Setup
    bind_uniforms(camera_matrices, params.fov_tangent, params.aspect_ratio, mode, step_size, params.phong_flags, params.blinn_phong, light_pos)
    
    # 3. Dispatch Compute Shader
    clear_output_texture()
    bind_shader_and_output(rendering_shader, output_texture)
    dispatch_compute_groups(screen_resolution)
    
    # 4. Per-Pixel Shading
    for pixel in screen_resolution:
        p, normal = get_surface_point_and_normal(pixel)
        direction = normal if mode == "occlusion" else normalize(light_pos - p)
        cone_params = params.occlusion_params if mode == "occlusion" else params.shadow_params
        total_extinction = 0.0
        # The sources do not specify the exact Gaussian weighting or cone sampling function [S1, unofficial].
        for i in range(cone_params.max_gaussian_packing):
            sample_pos = p + direction * (i * cone_params.initial_step)
            sample_radius = cone_params.r_sigma + i * cone_params.d_sigma
            # Implement cone extinction sampling and Gaussian weighting here
            total_extinction += 0.0
        visibility = exp(-total_extinction * step_size)
        color = apply_blinn_phong(p, normal, light_pos, visibility, params.blinn_phong)
        write_to_output_texture(pixel, color)
    return True
```

### Edge Cases and Pitfalls
*   **Null Volume:** If the current volume texture is null, the initialization process fails and returns false [S1, unofficial].

## Background
The method is implemented in the `cppvolrend` project, a volume rendering application developed using C++ and GLSL [S1, unofficial]. It implements techniques from "Directional Ambient Occlusion and Shadows with Cone Tracing" (Schott et al., 2009) and "Parallel distributed, GPU-accelerated, advanced lighting calculations for large-scale volume visualization" (Shih et al., 2016) [S1, unofficial]. The implementation aims to replicate results from various volume rendering papers, including those on extinction-based shading and directional occlusion [S1, unofficial].
