# Hybrid Preshading with Postclassification

Also called: Hybrid Classification and Shading

## Overview
Hybrid Preshading with Postclassification is a real-time volume rendering optimization that decouples classification from shading to balance visual fidelity and performance [S1]. It solves the trade-off between the speed of preclassification/preshading (which often requires opacity-weighted interpolation to avoid artifacts) and the visual quality of postclassification/postshading (which is computationally expensive) [S1]. Unlike its siblings, it performs classification after interpolation (postclassification) to ensure accurate material assignment, but performs shading before interpolation (preshading) using a precomputed reflectance map to maintain high rendering speeds [S1].

## How it works
**Inputs:**
- Volume dataset $V$ containing scalar density values [S1].
- Transfer function mapping density to color and opacity [S1].
- Lighting model and light positions [S1].
- Camera parameters defining ray origins and directions [S1].

**Outputs:**
- Rendered image with volumetric shading [S1].

**Data Structures:**
1. **Volume Grid:** Standard 3D grid storing scalar density values [S1].
2. **Gradient Map:** Precomputed for each voxel [S1]. The gradient vector $\nabla V$ at each voxel is quantized to one of $N$ discrete space directions [S1].
   - **Layout:** For each voxel $(i, j, k)$, store an integer index $d \in [0, N-1]$ representing the quantized gradient direction [S1].
   - **Size:** $N = 8192$ quantized directions [S1].
3. **Preshaded Reflectance Map:** A lookup table storing the shaded color for each of the $N$ quantized directions [S1].
   - **Layout:** Array of size $N$, where each entry contains the RGB color resulting from applying the lighting model to the base material color for that specific direction [S1].
   - **Generation:** Before rendering, for each of the $N$ directions, the algorithm computes the shading result and stores it in the map [S1].

**Steps:**
1. **Precomputation (Gradient Quantization):** Compute the gradient $\nabla V$ for every voxel in the volume [S1]. Quantize each gradient vector to the nearest of the $N$ predefined space directions [S1]. Store the index of this direction in the Gradient Map for each voxel [S1].
2. **Precomputation (Preshaded Reflectance Map):** Apply shading on every quantized direction before every rendering to generate a preshaded reflectance map [S1].
3. **Rendering (Ray Marching):** For each pixel, cast a ray through the volume [S1]. Sample the volume along the ray [S1].
4. **Interpolation:** Perform trilinear interpolation of the volume samples and the gradient at the sampling location [S1]. This yields an interpolated density and an interpolated direction index [S1].
5. **Vertex Shading:** Identify the 8 voxels surrounding the current sampling point [S1]. For each of the 8 vertices, retrieve its precomputed gradient direction index [S1]. Look up the shaded color from the Preshaded Reflectance Map using the index [S1].
6. **Color Interpolation:** Perform trilinear interpolation of the 8 preshaded vertex colors and the opacities at the sampling location [S1].
7. **Postclassification:** Use the interpolated density to determine the final opacity and color contribution, applying the transfer function after interpolation [S1].
8. **Compositing:** Composite the resulting color and opacity along the ray using standard front-to-back volume integration [S1].

**Parameters:**
- Number of quantized space directions: $N = 8192$ [S1].
- Sampling rate $\Delta s = 0.5$ (distance between consecutive interpolations), allowing between two and four samplings along a ray within a cell [S1].
- Image resolution: $512 \times 512$ pixels [S1].
- Pixel subdivisions and precomputed rays: Fixed to $16 \times 16$ [S1].
- Data precision: Color and opacity are computed on 16-bit unsigned integers [S1].

**Edge Cases and Pitfalls:**
- **Artifacts:** Mueller et al. reported bad artifacts with preshading and postclassification, but this implementation shows no visible artifacts, suggesting the previous interpretation may be erroneous [S1].
- **Interpolation Requirement:** Preclassification/preshading requires opacity-weighted color interpolation to avoid artifacts, which this hybrid method avoids by deferring classification [S1].
- **Hardware Limitations:** SIMD extensions (MMX, SSE, or 3DNow!) are used to improve memory copying and trilinear interpolation [S1]. Code running on MMX-only processors cannot perform line equation tests, causing minor artifacts on the image [S1].
- **Quantization Error:** Using a finite set of 8192 directions may introduce directional aliasing or lighting inaccuracies for smooth gradients [S1].

**Pseudocode:**

```python
def precompute_gradient_map(volume, directions):
    """
    Computes the gradient for each voxel and quantizes it to one of N directions.
    Returns a 3D grid of indices.
    """
    N = len(directions)
    H, W, D = len(volume), len(volume[0]), len(volume[0][0])
    gradient_map = [[[-1] * D for _ in range(W)] for _ in range(H)]
    for i in range(H):
        for j in range(W):
            for k in range(D):
                grad = compute_gradient(volume, i, j, k)
                best_idx = 0
                best_dot = -float('inf')
                for d in range(N):
                    dot_val = dot(grad, directions[d])
                    if dot_val > best_dot:
                        best_dot = dot_val
                        best_idx = d
                gradient_map[i][j][k] = best_idx
    return gradient_map

def precompute_reflectance_map(volume, transfer_function, directions):
    """
    Generates a preshaded reflectance map for each quantized direction.
    """
    N = len(directions)
    reflectance_map = [None] * N
    base_color = transfer_function.get_color(0.5)
    for d in range(N):
        shaded_color = apply_lighting(base_color, directions[d])
        reflectance_map[d] = shaded_color
    return reflectance_map

def render_volume(volume, gradient_map, reflectance_map, camera, transfer_function):
    """
    Renders the volume using hybrid preshading and postclassification.
    """
    H, W = camera.height, camera.width
    image = [[(0, 0, 0) for _ in range(W)] for _ in range(H)]
    delta_s = 0.5
    for y in range(H):
        for x in range(W):
            ray = camera.get_ray(x, y)
            r, g, b = 0.0, 0.0, 0.0
            alpha = 0.0
            t = ray.origin
            while t < ray.end:
                coords = get_voxel_coords(t)
                preshaded_colors = []
                opacities = []
                for v in coords:
                    idx = gradient_map[v[0]][v[1]][v[2]]
                    preshaded_colors.append(reflectance_map[idx])
                    density = volume[v[0]][v[1]][v[2]]
                    opacities.append(transfer_function.get_opacity(density))
                interp_color = trilinear_interpolate(preshaded_colors, t)
                interp_opacity = trilinear_interpolate(opacities, t)
                alpha_c = interp_opacity
                if alpha_c > 0:
                    r += interp_color[0] * alpha_c * (1.0 - alpha)
                    g += interp_color[1] * alpha_c * (1.0 - alpha)
                    b += interp_color[2] * alpha_c * (1.0 - alpha)
                    alpha += alpha_c * (1.0 - alpha)
                t += delta_s
            image[y][x] = (int(r * 255), int(g * 255), int(b * 255))
    return image
```

## Subtopics

### [Fast Two-Pass Shading](2311-fast-two-pass-shading.md)
Fast Two-Pass Shading is a rendering optimization that avoids redundant per-fragment computations—specifically volume texture access, classification, and lighting—by sharing intermediate results between pixels covered by the same splat. It decouples the classification and illumination steps from the geometric filtering step by storing intermediate results in a render target (P-buffer).

### [Congradient Shading](2341-congradient-shading.md)
Congradient shading is a real-time volumetric shading acceleration technique that defines the surface orientation of a voxel as one of a finite set of local gradients, enabling a fast table-driven mechanism. It solves the performance bottleneck of per-voxel normal calculation and lighting integration by integrating shading into the projection pipeline, generating "congradient values" (concatenated color and gradient data) that serve as direct indices to a precomputed illumination look-up table. Unlike sibling methods that may perform shading in a separate post-processing stage or require complex normal quantization, congradient shading operates as a pipeline with the viewing process, accruing no additional time for shading because the congradient calculation time is much less than the projection time.

### [Fake Phong Illumination via Normal Quantization](5846-fake-phong-illumination-via-normal-quantization.md)
Fake Phong Illumination via Normal Quantization is a real-time approximation technique for volume rendering that replaces per-voxel Phong lighting calculations with a pre-computed color lookup table indexed by quantized surface normals. It solves the performance bottleneck of interactive volumetric rendering by moving the computational cost of the Phong equation to a pre-processing stage, allowing rendering to proceed via simple texture mapping. Unlike real-time Phong illumination which calculates lighting dynamically for every sample, this method sacrifices image fidelity to achieve speed, specifically introducing directional aliasing artifacts due to the discrete nature of the normal vector quantization.

### [Hybrid Gradient Computation](7505-hybrid-gradient-computation.md)
A technique to compute gradient directions for lighting that adaptively align with post-classified density variations while using pre-computed gradient directions for sampling, avoiding the need for two-sided lighting. It differs from standard pre-classified gradients by flipping normals to ensure single-sided lighting correctly illuminates low-scalar-value regions (like dentin) without lighting back-facing surfaces.

## Operating characteristics
- **Time Complexity:** The per-voxel shading cost is reduced to a table lookup during rendering, as shading is precomputed [S1]. The dominant cost is the trilinear interpolation of the preshaded colors and opacities [S1]. The precomputation phase is $O(N \cdot V)$ where $N$ is the number of directions and $V$ is the number of voxels, but this is done once [S1].
- **Memory Complexity:** Requires storage for the volume data, the gradient map (1 integer per voxel), and the preshaded reflectance map ($N$ colors) [S1]. With $N=8192$, the reflectance map is small [S1].
- **Performance:** Benchmarks were performed on platforms using MMX, SSE, or 3DNow! SIMD extensions for memory copying and trilinear interpolation [S1]. The method allows high-quality rendering on $512 \times 512$ images with up to 4x zoom without visible noise [S1].
- **Strengths:** Combines the speed of preshading with the visual quality of postclassification [S1]. Avoids the artifacts associated with preclassification/preshading (which requires opacity-weighted interpolation) and the slowness of postclassification/postshading [S1].
- **Limitations:** Relies on quantization of gradient directions, which may introduce directional artifacts [S1]. The claim of "no artifacts" contradicts Mueller et al., suggesting potential sensitivity to specific volume characteristics or transfer functions [S1].

## Background
Described in [S1], the method addresses the limitations of traditional preclassification/preshading and postclassification/postshading approaches by proposing a hybrid strategy [S1]. The authors argue against the interpretation by Mueller et al. that preshading and postclassification inherently produce bad artifacts, claiming their implementation shows no visible artifacts [S1]. The technique is part of a broader effort to optimize real-time volume rendering using SIMD instructions and precomputed data structures [S1].
