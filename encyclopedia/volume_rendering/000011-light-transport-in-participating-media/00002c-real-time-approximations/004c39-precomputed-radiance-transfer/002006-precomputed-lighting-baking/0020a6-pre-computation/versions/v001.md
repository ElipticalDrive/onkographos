# Pre-computation
## Overview
Pre-computation is a technique used in volume rendering to accelerate the evaluation of light transport in participating media by calculating and storing intermediate radiance variables as voxel data [S1]. It solves the problem of redundant per-voxel integration during ray marching by pre-calculating terms such as direct radiance ($L_{ri}$), diffusion radiance ($L_{0d}, \vec{L}_{1d}$), and their density derivatives, allowing the renderer to reuse these values instead of recomputing them for every camera ray [S1]. Unlike [Hybrid Preshading with Postclassification](2171-hybrid-preshading-with-postclassification.md), which may handle post-classification differently, this method explicitly pre-computes the diffusion components via a solver to enable efficient derivative-based shading [S1].
## How it works
**Inputs and Outputs:**
*   **Inputs:** Initial diffusion radiance estimates $L_{0d}, \vec{L}_{1d}$ and their derivatives; scattering coefficient $\kappa$; absorption coefficient $\kappa_a$; total extinction coefficient $\kappa_t$; source term $S$.
*   **Outputs:** Pre-computed radiance fields $L_{ri}, L_{0d}, \vec{L}_{1d}$ and their density derivatives $\partial_\pi L_{ri}, \partial_\pi L_{0d}, \partial_\pi \vec{L}_{1d}$ stored as voxels.

**Data Structures:**
The method stores fields as 3D grids (voxels). Each voxel at position $v_{xu}$ holds scalar or vector values for the radiance terms and their derivatives. The exact bit-packing or memory layout is not specified in the sources [S1].

**Steps:**
The pre-computation is performed in parallel for all voxel positions $v_{xu}$ in the volume [S1].

1.  **Compute Radiance and Derivatives ($L_{ri}$):** Calculate $L_{ri}(v_{xu}, \boldsymbol{\omega}')$ and its density derivative $\partial_\pi L_{ri}(v_{xu}, \boldsymbol{\omega}')$ using the source equations [S1]. The source cites Equation 31 and 41 for this step [S1]. The text notes that $L_{ri}$ involves estimating the integral of solid angle over the unit sphere $S^2$ using the Monte Carlo Method [S1].
2.  **Compute Intermediate Variable $Q_{0ri}$:** Calculate $Q_{0ri}(v_{xu})$ and $\partial_\pi Q_{0ri}(v_{xu})$ using Equations 37 and 15 [S1].
3.  **Compute Intermediate Variable $\vec{Q}_{1ri}$:** Calculate $\vec{Q}_{1ri}(v_{xu})$ and $\partial_\pi \vec{Q}_{1ri}(v_{xu})$ using Equations 38 and 16 [S1].
4.  **Compute Extinction Coefficient $\kappa$:** Calculate $\kappa(v_{xu})$ and $\partial_\pi \kappa(v_{xu})$ using Equations 35 and 12 [S1].
5.  **Compute Source Term $S$:** Calculate $S(v_{xu})$ and $\partial_\pi S(v_{xu})$ using Equations 36 and 14 [S1].
6.  **Solve Diffusion Radiance:** Call `DiffusionSolver` to compute the final diffusion radiance $L_{0d}, \vec{L}_{1d}$ and their derivatives $\partial_\pi L_{0d}, \partial_\pi \vec{L}_{1d}$ using the pre-computed $S, \kappa, \kappa_a$ [S1]. The solver uses a Jacobi iterative method to solve the differential diffusion equation [S1].
7.  **Return Results:** Return the fields $L_{ri}, L_{0d}, \vec{L}_{1d}$ and their derivatives [S1].

## Subtopics
## Operating characteristics
*   **Time Complexity:** The pre-computation step is performed once per volume update or light change. It involves parallel iteration over all voxels and a global diffusion solver [S1]. The exact complexity is not given, but it is $O(N)$ for the voxel loop where $N$ is the number of voxels, plus the cost of the diffusion solver [S1].
*   **Memory Complexity:** Requires storing multiple fields ($L_{ri}, L_{0d}, \vec{L}_{1d}$ and their derivatives) for every voxel [S1]. The exact memory footprint is not given [S1].
*   **Measured Performance:** Not given in the sources.
*   **Strengths:** Eliminates redundant calculations during ray marching by reusing pre-computed voxel data [S1]. Enables efficient computation of radiance derivatives for density-based shading [S1].
*   **Limitations:** Requires significant memory to store the pre-computed fields [S1]. The diffusion solver may be computationally expensive if not optimized [S1].
*   **When to Use:** When rendering participating media with density-dependent shading effects where ray marching is performed frequently [S1].
*   **When Not to Use:** When memory is constrained or the volume changes dynamically every frame without pre-computation updates [G].
