# Local Piecewise Integration for Light Propagation

Also called: Local Piecewise Integration

## Overview
Local Piecewise Integration is a precomputation technique used in direct volume rendering to efficiently calculate high-resolution global shadows and light propagation from a distant light source through a participating medium [S1]. It solves the problem of expensive per-voxel absorption integration by approximating the opacity integral using short, reusable local segments, enabling interactive frame rates for large-scale volumes [S1]. Unlike object-order light propagation methods, it allows the light source to be positioned anywhere in the scene, including within the volume, and handles large scales via multi-resolution data management [S1]. Compared to simple blur-based approximations like Kniss et al. [KPH*03], it provides nearly physically correct scattering effects [S1].

## How it works
**Inputs:**
*   Volumetric dataset with extinction/opacity field [S1].
*   Light source direction and intensity $I_0$ [S1].
*   Transfer Function (TF) mapping scalar values to opacity $\alpha$ [S1].
*   Parameters:
    *   $N$: Number of samples taken along the local piecewise segment (Not given in the sources).
    *   $\Delta s$: Step length for the global light integration, equal to the length of the local piecewise segments (Typically 8-16 voxels) [S1].
    *   $I_{bias}$: Adjusts the minimum lighting so that no region is completely dark [S1].
    *   $R\Omega$: Scattering sphere radius (Not given in the sources).

**Outputs:**
*   Precomputed local piecewise segment opacities $\alpha_{lp}(s_0)$ stored in the Shadow Volume Representation (SVR) [S1].
*   Global light intensity $I(s)$ for each voxel during rendering [S1].

**Data Structures:**
*   **Shadow Volume Representation (SVR):** A 3D grid storing precomputed light information. The resolution can differ from the volume dataset to balance performance and quality [S1].
*   **Local Piecewise Segments:** For each voxel, a single precomputed opacity value $\alpha_{lp}(s_0)$ corresponding to the segment of length $\Delta s$ extending towards the light source [S1].

**Algorithm Steps:**

1.  **Local Segment Opacity Calculation:**
    For each voxel location $s_0$ in the volume, cast a ray in the direction of the light source [S1]. The method computes the transparency $T_{lp}(s_n)$ for segments starting at $s_n = n \Delta s$, where $s_0$ is the current voxel location [S1].
    a. Sample $N$ points $n_i$ along the segment $[s_0, s_0 + \Delta s]$ using the current Transfer Function to get point opacities $\alpha(n_i)$ [S1].
    b. Compute the segment opacity $\alpha_{lp}(s_0)$ using the product of individual sample transparencies:
       $$ \alpha_{lp}(s_0) = 1 - \prod_{i=0}^{N} (1 - \alpha(n_i)) $$
    c. Compute the segment transparency $T_{lp}(s_0)$:
       $$ T_{lp}(s_0) = 1 - \alpha_{lp}(s_0) = \prod_{i=0}^{N} (1 - \alpha(n_i)) $$
       (Note: The source defines $T_{lp}(s_n) = e^{-\int_{s_n}^{s_n+\Delta s} \tau(t) dt}$ and relates it to opacity via $\alpha_{lp} = 1 - T_{lp}$) [S1].
    d. Store $\alpha_{lp}(s_0)$ in the SVR for the voxel at $s_0$ [S1].

2.  **Global Light Integration (Precomputation/Update):**
    Using the precomputed local segments, calculate the global light intensity reaching each voxel [S1]. The intensity $I(s)$ at position $s$ is:
    $$ I(s) = I_0 \times \prod_{n=0}^{k} T_{lp}(s_n) $$
    where $k$ is the number of segments from the light source to $s$ [S1].
    *   This integration is updated at a lower frequency than the rendering frame rate [S1].
    *   A bias term $I_{bias}$ may be applied to ensure no region is completely dark [S1].

3.  **Rendering:**
    During ray marching for image generation:
    a. For each sample along the view ray, perform one additional texture look-up in the SVR to retrieve the pre-computed light intensities [S1].
    b. Composite the volume color using the retrieved lighting information [S1].

**Pseudocode:**

```python
def compute_local_piecewise_segments(volume_data, light_direction, delta_s, num_samples_per_segment):
    """
    Precomputes local piecewise segment opacities for all voxels.
    For each voxel, casts a ray in the light direction and computes the opacity 
    of the first segment starting at the voxel.
    """
    dims = volume_data.shape
    # SVR stores the opacity of the first segment starting at each voxel
    svr = [[[[0.0 for _ in range(dims[3])] for _ in range(dims[2])] for _ in range(dims[1])] for _ in range(dims[0])]
    
    for x in range(dims[0]):
        for y in range(dims[1]):
            for z in range(dims[2]):
                current_pos = [float(x), float(y), float(z)]
                
                # Segment starts at current voxel (n=0)
                s_n = current_pos[:]
                
                # Check if start is within bounds
                if not (0 <= s_n[0] < dims[0] and 0 <= s_n[1] < dims[1] and 0 <= s_n[2] < dims[2]):
                    continue
                
                # Sample N points along the segment [s_n, s_n + delta_s * light_direction]
                product_transparency = 1.0
                for i in range(num_samples_per_segment + 1):
                    t = i / num_samples_per_segment
                    sample_pos = [
                        s_n[0] + t * delta_s * light_direction[0],
                        s_n[1] + t * delta_s * light_direction[1],
                        s_n[2] + t * delta_s * light_direction[2]
                    ]
                    
                    # Standard trilinear interpolation for volume value
                    val = interpolate_volume(volume_data, sample_pos, dims)
                    
                    # Transfer function to opacity
                    alpha_ni = transfer_function(val)
                    
                    product_transparency *= (1.0 - alpha_ni)
                
                # T_lp = product_transparency, so alpha_lp = 1 - T_lp
                alpha_lp = 1.0 - product_transparency
                
                svr[x][y][z] = alpha_lp
                
    return svr

def interpolate_volume(volume_data, pos, dims):
    # Standard trilinear interpolation
    x, y, z = pos
    x0, y0, z0 = int(x), int(y), int(z)
    x1, y1, z1 = min(x0 + 1, dims[0] - 1), min(y0 + 1, dims[1] - 1), min(z0 + 1, dims[2] - 1)
    dx, dy, dz = x - x0, y - y0, z - z0
    
    v000 = volume_data[x0][y0][z0]
    v100 = volume_data[x1][y0][z0]
    v010 = volume_data[x0][y1][z0]
    v110 = volume_data[x1][y1][z0]
    v001 = volume_data[x0][y0][z1]
    v101 = volume_data[x1][y0][z1]
    v011 = volume_data[x0][y1][z1]
    v111 = volume_data[x1][y1][z1]
    
    def lerp(a, b, t): return a + t * (b - a)
    
    c00 = lerp(v000, v100, dx)
    c10 = lerp(v010, v110, dx)
    c01 = lerp(v001, v101, dx)
    c11 = lerp(v011, v111, dx)
    
    c0 = lerp(c00, c10, dy)
    c1 = lerp(c01, c11, dy)
    
    return lerp(c0, c1, dz)

def transfer_function(val):
    # Standard linear mapping or lookup; simplified for implementation
    return max(0.0, min(1.0, val))
```

**Parameters:**
*   $N$: The number of samples taken along the local piecewise segment (Not given in the sources).
*   $\Delta s$: The step length for the global light integration, which is equal to the length of the local piecewise segments (Typically 8-16 voxels) [S1].
*   $I_{bias}$: Adjusts the minimum lighting so that no region is completely dark, preventing important structures from being obscured by shadows [S1].
*   $R\Omega$: Scattering sphere radius; an increase results in less distinct shadows (Not given in the sources).

**Pitfalls:**
*   The local piecewise segments must be recomputed whenever the Transfer Function (TF) changes or the volume moves relative to the light source [S1].
*   Block artifacts (jagged edges) appear on sharp edges and surfaces if the Shadow Volume Representation (SVR) resolution is too low [S1].
*   Banding effects appear on the side of the head due to interpolation between shadowed and un-shadowed regions when SVR size is reduced [S1].

## Subtopics

### Source Term Computation for External Lighting
A variant or related step where the multiple scattering source term $q_{ri}(x)$ for external directional light $L_l$ is computed as $q_{ri}(x) = L_l \cdot \sigma_s(x) \cdot T(x)$, where $\sigma_s$ is the scattering coefficient and $T(x)$ is transmittance [S2]. This term is computed via raymarching and stored at the full resolution of the dataset extinction field [S2].

### Radial Grids for Local Light Sources
A propagation scheme using radial grids (topologically equivalent to rectilinear grids but cyclic in two angular dimensions) for local point lights [S3]. It allows approximate treatment of space as locally Euclidean and extends Principal-Ordinates Propagation (POP) to local light sources by using spherical grids aligned with the initial principal directions of the point source [S3]. VPLs are prefiltered based on importance and anisotropy [S3].

## Operating characteristics
*   **Time Complexity:** Integration of light intensities without the local piecewise approximation is approximately 10 times slower [S1].
*   **Performance:** Global light integration updates in 284-552 ms (for 8 voxel segments) depending on SVR size; first order scattering incremental refinements take 62-233 ms [S1]. High frame rates, 15-22 frames per seconds (fps), are reached once the light calculations are updated, since only one additional texture look-up must be performed for each sample during ray casting [S1].
*   **Memory Complexity:** Requires storage for the Shadow Volume Representation (SVR) [S1].
*   **Accuracy:** Root Mean Square (RMS) error of 0.19 for $\Delta E$ (CIE 1976 L*u*v* color space), with 6% of pixels having $\Delta E$ above 6 [S1].
*   **Strengths:** Nearly physically correct scattering effects compared to blur-based methods; light source can be positioned anywhere, even within the volume; handles large scale volumes via multi-resolution data management [S1].
*   **Limitations:** Block artifacts (jagged edges) appear on sharp edges if SVR resolution is too low; banding effects appear due to interpolation between shadowed and un-shadowed regions when SVR size is reduced [S1].
*   **When to use:** When interactive global shadowing and light propagation in large volumetric datasets is required, and the light source is distant or directional [S1].

## Background
Local Piecewise Integration was introduced in the paper "Interactive Global Light Propagation in Direct Volume Rendering using Local Piecewise Integration" [S1]. It builds on the concept of piecewise integration for opacity [Max95] and opacity correction [PH89] [S1]. The method was developed to address the computational cost of global light propagation in volume rendering, offering an interactive alternative to object-order methods and more accurate results than simple blur approximations [S1].
