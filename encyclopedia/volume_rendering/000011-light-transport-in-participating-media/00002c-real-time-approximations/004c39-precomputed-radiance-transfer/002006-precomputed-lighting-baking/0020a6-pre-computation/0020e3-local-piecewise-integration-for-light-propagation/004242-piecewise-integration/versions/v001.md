# Piecewise Integration

Also called: Piecewise Light Propagation, Segmented Light Transport

## Overview
Piecewise Integration is a precomputation technique for real-time volume rendering that approximates global light transport by dividing light paths into discrete segments. It solves the problem of expensive volumetric illumination by storing transmittance data in a multiresolution 3D texture, allowing incoming radiance to be computed via a single texture lookup per sample. It is distinguished from full path-tracing methods by its reliance on precomputed segment data and from simple direct illumination by its inclusion of first-order inscattering approximations [S1].

## How it works
**Inputs:**
*   Volumetric dataset (density/scattering coefficients).
*   Light source definition (position, radiance $L_0$, type: directional or point) [S1].
*   Transfer function (mapping scalar values to optical properties) [S1].
*   Number of segments $k$ [S1].

**Outputs:**
*   Final radiance 3D texture [S1].

**Data Structures:**
1.  **Piecewise Segment Texture:** An intermediate 3D texture storing transmittance values between segment endpoints. It uses a multiresolution structure and a lower-resolution grid to reduce memory usage [S1].
2.  **Final Radiance Texture:** A 3D texture accumulating the progressive refinement results [S1].
3.  **Auxiliary Textures:** Three additional 3D textures are required for intermediate computations [S1].

**Steps:**
1.  **Segmentation:** For each voxel in the volume, cast short rays towards the light source. These rays define the piecewise segments [S1].
2.  **Precomputation:** Store the transmittance $T(\tilde{x}_n, \tilde{x}_{n+1})$ for each segment endpoint pair into the Piecewise Segment Texture [S1].
3.  **Radiance Evaluation:** For each voxel, send global rays towards the light source. The ray steps are sized equal to the short ray length used in segmentation. At each sample position, sample the Piecewise Segment Texture to retrieve transmittance values [S1].
4.  **Inscattering Approximation:** Approximate first-order inscattering by treating scattering in the vicinity of the sample point as emission [S1].
5.  **Progressive Refinement:** To maintain interactivity, refine the final radiance by sending one ray at a time and blending the result into the Final Radiance Texture [S1].

**Formula:**
The incoming radiance $L_i$ at a position $\tilde{x}$ from direction $\tilde{\omega}_i$ is computed as [S1]:

$$
L_i(\tilde{x}, \tilde{\omega}_i) = L_0 \cdot \prod_{n=0}^{k} T(\tilde{x}_n, \tilde{x}_{n+1})
$$

Where:
*   $L_0$ is the source radiance [S1].
*   $k$ is the number of segments [S1].
*   $T(\tilde{x}_n, \tilde{x}_{n+1})$ is the transmittance between segment endpoints $\tilde{x}_n$ and $\tilde{x}_{n+1}$ [S1].
*   $\tilde{x}_n$ and $\tilde{x}_{n+1}$ are the endpoints of the $n$-th segment [S1].

**Parameters:**
*   $k$: The number of segments into which rays are divided [S1]. Value not given in the sources.

**Pitfalls:**
*   **Recomputation:** If the light source position, type, or the transfer function changes, the radiance must be fully recomputed [S1].
*   **Memory:** Requires sufficient graphics memory for three additional 3D textures, though mitigated by multiresolution structures [S1].
*   **Light Source Limitation:** Supports only a single directional or point light source [S1].

**Pseudocode:**
```python
def piecewise_integration(volume, light_source, k, transfer_function):
    """
    Computes volumetric illumination using piecewise integration.
    
    Args:
        volume: 3D array of density/scattering coefficients.
        light_source: Object containing position, radiance L0, and type.
        k: Number of segments.
        transfer_function: Function mapping volume values to optical properties.
        
    Returns:
        final_radiance_texture: 3D texture with computed radiance.
    """
    # 1. Determine short ray step size based on k and volume bounds
    # [G] Assuming uniform grid, step size is derived from volume dimensions and k
    step_size = compute_step_size(volume.dimensions, k, light_source)
    
    # 2. Precompute piecewise segments
    # Cast short rays towards light source for each voxel
    piecewise_segment_texture = create_multiresolution_3d_texture(volume.dimensions)
    
    for voxel in volume.voxels:
        # Cast short ray from voxel towards light source
        segment_endpoints = cast_short_ray(voxel.position, light_source, step_size)
        
        # Compute transmittance for each segment
        for n in range(len(segment_endpoints) - 1):
            x_n = segment_endpoints[n]
            x_n1 = segment_endpoints[n+1]
            
            # Get optical properties from transfer function
            density_n = transfer_function(volume.value_at(x_n))
            density_n1 = transfer_function(volume.value_at(x_n1))
            
            # Compute transmittance T(x_n, x_n1)
            # [G] Standard exponential transmittance: exp(-integral of density * step)
            transmittance = exp(-density_n * step_size) # Approximation for small step
            
            piecewise_segment_texture.set_value(x_n, transmittance)
            
    # 3. Initialize final radiance texture
    final_radiance_texture = create_3d_texture(volume.dimensions, initial_value=0)
    
    # 4. Progressive refinement
    # Send one ray at a time and blend
    for voxel in volume.voxels:
        # Send global ray towards light source
        ray = Ray(voxel.position, normalize(light_source.position - voxel.position))
        
        incoming_radiance = 0
        accumulated_transmittance = 1.0
        
        # Sample along the ray using steps equal to short ray size
        current_pos = voxel.position
        while current_pos is within volume bounds:
            # Sample from piecewise segment texture
            # [G] Retrieve precomputed transmittance for the segment starting at current_pos
            segment_transmittance = piecewise_segment_texture.get_value(current_pos)
            
            # Update accumulated transmittance
            accumulated_transmittance *= segment_transmittance
            
            # Approximate first-order inscattering
            # Treat scattering in vicinity as emission
            density = transfer_function(volume.value_at(current_pos))
            scattering_coeff = density # Simplified approximation
            emitted_radiance = scattering_coeff * light_source.L0 # [G] Simplified emission model
            
            # Add contribution
            incoming_radiance += emitted_radiance * accumulated_transmittance
            
            # Advance step
            current_pos += ray.direction * step_size
            
        # Blend result into final texture
        final_radiance_texture.set_value(voxel.position, incoming_radiance)
        
    return final_radiance_texture
```

## Operating characteristics
*   **Time Complexity:** Low rendering times due to the single extra lookup required to compute incoming radiance at the sample position [S1].
*   **Memory Complexity:** Requires three additional 3D textures for computations. Memory requirements are alleviated by using a multiresolution structure and a lower-resolution grid [S1].
*   **Performance:** Supports interactive frame rates, provided sufficient graphics memory is available [S1].
*   **Strengths:** Enables interactive progressive refinement; supports dynamic movement of a single light source [S1].
*   **Limitations:** Radiance must be recomputed if the light source or transfer function changes, which can be costly but is performed interactively and progressively [S1]. Limited to single directional or point light sources [S1].

## Background
Piecewise Integration was introduced by Habel et al. in 2008 [S1]. It was developed for volume ray-casting but can be combined with other rendering paradigms [S1]. The technique is part of the broader effort to achieve interactive volume rendering with volumetric illumination, building on concepts like Summed Area Tables which were exploited by Diaz et al. for illumination effects [S1].
