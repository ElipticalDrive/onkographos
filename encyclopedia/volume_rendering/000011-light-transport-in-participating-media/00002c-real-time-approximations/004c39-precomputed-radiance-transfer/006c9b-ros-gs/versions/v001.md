# ROS-GS
Also called: Relightable Outdoor Scenes With Gaussian Splatting

## Overview
ROS-GS is a two-stage pipeline for efficiently reconstructing relightable outdoor scenes from multi-view images captured under unconstrained lighting conditions, decomposing geometry, texture, and lighting using Gaussian Splatting [S1]. It differs from its siblings by explicitly separating high-frequency directional sunlight (modeled via Spherical Gaussians) from low-frequency ambient illumination (modeled via Spherical Harmonics) and using deferred shading to resolve normal variance artifacts inherent in Gaussian splatting, whereas methods like [PRTGaussian](19768-prtgaussian.md) typically bake lighting into per-Gaussian coefficients without explicit directional sun modeling [S1].

## How it works
**Inputs:** $N$ multi-view images of an outdoor scene under unconstrained lighting.
**Outputs:** A relightable scene representation supporting novel view synthesis and dynamic lighting changes.

### Data Structures
The method uses two stages with distinct Gaussian definitions.

**Stage I Geometry Initialization:**
Each Gaussian $k$ is defined as $G_I = \{p_k, \sigma_k, R_k, o_k, \rho_k, \Lambda_k\}$:
*   $p_k \in \mathbb{R}^3$: Position.
*   $\sigma_k \in \mathbb{R}^3$: Scaling.
*   $R_k \in SO(3)$: Rotation.
*   $o_k \in [0, 1]$: Opacity.
*   $\rho_k \in [0, 1]^3$: Base color.
*   $\Lambda_k$: Per-Gaussian embedding capturing local appearance variations.
*   Additionally, a set of per-image embeddings $\{\Xi_j\}_{j=1}^N$ accounts for lighting changes across views.

**Stage II Texture-Lighting Decomposition:**
Geometry attributes are inherited from Stage I. Each Gaussian $k$ is defined as $G_{II} = \{p_k, \sigma_k, R_k, o_k, \rho_k, t_k\}$:
*   $p_k, \sigma_k, R_k, o_k$: Inherited from Stage I.
*   $\rho_k \in [0, 1]^3$: Reused as albedo.
*   $t_k \in \mathbb{R}^{1 \times (n+1)}$: Per-Gaussian SH coefficients for the radiance transfer function.
*   $l_c \in \mathbb{R}^{3 \times (n+1)}$: Globally shared SH coefficients for ambient illumination, where $c=1 \dots N$ indexes input views.

### Steps

**Stage I: Geometry Initialization**
1.  **Appearance Transformation:** For each view $j$, predict affine parameters $(\gamma, \beta)$ using an MLP $f_{app}$:
    $$(\gamma, \beta) = f_{app}(\rho_k, \Lambda_k, \Xi_j)$$
    Compute transformed appearance:
    $$\tilde{\rho}_k = \gamma \cdot \rho_k + \beta$$
2.  **Rasterization:** Rasterize the Gaussians using standard 2DGS rasterization [S1].
3.  **Normal Prior Application:**
    *   Identify non-edge regions using the Canny edge detector with thresholds $[100, 200]$ followed by a 3x3 dilation kernel [S1].
    *   Exclude dynamic regions using semantic masks from MMSegmentation [S1].
    *   Apply monocular normal prior loss $L_{np}$ only to the intersection of non-edge and static regions [S1].
4.  **Mesh Extraction:**
    *   Render depth maps from training views.
    *   Filter out sky, foliage, and dynamic occluders using semantic masks.
    *   Fuse depth maps via Truncated Signed Distance Function (TSDF) integration to obtain clean surface meshes [S1].

**Stage II: Texture-Lighting Decomposition**
1.  **Lighting Model Definition:**
    *   **Sunlight:** Modeled as a Spherical Gaussian (SG) $SG_{\mu, \lambda, \xi}(\nu) = \mu e^{\lambda(\nu \cdot \xi - 1)}$, where $\mu \in \mathbb{R}^{3+}$ is lobe amplitude, $\lambda \in \mathbb{R}^+$ is sharpness, and $\xi \in S^2$ is sun direction [S1].
    *   **Ambient:** Modeled by globally shared SH coefficients $l_c$ [S1].
2.  **Rendering:**
    *   Compute Sun Irradiance $I_{sun}$:
        $$I_{sun} = \int_{\Omega} V_{sun}(x, \omega_i) SG_{\mu, \lambda, \xi}(\omega_i) (\omega_i \cdot n) d\omega_i$$
        where $V_{sun} \in \{0, 1\}$ is visibility [S1].
    *   Compute Ambient Irradiance $I_{amb}$ by splatting per-Gaussian transfer functions $t_k$ with shared ambient SH $l_c$:
        $$I_{amb} = S\left(\sum_{j=1}^{N} l_{cj} \cdot t_{jk}\right)$$
        where $S(\cdot)$ denotes the 2DGS rasterization process [S1].
    *   **Deferred Shading:** To mitigate local normal variance, perform shading in screen space using final accumulated normals rather than per-Gaussian normals [S1].
    *   Compute final color $C(x)$ for diffuse surfaces ($f_d = \rho/\pi$):
        $$C(x) = \frac{\rho}{\pi} (I_{sun} + I_{amb})$$
        where $\rho$ is the albedo map generated by splatting [S1].

### Formulas
*   **Rendering Equation:**
    $$L(x, \omega_o) = \int_{\Omega} f_r(x, \omega_o, \omega_i) L_{in}(x, \omega_i) (\omega_i \cdot n) d\omega_i$$
    [S1]
*   **PRT Approximation:**
    $$L(x) = \sum_{k=1}^{(n+1)^2} T(x)_k L_k^{in}$$
    [S1]
*   **Stage I Loss:**
    $$L_{1st} = \lambda_1 L_{render} + \lambda_2 L_{reg} + \lambda_3 L_{np} + \lambda_4 L_{mask}$$
    where $L_{render}$ is L1 + D-SSIM, $L_{reg}$ is 2DGS normal consistency/distortion, $L_{mask}$ is BCE between sky regions in semantic masks and rendered alpha [S1].
*   **Normal Prior Loss:**
    $$L_{np} = \sum (1 - n_p^T \hat{n}_r) + \sum (1 - n_p^T \hat{n}_s)$$
    where $n_p$ is prior normal, $\hat{n}_r$ is alpha-blended rendered normal, $\hat{n}_s$ is normal from depth map gradient [S1].
*   **Stage II Loss:**
    $$L_{2nd} = \lambda_1 L_{render} + \lambda_5 L_{sp} + \lambda_6 L_{amb}$$
    [S1]
*   **Sunlight Color Prior:**
    $$L_{sp} = \|f_{sun}(\theta) - \mu\|_1$$
    where $f_{sun}$ is piecewise polynomial fitting of modified Nishita model, $\theta$ is simulated solar elevation angle [S1].
*   **Ambient Light Prior:**
    $$L_{amb} = \sum_x \left( \|I_{amb}(x + e_x) - I_{amb}(x)\|_1 + \|I_{amb}(x + e_y) - I_{amb}(x)\|_1 \right)$$
    where $e_x, e_y$ are unit pixel shifts [S1].

### Parameters
*   **SH Order ($n$):** Set to 2 (second-order SH) for ambient illumination [S1].
*   **Canny Edge Thresholds:** $[100, 200]$ [S1].
*   **Dilation Kernel:** 3x3 [S1].

### Edge Cases and Pitfalls
*   **Weakly Textured/Planar Regions:** Hinder smooth normal optimization. Mitigated by applying monocular normal prior only to non-edge regions [S1].
*   **Dynamic Foreground Objects:** Cause multi-view inconsistencies. Mitigated by excluding dynamic regions using semantic masks [S1].
*   **Local Normal Variance:** Individual Gaussian normals can vary significantly, causing shading artifacts. Mitigated by deferred shading in screen space using final accumulated normals [S1].

## Operating characteristics
*   **Time Complexity:** Two-stage optimization. Stage I is comparable to 2DGS training with added normal prior computation. Stage II is faster as geometry is fixed, but requires deferred shading calculations [S1].
*   **Memory Complexity:** Stores per-Gaussian embeddings (Stage I) and SH coefficients (Stage II). Global ambient SH coefficients are small ($3 \times (n+1)$) [S1].
*   **Strengths:** Efficient reconstruction of relightable outdoor scenes; handles unconstrained lighting; avoids baked-in shadow artifacts of pure PRT methods [S1].
*   **Limitations:** Requires multi-view input; relies on off-the-shelf monocular normal estimators and semantic segmentation [S1].
*   **When to use:** Novel view synthesis and realistic relighting of outdoor scenes with complex lighting [S1].
*   **When not to use:** Indoor scenes with complex local lighting or single-view inputs [S1].

## Background
ROS-GS was proposed to address the high computational overhead of neural networks like NeRF and the inefficiency of low-frequency lighting representations in outdoor relighting [S1]. It builds on [Precomputed Radiance Transfer](13182-precomputed-radiance-transfer.md) by integrating PRT with 2DGS principles, using a hybrid lighting model (SG for sun, SH for ambient) to capture high-frequency directional effects that omnidirectional PRT assumptions limit [S1]. It was developed to enable efficient, high-quality relighting of outdoor scenes captured under unconstrained lighting conditions [S1].
